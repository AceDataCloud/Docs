## 簡介

Luma 是 Ace Data Cloud 提供的 AI 視頻服務，Luma Dream Machine 視頻生成。通過 Ace Data Cloud 統一 API，你可以使用 JavaScript 快速整合 Luma，實現文生視頻、圖生視頻、視頻續寫、首尾幀控制、循環視頻等功能。

## 前置條件

- 擁有 [Ace Data Cloud](https://platform.acedata.cloud) 帳號並獲取 API Token
- Node.js 18+ 或現代瀏覽器環境

## 基礎用法

調用 Luma API 的主端點為：

```
POST https://api.acedata.cloud/luma/videos
```



完整 JavaScript 程式碼範例：

```javascript
const response = await fetch("https://api.acedata.cloud/luma/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "Astronauts shuttle from space to volcano",
  "action": "generate",
  "enhancement": true
}),
});

const result = await response.json();
console.log(result);
```

請將 `YOUR_API_TOKEN` 替換為你在 Ace Data Cloud 平臺獲取的實際 Token。

## 響應處理

建議檢查響應狀態碼並處理錯誤：

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("調用成功:", result);
} else {
  console.error(`調用失敗，狀態碼: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js 封裝

推薦封裝為可重用函數：

```javascript
async function callLuma(data) {
  const response = await fetch("https://api.acedata.cloud/luma/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## 錯誤處理

常見錯誤碼：

| 狀態碼 | 說明 |
|--------|------|
| 401 | 認證失敗，請檢查 API Token |
| 403 | 餘額不足或無權訪問 |
| 429 | 請求頻率超限 |
| 500 | 伺服器內部錯誤 |
