## 簡介

Seedream 是 Ace Data Cloud 提供的 AI 圖像服務，字節跳動 Seedream 圖像生成模型。透過 Ace Data Cloud 統一 API，你可以使用 cURL 快速調用 Seedream，實現文生圖、圖片編輯、多種解析度、水印控制等功能。

## 前置條件

- 擁有 [Ace Data Cloud](https://platform.acedata.cloud) 帳號並獲取 API Token
- 安裝了 cURL 的終端環境

## 基礎用法

調用 Seedream API 的主端點為：

```
POST https://api.acedata.cloud/seedream/images
```

本範例使用 `doubao-seedream-4-0-250828` 模型。
可用模型包括：`doubao-seedream-4-5-251128`、`doubao-seedream-4-0-250828`、`doubao-seedream-3-0-t2i-250415`、`doubao-seededit-3-0-i2i-250628`。

完整 cURL 命令範例：

```bash
curl -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一隻白色的暹羅貓坐在窗臺上", "model": "doubao-seedream-4-0-250828", "size": "1K"}'
```

請將 `YOUR_API_TOKEN` 替換為你在 Ace Data Cloud 平台獲取的實際 Token。

## 回應範例

成功調用後返回 JSON 格式資料，例如：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## 使用 jq 處理回應

推薦使用 jq 工具格式化輸出：

```bash
curl -s -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一隻白色的暹羅貓坐在窗臺上", "model": "doubao-seedream-4-0-250828", "size": "1K"}' | jq .
```

## 錯誤處理

常見錯誤碼：

| 狀態碼 | 說明 |
|--------|------|
| 401 | 認證失敗，請檢查 API Token |
| 403 | 餘額不足或無權訪問 |
| 429 | 請求頻率超限 |
| 500 | 伺服器內部錯誤 |
