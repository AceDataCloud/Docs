## 簡介

Seedream 是 Ace Data Cloud 提供的 AI 圖像服務，字節跳動 Seedream 圖像生成模型。透過 Ace Data Cloud 統一 API，你可以使用 JavaScript 快速整合 Seedream，實現文生圖、圖片編輯、多種解析度、水印控制等功能。

## 前置條件

- 擁有 [Ace Data Cloud](https://platform.acedata.cloud) 帳號並獲取 API Token
- Node.js 18+ 或現代瀏覽器環境

## 基礎用法

呼叫 Seedream API 的主端點為：

```
POST https://api.acedata.cloud/seedream/images
```

本範例使用 `doubao-seedream-4-0-250828` 模型。  
可用模型包括：`doubao-seedream-4-5-251128`、`doubao-seedream-4-0-250828`、`doubao-seedream-3-0-t2i-250415`、`doubao-seededit-3-0-i2i-250628`。

完整 JavaScript 程式碼範例：

```javascript
const response = await fetch("https://api.acedata.cloud/seedream/images", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "一隻白色的暹羅貓坐在窗台上",
  "model": "doubao-seedream-4-0-250828",
  "size": "1K"
}),
});

const result = await response.json();
console.log(result);
```

請將 `YOUR_API_TOKEN` 替換為你在 Ace Data Cloud 平台獲取的實際 Token。

## 回應處理

建議檢查回應狀態碼並處理錯誤：

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("呼叫成功:", result);
} else {
  console.error(`呼叫失敗，狀態碼: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js 封裝

推薦封裝為可重用函式：

```javascript
async function callSeedream(data) {
  const response = await fetch("https://api.acedata.cloud/seedream/images", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## 錯誤處理

常見錯誤碼：

| 狀態碼 | 說明 |
|--------|------|
| 401 | 認證失敗，請檢查 API Token |
| 403 | 餘額不足或無權訪問 |
| 429 | 請求頻率超限 |
| 500 | 伺服器內部錯誤 |
