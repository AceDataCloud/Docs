## 簡介

AI Chat 是 Ace Data Cloud 提供的 AI 聊天服務，多模型 AI 對話服務。透過 Ace Data Cloud 統一 API，你可以使用 cURL 快速調用 AI Chat，實現多模型支援、有狀態對話、預設角色等功能。

## 前置條件

- 擁有 [Ace Data Cloud](https://platform.acedata.cloud) 帳號並取得 API Token
- 安裝了 cURL 的終端環境

## 基礎用法

調用 AI Chat API 的主端點為：

```
POST https://api.acedata.cloud/aichat/conversations
```

本範例使用 `gpt-4o` 模型。
可用模型包括：`gpt-4o`、`gpt-4`、`deepseek-r1`、`grok-3`。

完整 cURL 命令範例：

```bash
curl -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什麼是人工智能？", "stateful": true}'
```

請將 `YOUR_API_TOKEN` 替換為你在 Ace Data Cloud 平台取得的實際 Token。

## 回應範例

成功調用後返回 JSON 格式資料，例如：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## 使用 jq 處理回應

推薦使用 jq 工具格式化輸出：

```bash
curl -s -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什麼是人工智能？", "stateful": true}' | jq .
```

## 錯誤處理

常見錯誤碼：

| 狀態碼 | 說明 |
|--------|------|
| 401 | 認證失敗，請檢查 API Token |
| 403 | 餘額不足或無權訪問 |
| 429 | 請求頻率超限 |
| 500 | 伺服器內部錯誤 |
