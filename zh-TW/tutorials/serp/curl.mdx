## 簡介

Google Search 是 Ace Data Cloud 提供的搜尋服務，Google 搜尋 API。透過 Ace Data Cloud 統一 API，你可以使用 cURL 快速調用 Google Search，實現網頁搜尋、圖片搜尋、新聞搜尋、地圖搜尋、影片搜尋等功能。

## 前置條件

- 擁有 [Ace Data Cloud](https://platform.acedata.cloud) 帳號並取得 API Token
- 安裝了 cURL 的終端環境

## 基礎用法

調用 Google Search API 的主端點為：

```
POST https://api.acedata.cloud/serp/google
```

完整 cURL 命令範例：

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}'
```

請將 `YOUR_API_TOKEN` 替換為你在 Ace Data Cloud 平台取得的實際 Token。

## 回應範例

成功調用後回傳 JSON 格式資料，例如：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## 使用 jq 處理回應

建議使用 jq 工具格式化輸出：

```bash
curl -s -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}' | jq .
```

## 錯誤處理

常見錯誤碼：

| 狀態碼 | 說明 |
|--------|------|
| 401 | 認證失敗，請檢查 API Token |
| 403 | 餘額不足或無權限訪問 |
| 429 | 請求頻率超限 |
| 500 | 伺服器內部錯誤 |
