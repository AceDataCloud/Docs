## 簡介

Face Change 是 Ace Data Cloud 提供的 AI 影像服務，AI 人臉處理服務。透過 Ace Data Cloud 統一 API，你可以使用 Python 快速整合 Face Change，實現人臉替換、人臉美化、年齡變換、性別變換、動漫化、人臉分析等功能。

## 前置條件

- 擁有 [Ace Data Cloud](https://platform.acedata.cloud) 帳號並取得 API Token
- Python 3.7 及以上環境
- 安裝 requests 套件：`pip install requests`

## 基礎用法

呼叫 Face Change API 的主端點為：

```
POST https://api.acedata.cloud/face/swap
```



完整 Python 程式碼範例：

```python
import requests

url = "https://api.acedata.cloud/face/swap"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "source_image_url": "https://example.com/source-face.jpg",
    "target_image_url": "https://example.com/target-face.jpg"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

請將 `YOUR_API_TOKEN` 替換為你在 Ace Data Cloud 平台取得的實際 Token。

## 回應處理

成功呼叫後，API 回傳 JSON 格式資料。建議檢查 HTTP 狀態碼：

```python
if response.status_code == 200:
    result = response.json()
    print("呼叫成功:", result)
else:
    print(f"呼叫失敗，狀態碼: {response.status_code}")
    print(response.text)
```

## 進階用法

對於支援非同步任務的 API，可以透過回調 URL 取得結果：

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# 結果將透過回調 URL 推送到你的伺服器
```

## 錯誤處理

常見錯誤碼：

| 狀態碼 | 說明 |
|--------|------|
| 401 | 認證失敗，請檢查 API Token |
| 403 | 餘額不足或無權限存取 |
| 429 | 請求頻率超限 |
| 500 | 伺服器內部錯誤 |
