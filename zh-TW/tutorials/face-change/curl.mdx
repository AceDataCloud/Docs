## 簡介

Face Change 是 Ace Data Cloud 提供的 AI 影像服務，AI 人臉處理服務。透過 Ace Data Cloud 統一 API，你可以使用 cURL 快速調用 Face Change，實現人臉替換、人臉美化、年齡變換、性別變換、動漫化、人臉分析等功能。

## 前置條件

- 擁有 [Ace Data Cloud](https://platform.acedata.cloud) 帳號並獲取 API Token
- 安裝了 cURL 的終端環境

## 基礎用法

調用 Face Change API 的主端點為：

```
POST https://api.acedata.cloud/face/swap
```

完整 cURL 命令示例：

```bash
curl -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}'
```

請將 `YOUR_API_TOKEN` 替換為你在 Ace Data Cloud 平臺獲取的實際 Token。

## 回應示例

成功調用後返回 JSON 格式資料，例如：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## 使用 jq 處理回應

推薦使用 jq 工具格式化輸出：

```bash
curl -s -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}' | jq .
```

## 錯誤處理

常見錯誤碼：

| 狀態碼 | 說明 |
|--------|------|
| 401 | 認證失敗，請檢查 API Token |
| 403 | 餘額不足或無權訪問 |
| 429 | 請求頻率超限 |
| 500 | 伺服器內部錯誤 |
