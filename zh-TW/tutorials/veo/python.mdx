## 簡介

Veo 是 Ace Data Cloud 提供的 AI 視頻服務，Google Veo 視頻生成模型。透過 Ace Data Cloud 統一 API，你可以使用 Python 快速整合 Veo，實現文生視頻、圖生視頻、4K 解析度、多種比例等功能。

## 前置條件

- 擁有 [Ace Data Cloud](https://platform.acedata.cloud) 帳號並取得 API Token
- Python 3.7 及以上環境
- 安裝 requests 套件：`pip install requests`

## 基礎用法

呼叫 Veo API 的主端點為：

```
POST https://api.acedata.cloud/veo/videos
```

本範例使用 `veo3` 模型。
可用模型包括：`veo2`、`veo2-fast`、`veo3`、`veo3-fast`、`veo31`、`veo31-fast`。

完整 Python 程式碼範例：

```python
import requests

url = "https://api.acedata.cloud/veo/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "text2video",
    "prompt": "A coffee mug rotating slowly on a marble counter",
    "model": "veo3"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

請將 `YOUR_API_TOKEN` 替換為你在 Ace Data Cloud 平台取得的實際 Token。

## 回應處理

成功呼叫後，API 回傳 JSON 格式資料。建議檢查 HTTP 狀態碼：

```python
if response.status_code == 200:
    result = response.json()
    print("呼叫成功:", result)
else:
    print(f"呼叫失敗，狀態碼: {response.status_code}")
    print(response.text)
```

## 進階用法

對於支援非同步任務的 API，可以透過回調 URL 獲取結果：

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# 結果將透過回調 URL 推送到你的伺服器
```

## 錯誤處理

常見錯誤碼：

| 狀態碼 | 說明 |
|--------|------|
| 401 | 認證失敗，請檢查 API Token |
| 403 | 餘額不足或無權限訪問 |
| 429 | 請求頻率超限 |
| 500 | 伺服器內部錯誤 |
