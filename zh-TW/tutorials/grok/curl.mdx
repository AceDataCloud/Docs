## 簡介

Grok 是 Ace Data Cloud 提供的 AI 聊天服務，xAI Grok 系列大型語言模型。透過 Ace Data Cloud 統一 API，你可以使用 cURL 快速調用 Grok，實現多輪對話、系統提示詞、串流輸出、JSON 輸出模式、視覺理解等功能。

## 前置條件

- 擁有 [Ace Data Cloud](https://platform.acedata.cloud) 帳號並取得 API Token
- 安裝了 cURL 的終端環境

## 基礎用法

調用 Grok API 的主端點為：

```
POST https://api.acedata.cloud/grok/chat/completions
```

本範例使用 `grok-3` 模型。
可用模型包括：`grok-4`、`grok-4-1-fast`、`grok-3`、`grok-3-mini`、`grok-2-vision`。

完整 cURL 指令範例：

```bash
curl -X POST https://api.acedata.cloud/grok/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "grok-3", "messages": [{"role": "user", "content": "你好，請介紹一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

請將 `YOUR_API_TOKEN` 替換為你在 Ace Data Cloud 平台取得的實際 Token。

## 回應範例

成功調用後返回 JSON 格式資料，例如：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## 使用 jq 處理回應

建議使用 jq 工具格式化輸出：

```bash
curl -s -X POST https://api.acedata.cloud/grok/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "grok-3", "messages": [{"role": "user", "content": "你好，請介紹一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## 錯誤處理

常見錯誤碼：

| 狀態碼 | 說明 |
|--------|------|
| 401 | 認證失敗，請檢查 API Token |
| 403 | 餘額不足或無權限訪問 |
| 429 | 請求頻率超限 |
| 500 | 伺服器內部錯誤 |
