## 簡介

Claude 是 Ace Data Cloud 提供的 AI 聊天服務，Anthropic Claude 系列大語言模型。透過 Ace Data Cloud 統一 API，你可以使用 Python 快速整合 Claude，實現多輪對話、系統提示詞、串流輸出、JSON 輸出模式等功能。

## 前置條件

- 擁有 [Ace Data Cloud](https://platform.acedata.cloud) 帳號並取得 API Token
- Python 3.7 及以上環境
- 安裝 requests 套件：`pip install requests`

## 基礎用法

呼叫 Claude API 的主要端點為：

```
POST https://api.acedata.cloud/v1/chat/completions
```

本範例使用 `claude-sonnet-4-6` 模型。
可用模型包括：`claude-sonnet-4-6`、`claude-opus-4-5-20251101`、`claude-3-5-sonnet`。

完整 Python 程式碼範例：

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "claude-sonnet-4-6",
    "messages": [
        {
            "role": "user",
            "content": "你好，請介紹一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

請將 `YOUR_API_TOKEN` 替換為你在 Ace Data Cloud 平台取得的實際 Token。

## 回應處理

成功呼叫後，API 回傳 JSON 格式資料。建議檢查 HTTP 狀態碼：

```python
if response.status_code == 200:
    result = response.json()
    print("呼叫成功:", result)
else:
    print(f"呼叫失敗，狀態碼: {response.status_code}")
    print(response.text)
```

## 進階用法

對於聊天類 API，支援串流輸出以取得即時回應：

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## 錯誤處理

常見錯誤碼：

| 狀態碼 | 說明 |
|--------|------|
| 401 | 認證失敗，請檢查 API Token |
| 403 | 餘額不足或無權限訪問 |
| 429 | 請求頻率超限 |
| 500 | 伺服器內部錯誤 |
