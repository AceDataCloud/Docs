## 簡介

Suno 是 Ace Data Cloud 提供的 AI 音頻服務，Suno AI 音樂生成。透過 Ace Data Cloud 統一 API，你可以使用 JavaScript 快速整合 Suno，實現文本生成音樂、自訂歌詞、歌曲續寫、翻唱、人聲分離、歌詞生成等功能。

## 前置條件

- 擁有 [Ace Data Cloud](https://platform.acedata.cloud) 帳號並取得 API Token
- Node.js 18+ 或現代瀏覽器環境

## 基礎用法

呼叫 Suno API 的主端點為：

```
POST https://api.acedata.cloud/suno/audios
```

本範例使用 `chirp-v5` 模型。
可用模型包括：`chirp-v5`、`v4-5-plus`、`v4-5`、`v4`、`v3-5`。

完整 JavaScript 程式碼範例：

```javascript
const response = await fetch("https://api.acedata.cloud/suno/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A cheerful pop song about summer vacation",
  "model": "chirp-v5",
  "custom": false
}),
});

const result = await response.json();
console.log(result);
```

請將 `YOUR_API_TOKEN` 替換為你在 Ace Data Cloud 平台取得的實際 Token。

## 回應處理

建議檢查回應狀態碼並處理錯誤：

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("呼叫成功:", result);
} else {
  console.error(`呼叫失敗，狀態碼: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js 封裝

推薦封裝為可重複使用函式：

```javascript
async function callSuno(data) {
  const response = await fetch("https://api.acedata.cloud/suno/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## 錯誤處理

常見錯誤碼：

| 狀態碼 | 說明 |
|--------|------|
| 401 | 認證失敗，請檢查 API Token |
| 403 | 餘額不足或無權訪問 |
| 429 | 請求頻率超限 |
| 500 | 伺服器內部錯誤 |
