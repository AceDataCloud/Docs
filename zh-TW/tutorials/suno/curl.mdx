## 簡介

Suno 是 Ace Data Cloud 提供的 AI 音訊服務，Suno AI 音樂生成。透過 Ace Data Cloud 統一 API，你可以使用 cURL 快速調用 Suno，實現文本生成音樂、自訂歌詞、歌曲續寫、翻唱、人聲分離、歌詞生成等功能。

## 前置條件

- 擁有 [Ace Data Cloud](https://platform.acedata.cloud) 帳號並取得 API Token
- 安裝了 cURL 的終端環境

## 基礎用法

調用 Suno API 的主端點為：

```
POST https://api.acedata.cloud/suno/audios
```

本範例使用 `chirp-v5` 模型。  
可用模型包括：`chirp-v5`、`v4-5-plus`、`v4-5`、`v4`、`v3-5`。

完整 cURL 指令範例：

```bash
curl -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}'
```

請將 `YOUR_API_TOKEN` 替換為你在 Ace Data Cloud 平台取得的實際 Token。

## 回應範例

成功調用後回傳 JSON 格式資料，例如：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## 使用 jq 處理回應

建議使用 jq 工具格式化輸出：

```bash
curl -s -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}' | jq .
```

## 錯誤處理

常見錯誤碼：

| 狀態碼 | 說明                   |
|--------|------------------------|
| 401    | 認證失敗，請檢查 API Token |
| 403    | 餘額不足或無權訪問       |
| 429    | 請求頻率超限           |
| 500    | 伺服器內部錯誤         |
