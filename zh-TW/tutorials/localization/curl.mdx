## 簡介

Localization 是 Ace Data Cloud 提供的工具服務，AI 翻譯本地化服務。透過 Ace Data Cloud 統一 API，你可以使用 cURL 快速調用 Localization，實現 Markdown 翻譯、JSON 翻譯、18 種語言、保持格式等功能。

## 前置條件

- 擁有 [Ace Data Cloud](https://platform.acedata.cloud) 帳號並獲取 API Token
- 安裝了 cURL 的終端環境

## 基礎用法

調用 Localization API 的主端點為：

```
POST https://api.acedata.cloud/localization/translate
```

本示例使用 `gpt-4` 模型。
可用模型包括：`gpt-3.5`、`gpt-4`。

完整 cURL 命令示例：

```bash
curl -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 歡迎使用\n\n這是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}'
```

請將 `YOUR_API_TOKEN` 替換為你在 Ace Data Cloud 平台獲取的實際 Token。

## 回應示例

成功調用後返回 JSON 格式資料，例如：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## 使用 jq 處理回應

推薦使用 jq 工具格式化輸出：

```bash
curl -s -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 歡迎使用\n\n這是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}' | jq .
```

## 錯誤處理

常見錯誤碼：

| 狀態碼 | 說明 |
|--------|------|
| 401 | 認證失敗，請檢查 API Token |
| 403 | 餘額不足或無權訪問 |
| 429 | 請求頻率超限 |
| 500 | 伺服器內部錯誤 |
