---
title: "認證"
description: "如何使用 Ace Data Cloud API 進行身份認證"
---

所有 Ace Data Cloud API 使用 **Bearer Token** 認證。

## 獲取 Token

1. 在 [platform.acedata.cloud](https://platform.acedata.cloud) 註冊帳號
2. 訂閱需要的服務
3. 為每個服務建立憑證（API Token）

## 使用 Token

在每個請求的 `Authorization` 標頭中包含 Token：

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Tip">
  每個 Token 綁定到特定的服務訂閱。不同服務使用不同的 Token，或建立**全域**憑證以跨服務使用。
</Note>

## 速率限制

速率限制因服務和訂閱等級而異。超出限制時，API 回傳 `429 Too Many Requests`。

## 安全最佳實踐

- 不要在客戶端程式碼中暴露 API Token
- 使用環境變數儲存 Token
- 定期輪換 Token
- 開發和生產環境使用不同的 Token
