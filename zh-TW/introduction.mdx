## 什麼是 Ace Data Cloud？

Ace Data Cloud 是一個統一 AI API 平台，透過一個 API Key 和一致的介面，訪問全球領先的 AI 服務。

## 核心優勢

- **統一 API** — 一個 API Key 訪問 50+ AI 服務
- **OpenAI 相容** — Claude、Gemini、DeepSeek 等均可透過 OpenAI 介面直接調用
- **互動式沙盒** — 在文件中直接測試每個 API
- **按量付費** — 無訂閱費，按實際使用量計費
- **MCP 伺服器** — 原生支援 Cursor、Claude 等 AI 程式設計工具
