Germey Technology, LLC（以下简称“我们”或“我们的”），即Ace Data Cloud的公司，致力于保护您的隐私。本隐私政策解释了我们如何在您访问我们的Ace Data Cloud网站平台时收集、使用、披露和保护您的信息。请仔细阅读本隐私政策。使用本平台即表示您同意本隐私政策的条款。

## 我们收集的信息

我们收集各种类型的信息以向您提供和改进我们的服务：

1. **个人信息**：可以用来识别您的信息，例如您的姓名、电子邮件地址、电话号码、支付信息以及其他类似数据。
2. **非个人信息**：无法用于识别您的信息，包括但不限于您的IP地址、浏览器类型、操作系统、引荐URL以及您使用我们平台的相关信息。
3. **技术数据**：关于您使用我们API的数据，包括请求次数、请求数据类型以及相关的元数据。

## 使用目的

我们收集的信息用于以下各种目的：

1. **提供和维护服务**：运营和维护我们的平台，包括处理交易和提供客户支持。
2. **改进我们的平台**：了解您如何使用我们的平台，并改进和增强功能和用户体验。
3. **与您沟通**：向您发送更新、宣传材料和其他可能感兴趣的信息。您可以随时选择退出这些通讯。
4. **确保安全**：监控和分析使用情况和活动趋势，以确保我们平台的安全性和完整性。
5. **遵守法律义务**：遵守适用的法律、法规和法律程序。

## 信息披露

我们可能在以下情况下披露您的信息：

1. **服务提供商**：我们可能会与代表我们提供服务的第三方服务提供商共享您的信息，例如支付处理、数据分析、电子邮件发送、托管服务和客户支持。
2. **法律要求**：如果法律要求或响应公共当局的有效请求（例如法院或政府机构），我们可能会披露您的信息。
3. **业务转移**：在任何合并、公司资产出售、融资或将我们全部或部分业务出售给另一家公司时，或者在此类交易谈判期间，我们可能会披露或转移您的信息。
4. **您的同意**：在获得您明确同意的情况下，我们可能会为其他目的披露您的信息。

## 安全措施

我们实施合理的安全措施，以保护您的信息免受未经授权的访问、使用、篡改和披露。这些措施包括：

1. **数据加密**：我们使用行业标准的加密技术来保护传输到我们平台和从我们平台传输的数据。
2. **访问控制**：访问您的个人信息仅限于需要这些信息来履行其工作职责的授权人员。
3. **定期审计**：我们定期审计我们的安全系统和流程，以确保遵守行业标准和最佳实践。
4. **安全存储**：我们将个人信息存储在安全的环境中，防止未经授权的访问、使用或披露。

### 您的权利

您有权：

1. **访问您的信息**：请求访问我们持有的关于您的个人信息。
2. **更正您的信息**：请求更正任何不准确或不完整的个人信息。
3. **删除您的信息**：在法律规定的某些例外情况下，您可以请求删除您的个人信息。如果您希望删除您的信息，请联系我方支持团队 - office@acedata.cloud。
4. **选择退出**：通过遵循那些通信中包含的取消订阅指示，选择退出接收我们的宣传通信。

## 本隐私政策的变更

我们可能会不时更新本隐私政策。我们将在平台上发布新的隐私政策，以通知您任何变更。建议您定期查看本隐私政策的任何变更。本隐私政策的变更在发布时生效。
