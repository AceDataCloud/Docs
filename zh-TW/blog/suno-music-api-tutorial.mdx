## Suno 簡介

Suno 是目前最強大的 AI 音樂生成平台之一。透過 Ace Data Cloud 的 Suno API，你可以透過簡單的 API 調用生成高品質音樂。

## API 端點

| 端點 | 功能 |
|------|------|
| `POST /suno/audios` | 生成音樂（主端點） |
| `POST /suno/lyrics` | 生成歌詞 |
| `POST /suno/persona` | 管理歌手風格 |
| `POST /suno/wav` | 取得 WAV 格式 |
| `POST /suno/mp4` | 取得 MP4 格式 |
| `POST /suno/tasks` | 查詢任務狀態 |

## 基礎生成

### 文字描述生成

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### 自訂歌詞生成

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\n夏日的陽光灑滿了海岸\n微風中傳來浪花的聲音\n\n[Chorus]\n讓我們一起去遠方\n追逐那自由的夢想",
        "style": "pop upbeat",
        "title": "夏日冒險",
    },
)
```

## 進階功能

### 歌曲續寫

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### 生成歌詞

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "寫一首關於冬天的歌",
    },
)
```

## 可用模型

| 模型 | 特點 |
|------|------|
| chirp-v5 | 最新版本，最佳音質 |
| v4-5-plus | 增強版 |
| v4-5 | 穩定版 |
| v4 | 經典版 |
