## 什麼是 MCP

Model Context Protocol（MCP）是一種開放協議，允許 AI 助手（如 Claude、Cursor）直接調用外部工具和 API。透過 MCP，AI 不僅能回答問題，還能執行實際操作。

## Ace Data Cloud 提供的 MCP Server

| MCP Server | PyPI 套件名 | 功能 |
|------------|-------------|------|
| MCPSuno | mcp-suno | AI 音樂生成 |
| MCPSerp | mcp-serp | Google 搜尋 |
| MCPMidjourney | mcp-midjourney | AI 圖像生成 |
| MCPLuma | mcp-luma | AI 影片生成 |
| MCPSora | mcp-sora | AI 影片生成 |
| MCPVeo | mcp-veo | AI 影片生成 |
| MCPNanoBanana | mcp-nano-banana | AI 圖像生成 |

## 安裝與使用

### 安裝

```bash
pip install mcp-suno  # 或其他 MCP Server
```

### 配置環境變數

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### 在 Cursor 中配置

在 Cursor 的 MCP 設定中添加：

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### 在 Claude Desktop 中配置

編輯 Claude Desktop 配置檔，添加 MCP Server 配置。

## 使用場景

1. **在 Cursor 中生成音樂**：告訴 AI "用 Suno 生成一首歡快的歌曲"，AI 將直接調用 API
2. **搜尋即時資訊**：AI 可以透過 SERP MCP Server 搜尋最新資訊
3. **生成專案素材**：AI 可以調用 Midjourney 生成專案需要的圖片素材

## MCP vs 直接 API 調用

- **MCP**：適合在 AI 程式設計工具中使用，由 AI 自動調用
- **API**：適合在自己的應用中整合，程式控制

兩者使用相同的 Ace Data Cloud API Token，底層調用的也是相同的 API 端點。

## 總結

MCP 讓 AI 助手能夠直接調用 Ace Data Cloud 的各種 API。所有 MCP Server 都已發布到 PyPI，安裝配置簡單，讓你的 AI 工具更強大。

前往 [platform.acedata.cloud](https://platform.acedata.cloud) 獲取 API Token。
