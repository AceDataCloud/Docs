這篇文件目標只有一個：讓你**在 5 分鐘之內**，用 AceData Cloud 代理跑通第一條 Claude Code 指令。完整教學見各 IDE 子文件（[VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)）；本文只走「**終端 CLI** + **VS Code 擴充功能**」最快路徑。

> **為什麼用 AceData Cloud 代理 Claude Code**：
> - 國內直連，無需自配 VPN
> - 價格相比官方更低（按平台 Token 計費）
> - 同一把 Key 同時支援 Claude Messages API + Claude Code Token 協議

## 第 1 分鐘：申請憑證

打開 [Claude Messages 服務頁](https://platform.acedata.cloud/documents/claude-messages) 點擊「**Acquire**」按鈕：

![](https://cdn.acedata.cloud/nyq0xz.png)

平台會自動給你建立一個 Application 並贈送免費額度。把詳情頁裡的 **Base URL** + **API Token** 兩項記下來 —— 後續 5 步都要用。

| 欄位 | 值 | 用途 |
|------|------|------|
| `BASE_URL` | `https://api.acedata.cloud` | Claude Messages 兼容入口 |
| `API_TOKEN` | `sk-...`（詳情頁可複製） | Anthropic 兼容鑑權頭 |

## 第 2 分鐘：安裝 Claude Code

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows（原生 PowerShell）：

```powershell
irm https://claude.ai/install.ps1 | iex
```

安裝結束後，新開一個終端，確認能跑：

```bash
claude --version
```

> 看到版本號即可。Claude Code 自帶 Node.js 執行時，不依賴你機器上的 Node 版本。

## 第 3 分鐘：把環境變數指向 AceData Cloud

不要走官方 `claude login` 流程，而是用環境變數覆寫。兩種做法任選其一：

**做法 A：臨時（僅當前 Shell 會話）**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-你的-Token"
```

**做法 B：持久化（推薦）**

把上面兩行追加到 `~/.zshrc` 或 `~/.bashrc`，然後 `source` 一下。

> **常見踩坑**：環境變數名是 `ANTHROPIC_AUTH_TOKEN`，不是 `ANTHROPIC_API_KEY`；用錯名字時 Claude Code 會回退到官方端點報 401。

## 第 4 分鐘：跑第一條指令

進任意 Git 倉庫，跑：

```bash
claude
```

第一次啟動時若提示登入，按 `Esc` 跳過。然後輸入：

```
列出當前專案的依賴，並簡要解釋每個的用途。
```

正常會看到 Claude 調用 `read_file` / `glob` / `grep` 等工具瀏覽倉庫，然後給出列表。如果模型有正確回應、沒有報 401，說明代理已生效。

## 第 5 分鐘：把 VS Code 擴充功能也接上

1. 打開 VS Code → 擴充功能面板 → 搜 `Claude Code`，安裝 Anthropic 官方那個；
2. 重啟 VS Code 或在命令面板執行 `Developer: Reload Window`，讓擴充功能載入第 3 分鐘設定好的 `~/.claude/settings.json`；
3. 點擊編輯器右上角的 ✦ Spark 圖示，或底部狀態欄的「✱ Claude Code」打開面板；
4. 第一次會提示登入官方帳號，按 `Esc` 跳過即可——擴充功能會自動使用第 3 分鐘配置的 `ANTHROPIC_BASE_URL` 和 `ANTHROPIC_AUTH_TOKEN`。

> **提示**：VS Code 擴充功能和 CLI 共用同一份 `~/.claude/settings.json`，所以你不需要在 VS Code 裡再單獨配置一次。如果想用專案級配置覆蓋，可以在倉庫根目錄建立 `.claude/settings.local.json`（已 gitignored）。

成功後即可在面板裡拖文件提問、用 `@-mention` 引用文件做修改提案。所有計費都走 AceData Cloud。

## 驗證你確實在走代理

用 `--debug` 模式啟動一次，確認請求實際打到的是 AceData Cloud：

```bash
claude --debug -p "say hi" 2>&1 | grep -iE 'base.?url|api\.acedata|anthropic\.com' | head
```

看到 `https://api.acedata.cloud` 字樣即說明代理已接管；如果出現 `api.anthropic.com` 或返回 401，回到第 3 分鐘檢查環境變數名（必須是 `ANTHROPIC_AUTH_TOKEN`，不是 `ANTHROPIC_API_KEY`），並確認 `~/.claude/.credentials.json` 沒有把官方 token 寫在那裡（刪掉那個檔案即可）。

## 5 個最常被問的問題

**Q：跑了 `claude login` 後又把環境變數改成了 AceData，怎麼不生效？**  
A：`claude login` 會在 `~/.claude/.credentials.json` 寫入官方 token，**優先級高於環境變數**。刪除該檔案後再 `source ~/.zshrc` 即可。

**Q：能用 `--model claude-opus-4-7` 這種模型名嗎？**  
A：能。AceData Cloud 代理透傳 model 欄位，所有 Anthropic 公開模型 + 我們擴展的 `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5` 都支援。

**Q：能配多個 Profile（個人 + 公司）嗎？**  
A：能。Claude Code 支援 `~/.claude/settings.json` 多 profile；或者最簡單：寫兩個 shell 函數 `claude_personal` / `claude_work`，分別 export 不同的 `ANTHROPIC_AUTH_TOKEN` 後調 `claude $@`。

**Q：能在 GitHub Actions 裡跑嗎？**  
A：能。詳見 [Claude Code GitHub Actions 配置教學](https://platform.acedata.cloud/documents/claude-code-github-actions-integration)。

**Q：免費額度用完之後？**  
A：到 [應用管理](https://platform.acedata.cloud/applications) → 選這個 Claude Application → Topup 充值（按 Token 實際消耗扣費），或者切換到積分訂閱。
