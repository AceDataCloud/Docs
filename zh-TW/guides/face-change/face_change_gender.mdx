本文將介紹一種 人臉性別轉換 API 對接說明，它可以通過用戶上傳一張人臉圖片，基於人臉編輯與生成算法，輸出一張人臉性別轉換的圖片。男變女可實現美顏、淡妝、加瀏海和長髮的效果；女變男可實現加鬍鬚、變短髮的效果。

## 申請流程

要使用 API，需要先到 [人臉性別轉換 API](https://platform.acedata.cloud/documents/0e4e5318-060e-4976-8d3a-171301240f8c) 對應頁面申請對應的服務，進入頁面之後，點擊「Acquire」按鈕，如圖所示：

![](https://cdn.acedata.cloud/q6ytrc.png)

如果你尚未登錄或註冊，會自動跳轉到登錄頁面邀請您來註冊和登錄，登錄註冊之後會自動返回當前頁面。

在首次申請時會有免費額度贈送，可以免費使用該 API。

## 基本使用

首先先了解下基本的使用方式，就是輸入圖片鏈接以及性別信息，便可獲得處理後結果圖片，首先需要簡單地傳遞一個 `image_url` 字段，人臉圖片如下圖所示：

<p><img src="https://cdn.acedata.cloud/lrbtcn.jpg" width="500" class="m-auto"></p>

然後我們還需上傳關於人臉性別信息參數 `gender_infos` ，它是一個數組，我們可以傳多個信息，我們接下來就可以在界面上填寫對應的內容，如圖所示：

<p><img src="https://cdn.acedata.cloud/j22eg4.png" width="500" class="m-auto"></p>

可以看到這裡我們設置了 Request Headers，包括：

- `accept`：想要接收怎樣格式的響應結果，這裡填寫為 `application/json`，即 JSON 格式。
- `authorization`：調用 API 的密鑰，申請之後可以直接下拉選擇。

另外設置了 Request Body，包括：

- `image_url`：需要處理的人臉圖片鏈接。
- `gender_infos`：關於人臉性別和區域信息，其中性別是必選參數，0表示由男性變為女性，1表示女性變為男性。

選擇之後，可以發現右側也生成了對應代碼，如圖所示：

<p><img src="https://cdn.acedata.cloud/5kwudj.png" width="500" class="m-auto"></p>

點擊「Try」按鈕即可進行測試，如上圖所示，這裡我們就得到了如下結果：

```json
{
  "image_url": "https://faceeffect-1254418846.cos.ap-guangzhou.myqcloud.com/ft/SwapGenderPic/1256437459/1d85ceb9-6847-41ec-a9fd-7a20ddbd13b6"
}
```

可以看到，這裡返回的結果中有一個 `image_url` 字段，就是根據輸入性別變化參數而變化後的人臉圖片。其中變化後人臉信息如下所示：

<p><img src="https://cdn.acedata.cloud/hm7w44.png" width="500" class="m-auto"></p>

可以看到圖片中人臉是根據輸入的性別發生了變化。

另外如果想生成對應的對接代碼，可以直接複製生成，例如 CURL 的代碼如下：

```shell
curl -X POST 'https://api.acedata.cloud/face/change-gender' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg",
  "gender_infos": [{"gender":1}]
}'
```

Python 的對接代碼如下：

```python
import requests

url = "https://api.acedata.cloud/face/change-gender"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg",
    "gender_infos": [{"gender":1}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 錯誤處理

在調用 API 時，如果遇到錯誤，API 會返回相應的錯誤代碼和信息。例如：

- `400 token_mismatched`：Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`：Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`：Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`：Too many requests, you have exceeded the rate limit.
- `500 api_error`：Internal server error, something went wrong on the server.

### 錯誤響應示例

```json
}
```
