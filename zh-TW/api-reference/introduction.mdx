## 基礎 URL

所有 API 端點的基礎地址：

```
https://api.acedata.cloud
```

## 認證

所有端點需要 Bearer Token 認證：

```
Authorization: Bearer YOUR_API_TOKEN
```

## 在線測試

本參考文件中的每個端點都包含互動式沙盒。輸入 API Token 即可直接在瀏覽器中測試請求。

<Note title="Tip">
  在 [platform.acedata.cloud](https://platform.acedata.cloud) 獲取 API Token。
</Note>
