[MCP（Model Context Protocol）](https://modelcontextprotocol.io) 是由 Anthropic 推出的模型上下文協議，允許 AI 模型（如 Claude、GPT 等）通過標準化接口調用外部工具。通過 AceData Cloud 提供的 Veo MCP Server，你可以在 Claude Desktop、VS Code、Cursor 等 AI 客戶端中直接使用 Google Veo 生成 AI 視頻。

## 功能概覽

Veo MCP Server 提供以下核心功能：

- **文本生成視頻** — 通過文本提示詞生成高質量視頻
- **圖片生成視頻** — 以圖片為基礎生成視頻
- **多模型支持** — 支持 veo3、veo2、veo31-fast-ingredient 等模型
- **多種分辨率** — 支持 4K、1080p、GIF 等輸出格式
- **多種畫面比例** — 支持 16:9、9:16 等比例
- **1080p 升級** — 將已生成視頻升級到 1080p
- **任務查詢** — 監控生成進度並獲取結果

## 前置準備

使用前，你需要獲取 AceData Cloud API Token：

1. 註冊或登錄 [AceData Cloud 平台](https://platform.acedata.cloud)
2. 前往 [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos) 頁面
3. 點擊「Acquire」獲取 API Token（首次申請贈送免費額度）

## 安裝配置

### 方式一：pip 安裝（推薦）

```bash
pip install mcp-veo
```

### 方式二：源碼安裝

```bash
git clone https://github.com/AceDataCloud/VeoMCP.git
cd VeoMCP
pip install -e .
```

安裝完成後，即可使用 `mcp-veo` 命令啟動服務。

## 在 Claude Desktop 中使用

編輯 Claude Desktop 配置文件：

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

添加以下配置：

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

如果使用 `uvx`（無需提前安裝包）：

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

保存配置後重啟 Claude Desktop，即可在對話中使用 Veo 相關工具。

## 在 VS Code / Cursor 中使用

在項目根目錄創建 `.vscode/mcp.json`：

```json
{
  "servers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

或者使用 `uvx`：

```json
{
  "servers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

## 可用工具列表

| 工具名                   | 說明           |
| --------------------- | ------------ |
| `veo_text_to_video`   | 通過文本提示詞生成視頻  |
| `veo_image_to_video`  | 以圖片為基礎生成視頻   |
| `veo_get_1080p`       | 將視頻升級到 1080p |
| `veo_get_task`        | 查詢單個任務狀態     |
| `veo_get_tasks_batch` | 批量查詢任務狀態     |

## 使用示例

配置完成後，你可以在 AI 客戶端中直接用自然語言調用這些功能，例如：

- 「幫我用 Veo 生成一段星空延時攝影視頻」
- 「用這張風景照生成一段 4K 視頻」
- 「生成一段豎屏 9:16 的短視頻」
- 「把這個視頻升級到 1080p」
