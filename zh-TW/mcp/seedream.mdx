[MCP（Model Context Protocol）](https://modelcontextprotocol.io) 是由 Anthropic 推出的模型上下文協議，允許 AI 模型（如 Claude、GPT 等）通過標準化介面調用外部工具。透過 AceData Cloud 提供的 Seedream MCP Server，你可以在 Claude Desktop、VS Code、Cursor 等 AI 用戶端中直接使用字節跳動 Seedream 生成和編輯 AI 圖像。

## 功能概覽

Seedream MCP Server 提供以下核心功能：

- **文本生成圖像** — 通過文本提示詞生成高品質圖像（支援中英文提示詞）
- **圖像編輯** — 修改已有圖像的風格、背景、屬性等
- **虛擬試衣** — 將服裝穿戴到人物照片上
- **多模型支援** — 支援 Seedream v4.5、v4.0、v3.0 T2I、SeedEdit v3.0 I2I 等模型
- **多種解析度** — 支援 1K、2K、4K 及自適應解析度
- **種子控制** — 通過 seed 參數實現可複現的生成結果
- **任務查詢** — 監控生成進度並獲取結果

## 前置準備

使用前，你需要獲取 AceData Cloud API Token：

1. 註冊或登入 [AceData Cloud 平台](https://platform.acedata.cloud)
2. 前往 [Seedream Images API](https://platform.acedata.cloud/documents/seedream-images) 頁面
3. 點擊「Acquire」獲取 API Token（首次申請贈送免費額度）

## 安裝配置

### 方式一：pip 安裝（推薦）

```bash
pip install mcp-seedream-pro
```

### 方式二：原始碼安裝

```bash
git clone https://github.com/AceDataCloud/SeedreamMCP.git
cd SeedreamMCP
pip install -e .
```

安裝完成後，即可使用 `mcp-seedream-pro` 命令啟動服務。

## 在 Claude Desktop 中使用

編輯 Claude Desktop 配置檔：

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

添加以下配置：

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

如果使用 `uvx`（無需提前安裝套件）：

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

保存配置後重啟 Claude Desktop，即可在對話中使用 Seedream 相關工具。

## 在 VS Code / Cursor 中使用

在專案根目錄建立 `.vscode/mcp.json`：

```json
{

      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
```

## 可用工具列表

| 工具名 | 說明 |
|--------|------|
| `seedream_generate_image` | 通過文本提示詞生成圖像 |
| `seedream_edit_image` | 編輯或修改已有圖像 |
| `seedream_get_task` | 查詢單個任務狀態 |
| `seedream_get_tasks_batch` | 批量查詢任務狀態 |
| `seedream_list_models` | 列出所有可用模型及其能力 |
| `seedream_list_sizes` | 列出可用的圖像尺寸和解析度選項 |

## 使用示例

配置完成後，你可以在 AI 用戶端中直接用自然語言調用這些功能，例如：

- 「幫我用 Seedream 生成一張水墨畫風格的山水圖」
- 「把這張照片的背景改成星空」
- 「用 Seedream v4.5 生成一張 4K 高清人像」
- 「把這件衣服虛擬試穿到這張照片上」
