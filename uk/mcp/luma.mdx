[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — це протокол контексту моделі, розроблений компанією Anthropic, який дозволяє AI моделям (таким як Claude, GPT тощо) викликати зовнішні інструменти через стандартизований інтерфейс. Завдяки Luma MCP Server, наданому AceData Cloud, ви можете безпосередньо генерувати AI відео в таких AI клієнтах, як Claude Desktop, VS Code, Cursor тощо.

## Огляд функцій

Luma MCP Server надає такі основні функції:

- **Генерація відео з тексту** — створення відео високої якості за допомогою текстових підказок
- **Генерація відео з зображення** — створення відео на основі зображення
- **Продовження відео** — продовження генерації з останнього кадру існуючого відео
- **Різні співвідношення сторін** — підтримка 16:9, 9:16, 1:1 та інших співвідношень
- **Покращення зображення** — необов'язкова функція покращення візуальної якості
- **Запит завдань** — моніторинг прогресу генерації та отримання результатів

## Попередня підготовка

Перед використанням вам потрібно отримати AceData Cloud API Token:

1. Зареєструйтесь або увійдіть на [платформу AceData Cloud](https://platform.acedata.cloud)
2. Перейдіть на сторінку [Luma Videos API](https://platform.acedata.cloud/documents/luma-videos)
3. Натисніть «Acquire», щоб отримати API Token (перший запит надає безкоштовний ліміт)

## Встановлення та налаштування

### Спосіб перший: установка через pip (рекомендується)

```bash
pip install mcp-luma
```

### Спосіб другий: установка з вихідного коду

```bash
git clone https://github.com/AceDataCloud/MCPLuma.git
cd MCPLuma
pip install -e .
```

Після завершення установки ви можете використовувати команду `mcp-luma` для запуску сервісу.

## Використання в Claude Desktop

Редагуйте конфігураційний файл Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додайте наступну конфігурацію:

```json
{
  "mcpServers": {
    "luma": {
      "command": "mcp-luma",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Якщо ви використовуєте `uvx` (не потрібно попередньо встановлювати пакет):

```json
{
  "mcpServers": {
    "luma": {
      "command": "uvx",
      "args": ["mcp-luma"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Збережіть конфігурацію та перезапустіть Claude Desktop, щоб використовувати інструменти Luma в діалозі.

## Використання в VS Code / Cursor

У кореневій директорії проекту створіть `.vscode/mcp.json`:

```json

      "command": "mcp-luma",
      "env": {

      }
    }
  }

```

Або використовуйте `uvx`:

```json
{
  "servers": {
    "luma": {
      "command": "uvx",

      "env": {
```

## Список доступних інструментів

| Назва інструменту                     | Опис                       |
| ------------------------------------- | -------------------------- |
| `luma_generate_video`                 | Генерація відео з текстових підказок    |
| `luma_generate_video_from_image`      | Генерація відео з зображення        |
| `luma_extend_video`                   | Продовження існуючого відео         |
| `luma_extend_video_from_url`          | Продовження відео з вказаного URL |
| `luma_get_task`                       | Запит стану одного завдання       |
| `luma_get_tasks_batch`                | Пакетний запит стану завдань     |

## Приклади використання

Після налаштування ви можете безпосередньо використовувати ці функції в AI клієнті природною мовою, наприклад:

- «Допоможіть мені згенерувати відео заходу сонця на березі моря»
- «Використайте це зображення як перший кадр, щоб згенерувати 5-секундне відео»
- «Продовжте це відео, додавши ще один фрагмент»
- «Згенеруйте вертикальне відео зі співвідношенням 9:16»
