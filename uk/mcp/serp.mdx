[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — це протокол контексту моделі, розроблений компанією Anthropic, який дозволяє AI моделям (таким як Claude, GPT тощо) викликати зовнішні інструменти через стандартизований інтерфейс. Завдяки SERP MCP Server, наданому AceData Cloud, ви можете безпосередньо виконувати пошук в Google у таких AI-клієнтах, як Claude Desktop, VS Code, Cursor тощо, отримуючи результати пошуку веб-сторінок, зображень, новин, відео, місць тощо.

## Огляд функцій

SERP MCP Server надає такі основні функції:

- **Пошук веб-сторінок** — пошук результатів веб-сторінок Google
- **Пошук зображень** — пошук зображень Google
- **Пошук новин** — пошук новин Google
- **Пошук відео** — пошук відео Google
- **Пошук місць** — пошук інформації про місця Google
- **Пошук на карті** — пошук карт Google
- **Багатомовність та багаторегіональність** — підтримка параметрів країни та мови
- **Фільтрація за часовими рамками** — фільтрація результатів за днями, тижнями, місяцями, роками

## Попередня підготовка

Перед використанням вам потрібно отримати AceData Cloud API Token:

1. Зареєструйтесь або увійдіть на [платформу AceData Cloud](https://platform.acedata.cloud)
2. Перейдіть на сторінку [Google SERP API](https://platform.acedata.cloud/documents/serp-google)
3. Натисніть «Acquire», щоб отримати API Token (перший запит надає безкоштовний ліміт)

## Встановлення та налаштування

### Спосіб перший: установка через pip (рекомендується)

```bash
pip install mcp-serp
```

### Спосіб другий: установка з вихідного коду

```bash
git clone https://github.com/AceDataCloud/SerpMCP.git
cd SerpMCP
pip install -e .
```

Після завершення установки ви можете використовувати команду `mcp-serp` для запуску сервісу.

## Використання в Claude Desktop

Редагуйте конфігураційний файл Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додайте наступну конфігурацію:

```json
{
  "mcpServers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Якщо ви використовуєте `uvx` (не потрібно попередньо встановлювати пакет):

```json
{
  "mcpServers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Збережіть конфігурацію та перезапустіть Claude Desktop, щоб мати можливість використовувати інструменти пошуку Google в діалозі.

## Використання в VS Code / Cursor

У кореневій директорії проекту створіть файл `.vscode/mcp.json`:

```json
{
  "servers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Або використовуйте `uvx`:

```json
{
  "servers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

## Список доступних інструментів

| Назва інструменту      | Опис          |
| -------------------- | ----------- |
| `serp_google_search` | Пошук веб-сторінок Google |
| `serp_google_images` | Пошук зображень Google |
| `serp_google_news`   | Пошук новин Google |
| `serp_google_videos` | Пошук відео Google |
| `serp_google_places` | Пошук місць Google |
| `serp_google_maps`   | Пошук карт Google |
