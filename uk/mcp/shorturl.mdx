[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — це протокол контексту моделі, розроблений Anthropic, який дозволяє AI-моделям (таким як Claude, GPT тощо) викликати зовнішні інструменти через стандартизований інтерфейс. За допомогою ShortURL MCP Server від AceData Cloud ви можете безпосередньо створювати короткі посилання у клієнтах AI, таких як Claude Desktop, VS Code, Cursor тощо.

## Огляд функцій

ShortURL MCP Server надає такі основні функції:

- **Скорочення одного посилання** — перетворення довгого URL у коротке, зручне для поширення посилання
- **Пакетне скорочення посилань** — одночасне скорочення кількох URL (до 10)
- **Інструкції з використання** — отримання повного керівництва та найкращих практик
- **Інформація про API** — перегляд деталей API та опис кодів помилок

## Попередні вимоги

Перед використанням необхідно отримати API Token від AceData Cloud:

1. Зареєструйтесь або увійдіть на [AceData Cloud платформу](https://platform.acedata.cloud)
2. Перейдіть на сторінку [ShortURL API](https://platform.acedata.cloud/documents/short-url)
3. Натисніть «Acquire» для отримання API Token (перший запит надає безкоштовний ліміт)

## Встановлення та налаштування

### Варіант 1: Встановлення через pip (рекомендується)

```bash
pip install mcp-shorturl
```

### Варіант 2: Встановлення з вихідного коду

```bash
git clone https://github.com/AceDataCloud/ShortURLMCP.git
cd ShortURLMCP
pip install -e .
```

Після встановлення можна запускати сервер командою `mcp-shorturl`.

## Використання в Claude Desktop

Відредагуйте конфігураційний файл Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додайте наступну конфігурацію:

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ваш API Token"
      }
    }
  }
}
```

Якщо використовуєте `uvx` (не потребує попереднього встановлення пакетів):

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "uvx",
      "args": ["mcp-shorturl"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ваш API Token"
      }
    }
  }
}
```

Після збереження конфігурації перезапустіть Claude Desktop — тепер ви зможете користуватися інструментами ShortURL у діалогах.

## Використання у VS Code / Cursor

Створіть у корені проекту файл `.vscode/mcp.json`:

```json
{
  "servers": {
    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ваш API Token"
      }
    }
  }
}
```

Або з `uvx`:

```json
{
  "servers": {
    "shorturl": {
      "command": "uvx",
      "args": ["mcp-shorturl"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ваш API Token"
      }
    }
  }
}
```

## Список доступних інструментів

| Назва інструменту           | Опис                                  |
|-----------------------------|-------------------------------------|
| `shorturl_create`            | Скорочення одного URL                |
| `shorturl_batch_create`      | Пакетне скорочення кількох URL (до 10) |
| `shorturl_get_usage_guide`   | Отримання повного керівництва       |
| `shorturl_get_api_info`      | Отримання деталей API               |

## Приклади використання
