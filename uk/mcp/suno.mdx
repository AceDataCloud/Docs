[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — це протокол контексту моделі, представлений Anthropic, який дозволяє моделям ШІ (таким як Claude, GPT тощо) викликати зовнішні інструменти через стандартизований інтерфейс. За допомогою Suno MCP Server, наданого AceData Cloud, ви можете безпосередньо генерувати музику, тексти пісень і керувати аудіопроєктами в таких клієнтах ШІ, як Claude Desktop, VS Code, Cursor тощо.

## Огляд функцій

Suno MCP Server надає такі основні функції:

- **Генерація музики** — генерування музики ШІ за текстовими підказками
- **Користувацька творчість** — повний контроль над текстами пісень, назвами та музичними стилями
- **Продовження пісень** — продовження наявних пісень з будь-якої часової точки
- **Кавери/ремікси** — створення кавер-версій у різних стилях
- **Генерація текстів пісень** — генерування структурованих текстів пісень на основі описів
- **Голосові персонажі** — збереження та повторне використання голосових стилів
- **Конвертація медіа** — отримання MP4, WAV, MIDI, розділеного вокалу тощо
- **Оптимізація стилю** — оптимізація тегів музичного стилю
- **Запит завдань** — моніторинг прогресу генерації та отримання результатів

## Попередня підготовка

Перед використанням вам потрібно отримати AceData Cloud API Token:

1. Зареєструйтеся або увійдіть на [платформу AceData Cloud](https://platform.acedata.cloud)
2. Перейдіть на сторінку [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Натисніть «Acquire», щоб отримати API Token (за перше отримання надається безкоштовний ліміт)

## Спосіб 1: використання розміщеного MCP Server (рекомендовано, без встановлення)

AceData Cloud уже розмістив **Suno MCP Server** у хмарі, **не потрібно локально встановлювати жодні залежності**, просто вкажіть цей URL у клієнті ШІ, щоб почати користуватися:

```
https://suno.mcp.acedata.cloud/mcp
```

Спосіб автентифікації: достатньо додати `Authorization: Bearer ваш API Token` у заголовок запиту (Claude.ai автоматично виконує це через OAuth, не потрібно вручну вводити Token).

### Claude.ai (вебверсія, вхід через OAuth, найпростіше)

1. Відкрийте [Claude.ai](https://claude.ai) → **Customize** у нижньому лівому куті → **Connectors** → **Add More**
2. У полі URL введіть: `https://suno.mcp.acedata.cloud/mcp`
3. Завершіть авторизаційний вхід OAuth (автоматичне перенаправлення на сторінку входу AceData Cloud)
4. Поверніться до інтерфейсу чату, і інструмент буде доступний

### Claude Desktop

Відредагуйте файл конфігурації:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Після збереження перезапустіть Claude Desktop, щоб зміни набули чинності.

### Claude Code (термінальний командний рядок)

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Інші клієнти з підтримкою MCP

Будь-який клієнт, що підтримує протокол MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant тощо), може підключитися, вказавши такі два параметри:

- **URL**: `https://suno.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer ваш API Token`

## Спосіб 2: локальний запуск (встановлення через pip / uvx)

Якщо вам потрібно працювати офлайн, налаштовувати код або розгортати у внутрішній мережі, ви можете встановити MCP Server локально та запустити його через stdio.

### Встановлення

Встановлення через pip (рекомендовано):

```bash
pip install mcp-suno
```

Або встановлення з вихідного коду:

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

Після завершення встановлення ви можете використати команду `mcp-suno` для запуску служби.

### Використання в Claude Desktop (локально)

Відредагуйте файл конфігурації Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додайте таку конфігурацію:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Якщо використовуєте `uvx` (не потрібно встановлювати пакет заздалегідь):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Після збереження конфігурації перезапустіть Claude Desktop, щоб зміни набули чинності.

### Використання у VS Code / Cursor (локально)

## Приклади використання

Після завершення налаштування ви можете безпосередньо викликати ці функції в AI-клієнті природною мовою, наприклад:

- 「Допоможи мені згенерувати поп-музику про літо」
- 「Зроби кавер цієї пісні в джазовому стилі」
- 「Продовж цю пісню, починаючи з 30-ї секунди」
- 「Згенеруй текст пісні китайською мовою, тема — подорожі」
- 「Відокрем вокал цієї пісні»
- 「Допоможи мені перетворити цю пісню у формат MIDI」

## Розширене керування та Studio-проєкти

`suno_generate_music` підтримує `variety`; `suno_generate_custom_music` також підтримує
`max_mode` і `audio_weight`. Для `max_mode` використовується вищий тарифний рівень API, за замовчуванням він не ввімкнений,
і його слід установлювати після того, як користувач явно вибере розширений режим. Поточні ціни визначаються сторінкою сервісу платформи.

`suno_generate_with_custom_model` може використовувати `instrumental=true` для генерації інструментальної музики або
`lyric_prompt` для автоматичної генерації тексту пісні; інакше надайте
`lyric`. Назву та стиль можна не вказувати, також можна передати
`negative_tags`, `vocal_gender`, `weirdness`, `style_influence`, `duration` і
`callback_url`. Явні контрольні значення `0` буде збережено.

`request.action` у `suno_manage_project` може бути `create`, `retrieve`, `save`,
`upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`,
`remove_track`, `render`. Вхідні дані відрізняються залежно від дії, для змін у проєкті слід використовувати останній отриманий `version_id`;
під час збереження передавайте повний `state`, зберігаючи наявні доріжки та поля.

Окрім `retrieve`, для кожного виклику необхідно вказувати `idempotency_key`. Для нових операцій запису використовуйте новий ключ;
у разі тайм-ауту або невизначеного результату прийняття зберігайте початковий ключ і повторюйте запит, що є повністю ідентичним, або перевіряйте початкове завдання, не
змінюйте ключ автоматично та не надсилайте повторно платну генерацію. Інтервали вихідного аудіо вимірюються в секундах, інтервали часової шкали проєкту — у тактах. Генерація лише створює кандидатів,
для запису в доріжку потрібно вибрати кандидата та викликати `commit_candidate`.

Для асинхронно прийнятого `task_id` використовуйте `suno_get_task` для запиту. Якщо `finished_at` порожнє, продовжуйте очікування,
після кінцевого стану перевірте `response.success` і помилки; не вважайте успішне прийняття успішною генерацією, фіксацією або експортом.
`suno_get_tasks_batch` повертає повні JSON-записи завдань, зберігаючи об’єкти користувацьких моделей, стан проєкту,
кандидатів і всілякі результати, зокрема MIDI. Повний робочий процес дивіться в [Посібнику зі Studio-проєктів](https://platform.acedata.cloud/documents/suno-projects-integration).
