[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — це протокол контексту моделі, розроблений компанією Anthropic, який дозволяє AI моделям (таким як Claude, GPT тощо) викликати зовнішні інструменти через стандартизований інтерфейс. Завдяки Veo MCP Server, наданому AceData Cloud, ви можете безпосередньо використовувати Google Veo для генерації AI відео в таких AI клієнтах, як Claude Desktop, VS Code, Cursor тощо.

## Огляд функцій

Veo MCP Server надає такі основні функції:

- **Генерація відео з тексту** — створення високоякісного відео за допомогою текстових підказок
- **Генерація відео з зображень** — створення відео на основі зображень
- **Підтримка кількох моделей** — підтримка моделей veo3, veo2, veo31-fast-ingredient тощо
- **Різні роздільні здатності** — підтримка 4K, 1080p, GIF тощо
- **Різні співвідношення сторін** — підтримка 16:9, 9:16 тощо
- **Оновлення до 1080p** — оновлення вже згенерованого відео до 1080p
- **Запит завдань** — моніторинг прогресу генерації та отримання результатів

## Попередня підготовка

Перед використанням вам потрібно отримати AceData Cloud API Token:

1. Зареєструйтесь або увійдіть на [платформу AceData Cloud](https://platform.acedata.cloud)
2. Перейдіть на сторінку [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos)
3. Натисніть «Acquire», щоб отримати API Token (перший запит надає безкоштовний ліміт)

## Встановлення та налаштування

### Спосіб перший: установка через pip (рекомендується)

```bash
pip install mcp-veo
```

### Спосіб другий: установка з вихідного коду

```bash
git clone https://github.com/AceDataCloud/MCPVeo.git
cd MCPVeo
pip install -e .
```

Після завершення установки ви можете використовувати команду `mcp-veo` для запуску сервісу.

## Використання в Claude Desktop

Редагуйте конфігураційний файл Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додайте наступну конфігурацію:

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Якщо ви використовуєте `uvx` (не потрібно попередньо встановлювати пакет):

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Збережіть конфігурацію та перезапустіть Claude Desktop, щоб використовувати інструменти Veo в діалозі.

## Використання в VS Code / Cursor

У кореневій директорії проекту створіть `.vscode/mcp.json`:

```json
{
  "servers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Або використовуйте `uvx`:

```json
{
  "servers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

## Список доступних інструментів

| Назва інструменту         | Опис                     |
| --------------------- | ---------------------- |
| `veo_text_to_video`   | Генерація відео з текстових підказок  |
| `veo_image_to_video`  | Генерація відео на основі зображень   |
| `veo_get_1080p`       | Оновлення відео до 1080p |
| `veo_get_task`        | Запит статусу окремого завдання     |
| `veo_get_tasks_batch` | Пакетний запит статусу завдань     |

## Приклади використання

Після завершення налаштування ви можете безпосередньо використовувати ці функції в AI клієнтах, наприклад:

- «Допоможи мені створити відео з таймлапсом зоряного неба за допомогою Veo»
- «Створи 4K відео на основі цього пейзажного зображення»
- «Згенеруй коротке відео у вертикальному форматі 9:16»
- «Онови це відео до 1080p»
