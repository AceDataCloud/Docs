[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — це протокол контексту моделі, розроблений компанією Anthropic, який дозволяє AI-моделям (таким як Claude, GPT тощо) викликати зовнішні інструменти через стандартизований інтерфейс. За допомогою Veo MCP Server від AceData Cloud ви можете безпосередньо використовувати Google Veo для створення AI-відео в клієнтах AI, таких як Claude Desktop, VS Code, Cursor тощо.

## Огляд функцій

Veo MCP Server надає такі основні функції:

- **Генерація відео з тексту** — створення високоякісних відео на основі текстових підказок
- **Генерація відео з зображень** — створення відео на основі зображень
- **Підтримка кількох моделей** — підтримка моделей veo3, veo2, veo31-fast-ingredients тощо
- **Різні роздільні здатності** — підтримка форматів 4K, 1080p, GIF тощо
- **Різні співвідношення сторін** — підтримка 16:9, 9:16 та інших пропорцій
- **Покращення до 1080p** — оновлення вже створеного відео до 1080p
- **Запит стану завдань** — моніторинг прогресу генерації та отримання результатів

## Попередні вимоги

Перед використанням вам потрібно отримати API Token AceData Cloud:

1. Зареєструйтесь або увійдіть на [AceData Cloud платформу](https://platform.acedata.cloud)
2. Перейдіть на сторінку [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos)
3. Натисніть «Acquire» для отримання API Token (перший запит надає безкоштовний ліміт)

## Встановлення та налаштування

### Варіант 1: встановлення через pip (рекомендовано)

```bash
pip install mcp-veo
```

### Варіант 2: встановлення з вихідного коду

```bash
git clone https://github.com/AceDataCloud/VeoMCP.git
cd VeoMCP
pip install -e .
```

Після встановлення можна запускати сервіс командою `mcp-veo`.

## Використання в Claude Desktop

Відредагуйте конфігураційний файл Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додайте наступну конфігурацію:

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Якщо використовуєте `uvx` (без необхідності попередньо встановлювати пакети):

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Після збереження конфігурації перезапустіть Claude Desktop, щоб використовувати інструменти Veo у діалогах.

## Використання у VS Code / Cursor

Створіть у кореневій папці проекту файл `.vscode/mcp.json`:

```json
{
  "servers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Або використовуйте `uvx`:

```json
{
  "servers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

## Список доступних інструментів

| Назва інструменту       | Опис                              |
|-------------------------|----------------------------------|
| `veo_text_to_video`      | Генерація відео з текстових підказок |
| `veo_image_to_video`     | Генерація відео на основі зображень  |
| `veo_get_1080p`          | Оновлення відео до 1080p             |
| `veo_get_task`           | Запит статусу окремого завдання       |
| `veo_get_tasks_batch`    | Масовий запит статусів завдань        |

## Приклади використання

Після налаштування ви можете безпосередньо викликати ці функції природною мовою в AI-клієнті, наприклад:

- «Допоможи мені створити відео з таймлапсом зоряного неба за допомогою Veo»
- «Зроби 4K відео з цього пейзажного фото»
- «Створи коротке відео у вертикальному форматі 9:16»
- «Онови це відео до 1080p»
