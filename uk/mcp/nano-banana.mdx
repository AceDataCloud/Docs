[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — це протокол контексту моделі, представлений компанією Anthropic, який дозволяє AI моделям (таким як Claude, GPT тощо) викликати зовнішні інструменти через стандартизований інтерфейс. Завдяки Nano Banana MCP Server, наданому AceData Cloud, ви можете безпосередньо генерувати та редагувати AI зображення в таких AI клієнтах, як Claude Desktop, VS Code, Cursor тощо.

## Огляд функцій

Nano Banana MCP Server надає такі основні функції:

- **Генерація зображень** — створення високоякісних зображень за текстовими підказками
- **Редагування зображень** — модифікація існуючих зображень або комбінування кількох зображень
- **Віртуальна примірка** — одягання одягу на фотографії людей
- **Продуктове впровадження** — розміщення продукту в реальних сценах
- **Підтримка кількох моделей** — підтримка моделей nano-banana, nano-banana-2 та nano-banana-pro
- **Запит завдань** — моніторинг прогресу генерації та отримання результатів

## Попередня підготовка

Перед використанням вам потрібно отримати AceData Cloud API Token:

1. Зареєструйтесь або увійдіть на [платформу AceData Cloud](https://platform.acedata.cloud)
2. Перейдіть на сторінку [Nano Banana Images API](https://platform.acedata.cloud/documents/nano-banana-images)
3. Натисніть «Acquire», щоб отримати API Token (перший запит надає безкоштовний ліміт)

## Встановлення та налаштування

### Спосіб 1: Встановлення через pip (рекомендується)

```bash
pip install mcp-nanobanana-pro
```

### Спосіб 2: Встановлення з вихідного коду

```bash
git clone https://github.com/AceDataCloud/NanoBananaMCP.git
cd NanoBananaMCP
pip install -e .
```

Після завершення встановлення ви можете використовувати команду `mcp-nanobanana-pro` для запуску сервісу.

## Використання в Claude Desktop

Редагуйте конфігураційний файл Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додайте наступну конфігурацію:

```json
{
  "mcpServers": {
    "nanobanana": {
      "command": "mcp-nanobanana-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Якщо ви використовуєте `uvx` (не потрібно попередньо встановлювати пакет):

```json
{
  "mcpServers": {
    "nanobanana": {
      "command": "uvx",
      "args": ["mcp-nanobanana-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Збережіть конфігурацію та перезапустіть Claude Desktop, щоб використовувати інструменти Nano Banana в діалозі.

## Використання в VS Code / Cursor

У кореневій директорії проекту створіть `.vscode/mcp.json`:

```json
{
  "servers": {
    "nanobanana": {
      "command": "mcp-nanobanana-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Або використовуйте `uvx`:

```json
{
  "servers": {
    "nanobanana": {
      "command": "uvx",
      "args": ["mcp-nanobanana-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

## Список доступних інструментів

| Назва інструменту                | Опис                     |
| ---------------------------- | ---------------------- |
| `nanobanana_generate_image`  | Генерація зображень за текстовими підказками |
| `nanobanana_edit_image`      | Редагування або комбінування існуючих зображень |
| `nanobanana_get_task`        | Запит статусу окремого завдання |
| `nanobanana_get_tasks_batch` | Пакетний запит статусу завдань |
