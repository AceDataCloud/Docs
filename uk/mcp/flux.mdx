[MCP（Model Context Protocol）](https://modelcontextprotocol.io) — це протокол контексту моделі, представлений Anthropic, який дозволяє AI-моделям (таким як Claude, GPT тощо) викликати зовнішні інструменти через стандартизовані інтерфейси. За допомогою Flux MCP Server, наданого AceData Cloud, ви можете безпосередньо генерувати та редагувати AI-зображення в AI-клієнтах, таких як Claude Desktop, VS Code, Cursor тощо.

## Огляд функцій

Flux MCP Server надає такі основні функції:

- **Генерація зображень із тексту** — генерування високоякісних зображень за текстовими підказками
- **Редагування зображень** — редагування наявних зображень на основі текстових інструкцій
- **Підтримка кількох моделей** — підтримка різних моделей, зокрема Flux Pro, Flux Dev, Flux 2, Flux Kontext тощо
- **Запит моделей** — перегляд усіх доступних моделей та їхніх можливостей
- **Запит завдань** — моніторинг прогресу генерації та отримання результатів

## Попередня підготовка

Перед використанням вам потрібно отримати AceData Cloud API Token:

1. Зареєструйтеся або увійдіть на [платформу AceData Cloud](https://platform.acedata.cloud)
2. Перейдіть на сторінку [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Натисніть «Acquire», щоб отримати API Token (за перше отримання надається безкоштовний ліміт)

## Спосіб 1: використання хостованого MCP Server (рекомендовано, без встановлення)

AceData Cloud уже розмістив **Flux MCP Server** у хмарі, **не потрібно локально встановлювати жодні залежності** — просто вкажіть цей URL в AI-клієнті, і ним можна користуватися:

```
https://flux.mcp.acedata.cloud/mcp
```

Спосіб автентифікації: достатньо додати `Authorization: Bearer ваш API Token` до заголовка запиту (Claude.ai автоматично виконує це через OAuth, тому не потрібно вручну вводити Token).

### Claude.ai（вебверсія, вхід через OAuth, найпростіше）

1. Відкрийте [Claude.ai](https://claude.ai) → у нижньому лівому куті **Customize** → **Connectors** → **Add More**
2. У полі URL введіть: `https://flux.mcp.acedata.cloud/mcp`
3. Завершіть вхід через OAuth-авторизацію (автоматичне перенаправлення на сторінку входу AceData Cloud)
4. Поверніться до інтерфейсу чату, і інструмент буде доступний для використання

### Claude Desktop

Відредагуйте файл конфігурації:

- macOS：`~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows：`%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Після збереження перезапустіть Claude Desktop, щоб зміни набули чинності.

### Claude Code（командний рядок термінала）

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### VS Code（GitHub Copilot）

### Інші клієнти з підтримкою MCP

Будь-який клієнт, що підтримує протокол MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant тощо), може підключитися, вказавши такі два параметри:

- **URL**：`https://flux.mcp.acedata.cloud/mcp`
- **Header**：`Authorization: Bearer ваш API Token`

## Спосіб 2: локальний запуск (встановлення через pip / uvx)

Якщо вам потрібен автономний запуск, налаштування коду або розгортання у внутрішній мережі, ви можете встановити MCP Server локально та запустити його через stdio.

### Встановлення

Встановлення через pip (рекомендовано):

```bash
pip install mcp-flux-pro
```

Або встановлення з вихідного коду:

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Після завершення встановлення ви можете використовувати команду `mcp-flux-pro` для запуску служби.

### Використання в Claude Desktop（локально）

Відредагуйте файл конфігурації Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додайте таку конфігурацію:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Якщо використовується `uvx`（немає потреби встановлювати пакет заздалегідь）:

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Після збереження конфігурації перезапустіть Claude Desktop, щоб зміни набули чинності.

## Список доступних інструментів

| Назва інструмента                    | Опис                       |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | Генерування зображення за текстовою підказкою              |
| `flux_edit_image`      | Редагування наявного зображення на основі текстової інструкції             |
| `flux_generate_video`  | Генерація текст-у-відео/зображення-у-відео/відео FLUX 3 та покращення наявних чернеток |
| `flux_get_task`        | Запит стану окремого завдання                 |
| `flux_get_tasks_batch` | Пакетний запит стану завдань                 |
| `flux_list_models`     | Виведення списку всіх доступних моделей та їхніх можливостей             |
| `flux_list_actions`    | Виведення списку всіх доступних інструментів і прикладів робочих процесів           |

## Обмеження моделей і розмірів
`flux-2-flex`、`flux-2-pro`、`flux-2-max` та моделі Kontext для `size` повинні використовувати
співвідношення, наприклад `1:1` або `16:9`, не можна використовувати піксельні розміри на кшталт `1024x1024`.
`flux-2-klein` підтримує лише генерацію та не входить до доступних моделей у `flux_edit_image`.

`flux_generate_video` розрізняє `t2v`、`i2v`、`v2v` та
`draft_enhance` через `request.mode`, а вхідні дані відображаються відповідно до режиму. Покращення чернетки повинно посилатися на власний тимчасовий `draft_task_id`.
Подання за замовчуванням є асинхронним, збережіть повернений ID завдання та використовуйте `flux_get_task` для отримання результату.
