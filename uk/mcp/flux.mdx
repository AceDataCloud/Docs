[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — це протокол контексту моделі, розроблений Anthropic, який дозволяє AI-моделям (наприклад, Claude, GPT тощо) викликати зовнішні інструменти через стандартизований інтерфейс. За допомогою Flux MCP Server від AceData Cloud ви можете безпосередньо створювати та редагувати AI-зображення у клієнтах AI, таких як Claude Desktop, VS Code, Cursor тощо.

## Огляд функцій

Flux MCP Server надає такі основні функції:

- **Генерація зображень з тексту** — створення високоякісних зображень за текстовими підказками
- **Редагування зображень** — редагування існуючих зображень на основі текстових інструкцій
- **Підтримка кількох моделей** — підтримка моделей Flux Pro, Flux Dev, Flux Schnell, Flux Kontext та інших
- **Перегляд моделей** — перегляд усіх доступних моделей та їх можливостей
- **Перегляд завдань** — моніторинг прогресу генерації та отримання результатів

## Попередні вимоги

Перед використанням необхідно отримати AceData Cloud API Token:

1. Зареєструйтесь або увійдіть на [AceData Cloud платформу](https://platform.acedata.cloud)
2. Перейдіть на сторінку [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Натисніть «Acquire» для отримання API Token (перший запит надає безкоштовний ліміт)

## Встановлення та налаштування

### Варіант 1: встановлення через pip (рекомендовано)

```bash
pip install mcp-flux-pro
```

### Варіант 2: встановлення з вихідного коду

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Після встановлення можна запускати сервер командою `mcp-flux-pro`.

## Використання в Claude Desktop

Відредагуйте конфігураційний файл Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додайте наступну конфігурацію:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ваш API Token"
      }
    }
  }
}
```

Якщо використовуєте `uvx` (не потрібно попередньо встановлювати пакети):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ваш API Token"
      }
    }
  }
}
```

Збережіть конфігурацію та перезапустіть Claude Desktop, щоб використовувати інструменти Flux у діалогах.

## Використання у VS Code / Cursor

Створіть у корені проєкту файл `.vscode/mcp.json`:

```json
{
  "servers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ваш API Token"
      }
    }
  }
}
```

Або з використанням `uvx`:

```json
{
  "servers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ваш API Token"
      }
    }
  }
}
```

## Список доступних інструментів

| Назва інструменту        | Опис                                  |
|--------------------------|--------------------------------------|
| `flux_generate_image`     | Генерація зображення за текстовою підказкою |
| `flux_edit_image`         | Редагування існуючого зображення за текстовою інструкцією |
| `flux_get_task`           | Перегляд статусу одного завдання     |
| `flux_get_tasks_batch`    | Масовий перегляд статусів завдань    |
| `flux_list_models`        | Перелік усіх доступних моделей та їх можливостей |
| `flux_list_actions`       | Перелік усіх доступних інструментів та прикладів робочих процесів |

## Приклади використання

Після налаштування ви можете безпосередньо викликати ці функції природною мовою у AI-клієнтах, наприклад:

- «Допоможи мені згенерувати Flux зображення міського нічного пейзажу в стилі кіберпанк»
- «Зміни фон цього фото на пляж»
- «Відредагуй це зображення за допомогою моделі Flux Kontext Pro, зміни колір одягу на червоний»
- «Покажи всі доступні моделі Flux»
