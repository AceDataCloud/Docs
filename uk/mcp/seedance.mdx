[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — це протокол контексту моделі, представлений Anthropic, який дозволяє AI-моделям (таким як Claude, GPT тощо) викликати зовнішні інструменти через стандартизовані інтерфейси. Через Seedance MCP Server, наданий AceData Cloud, ви можете безпосередньо використовувати ByteDance Seedance для генерації AI-відео в таких AI-клієнтах, як Claude Desktop, VS Code, Cursor тощо.

## Огляд функцій

Seedance MCP Server надає такі основні функції:

- **Генерація відео з тексту** — створення високоякісних відео за текстовими підказками
- **Генерація відео із зображень** — створення відео з використанням зображень як референсів (режими першого кадру, останнього кадру, референсного зображення тощо)
- **Підтримка кількох моделей** — підтримка Seedance 1.x, 1.5, 2.0 та 2.5
- **Кілька роздільних здатностей** — підтримка 480p, 720p, 1080p, деякі моделі підтримують 4k
- **Різні співвідношення сторін** — підтримка 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 та adaptive
- **Гнучка тривалість** — 2–30 секунд або автоматична тривалість залежно від підтримки моделі
- **Мультимодальне відео** — підтримка генерації аудіо, референсного аудіо/відео, а також редагування та подовження відео у 2.5
- **Запит завдань** — моніторинг прогресу генерації та отримання результатів

## Рекомендовано: OAuth-авторизація з розміщеним MCP

У клієнтах, що підтримують віддалений MCP OAuth, додайте адресу сервера:

```text
https://seedance.mcp.acedata.cloud/mcp
```

Виберіть підключення або вхід, увійдіть до Ace Data Cloud, перегляньте дозволи й авторизуйтеся, а потім увімкніть інструменти. Цей шлях не потребує попереднього створення або копіювання API Token. Сервіс уже підтримує OAuth discovery, динамічну реєстрацію клієнтів (DCR) і S256 PKCE; DCR реєструє клієнтів, користувачі все одно мають увійти й авторизуватися, API використовується за звичайною тарифікацією.

| Клієнт                            | Спосіб підключення та умови                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Вебверсія Claude або версія Desktop із віддаленими конекторами | Додайте вказану вище адресу в інтерфейсі конекторів і авторизуйтеся; доступність залежить від версії та тарифного плану. Не записуйте віддалену HTTP-конфігурацію до локального файлу конфігурації stdio.                      |
| VS Code із підтримкою нативного віддаленого MCP OAuth     | Виконайте **MCP: Add Server**, виберіть HTTP, введіть адресу та увійдіть за підказками; спеціалізоване розширення AceDataCloud використовує окреме налаштування API Key. |
| Інші клієнти                          | Переконайтеся, що поточна версія підтримує віддалений HTTP, OAuth/DCR, і використовуйте інструкції з конфігурації цього клієнта. Формат конфігураційного файлу не можна використовувати між різними клієнтами.                     |

## Альтернативний шлях через API Token

Для локального stdio, самостійного хостингу або клієнтів, що не підтримують віддалений OAuth, використовуйте API Token. Увійдіть до [платформи Ace Data Cloud](https://platform.acedata.cloud), виберіть сервіс і створіть API-облікові дані з потрібними дозволами. Зберігайте Token у налаштуваннях облікових даних клієнта або локальних змінних середовища, не розміщуйте його в URL, вмісті чату чи репозиторіях. Конфігурацію HTTP Header для різних клієнтів слід заповнювати відповідно до інструкцій їхніх версій.

Встановлення MCP з відкритим вихідним кодом або завершення авторизації не означає отримання безкоштовної квоти та не гарантує час генерації або права на комерційне використання. Перед генерацією перевірте поточні ціни сервісу, баланс і застосовні умови.

## Спосіб 2: локальний запуск (встановлення через pip / uvx)

Якщо вам потрібні локальний stdio, користувацький код або самостійний хостинг, ви можете запустити MCP Server локально. Для генерації все одно потрібне підключення до API через інтернет, це не офлайн-інференс.

### Встановлення

Встановлення через pip (рекомендовано):

```bash
pip install mcp-seedance
```

Або встановлення з вихідного коду:

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Після завершення встановлення ви можете запустити сервіс за допомогою команди `mcp-seedance`.

### Використання у Claude Desktop (локально)

Відредагуйте файл конфігурації Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додайте таку конфігурацію:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Якщо використовується `uvx` (не потрібно встановлювати пакет заздалегідь):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Після збереження конфігурації перезапустіть Claude Desktop, щоб зміни набули чинності.

### Використання у VS Code (локально)

Створіть `.vscode/mcp.json` у кореневому каталозі проєкту:

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Або використовуйте `uvx`:

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Для інших локальних клієнтів заповнюйте command, args та env відповідно до інструкцій з конфігурації stdio їхньої поточної версії; не використовуйте конфігурацію VS Code безпосередньо як універсальний формат.

## Перевірка результатів і поширені помилки

Попросіть клієнт створити просту відеороботу, збережіть номер завдання та запитуйте це саме завдання, доки не буде досягнуто успішного кінцевого стану, після чого відкрийте або відтворіть остаточне посилання. Успішне підключення, завантаження списку інструментів, HTTP 200, номер завдання та попередній перегляд у стані обробки не означають остаточний результат.

У разі 401 увійдіть повторно або перевірте Token і дозволи; за недостатнього балансу перевірте рахунки; під час обробки завдання продовжуйте виконувати запити; у разі остаточної помилки прочитайте помилку й вирішіть, чи повторювати спробу, оскільки нова генерація може оплачуватися повторно.

## Список доступних інструментів

| Назва інструменту                                  | Опис             |
| ------------------------------------ | -------------- |
| `seedance_generate_video`            | Генерація відео за текстовими підказками    |
| `seedance_generate_video_from_image` | Генерація відео із зображенням як референсом     |
| `seedance_get_task`                  | Запит статусу окремого завдання       |
| `seedance_get_tasks_batch`           | Пакетний запит статусу завдань       |
| `seedance_list_models`               | Перелік усіх доступних моделей та їхніх можливостей   |
| `seedance_list_resolutions`          | Перелік доступних роздільних здатностей і співвідношень сторін   |
| `seedance_list_actions`              | Перелік усіх доступних інструментів і прикладів робочих процесів |
