[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — це протокол контексту моделі, розроблений Anthropic, який дозволяє AI-моделям (таким як Claude, GPT тощо) викликати зовнішні інструменти через стандартизований інтерфейс. За допомогою Seedream MCP Server від AceData Cloud ви можете безпосередньо використовувати генерацію та редагування AI-зображень Seedream від ByteDance у клієнтах AI, таких як Claude Desktop, VS Code, Cursor тощо.

## Огляд функцій

Seedream MCP Server надає такі основні функції:

- **Генерація зображень за текстом** — створення високоякісних зображень за текстовими підказками (підтримка китайської та англійської мов)
- **Редагування зображень** — зміна стилю, фону, властивостей існуючих зображень
- **Віртуальна примірка одягу** — накладання одягу на фотографії людей
- **Підтримка кількох моделей** — підтримка Seedream v4.5, v4.0, v3.0 T2I, SeedEdit v3.0 I2I та інших моделей
- **Різні роздільні здатності** — підтримка 1K, 2K, 4K та адаптивних роздільних здатностей
- **Контроль зерна (seed)** — відтворюване генерування результатів за допомогою параметра seed
- **Запит завдань** — моніторинг прогресу генерації та отримання результатів

## Попередні вимоги

Перед використанням необхідно отримати API Token AceData Cloud:

1. Зареєструйтесь або увійдіть на [AceData Cloud платформу](https://platform.acedata.cloud)
2. Перейдіть на сторінку [Seedream Images API](https://platform.acedata.cloud/documents/seedream-images)
3. Натисніть «Acquire» для отримання API Token (перший запит надає безкоштовний ліміт)

## Встановлення та налаштування

### Варіант 1: Встановлення через pip (рекомендовано)

```bash
pip install mcp-seedream-pro
```

### Варіант 2: Встановлення з вихідного коду

```bash
git clone https://github.com/AceDataCloud/MCPSeedream.git
cd MCPSeedream
pip install -e .
```

Після встановлення можна запускати сервіс командою `mcp-seedream-pro`.

## Використання в Claude Desktop

Відредагуйте конфігураційний файл Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додайте наступну конфігурацію:

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ваш API Token"
      }
    }
  }
}
```

Якщо використовуєте `uvx` (без необхідності попереднього встановлення пакетів):

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ваш API Token"
      }
    }
  }
}
```

Збережіть конфігурацію та перезапустіть Claude Desktop, після чого можна використовувати інструменти Seedream у діалогах.

## Список доступних інструментів

| Назва інструменту           | Опис                          |
|-----------------------------|-------------------------------|
| `seedream_generate_image`   | Генерація зображення за текстом |
| `seedream_edit_image`       | Редагування або зміна існуючого зображення |
| `seedream_get_task`         | Запит статусу одного завдання  |
| `seedream_get_tasks_batch`  | Масовий запит статусів завдань |
| `seedream_list_models`      | Перелік усіх доступних моделей та їх можливостей |
| `seedream_list_sizes`       | Перелік доступних розмірів та роздільних здатностей зображень |

## Приклади використання

Після налаштування ви можете безпосередньо викликати ці функції природною мовою у AI-клієнтах, наприклад:

- «Згенеруй за допомогою Seedream картину в стилі тушевого живопису з пейзажем»
- «Змініть фон цього фото на зоряне небо»
- «Згенеруй портрет у 4K якості за допомогою Seedream v4.5»
- «Віртуально приміряй цей одяг на цю фотографію»
