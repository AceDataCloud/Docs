## Базовий URL

Базова адреса для всіх API кінцевих точок:

```
https://api.acedata.cloud
```

## Аутентифікація

Для всіх кінцевих точок потрібна аутентифікація Bearer Token:

```
Authorization: Bearer YOUR_API_TOKEN
```

## Онлайн тестування

Кожна кінцева точка в цьому довіднику має інтерактивну пісочницю. Введіть API Token, щоб безпосередньо тестувати запити у браузері.

<Note title="Підказка">
  Отримайте API Token на [platform.acedata.cloud](https://platform.acedata.cloud).
</Note>
