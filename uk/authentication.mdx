---
title: "Аутентифікація"
description: "Як використовувати Ace Data Cloud API для аутентифікації"
---

Всі Ace Data Cloud API використовують аутентифікацію **Bearer Token**.

## Отримання Token

1. Зареєструйте обліковий запис на [platform.acedata.cloud](https://platform.acedata.cloud)
2. Підпишіться на потрібні сервіси
3. Створіть облікові дані (API Token) для кожного сервісу

## Використання Token

Включіть Token у заголовок `Authorization` кожного запиту:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Порада">
  Кожен Token прив’язаний до конкретної підписки на сервіс. Для різних сервісів використовуйте різні Token, або створіть **глобальні** облікові дані для використання між сервісами.
</Note>

## Обмеження швидкості

Обмеження швидкості залежать від сервісу та рівня підписки. Якщо перевищено ліміт, API повертає `429 Too Many Requests`.

## Найкращі практики безпеки

- Не розкривайте API Token у клієнтському коді
- Зберігайте Token у змінних середовища
- Регулярно оновлюйте Token
- Використовуйте різні Token для розробки та продакшн середовищ
