OpenAI ChatGPT — це дуже потужна AI-система для діалогів, яка може генерувати плавні та природні відповіді всього за кілька секунд після введення підказки. ChatGPT вирізняється своєю видатною здатністю розуміти та генерувати мову, і сьогодні він широко застосовується у різних галузях і сферах, його вплив стає дедалі помітнішим. Незалежно від того, чи це повсякденні розмови, креативне письмо, професійні консультації чи програмування, ChatGPT надає вражаючу інтелектуальну підтримку, значно підвищуючи продуктивність і творчість людини.

Цей документ головним чином описує процес використання OpenAI Chat Completion 4o Image API, за допомогою якого ми можемо легко користуватися мультимодальними функціями офіційного OpenAI ChatGPT.

## Процес заявки

Щоб використовувати OpenAI Chat Completion 4o Image API, спочатку перейдіть на сторінку [OpenAI Chat Completion 4o Image API](https://platform.acedata.cloud/documents/openai-chat-completions) та натисніть кнопку «Acquire», щоб отримати необхідні для запиту облікові дані:

![](https://cdn.acedata.cloud/nyq0xz.png)

Якщо ви ще не увійшли або не зареєструвалися, вас автоматично перенаправлять на сторінку входу, де ви зможете зареєструватися та увійти. Після входу або реєстрації ви автоматично повернетесь на цю сторінку.

При першій заявці надається безкоштовний ліміт, що дозволяє безкоштовно користуватися API.

## Модель малювання GPT-4o

### Генерація зображення за зразком

Нижче наведено приклад створення зображення в кастомному стилі на основі одного зображення. Спочатку подивимось на вхідне зображення:

![](https://cdn.acedata.cloud/qzx2z1.png)

Як бачимо, зразок — це фото реальної людини. Ми можемо змінити стиль, наприклад, зробити його аніме-стилем. Приклад запиту:

```json
{
  "model": "gpt-4o-image",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "生成动漫风格的图片，并且带上个帽子"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

## Обробка помилок

При виклику API у разі помилки API повертає відповідний код помилки та повідомлення. Наприклад:

- `400 token_mismatched`: Некоректний запит, можливо, через відсутні або недійсні параметри.
- `400 api_not_implemented`: Некоректний запит, можливо, через відсутні або недійсні параметри.
- `401 invalid_token`: Несанкціонований доступ, недійсний або відсутній токен авторизації.
- `429 too_many_requests`: Занадто багато запитів, перевищено ліміт швидкості.
- `500 api_error`: Внутрішня помилка сервера.
