## 1. Отримання API Key

Відкрийте [список застосунків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступного застосунку та скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Надсилання першого запиту

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Зображення успішної відповіді розташоване в `data[].url`. Нижче наведено фактичний результат 1024×1536, отриманий через Ace Data Cloud 8 вересня 2026 року (завдання `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Білий кухоль, згенерований GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Поширені параметри

| Поле                | Опис                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (рекомендовано за замовчуванням), `gpt-image-2.5-flare` (швидше) або `gpt-image-2.5-sunburst` (вища точність і контроль); для всіх трьох можна вибрати відповідний варіант `:official`, а `gpt-image-2` також підтримує `:reverse` |
| `prompt`          | Опис зображення, максимум 32 000 символів                                                                                                                     |
| `size`            | `auto` або `WIDTHxHEIGHT`; ширина й висота мають бути кратними 16, довша сторона не перевищує 3840, загальна кількість пікселів становить 655 360–8 294 400, а співвідношення сторін не перевищує 3:1                                                       |
| `n`               | 1–10; за `response_format=b64_json` підтримується лише 1                                                                                                 |
| `quality`         | `low`, `medium`, `high` або `auto`; підтримка та спосіб тарифікації відрізняються для різних каналів                                                                                          |
| `response_format` | `url` або `b64_json`                                                                                                                     |
| `callback_url`    | Необов'язковий; надсилає результат на цю адресу після завершення тривалого завдання                                                                                                                      |

Поширені розміри:

| Пропорція   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` вибирає формат кадру відповідно до пропорцій, пікселів і наміру компонування в підказці; якщо потрібні точні пікселі, вкажіть розмір безпосередньо.

### Моделі та способи тарифікації

| Модель                                | Сценарії застосування та спосіб тарифікації                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Канал реверсингу за замовчуванням, фіксована тарифікація за кількістю успішних зображень                        |
| `gpt-image-2:reverse`             | Явний вибір каналу реверсингу, фіксована тарифікація за кількістю успішних зображень                      |
| `gpt-image-2:official`            | Канал офіційного API, вища стабільність, тарифікація за фактичним використанням Token            |
| `gpt-image-2.5-flare`             | Акцент на швидкості генерації, фіксована тарифікація за кількістю успішних зображень                        |
| `gpt-image-2.5-flare:official`    | Канал офіційного API, вища стабільність та акцент на швидкості генерації, тарифікація за фактичним використанням Token     |
| `gpt-image-2.5-sunburst`          | Акцент на високій точності та детальному контролі, фіксована тарифікація за кількістю успішних зображень                    |
| `gpt-image-2.5-sunburst:official` | Канал офіційного API, вища стабільність та акцент на високій точності й детальному контролі, тарифікація за фактичним використанням Token |

Ціна на сторінці для каналів офіційного API є оцінкою перед запитом; остаточна сума визначається фактичним використанням Token у відповіді та записами про використання.

## 4. Генерація кількох зображень

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` і `gpt-image-2:reverse` тарифікуються за кількістю успішних зображень; `gpt-image-2:official`, `gpt-image-2.5-flare:official` і `gpt-image-2.5-sunburst:official` розраховуються відповідно до фактичних Token текстового вводу й виводу зображень у відповіді. Ціна на сторінці є оцінкою перед запитом, остаточна сума визначається записами про використання.

## 5. Асинхронний зворотний виклик

Після додавання `callback_url` до тіла запиту інтерфейс спочатку поверне `{"task_id": "..."}`, а після завершення надішле остаточний результат методом POST на цей URL; синхронні запити, як і раніше, повертають `created` і `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Одержувач зворотного виклику повинен використовувати `task_id` для дедуплікації та перевіряти джерело запиту й формат даних.

## 6. Усунення помилок

| Статус  | Перевірка                                                  |
| --- | --------------------------------------------------- |
| 400 | Комбінацію `model`, `prompt`, формату розміру, `n` і `response_format`    |
| 401 | Чи API Key повний, чи Header має вигляд `Authorization: Bearer ...` |
| 429 | Запити надто часті, повторіть спробу пізніше                                         |
| 504 | Тайм-аут синхронної генерації; використовуйте `callback_url`                            |

Відповідь із помилкою міститиме `error.code`, `error.message` і `trace_id`. Під час повідомлення про проблему надайте `trace_id`, не надавайте API Key.

Повний перелік полів і актуальні значення дивіться на сторінці [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Для редагування зображень дивіться [редагування зображень GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-edits).
