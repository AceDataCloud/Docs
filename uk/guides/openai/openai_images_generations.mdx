## 1. Отримання API Key

Відкрийте [список додатків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступних додатків і скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Надсилання першого запиту

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer ваш API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Мінімалістична редакційна ілюстрація продукту: одна проста біла керамічна чашка для кави, розташована по центру на суцільному кобальтово-синьому столі, блідий кремовий фон, м'яка тінь, чисті геометричні форми, без тексту, без логотипу, портретна композиція",
    "size": "1024x1536"
  }'
```

Успішно отримане зображення знаходиться в `data[].url`. Нижче наведено результат 1024×1536, отриманий 8 вересня 2026 року через Ace Data Cloud (завдання `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, трасування `eb938601-8192-407f-b539-1e0554b697ec`):

![GPT Image 2 згенерована біла чашка](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Загальні параметри

| Поле               | Опис                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (рекомендується за замовчуванням), `gpt-image-2.5-flare` (швидше) або `gpt-image-2.5-sunburst` (вища точність і контроль); також можна явно вибрати `gpt-image-2:official` або `gpt-image-2:reverse` |
| `prompt`          | Опис зображення, максимум 32,000 символів                                                                                                                     |
| `size`            | `auto` або `WIDTHxHEIGHT`; ширина і висота повинні бути кратні 16, довша сторона не перевищує 3840, загальна кількість пікселів від 655,360 до 8,294,400, співвідношення сторін не більше 3:1                                                       |
| `n`               | 1–10; `response_format=b64_json` підтримує лише 1                                                                                                 |
| `quality`         | `low`, `medium`, `high` або `auto`; різні лінії підтримки та способи оплати різні                                                                                          |
| `response_format` | `url` або `b64_json`                                                                                                                     |
| `callback_url`    | Необов'язково; після завершення довгих завдань результати надсилаються на цю адресу                                                                                                                      |

Загальні розміри:

| Співвідношення | 1K          | 2K          | 4K          |
| -------------- | ----------- | ----------- | ----------- |
| 1:1            | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3            | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4            | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9           | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16           | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` вибере формат зображення на основі співвідношення, пікселів і наміру макета в підказці; для точних пікселів вкажіть розмір безпосередньо.

## 4. Генерація кількох зображень

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer ваш API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Маленька лисиця, що читає під світлом грибка, акварельна ілюстрація",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` та `:reverse` оплачується за кількістю успішно згенерованих зображень; `gpt-image-2:official` розраховується на основі фактичних токенів, використаних для текстового вводу та виходу зображення. Ціни на сторінці є попередніми оцінками перед запитом, остаточні ціни базуються на записах використання.

## 5. Асинхронний зворотний виклик

Після додавання `callback_url` до тіла запиту, інтерфейс спочатку поверне `{"task_id": "..."}`, а після завершення надішле остаточний результат на цю URL-адресу; синхронні запити все ще повертають `created` і `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "Постер продукту з чіткою типографікою",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Отримувач зворотного виклику повинен використовувати `task_id` для уникнення дублікатів і перевіряти джерело запиту та формат даних.

## 6. Виправлення помилок

| Статус | Перевірка                                                  |
| ------ | --------------------------------------------------------- |
| 400    | `model`, `prompt`, формат розміру, комбінація `n` та `response_format`    |
| 401    | Чи повний API Key, заголовок має бути `Authorization: Bearer ...` |
| 429    | Запити надто часті, спробуйте пізніше                                         |
| 504    | Синхронна генерація перевищила час; використовуйте `callback_url`                            |

Помилки у відповіді міститимуть `error.code`, `error.message` та `trace_id`. При повідомленні про проблеми надайте `trace_id`, не надавайте API Key.

Повні поля та реальні переліки можна знайти на сторінці [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Для редагування зображень дивіться [GPT Image 2 / 2.5 Редагування зображень](https://platform.acedata.cloud/documents/openai-images-edits).
