## 1. Отримання API Key

Відкрийте [список застосунків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступного застосунку та скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Надсилання першого запиту

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Зображення з успішної відповіді знаходиться в `data[].url`. Нижче наведено фактичний результат 1024×1536, отриманий через запит Ace Data Cloud 8 вересня 2026 року (завдання `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Біла кавова чашка, згенерована GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Поширені параметри

| Поле                | Опис                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (рекомендовано за замовчуванням), `gpt-image-2.5-flare` (швидше) або `gpt-image-2.5-sunburst` (вища точність і контроль); для всіх трьох можна вибрати відповідний варіант `:official`, а `gpt-image-2` також підтримує `:reverse` |
| `prompt`          | Опис зображення, максимум 32 000 символів                                                                                                                     |
| `size`            | `auto` або `WIDTHxHEIGHT`; ширина й висота мають бути кратними 16, довша сторона не повинна перевищувати 3840, загальна кількість пікселів становить 655 360–8 294 400, а співвідношення сторін не перевищує 3:1                                                       |
| `n`               | 1–10; за `response_format=b64_json` підтримується лише 1                                                                                                 |
| `quality`         | Моделі GPT Image підтримують `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare / Sunburst (включно з `:official`) додатково підтримують `xhigh`, `max`. Офіційний канал тарифікується за фактичним використанням Token             |
| `response_format` | `url` або `b64_json`                                                                                                                     |
| `callback_url`    | Необов’язково; після завершення тривалого завдання надсилає результат на цю адресу                                                                                                                      |

Поширені розміри:

| Співвідношення   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` вибирає формат кадру відповідно до співвідношення, пікселів і наміру компонування в підказці; коли потрібні точні пікселі, вкажіть розмір безпосередньо.

## 4. Генерація кількох зображень

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` та їхні псевдоніми `:reverse` оплачуються за кількістю успішних зображень; `gpt-image-2:official`, `gpt-image-2.5-flare:official` і `gpt-image-2.5-sunburst:official` розраховуються за фактичними Token текстового вводу та виводу зображень у відповіді. Ціни на сторінці є оцінкою до запиту, остаточна сума визначається записами використання.

## 5. Асинхронний зворотний виклик

Після додавання `callback_url` до тіла запиту інтерфейс спочатку поверне `{"task_id": "..."}`, а після завершення надішле остаточний результат методом POST на цю URL-адресу; синхронні запити й надалі повертають `created` і `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Одержувач зворотного виклику має використовувати `task_id` для дедуплікації та перевіряти джерело запиту й формат даних.

## 6. Усунення несправностей

| Статус  | Перевірка                                                  |
| --- | --------------------------------------------------- |
| 400 | Комбінацію `model`, `prompt`, формату розміру, `n` і `response_format`    |
| 401 | Чи повний API Key, чи має Header вигляд `Authorization: Bearer ...` |
| 429 | Запити надто часті, повторіть пізніше                                         |
| 504 | Час очікування синхронної генерації минув; використовуйте `callback_url`                            |

Відповідь про помилку міститиме `error.code`, `error.message` і `trace_id`. Під час повідомлення про проблему надавайте `trace_id`, не надавайте API Key.

Повний перелік полів і актуальні переліки значень наведено на сторінці [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Для редагування зображень дивіться [Редагування зображень GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-edits).

## GPT Image 2.6

GPT Image 2.6 використовує інтерфейси генерації, редагування, асинхронних завдань і тарифікації версії 2.5:

| Модель                                                          | Тарифікація                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/зображення                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/зображення                   |
| `gpt-image-2.6-flare:official`                              | Як для 2.5 official, за фактичним використанням Token |
| `gpt-image-2.6-sunburst:official`                           | Як для 2.5 official, за фактичним використанням Token |

Якість може бути `auto`, `low`, `medium`, `high`, `xhigh`, `max`; для розміру використовуйте `auto` або `WIDTHxHEIGHT`, що відповідає наведеним вище обмеженням. Цей інтерфейс підтримує `png`, `jpeg`, `webp`; GPT Image 2.6 також підтримує нативну GIF-анімацію, SVG поки не підтримується. Редагування підтримує URL зображень JSON і завантаження файлів multipart. `:reverse` є явним псевдонімом звичайної версії з такою самою назвою. Використовуйте повну назву моделі, не передавайте `gpt-image-2.6`.

### GIF-анімація GPT Image 2.6

Звичайні версії Flare, Sunburst, `:reverse` і `:official` у GPT Image 2.6 можуть використовувати `output_format: "gif"`. Кадри анімації, інформація про цикл і тривалість відтворення зберігаються; `frame_count` позначає кількість кадрів, а `frame_duration_ms` — кількість мілісекунд на кадр, кількість кадрів має бути цілим числом від 2 до 16, тривалість кожного кадру має бути цілим числом від 20 до 655350 мілісекунд і використовується лише для GIF; кодування округлюється до найближчих 10 мс. Якщо не вказано, за замовчуванням використовується 9 кадрів по 200 мілісекунд кожен; якщо `size` для GIF пропущено або має значення auto, використовується пресет 512x512.

Рекомендується спочатку використовувати `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. GIF має окремі обмеження щодо розміру та кількості кадрів, не можна безпосередньо застосовувати специфікації статичного 4K; деякі моделі коригують фактичний розмір виводу. `n` означає кількість GIF-файлів, що повертаються, а не кількість кадрів анімації. Звичайні версії та `:reverse` і надалі оплачуються за кількістю успішних файлів, офіційні версії — за фактичним використанням Token.

```json
{
  "model": "gpt-image-2.6-flare",
  "prompt": "A small red ball moves left and right on a white background, seamless looping animation, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### Статичні зображення 4K GPT Image 2.6

Flare, Sunburst та їхні варіанти `:reverse`, `:official` можуть використовувати згадані вище пресети пікселів 4K, наприклад `3840x2160` і `2160x3840`. Як для генерації, так і для редагування конкретні пікселі передаються через `size`; `4K` не є допустимим значенням `size`, а `4096x4096` також перевищує поточне обмеження пікселів. Наведені вище специфікації 4K застосовуються до статичних PNG/JPEG/WebP, для GIF використовуйте його спеціальні параметри.

### Складність композиції GPT Image 2.6

`complexity` може бути `low`, `medium`, `high`; якщо його пропущено, використовується стандартне значення моделі `high`. Він керує складністю планування та є незалежним від якості рендерингу `quality`; додатково не оплачується за раз, офіційні версії й надалі розраховуються за фактичними Token. Інші моделі не підтримують цей параметр.

GIF не підтримує mask, зображення з позначками, користувацьке стиснення, переписування підказок або часткове потокове виведення зображень; несумісні комбінації буде відхилено до генерації. Розмір, кількість кадрів і кількість спільно обмежені бюджетом пікселів моделі; для звичайної Flare підтверджено працездатність `1024x1024` із 2 кадрами, але цей висновок не можна поширювати на всі комбінації 1K або GIF 4K.
