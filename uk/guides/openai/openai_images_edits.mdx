## 1. Отримати API Key

Відкрийте [список додатків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступних додатків і скопіюйте API Key.

![Отримати Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Редагування за URL зображення

Оригінал:

![GPT Image 2 редагування оригіналу](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer ваш API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Залиште чашку, стіл, кут камери, портретну компоновку та м'яку тінь незмінними. Змініть лише колір чашки з білого на яскраво-оранжевий, а блідий кремовий фон на насичений темно-морський синій. Без тексту та логотипу.",
    "size": "1024x1536"
  }'
```

Успішна відповідь:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Це результат редагування, виконаного 8 вересня 2026 року через Ace Data Cloud, чашка стала оранжевою, фон став темно-морським синім, і збереглася оригінальна композиція та розмір 1024×1536:

![GPT Image 2 оранжева чашка редагування результат](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Завантаження локального зображення

Використовуйте `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer ваш API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Замініть фон на яскраву сучасну студію"
```

Можна повторно передавати `image`, серія GPT Image підтримує до 16 референсних зображень. `image` в JSON запиті може бути єдиним URL або масивом URL; локальні файли завантажуються через multipart.

## 4. Загальні параметри

| Поле                | Опис                                                                                                                       |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (швидше), `gpt-image-2.5-sunburst` (вища точність і контроль), `gpt-image-2:official` або `gpt-image-2:reverse` |
| `image`           | JSON використовує єдиний URL або масив з максимум 16 URL; multipart використовує одне або кілька полів файлів `image`                                                            |
| `prompt`          | Інструкції для редагування                                                                                                                     |
| `size`            | `auto` або відповідно до обмежень `WIDTHxHEIGHT`                                                                                             |
| `n`               | 1–10; підтримується лише 1 при `response_format=b64_json`                                                                                   |
| `response_format` | `url` або `b64_json`                                                                                                       |
| `callback_url`    | Додаткова адреса для асинхронного зворотного виклику                                                                                                                 |

Правила розміру аналогічні до інтерфейсу генерації: ширина та висота повинні бути кратними 16, довга сторона не перевищує 3840, загальна кількість пікселів від 655,360 до 8,294,400, співвідношення сторін не перевищує 3:1. Якщо пропустити `size` або використовувати `auto`, модель вибере формат на основі підказки та першого референсного зображення.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` та `:reverse` стягуються за кількістю успішних зображень; `gpt-image-2:official` розраховується на основі фактичних токенів текстового вводу, референсних зображень та виходу зображення, остаточно на основі записів використання.

## 5. Асинхронний зворотний виклик та усунення помилок

Довгі завдання можуть включати в запит:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Асинхронна відповідь 200 буде `{"task_id": "..."}`; після завершення буде зворотний виклик з остаточним результатом. Синхронний запит повертає `created` та `data`.

| Статус  | Перевірка                      |
| --- | ----------------------- |
| 400 | Формат/кількість зображень, комбінація параметрів та формат розміру       |
| 401 | API Key та Bearer Header |
| 429 | Частота запитів                    |
| 504 | Використовуйте асинхронний зворотний виклик                  |

Помилкові відповіді міститимуть `trace_id`. При повідомленні про проблеми надайте цей ID, не надавайте API Key.

Повні поля та актуальні переліки можна знайти на сторінці [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Для генерації зображень у чистому тексті перегляньте [GPT Image 2 / 2.5 генерація зображень](https://platform.acedata.cloud/documents/openai-images-generations).
