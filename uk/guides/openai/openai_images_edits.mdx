## 3. Завантаження локального зображення

Використовуйте `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` можна передавати повторно, серія GPT Image підтримує до 16 референсних зображень. `image` у JSON-запиті може бути одним URL або масивом URL; локальні файли завантажуються через multipart.

### Моделі та способи тарифікації

| --------------------------------- | ------------------------------------------------ |

| `gpt-image-2:reverse`             | Явний вибір реверсного каналу, фіксована тарифікація за кількістю успішних зображень                             |

| `gpt-image-2.6-flare`             | Акцент на швидкості генерації, фіксована тарифікація за кількістю успішних зображень                               |

| `gpt-image-2.6-sunburst`          | Акцент на високій точності відтворення та детальному контролі, фіксована тарифікація за кількістю успішних зображень                           |
| `gpt-image-2.5-sunburst:reverse`  | Явний реверсний псевдонім, еквівалентний `gpt-image-2.5-sunburst`, фіксована тарифікація за кількістю успішних зображень |
| `gpt-image-2.6-sunburst:reverse`  | Явний реверсний псевдонім, еквівалентний `gpt-image-2.6-sunburst`, фіксована тарифікація за кількістю успішних зображень |
| `gpt-image-2.5-sunburst:official` | Офіційний API-канал, вища стабільність і акцент на високій точності відтворення та детальному контролі, тарифікація за фактичним використанням Token        |
| `gpt-image-2.6-sunburst:official` | Офіційний API-канал, вища стабільність і акцент на високій точності відтворення та детальному контролі, тарифікація за фактичним використанням Token        |

Реверсні моделі 2.0 / 2.5 (включно з псевдонімом `:reverse`) під час автоматичного відновлення можуть використовувати GPT Image 2.5 Flare для завершення запиту; модель запиту та спосіб фіксованої тарифікації за кількістю успішних зображень залишаються незмінними.

Ціна на сторінці офіційного API-каналу є оцінкою до запиту, остаточна вартість визначається фактичним використанням Token у відповіді та записами про використання.

`quality` підтримує `auto`, `low`, `medium`, `high`; Flare та Sunburst 2.5 / 2.6 (включно з варіантами `:reverse` і `:official`) додатково підтримують `xhigh`, `max`. Це поле можна передавати як для редагування JSON URL зображення, так і для редагування multipart-файлів; офіційний канал тарифікується за фактичним використанням Token.

## 4. Локальне редагування за допомогою маски

Офіційний інтерфейс Images Edit визначає область, дозволену для змін, через `mask`. Моделі `:official` Ace Data Cloud дотримуються такого самого multipart-контракту:

- `mask` має бути PNG з Alpha-каналом, розміром не більше 4MB;
- розмір маски має повністю збігатися з першою `image`;
- прозорі пікселі з Alpha, що дорівнює `0`, означають, що редагування дозволене, непрозорі пікселі означають, що їх слід зберегти;
- RGB-зображення, які мають лише чорно-білий колір, але не мають прозорого каналу, не можуть бути дійсними масками;
- запит має описувати бажане повне зображення, водночас чітко вказуючи локальні зміни та вміст, який має залишитися незмінним.

Нижче спочатку створюється маска з оригінального зображення. Приклад робить центральний прямокутник прозорим, дозволяючи моделі змінювати лише цю область:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Потім завантажте разом оригінальне зображення та маску:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Також можна використовувати спосіб виклику `images.edit` з офіційного Python SDK OpenAI, лише вказавши `base_url` на Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Під час використання `mask` оригінальне зображення та маска мають бути завантажені в одному multipart-запиті окремо через `image=@input.png` і `mask=@mask.png`. Не передавайте разом URL оригінального зображення та локальний файл маски; запити редагування лише з URL не підтримують додавання локального файлу `mask`. Маска обмежує область редагування, але модель генерації все одно може природно поєднувати краї; коли потрібні суворі межі, слід використовувати чіткі Alpha-краї та повторно зазначити в підказці, який вміст має залишатися незмінним.

Наведений вище спосіб виклику відповідає прикладам масок в [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) і [офіційному Cookbook GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Поширені параметри

| Поле                | Опис                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (швидше) або `gpt-image-2.5-sunburst` (вища точність і контроль); для всіх трьох можна вибрати відповідний варіант `:official`, а `gpt-image-2` також підтримує `:reverse` |
| `image`           | JSON використовує один URL або масив до 16 URL; multipart використовує одне чи кілька полів файлу `image`. Під час використання `mask` необхідно завантажувати локальний файл зображення                                              |
| `mask`            | Необов’язкова PNG-маска, лише для multipart-завантаження файлів; повинна мати Alpha-канал, збігатися за розміром із першим `image` і не перевищувати 4 МБ                                                                 |
| `prompt`          | Інструкція для редагування                                                                                                                             |
| `size`            | `auto` або `WIDTHxHEIGHT`, що відповідає обмеженням                                                                                                     |
| `n`               | 1–10; при `response_format=b64_json` підтримується лише 1                                                                                           |
| `response_format` | `url` або `b64_json`                                                                                                               |
| `callback_url`    | Необов’язкова адреса асинхронного зворотного виклику                                                                                                                         |

Правила розмірів такі самі, як у інтерфейсі генерації: ширина й висота мають бути кратними 16, довша сторона не повинна перевищувати 3840, загальна кількість пікселів становить 655 360–8 294 400, а співвідношення сторін не повинно перевищувати 3:1. Якщо не вказати `size` або використовувати `auto`, модель вибере формат кадру на основі підказки та першого еталонного зображення.

За `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` та їхні псевдоніми `:reverse` плата стягується за кількістю успішно створених зображень; для `gpt-image-2:official`, `gpt-image-2.5-flare:official` і `gpt-image-2.5-sunburst:official` розрахунок здійснюється відповідно до фактичних Token текстового вводу, вводу еталонних зображень і виводу зображень, остаточним є запис про використання.

## 6. Асинхронні зворотні виклики та усунення помилок

До тривалих завдань можна додати в запит:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Асинхронна відповідь 200 має вигляд `{"task_id": "..."}`; після завершення буде надіслано зворотний виклик з остаточним результатом. Синхронні запити повертають `created` і `data`.

| Статус  | Перевірка                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Формат/кількість зображень, комбінація параметрів і формат розмірів; під час використання `mask` перевірте Alpha-канал PNG, обмеження 4 МБ і відповідність її розмірів першому оригінальному зображенню |
| 401 | API Key і Bearer Header                                           |
| 429 | Частота запитів                                                              |
| 504 | Перейдіть на асинхронний зворотний виклик                                                            |

Відповідь з помилкою містить `trace_id`. Під час повідомлення про проблему надайте цей ID, але не надавайте API Key.

Повний перелік полів і актуальні переліки значень дивіться на сторінці [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Для генерації зображень лише з тексту дивіться [генерацію зображень GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

GPT Image 2.6 використовує інтерфейси генерації, редагування, асинхронних завдань і тарифікації версії 2.5:

| Модель                                                          | Тарифікація                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/зображення                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/зображення                   |
| `gpt-image-2.6-flare:official`                              | Як для 2.5 official, оплата за фактичне використання Token |
| `gpt-image-2.6-sunburst:official`                           | Як для 2.5 official, оплата за фактичне використання Token |

Для якості доступні `auto`, `low`, `medium`, `high`, `xhigh`, `max`; для розміру використовуйте `auto` або `WIDTHxHEIGHT`, що відповідає наведеним вище обмеженням. Цей інтерфейс підтримує `png`, `jpeg`, `webp`; GPT Image 2.6 також підтримує нативні анімовані `gif`, SVG поки що не підтримується. Редагування підтримує URL зображень JSON і multipart-завантаження файлів. `:reverse` є явним псевдонімом звичайної версії з такою самою назвою. Використовуйте повну назву моделі, не передавайте `gpt-image-2.6`.

### Перетворення зображень GPT Image 2.6 на анімовані GIF
Звичайна версія Flare, `:reverse`, `:official`, а також `gpt-image-2.6-sunburst:official` можуть використовувати `output_format: "gif"`. Звичайна версія Sunburst і `:reverse` наразі не підтримують GIF, але все ще підтримують генерацію та редагування статичних зображень. Кадри анімації, інформація про цикл і тривалість відтворення зберігаються; `frame_count` означає кількість кадрів, а `frame_duration_ms` означає кількість мілісекунд на кадр, обидва мають бути додатними цілими числами та використовуються лише для GIF. Якщо не вказано, за замовчуванням використовується 9 кадрів по 200 мілісекунд кожен; коли `size` для GIF пропущено або має значення auto, використовується пресет 512x512.

Рекомендується спочатку використовувати `size: "512x512"`、`frame_count: 9`、`frame_duration_ms: 200`。GIF має окремі обмеження щодо розміру та кількості кадрів, тому не можна безпосередньо застосовувати специфікації статичного 4K; деякі моделі коригують фактичний розмір виводу. `n` означає кількість повернених GIF-файлів, а не кількість кадрів анімації. Звичайна версія та `:reverse` і надалі оплачуються за кількістю успішно створених файлів, офіційна версія оплачується за фактичним використанням Token.

```json
{
  "model": "gpt-image-2.6-flare",
  "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
  "prompt": "Animate the mug gently moving left and right. Keep its appearance and the background, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### GPT Image 2.6 4K статичні зображення

Flare, Sunburst та їхні варіанти `:reverse`, `:official` можуть використовувати вищезазначені пресети пікселів 4K, наприклад `3840x2160` і `2160x3840`. Як генерація, так і редагування передають конкретні пікселі через `size`; `4K` не є дійсним значенням `size`, а `4096x4096` також перевищує поточний ліміт пікселів. Зазначені вище специфікації 4K застосовуються до статичних PNG/JPEG/WebP, для GIF використовуйте його спеціальні параметри.
