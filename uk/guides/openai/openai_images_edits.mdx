## 3. Завантаження локального зображення

Використовуйте `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` можна передавати повторно, серія GPT Image підтримує до 16 референсних зображень. `image` у JSON-запиті може бути одним URL або масивом URL; локальні файли завантажуються через multipart.

## 4. Локальне редагування за допомогою маски

Офіційний інтерфейс Images Edit визначає область, яку дозволено змінювати, через `mask`. Моделі Ace Data Cloud `:official` дотримуються такого самого multipart-контракту:

- `mask` має бути PNG з Alpha-каналом, розміром не більше 4 МБ;
- розмір маски має повністю збігатися з першою `image`;
- прозорі пікселі з Alpha `0` означають, що редагування дозволено, а непрозорі пікселі означають, що їх слід зберегти;
- RGB-зображення, які мають лише чорно-білий колір, але не мають каналу прозорості, не можуть використовуватися як дійсні маски;
- підказка має описувати очікуване повне зображення, водночас чітко зазначаючи локальні зміни та вміст, який потрібно залишити незмінним.

Нижче спочатку створюється маска з оригінального зображення. У прикладі центральний прямокутник робиться прозорим, дозволяючи моделі змінювати лише цю область:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Потім завантажте разом оригінальне зображення та маску:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Також можна використовувати спосіб виклику `images.edit` з офіційного Python SDK OpenAI, потрібно лише вказати `base_url` на Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Наразі `mask` надається як поле multipart-файлу. Якщо потрібно передавати оригінальне зображення через URL, також змініть запит на multipart: `image` може й надалі бути текстовим полем URL, а `mask` завантажуйте через `@mask.png`. Маска обмежує область редагування, але модель генерації все одно може природно змішувати краї; якщо потрібні строгі межі, слід використовувати чіткі Alpha-краї та повторно зазначити в підказці, який вміст має залишитися незмінним.

Наведені вище способи виклику відповідають прикладам масок у [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) та [офіційному Cookbook GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Поширені параметри

| Поле                | Опис                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (швидше) або `gpt-image-2.5-sunburst` (вища точність і контроль); для всіх трьох можна вибрати відповідні варіанти `:official`, а `gpt-image-2` також підтримує `:reverse` |
| `image`           | JSON використовує один URL або масив із максимум 16 URL; multipart використовує одне або кілька файлових полів `image`                                                                    |
| `prompt`          | Інструкція для редагування                                                                                                                             |
| `size`            | `auto` або `WIDTHxHEIGHT`, що відповідає обмеженням                                                                                                     |
| `n`               | 1–10; при `response_format=b64_json` підтримується лише 1                                                                                           |
| `response_format` | `url` або `b64_json`                                                                                                               |
| `callback_url`    | Необов’язкова адреса асинхронного зворотного виклику                                                                                                                         |

Правила розміру такі самі, як для інтерфейсу генерації: ширина й висота мають бути кратними 16, довша сторона не має перевищувати 3840, загальна кількість пікселів має становити 655,360–8,294,400, а співвідношення сторін не має перевищувати 3:1. Якщо не вказати `size` або використати `auto`, модель вибере формат кадру на основі підказки та першого референсного зображення.
`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` і `gpt-image-2:reverse` оплачуються за кількістю успішно створених зображень; `gpt-image-2:official`、`gpt-image-2.5-flare:official` і `gpt-image-2.5-sunburst:official` розраховуються за фактичними Token текстового вводу, вводу референсних зображень і виводу зображень, остаточні дані визначаються записами використання.

## 6. Асинхронний зворотний виклик і налагодження

Для тривалих завдань до запиту можна додати:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Асинхронна відповідь 200 має вигляд `{"task_id": "..."}`; після завершення надсилається зворотний виклик з остаточним результатом. Синхронні запити повертають `created` і `data`.

| Статус  | Перевірка                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Формат/кількість зображень, комбінацію параметрів і формат розмірів; під час використання `mask` перевірте PNG Alpha-канал, обмеження 4MB і відповідність його розмірів першому оригінальному зображенню |
| 401 | API Key і Bearer Header                                           |
| 429 | Частоту запитів                                                              |
| 504 | Перейдіть на асинхронний зворотний виклик                                                            |

Відповідь з помилкою міститиме `trace_id`. Під час повідомлення про проблему надайте цей ID, не надавайте API Key.

Повний перелік полів і актуальні переліки значень дивіться на сторінці [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Для створення зображень із простого тексту дивіться [Генерація зображень GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
