## 1. Отримання API Key

Відкрийте [список застосунків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступного застосунку та скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Редагування за допомогою URL зображення

Оригінальне зображення:

![Оригінальне зображення для редагування GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

Успішна відповідь:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Це результат редагування, фактично виконаного через Ace Data Cloud 8 вересня 2026 року: чашка стала помаранчевою, фон — темно-синім морським, при цьому збережено оригінальну композицію та розмір 1024×1536:

![Результат редагування помаранчевої чашки GPT Image 2](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Завантаження локального зображення

Використовуйте `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` можна передавати повторно; серія GPT Image підтримує до 16 референсних зображень. `image` у JSON-запиті може бути одним URL або масивом URL; локальні файли завантажуються через multipart.

## 4. Поширені параметри

| Поле                | Опис                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (швидше) або `gpt-image-2.5-sunburst` (вища точність і контроль); для всіх трьох можна вибрати відповідний варіант `:official`, а `gpt-image-2` також підтримує `:reverse` |
| `image`           | JSON використовує один URL або масив до 16 URL; multipart використовує одне або кілька полів файлів `image`                                                                    |
| `prompt`          | Інструкція з редагування                                                                                                                             |
| `size`            | `auto` або `WIDTHxHEIGHT`, що відповідає обмеженням                                                                                                     |
| `n`               | 1–10; за `response_format=b64_json` підтримується лише 1                                                                                           |
| `response_format` | `url` або `b64_json`                                                                                                               |
| `callback_url`    | Необов’язкова адреса асинхронного зворотного виклику                                                                                                                         |

Правила розмірів узгоджуються з інтерфейсом генерації: ширина й висота мають бути кратними 16, довша сторона не має перевищувати 3840, загальна кількість пікселів становить 655 360–8 294 400, а співвідношення сторін не перевищує 3:1. Якщо `size` пропущено або використано `auto`, модель вибере формат кадру на основі підказки та першого референсного зображення.

За `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` і `gpt-image-2:reverse` стягується плата за кількістю успішно створених зображень; для `gpt-image-2:official`, `gpt-image-2.5-flare:official` і `gpt-image-2.5-sunburst:official` розрахунок здійснюється за фактичними Token текстового вводу, вводу референсних зображень і виводу зображень, остаточні дані визначаються записами про використання.

## 5. Асинхронний зворотний виклик і усунення помилок

Для тривалих завдань до запиту можна додати:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Асинхронна відповідь 200 має вигляд `{"task_id": "..."}`; після завершення надсилається зворотний виклик з остаточним результатом. Синхронний запит натомість повертає `created` і `data`.

| Статус  | Перевірка                      |
| --- | ----------------------- |
| 400 | Формат/кількість зображень, комбінації параметрів і формат розміру       |
| 401 | API Key і Bearer Header |
| 429 | Частота запитів                    |
| 504 | Перейдіть на асинхронний зворотний виклик                  |

Відповідь про помилку міститиме `trace_id`. Повідомляючи про проблему, надавайте цей ID, але не надавайте API Key.

Повний перелік полів і актуальні переліки значень наведено на сторінці [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Для генерації зображень лише за текстом дивіться [генерацію зображень GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
