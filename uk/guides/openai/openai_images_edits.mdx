Відкрийте [список застосунків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступного застосунку та скопіюйте API Key.

## 2. Редагування за допомогою URL зображення

Оригінальне зображення:

![Оригінальне зображення для редагування GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",

  }'
```

## 3. Завантаження локального зображення

Використовуйте `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` можна передавати повторно; серія GPT Image підтримує до 16 референсних зображень. `image` у JSON-запиті може бути одним URL або масивом URL; локальні файли завантажуються через multipart.

### Моделі та спосіб тарифікації

| Модель                                | Сценарії використання та спосіб тарифікації                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Стандартний зворотний канал, фіксована оплата за кількістю успішних зображень                        |
| `gpt-image-2:reverse`             | Явний вибір зворотного каналу, фіксована оплата за кількістю успішних зображень                      |
| `gpt-image-2:official`            | Офіційний API-канал, вища стабільність, оплата за фактичне використання Token            |
| `gpt-image-2.5-flare`             | Орієнтований на швидкість генерації, фіксована оплата за кількістю успішних зображень                        |
| `gpt-image-2.5-flare:official`    | Офіційний API-канал, вища стабільність і орієнтація на швидкість генерації, оплата за фактичне використання Token     |
| `gpt-image-2.5-sunburst`          | Орієнтований на високу точність відтворення та детальний контроль, фіксована оплата за кількістю успішних зображень                    |
| `gpt-image-2.5-sunburst:official` | Офіційний API-канал, вища стабільність і орієнтація на високу точність відтворення та детальний контроль, оплата за фактичне використання Token |

Ціна на сторінці для офіційного API-каналу є оцінкою до надсилання запиту; остаточна вартість визначається фактичним використанням Token у відповіді та записах про використання.

`quality` підтримує `auto`, `low`, `medium`, `high`; лише `gpt-image-2.5-flare` і `gpt-image-2.5-sunburst` (включно з варіантами `:official`) додатково підтримують `xhigh`, `max`. Це поле можна передавати як для редагування URL зображень через JSON, так і для редагування файлів через multipart; офіційні канали тарифікуються за фактичним використанням Token.

## 4. Локальне редагування за допомогою маски

Офіційний інтерфейс Images Edit використовує `mask` для визначення області, у якій дозволено зміни. Моделі Ace Data Cloud з `:official` дотримуються такого самого multipart-контракту:

- `mask` має бути PNG з альфа-каналом, розміром не більше 4MB;
- розмір маски має повністю збігатися з першою `image`;
- прозорі пікселі з Alpha, що дорівнює `0`, позначають дозволену для редагування область, а непрозорі пікселі позначають те, що слід зберегти;
- RGB-зображення лише з чорно-білими кольорами, але без прозорого каналу, не можуть використовуватися як дійсні маски;
- підказка повинна описувати очікуване повне зображення, водночас чітко вказуючи локальні зміни та вміст, який має залишитися незмінним.

Нижче спочатку створюється маска з оригінального зображення. Приклад робить центральний прямокутник прозорим, дозволяючи моделі змінювати лише цю область:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Потім завантажте разом оригінальне зображення та маску:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Також можна використати спосіб виклику `images.edit` з офіційного Python SDK OpenAI, лише вказавши `base_url` на Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```
Під час використання `mask` оригінальне зображення та маска повинні бути завантажені в одному й тому самому multipart-запиті окремо через `image=@input.png` і `mask=@mask.png`. Не передавайте разом URL оригінального зображення та локальний файл маски; запити редагування лише з URL не підтримують додавання локального файлу `mask`. Маска обмежує область редагування, але модель генерації все одно може виконувати природне змішування на краях; якщо потрібні суворі межі, слід використовувати чіткі Alpha-краї та повторно вказувати в промпті, який вміст має залишатися незмінним.

Наведений вище спосіб виклику узгоджується з прикладами масок в [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) і [офіційному Cookbook GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Поширені параметри

| Поле                | Опис                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (швидше) або `gpt-image-2.5-sunburst` (вища точність і контроль); для всіх трьох можна вибрати відповідний варіант `:official`, а `gpt-image-2` також підтримує `:reverse` |
| `image`           | JSON використовує один URL або масив до 16 URL; multipart використовує одне чи кілька полів файлу `image`. Під час використання `mask` необхідно завантажувати локальний файл зображення                                              |
| `mask`            | Необов’язкова PNG-маска, лише для multipart-завантаження файлів; повинна мати Alpha-канал, збігатися за розміром з першим `image` і не перевищувати 4 МБ                                                                 |
| `prompt`          | Інструкція з редагування                                                                                                                             |
| `size`            | `auto` або `WIDTHxHEIGHT`, що відповідає обмеженням                                                                                                     |
| `n`               | 1–10; за `response_format=b64_json` підтримується лише 1                                                                                           |
| `response_format` | `url` або `b64_json`                                                                                                               |
| `callback_url`    | Необов’язкова адреса асинхронного зворотного виклику                                                                                                                         |

Правила розмірів такі самі, як для інтерфейсу генерації: ширина й висота мають бути кратними 16, довша сторона не повинна перевищувати 3840, загальна кількість пікселів становить 655,360–8,294,400, а співвідношення сторін не повинно перевищувати 3:1. Якщо `size` не вказано або використовується `auto`, модель вибере формат кадру на основі промпту та першого еталонного зображення.

За `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` і `gpt-image-2:reverse` стягується плата за кількістю успішно створених зображень; `gpt-image-2:official`, `gpt-image-2.5-flare:official` і `gpt-image-2.5-sunburst:official` оплачуються відповідно до фактичних Token текстового вводу, вводу еталонних зображень і виводу зображень, остаточні дані визначаються записами про використання.

## 6. Асинхронні зворотні виклики та усунення помилок

До довгих завдань у запиті можна додати:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Асинхронна відповідь 200 має вигляд `{"task_id": "..."}`; після завершення виконується зворотний виклик з остаточним результатом. Синхронний запит натомість повертає `created` і `data`.

| Статус  | Перевірити                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Формат/кількість зображень, комбінацію параметрів і формат розмірів; під час використання `mask` перевірте Alpha-канал PNG, обмеження 4 МБ і відповідність її розміру першому оригінальному зображенню |
| 401 | API Key і Bearer Header                                           |
| 429 | Частоту запитів                                                              |
| 504 | Перейдіть на асинхронний зворотний виклик                                                            |

Відповідь з помилкою міститиме `trace_id`. Під час повідомлення про проблему надайте цей ID, не надавайте API Key.

Повні поля та актуальні переліки дивіться на сторінці [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Для генерації зображень лише з тексту дивіться [Генерація зображень GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
