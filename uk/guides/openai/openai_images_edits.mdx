## 3. Завантаження локального зображення

Використовуйте `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` можна передавати повторно; серія GPT Image підтримує до 16 референсних зображень. `image` у JSON-запиті може бути одним URL або масивом URL; локальні файли завантажуються через multipart.

### Моделі та способи тарифікації

| `gpt-image-2:reverse` | Явний вибір каналу зворотної розробки; фіксована оплата за кількістю успішно створених зображень |

| `gpt-image-2.6-flare` | Орієнтовано на швидкість генерації; фіксована оплата за кількістю успішно створених зображень |

| `gpt-image-2.6-sunburst` | Акцент на високій точності відтворення та детальному контролі; фіксована оплата за кількість успішно створених зображень |
| `gpt-image-2.5-sunburst:reverse` | Явний зворотний псевдонім, еквівалентний `gpt-image-2.5-sunburst`; фіксована оплата за кількість успішно створених зображень |
| `gpt-image-2.6-sunburst:reverse` | Явний зворотний псевдонім, еквівалентний `gpt-image-2.6-sunburst`; фіксована оплата за кількість успішно створених зображень |
| `gpt-image-2.5-sunburst:official` | Офіційний API-канал із вищою стабільністю та акцентом на високу точність відтворення й детальний контроль; оплата здійснюється за фактичне використання токенів |
| `gpt-image-2.6-sunburst:official` | Офіційний API-канал із вищою стабільністю та акцентом на високу точність відтворення й детальний контроль; оплата здійснюється за фактичне використання токенів |

Ціни на сторінці офіційного API є оцінкою до надсилання запиту; остаточний розрахунок ґрунтується на фактичному використанні токенів і записах про використання у відповіді.

`quality` підтримує `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare і Sunburst (включно з варіантами `:reverse` та `:official`) додатково підтримують `xhigh`, `max`. Це поле можна передавати як для редагування JSON URL зображення, так і для редагування файлів multipart; офіційний канал стягує плату за фактичне використання токенів.

## 4. Локальне редагування за допомогою маски

Офіційний інтерфейс Images Edit використовує `mask` для визначення області, у якій дозволено внесення змін. Моделі Ace Data Cloud з `:official` дотримуються такого самого multipart-контракту:

- `mask` має бути PNG з Alpha-каналом, розміром не більше 4MB;
- розмір маски має повністю збігатися з першою `image`;
- прозорі пікселі з Alpha, що дорівнює `0`, означають, що редагування дозволене, а непрозорі пікселі означають, що їх слід зберегти;
- RGB-зображення, які мають лише чорно-білий колір, але не мають каналу прозорості, не можуть використовуватися як дійсна маска;
- підказка повинна описувати очікуване повне зображення, водночас чітко вказуючи локальні зміни та вміст, який має залишитися незмінним.

Нижче спочатку створюється маска з оригінального зображення. У прикладі центральний прямокутник робиться прозорим, дозволяючи моделі змінювати лише цю область:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Потім завантажте разом оригінальне зображення та маску:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Також можна використати спосіб виклику `images.edit` з офіційного Python SDK OpenAI, лише вказавши Ace Data Cloud як `base_url`:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Під час використання `mask` оригінальне зображення та маску потрібно завантажувати в одному multipart-запиті через `image=@input.png` і `mask=@mask.png` відповідно. Не передавайте разом URL оригінального зображення та локальний файл маски; запити редагування лише з URL не підтримують додавання локального файлу `mask`. Маска обмежує область редагування, але модель генерації все одно може природно поєднувати краї; якщо потрібні суворі межі, слід використовувати чіткі Alpha-краї та повторно вказувати в підказці, який вміст має залишатися незмінним.

Наведений вище спосіб виклику відповідає прикладам масок в [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) і [офіційному Cookbook GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Поширені параметри

| Поле                | Опис                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (швидше) або `gpt-image-2.5-sunburst` (вища точність і контроль); для всіх трьох можна вибрати відповідний варіант `:official`, а `gpt-image-2` також підтримує `:reverse` |
| `image`           | JSON використовує один URL або масив до 16 URL; multipart використовує одне або кілька полів файлу `image`. Під час використання `mask` потрібно завантажувати локальний файл зображення                                              |
| `mask`            | Необов'язкова PNG-маска, лише для multipart-завантаження файлів; повинна мати Alpha-канал, той самий розмір, що й перше `image`, і не перевищувати 4 МБ                                                                 |
| `prompt`          | Інструкція для редагування                                                                                                                             |
| `size`            | `auto` або `WIDTHxHEIGHT`, що відповідає обмеженням                                                                                                     |
| `n`               | 1–10; при `response_format=b64_json` підтримується лише 1                                                                                           |
| `response_format` | `url` або `b64_json`                                                                                                               |
| `callback_url`    | Необов'язкова адреса асинхронного зворотного виклику                                                                                                                         |

Правила розмірів такі самі, як для інтерфейсу генерації: ширина й висота мають бути кратними 16, довша сторона не повинна перевищувати 3840, загальна кількість пікселів має становити 655 360–8 294 400, а співвідношення сторін не повинно перевищувати 3:1. Якщо не вказати `size` або використати `auto`, модель вибере формат кадру на основі підказки та першого еталонного зображення.

За `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` і їхні псевдоніми `:reverse` стягується плата за кількістю успішно створених зображень; `gpt-image-2:official`, `gpt-image-2.5-flare:official` і `gpt-image-2.5-sunburst:official` оплачуються за фактичними Token текстового вводу, вводу еталонного зображення та виводу зображення, остаточна сума визначається записами про використання.

## 6. Асинхронні зворотні виклики та усунення помилок

Для тривалих завдань до запиту можна додати:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Асинхронна відповідь 200 має вигляд `{"task_id": "..."}`; після завершення викликається зворотний виклик з остаточним результатом. Синхронні запити натомість повертають `created` і `data`.

| Статус  | Перевірка                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Формат/кількість зображень, комбінацію параметрів і формат розмірів; під час використання `mask` перевірте Alpha-канал PNG, обмеження 4 МБ і відповідність її розміру першому оригінальному зображенню |
| 401 | API Key і Bearer Header                                           |
| 429 | Частоту запитів                                                              |
| 504 | Перейдіть на асинхронний зворотний виклик                                                            |

Відповідь про помилку містить `trace_id`. Повідомляючи про проблему, надайте цей ID, але не надавайте API Key.

Повний перелік полів і актуальні переліки значень наведено на сторінці [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Для генерації зображень із простого тексту дивіться [Генерація зображень GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

GPT Image 2.6 використовує інтерфейси генерації, редагування, асинхронних завдань і тарифікації версії 2.5:

| Модель                                                          | Тарифікація                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/зображення                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/зображення                   |
| `gpt-image-2.6-flare:official`                              | Така сама, як у 2.5 official, оплата за фактичне використання Token |
| `gpt-image-2.6-sunburst:official`                           | Така сама, як у 2.5 official, оплата за фактичне використання Token |

Для якості доступні `auto`, `low`, `medium`, `high`, `xhigh`, `max`; для розміру використовуйте `auto` або `WIDTHxHEIGHT`, що відповідає наведеним вище обмеженням. Цей інтерфейс підтримує `png`, `jpeg`, `webp`; GPT Image 2.6 також підтримує нативні анімовані зображення `gif`, SVG поки що не підтримується. Редагування підтримує URL зображень JSON і multipart-завантаження файлів. `:reverse` є явним псевдонімом звичайної версії з тією самою назвою. Використовуйте повну назву моделі, не передавайте `gpt-image-2.6`.

### Перетворення зображення на анімований GIF у GPT Image 2.6
GPT Image 2.6 Flare、Sunburst у звичайній версії、`:reverse`、`:official` усі можуть використовувати `output_format: "gif"`. Кадри анімації, інформація про цикл і тривалість відтворення зберігаються; `frame_count` означає кількість кадрів, `frame_duration_ms` означає кількість мілісекунд на кадр, кількість кадрів має бути цілим числом від 2 до 16, тривалість кожного кадру має бути цілим числом від 20 до 655350 мілісекунд і використовується лише для GIF; кодування округлюється до найближчих 10 мс. Якщо не вказано, за замовчуванням використовуються 9 кадрів по 200 мілісекунд на кадр; якщо `size` для GIF пропущено або має значення auto, використовується пресет 512x512.

Рекомендується спочатку використовувати `size: "512x512"`、`frame_count: 9`、`frame_duration_ms: 200`。GIF має окремі обмеження щодо розміру та кількості кадрів, не можна безпосередньо застосовувати статичні специфікації 4K; деякі моделі коригують фактичний розмір виводу. `n` означає кількість повернених GIF-файлів, а не кількість кадрів анімації. Звичайна версія та `:reverse` і надалі тарифікуються за кількістю успішних файлів, офіційна версія тарифікується за фактичним використанням Token.

```json
{
  "model": "gpt-image-2.6-flare",
  "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
  "prompt": "Animate the mug gently moving left and right. Keep its appearance and the background, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### GPT Image 2.6 Статичні зображення 4K

Flare、Sunburst та їхні варіанти `:reverse`、`:official` усі можуть використовувати згадані вище пресети пікселів 4K, наприклад `3840x2160` і `2160x3840`。І генерація, і редагування передають конкретні пікселі через `size`; `4K` не є дійсним значенням `size`, а `4096x4096` також перевищує поточний ліміт пікселів. Наведені вище специфікації 4K застосовуються до статичних PNG/JPEG/WebP, для GIF слід використовувати спеціальні параметри.

### Складність композиції GPT Image 2.6

`complexity` може бути `low`、`medium`、`high`, якщо його пропущено, використовується стандартне значення моделі `high`。Він керує складністю планування та є незалежним від якості рендерингу `quality`; додаткової оплати за запит немає, офіційна версія й надалі розраховується за фактичними Token. Інші моделі не підтримують цей параметр.

GIF не підтримує mask, зображення розмітки, користувацьке стиснення, переписування підказок або частковий потоковий вивід зображень; несумісні комбінації буде відхилено до генерації. Розмір, кількість кадрів і кількість файлів спільно обмежені бюджетом пікселів моделі; для звичайного Flare підтверджено працездатність `1024x1024` і 2 кадрів, цей висновок не можна поширювати на всі комбінації 1K або GIF 4K.

### Редагування з напрямними розмітки

Статичне редагування GPT Image 2.6 підтримує `markup`。Завантажте прозорий PNG такого самого розміру, як перше референсне зображення, на окремому шарі обведіть місце, яке потрібно змінити, і в `prompt` опишіть вимоги до змін. Шар розмітки має містити прозорі пікселі; кожне з двох зображень не повинно перевищувати 16777216 пікселів, а зображення розмітки не повинно перевищувати 40MB. JSON може передавати HTTPS URL, PNG base64 data URL або `{ "image_url": "https://..." }`; multipart завантажує файл через `markup`。Платформа передає шар розмітки у вигляді файлу. `markup` не можна використовувати разом із `mask`、GIF або `prompt_rewriter`, `file_id` не підтримується.

`input_fidelity` не застосовується до GPT Image 2.6, будь ласка, пропустіть його.
