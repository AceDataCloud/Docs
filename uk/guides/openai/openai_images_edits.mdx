## 3. Завантаження локального зображення

Використовуйте `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` можна передавати повторно; серія GPT Image підтримує до 16 референсних зображень. `image` у JSON-запиті може бути одним URL або масивом URL; локальні файли завантажуються через multipart.

### Моделі та спосіб тарифікації

| Модель                                | Сценарії використання та спосіб тарифікації                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Канал зворотного доступу за замовчуванням, фіксована оплата за кількістю успішних зображень                        |
| `gpt-image-2:reverse`             | Явний вибір каналу зворотного доступу, фіксована оплата за кількістю успішних зображень                      |
| `gpt-image-2:official`            | Канал офіційного API, вища стабільність, оплата за фактичним використанням Token            |
| `gpt-image-2.5-flare`             | Акцент на швидкості генерації, фіксована оплата за кількістю успішних зображень                        |
| `gpt-image-2.5-flare:official`    | Канал офіційного API, вища стабільність і акцент на швидкості генерації, оплата за фактичним використанням Token     |
| `gpt-image-2.5-sunburst`          | Акцент на високій точності відтворення та детальному контролі, фіксована оплата за кількістю успішних зображень                    |
| `gpt-image-2.5-sunburst:official` | Канал офіційного API, вища стабільність і акцент на високій точності відтворення та детальному контролі, оплата за фактичним використанням Token |

Ціна на сторінці для каналу офіційного API є оцінкою до запиту; остаточна сума визначається фактичним використанням Token у відповіді та записами про використання.

## 4. Локальне редагування за допомогою маски

Офіційний інтерфейс Images Edit використовує `mask` для визначення області, яку дозволено змінювати. Моделі Ace Data Cloud `:official` дотримуються того самого multipart-контракту:

- `mask` має бути PNG з Alpha-каналом і розміром не більше 4 МБ;
- розмір маски має повністю збігатися з першою `image`;
- прозорі пікселі з Alpha `0` означають, що редагування дозволене, непрозорі пікселі означають, що їх слід зберегти;
- RGB-зображення, що мають лише чорно-білий колір, але не мають каналу прозорості, не можуть бути дійсною маскою;
- промпт має описувати очікуване повне зображення, водночас чітко зазначаючи локальні зміни та вміст, який має залишитися незмінним.

Нижче спочатку створюється маска з оригінального зображення. У прикладі центральний прямокутник робиться прозорим, що дозволяє моделі змінювати лише цю область:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Потім завантажте оригінальне зображення та маску разом:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Також можна продовжувати використовувати спосіб виклику `images.edit` офіційного Python SDK OpenAI, потрібно лише вказати Ace Data Cloud у `base_url`:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Під час використання `mask` оригінальне зображення та маску потрібно завантажувати в одному multipart-запиті окремо через `image=@input.png` і `mask=@mask.png`. Не передавайте разом URL оригінального зображення та локальний файл маски; запити на редагування лише з URL не підтримують додавання локального файлу `mask`. Маска обмежує область редагування, але модель генерації все одно може природно змішувати краї; якщо потрібні суворі межі, слід використовувати чіткі Alpha-краї та повторно зазначити в промпті, який вміст має залишитися незмінним.

Наведений вище спосіб виклику відповідає прикладам масок у [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) та [офіційному Cookbook GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).
## 5. Поширені параметри

| Поле                | Опис                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (швидше) або `gpt-image-2.5-sunburst` (вища точність і контроль); для всіх трьох можна вибрати відповідний варіант `:official`, а `gpt-image-2` також підтримує `:reverse` |
| `image`           | JSON використовує один URL або масив до 16 URL; multipart використовує одне або кілька файлових полів `image`. Під час використання `mask` потрібно завантажити локальний файл зображення                                              |
| `mask`            | Необов’язкова PNG-маска, лише для завантаження файлів multipart; повинна мати Alpha-канал, бути того самого розміру, що й перше `image`, і не перевищувати 4 МБ                                                                 |
| `prompt`          | Інструкція з редагування                                                                                                                             |
| `size`            | `auto` або `WIDTHxHEIGHT`, що відповідає обмеженням                                                                                                     |
| `n`               | 1–10; за `response_format=b64_json` підтримується лише 1                                                                                           |
| `response_format` | `url` або `b64_json`                                                                                                               |
| `callback_url`    | Необов’язкова адреса асинхронного зворотного виклику                                                                                                                         |

Правила розмірів узгоджуються з інтерфейсом генерації: ширина й висота повинні бути кратними 16, довша сторона не має перевищувати 3840, загальна кількість пікселів становить 655,360–8,294,400, а співвідношення сторін не перевищує 3:1. Якщо `size` пропущено або використовується `auto`, модель вибере формат кадру на основі підказки та першого референсного зображення.

За `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` і `gpt-image-2:reverse` стягується плата за кількістю успішних зображень; `gpt-image-2:official`, `gpt-image-2.5-flare:official` і `gpt-image-2.5-sunburst:official` оплачуються на основі фактичних Token текстового введення, введення референсних зображень і виведення зображень, остаточні дані визначаються записами про використання.

## 6. Асинхронний зворотний виклик і налагодження

До довготривалих запитів можна додати:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Асинхронна відповідь 200 має вигляд `{"task_id": "..."}`; після завершення надсилається зворотний виклик із фінальним результатом. Синхронні запити натомість повертають `created` і `data`.

| Статус  | Перевірка                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Формат/кількість зображень, комбінації параметрів і формат розмірів; під час використання `mask` перевірте PNG Alpha-канал, обмеження 4 МБ і відповідність його розміру першому оригінальному зображенню |
| 401 | API Key і Bearer Header                                           |
| 429 | Частоту запитів                                                              |
| 504 | Використайте асинхронний зворотний виклик                                                            |

Відповідь про помилку міститиме `trace_id`. Під час повідомлення про проблему надайте цей ID, не надавайте API Key.

Повний перелік полів і актуальні переліки значень наведено на сторінці [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Для генерації зображень лише з тексту дивіться [Генерація зображень GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
