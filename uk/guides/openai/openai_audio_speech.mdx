---
title: "OpenAI API синтезу мови (/v1/audio/speech)"
description: "OpenAI generation API guide - Ace Data Cloud"
---

Перетворює текст у природну мову, **повністю сумісний з OpenAI `/v1/audio/speech`**. Будь-який OpenAI SDK просто вказує `base_url` на `https://api.acedata.cloud`, замінює ключ на ваш AceData Token і може бути використаний безпосередньо. Інтерфейс синхронно повертає аудіо байтовий потік.

- **Адреса запиту**: `POST https://api.acedata.cloud/v1/audio/speech` (псевдонім `POST /openai/audio/speech`)
- **Аутентифікація**: заголовок запиту `Authorization: Bearer {token}`
- **Оплата**: за кількість байтів тексту в запиті, приблизно 85% від офіційної ціни OpenAI (див. таблицю нижче).

## Параметри запиту

| Поле                | Тип     | Обов'язково | Опис                                                            |
| ----------------- | ------ | --------- | ------------------------------------------------------------- |
| `input`           | string | Так       | Текст, який потрібно синтезувати.                                                       |
| `model`           | string | Ні        | `tts-1` (швидше) або `tts-1-hd` (вища якість, за замовчуванням).                             |
| `voice`           | string | Ні        | Один з `alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`, за замовчуванням `alloy`. |
| `response_format` | string | Ні        | `mp3` (за замовчуванням), `opus`, `aac`, `flac`, `wav`, `pcm`.                    |
| `speed`           | number | Ні        | Швидкість мови 0.25–4.0, за замовчуванням 1.0.                                           |

## Приклад

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/speech' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -o speech.mp3 \
  -d '{
    "model": "tts-1-hd",
    "input": "Що, якщо один API надасть вам усі моделі AI відео?",
    "voice": "nova",
    "response_format": "mp3"
  }'
```

Повертається сам аудіофайл (`Content-Type: audio/mpeg`), який можна безпосередньо записати в `speech.mp3` для відтворення.

Використовуючи офіційний OpenAI Python SDK:

```python
from openai import OpenAI
client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
client.audio.speech.create(model="tts-1-hd", voice="nova", input="Привіт від AceData.").stream_to_file("speech.mp3")
```

## Ціни

| Модель         | Офіційна ціна OpenAI    | Ціна на цій платформі (приблизно 85% знижка)       |
| ---------- | ------------- | ------------------ |
| `tts-1`    | $15 / 1 мільйон символів | приблизно $12.75 / 1 мільйон символів |
| `tts-1-hd` | $30 / 1 мільйон символів | приблизно $25.5 / 1 мільйон символів  |

> Оплата за кількість байтів тексту в запиті; поле `official_price` показує офіційну ціну OpenAI для порівняння.

## Код помилки

| Код статусу | code                    | Опис               |
| --- | ----------------------- | ---------------- |
| 400 | `bad_request`           | `input` порожній або параметри недійсні. |
| 401 | `authentication_failed` | токен недійсний.        |
| 403 | `used_up`               | недостатньо коштів.            |
| 429 | `too_many_requests`     | запити надто часті.          |
| 500 | `api_error`             | помилка на стороні сервера/внутрішня помилка.         |
