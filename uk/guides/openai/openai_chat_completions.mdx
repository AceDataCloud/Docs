OpenAI ChatGPT — це дуже потужна система AI-діалогів, достатньо ввести підказку, і вона зможе за лічені секунди згенерувати плавну та природну відповідь. ChatGPT вирізняється в галузі своїми видатними можливостями розуміння та генерації мови, і сьогодні ChatGPT уже широко використовується в різних галузях і сферах, а його вплив стає дедалі помітнішим. Чи то щоденні діалоги, творче письмо, чи професійні консультації, програмування коду — ChatGPT може надати вражаючу інтелектуальну допомогу, значно підвищуючи ефективність роботи та творчі можливості людини.

Цей документ головним чином представляє процес використання операцій OpenAI Chat Completion API, за допомогою якого ми можемо легко використовувати функції діалогу офіційного OpenAI ChatGPT.

## GPT-6.1 Sol

Використовуйте `model: "gpt-6.1-sol"` для вибору цієї моделі. Підтримуються потокове виведення, виклики функцій, структуроване виведення та введення зображень. Протягом першого тижня після відкриття доступ надається лише верифікованим власникам ACE T1+ (щонайменше 100 000 ACE) або авторизованим користувачам; конкретний час відкриття доступу визначається підказками доступу в консолі.

Рівні міркування підтримують `low`, `medium`, `high`, `xhigh` і `max`; `none` або `minimal` наразі не підтримуються. Рекомендується почати з `reasoning_effort: "low"`. Якщо введення перевищує 272 000 tokens, до всього запиту застосовується тарифікація довгого контексту, а вартість визначається поточними цінами в консолі.

## Базове використання

Далі можна заповнити відповідний вміст в інтерфейсі, як показано на зображенні:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

Під час першого використання цього інтерфейсу нам потрібно заповнити щонайменше три поля: одне з них — `authorization`, його можна безпосередньо вибрати у розкривному списку. Інший параметр — `model`, `model` — це категорія моделі OpenAI ChatGPT, яку ми обираємо для використання; тут у нас є переважно 20 моделей, деталі можна переглянути в наданих нами моделях. Останній параметр — `messages`, `messages` — це масив введених нами запитів, це масив, який означає, що можна одночасно завантажувати кілька запитів; кожен запит містить `role` і `content`, де `role` позначає роль запитувача, ми надаємо три ролі: `user`, `assistant`, `system`. Інший параметр `content` — це конкретний зміст нашого запитання.

Водночас ви можете звернути увагу, що праворуч генерується відповідний код виклику; ви можете скопіювати код і запустити його безпосередньо або безпосередньо натиснути кнопку «Try» для тестування.

Поширені необов’язкові параметри:

- `max_tokens`: обмежує максимальну кількість token в одній відповіді.
- `temperature`: випадковість генерації, від 0 до 2, чим більше значення, тим більш розгалужений результат.
- `n`: скільки варіантів відповідей генерувати за один раз.
- `response_format`: налаштування формату повернення.

Результат повернення загалом має кілька полів, описаних нижче:

- `model ` — обрана модель OpenAI ChatGPT з офіційного сайту.
- `choices` — інформація про відповідь ChatGPT на запит.

Серед них `choices` містить інформацію про відповіді ChatGPT, `choices` всередині нього — це ChatGPT, як можна побачити на зображенні.

## Потокова відповідь

Цей інтерфейс також підтримує потокові відповіді, що дуже корисно для інтеграції з вебсторінками та дозволяє вебсторінкам реалізувати ефект посимвольного відображення.

Якщо ви хочете повертати відповідь потоково, можете змінити параметр `stream ` у заголовку запиту на `true`.

Зміни показано на зображенні, однак код виклику потребує відповідних змін, щоб підтримувати потокову відповідь.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

Після зміни `stream` на `true` API повертатиме відповідні JSON-дані рядок за рядком, а на рівні коду нам потрібно внести відповідні зміни, щоб отримувати результати по рядках.

Приклад коду виклику Python:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

JavaScript також підтримується, наприклад, код потокового виклику для Node.js наведено нижче:

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4",
    messages: [{ role: "user", content: "hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```


## Багатораундовий діалог

Якщо ви хочете інтегрувати функцію багатораундового діалогу, потрібно передати кілька запитів у поле `messages`; конкретний приклад кількох запитів показано на зображенні нижче:

<p><img src="https://cdn.acedata.cloud/oz4mar.png" width="400" className="m-auto" /></p>

Приклад коду виклику Python:
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"Hello"},{"role":"assistant","content":"Hi! How can I assist you today?"},{"role":"user","content":"What I say just now?"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Завантаживши кілька запитів, можна легко реалізувати багатораундовий діалог і отримати таку відповідь:

## Інтеграція з OpenAI-Python

OpenAI Chat Completion API сумісний з офіційним інтерфейсом OpenAI; для інтеграції можна безпосередньо використовувати офіційний SDK [OpenAI-Python](https://github.com/openai/openai-python). У цій статті буде коротко представлено спосіб використання.

1. Спочатку потрібно налаштувати локальне середовище `Python`; цей процес можна пошукати в Google.
2. Завантажте та встановіть середовище розробки, наприклад редактор VSCode.
3. Налаштуйте змінні середовища `OpenAI`.

- У папці проєкту створіть файл із назвою `.env` і збережіть його.
- Вміст файлу `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # 再次提醒：如果你使用官网OpenAI的key，不要用这个地址。
```

Замініть `sk-xxx` на власний key. `OPENAI_BASE_URL` є проксі-інтерфейсом для доступу до OpenAI.

4. Встановіть пакети залежностей проєкту

```shell
pip install openai
```

У Mac OS команда має вигляд:

```shell
pip3 install openai
```

5. Створіть файл вихідного коду прикладу

Припустімо, ми створили приклад коду `index.py`, конкретний вміст такий:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

Інформацію відповіді в `choices` потрібно рендерити за допомогою синтаксису `markdown`, щоб отримати найкращий досвід; зрештою, це також відображає потужні переваги функції доступу нашої моделі до інтернету.

## Візуальна модель

gpt-4o — це мультимодальна велика мовна модель, розроблена OpenAI; на основі GPT-4 вона додає можливість візуального розуміння. Ця модель може одночасно обробляти текстові та зображувальні входи, реалізуючи міжмодальне розуміння й генерацію.

Текстова обробка з використанням моделі gpt-4o узгоджується з базовим використанням, описаним вище; нижче буде коротко представлено, як використовувати можливості моделі для обробки зображень.

Можливості моделі gpt-4o для обробки зображень переважно використовуються шляхом додавання поля `type` на основі початкового вмісту `content`; за допомогою цього поля можна визначити, чи завантажено текст або зображення, і таким чином використовувати можливості моделі gpt-4o для обробки зображень. Нижче переважно описано виклик цієї функції двома способами: Curl і Python.

- Спосіб зі скриптом Curl

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

- Спосіб зі скриптом Python
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
                    }
                },
            ],
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Окрім gpt-4o, є ще одна модель із нижчою вартістю, яка називається gpt-4o-mini. gpt-4o-mini — це новітнє покоління великих мовних моделей, розроблене OpenAI, вона не лише швидко відповідає, але й коштує дешевше, а також підтримує мультимодальність. ## Обробка помилок

Під час виклику API, якщо виникає помилка, API поверне відповідний код помилки та інформацію. Наприклад:

- `400 token_mismatched`：Неправильний запит, можливо, через відсутні або недійсні параметри.
- `400 api_not_implemented`：Неправильний запит, можливо, через відсутні або недійсні параметри.
- `401 invalid_token`：Неавторизовано, недійсний або відсутній токен авторизації.
- `429 too_many_requests`：Забагато запитів, ви перевищили обмеження швидкості.
- `500 api_error`：Внутрішня помилка сервера, щось пішло не так на сервері.
