OpenAI ChatGPT — це дуже потужна система AI-діалогів: достатньо ввести підказку, і вона зможе за кілька секунд згенерувати плавну та природну відповідь. ChatGPT вирізняється в галузі своїми чудовими можливостями розуміння та генерування мови. Сьогодні ChatGPT уже широко застосовується в різних галузях і сферах, а його вплив стає дедалі помітнішим. Чи то повсякденні діалоги, творче письмо, професійні консультації або програмування коду — ChatGPT може надати вражаючу інтелектуальну допомогу, значно підвищуючи ефективність роботи та творчість людей.

Цей документ переважно описує процес використання операцій OpenAI Chat Completion API, за допомогою якого ми можемо легко використовувати функції діалогу офіційного OpenAI ChatGPT.

Запити сумісних моделей, прийняті платформою, тарифікуються відповідно до використання введення, виведення та кешу цієї моделі. `prompt_tokens` у Chat Completions містить кешовані token, а зазначена кешована частина розраховується за відповідною ціною кешу; зміна формату інтерфейсу не перетворюється на оплату за фіксовану кількість разів. Вартість визначається поточними цінами моделей у консолі та `usage.cost` у відповіді.

## GPT-6.1 Terra

Використовуйте `model: "gpt-6.1-terra"` для вибору цієї моделі. Підтримуються текстовий і графічний ввід та потокове виведення; функціональні інструменти та структуроване виведення викликайте відповідно до формату параметрів цього інтерфейсу. Рівні міркування підтримують `low`, `medium`, `high`, `xhigh` і `max`, рекомендується починати з `reasoning_effort: "low"`; `none` або `minimal` не підтримуються. Коли ввід перевищує 272,000 tokens, застосовується ціна довгого контексту; фактична вартість визначається поточними цінами в консолі та використанням у відповіді.

## GPT-6.1 Sol

Використовуйте `model: "gpt-6.1-sol"` для вибору цієї моделі. Підтримуються потокове виведення, виклик функцій, структуроване виведення та введення зображень. Протягом першого тижня після відкриття вона доступна лише перевіреним власникам ACE T1+ (щонайменше 100,000 ACE) або авторизованим користувачам; конкретний час відкриття визначається підказками доступу в консолі.

Рівні міркування підтримують `low`, `medium`, `high`, `xhigh` і `max`, `none` або `minimal` наразі не підтримуються. Рекомендується починати з `reasoning_effort: "low"`. Коли ввід перевищує 272,000 tokens, до всього запиту застосовується ціна довгого контексту, а вартість визначається поточними цінами в консолі.

## Базове використання

Далі можна заповнити відповідний вміст в інтерфейсі, як показано на зображенні:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

Під час першого використання цього інтерфейсу нам потрібно заповнити щонайменше три поля: одне з них — `authorization`, яке можна безпосередньо вибрати у спадному списку. Інший параметр — `model`, `model` — це категорія моделі офіційного сайту OpenAI ChatGPT, яку ми вибираємо для використання; тут ми маємо переважно 20 моделей, деталі можна переглянути в наданих нами моделях. Останній параметр — `messages`, `messages` — це масив введених нами запитів; це масив, що означає можливість одночасно завантажити кілька запитів, кожен запит містить `role` і `content`, де `role` позначає роль запитувача, ми надаємо три ідентичності: `user`, `assistant`, `system`. Інший `content` — це конкретний вміст нашого запиту.

Водночас ви можете помітити, що праворуч є генерація відповідного коду виклику: ви можете скопіювати код і запустити його безпосередньо або натиснути кнопку «Try» для тестування.

Поширені необов’язкові параметри:

- `max_tokens`: обмежує максимальну кількість token для однієї відповіді.
- `temperature`: випадковість генерації, від 0 до 2; що більше значення, то більш розгалужений результат.
- `n`: скільки варіантів відповідей генерувати за один раз.
- `response_format`: налаштування формату відповіді.

<p><img src="https://cdn.acedata.cloud/mthuu2.png" width="400" className="m-auto" /></p>

Результат, що повертається, має кілька полів, описаних нижче:

- `model ` — вибрана модель офіційного сайту OpenAI ChatGPT.
- `choices` — інформація про відповідь, надану ChatGPT на запит.
- `usage `: статистична інформація про token для цієї пари запитання-відповідь.

Серед них `choices` містить інформацію про відповідь ChatGPT, `choices` всередині нього — це ChatGPT, як можна побачити на зображенні.

## Потокова відповідь

Цей інтерфейс також підтримує потокову відповідь, що дуже корисно для інтеграції з вебсторінками та може дозволити вебсторінці реалізувати ефект поступового відображення символ за символом.

Якщо ви хочете повертати відповідь потоково, можна змінити параметр `stream ` у заголовку запиту на `true`.

Зміна показана на зображенні, але код виклику потребує відповідних змін для підтримки потокової відповіді.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

Після зміни `stream` на `true` API повертатиме відповідні JSON-дані рядок за рядком, і на рівні коду нам потрібно внести відповідні зміни, щоб отримати результат рядок за рядком.

Приклад коду виклику Python:
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```javascript
const options = {
```

## Багатораундовий діалог
Якщо ви хочете підключити функцію багатораундового діалогу, потрібно передати кілька запитів у поле `messages`; конкретний приклад кількох запитів показано на зображенні нижче:

<p><img src="https://cdn.acedata.cloud/oz4mar.png" width="400" className="m-auto" /></p>

Приклад коду виклику Python:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"Hello"},{"role":"assistant","content":"Hi! How can I assist you today?"},{"role":"user","content":"What I say just now?"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Передаючи кілька запитів, можна легко реалізувати багатораундовий діалог і отримати таку відповідь:

## Підключення OpenAI-Python

OpenAI Chat Completion API сумісний з офіційним інтерфейсом OpenAI, і його можна безпосередньо підключити за допомогою офіційного SDK [OpenAI-Python](https://github.com/openai/openai-python); у цій статті буде коротко представлено спосіб використання.

1. Спочатку потрібно налаштувати локальне середовище `Python`; цей процес можна пошукати в Google.
2. Завантажте та встановіть середовище розробки, наприклад редактор VSCode.
3. Налаштуйте змінні середовища `OpenAI`.

- У папці проєкту створіть файл із назвою `.env` і збережіть його.
- Вміст файлу `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # 再次提醒：如果你使用官网OpenAI的key，不要用这个地址。
```

Замініть `sk-xxx` власним key. `OPENAI_BASE_URL` — це проксі-інтерфейс для доступу до OpenAI.

4. Встановіть пакети, від яких залежить проєкт.

```shell
pip install openai
```

У Mac OS команда має вигляд:

```shell
pip3 install openai
```

5. Створіть файл із прикладом вихідного коду.

Припустімо, ми створили приклад коду `index.py`, його конкретний вміст такий:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Візуальна модель

gpt-4o — це мультимодальна велика мовна модель, розроблена OpenAI; на основі GPT-4 вона отримала здатність візуального розуміння. Ця модель може одночасно обробляти текстові та графічні вхідні дані, реалізуючи міжмодальне розуміння та генерацію.

Текстова обробка за допомогою моделі gpt-4o узгоджується з описом базового використання вище; нижче буде коротко представлено, як використовувати можливості моделі для обробки зображень.

Можливість обробки зображень моделі gpt-4o переважно використовується шляхом додавання поля `type` до початкового вмісту `content`; за допомогою цього поля можна визначити, чи завантажується текст або зображення, і таким чином використовувати можливість моделі gpt-4o для обробки зображень. Нижче переважно описано виклик цієї функції двома способами: Curl і Python.

- Спосіб за допомогою скрипту Curl

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \

    "messages": [
      {
        "role": "user",
        "content": [
          {

            "text": "What'\''s in this image?"

            }
          }

  }'
```

- Спосіб за допомогою скрипту Python
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
                    }
                },
            ],
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Окрім gpt-4o, існує ще одна модель із нижчою вартістю, що називається gpt-4o-mini. gpt-4o-mini — це новітнє покоління великих мовних моделей, розроблене OpenAI; вона не лише швидко відповідає, але й має нижчу ціну та також підтримує мультимодальність. Щодо використання функції vision можна звернутися до вмісту про використання моделі gpt-4o вище.

## Обробка помилок

Під час виклику API, якщо виникає помилка, API поверне відповідний код помилки та інформацію. Наприклад:

- `400 token_mismatched`：Неправильний запит, можливо, через відсутні або недійсні параметри.
- `400 api_not_implemented`：Неправильний запит, можливо, через відсутні або недійсні параметри.
- `401 invalid_token`：Неавторизовано, недійсний або відсутній токен авторизації.
- `429 too_many_requests`：Забагато запитів, ви перевищили ліміт частоти запитів.
- `500 api_error`：Внутрішня помилка сервера, на сервері щось пішло не так.
