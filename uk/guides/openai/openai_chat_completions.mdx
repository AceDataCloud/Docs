OpenAI ChatGPT — це дуже потужна AI система діалогу, яка може генерувати плавні та природні відповіді всього за кілька секунд, просто ввівши підказку. ChatGPT виділяється в галузі завдяки своїм видатним можливостям розуміння та генерації мови, і сьогодні ChatGPT вже широко використовується в різних галузях та сферах, його вплив стає все більш помітним. Незалежно від того, чи це повсякденні розмови, креативне письмо, чи професійні консультації, програмування, ChatGPT може надати вражаючу інтелектуальну допомогу, значно підвищуючи продуктивність та креативність людей.

Цей документ в основному описує процес використання OpenAI Chat Completion API, за допомогою якого ми можемо легко використовувати функцію діалогу офіційного OpenAI ChatGPT.

При першій заявці буде надано безкоштовний ліміт, який дозволяє безкоштовно використовувати цей API.

## Основне використання

Далі ви можете заповнити відповідні дані на інтерфейсі, як показано на малюнку:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

При першому використанні цього інтерфейсу нам потрібно заповнити принаймні три поля: одне з них — `authorization`, яке можна вибрати безпосередньо зі списку. Інший параметр — `model`, `model` — це категорія моделі, яку ми вибираємо для використання з офіційного сайту OpenAI ChatGPT, тут у нас є 20 моделей, деталі можна переглянути в наданих моделях. Останній параметр — `messages`, `messages` — це масив запитів, який представляє собою масив, що дозволяє одночасно завантажувати кілька запитів, кожен з яких містить `role` та `content`, де `role` вказує на роль запитувача, ми надали три ідентичності: `user`, `assistant`, `system`. Інший `content` — це конкретний зміст нашого запиту.

Ви також можете помітити, що праворуч є відповідний код виклику, який ви можете скопіювати та запустити, або просто натиснути кнопку «Try» для тестування.

Звичайні необов'язкові параметри:

- `max_tokens`: обмеження на максимальну кількість токенів у відповіді.
- `temperature`: випадковість генерації, від 0 до 2, чим більше значення, тим більше розсіювання.
- `n`: скільки кандидатних відповідей генерувати за один раз.
- `response_format`: налаштування формату відповіді.

## Потокова відповідь

Цей інтерфейс також підтримує потокову відповідь, що дуже корисно для веб-інтеграції, оскільки дозволяє веб-сторінці реалізувати ефект поетапного відображення.

Якщо ви хочете отримати потокову відповідь, ви можете змінити параметр `stream` у заголовку запиту на `true`.

Зміна, як показано на малюнку, але код виклику потребує відповідних змін, щоб підтримувати потокову відповідь.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

Після зміни `stream` на `true`, API буде повертати відповідні JSON дані по рядках, на рівні коду нам потрібно внести відповідні зміни, щоб отримати результати по рядках.

Приклад коду виклику на Python:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Багатократний діалог

Якщо ви хочете інтегрувати функцію багатократного діалогу, вам потрібно завантажити кілька запитів у поле `messages`, приклади кількох запитів наведені на зображенні нижче:

<p><img src="https://cdn.acedata.cloud/oz4mar.png" width="400" className="m-auto" /></p>

Приклад виклику на Python:
```
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"Привіт"},{"role":"assistant","content":"Привіт! Чим я можу вам допомогти сьогодні?"},{"role":"user","content":"Що я тільки що сказав?"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Інтеграція з OpenAI-Python

Сервіс OpenAI Chat Completion API є верхнім шаром офіційного сервісу OpenAI, детальніше можна ознайомитися з офіційним [OpenAI-Python](https://github.com/openai/openai-python), у цій статті буде коротко описано, як використовувати наданий офіційний сервіс.

1. Спочатку потрібно налаштувати локальне середовище `Python`, цей процес можна знайти в Google.
2. Завантажте та встановіть середовище розробки, наприклад, встановіть редактор VSCode.
3. Налаштуйте змінні середовища `OpenAI`.

- У папці проекту створіть файл з назвою `.env` і збережіть
- Вміст файлу `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # Ще раз нагадую: якщо ви використовуєте ключ OpenAI з офіційного сайту, не використовуйте цю адресу.
```

`sk-xxx` замініть на свій ключ. `OPENAI_BASE_URL` - це проксі-інтерфейс для доступу до OpenAI.

4. Встановіть залежності проекту

```shell
pip install openai
```

У Mac OS команда буде:

```shell
pip3 install openai
```

5. Створіть файл з прикладом вихідного коду

Припустимо, ми створили приклад коду `index.py`, конкретний вміст виглядає так:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "привіт",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Візуальна модель

gpt-4o - це багатомодальна велика мовна модель, розроблена OpenAI, яка на базі GPT-4 отримала можливості візуального розуміння. Ця модель може одночасно обробляти текстові та зображення, реалізуючи міжмодальне розуміння та генерацію.

Використання текстової обробки моделі gpt-4o є таким же, як і в основному вмісті, описаному вище, нижче буде коротко описано, як використовувати можливості обробки зображень моделі.

Використання можливостей обробки зображень моделі gpt-4o в основному здійснюється шляхом додавання поля `type` до вмісту `content`, за допомогою якого можна дізнатися, чи завантажено текст чи зображення, щоб використовувати можливості обробки зображень моделі gpt-4o, нижче буде описано, як викликати цю функцію за допомогою Curl та Python.

- Curl скрипт

```

-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {

## Обробка помилок

При виклику API, якщо виникає помилка, API поверне відповідний код помилки та інформацію. Наприклад:

- `400 token_mismatched`: Неправильний запит, можливо, через відсутні або недійсні параметри.
- `400 api_not_implemented`: Неправильний запит, можливо, через відсутні або недійсні параметри.
- `401 invalid_token`: Неавторизовано, недійсний або відсутній токен авторизації.
- `429 too_many_requests`: Занадто багато запитів, ви перевищили ліміт запитів.
- `500 api_error`: Внутрішня помилка сервера, щось пішло не так на сервері.
