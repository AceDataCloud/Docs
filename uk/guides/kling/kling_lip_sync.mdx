title: "API для синхронізації губ Kling (Kling Lip Sync)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Дайте можливість **існуючому відео Kling** (5 секунд або 10 секунд) "говорити" відповідно до аудіо або тексту — тобто синхронізувати губи (Lip Sync). У поєднанні з `/kling/videos` `image2video` (зробіть фотографії рухомими) це може скласти повний процес "**говорячих фотографій / цифрових аватарів**".

> Цей інтерфейс є простим пакетом, наданим AceDataCloud, для загальних сценаріїв, що використовують аудіо/текст; це не є полем дзеркала багатоступеневих інтерфейсів Kling "Розпізнавання облич → Розширена синхронізація губ". Будь ласка, орієнтуйтеся на таблицю параметрів на цій сторінці.

- **Адреса інтерфейсу**: `POST https://api.acedata.cloud/kling/lip-sync`
- **Формат запиту**: `application/json`
- **Формат відповіді**: `application/json`
- **Оплата**: кожен успішний виклик **2.45 Credits** (фіксовано)

## Заголовки запиту (Request Headers)

| Поле              | Значення               | Опис                                               |
| ---------------- | --------------------- | ------------------------------------------------ |
| `authorization`  | `Bearer ${API_KEY}`   | Ваш API ключ, [адреса отримання](https://platform.acedata.cloud) |
| `content-type`   | `application/json`    | Формат тіла запиту                                   |
| `accept`         | `application/json`    | Формат відповіді                                    |

## Параметри запиту (Request Body)

| Параметр         | Тип      | Обов'язковий | За замовчуванням | Опис                                                                                                                       |
| ---------------- | ------- | ------------ | ---------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `mode`           | string  | Так          | —                | Режим генерації. Перелік: `audio2video` (аудіо-управління), `text2video` (текстове управління)                                                                           |
| `video_id`       | string  | Один з двох  | —                | ID відео, згенерованого Kling (наприклад, `video_id`, повернуте з `image2video` з `/kling/videos`). **Підтримуються лише 5s/10s відео, згенеровані протягом 30 днів**. `video_id` та `video_url` один з двох, не можна передавати одночасно |
| `video_url`      | string  | Один з двох  | —                | Посилання на відео, доступне в Інтернеті. Обмеження: `.mp4`/`.mov`, ≤100MB, тривалість 2–10s, лише 720p/1080p, сторони 720–1920px. Один з двох з `video_id`                                  |
| `audio_url`      | string  | Умовно       | —                | URL для завантаження аудіо, обов'язковий при `audio2video` + `audio_type=url`. Формат `.mp3`/`.wav`/`.m4a`/`.aac`, ≤5MB                                     |
| `audio_type`     | string  | Ні           | `url`           | Спосіб передачі аудіо. Перелік: `url`, `file` (діє при `audio2video`)                                                                                |
| `audio_file`     | string  | Умовно       | —                | Base64 аудіофайлу, обов'язковий при `audio_type=file`. Формат такий же, ≤5MB                                                                             |
| `text`           | string  | Умовно       | —                | Текст для читання, обов'язковий при `text2video`, **максимум 120 символів**                                                                                     |
| `voice_id`       | string  | Умовно       | —                | ID голосу, обов'язковий при `text2video`                                                                                                   |
| `voice_language` | string  | Ні           | `zh`            | Мова голосу. Перелік: `zh`, `en` (діє при `text2video`)                                                                                      |
| `voice_speed`    | float   | Ні           | `1.0`           | Швидкість мови, діапазон `0.8`–`2.0`, точність до одного знака після коми (діє при `text2video`)                                                                              |
| `callback_url`   | string  | Ні           | —                | URL для зворотного виклику. Якщо передати цей параметр або `async=true`, то **асинхронний режим**: негайно повертає `task_id`, результат буде повернуто після генерації                                                                 |
| `async`          | boolean | Ні           | `false`         | Чи асинхронно. Якщо `true`, негайно повертає `task_id`, у поєднанні з `/kling/tasks` для опитування або зворотним викликом `callback_url`                                                      |

## Приклад запиту

### 1) Аудіо-управління (audio2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2) Текстове управління (text2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "Брате, давно не бачились, у мене все добре, бережи себе.",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## Приклад відповіді (успішно синхронізовано)

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| Поле          | Тип      | Опис                                         |
| ------------- | ------- | ------------------------------------------ |
| `success`     | boolean | Чи успішно                                       |
| `task_id`     | string  | ID цього завдання (можна використовувати для запиту `/kling/tasks`)             |
| `video_id`    | string  | ID згенерованого відео Kling (можна використовувати як вхід для наступного `extend`/`lip-sync`) |
| `video_url`   | string  | URL згенерованого відео (збережено на платформі CDN, довгостроково дійсно)              |
| `duration`    | string  | Тривалість відео (секунди)                                    |
| `state`       | string  | Статус завдання: `succeed` / `failed`                  |

## Асинхронний режим та запит

При передачі `callback_url` або `async: true` інтерфейс **негайно повертає** `task_id`; далі можна:

- **Опитування**: `POST /kling/tasks`, body `{ "action": "retrieve", "id": "<task_id>" }` (безкоштовно)
- **Зворотний виклик**: після завершення генерації результат буде надіслано на ваш `callback_url`

## Повний процес: говорячі фотографії (image2video → lip-sync)
```bash
# Крок 1: Зробіть фото рухомим, отримайте video_id
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"look at camera, natural","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# Крок 2: Синхронізуйте губи з аудіо
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"}'
# → { "video_url": "https://platform2.cdn.acedata.cloud/kling/....mp4", ... }
```

## Помилка відповіді

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "один з video_id або video_url є обов'язковим" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | код                     | Значення                                             |
| ---- | ----------------------- | -------------------------------------------------- |
| 400  | `bad_request`           | Відсутні або недійсні параметри (наприклад, не передано mode, конфлікт між video та audio, текст перевищує 120 символів) |
| 401  | `authorization_missing` | Відсутній або недійсний API ключ                           |
| 403  | `forbidden`             | Контент заблоковано системою контролю ризиків              |
| 429  | `too_many_requests`     | Обмеження на кількість запитів, будь ласка, спробуйте пізніше |
| 500  | `api_error`             | Помилка на стороні сервера або внутрішня помилка          |

## Зверніть увагу

- `video_id` повинен бути **створений протягом 30 днів**, і бути **5s або 10s**; в іншому випадку, передайте відповідне відео через `video_url`.
- Рекомендується, щоб вхідне відео було **чітким, з фронтальним зображенням, однією особою**, для кращого ефекту синхронізації губ.
- Тривалість аудіо/тексту повинна відповідати тривалості відео (аудіо не повинно перевищувати довжину відео).
- Оплата відбувається при **успішному** виконанні (2.45 Credits/раз); помилки в перевірці параметрів (4xx) не підлягають оплаті.
