Надсилайте завдання через `POST /kling/video-commerce`, використовуйте наявний `POST /kling/tasks` для перевірки статусу завдання платформи.

## Вхідні дані

Завантажте одне зображення людини та вкажіть voice_id, або використовуйте попередньо встановлений avatar_id (ці два варіанти взаємовиключні, для попередньо встановленого персонажа не можна окремо вказувати voice_id). Необхідно надати speech_script обсягом до 2000 символів. Під час надання інформації про товар потрібні щонайменше одне ref_image та один goods_title; озвучення товару не підтримує speech_rate. Звичайне озвучення персонажа підтримує швидкість мовлення 0.8, 1.0 або 1.2.

Нижче наведено приклад структури запиту, замініть URL-адреси матеріалів перед викликом.

```json
{
  "contents": [
    {
      "type": "avatar_image",
      "url": "https://your-cdn.example/person.jpg"
    },
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    },
    {
      "type": "speech_script",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "voice_id": "male_calm_informative"
  },
  "async": true
}
```

## Результати та тарифікація

Синхронний режим повертає результат генерації; асинхронний режим спочатку повертає `task_id`, а завершений результат містить у `data` посилання на відео або зображення та обчислений сервером `usage`. `callback_url` використовується для сповіщення про завершення; запит із `watermark=true` одночасно повертає версію з водяним знаком.

Звичайне озвучення персонажа: 720p — 1.4 Credits/секунду, 1080p — 1.68 Credits/секунду; озвучення товару: 720p — 1.96 Credits/секунду, 1080p — 2.24 Credits/секунду. Відео тарифікується за фактичною тривалістю генерації, базова ціна за секунду до генерації не є загальною ціною всього завдання. За невдалі завдання плата за генерацію не стягується.
