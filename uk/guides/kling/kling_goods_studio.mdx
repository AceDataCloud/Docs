Надсилайте завдання через `POST /kling/goods-studio`, використовуйте наявний `POST /kling/tasks` для перевірки статусу завдань платформи.

## Вхідні дані

Надайте 1–5 зображень товару та назву товару до 200 символів; опис товару необов’язковий, до 2000 символів. Тривалість може становити 15, 30 або 60 секунд.

Нижче наведено приклад структури запиту, замініть URL матеріалів перед викликом.

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## Результати та тарифікація

Синхронний режим повертає результат генерації; асинхронний режим спочатку повертає `task_id`, а завершений результат містить посилання на відео або зображення в `data` та обчислений сервером `usage`. `callback_url` використовується для сповіщення про завершення; запит із `watermark=true` одночасно повертає версію з водяним знаком.

720p: 2,38 Credits/секунда; 1080p: 2,8 Credits/секунда. Відео тарифікується за фактичною тривалістю генерації, базова ціна за секунду до генерації не є загальною вартістю всього завдання. За невдалі завдання плата за генерацію не стягується.
