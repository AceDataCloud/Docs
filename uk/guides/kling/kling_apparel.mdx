Надсилайте завдання через `POST /kling/apparel`, використовуйте наявний `POST /kling/tasks` для перевірки статусу завдань платформи.

## Вхідні дані

Надайте опис товару обсягом до 2500 символів, одне референсне відео тривалістю 5–180 секунд і 1–5 зображень товару. Додатково можна надати 1–5 зображень моделі, файл фонової музики та вказати голос для озвучення; якщо голос не вказано, використовується нативне усне мовлення.

Нижче наведено приклад структури запиту, замініть URL матеріалів перед викликом.

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "你的商品或口播内容"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## Результати та тарифікація

Синхронний режим повертає згенерований результат; асинхронний режим спочатку повертає `task_id`, а завершений результат містить посилання на відео або зображення в `data` та обчислений сервером `usage`. `callback_url` використовується для сповіщення про завершення; запит із `watermark=true` одночасно повертає версію з водяним знаком.

Нативне усне мовлення: 720p — 1.82 Credits/секунду, 1080p — 2.38 Credits/секунду; вказане озвучення: 720p — 2.38 Credits/секунду, 1080p — 2.8 Credits/секунду. Відео тарифікується за фактичною тривалістю генерації, базова ціна за секунду до генерації не означає загальну вартість усього завдання. За невдалі завдання плата за генерацію не стягується.
