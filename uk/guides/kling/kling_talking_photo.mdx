Одним кліком перетворіть **одну фотографію + один аудіозапис** на «відео, що говорить». Сервіс автоматично виконує два кроки всередині: спочатку використовує image2video, щоб оживити фотографію, потім використовує lip-sync для синхронізації рухів губ з аудіо. Вам потрібно зробити лише **один** виклик.

- **Адреса API**：`POST https://api.acedata.cloud/kling/talking-photo`
- **Тарифікація**：за тривалістю, 5 секунд **16.45 Credits**、10 секунд **30.45 Credits**(= об'єднана ціна image2video + lip-sync)

## Заголовки запиту

| Поле              | Значення                   |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## Параметри запиту

| Параметр             | Тип      | Обов'язковий  | За замовчуванням                  | Опис                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | Так   | —                   | Публічний URL фотографії людини, рекомендується чітке фото анфас                    |
| `audio_url`    | string  | Так   | —                   | Публічний URL аудіо для керування（.mp3/.wav/.m4a/.aac,≤5MB） |
| `prompt`       | string  | Ні   | —                   | Підказка щодо рухів/виразів обличчя на етапі анімації фотографії                      |
| `model`        | string  | Ні   | `kling-v2-1-master` | Модель Kling, що використовується для анімації фотографії                     |
| `duration`     | integer | Ні   | `5`                 | Тривалість відео（5 або 10 секунд）                        |
| `mode`         | string  | Ні   | `pro`               | Якість анімації（std/pro）                        |
| `callback_url` | string  | Ні   | —                   | Якщо передано або `async=true`, асинхронно повертається task_id        |
| `async`        | boolean | Ні   | `false`             | Асинхронний режим, використовується разом з опитуванням або зворотним викликом `/kling/tasks`          |

## Приклад запиту

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Приклад відповіді

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Поле                 | Опис                        |
| ------------------ | ------------------------- |
| `video_url`        | Фінальне відео, що говорить（вже збережене на CDN цієї платформи）      |
| `source_video_url` | Проміжне анімоване відео з фотографії（результат image2video） |
| `video_id`         | ID відео Kling                   |

## Примітки

- Для фотографії рекомендується чітке фото анфас з однією людиною.
- Рекомендована тривалість аудіо не повинна перевищувати тривалість відео（5 с/10 с）.
- Тарифікація відбувається після успішного виконання; за помилку перевірки параметрів（4xx）плата не стягується.
- Генерація займає приблизно 4–6 хвилин（два кроки), рекомендується використовувати `async=true` + опитування `/kling/tasks`.
