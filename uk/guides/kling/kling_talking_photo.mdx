---
title: "API для говорячих фотографій Kling (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Одним натисканням перетворіть **фото + аудіо** на «говоряче відео». Сервіс автоматично виконує два кроки: спочатку за допомогою image2video анімує фото, а потім за допомогою lip-sync синхронізує рухи губ з аудіо. Вам потрібно викликати **один раз**.

- **Адреса API**: `POST https://api.acedata.cloud/kling/talking-photo`
- **Оплата**: за тривалістю, 5 секунд **16.45 Credits**, 10 секунд **30.45 Credits** (= ціна за об'єднання image2video + lip-sync)

## Заголовки запиту

| Поле              | Значення               |
| ---------------- | --------------------- |
| `authorization`  | `Bearer ${API_KEY}`   |
| `content-type`   | `application/json`    |

## Параметри запиту

| Параметр         | Тип      | Обов'язковий | За замовчуванням       | Опис                                      |
| ---------------- | ------- | ------------ | --------------------- | ----------------------------------------- |
| `image_url`      | string  | Так          | —                     | Публічний URL фотографії персонажа, рекомендується чітке зображення обличчя |
| `audio_url`      | string  | Так          | —                     | Публічний URL аудіо (формати .mp3/.wav/.m4a/.aac, ≤5MB) |
| `prompt`         | string  | Ні           | —                     | Підказки для анімації фото на етапі анімації/емоцій |
| `model`          | string  | Ні           | `kling-v2-1-master`  | Модель Kling, що використовується для анімації фото |
| `duration`       | integer | Ні           | `5`                   | Тривалість відео (5 або 10 секунд)      |
| `mode`           | string  | Ні           | `pro`                 | Якість анімації (std/pro)               |
| `callback_url`   | string  | Ні           | —                     | Якщо передано або `async=true`, то асинхронно повертає task_id |
| `async`          | boolean | Ні           | `false`               | Асинхронний режим, разом з `/kling/tasks` для опитування або зворотного виклику |

## Приклад запиту

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Приклад відповіді

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Поле                 | Опис                          |
| ------------------- | ----------------------------- |
| `video_url`         | Остаточне говорюче відео (збережене на платформі CDN) |
| `source_video_url`  | Проміжне анімаційне відео (результат image2video) |
| `video_id`          | ID відео Kling                |

## Зверніть увагу

- Рекомендується, щоб фото було чітким, з обличчям, однією особою.
- Рекомендується, щоб тривалість аудіо не перевищувала тривалість відео (5с/10с).
- Оплата відбувається при успіху; перевірка параметрів, що не пройшла (4xx), не підлягає оплаті.
- Генерація займає приблизно 4–6 хвилин (два кроки), рекомендується використовувати `async=true` + `/kling/tasks` для опитування.
