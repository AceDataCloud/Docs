Надішліть завдання через `POST /kling/virtual-try-on`, використовуйте наявний `POST /kling/tasks` для перевірки статусу завдання на платформі.

## Вхідні дані

Необхідно надати рівно одне зображення product_image та одне зображення person_image. Значення за замовчуванням для keep_face, keep_pose, keep_background — true, їх можна вимкнути окремо. Найдовша сторона вхідного зображення не повинна перевищувати 2048px, найкоротша сторона має бути більшою за 300px, розмір файлу не повинен перевищувати 10MB.

Нижче наведено приклад структури запиту, замініть URL матеріалів перед викликом.

```json
{
  "contents": [
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "person_image",
      "url": "https://your-cdn.example/person.jpg"
    }
  ],
  "async": true
}
```

## Результати та тарифікація

Синхронний режим повертає результат генерації; асинхронний режим спочатку повертає `task_id`, а завершений результат містить посилання на відео або зображення в `data` та обчислений сервером `usage`. `callback_url` використовується для сповіщення про завершення; запит із `watermark=true` одночасно повертає версію з водяним знаком.

1.12 Credits/зображення, оплата здійснюється за фактичною кількістю вихідних зображень. Відео розраховується за фактичною тривалістю генерації, базова ціна за секунду до генерації не є загальною ціною всього завдання. За невдалі завдання плата за генерацію не стягується.
