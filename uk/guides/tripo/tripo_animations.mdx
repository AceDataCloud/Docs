---
title: "Анімація персонажів Tripo"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Викличте `POST /tripo/animations`, використовуючи `action` для вибору перевірки скелета, автоматичного прив’язування скелета або перенесення анімації. Передайте `async: true`, щоб опитувати `/tripo/tasks`, або `callback_url`, щоб отримати кінцевий результат.

1. **Перевірка**. Надішліть `{"action":"rig_check","model_id":"5db97adc-a877-4587-af16-bbf443aa55de"}`. Елемент результату містить булеве значення `riggable` і необов’язкове поле `rig_type`. Успішна перевірка з `riggable: false` означає, що ця модель не підходить для прив’язування скелета. Ця операція безкоштовна.
2. **Прив’язування**. Надішліть `{"action":"rig","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","model":"v3.0-20260909","rig_type":"biped","format":"GLB"}`. Результатом є нова модель зі скелетом; збережіть її `data[0].id`. Для перевірки та прив’язування також можна зчитати наявний файл через `model_url`.
3. **Перенесення**. Використайте ID результату прив’язування як `model_id`. Наприклад, `{"action":"retarget","model_id":"96a66a1d-69d2-48f0-846b-bdf02ed9bcc4","animations":["preset:walk","preset:idle"],"format":"GLB","async":true}`. Виберіть пресети, сумісні з версією та типом скелета; для одного передайте `animation`, для кількох — `animations`, не більше п’яти; оплата стягується за кількістю рухів. Пакетний запит може повернути один файл із кількома доріжками анімації.

Прив’язування та перенесення підтримують GLB і FBX. Використовуйте `export_with_geometry`, щоб керувати включенням геометрії до результату перенесення, а `animate_in_place` — щоб керувати збереженням переміщення. Адреса для завантаження файлу моделі міститься в `data[0].model_url`.
