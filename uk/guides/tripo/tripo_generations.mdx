---

Викличте `POST /tripo/generations`, щоб створити нову модель, передавши текст, одне зображення або кілька ракурсів одного об’єкта. Використовуйте AceDataCloud Token; за замовчуванням результат повертається синхронно. Якщо передати `async: true` або `callback_url`, спочатку повертаються HTTP 200 і `task_id`. Завершений зворотний виклик і синхронний результат мають однакову структуру JSON.

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

`action` за замовчуванням має значення `generate`. Виберіть один із трьох варіантів вводу: `prompt` (1–1024 символи), `image_url`, `image_urls`. Зображення мають бути загальнодоступними PNG/JPEG за HTTPS, розміром не більше 20 MiB. Кілька ракурсів розміщуються в порядку: спереду, ліворуч, ззаду, праворуч; необхідно надати вигляд спереду та принаймні ще один, а для пропуску проміжних ракурсів можна використовувати null.

`model` за замовчуванням має значення `v3.1-20260211`; також можна явно вибрати `v3.0-20250812`, `v2.5-20250123`, `P1-20260311` або `P2-20260801`. `texture` за замовчуванням має значення `standard`, для чистої геометрії використовуйте `none`. Різні моделі та рівні текстурування використовують різні квоти.

Завантажте GLB з `data[0].model_url`, `image_url` — необов’язкове попереднє зображення. Збережіть `data[0].id` для подальших операцій із текстурування, конвертації або роботи зі скелетом. Під час повторної спроби того самого запиту зберігайте той самий `Idempotency-Key` і тіло запиту.
