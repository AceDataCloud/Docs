---
title: "Обробка моделей Tripo"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Використовуйте `POST /tripo/models` для обробки наявної моделі, передавши потрібну `action`. Синхронний та асинхронний режими, зворотні виклики, належність обліковому запису та запити завдань такі самі, як для генерації 3D.

| action  | Вхідні дані | Результат |
| ------- | ----------- | --------- |
| import  | `model_url`, загальнодоступний файл GLB, GLTF, FBX, OBJ або STL через HTTPS, не більше 150 MiB | ID моделі, який можна використовувати надалі, і GLB; за наявності даних повертаються `normalize_scale` і `normalize_translation` |
| texture | `model_id` або `model_url`; за бажанням один із трьох параметрів: `prompt`, `image_url`, `image_urls` | Нова модель, текстура та необов’язковий попередній перегляд |
| convert | `model_id` або `model_url`, а також цільовий `format` | Перетворений файл моделі |

```json
{"action":"texture","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","prompt":"蓝色哑光表面","texture_quality":"standard","async":true}
```

Для якості текстур підтримуються `fast`, `standard`, `detailed`, `extreme`. При використанні текстової підказки можна додати `style_image_url`; зображення та багаторакурсні референси відповідають формату інтерфейсу генерації. Інші параметри текстур див. в OpenAPI.

Для перетворення підтримуються `GLTF`, `FBX`, `USDZ`, `OBJ`, `STL` і `3MF`. Поле `format` у поверненому елементі вказує фактичний формат результату; наприклад, у відповідь на запит GLTF може бути надано двійковий GLB. Для OBJ матеріали й текстури пакуються в ZIP. При запиті FBX задайте `texture_packaging: "zip"`, щоб отримати окремі текстури; у запакованому результаті буде вказано `container: "ZIP"`. Увімкнення нестандартних налаштувань сітки або текстур може тарифікуватися як розширене перетворення; докладніше див. у цінах сервісу.

Використовуйте `data[0].id` для посилання на модель цього облікового запису; перетворення нормалізації імпортованої моделі відповідає формулі `normalized = original × normalize_scale + normalize_translation`. Адреса завантаження моделі міститься в `data[0].model_url`.
