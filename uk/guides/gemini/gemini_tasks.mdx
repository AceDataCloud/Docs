Основна функція Gemini Tasks API полягає у запиті стану виконання завдання за допомогою ID завдання, згенерованого через Gemini Videos Generation API.

Цей документ детально описує інструкції з інтеграції Gemini Tasks API, щоб допомогти вам легко інтегрувати та перевіряти стан виконання завдань Gemini Videos Generation API.

## Процес подачі заявки

Щоб використовувати Gemini Tasks API, спочатку потрібно подати заявку на відповідний сервіс на сторінці [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos) та скопіювати ID завдання, який повертає Gemini Videos Generation API.

Потім перейдіть на сторінку [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) для подачі заявки на відповідний сервіс. Після входу на сторінку натисніть кнопку «Acquire».

Якщо ви ще не увійшли або не зареєстровані, вас автоматично перенаправить на [сторінку входу](https://platform.acedata.cloud) з пропозицією зареєструватися та увійти. Після входу або реєстрації ви автоматично повернетесь на поточну сторінку.

При першій подачі заявки надається безкоштовний ліміт, що дозволяє безкоштовно користуватися API.

## Приклад запиту

Gemini Tasks API можна використовувати для отримання результатів Gemini Videos Generation API.

### Налаштування заголовків запиту та тіла запиту

**Request Headers** включають:

- `accept`: вказує формат відповіді JSON, тут встановлено `application/json`.
- `authorization`: ключ доступу до API, який можна вибрати зі списку після подачі заявки.

**Request Body** включає:

- `id`: ID завдання, яке потрібно перевірити.
- `action`: тип операції з завданням, для одиночного запиту вказується `retrieve`.

### Приклад коду CURL

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Приклад відповіді

Після успішного запиту API поверне детальну інформацію про завдання. Поле `request` містить тіло запиту, з яким було створено завдання, а поле `response` — тіло відповіді після завершення завдання, наприклад:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
        "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Опис полів:

- `id`: ID створеного завдання, унікальний ідентифікатор цього завдання.
- `request`: інформація про запит, що був надісланий для створення завдання.
- `response`: інформація про відповідь після виконання завдання.

## Масовий запит

Для отримання інформації про кілька завдань одночасно встановіть `action` у значення `retrieve_batch` та передайте масив ID завдань через поле `ids`:

**Request Body** включає:

- `ids`: масив ID завдань для запиту.
- `action`: тип операції, для масового запиту вказується `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
