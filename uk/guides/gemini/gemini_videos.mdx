У цьому документі буде представлено інструкцію з інтеграції API генерації відео Gemini, який може генерувати відео Google Gemini (omni-flash) на основі введених текстових підказок (а також необов'язкових зображень для посилання).

## Процес подачі заявки

Щоб використовувати API генерації відео Gemini, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications), щоб отримати ваш API Token, зберігши його для подальшого використання.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, де вас запросять зареєструватися та увійти. Після завершення ви будете автоматично повернені на цю сторінку.

**Один API Token дозволяє викликати всі послуги платформи, не потрібно окремо подавати заявку на кожну послугу.** Перший запит на отримання токена надає безкоштовний ліміт, щоб ви могли безкоштовно протестувати; якщо ліміт вичерпано, ви можете поповнити загальний баланс у [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [API генерації відео Gemini →](https://platform.acedata.cloud/documents/gemini-videos)

## Основне використання

Спочатку ознайомтеся з основними способами використання, введіть підказку `prompt`, модель `model` та співвідношення сторін `aspect_ratio`, щоб згенерувати відповідне відео.

Ми налаштували заголовки запиту, які включають:

- `accept`: формат відповіді, який ви хочете отримати, тут вказано `application/json`, тобто формат JSON.
- `authorization`: ключ для виклику API, після подачі заявки ви можете вибрати його зі списку.

Також налаштовано тіло запиту, яке включає:

- `prompt`: текстова підказка, що описує вміст відео, **обов'язково**.
- `model`: модель для генерації відео, наразі підтримується лише `omni-flash`, за замовчуванням це `omni-flash`.
- `aspect_ratio`: співвідношення сторін для згенерованого відео, можна вибрати `16:9` (горизонтальне) або `9:16` (вертикальне), за замовчуванням `16:9`.
- `resolution`: необов'язкове вихідне розділення, можна вибрати `720p` або `1080p`, за замовчуванням `720p`.
- `image_urls`: масив посилань на зображення для посилання, що використовується для направлення генерації відео, порожні поля будуть проігноровані. Коли ви використовуєте `video_urls` для редагування відео, цей параметр є обов'язковим (принаймні одне зображення).
- `video_urls`: масив посилань на відео для посилання (максимум 1), використовується для **редагування відео / відео посилання**; якщо надається, потрібно одночасно надати принаймні одне `image_urls`.
- `callback_url`: адреса асинхронного зворотного виклику, після налаштування API негайно поверне `task_id`, а після завершення завдання надішле результати на цю адресу.
- `async`: необов'язковий, якщо встановити в `true`, інтерфейс негайно поверне `task_id`, не потрібно надавати `callback_url`, потім через відповідний інтерфейс запиту завдань можна опитувати результати.

Натисніть кнопку «Спробувати», щоб провести тестування, отримані результати будуть схожі на такі:

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://platform2.cdn.acedata.cloud/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "Кінематографічний кадр кошеняти, що переслідує метелика в сонячному саду"
    }
  ],
  "started_at": 1784112953.856,
  "finished_at": 1784113021.328,
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

У відповіді є кілька полів, описаних нижче:

- `success`: чи успішно виконано запит на генерацію відео.
- `task_id`: ID завдання на генерацію відео.
- `trace_id`: ID відстеження запиту, використовується для усунення неполадок.
- `data`: список результатів згенерованого відео.
  - `id`: унікальний ідентифікатор згенерованого відео.
  - `video_url`: посилання на згенероване відео (`state` дорівнює `pending`, то буде `null`).
  - `state`: стан завдання на генерацію відео, можливі значення `pending` / `succeeded` / `failed`.
  - `aspect_ratio`: співвідношення сторін цього відео, яке відповідає параметрам запиту.
  - `prompt`: підказка, що використовувалася для генерації цього відео.

При синхронному поверненні на верхньому рівні також будуть додані поля `started_at`, `finished_at`, `elapsed` (час, секунди) та `cost` (витрати за цю операцію, одиниця Credit).

Нам потрібно лише отримати згенероване відео за посиланням `video_url` у результаті `data`.

Відповідний код CURL виглядає так:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Кінематографічний кадр кошеняти, що переслідує метелика в сонячному саду",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Відповідний код Python виглядає так:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "Кінематографічний кадр кошеняти, що переслідує метелика в сонячному саду",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Генерація відео на основі зображень

Якщо ви хочете згенерувати відео на основі зображень, ви можете передати одне або кілька посилань на зображення в `image_urls`, щоб направити генерацію відео:

```json
{
  "prompt": "Жінка повільно обертається і усміхається в камеру, легкий вітерець",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3.png"
  ]
}
```

## Редагування відео / відео для посилання (вхідне відео, генерація відео)

Підтримується безпосереднє «введення відео, генерація нового відео»: передайте посилання на відео для посилання в `video_urls` (максимум 1), і **одночасно** надайте принаймні одне посилання на зображення в `image_urls` (жорстка вимога з боку постачальника), а потім використовуйте `prompt`, щоб описати бажаний ефект редагування (зміна стилю, зміна сцени, додавання/видалення елементів тощо).

Ось повний реальний приклад — змінити відео з сонячного пляжу на зимову сцену з снігом, зберігши при цьому розташування пляжу, пальм і човнів. Редагування відео займає більше часу (в цьому прикладі близько 6,5 хвилин), тому використовується асинхронна подача з `async: true`:
```json
{
  "prompt": "Перетворіть цей сонячний тропічний пляж на снігову зимову сцену з сильним снігопадом і похмурим небом; збережіть той самий пляж, пальми та розташування човнів.",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://platform2.cdn.acedata.cloud/seedance/dd3dc063-3383-4f29-bedc-e771a096758c.mp4"
  ],
  "async": true
}
```

Після подання запиту інтерфейс негайно повертає `task_id`:

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

Потім використовуйте цей `task_id` як `id` для опитування [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks), після завершення завдання ви зможете отримати згенероване нове відео (це реальний результат цього прикладу):

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://platform2.cdn.acedata.cloud/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "Перетворіть цей сонячний тропічний пляж на снігову зимову сцену з сильним снігопадом і похмурим небом; збережіть той самий пляж, пальми та розташування човнів."
    }
  ],
  "started_at": 1784084482.914,
  "finished_at": 1784084877.09,
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Якщо потрібно отримати більш якісний результат, можна встановити `resolution` на `1080p` (інші параметри залишити без змін).

> Підказка: медіа-посилання, наведені в прикладі, є реальними згенерованими результатами. **Посилання на відео та зображення, згенеровані платформою, мають термін зберігання, після закінчення якого вони стануть недоступними**, будь ласка, завантажте їх своєчасно після отримання результату.

> Увага: максимальна кількість посилань на відео - 1; і при наданні `video_urls` необхідно надати принаймні одне `image_urls`, в іншому випадку буде повернено таку помилку:

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (принаймні одне зображення) є обов'язковим, коли надано video_urls."
  }
}
```

## Асинхронний зворотний виклик

Генерація відео потребує певного часу на обробку. Якщо ви не хочете підтримувати довге з'єднання, ви можете передати `callback_url`, у цьому випадку API негайно поверне `task_id`, а після завершення завдання надішле остаточний результат на цю адресу:

```json
{
  "prompt": "Кінематографічний кадр кошеняти, що переслідує метелика в сонячному саду",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Негайно повернене значення виглядає так:

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## Запит результатів завдання

Якщо ви використовували асинхронний зворотний виклик або хочете активно перевірити статус завдання, ви можете скористатися [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) для перевірки останнього статусу та результату завдання за `task_id`:

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

Після завершення завдання повернене значення виглядає приблизно так, структура `response.data` така ж, як і під час синхронної генерації (під час генерації `state` буде `pending`, а `video_url` - `null`):

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
  "type": "videos",
  "request": {
    "model": "omni-flash",
    "prompt": "Часова зйомка хмар над сніговими горами на світанку",
    "aspect_ratio": "16:9",
    "async": true
  },
  "response": {
    "success": true,
    "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
    "data": [
      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
        "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4",
        "state": "succeeded",
        "aspect_ratio": "16:9",
        "prompt": "Часова зйомка хмар над сніговими горами на світанку"
      }
    ],
    "elapsed": 96.716,
    "cost": {
      "amount": 1.932,
      "currency": "credit",
      "list_amount": 2.1
    }
  }
}
```

## Обробка помилок

Коли запит має проблеми, API повертає відповідний код помилки та опис, найбільш поширені з них:

- `400`: помилка параметрів запиту, наприклад, відсутній `prompt` або `aspect_ratio` має недійсне значення.
- `401`: помилка авторизації, токен недійсний або не відповідає API.
- `403`: недостатньо коштів, або підказка потрапила під вміст, що підлягає перевірці.
- `500`: внутрішня помилка сервера або збій генерації на стороні постачальника.
