У цьому документі буде представлено інструкцію з інтеграції API генерації відео Gemini, який може генерувати відео Google Gemini (omni-flash) на основі введених текстових підказок (а також необов'язкових референсних зображень).

## Процес подачі заявки

Щоб використовувати API генерації відео Gemini, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications), щоб отримати ваш API Token, зберігши його для подальшого використання.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, щоб запросити реєстрацію та вхід, після чого ви будете автоматично повернені на цю сторінку.

**Один API Token дозволяє викликати всі послуги платформи, не потрібно окремо подавати заявку на кожну послугу.** Перший запит на отримання токена надає безкоштовний ліміт, щоб ви могли безкоштовно протестувати; якщо ліміт вичерпано, ви можете поповнити загальний баланс в [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [API генерації відео Gemini →](https://platform.acedata.cloud/documents/gemini-videos)

## Основне використання

Спочатку ознайомтеся з основними способами використання, введіть підказку `prompt`, модель `model` та співвідношення сторін `aspect_ratio`, щоб згенерувати відповідне відео.

Ми налаштували заголовки запиту, які включають:

- `accept`: формат відповіді, який ви хочете отримати, тут вказано `application/json`, тобто формат JSON.
- `authorization`: ключ для виклику API, після подачі заявки ви можете вибрати його зі списку.

Також налаштовано тіло запиту, яке включає:

- `prompt`: текстова підказка, що описує вміст відео, **обов'язково**.
- `model`: модель для генерації відео, наразі підтримується лише `omni-flash`, за замовчуванням це `omni-flash`.
- `aspect_ratio`: співвідношення сторін для згенерованого відео, можна вибрати `16:9` (горизонтальне) або `9:16` (вертикальне), за замовчуванням `16:9`.
- `resolution`: необов'язкове вихідне розділення, можна вибрати `720p` або `1080p`, за замовчуванням `720p`.
- `image_urls`: масив посилань на референсні зображення, які використовуються для направлення генерації відео, порожні поля будуть проігноровані. Коли ви використовуєте `video_urls` для редагування відео, цей параметр є обов'язковим (принаймні одне зображення).
- `video_urls`: масив посилань на референсні відео (максимум 1), для **редагування відео / відео посилання**; якщо надається, потрібно також надати принаймні одне `image_urls`.
- `callback_url`: адреса асинхронного зворотного виклику, після налаштування API негайно поверне `task_id`, а після завершення завдання надішле результати на цю адресу.
- `async`: необов'язковий, якщо встановити в `true`, інтерфейс негайно поверне `task_id`, не потрібно надавати `callback_url`, потім через відповідний інтерфейс запиту завдань можна опитувати результати.

Натисніть кнопку «Спробувати», щоб провести тестування, отримані результати будуть схожі на такі:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Повернуті результати містять кілька полів, описаних нижче:

- `success`: чи успішно виконано запит на генерацію відео.
- `task_id`: ID завдання на генерацію відео.
- `trace_id`: ID відстеження запиту, використовується для усунення проблем.
- `data`: список результатів згенерованого відео.
  - `id`: унікальний ідентифікатор згенерованого відео.
  - `video_url`: URL-адреса згенерованого відео.
  - `state`: стан завдання на генерацію відео, можливі значення `pending` / `succeeded` / `failed`.

Нам потрібно лише отримати згенероване відео за URL-адресою `video_url` з результату `data`.

Відповідний код CURL виглядає так:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Відповідний код Python виглядає так:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Генерація відео на основі зображень

Якщо ви хочете згенерувати відео на основі референсних зображень, ви можете передати одне або кілька посилань на зображення в `image_urls`, щоб направити генерацію відео:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## Редагування відео / референсне відео

Підтримується безпосереднє редагування існуючого відео або використання його як референс: передайте посилання на референсне відео в `video_urls` (максимум 1), і **одночасно** надайте принаймні одне референсне зображення в `image_urls` (жорстка вимога). Ви можете описати бажаний ефект редагування за допомогою `prompt` (зміна стилю, зміна сцени, додавання/видалення елементів тощо):

```json
{
  "prompt": "Restyle the video into cinematic anime, keep the motion",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ],
  "video_urls": [
    "https://cdn.acedata.cloud/example-source.mp4"
  ]
}
```

> Зверніть увагу: максимальна кількість референсних відео - 1; і при наданні `video_urls` потрібно надати принаймні одне `image_urls` (в іншому випадку буде повернено помилку параметра).

## Асинхронний зворотний виклик

Генерація відео потребує певного часу на обробку. Якщо ви не хочете підтримувати довге з'єднання в очікуванні, ви можете передати `callback_url`, у цьому випадку API негайно поверне `task_id`, а після завершення завдання надішле остаточні результати на цю адресу:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Негайно повернуті результати виглядають так:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Запит результатів завдання

Якщо ви використовували асинхронний зворотний виклик або хочете активно перевірити статус завдання, ви можете використовувати [API завдань Gemini](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) для перевірки останнього статусу та результатів завдання за `task_id`.

## Обробка помилок

Коли запит викликає проблеми, API поверне відповідний код помилки та опис, найбільш поширені наведені нижче:
- `400`：Параметри запиту некоректні, наприклад, відсутній `prompt` або значення `aspect_ratio` є недійсним.
- `401`：Не вдалося пройти аутентифікацію, токен недійсний або не відповідає API.
- `403`：Недостатньо коштів, або підказка потрапила під вмістовий контроль і була відхилена.
- `500`：Внутрішня помилка сервера або невдала генерація з боку сервера.
