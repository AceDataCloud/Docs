У цій статті буде описано інструкцію з інтеграції Gemini Videos Generation API, який дозволяє генерувати відео Google Gemini (omni-flash) за допомогою текстових підказок (та опціонально референсних зображень).

## Процес подачі заявки

Щоб використовувати API, спочатку потрібно подати заявку на відповідну послугу на сторінці [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos). Після переходу на сторінку натисніть кнопку «Acquire», як показано на зображенні:

![](https://cdn.acedata.cloud/q6ytrc.png)

Якщо ви ще не увійшли або не зареєстровані, вас автоматично перенаправить на сторінку входу, де можна зареєструватися та увійти. Після входу ви повернетесь на поточну сторінку.

При першій подачі заявки надається безкоштовний ліміт для використання API.

## Основне використання

Спочатку ознайомтеся з базовим способом використання: введіть текстову підказку `prompt`, модель `model` та співвідношення сторін `aspect_ratio`, щоб згенерувати відповідне відео.

Тут ми встановлюємо заголовки запиту (Request Headers), зокрема:

- `accept`: формат відповіді, який ви хочете отримати, тут вказано `application/json` (формат JSON).
- `authorization`: ключ для виклику API, який можна вибрати зі списку після подачі заявки.

Також встановлюється тіло запиту (Request Body), яке містить:

- `prompt`: текстова підказка, що описує бажаний контент відео, **обов’язковий параметр**.
- `model`: модель для генерації відео, наразі підтримується лише `omni-flash`, за замовчуванням `omni-flash`.
- `aspect_ratio`: співвідношення сторін відео, можна вибрати `16:9` (горизонтальне) або `9:16` (вертикальне), за замовчуванням `16:9`.
- `image_urls`: опціональний масив посилань на референсні зображення (або відео), які використовуються для керування генерацією відео; порожні елементи ігноруються.
- `callback_url`: URL для асинхронного зворотного виклику; якщо заданий, API негайно поверне `task_id`, а після завершення завдання на цей URL буде надіслано POST із результатом.

Натисніть кнопку «Try» для тестування, результат буде схожий на наступний:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

У відповіді є кілька полів, які описані нижче:

- `success`: чи був успішним запит на генерацію відео.
- `task_id`: ідентифікатор завдання генерації відео.
- `trace_id`: ідентифікатор трасування запиту для відлагодження.
- `data`: список результатів згенерованих відео.
  - `id`: унікальний ідентифікатор згенерованого відео.
  - `video_url`: URL згенерованого відео.
  - `state`: стан завдання генерації відео, можливі значення `pending` / `succeeded` / `failed`.

Нам потрібно лише отримати відео за посиланням `video_url` у полі `data`.

Відповідний код CURL:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Відповідний код на Python:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Генерація відео на основі зображень

Якщо ви хочете згенерувати відео на основі референсних зображень, передайте один або кілька URL зображень у `image_urls` для керування генерацією відео:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## Асинхронний зворотний виклик

Генерація відео потребує певного часу. Якщо ви не хочете утримувати з’єднання відкритим, можна передати `callback_url`. У цьому випадку API негайно поверне `task_id`, а після завершення завдання на цей URL буде надіслано POST із результатом:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Негайна відповідь матиме вигляд:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Перевірка результатів завдання

Якщо ви використовували асинхронний зворотний виклик або хочете самостійно перевірити статус завдання, можна звернутися до [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) з параметром `task_id` для отримання актуального статусу та результатів.

## Обробка помилок

Якщо запит викликає помилку, API поверне відповідний код помилки та опис. Найпоширеніші:

- `400`: некоректні параметри запиту, наприклад, відсутній `prompt` або неправильне значення `aspect_ratio`.
- `401`: помилка аутентифікації, недійсний токен або невідповідність API.
- `403`: недостатньо коштів або підказка відхилена через модерацію контенту.
- `500`: внутрішня помилка сервера або помилка генерації на стороні сервера.
