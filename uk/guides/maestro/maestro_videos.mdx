Maestro — це **Agent рідний** відео виробничий інтерфейс: ви описуєте бажане відео однією природною мовою `prompt` (за бажанням можна додати `file_urls` з посиланнями на зображення / відео / аудіо), безголовний «AI режисер» автоматично виконає вибір теми, напише сценарій, згенерує зображення, озвучить, підбере музику, зкомпонує та відрендерить, в результаті чого буде створено готове відео з субтитрами, яке буде завантажено на CDN.

У цій статті буде детально описано інтеграцію Maestro відео генерації API, щоб допомогти вам швидко інтегрувати та повністю використовувати можливості цього API.

Це **асинхронний завдання** інтерфейс: після подачі буде негайно повернуто `task_id`, після чого через [Maestro завдання запит API](development_maestro_tasks.md) (`POST /maestro/tasks`) можна опитувати результати (опитування безкоштовне). Щоб продовжити ітерацію на вже існуючому відео, можна використовувати `action: remix` / `edit` / `extend` разом з `ref_task_id`.

## Основне використання

`POST https://api.acedata.cloud/maestro/videos`

Найбазовіший спосіб використання вимагає лише передачі одного природного мовного `prompt`, AI режисер автоматично вирішить сценарій, зображення, озвучення та монтаж. Тут ми спочатку розглянемо заголовки запиту та тіло запиту, які потрібно налаштувати.

**Request Headers** включають:

- `accept`: бажаний формат відповіді, тут вказується `application/json`, тобто формат JSON.
- `authorization`: ключ для виклику API, після подачі заявки можна вибрати з випадаючого списку.
- `content-type`: формат тіла запиту, тут вказується `application/json`.

**Request Body** в основному включає:

- `prompt`: описуєте відео природною мовою (тема, що показати, стиль, аудиторія).
- `langs`: масив мов виводу, наприклад, `["zh-cn", "en"]`, за замовчуванням `["zh-cn"]`.
- `aspect`: співвідношення сторін, `9:16` (за замовчуванням) / `16:9` / `1:1`.
- `duration`: цільова тривалість (секунди), за замовчуванням 30.

Усі поля тіла запиту наведені в таблиці нижче:

| Поле            | Тип       | Обов'язкове  | Опис                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Так   | Описуєте відео природною мовою (тема, що показати, стиль, аудиторія). Сценарій, зображення, озвучення, монтаж визначає AI                                                                                                                                                                             |
| `action`      | string   | Ні   | `generate` (за замовчуванням, створити нове відео) / `remix` / `edit` / `extend` (ітерація на вже існуючому відео, потрібно разом з `ref_task_id`)                                                                                                                                                |
| `ref_task_id` | string   | Ні   | Обов'язкове, коли `action` є remix / edit / extend: історичний `task_id`, з якого почати                                                                                                                                                                   |
| `file_urls`   | string[] | Ні   | Посилання на медіа (зображення / відео / аудіо URL), наприклад, зображення продукту, логотип або фрагменти матеріалів, до яких потрібно додати субтитри                                                                                                                                                                             |
| `langs`       | string[] | Ні   | Мови виводу, наприклад, `["zh-cn", "en"]`, за замовчуванням `["zh-cn"]`. Перша мова є основною; за кожну додаткову мову повторюється зображення, лише додається озвучення + рендеринг, **за кожну додаткову +6 балів**                                                                                                                                          |
| `aspect`      | string   | Ні   | `9:16` (за замовчуванням) / `16:9` / `1:1` (підказка щодо співвідношення сторін, AI може налаштувати відповідно до prompt)                                                                                                                                                                         |
| `duration`    | int      | Ні   | Цільова тривалість (секунди, **1–600**, тобто максимум 10 хвилин), за замовчуванням 30. **Оплата за фактичну тривалість готового відео**, чим довше, тим дорожче (див. нижче про оплату)                                                                                                                                                                  |
| `quality`     | string   | Ні   | Рівень виробництва (множник на ціну за тривалість): `draft` (швидкий перегляд, приблизно **0.5×** стандартного) / `standard` (за замовчуванням, збалансований, **1×**) / `premium` (більш детальний, витрачає більше часу, приблизно **2×** стандартного)                                                                                                             |
| `scenario`    | string   | Ні   | Підказка типу відео (лише підказка, AI режисер все ще вирішує остаточну структуру): `auto` (за замовчуванням) / `narrated` (багато сцен реальних фотографій + озвучення + картки даних) / `drama` (персонажі + діалоги короткої п'єси) / `avatar` (цифрова людина / озвучення, потрібно передати зображення через `file_urls`) / `motion` (абстрактні динамічні субтитри / дані / анімація логотипу) / `slideshow` (презентація / демонстраційна колода)                               |
| `style`       | string   | Ні   | Пресет візуального стилю: `auto` (за замовчуванням) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`, також приймає вільний текст як м'яка підказка. Не змінює маршрут, не змінює структуру |
| `voice`       | string   | Ні   | Тон озвучення (незалежно від мови, універсальний для всіх мов): `auto` (за замовчуванням) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`                                    |

Нижче наведено конкретний приклад. Припустимо, ми хочемо створити двомовне (китайською та англійською), вертикальне, 20-секундне науково-популярне відео, відповідний код CURL виглядає так:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "За 20 секунд пояснити, що таке векторна база даних, підходить для глядачів без підготовки, в кінці дати запам'ятовувальну фразу",
  "langs": ["zh-cn", "en"],
  "aspect": "9:16",
  "duration": 20
}'
```

Відповідний код на Python виглядає так:
```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "За 20 секунд поясніть, що таке векторна база даних, підходить для глядачів без базових знань, в кінці дайте одну запам'ятовувальну фразу",
    "langs": ["zh-cn", "en"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Натиснувши «Запустити», ви можете відразу отримати результат, як показано нижче:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Опис полів у повернутому результаті:

- `success`：Чи успішно було подано завдання.
- `task_id`：ID завдання на створення відео, який буде використано для опитування результатів через [API запиту завдань Maestro](development_maestro_tasks.md).
- `trace_id`：ID відстеження цього запиту, який можна надати технічній підтримці для локалізації проблем.

Оскільки виробництво відео займає багато часу, API тут **відразу повертає `task_id`**, і не чекає завершення рендерингу відео. Далі потрібно використовувати `task_id` для опитування результатів, див. розділ «Отримати результати».

## Визначення типу та стилю відео (сценарій / стиль)

Якщо не передати `scenario`, AI автоматично визначить (еквівалентно `auto`); якщо ви хочете закріпити відео за певним типом, передайте його явно. Наприклад, для створення **вертикальної короткометражки** можна вказати такі дані:

- `scenario`：Тип відео, тут встановлено `drama` (короткометражка з персонажами + діалогами).
- `style`：Візуальний стиль, тут встановлено `cinematic` (кінематографічна якість).

Приклад CURL коду виглядає так:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Два сусіди по кімнаті посварилися через кота, але потім помирилися, три акти з поворотами, закінчення тепле",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Звичні комбінації:

- Короткометражка: `scenario: "drama"` (персонажі + діалоги).
- Цифрова людина / озвучка: `scenario: "avatar"`, і передайте `file_urls` з зображенням людини.
- Динамічні субтитри / анімація даних: `scenario: "motion"`; демонстрація / презентація: `scenario: "slideshow"`.
- `style` - це попередньо визначений візуальний стиль (наприклад, `modern` / `neon` / `luxury`), не змінює тип, лише впливає на сприйняття.
- `voice` використовується для визначення тону озвучки (наприклад, `warm-female` / `deep-male`), не залежить від мови, універсально для всіх мов.

Повернутий результат такий же, як і в «Основному використанні», також відразу повертає `task_id`.

## Багатомовний вихід

Передавши кілька мов у `langs`, ви можете одночасно отримати багатомовні версії. Перша мова є основною, а кожна наступна мова буде **використовувати ту ж саму картину**, лише додатково озвучуючи + рендеруючи, тому **кожна додаткова мова лише +6 балів**. Приклад:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Представте наш продукт інтелектуального обслуговування клієнтів, підкресліть 3 основні переваги",
  "langs": ["zh-cn", "en", "ja"],
  "aspect": "16:9",
  "duration": 30
}'
```

Після завершення завдання кожна мова відповідатиме одному `variant` у результаті (див. [API запиту завдань Maestro](development_maestro_tasks.md)).

## Ітерація на основі вже існуючого відео (ремікс / редагування / розширення)

Передайте `action` та `ref_task_id` попереднього завдання, щоб внести диференційні зміни на основі оригінального проекту (наприклад, «змінити заголовок 2 акту» «змінити озвучку» «загалом затемнити»). Невеликі зміни виконуються швидко, великі зміни потребують повторної роботи:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "Змінити заголовок на початку на більш вражаючу фразу, загальний колір більш темний"
}'
```

- `remix`：Переробка на основі структури оригінального відео (збереження теми, коригування виконання).
- `edit`：Тонке редагування конкретної частини (наприклад, зміна заголовка, зміна озвучки, корекція кольору).
- `extend`：Розширення змісту на основі оригінального відео.

Повернутий результат також відразу повертає новий `task_id`, за яким можна опитувати, щоб отримати готовий продукт.

## Отримати результати

Оскільки виробництво відео займає багато часу, цей API відразу повертає `task_id` після подачі, вам потрібно використовувати його для опитування результатів через [API запиту завдань Maestro](development_maestro_tasks.md):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Коли завдання завершено, буде повернута інформація про готовий продукт (кожна мова відповідатиме одному `variant`). `status` пройде через `pending → planning → producing → succeeded` (або `failed`), **опитування безкоштовне, не витрачає бали**. Повний формат відповіді та історію запитів дивіться в [інструкції з інтеграції API запиту завдань Maestro](development_maestro_tasks.md).

## Оплата

**Оплата здійснюється за фактичний готовий продукт після завершення завдання, невдалі завдання не підлягають оплаті.** Оплата базується на фактичній тривалості готового продукту та кількості мов, які були фактично вироблені — наприклад, якщо запитано 600 секунд, але в результаті отримано 50 секунд, оплата буде лише за приблизно 50 секунд; якщо якась мова в результаті не була вироблена, також не буде стягнуто +6 за цю мову. Подання завдання само по собі не підлягає окремій оплаті (результати можна безкоштовно опитувати через `/maestro/tasks`).

Бали за один готовий продукт приблизно оцінюються за формулою:

```
бали ≈ 0.85 × тривалість готового продукту в секундах × коефіцієнт якості × коефіцієнт сцени + 6 × max(кількість мов − 1, 0)
```

- Коефіцієнт якості: `draft` 0.5× / `standard` 1× (за замовчуванням) / `premium` 2×.
- Коефіцієнт сцени: `drama` 1.35× / `avatar` 1.15× / інші 1×.

Наприклад, для стандартного рівня, не короткометражки / цифрової людини, однієї мови, бали за різну тривалість готового продукту приблизно такі:
| Тривалість відео                  | Стандартні бали |
| --------------------------- | ----- |
| 30с                         | 25.5  |
| 60с                         | 51    |
| 120с (2 хвилини)                  | 102   |
| 300с (5 хвилин)                  | 255   |
| 600с (10 хвилин, максимум)              | 510   |
| За кожну додаткову мову (`langs` більше 1) | +6    |
| Опитування `/maestro/tasks`         | Безкоштовно    |

## Обробка помилок

При виклику API, якщо виникає помилка, API повертає відповідний код помилки та інформацію. Наприклад:

- `400 invalid_request`：Неправильний запит, можливо, через відсутній `prompt` або недійсні параметри.
- `401 invalid_token`：Неавторизовано, недійсний або відсутній токен авторизації.
- `403 forbidden`：Заборонено, недостатньо коштів або доступу.
- `429 too_many_requests`：Занадто багато запитів, ви перевищили ліміт запитів.
- `500 api_error`：Внутрішня помилка сервера, щось пішло не так на сервері.

### Приклад відповіді на помилку

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
