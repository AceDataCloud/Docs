Maestro — це **Agent-нативний** інтерфейс для створення відео: ви одним природномовним `prompt` описуєте бажане відео (за потреби додаєте референсні зображення / відео / аудіо через `file_urls`), а безголовий «AI-режисер» автоматично виконає вибір теми, написання сценарію, генерацію зображень, озвучення, підбір музики, композитинг і рендеринг, зрештою створивши готове відео із субтитрами та завантаживши його на CDN.

У цій статті буде детально представлено інструкцію з інтеграції API генерації відео Maestro, що допоможе вам швидко інтегруватися та повною мірою використати можливості цього API.

Це інтерфейс **асинхронних завдань**: після надсилання буде негайно повернуто `task_id`, а потім результат можна отримати шляхом опитування через [API запиту завдань Maestro](/uk/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (опитування безкоштовне та не тарифікується). Щоб продовжити ітерації над наявним відео, можна використати `action: remix` / `edit` / `extend` разом із `ref_task_id`.

## Процес подання заявки

Щоб використовувати API генерації відео Maestro, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications), щоб отримати свій API Token і зберегти його для подальшого використання.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не ввійшли або не зареєструвалися, вас буде автоматично перенаправлено на сторінку входу із запрошенням зареєструватися та ввійти, а після завершення вас буде автоматично повернуто на поточну сторінку.

**Один API Token може викликати всі сервіси платформи, немає потреби окремо подавати заявку для кожного сервісу.** Під час першого отримання буде надано безкоштовний ліміт, яким можна скористатися для безкоштовного тестування; якщо ліміту недостатньо, можна поповнити загальний баланс у [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [API генерації відео Maestro →](https://platform.acedata.cloud/documents/maestro-videos)

## Базове використання

`POST https://api.acedata.cloud/maestro/videos`

Для найпростішого використання достатньо передати один природномовний `prompt`, а AI-режисер автоматично визначить сценарій, зображення, озвучення та монтаж. Тут ми спочатку ознайомимося з заголовками запиту й тілом запиту, які потрібно налаштувати.

**Request Headers** включають:

- `accept`：у якому форматі ви хочете отримати результат відповіді, тут слід вказати `application/json`, тобто формат JSON.
- `authorization`：ключ для виклику API, після отримання заявки його можна безпосередньо вибрати зі спадного списку.
- `content-type`：формат тіла запиту, тут слід вказати `application/json`.

**Request Body** переважно включає:

- `prompt`：опишіть природною мовою відео, яке потрібно створити (тема, що показати, стиль, аудиторія).
- `langs`：масив мов готового відео, щоразу передається лише одна, наприклад `["zh-cn"]`, за замовчуванням `["zh-cn"]`.
- `aspect`：співвідношення сторін, `9:16` (за замовчуванням) / `16:9` / `1:1`.
- `duration`：цільова тривалість (секунди), за замовчуванням 30.

Усі поля тіла запиту наведено в таблиці нижче:

| Поле            | Тип       | Обов’язкове  | Опис                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Так   | Опишіть природною мовою відео, яке потрібно створити (тема, що показати, стиль, аудиторія). Сценарій, зображення, озвучення та монтаж визначає AI                                                                                                                                                                             |
| `action`      | string   | Ні   | `generate` (за замовчуванням, створення нового відео) / `remix` / `edit` / `extend` (ітерація над наявним відео, потрібно використовувати разом із `ref_task_id`)                                                                                                                                                |
| `ref_task_id` | string   | Ні   | Обов’язкове, коли `action` має значення remix / edit / extend: `task_id` історичного завдання, що використовується як початкова точка                                                                                                                                                                   |
| `file_urls`   | string[] | Ні   | Референсні медіафайли (URL зображень / відео / аудіо), наприклад зображення продукту або logo, які мають з’явитися в кадрі, або фрагменти матеріалу, до яких потрібно додати субтитри                                                                                                                                                                             |
| `langs`       | string[] | Ні   | Мова готового відео, щоразу можна передати лише одну, наприклад `["zh-cn"]`, за замовчуванням `["zh-cn"]`                                                                                                                                                                                    |
| `aspect`      | string   | Ні   | `9:16` (за замовчуванням) / `16:9` / `1:1`, уніфікований вихід 1080p/30fps                                                                                                                                                                                  |
| `duration`    | int      | Ні   | Цільова тривалість (секунди), за замовчуванням 30, підтримується **5–300 секунд**. Тарифікація здійснюється за фактичною тривалістю готового відео, але вона не перевищуватиме запитувану тривалість                                                                                                                                                                             |
| `scenario`    | string   | Ні   | Тип відео: `auto` / `narrated` / `captions` / `avatar` / `drama`. Для `captions` потрібно передати вихідне відео, для `avatar` потрібно передати портрет                                                                                                                                    |
| `style`       | string   | Ні   | Пресет візуального стилю: `auto` (за замовчуванням) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`, також приймається довільний текст як м’яка підказка. Ортогональний до `scenario`, не змінює маршрутизацію |
| `voice`       | string   | Ні   | Тембр голосу для закадрового тексту (незалежний від мови, універсальний для різних мов): `auto` (за замовчуванням) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`                                    |

Нижче продемонстровано на конкретному прикладі. Припустімо, що ми хочемо згенерувати китайське вертикальне 20-секундне коротке науково-популярне відео, відповідний CURL-код має такий вигляд:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

Відповідний Python-код має такий вигляд:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Натиснувши запуск, можна побачити, що буде негайно отримано результат, як показано нижче:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Опис полів результату відповіді наведено нижче:
- `success`：чи було це завдання успішно подано.
- `task_id`：ID цього завдання з генерації відео, надалі використовуйте його для опитування результату через [API запиту завдань Maestro](/uk/guides/maestro/maestro_tasks).
- `trace_id`：ID відстеження цього запиту, у разі виникнення проблем його можна надати технічній підтримці для локалізації.

Оскільки створення відео займає тривалий час, інтерфейс **негайно повертає `task_id`** і не чекатиме завершення рендерингу відео. Далі потрібно використовувати `task_id` для опитування результату, детальніше дивіться в розділі «Отримання результату».

## Вказання типу та стилю відео (scenario / style)

Якщо `scenario` не передається, AI визначає його автоматично (еквівалентно `auto`); якщо ви хочете прив’язати відео до певного типу, передайте його явно. Наприклад, для створення **вертикальної короткої драми** можна вказати таке:

- `scenario`：тип відео, тут встановлено `drama` (коротка драма з персонажами + діалогами).
- `style`：візуальний стиль, тут встановлено `cinematic` (кінематографічна якість).

CURL-код прикладу заповнення наведено нижче:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Поширені способи поєднання:

- Відео з озвученням: `scenario: "narrated"`.
- Автоматичні субтитри: `scenario: "captions"`, потрібно передати вихідне відео через `file_urls`.
- Цифрова людина / мовлення в кадрі: `scenario: "avatar"`, потрібно передати одне портретне зображення через `file_urls`.
- Коротка драма: `scenario: "drama"` (персонажі + діалоги).
- `style` — це пресет візуального стилю (наприклад, `modern` / `neon` / `luxury`), він не змінює тип, а впливає лише на візуальне сприйняття.
- `voice` використовується для вказання тембру голосу за кадром (наприклад, `warm-female` / `deep-male`), не залежить від мови та є універсальним для різних мов.

Результат відповідає «Базовому використанню»: також негайно повертається `task_id`.

## Мова готового відео

Одне завдання надає лише одне готове відео однією мовою. `langs` може містити лише один мовний код, наприклад `["zh-cn"]` або `["en"]`; передавання кількох мов поверне 400. Якщо потрібні відео різними мовами, створюйте завдання окремо. Вибір мови не змінює ціну за секунду.

## Ітерації над наявним відео (remix / edit / extend)

Передайте `action` і `ref_task_id` попереднього завдання, щоб внести поступові зміни на основі оригінального проєкту (наприклад, «змінити заголовок 2-ї сцени», «замінити озвучення», «зробити все темнішим»). Невеликі зміни виконуються швидко, а великі зміни призведуть до переробки:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`：повторна інтерпретація на основі структури оригінального відео (зберігає тему, коригує подачу).
- `edit`：точне редагування вказаної локальної частини (наприклад, заміна заголовка, озвучення, кольорокорекція).
- `extend`：розширення вмісту на основі оригінального відео.

Результат також негайно повертає новий `task_id`, використовуйте його для опитування, щоб отримати готове відео після ітерації.

## Отримання результату

Оскільки створення відео займає тривалий час, цей інтерфейс негайно повертає `task_id` після подання, і вам потрібно використовувати його для опитування результату через [API запиту завдань Maestro](/uk/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Після завершення завдання буде повернуто інформацію про готове відео (розташовану в масиві `variants`). `status` проходитиме через `pending → planning → producing → succeeded` (або `failed`), **опитування безкоштовне та не витрачає бали**. Повний формат відповіді та запит списку історії дивіться в [інструкції з інтеграції API запиту завдань Maestro](/uk/guides/maestro/maestro_tasks).

## Тарифікація

**Після успішного завершення завдання стягується плата за фактичну тривалість наданого готового відео; за невдачу плата не стягується.** Тривалість тарифікації обчислюється в цілих секундах і не перевищує запитану тривалість; якщо неможливо прочитати тривалість готового відео, використовується запитана тривалість. Саме подання завдання окремо не тарифікується, опитування `/maestro/tasks` є безкоштовним.

```
Бали = фактична кількість секунд тарифікації × 0.7
```

Для всіх сценаріїв, дій і мов застосовується однакова ціна, без множників сценаріїв або доплат за мову. Кожне завдання надає лише одне готове відео однією мовою. Запитувана цільова тривалість підтримує 5–300 секунд, єдиний вихідний формат — 1080p / 30fps.

| Фактична тривалість тарифікації | Бали |
| ------------------------------ | ---: |
| 30 секунд                      |   21 |
| 60 секунд                      |   42 |
| 120 секунд                     |   84 |
| 300 секунд                     |  210 |
| Опитування `/maestro/tasks`    | безкоштовно |

## Обробка помилок

Під час виклику API, якщо виникає помилка, API повертає відповідний код та інформацію про помилку. Наприклад:

- `400 invalid_request`：Неправильний запит, можливо через відсутній `prompt` або недійсні параметри.
- `401 invalid_token`：Неавторизовано, недійсний або відсутній токен авторизації.
- `403 forbidden`：Заборонено, недостатній баланс або доступ.
- `429 too_many_requests`：Забагато запитів, ви перевищили ліміт швидкості.
- `500 api_error`：Внутрішня помилка сервера, на сервері щось пішло не так.

### Приклад відповіді про помилку

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
