Цей документ головним чином описує процес використання ADSL Proxy API, за допомогою якого ми можемо легко витягувати IP ADSL та додавати IP до білого списку ADSL Proxy.

## Процес заявки

Щоб використовувати витягування IP ADSL та додавання IP до білого списку ADSL Proxy, спочатку можна перейти на сторінки [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/adsl-extract) та [ADSL Proxy Whitelist API](https://platform.acedata.cloud/documents/adsl-whitelist) і натиснути кнопку «Отримати», щоб отримати необхідні для запиту облікові дані:

![](https://cdn.acedata.cloud/nyq0xz.png)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, запрошуючи вас зареєструватися та увійти. Після входу або реєстрації ви автоматично повернетеся на цю сторінку.

При першій заявці буде надано безкоштовний ліміт, який дозволяє безкоштовно використовувати цей API.

## Витягування IP ADSL

Далі ви можете заповнити відповідні дані на інтерфейсі [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/adsl-extract), далі демонструється, як витягнути IP ADSL.

### Налаштування заголовків запиту та тіла запиту

**Request Headers** включає:

- `accept`: вказує на прийняття відповіді у форматі JSON, тут заповнюється як `application/json`.
- `authorization`: ключ для виклику API, після заявки можна вибрати з випадаючого списку.

**Request Body** включає:

- `number`: кількість витягуваних IP ADSL, за замовчуванням 1.
- `type`: тип витягуваних IP ADSL, головним чином поділяється на `http` та `socks`, за замовчуванням `http`.
- `province`: провінція, в якій знаходиться IP, за замовчуванням випадкова.
- `city`: місто, в якому знаходиться IP, за замовчуванням випадкове.

```bash
curl -X POST 'https://api.acedata.cloud/adsl/extract' \

-H 'content-type: application/json' \
-d '{

  "city": "温州"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "province": "浙江",
    "city": "温州"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Приклад відповіді

Після успішного запиту API поверне інформацію про результати обробки зображень. Наприклад:

```json
{
  "success": true,
  "data": [
    {
      "ip": "115.219.4.171",
      "port": 23456,
      "proxy": "115.219.4.171:23456",
      "outbound_ip": "115.219.4.171",
      "province": "浙江",
      "city": "温州",
      "expire_at": 1721877364.588,
      "dialed_at": 1721876984.588
    }
  ],
  "trace_id": "406465b0-f086-4a12-87a7-cdf05a3930a1"
}
```

Можна побачити, що в результаті є поле `data`, яке містить деталі завдання на отримання IP, інша інформація наведена на малюнку нижче:

- `success` - статус результату завдання на отримання ADSL IP.
- `data` - детальна інформація про отримане ADSL IP.

З `data` можна чітко побачити деталі цього IP, основна інформація, зокрема `ip`, вказує на отриману IP-адресу, інша інформація наведена нижче:

- `ip` - IP-адреса, отримана з ADSL.
- `port` - інформація про порт IP, отриманого з ADSL.
- `proxy` - повна інформація про проксі ADSL.
- `province` - провінція, в якій знаходиться IP, отримане з ADSL.
- `city` - місто, в якому знаходиться IP, отримане з ADSL.

Можна побачити, що ми можемо легко використовувати вище наведений `proxy` для подальшої роботи з IP-проксі.

Спочатку, перед використанням IP-проксі, нам потрібно додати свою мережеву IP-адресу (метод отримання локальної мережевої IP, будь ласка, шукайте самостійно) до білого списку, далі розглянемо, як використовувати IP-проксі:

### Використання проксі

> Увага: перед використанням отриманого проксі IP, обов'язково додайте IP до білого списку, інакше не зможете використовувати, про додавання до білого списку дивіться нижче.

Приклад коду Curl:

```shell
curl -x 115.219.4.171:23456 myip.vpsnb.net # http proxy
curl --socks5 115.219.3.54:23457 myip.vpsnb.net # socks proxy
```

Приклад проксі на Python:

```python
import requests
import socks
import socket
import time

def test_http_proxy(proxy):
    try:
        start_time = time.time()
        response = requests.get(
            'http://httpbin.org/ip', proxies={'http': proxy, 'https': proxy}, timeout=100)
        elapsed_time = time.time() - start_time
        print(response)
        if response.status_code == 200:
            print(f"HTTP Proxy {proxy} success. time: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"HTTP Proxy {proxy} failed. code: {response.status_code}")
    except Exception as e:
        print(f"HTTP Proxy {proxy} failed: {str(e)}")

def test_socks_proxy(proxy):
    proxy_parts = proxy.split(':')
    if len(proxy_parts) != 2:
        print(f"SOCKS failed: {proxy}")
        return

    host, port = proxy_parts
    port = int(port)

    try:
        start_time = time.time()
        socks.set_default_proxy(socks.SOCKS5, host, port)
        socket.socket = socks.socksocket
        response = requests.get('http://httpbin.org/ip', timeout=10)
        elapsed_time = time.time() - start_time

        if response.status_code == 200:
            print(f"SOCKS Proxy {proxy} success. time: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"SOCKS Proxy {proxy} failed. code: {response.status_code}")
    except Exception as e:
        print(f"SOCKS Proxy {proxy} failed: {str(e)}")
    finally:
        socks.set_default_proxy()
        socket.socket = socket.socket

if __name__ == "__main__":
    # HTTP Proxy
    http_proxy = "http://115.219.4.171:23456"
    test_http_proxy(http_proxy)

    # SOCKS Proxy
    socks_proxy = "115.219.3.54:23457"
    test_socks_proxy(socks_proxy)

```

## Додавання IP білого списку

Далі можна заповнити відповідні дані на інтерфейсі, як показано на малюнку:

<p><img src="https://cdn.acedata.cloud/wz4obo.png" width="500" class="m-auto"></p>

При першому використанні цього інтерфейсу нам потрібно заповнити принаймні три поля: одне з них - `authorization`, яке можна вибрати безпосередньо зі списку. Інший параметр - це `ip`, `ip` - це локальна мережа IP-проксі, витягнута вище. Останній параметр - `action`, `action` - це операція, яку ми виконуємо з білим списком, тут ми додаємо до білого списку.

Водночас ви можете помітити, що праворуч є відповідний код виклику, ви можете скопіювати код і безпосередньо виконати його, або просто натиснути кнопку «Спробувати» для тестування.

<p><img src="https://cdn.acedata.cloud/cs5ib2.png" width="500" class="m-auto"></p>

Приклад коду виклику на Python:

```python
import requests

url = "https://api.acedata.cloud/adsl/whitelist"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "ip": "113.112.122.132",
    "action": "add"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Після виклику ми виявили, що повернене значення таке:

```json

  "success": true
}
```

Повернене значення має одне поле, описане нижче:

- `success`, статус результату операції.

Тут `success` містить статус результату операції, ми можемо бачити, що IP `113.112.122.132` успішно додано до білого списку.

## Обробка помилок

При виклику API, якщо виникає помилка, API поверне відповідний код помилки та інформацію. Наприклад:

- `400 token_mismatched`: Неправильний запит, можливо, через відсутні або недійсні параметри.
- `400 api_not_implemented`: Неправильний запит, можливо, через відсутні або недійсні параметри.
- `401 invalid_token`: Неавторизовано, недійсний або відсутній токен авторизації.
- `429 too_many_requests`: Занадто багато запитів, ви перевищили ліміт запитів.
- `500 api_error`: Внутрішня помилка сервера, щось пішло не так на сервері.
