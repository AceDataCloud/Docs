Google SERP (Сторінка результатів пошуку) — це сторінка результатів, яку користувачі бачать після введення запиту в пошуковій системі Google. Вона відображає природні результати пошуку, рекламу, виділені фрагменти, графіки знань, а також різноманітний контент, такий як зображення, відео тощо, з метою надання користувачам найбільш релевантної інформації.

У цій статті буде детально описано Google SERP API, який може надати результати запиту, введеного в пошуковій системі Google, а також містить багато типів контенту, таких як виділені фрагменти, графіки знань та зображення.

Цей документ міститиме інструкції щодо інтеграції Google SERP API.

## Процес подачі заявки

Щоб використовувати Google SERP API, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications), щоб отримати ваш API Token, зберігши його для подальшого використання.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, запрошуючи вас зареєструватися та увійти. Після завершення ви автоматично повернетеся на цю сторінку.

**Один API Token дозволяє викликати всі послуги платформи, без необхідності окремої заявки для кожної послуги.** При першій подачі заявки надається безкоштовний ліміт, щоб ви могли безкоштовно протестувати; якщо ліміт вичерпано, ви можете поповнити загальний баланс в [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [Google SERP API →](https://platform.acedata.cloud/documents/serp-google)

## Основне використання

Спочатку ознайомтеся з основним способом використання, а саме введенням типу пошукового ресурсу та ключового слова, щоб отримати результати пошуку. Вам потрібно просто передати поле `query` і вказати відповідну модель.

Наприклад, щоб знайти інформацію про "apple inc", ми можемо заповнити відповідні дані на інтерфейсі, як показано на малюнку:

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

Ми бачимо, що тут ми налаштували заголовки запиту, включаючи:

- `accept`: формат відповіді, який ви хочете отримати, тут вказано `application/json`, тобто формат JSON.
- `authorization`: ключ для виклику API, який можна вибрати зі списку після подачі заявки.

Також налаштовано тіло запиту, яке включає:

- `type`: тип пошукового ресурсу, наразі підтримується лише шість типів, за замовчуванням — `search`.
- `query`: ключове слово для пошуку.
- `country`: країна, в якій потрібно налаштувати результати пошуку, за замовчуванням — США (US).
- `language`: мова, на якій потрібно налаштувати результати пошуку, за замовчуванням — англійська (en).
- `range`: часовий діапазон для налаштування результатів пошуку, за замовчуванням — без обмежень.
- `number`: розмір сторінки для налаштування результатів пошуку, за замовчуванням — 10.
- `page`: номер сторінки для налаштування результатів пошуку, за замовчуванням — 1.

## Налаштування діапазону часу результатів пошуку
本文 також можна налаштувати часовий діапазон результатів пошуку, який включає п'ять варіантів: `qdr:h` (останній годину), `qdr:d` (остання доба), `qdr:w` (останній тиждень), `qdr:m` (останий місяць), за замовчуванням без обмежень. Ми можемо передати відповідний часовий діапазон через `range`, наприклад, тут встановлено `qdr:d`, що означає пошук результатів за останню добу, тому введення виглядає так:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "range": "qdr:d",
  "query": "apple inc"
}'
```

## Налаштування пагінації результатів пошуку

Цей API також підтримує налаштування пагінації результатів пошуку, `number` та `page` вказують на розмір сторінки та номер сторінки, у цій статті буде встановлено, що на одній сторінці міститься 20 результатів пошуку для пагінації, конкретна інформація, як показано на малюнку:

<p><img src="https://cdn.acedata.cloud/dqla1e.png" width="500" className="m-auto" /></p>

> Зверніть увагу: коли кількість результатів на сторінці перевищує 10, зняті бали подвоюються.

Код виглядає так:
```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc",
  "number": 20,
  "page": 1
}'
```
