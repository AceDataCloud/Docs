CC Switch можна використовувати для управління провайдером та API Key Codex через графічний інтерфейс.

## 1. Отримання API Key

Відкрийте [список додатків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступних додатків і скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Встановлення CC Switch

Завантажте та встановіть з [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), або запустіть на macOS:

```bash
brew install --cask cc-switch
```

## 3. Додавання провайдера

1. Відкрийте CC Switch, перемкніться на **Codex**.
2. Натисніть **Add Provider**, виберіть **Custom**.
3. Заповніть:

| Поле       | Зміст                             |
| -------- | ------------------------------ |
| Name     | `acedatacloud`                 |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | Тільки що скопійований Ace Data Cloud API Key   |

Якщо CC Switch пропонує редактор для налаштувань, конфігурація повинна залишатися такою:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"
requires_openai_auth = true
```

CC Switch зберігатиме API Key у `~/.codex/auth.json`:

```json
{
  "OPENAI_API_KEY": "{token}"
}
```

Не додавайте `env_key` або `[model_providers.acedatacloud.auth]` у вищезгаданий провайдер; ручна конфігурація та конфігурація CC Switch - це вибір одного з двох. Не потрібно фіксувати `model`, просто виберіть його безпосередньо в Codex.

## 4. Увімкнення та перевірка

Увімкніть провайдер `acedatacloud`, повністю вийдіть і перезапустіть Codex або VS Code. Запустіть `/model`, підтвердіть, що провайдер - `acedatacloud`, потім виберіть модель і надішліть просте повідомлення.

Якщо повертається 401, підтвердіть, що активовано `acedatacloud`, і перевірте, чи `OPENAI_API_KEY` у `~/.codex/auth.json` є тільки що скопійованим Ace Data Cloud API Key. Записи викликів можна переглянути в [історії використання](https://platform.acedata.cloud/console/usages).
