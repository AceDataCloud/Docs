## 1. Отримання API Key

Відкрийте [список додатків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступних додатків і скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Встановлення Codex

```bash
npm install -g @openai/codex
```

## 3. Налаштування API Key

macOS / Linux：

```bash
export ACEDATACLOUD_API_KEY="ваш API Key"
```

Для тривалого збереження додайте цей рядок до `~/.zshrc` або `~/.bashrc`. Windows PowerShell використовуйте:

```powershell
setx ACEDATACLOUD_API_KEY "ваш API Key"
```

Після налаштування перезапустіть термінал.

## 4. Налаштування AceDataCloud

Редагуйте `~/.codex/config.toml` (для Windows `%USERPROFILE%\.codex\config.toml`), додайте:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Для Windows змініть останні два рядки на:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Не потрібно заповнювати `model`; після запуску можна вибрати модель у Codex. Існуючі конфігурації можна зберегти, не створюйте повторно провайдер з тією ж назвою.

## 5. Запуск

```bash
cd /path/to/your/project
codex
```

Увійшовши в Codex, запустіть `/model`, підтверджуючи, що Provider - `acedatacloud`, а потім виберіть потрібну модель. Записи викликів і баланс можна переглянути в [історії використання](https://platform.acedata.cloud/console/usages) та [списку додатків](https://platform.acedata.cloud/console/applications).

Якщо з'явиться повідомлення про відсутність Key або повернеться 401, підтверджуйте, що змінна середовища налаштована, і повністю вийдіть, а потім знову відкрийте термінал і Codex.
