---
title: "Посібник з налаштування Codex Desktop"
description: "Codex API guide - Ace Data Cloud"
---

Codex Desktop спільно використовує `~/.codex/config.toml` з Codex CLI.

## 1. Отримання API Key

Відкрийте [список додатків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступних додатків і скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Налаштування API Key

macOS：

```bash
launchctl setenv ACEDATACLOUD_API_KEY "ваш API Key"
```

Windows PowerShell：

```powershell
setx ACEDATACLOUD_API_KEY "ваш API Key"
```

## 3. Налаштування AceDataCloud

Редагуйте `~/.codex/config.toml` (для Windows це `%USERPROFILE%\.codex\config.toml`), додайте:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Для Windows змініть останні два рядки на:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Не потрібно заповнювати `model`; після відкриття Codex просто виберіть модель.

## 4. Перезапуск і перевірка

Повністю вийдіть і знову відкрийте Codex Desktop, створіть нове локальне завдання і надішліть просте повідомлення. Провайдер має відображатися як `acedatacloud`; реальні виклики можна переглянути в [історії використання](https://platform.acedata.cloud/console/usages).

Якщо налаштування не вступили в силу, переконайтеся, що ви редагували `~/.codex/config.toml` для поточного користувача, змінна середовища налаштована, а потім знову повністю перезапустіть додаток. Хмарні завдання або автоматизація, що працюють в різних середовищах, потребують окремого налаштування Key у відповідному середовищі.
