Розширення Codex для VS Code використовує спільний файл `~/.codex/config.toml` з Codex CLI.

## 1. Отримання API Key

Відкрийте [список додатків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступних додатків і скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Встановлення розширення

Встановіть **Codex – OpenAI's coding agent**, опубліковане OpenAI, з ринку розширень VS Code, або запустіть:

```bash
code --install-extension openai.chatgpt
```

## 3. Налаштування API Key

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="ваш API Key"
```

Щоб це діяло постійно, додайте цей рядок до `~/.zshrc` або `~/.bashrc`. Windows PowerShell використовуйте:

```powershell
setx ACEDATACLOUD_API_KEY "ваш API Key"
```

## 4. Налаштування AceDataCloud

Редагуйте `~/.codex/config.toml` (для Windows `%USERPROFILE%\.codex\config.toml`), додайте:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Для Windows змініть останні два рядки на:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Не потрібно заповнювати `model`; модель можна вибрати в панелі Codex.

## 5. Перезапуск і перевірка

Повністю вийдіть і знову відкрийте VS Code, потім відкрийте панель Codex. Запустіть `/model`, підтверджуючи, що Provider - `acedatacloud`, а потім надішліть просте повідомлення; записи викликів можна переглянути в [історії використання](https://platform.acedata.cloud/console/usages).

Якщо розширення не може прочитати Key, запустіть VS Code з терміналу, де вже налаштовані змінні середовища, або налаштуйте системні змінні середовища, а потім перезапустіть VS Code. Remote SSH, WSL і Dev Container потрібно налаштувати в середовищі, де фактично працює розширення.
