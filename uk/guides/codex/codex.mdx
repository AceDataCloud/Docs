---
title: "Посібник з налаштування Codex"
description: "Codex API guide - Ace Data Cloud"
---

Codex CLI, Desktop та розширення VS Code використовують спільний файл `~/.codex/config.toml`. Налаштуйте провайдера `acedatacloud` один раз, і ви зможете використовувати Codex через Ace Data Cloud.

| Спосіб використання   | Посібник з налаштування                                                                  |
| ------------------ | ------------------------------------------------------------------------------------- |
| Terminal / CLI     | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)      |
| Desktop            | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)   |
| VS Code            | [Codex for VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)|
| Графічний перемикач | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration) |

Спільні налаштування складаються з трьох пунктів:

- Провайдер: `acedatacloud`
- Базовий URL: `https://api.acedata.cloud/v1`
- API Key: отримайте з [списку додатків](https://platform.acedata.cloud/console/applications) та збережіть у `ACEDATACLOUD_API_KEY`

Не потрібно фіксувати модель у налаштуваннях підключення; після запуску Codex ви можете безпосередньо вибрати модель.

Поверніться до [Центру налаштувань Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
