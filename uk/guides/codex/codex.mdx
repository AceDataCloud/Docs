---
title: "Інструкція з налаштування Codex"
description: "Codex 集成指南 - Ace Data Cloud"
---

Codex CLI — це відкритий локальний агент програмування від OpenAI, який може читати код, змінювати файли, виконувати команди та допомагати у виконанні розробницьких завдань у терміналі. Завдяки проксі Ace Data Cloud ви можете використовувати Codex CLI за нижчою ціною без необхідності окремої підписки на офіційний акаунт OpenAI.

Виберіть відповідний повний посібник з налаштування залежно від сценарію використання:

| Платформа | Опис | Посилання на посібник |
|-----------|------|----------------------|
| **VS Code** | Офіційне розширення, чат у бічній панелі редактора, посилання на файли, перегляд diff | [Інструкція з налаштування VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| **Термінал (CLI)** | Основний досвід, запускайте `codex` у будь-якому терміналі, щоб почати | [Інструкція з налаштування терміналу](https://platform.acedata.cloud/documents/codex-terminal-integration) |

> **Підказка**: Для першої заявки перейдіть до [Ace Data Cloud консолі](https://platform.acedata.cloud/console/applications), щоб отримати API Token і безкоштовний ліміт. Codex CLI працює через сумісний інтерфейс OpenAI Responses Ace Data Cloud (`/v1/responses`), більше інформації про моделі та тарифи можна знайти на [сторінці сервісу OpenAI](https://platform.acedata.cloud/documents/openai).
