---
title: "Посібник з інтеграції API завдань Qwen Image"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

Використовуйте `POST https://api.acedata.cloud/qwen-image/tasks` для запиту асинхронних завдань генерації зображень. Цей запит безкоштовний.

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Для пакетного запиту використовуйте `action=retrieve_batch` та масив `ids`. Після успішного виконання завдання, `response.data` міститиме постійну адресу згенерованого зображення та фактичне використання.
