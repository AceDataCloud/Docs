`POST https://api.acedata.cloud/qwen-image/tasks` використовується для запиту, масового запиту або видалення асинхронних завдань Qwen Image. Цей інтерфейс не генерує додаткові витрати на API.

## Запит одного завдання

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Після завершення завдання, `response.data` міститиме постійне CDN зображення, `response.usage` міститиме реальну кількість вхідних/вихідних даних, `response.cost` буде інформацією про розрахунок завдання.

## Масовий запит

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Повертає `{ "items": [...], "count": 2 }`. Список запитів також підтримує фільтрацію за користувачем, додатком та діапазоном часу створення.

## Видалення записів завдань

```json
{"action":"delete","id":"TASK_ID"}
```

Видалення вплине лише на історію завдань, не видалить вже згенеровані файли CDN.
