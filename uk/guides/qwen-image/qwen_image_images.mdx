---
title: "API генерації та редагування зображень Qwen"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` виконує генерацію зображень за текстом і редагування за 1–3 референсними зображеннями через один і той самий інтерфейс, підтримує `qwen-image-3.0` і `qwen-image-3.0-pro`.

## Вибір моделі

| Модель                   | Відповідні сценарії       | Офіційна стандартна ціна                   |
| -------------------- | ---------- | ----------------------- |
| `qwen-image-3.0`     | Пакетне створення, швидкі ітерації  | Вивід $0.030/зображення             |
| `qwen-image-3.0-pro` | Складне компонування, високоточний фінальний результат | 1K $0.040/зображення; 2K $0.075/зображення |

Референсні зображення оплачуються за фактичною кількістю вхідних зображень, офіційна стандартна ціна — $0.003/зображення.

## Синхронна генерація

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "A simple red circle centered on a clean white background.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

Успішна відповідь містить постійну CDN-адресу зображення, фактичне usage та вартість цього запиту:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Редагування референсних зображень

Додайте `image_urls`, підтримується 1–3 публічно доступні зображення:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "保留主体，将背景改成暖色电影海报风格",
  "image_urls": ["https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` використовується лише для генерації зображень за текстом. Діапазон `n` становить 1–6; співвідношення сторін має бути від 1:8 до 8:1.

## Асинхронні завдання

Після встановлення `async: true` інтерфейс негайно повертає `task_id`. Використовуйте `/qwen-image/tasks` для запиту фінального стану або передайте `callback_url` для отримання сповіщення про завершення. Генерація оплачується лише один раз, повторна плата за запити завдань не стягується.
