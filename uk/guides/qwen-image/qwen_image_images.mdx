title: "Qwen Image генерація та редагування API"

---

`POST https://api.acedata.cloud/qwen-image/images` через той самий інтерфейс виконується генерація з тексту та редагування 1–3 референсних зображень, підтримує `qwen-image-3.0` та `qwen-image-3.0-pro`.

## Вибір моделі

| Модель                   | Підходящі сцени       | Офіційна стандартна ціна                   |
| -------------------- | ---------- | ----------------------- |
| `qwen-image-3.0`     | Масове створення, швидка ітерація  | Вихід $0.030/зображення             |
| `qwen-image-3.0-pro` | Складна верстка, висока точність | 1K $0.040/зображення; 2K $0.075/зображення |

Референсні зображення оплачуються за реальною кількістю введень, офіційна стандартна ціна $0.003/зображення.

## Синхронна генерація

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "Простий червоний круг, розташований по центру на чистому білому фоні.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

Успішна відповідь містить постійне CDN зображення, реальне використання та витрати:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Редагування референсних зображень

Додайте `image_urls`, підтримує 1–3 відкритих доступних зображення:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "Залишити об'єкт, змінити фон на теплий **###** постерний стиль",
  "image_urls": ["https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` використовується лише для генерації з тексту. `n` в межах 1–6; співвідношення сторін має бути від 1:8 до 8:1.

## Асинхронні завдання

Після встановлення `async: true` інтерфейс негайно повертає `task_id`. Використовуйте `/qwen-image/tasks` для запиту кінцевого стану або передайте `callback_url` для отримання повідомлення про завершення. Генерація оплачується лише один раз, запит завдання не повторно оплачується.
