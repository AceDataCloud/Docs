---
title: "Посібник з інтеграції API зображень Qwen"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` підтримує `qwen-image-3.0` та `qwen-image-3.0-pro` для генерації зображень за текстом та редагування 1–3 референсних зображень.

## Генерація зображень за текстом

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen-image-3.0","prompt":"Дуже мінімалістичний технологічний постер","size":"1024*1024","n":1}'
```

## Редагування зображень

Додайте `image_urls` в той же запит, підтримується 1–3 публічних зображення:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "Залишити об'єкт, змінити на теплий **###** стиль постера",
  "image_urls": ["https://cdn.acedata.cloud/r9vsv9.png"],
  "size": "2048*2048",
  "prompt_extend": true,
  "prompt_extend_mode": "direct",
  "enable_thinking": true,
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` підтримується лише для генерації зображень за текстом. `n` в діапазоні від 1 до 6. Загальна кількість пікселів виходу повинна бути в межах від 512×512 до 2048×2048, співвідношення сторін від 1:8 до 8:1.

## Асинхронний виклик

Встановлення `async: true` дозволяє негайно отримати `task_id`; також можна передати `callback_url` для отримання остаточних результатів. Після завершення запитуйте через `/qwen-image/tasks`.

Успішна відповідь містить `data[].image_url`, `usage`, `task_id` та `trace_id`. Посилання на зображення буде максимально перенесено до Ace Data Cloud CDN. Реальні приклади відповідей будуть додані після виробничої E2E верифікації.
