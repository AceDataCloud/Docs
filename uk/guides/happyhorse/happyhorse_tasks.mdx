HappyHorse Tasks API використовується для запиту завдань на створення або редагування відео, створених за допомогою HappyHorse Videos API.

## Процес подачі заявки

Щоб використовувати HappyHorse Videos API, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications) для отримання вашого API Token, залиште його на випадок потреби.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, де вас запросять зареєструватися та увійти, після чого ви будете автоматично повернені на поточну сторінку.

**Один API Token дозволяє викликати всі послуги платформи, не потрібно окремо подавати заявку на кожну послугу.** Перший запит на отримання токена надає безкоштовний ліміт, щоб ви могли безкоштовно спробувати; якщо ліміт вичерпано, ви можете поповнити загальний баланс в [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Приклад запиту

HappyHorse Tasks API можна використовувати для запиту результатів HappyHorse Videos API.

### Налаштування заголовків запиту та тіла запиту

**Request Headers** включає:

- `accept`: вказує на прийом відповіді у форматі JSON, тут вказується `application/json`.
- `authorization`: ключ для виклику API, після подачі заявки його можна вибрати зі списку.

**Request Body** включає:

- `id`: ID завдання, яке потрібно запитати.
- `action`: спосіб виконання операції над завданням, для одиночного запиту вказується `retrieve`.

### Приклад коду CURL

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Приклад відповіді

Після успішного запиту API поверне деталі цього завдання. Поле `request` є тілом запиту під час створення завдання, поле `response` є тілом відповіді після завершення завдання, наприклад:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262774.423,
  "elapsed": 52.6,
  "request": {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "Кінематографічний кадр білого коня, що біжить по пляжу при місячному світлі",
    "resolution": "720P",
    "duration": 5
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "1469cfc3-3004-4d9e-ab10-xxxxxx",
        "video_url": "https://cdn.acedata.cloud/happyhorse/c8cbf53aa0.mp4",
        "state": "succeeded",
        "duration": 5,
        "resolution": "720P",
        "ratio": "16:9"
      }
    ]
  }
}
```

Опис полів:

- `id`: ID завдання на створення, що використовується для унікальної ідентифікації цього завдання.
- `request`: інформація про запит під час створення завдання.
- `response`: поточна або остаточна інформація про повернення завдання.
- `created_at`: час створення завдання, Unix-час (секунди, з плаваючою комою).
- `started_at`: час початку виконання завдання, Unix-час (секунди, з плаваючою комою).
- `finished_at`: час завершення завдання, Unix-час (секунди, з плаваючою комою). Поле не повертається, якщо завдання не завершено.
- `elapsed`: час виконання завдання, одиниця виміру - секунди (з плаваючою комою, зберігається 3 знаки після коми). Поле не повертається, якщо завдання не завершено.

## Пакетний запит

Для запиту деталей кількох ID завдань, встановіть `action` на `retrieve_batch` і передайте масив ID завдань через `ids`:

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```

У повернутому результаті будуть включені поля `items` та `count`, де `items` - масив деталей завдань, а `count` - кількість завдань, що відповідають запиту.
