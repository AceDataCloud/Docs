У цьому документі описується спосіб інтеграції API HappyHorse Videos. Цей інтерфейс підтримує генерацію відео з тексту, відео з першого кадру, відео з референсного зображення та редагування відео через єдиний вхідний пункт `/happyhorse/videos` та параметр `action`.

## Процес подачі заявки

Щоб використовувати API HappyHorse Videos, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications) для отримання вашого API Token, зберігайте його для подальшого використання.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, щоб запросити реєстрацію та вхід, після чого ви будете автоматично повернені на цю сторінку.

**Один API Token дозволяє викликати всі послуги платформи, не потрібно окремо подавати заявку на кожну послугу.** Перший запит на отримання токена надає безкоштовний ліміт, щоб ви могли безкоштовно протестувати; якщо ліміт вичерпано, ви можете поповнити загальний баланс в [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Типи операцій

`action` визначає режим генерації для цього запиту:

- `generate`: генерація відео з тексту, за замовчуванням action, підтримує `happyhorse-1.0-t2v` та `happyhorse-1.1-t2v`, обов'язково потрібно передати `prompt`.
- `image_to_video`: відео з першого кадру, підтримує `happyhorse-1.0-i2v` та `happyhorse-1.1-i2v`, обов'язково потрібно передати `image_url`.
- `reference_to_video`: відео з референсного зображення, підтримує `happyhorse-1.0-r2v` та `happyhorse-1.1-r2v`, обов'язково потрібно передати `prompt` та 1–9 `image_urls`.
- `video_edit`: редагування відео, підтримує `happyhorse-1.0-video-edit`, обов'язково потрібно передати `prompt` та `video_url`, додатково можна передати 0–5 референсних зображень `image_urls`.

Кожна дія за замовчуванням використовує модель 1.1; `video_edit` наразі підтримує лише `happyhorse-1.0-video-edit`.

## Основне використання

Для генерації відео з тексту потрібно лише надати `prompt`, також можна вказати параметри `resolution`, `ratio`, `duration` тощо:

```json
{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "Кінематографічний білий кінь піднімає голову, грива м'яко коливається на вітрі на світанку, повільний зум камери, тепле кінематографічне освітлення",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

Приклад повернутого результату:

```json
{
  "success": true,
  "task_id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
  "trace_id": "6071ab5e-2f37-46f0-9e07-f1e378112e69",
  "data": [
    {
      "id": "9650580f-6d9e-4bc1-823a-29011790c5cb",
      "video_url": "https://platform2.cdn.acedata.cloud/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1.mp4",
      "state": "succeeded",
      "duration": 5,
      "resolution": "720P",
      "ratio": null
    }
  ]
}
```

Опис полів:

- `success`: чи був запит успішним.
- `task_id`: ID завдання на стороні Ace Data Cloud, може бути використаний для перевірки статусу завдання.
- `trace_id`: ID відстеження цього запиту, використовується для усунення проблем.
- `data`: список результатів відео.
  - `id`: ID завдання HappyHorse.
  - `video_url`: CDN-адреса згенерованого відео.
  - `state`: статус завдання, можливі значення `pending` / `succeeded` / `error`.
  - `duration`: тривалість відео для розрахунку вартості, в секундах; для `video_edit` це сума тривалостей вхідного та вихідного відео.
  - `resolution`: вихідна роздільна здатність.
  - `ratio`: вихідне співвідношення сторін.

Відповідний код CURL виглядає так:

```shell
curl -X POST 'https://api.acedata.cloud/happyhorse/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "Кінематографічний білий кінь піднімає голову, грива м'яко коливається на вітрі на світанку, повільний зум камери, тепле кінематографічне освітлення",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}'
```

Відповідний код Python виглядає так:

```python
import requests

url = "https://api.acedata.cloud/happyhorse/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "Кінематографічний білий кінь піднімає голову, грива м'яко коливається на вітрі на світанку, повільний зум камери, тепле кінематографічне освітлення",
    "resolution": "720P",
    "ratio": "16:9",
    "duration": 5,
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Відео з першого кадру

При використанні `image_to_video`, `image_url` буде використовуватися як перший кадр відео. Вихідне співвідношення сторін намагатиметься відповідати зображенню першого кадру, тому для цієї дії не потрібно передавати `ratio`.

```json
{
  "action": "image_to_video",
  "model": "happyhorse-1.1-i2v",
  "image_url": "https://cdn.acedata.cloud/b1c82e4937.png",
  "prompt": "Кінематографічний білий кінь піднімає голову, грива м'яко коливається на вітрі на світанку, повільний зум камери, тепле кінематографічне освітлення",
  "resolution": "1080P",
  "duration": 5
}
```

## Відео з референсного зображення

При використанні `reference_to_video`, `image_urls` можуть містити 1–9 референсних зображень. У підказках можна використовувати `character1`, `character2` тощо для посилання на відповідні зображення в порядку.

```json
{
  "action": "reference_to_video",
  "model": "happyhorse-1.1-r2v",
  "prompt": "character1 йде вперед через світанковий луг у стилі теплого шкіряного оздоблення з золотими акцентами від character2",
  "image_urls": [
    "https://cdn.acedata.cloud/b1c82e4937.png",
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

## Редагування відео

При використанні `video_edit` обов'язково потрібно передати відео для редагування `video_url` та намір редагування `prompt`. Додаткові `image_urls` можуть бути використані як референсні зображення, наприклад, для зміни одягу, стилю або часткової заміни. `audio_setting` може бути `auto` або `origin`, де `origin` означає збереження оригінального звуку відео.

```json
{
  "action": "video_edit",
  "model": "happyhorse-1.0-video-edit",
  "prompt": "Застосуйте стиль теплого шкіряного оздоблення з референсного зображення, зберігаючи оригінальний рух камери",
  "video_url": "https://platform2.cdn.acedata.cloud/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1.mp4",
  "image_urls": [
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "audio_setting": "auto"
}
```

## Асинхронний зворотний виклик
Відео генерація потребує певного часу обробки. Якщо ви не хочете підтримувати довге з'єднання в очікуванні, ви можете передати `callback_url`, у цьому випадку API негайно поверне `task_id`, а після завершення завдання остаточний результат буде надіслано на цю адресу:

```json
{
  "action": "generate",
  "prompt": "A horse running through a snowy forest",
  "duration": 5,
  "callback_url": "https://your-domain.com/callback/happyhorse"
}
```

Негайно повернуті результати виглядають так:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

Якщо ви хочете лише опитувати, без необхідності в зворотному виклику, ви також можете передати `"async": true`, а потім через [HappyHorse Tasks API](https://platform.acedata.cloud/documents/happyhorse-tasks) перевірити результати завдання.

## Інформація про тарифи

HappyHorse стягує плату за кількість секунд вихідного відео та роздільну здатність:

- `720P`: від приблизно $0.105 / сек.
- `1080P`: від приблизно $0.18 / сек.
- `video_edit`: стягується плата за загальну тривалість вхідного та вихідного відео, фактична тривалість для розрахунку плати визначається за статистикою після завершення завдання.

Неуспішні завдання не підлягають оплаті і не займають безкоштовний ліміт.

## Обробка помилок

Коли запит має проблеми, API поверне відповідний код помилки та опис, найбільш поширені з них:

- `400`: Неправильні параметри запиту, наприклад, action не відповідає model, відсутні `prompt` / `image_url` / `video_url`, або `duration` перевищує діапазон 3–15 секунд.
- `401`: Помилка авторизації, токен недійсний або не відповідає API.
- `403`: Недостатньо коштів, або підказка потрапила під вмістовий контроль і була відхилена.
- `429`: Запити надто часті, спрацьовує обмеження, будь ласка, спробуйте пізніше.
- `500`: Внутрішня помилка сервера або невдача генерації на upstream.
