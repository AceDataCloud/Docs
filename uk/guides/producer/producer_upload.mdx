---
title: "Інструкція з інтеграції API завантаження референсного аудіо Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer дозволяє нам завантажувати референсне аудіо для вторинної творчості, у цьому документі пояснюється спосіб інтеграції відповідного API.

Цей API має лише один вхідний параметр — `audio_url`, це загальнодоступна CDN-адреса, підтримується суфікс mp3.

Тут ми вводимо `audio_url` як `https://cdn.acedata.cloud/suno_demo.mp3`, це загальнодоступна CDN-адреса.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Результат такий:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Soft female vocals, bright and cheerful]\n\n[Verse 1]\n阳光洒在海边\n浪花笑得灿烂\n你和我在沙滩\n钟表停止转\n冰淇淋在融化\n手牵手去散步\n风儿轻轻吹过\n心跳不停跳\n\n[Chorus]\n夏天夏天\n时间停在这一天\n笑声回荡\n蔚蓝天空在身旁",
    "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
  }
}
```

Можна побачити, що поле `audio_id` у `data` є ID пісні після завантаження.

Після отримання ID пісні ми можемо використовувати [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration) для створення користувацьких пісень, наприклад, передати `upload_extend` у `action`, а також передати повернений ID пісні в `audio_id`, і тоді можна буде генерувати нові пісні на основі референсного аудіо.
