---
title: "Інструкція з інтеграції API для завантаження відео Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer дозволяє нам завантажувати відео, пов'язані з піснями. У цьому документі пояснюється метод інтеграції відповідного API.

Цей API має лише один вхідний параметр, а саме `audio_id`, який є унікальним ID пісні.

Тут ми вводимо `audio_id`, який є `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, це ID пісні, згенероване Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Результат виглядає так:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4"
  }
}
```

Як видно, поле `video_url` в `data` є посиланням на завантажене відео.
