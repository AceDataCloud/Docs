---
title: "Producer завантаження WAV API інтеграція"
description: "Producer Music Generation 集成指南 - Ace Data Cloud"
---

Producer дозволяє нам завантажувати пов'язані з піснею WAV файли, цей документ пояснює методи інтеграції відповідного API.

Цей API має лише один вхідний параметр, а саме `audio_id`, який є унікальним ID пісні.

Тут ми вводимо `audio_id`, який є `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, це ID пісні, згенероване Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/wav' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Результат виглядає так:

```
{
  "success": true,
  "task_id": "44963173-b6c5-463c-915f-96730d14ec63",
  "trace_id": "f75d6a27-54bc-49fd-a40e-6d4cd0427764",
  "data": [
    {
      "title": "Прокинувся з сонцем в очах",
      "file_url": "https://cdn.ttapi.io/other/2025-12-30/a1508051-a6b8-4867-8cbb-32273a99c2ae.wav"
    }
  ]
}
```

Можна побачити, що поле `file_url` в `data` є посиланням для завантаження WAV.
