Продовжити підтримує API, сумісний з OpenAI. Щоб зафіксувати використання Chat Completions, потрібно явно встановити `useResponsesApi: false`.

## Налаштування

У локальному YAML конфігурації Continue додайте:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

У менеджері секретів Continue збережіть `ACEDATACLOUD_API_KEY`, не додавайте реальний токен до конфігурації проекту. JSON конфігурація Continue вже застаріла, нова конфігурація використовує YAML.

## Перевірка

Перезавантажте VS Code, відкрийте бічну панель Continue, виберіть модель у Local Config і надішліть `Reply only OK`; потім виконайте ще раз завдання з читання файлів. Якщо запит помилково надіслано на `/responses`, перевірте, чи знаходиться `useResponsesApi: false` у цій моделі.
