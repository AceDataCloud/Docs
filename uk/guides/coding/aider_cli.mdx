Aider підключається до OpenAI-сумісного API через префікс моделі `openai/` LiteLLM.

## Конфігурація

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

Замініть `MODEL_ID` на модель, обрану в майстрі конфігурації Coding. Також можна записати відповідні параметри в локальний `.env` або `.aider.conf.yml`, але не слід подавати справжній токен.

## Перевірка

```bash
aider --model openai/MODEL_ID --message "Reply only OK"
```

При першому використанні невідомої моделі Aider може повідомити про відсутність метаданих моделі; це не є рівнозначним невдачі авторизації. 401 перевіряє токен, 404 перевіряє ID моделі та базовий URL `/v1`.
