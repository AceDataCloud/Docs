## 1. Отримання API Key

Відкрийте [список застосунків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступного застосунку та скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Запуск майстра

```bash
hermes model
```

Виберіть **Custom endpoint**, послідовно заповніть:

| Поле             | Значення                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | Щойно скопійований API Key                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | Перейдіть до [каталогу моделей](https://platform.acedata.cloud/models), щоб переглянути, та без змін введіть назву цільової моделі, наприклад `claude-opus-5`, `gpt-6-sol` |
| Context length | Залиште порожнім для автоматичного визначення або заповніть відповідно до каталогу моделей                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model` — це назва моделі, що використовується параметром `model` в API-запиті, а не UUID сервісу чи API. Спершу її можна переглянути в [каталозі моделей](https://platform.acedata.cloud/models); якщо потрібна точна перевірка, використайте поточний API Key, щоб надіслати запит `GET https://api.acedata.cloud/v1/models`, і скопіюйте значення `id` цільової моделі з масиву `data` у відповіді.

Майстер запише дані до `~/.hermes/config.yaml` і локального файлу облікових даних.

## 3. Перевірка

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

Якщо майстер не зберіг конфігурацію, можна виконати `hermes model --reset` і повторити спробу; 401 означає, що API Key недійсний або не зчитується конфігурацією поточного користувача.
