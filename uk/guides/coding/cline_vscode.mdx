## 1. Отримання API Key

Відкрийте [список застосунків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступного застосунку та скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Налаштування Cline

Встановіть і відкрийте Cline у VS Code, потім через кнопку налаштувань на панелі Cline перейдіть до конфігурації Provider та заповніть:

| Поле                                | Значення                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| API Provider                      | `OpenAI Compatible`                                                                            |
| Base URL                          | `https://api.acedata.cloud/v1`                                                                 |
| API Key                           | Щойно скопійований API Key                                                                                  |
| Model ID                          | Перейдіть до [каталогу моделей](https://platform.acedata.cloud/models), перегляньте та заповніть назву цільової моделі без змін, наприклад `claude-opus-5`, `gpt-6-sol` |
| Custom Headers                    | Залишити порожнім                                                                                             |
| Set Azure API version             | Залишити порожнім                                                                                             |
| Use Azure Identity Authentication | Вимкнути                                                                                             |

![Інтерфейс налаштування Cline OpenAI Compatible](https://cdn.acedata.cloud/8f356c2f1378.png)

`Model ID` — це назва моделі, що використовується параметром `model` в API-запиті, а не UUID сервісу чи API, і її не можна скорочувати самостійно. Спочатку можна переглянути її в [каталозі моделей](https://platform.acedata.cloud/models); якщо потрібна точна перевірка, використайте поточний API Key для запиту `GET https://api.acedata.cloud/v1/models` і скопіюйте значення `id` цільової моделі з масиву `data` у відповіді.

Інші налаштування можливостей моделі поки що залиште за замовчуванням; коли знадобляться зображення або більший контекст, налаштуйте їх відповідно до фактичних можливостей вибраної моделі.

## 3. Перевірка

Після збереження створіть нове завдання та надішліть `Reply only OK`. Потім попросіть Cline прочитати тестовий файл, щоб підтвердити підтримку моделлю викликів інструментів; записи викликів можна переглянути в [історії використання](https://platform.acedata.cloud/console/usages).

401 зазвичай означає помилку Key; 404 зазвичай означає неправильний Base URL або те, що введений Model ID не повністю збігається з `id` у каталозі. Якщо модель може спілкуватися в чаті, але не може працювати з файлами, перевірте можливості виклику інструментів цієї моделі.
