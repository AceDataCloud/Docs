## 1. Отримати API Key

Відкрийте [Список додатків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступних додатків і скопіюйте API Key.

![Отримати Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Налаштування Provider

Плагін Kilo Code для JetBrains використовує формат `kilo.jsonc` для Provider. Налаштування повинні бути в середовищі користувача, де фактично працює плагін; під час віддаленої розробки зазвичай це віддалений хост backend.

Запишіть у `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

В екологічному середовищі, де запускається backend JetBrains, експортуйте `ACEDATACLOUD_API_KEY`, а потім перезапустіть IDE або віддалений backend.

## 3. Перевірка

Виберіть `acedatacloud/MODEL_ID`, надішліть `Reply only OK`, а потім дайте Agent прочитати тестовий файл. Якщо локально все працює, а віддалено - ні, спочатку перевірте, чи правильно написані конфігураційний файл і змінні середовища на віддаленому хості.
