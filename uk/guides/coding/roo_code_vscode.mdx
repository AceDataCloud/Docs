## 1. Отримання API Key

Відкрийте [список застосунків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступного застосунку та скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Налаштування

Roo Code офіційно надає OpenAI-compatible Provider і вимагає, щоб модель підтримувала нативний OpenAI tools/function calling.

1. Відкрийте налаштування Roo Code у VS Code.
2. Установіть **API Provider** на **OpenAI Compatible**.
3. Заповніть:

| Поле       | Значення                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | Щойно скопійований API Key                  |
| Model ID | ID моделі, вибраний у майстрі налаштування Coding         |

![Інтерфейс налаштування Roo Code OpenAI Compatible](https://cdn.acedata.cloud/b6a0e7156438.png)

Далі встановіть опції context, max output, зображень і computer-use відповідно до фактичних можливостей моделі. Нарешті збережіть налаштування та перезавантажте VS Code.

## 3. Перевірка

Спочатку надішліть `Reply only OK`, а потім попросіть Roo Code прочитати тестовий файл. Якщо звичайний чат працює успішно, але інструменти Agent не працюють, змініть модель на таку, що підтримує нативний tool calling, і переконайтеся, що сумісний endpoint може коректно потоково повертати параметри та результати інструментів.
