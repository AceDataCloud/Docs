Офіційна документація Coze для кастомізованих моделей підтримує OpenAI Chat API. Різні версії орендарів Coze можуть по-різному обробляти з'єднання шляхів, потоковий вивід та виклики інструментів, тому при першому підключенні перевірте кожен пункт нижче.

## Налаштування

1. Увійдіть у керування моделями Coze та додайте нову кастомізовану модель.
2. Виберіть протокол OpenAI Chat API.
3. У полі Base API URL введіть `https://api.acedata.cloud/v1`.
4. У полі API Key введіть ваш Ace Data Cloud API Token.
5. У полі Model введіть точний ID моделі, що підтримує Chat Completions у каталозі моделей.
6. Збережіть та заверште тестування з'єднання Coze.
7. У Bot/Agent надішліть `Reply only OK`, а потім ще раз протестуйте виклик інструменту.

## Поточні обмеження

- Різні регіони, версії або пакети Coze можуть відображати різні форми.
- Base API URL слід використовувати базовий, не додаючи повторно `/chat/completions`; якщо поточний інтерфейс чітко вимагає повний API URL, дотримуйтесь підказок форми.
- Chat Completions, Responses та Anthropic Messages є трьома незалежними маршрутами, які не можуть взаємозамінювати один одного для верифікації.
