Офіційна документація Coze для користувацьких моделей підтримує Anthropic Messages API. Різні версії орендарів Coze можуть по-різному обробляти заголовки, з'єднання шляхів, потокову передачу та виклики інструментів, тому при першому підключенні перевірте кожен пункт нижче.

## Налаштування

1. Увійдіть у керування моделями Coze та додайте нову користувацьку модель.
2. Виберіть Protocol Anthropic Messages API.
3. У полі Base API URL введіть `https://api.acedata.cloud`.
4. У полі API Key введіть ваш Ace Data Cloud API Token.
5. У полі Model введіть точний ID моделі, що підтримує Anthropic Messages, з каталогу моделей.
6. Збережіть і заверште тестування підключення Coze.
7. У Bot/Agent надішліть `Reply only OK`, потім ще раз протестуйте виклик інструменту.

## Поточні обмеження

- Різні регіони, версії або пакети Coze можуть відображати різні форми.
- Base API URL не слід повторно доповнювати `/v1/messages`; якщо поточний інтерфейс чітко вимагає повний API URL, дотримуйтесь підказок форми.
- Messages, Chat Completions та Responses є трьома незалежними маршрутами, які не можуть взаємозамінювати один одного для верифікації.
