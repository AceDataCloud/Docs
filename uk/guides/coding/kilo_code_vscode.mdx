## 1. Отримання API Key

Відкрийте [список застосунків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступного застосунку та скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Додавання Custom provider

У Kilo Code відкрийте **Settings → Providers**, натисніть **Custom provider**, а потім заповніть:

| Поле           | Значення                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------- |
| Provider ID  | `acedatacloud`                                                                                 |
| Display name | `AceDataCloud`                                                                                 |
| Provider API | `OpenAI Compatible`                                                                            |
| Base URL     | `https://api.acedata.cloud/v1`                                                                 |
| API key      | Щойно скопійований API Key                                                                                  |
| Models       | Перейдіть до [каталогу моделей](https://platform.acedata.cloud/models), щоб переглянути та додати назви моделей для використання, наприклад `claude-opus-5`, `gpt-6-sol` |

![Інтерфейс налаштування Kilo Code Custom provider](https://cdn.acedata.cloud/94eb5abd7a6f.png)

`id` моделі тут — це назва моделі, що використовується параметром `model` у API-запиті, а не UUID сервісу або API. Спершу можна переглянути її в [каталозі моделей](https://platform.acedata.cloud/models); для точної перевірки скопіюйте без змін з масиву `data` у відповіді `/v1/models`, не вгадуйте та не скорочуйте самостійно.

Натисніть **Submit**, і модель з’явиться у селекторі. Якщо потрібен спільний доступ для команди або детальніші налаштування, також можна відповідно до офіційної документації редагувати користувацький `~/.config/kilo/kilo.jsonc` або проєктний `./kilo.jsonc`.

## 3. Перевірка

Виберіть `acedatacloud/MODEL_ID` і надішліть `Відповідайте лише OK`, після чого ще раз виконайте операцію лише для читання файлу. Якщо модель не з’явилася, перевірте, чи було надіслано Provider, чи назва моделі повністю збігається з `id` у каталозі, а також чи правильний Base URL.
