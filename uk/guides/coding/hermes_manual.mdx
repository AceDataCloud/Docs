## 1. Отримання API Key

Відкрийте [список застосунків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступного застосунку та скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Збереження Key

У `~/.hermes/.env` запишіть:

```dotenv
ACEDATACLOUD_API_KEY=ваш API Key
```

## 3. Налаштування Provider

Додайте до `~/.hermes/config.yaml`:

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

Перейдіть до [каталогу моделей](https://platform.acedata.cloud/models), щоб переглянути назви моделей (наприклад, `claude-opus-5`, `gpt-6-sol`), і замініть усі `MODEL_ID` на одну й ту саму назву; для точної перевірки орієнтуйтеся на значення `id` у відповіді `/v1/models`. Це значення є назвою моделі, яку використовує параметр API `model`, а не UUID сервісу чи API. Не записуйте справжній Key у YAML і не додавайте `.env` до комітів.

## 4. Перевірка

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

Якщо повертається 401, перевірте `~/.hermes/.env`; якщо конфігурація не застосувалася, повністю вийдіть і перезапустіть Hermes.
