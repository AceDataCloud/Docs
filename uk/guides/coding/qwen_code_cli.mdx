Qwen Code використовує `~/.qwen/settings.json` для налаштування `modelProviders`. Тут фіксовано використання протоколу, сумісного з OpenAI.

## Налаштування

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud` повинен бути масивом. Записи провайдера є незалежними налаштуваннями, не успадковують автоматично інші параметри верхнього рівня, заголовки або параметри тіла.

## Перевірка

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Reply only OK"
```

Увійдіть і надішліть `Reply only OK`, потім знову запустіть інструмент для читання файлів. Якщо суворо сумісний кінець відмовляється від формату результатів інструмента, будь ласка, перевірте поточну версію Qwen Code та офіційні вказівки щодо сумісності.
