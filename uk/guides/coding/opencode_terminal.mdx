## 1. Отримання API Key

Відкрийте [список застосунків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступного застосунку та скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Встановлення OpenCode

```bash
curl -fsSL https://opencode.ai/install | bash
```

Також можна використати npm:

```bash
npm install -g opencode-ai
```

## 3. Налаштування API Key

```bash
export ACEDATACLOUD_API_KEY="ваш API Key"
```

Щоб зміни діяли довгостроково, додайте цей рядок до `~/.zshrc` або `~/.bashrc`, а потім повторно відкрийте термінал.

## 4. Налаштування Provider

Відредагуйте `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ace Data Cloud",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  }
}
```

Перейдіть до [каталогу моделей](https://platform.acedata.cloud/models), щоб переглянути назви моделей (наприклад, `claude-opus-5`, `gpt-6-sol`), і замініть усі `MODEL_ID` на одну й ту саму назву; для точної перевірки орієнтуйтеся на значення `id` у відповіді `/v1/models`. Це значення є назвою моделі, що використовується параметром API `model`, а не UUID сервісу чи API. Ace Data Cloud тут використовує Chat Completions, тому adapter — `@ai-sdk/openai-compatible`.

## 5. Перевірка та запуск

```bash
opencode auth list
opencode models acedatacloud
opencode run --model acedatacloud/MODEL_ID "Reply only OK"
```

Потім запустіть `opencode` у каталозі проєкту. Якщо модель не відображається, перевірте шлях до файлу конфігурації, синтаксис JSON і змінні середовища; 401 означає, що Key недійсний або не експортований.

Розширення IDE повторно використовує ту саму конфігурацію OpenCode runtime, дивіться [OpenCode IDE Extension](https://platform.acedata.cloud/documents/opencode-ide-integration).
