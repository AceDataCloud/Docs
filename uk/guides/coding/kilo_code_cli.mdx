## 1. Отримати API Key

Відкрийте [список додатків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступних додатків і скопіюйте API Key.

![Отримати Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Конфігурація

Kilo CLI читає `kilo.jsonc` і отримує API Key з оболонки, з якої запускається CLI.

Запишіть у `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Потім у поточній оболонці експортуйте Token:

```bash
export ACEDATACLOUD_API_KEY="ВСТАВТЕ_ВАШ_ACEDATACLOUD_API_TOKEN_ТУТ"
```

## 3. Перевірка

```bash
kilo run -m acedatacloud/MODEL_ID "Відповідайте тільки OK"
```

Якщо CLI не може прочитати Token, переконайтеся, що змінна була `export`, а не просто записана в не завантажений `.env` файл.
