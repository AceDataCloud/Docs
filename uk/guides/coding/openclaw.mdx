## 1. Отримання API Key

Відкрийте [список додатків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступних додатків і скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Встановлення OpenClaw та плагіна

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

Плагін вимагає OpenClaw `2026.4.2` або новішої версії, наразі нативно надає можливості Chat та Web Search.

## 3. Конфігурація Key

Рекомендується використовувати onboarding:

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "ваш API Key"
```

Також можна використовувати змінні середовища:

```bash
export ACEDATACLOUD_API_KEY="ваш API Key"
```

## 4. Додатково: ручна конфігурація

Якщо не використовуєте onboarding, увімкніть плагін та налаштуйте модель за замовчуванням у `~/.openclaw/openclaw.json`:

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

Не записуйте API Key у цей файл; продовжуйте використовувати змінні середовища.

## 5. Вибір моделі та перевірка

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "Відповісти лише OK"
```

Замініть `MODEL_ID` на модель, яку наразі надає Coding Plan. Якщо потрібно встановити як модель за замовчуванням, виконайте:

```bash
openclaw models set acedatacloud/MODEL_ID
```

Записи викликів можна переглянути в [історії використання](https://platform.acedata.cloud/console/usages). 401 означає, що Key недійсний; якщо модель не існує, спочатку перевірте точний ID та версію плагіна. `cost: 0` у каталозі плагінів лише вказує на те, що OpenClaw не повторно оцінює, фактичні витрати все ще реєструються Ace Data Cloud.

## Web Search

```bash
openclaw infer web search \
  --provider acedatacloud --query "останні фреймворки AI агентів" --limit 5
```

Наразі не сприймайте можливості зображень, відео або музики, згадані в описі плагіна, як нативні можливості OpenClaw Provider.
