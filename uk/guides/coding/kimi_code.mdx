## 1. Отримання API Key

Відкрийте [список застосунків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступного застосунку та скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Встановлення Kimi Code

macOS / Linux:

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

Також можна встановити через npm:

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. Налаштування AceDataCloud

Відредагуйте `~/.kimi/config.toml`, додайте таку конфігурацію:

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "твій API Key"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

Перейдіть до [каталогу моделей](https://platform.acedata.cloud/models), щоб переглянути назви моделей (наприклад, `claude-opus-5`, `gpt-6-sol`), і замініть усі `MODEL_ID` на одну й ту саму назву; для точної перевірки орієнтуйтеся на значення `id` у відповіді `/v1/models`. Це значення є назвою моделі, що використовується параметром API `model`, а не UUID сервісу або API. `type = "openai"` використовує протокол OpenAI Chat Completions.

Файл конфігурації містить Key, для macOS / Linux рекомендується обмежити права доступу:

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. Перевірка та запуск

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

Після входу в проєкт запустіть `kimi`, щоб почати використання. Якщо повертається 401, перевірте API Key; якщо з’являється повідомлення model not found, переконайтеся, що `default_model`, назва в таблиці моделей і поле `model` використовують один і той самий ID.
