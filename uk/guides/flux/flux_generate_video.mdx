Flux Videos API використовує `POST /flux/videos` для генерації відео, генерації відео з ключових кадрів, продовження відео та покращення чернеток. `action=generate` (за замовчуванням), `mode` вибирає режим генерації; для запиту результатів уніфіковано використовується наявний `POST /flux/tasks`.

> Наразі Beta. Генерація відео з тексту, генерація відео із зображень, продовження відео та покращення чернеток уже доступні. HTTP 200 та ID завдання означають лише прийняття завдання, необхідно продовжувати запитувати остаточний результат.

## 1. Отримання API Token

1. Зареєструйтеся або увійдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications), створіть застосунок і отримайте API Token. Один універсальний API Token може викликати сервіси платформи; переконайтеся, що застосунок має права доступу до сервісу Flux і доступний баланс.
2. Перегляньте тарифи та ціни на кожну операцію на [сторінці сервісу Flux](https://platform.acedata.cloud/services/flux?tab=pricing). У разі недостатнього балансу поповніть його на [сторінці балансу консолі](https://platform.acedata.cloud/console/coin).
3. Запити використовують `Authorization: Bearer &lt;ваш Token>`. Token слід зберігати у змінних середовища на сервері, не записуйте його на фронтенд-сторінках, у публічних репозиторіях, скриншотах або callback URL.

![Отримання API Token у консолі](https://cdn.acedata.cloud/dvc3cg.jpg)

Код у цій статті уніфіковано зчитує змінну середовища:

```bash
export ACEDATACLOUD_API_TOKEN='замініть на свій власний API Token'
```

| Пункт      | Значення                                               |
| ------- | ----------------------------------------------- |
| Коренева адреса API | `https://api.acedata.cloud`                     |
| Надсилання відеозавдання  | `POST /flux/videos`                             |
| Запит наявного завдання  | `POST /flux/tasks`                              |
| Автентифікація      | `Authorization: Bearer $ACEDATACLOUD_API_TOKEN` |
| Формат запиту    | `Content-Type: application/json`                |

Повні поля та онлайн-налагодження дивіться в [Flux Videos API](https://platform.acedata.cloud/documents/flux-videos), запит завдань дивіться в [Flux Tasks API](https://platform.acedata.cloud/documents/flux-tasks)。

## 2. Вибір операції та введення

| action                      | mode            | Введення                       | Результат            |
| --------------------------- | --------------- | ------------------------ | ------------- |
| `generate` (значення за замовчуванням, якщо action пропущено) | `t2v`           | `prompt`                 | Генерація відео з тексту       |
| `generate`                  | `i2v`           | `prompt`、`keyframes`     | Генерація відео з одного або кількох ключових кадрів |
| `generate`                  | `v2v`           | `prompt`、`start_video`   | Продовження на основі вхідного відео      |
| `generate`                  | `draft_enhance` | `draft_task_id` власної завершеної чернетки | Покращення цієї чернетки         |

Модель генерації — `flux-3`, `action` — `generate` (за замовчуванням). Через `mode` вибираються генерація відео з тексту, генерація відео із зображень, продовження відео або покращення чернетки.

### Загальні параметри генерації

| Параметр                 | Опис                                                           |
| ------------------ | ------------------------------------------------------------ |
| `mode`             | Обов’язковий; `t2v`, `i2v`, `v2v` або `draft_enhance`                       |
| `prompt`           | Обов’язковий для звичайної генерації; для покращення чернетки не дозволяється перезаписувати оригінальний промпт                                        |
| `duration`         | Для t2v/i2v — ціле число 5–20 секунд, для v2v — ціле число 5–15 секунд, або `auto`; остаточна тривалість виводу може трохи відрізнятися від запитаного значення |
| `resolution`       | `hd`, `fhd`, `qhd`, `uhd`; для звичайної генерації за замовчуванням `hd`, для покращення чернетки за замовчуванням `fhd`              |
| `aspect_ratio`     | `auto`, `21:9`, `2:1`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `9:21`   |
| `draft`            | Чи спочатку генерувати чернетку; чернетки підтримують лише `hd`                                           |
| `generate_audio`   | Чи генерувати синхронний аудіосупровід; `false` є допустимим значенням, зберігайте явне булеве значення                               |
| `safety_tolerance` | Необов’язковий; ціле число 0–4                                                   |
| `async`            | Рекомендовано встановити `true`, щоб негайно повернути ID завдання платформи, а потім опитувати результати                                |
| `callback_url`     | Необов’язковий; HTTP(S)-адреса для отримання остаточного JSON-результату; після встановлення також прийматиметься асинхронно                        |

URL матеріалів мають бути доступними для читання сервісом. Якщо використовуються тимчасові підписані URL, слід передбачити достатній строк дії для завантаження та обробки. Не використовуйте адресу вебсторінки як адресу файлу зображення або відео.

## 3. Генерація відео з тексту: повний перевірений запит і результат

Наведений нижче запит успішно виконано у production-інтерфейсі до зміни цін 2026-10-02. Пропуск `action` підтвердив поведінку генерації за замовчуванням; `async=true` дозволяє уникнути тривалого очікування HTTP-з’єднання.

```bash
curl -X POST 'https://api.acedata.cloud/flux/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light, steady camera, no text.",
    "duration": 5,
    "resolution": "hd",
    "draft": true,
    "async": true
  }'
```

Відповідь про прийняття (реальний ID завдання):

```json
{
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607"
}
```

Збережіть `task_id` зі своєї відповіді та продовжуйте запит; не використовуйте ID завдання з прикладу в документації для запиту результатів інших облікових записів.

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"замініть на task_id, повернутий цього разу"}'
```

Поле `response`, повернуте запитом завдання, містить остаточний бізнес-результат. Нижче наведено `response` успішного результату цієї перевірки, без зовнішніх метаданих завдання. URL відео в документації замінено на копію того самого файлу в довгостроковому прикладному CDN (SHA-256 збігається), фактичний виклик поверне URL результату власного завдання цього разу:
```json
{
  "success": true,
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607",
  "data": [
    {
      "id": "4341eb66-3845-4972-bb86-712a6cfae845",
      "model": "flux-3",
      "video_url": "https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4",
      "seconds": 5.041667,
      "width": 1280,
      "height": 704,
      "fps": 24,
      "draft_task_id": "4341eb66-3845-4972-bb86-712a6cfae845"
    }
  ],
  "usage": {
    "action": "generate",
    "seconds": 5.041667,
    "output_mp_seconds": 4.3326825781250005,
    "mode": "t2v",
    "resolution": "hd",
    "draft": true
  },
  "cost": {
    "amount": 2.6884689277500002,
    "currency": "credit",
    "list_amount": 2.9871876975000005
  }
}
```

[Переглянути це тестове відео](https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4)。Перевірка медіа підтверджує, що вихідним файлом є MP4 із роздільною здатністю 1280×704, 24 fps і тривалістю 5.041667 секунди, розмір файлу — 2,607,276 байтів。

| Поле відповіді                              | Призначення                                       |
| --------------------------------- | ---------------------------------------- |
| `success`                         | Чи було остаточне завдання успішним; `task_id`, повернений на етапі прийняття, не означає `success=true` |
| `task_id`                         | ID завдання платформи, використовується для опитування та ідемпотентної обробки в бізнес-логіці                      |
| `trace_id`                        | Надається працівникам підтримки під час усунення несправностей                             |
| `data[].video_url`                | Доступна для читання адреса результату відео                               |
| `data[].seconds/width/height/fps` | Фактична тривалість, розміри та частота кадрів вихідного файлу, виміряні на сервері                       |
| `data[].draft_task_id`            | Вхідний ID покращення чернетки; з’являється лише під час повернення повторно використовуваної чернетки                  |
| `usage`                           | Остаточний обсяг використання для виставлення рахунку; не замінюйте фактичні `seconds` запитаним `duration`      |
| `cost.amount`                     | Credits, остаточно списані цього разу; `currency=credit` не є доларами США   |
| `cost.list_amount`                | Credits до знижки на споживання для користувачів застосунку; повертається за потреби                 |

Це історичне тестування до зміни цін: `list_amount=2.9871876975` Credits, обліковий запис тоді мав знижку на споживання 10%, а фактичний `amount=2.68846892775` Credits. Нова ціна від 2026-10-02 знижена приблизно на 6.33%; та сама чернетка тривалістю 5.041667 секунди за поточною ціною коштує 2.798125185 Credits (до знижки на споживання), а за наявності знижки на споживання 10% — 2.5183126665 Credits. Рахунки за історичні завдання не перераховуються. Тарифи й знижки інших облікових записів можуть відрізнятися; це не фіксована ціна в доларах США для всіх користувачів.

## 4. Зображення у відео: звичайні та з часовими ключовими кадрами

Нижче наведено приклади параметрів, потрібно замінити URL матеріалів; це не заява про те, що цей приклад уже успішно виконано. Після завершення генерації виконайте запит за наведеним вище процесом, структура результату буде такою самою.

Для одного або двох зображень використовуйте звичайний масив:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "The camera slowly moves around the product in soft studio light.",
  "keyframes": ["https://example.com/first-frame.jpg"],
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "async": true
}
```

Під час зазначення моментів ключових кадрів використовуйте пари `[секунди, URL зображення]`:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "A smooth transition from morning light to a warm sunset.",
  "keyframes": [[0, "https://example.com/start.jpg"], [5, "https://example.com/end.jpg"]],
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

Допускається 1–10 ключових кадрів. Масив із часом має бути відсортований за зростанням часу, час становить 0–20 секунд; не можна змішувати звичайні URL та елементи з часом. Для трьох або більше звичайних ключових кадрів потрібно явно вказати `duration`, не можна використовувати auto.

```json
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "draft": false,
  "mode": "i2v",
  "keyframes": [
    "<下图 PNG 文件的原始 base64 字符串>"
  ]
}
```

## 5. Продовження відео

Передайте адресу наявного відеофайлу в `start_video`, `mode=v2v`, максимальна тривалість — 15 секунд.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "v2v",
  "prompt": "Continue the sailboat drifting forward with the same steady camera.",
  "start_video": "https://example.com/source.mp4",
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

## 6. Спочатку чернетка, потім покращення

1. Згенеруйте чернетку з `draft=true`、`resolution=hd` і дочекайтеся успіху.
2. Візьміть ID чернетки платформи з остаточного `data[0].draft_task_id`.
3. Подайте запит на покращення за допомогою облікових даних застосунку того самого власника:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "draft_enhance",
  "draft_task_id": "替换为自己的已完成草稿 ID",
  "resolution": "fhd",
  "async": true
}
```

Під час покращення чернетки не можна передавати `prompt`、`duration`、`aspect_ratio`、`version`、`generate_audio`、`draft`、`keyframes`、`start_video` для перезапису початкового вмісту. Кеш чернетки є тимчасовим ресурсом, будь ласка, своєчасно виконуйте покращення; постійне зберігання або фіксована кількість днів зберігання не гарантуються. Чернетки не від вас/не з поточного застосунку, незавершені чернетки та кеші, що втратили чинність, не можуть використовуватися повторно. Чернетка та покращення є двома завданнями, після успіху за них стягується плата окремо.

### Фактичний результат тестування покращення чернетки

Повний вхідний запит цього фактичного тестування наведено нижче; під час відтворення покращення чернетки необхідно замінити на власний ID чернетки. Для URL матеріалу використовується довгострокова демонстраційна копія того самого файлу:

## 7. Наскрізний виклик Python

Встановіть `requests`, налаштуйте власний Token, запустіть наведений нижче скрипт, щоб завершити «одноразове подання → опитування → виведення URL відео». Для запитів і повторних мережевих спроб слід використовувати початковий task_id, щоб уникнути повторного подання платних завдань.
```python
import os
import time
import requests

base_url = "https://api.acedata.cloud"
headers = {
    "Authorization": "Bearer " + os.environ["ACEDATACLOUD_API_TOKEN"],
    "Accept": "application/json",
}
payload = {
    "action": "generate",
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "Невеликий іграшковий вітрильник, що пливе по спокійній блакитній воді в теплому ранковому світлі.",
    "duration": 5,
    "resolution": "hd",
    "draft": True,
    "async": True,
}
submitted = requests.post(base_url + "/flux/videos", json=payload, headers=headers, timeout=120)
submitted.raise_for_status()
accepted = submitted.json()
if accepted.get("error"):
    raise RuntimeError(accepted["error"])
task_id = accepted["task_id"]
print("ID завдання:", task_id)  # Зберігайте постійно для відновлення опитування

# 30 хвилин — це ліміт очікування клієнта в цьому прикладі, а не обіцянка терміну завершення сервісом.
deadline = time.monotonic() + 30 * 60
while time.monotonic() < deadline:
    polled = requests.post(
        base_url + "/flux/tasks",
        json={"action": "retrieve", "id": task_id},
        headers=headers,
        timeout=30,
    )
    polled.raise_for_status()
    task = polled.json()
    if task.get("error"):
        raise RuntimeError(task["error"])
    result = task.get("response") or task.get("result")
    if isinstance(result, dict) and result.get("success") is True:
        print("Відео:", result["data"][0]["video_url"])
        print("Використання:", result.get("usage"))
        print("Вартість:", result.get("cost"))
        break
    if isinstance(result, dict) and result.get("error"):
        raise RuntimeError(result["error"])
    time.sleep(10)
else:
    raise TimeoutError("Все ще обробляється; відновіть опитування з task_id=" + task_id)
```

Після тайм-ауту мережі не вважайте невідомий стан невдачею та не надсилайте запит повторно негайно. Якщо `task_id` уже отримано, продовжуйте запитувати це завдання; записуйте `task_id` і `trace_id` для спрощення діагностики. Сам інтерфейс опитування не стягує плату за генерацію.

## 8. Використання зворотного виклику

Додайте `callback_url` під час надсилання, і після завершення завдання остаточний результат JSON буде надіслано POST-запитом на цю адресу; структура успішного результату узгоджується з наведеним вище `response`, а у разі невдачі містить `error`.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "t2v",
  "prompt": "Невеликий вітрильник на спокійній воді.",
  "duration": 5,
  "resolution": "hd",
  "draft": true,
  "callback_url": "https://your-server.example/flux-callback"
}
```

Адреса зворотного виклику має бути доступною з публічного інтернету. Після отримання сповіщення обробляйте його ідемпотентно за `task_id`, якнайшвидше повертайте 2xx; бізнес-обробку можна поставити в чергу. У цьому документі не заявляється, що зворотний виклик має автентифікацію підписом: перед чутливими операціями, такими як надання бізнес-переваг, використовуйте власний Token, щоб запитати те саме завдання та звірити результат. Якщо зворотний виклик не отримано, також можна продовжувати опитування, не генеруйте повторно.

## 9. Поточне тарифікування та прайс-лист

Оновлено 2026-10-02: ціна за одиницю для кожного рівня цього інтерфейсу відео знижена приблизно на 6,33%; спосіб вимірювання, пакети та правила знижок на споживання залишаються незмінними. `cost` в історичному фактичному `response` вище є рахунком на момент завершення завдання та не представляє поточну ціну.

Генерація відео тарифікується за **фактичними секундами виводу**. Нижче наведено поточні ціни в Credits без застосування знижок на споживання облікового запису, що узгоджуються з правилами на [сторінці цін Flux](https://platform.acedata.cloud/services/flux?tab=pricing).

| Операція/режим              | Роздільна здатність | Ціна в Credits |
| ------------------ | --- | ---------: |
| Чернетка t2v / i2v       | hd  |  0.555 / секунда |
| Чернетка v2v             | hd  |   1.11 / секунда |
| t2v / i2v / покращення відповідної чернетки | hd  | 1.5725 / секунда |
| Те саме                 | fhd | 2.6825 / секунда |
| Те саме                 | qhd |    3.7 / секунда |
| Те саме                 | uhd |    7.4 / секунда |
| v2v / покращення відповідної чернетки       | hd  | 3.7925 / секунда |
| Те саме                 | fhd | 4.9025 / секунда |
| Те саме                 | qhd | 6.0125 / секунда |
| Те саме                 | uhd | 8.7875 / секунда |

Конвертація в долари США: `фактична вартість (USD) = cost.amount (Credits) × ціна пакета / кількість пакета`. Рівні поповнення та знижки на споживання впливають на фактичну ціну, Credits не можна безпосередньо вважати USD. За невдалі завдання плата за генерацію не стягується; остаточна сума визначається результатом завершення та записами викликів у консолі.

## 10. Поширені запитання та діагностика

| Ситуація                       | Рекомендація                                                   |
| ------------------------ | ---------------------------------------------------- |
| Помилка параметрів（400）                | Перевірте action=generate, mode, duration, формат ключових кадрів; не змішуйте поля різних режимів генерації |
| Помилка автентифікації（401）                | Перевірте Bearer Token, дозволи застосунку та дійсність облікових даних                          |
| Відхилення модерацією контенту（403）              | Скоригуйте матеріали та підказку, не надсилайте повторно без змін                                    |
| Обмеження швидкості（429）                  | Зменште паралелізм, повторіть спробу з відступом                                            |
| service_unavailable（503） | Поточна операція недоступна; уже прийняті асинхронні завдання можуть повідомити цю помилку в остаточному response                |
| task_id уже повернуто, але відео ще немає        | Продовжуйте запитувати response, не вважайте HTTP 200 завершенням генерації                     |
| Чернетку неможливо повторно використати                   | Переконайтеся, що це ваш/поточний застосунок, завдання завершено, початковий запит мав draft=true, і перевірте, чи тимчасовий кеш усе ще дійсний          |

Під час надання зворотного зв’язку вкажіть `task_id`, `trace_id`, час запиту та знеособлені параметри, не надсилайте API Token. Більше способів дивіться в [посібнику з інтеграції Flux MCP](https://platform.acedata.cloud/documents/flux-mcp).
