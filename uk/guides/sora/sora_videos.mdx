У цьому документі описується інструкція з інтеграції Sora Videos Generation API, за допомогою якого можна генерувати офіційні відео Sora, вводячи власні параметри. Цей API підтримує два режими:

- **Version 1 (класичний режим)**: підтримує параметри `duration` (10/15/25 секунд), `orientation` (горизонтальна/вертикальна орієнтація), `size` (small/large роздільна здатність), референсні зображення `image_urls`, посилання на персонажа `character_url` тощо.
- **Version 2 (режим для партнерів)**: підтримує `seconds` (4/8/12 секунд), роздільну здатність на рівні пікселів `size` (наприклад, 1280x720), референсні зображення `input_reference` тощо.

## Процес подачі заявки

Щоб використовувати API, спочатку потрібно подати заявку на відповідний сервіс на сторінці [Sora Videos Generation API](https://platform.acedata.cloud/documents/99a24421-2e22-4028-8201-e19cb834b67e). Після переходу на сторінку натисніть кнопку «Acquire», як показано на зображенні:

![](https://cdn.acedata.cloud/q6ytrc.png)

Якщо ви ще не увійшли або не зареєстровані, система автоматично перенаправить вас на сторінку входу/реєстрації. Після входу або реєстрації ви повернетесь на поточну сторінку.

При першій подачі заявки вам буде надано безкоштовний ліміт для безкоштовного використання API.

## Базове використання (Version 1)

Спершу розглянемо базовий спосіб використання Version 1: вводимо текст підказки `prompt`, масив посилань на референсні зображення `image_urls` та модель `model`, і отримуємо оброблений результат. Деталі наведені нижче:

<p><img src="https://cdn.acedata.cloud/h8dyz3.png" width="500" className="m-auto" /></p>

Тут ми налаштували заголовки запиту (Request Headers), зокрема:

- `accept`: формат відповіді, який хочемо отримати, тут вказано `application/json` (JSON формат).
- `authorization`: ключ для виклику API, який можна вибрати зі списку після подачі заявки.

Також налаштовано тіло запиту (Request Body), що містить:

- `model`: модель для генерації відео, підтримуються `sora-2` (стандартний режим) та `sora-2-pro` (режим HD). Модель `sora-2-pro` підтримує відео тривалістю 25 секунд, а `sora-2` — лише 10 або 15 секунд.
- `size`: роздільна здатність відео, `small` — стандартна, `large` — HD (тільки для Version 1).
- `duration`: тривалість відео, підтримуються 10, 15, 25 секунд (25 секунд підтримується лише `sora-2-pro`, тільки Version 1).
- `orientation`: орієнтація кадру, підтримується `landscape` (горизонтальна) та `portrait` (вертикальна) (тільки Version 1).
- `image_urls`: масив посилань на референсні зображення для генерації відео з картинки (тільки Version 1).
- `character_url`: посилання на персонажа (відео без реальних людей) (тільки Version 1).
- `character_start`/`character_end`: час появи персонажа у відео в секундах, різниця між ними 1-3 секунди (тільки Version 1).
- `prompt`: текст підказки (обов’язковий).
- `callback_url`: URL для асинхронного зворотного виклику.
- `version`: версія API, `1` (за замовчуванням) або `2`.

## Генерація відео з картинки (Version 1)

Для генерації відео з картинки параметр `image_urls` повинен містити посилання на референсні зображення. Можна вказати:

- `image_urls`: масив посилань на референсні зображення для генерації відео. Не можна передавати реальні зображення з обличчями людей, інакше задача може завершитися помилкою.

## Режим Version 2

Окрім Version 1, API підтримує режим Version 2, який активується встановленням параметра `version` у значення `2`. Version 2 підтримує коротші відео та контроль роздільної здатності на рівні пікселів.

### Пояснення параметрів Version 2

| Параметр       | Тип      | Обов’язковий | Опис                                      |
|----------------|----------|--------------|-------------------------------------------|
| `version`      | integer  | Так          | Встановити `2`                            |
| `prompt`       | string   | Так          | Текст підказки для генерації відео       |
| `model`        | string   | Ні           | `sora-2` (за замовчуванням) або `sora-2-pro` |
| `duration`     | integer  | Ні           | Тривалість відео: `4` (за замовчуванням), `8`, `12` секунд |
| `size`         | string   | Ні           | Роздільна здатність: `720x1280` (за замовчуванням), `1280x720`, `1024x1792`, `1792x1024` |
| `image_urls`   | array    | Ні           | Масив URL референсних зображень, використовується лише перше зображення, розмір повинен відповідати `size` |
| `callback_url` | string   | Ні           | URL для асинхронного зворотного виклику |

### Використання референсних зображень (Version 2)

У режимі Version 2 можна передати параметр `image_urls` для керування генерацією відео за допомогою референсного зображення (використовується лише перше зображення):

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "version": 2,
    "prompt": "a person walking through a beautiful garden",
    "model": "sora-2",
    "duration": 4,
    "size": "1280x720",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

> **Увага**: розмір референсного зображення повинен відповідати параметру `size`. Наприклад, якщо `size` встановлено в `1280x720`, то розмір зображення має бути 1280×720.

### Порівняння параметрів Version 1 та Version 2

| Параметр       | Version 1           | Version 2                                      |
|----------------|---------------------|-----------------------------------------------|
| `version`      | 1 (за замовчуванням) | 2                                             |
| `prompt`       | ✅                   | ✅                                             |
| `model`        | ✅ sora-2 / sora-2-pro | ✅ sora-2 / sora-2-pro                         |
| `duration`     | ✅ 10/15/25 секунд    | ✅ 4/8/12 секунд                               |
| `orientation`  | ✅ landscape/portrait | ❌                                             |
| `size`         | ✅ small/large        | ✅ 720x1280/1280x720/1024x1792/1792x1024      |
| `image_urls`   | ✅ кілька зображень   | ✅ лише перше зображення                        |
| `character_url`| ✅                    | ❌                                             |
| `callback_url` | ✅                    | ✅                                             |

## Асинхронний зворотний виклик (callback)

Оскільки генерація відео через Sora Videos Generation API займає приблизно 1-2 хвилини, а HTTP-запит може довго тримати з’єднання, що призводить до зайвого навантаження на систему, API підтримує асинхронний зворотний виклик.

Процес такий: клієнт при запиті вказує додатково поле `callback_url`. Після відправлення запиту API одразу повертає результат із полем `task_id` — ідентифікатором задачі. Коли задача завершиться, результат генерації відео буде надіслано POST-запитом у форматі JSON на вказаний `callback_url`, включно з полем `task_id`, що дозволяє зв’язати результат із задачею.

Webhook callback — це HTTP-сервіс, який приймає запити. Розробник повинен замінити URL на власний сервер. Для демонстрації використаємо публічний сервіс https://webhook.site/, де можна отримати унікальний Webhook URL, як показано на зображенні:

![](https://cdn.acedata.cloud/cjjfly.png)

## Обробка помилок

При виклику API у разі помилки повертається відповідний код та повідомлення. Наприклад:

- `400 token_mismatched`: некоректний запит, можливо, через відсутні або неправильні параметри.
- `400 api_not_implemented`: некоректний запит, можливо, через відсутні або неправильні параметри.
- `401 invalid_token`: неавторизований доступ, неправильний або відсутній токен.
- `429 too_many_requests`: перевищено ліміт запитів.
- `500 api_error`: внутрішня помилка сервера.
