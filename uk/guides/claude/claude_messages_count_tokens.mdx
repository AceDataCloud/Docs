Claude Messages Count Tokens API може обчислювати кількість вхідних токенів Message без фактичного створення повідомлення, включно з підрахунком токенів для таких матеріалів, як інструменти, зображення та документи. Це дуже корисно, коли потрібно оцінити вартість або перевірити, чи не перевищує введення обмеження контексту моделі.

Цей документ головним чином описує процес використання Claude Messages Count Tokens API.

## Процес подання заявки

Щоб використовувати Claude Messages Count Tokens API, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications), щоб отримати ваш API Token, і збережіть його для подальшого використання.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не увійшли або не зареєструвалися, вас буде автоматично перенаправлено на сторінку входу із запрошенням зареєструватися та увійти, після завершення ви автоматично повернетеся на поточну сторінку.

**Один API Token може викликати всі сервіси платформи, немає потреби подавати заявку окремо для кожного сервісу.** Під час першого подання заявки буде надано безкоштовний ліміт, щоб ви могли безкоштовно спробувати; коли ліміту недостатньо, ви можете поповнити загальний баланс у [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Базове використання

Шлях запиту Claude Messages Count Tokens API — `/v1/messages/count_tokens`, що відповідає офіційному API Anthropic. Нам потрібно надати щонайменше два обов’язкові параметри:

- `model`: виберіть використовувану модель Claude; `claude-opus-5-5` можна використовувати для Messages Token Count, як і найновішу флагманську `claude-fable-5-1`; попередня `claude-fable-5` все ще зберігається для сумісності.
- `messages`: масив вхідних повідомлень, кожне повідомлення містить `role` (роль) і `content` (вміст).

Поширені необов’язкові параметри:

- `system`: системний промпт, враховується в кількості Token.
- `tools`: визначення інструментів, враховуються в кількості Token.
- `thinking`: конфігурація розширеного мислення.
- `tool_choice`: конфігурація вибору інструменту.
- `cache_control`: конфігурація керування кешем верхнього рівня або рівня блоків вмісту.

`messages`, `system`, відтворення викликів інструментів, URL-зображення та блоки вмісту document/PDF використовують таку саму стабільну структуру запиту, як і Messages API.

### Приклад cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Приклад Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Приклад результату, що повертається:

```json
{
  "input_tokens": 11
}
```

### Використання Anthropic SDK

Claude Messages Count Tokens API приймає стабільну структуру запитів Anthropic SDK і може викликатися через бібліотеку `anthropic`. Інтерфейс використовує власну можливість Count Tokens, що відповідає вибраній моделі, для підрахунку введення та може використовуватися для перевірки обсягу введення перед надсиланням запиту Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Підрахунок Token із включеними інструментами

Якщо ваш запит містить визначення інструментів, ці інструменти також буде враховано в кількості Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Підрахунок Token із включеним системним промптом

Системний промпт також буде враховано в кількості Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Примітки

- Цей API лише обчислює кількість вхідних Token і не створює жодного виводу моделі.
- Результат підрахунку Token можна використовувати для оцінки обсягу введення та перевірки контекстного вікна; остаточна оплата визначається на основі `usage` у фактичній відповіді Messages.
- Зображення, PDF, визначення інструментів, системні промпти та конфігурації thinking буде включено до результату відповідно до правил введення вибраної моделі.
- Цей API є повністю безкоштовним і не витрачає жодних лімітів.
