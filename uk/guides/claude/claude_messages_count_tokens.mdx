API Claude Messages Count Tokens може обчислювати кількість вхідних Token одного Message без фактичного створення повідомлення, включно з підрахунком Token для таких матеріалів, як інструменти, зображення та документи. Це дуже корисно, коли потрібно оцінити вартість або перевірити, чи не перевищує введення обмеження контексту моделі.

У цьому документі переважно представлено процес використання API Claude Messages Count Tokens.

## Процес подання заявки

Щоб використовувати API Claude Messages Count Tokens, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications), щоб отримати ваш API Token і зберегти його для подальшого використання.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не ввійшли або не зареєструвалися, вас буде автоматично перенаправлено на сторінку входу, де вам буде запропоновано зареєструватися та ввійти; після завершення ви автоматично повернетеся на поточну сторінку.

**Один API Token може викликати всі сервіси платформи, не потрібно подавати заявку окремо для кожного сервісу.** Під час першого подання заявки надається безкоштовний ліміт для безкоштовного ознайомлення; коли ліміту недостатньо, ви можете поповнити загальний баланс у [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Базове використання

Шлях запиту API Claude Messages Count Tokens — `/v1/messages/count_tokens`, що відповідає офіційному API Anthropic. Нам потрібно щонайменше надати два обов'язкові параметри:

- `model`: вибір моделі Claude для використання; `claude-opus-5-5` можна використовувати для Messages Token Count, як і новітню флагманську модель `claude-fable-5-1`; попередня `claude-fable-5` усе ще збережена для сумісності. `claude-sonnet-5-5` додано до нативного інтерфейсу серії Messages, він підтримує введення зображень та адаптивне мислення; його офіційні довідкові ціни на введення, виведення та читання кешу становлять 2, 10 і 0,20 долара США за мільйон Token відповідно.
- `messages`: масив вхідних повідомлень, кожне повідомлення містить `role` (роль) і `content` (вміст).

Поширені необов'язкові параметри:

- `system`: системний промпт, враховується в кількості Token.
- `tools`: визначення інструментів, враховуються в кількості Token.
- `thinking`: конфігурація розширеного мислення.
- `tool_choice`: конфігурація вибору інструменту.
- `cache_control`: конфігурація керування кешем верхнього рівня або на рівні блоків вмісту.

`messages`, `system`, відтворення викликів інструментів, URL-зображення та блоки вмісту document/PDF використовують ту саму стабільну структуру запитів, що й Messages API.

### Приклад cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Приклад Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Приклад результату відповіді:

```json
{
  "input_tokens": 11
}
```

### Використання Anthropic SDK

API Claude Messages Count Tokens приймає стабільну структуру запитів Anthropic SDK і може викликатися через бібліотеку `anthropic`. Інтерфейс використовує нативну можливість Count Tokens, що відповідає вибраній моделі, для підрахунку введення; його можна використовувати для перевірки обсягу введення перед надсиланням запиту Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Підрахунок Token з інструментами

Якщо ваш запит містить визначення інструментів, ці інструменти також враховуються в кількості Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Підрахунок Token із системним промптом

Системний промпт також враховується в кількості Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Зауваження

- Цей API обчислює лише кількість вхідних Token і не створює жодного виведення моделі.
- Результат підрахунку Token можна використовувати для оцінки обсягу введення та перевірки контекстного вікна; остаточна тарифікація визначається `usage` у фактичній відповіді Messages.
- Зображення, PDF, визначення інструментів, системні промпти та конфігурація thinking враховуються в результаті відповідно до правил введення вибраної моделі.
- Цей API є повністю безкоштовним і не витрачає жодного ліміту.
