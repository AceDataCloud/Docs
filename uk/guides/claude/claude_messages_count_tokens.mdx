Claude Messages Count Tokens API може без фактичного створення повідомлень обчислити кількість вхідних токенів для одного повідомлення, включаючи токен-лічильник для інструментів, зображень та документів. Це дуже корисно, коли потрібно оцінити витрати або перевірити, чи не перевищує вхідне повідомлення обмеження контексту моделі.

Цей документ в основному описує процес використання Claude Messages Count Tokens API.

## Основне використання

Запит до Claude Messages Count Tokens API має шлях `/v1/messages/count_tokens`, що відповідає офіційному API Anthropic. Нам потрібно надати принаймні два обов'язкових параметри:

- `model`: вибір моделі Claude, наприклад, `claude-opus-4-8`, `claude-sonnet-4-6` тощо.
- `messages`: масив вхідних повідомлень, кожне з яких містить `role` (роль) та `content` (вміст).

Звичайні необов'язкові параметри:

- `system`: системне підказування, яке враховується в кількості токенів.
- `tools`: визначення інструментів, яке враховується в кількості токенів.
- `thinking`: конфігурація розширеного мислення.
- `tool_choice`: конфігурація вибору інструментів.
- `cache_control`: конфігурація контролю кешування на верхньому або блочному рівні.

`messages`, `system`, виклики інструментів, URL зображень та блоки вмісту документів/PDF використовують таку ж стабільну структуру запиту, як і Messages API.

### cURL приклад

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-opus-4-8",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python приклад

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-opus-4-8",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Приклад повернутого результату:

```json
{
  "input_tokens": 11
}
```

### Використання Anthropic SDK

Claude Messages Count Tokens API приймає стабільну структуру запиту Anthropic SDK, яку можна викликати через бібліотеку `anthropic`. Поточне значення повертається локальним оцінювачем Ace Data Cloud і не є точним результатом офіційного токенізатора Anthropic; фактична кількість токенів для мультимодальних, інструментальних та різних моделей Claude може відрізнятися.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Облік токенів з інструментами

Якщо ваш запит містить визначення інструментів, ці інструменти також будуть враховані в кількості токенів:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Облік токенів з системними підказками

Системні підказки також будуть враховані в кількості токенів:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Зверніть увагу

- Цей API лише обчислює кількість вхідних токенів і не генерує жодного виходу моделі.
- Результати обліку токенів можуть бути використані для грубої оцінки обсягу вхідних даних і не повинні використовуватися як точна основа для виставлення рахунків, контролю вікна контексту або порівняння токенізаторів моделі.
- Поточний оцінювач не обчислює точно токени зображень і PDF, а також не відображає відмінності офіційних токенізаторів різних моделей Claude.
- Цей API абсолютно безкоштовний і не витрачає жодних лімітів.
