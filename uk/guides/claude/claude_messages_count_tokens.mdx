Claude Messages Count Tokens API може обчислювати кількість вхідних Token одного Message без фактичного створення повідомлення, включно з підрахунком Token для таких матеріалів, як інструменти, зображення та документи. Це дуже корисно, коли потрібно оцінити вартість або перевірити, чи не перевищує введення обмеження контексту моделі.

У цьому документі переважно описано процес використання Claude Messages Count Tokens API.

## Процес подання заявки

Щоб використовувати Claude Messages Count Tokens API, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications), щоб отримати свій API Token і зберегти його для подальшого використання.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не ввійшли в систему або не зареєструвалися, вас буде автоматично перенаправлено на сторінку входу із запрошенням зареєструватися та ввійти в систему; після завершення вас буде автоматично повернуто на поточну сторінку.

**Один API Token може викликати всі сервіси платформи, не потрібно подавати окрему заявку для кожного сервісу.** Під час першого подання заявки надається безкоштовна квота для безкоштовного ознайомлення; коли квоти недостатньо, ви можете поповнити загальний баланс у [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Базове використання

Шлях запиту Claude Messages Count Tokens API — `/v1/messages/count_tokens`, що відповідає офіційному API Anthropic. Потрібно надати щонайменше два обов’язкові параметри:

- `model`: вкажіть повний ID моделі зі списку моделей цього інтерфейсу та використовуйте ту саму модель у подальших запитах Messages.
- `messages`: масив вхідних повідомлень, де кожне повідомлення містить `role` (роль) і `content` (вміст).

Поширені необов’язкові параметри:

- `system`: системний промпт, який враховується в кількості Token.
- `tools`: визначення інструментів, які враховуються в кількості Token.
- `thinking`: конфігурація розширеного мислення.
- `tool_choice`: конфігурація вибору інструменту.
- `cache_control`: конфігурація керування кешем верхнього рівня або рівня блоку вмісту.

`messages`, `system`, відтворення викликів інструментів, URL-зображення та блоки вмісту document/PDF використовують ту саму стабільну структуру запитів, що й Messages API.

### Приклад cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Приклад Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Приклад результату відповіді:

```json
{
  "input_tokens": 11
}
```

### Використання Anthropic SDK

Claude Messages Count Tokens API приймає стабільну структуру запитів Anthropic SDK і може викликатися через бібліотеку `anthropic`. Інтерфейс підраховує вхідні Token відповідно до вибраної моделі та може використовуватися для перевірки обсягу введення перед надсиланням запиту Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Підрахунок Token з інструментами

Якщо ваш запит містить визначення інструментів, ці інструменти також будуть враховані в кількості Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Підрахунок Token із системним промптом

Системний промпт також буде врахований у кількості Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Примітки

- Цей API обчислює лише кількість вхідних Token і не створює жодного виводу моделі.
- Результат підрахунку Token може використовуватися для оцінки обсягу введення та перевірки контекстного вікна; остаточна вартість визначається за `usage` у фактичній відповіді Messages.
- Зображення, PDF, визначення інструментів, системні промпти та конфігурація thinking будуть включені в результат відповідно до правил введення вибраної моделі.
- Цей API повністю безкоштовний і не витрачає жодної квоти.
