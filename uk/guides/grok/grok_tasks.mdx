Основна функція Grok Tasks API полягає у запиті стану виконання завдання за допомогою ID завдання, згенерованого Grok Videos Generation API.

Цей документ детально описує інструкції з інтеграції Grok Tasks API, щоб допомогти вам легко інтегруватися та перевіряти стан виконання завдань Grok Videos Generation API.

## Процес подачі заявки

Щоб використовувати Grok Tasks API, спочатку потрібно подати заявку на відповідний сервіс на сторінці [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos) та скопіювати ID завдання, який повертає Grok Videos Generation API.

Потім перейдіть на сторінку [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) для подачі заявки на відповідний сервіс. Після входу на сторінку натисніть кнопку «Acquire».

Якщо ви ще не увійшли або не зареєстровані, вас автоматично перенаправить на [сторінку входу](https://platform.acedata.cloud) з пропозицією зареєструватися або увійти. Після входу або реєстрації ви автоматично повернетеся на поточну сторінку.

Під час першої заявки надається безкоштовний ліміт, який дозволяє безкоштовно використовувати цей API.

## Приклад запиту

Grok Tasks API можна використовувати для запиту результатів Grok Videos Generation API.

### Налаштування заголовків запиту та тіла запиту

**Request Headers** включають:

- `accept`: вказує, що приймається відповідь у форматі JSON, тут потрібно вказати `application/json`.
- `authorization`: ключ для виклику API, який можна вибрати зі списку після подачі заявки.

**Request Body** включає:

- `id`: ID завдання, яке потрібно перевірити.
- `action`: спосіб дії з завданням, для одиничного запиту вказується `retrieve`.

### Приклад коду CURL

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Приклад відповіді

Після успішного запиту API поверне детальну інформацію про завдання. Поле `request` містить тіло запиту, з яким було створено завдання, а поле `response` — тіло відповіді після завершення завдання, наприклад:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Опис полів:

- `id`: ID створеного завдання, який унікально ідентифікує це завдання.
- `request`: інформація про запит, з яким створювалося завдання.
- `response`: інформація про відповідь на запит після виконання завдання.

## Масовий запит

Для запиту деталей кількох завдань одночасно встановіть `action` у значення `retrieve_batch` та передайте масив ID завдань через `ids`:

**Request Body** включає:

- `ids`: масив ID завдань, які потрібно перевірити.
- `action`: спосіб дії з завданнями, для масового запиту вказується `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
