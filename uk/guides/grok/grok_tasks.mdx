Основна функція Grok Tasks API полягає в тому, щоб за допомогою введеного ID завдання, згенерованого Grok Videos Generation API, перевіряти стан виконання цього завдання.

Цей документ детально описує інструкції з інтеграції Grok Tasks API, щоб допомогти вам легко інтегрувати та перевіряти стан виконання завдань Grok Videos Generation API.

## Процес подачі заявки

Щоб використовувати Grok Videos Generation API, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications) для отримання вашого API Token, зберігайте його для подальшого використання.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, щоб запросити реєстрацію та вхід, після чого ви будете автоматично повернені на цю сторінку.

**Один API Token дозволяє викликати всі послуги платформи, не потрібно окремо запитувати для кожної послуги.** Перший запит надає безкоштовний ліміт, щоб ви могли безкоштовно протестувати; при недостатньому ліміті ви можете поповнити загальний баланс в [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [Grok Videos Generation API →](https://platform.acedata.cloud/documents/grok-videos)

## Приклад запиту

Grok Tasks API можна використовувати для перевірки результатів Grok Videos Generation API.

### Налаштування заголовків запиту та тіла запиту

**Request Headers** включає:

- `accept`: вказує на прийняття відповіді у форматі JSON, тут вказується `application/json`.
- `authorization`: ключ для виклику API, після запиту можна вибрати з випадаючого списку.

**Request Body** включає:

- `id`: ID завдання, яке потрібно перевірити.
- `action`: спосіб виконання операції над завданням, для одиночного запиту вказується `retrieve`.

### Приклад коду CURL

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Приклад відповіді

Після успішного запиту API поверне детальну інформацію про це завдання. Поле `request` містить body запиту, що ініціював завдання, а поле `response` містить body відповіді, що повертається після завершення завдання, наприклад:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262729.623,
  "elapsed": 7.8,
  "request": {
    "prompt": "Кінематографічний кадр кошеняти, що переслідує метелика в сонячному саду",
    "model": "grok-imagine-video-1.5-fast:reverse",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video-1.5-fast:reverse:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Опис полів:

- `id`: ID згенерованого завдання, що унікально ідентифікує це завдання.
- `request`: інформація про запит у завданні.
- `response`: інформація про відповідь у завданні.
- `created_at`: час створення завдання, Unix timestamp (секунди, з плаваючою комою).
- `started_at`: час початку виконання завдання, Unix timestamp (секунди, з плаваючою комою).
- `finished_at`: час завершення завдання, Unix timestamp (секунди, з плаваючою комою). Поле не повертається, якщо завдання не завершено.
- `elapsed`: час виконання завдання, в секундах (з плаваючою комою, з 3 знаками після коми). Поле не повертається, якщо завдання не завершено.

## Пакетний запит

Для перевірки деталей кількох ID завдань, встановіть `action` на `retrieve_batch` і передайте масив ID завдань через `ids`:

**Request Body** включає:

- `ids`: масив ID завдань, які потрібно перевірити.
- `action`: спосіб виконання операції над завданням, для пакетного запиту вказується `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
