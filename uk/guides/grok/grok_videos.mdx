Ця стаття ознайомить з інструкцією щодо інтеграції API Grok Videos Generation, який дозволяє генерувати відео Grok Imagine (xAI) шляхом введення текстових підказок, зображень та за бажанням референсних картинок.

## Процес подання заявки

Щоб використовувати API, потрібно спершу подати заявку на відповідній сторінці [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos). Після входу на сторінку натисніть кнопку «Acquire», як показано нижче:

![](https://cdn.acedata.cloud/q6ytrc.png)

Якщо ви ще не увійшли або не зареєстровані, система автоматично перенаправить вас на сторінку входу для реєстрації та входу, після чого поверне вас назад на цю сторінку.

Перший раз при поданні заявки вам буде надано безкоштовний кредит для безкоштовного використання API.

## Опис моделей

Цей API підтримує дві моделі:

- `grok-imagine-video` (за замовчуванням): підтримує текстове відео (тільки `prompt`) та відео з зображення (`image_url`), має нижчу ціну.
- `grok-imagine-video-1.5-preview`: підтримує лише відео з зображення, **обов’язково** потрібно передати `image_url`.

## Основне використання

Спершу ознайомимося з базовим способом використання — потрібно ввести параметри `prompt`, `model` тощо, і отримати відповідне відео.

Зверніть увагу, що тут налаштовано заголовки запиту, зокрема:

- `accept`: формат відповіді, який очікуємо отримати, тут — `application/json`, тобто JSON.
- `authorization`: ключ доступу до API, який можна вибрати з випадаючого списку після реєстрації.

Також налаштовано тіло запиту (`Request Body`), що містить:

- `prompt`: текстовий опис бажаного відео. Обов’язково для `grok-imagine-video`; опціонально при передачі `image_url`.
- `model`: модель для генерації відео, за замовчуванням `grok-imagine-video` або `grok-imagine-video-1.5-preview`.
- `image_url`: посилання на зображення для відео з зображення. Обов’язково для `grok-imagine-video-1.5-preview`.
- `reference_image_urls`: опційний масив посилань на референсні зображення для керування стилем або змістом відео.
- `aspect_ratio`: співвідношення сторін відео, опційно: `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`.
- `resolution`: роздільна здатність вихідного відео, опційно: `480p` (за замовчуванням) або `720p`, вища роздільна здатність — більший споживчий кредит.
- `duration`: тривалість відео в секундах, діапазон 1–15, за замовчуванням 8. Оплачується за фактичну тривалість.
- `callback_url`: асинхронна URL-адреса для зворотного виклику, після її вказання API одразу поверне `task_id`, а коли завдання завершиться — надішле результат POST-запитом.

Для тестування натисніть кнопку «Try», і отримаєте результат, схожий на цей:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/grok/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Розглянемо поля відповіді:

- `success`: чи вдалося успішно створити відео.
- `task_id`: ідентифікатор завдання.
- `trace_id`: ідентифікатор трекінгу запиту для діагностики.
- `data`: список результатів створення відео.
  - `id`: унікальний ідентифікатор відео.
  - `video_url`: посилання на згенероване відео.
  - `state`: статус завдання — `pending`, `succeeded`, `failed`.

Для отримання відео потрібно перейти за `video_url`.

Приклад CURL-запиту:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "resolution": "480p",
  "duration": 8
}'
```

Приклад Python-коду:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Відео з зображення

Щоб створити відео на основі одного зображення, потрібно передати `image_url`. Для моделі `grok-imagine-video-1.5-preview` це обов’язково:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5-preview",
  "image_url": "https://cdn.acedata.cloud/grok/example-input.png",
  "resolution": "720p",
  "duration": 8
}
```

## Використання референсних зображень

Щоб керувати стилем або змістом відео за допомогою однієї або кількох референсних картинок, додайте їх у `reference_image_urls`:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/grok/example-reference.png"
  ]
}
```

## Асинхронний зворотній зв’язок

Створення відео може зайняти деякий час. Якщо не бажаєте чекати у довгому з’єднанні, вкажіть `callback_url`. У цьому випадку API одразу поверне `task_id`, а коли завдання завершиться — надішле результат POST-запитом на цю адресу:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "duration": 8,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

Приклад відповіді:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Перевірка статусу завдання

Якщо використовуєте асинхронний режим або бажаєте самостійно перевіряти статус, можна зробити запит до [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) з `task_id`, щоб отримати актуальний статус і результати.

## Інформація про оплату

Цей сервіс оплачується за кількістю створених секунд відео, ціна залежить від `model` та `resolution`. Загальна вартість = ціна за секунду × `duration` (за замовчуванням 8 секунд). Вища роздільна здатність (`720p`) коштує дорожче за `480p`, а `grok-imagine-video-1.5-preview` — дорожче за `grok-imagine-video`. Конкретні ціни дивіться на ціновій сторінці.

## Обробка помилок

При виникненні проблем API поверне відповідний код помилки та опис. Найчастіші:

- `400`: неправильні параметри запиту, наприклад, відсутній `prompt` для текстового відео, або `image_url` для `grok-imagine-video-1.5-preview`, або `duration` поза межами 1–15.
- `401`: помилка автентифікації — токен недійсний або не співпадає.
- `403`: недостатньо балансу або контент підпадає під фільтр.
- `429`: занадто часті запити, перевищено ліміт — спробуйте пізніше.
- `500`: внутрішня помилка сервера або невдача генерації з боку системи.
