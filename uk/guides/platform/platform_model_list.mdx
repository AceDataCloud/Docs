---
title: "Отримання списку моделей платформи AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Повертає публічний каталог моделей платформи, відповідь використовує структуру у стилі OpenAI `{ "object": "list", "data": [...] }`. Цей каталог використовується для вибору моделей і виявлення можливостей, але не означає, що поточний обліковий запис обов’язково вже подав заявку на відповідну послугу.

## Огляд інтерфейсу

| Пункт   | Вміст                                              |
| --- | ----------------------------------------------- |
| Метод  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| Авторизація  | Публічний, токен облікового запису не потрібен                                       |
| Пагінація  | Без пагінації, усі відповідні елементи знаходяться в `data`                              |

## Параметри запиту

| Параметр             | Тип      | Обов’язковий  | Опис                                      |
| -------------- | ------- | --- | --------------------------------------- |
| `owned_by`     | string  | Ні   | Точна фільтрація за ідентифікатором постачальника моделі в каталозі                        |
| `type`         | string  | Ні   | Точна фільтрація за типом моделі, наприклад `chat`                     |
| `capability`   | string  | Ні   | Повертає лише моделі, чиї `capabilities` містять цю можливість, наприклад `vision` |
| `with_pricing` | boolean | Ні   | Додає публічну інформацію про ціни, коли має значення `1`, `true` або `yes`            |

`service_id`, `tag`, `limit`, `offset` і `ordering` наразі не підтримуються; їх передавання не створює відповідного ефекту фільтрації або пагінації.

## Приклади запитів

```shell
# 全部公开模型
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# 支持视觉的 chat 模型，并附价格
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## Структура фактичної відповіді

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

`pricing` і верхньорівневий `credit_usd_rate` з’являються лише за умови `with_pricing=true`; не кожна модель має придатний для обчислення `pricing`. Об’єкти моделей визначаються публічними полями з `config/models.json`, клієнти мають ігнорувати нові поля.

> Цінові поля є даними для відображення в каталозі. Фактичні бізнес-виклики все одно визначаються правилами тарифікації відповідного API/Service і остаточними записами про використання.
