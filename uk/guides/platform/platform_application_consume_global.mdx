---
title: "Налаштування спільного використання глобального балансу AceDataCloud Application"
description: "Platform API guide - Ace Data Cloud"
---

Налаштуйте `allow_consume_global`. Після увімкнення відповідні Application з оплатою за використання можуть продовжувати використовувати глобальний баланс облікового запису, коли їхнього власного балансу недостатньо.

## Підготовка

- Створіть і безпечно збережіть [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Отримайте `application_id` Application, яким ви володієте, зі [списку заявок на послуги](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='ваш токен облікового запису'
export APPLICATION_ID='ваш Application ID'
```

## Огляд інтерфейсу

| Пункт    | Вміст                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------- |
| Метод   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Авторизація   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

У разі успіху повертається оновлений об’єкт Application. Орієнтуйтеся на `allow_consume_global` у відповіді, а не припускайте, що значення запиту обов’язково було збережене.

> Application типу `Period` не дозволяється витрачати глобальний баланс. Навіть якщо надіслати запит `true`, сервер збереже для цього поля значення `false`.

## Обробка помилок

- `401`: Account Token недійсний або відсутній.
- `403`: поточний обліковий запис не є власником цього Application.
- `404`: Application ID не існує.

Точка поповнення глобального балансу та доступні пакети визначаються платформною консоллю і фактичними пакетами, що повертаються під час [створення замовлення](https://platform.acedata.cloud/documents/platform-order-create); не припускайте існування пакетів типу `Wallet`.
