Модель Provider, IDE Extension та MCP OpenCode є трьома незалежними можливостями. IDE Extension підключається до локального OpenCode runtime і повторно використовує ту ж конфігурацію Provider; вона не представляє рідну підтримку Ace Data Cloud в хост-редакторі.

| Маршрут                        | Опис                                                      | Посилання                                                                                 | Статус      |
| ----------------------------- | ------------------------------------------------------- | -------------------------------------------------------------------------------------- | ------- |
| Terminal / CLI / TUI Provider | Використання `opencode.json[c]` та Chat Completions                | [Конфігурація Provider](https://platform.acedata.cloud/documents/opencode-terminal-integration) | Підтверджена конфігурація контракту |
| IDE Extension                 | VS Code, Cursor, Windsurf, VSCodium та інші хости підключаються до OpenCode runtime | [Конфігурація IDE](https://platform.acedata.cloud/documents/opencode-ide-integration)           | Експериментальна     |
| MCP                           | Виклик віддалених інструментів в OpenCode                                      | [Огляд MCP](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | Незалежна можливість    |

Після успішної конфігурації Provider, IDE Extension повинна використовувати той же Provider та модель. Все ще потрібно окремо перевірити чат, читання файлів, редагування та виклик інструментів в IDE, не слід автоматично екстраполювати один звичайний запит CLI на всі можливості IDE.

ID моделі визначається за [реальним каталогом](https://platform.acedata.cloud/models).
