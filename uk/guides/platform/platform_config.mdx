Зчитує публічні перемикачі функцій і визначення країни/регіону в контексті поточного запиту. Підходить для визначення під час запуску фронтенду, чи слід відображати функції; це не назва бренду сайту, контактні дані або каталог оголошень.

## Огляд API

| Пункт   | Вміст                                              |
| --- | ----------------------------------------------- |
| Метод  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Авторизація  | Публічна; за наявності стану входу деякі перемикачі функцій можуть обчислюватися для користувача                          |

## Параметри запиту та заголовки

| Назва                    | Розташування     | Опис                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | Дволітерний ASCII-код країни; використовується для перевизначення країни відображення у відповіді, не змінюючи серверну перевірку безпеки |
| `features`            | query  | Вираз перевизначення перемикачів функцій; діє лише для перемикачів, яким дозволене клієнтське перевизначення, або для суперадміністраторів        |
| `X-Feature-Overrides` | header | Те саме джерело перевизначення, що й `features`                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## Фактична структура відповіді

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| Поле         | Тип            | Опис                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Перемикачі функцій, видимі для поточного запиту; ключі змінюються залежно від конфігурації платформи, клієнт повинен зчитувати їх за потреби та встановлювати безпечні значення за замовчуванням для відсутніх ключів |
| `country`  | string / null | Код країни у нижньому регістрі; якщо його неможливо визначити, може бути `null`                     |

Не зчитуйте з цього API назву сайту, CDN, валюту, мову, контактні дані служби підтримки або оголошення; ці поля не належать до поточного контракту відповіді.

## Рекомендації щодо використання

- Перемикачі функцій обчислюються відповідно до користувача, відбитка та контексту сайту, не використовуйте довготривалий спільний кеш між користувачами.
- Переданий клієнтом `country` впливає лише на значення, що повертається, і не обходить серверні регіональні політики або політики безпеки.
- Нерозпізнані параметри query ігноруються; використовуйте лише параметри, наведені на цій сторінці.
