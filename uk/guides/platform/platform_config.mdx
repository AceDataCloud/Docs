Зчитує публічні перемикачі функцій і визначення країни/регіону в контексті поточного запиту. Підходить для визначення під час запуску фронтенду, чи потрібно відображати функції; це не назва бренду сайту, контактні дані або каталог оголошень.

## Огляд інтерфейсу

| Пункт   | Вміст                                              |
| --- | ----------------------------------------------- |
| Метод  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Авторизація  | Публічна; за наявності стану входу деякі перемикачі функцій можуть обчислюватися для користувача                          |

## Параметри запиту та заголовки

| Назва                    | Розташування     | Опис                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | Вираз перевизначення перемикачів функцій; діє лише для перемикачів, яким дозволено перевизначення клієнтом, або для суперадміністратора |
| `X-Feature-Overrides` | header | Джерело перевизначення, таке саме, як `features`           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## Структура фактичної відповіді

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| Поле         | Тип            | Опис                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Перемикачі функцій, видимі для поточного запиту; ключі змінюватимуться залежно від конфігурації платформи, клієнт має зчитувати їх за потреби та встановлювати безпечні значення за замовчуванням для відсутніх ключів |
| `region`   | string / null | Код країни або регіону, визначений за IP запиту, у нижньому регістрі; якщо визначити неможливо — `null`        |

Не зчитуйте з цього інтерфейсу назву сайту, CDN, валюту, мову, контактні дані служби підтримки або оголошення; ці поля не належать до поточного контракту відповіді.

## Рекомендації щодо використання

- Перемикачі функцій обчислюються за користувачем, відбитком і контекстом сайту, не використовуйте довготривале спільне кешування між користувачами.
- Вибір селектора регіону зберігається лише на фронтенді; під час відображення пріоритетно використовуйте вибраний регіон, інакше використовуйте `region` цього інтерфейсу. Цей інтерфейс не приймає параметри перевизначення регіону.
- Нерозпізнані query-параметри буде проігноровано; використовуйте лише параметри, наведені на цій сторінці.
