---
title: "Отримання списку API у сервісі платформи AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Повертає поточні увімкнені та не застарілі API цього сервісу посторінково через Service UUID. Якщо є лише alias, спочатку викличте [деталі сервісу](https://platform.acedata.cloud/documents/platform-service-detail), щоб отримати `id`.

## Огляд інтерфейсу

| Пункт   | Вміст                                                                  |
| --- | ------------------------------------------------------------------- |
| Метод  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| Авторизація  | Публічний, токен облікового запису не потрібен                                                           |
| Пагінація  | `count` + `items`                                                   |

## Параметри

| Параметр           | Розташування    | Обов'язковий  | Опис                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | Так   | Service UUID, alias не підтримується           |
| `limit`      | query | Ні   | Кількість записів на сторінці, максимум 100                      |
| `offset`     | query | Ні   | Зсув пагінації                            |
| `ordering`   | query | Ні   | Вираз сортування Django; рекомендовано `rank` або `-rank` |

Поточний інтерфейс не підтримує фільтрацію за `stage`; він уже виключає API `Deprecated`.

```shell
export SERVICE_ID='Ваш Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

Елементи списку використовують таку саму індексну структуру, як і [список API платформи](https://platform.acedata.cloud/documents/platform-api-list), і наразі містять `definition`. Якщо потрібна стабільна точка входу для окремого API, продовжуйте викликати `/api/v1/apis/{api_id}`.

## Обробка помилок

- Сервіс не існує або не видимий на поточному сайті: `404`.
- `service_id` має бути UUID; alias не буде розв’язано в цій дії.
