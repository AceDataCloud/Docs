Inferpal - це розширення для Visual Studio 2022/2026, яке офіційно підтримує підключення до сервісів, сумісних з OpenAI. Версія розширення може впливати на редагування, виклики інструментів та облік використання; при першому підключенні, будь ласка, зафіксуйте версію та виконайте мінімальну перевірку, наведені нижче.

## Налаштування

1. Встановіть Inferpal з Visual Studio Marketplace або офіційного репозиторію.
2. Відкрийте **Settings → Connection** в Inferpal.
3. Виберіть Provider OpenAI-compatible.
4. У полі Base URL введіть `https://api.acedata.cloud/v1`.
5. У полі API Key введіть ваш Ace Data Cloud API Token.
6. У полі Model введіть точний ID моделі, що підтримує Chat Completions у каталозі моделей.
7. Після збереження надішліть `Reply only OK`, а потім виконайте ще раз запит, що містить контекст коду.

## Поточні обмеження

- Цей посібник охоплює лише Inferpal і не означає, що вбудований Copilot Visual Studio або інші розширення підтримують ті ж поля.
- Різні версії можуть автоматично додавати шляхи до Base URL; якщо запит не вдався, спочатку перевірте, чи потрапляє остаточний запит на Chat Completions endpoint.
- До завершення фіксації версії E2E не гарантується, що всі режими редагування, доповнення або викликів інструментів будуть доступні.
