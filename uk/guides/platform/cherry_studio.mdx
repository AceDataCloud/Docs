## 1. Отримання API Key

Відкрийте [список застосунків Ace Data Cloud](https://platform.acedata.cloud/console/applications), увійдіть до доступного застосунку та скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Додавання Provider

Відкрийте Cherry Studio, перейдіть до **Налаштування → Сервіси моделей → Додати постачальника** та заповніть:

| Поле      | Значення                           |
| ------- | --------------------------- |
| Назва постачальника   | `Ace Data Cloud`            |
| Тип постачальника   | `OpenAI`                    |
| API Key | Щойно скопійований API Key               |
| API-адреса  | `https://api.acedata.cloud` |

![Екран налаштування додавання Ace Data Cloud Provider у Cherry Studio](https://cdn.acedata.cloud/b67a927eae62.png)

Cherry Studio автоматично доповнить `/v1/chat/completions` для типу OpenAI. Під час використання універсальної точки входу не додавайте `#` наприкінці адреси, а також не потрібно створювати кілька Provider для кожного сімейства моделей.

## 3. Додавання та ввімкнення моделі

1. Натисніть **Отримати список моделей**; якщо поточна версія не підтримує автоматичне отримання, перейдіть до [каталогу моделей](https://platform.acedata.cloud/models), перегляньте його та вручну додайте назву цільової моделі, наприклад `claude-opus-5`, `gpt-6-sol`.
2. Натисніть кнопку перевірки поруч з API Key, щоб перевірити з’єднання.
3. Увімкніть перемикач **Увімкнути** для Provider.
4. Виберіть щойно додану модель у засобі вибору моделей для діалогу.

![Список Provider і моделей у Cherry Studio](https://cdn.acedata.cloud/149de1d088bf.png)

> Після отримання моделей або їх ручного додавання увімкніть перемикач Provider у верхньому правому куті.

Надішліть `Reply only OK` та перевірте виклик у [історії використання](https://platform.acedata.cloud/console/usages). У разі 401 перевірте Key; якщо модель не відображається, перевірте, чи увімкнено Provider; у разі 404 перевірте, чи вручну введена назва моделі повністю збігається з її `id` у каталозі.

## Про GPT Image 2

Звичайний користувацький чат Provider у Cherry Studio не може безпосередньо викликати Images API. Для генерації та редагування `gpt-image-2` слід використовувати спеціальний інтерфейс Ace Data Cloud:

- [Генерація зображень GPT Image 2](https://platform.acedata.cloud/documents/openai-images-generations)
- [Редагування зображень GPT Image 2](https://platform.acedata.cloud/documents/openai-images-edits)

Не вводьте `/openai/images/generations` у чат Provider.
