Офіційно Coze підтримує підключення користувацьких моделей і надає три протоколи: OpenAI Chat API, OpenAI Responses API та Anthropic Messages API. Базовий URL, з'єднання шляхів, заголовки, стрімінг та контракти викликів інструментів для трьох маршрутів різні, тому їх потрібно налаштовувати та перевіряти окремо.

| Маршрут                  | Статус    | Посібник                                                                                  |
| ----------------------- | -------- | --------------------------------------------------------------------------------------- |
| OpenAI Chat Completions | Експериментальний | [Налаштування Chat](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | Експериментальний | [Налаштування Responses](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | Експериментальний | [Налаштування Messages](https://platform.acedata.cloud/documents/coze-messages-integration)   |

“Експериментальний” означає, що офіційні можливості та точки налаштування підтверджені, але різні регіони, версії або пакети Coze можуть відображати різні форми, Ace Data Cloud все ще потрібно завершити перевірку фіксованої версії відповідно до протоколу. Не слід екстраполювати успіх одного протоколу на інші два.

## Принципи налаштування

- Базовий API URL слід заповнити відповідно до документації; не потрібно повторно додавати endpoint path, який клієнт автоматично доповнить.
- API Key використовуйте свій Ace Data Cloud API Token.
- Model використовуйте точний ID моделі, сумісний з обраним протоколом, з каталогу моделей.
- Після успішного звичайного тексту також слід перевірити стрімінг та виклики інструментів.
