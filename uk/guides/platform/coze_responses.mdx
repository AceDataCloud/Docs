Документація Coze щодо користувацьких моделей підтримує OpenAI Responses API та надає базову URL API, API Key та поля моделі. Різні версії орендарів Coze можуть по-різному обробляти з'єднання шляхів, потоковий вивід та виклики інструментів, тому при першому підключенні перевірте кожен пункт нижче.

## Налаштування

1. Увійдіть у керування моделями Coze та додайте нову користувацьку модель.
2. Виберіть Protocol OpenAI Responses API.
3. Уведіть Base API URL `https://api.acedata.cloud/v1`.
4. Уведіть API Key вашого Ace Data Cloud API Token.
5. Уведіть Model точний ID моделі, що підтримує Responses API, з каталогу моделей.
6. Збережіть та заверште тестування з'єднання Coze.
7. У Bot/Agent надішліть `Reply only OK`, потім ще раз протестуйте виклик інструменту.

## Поточні обмеження

- Різні регіони, версії або пакети Coze можуть відображати різні форми.
- Base API URL слід використовувати базовий, не додавайте повторно `/responses`; якщо поточний інтерфейс чітко вимагає повний API URL, дотримуйтесь підказок форми.
- Chat Completions, Responses та Anthropic Messages є трьома незалежними маршрутами, які не можуть взаємозамінювати один одного для верифікації.
