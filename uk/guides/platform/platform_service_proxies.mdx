---
title: "Отримання списку Proxy для сервісу на платформі AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Повертає кінцеві точки Proxy, підключені до цього сервісу, посторінково за UUID сервісу. Якщо є лише alias, спочатку викличте [деталі сервісу](https://platform.acedata.cloud/documents/platform-service-detail), щоб отримати `id`.

## Огляд інтерфейсу

| Пункт   | Вміст                                                                  |
| --- | ---------------------------------------------------------------------- |
| Метод  | `GET`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| Авторизація  | Публічний, токен облікового запису не потрібен                                                              |
| Пагінація  | `count` + `items`                                                      |

## Параметри

| Параметр                 | Розташування    | Обов’язковий  | Опис                               |
| ------------------ | ----- | --- | -------------------------------- |
| `service_id`       | path  | Так   | Service UUID, alias не підтримується           |
| `limit` / `offset` | query | Ні   | Пагінація                               |
| `ordering`         | query | Ні   | Вираз сортування Django; рекомендовано `rank` або `-rank` |

```shell
export SERVICE_ID='Ваш Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## Опис відповіді

Елементи списку серіалізуються моделлю Proxy; поля, перевірені в онлайн-середовищі, включають `id`, `service_id`, `title`, `endpoint`, `price`, `stage`, `rank`, `tags`, `metadata`, `document_id`, `service` і поля часу.

- Полем бізнес-входу є `endpoint`, а не `path`.
- Полем ціноутворення є `price`, а не `cost`.
- Якщо тип Service не є Proxy або Proxy не підключено, повертається порожній `items`.

Публічна інтеграція покладається лише на `endpoint` і опубліковані можливості та не повинна покладатися на неопубліковані деталі реалізації.
