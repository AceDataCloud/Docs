Офіційний IDE Extension OpenCode підтримує редактори VS Code, Cursor, Windsurf, VSCodium та повторно використовує локальний runtime OpenCode і конфігурацію Provider. IDE розширення повторно використовує локальний CLI Provider, але ланцюг запитів для різних версій редакторів може змінюватися; при першій інтеграції будь ласка, зафіксуйте версію та заверште мінімальну верифікацію.

## Налаштування Provider

Спочатку відповідно до [конфігурації OpenCode Terminal](https://platform.acedata.cloud/documents/opencode-terminal-integration) налаштуйте Ace Data Cloud Provider у `opencode.json` або `opencode.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## Встановлення IDE Extension

1. У інтегрованому терміналі редактора запустіть `opencode`, дотримуючись офіційного процесу для автоматичної установки Extension; також можна вручну встановити з відповідного Marketplace.
2. Перезавантажте редактор.
3. Ініціюйте `Reply only OK` з OpenCode Extension.
4. Знову виконайте запит, який потребує читання файлів або зміни коду, щоб підтвердити, що IDE Extension використовує той самий Provider і модель.

## Поточні обмеження

- Можливості Provider походять з OpenCode runtime, не означає, що хост-редактор нативно підтримує Ace Data Cloud.
- Версії розширень VS Code та їхніх форків можуть відрізнятися, слід окремо фіксувати версії.
- Успішний звичайний чат не може замінити верифікацію читання файлів, редагування та виклику інструментів.
