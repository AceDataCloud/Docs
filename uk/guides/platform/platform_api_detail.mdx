Отримайте повну інформацію про одну кінцеву точку API за ID API — на відміну від [інтерфейсу списку](https://platform.acedata.cloud/documents/platform-api-list), додаються поля `definition` (OpenAPI 3.0 Schema), `service` (деталі належної служби) та `products` (пов’язані продукти).

Підходить для таких сценаріїв, як автоматичне генерування SDK, передавання описів інструментів LLM Agent, динамічний рендеринг сайтів документації тощо.

> ℹ️ Цей інтерфейс належить до **API керування платформою AceDataCloud**, з єдиним префіксом `https://platform.acedata.cloud/api/v1/`. Повний індекс інтерфейсів дивіться в [Отримання списку документів платформи AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list).

## Огляд інтерфейсу

| Пункт   | Вміст                                                    |
| --- | ----------------------------------------------------- |
| Метод  | `GET`                                                 |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}` |
| Автентифікація  | ❌ Відкрита                                                  |

Наразі доступні як `/apis/{id}`, так і `/apis/{id}/`; у прикладах уніфіковано використовується форма без завершального слеша.

## Опис автентифікації

Цей інтерфейс **повністю відкритий, не потребує токена облікового запису або стану входу**.

## Параметри шляху

| Параметр       | Тип   | Обов’язковий  | Опис                    |
| -------- | ---- | --- | --------------------- |
| `api_id` | UUID | ✅   | ID API (формат UUID, псевдоніми не підтримуються) |

## Приклади запитів

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/apis/afc7917f-d89f-4dc9-95c2-863936b02cad' \
  -H 'accept: application/json'
```

### Python

```python
import requests

api_id = "afc7917f-d89f-4dc9-95c2-863936b02cad"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/apis/{api_id}",
    headers={"accept": "application/json"},
    timeout=10,
)
api = resp.json()
print(f"API: {api['title']}")
print(f"路径: {api['path']}")
print(f"所属服务: {api['service']['title']} ({api['service']['alias']})")
print(f"OpenAPI 路径数: {len(api.get('definition', {}).get('paths', {}))}")
```

### Node.js

```javascript
const apiId = 'afc7917f-d89f-4dc9-95c2-863936b02cad'
const r = await fetch(`https://platform.acedata.cloud/api/v1/apis/${apiId}`)
const api = await r.json()
console.log(api.title, api.path, api.service.title)
```

## Опис полів відповіді

Інтерфейс деталей додатково містить, окрім [полів інтерфейсу списку](https://platform.acedata.cloud/documents/platform-api-list):

| Поле           | Тип     | Опис                                                                                          |
| ------------ | ------ | ------------------------------------------------------------------------------------------- |
| `service`    | object | Ключова інформація належної служби: `id`, `title`, `type`, `alias`                                                       |
| `products`   | array  | Список пов’язаних продуктів (зазвичай порожній, для використання операційною стороною)                                                                         |
| `definition` | object | **Повне визначення специфікації OpenAPI 3.0**, містить `paths`, `components`, `info` тощо, і може безпосередньо передаватися в `openapi-generator` для генерування коду клієнта |

## Обробка помилок

| HTTP | code        | Значення                 |
| ---- | ----------- | ------------------ |
| 400  | `invalid`   | `api_id` не є дійсним UUID |
| 404  | `not_found` | API не існує або вимкнено        |

## Практичні поради

- **Поле `definition` дуже велике**: OpenAPI Schema одного API може містити сотні рядків JSON. Якщо потрібно лише створити індекс служб і Schema не потрібна, слід натомість використовувати [інтерфейс списку](https://platform.acedata.cloud/documents/platform-api-list).
- **Поширений спосіб використання для генерування SDK**:
  ```shell
  # 拿到 OpenAPI 文件
  curl -s 'https://platform.acedata.cloud/api/v1/apis/<api_id>' | jq '.definition' > openapi.json

  # 用 openapi-generator-cli 生成 Python 客户端
  openapi-generator-cli generate -i openapi.json -g python -o ./client
  ```
- **Відстеження змін API**: поле `updated_at` — це час останньої зміни schema. Підписка на це поле дає змогу автоматично повторно генерувати SDK у разі змін OpenAPI.
