[ChatBox](https://chatboxai.app/) — це відкритий AI-клієнт, що підтримує Windows, macOS, Linux, iOS, Android і Web. Він підтримує користувацьких постачальників типу «OpenAI API», тому може безпосередньо підключатися до Ace Data Cloud. У цій статті описано процес налаштування.

## Процес подання заявки

Щоб підключити Ace Data Cloud у ChatBox, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications), отримайте свій API Token і збережіть його про запас.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не ввійшли або не зареєструвалися, вас буде автоматично перенаправлено на сторінку входу, де вам буде запропоновано зареєструватися та ввійти; після входу або реєстрації ви автоматично повернетеся на поточну сторінку.

Під час першого подання заявки надається безкоштовний ліміт, який дозволяє безкоштовно випробувати модельні сервіси Ace Data Cloud.

## Завантаження ChatBox

Перейдіть на [офіційний сайт ChatBox](https://chatboxai.app/) для завантаження відповідно до платформи або безпосередньо використовуйте версію [Web](https://web.chatboxai.app/), що не потребує встановлення:

- Настільні системи: Windows `.exe`, macOS `.dmg` (окремо для Intel / Apple Silicon), Linux AppImage
- Мобільні системи: App Store, Google Play, пряме посилання на Android з офіційного сайту

## Налаштування Ace Data Cloud

Запустіть ChatBox, перейдіть до **Налаштування → Моделі → Додати користувацького Provider**, встановіть для **API Mode** значення **OpenAI API Compatible**, а потім заповніть:

| Поле       | Значення                           | Опис                                      |
| -------- | --------------------------- | --------------------------------------- |
| API ключ   | Ваш Ace Data Cloud Token     | Token, скопійований із консолі                            |
| API Host | `https://api.acedata.cloud` | Вказуйте лише кореневий домен, **не додавайте `/openai` або `/v1`**         |
| API Path | `/v1/chat/completions`      | Типово в ChatBox встановлено `/chat/completions`, потрібно вручну змінити на цей |

![Інтерфейс налаштування ChatBox Ace Data Cloud Provider](https://cdn.acedata.cloud/3789c8e3dd4d.png)

Шлях запиту ChatBox має вигляд `{API Host} + {API Path}`, тому в Host достатньо вказати лише кореневий домен:

| API Host                              | Остаточний запит                                                      | Результат                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | Правильно                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (під `/openai` немає `/v1`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

ChatBox не викликає `/v1/models` автоматично, тому в полі «Користувацькі моделі» внизу сторінки налаштувань моделей потрібно вручну ввести ID моделей (по одному в рядок); після збереження їх можна буде вибрати у випадаючому списку моделей в інтерфейсі чату. Перемикачі можливостей, контекстне вікно та ліміт виводу потрібно заповнювати відповідно до поточних умов вибраної моделі, не копіюйте значення інших моделей.

## Вибір моделі

Каталог моделей постійно оновлюється. Надавайте пріоритет списку моделей, автоматично завантаженому клієнтом; якщо потрібно вводити вручну, спочатку надішліть запит `GET https://api.acedata.cloud/v1/models`, щоб отримати поточні ID моделей, а потім виберіть відповідно до підтримуваних клієнтом можливостей контексту, зображень і викликів інструментів.

## Перевірка підключення

Якщо ви не впевнені, чи проблема в ChatBox, чи в мережі, спочатку можна безпосередньо перевірити кінцеву точку за допомогою curl (замініть `{token}` на свій Token):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Повернення OpenAI-сумісного об’єкта `chat.completion` означає, що і Token, і кінцева точка готові; якщо повертається `HTTP 403 used_up`, це означає, що Token дійсний, але балансу недостатньо — поповніть рахунок у [консолі](https://platform.acedata.cloud/console/applications).

## Поширені запитання

### Відображається 404 Not Found

Зазвичай це означає, що до API Host зайво додано `/openai` або `/v1`. У Host вказуйте лише `https://api.acedata.cloud`, а шлях залиште типовому `/v1/chat/completions`.

### Відображається 401 / token_mismatched

Переконайтеся, що в «API ключ» вставлено Token Ace Data Cloud (без префікса `Bearer`, без зайвих пробілів) і що баланс відповідного застосунку достатній.

### Модель не відображається у випадаючому списку моделей

ChatBox не завантажує список моделей автоматично, потрібно вручну ввести ID моделі в поле «Користувацькі моделі» та зберегти.

### Хочу генерувати зображення в ChatBox

Генерація зображень Ace Data Cloud є окремим Images API (`/openai/images/generations`) і має інший шлях, ніж інтерфейс чату, тому вхід для зображень ChatBox не можна підключити безпосередньо. Якщо потрібно створювати зображення, зверніться до [документації API генерації зображень](https://platform.acedata.cloud/documents/openai-images-generations) для виклику через curl / SDK.
