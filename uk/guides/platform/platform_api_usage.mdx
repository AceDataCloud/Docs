---
title: "Отримання зразків нещодавніх викликів API платформи AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Публічно повертає зразки записів викликів певного API за останні 15 хвилин для швидкого спостереження за нещодавнім станом. Це не інтерфейс підрахунку, агрегований за кодами стану, і його не можна використовувати для особистих рахунків, SLA або повної статистики використання.

## Огляд інтерфейсу

| Пункт   | Вміст                                                           |
| --- | ------------------------------------------------------------ |
| Метод  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| Авторизація  | Публічна, токен облікового запису не потрібен                                                    |
| Ліміт  | Після об’єднання нещодавно створених/завершених записів повертається максимум 5 000 записів                                    |

`api_id` отримується зі [списку API](https://platform.acedata.cloud/documents/platform-api-list).

```shell
export API_ID='Ваш API ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## Структура фактичної відповіді

Відповідь безпосередньо є масивом, без використання envelope пагінації:

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| Поле            | Опис        |
| ------------- | --------- |
| `api_id`      | API ID    |
| `created_at`  | Час створення запису    |
| `trace_id`    | Ідентифікатор відстеження запиту    |
| `status_code` | Код стану HTTP  |
| `elapsed`     | Тривалість виклику, у секундах |

Якщо API не існує, наразі також може повертатися порожній масив, оскільки ця action безпосередньо виконує запит до нещодавнього usage за ID і не перевіряє спочатку об’єкт API. Щоб обчислити рівень успішності, клієнт має самостійно згрупувати повернуті зразки; щоб перевірити персональні списання, використовуйте інтерфейс рівня облікового запису.
