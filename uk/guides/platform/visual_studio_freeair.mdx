FreeAIr - це відкритий розширення для Visual Studio 2022/2026, яке, за офіційною заявою, може підключатися до будь-якого API, сумісного з OpenAI. Поведінка запитів може змінюватися в різних версіях розширення; при першому підключенні будь ласка, зафіксуйте версію та виконайте мінімальну перевірку, наведені нижче.

## Налаштування

1. Встановіть FreeAIr з Visual Studio Marketplace або з офіційного репозиторію.
2. Відкрийте налаштування FreeAIr і додайте підключення, сумісне з OpenAI.
3. У полі Endpoint введіть `https://api.acedata.cloud/v1`.
4. У полі Token введіть свій Ace Data Cloud API Token.
5. У полі Model введіть точний ID моделі, що підтримує Chat Completions, з каталогу моделей.
6. Після збереження надішліть `Reply only OK`, а потім ще раз протестуйте запит з контекстом проекту.

## Поточні межі

- Цей посібник охоплює лише FreeAIr і не означає, що вбудований Copilot у Visual Studio підтримує довільний базовий URL.
- Версії розширення можуть змінювати спосіб складання endpoint; під час перевірки слід перевіряти остаточний URL запиту.
- Виклики інструментів та можливості MCP в розширенні потребують окремої перевірки, не можна використовувати успішний звичайний чат як заміну.
