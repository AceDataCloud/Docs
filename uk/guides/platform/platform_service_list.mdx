Посторінково повертає каталог Service, видимий на поточному сайті, включно з типами сервісів, інформацією для відображення, безкоштовними квотами, пакетами та пов’язаними API/Proxy ID. Підходить для створення маркетплейсу сервісів або вибору сервісів для подання заявки.

## Огляд інтерфейсу

| Пункт   | Вміст                                                |
| --- | ------------------------------------------------- |
| Метод  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| Авторизація  | Публічний; за наявності стану входу `applied` відображає поточний обліковий запис                        |
| Пагінація  | `count` + `items`                                 |

## Параметри запиту

| Параметр               | Тип      | Обов’язковий  | Опис                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | Ні   | Фільтрація за ID сервісу; підтримує повторювані параметри         |
| `private`        | boolean | Ні   | Фільтрація за статусом публічності; правила видимості сайту все ще діють      |
| `type`           | string  | Ні   | Тип сервісу; підтримує повторювані параметри              |
| `tag`            | string  | Ні   | Фільтрація за тегом                    |
| `include_facets` | boolean | Ні   | Коли `true`, додається статистика типів/тегів, доступних на поточному сайті |
| `limit`          | integer | Ні   | Кількість записів на сторінці, максимум 100              |
| `offset`         | integer | Ні   | Зсув пагінації                    |
| `ordering`       | string  | Ні   | Підтримуються лише `rank` або `-rank`     |

Список не підтримує фільтрацію за `alias`; за наявності alias безпосередньо запитуйте `/api/v1/services/{alias}`. `applied_count`, `updated_at` не є дозволеними полями сортування.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## Опис відповіді

Відповідь має вигляд `{count, items}`; `facets` додається лише за `include_facets=true`. Елемент сервісу містить поточні публічні поля, такі як `id`, `alias`, `title`, `description`, `type`, `applied_count`, `free_amount`, `unit`, `private`, `need_verify`, `rank`, `tags`, `thumbnail`, `doc_url`, `demo_url`, `api_ids`, `proxy_ids`, `cost`, `packages` тощо.

`applied` в анонімному списку не представляє статус заявки будь-якого облікового запису. Коли потрібен стан, пов’язаний з обліковим записом, слід використовувати дійсний стан входу та вважати [список заявок на сервіс](https://platform.acedata.cloud/documents/platform-application-list) остаточним джерелом.
