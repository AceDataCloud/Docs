Офіційна документація GitHub Copilot BYOK вказує, що VS Code є підтримуваним локальним клієнтом і підтримує OpenAI-сумісні постачальники. Версія VS Code, корпоративна політика та видимість моделі можуть вплинути на кінцеву точку; для першого підключення перевірте фактичний запит, як зазначено нижче.

## Налаштування

1. Підтвердіть, що ваш обліковий запис або організація GitHub Copilot активували функцію BYOK/Custom Models.
2. У менеджері моделей Copilot у VS Code додайте OpenAI-сумісного постачальника.
3. У полі Base URL введіть `https://api.acedata.cloud/v1`.
4. У полі API Key введіть ваш Ace Data Cloud API Token.
5. У полі Model введіть точний ID моделі, сумісної з обраним протоколом, з каталогу моделей.
6. У Copilot Chat надішліть `Reply only OK`, а потім ще раз протестуйте запит з контекстом робочої області.

## Поточні обмеження

- Налаштування Copilot App, CLI, GitHub Desktop, Enterprise BYOK відрізняються від налаштувань VS Code, тому цей посібник не застосовує кроки для інших клієнтів безпосередньо до VS Code.
- Політика організації може забороняти особисте додавання постачальників або моделей.
- Завершення табуляції, Chat, Agent та фонові завдання можуть використовувати різні шляхи моделей, їх слід перевіряти окремо.
