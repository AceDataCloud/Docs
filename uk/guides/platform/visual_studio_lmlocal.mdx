LMLocal - це розширення для Visual Studio 2022/2026, яке офіційно підтримує OpenAI-сумісний API та користувацький базовий URL. Вхід для налаштування може змінюватися з версією розширення; для першого підключення, будь ласка, зафіксуйте версію та перевірте реальне редагування, виклики інструментів та облік використання.

## Налаштування

1. Встановіть LMLocal з Visual Studio Marketplace або офіційного репозиторію.
2. У Providers додайте новий Custom/OpenAI-сумісний Provider.
3. У полі Base URL введіть `https://api.acedata.cloud/v1`.
4. У полі Auth Key введіть ваш Ace Data Cloud API Token.
5. У полі Model введіть точний ID моделі, що підтримує Chat Completions, з каталогу моделей.
6. Після збереження надішліть `Reply only OK`, а потім ще раз протестуйте процес редагування проекту.

## Поточні обмеження

- Цей посібник охоплює лише LMLocal і не представляє спільні налаштування для інших розширень Visual Studio.
- Різні версії можуть окремо обробляти запити на чат, редагування, збірку та тестування; кожен режим потрібно перевіряти окремо.
- Якщо клієнт автоматично додає `/v1` або шлях до кінцевої точки, будь ласка, уникайте повторних шляхів.
