---
title: "Посібник з інтеграції Hermes Agent"
description: "Platform API guide - Ace Data Cloud"
---

Hermes Agent інтегрується з Ace Data Cloud через протокол OpenAI Chat Completions. Виберіть один з варіантів конфігурації:

| Варіант конфігурації        | Посібник                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| Інтерактивний гід `hermes model` | [Конфігурація гіда](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| Ручна конфігурація `config.yaml`  | [Ручна конфігурація](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| Приватне розгортання платформи              | [Управляюче розгортання](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

Загальні параметри для локальної інтеграції:

- Базовий URL: `https://api.acedata.cloud/v1`
- Транспорт: `chat_completions`
- Провайдер: `custom:acedatacloud`
- API Key: отримати з [списку додатків](https://platform.acedata.cloud/console/applications)

Обидва локальні способи в кінцевому підсумку записуються в `~/.hermes/config.yaml`, не повторюйте конфігурацію.

Поверніться до [Центру конфігурації Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
