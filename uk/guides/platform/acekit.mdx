Ви, ймовірно, теж стикалися з такою ситуацією: користуєтеся Claude Code, Cursor або Codex, код пишеться як по маслу, і раптом вам потрібна ілюстрація, фрагмент фонової музики, коротке відео або ви хочете, щоб він заодно знайшов найсвіжіші матеріали. Але виявляється — сам agent цього не вміє. Вам доводиться самостійно шукати API, читати документацію, налаштовувати ключі, писати код викликів, обробляти асинхронне опитування — після всіх цих клопотів натхнення вже давно охололо.

[AceKit](https://github.com/AceDataCloud/AceKit) створений саме для того, щоб позбавити вас усього цього. Однією командою він встановлює у вашого агента для кодування весь набір можливостей AceData Cloud: генерацію зображень, відео, музики, вебпошук, LLM-діалоги тощо. Після встановлення ви просто говорите звичайною мовою, а agent сам завантажує відповідну навичку, сам проходить автентифікацію, сам виконує опитування і завершує роботу.

## Зрозумійте за 30 секунд, що він робить

До встановлення vs після встановлення:

| Що ви кажете               | До встановлення                   | Після встановлення (agent робить сам)                      |
| ------------------ | --------------------- | ----------------------------------- |
| "Додай до цього README зображення для обкладинки" | agent не вміє, пропонує вам самим шукати API генерації зображень | Викликає NanoBanana / Flux / Midjourney для генерації зображення |
| "Перетвори цей скрипт на 30-секундне коротке відео"  | Не вміє                    | Викликає Sora / Veo / Kling / Seedance для створення відео  |
| "Додай до цього demo фрагмент фонової музики"  | Не вміє                    | Викликає Suno для створення музики                           |
| "Пошукай найновіше про X і підсумуй"     | Не має доступу до інтернету                  | Викликає Google SERP для отримання результатів у реальному часі                 |
| "Скороти це довге посилання"         | Не вміє                    | Викликає сервіс коротких посилань і повертає посилання surl.id                  |

Одним реченням: **ваш агент для кодування перетворюється з «того, хто лише пише код», на «того, хто ще й генерує зображення, відео, музику та шукає в інтернеті».**

## Початок роботи за три кроки

Увесь процес займає кілька хвилин, потрібен Node.js 18+.

**Крок перший · отримайте API Token.** У [консолі](https://platform.acedata.cloud/console/applications) скопіюйте Token — один і той самий використовується для всіх можливостей; під час першого оформлення надається безкоштовний ліміт, тож спочатку можна спробувати безкоштовно.

![Скопіюйте API Token у консолі](https://cdn.acedata.cloud/dvc3cg.jpg)

**Крок другий · встановіть.** Одна команда:

```bash
npx acekit
```

Вона автоматично визначить агентів для кодування на вашій машині та встановить повний набір навичок. Реальний запуск виглядає так (на цій машині встановлено лише Claude Code):

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> Якщо Token не задано, під час першого запуску з’явиться інтерактивна підказка вставити його; також можна заздалегідь виконати `export ACEDATACLOUD_API_TOKEN=вашtoken`, щоб встановлення відбулося повністю без нагляду. Кількість навичок змінюватиметься зі зростанням можливостей платформи; орієнтуйтеся на поточний список, який показує `npx acekit list`.

**Крок третій · говоріть звичайною мовою.** Перезавантажте agent, а потім просто дайте команду, наприклад:

```text
用 short-url 技能把 https://platform.acedata.cloud/services 缩短一下
```

agent сам завантажить навичку, сам виконає виклик і надасть вам реальний результат, за яким можна перейти.

## Реальний запуск (із виводом)

Усі чотири приклади нижче — це **реальні виклики та результати, отримані безпосередньо на місці**, а не демонстрація. `$KEY` у командах — це ваш API Token.

**① Скорочення URL (синхронно, відповідь за секунди)**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

Повертається `https://surl.id/r/1uKp2kilXQ` — після переходу виконується 302-перенаправлення назад на початкову сторінку services.

**② Пошук в інтернеті (синхронно)**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

Отримуємо результати Google у реальному часі (уривок):

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ LLM-діалог (синхронно, один інтерфейс для підключення 50+ моделей)**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP是用于统一管理和交换模型上下文信息的协议。
（39 tokens，本次约 0.00007 credit）
```

**④ Генерація зображення (асинхронно, близько 20 секунд, agent автоматично виконує опитування до появи зображення)**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

Приблизно через 22 секунди повертається реальне зображення (HTTP 200 · image/png · 317 KB · цього разу приблизно 0.13 credit):

![Зображення, реально згенероване AceKit](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

Насправді вам не потрібно запам’ятовувати ці інтерфейси — після встановлення навичок agent сам, відповідно до власного `SKILL.md`, сформує правильні запити, обробить автентифікацію та опитування. Вище лише показано, «що він робить за лаштунками».

## Що саме він встановлює

AceKit — це «парадний вхід» до всього набору інструментів розробника AceData; наразі одним встановленням додається **набір інструментів навичок (Skills)**:

- **Набір Agent-навичок**: кожна навичка — це готовий посібник з роботи `SKILL.md` — у ньому чітко описано автентифікацію, асинхронне опитування, повторні спроби після помилок і заповнення параметрів, тож agent достатньо просто дотримуватися інструкцій. Виконайте `npx acekit list`, щоб переглянути поточний список (на момент написання цієї статті їх 19, і кількість постійно зростає):
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **Єдиний Token**: один `ACEDATACLOUD_API_TOKEN` відкриває всі можливості, оплата за фактичним використанням.

Класифікація за можливостями (згідно з `npx acekit list`):

| Тип         | Постачальники                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ Генерація зображень      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 Генерація відео      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 Генерація музики / аудіо | Suno · Producer · Fish Audio（TTS）                    |
| 💬 LLM-діалог   | Єдиний інтерфейс для 50+ моделей（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 Пошук       | Google SERP（вебсторінки · зображення · новини · карти · відео）                  |
| 🔗 Інструменти       | Короткі посилання · Обробка облич                                            |

> Ці самі можливості AceData також надає як окремі **MCP-сервери**（Suno、Midjourney、Sora、SERP… вже опубліковані в PyPI / VS Code / Smithery / Docker）、**CLI командного рядка** та **Python / TypeScript SDK**, які можна використовувати окремо за потреби。У AceKit v0.2 запланована підтримка встановлення окремих можливостей через `acekit add <name>`, а також автоматичний запис MCP-конфігурації для кожного agent。

## Які Agent підтримуються

| Agent                        | Місце встановлення навичок                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode тощо | `~/.agents/skills`（вкажіть цей шлях для вашого agent） |

Під час встановлення AceKit автоматично виявляє agent, уже встановлені на машині, і встановлює лише в ті, які було виявлено。

## Пасхалка: керуйте самим Claude Code за допомогою того самого Token

Інтерфейс AceData також сумісний із форматом Anthropic `/v1/messages`, тому вам**не потрібна офіційна підписка Anthropic** — Claude Code можна керувати тим самим AceData Token。У кореневому каталозі проєкту створіть `.claude/settings.local.json`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Перезапустіть Claude Code — він не лише використовуватиме всю лінійку моделей Claude, а й отримає через AceKit «руки» для генерації зображень, відео та музики。Докладніше дивіться в [посібнику з інтеграції Claude Code](https://platform.acedata.cloud/documents/claude-code-integration)。
