Ace Data Cloud надає вхід для приватного розгортання Hermes Agent. Цей вхід є контрольованою службою, доступність та вибір ресурсів визначаються поточним відображенням на консолі.

## Кроки використання

1. Знайдіть на платформі **Hermes Agent приватне розгортання**.
2. Виберіть доступну конфігурацію та створіть службу відповідно до підказок на сторінці.
3. Дочекайтеся, поки платформа відобразить стан готовності.
4. Використовуйте наданий на сторінці вхід та облікові дані для доступу до екземпляра.
5. Спочатку надішліть `Reply only OK`, а потім починайте реальне завдання.

Модель, облікові дані, зберігання та дії з видаленням визначаються сторінкою створення та вікном підтвердження; не використовуйте YAML з локального посібника Hermes безпосередньо як контракт для розгортання на платформі. Перед видаленням спочатку експортуйте дані, які потрібно зберегти.

Якщо консоль не відображає вхід для створення, це означає, що поточний обліковий запис ще не має доступу до цієї служби, можна скористатися [Hermes інтерактивним майстром](https://platform.acedata.cloud/documents/hermes-wizard-integration) або [ручним налаштуванням](https://platform.acedata.cloud/documents/hermes-manual-integration).
