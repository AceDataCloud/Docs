Основна функція Artistic QR Tasks API полягає в тому, щоб за допомогою введеного ID завдання, згенерованого Artistic QR Generation API, перевірити стан виконання цього завдання.

Цей документ детально описує інтеграцію Artistic QR Tasks API, щоб допомогти вам легко інтегрувати та повністю використовувати потужні можливості цього API. За допомогою Artistic QR Tasks API ви можете легко реалізувати перевірку стану виконання завдань Artistic QR Generation API.

## Процес подачі заявки

Щоб використовувати Artistic QR Tasks API, спочатку потрібно перейти на сторінку подачі заявки [Artistic QR Generation API](https://platform.acedata.cloud/documents/ee085d2a-a0b9-4f0e-8b4d-8da407345138) для отримання відповідної послуги, а потім скопіювати ID завдання Artistic QR Generation API, як показано на малюнку:

<p><img src="https://cdn.acedata.cloud/2wicjy.png" width="500" class="m-auto"></p>

Нарешті, перейдіть на сторінку Artistic QR Tasks API [Artistic QR Tasks API](https://platform.acedata.cloud/documents/21de9d76-6e39-4ac3-b8b9-20e7194c02b4) для отримання відповідної послуги, після входу на сторінку натисніть кнопку «Acquire», як показано на малюнку:

![Сторінка подачі заявки](https://cdn.acedata.cloud/rci31i.png)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на [сторінку входу](https://platform.acedata.cloud), запрошуючи вас зареєструватися та увійти. Після входу або реєстрації ви автоматично повернетеся на поточну сторінку.

При першій подачі заявки вам буде надано безкоштовний ліміт, який дозволяє безкоштовно використовувати цей API.

## Приклад запиту

Artistic QR Tasks API можна використовувати для перевірки результатів одного API Artistic QR Generation API. Щоб дізнатися, як використовувати Artistic QR Generation API, будь ласка, зверніться до документа [Artistic QR Generation API](https://platform.acedata.cloud/documents/ee085d2a-a0b9-4f0e-8b4d-8da407345138).

Розглянемо приклад з ID завдання, повернутим сервісом Artistic QR Generation API. Припустимо, у нас є ID завдання: e2c65b20-a970-431e-99c1-76721e799df8, далі демонструємо, як передати ID завдання.

### Налаштування заголовків запиту та тіла запиту

**Request Headers** включає:

- `accept`: вказує на прийняття відповіді у форматі JSON, тут вказується `application/json`.
- `authorization`: ключ для виклику API, після подачі заявки можна вибрати з випадаючого списку.

**Request Body** включає:

- `id`: ID завдання, яке потрібно завантажити.
- `action`: спосіб виконання завдання.

Налаштування виглядає так, як показано на малюнку:

<p><img src="https://cdn.acedata.cloud/use825.png" width="500" class="m-auto"></p>

### Приклад коду

Можна помітити, що на правій стороні сторінки вже автоматично згенеровано код на різних мовах, як показано на малюнку:

<p><img src="https://cdn.acedata.cloud/jejwy6.png" width="500" class="m-auto"></p>

Деякі приклади коду наведені нижче:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/qrart/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "e2c65b20-a970-431e-99c1-76721e799df8",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/qrart/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "e2c65b20-a970-431e-99c1-76721e799df8",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Помилка обробка

У разі виклику API, якщо виникає помилка, API поверне відповідний код помилки та інформацію. Наприклад:

- `400 token_mismatched`：Неправильний запит, можливо, через відсутні або недійсні параметри.
- `400 api_not_implemented`：Неправильний запит, можливо, через відсутні або недійсні параметри.
- `401 invalid_token`：Неавторизовано, недійсний або відсутній токен авторизації.
- `429 too_many_requests`：Занадто багато запитів, ви перевищили ліміт запитів.
- `500 api_error`：Внутрішня помилка сервера, щось пішло не так на сервері.
