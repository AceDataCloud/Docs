Цей інтерфейс базується на [Fish Audio офіційному Model API](https://docs.fish.audio/resources/api-reference/model) і використовується для **запиту повних деталей одного клонованого голосу за `_id`**. Адреса: `GET https://api.acedata.cloud/fish/model/{id}`.

> Для створення голосу, будь ласка, зверніться до [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); для пагінації зверніться до [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query).

## Процес подачі заявки

Щоб використовувати Fish Model API, спочатку перейдіть до [Ace Data Cloud консолі](https://platform.acedata.cloud/console/applications) для отримання вашого API Token, зберігайте його для подальшого використання.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, де вас запросять зареєструватися та увійти. Після завершення ви автоматично повернетеся на цю сторінку.

**Один API Token дозволяє викликати всі послуги платформи, не потрібно окремо подавати заявку на кожну послугу.** Перший запит на отримання токена надає безкоштовний ліміт для тестування; якщо ліміт вичерпано, ви можете поповнити загальний баланс в [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Параметри шляху

| Параметр | Обов'язковий | Опис                                                                                                                                                                                                |
| -------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`     | Так          | `_id` голосу (32-значний шістнадцятковий рядок). Можна отримати під час створення через [Fish Model Create](https://platform.acedata.cloud/documents/fish-model) або через [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query). |

Без тіла запиту, без параметрів запиту.

## Приклад: отримання повних деталей публічного іспанського голосу

```shell
curl 'https://api.acedata.cloud/fish/model/8d2c17a9b26d4d83888ea67a1ee565b2' \
  -H 'authorization: Bearer {token}'
```

Отриманий `_id` просто передайте в `reference_id` [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) для синтезу голосу з таким же тембром:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

## Відмінності з інтерфейсом списку

| Поле                                               | `GET /fish/model` (список) | `GET /fish/model/{id}` (деталі) |
| -------------------------------------------------- | --------------------- | -------------------------- |
| `samples[].audio`                                  | Короткочасне R2 кешування URL | Пряме посилання R2 з підписом (включаючи підпис запиту) |
| `unliked` / `liked` / `marked` / `dmca_taken_down` | Так само існує          | Так само існує               |
| `default_text` / `lock_visibility`                 | Так само існує          | Так само існує               |

Якщо вам просто потрібно прослухати, `samples[].audio` в інтерфейсі списку вже достатньо; для більш стабільного посилання на завантаження рекомендується використовувати цей інтерфейс.

## Поля відповіді (вибірково)

| Поле            | Тип       | Опис                                          |
| ------------- | -------- | ------------------------------------------- |
| `_id`         | string   | ID голосу (використовується для `/fish/tts` в `reference_id`).     |
| `type`        | string   | Тип моделі, зазвичай `tts`.                             |
| `title`       | string   | Назва голосу.                                       |
| `description` | string   | Довгий опис.                                        |
| `state`       | string   | Статус навчання: `trained` означає доступний, `training` означає, що ще триває навчання.      |
| `tags`        | string[] | Теги загальної бібліотеки.                                      |
| `samples`     | object[] | Попередньо задані зразки, що містять `title`, `text`, `task_id`, `audio` пряме посилання. |
| `languages`   | string[] | Код мов, в яких голос має перевагу.                                  |
| `visibility`  | string   | `public` або `private`.                       |
| `like_count`  | integer  | Кількість лайків у загальній бібліотеці.                                     |
| `task_count`  | integer  | Кількість історичних синтезів (може використовуватися для посилання на популярність).                          |
| `author`      | object   | Інформація про автора: `_id` / `nickname` / `avatar`.       |
| `created_at`  | string   | ISO 8601 час створення.                              |
| `updated_at`  | string   | ISO 8601 час останнього оновлення.                            |

## Інформація про оплату

Цей інтерфейс не підлягає оплаті — запит деталей одного голосу за ID є безкоштовною операцією. Створення голосу ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) також безкоштовне, витрати виникають лише під час виклику [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) для синтезу голосу.

## Обробка помилок
- `400 token_mismatched`：Шляхом `id` не є дійсним форматом, або верхній рівень повідомляє «Модель не знайдена».
- `401 invalid_token`：Токен авторизації не існує або недійсний.
- `404 not_found`：Вказаний `_id` не видимий на Fish (зразок видалено, приватний або належить іншому обліковому запису).
- `429 too_many_requests`：Перевищено обмеження швидкості облікового запису.
- `500 api_error`：Внутрішня помилка сервера.

При фактичному запиті неіснуючого ID верхній рівень безпосередньо повертає `400 Model not found` (перевірено):

```shell
curl 'https://api.acedata.cloud/fish/model/test123' \
  -H 'authorization: Bearer {token}'
```

Повертає:

```json
{ "status": 400, "message": "Model not found" }
```

Приклад помилкового відповіді:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Висновок

Знаючи звук `_id`, безпосередньо використовуйте цей інтерфейс для отримання повної ModelEntity, найпоширеніше використання: (1) прослуховування `samples[].audio`, (2) передача `_id` до `reference_id` `/fish/tts` для завершення синтезу. Якщо є лише заголовок або мітки, спочатку використовуйте [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) для пошуку.
