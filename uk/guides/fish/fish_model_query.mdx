Цей API базується на [офіційному Model API Fish Audio](https://docs.fish.audio/resources/api-reference/model) і використовується для **посторінкового пошуку в публічній бібліотеці голосів Fish або клонованих голосів поточного акаунта**. Адреса: `GET https://api.acedata.cloud/fish/model`.

> Щоб створити голос, дивіться [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); щоб отримати детальну інформацію про окремий голос за `_id`, дивіться [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Процес подання заявки

Щоб використовувати Fish Model API, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications), щоб отримати свій API Token, і збережіть його для подальшого використання.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не увійшли в систему або не зареєструвалися, вас буде автоматично перенаправлено на сторінку входу, де вам буде запропоновано зареєструватися та увійти; після завершення ви автоматично повернетеся на поточну сторінку.

**Один API Token дозволяє викликати всі сервіси платформи, без потреби подавати окрему заявку для кожного сервісу.** Під час першого подання заявки надається безкоштовна квота для безкоштовного ознайомлення; коли квоти недостатньо, ви можете поповнити універсальний баланс у [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Параметри запиту

| Параметр             | Тип    | За замовчуванням | Опис                                                                                  |
| ---------------- | ------- | ---- | ------------------------------------------------------------------------------------- |
| `page_size`      | integer | 10   | Кількість записів на сторінці.                                                                            |
| `page_number`    | integer | 1    | Номер сторінки, починаючи з 1.                                                                          |
| `title`          | string  | —    | Нечіткий пошук за назвою.                                                                      |
| `tag`            | string  | —    | Фільтрування за одним тегом.                                                                      |
| `self`           | boolean | —    | Якщо `true`, повертаються лише голоси, створені та збережені через цю платформу поточним обліковим записом виклику.                                |
| `author_id`      | string  | —    | Фільтрування за ID автора голосу.                                                                  |
| `language`       | string  | —    | Фільтрування за мовою голосу, наприклад `en`, `zh`, `es`.                                                  |
| `title_language` | string  | —    | Фільтрування за мовою назви в загальнодоступній бібліотеці голосів.                                                        |
| `sort_by`        | string  | —    | Поле сортування; якщо `self=true`, підтримуються `created_at`, `task_count`.                              |

## Приклад 1: пагінація за замовчуванням (за `page_size`)

```shell
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=2'
```

## Приклад 2: нечіткий пошук за заголовком (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Відповідь (перевірено фактично):

```json
{
  "total": 161,
  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",
      "type": "tts",
      "title": "Miles Morales ( Narration Paw )",
      "tags": ["male", "middle-aged", "entertainment", "storytelling", "Children's Content"],
      "languages": ["en"],
      "visibility": "public",
      "task_count": 770
    },
    {
      "_id": "76b55591c758444cb95253708696dfad",
      "type": "tts",
      "title": "Joe NARRATION",
      "tags": ["male", "middle-aged", "narration", "deep", "raspy"],
      "languages": ["en"],
      "visibility": "public"
    }
  ],
  "has_more": null

```

Зверніть увагу, що `title` є «глобальним нечітким зіставленням» і водночас знаходить усі голоси в публічній бібліотеці Fish (не лише власні).

## Приклад 3: вивести лише створені вами голоси (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Приклад відповіді:

```json
{
  "total": 1,
  "items": [
    {
      "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
      "type": "tts",
      "title": "copilot-smoke-test",
      "description": "smoke test from api.acedata.cloud",
      "state": "trained",
      "languages": ["zh"],
      "visibility": "public",
      "samples": [
        {
          "title": "Default Sample",
          "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
          "task_id": "6a1bf398dfae49dca0e23159214342a0",
          "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
        }
      ],
      "created_at": "2026-05-10T03:52:55.601000Z",
      "author": {
        "_id": "780f2b2f862d41a08c0507bbbda77eb6",
        "nickname": "Penny Conrad"
      }
    }
  ],
  "has_more": false
}
```
`self=true` перелічує голоси, створені та збережені через цю платформу для фактичного акаунта виклику; голоси, створені тим самим акаунтом з використанням різних API Token, також будуть перелічені разом. Результати пагінуються у зворотному хронологічному порядку за часом створення, а `author_id` може додатково фільтрувати ID автора цих голосів. Цей параметр фільтрує лише список, голоси все ще доступні публічно.

`self=true` не підтримує `title_language`; якщо потрібно шукати за мовою назви, виконайте запит до публічної бібліотеки голосів.

## Приклад 4: фільтрування за мовою + тегом

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> `tag` має менш суворе зіставлення; якщо кількість збігів дорівнює 0, рекомендується використовувати нечітке зіставлення `title`.

## Поля відповіді

Кожен елемент у `items[]` є повним об’єктом ModelEntity, поширені поля:

| Поле            | Тип       | Опис                                        |
| ------------- | -------- | ----------------------------------------- |
| `_id`         | string   | ID голосу, використовується як значення `reference_id` у `/fish/tts`. |
| `type`        | string   | Тип моделі, зазвичай `tts`.                           |
| `title`       | string   | Назва голосу.                                     |
| `description` | string   | Опис голосу.                                     |
| `state`       | string   | Стан навчання: `trained` означає доступний.                      |
| `tags`        | string[] | Теги публічної бібліотеки.                                    |
| `languages`   | string[] | Мови, у яких голос найкращий.                                  |
| `visibility`  | string   | `public` або `private`.                     |
| `samples`     | object[] | Попередньо встановлені зразки (містять пряме посилання `audio`).                       |
| `like_count`  | integer  | Кількість вподобань у публічній бібліотеці.                                   |
| `task_count`  | integer  | Кількість історичних синтезів.                                   |
| `author`      | object   | Інформація про автора голосу: `_id` / `nickname` / `avatar`.     |
| `total`（верхній рівень）   | integer  | Загальна кількість елементів, що відповідають умовам.                                 |
| `has_more`    | boolean? | За `self=true` є булевим значенням; запит до публічної бібліотеки голосів може бути `null`.      |

## Інформація про тарифікацію

Цей інтерфейс не тарифікується — пагінований запит списку голосів є безкоштовною операцією. Створення голосів ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) також безкоштовне, витрати виникають лише під час виклику [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) для синтезу мовлення відповідно до використання.

## Обробка помилок

- `400 token_mismatched`: параметри запиту відсутні або недійсні.
- `401 invalid_token`: токен автентифікації не існує або недійсний.
- `429 too_many_requests`: спрацювало обмеження швидкості для акаунта.
- `500 api_error`: внутрішня помилка сервера.

Приклад відповіді з помилкою:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Висновок

Щоб вибрати голос із публічної бібліотеки Fish і передати його до `reference_id` у `/fish/tts`, спочатку використайте цей інтерфейс разом із `title` / `tag` / `language` для пошуку, визначте цільовий `_id`, а потім використайте [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get), щоб отримати зразки для прослуховування. Щоб перелічити голоси, створені вами, достатньо передати `self=true`.
