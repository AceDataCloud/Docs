Цей API базується на [офіційному Model API Fish Audio](https://docs.fish.audio/resources/api-reference/model) і використовується для **створення моделі клонованого голосу, яку можна повторно використовувати протягом тривалого часу, на основі аудіозразка**. Адреса: `POST https://api.acedata.cloud/fish/model`.

> Якщо вам потрібно лише тимчасово використати еталонний голос, немає потреби створювати модель — можна безпосередньо використати одноразове миттєве клонування через `references` у [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts). Для посторінкового пошуку наявних голосів дивіться [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query); для отримання деталей одного голосу за `_id` дивіться [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Процес подання заявки

Щоб використовувати Fish Model API, спершу перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications), щоб отримати свій API Token, і збережіть його для подальшого використання.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не увійшли або не зареєструвалися, вас буде автоматично перенаправлено на сторінку входу із запрошенням зареєструватися та увійти, після завершення ви автоматично повернетеся на поточну сторінку.

**Один API Token може викликати всі сервіси платформи, не потрібно подавати заявку окремо для кожного сервісу.** Під час першого отримання заявки надається безкоштовна квота для безкоштовного тестування; коли квоти недостатньо, ви можете поповнити універсальний баланс у [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Поля тіла запиту

| Поле                      | Тип       | Обов'язкове  | Опис                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | Так   | Назва голосу, яка використовується для його ідентифікації у списку консолі.                                                             |
| `voices`                | string   | Так   | HTTP(S) URL аудіозразка (**один рядок**, не масив). Цей API не підтримує multipart/бінарне завантаження; спершу розмістіть аудіо в будь-якому загальнодоступному об'єктному сховищі. |
| `description`           | string   | Ні   | Опис голосу.                                                                         |
| `cover_image`           | string   | Ні   | HTTP(S) URL зображення обкладинки.                                                              |
| `tags`                  | string[] | Ні   | Теги для пошуку в загальнодоступній бібліотеці, наприклад `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | Ні   | Еталонний текст, що відповідає зразку (використовується для виправлення вимови).                                                           |
| `enhance_audio_quality` | boolean  | Ні   | Чи покращувати якість аудіо зразка перед навчанням.                                                                |
| `generate_sample`       | boolean  | Ні   | Чи автоматично генерувати зразок аудіо після завершення навчання.                                                            |

> Докладнішу інформацію про моделі голосу дивіться в [офіційній документації Fish](https://docs.fish.audio/resources/api-reference/model).

> Створений голос буде збережено у відкритому доступі на тривалий час, і інші користувачі можуть шукати та використовувати його. Не потрібно передавати `visibility`; навіть якщо передати `private` або `unlist`, поточний API не змінить на цій підставі область публічного доступу.

## Приклад: створення публічного клонованого голосу

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的中文音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Зверніть увагу: `voices` має бути **рядком** (один URL аудіо), а не масивом. Якщо передати як `["..."]`, upstream відхилить запит. Рекомендується використовувати загальнодоступне пряме посилання, яке можна завантажити, із суфіксом `.mp3` або `.wav`.

Успішна відповідь безпосередньо повертає об'єкт ModelEntity платформи Fish (у прикладі нижче показано мінімальний придатний голос, який ми протестували; деякі довгі поля видалено для зручності читання):

`_id` можна використовувати як значення поля `reference_id` у подальшому [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts), щоб виконувати синтез мовлення з використанням цього клонованого голосу:

Успішно створений голос буде збережено у відкритому доступі; через `self=true` у [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query) можна отримати голоси, створені поточним користувачем-викликачем через цю платформу. `self=true` лише фільтрує список і не обмежує використання цього голосу іншими користувачами.

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，这是一段使用我刚创建的克隆音色合成的语音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Вимоги до зразків

Практичні рекомендації (відповідають upstream; дивіться [офіційну документацію Fish](https://docs.fish.audio/resources/api-reference/model)):

- Рекомендована тривалість — понад 30 секунд, найкращий результат — до 5 хвилин; після 10 хвилин гранична користь невелика.
- Частота дискретизації 16 кГц і вище, підходять як моно, так і стерео.
- Вміст має бути якомога чистішим: без фонової музики, луни та помітного шуму середовища; один і той самий мовник.
- Рекомендовані формати: `mp3` / `wav`.

Якщо ви не впевнені в якості зразка, можна одночасно передати `enhance_audio_quality: true`, щоб upstream спершу покращив якість аудіо.

## Опис тарифікації
Створення моделі клонування голосу (`POST /fish/model`) безкоштовне, жодна плата не стягується; інтерфейси запиту голосів ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)、[Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) також не тарифікуються. Витрати виникають лише під час подальшого виклику [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) для синтезу мовлення відповідно до використання.

## Обробка помилок

- `400 token_mismatched`: параметри запиту відсутні або недійсні (найчастіше `voices` не є URL або передано як масив).
- `400`: якщо еталонне аудіо неможливо завантажити, його тривалість надто коротка або формат не розпізнається, перевірте URL аудіо та формат файлу.
- `401 invalid_token`: токен автентифікації не існує або недійсний.
- `429 too_many_requests`: спрацьовує обмеження швидкості для облікового запису.
- `500 api_error`: внутрішня помилка сервера.

Приклад відповіді з помилкою:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Висновок

Для виклику цього інтерфейсу потрібно лише підготувати URL зразка аудіо, доступного публічно, помістити його в поле `voices`, щоб отримати `_id`, а потім передати його до `reference_id` у `/fish/tts`, і буде завершено наскрізний процес «клонування → синтез». Поширена помилка полягає в тому, що `voices` має бути рядком, а не масивом.

## Створення та повторне використання голосу через MCP

У Fish MCP викличте
`fish_create_model(title="Мій голос", voices="https://example.com/authorized-voice.wav")`.
`voices` — це один HTTP(S) URL аудіо; також можна передати `description`, `cover_image`, `tags`,
`texts`, `enhance_audio_quality`, `generate_sample`.

Цей інструмент довгостроково зберігає публічні голоси, інші користувачі можуть виявити та використовувати їх; використовуйте лише
аудіоматеріали, на обробку та публікацію яких отримано дозвіл. Інструмент не має приватної або непублічної опції. Повернений після успішного створення `_id` використовується для
`reference_id` у `fish_generate_audio`, а `fish_list_models(self=true)` може запитувати власні
збережені голоси. Якщо еталонний голос потрібен лише одноразово, використовуйте `references` у `fish_generate_audio`,
без необхідності створювати довгостроковий голос.
