Цей інтерфейс базується на [Fish Audio офіційному Model API](https://docs.fish.audio/resources/api-reference/model) і призначений для **створення нового клонованого голосу на основі аудіо зразка**. Адреса: `POST https://api.acedata.cloud/fish/model`.

> Для пагінованого пошуку існуючих голосів, будь ласка, зверніться до [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query); для запиту деталей одного голосу за `_id` зверніться до [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Процес подачі заявки

Щоб використовувати Fish Model API, спочатку перейдіть до [Ace Data Cloud консолі](https://platform.acedata.cloud/console/applications) для отримання вашого API Token, зберігайте його для подальшого використання.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, щоб запросити реєстрацію та вхід, після чого ви будете автоматично повернені на цю сторінку.

**Один API Token дозволяє викликати всі послуги платформи, не потрібно окремо запитувати для кожної послуги.** Перший запит на отримання токена надає безкоштовний ліміт для тестування; при недостатньому ліміті ви можете поповнити загальний баланс в [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Параметри запиту

| Поле                      | Тип       | Обов'язкове  | Опис                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | Так   | Назва голосу, використовується для ідентифікації в списку консолі.                                                             |
| `voices`                | string   | Так   | HTTP(S) URL аудіо зразка (**один рядок**, не масив). Цей інтерфейс не підтримує multipart/бінарне завантаження, спочатку розмістіть аудіо в будь-якому загальнодоступному об'єктному сховищі. |
| `description`           | string   | Ні   | Опис голосу.                                                                         |
| `cover_image`           | string   | Ні   | HTTP(S) URL обкладинки.                                                              |
| `tags`                  | string[] | Ні   | Теги для пошуку в загальній бібліотеці, наприклад, `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | Ні   | Посилання на текст, що відповідає зразку (для корекції вимови).                                                           |
| `enhance_audio_quality` | boolean  | Ні   | Чи потрібно покращити якість звуку зразка перед навчанням.                                                                |
| `generate_sample`       | boolean  | Ні   | Чи потрібно автоматично генерувати зразок аудіо після завершення навчання.                                                            |

> Поля повністю відповідають верхньому рівню, будь ласка, також зверніться до [Fish офіційної документації](https://docs.fish.audio/resources/api-reference/model).

## Приклад: створення приватного клонованого голосу

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "Мій клонований голос",
    "description": "Клонований китайський голос з подкасту",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Зверніть увагу: `voices` має бути **рядком** (один аудіо URL), а не масивом. Якщо передати як `["..."]`, верхній рівень відмовить.

Успішна відповідь повертає об'єкт ModelEntity платформи Fish (нижче наведено наш мінімальний тестований голос, частини довгих полів видалено для зручності читання):

```json
{

  "type": "tts",
  "title": "copilot-smoke-test",
  "description": "smoke test from api.acedata.cloud",
  "cover_image": "coverimage/e5c6db52c3ed417f9cb2e5a33fb04667",
  "train_mode": "fast",
  "state": "trained",
```

`_id` може бути використаний як значення поля `reference_id` в подальшому [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) для синтезу мови з використанням цього клонованого голосу:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，这是一段使用我刚创建的克隆音色合成的语音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Вимоги до зразків

Рекомендації (відповідають верхньому рівню, можна звернутися до [Fish офіційної документації](https://docs.fish.audio/resources/api-reference/model)):

- Рекомендується тривалість від 30 секунд до 5 хвилин; понад 10 хвилин маржа вигоди незначна.
- Частота дискретизації 16 кГц і вище, моно або стерео.
- Зміст має бути якомога чистішим: без фонової музики, відлуння, явного шуму; один і той же спікер.
- Рекомендується формат `mp3` / `wav`.

Якщо ви не впевнені в якості зразка, ви можете одночасно передати `enhance_audio_quality: true`, щоб верхній рівень спочатку покращив якість звуку.

## Інформація про тарифи

Створення моделі клонованого голосу (`POST /fish/model`) безкоштовне, ніяких витрат не стягується; інтерфейси запиту голосу ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query), [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) також безкоштовні. Витрати виникають лише при подальшому виклику [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) для синтезу мови.

## Обробка помилок

- `400 token_mismatched`: відсутні або недійсні параметри запиту (найпоширеніша причина - `voices` не є URL, або передано як масив).
- `401 invalid_token`: токен авторизації відсутній або недійсний.
- `429 too_many_requests`: перевищено обмеження швидкості облікового запису.
- `500 api_error`: внутрішня помилка сервера.

Приклад помилкової відповіді:
```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices є обов'язковим і має бути URL HTTP(S), що вказує на аудіофайл"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Висновок

Для виклику цього інтерфейсу потрібно підготувати доступне для публіки зразкове аудіо URL, помістити його в поле `voices`, щоб отримати `_id`, а потім передати його в `reference_id` для `/fish/tts`, щоб завершити енд-ту-енд «клонування → синтез». Загальні проблеми полягають у тому, що `voices` має бути рядком, а не масивом.
