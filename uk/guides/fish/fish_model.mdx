Цей інтерфейс базується на [Fish Audio офіційному Model API](https://docs.fish.audio/resources/api-reference/model) і призначений для **створення довгостроково використовуваної клонованої звукової моделі на основі аудіо зразка**. Адреса: `POST https://api.acedata.cloud/fish/model`.

> Якщо вам потрібно тимчасово використовувати референсний звук, модель створювати не потрібно, можна безпосередньо використовувати [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) з `references` для одноразового миттєвого клонування. Для пагінованого пошуку існуючих звуків зверніться до [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query); для запиту деталей окремого звуку за `_id` зверніться до [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Процес подачі заявки

Щоб використовувати Fish Model API, спочатку перейдіть до [Ace Data Cloud консолі](https://platform.acedata.cloud/console/applications) для отримання вашого API Token, зберігайте його для подальшого використання.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, щоб запросити реєстрацію та вхід, після чого ви будете автоматично повернені на цю сторінку.

**Один API Token дозволяє викликати всі послуги платформи, не потрібно окремо запитувати для кожної послуги.** Перший запит на отримання токена надає безкоштовний ліміт для тестування; якщо ліміт вичерпано, ви можете поповнити загальний баланс в [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Поля тіла запиту

| Поле                      | Тип       | Обов'язкове  | Опис                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | Так   | Назва звуку, використовується для ідентифікації в списку консолі.                                                             |
| `voices`                | string   | Так   | HTTP(S) URL аудіо зразка (**один рядок**, не масив). Цей інтерфейс не підтримує multipart/бінарне завантаження, спочатку розмістіть аудіо в будь-якому загальнодоступному об'єктному сховищі. |
| `description`           | string   | Ні   | Опис звуку.                                                                         |
| `cover_image`           | string   | Ні   | HTTP(S) URL обкладинки.                                                              |
| `tags`                  | string[] | Ні   | Теги для пошуку в загальній бібліотеці, наприклад, `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | Ні   | Референсні тексти, що відповідають зразкам (для корекції вимови).                                                           |
| `enhance_audio_quality` | boolean  | Ні   | Чи потрібно покращити якість звуку перед навчанням.                                                                |
| `generate_sample`       | boolean  | Ні   | Чи потрібно автоматично генерувати зразок аудіо після завершення навчання.                                                            |

> Поля повністю відповідають верхньому рівню, будь ласка, також зверніться до [Fish офіційної документації](https://docs.fish.audio/resources/api-reference/model).

## Приклад: створення приватного клонованого звуку

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "Мій клонований звук",
    "description": "Клонований китайський звук з подкасту",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Зверніть увагу: `voices` має бути **рядком** (один аудіо URL), а не масивом. Якщо передати як `["..."]`, верхній рівень відмовить.

Успішна відповідь повертає об'єкт ModelEntity платформи Fish (нижче наведено наш мінімальний тестований звук, частини довгих полів видалено для зручності читання):

```json

  "cover_image": "coverimage/e5c6db52c3ed417f9cb2e5a33fb04667",
```

`_id` може бути використаний як значення поля `reference_id` в подальшому [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) для використання цього клонованого звуку для синтезу мови:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Привіт, це фрагмент мови, синтезований з використанням щойно створеного клонованого звуку.",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Вимоги до зразків

Рекомендації (відповідають верхньому рівню, можна звернутися до [Fish офіційної документації](https://docs.fish.audio/resources/api-reference/model)):

- Рекомендується тривалість від 30 секунд до 5 хвилин; понад 10 хвилин маргінальна вигода незначна.
- Частота дискретизації 16 кГц і вище, моно або стерео.
- Зміст має бути якомога чистішим: без фонової музики, відлуння, явного шуму навколишнього середовища; один і той же спікер.
- Рекомендується формат `mp3` / `wav`.

Якщо ви не впевнені в якості зразка, ви можете одночасно передати `enhance_audio_quality: true`, щоб верхній рівень спочатку покращив якість звуку.

## Інформація про тарифи

Створення клонованої звукової моделі (`POST /fish/model`) безкоштовне, жодних витрат не стягується; інтерфейси запиту звуку ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query), [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) також не підлягають оплаті. Витрати виникають лише під час подальшого виклику [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) для синтезу мови.

## Обробка помилок
- `400 token_mismatched`：параметри запиту відсутні або недійсні (найпоширеніша причина - `voices` не є URL, або передано у вигляді масиву).
- `401 invalid_token`：токен авторизації відсутній або недійсний.
- `429 too_many_requests`：активовано обмеження швидкості облікового запису.
- `500 api_error`：внутрішня помилка сервера.

Приклад помилки:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Висновок

Для виклику цього інтерфейсу потрібно підготувати зразок аудіо URL, доступний для публічного доступу, помістити його в поле `voices`, щоб отримати `_id`, а потім передати його в `reference_id` для `/fish/tts`, щоб завершити процес «клонування → синтезу». Поширена помилка - `voices` повинно бути рядком, а не масивом.
