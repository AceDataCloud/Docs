У цій статті описано інтеграцію та використання Nano Banana Images API. Цей інтерфейс підтримує дві функції: **генерація зображень (generate)** та **редагування зображень (edit)**.

## Процес отримання доступу

Щоб використовувати Nano Banana Images API, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications), щоб отримати свій API Token і зберегти його для подальшого використання.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не ввійшли в систему або не зареєструвалися, вас автоматично буде перенаправлено на сторінку входу із пропозицією зареєструватися та увійти. Після завершення ви автоматично повернетеся на поточну сторінку.

**Одного API Token достатньо для виклику всіх сервісів платформи, немає потреби окремо подавати заявку на кожен сервіс.** Під час першого отримання доступу надається безкоштовний ліміт, яким можна користуватися без оплати; коли ліміту буде недостатньо, ви можете поповнити загальний баланс у [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## Огляд API

- **Base URL**: `https://api.acedata.cloud`
- **Endpoint**: `POST /nano-banana/images`
- **Спосіб автентифікації**: передайте `authorization: Bearer {token}` у HTTP Header
- **Заголовки запиту**:
  - `accept: application/json`
  - `content-type: application/json`
- **Дія (action)**:
  - `generate`: генерування зображень на основі текстових підказок
  - `edit`: редагування на основі наданих зображень
- **Модель (model)** (необов'язково):
  - `nano-banana` (за замовчуванням): базується на Gemini 2.5 Flash Image, швидка робота, низька вартість
  - `nano-banana-2-lite`: базується на Gemini 3.1 Flash Lite Image, підтримує лише 1K, висока швидкість генерації
  - `nano-banana-2`: базується на Gemini 3.1 Flash Image Preview, якість рівня Pro + швидкість Flash
  - `nano-banana-2.1`: нова ефективна модель зображень, підтримує генерацію та редагування з роздільною здатністю 1K, 2K і 4K
  - `nano-banana-pro`: базується на Gemini 3 Pro Image Preview, найвища якість
  - `nano-banana:official`, `nano-banana-2-lite:official`, `nano-banana-2:official`, `nano-banana-pro:official`: офіційні версії відповідних моделей, які забезпечують кращу якість зображень і стабільність, але мають інші тарифи
- **Асинхронний зворотний виклик**: необов'язковий, отримання сповіщень про завершення завдання та результатів через `callback_url`
- **Кількість зображень**: необов'язково, за допомогою `count` можна вказати від 1 до 4 зображень, за замовчуванням — 1; кожне зображення створюється окремим викликом генерації; звичайні технічні помилки або відмова постачальника з міркувань безпеки впливають лише на відповідний виклик, інші успішно згенеровані зображення повертаються як зазвичай, а оплата стягується відповідно до фактичної кількості успішно створених зображень

## Швидкий старт: генерація зображень (`action=generate`)

**Мінімально необхідні параметри**: `action`, `prompt`

Якщо ви хочете безпосередньо створити зображення на основі текстової підказки, достатньо встановити для `action` значення `generate` і надати чіткий `prompt`.

### Приклад запиту (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Приклад запиту (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Приклад успішної відповіді

```json
{
  "success": true,
  "task_id": "70e6931b-6e34-43db-9e36-8765e2809d04",
  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {
      "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
      "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }
  ]
}
```

### Опис полів

- `success`: чи був успішним поточний запит.
- `task_id`: ID завдання.
- `trace_id`: ID відстеження ланцюжка викликів, що полегшує пошук і усунення проблем.
- `count`: кількість зображень, запитаних для генерації або редагування; підтримується від 1 до 4, за замовчуванням — 1. `data` містить лише успішно згенеровані зображення, а оплата здійснюється відповідно до фактичної кількості повернутих зображень. Для кожного виклику примусово застосовується вбудована політика безпеки постачальника; відхилення одного виклику не впливає на інші успішні виклики, якщо всі виклики відхилено, повертається код 403.
- `data[]`: список результатів.
  - `prompt`: текстова підказка, використана для генерації (повертається у відповіді).
  - `image_url`: пряме посилання на згенероване зображення.

> Примітка: для генерації зображень через `/nano-banana/images` потрібні лише `action` і `prompt`.

## Редагування зображень (`action=edit`)

Якщо ви хочете відредагувати наявне зображення, встановіть для `action` значення `edit` і передайте список посилань на зображення, які потрібно відредагувати (одне або кілька), через `image_urls`, а також надайте `prompt` з описом мети редагування.

Наприклад, тут ми надаємо одну фотографію людини та одну фотографію одягу, щоб одягнути людину в цей одяг. У такому разі можна одночасно передати посилання на зображення та вказати для action значення `edit`. URL може бути HTTP URL — загальнодоступним посиланням, доступним за протоколом `https` або `http`, а також зображенням у кодуванні Base64, наприклад `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Приклад запиту (cURL)
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Приклад запиту (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

- Інші поля такі самі, як у відповіді для «Генерації зображень».

## Асинхронний зворотний виклик (необов’язково, рекомендовано)

Генерація або редагування можуть потребувати певного часу. Щоб уникнути зайвого використання ресурсів через тривале з’єднання, рекомендується використовувати **Webhook-зворотний виклик** через `callback_url`:

1. Додайте `callback_url` до тіла запиту, наприклад адресу Webhook вашого сервера (має бути доступною з публічного Інтернету та підтримувати POST JSON).
2. API **негайно поверне** відповідь із `task_id` (або основним результатом).
3. Після завершення завдання платформа надішле повний JSON на `callback_url` методом `POST`. Ви можете пов’язати запит із результатом за допомогою `task_id`.

**Приклад даних зворотного виклику** (структура полів така сама, як у синхронній успішній відповіді):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Обробка помилок

У разі невдалого виклику буде повернено стандартний формат помилки та ID відстеження. Найпоширеніші помилки:

- **400 `token_mismatched`**: некоректний запит або помилка в параметрах.
- **400 `api_not_implemented`**: інтерфейс не реалізовано (зверніться до служби підтримки).
- **401 `invalid_token`**: помилка автентифікації або відсутній Token.
- **403 `forbidden`**: вбудована політика безпеки постачальника відхилила запит або результат генерації. Цей виклик не поверне зображення та не тарифікуватиметься; запити з кількома зображеннями все одно можуть повертати результати й тарифікуватися за інші успішні виклики.
- **429 `too_many_requests`**: перевищено допустиму частоту запитів.
- **500 `api_error`**: помилка сервера.

### Приклад відповіді з помилкою

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Порівняння параметрів і примітки

- **Обов’язкові**: `action`, `prompt`
- **Лише для редагування**: `image_urls` (масив, щонайменше 1 елемент)
- **Необов’язкові**: `model` (за замовчуванням `nano-banana`, доступні також `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-2.1`, `nano-banana-pro`; для всіх моделей, крім `nano-banana-2.1`, також доступні відповідні офіційні версії каналів `:official`), `aspect_ratio` (`auto` або конкретне співвідношення сторін, наприклад `1:1`, `16:9`), `resolution` (роздільна здатність, наприклад `1K`, `2K`, `4K`; `nano-banana-2-lite` підтримує лише `1K`), `callback_url` (для асинхронного зворотного виклику)
- **Headers**: обов’язково потрібно вказати `authorization: Bearer {token}`; для `accept` рекомендується значення `application/json`
- **Доступність зображень**: `image_urls` мають містити прямі посилання, доступні з публічного Інтернету (HTTP/HTTPS); рекомендується використовувати HTTPS
- **Ідемпотентність і відстеження**: зберігайте `task_id` і `trace_id` для усунення несправностей і пов’язування результатів

Якщо явно передати `"aspect_ratio": "auto"`, система вибере найближче попередньо встановлене співвідношення сторін відповідно до пропорцій, орієнтації або макета, зазначених у підказці. Це підходить як для генерації, так і для редагування. Наприклад, якщо в підказці зазначено «мініатюра YouTube», можна вибрати `16:9`. Якщо в підказці немає вимог до розміру або автоматичне визначення недоступне, для генерації тексту в зображення використовується формат кадру за замовчуванням, а для редагування зображення — формат першого референсного зображення з найближчим підтримуваним співвідношенням сторін. Якщо це поле не вказано, використовується формат кадру за замовчуванням або співвідношення сторін референсного зображення. Якщо вимоги до формату кадру вже чітко визначені, передавайте конкретне співвідношення сторін безпосередньо.
