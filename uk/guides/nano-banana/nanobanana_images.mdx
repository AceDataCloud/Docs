Цей документ описує інтеграцію та використання Nano Banana Images API. Цей інтерфейс підтримує дві можливості: **генерація зображень (generate)** та **редагування зображень (edit)**.

## Процес подачі заявки

Щоб використовувати Nano Banana Images API, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications) для отримання вашого API Token, зберігайте його для подальшого використання.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, щоб запросити реєстрацію та вхід, після чого ви будете автоматично повернені на цю сторінку.

**Один API Token дозволяє викликати всі послуги платформи, не потрібно окремо подавати заявку на кожну послугу.** Перший запит на отримання токена надає безкоштовний ліміт, щоб ви могли безкоштовно спробувати; якщо ліміт вичерпано, ви можете поповнити загальний баланс в [консолі](https://platform.acedata.cloud/console/coin).

> 📘 Повна документація: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## Огляд інтерфейсу

- **Базовий URL**: `https://api.acedata.cloud`
- **Кінцева точка**: `POST /nano-banana/images`
- **Метод аутентифікації**: HTTP Header містить `authorization: Bearer {token}`
- **Заголовки запиту**:
  - `accept: application/json`
  - `content-type: application/json`
- **Дії (action)**:
  - `generate`: генерувати зображення на основі текстового підказки
  - `edit`: редагувати на основі наданого зображення
- **Модель (model)** (необов'язково):
  - `nano-banana` (за замовчуванням): на основі Gemini 2.5 Flash Image, швидка, низька вартість
  - `nano-banana-2-lite`: на основі Gemini 3.1 Flash Lite Image, підтримує лише 1K, швидка генерація
  - `nano-banana-2`: на основі Gemini 3.1 Flash Image Preview, Pro рівень якості + Flash швидкість
  - `nano-banana-pro`: на основі Gemini 3 Pro Image Preview, найвища якість
  - `nano-banana:official`, `nano-banana-2-lite:official`, `nano-banana-2:official`, `nano-banana-pro:official`: офіційні версії відповідних моделей, краща якість зображення та стабільність, різна вартість
- **Асинхронний зворотний виклик**: необов'язково, через `callback_url` отримувати сповіщення про завершення завдання та результати

## Швидкий старт: генерація зображення (`action=generate`)

**Мінімально необхідні параметри**: `action`, `prompt`
Коли ви хочете безпосередньо отримати зображення на основі підказки, встановіть `action` на `generate` і надайте чіткий `prompt`.

### Приклад запиту (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "Фотореалістичний крупний план портрета літнього японського кераміста з глибокими, сонячними зморшками та теплим, усміхненим обличчям. Він уважно оглядає свіжозроблену чайну чашку. Обстановка - його сільська, залита сонцем майстерня. Сцена освітлена м'яким, золотим світлом, що проникає через вікно, підкреслюючи тонку текстуру глини. Знято з об'єктивом 85 мм, що призводить до м'якого, розмитого фону (боке). Загальний настрій спокійний і майстерний. Вертикальна орієнтація портрета.",
    "count": 1
  }'
```

### Приклад запиту (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "Фотореалістичний крупний план портрета літнього японського кераміста "
        "з глибокими, сонячними зморшками та теплим, усміхненим обличчям. Він уважно "
        "оглядає свіжозроблену чайну чашку. Обстановка - його сільська, залита сонцем "
        "майстерня. Сцена освітлена м'яким, золотим світлом, що проникає через "
        "вікно, підкреслюючи тонку текстуру глини. Знято з об'єктивом 85 мм "
        "з розмитим фоном (боке). Загальний настрій спокійний і майстерний. "
        "Вертикальна орієнтація портрета."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Опис полів

- `success`: чи був запит успішним.
- `task_id`: ID завдання.

- `data[]`: список результатів.

  - `image_url`: пряма URL-адреса згенерованого зображення.

> Примітка: `/nano-banana/images` потрібно лише `action` та `prompt`, щоб згенерувати зображення

## Редагування зображення (`action=edit`)

Коли ви хочете редагувати на основі вже існуючого зображення, встановіть `action` на `edit` і передайте список URL-адрес зображень для редагування (1 або більше), одночасно надаючи опис цілей редагування в `prompt`.

Наприклад, тут ми надаємо фотографію людини та фотографію одягу, щоб людина могла одягнути цей одяг, тому можна одночасно передати URL-адреси зображень і вказати action як `edit`, URL можуть бути HTTP URL, відкриті для доступу через протоколи `https` або `http`, або можуть бути зображення в кодуванні Base64, наприклад `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Приклад запиту (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "дозвольте цій людині одягнути цю футболку",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

## Асинхронний зворотний виклик (необов'язково, рекомендовано)

Генерація або редагування можуть зайняти певний час. Щоб уникнути тривалих з'єднань, рекомендується використовувати `callback_url` для **Webhook зворотного виклику**:

1. Додайте `callback_url` до тіла запиту, наприклад, адресу вашого сервера Webhook (повинен бути доступний з публічної мережі, підтримувати POST JSON).
2. API **відразу поверне** відповідь, що містить `task_id` (або базовий результат).
3. Коли завдання буде завершено, платформа надішле повний JSON на `callback_url` за допомогою `POST`. Ви можете пов'язати запит з результатом за допомогою `task_id`.

**Приклад навантаження зворотного виклику** (структура полів така ж, як у синхронному успішному поверненні):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "біла сіамська кішка",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
```

## Обробка помилок

При невдалому виклику буде повернено стандартний формат помилки та ідентифікатор відстеження. Поширені помилки:

- **400 `token_mismatched`**：недійсний запит або помилка параметрів.
- **400 `api_not_implemented`**：інтерфейс не реалізовано (будь ласка, зв'яжіться з підтримкою).
- **401 `invalid_token`**：не вдалося пройти аутентифікацію або відсутній токен.
- **429 `too_many_requests`**：перевищено частоту запитів.
- **500 `api_error`**：виклик сервера не вдався.

### Приклад відповіді з помилкою

```json

  "success": false,
  "error": {
    "code": "api_error",
    "message": "Внутрішня помилка сервера."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Параметри та зауваження

- **Обов'язкові**：`action`、`prompt`
- **Спеціально для редагування**：`image_urls`（масив, щонайменше 1 елемент）
- **Необов'язкові**：`model`（за замовчуванням `nano-banana`, можна вибрати `nano-banana-2-lite`、`nano-banana-2`、`nano-banana-pro`, або відповідні версії `:official`), `aspect_ratio`（співвідношення сторін, наприклад, `1:1`、`16:9`）、`resolution`（роздільна здатність, наприклад, `1K`、`2K`、`4K`; `nano-banana-2-lite` підтримує лише `1K`）、`callback_url`（для асинхронного зворотного виклику）
- **Заголовки**：необхідно надати `authorization: Bearer {token}`; `accept` рекомендується встановити на `application/json`
- **Доступність зображень**：`image_urls` повинні бути прямими посиланнями, доступними з публічної мережі (HTTP/HTTPS), рекомендується використовувати HTTPS
- **Ідемпотентність та відстеження**：зберігайте `task_id` та `trace_id`, щоб полегшити усунення неполадок та зв'язок результатів
