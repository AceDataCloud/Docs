SUNO дозволяє нам створювати користувацьких голосових персонажів за допомогою будь-якого аудіофайлу, реалізуючи клонування голосу для генерації музики. На відміну від наявного Persona API (який використовує згенерований Suno `audio_id`), цей API приймає публічно доступний `audio_url`, тобто ваш власний запис голосу. Цей документ пояснює спосіб інтеграції API клонування голосу.

У лінії створення, що підтримує перевірку тембру, можна використати початковий застосунок та ідентифікацію виклику й передати `persona_id` з результату створення до `POST /suno/availability`. Коли пов’язаний акаунт онлайн, повертається `data.available=true`, а коли офлайн підтверджено — повертається `data.available=false`. [Посібник із перевірки доступності тембру](https://platform.acedata.cloud/documents/suno-availability-integration)

## Крок перший: створення голосового персонажа

Тарифікація: після успішного створення голосового персонажа стандартна вартість кожного запиту становить **0.15 Credits**. Застосовні знижки на споживання визначаються фактичним рахунком, невдалі запити не оплачуються.

Цей API має три вхідні параметри: `audio_url` (обов’язковий), який є URL публічно доступного аудіофайлу у форматі MP3 або WAV із чітким голосом однієї людини; `name` і `description` (необов’язкові), які є назвою та описом голосового персонажа.

> **Вимоги до аудіофайлу**
> - Формат аудіо має бути `WAV` або `MP3`
> - Тривалість аудіо має бути в межах `10~240 секунд`; рекомендується використовувати чистий матеріал із сухим голосом однієї людини тривалістю `30~60 секунд`
> - Аудіо має містити **чіткий, розпізнаваний голос однієї людини, що говорить або співає**
> - Обов’язково уникайте **фонового шуму, акомпанементу, еха, реверберації**; повні пісні з акомпанементом зазвичай не проходять перевірку голосового відбитка
> - Не включайте **кількох мовців** або **кілька голосів**
> - Матеріали із занадто низькою гучністю, нечітким мовленням або надмірним шумом можуть призвести до **невдалого клонування** або **гіршого результату генерації**
> **Опис обмежень використання**
> - Голосові персонажі, створені шляхом завантаження аудіо, є **приватними ресурсами**
> - Цей голосовий персонаж **не підтримує повторне використання між акаунтами**
> - Рекомендується використати його якомога швидше після успішного створення; у разі тривалої невикористаності він може **стати недійсним або недоступним**
> - Повернене значення `name` генерується системою автоматично, орієнтуйтеся на повернений `persona_id`

> **Обробляйте збої за явною ознакою повторної спроби**
> `retryable` в об’єкті помилки є необов’язковим булевим полем. Коли `error.retryable` дорівнює `true`, це означає, що після цього збою дозволено пізніше повторно надіслати запит із тим самим матеріалом і тими самими параметрами. Явно невиконані запити через зайнятість сервісу або деякі тимчасові збої перевірки голосового відбитка можуть мати цю ознаку; рекомендується використовувати інтервали з відступом і обмежувати кількість повторних спроб.
> Коли `retryable` дорівнює `false` або поле відсутнє, не надсилайте повторно автоматично лише на підставі HTTP 500, `busy` або тексту помилки. Проблеми формату, тривалості, чіткості, повторного запису та модерації вмісту слід спочатку виправити; у разі тайм-ауту надсилання, переривання з’єднання або неясного результату створення слід пріоритетно використати початковий `task_id` для перевірки завдання, щоб уникнути повторного створення тембру. Невдалі запити не тарифікуються, а успішні повторні запити тарифікуються за звичайними правилами.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Вищезазначений `https://cdn.acedata.cloud/suno_demo.mp3` є прикладом матеріалу, який можна викликати безпосередньо (MP3, 41 секунда, сухий голос однієї людини).
> Якщо потрібен приклад у форматі `WAV`, можна використати
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 секунда, моно, 44.1kHz).

Результат такий:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Як видно, поле `persona_id` у `data` є ID створеного голосового персонажа. Поле `is_public` завжди має значення `false`, оскільки голосові персонажі, створені шляхом завантаження аудіо, є приватними. Зверніть увагу, що повернене значення `name` генерується системою автоматично; надалі використовуйте `persona_id` для посилання на цей голосовий персонаж.

## Крок другий: використання голосового персонажа для генерації музики

Після отримання ID голосового персонажа ми можемо використовувати [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для генерації музики. Установіть `action` як `generate` і встановіть `persona_id` як ID голосового персонажа, повернений вище; згенерована пісня буде виконана клонованим голосом.

> **Примітка:** Клонування голосу підтримує лише моделі `chirp-v4-5` і вище (наприклад, `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`) та не підтримує `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Результат такий:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` можна використовувати для генерації `generate`, а також для каверів `cover` / `upload_cover`. Під час зазначення голосу не потрібно одночасно заповнювати `vocal_gender`; схожість голосу все ще залежить від еталонного матеріалу та результату генерації.

Голоси, створені через цей інтерфейс, є приватними ресурсами. Перед створенням каверу на наявну пісню спочатку викличте `/suno/upload`, передавши `audio_url` оригінальної пісні та `persona_id` цього голосу; після успішного завантаження викличте `/suno/audios` із поверненим `data.audio_id` та тим самим `persona_id`:
```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

Створення голосу, завантаження оригінальної пісні та кавер-версії повинні використовувати той самий сервісний канал. Будь ласка, не використовуйте безпосередньо ID пісні, який раніше не був пов’язаний із цим приватним голосом; докладніше див. [Suno завантаження довідкового аудіо](https://platform.acedata.cloud/documents/suno-upload).
