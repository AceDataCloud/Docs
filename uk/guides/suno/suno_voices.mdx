title: "Інструкція з інтеграції Suno API для клонування голосу"

---

SUNO дозволяє створювати кастомні голосові персонажі на основі будь-яких аудіофайлів, реалізуючи клонування голосу для генерації музики. На відміну від існуючого Persona API (який використовує `audio_id`, згенерований Suno), цей API приймає публічно доступний `audio_url` — власний запис людського голосу. У цій документації описано, як інтегрувати API клонування голосу.

## Крок 1: Створення голосового персонажа

API має три вхідні параметри: `audio_url` (обов’язковий) — URL публічно доступного аудіофайлу формату MP3 або WAV з чітким одноособовим голосом; `name` та `description` (необов’язкові) — назва та опис голосового персонажа.

**Вимоги до аудіофайлу:**
- Формат: MP3 або WAV
- Тривалість: не менше 10 секунд
- Зміст: чіткий одноособовий голос, мінімум фонових шумів або музики

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

Результат:

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

Як бачимо, поле `persona_id` у `data` — це ID створеного голосового персонажа. Поле `is_public` завжди `false`, оскільки голосові персонажі, створені через завантаження аудіо, є приватними.

## Крок 2: Генерація музики з використанням голосового персонажа

Після отримання ID голосового персонажа можна використовувати [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) для генерації музики. Встановіть `action` в `generate`, а `persona_id` — у значення ID голосового персонажа, отриманого вище. Згенерована пісня буде виконана клонованим голосом.

> **Увага:** Клонування голосу підтримується лише моделями `chirp-v4-5` та вище (наприклад, `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), не підтримується `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

Результат:

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

Як бачимо, згенерована пісня виконана клонованим голосом. `persona_id` також можна використовувати з дією `cover` для виконання каверів існуючих пісень клонованим голосом.
