SUNO дозволяє нам створювати користувацьких голосових персонажів через будь-які аудіофайли, реалізуючи клонування голосу для генерації музики. На відміну від наявного Persona API (який використовує `audio_id`, згенерований Suno), цей API приймає публічно доступний `audio_url`, тобто ваш власний запис людського голосу. Цей документ пояснює метод інтеграції API клонування голосу.

## Перший крок: створення голосового персонажа

Цей API має три вхідні параметри: `audio_url` (обов’язковий), який є URL загальнодоступного аудіофайлу у форматі MP3 або WAV, що містить чіткий голос однієї людини; `name` і `description` (необов’язкові), які є назвою та описом голосового персонажа.

> **Вимоги до аудіофайлу**
> - Формат аудіо має бути `WAV` або `MP3`
> - Тривалість аудіо має бути в межах `10~240 секунд`; рекомендовано використовувати чистий матеріал із сухим голосом однієї людини тривалістю `30~60 секунд`
> - Аудіо має містити **чіткий, розпізнаваний голос однієї людини, що говорить або співає**
> - Обов’язково уникайте **фонового шуму, акомпанементу, відлуння, реверберації**; повні пісні з акомпанементом зазвичай не проходять перевірку голосового відбитка
> - Не додавайте **кількох мовців** або **кілька голосів**
> - Матеріали із надто низькою гучністю, нечітким мовленням або надмірним шумом можуть призвести до **невдалого клонування** або **гіршого результату генерації**
>
> **Опис обмежень використання**
> - Голосові персонажі, створені шляхом завантаження аудіо, є **приватними ресурсами**
> - Цей голосовий персонаж **не підтримує повторне використання між акаунтами**
> - Рекомендовано використати його якомога швидше після успішного створення; за тривалого невикористання він може **стати недійсним або недоступним**
> - Повернене значення `name` автоматично генерується системою, орієнтуйтеся на повернений `persona_id`

> **У разі невдалого виклику спочатку повторіть спробу**
> Клонування голосу є обчислювально інтенсивним завданням, тому навіть за повної відповідності матеріалу вимогам існує певна ймовірність випадкового збою; поширені відповіді, як-от
> `voices_sound_different` (перевірку голосового відбитка не пройдено) тощо. **Такі збої не пов’язані з якістю аудіо; повторна спроба з тим самим матеріалом зазвичай буде успішною**,
> рекомендовано реалізувати 1~2 автоматичні повторні спроби для невдалих результатів під час інтеграції. Невдалі запити не тарифікуються.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Наведений вище `https://cdn.acedata.cloud/suno_demo.mp3` є прикладом матеріалу, який можна викликати безпосередньо (MP3, 41 секунда, сухий голос однієї людини).
> Якщо потрібен приклад у форматі `WAV`, можна використати
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 секунда, моно 44.1kHz).

Результат такий:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Як видно, поле `persona_id` у `data` — це саме ID створеного голосового персонажа. Поле `is_public` завжди має значення `false`, оскільки голосові персонажі, створені шляхом завантаження аудіо, є приватними. Зверніть увагу, що повернене значення `name` автоматично генерується системою; надалі використовуйте `persona_id` для посилання на цей голосовий персонаж.

## Другий крок: використання голосового персонажа для генерації музики

Після отримання ID голосового персонажа ми можемо використовувати [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для генерації музики. Встановіть `action` як `generate` і встановіть `persona_id` як ID голосового персонажа, повернений вище, — згенерована пісня буде виконана клонованим голосом.

> **Увага:** клонування голосу підтримує лише моделі `chirp-v4-5` і вище (наприклад, `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), але не підтримує `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Результат такий:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` можна використовувати для генерації через `generate`, а також для каверів через `cover` / `upload_cover`. Під час указання голосу не потрібно одночасно заповнювати `vocal_gender`; схожість голосу все одно залежить від еталонного матеріалу та результату генерації.

Голос, створений через цей інтерфейс, є приватним ресурсом. Перед створенням каверу на наявну пісню спочатку викличте `/suno/upload`, передавши `audio_url` оригінальної пісні та `persona_id` цього голосу; після успішного завантаження викличте `/suno/audios` із поверненим `data.audio_id` і тим самим `persona_id`:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

Створення голосу, завантаження оригінальної пісні та створення каверу мають використовувати той самий канал сервісу. Не використовуйте напряму повторно ID пісень, які раніше не були пов’язані з цим приватним голосом; докладніше див. у [Suno завантаження еталонного аудіо](https://platform.acedata.cloud/documents/suno-upload).
