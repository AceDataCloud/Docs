---
title: "Suno API для клонування голосу: інструкція з інтеграції"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

SUNO дозволяє нам створювати користувацькі голосові ролі за допомогою будь-якого аудіофайлу, реалізуючи клонування голосу для генерації музики. На відміну від існуючого API Persona (який використовує `audio_id`, згенерований Suno), цей API приймає публічно доступний `audio_url`, тобто ваше власне голосове записування. У цьому документі пояснюється, як інтегрувати API клонування голосу.

Цей API має три вхідні параметри: `audio_url` (обов'язковий), який є публічно доступним URL-адресою аудіофайлу формату MP3 або WAV, що містить чіткий голос однієї особи; `name` та `description` (необов'язкові), які є назвою та описом голосової ролі.

**Вимоги до аудіофайлів:**

- Формат: MP3 або WAV
- Тривалість: не менше 10 секунд
- Зміст: чіткий голос однієї особи, намагайтеся зменшити фоновий шум або музику

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://example.com/my-vocal-recording.mp3",
  "name": "My Voice",
  "description": "A warm male voice"
}'
```

Результат виглядає так:

```json
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dde0be60-5280-4bd2-89a0-4020ddd3db52",
    "name": "My Voice",
    "is_public": false
  }
}
```

Як видно, поле `persona_id` в `data` є ID створеної голосової ролі. Поле `is_public` завжди дорівнює `false`, оскільки голосові ролі, створені шляхом завантаження аудіо, є приватними.

Отримавши ID голосової ролі, ми можемо використовувати [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) для генерації музики. Встановіть `action` на `vox` і `persona_id` на значення, яке повернулося вище, згенерована пісня буде виконана з використанням клонованого голосу.
