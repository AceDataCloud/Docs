Якщо ви хочете налаштувати генерацію пісень, але не хочете самостійно писати тексти, ви можете використовувати API для генерації текстів, наданий AceDataCloud, щоб створити тексти через prompt. API - це [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Основним вхідним параметром цього API є `prompt`, необов'язковий `model` (можливі значення `default`, `remi-v1`, за замовчуванням `default`), приклад заповнення наведено нижче:

![](https://cdn.acedata.cloud/p53wtj.png)

Тут ми вводимо `prompt` як `A song about winter`, щоб згенерувати пісню, пов'язану із зимою.

Натискаємо "Запустити", результат виглядає так:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nСніжинки падають з неба\nХолодний дотик зими\nО, як це мене підносить\nЯ загортаюся в шари\nО, так затишно\nВиходжу і відчуваю мороз на носі\n\n[Chorus]\nО\nХолодний дотик зими\nЦе пора, яку я так люблю\nСнігопад приносить відчуття таке божественне\nХолодний дотик зими\nЦе магічний час",
      "title": "Холодний дотик зими",
      "status": "complete",
      "tags": ["мрійливий, м'який, баллада"]
    },
    {
      "text": "[Verse]\nСвіт покритий білим покривалом\nСнігові бурульки звисають\nСяють так яскраво\nХолодне повітря заповнює мої легені з кожним вдихом\nІду снігом\nЗалишаю сліди позаду\n\n[Chorus]\nЗимова казка\nВсе так яскраво\nЗимова казка\nОбійми мене через ніч",
      "title": "Зимова казка",

```

Можна побачити, що `data` є масивом, який кожного разу повертає кілька кандидатів на тексти, де кожен елемент поля `text` є змістом тексту, `title` - це заголовок, а `tags` - рекомендовані жанрові мітки.

Отримавши тексти, ми можемо використовувати [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для генерації налаштованих пісень.
