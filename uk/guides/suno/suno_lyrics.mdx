Якщо ви хочете налаштувати генерацію пісень, але не дуже хочете самостійно писати тексти, ви можете використовувати API генерації текстів, наданий AceDataCloud, щоб генерувати тексти через prompt. API - це [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Основний вхідний параметр цього API - це `prompt`, необов'язковий `model` (за замовчуванням chirp-v3), приклад заповнення наведено нижче:

![](https://cdn.acedata.cloud/p53wtj.png)

Тут ми вводимо `prompt` як `A song about winter`, щоб згенерувати пісню, пов'язану із зимою.

Натискаємо "Запустити", результат виглядає так:

```
{
  "success": true,
  "task_id": "57e8ce3a-39cb-41a2-802f-e70a324f4d0a",
  "data": {
    "text": "[Verse]\nСніжинки падають з неба\nХолодний дотик зими\nО, як це мене підносить\nЯ загортаюся в шари\nО, так затишно\nВиходжу і відчуваю мороз на носі\nДивись\n\n[Verse 2]\nСвіт покритий білою ковдрою\nСосульки звисають\nСяють так яскраво\nХолодне повітря заповнює мої легені з кожним вдихом\nІду снігом\nЗалишаю сліди, які не зникнуть\n\n[Chorus]\nО\nХолодний дотик зими\nЦе сезон, який я так люблю\nСнігопад приносить відчуття таке божественне\nХолодний дотик зими\nЦе магічний час",
    "title": "Холодний дотик зими",
    "status": "complete"
  }
}
```

Можна побачити, що поле `text` в `data` містить інформацію про текст пісні.

Отримавши текст пісні, ми можемо використовувати [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для генерації кастомізованих пісень.
