title: "Інструкція з інтеграції API генерації текстів Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Якщо ви хочете налаштовувати генерацію пісень, але не дуже хочете самостійно писати тексти, ви можете використовувати API генерації текстів, наданий AceDataCloud, щоб генерувати тексти через prompt, API — [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Тарифікація: після успішної генерації стандартна вартість кожного запиту становить **0.08 Credits**. Коли один запит повертає кілька варіантів тексту, він усе одно тарифікується лише як один запит; застосовні знижки на споживання визначаються фактичним рахунком, невдалі запити не тарифікуються.

Основний вхідний параметр цього API — `prompt`, необов’язковий `model` (необов’язкові значення `default`, `remi-v1`, за замовчуванням `default`), приклад заповнення наведено нижче:

![](https://cdn.acedata.cloud/p53wtj.png)

Тут введений нами `prompt` — `A song about winter`, для генерації пісні, пов’язаної із зимою.

Натисніть запуск, результат такий:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nSnowflakes falling from the sky\nWinter's cold touch\nOh how it gets me high\nI bundle up in layers\nOh so cozy\nStepping out and feeling the frost on my nose\n\n[Chorus]\nOh\nWinter's cold touch\nIt's a season that I love so much\nSnowfall brings a feeling so divine\nWinter's cold touch\nIt's a magical time",
      "title": "Winter's Cold Touch",
      "status": "complete",
      "tags": ["dreamy, mellow, ballad"]
    },
    {
      "text": "[Verse]\nThe world is covered in a blanket of white\nIcicles hanging\nShimmering so bright\nThe chilly air fills my lungs with every breath\nWalking in the snow\nLeaving footprints behind\n\n[Chorus]\nWinter wonderland\nEverything is so bright\nWinter wonderland\nHold me through the night",
      "title": "Winter Wonderland",
      "status": "complete",
      "tags": ["dream pop, mellow, shoegaze"]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,
  "elapsed": 7.433
}
```

Можна побачити, що `data` — це масив, який щоразу повертає кілька варіантів текстів, де поле `text` кожного елемента є вмістом тексту пісні, `title` — заголовок, а `tags` — рекомендовані теги музичного стилю.

Після отримання тексту ми можемо використовувати [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для налаштованої генерації пісень.
