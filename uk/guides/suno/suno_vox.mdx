SUNO дозволяє нам створити нову версію Persona-v2-vox: стиль співака, яка відрізняється від старої версії, для цього потрібно спочатку отримати `vox_audio_id`. У цьому документі пояснюється метод інтеграції для створення нової версії Persona-v2-vox.

Спочатку потрібно отримати значення параметра `vox_audio_id` за допомогою цього API, який може приймати кілька вхідних параметрів, таких як `audio_id`, `vocal_start`, `vocal_end`, що є посиланням на ID пісні та вибраний часовий діапазон.

Тут ми вводимо `audio_id`, яке є `42599b24-fb14-4cd3-a444-e15ffde3661b`.

```python
import requests

url = "https://api.acedata.cloud/suno/vox"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Можна побачити, що поле `id` в `data` є тим, що нам потрібно, `vox_audio_id`, після чого ми переходимо до [Persona API](https://platform.acedata.cloud/documents/suno-persona) для створення нової версії Persona-v2-vox: стиль співака, конкретні введення наведені нижче:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "test",
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20,
    "vox_audio_id": "24f0827e-5847-4011-b9b7-fc0b62032b65"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Після виклику отримуємо наступний результат:

```json

  "data": {
    "persona_id": "49bef16d-6a09-49d1-8c24-a81663698b98"
  }
}
```

Потім ми можемо використовувати значення `persona_id` для створення нової версії Persona-v2-vox: стиль співака, конкретний метод створення та [інструкція з інтеграції API для генерації пісень Suno](https://platform.acedata.cloud/documents/suno-audios-integration#%E8%87%AA%E5%AE%9A%E4%B9%89%E6%AD%8C%E6%89%8B%E9%A3%8E%E6%A0%BC%E7%94%9F%E6%88%90%E5%8A%9F%E8%83%BD) є однаковими, в кінці ми можемо використовувати Suno Vox API для створення нової версії Persona-v2-vox: стиль співака для написання пісень.
