SUNO дозволяє нам здійснювати вторинну творчість на основі згенерованої музики, отримувати тексти пісень та аудіо часові лінії. У цьому документі описано методи інтеграції відповідних API.

Цей API має лише один вхідний параметр — `audio_id`, який є офіційним ідентифікатором згенерованої пісні.

Тут ми вводимо `audio_id` зі значенням `ec13e502-d043-4eb2-92ee-e900c6da69d1`.

```python
import requests

url = "https://api.acedata.cloud/suno/timing"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "ec13e502-d043-4eb2-92ee-e900c6da69d1"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Опис поля aligned_words

Як видно, `data.aligned_words` — це масив об’єктів, кожен з яких представляє слово або фразу з часовою інформацією.

- `word`: фактичне слово або фраза в тексті пісні
- `success`: булеве значення, що вказує, чи було успішним вирівнювання цього слова
- `start_s`: час початку слова (в секундах)
- `end_s`: час закінчення слова (в секундах)
- `p_align`: ймовірність або коефіцієнт довіри вирівнювання, в діапазоні від 0 до 1
