З поширенням застосувань ШІ різноманітні програми на основі ШІ поступово стають звичними. ШІ все більше проникає в усі сфери життя людей. А галузей, пов'язаних із ШІ, стає все більше: від початкового написання текстів до медицини та освіти, а тепер і до музики.

Suno — це професійна платформа для створення високоякісних пісень і музики на основі ШІ, де користувачам потрібно лише ввести простий текстовий запит, щоб згенерувати пісню з вокалом відповідно до жанру та стилю. Цей генератор музики на основі ШІ розроблений командою з відомих технологічних компаній, таких як Meta, TikTok, Kensho, з метою створення чудової музики без необхідності у музичних інструментах.

Ось прогрес оновлення моделі:

| Версія | model           | Дата запуску  | обмеження на текст | обмеження на стиль | максимальна тривалість пісні |
| ------ | --------------- | ------------- | ------------------ | ------------------ | ----------------------------- |
| v5.5   | chirp-v5-5      | 2026.03.27    | 5000               | 1000               | 8 хвилин                      |
| v5     | chirp-v5        | 2025.09.23    | 5000               | 1000               | 8 хвилин                      |
| v4.5+  | chirp-v4-5-plus | 2025.07.17    | 5000               | 1000               | 8 хвилин                      |
| v4.5   | chirp-v4-5      | 2025.05.03    | 5000               | 1000               | 4 хвилини                     |
| v4     | chirp-v4        | 2024.12.17    | 3000               | 200                | 150 секунд                    |
| v3.5   | chirp-v3-5      | ---           | 3000               | 200                | 120 секунд                    |

> У наведеній таблиці обмеження `lyric` та `style` є верхньою межею для режиму налаштування (`custom` = `true`). У неналаштованому режимі натхнення (`custom` = `false`) заповнюється лише `prompt`, максимальна довжина якого становить 500 символів (для всіх моделей однаково).

Suno тепер підтримує останню модель `chirp-v5-5`. Щоб викликати останню версію, потрібно встановити параметр `model` на `chirp-v5-5`; `chirp-v5` та попередні версії все ще можна використовувати.

Однак офіційний Suno не надає API, AceDataCloud пропонує набір API для Suno, що імітує інтеграцію з офіційним Suno, що дозволяє швидко та зручно генерувати бажану музику.

## Заявка та використання

Щоб використовувати Suno Audios Generation API, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications), щоб отримати ваш API Token для резервного копіювання.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, щоб запросити реєстрацію та вхід, після чого ви будете автоматично повернені на поточну сторінку.

**Один API Token дозволяє викликати всі послуги платформи, без необхідності окремої заявки для кожної послуги.** Перший запит на отримання токена надає безкоштовний ліміт для тестування; при недостатньому ліміті ви можете поповнити загальний баланс у [консолі](https://platform.acedata.cloud/console/coin).

## Основне використання

Щоб створити пісню, ви можете ввести будь-який текст, наприклад, якщо я хочу згенерувати пісню про Різдво, я можу ввести `a song for Christmas`, як показано на малюнку:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

Ми бачимо, що тут ми налаштували заголовки запиту, включаючи:

- `accept`: формат відповіді, який ви хочете отримати, тут вказано `application/json`, тобто формат JSON.
- `authorization`: ключ для виклику API, який можна вибрати після подачі заявки.

Також налаштовано тіло запиту, включаючи:
- `action`：Ця музична генераційна задача має поведінку, за замовчуванням `generate`, основні включають: `extend`, `upload_extend`, `cover`, `upload_cover`, `replace_section`, `replace_section`, `concat`, `stems`, `all_stems`, `remaster`.
- `prompt`：Офіційний підказка для натхнення від Suno (діє, коли `custom` є `false`), максимум 500 символів.
- `model`：Модель для цієї музичної генераційної задачі, за замовчуванням `chirp-v4`, основні включають: `chirp-v3`, `chirp-v4`, `chirp-v3-5`, `chirp-v4-5`, `chirp-v4-5-plus`, `chirp-v5`, `chirp-v5-5`.
- `lyric`：Офіційний текст пісні в режимі налаштування від Suno. `chirp-v3-5` та `chirp-v4` максимум 3000 символів; `chirp-v4-5` та вище (включаючи `chirp-v5`, `chirp-v5-5`) максимум 5000 символів.
- `custom`：Чи використовувати режим налаштування, за замовчуванням: `false`.
- `instrumental`：Чисто музичний варіант натхнення від Suno.
- `title`：Офіційна назва музики в режимі налаштування від Suno. `chirp-v3-5`, `chirp-v4` максимум 80 символів; `chirp-v4-5` та вище максимум 100 символів.
- `style`：Стиль музики в режимі налаштування від Suno. `chirp-v3-5` та `chirp-v4` максимум 200 символів; `chirp-v4-5` та вище (включаючи `chirp-v5`, `chirp-v5-5`) максимум 1000 символів.
- `style_negative`：Стиль, який потрібно виключити в режимі налаштування від Suno.
- `audio_weight`：Вага завантаженого референсного аудіо, діапазон 0-1, чим більше, тим більше залежить від референсного аудіо.
- `audio_id`：ID референсної музики.
- `overpainting_start`/`overpainting_end`：Час початку та закінчення додавання вокалу до вже існуючої чистої музики, одиниця - секунди.
- `underpainting_start`/`underpainting_end`：Час початку та закінчення додавання акомпанементу до чистого виконання, одиниця - секунди.
- `persona_id`：ID пісні артиста.
- `continue_at`：Час у секундах для продовження існуючого аудіо. Наприклад, 213.5 означає продовжити до 3 хвилин 33.5 секунд.
- `style_influence`：Розширений параметр «Style Influence» в режимі налаштування, діапазон 0-1, чим більше, тим більше відповідає обраному стилю.
- `replace_section_end`：Кінцевий час заміни фрагмента.
- `replace_section_start`：Початковий час заміни фрагмента.
- `vocal_gender`：Контроль переваги чоловічого або жіночого голосу, жіночий `f`, чоловічий `m`, дійсно для моделей 4.5 та вище; це перевага, не гарантує суворого дотримання.
- `weirdness`：Розширений параметр «Weirdness» в режимі налаштування, діапазон 0-1, чим більше, тим більше креативності та експериментальності.
- `duration`：Очікувана тривалість пісні, одиниця - секунди, має бути цілим числом, діапазон 10 до 360. Цей параметр використовується для генерації пісень в режимі налаштування (`custom` є `true`). Це схильний підказка, а не жорстке обмеження: модель буде на нього орієнтуватися, але не гарантує досягнення, фактична тривалість продукту визначається полем `duration` у відповіді, зазвичай коротше за очікуване значення.
- `lyric_prompt`：Підказка для генерації тексту пісні, коли і тільки коли `custom` є `true` і `lyric` не передано.
- `callback_url`：URL для отримання результатів зворотного виклику.
- `async`：Необов'язковий, якщо встановити `true`, інтерфейс негайно повертає `task_id`, не потрібно надавати `callback_url`, потім через відповідний інтерфейс запиту завдань опитувати для отримання результатів.

## Налаштування генерації

Якщо ви хочете налаштувати генерацію тексту пісні, ви можете ввести текст:

Тоді поле `lyric` може приймати подібний зміст:

```
[Куплет]\nСніжинки падають навколо\nСяючий білий\nПокриваючи землю\nДіти сміються\nПовні задоволення\nУ цій зимовій казці сьогодні вночі\nСанки Санти\nВ небі\nНіс Рудольфа сяє яскраво\nО, мій\nЧути дзвоники\nЛунають так чітко\nПриносячи радість і святковий настрій\n[Куплет 2]\nСмаження каштанів біля вогню\nРіздвяні вогні\nВони мерехтять і показують\nСім'ї збираються з любов'ю та радістю\nПоширюючи тепло всім близьким
```

> Зверніть увагу, що в тексті пісні `\n` є символом нового рядка, якщо ви не знаєте, як згенерувати текст пісні, ви можете скористатися API генерації тексту пісень, наданим AceDataCloud, щоб згенерувати текст через prompt, API - це [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Далі ми можемо налаштувати генерацію пісні на основі тексту, заголовка, стилю, вказавши наступні параметри:

- lyric: текст пісні
- custom: заповнити `true`, що означає налаштовану генерацію, цей параметр за замовчуванням є false, що означає використання генерації через `prompt`.
- title: заголовок пісні.
- style: стиль пісні, необов'язковий.

## Функція налаштування стилю співака для генерації
Якщо ви хочете використовувати стиль співака для генерації пісень, спочатку за допомогою основного використання згенеруйте пісню, а потім потрібно налаштувати цю пісню на стиль співака. Для цього потрібно перейти до [Suno Persona API](https://platform.acedata.cloud/documents/suno-persona) і за допомогою згенерованого музичного ID `audio_id` створити параметр id співака `persona_id`, конкретні параметри наведені на малюнку нижче:

<p><img src="https://cdn.acedata.cloud/pmzo3l.png" width="500" className="m-auto" /></p>

Після заповнення автоматично згенерувався код, як показано нижче:

<p><img src="https://cdn.acedata.cloud/a5g0nj.png" width="500" className="m-auto" /></p>

Відповідний код на Python:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "name": "test"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Коли натискаєте "Запустити", ви отримаєте результат, як показано нижче:

```json

  "task_id": "7628b754-4fe7-4e79-bda4-806d0dd8bf6e",
  "data": {
    "persona_id": "e0d7319e-aa2a-44cb-b00a-916218d7cb0b"
  }

## Функція продовження генерації

Якщо ви хочете продовжити генерацію вже створеної пісні Suno, ви можете налаштувати параметр `action` на `extend` і ввести ID пісні, яку потрібно продовжити. ID пісні можна отримати за допомогою основного використання, як зазначено вище, в даному випадку ID пісні буде:

```

```

## Заміна фрагмента

Коли після генерації пісні потрібно провести окрему операцію заміни фрагмента пісні, можна замінити певний фрагмент пісні.

> ⚠️ **Увага**: `replace_section` при окремому використанні **поверне лише новий згенерований "замінений фрагмент"** (тобто новий аудіо фрагмент, що замінює ту частину, тривалість приблизно дорівнює `replace_section_end - replace_section_start`, з невеликою кількістю контексту), **і не поверне зібрану повну пісню**. Щоб отримати повний продукт, зібраний з оригінальної пісні, потрібно після успішного `replace_section` знову надіслати запит на [музичне збирання](#музичне-збирання). Повний процес дивіться нижче.

Опис параметрів:

- action: значення `replace_section`.
- audio_id: ID оригінальної пісні (джерела, що замінюється).
- model: модель генерації пісень.
- lyric: повний текст пісні після заміни (включаючи замінений фрагмент та його контекст, що відповідає змісту в `prompt`).
- prompt: новий текст, що потрібно замінити.
- style: стиль пісні, необов'язковий.
- replace_section_start: початковий час заміненого фрагмента в оригінальній пісні (секунди).
- replace_section_end: кінцевий час заміненого фрагмента в оригінальній пісні (секунди).

## Контроль тривалості пісні

За замовчуванням тривалість згенерованої пісні визначається моделлю, зазвичай від 30 секунд до 4 хвилин. Якщо потрібно отримати довший або коротший продукт, можна вказати бажану тривалість через параметр `duration`, одиниця виміру - секунди, значення - ціле число від 10 до 360.

Цей параметр використовується для генерації пісень у кастомному режимі (`custom` дорівнює `true`). Слід особливо зазначити, що `duration` є **схильним підказкою, а не жорсткою вимогою**: модель під час створення буде орієнтуватися на це значення, але не гарантує його досягнення, в реальних умовах фактична тривалість зазвичай помітно коротша за очікувану, а дві пісні, отримані в одному запиті, можуть мати різницю в тривалості в кілька разів. Тому не слід використовувати це як точний контроль тривалості, якщо в бізнесі потрібна фіксована тривалість, будь ласка, обріжте або повторіть запит після отримання продукту.

Відповідний код на Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "Під світлом міста",
    "style": "лоу-фай піано",
    "lyric": "[Куплет]\nСонце підкрадається\nЗолото на підлозі\n[Приспів]\nПід світлом міста\n",
    "duration": 330
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Слід зазначити, що `duration` у запиті є **бажаною тривалістю**, а поле `duration` у відповіді `data` для кожної пісні є **фактичною тривалістю** цієї пісні. Обидва назви однакові, але значення різні, фактична тривалість не гарантує відповідність бажаній. Довжина тексту є одним з основних факторів, що впливають на тривалість продукту, якщо потрібно отримати довший продукт, рекомендується одночасно надати більш повний текст.

Інтерфейс не проводить додаткову перевірку `duration`, параметри передаються моделі без змін. Якщо передано значення, яке не підтримується поточним режимом або моделлю, це може проявитися в тому, що це значення буде проігноровано, рекомендується спочатку підтвердити ефект за допомогою одного запиту, а потім використовувати його в масовому порядку.

## Функція натхнення Inspo

Нова функція натхнення Inspo від Suno може генерувати абсолютно нову музику на основі 1 до 4 сегментів референсних аудіо. На відміну від каверів, Inspo не відтворює оригінальну пісню, а витягує стильове натхнення з референсних аудіо, поєднуючи його з підказками, стильовими тегами тощо для створення нових творів. Під час використання потрібно заповнити такі параметри:

- action: вміст - `inspo`.
- audio_urls: список URL-адрес референсних аудіо, потрібно надати 1 до 4 відкритих доступних аудіоадрес.
- model: використовувана модель, наприклад, `chirp-v5`.
- prompt: текст пісень або творчі підказки (необов'язково).
- tags: музичні стильові теги, наприклад, `акустичний, фолк, теплий` (необов'язково).
- title: заголовок пісні (необов'язково).
- audio_weight: вага впливу референсного аудіо на результати генерації, діапазон значень від 0 до 1 (необов'язково).

> Примітка: референсне аудіо повинно бути відкритим доступом. Якщо референсне аудіо повністю збігається з відомими записами в бібліотеці платформи, Suno може відмовити в генерації через перевірку авторських прав, рекомендується використовувати власні або згенеровані Suno аудіо як джерело натхнення.

Відповідний код на Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "inspo",
    "model": "chirp-v5",
    "audio_urls": [
        "https://cdn1.suno.ai/935dd2f5-ddef-43cf-8e68-5a262425694d.mp3"
    ],
    "prompt": "теплий акустичний фолк з м'якими вокалами",
    "tags": "акустичний, фолк, теплий",
    "title": "Демо натхнення",
    "audio_weight": 0.6
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)

## Асинхронний зворотний виклик

Оскільки час генерації музики Suno відносно довгий, приблизно 1-2 хвилини, якщо API довго не відповідає, HTTP запит буде постійно підтримувати з'єднання, що призводить до додаткових витрат системних ресурсів, тому цей API також підтримує асинхронні зворотні виклики.

Загальний процес: коли клієнт ініціює запит, додатково вказується поле `callback_url`, після ініціації API запиту, API відразу повертає результат, що містить інформацію про поле `task_id`, яке представляє ID поточного завдання. Коли завдання завершено, результат генерації музики буде надіслано на вказаний клієнтом `callback_url` у форматі POST JSON, в якому також міститься поле `task_id`, таким чином результати завдання можна пов'язати за ID.

Далі ми розглянемо приклад, щоб зрозуміти, як саме це працює.

По-перше, зворотний виклик Webhook — це сервіс, який може приймати HTTP запити, розробники повинні замінити його на URL свого HTTP сервера. Для зручності демонстрації використовується публічний сайт зразка Webhook https://webhook.site/, відкривши цей сайт, ви отримаєте URL Webhook, як показано на малюнку:

![](https://cdn.acedata.cloud/fwfqin.png)

Далі ми можемо налаштувати поле `callback_url` на вказаний вище URL Webhook, одночасно заповнивши `prompt`, як показано на малюнку:
