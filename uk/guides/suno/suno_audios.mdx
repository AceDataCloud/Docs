З поширенням застосувань ШІ різноманітні програми на основі ШІ поступово стають звичними. ШІ все більше проникає в усі сфери життя людей. А галузей, пов'язаних із ШІ, стає все більше — від початкового написання текстів до медицини та освіти, а тепер і до музики.

Suno — це професійна платформа для створення високоякісних пісень і музики на основі ШІ, де користувачі можуть просто ввести прості текстові підказки, щоб згенерувати пісні з вокалом відповідно до жанру та стилю. Цей генератор музики на основі ШІ розроблений командою з відомих технологічних компаній, таких як Meta, TikTok, Kensho, з метою дозволити всім створювати чудову музику без використання будь-яких музичних інструментів.

Ось прогрес оновлення моделі:

| Версія  | model           | Дата запуску  | обмеження prompt | обмеження стилю | максимальна тривалість пісні |
| ------- | --------------- | -------------- | ---------------- | ---------------- | ----------------------------- |
| v5      | chirp-v5        | 2025.09.23     | 5000             | 1000             | 8 хвилин                      |
| v4.5+   | chirp-v4-5-plus | 2025.07.17     | 5000             | 1000             | 8 хвилин                      |
| v4.5    | chirp-v4-5      | 2025.05.03     | 5000             | 1000             | 4 хвилини                     |
| v4      | chirp-v4        | 2024.12.17     | 3000             | 200              | 150 секунд                    |
| v3.5    | chirp-v3-5      | ---            | 3000             | 200              | 120 секунд                    |

Suno нещодавно оновила модель генерації музики до версії V5, для виклику останньої V5 потрібно просто змінити параметр model на `chirp-v5`, що дозволяє генерувати пісні тривалістю до 9 хвилин.

Однак Suno офіційно не надає API, AceDataCloud пропонує набір API Suno, що імітує інтеграцію з офіційним Suno, що дозволяє швидко і зручно генерувати бажану музику.

## Заявка та використання

Щоб використовувати Suno Audios API, спочатку перейдіть на сторінку [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) і натисніть кнопку «Acquire», щоб отримати необхідні для запиту облікові дані:

![](https://cdn.acedata.cloud/nyq0xz.png)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, щоб запросити реєстрацію та вхід. Після входу або реєстрації ви будете автоматично повернені на поточну сторінку.

При першій заявці вам буде надано безкоштовний ліміт, який дозволяє безкоштовно використовувати цей API.

## Основне використання

Щоб створити пісню, ви можете ввести будь-який текст, наприклад, якщо я хочу згенерувати пісню про Різдво, я можу ввести `a song for Christmas`, як показано на малюнку:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" class="m-auto"></p>

Ми бачимо, що тут ми налаштували заголовки запиту, включаючи:

- `accept`: формат відповіді, який ви хочете отримати, тут вказано `application/json`, тобто формат JSON.
- `authorization`: ключ для виклику API, після заявки ви можете вибрати його зі списку.

Також налаштовано тіло запиту, яке включає:

- `action`: дія для цього завдання генерації музики, за замовчуванням `generate`, основні дії: `extend`, `upload_extend`, `cover`, `upload_cover`, `replace_section`, `concat`, `stems`, `all_stems`, `remaster`.
- `prompt`: підказка для натхнення від Suno.
- `model`: модель для цього завдання генерації музики, за замовчуванням `chirp-v3-5`, основні моделі: `chirp-v3`, `chirp-v4`, `chirp-v3-5`, `chirp-v4-5`, `chirp-v4-5-plus`, `chirp-v5`.
- `lyric`: текст пісні в режимі налаштування від Suno.
- `custom`: чи використовувати режим налаштування, за замовчуванням: `false`.
- `instrumental`: опція чистої музики в режимі натхнення від Suno.
- `title`: заголовок музики в режимі налаштування від Suno.
- `style`: стиль музики в режимі налаштування від Suno.
- `style_negative`: виключений стиль в режимі налаштування від Suno.
- `audio_weight`: вага завантаженого референсного аудіо, діапазон 0-1, чим більше, тим більше залежить від референсного аудіо.
- `audio_id`: ID референсної музики.
- `overpainting_start`/`overpainting_end`: час початку та закінчення додавання вокалу до вже існуючої чистої музики, в секундах.
- `underpainting_start`/`underpainting_end`: час початку та закінчення додавання акомпанементу до чистого виконання, в секундах.
- `persona_id`: ID пісні артиста.
- `continue_at`: час у секундах для продовження існуючого аудіо. Наприклад, 213.5 означає продовжити до 3 хвилин 33.5 секунд.
- `style_influence`: розширений параметр `style_influence`.
- `replace_section_end`: кінцевий час заміни фрагмента.
- `replace_section_start`: початковий час заміни фрагмента.
- `vocal_gender`: контроль за жіночим або чоловічим вокалом, жіночий `f`, чоловічий `m`, дійсно для моделей 4.5 і вище.
- `weirdness`: розширений параметр `weirdness`.
- `lyric_prompt`: підказка для генерації тексту, яка діє лише тоді, коли `custom` дорівнює `true` і `lyric` не передано.
- `callback_url`: URL для отримання результатів.

  - style: стиль

## Налаштування генерації

Якщо ви хочете налаштувати генерацію тексту пісні, ви можете ввести текст:

Тоді поле `lyric` може приймати подібний зміст:

```
[Куплет]\nСніжинки падають навколо\nСяючий білий\nПокриваючи землю\nДіти сміються\nПовні задоволення\nУ цій зимовій казці сьогодні вночі\nСанки Санти\nВ небі\nНіс Рудольфа сяє яскраво\nО, мій\nЧути дзвоники\nЛунають так чітко\nПриносячи радість і святковий настрій\n[Куплет 2]\nСмажені каштани біля вогню\nРіздвяні вогні\nВони мерехтять і показують\nСім'ї збираються з любов'ю та радістю\nПоширюючи тепло всім близьким
```

> Зверніть увагу, що в тексті пісні `\n` є символом нового рядка, якщо ви не знаєте, як згенерувати текст пісні, ви можете скористатися API генерації тексту пісень, наданим AceDataCloud, щоб згенерувати текст через prompt, API - це [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/514d82dc-f7ab-4638-9f21-8b9275916b08).

Далі ми можемо налаштувати генерацію пісні на основі тексту, заголовка, стилю, вказавши наступні параметри:

- lyric: текст пісні
- custom: заповнити `true`, що означає налаштовану генерацію, цей параметр за замовчуванням є false, що означає використання `prompt` для генерації.
- title: заголовок пісні.
- style: стиль пісні, необов'язковий.

## Функція налаштування стилю співака для генерації
Якщо ви хочете використовувати стиль співака для генерації пісні, спочатку за допомогою основного використання згенеруйте пісню, а потім потрібно налаштувати цю пісню на стиль співака. Для цього потрібно перейти до [Suno Persona API](https://platform.acedata.cloud/documents/78bb6c62-6ce0-490f-a7df-e89d80ec0583) і на основі офіційно згенерованого музичного ID `audio_id` створити параметр id стилю співака `persona_id`, конкретні параметри наведені на малюнку нижче:

<p><img src="https://cdn.acedata.cloud/pmzo3l.png" width="500" class="m-auto"></p>

Після заповнення автоматично згенерувався код, як показано нижче:

<p><img src="https://cdn.acedata.cloud/a5g0nj.png" width="500" class="m-auto"></p>

Відповідний код на Python:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "name": "test"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Клікнувши "Запустити", ви можете побачити результат, як показано нижче:

```json

  "data": {
    "persona_id": "e0d7319e-aa2a-44cb-b00a-916218d7cb0b"
  }
}
```

Ми взяли `audio_id` та `persona_id` відповідно як `97efc9f4-0e8d-4b3e-88df-14568fa1b11f` та `e0d7319e-aa2a-44cb-b00a-916218d7cb0b` для цього прикладу. Потім можна встановити параметр `action` на `artist_consistency` (якщо це новий стиль співака Persona-v2-vox, `action` повинен бути встановлений на `artist_consistency_vox`), і ввести ID пісні, яку потрібно продовжити генерувати, та ID стилю співака, заповнивши приклад, як показано нижче:

<p><img src="https://cdn.acedata.cloud/fukijq.png" width="500" class="m-auto"></p>

Після заповнення автоматично згенерувався код, як показано нижче:

<p><img src="https://cdn.acedata.cloud/5uzk9d.png" width="500" class="m-auto"></p>

Відповідний код на Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "artist_consistency",
    "prompt": "A song for Christmas",
    "model": "chirp-v4-5",
    "persona_id": "e0d7319e-aa2a-44cb-b00a-916218d7cb0b",
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Функція продовження генерації

Якщо ви хочете продовжити генерацію вже згенерованої пісні Suno, ви можете встановити параметр `action` на `extend` і ввести ID пісні, яку потрібно продовжити генерувати. ID пісні можна отримати за допомогою основного використання, як було зазначено вище, і в цьому випадку ви можете побачити ID пісні як:

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> Зверніть увагу, що тут `id` у тексті пісні є ID згенерованої пісні. Якщо ви не знаєте, як згенерувати пісню, ви можете звернутися до основного використання, щоб згенерувати пісню.

Якщо ви хочете продовжити генерацію власної завантаженої пісні, ви можете встановити параметр `action` на `upload_extend` і ввести ID пісні, яку потрібно продовжити генерувати. ID пісні можна отримати за допомогою [Suno Upload Generation API](https://platform.acedata.cloud/documents/766db278-012c-43c4-9245-5f18d8dc4d82), як показано на малюнку нижче:

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" class="m-auto"></p>

Далі ми повинні заповнити текст пісні, стиль для створення пісні, і можемо вказати такі параметри:

- lyric: текст пісні
- custom: заповнити `true`, що означає, що це кастомна генерація, цей параметр за замовчуванням є false, що означає використання `prompt` для генерації.
- style: стиль пісні, необов'язковий.
- continue_at: час продовження існуючого аудіо в секундах. Наприклад, 213.5 означає продовжити до 3 хвилин 33.5 секунд.

Приклад заповнення наведено нижче:

<p><img src="https://cdn.acedata.cloud/zp9s42.png" width="500" class="m-auto"></p>

Після заповнення автоматично згенерувався код, як показано нижче:

<p><img src="https://cdn.acedata.cloud/wwpw78.png" width="500" class="m-auto"></p>

Відповідний код на Python:
```python

url = "https://api.acedata.cloud/suno/audios"

    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "prompt": "Пісня на Різдво",
    "model": "chirp-v4-5",
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "continue_at": 2,
    "lyric": "[Куплет]\\nСніжинки падають навколо\\nБлискучі білі\\nПокривають землю\\nДіти сміються\\nПовні радості\\nУ цій зимовій казці сьогодні ввечері\\nСанти сани\\nВ небі\\nНіс Рудольфа світиться яскраво\\nО, Боже\\nЧути дзвоники\\nЛунають так чітко\\nПриносять радість і святковий настрій\\n[Куплет 2]\\nСмажені каштани біля вогню\\nРіздвяні вогні\\nВони мерехтять і світять\\nСім'ї збираються з любов'ю та радістю\\nПоширюючи тепло всім близьким",
    "custom": True,

print(response.text)
```

- action: значення `concat`.

- action: вміст `cover`, коли це кавер на користувацьки завантажену музику, потрібно вказати вміст: `upload_cover`.
- audio_id: ID раніше згенерованої пісні.

Наприклад, якщо ID раніше згенерованої пісні: 0a1e1b10-c36a-41c9-9bfb-b26d9d25db98, то параметри можуть бути такими:

## Заміна фрагмента

Коли після генерації пісні потрібно провести окрему операцію заміни фрагмента пісні, можна замінити певний фрагмент пісні. Для цього потрібно вказати такі параметри:

- action: вміст `replace_section`.
- audio_id: ID раніше згенерованої пісні.
- model: модель генерації пісень,
- lyric: повний текст заміни (достатньо, щоб повторювався з prompt, не потрібно повного тексту),
- prompt: частина тексту, яку потрібно замінити.
- style: стиль пісні, необов'язковий.
- replace_section_start: початковий час на часовій осі тексту, відповідного `lyric`.
- replace_section_end: кінцевий час на часовій осі тексту, відповідного `lyric`.

## Налаштування розширених параметрів

<p><img src="https://cdn.acedata.cloud/1xonxy.png" width="500" class="m-auto"></p>

Діапазон розширених параметрів знаходиться в межах 0-1, конкретні параметри наведені на малюнку нижче:

<p><img src="https://cdn.acedata.cloud/7i94ih.png" width="500" class="m-auto"></p>

Після заповнення автоматично згенерувався код, як показано нижче:

<p><img src="https://cdn.acedata.cloud/2dlbo6.png" width="500" class="m-auto"></p>

Відповідний Python код:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v4-5",
    "lyric": "Привіт Привіт Привіт ",
    "custom": True,
    "weirdness": 0.4,
    "style_influence": 0.4,
    "audio_weight": 0.4
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Асинхронний зворотний виклик

Оскільки час генерації музики Suno відносно тривалий, приблизно 1-2 хвилини, якщо API довго не відповідає, HTTP запит буде постійно підтримувати з'єднання, що призводить до додаткових витрат системних ресурсів, тому цей API також підтримує асинхронні зворотні виклики.

Загальний процес: коли клієнт ініціює запит, додатково вказується поле `callback_url`, після ініціації API запиту, API відразу повертає результат, що містить інформацію про поле `task_id`, яке представляє поточний ID завдання. Коли завдання завершено, результат генерації музики буде надіслано на вказаний клієнтом `callback_url` у форматі POST JSON, в якому також міститься поле `task_id`, таким чином результати завдання можна пов'язати за ID.
