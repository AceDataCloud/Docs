Suno MP3 URL API генерує шлях до відтворювальної адреси, що закінчується на `.mp3`, для вже існуючої музики, що підходить для випадків, коли старі посилання для завантаження не працюють, для відтворення на мобільних пристроях або коли потрібно повторно отримати публічне аудіо URL.

Обов'язковий параметр `audio_id` - це ID аудіо, що повертається інтерфейсом генерації аудіо Suno. Кожен виклик створює незалежне завдання MP3 URL, не змінюючи оригінальне завдання генерації музики і не змінюючи оригінальний ID аудіо.

## Синхронний виклик

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={
        "accept": "application/json",
        "authorization": "Bearer <YOUR_API_TOKEN>",
        "content-type": "application/json"
    },
    json={"audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f"},
    timeout=240
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["file_url"])
```

У разі успіху, `data[0].file_url` є адресою для відтворення аудіо. Інтерфейс спочатку намагатиметься зберегти за адресою `https://platform2.cdn.acedata.cloud/suno/{audio_id}.mp3`; якщо збереження перевищить 30 секунд або зазнає невдачі, повернеться поточна доступна адреса вихідного аудіо.

## Асинхронний виклик

Якщо час обробки довгий, можна передати `async: true`:

```python
submission = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={"authorization": "Bearer <YOUR_API_TOKEN>"},
    json={
        "audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f",
        "async": True
    }
).json()

export_task_id = submission["task_id"]
```

Потім через `/suno/tasks` можна запитати `export_task_id`. Також можна надати `callback_url`, щоб отримати остаточний результат після завершення завдання. Синхронна відповідь, запит завдання та зворотний виклик використовують однакову структуру даних.

## Зверніть увагу

- `audio_id` повинен походити з впізнаваного аудіо Suno.
- Завдання MP3 URL незалежні від оригінального завдання генерації музики.
- Збереження може тривати максимум 30 секунд; тайм-аут або невдача збереження не блокуватим результат, а поверне до адреси вихідного аудіо.
- Рекомендується, щоб бізнес-сторона своєчасно завантажувала результати та зберігала їх відповідно до своєї стратегії збереження даних.
