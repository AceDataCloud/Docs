SUNO дозволяє нам завантажувати референсне аудіо для вторинної творчої роботи, цей документ пояснює відповідні методи інтеграції API.

Для звичайного завантаження потрібен лише `audio_url`, це загальнодоступна адреса аудіо CDN. `mode` за замовчуванням має значення `standard`, тому наявні виклики не потребують змін. Успішне звичайне завантаження споживає **0.06 Credits**; за невдале завантаження плата не стягується.

Тут введений нами `audio_url` — це `https://cdn.acedata.cloud/suno_demo.mp3`, загальнодоступна адреса CDN.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Можна побачити, що `data` завжди є об’єктом, а `audio_id` — це ID пісні після завантаження. Результати аналізу, як-от `lyric`, `style`, `duration`, назва та медіа-URL, є необов’язковими полями; конкретний склад залежить від вмісту відповіді.

Після отримання ID пісні можна через [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) викликати `upload_extend`, `upload_cover` або такі операції, як вибірка інтервалу, що потребують `audio_id`. Якщо потрібно створити нову музику за допомогою функції творчості на основі натхнення Inspo, використовуючи від 1 до 4 повних референсних аудіо, безпосередньо викликайте `action=inspo` і передавайте список вихідних загальнодоступних URL аудіо; сервіс автоматично виконає завантаження та аналіз, без потреби клієнту формувати метадані аудіо.

## Завантаження оригінальної пісні для каверу приватним голосом

Під час створення каверу приватним голосом, створеним за допомогою `/suno/voices`, передайте `persona_id` цього голосу в запиті звичайного завантаження, щоб пов’язати оригінальну пісню з голосом:

```json
{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "mode": "standard",
  "persona_id": "<声音创建接口返回的 persona_id>"
}
```

Після успішного завантаження використовуйте повернений `data.audio_id` для виклику `/suno/audios`, установіть `action: "upload_cover"` і передайте той самий `persona_id`. Не продовжуйте використовувати ID аудіо, який раніше не був пов’язаний із цим голосом.

`persona_id` підтримується лише для звичайного завантаження та не може використовуватися одночасно з `mode: "enhanced"`. Не потрібно додатково вказувати `vocal_gender`; переваги щодо статі не можуть замінити ID голосу. Створення голосу, завантаження оригінальної пісні та створення каверу мають використовувати той самий сервісний канал.

## Режим покращеного завантаження

> `audio_url` є вхідною адресою, її буде безпосередньо передано до процесу обробки аудіо, без попереднього перенесення сервісом постійного зберігання медіа фінального стану. Переконайтеся, що вона є загальнодоступною протягом обробки завдання.

Коли звичайне завантаження не може обробити аудіо, яким ви володієте або на використання якого отримали дозвіл, можна встановити для `mode` значення `enhanced`. Цей режим також має надати `name` від 1 до 100 символів і використовувати загальнодоступний HTTPS `audio_url`.

Покращене завантаження завжди використовує асинхронну обробку, яка зазвичай потребує 2 хвилин або більше. Успішна обробка споживає **1.87 Credits**; за невдалу обробку плата не стягується.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

Інтерфейс негайно поверне `task_id` і `trace_id`. Використовуйте [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) для перевірки завдання, а після успіху зчитайте ID завантаженого аудіо з `response.data.audio_id`. Також можна надати HTTPS `callback_url` для отримання фінального стану.
Покращений `audio_id`, отриманий під час завантаження, можна використовувати для Cover, Samples і Mashup. Витягнення акомпанементу та MIDI, розділення всіх доріжок, а також розділення вокалу/акомпанементу все ще можуть бути обмежені обліковим записом, якому належить аудіо; для не зазначених операцій не гарантується підтримка між обліковими записами. Що коротше аудіо, то зазвичай вищий рівень успішності обробки.
