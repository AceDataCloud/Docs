SUNO дозволяє нам завантажувати референсне аудіо для вторинної творчості, цей документ пояснює відповідні методи інтеграції API.

Для звичайного завантаження потрібен лише `audio_url`, це загальнодоступна адреса аудіо CDN. `mode` за замовчуванням має значення `standard`, тому наявні виклики не потрібно змінювати. Успішне звичайне завантаження споживає **0.06 Credits**; за невдале завантаження плата не стягується.

Тут введений нами `audio_url` — це `https://cdn.acedata.cloud/suno_demo.mp3`, загальнодоступна адреса CDN.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Як можна побачити, `data` завжди є об’єктом, а `audio_id` — це ID пісні після завантаження. Результати аналізу, такі як `lyric`, `style`, `duration`, назва та медіа-URL, є необов’язковими полями; конкретні дані залежать від вмісту відповіді.

Після отримання ID пісні можна через [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) викликати `upload_extend`, `upload_cover` або такі операції, як вибірка інтервалу, що потребують `audio_id`. Якщо потрібно через функцію творчості на основі натхнення Inspo створити нову музику на основі 1–4 повних референсних аудіо, безпосередньо викличте `action=inspo` і передайте список вихідних загальнодоступних URL аудіо; сервіс автоматично завершить завантаження та аналіз, без потреби клієнту формувати audio metadata.

## Розширений режим завантаження

> `audio_url` є вхідною адресою та буде безпосередньо передано процесу обробки аудіо, без попереднього перенесення службою постійного зберігання кінцевих медіафайлів. Будь ласка, переконайтеся, що вона є загальнодоступною протягом обробки завдання.

Коли звичайне завантаження не може обробити аудіо, яким ви володієте або на використання якого отримали дозвіл, можна встановити для `mode` значення `enhanced`. Для цього режиму також обов’язково потрібно надати `name` довжиною від 1 до 100 символів і використовувати загальнодоступний HTTPS `audio_url`.

Розширене завантаження завжди використовує асинхронну обробку та зазвичай потребує 2 хвилин або більше. Успішна обробка споживає **1.87 Credits**; за невдалу обробку плата не стягується.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

Інтерфейс негайно поверне `task_id` і `trace_id`. Використовуйте [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) для запиту завдання, а після успіху прочитайте ID аудіо після завантаження з `response.data.audio_id`. Також можна надати HTTPS `callback_url` для отримання кінцевого стану.

`audio_id`, отриманий через розширене завантаження, може використовуватися для Cover, Samples і Mashup. Витягування акомпанементу та MIDI, розділення всіх доріжок, а також розділення вокалу/акомпанементу все ще можуть бути обмежені акаунтом, якому належить аудіо; для не перелічених операцій не гарантується підтримка міжакаунтного використання. Чим коротше аудіо, тим зазвичай вища ймовірність успішної обробки.
