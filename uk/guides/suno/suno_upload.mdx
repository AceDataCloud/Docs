SUNO дозволяє нам завантажувати референсне аудіо для повторної творчості, цей документ пояснює методи інтеграції відповідних API.

Звичайне завантаження вимагає лише `audio_url`, це публічно доступна адреса аудіо CDN. `mode` за замовчуванням є `standard`, тому існуючі виклики не потребують змін.

Тут ми вводимо `audio_url` як `https://cdn.acedata.cloud/suno_demo.mp3`, це публічно доступна адреса CDN.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Отримавши ID пісні, ми можемо використовувати [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для створення кастомізованих пісень, наприклад, передавши `action` як `upload_extend`, а `audio_id` як повернений ID пісні, ми можемо створити нову пісню на основі референсного аудіо.

## Розширений режим завантаження

Коли звичайне завантаження не може обробити аудіо, яке ви маєте або на яке маєте ліцензію, можна встановити `mode` на `enhanced`. Цей режим також вимагає наявності `name` від 1 до 100 символів і використання публічно доступного HTTPS `audio_url`.

Розширене завантаження завжди обробляється асинхронно, зазвичай потребує 2 хвилини або більше. Успішна обробка споживає **1.87 Credits**, що за максимальним тарифом становить приблизно **¥1.20/раз**; у разі невдачі плата не стягується.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

Інтерфейс негайно поверне `task_id` та `trace_id`. Використовуйте [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) для перевірки завдання, після успішної обробки зчитуйте ID завантаженого аудіо з `response.data.audio_id`. Також можна надати HTTPS `callback_url` для отримання фінального статусу.

Отриманий з розширеного завантаження `audio_id` може бути використаний для Cover, Samples та Mashup. Акустичні треки та MIDI екстракція, повна відокремленість треків, а також відокремлення вокалу/аккомпанементу можуть залишатися під обмеженнями облікового запису, до якого належить аудіо; не гарантовано підтримка не перерахованих операцій для використання між обліковими записами. Чим коротше аудіо, тим зазвичай вища ймовірність успішної обробки.
