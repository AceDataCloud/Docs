Спеціалізована музична модель може навчатися послідовним музичним характеристикам з 6 до 24 авторизованих аудіо та використовуватися для подальшого створення пісень. Створення є асинхронною операцією; рекомендується використовувати 24 аудіо з однаковим стилем та чіткою якістю для досягнення більш стабільного результату.

> Можна подавати лише ті аудіо, на які ви маєте законні права використання або отримали авторизацію на створення моделі та подальше генерування. Не завантажуйте музику або звукові матеріали без дозволу.

## Створення моделі

Викликайте `POST /suno/custom-models` і встановіть `action=create`. Рекомендується одночасно надсилати унікальний заголовок запиту `Idempotency-Key`; при повторних спробах в мережі використовуйте той самий ключ, щоб уникнути повторного створення:

```json
{
  "action": "create",
  "name": "Моя Інді Модель",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

Інтерфейс негайно повертає ID моделі платформи та ID завдання. Після завершення створення, зворотний виклик або запит результату міститиме `status`, що зміниться на `ready`. Лише успішне створення моделі буде коштувати **10 Credits**; невдале створення не призведе до витрат.

## Запит моделі

Запит на одну модель:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Пагінований запит на моделі поточного застосунку:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Всі моделі належать створеному застосунку Suno. Зміна облікових даних API не змінює належність моделі, інші застосунки не можуть запитувати або використовувати цю модель.

## Використання моделі для генерації пісень

Після того, як статус моделі стане `ready`, продовжте викликати `POST /suno/custom-models` і встановіть `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Неоновий дощ",
  "lyric": "[Куплет]\nМіські вогні падають крізь дощ",
  "style": "інді рок, теплий аналоговий синтезатор"
}
```

`id` має бути спеціалізованою музичною моделлю з поточного застосунку, статус якої `ready`. Якщо модель недоступна, запит не вдасться, автоматично не буде використано іншу модель. Успішна генерація пісні споживає **0.90 Credits**; невдала генерація не призводить до витрат. Запити та архівування моделей безкоштовні.

## Архівування моделі

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Поточна бета-версія архівує модель і забороняє подальше використання, у відповіді `capacity_released=false` вказує, що архівування не гарантує звільнення ємності моделі. Операцію архівування можна повторно викликати, вона не призведе до повторних витрат.
