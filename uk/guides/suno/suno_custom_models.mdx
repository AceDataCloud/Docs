Кастомні музичні моделі можуть вивчати узгоджені музичні характеристики з 6 до 24 ліцензованих аудіозаписів і використовувати їх для подальшого створення пісень. Створення є асинхронною операцією; для стабільнішого результату рекомендується використовувати 24 аудіозаписи з узгодженим стилем і чіткою якістю звуку.

> Можна надсилати лише аудіозаписи, на використання яких ви маєте законні права або для яких отримали дозвіл на створення моделі та подальшу генерацію. Не завантажуйте музику чи звукові матеріали без дозволу.

## Створення моделі

Викличте `POST /suno/custom-models` і встановіть `action=create`:

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

Інтерфейс негайно повертає ID моделі платформи та ID завдання. Після завершення створення `status` у зворотному виклику або результаті запиту зміниться на `ready`. **10 Credits** стягуються лише за успішне створення моделі; за невдале створення плата не стягується.

## Запит моделі

Запит однієї моделі:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Пагінований запит моделей поточного застосунку:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Усі моделі належать застосунку Suno, який їх створив. Ротація API-облікових даних не змінює належність моделі, а інші застосунки не можуть запитувати чи використовувати цю модель.

## Генерація пісень за допомогою моделі

Коли статус моделі стане `ready`, продовжуйте викликати `POST /suno/custom-models` і встановіть `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id` має бути ID кастомної музичної моделі поточного застосунку зі статусом `ready`. Якщо модель недоступна, запит завершиться помилкою й автоматично не перейде на використання іншої моделі. `persona_id` є взаємовиключним із кастомною музичною моделлю; у разі одночасного надсилання інтерфейс поверне HTTP 400 до надсилання запиту до сервісу генерації, і плата не стягуватиметься. Щоб використовувати Persona, натомість скористайтеся операцією `artist_consistency` або `artist_consistency_vox` у `/suno/audios`.

Успішна генерація пісні споживає **0.90 Credits**; за невдалу генерацію плата не стягується. Запитування та архівування моделей є безкоштовними.

## Архівування моделі

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Поточна Beta-версія архівує модель і забороняє її подальше використання; `capacity_released=false` у відповіді означає, що архівування не гарантує вивільнення ємності моделі. Операцію архівування можна викликати повторно, і повторна плата не стягується.
