---
title: "Suno змішування текстів пісень API інтеграція"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Якщо ви хочете використовувати тексти двох пісень для створення змішаної пісні, спочатку можна скористатися цим API для генерації відповідних текстів, API - це [Suno MashupLyrics Generation API](https://platform.acedata.cloud/documents/suno-mashup-lyrics).

Основні вхідні параметри цього API - це `lyrics_a`, `lyrics_b`, приклад заповнення наведено нижче:

![](https://cdn.acedata.cloud/g9n3t6.png)

Натисніть "Запустити", результат буде таким:

```
{
  "success": true,
  "task_id": "80aa3cd3-ca87-4ca3-82d2-1830e3d8f53a",
  "data": {
    "text": "Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nSambuy come, Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \nSambuy come back",
    "title": "Lyrics Mashup",
    "tags": [],
    "status": "complete"
  }
}
```

Можна побачити, що поле `text` в `data` містить інформацію про тексти.

Отримавши тексти, ми можемо використовувати [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для створення кастомізованої пісні.
