---
title: "API перевірки доступності аудіо Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

`POST /suno/availability` шукає на основі `audio_id` позитивні докази того, що аудіо може й надалі оброблятися на поточному маршруті. Його можна викликати перед такими операціями, як продовження чи кавер; результат відображає лише стан на момент перевірки та не гарантує успіх конкретної операції. Цей інтерфейс повертає відповідь синхронно, потребує API Token і наразі не списує Credits.

`audio_id` — це ID пісні, повернений завершеним завданням Suno, а не `task_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

Приклад успішної відповіді:

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

У разі успішної перевірки `data.available` має значення `true`; якщо підтвердити неможливо, повертається `503 availability_unknown` без `false`. Помилка формату `audio_id` повертає 400; перевищення ліміту запитів або помилка сервісу також повертають відповідь із помилкою. Стан може змінитися між завершенням перевірки та фактичним виконанням операції.
