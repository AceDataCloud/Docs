Основна функція Suno Tasks API полягає в тому, щоб за допомогою введеного ID завдання, отриманого з Suno Audios Generation API або Suno Lyrics Generation API, перевіряти стан виконання цього завдання.

Цей документ детально описує інтеграцію Suno Tasks API, щоб допомогти вам легко інтегрувати та повністю використовувати потужні можливості цього API. За допомогою Suno Tasks API ви можете легко реалізувати запити на перевірку стану виконання завдань Suno Lyrics Generation API або Suno Audios Generation API.

## Процес подачі заявки

Щоб використовувати Suno Tasks API, спочатку потрібно перейти на сторінку подачі заявки [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для отримання відповідної послуги, а потім скопіювати ID завдання Suno Audios Generation API, як показано на малюнку:

<p><img src="https://cdn.acedata.cloud/bc6754.png" width="500" className="m-auto" /></p>

Нарешті, перейдіть на сторінку Tasks API [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) для отримання відповідної послуги, після входу на сторінку натисніть кнопку «Acquire», як показано на малюнку:

![Сторінка подачі заявки](https://cdn.acedata.cloud/rci31i.png)

Якщо ви ще не увійшли в систему або не зареєструвалися, вас автоматично перенаправлять на [сторінку входу](https://platform.acedata.cloud), запрошуючи вас зареєструватися та увійти. Після входу або реєстрації ви автоматично повернетеся на поточну сторінку.

При першій подачі заявки вам буде надано безкоштовний ліміт, який дозволяє безкоштовно використовувати цей API.

## Приклад запиту

Suno Tasks API можна використовувати для перевірки результатів двох API: Suno Audios Generation API та Suno Lyrics Generation API. Щоб дізнатися, як використовувати Suno Audios Generation API, будь ласка, зверніться до документа [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios-integration). Щоб дізнатися, як використовувати Suno Lyrics Generation API, будь ласка, зверніться до [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics-generation-integration).

Розглянемо приклад з ID завдання, отриманого від служби Suno Audios Generation API, щоб продемонструвати, як використовувати цей API. Припустимо, у нас є ID завдання: eae26f89-b64b-404d-a80c-761996660b1c, далі продемонструємо, як передати ID завдання.

### Налаштування заголовків запиту та тіла запиту

**Request Headers** включає:

- `accept`: вказує на прийняття відповіді у форматі JSON, тут вказується `application/json`.
- `authorization`: ключ для виклику API, після подачі заявки можна вибрати з випадаючого списку.

**Request Body** включає:

- `id`: ID завдання, яке потрібно завантажити.
- `action`: спосіб виконання дії над завданням.

Налаштування виглядає так, як показано на малюнку:

<p><img src="https://cdn.acedata.cloud/uo7t6n.png" width="500" className="m-auto" /></p>

### Приклад коду

Можна помітити, що на правій стороні сторінки автоматично згенеровано код на різних мовах, як показано на малюнку:

<p><img src="https://cdn.acedata.cloud/p6vi9o.png" width="500" className="m-auto" /></p>

Деякі приклади коду наведені нижче:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/suno/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "eae26f89-b64b-404d-a80c-761996660b1c",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "eae26f89-b64b-404d-a80c-761996660b1c",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "ids": ["eae26f89-b64b-404d-a80c-761996660b1c","0d3ed03b-912b-4f7d-941b-8441323cb77b"],
    "action": "retrieve_batch"
```

## Обробка помилок

При виклику API, якщо виникає помилка, API поверне відповідний код помилки та інформацію. Наприклад:

- `400 token_mismatched`: Неправильний запит, можливо, через відсутні або недійсні параметри.
- `400 api_not_implemented`: Неправильний запит, можливо, через відсутні або недійсні параметри.
- `401 invalid_token`: Неавторизовано, недійсний або відсутній токен авторизації.
- `429 too_many_requests`: Занадто багато запитів, ви перевищили ліміт запитів.
- `500 api_error`: Внутрішня помилка сервера, щось пішло не так на сервері.
