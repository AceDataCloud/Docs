API проєкту Suno Studio керує багатодоріжковими музичними проєктами через одну точку входу:

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

`action` у запиті визначає тип операції. Первинний ключ Project всюди використовує `id`; `version_id` позначає поточну версію проєкту, і всі операції модифікації та експорту повинні передавати останню версію, щоб уникнути перезапису через паралельні зміни.

## Огляд операцій

| action             | Режим  | Призначення                      |
| ------------------ | --- | ----------------------- |
| `create`           | Синхронний  | Створення порожнього проєкту                   |
| `retrieve`         | Синхронний  | Читання проєкту та повного редагованого `state`      |
| `save`             | Синхронний  | Збереження повного стану проєкту                |
| `upload`           | Асинхронний  | Ініціалізація матеріалу, який можна додати до проєкту, з HTTPS-адреси аудіо |
| `add_track`        | Асинхронний  | Додавання наявного аудіо до проєкту               |
| `generate_track`   | Асинхронний  | Генерування кандидатів нової аудіодоріжки для вказаного інтервалу            |
| `replace_section`  | Асинхронний  | Генерування кандидатів для локальної заміни                |
| `commit_candidate` | Асинхронний  | Додавання вибраного кандидата до проєкту             |
| `remove_track`     | Синхронний  | Видалення вказаної доріжки                  |
| `render`           | Асинхронний  | Експорт збереженої версії як повної пісні           |

Асинхронні операції негайно повертають `task_id`. Використовуйте безкоштовний інтерфейс `/suno/tasks` для опитування або передайте `callback_url` для отримання результату в кінцевому стані.

## Створення та читання

```json
{"action":"create","title":"My Studio Project"}
```

Усі операції модифікації повинні надсилати унікальний Header `Idempotency-Key`. Після успішного створення `data.id` у відповіді є Project ID. Новий порожній проєкт може не мати `version_id` до першого збереження.

```json
{"action":"retrieve","id":"PROJECT_ID"}
```

Відповідь на читання містить повний `state`. Рекомендується спочатку виконати читання, потім змінити та зберегти дані на основі повернених значень; не створюйте внутрішню структуру тактів і доріжок вручну з нуля.

## Збереження повного стану

```json
{
  "action":"save",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Edited Project",
  "state":{"tracks":[],"timing":{}}
}
```

Під час першого збереження нового порожнього проєкту `version_id` можна не вказувати; після того як перше збереження створить версію, наступні збереження повинні передавати останнє значення. Якщо версія вже змінилася, інтерфейс повертає HTTP 409. У такому разі повторно виконайте `retrieve`, об'єднайте зміни та надішліть їх із новим ключем ідемпотентності; не повторюйте старий запит бездумно.

## Завантаження та додавання доріжок

```json
{
  "action":"upload",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "audio_url":"https://cdn.example.com/reference.mp3",
  "async":true
}
```

Після завершення завантаження результат завдання повертає кандидат `audio_id`. Потім додайте його до проєкту:

```json
{
  "action":"add_track",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "audio_id":"AUDIO_ID",
  "name":"Backing Vocals"
}
```

## Генерування та заміна

`generate_track` генерує кандидатів аудіодоріжки для інтервалу проєкту; `replace_section` повертає двох кандидатів локальної заміни. Обидві операції не вибирають художній результат автоматично.

```json
{
  "action":"replace_section",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "source_audio_id":"AUDIO_ID",
  "start_seconds":35.12,
  "end_seconds":48.76,
  "model":"chirp-v6",
  "replacement_lyrics":"新的歌词片段",
  "async":true
}
```

Після вибору кандидата виконайте додавання:

```json
{
  "action":"commit_candidate",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "operation_id":"OPERATION_ID",
  "candidate_id":"CANDIDATE_ID",
  "track_id":"TRACK_ID"
}
```

Кандидати пов'язані з версією проєкту на час генерування. Якщо проєкт уже змінився, старі кандидати не можна додати безпосередньо.

## Експорт повної пісні

```json
{
  "action":"render",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Final Mix",
  "lyrics":"[Instrumental]",
  "async":true,
  "callback_url":"https://example.com/webhooks/suno"
}
```

Сервер читає авторитетний стан проєкту вказаної версії та збирає параметри експорту. Результат кінцевого стану містить `render_id`, `audio_id`, `audio_url` і тривалість. Проєкт прив'язаний до середовища виконання під час створення, і його не можна переносити між середовищами або автоматично перемикати в разі збою.

> Завантажуйте або обробляйте лише аудіо, на законне використання якого ви маєте право. API проєкту наразі перебуває у Beta; зберігайте остаточні URL-адреси аудіо у важливих результатах.
