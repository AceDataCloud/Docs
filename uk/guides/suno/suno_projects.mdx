API проєкту Suno Studio через одну точку входу керує багатодоріжковими музичними проєктами:

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

`action` у запиті визначає тип операції. Первинний ключ Project уніфіковано використовує `id`; `version_id` позначає поточну версію проєкту, і всі операції зі зміни та експорту мають надсилати найновішу версію, щоб уникнути перезапису через паралельні зміни.

## Огляд операцій

| action             | Режим  | Призначення                      |
| ------------------ | --- | ----------------------- |
| `create`           | Синхронний  | Створення порожнього проєкту                   |
| `retrieve`         | Синхронний  | Читання проєкту та повного редагованого `state`      |
| `save`             | Синхронний  | Збереження повного стану проєкту                |
| `upload`           | Асинхронний  | Ініціалізація з HTTPS-адреси аудіо матеріалу, який можна додати до проєкту |
| `add_track`        | Асинхронний  | Додавання наявного аудіо до проєкту               |
| `generate_track`   | Асинхронний  | Генерування кандидатів нової аудіодоріжки для заданого інтервалу            |
| `replace_section`  | Асинхронний  | Генерування кандидатів для локальної заміни                |
| `commit_candidate` | Асинхронний  | Застосування вибраного кандидата до проєкту             |
| `remove_track`     | Синхронний  | Видалення вказаної доріжки                  |
| `render`           | Асинхронний  | Експорт збереженої версії як повної пісні           |

Асинхронні операції одразу повертають `task_id`. Використовуйте безкоштовний інтерфейс `/suno/tasks` для опитування або передайте `callback_url` для отримання результату в кінцевому стані.

## Створення та читання

```json
{"action":"create","title":"My Studio Project"}
```

Усі операції зі зміни мають надсилати унікальний Header `Idempotency-Key`. Після успішного створення `data.id` у відповіді є Project ID.

```json
{"action":"retrieve","id":"PROJECT_ID"}
```

Відповідь на читання містить повний `state`. Рекомендується спочатку виконати читання, потім змінити та зберегти дані на основі поверненого значення; не створюйте внутрішню структуру ритму та доріжок вручну з нуля.

## Збереження повного стану

```json
{
  "action":"save",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Edited Project",
  "state":{"tracks":[],"timing":{}}
}
```

Якщо версія вже змінилася, інтерфейс повертає HTTP 409. У такому разі знову виконайте `retrieve`, об’єднайте зміни та надішліть їх із новим ключем ідемпотентності; не повторюйте старий запит бездумно.

## Завантаження та додавання доріжок

```json
{
  "action":"upload",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "audio_url":"https://cdn.example.com/reference.mp3",
  "async":true
}
```

Після завершення завантаження результат завдання повертає кандидатний `audio_id`. Потім додайте його до проєкту:

```json
{
  "action":"add_track",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "audio_id":"AUDIO_ID",
  "name":"Backing Vocals"
}
```

## Генерування та заміна

`generate_track` генерує кандидатів аудіодоріжки для інтервалу проєкту; `replace_section` повертає двох кандидатів для локальної заміни. Обидві операції не вибирають художній результат автоматично.

```json
{
  "action":"replace_section",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "source_audio_id":"AUDIO_ID",
  "start_seconds":35.12,
  "end_seconds":48.76,
  "model":"chirp-v6",
  "replacement_lyrics":"新的歌词片段",
  "async":true
}
```

Після вибору кандидата застосуйте його:

```json
{
  "action":"commit_candidate",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "operation_id":"OPERATION_ID",
  "candidate_id":"CANDIDATE_ID",
  "track_id":"TRACK_ID"
}
```

Кандидати прив’язані до версії проєкту на час генерування. Якщо проєкт уже змінився, старі кандидати не можна застосувати безпосередньо.

## Експорт повної пісні

```json
{
  "action":"render",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Final Mix",
  "lyrics":"[Instrumental]",
  "async":true,
  "callback_url":"https://example.com/webhooks/suno"
}
```

Сервер читає авторитетний стан проєкту вказаної версії та формує параметри експорту. Результат у кінцевому стані містить `render_id`, `audio_id`, `audio_url` і тривалість. Проєкт прив’язаний до середовища виконання на момент створення та не може переноситися між середовищами або автоматично перемикатися в разі збою.

> Завантажувати або обробляти можна лише аудіо, на законне використання якого ви маєте права. API проєктів наразі перебуває у Beta; зберігайте остаточні URL аудіо з важливих результатів.
