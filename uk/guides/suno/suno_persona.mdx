---
title: "Інструкція з інтеграції API користувацького стилю виконавця Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO дозволяє нам задавати стиль виконавця для вже згенерованих пісень, а потім на його основі виконувати вторинну творчість; у цьому документі пояснюється спосіб інтеграції відповідного API.

Запит списку `GET /suno/persona` і видалення запису `DELETE /suno/persona` не тарифікуються, додатковий заголовок запиту для звільнення від тарифікації не потрібен. Операція створення `POST /suno/persona` усе ще тарифікується згідно з правилами ціноутворення інтерфейсу.

Цей API має лише три вхідні параметри: спочатку `audio_id`, це ID пісні, яка вже була успішно згенерована офіційно, далі `name`, `description` — це назва й опис стилю виконавця.

Тут введений нами `audio_id` — це `https://cdn.acedata.cloud/2qhzs3.png`; для цього можна звернутися до [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios), щоб виконати користувацьку генерацію пісні, і зрештою отримати `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Результат такий:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Можна побачити, що поле `persona_id` у `data` — це ID стилю виконавця після генерації.

Після отримання ID стилю виконавця ми можемо використовувати [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios), щоб виконати користувацьку генерацію пісні; наприклад, передати в `action` значення `artist_consistency`, водночас передати в `audio_id` ID завантаженої пісні, а також потрібно завантажити параметр `persona_id`, значенням якого є повернений вище ID стилю виконавця — тоді можна буде генерувати нові пісні на основі референсного стилю виконавця.
