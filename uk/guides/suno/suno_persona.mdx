---
title: "Інструкція з інтеграції API користувацького стилю співака Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO дозволяє нам встановлювати стиль співака для вже згенерованих пісень, а потім виконувати на його основі вторинну творчість, цей документ пояснює відповідний метод інтеграції API.

Запит списку `GET /suno/persona` і видалення записів `DELETE /suno/persona` не тарифікуються, додатковий заголовок запиту для звільнення від тарифікації не потрібен. Операція створення `POST /suno/persona` усе ще тарифікується відповідно до правил ціноутворення інтерфейсу.

На лінії створення, що підтримує запит тембру голосу, можна використовувати оригінальний застосунок і ідентичність виклику, щоб передати `persona_id` з результату створення до `POST /suno/availability`. Якщо доступність підтверджено, повертається `data.available=true`. [Посібник із перевірки доступності тембру голосу](https://platform.acedata.cloud/documents/suno-availability-integration)

Цей API має лише три вхідні параметри: спочатку `audio_id`, це ID пісні, яка вже була успішно згенерована офіційно, далі `name`, `description` — це назва та опис стилю співака.

Тут введений нами `audio_id` — це `https://cdn.acedata.cloud/2qhzs3.png`, для цього можна звернутися до [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios), щоб виконати користувацьку генерацію пісні, і зрештою отримати `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Результат такий:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Можна побачити, що поле `persona_id` у `data` — це ID стилю співака після генерації.

Після отримання ID стилю співака ми можемо використовувати [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для користувацької генерації пісні, наприклад, передати `artist_consistency` в `action`, водночас передати ID завантаженої пісні в `audio_id`, також потрібно завантажити параметр `persona_id`, це значення є ID стилю співака, поверненим вище, і тоді можна генерувати нові пісні на основі еталонного стилю співака.
