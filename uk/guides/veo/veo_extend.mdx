У цьому документі буде представлено інструкцію з інтеграції Veo Extend API. Цей інтерфейс використовується для **продовження тривалості** вже згенерованого відео Veo, AI автоматично дописує наступні кадри.

## Процес подачі заявки

Щоб використовувати API, спочатку потрібно перейти на відповідну сторінку сервісу Veo для подачі заявки. Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу.

## Основне використання

Для виклику цього інтерфейсу потрібно передати наступні параметри:

- `video_id` (обов'язковий): ID завдання вихідного відео (з `/veo/videos` або з цього самого інтерфейсу).
- `model` (обов'язковий): модель, що використовується для продовження, **підтримуються лише моделі `veo31-fast` та `veo31`**, інші моделі не підтримуються.
- `prompt` (необов'язковий): текстове підказка для направлення продовження кадрів.
- `aspect_ratio` (необов'язковий): `16:9` або `9:16`, за замовчуванням `16:9`.
- `resolution` (необов'язковий): `720p` або `1080p`.

Приклад запиту:

```shell
curl -X POST 'https://api.acedata.cloud/veo/extend' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "model": "veo31-fast",
    "prompt": "камера повільно віддаляється, щоб показати більше пейзажу"
  }'
```

Результат відповіді такий же, як у `/veo/videos`:

```json
{
  "success": true,
  "task_id": "5fa2d9a6-7e54-481b-a4b0-3dc6f25dd2ab",
  "data": [
    {
      "id": "9b6f3b6b9c45419fbf2e3fe2f10b2b3a",
      "video_url": "https://platform.cdn.acedata.cloud/veo/5fa2d9a6.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

## Важливі обмеження

`video_id` повинен бути отриманий з TTAPI лінії, згенерованої або завершеної `data[].id`. Історичні ID відео, згенеровані старою лінією до переходу на TTAPI, не можуть бути використані в цьому інтерфейсі, при виклику буде повернено `400 bad_request`; будь ласка, перегенеруйте через `/veo/videos`, а потім продовжте.

Результати відео, отримані з `/veo/extend`, можуть **продовжуватися через `/veo/extend`** ще раз, але **не можуть** оброблятися наступними інтерфейсами:

- `/veo/reshoot` — не можна змінювати рух камери
- `/veo/objects` — не можна додавати або видаляти об'єкти

Якщо переданий `video_id` є результатом продовження, відповідні інтерфейси повернуть 400 помилку, будь ласка, використовуйте оригінальне відео як джерело.

## Інформація про тарифи

- `model=veo31-fast`: 1.68 Credit / раз
- `model=veo31`: 12.00 Credit / раз

## Асинхронний зворотний виклик

Інтерфейс підтримує асинхронний режим, передавши `callback_url`, ви зможете отримати результати через POST запит після завершення завдання. Якщо немає публічної адреси для зворотного виклику, ви також можете встановити `async` в `true`, інтерфейс також негайно поверне `task_id`, а потім через відповідний інтерфейс запиту завдань можна опитувати для отримання результатів.
