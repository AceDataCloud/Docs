У цьому документі буде представлено інструкцію з інтеграції Veo Reshoot API. Цей інтерфейс використовується для повторної генерації вже створеного відео Veo відповідно до **нового способу руху камери**, вміст зображення залишається незмінним, але позиція та рух камери будуть переосмислені відповідно до `motion_type`.

## Процес подачі заявки

Щоб використовувати API, спочатку потрібно подати заявку на відповідній сторінці сервісу Veo. Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу.

## Основне використання

Для виклику цього інтерфейсу потрібно передати наступні параметри:

- `video_id` (обов'язковий): ID завдання вихідного відео. **Не може** бути вихідним відео з `/veo/extend`.
- `motion_type` (обов'язковий): новий спосіб руху камери, використовуючи прості псевдоніми у стилі великих літер з підкресленнями.

### Підтримувані значення `motion_type`

| Псевдонім                          | Значення         |
| ---------------------------------- | ---------------- |
| `STATIONARY`                       | Камера нерухома       |
| `STATIONARY_UP`                    | Камера нерухома, нахилена вгору    |
| `STATIONARY_DOWN`                  | Камера нерухома, нахилена вниз    |
| `STATIONARY_LEFT`                  | Камера нерухома, нахилена вліво      |
| `STATIONARY_RIGHT`                 | Камера нерухома, нахилена вправо      |
| `STATIONARY_DOLLY_IN_ZOOM_OUT`     | Камера нерухома, вперед + зменшення фокусу |
| `STATIONARY_DOLLY_OUT_ZOOM_IN`     | Камера нерухома, назад + збільшення фокусу |
| `UP`                               | Камера піднімається         |
| `DOWN`                             | Камера опускається         |
| `LEFT_TO_RIGHT`                    | Камера переміщується зліва направо     |
| `RIGHT_TO_LEFT`                    | Камера переміщується справа наліво     |
| `FORWARD`                          | Камера рухається вперед       |
| `BACKWARD`                         | Камера рухається назад        |
| `DOLLY_IN_ZOOM_OUT`                | Рухаючись вперед + зменшення фокусу   |
| `DOLLY_OUT_ZOOM_IN`                | Рухаючись назад + збільшення фокусу   |

Приклад запиту:

```shell
curl -X POST 'https://api.acedata.cloud/veo/reshoot' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "motion_type": "LEFT_TO_RIGHT"
  }'
```

Структура результату відповіді така ж, як у `/veo/videos`.

## Інформація про тарифи

- Одноразова перезйомка: 1.20 Credit.

## Асинхронний зворотний виклик

Інтерфейс підтримує асинхронний режим, передавши `callback_url`, ви зможете отримати результати через POST запит після завершення завдання. Якщо немає публічної адреси для зворотного виклику, ви також можете встановити `async` в `true`, інтерфейс також негайно поверне `task_id`, а потім через відповідний інтерфейс запиту завдань можна опитувати для отримання результатів.
