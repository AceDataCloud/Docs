Цей документ представить інструкцію з інтеграції Veo Upsample API. Цей інтерфейс використовується для підвищення якості вже згенерованого відео Veo або для виводу попереднього перегляду анімації.

## Процес подачі заявки

Щоб використовувати API, спочатку потрібно перейти на відповідну сторінку сервісу Veo для подачі заявки. Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу.

## Основне використання

Для виклику цього інтерфейсу потрібно передати два параметри:

- `video_id`: ID завдання вихідного відео. Це може бути ID відео, згенероване будь-яким з інтерфейсів `/veo/videos`, `/veo/extend`, `/veo/reshoot`, `/veo/objects`.
- `action`: дія підвищення якості, підтримуються три варіанти:
  - `1080p`: підвищити якість відео до роздільної здатності 1080p.
  - `4k`: підвищити якість відео до роздільної здатності 4K.
  - `gif`: перетворити відео в анімацію (GIF) для попереднього перегляду.

Приклад запиту:

```shell
curl -X POST 'https://api.acedata.cloud/veo/upsample' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "4k"
  }'
```

Результат відповіді такий же, як у `/veo/videos`, все ще має структуру асинхронного завдання, можна перевірити статус завдання через `task_id` в інтерфейсі `/veo/tasks`:

```json
{
  "success": true,
  "task_id": "8f5a90ae-3f86-4c4f-86f7-7126f5e92c76",
  "trace_id": "0f3e09c2-4c2e-46ea-9cdc-a31ec48b7c12",
  "data": [
    {
      "id": "253eedc47f1c4eb2a370ed2312168f4b",
      "video_url": "https://platform.cdn.acedata.cloud/veo/8f5a90ae.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

Опис полів відповіді:

- `success`: чи успішно подано завдання на підвищення якості.
- `task_id`: ID цього завдання на підвищення якості.
- `data`: результати відео після підвищення якості.
  - `video_url`: адреса відео після підвищення якості.

## Опис тарифікації

- `action=1080p`: 0.16 Credit / раз
- `action=4k`: 0.50 Credit / раз
- `action=gif`: 0.13 Credit / раз

Якщо передане `action` не входить до вищезазначених варіантів, буде застосовано стандартна тарифікація 0.50 Credit. Рекомендується явно передавати підтримувані значення.

## Асинхронний зворотний виклик

Інтерфейс також підтримує асинхронний режим, передавши `callback_url`, ви зможете отримати результати через POST запит після завершення завдання. Якщо немає публічної адреси для зворотного виклику, можна встановити `async` в `true`, інтерфейс також відразу поверне `task_id`, а потім через відповідний інтерфейс запиту завдань можна опитувати результати.
