У цьому документі буде представлено інструкцію з інтеграції API Veo Objects. Цей інтерфейс використовується для виконання операцій **додавання або видалення об'єктів** на вже згенерованому відео Veo (на основі маски для локального перерисування).

## Процес подачі заявки

Щоб використовувати API, спочатку потрібно перейти на відповідну сторінку сервісу Veo для подачі заявки. Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу.

## Основне використання

Для виклику цього інтерфейсу потрібно передати наступні параметри:

- `video_id` (обов'язковий): ID завдання вихідного відео. **Не може** бути вихідним відео з `/veo/extend`.
- `action` (обов'язковий): тип операції, `insert` або `remove`.
- `prompt`:
  - `action=insert`: **обов'язковий**, опис об'єкта, який потрібно додати.
  - `action=remove`: необов'язковий, опис вмісту, який потрібно видалити (в основному для ведення журналу, фактична область видалення визначається `image_mask`).
- `image_mask`:
  - `action=insert`: необов'язковий. Якщо не передати, AI автоматично визначить місце вставки; якщо передати, то вставка відбудеться в області білих пікселів.
  - `action=remove`: **обов'язковий**, область білих пікселів є об'єктом, який потрібно видалити.

`image_mask` приймає два формати:

1. **Публічно доступна HTTP(S) адреса зображення** (рекомендується).
2. **base64 закодований JPEG рядок**, може мати префікс `data:image/jpeg;base64,`, або бути чистим base64.

Приклад запиту (додавання об'єкта, без передачі маски, щоб AI автоматично визначив місце):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "insert",
    "prompt": "додати літаючу свиню з чорними крилами"
  }'
```

Приклад запиту (видалення об'єкта за маскою):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "remove",
    "image_mask": "https://example.com/mask.jpg",
    "prompt": "видалити білу хмару"
  }'
```

Структура результату відповідає `/veo/videos`.

## Інформація про тарифи

- `action=insert` або `remove`: 1.50 Credit / раз.

## Асинхронний зворотний виклик

Інтерфейс підтримує асинхронний режим, передавши `callback_url`, ви зможете отримати результати через POST запит після завершення завдання. Якщо немає публічної адреси для зворотного виклику, також можна встановити `async` в `true`, інтерфейс також негайно поверне `task_id`, після чого результати можна отримати через відповідний інтерфейс запиту завдань.
