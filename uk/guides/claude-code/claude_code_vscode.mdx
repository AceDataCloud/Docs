Claude Code — це інструмент програмування, випущений компанією Anthropic, також відомий як один з найпотужніших програмних агентів у світі. Розширення Claude Code для VS Code надає рідний графічний інтерфейс, що є рекомендованим способом використання Claude Code у VS Code.

Цей документ в основному описує, як налаштувати та використовувати розширення Claude Code у VS Code через проксі-сервіс Ace Data Cloud.

## Процес подачі заявки

Щоб використовувати Claude Code, спочатку перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud/console/applications), щоб отримати ваш API Token, залиште його на випадок потреби.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Якщо ви ще не увійшли або не зареєструвалися, вас автоматично перенаправлять на сторінку входу, запрошуючи вас зареєструватися та увійти, після входу ви автоматично повернетеся на цю сторінку.

При першій подачі заявки буде надано безкоштовний ліміт, щоб ви могли безкоштовно випробувати послуги Claude Code.

## Встановлення плагіна Claude Code

У магазині розширень VS Code знайдіть **Claude Code**, підтвердіть, що видавець — **Anthropic**, і встановіть. Після завершення установки в панелі активності з'явиться вхід до Claude Code.

## Налаштування Ace Data Cloud API

При першому відкритті плагіна з'явиться запит на вхід до офіційного облікового запису Anthropic. Ми можемо пропустити офіційний вхід, налаштувавши проксі API Ace Data Cloud для використання без офіційної підписки.

Розширення та термінал CLI читають одну й ту ж набір налаштувань Claude Code. Повну аутентифікацію, обробку конфліктів облікових даних та глобальні налаштування дивіться в [інструкції з налаштування терміналу Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration). Якщо ви хочете, щоб це діяло лише для поточного проекту, створіть у кореневій директорії проекту файл `.claude/settings.local.json`, який буде додано до `.gitignore`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Де `{token}` — це щойно скопійований API Key. Якщо в середовищі, в якому ви запускаєте VS Code, вже є старий `ANTHROPIC_API_KEY`, спочатку виконайте `unset ANTHROPIC_API_KEY` у цьому середовищі; не використовуйте порожній рядок для очищення і не розміщуйте реальний ключ у спільному файлі `.claude/settings.json`.

Нижче наведено налаштування, виконане на локальному комп'ютері з використанням VS Code 1.136.1 та розширення Claude Code 2.1.251. На скріншоті використано заповнювальний ключ, щоб уникнути витоку реальних облікових даних:

![Налаштування Ace Data Cloud Claude Code у VS Code](https://cdn.acedata.cloud/f925e9e9597b.png)

Після завершення налаштування перезапустіть VS Code.

> Увага: вказане вище налаштування діє лише для поточного проекту, і рекомендується додати шлях до файлу `.claude/settings.local.json` до файлу `.gitignore`, щоб уникнути його потрапляння до віддаленого репозиторію.

Якщо ви хочете, щоб це діяло для всіх проектів, ви можете безпосередньо додати це налаштування до каталогу користувача. Відповідний шлях — `~/.claude/settings.json`,

> Увага: після завершення налаштування перезапустіть або перезавантажте VS Code, щоб ці налаштування набрали чинності.

## Основне використання

Після налаштування на панелі Claude Code надішліть просте завдання лише для читання, наприклад, "Прочитайте README.md і підсумуйте його в одному реченні". Після успішного виконання завдання ви можете перевірити цей виклик у [історії використання](https://platform.acedata.cloud/console/usages).

## Як перевірити залишок ліміту

Через [консолю Ace Data Cloud - Список додатків](https://platform.acedata.cloud/console/applications) ви можете перевірити залишок ліміту на вашому рахунку.

Через [консолю Ace Data Cloud - Історія використання](https://platform.acedata.cloud/console/usages) ви можете переглянути всю історію використання та деталі витрат.
