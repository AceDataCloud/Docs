Claude Code — це інструмент **Agentic Coding**, розроблений компанією Anthropic, також відомий як один з найпотужніших програмних агентів у світі. Claude Code надає плагін, спеціально розроблений для JetBrains IDE, який підтримує повний спектр JetBrains IDE, включаючи IntelliJ IDEA, PyCharm, WebStorm, GoLand, PhpStorm, Android Studio тощо.

Цей документ в основному описує, як налаштувати та використовувати Claude Code в JetBrains IDE через проксі-сервіс AceData Cloud.

## Процес подачі заявки

Щоб використовувати Claude Code, спочатку перейдіть на [сторінку сервісу Claude Messages](https://platform.acedata.cloud/documents/claude-messages) і натисніть кнопку «Acquire», щоб отримати необхідні облікові дані для запиту:

![](https://cdn.acedata.cloud/nyq0xz.png)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, запрошуючи вас зареєструватися та увійти. Після входу та реєстрації ви автоматично повернетеся на цю сторінку.

При першій подачі заявки вам буде надано безкоштовний ліміт, щоб ви могли безкоштовно випробувати послуги Claude Code.

## Встановлення

### Попередні умови

Плагін Claude Code для JetBrains залежить від Claude Code CLI, тому спочатку переконайтеся, що CLI встановлено:

```bash
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# Або використовуйте Homebrew
brew install claude-code
```

Після завершення встановлення ви можете перевірити:

```bash
claude --version
```

### Встановлення плагіна

![Плагін Claude Code в JetBrains Marketplace](https://cdn.acedata.cloud/de78fd305b.png)

1. Відкрийте JetBrains IDE
2. Перейдіть до **Settings** → **Plugins** → **Marketplace**
3. Знайдіть **Claude Code**
4. Натисніть **Install** для встановлення плагіна
5. Перезавантажте IDE

Або відвідайте [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/27310-claude-code-beta-) для онлайн-встановлення.

> **Важливо**: після встановлення плагіна потрібно **повністю перезавантажити IDE** (можливо, потрібно буде перезавантажити кілька разів), щоб він запрацював.

## Налаштування AceData Cloud API

Плагін Claude Code для JetBrains виконує команду `claude` через інтегрований термінал, тому спосіб налаштування змінних середовища такий же, як і для CLI.

### Крок перший: створення config.json

Створіть файл конфігурації для Claude Code:

| Система                | Шлях                                   |
| ----------------- | ------------------------------------ |
| **macOS / Linux** | `~/.claude/config.json`              |
| **Windows**       | `C:\Users\{ім'я_користувача}\.claude\config.json` |

У цьому файлі запишіть наступний вміст і збережіть:

```json
{
  "primaryApiKey": "self"
}
```

Швидка команда для створення на macOS / Linux:

```bash
mkdir -p ~/.claude && echo '{"primaryApiKey": "self"}' > ~/.claude/config.json
```

### Крок другий: налаштування змінних середовища

**Спосіб перший: налаштування в конфігураційному файлі Shell (рекомендується)**

Додайте наступний вміст до вашого `~/.zshrc` або `~/.bashrc`, замінивши `{token}` на ваш API токен:

```bash
# AceData Cloud - Налаштування проксі для Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Після внесення змін виконайте `source ~/.zshrc`, щоб налаштування набрали чинності, а потім **перезавантажте JetBrains IDE**.

**Спосіб другий: налаштування в settings.json Claude Code**

Редагуйте `~/.claude/settings.json` (якщо не існує, створіть):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Підказка**: API токен можна переглянути в [консолі AceData Cloud](https://platform.acedata.cloud/console).

## Основне використання

### Запуск з інтегрованого терміналу IDE

Відкрийте інтегрований термінал JetBrains IDE і виконайте:

```bash
claude
```

При запуску в інтегрованому терміналі IDE всі інтегровані функції (перегляд Diff, вибір контексту тощо) автоматично активуються.

### Підключення з зовнішнього терміналу

Якщо ви запускаєте Claude Code в зовнішньому терміналі, ви можете використовувати команду `/ide` для підключення до JetBrains IDE:

```bash
claude
> /ide
```

Переконайтеся, що ви запускаєте Claude Code з того ж шляху, що й коренева директорія проекту IDE, щоб Claude міг отримати доступ до тих самих файлів.

### Гарячі клавіші

| Гаряча клавіша                                      | Функція                      |
| ------------------------------------------------ | ----------------------- |
| `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux)        | Швидке відкриття Claude Code        |
| `Cmd+Option+K` (Mac) / `Alt+Ctrl+K` (Windows/Linux) | Вставка посилання на файл (наприклад, `@File#L1-99`) |

### Інтегровані функції

Плагін Claude Code для JetBrains надає наступні інтегровані функції:

- **Перегляд Diff**: зміни коду відображаються безпосередньо в переглядачі Diff IDE
- **Вибір контексту**: поточний вибраний код і вкладки автоматично передаються Claude
- **Посилання на файли**: швидке посилання на файли та номери рядків за допомогою гарячих клавіш
- **Діагностика**: інформація про Lint, синтаксичні помилки тощо автоматично передається Claude

## Налаштування плагіна

У **Settings** → **Tools** → **Claude Code [Beta]** можна налаштувати:

| Налаштування                      | Опис                                         |
| ----------------------------- | ------------------------------------------ |
| **Claude command**            | Налаштування власного шляху до команди Claude (наприклад, `/usr/local/bin/claude`) |
| **Enable automatic updates**  | Автоматична перевірка та встановлення оновлень плагіна                                |
| **Enable using Option+Enter** | Використання Option+Enter для переносу рядка в підказках на macOS             |

### Налаштування для користувачів WSL

Якщо ви використовуєте середовище WSL, потрібно налаштувати команду Claude як:

```
wsl -d Ubuntu -- bash -lic "claude"
```

(замініть `Ubuntu` на назву вашої версії WSL)

## Поширені запитання

### Що робити, якщо з'єднання не вдалося?

1. Перевірте, чи правильно створено файл `~/.claude/config.json`
2. Переконайтеся, що змінні середовища налаштовані правильно
3. Переконайтеся, що API токен дійсний (можна переглянути в [консолі](https://platform.acedata.cloud/console))
4. Перезавантажте JetBrains IDE і спробуйте ще раз

### Плагін не працює?

1. Переконайтеся, що ви запускаєте Claude Code з кореневої директорії проекту
2. Перевірте, чи плагін увімкнено в налаштуваннях IDE
3. Повністю перезавантажте IDE (можливо, потрібно буде перезавантажити кілька разів)
4. Якщо ви використовуєте режим віддаленої розробки, переконайтеся, що плагін встановлено на віддаленому хості (Settings → Plugin (Host))

### IDE не виявлено?

1. Переконайтеся, що плагін встановлено та увімкнено
2. Перезавантажте IDE
3. Переконайтеся, що ви запускаєте Claude Code в інтегрованому терміналі
4. Користувачам WSL слід ознайомитися з [посібником з усунення несправностей WSL](https://code.claude.com/docs/en/troubleshooting#jetbrains-ide-not-detected-on-wsl2)

### command not found

Якщо при натисканні на іконку Claude з'являється повідомлення "command not found":

1. Переконайтеся, що CLI встановлено: `which claude`
2. Налаштуйте повний шлях до команди Claude в налаштуваннях плагіна
3. Користувачі WSL повинні використовувати вказаний вище формат команди WSL
### Як переглянути залишок?

Увійдіть до [консолі AceData Cloud](https://platform.acedata.cloud/console), щоб переглянути залишок та використання вашого облікового запису.
