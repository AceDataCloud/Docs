## 1. Отримання API Key

Відкрийте [Список додатків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступних додатків і скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Встановлення CLI та плагіна

Спочатку встановіть Claude Code CLI.

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

Потім з JetBrains Marketplace встановіть **Claude Code** плагін і перезапустіть IDE. Плагін викликає локальну команду `claude`; якщо з'явиться повідомлення про те, що команда не знайдена, заповніть її повний шлях у **Settings → Tools → Claude Code**.

## 3. Налаштування Ace Data Cloud

Налаштуйте в середовищі запуску JetBrains backend.

macOS / Linux / WSL：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="ваш API Key"
unset ANTHROPIC_API_KEY
```

Windows PowerShell：

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "ваш API Key"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

Також можна використовувати проєкт з проігнорованим `.claude/settings.local.json`:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "ваш API Key"
  }
}
```

Для віддаленої розробки потрібно налаштувати та встановити плагін на віддаленому хості; користувачі WSL можуть встановити команду Claude як `wsl -d Ubuntu -- bash -lic "claude"`.

## 4. Перевірка

Запустіть `claude` з інтегрованого терміналу IDE або введіть `/ide` в зовнішньому терміналі. Після успішного з'єднання нехай Claude відповість `OK`, потім прочитайте тестовий файл і перевірте цей запит в історії використання Ace Data Cloud [використання](https://platform.acedata.cloud/console/usages).

Якщо плагін не запускається, спочатку запустіть `claude --version` в тому ж терміналі; 401 перевірте фактичні успадковані змінні середовища backend і старий `ANTHROPIC_API_KEY`.
