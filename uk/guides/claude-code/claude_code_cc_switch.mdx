## 1. Отримання API Key

Відкрийте [список додатків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступних додатків і скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Встановлення CC Switch

Завантажте з [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), macOS також може працювати:

```bash
brew install --cask cc-switch
```

## 3. Додавання Provider

Відкрийте CC Switch, виберіть **Claude Code → Add Provider → Custom**, заповніть:

| Поле        | Значення                       |
| ----------- | ------------------------------ |
| Name        | `Ace Data Cloud`              |
| Base URL    | `https://api.acedata.cloud`   |
| API Key     | Тільки що скопійований API Key |
| API Format  | `Anthropic Messages`          |

Якщо потрібно використовувати JSON редактор, налаштуйте так:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

CC Switch запише конфігурацію в налаштування користувача Claude Code. Не зберігайте реальний Key у командному репозиторії, а також не залишайте старий `ANTHROPIC_API_KEY`.

## 4. Увімкнення та перевірка

Після збереження увімкніть **Ace Data Cloud**, перезапустіть Claude Code. Відправте просте завдання лише для читання та перевірте виклик у [історії використання](https://platform.acedata.cloud/console/usages). Якщо після перемикання все ще використовується стара конфігурація, повністю вийдіть з Claude Code та CC Switch і спробуйте ще раз.
