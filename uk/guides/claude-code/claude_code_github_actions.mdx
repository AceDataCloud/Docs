## 1. Отримання API Key

Відкрийте [список додатків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступних додатків і скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

У цільовому GitHub репозиторії в **Settings → Secrets and variables → Actions** створіть новий Secret:

```text
ACEDATACLOUD_API_KEY
```

## 2. Встановлення GitHub App

Встановіть [Claude GitHub App](https://github.com/apps/claude) та надайте доступ до цільового репозиторію. Цей офіційний додаток запитує фіксований набір повних прав; зокрема, Claude Code Action фактично використовує права Contents, Issues та Pull requests, сторінка встановлення GitHub не може мати лише ці три пункти. Якщо організація вимагає мінімальних прав, будь ласка, створіть користувацький GitHub App відповідно до офіційної документації.

## 3. Додавання Workflow

Створіть `.github/workflows/claude.yml`:

```yaml
name: Claude Code

on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  claude:
    if: contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      actions: read
      id-token: write
    env:
      ANTHROPIC_BASE_URL: https://api.acedata.cloud
      ANTHROPIC_CUSTOM_HEADERS: "Authorization: Bearer ${{ secrets.ACEDATACLOUD_API_KEY }}"
    steps:
      - uses: actions/checkout@v6
        with:
          fetch-depth: 1
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: dummy-not-used
```

`claude-code-action` потребує ненульового введення `anthropic_api_key`; тут значення-заповнювач не буде використовуватися для автентифікації на платформі. `ANTHROPIC_CUSTOM_HEADERS` буде перекривати Bearer Header, необхідний для Ace Data Cloud, реальний Key надходить лише з GitHub Secret.

## 4. Перевірка

Після подання Workflow надішліть у коментарі Issue або PR:

```text
@claude Reply only OK
```

Успішно, Workflow дійсно завершиться, і відповідний Issue/PR оновить результат. Якщо Action повідомляє про відсутність облікових даних, підтвердіть, що `dummy-not-used` все ще існує; 401 перевірте Secret `ACEDATACLOUD_API_KEY`. Не друкуйте Secret у логах. Можна використовувати `claude_args` для налаштування `--max-turns` або вибору поточно доступної моделі, але підключення шаблону не фіксує модель.
