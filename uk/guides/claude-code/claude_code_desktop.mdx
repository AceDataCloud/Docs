Claude Code — це інструмент **Agentic Coding**, розроблений компанією Anthropic, який також відомий як один з найпотужніших програмних агентів у світі. Настільний додаток Claude Code пропонує незалежний графічний інтерфейс, підтримує функції перевірки Diff, паралельних сесій (ізоляція через Git Worktree), віддалених сесій тощо, без необхідності використовувати будь-яке IDE.

Цей документ в основному описує, як налаштувати та використовувати Claude Code настільний додаток через проксі-сервіс AceData Cloud.

> **Увага**: Настільний додаток Claude Code наразі знаходиться на стадії попереднього перегляду (Preview), підтримується лише на macOS та Windows.

## Процес подачі заявки

Щоб використовувати Claude Code, спочатку перейдіть на [сторінку сервісу Claude Messages](https://platform.acedata.cloud/documents/claude-messages) і натисніть кнопку «Acquire», щоб отримати необхідні облікові дані для запиту:

![](https://cdn.acedata.cloud/nyq0xz.png)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, щоб запросити реєстрацію та вхід. Після входу або реєстрації ви будете автоматично повернені на поточну сторінку.

При першій подачі заявки вам буде надано безкоштовний ліміт, щоб ви могли безкоштовно випробувати послуги Claude Code.

## Встановлення настільного додатку

### Системні вимоги

- macOS (Intel та Apple Silicon) або Windows (x64 / ARM64)
- Linux наразі не підтримує настільний додаток

### Завантаження та встановлення

Перейдіть на [офіційну сторінку завантаження Claude](https://claude.ai) та завантажте інсталяційний пакет для відповідної платформи:

- **macOS**: завантажте файл `.dmg`, перетягніть у папку Applications
- **Windows x64**: завантажте інсталяційний пакет `.exe`, дотримуйтесь інструкцій для встановлення
- **Windows ARM64**: завантажте версію ARM64 (увага: ARM64 не підтримує локальні сесії, потрібно використовувати віддалені сесії)

![Сторінка завантаження настільного додатку Claude](https://cdn.acedata.cloud/c3c8c57264.png)

Після завершення встановлення запустіть Claude з папки Applications (macOS) або з меню «Пуск» (Windows).

## Налаштування AceData Cloud API

Після запуску настільного додатку потрібно увійти в обліковий запис Anthropic. Ми можемо використовувати проксі API AceData Cloud, **не потребуючи офіційної підписки**, налаштувавши змінні середовища.

Настільний додаток читає змінні середовища з вашого Shell середовища, тому потрібно налаштувати їх у файлі конфігурації Shell.

### Налаштування змінних середовища

**Користувачі macOS**

Додайте наступний вміст до `~/.zshrc` (або `~/.bashrc`), замінивши `{token}` на ваш API токен:

```bash
# AceData Cloud - проксі налаштування Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Збережіть і виконайте:

```bash
source ~/.zshrc
```

**Користувачі Windows**

Додайте наступні системні змінні середовища через «Системні властивості → Додатково → Змінні середовища»:

| Ім'я змінної                | Значення                           |
| ---------------------- | ----------------------------- |
| `ANTHROPIC_AUTH_TOKEN` | `{token}` (замініть на ваш API токен)     |
| `ANTHROPIC_BASE_URL`   | `https://api.acedata.cloud` |

Або використовуйте PowerShell:

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**Також можна налаштувати через settings.json**

Редагуйте `~/.claude/settings.json` (якщо не існує, створіть):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Порада**: API токен можна переглянути в [консолі AceData Cloud](https://platform.acedata.cloud/console). Після налаштування потрібно **перезапустити настільний додаток**, щоб змінні середовища набрали чинності.

## Основне використання

### Відкриття проекту

1. Запустіть настільний додаток Claude
2. Натисніть на вкладку **Code** у верхній частині
3. Виберіть режим виконання **Local**
4. Натисніть **Select folder**, щоб вибрати каталог вашого проекту

### Початок діалогу

У текстовому полі введіть природну мову, описуючи ваші потреби:

- «Знайти TODO коментарі та виправити їх»
- «Додати тест до основної функції»
- «Пояснити архітектуру цього проекту»

Claude проаналізує вашу кодову базу, запропонує варіанти змін і відобразить зміни у вигляді Diff.

### Режим дозволів

Перемикайтеся між режимами за допомогою селектора режиму поруч із кнопкою надсилання:

| Режим       | Опис                 |
| -------- | ------------------ |
| **Ask**  | Запитувати підтвердження перед кожною зміною (рекомендується для новачків)  |
| **Code** | Автоматично приймати редагування файлів, але команди терміналу все ще потребують підтвердження |
| **Plan** | Спочатку розробити детальний план, чекати на затвердження, виконувати лише після підтвердження |

### Паралельні сесії

Натисніть **+ New session** на бічній панелі, щоб запустити кілька паралельних сесій. Для Git репозиторіїв кожна сесія отримає незалежну копію проекту через Worktree, що не заважає одна одній.

Worktree за замовчуванням зберігається в каталозі `~/.claude-worktrees/`.

### Перевірка Diff

Коли Claude змінює файли, відображається статистика змін (наприклад, `+12 -1`), натисніть, щоб відкрити переглядач Diff і перевірити зміни по файлах. Ви також можете натиснути на конкретні рядки коду, щоб додати коментарі, Claude буде коригуватися відповідно до ваших відгуків.

## Підключення зовнішніх інструментів

Перед початком сесії натисніть кнопку **⋯**, виберіть **Connectors**, щоб додати зовнішні інтеграції:

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- Більше...

Після підключення Claude може безпосередньо читати календар, надсилати повідомлення, створювати Issue тощо.

## Взаємозв'язок з CLI

Настільний додаток і CLI використовують один і той же базовий двигун, спільно використовують такі налаштування:

- Файли пам'яті проекту `CLAUDE.md` / `CLAUDE.local.md`
- Налаштування сервера MCP у `~/.claude.json` / `.mcp.json`
- Налаштування в `~/.claude/settings.json`
- Налаштування Hooks і Skills

Обидва можуть одночасно працювати в одному проекті, кожен підтримує незалежну історію сесій.

## Поширені запитання

### Що робити, якщо з'єднання не вдалося?

1. Перевірте, чи правильно створено файл `~/.claude/config.json`
2. Переконайтеся, що змінні середовища налаштовані правильно (перезапустіть настільний додаток, щоб вони набрали чинності)
3. Переконайтеся, що API токен дійсний (можна переглянути в [консолі](https://platform.acedata.cloud/console))
4. Якщо ви використовуєте `settings.json` для налаштування змінних середовища, переконайтеся, що формат файлу правильний

### Не можу знайти встановлені інструменти?

Якщо Claude не може знайти команди `npm`, `node` тощо:

1. Переконайтеся, що ці інструменти працюють у звичайному терміналі
2. Перевірте, чи правильно налаштовано PATH у вашому файлі конфігурації Shell (`~/.zshrc`, `~/.bashrc`)
3. Перезапустіть настільний додаток, щоб перезавантажити змінні середовища

### Як переглянути залишок ліміту?

Увійдіть до [консолі AceData Cloud](https://platform.acedata.cloud/console), щоб переглянути залишок ліміту та використання вашого облікового запису.
