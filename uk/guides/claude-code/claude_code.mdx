Claude Code підключається до Coding Plan через протокол Anthropic Messages, наразі доступні два входи для конфігурації: термінал та VS Code.

| Використання входу   | Посібник з конфігурації                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------ |
| Термінал / CLI     | [Конфігурація терміналу Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code            | [Конфігурація Claude Code для VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## Загальна конфігурація

- Базовий URL: `https://api.acedata.cloud`
- API Token: отримати з Coding Application та налаштувати через `ANTHROPIC_AUTH_TOKEN` у посібнику
- Model ID: вибрати з каталогу реальних моделей
- Після зміни конфігурації: перезапустити Claude Code; користувачам VS Code потрібно перезавантажити вікно

Не зберігайте одночасно старий `ANTHROPIC_API_KEY`, а також не записуйте реальний Token у спільні файли команди.

Повернутися до [Центру конфігурації Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
