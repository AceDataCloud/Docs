---
title: "Інструкція з налаштування Claude Code"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code — це програмний інтелект від Anthropic, який можна використовувати в терміналі, IDE, настільних додатках та інших середовищах. Через проксі AceData Cloud ви можете користуватися Claude Code за нижчою ціною.

> **Вперше підключаєтеся?** Рекомендуємо спочатку ознайомитися з [Claude Code 5-хвилинним швидким стартом](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) — від отримання облікових даних до успішного запуску першої команди, все за п’ять кроків.

Виберіть повну інструкцію для відповідної платформи залежно від сценарію використання:

| Платформа | Опис | Посилання на інструкцію |
|------|------|---------|
| **⚡ 5-хвилинний швидкий старт** | Від отримання облікових даних до першої команди `claude` за п’ять кроків | [5-хвилинна інструкція](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) |
| **Термінал (CLI)** | Основний досвід, запускайте `claude` у будь-якому терміналі | [Інструкція з налаштування терміналу](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code** | Рідне розширення з підтримкою вбудованого Diff, @-згадок, планування рев’ю | [Інструкція з налаштування VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | Редактор, сумісний з VS Code, повна підтримка розширення Claude Code | [Інструкція з налаштування Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **JetBrains IDE** | Підтримка IntelliJ IDEA, PyCharm, WebStorm та інших IDE | [Інструкція з налаштування JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Автоматизація коду рев’ю та обробки Issue за допомогою `@claude` | [Інструкція з налаштування GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |
| **Настільний додаток (Preview)** | Окремий графічний клієнт з підтримкою паралельних сесій та підключення зовнішніх інструментів | [Інструкція з налаштування настільного додатку](https://platform.acedata.cloud/documents/claude-code-desktop-integration) |

> **Підказка**: Для першого запиту перейдіть на [сторінку сервісу Claude Messages](https://platform.acedata.cloud/documents/claude-messages) та натисніть «Acquire» для отримання облікових даних з безкоштовним лімітом.
