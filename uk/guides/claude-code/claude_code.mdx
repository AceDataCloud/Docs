---
title: "Інструкція з налаштування Claude Code"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code — це програмний інтелект від Anthropic, який можна використовувати в терміналі, IDE та CI/CD конвеєрах. Через проксі AceData Cloud ви можете користуватися Claude Code за нижчою ціною.

Оберіть повну інструкцію налаштування для відповідної платформи залежно від сценарію використання:

| Платформа | Опис | Посилання на інструкцію |
|-----------|-------|------------------------|
| **VS Code** | Рідне розширення, підтримує вбудований Diff, @-згадки, планування рев’ю | [Інструкція з налаштування VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | Редактор, сумісний з VS Code, повна підтримка розширення Claude Code | [Інструкція з налаштування Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **Термінал (CLI)** | Основний досвід, запускайте `claude` у будь-якому терміналі | [Інструкція з налаштування терміналу](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **JetBrains IDE** | Підтримка IntelliJ IDEA, PyCharm, WebStorm та інших IDE | [Інструкція з налаштування JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Автоматизуйте код-рев’ю та обробку Issue за допомогою `@claude` | [Інструкція з налаштування GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Підказка**: Для першої заявки перейдіть на [Claude Messages сервісну сторінку](https://platform.acedata.cloud/documents/claude-messages) та натисніть «Acquire» для отримання облікових даних і безкоштовного ліміту.
