---
title: "Claude Code налаштування"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code — це програмний агент, розроблений компанією Anthropic, який можна використовувати в терміналах, IDE, настільних додатках та інших середовищах. Завдяки проксі AceData Cloud ви можете використовувати Claude Code за нижчою ціною.

Будь ласка, оберіть відповідний посібник з налаштування в залежності від вашого сценарію використання:

| Платформа           | Опис                                        | Посилання на посібник                                                                                     |
| ------------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **Термінал (CLI)**  | Основний досвід, запустіть `claude` в будь-якому терміналі, щоб почати                | [Посібник з налаштування терміналу](https://platform.acedata.cloud/documents/claude-code-terminal-integration)                    |
| **VS Code**        | Нативне розширення, підтримує вбудовані Diff, @-згадки, планування оглядів            | [Посібник з налаштування VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)               |
| **JetBrains IDE**  | Підтримує всі IDE, такі як IntelliJ IDEA, PyCharm, WebStorm | [Посібник з налаштування JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)          |
| **GitHub Actions** | Автоматизація огляду коду та обробки Issue за допомогою `@claude`             | [Посібник з налаштування GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Порада**: вперше подаючи заявку, ви можете перейти на [сторінку послуг Claude Messages](https://platform.acedata.cloud/documents/claude-messages) і натиснути «Acquire», щоб отримати облікові дані, що надають безкоштовний кредит.
