## 1. Отримання API Key

Відкрийте [список додатків Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдіть до доступних додатків і скопіюйте API Key.

![Отримання Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Встановлення Claude Code

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
```

Після встановлення перевірте:

```bash
claude --version
```

## 3. Налаштування Ace Data Cloud

Для глобального використання додайте наступні змінні до `~/.zshrc` або `~/.bashrc`：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="ваш API Key"
unset ANTHROPIC_API_KEY
```

Перезапустіть термінал або `source` відповідний конфігураційний файл.

Для дії лише в поточному проекті можна створити `.claude/settings.local.json`, що додано до `.gitignore`：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "ваш API Key"
  }
}
```

Виберіть один з двох способів. Не записуйте реальний Key у командний файл `.claude/settings.json`, що ділиться з командою; якщо в середовищі вже є `ANTHROPIC_API_KEY`, його слід дійсно скасувати, а не встановлювати як порожній рядок.

## 4. Запуск та перевірка

```bash
cd /path/to/your/project
claude
```

Після входу надішліть завдання лише для читання, наприклад, "прочитайте README.md і підсумуйте в одному реченні". Записи викликів та баланс можна переглянути в [історії використання](https://platform.acedata.cloud/console/usages) та [списку додатків](https://platform.acedata.cloud/console/applications).

Якщо повертається 401, перевірте, чи Key повний, чи старий `ANTHROPIC_API_KEY` скасовано, і повністю перезапустіть Claude Code. Модель не потрібно фіксувати в конфігурації підключення, її можна вибрати в Claude Code з доступних моделей.
