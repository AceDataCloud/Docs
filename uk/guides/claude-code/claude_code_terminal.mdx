Claude Code — це інструмент **Agentic Coding**, розроблений компанією Anthropic, також відомий як один з найпотужніших програмних агентів у світі. Термінал CLI є основним досвідом Claude Code, ви можете виконувати команду `claude` в будь-якому терміналі, спілкуючись з AI за допомогою природної мови для програмування.

Цей документ в основному описує, як через проксі-сервіс AceData Cloud встановити, налаштувати та використовувати Claude Code CLI в терміналі.

## Процес подачі заявки

Щоб використовувати Claude Code, спочатку перейдіть на [сторінку сервісу Claude Messages](https://platform.acedata.cloud/documents/claude-messages) і натисніть кнопку «Acquire», щоб отримати необхідні облікові дані для запиту:

![](https://cdn.acedata.cloud/nyq0xz.png)

Якщо ви ще не увійшли в систему або не зареєстровані, вас автоматично перенаправлять на сторінку входу, запрошуючи вас зареєструватися та увійти. Після входу або реєстрації ви автоматично повернетеся на цю сторінку.

При першій подачі заявки вам буде надано безкоштовний ліміт, щоб ви могли безкоштовно випробувати послуги Claude Code.

## Встановлення Claude Code

### Системні вимоги

- macOS, Linux або Windows (включаючи WSL)
- Node.js не є обов'язковим, рідний спосіб встановлення автоматично обробляє залежності

### Способи встановлення

Claude Code підтримує кілька способів встановлення:

**Спосіб перший: рідне встановлення (рекомендується)**

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows CMD:

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**Спосіб другий: Homebrew (macOS / Linux)**

```bash
brew install claude-code
```

**Спосіб третій: WinGet (Windows)**

```cmd
winget install Claude.ClaudeCode
```

Рідне встановлення автоматично оновлюється у фоновому режимі, завжди підтримуючи останню версію.

## Налаштування AceData Cloud API

Після завершення встановлення за замовчуванням вам буде запропоновано увійти в обліковий запис Anthropic. Ми можемо використовувати проксі API AceData Cloud, налаштувавши змінні середовища, **без необхідності офіційної підписки**.

### Налаштування змінних середовища

Є два способи налаштування змінних середовища, виберіть будь-який.

**Спосіб перший: налаштування в конфігураційному файлі Shell (рекомендується)**

Додайте наступний вміст до вашого конфігураційного файлу Shell (`~/.zshrc`, `~/.bashrc` або `~/.bash_profile`), замінивши `{token}` на API токен, отриманий у консолі AceData Cloud:

```bash
# AceData Cloud - Налаштування проксі Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Після внесення змін виконайте наступну команду, щоб активувати налаштування:

```bash
source ~/.zshrc  # або source ~/.bashrc
```

**Спосіб другий: налаштування в settings.json Claude Code**

Редагуйте `~/.claude/settings.json` (якщо не існує, створіть), додайте конфігурацію `env`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Перевага цього способу полягає в тому, що змінні середовища діють лише для Claude Code і не впливають на інші програми.

> **Порада**: API токен можна переглянути в [консолі AceData Cloud](https://platform.acedata.cloud/console). Значення `ANTHROPIC_AUTH_TOKEN` буде автоматично додано з префіксом `Bearer`, що надсилається на сервер.

## Початок використання

### Запуск інтерактивного режиму

Відкрийте термінал, перейдіть до каталогу вашого проекту, а потім виконайте:

```bash
cd /path/to/your/project
claude
```

Ви побачите вітальну сторінку Claude Code, просто введіть природну мову, щоб почати взаємодію.

### Загальні команди

| Команда               | Опис          | Приклад                   |
| ---------------- | ----------- | -------------------- |
| `claude`         | Запустити інтерактивний режим      | `claude`             |
| `claude "завдання"`    | Виконати одноразове завдання     | `claude "виправити помилку збірки"`    |
| `claude -p "запит"` | Виконати запит і вийти     | `claude -p "пояснити цю функцію"` |
| `claude -c`      | Продовжити останню розмову в поточному каталозі | `claude -c`          |
| `claude -r`      | Відновити попередню розмову     | `claude -r`          |
| `claude commit`  | Створити Git коміт   | `claude commit`      |

### Команди інтерактивного режиму

В інтерактивному режимі можна використовувати наступні вбудовані команди:

| Команда                | Функція        |
| ----------------- | --------- |
| `/help`           | Показати допомогу    |
| `/clear`          | Очистити історію розмови    |
| `/config`         | Відкрити панель налаштувань    |
| `/model`          | Переключити модель      |
| `/mcp`            | Керувати MCP сервісом |
| `/compact`        | Стиснути контекст     |
| `/memory`         | Керувати пам'яттю      |
| `/login`          | Переключити обліковий запис      |
| `exit` або `Ctrl+C` | Вийти        |

### Приклади діалогової взаємодії

```bash
# Аналіз проекту
> what does this project do?

# Виправлення помилок
> there's a bug where users can submit empty forms - fix it

# Написання тестів
> write unit tests for the calculator functions

# Рефакторинг коду
> refactor the authentication module to use async/await

# Git операції
> commit my changes with a descriptive message
> create a pr for this feature
```

## Розширене використання

### Конвеєри та сценарії

Claude Code дотримується філософії Unix, підтримуючи конвеєри та сценарії:

```bash
# Моніторинг журналів та автоматичне сповіщення
tail -f app.log | claude -p "якщо виявлено аномалію, сповістіть мене"

# Автоматичний переклад нових текстів
claude -p "якщо є нові рядки тексту, перекласти їх на французьку та створити PR"

# Код-рев'ю
git diff main | claude -p "переглянути ці зміни"
```

### Посилання на змінні середовища

Ось деякі з поширених змінних середовища, які підтримує Claude Code:

| Змінна                           | Опис                                    |
| ---------------------------- | ------------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`       | Значення для заголовка Authorization (автоматично додається префікс Bearer) |
| `ANTHROPIC_API_KEY`          | API ключ (надсилається як заголовок X-Api-Key)              |
| `ANTHROPIC_BASE_URL`         | Основний URL API                            |
| `ANTHROPIC_MODEL`            | Перекрити модель за замовчуванням                                |
| `ANTHROPIC_SMALL_FAST_MODEL` | Модель рівня Haiku (для фонових завдань)                     |
| `MAX_THINKING_TOKENS`        | Встановити бюджет токенів для роздумів (встановіть 0, щоб вимкнути режим роздумів)            |
| `DISABLE_COST_WARNINGS`      | Встановіть 1, щоб вимкнути попередження про витрати                           |

### Файл пам'яті проекту CLAUDE.md

У кореневому каталозі проекту створіть файл `CLAUDE.md`, щоб надати Claude Code специфічні інструкції та контекст для проекту. Claude автоматично завантажить цей файл під час запуску.

```markdown
# Опис проекту
Це повноцінний проект Django + Vue.js.

## Кодекс стилю
- Використовуйте Python 3.12
- Дотримуйтесь стилю коду PEP 8
- Усі API повинні мати написані юніт-тести
```

## Поширені запитання

### Що робити, якщо з'єднання не вдалося?
1. Перевірте, чи правильно створено файл `~/.claude/config.json`, вміст якого: `{"primaryApiKey": "self"}`
2. Підтвердіть, що змінні середовища правильно налаштовані:
   ```bash
   echo $ANTHROPIC_AUTH_TOKEN
   echo $ANTHROPIC_BASE_URL
   ```
3. Переконайтеся, що API токен дійсний (можна переглянути в [консолі](https://platform.acedata.cloud/console))
4. Спробуйте перезапустити термінал

### команда не знайдена: claude

Якщо після встановлення з'являється повідомлення `команда не знайдена`, спробуйте:

1. Закрити та знову відкрити термінал
2. Перевірте PATH: `echo $PATH`
3. Перевстановіть: `curl -fsSL https://claude.ai/install.sh | bash`

### Як переглянути залишок кредиту?

Увійдіть до [консолі AceData Cloud](https://platform.acedata.cloud/console), щоб переглянути залишок кредиту та використання вашого облікового запису.
