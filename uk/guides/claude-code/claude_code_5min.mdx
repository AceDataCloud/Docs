Цей документ має одну мету: дозволити вам **за 5 хвилин** за допомогою проксі AceData Cloud виконати першу команду Claude Code. Повний посібник дивіться у піддокументах для IDE ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); цей документ описує найшвидший шлях — «**термінал CLI** + **розширення VS Code**».

> **Чому варто використовувати проксі AceData Cloud для Claude Code**:
> - Пряме підключення в межах країни, без потреби у власному VPN
> - Ціна нижча за офіційну (оплата за токени платформи)
> - Один ключ одночасно підтримує Claude Messages API + протокол Claude Code Token

## Хвилина 1: Отримання облікових даних

Відкрийте [сторінку сервісу Claude Messages](https://platform.acedata.cloud/documents/claude-messages) та натисніть кнопку «**Acquire**»:

![](https://cdn.acedata.cloud/nyq0xz.png)

Платформа автоматично створить для вас Application і надасть безкоштовний ліміт. Запишіть **Base URL** та **API Token** зі сторінки деталей — вони знадобляться у наступних 5 кроках.

| Поле | Значення | Призначення |
|------|----------|-------------|
| `BASE_URL` | `https://api.acedata.cloud` | Сумісний вхід Claude Messages |
| `API_TOKEN` | `sk-...` (копіюється зі сторінки деталей) | Сумісний заголовок авторизації Anthropic |

## Хвилина 2: Встановлення Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (рідний PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Після встановлення відкрийте новий термінал і перевірте запуск:

```bash
claude --version
```

> Якщо бачите номер версії — все гаразд. Claude Code має вбудоване середовище Node.js, не залежить від версії Node на вашій машині.

## Хвилина 3: Налаштування змінних оточення для AceData Cloud

Не використовуйте офіційний процес `claude login`, а замініть налаштування через змінні оточення. Оберіть один із двох способів:

**Спосіб A: Тимчасово (лише для поточної сесії Shell)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-ваш-Token"
```

**Спосіб B: Постійно (рекомендовано)**

Додайте ці дві рядки до `~/.zshrc` або `~/.bashrc`, потім виконайте `source`.

> **Поширена помилка**: ім’я змінної — `ANTHROPIC_AUTH_TOKEN`, а не `ANTHROPIC_API_KEY`; неправильне ім’я призведе до повернення Claude Code до офіційної точки доступу з помилкою 401.

## Хвилина 4: Виконання першої команди

Перейдіть у будь-який Git репозиторій і виконайте:

```bash
claude
```

Якщо при першому запуску з’явиться запит на вхід, натисніть `Esc`, щоб пропустити. Потім введіть:

```
Перелічіть залежності поточного проекту та коротко поясніть призначення кожної.
```

Зазвичай Claude використовує `read_file` / `glob` / `grep` для перегляду репозиторію, а потім надає список. Якщо модель відповідає коректно і не виникає помилка 401, значить проксі працює.

## Хвилина 5: Підключення розширення VS Code

1. Відкрийте VS Code → панель розширень → пошукайте `Claude Code` та встановіть офіційне розширення Anthropic;
2. Перезапустіть VS Code або виконайте у командній панелі `Developer: Reload Window`, щоб розширення завантажило налаштування з `~/.claude/settings.json`, встановлені на хвилині 3;
3. Клацніть на ✦ Spark у верхньому правому куті редактора або на «✱ Claude Code» у статус-барі, щоб відкрити панель;
4. При першому запуску буде запит на вхід в офіційний акаунт — натисніть `Esc`, щоб пропустити. Розширення автоматично використає `ANTHROPIC_BASE_URL` та `ANTHROPIC_AUTH_TOKEN`, налаштовані на хвилині 3.

> **Порада**: Розширення VS Code і CLI використовують один і той самий файл `~/.claude/settings.json`, тому не потрібно налаштовувати окремо у VS Code. Якщо хочете перекрити налаштування на рівні проекту, створіть у корені репозиторію `.claude/settings.local.json` (цей файл ігнорується git).

Після успішного підключення можна перетягувати файли у панель для запитань, використовувати `@-mention` для посилань на файли та пропонувати зміни. Всі платежі проходять через AceData Cloud.

## Перевірка, що ви дійсно використовуєте проксі

Запустіть з режимом `--debug` і переконайтесь, що запити йдуть на AceData Cloud:

```bash
claude --debug -p "say hi" 2>&1 | grep -iE 'base.?url|api\.acedata|anthropic\.com' | head
```

Якщо бачите `https://api.acedata.cloud`, значить проксі працює; якщо з’являється `api.anthropic.com` або помилка 401 — поверніться до хвилини 3, перевірте ім’я змінної (має бути `ANTHROPIC_AUTH_TOKEN`, а не `ANTHROPIC_API_KEY`), а також переконайтесь, що у `~/.claude/.credentials.json` немає офіційного токена (видаліть цей файл, якщо є).

## 5 найпоширеніших запитань

**Q: Після виконання `claude login` і зміни змінних оточення на AceData проксі не працює. Чому?**  
A: `claude login` записує офіційний токен у `~/.claude/.credentials.json`, який має вищий пріоритет за змінні оточення. Видаліть цей файл і виконайте `source ~/.zshrc`.

**Q: Чи можна використовувати модель з назвою `--model claude-opus-4-7`?**  
A: Так. Проксі AceData Cloud пропускає поле model, підтримуючи всі публічні моделі Anthropic та розширені `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5`.

**Q: Чи можна налаштувати кілька профілів (особистий + робочий)?**  
A: Так. Claude Code підтримує кілька профілів у `~/.claude/settings.json`; або найпростіше — створіть два shell-функції `claude_personal` / `claude_work`, що експортують різні `ANTHROPIC_AUTH_TOKEN` і викликають `claude $@`.

**Q: Чи можна запускати у GitHub Actions?**  
A: Так. Деталі у [Claude Code GitHub Actions Integration](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**Q: Що робити, коли безкоштовний ліміт вичерпано?**  
A: Перейдіть у [Управління додатками](https://platform.acedata.cloud/applications) → оберіть свій Claude Application → поповніть баланс (оплата за фактичне споживання токенів) або перейдіть на підписку з балами.
