Цей документ має одну мету: допомогти вам **за 5 хвилин** за допомогою проксі AceData Cloud виконати першу команду Claude Code. Повний посібник дивіться у піддокументах для IDE ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); тут ми розглядаємо найшвидший шлях «**термінал CLI** + **розширення VS Code**».

> **Чому варто використовувати проксі AceData Cloud для Claude Code**:
> - Пряме підключення в межах країни, без потреби у власному VPN
> - Ціна нижча за офіційну (оплата за токени платформи)
> - Один ключ підтримує одночасно Claude Messages API + протокол Claude Code Token

## Хвилина 1: Отримання облікових даних

Відкрийте [сторінку сервісу Claude Messages](https://platform.acedata.cloud/documents/claude-messages) та натисніть кнопку «**Acquire**»:

![](https://cdn.acedata.cloud/nyq0xz.png)

Платформа автоматично створить для вас Application і подарує безкоштовний ліміт. Запишіть **Base URL** та **API Token** зі сторінки деталей — вони знадобляться у наступних 5 кроках.

| Поле | Значення | Призначення |
|------|----------|-------------|
| `BASE_URL` | `https://api.acedata.cloud` | Сумісний вхідний пункт Claude Messages |
| `API_TOKEN` | `sk-...` (копіюється зі сторінки деталей) | Сумісний заголовок авторизації Anthropic |

## Хвилина 2: Встановлення Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (рідний PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Після встановлення відкрийте новий термінал і перевірте:

```bash
claude --version
```

> Якщо бачите номер версії — все гаразд. Claude Code має вбудований Node.js runtime, не залежить від версії Node на вашій машині.

## Хвилина 3: Налаштування змінних середовища на AceData Cloud

Не використовуйте офіційну команду `claude login`, а замініть налаштування через змінні середовища. Оберіть один із двох способів:

**Спосіб A: Тимчасово (тільки для поточної сесії Shell)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-ваш-Token"
```

**Спосіб B: Постійно (рекомендовано)**

Додайте ці дві рядки у `~/.zshrc` або `~/.bashrc`, потім виконайте `source`.

> **Поширена помилка**: змінна має називатися `ANTHROPIC_AUTH_TOKEN`, а не `ANTHROPIC_API_KEY`; при неправильній назві Claude Code поверне 401 з офіційного кінцевого пункту.

## Хвилина 4: Виконання першої команди

Перейдіть у будь-який Git-репозиторій і виконайте:

```bash
claude
```

Якщо при першому запуску з’явиться запит на логін, натисніть `Esc`, щоб пропустити. Потім введіть:

```
Перелічіть залежності поточного проєкту та коротко поясніть призначення кожної.
```

Зазвичай Claude викликає інструменти `read_file` / `glob` / `grep` для перегляду репозиторію і надає список. У нижній панелі статусу з’явиться `connected to api.acedata.cloud` — це ключовий індикатор, що проксі працює.

## Хвилина 5: Підключення розширення VS Code

1. Відкрийте VS Code → панель розширень → знайдіть `Claude Code` і встановіть офіційне розширення Anthropic;
2. Натисніть **Cmd+Shift+P** → введіть `Claude Code: Set Custom API Endpoint`;
3. Введіть `https://api.acedata.cloud` та натисніть Enter;
4. Знову виконайте `Claude Code: Set API Token` і введіть ваш токен.

Після успішного налаштування у бічній панелі з’явиться панель Claude Code, де можна перетягувати файли для запитів або робити пропозиції змін через `@-mention`. Всі витрати оплачує AceData Cloud.

## Перевірка, що ви дійсно використовуєте проксі

У чаті Claude Code введіть:

```
Зроби запит до https://api.acedata.cloud/whoami і скажи, що повернулося
```

Якщо повертається інформація про ваш акаунт (`{user_id, plan, ...}`), значить запит пройшов через AceData Cloud. Якщо ж ви бачите 401 з офіційного домену, поверніться до хвилини 3 і перевірте назви змінних середовища.

## 5 найпоширеніших запитань

**Q: Я виконав `claude login`, а потім змінив змінні середовища на AceData — чому це не працює?**  
A: `claude login` записує офіційний токен у `~/.claude/.credentials.json`, який має вищий пріоритет за змінні середовища. Видаліть цей файл і виконайте `source ~/.zshrc`.

**Q: Чи можна використовувати модель з назвою `--model claude-opus-4-7`?**  
A: Так. Проксі AceData Cloud передає поле model напряму, підтримуючи всі публічні моделі Anthropic та наші розширення `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5`.

**Q: Чи можна налаштувати кілька профілів (особистий + робочий)?**  
A: Так. Claude Code підтримує кілька профілів у `~/.claude/settings.json`; або найпростіше — створіть два shell-функції `claude_personal` / `claude_work`, які експортують різні `ANTHROPIC_AUTH_TOKEN` і викликають `claude $@`.

**Q: Чи можна запускати у GitHub Actions?**  
A: Так. Деталі у [Claude Code GitHub Actions інтеграції](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**Q: Що робити, коли безкоштовний ліміт вичерпано?**  
A: Перейдіть у [управління додатками](https://platform.acedata.cloud/applications) → виберіть цей Claude Application → поповніть баланс (оплата за фактичне споживання токенів) або переключіться на підписку з балами.
