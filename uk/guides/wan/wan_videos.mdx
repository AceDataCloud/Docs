`POST https://api.acedata.cloud/wan/videos` одночасно підтримує наявні моделі Wan 2.6 та `wan3.0-video`. Wan 3 автоматично визначає режим тексту, першого й останнього кадру або референсних матеріалів на основі `media`.

## Генерація відео з тексту Wan 3

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "A paper boat drifting through a neon city at night",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 підтримує цілі числа від 2 до 30 секунд або інтелектуальну тривалість `-1`, роздільна здатність: `480P`, `720P`, `1080P`.

## Мультимедійні референси

```json
{
  "model": "wan3.0-video",
  "prompt": "Create a cinematic product reveal",
  "media": [
    {"type":"first_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"},
    {"type":"last_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460-a2a2c1afbf39.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` підтримує:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

Режими першого й останнього кадру та референсних матеріалів не можна змішувати. Для референсного відео остаточний розрахунок здійснюється за фактичною кількістю секунд вхідного відео плюс кількістю секунд успішно згенерованого вихідного відео; текстові, графічні та аудіовходи не збільшують кількість секунд відео.

## Офіційна стандартна ціна

| Роздільна здатність   |      Ціна |
| ----- | ------: |
| 480P  | $0.05/секунду |
| 720P  | $0.10/секунду |
| 1080P | $0.20/секунду |

## Сумісність із Wan 2.6

Наявні `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` та flash-варіанти й надалі використовують такі параметри, як `action`, `image_url`, `reference_video_urls`; шлях виклику не змінюється.

## Асинхронність і результати

Після встановлення `async: true` одразу повертається `task_id`, кінцевий стан отримується через `/wan/tasks`. Успішно згенеровані відео буде перенесено до AceDataCloud CDN, а в відповіді буде повернуто фактичні usage та cost.
