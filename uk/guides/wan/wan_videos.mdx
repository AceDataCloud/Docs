`POST https://api.acedata.cloud/wan/videos` одночасно підтримує існуючу модель Wan 2.6 та `wan3.0-video`. Wan 3 автоматично розпізнає текст, перші та останні кадри або референсні матеріали на основі `media`.

## Wan 3 текст у відео

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "Паперовий човен, що пливе через неонове місто вночі",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 підтримує цілі секунди від 2 до 30 або `-1` для інтелектуальної тривалості, роздільна здатність `480P`, `720P`, `1080P`.

## Мультимедійні референси

```json
{
  "model": "wan3.0-video",
  "prompt": "Створити кінематографічний продукт для презентації",
  "media": [
    {"type":"first_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"},
    {"type":"last_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` підтримує:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

Режими перших та останніх кадрів і референсних матеріалів не можуть використовуватися разом. Остаточна тривалість референсного відео розраховується на основі фактичної тривалості введеного відео плюс тривалість вихідного відео; текстові, зображення та аудіо не збільшують тривалість відео.

## Офіційні стандартні ціни

| Роздільна здатність |      Ціна |
| ----- | ------: |
| 480P  | $0.05/сек |
| 720P  | $0.10/сек |
| 1080P | $0.20/сек |

## Сумісність з Wan 2.6

Існуючі `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` та варіанти flash продовжують використовувати параметри `action`, `image_url`, `reference_video_urls` тощо, шлях виклику залишається незмінним.

## Асинхронність та результати

Після налаштування `async: true` ви відразу отримуєте `task_id`, через `/wan/tasks` отримуєте кінцевий стан. Успішні відео будуть збережені в AceDataCloud CDN, і в відповіді буде повернуто фактичне використання та вартість.
