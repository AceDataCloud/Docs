## Основне використання

Спочатку потрібно ознайомитися з основним способом використання, а саме введенням підказки `prompt`, дії `action`, посиланням на зображення першого кадру `image_url` та моделлю `model`, щоб отримати оброблений результат. Спочатку потрібно просто передати поле `action`, значення якого буде `text2video`, яке містить дві основні дії: генерація відео з тексту (`text2video`), генерація відео з зображення (`image2video`). Потім потрібно ввести модель `model`, наразі основні моделі: `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`, `wan2.6-t2v`, деталі наведені нижче:

<p><img src="https://cdn.acedata.cloud/03gqdz.png" width="500" className="m-auto" /></p>

Ми бачимо, що тут налаштовані заголовки запиту, включаючи:

- `accept`: формат відповіді, який ви хочете отримати, тут вказано `application/json`, тобто формат JSON.
- `authorization`: ключ для виклику API, після подачі заявки ви можете вибрати його зі списку.

Також налаштовано тіло запиту, яке включає:

- `model`: модель для генерації відео, основні моделі: `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`, `wan2.6-t2v`.
- `action`: дія для завдання генерації відео, основні три дії: генерація відео з тексту (`text2video`), генерація відео з зображення (`image2video`). Для генерації відео з тексту наразі підтримується лише модель `wan2.6-t2v`, для генерації відео з зображення підтримуються моделі `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`.
- `image_url`: при виборі дії генерації відео з зображення `image2video` необхідно завантажити посилання на зображення першого кадру, наразі підтримуються моделі `wan2.6-i2v`, `wan2.6-i2v-flash`.
- `reference_video_urls`: необов'язковий параметр для генерації відео з зображення, вказує посилання на відео для генерації, наразі підтримується модель `wan2.6-r2v`.
- `size`: вказує роздільну здатність генерованого відео, формат ширина*висота. Значення за замовчуванням та доступні значення залежать від параметра моделі, детальні правила можна знайти в [документації](https://modelstudio.console.alibabacloud.com/ap-southeast-1/?tab=api#/api/?type=model&url=2865250).
- `duration`: тривалість генерації відео, підтримуються 5, 10, 15 секунд.
- `shot_type`: необов'язковий параметр, вказує тип кадру для генерованого відео, тобто чи складається відео з одного безперервного кадру чи з кількох змінних кадрів. Умови дії: діє лише коли "prompt_extend": true. Пріоритет параметрів: shot_type > prompt. Наприклад, якщо shot_type встановлено на "single", навіть якщо prompt містить "згенерувати відео з кількома кадрами", модель все одно виведе відео з одним кадром, детальні правила можна знайти в [документації](https://modelstudio.console.alibabacloud.com/ap-southeast-1/?tab=api#/api/?type=model&url=2865250).
- `negative_prompt`: необов'язковий, зворотний підказка, що описує те, що не бажано бачити у відео, може обмежити вміст відео. Підтримує китайську та англійську мови, довжина не перевищує 500 символів, частина, що перевищує, буде автоматично обрізана. Приклад значень: низька роздільна здатність, помилка, найгірша якість, низька якість, дефекти, зайві пальці, неправильні пропорції тощо.
- `resolution`: вказує рівень роздільної здатності генерованого відео, використовується для налаштування чіткості відео (загальна кількість пікселів). Модель автоматично масштабує до близької загальної кількості пікселів відповідно до вибраного рівня роздільної здатності, співвідношення сторін відео намагатиметься зберегти таке ж, як у вхідного зображення img_url, більше пояснень дивіться в [документації](https://modelstudio.console.alibabacloud.com/ap-southeast-1/?tab=api#/api/?type=model&url=2867393).
- `audio_url`: URL аудіофайлу, модель використовуватиме це аудіо для генерації відео. Спосіб використання дивіться в [документації](https://modelstudio.console.alibabacloud.com/ap-southeast-1/?tab=api#/api/?type=model&url=2867393).
- `audio`: чи генерувати відео з аудіо. Пріоритет параметрів: audio > audio_url. Коли audio=false, навіть якщо передано audio_url, вихід все ще буде беззвучним відео, і оплата буде розрахована як за беззвучне відео, значення за замовчуванням - true.
- `prompt_extend`: чи активувати розумне переписування підказки. При активації використовується велика модель для розумного переписування введеної підказки. Для коротших підказок ефект генерації значно покращується, але це збільшує час виконання, значення за замовчуванням - true.
- `prompt`: підказка.
- `callback_url`: URL для отримання результатів зворотного виклику.
- `async`: необов'язковий, якщо встановити `true`, інтерфейс негайно повертає `task_id`, не потрібно надавати `callback_url`, потім через відповідний інтерфейс запиту завдань можна опитувати результати.

Після вибору ви також можете побачити згенерований відповідний код, як показано на малюнку:

<p><img src="https://cdn.acedata.cloud/03gqdz.png" width="500" className="m-auto" /></p>

Натисніть кнопку «Спробувати», щоб провести тестування, як показано на малюнку, ми отримали наступний результат:

```json
{
  "success": true,
  "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4",
  "state": "completed",
  "task_id": "a4bca552-d964-46a1-8ff7-fd922f916582"
}
```

У повернутому результаті є кілька полів, описаних нижче:

- `success`: статус завдання генерації відео.
- `task_id`: ID завдання генерації відео.
- `video_url`: посилання на відео, згенероване в рамках завдання.
- `state`: статус завдання генерації відео.

Ми отримали задовільну інформацію про відео, нам потрібно лише отримати згенероване відео Tongyi Wanxiang за адресою посилання `video_url` у результаті.

Крім того, якщо ви хочете згенерувати відповідний код інтеграції, ви можете просто скопіювати його, наприклад, код CURL виглядає так:
```shell
curl -X POST 'https://api.acedata.cloud/wan/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "wan2.6-t2v",
  "prompt": "Астронавти переміщуються з космосу до вулкана",
  "duration": 5
}'
```

## Функція генерації відео з зображення

Якщо ви хочете створити відео на основі зображення або відео, ви можете встановити параметр `action` на `image2video` і ввести посилання на зображення або відео, яке потрібно використовувати як посилання. Далі ми повинні заповнити наступні підказки для налаштування генерації відео, щоб вказати такі дані:

- `model`: модель для генерації відео, основні моделі: `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`, `wan2.6-t2v`.
- `image_url`: коли вибирається дія генерації відео з зображення `image2video`, потрібно завантажити посилання на перше зображення. Наразі підтримуються лише моделі `wan2.6-i2v`, `wan2.6-i2v-flash`.
- `reference_video_urls`: під час генерації відео з зображення є необов'язковим, вказує посилання на відео для генерації, наразі підтримується лише модель `wan2.6-r2v`.
- `prompt`: підказка.

Приклад заповнення виглядає так:

<p><img src="https://cdn.acedata.cloud/94l0kk.png" width="500" className="m-auto" /></p>

Після заповнення автоматично згенерувався код, як показано нижче:

<p><img src="https://cdn.acedata.cloud/b5q8tt.png" width="500" className="m-auto" /></p>

Відповідний код на Python:

```python
import requests

url = "https://api.acedata.cloud/wan/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "image2video",
    "model": "wan2.6-i2v",
    "prompt": "Астронавти переміщуються з космосу до вулкана",
    "duration": 5,
    "image_url": "https://cdn.acedata.cloud/r9vsv9.png",
    "callback_url": "https://www.baidu.com/"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Клікнувши на виконання, ви можете побачити результат, як показано нижче:

```json
{
  "success": true,
  "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4",
  "state": "completed",
  "task_id": "a4bca552-d964-46a1-8ff7-fd922f916582"
}
```

Можна побачити, що результати збігаються з попереднім текстом, що реалізує функцію розширення відео.

## Асинхронний зворотний виклик

Оскільки час генерації API Wan Videos є відносно тривалим, приблизно 1-2 хвилини, якщо API довго не відповідає, HTTP запит буде підтримувати з'єднання, що призведе до додаткових витрат системних ресурсів, тому цей API також підтримує асинхронний зворотний виклик.

Загальний процес: коли клієнт ініціює запит, додатково вказується поле `callback_url`, після ініціації API запит поверне результат, що містить інформацію про поле `task_id`, яке представляє поточний ID завдання. Коли завдання завершено, результат генерації відео буде надіслано на вказане клієнтом `callback_url` у форматі POST JSON, в якому також буде включено поле `task_id`, таким чином результати завдання можна буде пов'язати за ID.

Давайте розглянемо приклад, щоб зрозуміти, як це працює.

По-перше, Webhook зворотний виклик - це служба, яка може приймати HTTP запити, розробники повинні замінити на URL свого HTTP сервера. Для зручності демонстрації використовується публічний веб-сайт Webhook https://webhook.site/, відкривши цей сайт, ви отримаєте Webhook URL, як показано на малюнку:

Далі ми можемо встановити поле `callback_url` на вказаний Webhook URL, одночасно заповнивши відповідні параметри, конкретний зміст, як показано на малюнку:

## Обробка помилок

При виклику API, якщо виникає помилка, API поверне відповідний код помилки та інформацію. Наприклад:

- `400 token_mismatched`: Неправильний запит, можливо, через відсутні або недійсні параметри.
- `400 api_not_implemented`: Неправильний запит, можливо, через відсутні або недійсні параметри.
- `401 invalid_token`: Неавторизовано, недійсний або відсутній токен авторизації.
- `429 too_many_requests`: Занадто багато запитів, ви перевищили ліміт запитів.
- `500 api_error`: Внутрішня помилка сервера, щось пішло не так на сервері.

### Приклад відповіді з помилкою

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Wan 3.0 Універсальна генерація відео

`wan3.0-video` підтримує генерацію відео з тексту, перших/останніх кадрів, а також зображень, відео, аудіо, файлів або веб-сторінок в одній моделі. Передайте матеріали через масив `media`:

```json
{
  "model": "wan3.0-video",
  "prompt": "Створіть рекламний ролик у кіно стилі з продуктом на зображенні 1",
  "media": [{"type":"reference_image","url":"https://cdn.example.org/product.png"}],
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5,
  "audio": true,
  "watermark": false,
  "async": true
}
```

`duration` підтримує цілі числа від 2 до 30 секунд або `-1`, щоб дозволити моделі вибрати тривалість. Посилання на матеріали та режим перших/останніх кадрів не можуть використовуватися разом. Після генерації продовжуйте перевіряти через `/wan/tasks`.
