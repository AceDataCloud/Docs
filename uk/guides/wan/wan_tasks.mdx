title: "Wan завдання запиту API"
description: "Wan API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/wan/tasks` використовується для запиту, масового запиту або видалення Wan відео завдань. Запит завдань не повторно стягує витрати на генерацію.

## Запит одного завдання

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Завершене завдання `response.data.video_url` є постійною CDN адресою; `response.usage` містить роздільну здатність, секунди вхідного/вихідного відео, частоту кадрів та співвідношення; `response.cost` є розрахунком витрат на генерацію завдання.

## Масовий запит

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Повертає `{ "items": [...], "count": 2 }`. Під час виконання завдання може ще не бути `finished_at` та остаточного `response`.

## Видалення запису завдання

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

Видалення впливає лише на історію завдань, не видаляючи вже згенероване CDN відео.
