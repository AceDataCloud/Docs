**Перед підтвердженням та погодженням з цими умовами обслуговування (далі - "Угода") користувач повинен уважно прочитати весь текст, особливо частини, виділені жирним шрифтом, включаючи обмеження або відмови від відповідальності користувача.**

Ace Data Cloud надає API та послуги проксі лише користувачам, які завершили реєстрацію та подали запит на активацію послуг (далі - "послуги"). Натискаючи кнопку "Заявка" та погоджуючись з цією угодою, ви підтверджуєте, що прочитали, зрозуміли та прийняли всі умови, а також погоджуєтеся дотримуватися їх юридичних зобов'язань. Якщо ви не погоджуєтеся з цією угодою або не можете повністю зрозуміти її зміст, будь ласка, не продовжуйте реєстрацію або подачу заявки на послуги, що надаються Ace Data Cloud.

## Обсяг послуг

Ця угода регулює ваше використання API та послуг проксі Ace Data Cloud, які є **додатковими продуктами Germey Technology, LLC**.

Ця угода є доповненням до "Угоди про обслуговування користувачів" і є її невід'ємною частиною. У разі конфлікту між цією угодою та "Угодою про обслуговування користувачів" перевага надається цій угоді. Ace Data Cloud може постійно оновлювати або публікувати правила, політики, заяви та рекомендації, пов'язані з послугами, які стануть частиною цієї угоди з моменту публікації.

**Якщо ви не відповідаєте умовам цієї угоди, Ace Data Cloud залишає за собою право в будь-який час призупинити або припинити ваше використання послуг. Крім того, Ace Data Cloud може за необхідності коригувати обсяг послуг і робити оголошення без будь-якої відповідальності.**

## Формат та зміст послуг

Послуги, що надаються Ace Data Cloud, включають API послуги, HTTP проксі послуги та послуги з надання даних у великих обсягах. Після набуття чинності цією угодою користувач повинен попередньо сплатити відповідну вартість послуг. Після отримання попередньої оплати Ace Data Cloud активує послуги.

Користувач повинен уповноважити Ace Data Cloud взаємодіяти з третіми сторонами для перевірки джерел інформації про послуги. Користувач погоджується, що Ace Data Cloud може вибирати конкретні джерела інформації для надання послуг перевірки на основі якості, технічних можливостей та інших факторів. Якщо джерело інформації недоступне, Ace Data Cloud надасть альтернативне джерело.

## Активація послуг, оплата та зняття коштів

Послуги API вимагають попередньої оплати. Користувач може вибрати та попередньо сплатити відповідний пакет продуктів відповідно до своїх потреб. Ціна пакета може коливатися в залежності від ринкових умов. Користувач повинен забезпечити достатній баланс на рахунку та залишок викликів, щоб уникнути перерв у наданні послуг.

**Користувач повинен гарантувати, що джерело коштів для оплати є законним. У разі виявлення незаконної діяльності Ace Data Cloud залишає за собою право припинити співпрацю та вжити юридичних заходів.**

## Політика повернення, повернення товарів та скасування

**Політика повернення**
Всі віртуальні продукти та послуги, надані Ace Data Cloud, не підлягають поверненню після продажу за нормальних умов. Лише у випадку, якщо технічні збої або інші непереборні обставини призводять до неможливості подальшого надання послуг, користувач може подати заявку на повернення. Конкретна сума повернення та умови будуть визначені Ace Data Cloud відповідно до фактичних обставин.

**Процес подачі заявки на повернення**
Для подачі заявки на повернення користувач повинен звернутися через канали підтримки клієнтів на офіційному веб-сайті та надати детальні докази перерви або збоїв у наданні послуг. Після перевірки заявки, що відповідає умовам, буде оброблено протягом розумного терміну.

**Політика скасування**
Щодо підписних послуг, користувач може в будь-який час скасувати послугу. Повернення попередньо сплачених коштів розглядається лише у випадку, якщо послуга не може бути надана через технічні проблеми або інші непереборні обставини. В інших випадках повернення коштів за скасування послуг не проводиться.

**Політика доставки та виконання**
Оскільки всі продукти та послуги доставляються в цифровому форматі, політика доставки або виконання не застосовується до фізичних товарів.

**Політика повернення товарів**
У зв'язку з особливим характером віртуальних продуктів, повернення проданих товарів не приймається. Якщо у вас є будь-які запитання або проблеми з продуктом або послугою, будь ласка, зв'яжіться з підтримкою клієнтів, і ми надамо відповідні рішення відповідно до конкретних обставин.

Ця політика повернення, повернення товарів та скасування буде оновлюватися відповідно до чинного законодавства та потреб компанії. Продовжуючи користуватися послугами, ви погоджуєтеся дотримуватися умов чинної політики.

## Права та обов'язки користувача

**Користувач несе відповідальність за всі юридичні питання, що виникають у зв'язку з використанням послуг.** Користувач повинен забезпечити, щоб його використання послуг відповідало "Закону про захист персональних даних" та отримати відповідні дозволи на обробку персональної інформації. Користувач повинен надати підтвердження дозволу та співпрацювати з процесом перевірки Ace Data Cloud.

**Користувач не має права повторно розподіляти, продавати або передавати права на послуги.** Він повинен використовувати послуги лише для уповноважених цілей і в межах узгодженого обсягу.

## Права та обов'язки Ace Data Cloud

**Ace Data Cloud має право приймати або відхиляти запити користувачів відповідно до фактичних обставин або торгових записів.** Ace Data Cloud може стягувати з користувачів плату за послуги та має право призупинити надання послуг у разі прострочення платежу.

Ace Data Cloud надасть користувачам необхідну технічну підтримку, щоб забезпечити безпеку та нормальну роботу системи. Однак Ace Data Cloud не несе відповідальності за перерви в наданні послуг, викликані зовнішніми факторами.

**Якщо інше не передбачено законом або цією угодою, Ace Data Cloud зобов'язується зберігати конфіденційність даних користувачів та торгових записів.**

## Відповідальність за порушення та відмова від відповідальності

**Зміни в законодавстві, нормативних актах та політиках можуть вплинути на виконання цієї угоди.** У такому випадку сторони повинні домовитися про коригування. Якщо досягти угоди не вдається, будь-яка зі сторін може припинити цю угоду без настання відповідальності за порушення.

**Користувач повинен підтримувати стабільність і безпеку своєї платформи та системи.** Ace Data Cloud не несе відповідальності за будь-які збитки, викликані вразливостями або неналежними заходами безпеки.

## Додаткові умови

**Ця угода набирає чинності, коли користувач реєструється в Ace Data Cloud і погоджується з цією угодою.** Якщо ця угода суперечить паперовому контракту, укладеному між користувачем та Ace Data Cloud, перевага надається паперовому контракту. Для питань, не охоплених паперовим контрактом, застосовуються онлайн-правила, з якими користувач погоджується під час реєстрації та використання послуг Ace Data Cloud.
