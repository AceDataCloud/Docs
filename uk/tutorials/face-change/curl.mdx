## Вступ

Face Change — це AI сервіс обробки зображень, який надає Ace Data Cloud, спеціалізований на обробці облич. За допомогою уніфікованого API Ace Data Cloud ви можете швидко викликати Face Change через cURL для заміни облич, покращення обличчя, зміни віку, зміни статі, аніме-ефекту, аналізу облич тощо.

## Передумови

- Мати акаунт на [Ace Data Cloud](https://platform.acedata.cloud) та отримати API Token
- Встановлене середовище з підтримкою cURL

## Базове використання

Основна кінцева точка для виклику Face Change API:

```
POST https://api.acedata.cloud/face/swap
```

Повний приклад команди cURL:

```bash
curl -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}'
```

Будь ласка, замініть `YOUR_API_TOKEN` на фактичний токен, отриманий на платформі Ace Data Cloud.

## Приклад відповіді

Після успішного виклику повертається JSON-дані, наприклад:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обробка відповіді за допомогою jq

Рекомендується використовувати інструмент jq для форматованого виводу:

```bash
curl -s -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}' | jq .
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис                              |
|-----------|----------------------------------|
| 401       | Помилка автентифікації, перевірте API Token |
| 403       | Недостатньо коштів або відсутній доступ |
| 429       | Перевищено ліміт запитів         |
| 500       | Внутрішня помилка сервера        |

## Наступні кроки

- Перейдіть до [Ace Data Cloud Консолі](https://platform.acedata.cloud) для отримання API Token
- Ознайомтеся з [API документацією](https://docs.acedata.cloud/zh-CN/api-reference) для повного опису параметрів
- Перегляньте [Плани тарифікації](https://platform.acedata.cloud/services) для ознайомлення з вартістю послуг
