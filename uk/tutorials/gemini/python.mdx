## Вступ

Gemini — це AI чат-сервіс від Ace Data Cloud, заснований на великій мовній моделі серії Google Gemini. Через уніфікований API Ace Data Cloud ви можете швидко інтегрувати Gemini за допомогою Python, реалізуючи багатокрокові діалоги, системні підказки, потоковий вивід, режим виводу JSON та інші функції.

## Попередні умови

- Наявність акаунту [Ace Data Cloud](https://platform.acedata.cloud) та отримання API Token
- Середовище Python 3.7 і вище
- Встановлена бібліотека requests: `pip install requests`

## Базове використання

Основна кінцева точка для виклику Gemini API:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

У цьому прикладі використовується модель `gemini-2.5-flash`.
Доступні моделі: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Повний приклад коду на Python:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gemini-2.5-flash",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Будь ласка, замініть `YOUR_API_TOKEN` на фактичний токен, отриманий на платформі Ace Data Cloud.

## Обробка відповіді

Після успішного виклику API повертає дані у форматі JSON. Рекомендується перевіряти HTTP статус-код:

```python
if response.status_code == 200:
    result = response.json()
    print("Виклик успішний:", result)
else:
    print(f"Виклик не вдався, статус-код: {response.status_code}")
    print(response.text)
```

## Розширене використання

Для чат-API підтримується потоковий вивід для отримання відповіді в реальному часі:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Обробка помилок

Поширені коди помилок:

| Код статусу | Опис |
|-------------|------|
| 401 | Помилка автентифікації, перевірте API Token |
| 403 | Недостатньо коштів або відсутній доступ |
| 429 | Перевищено ліміт частоти запитів |
| 500 | Внутрішня помилка сервера |
