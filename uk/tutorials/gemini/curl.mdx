## Вступ

Gemini — це AI чат-сервіс від Ace Data Cloud, великий мовний модельний ряд Google Gemini. Через уніфікований API Ace Data Cloud ви можете швидко викликати Gemini за допомогою cURL, реалізуючи багатокрокові діалоги, системні підказки, потоковий вивід, режим JSON-виводу та інші функції.

## Передумови

- Мати обліковий запис [Ace Data Cloud](https://platform.acedata.cloud) та отримати API Token
- Встановлене середовище терміналу з cURL

## Базове використання

Головна кінцева точка виклику Gemini API:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

У цьому прикладі використовується модель `gemini-2.5-flash`.  
Доступні моделі: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Повний приклад команди cURL:

```bash
curl -X POST https://api.acedata.cloud/gemini/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gemini-2.5-flash", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Будь ласка, замініть `YOUR_API_TOKEN` на фактичний токен, отриманий на платформі Ace Data Cloud.

## Приклад відповіді

Після успішного виклику повертається JSON-дані, наприклад:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обробка відповіді за допомогою jq

Рекомендується використовувати інструмент jq для форматування виводу:

```bash
curl -s -X POST https://api.acedata.cloud/gemini/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gemini-2.5-flash", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис                         |
|-----------|------------------------------|
| 401       | Аутентифікація не вдалася, перевірте API Token |
| 403       | Недостатньо коштів або відсутній доступ |
| 429       | Перевищено ліміт частоти запитів |
| 500       | Внутрішня помилка сервера    |

## Наступні кроки

- Перейдіть до [Ace Data Cloud Консолі](https://platform.acedata.cloud) для отримання API Token
- Ознайомтеся з [API документацією](https://docs.acedata.cloud/zh-CN/api-reference) для повного опису параметрів
- Перегляньте [Плани тарифікації](https://platform.acedata.cloud/services) для ознайомлення з вартістю
