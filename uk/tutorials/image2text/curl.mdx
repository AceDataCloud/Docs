## Вступ

Image2Text — це сервіс розпізнавання капч, що надається Ace Data Cloud, для розпізнавання зображень капч. Через уніфікований API Ace Data Cloud ви можете швидко викликати Image2Text за допомогою cURL для розпізнавання капч, підтримки введення у форматі Base64, URL тощо.

## Передумови

- Мати обліковий запис [Ace Data Cloud](https://platform.acedata.cloud) та отримати API Token
- Встановлене середовище терміналу з cURL

## Базове використання

Основна кінцева точка для виклику Image2Text API:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Повний приклад команди cURL:

```bash
curl -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}'
```

Будь ласка, замініть `YOUR_API_TOKEN` на фактичний токен, отриманий на платформі Ace Data Cloud.

## Приклад відповіді

Після успішного виклику повертається дані у форматі JSON, наприклад:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Використання jq для обробки відповіді

Рекомендується використовувати інструмент jq для форматування виводу:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}' | jq .
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис                          |
|-----------|------------------------------|
| 401       | Помилка автентифікації, перевірте API Token |
| 403       | Недостатньо коштів або відсутній доступ |
| 429       | Перевищено ліміт частоти запитів |
| 500       | Внутрішня помилка сервера    |

## Наступні кроки

- Перейдіть до [Ace Data Cloud Консолі](https://platform.acedata.cloud) для отримання API Token
- Ознайомтесь з [API документацією](https://docs.acedata.cloud/zh-CN/api-reference) для повного опису параметрів
- Перегляньте [Плани ціноутворення](https://platform.acedata.cloud/services) для ознайомлення з вартістю
