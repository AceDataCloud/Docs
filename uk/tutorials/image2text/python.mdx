## Вступ

Image2Text — це сервіс розпізнавання капч, що надається Ace Data Cloud. За допомогою уніфікованого API Ace Data Cloud ви можете швидко інтегрувати Image2Text у Python для розпізнавання капч, підтримки введення у форматі Base64, URL та інших функцій.

## Попередні умови

- Наявність облікового запису [Ace Data Cloud](https://platform.acedata.cloud) та отримання API Token
- Середовище Python 3.7 або новіше
- Встановлена бібліотека requests: `pip install requests`

## Базове використання

Основна кінцева точка API Image2Text:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Повний приклад коду на Python:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/image2text"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Будь ласка, замініть `YOUR_API_TOKEN` на ваш фактичний токен, отриманий на платформі Ace Data Cloud.

## Обробка відповіді

Після успішного виклику API повертає дані у форматі JSON. Рекомендується перевіряти HTTP статус-код:

```python
if response.status_code == 200:
    result = response.json()
    print("Виклик успішний:", result)
else:
    print(f"Виклик не вдався, статус код: {response.status_code}")
    print(response.text)
```

## Розширене використання

Для API, що підтримують асинхронні завдання, можна отримувати результати через callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Результати будуть надіслані на ваш сервер через callback URL
```

## Обробка помилок

Поширені коди помилок:

| Код статусу | Опис                              |
|-------------|----------------------------------|
| 401         | Аутентифікація не пройдена, перевірте API Token |
| 403         | Недостатньо коштів або відсутній доступ |
| 429         | Перевищено ліміт частоти запитів |
| 500         | Внутрішня помилка сервера        |
