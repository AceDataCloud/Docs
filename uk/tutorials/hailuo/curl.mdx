## Вступ

Hailuo — це AI відеосервіс від Ace Data Cloud, модель генерації відео MiniMax Hailuo. За допомогою уніфікованого API Ace Data Cloud ви можете швидко викликати Hailuo через cURL для створення відео на основі тексту, зображень, режисерського режиму та інших функцій.

## Передумови

- Мати обліковий запис [Ace Data Cloud](https://platform.acedata.cloud) та отримати API Token
- Встановлене середовище терміналу з cURL

## Базове використання

Основна кінцева точка виклику Hailuo API:

```
POST https://api.acedata.cloud/hailuo/videos
```

У цьому прикладі використовується модель `minimax-t2v`.
Доступні моделі: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Повний приклад команди cURL:

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}'
```

Будь ласка, замініть `YOUR_API_TOKEN` на фактичний токен, отриманий на платформі Ace Data Cloud.

## Приклад відповіді

Після успішного виклику повертається дані у форматі JSON, наприклад:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обробка відповіді за допомогою jq

Рекомендується використовувати інструмент jq для форматування виводу:

```bash
curl -s -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}' | jq .
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис                         |
|-----------|------------------------------|
| 401       | Помилка автентифікації, перевірте API Token |
| 403       | Недостатньо коштів або відсутній доступ |
| 429       | Перевищено ліміт частоти запитів |
| 500       | Внутрішня помилка сервера    |

## Наступні кроки

- Перейдіть до [Ace Data Cloud консолі](https://platform.acedata.cloud) для отримання API Token
- Ознайомтеся з [API документацією](https://docs.acedata.cloud/zh-CN/api-reference) для повного опису параметрів
- Перегляньте [плани ціноутворення](https://platform.acedata.cloud/services) для ознайомлення з вартістю
