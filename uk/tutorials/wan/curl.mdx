## Вступ

Wan — це AI відеосервіс від Ace Data Cloud, модель генерації відео від Alibaba Wanxiang. Через уніфікований API Ace Data Cloud ви можете швидко викликати Wan за допомогою cURL для створення відео з тексту, відео з зображень, відео за зразком, а також підтримки різних роздільних здатностей.

## Передумови

- Наявність облікового запису [Ace Data Cloud](https://platform.acedata.cloud) та отримання API Token
- Встановлене середовище терміналу з cURL

## Базове використання

Основна кінцева точка для виклику Wan API:

```
POST https://api.acedata.cloud/wan/videos
```

У цьому прикладі використовується модель `wan2.6-t2v`.
Доступні моделі: `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`.

Повний приклад команди cURL:

```bash
curl -X POST https://api.acedata.cloud/wan/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "model": "wan2.6-t2v", "prompt": "Astronauts shuttle from space to volcano", "resolution": "720P"}'
```

Замість `YOUR_API_TOKEN` вставте фактичний токен, отриманий на платформі Ace Data Cloud.

## Приклад відповіді

Після успішного виклику повертається JSON-дані, наприклад:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обробка відповіді за допомогою jq

Рекомендується використовувати інструмент jq для форматованого виводу:

```bash
curl -s -X POST https://api.acedata.cloud/wan/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "model": "wan2.6-t2v", "prompt": "Astronauts shuttle from space to volcano", "resolution": "720P"}' | jq .
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис |
|-----------|-------|
| 401 | Помилка автентифікації, перевірте API Token |
| 403 | Недостатньо коштів або відсутній доступ |
| 429 | Перевищено ліміт запитів |
| 500 | Внутрішня помилка сервера |

## Наступні кроки

- Перейдіть до [Ace Data Cloud Консолі](https://platform.acedata.cloud) для отримання API Token
- Ознайомтеся з [API документацією](https://docs.acedata.cloud/zh-CN/api-reference) для повного опису параметрів
- Перегляньте [Плани тарифікації](https://platform.acedata.cloud/services) для інформації про вартість
