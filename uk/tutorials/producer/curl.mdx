## Вступ

Producer — це AI аудіосервіс від Ace Data Cloud, FUZZ Producer AI для генерації музики. Через уніфікований API Ace Data Cloud ви можете швидко викликати Producer за допомогою cURL для створення музики з тексту, налаштування текстів пісень, продовження пісень, каверів, розділення вокалу, створення MV та інших функцій.

## Передумови

- Мати обліковий запис [Ace Data Cloud](https://platform.acedata.cloud) та отримати API Token
- Встановлене середовище терміналу з cURL

## Базове використання

Головна кінцева точка для виклику Producer API:

```
POST https://api.acedata.cloud/producer/audios
```

У цьому прикладі використовується модель `FUZZ-2.0 Pro`.
Доступні моделі: `FUZZ-2.0 Pro`, `FUZZ-2.0`, `FUZZ-1.1 Pro`, `FUZZ-1.0 Pro`.

Повний приклад команди cURL:

```bash
curl -X POST https://api.acedata.cloud/producer/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A relaxing jazz piece for a coffee shop", "model": "FUZZ-2.0 Pro", "lyric": "[Verse]\nSoft piano keys in the morning light", "custom": true}'
```

Будь ласка, замініть `YOUR_API_TOKEN` на фактичний токен, отриманий на платформі Ace Data Cloud.

## Приклад відповіді

Після успішного виклику повертається дані у форматі JSON, наприклад:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обробка відповіді за допомогою jq

Рекомендується використовувати інструмент jq для форматування виводу:

```bash
curl -s -X POST https://api.acedata.cloud/producer/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A relaxing jazz piece for a coffee shop", "model": "FUZZ-2.0 Pro", "lyric": "[Verse]\nSoft piano keys in the morning light", "custom": true}' | jq .
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис |
|-----------|-------|
| 401       | Помилка автентифікації, перевірте API Token |
| 403       | Недостатньо коштів або відсутній доступ |
| 429       | Перевищено ліміт запитів |
| 500       | Внутрішня помилка сервера |

## Наступні кроки

- Перейдіть до [Ace Data Cloud консолі](https://platform.acedata.cloud) для отримання API Token
- Ознайомтеся з [API документацією](https://docs.acedata.cloud/zh-CN/api-reference) для повного опису параметрів
- Перегляньте [плани тарифікації](https://platform.acedata.cloud/services) для ознайомлення з вартістю
