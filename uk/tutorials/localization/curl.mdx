## Вступ

Localization — це сервіс інструментів, який надає Ace Data Cloud для AI-перекладу та локалізації. Через уніфікований API Ace Data Cloud ви можете швидко викликати Localization за допомогою cURL, щоб реалізувати переклад Markdown, переклад JSON, підтримку 18 мов, збереження форматування та інші функції.

## Передумови

- Мати обліковий запис [Ace Data Cloud](https://platform.acedata.cloud) та отримати API Token
- Встановлене середовище терміналу з cURL

## Базове використання

Головна кінцева точка для виклику Localization API:

```
POST https://api.acedata.cloud/localization/translate
```

У цьому прикладі використовується модель `gpt-4`.  
Доступні моделі: `gpt-3.5`, `gpt-4`.

Повний приклад команди cURL:

```bash
curl -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}'
```

Будь ласка, замініть `YOUR_API_TOKEN` на фактичний токен, отриманий на платформі Ace Data Cloud.

## Приклад відповіді

Після успішного виклику повертається дані у форматі JSON, наприклад:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обробка відповіді за допомогою jq

Рекомендується використовувати інструмент jq для форматування виводу:

```bash
curl -s -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}' | jq .
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис                           |
|-----------|-------------------------------|
| 401       | Помилка автентифікації, перевірте API Token |
| 403       | Недостатньо коштів або відсутній доступ |
| 429       | Перевищено ліміт частоти запитів |
| 500       | Внутрішня помилка сервера      |

## Наступні кроки

- Перейдіть до [Ace Data Cloud консолі](https://platform.acedata.cloud) для отримання API Token
- Ознайомтеся з [API документацією](https://docs.acedata.cloud/zh-CN/api-reference) для повного опису параметрів
- Ознайомтеся з [тарифними планами](https://platform.acedata.cloud/services) для інформації про вартість
