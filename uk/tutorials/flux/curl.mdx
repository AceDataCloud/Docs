## Вступ

Flux — це AI-сервіс зображень, наданий Ace Data Cloud, модель генерації зображень Black Forest Labs Flux. Через уніфікований API Ace Data Cloud ви можете швидко викликати Flux за допомогою cURL для створення зображень за текстом, редагування зображень, використання різних моделей, налаштування розмірів тощо.

## Передумови

- Наявність облікового запису [Ace Data Cloud](https://platform.acedata.cloud) та отримання API Token
- Встановлене середовище терміналу з cURL

## Базове використання

Основна кінцева точка для виклику Flux API:

```
POST https://api.acedata.cloud/flux/images
```

У цьому прикладі використовується модель `flux-pro-1.1`. Доступні моделі: `flux-dev`, `flux-pro`, `flux-pro-1.1`, `flux-pro-1.1-ultra`, `flux-kontext-pro`, `flux-kontext-max`.

Повний приклад команди cURL:

```bash
curl -X POST https://api.acedata.cloud/flux/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat sitting on a windowsill", "model": "flux-pro-1.1", "size": "1024x1024"}'
```

Замість `YOUR_API_TOKEN` вставте фактичний токен, отриманий на платформі Ace Data Cloud.

## Приклад відповіді

Після успішного виклику повертається JSON-дані, наприклад:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обробка відповіді за допомогою jq

Рекомендується використовувати інструмент jq для форматування виводу:

```bash
curl -s -X POST https://api.acedata.cloud/flux/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat sitting on a windowsill", "model": "flux-pro-1.1", "size": "1024x1024"}' | jq .
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис                         |
|-----------|------------------------------|
| 401       | Аутентифікація не пройдена, перевірте API Token |
| 403       | Недостатньо коштів або відсутній доступ |
| 429       | Перевищено ліміт частоти запитів |
| 500       | Внутрішня помилка сервера    |

## Наступні кроки

- Перейдіть до [Ace Data Cloud Консолі](https://platform.acedata.cloud) для отримання API Token
- Ознайомтеся з [API документацією](https://docs.acedata.cloud/zh-CN/api-reference) для повного опису параметрів
- Перегляньте [Плани тарифікації](https://platform.acedata.cloud/services) для ознайомлення з вартістю
