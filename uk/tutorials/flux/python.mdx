## Вступ

Flux — це AI-сервіс з обробки зображень від Ace Data Cloud, модель генерації зображень Black Forest Labs Flux. Через уніфікований API Ace Data Cloud ви можете швидко інтегрувати Flux за допомогою Python, реалізуючи функції генерації зображень за текстом, редагування зображень, використання різних моделей, налаштування розмірів тощо.

## Передумови

- Наявність облікового запису [Ace Data Cloud](https://platform.acedata.cloud) та отримання API Token
- Середовище Python 3.7 і вище
- Встановлена бібліотека requests: `pip install requests`

## Базове використання

Основна точка доступу до Flux API:

```
POST https://api.acedata.cloud/flux/images
```

У цьому прикладі використовується модель `flux-pro-1.1`.
Доступні моделі: `flux-dev`, `flux-pro`, `flux-pro-1.1`, `flux-pro-1.1-ultra`, `flux-kontext-pro`, `flux-kontext-max`.

Повний приклад коду на Python:

```python
import requests

url = "https://api.acedata.cloud/flux/images"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A white siamese cat sitting on a windowsill",
    "model": "flux-pro-1.1",
    "size": "1024x1024"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Будь ласка, замініть `YOUR_API_TOKEN` на фактичний токен, отриманий на платформі Ace Data Cloud.

## Обробка відповіді

Після успішного виклику API повертає дані у форматі JSON. Рекомендується перевіряти HTTP статус-код:

```python
if response.status_code == 200:
    result = response.json()
    print("Виклик успішний:", result)
else:
    print(f"Виклик не вдався, статус-код: {response.status_code}")
    print(response.text)
```

## Розширене використання

Для API, що підтримують асинхронні завдання, можна отримати результат через callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Результат буде надіслано на ваш сервер через callback URL
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис |
|-----------|------|
| 401       | Помилка автентифікації, перевірте API Token |
| 403       | Недостатньо коштів або відсутній доступ |
| 429       | Перевищено ліміт запитів |
| 500       | Внутрішня помилка сервера |
