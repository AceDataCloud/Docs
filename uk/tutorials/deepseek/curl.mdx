## Вступ

DeepSeek — це AI чат-сервіс від Ace Data Cloud, серія великих мовних моделей DeepSeek. Через уніфікований API Ace Data Cloud ви можете швидко викликати DeepSeek за допомогою cURL, реалізуючи багатокрокові діалоги, системні підказки, потоковий вивід, режим JSON-виводу, глибоке логічне виведення та інші функції.

## Передумови

- Наявність облікового запису [Ace Data Cloud](https://platform.acedata.cloud) та отримання API Token
- Встановлене середовище терміналу з cURL

## Базове використання

Основна кінцева точка для виклику DeepSeek API:

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

У цьому прикладі використовується модель `deepseek-r1`.  
Доступні моделі: `deepseek-r1`, `deepseek-r1-0528`, `deepseek-v3`, `deepseek-v3-250324`.

Повний приклад команди cURL:

```bash
curl -X POST https://api.acedata.cloud/deepseek/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-r1", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Замість `YOUR_API_TOKEN` вставте фактичний токен, отриманий на платформі Ace Data Cloud.

## Приклад відповіді

Після успішного виклику повертається JSON-дані, наприклад:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обробка відповіді за допомогою jq

Рекомендується використовувати інструмент jq для форматування виводу:

```bash
curl -s -X POST https://api.acedata.cloud/deepseek/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-r1", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис                               |
|-----------|----------------------------------|
| 401       | Помилка автентифікації, перевірте API Token |
| 403       | Недостатньо коштів або відсутній доступ |
| 429       | Перевищено ліміт частоти запитів |
| 500       | Внутрішня помилка сервера        |

## Наступні кроки

- Перейдіть до [Ace Data Cloud Консолі](https://platform.acedata.cloud) для отримання API Token
- Ознайомтеся з [документацією API](https://docs.acedata.cloud/zh-CN/api-reference) для повного опису параметрів
- Перегляньте [плани ціноутворення](https://platform.acedata.cloud/services) для ознайомлення з вартістю
