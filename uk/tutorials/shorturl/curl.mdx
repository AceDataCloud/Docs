## Вступ

Short URL — це сервіс скорочення посилань, наданий Ace Data Cloud. Через уніфікований API Ace Data Cloud ви можете швидко викликати Short URL за допомогою cURL для скорочення URL, налаштування власного домену та інших функцій.

## Передумови

- Мати обліковий запис [Ace Data Cloud](https://platform.acedata.cloud) та отримати API Token
- Встановлене середовище терміналу з cURL

## Базове використання

Основна кінцева точка API Short URL:

```
POST https://api.acedata.cloud/shorturl
```

Повний приклад команди cURL:

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}'
```

Будь ласка, замініть `YOUR_API_TOKEN` на фактичний токен, отриманий на платформі Ace Data Cloud.

## Приклад відповіді

Після успішного виклику повертається дані у форматі JSON, наприклад:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обробка відповіді за допомогою jq

Рекомендується використовувати інструмент jq для форматованого виводу:

```bash
curl -s -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}' | jq .
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис                          |
|-----------|-------------------------------|
| 401       | Помилка автентифікації, перевірте API Token |
| 403       | Недостатньо коштів або відсутній доступ |
| 429       | Перевищено ліміт частоти запитів |
| 500       | Внутрішня помилка сервера     |

## Наступні кроки

- Перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud) для отримання API Token
- Ознайомтеся з [документацією API](https://docs.acedata.cloud/zh-CN/api-reference) для повного опису параметрів
- Перегляньте [тарифи](https://platform.acedata.cloud/services) для ознайомлення з вартістю послуг
