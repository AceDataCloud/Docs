## Вступ

Grok — це AI чат-сервіс від Ace Data Cloud, серія великих мовних моделей xAI Grok. За допомогою уніфікованого API Ace Data Cloud ви можете швидко інтегрувати Grok на JavaScript, реалізуючи багатокрокові діалоги, системні підказки, потоковий вивід, режим виводу JSON, візуальне розуміння та інші функції.

## Передумови

- Наявність облікового запису [Ace Data Cloud](https://platform.acedata.cloud) та отримання API Token
- Node.js 18+ або сучасне браузерне середовище

## Базове використання

Головна кінцева точка для виклику Grok API:

```
POST https://api.acedata.cloud/grok/chat/completions
```

У цьому прикладі використовується модель `grok-3`.
Доступні моделі: `grok-4`, `grok-4-1-fast`, `grok-3`, `grok-3-mini`, `grok-2-vision`.

Повний приклад коду на JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/grok/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "grok-3",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Будь ласка, замініть `YOUR_API_TOKEN` на ваш фактичний токен, отриманий на платформі Ace Data Cloud.

## Обробка відповіді

Рекомендується перевіряти статус відповіді та обробляти помилки:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Виклик успішний:", result);
} else {
  console.error(`Виклик не вдався, статус: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Обгортка для Node.js

Рекомендується створити функцію для повторного використання:

```javascript
async function callGrok(data) {
  const response = await fetch("https://api.acedata.cloud/grok/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Обробка помилок

Поширені коди помилок:

| Код статусу | Опис |
|------------|-------|
| 401 | Аутентифікація не вдалася, перевірте API Token |
| 403 | Недостатньо коштів або відсутній доступ |
| 429 | Перевищено ліміт частоти запитів |
| 500 | Внутрішня помилка сервера |
