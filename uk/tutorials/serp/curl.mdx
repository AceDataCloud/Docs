## Вступ

Google Search — це сервіс пошуку, який надає Ace Data Cloud, API для пошуку Google. Через уніфікований API Ace Data Cloud ви можете швидко викликати Google Search за допомогою cURL для реалізації пошуку веб-сторінок, зображень, новин, карт, відео та інших функцій.

## Передумови

- Наявність облікового запису [Ace Data Cloud](https://platform.acedata.cloud) та отримання API Token
- Встановлене середовище терміналу з cURL

## Базове використання

Основна кінцева точка виклику Google Search API:

```
POST https://api.acedata.cloud/serp/google
```

Повний приклад команди cURL:

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}'
```

Будь ласка, замініть `YOUR_API_TOKEN` на фактичний токен, отриманий на платформі Ace Data Cloud.

## Приклад відповіді

Після успішного виклику повертаються дані у форматі JSON, наприклад:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обробка відповіді за допомогою jq

Рекомендується використовувати інструмент jq для форматування виводу:

```bash
curl -s -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}' | jq .
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис                         |
|-----------|------------------------------|
| 401       | Помилка автентифікації, перевірте API Token |
| 403       | Недостатньо коштів або відсутній доступ |
| 429       | Перевищено ліміт частоти запитів |
| 500       | Внутрішня помилка сервера    |

## Наступні кроки

- Перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud) для отримання API Token
- Ознайомтеся з [документацією API](https://docs.acedata.cloud/zh-CN/api-reference) для повного опису параметрів
- Перегляньте [цінові плани](https://platform.acedata.cloud/services) для ознайомлення з вартістю послуг
