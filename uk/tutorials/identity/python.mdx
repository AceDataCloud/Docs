## Вступ

Identity — це сервіс автентифікації, який надає Ace Data Cloud для перевірки особистих даних: посвідчення особи, банківської картки, номера телефону. За допомогою уніфікованого API Ace Data Cloud ви можете швидко інтегрувати Identity у Python для реалізації функцій OCR посвідчення особи, перевірки посвідчення особи, банківської картки, номера телефону тощо.

## Передумови

- Наявність облікового запису [Ace Data Cloud](https://platform.acedata.cloud) та отримання API Token
- Середовище Python 3.7 і вище
- Встановлена бібліотека requests: `pip install requests`

## Базове використання

Основна кінцева точка для виклику Identity API:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Повний приклад коду на Python:

```python
import requests

url = "https://api.acedata.cloud/identity/idcard/ocr"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "image_url": "https://example.com/idcard-front.jpg"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Будь ласка, замініть `YOUR_API_TOKEN` на фактичний токен, отриманий на платформі Ace Data Cloud.

## Обробка відповіді

Після успішного виклику API повертає дані у форматі JSON. Рекомендується перевіряти HTTP статус код:

```python
if response.status_code == 200:
    result = response.json()
    print("Виклик успішний:", result)
else:
    print(f"Виклик не вдався, статус код: {response.status_code}")
    print(response.text)
```

## Розширене використання

Для API, що підтримують асинхронні завдання, результат можна отримати через callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Результат буде надіслано на ваш сервер через callback URL
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис |
|-----------|-------|
| 401 | Аутентифікація не пройдена, перевірте API Token |
| 403 | Недостатньо коштів або відсутній доступ |
| 429 | Перевищено ліміт запитів |
| 500 | Внутрішня помилка сервера |
