## Вступ

Identity — це сервіс автентифікації, який надає Ace Data Cloud для перевірки особистих документів, банківських карток та номерів телефонів. Використовуючи уніфікований API Ace Data Cloud, ви можете швидко викликати Identity за допомогою cURL для реалізації функцій OCR посвідчення особи, перевірки посвідчення особи, банківської картки та номера телефону.

## Передумови

- Наявність облікового запису [Ace Data Cloud](https://platform.acedata.cloud) та отримання API Token
- Встановлене середовище терміналу з підтримкою cURL

## Базове використання

Основна кінцева точка для виклику Identity API:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Повний приклад команди cURL:

```bash
curl -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}'
```

Будь ласка, замініть `YOUR_API_TOKEN` на фактичний токен, отриманий на платформі Ace Data Cloud.

## Приклад відповіді

Після успішного виклику повертається дані у форматі JSON, наприклад:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обробка відповіді за допомогою jq

Рекомендується використовувати інструмент jq для форматованого виводу:

```bash
curl -s -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}' | jq .
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис                          |
|-----------|-------------------------------|
| 401       | Аутентифікація не пройдена, перевірте API Token |
| 403       | Недостатньо коштів або відсутній доступ |
| 429       | Перевищено ліміт частоти запитів |
| 500       | Внутрішня помилка сервера     |

## Наступні кроки

- Перейдіть до [Ace Data Cloud консолі](https://platform.acedata.cloud) для отримання API Token
- Ознайомтеся з [API документацією](https://docs.acedata.cloud/zh-CN/api-reference) для повного опису параметрів
- Перегляньте [плани тарифікації](https://platform.acedata.cloud/services) для ознайомлення з вартістю послуг
