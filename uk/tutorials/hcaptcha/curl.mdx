## Вступ

hCaptcha — це сервіс капч, який надає Ace Data Cloud, рішення hCaptcha. Через уніфікований API Ace Data Cloud ви можете швидко викликати hCaptcha за допомогою cURL, реалізуючи отримання hCaptcha Token, розпізнавання зображень hCaptcha та інші функції.

## Передумови

- Наявність облікового запису [Ace Data Cloud](https://platform.acedata.cloud) та отримання API Token
- Встановлене середовище терміналу з cURL

## Базове використання

Головна кінцева точка для виклику hCaptcha API:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Повний приклад команди cURL:

```bash
curl -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}'
```

Будь ласка, замініть `YOUR_API_TOKEN` на фактичний Token, отриманий на платформі Ace Data Cloud.

## Приклад відповіді

Після успішного виклику повертається дані у форматі JSON, наприклад:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обробка відповіді за допомогою jq

Рекомендується використовувати інструмент jq для форматованого виводу:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}' | jq .
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис                          |
|-----------|-------------------------------|
| 401       | Аутентифікація не пройдена, перевірте API Token |
| 403       | Недостатньо коштів або відсутній доступ |
| 429       | Перевищено ліміт частоти запитів |
| 500       | Внутрішня помилка сервера     |

## Наступні кроки

- Перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud) для отримання API Token
- Ознайомтеся з [документацією API](https://docs.acedata.cloud/zh-CN/api-reference) для повного опису параметрів
- Перегляньте [плани тарифікації](https://platform.acedata.cloud/services) для ознайомлення з вартістю
