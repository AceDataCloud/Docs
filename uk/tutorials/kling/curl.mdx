---

## Вступ

Kling — це AI відео сервіс від Ace Data Cloud, модель швидкого створення відео. Через уніфікований API Ace Data Cloud ви можете швидко викликати Kling за допомогою cURL для створення відео з тексту, відео з зображень, продовження відео, з різною тривалістю та співвідношенням сторін.

## Передумови

- Мати акаунт [Ace Data Cloud](https://platform.acedata.cloud) та отримати API Token
- Встановлене середовище терміналу з cURL

## Базове використання

Головна кінцева точка для виклику Kling API:

```
POST https://api.acedata.cloud/kling/videos
```

У цьому прикладі використовується модель `kling-v2-5-turbo`. Доступні моделі: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`.

Повний приклад команди cURL:

```bash
curl -X POST https://api.acedata.cloud/kling/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A white cat walking in the snow", "model": "kling-v2-5-turbo", "duration": 5, "aspect_ratio": "16:9"}'
```

Будь ласка, замініть `YOUR_API_TOKEN` на ваш реальний токен, отриманий на платформі Ace Data Cloud.

## Приклад відповіді

Після успішного виклику повертається JSON, наприклад:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обробка відповіді за допомогою jq

Рекомендується використовувати інструмент jq для форматованого виводу:

```bash
curl -s -X POST https://api.acedata.cloud/kling/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A white cat walking in the snow", "model": "kling-v2-5-turbo", "duration": 5, "aspect_ratio": "16:9"}' | jq .
```

## Обробка помилок

Поширені коди помилок:

| Код стану | Опис |
|-----------|------|
| 401       | Аутентифікація не вдалася, перевірте API Token |
| 403       | Недостатньо коштів або відсутній доступ |
| 429       | Перевищено ліміт частоти запитів |
| 500       | Внутрішня помилка сервера |

## Наступні кроки

- Перейдіть до [консолі Ace Data Cloud](https://platform.acedata.cloud) для отримання API Token
- Ознайомтеся з [документацією API](https://docs.acedata.cloud/zh-CN/api-reference) для повного опису параметрів
- Перегляньте [плани тарифікації](https://platform.acedata.cloud/services) для інформації про вартість
