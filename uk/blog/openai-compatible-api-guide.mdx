## Що таке сумісний інтерфейс OpenAI

Формат Chat Completions API від OpenAI став фактичним галузевим стандартом. Багато великих мовних моделей надають інтерфейси, сумісні з OpenAI, що дозволяє розробникам використовувати один і той же код для роботи з різними моделями.

Ace Data Cloud надає сумісні з OpenAI інтерфейси Chat Completions для моделей Claude, Gemini, DeepSeek, Grok, Kimi тощо — достатньо змінити Base URL і назву моделі для перемикання.

## Підтримувані моделі

| Сервіс | Ендпоінт | Приклад моделі |
|--------|----------|----------------|
| Claude | `POST /v1/chat/completions` | claude-sonnet-4-6 |
| OpenAI | `POST /openai/chat/completions` | gpt-4o |
| Gemini | `POST /gemini/chat/completions` | gemini-2.5-flash |
| DeepSeek | `POST /deepseek/chat/completions` | deepseek-r1 |
| Grok | `POST /grok/chat/completions` | grok-3 |
| Kimi | `POST /kimi/chat/completions` | kimi-k2.5 |

## Уніфікований спосіб виклику

Усі чат-моделі використовують однаковий формат запиту:

```python
import requests

def chat(endpoint, model, message):
    return requests.post(
        f"https://api.acedata.cloud{endpoint}",
        headers={
            "Authorization": "Bearer YOUR_API_TOKEN",
            "Content-Type": "application/json",
        },
        json={
            "model": model,
            "messages": [{"role": "user", "content": message}],
            "max_tokens": 1024,
            "temperature": 0.7,
        },
    ).json()

# Виклик різних моделей — достатньо змінити ендпоінт і назву моделі
claude = chat("/v1/chat/completions", "claude-sonnet-4-6", "你好")
gpt = chat("/openai/chat/completions", "gpt-4o", "你好")
gemini = chat("/gemini/chat/completions", "gemini-2.5-flash", "你好")
deepseek = chat("/deepseek/chat/completions", "deepseek-r1", "你好")
```

## Потоковий вивід

Всі чат API підтримують потоковий вивід (Server-Sent Events):

```python
data = {
    "model": "claude-sonnet-4-6",
    "messages": [{"role": "user", "content": "写一首诗"}],
    "stream": True,
}

response = requests.post(
    "https://api.acedata.cloud/v1/chat/completions",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json=data,
    stream=True,
)

for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Сумісність з OpenAI SDK

Оскільки формат інтерфейсу сумісний, ви можете безпосередньо використовувати офіційний SDK OpenAI, лише змінивши base_url:

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_TOKEN",
    base_url="https://api.acedata.cloud/v1",  # Claude
    # base_url="https://api.acedata.cloud/openai",  # OpenAI
    # base_url="https://api.acedata.cloud/gemini",  # Gemini
)

response = client.chat.completions.create(
    model="claude-sonnet-4-6",
    messages=[{"role": "user", "content": "你好"}],
)
print(response.choices[0].message.content)
```
