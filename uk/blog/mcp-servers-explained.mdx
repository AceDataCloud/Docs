## Що таке MCP

Model Context Protocol (MCP) — це відкритий протокол, який дозволяє AI асистентам (наприклад, Claude, Cursor) безпосередньо викликати зовнішні інструменти та API. Завдяки MCP AI може не лише відповідати на запитання, а й виконувати реальні дії.

## Встановлення та використання

### Встановлення

```bash
pip install mcp-suno  # або інший MCP Server
```

### Налаштування змінних середовища

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### Налаштування в Cursor

Додайте у налаштування MCP Cursor:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### Налаштування в Claude Desktop

Відредагуйте конфігураційний файл Claude Desktop, додавши налаштування MCP Server.

## Сценарії використання

1. **Генерація музики в Cursor**: скажіть AI "згенеруй веселу пісню за допомогою Suno", AI безпосередньо викличе API
2. **Пошук актуальної інформації**: AI може шукати найновішу інформацію через MCP Server SERP
3. **Генерація матеріалів для проекту**: AI може викликати Midjourney для створення потрібних зображень

## MCP vs прямий виклик API

- **MCP**: підходить для використання в AI інструментах програмування, виклики здійснює AI автоматично
- **API**: підходить для інтеграції у власні додатки з програмним контролем

Обидва способи використовують однаковий Ace Data Cloud API Token і викликають ті ж API кінцеві точки.

## Підсумок

MCP дозволяє AI асистентам безпосередньо викликати різні API Ace Data Cloud. Всі MCP Server опубліковані на PyPI, їх легко встановити та налаштувати, що робить ваші AI інструменти потужнішими.

Отримайте API Token на [platform.acedata.cloud](https://platform.acedata.cloud).
