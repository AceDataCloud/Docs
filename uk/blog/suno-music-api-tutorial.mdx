## Вступ до Suno

Suno — одна з найпотужніших платформ для генерації музики за допомогою ШІ. Через Suno API від Ace Data Cloud ви можете створювати високоякісну музику простими викликами API.

## API кінцеві точки

| Кінцева точка | Функція |
|---------------|---------|
| `POST /suno/audios` | Генерація музики (основна кінцева точка) |
| `POST /suno/lyrics` | Генерація текстів пісень |
| `POST /suno/persona` | Управління стилями виконавців |
| `POST /suno/wav` | Отримання у форматі WAV |
| `POST /suno/mp4` | Отримання у форматі MP4 |
| `POST /suno/tasks` | Перевірка статусу завдань |

## Базова генерація

### Генерація за текстовим описом

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### Генерація з власним текстом пісні

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\n夏日的阳光洒满了海岸\n微风中传来浪花的声音\n\n[Chorus]\n让我们一起去远方\n追逐那自由的梦想",
        "style": "pop upbeat",
        "title": "夏日冒险",
    },
)
```

## Розширені можливості

### Продовження пісні

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### Генерація текстів пісень

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "写一首关于冬天的歌",
    },
)
```

## Доступні моделі

| Модель | Особливості |
|--------|-------------|
| chirp-v5 | Остання версія, найкраща якість звуку |
| v4-5-plus | Покращена версія |
| v4-5 | Стабільна версія |
| v4 | Класична версія |

## Підсумок

Suno API через платформу Ace Data Cloud надає повний функціонал для генерації музики. Від простої генерації за текстом до створення власних текстів пісень — все це можна реалізувати кількома рядками коду.

Зареєструйтесь і спробуйте на [platform.acedata.cloud](https://platform.acedata.cloud).
