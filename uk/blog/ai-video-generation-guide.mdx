## Огляд

Генерація AI-відео швидко розвивається. Ace Data Cloud пропонує 7 видів API для генерації відео, що охоплюють різні сценарії від тексту до відео до зображення до відео.

## Доступні сервіси генерації відео

| Сервіс | Ендпоінт | Модель | Особливості |
|--------|----------|--------|-------------|
| Sora   | `POST /sora/videos` | sora-2, sora-2-pro | Від OpenAI, кінематографічна якість |
| Veo    | `POST /veo/videos` | veo3, veo3-fast | Від Google, підтримка 4K |
| Kling  | `POST /kling/videos` | kling-v2-5-turbo | Від Kuaishou, висока швидкість |
| Luma   | `POST /luma/videos` | — | Контроль початкового та кінцевого кадру |
| Hailuo | `POST /hailuo/videos` | minimax-t2v | Від MiniMax |
| Seedance | `POST /seedance/videos` | doubao-seedance-1-0-pro-250528 | Від ByteDance |
| Wan    | `POST /wan/videos` | wan2.6-t2v | Від Alibaba |

## Швидкий старт

### Генерація відео Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A cat playing in a sunny garden",
        "model": "sora-2",
        "duration": 10,
        "orientation": "landscape",
    },
)
print(response.json())
```

### Генерація відео Kling

```python
response = requests.post(
    "https://api.acedata.cloud/kling/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A white cat walking in the snow",
        "model": "kling-v2-5-turbo",
        "duration": 5,
        "aspect_ratio": "16:9",
    },
)
print(response.json())
```

### Генерація відео Veo

```python
response = requests.post(
    "https://api.acedata.cloud/veo/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A coffee mug rotating on a marble counter",
        "model": "veo3",
    },
)
print(response.json())
```

## Обробка асинхронних завдань

Генерація відео зазвичай займає тривалий час. Всі відео API підтримують:

1. **Повідомлення зворотного виклику**: встановіть `callback_url` у запиті, результат буде автоматично надіслано після завершення генерації
2. **Опитування статусу**: перевірка прогресу завдання через ендпоінт `/tasks`

```python
# Використання callback URL
data = {
    "prompt": "A sunrise over mountains",
    "model": "sora-2",
    "callback_url": "https://your-server.com/webhook",
}

# Або опитування статусу завдання
task_response = requests.post("https://api.acedata.cloud/sora/tasks",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json={"task_id": "your-task-id"})
```

## Рекомендації щодо вибору

- **Найкраща якість зображення**: Sora (sora-2-pro)
- **Найшвидша швидкість**: Kling (kling-v2-5-turbo)
- **Найвища роздільна здатність**: Veo (підтримка 4K)
- **Контроль початкового та кінцевого кадру**: Luma
- **Оптимальне співвідношення ціни та якості**: Wan
