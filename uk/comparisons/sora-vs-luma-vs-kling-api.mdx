## Детальний аналіз

### Функціональність

Sora, Luma та Kling викликаються через уніфікований API Ace Data Cloud, підтримують стандартний REST інтерфейс та аутентифікацію Bearer Token.

**Sora** основна кінцева точка — `POST https://api.acedata.cloud/sora/videos`, підтримує генерацію відео з тексту, різну тривалість, альбомну та портретну орієнтацію, керування персонажами. Також доступні кінцеві точки `/sora/tasks` та інші.

**Luma** основна кінцева точка — `POST https://api.acedata.cloud/luma/videos`, підтримує генерацію відео з тексту, генерацію відео з зображень, продовження відео, керування початковим та кінцевим кадром. Також доступні кінцеві точки `/luma/tasks` та інші.

**Kling** основна кінцева точка — `POST https://api.acedata.cloud/kling/videos`, підтримує генерацію відео з тексту, генерацію відео з зображень, продовження відео, різну тривалість. Також доступні кінцеві точки `/kling/tasks`, `/kling/motion` та інші.

## Приклади коду

Нижче наведено приклади виклику API Ace Data Cloud для Sora, Luma та Kling. Всі запити використовують однаковий базовий URL (`https://api.acedata.cloud`) та спосіб аутентифікації.

### Виклик Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
},
)
print(response.json())
```
