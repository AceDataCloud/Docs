## Огляд

AI відеогенерація — найпопулярніший напрямок AI технологій у 2024-2025 роках. За допомогою Ace Data Cloud ви можете використовувати різні моделі відеогенерації, такі як Sora, Luma, Kling, для створення автоматизованих конвеєрів виробництва відео.

## Залучені сервіси

- **Sora**: `POST https://api.acedata.cloud/sora/videos`
- **Luma**: `POST https://api.acedata.cloud/luma/videos`
- **Kling**: `POST https://api.acedata.cloud/kling/videos`

## Технічне рішення

### Попередні умови

1. Зареєструвати акаунт на [Ace Data Cloud](https://platform.acedata.cloud)
2. Отримати API Token
3. Встановити Python 3.7+ та бібліотеку requests

### Кроки реалізації

### Крок 1: Вибір моделі відео

Sora спеціалізується на якості кінофільму, Luma підтримує контроль початкових і кінцевих кадрів, Kling забезпечує швидку генерацію.

### Крок 2: Надсилання завдання на генерацію

Sora використовує `/sora/videos`, Luma — `/luma/videos`, Kling — `/kling/videos`.

### Крок 3: Перевірка статусу завдання

Всі відео API підтримують перевірку прогресу завдання через кінцеву точку `/tasks`.

## Приклад коду

Нижче наведено повний приклад на Python із використанням Sora:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_sora():
    response = requests.post(
        "https://api.acedata.cloud/sora/videos",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
},
    )
    return response.json()

result = call_sora()
print(result)
```

## Кращі практики

- **Повторні спроби при помилках**: застосовуйте експоненціальне відновлення для помилок 429 (обмеження швидкості) та 5xx
- **Асинхронна обробка**: для тривалих завдань (генерація зображень/відео) використовуйте callback_url для асинхронного отримання результатів
- **Контроль витрат**: моніторинг використання та витрат через консоль Ace Data Cloud
- **Безпека Token**: зберігайте API Token у змінних середовища, не жорстко кодуйте в коді
