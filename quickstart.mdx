本指南带你完成第一个 API 调用：以 Midjourney 文生图为例，提交任务、轮询结果。

## 1. 拿到 API Token

<Steps>
  <Step title="注册并登录">
    访问 [platform.acedata.cloud](https://platform.acedata.cloud) 注册账号，新账号默认带试用额度。
  </Step>
  <Step title="订阅服务">
    在 [Midjourney 服务页](https://platform.acedata.cloud/services) 点击「获取」完成订阅。
  </Step>
  <Step title="创建凭证">
    进入服务的「凭证」标签，点击「创建凭证」，复制生成的 Token。
  </Step>
</Steps>

更多 Token 相关说明见 [网关与认证](/authentication)。

## 2. 提交第一个任务

所有请求都需要 `Authorization: Bearer YOUR_API_TOKEN` 头。以下例子提交一个 Midjourney 图像生成任务：

<CodeGroup>

```bash cURL
curl -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "a cute kitten playing with yarn, studio lighting",
    "callback_url": "https://your-server.com/webhook"
  }'
```

```python Python
import requests

resp = requests.post(
    "https://api.acedata.cloud/midjourney/imagine",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "a cute kitten playing with yarn, studio lighting",
        "callback_url": "https://your-server.com/webhook",
    },
    timeout=300,
)
data = resp.json()
print(data)
```

```javascript Node.js
const res = await fetch("https://api.acedata.cloud/midjourney/imagine", {
  method: "POST",
  headers: {
    Authorization: "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    prompt: "a cute kitten playing with yarn, studio lighting",
    callback_url: "https://your-server.com/webhook",
  }),
});
const data = await res.json();
console.log(data);
```

```go Go
package main

import (
  "bytes"
  "encoding/json"
  "fmt"
  "io"
  "net/http"
)

func main() {
  body, _ := json.Marshal(map[string]string{
    "prompt":       "a cute kitten playing with yarn, studio lighting",
    "callback_url": "https://your-server.com/webhook",
  })
  req, _ := http.NewRequest("POST",
    "https://api.acedata.cloud/midjourney/imagine",
    bytes.NewReader(body))
  req.Header.Set("Authorization", "Bearer YOUR_API_TOKEN")
  req.Header.Set("Content-Type", "application/json")
  resp, _ := http.DefaultClient.Do(req)
  defer resp.Body.Close()
  out, _ := io.ReadAll(resp.Body)
  fmt.Println(string(out))
}
```

</CodeGroup>

返回结构（同步直出，长任务会先返回 `task_id`）：

```json
{
  "success": true,
  "task_id": "1bae3bec-3ac4-4180-a148-74ee6cb68b98",
  "image_url": "https://cdn.acedata.cloud/midjourney/.../kitten.png",
  "image_id": "1234197197067915365",
  "actions": ["upscale1", "upscale2", "variation1", "variation2"]
}
```

记下 `task_id`——之后追加放大、变体、Webhook 重投时都会用到。

## 3. 轮询任务结果

如果你**没有**配置 `callback_url`，或同步请求超时，使用 `tasks` 端点查询结果：

<CodeGroup>

```bash cURL
curl -X POST https://api.acedata.cloud/midjourney/tasks \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "1bae3bec-3ac4-4180-a148-74ee6cb68b98",
    "action": "retrieve"
  }'
```

```python Python
import requests, time

task_id = "1bae3bec-3ac4-4180-a148-74ee6cb68b98"
while True:
    r = requests.post(
        "https://api.acedata.cloud/midjourney/tasks",
        headers={"Authorization": "Bearer YOUR_API_TOKEN"},
        json={"id": task_id, "action": "retrieve"},
    ).json()
    if r.get("success"):
        print(r)
        break
    time.sleep(5)
```

</CodeGroup>

## 任务状态

| `status` 字段值 | 含义 |
|---|---|
| `pending` | 任务在排队中 |
| `running` | 上游正在生成 |
| `success` | 完成，可以读取最终字段（URL 等） |
| `failed` | 失败，看 `error.code` / `error.message` |

详见 [异步任务模式](/concepts/async-tasks)。
