title: "Async tasks"
description: "Submit a generation once, query its task ID, and retrieve the final result."
---

Endpoints that support `async: true` can return a task ID while generation continues. Save that ID immediately. Query the task until its documented terminal state, then read the result or error.

## Submit once and query the result

This example creates an ACE Music song and queries the original task. Install `requests` with `pip install requests` and set `ACEDATACLOUD_API_KEY` as described in [Quickstart](/en/quickstart).

```python
import os
import time
import requests

headers = {"Authorization": f"Bearer {os.environ['ACEDATACLOUD_API_KEY']}"}
submitted = requests.post(
    "https://api.acedata.cloud/acemusic/audios",
    headers=headers,
    json={
        "action": "generate",
        "model": "acemusic-v1.1",
        "custom": False,
        "prompt": "An uplifting acoustic folk song about coming home",
        "async": True,
    },
    timeout=30,
)
submitted.raise_for_status()
task_id = submitted.json()["task_id"]
print("Save this task ID to resume later:", task_id, flush=True)

# Keep this ID when resuming. Submit the generation only once.
for attempt in range(180):
    response = requests.post(
        "https://api.acedata.cloud/acemusic/tasks",
        headers=headers,
        json={"action": "retrieve", "id": task_id},
        timeout=30,
    )
    response.raise_for_status()
    task = response.json()
    state = task.get("state") or task.get("status")
    if state in {"succeeded", "failed", "partial_failed"}:
        result = task.get("response") or {}
        if state != "succeeded":
            raise RuntimeError({"task_id": task_id, "state": state, "error": result.get("error")})
        for track in result.get("data", []):
            print(track["audio_url"])
        break
    time.sleep(5)
else:
    print("Still pending. Resume querying this task ID:", task_id)

```

`created`, `submitting`, `processing`, and `submission_unknown` require further queries. `partial_failed` is a terminal result. For successful song generation, `response.data` contains the tracks and their `audio_url` values. The track IDs in that list are used for later cover or mashup requests. [ACE Music task reference](/en/guides/acemusic/acemusic_tasks) describes all fields.

To resume after leaving your script, use the saved ID in this query. Replace `YOUR_TASK_ID` with the ID printed above.

```bash
curl --fail-with-body https://api.acedata.cloud/acemusic/tasks \
  --header "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"action":"retrieve","id":"YOUR_TASK_ID"}'
```

## Use the endpoint's task contract

Each service documents its own query path, request fields and terminal states. Use the corresponding [service guide](/en/services) for Suno, Veo, Seedance and other APIs. A successful HTTP response to a task query may still describe a pending generation. Some operations return their full result synchronously or stream output.

If a query fails or reaches the polling limit, keep the original task ID and query it again later. A connection timeout during submission can leave the outcome uncertain. Check your task history or contact support with `trace_id` before submitting the same generation again.

## Webhook callbacks

Where supported by the endpoint, include `callback_url` in the original generation request to receive its final result. ACE Music accepts an HTTPS callback URL and uses asynchronous execution for that request.

```json
{
  "action": "generate",
  "model": "acemusic-v1.1",
  "custom": false,
  "prompt": "An uplifting acoustic folk song about coming home",
  "async": true,
  "callback_url": "https://your-app.example/callbacks/acemusic"
}
```

Save the submitted task ID in your application. Process callbacks idempotently by that ID and return a `2xx` response promptly. Treat a callback as a notification and query the recorded task to verify its result before updating your application. Polling also recovers a missing callback. For the exact callback payload, follow the selected endpoint's guide.
