ACE Music MCP provides song creation, lyric generation, and task query tools for clients that support the Model Context Protocol. Use AceDataCloud API credentials that have been granted ACE Music service permissions.

## Configuration

The server package name is `mcp-acemusic`, supporting standard input/output and hosted HTTP access. The release status of the package and hosted endpoint is subject to the release notes of the [MCP repository](https://github.com/AceDataCloud/MCPs/tree/main/acemusic).

After release, you can configure the stdio service in clients that support MCP:

```json
{
  "mcpServers": {
    "acemusic": {
      "command": "uvx",
      "args": ["mcp-acemusic"],
      "env": {"ACEDATACLOUD_API_TOKEN": "YOUR_API_KEY"}
    }
  }
}
```

The environment variable is `ACEDATACLOUD_API_TOKEN`. The tools include inspiration-based song generation, custom song generation, lyric generation, and task queries; specific startup parameters and versions are subject to the package README.

## Creation Process

1. Tell the assistant the song theme, style, or provide a custom title and lyrics.
2. The assistant submits one generation request and saves the returned task ID.
3. Use the task tool to wait for and query the original task, without resubmitting due to waiting.
4. The results include playback and download URLs for two candidates; the lyric assistant can generate an editable draft first.

Generation and lyric tools have fees, while task queries are free. A fee is charged once per group for the complete two songs; no generation fee is charged for final failure or partial failure. The models are `acemusic-v1.1` and `acemusic-v1`. Uploading, cover songs, continuation, stem separation, or voice tools are currently not provided.

For API parameter and error conventions, see the [song guide](https://platform.acedata.cloud/documents/acemusic-audios-integration) and [task guide](https://platform.acedata.cloud/documents/acemusic-tasks-integration).
