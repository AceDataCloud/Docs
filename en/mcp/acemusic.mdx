ACE Music MCP provides clients that support Model Context Protocol with tools for song creation, reference audio upload, cover creation, dual-reference fusion, lyric generation, and task queries. Use AceDataCloud API credentials that have been granted access to the ACE Music service.

## Configuration

The server package name is `mcp-acemusic`, supporting standard input/output and hosted HTTP access. The release status of the package and hosted endpoint is subject to the release notes in the [MCP repository](https://github.com/AceDataCloud/MCPs/tree/main/acemusic).

After release, you can configure the stdio service in clients that support MCP:

```json
{
  "mcpServers": {
    "acemusic": {
      "command": "uvx",
      "args": ["mcp-acemusic"],
      "env": {"ACEDATACLOUD_API_TOKEN": "YOUR_API_KEY"}
    }
  }
}
```

The environment variable is `ACEDATACLOUD_API_TOKEN`. Tools include inspiration-based song generation, custom song generation, reference upload, cover creation, fusion, lyric generation, and task queries; specific startup parameters and versions are subject to the package README.

## Creation Workflow

1. Tell the assistant the song theme, style, or provide a custom title and lyrics.
2. The assistant submits one generation and saves the returned task ID.
3. Use the task tool to wait for and query the original task, without resubmitting because of waiting.
4. The result includes playback and download URLs for two candidates; the lyrics assistant can first generate an editable draft.

Generation, upload, and lyric tools are charged separately, while task queries are free. The complete pair of songs from generation, cover creation, and fusion is charged once as a group; no generation fee is charged for final failure or partial failure. One fee is charged after a reference is successfully imported, and failures are not charged. Basic generation supports `acemusic-v1.1` and `acemusic-v1`; cover creation and fusion use `acemusic-v1.1`. For cover creation, select one of your own platform audio tracks; for fusion, select exactly two different and compatible audio tracks. Reference import currently supports MP3 files only. Import a new reference only when the user explicitly chooses an upload operation; do not implicitly submit another paid upload for cover creation. Instrumental-only, style strength, continuation, track separation, or voice tools are not currently available.

For API parameter and error conventions, see the [Song Guide](https://platform.acedata.cloud/documents/acemusic-audios-integration) and the [Task Guide](https://platform.acedata.cloud/documents/acemusic-tasks-integration).
