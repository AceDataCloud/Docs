ACE Music MCP provides song creation, lyrics and task tools for Model Context Protocol clients. Use an AceDataCloud API credential with ACE Music permissions.

The package name is `mcp-acemusic`; supported transports include stdio and hosted HTTP. Confirm release availability, environment variables, startup flags and exact tool names in the [package README](https://github.com/AceDataCloud/MCPs/tree/main/acemusic).

After publication, a stdio client can use:

```json
{"mcpServers":{"acemusic":{"command":"uvx","args":["mcp-acemusic"],"env":{"ACEDATACLOUD_API_TOKEN":"YOUR_API_KEY"}}}}
```

Describe an idea or provide a title, lyrics and style. Submit once, retain the returned task ID, then query that task until completion. Results contain playback and download links for the song candidates. Lyrics can be generated and edited first.

Song and lyrics tools have separate charges; task queries are free. A complete two-track group is charged once; final failed or partial groups are free. Models are `acemusic-v1.1` and `acemusic-v1`. Upload, cover, extension, stems and voice tools are outside this release.

See the [song guide](https://platform.acedata.cloud/documents/acemusic-audios-integration) and [tasks guide](https://platform.acedata.cloud/documents/acemusic-tasks-integration) for the public contract.
