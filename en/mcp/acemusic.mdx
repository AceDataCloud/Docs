ACE Music MCP enables AI clients that support the [Model Context Protocol](https://modelcontextprotocol.io) to call tools for song creation, reference audio upload, cover creation, dual-reference fusion, lyrics generation, and task queries. You can first ask the assistant to write lyrics, generate a song after confirmation, or continue creating with your own reference audio track.

## Application and Usage

Before integrating, first obtain an AceDataCloud API Token:

1. Register or log in to the [AceDataCloud Console](https://platform.acedata.cloud/console/applications).
2. Open **General Applications** and click **Create API Key**; if you already have an available API Key, copy it directly. The API Key here is the API Token used in this guide.
3. Confirm that this credential allows access to the relevant ACE Music APIs, and that the application balance, validity period, and credential limits meet the call requirements. Credentials from an existing ACE Music application can also be used.
4. When you need to manage, update, or revoke credentials, go to [API Credential Management](https://platform.acedata.cloud/console/credentials). For pricing and quotas, see the [ACE Music Service Page](https://platform.acedata.cloud/services/acemusic).

Replace `YOUR_API_TOKEN` in the examples below with the copied API Key. Do not use an account management Token instead of API calling credentials, and do not write real keys in conversations, public code, or repositories.

## Method 1: Run the MCP Server Locally

Local integration uses the published Python package [`mcp-acemusic`](https://pypi.org/project/mcp-acemusic/). First install [uv](https://docs.astral.sh/uv/getting-started/installation/), ensure that the client can run `uvx`, then add the following stdio configuration:

```json
{
  "mcpServers": {
    "acemusic": {
      "command": "uvx",
      "args": ["mcp-acemusic"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

For example, the configuration file locations for Claude Desktop are:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

Merge the configuration into the existing `mcpServers`, save it, then restart or reconnect the client. Other clients that support stdio only need to enter the same command, arguments, and environment variables through their configuration entry points.

## Method 2: Connect to the Hosted MCP Server

Clients that support Streamable HTTP can configure the following connection information:

| Configuration Item | Content                                  |
| ------------------ | ---------------------------------------- |
| Server URL         | `https://acemusic.mcp.acedata.cloud/mcp` |
| Request Header     | `Authorization: Bearer YOUR_API_TOKEN`   |

For example, configure the following in VS Code's `.vscode/mcp.json`:

```json
{
  "servers": {
    "acemusic": {
      "type": "http",
      "url": "https://acemusic.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_TOKEN"
      }
    }
  }
}
```

After saving, connect to the server in the client and load the tools. The HTTP configuration format may differ across clients; please use that client's MCP settings entry point. If valid credentials are not provided, the server will reject the connection; if the client only supports OAuth, connect according to its authorization flow. Specific compatibility depends on the current support status of the client and server.

## Available Tools

| Tool                             | Purpose                                                        |
| -------------------------------- | -------------------------------------------------------------- |
| `acemusic_generate_music`        | Generate a song based on theme and style descriptions          |
| `acemusic_generate_custom_music` | Generate a song based on title, lyrics, and music style        |
| `acemusic_upload_audio`          | Import one reference audio track from a public HTTPS MP3 URL, billed separately |
| `acemusic_cover_audio`           | Create a cover using one of your own platform audio tracks     |
| `acemusic_mashup_audio`          | Fuse exactly two different and compatible platform audio tracks |
| `acemusic_generate_lyrics`       | Generate editable titles and lyrics, billed separately         |
| `acemusic_get_task`              | Query the status and result of one original task               |
| `acemusic_get_tasks_batch`       | Batch query original tasks, 1–50 per request                   |
| `acemusic_list_tasks`            | Paginate through your own history, up to 50 items per page     |
| `acemusic_list_models`           | View available models and the default model                    |
| `acemusic_get_capabilities`      | View supported operations and task recovery instructions       |

Basic song generation supports `acemusic-v1.1` (default) and `acemusic-v1`. Covers and fusion use `acemusic-v1.1`, require lyrics and style, and have an optional title; `audio_influence` ranges from 1–100, with a default of 60. The `audio_id` of a reference audio track comes from the audio track `id` in a completed task, and is different from `task_id`.

Currently, tools are not provided for instrumental-only control, style strength, continuation, stem separation, timbre, WAV, MIDI, or video export. Please refer to the actual tool parameters, and do not apply fields from other music services.

## From Lyrics to Song

After successfully connecting, you can tell the assistant:

> First help me write Chinese folk song lyrics about my hometown, and provide a title. Let me confirm the lyrics first, then generate the song.

After confirmation, say:

> Generate a song using the title and lyrics just confirmed. The style is warm folk music and acoustic guitar. After submitting once, save the task ID, query the same task, and after completion give me the playback and download links for the two candidates.

The assistant should perform the following steps:

1. Call the lyrics tool to generate a draft, allowing you to confirm or modify it.
2. Use the custom song tool to submit one creation and save the `task_id`.
3. Query the original task approximately every 10 seconds, gradually extending the interval according to the waiting situation.
4. Check the task and the status of each audio track, and return the `audio_url` of completed audio tracks. A complete song task contains two candidates; a reference upload task contains one audio track.

If you need to create a cover of an existing work, directly use the `audio_id` of a completed audio track. Only call the upload tool when you explicitly choose to import a new reference, to avoid additional reference upload charges.

## Task Status and Fees

`created`, `submitting`, `processing`, and `storing` indicate that the task is still being processed. `succeeded` indicates complete success, while `partial_failed` and `failed` are terminal states; in the case of partial failure, one playable candidate may still be retained. Song results are located in `response.data` of the task record.

If the status is `submission_unknown`, it means that the submission result requires further verification. Retain the original task ID, Trace ID, and request information, and do not automatically regenerate. The original task should likewise be queried first after a client timeout, disconnection, or restart.
Generation, cover, and remix are charged per complete dual-track group, with each group charged only once; no generation fee is charged for final failures or partial failures. Reference uploads and the lyrics assistant are charged separately per successful operation. Task queries are free but still require valid credentials and access permissions. Specific pricing is subject to the [ACE Music service page](https://platform.acedata.cloud/services/acemusic) and the actual application plan.

## Frequently Asked Questions

- **Cannot find the `uvx` command**: Install uv first, and make sure the AI client's runtime environment can find the command, then reconnect MCP.
- **Connection returns 401/403**: Check whether the API Token is correct, whether it has been revoked, and whether the credentials are allowed to access the relevant ACE Music APIs.
- **Insufficient balance or quota prompt**: Check the application balance and API Key quota in the console. Free queries still require task API permissions.
- **No audio received immediately after submission**: Generation is an asynchronous task; use the original `task_id` to query it. Successful acceptance does not mean that the audio has been delivered.
- **Need to view underlying API parameters**: Refer to the [Song and Reference Audio Integration Guide](https://platform.acedata.cloud/documents/acemusic-audios-integration), [Lyrics Generation Integration Guide](https://platform.acedata.cloud/documents/acemusic-lyrics-integration), and [Task Query Integration Guide](https://platform.acedata.cloud/documents/acemusic-tasks-integration). For MCP installation and version information, see the [project repository](https://github.com/AceDataCloud/MCPs/tree/main/acemusic).
