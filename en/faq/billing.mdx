## How do Credits relate to USD?

The platform deducts **Credits** internally and displays USD as a reference.

- Packages convert USD → Credits at purchase time
- Current reference rate: ~`$0.095215 / Credit` (≈ 10.5 Credits = $1)
- The rate moves over time; **already-purchased packages are not retroactively affected**

Formula:

```
Credits needed = USD quote / (package.price / package.amount)
```

## When does billing happen?

| Call type | When |
|---|---|
| Sync LLM (chat completions) | On response, by `usage.total_tokens` |
| Async generation (image / video / audio) | When the task reaches **success** — failures don't bill |
| Moderation rejection (HTTP 403) | No charge |
| Upstream 5xx / timeout | No charge |
| 4xx (bad request) | No charge |
| Polling (`/tasks`) | Always free |

## Balance order

1. **Service quota** — bundled with subscription, single-service
2. **Global balance** — universal

Behavior:

- Service quota deducted first
- If exhausted and the Application has `allow_consume_global` enabled, global balance picks up
- Both exhausted → HTTP `402 insufficient_balance`

## Refunds

- **Task failure / outage**: auto no-charge
- **User error / wrong prompt**: completed work is not refunded; you can file an appeal at `support@acedata.cloud` with the `trace_id`
- **Mass incidents (upstream outage)**: submit a list of `trace_id`s — confirmed cases get **full refund**

## Precision

- Internal precision: 6-decimal Credits
- Per-charge floor: `0.000001 Credit`
- Statements: rounded to 4 decimals
