## Introduction

Image2Text is a captcha service provided by Ace Data Cloud for image captcha recognition. Through the unified API of Ace Data Cloud, you can quickly call Image2Text using cURL to achieve image captcha recognition, Base64 input, URL input, and other functions.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Terminal environment with cURL installed

## Basic Usage

The main endpoint for calling the Image2Text API is:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}'
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Using jq to Process Response

It is recommended to use the jq tool for formatted output:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                          |
|-------------|------------------------------------|
| 401         | Authentication failed, please check API Token |
| 403         | Insufficient balance or no access  |
| 429         | Request rate limit exceeded         |
| 500         | Internal server error               |
