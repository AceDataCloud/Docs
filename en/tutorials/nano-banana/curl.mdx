## Introduction

Nano Banana is an AI image service provided by Ace Data Cloud, based on Gemini's image generation service. Through the unified API of Ace Data Cloud, you can quickly call Nano Banana using cURL to achieve text-to-image, image editing, multiple aspect ratios, high resolution, and other features.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Terminal environment with cURL installed

## Basic Usage

The main endpoint for calling the Nano Banana API is:

```
POST https://api.acedata.cloud/nano-banana/images
```

This example uses the `nano-banana-2` model.  
Available models include: `nano-banana`, `nano-banana-2`, `nano-banana-pro`.

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat", "model": "nano-banana-2", "aspect_ratio": "1:1"}'
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Processing Response with jq

It is recommended to use the jq tool for formatted output:

```bash
curl -s -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat", "model": "nano-banana-2", "aspect_ratio": "1:1"}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                       |
|-------------|---------------------------------|
| 401         | Authentication failed, please check API Token |
| 403         | Insufficient balance or no access rights |
| 429         | Request rate limit exceeded      |
| 500         | Internal server error            |
