## Introduction

Luma is an AI video service provided by Ace Data Cloud, featuring Luma Dream Machine video generation. Through the unified API of Ace Data Cloud, you can quickly call Luma using cURL to achieve text-to-video, image-to-video, video continuation, start/end frame control, looped videos, and more.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Terminal environment with cURL installed

## Basic Usage

The main endpoint for calling the Luma API is:

```
POST https://api.acedata.cloud/luma/videos
```

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}'
```

Please replace `YOUR_API_TOKEN` with the actual token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Processing Response with jq

It is recommended to use the jq tool for formatted output:

```bash
curl -s -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                       |
|-------------|---------------------------------|
| 401         | Authentication failed, please check the API Token |
| 403         | Insufficient balance or no access rights |
| 429         | Request rate limit exceeded      |
| 500         | Internal server error            |
