## Introduction

Identity is an authentication service provided by Ace Data Cloud for real-name verification of ID cards, bank cards, and phone numbers. Through the unified API of Ace Data Cloud, you can quickly integrate Identity using JavaScript to achieve functionalities such as ID card OCR, ID card verification, bank card verification, and phone number verification.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Node.js 18+ or a modern browser environment

## Basic Usage

The main endpoint for calling the Identity API is:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Complete JavaScript code example:

```javascript
const response = await fetch("https://api.acedata.cloud/identity/idcard/ocr", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "image_url": "https://example.com/idcard-front.jpg"
}),
});

const result = await response.json();
console.log(result);
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Handling

It is recommended to check the response status code and handle errors:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Call succeeded:", result);
} else {
  console.error(`Call failed, status code: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js Wrapper

It is recommended to encapsulate as a reusable function:

```javascript
async function callIdentity(data) {
  const response = await fetch("https://api.acedata.cloud/identity/idcard/ocr", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Error Handling

Common error codes:

| Status Code | Description                      |
|-------------|--------------------------------|
| 401         | Authentication failed, please check API Token |
| 403         | Insufficient balance or no access permission |
| 429         | Request rate limit exceeded     |
| 500         | Internal server error           |
