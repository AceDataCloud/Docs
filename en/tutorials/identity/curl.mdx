## Introduction

Identity is an authentication service provided by Ace Data Cloud for real-name verification of ID cards, bank cards, and phone numbers. Through the unified API of Ace Data Cloud, you can quickly call Identity using cURL to perform functions such as ID card OCR, ID card verification, bank card verification, and phone number verification.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Terminal environment with cURL installed

## Basic Usage

The main endpoint for calling the Identity API is:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}'
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Using jq to Process the Response

It is recommended to use the jq tool for formatted output:

```bash
curl -s -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                     |
|-------------|--------------------------------|
| 401         | Authentication failed, please check API Token |
| 403         | Insufficient balance or no access rights |
| 429         | Request rate limit exceeded     |
| 500         | Internal server error           |
