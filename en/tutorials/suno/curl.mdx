## Introduction

Suno is an AI audio service provided by Ace Data Cloud, offering Suno AI music generation. Through the unified API of Ace Data Cloud, you can quickly call Suno using cURL to achieve features such as text-to-music generation, custom lyrics, song continuation, cover singing, vocal separation, and lyric generation.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Terminal environment with cURL installed

## Basic Usage

The main endpoint for calling the Suno API is:

```
POST https://api.acedata.cloud/suno/audios
```

This example uses the `chirp-v5` model.  
Available models include: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`.

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}'
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Processing Response with jq

It is recommended to use the jq tool for formatted output:

```bash
curl -s -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                      |
|-------------|--------------------------------|
| 401         | Authentication failed, please check API Token |
| 403         | Insufficient balance or no access rights |
| 429         | Request rate limit exceeded     |
| 500         | Internal server error           |
