## Introduction

Fish TTS is an AI audio service provided by Ace Data Cloud, offering Fish speech synthesis services. Through the unified API of Ace Data Cloud, you can quickly call Fish TTS using cURL to achieve text-to-speech, multiple voice tones, custom voices, and other features.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- A terminal environment with cURL installed

## Basic Usage

The main endpoint to call the Fish TTS API is:

```
POST https://api.acedata.cloud/fish/audios
```

This example uses the `fish-tts` model.  
Available models include: `fish-tts`.

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/fish/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "speech", "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务", "voice_id": "d7900c21663f485ab63ebdb7e5905036", "model": "fish-tts"}'
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Processing Response with jq

It is recommended to use the jq tool for formatted output:

```bash
curl -s -X POST https://api.acedata.cloud/fish/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "speech", "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务", "voice_id": "d7900c21663f485ab63ebdb7e5905036", "model": "fish-tts"}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                      |
|-------------|--------------------------------|
| 401         | Authentication failed, please check API Token |
| 403         | Insufficient balance or no access rights |
| 429         | Request rate limit exceeded     |
| 500         | Internal server error           |
