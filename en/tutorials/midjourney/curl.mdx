## Introduction

Midjourney is an AI image service provided by Ace Data Cloud, offering Midjourney AI image generation. Through the unified API of Ace Data Cloud, you can quickly call Midjourney using cURL to achieve text-to-image, image editing, image description, image-to-video, Seed control, asynchronous callbacks, and other functions.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Terminal environment with cURL installed

## Basic Usage

The main endpoint for calling the Midjourney API is:

```
POST https://api.acedata.cloud/midjourney/imagine
```

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}'
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Using jq to Process the Response

It is recommended to use the jq tool for formatted output:

```bash
curl -s -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                      |
|-------------|--------------------------------|
| 401         | Authentication failed, please check API Token |
| 403         | Insufficient balance or no access rights |
| 429         | Request rate limit exceeded    |
| 500         | Internal server error          |
