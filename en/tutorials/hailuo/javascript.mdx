## Introduction

Hailuo is an AI video service provided by Ace Data Cloud, featuring the MiniMax Hailuo video generation model. Through the unified API of Ace Data Cloud, you can quickly integrate Hailuo using JavaScript to achieve text-to-video, image-to-video, director mode, and other functions.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Node.js 18+ or a modern browser environment

## Basic Usage

The main endpoint for calling the Hailuo API is:

```
POST https://api.acedata.cloud/hailuo/videos
```

This example uses the `minimax-t2v` model.  
Available models include: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Complete JavaScript code example:

```javascript
const response = await fetch("https://api.acedata.cloud/hailuo/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "model": "minimax-t2v",
  "prompt": "A golden sunset over the ocean waves"
}),
});

const result = await response.json();
console.log(result);
```

Please replace `YOUR_API_TOKEN` with the actual token you obtained from the Ace Data Cloud platform.

## Response Handling

It is recommended to check the response status code and handle errors:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Call succeeded:", result);
} else {
  console.error(`Call failed, status code: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js Wrapper

It is recommended to encapsulate the call into a reusable function:

```javascript
async function callHailuo(data) {
  const response = await fetch("https://api.acedata.cloud/hailuo/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Error Handling

Common error codes:

| Status Code | Description                      |
|-------------|--------------------------------|
| 401         | Authentication failed, please check API Token |
| 403         | Insufficient balance or no access permission |
| 429         | Request rate limit exceeded     |
| 500         | Internal server error           |
