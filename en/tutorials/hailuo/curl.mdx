## Introduction

Hailuo is an AI video service provided by Ace Data Cloud, featuring the MiniMax Hailuo video generation model. Through the unified API of Ace Data Cloud, you can quickly call Hailuo using cURL to achieve text-to-video, image-to-video, director mode, and other functions.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Terminal environment with cURL installed

## Basic Usage

The main endpoint for calling the Hailuo API is:

```
POST https://api.acedata.cloud/hailuo/videos
```

This example uses the `minimax-t2v` model.  
Available models include: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}'
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Using jq to Process the Response

It is recommended to use the jq tool to format the output:

```bash
curl -s -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                      |
|-------------|--------------------------------|
| 401         | Authentication failed, please check the API Token |
| 403         | Insufficient balance or no access permission |
| 429         | Request rate limit exceeded    |
| 500         | Internal server error          |
