## Introduction

ADSL HTTP Proxy is a network proxy service provided by Ace Data Cloud, offering ADSL dynamic proxy IP extraction. Through the unified API of Ace Data Cloud, you can quickly call ADSL HTTP Proxy using cURL to achieve HTTP/SOCKS proxy, multi-operator, multi-province, custom duration, IP whitelist, and other features.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Terminal environment with cURL installed

## Basic Usage

The main endpoint for calling the ADSL HTTP Proxy API is:

```
POST https://api.acedata.cloud/adsl/extract
```

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}'
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Processing Response with jq

It is recommended to use the jq tool to format the output:

```bash
curl -s -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                          |
|-------------|------------------------------------|
| 401         | Authentication failed, please check API Token |
| 403         | Insufficient balance or no access  |
| 429         | Request rate limit exceeded         |
| 500         | Internal server error               |
