## Introduction

ADSL HTTP Proxy is a network proxy service provided by Ace Data Cloud, offering dynamic ADSL proxy IP extraction. Through the unified API of Ace Data Cloud, you can quickly integrate ADSL HTTP Proxy using Python to achieve HTTP/SOCKS proxy, multi-operator, multi-province, custom duration, IP whitelist, and other features.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Python 3.7 or above environment
- Install the requests library: `pip install requests`

## Basic Usage

The main endpoint for calling the ADSL HTTP Proxy API is:

```
POST https://api.acedata.cloud/adsl/extract
```



Complete Python code example:

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "number": 5,
    "type": "http",
    "duration": 300,
    "province": "广东",
    "isp": "电信"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Handling

After a successful call, the API returns data in JSON format. It is recommended to check the HTTP status code:

```python
if response.status_code == 200:
    result = response.json()
    print("Call succeeded:", result)
else:
    print(f"Call failed, status code: {response.status_code}")
    print(response.text)
```

## Advanced Usage

For APIs that support asynchronous tasks, you can get the results via a callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# The results will be pushed to your server through the callback URL
```

## Error Handling

Common error codes:

| Status Code | Description |
|-------------|-------------|
| 401 | Authentication failed, please check the API Token |
| 403 | Insufficient balance or no access permission |
| 429 | Request rate limit exceeded |
| 500 | Internal server error |
