## Introduction

reCAPTCHA is a captcha service provided by Ace Data Cloud, based on the Google reCAPTCHA solution. Through the unified API of Ace Data Cloud, you can quickly call reCAPTCHA using cURL to achieve functions such as reCAPTCHA v2 Token, reCAPTCHA v2 recognition, reCAPTCHA v3 Token, and more.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- A terminal environment with cURL installed

## Basic Usage

The main endpoint to call the reCAPTCHA API is:

```
POST https://api.acedata.cloud/captcha/token/recaptcha2
```

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/captcha/token/recaptcha2 \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-", "website_url": "https://www.google.com/recaptcha/api2/demo"}'
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Using jq to Process the Response

It is recommended to use the jq tool for formatted output:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/token/recaptcha2 \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-", "website_url": "https://www.google.com/recaptcha/api2/demo"}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                      |
|-------------|--------------------------------|
| 401         | Authentication failed, please check API Token |
| 403         | Insufficient balance or no access permission |
| 429         | Request rate limit exceeded    |
| 500         | Internal server error          |
