## Introduction

Producer is an AI audio service provided by Ace Data Cloud, FUZZ Producer AI music generation. Through the unified API of Ace Data Cloud, you can quickly call Producer using cURL to achieve functions such as text-to-music generation, custom lyrics, song continuation, cover singing, vocal separation, MV generation, and more.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Terminal environment with cURL installed

## Basic Usage

The main endpoint for calling the Producer API is:

```
POST https://api.acedata.cloud/producer/audios
```

This example uses the `FUZZ-2.0 Pro` model.  
Available models include: `FUZZ-2.0 Pro`, `FUZZ-2.0`, `FUZZ-1.1 Pro`, `FUZZ-1.0 Pro`.

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/producer/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A relaxing jazz piece for a coffee shop", "model": "FUZZ-2.0 Pro", "lyric": "[Verse]\nSoft piano keys in the morning light", "custom": true}'
```

Please replace `YOUR_API_TOKEN` with the actual token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Processing Response with jq

It is recommended to use the jq tool for formatted output:

```bash
curl -s -X POST https://api.acedata.cloud/producer/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A relaxing jazz piece for a coffee shop", "model": "FUZZ-2.0 Pro", "lyric": "[Verse]\nSoft piano keys in the morning light", "custom": true}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                      |
|-------------|--------------------------------|
| 401         | Authentication failed, please check API Token |
| 403         | Insufficient balance or no access rights |
| 429         | Request rate limit exceeded     |
| 500         | Internal server error           |
