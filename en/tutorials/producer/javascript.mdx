## Introduction

Producer is an AI audio service provided by Ace Data Cloud, FUZZ Producer AI music generation. Through the unified API of Ace Data Cloud, you can quickly integrate Producer using JavaScript to achieve functions such as text-to-music generation, custom lyrics, song continuation, cover singing, vocal separation, MV generation, and more.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Node.js 18+ or a modern browser environment

## Basic Usage

The main endpoint for calling the Producer API is:

```
POST https://api.acedata.cloud/producer/audios
```

This example uses the `FUZZ-2.0 Pro` model.  
Available models include: `FUZZ-2.0 Pro`, `FUZZ-2.0`, `FUZZ-1.1 Pro`, `FUZZ-1.0 Pro`.

Complete JavaScript code example:

```javascript
const response = await fetch("https://api.acedata.cloud/producer/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A relaxing jazz piece for a coffee shop",
  "model": "FUZZ-2.0 Pro",
  "lyric": "[Verse]\nSoft piano keys in the morning light",
  "custom": true
}),
});

const result = await response.json();
console.log(result);
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Handling

It is recommended to check the response status code and handle errors:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Call succeeded:", result);
} else {
  console.error(`Call failed, status code: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js Wrapper

It is recommended to encapsulate it as a reusable function:

```javascript
async function callProducer(data) {
  const response = await fetch("https://api.acedata.cloud/producer/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Error Handling

Common error codes:

| Status Code | Description                          |
|-------------|------------------------------------|
| 401         | Authentication failed, please check API Token |
| 403         | Insufficient balance or no access  |
| 429         | Request rate limit exceeded         |
| 500         | Internal server error               |
