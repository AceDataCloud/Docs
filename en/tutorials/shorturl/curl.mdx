## Introduction

Short URL is a tool service provided by Ace Data Cloud for generating short links. Through the unified API of Ace Data Cloud, you can quickly call Short URL using cURL to achieve URL shortening, custom domains, and other functions.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- A terminal environment with cURL installed

## Basic Usage

The main endpoint for calling the Short URL API is:

```
POST https://api.acedata.cloud/shorturl
```

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}'
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Processing Response with jq

It is recommended to use the jq tool for formatted output:

```bash
curl -s -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                  |
|-------------|------------------------------|
| 401         | Authentication failed, please check the API Token |
| 403         | Insufficient balance or no access permission |
| 429         | Request rate limit exceeded  |
| 500         | Internal server error        |
