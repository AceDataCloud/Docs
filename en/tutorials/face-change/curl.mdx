## Introduction

Face Change is an AI image service provided by Ace Data Cloud, specializing in AI face processing. Through the unified API of Ace Data Cloud, you can quickly call Face Change using cURL to achieve face swapping, face beautification, age transformation, gender transformation, animation style, face analysis, and other functions.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Terminal environment with cURL installed

## Basic Usage

The main endpoint for calling the Face Change API is:

```
POST https://api.acedata.cloud/face/swap
```

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}'
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Using jq to Process the Response

It is recommended to use the jq tool for formatted output:

```bash
curl -s -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                      |
|-------------|--------------------------------|
| 401         | Authentication failed, please check the API Token |
| 403         | Insufficient balance or no access rights |
| 429         | Request rate limit exceeded    |
| 500         | Internal server error          |
