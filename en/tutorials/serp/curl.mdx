## Introduction

Google Search is a search service provided by Ace Data Cloud, offering the Google Search API. Through the unified API of Ace Data Cloud, you can quickly call Google Search using cURL to perform web search, image search, news search, map search, video search, and more.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- A terminal environment with cURL installed

## Basic Usage

The main endpoint for calling the Google Search API is:

```
POST https://api.acedata.cloud/serp/google
```

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}'
```

Please replace `YOUR_API_TOKEN` with the actual Token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Processing Response with jq

It is recommended to use the jq tool for formatted output:

```bash
curl -s -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                      |
|-------------|--------------------------------|
| 401         | Authentication failed, please check API Token |
| 403         | Insufficient balance or no access rights |
| 429         | Request rate limit exceeded    |
| 500         | Internal server error          |
