## Introduction

Sora is an AI video service provided by Ace Data Cloud, featuring the OpenAI Sora video generation model. Through the unified API of Ace Data Cloud, you can quickly call Sora using cURL to generate videos from text, with features such as multiple durations, landscape or portrait orientation, character control, reference images, and more.

## Prerequisites

- Have an [Ace Data Cloud](https://platform.acedata.cloud) account and obtain an API Token
- Terminal environment with cURL installed

## Basic Usage

The main endpoint for calling the Sora API is:

```
POST https://api.acedata.cloud/sora/videos
```

This example uses the `sora-2` model.  
Available models include: `sora-2`, `sora-2-pro`.

Complete cURL command example:

```bash
curl -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}'
```

Please replace `YOUR_API_TOKEN` with the actual token you obtained from the Ace Data Cloud platform.

## Response Example

A successful call returns data in JSON format, for example:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Using jq to Process the Response

It is recommended to use the jq tool for formatted output:

```bash
curl -s -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}' | jq .
```

## Error Handling

Common error codes:

| Status Code | Description                      |
|-------------|--------------------------------|
| 401         | Authentication failed, please check API Token |
| 403         | Insufficient balance or no access permission |
| 429         | Request rate limit exceeded     |
| 500         | Internal server error           |
