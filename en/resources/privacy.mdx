## Google API Services User Data Policy (Limited Use)

When you choose to connect Ace Data Cloud with Google services (including Google Workspace API, Google Drive, Gmail, Google Calendar, etc.), our use and transmission of any information received from the Google API fully comply with the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the **Limited Use** requirements. Specifically:

1. **Only for Requested Features**: We access your Google data only when you actively request and enable a feature (e.g., reading your Drive files, sending calendar invites, organizing Gmail emails), and solely to implement that feature.

2. **No Use for Advertising**: We never use data obtained from the Google API for advertising, ad targeting, or third-party marketing purposes.

3. **No Sale to Third Parties**: We never sell user data obtained from the Google API.

4. **No Transfer to Third Parties**: Except under the following circumstances, we do not transfer data obtained from the Google API to any other party: (a) necessary to provide or improve user-facing features; (b) for security purposes (e.g., abuse investigations); (c) to comply with applicable laws; or (d) as part of a merger, acquisition, or asset sale, with user consent.

5. **No Manual Reading Allowed**: We do not allow any manual personnel to read data obtained from the Google API unless: (a) you have given explicit consent; (b) for security purposes (e.g., abuse investigations); (c) to comply with applicable laws; or (d) the data has been aggregated and anonymized for internal operations only.

If you wish to revoke Ace Data Cloud’s access to your Google account at any time, you can do so at the [Google Account Connected Apps](https://myaccount.google.com/connections) page.
