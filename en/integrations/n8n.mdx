---
title: "Use AceDataCloud in n8n"
description: "Import a chat workflow and connect it to your AceDataCloud API token."
---

Use n8n's HTTP Request node to call AceDataCloud. The [sample workflow](https://raw.githubusercontent.com/AceDataCloud/Docs/main/examples/n8n/acedatacloud-chat.json) sends a prompt to the Chat Completions API and returns the response and token usage. It uses only built-in n8n nodes.

## Import the workflow

1. Create an [AceDataCloud API token](https://platform.acedata.cloud/console/applications).
2. In n8n, create a workflow and choose **Import from URL**. Paste the [sample workflow URL](https://raw.githubusercontent.com/AceDataCloud/Docs/main/examples/n8n/acedatacloud-chat.json). You can also download the JSON file and choose **Import from File**.
3. Open **AceDataCloud chat**. Under **Authentication → Generic Credential Type**, select **Bearer Auth** and create a credential containing your AceDataCloud token. Paste only the token; n8n adds the `Bearer ` prefix. Save the credential and select it in this node.
4. In **Set prompt and model**, replace the sample prompt and choose a [supported chat model](https://platform.acedata.cloud/documents/openai-chat-completions).
5. Select **Execute workflow**. The HTTP Request output contains `choices[0].message.content` and `usage`.

Keep the token in the n8n credential. Do not put it in the workflow JSON or a Set node. Each execution calls a billable API; review the model's current price before activating a schedule or webhook.

## Customize the flow

Replace the manual trigger with your own trigger. Map its text to `prompt` in **Set prompt and model**. The HTTP Request node sends a non-streaming `POST` to `https://api.acedata.cloud/v1/chat/completions`; n8n can then pass the result to another node. For the request and response schema, see [Chat Completions](/en/guides/openai/openai_chat_completions).

If the request fails, check the node's selected credential, whether the token was pasted without a `Bearer ` prefix, the model name, and your available balance. An authentication or billing error should be fixed before rerunning the workflow.
