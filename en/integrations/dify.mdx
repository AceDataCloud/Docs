---
title: "Use AceDataCloud models in Dify"
description: "Configure an OpenAI API-compatible model provider in Dify."
---

Dify's OpenAI API-compatible model provider can call AceDataCloud chat models. You can configure a model in Dify without installing an AceDataCloud plugin.

## Configure the model

1. Create an [AceDataCloud API token](https://platform.acedata.cloud/console/applications).
2. In Dify, open **Settings → Model Provider** and install [OpenAI-API-compatible](https://marketplace.dify.ai/plugin/langgenius/openai_api_compatible) from the Marketplace if it is not already installed.
3. Add a chat model using these values:

| Field | Value |
| --- | --- |
| API Base URL | `https://api.acedata.cloud/v1` |
| API key | Your AceDataCloud token |
| Model name | `gpt-5.5`, or another [supported chat model](https://platform.acedata.cloud/documents/openai-chat-completions) |
| Model type | LLM |
| Completion mode | Chat |
| API type | Chat Completions API |

4. Save and test the model, then select it in a Dify **LLM** node.

The Base URL ends in `/v1`. Do not add `/chat/completions`; Dify adds the operation path. The older `/openai/v1` URL does not serve this endpoint.

Each test or workflow run uses your AceDataCloud balance. Check the model's current price and Dify's retry settings before publishing a workflow. Keep the API key in Dify's provider credential settings, never in a prompt or workflow export.

For the request and response schema, see [Chat Completions](/en/guides/openai/openai_chat_completions).
