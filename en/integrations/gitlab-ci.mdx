---
title: "Call AceDataCloud from GitLab CI"
description: "Run a manual pipeline job that summarizes a commit title with a chat model."
---

Use a GitLab CI job to call the AceDataCloud Chat Completions API. The [sample pipeline](https://raw.githubusercontent.com/AceDataCloud/Docs/main/examples/gitlab/acedatacloud-chat.gitlab-ci.yml) summarizes the latest commit title and saves the result as a short-lived artifact. The job is manual and runs only on the default branch.

## Set up the job

1. Create an [AceDataCloud API token](https://platform.acedata.cloud/console/applications).
2. In your GitLab project, open **Settings → CI/CD → Variables**. Add `ACEDATACLOUD_API_TOKEN` as a masked and hidden variable. Protect the variable and the default branch.
3. Copy the [sample pipeline YAML](https://raw.githubusercontent.com/AceDataCloud/Docs/main/examples/gitlab/acedatacloud-chat.gitlab-ci.yml) into your `.gitlab-ci.yml`. If your pipeline already has `stages`, add `report` to that list and copy only the job.
4. Run a pipeline on the default branch, start the manual **acedatacloud_commit_summary** job, and download `summary.txt` from its artifacts.

The job sends `CI_COMMIT_TITLE` to AceDataCloud. Do not send confidential commit text unless your project's data policy allows it. Each manual run makes one billable API request; check the model's current price before enabling other triggers. The token stays in GitLab's CI/CD variable store and is not written to the artifact.

To summarize a different input, change the `jq --arg title` line and the prompt in the sample. Keep the token in the CI/CD variable and encode user-controlled text with `jq --arg`, not shell string interpolation inside JSON. The request schema is documented in [Chat Completions](/en/guides/openai/openai_chat_completions).

This is a copyable CI example. Publishing a reusable component to the [GitLab CI/CD Catalog](https://docs.gitlab.com/ci/components/) requires a GitLab-hosted component project and a release.
