---
title: "Use AceDataCloud in Open WebUI"
description: "Connect an AceDataCloud chat model through Open WebUI's OpenAI-compatible provider."
---

Open WebUI supports OpenAI-compatible Chat Completions endpoints. Connect it directly to AceDataCloud; no custom Pipe or provider module is needed.

## Add the connection

1. Create an [AceDataCloud API token](https://platform.acedata.cloud/console/applications).
2. In Open WebUI, open **Settings → Admin → Connections**. Under **Manage OpenAI API Connections**, choose **Add Connection**.
3. Enter `https://api.acedata.cloud/v1` as the URL and your AceDataCloud token as the API key.
4. Add `gpt-5.5` to **Model IDs** if it is not discovered automatically. Save the connection, select that model in a new chat, and send a short prompt.

Open WebUI's **Verify Connection** calls `/models`; a failed discovery check is not proof that Chat Completions failed. If it fails, add the model ID manually and test an actual chat request. AceDataCloud's `/v1/models` and `/v1/chat/completions` routes accept the same Bearer token. Use only models listed in the [current catalog](https://platform.acedata.cloud/documents/openai-chat-completions).

Keep the token in Open WebUI's connection settings. Each test prompt can incur API charges; check the model's current price. For protocol details, see [Chat Completions](/en/guides/openai/openai_chat_completions) and the [Open WebUI provider guide](https://docs.openwebui.com/getting-started/quick-start/connect-a-provider/starting-with-openai-compatible/).
