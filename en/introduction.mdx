Ace Data Cloud provides APIs for text responses, images, songs, video, speech, search and data tools. Follow the [illustrated API key steps](https://platform.acedata.cloud/documents/platform-credential-create?lang=en) to connect your application to the services available to your account. Each service guide includes its supported operations, request fields and output format.

For a text reply, try [Chat Completions](https://platform.acedata.cloud/documents/openai-chat-completions-integration?lang=en). To generate images or music, start with [GPT Image 2.6](https://platform.acedata.cloud/models/gpt-image-2.6-flare?m=image&lang=en), [ACE Music](https://platform.acedata.cloud/documents/acemusic-audios-integration?lang=en), or [Suno](https://platform.acedata.cloud/documents/suno-audios-integration?lang=en). Long-running generation returns a task ID that you use to retrieve the final result. See [async tasks](https://platform.acedata.cloud/documents/acemusic-tasks-integration?lang=en) for a complete example.

For application code, use the [SDK guide](https://platform.acedata.cloud/documents/acedatacloud-sdk?lang=en). To connect an assistant or workflow, follow the [MCP setup guide](https://platform.acedata.cloud/documents/mcp-tutorials-claude-desktop?lang=en).
