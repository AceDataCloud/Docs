## What is Ace Data Cloud?

Ace Data Cloud is a unified AI API platform that provides access to leading AI services worldwide through a single API Key and consistent interface.

## Core Advantages

- **Unified API** — Access 50+ AI services with a single API Key
- **OpenAI Compatible** — Directly call Claude, Gemini, and others via OpenAI interface
- **Interactive Sandbox** — Test each API directly within the documentation
- **Pay-as-you-go** — No subscription fees, pay based on actual usage
- **MCP Server** — Native support for AI programming tools like Cursor, Claude, and more
