Ace Data Cloud provides APIs for text responses, images, songs, video, speech, search and data tools. Use an application API key with the services available to your account. Each service guide includes its supported operations, request fields and output format.

Start with [GPT Image 2.6](https://platform.acedata.cloud/models/gpt-image-2.6-flare?m=image&lang=en), [ACE Music](/en/guides/acemusic/acemusic_audios), or [Suno](/en/guides/suno/suno_audios). Long-running generation returns a task ID that you use to retrieve the final result. See [async tasks](/en/concepts/async-tasks) for a complete example.

For application code, use the [SDK guide](/en/guides/platform/sdk). To connect an assistant or workflow, browse [n8n workflows](/en/integrations/n8n) and [MCP](/en/mcp/overview).
