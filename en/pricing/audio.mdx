---
title: "Audio & Music Pricing"
description: "Per-track pricing for Suno, Producer and Fish Audio."
---

Audio / music generation is billed **per track** or **per synthesis call**.

## Suno

| Operation | Unit Price (USD) | Note |
|---|---|---|
| `/generate` | $0.08 | Returns 2 songs |
| Custom mode | $0.08 | Custom lyrics / style |
| Extend | $0.05 | Lengthen existing song |
| Cover | $0.10 | Re-rendition / remix |
| Lyrics | $0.005 | Lyrics only |
| Persona (vocal) | $0.05 | Vocal replacement |
| Vocal / Instrumental split | $0.02 | Stem extraction |
| WAV / MIDI / MP4 export | $0.01 | Per format |

## Producer (FUZZ)

| Operation | Unit Price (USD) |
|---|---|
| Generate | $0.08 |
| Custom | $0.08 |
| Extend | $0.05 |
| Cover | $0.10 |
| Vocal swap | $0.05 |
| Instrumental swap | $0.05 |
| Lyrics | $0.005 |
| Upload reference | $0.01 |

## Fish Audio (TTS)

| Operation | Unit Price |
|---|---|
| Text-to-speech | $0.015 / 1k chars |
| Voice clone (single shot) | $0.05 / call |
| Custom voice model | Console quote |

## Rules

- Charged when the task reaches **success**
- `failed` / upstream timeout = no charge
- A 2-song generation = **one** charge
- Multiple format exports (MP3 / WAV / MIDI / MP4) of the same track are billed separately

<Note>
  Reference only. Live prices: [platform.acedata.cloud](https://platform.acedata.cloud).
</Note>
