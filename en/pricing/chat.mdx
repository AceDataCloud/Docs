LLM chat endpoints are priced **per token** with separate input / output rates. All prices below are **per 1M tokens**.

## Formula

```
USD = prompt_tokens × prompt_price + completion_tokens × completion_price
```

The `usage` field of each response returns `prompt_tokens` and `completion_tokens`.

## Caching & Discounts

- Some providers (Anthropic, Gemini) support **prompt caching**; hits drop the input rate significantly
- Streaming (`stream: true`) doesn't change pricing
- Function-calling tokens are counted normally

## No Charge

- Malformed request (400)
- Invalid token (401)
- Insufficient balance (402)
- Moderation rejection (403)
- Upstream 5xx
