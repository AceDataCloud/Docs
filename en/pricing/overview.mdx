Ace Data Cloud uses **pay-as-you-go** billing — no monthly subscription fees. You're charged only when a request actually succeeds.

## Currency

- The console displays **USD** as the reference price
- Internally, the platform deducts **Credits**; packages convert USD → Credits at purchase time
- Full details in [FAQ — Billing](/en/faq/billing)

## When You Get Charged

| API type | Trigger |
|---|---|
| Sync (Chat) | On response, by token / character count |
| Async (Image / Video / Audio) | When the task reaches **success** — failures don't bill |
| Moderation rejection (403) | **No charge** |
| Upstream timeout / 5xx | **No charge** |

## Discounts

- **$ACE token staking** unlocks auto-stacking discounts. See [Token program](https://platform.acedata.cloud/coin)
- **Enterprise volume**: tiered rebates above $5k/month, contact `sales@acedata.cloud`

## Live Prices

The console is always authoritative:

1. Sign in at [platform.acedata.cloud](https://platform.acedata.cloud)
2. Open any service detail page
3. Check the **Pricing** tab for current USD prices

<Note>
  Pricing in these docs is updated periodically but **can lag**. When in doubt, trust the console.
</Note>

## Balance & Quota

- **Service quota**: included with each subscription, only spendable on that service
- **Global balance**: works across all services
- Deduction order: service quota → global balance
- Once exhausted, requests return `402 insufficient_balance`

See [FAQ — Billing](/en/faq/billing) for details.
