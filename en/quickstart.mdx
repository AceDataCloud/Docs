Start with a text response, or choose an image, music, video, or search API below.

## Get your API key

Sign in to [Applications](https://platform.acedata.cloud/console/applications?lang=en&utm_source=docs&utm_medium=referral&utm_campaign=evergreen) and open **General Application**. If it is missing, select **Initialize General Application**. Click the copy button marked **1** beside **API KEY**.

![The copy button marked 1 beside API KEY on the General Application card](https://raw.githubusercontent.com/AceDataCloud/NanoBananaDify/2522b2f57210597af2db866445319334a1677a23/_assets/tutorial/get-api-key-en.png)

Check the selected model's [price](https://platform.acedata.cloud/models?lang=en) and your application balance.

Save the raw key in your terminal environment.

```bash
export ACEDATACLOUD_API_KEY="YOUR_API_KEY"
```

## Send a request

Run this command from your terminal or backend. It requests one short text response.

```bash
curl --fail-with-body https://api.acedata.cloud/v1/chat/completions \
  --header "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-6-luna",
    "messages": [{"role": "user", "content": "Say hello in one sentence."}]
  }'
```

## Read the result

A successful HTTP `200` response contains fields like these. This example illustrates the response structure. Read the answer from `choices[0].message.content`; `finish_reason` describes why it ended.

```json
{
  "id": "chatcmpl-example",
  "object": "chat.completion",
  "model": "gpt-6-luna",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "finish_reason": "stop"
    }
  ]
}
```

If the response contains `error`, use its `code` and `message` to resolve the request. Keep `trace_id` when contacting support. The [Chat API guide](https://platform.acedata.cloud/documents/openai-chat-completions-integration?lang=en) covers the response fields.
