This guide walks you through your first API call: submit a Midjourney text-to-image task and poll for the result.

## 1. Get an API Token

<Steps>
  <Step title="Sign up & log in">
    Go to [platform.acedata.cloud](https://platform.acedata.cloud). Trial credits are added automatically.
  </Step>
  <Step title="Subscribe">
    Open the [Midjourney service page](https://platform.acedata.cloud/services) and click **Get**.
  </Step>
  <Step title="Create a credential">
    Inside the service, open **Credentials** → **Create credential**. Copy the token.
  </Step>
</Steps>

More on tokens in [Gateway & Authentication](/en/authentication).

## 2. Submit Your First Task

Every request needs `Authorization: Bearer YOUR_API_TOKEN`. The example below submits a Midjourney image generation:

<CodeGroup>

```bash cURL
curl -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "a cute kitten playing with yarn, studio lighting",
    "callback_url": "https://your-server.com/webhook"
  }'
```

```python Python
import requests

resp = requests.post(
    "https://api.acedata.cloud/midjourney/imagine",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "a cute kitten playing with yarn, studio lighting",
        "callback_url": "https://your-server.com/webhook",
    },
    timeout=300,
)
data = resp.json()
print(data)
```

```javascript Node.js
const res = await fetch("https://api.acedata.cloud/midjourney/imagine", {
  method: "POST",
  headers: {
    Authorization: "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    prompt: "a cute kitten playing with yarn, studio lighting",
    callback_url: "https://your-server.com/webhook",
  }),
});
const data = await res.json();
console.log(data);
```

```go Go
package main

import (
  "bytes"
  "encoding/json"
  "fmt"
  "io"
  "net/http"
)

func main() {
  body, _ := json.Marshal(map[string]string{
    "prompt":       "a cute kitten playing with yarn, studio lighting",
    "callback_url": "https://your-server.com/webhook",
  })
  req, _ := http.NewRequest("POST",
    "https://api.acedata.cloud/midjourney/imagine",
    bytes.NewReader(body))
  req.Header.Set("Authorization", "Bearer YOUR_API_TOKEN")
  req.Header.Set("Content-Type", "application/json")
  resp, _ := http.DefaultClient.Do(req)
  defer resp.Body.Close()
  out, _ := io.ReadAll(resp.Body)
  fmt.Println(string(out))
}
```

</CodeGroup>

Response shape (sync result if fast; otherwise `task_id` only):

```json
{
  "success": true,
  "task_id": "1bae3bec-3ac4-4180-a148-74ee6cb68b98",
  "image_url": "https://cdn.acedata.cloud/midjourney/.../kitten.png",
  "image_id": "1234197197067915365",
  "actions": ["upscale1", "upscale2", "variation1", "variation2"]
}
```

Save the `task_id` — you'll need it for upscales, variations, and webhook redelivery.

## 3. Poll for the Result

If you didn't set `callback_url`, or the sync wait timed out, use the `tasks` endpoint:

<CodeGroup>

```bash cURL
curl -X POST https://api.acedata.cloud/midjourney/tasks \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "1bae3bec-3ac4-4180-a148-74ee6cb68b98",
    "action": "retrieve"
  }'
```

```python Python
import requests, time

task_id = "1bae3bec-3ac4-4180-a148-74ee6cb68b98"
while True:
    r = requests.post(
        "https://api.acedata.cloud/midjourney/tasks",
        headers={"Authorization": "Bearer YOUR_API_TOKEN"},
        json={"id": task_id, "action": "retrieve"},
    ).json()
    if r.get("success"):
        print(r)
        break
    time.sleep(5)
```

</CodeGroup>

## Task Statuses

| `status` | Meaning |
|---|---|
| `pending` | Queued upstream |
| `running` | Upstream is generating |
| `success` | Done — read the final fields |
| `failed` | Failed — see `error.code` / `error.message` |

Full pattern in [Async task model](/en/concepts/async-tasks).
