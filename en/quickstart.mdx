Start with a text response, or choose an image, music, video, or search API below.

## Get your API key

1. Open [Applications](https://platform.acedata.cloud/console/applications?lang=en&utm_source=docs&utm_medium=referral&utm_campaign=evergreen) and sign in or register.
2. Find **General application**. If needed, select **Initialize General Application**, then copy its **API Key**. A general key can access services available to your account.
3. Check the selected model's [price](https://platform.acedata.cloud/models?lang=en) and your application balance. See [API keys](https://platform.acedata.cloud/documents/api-key-guide?lang=en) for separate keys and optional restrictions.

Click **1** to copy the key. **2** opens **Manage Keys** when you want a separate key for this integration.

![Copy the API key from General Application, or open Manage Keys](https://raw.githubusercontent.com/AceDataCloud/NanoBananaDify/2522b2f57210597af2db866445319334a1677a23/_assets/tutorial/get-api-key-en.png)

Save the raw key in your terminal environment.

```bash
export ACEDATACLOUD_API_KEY="YOUR_API_KEY"
```

## Send a request

Run this command from your terminal or backend. It requests one short text response.

```bash
curl --fail-with-body https://api.acedata.cloud/v1/chat/completions \
  --header "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-6-luna",
    "messages": [{"role": "user", "content": "Say hello in one sentence."}]
  }'
```

## Read the result

The answer is in `choices[0].message.content`. The following excerpt illustrates the response shape.

```json
{
  "choices": [
    {"message": {"role": "assistant", "content": "Hello! How can I help you today?"}}
  ]
}
```

If the response contains `error`, use its `code` and `message` to resolve the request. Keep `trace_id` when contacting support. The [Chat API guide](https://platform.acedata.cloud/documents/openai-chat-completions-integration?lang=en) covers the response fields.
