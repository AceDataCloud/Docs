## Code Examples

The following examples demonstrate how to call Gemini vs DeepSeek respectively via the Ace Data Cloud API. All requests use the same Base URL (`https://api.acedata.cloud`) and authentication method.

### Calling Gemini

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/gemini/chat/completions",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "model": "gemini-2.5-flash",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
},
)
print(response.json())
```
