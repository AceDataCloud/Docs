## What is $ACE

$ACE is an SPL token issued by Ace Data Cloud on the **Solana blockchain**. Simply holding $ACE tokens in your wallet automatically unlocks discounts on all platform API calls — no tokens are spent or transferred.

<Info>
  $ACE tokens are only **held**, never consumed. All API calls are still billed in USD/Credits. Discounts are applied automatically based on your on-chain balance.
</Info>

  </Step>
</Steps>

## How It Works

```
Your Solana Wallet (holding $ACE)
    ↓ Platform periodically reads on-chain balance
CoinInfo (records your address and balance)
    ↓ Matches CoinPolicy tier thresholds
ConsumptionDiscount (discount record created)
    ↓ Applied automatically on API calls
API bill reduced by discount amount
```

- The platform **only reads** your on-chain balance — it never moves or spends your $ACE tokens
- Balance changes are picked up in the next check cycle and discount tiers update automatically
- Discounts apply to all supported API services
