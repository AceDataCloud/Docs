Hermes Agent integrates with Ace Data Cloud through the OpenAI Chat Completions protocol. Choose one of the configuration methods:

| Configuration Method         | Guide                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| `hermes model` Interactive Wizard | [Wizard Configuration](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| `config.yaml` Manual Configuration  | [Manual Configuration](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| Platform Private Deployment              | [Managed Deployment](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

Common parameters for local integration:

- Base URL: `https://api.acedata.cloud/v1`
- Transport: `chat_completions`
- Provider: `custom:acedatacloud`
- API Key: Obtain from [Application List](https://platform.acedata.cloud/console/applications)

Both local methods ultimately write to `~/.hermes/config.yaml`, do not configure it multiple times.

Return to [Coding Plan Configuration Center](https://platform.acedata.cloud/documents/coding-plan-integration).
