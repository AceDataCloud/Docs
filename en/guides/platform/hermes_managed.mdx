Ace Data Cloud provides an entry for Hermes Agent private deployment. This entry is a controlled service, and its availability and selectable resources are subject to what is currently displayed on the console.

## Steps to Use

1. Find **Hermes Agent Private Deployment** on the platform.
2. Follow the page prompts to select available configurations and create the service.
3. Wait for the platform to display the ready status.
4. Use the entry and credentials provided on the page to access the instance.
5. First send `Reply only OK`, then start the real task.

The model, credentials, storage, and deletion behavior are subject to the creation page and confirmation pop-up; do not directly treat the YAML from the local Hermes tutorial as the platform deployment contract. Export any data that needs to be retained before deletion.

If the console does not display the creation entry, it indicates that the current account does not have this service enabled; you can alternatively use the [Hermes Interactive Wizard](https://platform.acedata.cloud/documents/hermes-wizard-integration) or [Manual Configuration](https://platform.acedata.cloud/documents/hermes-manual-integration).
