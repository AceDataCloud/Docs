LMLocal is an extension for Visual Studio 2022/2026 that officially supports OpenAI-compatible APIs and custom Base URLs. The configuration entry may change with the extension version; please fix the version for the first integration and check the actual editing, tool calls, and usage records.

## Configuration

1. Install LMLocal from the Visual Studio Marketplace or the official repository.
2. Add a Custom/OpenAI-compatible Provider in Providers.
3. Fill in the Base URL as `https://api.acedata.cloud/v1`.
4. Fill in the Auth Key with your Ace Data Cloud API Token.
5. Fill in the Model with the exact model ID that supports Chat Completions in the model directory.
6. After saving, send `Reply only OK`, then test the project editing process again.

## Current Boundaries

- This guide only covers LMLocal and does not represent shared configurations for other Visual Studio extensions.
- Different versions may handle chat, editing, building, and testing requests separately; each mode needs independent verification.
- If the client automatically appends `/v1` or endpoint paths, please avoid duplicate paths.
