---
title: "Retrieve Recent API Call Samples from the AceDataCloud Platform"
description: "Platform integration guide - Ace Data Cloud"
---

Publicly returns samples of call records for an API within the most recent 15 minutes, for quickly observing recent status. It is not a counting interface aggregated by status code, and cannot be used for personal billing, SLA, or complete usage statistics.

## API Overview

| Item   | Content                                                           |
| --- | ------------------------------------------------------------ |
| Method  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| Authentication  | Public, no account token required                                                    |
| Limit  | Returns up to 5,000 records after merging the most recently created/completed records                                    |

Obtain `api_id` from the [API List](https://platform.acedata.cloud/documents/platform-api-list).

```shell
export API_ID='Your API ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## Actual Response Structure

The response is directly an array and does not use a pagination envelope:

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| Field            | Description        |
| ------------- | --------- |
| `api_id`      | API ID    |
| `created_at`  | Record creation time    |
| `trace_id`    | Request trace identifier    |
| `status_code` | HTTP status code  |
| `elapsed`     | Call duration, in seconds |

When the API does not exist, it may currently also return an empty array, because this action directly queries recent usage by ID and does not first validate the API object. To calculate the success rate, the client must group the returned samples itself; to check personal charges, please use the account-level interface.
