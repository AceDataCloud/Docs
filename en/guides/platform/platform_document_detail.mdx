Retrieve the complete content and navigation relationships of a single document by document UUID or alias. When the alias is known, you can request it directly without first filtering from the list.

## API Overview

| Item   | Content                                                              |
| --- | --------------------------------------------------------------- |
| Method  | `GET`                                                           |
| URL | `https://platform.acedata.cloud/api/v1/documents/{id_or_alias}` |
| Authentication  | Public; direct access is available if the UUID or alias is known                                       |

## Parameters

- `id_or_alias`: Document UUID, current alias, or old alias retained in `redirect_from`.
- `lang`: Optional language hint; `Accept-Language` can also be used. The final content language is determined by the response `content_locale`.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/documents/platform-token' \
  --data-urlencode 'lang=zh-CN' \
  -H 'Accept: application/json'
```

## Response Description

The details use a single-object response and currently include:

- `id`, `alias`, `redirect_from`, `name`, `title`, `type`, `rank`, `tags`;
- `content`, `content_mode`, `content_locale`, `content_hash`;
- `parent`, `sibling`, and public `children` summaries sorted by rank;
- `api` / `proxy` / `dataset` / `integration` associations, as well as `agent` (when present).

The response does not contain a `breadcrumbs` field. When building breadcrumbs, you can continue retrieving the details of `parent`, or use cached document directory relationships.

## Error Handling

- The ID/alias does not exist or does not meet the current site's visibility requirements: `404`. `private` only controls list visibility and does not prevent people who know the link from reading it directly; it cannot serve as a confidentiality boundary.
- The current route uses the no-trailing-slash form; do not rely on the proxy layer to automatically add a trailing slash.
