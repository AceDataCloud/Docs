Coze officially supports integrating custom models and provides three protocols: OpenAI Chat API, OpenAI Responses API, and Anthropic Messages API. The Base URL, path composition, Header, streaming, and tool-calling contracts differ across the three routes, so they must be configured and validated separately.

| Route                   | Status       | Guide                                                                               |
| ----------------------- | ------------ | ----------------------------------------------------------------------------------- |
| OpenAI Chat Completions | Experimental | [Chat Configuration](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | Experimental | [Responses Configuration](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | Experimental | [Messages Configuration](https://platform.acedata.cloud/documents/coze-messages-integration)   |

“Experimental” means that the official capability and configuration entry have been confirmed, but different Coze regions, versions, or plans may display different forms. Ace Data Cloud still needs to complete fixed-version validation according to the protocol. Do not extrapolate the success of one protocol to the other two.

## Configuration Principles

- For the Base API URL, prioritize the base provided in the documentation; do not append endpoint paths that the client automatically completes again.
- Use your Ace Data Cloud API Token as the API Key.
- For Model, use the exact model ID in the model catalog that is compatible with the selected protocol.
- After regular text succeeds, streaming and tool calling should also be validated.
