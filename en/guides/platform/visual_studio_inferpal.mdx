Inferpal is an extension for Visual Studio 2022/2026 that officially supports connecting to OpenAI-compatible services. The extension version may affect editing, tool invocation, and usage logging; please fix the version and complete the minimum validation below for the first connection.

## Configuration

1. Install Inferpal from the Visual Studio Marketplace or the official repository.
2. Open Inferpal's **Settings → Connection**.
3. Select OpenAI-compatible for Provider.
4. Fill in the Base URL as `https://api.acedata.cloud/v1`.
5. Fill in the API Key with your Ace Data Cloud API Token.
6. Fill in the Model with the exact model ID that supports Chat Completions in the model directory.
7. After saving, send `Reply only OK`, then execute a request that includes code context again.

## Current Boundaries

- This guide only covers Inferpal and does not represent that Visual Studio's built-in Copilot or other extensions support the same fields.
- Different versions may automatically append paths to the Base URL; if the request fails, please first verify that the final request falls under the Chat Completions endpoint.
- Before completing the fixed version E2E, there is no commitment that all editing, completion, or tool invocation modes will be available.
