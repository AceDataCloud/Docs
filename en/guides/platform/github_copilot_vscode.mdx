---

GitHub Copilot’s official BYOK documentation lists VS Code as a supported local client and supports OpenAI-compatible Providers. VS Code versions, enterprise policies, and model visibility may affect the final endpoint; for the initial integration, please inspect the actual requests as described below.

## Configuration Scope

1. Confirm that your GitHub Copilot account or organization has enabled the BYOK/Custom Models feature.
2. Add an OpenAI-compatible Provider in VS Code’s Copilot model management.
3. Set the Base URL to `https://api.acedata.cloud/v1`.
4. Set the API Key to your Ace Data Cloud API Token.
5. Set the Model to the exact model ID in the model catalog that is compatible with the selected protocol.
6. Send `Reply only OK` in Copilot Chat, then test another request with workspace context.

## Current Boundaries

- Copilot App, CLI, GitHub Desktop, Enterprise BYOK, and VS Code have different configuration contracts; this guide does not directly apply steps for other clients to VS Code.
- Organization policies may prohibit individuals from adding Providers or models.
- Tab completion, Chat, Agent, and background tasks may use different model paths and should be validated separately.
