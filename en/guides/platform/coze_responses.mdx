The official Coze custom model documentation supports the OpenAI Responses API and provides the Base API URL, API Key, and model fields. Different Coze tenant versions may handle path concatenation, streaming output, and tool invocation differently. Please check each item below when connecting for the first time.

## Configuration

1. Go to Coze model management and add a custom model.
2. Select Protocol as OpenAI Responses API.
3. Fill in Base API URL as `https://api.acedata.cloud/v1`.
4. Fill in API Key with your Ace Data Cloud API Token.
5. Fill in Model with the exact model ID that supports the Responses API in the model directory.
6. Save and complete the Coze connection test.
7. In Bot/Agent, send `Reply only OK`, then test the tool invocation again.

## Current Boundaries

- Different Coze regions, versions, or packages may display different forms.
- The Base API URL should use base, do not append `/responses` again; if the current UI explicitly requires a complete API URL, follow the form prompt.
- Chat Completions, Responses, and Anthropic Messages are three independent routes and cannot substitute for each other in validation.
