---
title: "Retrieve AceDataCloud Platform Order Details"
description: "Platform integration guide - Ace Data Cloud"
---

Query an order by order ID. This endpoint supports two read modes: anonymous access returns only the minimum fields required by the payment page; the order owner carrying an Account Token receives full details.

## API Overview

| Item   | Content                                                   |
| --- | --------------------------------------------------------- |
| Method  | `GET`                                                     |
| URL | `https://platform.acedata.cloud/api/v1/orders/{order_id}` |
| Authentication  | Optional; anonymous access provides a minimum projection, while an authenticated owner receives a full projection                                    |

`/orders/{id}` and `/orders/{id}/` are both currently available. The order ID is part of the payment link and should be treated as a sensitive opaque identifier; do not distribute it publicly.

## Anonymous Query

The payment page can read directly when the login session is lost:

```shell
export ORDER_ID='your order ID'
curl "https://platform.acedata.cloud/api/v1/orders/${ORDER_ID}" \
  -H 'Accept: application/json'
```

The anonymous response contains only `id`, `description`, `price`, `state`, `pay_way`, `pay_url`, `expired_at`, and `created_at`. It does not return account, Application, Package, internal payment identifiers, or metadata.

## Authenticated Query

```shell
export PLATFORM_TOKEN='your account token'
curl "https://platform.acedata.cloud/api/v1/orders/${ORDER_ID}" \
  -H 'Accept: application/json' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

The order owner receives complete Order details, including `application` / `applications`, `package` / `packages`, `bank_details`, `invoice_automation`, and model fields. If authenticated but not the order owner, `403` is returned; super administrators are excluded.

## Key Fields

| Field            | Description                                                          |
| ------------- | ----------------------------------------------------------- |
| `state`       | `Pending`, `Paid`, `Finished`, `Expired`, `Failed`, or `Refunded` |
| `pay_way`     | The order's current payment method; the field name is not `payment_method`                             |
| `pay_url`     | Hosted payment page or QR code address; may be empty                                           |
| `price`       | The final amount payable for the order; the current order model does not provide a `final_price` field                         |
| `amount`      | Package quota quantity; visible only in the authenticated full response                                            |
| `finished_at` | Order completion time; the field name is not `paid_at`                                      |

The full response may include additional fields depending on the payment method. Clients should read them as needed and always avoid logging sensitive metadata in the full response.

## Error Handling

- `404`: The order ID does not exist.
- `403`: Logged in but not the order owner.
- Anonymous requests do not return `401`; they only receive the minimum public projection.
