---
title: "OpenCode IDE Extension Integration with Ace Data Cloud"
description: "Platform integration guide - Ace Data Cloud"
---

The official OpenCode IDE Extension supports editors such as VS Code, Cursor, Windsurf, VSCodium, and reuses the OpenCode local runtime and Provider configuration. The IDE extension reuses the local CLI Provider, but the request chain may vary between different editor versions; please fix the version and complete minimal validation for the first integration.

## Configure Provider

First, configure the Ace Data Cloud Provider in `opencode.json` or `opencode.jsonc` according to the [OpenCode Terminal configuration](https://platform.acedata.cloud/documents/opencode-terminal-integration):

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## Install IDE Extension

1. Run `opencode` in the integrated terminal of the editor to automatically install the Extension following the official process; you can also manually install it from the corresponding Marketplace.
2. Reload the editor.
3. Initiate `Reply only OK` from the OpenCode Extension.
4. Execute the request that requires reading files or modifying code again to confirm that the IDE Extension uses the same Provider and model.

## Current Boundaries

- The capabilities of the Provider come from the OpenCode runtime and do not represent native support for Ace Data Cloud in the host editor.
- The extension versions of VS Code and its forks may differ, and versions should be recorded separately.
- Successful ordinary chat cannot replace validation for file reading, editing, and tool invocation.
