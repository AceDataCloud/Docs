---
title: "Retrieve the List of APIs Under an AceDataCloud Platform Service"
description: "Platform integration guide - Ace Data Cloud"
---

Returns the currently enabled and non-deprecated APIs of the service by Service UUID with pagination. If only alias is available, first call [Service Details](https://platform.acedata.cloud/documents/platform-service-detail) to obtain `id`.

## API Overview

| Item   | Content                                                             |
| --- | ------------------------------------------------------------------- |
| Method  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| Authentication  | Public, no account token required                                                           |
| Pagination  | `count` + `items`                                                   |

## Parameters

| Parameter           | Location    | Required  | Description                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | Yes   | Service UUID; alias is not supported           |
| `limit`      | query | No   | Number of items per page, maximum 100                      |
| `offset`     | query | No   | Pagination offset                            |
| `ordering`   | query | No   | Django ordering expression; `rank` or `-rank` is recommended |

The current endpoint does not support `stage` filtering; it already excludes `Deprecated` APIs.

```shell
export SERVICE_ID='Your Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

List items use the same index structure as the [Platform API List](https://platform.acedata.cloud/documents/platform-api-list), and currently include `definition`. When a stable entry point for a single API is required, continue by calling `/api/v1/apis/{api_id}`.

## Error Handling

- The service does not exist or is not visible on the current site: `404`.
- `service_id` must be a UUID; alias will not be resolved in this action.
