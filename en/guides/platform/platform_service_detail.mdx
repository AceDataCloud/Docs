Retrieve complete information for a single service by service ID (UUID) or alias—more comprehensive fields than returned by [Retrieve AceDataCloud Platform Service List](https://platform.acedata.cloud/documents/platform-service-list), additionally expanding associated objects such as `apis`, `proxies`, `datasets`, and `packages`. Suitable for scenarios such as service detail pages, pricing comparison pages, Agent tool descriptions, and more.

> ℹ️ This API belongs to the **AceDataCloud Platform Management API**, with the unified prefix `https://platform.acedata.cloud/api/v1/`. For the complete API index, see [Retrieve AceDataCloud Platform Document List](https://platform.acedata.cloud/documents/platform-document-list).

## API Overview

| Item   | Content                                                         |
| --- | ------------------------------------------------------------- |
| Method  | `GET`                                                         |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}` |
| Authentication  | ❌ Public                                                          |

`/services/{id}` and `/services/{id}/` are both currently available; examples consistently use the form without a trailing slash.

## Authentication Description

This API is completely public. **However, after including an account token, the `applied` field in the response will reflect the actual application status of the current account**, otherwise it will always be `false`.

For how to obtain an account token, see [Manage AceDataCloud Platform Account Tokens](https://platform.acedata.cloud/documents/platform-token).

## Path Parameters

| Parameter           | Type            | Required  | Description                                                    |
| ------------ | ------------- | --- | ----------------------------------------------------- |
| `service_id` | UUID / string | ✅   | Service ID (UUID) or alias (such as `midjourney`, `openai`, `webextrator`, etc.) |

## Request Examples

### cURL

```shell
# 按 UUID 查询
curl 'https://platform.acedata.cloud/api/v1/services/8efa1d83-9b75-4562-b44a-af95ce563d05' \
  -H 'accept: application/json'

# 按 alias 查询
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json'

# 带账户令牌看 applied 状态
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

resp = requests.get(
    "https://platform.acedata.cloud/api/v1/services/midjourney",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
svc = resp.json()
print(f"服务: {svc['title']} ({svc['alias']})")
print(f"已申请: {svc['applied']}, 免费额度: {svc['free_amount']} {svc['unit']}")
print(f"API 数: {len(svc['apis'])}, 套餐数: {len(svc['packages'])}")
for pkg in svc["packages"]:
    print(f"  ¥{pkg['price']:>7.2f}  ->  {pkg['amount']} {svc['unit']}")
```

### Node.js

```javascript
const r = await fetch('https://platform.acedata.cloud/api/v1/services/midjourney', {
  headers: { accept: 'application/json' },
})
const svc = await r.json()
console.log(`${svc.title} - 套餐 ${svc.packages.length} 个 - API ${svc.apis.length} 个`)
```

## Response Field Descriptions

In addition to all fields in the [list API](https://platform.acedata.cloud/documents/platform-service-list), the detail API additionally expands:

| Field         | Type    | Description                                                            |
| ---------- | ----- | ------------------------------------------------------------- |
| `apis`     | array | Complete list of associated API objects (each entry includes `id`, `name`, `title`, `path`, `stage`, `cost`) |
| `proxies`  | array | Complete list of associated Proxy objects                                              |
| `datasets` | array | Associated datasets (if `type=Dataset`)                                      |
| `packages` | array | Package list, including `type` (`Usage`/`Period`), `price`, `amount`, `duration`   |

For definitions of the remaining fields, see [Retrieve AceDataCloud Platform Service List → Response Field Descriptions](https://platform.acedata.cloud/documents/platform-service-list).

## Error Handling

| HTTP | code        | Meaning                            |
| ---- | ----------- | ----------------------------- |
| 404  | `not_found` | `service_id` (UUID or alias) does not exist |
| 500  | —           | Usually caused by mistakenly adding a trailing slash to the URL; remove it and retry          |

## Practical Tips

- **`alias` > `UUID`**: Hardcoding `alias` (such as `midjourney`) into code is more stable; UUIDs change when migrating environments.
- **The `apis` field does not include the OpenAPI definition**: The complete OpenAPI 3.0 Schema is available in the [Retrieve AceDataCloud Platform API Details](https://platform.acedata.cloud/documents/platform-api-detail) API.
- **Retrieve a service's "complete capabilities"**: Use this API to obtain `api_ids`, then call `/apis/{api_id}` one by one to retrieve details.
- **If `applied=true`**, you can directly [create API credentials](https://platform.acedata.cloud/documents/platform-credential-create) to obtain the 32-character Token required to call business APIs, without needing to apply again.
