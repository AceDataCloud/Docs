FreeAIr is an open-source extension for Visual Studio 2022/2026, officially stated to connect to any OpenAI-compatible API. The request behavior may vary between different extension versions; please fix the version and complete the minimum validation below for the first connection.

## Configuration

1. Install FreeAIr from the Visual Studio Marketplace or the official repository.
2. Open FreeAIr settings and add an OpenAI-compatible connection.
3. Fill in the Endpoint as `https://api.acedata.cloud/v1`.
4. Fill in the Token with your Ace Data Cloud API Token.
5. Fill in the Model with the exact model ID that supports Chat Completions in the model directory.
6. After saving, send `Reply only OK`, then test the request with project context again.

## Current Boundaries

- This guide only covers FreeAIr and does not represent that Visual Studio's built-in Copilot supports arbitrary Base URL.
- The extension version may change the way the endpoint is concatenated; verify the final request URL during validation.
- Tool calls and MCP capabilities within the extension need independent validation and cannot be replaced by successful ordinary chats.
