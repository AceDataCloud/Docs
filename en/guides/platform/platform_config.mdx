title: "Get AceDataCloud Platform Runtime Configuration"
description: "Platform integration guide - Ace Data Cloud"
---

Read public feature flags and country/region detection under the current request context. Suitable for determining whether features should be displayed when the frontend starts; it is not site branding, contact information, or an announcement directory.

## API Overview

| Item   | Content                                          |
| --- | ----------------------------------------------- |
| Method  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Authentication  | Public; when login state is carried, some feature flags may be calculated per user                          |

## Query Parameters and Request Headers

| Name                    | Location     | Description                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | Feature flag override expression; only effective for flags that allow client-side overrides or for super administrators |
| `X-Feature-Overrides` | header | Override source identical to `features`           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## Actual Response Structure

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| Field         | Type            | Description                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Feature flags visible to the current request; keys may change with platform configuration, and clients should read them as needed and set safe default values for missing keys |
| `region`   | string / null | Country or region code detected based on the request IP, in lowercase; `null` when it cannot be identified        |

Do not read the site name, CDN, currency, language, customer service contact information, or announcements from this API; these fields are not part of the current response contract.

## Usage Recommendations

- Feature flags are calculated based on the user, fingerprint, and site context; do not share caches across users for a long time.
- The region selector choice is saved only on the frontend. When displaying, prioritize the selected region; otherwise, use this API's `region`. This API does not accept region override parameters.
- Unrecognized query parameters are ignored; use only the parameters listed on this page.
