title: "Get AceDataCloud Platform Runtime Configuration"

Read the public feature flags and country/region determination under the current request context. Suitable for deciding whether features should be displayed when the frontend starts; it is not site branding, contact information, or an announcement directory.

## API Overview

| Item   | Content                                              |
| --- | ----------------------------------------------- |
| Method  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Authentication  | Public; when login state is carried, some feature flags may be calculated by user                          |

## Query Parameters and Request Headers

| Name                    | Location     | Description                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | Two-letter ASCII country code; used to override the display country in the response, without changing server-side security determination |
| `features`            | query  | Feature flag override expression; only effective for flags that allow client overrides or for super administrators        |
| `X-Feature-Overrides` | header | Override source identical to `features`                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## Actual Response Structure

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| Field         | Type            | Description                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Feature flags visible to the current request; keys may change with platform configuration, and clients should read them as needed and set safe default values for missing keys |
| `country`  | string / null | Lowercase country code; may be `null` when it cannot be identified                     |

Do not read the site name, CDN, currency, language, customer service contact information, or announcements from this API; these fields are not part of the current response contract.

## Usage Recommendations

- Feature flags are calculated based on the user, fingerprint, and site context; do not share caches across users for a long time.
- The `country` passed by the client only affects the return value and will not bypass server-side regional or security policies.
- Unrecognized query parameters will be ignored; use only the parameters listed on this page.
