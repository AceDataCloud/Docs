---
title: "Get the AceDataCloud Platform Service List"
description: "Platform integration guide - Ace Data Cloud"
---

Returns a paginated Service catalog visible to the current site, including service types, display information, free quotas, packages, and associated API/Proxy IDs. Suitable for building a service marketplace or selecting services to apply for.

## API Overview

| Item   | Content                                           |
| ------ | ------------------------------------------------- |
| Method | `GET`                                             |
| URL    | `https://platform.acedata.cloud/api/v1/services/` |
| Auth   | Public; with a login session, `applied` reflects the current account |
| Pagination | `count` + `items`                             |

## Query Parameters

| Parameter        | Type    | Required | Description                                      |
| ---------------- | ------- | -------- | ------------------------------------------------ |
| `id`             | UUID    | No       | Filter by service ID; repeated parameters supported |
| `private`        | boolean | No       | Filter by public status; site visibility rules still apply |
| `type`           | string  | No       | Service type; repeated parameters supported      |
| `tag`            | string  | No       | Filter by tag                                    |
| `include_facets` | boolean | No       | When `true`, adds type/tag statistics available on the current site |
| `limit`          | integer | No       | Number of items per page, maximum 100            |
| `offset`         | integer | No       | Pagination offset                                |
| `ordering`       | string  | No       | Only `rank` or `-rank` is supported              |

The list does not support filtering by `alias`; when an alias is available, directly request `/api/v1/services/{alias}`. `applied_count` and `updated_at` are not allowed ordering fields.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## Response Description

The response is `{count, items}`; `facets` is added only when `include_facets=true`. Service items include currently public fields such as `id`, `alias`, `title`, `description`, `type`, `applied_count`, `free_amount`, `unit`, `private`, `need_verify`, `rank`, `tags`, `thumbnail`, `doc_url`, `demo_url`, `api_ids`, `proxy_ids`, `cost`, and `packages`.

`applied` in an anonymous list does not represent the application status of an account. When account-related status is needed, a valid login session should be included, and the [Service Application List](https://platform.acedata.cloud/documents/platform-application-list) should be used as the final reference.
