## 1. Obtain API Key

Open the [Ace Data Cloud application list](https://platform.acedata.cloud/console/applications), enter an available application, and copy the API Key.

![Obtain Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Add Provider

Open Cherry Studio, go to **Settings → Model Services → Add Provider**, and fill in:

| Field      | Value                           |
| ------- | --------------------------- |
| Provider Name   | `Ace Data Cloud`            |
| Provider Type   | `OpenAI`                    |
| API Key | The API Key just copied               |
| API Address  | `https://api.acedata.cloud` |

![Cherry Studio Add Ace Data Cloud Provider Configuration Screen](https://cdn.acedata.cloud/b67a927eae62.png)

Cherry Studio will automatically append `/v1/chat/completions` for the OpenAI type. When using the general endpoint, do not add `#` at the end of the address, and there is no need to create multiple Providers by model family.

## 3. Add and Enable Models

1. Click **Get Model List**; if the current version does not support automatic retrieval, go to the [model catalog](https://platform.acedata.cloud/models) to check, then manually add the target model name, for example, `claude-opus-5`, `gpt-6-sol`.
2. Click the check button next to the API Key to verify the connection.
3. Turn on the Provider's **Enable** switch.
4. Select the newly added model in the chat model selector.

![Cherry Studio Provider and Model List](https://cdn.acedata.cloud/149de1d088bf.png)

> After completing model retrieval or manual addition, please turn on the Provider switch in the upper-right corner.

Send `Reply only OK`, and verify the call in [usage history](https://platform.acedata.cloud/console/usages). For 401, check the Key; if the model is not displayed, check whether the Provider is enabled; for 404, check whether the manually entered model name exactly matches the `id` in the catalog.

## About GPT Image 2

Cherry Studio's standard custom chat Provider cannot directly call the Images API. Generation and editing with `gpt-image-2` should use the Ace Data Cloud dedicated interfaces:

- [GPT Image 2 Image Generation](https://platform.acedata.cloud/documents/openai-images-generations)
- [GPT Image 2 Image Editing](https://platform.acedata.cloud/documents/openai-images-edits)

Do not enter `/openai/images/generations` into the chat Provider.
