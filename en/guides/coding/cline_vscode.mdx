## 1. Obtain an API Key

Open the [Ace Data Cloud application list](https://platform.acedata.cloud/console/applications), enter an available application, and copy the API Key.

![Obtain Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configure Cline

Install and open Cline in VS Code, then enter the Provider configuration through the settings button in the Cline panel and fill in:

| Field                             | Value                                                                                          |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| API Provider                      | `OpenAI Compatible`                                                                            |
| Base URL                          | `https://api.acedata.cloud/v1`                                                                 |
| API Key                           | The API Key just copied                                                                       |
| Model ID                          | Go to the [model catalog](https://platform.acedata.cloud/models) to view it, and fill in the target model name exactly as is, for example, `claude-opus-5`, `gpt-6-sol` |
| Custom Headers                    | Leave blank                                                                                   |
| Set Azure API version             | Leave blank                                                                                   |
| Use Azure Identity Authentication | Turn off                                                                                      |

![Cline OpenAI Compatible Configuration Interface](https://cdn.acedata.cloud/8f356c2f1378.png)

`Model ID` is the model name used by the `model` parameter in API requests. It is not the UUID of a service or API, and it cannot be abbreviated manually. You can first check it in the [model catalog](https://platform.acedata.cloud/models); if precise validation is needed, use the current API Key to request `GET https://api.acedata.cloud/v1/models`, and copy the `id` value of the target model from the response's `data` array.

Keep the remaining model capability settings at their defaults for now; when images or a larger context are needed, adjust them according to the actual capabilities of the selected model.

## 3. Verify

After saving, create a new task and send `Reply only OK`. Then have Cline read a test file to confirm that the model supports tool calling; call records can be viewed in [usage history](https://platform.acedata.cloud/console/usages).

A 401 usually indicates an incorrect Key; a 404 usually indicates that the Base URL is incorrect, or that the entered Model ID does not exactly match the `id` in the catalog. If the model can chat but cannot operate files, check the model's tool-calling capability.
