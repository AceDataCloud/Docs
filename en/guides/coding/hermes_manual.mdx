## 1. Obtain the API Key

Open the [Ace Data Cloud application list](https://platform.acedata.cloud/console/applications), enter an available application, and copy the API Key.

![Obtain Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Save the Key

Write the following in `~/.hermes/.env`:

```dotenv
ACEDATACLOUD_API_KEY=your API Key
```

## 3. Configure the Provider

Add the following to `~/.hermes/config.yaml`:

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

Go to the [model catalog](https://platform.acedata.cloud/models) to view model names (for example, `claude-opus-5`, `gpt-6-sol`), and replace all `MODEL_ID` values with the same name; for precise verification, use the `id` value in the `/v1/models` response. This value is the model name used by the API `model` parameter, not the UUID of the service or API. Do not write the real Key into YAML or commit `.env`.

## 4. Verify

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

If it returns 401, check `~/.hermes/.env`; if the configuration does not take effect, completely exit and restart Hermes.
