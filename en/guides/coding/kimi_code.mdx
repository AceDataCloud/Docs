## 1. Obtain an API Key

Open the [Ace Data Cloud application list](https://platform.acedata.cloud/console/applications), enter an available application, and copy the API Key.

![Obtain Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Install Kimi Code

macOS / Linux:

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

You can also install it via npm:

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. Configure AceDataCloud

Edit `~/.kimi/config.toml` and add the following configuration:

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "your API Key"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

Go to the [model catalog](https://platform.acedata.cloud/models) to view model names (for example, `claude-opus-5`, `gpt-6-sol`), and replace all `MODEL_ID` values with the same name; for precise validation, use the `id` value in the `/v1/models` response. This value is the model name used by the API `model` parameter, not the UUID of the service or API. `type = "openai"` uses the OpenAI Chat Completions protocol.

The configuration file contains the Key; on macOS / Linux, it is recommended to restrict permissions:

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. Verify and Start

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

Run `kimi` after entering the project to start using it. If it returns 401, check the API Key; if it indicates model not found, confirm that `default_model`, the model table name, and the `model` field use the same ID.
