The Midjourney Shorten API exposes Midjourney's official `/shorten` (prompt-analyzer) command. Given a prompt, the upstream model analyzes which tokens carry the most weight and returns up to 5 shortened candidate prompts that preserve the dominant ideas while stripping low-weight filler. Typical use cases:

- Trimming long prompts before calling `imagine` so the dominant concepts get more weight in the generated image.
- Reverse-engineering how Midjourney weighs individual tokens for prompt engineering experiments.
- Cleaning up user-supplied prompts in an automated pipeline (merging synonyms, dropping redundancies).

This document describes how to integrate the Midjourney Shorten API.

## Application Process

To use the Midjourney Shorten API, first apply for the service on the application page [Midjourney Shorten API](https://platform.acedata.cloud/documents/f0c6be1d-c084-43ac-bde6-44ef9cf824a2). After the page loads, click the "Acquire" button.

If you are not logged in or registered, you will be redirected to the [login page](https://platform.acedata.cloud) and returned to the application page after sign-in.

First-time applicants receive a free quota that lets you call the API without payment.

## Request Example

Let's take a longer prompt and ask the API to shorten it.

### Request Headers and Body

**Request Headers** include:

- `accept`: response format; set to `application/json`.
- `authorization`: your API key, available in the dropdown after acquiring the service.

**Request Body** includes:

- `prompt`: the text prompt to analyze and shorten. English prompts are recommended for best results.

### Code Examples

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/midjourney/shorten' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "a serene mountain lake at sunrise, mist rising from the water, towering pine trees on the shore, golden hour lighting, ultra detailed, cinematic, 35mm film photography style, masterpiece --ar 16:9 --v 6"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/midjourney/shorten"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "prompt": (
        "a serene mountain lake at sunrise, mist rising from the water, "
        "towering pine trees on the shore, golden hour lighting, ultra "
        "detailed, cinematic, 35mm film photography style, masterpiece "
        "--ar 16:9 --v 6"
    )
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

### Response Example

On success the API returns up to 5 shortened candidate prompts. For example:

```json
{
  "prompts": [
    "a serene mountain lake at sunrise, mist rising from the water, golden hour lighting --ar 16:9",
    "mountain lake sunrise with mist, golden light --ar 16:9 --v 6",
    "tranquil alpine lake, dawn mist, warm golden tones, cinematic --ar 16:9",
    "sunrise over a misty mountain lake, rich golden hour photography --ar 16:9 --style raw",
    "misty lake at dawn, mountains in background, golden sunrise --ar 16:9"
  ]
}
```

The result contains a `prompts` field with several candidate prompts. Each candidate preserves the highest-weighted tokens from the original prompt and drops repetitions or redundant descriptors.

## Error Handling

When an error occurs the API returns a corresponding error code and message, for example:

- `400 token_mismatched`: Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`: Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`: Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`: Too many requests, you have exceeded the rate limit.
- `500 api_error`: Internal server error, something went wrong on the server.

### Error Response Example


## Conclusion

You now know how to call the Midjourney Shorten API to analyze and shorten a prompt. A common pattern is to chain Shorten with Imagine: first call Shorten to obtain a handful of compact candidates, then pick the one you prefer and pass it to the Imagine API for image generation.
