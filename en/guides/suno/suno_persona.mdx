title: "Suno Custom Singer Style API Integration Guide"
description: "Suno Music Generation Integration Guide - Ace Data Cloud"
---

SUNO allows us to set a singer style for an already generated song and then create secondary works based on it. This document explains how to integrate the related API.

This API has only three input parameters. First, `audio_id`, which is the ID of a song that has already been successfully generated by the official system. Next, `name` and `description` represent the name and description of the singer style.

Here, the `audio_id` we input is `https://cdn.acedata.cloud/2qhzs3.png`. You can refer to the [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) to perform custom song generation, and finally obtain the `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

The result is as follows:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

As you can see, the `persona_id` field in `data` is the ID of the generated singer style.

Once you have the singer style ID, you can use the [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) to generate custom songs. For example, set the `action` parameter to `artist_consistency`, pass the uploaded song ID as `audio_id`, and also include the `persona_id` parameter, which is the singer style ID returned above. This allows you to generate new songs based on the referenced singer style.
