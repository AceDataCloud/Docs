If you want to generate custom songs but do not really want to write the lyrics yourself, you can use the lyrics generation API provided by AceDataCloud to generate lyrics through a prompt. The API is [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Billing: After successful generation, the standard fee for each request is **0.08 Credits**. When one request returns multiple lyric candidates, it is still billed as only one request; applicable consumption discounts are subject to the actual bill, and failed requests are not charged.

The main input parameter of this API is `prompt`, with an optional `model` (optional values: `default`, `remi-v1`, default: `default`). An example is as follows:

![](https://cdn.acedata.cloud/p53wtj.png)

Here, the `prompt` we entered is `A song about winter`, generating a song related to winter.

Click Run, and the result is as follows:

As you can see, `data` is an array, and multiple lyric candidates are returned each time. The `text` field of each element is the lyric content, `title` is the title, and `tags` are the recommended music style tags.

After obtaining the lyrics, we can use the [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) to generate custom songs.
