SUNO allows us to create custom voice personas from any audio file, enabling voice cloning for music generation. Unlike the existing Persona API (which uses a Suno-generated `audio_id`), this API accepts a publicly accessible `audio_url`, namely your own vocal recording. This document explains how to integrate the voice cloning API.

On creation routes that support voice availability queries, you can pass the `persona_id` from the creation result to `POST /suno/availability` using the original application and caller identity. When the associated account is online, it returns `data.available=true`; when confirmed offline, it returns `data.available=false`. [Voice Availability Query Guide](https://platform.acedata.cloud/documents/suno-availability-integration)

## Step 1: Create a Voice Persona

Billing: After successful voice persona creation, the standard fee for each request is **0.15 Credits**. Applicable consumption discounts are subject to the actual bill, and failed requests are not charged.

This API has three input parameters: `audio_url` (required), which is a publicly accessible MP3 or WAV audio file URL containing clear vocals from a single person; and `name` and `description` (optional), which are the name and description of the voice persona.

> **Audio File Requirements**
> - The audio format must be `WAV` or `MP3`
> - The audio duration must be between `10~240 seconds`; clean dry vocal material from a single person of `30~60 seconds` is recommended
> - The audio should contain **clear, recognizable speech or singing vocals from a single person**
> - Be sure to avoid **background noise, accompaniment, echo, and reverberation**; complete songs with accompaniment usually cannot pass voiceprint verification
> - Do not include **multiple speakers** or **multiple vocals**
> - Material with excessively low volume, unclear speech, or excessive noise may result in **cloning failure** or **poor generation quality**
> **Usage Restrictions**
> - Voice personas created by uploading audio are **private resources**
> - This voice persona **does not support reuse across accounts**
> - It is recommended to use it as soon as possible after successful creation; it may become **invalid or unavailable** if left unused for a long time
> - The returned `name` is automatically generated by the system; please use the returned `persona_id` as the reference

> **Handle Failures According to Explicit Retry Flags**
> `retryable` in the error object is an optional Boolean field. When `error.retryable` is `true`, it indicates that this failure permits another request later using the same material and parameters. Explicitly unaccepted service-busy cases or some temporary voiceprint verification failures may include this flag; it is recommended to use backoff intervals and limit the number of retries.
> When `retryable` is `false` or the field is missing, do not automatically resend solely based on HTTP 500, `busy`, or error text. Format, duration, clarity, duplicate recording, and content review issues should be corrected first; when submission times out, the connection is interrupted, or the creation result is unclear, the original `task_id` should be used to query the task first to avoid creating duplicate voice personas. Failed requests are not billed, while successfully retried requests are billed according to normal rules.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> The above `https://cdn.acedata.cloud/suno_demo.mp3` is a directly usable sample material (MP3, 41 seconds, single-person dry vocal).
> For a `WAV` format sample, you can use
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 seconds, mono 44.1kHz).

The result is as follows:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

As you can see, the `persona_id` field in `data` is the created voice persona ID. The `is_public` field is always `false`, because voice personas created by uploading audio are private. Note that the returned `name` is automatically generated by the system; please use `persona_id` to reference this voice persona afterward.

## Step 2: Generate Music Using the Voice Persona

After obtaining the voice persona ID, we can use the [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) for music generation. Set `action` to `generate`, and set `persona_id` to the voice persona ID returned above; the generated song will be sung using the cloned voice.

> **Note:** Voice cloning only supports `chirp-v4-5` and later models (such as `chirp-v4-5`, `chirp-v5`, and `chirp-v5-5`), and does not support `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

The result is as follows:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` can be used for `generate` generation, as well as `cover` / `upload_cover` covers. When specifying a voice, there is no need to fill in `vocal_gender` at the same time; voice similarity still depends on the reference material and the generated result.

Voices created through this API are private resources. Before covering an existing song, first call `/suno/upload`, passing the original song's `audio_url` and the voice's `persona_id`; after a successful upload, call `/suno/audios` using the returned `data.audio_id` and the same `persona_id`:
```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<the audio_id returned after uploading associated with this voice>",
  "persona_id": "<the persona_id returned by the voice creation API>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\nEnter the lyrics to be sung",
  "async": true
}
```

Creating a voice, uploading the original track, and creating a cover must use the same service channel. Do not directly reuse a song ID that was not previously associated with this private voice; see [Suno Upload Reference Audio](https://platform.acedata.cloud/documents/suno-upload) for details.
