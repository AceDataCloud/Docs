## How to Create?

Want to create such QR codes? How to make such art QR codes?

Technically, this is relatively complex. In today's AI era, the current solution for art QR codes is based on Stable Diffusion. By inputting prompts, we can generate corresponding images, and by integrating some QR code content, the final effect is achieved.

So the main challenge here is: how to make the QR code both beautiful and artistic, while still being scannable. Honestly, this technology is quite difficult and requires a lot of parameter tuning to achieve even a slightly better effect.

Probably 99% of people give up at the first step.

Assuming we keep adjusting and finally create such an effect, running it in production is also a considerable cost. For faster speed, a high-performance GPU may be required, which could easily cost tens of thousands of yuan.

Some friends might say: I don't want to spend so much effort or money; I just want to make an art QR code, or I want to integrate this capability into my product. It would be great if there were ready-made APIs.

Are there? Yes, there are.

Our platform provides art QR code generation APIs. We can call the API by inputting various parameters such as image content, QR code link, style, and more, to easily generate the desired art QR code. Moreover, the first application grants 20 free drawing times.

## Basic Usage

To use the basic functions of the art QR code, you need to fill in the following required parameters:

- `type`: QR code type, such as plain text, link, etc.
- `content`: QR code content, for example, a link if the type is link.
- `prompt`: Drawing style prompt for the QR code, strongly recommended in English. For example, `pizza` will draw a pizza-like QR code.
- `callback_url`: Optional, asynchronous callback URL; if provided, the task ID will be returned immediately.
- `content_image_url`: Optional, image URL containing the actual QR code content.
- `aspect_ratio`: Optional, canvas aspect ratio, default is 1:1.
- `ecl`: Error correction level, default is H.
- `qrw`: QR code weight, 1.5-3, the larger the closer to a real QR code.
- `seed`: Fixed random seed to generate reproducible QR codes.
- `steps`: Drawing iteration steps, 10-20, default 16.
- `preset`: Preset background style.
- `pattern`: Main style, default is custom.
- `position`: QR code position, default center.
- `marker_shape`: Positioning point shape, default square.
- `sub_marker`: Auxiliary positioning point shape, default square.
- `pixel_style`: Pixel style, e.g., square, rounded, dot.
- `padding_level`/`padding_noise`: Padding and noise intensity.
- `rotate`: Rotation angle, default 0.
- `rawurl`: Whether to keep the original URL, default false; if enabled, no short link is generated.

## Advanced Parameters

This API also provides more advanced parameters for further customization, explained as follows:

-   preset: Preset background style. The style of the QR code background, such as surreal, neon effect, hand-drawn style, etc.
-   steps: Number of drawing iterations. The higher the number, the stronger the artistic style of the QR code. Range is 10-20, default 16.
-   qrw: QR code weight. The higher the weight, the closer the image is to a real QR code, but the artistic style weakens. Range is 1.5-3, default 1.5.
-   seed: Random seed. Used to generate random QR codes; the same seed produces the same style. Range is 1-9007199254740991.
-   rawurl: Whether to keep the original URL. By default, input URLs are shortened to improve scan rate; default is false.
-   padding_level: QR code inner padding size.
-   aspect_ratio: QR code aspect ratio.
-   position: QR code position.
-   pixel_style: QR code pixel style.
-   marker_shape: QR code positioning frame shape.
-   sub_marker: QR code sub-marker style.
-   rotate: QR code rotation angle.
-   ecl: QR code error correction level.
-   padding_noise: QR code inner padding noise.
-   pattern: Preset QR code style combinations, such as positioning frame style (square, circle, etc.), pixel style (square, circle, etc.).

## QR Code Aspect Ratio `aspect_ratio`

The `aspect_ratio` parameter allows setting the QR code's width-to-height ratio, such as square 1:1, rectangle 16:9, etc. Examples:

-   768x768: Aspect ratio 1:1, canvas width and height equal. Pixel size 768x768, resulting in a square QR code canvas.
-   1008x576: Aspect ratio 16:9, width is 16/9 times the height. Pixel size 1008x576, wider canvas suitable for widescreen display.
-   576x1008: Aspect ratio 9:16, width is 9/16 times the height. Pixel size 576x1008, taller canvas suitable for portrait display.
-   864x672: Aspect ratio 4:3, width is 4/3 times the height. Pixel size 864x672, slightly square-like canvas, suitable for general display.
-   672x864: Aspect ratio 3:4, width is 3/4 times the height. Pixel size 672x864, slightly vertical rectangle, suitable for general display.

```java
curl -X POST "https://api.zhishuyun.com/qrart/generate?token={token}" \
  -H "accept: application/json" \
  -H "content-type: application/json" \
  -d '{
    "type": "link",
    "content": "https://data.zhishuyun.com",
    "prompt": "Fish",
    "aspect_ratio": "576x1008"
  }'
```

## QR Code Pixel Style `pixel_style`

We can customize the QR code pixel style by passing `pixel_style`. Available options:

- square: Uses square pixel units; each pixel unit is square-shaped.
- rounded: Pixel units with rounded corners, making the QR code look softer and more modern.
- dot: Uses small dots as pixel units, creating a dotted effect similar to printing.
- squircle: Rounded square, similar to rounded rectangles but closer to circles, giving a unique style.
- row: Pixel units arranged in rows, creating a horizontal pattern.
- column: Pixel units arranged in columns, creating a vertical pattern.

Style preview:

![](https://cdn.zhishuyun.com/2023-08-28-172007.png)

## QR Code Frame Style `marker_shape`

`marker_shape` customizes the positioning frame style. Options:

- square: Square shape, used to highlight specific positions or elements.
- circle: Circular shape, used to mark key areas or elements.
- plus: Plus shape, similar to a cross, used to highlight attention or specific information.
- box: Box shape, like an outlined rectangle, used to surround areas or elements.
- octagon: Octagonal shape with unique corners, for visual attraction.
- random: Random shapes, adding artistic and visual interest.
- tiny-plus: Tiny plus signs, used to mark fine elements or details.

Style preview:

![](https://cdn.zhishuyun.com/2023-08-28-172144.png)

## QR Code Sub-Marker Style `sub_marker`

`sub_marker` defines the shape of sub-markers (smaller markers). Options:

- square: Square sub-marker shape, used to highlight specific position details.
- circle: Circular sub-marker shape, emphasizing key details or elements.
- box: Box-shaped sub-marker, similar to outlined rectangles, suitable for marking small areas.
- random: Random shapes, adding artistic and visual interest.
- plus: Plus-shaped sub-marker, similar to a cross, used to mark fine information or elements.

## QR Code Rotation Angle `rotate`

`rotate` controls the QR code rotation angle. Options:

- 0: No rotation, QR code keeps original orientation.
- 90: Rotate QR code 90 degrees clockwise, displaying vertically.
- 180: Rotate QR code 180 degrees, upside down.
- 270: Rotate QR code 270 degrees clockwise, displaying in reverse vertical orientation.
