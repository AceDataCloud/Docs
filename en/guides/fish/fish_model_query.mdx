This API is based on the [Fish Audio official Model API](https://docs.fish.audio/resources/api-reference/model), and is used to **paginate and retrieve the Fish public voice library or cloned voices under the current account**. The endpoint is `GET https://api.acedata.cloud/fish/model`.

> To create a voice, please refer to [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); to query details of a single voice by `_id`, please refer to [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Application Process

To use the Fish Model API, first go to the [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) to obtain your API Token and keep it for later use.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

If you have not yet logged in or registered, you will be automatically redirected to the login page and invited to register and log in. After completion, you will automatically return to the current page.

**One API Token can call all platform services; there is no need to apply separately for each service.** Your first application includes free credits for a free trial; when credits are insufficient, you can recharge your general balance in the [console](https://platform.acedata.cloud/console/coin).

> 📘 Full documentation: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Query Parameters

| Parameter             | Type    | Default | Description                                                                                  |
| ---------------- | ------- | ---- | ------------------------------------------------------------------------------------- |
| `page_size`      | integer | 10   | Number of items per page.                                                                            |
| `page_number`    | integer | 1    | Page number, starting from 1.                                                                          |
| `title`          | string  | —    | Fuzzy search by title.                                                                      |
| `tag`            | string  | —    | Filter by a single tag.                                                                      |
| `self`           | boolean | —    | When `true`, returns only voices created and saved through this platform by the account making the current call.                                |
| `author_id`      | string  | —    | Filter by voice author ID.                                                                  |
| `language`       | string  | —    | Filter by voice language, such as `en`, `zh`, or `es`.                                                  |
| `title_language` | string  | —    | Filter by title language in the public voice library.                                                        |
| `sort_by`        | string  | —    | Sort field; when `self=true`, supports `created_at` and `task_count`.                              |

## Example 1: Default Pagination (by `page_size`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=2'
```

```shell

  -H 'authorization: Bearer {token}' \
```

## Example 3: List Only Voices Created by Yourself (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Response example:


`self=true` lists the voices created and saved through this platform by the actual calling account; voices created by the same account using different API Tokens will also be listed together. Results are paginated in reverse chronological order by creation time, and `author_id` can further filter the author ID of these voices. This parameter only filters the list; the voices remain publicly available.

`self=true` does not support `title_language`; if you need to search by title language, please query the public voice library.

## Example 4: Filter by Language + Tag

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> `tag` matching is relatively lenient; if there are 0 matches, consider using fuzzy matching with `title` instead.

## Response Fields

Each item in `items[]` is a complete ModelEntity object. Common fields include:

| Field            | Type       | Description                                        |
| ------------- | -------- | ----------------------------------------- |
| `_id`         | string   | Voice ID, used as the value of `reference_id` in `/fish/tts`. |
| `type`        | string   | Model type, usually `tts`.                           |
| `title`       | string   | Voice name.                                     |
| `description` | string   | Voice description.                                     |
| `state`       | string   | Training status: `trained` indicates availability.                      |
| `tags`        | string[] | Public library tags.                                    |
| `languages`   | string[] | Languages the voice is proficient in.                                  |
| `visibility`  | string   | `public` or `private`.                     |
| `samples`     | object[] | Preset samples (including direct `audio` links).                       |
| `like_count`  | integer  | Number of likes in the public library.                                   |
| `task_count`  | integer  | Number of historical synthesis requests.                                   |
| `author`      | object   | Voice author information: `_id` / `nickname` / `avatar`.     |
| `total` (top level)   | integer  | Total number of items matching the criteria.                                 |
| `has_more`    | boolean? | A boolean when `self=true`; may be `null` for public voice library queries.      |

## Billing Information

This API is not billed—paginated voice list queries are free operations. Creating voices ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) is also free. Charges are incurred only based on usage when calling [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) to synthesize speech.

## Error Handling

- `400 token_mismatched`: Request parameters are missing or invalid.
- `401 invalid_token`: The authentication token does not exist or is invalid.
- `429 too_many_requests`: The account rate limit has been triggered.
- `500 api_error`: Internal server error.

Error response example:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusion

To select a voice from the Fish public library for the `reference_id` of `/fish/tts`, first use this API with `title` / `tag` / `language` to search, identify the target `_id`, and then use [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) to retrieve samples for listening. To list voices you created yourself, simply pass `self=true`.
