This article describes the integration for the Fish Model API. The endpoint is fully compatible with the [Fish Audio official OpenAPI](https://docs.fish.audio/resources/api-reference/model) and exposes:

- `POST /fish/model`: create a new cloned Voice Model from one or more audio samples.
- `GET /fish/model`: list voice models visible to the current account or to the platform.

## Application Process

To use the API, first apply for the corresponding service on the [Fish Model API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509) page and click the "Acquire" button.

If you are not yet logged in or registered, you will be redirected to the login page; after signing in you will be returned to the current page.

A free quota is granted on the first acquisition so the API can be tried for free.

## Differences from the Official API

- **Authentication**: use `Authorization: Bearer {token}` where `{token}` is the credential issued by this platform.
- **Sample upload on create**: only the JSON form is supported on this endpoint, with audio samples passed as URLs in the `voices` field. The Fish Audio official endpoint also accepts multipart and msgpack binary uploads — that path is not implemented here yet. The URL-based form covers roughly 80% of common usage.
- **Response shape**: both `POST /fish/model` and `GET /fish/model` forward the upstream Fish response verbatim with no platform envelope wrapping. Errors use the platform-standard `{success:false, error:{code,message}, trace_id}` shape.

## Create a Voice Model (POST /fish/model)

The minimum request needs `title` and `voices`. `voices` is a list of audio sample URLs; each file should ideally be at least 30 seconds long with a sample rate of 16 kHz or higher.

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "My cloned voice",
    "description": "Cloned from a podcast recording",
    "voices": [
      "https://example.com/sample-voice.mp3"
    ],
    "cover_image": "https://example.com/cover.png",
    "visibility": "private"
  }'
```

A successful response is the Fish-Audio ModelEntity directly:

```json
{
  "_id": "d7900c21663f485ab63ebdb7e5905036",
  "type": "tts",
  "title": "My cloned voice",
  "description": "Cloned from a podcast recording",
  "cover_image": "https://example.com/cover.png",
  "train_mode": "fast",
  "state": "trained",
  "tags": [],
  "samples": [],
  "created_at": "2025-05-09T12:34:56.789Z",
  "updated_at": "2025-05-09T12:34:56.789Z",
  "languages": ["en", "zh"],
  "visibility": "private",
  "lock_visibility": false,
  "like_count": 0,
  "mark_count": 0,
  "shared_count": 0,
  "task_count": 0,
  "author": {
    "_id": "user_id",
    "nickname": "user_nickname",
    "avatar": "user_avatar"
  }
}
```

The returned `_id` can be passed as `reference_id` to the [Fish TTS API](https://platform.acedata.cloud/documents/77adcb84-d59f-5ef9-b8a0-8b35eb42a71d) to synthesize speech with this voice.

## List Voice Models (GET /fish/model)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=10' \
  --data-urlencode 'page_number=1' \
  --data-urlencode 'self=true'
```

Supported query parameters (matching the Fish Audio official spec):

- `page_size`: items per page, default 10.
- `page_number`: page index, starts at 1.
- `title`: fuzzy search by title.
- `tag`: filter by tag.
- `self`: `true` to return only models created by the current account.
- `author_id`: filter by creator.
- `language`: filter by voice language.
- `title_language`: filter by title language.

A successful response forwards the Fish paginated structure directly:

```json
{
  "items": [
    {
      "_id": "d7900c21663f485ab63ebdb7e5905036",
      "title": "My cloned voice",
      "description": "Cloned from a podcast recording",
      "cover_image": "https://example.com/cover.png",
      "type": "tts",
      "state": "trained",
      "tags": [],
      "languages": ["en", "zh"],
      "visibility": "private",
      "created_at": "2025-05-09T12:34:56.789Z",
      "updated_at": "2025-05-09T12:34:56.789Z"
    }
  ],
  "total": 1
}
```

## Billing

Only the create operation is billable (`POST /fish/model` with a `voices` field in the request body). Listing voice models with `GET /fish/model` does not consume credits.

## Error Handling

- `400 token_mismatched`: Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`: Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`: Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`: Too many requests, you have exceeded the rate limit.
- `500 api_error`: Internal server error, something went wrong on the server.

### Error Response Example

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusion

The Fish Model API mirrors the Fish Audio official ModelEntity endpoints and can replace existing code with no shape changes. The `_id` returned by `POST /fish/model` plugs directly into the `reference_id` field of [Fish TTS API](https://platform.acedata.cloud/documents/77adcb84-d59f-5ef9-b8a0-8b35eb42a71d) to perform speech synthesis with the cloned voice.
