Submit tasks via `POST /kling/apparel`, and use the existing `POST /kling/tasks` to query platform task status.

## Input

Provide a product description of up to 2,500 characters, a 5–180 second reference video, and 1–5 product images. You may additionally provide 1–5 model images, a background music file, and specify a voiceover timbre; if no timbre is specified, native spoken narration will be used.

The following is an example request structure. Replace the asset URLs before calling.

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "Your product or spoken narration content"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## Results and Billing

Synchronous mode returns the generated result; asynchronous mode first returns a `task_id`, and the completed result includes video or image links in `data` and server-calculated `usage`. `callback_url` is used for completion notifications; requests with `watermark=true` return a watermarked version as well.

Native spoken narration: 1.82 Credits/second for 720p and 2.38 Credits/second for 1080p; specified voiceover: 2.38 Credits/second for 720p and 2.8 Credits/second for 1080p. Videos are billed based on the actual generated duration. The per-second base price before generation does not represent the total price of the entire task. Failed tasks are not charged generation fees.
