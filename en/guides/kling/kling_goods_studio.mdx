Submit tasks via `POST /kling/goods-studio`, and use the existing `POST /kling/tasks` to query platform task status.

## Input

Provide 1–5 product images and a product title of up to 200 characters; the product description is optional, up to 2000 characters. Duration can optionally be 15, 30, or 60 seconds.

Below is an example request structure. Replace the asset URL before calling.

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "Your product or voice-over content"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## Results and Billing

Synchronous mode returns the generated result; asynchronous mode first returns a `task_id`, and the completed result includes video or image links in `data` and server-calculated `usage`. `callback_url` is used for completion notifications; requests with `watermark=true` also return a watermarked version.

720p: 2.38 Credits/second; 1080p: 2.8 Credits/second. Videos are billed based on the actual generated duration. The per-second base price before generation does not represent the total price of the entire task. Failed tasks are not charged generation fees.
