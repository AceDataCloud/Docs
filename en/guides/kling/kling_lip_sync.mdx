## Kling Lip Sync API

`POST https://api.acedata.cloud/kling/lip-sync`

Drive an existing Kling video (5s or 10s) with audio or text so the character speaks in sync. Pair with `/kling/videos` image2video for a full talking-photo pipeline.

### Request parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `mode` | string | yes | `audio2video` or `text2video` |
| `video_id` | string | one-of | ID of a Kling-generated video (e.g. from image2video), within 30 days |
| `video_url` | string | one-of | Public URL of a 5s/10s video |
| `audio_url` | string | for audio2video | Public URL of the driving audio |
| `text` | string | for text2video | Text to speak (max 120 chars) |
| `voice_id` | string | for text2video | Voice ID |
| `callback_url` | string | no | If set (or `async=true`), returns task_id and calls back |
