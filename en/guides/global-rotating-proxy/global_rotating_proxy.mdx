
## Code Integration

Below is an example in Python demonstrating how to set up the proxy:

```python
import requests

proxy = 'http://{proxy_username}:{proxy_password}@global.proxy.acedata.cloud:30007'

proxies = {
    'http': proxy,
    'https': proxy
}

for _ in range(3):
    resp = requests.get('https://ipinfo.io', proxies=proxies)
    print(resp.text)
```

Here, we first declare the proxy URL and assign it to the `proxy` variable. The protocol is HTTP, followed by the proxy username and password (as shown in the console, separated by a colon), then an `@` symbol, followed by the proxy address and port.

> Tip: You need to replace `{proxy_username}:{proxy_password}` in the code above with your proxy username and password. The final result should look like `proxy = 'http://1f78266a:eff0896726224fa2a99fe82dd1f07562@global.proxy.acedata.cloud:30007'` without the `{` and `}` characters.

Next, we declare a `proxies` variable with two key-value pairs: `http` and `https`, both set to the `proxy` variable. This means requests to HTTP and HTTPS websites will use the proxy defined by `proxy`. Then, a loop runs three times to test the proxy.

Of course, the proxy setup above is a relatively simple method.

In fact, the above code is equivalent to setting an additional header - Proxy Authorization during the request. Therefore, the code can also be rewritten as follows:

```python
import requests
import base64

proxy_host = 'global.proxy.acedata.cloud'
proxy_port = '30007'
proxy_username = '{proxy_username}' # 8-character username
proxy_password = '{proxy_password}' # 32-character password

credentials = base64.b64encode(
    f'{proxy_username}:{proxy_password}'.encode()).decode()

proxies = {
    'http': f'http://{proxy_host}:{proxy_port}',
    'https': f'http://{proxy_host}:{proxy_port}'
}

headers = {
    'Proxy-Authorization': f'Basic {credentials}'
}

for _ in range(3):
    resp = requests.get('https://ipinfo.io',
                        proxies=proxies, headers=headers)
    print(resp.text)
```

Here, we set the proxy username and password via the `Proxy-Authorization` request header (Base64 encoded). The effect of this code is the same.

For other languages, such as JavaScript with axios, a similar setup can be used:

```javascript
const axios = require("axios");
const base64 = require("base64");

const proxy_host = "global.proxy.acedata.cloud";
const proxy_port = "30007";
const proxy_username = "{proxy_username}"; // 8-character username
const proxy_password = "{proxy_password}"; // 32-character password

const credentials = base64.encode(`${proxy_username}:${proxy_password}`);

const proxies = {
  http: `http://${proxy_host}:${proxy_port}`,
  https: `http://${proxy_host}:${proxy_port}`,
};

const headers = {
  "Proxy-Authorization": `Basic ${credentials}`,
};

for (let i = 0; i < 3; i++) {
  axios
    .get("https://ipinfo.io", { proxies, headers })
    .then((resp) => console.log(resp.data))
    .catch((err) => console.error(err));
}
```

The effect is the same.

For other languages, please refer to the above examples and adapt accordingly.

## IP Persistence

Similarly, you can add `session` and a 5-digit fixed number to the username to achieve IP persistence for a period of time, valid for about 10 minutes.

For example, to fix the IP for a period, if the original username is `1f78266a`, you can modify it to `1f78266a-session-12345`. If `12345` remains unchanged, the IP will remain the same during this period. The curl command can be rewritten as:

```
curl -x 1f78266a-session-12345:eff0896726224fa2a99fe82dd1f07562@global.proxy.acedata.cloud:30007 https://ipinfo.io
```
