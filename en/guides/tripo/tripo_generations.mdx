---
title: "Tripo 3D Generation"
description: "Tripo 3D integration guide - Ace Data Cloud"
---

Call `POST /tripo/generations` to create a new model, providing text, a single image, or multiple views of the same object. Use an AceDataCloud Token; results are returned synchronously by default. When `async: true` or `callback_url` is provided, HTTP 200 and `task_id` are returned first. The completion callback has the same JSON structure as the synchronous result.

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

`action` defaults to `generate`. Choose one of three inputs: `prompt` (1–1024 characters), `image_url`, or `image_urls`. Images must be public HTTPS PNG/JPEG files no larger than 20 MiB. Multiple views are arranged in front, left, back, and right order; the front and at least one other view must be provided, and null can be used to skip intermediate views.

`model` defaults to `v3.1-20260211`; `v3.0-20250812`, `v2.5-20250123`, `P1-20260311`, or `P2-20260801` can also be explicitly selected. `texture` defaults to `standard`; use `none` for geometry only. Different models and texture tiers use different amounts of quota.

Download the GLB from `data[0].model_url`; `image_url` is an optional preview. Retain `data[0].id` for subsequent texture, conversion, or rigging operations. When retrying the same submission, retain the same `Idempotency-Key` and request body.
