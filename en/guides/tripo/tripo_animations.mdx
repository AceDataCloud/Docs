---
title: "Tripo Character Animation"
description: "Tripo 3D integration guide - Ace Data Cloud"
---

Call `POST /tripo/animations` and use `action` to select a rig check, auto-rigging, or animation retargeting. Pass `async: true` to poll `/tripo/tasks`, or pass `callback_url` to receive the final result.

1. **Check**. Send `{"action":"rig_check","model_id":"5db97adc-a877-4587-af16-bbf443aa55de"}`. The result item contains the boolean `riggable` and an optional `rig_type`. A successful check with `riggable: false` means the model is not suitable for rigging. This operation is free.
2. **Rig**. Send `{"action":"rig","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","model":"v3.0-20260909","rig_type":"biped","format":"GLB"}`. The result is a new rigged model; retain its `data[0].id`. Checking and rigging can also read existing files via `model_url`.
3. **Retarget**. Use the ID of the rigging result as `model_id`. For example, `{"action":"retarget","model_id":"96a66a1d-69d2-48f0-846b-bdf02ed9bcc4","animations":["preset:walk","preset:idle"],"format":"GLB","async":true}`. Select presets compatible with the rig version and type; pass `animation` for a single animation or `animations` for a batch, up to five, billed by the number of animations. A batch request can deliver one file containing multiple animation tracks.

Both rigging and retargeting support GLB and FBX. Use `export_with_geometry` to control whether the retargeting result includes geometry, and `animate_in_place` to control whether displacement is retained. The download URL for the model file is located at `data[0].model_url`.
