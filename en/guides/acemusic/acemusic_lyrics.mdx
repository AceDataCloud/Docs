---
title: "ACE Music lyrics API"
description: "ACE Music integration guide - Ace Data Cloud"
---

Generate a title and editable lyrics from a topic and optional style. Review the text, then use [custom song generation](https://platform.acedata.cloud/documents/acemusic-audios-integration). Lyrics generation is a separate paid operation.

```bash
curl --request POST 'https://api.acedata.cloud/acemusic/lyrics' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{"prompt":"A song about home and returning to family","style":"Warm acoustic folk"}'
```

`prompt` is required; `style` is optional. The request waits for the result. If it exceeds the wait budget, HTTP 202 returns the original task ID for polling. A completed result uses the `success`, `task_id`, and `trace_id` envelope. Its `data` array contains `title` and `text`; the text is an editable lyric draft, not an audio URL.

Successful lyrics generation is charged once. At the November 17, 2026 largest-package and exchange-rate reference, it is approximately US$0.001497 (CNY 0.01). Applicable package tiers, discounts, site pricing and exchange rates affect the effective amount. Failed generation is free; queries for an existing personal task are free.

If a request is interrupted, keep any received task ID and use the [tasks API](https://platform.acedata.cloud/documents/acemusic-tasks-integration). Do not automatically repeat a paid synchronous request. Authentication, access, balance, input and rate-limit errors follow the song API contract.
