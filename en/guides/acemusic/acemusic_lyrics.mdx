---
title: "ACE Music Lyrics Generation API"
description: "ACE Music integration guide - Ace Data Cloud"
---

Generate titles and lyrics based on themes and styles. After editing, they can be used for [ACE Music Custom Song Generation](https://platform.acedata.cloud/documents/acemusic-audios-integration). Lyrics generation is billed separately; calling the song generation API will not implicitly call this interface.

```bash
curl --request POST 'https://api.acedata.cloud/acemusic/lyrics' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{"prompt":"A Chinese song about hometown and returning home","style":"Warm Chinese-style folk music"}'
```

`prompt` is required; `style` is optional. This interface waits for synchronous results. When the waiting budget is exceeded, it returns HTTP 202 and a task ID; in this case, continue querying the original task. After completion, the result continues to use the `success`, `task_id`, and `trace_id` envelope, and `data` is a lyrics list containing `title` and `text`. `text` is editable lyrics, not an audio URL.

One lyrics fee is charged for each successful generation. Based on the maximum plan and exchange rate benchmark on 2026-11-17, it is equivalent to ¥0.01 RMB, approximately US$0.001497; actual conversion varies according to the plan used, discounts, site markups, and exchange rates. Failed generations are not charged. Querying completed personal tasks is free.

Keep any obtained task ID when the network is interrupted. Do not automatically resend synchronous billable requests; prioritize using the [Task API](https://platform.acedata.cloud/documents/acemusic-tasks-integration) to query the original task. Handling of permissions, balance, parameters, and rate limit errors is consistent with the song API.
