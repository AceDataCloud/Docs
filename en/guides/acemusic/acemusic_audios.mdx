Create a group of two song candidates from an idea or custom lyrics. Choose `acemusic-v1.1` (default) or `acemusic-v1`.

## Authentication

Acquire ACE Music in the [console](https://platform.acedata.cloud/console/applications), or use an authorized global application. Send `Authorization: Bearer YOUR_API_KEY`. Service access, application balance and credential limits apply.

## Generate from an idea

```bash
curl --request POST 'https://api.acedata.cloud/acemusic/audios' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'Idempotency-Key: music-draft-001' \
  --data '{"model":"acemusic-v1.1","custom":false,"prompt":"A warm folk song about coming home","async":true}'
```

For custom creation, set `custom=true` and provide `title`, `lyric`, and `style`. Use optional `[Verse]` and `[Chorus]` lyric markers. The [lyrics API](https://platform.acedata.cloud/documents/acemusic-lyrics-integration) creates an editable draft as a separate operation.

| Field | Meaning |
| --- | --- |
| `action` | Only `generate`; may be omitted |
| `model` | `acemusic-v1.1` or `acemusic-v1` |
| `custom` | `false` for an idea; `true` for custom lyrics |
| `prompt` | Required for idea mode |
| `lyric`, `style`, `title` | Required for custom mode |
| `async` | Defaults to `true`; save the returned task ID |
| `callback_url` | Optional HTTPS final-result callback; implies asynchronous execution |

Audio uploads, covers, extension, stems and voice parameters are outside this release. The generated performance and actual duration depend on the result.

## Retrieve the result

Save the platform `task_id` and use the [tasks API](https://platform.acedata.cloud/documents/acemusic-tasks-integration). Acceptance does not mean generation has completed. Final `data` contains tracks with `id`, `model`, `state`, `title`, `lyric`, `style`, actual `duration` in seconds, `audio_url`, and optional `image_url`.

The group succeeds after both audio files are available. A final partial failure uses `partial_failed` and retains the playable track. A missing cover does not prevent playback. After a refresh or network interruption, query the original task rather than submitting again.

The same `Idempotency-Key` and payload return the original task. A different payload with the same key conflicts. If acceptance is uncertain, retain the original identity and key; do not generate a new key and automatically resubmit.

## Pricing

A complete two-track group is charged once. Final failed or partial groups are free, and task queries are free. Lyrics generation is separately charged and is not implicitly invoked by song creation.

At the largest package and exchange-rate reference captured on November 17, 2026, a complete group is approximately US$0.02995 (CNY 0.20). Effective amounts vary with package tier, discounts, site pricing and later exchange rates. Check the console for applicable pricing.

## Callbacks and errors

Callbacks contain the final task result and may be redelivered. Deduplicate using `task_id` and acknowledge successful receipt. A failed callback does not regenerate music or add a charge; polling remains available.

Invalid input returns 400, invalid authentication or access returns 401/403, insufficient balance returns 402, rate limiting returns 429, and service failure returns 500. Asynchronous failures appear in the task's final state and `error`. Keep `task_id` and `trace_id` for support.
