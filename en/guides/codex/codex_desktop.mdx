---

Codex Desktop shares `~/.codex/config.toml` with Codex CLI.

## 1. Obtain API Key

Open the [Ace Data Cloud application list](https://platform.acedata.cloud/console/applications), enter the available application, and copy the API Key.

![Obtain Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Set API Key

macOS：

```bash
launchctl setenv ACEDATACLOUD_API_KEY "your API Key"
```

Windows PowerShell：

```powershell
setx ACEDATACLOUD_API_KEY "your API Key"
```

## 3. Configure AceDataCloud

Edit `~/.codex/config.toml` (for Windows, it is `%USERPROFILE%\.codex\config.toml`), and add:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

For Windows, change the last two lines to:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

No need to fill in `model`; simply select the model after opening Codex.

## 4. Restart and Verify

Completely exit and reopen Codex Desktop, create a local task, and send a simple message. The Provider should display as `acedatacloud`; actual calls can be viewed in the [Usage History](https://platform.acedata.cloud/console/usages).

If the configuration does not take effect, ensure that you have modified the current user's `~/.codex/config.toml`, the environment variable has been set, and then restart the application completely again. Cloud tasks or automation running in different environments need to configure the Key separately in the corresponding environment.
