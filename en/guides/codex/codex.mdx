Codex CLI, Desktop, and VS Code extension share `~/.codex/config.toml`. Configure the `acedatacloud` provider once to use Codex through Ace Data Cloud.

| Usage Method     | Configuration Guide                                                                                   |
| ---------------- | ----------------------------------------------------------------------------------------------------- |
| Terminal / CLI   | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)                    |
| Desktop          | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)                 |
| VS Code          | [Codex for VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)              |
| Graphical Switch  | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration)            |

There are only three common configurations:

- Provider: `acedatacloud`
- Base URL: `https://api.acedata.cloud/v1`
- API Key: Obtain from [Application List](https://platform.acedata.cloud/console/applications) and save to `ACEDATACLOUD_API_KEY`

There is no need to fix the model in the access configuration; you can select the model directly after starting Codex.

Return to the [Coding Plan Configuration Center](https://platform.acedata.cloud/documents/coding-plan-integration).
