## 1. Obtain API Key

Open the [Ace Data Cloud application list](https://platform.acedata.cloud/console/applications), access the available applications, and copy the API Key.

![Get Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Install CC Switch

Download from [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), it can also run on macOS:

```bash
brew install --cask cc-switch
```

## 3. Add Provider

Open CC Switch, select **Claude Code → Add Provider → Custom**, and fill in:

| Field       | Value                          |
| ----------- | ------------------------------ |
| Name        | `Ace Data Cloud`              |
| Base URL    | `https://api.acedata.cloud`   |
| API Key     | The API Key just copied        |
| API Format  | `Anthropic Messages`           |

If you need to use the JSON editor, configure it as:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

CC Switch will write the configuration into the user settings of Claude Code. Do not save the real Key in the team repository, and do not keep the old `ANTHROPIC_API_KEY` at the same time.

## 4. Enable and Verify

After saving, enable **Ace Data Cloud**, and reopen Claude Code. Send a simple read-only task and check the calls in [Usage History](https://platform.acedata.cloud/console/usages). If the old configuration is still used after switching, completely exit Claude Code and CC Switch and try again.
