Cursor is an AI programming editor based on VS Code with rich built-in AI features. The Claude Code VS Code extension is fully compatible with Cursor. You can install the Claude Code extension in Cursor to get a native Agentic Coding experience—automatically reading codebases, editing across files, running terminal commands, and completing complex programming tasks directly in Cursor.

This document mainly introduces how to configure and use the Claude Code extension in Cursor through the AceData Cloud proxy service.

## Application Process

To use Claude Code, you can first go to the [Claude Messages service page](https://platform.acedata.cloud/documents/claude-messages) and click the "Acquire" button to obtain the credentials needed for the request:

![](https://cdn.acedata.cloud/nyq0xz.png)

If you are not logged in or registered, you will be automatically redirected to the login page inviting you to register and log in. After logging in or registering, you will be automatically returned to the current page.

There is a free quota available for first-time applicants, allowing you to experience Claude Code services for free.

## Install Plugin

### System Requirements

- Cursor latest version (based on VS Code 1.98.0+)

### Installation Steps

In Cursor, press `Cmd+Shift+X` (Mac) or `Ctrl+Shift+X` (Windows/Linux) to open the extension view, search for **Claude Code**, find the plugin published by Anthropic, and click "Install":

![Claude Code Plugin in Cursor Extension Marketplace](https://cdn.acedata.cloud/10ddf71320.png)

You can also install directly via the following link:

- [Cursor Installation Link](cursor:extension/anthropic.claude-code)

After installation, select trust in the pop-up information prompt to complete the installation.

> If the extension does not appear after installation, please restart Cursor or execute "Developer: Reload Window" in the command palette.

## Configure AceData Cloud API

The first time you open the plugin, you will be prompted to log in to the official Anthropic account. You can skip the official login and use the AceData Cloud proxy API configuration instead, **without an official subscription**.

### Step 1: Configure Environment Variables

You can choose to configure environment variables in any of the following locations:

**Option A: User-level Configuration (Applicable to all projects)**

Edit `~/.claude/settings.json` (create it if it does not exist), add the `env` configuration, and replace `{token}` with the API token obtained from the AceData Cloud console:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

**Option B: Project-level Configuration (Current project only)**

Create `.claude/settings.json` (shared configuration) or `.claude/settings.local.json` (personal configuration, gitignored) in the project root directory:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Tip**: The API token can be viewed in the [AceData Cloud Console](https://platform.acedata.cloud/console). The value of `ANTHROPIC_AUTH_TOKEN` will automatically have the `Bearer` prefix added when sent to the server. Project-level configuration takes priority over user-level configuration. It is recommended to use `.claude/settings.json` for shared team configuration and `.claude/settings.local.json` for personal sensitive information.

### Step 2: Disable Login Prompt (Optional)

If you don't want to see the login prompt every time you open Cursor, you can disable it:

Press `Cmd+,` (Mac) or `Ctrl+,` (Windows/Linux) to open settings, search for "Claude Code login", and check the **Disable Login Prompt** option.

After configuration is complete, reopen the Claude Code plugin panel to start using it.

## Open the Claude Code Panel

After installation and configuration, there are several ways to open Claude Code:

| Method | Operation |
|--------|-----------|
| **Editor Toolbar** | Click the ✦ Spark icon in the top-right corner (requires a file to be open) |
| **Status Bar** | Click "✱ Claude Code" on the right side of the bottom status bar (no file needed) |
| **Command Palette** | `Cmd+Shift+P` / `Ctrl+Shift+P`, search for "Claude Code" |
| **Shortcut** | `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux) to toggle focus |

Claude Code defaults to using the **editor area view** as the chat area, providing a larger visible area. You can also drag the panel to the sidebar or other positions.

## Differences Between Cursor Built-in AI and Claude Code

Cursor comes with built-in AI programming features (Tab completion, Cmd+K editing, Chat, etc.). The Claude Code extension runs as an independent Agent, complementing Cursor's built-in AI:

| Feature | Cursor Built-in AI | Claude Code Extension |
|---------|-------------------|----------------------|
| **Work Mode** | Inline completion + chat | Full Agent (autonomously reads/writes files, executes commands) |
| **Code Editing** | Single file inline editing | Cross-file autonomous editing with Diff review |
| **Terminal Operations** | Does not directly operate terminal | Can run terminal commands (install dependencies, run tests, etc.) |
| **Context** | Manually select context | Automatically analyzes entire codebase |
| **Permission Control** | None | Multi-level permission modes (Ask / Plan / Auto) |
| **MCP Support** | Cursor has its own MCP | Claude Code has independent MCP configuration |

Both can be used simultaneously without conflict.

## Basic Usage

### Conversational Interaction

Type natural language directly in the Claude Code panel to interact with Claude. For example:

- "Help me analyze the overall architecture of this project"
- "This code has a Bug, help me fix it"
- "Refactor this function to improve readability"
- "Write unit tests for this module"

Claude Code will automatically understand your codebase context and analyze and edit across files. When Claude needs to modify files, it displays a Diff comparison view where you can choose to accept or reject changes.

### Context References

Use the `@` symbol in the conversation to reference specific files or context:

- `@filename.py` — Reference a specific file (supports fuzzy matching)
- `@src/components/` — Reference an entire directory (requires trailing slash)
- `@terminal:name` — Reference terminal output

After selecting code in the editor, press `Option+K` (Mac) / `Alt+K` (Windows/Linux) to quickly insert an `@` reference (e.g., `@app.ts#5-10`).

### Slash Commands

Click the `/` icon in the dialog box, or type `/` directly, to use rich built-in features:

| Command | Function |
|---------|----------|
| `/new` | New conversation |
| `/model` | Switch model |
| `/compact` | Compact context |
| `/mcp` | Configure MCP services |
| `/config` | Open settings |
| `/usage` | View usage |
| `/memory` | Manage Claude memory |
| `/help` | Show help information |

### Review Code Changes

When Claude needs to modify files, it displays a Diff comparison view showing the original code and the comparison after modification. You can choose to accept or reject each change, or tell Claude what you'd prefer instead.

### Permission Modes

Switch between different permission modes using the mode indicator at the bottom of the panel:

| Mode | Description |
|------|-------------|
| **Default (Ask)** | Asks for confirmation before each operation (default) |
| **Plan** | Claude creates a plan and waits for approval before executing |
| **acceptEdits** | Automatically accepts file edits, but terminal commands still require confirmation |
| **bypassPermissions** | Skips all permission prompts for full automation (use with caution) |

### Multiple Parallel Sessions

Use **Open in New Tab** or **Open in New Window** from the Command Palette to start multiple independent conversations. Each conversation maintains its own history and context, allowing parallel work on different tasks.

## Other Settings

### Switch Models

Claude Code supports switching between different models, such as Claude Sonnet, Claude Opus, etc. You can configure this through the `/model` command or in the **Selected Model** plugin setting.

### Auto Mode

In the plugin settings, set **Initial Permission Mode** to `bypassPermissions`. Once enabled, Claude Code will not prompt for confirmation when performing file edits, terminal commands, etc., achieving a fully automated workflow.

You can also set it to `acceptEdits` for a semi-automatic mode that automatically accepts edits but still requires confirmation for terminal commands.

> **Note**: Before enabling auto mode, make sure you understand the risks. It is recommended to use it in trusted project environments.

### Use CLI in Terminal

If you prefer a command-line style, check **Use Terminal** in Cursor settings. Claude Code will run in CLI mode in the integrated terminal. You can also open Cursor's integrated terminal directly and run the `claude` command.

## FAQ

### What to do if connection fails?

1. Confirm that the environment variables in `~/.claude/settings.json` or `.claude/settings.json` are correctly configured, especially `ANTHROPIC_AUTH_TOKEN` and `ANTHROPIC_BASE_URL`
2. Confirm the API token is valid (check in the [Console](https://platform.acedata.cloud/console))
3. Check that the network connection is working and you can access `https://api.acedata.cloud`
4. Restart Cursor and try again

### Will Claude Code conflict with Cursor's built-in AI?

No. Claude Code runs as an independent extension and does not affect Cursor's Tab completion, Cmd+K, Chat, and other features. You can use both simultaneously.

### Spark icon not visible?

1. Make sure a file is open (just opening a folder is not enough)
2. Confirm Cursor is on the latest version
3. Execute "Developer: Reload Window" in the command palette
4. Or click "✱ Claude Code" in the bottom status bar directly

### How to check remaining credits?

Log in to the [AceData Cloud Console](https://platform.acedata.cloud/console) to view your current account's remaining credits and usage.
