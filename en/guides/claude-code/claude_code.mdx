Claude Code is a programming AI agent launched by Anthropic, usable in various environments such as terminals, IDEs, and desktop applications. By using the AceData Cloud proxy, you can access Claude Code at a lower cost.

> **First time connecting?** It is recommended to first read [Claude Code 5-Minute Quick Start](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) — from obtaining credentials to running your first command, completed in five steps.

Choose the complete configuration guide for the corresponding platform based on your usage scenario:

| Platform | Description | Tutorial Link |
|----------|-------------|---------------|
| **⚡ 5-Minute Quick Start** | From obtaining credentials to the first `claude` command, completed in five steps | [5-Minute Tutorial](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) |
| **Terminal (CLI)** | Core experience, start by running `claude` in any terminal | [Terminal Configuration Guide](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code** | Native extension supporting inline Diff, @-mentions, and planned reviews | [VS Code Configuration Guide](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | VS Code compatible editor, fully supports Claude Code extension | [Cursor Configuration Guide](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **JetBrains IDE** | Supports IntelliJ IDEA, PyCharm, WebStorm, and the entire JetBrains IDE family | [JetBrains Configuration Guide](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automate code reviews and Issue handling using `@claude` | [GitHub Actions Configuration Guide](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |
| **Desktop Application (Preview)** | Standalone graphical client supporting parallel sessions and external tool connections | [Desktop Application Configuration Guide](https://platform.acedata.cloud/documents/claude-code-desktop-integration) |

> **Tip**: For first-time applicants, visit the [Claude Messages service page](https://platform.acedata.cloud/documents/claude-messages) and click "Acquire" to get credentials and receive free quota.
