Claude Code is a programming agent launched by Anthropic, which can be used in various environments such as terminals, IDEs, and desktop applications. By using the AceData Cloud proxy, you can use Claude Code at a lower cost.

> **First time here?** Start with the [Claude Code 5-Minute Quick Start](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) — it walks you from acquiring credentials to your first successful `claude` command in five steps.

Pick the tutorial that matches how you want to use Claude Code:

| Platform            | Description                                 | Tutorial Link                                                                                              |
| ------------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **⚡ 5-Minute Quick Start** | From acquiring credentials to your first `claude` command, in five steps | [5-Minute Quick Start](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) |
| **Terminal (CLI)**  | Core experience, run `claude` in any terminal to get started | [Terminal Configuration Tutorial](https://platform.acedata.cloud/documents/claude-code-terminal-integration)                    |
| **VS Code**        | Native extension, supports inline Diff, @-mentions, scheduled reviews | [VS Code Configuration Tutorial](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)               |
| **Cursor**         | VS Code compatible editor, fully supported by Claude Code extension | [Cursor Configuration Tutorial](https://platform.acedata.cloud/documents/claude-code-cursor-integration)                 |
| **JetBrains IDE**  | Supports all IDEs including IntelliJ IDEA, PyCharm, WebStorm | [JetBrains Configuration Tutorial](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)          |
| **GitHub Actions** | Automate code reviews and issue handling with `@claude` | [GitHub Actions Configuration Tutorial](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |
| **Desktop App (Preview)** | Standalone GUI client with parallel sessions and external connectors | [Desktop App Configuration Tutorial](https://platform.acedata.cloud/documents/claude-code-desktop-integration) |

> **Tip**: First-time applicants can visit the [Claude Messages service page](https://platform.acedata.cloud/documents/claude-messages) and click "Acquire" to obtain a credential, which includes free credits.
