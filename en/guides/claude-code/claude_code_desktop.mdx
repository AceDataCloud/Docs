Claude Code is an **Agentic Coding** tool launched by Anthropic, also known as one of the world's most powerful programming agents. The Claude Code desktop application provides an independent graphical interface, supporting features such as Diff review, parallel sessions (isolated via Git Worktree), remote sessions, and more, without relying on any IDE.

> **Important**: The Claude Code desktop application **does not support** third-party API proxies (including AceData Cloud). The desktop app only authenticates via Anthropic's official subscriptions (Pro, Max, Teams, Enterprise). Environment variables such as `ANTHROPIC_API_KEY` and `ANTHROPIC_AUTH_TOKEN` **do not take effect** in the desktop app.
>
> If you need to use Claude Code through the AceData Cloud proxy, please use one of the following:
> - [Terminal CLI Configuration Tutorial](https://platform.acedata.cloud/documents/claude-code-terminal-integration) (Recommended)
> - [VS Code Extension Configuration Tutorial](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)
> - [JetBrains IDE Configuration Tutorial](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)

## Desktop App Overview

### System Requirements

- macOS (Intel and Apple Silicon) or Windows (x64 / ARM64)
- Linux desktop application is not currently supported
- Requires an Anthropic official subscription (Pro, Max, Teams, or Enterprise)

### Download and Install

Go to the [Claude official download page](https://claude.ai) to download the installation package for your platform:

- **macOS**: Download the `.dmg` file and drag it into the Applications folder
- **Windows x64**: Download the `.exe` installation package and follow the prompts to install
- **Windows ARM64**: Download the ARM64 version (Note: ARM64 does not support local sessions and requires remote sessions)

![Claude Desktop Application Download Page](https://cdn.acedata.cloud/c3c8c57264.png)

After installation, launch Claude from the Applications folder (macOS) or Start menu (Windows).

## Features

The desktop app adds these capabilities on top of the standard Claude Code experience:

- **Visual Diff Review**: Code change review with inline comments
- **App Preview**: Built-in dev server for live previews
- **PR Monitoring**: GitHub PR status monitoring with auto-fix and auto-merge
- **Parallel Sessions**: Multi-session support with automatic Git Worktree isolation
- **Scheduled Tasks**: Run Claude tasks on a recurring schedule
- **Connectors**: GitHub, Slack, Linear, Notion and more external integrations
- **Multiple Environments**: Local, SSH, and Cloud runtime environments

### Permission Modes

| Mode       | Description                          |
|------------|--------------------------------------|
| **Ask**    | Ask for confirmation before each modification (recommended for beginners) |
| **Code**   | Automatically accept file edits, but terminal commands still require confirmation |
| **Plan**   | Create a detailed plan and wait for approval before execution |

### Connect External Tools

Before starting a session, click the **+** button and select **Connectors** to add external integrations:

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- More...

### Relationship with CLI

The desktop application and CLI use the same underlying engine and share the following configurations:

- `CLAUDE.md` / `CLAUDE.local.md` project memory files
- `~/.claude.json` / `.mcp.json` MCP server configurations
- `~/.claude/settings.json` settings
- Hooks and Skills configurations

Both can run simultaneously on the same project, each maintaining independent session histories.
