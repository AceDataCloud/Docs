Claude Code is an **Agentic Coding** tool launched by Anthropic, also known as one of the world's most powerful programming agents. The Claude Code desktop application provides an independent graphical interface, supporting features such as Diff review, parallel sessions (isolated via Git Worktree), remote sessions, and more, without relying on any IDE.

This document mainly introduces how to configure and use the Claude Code desktop application through the proxy service of AceData Cloud.

> **Note**: The Claude Code desktop application is currently in the preview stage and only supports macOS and Windows.

## Application Process

To use Claude Code, you can first go to the [Claude Messages service page](https://platform.acedata.cloud/documents/claude-messages) and click the "Acquire" button to obtain the credentials needed for the request:

![](https://cdn.acedata.cloud/nyq0xz.png)

If you are not logged in or registered, you will be automatically redirected to the login page inviting you to register and log in. After logging in or registering, you will be automatically returned to the current page.

You will receive a free quota upon your first application, allowing you to experience Claude Code services for free.

## Install Desktop Application

### System Requirements

- macOS (Intel and Apple Silicon) or Windows (x64 / ARM64)
- Linux desktop application is not currently supported

### Download and Install

Go to the [Claude official download page](https://claude.ai) to download the installation package for your platform:

- **macOS**: Download the `.dmg` file and drag it into the Applications folder
- **Windows x64**: Download the `.exe` installation package and follow the prompts to install
- **Windows ARM64**: Download the ARM64 version (Note: ARM64 does not support local sessions and requires remote sessions)

![Claude Desktop Application Download Page](https://cdn.acedata.cloud/c3c8c57264.png)

After installation, launch Claude from the Applications folder (macOS) or Start menu (Windows).

## Configure AceData Cloud API

After launching the desktop application, you need to log in to your Anthropic account. You can use environment variables to configure the AceData Cloud proxy API, **without the need for an official subscription**.

The desktop application reads environment variables from your Shell environment, so you need to set them in your Shell configuration file.

### Configure Environment Variables

**macOS Users**

Add the following content to `~/.zshrc` (or `~/.bashrc`), replacing `{token}` with your API token:

```bash
# AceData Cloud - Claude Code Proxy Configuration
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

After saving, execute:

```bash
source ~/.zshrc
```

**Windows Users**

Add the following system environment variables through "System Properties → Advanced → Environment Variables":

| Variable Name            | Value                           |
| ------------------------ | ------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`  | `{token}` (replace with your API token) |
| `ANTHROPIC_BASE_URL`    | `https://api.acedata.cloud`   |

Or use PowerShell:

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**You can also configure via settings.json**

Edit `~/.claude/settings.json` (create it if it does not exist):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Tip**: The API token can be viewed in the [AceData Cloud Console](https://platform.acedata.cloud/console). After configuration, you need to **restart the desktop application** for the environment variables to take effect.

## Basic Usage

### Open Project

1. Launch the Claude desktop application
2. Click on the **Code** tab at the top
3. Select **Local** running mode
4. Click **Select folder** to choose your project directory

### Start Conversation

Enter a natural language description of your needs in the input box:

- "Find TODO comments and fix them"
- "Add tests for the main function"
- "Explain the architecture of this project"

Claude will analyze your codebase, propose modification plans, and display changes in a Diff view.

### Permission Mode

Switch using the mode selector next to the send button:

| Mode       | Description                          |
|------------|--------------------------------------|
| **Ask**    | Ask for confirmation before each modification (recommended for beginners) |
| **Code**   | Automatically accept file edits, but terminal commands still require confirmation |
| **Plan**   | Create a detailed plan and wait for approval before execution |

### Parallel Sessions

Click the **+ New session** in the sidebar to start multiple parallel sessions. For Git repositories, each session will obtain an independent project copy via Worktree, without interference.

Worktree is stored by default in the `~/.claude-worktrees/` directory.

### Diff Review

When Claude modifies files, it will display change statistics (e.g., `+12 -1`), and clicking will open the Diff viewer for file-by-file review of modifications. You can also click specific lines of code to add comments, and Claude will adjust based on your feedback.

## Connect External Tools

Before starting a session, click the **⋯** button and select **Connectors** to add external integrations:

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- More...

After connecting, Claude can directly read calendars, send messages, create issues, and more.

## Relationship with CLI

The desktop application and CLI use the same underlying engine and share the following configurations:

- `CLAUDE.md` / `CLAUDE.local.md` project memory files
- `~/.claude.json` / `.mcp.json` MCP server configurations
- `~/.claude/settings.json` settings
- Hooks and Skills configurations

Both can run simultaneously on the same project, each maintaining independent session histories.

## Frequently Asked Questions

### What to do if the connection fails?

1. Check if the `~/.claude/config.json` file is correctly created
2. Confirm that environment variables are correctly set (restart the desktop application for them to take effect)
3. Confirm that the API token is valid (can be viewed in the [console](https://platform.acedata.cloud/console))
4. If using `settings.json` to configure environment variables, ensure the file format is correct

### What if the installed tools cannot be found?

If Claude cannot find commands like `npm`, `node`, etc.:

1. Confirm that these tools work normally in a regular terminal
2. Check your Shell configuration file (`~/.zshrc`, `~/.bashrc`) to ensure PATH is correctly set
3. Restart the desktop application to reload environment variables

### How to check the remaining quota?

Log in to the [AceData Cloud Console](https://platform.acedata.cloud/console) to view the current account's remaining quota and usage.
