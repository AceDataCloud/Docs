OpenAI recently provided an interface for creating model responses. It accepts text or image inputs to generate text or image outputs. The model can call your own custom code or use built-in tools such as web search or file search to use your own data as input for the model's responses.

This document mainly introduces the usage process of the OpenAI Responses API operations, which allows us to easily use the official OpenAI model response creation features.

## Application Process

To use the OpenAI Responses API, first visit the [OpenAI Responses API](https://platform.acedata.cloud/documents/81e285a6-d010-4a2d-a3a8-ca113d4ef82a) page and click the "Acquire" button to obtain the credentials required for requests:

![](https://cdn.acedata.cloud/nyq0xz.png)

If you are not logged in or registered, you will be automatically redirected to the login page to register and log in. After logging in or registering, you will be automatically returned to the current page.

There is a free quota granted upon the first application, allowing you to use the API for free.

## Basic Usage

Next, you can fill in the corresponding content on the interface, as shown below:

<p><img src="https://cdn.acedata.cloud/8lu8di.png" width="400" className="m-auto" /></p>

When using the interface for the first time, at least three fields need to be filled: one is `authorization`, which can be selected directly from the dropdown list. Another parameter is `model`, which is the OpenAI ChatGPT official model category you choose to use. There are mainly 20 models available; details can be found in the models we provide. The last parameter is `input`, which is an array of query terms you input. It is an array, meaning you can upload multiple query terms simultaneously. Each query term contains `role` and `content`, where `role` indicates the role of the questioner. We provide three roles: `user`, `assistant`, and `system`. The other field, `content`, is the specific content of your query.

You can also notice the corresponding generated call code on the right side. You can copy the code to run directly or click the "Try" button to test.

Common optional parameters:

- `max_tokens`: Limits the maximum number of tokens in a single response.
- `temperature`: Controls randomness in generation, between 0-2; the higher the value, the more divergent the output.
- `n`: Number of candidate responses generated at once.
- `response_format`: Return format setting.
- `tools`: Function/tool call definitions.
- `background`: Whether to run asynchronously in the background.

## Streaming Responses

This interface also supports streaming responses, which is very useful for web integration, allowing the webpage to display text character by character.

If you want to receive streaming responses, you can change the `stream` parameter in the request header to `true`.

The modification is shown below, but the call code needs corresponding changes to support streaming responses.

<p><img src="https://cdn.acedata.cloud/xidnao.png" width="400" className="m-auto" /></p>

After changing `stream` to `true`, the API will return the corresponding JSON data line by line. At the code level, you need to make corresponding modifications to obtain the incremental results.

Python sample call code:

```python
import requests

url = "https://api.acedata.cloud/openai/responses"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Multi-turn Conversations

If you want to integrate multi-turn conversation functionality, you need to upload multiple query terms in the `input` field. An example of multiple query terms is shown below:

Python sample call code:

```python
import requests

url = "https://api.acedata.cloud/openai/responses"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",

response = requests.post(url, json=payload, headers=headers)
```

## Vision Model

gpt-4o is a multimodal large language model developed by OpenAI, which adds visual understanding capabilities on top of GPT-4. This model can handle both text and image inputs, achieving cross-modal understanding and generation.

Text processing with the gpt-4o model is consistent with the basic usage described above. Below is a brief introduction on how to use the model's image processing capabilities.

The image processing capability of the gpt-4o model is mainly achieved by adding a `type` field to the original `content`. This field indicates whether the upload is text or image, thereby enabling the gpt-4o model's image processing ability. Below are two methods using Curl and Python to call this feature.

- Curl script method

```
curl -X POST 'https://api.acedata.cloud/openai/responses' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4.1",
    "input": [
      {
        "role": "user",
        "content": [
          {"type": "input_text", "text": "what is in this image?"},
          {
            "type": "input_image",
            "image_url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
          }
        ]
      }
    ]
  }'
```
