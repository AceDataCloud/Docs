This document introduces the SeeDance Videos Generation API integration guide, which allows generating official SeeDance videos by inputting custom parameters.

## Application Process

To use the API, you need to apply for the corresponding service on the [SeeDance Videos Generation API](https://platform.acedata.cloud/documents/seedance-videos) page. After entering the page, click the "Acquire" button as shown:

![](https://cdn.acedata.cloud/q6ytrc.png)

If you are not logged in or registered, you will be automatically redirected to the login page to register and log in. After logging in or registering, you will be automatically returned to the current page.

There is a free quota granted upon the first application, allowing free use of the API.

## Basic Usage

First, understand the basic usage: by inputting the prompt `content.text`, type `content.type=text`, and model `model`, you can get the processed result. The details are as follows:

<p><img src="https://cdn.acedata.cloud/seedance_parameters.png" width="500" className="m-auto" /></p>

Here we set the Request Headers, including:

- `accept`: the desired response format, here set to `application/json` (JSON format).
- `authorization`: the API key for calling the API, selectable after application.

Also, the Request Body includes:

- `model`: the video generation model, optional values: `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`, `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-lite-t2v-250428`, `doubao-seedance-1-0-lite-i2v-250428`.
- `content`: input content array, `type` can be `text` or `image_url`.
- `resolution`: output resolution, options: `480p` / `720p` / `1080p`.
- `ratio`: aspect ratio, options: `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive`.
- `duration`: video duration (seconds), range 2–12.
- `seed`: random seed, integer, -1 to 4294967295.
- `camerafixed`: whether to fix the camera, `true` / `false`.
- `watermark`: whether to add watermark, `true` / `false`.
- `generate_audio`: whether to generate videos with audio, `true` / `false`, **only supported by `doubao-seedance-1-5-pro-251215`**.
- `service_tier`: inference mode, `default` (online) or `flex` (offline, priced at 50% of online).
- `return_last_frame`: whether to return the last frame image URL in the result.
- `execution_expires_after`: task timeout (seconds), range 3600–259200.
- `callback_url`: asynchronous callback URL; if set, the API immediately returns `task_id`, and posts the result to this URL upon task completion.

After selection, the corresponding code is generated on the right side, as shown:

<p><img src="https://cdn.acedata.cloud/seedance_request.png" width="500" className="m-auto" /></p>

Click the "Try" button to test. As shown above, we get the following result:

The returned result contains multiple fields, described as follows:

- `success`: the status of the video generation task.
- `task_id`: the video generation task ID.
- `trace_id`: the video generation trace ID.
- `data`: the result list of the video generation task.
  - `task_id`: the server-side ID of the video generation task.
  - `video_url`: the video link of the video generation task.
  - `status`: the status of the video generation task.
  - `model`: the model used for video generation.

You can see that we have obtained satisfactory video information. We only need to retrieve the generated SeeDance video from the video link in the `data` field.

If you want to generate corresponding integration code, you can directly copy the generated code. For example, the CURL code is as follows:

```shell
curl -X POST 'https://api.acedata.cloud/seedance/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "content": [{"text":"A kitten yawning at the camera. --rs 720p --rt 16:9 --dur 5 --fps 24 --wm true --seed 11 --cf false","type":"text"}],
  "model": "doubao-seedance-1-0-pro-250528"
}'
```

## Inline Parameter Description

At the end of the `content[].text` prompt, you can append generation parameters in the form `--parameter value` (old method, weak validation, defaults used if input is incorrect). The complete parameter list is as follows:

| Inline Parameter | Corresponding Field | Description     | Value Range                                                  |
| ---------------- | ------------------- | --------------- | ------------------------------------------------------------ |
| `--rs`           | `resolution`        | Output resolution | `480p` / `720p` / `1080p`                                   |
| `--rt`           | `ratio`             | Aspect ratio     | `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` |
| `--dur`          | `duration`          | Video duration (seconds) | 2–12                                                      |
| `--frames`       | `frames`            | Number of frames | Integer satisfying 25+4n within [29, 289]                   |
| `--fps`          | `framespersecond`   | Frame rate       | Only supports `24`                                           |
| `--seed`         | `seed`              | Random seed      | -1 to 4294967295                                            |
| `--cf`           | `camerafixed`       | Fixed camera     | `true` / `false`                                            |
| `--wm`           | `watermark`         | Add watermark    | `true` / `false`                                            |

> **Recommended practice**: Use the corresponding top-level fields directly in the Request Body (e.g., `resolution`, `ratio`, etc.) for strong validation mode. If parameters are incorrect, clear error messages will be returned, making troubleshooting easier.

## Generating Videos with Audio

`doubao-seedance-1-5-pro-251215` supports generating videos with audio via the `generate_audio` parameter:

```json
{
  "model": "doubao-seedance-1-5-pro-251215",
  "content": [
    {
      "type": "text",
      "text": "A girl holds a fox, the wind blows her hair, you can hear the sound of the wind"
    }
  ],
  "generate_audio": true,
  "ratio": "16:9",
  "duration": 5
}
```

Other models do not support this parameter; it will be ignored if passed.

## First Frame of Image-to-Video

For image-to-video tasks, the `content` parameter must include an item with `type` as `image_url`. The `image_url` field must be in object format: `{"url": "https://..."}` or Base64 format `{"url": "data:image/png;base64,..."}`.

> **Note**: `image_url` does not support passing a string directly (e.g., `"image_url": "https://..."`); it must be in object format `"image_url": {"url": "https://..."}`. Otherwise, a 400 error will be returned.

Corresponding code:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": [
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/i2v_foxrgirl.png"
            }
        },
        {
            "type": "text",
            "text": "A girl holds a fox in her arms. She opens her eyes and gazes tenderly at the camera, while the fox affectionately holds her back. As the camera slowly pulls away, her hair is gently blown by the wind. --ratio adaptive  --dur 5"
        }
    ],
    "model": "doubao-seedance-1-0-pro-250528"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Clicking run, you will immediately get a result like:

```
{
    "success": true,
    "task_id": "dc7cceb5-3c12-4de7-a5f4-abcbba3e8e39",
    "trace_id": "b3b09de3-b7fa-4bb0-88b5-aad4b4a96fd4",
    "data": {
        "task_id": "cgt-20251222072003-x2259",
        "status": "succeeded",

    }
}
```

You can see the generated effect is an image-to-video creation, similar to the previous results.

## First and Last Frame of Image-to-Video

To specify the first and last frames in image-to-video, the `content` parameter must include items of type `image_url` with `role` set to `first_frame` and `last_frame`, respectively, specifying:

- role: specifies first or last frame.
- image_url
  - url: image link

Additionally, `content` needs to include a `text` type as the prompt.

Corresponding code:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
   "model": "doubao-seedance-1-0-pro-250528",
    "content": [
         {
            "type": "text",
            "text": "360-degree shot"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_first_frame.jpeg"
            },
            "role": "first_frame"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_last_frame.jpeg"
            },
            "role": "last_frame"
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Clicking run, you will immediately get a result like:

## Asynchronous Callback

Since SeeDance Videos Generation API takes a relatively long time to generate (about 1-2 minutes), you can use asynchronous mode via the `callback_url` field to avoid long HTTP connection occupation.

Overall process: the client specifies `callback_url` when making a request; the API immediately returns a response containing `task_id`; after task completion, the platform sends the generated result as a POST JSON to the `callback_url`. The result also contains `task_id` for correlation.

```json
{
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd"
}
```

When the task is completed, the platform pushes the following content to `callback_url`:

```json
{
  "success": true,
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd",
  "trace_id": "4a4a3721-00fb-43d2-aff2-3b516ac01a8a",
  "data": {
    "task_id": "cgt-20251222073134-54qcw",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

The `task_id` field in the result matches the one returned at request time, enabling task correlation.

## Error Handling

When calling the API, if errors occur, the API returns corresponding error codes and messages. For example:

- `400 token_mismatched`: Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`: Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`: Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`: Too many requests, rate limit exceeded.
- `500 api_error`: Internal server error, something went wrong on the server.

### Error Response Example

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
