---

Producer allows us to upload reference audio for secondary creation. This document explains the integration method for the related API.

This API has only one input parameter, which is `audio_url`. It is a publicly accessible CDN URL that supports the mp3 suffix.

Here, the `audio_url` we input is `https://cdn.acedata.cloud/suno_demo.mp3`, which is a publicly accessible CDN URL.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

The result is as follows:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Soft female vocals, bright and cheerful]\n\n[Verse 1]\nSunlight shines on the seaside\nWaves smile brilliantly\nYou and I on the beach\nThe clock stops ticking\nIce cream is melting\nHand in hand for a walk\nThe breeze gently blows\nHeartbeat never stops\n\n[Chorus]\nSummer, summer\nTime stops on this day\nLaughter echoes\nThe blue sky beside us",
    "audio_url": "https://storage.googleapis.com/corpusant-app-public/producer/raw/d906da31-87cb-42f5-98df-2fc4969923b1.mp3"
  }
}
```

As you can see, the `audio_id` field in `data` is the uploaded song ID.

With the song ID, we can use the [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration) to generate custom songs. For example, by passing `upload_extend` to the `action` parameter and the returned song ID to `audio_id`, new songs can be generated based on the reference audio.
