This document introduces the integration and usage of the Nano Banana Images API. This interface supports two capabilities: **Image Generation (generate)** and **Image Editing (edit)**.

## Application Process

To use the Nano Banana Images API, first go to the [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) to obtain your API Token for later use.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

If you are not logged in or registered, you will automatically be redirected to the login page and prompted to register and log in. Once completed, you will automatically return to the current page.

**A single API Token can be used to access all platform services, so there is no need to apply for each service separately.** Free credits will be granted upon your first application, allowing you to try the service for free. When your credits are insufficient, you can recharge your general balance through the [Console](https://platform.acedata.cloud/console/coin).

> 📘 Complete Documentation: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## API Overview

- **Base URL**: `https://api.acedata.cloud`
- **Endpoint**: `POST /nano-banana/images`
- **Authentication Method**: Include `authorization: Bearer {token}` in the HTTP Header.
- **Request Headers**:
  - `accept: application/json`
  - `content-type: application/json`
- **Action**:
  - `generate`: Generate images based on text prompts.
  - `edit`: Edit images based on provided images.
- **Model** (optional):
  - `nano-banana` (default): Based on Gemini 2.5 Flash Image, offering fast speed and low cost.
  - `nano-banana-2-lite`: Based on Gemini 3.1 Flash Lite Image, supports only 1K resolution and offers fast generation speed.
  - `nano-banana-2`: Based on Gemini 3.1 Flash Image Preview, offering Pro-level quality with Flash speed.
  - `nano-banana-2.1`: A new-generation efficient image model, supporting 1K, 2K, and 4K image generation and editing.
  - `nano-banana-pro`: Based on Gemini 3 Pro Image Preview, offering the highest quality.
  - `nano-banana:official`, `nano-banana-2-lite:official`, `nano-banana-2:official`, `nano-banana-pro:official`: Official channel versions of the corresponding models, offering better image quality and stability, with different billing rates.
- **Asynchronous Callback**: Optional. Receive task completion notifications and results through `callback_url`.
- **Number of Images**: Optional. Specify 1–4 images through `count`, with a default of 1 image. Each image is generated through an independent generation call. Ordinary technical failures or provider safety refusals only affect the corresponding call; other successfully generated images will still be returned, and billing is based on the actual number of successfully generated images.

## Quick Start: Generate Images (`action=generate`)

**Minimum Required Parameters**: `action`, `prompt`

When you only want to generate images directly based on prompts, simply set `action` to `generate` and provide a clear `prompt`.

### Request Example (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Request Example (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Field Descriptions

- `success`: Whether the current request was successful.
- `task_id`: Task ID.
- `trace_id`: Trace ID, which makes troubleshooting easier.
- `count`: Number of images requested for generation or editing. Supports 1–4, with a default of 1. `data` only contains successfully generated images, and billing is based on the actual number of images returned. Each generation call is required to use the provider's native safety policies. A refusal for one call will not affect other successful calls. If all calls are refused, a 403 error will be returned.
- `data[]`: Result list.
  - `prompt`: The prompt used for generation (echoed back).
  - `image_url`: Direct URL of the generated image.

> Note: `/nano-banana/images` only requires `action` and `prompt` to generate images.

## Edit Images (`action=edit`)

When you want to edit existing images, set `action` to `edit` and pass the list of image links to be edited (one or multiple images) through `image_urls`, while also providing a `prompt` describing the editing objective.

For example, here we provide a photo of a person and a photo of a piece of clothing, and want the person to wear that clothing. In this case, we can pass both image links simultaneously and specify the action as `edit`. The URLs can be HTTP URLs, meaning publicly accessible links using the `https` or `http` protocol, or Base64-encoded images, such as `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Request Example (cURL)
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Request Example (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

- `image_urls[]`: List of image URLs to be edited (must be publicly accessible). Multiple images can be provided, and the service will combine these materials with the `prompt` to perform the edit.
- All other fields are the same as those returned by "Generate Image".

## Asynchronous Callback (Optional, Recommended)

Generation or editing may take some time. To avoid occupying resources with long-lived connections, it is recommended to use **Webhook callbacks** through `callback_url`:

1. Add `callback_url` to the request body, for example, your server-side Webhook address (must be publicly accessible and support POST JSON).
2. The API will **return immediately** with a response containing `task_id` (or basic results).
3. When the task is completed, the platform will send the complete JSON to `callback_url` via `POST`. You can associate the request with the result using `task_id`.

**Callback Payload Example** (the field structure is consistent with the synchronous successful response):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Error Handling

When a call fails, a standard error format and trace ID will be returned. Common errors are as follows:

- **400 `token_mismatched`**: Invalid request or incorrect parameters.
- **400 `api_not_implemented`**: The interface has not been implemented (please contact support).
- **401 `invalid_token`**: Authentication failed or Token is missing.
- **403 `forbidden`**: The provider's native safety policy rejected the request or generation result. This call will not return an image or incur a charge; for multi-image requests, other successful calls may still be returned and charged.
- **429 `too_many_requests`**: Request rate limit exceeded.
- **500 `api_error`**: Server-side exception.

### Error Response Example

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Parameter Reference and Notes

- **Required**: `action`, `prompt`
- **For Editing Only**: `image_urls` (array, at least 1 item)
- **Optional**: `model` (defaults to `nano-banana`; options include `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-2.1`, and `nano-banana-pro`; except for `nano-banana-2.1`, corresponding `:official` official-channel versions are also available), `aspect_ratio` (`auto` or a specific aspect ratio, such as `1:1` or `16:9`), `resolution` (resolution, such as `1K`, `2K`, or `4K`; `nano-banana-2-lite` only supports `1K`), `callback_url` (for asynchronous callbacks)
- **Headers**: Must provide `authorization: Bearer {token}`; it is recommended to set `accept` to `application/json`
- **Image Accessibility**: `image_urls` must be direct links that are publicly accessible (HTTP/HTTPS); HTTPS is recommended.
- **Idempotency and Tracking**: Retain `task_id` and `trace_id` for troubleshooting and associating results.

Explicitly passing `"aspect_ratio": "auto"` will select the closest preset based on the ratio, orientation, or layout in the prompt, and is suitable for both generation and editing. For example, if the prompt says "YouTube thumbnail", it can select `16:9`. If the prompt does not specify size requirements or automatic detection is unavailable, text-to-image generation uses the default aspect ratio, while image editing follows the first reference image and uses the closest supported aspect ratio. If this field is omitted, the default aspect ratio or the reference image's aspect ratio will be used. If there is already a clearly specified aspect ratio requirement, pass the specific ratio directly.
