This page tracks **developer-impacting** changes (new endpoints, new models, billing changes, behavior shifts). Internal refactors, bug fixes, and doc edits are not listed.

For full release history, see each repository's GitHub Releases.

## 2025-12

<Update label="2025-12" tags={["docs"]}>
  **Docs information architecture overhaul**

  - Added [Response format](/en/concepts/responses) and [Async task model](/en/concepts/async-tasks)
  - Added [Pricing](/en/pricing/overview) section (chat / image / video / audio)
  - Added [FAQ](/en/faq/billing) section (billing / concurrency / storage)
  - New top-level tabs: Guides / Pricing / API Reference / MCP / FAQ / About
  - Docs site is now maintained independently (decoupled from PlatformBackend sync)
</Update>

## 2025-11

<Update label="2025-11" tags={["model"]}>
  **GPT Image 2**

  - Released `gpt-image-2` with 14 size scenarios
  - Supports both text-to-image and edit (inpaint)
</Update>

<Update label="2025-11" tags={["model"]}>
  **Veo 3.1**

  - Google `veo-3.1` launched with significant quality improvement
  - Cheap-tier `veo-3-fast` also available
</Update>

## 2025-10

<Update label="2025-10" tags={["model"]}>
  **Seedream 5.0 / Seedance 2.0**

  - ByteDance flagship image model `seedream-5.0`
  - Video `seedance-2.0` with 1080p support
</Update>

<Update label="2025-10" tags={["mcp"]}>
  **New MCP servers: Producer / Wan / Hailuo / Kling**

  - 4 new MCP servers, total now 15
  - All support both `stdio` and `streamable-http` transports
</Update>

## 2025-09

<Update label="2025-09" tags={["model"]}>
  **Claude 4.5 / Sonnet 4.5 / Haiku 4.5**

  - Anthropic 4.5 series launched
  - OpenAI Chat Completions-compatible
</Update>

<Update label="2025-09" tags={["billing"]}>
  **Failed tasks now uniformly free**

  - Previously some upstream errors partially billed
  - Platform-wide rule: **only `success` charges**
  - Moderation 403 doesn't charge
</Update>

## 2025-08

<Update label="2025-08" tags={["model"]}>
  **Sora 2 launched**

  - Supports 720p / 1080p
  - Image-to-video and character reference
</Update>

<Update label="2025-08" tags={["api"]}>
  **Webhook signatures**

  - Async webhooks now support `callback_secret`
  - Header `X-Callback-Signature: HMAC-SHA256(secret, body)`
  - See [Async task model](/en/concepts/async-tasks)
</Update>

## 2025-07

<Update label="2025-07" tags={["model"]}>
  **GPT-5 series**

  - OpenAI GPT-5 / GPT-5-mini available
  - Reasoning-effort parameter supported
</Update>

<Update label="2025-07" tags={["platform"]}>
  **X402 crypto payments**

  - Solana USDC / Base USDC on-chain payment
  - Console → Top Up → Crypto
</Update>
