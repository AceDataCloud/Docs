Όλα τα Ace Data Cloud API χρησιμοποιούν πιστοποίηση **Bearer Token**.

## Απόκτηση Token

1. Εγγραφείτε στο [platform.acedata.cloud](https://platform.acedata.cloud)
2. Εγγραφείτε στις απαιτούμενες υπηρεσίες
3. Δημιουργήστε διαπιστευτήρια (API Token) για κάθε υπηρεσία

## Χρήση Token

Συμπεριλάβετε το Token στην κεφαλίδα `Authorization` κάθε αιτήματος:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Tip">
  Κάθε Token συνδέεται με συγκεκριμένη συνδρομή υπηρεσίας. Χρησιμοποιήστε διαφορετικά Token για διαφορετικές υπηρεσίες ή δημιουργήστε **παγκόσμια** διαπιστευτήρια για χρήση σε πολλές υπηρεσίες.
</Note>

## Όρια Ροής Αιτημάτων

Τα όρια ροής διαφέρουν ανάλογα με την υπηρεσία και το επίπεδο συνδρομής. Σε περίπτωση υπέρβασης, το API επιστρέφει `429 Too Many Requests`.

## Καλύτερες Πρακτικές Ασφαλείας

- Μην εκθέτετε το API Token στον κώδικα πελάτη
- Αποθηκεύστε το Token σε μεταβλητές περιβάλλοντος
- Περιοδικά ανανεώνετε τα Token
- Χρησιμοποιήστε διαφορετικά Token για περιβάλλοντα ανάπτυξης και παραγωγής
