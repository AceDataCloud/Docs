Όλα τα Ace Data Cloud API χρησιμοποιούν πιστοποίηση **Bearer Token**.

## Απόκτηση Token

1. Εγγραφείτε στο [platform.acedata.cloud](https://platform.acedata.cloud)
2. Συνδρομή στις απαιτούμενες υπηρεσίες
3. Δημιουργήστε διαπιστευτήρια (API Token) για κάθε υπηρεσία

## Χρήση Token

Συμπεριλάβετε το Token στην κεφαλίδα `Authorization` κάθε αιτήματος:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Σημείωση">
  Κάθε Token συνδέεται με συγκεκριμένη συνδρομή υπηρεσίας. Χρησιμοποιήστε διαφορετικά Tokens για διαφορετικές υπηρεσίες ή δημιουργήστε **παγκόσμια** διαπιστευτήρια για χρήση σε πολλές υπηρεσίες.
</Note>

## Περιορισμοί ρυθμού

Οι περιορισμοί ρυθμού διαφέρουν ανάλογα με την υπηρεσία και το επίπεδο συνδρομής. Όταν ξεπεραστεί το όριο, το API επιστρέφει `429 Too Many Requests`.

## Καλύτερες πρακτικές ασφαλείας

- Μην εκθέτετε το API Token στον κώδικα πελάτη
- Αποθηκεύστε το Token σε μεταβλητές περιβάλλοντος
- Περιστρέφετε τα Tokens τακτικά
- Χρησιμοποιήστε διαφορετικά Tokens για περιβάλλοντα ανάπτυξης και παραγωγής
