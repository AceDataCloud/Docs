---

## Εισαγωγή

Το Short URL είναι μια υπηρεσία εργαλείου που παρέχεται από το Ace Data Cloud για τη δημιουργία συντομευμένων συνδέσμων. Μέσω του ενοποιημένου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του Short URL και να πραγματοποιήσετε λειτουργίες όπως συντόμευση URL και προσαρμοσμένα ονόματα τομέα.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και έχετε λάβει το API Token
- Έχετε εγκαταστήσει περιβάλλον τερματικού με cURL

## Βασική Χρήση

Το κύριο endpoint για κλήση του Short URL API είναι:

```
POST https://api.acedata.cloud/shorturl
```

Πλήρες παράδειγμα εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}'
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα Απάντησης

Μετά από επιτυχή κλήση, επιστρέφονται δεδομένα σε μορφή JSON, για παράδειγμα:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση jq για Επεξεργασία Απάντησης

Συνιστάται η χρήση του εργαλείου jq για μορφοποιημένη έξοδο:

```bash
curl -s -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}' | jq .
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή                          |
|--------------------|----------------------------------|
| 401                | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403                | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429                | Υπερβολικός ρυθμός αιτήσεων       |
| 500                | Εσωτερικό σφάλμα διακομιστή       |

## Επόμενα Βήματα

- Μεταβείτε στην [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud) για να λάβετε το API Token
- Δείτε την [Τεκμηρίωση API](https://docs.acedata.cloud/zh-CN/api-reference) για πλήρη περιγραφή παραμέτρων
- Εξερευνήστε τα [Προγράμματα Τιμολόγησης](https://platform.acedata.cloud/services) για πληροφορίες κόστους
