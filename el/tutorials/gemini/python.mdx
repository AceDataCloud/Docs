## Εισαγωγή

Το Gemini είναι μια υπηρεσία συνομιλίας AI που παρέχεται από το Ace Data Cloud, βασισμένη στη σειρά μεγάλων γλωσσικών μοντέλων Google Gemini. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Gemini με Python, υλοποιώντας λειτουργίες όπως πολυγλωσσική συνομιλία, συστήματα προτροπών, ροή εξόδου και λειτουργία εξόδου JSON.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και έχετε λάβει API Token
- Περιβάλλον Python 3.7 ή νεότερο
- Εγκατάσταση της βιβλιοθήκης requests: `pip install requests`

## Βασική χρήση

Το κύριο endpoint για κλήση του Gemini API είναι:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `gemini-2.5-flash`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Πλήρες παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gemini-2.5-flash",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση απάντησης

Μετά από επιτυχή κλήση, το API επιστρέφει δεδομένα σε μορφή JSON. Συνιστάται να ελέγχετε τον κωδικό κατάστασης HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Επιτυχής κλήση:", result)
else:
    print(f"Αποτυχία κλήσης, κωδικός κατάστασης: {response.status_code}")
    print(response.text)
```

## Προχωρημένη χρήση

Για API συνομιλίας, υποστηρίζεται ροή εξόδου για λήψη απαντήσεων σε πραγματικό χρόνο:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Διαχείριση σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός | Περιγραφή |
|---------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπέρβαση ορίου συχνότητας αιτημάτων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
