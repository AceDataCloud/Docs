## Εισαγωγή

Το Gemini είναι μια υπηρεσία συνομιλίας AI που παρέχεται από το Ace Data Cloud, βασισμένη στη σειρά μεγάλων γλωσσικών μοντέλων Google Gemini. Μέσω του ενοποιημένου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Gemini με JavaScript, υλοποιώντας λειτουργίες όπως πολυγλωσσικές συνομιλίες, συστήματα προτροπής, ροή εξόδου και λειτουργία εξόδου JSON.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και έχετε αποκτήσει API Token
- Node.js 18+ ή σύγχρονο περιβάλλον browser

## Βασική Χρήση

Το κύριο endpoint για κλήση του Gemini API είναι:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

Το παράδειγμα αυτό χρησιμοποιεί το μοντέλο `gemini-2.5-flash`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Πλήρες παράδειγμα κώδικα JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/gemini/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "gemini-2.5-flash",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Συνιστάται να ελέγχετε τον κωδικό κατάστασης της απάντησης και να χειρίζεστε τα σφάλματα:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Κλήση επιτυχής:", result);
} else {
  console.error(`Κλήση αποτυχημένη, κωδικός κατάστασης: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Ενσωμάτωση Node.js

Συνιστάται η συσκευασία σε επαναχρησιμοποιήσιμη συνάρτηση:

```javascript
async function callGemini(data) {
  const response = await fetch("https://api.acedata.cloud/gemini/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπέρβαση ορίου συχνότητας αιτημάτων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
