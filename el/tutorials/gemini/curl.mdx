## Εισαγωγή

Το Gemini είναι μια υπηρεσία AI συνομιλίας που παρέχεται από το Ace Data Cloud, βασισμένη στη σειρά μεγάλων γλωσσικών μοντέλων Google Gemini. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του Gemini, υλοποιώντας λειτουργίες όπως πολυγλωσσική συνομιλία, συστήματα προτροπής, ροή εξόδου και λειτουργία εξόδου JSON.

## Προαπαιτούμενα

- Διαθέσιμος λογαριασμός στο [Ace Data Cloud](https://platform.acedata.cloud) και απόκτηση API Token
- Περιβάλλον τερματικού με εγκατεστημένο cURL

## Βασική Χρήση

Το κύριο endpoint για κλήση του Gemini API είναι:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `gemini-2.5-flash`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Πλήρες παράδειγμα εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/gemini/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gemini-2.5-flash", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα Απόκρισης

Μετά από επιτυχή κλήση, επιστρέφονται δεδομένα σε μορφή JSON, π.χ.:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση jq για Επεξεργασία Απόκρισης

Συνιστάται η χρήση του εργαλείου jq για μορφοποιημένη έξοδο:

```bash
curl -s -X POST https://api.acedata.cloud/gemini/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gemini-2.5-flash", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή                         |
|--------------------|---------------------------------|
| 401                | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403                | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429                | Υπέρβαση ορίου συχνότητας αιτήσεων |
| 500                | Εσωτερικό σφάλμα διακομιστή     |
