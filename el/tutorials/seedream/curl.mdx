## Εισαγωγή

Το Seedream είναι μια υπηρεσία AI εικόνων που παρέχεται από το Ace Data Cloud, με το μοντέλο δημιουργίας εικόνων Seedream της ByteDance. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του Seedream, επιτυγχάνοντας λειτουργίες όπως δημιουργία εικόνας από κείμενο, επεξεργασία εικόνας, πολλαπλές αναλύσεις και έλεγχο υδατογραφήματος.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να αποκτήσετε API Token
- Περιβάλλον τερματικού με εγκατεστημένο cURL

## Βασική Χρήση

Το κύριο endpoint για κλήση του Seedream API είναι:

```
POST https://api.acedata.cloud/seedream/images
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `doubao-seedream-4-0-250828`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`, `doubao-seedream-3-0-t2i-250415`, `doubao-seededit-3-0-i2i-250628`.

Πλήρες παράδειγμα εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}'
```

Παρακαλώ αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα Απάντησης

Μετά από επιτυχή κλήση, επιστρέφονται δεδομένα σε μορφή JSON, για παράδειγμα:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση jq για Επεξεργασία Απάντησης

Συνιστάται η χρήση του εργαλείου jq για μορφοποιημένη έξοδο:

```bash
curl -s -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}' | jq .
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφάλματος:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
