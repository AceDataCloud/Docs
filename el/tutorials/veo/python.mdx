## Εισαγωγή

Το Veo είναι μια υπηρεσία AI βίντεο που παρέχεται από το Ace Data Cloud, με το μοντέλο δημιουργίας βίντεο Google Veo. Μέσω του ενοποιημένου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Veo με Python, επιτυγχάνοντας λειτουργίες όπως δημιουργία βίντεο από κείμενο, δημιουργία βίντεο από εικόνες, ανάλυση 4K, διάφορες αναλογίες κ.ά.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και έχετε αποκτήσει API Token
- Περιβάλλον Python 3.7 ή νεότερο
- Εγκατάσταση της βιβλιοθήκης requests: `pip install requests`

## Βασική Χρήση

Το κύριο endpoint για κλήση του Veo API είναι:

```
POST https://api.acedata.cloud/veo/videos
```

Σε αυτό το παράδειγμα χρησιμοποιούμε το μοντέλο `veo3`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `veo2`, `veo2-fast`, `veo3`, `veo3-fast`, `veo31`, `veo31-fast`.

Πλήρες παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/veo/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "text2video",
    "prompt": "A coffee mug rotating slowly on a marble counter",
    "model": "veo3"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απάντησης

Μετά από επιτυχή κλήση, το API επιστρέφει δεδομένα σε μορφή JSON. Συνιστάται να ελέγχετε τον κωδικό κατάστασης HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Επιτυχής κλήση:", result)
else:
    print(f"Αποτυχία κλήσης, κωδικός κατάστασης: {response.status_code}")
    print(response.text)
```

## Προχωρημένη Χρήση

Για API που υποστηρίζουν ασύγχρονες εργασίες, μπορείτε να λάβετε το αποτέλεσμα μέσω callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Το αποτέλεσμα θα σταλεί στον server σας μέσω του callback URL
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπέρβαση ορίου συχνότητας αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
