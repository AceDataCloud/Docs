## Εισαγωγή

Το reCAPTCHA είναι μια υπηρεσία CAPTCHA που παρέχεται από το Ace Data Cloud, λύση Google reCAPTCHA. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το reCAPTCHA με Python, υλοποιώντας λειτουργίες όπως reCAPTCHA v2 Token, αναγνώριση reCAPTCHA v2, reCAPTCHA v3 Token κ.ά.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να έχετε αποκτήσει API Token
- Περιβάλλον Python 3.7 ή νεότερο
- Εγκατάσταση της βιβλιοθήκης requests: `pip install requests`

## Βασική χρήση

Το κύριο endpoint για κλήση του reCAPTCHA API είναι:

```
POST https://api.acedata.cloud/captcha/token/recaptcha2
```



Πλήρες παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/recaptcha2"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-",
    "website_url": "https://www.google.com/recaptcha/api2/demo"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Παρακαλώ αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση απάντησης

Μετά από επιτυχή κλήση, το API επιστρέφει δεδομένα σε μορφή JSON. Συνιστάται να ελέγχετε τον κωδικό κατάστασης HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Επιτυχής κλήση:", result)
else:
    print(f"Αποτυχία κλήσης, κωδικός κατάστασης: {response.status_code}")
    print(response.text)
```

## Προχωρημένη χρήση

Για API που υποστηρίζουν ασύγχρονες εργασίες, μπορείτε να λάβετε το αποτέλεσμα μέσω callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Το αποτέλεσμα θα προωθηθεί στον server σας μέσω του callback URL
```

## Διαχείριση σφαλμάτων

Συνηθισμένοι κωδικοί σφάλματος:

| Κωδικός κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, παρακαλώ ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |


## Άλλα endpoints

Η υπηρεσία reCAPTCHA παρέχει επίσης τα εξής endpoints:

- `POST https://api.acedata.cloud/captcha/recognition/recaptcha2`
- `POST https://api.acedata.cloud/captcha/token/recaptcha3`
