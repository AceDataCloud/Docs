## Εισαγωγή

Το Flux είναι μια υπηρεσία AI εικόνας που παρέχεται από το Ace Data Cloud, με το μοντέλο δημιουργίας εικόνων Black Forest Labs Flux. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του Flux, επιτυγχάνοντας λειτουργίες όπως δημιουργία εικόνων από κείμενο, επεξεργασία εικόνων, διάφορα μοντέλα και προσαρμοσμένες διαστάσεις.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να έχετε αποκτήσει API Token
- Περιβάλλον τερματικού με εγκατεστημένο cURL

## Βασική Χρήση

Το κύριο endpoint για την κλήση του Flux API είναι:

```
POST https://api.acedata.cloud/flux/images
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `flux-pro-1.1`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `flux-dev`, `flux-pro`, `flux-pro-1.1`, `flux-pro-1.1-ultra`, `flux-kontext-pro`, `flux-kontext-max`.

Πλήρες παράδειγμα εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/flux/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat sitting on a windowsill", "model": "flux-pro-1.1", "size": "1024x1024"}'
```

Παρακαλούμε αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που έχετε αποκτήσει από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα Απόκρισης

Μετά από επιτυχή κλήση, επιστρέφεται δεδομένα σε μορφή JSON, για παράδειγμα:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση του jq για Επεξεργασία Απόκρισης

Συνιστάται η χρήση του εργαλείου jq για μορφοποιημένη έξοδο:

```bash
curl -s -X POST https://api.acedata.cloud/flux/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat sitting on a windowsill", "model": "flux-pro-1.1", "size": "1024x1024"}' | jq .
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφάλματος:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
