## Εισαγωγή

Το Flux είναι μια υπηρεσία AI εικόνας που παρέχεται από το Ace Data Cloud, με το μοντέλο δημιουργίας εικόνων Flux της Black Forest Labs. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Flux με JavaScript, επιτυγχάνοντας λειτουργίες όπως δημιουργία εικόνων από κείμενο, επεξεργασία εικόνων, διάφορα μοντέλα, προσαρμοσμένες διαστάσεις και άλλα.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και έχετε λάβει το API Token
- Node.js 18+ ή σύγχρονο περιβάλλον browser

## Βασική Χρήση

Το κύριο endpoint για κλήση του Flux API είναι:

```
POST https://api.acedata.cloud/flux/images
```

Το παράδειγμα αυτό χρησιμοποιεί το μοντέλο `flux-pro-1.1`. Διαθέσιμα μοντέλα περιλαμβάνουν: `flux-dev`, `flux-pro`, `flux-pro-1.1`, `flux-pro-1.1-ultra`, `flux-kontext-pro`, `flux-kontext-max`.

Πλήρες παράδειγμα κώδικα JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/flux/images", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A white siamese cat sitting on a windowsill",
  "model": "flux-pro-1.1",
  "size": "1024x1024"
}),
});

const result = await response.json();
console.log(result);
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Συνιστάται να ελέγχετε τον κωδικό κατάστασης της απάντησης και να χειρίζεστε τα σφάλματα:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Επιτυχής κλήση:", result);
} else {
  console.error(`Αποτυχία κλήσης, κωδικός κατάστασης: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Συσκευασία για Node.js

Συνιστάται η συσκευασία σε επαναχρησιμοποιήσιμη συνάρτηση:

```javascript
async function callFlux(data) {
  const response = await fetch("https://api.acedata.cloud/flux/images", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
