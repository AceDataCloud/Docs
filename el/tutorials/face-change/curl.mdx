## Εισαγωγή

Το Face Change είναι μια υπηρεσία AI εικόνας που παρέχεται από το Ace Data Cloud, μια υπηρεσία επεξεργασίας προσώπου με τεχνητή νοημοσύνη. Μέσω του ενοποιημένου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του Face Change και να πραγματοποιήσετε λειτουργίες όπως αντικατάσταση προσώπου, βελτίωση προσώπου, αλλαγή ηλικίας, αλλαγή φύλου, μετατροπή σε anime, ανάλυση προσώπου κ.ά.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να έχετε λάβει το API Token
- Περιβάλλον τερματικού με εγκατεστημένο cURL

## Βασική Χρήση

Το κύριο endpoint για κλήση του Face Change API είναι:

```
POST https://api.acedata.cloud/face/swap
```

Πλήρες παράδειγμα εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}'
```

Παρακαλούμε αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα Απόκρισης

Μετά από επιτυχή κλήση, επιστρέφονται δεδομένα σε μορφή JSON, για παράδειγμα:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση του jq για Επεξεργασία Απόκρισης

Συνιστάται η χρήση του εργαλείου jq για μορφοποιημένη έξοδο:

```bash
curl -s -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}' | jq .
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
