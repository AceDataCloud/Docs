## Εισαγωγή

Το Face Change είναι μια υπηρεσία AI επεξεργασίας εικόνων και προσώπων που παρέχεται από το Ace Data Cloud. Μέσω του ενοποιημένου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Face Change με Python για να πραγματοποιήσετε αντικατάσταση προσώπου, βελτίωση προσώπου, αλλαγή ηλικίας, αλλαγή φύλου, μετατροπή σε καρτούν, ανάλυση προσώπου και άλλες λειτουργίες.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να έχετε αποκτήσει API Token
- Περιβάλλον Python 3.7 ή νεότερο
- Εγκατάσταση της βιβλιοθήκης requests: `pip install requests`

## Βασική Χρήση

Το κύριο endpoint για κλήση του Face Change API είναι:

```
POST https://api.acedata.cloud/face/swap
```

Πλήρες παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/face/swap"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "source_image_url": "https://example.com/source-face.jpg",
    "target_image_url": "https://example.com/target-face.jpg"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Παρακαλούμε αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που έχετε αποκτήσει από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Μετά από επιτυχή κλήση, το API επιστρέφει δεδομένα σε μορφή JSON. Συνιστάται να ελέγχετε τον κωδικό κατάστασης HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Επιτυχής κλήση:", result)
else:
    print(f"Αποτυχία κλήσης, κωδικός κατάστασης: {response.status_code}")
    print(response.text)
```

## Προχωρημένη Χρήση

Για API που υποστηρίζουν ασύγχρονες εργασίες, μπορείτε να λάβετε τα αποτελέσματα μέσω callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Τα αποτελέσματα θα αποστέλλονται στο διακομιστή σας μέσω του callback URL
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή απαγόρευση πρόσβασης |
| 429 | Υπέρβαση ορίου συχνότητας αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
