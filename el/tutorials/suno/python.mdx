## Εισαγωγή

Το Suno είναι μια υπηρεσία AI ήχου που παρέχεται από το Ace Data Cloud, για δημιουργία μουσικής με AI. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Suno με Python, υλοποιώντας λειτουργίες όπως δημιουργία μουσικής από κείμενο, προσαρμοσμένους στίχους, συνέχιση τραγουδιών, διασκευές, διαχωρισμό φωνής, δημιουργία στίχων κ.ά.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και έχετε λάβει το API Token
- Περιβάλλον Python 3.7 ή νεότερο
- Εγκατάσταση της βιβλιοθήκης requests: `pip install requests`

## Βασική Χρήση

Το κύριο endpoint για κλήση του Suno API είναι:

```
POST https://api.acedata.cloud/suno/audios
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `chirp-v5`.
Διαθέσιμα μοντέλα είναι: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`.

Πλήρες παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A cheerful pop song about summer vacation",
    "model": "chirp-v5",
    "custom": false
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Μετά από επιτυχή κλήση, το API επιστρέφει δεδομένα σε μορφή JSON. Συνιστάται να ελέγχετε τον HTTP κωδικό κατάστασης:

```python
if response.status_code == 200:
    result = response.json()
    print("Επιτυχής κλήση:", result)
else:
    print(f"Αποτυχία κλήσης, κωδικός κατάστασης: {response.status_code}")
    print(response.text)
```

## Προχωρημένη Χρήση

Για API που υποστηρίζουν ασύγχρονες εργασίες, μπορείτε να λάβετε τα αποτελέσματα μέσω callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Τα αποτελέσματα θα σταλούν στον server σας μέσω του callback URL
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |

## Άλλα Endpoints

Η υπηρεσία Suno παρέχει επίσης τα εξής endpoints:

- `POST https://api.acedata.cloud/suno/lyrics`

- `POST https://api.acedata.cloud/suno/wav`
- `POST https://api.acedata.cloud/suno/mp4`
- `POST https://api.acedata.cloud/suno/tasks`
