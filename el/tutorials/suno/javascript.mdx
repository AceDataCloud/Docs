## Εισαγωγή

Το Suno είναι μια υπηρεσία AI ήχου που παρέχεται από το Ace Data Cloud, για τη δημιουργία μουσικής με τεχνητή νοημοσύνη. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Suno με JavaScript, επιτυγχάνοντας λειτουργίες όπως δημιουργία μουσικής από κείμενο, προσαρμοσμένους στίχους, συνέχεια τραγουδιών, διασκευές, διαχωρισμό φωνής, δημιουργία στίχων κ.ά.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να έχετε λάβει API Token
- Node.js 18+ ή σύγχρονο περιβάλλον browser

## Βασική Χρήση

Το κύριο endpoint του Suno API είναι:

```
POST https://api.acedata.cloud/suno/audios
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `chirp-v5`.
Διαθέσιμα μοντέλα είναι: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`.

Πλήρες παράδειγμα κώδικα JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/suno/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A cheerful pop song about summer vacation",
  "model": "chirp-v5",
  "custom": false
}),
});

const result = await response.json();
console.log(result);
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Συνιστάται να ελέγχετε τον κωδικό κατάστασης της απάντησης και να χειρίζεστε τα σφάλματα:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Επιτυχής κλήση:", result);
} else {
  console.error(`Αποτυχία κλήσης, κωδικός κατάστασης: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Ενσωμάτωση σε Node.js

Συνιστάται η δημιουργία επαναχρησιμοποιήσιμης συνάρτησης:

```javascript
async function callSuno(data) {
  const response = await fetch("https://api.acedata.cloud/suno/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
