## Εισαγωγή

Το Kling είναι μια υπηρεσία AI βίντεο που παρέχεται από το Ace Data Cloud, ένα μοντέλο γρήγορης δημιουργίας βίντεο. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του Kling, υλοποιώντας λειτουργίες όπως δημιουργία βίντεο από κείμενο, δημιουργία βίντεο από εικόνα, συνέχιση βίντεο, διάφορες διάρκειες και αναλογίες διαστάσεων.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και έχετε λάβει API Token
- Έχετε εγκαταστήσει περιβάλλον τερματικού με cURL

## Βασική Χρήση

Το κύριο endpoint για κλήση του Kling API είναι:

```
POST https://api.acedata.cloud/kling/videos
```

Το παράδειγμα αυτό χρησιμοποιεί το μοντέλο `kling-v2-5-turbo`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`.

Παράδειγμα πλήρους εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/kling/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A white cat walking in the snow", "model": "kling-v2-5-turbo", "duration": 5, "aspect_ratio": "16:9"}'
```

Παρακαλώ αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα Απόκρισης

Μετά από επιτυχή κλήση, επιστρέφονται δεδομένα σε μορφή JSON, για παράδειγμα:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση jq για Επεξεργασία Απόκρισης

Συνιστάται η χρήση του εργαλείου jq για μορφοποιημένη έξοδο:

```bash
curl -s -X POST https://api.acedata.cloud/kling/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A white cat walking in the snow", "model": "kling-v2-5-turbo", "duration": 5, "aspect_ratio": "16:9"}' | jq .
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, παρακαλώ ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
