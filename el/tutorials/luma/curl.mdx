## Εισαγωγή

Το Luma είναι μια υπηρεσία AI βίντεο που παρέχεται από το Ace Data Cloud, με δυνατότητα δημιουργίας βίντεο μέσω της Luma Dream Machine. Μέσω του ενοποιημένου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του Luma, επιτυγχάνοντας λειτουργίες όπως δημιουργία βίντεο από κείμενο, δημιουργία βίντεο από εικόνες, επέκταση βίντεο, έλεγχο αρχικών και τελικών καρέ, βρόχο βίντεο και άλλα.

## Προαπαιτούμενα

- Διαθέσιμος λογαριασμός στο [Ace Data Cloud](https://platform.acedata.cloud) και απόκτηση API Token
- Περιβάλλον τερματικού με εγκατεστημένο cURL

## Βασική Χρήση

Το κύριο endpoint για κλήση του Luma API είναι:

```
POST https://api.acedata.cloud/luma/videos
```

Πλήρες παράδειγμα εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}'
```

Παρακαλούμε αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα Απόκρισης

Μετά από επιτυχή κλήση, επιστρέφονται δεδομένα σε μορφή JSON, για παράδειγμα:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση του jq για Επεξεργασία Απόκρισης

Συνιστάται η χρήση του εργαλείου jq για μορφοποιημένη έξοδο:

```bash
curl -s -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}' | jq .
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, παρακαλώ ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |

## Επόμενα Βήματα

- Μεταβείτε στο [Ace Data Cloud Console](https://platform.acedata.cloud) για να αποκτήσετε το API Token
- Δείτε την [Τεκμηρίωση API](https://docs.acedata.cloud/zh-CN/api-reference) για πλήρη περιγραφή παραμέτρων
- Εξερευνήστε τα [Προγράμματα Τιμολόγησης](https://platform.acedata.cloud/services) για πληροφορίες κόστους
