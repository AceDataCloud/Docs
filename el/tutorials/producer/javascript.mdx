## Εισαγωγή

Το Producer είναι μια υπηρεσία AI ήχου που παρέχεται από το Ace Data Cloud, FUZZ Producer AI δημιουργία μουσικής. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Producer με JavaScript για να υλοποιήσετε λειτουργίες όπως δημιουργία μουσικής από κείμενο, προσαρμοσμένους στίχους, συνέχεια τραγουδιού, διασκευές, διαχωρισμό φωνής, δημιουργία MV κ.ά.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να έχετε λάβει API Token
- Node.js 18+ ή σύγχρονο περιβάλλον browser

## Βασική Χρήση

Το κύριο endpoint για κλήση του Producer API είναι:

```
POST https://api.acedata.cloud/producer/audios
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `FUZZ-2.0 Pro`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `FUZZ-2.0 Pro`, `FUZZ-2.0`, `FUZZ-1.1 Pro`, `FUZZ-1.0 Pro`.

Πλήρες παράδειγμα κώδικα JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/producer/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A relaxing jazz piece for a coffee shop",
  "model": "FUZZ-2.0 Pro",
  "lyric": "[Verse]\nSoft piano keys in the morning light",
  "custom": true
}),
});

const result = await response.json();
console.log(result);
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απάντησης

Συνιστάται να ελέγχετε τον κωδικό κατάστασης της απάντησης και να χειρίζεστε τα σφάλματα:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Επιτυχής κλήση:", result);
} else {
  console.error(`Αποτυχία κλήσης, κωδικός κατάστασης: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Ενσωμάτωση σε Node.js

Συνιστάται η συσκευασία σε επαναχρησιμοποιήσιμη συνάρτηση:

```javascript
async function callProducer(data) {
  const response = await fetch("https://api.acedata.cloud/producer/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
