## Εισαγωγή

Το Producer είναι μια υπηρεσία AI ήχου που παρέχεται από το Ace Data Cloud, FUZZ Producer AI για δημιουργία μουσικής. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Producer με Python, για να δημιουργήσετε μουσική από κείμενο, προσαρμοσμένους στίχους, συνέχιση τραγουδιών, διασκευές, διαχωρισμό φωνής, δημιουργία MV και άλλες λειτουργίες.

## Προαπαιτούμενα

- Διαθέσιμος λογαριασμός στο [Ace Data Cloud](https://platform.acedata.cloud) και απόκτηση API Token
- Περιβάλλον Python 3.7 ή νεότερο
- Εγκατάσταση της βιβλιοθήκης requests: `pip install requests`

## Βασική Χρήση

Το κύριο endpoint του Producer API είναι:

```
POST https://api.acedata.cloud/producer/audios
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `FUZZ-2.0 Pro`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `FUZZ-2.0 Pro`, `FUZZ-2.0`, `FUZZ-1.1 Pro`, `FUZZ-1.0 Pro`.

Πλήρες παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/producer/audios"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A relaxing jazz piece for a coffee shop",
    "model": "FUZZ-2.0 Pro",
    "lyric": "[Verse]\nSoft piano keys in the morning light",
    "custom": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Μετά από επιτυχή κλήση, το API επιστρέφει δεδομένα σε μορφή JSON. Συνίσταται να ελέγχετε τον κωδικό κατάστασης HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Επιτυχής κλήση:", result)
else:
    print(f"Αποτυχία κλήσης, κωδικός κατάστασης: {response.status_code}")
    print(response.text)
```

## Προχωρημένη Χρήση

Για API που υποστηρίζουν ασύγχρονες εργασίες, μπορείτε να λάβετε το αποτέλεσμα μέσω callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Το αποτέλεσμα θα προωθηθεί στον server σας μέσω του callback URL
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |

## Άλλα Endpoints

Η υπηρεσία Producer παρέχει επίσης τα εξής endpoints:

- `POST https://api.acedata.cloud/producer/videos`
- `POST https://api.acedata.cloud/producer/wav`
- `POST https://api.acedata.cloud/producer/tasks`
- `POST https://api.acedata.cloud/producer/lyrics`
