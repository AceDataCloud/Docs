## Εισαγωγή

Το Fish TTS είναι μια υπηρεσία AI ήχου που παρέχεται από το Ace Data Cloud, υπηρεσία σύνθεσης φωνής Fish. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του Fish TTS, επιτυγχάνοντας μετατροπή κειμένου σε ομιλία, πολλαπλές φωνές, προσαρμοσμένη φωνή και άλλες λειτουργίες.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και έχετε λάβει το API Token
- Έχετε εγκαταστήσει περιβάλλον τερματικού με cURL

## Βασική Χρήση

Το κύριο endpoint για κλήση του Fish TTS API είναι:

```
POST https://api.acedata.cloud/fish/audios
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `fish-tts`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `fish-tts`.

Πλήρες παράδειγμα εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/fish/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "speech", "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务", "voice_id": "d7900c21663f485ab63ebdb7e5905036", "model": "fish-tts"}'
```

Παρακαλώ αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα Απόκρισης

Μετά από επιτυχή κλήση, επιστρέφονται δεδομένα σε μορφή JSON, για παράδειγμα:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση jq για Επεξεργασία Απόκρισης

Συνιστάται η χρήση του εργαλείου jq για μορφοποιημένη έξοδο:

```bash
curl -s -X POST https://api.acedata.cloud/fish/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "speech", "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务", "voice_id": "d7900c21663f485ab63ebdb7e5905036", "model": "fish-tts"}' | jq .
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
