title: "Γρήγορη Εκκίνηση QR Art με cURL"
---

## Εισαγωγή

Το QR Art είναι μια υπηρεσία AI εικόνων που παρέχεται από το Ace Data Cloud, δημιουργώντας καλλιτεχνικά QR κωδικούς με τη βοήθεια AI. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του QR Art, υλοποιώντας λειτουργίες όπως QR κωδικούς συνδέσμων, κειμένου, προκαθορισμένα στυλ και προσαρμοσμένες παραμέτρους.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να έχετε αποκτήσει API Token
- Περιβάλλον τερματικού με εγκατεστημένο cURL

## Βασική Χρήση

Το κύριο endpoint για κλήση του QR Art API είναι:

```
POST https://api.acedata.cloud/qrart/generate
```

Πλήρες παράδειγμα εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}'
```

Παρακαλούμε αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που έχετε λάβει από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα Απόκρισης

Μετά από επιτυχή κλήση, επιστρέφονται δεδομένα σε μορφή JSON, για παράδειγμα:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση jq για Επεξεργασία Απόκρισης

Συνιστάται η χρήση του εργαλείου jq για μορφοποιημένη έξοδο:

```bash
curl -s -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}' | jq .
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπέρβαση ορίου συχνότητας αιτημάτων |
| 500 | Εσωτερικό σφάλμα διακομιστή |

## Επόμενα Βήματα

- Μεταβείτε στο [Ace Data Cloud Console](https://platform.acedata.cloud) για να αποκτήσετε API Token
- Δείτε την [Τεκμηρίωση API](https://docs.acedata.cloud/zh-CN/api-reference) για πλήρη περιγραφή παραμέτρων
- Εξετάστε τα [Σχέδια Τιμολόγησης](https://platform.acedata.cloud/services) για πληροφορίες κόστους
