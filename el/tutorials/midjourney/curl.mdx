---

## Εισαγωγή

Το Midjourney είναι μια υπηρεσία AI εικόνων που παρέχεται από το Ace Data Cloud, δημιουργώντας εικόνες με Midjourney AI. Μέσω του ενοποιημένου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του Midjourney, υλοποιώντας λειτουργίες όπως δημιουργία εικόνων από κείμενο, επεξεργασία εικόνων, περιγραφή εικόνων, δημιουργία βίντεο από εικόνες, έλεγχο Seed, ασύγχρονη ανάκληση κ.ά.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να λάβετε API Token
- Περιβάλλον τερματικού με εγκατεστημένο cURL

## Βασική Χρήση

Το βασικό endpoint για την κλήση του Midjourney API είναι:

```
POST https://api.acedata.cloud/midjourney/imagine
```

Πλήρες παράδειγμα εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}'
```

Παρακαλώ αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα Απόκρισης

Μετά από επιτυχή κλήση, επιστρέφονται δεδομένα σε μορφή JSON, για παράδειγμα:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση jq για Επεξεργασία Απόκρισης

Συνιστάται η χρήση του εργαλείου jq για μορφοποίηση της εξόδου:

```bash
curl -s -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}' | jq .
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, παρακαλώ ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |

- Δείτε την [Τεκμηρίωση API](https://docs.acedata.cloud/zh-CN/api-reference) για πλήρη περιγραφή παραμέτρων
- Εξερευνήστε τα [Σχέδια Τιμολόγησης](https://platform.acedata.cloud/services) για πληροφορίες κόστους
