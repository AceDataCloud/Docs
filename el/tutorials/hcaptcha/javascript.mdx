## Εισαγωγή

Το hCaptcha είναι μια υπηρεσία CAPTCHA που παρέχεται από το Ace Data Cloud. Η λύση hCaptcha επιτρέπει, μέσω του ενοποιημένου API του Ace Data Cloud, την γρήγορη ενσωμάτωση του hCaptcha με JavaScript, επιτυγχάνοντας την απόκτηση του hCaptcha Token, την αναγνώριση εικόνων hCaptcha και άλλες λειτουργίες.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να έχετε λάβει API Token
- Node.js 18+ ή σύγχρονο περιβάλλον browser

## Βασική Χρήση

Το κύριο endpoint για κλήση του hCaptcha API είναι:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Πλήρες παράδειγμα κώδικα JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/captcha/token/hcaptcha", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2",
  "website_url": "https://accounts.hcaptcha.com/demo"
}),
});

const result = await response.json();
console.log(result);
```

Παρακαλώ αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Συνιστάται να ελέγχετε τον κωδικό κατάστασης της απάντησης και να χειρίζεστε τα σφάλματα:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Επιτυχής κλήση:", result);
} else {
  console.error(`Αποτυχία κλήσης, κωδικός κατάστασης: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Ενσωμάτωση σε Node.js

Συνιστάται η δημιουργία επαναχρησιμοποιήσιμης συνάρτησης:

```javascript
async function callhCaptcha(data) {
  const response = await fetch("https://api.acedata.cloud/captcha/token/hcaptcha", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, παρακαλώ ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπέρβαση ορίου συχνότητας αιτημάτων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
