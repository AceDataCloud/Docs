## Εισαγωγή

Το hCaptcha είναι μια υπηρεσία CAPTCHA που παρέχεται από το Ace Data Cloud, προσφέροντας λύσεις hCaptcha. Μέσω του ενοποιημένου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το hCaptcha με Python, υλοποιώντας λειτουργίες όπως λήψη hCaptcha Token και αναγνώριση εικόνων hCaptcha.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να έχετε αποκτήσει API Token
- Περιβάλλον Python 3.7 ή νεότερο
- Εγκατάσταση της βιβλιοθήκης requests: `pip install requests`

## Βασική Χρήση

Το κύριο endpoint για κλήση του hCaptcha API είναι:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Πλήρες παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/hcaptcha"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2",
    "website_url": "https://accounts.hcaptcha.com/demo"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Παρακαλώ αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Μετά από επιτυχή κλήση, το API επιστρέφει δεδομένα σε μορφή JSON. Συνιστάται να ελέγχετε τον HTTP κωδικό κατάστασης:

```python
if response.status_code == 200:
    result = response.json()
    print("Επιτυχής κλήση:", result)
else:
    print(f"Αποτυχία κλήσης, κωδικός κατάστασης: {response.status_code}")
    print(response.text)
```

## Προχωρημένη Χρήση

Για API που υποστηρίζουν ασύγχρονες εργασίες, μπορείτε να λάβετε τα αποτελέσματα μέσω callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Το αποτέλεσμα θα αποσταλεί στο διακομιστή σας μέσω του callback URL
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
