## Εισαγωγή

Το Seedance είναι μια υπηρεσία AI βίντεο που παρέχεται από το Ace Data Cloud, με το μοντέλο δημιουργίας βίντεο Seedance της ByteDance. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Seedance με Python, επιτυγχάνοντας λειτουργίες όπως δημιουργία βίντεο από κείμενο, δημιουργία βίντεο από εικόνα, παραγωγή ήχου και υποστήριξη πολλαπλών αναλύσεων.

## Προαπαιτούμενα

- Διαθέσιμος λογαριασμός στο [Ace Data Cloud](https://platform.acedata.cloud) και απόκτηση API Token
- Περιβάλλον Python 3.7 ή νεότερο
- Εγκατάσταση της βιβλιοθήκης requests: `pip install requests`

## Βασική Χρήση

Το κύριο endpoint για κλήση του Seedance API είναι:

```
POST https://api.acedata.cloud/seedance/videos
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `doubao-seedance-1-0-pro-250528`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`.

Πλήρες παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "doubao-seedance-1-0-pro-250528",
    "content": [
        {
            "type": "text",
            "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"
        }
    ]
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Παρακαλώ αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Μετά από επιτυχή κλήση, το API επιστρέφει δεδομένα σε μορφή JSON. Συνιστάται να ελέγχετε τον HTTP κωδικό κατάστασης:

```python
if response.status_code == 200:
    result = response.json()
    print("Επιτυχής κλήση:", result)
else:
    print(f"Αποτυχία κλήσης, κωδικός κατάστασης: {response.status_code}")
    print(response.text)
```

## Προχωρημένη Χρήση

Για API που υποστηρίζουν ασύγχρονες εργασίες, μπορείτε να λάβετε το αποτέλεσμα μέσω callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Το αποτέλεσμα θα σταλεί στο διακομιστή σας μέσω του callback URL
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, παρακαλώ ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
