---

## Εισαγωγή

Το Kimi είναι μια υπηρεσία συνομιλίας AI που παρέχεται από το Ace Data Cloud, βασισμένη στη μεγάλη γλωσσική μονάδα σειράς Kimi της Moon's Dark Side. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του Kimi, υλοποιώντας λειτουργίες όπως πολυγλωσσική συνομιλία, συστήματα προτροπής, ροή εξόδου και λειτουργία εξόδου JSON.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να έχετε αποκτήσει API Token
- Ένα περιβάλλον τερματικού με εγκατεστημένο cURL

## Βασική Χρήση

Το κύριο endpoint για κλήση του Kimi API είναι:

```
POST https://api.acedata.cloud/kimi/chat/completions
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `kimi-k2.5`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `kimi-k2.5`, `kimi-k2-thinking-turbo`, `kimi-k2-thinking`, `kimi-k2-instruct-0905`.

Πλήρες παράδειγμα εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "kimi-k2.5", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα Απόκρισης

Μετά από επιτυχή κλήση, επιστρέφονται δεδομένα σε μορφή JSON, για παράδειγμα:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση του jq για Επεξεργασία Απόκρισης

Συνιστάται η χρήση του εργαλείου jq για μορφοποίηση της εξόδου:

```bash
curl -s -X POST https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "kimi-k2.5", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
