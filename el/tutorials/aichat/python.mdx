## Εισαγωγή

Το AI Chat είναι μια υπηρεσία συνομιλίας AI που παρέχεται από το Ace Data Cloud, μια υπηρεσία συνομιλίας πολλαπλών μοντέλων AI. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το AI Chat με Python, υποστηρίζοντας πολλαπλά μοντέλα, διαλόγους με κατάσταση, προκαθορισμένους ρόλους και άλλες λειτουργίες.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και λάβετε το API Token
- Περιβάλλον Python 3.7 ή νεότερο
- Εγκατάσταση της βιβλιοθήκης requests: `pip install requests`

## Βασική Χρήση

Το κύριο endpoint για κλήση του AI Chat API είναι:

```
POST https://api.acedata.cloud/aichat/conversations
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `gpt-4o`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Πλήρες παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/aichat/conversations"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gpt-4o",
    "question": "什么是人工智能？",
    "stateful": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Παρακαλώ αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Μετά από επιτυχή κλήση, το API επιστρέφει δεδομένα σε μορφή JSON. Συνιστάται να ελέγχετε τον κωδικό κατάστασης HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Επιτυχής κλήση:", result)
else:
    print(f"Αποτυχία κλήσης, κωδικός κατάστασης: {response.status_code}")
    print(response.text)
```

## Προχωρημένη Χρήση

Για API που υποστηρίζουν ασύγχρονες εργασίες, μπορείτε να λάβετε τα αποτελέσματα μέσω callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Τα αποτελέσματα θα προωθηθούν στον server σας μέσω του callback URL
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
