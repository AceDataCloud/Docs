## Εισαγωγή

Το AI Chat είναι μια υπηρεσία AI συνομιλίας που παρέχεται από το Ace Data Cloud, υποστηρίζοντας πολλαπλά μοντέλα AI για διάλογο. Μέσω του ενοποιημένου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του AI Chat, υλοποιώντας λειτουργίες όπως υποστήριξη πολλαπλών μοντέλων, διαλόγους με κατάσταση και προκαθορισμένους ρόλους.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και έχετε λάβει το API Token
- Έχετε εγκαταστήσει περιβάλλον τερματικού με cURL

## Βασική Χρήση

Το κύριο endpoint για κλήση του AI Chat API είναι:

```
POST https://api.acedata.cloud/aichat/conversations
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `gpt-4o`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Πλήρες παράδειγμα εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}'
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα Απόκρισης

Μετά από επιτυχή κλήση, επιστρέφονται δεδομένα σε μορφή JSON, για παράδειγμα:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση του jq για Επεξεργασία Απόκρισης

Συνιστάται η χρήση του εργαλείου jq για μορφοποιημένη έξοδο:

```bash
curl -s -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}' | jq .
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |

## Επόμενα Βήματα

- Μεταβείτε στην [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud) για να λάβετε το API Token
- Δείτε την [Τεκμηρίωση API](https://docs.acedata.cloud/zh-CN/api-reference) για πλήρη περιγραφή παραμέτρων
- Εξερευνήστε τα [Προγράμματα Τιμολόγησης](https://platform.acedata.cloud/services) για πληροφορίες κόστους
