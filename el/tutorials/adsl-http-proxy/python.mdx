## Εισαγωγή

Το ADSL HTTP Proxy είναι μια υπηρεσία δικτυακού μεσολαβητή που παρέχεται από το Ace Data Cloud, για εξαγωγή δυναμικών IP μέσω ADSL. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το ADSL HTTP Proxy με Python, υλοποιώντας λειτουργίες όπως HTTP/SOCKS proxy, πολλούς παρόχους, πολλαπλές επαρχίες, προσαρμοσμένη διάρκεια, λίστα επιτρεπόμενων IP κ.ά.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και έχετε λάβει API Token
- Περιβάλλον Python 3.7 ή νεότερο
- Εγκατάσταση της βιβλιοθήκης requests: `pip install requests`

## Βασική Χρήση

Το κύριο endpoint του ADSL HTTP Proxy API είναι:

```
POST https://api.acedata.cloud/adsl/extract
```

Πλήρες παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "number": 5,
    "type": "http",
    "duration": 300,
    "province": "广东",
    "isp": "电信"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Μετά από επιτυχή κλήση, το API επιστρέφει δεδομένα σε μορφή JSON. Συνιστάται να ελέγχετε τον κωδικό κατάστασης HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Επιτυχής κλήση:", result)
else:
    print(f"Αποτυχία κλήσης, κωδικός κατάστασης: {response.status_code}")
    print(response.text)
```

## Προχωρημένη Χρήση

Για API που υποστηρίζουν ασύγχρονες εργασίες, μπορείτε να λάβετε τα αποτελέσματα μέσω callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Τα αποτελέσματα θα προωθηθούν στον server σας μέσω του callback URL
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή απαγορευμένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
