## Εισαγωγή

Το ADSL HTTP Proxy είναι μια υπηρεσία δικτυακού διαμεσολαβητή που παρέχεται από το Ace Data Cloud, για εξαγωγή δυναμικών IP ADSL. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του ADSL HTTP Proxy, υλοποιώντας λειτουργίες όπως HTTP/SOCKS proxy, πολλούς παρόχους, πολλαπλές επαρχίες, προσαρμοσμένη διάρκεια και λίστα επιτρεπόμενων IP.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και έχετε λάβει το API Token
- Έχετε εγκαταστήσει περιβάλλον τερματικού με cURL

## Βασική Χρήση

Το κύριο endpoint για κλήση του ADSL HTTP Proxy API είναι:

```
POST https://api.acedata.cloud/adsl/extract
```

Πλήρες παράδειγμα εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}'
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα Απόκρισης

Μετά από επιτυχή κλήση, επιστρέφονται δεδομένα σε μορφή JSON, για παράδειγμα:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση jq για Επεξεργασία Απόκρισης

Συνιστάται η χρήση του εργαλείου jq για μορφοποιημένη έξοδο:

```bash
curl -s -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}' | jq .
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή                         |
|--------------------|----------------------------------|
| 401                | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403                | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429                | Υπερβολικός ρυθμός αιτήσεων       |
| 500                | Εσωτερικό σφάλμα διακομιστή       |
