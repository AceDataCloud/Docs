## Εισαγωγή

Το Nano Banana είναι μια υπηρεσία AI εικόνας που παρέχεται από το Ace Data Cloud, βασισμένη στην υπηρεσία δημιουργίας εικόνων Gemini. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Nano Banana με JavaScript, επιτυγχάνοντας λειτουργίες όπως δημιουργία εικόνων από κείμενο, επεξεργασία εικόνων, πολλαπλές αναλογίες και υψηλή ανάλυση.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και έχετε λάβει το API Token
- Node.js 18+ ή σύγχρονο περιβάλλον browser

## Βασική Χρήση

Το κύριο endpoint για κλήση του Nano Banana API είναι:

```
POST https://api.acedata.cloud/nano-banana/images
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `nano-banana-2`.  
Διαθέσιμα μοντέλα περιλαμβάνουν: `nano-banana`, `nano-banana-2`, `nano-banana-pro`.

Πλήρες παράδειγμα κώδικα JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/nano-banana/images", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A white siamese cat",
  "model": "nano-banana-2",
  "aspect_ratio": "1:1"
}),
});

const result = await response.json();
console.log(result);
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Συνιστάται να ελέγχετε τον κωδικό κατάστασης της απάντησης και να χειρίζεστε τα σφάλματα:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Κλήση επιτυχής:", result);
} else {
  console.error(`Κλήση αποτυχημένη, κωδικός κατάστασης: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Ενσωμάτωση σε Node.js

Συνιστάται η δημιουργία επαναχρησιμοποιήσιμης συνάρτησης:

```javascript
async function callNanoBanana(data) {
  const response = await fetch("https://api.acedata.cloud/nano-banana/images", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
