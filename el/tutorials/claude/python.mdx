## Εισαγωγή

Το Claude είναι μια υπηρεσία συνομιλίας AI που παρέχεται από το Ace Data Cloud, βασισμένη στη σειρά μεγάλων γλωσσικών μοντέλων Anthropic Claude. Μέσω του ενοποιημένου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Claude με Python, επιτυγχάνοντας λειτουργίες όπως πολυγλωσσικές συνομιλίες, συστήματα προτροπής, ροή εξόδου και λειτουργία εξόδου σε JSON.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και έχετε λάβει το API Token
- Περιβάλλον Python 3.7 ή νεότερο
- Εγκατάσταση της βιβλιοθήκης requests: `pip install requests`

## Βασική Χρήση

Το κύριο endpoint για κλήση του Claude API είναι:

```
POST https://api.acedata.cloud/v1/chat/completions
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `claude-sonnet-4-6`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `claude-sonnet-4-6`, `claude-opus-4-5-20251101`, `claude-3-5-sonnet`.

Πλήρες παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "claude-sonnet-4-6",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Μετά από επιτυχή κλήση, το API επιστρέφει δεδομένα σε μορφή JSON. Συνιστάται να ελέγχετε τον κωδικό κατάστασης HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Επιτυχής κλήση:", result)
else:
    print(f"Αποτυχία κλήσης, κωδικός κατάστασης: {response.status_code}")
    print(response.text)
```

## Προχωρημένη Χρήση

Για API συνομιλίας, υποστηρίζεται ροή εξόδου για λήψη απαντήσεων σε πραγματικό χρόνο:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |

## Άλλα Endpoints

Η υπηρεσία Claude παρέχει επίσης τα εξής endpoints:

- `POST https://api.acedata.cloud/v1/messages`
- `POST https://api.acedata.cloud/v1/messages/count_tokens`
