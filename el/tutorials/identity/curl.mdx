title: "Γρήγορη εκκίνηση με το Identity cURL"
---

## Εισαγωγή

Το Identity είναι μια υπηρεσία ταυτοποίησης που παρέχεται από το Ace Data Cloud, για επαλήθευση ταυτότητας/τραπεζικής κάρτας/αριθμού κινητού τηλεφώνου με πραγματικά στοιχεία. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του Identity και να πραγματοποιήσετε λειτουργίες όπως OCR ταυτότητας, επαλήθευση ταυτότητας, επαλήθευση τραπεζικής κάρτας και επαλήθευση αριθμού κινητού τηλεφώνου.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να έχετε λάβει API Token
- Να έχετε εγκαταστήσει περιβάλλον τερματικού με cURL

## Βασική χρήση

Το κύριο endpoint για κλήση του Identity API είναι:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Πλήρες παράδειγμα εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}'
```

Παρακαλούμε αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα απόκρισης

Μετά από επιτυχή κλήση, επιστρέφονται δεδομένα σε μορφή JSON, για παράδειγμα:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση του jq για επεξεργασία απόκρισης

Συνιστάται η χρήση του εργαλείου jq για μορφοποιημένη έξοδο:

```bash
curl -s -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}' | jq .
```

## Διαχείριση σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
