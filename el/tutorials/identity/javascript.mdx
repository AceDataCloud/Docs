## Εισαγωγή

Το Identity είναι μια υπηρεσία επαλήθευσης ταυτότητας που παρέχεται από το Ace Data Cloud, για επαλήθευση πραγματικής ταυτότητας με βάση ταυτότητα/τραπεζική κάρτα/αριθμό κινητού τηλεφώνου. Μέσω του ενιαίου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Identity με JavaScript, υλοποιώντας λειτουργίες όπως OCR ταυτότητας, επαλήθευση ταυτότητας, επαλήθευση τραπεζικής κάρτας και επαλήθευση αριθμού κινητού τηλεφώνου.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να έχετε αποκτήσει API Token
- Node.js 18+ ή σύγχρονο περιβάλλον browser

## Βασική Χρήση

Το κύριο endpoint του Identity API είναι:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Πλήρες παράδειγμα κώδικα JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/identity/idcard/ocr", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "image_url": "https://example.com/idcard-front.jpg"
}),
});

const result = await response.json();
console.log(result);
```

Παρακαλώ αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Συνιστάται να ελέγχετε τον κωδικό κατάστασης της απάντησης και να χειρίζεστε τα σφάλματα:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Επιτυχής κλήση:", result);
} else {
  console.error(`Αποτυχία κλήσης, κωδικός κατάστασης: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Ενσωμάτωση σε Node.js

Συνιστάται η συσκευασία σε επαναχρησιμοποιήσιμη συνάρτηση:

```javascript
async function callIdentity(data) {
  const response = await fetch("https://api.acedata.cloud/identity/idcard/ocr", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, παρακαλώ ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή απαγόρευση πρόσβασης |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |

## Επόμενα Βήματα

- Μεταβείτε στο [Ace Data Cloud Console](https://platform.acedata.cloud) για να αποκτήσετε API Token
- Δείτε την [Τεκμηρίωση API](https://docs.acedata.cloud/zh-CN/api-reference) για πλήρη περιγραφή παραμέτρων
- Εξερευνήστε τα [Προγράμματα Τιμολόγησης](https://platform.acedata.cloud/services) για πληροφορίες κόστους
