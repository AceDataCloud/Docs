## Εισαγωγή

Το Identity είναι μια υπηρεσία ταυτοποίησης που παρέχεται από το Ace Data Cloud, για επαλήθευση ταυτότητας μέσω ταυτότητας/τραπεζικής κάρτας/αριθμού κινητού τηλεφώνου. Μέσω του ενοποιημένου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Identity με Python, υλοποιώντας λειτουργίες όπως OCR ταυτότητας, επαλήθευση ταυτότητας, επαλήθευση τραπεζικής κάρτας και επαλήθευση αριθμού κινητού τηλεφώνου.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να έχετε αποκτήσει API Token
- Περιβάλλον Python 3.7 ή νεότερο
- Εγκατάσταση της βιβλιοθήκης requests: `pip install requests`

## Βασική Χρήση

Το κύριο endpoint για κλήση του Identity API είναι:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Πλήρες παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/identity/idcard/ocr"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "image_url": "https://example.com/idcard-front.jpg"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Παρακαλώ αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που έχετε λάβει από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Μετά από επιτυχή κλήση, το API επιστρέφει δεδομένα σε μορφή JSON. Συνιστάται να ελέγχετε τον HTTP κωδικό κατάστασης:

```python
if response.status_code == 200:
    result = response.json()
    print("Επιτυχής κλήση:", result)
else:
    print(f"Αποτυχία κλήσης, κωδικός κατάστασης: {response.status_code}")
    print(response.text)
```

## Προχωρημένη Χρήση

Για API που υποστηρίζουν ασύγχρονες εργασίες, μπορείτε να λάβετε το αποτέλεσμα μέσω callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Το αποτέλεσμα θα σταλεί στο server σας μέσω του callback URL
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, παρακαλώ ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπέρβαση ορίου συχνότητας αιτημάτων |
| 500 | Εσωτερικό σφάλμα διακομιστή |

## Άλλα Endpoints

Η υπηρεσία Identity παρέχει επίσης τα ακόλουθα endpoints:

- `POST https://api.acedata.cloud/identity/idcard/check-1e`
- `POST https://api.acedata.cloud/identity/bankcard/check-1e`
- `POST https://api.acedata.cloud/identity/phone/check-1e`
