## Εισαγωγή

Το Hailuo είναι μια υπηρεσία AI βίντεο που παρέχεται από το Ace Data Cloud, με το μοντέλο δημιουργίας βίντεο MiniMax Hailuo. Μέσω του ενοποιημένου API του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε το cURL για γρήγορη κλήση του Hailuo και να υλοποιήσετε λειτουργίες όπως δημιουργία βίντεο από κείμενο, δημιουργία βίντεο από εικόνα, λειτουργία σκηνοθέτη κ.ά.

## Προαπαιτούμενα

- Να έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και να έχετε αποκτήσει API Token
- Περιβάλλον τερματικού με εγκατεστημένο cURL

## Βασική Χρήση

Το κύριο endpoint για κλήση του Hailuo API είναι:

```
POST https://api.acedata.cloud/hailuo/videos
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `minimax-t2v`.
Διαθέσιμα μοντέλα περιλαμβάνουν: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Πλήρες παράδειγμα εντολής cURL:

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}'
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που έχετε λάβει από την πλατφόρμα Ace Data Cloud.

## Παράδειγμα Απόκρισης

Μετά από επιτυχή κλήση, επιστρέφονται δεδομένα σε μορφή JSON, για παράδειγμα:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Χρήση jq για Επεξεργασία Απόκρισης

Συνιστάται η χρήση του εργαλείου jq για μορφοποιημένη έξοδο:

```bash
curl -s -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}' | jq .
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Ανεπαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπέρβαση ορίου συχνότητας αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |

## Επόμενα Βήματα

- Μεταβείτε στην [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud) για να αποκτήσετε API Token
- Δείτε την [Τεκμηρίωση API](https://docs.acedata.cloud/zh-CN/api-reference) για πλήρη περιγραφή παραμέτρων
- Εξερευνήστε τα [Προγράμματα Τιμολόγησης](https://platform.acedata.cloud/services) για πληροφορίες κόστους
