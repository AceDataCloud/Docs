## Εισαγωγή

Το Hailuo είναι μια υπηρεσία AI βίντεο που παρέχεται από το Ace Data Cloud, με το μοντέλο δημιουργίας βίντεο MiniMax Hailuo. Μέσω του ενοποιημένου API του Ace Data Cloud, μπορείτε να ενσωματώσετε γρήγορα το Hailuo με Python, υλοποιώντας λειτουργίες όπως δημιουργία βίντεο από κείμενο, δημιουργία βίντεο από εικόνα, λειτουργία σκηνοθέτη και άλλα.

## Προαπαιτούμενα

- Έχετε λογαριασμό στο [Ace Data Cloud](https://platform.acedata.cloud) και έχετε λάβει API Token
- Περιβάλλον Python 3.7 ή νεότερο
- Εγκατάσταση της βιβλιοθήκης requests: `pip install requests`

## Βασική Χρήση

Το κύριο endpoint για κλήση του Hailuo API είναι:

```
POST https://api.acedata.cloud/hailuo/videos
```

Το παράδειγμα χρησιμοποιεί το μοντέλο `minimax-t2v`.
Διαθέσιμα μοντέλα είναι: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Πλήρες παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/hailuo/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "model": "minimax-t2v",
    "prompt": "A golden sunset over the ocean waves"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Αντικαταστήστε το `YOUR_API_TOKEN` με το πραγματικό Token που λάβατε από την πλατφόρμα Ace Data Cloud.

## Διαχείριση Απαντήσεων

Μετά από επιτυχή κλήση, το API επιστρέφει δεδομένα σε μορφή JSON. Συνιστάται να ελέγχετε τον κωδικό κατάστασης HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Επιτυχής κλήση:", result)
else:
    print(f"Αποτυχία κλήσης, κωδικός κατάστασης: {response.status_code}")
    print(response.text)
```

## Προχωρημένη Χρήση

Για API που υποστηρίζουν ασύγχρονες εργασίες, μπορείτε να λάβετε τα αποτελέσματα μέσω callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Τα αποτελέσματα θα αποσταλούν στον server σας μέσω του callback URL
```

## Διαχείριση Σφαλμάτων

Συνηθισμένοι κωδικοί σφαλμάτων:

| Κωδικός Κατάστασης | Περιγραφή |
|--------------------|-----------|
| 401 | Αποτυχία πιστοποίησης, ελέγξτε το API Token |
| 403 | Μη επαρκές υπόλοιπο ή μη εξουσιοδοτημένη πρόσβαση |
| 429 | Υπερβολικός ρυθμός αιτήσεων |
| 500 | Εσωτερικό σφάλμα διακομιστή |
