## Βασικό URL

Η βασική διεύθυνση για όλα τα σημεία τερματισμού API:

```
https://api.acedata.cloud
```

## Πιστοποίηση

Όλα τα σημεία τερματισμού απαιτούν πιστοποίηση Bearer Token:

```
Authorization: Bearer YOUR_API_TOKEN
```

## Δοκιμή Online

Κάθε σημείο τερματισμού σε αυτή την αναφορά περιλαμβάνει έναν διαδραστικό sandbox. Εισάγετε το API Token για να δοκιμάσετε τα αιτήματα απευθείας στον περιηγητή.

<Note title="Tip">
  Λάβετε το API Token στο [platform.acedata.cloud](https://platform.acedata.cloud).
</Note>
