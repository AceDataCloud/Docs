## Βασικό URL

Η βασική διεύθυνση για όλα τα σημεία τερματισμού API:

```
https://api.acedata.cloud
```

## Πιστοποίηση

Όλα τα σημεία τερματισμού απαιτούν πιστοποίηση Bearer Token:

```
Authorization: Bearer YOUR_API_TOKEN
```

## Δοκιμή σε απευθείας σύνδεση

Κάθε σημείο τερματισμού σε αυτήν την αναφορά περιλαμβάνει έναν διαδραστικό χώρο δοκιμών. Εισάγετε το API Token για να δοκιμάσετε απευθείας τα αιτήματα στον περιηγητή.

<Note title="Tip">
  Λάβετε το API Token στο [platform.acedata.cloud](https://platform.acedata.cloud).
</Note>
