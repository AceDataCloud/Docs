## API生成 βίντεο ψηφιακού ανθρώπου

`POST https://api.acedata.cloud/dreamina/videos`

Δημιουργία βίντεο ψηφιακού ανθρώπου με οδήγηση ήχου (OmniHuman 1.5). Παρέχετε μια φωτογραφία του προσώπου και έναν ήχο οδήγησης για να δημιουργήσετε ένα βίντεο όπου το πρόσωπο μιλάει και συγχρονίζεται με τα χείλη.

### Κεφαλίδες Αιτήματος

| Κεφαλίδα         | Τιμή                     |
| ---------------- | ----------------------- |
| `Authorization`  | `Bearer &lt;το API Key σας>` |
| `Content-Type`   | `application/json`      |

### Παράμετροι Αιτήματος

| Παράμετρος      | Τύπος     | Υποχρεωτική | Περιγραφή                                                                |
| ---------------- | -------- | ----------- | ----------------------------------------------------------------------- |
| `model`          | string   | Όχι         | Μοντέλο, προεπιλογή `omnihuman-1.5`                                     |
| `image_url`      | string   | Ναι         | Δημόσιο URL φωτογραφίας του προσώπου, προτείνεται καθαρή και ευθεία λήψη |
| `audio_url`      | string   | Ναι         | Δημόσιο URL ήχου οδήγησης (mp3/wav), προτείνεται &lt; 60 δευτερόλεπτα     |
| `prompt`         | string   | Όχι         | Έλεγχος έκφρασης, συναισθημάτων, σταθερότητας και στυλ                  |
| `mask_url`       | string[] | Όχι         | URL μάσκας του κύριου, για να προσδιορίσετε το αντικείμενο οδήγησης σε εικόνες με πολλούς ανθρώπους |
| `callback_url`   | string   | Όχι         | Αν παρασχεθεί, επιστρέφει άμεσα το `task_id`, και μετά καλεί αυτή τη διεύθυνση όταν ολοκληρωθεί η δημιουργία αποτελέσματος |
| `async`          | boolean  | Όχι         | Όταν οριστεί σε `true`, επιστρέφει άμεσα το `task_id`, χωρίς να απαιτεί `callback_url`, μέσω του `/dreamina/tasks` για να ελέγξει το αποτέλεσμα |

### Συστάσεις Εισόδου

- **Εικόνα**: Καθαρή, καλά φωτισμένη πρόσοψη προσώπου είναι η καλύτερη; το πρόσωπο χωρίς εμπόδια, με μέτρια αναλογία στην εικόνα.
- **Ήχος**: mp3/wav, πρέπει να είναι δημόσια προσβάσιμος. Συνιστάται η διάρκεια να είναι κάτω από 60 δευτερόλεπτα (1080p προτείνεται ≤30 δευτερόλεπτα, 720p ≤60 δευτερόλεπτα).
- Το `image_url` και το `audio_url` πρέπει να είναι προσβάσιμα δημόσια.

### Παράδειγμα Απόκρισης

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",
  "data": {
    "task_id": "362b4fed67bd11f1ad1100163e57d510",
    "status": "done",
    "video_url": "https://cdn.acedata.cloud/634d760216.mp4",
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }

```

### Ασύγχρονη και Ερώτηση

Η διεπαφή επιστρέφει από προεπιλογή το τελικό βίντεο συγχρόνως. Για μεγαλύτερες εργασίες, μπορείτε να χρησιμοποιήσετε μία από τις δύο ασύγχρονες μεθόδους:

- Παρέχοντας `callback_url`: Η διεπαφή επιστρέφει άμεσα το `task_id`, και μετά καλεί αυτή τη διεύθυνση όταν ολοκληρωθεί η δημιουργία αποτελέσματος.
- Παρέχοντας `async: true`: Η διεπαφή επιστρέφει άμεσα το `task_id`, και στη συνέχεια μέσω του `POST /dreamina/tasks` (δωρεάν) ελέγχει το αποτέλεσμα με βάση το `task_id` ή το `trace_id`.

Για λεπτομέρειες σχετικά με τη διαδικασία ελέγχου, δείτε το [Dreamina Tasks API](https://platform.acedata.cloud/documents/dreamina-tasks-integration).

### Διαχείριση Σφαλμάτων

| Κωδικός Κατάστασης | code                                      | Σημασία                                   |
| ------------------ | ----------------------------------------- | ---------------------------------------- |
| 400                | `bad_request`                             | Λείπουν ή είναι άκυρες παράμετροι (π.χ. `image_url` / `audio_url`) |
| 401                | `authorization_missing` / `invalid_token` | Λείπει ή είναι άκυρο το διακριτικό εξουσιοδότησης                            |
| 403                | `forbidden`                               | Έλλειψη υπολοίπου/ποσοστού ή μη εξουσιοδοτημένο upstream                       |
| 429                | `too_many_requests`                       | Πάρα πολλές αιτήσεις, υπέρβαση ορίου ρυθμού                          |
| 500                | `api_error`                               | Εσωτερικό σφάλμα διακομιστή                              |

```json
{
  "error": {
    "code": "bad_request",
    "message": "image_url is required (a public URL of a portrait image)"
  },
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

### Χρέωση

Η χρέωση γίνεται με βάση τη διάρκεια του παραγόμενου βίντεο, με τη μέγιστη τιμή περίπου **¥1/δευτερόλεπτο** (π.χ. βίντεο 10 δευτερολέπτων περίπου ¥10).
