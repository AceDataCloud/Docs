## Dreamina Tasks API της διασύνδεσης και χρήσης

Το Dreamina Tasks API χρησιμοποιείται για την αναζήτηση των αποτελεσμάτων εκτέλεσης των ψηφιακών βίντεο εργασιών που δημιουργούνται από το [Dreamina Video Generation API](https://platform.acedata.cloud/documents/dreamina-videos-integration). Όταν εισάγετε `callback_url` ή `async: true` στη διεπαφή δημιουργίας, η διεπαφή επιστρέφει αμέσως ένα `task_id`, το οποίο μπορείτε να χρησιμοποιήσετε μέσω αυτής της διεπαφής για να ελέγξετε την κατάσταση της εργασίας και τη τελική διεύθυνση βίντεο με βάση το `task_id` ή το `trace_id`. **Αυτή η διεπαφή είναι δωρεάν.**

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε τη σειρά API Dreamina, πρώτα πηγαίνετε στο [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πίστωση, ώστε να μπορείτε να δοκιμάσετε δωρεάν. Όταν η πίστωση εξαντληθεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο σας στο [console](https://platform.acedata.cloud/console/coin).

## Παράμετροι αιτήματος

**Request Headers**

- `accept`: καθορίζει την αποδοχή απαντήσεων σε μορφή JSON, συμπληρώστε `application/json`.
- `authorization`: το κλειδί για την κλήση του API, μορφή `Bearer {token}`.
- `content-type`: συμπληρώστε `application/json`.

**Request Body**

| Παράμετρος  | Τύπος     | Υποχρεωτική | Περιγραφή                                           |
| ----------- | -------- | --------- | ------------------------------------------------- |
| `action`    | string   | Όχι       | Τύπος ενέργειας, `retrieve` (προεπιλογή, αναζήτηση ενός) ή `retrieve_batch` (μαζική αναζήτηση) |
| `id`        | string   | Όχι       | Το ID της εργασίας που θέλετε να αναζητήσετε (το `task_id` που επιστρέφεται κατά τη δημιουργία βίντεο) |
| `trace_id`  | string   | Όχι       | Το ID παρακολούθησης της εργασίας που θέλετε να αναζητήσετε, μπορεί να χρησιμοποιηθεί αντί του `id` |
| `ids`       | string[] | Όχι       | Λίστα ID εργασιών για μαζική αναζήτηση, χρησιμοποιείται με `retrieve_batch` |

> Όταν αναζητάτε μία μόνο εργασία, τουλάχιστον ένα από τα `id` ή `trace_id` πρέπει να παρέχεται.

## Αναζήτηση μίας μόνο εργασίας

### CURL

```bash
curl -X POST 'https://api.acedata.cloud/dreamina/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "retrieve",
  "id": "362b4fed-67bd-11f1-ad11-00163e57d510"
}'
```

### Python

```python
import requests

url = "https://api.acedata.cloud/dreamina/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "retrieve",
    "id": "362b4fed-67bd-11f1-ad11-00163e57d510"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Παράδειγμα απάντησης

Αφού η αίτηση είναι επιτυχής, το API επιστρέφει τις λεπτομέρειες της εργασίας. Το `request` είναι το σώμα της αίτησης κατά τη δημιουργία της εργασίας, το `response` είναι το σώμα της απάντησης μετά την ολοκλήρωση της εργασίας, όπου το `data.video_url` είναι η διεύθυνση του παραγόμενου ψηφιακού βίντεο:

```json
{
  "id": "362b4fed-67bd-11f1-ad11-00163e57d510",
  "started_at": 1769262721.823,
  "finished_at": 1769262769.123,
  "elapsed": 47.3,
  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",
  "request": {
    "model": "omnihuman-1.5",
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  },
  "response": {
    "success": true,
    "data": {
      "task_id": "362b4fed67bd11f1ad1100163e57d510",
      "status": "done",
      "video_url": "https://cdn.acedata.cloud/634d760216.mp4",
      "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
      "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
    }
  }
}
```

Περιγραφή πεδίων:

- `id`: Το μοναδικό ID της εργασίας δημιουργίας βίντεο.
- `trace_id`: Το ID παρακολούθησης της τρέχουσας αίτησης, χρησιμοποιείται για την επίλυση προβλημάτων.
- `request`: Το περιεχόμενο της αίτησης που υποβλήθηκε κατά τη δημιουργία της εργασίας.
- `response`: Το περιεχόμενο της απάντησης που επιστρέφεται μετά την ολοκλήρωση της εργασίας. Όταν το `response.data.status` είναι `done`, το `response.data.video_url` είναι η τελική διεύθυνση βίντεο.
- `created_at`: Η ώρα δημιουργίας της εργασίας, Unix χρονική σφραγίδα (δευτερόλεπτα, κινητό).
- `started_at`: Η ώρα έναρξης εκτέλεσης της εργασίας, Unix χρονική σφραγίδα (δευτερόλεπτα, κινητό).
- `finished_at`: Η ώρα ολοκλήρωσης της εργασίας, Unix χρονική σφραγίδα (δευτερόλεπτα, κινητό). Δεν επιστρέφεται αυτό το πεδίο αν η εργασία δεν έχει ολοκληρωθεί.
- `elapsed`: Ο χρόνος εκτέλεσης της εργασίας, μονάδα σε δευτερόλεπτα (κινητό, διατηρεί 3 δεκαδικά). Δεν επιστρέφεται αυτό το πεδίο αν η εργασία δεν έχει ολοκληρωθεί.

> Εάν η εργασία δεν έχει ολοκληρωθεί, το `status` μπορεί να είναι σε κατάσταση που δεν είναι `done`; εάν η εργασία δεν υπάρχει ή δεν έχει παραχθεί αποτέλεσμα, η διεπαφή θα επιστρέψει κενό αντικείμενο `{}`, παρακαλώ δοκιμάστε ξανά αργότερα.

## Μαζική αναζήτηση εργασιών

Ορίστε το `action` σε `retrieve_batch` και εισάγετε τον πίνακα `ids`:

```bash
curl -X POST 'https://api.acedata.cloud/dreamina/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "retrieve_batch",
  "ids": [
    "362b4fed-67bd-11f1-ad11-00163e57d510",
    "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70"
  ]
}'
```

Στα αποτελέσματα επιστροφής, το `items` είναι ο πίνακας λεπτομερειών των μαζικών εργασιών (κάθε στοιχείο έχει την ίδια μορφή με το αποτέλεσμα μίας μόνο αναζήτησης), το `count` είναι ο αριθμός των εργασιών που επιστρέφονται αυτή τη φορά.

## Διαχείριση σφαλμάτων

Όταν καλείτε το API και προκύψει σφάλμα, θα επιστραφεί ο αντίστοιχος κωδικός σφάλματος και πληροφορίες:

- `400 bad_request`: Σφάλμα αιτήματος, μπορεί να λείπουν απαραίτητες παράμετροι όπως `id` / `trace_id`.
- `401 invalid_token`: Μη εξουσιοδοτημένο, το διαπιστευτήριο εξουσιοδότησης είναι άκυρο ή λείπει.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχει ξεπεραστεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.

### Παράδειγμα σφάλματος απάντησης

```json
{
  "error": {
    "code": "bad_request",
    "message": "id or trace_id is required to retrieve a task"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Συμπέρασμα

Σε συνδυασμό με τη διεπαφή δημιουργίας με `callback_url` / `async` ασύγχρονη λειτουργία, μπορείτε να επιτύχετε σταθερή αναζήτηση. Εάν έχετε οποιαδήποτε ερώτηση, παρακαλώ επικοινωνήστε με την τεχνική υποστήριξη μας.
