Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο σύνδεσης με το hCaptcha πρωτόκολλο αναγνώρισης API, που επιτρέπει στους χρήστες να μην χρειάζεται να αναγνωρίζουν και να επιλέγουν εικόνες captcha hCaptcha, αλλά να ολοκληρώνουν την επαλήθευση υποβάλλοντας απλώς το Website Key, επιτυγχάνοντας αυτόματη αποκωδικοποίηση στο παρασκήνιο.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [hCaptcha Πρωτόκολλο Αναγνώρισης API](https://platform.acedata.cloud/documents/34806b3a-f0f6-45c5-b8b1-143ced7b9393) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις, που σας επιτρέπουν να χρησιμοποιήσετε το API δωρεάν.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε το URL της ιστοσελίδας που χρειάζεται να επεξεργαστεί το hCaptcha captcha, για να λάβετε το επεξεργασμένο αποτέλεσμα. Πρέπει πρώτα να μεταβιβάσετε ένα πεδίο `website_url`. Η ιστοσελίδα παραδείγματός μας είναι: `https://accounts.hcaptcha.com/demo`, και πρέπει να αποκτήσουμε το `website_key` από τη σελίδα `website_url`. Πρώτα, ανοίξτε αυτή τη σελίδα, πατήστε F12 για να εισέλθετε στην κονσόλα και στη συνέχεια κάντε παγκόσμια αναζήτηση στην καρτέλα Element για το `hcaptcha-demo`, από όπου μπορούμε να πάρουμε το παρακάτω αποτέλεσμα:

<p><img src="https://cdn.acedata.cloud/bmx7ik.png" width="500" class="m-auto"></p>

Το `data-sitekey` που αντιστοιχεί σε μια σειρά χαρακτήρων είναι η τιμή του `website_key`. Ακολουθούν τα συγκεκριμένα αποτελέσματα παραμέτρων:

<p><img src="https://cdn.acedata.cloud/st6q7a.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `website_url`: το URL της ιστοσελίδας που χρειάζεται να επεξεργαστεί το captcha.
- `website_key`: ο αναγνωριστικός κωδικός του ιστότοπου στο hCaptcha.

由上图分析可知，此次POST请求的URL为：`https://accounts.hcaptcha.com/demo`，我们仅需要提交参数 `g-recaptcha-response`、`h-captcha-response` 和 `email`，然后我们只需要将处理后的token传入下面的data中即可，调用token验证所对应CURL代码如下：

```shell
curl 'https://accounts.hcaptcha.com/demo' \
  --data-raw 'email=&g-recaptcha-response={token}&h-captcha-response={token}'
```

调用token验证所对应的Python代码如下：

```python
import requests

token = '{token}'

data = {
    'email': '',
    'g-recaptcha-response': token,
    'h-captcha-response': token
}

response = requests.post('https://accounts.hcaptcha.com/demo',
                        data=data)

if response.status_code == 200:
    print(response.text)

```

另外如果想生成对应的对接代码，可以直接复制生成，例如 CURL 的代码如下：

```shell
curl -X POST 'https://api.acedata.cloud/captcha/token/hcaptcha' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2",
  "website_url": "https://accounts.hcaptcha.com/demo"
}'
```

Python 的对接代码如下：

```python
import requests

url = "https://api.acedata.cloud/captcha/token/hcaptcha"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2",
    "website_url": "https://accounts.hcaptcha.com/demo"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 错误处理

在调用 API 时，如果遇到错误，API 会返回相应的错误代码和信息。例如：

- `400 token_mismatched`：Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`：Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`：Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`：Too many requests, you have exceeded the rate limit.
- `500 api_error`：Internal server error, something went wrong on the server.

```json
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
