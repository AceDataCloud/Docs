Αυτό το άρθρο θα παρουσιάσει μια μέθοδο για την ενσωμάτωση του API αναγνώρισης εικόνας hCaptcha, το οποίο μπορεί να αναγνωρίσει το περιεχόμενο που εισάγει ο χρήστης και την εικόνα του captcha hCaptcha, επιστρέφοντας τελικά τις συντεταγμένες της μικρής εικόνας που πρέπει να κάνετε κλικ για να ολοκληρώσετε την επαλήθευση.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το API αναγνώρισης εικόνας hCaptcha, πρώτα πηγαίνετε στο [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη σελίδα που βρίσκεστε.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν. Όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό σας υπόλοιπο στο [Console](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [hCaptcha API αναγνώρισης εικόνας →](https://platform.acedata.cloud/documents/recognition-hcaptcha-integration)

## Βασική χρήση

Πρώτα, ας κατανοήσουμε τη βασική μέθοδο χρήσης, δηλαδή να εισάγουμε την εικόνα του captcha hCaptcha που χρειάζεται επεξεργασία, για να αποκτήσουμε το επεξεργασμένο αποτέλεσμα. Πρέπει πρώτα να περάσουμε ένα πεδίο `queries`, το οποίο είναι η συγκεκριμένη εικόνα captcha hCaptcha. Πρέπει να αποκόψουμε αυτή την εικόνα captcha από μια ιστοσελίδα που έχει captcha hCaptcha, το παράδειγμα της ιστοσελίδας είναι: `https://democaptcha.com/demo-form-eng/hcaptcha.html`, κάνοντας κλικ στο πλαίσιο επιλογής για να εμφανιστεί η πλήρης εικόνα captcha, όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/xryo59.png" width="500" className="m-auto" /></p>

Το πεδίο `queries` είναι το στιγμιότυπο της εικόνας captcha που αναφέρθηκε παραπάνω, το μέγεθος της εικόνας προτείνεται να μην υπερβαίνει τα 100kb, και πρέπει επίσης να αποκόψετε την περιοχή που υποδεικνύεται από το κόκκινο βέλος στην παραπάνω εικόνα, και θα χρειαστεί να συμπιέσετε το μέγεθος της εικόνας και να την μετατρέψετε σε κωδικοποίηση Base64, όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/g8ikkb.png" width="500" className="m-auto" /></p>

Επιπλέον, πρέπει να εισάγετε την παράμετρο αναγνώρισης που σχετίζεται με την εικόνα captcha `question`, η οποία υποστηρίζει μετάφραση στα κινέζικα και αγγλικά, μπορείτε να περάσετε απευθείας το σχετικό περιεχόμενο αναγνώρισης. Από το περιεχόμενο που εκτελείται στην εικόνα της ιστοσελίδας παραπάνω, μπορεί να φανεί ότι η είσοδος `question` πρέπει να είναι `Please click on the UNIQUE object among the others.`. Οι λεπτομέρειες είναι οι εξής:

<p><img src="https://cdn.acedata.cloud/empncr.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `queries`: Λίστα εικόνων captcha κωδικοποιημένων σε Base64.
- `question`: Παράμετρος αναγνώρισης που σχετίζεται με την εικόνα captcha, υποστηρίζει άμεση είσοδο στα κινέζικα και αγγλικά.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/bww9b0.png" width="500" className="m-auto" /></p>

Κάνοντας κλικ στο κουμπί «Try» μπορείτε να κάνετε δοκιμές, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "solution": {
    "label": "Please click on the UNIQUE object among the others",
    "box": [
      "360",
      "276"
    ],
    "confidences": 0.6354503631591797
  }
}
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, τα οποία περιγράφονται ως εξής:

- `solution`, το αποτέλεσμα της επεξεργασίας της εικόνας captcha hCaptcha.
    - `label`, το περιεχόμενο που αναγνωρίστηκε από την εικόνα captcha hCaptcha.
    - `box`, οι πληροφορίες θέσης του αποτελέσματος αναγνώρισης της εικόνας captcha hCaptcha, που αποτελούνται από τις συντεταγμένες της εικόνας.
    - `confidences`, η εμπιστοσύνη της αναγνώρισης που πληροί το περιεχόμενο αναγνώρισης της εικόνας captcha hCaptcha.
- `started_at`, `finished_at`: Ο χρόνος έναρξης και ολοκλήρωσης της επεξεργασίας της τρέχουσας αίτησης, Unix timestamp (δευτερόλεπτα, float).
- `elapsed`: Ο συνολικός χρόνος επεξεργασίας (δευτερόλεπτα).

Μπορείτε να δείτε ότι έχουμε λάβει το αποτέλεσμα επαλήθευσης της εικόνας captcha hCaptcha, και απλά πρέπει να κάνουμε κλικ στην περιοχή που υποδεικνύεται από τις συντεταγμένες `box` της απάντησης για να περάσουμε την επαλήθευση.

Ακολουθεί η περιγραφή του πώς να κάνετε κλικ χρησιμοποιώντας τις πληροφορίες θέσης `box` της απάντησης. Πρώτα, θα δημιουργήσουμε ένα ορθογώνιο σύστημα συντεταγμένων για την εικόνα captcha που ανεβάσατε, όπου το κέντρο είναι στην κάτω αριστερή γωνία της εικόνας, το 360 είναι η αντίστοιχη οριζόντια συντεταγμένη και το 276 είναι η αντίστοιχη κατακόρυφη συντεταγμένη. Απλά πρέπει να κάνουμε κλικ στις συντεταγμένες της εικόνας captcha, όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/4ykvbl.png" width="500" className="m-auto" /></p>

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα ενσωμάτωσης, μπορείτε να τον αντιγράψετε απευθείας, για παράδειγμα, ο κώδικας CURL είναι ως εξής:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/hcaptcha' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "question": "Please click on the UNIQUE object among the others.",
  "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"]
}'
```

Ο κώδικας ενσωμάτωσης Python είναι ως εξής:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/hcaptcha"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "question": "Please click on the UNIQUE object among the others.",
    "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Ασύγχρονη λειτουργία (async)

Από προεπιλογή, το API είναι συγχρονισμένο και μπλοκαρισμένο: μια αίτηση θα περιμένει μέχρι να ολοκληρωθεί η επεξεργασία του αποτελέσματος αναγνώρισης. Εάν κάνετε εναλλαγή πολλών αναγνωριστών (multi-solver rotation) και θέλετε να «λάβετε αμέσως το task_id μετά την υποβολή της εργασίας, να προγραμματίσετε άλλους αναγνωριστές και αργότερα να επιστρέψετε για να διαβάσετε το αποτέλεσμα», μπορείτε να περάσετε `async: true` στο σώμα της αίτησης.

Αφού περάσετε `async: true`, η διεπαφή θα επιστρέψει αμέσως ένα `task_id`, χωρίς να μπλοκάρει την αναμονή:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/hcaptcha' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "question": "Please click on the UNIQUE object among the others.",
  "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"],
  "async": true
}'
```
```json
{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

Για να ελέγξετε την πρόοδο ενεργά, μπορείτε να χρησιμοποιήσετε το `task_id` για να ελέγξετε το `POST /captcha/tasks` (συνιστάται κάθε 3~5 δευτερόλεπτα). Αυτή η διεπαφή δεν θα ενεργοποιήσει ή θα προχωρήσει την επεξεργασία του έργου. Ακόμα και αν δεν ελέγξετε, αν διακοπεί η σύνδεση ή αν αποσυνδεθείτε από τον πελάτη, ο διακομιστής θα συνεχίσει να επεξεργάζεται:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002"
}'
```

Κατά την επεξεργασία θα επιστραφεί `status: processing`:

```json
{ "success": true, "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002", "status": "processing" }
```

Όταν ολοκληρωθεί η επεξεργασία θα επιστραφεί `status: ready` και το αποτέλεσμα αναγνώρισης `solution` (η δομή πεδίου είναι απολύτως συμβατή με τη λειτουργία συγχρονισμού):

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "ready",
  "solution": {
    "label": "Παρακαλώ κάντε κλικ στο ΜΟΝΑΔΙΚΟ αντικείμενο ανάμεσα στα άλλα",
    "box": ["360", "276"],
    "confidences": 0.6354503631591797
  }
}
```

Πληροφορίες χρέωσης: Στη λειτουργία ασύγχρονης επεξεργασίας, η δημιουργία έργου και η ανάγνωση της κατάστασης «σε επεξεργασία» δεν χρεώνονται. **Ο πελάτης χρεώνεται μία φορά κατά την πρώτη επιτυχή ανάγνωση του αποτελέσματος** (σύμφωνα με τη συμπεριφορά και την τιμή της λειτουργίας συγχρονισμού). Ο διακομιστής θα προχωρήσει αυτόματα το έργο, αλλά δεν θα χρεώσει νωρίτερα επειδή ολοκληρώθηκε πρώτα στο παρασκήνιο. Εάν το έργο δεν ολοκληρωθεί εντός 120 δευτερολέπτων, θα τερματιστεί με HTTP 504 `timeout`, χωρίς χρέωση. Το `/captcha/tasks` δεν είναι υπεύθυνο για την προώθηση του έργου.

## Διαχείριση σφαλμάτων

Κατά την κλήση της API, εάν προκύψει σφάλμα, η API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα απόκρισης σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
