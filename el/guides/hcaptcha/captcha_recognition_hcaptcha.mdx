Αυτό το άρθρο θα παρουσιάσει μια μέθοδο για την ενσωμάτωση του API αναγνώρισης εικόνας hCaptcha, το οποίο μπορεί να αναγνωρίσει το περιεχόμενο που εισάγει ο χρήστης και την εικόνα του captcha hCaptcha, επιστρέφοντας τελικά τις συντεταγμένες της μικρής εικόνας που πρέπει να κάνετε κλικ για να ολοκληρώσετε την επαλήθευση.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα του [API αναγνώρισης εικόνας hCaptcha](https://platform.acedata.cloud/documents/c9a5cc2f-e410-425f-857a-f8700205da6c) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να σας προσκαλέσουν να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να χρησιμοποιήσετε το API δωρεάν.

## Βασική χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε την εικόνα του captcha hCaptcha που χρειάζεται επεξεργασία, για να λάβετε το επεξεργασμένο αποτέλεσμα. Πρέπει πρώτα να περάσετε ένα πεδίο `queries`, το οποίο είναι η συγκεκριμένη εικόνα captcha hCaptcha. Πρέπει να αποκόψετε αυτήν την εικόνα captcha από μια ιστοσελίδα που έχει captcha hCaptcha, το παράδειγμα της ιστοσελίδας είναι: `https://democaptcha.com/demo-form-eng/hcaptcha.html`, κάνοντας κλικ στο πλαίσιο ελέγχου για να εμφανιστεί η πλήρης εικόνα captcha, όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/xryo59.png" width="500" className="m-auto" /></p>

Το πεδίο `queries` είναι το στιγμιότυπο της εικόνας captcha που αναφέρθηκε παραπάνω. Το μέγεθος της εικόνας προτείνεται να μην υπερβαίνει τα 100kb, και πρέπει επίσης να αποκόψετε την περιοχή που υποδεικνύεται από το κόκκινο βέλος στην παραπάνω εικόνα, και θα χρειαστεί να συμπιέσετε το μέγεθος της εικόνας και να το μετατρέψετε σε κωδικοποίηση Base64, όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/g8ikkb.png" width="500" className="m-auto" /></p>

Επιπλέον, πρέπει να εισάγετε την παράμετρο περιεχομένου αναγνώρισης που σχετίζεται με την εικόνα captcha `question`, η οποία υποστηρίζει μετάφραση στα κινέζικα και τα αγγλικά. Μπορείτε να περάσετε απευθείας το σχετικό περιεχόμενο αναγνώρισης. Από το περιεχόμενο που εκτελείται στην εικόνα της ιστοσελίδας παραπάνω, μπορεί να φανεί ότι η είσοδος `question` πρέπει να είναι `Please click on the UNIQUE object among the others.`. Οι συγκεκριμένες λεπτομέρειες είναι οι εξής:

<p><img src="https://cdn.acedata.cloud/empncr.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, συμπεριλαμβανομένων:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, συμπεριλαμβανομένων:

- `queries`: Λίστα εικόνων captcha σε κωδικοποίηση Base64.
- `question`: Παράμετρος περιεχομένου αναγνώρισης που σχετίζεται με την εικόνα captcha, υποστηρίζει άμεση είσοδο στα κινέζικα και τα αγγλικά.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/bww9b0.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "solution": {
    "label": "Please click on the UNIQUE object among the others",
    "box": [
      "360",
      "276"
    ],
    "confidences": 0.6354503631591797
  }
}
```

Το επιστρεφόμενο αποτέλεσμα περιλαμβάνει πολλά πεδία, τα οποία περιγράφονται ως εξής:

- `solution`, το αποτέλεσμα της επεξεργασίας της εικόνας captcha hCaptcha.
  - `label`, το περιεχόμενο που αναγνωρίστηκε από την εικόνα captcha hCaptcha.
  - `box`, οι πληροφορίες θέσης του αποτελέσματος αναγνώρισης της εικόνας captcha hCaptcha, οι οποίες αποτελούνται από τις συντεταγμένες της εικόνας.
  - `confidences`, η εμπιστοσύνη της αναγνώρισης του περιεχομένου μετά την αναγνώριση της εικόνας captcha hCaptcha.

Μπορείτε να δείτε ότι έχουμε λάβει το αποτέλεσμα της επαλήθευσης της εικόνας captcha hCaptcha. Χρειάζεται μόνο να κάνουμε κλικ στην περιοχή που υποδεικνύεται από τις συντεταγμένες `box` της εικόνας captcha για να περάσουμε την επαλήθευση.

Παρακάτω θα παρουσιαστεί πώς να κάνετε κλικ χρησιμοποιώντας τις πληροφορίες θέσης `box` του αποτελέσματος. Αρχικά, θα δημιουργήσουμε ένα ορθογώνιο σύστημα συντεταγμένων για την εικόνα captcha που ανεβάσατε, όπου το κέντρο είναι στην κάτω αριστερή γωνία της εικόνας, το 360 είναι η αντίστοιχη οριζόντια συντεταγμένη και το 276 είναι η αντίστοιχη κατακόρυφη συντεταγμένη. Χρειάζεται απλώς να κάνετε κλικ στις συντεταγμένες της εικόνας captcha, όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/4ykvbl.png" width="500" className="m-auto" /></p>

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα ενσωμάτωσης, μπορείτε να τον αντιγράψετε απευθείας, για παράδειγμα, ο κώδικας CURL είναι ο εξής:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/hcaptcha' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "question": "Please click on the UNIQUE object among the others.",
  "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"]
}'
```

Ο κώδικας ενσωμάτωσης Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/hcaptcha"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "question": "Please click on the UNIQUE object among the others.",
    "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και τις πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
