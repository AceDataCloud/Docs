Γνωρίζουμε ότι η σύνδεση με ορισμένα API ερωτήσεων και απαντήσεων στην αγορά δεν είναι τόσο εύκολη, όπως το API Chat Completions της OpenAI, το οποίο έχει ένα πεδίο `messages`. Για να ολοκληρωθεί η συνεχής συνομιλία, πρέπει να μεταφέρουμε όλο το ιστορικό του πλαισίου και να διαχειριστούμε το πρόβλημα υπέρβασης του περιορισμού των Token.

Το AI API ερωτήσεων και απαντήσεων της AceDataCloud έχει βελτιστοποιηθεί για την παραπάνω κατάσταση, διατηρώντας την αποτελεσματικότητα των ερωτήσεων και απαντήσεων, έχει συσκευάσει την υλοποίηση της συνεχούς συνομιλίας, χωρίς να χρειάζεται να ανησυχούμε για τη μεταφορά των μηνυμάτων ή το πρόβλημα υπέρβασης του περιορισμού των Token (το API το διαχειρίζεται αυτόματα εσωτερικά). Παρέχει επίσης δυνατότητες αναζήτησης και τροποποίησης συνομιλιών, απλοποιώντας σημαντικά τη συνολική σύνδεση.

Αυτό το έγγραφο θα παρουσιάσει τις οδηγίες σύνδεσης του AI API ερωτήσεων και απαντήσεων.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [AI API ερωτήσεων και απαντήσεων](https://platform.acedata.cloud/documents/59fb1199-6694-4afb-a222-3554d7f7d05a) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να χρησιμοποιήσετε το API δωρεάν.

## Βασική Χρήση

Αρχικά, ας κατανοήσουμε τη βασική μέθοδο χρήσης, δηλαδή την εισαγωγή ερώτησης και την απόκτηση απάντησης, απλά μεταφέροντας ένα πεδίο `question` και καθορίζοντας το αντίστοιχο μοντέλο.

Για παράδειγμα, ρωτώντας: “What's your name;”, μπορούμε στη συνέχεια να συμπληρώσουμε το αντίστοιχο περιεχόμενο στην οθόνη, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/xqxda4.png)

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, συμπεριλαμβανομένων:

- `accept`: ποια μορφή απάντησης θέλουμε να λάβουμε, εδώ συμπληρώνουμε `application/json`, δηλαδή μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, συμπεριλαμβανομένων:

- `model`: η επιλογή του μοντέλου, όπως το δημοφιλές GPT 3.5, GPT 4 κ.λπ.
- `question`: η ερώτηση που θέλουμε να κάνουμε, μπορεί να είναι οποιοδήποτε απλό κείμενο.

Αφού επιλέξουμε, μπορούμε να δούμε ότι στα δεξιά έχει παραχθεί ο αντίστοιχος κώδικας, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/dvkps6.png" width="500" class="m-auto"></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "answer": "I am an AI language model developed by OpenAI and I don't have a personal name. However, you can call me GPT or simply Chatbot. How can I assist you today?"
}
```

Μπορείτε να δείτε ότι το αποτέλεσμα που επιστρέφεται περιέχει ένα πεδίο `answer`, το οποίο είναι η απάντηση στην ερώτηση. Μπορούμε να εισάγουμε οποιαδήποτε ερώτηση και να λάβουμε οποιαδήποτε απάντηση.

Εάν δεν χρειάζεστε υποστήριξη για πολλές συνομιλίες, αυτό το API μπορεί να διευκολύνει σημαντικά τη σύνδεσή σας.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο παρακάτω κώδικας CURL:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "question": "What's your name?"
}'
```

Ο κώδικας σύνδεσης Python είναι ως εξής:

```python
import requests

url = "https://api.acedata.cloud/aichat/conversations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-3.5",
    "question": "What's your name?"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Πολλές Συνομιλίες

Εάν θέλετε να συνδέσετε τη λειτουργία πολλαπλών συνομιλιών, πρέπει να μεταφέρετε μια επιπλέον παράμετρο `stateful`, η τιμή της οποίας θα είναι `true`. Σε κάθε επόμενη αίτηση, θα πρέπει να περιλαμβάνετε αυτή την παράμετρο. Αφού μεταφέρετε την παράμετρο `stateful`, το API θα επιστρέψει επιπλέον μια παράμετρο `id`, που αντιπροσωπεύει το ID της τρέχουσας συνομιλίας. Στη συνέχεια, απλά πρέπει να μεταφέρετε αυτό το ID ως παράμετρο για να υλοποιήσετε εύκολα τις πολλές συνομιλίες.

Ας δούμε τώρα τη συγκεκριμένη διαδικασία.

Στην πρώτη αίτηση, ρυθμίζουμε την παράμετρο `stateful` σε `true` και μεταφέρουμε κανονικά τις παραμέτρους `model` και `question`, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/fn4bi9.png)

Ο αντίστοιχος κώδικας είναι ως εξής:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "question": "What's your name?",
  "stateful": true
}'
```

Μπορούμε να λάβουμε την εξής απάντηση:

```json
{
  "answer": "I am an AI language model created by OpenAI and I don't have a personal name. You can simply call me OpenAI or ChatGPT. How can I assist you today?",
  "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"
}
```

Στη δεύτερη αίτηση, μεταφέρουμε το πεδίο `id` που επιστράφηκε από την πρώτη αίτηση ως παράμετρο, ενώ η παράμετρος `stateful` παραμένει ρυθμισμένη σε `true`, ρωτώντας «What I asked you just now;», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/46a6kd.png)

Ο αντίστοιχος κώδικας είναι ως εξής:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "stateful": true,
  "id": "7cdb293b-2267-4979-a1ec-48d9ad149916",
  "question": "What I asked you just now?"
}'
```

Το αποτέλεσμα είναι το εξής:

```json
{
  "answer": "You asked me what my name is. As an AI language model, I do not possess a personal identity, so I don't have a specific name. However, you can refer to me as OpenAI or ChatGPT, the names used for this AI model. Is there anything else I can help you with?",
  "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"
}
```

Μπορείτε να δείτε ότι μπορούμε να απαντήσουμε στις αντίστοιχες ερωτήσεις με βάση το πλαίσιο.

## Ροή Απάντησης

Αυτή η διεπαφή υποστηρίζει επίσης ροή απάντησης, κάτι που είναι πολύ χρήσιμο για τη σύνδεση ιστοσελίδων, καθώς επιτρέπει την εμφάνιση αποτελεσμάτων λέξη προς λέξη.

Εάν θέλετε να επιστρέψετε την απάντηση με ροή, μπορείτε να αλλάξετε την παράμετρο `accept` στα Request Headers σε `application/x-ndjson`.

Η αλλαγή είναι όπως φαίνεται στην εικόνα, αλλά ο κώδικας κλήσης πρέπει να έχει τις αντίστοιχες αλλαγές για να υποστηρίξει τη ροή απάντησης.

![](https://cdn.acedata.cloud/axt1aa.png)

Αφού αλλάξετε το `accept` σε `application/x-ndjson`, το API θα επιστρέφει γραμμή προς γραμμή τα αντίστοιχα δεδομένα JSON, και σε επίπεδο κώδικα θα χρειαστεί να κάνουμε τις κατάλληλες αλλαγές για να αποκτήσουμε τα αποτελέσματα γραμμή προς γραμμή.

Δείγμα κώδικα κλήσης Python:
```python
import requests

url = "https://api.acedata.cloud/aichat/conversations"

headers = {
    "accept": "application/x-ndjson",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-3.5",
    "stateful": True,
    "id": "7cdb293b-2267-4979-a1ec-48d9ad149916",
    "question": "Γειά σου"
}

response = requests.post(url, json=payload, headers=headers, stream=True)
for line in response.iter_lines():
    print(line.decode())
```

Η έξοδος είναι ως εξής:

```json
{"answer": "Γειά σου", "delta_answer": "Γειά σου", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Γειά σου!", "delta_answer": "!", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Γειά σου! Πώς", "delta_answer": " Πώς", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Γειά σου! Πώς μπορώ", "delta_answer": " μπορώ", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Γειά σου! Πώς μπορώ να", "delta_answer": " να", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Γειά σου! Πώς μπορώ να βοηθήσω", "delta_answer": " βοηθήσω", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Γειά σου! Πώς μπορώ να βοηθήσω εσένα", "delta_answer": " εσένα", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Γειά σου! Πώς μπορώ να βοηθήσω εσένα σήμερα", "delta_answer": " σήμερα", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Γειά σου! Πώς μπορώ να βοηθήσω εσένα σήμερα;", "delta_answer": ";", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
```

Μπορείτε να δείτε ότι η απάντηση μέσα στο `answer` είναι το πιο πρόσφατο περιεχόμενο απάντησης, ενώ το `delta_answer` είναι το νέο περιεχόμενο απάντησης, μπορείτε να το χρησιμοποιήσετε για να το συνδέσετε στο σύστημά σας.

Η JavaScript υποστηρίζεται επίσης, για παράδειγμα, ο κωδικός ροής για το Node.js είναι ως εξής:

```javascript
const axios = require("axios");

const url = "https://api.acedata.cloud/aichat/conversations";
const headers = {
  "Content-Type": "application/json",
  Accept: "application/x-ndjson",
  Authorization: "Bearer {token}",
};
const body = {
  question: "Γειά σου",
  model: "gpt-3.5",
  stateful: true,
};

axios
  .post(url, body, { headers: headers, responseType: "stream" })
  .then((response) => {
    console.log(response.status);
    response.data.on("data", (chunk) => {
      console.log(chunk.toString());
    });
  })
  .catch((error) => {
    console.error(error);
  });
```

Παράδειγμα κώδικα Java:

```java
String url = "https://api.acedata.cloud/aichat/conversations";
OkHttpClient client = new OkHttpClient();
MediaType mediaType = MediaType.parse("application/json");
RequestBody body = RequestBody.create(mediaType, "{\"question\": \"Γειά σου\", \"stateful\": true, \"model\": \"gpt-3.5\"}");
Request request = new Request.Builder()
        .url(url)
        .post(body)
        .addHeader("Content-Type", "application/json")
        .addHeader("Accept", "application/x-ndjson")
        .addHeader("Authorization", "Bearer {token}")
        .build();

client.newCall(request).enqueue(new Callback() {
    @Override
    public void onFailure(Call call, IOException e) {
        e.printStackTrace();
    }

    @Override
    public void onResponse(Call call, Response response) throws IOException {
        if (!response.isSuccessful()) throw new IOException("Αναπάντεχος κωδικός " + response);
        try (BufferedReader br = new BufferedReader(
                new InputStreamReader(response.body().byteStream(), "UTF-8"))) {
            String responseLine;
            while ((responseLine = br.readLine()) != null) {
                System.out.println(responseLine);
            }
        }
    }
});
```

Άλλες γλώσσες μπορούν να τροποποιηθούν ανάλογα, η αρχή είναι η ίδια.

## Προεπιλογές μοντέλου

Γνωρίζουμε ότι οι σχετικές API του OpenAI έχουν την έννοια του `system_prompt`, δηλαδή να ρυθμίζουν μια προεπιλογή για ολόκληρο το μοντέλο, όπως το όνομά του κ.λπ. Αυτή η API ερωτήσεων AI εκθέτει επίσης αυτή την παράμετρο, που ονομάζεται `preset`, χρησιμοποιώντας την μπορούμε να προσθέσουμε προεπιλογές στο μοντέλο, ας δούμε ένα παράδειγμα:

Εδώ προσθέτουμε επιπλέον το πεδίο `preset`, με περιεχόμενο `Είσαι ένας επαγγελματίας καλλιτέχνης`, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/ird6i9.png)

Ο αντίστοιχος κωδικός είναι ως εξής:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "stateful": true,
  "question": "Τι μπορείς να με βοηθήσεις;",
  "preset": "Είσαι ένας επαγγελματίας καλλιτέχνης"
}'
```

Το αποτέλεσμα είναι ως εξής:

```python
{
    "answer": "Ως επαγγελματίας καλλιτέχνης, μπορώ να προσφέρω μια σειρά υπηρεσιών και βοήθειας ανάλογα με τις συγκεκριμένες ανάγκες σας. Ακολουθούν μερικοί τρόποι που μπορώ να σας βοηθήσω:\n\n1. Προσαρμοσμένη Τέχνη: Αν έχετε μια συγκεκριμένη όραση ή ιδέα, μπορώ να δημιουργήσω προσαρμοσμένη τέχνη για εσάς. Αυτό μπορεί να περιλαμβάνει πίνακες, σχέδια, ψηφιακή τέχνη ή οποιοδήποτε άλλο μέσο προτιμάτε.\n\n2. Παραγγελίες: Αν έχετε ένα συγκεκριμένο θέμα ή έννοια στο μυαλό σας, μπορώ να δημιουργήσω παραγγελίες τέχνης προσαρμοσμένες στις προτιμήσεις σας. Αυτό θα μπορούσε να είναι για προσωπική απόλαυση ή ως μοναδικό δώρο για κάποιον ειδικό.\n\n3. Συμβουλευτική Τέχνης: Αν χρειάζεστε καθοδήγηση σχετικά με την επιλογή τέχνης, τον εσωτερικό σχεδιασμό ή πώς να παρουσιάσετε και να εκθέσετε την τέχνη στον χώρο σας, μπορώ να παρέχω επαγγελματικές συμβουλές για να βοηθήσω να ενισχύσετε την αισθητική σας αίσθηση και να δημιουργήσετε μια συνεκτική εμφάνιση."
}
```

Μπορείτε να δείτε ότι εδώ λέμε στο GPT ότι είναι ένα ρομπότ και ρωτάμε τι μπορεί να κάνει για εμάς, και μπορεί να υποδυθεί τον ρόλο ενός ρομπότ για να απαντήσει στις ερωτήσεις.

## Αναγνώριση εικόνας

Αυτή η AI υποστηρίζει επίσης την προσθήκη συνημμένων για αναγνώριση εικόνας, μεταφέροντας το αντίστοιχο σύνδεσμο εικόνας μέσω του `references`, για παράδειγμα, εδώ έχω μια εικόνα ενός μήλου, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/ht05g0.png)

Ο σύνδεσμος της εικόνας είναι [https://cdn.acedata.cloud/ht05g0.png](https://cdn.acedata.cloud/ht05g0.png), μπορούμε να το μεταφέρουμε απευθείας ως παράμετρο `references`, ενώ πρέπει να σημειωθεί ότι το μοντέλο πρέπει να επιλεγεί υποστηρίζοντας την οπτική αναγνώριση, αυτή τη στιγμή υποστηρίζεται το `gpt-4-vision`, οπότε η είσοδος είναι ως εξής:

![](https://cdn.acedata.cloud/cstrbq.png)

Ο αντίστοιχος κωδικός είναι ως εξής:

Μπορείτε να δείτε ότι έχουμε επιτυχώς λάβει την αντίστοιχη απάντηση για την εικόνα.

## Διαδικτυακές ερωτήσεις και απαντήσεις

Αυτή η API υποστηρίζει επίσης διαδικτυακά μοντέλα, συμπεριλαμβανομένων των GPT-3.5 και GPT-4, και τα δύο μπορούν να υποστηρίξουν, πίσω από την API υπάρχει μια αυτόματη διαδικασία αναζήτησης στο διαδίκτυο και συνοψίσεως, μπορούμε να επιλέξουμε το μοντέλο ως `gpt-3.5-browsing` για να το δοκιμάσουμε, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/x5i8np.png)

Ο κωδικός είναι ως εξής:
```
```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \

Μπορείτε να δείτε ότι αυτόματα συνδέθηκε στο διαδίκτυο και αναζήτησε πληροφορίες από την ιστοσελίδα The Weather Channel, και στη συνέχεια επέστρεψε τα αποτελέσματα σε πραγματικό χρόνο.
