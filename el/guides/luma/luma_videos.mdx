Με την ευρεία εφαρμογή της AI, διάφορα προγράμματα AI έχουν σταδιακά γίνει δημοφιλή. Η AI έχει βαθιά διεισδύσει σε όλες τις πτυχές της εργασιακής και καθημερινής ζωής των ανθρώπων. Οι τομείς που σχετίζονται με την AI αυξάνονται συνεχώς, από την αρχική συγγραφή, στην ιατρική εκπαίδευση, μέχρι τώρα, στα βίντεο.

Η Luma είναι μια επαγγελματική πλατφόρμα υψηλής ποιότητας για τη δημιουργία βίντεο, όπου οι χρήστες απλώς ανεβάζουν υλικό και μπορούν αυτόματα να δημιουργήσουν βίντεο υψηλής ποιότητας σύμφωνα με διάφορα στυλ και εφέ. Αυτός ο AI δημιουργός βίντεο έχει αναπτυχθεί από μέλη ομάδας γνωστών τεχνολογικών εταιρειών, με στόχο να επιτρέπει σε όλους να δημιουργούν εύκολα εξαιρετικά βίντεο χωρίς περίπλοκα εργαλεία επεξεργασίας.

Ωστόσο, η Luma δεν παρέχει επίσημα API, η AceDataCloud προσφέρει ένα σύνολο API της Luma, προσομοιώνοντας τη σύνδεση με την επίσημη Suno, διευκολύνοντας την ταχεία δημιουργία των επιθυμητών βίντεο.

## Αίτηση και Χρήση

Για να χρησιμοποιήσετε το Luma Videos API, μπορείτε πρώτα να επισκεφθείτε τη σελίδα [Luma Videos Generation API](https://platform.acedata.cloud/documents/5bd3597d-1ff8-44ad-a580-b66b48393e7f) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να σας προσκαλέσουν να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Για να δημιουργήσετε οποιοδήποτε βίντεο, μπορείτε να εισάγετε οποιοδήποτε κείμενο, για παράδειγμα, αν θέλετε να δημιουργήσετε ένα βίντεο σχετικά με αστροναύτες που μετακινούνται μεταξύ του διαστήματος και ηφαιστείων, μπορείτε να εισάγετε `Astronauts shuttle from space to volcano`, όπως φαίνεται στην εικόνα:

Ο παραγόμενος κώδικας είναι ο εξής:

<p><img src="https://cdn.acedata.cloud/ieq7yn.png" width="500" className="m-auto" /></p>

Κύριες παράμετροι αιτήματος:

- `prompt`: Η λέξη-κλειδί για τη δημιουργία του βίντεο.
- `aspect_ratio`: Η αναλογία διαστάσεων του βίντεο, προεπιλογή 16:9.
- `end_image_url`: Προαιρετικό, καθορίζει την τελευταία καρέ.
- `enhancement`: Προαιρετικό, διακόπτης ενίσχυσης ευκρίνειας.
- `loop`: Εάν θα δημιουργηθεί βίντεο σε βρόχο, προεπιλογή false.
- `timeout`: Προαιρετικό, αριθμός δευτερολέπτων για timeout.
- `callback_url`: Διεύθυνση ασύγχρονης κλήσης.

## Δημιουργία Προσαρμοσμένων Πρώτων και Τελευταίων Καρέ

Εάν θέλετε να δημιουργήσετε βίντεο μέσω προσαρμοσμένων πρώτων και τελευταίων καρέ, μπορείτε να εισάγετε τους συνδέσμους εικόνας των πρώτων και τελευταίων καρέ:

Αυτή τη στιγμή, το πεδίο `start_image_url` μπορεί να λάβει την παρακάτω εικόνα ως την πρώτη καρέ του βίντεο:

![Πρώτη καρέ](https://cdn.acedata.cloud/r9vsv9.png)

Στη συνέχεια, πρέπει να προσαρμόσουμε τη δημιουργία του βίντεο με βάση τις πρώτες και τελευταίες καρέ, καθορίζοντας τα εξής περιεχόμενα:

- action: Η ενέργεια της εργασίας δημιουργίας βίντεο, συνήθως είναι η κανονική δημιουργία `generate` και η επεκταμένη δημιουργία `extend`, προεπιλογή `generate`.
- start_image_url: Καθορίζει την πρώτη καρέ του παραγόμενου βίντεο.
- end_image_url: Καθορίζει την τελευταία καρέ του παραγόμενου βίντεο.
- prompt: Το περιεχόμενο των λέξεων-κλειδιών για τη δημιουργία του βίντεο.

Το δείγμα συμπλήρωσης είναι ως εξής:

<p><img src="https://cdn.acedata.cloud/tx80pu.png" width="500" className="m-auto" /></p>

Ο αντίστοιχος κώδικας:

```python
import requests

url = "https://api.acedata.cloud/luma/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "start_image_url": "https://cdn.acedata.cloud/r9vsv9.png",
    "action": "generate",
    "prompt": "Astronauts shuttle from space to volcano"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Λειτουργίες επέκτασης βίντεο

Αν θέλετε να συνεχίσετε τη δημιουργία του παραγόμενου βίντεο, μπορείτε να ρυθμίσετε την παράμετρο `action` σε `extend` και να εισάγετε το ID ή το σύνδεσμο του βίντεο που θέλετε να συνεχίσετε, το ID και ο σύνδεσμος του βίντεο αποκτώνται με βάση τη βασική χρήση, όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/fwknj4.png" width="500" className="m-auto" /></p>

Αυτή τη στιγμή μπορείτε να δείτε ότι το ID του βίντεο είναι:

```
"video_id": "0105c090-03a5-425a-8026-523341cd575b",
"video_url": "https://platform.cdn.acedata.cloud/luma/12a18694-fd4b-47e7-9c50-34f30862cff6.mp4"
```

> Σημειώστε ότι εδώ το `video_id` και το `video_url` είναι το ID και ο σύνδεσμος του παραγόμενου βίντεο. Αν δεν ξέρετε πώς να δημιουργήσετε βίντεο, μπορείτε να ανατρέξετε στη βασική χρήση παραπάνω για να δημιουργήσετε βίντεο.

Για να συνεχίσετε τη δημιουργία του βίντεο, πρέπει να ανεβάσετε το σύνδεσμο ή το ID του βίντεο. Ακολουθεί η επίδειξη της χρήσης του ID του βίντεο για επέκταση, στη συνέχεια πρέπει να συμπληρώσουμε τις λέξεις-κλειδιά για να προσαρμόσουμε τη δημιουργία του βίντεο, ώστε να καθορίσουμε τα εξής περιεχόμενα:

- action: Αυτή τη στιγμή η συμπεριφορά επέκτασης του βίντεο, εδώ θα είναι `extend`.
- prompt: Οι λέξεις-κλειδιά που χρειάζονται για την επέκταση του βίντεο.
- video_url: Ο σύνδεσμος του βίντεο που χρειάζεται για την επέκταση.
- video_id: Το μοναδικό ID του βίντεο που χρειάζεται για την επέκταση.
- end_image_url: Ο σύνδεσμος της εικόνας της τελευταίας καρέ που μπορεί να καθοριστεί για την επέκταση, προαιρετική παράμετρος.

## Ασύγχρονη κλήση επιστροφής

Δεδομένου ότι η δημιουργία βίντεο από το Luma διαρκεί σχετικά μεγάλο χρονικό διάστημα, περίπου 1-2 λεπτά, αν η API δεν απαντά για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων του συστήματος, γι' αυτό η API παρέχει επίσης υποστήριξη για ασύγχρονη κλήση επιστροφής.
整体流程 είναι: Ο πελάτης ξεκινά το αίτημα, προσδιορίζοντας επιπλέον ένα πεδίο `callback_url`. Μετά την εκκίνηση του API αιτήματος, το API επιστρέφει αμέσως ένα αποτέλεσμα που περιλαμβάνει μια πληροφορία πεδίου `task_id`, που αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα της μουσικής θα αποσταλεί στον καθορισμένο `callback_url` του πελάτη με τη μορφή POST JSON, το οποίο περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε αυτό μέσω ενός παραδείγματος.

Καταρχάς, το Webhook callback είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα, οι προγραμματιστές θα πρέπει να το αντικαταστήσουν με το URL του HTTP διακομιστή που έχουν δημιουργήσει. Για λόγους ευκολίας, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να αποκτήσετε ένα Webhook URL, όπως φαίνεται στην εικόνα:
