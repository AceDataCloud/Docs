Με τη διεύρυνση της εφαρμογής της AI, διάφορα προγράμματα AI έχουν σταδιακά διαδοθεί. Η AI έχει σταδιακά διεισδύσει σε κάθε πτυχή της εργασίας και της ζωής των ανθρώπων. Και οι κλάδοι που περιλαμβάνει η AI γίνονται όλο και περισσότεροι, από την αρχική συγγραφή, έως την ιατρική και την εκπαίδευση, και τώρα έως τα βίντεο.

Το Luma είναι μια επαγγελματική πλατφόρμα δημιουργίας βίντεο υψηλής ποιότητας, όπου οι χρήστες χρειάζεται μόνο να ανεβάσουν υλικό και μπορούν να δημιουργήσουν αυτόματα βίντεο υψηλής ποιότητας σύμφωνα με διαφορετικά στυλ και εφέ. Αυτή η γεννήτρια βίντεο AI έχει αναπτυχθεί από μέλη ομάδας γνωστών εταιρειών τεχνολογίας, με στόχο να επιτρέπει σε όλους να δημιουργούν εύκολα εξαιρετικά βίντεο χωρίς περίπλοκα εργαλεία επεξεργασίας.

Ωστόσο, το επίσημο Luma δεν παρέχει API, ενώ το AceDataCloud παρέχει ένα σύνολο API για το Luma, προσομοιώνοντας την ενσωμάτωση με το επίσημο Suno, ώστε να μπορούν να δημιουργούνται γρήγορα και εύκολα τα επιθυμητά βίντεο.

## Αίτηση και χρήση

Για να χρησιμοποιήσετε το Luma Videos Generation API, αποκτήστε πρώτα το API Token σας από την [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) και κρατήστε το ως εφεδρικό.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση προσφέρει δωρεάν υπόλοιπο για δωρεάν δοκιμή· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο από την [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Luma Videos Generation API →](https://platform.acedata.cloud/documents/luma-videos)

## Βασική χρήση

Για το βίντεο που θέλετε να δημιουργήσετε, μπορείτε να εισαγάγετε ελεύθερα ένα κείμενο. Για παράδειγμα, αν θέλω να δημιουργήσω ένα βίντεο για αστροναύτες που κινούνται ανάμεσα στο διάστημα και ένα ηφαίστειο, μπορώ να εισαγάγω `Astronauts shuttle from space to volcano`, όπως φαίνεται στην εικόνα:

Κύριες παράμετροι αιτήματος:

- `prompt`: Η προτροπή για τη δημιουργία βίντεο.
- `aspect_ratio`: Η αναλογία πλάτους-ύψους του βίντεο, προεπιλογή 16:9.
- `end_image_url`: Προαιρετικό, καθορίζει το τελικό καρέ.
- `enhancement`: Προαιρετικό, διακόπτης ενίσχυσης ευκρίνειας.
- `loop`: Αν θα δημιουργηθεί βίντεο σε επανάληψη, προεπιλογή false.
- `timeout`: Προαιρετικό, δευτερόλεπτα χρονικού ορίου.
- `callback_url`: Διεύθυνση ασύγχρονης επανάκλησης.
- `async`: Προαιρετικό, όταν οριστεί σε `true`, η διεπαφή επιστρέφει αμέσως το `task_id`, χωρίς να χρειάζεται να παρέχετε `callback_url`, και στη συνέχεια λαμβάνετε το αποτέλεσμα με περιοδικά ερωτήματα μέσω της αντίστοιχης διεπαφής αναζήτησης εργασίας.

Μπορείτε να κάνετε κλικ στο κουμπί «Try» για να δοκιμάσετε απευθείας το API, περιμένετε 1-2 λεπτά και το αποτέλεσμα είναι το εξής:

Μπορούμε να δούμε ότι σε αυτό το σημείο έχουμε λάβει τις σχετικές πληροφορίες αυτού του βίντεο, συμπεριλαμβανομένων του ID βίντεο, του συνδέσμου βίντεο, του εξωφύλλου βίντεο και άλλου περιεχομένου.

Η περιγραφή των πεδίων είναι η εξής:

- success: Αν η δημιουργία ήταν επιτυχής· αν είναι επιτυχής, είναι `true`, διαφορετικά είναι `false`
- task_id: Το μοναδικό ID της εργασίας δημιουργίας βίντεο εδώ
- video_id: Το μοναδικό ID του βίντεο που παράγεται από την εργασία δημιουργίας βίντεο εδώ
- prompt: Οι λέξεις-κλειδιά της εργασίας δημιουργίας βίντεο εδώ
- video_url: Ο σύνδεσμος του αποτελέσματος βίντεο της εργασίας δημιουργίας βίντεο εδώ
- video_height: Το ύψος της εικόνας εξωφύλλου του βίντεο μετά τη δημιουργία
- video_width: Το πλάτος της εικόνας εξωφύλλου του βίντεο μετά τη δημιουργία
- state: Η κατάσταση της εργασίας δημιουργίας βίντεο εδώ· αν η εργασία ολοκληρωθεί, είναι `completed`.
- thumbnail_url: Ο σύνδεσμος της εικόνας εξωφύλλου του βίντεο μετά τη δημιουργία
- thumbnail_width: Το πλάτος της εικόνας εξωφύλλου του βίντεο μετά τη δημιουργία
- thumbnail_height: Το ύψος της εικόνας εξωφύλλου του βίντεο μετά τη δημιουργία

## Δημιουργία με προσαρμοσμένα αρχικά και τελικά καρέ

Αν θέλετε να δημιουργήσετε ένα βίντεο μέσω προσαρμοσμένων αρχικών και τελικών καρέ του βίντεο, μπορείτε να εισαγάγετε τους συνδέσμους εικόνων των αρχικών και τελικών καρέ:

Σε αυτήν την περίπτωση, στο πεδίο `start_image_url` του αρχικού καρέ του βίντεο μπορείτε να περάσετε την παρακάτω εικόνα ως αρχικό καρέ του βίντεο:

![Αρχικό καρέ](https://cdn.acedata.cloud/r9vsv9.png)

Στη συνέχεια, για να δημιουργήσουμε προσαρμοσμένα ένα βίντεο βάσει των αρχικών και τελικών καρέ και των λέξεων-κλειδιών, μπορούμε να καθορίσουμε το ακόλουθο περιεχόμενο:

- action: Η ενέργεια της εργασίας δημιουργίας βίντεο, συνήθως είναι η κανονική δημιουργία `generate` και η εκτεταμένη δημιουργία `extend`, με προεπιλογή `generate`.
- start_image_url: Καθορίζει το αρχικό καρέ του παραγόμενου βίντεο.
- end_image_url: Καθορίζει το τελικό καρέ του παραγόμενου βίντεο.
- prompt: Το περιεχόμενο λέξεων-κλειδιών για τη δημιουργία του βίντεο.

Ο αντίστοιχος κώδικας:

```python
import requests

url = "https://api.acedata.cloud/luma/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "start_image_url": "https://cdn.acedata.cloud/r9vsv9.png",
    "action": "generate",
    "prompt": "Astronauts shuttle from space to volcano"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Λειτουργία επέκτασης βίντεο

Αν θέλετε να συνεχίσετε να δημιουργείτε το παραγόμενο βίντεο, μπορείτε να ορίσετε την παράμετρο `action` σε `extend` και να εισαγάγετε το ID ή τον σύνδεσμο του βίντεο που χρειάζεται να συνεχίσει να δημιουργείται. Η λήψη του ID και του συνδέσμου του βίντεο γίνεται σύμφωνα με τη βασική χρήση, όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/fwknj4.png" width="500" className="m-auto" /></p>

Σε αυτό το σημείο μπορείτε να δείτε ότι το ID του βίντεο είναι:

```
"video_id": "0105c090-03a5-425a-8026-523341cd575b",
"video_url": "https://platform.cdn.acedata.cloud/luma/12a18694-fd4b-47e7-9c50-34f30862cff6.mp4"
```

> Σημείωση: Εδώ, το `video_id` και το `video_url` στο βίντεο είναι το ID και ο σύνδεσμος του βίντεο μετά τη δημιουργία. Αν δεν γνωρίζετε πώς να δημιουργήσετε βίντεο, μπορείτε να ανατρέξετε στη βασική χρήση παραπάνω για να δημιουργήσετε βίντεο.

Για να συνεχίσετε τη δημιουργία βίντεο, πρέπει να μεταφορτώσετε τον σύνδεσμο ή το ID του βίντεο. Παρακάτω παρουσιάζεται η χρήση του ID βίντεο για επέκταση. Στη συνέχεια πρέπει να συμπληρώσουμε λέξεις-κλειδιά για προσαρμοσμένη δημιουργία βίντεο και μπορούμε να ορίσουμε το ακόλουθο περιεχόμενο:

- action：Η ενέργεια επέκτασης του βίντεο αυτή τη στιγμή, εδώ θα πρέπει να είναι `extend` .
- prompt：Οι λέξεις-κλειδιά του βίντεο που χρειάζεται να επεκταθεί.
- video_url：Ο σύνδεσμος του βίντεο που χρειάζεται να επεκταθεί και να δημιουργηθεί.
- video_id：Το μοναδικό ID του βίντεο που χρειάζεται να επεκταθεί και να δημιουργηθεί.
- end_image_url：Ο σύνδεσμος εικόνας του τελευταίου καρέ που μπορεί να οριστεί για το επεκτεινόμενο παραγόμενο βίντεο, προαιρετική παράμετρος.

Το παράδειγμα συμπλήρωσης είναι το ακόλουθο:

<p><img src="https://cdn.acedata.cloud/vv0rxk.png" width="500" className="m-auto" /></p>

<p><img src="https://cdn.acedata.cloud/woapxi.png" width="500" className="m-auto" /></p>

Ο αντίστοιχος κώδικας Python:

```python
import requests

url = "https://api.acedata.cloud/luma/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "video_id": "0105c090-03a5-425a-8026-523341cd575b",

}

response = requests.post(url, json=payload, headers=headers)

```

## Ασύγχρονη επανάκληση

Επειδή ο χρόνος δημιουργίας βίντεο από το Luma είναι σχετικά μεγάλος, απαιτώντας περίπου 1-2 λεπτά, εάν το API δεν ανταποκρίνεται για μεγάλο χρονικό διάστημα, το αίτημα HTTP θα διατηρεί συνεχώς τη σύνδεση, οδηγώντας σε πρόσθετη κατανάλωση πόρων συστήματος, επομένως αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη επανάκληση.
Η συνολική διαδικασία είναι: όταν ο πελάτης ξεκινά ένα αίτημα, καθορίζει επιπλέον ένα πεδίο `callback_url`. Αφού ο πελάτης ξεκινήσει ένα αίτημα API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα, το οποίο περιλαμβάνει πληροφορίες πεδίου `task_id`, που αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα της δημιουργίας μουσικής θα αποσταλεί με τη μορφή POST JSON στο `callback_url` που έχει καθορίσει ο πελάτης, το οποίο περιλαμβάνει επίσης το πεδίο `task_id`, ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Παρακάτω θα κατανοήσουμε μέσω ενός παραδείγματος πώς ακριβώς γίνεται η διαδικασία.

Αρχικά, το Webhook callback είναι μια υπηρεσία που μπορεί να λάβει αιτήματα HTTP, και ο προγραμματιστής θα πρέπει να το αντικαταστήσει με το URL του HTTP διακομιστή που έχει δημιουργήσει ο ίδιος. Εδώ, για ευκολία επίδειξης, χρησιμοποιείται ένας δημόσιος ιστότοπος δείγματος Webhook https://webhook.site/· ανοίγοντας αυτόν τον ιστότοπο μπορείτε να λάβετε ένα Webhook URL, όπως φαίνεται στην εικόνα:
