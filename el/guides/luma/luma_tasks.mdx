Η κύρια λειτουργία του Luma Tasks API είναι να ελέγχει την κατάσταση εκτέλεσης ενός έργου μέσω της εισαγωγής του ID έργου που έχει παραχθεί από το Luma Videos Generation API.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες διασύνδεσης του Luma Tasks API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του Luma Tasks API, μπορείτε εύκολα να ελέγξετε την κατάσταση εκτέλεσης των έργων του Luma Videos Generation API.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Luma Videos Generation API, πρώτα επισκεφθείτε την [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν. Όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό σας υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Luma Videos Generation API →](https://platform.acedata.cloud/documents/luma-videos)

## Παράδειγμα αιτήματος

Το Luma Tasks API μπορεί να χρησιμοποιηθεί για να ελέγξει τα αποτελέσματα του Luma Videos Generation API. Για πληροφορίες σχετικά με το πώς να χρησιμοποιήσετε το Luma Videos Generation API, ανατρέξτε στην τεκμηρίωση [Luma Videos Generation API](https://platform.acedata.cloud/documents/luma-videos-integration).

Θα χρησιμοποιήσουμε ένα παράδειγμα με το ID έργου που επιστρέφει η υπηρεσία Luma Videos Generation API. Ας υποθέσουμε ότι έχουμε ένα ID έργου: 50fc6182-fa86-4c7d-ac12-2fa27ec2f151, και θα δείξουμε πώς να το χρησιμοποιήσουμε περνώντας το ID έργου.

### Ρύθμιση κεφαλίδων αιτήματος και σώματος αιτήματος

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `id`: το ID του έργου που έχει ανέβει.
- `action`: ο τρόπος λειτουργίας του έργου.

### Παράδειγμα κώδικα

Μπορείτε να παρατηρήσετε ότι στη δεξιά πλευρά της σελίδας έχουν παραχθεί αυτόματα διάφοροι κώδικες σε γλώσσες, όπως φαίνεται στην εικόνα:

Ορισμένα παραδείγματα κώδικα είναι τα εξής:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/luma/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "50fc6182-fa86-4c7d-ac12-2fa27ec2f151",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/luma/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "50fc6182-fa86-4c7d-ac12-2fa27ec2f151",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Η επιστρεφόμενη απάντηση περιέχει πολλά πεδία, το πεδίο request είναι το σώμα της αίτησης κατά την εκκίνηση του έργου, ενώ το πεδίο response είναι το σώμα της απάντησης που επιστρέφεται μετά την ολοκλήρωση του έργου, το οποίο είναι σύμφωνο με την αίτηση και την απάντηση του Luma Videos Generation API. Η περιγραφή των πεδίων είναι η εξής.

- `id`, το ID που δημιουργεί αυτό το έργο βίντεο, χρησιμοποιείται για την μοναδική αναγνώριση αυτού του έργου παραγωγής βίντεο.
- `video_id`, η μοναδική αναγνώριση του βίντεο στο έργο που ελέγχεται, χρειάζεται να παρασχεθεί αυτή η παράμετρος όταν απαιτείται να επεκταθεί το βίντεο την επόμενη φορά.
- `request`, οι πληροφορίες της αίτησης στο έργο βίντεο.
- `response`, οι πληροφορίες της απάντησης στο έργο βίντεο.
- `created_at`, η ώρα δημιουργίας του έργου, Unix χρονική σφραγίδα (δευτερόλεπτα, κινητής υποδιαστολής).
- `started_at`, η ώρα έναρξης εκτέλεσης του έργου, Unix χρονική σφραγίδα (δευτερόλεπτα, κινητής υποδιαστολής).
- `finished_at`, η ώρα ολοκλήρωσης του έργου, Unix χρονική σφραγίδα (δευτερόλεπτα, κινητής υποδιαστολής). Το πεδίο αυτό δεν επιστρέφεται αν το έργο δεν έχει ολοκληρωθεί.
- `elapsed`, ο χρόνος εκτέλεσης του έργου, μονάδα σε δευτερόλεπτα (κινητής υποδιαστολής, διατηρεί 3 δεκαδικά ψηφία). Το πεδίο αυτό δεν επιστρέφεται αν το έργο δεν έχει ολοκληρωθεί.

## Σφάλμα Διαχείριση

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
