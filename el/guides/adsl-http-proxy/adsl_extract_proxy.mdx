Αυτό το έγγραφο περιγράφει κυρίως τη διαδικασία χρήσης του ADSL Proxy API, με το οποίο μπορούμε εύκολα να εξάγουμε τη διεύθυνση IP του ADSL και να προσθέσουμε διευθύνσεις IP στη λευκή λίστα του ADSL Proxy.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε την εξαγωγή της διεύθυνσης IP του ADSL και να προσθέσετε διευθύνσεις IP στη λευκή λίστα του ADSL Proxy, μπορείτε πρώτα να επισκεφθείτε τις σελίδες [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/d8426c17-d22c-449a-b6bf-0a7790928e4d) και [ADSL Proxy Whitelist API](https://platform.acedata.cloud/documents/c21534fe-1f62-424b-9b10-a805cb473dd1) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Εξαγωγή της Διεύθυνσης IP του ADSL

Στη συνέχεια, μπορείτε να συμπληρώσετε τα αντίστοιχα περιεχόμενα στη διεπαφή [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/d8426c17-d22c-449a-b6bf-0a7790928e4d), και παρακάτω θα δείξουμε πώς να εξάγετε τη διεύθυνση IP του ADSL.

### Ρύθμιση Κεφαλίδων Αίτησης και Σώματος Αίτησης

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `number`: ο αριθμός των διευθύνσεων IP του ADSL που θα εξαχθούν, προεπιλεγμένο είναι το 1.
- `type`: ο τύπος της διεύθυνσης IP του ADSL που θα εξαχθεί, κυρίως διαχωρίζεται σε `http` και `socks`, προεπιλεγμένο είναι το `http`.
- `province`: η επαρχία στην οποία βρίσκεται η διεύθυνση IP, προεπιλεγμένο είναι τυχαίο.
- `city`: η πόλη στην οποία βρίσκεται η διεύθυνση IP, προεπιλεγμένο είναι τυχαίο.

### Παράδειγμα Κώδικα

Μπορούμε να παρατηρήσουμε ότι στη δεξιά πλευρά της σελίδας έχουν αυτόματα παραχθεί διάφορες γλώσσες κώδικα, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/e2rmr0.png" width="500" class="m-auto"></p>

Ορισμένα παραδείγματα κώδικα είναι τα εξής:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/adsl/extract' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "province": "浙江",
  "city": "温州"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "province": "浙江",
    "city": "温州"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Παράδειγμα Απόκρισης

Αφού η αίτηση είναι επιτυχής, το API θα επιστρέψει πληροφορίες σχετικά με την εικόνα του backend μετά την αλλαγή προσώπου. Για παράδειγμα:

```json
{
  "success": true,
  "data": [
    {
      "ip": "115.219.4.171",
      "port": 23456,
      "proxy": "115.219.4.171:23456",
      "outbound_ip": "115.219.4.171",
      "province": "浙江",
      "city": "温州",
      "expire_at": 1721877364.588,
      "dialed_at": 1721876984.588
    }
  ],
  "trace_id": "406465b0-f086-4a12-87a7-cdf05a3930a1"
}
```

Μπορούμε να δούμε ότι το αποτέλεσμα περιέχει ένα πεδίο `data`, το οποίο περιλαμβάνει λεπτομέρειες για την εργασία εξαγωγής IP, οι άλλες πληροφορίες φαίνονται στην παρακάτω εικόνα:

- `success`, η κατάσταση του αποτελέσματος της εργασίας εξαγωγής ADSL IP.
- `data`, λεπτομέρειες για την εξαγωγή ADSL IP.

Από το `data` μπορούμε να δούμε σαφώς τις λεπτομέρειες αυτού του IP, οι κύριες πληροφορίες περιλαμβάνουν το `ip`, το οποίο δείχνει τη διεύθυνση IP που εξήχθη, οι άλλες πληροφορίες είναι οι εξής:

- `ip`, η διεύθυνση IP που εξήχθη από το ADSL.
- `port`, οι πληροφορίες θύρας IP που εξήχθη από το ADSL.
- `proxy`, οι πλήρεις πληροφορίες του proxy της IP που εξήχθη από το ADSL.
- `province`, η επαρχία στην οποία ανήκει η IP που εξήχθη από το ADSL.
- `city`, η πόλη στην οποία ανήκει η IP που εξήχθη από το ADSL.

Μπορούμε να δούμε ότι μπορούμε εύκολα να χρησιμοποιήσουμε το παραπάνω `proxy` για να προχωρήσουμε στην επόμενη εργασία IP proxy.

Πρώτα, πριν χρησιμοποιήσουμε το IP proxy, πρέπει να προσθέσουμε τη δική μας διεύθυνση IP δικτύου (μέθοδος για να αποκτήσουμε τη διεύθυνση IP του τοπικού δικτύου, παρακαλώ αναζητήστε την) στη λευκή λίστα παρακάτω, στη συνέχεια θα μιλήσουμε για το πώς να χρησιμοποιήσουμε το IP proxy:

### Χρήση Proxy

> Σημείωση: Πριν χρησιμοποιήσετε το εξαγόμενο proxy IP, βεβαιωθείτε ότι έχετε προσθέσει τη λευκή λίστα IP, αλλιώς δεν θα μπορείτε να το χρησιμοποιήσετε. Για πληροφορίες σχετικά με την προσθήκη στη λευκή λίστα, παρακαλώ ανατρέξτε στο παρακάτω περιεχόμενο.

Παράδειγμα κώδικα Curl:

```shell
curl -x 115.219.4.171:23456 myip.vpsnb.net # http proxy
curl --socks5 115.219.3.54:23457 myip.vpsnb.net # socks proxy
```

```python
def test_http_proxy(proxy):
    try:
        start_time = time.time()
        response = requests.get(
            'http://httpbin.org/ip', proxies={'http': proxy, 'https': proxy}, timeout=100)
        elapsed_time = time.time() - start_time
        print(response)
        if response.status_code == 200:
            print(f"HTTP Proxy {proxy} success. time: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"HTTP Proxy {proxy} failed. code: {response.status_code}")
    except Exception as e:
        print(f"HTTP Proxy {proxy} failed: {str(e)}")

def test_socks_proxy(proxy):
    proxy_parts = proxy.split(':')
    if len(proxy_parts) != 2:
        print(f"SOCKS failed: {proxy}")
        return

    host, port = proxy_parts
    port = int(port)

    try:
        start_time = time.time()
        socks.set_default_proxy(socks.SOCKS5, host, port)
        socket.socket = socks.socksocket
        response = requests.get('http://httpbin.org/ip', timeout=10)
        elapsed_time = time.time() - start_time

        if response.status_code == 200:
            print(f"SOCKS Proxy {proxy} success. time: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"SOCKS Proxy {proxy} failed. code: {response.status_code}")
    except Exception as e:
        print(f"SOCKS Proxy {proxy} failed: {str(e)}")
    finally:
        socks.set_default_proxy()
        socket.socket = socket.socket

if __name__ == "__main__":
    # HTTP Proxy
    http_proxy = "http://115.219.4.171:23456"
    test_http_proxy(http_proxy)

    # SOCKS Proxy
    socks_proxy = "115.219.3.54:23457"
    test_socks_proxy(socks_proxy)

```

## Προσθήκη IP Λευκής Λίστας

接下来就可以在界面上填写对应的内容，如图所示：

<p><img src="https://cdn.acedata.cloud/wz4obo.png" width="500" class="m-auto"></p>

在第一次使用该接口时，我们至少需要填写三个内容，一个是 `authorization`，直接在下拉列表里面选择即可。另一个参数是 `ip`， `ip` 就是我们需要使用上文提取到的 IP 代理的本机网络地址。最后一个参数是`action`，`action` 是我们对白名单进行的操作，这里是对白名单进行添加的操作。

同时您可以注意到右侧有对应的调用代码生成，您可以复制代码直接运行，也可以直接点击「Try」按钮进行测试。

<p><img src="https://cdn.acedata.cloud/cs5ib2.png" width="500" class="m-auto"></p>

Python 样例调用代码：

```python
import requests

url = "https://api.acedata.cloud/adsl/whitelist"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "ip": "113.112.122.132",
    "action": "add"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

调用之后，我们发现返回结果如下：

```json
{
  "success": true
}
```

返回结果一共有一个字段，介绍如下：

- `success `，此处操作结果的状态。

其中 `success` 是包含了操作结果的状态，我们可以看到将 IP `113.112.122.132` 已经成功添加到白名单内。
