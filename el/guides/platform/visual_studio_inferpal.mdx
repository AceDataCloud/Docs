Inferpal είναι μια επέκταση για Visual Studio 2022/2026, που υποστηρίζει επίσημα τη σύνδεση με υπηρεσίες συμβατές με το OpenAI. Η έκδοση της επέκτασης μπορεί να επηρεάσει την επεξεργασία, τις κλήσεις εργαλείων και την καταγραφή χρήσης. Για πρώτη σύνδεση, παρακαλώ σταθεροποιήστε την έκδοση και ολοκληρώστε την ελάχιστη επαλήθευση παρακάτω.

## Ρύθμιση

1. Εγκαταστήστε το Inferpal από το Visual Studio Marketplace ή το επίσημο αποθετήριο.
2. Ανοίξτε τις **Ρυθμίσεις → Σύνδεση** του Inferpal.
3. Επιλέξτε Provider OpenAI-compatible.
4. Συμπληρώστε το Base URL με `https://api.acedata.cloud/v1`.
5. Συμπληρώστε το API Key με το Ace Data Cloud API Token σας.
6. Συμπληρώστε το Model με το ακριβές ID μοντέλου που υποστηρίζει Chat Completions στον κατάλογο μοντέλων.
7. Αποθηκεύστε και στείλτε `Reply only OK`, στη συνέχεια εκτελέστε ξανά το αίτημα που περιλαμβάνει το πλαίσιο κώδικα.

## Τρέχοντα όρια

- Αυτός ο οδηγός καλύπτει μόνο το Inferpal και δεν αντιπροσωπεύει την υποστήριξη των ενσωματωμένων Copilot ή άλλων επεκτάσεων του Visual Studio για τα ίδια πεδία.
- Διαφορετικές εκδόσεις μπορεί να προσθέτουν αυτόματα διαδρομές στο Base URL. Εάν αποτύχει το αίτημα, παρακαλώ ελέγξτε πρώτα αν το τελικό αίτημα βρίσκεται στο Chat Completions endpoint.
- Δεν δεσμευόμαστε ότι όλα τα μοντέλα επεξεργασίας, συμπλήρωσης ή κλήσεων εργαλείων θα είναι διαθέσιμα πριν ολοκληρωθεί η σταθεροποίηση της έκδοσης E2E.
