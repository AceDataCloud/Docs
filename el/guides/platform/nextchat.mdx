Το [NextChat](https://github.com/ChatGPTNextWeb/NextChat) (πρώην ChatGPT-Next-Web) είναι ένας ανοιχτού κώδικα πελάτης AI, που μπορεί να αναπτυχθεί σε Vercel, Cloudflare ή Docker. Υποστηρίζει προσαρμοσμένα συμβατά με OpenAI endpoints, επομένως μπορεί να συνδεθεί με το Ace Data Cloud. Αυτό το άρθρο παρουσιάζει τη διαδικασία διαμόρφωσης.

## Διαδικασία αίτησης

Για να συνδέσετε το Ace Data Cloud στο NextChat, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications), αποκτήστε το API Token σας και κρατήστε το για μελλοντική χρήση.

![Λήψη Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά τη σύνδεση ή εγγραφή θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, παρέχεται δωρεάν πίστωση, ώστε να μπορείτε να δοκιμάσετε δωρεάν τις υπηρεσίες μοντέλων του Ace Data Cloud.

## Λήψη του NextChat

Μπορείτε να χρησιμοποιήσετε την έκδοση για υπολογιστή (λήψη `.exe` / `.dmg` / AppImage από τη [σελίδα Releases](https://github.com/ChatGPTNextWeb/NextChat/releases)), την [online έκδοση Web](https://app.nextchat.club/), ή να το αναπτύξετε μόνοι σας σε Vercel / Cloudflare / Docker (δείτε την προχωρημένη ενότητα παρακάτω).

## Διαμόρφωση του Ace Data Cloud

Εκκινήστε το NextChat και μεταβείτε στις **Ρυθμίσεις → Υπηρεσία μοντέλων**:

| Πεδίο          | Τιμή                           | Περιγραφή                              |
| ----------- | --------------------------- | ------------------------------- |
| Πάροχος υπηρεσίας μοντέλων       | `OpenAI`                    | Χρήση πρωτοκόλλου συμβατού με OpenAI                  |
| Διεύθυνση διεπαφής OpenAI | `https://api.acedata.cloud` | Συμπληρώστε μόνο το ριζικό domain, **χωρίς `/openai`, χωρίς `/v1`** |
| API Key     | Το Ace Data Cloud Token σας     | Token που αντιγράφηκε από την κονσόλα                    |

![Διεπαφή διαμόρφωσης NextChat Ace Data Cloud](https://cdn.acedata.cloud/47e0aed34570.png)

Το NextChat θα προσθέσει αυτόματα το `/v1/chat/completions` μετά τη διεύθυνση διεπαφής, επομένως αρκεί να συμπληρώσετε μόνο το ριζικό domain:

| Διεύθυνση διεπαφής                                  | Πραγματικό αίτημα                                                      | Αποτέλεσμα                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | Σωστό                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (δεν υπάρχει `/v1` κάτω από το `/openai`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

Στο πεδίο «Προσαρμοσμένα ονόματα μοντέλων», συμπληρώστε τα μοντέλα διαχωρισμένα με αγγλικά κόμματα. Το NextChat υποστηρίζει ειδική σύνταξη: το `+όνομα_μοντέλου` προσθέτει, το `-όνομα_μοντέλου` αποκρύπτει, το `όνομα_μοντέλου=όνομα_εμφάνισης` προσαρμόζει το όνομα εμφάνισης, και το `-all` αποκρύπτει πρώτα όλα. Η προτεινόμενη πιο καθαρή μορφή είναι:

```text
-all,+MODEL_ID=όνομα εμφάνισης
```

## Επιλογή μοντέλου

Ο κατάλογος μοντέλων θα ενημερώνεται συνεχώς. Δώστε προτεραιότητα στη λίστα μοντέλων που φορτώνεται αυτόματα από τον πελάτη· όταν χρειάζεται χειροκίνητη συμπλήρωση, ζητήστε πρώτα `GET https://api.acedata.cloud/v1/models` για να λάβετε το τρέχον ID μοντέλου και, στη συνέχεια, επιλέξτε σύμφωνα με τις δυνατότητες περιβάλλοντος, εικόνων και κλήσεων εργαλείων που υποστηρίζει ο πελάτης.

## Επαλήθευση σύνδεσης

Εάν δεν είστε βέβαιοι αν το πρόβλημα βρίσκεται στο NextChat ή στο δίκτυο, μπορείτε πρώτα να χρησιμοποιήσετε απευθείας curl για να επαληθεύσετε το endpoint (αντικαταστήστε το `{token}` με το Token σας):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Η επιστροφή ενός αντικειμένου `chat.completion` συμβατού με OpenAI σημαίνει ότι τόσο το Token όσο και το endpoint είναι έτοιμα· εάν επιστραφεί `HTTP 403 used_up`, αυτό σημαίνει ότι το Token είναι έγκυρο αλλά το υπόλοιπο δεν επαρκεί, και μπορείτε να επαναφορτίσετε στην [κονσόλα](https://platform.acedata.cloud/console/applications).

## Προχωρημένα: ανάπτυξη με ένα κλικ στο δικό σας domain

Το NextChat υποστηρίζει την ανάπτυξη ενός δικού σας ιστότοπου AI. Με παράδειγμα το Docker (αντικαταστήστε το `{token}` με το Token σας):

```bash
docker run -d \
  --name nextchat \
  -p 3000:3000 \
  -e OPENAI_API_KEY={token} \
  -e BASE_URL=https://api.acedata.cloud \
  -e CODE=your-password \
  -e CUSTOM_MODELS="-all,+MODEL_ID=显示名称" \
  yidadaa/chatgpt-next-web
```

Κατά την ανάπτυξη σε Vercel / Cloudflare, αρκεί να διαμορφώσετε στις μεταβλητές περιβάλλοντος του έργου τα ίδια `OPENAI_API_KEY`, `BASE_URL`, `CODE`, `CUSTOM_MODELS`. Το `CODE` υποστηρίζει πολλαπλούς κωδικούς πρόσβασης διαχωρισμένους με αγγλικά κόμματα, διευκολύνοντας τη στατιστική χρήσης ανά άτομο. Για την πλήρη περιγραφή των παραπάνω μεταβλητών περιβάλλοντος (προεπιλογή `BASE_URL`: `https://api.openai.com`, και σύνταξη `+/-/=/-all/+all` του `CUSTOM_MODELS`), ανατρέξτε στο [επίσημο README του NextChat](https://github.com/ChatGPTNextWeb/NextChat#environment-variables).

## Συχνές ερωτήσεις

### Εμφανίζεται 404 Not Found

Συνήθως η διεύθυνση διεπαφής έχει γραφτεί ως `.../openai` ή `.../openai/v1`. Αλλάξτε την σε `https://api.acedata.cloud`, ώστε το NextChat να προσθέσει μόνο του το `/v1/chat/completions`.

### Το μοντέλο που προστέθηκε δεν εμφανίζεται στην αναπτυσσόμενη λίστα μοντέλων

Ελέγξτε τη μορφή του `CUSTOM_MODELS`: κάθε μοντέλο πρέπει να έχει `+` μπροστά του· εάν χρησιμοποιήσατε `-all`, βεβαιωθείτε ότι στη συνέχεια προσθέσατε ξανά τα απαιτούμενα μοντέλα με `+`.

### Εμφανίζεται 401 Unauthorized

Επιβεβαιώστε ότι στο API Key έχετε επικολλήσει το Token του Ace Data Cloud (χωρίς το πρόθεμα `Bearer`, χωρίς επιπλέον κενά) και ότι το υπόλοιπο της αντίστοιχης εφαρμογής είναι επαρκές.
