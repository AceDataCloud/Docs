Ερωτηθείτε για τις λεπτομέρειες κλήσεων επιχειρησιακών API του τρέχοντος λογαριασμού των τελευταίων 60 ημερών, κατάλληλο για επαλήθευση χρεώσεων, εντοπισμό αποτυχημένων αιτημάτων, καθώς και διερεύνηση προβλημάτων ανά υπηρεσία, Application, API ή διαπιστευτήριο.

> Αυτή η σελίδα ερωτά τα αρχεία κλήσεων του ίδιου του λογαριασμού. Εάν θέλετε μόνο να δείτε τα δημόσια στατιστικά κλήσεων ενός API σε ολόκληρη την πλατφόρμα, χρησιμοποιήστε τα [Στατιστικά κλήσεων API](https://platform.acedata.cloud/documents/platform-api-usage).

## Προετοιμασία

### 1. Δημιουργία διακριτικού λογαριασμού

Αυτή η διεπαφή ανήκει στο API διαχείρισης πλατφόρμας και απαιτεί τη χρήση **Account Token (διακριτικό λογαριασμού)**:

1. Συνδεθείτε στην [πλατφόρμα AceDataCloud](https://platform.acedata.cloud).
2. Ανοίξτε την [κονσόλα Account Token](https://platform.acedata.cloud/console/platform-tokens).
3. Κάντε κλικ στο «Δημιουργία» και αποθηκεύστε αμέσως το διακριτικό σε διαχειριστή κωδικών πρόσβασης ή Secret Manager.

Για πλήρεις οδηγίες δείτε τη [Διαχείριση διακριτικών λογαριασμού πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-token). Το διακριτικό λογαριασμού χρησιμοποιείται για `platform.acedata.cloud/api/v1/**`· για την κλήση επιχειρησιακών διεπαφών `api.acedata.cloud/**` χρησιμοποιούνται διαπιστευτήρια API (Credential), και τα δύο δεν μπορούν να χρησιμοποιηθούν εναλλακτικά.

```shell
export PLATFORM_TOKEN='你的账户令牌'
```

Μην γράφετε το διακριτικό σε κώδικα frontend, αρχεία καταγραφής ή δημόσια αποθετήρια· εάν διαρρεύσει, διαγράψτε το αμέσως από την κονσόλα και δημιουργήστε νέο.

### 2. Προετοιμασία ID φίλτρων (προαιρετικό)

Μπορείτε να δείτε τα αρχεία που ο τρέχων λογαριασμός έχει δικαίωμα να δει χωρίς να περάσετε συνθήκες φίλτρου. Όταν χρειάζεται να περιορίσετε το εύρος:

- `application_id`: αποκτήστε το από τη [λίστα αιτήσεων υπηρεσίας](https://platform.acedata.cloud/documents/platform-application-list)·
- `credential_id`: αποκτήστε το από τη [λίστα διαπιστευτηρίων API](https://platform.acedata.cloud/documents/platform-credential-list)·
- `api_id`: αποκτήστε το από τη [λίστα API](https://platform.acedata.cloud/documents/platform-api-list)·
- `service_id`: αποκτήστε το από τη [λίστα υπηρεσιών](https://platform.acedata.cloud/documents/platform-service-list).

Οι απλοί χρήστες δεν χρειάζεται να περάσουν `user_id`· εάν περαστεί ρητά, πρέπει να συμφωνεί με τον τρέχοντα λογαριασμό, διαφορετικά επιστρέφεται `403`. Οι διαχειριστές μπορούν να χρησιμοποιήσουν αυτή την παράμετρο για φιλτράρισμα μεταξύ λογαριασμών.

## Επισκόπηση διεπαφής

| Στοιχείο           | Περιεχόμενο                                               |
| ------------------ | -------------------------------------------------------- |
| Μέθοδος            | `GET`                                                    |
| URL                | `https://platform.acedata.cloud/api/v1/usage/apis/`      |
| Πιστοποίηση        | `Authorization: Bearer ${PLATFORM_TOKEN}`                |
| OAuth Scope        | `usage:read`（`platform:read` / `platform` μπορεί να περιλαμβάνει επεκτατικά） |
| Σελιδοποίηση       | `count` + `items`, 10 εγγραφές ανά σελίδα από προεπιλογή |

## Εύρος ερωτήματος

| `perspective` | Σημασία                                                     |
| ------------- | ---------------------------------------------------------- |
| `both`        | Προεπιλεγμένη τιμή· επιστρέφει εγγραφές που πληρώθηκαν ή κλήθηκαν πραγματικά από τον τρέχοντα λογαριασμό |
| `billing`     | Επιστρέφει μόνο εγγραφές που πληρώθηκαν από τον τρέχοντα λογαριασμό |
| `actor`       | Επιστρέφει μόνο εγγραφές που κλήθηκαν πραγματικά από τον τρέχοντα λογαριασμό |

## Παράμετροι ερωτήματος

| Παράμετρος         | Τύπος      | Υποχρεωτικό | Προεπιλογή     | Περιγραφή                                      |
| ------------------ | ---------- | ----------- | --------------- | ---------------------------------------------- |
| `perspective`     | string     | Όχι         | `both`          | `billing`, `actor` ή `both`                    |
| `user_id`         | UUID       | Όχι         | —               | Μόνο οι διαχειριστές φιλτράρουν ανά χρήστη· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `service_id`      | UUID       | Όχι         | —               | Φιλτράρισμα ανά υπηρεσία· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `application_id`  | UUID       | Όχι         | —               | Φιλτράρισμα ανά Application· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `api_id`          | UUID       | Όχι         | —               | Φιλτράρισμα ανά API· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `credential_id`   | UUID       | Όχι         | —               | Φιλτράρισμα ανά διαπιστευτήριο API· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `status_code`     | integer    | Όχι         | —               | Φιλτράρισμα ανά κωδικό κατάστασης HTTP· υποστηρίζει επαναλαμβανόμενες τιμές ή τιμές διαχωρισμένες με κόμμα |
| `created_at_from` | datetime   | Όχι         | —               | Κάτω όριο χρόνου δημιουργίας, ISO 8601         |
| `created_at_to`   | datetime   | Όχι         | —               | Άνω όριο χρόνου δημιουργίας, ISO 8601          |
| `limit`           | integer    | Όχι         | 10              | Αριθμός εγγραφών ανά σελίδα, μέγιστο 100       |
| `offset`          | integer    | Όχι         | 0               | Μετατόπιση σελιδοποίησης                        |
| `ordering`        | string     | Όχι         | `-created_at`   | Φθίνουσα σειρά κατά χρόνο δημιουργίας          |

Όταν ο χρόνος αιτήματος είναι προγενέστερος από τις τελευταίες 60 ημέρες, η διεπαφή επιστρέφει σφάλμα επικύρωσης πεδίου `400`, υποδεικνύοντας ότι οι πλήρεις λεπτομέρειες κλήσεων διατηρούνται μόνο για 60 ημέρες.

## Παραδείγματα αιτημάτων

Ερώτημα για τις τελευταίες 100 εγγραφές:

```shell
curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/' \
  --data-urlencode 'perspective=both' \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=-created_at' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Φιλτράρισμα κατά χρόνο, Application και κατάσταση αποτυχίας:

```shell
export APPLICATION_ID='你的 Application ID'

curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'created_at_from=2026-09-01T00:00:00Z' \
  --data-urlencode 'created_at_to=2026-09-02T00:00:00Z' \
  --data-urlencode 'status_code=500' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Παράδειγμα σελιδοποίησης Python:

```python
import os
import requests

url = "https://platform.acedata.cloud/api/v1/usage/apis/"
headers = {"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"}
params = {"perspective": "both", "limit": 100, "offset": 0}

response = requests.get(url, headers=headers, params=params, timeout=30)
response.raise_for_status()
data = response.json()

for usage in data["items"]:
    print(usage["created_at"], usage["status_code"], usage["deducted_amount"], usage["trace_id"])

if params["offset"] + len(data["items"]) < data["count"]:
    params["offset"] += len(data["items"])
```

## Κύρια πεδία

| Πεδίο                            | Περιγραφή                                  |
| -------------------------------- | ------------------------------------------ |
| `user_id`                        | Ο λογαριασμός που επιβαρύνεται για αυτή τη χρέωση |
| `actor_user_id`                  | Ο λογαριασμός που πραγματικά ξεκίνησε την κλήση· μπορεί να διαφέρει από το `user_id` όταν εξουσιοδοτείται άλλος να χρησιμοποιεί τα διαπιστευτήρια |
| `used_amount`                    | Η χρήση αυτής της κλήσης που υπολογίζεται σύμφωνα με τους αρχικούς κανόνες |
| `original_amount`                | Η αρχική χρήση πριν από την εφαρμογή έκπτωσης |
| `deducted_amount`                | Το ποσό που τελικά αφαιρείται πραγματικά |
| `remaining_amount`               | Το υπόλοιπο διαθέσιμο ποσό του Application μετά την ολοκλήρωση αυτής της χρέωσης |
| `elapsed`                        | Ο χρόνος κλήσης που καταγράφεται από τον διακομιστή, σε δευτερόλεπτα |
| `trace_id`                       | Το αναγνωριστικό παρακολούθησης που χρησιμοποιείται κατά τη διερεύνηση ενός μεμονωμένου αιτήματος |
| `metadata`                       | Δημόσια μεταδεδομένα· η λίστα δεν επιστρέφει πλήρες περιεχόμενο αιτήματος ή απόκρισης |
| `api` / `service` / `credential` | Σύνοψη των συσχετισμένων αντικειμένων για ευκολότερη εμφάνιση· μπορεί να είναι κενή όταν το συσχετισμένο αντικείμενο δεν υπάρχει πλέον |

Η μονάδα ποσού καθορίζεται από το `service.unit` του αντίστοιχου Application και δεν πρέπει να θεωρείται ως δολάρια από προεπιλογή.

## Σφάλματα και επανειλημμένες προσπάθειες

| HTTP | `error`                   | Σημασία             | Τρόπος χειρισμού                               |
| ---- | ------------------------- | ------------------- | ---------------------------------------------- |
| 400  | Σφάλμα επικύρωσης πεδίου  | Το εύρος ερωτήματος είναι παλαιότερο από την περίοδο διατήρησης 60 ημερών | Προσαρμόστε την ώρα έναρξης εντός των τελευταίων 60 ημερών |
| 401  | `not_authenticated`       | Το διακριτικό λογαριασμού λείπει ή είναι μη έγκυρο | Ελέγξτε το Account Token, μην χρησιμοποιείτε κατά λάθος το επιχειρηματικό Credential |
| 403  | `permission_denied`       | Το αίτημα περιλαμβάνει εγγραφές που δεν έχετε δικαίωμα να δείτε | Αφαιρέστε τις μη εξουσιοδοτημένες συνθήκες φιλτραρίσματος χρηστών |
| 429  | `usage_query_in_progress` | Το ακριβώς ίδιο ερώτημα εξακολουθεί να εκτελείται | Περιμένετε το `Retry-After` και έπειτα επαναλάβετε με εκθετική υποχώρηση |
| 503  | `usage_query_timeout`     | Το ερώτημα υπερβαίνει το ασφαλές χρονικό όριο του διακομιστή | Περιορίστε το χρονικό εύρος ή προσθέστε συνθήκες φιλτραρίσματος πριν την επανάληψη |

Για την ίδια ομάδα παραμέτρων ερωτήματος διατηρείται το πολύ ένα αίτημα σε εξέλιξη. Για ερωτήματα μεγάλου εύρους, προτιμήστε παράθυρα μίας ημέρας ή μικρότερα και μη στοιβάζετε πανομοιότυπα αιτήματα σε σταθερά διαστήματα.
