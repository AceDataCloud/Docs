Αναζητήστε τις λεπτομέρειες των κλήσεων επιχειρησιακού API του τρέχοντος λογαριασμού για τις τελευταίες 60 ημέρες, κατάλληλες για επαλήθευση χρεώσεων, εντοπισμό αποτυχημένων αιτημάτων και διερεύνηση προβλημάτων ανά υπηρεσία, Application, API ή διαπιστευτήριο.

> Αυτή η σελίδα αναζητά το ιστορικό κλήσεων του ίδιου του λογαριασμού. Εάν θέλετε μόνο να δείτε τα δημόσια στατιστικά κλήσεων ενός συγκεκριμένου API σε ολόκληρη την πλατφόρμα, χρησιμοποιήστε τα [Στατιστικά κλήσεων API](https://platform.acedata.cloud/documents/platform-api-usage).

## Εύρος διατήρησης δεδομένων

Τα αρχεία κλήσεων και οι περιλήψεις χρέωσης διατηρούνται για τις τελευταίες 60 ημέρες· τα σώματα αιτημάτων και αποκρίσεων διατηρούνται για τις τελευταίες 30 ημέρες. Τα αρχεία 30–60 ημερών εξακολουθούν να επιτρέπουν την αναζήτηση περιλήψεων όπως trace, κατάσταση, χρόνος, μοντέλο, χρήση και πραγματική χρέωση, αλλά τα `metadata.request` και `metadata.response` στις λεπτομέρειες δεν επιστρέφονται πλέον. Οι περιλήψεις που απαιτούνται για τη συγκεντρωτική παρουσίαση μοντέλων και τα στατιστικά έγκυρων αποτελεσμάτων διατηρούνται πριν από τη λήξη των σωμάτων. Εάν χρειάζεστε μακροχρόνια διατήρηση των σωμάτων, αποθηκεύστε τα εσείς κατά την κλήση.

## Προετοιμασία

### 1. Δημιουργία διακριτικού λογαριασμού

Αυτή η διεπαφή ανήκει στο API διαχείρισης της πλατφόρμας και απαιτεί τη χρήση **Account Token (διακριτικό λογαριασμού)**:

1. Συνδεθείτε στην [πλατφόρμα AceDataCloud](https://platform.acedata.cloud).
2. Ανοίξτε την [κονσόλα Account Token](https://platform.acedata.cloud/console/platform-tokens).
3. Κάντε κλικ στο «Δημιουργία» και αποθηκεύστε αμέσως το διακριτικό σε διαχειριστή κωδικών πρόσβασης ή Secret Manager.

Για πλήρεις οδηγίες, δείτε τη [Διαχείριση διακριτικών λογαριασμού πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-token). Τα διακριτικά λογαριασμού χρησιμοποιούνται για το `platform.acedata.cloud/api/v1/**`· για την κλήση επιχειρησιακών διεπαφών `api.acedata.cloud/**` χρησιμοποιούνται διαπιστευτήρια API (Credential), και τα δύο δεν μπορούν να χρησιμοποιηθούν εναλλακτικά.

```shell
export PLATFORM_TOKEN='你的账户令牌'
```

Μην γράφετε το διακριτικό σε κώδικα frontend, αρχεία καταγραφής ή δημόσια αποθετήρια· εάν διαρρεύσει, διαγράψτε το αμέσως από την κονσόλα και δημιουργήστε νέο.

### 2. Προετοιμασία ID φίλτρων (προαιρετικό)

Μπορείτε να δείτε τα αρχεία που ο τρέχων λογαριασμός έχει δικαίωμα να δει χωρίς να περάσετε συνθήκες φιλτραρίσματος. Όταν χρειάζεται να περιορίσετε το εύρος:

- `application_id`: λάβετε το από τη [λίστα αιτήσεων υπηρεσίας](https://platform.acedata.cloud/documents/platform-application-list)·
- `credential_id`: λάβετε το από τη [λίστα διαπιστευτηρίων API](https://platform.acedata.cloud/documents/platform-credential-list)·
- `api_id`: λάβετε το από τη [λίστα API](https://platform.acedata.cloud/documents/platform-api-list)·
- `service_id`: λάβετε το από τη [λίστα υπηρεσιών](https://platform.acedata.cloud/documents/platform-service-list).

Οι απλοί χρήστες δεν χρειάζεται να περάσουν `user_id`· εάν περαστεί ρητά, πρέπει να αντιστοιχεί στον τρέχοντα λογαριασμό, διαφορετικά επιστρέφεται `403`. Οι διαχειριστές μπορούν να χρησιμοποιήσουν αυτήν την παράμετρο για φιλτράρισμα μεταξύ λογαριασμών.

## Επισκόπηση διεπαφής

| Στοιχείο           | Περιεχόμενο                                                  |
| ----------------- | ----------------------------------------------------------- |
| Μέθοδος           | `GET`                                                       |
| URL               | `https://platform.acedata.cloud/api/v1/usage/apis/`         |
| Αυθεντικοποίηση   | `Authorization: Bearer ${PLATFORM_TOKEN}`                   |
| OAuth Scope       | `usage:read` (τα `platform:read` / `platform` μπορούν να περιλαμβάνουν επεκτατικά) |
| Σελιδοποίηση      | `count` + `items`, 10 εγγραφές ανά σελίδα από προεπιλογή    |

## Εύρος αναζήτησης

| `perspective` | Σημασία                                              |
| ------------- | ---------------------------------------------------- |
| `both`        | Προεπιλεγμένη τιμή· επιστρέφει εγγραφές που χρεώθηκαν ή κλήθηκαν πραγματικά από τον τρέχοντα λογαριασμό |
| `billing`     | Επιστρέφει μόνο εγγραφές που χρεώθηκαν στον τρέχοντα λογαριασμό |
| `actor`       | Επιστρέφει μόνο εγγραφές που κλήθηκαν πραγματικά από τον τρέχοντα λογαριασμό |

## Παράμετροι αναζήτησης

| Παράμετρος          | Τύπος       | Υποχρεωτικό | Προεπιλογή    | Περιγραφή                                      |
| ------------------ | ---------- | ----------- | ------------- | ---------------------------------------------- |
| `perspective`      | string     | Όχι         | `both`        | `billing`, `actor` ή `both`                    |
| `user_id`          | UUID       | Όχι         | —             | Μόνο οι διαχειριστές φιλτράρουν ανά χρήστη· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `service_id`       | UUID       | Όχι         | —             | Φιλτράρισμα ανά υπηρεσία· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `application_id`   | UUID       | Όχι         | —             | Φιλτράρισμα ανά Application· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `api_id`           | UUID       | Όχι         | —             | Φιλτράρισμα ανά API· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `credential_id`    | UUID       | Όχι         | —             | Φιλτράρισμα ανά διαπιστευτήριο API· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `status_code`      | integer    | Όχι         | —             | Φιλτράρισμα ανά κωδικό κατάστασης HTTP· υποστηρίζει επαναλαμβανόμενες τιμές ή τιμές διαχωρισμένες με κόμμα |
| `created_at_from`  | datetime   | Όχι         | —             | Κάτω όριο χρόνου δημιουργίας, ISO 8601         |
| `created_at_to`    | datetime   | Όχι         | —             | Άνω όριο χρόνου δημιουργίας, ISO 8601          |
| `limit`            | integer    | Όχι         | 10            | Αριθμός εγγραφών ανά σελίδα, μέγιστο 100       |
| `offset`           | integer    | Όχι         | 0             | Μετατόπιση σελιδοποίησης                        |
| `ordering`         | string     | Όχι         | `-created_at` | Φθίνουσα σειρά κατά χρόνο δημιουργίας           |

Όταν ο χρόνος αιτήματος είναι παλαιότερος από τις τελευταίες 60 ημέρες, η διεπαφή επιστρέφει σφάλμα επικύρωσης πεδίου `400`, υποδεικνύοντας ότι οι πλήρεις λεπτομέρειες κλήσεων διατηρούνται μόνο για 60 ημέρες.

## Παραδείγματα αιτημάτων

Αναζήτηση των 100 πιο πρόσφατων εγγραφών:

```shell
curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/' \
  --data-urlencode 'perspective=both' \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=-created_at' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Φιλτράρισμα κατά χρόνο, Application και κατάσταση αποτυχίας:

```shell
export APPLICATION_ID='你的 Application ID'

curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'created_at_from=2026-09-01T00:00:00Z' \
  --data-urlencode 'created_at_to=2026-09-02T00:00:00Z' \
  --data-urlencode 'status_code=500' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Παράδειγμα σελιδοποίησης Python:

```python
import os
import requests

url = "https://platform.acedata.cloud/api/v1/usage/apis/"
headers = {"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"}
params = {"perspective": "both", "limit": 100, "offset": 0}

response = requests.get(url, headers=headers, params=params, timeout=30)
response.raise_for_status()
data = response.json()

for usage in data["items"]:
    print(usage["created_at"], usage["status_code"], usage["deducted_amount"], usage["trace_id"])

if params["offset"] + len(data["items"]) < data["count"]:
    params["offset"] += len(data["items"])
```

## Βασικά πεδία

| Πεδίο                            | Περιγραφή                                  |
| -------------------------------- | ----------------------------------- |
| `user_id`                        | Ο λογαριασμός που επιβαρύνεται για αυτήν τη χρέωση                           |
| `actor_user_id`                  | Ο λογαριασμός που πραγματικά ξεκίνησε την κλήση· μπορεί να διαφέρει από το `user_id` όταν εξουσιοδοτείται άλλος να χρησιμοποιεί τα διαπιστευτήρια |
| `used_amount`                    | Η χρήση αυτής της κλήσης που υπολογίζεται σύμφωνα με τους αρχικούς κανόνες                       |
| `original_amount`                | Η αρχική χρήση πριν από την εφαρμογή έκπτωσης                          |
| `deducted_amount`                | Το ποσό που τελικά αφαιρέθηκε                           |
| `remaining_amount`               | Το υπόλοιπο ποσό του Application μετά την ολοκλήρωση αυτής της χρέωσης           |
| `elapsed`                        | Ο χρόνος κλήσης που καταγράφηκε από τον διακομιστή, σε δευτερόλεπτα                     |
| `trace_id`                       | Το αναγνωριστικό παρακολούθησης που χρησιμοποιείται για τη διερεύνηση ενός μεμονωμένου αιτήματος                      |
| `metadata`                       | Δημόσια μεταδεδομένα· η λίστα δεν επιστρέφει το πλήρες περιεχόμενο αιτήματος ή απόκρισης               |
| `api` / `service` / `credential` | Σύνοψη των συσχετισμένων αντικειμένων για εύκολη εμφάνιση· μπορεί να είναι κενή όταν το συσχετισμένο αντικείμενο δεν υπάρχει πλέον           |

Η μονάδα ποσού καθορίζεται από το `service.unit` του αντίστοιχου Application και δεν πρέπει να θεωρείται προεπιλεγμένα ως δολάρια ΗΠΑ.

## Σφάλματα και επαναλήψεις

| HTTP | `error`                   | Σημασία             | Τρόπος χειρισμού                               |
| ---- | ------------------------- | -------------- | ---------------------------------- |
| 400  | Σφάλμα επικύρωσης πεδίου                    | Το εύρος ερωτήματος προηγείται της περιόδου διατήρησης των 60 ημερών | Προσαρμόστε την ώρα έναρξης εντός των τελευταίων 60 ημερών                  |
| 401  | `not_authenticated`       | Το διακριτικό λογαριασμού λείπει ή δεν είναι έγκυρο      | Ελέγξτε το Account Token, μην χρησιμοποιείτε λανθασμένα το επιχειρηματικό Credential |
| 403  | `permission_denied`       | Το αίτημα περιλαμβάνει εγγραφές που δεν έχετε δικαίωμα να δείτε    | Αφαιρέστε μη εξουσιοδοτημένα κριτήρια φιλτραρίσματος χρηστών                       |
| 429  | `usage_query_in_progress` | Ένα απολύτως ίδιο ερώτημα εξακολουθεί να εκτελείται    | Περιμένετε το `Retry-After` και έπειτα επαναλάβετε με εκθετική καθυστέρηση             |
| 503  | `usage_query_timeout`     | Το ερώτημα υπερέβη το ασφαλές χρονικό όριο του διακομιστή    | Περιορίστε το χρονικό εύρος ή προσθέστε κριτήρια φιλτραρίσματος πριν την επανάληψη                   |

Διατηρείτε το πολύ ένα αίτημα σε εξέλιξη για το ίδιο σύνολο παραμέτρων ερωτήματος. Για ερωτήματα μεγάλου εύρους, χρησιμοποιείτε κατά προτεραιότητα παράθυρα μίας ημέρας ή μικρότερα και μην επικαλύπτετε πανομοιότυπα αιτήματα σε σταθερά διαστήματα.
