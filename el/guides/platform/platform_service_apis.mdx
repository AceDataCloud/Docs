Επιστρέφει σελιδοποιημένα τα API που είναι ενεργοποιημένα και δεν έχουν αποσυρθεί αυτήν τη στιγμή για την υπηρεσία μέσω Service UUID. Όταν υπάρχει μόνο alias, καλέστε πρώτα τις [λεπτομέρειες υπηρεσίας](https://platform.acedata.cloud/documents/platform-service-detail) για να αποκτήσετε το `id`.

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                                         |
| --- | ------------------------------------------------------------------- |
| Μέθοδος  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| Πιστοποίηση  | Δημόσιο, δεν απαιτείται διακριτικό λογαριασμού                                                           |
| Σελιδοποίηση  | `count` + `items`                                                   |

## Παράμετροι

| Παράμετρος           | Θέση    | Υποχρεωτικό  | Περιγραφή                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | Ναι   | Service UUID, δεν υποστηρίζεται alias           |
| `limit`      | query | Όχι   | Αριθμός εγγραφών ανά σελίδα, μέγιστο 100                      |
| `offset`     | query | Όχι   | Μετατόπιση σελιδοποίησης                            |
| `ordering`   | query | Όχι   | Έκφραση ταξινόμησης Django· συνιστάται `rank` ή `-rank` |

Η τρέχουσα διεπαφή δεν υποστηρίζει φιλτράρισμα `stage`· έχει ήδη εξαιρέσει τα API `Deprecated`.

```shell
export SERVICE_ID='το Service ID σας'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

Τα στοιχεία της λίστας χρησιμοποιούν την ίδια δομή ευρετηρίου με τη [λίστα API πλατφόρμας](https://platform.acedata.cloud/documents/platform-api-list) και αυτήν τη στιγμή περιλαμβάνουν το `definition`. Όταν χρειάζεστε ένα σταθερό σημείο εισόδου για μεμονωμένο API, συνεχίστε να καλείτε το `/api/v1/apis/{api_id}`.

## Διαχείριση σφαλμάτων

- Η υπηρεσία δεν υπάρχει ή δεν είναι ορατή στον τρέχοντα ιστότοπο: `404`.
- Το `service_id` πρέπει να είναι UUID· το alias δεν αναλύεται σε αυτήν την ενέργεια.
