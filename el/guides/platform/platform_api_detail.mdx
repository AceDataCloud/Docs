Ανακτήστε πλήρεις πληροφορίες για ένα μεμονωμένο API endpoint μέσω του API ID — σε σύγκριση με τη [διεπαφή λίστας](https://platform.acedata.cloud/documents/platform-api-list), περιλαμβάνει επιπλέον τα πεδία `definition` (OpenAPI 3.0 Schema), `service` (λεπτομέρειες της υπηρεσίας στην οποία ανήκει) και `products` (συσχετισμένα προϊόντα).

Κατάλληλο για σενάρια όπως η αυτόματη δημιουργία SDK, η παροχή περιγραφών εργαλείων σε LLM Agent και η δυναμική απόδοση ιστοτόπων τεκμηρίωσης.

> ℹ️ Αυτή η διεπαφή ανήκει στο **API διαχείρισης της πλατφόρμας AceDataCloud**, με ενιαίο πρόθεμα `https://platform.acedata.cloud/api/v1/`. Για το πλήρες ευρετήριο διεπαφών, δείτε τη [Λήψη λίστας εγγράφων της πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list).

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                           |
| --- | ----------------------------------------------------- |
| Μέθοδος  | `GET`                                                 |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}` |
| Αυθεντικοποίηση  | ❌ Δημόσιο                                                  |

Τα `/apis/{id}` και `/apis/{id}/` είναι προς το παρόν και τα δύο διαθέσιμα· τα παραδείγματα χρησιμοποιούν ομοιόμορφα τη μορφή χωρίς τελική κάθετο.

## Περιγραφή αυθεντικοποίησης

Αυτή η διεπαφή είναι **πλήρως δημόσια και δεν απαιτεί διακριτικό λογαριασμού ή κατάσταση σύνδεσης**.

## Παράμετροι διαδρομής

| Παράμετρος       | Τύπος   | Υποχρεωτικό  | Περιγραφή                    |
| -------- | ---- | --- | --------------------- |
| `api_id` | UUID | ✅   | API ID (μορφή UUID, δεν υποστηρίζονται ψευδώνυμα) |

## Παραδείγματα αιτήματος

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/apis/afc7917f-d89f-4dc9-95c2-863936b02cad' \
  -H 'accept: application/json'
```

### Python

```python
import requests

api_id = "afc7917f-d89f-4dc9-95c2-863936b02cad"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/apis/{api_id}",
    headers={"accept": "application/json"},
    timeout=10,
)
api = resp.json()
print(f"API: {api['title']}")
print(f"路径: {api['path']}")
print(f"所属服务: {api['service']['title']} ({api['service']['alias']})")
print(f"OpenAPI 路径数: {len(api.get('definition', {}).get('paths', {}))}")
```

### Node.js

```javascript
const apiId = 'afc7917f-d89f-4dc9-95c2-863936b02cad'
const r = await fetch(`https://platform.acedata.cloud/api/v1/apis/${apiId}`)
const api = await r.json()
console.log(api.title, api.path, api.service.title)
```

## Περιγραφή πεδίων απόκρισης

Η διεπαφή λεπτομερειών περιλαμβάνει επιπλέον, πέρα από τα [πεδία της διεπαφής λίστας](https://platform.acedata.cloud/documents/platform-api-list):

| Πεδίο           | Τύπος     | Περιγραφή                                                                                          |
| ------------ | ------ | ------------------------------------------------------------------------------------------- |
| `service`    | object | Βασικές πληροφορίες της υπηρεσίας στην οποία ανήκει: `id`, `title`, `type`, `alias`                                                       |
| `products`   | array  | Λίστα συσχετισμένων προϊόντων (συνήθως κενή, για χρήση από την πλευρά λειτουργιών)                                                                         |
| `definition` | object | **Πλήρης ορισμός προδιαγραφών OpenAPI 3.0**, που περιλαμβάνει `paths`, `components`, `info` κ.λπ. και μπορεί να δοθεί απευθείας στο `openapi-generator` για τη δημιουργία κώδικα πελάτη |

## Διαχείριση σφαλμάτων

| HTTP | code        | Σημασία                 |
| ---- | ----------- | ------------------ |
| 400  | `invalid`   | Το `api_id` δεν είναι έγκυρο UUID |
| 404  | `not_found` | Το API δεν υπάρχει ή έχει αποσυρθεί        |

## Χρήσιμες συμβουλές

- **Το πεδίο `definition` είναι πολύ μεγάλο**: Το OpenAPI Schema ενός μεμονωμένου API μπορεί να έχει εκατοντάδες γραμμές JSON. Εάν θέλετε μόνο να δημιουργήσετε ευρετήριο υπηρεσιών και δεν χρειάζεστε το Schema, θα πρέπει να χρησιμοποιήσετε αντ’ αυτού τη [διεπαφή λίστας](https://platform.acedata.cloud/documents/platform-api-list).
- **Συνήθης χρήση για τη δημιουργία SDK**:
  ```shell
  # 拿到 OpenAPI 文件
  curl -s 'https://platform.acedata.cloud/api/v1/apis/<api_id>' | jq '.definition' > openapi.json

  # 用 openapi-generator-cli 生成 Python 客户端
  openapi-generator-cli generate -i openapi.json -g python -o ./client
  ```
- **Παρακολούθηση αλλαγών API**: Το πεδίο `updated_at` είναι η ώρα της τελευταίας αλλαγής του schema. Η εγγραφή σε αυτό το πεδίο επιτρέπει την αυτόματη επαναδημιουργία του SDK όταν αλλάζει το OpenAPI.
