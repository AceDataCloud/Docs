title: "Λήψη λεπτομερειών παραγγελίας της πλατφόρμας AceDataCloud"

Ερωτήστε μια παραγγελία μέσω του ID παραγγελίας. Αυτό το endpoint υποστηρίζει δύο λειτουργίες ανάγνωσης: η ανώνυμη πρόσβαση επιστρέφει μόνο τα ελάχιστα πεδία που απαιτούνται από τη σελίδα πληρωμής· όταν ο κάτοχος της παραγγελίας φέρει Account Token, επιστρέφονται πλήρεις λεπτομέρειες.

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                                        |
| --- | --------------------------------------------------------- |
| Μέθοδος  | `GET`                                                     |
| URL | `https://platform.acedata.cloud/api/v1/orders/{order_id}` |
| Αυθεντικοποίηση  | Προαιρετική· ανώνυμη για ελάχιστη προβολή, αυθεντικοποιημένος κάτοχος για πλήρη προβολή                                    |

Τα `/orders/{id}` και `/orders/{id}/` είναι προς το παρόν και τα δύο διαθέσιμα. Το ID παραγγελίας αποτελεί μέρος του συνδέσμου πληρωμής και πρέπει να θεωρείται ευαίσθητο αδιαφανές αναγνωριστικό· μην το διαδίδετε δημόσια.

## Ανώνυμο ερώτημα

Η σελίδα πληρωμής μπορεί να το διαβάσει απευθείας όταν χαθεί η κατάσταση σύνδεσης:

```shell
export ORDER_ID='το ID της παραγγελίας σας'
curl "https://platform.acedata.cloud/api/v1/orders/${ORDER_ID}" \
  -H 'Accept: application/json'
```

Η ανώνυμη απόκριση περιλαμβάνει μόνο τα `id`, `description`, `price`, `state`, `pay_way`, `pay_url`, `expired_at`, `created_at`. Δεν επιστρέφει λογαριασμό, Application, Package, εσωτερικά αναγνωριστικά πληρωμής ή metadata.

## Αυθεντικοποιημένο ερώτημα

```shell
export PLATFORM_TOKEN='το διακριτικό λογαριασμού σας'
curl "https://platform.acedata.cloud/api/v1/orders/${ORDER_ID}" \
  -H 'Accept: application/json' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Ο κάτοχος της παραγγελίας θα λάβει πλήρεις λεπτομέρειες Order, συμπεριλαμβανομένων των `application` / `applications`, `package` / `packages`, `bank_details`, `invoice_automation` και των πεδίων του μοντέλου. Εάν υπάρχει αυθεντικοποίηση αλλά δεν είναι ο κάτοχος της παραγγελίας, επιστρέφεται `403`· εξαιρούνται οι υπερδιαχειριστές.

## Βασικά πεδία

| Πεδίο            | Περιγραφή                                                          |
| ------------- | ----------------------------------------------------------- |
| `state`       | `Pending`, `Paid`, `Finished`, `Expired`, `Failed` ή `Refunded` |
| `pay_way`     | Η τρέχουσα μέθοδος πληρωμής της παραγγελίας· το όνομα πεδίου δεν είναι `payment_method`                             |
| `pay_url`     | Φιλοξενούμενη σελίδα πληρωμής ή διεύθυνση κωδικού QR, μπορεί να είναι κενή                                           |
| `price`       | Το τελικό πληρωτέο ποσό της παραγγελίας· το τρέχον μοντέλο παραγγελίας δεν παρέχει πεδίο `final_price`                         |
| `amount`      | Ποσότητα πίστωσης πακέτου· ορατή μόνο στην πλήρη αυθεντικοποιημένη απόκριση                                            |
| `finished_at` | Χρόνος ολοκλήρωσης παραγγελίας· το όνομα πεδίου δεν είναι `paid_at`                                      |

Η πλήρης απόκριση μπορεί να περιλαμβάνει πρόσθετα πεδία ανάλογα με τη μέθοδο πληρωμής· οι πελάτες πρέπει να τα διαβάζουν όπως απαιτείται και να αποφεύγουν πάντα την καταγραφή ευαίσθητων metadata από την πλήρη απόκριση.

## Χειρισμός σφαλμάτων

- `404`: Το ID παραγγελίας δεν υπάρχει.
- `403`: Έχει γίνει σύνδεση, αλλά δεν είναι ο κάτοχος της παραγγελίας.
- Τα ανώνυμα αιτήματα δεν επιστρέφουν `401`· λαμβάνουν μόνο την ελάχιστη δημόσια προβολή.
