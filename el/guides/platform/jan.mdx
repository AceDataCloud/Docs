Το [Jan](https://jan.ai/) είναι ένας offline-first ανοιχτού κώδικα AI desktop client, που μπορεί τόσο να εκτελεί μοντέλα τοπικά όσο και να συνδέεται σε endpoints συμβατά με OpenAI μέσω του **Remote Engine**. Αυτό το άρθρο παρουσιάζει πώς να συνδεθείτε με το Ace Data Cloud.

## Διαδικασία αίτησης

Για να συνδεθείτε με το Ace Data Cloud στο Jan, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications), λάβετε το API Token σας και κρατήστε το για χρήση.

![Λήψη Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά τη σύνδεση και την εγγραφή, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, παρέχεται δωρεάν πίστωση, ώστε να μπορείτε να δοκιμάσετε δωρεάν τις υπηρεσίες μοντέλων του Ace Data Cloud.

## Λήψη του Jan

Μεταβείτε στην [επίσημη ιστοσελίδα του Jan](https://jan.ai/) για λήψη ανά πλατφόρμα (Windows, macOS, Linux). Για μοντέλα Apple Silicon, κατεβάστε το πακέτο arm64 για βέλτιστη απόδοση.

## Ρύθμιση του Ace Data Cloud

Το Jan χωρίζει τα μοντέλα σε δύο κατηγορίες: **Local Engine** (τοπική εκτέλεση) και **Remote Engine** (API τρίτων). Το Ace Data Cloud χρησιμοποιεί το πρωτόκολλο συμβατό με OpenAI και συνδέεται μέσω του Remote Engine.

Ανοίξτε το Jan, μεταβείτε στο **Settings → Model Providers**, βρείτε την κάρτα **OpenAI** και επεξεργαστείτε:

| Πεδίο       | Τιμή                              | Περιγραφή                       |
| -------- | ------------------------------ | ------------------------ |
| API Key  | Το Ace Data Cloud Token σας        | Token που αντιγράφηκε από την κονσόλα             |
| Base URL | `https://api.acedata.cloud/v1` | **Πρέπει να τελειώνει με `/v1`, χωρίς κάθετο στο τέλος** |

> Το Base URL πρέπει να τελειώνει με `/v1`, σύμφωνα με τη σαφή σύμβαση της επίσημης τεκμηρίωσης του Jan. Εάν δεν θέλετε να αντικαταστήσετε την αρχική ρύθμιση OpenAI, μπορείτε να δημιουργήσετε έναν νέο Provider τύπου `openai-compatible` μέσω του «+ Add Provider» και να συμπληρώσετε το ίδιο περιεχόμενο.

![Διεπαφή ρύθμισης προσθήκης AceDataCloud Provider στο Jan](https://cdn.acedata.cloud/26017d28afa1.png)

Μετά την αποθήκευση του προσαρμοσμένου Provider, το Jan θα προσπαθήσει πρώτα να καλέσει το `{Base URL}/models` για να λάβει τη λίστα μοντέλων. Εάν η τρέχουσα έκδοση ή το endpoint δεν επιστρέφει διαθέσιμη λίστα, κάντε κλικ στο **+ Add Model** στο κάτω μέρος της ίδιας σελίδας επεξεργασίας και συμπληρώστε χειροκίνητα το ID του μοντέλου. Μετά την προσθήκη, το μοντέλο θα εμφανιστεί στο αναπτυσσόμενο μενού επάνω αριστερά και θα έχει το εικονίδιο «Cloud» για διάκριση μεταξύ απομακρυσμένου / τοπικού.

![Διεπαφή διαχείρισης μοντέλων Provider του Jan](https://cdn.acedata.cloud/ae485550946c.png)

> Το `MODEL_ID` είναι σύμβολο κράτησης θέσης· μεταβείτε στον [κατάλογο μοντέλων](https://platform.acedata.cloud/models) για να δείτε και να το αντικαταστήσετε με το όνομα του επιθυμητού μοντέλου· για ακριβή επαλήθευση, χρησιμοποιήστε την τιμή `id` στην απόκριση του `/v1/models`. Αυτή η τιμή είναι το όνομα μοντέλου που χρησιμοποιείται από την παράμετρο API `model`, όχι το UUID της υπηρεσίας ή του API.

## Επιλογή μοντέλου

Ο [κατάλογος μοντέλων](https://platform.acedata.cloud/models) ενημερώνεται συνεχώς. Δώστε προτεραιότητα στη λίστα μοντέλων που φορτώνεται αυτόματα από τον client· όταν απαιτείται χειροκίνητη συμπλήρωση, ζητήστε πρώτα `GET https://api.acedata.cloud/v1/models`, αντιγράψτε την τιμή `id` του επιθυμητού μοντέλου από τον πίνακα `data` της απόκρισης και, στη συνέχεια, επιλέξτε σύμφωνα με τις δυνατότητες περιβάλλοντος, εικόνων και κλήσης εργαλείων που υποστηρίζει ο client.

## Επαλήθευση σύνδεσης

Εάν δεν είστε βέβαιοι αν το πρόβλημα βρίσκεται στο Jan ή στο δίκτυο, μπορείτε πρώτα να επαληθεύσετε απευθείας το endpoint με curl (αντικαταστήστε το `{token}` με το Token σας):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Η επιστροφή ενός αντικειμένου `chat.completion` συμβατού με OpenAI σημαίνει ότι τόσο το Token όσο και το endpoint είναι έτοιμα· εάν επιστραφεί `HTTP 403 used_up`, σημαίνει ότι το Token είναι έγκυρο αλλά το υπόλοιπο είναι ανεπαρκές. Μεταβείτε στην [κονσόλα](https://platform.acedata.cloud/console/applications) για ανανέωση υπολοίπου.

## Προχωρημένα: τοπική + cloud υβριδική χρήση

Το Jan περιλαμβάνει έναν τοπικό API Server συμβατό με OpenAI που μπορεί να ενεργοποιηθεί (Settings → Local API Server). Μετά την ενεργοποίηση, ακούει στο `http://localhost:1337/v1/chat/completions` και εκτελεί τα τοπικά μοντέλα που έχετε κατεβάσει. Με αυτόν τον τρόπο, μπορείτε να ορίσετε το Base URL σε τοπικό περιβάλλον για δωρεάν αποσφαλμάτωση σε frameworks όπως LangChain / LlamaIndex, και να μεταβαίνετε στα απομακρυσμένα μοντέλα Ace Data Cloud για σύνθετες εργασίες. Το περιβάλλον συνομιλίας δεν χάνεται κατά την αλλαγή μοντέλων.

## Συχνές ερωτήσεις

### Εμφανίζεται Connection error ή 404

Συνήθως λείπει το `/v1` από το Base URL. Αλλάξτε το σε `https://api.acedata.cloud/v1` (πρέπει να τελειώνει με `/v1` και να μην γραφτεί ως `.../openai/v1`).

### Εμφανίζεται 401 Unauthorized

Βεβαιωθείτε ότι στο API Key έχει επικολληθεί το Token του Ace Data Cloud (χωρίς πρόθεμα `Bearer` και χωρίς επιπλέον κενά) και ότι το υπόλοιπο της αντίστοιχης εφαρμογής είναι επαρκές.

### Το απομακρυσμένο μοντέλο δεν εμφανίζεται στο αναπτυσσόμενο μενού

Κάντε πρώτα κλικ στο κουμπί ανανέωσης μοντέλων για να ενεργοποιήσετε το `/v1/models`· εάν η αυτόματη ανακάλυψη αποτύχει, προσθέστε χειροκίνητα ένα μοντέλο με **+ Add Model**, προσθέτοντας ακριβώς την τιμή `id` του μοντέλου από τον κατάλογο.

### Μπορώ να ανεβάσω εικόνες για να τις αναλύσει το μοντέλο

Ναι, αλλά πρέπει να επιλέξετε από τον τρέχοντα κατάλογο μοντέλων ένα μοντέλο που υποστηρίζει ρητά οπτική είσοδο.
