Δημιουργήστε νέο Token ή κωδικό πρόσβασης για ένα υπάρχον Credential. Το ID διαπιστευτηρίου, η συσχέτιση Application, τα όρια και άλλα πεδία παραμένουν αμετάβλητα, ενώ το παλιό μυστικό καθίσταται αμέσως άκυρο.

> Η περιστροφή θα διακόψει τους πελάτες που εξακολουθούν να χρησιμοποιούν το παλιό μυστικό. Προετοιμάστε πρώτα ασφαλή διανομή και σχέδιο επαναφοράς και, στη συνέχεια, εκτελέστε τη λειτουργία εγγραφής.

## Επισκόπηση διεπαφής

| Στοιχείο    | Περιεχόμενο                                                                |
| ----------- | -------------------------------------------------------------------------- |
| Μέθοδος     | `POST`                                                                     |
| URL         | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}/rotate/` |
| Αυθεντικοποίηση | Account Token                                                          |
| Body        | Κανένα ή `{}`                                                              |

Λάβετε το `credential_id` από τη [λίστα διαπιστευτηρίων](https://platform.acedata.cloud/documents/platform-credential-list):

```shell
export PLATFORM_TOKEN='你的账户令牌'
export CREDENTIAL_ID='要轮换的 Credential ID'

curl -X POST \
  "https://platform.acedata.cloud/api/v1/credentials/${CREDENTIAL_ID}/rotate/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Σε περίπτωση επιτυχίας επιστρέφεται το ενημερωμένο Credential. Όταν `type=Token`, διαβάστε το νέο `token`· όταν `type=Identity`, διαβάστε το νέο `password`. Αντιμετωπίστε την πλήρη απόκριση ως μυστικό και ενημερώστε αμέσως τους καλούντες.

## Διαχείριση σφαλμάτων

- `401`: Το Account Token δεν είναι έγκυρο.
- `403`: Δεν έχετε δικαίωμα διαχείρισης αυτού του διαπιστευτηρίου.
- `404`: Το Credential ID δεν υπάρχει.
