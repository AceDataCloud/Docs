Το μοντέλο Coding Plan του OpenCode, ο Provider, η IDE Extension και το MCP είναι τρεις ανεξάρτητες δυνατότητες. Η IDE Extension συνδέει το τοπικό OpenCode runtime και επαναχρησιμοποιεί την ίδια ρύθμιση Provider. Δεν αντιπροσωπεύει την εγγενή υποστήριξη του Ace Data Cloud από τον κεντρικό επεξεργαστή.

| Διαδρομή                        | Περιγραφή                                                  | Σύνδεσμος                                                                                  | Κατάσταση      |
| ----------------------------- | ------------------------------------------------------- | --------------------------------------------------------------------------------------- | --------- |
| Terminal / CLI / TUI Provider | Χρησιμοποιεί `opencode.json[c]` και Chat Completions                | [Ρύθμιση Provider](https://platform.acedata.cloud/documents/opencode-terminal-integration) | Επαληθευμένη ρύθμιση |
| IDE Extension                 | VS Code, Cursor, Windsurf, VSCodium και άλλοι κεντρικοί συνδέονται με το OpenCode runtime | [Ρύθμιση IDE](https://platform.acedata.cloud/documents/opencode-ide-integration)           | Πειραματική     |
| MCP                           | Κλήση απομακρυσμένων εργαλείων εντός του OpenCode                                      | [Επισκόπηση MCP](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | Ανεξάρτητη δυνατότητα    |

Αφού η ρύθμιση του Provider είναι επιτυχής, η IDE Extension θα πρέπει να χρησιμοποιεί τον ίδιο Provider και μοντέλο. Πρέπει να επαληθευτούν ξεχωριστά οι συνομιλίες, η ανάγνωση αρχείων, η επεξεργασία και οι κλήσεις εργαλείων εντός της IDE, και δεν θα πρέπει να εξάγεται αυτόματα ένα απλό αίτημα CLI ως όλες οι δυνατότητες της IDE.

Ο ID του μοντέλου είναι σύμφωνα με τον [ζωντανό κατάλογο](https://platform.acedata.cloud/models).
