[LibreChat](https://www.librechat.ai/) είναι ένας εξαιρετικά παραμετροποιήσιμος ανοιχτού κώδικα AI πελάτης, που μπορεί να περιγραφεί με το `librechat.yaml` για παρόχους υπηρεσιών, μοντέλα και κανόνες δρομολόγησης. Υποστηρίζει προσαρμοσμένα OpenAI συμβατά endpoints, επιτρέποντας τη σύνδεση με το Ace Data Cloud. Αυτό το άρθρο περιγράφει τη διαδικασία ρύθμισης.

## Διαδικασία αίτησης

Για να συνδεθείτε με το Ace Data Cloud στο LibreChat, πρώτα επισκεφθείτε την [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πίστωση για να δοκιμάσετε δωρεάν τις υπηρεσίες μοντέλων του Ace Data Cloud.

## Ανάπτυξη του LibreChat

Το LibreChat αναπτύσσεται μέσω Docker Compose, πρώτα ετοιμάστε τον φάκελο και κατεβάστε την επίσημη ρύθμιση:

```bash
mkdir -p ~/librechat && cd ~/librechat
curl -O https://raw.githubusercontent.com/danny-avila/LibreChat/main/docker-compose.yml
curl -O https://raw.githubusercontent.com/danny-avila/LibreChat/main/.env.example
mv .env.example .env
```

Στο `.env`, χρησιμοποιήστε το `openssl rand -hex 32` για να δημιουργήσετε τα `JWT_SECRET`, `JWT_REFRESH_SECRET`, `CREDS_KEY`, `CREDS_IV` και άλλα ασφαλή κλειδιά, και ρυθμίστε το `ALLOW_REGISTRATION` όπως απαιτείται.

## Ρύθμιση του Ace Data Cloud

Δημιουργήστε το `librechat.yaml`, προσθέτοντας το Ace Data Cloud ως προσαρμοσμένο OpenAI συμβατό endpoint (για πλήρη περιγραφή πεδίων δείτε την επίσημη [τεκμηρίωση Custom Endpoints](https://www.librechat.ai/docs/quick_start/custom_endpoints), αντικαταστήστε το `{token}` με το Token σας):

```yaml
version: 1.0.5
cache: true

endpoints:
  custom:
    - name: "Ace Data Cloud"
      apiKey: "{token}"
      baseURL: "https://api.acedata.cloud/v1"
      models:
        default:
          - "MODEL_ID"
        fetch: true
      titleConvo: true
      titleModel: "MODEL_ID"
      modelDisplayLabel: "Ace Data Cloud"
```

Στο `docker-compose.yml`, κάτω από την υπηρεσία `api`, προσθέστε αυτό το αρχείο στο κοντέινερ και στη συνέχεια εκτελέστε `docker compose up -d`:

```yaml
    volumes:
      - type: bind
        source: ./librechat.yaml
        target: /app/librechat.yaml
```

Σημειώστε τους κανόνες διαδρομής του `baseURL`:

| baseURL                               | Πραγματικό αίτημα                                           | Αποτέλεσμα                 |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | Σωστό                     |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | Επίσης διαθέσιμο          |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (δεν υπάρχει `/v1` κάτω από `/openai`) |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404 (λείπει το `/v1`)    |

## Επιλογή μοντέλου

Ο κατάλογος μοντέλων θα ενημερώνεται συνεχώς. Προτιμήστε να χρησιμοποιήσετε τη λίστα μοντέλων που φορτώνεται αυτόματα από τον πελάτη. Εάν χρειαστεί να συμπληρώσετε χειροκίνητα, πρώτα ζητήστε `GET https://api.acedata.cloud/v1/models` για να αποκτήσετε το τρέχον ID μοντέλου και στη συνέχεια επιλέξτε με βάση τις δυνατότητες του πελάτη για συμφραζόμενα, εικόνες και κλήσεις εργαλείων.

## Επαλήθευση σύνδεσης

Εάν δεν είστε σίγουροι αν το πρόβλημα προέρχεται από το LibreChat ή το δίκτυο, μπορείτε πρώτα να επαληθεύσετε απευθείας το endpoint με curl (αντικαταστήστε το `{token}` με το Token σας):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Η επιστροφή ενός αντικειμένου `chat.completion` συμβατού με το OpenAI σημαίνει ότι το Token και το endpoint είναι έτοιμα. Εάν επιστραφεί `HTTP 403 used_up`, αυτό σημαίνει ότι το Token είναι έγκυρο αλλά η πίστωση έχει εξαντληθεί, μπορείτε να ανανεώσετε την πίστωση στην [κονσόλα](https://platform.acedata.cloud/console/applications).

## Προχωρημένα: Τεχνικές ρύθμισης yaml

Το `librechat.yaml` υποστηρίζει πολλαπλές ομάδες endpoint, μπορείτε να χρησιμοποιήσετε το `apiKey: "user_provided"` για να επιτρέψετε σε κάθε χρήστη να συμπληρώσει το δικό του Key. Το `titleModel` καθορίζει το μοντέλο που θα χρησιμοποιηθεί για τη δημιουργία τίτλων συνομιλιών. Το `dropParams` μπορεί να χρησιμοποιηθεί για να διαγράψει ομοιόμορφα παραμέτρους που δεν υποστηρίζονται από το API στόχο. Δείτε περισσότερα στην [αναλυτική τεκμηρίωση του librechat.yaml](https://www.librechat.ai/docs/configuration/librechat_yaml).

## Συχνές ερωτήσεις

### Δεν βλέπω το endpoint του Ace Data Cloud μετά την εκκίνηση

Συνήθως αυτό συμβαίνει επειδή το yaml δεν έχει προστεθεί στο κοντέινερ ή υπάρχει σφάλμα στην εσοχή. Ελέγξτε τα volumes του `docker-compose.yml` και επιβεβαιώστε την εσοχή του yaml.

### Εμφανίζεται 404

Το `baseURL` έχει γραφεί ως `.../openai/v1` ή λείπει το `/v1`. Αλλάξτε το σε `https://api.acedata.cloud/v1`.

### Το αναπτυσσόμενο μενού μοντέλων είναι κενό

Εάν το `fetch: true` αλλά η κλήση στο `/v1/models` αποτύχει, αλλάξτε το σε `fetch: false` και καταχωρίστε χειροκίνητα το `default`.

### Οι αλλαγές στο yaml δεν ισχύουν

Πρέπει να επανεκκινήσετε το κοντέινερ: `docker compose restart api`.
