Το [Open WebUI](https://openwebui.com/) (πρώην Ollama WebUI) είναι ένας ανοιχτού κώδικα AI client που υποστηρίζει πολλούς χρήστες, βάσεις γνώσης, RAG και ιδιωτική ανάπτυξη. Υποστηρίζει προσαρμοσμένα συμβατά με OpenAI endpoints, επομένως μπορεί να συνδεθεί με το Ace Data Cloud. Αυτό το άρθρο παρουσιάζει τη διαδικασία διαμόρφωσης.

## Διαδικασία αίτησης

Για να συνδέσετε το Ace Data Cloud στο Open WebUI, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications), αποκτήστε το API Token σας και κρατήστε το για μελλοντική χρήση.

![Λήψη Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε συνδεθεί ή εγγραφεί ακόμη, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε· μετά τη σύνδεση ή την εγγραφή, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση παρέχεται δωρεάν υπόλοιπο, ώστε να μπορείτε να δοκιμάσετε δωρεάν τις υπηρεσίες μοντέλων του Ace Data Cloud.

## Ανάπτυξη και διαμόρφωση του Ace Data Cloud

Το Open WebUI συνδέεται με συμβατά με OpenAI endpoints μέσω μεταβλητών περιβάλλοντος και μπορεί να αναπτυχθεί με μία εντολή Docker (αντικαταστήστε το `{token}` με το Token σας):

```bash
docker run -d \
  --name open-webui \
  -p 3000:8080 \
  -e WEBUI_SECRET_KEY=$(openssl rand -base64 32) \
  -e OPENAI_API_BASE_URL=https://api.acedata.cloud/v1 \
  -e OPENAI_API_KEY={token} \
  -v open-webui:/app/backend/data \
  ghcr.io/open-webui/open-webui:main
```

| Μεταβλητή περιβάλλοντος                              | Λειτουργία                                 |
| --------------------------------- | ---------------------------------- |
| `OPENAI_API_BASE_URL`             | Σημείο εισόδου Ace Data Cloud, **πρέπει να τελειώνει σε `/v1`** |
| `OPENAI_API_KEY`                  | Το Token σας                           |
| `WEBUI_SECRET_KEY`                | Κλειδί κρυπτογράφησης session, δημιουργείται αυτόματα                  |
| `-v open-webui:/app/backend/data` | Μόνιμη αποθήκευση δεδομένων συνομιλιών / χρηστών                       |

Ανοίξτε το `http://IPτουδιακομιστήσας:3000`· ο πρώτος λογαριασμός που εγγράφεται γίνεται αυτόματα διαχειριστής. Σημειώστε τους κανόνες διαδρομής του Base URL:

| OPENAI_API_BASE_URL                   | Πραγματικό αίτημα                                                   | Αποτέλεσμα                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | Σωστό                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | Επίσης λειτουργεί                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (δεν υπάρχει `/v1` κάτω από το `/openai`) |

Μετά τη σύνδεση, μεταβείτε στο **Admin Panel → Settings → Connections** και πατήστε «Verify Connection» για επαλήθευση· στο **Settings → Models** μπορείτε να φιλτράρετε και να κάνετε Pin στα μοντέλα που χρησιμοποιείτε συχνά.

> Εκτός από τις μεταβλητές περιβάλλοντος, το Open WebUI υποστηρίζει επίσης την απευθείας προσθήκη σύνδεσης από τη διεπαφή: μεταβείτε στο **Admin Settings → Connections**, πατήστε ➕ και συμπληρώστε το URL (`https://api.acedata.cloud/v1`) και το API Key. Το Open WebUI θα καλέσει αυτόματα το `/models` για να ανακτήσει τη λίστα μοντέλων. Για λεπτομέρειες, δείτε την επίσημη τεκμηρίωση [Starting With OpenAI-Compatible Servers](https://docs.openwebui.com/getting-started/quick-start/connect-a-provider/starting-with-openai-compatible).

![Διεπαφή διαμόρφωσης σύνδεσης Open WebUI Ace Data Cloud](https://cdn.acedata.cloud/f366abfd935d.png)

> Το `MODEL_ID` χρησιμοποιείται μόνο για επίδειξη προαιρετικής allow list· όταν είναι κενό, θα εμφανίζονται όλα τα μοντέλα που επιστρέφει το `/models`.

## Επιλογή μοντέλου

Ο κατάλογος μοντέλων ενημερώνεται συνεχώς. Δώστε προτεραιότητα στη λίστα μοντέλων που φορτώνεται αυτόματα από τον client· αν χρειάζεται χειροκίνητη συμπλήρωση, ζητήστε πρώτα `GET https://api.acedata.cloud/v1/models` για να λάβετε το τρέχον model ID και, στη συνέχεια, επιλέξτε σύμφωνα με τις δυνατότητες context, εικόνων και κλήσεων εργαλείων που υποστηρίζει ο client.

## Επαλήθευση ενσωμάτωσης

Αν δεν είστε βέβαιοι αν το πρόβλημα βρίσκεται στο Open WebUI ή στο δίκτυο, μπορείτε πρώτα να χρησιμοποιήσετε curl για απευθείας επαλήθευση του endpoint (αντικαταστήστε το `{token}` με το Token σας):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Η επιστροφή ενός συμβατού με OpenAI αντικειμένου `chat.completion` σημαίνει ότι το Token και το endpoint είναι έτοιμα· αν επιστραφεί `HTTP 403 used_up`, αυτό σημαίνει ότι το Token είναι έγκυρο αλλά το υπόλοιπο δεν επαρκεί. Μπορείτε να κάνετε ανανέωση στην [κονσόλα](https://platform.acedata.cloud/console/applications).

## Προχωρημένα: βάση γνώσης και πολλοί χρήστες

Η βάση γνώσης (RAG) του Open WebUI χρησιμοποιεί από προεπιλογή το ChromaDB για την αποθήκευση διανυσμάτων και το μοντέλο ενσωμάτωσης μπορεί να οριστεί σε `text-embedding-3-large` (μέσω Ace Data Cloud). Τα πρωτότυπα έγγραφα αποθηκεύονται μόνο στον διακομιστή σας και μόνο τα τμήματα που αντιστοιχούν αποστέλλονται στο μοντέλο. Στο **Admin Panel → Users** μπορείτε να διαχειριστείτε τους ρόλους χρηστών (Pending / User / Admin)· συνιστάται να ορίσετε το «Default User Role» σε `pending`, ώστε οι νέοι χρήστες να χρειάζονται έγκριση πριν μπορέσουν να το χρησιμοποιήσουν, αποφεύγοντας την αυθαίρετη εγγραφή εξωτερικών χρηστών και την κατανάλωση υπολοίπου. Αν χρησιμοποιείτε αντίστροφο proxy nginx, προσθέστε `proxy_buffering off;` και `client_max_body_size 100M;`.

## Συχνές ερωτήσεις

### Εμφανίζεται Connection error / 404

Συνήθως το `OPENAI_API_BASE_URL` έχει γραφτεί ως `.../openai/v1` ή λείπει το `/v1`. Αλλάξτε το σε `https://api.acedata.cloud/v1`.

### Δεν είναι δυνατή η συνομιλία μετά τη μεταφόρτωση εγγράφων

Στις ρυθμίσεις RAG του Admin Panel, επιλέξτε το μοντέλο ενσωμάτωσης ως `text-embedding-3-large` (OpenAI provider).

### Τα δεδομένα χάνονται μετά την επανεκκίνηση του container

Κατά την εκκίνηση πρέπει να προσαρτήσετε τον τόμο δεδομένων `-v open-webui:/app/backend/data`.
