Επιστρέφει σελιδοποιημένα τα έγγραφα προγραμματιστών που είναι ορατά στον τρέχοντα ιστότοπο, και μπορεί να χρησιμοποιηθεί για αναζήτηση, ευρετηρίαση ή δημιουργία πλοήγησης στον πελάτη. Η λίστα περιλαμβάνει επί του παρόντος το `content` και τις ένθετες πληροφορίες γονέα κάθε εγγράφου, και η απόκριση μπορεί να είναι μεγάλη.

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                        |
| --- | -------------------------------------------------- |
| Μέθοδος  | `GET`                                              |
| URL | `https://platform.acedata.cloud/api/v1/documents/` |
| Αυθεντικοποίηση  | Δημόσια· οι μη διαχειριστές δεν μπορούν να δουν private έγγραφα                              |
| Σελιδοποίηση  | `count` + `items`                                  |

## Παράμετροι ερωτήματος

| Παράμετρος         | Τύπος      | Υποχρεωτική  | Προεπιλογή     | Περιγραφή                           |
| ---------- | ------- | --- | ------ | ---------------------------- |
| `id`       | UUID    | Όχι   | —      | Φιλτράρισμα κατά ID εγγράφου· υποστηρίζονται επαναλαμβανόμενες παράμετροι             |
| `private`  | boolean | Όχι   | —      | Φιλτράρισμα κατά κατάστασης private· οι μη διαχειριστές εξακολουθούν να μην μπορούν να δουν ιδιωτικά έγγραφα |
| `type`     | string  | Όχι   | —      | Ακριβές φιλτράρισμα κατά της πραγματικής τιμής `type` του Document  |
| `tag`      | string  | Όχι   | —      | Φιλτράρισμα κατά ετικέτας                        |
| `limit`    | integer | Όχι   | 10     | Αριθμός στοιχείων ανά σελίδα, μέγιστο 100                  |
| `offset`   | integer | Όχι   | 0      | Μετατόπιση σελιδοποίησης                        |
| `ordering` | string  | Όχι   | `rank` | Υποστηρίζεται μόνο ταξινόμηση κατά `rank`· το πρόθεμα `-` υποδεικνύει φθίνουσα σειρά   |

Η τρέχουσα διεπαφή λίστας δεν υποστηρίζει φιλτράρισμα `alias` ή `parent_id`. Όταν το alias είναι γνωστό, καλέστε απευθείας τις [λεπτομέρειες εγγράφου](https://platform.acedata.cloud/documents/platform-document-detail)· κατά τη δημιουργία δενδρικής πλοήγησης, μετά την ανάκτηση μίας σελίδας, ομαδοποιήστε στον πελάτη χρησιμοποιώντας το `parent.id` κάθε στοιχείου.

## Παράδειγμα αιτήματος

```shell
curl --get 'https://platform.acedata.cloud/api/v1/documents/' \
  --data-urlencode 'tag=development' \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/documents/",
    params={"tag": "development", "limit": 100, "offset": 0},
    timeout=30,
)
response.raise_for_status()
data = response.json()
for document in data["items"]:
    parent = document.get("parent") or {}
    print(document["alias"], parent.get("alias"))
```

Η λίστα χρησιμοποιεί το `DocumentIndexSerializer` και επί του παρόντος επιστρέφει πεδία μοντέλου και ένθετες σχέσεις· τα συσχετισμένα έγγραφα API ενδέχεται επίσης να περιλαμβάνουν `api_method`. Πεδία μπορεί να προστεθούν με συμβατότητα προς τα πίσω, και ο πελάτης θα πρέπει να διαβάζει όσα χρειάζεται. Όταν απαιτούνται `children`, η αναλυμένη γλώσσα περιεχομένου και το hash περιεχομένου, χρησιμοποιήστε τη διεπαφή λεπτομερειών.

Για δημόσιες εγγραφές που συνδέονται με έγγραφα πηγής, το `content_source` παρέχει το αναγνωριστικό του εγγράφου πηγής, το hash του περιεχομένου πηγής, τη ζητούμενη γλώσσα, τον χρόνο ενημέρωσης της μετάφρασης και κατάσταση `ready`, `stale`, `missing`, `missing_source` ή `ambiguous`· για άλλες εγγραφές αυτό το πεδίο είναι `null`. Το `content_hash` όταν είναι `ready` αντιστοιχεί στη μετάφραση αυτής της γλώσσας. Το κυρίως κείμενο εξακολουθεί να εμφανίζεται σύμφωνα με τους αρχικούς κανόνες, συμπεριλαμβανομένης της γλωσσικής εφεδρείας όταν λείπει μετάφραση· οι πελάτες που χρειάζεται να συγχρονίζουν έγγραφα θα πρέπει να ελέγχουν ταυτόχρονα την κατάσταση και το hash, και δεν μπορούν να κρίνουν ότι έχει ενημερωθεί μόνο επειδή το κυρίως κείμενο δεν είναι κενό.

## Προτάσεις χρήσης

- Η απόκριση περιέχει κυρίως κείμενο· κατά τον μαζικό συγχρονισμό χρησιμοποιήστε σελιδοποίηση και ορίστε εύλογο χρονικό όριο, μην ανακτάτε την ίδια σελίδα ταυτόχρονα.
- Το alias είναι το σταθερό αναγνωριστικό URL της δημόσιας σελίδας· όταν το alias είναι γνωστό, ζητήστε απευθείας `/api/v1/documents/{alias}`.
- Η τρέχουσα διεπαφή δεν μπορεί να φιλτράρει στον διακομιστή κατά γονέα· κατά τη δημιουργία πλοήγησης, ομαδοποιήστε στον πελάτη κατά `parent.id`.
