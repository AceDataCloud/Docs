Η «Αίτηση (Application)» υποδηλώνει τη σχέση συνδρομής του τρέχοντος λογαριασμού με μια συγκεκριμένη υπηρεσία — πρέπει πρώτα να υποβληθεί αίτηση, ώστε στη συνέχεια να δημιουργηθούν διαπιστευτήρια API για αυτήν την αίτηση και να κληθούν επιχειρησιακές διεπαφές. Κατά την πρώτη αίτηση για μια υπηρεσία, το Application θα λάβει το `free_amount` που είναι τη δεδομένη στιγμή ρυθμισμένο για την υπηρεσία· αυτή η τιμή μπορεί να είναι 0.

> ℹ️ Αυτή η διεπαφή ανήκει στο **API διαχείρισης της πλατφόρμας AceDataCloud**, με ενιαίο πρόθεμα `https://platform.acedata.cloud/api/v1/`. Για το πλήρες ευρετήριο διεπαφών, δείτε τη [Λήψη λίστας εγγράφων πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list).

## Πλήρης ροή ενσωμάτωσης

Οι νέοι χρήστες, από την εγγραφή έως την επιτυχή κλήση της πρώτης επιχειρησιακής διεπαφής, συνήθως ακολουθούν αυτά τα 5 βήματα:

1. **Λήψη διακριτικού λογαριασμού** → [Διαχείριση διακριτικών λογαριασμού πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-token)
2. **Επιλογή υπηρεσίας** → [Λήψη λίστας υπηρεσιών πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-service-list)
3. **Δημιουργία αίτησης**（το παρόν έγγραφο）→ Λήψη αρχικού ορίου σύμφωνα με τη διαμόρφωση της υπηρεσίας
4. **Δημιουργία διαπιστευτηρίων API** → [Δημιουργία διαπιστευτηρίων API πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-credential-create)
5. **Κλήση επιχειρησιακής διεπαφής** → Χρησιμοποιήστε το ληφθέν Token 32 χαρακτήρων για να καλέσετε το `https://api.acedata.cloud/<path>`

## Επισκόπηση διεπαφής

| Στοιχείο            | Περιεχόμενο                                                    |
| ------------ | ----------------------------------------------------- |
| Μέθοδος           | `POST`                                                |
| URL          | `https://platform.acedata.cloud/api/v1/applications/` |
| Αυθεντικοποίηση           | ✅ Απαιτείται διακριτικό λογαριασμού                                              |
| Content-Type | `application/json`                                    |

## Περιγραφή αυθεντικοποίησης（πώς να αποκτήσετε διακριτικό λογαριασμού）

Κεφαλίδα αιτήματος:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

Το διακριτικό λογαριασμού (Account Token) είναι ένα «κλειδί επιπέδου λογαριασμού» μέσω του οποίου οι προγραμματιστές διαχειρίζονται τους πόρους του δικού τους λογαριασμού μέσω API. Τρόποι λήψης:

1. **Δημιουργία με ένα κλικ από την κονσόλα（συνιστάται）**：Συνδεθείτε στην [πλατφόρμα AceDataCloud](https://platform.acedata.cloud) → [Κονσόλα Account Token](https://platform.acedata.cloud/console/platform-tokens) → κάντε κλικ στο «Δημιουργία» για να αποκτήσετε ένα διακριτικό που αρχίζει με `platform-v1-`.
2. **Δημιουργία μέσω API**：Χρησιμοποιήστε ένα υπάρχον διακριτικό λογαριασμού ή JWT κατάστασης σύνδεσης προγράμματος περιήγησης για να καλέσετε `POST /api/v1/platform-tokens/`, δείτε λεπτομέρειες στη [Διαχείριση διακριτικών λογαριασμού πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-token).

> ⚠️ Το διακριτικό λογαριασμού είναι εξίσου ευαίσθητο με έναν κωδικό πρόσβασης· απαγορεύεται να γράφεται σε κώδικα frontend ή σε δημόσια αποθετήρια. Εάν διαρρεύσει, διαγράψτε το αμέσως από την κονσόλα και δημιουργήστε νέο.

## Σώμα αιτήματος

| Παράμετρος           | Τύπος   | Υποχρεωτικό  | Περιγραφή                                                                                                  |
| ------------ | ---- | --- | --------------------------------------------------------------------------------------------------- |
| `service_id` | UUID | ✅   | Το ID της υπηρεσίας για την οποία υποβάλλεται αίτηση. Μπορεί να ληφθεί από το `items[].id` της [λίστας υπηρεσιών](https://platform.acedata.cloud/documents/platform-service-list) |

## Παράδειγμα αιτήματος

### cURL

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/applications/' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'content-type: application/json' \
  -d '{"service_id": "38ecf158-36f2-42f2-8e7f-6786cdfc2452"}'
```

### Python

```python
import os
import requests

PLATFORM_TOKEN = os.environ["PLATFORM_TOKEN"]
SERVICE_ID = "38ecf158-36f2-42f2-8e7f-6786cdfc2452"

resp = requests.post(
    "https://platform.acedata.cloud/api/v1/applications/",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {PLATFORM_TOKEN}",
        "content-type": "application/json",
    },
    json={"service_id": SERVICE_ID},
    timeout=10,
)

if resp.status_code == 201:
    app = resp.json()
    print(f"申请成功！application_id={app['id']}")
    print(f"初始额度：{app['remaining_amount']} {app.get('service', {}).get('unit', '')}")
elif resp.status_code == 400 and resp.json().get("code") == "duplication":
    print("⚠️ 已经申请过此服务，请到 /applications/ 列表里找到现成的 application_id")
else:
    print(f"申请失败：HTTP {resp.status_code} - {resp.text}")
```

### Node.js

```javascript
const PLATFORM_TOKEN = process.env.PLATFORM_TOKEN
const SERVICE_ID = '38ecf158-36f2-42f2-8e7f-6786cdfc2452'

const resp = await fetch('https://platform.acedata.cloud/api/v1/applications/', {
  method: 'POST',
  headers: {
    accept: 'application/json',
    authorization: `Bearer ${PLATFORM_TOKEN}`,
    'content-type': 'application/json',
  },
  body: JSON.stringify({ service_id: SERVICE_ID }),
})

if (resp.status === 201) {
  const app = await resp.json()
  console.log('application_id =', app.id)
} else {
  console.error(await resp.text())
}
```

  "used_amount": 0.0,
  "paid": false,
  "user_id": "89518d07-5560-4b05-92c1-667f3ddf6a4b",
  "disabled": false,
  "allow_consume_global": false,
  "scope": "Individual",
  "type": "Usage",
  "expired_at": null,
  "tags": null,
  "metadata": null,

  "client_fingerprint": null,
  "created_at": "2026-04-26T07:52:27.462400Z",
  "updated_at": "2026-04-26T07:52:27.462400Z"

Η δομή των επιστρεφόμενων πεδίων είναι ίδια με τη [Λήψη λεπτομερειών αίτησης υπηρεσίας πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-application-detail).

### Έχει ήδη υποβληθεί αίτηση（HTTP 400）

```json
{
  "detail": "Item already exists.",
  "code": "duplication",
  "trace_id": "1a87524f8cbba0b790b2951e2e43117e"
}
```

Αυτό είναι ένας αυστηρός περιορισμός βάσει σχεδιασμού：**κάθε χρήστης μπορεί να έχει μόνο ένα Application για κάθε υπηρεσία**. Εάν υπάρχει ήδη, αναζητήστε το υπάρχον μέσω της [Λήψης λίστας αιτήσεων υπηρεσιών πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-application-list).

### Η υπηρεσία δεν υπάρχει（HTTP 404）

```json
{
  "detail": "Service not found.",
  "code": "not_found",
  "trace_id": "..."
}
```

### Η υπηρεσία απαιτεί έγκριση（HTTP 403）

```json
{
  "detail": "This service requires manual verification.",
  "code": "need_verify",
  "trace_id": "..."
}
```

Εάν η υπηρεσία έχει `need_verify=true`（το πεδίο αυτό είναι ορατό στη λίστα υπηρεσιών）, απαιτείται η διαδικασία αιτήματος υποστήριξης για αίτηση προσθήκης στη λίστα επιτρεπόμενων.

## Διαχείριση σφαλμάτων
| HTTP | κωδικός             | Σημασία                   |
| ---- | ------------------- | ------------------------- |
| 400  | `duplication`       | Αυτή η υπηρεσία έχει ήδη αιτηθεί από τον τρέχοντα λογαριασμό |
| 400  | `invalid`           | Το `service_id` λείπει ή έχει λανθασμένη μορφή |
| 401  | `not_authenticated` | Λείπει το διακριτικό λογαριασμού ή το διακριτικό έχει διαγραφεί |
| 403  | `need_verify`       | Η υπηρεσία απαιτεί έγκριση, παρακαλούμε ακολουθήστε τη διαδικασία ticket |
| 404  | `not_found`         | Η υπηρεσία δεν υπάρχει ή έχει αποσυρθεί |

Ενιαία μορφή απόκρισης σφάλματος:

```json
{
  "detail": "...",
  "code": "...",
  "trace_id": "..."
}
```

## Χρήσιμες συμβουλές

- **Η ίδια η δημιουργία δεν χρεώνεται**: κατά την πρώτη δημιουργία, το αρχικό όριο ορίζεται σύμφωνα με το τρέχον `free_amount` της υπηρεσίας· αυτή η τιμή μπορεί να είναι 0 και η εκ νέου δημιουργία Application του ίδιου τύπου δεν εγγυάται επαναλαμβανόμενη δωρεάν παροχή.
- **Το αν απαιτείται πληρωμή εξαρτάται από το πεδίο `paid`**: αμέσως μετά την αίτηση `paid=false`, και μετά την κλήση [Δημιουργία εντολής επαναφόρτισης της πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-order-create) για ολοκλήρωση της πληρωμής γίνεται `true`.
- **`disabled=true` σημαίνει ότι έχει απενεργοποιηθεί προσωρινά**—για παράδειγμα, λόγω ενεργοποίησης ελέγχου κινδύνου, οφειλών κ.λπ. Όταν είναι απενεργοποιημένο, οι επιχειρησιακές διεπαφές θα επιστρέφουν `403`.
- **Μην δημιουργείτε με απεριόριστη ταυτόχρονη εκτέλεση**: πρώτα λάβετε το στοχευόμενο `service_id` από τη σελιδοποιημένη λίστα υπηρεσιών και, στη συνέχεια, υποβάλετε αίτηση για κάθε στοιχείο σύμφωνα με τις επιχειρησιακές ανάγκες· όταν συναντάτε `duplication`, επαναχρησιμοποιήστε το υπάρχον Application.
