Συγκεντρώστε ανά ημερομηνία και API τον αριθμό αιτημάτων και την πραγματικά αφαιρεθείσα ποσότητα του τρέχοντος λογαριασμού, κατάλληλο για δημιουργία μηνιαίων αναφορών, διαγραμμάτων τάσεων και ανάλυση κόστους. Όταν χρειάζεται αποσφαλμάτωση ανά εγγραφή, χρησιμοποιήστε τη [λίστα εγγραφών κλήσεων](https://platform.acedata.cloud/documents/platform-usage-list), ενώ όταν χρειάζεστε πλήρεις λεπτομέρειες εκτός σύνδεσης, χρησιμοποιήστε την [εξαγωγή όγκου κλήσεων](https://platform.acedata.cloud/documents/platform-usage-export)。

Το εύρος ερωτήματος για εγγραφές κλήσεων και περιλήψεις χρέωσης είναι οι τελευταίες 60 ημέρες· τα σώματα αιτημάτων και αποκρίσεων διατηρούνται ξεχωριστά μόνο για τις τελευταίες 30 ημέρες. Η λήξη των σωμάτων δεν αλλάζει την πραγματική χρέωση, τη χρήση ή τα συγκεντρωτικά στατιστικά αυτής της εγγραφής.

## Προετοιμασία

1. Συνδεθείτε στην [πλατφόρμα AceDataCloud](https://platform.acedata.cloud)。
2. Δημιουργήστε ένα διακριτικό λογαριασμού στην [κονσόλα Account Token](https://platform.acedata.cloud/console/platform-tokens) και αποθηκεύστε το αμέσως。
3. Εάν χρειάζεται να περιορίσετε το εύρος, λάβετε το αντίστοιχο ID από τη [λίστα αιτήσεων υπηρεσίας](https://platform.acedata.cloud/documents/platform-application-list), τη [λίστα διαπιστευτηρίων API](https://platform.acedata.cloud/documents/platform-credential-list) ή τη [λίστα API](https://platform.acedata.cloud/documents/platform-api-list)。

Για πλήρεις οδηγίες διακριτικών, δείτε τη [διαχείριση διακριτικών λογαριασμού](https://platform.acedata.cloud/documents/platform-token)。Αυτή η διεπαφή χρησιμοποιεί Account Token και όχι επιχειρησιακό Credential。

```shell
export PLATFORM_TOKEN='你的账户令牌'
```

## Επισκόπηση διεπαφής

| Στοιχείο           | Περιεχόμενο                                                  |
| ----------------- | ----------------------------------------------------------- |
| Μέθοδος           | `GET`                                                       |
| URL               | `https://platform.acedata.cloud/api/v1/usage/apis/aggregate/` |
| Αυθεντικοποίηση   | `Authorization: Bearer ${PLATFORM_TOKEN}`                   |
| OAuth Scope       | `usage:read`（`platform:read` / `platform` μπορούν να το περιλαμβάνουν） |
| Εύρος δικαιωμάτων | Οι απλοί χρήστες περιορίζονται στη δική τους επί πληρωμή χρήση· οι διαχειριστές μπορούν να περάσουν `user_id` |

## Παράμετροι ερωτήματος

| Παράμετρος         | Τύπος             | Υποχρεωτικό | Προεπιλογή                                | Περιγραφή                                               |
| ----------------- | ---------------- | ---------- | ------------------------------------------ | ------------------------------------------------------ |
| `created_at_from` | date / datetime  | Όχι        | Η πρώτη ημέρα του τρέχοντος μήνα στην επιλεγμένη ζώνη ώρας | Ώρα έναρξης, προτεινόμενο όνομα παραμέτρου             |
| `created_at_to`   | date / datetime  | Όχι        | Τρέχουσα ώρα                               | Ώρα λήξης, προτεινόμενο όνομα παραμέτρου               |
| `timezone`        | string           | Όχι        | `UTC`                                      | Ζώνη ώρας IANA, π.χ. `Asia/Shanghai`· μη έγκυρες τιμές επιστρέφουν σε UTC |
| `service_id`      | UUID             | Όχι        | —                                          | Φιλτράρισμα ανά υπηρεσία· υποστηρίζει επαναλαμβανόμενη παράμετρο |
| `application_id`  | UUID             | Όχι        | —                                          | Φιλτράρισμα ανά Application· υποστηρίζει επαναλαμβανόμενη παράμετρο |
| `api_id`          | UUID             | Όχι        | —                                          | Φιλτράρισμα ανά API· υποστηρίζει επαναλαμβανόμενη παράμετρο |
| `credential_id`   | UUID             | Όχι        | —                                          | Φιλτράρισμα ανά διαπιστευτήριο API· υποστηρίζει επαναλαμβανόμενη παράμετρο |
| `include_models`  | boolean          | Όχι        | `false`                                    | Αν θα υπολογιστεί επιπλέον συγκέντρωση διαστάσεων μοντέλου· αυξάνει το κόστος ερωτήματος |
| `user_id`         | UUID             | Όχι        | Οι απλοί χρήστες περιορίζονται στον εαυτό τους· όταν ο διαχειριστής δεν το περνά, αφορά όλους τους λογαριασμούς | Μόνο οι διαχειριστές μπορούν να ορίσουν οποιονδήποτε λογαριασμό |

Τα `start_time` / `end_time` μπορούν ακόμη να χρησιμοποιηθούν ως συμβατά ψευδώνυμα για παλιούς πελάτες· για νέες ενσωματώσεις χρησιμοποιήστε ομοιόμορφα τα `created_at_from` / `created_at_to`。Η μορφή ημερομηνίας του `created_at_to` περιλαμβάνει αυτή τη φυσική ημέρα, δηλαδή χρησιμοποιείται ως όριο τα μεσάνυχτα της επόμενης ημέρας。

## Παραδείγματα αιτημάτων

Ερώτημα για την ημερήσια/ανά API συγκέντρωση του τρέχοντος μήνα στην ώρα Πεκίνου, μαζί με τη διάσταση μοντέλου:

```shell
curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/aggregate/' \
  --data-urlencode 'timezone=Asia/Shanghai' \
  --data-urlencode 'include_models=true' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Ερώτημα για τη χρήση μίας εβδομάδας του καθορισμένου Application:

```shell
export APPLICATION_ID='你的 Application ID'

curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/aggregate/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'created_at_from=2026-09-01' \
  --data-urlencode 'created_at_to=2026-09-07' \
  --data-urlencode 'timezone=Asia/Shanghai' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Παράδειγμα Python:

```python
import os
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/usage/apis/aggregate/",
    headers={"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"},
    params={
        "created_at_from": "2026-09-01",
        "created_at_to": "2026-09-07",
        "timezone": "Asia/Shanghai",
        "include_models": "true",
    },
    timeout=30,
)
response.raise_for_status()
data = response.json()
print("requests:", data["requests"], "deducted:", data["total"])
for row in data["items"]:
    print(row["date"], row["api_id"], row["amount"])
```

## Παράδειγμα απόκρισης

```json
{
  "items": [
    {
      "date": "2026-09-01",
      "api_id": "00000000-0000-4000-8000-000000000001",
      "amount": 12.5
    }
  ],
  "total": 12.5,
  "apis": {
    "00000000-0000-4000-8000-000000000001": {
      "title": "Example API"
    }
  },
  "requests": 42,
  "models": [
    {
      "model": "example-model",
      "amount": 12.5,
      "requests": 42
    }
  ]
}
```

## Πεδία απόκρισης

| Πεδίο      | Περιγραφή                                                        |
| ---------- | ---------------------------------------------------------------- |
| `items`    | Ομαδοποιημένα ανά ημερομηνία στην επιλεγμένη ζώνη ώρας και `api_id`· κάθε γραμμή περιλαμβάνει `date`、`api_id`、`amount` |
| `total`    | Το άθροισμα του `deducted_amount` εντός του εύρους ερωτήματος    |
| `apis`     | Αντιστοίχιση από ID API σε σύνοψη τίτλου, για διευκόλυνση εμφάνισης των `items` |
| `requests` | Ο συνολικός αριθμός αιτημάτων εντός του εύρους ερωτήματος        |
| `models`   | Υπολογίζεται μόνο όταν `include_models=true`· κάθε στοιχείο περιλαμβάνει `model`、`amount`、`requests` |

Η μονάδα ποσότητας εξαρτάται από το `service.unit` του σχετικού Application。Εάν το ερώτημα περιλαμβάνει υπηρεσίες με διαφορετικές μονάδες, διαχωρίστε πρώτα τα στατιστικά ανά `service_id` ή `application_id`, ώστε να αποφύγετε την άμεση σύγκριση ή πρόσθεση。

Όταν ο χρόνος λήξης δεν είναι μεγαλύτερος από τον χρόνο έναρξης, η διεπαφή επιστρέφει πλήρη κενή δομή: `items=[]`、`total=0`、`apis={}`、`requests=0`、`models=[]`。

## Σφάλματα και προτάσεις απόδοσης

| HTTP | `error`                 | Τρόπος χειρισμού                                      |
| ---- | ----------------------- | --------------------------------------------------- |
| 400  | `usage_history_expired` | Προσαρμόστε το χρονικό εύρος μετά το `available_from` της απόκρισης |
| 401  | `not_authenticated`     | Ελέγξτε το Account Token, μην χρησιμοποιείτε κατά λάθος επιχειρησιακό Credential |
| 403  | `permission_denied`     | Οι απλοί χρήστες δεν μπορούν να υποβάλουν ερώτημα για άλλους λογαριασμούς |

- Μην ενεργοποιείτε το `include_models` από προεπιλογή· ενεργοποιήστε το μόνο όταν η αναφορά χρειάζεται όντως διαχωρισμό μοντέλων。
- Για ερωτήματα μεγάλου εύρους, προτιμήστε να τα διαχωρίζετε ανά `service_id` ή `application_id`, αποφεύγοντας τόσο την ανάμειξη μονάδων όσο και τη μείωση του κόστους ερωτήματος。
- Οι ημερομηνίες χωρίς κλήσεις δεν συμπληρώνονται αυτόματα με μηδενικά· ο πελάτης πρέπει να συμπληρώνει τον άξονα ημερομηνιών πριν από τη σχεδίαση γραφήματος。
