[`@acedatacloud/sdk`](https://www.npmjs.com/package/@acedatacloud/sdk) είναι το επίσημο TypeScript / JavaScript SDK της Ace Data Cloud, που περιλαμβάνει όλες τις υπηρεσίες του `api.acedata.cloud` σε τυποποιημένες μεθόδους όπως `client.openai.chat.completions.create(...)`, `client.images.generate(...)`, `client.search.google(...)` κ.λπ., με ενσωματωμένη ροή SSE, επαναλήψεις με καθυστέρηση και τυποποιημένες εξαιρέσεις.

Μπορεί να χρησιμοποιηθεί σε Node.js, Deno, Bun και σύγχρονους περιηγητές (με bundler).

Διεύθυνση πηγαίου κώδικα και πακέτου:

- Αποθετήριο SDK: [https://github.com/AceDataCloud/SDK](https://github.com/AceDataCloud/SDK)
- npm SDK: [https://www.npmjs.com/package/@acedatacloud/sdk](https://www.npmjs.com/package/@acedatacloud/sdk)

## Εγκατάσταση

```bash
npm install @acedatacloud/sdk
# ή pnpm add / yarn add / bun add
```

Αν χρειάζεστε πληρωμή στο δίκτυο X402 (χωρίς διαδρομή API Token), εγκαταστήστε και ένα άλλο:

```bash
npm install @acedatacloud/x402-client ethers
```

Έξοδος ελέγχου έκδοσης καθαρού npm έργου:

```text
$ npm ls @acedatacloud/sdk
└── @acedatacloud/sdk@2026.504.2

$ node -e "console.log(require('@acedatacloud/sdk').AceDataCloud?.name)"
AceDataCloud
```

Επεξήγηση αποτελεσμάτων:

- Η έκδοση του πακέτου είναι `2026.504.2` (CalVer, 2η αναθεώρηση της 504ης ISO εβδομάδας του 2026).
- `AceDataCloud` είναι η κύρια κλάση για τη δημιουργία του πελάτη, προσβάσιμη από την προεπιλεγμένη εξαγωγή.

## Προετοιμασία API Token

Ανατρέξτε στο [SDK Επισκόπηση - Αίτηση API Token](https://platform.acedata.cloud/documents/acedatacloud-sdk#申请-api-token) για να αποκτήσετε το token, στη συνέχεια στο shell `export`:

```bash
export ACEDATACLOUD_API_TOKEN={token}
```

Κατά τη δημιουργία του πελάτη, αν δεν περάσετε το `apiToken`, το SDK θα διαβάσει αυτόματα τη μεταβλητή περιβάλλοντος `ACEDATACLOUD_API_TOKEN`. Αν έχετε ήδη αποθηκευμένο το `ACEDATACLOUD_API_KEY` στο περιβάλλον σας (σύμφωνα με τη συμφωνία του έργου), μπορείτε να το περάσετε ρητά: `new AceDataCloud({ apiToken: process.env.ACEDATACLOUD_API_KEY })`.

## Παράδειγμα 1: chat.completions (μη ροής)

```ts
import { AceDataCloud } from '@acedatacloud/sdk';

const client = new AceDataCloud();

const t0 = Date.now();
const res = await client.openai.chat.completions.create({
  model: 'gpt-4o-mini',
  messages: [
    { role: 'user', content: 'Reply with exactly: ADC_TS_SDK_OK' }
  ],
  max_tokens: 20,
  temperature: 0
});
console.log('elapsed_ms', Date.now() - t0);
console.log('id', res.id);
console.log('model', res.model);
console.log('content', res.choices[0].message.content);
console.log('usage', JSON.stringify(res.usage));
```

Αποτέλεσμα εκτέλεσης προγράμματος:

```text
elapsed_ms 2543
id chatcmpl-DldCcLvkTFaioST8e6SjOl0wJScQA
model gpt-4o-mini
content ADC_TS_SDK_OK
usage {"prompt_tokens":16,"completion_tokens":6,"total_tokens":22}
```

Επεξήγηση αποτελεσμάτων:

- `id chatcmpl-DldCcLvkTFaioST8e6SjOl0wJScQA` είναι το ID απόκρισης συμβατό με το OpenAI, το οποίο μπορείτε να βρείτε στην κονσόλα [ιστορικό χρήσης](https://platform.acedata.cloud/console/usages).
- `content ADC_TS_SDK_OK` είναι η σταθερή αναγνώριση που επιστρέφει το μοντέλο, αποδεικνύοντας ότι η απόκριση δεν έχει παραποιηθεί από το SDK.
- Μια ολοκλήρωση συνομιλίας καταναλώνει περίπου 22 tokens, με βάση την τιμή του gpt-4o-mini.
- Το SDK δηλώνει την απόκριση ως `Record<string, unknown>`, κατά την εκτέλεση είναι ένα JSON αντικείμενο, η πρόσβαση με τελείες όπως `.id` / `.choices[0].message.content` μπορεί να εκτελείται σε `.mjs`, Node REPL, Bun; σε αυστηρά έργα TypeScript μπορεί να χρειαστεί `(res as any).id` ή να απενεργοποιήσετε το `noImplicitAny` στο tsconfig.

## Παράδειγμα 2: chat.completions (SSE ροής)

Ανοίγοντας το `stream: true`, το `create` επιστρέφει έναν ασύγχρονο επαναληπτή, όπου κάθε καρέ είναι ένα `ChatCompletionChunk`.

```ts
import { AceDataCloud } from '@acedatacloud/sdk';

const client = new AceDataCloud();

const t0 = Date.now();
let firstChunkMs: number | null = null;
let chunks = 0;
const collected: string[] = [];

const stream = await client.openai.chat.completions.create({
  model: 'gpt-4o-mini',
  messages: [
    { role: 'user', content: 'Count from 1 to 5, separated by single spaces, no extra text.' }
  ],
  max_tokens: 20,
  stream: true
});

for await (const chunk of stream) {
  if (firstChunkMs === null) firstChunkMs = Date.now() - t0;
  chunks++;
  const delta = chunk.choices[0]?.delta?.content;
  if (delta) collected.push(delta);
}

console.log('total_elapsed_ms', Date.now() - t0);
console.log('first_chunk_ms', firstChunkMs);
console.log('chunks', chunks);
console.log('collected', collected.join('').trim());
```

Αποτέλεσμα εκτέλεσης προγράμματος:

```text
total_elapsed_ms 2616
first_chunk_ms 2481
chunks 13
collected 1 2 3 4 5
```

Επεξήγηση αποτελεσμάτων:

- Η καθυστέρηση του πρώτου καρέ 2481 ms είναι ο χρόνος που χρειάζεται το μοντέλο για να δημιουργήσει το πρώτο token; τα επόμενα 12 καρέ έφτασαν όλα εντός 135 ms.
- Τα 13 καρέ συνδυάζονται σε `"1 2 3 4 5"`, κάθε token σε ξεχωριστό καρέ + το τελευταίο καρέ με `finish_reason`.
- Η ροή δεν εξοικονομεί περισσότερα tokens από τη μη ροή, αλλά η καθυστέρηση του πρώτου χαρακτήρα μειώνεται σημαντικά, κατάλληλη για πραγματική UI.

## Παράδειγμα 3: images.generate (NanoBanana)

`client.images.generate({ provider: 'nano-banana', ... })` επιστρέφει άμεσα, **δεν χρειάζεται να περάσετε το `wait` παράμετρο** — το API NanoBanana είναι εγγενώς συγχρονισμένο.

```ts
import { AceDataCloud } from '@acedatacloud/sdk';

const client = new AceDataCloud();

const t0 = Date.now();
const img = await client.images.generate({
  provider: 'nano-banana',
  prompt: 'A minimalist logo of a yellow banana on a white background, flat design'
});
console.log('elapsed_ms', Date.now() - t0);
console.log('task_id', img.task_id);
console.log('trace_id', img.trace_id);
console.log('image_url', img.data[0].image_url);
```

Αποτέλεσμα εκτέλεσης προγράμματος:

```text
elapsed_ms 16634
task_id 8e4b44a6-5ece-46a4-9013-9e0c8aca2217
trace_id 9529e241-54fe-40da-98a2-871e14989fb5
image_url https://platform.cdn.acedata.cloud/nanobanana/331be1d3-3330-4196-bd1c-aa75717c549c.png
```

Επεξήγηση αποτελεσμάτων:

- `image_url` είναι η σταθερή διεύθυνση στο CDN, μπορεί να χρησιμοποιηθεί άμεσα `<img src />` ή να κατέβει.
- Στα 16.6 δευτερόλεπτα, ο περισσότερος χρόνος είναι η εκτίμηση του μοντέλου, το κόστος του τοπικού SDK είναι αμελητέο.
- `trace_id` είναι το ID αιτήματος που έχει ανατεθεί από την πλατφόρμα, αν υπάρξει πρόβλημα, δώστε αυτό το ID στην υποστήριξη για γρήγορη εντοπισμό.
- Για υπηρεσίες ασύγχρονης φύσης (Midjourney, Sora, Veo κ.λπ.) απαιτείται TaskHandle polling, δείτε [SDK Task Polling και Streaming Responses](https://platform.acedata.cloud/documents/sdk-tasks-and-streaming).

## Παράδειγμα 4: Τυποποιημένη διαχείριση σφαλμάτων

Το SDK θα ρίξει σφάλματα σε συγκεκριμένες υποκλάσεις (π.χ. `AuthenticationError` / `BadRequestError` / `RateLimitError` / `InternalServerError` / `APIConnectionError` κ.λπ.) ανάλογα με την κατάσταση HTTP, μπορείτε να χρησιμοποιήσετε το `instanceof` για ακριβή διακλάδωση.
```ts
import { AceDataCloud, AuthenticationError } from '@acedatacloud/sdk';

const bad = new AceDataCloud({ apiToken: 'definitely-not-a-real-token' });

try {
  await bad.openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [{ role: 'user', content: 'hi' }],
    max_tokens: 5
  });
} catch (err: any) {
  console.log('err_class', err.constructor.name);
  console.log('status', err.statusCode);
  console.log('code', err.code);
  console.log('instanceof AuthenticationError =', err instanceof AuthenticationError);
}
```

Το αποτέλεσμα της εκτέλεσης του προγράμματος:

```text
A. err_class AuthenticationError
A. status 401
A. code invalid_token
A. instanceof AuthenticationError = true
```

Επεξήγηση αποτελέσματος:

- 401 αυτόματα χαρτογραφείται σε `AuthenticationError`, ο επιχειρηματικός κώδικας μπορεί να χρησιμοποιήσει `instanceof` για ακριβή διακλάδωση.
- `code: invalid_token` προέρχεται από το PlatformGateway, διευκολύνοντας τη σύγκριση με τα αρχεία καταγραφής του backend.
- Ομοίως 429 → `RateLimitError`, 400 → `BadRequestError`, 5xx → `InternalServerError`.

## Παράδειγμα 5: Πολυμοντέλο δρομολόγηση

Ο ίδιος πελάτης μπορεί να αλλάξει ελεύθερα μεταξύ πολλών υπηρεσιών, αρκεί το όνομα του μοντέλου να είναι το ίδιο.

```ts
import { AceDataCloud } from '@acedatacloud/sdk';

const client = new AceDataCloud();

const MODELS = ['gpt-4o-mini', 'gemini-2.5-flash', 'deepseek-v3', 'grok-3-fast'];

for (const model of MODELS) {
  const t0 = Date.now();
  try {
    const r = await client.openai.chat.completions.create({
      model,
      messages: [{ role: 'user', content: 'Reply with exactly: ADC_OK' }],
      max_tokens: 5
    });
    console.log(model.padEnd(28), `${Date.now() - t0}ms`, `content="${r.choices[0].message.content}"`);
  } catch (err: any) {
    console.log(model.padEnd(28), `${Date.now() - t0}ms`, 'ERR', err.statusCode, err.code);
  }
}
```

Το αποτέλεσμα της εκτέλεσης του προγράμματος:

```text
gpt-4o-mini                  2189ms   content="ADC_OK"
gemini-2.5-flash             2569ms   content=""
deepseek-v3                  2047ms   content="ADC_OK"
grok-3-fast                  3598ms   content="ADC_OK"
```

Επεξήγηση αποτελέσματος:

- Ένας κώδικας, ένα token, καλύπτει τις υπηρεσίες μοντέλων OpenAI / Google / DeepSeek / xAI.
- Το `gemini-2.5-flash` αυτή τη φορά δεν επέστρεψε `ADC_OK`, είναι διαφορά στυλ εξόδου του μοντέλου — το SDK δεν έχει σιωπηλά απορρίψει τίποτα, μεταφέροντας πιστά τα λόγια του μοντέλου στην επιχείρηση.
- Οι τιμές χρεώνονται με βάση την πραγματική τιμή του token, η διαδρομή περνά μόνο μία φορά από το PlatformGateway.

## Παράδειγμα 6: Αναζήτηση Google

```ts
import { AceDataCloud } from '@acedatacloud/sdk';

const client = new AceDataCloud();

const t0 = Date.now();
const r = await client.search.google({
  query: 'Ace Data Cloud',
  resource: 'web'
});
const items = (r as any).organic ?? [];
console.log('elapsed_ms', Date.now() - t0);
console.log('organic_count', items.length);
items.slice(0, 2).forEach((it: any, i: number) => {
  console.log(`#${i + 1}`, it.title, '->', it.link);
});
```

Το αποτέλεσμα της εκτέλεσης του προγράμματος:

```text
elapsed_ms 2382
organic_count 10
#1 Ace Data Cloud -> https://platform.acedata.cloud/
#2 Ace Data Cloud - GitHub -> https://github.com/acedatacloud
```

Επεξήγηση αποτελέσματος:

- Μια αίτηση επιστρέφει 10 οργανικά αποτελέσματα, το όνομα πεδίου είναι `organic` (όχι `organic_results`).
- Η αναζήτηση περνά μέσω της υπηρεσίας [Serp](https://platform.acedata.cloud/services/serp), χρεώνεται ανά αίτηση.
- Ο ίδιος πελάτης μπορεί να κάνει chat και να αναζητήσει, ένα token είναι αρκετό.

## Επιλογές ρύθμισης

```ts
const client = new AceDataCloud({
  // Υποχρεωτικό ένα από τα δύο: ρητό token ή μεταβλητή περιβάλλοντος ACEDATACLOUD_API_TOKEN
  apiToken: process.env.MY_TOKEN,

  // Ρίζα διεύθυνσης API της πλατφόρμας, προεπιλογή https://api.acedata.cloud
  baseURL: 'https://api.acedata.cloud',

  // Ορισμένες υπηρεσίες (όπως τα μεταδεδομένα του dashboard) περνούν από το domain της πλατφόρμας
  platformBaseURL: 'https://platform.acedata.cloud',

  // Χρόνος υπέρβασης για μία αίτηση, σε χιλιοστά του δευτερολέπτου; προεπιλογή 300_000 (5 λεπτά)
  timeout: 300_000,

  // Αριθμός αυτόματων επαναλήψεων, προεπιλογή 2; συνθήκες επανάληψης: 408 / 409 / 429 / 5xx / σφάλματα δικτύου
  maxRetries: 2,

  // Προσαρμοσμένες κεφαλίδες αιτήματος
  defaultHeaders: { 'x-app': 'my-service/1.0' }
});
```

## Χρήση στον περιηγητή

`@acedatacloud/sdk` είναι πακέτο ESM + ISO (ισομορφικό), μπορεί να εισαχθεί απευθείας σε σύγχρονους περιηγητές με bundler. Σημείωση: **Μην σκληροκωδικοποιείτε το API Token στον κώδικα του frontend**. Συνιστώμενη προσέγγιση για το frontend:

1. Χρησιμοποιήστε τον [X402 `paymentHandler`](https://platform.acedata.cloud/documents/sdk-x402-payment) — το πορτοφόλι του χρήστη υπογράφει USDC ανά αίτηση, χωρίς ανάγκη για token.
2. Ή χρησιμοποιήστε το SDK στον δικό σας server, ο περιηγητής καλεί μόνο το backend σας.

## Προχωρημένο: Περιστροφή εργασιών και ροές απαντήσεων

- Υπηρεσίες τύπου εργασίας (Midjourney, Sora, Veo, Suno): χρησιμοποιήστε `TaskHandle` για περιστροφή, λεπτομέρειες μονάδας, υπέρβασης και επαναλήψεων δείτε [SDK περιστροφή εργασιών και ροές](https://platform.acedata.cloud/documents/sdk-tasks-and-streaming).
- Ροή chat: το παράδειγμα 2 αυτής της σελίδας έχει ήδη επιδείξει; η ροή ήχου / βίντεο υποστηρίζεται επίσης.

## Προχωρημένο: X402 πληρωμές hook

Εάν δεν θέλετε να ζητήσετε API Token και θέλετε να πληρώσετε ανά αίτηση στην αλυσίδα, μπορείτε να χρησιμοποιήσετε το `paymentHandler`:

```ts
import { AceDataCloud } from '@acedatacloud/sdk';
import { createX402PaymentHandler } from '@acedatacloud/x402-client';

const client = new AceDataCloud({
  paymentHandler: createX402PaymentHandler({
    network: 'base',
    evmProvider: (window as any).ethereum,  // Παροχέας EIP-1193, ή viem walletClient
    evmAddress: userAddress
  })
});
```

> `createX402PaymentHandler` στην πλευρά TypeScript δέχεται `{ network, evmProvider, evmAddress, preferScheme? }` (αλυσίδα EVM) ή `{ network: 'solana', solanaWallet }` (Solana). Στον server Node, εάν δεν υπάρχει `window.ethereum`, χρησιμοποιήστε το `createWalletClient` του viem (βασισμένο σε ιδιωτικό κλειδί) για να τυλίξετε έναν συμβατό με EIP-1193 παροχέα και να τον περάσετε εδώ; λεπτομέρειες και πραγματικά αποτελέσματα στην αλυσίδα δείτε [SDK + X402 πληρωμές hook](https://platform.acedata.cloud/documents/sdk-x402-payment).
