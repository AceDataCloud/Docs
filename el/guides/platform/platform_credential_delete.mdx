Διαγράψτε οριστικά ένα διαπιστευτήριο API. Μετά τη διαγραφή, **δεν μπορεί να ανακτηθεί αμέσως**, και όλες οι επιχειρηματικές διεπαφές που χρησιμοποιούν αυτό το Token θα λάβουν αμέσως `401`.

> ℹ️ Αυτή η διεπαφή ανήκει στο **API διαχείρισης πλατφόρμας AceDataCloud**, με ενιαίο πρόθεμα `https://platform.acedata.cloud/api/v1/`.

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                                          |
| --- | ------------------------------------------------------------------- |
| Μέθοδος  | `DELETE`                                                            |
| URL | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}` |
| Αυθεντικοποίηση  | ✅ Απαιτείται διακριτικό λογαριασμού                                                            |

Τα `/credentials/{id}` και `/credentials/{id}/` είναι και τα δύο διαθέσιμα προς το παρόν· τα παραδείγματα χρησιμοποιούν ομοιόμορφα τη μορφή χωρίς τελική κάθετο.

## Οδηγίες αυθεντικοποίησης (πώς να αποκτήσετε διακριτικό λογαριασμού)

Κεφαλίδα αιτήματος:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

Για τον τρόπο απόκτησης, δείτε [Διαχείριση διακριτικού λογαριασμού πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-token).

## Παράμετροι διαδρομής

| Παράμετρος              | Τύπος   | Υποχρεωτικό  | Περιγραφή        |
| --------------- | ---- | --- | --------- |
| `credential_id` | UUID | ✅   | ID του διαπιστευτηρίου προς διαγραφή |

## Παραδείγματα αιτήματος

### cURL

```shell
curl -X DELETE 'https://platform.acedata.cloud/api/v1/credentials/df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

cred_id = "df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6"
resp = requests.delete(
    f"https://platform.acedata.cloud/api/v1/credentials/{cred_id}",
    headers={"authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"},
    timeout=10,
)
assert resp.status_code == 204, resp.text
print("✅ 已删除")
```

### Node.js

```javascript
const credId = 'df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6'
const r = await fetch(`https://platform.acedata.cloud/api/v1/credentials/${credId}`, {
  method: 'DELETE',
  headers: { authorization: `Bearer ${process.env.PLATFORM_TOKEN}` },
})
console.log('status:', r.status) // 204
```

## Απόκριση

- **Επιτυχία**: `HTTP 204 No Content`, **χωρίς σώμα απόκρισης**.
- **Αποτυχία**: επιστρέφεται JSON σφάλματος, δείτε τον παρακάτω πίνακα.

## Χειρισμός σφαλμάτων

| HTTP | code                | Σημασία         |
| ---- | ------------------- | ---------- |
| 401  | `not_authenticated` | Λείπει διακριτικό λογαριασμού     |
| 403  | `permission_denied` | Αυτό το διαπιστευτήριο δεν ανήκει σε εσάς    |
| 404  | `not_found`         | Το διαπιστευτήριο δεν υπάρχει ή έχει διαγραφεί |

## Χρήσιμες συμβουλές

- **Η διαγραφή είναι μη αναστρέψιμη**——η πλατφόρμα δεν διατηρεί αντίγραφο του Token. Εάν απλώς υποπτεύεστε διαρροή αλλά θέλετε να διατηρήσετε τα δεδομένα παρακολούθησης, θα πρέπει να χρησιμοποιήσετε [Περιστροφή διαπιστευτηρίων API πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-credential-rotate) αντί για διαγραφή.
- **Η διαγραφή δεν επιστρέφει το όριο που έχει ήδη καταναλωθεί από αυτό το διαπιστευτήριο**. Το υπόλοιπο της Application αφαιρείται σε πραγματικό χρόνο βάσει κατανάλωσης και η διαγραφή διαπιστευτηρίου δεν επηρεάζει το λογιστικό υπόλοιπο.
- Μετά τη διαγραφή, μπορείτε να επιβεβαιώσετε ξανά τα εναπομείναντα διαπιστευτήρια μέσω της [Λίστας διαπιστευτηρίων API](https://platform.acedata.cloud/documents/platform-credential-list) σύμφωνα με το `application_id`.
- **Ελέγξτε πρώτα τους καλούντες πριν από μαζική εκκαθάριση**: η λίστα προς το παρόν δεν διαθέτει πεδίο τελευταίου χρόνου χρήσης· θα πρέπει να συνδυάσετε τις ρυθμίσεις ανάπτυξης και τα αρχεία κλήσεων για να επιβεβαιώσετε ότι το διαπιστευτήριο δεν χρησιμοποιείται πλέον και στη συνέχεια να τα διαγράψετε ένα προς ένα.
