---
title: "Λήψη λίστας Proxy κάτω από την υπηρεσία της πλατφόρμας AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Επιστρέφει σελιδοποιημένα τα τελικά σημεία Proxy που είναι προσαρτημένα σε αυτή την υπηρεσία μέσω Service UUID. Όταν υπάρχει μόνο alias, καλέστε πρώτα τις [λεπτομέρειες υπηρεσίας](https://platform.acedata.cloud/documents/platform-service-detail) για να λάβετε το `id`.

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                                                     |
| --- | ---------------------------------------------------------------------- |
| Μέθοδος  | `GET`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| Αυθεντικοποίηση  | Δημόσια, δεν απαιτείται διακριτικό λογαριασμού                                                              |
| Σελιδοποίηση  | `count` + `items`                                                      |

## Παράμετροι

| Παράμετρος                 | Θέση    | Υποχρεωτικό  | Περιγραφή                               |
| ------------------ | ----- | --- | -------------------------------- |
| `service_id`       | path  | Ναι   | Service UUID, δεν υποστηρίζεται alias           |
| `limit` / `offset` | query | Όχι   | Σελιδοποίηση                               |
| `ordering`         | query | Όχι   | Έκφραση ταξινόμησης Django· προτείνεται `rank` ή `-rank` |

```shell
export SERVICE_ID='你的 Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## Περιγραφή απόκρισης

Τα στοιχεία της λίστας σειριοποιούνται από το μοντέλο Proxy, και τα πεδία που έχουν επαληθευτεί online περιλαμβάνουν `id`, `service_id`, `title`, `endpoint`, `price`, `stage`, `rank`, `tags`, `metadata`, `document_id`, `service` και πεδία χρόνου.

- Το πεδίο επιχειρηματικής εισόδου είναι το `endpoint`, όχι το `path`.
- Το πεδίο τιμολόγησης είναι το `price`, όχι το `cost`.
- Όταν ο τύπος Service δεν είναι Proxy ή δεν έχει προσαρτημένο Proxy, επιστρέφονται κενά `items`.

Η δημόσια ενσωμάτωση βασίζεται μόνο στο `endpoint` και στις δημοσιευμένες δυνατότητες, και δεν πρέπει να βασίζεται σε μη δημοσιευμένες λεπτομέρειες υλοποίησης.
