Διαβάστε τους δημόσιους διακόπτες λειτουργιών και τον προσδιορισμό χώρας/περιοχής στο τρέχον περιβάλλον αιτήματος. Είναι κατάλληλο για την απόφαση εμφάνισης λειτουργιών κατά την εκκίνηση του frontend· δεν αφορά την επωνυμία του ιστότοπου, τα στοιχεία επικοινωνίας ή τον κατάλογο ανακοινώσεων.

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                              |
| --- | ----------------------------------------------- |
| Μέθοδος  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Αυθεντικοποίηση  | Δημόσιο· όταν μεταφέρεται κατάσταση σύνδεσης, ορισμένοι διακόπτες λειτουργιών μπορεί να υπολογίζονται ανά χρήστη                          |

## Παράμετροι ερωτήματος και κεφαλίδες αιτήματος

| Όνομα                    | Θέση     | Περιγραφή                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | Διψήφιος κωδικός χώρας ASCII· χρησιμοποιείται για την παράκαμψη της χώρας εμφάνισης στην απόκριση, χωρίς να αλλάζει την αξιολόγηση ασφαλείας του διακομιστή |
| `features`            | query  | Έκφραση παράκαμψης διακόπτη λειτουργίας· ισχύει μόνο για διακόπτες που επιτρέπεται να παρακαμφθούν από τον πελάτη ή για υπερδιαχειριστές        |
| `X-Feature-Overrides` | header | Πηγή παράκαμψης ίδια με το `features`                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## Πραγματική δομή απόκρισης

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| Πεδίο         | Τύπος            | Περιγραφή                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Οι διακόπτες λειτουργιών που είναι ορατοί στο τρέχον αίτημα· τα κλειδιά αλλάζουν ανάλογα με τη διαμόρφωση της πλατφόρμας και ο πελάτης θα πρέπει να τα διαβάζει όπως απαιτείται και να ορίζει ασφαλείς προεπιλεγμένες τιμές για κλειδιά που λείπουν |
| `country`  | string / null | Κωδικός χώρας με πεζά γράμματα· μπορεί να είναι `null` όταν δεν είναι δυνατή η αναγνώριση                     |

Μην ανακτάτε από αυτήν τη διεπαφή το όνομα του ιστότοπου, το CDN, το νόμισμα, τη γλώσσα, τα στοιχεία επικοινωνίας εξυπηρέτησης πελατών ή τις ανακοινώσεις· αυτά τα πεδία δεν ανήκουν στο τρέχον συμβόλαιο απόκρισης.

## Συστάσεις χρήσης

- Οι διακόπτες λειτουργιών υπολογίζονται ανά χρήστη, αποτύπωμα και περιβάλλον ιστότοπου· μην μοιράζεστε μακροπρόθεσμα την προσωρινή μνήμη μεταξύ χρηστών.
- Το `country` που παρέχεται από τον πελάτη επηρεάζει μόνο την τιμή επιστροφής και δεν παρακάμπτει τις πολιτικές περιοχής ή ασφάλειας του διακομιστή.
- Οι μη αναγνωρισμένες παράμετροι query αγνοούνται· χρησιμοποιείτε μόνο τις παραμέτρους που αναφέρονται σε αυτήν τη σελίδα.
