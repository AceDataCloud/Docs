---
title: "Λήψη διαμόρφωσης λειτουργίας της πλατφόρμας AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Διαβάζει τους δημόσιους διακόπτες λειτουργιών και τον προσδιορισμό χώρας/περιοχής στο πλαίσιο του τρέχοντος αιτήματος. Είναι κατάλληλο για τον καθορισμό του αν θα εμφανίζονται λειτουργίες κατά την εκκίνηση του frontend· δεν αφορά την επωνυμία του ιστότοπου, τα στοιχεία επικοινωνίας ή τον κατάλογο ανακοινώσεων.

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                              |
| --- | ----------------------------------------------- |
| Μέθοδος  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Αυθεντικοποίηση  | Δημόσια· όταν μεταφέρεται κατάσταση σύνδεσης, ορισμένοι διακόπτες λειτουργιών ενδέχεται να υπολογίζονται ανά χρήστη                          |

## Παράμετροι ερωτήματος και κεφαλίδες αιτήματος

| Όνομα                    | Θέση     | Περιγραφή                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | Έκφραση παράκαμψης διακοπτών λειτουργιών· ισχύει μόνο για διακόπτες που επιτρέπουν παράκαμψη από τον πελάτη ή για υπερδιαχειριστές |
| `X-Feature-Overrides` | header | Πηγή παράκαμψης ίδια με το `features`           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## Πραγματική δομή απόκρισης

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| Πεδίο         | Τύπος            | Περιγραφή                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Οι διακόπτες λειτουργιών που είναι ορατοί στο τρέχον αίτημα· τα κλειδιά αλλάζουν ανάλογα με τη διαμόρφωση της πλατφόρμας και ο πελάτης θα πρέπει να τα διαβάζει όπως απαιτείται και να ορίζει ασφαλείς προεπιλεγμένες τιμές για κλειδιά που λείπουν |
| `region`   | string / null | Κωδικός χώρας ή περιοχής που ανιχνεύεται βάσει της IP του αιτήματος, με πεζά γράμματα· είναι `null` όταν δεν μπορεί να αναγνωριστεί        |

Μην διαβάζετε από αυτήν τη διεπαφή το όνομα του ιστότοπου, το CDN, το νόμισμα, τη γλώσσα, τα στοιχεία επικοινωνίας εξυπηρέτησης πελατών ή τις ανακοινώσεις· αυτά τα πεδία δεν ανήκουν στο τρέχον συμβόλαιο απόκρισης.

## Προτάσεις χρήσης

- Οι διακόπτες λειτουργιών υπολογίζονται ανά χρήστη, αποτύπωμα και πλαίσιο ιστότοπου· μην μοιράζεστε μακροπρόθεσμα την προσωρινή αποθήκευση μεταξύ χρηστών.
- Η επιλογή του επιλογέα περιοχής αποθηκεύεται μόνο στο frontend· κατά την εμφάνιση, χρησιμοποιήστε κατά προτεραιότητα την ήδη επιλεγμένη περιοχή, διαφορετικά χρησιμοποιήστε το `region` αυτής της διεπαφής. Αυτή η διεπαφή δεν δέχεται παραμέτρους παράκαμψης περιοχής.
- Οι μη αναγνωρισμένες παράμετροι query θα αγνοηθούν· χρησιμοποιείτε μόνο τις παραμέτρους που αναφέρονται σε αυτήν τη σελίδα.
