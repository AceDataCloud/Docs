Ανακτήστε πλήρεις πληροφορίες για μία μεμονωμένη υπηρεσία μέσω ID υπηρεσίας (UUID) ή ψευδωνύμου (alias)—τα πεδία που επιστρέφονται είναι πληρέστερα από τη [Λήψη λίστας υπηρεσιών πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-service-list), και επιπλέον επεκτείνονται συσχετισμένα αντικείμενα όπως `apis`, `proxies`, `datasets`, `packages`. Κατάλληλο για σενάρια όπως σελίδες λεπτομερειών υπηρεσίας, σελίδες σύγκρισης τιμών, περιγραφές εργαλείων Agent κ.λπ.

> ℹ️ Αυτή η διεπαφή ανήκει στο **API διαχείρισης πλατφόρμας AceDataCloud**, με ενιαίο πρόθεμα `https://platform.acedata.cloud/api/v1/`。Για το πλήρες ευρετήριο διεπαφών, δείτε τη [Λήψη λίστας εγγράφων πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list)。

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                                   |
| --- | ------------------------------------------------------------- |
| Μέθοδος  | `GET`                                                         |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}` |
| Αυθεντικοποίηση  | ❌ Δημόσιο                                                          |

Τα `/services/{id}` και `/services/{id}/` είναι επί του παρόντος και τα δύο διαθέσιμα·τα παραδείγματα χρησιμοποιούν ενιαία τη μορφή χωρίς τελική κάθετο.

## Περιγραφή αυθεντικοποίησης

Αυτή η διεπαφή είναι πλήρως δημόσια. **Ωστόσο, μετά την προσθήκη διακριτικού λογαριασμού, το πεδίο `applied` στην απόκριση θα αντικατοπτρίζει την πραγματική κατάσταση αίτησης του τρέχοντος λογαριασμού**, διαφορετικά θα είναι πάντα `false`.

Για τον τρόπο λήψης διακριτικού λογαριασμού, δείτε τη [Διαχείριση διακριτικών λογαριασμού πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-token)。

## Παράμετροι διαδρομής

| Παράμετρος           | Τύπος            | Υποχρεωτικό  | Περιγραφή                                                    |
| ------------ | ------------- | --- | ----------------------------------------------------- |
| `service_id` | UUID / string | ✅   | ID υπηρεσίας (UUID) ή ψευδώνυμο (`midjourney`、`openai`、`webextrator` κ.λπ.) |

## Παραδείγματα αιτήματος

### cURL

```shell
# 按 UUID 查询
curl 'https://platform.acedata.cloud/api/v1/services/8efa1d83-9b75-4562-b44a-af95ce563d05' \
  -H 'accept: application/json'

# 按 alias 查询
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json'

# 带账户令牌看 applied 状态
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

resp = requests.get(
    "https://platform.acedata.cloud/api/v1/services/midjourney",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
svc = resp.json()
print(f"服务: {svc['title']} ({svc['alias']})")
print(f"已申请: {svc['applied']}, 免费额度: {svc['free_amount']} {svc['unit']}")
print(f"API 数: {len(svc['apis'])}, 套餐数: {len(svc['packages'])}")
for pkg in svc["packages"]:
    print(f"  ¥{pkg['price']:>7.2f}  ->  {pkg['amount']} {svc['unit']}")
```

### Node.js

```javascript
const r = await fetch('https://platform.acedata.cloud/api/v1/services/midjourney', {
  headers: { accept: 'application/json' },
})
const svc = await r.json()
console.log(`${svc.title} - 套餐 ${svc.packages.length} 个 - API ${svc.apis.length} 个`)
```

## Περιγραφή πεδίων απόκρισης

Η διεπαφή λεπτομερειών, πέρα από όλα τα πεδία της [διεπαφής λίστας](https://platform.acedata.cloud/documents/platform-service-list), επεκτείνει επιπλέον:

| Πεδίο         | Τύπος    | Περιγραφή                                                            |
| ---------- | ----- | ------------------------------------------------------------- |
| `apis`     | array | Πλήρης λίστα συσχετισμένων αντικειμένων API (κάθε εγγραφή περιέχει `id`、`name`、`title`、`path`、`stage`、`cost`) |
| `proxies`  | array | Πλήρης λίστα συσχετισμένων αντικειμένων Proxy                                              |
| `datasets` | array | Συσχετισμένα σύνολα δεδομένων (εάν `type=Dataset`)                                      |
| `packages` | array | Λίστα πακέτων, περιέχει `type` (`Usage`/`Period`)、`price`、`amount`、`duration`   |

Για τους ορισμούς των υπόλοιπων πεδίων, δείτε [Λήψη λίστας υπηρεσιών πλατφόρμας AceDataCloud → Περιγραφή πεδίων απόκρισης](https://platform.acedata.cloud/documents/platform-service-list)。

## Χειρισμός σφαλμάτων

| HTTP | code        | Σημασία                            |
| ---- | ----------- | ----------------------------- |
| 404  | `not_found` | Το `service_id` (UUID ή alias) δεν υπάρχει |
| 500  | —           | Συνήθως οφείλεται σε λανθασμένη προσθήκη κάθετου στο τέλος του URL·αφαιρέστε την και δοκιμάστε ξανά          |

## Χρήσιμες συμβουλές

- **`alias` > `UUID`**：Η ενσωμάτωση του `alias` (π.χ. `midjourney`) απευθείας στον κώδικα είναι πιο σταθερή·το UUID αλλάζει κατά τη μετεγκατάσταση περιβάλλοντος.
- **Το πεδίο `apis` δεν περιέχει ορισμούς OpenAPI**：Το πλήρες OpenAPI 3.0 Schema βρίσκεται στη διεπαφή [Λήψη λεπτομερειών API πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-api-detail)。
- **Λήψη των «πλήρων δυνατοτήτων» μιας υπηρεσίας**：Χρησιμοποιήστε αυτή τη διεπαφή για να λάβετε το `api_ids`, έπειτα καλέστε διαδοχικά το `/apis/{api_id}` για να λάβετε λεπτομέρειες.
- **Εάν `applied=true`**，μπορείτε απευθείας να [δημιουργήσετε διαπιστευτήρια API](https://platform.acedata.cloud/documents/platform-credential-create) για να λάβετε το 32ψήφιο Token που απαιτείται για την κλήση της επιχειρησιακής διεπαφής, χωρίς να χρειάζεται νέα αίτηση.
