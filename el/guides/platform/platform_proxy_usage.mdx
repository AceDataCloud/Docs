Ερωτηθείτε για τις εγγραφές χρήσης του τρέχοντος λογαριασμού υπό υπηρεσίες τύπου Proxy. Για συνήθεις κλήσεις API, χρησιμοποιήστε τις [Εγγραφές κλήσεων API](https://platform.acedata.cloud/documents/platform-usage-list). Εάν δεν είστε βέβαιοι για τον τύπο της υπηρεσίας, μπορείτε πρώτα να δείτε το `type` στις [λεπτομέρειες υπηρεσίας](https://platform.acedata.cloud/documents/platform-service-detail).

## Προετοιμασία

1. Συνδεθείτε στην [πλατφόρμα AceDataCloud](https://platform.acedata.cloud).
2. Δημιουργήστε ένα διακριτικό λογαριασμού στην [κονσόλα Account Token](https://platform.acedata.cloud/console/platform-tokens) και αποθηκεύστε το αμέσως σε έναν διαχειριστή κωδικών πρόσβασης ή Secret Manager.
3. Ανοίξτε τη [σελίδα προσωπικού προφίλ](https://auth.acedata.cloud/user/profile), αντιγράψτε το UUID του τρέχοντος λογαριασμού και αποθηκεύστε το ως `USER_ID`. Μπορεί επίσης να χρησιμοποιηθεί το `user_id` στην απόκριση δημιουργίας διακριτικού λογαριασμού.
4. Λάβετε το `application_id` της υπηρεσίας τύπου Proxy από τη [λίστα αιτήσεων υπηρεσίας](https://platform.acedata.cloud/documents/platform-application-list). Όταν χρειάζεται φιλτράρισμα ανά τελικό σημείο Proxy, λάβετε το `proxy_id` από τη [λίστα Proxy υπό την υπηρεσία](https://platform.acedata.cloud/documents/platform-service-proxies).

Για την πλήρη περιγραφή των διακριτικών, δείτε τη [διαχείριση διακριτικών λογαριασμού](https://platform.acedata.cloud/documents/platform-token). Αυτή η διεπαφή χρησιμοποιεί Account Token και δεν χρησιμοποιεί το Credential που καλεί επιχειρησιακά API.

```shell
export PLATFORM_TOKEN='你的账户令牌'
export USER_ID='你的账户 UUID'
export APPLICATION_ID='你的 Proxy Application ID'
```

## Επισκόπηση διεπαφής

| Στοιχείο     | Περιεχόμενο                                            |
| ----------- | ----------------------------------------------------- |
| Μέθοδος     | `GET`                                                 |
| URL         | `https://platform.acedata.cloud/api/v1/usage/proxies/` |
| Αυθεντικοποίηση | `Authorization: Bearer ${PLATFORM_TOKEN}`             |
| Scope       | `usage:read`                                          |
| Σελιδοποίηση | `count` + `items`, 10 εγγραφές ανά σελίδα από προεπιλογή |

Όταν ο κάτοχος του Application υποβάλλει ερώτημα με `application_id`, ο διακομιστής θα συγχρονίσει πρώτα τις διαθέσιμες εγγραφές αυτού του Application και έπειτα θα επιστρέψει τη λίστα· επομένως, ο χρόνος απόκρισης μπορεί να είναι μεγαλύτερος από εκείνον μιας συνήθους λίστας χρήσης API. Οι εξουσιοδοτημένοι χρήστες μπορούν να διαβάσουν υπάρχουσες ορατές εγγραφές, αλλά δεν θα ενεργοποιήσουν συγχρονισμό από την πλευρά του κατόχου.

## Παράμετροι ερωτήματος

| Παράμετρος             | Τύπος      | Υποχρεωτικό για | Προεπιλογή     | Περιγραφή                                      |
| --------------------- | --------- | --------------- | -------------- | ---------------------------------------------- |
| `user_id`             | UUID      | υποχρεωτικό για συνήθεις χρήστες | —              | UUID τρέχοντος λογαριασμού· άλλος λογαριασμός επιστρέφει `403` |
| `application_id`      | UUID      | συνιστάται      | —              | Φιλτράρισμα κατά Proxy Application· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `proxy_id`            | UUID      | όχι             | —              | Φιλτράρισμα κατά τελικό σημείο Proxy· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `limit`               | integer   | όχι             | 10             | Αριθμός εγγραφών ανά σελίδα, μέγιστο 100       |
| `offset`              | integer   | όχι             | 0              | Μετατόπιση σελιδοποίησης                        |
| `ordering`            | string    | όχι             | `-created_at`  | Φθίνουσα σειρά κατά χρόνο δημιουργίας          |

Η τρέχουσα διεπαφή δεν υποστηρίζει άμεσο φιλτράρισμα κατά μοντέλο, κωδικό κατάστασης HTTP, Credential ή χρονικό εύρος, ούτε υποστηρίζει την παράμετρο `perspective` της διεπαφής χρήσης API. Μην προσθέτετε αυτές τις μη υποστηριζόμενες παραμέτρους στο αίτημα και υποθέτετε ότι έχουν τεθεί σε ισχύ.

## Παράδειγμα αιτήματος

```shell
curl --get 'https://platform.acedata.cloud/api/v1/usage/proxies/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=-created_at' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Παράδειγμα σελιδοποίησης Python:

```python
import os
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/usage/proxies/",
    headers={"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"},
    params={
        "user_id": os.environ["USER_ID"],
        "application_id": os.environ["APPLICATION_ID"],
        "limit": 100,
    },
    timeout=60,
)
response.raise_for_status()
data = response.json()

for usage in data["items"]:
    print(usage["created_at"], usage["deducted_amount"], usage["remaining_amount"])
```

## Βασικά πεδία

| Πεδίο                    | Περιγραφή                                           |
| ------------------------ | --------------------------------------------------- |
| `user_id`                | Ο λογαριασμός που επιβαρύνεται για αυτή την χρέωση  |
| `actor_user_id`          | Ο πραγματικός καλών· οι παλιές εγγραφές μπορεί να είναι κενές |
| `application_id`         | Το Proxy Application που δημιούργησε αυτή την εγγραφή |
| `proxy_id`               | Το αντίστοιχο τελικό σημείο Proxy                   |
| `credential_id`          | Συσχετισμένο ID διαπιστευτηρίου· οι παλιές εγγραφές μπορεί να είναι κενές |
| `used_amount`            | Η χρήση της αρχικής εγγραφής· μπορεί να είναι κενή  |
| `deducted_amount`        | Το τελικό ποσό που αφαιρέθηκε πραγματικά            |
| `remaining_amount`       | Το υπόλοιπο διαθέσιμο ποσό του Application μετά τη χρέωση |
| `metadata`               | Δημόσια μεταδεδομένα· μπορεί να είναι κενά          |
| `service` / `credential` | Σύνοψη συσχετισμένου αντικειμένου για εύκολη εμφάνιση· μπορεί να είναι κενή όταν το συσχετισμένο αντικείμενο δεν υπάρχει |

Η μονάδα ποσού καθορίζεται από το `service.unit` του αντίστοιχου Application.

## Χειρισμός σφαλμάτων

| HTTP | Σημασία                         | Τρόπος χειρισμού                                      |
| ---- | ------------------------------- | ----------------------------------------------------- |
| 401  | Το διακριτικό λογαριασμού λείπει ή δεν είναι έγκυρο | Ελέγξτε το Account Token, μην χρησιμοποιήσετε κατά λάθος επιχειρησιακό Credential |
| 403  | Δεν υπάρχει δικαίωμα προβολής των εγγραφών στο αίτημα | Χρησιμοποιήστε Application που ανήκει στον τρέχοντα λογαριασμό, αφαιρέστε μη εξουσιοδοτημένο `user_id` |
| 5xx  | Ο συγχρονισμός ή το ερώτημα απέτυχε προσωρινά | Διατηρήστε τις συνθήκες φιλτραρίσματος και επαναλάβετε με εκθετική αναμονή· σε συνεχή αποτυχία, δώστε στους υπεύθυνους υποστήριξης το Application ID και τον χρόνο |
