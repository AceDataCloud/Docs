Το [LobeChat](https://lobehub.com/) είναι ένας ανοιχτού κώδικα AI client που υποστηρίζει plugins, βάσεις γνώσης και αυτο-φιλοξενία, και μπορεί να χρησιμοποιηθεί online ή να αναπτυχθεί με Docker. Υποστηρίζει προσαρμοσμένα συμβατά με OpenAI endpoints, επομένως μπορεί να συνδεθεί με το Ace Data Cloud. Αυτό το άρθρο παρουσιάζει τη διαδικασία διαμόρφωσης.

## Διαδικασία αίτησης

Για να συνδέσετε το Ace Data Cloud στο LobeChat, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications), αποκτήστε το API Token σας και κρατήστε το για μελλοντική χρήση.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε συνδεθεί ή εγγραφεί ακόμη, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης όπου θα σας προσκαλέσει να εγγραφείτε και να συνδεθείτε. Μετά τη σύνδεση και την εγγραφή, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση θα δοθεί δωρεάν πίστωση, ώστε να μπορείτε να δοκιμάσετε δωρεάν τις υπηρεσίες μοντέλων του Ace Data Cloud.

## Διαμόρφωση του Ace Data Cloud

Μεταβείτε στις **Ρυθμίσεις εφαρμογής → Γλωσσικά μοντέλα** του LobeChat, βρείτε την κάρτα **OpenAI** και ενεργοποιήστε την, συμπληρώνοντας:

| Πεδίο       | Τιμή                              | Περιγραφή                         |
| -------- | ------------------------------ | -------------------------- |
| API Key  | Το Ace Data Cloud Token σας        | Token που αντιγράφηκε από την κονσόλα               |
| Διεύθυνση API proxy | `https://api.acedata.cloud/v1` | **Πρέπει να τελειώνει με `/v1`**           |
| Λειτουργία αιτήματος client  | Ενεργοποίηση                             | Άμεση σύνδεση από τον browser, το Key δεν περνά από τον server του LobeChat |

![Διεπαφή διαμόρφωσης LobeChat OpenAI Provider](https://cdn.acedata.cloud/629ef9d3084a.png)

> Όταν χρησιμοποιείτε το Chat Completions API, διατηρήστε το Responses API Specification απενεργοποιημένο.

Το LobeChat δεν προσθέτει αυτόματα το `/v1` στο Base URL· η διαδρομή αιτήματος είναι απευθείας `{Διεύθυνση API proxy}/chat/completions`:

| Διεύθυνση API proxy                              | Πραγματικό αίτημα                                                   | Αποτέλεσμα                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | Σωστό                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | Επίσης λειτουργεί                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (δεν υπάρχει `/v1` κάτω από το `/openai`) |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404 (λείπει το `/v1`)             |

Το LobeChat καλεί από προεπιλογή το `/v1/models` για αυτόματη ανάκτηση μοντέλων. Όταν το Ace Data Cloud επιστρέφει πολλά μοντέλα, η διεπαφή μπορεί να γίνει πολύ μεγάλη· συνιστάται να συμπληρώσετε χειροκίνητα ένα allow list στο «Λίστα μοντέλων → Προσαρμοσμένα ονόματα μοντέλων», διαχωρίζοντάς τα με αγγλικά κόμματα. Αν χρειάζεστε προσαρμοσμένο εμφανιζόμενο όνομα, μπορείτε να χρησιμοποιήσετε `=`, με μορφή `MODEL_ID=εμφανιζόμενο όνομα`.

## Επιλογή μοντέλου

Ο κατάλογος μοντέλων θα ενημερώνεται συνεχώς. Δώστε προτεραιότητα στη λίστα μοντέλων που φορτώνεται αυτόματα από τον client· όταν χρειάζεται χειροκίνητη συμπλήρωση, ζητήστε πρώτα `GET https://api.acedata.cloud/v1/models` για να λάβετε τα τρέχοντα model ID και έπειτα επιλέξτε ανάλογα με τις δυνατότητες context, εικόνων και κλήσης εργαλείων που υποστηρίζει ο client.

## Επαλήθευση σύνδεσης

Αν δεν είστε βέβαιοι αν το πρόβλημα βρίσκεται στο LobeChat ή στο δίκτυο, μπορείτε πρώτα να επαληθεύσετε απευθείας το endpoint με curl (αντικαταστήστε το `{token}` με το Token σας):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Η επιστροφή ενός συμβατού με OpenAI αντικειμένου `chat.completion` σημαίνει ότι τόσο το Token όσο και το endpoint είναι έτοιμα· αν επιστραφεί `HTTP 403 used_up`, αυτό σημαίνει ότι το Token είναι έγκυρο αλλά το υπόλοιπο δεν επαρκεί, και μπορείτε να κάνετε ανανέωση υπολοίπου στην [κονσόλα](https://platform.acedata.cloud/console/applications).

## Προχωρημένα: Αυτο-φιλοξενία με Docker

Αν θέλετε να αναπτύξετε μια ιδιωτική έκδοση για χρήση από την ομάδα, μπορείτε να την εκκινήσετε με μία εντολή Docker (αντικαταστήστε το `{token}` με το Token σας):

```bash
docker run -d \
  --name lobe-chat \
  -p 3210:3210 \
  -e OPENAI_API_KEY={token} \
  -e OPENAI_PROXY_URL=https://api.acedata.cloud/v1 \
  -e ACCESS_CODE=your-secret-password \
  -e OPENAI_MODEL_LIST="MODEL_ID" \
  lobehub/lobe-chat:latest
```

Ανοίξτε το `http://IP του server σας:3210`, εισαγάγετε το `ACCESS_CODE` και μπορείτε να το χρησιμοποιήσετε· τα μέλη της ομάδας δεν χρειάζεται να συμπληρώνουν το καθένα ξεχωριστά Key. Για πλήρη περιγραφή των environment variables όπως `OPENAI_API_KEY`, `OPENAI_PROXY_URL`, `OPENAI_MODEL_LIST` που χρησιμοποιούνται παραπάνω, ανατρέξτε στην [τεκμηρίωση environment variables παρόχων μοντέλων του LobeChat](https://lobehub.com/docs/self-hosting/environment-variables/model-provider). Αν χρησιμοποιείτε nginx reverse proxy με HTTPS, φροντίστε να προσθέσετε `proxy_buffering off;`, διαφορετικά οι streaming αποκρίσεις θα αποθηκεύονται σε buffer. Για περισσότερες μορφές ανάπτυξης, ανατρέξτε στο [εισαγωγικό εγχειρίδιο αυτο-φιλοξενίας του LobeChat](https://lobehub.com/docs/self-hosting/start) και στην [ανάπτυξη με Docker Compose](https://lobehub.com/docs/self-hosting/platform/docker-compose).

## Συχνές ερωτήσεις

### Εμφανίζεται 404 Not Found

Συνήθως η διεύθυνση API proxy έχει γραφτεί ως `.../openai/v1` ή λείπει το `/v1`. Αλλάξτε τη σε `https://api.acedata.cloud/v1`.

### Η λίστα μοντέλων είναι κενή

Ενεργοποιήστε τον διακόπτη «Λειτουργία αιτήματος client»· ή συμπληρώστε χειροκίνητα το allow list μοντέλων στα «Προσαρμοσμένα ονόματα μοντέλων».

### Εμφανίζεται 401 Unauthorized

Επιβεβαιώστε ότι στο API Key έχετε επικολλήσει το Token του Ace Data Cloud (χωρίς πρόθεμα `Bearer` και χωρίς επιπλέον κενά), και ότι η εφαρμογή στην οποία ανήκει διαθέτει επαρκές υπόλοιπο.
