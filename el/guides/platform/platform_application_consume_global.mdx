title: "Ρύθμιση κοινής χρήσης καθολικού υπολοίπου για το AceDataCloud Application"

Ρυθμίστε το `allow_consume_global`. Αφού ενεργοποιηθεί, τα επιλέξιμα Application με χρέωση βάσει χρήσης μπορούν να συνεχίσουν να χρησιμοποιούν το καθολικό υπόλοιπο του λογαριασμού όταν το δικό τους υπόλοιπο είναι ανεπαρκές.

## Προετοιμασία

- Δημιουργήστε και αποθηκεύστε με ασφάλεια το [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Αποκτήστε το `application_id` του Application που σας ανήκει από τη [λίστα αιτήσεων υπηρεσιών](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='你的账户令牌'
export APPLICATION_ID='你的 Application ID'
```

## Επισκόπηση διεπαφής

| Στοιχείο    | Περιεχόμενο                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------- |
| Μέθοδος   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Επαλήθευση   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

Σε περίπτωση επιτυχίας επιστρέφεται το ενημερωμένο αντικείμενο Application. Χρησιμοποιήστε ως αναφορά το `allow_consume_global` στην απόκριση, αντί να υποθέσετε ότι η τιμή του αιτήματος αποθηκεύτηκε οπωσδήποτε.

> Τα Application τύπου `Period` δεν επιτρέπεται να καταναλώνουν καθολικό υπόλοιπο. Ακόμη και αν ζητηθεί `true`, ο διακομιστής θα διατηρήσει αυτό το πεδίο ως `false`.

## Διαχείριση σφαλμάτων

- `401`: Το Account Token είναι μη έγκυρο ή λείπει.
- `403`: Ο τρέχων λογαριασμός δεν είναι ο ιδιοκτήτης αυτού του Application.
- `404`: Το Application ID δεν υπάρχει.

Η είσοδος για φόρτιση του καθολικού υπολοίπου και τα διαθέσιμα πακέτα βασίζονται στην κονσόλα της πλατφόρμας και στα πραγματικά πακέτα που επιστρέφονται από τη [δημιουργία παραγγελίας](https://platform.acedata.cloud/documents/platform-order-create)· μην υποθέτετε ότι υπάρχει πακέτο τύπου `Wallet`.
