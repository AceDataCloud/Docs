Ρυθμίστε το `allow_consume_global`. Μετά την ενεργοποίηση, τα επιλέξιμα Application χρέωσης βάσει χρήσης μπορούν να συνεχίσουν να χρησιμοποιούν το καθολικό υπόλοιπο του λογαριασμού όταν το δικό τους υπόλοιπο είναι ανεπαρκές.

## Προετοιμασία

- Δημιουργήστε και αποθηκεύστε με ασφάλεια το [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Λάβετε το `application_id` του οποίου είστε κάτοχος από τη [λίστα αιτήσεων υπηρεσίας](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='你的账户令牌'
export APPLICATION_ID='你的 Application ID'
```

## Επισκόπηση διεπαφής

| Στοιχείο    | Περιεχόμενο                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------- |
| Μέθοδος   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Πιστοποίηση   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

Σε περίπτωση επιτυχίας επιστρέφεται το ενημερωμένο αντικείμενο Application. Λάβετε ως έγκυρο το `allow_consume_global` στην απόκριση, αντί να υποθέσετε ότι η τιμή του αιτήματος αποθηκεύτηκε οπωσδήποτε.

> Application τύπου `Period` δεν επιτρέπεται να καταναλώνουν καθολικό υπόλοιπο. Ακόμη και αν ζητηθεί `true`, ο διακομιστής θα διατηρήσει αυτό το πεδίο ως `false`.

## Χειρισμός σφαλμάτων

- `401`: Το Account Token είναι άκυρο ή λείπει.
- `403`: Ο τρέχων λογαριασμός δεν είναι ο κάτοχος αυτού του Application.
- `404`: Το Application ID δεν υπάρχει.

Για την είσοδο ανανέωσης του καθολικού υπολοίπου και τα διαθέσιμα πακέτα, να βασίζεστε στην κονσόλα της πλατφόρμας και στα πραγματικά πακέτα που επιστρέφονται από τη [δημιουργία παραγγελίας](https://platform.acedata.cloud/documents/platform-order-create)· μην υποθέτετε ότι υπάρχει πακέτο τύπου `Wallet`.

## Εφαρμογές με εξουσιοδοτημένη υπερανάληψη

Όταν το πεδίο μόνο για ανάγνωση `allow_overdraft=true` μιας εφαρμογής χρέωσης βάσει χρήσης είναι ενεργό, η εφαρμογή μπορεί να συνεχίσει να χρεώνει από το δικό της υπόλοιπο, ακόμη και αν το υπόλοιπο γίνει αρνητικό, και δεν θα μεταβεί στον καθολικό λογαριασμό λόγω ανεπαρκούς υπολοίπου. Οι εφαρμογές χωρίς ενεργοποιημένη υπερανάληψη εξακολουθούν να ακολουθούν το `allow_consume_global`· μετά τη μετάβαση, το αν επιτρέπεται η υπερανάληψη εξαρτάται από τη ρύθμιση του καθολικού Application που χρεώνεται στην πράξη.
