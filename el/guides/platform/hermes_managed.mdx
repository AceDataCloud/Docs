title: "Ανάπτυξη Hermes"

Δημιουργήστε ανεξάρτητες παρουσίες κοντέινερ Hermes για κάθε Application. Από προεπιλογή χρησιμοποιείται βασική εικόνα σταθερής έκδοσης, διατηρώντας τις εγγενείς λειτουργίες· η πλατφόρμα παρέχει αγορά, ανανέωση, επίμονη αποθήκευση και διαχείριση ανάπτυξης.

## Δημιουργία και αγορά

1. Ανοίξτε το [Hermes Deployment](https://platform.acedata.cloud/services/hermes) και δημιουργήστε ένα Application.
2. Επιλέξτε ένα πακέτο διάρκειας στη σελίδα αγοράς και ολοκληρώστε την πληρωμή.
3. Επιστρέψτε στη σελίδα ρυθμίσεων, όπου μπορείτε να επιλέξετε το μοντέλο συνομιλίας της πλατφόρμας από την αναπτυσσόμενη λίστα και να δείτε την τρέχουσα τιμή του μοντέλου. Η πλατφόρμα θα δημιουργήσει ανεξάρτητα διαπιστευτήρια API για αυτή την παρουσία· μπορείτε επίσης να απενεργοποιήσετε την πρόσβαση της πλατφόρμας και να κάνετε ρυθμίσεις μόνοι σας στην εγγενή κονσόλα.
4. Επιλέξτε αυτόματη δημιουργία διαπιστευτηρίων πρόσβασης ή ορίστε τον δικό σας ισχυρό κωδικό πρόσβασης/Token· επιλέξτε A2A και EnvarPay όπως απαιτείται και, μετά την επιβεβαίωση, ξεκινήστε την ανάπτυξη. Τα διαπιστευτήρια πρόσβασης και τα διαπιστευτήρια API του μοντέλου είναι ανεξάρτητα μεταξύ τους.
5. Αφού η παρουσία είναι έτοιμη, αποκτήστε τη διεύθυνση πρόσβασης και τα διαπιστευτήρια σύνδεσης από τη σελίδα διαχείρισης.
6. Συνδεθείτε στην εγγενή κονσόλα για να ρυθμίσετε τα κανάλια. Εάν η πρόσβαση στο μοντέλο της πλατφόρμας απενεργοποιήθηκε κατά την ανάπτυξη, πρέπει επίσης να ρυθμίσετε μόνοι σας τον πάροχο μοντέλου και τα διαπιστευτήρια, ώστε να μπορεί να χρησιμοποιηθεί η συνομιλία.

Το τέλος ανάπτυξης χρεώνεται σύμφωνα με τη διάρκεια του πακέτου· οι συγκεκριμένες τιμές σε δολάρια ΗΠΑ και η διάρκεια υπόκεινται στη σελίδα αγοράς. Τα τέλη κλήσεων μοντέλου χρεώνονται ξεχωριστά· η αγορά διάρκειας ανάπτυξης δεν παρέχει δωρεάν πίστωση μοντέλου. Όταν είναι ενεργοποιημένη η πρόσβαση της πλατφόρμας, τα αποκλειστικά διαπιστευτήρια API παρέχουν μόνο τη διεπαφή συνομιλίας που αντιστοιχεί στο επιλεγμένο μοντέλο και οι κλήσεις χρεώνονται επιπλέον από το υπόλοιπο της πλατφόρμας σας. Κάθε Application αγοράζεται, ανανεώνεται και διαχειρίζεται ξεχωριστά.

## Κωδικοί πρόσβασης, διαπιστευτήρια και επακόλουθες ρυθμίσεις

Τα διαπιστευτήρια πρόσβασης ρυθμίζονται πριν από την πρώτη εκκίνηση. Η αυτόματη δημιουργία χρησιμοποιεί τυχαία διαπιστευτήρια, ο προσαρμοσμένος κωδικός πρόσβασης πρέπει να έχει τουλάχιστον 16 χαρακτήρες και το OpenClaw Token τουλάχιστον 32 χαρακτήρες. Τα πρόχειρα δεν αποθηκεύουν κωδικούς πρόσβασης· μετά την αλλαγή σελίδας μπορεί να χρειαστεί να τους εισαγάγετε ξανά. Μετά την ανάπτυξη, μόνο ο κάτοχος και οι διαχειριστές του Application μπορούν να δουν τα διαπιστευτήρια πρόσβασης.

Τα διαπιστευτήρια API μοντέλου κάθε παρουσίας δεν επαναχρησιμοποιούνται μεταξύ τους, η ισχύς τους παρατείνεται με την ανανέωση της ανάπτυξης και ανακαλούνται όταν διαγραφεί η παρουσία. Εάν το μοντέλο της πλατφόρμας δεν συνδέθηκε κατά την πρώτη ανάπτυξη, μπορείτε να επιλέξετε ένα μοντέλο πλατφόρμας στη σελίδα ρυθμίσεων αυτού του Application και να αναπτύξετε ξανά· η πλατφόρμα θα ενημερώσει το προεπιλεγμένο μοντέλο, διατηρώντας τις συνομιλίες και άλλες εγγενείς ρυθμίσεις. Στη συνέχεια, τροποποιήστε τα μοντέλα και τα κανάλια στην εγγενή κονσόλα· εάν επιλέξετε μοντέλο άλλης υπηρεσίας, προσαρμόστε πρώτα την εξουσιοδότηση της αντίστοιχης διεπαφής στη διαχείριση διαπιστευτηρίων της πλατφόρμας ή χρησιμοποιήστε τα αντίστοιχα διαπιστευτήρια. Η συνήθης επαν-ανάπτυξη δεν θα αντικαταστήσει τις εγγενείς ρυθμίσεις. Περιβάλλοντα ανάπτυξης που δεν έχουν περάσει την επαλήθευση δημοσίευσης θα απορρίπτουν προσωρινά νέες αναπτύξεις· επικοινωνήστε με την υποστήριξη.

## Προαιρετικά στοιχεία ανάπτυξης

Αφού επιλέξετε A2A, το πρότυπο ανάπτυξης θα εκκινήσει την εγγενή πύλη A2A του Hermes και θα παρέχει το διακριτικό κατόχου στη σελίδα διαχείρισης. Αφού επιλέξετε EnvarPay, θα εγκατασταθεί επιπλέον ανεξάρτητο κοντέινερ υπηρεσίας και επίμονο καθολικό, και πρέπει πρώτα να ενεργοποιηθεί το A2A. Το EnvarPay αρχικά διαθέτει μόνο διαπιστευτήρια πρόσβασης κατόχου, χωρίς ταυτότητα υπηρεσίας ή είσπραξης, και δεν θα χρεώνει ή αγοράζει αυτόματα για λογαριασμό σας. Καμία από τις δύο επιλογές δεν καταχωρεί αυτόματα την παρουσία στο Envar· για υπάρχουσες παρουσίες, μπορείτε να εισέλθετε στις ρυθμίσεις από τη σελίδα διαχείρισης και να αναπτύξετε ξανά μετά την ενεργοποίηση. Τα ενεργοποιημένα στοιχεία δεν μπορούν προς το παρόν να απενεργοποιηθούν σε αυτόν τον οδηγό.

## Έκδοση και δεδομένα

Η σελίδα ρυθμίσεων εμφανίζει την τρέχουσα δημοσιευμένη έκδοση εικόνας. Οι νέες παρουσίες χρησιμοποιούν την τρέχουσα δημοσιευμένη έκδοση της υπηρεσίας· οι υπάρχουσες παρουσίες δεν αντικαθίστανται αυτόματα με τις ενημερώσεις του καταλόγου. Η επαν-ανάπτυξη θα εφαρμόσει την τρέχουσα έκδοση της υπηρεσίας· δημιουργήστε πρώτα αντίγραφο ασφαλείας και επιβεβαιώστε τις απαιτήσεις αναβάθμισης της έκδοσης που χρησιμοποιείται.

Κάθε παρουσία παρέχει από προεπιλογή 1 CPU, όριο μνήμης 2 GiB και 10 GiB επίμονης αποθήκευσης. Η επανεκκίνηση διατηρεί τα δεδομένα της παρουσίας. Η ενεργή διαγραφή της ανάπτυξης ή η ανάκτηση μετά τη λήξη θα διαγράψει την αποθήκευση· εξαγάγετε εκ των προτέρων τα δεδομένα που χρειάζεται να διατηρήσετε.

## Ανανέωση και λήξη

Ανανεώστε στη σελίδα αγοράς του τρέχοντος Application και η περίοδος ισχύος θα παραταθεί σύμφωνα με τους υφιστάμενους κανόνες διάρκειας της πλατφόρμας. Μετά τη λήξη, το σημείο πρόσβασης αναστέλλεται και η ανανέωση εντός της περιόδου χάριτος αποκαθιστά την πρόσβαση· μετά την περίοδο χάριτος, η παρουσία και τα δεδομένα θα ανακτηθούν. Ισχύουν ο χρόνος λήξης, η κατάσταση χρέωσης και οι ειδοποιήσεις διαγραφής στη σελίδα διαχείρισης.

## Σύνδεση στη διεπαφή διαχείρισης

Στη σελίδα διαχείρισης ανάπτυξης, αντιγράψτε τη διεύθυνση Dashboard, το όνομα χρήστη `admin` και τον κωδικό πρόσβασης, και ανοίξτε τα για να συνδεθείτε. Οι πληροφορίες σύνδεσης παρέχονται μόνο στον κάτοχο αυτού του Application και στους διαχειριστές της πλατφόρμας. Τα μοντέλα, οι δεξιότητες και τα κανάλια ρυθμίζονται στην εγγενή διεπαφή Hermes.

## Συχνές ερωτήσεις

- **Γιατί η νέα παρουσία δεν μπορεί ακόμη να απαντήσει;** Η ολοκλήρωση της ανάπτυξης σημαίνει μόνο ότι το κοντέινερ είναι έτοιμο. Εάν η πρόσβαση στο μοντέλο της πλατφόρμας απενεργοποιήθηκε κατά την ανάπτυξη, πρέπει να επιλέξετε συμπληρωματικά μοντέλο πλατφόρμας στη σελίδα ρυθμίσεων και να αναπτύξετε ξανά ή να ρυθμίσετε μόνοι σας το μοντέλο και τα διαπιστευτήρια στην εγγενή διεπαφή.
- **Είναι προεγκατεστημένα πρόσθετα plugins ή model fallback;** Δεν προστίθενται από προεπιλογή· ρυθμίστε τα στην εγγενή διεπαφή ανάλογα με τις ανάγκες.
- **Πώς ενημερώνεται μια υπάρχουσα παρουσία;** Το αρχικό Application και η παραγγελία διατηρούνται και η επαν-ανάπτυξη χρησιμοποιεί την τρέχουσα έκδοση της υπηρεσίας· πριν από την αναβάθμιση, δημιουργήστε πρώτα αντίγραφο ασφαλείας των δεδομένων και ελέγξτε τη συμβατότητα της έκδοσης.
- **Τι να κάνω εάν η εκκίνηση αποτύχει;** Πρώτα ελέγξτε τα αρχεία καταγραφής ανάπτυξης και τα συμβάντα και ρυθμίστε το μοντέλο μόνο αφού επιβεβαιώσετε ότι η παρουσία είναι έτοιμη. Μην εκθέτετε τον κωδικό πρόσβασης και τα κλειδιά της παρουσίας σε δημόσια σχόλια ή στιγμιότυπα οθόνης.
