---
title: "Ανάπτυξη Hermes"
description: "Platform API guide - Ace Data Cloud"
---

Δημιουργήστε ανεξάρτητη παρουσία container Hermes για κάθε Application. Από προεπιλογή χρησιμοποιείται μια βασική εικόνα σταθερρής έκδοσης, διατηρώντας τις εγγενείς λειτουργίες· η πλατφόρμα παρέχει αγορά, ανανέωση, μόνιμη αποθήκευση και διαχείριση ανάπτυξης.

## Δημιουργία και αγορά

1. Ανοίξτε το [Hermes 部署](https://platform.acedata.cloud/services/hermes) και δημιουργήστε ένα Application.
2. Επιλέξτε ένα πακέτο διάρκειας στη σελίδα αγοράς και ολοκληρώστε την πληρωμή.
3. Επιστρέψτε στη σελίδα διαμόρφωσης, όπου μπορείτε να επιλέξετε ένα μοντέλο συνομιλίας της πλατφόρμας από την αναπτυσσόμενη λίστα και να δείτε την τρέχουσα τιμή του μοντέλου. Η πλατφόρμα θα δημιουργήσει ανεξάρτητα διαπιστευτήρια API για αυτή την παρουσία· μπορείτε επίσης να απενεργοποιήσετε την πρόσβαση πλατφόρμας και να διαμορφώσετε μόνοι σας στο εγγενές κονσόλα.
4. Επιλέξτε αυτόματη δημιουργία διαπιστευτηρίων πρόσβασης ή ορίστε δικό σας ισχυρό κωδικό πρόσβασης/Token και, μετά την επιβεβαίωση, ξεκινήστε την ανάπτυξη. Τα διαπιστευτήρια πρόσβασης και τα διαπιστευτήρια API του μοντέλου είναι ανεξάρτητα μεταξύ τους.
5. Αφού η παρουσία είναι έτοιμη, λάβετε τη διεύθυνση πρόσβασης και τα διαπιστευτήρια σύνδεσης από τη σελίδα διαχείρισης.
6. Συνδεθείτε στην εγγενή κονσόλα και διαμορφώστε τους δικούς σας παρόχους μοντέλων, κλειδιά και κανάλια.

Το κόστος ανάπτυξης χρεώνεται σύμφωνα με τη διάρκεια του πακέτου· οι συγκεκριμένες τιμές σε δολάρια ΗΠΑ και η διάρκεια υπόκεινται στη σελίδα αγοράς. Τα έξοδα κλήσεων μοντέλου χρεώνονται ξεχωριστά· η αγορά χρόνου ανάπτυξης δεν παρέχει δωρεάν μονάδες μοντέλου. Όταν είναι ενεργοποιημένη η πρόσβαση πλατφόρμας, τα αποκλειστικά διαπιστευτήρια API ανοίγουν μόνο τη διεπαφή συνομιλίας που αντιστοιχεί στο επιλεγμένο μοντέλο και οι κλήσεις χρεώνονται επιπλέον από το υπόλοιπο της πλατφόρμας σας. Κάθε Application αγοράζεται, ανανεώνεται και διαχειρίζεται ξεχωριστά.

## Κωδικοί πρόσβασης, διαπιστευτήρια και επακόλουθη διαμόρφωση

Τα διαπιστευτήρια πρόσβασης ορίζονται πριν από την πρώτη εκκίνηση. Η αυτόματη δημιουργία χρησιμοποιεί τυχαία διαπιστευτήρια, ο προσαρμοσμένος κωδικός πρόσβασης πρέπει να έχει τουλάχιστον 16 χαρακτήρες και το OpenClaw Token τουλάχιστον 32 χαρακτήρες. Τα πρόχειρα δεν αποθηκεύουν κωδικούς πρόσβασης· μετά την αλλαγή σελίδας μπορεί να χρειαστεί να τους εισαγάγετε ξανά. Μετά την ανάπτυξη, μόνο ο ιδιοκτήτης και οι διαχειριστές του Application μπορούν να δουν τα διαπιστευτήρια πρόσβασης.

Τα διαπιστευτήρια API μοντέλου κάθε παρουσίας δεν επαναχρησιμοποιούνται μεταξύ τους, η ισχύς τους παρατείνεται με την ανανέωση της ανάπτυξης και ανακαλούνται όταν διαγράφεται η παρουσία. Μετά την αρχικοποίηση της ανάπτυξης, τροποποιήστε τα μοντέλα και τα κανάλια στην εγγενή κονσόλα· εάν επιλέξετε μοντέλο άλλης υπηρεσίας, προσαρμόστε πρώτα την εξουσιοδότηση της αντίστοιχης διεπαφής στη διαχείριση διαπιστευτηρίων της πλατφόρμας ή χρησιμοποιήστε τα αντίστοιχα διαπιστευτήρια. Η συνήθης επαναφορά ανάπτυξης δεν θα αντικαταστήσει τις εγγενείς ρυθμίσεις. Περιβάλλοντα ανάπτυξης που δεν έχουν επαληθευτεί για δημοσίευση θα απορρίπτουν προσωρινά νέες αναπτύξεις· επικοινωνήστε με την υποστήριξη.

## Εκδόσεις και δεδομένα

Η σελίδα διαμόρφωσης εμφανίζει την τρέχουσα δημοσιευμένη έκδοση εικόνας. Οι νέες παρουσίες χρησιμοποιούν την τρέχουσα δημοσιευμένη έκδοση της υπηρεσίας· οι υπάρχουσες παρουσίες δεν αντικαθίστανται αυτόματα με ενημερώσεις του καταλόγου. Η επαναφορά ανάπτυξης θα εφαρμόσει την τρέχουσα έκδοση της υπηρεσίας· δημιουργήστε πρώτα αντίγραφο ασφαλείας και επιβεβαιώστε τις απαιτήσεις αναβάθμισης της έκδοσης που χρησιμοποιείτε.

Κάθε παρουσία παρέχει από προεπιλογή 1 CPU, όριο μνήμης 2 GiB και 10 GiB μόνιμης αποθήκευσης. Η επανεκκίνηση διατηρεί τα δεδομένα της παρουσίας. Η ενεργή διαγραφή της ανάπτυξης ή η ανάκτηση μετά τη λήξη θα διαγράψει την αποθήκευση· εξαγάγετε εκ των προτέρων τα δεδομένα που χρειάζεται να διατηρήσετε.

## Ανανέωση και λήξη

Ανανεώστε στη σελίδα αγοράς του τρέχοντος Application και η περίοδος ισχύος θα παραταθεί σύμφωνα με τους υφιστάμενους κανόνες διάρκειας της πλατφόρμας. Μετά τη λήξη, η είσοδος πρόσβασης αναστέλλεται· η ανανέωση εντός της περιόδου χάριτος αποκαθιστά την πρόσβαση. Μετά την περίοδο χάριτος, η παρουσία και τα δεδομένα θα ανακτηθούν. Υπερισχύουν η ώρα λήξης, η κατάσταση χρέωσης και οι ειδοποιήσεις διαγραφής στη σελίδα διαχείρισης.

## Σύνδεση στη διεπαφή διαχείρισης

Στη σελίδα διαχείρισης ανάπτυξης, αντιγράψτε τη διεύθυνση Dashboard, το όνομα χρήστη `admin` και τον κωδικό πρόσβασης, ανοίξτε τη διεύθυνση και συνδεθείτε. Οι πληροφορίες σύνδεσης παρέχονται μόνο στον ιδιοκτήτη αυτού του Application και στους διαχειριστές της πλατφόρμας. Τα μοντέλα, οι δεξιότητες και τα κανάλια διαμορφώνονται στην εγγενή διεπαφή Hermes.

## Συχνές ερωτήσεις

- **Γιατί η νέα παρουσία δεν μπορεί ακόμη να απαντήσει;** Η ολοκλήρωση της ανάπτυξης σημαίνει ότι το container είναι έτοιμο· πρέπει να διαμορφώσετε το μοντέλο και τα διαπιστευτήρια στην εγγενή διεπαφή πριν αρχίσετε να τη χρησιμοποιείτε.
- **Προεγκαθίστανται πρόσθετα plugins ή model fallback;** Δεν προστίθενται από προεπιλογή· διαμορφώστε τα στην εγγενή διεπαφή ανάλογα με τις ανάγκες.
- **Πώς ενημερώνεται μια υπάρχουσα παρουσία;** Το αρχικό Application και η παραγγελία διατηρούνται και χρησιμοποιείται η τρέχουσα έκδοση της υπηρεσίας κατά την επαναφορά ανάπτυξης· πριν από την αναβάθμιση, δημιουργήστε αντίγραφο ασφαλείας των δεδομένων και ελέγξτε τη συμβατότητα της έκδοσης.
- **Τι να κάνω αν αποτύχει η εκκίνηση;** Ελέγξτε πρώτα τα αρχεία καταγραφής και τα συμβάντα ανάπτυξης και διαμορφώστε το μοντέλο αφού επιβεβαιώσετε ότι η παρουσία είναι έτοιμη. Μην εκθέτετε τον κωδικό πρόσβασης και τα κλειδιά της παρουσίας σε δημόσια σχόλια ή στιγμιότυπα οθόνης.
