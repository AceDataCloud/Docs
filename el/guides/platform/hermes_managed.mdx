Δημιουργήστε ανεξάρτητη παρουσία κοντέινερ Hermes για κάθε Application. Από προεπιλογή χρησιμοποιείται μια βασική εικόνα σταθερής έκδοσης διανομής, διατηρώντας τις εγγενείς λειτουργίες· η πλατφόρμα παρέχει αγορά, ανανέωση, επίμονη αποθήκευση και διαχείριση ανάπτυξης.

## Δημιουργία και αγορά

1. Ανοίξτε το [Ανάπτυξη Hermes](https://platform.acedata.cloud/services/hermes) και δημιουργήστε ένα Application.
2. Επιλέξτε ένα πακέτο διάρκειας στη σελίδα αγοράς και ολοκληρώστε την πληρωμή.
3. Επιστρέψτε στη σελίδα διαμόρφωσης, όπου μπορείτε να επιλέξετε ένα μοντέλο συνομιλίας της πλατφόρμας από την αναπτυσσόμενη λίστα και να δείτε την τρέχουσα τιμή του μοντέλου. Η πλατφόρμα θα δημιουργήσει ανεξάρτητα διαπιστευτήρια API για αυτή την παρουσία· μπορείτε επίσης να απενεργοποιήσετε την πρόσβαση στην πλατφόρμα και να πραγματοποιήσετε τη διαμόρφωση μόνοι σας στην εγγενή κονσόλα.
4. Επιλέξτε αυτόματη δημιουργία διαπιστευτηρίων πρόσβασης ή ορίστε τον δικό σας ισχυρό κωδικό πρόσβασης/Token και, μετά την επιβεβαίωση, ξεκινήστε την ανάπτυξη. Τα διαπιστευτήρια πρόσβασης και τα διαπιστευτήρια API μοντέλου είναι ανεξάρτητα μεταξύ τους.
5. Αφού η παρουσία είναι έτοιμη, λάβετε τη διεύθυνση πρόσβασης και τα διαπιστευτήρια σύνδεσης από τη σελίδα διαχείρισης.
6. Συνδεθείτε στην εγγενή κονσόλα για να διαμορφώσετε τα κανάλια. Εάν απενεργοποιήσατε την πρόσβαση στο μοντέλο της πλατφόρμας κατά την ανάπτυξη, πρέπει επίσης να διαμορφώσετε μόνοι σας τον πάροχο μοντέλου και τα διαπιστευτήρια, ώστε να μπορεί να χρησιμοποιηθεί η συνομιλία.

Το τέλος ανάπτυξης χρεώνεται με βάση τη διάρκεια του πακέτου· για τις συγκεκριμένες τιμές σε δολάρια ΗΠΑ και τη διάρκεια, ανατρέξτε στη σελίδα αγοράς. Τα τέλη κλήσεων μοντέλου χρεώνονται ξεχωριστά· η αγορά διάρκειας ανάπτυξης δεν παρέχει δωρεάν πίστωση μοντέλου. Όταν είναι ενεργοποιημένη η πρόσβαση στην πλατφόρμα, τα αποκλειστικά διαπιστευτήρια API παρέχουν πρόσβαση μόνο στη διεπαφή συνομιλίας που αντιστοιχεί στο επιλεγμένο μοντέλο και οι κλήσεις χρεώνονται επιπλέον από το υπόλοιπο της πλατφόρμας σας. Κάθε Application αγοράζεται, ανανεώνεται και διαχειρίζεται ξεχωριστά.

## Κωδικοί πρόσβασης, διαπιστευτήρια και μεταγενέστερη διαμόρφωση

Τα διαπιστευτήρια πρόσβασης ορίζονται πριν από την πρώτη εκκίνηση. Η αυτόματη δημιουργία χρησιμοποιεί τυχαία διαπιστευτήρια, ο προσαρμοσμένος κωδικός πρόσβασης πρέπει να έχει τουλάχιστον 16 χαρακτήρες και το OpenClaw Token τουλάχιστον 32 χαρακτήρες. Τα πρόχειρα δεν αποθηκεύουν κωδικούς πρόσβασης· μετά την αλλαγή σελίδας μπορεί να χρειαστεί να τους εισαγάγετε ξανά. Μετά την ανάπτυξη, μόνο ο ιδιοκτήτης και οι διαχειριστές του Application μπορούν να δουν τα διαπιστευτήρια πρόσβασης.

Τα διαπιστευτήρια API μοντέλου κάθε παρουσίας δεν επαναχρησιμοποιούνται μεταξύ τους, η περίοδος ισχύος τους παρατείνεται με την ανανέωση της ανάπτυξης και ανακαλούνται όταν διαγράφεται η παρουσία. Εάν δεν συνδέσατε μοντέλο πλατφόρμας κατά την πρώτη ανάπτυξη, μπορείτε να επιλέξετε ένα μοντέλο πλατφόρμας στη σελίδα διαμόρφωσης του συγκεκριμένου Application και να αναπτύξετε ξανά· η πλατφόρμα θα ενημερώσει το προεπιλεγμένο μοντέλο, διατηρώντας τις συνεδρίες και άλλες εγγενείς ρυθμίσεις. Στη συνέχεια, τροποποιήστε τα μοντέλα και τα κανάλια στην εγγενή κονσόλα· εάν επιλέξετε μοντέλο άλλης υπηρεσίας, προσαρμόστε πρώτα την εξουσιοδότηση της αντίστοιχης διεπαφής στη διαχείριση διαπιστευτηρίων της πλατφόρμας ή χρησιμοποιήστε τα αντίστοιχα διαπιστευτήρια. Η συνήθης επαναληπτική ανάπτυξη δεν αντικαθιστά τις εγγενείς ρυθμίσεις. Τα περιβάλλοντα ανάπτυξης που δεν έχουν επαληθευτεί για δημοσίευση θα απορρίπτουν προσωρινά νέες αναπτύξεις· επικοινωνήστε με την υποστήριξη.

## Έκδοση και δεδομένα

Η σελίδα διαμόρφωσης εμφανίζει την τρέχουσα δημοσιευμένη έκδοση εικόνας. Οι νέες παρουσίες χρησιμοποιούν την τρέχουσα δημοσιευμένη έκδοση της υπηρεσίας· οι υπάρχουσες παρουσίες δεν αντικαθίστανται αυτόματα με τις ενημερώσεις του καταλόγου. Η επαναληπτική ανάπτυξη θα εφαρμόσει την τρέχουσα έκδοση της υπηρεσίας· δημιουργήστε πρώτα αντίγραφο ασφαλείας και επιβεβαιώστε τις απαιτήσεις αναβάθμισης της έκδοσης που χρησιμοποιείτε.

Κάθε παρουσία παρέχει από προεπιλογή 1 CPU, όριο μνήμης 2 GiB και 10 GiB επίμονης αποθήκευσης. Η επανεκκίνηση διατηρεί τα δεδομένα της παρουσίας. Η ενεργή διαγραφή της ανάπτυξης ή η ανάκτηση μετά τη λήξη θα διαγράψει την αποθήκευση· εξαγάγετε εκ των προτέρων τα δεδομένα που χρειάζεται να διατηρήσετε.

## Ανανέωση και λήξη

Ανανεώστε στη σελίδα αγοράς του τρέχοντος Application και η περίοδος ισχύος θα παραταθεί σύμφωνα με τους ισχύοντες κανόνες διάρκειας της πλατφόρμας. Μετά τη λήξη, το σημείο πρόσβασης τίθεται σε παύση· η ανανέωση εντός της περιόδου χάριτος επαναφέρει την πρόσβαση. Μετά την περίοδο χάριτος, η παρουσία και τα δεδομένα θα ανακτηθούν. Ισχύουν η ώρα λήξης, η κατάσταση χρέωσης και οι ειδοποιήσεις διαγραφής στη σελίδα διαχείρισης.

## Σύνδεση στη διεπαφή διαχείρισης

Στη σελίδα διαχείρισης ανάπτυξης, αντιγράψτε τη διεύθυνση Dashboard, το όνομα χρήστη `admin` και τον κωδικό πρόσβασης, και ανοίξτε τη διεύθυνση για να συνδεθείτε. Οι πληροφορίες σύνδεσης παρέχονται μόνο στον ιδιοκτήτη του συγκεκριμένου Application και στους διαχειριστές της πλατφόρμας. Τα μοντέλα, οι δεξιότητες και τα κανάλια διαμορφώνονται στην εγγενή διεπαφή του Hermes.

## Συχνές ερωτήσεις

- **Γιατί η νέα παρουσία δεν μπορεί ακόμη να απαντήσει;** Η ολοκλήρωση της ανάπτυξης σημαίνει μόνο ότι το κοντέινερ είναι έτοιμο. Εάν απενεργοποιήσατε την πρόσβαση στο μοντέλο της πλατφόρμας κατά την ανάπτυξη, πρέπει να επιλέξετε συμπληρωματικά ένα μοντέλο πλατφόρμας στη σελίδα διαμόρφωσης και να αναπτύξετε ξανά ή να διαμορφώσετε μόνοι σας το μοντέλο και τα διαπιστευτήρια στην εγγενή διεπαφή.
- **Είναι προεγκατεστημένα πρόσθετα plugins ή model fallback;** Δεν προστίθενται από προεπιλογή· διαμορφώστε τα στην εγγενή διεπαφή σύμφωνα με τις ανάγκες σας.
- **Πώς ενημερώνεται μια υπάρχουσα παρουσία;** Το αρχικό Application και η παραγγελία διατηρούνται και κατά την επαναληπτική ανάπτυξη χρησιμοποιείται η τρέχουσα έκδοση της υπηρεσίας· πριν από την αναβάθμιση, δημιουργήστε πρώτα αντίγραφο ασφαλείας των δεδομένων και ελέγξτε τη συμβατότητα έκδοσης.
- **Τι να κάνω αν αποτύχει η εκκίνηση;** Ελέγξτε πρώτα τα αρχεία καταγραφής ανάπτυξης και τα συμβάντα και διαμορφώστε το μοντέλο αφού επιβεβαιώσετε ότι η παρουσία είναι έτοιμη. Μην εκθέτετε τον κωδικό πρόσβασης και τα κλειδιά της παρουσίας σε δημόσια σχόλια ή στιγμιότυπα οθόνης.
