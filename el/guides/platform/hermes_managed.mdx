Δημιουργήστε ανεξάρτητη παρουσία κοντέινερ Hermes για κάθε Application. Από προεπιλογή χρησιμοποιείται βασική εικόνα σταθερής έκδοσης κυκλοφορίας, διατηρώντας τις εγγενείς λειτουργίες· η πλατφόρμα παρέχει αγορά, ανανέωση, μόνιμη αποθήκευση και διαχείριση ανάπτυξης.

## Δημιουργία και αγορά

1. Ανοίξτε το [Ανάπτυξη Hermes](https://platform.acedata.cloud/services/hermes) και δημιουργήστε Application.
2. Στη σελίδα αγοράς επιλέξτε πακέτο διάρκειας και ολοκληρώστε την πληρωμή.
3. Επιστρέψτε στη σελίδα ρυθμίσεων, όπου μπορείτε να επιλέξετε το μοντέλο συνομιλίας της πλατφόρμας από την αναπτυσσόμενη λίστα και να δείτε την τρέχουσα τιμή του μοντέλου. Η πλατφόρμα θα δημιουργήσει ανεξάρτητα διαπιστευτήρια API για αυτή την παρουσία· μπορείτε επίσης να απενεργοποιήσετε την πρόσβαση της πλατφόρμας και να κάνετε ρυθμίσεις μόνοι σας στην εγγενή κονσόλα.
4. Επιλέξτε αυτόματη δημιουργία διαπιστευτηρίων πρόσβασης ή ορίστε τον δικό σας ισχυρό κωδικό πρόσβασης/Token· επιλέξτε A2A και EnvarPay ανάλογα με τις ανάγκες και, μετά την επιβεβαίωση, ξεκινήστε την ανάπτυξη. Τα διαπιστευτήρια πρόσβασης και τα διαπιστευτήρια API του μοντέλου είναι ανεξάρτητα μεταξύ τους.
5. Αφού η παρουσία είναι έτοιμη, λάβετε τη διεύθυνση πρόσβασης και τα διαπιστευτήρια σύνδεσης από τη σελίδα διαχείρισης.
6. Συνδεθείτε στην εγγενή κονσόλα για να ρυθμίσετε τα κανάλια. Αν η πρόσβαση στο μοντέλο της πλατφόρμας ήταν απενεργοποιημένη κατά την ανάπτυξη, πρέπει επίσης να ρυθμίσετε μόνοι σας τον πάροχο μοντέλου και τα διαπιστευτήρια, ώστε να μπορεί να χρησιμοποιηθεί η συνομιλία.

Το κόστος ανάπτυξης χρεώνεται βάσει της διάρκειας του πακέτου· οι συγκεκριμένες τιμές σε δολάρια ΗΠΑ και η διάρκεια υπερισχύουν σύμφωνα με τη σελίδα αγοράς. Το κόστος κλήσεων μοντέλου χρεώνεται ξεχωριστά· η αγορά διάρκειας ανάπτυξης δεν παρέχει δωρεάν πίστωση μοντέλου. Όταν είναι ενεργοποιημένη η πρόσβαση της πλατφόρμας, τα αποκλειστικά διαπιστευτήρια API ανοίγουν μόνο τη διεπαφή συνομιλίας που αντιστοιχεί στο επιλεγμένο μοντέλο και οι κλήσεις χρεώνονται επιπλέον από το υπόλοιπό σας στην πλατφόρμα. Κάθε Application αγοράζεται, ανανεώνεται και διαχειρίζεται ξεχωριστά.

## Κωδικοί πρόσβασης, διαπιστευτήρια και μεταγενέστερη ρύθμιση

Τα διαπιστευτήρια πρόσβασης ορίζονται πριν από την πρώτη εκκίνηση. Η αυτόματη δημιουργία χρησιμοποιεί τυχαία διαπιστευτήρια, ο προσαρμοσμένος κωδικός πρόσβασης απαιτεί τουλάχιστον 16 χαρακτήρες και το OpenClaw Token απαιτεί τουλάχιστον 32 χαρακτήρες. Τα πρόχειρα δεν αποθηκεύουν κωδικούς πρόσβασης· μετά την αλλαγή σελίδας μπορεί να χρειαστεί να τους εισαγάγετε ξανά. Μετά την ανάπτυξη, μόνο ο κάτοχος και οι διαχειριστές του Application μπορούν να δουν τα διαπιστευτήρια πρόσβασης.

Τα διαπιστευτήρια API μοντέλου κάθε παρουσίας δεν επαναχρησιμοποιούνται μεταξύ τους, η ισχύς τους παρατείνεται με την ανανέωση της ανάπτυξης και ανακαλούνται όταν διαγράφεται η παρουσία. Αν κατά την πρώτη ανάπτυξη δεν συνδέθηκε μοντέλο της πλατφόρμας, μπορείτε να επιλέξετε μοντέλο της πλατφόρμας στη σελίδα ρυθμίσεων αυτού του Application και να αναπτύξετε ξανά· η πλατφόρμα θα ενημερώσει το προεπιλεγμένο μοντέλο, διατηρώντας τις συνεδρίες και άλλες εγγενείς ρυθμίσεις. Στη συνέχεια, τροποποιήστε τα μοντέλα και τα κανάλια στην εγγενή κονσόλα· αν επιλέξετε μοντέλο άλλης υπηρεσίας, προσαρμόστε πρώτα την εξουσιοδότηση της αντίστοιχης διεπαφής στη διαχείριση διαπιστευτηρίων της πλατφόρμας ή χρησιμοποιήστε τα αντίστοιχα διαπιστευτήρια. Η συνηθισμένη επανα-ανάπτυξη δεν θα αντικαταστήσει τις εγγενείς ρυθμίσεις. Τα περιβάλλοντα ανάπτυξης που δεν έχουν επαληθευτεί για κυκλοφορία θα απορρίπτουν προσωρινά νέες αναπτύξεις· επικοινωνήστε με την υποστήριξη.

## Προαιρετικά στοιχεία ανάπτυξης

Αφού επιλέξετε A2A, το πρότυπο ανάπτυξης θα εκκινήσει την εγγενή πύλη A2A του Hermes και θα παρέχει το διακριτικό κατόχου στη σελίδα διαχείρισης. Αφού επιλέξετε EnvarPay, θα εγκατασταθεί επιπλέον ανεξάρτητο κοντέινερ υπηρεσίας και μόνιμο καθολικό, ενώ πρέπει πρώτα να ενεργοποιηθεί το A2A. Το EnvarPay αρχικά διαθέτει μόνο διαπιστευτήρια πρόσβασης κατόχου, χωρίς ταυτότητα υπηρεσίας ή είσπραξης, και δεν θα χρεώνει αυτόματα ούτε θα αγοράζει εκ μέρους σας. Καμία από τις δύο επιλογές δεν θα καταχωρίσει αυτόματα την παρουσία στο Envar· οι υπάρχουσες παρουσίες μπορούν να εισέλθουν στις ρυθμίσεις από τη σελίδα διαχείρισης και να αναπτυχθούν ξανά μετά την ενεργοποίηση. Τα ήδη ενεργοποιημένα στοιχεία δεν μπορούν προς το παρόν να απενεργοποιηθούν σε αυτόν τον οδηγό.

Αφού ενεργοποιηθεί το A2A και η παρουσία είναι έτοιμη, η κάρτα διεύθυνσης πρόσβασης στη σελίδα διαχείρισης θα εμφανίζει μια διεύθυνση Agent Card που μπορεί να αντιγραφεί. Το εγγενές A2A του Hermes χρησιμοποιεί ανεξάρτητη δημόσια διεύθυνση· η διεύθυνση σύνδεσης Dashboard δεν μπορεί να χρησιμοποιηθεί ως διεύθυνση Agent Card. Αν είναι ταυτόχρονα ενεργοποιημένο το EnvarPay, η σελίδα διαχείρισης θα εμφανίζει επίσης την αντίστοιχη «διεύθυνση πρόσβασης Envar»· κατά τη σύνδεση υπηρεσίας στο Envar, αντιγράψτε κατά προτεραιότητα αυτό το URL.

## Έκδοση και δεδομένα

Η σελίδα ρυθμίσεων εμφανίζει την τρέχουσα δημοσιευμένη έκδοση εικόνας. Οι νέες παρουσίες χρησιμοποιούν την τρέχουσα δημοσιευμένη έκδοση της υπηρεσίας· οι υπάρχουσες παρουσίες δεν αντικαθίστανται αυτόματα με τις ενημερώσεις του καταλόγου. Η επανα-ανάπτυξη θα εφαρμόσει την τρέχουσα έκδοση της υπηρεσίας· δημιουργήστε πρώτα αντίγραφο ασφαλείας και επιβεβαιώστε τις απαιτήσεις αναβάθμισης της έκδοσης που χρησιμοποιείται.

Κάθε παρουσία παρέχει από προεπιλογή 1 CPU, όριο μνήμης 2 GiB και μόνιμη αποθήκευση 10 GiB. Η επανεκκίνηση διατηρεί τα δεδομένα της παρουσίας. Η ενεργή διαγραφή της ανάπτυξης ή η ανάκτηση μετά τη λήξη θα διαγράψει τον χώρο αποθήκευσης· εξαγάγετε εκ των προτέρων τα δεδομένα που πρέπει να διατηρηθούν.

## Ανανέωση και λήξη

Ανανεώστε στη σελίδα αγοράς του τρέχοντος Application και η περίοδος ισχύος θα παραταθεί σύμφωνα με τους υπάρχοντες κανόνες διάρκειας της πλατφόρμας. Μετά τη λήξη, το σημείο πρόσβασης αναστέλλεται· η ανανέωση εντός της περιόδου χάριτος αποκαθιστά την πρόσβαση. Μετά την υπέρβαση της περιόδου χάριτος, η παρουσία και τα δεδομένα θα ανακτηθούν. Υπερισχύουν ο χρόνος λήξης, η κατάσταση χρέωσης και η ειδοποίηση διαγραφής στη σελίδα διαχείρισης.

## Σύνδεση στη διεπαφή διαχείρισης

Στη σελίδα διαχείρισης ανάπτυξης, αντιγράψτε τη διεύθυνση Dashboard, το όνομα χρήστη `admin` και τον κωδικό πρόσβασης και ανοίξτε τα για σύνδεση. Οι πληροφορίες σύνδεσης παρέχονται μόνο στον κάτοχο του συγκεκριμένου Application και στους διαχειριστές της πλατφόρμας. Τα μοντέλα, οι δεξιότητες και τα κανάλια ρυθμίζονται στην εγγενή διεπαφή Hermes.

## Συχνές ερωτήσεις

- **Γιατί η νέα παρουσία δεν μπορεί ακόμη να απαντήσει;** Η ολοκλήρωση της ανάπτυξης σημαίνει μόνο ότι το κοντέινερ είναι έτοιμο. Αν η πρόσβαση στο μοντέλο της πλατφόρμας ήταν απενεργοποιημένη κατά την ανάπτυξη, πρέπει να επιλέξετε εκ νέου μοντέλο της πλατφόρμας στη σελίδα ρυθμίσεων και να αναπτύξετε ξανά, ή να ρυθμίσετε μόνοι σας το μοντέλο και τα διαπιστευτήρια στην εγγενή διεπαφή.
- **Υπάρχουν προεγκατεστημένα πρόσθετα plugins ή model fallback;** Από προεπιλογή δεν προστίθενται· ρυθμίστε τα στην εγγενή διεπαφή ανάλογα με τις ανάγκες.
- **Πώς ενημερώνονται οι υπάρχουσες παρουσίες;** Το αρχικό Application και η παραγγελία διατηρούνται και κατά την επανα-ανάπτυξη χρησιμοποιείται η τρέχουσα έκδοση της υπηρεσίας· πριν από την αναβάθμιση, δημιουργήστε αντίγραφο ασφαλείας των δεδομένων και ελέγξτε τη συμβατότητα της έκδοσης.
- **Τι να κάνω αν αποτύχει η εκκίνηση;** Ελέγξτε πρώτα τα αρχεία καταγραφής ανάπτυξης και τα συμβάντα και ρυθμίστε το μοντέλο αφού επιβεβαιώσετε ότι η παρουσία είναι έτοιμη. Μην αποκαλύπτετε τον κωδικό πρόσβασης και τα κλειδιά της παρουσίας σε δημόσια σχόλια ή στιγμιότυπα οθόνης.
