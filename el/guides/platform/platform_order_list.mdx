Επιστρέφει σελιδοποιημένα τις παραγγελίες ανανέωσης του λογαριασμού, κατάλληλο για αναζήτηση ID παραγγελίας, προβολή κατάστασης πληρωμής και συμφωνία λογαριασμών.

## Προετοιμασία

Δημιουργήστε ένα [Account Token](https://platform.acedata.cloud/documents/platform-token) και λάβετε το UUID του τρέχοντος λογαριασμού από το `GET /api/v1/platform-tokens/me/`.

```shell
export PLATFORM_TOKEN='你的账户令牌'
export USER_ID='你的账户 UUID'
```

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                              |
| --- | ----------------------------------------------- |
| Μέθοδος  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/orders/` |
| Πιστοποίηση  | Account Token, το OAuth token απαιτεί `orders:read`       |
| Σελιδοποίηση  | `count` + `items`                               |

Οι απλοί χρήστες πρέπει να μεταβιβάζουν το δικό τους `user_id`· διαφορετικά, όταν η σελιδοποίηση συναντά αντικείμενα χωρίς δικαίωμα πρόσβασης, ενδέχεται να επιστραφεί `403`.

## Παράμετροι ερωτήματος

| Παράμετρος                    | Τύπος       | Υποχρεωτικό     | Περιγραφή                                                        |
| --------------------- | -------- | ------ | --------------------------------------------------------- |
| `user_id`             | UUID     | Υποχρεωτικό για απλούς χρήστες | Λογαριασμός στον οποίο ανήκει η παραγγελία· υποστηρίζει επαναλαμβανόμενες παραμέτρους                                             |
| `pay_way`             | string   | Όχι      | Φιλτράρισμα κατά τρόπο πληρωμής· υποστηρίζει επαναλαμβανόμενες ή τιμές διαχωρισμένες με κόμμα                                        |
| `state`               | string   | Όχι      | Φιλτράρισμα κατά κατάσταση· υποστηρίζει επαναλαμβανόμενες ή τιμές διαχωρισμένες με κόμμα                                          |
| `created_at_from/to`  | datetime | Όχι      | Εύρος χρόνου δημιουργίας                                                    |
| `finished_at_from/to` | datetime | Όχι      | Εύρος χρόνου ολοκλήρωσης                                                    |
| `limit` / `offset`    | integer  | Όχι      | Σελιδοποίηση                                                        |
| `ordering`            | string   | Όχι      | `created_at`, `-created_at`, `finished_at` ή `-finished_at` |

Η τρέχουσα λίστα δεν υποστηρίζει φιλτράρισμα με `application_id`, `service_id`, `package_id`, `payment_method` ή `tag`· το όνομα του πεδίου τρόπου πληρωμής είναι `pay_way`.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/orders/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode 'state=Paid,Finished' \
  --data-urlencode 'pay_way=Stripe' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## Περιγραφή απόκρισης

Η απόκριση είναι `{count, items}`. Τα στοιχεία της διαδικτυακής λίστας περιλαμβάνουν `id`, `user_id`, `application_id/application_ids`, `package_id/package_ids`, `price`, `amount`, `discount`, `remaining_amount`, `state`, `pay_way`, `pay_id`, `pay_url`, `finished_at`, `expired_at`, `invoice`, `metadata` και πεδία χρόνου.

- Οι πραγματικές καταστάσεις είναι `Pending`, `Paid`, `Finished`, `Expired`, `Failed`, `Refunded`, δεν υπάρχει `Cancelled`.
- Τα ονόματα πεδίων είναι `pay_way`, `finished_at`, `discount` και `price`, όχι `payment_method`, `paid_at`, `discount_rate` ή `final_price`.
- Το `price` είναι η τελική τιμή που καταγράφεται για την παραγγελία· το νόμισμα και οι λεπτομέρειες διακανονισμού ενδέχεται να βρίσκονται σε ελεγχόμενο metadata και δεν μπορούν να συναχθούν αυθαίρετα μόνο από τον τρόπο πληρωμής.
