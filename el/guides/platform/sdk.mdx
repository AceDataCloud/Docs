Το Ace Data Cloud παρέχει επίσημα SDK πελάτη σε TypeScript / Python / Go, που περιλαμβάνουν τις δυνατότητες chat completions, images, video, music, search, x402 κ.λπ. από το `api.acedata.cloud`, συσκευάζοντας τις σε ισχυρούς τύπους μεθόδων, εξοικονομώντας την εργασία χειροκίνητης γραφής HTTP, SSE, αναμονής εργασιών, διαχείρισης σφαλμάτων και επαναλήψεων.

Αυτό το κεφάλαιο οργανώνεται με βάση τη σειρά πραγματικής πρόσβασης: πρώτα αποκτάτε το API Token από την κονσόλα, στη συνέχεια επιλέγετε γλώσσα και βλέπετε τα αντίστοιχα κεφάλαια, και τέλος εξετάζετε την αναμονή εργασιών, τις ροές απαντήσεων και τις προηγμένες χρήσεις πληρωμών X402.

## Αποθετήριο και Πακέτα

- Πηγαίος κώδικας SDK (monorepo): [https://github.com/AceDataCloud/SDK](https://github.com/AceDataCloud/SDK)
- TypeScript: [`@acedatacloud/sdk`](https://www.npmjs.com/package/@acedatacloud/sdk)
- Python: [`acedatacloud`](https://pypi.org/project/acedatacloud/)
- Go: [`github.com/AceDataCloud/SDK/go`](https://pkg.go.dev/github.com/AceDataCloud/SDK/go)
- Πελάτης X402 (TypeScript): [`@acedatacloud/x402-client`](https://www.npmjs.com/package/@acedatacloud/x402-client)
- Πελάτης X402 (Python): [`acedatacloud-x402`](https://pypi.org/project/acedatacloud-x402/)

## Πότε να χρησιμοποιήσετε SDK / MCP / Γενικό HTTP / X402

| Σενάριο                                      | Συνιστώμενος Τρόπος                                                       |
| ------------------------------------------- | ---------------------------------------------------------------------- |
| Υπηρεσίες backend, CLI, αυτοματοποιημένα σενάρια, πλαίσια Agent | **SDK** (αυτό το κεφάλαιο)                                                |
| Κλήσεις πελατών MCP όπως Claude Desktop / Cursor / Cline | MCP Servers                                                            |
| Μοναδική επαλήθευση curl, αποσφαλμάτωση, περιβάλλον που υποστηρίζει μόνο HTTP | Γενικό HTTP (γρήγορη εκκίνηση κάθε υπηρεσίας)                                   |
| Δεν θέλετε να δημιουργήσετε API Token, πληρώστε USDC κατά την κλήση | [Οδηγός ενσωμάτωσης X402](https://platform.acedata.cloud/documents/x402-integration) |

Το SDK και το X402 δεν είναι αμοιβαία αποκλειστικά: το SDK υποστηρίζει ταυτόχρονα τη «διαδρομή token» και τη «διαδρομή `paymentHandler`», δείτε [SDK + X402 Payment Hook](https://platform.acedata.cloud/documents/sdk-x402-payment).

## Αίτηση API Token

Για να χρησιμοποιήσετε το SDK, πρώτα πηγαίνετε στο [Ace Data Cloud Console - Λίστα Εφαρμογών](https://platform.acedata.cloud/console/applications) για να ζητήσετε ένα API Token:

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά την εγγραφή θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα έχετε δωρεάν πίστωση, ώστε να μπορείτε να δοκιμάσετε δωρεάν τις διάφορες υπηρεσίες AI που προσφέρει το Ace Data Cloud.

Αντιγράψτε το Token που μόλις αποκτήσατε, το οποίο θα αναφέρεται παρακάτω ως `{token}`.

## Ενοποιημένη Μεταβλητή Περιβάλλοντος

Τα SDK και των τριών γλωσσών θα διαβάσουν αυτόματα την ίδια μεταβλητή περιβάλλοντος `ACEDATACLOUD_API_TOKEN`, συνιστάται να την `export` στο shell, ώστε το SDK να την ανιχνεύει αυτόματα:

```bash
export ACEDATACLOUD_API_TOKEN={token}
# Προαιρετικό: προεπιλογή https://api.acedata.cloud
# export ACEDATACLOUD_BASE_URL=https://api.acedata.cloud
```

Μπορείτε επίσης να την περάσετε ρητά κατά την κατασκευή του πελάτη, οι αντίστοιχες ονομασίες παραμέτρων για τις τρεις γλώσσες είναι:

- TypeScript: `new AceDataCloud({ apiToken: '{token}' })`
- Python: `AceDataCloud(api_token="{token}")`
- Go: `adc.NewClient(adc.WithAPIToken("{token}"))`

> Σημείωση: Στο αποθετήριο του έργου AceDataCloud, η κοινή ονομασία είναι `ACEDATACLOUD_API_KEY` (στο `.env` / CI), αλλά αυτά τα τρία SDK αναγνωρίζουν μόνο το `ACEDATACLOUD_API_TOKEN`. Εάν το περιβάλλον σας έχει μόνο `ACEDATACLOUD_API_KEY`, παρακαλώ περάστε το ρητά κατά την κατασκευή.

## 30 Δευτερόλεπτα για να ξεκινήσετε με τρία παραδείγματα

Οι παρακάτω τρεις κωδικές ενότητες κάνουν το ίδιο πράγμα: καλούν το `gpt-4o-mini`, ζητώντας του να απαντήσει μόνο με `ADC_*_OK`. Κάθε ενότητα περιλαμβάνει **πραγματικά αποτελέσματα εκτέλεσης**, μπορείτε να χρησιμοποιήσετε το δικό σας token για να το αναπαραγάγετε.

### TypeScript

```ts
import { AceDataCloud } from '@acedatacloud/sdk';

const client = new AceDataCloud({ apiToken: process.env.ACEDATACLOUD_API_KEY });

const t0 = Date.now();
const res = await client.openai.chat.completions.create({
  model: 'gpt-4o-mini',
  messages: [{ role: 'user', content: 'Reply with exactly: ADC_TS_SDK_OK' }],
  max_tokens: 20,
  temperature: 0
});
console.log('elapsed_ms', Date.now() - t0);
console.log('id', res.id);
console.log('model', res.model);
console.log('content', res.choices[0].message.content);
console.log('usage', JSON.stringify(res.usage));
```

> Το SDK δηλώνει αυτή τη στιγμή την απάντηση ως `Record<string, unknown>`, κατά την εκτέλεση είναι ένα κανονικό JSON αντικείμενο, μπορείτε να έχετε άμεση πρόσβαση στα πεδία. Σε αυστηρά έργα TS, εάν αντιμετωπίσετε σφάλματα τύπου, μπορείτε προσωρινά να χρησιμοποιήσετε `as any`, ή να ανατρέξετε σε [SDK Task Polling and Streaming](https://platform.acedata.cloud/documents/sdk-tasks-and-streaming) για να δημιουργήσετε ένα τυποποιημένο wrapper.

Αποτελέσματα εκτέλεσης προγράμματος:

```text
elapsed_ms 2543
id chatcmpl-DldCcLvkTFaioST8e6SjOl0wJScQA
model gpt-4o-mini
content ADC_TS_SDK_OK
usage {"prompt_tokens":16,"completion_tokens":6,"total_tokens":22}
```

### Python
```python
import os, time, json
from acedatacloud import AceDataCloud

client = AceDataCloud(api_token=os.environ["ACEDATACLOUD_API_KEY"])

t0 = time.time()
res = client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Απάντησε ακριβώς: ADC_PY_SDK_OK"}],
    max_tokens=20,
    temperature=0,
)
print("elapsed_ms", int((time.time() - t0) * 1000))
print("id", res["id"])
print("model", res["model"])
print("content", res["choices"][0]["message"]["content"])
print("usage", json.dumps({k: v for k, v in res["usage"].items()
                            if k in ("prompt_tokens","completion_tokens","total_tokens")}))
```

> Το Python SDK επιστρέφει τρέχον `dict`, οπότε χρησιμοποιούμε `res["id"]` αντί για `res.id`. Αυτό διαφέρει από το `openai-python`, χρειάζεται προσοχή κατά τη μετανάστευση.

Αποτελέσματα εκτέλεσης προγράμματος:

```text
elapsed_ms 2963
id chatcmpl-DldFdnIlhSUXINpupgsUmZL78MnBu
model gpt-4o-mini
content ADC_PY_SDK_OK
usage {"prompt_tokens": 17, "completion_tokens": 7, "total_tokens": 24}
```

### Go

```go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    adc "github.com/AceDataCloud/SDK/go"
)

func main() {
    client, err := adc.NewClient(adc.WithAPIToken(os.Getenv("ACEDATACLOUD_API_KEY")))
    if err != nil {
        panic(err)
    }
    ctx, cancel := context.WithTimeout(context.Background(), 60*time.Second)
    defer cancel()

    t0 := time.Now()
    res, err := client.OpenAI().Chat().Completions().Create(ctx, adc.ChatCompletionRequest{
        Model:     "gpt-4o-mini",
        Messages:  []map[string]any{{"role": "user", "content": "Απάντησε ακριβώς: ADC_GO_SDK_OK"}},
        MaxTokens: 20,
    })
    if err != nil {
        panic(err)
    }
    fmt.Println("elapsed_ms", time.Since(t0).Milliseconds())
    fmt.Println("id", res["id"])
    fmt.Println("model", res["model"])
    choices := res["choices"].([]any)
    msg := choices[0].(map[string]any)["message"].(map[string]any)
    fmt.Println("content", msg["content"])
    usage := res["usage"].(map[string]any)
    fmt.Printf("usage prompt=%v completion=%v total=%v\n",
        usage["prompt_tokens"], usage["completion_tokens"], usage["total_tokens"])
}
```

> Η απάντηση του Go SDK είναι ομοιόμορφη `map[string]any`, δεν έχει ισχυρούς τύπους struct, χρειάζεται να κάνετε τύπο ισχυρής δήλωσης. Όλοι οι πόροι πρόσβασης είναι μέθοδοι αλυσίδας: `client.OpenAI().Chat().Completions().Create(...)`.

Αποτελέσματα εκτέλεσης προγράμματος:

```text
elapsed_ms 6436
id chatcmpl-89DHExvFvBc4ciIPfolZYUOy7ivxv
model gpt-4o-mini
content ADC_GO_SDK_OK
usage prompt=16 completion=5 total=21
```

Στις απαντήσεις και των τριών γλωσσών, οι `id`, `elapsed_ms`, `usage` προέρχονται από την ίδια πηγή: μέσω της αυθεντικοποίησης PlatformGateway → στοχευμένη OpenAI συμβατή API → καταγραφή χρέωσης. Το πεδίο `content` είναι η πραγματική έξοδος του μοντέλου, χρησιμοποιώντας σταθερή αναγνώριση `ADC_*_OK` για να αποδείξει ότι η απάντηση δεν έχει παραποιηθεί από το SDK.
