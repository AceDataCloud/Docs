Επιστρέφει σελιδοποιημένα τα Application που ο λογαριασμός κατέχει ή έχει εξουσιοδοτημένη πρόσβαση να χρησιμοποιεί, συμπεριλαμβανομένων υπολοίπου, κατάστασης, σύνοψης υπηρεσίας και συσχετισμένων διαπιστευτηρίων. Κατάλληλο για μαζική παρακολούθηση υπολοίπου, αναζήτηση Application ID και πρόσβαση στη διαχείριση διαπιστευτηρίων.

## Προετοιμασία

1. Συνδεθείτε στην [πλατφόρμα AceDataCloud](https://platform.acedata.cloud).
2. Δημιουργήστε ένα διακριτικό λογαριασμού στην [κονσόλα Account Token](https://platform.acedata.cloud/console/platform-tokens).
3. Οι απλοί χρήστες χρησιμοποιούν `user_id=me`· μπορείτε επίσης να λάβετε το δικό σας UUID από το `GET /api/v1/platform-tokens/me/`.

```shell
export PLATFORM_TOKEN='το διακριτικό λογαριασμού σας'
```

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                           |
| --- | ----------------------------------------------------- |
| Μέθοδος  | `GET`                                                 |
| URL | `https://platform.acedata.cloud/api/v1/applications/` |
| Αυθεντικοποίηση  | Account Token, το OAuth token απαιτεί `applications:read`       |
| Σελιδοποίηση  | `count` + `items`                                     |

Οι απλοί χρήστες πρέπει να περάσουν `user_id=me`. Εάν δεν περαστεί, το ερώτημα δεν περιορίζεται πρώτα ανά λογαριασμό και η σελιδοποίηση ενδέχεται να επιστρέψει `403` όταν συναντήσει αντικείμενα χωρίς δικαίωμα πρόσβασης· οι διαχειριστές μπορούν να δουν ολόκληρο τον πίνακα χωρίς να το περάσουν.

## Παράμετροι ερωτήματος

| Παράμετρος            | Τύπος          | Υποχρεωτικό     | Περιγραφή                                                  |
| ------------- | ----------- | ------ | --------------------------------------------------- |
| `user_id`     | UUID / `me` | Υποχρεωτικό για απλούς χρήστες | Υποκείμενο ερωτήματος· υποστηρίζει επαναλαμβανόμενες παραμέτρους                                         |
| `affiliation` | string      | Όχι      | `owner` (προεπιλογή) ή `granted`· μπορούν να περαστούν επανειλημμένα και τα δύο για ένωση, ισχύει μόνο όταν υπάρχει `user_id` |
| `service_id`  | UUID        | Όχι      | Φιλτράρισμα ανά υπηρεσία· υποστηρίζει επαναλαμβανόμενες παραμέτρους                                        |
| `scope`       | string      | Όχι      | `Individual` ή `Global`· υποστηρίζει επαναλαμβανόμενες παραμέτρους                      |
| `type`        | string      | Όχι      | `Usage` ή `Period`· υποστηρίζει επαναλαμβανόμενες παραμέτρους                           |
| `limit`       | integer     | Όχι      | Αριθμός στοιχείων ανά σελίδα, μέγιστο 100                                         |
| `offset`      | integer     | Όχι      | Μετατόπιση σελιδοποίησης                                               |
| `ordering`    | string      | Όχι      | Υποστηρίζονται μόνο `created_at` ή `-created_at`                    |

Τα `paid`, `disabled`, `expired`, `low_balance` και `tag` δεν είναι επί του παρόντος παράμετροι φιλτραρίσματος διακομιστή. Για ειδοποιήσεις υπολοίπου, αφού ανακτηθεί η λίστα, πρέπει να γίνεται έλεγχος στην πλευρά του πελάτη βάσει των `remaining_amount`, `service.unit` και των επιχειρησιακών ορίων κάθε Application.

## Παραδείγματα αιτημάτων

```shell
curl --get 'https://platform.acedata.cloud/api/v1/applications/' \
  --data-urlencode 'user_id=me' \
  --data-urlencode 'affiliation=owner' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Προβολή ταυτόχρονα των Application που κατέχετε και εκείνων που άλλοι έχουν εξουσιοδοτήσει για εσάς:

```shell
curl --get 'https://platform.acedata.cloud/api/v1/applications/' \
  --data-urlencode 'user_id=me' \
  --data-urlencode 'affiliation=owner' \
  --data-urlencode 'affiliation=granted' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## Περιγραφή απόκρισης

Η απόκριση είναι `{count, items}`. Κάθε στοιχείο περιέχει τα πεδία του μοντέλου Application και επιπλέον:

- `service`: `id`, `alias`, `title`, `type`, `unit`, `icon_url`·
- `credentials`: σύνοψη των διαπιστευτηρίων που ο τρέχων καλών έχει δικαίωμα να δει·
- `paid`, `remaining_amount`, `used_amount`, `disabled`, `allow_consume_global`·
- η πραγματική τιμή του `scope` είναι `Individual` ή `Global`·
- η πραγματική τιμή του `type` είναι `Usage` ή `Period`.

Το `remaining_amount` μπορεί να είναι κενό· ο πελάτης πρέπει πρώτα να ελέγξει για κενή τιμή και έπειτα να κάνει αριθμητική σύγκριση. Η μονάδα ποσόστωσης καθορίζεται από το `service.unit`.
