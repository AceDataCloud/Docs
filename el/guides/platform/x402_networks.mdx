Το Ace Data Cloud X402 πραγματοποιεί επί του παρόντος διακανονισμούς γύρω από το USDC και υποστηρίζει δύο τύπους αλυσίδων: EVM και Solana. Οι μέθοδοι υπογραφής, οι διευθύνσεις περιουσιακών στοιχείων, η συμπεριφορά gas και τα κατάλληλα σενάρια διαφέρουν μεταξύ δικτύων, επομένως πρέπει να επιλέξετε το δίκτυο πριν από την ενσωμάτωση.

## Τα αναγνωριστικά δικτύου χρησιμοποιούν CAIP-2

Το `accepts[].network` του x402 v2 είναι αναγνωριστικό CAIP-2 και όχι συντομογραφίες όπως `base`, `skale`. Κατά την αντιστοίχιση δικτύων, ο πελάτης πρέπει να συγκρίνει με βάση τη συμβολοσειρά CAIP-2:

| Δίκτυο             | Αναγνωριστικό CAIP-2                       |
| ------------------ | ------------------------------------------ |
| Base               | `eip155:8453`                              |
| SKALE Base         | `eip155:1187947933`                        |
| Solana mainnet     | `solana:5eykt4UsFv8P8NJdTREpY1vzqKqZKvdp`  |

## Πίνακας υποστήριξης

| Δίκτυο | scheme   | Περιουσιακό στοιχείο | Μέθοδος υπογραφής                      | Κατάλληλα σενάρια                                      |
| ------ | -------- | -------------------- | -------------------------------------- | ------------------------------------------------------ |
| Base   | `exact`  | Base USDC            | EIP-3009 `TransferWithAuthorization`   | Προτεινόμενο από προεπιλογή, ώριμη υποστήριξη πορτοφολιών και ρευστότητας. |
| Base   | `upto`   | Base USDC + Permit2  | Permit2 `PermitWitnessTransferFrom`    | API μεταγενέστερης μέτρησης για chat, μοντέλα κ.λπ.    |
| SKALE  | `exact`  | SKALE bridged USDC   | EIP-3009 `TransferWithAuthorization`   | Χαμηλό κόστος gas, κατάλληλο για επαλήθευση πληρωμών EVM και κλήσεις χαμηλού κόστους. |
| Solana | `exact`  | Solana USDC          | SPL `TransferChecked`                  | Σενάρια πορτοφολιών Solana, Agent ή εφαρμογών on-chain. |

Το `upto` παρέχεται επί του παρόντος μόνο στο Base. Τα πραγματικά διαθέσιμα στοιχεία υπερισχύονται από το `accepts` που επιστρέφει το API. Μπορείτε επίσης να ελέγξετε το Facilitator:

```bash
curl https://facilitator.acedata.cloud/supported
```

Η επιστροφή του Facilitator `/supported`:

```json
{
  "kinds": [
    { "x402Version": 2, "scheme": "exact", "network": "eip155:8453" },
    {
      "x402Version": 2,
      "scheme": "upto",
      "network": "eip155:8453",
      "extra": { "facilitatorAddress": "0xd019238EAA8a9Ca13C5792Ca10B4029D6ce25708" }
    },
    { "x402Version": 2, "scheme": "exact", "network": "eip155:1187947933" },
    {
      "x402Version": 2,
      "scheme": "exact",
      "network": "solana:5eykt4UsFv8P8NJdTREpY1vzqKqZKvdp",
      "extra": { "feePayer": "3SPm6qbgsDkj24MuR8Ss4sH97fziqyCiqFKDyeVU2igq" }
    }
  ]
}
```

Επεξήγηση αποτελεσμάτων:

- Το `exact` για Base, SKALE και Solana είναι διαδρομή πληρωμής σταθερού ποσού.
- Μόνο το Base παρέχει τη διαδρομή μεταγενέστερης μέτρησης `upto`, η οποία εξαρτάται από Permit2 approve.
- Το `extra.facilitatorAddress` στην εγγραφή `upto` είναι η διεύθυνση που πρέπει να γραφτεί στο witness κατά την υπογραφή από τον πελάτη και πρέπει να είναι ίδια με την τιμή που επιστρέφει ο διακομιστής.

## Base

Το Base χρησιμοποιεί το επίσημο συμβόλαιο USDC:

```text
0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913
```

Στο σχήμα `exact`, ο πελάτης υπογράφει EIP-712 `TransferWithAuthorization`. Το περιεχόμενο της υπογραφής περιλαμβάνει:

- `from`: διεύθυνση πορτοφολιού πληρωμής
- `to`: διεύθυνση είσπραξης του Ace Data Cloud
- `value`: ποσό αυτής της πληρωμής
- `validAfter` / `validBefore`: χρονικό παράθυρο ισχύος της υπογραφής
- `nonce`: τυχαίο nonce 32 byte

Αφού το Facilitator επαληθεύσει την υπογραφή, θα καλέσει on-chain το `transferWithAuthorization` του USDC για την ολοκλήρωση της μεταφοράς.

Το Base είναι το πιο προτεινόμενο δίκτυο για επίσημη ενσωμάτωση, ιδιαίτερα κατάλληλο για μεταγενέστερη μέτρηση `upto`, επειδή τα οικοσυστήματα Permit2, USDC και πορτοφολιών είναι όλα πιο ώριμα.

Παράδειγμα αποτελέσματος επαλήθευσης Base `exact`:

```text
payer 0x5d4f08D5c2bb60703284bc06671Eb680fA41B105
content ADC_BASE_E2E_OK
tx 0x408430ab3451bc22a51e510cdb4b063d6b9686724fea7a31fc109af20f5cd2f3
block 46726299
explorer https://basescan.org/tx/0x408430ab3451bc22a51e510cdb4b063d6b9686724fea7a31fc109af20f5cd2f3
transfer value 95215 atomic USDC
```

Επεξήγηση αποτελεσμάτων:

- Η πληρωμένη επανάληψη του API επέστρεψε το περιεχόμενο μοντέλου `ADC_BASE_E2E_OK`.
- Η on-chain συναλλαγή μπορεί να βρεθεί στο BaseScan και ο αριθμός block είναι `46726299`.
- Τα `95215` atomic USDC αντιστοιχούν σε `0.095215` USDC, το οποίο είναι το πραγματικό ποσό διακανονισμού αυτής της κλήσης API.

Αποτέλεσμα εκτέλεσης προγράμματος για την πληρωμή παραγγελίας Base `exact`:

```text
order 78481793-304e-47f7-bc0c-8231aec9cc1e
state Finished
tx 0xfec08cc00a159ea1ec692b32faa9bf3d17595a986301169e689d94f58bc44151
block 46726704
explorer https://basescan.org/tx/0xfec08cc00a159ea1ec692b32faa9bf3d17595a986301169e689d94f58bc44151
transfer value 1200000 atomic USDC
```

Επεξήγηση αποτελεσμάτων:

- Η τελική κατάσταση της παραγγελίας στην πλατφόρμα είναι `Finished`.
- Το `pay_id` της παραγγελίας γράφει το ίδιο hash συναλλαγής Base.
- Τα `1200000` atomic USDC αντιστοιχούν σε `1.2` USDC, που είναι το ιστορικό πραγματικό πληρωμένο ποσό αυτής της παραγγελίας 10 Credits υπό την παλιά πολιτική· οι νέες παραγγελίες δεν απολαμβάνουν πλέον επιπλέον έκπτωση για τη μέθοδο πληρωμής X402 και το συγκεκριμένο ποσό υπογραφής υπερισχύεται από την απόκριση 402 αυτής της φοράς.

## SKALE

Το SKALE χρησιμοποιεί bridged USDC και η μέθοδος υπογραφής είναι παρόμοια με του Base, επίσης EIP-3009. Είναι κατάλληλο για σενάρια πληρωμών EVM με χαμηλό κόστος gas· οι πραγματικές κλήσεις εξακολουθούν να υπερισχύονται από το `accepts` που επιστρέφει το API.

Το τυπικό `accepts` 402 του SKALE θα περιλαμβάνει:

```json
{
  "network": "eip155:1187947933",
  "scheme": "exact",
  "extra": {
    "name": "Bridged USDC (SKALE Bridge)",
    "version": "2",
    "chainId": 1187947933,
    "verifyingContract": "0x85889c8c714505E0c94b30fcfcF64fE3Ac8FCb20"
  }
}
```

Το SKALE παρέχει επί του παρόντος μόνο `exact`. Εάν χρειάζεστε μεταγενέστερη μέτρηση, χρησιμοποιήστε Base `upto`.

Παράδειγμα αποτελέσματος επαλήθευσης SKALE `exact`:

```text
content ADC_SKALE_E2E_OK
tx 0x9fd09901e74c763325fe118b2bc64765c3fca785b86b24a78b97964384db084f
block 1969317
explorer https://skale-base-explorer.skalenodes.com/tx/0x9fd09901e74c763325fe118b2bc64765c3fca785b86b24a78b97964384db084f
paid 0.095215 USDC
```

Επεξήγηση αποτελεσμάτων:
- Το API paid retry επιστρέφει το περιεχόμενο μοντέλου `ADC_SKALE_E2E_OK`。
- Η συναλλαγή είναι ήδη αναζητήσιμη στο SKALE explorer, και ο αριθμός block είναι `1969317`。
- Το ποσό διακανονισμού αυτής της πληρωμής `exact` είναι `0.095215` USDC。

## Solana

Το Solana χρησιμοποιεί SPL USDC `TransferChecked`。Ο πελάτης θα κατασκευάσει μια συναλλαγή μεταφοράς, θα την υπογράψει και θα την υποβάλει, και στη συνέχεια θα τοποθετήσει την υπογραφή συναλλαγής ή τη σειριοποιημένη συναλλαγή στο envelope `PAYMENT-SIGNATURE`。

Χαρακτηριστικά του Solana：

- Χρησιμοποιεί Solana wallet adapter ή base58 secret key；
- Το περιουσιακό στοιχείο είναι το Solana USDC mint；
- Προς το παρόν υποστηρίζεται μόνο το `exact`；
- Το Facilitator θα επαληθεύσει το mint, το destination, το authority και το amount του transfer instruction。

Εάν χρησιμοποιείται η λειτουργία wallet fee payer, το wallet θα υποβάλει απευθείας τη συναλλαγή, και το Facilitator είναι υπεύθυνο για την επιβεβαίωση της συναλλαγής και την επιστροφή του αποτελέσματος settlement。

Παράδειγμα αποτελέσματος επαλήθευσης Solana `exact`：

```text
payer AY2RmGm2zPxB1uKvvF4dKyYdr2VySyL3wcD1MKJZoLRd
HTTP 402 -> HTTP 200
content ADC_SOLANA_E2E_OK
chain signature not confirmed in this run
```

Επεξήγηση αποτελέσματος：

- Το paid retry έχει ήδη επιστρέψει HTTP 200, και η έξοδος μοντέλου είναι `ADC_SOLANA_E2E_OK`。
- Κατά την αναζήτηση του on-chain signature μέσω δημόσιου RPC ενδέχεται να προκύψει rate limiting。
- Επειδή οι αναζητήσεις δημόσιου RPC μπορεί να περιορίζονται, εδώ δεν αναγράφεται Solana explorer。Όταν απαιτείται αυστηρή συμφωνία, χρησιμοποιήστε δικό σας Solana RPC ή αρχεία διακανονισμού από την πλευρά της πλατφόρμας για να επιβεβαιώσετε το signature συναλλαγής。

## Πώς να επιλέξετε

| Τι θέλετε να κάνετε        | Προτεινόμενο δίκτυο                         |
| ------------ | ---------------------------- |
| Να ολοκληρώσετε γρήγορα την ελάχιστη ροή     | SKALE `exact` ή Base `exact` |
| Για κοινούς χρήστες Web3 | Base                         |
| Για μεταγενέστερη μέτρηση, όπως chat completion   | Base `upto`                  |
| Εφαρμογές οικοσυστήματος Solana  | Solana `exact`               |
| Επαλήθευση πληρωμών EVM χαμηλού κόστους | SKALE `exact`                |

Ανεξάρτητα από το chain που θα επιλέξετε, μην κάνετε hardcode την τιμή στον πελάτη。Η τιμή καθορίζεται από το `accepts[].maxAmountRequired` που επιστρέφει ο server。

## Νέα δίκτυα EVM

Οι πληρωμές σταθερού ποσού σε native USDC για τα παρακάτω δίκτυα υποστηρίζονται ήδη από τον κώδικα και θα ενεργοποιούνται ανά δίκτυο。
Η διαθεσιμότητα καθορίζεται από το `accepts` που επιστρέφει η παραγγελία ή το API· αυτό δεν σημαίνει ότι όλα τα δίκτυα έχουν ενεργοποιηθεί στην παραγωγή。

| Network      | Alias      | CAIP-2         | Native USDC                                  |
| ------------ | ---------- | -------------- | -------------------------------------------- |
| Arbitrum One | `arbitrum` | `eip155:42161` | `0xaf88d065e77c8cC2239327C5EDb3A432268e5831` |

Αυτά τα δίκτυα υποστηρίζουν μόνο `exact`, και η ακρίβεια του νομίσματος είναι 6。Μη χρησιμοποιείτε bridged USDC με το ίδιο όνομα。
Όταν χρησιμοποιείτε τον επίσημο TypeScript/Python X402 Client, μπορείτε να περάσετε τη συντομογραφία ή το αναγνωριστικό CAIP-2 του πίνακα。
Ο πελάτης χρησιμοποιεί το ID του target chain για την κατασκευή της υπογραφής· το wallet πρέπει να υποστηρίζει το target network。

Ο επίσημος πίνακας υποστήριξης του Phantom extension wallet περιλαμβάνει Arbitrum και Polygon· τα Optimism、Avalanche
δεν περιλαμβάνονται επί του παρόντος σε αυτόν τον πίνακα, και μπορείτε να χρησιμοποιήσετε Rabby ή MetaMask που υποστηρίζει το target chain。Οι διευθύνσεις EVM μπορούν να είναι ίδιες σε διαφορετικά chain,
αλλά τα υπόλοιπα είναι ανεξάρτητα μεταξύ τους, και οι διευθύνσεις Solana δεν ισχύουν για EVM USDC。
Δείτε τον [πίνακα υποστήριξης Phantom wallet](https://docs.phantom.com/wallet-sdks-overview#chain-support)。

### Είσοδος σταδιακής ενεργοποίησης νέου δικτύου

Η είσοδος για νέα chain είναι κρυφή από προεπιλογή。Κατά την πρόσβαση στην κονσόλα ή στο Studio, μπορείτε να χρησιμοποιήσετε `?features=x402-arbitrum`
για να ενεργοποιήσετε το αντίστοιχο chain, και πολλαπλά flag διαχωρίζονται με κόμμα。Για να απενεργοποιήσετε ένα μόνο chain, χρησιμοποιήστε `?features=-x402-arbitrum`，
και για να καθαρίσετε τις τοπικές παρακάμψεις, χρησιμοποιήστε `?features=none`。Οι διακόπτες αποθηκεύονται ξεχωριστά για κάθε domain。
Η προσφορά παραγγελίας και το retry πληρωμής χρησιμοποιούν τον ίδιο διακόπτη, ενώ ο server θα πραγματοποιήσει ανεξάρτητη επαλήθευση· τα υπάρχοντα αρχεία πληρωμών εξακολουθούν να είναι ορατά。
Η ενεργοποίηση μόνο του page flag δεν θα ενεργοποιήσει chain που δεν έχουν ακόμη ρυθμιστεί, και τα συγκεκριμένα πληρώσιμα δίκτυα εξακολουθούν να καθορίζονται από το πραγματικού χρόνου `accepts`。
