Κατεβάστε απευθείας τις λεπτομέρειες κλήσεων API του τρέχοντος λογαριασμού ως CSV, κατάλληλο για οικονομική συμφωνία, ανάλυση εκτός σύνδεσης ή αποθήκευση μεγάλου όγκου εγγραφών. Εάν χρειάζεται μόνο να προβάλετε μικρό αριθμό λεπτομερειών στη σελίδα, χρησιμοποιήστε πρώτα τη [λίστα αρχείων καταγραφής κλήσεων](https://platform.acedata.cloud/documents/platform-usage-list).

Το εύρος ερωτήματος για τα αρχεία καταγραφής κλήσεων και τη σύνοψη χρέωσης είναι οι πιο πρόσφατες 60 ημέρες· το σώμα αιτήματος και απόκρισης διατηρείται ξεχωριστά για τις πιο πρόσφατες 30 ημέρες. Η λήξη του σώματος δεν αλλάζει την πραγματική χρέωση, τη χρήση ή τα συγκεντρωτικά στατιστικά αυτής της εγγραφής.

## Προετοιμασία

1. Συνδεθείτε στην [πλατφόρμα AceDataCloud](https://platform.acedata.cloud).
2. Δημιουργήστε ένα διακριτικό λογαριασμού στην [κονσόλα Account Token](https://platform.acedata.cloud/console/platform-tokens) και αποθηκεύστε το αμέσως σε έναν διαχειριστή κωδικών πρόσβασης ή στο Secret Manager.
3. Ανάλογα με τις ανάγκες, λάβετε τα ID φίλτρων από τη [λίστα αιτήσεων υπηρεσίας](https://platform.acedata.cloud/documents/platform-application-list), τη [λίστα διαπιστευτηρίων API](https://platform.acedata.cloud/documents/platform-credential-list) ή τη [λίστα API](https://platform.acedata.cloud/documents/platform-api-list).

Για πλήρεις οδηγίες σχετικά με τα διακριτικά, ανατρέξτε στη [διαχείριση διακριτικών λογαριασμού](https://platform.acedata.cloud/documents/platform-token). Το διακριτικό λογαριασμού και το Credential που χρησιμοποιείται για την κλήση επιχειρηματικών API δεν μπορούν να χρησιμοποιηθούν εναλλακτικά.

```shell
export PLATFORM_TOKEN='το διακριτικό λογαριασμού σας'
```

## Επισκόπηση διεπαφής

| Στοιχείο           | Περιεχόμενο                                               |
| ----------------- | -------------------------------------------------------- |
| Μέθοδος           | `GET`                                                    |
| URL               | `https://platform.acedata.cloud/api/v1/usage/apis/export/` |
| Επαλήθευση        | `Authorization: Bearer ${PLATFORM_TOKEN}`                |
| OAuth Scope       | `usage:read`（`platform:read` / `platform` μπορεί να περιλαμβάνει） |
| Απόκριση          | `200 text/csv; charset=utf-8`                            |
| Όνομα αρχείου     | `usages.csv`                                             |

Αυτή η διεπαφή επιστρέφει σύγχρονα το CSV μέσω ροής, δεν δημιουργεί εργασία εξαγωγής και δεν επιστρέφει JSON ή σύνδεσμο λήψης. Μόνο όταν δεν παρέχονται και οι δύο χρόνοι έναρξης και λήξης, εξάγονται από προεπιλογή οι εγγραφές από την αρχή του τρέχοντος ημερολογιακού μήνα έως την τρέχουσα στιγμή· όταν παρέχεται μόνο ένα όριο, το άλλο δεν συμπληρώνεται αυτόματα με το όριο του τρέχοντος μήνα.

## Παράμετροι ερωτήματος

| Παράμετρος         | Τύπος      | Υποχρεωτικό | Προεπιλογή | Περιγραφή                        |
| ----------------- | --------- | ---------- | ---------- | -------------------------------- |
| `perspective`     | string    | Όχι        | `both`     | `billing`, `actor` ή `both`      |
| `service_id`      | UUID      | Όχι        | —          | Φιλτράρισμα κατά υπηρεσία· υποστηρίζει επαναλαμβανόμενη παράμετρο |
| `application_id`  | UUID      | Όχι        | —          | Φιλτράρισμα κατά Application· υποστηρίζει επαναλαμβανόμενη παράμετρο |
| `api_id`          | UUID      | Όχι        | —          | Φιλτράρισμα κατά API· υποστηρίζει επαναλαμβανόμενη παράμετρο |
| `credential_id`   | UUID      | Όχι        | —          | Φιλτράρισμα κατά διαπιστευτήριο API· υποστηρίζει επαναλαμβανόμενη παράμετρο |
| `status_code`     | integer   | Όχι        | —          | Υποστηρίζει επαναλαμβανόμενες ή διαχωρισμένες με κόμμα τιμές |
| `created_at_from` | datetime  | Όχι        | —          | Χρόνος έναρξης ISO 8601          |
| `created_at_to`   | datetime  | Όχι        | —          | Χρόνος λήξης ISO 8601            |

Το εύρος εξαγωγής περιορίζεται πάντα στις εγγραφές που είναι ορατές στον τρέχοντα λογαριασμό ως οντότητα πληρωμής και/ή πραγματικός καλών, και δεν υποστηρίζεται η εξαγωγή μεταξύ λογαριασμών.

## Παραδείγματα αιτημάτων

Αποθηκεύστε απευθείας το CSV του τρέχοντος μήνα:

```shell
curl --fail-with-body --location \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

Εξαγωγή κατά Application, χρόνο και κωδικό κατάστασης:

```shell
export APPLICATION_ID='το Application ID σας'

curl --fail-with-body --get \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'status_code=200,500' \
  --data-urlencode 'created_at_from=2026-09-01T00:00:00Z' \
  --data-urlencode 'created_at_to=2026-09-08T00:00:00Z' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

Αποθήκευση μέσω ροής και έλεγχος ακεραιότητας με Python:

```python
import os
from pathlib import Path

import requests

url = "https://platform.acedata.cloud/api/v1/usage/apis/export/"
headers = {"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"}
params = {
    "created_at_from": "2026-09-01T00:00:00Z",
    "created_at_to": "2026-09-08T00:00:00Z",
    "perspective": "both",
}
output = Path("usages.csv")

with requests.get(url, headers=headers, params=params, stream=True, timeout=120) as response:
    response.raise_for_status()
    if not response.headers.get("content-type", "").startswith("text/csv"):
        raise RuntimeError("服务器没有返回 CSV")
    with output.open("wb") as file:
        for chunk in response.iter_content(chunk_size=64 * 1024):
            file.write(chunk)

last_line = output.read_text(encoding="utf-8").splitlines()[-1]
if last_line.startswith("# truncated:") or last_line.startswith("# error:"):
    raise RuntimeError(f"导出不完整：{last_line}")
```

## Στήλες CSV

Η σειρά της κεφαλίδας CSV είναι σταθερή:

```text
Usage ID,API,Status Code,Deducted Amount,Original Amount,Trace ID,Created At
```

| Στήλη             | Περιγραφή                                      |
| ---------------- | --------------------------------------------- |
| `Usage ID`       | ID εγγραφής κλήσης                             |
| `API`            | Τίτλος API· όταν δεν είναι δυνατή η αντιστοίχιση, μπορεί να είναι το ID API ή κενή τιμή |
| `Status Code`    | Κωδικός κατάστασης HTTP                        |
| `Deducted Amount` | Τελικό πραγματικά αφαιρεθέν ποσό               |
| `Original Amount` | Αρχικό ποσό πριν από την έκπτωση Application   |
| `Trace ID`       | Αναγνωριστικό παρακολούθησης αιτήματος         |
| `Created At`     | Χρόνος δημιουργίας εγγραφής, ISO 8601          |

Η μονάδα ποσού καθορίζεται από το `service.unit` του αντίστοιχου Application.

## Έλεγχος εάν η εξαγωγή είναι πλήρης

Μία φορά μπορούν να εξαχθούν έως 1.000.000 εγγραφές. Αφού ο διακομιστής αρχίσει να επιστρέφει CSV, δεν μπορεί πλέον να μετατρέψει ένα ενδιάμεσο σφάλμα σε άλλη κατάσταση HTTP, επομένως ο πελάτης πρέπει να ελέγχει την τελευταία γραμμή:

- `# truncated:`：Επιτεύχθηκε το όριο γραμμών· εξαγάγετε τμηματικά με μικρότερα χρονικά παράθυρα.
- `# error:`：Η ανάγνωση μέσω ροής διακόπηκε· μειώστε το εύρος και εξαγάγετε ξανά.

Όταν το πρόγραμμα συμφωνίας εντοπίζει οποιοδήποτε marker, πρέπει να θεωρεί το αρχείο ελλιπές και δεν μπορεί να το καταχωρεί σιωπηρά.

## Σφάλματα και επανάληψη

| Περίπτωση                    | Τρόπος χειρισμού                                      |
| --------------------------- | ---------------------------------------------------- |
| `400 usage_history_expired` | Προσαρμόστε, χρησιμοποιώντας το `available_from` της απόκρισης, εντός του εύρους των πιο πρόσφατων 60 ημερών |
| `401 not_authenticated`     | Ελέγξτε εάν το Account Token υπάρχει, είναι σωστό και δεν έχει διαγραφεί |
| Απόκριση που δεν είναι CSV   | Μην την αποθηκεύετε ως επιτυχημένο αρχείο· πρώτα διαβάστε την απόκριση σφάλματος και διορθώστε το αίτημα |
| Διακοπή λήψης ή marker       | Μειώστε το χρονικό παράθυρο, χρησιμοποιήστε στρατηγική υποχώρησης και εξαγάγετε ξανά |
