Κατεβάστε απευθείας τα στοιχεία κλήσεων API του τρέχοντος λογαριασμού ως CSV, κατάλληλο για οικονομική συμφωνία, ανάλυση εκτός σύνδεσης ή αποθήκευση μεγάλου όγκου αρχείων. Εάν χρειάζεται μόνο να δείτε μικρό αριθμό στοιχείων στη σελίδα, χρησιμοποιήστε πρώτα τη [λίστα αρχείων καταγραφής κλήσεων](https://platform.acedata.cloud/documents/platform-usage-list).

## Προετοιμασία

1. Συνδεθείτε στην [πλατφόρμα AceDataCloud](https://platform.acedata.cloud).
2. Δημιουργήστε ένα διακριτικό λογαριασμού στην [κονσόλα Account Token](https://platform.acedata.cloud/console/platform-tokens) και αποθηκεύστε το αμέσως σε διαχειριστή κωδικών πρόσβασης ή Secret Manager.
3. Λάβετε τα ID φιλτραρίσματος, όπως απαιτείται, από τη [λίστα αιτήσεων υπηρεσίας](https://platform.acedata.cloud/documents/platform-application-list), τη [λίστα διαπιστευτηρίων API](https://platform.acedata.cloud/documents/platform-credential-list) ή τη [λίστα API](https://platform.acedata.cloud/documents/platform-api-list).

Για πλήρεις οδηγίες σχετικά με τα διακριτικά, δείτε τη [διαχείριση διακριτικών λογαριασμού](https://platform.acedata.cloud/documents/platform-token). Το διακριτικό λογαριασμού και το Credential για την κλήση επιχειρηματικών API δεν μπορούν να χρησιμοποιηθούν εναλλακτικά.

```shell
export PLATFORM_TOKEN='你的账户令牌'
```

## Επισκόπηση διεπαφής

| Στοιχείο           | Περιεχόμενο                                                |
| ----------------- | ---------------------------------------------------------- |
| Μέθοδος           | `GET`                                                      |
| URL               | `https://platform.acedata.cloud/api/v1/usage/apis/export/` |
| Επαλήθευση        | `Authorization: Bearer ${PLATFORM_TOKEN}`                  |
| OAuth Scope       | `usage:read`（`platform:read` / `platform` 可展开包含）           |
| Απόκριση          | `200 text/csv; charset=utf-8`                              |
| Όνομα αρχείου     | `usages.csv`                                               |

Αυτή η διεπαφή επιστρέφει συγχρονισμένα το CSV ως ροή, δεν δημιουργεί εργασία εξαγωγής και δεν επιστρέφει JSON ή σύνδεσμο λήψης. Μόνο όταν δεν παρέχονται τόσο η ώρα έναρξης όσο και η ώρα λήξης, εξάγονται από προεπιλογή τα αρχεία από την αρχή του τρέχοντος ημερολογιακού μήνα έως την τρέχουσα στιγμή· όταν παρέχεται μόνο ένα όριο, το άλλο όριο δεν συμπληρώνεται αυτόματα με το όριο του τρέχοντος μήνα.

## Παράμετροι ερωτήματος

| Παράμετρος        | Τύπος      | Υποχρεωτικό | Προεπιλογή | Περιγραφή                              |
| ---------------- | --------- | ----------- | ---------- | -------------------------------------- |
| `perspective`     | string   | Όχι         | `both`     | `billing`, `actor` ή `both`            |
| `service_id`      | UUID     | Όχι         | —          | Φιλτράρισμα κατά υπηρεσία· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `application_id`  | UUID     | Όχι         | —          | Φιλτράρισμα κατά Application· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `api_id`          | UUID     | Όχι         | —          | Φιλτράρισμα κατά API· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `credential_id`   | UUID     | Όχι         | —          | Φιλτράρισμα κατά διαπιστευτήριο API· υποστηρίζει επαναλαμβανόμενες παραμέτρους |
| `status_code`     | integer  | Όχι         | —          | Υποστηρίζει επαναλαμβανόμενες ή τιμές διαχωρισμένες με κόμμα |
| `created_at_from` | datetime | Όχι         | —          | Ώρα έναρξης ISO 8601                   |
| `created_at_to`   | datetime | Όχι         | —          | Ώρα λήξης ISO 8601                     |

Το εύρος εξαγωγής περιορίζεται πάντοτε στα αρχεία που είναι ορατά στον τρέχοντα λογαριασμό ως φορέα πληρωμής και/ή πραγματικό καλούντα και δεν υποστηρίζει εξαγωγή μεταξύ λογαριασμών.

## Παραδείγματα αιτημάτων

Αποθηκεύστε απευθείας το CSV του τρέχοντος μήνα:

```shell
curl --fail-with-body --location \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

Εξαγωγή κατά Application, ώρα και κωδικό κατάστασης:

```shell
export APPLICATION_ID='你的 Application ID'

curl --fail-with-body --get \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'status_code=200,500' \
  --data-urlencode 'created_at_from=2026-09-01T00:00:00Z' \
  --data-urlencode 'created_at_to=2026-09-08T00:00:00Z' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

Αποθήκευση ροής με Python και έλεγχος ακεραιότητας:

```python
import os
from pathlib import Path

import requests

url = "https://platform.acedata.cloud/api/v1/usage/apis/export/"
headers = {"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"}
params = {
    "created_at_from": "2026-09-01T00:00:00Z",
    "created_at_to": "2026-09-08T00:00:00Z",
    "perspective": "both",
}
output = Path("usages.csv")

with requests.get(url, headers=headers, params=params, stream=True, timeout=120) as response:
    response.raise_for_status()
    if not response.headers.get("content-type", "").startswith("text/csv"):
        raise RuntimeError("服务器没有返回 CSV")
    with output.open("wb") as file:
        for chunk in response.iter_content(chunk_size=64 * 1024):
            file.write(chunk)

last_line = output.read_text(encoding="utf-8").splitlines()[-1]
if last_line.startswith("# truncated:") or last_line.startswith("# error:"):
    raise RuntimeError(f"导出不完整：{last_line}")
```

## Στήλες CSV

Η σειρά των κεφαλίδων CSV είναι σταθερή ως εξής:

```text
Usage ID,API,Status Code,Deducted Amount,Original Amount,Trace ID,Created At
```

| Στήλη              | Περιγραφή                                |
| ------------------ | ---------------------------------------- |
| `Usage ID`         | ID αρχείου καταγραφής κλήσης             |
| `API`              | Τίτλος API· εάν δεν είναι δυνατή η αντιστοίχιση, μπορεί να είναι το ID API ή κενή τιμή |
| `Status Code`      | Κωδικός κατάστασης HTTP                  |
| `Deducted Amount`  | Τελικό ποσό μονάδων που αφαιρέθηκε πραγματικά |
| `Original Amount`  | Αρχικό ποσό μονάδων πριν από την έκπτωση της εφαρμογής |
| `Trace ID`         | Αναγνωριστικό παρακολούθησης αιτήματος   |
| `Created At`       | Χρόνος δημιουργίας αρχείου, ISO 8601     |

Η μονάδα ποσόστωσης καθορίζεται από το `service.unit` του αντίστοιχου Application.

## Καθορισμός εάν η εξαγωγή είναι πλήρης

Μία μόνο εξαγωγή μπορεί να παράγει έως 1.000.000 γραμμές δεδομένων. Αφού ο διακομιστής έχει αρχίσει να επιστρέφει CSV, δεν μπορεί πλέον να αλλάξει ένα ενδιάμεσο σφάλμα σε άλλη κατάσταση HTTP, επομένως ο πελάτης πρέπει να ελέγξει την τελευταία γραμμή:

- `# truncated:`：Έχει επιτευχθεί το όριο γραμμών· εξαγάγετε τμηματικά με μικρότερα χρονικά παράθυρα.
- `# error:`：Η ανάγνωση ροής διακόπηκε· μειώστε το εύρος και εξαγάγετε ξανά.

Όταν το πρόγραμμα συμφωνίας εντοπίζει οποιοδήποτε marker, πρέπει να θεωρεί το αρχείο ελλιπές και δεν μπορεί να το καταχωρίσει σιωπηρά.

## Σφάλματα και επαναλήψεις

| Περίπτωση                    | Τρόπος χειρισμού                                      |
| --------------------------- | ----------------------------------------------------- |
| `400 usage_history_expired` | Προσαρμόστε, χρησιμοποιώντας το `available_from` στην απόκριση, σε εύρος των τελευταίων 60 ημερών |
| `401 not_authenticated`     | Ελέγξτε εάν το Account Token υπάρχει, είναι σωστό και δεν έχει διαγραφεί |
| Απόκριση που δεν είναι CSV  | Μην αποθηκεύσετε ως επιτυχημένο αρχείο· πρώτα διαβάστε την απόκριση σφάλματος και διορθώστε το αίτημα |
| Διακοπή λήψης ή marker      | Μειώστε το χρονικό παράθυρο και εξαγάγετε ξανά χρησιμοποιώντας στρατηγική backoff |
