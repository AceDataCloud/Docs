## 1. Λήψη API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), εισέλθετε στην διαθέσιμη εφαρμογή και αντιγράψτε το API Key.

![Λήψη Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Προσθήκη Provider

Ανοίξτε το Cherry Studio, μεταβείτε στις **Ρυθμίσεις → Υπηρεσίες μοντέλων → Προσθήκη παρόχου** και συμπληρώστε:

| Πεδίο      | Τιμή                           |
| ------- | --------------------------- |
| Όνομα παρόχου   | `Ace Data Cloud`            |
| Τύπος παρόχου   | `OpenAI`                    |
| API Key | Το API Key που μόλις αντιγράψατε               |
| Διεύθυνση API  | `https://api.acedata.cloud` |

![Διεπαφή διαμόρφωσης προσθήκης Ace Data Cloud Provider στο Cherry Studio](https://cdn.acedata.cloud/b67a927eae62.png)

Το Cherry Studio θα συμπληρώσει αυτόματα το `/v1/chat/completions` για τον τύπο OpenAI. Όταν χρησιμοποιείτε τη γενική είσοδο, μην προσθέτετε `#` στο τέλος της διεύθυνσης και δεν χρειάζεται να δημιουργήσετε πολλαπλούς Provider ανά οικογένεια μοντέλων.

## 3. Προσθήκη και ενεργοποίηση μοντέλου

1. Κάντε κλικ στο **Λήψη λίστας μοντέλων**· εάν η τρέχουσα έκδοση δεν υποστηρίζει αυτόματη λήψη, μεταβείτε στον [κατάλογο μοντέλων](https://platform.acedata.cloud/models) για έλεγχο και, στη συνέχεια, προσθέστε χειροκίνητα το όνομα του μοντέλου-στόχου, για παράδειγμα `claude-opus-5`, `gpt-6-sol`.
2. Κάντε κλικ στο κουμπί ελέγχου δίπλα στο API Key για να επαληθεύσετε τη σύνδεση.
3. Ενεργοποιήστε τον διακόπτη **Ενεργοποίηση** του Provider.
4. Επιλέξτε το μοντέλο που μόλις προσθέσατε στον επιλογέα μοντέλου συνομιλίας.

![Λίστα Cherry Studio Provider και μοντέλων](https://cdn.acedata.cloud/149de1d088bf.png)

> Αφού ολοκληρώσετε τη λήψη ή τη χειροκίνητη προσθήκη μοντέλου, ενεργοποιήστε τον διακόπτη Provider επάνω δεξιά.

Στείλτε `Reply only OK` και ελέγξτε την κλήση στο [ιστορικό χρήσης](https://platform.acedata.cloud/console/usages). Για 401 ελέγξτε το Key· όταν δεν εμφανίζεται το μοντέλο, ελέγξτε εάν ο Provider είναι ενεργοποιημένος· για 404 ελέγξτε εάν το όνομα μοντέλου που συμπληρώθηκε χειροκίνητα αντιστοιχεί ακριβώς στο `id` του καταλόγου.

## Σχετικά με το GPT Image 2

Ο συνηθισμένος προσαρμοσμένος Provider συνομιλίας του Cherry Studio δεν μπορεί να καλέσει απευθείας το Images API. Η δημιουργία και επεξεργασία `gpt-image-2` πρέπει να χρησιμοποιεί την ειδική διεπαφή Ace Data Cloud:

- [Δημιουργία εικόνων GPT Image 2](https://platform.acedata.cloud/documents/openai-images-generations)
- [Επεξεργασία εικόνων GPT Image 2](https://platform.acedata.cloud/documents/openai-images-edits)

Μην συμπληρώνετε το `/openai/images/generations` στον Provider συνομιλίας.
