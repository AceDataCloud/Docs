Η επίσημη υποστήριξη του Coze για την σύνδεση προσαρμοσμένων μοντέλων παρέχει τρία πρωτόκολλα: OpenAI Chat API, OpenAI Responses API και Anthropic Messages API. Οι τρεις διαδρομές έχουν διαφορετικά Base URL, διαδρομές σύνθεσης, Header, streaming και συμβόλαια κλήσεων εργαλείων, επομένως πρέπει να ρυθμιστούν και να επαληθευτούν ξεχωριστά.

| Διαδρομή                  | Κατάσταση  | Οδηγίες                                                                                  |
| ----------------------- | --- | ----------------------------------------------------------------------------------- |
| OpenAI Chat Completions | Πειραματική | [Διαμόρφωση Chat](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | Πειραματική | [Διαμόρφωση Responses](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | Πειραματική | [Διαμόρφωση Messages](https://platform.acedata.cloud/documents/coze-messages-integration)   |

“Πειραματική” σημαίνει ότι οι επίσημες δυνατότητες και η είσοδος διαμόρφωσης έχουν επιβεβαιωθεί, αλλά διαφορετικές περιοχές, εκδόσεις ή πακέτα του Coze μπορεί να εμφανίζουν διαφορετικές φόρμες, η Ace Data Cloud πρέπει να ολοκληρώσει την επαλήθευση σταθερής έκδοσης σύμφωνα με το πρωτόκολλο. Μην επεκτείνετε την επιτυχία μιας συγκεκριμένης πρωτοκόλλου σε άλλες δύο.

## Αρχές Διαμόρφωσης

- Το Base API URL πρέπει να συμπληρώνεται πρώτα με το base που παρέχεται από το έγγραφο; μην προσθέτετε ξανά το endpoint path που θα συμπληρωθεί αυτόματα από τον πελάτη.
- Το API Key χρησιμοποιεί το API Token της Ace Data Cloud.
- Το Model χρησιμοποιεί το ακριβές ID μοντέλου που είναι συμβατό με το επιλεγμένο πρωτόκολλο στον κατάλογο μοντέλων.
- Μετά την επιτυχία του κανονικού κειμένου, θα πρέπει επίσης να επαληθευτεί το streaming και οι κλήσεις εργαλείων.
