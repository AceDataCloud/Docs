Το [ChatBox](https://chatboxai.app/) είναι ένας ανοιχτού κώδικα πελάτης AI που υποστηρίζει Windows, macOS, Linux, iOS, Android και Web. Υποστηρίζει προσαρμοσμένους παρόχους τύπου «OpenAI API», επομένως μπορεί να συνδεθεί απευθείας με το Ace Data Cloud. Αυτό το άρθρο παρουσιάζει τη διαδικασία διαμόρφωσης.

## Διαδικασία αίτησης

Για να συνδέσετε το Ace Data Cloud στο ChatBox, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications), λάβετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![Λήψη Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης, η οποία θα σας προσκαλέσει να εγγραφείτε και να συνδεθείτε. Μετά τη σύνδεση ή την εγγραφή, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση παρέχεται δωρεάν ποσό χρήσης, ώστε να μπορείτε να δοκιμάσετε δωρεάν τις υπηρεσίες μοντέλων του Ace Data Cloud.

## Λήψη του ChatBox

Μεταβείτε στον [επίσημο ιστότοπο του ChatBox](https://chatboxai.app/) για λήψη ανά πλατφόρμα ή χρησιμοποιήστε απευθείας την έκδοση [Web](https://web.chatboxai.app/) που δεν απαιτεί εγκατάσταση:

- Επιτραπέζιο: Windows `.exe`, macOS `.dmg` (διαχωρισμός Intel / Apple Silicon), Linux AppImage
- Κινητό: App Store, Google Play, απευθείας σύνδεσμος Android από τον επίσημο ιστότοπο

## Διαμόρφωση του Ace Data Cloud

Εκκινήστε το ChatBox, μεταβείτε στις **Ρυθμίσεις → Μοντέλα → Προσθήκη προσαρμοσμένου Provider**, ορίστε το **API Mode** σε **OpenAI API Compatible** και στη συνέχεια συμπληρώστε:

| Πεδίο | Τιμή | Περιγραφή |
| -------- | --------------------------- | --------------------------------------- |
| Κλειδί API | Το Ace Data Cloud Token σας | Το Token που αντιγράφηκε από την κονσόλα |
| API Host | `https://api.acedata.cloud` | Συμπληρώστε μόνο το ριζικό όνομα τομέα, **μην προσθέσετε `/openai` ή `/v1`** |
| API Path | `/v1/chat/completions` | Το προεπιλεγμένο του ChatBox είναι `/chat/completions`, πρέπει να το αλλάξετε χειροκίνητα σε αυτό |

![Διεπαφή διαμόρφωσης ChatBox Ace Data Cloud Provider](https://cdn.acedata.cloud/3789c8e3dd4d.png)

Η διαδρομή αιτήματος του ChatBox είναι `{API Host} + {API Path}`, επομένως στο Host αρκεί να συμπληρώσετε μόνο το ριζικό όνομα τομέα:

| API Host | Τελικό αίτημα | Αποτέλεσμα |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud` | `https://api.acedata.cloud/v1/chat/completions` | Σωστό |
| `https://api.acedata.cloud/openai` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (δεν υπάρχει `/v1` κάτω από το `/openai`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404 |

Το ChatBox δεν καλεί αυτόματα το `/v1/models`. Πρέπει να συμπληρώσετε χειροκίνητα τα ID των μοντέλων (ένα ανά γραμμή) στο πεδίο «Προσαρμοσμένα μοντέλα» στο κάτω μέρος της σελίδας ρυθμίσεων μοντέλων. Μετά την αποθήκευση, μπορείτε να τα επιλέξετε από το αναπτυσσόμενο μενού μοντέλων στη διεπαφή συνομιλίας. Οι διακόπτες δυνατοτήτων, το παράθυρο περιβάλλοντος και το ανώτατο όριο εξόδου πρέπει να συμπληρώνονται σύμφωνα με το τρέχον συμβόλαιο του επιλεγμένου μοντέλου· μην αντιγράφετε τις τιμές άλλων μοντέλων.

## Επιλογή μοντέλου

Ο κατάλογος μοντέλων θα ενημερώνεται συνεχώς. Δώστε προτεραιότητα στη λίστα μοντέλων που φορτώνεται αυτόματα από τον πελάτη· όταν απαιτείται χειροκίνητη συμπλήρωση, ζητήστε πρώτα `GET https://api.acedata.cloud/v1/models` για να λάβετε τα τρέχοντα ID μοντέλων και, στη συνέχεια, επιλέξτε με βάση τις δυνατότητες περιβάλλοντος, εικόνων και κλήσης εργαλείων που υποστηρίζει ο πελάτης.

## Επαλήθευση σύνδεσης

Αν δεν είστε βέβαιοι αν το πρόβλημα βρίσκεται στο ChatBox ή στο δίκτυο, μπορείτε πρώτα να χρησιμοποιήσετε curl για να επαληθεύσετε απευθείας το endpoint (αντικαταστήστε το `{token}` με το Token σας):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Η επιστροφή ενός αντικειμένου `chat.completion` συμβατού με OpenAI υποδεικνύει ότι τόσο το Token όσο και το endpoint είναι έτοιμα· αν επιστρέφεται `HTTP 403 used_up`, αυτό υποδεικνύει ότι το Token είναι έγκυρο αλλά το υπόλοιπο είναι ανεπαρκές. Μεταβείτε στην [κονσόλα](https://platform.acedata.cloud/console/applications) για ανανέωση υπολοίπου.

## Συχνές ερωτήσεις

### Εμφανίζεται 404 Not Found

Συνήθως το API Host περιέχει επιπλέον `/openai` ή `/v1`. Στο Host συμπληρώστε μόνο `https://api.acedata.cloud` και αφήστε τη διαδρομή στο προεπιλεγμένο `/v1/chat/completions`.

### Εμφανίζεται 401 / token_mismatched

Παρακαλούμε επιβεβαιώστε ότι στο «Κλειδί API» έχετε επικολλήσει το Token του Ace Data Cloud (χωρίς πρόθεμα `Bearer`, χωρίς επιπλέον κενά) και ότι το υπόλοιπο της αντίστοιχης εφαρμογής είναι επαρκές.

### Δεν εμφανίζεται μοντέλο στο αναπτυσσόμενο μενού μοντέλων

Το ChatBox δεν ανακτά αυτόματα τη λίστα μοντέλων. Πρέπει να συμπληρώσετε χειροκίνητα τα ID των μοντέλων στο πεδίο «Προσαρμοσμένα μοντέλα» και να τα αποθηκεύσετε.

### Θέλω να δημιουργήσω εικόνες στο ChatBox

Η δημιουργία εικόνων του Ace Data Cloud είναι ένα ανεξάρτητο Images API (`/openai/images/generations`), με διαφορετική διαδρομή από το API συνομιλίας, και η είσοδος εικόνων του ChatBox δεν μπορεί να συνδεθεί απευθείας. Αν χρειάζεστε δημιουργία εικόνων, ανατρέξτε στην [τεκμηρίωση Image Generation API](https://platform.acedata.cloud/documents/openai-images-generations) για κλήση μέσω curl / SDK.
