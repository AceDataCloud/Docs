Η επίσημη επέκταση IDE του OpenCode υποστηρίζει επεξεργαστές όπως το VS Code, Cursor, Windsurf, VSCodium κ.λπ., και επαναχρησιμοποιεί το τοπικό runtime και τη ρύθμιση του Provider του OpenCode. Η επέκταση IDE επαναχρησιμοποιεί τον τοπικό CLI Provider, αλλά η αλυσίδα αιτημάτων μπορεί να διαφέρει ανάλογα με την έκδοση του επεξεργαστή. Κατά την πρώτη σύνδεση, παρακαλώ σταθεροποιήστε την έκδοση και ολοκληρώστε την ελάχιστη επαλήθευση.

## Ρύθμιση Provider

Αρχικά, ακολουθήστε την [ρύθμιση του OpenCode Terminal](https://platform.acedata.cloud/documents/opencode-terminal-integration) για να ρυθμίσετε τον Ace Data Cloud Provider στο `opencode.json` ή `opencode.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## Εγκατάσταση IDE Extension

1. Εκτελέστε `opencode` στο ενσωματωμένο τερματικό του επεξεργαστή για να εγκαταστήσετε αυτόματα την επέκταση σύμφωνα με τη διαδικασία του επίσημου οδηγού. Μπορείτε επίσης να την εγκαταστήσετε χειροκίνητα από την αντίστοιχη αγορά.
2. Επαναφορτώστε τον επεξεργαστή.
3. Ξεκινήστε από την επέκταση OpenCode `Reply only OK`.
4. Εκτελέστε ξανά το αίτημα που απαιτεί ανάγνωση αρχείου ή τροποποίηση κώδικα, για να επιβεβαιώσετε ότι η επέκταση IDE χρησιμοποιεί τον ίδιο Provider και μοντέλο.

## Τρέχοντα όρια

- Οι δυνατότητες του Provider προέρχονται από το OpenCode runtime και δεν αντιπροσωπεύουν την εγγενή υποστήριξη του Ace Data Cloud από τον επεξεργαστή.
- Οι εκδόσεις των επεκτάσεων του VS Code και των διάφορων fork μπορεί να διαφέρουν, θα πρέπει να καταγράφονται ξεχωριστά οι εκδόσεις.
- Η επιτυχία σε κανονική συνομιλία δεν μπορεί να αντικαταστήσει την επαλήθευση ανάγνωσης αρχείων, επεξεργασίας και κλήσεων εργαλείων.
