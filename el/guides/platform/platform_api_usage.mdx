Επιστρέφει δημόσια δείγματα εγγραφών κλήσεων ενός API εντός των τελευταίων 15 λεπτών, για γρήγορη παρατήρηση της πρόσφατης κατάστασης. Δεν είναι διεπαφή καταμέτρησης συγκεντρωτικής ανά κωδικό κατάστασης και δεν μπορεί να χρησιμοποιηθεί για προσωπική χρέωση, SLA ή πλήρη στατιστικά χρήσης.

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                                        |
| --- | ------------------------------------------------------------ |
| Μέθοδος  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| Αυθεντικοποίηση  | Δημόσια, δεν απαιτείται διακριτικό λογαριασμού                                                    |
| Όριο  | Μετά τη συγχώνευση των πιο πρόσφατα δημιουργημένων/ολοκληρωμένων εγγραφών, επιστρέφονται έως 5.000 εγγραφές                                    |

Το `api_id` λαμβάνεται από τη [λίστα API](https://platform.acedata.cloud/documents/platform-api-list).

```shell
export API_ID='你的 API ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## Πραγματική δομή απόκρισης

Η απόκριση είναι απευθείας ένας πίνακας, χωρίς pagination envelope:

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| Πεδίο            | Περιγραφή        |
| ------------- | --------- |
| `api_id`      | ID API    |
| `created_at`  | Χρόνος δημιουργίας εγγραφής    |
| `trace_id`    | Αναγνωριστικό παρακολούθησης αιτήματος    |
| `status_code` | Κωδικός κατάστασης HTTP  |
| `elapsed`     | Διάρκεια κλήσης, σε δευτερόλεπτα |

Όταν το API δεν υπάρχει, ενδέχεται επίσης να επιστραφεί επί του παρόντος ένας κενός πίνακας, επειδή αυτή η action αναζητά απευθείας το πρόσφατο usage βάσει ID, χωρίς πρώτα να επαληθεύει το αντικείμενο API. Για τον υπολογισμό του ποσοστού επιτυχίας, ο πελάτης πρέπει να ομαδοποιεί μόνος του τα επιστρεφόμενα δείγματα· για την αναζήτηση προσωπικών χρεώσεων, χρησιμοποιήστε τη διεπαφή επιπέδου λογαριασμού.
