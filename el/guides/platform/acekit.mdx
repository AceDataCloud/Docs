Πιθανότατα έχετε συναντήσει κι εσείς αυτή την κατάσταση: χρησιμοποιείτε Claude Code, Cursor ή Codex, ο κώδικας γράφεται ομαλά, και ξαφνικά χρειάζεστε μια συνοδευτική εικόνα, ένα κομμάτι μουσικής υπόκρουσης, ένα σύντομο βίντεο ή θέλετε να αναζητήσει πρόχειρα τις πιο πρόσφατες πληροφορίες. Και τότε ανακαλύπτετε — ο ίδιος ο agent δεν ξέρει να κάνει αυτά τα πράγματα. Πρέπει να βρείτε μόνοι σας API, να διαβάσετε τεκμηρίωση, να ρυθμίσετε key, να γράψετε κώδικα κλήσης, να διαχειριστείτε ασύγχρονο polling· μέχρι να τελειώσετε όλη αυτή την ταλαιπωρία, η έμπνευση έχει ήδη χαθεί.

Το [AceKit](https://github.com/AceDataCloud/AceKit) υπάρχει ακριβώς για να σας γλιτώσει από όλη αυτή την ταλαιπωρία. Με μία γραμμή εντολής, εγκαθιστά στον coding agent σας ολόκληρο το σύνολο δυνατοτήτων του AceData Cloud για δημιουργία εικόνων, δημιουργία βίντεο, δημιουργία μουσικής, αναζήτηση στον ιστό, συνομιλία LLM και άλλα. Μετά την εγκατάσταση, απλώς μιλάτε φυσικά· ο agent θα φορτώσει μόνος του το κατάλληλο skill, θα κάνει μόνος του αυθεντικοποίηση, θα κάνει μόνος του polling και θα ολοκληρώσει τη δουλειά.

## Κατανοήστε σε 30 δευτερόλεπτα τι κάνει

Πριν την εγκατάσταση vs μετά την εγκατάσταση:

| Αυτό που λέτε | Πριν την εγκατάσταση | Μετά την εγκατάσταση (ο agent το κάνει μόνος του) |
| ------------------ | --------------------- | ----------------------------------- |
| "Βάλε μια εικόνα εξωφύλλου σε αυτό το README" | ο agent δεν ξέρει, σας λέει να βρείτε μόνοι σας API δημιουργίας εικόνων | καλεί NanoBanana / Flux / Midjourney για δημιουργία εικόνας |
| "Κάνε αυτό το script ένα σύντομο βίντεο 30 δευτερολέπτων" | δεν ξέρει | καλεί Sora / Veo / Kling / Seedance για δημιουργία βίντεο |
| "Βάλε ένα κομμάτι μουσικής υπόκρουσης σε αυτό το demo" | δεν ξέρει | καλεί Suno για δημιουργία τραγουδιού |
| "Αναζήτησε το πιο πρόσφατο X και μετά συνόψισέ το" | δεν μπορεί να συνδεθεί στο διαδίκτυο | καλεί Google SERP για αποτελέσματα σε πραγματικό χρόνο |
| "Σύντμησε αυτό το μεγάλο link" | δεν ξέρει | καλεί υπηρεσία σύντομων συνδέσμων και επιστρέφει link surl.id |

Με μία φράση: **ο coding agent σας από «ξέρει μόνο να γράφει κώδικα», γίνεται «ξέρει επίσης να δημιουργεί εικόνες, βίντεο, μουσική και να κάνει διαδικτυακές αναζητήσεις».**

## Ξεκινήστε σε τρία βήματα

Η όλη διαδικασία ολοκληρώνεται σε λίγα λεπτά και απαιτεί Node.js 18+.

**Βήμα πρώτο · Πάρτε ένα API Token.** Πηγαίνετε στην [κονσόλα](https://platform.acedata.cloud/console/applications) και αντιγράψτε το Token — όλες οι δυνατότητες μοιράζονται αυτό το ένα Token, η πρώτη αίτηση περιλαμβάνει δωρεάν πίστωση και μπορείτε να το δοκιμάσετε πρώτα δωρεάν.

![Αντιγράψτε το API Token στην κονσόλα](https://cdn.acedata.cloud/dvc3cg.jpg)

**Βήμα δεύτερο · Εγκαταστήστε.** Μία γραμμή εντολής:

```bash
npx acekit
```

Θα εντοπίσει αυτόματα τους coding agents στο μηχάνημά σας και θα εγκαταστήσει ολόκληρο το σύνολο skills. Η πραγματική εκτέλεση μοιάζει έτσι (σε αυτό το μηχάνημα είναι εγκατεστημένο μόνο το Claude Code):

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> Όταν δεν έχει οριστεί Token, η πρώτη εκτέλεση θα σας ζητήσει διαδραστικά να το επικολλήσετε· μπορείτε επίσης να κάνετε εκ των προτέρων `export ACEDATACLOUD_API_TOKEN=τοtokenσας`, ώστε η εγκατάσταση να είναι πλήρως χωρίς επίβλεψη. Ο αριθμός των skills θα αλλάζει καθώς αυξάνονται οι δυνατότητες της πλατφόρμας· ανατρέξτε στην τρέχουσα λίστα που εμφανίζει το `npx acekit list`.

**Βήμα τρίτο · Μιλήστε φυσικά.** Κάντε επαναφόρτωση του agent και έπειτα δώστε απευθείας οδηγίες, για παράδειγμα:

```text
Χρησιμοποίησε το skill short-url για να συντμήσεις το https://platform.acedata.cloud/services
```

Ο agent θα φορτώσει μόνος του το skill, θα ξεκινήσει μόνος του την κλήση και θα σας δώσει ένα πραγματικό αποτέλεσμα στο οποίο μπορείτε να μεταβείτε.

## Εκτελέστε το πραγματικά μία φορά (με έξοδο)

Τα παρακάτω τέσσερα παραδείγματα είναι όλα **πραγματικές κλήσεις, με αποτελέσματα που επιστράφηκαν επιτόπου**, όχι ενδεικτικά. Το `$KEY` στις εντολές είναι το API Token σας.

**① Σύντμηση URL (σύγχρονα, άμεση απάντηση)**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

Επιστρέφει `https://surl.id/r/1uKp2kilXQ` — ανοίγοντάς το θα κάνει ανακατεύθυνση 302 πίσω στην αρχική σελίδα services.

**② Διαδικτυακή αναζήτηση (σύγχρονα)**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

Λαμβάνετε αποτελέσματα Google σε πραγματικό χρόνο (απόσπασμα):

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ Συνομιλία LLM (σύγχρονα, ένα endpoint για 50+ μοντέλα)**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
Το MCP είναι ένα πρωτόκολλο για την ενοποιημένη διαχείριση και ανταλλαγή πληροφοριών πλαισίου μοντέλων.
（39 tokens, περίπου 0.00007 credit αυτή τη φορά）
```

**④ Δημιουργία εικόνας (ασύγχρονα, περίπου 20 δευτερόλεπτα, ο agent κάνει αυτόματα polling μέχρι να παραχθεί η εικόνα)**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

Μετά από περίπου 22 δευτερόλεπτα επιστρέφεται μια πραγματική εικόνα (HTTP 200 · image/png · 317 KB · περίπου 0.13 credit αυτή τη φορά):

![Εικόνα που δημιουργήθηκε πραγματικά από το AceKit](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

Στην πραγματικότητα δεν χρειάζεται να θυμάστε αυτά τα endpoints — αφού εγκαταστήσετε τα skills, ο agent θα συνθέσει μόνος του, βάσει του αντίστοιχου `SKILL.md`, τα σωστά αιτήματα και θα διαχειριστεί την αυθεντικοποίηση και το polling. Τα παραπάνω απλώς σας δείχνουν αναλυτικά «τι κάνει στο παρασκήνιο».

## Τι ακριβώς εγκαθιστά

Το AceKit είναι η «κύρια είσοδος» προς ολόκληρη την επιφάνεια εργαλείων προγραμματιστών του AceData και επί του παρόντος μία εγκατάσταση περιλαμβάνει το **σύνολο εργαλείων skills (Skills)**:

- **Ένα σύνολο Agent skills**: κάθε skill είναι ένα έτοιμο εγχειρίδιο λειτουργίας `SKILL.md` — η αυθεντικοποίηση, το ασύγχρονο polling, οι επαναλήψεις σε περίπτωση σφάλματος και ο τρόπος συμπλήρωσης των παραμέτρων είναι όλα καταγεγραμμένα με σαφήνεια, και ο agent απλώς ακολουθεί τις οδηγίες. Εκτελέστε `npx acekit list` για να δείτε την τρέχουσα λίστα (τη στιγμή που γράφεται αυτό είναι 19 και αυξάνονται συνεχώς):
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **Ενοποιημένο Token**：ένα `ACEDATACLOUD_API_TOKEN` ξεκλειδώνει όλες τις δυνατότητες, με χρέωση βάσει πραγματικής χρήσης.

Ομαδοποίηση ανά δυνατότητα (σύμφωνα με το `npx acekit list`)：

| Τύπος         | Πάροχοι                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ Δημιουργία εικόνων      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 Δημιουργία βίντεο      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 Δημιουργία μουσικής / ήχου | Suno · Producer · Fish Audio（TTS）                    |
| 💬 Συνομιλία LLM   | Ενοποιημένη διεπαφή για 50+ μοντέλα（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 Αναζήτηση       | Google SERP（ιστοσελίδες · εικόνες · ειδήσεις · χάρτες · βίντεο）                  |
| 🔗 Εργαλεία       | Σύντομοι σύνδεσμοι · επεξεργασία προσώπου                                            |

> Για αυτές τις ίδιες δυνατότητες, η AceData παρέχει επίσης ανεξάρτητους **MCP διακομιστές**（Suno、Midjourney、Sora、SERP… έχουν δημοσιευτεί σε PyPI / VS Code / Smithery / Docker）、**CLI γραμμής εντολών** και **Python / TypeScript SDK**, που μπορούν να χρησιμοποιηθούν ξεχωριστά ανάλογα με τις ανάγκες. Το AceKit v0.2 σχεδιάζει να υποστηρίζει εγκατάσταση μίας δυνατότητας με `acekit add <name>`, καθώς και αυτόματη εγγραφή της διαμόρφωσης MCP για κάθε agent.

## Ποια Agent υποστηρίζονται

| Agent                        | Τοποθεσία εγκατάστασης δεξιοτήτων                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode κ.ά. | `~/.agents/skills`（κατευθύνετε τον agent σας εδώ） |

Κατά την εγκατάσταση, το AceKit εντοπίζει αυτόματα τους agent που είναι ήδη εγκατεστημένοι στο μηχάνημα και εγκαθιστά μόνο σε εκείνους που εντοπίστηκαν.

## Easter egg：χρησιμοποιήστε το ίδιο Token για να τροφοδοτήσετε το ίδιο το Claude Code

Η διεπαφή της AceData είναι επίσης συμβατή με τη μορφή `/v1/messages` της Anthropic, επομένως **δεν χρειάζεστε επίσημη συνδρομή Anthropic**· μπορείτε να χρησιμοποιήσετε το ίδιο AceData Token για να τροφοδοτήσετε το Claude Code. Δημιουργήστε το `.claude/settings.local.json` στον ριζικό κατάλογο του έργου：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Απλώς επανεκκινήστε το Claude Code——θα χρησιμοποιεί τόσο ολόκληρη τη σειρά μοντέλων Claude, όσο και θα αποκτήσει μέσω του AceKit τα «χέρια» για δημιουργία εικόνων, βίντεο και μουσικής. Για περισσότερες λεπτομέρειες, δείτε τον [οδηγό ενσωμάτωσης Claude Code](https://platform.acedata.cloud/documents/claude-code-integration)。
