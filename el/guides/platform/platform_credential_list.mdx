Καταχώριση σελιδοποιημένων επιχειρηματικών διαπιστευτηρίων API. Η απόκριση περιέχει επί του παρόντος ευαίσθητα πεδία διαπιστευτηρίων Token ή Identity, τα οποία πρέπει να υποβάλλονται σε επεξεργασία μόνο στην πλευρά του διακομιστή και απαγορεύεται να εγγράφονται σε αρχεία καταγραφής, πλατφόρμες ανάλυσης, μόνιμη αποθήκευση frontend ή δημόσια αποθετήρια.

## Προετοιμασία

Δημιουργήστε ένα [Account Token](https://platform.acedata.cloud/documents/platform-token) και λάβετε το UUID του τρέχοντος λογαριασμού μέσω `GET /api/v1/platform-tokens/me/`.

```shell
export PLATFORM_TOKEN='το διακριτικό λογαριασμού σας'
export USER_ID='το UUID του λογαριασμού σας'
```

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                                   |
| --- | ---------------------------------------------------- |
| Μέθοδος  | `GET`                                                |
| URL | `https://platform.acedata.cloud/api/v1/credentials/` |
| Έλεγχος ταυτότητας  | Account Token, το OAuth token απαιτεί `credentials:read`       |
| Σελιδοποίηση  | `count` + `items`                                    |

Οι απλοί χρήστες θα πρέπει να περάσουν το δικό τους `user_id` ή ένα εξουσιοδοτημένο `application_id`, διαφορετικά μπορεί να επιστραφεί `403` όταν η σελιδοποίηση συναντήσει αντικείμενα χωρίς δικαίωμα πρόσβασης.

## Παράμετροι ερωτήματος

| Παράμετρος                 | Τύπος      | Υποχρεωτικό  | Περιγραφή                             |
| ------------------ | ------- | --- | ------------------------------ |
| `user_id`          | string  | Ανάλογα με το σενάριο | Κάτοχος διαπιστευτηρίου· υποστηρίζει επαναλαμβανόμενες παραμέτρους                   |
| `application_id`   | UUID    | Όχι   | Φιλτράρισμα κατά Application· υποστηρίζει επαναλαμβανόμενες παραμέτρους        |
| `host`             | string  | Όχι   | Ακριβές φιλτράρισμα κατά host· υποστηρίζει επαναλαμβανόμενες παραμέτρους             |
| `name`             | string  | Όχι   | Ακριβές φιλτράρισμα κατά όνομα· υποστηρίζει επαναλαμβανόμενες παραμέτρους                 |
| `granted`          | boolean | Όχι   | `true` για διαπιστευτήρια που έχουν εκχωρηθεί σε άλλους, `false` για διαπιστευτήρια ιδίας χρήσης |
| `limit` / `offset` | integer | Όχι   | Σελιδοποίηση                             |
| `ordering`         | string  | Όχι   | `created_at` ή `-created_at`   |

Τα `service_id`, `disabled`, `expired` δεν είναι επί του παρόντος παράμετροι φιλτραρίσματος.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/credentials/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## Περιγραφή απόκρισης

Η απόκριση που έχει επαληθευτεί online είναι `{count, items}`. Κάθε στοιχείο περιλαμβάνει `id`, `application_id`, `application`, `user_id`, `creator_id`, `name`, `type`, `limited_amount`, `used_amount`, `expired_at`, `allowed_api_ids`, `host`, `granted`, `granted_to_user_id`, `tags`, `metadata` και πεδία χρόνου, και επιστρέφει `token` ή `username/password` ανάλογα με τον τύπο.

> Η τρέχουσα απόκριση λίστας επιστρέφει πλήρεις ευαίσθητες τιμές. Μην τις εμφανίζετε στην κονσόλα του προγράμματος περιήγησης ή σε συστήματα συλλογής και μην βασίζεστε στην ανάκτηση απλού κειμένου μέσω της λίστας· ο πελάτης θα πρέπει να είναι συμβατός με μελλοντικές στρατηγικές απόκρυψης ευαίσθητων δεδομένων.
