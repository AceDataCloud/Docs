Επιστρέφει τον δημόσιο κατάλογο μοντέλων της πλατφόρμας, με απόκριση στη δομή τύπου OpenAI `{ "object": "list", "data": [...] }`. Αυτός ο κατάλογος χρησιμοποιείται για επιλογή μοντέλων και ανακάλυψη δυνατοτήτων και δεν σημαίνει ότι ο τρέχων λογαριασμός έχει απαραίτητα αιτηθεί τις αντίστοιχες υπηρεσίες.

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                              |
| --- | ----------------------------------------------- |
| Μέθοδος  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| Έλεγχος ταυτότητας  | Δημόσιο, δεν απαιτείται διακριτικό λογαριασμού                                       |
| Σελιδοποίηση  | Χωρίς σελιδοποίηση, όλα τα αντιστοιχισμένα στοιχεία βρίσκονται στο `data`                              |

## Παράμετροι ερωτήματος

| Παράμετρος             | Τύπος      | Υποχρεωτικό  | Περιγραφή                                      |
| -------------- | ------- | --- | --------------------------------------- |
| `owned_by`     | string  | Όχι   | Ακριβές φιλτράρισμα με βάση το αναγνωριστικό παρόχου μοντέλου στον κατάλογο                        |
| `type`         | string  | Όχι   | Ακριβές φιλτράρισμα με βάση τον τύπο μοντέλου, για παράδειγμα `chat`                     |
| `capability`   | string  | Όχι   | Επιστρέφει μόνο μοντέλα των οποίων το `capabilities` περιλαμβάνει αυτήν τη δυνατότητα, για παράδειγμα `vision` |
| `with_pricing` | boolean | Όχι   | Προσθέτει δημόσιες πληροφορίες τιμολόγησης όταν είναι `1`, `true` ή `yes`            |

Τα `service_id`, `tag`, `limit`, `offset` και `ordering` δεν υποστηρίζονται προς το παρόν· η παροχή τους δεν θα επιφέρει αντίστοιχο φιλτράρισμα ή αποτέλεσμα σελιδοποίησης.

## Παραδείγματα αιτημάτων

```shell
# 全部公开模型
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# 支持视觉的 chat 模型，并附价格
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## Δομή πραγματικής απόκρισης

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

Τα `pricing` και το ανώτατου επιπέδου `credit_usd_rate` εμφανίζονται μόνο όταν `with_pricing=true`· δεν διαθέτει κάθε μοντέλο υπολογίσιμο `pricing`. Το αντικείμενο μοντέλου βασίζεται στα δημόσια πεδία του `config/models.json` και ο πελάτης θα πρέπει να αγνοεί νέα πεδία.

> Τα πεδία τιμολόγησης είναι δεδομένα εμφάνισης καταλόγου. Οι πραγματικές επιχειρηματικές κλήσεις εξακολουθούν να υπόκεινται στους κανόνες χρέωσης του αντίστοιχου API/Service και στο τελικό αρχείο χρήσης.
