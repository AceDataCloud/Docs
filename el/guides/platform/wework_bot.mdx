Αναπτύξτε τη δική σας παρουσία λογαριασμού WeCom, συνδεθείτε σαρώνοντας με το κινητό WeCom και διαβάστε τον λογαριασμό, τις επαφές, τις συνομιλίες και τα τοπικά συγχρονισμένα μηνύματα μέσω REST API ή MCP. Η παρουσία αντιστοιχεί σε έναν συνηθισμένο λογαριασμό WeCom και δεν απαιτεί ιδιωτικοποιημένο διακομιστή ή ρύθμιση εταιρικού domain email.

Αυτή τη στιγμή βρίσκεται σε Alpha. Η ανάγνωση λογαριασμού έχει ολοκληρώσει πραγματική επαλήθευση συνομιλιών· η αποστολή κειμένου από τον ίδιο τον χρήστη και η ανάγνωση συμβάντων έχουν ολοκληρώσει πραγματική αποδοχή· οι ενέργειες για άλλες επαφές, ομάδες και η ανάκτηση νέων παρουσιών εξακολουθούν να χρειάζονται αποδοχή στο περιβάλλον ανάπτυξης. Η αποστολή πολυμέσων, η απάντηση με παράθεση, οι πραγματικές αναφορές @, η διαχείριση μελών ομάδας και οι αποδείξεις παράδοσης δεν είναι ακόμη διαθέσιμες. Ανατρέξτε στην τιμή επιστροφής του `/api/capabilities` της παρουσίας.

## Ανάπτυξη και σύνδεση

Ενεργοποιήστε την υπηρεσία στην κατηγορία Deployment και επιλέξτε πακέτο διάρκειας παρουσίας. Μετά την ανάπτυξη, ανοίξτε τη σελίδα διαχείρισης και σαρώστε με το WeCom του ίδιου του λογαριασμού· εάν απαιτείται επιβεβαίωση από κινητό ή άλλα βήματα σύνδεσης, ανοίξτε την απομακρυσμένη επιφάνεια εργασίας και εισαγάγετε τον κωδικό επιφάνειας εργασίας της παρουσίας. Τα διαπιστευτήρια API και ο κωδικός επιφάνειας εργασίας είναι ανεξάρτητα. Τα στοιχεία σύνδεσης αποθηκεύονται στον δίσκο της παρουσίας· η αναδημιουργία του κοντέινερ διατηρεί τον δίσκο· η διαγραφή του δίσκου διαγράφει την τοπική συνεδρία.

Κάθε παρουσία χρεώνεται ανεξάρτητα και λειτουργεί για τη διάρκεια που έχει αγοραστεί. Οι κλήσεις REST / MCP δεν χρεώνονται επιπλέον ανά μήνυμα· οι πραγματικές τιμές υπόκεινται στη σελίδα του πακέτου. Προς το παρόν, η προεπιλεγμένη αναφορά είναι τα πακέτα διάρκειας για bot WeChat· πριν από την τελική διάθεση, απαιτείται επιβεβαίωση τιμολόγησης σε συνδυασμό με τους πόρους λειτουργίας.

## API και MCP

Χρησιμοποιήστε τη διεύθυνση API της παρουσίας στη σελίδα διαχείρισης· όλες οι διεπαφές λογαριασμού φέρουν `Authorization: Bearer <token API παρουσίας>`. Αυτές οι διαδρομές ανήκουν σε αποκλειστική παρουσία και δεν είναι κοινόχρηστη πύλη API. Η διεύθυνση MCP είναι η διεύθυνση της παρουσίας με προσθήκη `/mcp/` και χρησιμοποιεί το ίδιο Bearer token.

| Διεπαφή                                                       | Λειτουργία                                          |
| -------------------------------------------------------- | ------------------------------------------- |
| `GET /api/status`、`GET /api/auth/status`                 | Αν ο λογαριασμός είναι έτοιμος και η λίστα δυνατοτήτων                                 |
| `GET /api/auth/qr`                                       | PNG Base64 του τρέχοντος κωδικού QR σύνδεσης                          |
| `GET /api/account`                                       | Τρέχων λογαριασμός                                        |
| `GET /api/contacts?kind=all`                             | Εσωτερικοί συνάδελφοι και εξωτερικές επαφές· μπορεί να καθοριστεί internal / external          |
| `GET /api/conversations`                                 | Τοπικές συνομιλίες, διατηρούν τα αρχικά ID συνομιλίας                              |
| `GET /api/messages`                                      | Τοπικά συγχρονισμένα μηνύματα· παράμετροι conversation_id, after_rowid, limit |
| `POST /api/search`                                       | Αναζήτηση επαφών, συνομιλιών και τοπικού κειμένου                               |
| `POST /api/messages`                                     | Ασύγχρονη εργασία αποστολής κειμένου, πρέπει να παρέχεται Idempotency-Key               |
| `POST /api/messages/send`                                | Ίδιο σημείο εισόδου αποστολής, υποστηρίζει έναν ή πολλούς στόχους                            |
| `GET /api/groups/{conversation_id}`                      | Τοπικά συγχρονισμένες πληροφορίες ομάδας και μέλη                                 |
| `GET /api/tasks`                                         | Πρόσφατες εργασίες και αποτελέσματα ανά στόχο                                 |
| `GET /api/tasks/{id}`                                    | Ερώτημα αποτελέσματος αποστολής                                      |
| `POST /api/tasks/{id}/cancel`                            | Ακύρωση εργασίας που δεν έχει ξεκινήσει ακόμη                                   |
| `POST /api/runtime/pause`、`POST /api/runtime/resume`     | Παύση αυτοματοποίησης· συνέχιση μετά την επαλήθευση από τον ίδιο τον χρήστη                               |
| `GET /api/diagnostics`、`GET /api/diagnostics/screenshot` | Κατάσταση παρουσίας και τρέχουσα οθόνη, και τα δύο απαιτούν έλεγχο ταυτότητας                              |
| `GET /api/events?after=0`                                | Συμβάντα μηνυμάτων με επαναλήψιμο δρομέα                                  |
| `WS /ws`                                                 | Ροή συμβάντων μηνυμάτων, έλεγχος ταυτότητας Bearer                             |

Το σώμα αποστολής περιλαμβάνει `target`, `type: "text"` και `text`. Το `target` δέχεται ID συνομιλίας, ID επαφής, ID εταιρικού χρήστη ή μοναδικό πλήρες όνομα· προτιμήστε ID· όταν το εμφανιζόμενο όνομα εξακολουθεί να μην μπορεί να εντοπιστεί μοναδικά, η παρουσία θα απορρίψει την ενέργεια και δεν θα μαντέψει το αντικείμενο. Για επαφές χωρίς τοπική συνομιλία, θα ανοιχθεί πρώτα η συνομιλία μέσω του πελάτη και θα γίνει αποστολή αφού επαληθευτεί το πραγματικό ID συνομιλίας. Η κεφαλίδα αιτήματος `Idempotency-Key` έχει 8–128 γράμματα, αριθμούς ή `_.:-`. Τα επαναλαμβανόμενα αιτήματα για την ίδια ενέργεια πρέπει να επαναχρησιμοποιούν το ίδιο κλειδί και το ίδιο σώμα αιτήματος.

Αντικαταστήστε το `target` με τον πίνακα `targets` για σειριακή αποστολή σε 1–50 ρητά καθορισμένους στόχους. Τα δύο δεν μπορούν να παρέχονται ταυτόχρονα. Όλοι οι στόχοι ολοκληρώνουν πρώτα την επίλυση ταυτότητας και διαφορετικά ψευδώνυμα που δείχνουν στο ίδιο αντικείμενο θα απορρίπτονται. Μετά την αποτυχία ενός στόχου, οι επόμενες αποστολές σταματούν και τα αποτελέσματα εργασίας καταγράφουν ανά στοιχείο `succeeded`, `failed`, `unknown` ή `not_attempted`· μην θεωρείτε τη μερική επιτυχία ως πλήρη επιτυχία. Αυτή η διαδικασία χρειάζεται επίσης να ολοκληρώσει πραγματική αποδοχή καθορισμένων επαφών στο περιβάλλον ανάπτυξης.

Οι εργασίες μπορεί να βρίσκονται σε queued, running, submitting, succeeded, failed, unknown ή cancelled. Το `succeeded` υποδηλώνει ότι, μετά την υποβολή, βρέθηκαν το ακριβές κείμενο και το ID μηνύματος διακομιστή στην αντίστοιχη καταγραφή συνομιλίας· το `delivered` εξακολουθεί να είναι null και δεν υποδηλώνει ότι το άλλο μέρος το έχει λάβει. Το unknown υποδηλώνει ότι το αποτέλεσμα είναι ασαφές· ελέγξτε το ιστορικό και μην επαναλάβετε την αποστολή με νέο κλειδί. Η παρουσία δεν επαναποστέλλει αυτόματα εργασίες που διακόπηκαν.

Το ιστορικό περιλαμβάνει μόνο περιεχόμενο που έχει ήδη συγχρονιστεί από τον πελάτη και δεν μπορεί να εγγυηθεί όλο το ιστορικό. Τα μη κειμενικά μηνύματα μπορεί να επιστρέφουν τύπο unknown· η λήψη συνημμένων δεν είναι ακόμη διαθέσιμη. Τα συμβάντα διατηρούν τις πιο πρόσφατες 10.000 εγγραφές· το `gap` υποδηλώνει ότι ο δρομέας έχει υπερβεί το παράθυρο διατήρησης. Η πρώτη σύνδεση δεν επαναμεταδίδει παλιό ιστορικό ως νέα μηνύματα.

Τα `server_accepted` και `server_id` στο ιστορικό μηνυμάτων μπορούν να χρησιμοποιηθούν για να επαληθευτεί αν ο διακομιστής έχει αποδεχθεί το τοπικό μήνυμα· όταν εμφανίζεται μόνο τοπική εγγραφή χωρίς ID διακομιστή, δεν μπορεί να θεωρηθεί ότι η αποστολή πέτυχε. Αυτά τα πεδία δεν υποδηλώνουν ότι ο παραλήπτης έχει λάβει ή διαβάσει το μήνυμα. Οι εγγραφές συμβάντων διατηρούν την κατάσταση κατά τη στιγμή της δημιουργίας· για να ερωτήσετε την τρέχουσα κατάσταση επιβεβαίωσης, χρησιμοποιήστε τη διεπαφή ιστορικού μηνυμάτων.

## Λογαριασμοί και διαπιστευτήρια

Συνδεθείτε μόνο σε λογαριασμούς για τους οποίους ο ίδιος ο χρήστης έχει δικαίωμα λειτουργίας. Ρυθμίστε το API token σε αξιόπιστες εφαρμογές· μπορεί να προσπελάσει τα δεδομένα λογαριασμού αυτής της παρουσίας. Μη δημοσιεύετε κωδικούς, κωδικούς QR ή στιγμιότυπα οθόνης συνομιλιών σε δημόσια σημεία. Η παύση της παρουσίας θα διακόψει τα συμβάντα πραγματικού χρόνου. Μετά την αποσύνδεση λογαριασμού ή την αφαίρεση της συσκευής από την πλευρά του κινητού, απαιτείται εκ νέου σύνδεση.

Η τρέχουσα εισαγωγή κειμένου υποστηρίζει μόνο μία γραμμή· οι αλλαγές γραμμής θα απορρίπτονται ρητά πριν από την αποστολή. Όταν ο πελάτης απαιτεί επαλήθευση ασφαλείας ή εκ νέου σύνδεση, αυτή πρέπει να ολοκληρώνεται από τον ίδιο τον χρήστη στην απομακρυσμένη επιφάνεια εργασίας· η παρουσία δεν θα παρακάμψει την επαλήθευση. Εργασίες μετά από διακοπή επαλήθευσης μπορεί να επιστρέφουν unknown· ερωτήστε πρώτα την καταγραφή μηνυμάτων και μην επαναστείλετε με νέο κλειδί ιδεμποτικότητας.

Όταν εντοπιστεί προτροπή επαλήθευσης ασφαλείας, έξοδος ή αλλαγή λογαριασμού, η ουρά αυτοματοποίησης θα τίθεται σε μόνιμη παύση. Αφού ολοκληρωθεί η επαλήθευση μέσω κινητού, μπορείτε να συνεχίσετε τις εργασίες που δεν έχουν εκτελεστεί ακόμη μέσω της επιλογής «Συνέχιση μετά την επαλήθευση» στην κονσόλα παρουσίας· εργασίες που έχουν ήδη υποβληθεί αλλά έχουν αβέβαιο αποτέλεσμα δεν θα επανασταλούν. Η συνήθης απομακρυσμένη εργασία μπορεί επίσης να ενεργοποιήσει επαλήθευση ασφαλείας WeCom. Το παράθυρο 24 ωρών χωρίς εκ νέου κλείδωμα μετά την επαλήθευση που αναφέρεται στις επίσημες οδηγίες δεν σημαίνει ότι η ανίχνευση έχει ήδη εξαλειφθεί, ούτε σημαίνει ότι η παρουσία μπορεί να εγγυηθεί μακροχρόνια λειτουργία χωρίς επίβλεψη.
