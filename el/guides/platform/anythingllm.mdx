Το [AnythingLLM](https://anythingllm.com/) είναι ένας πελάτης ανοιχτού κώδικα με τοποθέτηση «έγγραφα → ιδιωτικό ChatGPT», με βασική έννοια το **Workspace**—κάθε Workspace είναι ένα σύνολο εγγράφων, ένα σύνολο χρηστών και ένα σύνολο εργαλείων Agent, ανεξάρτητα απομονωμένα. Είναι σχεδιασμένο ειδικά για συνομιλία με έγγραφα και παρέχει δύο μορφές: εφαρμογή επιφάνειας εργασίας και Docker. Στο **LLM Provider**, περιλαμβάνει την επιλογή [OpenAI (Generic)](https://docs.anythingllm.com/setup/llm-configuration/cloud/openai-generic), όπου μπορεί να συμπληρωθεί προσαρμοσμένο Base URL, επομένως μπορεί να κατευθύνει απευθείας το μοντέλο συνομιλίας στο Ace Data Cloud. Αυτό το άρθρο παρουσιάζει τη διαδικασία ρύθμισης.

## Διαδικασία αίτησης

Για να ενσωματώσετε το Ace Data Cloud στο AnythingLLM, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications), αποκτήστε το API Token σας και κρατήστε το για χρήση αργότερα.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε· μετά τη σύνδεση ή την εγγραφή, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση θα σας δοθεί δωρεάν πίστωση, ώστε να μπορείτε να δοκιμάσετε δωρεάν τις υπηρεσίες μοντέλων του Ace Data Cloud.

## Λήψη του AnythingLLM

Για προσωπική χρήση, μπορείτε να κατεβάσετε την [έκδοση επιφάνειας εργασίας](https://anythingllm.com/download), όπου η διανυσματική βάση δεδομένων (LanceDB) εκτελείται τοπικά, η αναζήτηση εγγράφων είναι εντελώς εκτός σύνδεσης και σύνδεση στο διαδίκτυο απαιτείται μόνο κατά την κλήση μοντέλου· για ομαδικά σενάρια πολλών χρηστών χρησιμοποιήστε [ανάπτυξη με Docker](https://docs.anythingllm.com/installation-docker/overview).

## Ρύθμιση μοντέλου συνομιλίας

Εκκινήστε το AnythingLLM, μεταβείτε στο **Settings → LLM Preference** και επιλέξτε **OpenAI (Generic)** ως Provider (μην επιλέξετε το κανονικό OpenAI, καθώς αυτό δείχνει σταθερά στο `api.openai.com` και δεν διαθέτει προσαρμοσμένο Base URL). Για την επίσημη τεκμηρίωση, ανατρέξτε στο [OpenAI (Generic) LLM Provider](https://docs.anythingllm.com/setup/llm-configuration/cloud/openai-generic).

| Πεδίο                   | Τιμή                              | Περιγραφή                                       |
| -------------------- | ------------------------------ | ---------------------------------------- |
| Base URL             | `https://api.acedata.cloud/v1` | **Πρέπει να τελειώνει με `/v1`**                         |
| API Key              | Το Ace Data Cloud Token σας        | Το Token που αντιγράφηκε από την κονσόλα                             |
| Selected Model       | ID τρέχοντος μοντέλου                        | Προτιμήστε τη λίστα που φορτώνεται αυτόματα από το `/models`· αν δεν επιστρέφεται, αναζητήστε το με τη μέθοδο παραπάνω και συμπληρώστε το χειροκίνητα |
| Model context window | Συμπληρώστε σύμφωνα με το επιλεγμένο μοντέλο                        | Διαβάστε το ανώτατο όριο περιβάλλοντος από τον τρέχοντα κατάλογο μοντέλων, μην αντιγράφετε τις τιμές άλλων μοντέλων               |

![Διεπαφή ρύθμισης AnythingLLM Generic OpenAI](https://cdn.acedata.cloud/a155f5476de7.png)

> Οι δυνατότητες μοντέλου και το ανώτατο όριο περιβάλλοντος βασίζονται στον τρέχοντα κατάλογο μοντέλων.

Προσέξτε τους κανόνες διαδρομής του Base URL:

| Base URL                              | Πραγματικό αίτημα                                                   | Αποτέλεσμα                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | Σωστό                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | Επίσης μπορεί να χρησιμοποιηθεί                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (δεν υπάρχει `/v1` κάτω από το `/openai`) |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404 (λείπει το `/v1`)             |

## Ρύθμιση μοντέλου Embedding

Ο πυρήνας του AnythingLLM είναι το RAG και απαιτεί ένα μοντέλο ενσωμάτωσης για τη μετατροπή εγγράφων σε διανύσματα. Το **Embedding Preference** και το LLM Preference είναι δύο ανεξάρτητα σύνολα ρυθμίσεων—ανατρέξτε στην [επισκόπηση ρυθμίσεων Embedder](https://docs.anythingllm.com/setup/embedder-configuration/overview). Το ενσωματωμένο **AnythingLLM Embedder（Built-in / Native）** εκτελείται απευθείας τοπικά, λειτουργεί έτοιμο προς χρήση και χωρίς ρυθμίσεις, και είναι η προεπιλεγμένη και προτεινόμενη επιλογή:

Μεταβείτε στο **Settings → Embedding Preference**, διατηρήστε τον Provider στην προεπιλεγμένη τιμή **AnythingLLM Embedder**, χωρίς να χρειάζεται να συμπληρώσετε κανένα κλειδί. Θα ολοκληρώνει την διανυσματοποίηση εγγράφων τοπικά, ενώ τόσο το αρχικό κείμενο όσο και τα διανύσματα αποθηκεύονται στην τοπική LanceDB και δεν ανεβαίνουν στο cloud.

> Οι επιλογές Embedder του AnythingLLM (cloud: OpenAI / Azure OpenAI / Cohere· τοπικά: Built-in, LM Studio, [LocalAI](https://docs.anythingllm.com/setup/embedder-configuration/local/localai), Ollama) ενσωματώνονται όλες σύμφωνα με τη δική τους σταθερή μορφή. Μεταξύ αυτών, το cloud OpenAI embedding δείχνει σταθερά στο `api.openai.com` και δεν υποστηρίζει προσαρμοσμένο Base URL· αν θέλετε να χρησιμοποιήσετε προσαρμοσμένο endpoint, μπορείτε να χρησιμοποιήσετε το **Generic OpenAI** Embedder (που διαθέτει επίσης πεδίο Base URL και μπορεί να δείχνει στο `text-embedding-3-large` του Ace Data Cloud) ή το τοπικό **LocalAI** Embedder. Σε αυτό το άρθρο, το μοντέλο συνομιλίας χρησιμοποιεί το Ace Data Cloud, ενώ η ενσωμάτωση χρησιμοποιεί τον τοπικό Embedder που παρέχεται με το AnythingLLM· τα δύο δεν επηρεάζουν το ένα το άλλο.

## Επιλογή μοντέλου

Ο κατάλογος μοντέλων θα ενημερώνεται συνεχώς. Προτιμήστε τη λίστα μοντέλων που φορτώνεται αυτόματα από τον πελάτη· όταν απαιτείται χειροκίνητη συμπλήρωση, ζητήστε πρώτα `GET https://api.acedata.cloud/v1/models` για να αποκτήσετε το τρέχον ID μοντέλου και, στη συνέχεια, επιλέξτε σύμφωνα με τις δυνατότητες περιβάλλοντος, εικόνων και κλήσης εργαλείων που υποστηρίζει ο πελάτης.

## Επαλήθευση ενσωμάτωσης

Αν δεν είστε βέβαιοι αν το πρόβλημα βρίσκεται στο AnythingLLM ή στο δίκτυο, μπορείτε πρώτα να επαληθεύσετε απευθείας το endpoint με curl (αντικαταστήστε το `{token}` με το Token σας):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Η επιστροφή ενός αντικειμένου `chat.completion` συμβατού με OpenAI σημαίνει ότι τόσο το Token όσο και το endpoint είναι έτοιμα· αν επιστραφεί `HTTP 403 used_up`, σημαίνει ότι το Token είναι έγκυρο αλλά το υπόλοιπο δεν επαρκεί—απλώς επαναφορτίστε στην [κονσόλα](https://platform.acedata.cloud/console/applications).

## Προχωρημένα: Workspace και συνομιλία με έγγραφα

Μετά τη δημιουργία ενός νέου Workspace, ανεβάστε έγγραφα όπως PDF / Word / Markdown· το AnythingLLM θα τα χωρίσει σε παραγράφους, θα δημιουργήσει διανύσματα με τον τοπικό Embedder και θα τα αποθηκεύσει στην τοπική LanceDB. Κατά τη συνομιλία, θα ανακτά πρώτα τα σχετικά αποσπάσματα και στη συνέχεια θα υποβάλει τα αποσπάσματα μαζί με την ερώτησή σας στο μοντέλο συνομιλίας (δηλαδή το Ace Data Cloud) για απάντηση, ενώ θα επισημαίνει τις πηγές παραπομπών κάτω από την απάντηση. Στο επάνω μέρος κάθε Workspace μπορείτε να εναλλάσσετε μεταξύ των λειτουργιών **Query** (απαντά μόνο βάσει εγγράφων) και **Chat** (συνδυάζει γενική γνώση)· για σοβαρά σενάρια συνιστάται η λειτουργία Query ώστε να αποφεύγονται παραισθήσεις. Κατά την ανάπτυξη με Docker, μπορείτε να χρησιμοποιήσετε μεταβλητές περιβάλλοντος όπως `GENERIC_OPEN_AI_BASE_PATH`, `GENERIC_OPEN_AI_API_KEY`, `GENERIC_OPEN_AI_MODEL_PREF` για να προκαθορίσετε την ίδια ενσωμάτωση μοντέλου συνομιλίας και να ενεργοποιήσετε τη λειτουργία πολλών χρηστών.

## Συχνές ερωτήσεις

### Εμφανίζεται 404 / connection fail

Συνήθως το Base URL έχει γραφτεί ως `.../openai/v1` ή λείπει το `/v1`. Αλλάξτε το σε `https://api.acedata.cloud/v1`.

### Δεν είναι δυνατή η συνομιλία μετά τη μεταφόρτωση εγγράφου

Επιβεβαιώστε ότι στο **Settings → Embedding Preference** έχει επιλεγεί ένας διαθέσιμος Embedder (ο προεπιλεγμένος AnythingLLM Embedder μπορεί να εκτελείται τοπικά χωρίς πρόσθετη ρύθμιση) και μεταφορτώστε ξανά το έγγραφο για τη δημιουργία διανυσμάτων.

### Εμφανίζεται 401 Unauthorized
Βεβαιωθείτε ότι στο API Key έχει επικολληθεί το Token του Ace Data Cloud (χωρίς το πρόθεμα `Bearer`, χωρίς επιπλέον κενά), και ότι το υπόλοιπο της αντίστοιχης εφαρμογής είναι επαρκές.

### Θα μεταφορτωθούν τα τοπικά έγγραφα στο cloud;

Όχι. Το πρωτότυπο κείμενο των εγγράφων αποθηκεύεται τοπικά στο LanceDB, και μόνο τα αποσπάσματα που εντοπίζονται από την αναζήτηση μαζί με την ερώτησή σας αποστέλλονται στο μοντέλο.
