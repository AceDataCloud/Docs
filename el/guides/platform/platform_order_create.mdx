Δημιουργήστε μια εντολή προς πληρωμή για μία ή περισσότερες Applications. Η δημιουργία θα καταγράψει την εντολή, αλλά δεν θα ολοκληρώσει αυτόματα την πληρωμή· πριν από την πληρωμή, θα πρέπει να επαληθεύσετε τα `price`, πακέτο και Application στην απόκριση.

## Προετοιμασία

- Δημιουργήστε ένα [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Λάβετε το `application_id` από τη [λίστα Application](https://platform.acedata.cloud/documents/platform-application-list).
- Επιλέξτε από τα `packages` στις [λεπτομέρειες υπηρεσίας](https://platform.acedata.cloud/documents/platform-service-detail) ένα `package_id` που αντιστοιχεί στον τύπο Application και μπορεί να αγοραστεί.

```shell
export PLATFORM_TOKEN='Το Account Token σας'
export APPLICATION_ID='Το Application ID σας'
export PACKAGE_ID='Το Package ID σας'
```

## Επισκόπηση διεπαφής

| Στοιχείο    | Περιεχόμενο                                      |
| ---- | ----------------------------------------------- |
| Μέθοδος   | `POST`                                          |
| URL  | `https://platform.acedata.cloud/api/v1/orders/` |
| Πιστοποίηση   | Account Token, το OAuth token απαιτεί `orders:write`      |
| Body | JSON                                            |

## Σώμα αιτήματος

Οι εντολές για μία Application χρησιμοποιούν `application_id` + `package_id`· οι μαζικές εντολές χρησιμοποιούν `application_ids` + `package_ids` με αντίστοιχο μήκος. Οι κανονικές εντολές επιλέγουν μέθοδο πληρωμής στο επόμενο αίτημα `/pay/`. Οι εντολές αγοράς εντός εφαρμογής iOS περνούν `pay_way: "AppleIAP"` κατά τη δημιουργία και μπορούν να επιλέξουν μόνο ένα πακέτο Usage με `metadata.apple_product_id` και `metadata.apple_price`. Οι αγορές εντός εφαρμογής Apple χρησιμοποιούν ανεξάρτητες προκαθορισμένες τιμές σε δολάρια ΗΠΑ, χωρίς να προστίθενται εκπτώσεις μέλους, εκπτώσεις μεθόδου πληρωμής ή προσαυξήσεις ιστότοπου· το ποσό χρέωσης σε τοπικό νόμισμα για άλλες περιοχές υπόκειται στη σελίδα επιβεβαίωσης πληρωμής της Apple.

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/orders/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d "{\"application_id\":\"${APPLICATION_ID}\",\"package_id\":\"${PACKAGE_ID}\"}"
```

## Περιγραφή απόκρισης

Σε περίπτωση επιτυχίας επιστρέφεται `201` και το νεοδημιουργημένο αντικείμενο Order. Τα βασικά πεδία περιλαμβάνουν τα `id`, `price`, `discount`, `state`, `application_id/application_ids`, `package_id/package_ids`, `expired_at` και πεδία χρόνου. Οι νέες εντολές είναι συνήθως `Pending`, και στη συνέχεια καλείται η [πληρωμή εντολής](https://platform.acedata.cloud/documents/platform-order-pay).

- Το `price` είναι το πληρωτέο ποσό που υπολογίζεται από τον διακομιστή βάσει του πακέτου, της προσαύξησης ιστότοπου και των εκπτώσεων· μην το υπολογίζετε από τον client.
- Επιστρέφεται `400` όταν το Package δεν αντιστοιχεί στην υπηρεσία ή τον τύπο της Application.
- Τα δωρεάν και διαχειριζόμενα από το σύστημα Package δεν μπορούν να ληφθούν αυτόνομα μέσω της δημόσιας διεπαφής εντολών.
- Η δημιουργία εντολής για Application που δεν ανήκει στον τρέχοντα λογαριασμό θα απορριφθεί.
