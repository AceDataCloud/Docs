---
title: "Οδηγός Ενσωμάτωσης Hermes Agent"
description: "Platform API guide - Ace Data Cloud"
---

Ο Hermes Agent ενσωματώνεται στο Ace Data Cloud μέσω του πρωτοκόλλου OpenAI Chat Completions. Επιλέξτε μία από τις παρακάτω μεθόδους ρύθμισης:

| Μέθοδος Ρύθμισης                | Οδηγία                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| Οδηγός αλληλεπίδρασης `hermes model` | [Ρύθμιση μέσω οδηγού](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| Χειροκίνητη ρύθμιση `config.yaml`  | [Χειροκίνητη ρύθμιση](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| Ιδιωτική ανάπτυξη πλατφόρμας              | [Ανάπτυξη μέσω φιλοξενίας](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

Κοινές παράμετροι για τοπική ενσωμάτωση:

- Base URL: `https://api.acedata.cloud/v1`
- Transport: `chat_completions`
- Provider: `custom:acedatacloud`
- API Key: Λάβετε από τη [λίστα εφαρμογών](https://platform.acedata.cloud/console/applications)

Και οι δύο τοπικές μέθοδοι τελικά γράφονται στο `~/.hermes/config.yaml`, μην επαναλαμβάνετε τη ρύθμιση.

Επιστρέψτε στο [Κέντρο Ρύθμισης Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
