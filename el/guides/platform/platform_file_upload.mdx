Μεταφορτώστε τοπικά αρχεία στο CDN της πλατφόρμας AceDataCloud και αποκτήστε ένα δημόσια προσβάσιμο URL (μορφής `https://cdn.acedata.cloud/xxxxxx.png`), το οποίο μπορεί να χρησιμοποιηθεί άμεσα σε παραμέτρους όπως `image_url`, `reference_url` άλλων επιχειρηματικών API (όπως Midjourney, Suno, Flux).

Εφαρμόσιμα σενάρια:

- Πριν καλέσετε το Midjourney `/midjourney/imagine`, μεταφορτώστε πρώτα την εικόνα αναφοράς στο CDN για να λάβετε το URL.
- Αποθηκεύστε προσωρινά το βίντεο που δημιουργήθηκε στο προηγούμενο βήμα για χρήση ως είσοδο στο επόμενο βήμα.
- Φιλοξενήστε προσωρινά υλικό που μεταφορτώνουν οι χρήστες, αποφεύγοντας την ανάγκη δημιουργίας δικού σας S3.

> ℹ️ Αυτό το API ανήκει στο **API διαχείρισης της πλατφόρμας AceDataCloud**, με ενιαίο πρόθεμα `https://platform.acedata.cloud/api/v1/`.

## Επισκόπηση API

| Στοιχείο            | Περιεχόμενο                                    |
| ------------------ | ---------------------------------------------- |
| Μέθοδος            | `POST`                                         |
| URL                | `https://platform.acedata.cloud/api/v1/files/` |
| Αυθεντικοποίηση    | ✅ Απαιτείται διακριτικό λογαριασμού            |
| Content-Type       | `multipart/form-data`（**όχι JSON**）          |

## Οδηγίες αυθεντικοποίησης (πώς να αποκτήσετε διακριτικό λογαριασμού)

Κεφαλίδα αιτήματος:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

Τρόπος απόκτησης: συνδεθείτε στην [πλατφόρμα AceDataCloud](https://platform.acedata.cloud) → [κονσόλα Account Token](https://platform.acedata.cloud/console/platform-tokens) → κάντε κλικ στο κουμπί «Δημιουργία». Δείτε λεπτομέρειες στη [διαχείριση διακριτικών λογαριασμού πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-token).

## Σώμα αιτήματος (multipart/form-data)

| Πεδίο   | Τύπος  | Υποχρεωτικό | Περιγραφή                                      |
| ------ | ---- | ----------- | --------------------------------------------- |
| `file` | file | ✅          | Δυαδική ροή αρχείου. **Το προεπιλεγμένο όριο ανά αρχείο είναι 100 MB** |

## Παραδείγματα αιτημάτων

### cURL

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/files/' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}" \
  -F 'file=@./photo.jpg'
```

### Python

```python
import os
import requests

PLATFORM_TOKEN = os.environ["PLATFORM_TOKEN"]

with open("photo.jpg", "rb") as f:
    resp = requests.post(
        "https://platform.acedata.cloud/api/v1/files/",
        headers={
            "accept": "application/json",
            "authorization": f"Bearer {PLATFORM_TOKEN}",
        },
        files={"file": ("photo.jpg", f, "image/jpeg")},
        timeout=60,
    )

data = resp.json()
print(f"✅ 上传成功：{data['file_url']}")
# 直接用于其他业务接口：
# requests.post("https://api.acedata.cloud/midjourney/imagine",
#     json={"prompt": "...", "image_urls": [data["file_url"]]}, ...)
```

### Node.js

```javascript
const fs = require('fs')
const FormData = require('form-data')

const form = new FormData()
form.append('file', fs.createReadStream('./photo.jpg'))

const r = await fetch('https://platform.acedata.cloud/api/v1/files/', {
  method: 'POST',
  headers: {
    authorization: `Bearer ${process.env.PLATFORM_TOKEN}`,
    ...form.getHeaders(),
  },
  body: form,
})
const data = await r.json()
console.log('CDN URL:', data.file_url)
```

## Παράδειγμα απόκρισης (HTTP 200)

```json
{
  "file_url": "https://cdn.acedata.cloud/qrd7gw.jpg"
}
```

Απλώς χρησιμοποιήστε το πεδίο `file_url` απευθείας σε άλλα επιχειρηματικά API—το CDN URL είναι προς το παρόν δημόσια προσβάσιμο και δεν απαιτεί αυθεντικοποίηση· μην το θεωρείτε εγγύηση μόνιμης αρχειοθέτησης.

## Περιγραφή πεδίων απόκρισης

| Πεδίο      | Τύπος  | Περιγραφή      |
| ---------- | ------ | -------------- |
| `file_url` | string | URL πρόσβασης CDN |

## Διαχείριση σφαλμάτων

| HTTP | Παράδειγμα απόκρισης                           | Σημασία                                      |
| ---- | ---------------------------------------------- | -------------------------------------------- |
| 400  | `{"error":"No file provided"}`                 | Δεν επισυνάφθηκε το πεδίο `file` ή το όνομα πεδίου είναι λανθασμένο |
| 401  | Απόκριση σφάλματος αυθεντικοποίησης DRF        | Λείπει ή χρησιμοποιήθηκε μη έγκυρο διακριτικό λογαριασμού |
| 413  | `{"error":"File too large","max_bytes":...}`   | Το αρχείο υπερβαίνει τα 100 MB (προεπιλογή) |

## Χρήσιμες συμβουλές

- **Μεταφόρτωση εικόνων ως εικόνες αναφοράς**: Τα `image_urls` του Midjourney, το `image_url` του Flux και το `reference_url` του Veo δέχονται όλα CDN URL, **όχι** base64. Η λήψη URL μέσω αυτού του API πρώτα είναι συνήθης πρακτική.
- **Μην μεταφορτώνετε ευαίσθητα δεδομένα**: Το επιστρεφόμενο URL είναι δημόσια προσβάσιμο· η περίοδος διατήρησης εξαρτάται από την τρέχουσα πολιτική αποθήκευσης της πλατφόρμας· για μακροχρόνια αρχειοθέτηση, χρησιμοποιήστε τη δική σας αποθήκευση αντικειμένων.
- **Μεταφορτώσεις μεγάλου όγκου**: Ελέγξτε την ταυτόχρονη εκτέλεση και ορίστε χρονικό όριο για κάθε μεταφόρτωση· η απόδοση εξαρτάται από το μέγεθος αρχείου και το περιβάλλον δικτύου.
