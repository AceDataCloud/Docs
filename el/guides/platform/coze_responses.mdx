Coze επίσημη τεκμηρίωση προσαρμοσμένων μοντέλων υποστηρίζει το OpenAI Responses API και παρέχει τη διεύθυνση Base API URL, το API Key και τα πεδία μοντέλου. Διαφορετικές εκδόσεις ενοικιαστών Coze μπορεί να διαχειρίζονται διαφορετικά τη σύνθεση διαδρομών, την ροή εξόδου και τις κλήσεις εργαλείων, οπότε κατά την πρώτη σύνδεση παρακαλώ ελέγξτε τα παρακάτω βήματα.

## Ρύθμιση

1. Εισέλθετε στη διαχείριση μοντέλων Coze και προσθέστε ένα νέο προσαρμοσμένο μοντέλο.
2. Επιλέξτε το πρωτόκολλο OpenAI Responses API.
3. Συμπληρώστε τη Base API URL με `https://api.acedata.cloud/v1`.
4. Συμπληρώστε το API Key με το Ace Data Cloud API Token σας.
5. Συμπληρώστε το Model με το ακριβές ID μοντέλου που υποστηρίζει το Responses API στον κατάλογο μοντέλων.
6. Αποθηκεύστε και ολοκληρώστε τη δοκιμή σύνδεσης του Coze.
7. Στείλτε `Reply only OK` στο Bot/Agent και δοκιμάστε ξανά την κλήση εργαλείου.

## Τρέχοντα όρια

- Διαφορετικές περιοχές, εκδόσεις ή πακέτα Coze μπορεί να εμφανίζουν διαφορετικές φόρμες.
- Η Base API URL θα πρέπει να χρησιμοποιεί τη βάση, μην προσθέτετε ξανά `/responses`; αν η τρέχουσα διεπαφή απαιτεί σαφώς πλήρη API URL, ακολουθήστε τις υποδείξεις της φόρμας.
- Οι Chat Completions, Responses και Anthropic Messages είναι τρεις ανεξάρτητες διαδρομές και δεν μπορούν να αντικαταστήσουν η μία την άλλη για επαλήθευση.
