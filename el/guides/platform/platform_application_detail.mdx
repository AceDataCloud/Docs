Λάβετε την πλήρη κατάσταση μιας μεμονωμένης αίτησης υπηρεσίας μέσω του Application ID — σε σύγκριση με το API λίστας, περιλαμβάνει επιπλέον πεδία όπως το πλήρες αντικείμενο `service` (συμπεριλαμβανομένων των πακέτων `packages`), κατάλληλο για σελίδες λεπτομερειών.

> ℹ️ Αυτό το API ανήκει στο **API διαχείρισης πλατφόρμας AceDataCloud**, με ενιαίο πρόθεμα `https://platform.acedata.cloud/api/v1/`. Για το πλήρες ευρετήριο API, δείτε [Λήψη λίστας εγγράφων πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list).

## Επισκόπηση API

| Στοιχείο   | Περιεχόμενο                                                                    |
| --- | --------------------------------------------------------------------- |
| Μέθοδος  | `GET`                                                                 |
| URL | `https://platform.acedata.cloud/api/v1/applications/{application_id}` |
| Έλεγχος ταυτότητας  | ✅ Απαιτείται διακριτικό λογαριασμού                                                              |

Τα `/applications/{id}` και `/applications/{id}/` είναι και τα δύο διαθέσιμα επί του παρόντος· τα παραδείγματα χρησιμοποιούν ενιαία τη μορφή χωρίς τελική κάθετο.

## Περιγραφή ελέγχου ταυτότητας (πώς να αποκτήσετε διακριτικό λογαριασμού)

Κεφαλίδα αιτήματος:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

Για λεπτομερή τρόπο απόκτησης, δείτε [Διαχείριση διακριτικού λογαριασμού πλατφόρμας AceDataCloud](https://platform.acedata.cloud/documents/platform-token).

> ℹ️ Σε αντίθεση με το API λίστας, **ο έλεγχος δικαιωμάτων του API λεπτομερειών πραγματοποιείται απευθείας σε μεμονωμένο αντικείμενο**, χωρίς να χρειάζεται να περάσετε `?user_id=`. Ωστόσο, αν προσπαθήσετε να προσπελάσετε την αίτηση άλλου χρήστη, θα λάβετε `403 permission_denied`.

## Παράμετροι διαδρομής

| Παράμετρος               | Τύπος   | Υποχρεωτικό  | Περιγραφή             |
| ---------------- | ---- | --- | -------------- |
| `application_id` | UUID | ✅   | Application ID |

## Παραδείγματα αιτημάτων

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/applications/82f57141-2323-4453-8730-60f7d833a2da' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

app_id = "82f57141-2323-4453-8730-60f7d833a2da"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/applications/{app_id}",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
app = resp.json()
print(f"服务：{app['service']['title']}")
print(f"剩余 {app['remaining_amount']} {app['service']['unit']} / 已用 {app['used_amount']}")
```

### Node.js

```javascript
const appId = '82f57141-2323-4453-8730-60f7d833a2da'
const r = await fetch(`https://platform.acedata.cloud/api/v1/applications/${appId}`, {
  headers: { authorization: `Bearer ${process.env.PLATFORM_TOKEN}` },
})
console.log(await r.json())
```

## Περιγραφή πεδίων απόκρισης

Η σημασία των πεδίων είναι ίδια με εκείνη του [API λίστας](https://platform.acedata.cloud/documents/platform-application-list), με την επιπλέον συμπερίληψη:

| Πεδίο        | Τύπος     | Περιγραφή                                                        |
| --------- | ------ | --------------------------------------------------------- |
| `service` | object | Πλήρες αντικείμενο υπηρεσίας (συμπεριλαμβανομένων των πακέτων `packages`, του `unit`, του `free_amount`), το οποίο μπορεί να αποδοθεί απευθείας στον πίνακα λεπτομερειών υπηρεσίας |

## Χειρισμός σφαλμάτων

| HTTP | code                | Σημασία                  |
| ---- | ------------------- | ------------------- |
| 401  | `not_authenticated` | Λείπει το διακριτικό λογαριασμού              |
| 403  | `permission_denied` | Αυτό το Application δεν ανήκει σε εσάς  |
| 404  | `not_found`         | Το Application δεν υπάρχει ή έχει διαγραφεί |

## Χρήσιμες συμβουλές

- **Για μαζική παρακολούθηση, προτιμήστε τη λίστα**: αφού ανακτήσετε τη λίστα Application μία φορά, αξιολογήστε βάσει της μονάδας και του ορίου κάθε υπηρεσίας, ώστε να αποφύγετε αιτήματα λεπτομερειών ένα προς ένα.
- **Όταν χρειάζεται να δείτε τον αριθμό διαπιστευτηρίων**: χρησιμοποιήστε τη [λίστα διαπιστευτηρίων API](https://platform.acedata.cloud/documents/platform-credential-list) με φιλτράρισμα κατά `application_id`.
- **Προσέγγιση διερεύνησης για `disabled=true`**: ελέγξτε δελτία υποστήριξης / ειδοποιήσεις email για να δείτε αν η υπηρεσία απενεργοποιήθηκε λόγω ελέγχου κινδύνου, οφειλών ή παραβατικών κλήσεων· δεν μπορεί να ενεργοποιηθεί ξανά μέσω API, πρέπει να επικοινωνήσετε με την εξυπηρέτηση πελατών.
