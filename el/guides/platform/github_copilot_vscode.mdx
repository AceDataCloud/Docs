Η επίσημη τεκμηρίωση BYOK του GitHub Copilot αναφέρει ότι το VS Code είναι υποστηριζόμενος τοπικός πελάτης και υποστηρίζει OpenAI-compatible Provider. Η έκδοση του VS Code, η πολιτική της επιχείρησης και η ορατότητα του μοντέλου θα επηρεάσουν το τελικό endpoint; Για πρώτη φορά σύνδεσης, παρακαλώ ελέγξτε τα πραγματικά αιτήματα παρακάτω.

## Ρυθμίσεις

1. Επιβεβαιώστε ότι ο λογαριασμός ή ο οργανισμός σας στο GitHub Copilot έχει ενεργοποιήσει τη δυνατότητα BYOK/Custom Models.
2. Στη διαχείριση μοντέλων του Copilot στο VS Code, προσθέστε νέο OpenAI-compatible Provider.
3. Συμπληρώστε το Base URL με `https://api.acedata.cloud/v1`.
4. Συμπληρώστε το API Key με το Ace Data Cloud API Token σας.
5. Συμπληρώστε το Model με το ακριβές ID μοντέλου που είναι συμβατό με το επιλεγμένο πρωτόκολλο στον κατάλογο μοντέλων.
6. Στο Copilot Chat, στείλτε `Reply only OK`, και δοκιμάστε ξανά το αίτημα με το πλαίσιο εργασίας.

## Τρέχοντα όρια

- Η ρύθμιση του Copilot App, CLI, GitHub Desktop, Enterprise BYOK διαφέρει από τη ρύθμιση του VS Code, και αυτός ο οδηγός δεν εφαρμόζει άμεσα τα βήματα άλλων πελατών στο VS Code.
- Οι πολιτικές του οργανισμού μπορεί να απαγορεύουν στους χρήστες να προσθέτουν Provider ή μοντέλα.
- Η ολοκλήρωση με Tab, το Chat, ο Agent και οι εργασίες στο παρασκήνιο μπορεί να χρησιμοποιούν διαφορετικά μονοπάτια μοντέλων και θα πρέπει να επαληθεύονται ξεχωριστά.
