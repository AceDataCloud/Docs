Επιστρέφει σελιδοποιημένα τα ορατά API endpoints του τρέχοντος ιστότοπου. Κατάλληλο για αναζήτηση API βάσει επιχειρηματικής διαδρομής, υπηρεσίας ή σταδίου δημοσίευσης· εάν χρειάζεστε μόνο τον πλήρη ορισμό ενός API, καλέστε απευθείας τις [Λεπτομέρειες API](https://platform.acedata.cloud/documents/platform-api-detail).

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                    |
| --- | --------------------------------------------- |
| Μέθοδος  | `GET`                                         |
| URL | `https://platform.acedata.cloud/api/v1/apis/` |
| Επαλήθευση  | Δημόσιο, δεν απαιτείται διακριτικό λογαριασμού                                     |
| Σελιδοποίηση  | `count` + `items`                             |

## Παράμετροι ερωτήματος

| Παράμετρος        | Τύπος      | Υποχρεωτικό  | Περιγραφή                    |
| --------- | ------- | --- | --------------------- |
| `path`    | string  | Όχι   | Ακριβής αντιστοίχιση `path` ή `path2` |
| `service` | string  | Όχι   | Alias υπηρεσίας ή UUID       |
| `stage`   | string  | Όχι   | Φιλτράρισμα κατά στάδιο δημοσίευσης· μπορούν να περαστούν επανειλημμένα πολλές τιμές      |
| `limit`   | integer | Όχι   | Αριθμός εγγραφών ανά σελίδα, μέγιστο 100           |
| `offset`  | integer | Όχι   | Μετατόπιση σελιδοποίησης                 |

Τα `id`, `service_id`, `tag` δεν είναι επί του παρόντος παράμετροι φιλτραρίσματος λίστας· η εισαγωγή τους δεν θα παράγει το αντίστοιχο αποτέλεσμα φιλτραρίσματος.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/apis/' \
  --data-urlencode 'service=midjourney' \
  --data-urlencode 'stage=Production' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/apis/",
    params={"service": "midjourney", "limit": 20},
    timeout=30,
)
response.raise_for_status()
for api in response.json()["items"]:
    print(api["id"], api["method"], api["path"])
```

## Περιγραφή απόκρισης

Η διαδικτυακή απόκριση χρησιμοποιεί `{count, items}`. Κάθε στοιχείο λίστας περιλαμβάνει επί του παρόντος πεδία μοντέλου API, καθώς και:

- `document_id`: συσχετισμένο ID εγγράφου προγραμματιστή, μπορεί να είναι κενό·
- `service_id` / `service`: ID κύριας υπηρεσίας και σύνοψη, μπορεί να είναι κενό·
- `definition`: ορισμός OpenAPI, μπορεί να είναι μεγάλος·
- `method`, `path`, `path2`, `stage`, `cost`, `tags`, `metadata` κ.λπ.

Ο serializer της λίστας περιλαμβάνει επί του παρόντος το `definition`· κατά την ανάκτηση του πλήρους καταλόγου, πρέπει να χρησιμοποιείται σελιδοποίηση και να ορίζεται χρονικό όριο. Πεδία ενδέχεται να προστεθούν με τρόπο συμβατό προς τα πίσω, και ο πελάτης πρέπει να διαβάζει μόνο τα απαιτούμενα πεδία.
