FreeAIr είναι μια ανοιχτού κώδικα επέκταση για το Visual Studio 2022/2026, η οποία δηλώνει επίσημα ότι μπορεί να συνδεθεί με οποιοδήποτε OpenAI-compatible API. Η συμπεριφορά των αιτημάτων μπορεί να διαφέρει ανάλογα με την έκδοση της επέκτασης. Για την πρώτη σύνδεση, παρακαλώ σταθεροποιήστε την έκδοση και ολοκληρώστε την ελάχιστη επαλήθευση που ακολουθεί.

## Ρύθμιση

1. Εγκαταστήστε το FreeAIr από το Visual Studio Marketplace ή το επίσημο αποθετήριο.
2. Ανοίξτε τις ρυθμίσεις του FreeAIr και προσθέστε μια OpenAI-compatible σύνδεση.
3. Στο Endpoint συμπληρώστε `https://api.acedata.cloud/v1`.
4. Στο Token συμπληρώστε το Ace Data Cloud API Token σας.
5. Στο Model συμπληρώστε το ακριβές ID μοντέλου που υποστηρίζει Chat Completions στον κατάλογο μοντέλων.
6. Αφού αποθηκεύσετε, στείλτε `Reply only OK`, και δοκιμάστε ξανά ένα αίτημα με το πλαίσιο του έργου.

## Τρέχοντα όρια

- Αυτός ο οδηγός καλύπτει μόνο το FreeAIr και δεν αντιπροσωπεύει την υποστήριξη του Copilot που είναι ενσωματωμένο στο Visual Studio για arbitrary Base URL.
- Η έκδοση της επέκτασης μπορεί να αλλάξει τον τρόπο σύνθεσης του endpoint; κατά την επαλήθευση, θα πρέπει να ελέγξετε το τελικό URL αιτήματος.
- Η κλήση εργαλείων και οι δυνατότητες MCP εντός της επέκτασης απαιτούν ανεξάρτητη επαλήθευση και δεν μπορούν να αντικατασταθούν από επιτυχία σε κανονική συνομιλία.
