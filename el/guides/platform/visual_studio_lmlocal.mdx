LMLocal είναι μια επέκταση για το Visual Studio 2022/2026, που υποστηρίζει επίσημα το OpenAI-compatible API και προσαρμοσμένο Base URL. Η είσοδος ρύθμισης μπορεί να αλλάξει με τις εκδόσεις της επέκτασης; για πρώτη φορά σύνδεσης, παρακαλώ σταθεροποιήστε την έκδοση και ελέγξτε την πραγματική επεξεργασία, τις κλήσεις εργαλείων και την καταγραφή χρήσης.

## Ρύθμιση

1. Εγκαταστήστε το LMLocal από το Visual Studio Marketplace ή το επίσημο αποθετήριο.
2. Προσθέστε Custom/OpenAI-compatible Provider στους Παρόχους.
3. Συμπληρώστε το Base URL με `https://api.acedata.cloud/v1`.
4. Συμπληρώστε το Auth Key με το Ace Data Cloud API Token σας.
5. Συμπληρώστε το Model με το ακριβές ID μοντέλου που υποστηρίζει Chat Completions στον κατάλογο μοντέλων.
6. Αποθηκεύστε και στείλτε `Reply only OK`, στη συνέχεια δοκιμάστε ξανά τη διαδικασία επεξεργασίας έργου.

## Τρέχοντα όρια

- Αυτός ο οδηγός καλύπτει μόνο το LMLocal και δεν αντιπροσωπεύει άλλες ρυθμίσεις επεκτάσεων του Visual Studio.
- Διαφορετικές εκδόσεις μπορεί να διαχειρίζονται ξεχωριστά τα αιτήματα συνομιλίας, επεξεργασίας, κατασκευής και δοκιμών; κάθε λειτουργία πρέπει να επαληθεύεται ανεξάρτητα.
- Εάν ο πελάτης προσθέτει αυτόματα `/v1` ή endpoint path, παρακαλώ αποφύγετε επαναλαμβανόμενα μονοπάτια.
