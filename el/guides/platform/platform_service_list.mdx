Επιστρέφει σελιδοποιημένα τον κατάλογο Service που είναι ορατός στον τρέχοντα ιστότοπο, συμπεριλαμβανομένων του τύπου υπηρεσίας, των πληροφοριών εμφάνισης, του δωρεάν ορίου, των πακέτων και των συσχετισμένων ID API/Proxy. Κατάλληλο για τη δημιουργία αγοράς υπηρεσιών ή την επιλογή υπηρεσιών προς αίτηση.

## Επισκόπηση διεπαφής

| Στοιχείο   | Περιεχόμενο                                                |
| --- | ------------------------------------------------- |
| Μέθοδος  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| Πιστοποίηση  | Δημόσια· με κατάσταση σύνδεσης, το `applied` αντικατοπτρίζει μόνο τον τρέχοντα λογαριασμό                        |
| Σελιδοποίηση  | `count` + `items`                                 |

## Παράμετροι ερωτήματος

| Παράμετρος               | Τύπος      | Υποχρεωτικό  | Περιγραφή                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | Όχι   | Φιλτράρισμα βάσει ID υπηρεσίας· υποστηρίζει επαναλαμβανόμενες παραμέτρους         |
| `private`        | boolean | Όχι   | Φιλτράρισμα βάσει δημόσιας κατάστασης· οι κανόνες ορατότητας του ιστότοπου εξακολουθούν να ισχύουν      |
| `type`           | string  | Όχι   | Τύπος υπηρεσίας· υποστηρίζει επαναλαμβανόμενες παραμέτρους              |
| `tag`            | string  | Όχι   | Φιλτράρισμα βάσει ετικέτας                    |
| `include_facets` | boolean | Όχι   | Όταν είναι `true`, προσθέτει στατιστικά τύπων/ετικετών διαθέσιμα στον τρέχοντα ιστότοπο |
| `limit`          | integer | Όχι   | Αριθμός στοιχείων ανά σελίδα, μέγιστο 100              |
| `offset`         | integer | Όχι   | Μετατόπιση σελιδοποίησης                    |
| `ordering`       | string  | Όχι   | Υποστηρίζει μόνο `rank` ή `-rank`     |

Η λίστα δεν υποστηρίζει φιλτράρισμα `alias`· όταν υπάρχει ήδη alias, ζητήστε απευθείας `/api/v1/services/{alias}`. Τα `applied_count`, `updated_at` δεν είναι επιτρεπόμενα πεδία ταξινόμησης.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## Περιγραφή απόκρισης

Η απόκριση είναι `{count, items}`· το `facets` προστίθεται μόνο όταν `include_facets=true`. Τα στοιχεία υπηρεσίας περιλαμβάνουν τα τρέχοντα δημόσια πεδία `id`, `alias`, `title`, `description`, `type`, `applied_count`, `free_amount`, `unit`, `private`, `need_verify`, `rank`, `tags`, `thumbnail`, `doc_url`, `demo_url`, `api_ids`, `proxy_ids`, `cost`, `packages` και άλλα.

Το `applied` στην ανώνυμη λίστα δεν αντιπροσωπεύει την κατάσταση αίτησης κάποιου λογαριασμού. Όταν απαιτείται κατάσταση σχετική με λογαριασμό, θα πρέπει να υπάρχει έγκυρη κατάσταση σύνδεσης και να χρησιμοποιείται η [λίστα αιτήσεων υπηρεσιών](https://platform.acedata.cloud/documents/platform-application-list) ως τελική βάση.
