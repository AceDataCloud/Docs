Cursor παρέχει αυτή τη στιγμή OpenAI API Key και ρυθμίσεις **Override OpenAI Base URL**, που επιτρέπουν τη σύνδεση με υπηρεσίες συμβατές με το OpenAI. Αυτή η δυνατότητα υπάρχει, αλλά οι διαφορετικές εκδόσεις δεν χειρίζονται πλήρως με τον ίδιο τρόπο τα `/chat/completions`, `/responses`, τη λίστα μοντέλων και τις λειτουργίες Agent/Composer.

Η συμβατότητα μεταξύ διαφορετικών εκδόσεων του Cursor, λειτουργικών συστημάτων και τρόπων αιτημάτων μπορεί να διαφέρει. Παρακαλώ ολοκληρώστε την πραγματική έλεγχο λειτουργίας σύμφωνα με τη διαμόρφωση αυτής της σελίδας, μην υποθέτετε ότι όλες οι δυνατότητες είναι διαθέσιμες μόνο και μόνο επειδή μια συνομιλία ήταν επιτυχής.

## Cursor επίσημο BYOK τρέχουσες εγγυήσεις

Σύμφωνα με το [Cursor επίσημο έγγραφο Bring your own API key](https://cursor.com/help/models-and-usage/api-keys):

- Υποστηρίζει διαπιστευτήρια από OpenAI, Anthropic, Google, Azure OpenAI και AWS Bedrock;
- Το προσαρμοσμένο API Key χρησιμοποιείται μόνο για μοντέλα συνομιλίας, η ολοκλήρωση καρτελών συνεχίζει να χρησιμοποιεί τα ενσωματωμένα μοντέλα του Cursor;
- Το API Key δεν αποθηκεύεται μόνιμα στους διακομιστές του Cursor, αλλά αποστέλλεται σε κάθε αίτημα στο backend του Cursor για την τελική κατασκευή prompt;
- Όταν χρησιμοποιείτε το δικό σας Key, η πολιτική Zero Data Retention του Cursor δεν ισχύει, η επεξεργασία δεδομένων ακολουθεί την πολιτική του επιλεγμένου παρόχου.

## Διαμόρφωση

1. Ανοίξτε τις Ρυθμίσεις του Cursor → Μοντέλα.
2. Συμπληρώστε το Ace Data Cloud API Token σας στο OpenAI API Key.
3. Ενεργοποιήστε το **Override OpenAI Base URL**, συμπληρώστε `https://api.acedata.cloud/v1`.
4. Επιλέξτε ή προσθέστε το ακριβές ID μοντέλου που είναι συμβατό με το τρέχον πρωτόκολλο του Cursor.
5. Στείλτε πρώτα `Reply only OK`, και στη συνέχεια δοκιμάστε ξεχωριστά τις λειτουργίες Ask/Edit/Agent κ.λπ. που χρησιμοποιείτε πραγματικά.

## Τρέχοντα όρια

- Το προσαρμοσμένο API Key χρησιμοποιείται μόνο για μοντέλα συνομιλίας, η ολοκλήρωση καρτελών συνεχίζει να χρησιμοποιεί τα ενσωματωμένα μοντέλα του Cursor.
- Ο Cursor μπορεί ακόμα να ολοκληρώσει την τελική κατασκευή prompt στον διακομιστή; παρακαλώ αξιολογήστε τη διαδρομή δεδομένων σε συνδυασμό με τις επίσημες δηλώσεις απορρήτου.
- Η αντικατάσταση της Base URL μπορεί να καλύπτει μόνο μερικά αιτήματα ή να αλλάξει λόγω διαφορών εκδόσεων μεταξύ Chat Completions/Responses.
- Δεν θα πρέπει να δηλώνετε ότι οι Agent, Auto, Composer ή οι εργασίες παρασκηνίου είναι συνδεδεμένες μόνο και μόνο επειδή μια αίτηση συνομιλίας ήταν επιτυχής.

## Πλήρης έλεγχος συμβατότητας

Για μακροχρόνια χρήση σε παραγωγικές ροές εργασίας, παρακαλώ ολοκληρώστε τα παρακάτω ελέγχους:

1. Σταθερή έκδοση Cursor και λειτουργικό σύστημα;
2. Ολοκληρώστε πραγματικό smoke test με τον πελάτη για αυτή την έκδοση και καταγράψτε το τελικό πρωτόκολλο και τη διαδρομή αιτήματος;
3. Επιτυχής αίτηση Chat Completions για το ακριβές μοντέλο;
4. Οι κλήσεις εργαλείων και οι αιτήσεις Agent πράγματι περνούν από τον στόχο endpoint;
5. Η χρήση και οι χρεώσεις μπορούν να επαληθευτούν;
6. Καταγράψτε σαφώς αν το αίτημα πέρασε από τον διακομιστή του Cursor και τους αντίστοιχους περιορισμούς απορρήτου.

Μετά από αναβάθμιση του πελάτη, θα πρέπει να επαναλάβετε αυτούς τους ελέγχους για να επιβεβαιώσετε ότι το πρωτόκολλο αιτήματος, οι κλήσεις εργαλείων και η διαδρομή δεδομένων δεν έχουν αλλάξει.
