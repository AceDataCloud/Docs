Αυτό το άρθρο θα παρουσιάσει μια μέθοδο σύνδεσης με το API αναγνώρισης πρωτοκόλλου Cloudflare Turnstile, που επιτρέπει στους χρήστες να ολοκληρώνουν την επαλήθευση χωρίς να αναγνωρίζουν και να επιλέγουν το CAPTCHA Turnstile, απλά υποβάλλοντας το Website Key για αυτόματη αποκωδικοποίηση στο παρασκήνιο.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API αναγνώρισης πρωτοκόλλου Cloudflare Turnstile, πρώτα πηγαίνετε στο [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν. Όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό σας υπόλοιπο στο [Console](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Cloudflare Turnstile Πρωτόκολλο Αναγνώρισης API →](https://platform.acedata.cloud/documents/captcha-token-turnstile)

## Βασική Χρήση

Πρώτα πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, που είναι η εισαγωγή του URL της ιστοσελίδας που χρειάζεται να επεξεργαστεί το CAPTCHA Turnstile, για να αποκτήσετε το επεξεργασμένο αποτέλεσμα. Πρέπει πρώτα να περάσετε ένα πεδίο `website_url`, το παράδειγμα ιστοσελίδας μας είναι: `https://react-turnstile.vercel.app`, και πρέπει να αποκτήσουμε το `website_key` από τη σελίδα `website_url`. Ανοίξτε αυτή τη σελίδα, πατήστε F12 για να μπείτε στην κονσόλα, και κάντε παγκόσμια αναζήτηση για το `cf-turnstile` στην καρτέλα Element, όπου μπορείτε να βρείτε το στοιχείο που περιέχει το Turnstile, και η τιμή του `data-sitekey` είναι το `website_key`.

Οι ρυθμίσεις των Request Headers περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, ρυθμίστηκε το Request Body, που περιλαμβάνει:

- `website_url`: το URL της ιστοσελίδας που χρειάζεται να επεξεργαστεί το CAPTCHA.
- `website_key`: ο αναγνωριστικός δείκτης κλειδιού της ιστοσελίδας στο Cloudflare Turnstile (sitekey).
- `action`: προαιρετική παράμετρος, χρειάζεται να περαστεί μόνο εάν η στοχευμένη ιστοσελίδα έχει ορίσει προσαρμοσμένο `action` για το στοιχείο Turnstile.
- `cdata`: προαιρετική παράμετρος, χρειάζεται να περαστεί μόνο εάν η στοχευμένη ιστοσελίδα έχει ορίσει προσαρμοσμένο `cData` για το στοιχείο Turnstile.

Πατώντας το κουμπί «Δοκιμή» μπορείτε να κάνετε μια δοκιμή, και εδώ θα λάβουμε το εξής αποτέλεσμα:

```json
{
  "token": "0.mNQ2f9uP6mQ0y3H5Q8bqO7iM......",
  "started_at": 1784885653.0,
  "finished_at": 1784885665.4,
  "elapsed": 12.4
}
```

Το επιστρεφόμενο αποτέλεσμα περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `token`, το αποτέλεσμα της επαλήθευσης της εργασίας CAPTCHA Cloudflare Turnstile.
- `started_at`, `finished_at`: ο χρόνος έναρξης και ολοκλήρωσης της επεξεργασίας της τρέχουσας αίτησης, Unix timestamp (δευτερόλεπτα, float).
- `elapsed`: ο συνολικός χρόνος επεξεργασίας (δευτερόλεπτα).

Μπορούμε να δούμε ότι λάβαμε το αποτέλεσμα επαλήθευσης του CAPTCHA Turnstile, και μπορούμε να το χρησιμοποιήσουμε για POST ή προσομοίωση υποβολής στην στοχευμένη ιστοσελίδα, για μία μόνο χρήση, με διάρκεια 120s, προτείνεται να χρησιμοποιηθεί εντός 60s. Κατά την υποβολή, συνήθως στέλνουμε αυτό το token ως παράμετρο `cf-turnstile-response` στην στοχευμένη ιστοσελίδα, ο κώδικας Python για την κλήση της επαλήθευσης του token είναι ο εξής:

```python
import requests

token = '{token}'

data = {
    'cf-turnstile-response': token
}

response = requests.post('https://react-turnstile.vercel.app', data=data)

if response.status_code == 200:
    print(response.text)
```

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, για παράδειγμα, ο κώδικας CURL είναι ο εξής:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/token/turnstile' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "website_key": "0x4AAAAAAADnPIDROrmt1Wwj",
  "website_url": "https://react-turnstile.vercel.app"
}'
```

Ο κώδικας σύνδεσης Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/turnstile"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "website_key": "0x4AAAAAAADnPIDROrmt1Wwj",
    "website_url": "https://react-turnstile.vercel.app"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Ασύγχρονη Λειτουργία (async)

Από προεπιλογή, το API είναι συγχρονισμένο και μπλοκαρισμένο: μια αίτηση θα περιμένει μέχρι να ολοκληρωθεί η επεξεργασία του token πριν επιστρέψει. Εάν κάνετε εναλλαγή πολλών λύσεων (multi-solver rotation) και θέλετε «να λάβετε αμέσως το task_id μετά την υποβολή της εργασίας, να προγραμματίσετε άλλες λύσεις και αργότερα να επιστρέψετε για να διαβάσετε το αποτέλεσμα», μπορείτε να περάσετε `async: true` στο σώμα της αίτησης.

Με την παράμετρο `async: true`, η διεπαφή θα επιστρέψει αμέσως ένα `task_id`, χωρίς να μπλοκάρει την αναμονή:

```json
{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

Αν θέλετε να ελέγξετε την πρόοδο, μπορείτε να χρησιμοποιήσετε το `task_id` για να ελέγξετε το `POST /captcha/tasks` (συνιστάται κάθε 3~5 δευτερόλεπτα). Αυτή η διεπαφή δεν θα ενεργοποιήσει ή θα προχωρήσει την επεξεργασία της εργασίας. Ακόμα και αν δεν ελέγξετε, διακοπεί η σύνδεση ή αποσυνδεθείτε από τον πελάτη, ο διακομιστής θα συνεχίσει να επεξεργάζεται:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002"
}'
```

Κατά την επεξεργασία θα επιστραφεί `status: processing`; όταν ολοκληρωθεί η επεξεργασία θα επιστραφεί `status: ready` και token:

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "ready",
  "token": "0.mNQ2f9uP6mQ0y3H5Q8bqO7iM......"
}
```

Πληροφορίες χρέωσης: στην ασύγχρονη λειτουργία, η δημιουργία εργασίας και η ανάγνωση της κατάστασης «σε επεξεργασία» δεν χρεώνονται. **Η χρέωση γίνεται μία φορά όταν ο πελάτης διαβάσει επιτυχώς το αποτέλεσμα** (σύμφωνα με την υπάρχουσα συμπεριφορά και την τιμή της συγχρονισμένης λειτουργίας). Ο διακομιστής θα προχωρήσει αυτόματα την εργασία, αλλά δεν θα χρεώσει νωρίτερα επειδή η επεξεργασία ολοκληρώθηκε στο παρασκήνιο. Εάν η εργασία δεν ολοκληρωθεί εντός 120 δευτερολέπτων, θα τερματιστεί με HTTP 504 `timeout`, χωρίς χρέωση. Το `/captcha/tasks` δεν είναι υπεύθυνο για την προώθηση της εργασίας.

> Σημείωση: Το Cloudflare Turnstile δεν υποστηρίζει προς το παρόν την επιλογή Bring Your Own Proxy, επομένως αυτή η διεπαφή δεν δέχεται την παράμετρο `proxy`; αν περαστεί, θα επιστραφεί `400 invalid_proxy`.

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:
- `400 token_mismatched`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 invalid_proxy`：Κακή αίτηση, ο διακομιστής μεσολάβησης δεν υποστηρίζεται για αυτόν τον τύπο captcha.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παραδείγματα σφαλμάτων

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
