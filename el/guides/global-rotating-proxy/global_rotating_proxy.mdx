Αυτό το έγγραφο περιγράφει κυρίως τη διαδικασία σύνδεσης των παγκόσμιων αντιπροσώπων της Ace Data Cloud, συμπεριλαμβανομένων των μεθόδων αίτησης, χρήσης κ.λπ.

## Μέθοδος Αίτησης

Για να χρησιμοποιήσετε τις παγκόσμιες υπηρεσίες, μπορείτε πρώτα να επισκεφθείτε τη «[σελίδα αίτησης](https://platform.acedata.cloud/services/87ae4a5a-59d9-4c50-86d4-c0b5d393e5af)» για να κάνετε αίτηση, η πρώτη αίτηση έχει 1 πόντο δωρεάν.

![](https://cdn.acedata.cloud/cyzvmz.png)

Εάν δεν έχετε συνδεθεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης, αφού συνδεθείτε μπορείτε να συνεχίσετε την αίτηση.

## Μέθοδος Χρήσης

Αφού ολοκληρώσετε την αίτηση, μπορείτε να ελέγξετε το αποτέλεσμα της αίτησής σας στην «κονσόλα», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/y9boi5.png)

Κάντε κλικ στο «Credentials» για να δείτε το όνομα χρήστη και τον κωδικό πρόσβασης για τη χρήση της παγκόσμιας υπηρεσίας αντιπροσώπων, διαχωρισμένα με άνω και κάτω τελεία, όπου το όνομα χρήστη είναι 8 ψηφία και ο κωδικός είναι 32 ψηφία, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/ixwm85.png)

Αυτός ο αντιπρόσωπος είναι ένας περιστροφικός αντιπρόσωπος (Rotating Proxy), επομένως κατά τη χρήση χρειάζεται να ρυθμίσετε μόνο μια σταθερή διεύθυνση και θύρα αντιπροσώπου, η διεύθυνση και η θύρα του αντιπροσώπου είναι `global.proxy.acedata.cloud` και `30007`, αυτός ο αντιπρόσωπος είναι αντιπρόσωπος πρωτοκόλλου HTTP/HTTPS/SOCKS και μπορεί να χρησιμοποιηθεί για αιτήματα σε ιστότοπους πρωτοκόλλου HTTP και HTTPS.

> Σημείωση: Αυτός ο αντιπρόσωπος μπορεί να χρησιμοποιηθεί μόνο σε δίκτυα εκτός Κίνας, δεν είναι διαθέσιμος στην ηπειρωτική Κίνα.

## Δοκιμή Εντολών

Αφού έχετε το όνομα χρήστη και τον κωδικό πρόσβασης του αντιπροσώπου, ο πιο βολικός τρόπος είναι να κάνετε δοκιμή μέσω της εντολής curl, αν δεν είναι εγκατεστημένο, ανατρέξτε στο [https://curl.se/](https://curl.se/) για εγκατάσταση.

Αν το τρέχον όνομα χρήστη και κωδικός του αντιπροσώπου είναι `1f78266a:eff0896726224fa2a99fe82dd1f07562`, μπορούμε να κάνουμε δοκιμή με την παρακάτω εντολή curl:

```shell
curl -x 1f78266a:eff0896726224fa2a99fe82dd1f07562@global.proxy.acedata.cloud:30007 https://ipinfo.io
```

Εδώ χρησιμοποιούμε την παράμετρο `-x` του curl για να καθορίσουμε τη διεύθυνση του αντιπροσώπου, το πρωτόκολλο του αντιπροσώπου είναι προεπιλεγμένα HTTP/HTTPS, η URL που ζητάμε είναι [https://ipinfo.io](https://ipinfo.io), αυτός ο ιστότοπος μπορεί να επιστρέψει τη πραγματική διεύθυνση IP και την περιοχή της IP που ζητά τον ιστότοπο.

> Σημείωση: Ο παραπάνω κωδικός χρήστη μπορεί να είναι άκυρος, παρακαλώ αντικαταστήστε τον με τον κωδικό χρήστη σας.

Το αποτέλεσμα είναι το εξής:

## Σύνδεση Κώδικα

Ακολουθεί ένα παράδειγμα ρύθμισης του αντιπροσώπου με Python:

```python
import requests

proxy = 'http://{proxy_username}:{proxy_password}@global.proxy.acedata.cloud:30007'

proxies = {
    'http': proxy,
    'https': proxy
}

for _ in range(3):
    resp = requests.get('https://ipinfo.io', proxies=proxies)
    print(resp.text)
```

Εδώ δηλώνουμε πρώτα τη διεύθυνση URL του αντιπροσώπου και την ορίζουμε ως μεταβλητή proxy, το πρωτόκολλο είναι http, ακολουθούμενο από το όνομα χρήστη και τον κωδικό πρόσβασης του τούνελ του αντιπροσώπου (δηλαδή το όνομα χρήστη και τον κωδικό που εμφανίζεται στην κονσόλα, διαχωρισμένα με άνω και κάτω τελεία), ακολουθούμενο από ένα `@` και στη συνέχεια τη διεύθυνση και τη θύρα του αντιπροσώπου.

> Σημείωση: Πρέπει να αντικαταστήσετε το `{proxy_username}:{proxy_password}` στον παραπάνω κώδικα με το όνομα χρήστη και τον κωδικό πρόσβασης του αντιπροσώπου σας, το τελικό αποτέλεσμα θα είναι παρόμοιο με `proxy = 'http://1f78266a:eff0896726224fa2a99fe82dd1f07562@global.proxy.acedata.cloud:30007'`, προσέξτε ότι δεν υπάρχουν χαρακτήρες `{` και `}`.

Στη συνέχεια, δηλώνουμε μια μεταβλητή proxies, ρυθμίζοντας δύο ζεύγη κλειδιών, με τα ονόματα κλειδιών http και https, και οι τιμές τους είναι και οι δύο proxy, που αντιπροσωπεύει ότι για τους ιστότοπους πρωτοκόλλου HTTP και HTTPS, χρησιμοποιείται ο αντιπρόσωπος που ορίζεται από τη μεταβλητή proxy για τα αιτήματα. Στη συνέχεια, ορίζουμε τρεις επαναλήψεις για τη δοκιμή του αντιπροσώπου.

Φυσικά, η παραπάνω μέθοδος ρύθμισης του αντιπροσώπου είναι στην πραγματικότητα μια σχετικά απλή μέθοδος ρύθμισης.

Στην πραγματικότητα, ο παραπάνω κώδικας είναι ισοδύναμος με την προσθήκη ενός επιπλέον Headers - Proxy Authorization κατά την αίτηση, επομένως ο παραπάνω κώδικας μπορεί επίσης να ξαναγραφεί ως εξής:

```python
import requests
import base64

proxy_host = 'global.proxy.acedata.cloud'
proxy_port = '30007'
proxy_username = '{proxy_username}' # 8 ψηφία όνομα χρήστη
proxy_password = '{proxy_password}' # 32 ψηφία κωδικός

credentials = base64.b64encode(
    f'{proxy_username}:{proxy_password}'.encode()).decode()

proxies = {
    'http': f'http://{proxy_host}:{proxy_port}',
    'https': f'http://{proxy_host}:{proxy_port}'
}

headers = {
    'Proxy-Authorization': f'Basic {credentials}'
}

for _ in range(3):
    resp = requests.get('https://ipinfo.io',
                        proxies=proxies, headers=headers)
    print(resp.text)

```

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει επιπλέον το όνομα χρήστη και τον κωδικό πρόσβασης του αντιπροσώπου μέσω του Headers Proxy-Authorization (χρειάζεται κωδικοποίηση Base64), το αποτέλεσμα της εκτέλεσης αυτού του κώδικα είναι το ίδιο.

Για άλλες γλώσσες, όπως η axios της JavaScript, μπορείτε επίσης να χρησιμοποιήσετε παρόμοια μέθοδο ρύθμισης:
```javascript
const axios = require("axios");
const base64 = require("base64");

const proxy_host = "global.proxy.acedata.cloud";
const proxy_port = "30007";
const proxy_username = "{proxy_username}"; // 8 χαρακτήρες όνομα χρήστη
const proxy_password = "{proxy_password}"; // 32 χαρακτήρες κωδικός

const credentials = base64.encode(`${proxy_username}:${proxy_password}`);

const proxies = {
  http: `http://${proxy_host}:${proxy_port}`,
  https: `http://${proxy_host}:${proxy_port}`,
};

const headers = {
  "Proxy-Authorization": `Basic ${credentials}`,
};

for (let i = 0; i < 3; i++) {
  axios
    .get("https://ipinfo.io", { proxies, headers })
    .then((resp) => console.log(resp.data))
    .catch((err) => console.error(err));
}
```

Η εκτέλεση έχει το ίδιο αποτέλεσμα.

Για τις ρυθμίσεις άλλων γλωσσών, μπορείτε να ανατρέξετε παραπάνω και να τις τροποποιήσετε ανάλογα.

## Σταθερή IP

Όπως και με το παραπάνω περιεχόμενο, μπορούμε να επιτύχουμε μια σταθερή IP για μια χρονική περίοδο προσθέτοντας `session` στο username και προσθέτοντας έναν 5ψήφιο σταθερό αριθμό, με διάρκεια περίπου 10 λεπτά.

Για παράδειγμα, αν θέλουμε να επιτύχουμε μια σταθερή IP για μια χρονική περίοδο, το αρχικό username είναι `1f78266a`, μπορούμε να αλλάξουμε το username σε `1f78266a-session-12345`, όπου το `12345` αν παραμείνει το ίδιο, τότε η IP θα παραμείνει σταθερή για μια χρονική περίοδο, και το παραπάνω curl μπορεί να ξαναγραφεί ως εξής:

```
curl -x 1f78266a-session-12345:eff0896726224fa2a99fe82dd1f07562@global.proxy.acedata.cloud:30007 https://ipinfo.io
```

Εάν το πακέτο σας έχει εξαντληθεί, θα χρειαστεί να αγοράσετε περισσότερα για να συνεχίσετε να χρησιμοποιείτε αυτή την υπηρεσία proxy.

Για να αγοράσετε περισσότερα, παρακαλώ επισκεφθείτε τη «[σελίδα αίτησης](https://platform.acedata.cloud/services/87ae4a5a-59d9-4c50-86d4-c0b5d393e5af)» και απλά κάντε κλικ στο κουμπί «Αγορά περισσότερων» για να επιλέξετε, η τιμή ανά μονάδα είναι φθηνότερη για αγορές μεγαλύτερης ποσότητας.
