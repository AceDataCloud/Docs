Κάντε ένα **υπάρχον βίντεο 可灵** (5 δευτ. ή 10 δευτ.) να «μιλάει» σύμφωνα με ήχο ή κείμενο — δηλαδή συγχρονισμό χειλιών (Lip Sync). Σε συνδυασμό με το `image2video` του `/kling/videos` (για να ζωντανέψετε μια φωτογραφία), μπορείτε να δημιουργήσετε μια πλήρη ροή «**φωτογραφία που μιλάει / ψηφιακή ανθρώπινη παρουσίαση**».

> Αυτή η διεπαφή είναι μια βολική ενιαία ενθυλάκωση που παρέχεται από το AceDataCloud, προσανατολισμένη σε συνηθισμένα σενάρια που καθοδηγούνται από ήχο/κείμενο· δεν αποτελεί αντιστοίχιση πεδίων της επίσημης πολυβηματικής διεπαφής Kling «αναγνώριση προσώπου → Advanced Lip Sync». Ανατρέξτε στον πίνακα παραμέτρων αυτής της σελίδας.

- **Διεύθυνση διεπαφής**：`POST https://api.acedata.cloud/kling/lip-sync`
- **Μορφή αιτήματος**：`application/json`
- **Μορφή απόκρισης**：`application/json`
- **Χρέωση**：**2.45 Credits** για κάθε επιτυχημένη κλήση (σταθερή)

## Κεφαλίδες Αιτήματος（Request Headers）

| Πεδίο              | Τιμή                   | Περιγραφή                                               |
| --------------- | ------------------- | ------------------------------------------------ |
| `authorization` | `Bearer ${API_KEY}` | Το κλειδί API σας, [διεύθυνση απόκτησης](https://platform.acedata.cloud) |
| `content-type`  | `application/json`  | Μορφή σώματος αιτήματος                                            |
| `accept`        | `application/json`  | Μορφή απόκρισης                                             |

## Παράμετροι Αιτήματος（Request Body）

| Παράμετρος               | Τύπος      | Υποχρεωτικό  | Προεπιλογή      | Περιγραφή                                                                                                                       |
| ---------------- | ------- | --- | ------- | ------------------------------------------------------------------------------------------------------------------------ |
| `mode`           | string  | Ναι   | —       | Λειτουργία δημιουργίας. Επιλογές: `audio2video` (καθοδηγούμενο από ήχο), `text2video` (καθοδηγούμενο από κείμενο)                                                                           |
| `video_id`       | string  | Ένα από τα δύο | —       | ID του βίντεο που δημιουργήθηκε από 可灵 (όπως το `video_id` που επιστρέφεται από το image2video του `/kling/videos`). **Υποστηρίζονται μόνο βίντεο 5s/10s που δημιουργήθηκαν εντός 30 ημερών**. Επιλέξτε ένα από `video_id` και `video_url`, δεν μπορούν να σταλούν ταυτόχρονα |
| `video_url`      | string  | Ένα από τα δύο | —       | Δημόσια προσβάσιμος σύνδεσμος βίντεο. Περιορισμοί: `.mp4`/`.mov`, ≤100MB, διάρκεια 2–10s, μόνο 720p/1080p, πλευρά 720–1920px. Επιλέξτε ένα από αυτό και το `video_id`                                  |
| `audio_url`      | string  | Υπό όρους  | —       | URL λήψης του ήχου καθοδήγησης, υποχρεωτικό όταν `audio2video` + `audio_type=url`. Μορφές `.mp3`/`.wav`/`.m4a`/`.aac`, ≤5MB                                     |
| `audio_type`     | string  | Όχι   | `url`   | Τρόπος μεταφοράς ήχου. Επιλογές: `url`, `file` (ισχύει για `audio2video`)                                                                                |
| `audio_file`     | string  | Υπό όρους  | —       | Base64 του αρχείου ήχου, υποχρεωτικό όταν `audio_type=file`. Ίδιες μορφές με παραπάνω, ≤5MB                                                                             |
| `text`           | string  | Υπό όρους  | —       | Το κείμενο προς ανάγνωση, υποχρεωτικό για `text2video`, **έως 120 χαρακτήρες**                                                                                     |
| `voice_id`       | string  | Υπό όρους  | —       | ID χροιάς φωνής, υποχρεωτικό για `text2video`                                                                                                   |
| `voice_language` | string  | Όχι   | `zh`    | Γλώσσα χροιάς φωνής. Επιλογές: `zh`, `en` (ισχύει για `text2video`)                                                                                      |
| `voice_speed`    | float   | Όχι   | `1.0`   | Ταχύτητα ομιλίας, εύρος `0.8`–`2.0`, με ακρίβεια ενός δεκαδικού ψηφίου (ισχύει για `text2video`)                                                                              |
| `callback_url`   | string  | Όχι   | —       | Διεύθυνση επανάκλησης. Με την αποστολή αυτού ή του `async=true`, ενεργοποιείται η **ασύγχρονη λειτουργία**: επιστρέφεται άμεσα το `task_id`, και γίνεται επανάκληση μετά τη δημιουργία του αποτελέσματος                                                                 |
| `async`          | boolean | Όχι   | `false` | Εάν είναι ασύγχρονο. Όταν είναι `true`, επιστρέφεται άμεσα το `task_id`, σε συνδυασμό με ερωτήματα μέσω `/kling/tasks` ή επανάκληση `callback_url`                                                      |

## Παραδείγματα Αιτήματος

### 1）Καθοδηγούμενο από ήχο（audio2video）

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2）Καθοδηγούμενο από κείμενο（text2video）

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "哥，好久不见，我一切都好，你要照顾好自己。",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## Παράδειγμα Απόκρισης（επιτυχία συγχρονισμού）

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| Πεδίο          | Τύπος      | Περιγραφή                                         |
| ----------- | ------- | ------------------------------------------ |
| `success`   | boolean | Εάν ήταν επιτυχές                                       |
| `task_id`   | string  | ID της τρέχουσας εργασίας (μπορεί να χρησιμοποιηθεί για ερώτημα μέσω `/kling/tasks`)             |
| `video_id`  | string  | ID 可灵 του δημιουργημένου βίντεο (μπορεί να χρησιμοποιηθεί ως είσοδος για το επόμενο `extend`/`lip-sync`) |
| `video_url` | string  | URL του δημιουργημένου βίντεο ομιλίας (έχει αποθηκευτεί στο CDN αυτής της πλατφόρμας, με μακροχρόνια ισχύ)              |
| `duration`  | string  | Διάρκεια βίντεο (δευτερόλεπτα)                                    |
| `state`     | string  | Κατάσταση εργασίας: `succeed` / `failed`                  |

## Ασύγχρονη Λειτουργία και Ερωτήματα

Όταν σταλεί `callback_url` ή `async: true`, η διεπαφή **επιστρέφει άμεσα** το `task_id`· στη συνέχεια μπορείτε να:

- **Κάνετε polling**：`POST /kling/tasks`, body `{ "action": "retrieve", "id": "<task_id>" }`（δωρεάν）
- **Επανάκληση**：Μετά την ολοκλήρωση της δημιουργίας, το αποτέλεσμα αποστέλλεται με POST στο `callback_url` σας

## Πλήρης Ροή: Φωτογραφία που Μιλάει（image2video → lip-sync）
```bash
# 第 1 步：让照片动起来，拿到 video_id
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"look at camera, natural","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# 第 2 步：用音频对口型
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"}'
# → { "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4", ... }
```

## Απάντηση σφάλματος

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "one of video_id or video_url is required" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | code                    | Σημασία                                                 |
| ---- | ----------------------- | -------------------------------------------------- |
| 400  | `bad_request`           | Λείπουν ή είναι μη έγκυρες παράμετροι (π.χ. δεν δόθηκε mode, σύγκρουση μεταξύ video και audio όπου πρέπει να επιλεγεί ένα από τα δύο, το text υπερβαίνει τους 120 χαρακτήρες) |
| 401  | `authorization_missing` | Λείπει ή δεν είναι έγκυρο το κλειδί API                                      |
| 403  | `forbidden`             | Το περιεχόμενο αποκλείστηκε από τον έλεγχο κινδύνου                                            |
| 429  | `too_many_requests`     | Περιορισμός ταυτόχρονων αιτημάτων από τον πάροχο, δοκιμάστε ξανά αργότερα                                       |
| 500  | `api_error`             | Σφάλμα παρόχου ή εσωτερικό σφάλμα                                            |

## Σημειώσεις

- Το `video_id` πρέπει να είναι βίντεο Kling που δημιουργήθηκε εντός **30 ημερών** και να είναι **5s ή 10s**· διαφορετικά, χρησιμοποιήστε το `video_url` για να εισαγάγετε ένα βίντεο που πληροί τους περιορισμούς.
- Συνιστάται το εισαγόμενο βίντεο να έχει **καθαρό, μετωπικό πρόσωπο και ένα άτομο**, για το καλύτερο αποτέλεσμα συγχρονισμού χειλιών.
- Η διάρκεια του ήχου/κειμένου θα πρέπει να ταιριάζει με τη διάρκεια του βίντεο (ο ήχος δεν πρέπει να υπερβαίνει τη διάρκεια του βίντεο).
- Η χρέωση πραγματοποιείται κατά την **επιτυχία** (2.45 Credits/φορά)· η αποτυχία επαλήθευσης παραμέτρων (4xx) δεν χρεώνεται.
