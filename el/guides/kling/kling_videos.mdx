Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο σύνδεσης με το API Δημιουργίας Βίντεο Kling, το οποίο μπορεί να χρησιμοποιηθεί για τη δημιουργία βίντεο από την επίσημη Kling μέσω εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [API Δημιουργίας Βίντεο Kling](https://platform.acedata.cloud/documents/3b921a16-a411-4557-8335-53f21d3f9e46) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε την προτροπή `prompt`, τη δράση `action`, τη διεύθυνση URL της αρχικής εικόνας `start_image_url` και το μοντέλο `model`, για να λάβετε το επεξεργασμένο αποτέλεσμα. Πρέπει πρώτα να περάσετε ένα πεδίο `action`, του οποίου η τιμή είναι `text2video`. Αυτό περιλαμβάνει τρεις κύριες δράσεις: Δημιουργία βίντεο από κείμενο (`text2video`), Δημιουργία βίντεο από εικόνα (`image2video`), και Επέκταση βίντεο (`extend`). Στη συνέχεια, πρέπει να εισάγουμε το μοντέλο `model`, το οποίο περιλαμβάνει κυρίως τα μοντέλα `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`, όπως φαίνεται παρακάτω:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: τη μορφή της απάντησης που θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί API για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `model`: το μοντέλο για τη δημιουργία του βίντεο, κυρίως `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`.
- `mode`: η λειτουργία δημιουργίας βίντεο, κυρίως η κανονική λειτουργία `std` και η ταχεία λειτουργία `pro`.
- `action`: η δράση της τρέχουσας εργασίας δημιουργίας βίντεο, που περιλαμβάνει τρεις δράσεις: Δημιουργία βίντεο από κείμενο (`text2video`), Δημιουργία βίντεο από εικόνα (`image2video`), Επέκταση βίντεο (`extend`).
- `start_image_url`: όταν επιλέγετε τη δράση Δημιουργίας βίντεο από εικόνα (`image2video`), πρέπει να ανεβάσετε τη διεύθυνση URL της αρχικής εικόνας.
- `end_image_url`: προαιρετικό κατά τη Δημιουργία βίντεο από εικόνα, καθορίζει την τελική εικόνα.
- `aspect_ratio`: η αναλογία διαστάσεων του βίντεο, προαιρετική, υποστηρίζει `16:9`, `9:16`, `1:1`, προεπιλογή `16:9`.
- `cfg_scale`: η ένταση συσχέτισης, εύρος [0,1], όσο μεγαλύτερη, τόσο πιο κοντά στο prompt.
- `camera_control`: προαιρετικό, ελέγχει τις παραμέτρους κίνησης της κάμερας, υποστηρίζει προκαθορισμένα type/simple και ρυθμίσεις horizontal, vertical, pan, tilt, roll, zoom.
- `negative_prompt`: προαιρετικό, αντίθετες προτροπές που δεν θέλετε να εμφανιστούν, μέγιστο 200 χαρακτήρες.
- `element_list`: λίστα αναφοράς υποκειμένων, ισχύει μόνο για το μοντέλο `kling-video-o1`, οι λεπτομέρειες χρήσης αναφέρονται στην [επίσημη τεκμηρίωση](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `video_list`: αναφορά βίντεο, αποκτάται μέσω URL, ισχύει μόνο για το μοντέλο `kling-video-o1`, οι λεπτομέρειες χρήσης αναφέρονται στην [επίσημη τεκμηρίωση](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `prompt`: προτροπή.
- `callback_url`: η διεύθυνση URL για την επιστροφή αποτελεσμάτων.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/3yjql0.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να δοκιμάσετε, όπως φαίνεται στην παραπάνω εικόνα, και θα λάβετε το εξής αποτέλεσμα:

```json
{
  "success": true,
  "video_id": "af9a1af0-9aa0-4638-81c1-d41d6143c508",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7485378259/text2video/Cjil4mfBfs0AAAAAAKbMQQ-0_raw_video_1.mp4",
  "duration": "5.1",
  "state": "succeed",
  "task_id": "e3a575aa-a4bd-49c8-9b12-cde38d5462e0"
}
```

Η επιστροφή αποτελεσμάτων περιλαμβάνει πολλά πεδία, τα οποία περιγράφονται ως εξής:

- `success`, η κατάσταση της τρέχουσας εργασίας δημιουργίας βίντεο.
- `task_id`, το ID της τρέχουσας εργασίας δημιουργίας βίντεο.
- `video_id`, το ID του βίντεο της τρέχουσας εργασίας δημιουργίας βίντεο.
- `video_url`, η διεύθυνση URL του βίντεο της τρέχουσας εργασίας δημιουργίας βίντεο.
- `duration`, η διάρκεια του βίντεο της τρέχουσας εργασίας δημιουργίας βίντεο.
- `state`, η κατάσταση της τρέχουσας εργασίας δημιουργίας βίντεο.

Μπορείτε να δείτε ότι έχουμε λάβει ικανοποιητικές πληροφορίες βίντεο, και απλά πρέπει να αποκτήσουμε το παραγόμενο βίντεο Kling μέσω της διεύθυνσης URL του βίντεο που περιλαμβάνεται στο `data`.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο παρακάτω κώδικας CURL:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v1",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## Λειτουργία Επέκτασης Βίντεο

Εάν θέλετε να συνεχίσετε τη δημιουργία ενός ήδη παραγόμενου βίντεο Kling, μπορείτε να ρυθμίσετε την παράμετρο `action` σε `extend` και να εισάγετε το ID του βίντεο που θέλετε να συνεχίσετε. Η απόκτηση του ID του βίντεο γίνεται σύμφωνα με τη βασική χρήση, όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Αυτή τη στιγμή μπορείτε να δείτε ότι το ID του βίντεο είναι:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

> Σημείωση: το `video_id` εδώ είναι το ID του βίντεο που δημιουργήθηκε. Εάν δεν γνωρίζετε πώς να δημιουργήσετε βίντεο, μπορείτε να ανατρέξετε στη βασική χρήση παραπάνω για να δημιουργήσετε βίντεο.

Στη συνέχεια, πρέπει να συμπληρώσετε την επόμενη προτροπή που χρειάζεται για να προσαρμόσετε τη δημιουργία του βίντεο, ώστε να καθορίσετε τα εξής περιεχόμενα:
- `model`：Το μοντέλο που δημιουργεί βίντεο, κυρίως περιλαμβάνει τα μοντέλα `kling-v1`, `kling-v1-5` και `kling-v1-6`.
- `mode`：Ο τρόπος δημιουργίας βίντεο, κυρίως περιλαμβάνει τον κανονικό τρόπο `std` και τον γρήγορο τρόπο `pro`.
- `duration`：Η διάρκεια του βίντεο για αυτήν την εργασία δημιουργίας βίντεο, κυρίως περιλαμβάνει 5s και 10s.
- `start_image_url`：Όταν επιλέγεται η συμπεριφορά δημιουργίας βίντεο από εικόνα `image2video`, απαιτείται να ανεβεί ο σύνδεσμος της πρώτης εικόνας αναφοράς.
- `prompt`：Λέξη-κλειδί.

Το παράδειγμα συμπλήρωσης είναι το εξής:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" className="m-auto" /></p>

Αφού συμπληρωθεί, δημιουργείται αυτόματα ο παρακάτω κώδικας:

<p><img src="https://cdn.acedata.cloud/52x4u5.png" width="500" className="m-auto" /></p>

Ο αντίστοιχος κώδικας Python:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Κάνοντας κλικ στην εκτέλεση, μπορεί να παρατηρηθεί ότι θα ληφθεί ένα αποτέλεσμα, όπως παρακάτω:

```json
{
  "success": true,
  "video_id": "bbc3b105-ac72-4de2-8390-0cb37dc7d41e",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/extendVideo/Cjil4mfBfs0AAAAAAKhr6A-0_raw_video_1.mp4",
  "duration": "9.6",
  "state": "succeed",
  "task_id": "3ece87e6-3ee3-4f5e-bd70-5ae5eca89a23"
}
```

Μπορεί να παρατηρηθεί ότι το περιεχόμενο του αποτελέσματος είναι συνεπές με το παραπάνω κείμενο, επιτυγχάνοντας έτσι τη λειτουργία επέκτασης βίντεο.

## Ασύγχρονη κλήση επιστροφής

Δεδομένου ότι ο χρόνος δημιουργίας του API Kling Videos Generation είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, εάν το API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος, γι' αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη κλήση επιστροφής.

Η συνολική διαδικασία είναι: Όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`, μετά την υποβολή του API αίτημα, το API θα επιστρέψει αμέσως ένα αποτέλεσμα, που περιλαμβάνει μια πληροφορία πεδίου `task_id`, που αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα του δημιουργημένου βίντεο θα αποσταλεί μέσω POST JSON στη διεύθυνση `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε αυτό μέσω ενός παραδείγματος.

Αρχικά, η κλήση επιστροφής Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα, οι προγραμματιστές θα πρέπει να την αντικαταστήσουν με το URL του HTTP διακομιστή που έχουν δημιουργήσει. Για ευκολία επίδειξης, χρησιμοποιούμε έναν δημόσιο ιστότοπο Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να λάβετε ένα Webhook URL, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/tbcnai.png)

Αντιγράψτε αυτό το URL και μπορείτε να το χρησιμοποιήσετε ως Webhook, το δείγμα εδώ είναι `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`.

Στη συνέχεια, μπορούμε να ρυθμίσουμε το πεδίο `callback_url` στο παραπάνω Webhook URL, ενώ συμπληρώνουμε τα αντίστοιχα παραμέτρους, οι συγκεκριμένες λεπτομέρειες φαίνονται στην εικόνα:

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα απόκρισης σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
