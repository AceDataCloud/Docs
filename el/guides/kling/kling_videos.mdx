Το παρόν κείμενο θα παρουσιάσει οδηγίες ενσωμάτωσης ενός Kling Videos Generation API, το οποίο μπορεί να δημιουργεί επίσημα βίντεο Kling μέσω εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Kling Videos Generation API, αποκτήστε πρώτα το API Token σας από την [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση προσφέρει δωρεάν υπόλοιπο για δωρεάν δοκιμή· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να φορτίσετε γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Kling Videos Generation API →](https://platform.acedata.cloud/documents/kling-videos)

## Βασική χρήση

Αρχικά, ας κατανοήσουμε τον βασικό τρόπο χρήσης: εισάγετε το prompt `prompt`, την ενέργεια δημιουργίας `action`, την εικόνα αναφοράς πρώτου καρέ `start_image_url` και το μοντέλο `model`, και μπορείτε να λάβετε το επεξεργασμένο αποτέλεσμα. Πρώτα χρειάζεται να περάσετε απλά ένα πεδίο `action`, του οποίου η τιμή είναι `text2video`. Περιλαμβάνει κυρίως τρεις ενέργειες: κείμενο σε βίντεο (`text2video`), εικόνα σε βίντεο (`image2video`), επέκταση βίντεο (`extend`). Στη συνέχεια, χρειάζεται επίσης να εισαγάγουμε το μοντέλο `model`. Επί του παρόντος υπάρχουν κυρίως τα μοντέλα `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-o1`, και το συγκεκριμένο περιεχόμενο είναι το εξής:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ ορίσαμε τα Request Headers, που περιλαμβάνουν:

- `accept`: Ποια μορφή αποτελέσματος απόκρισης θέλετε να λαμβάνετε· εδώ συμπληρώνεται ως `application/json`, δηλαδή μορφή JSON.
- `authorization`: Το κλειδί για την κλήση του API, το οποίο μπορεί να επιλεγεί απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, ορίσαμε το Request Body, που περιλαμβάνει:

- `model`: Το μοντέλο για τη δημιουργία βίντεο, κυρίως τα μοντέλα `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-o1`.
- `mode`: Η λειτουργία δημιουργίας βίντεο, με διαθέσιμες τιμές την τυπική λειτουργία `std`, τη λειτουργία υψηλής ταχύτητας `pro` και τη λειτουργία εγγενούς 4K `4k`. Μεταξύ αυτών, το `4k` υποστηρίζει μόνο τα `kling-v3` και `kling-v3-omni`, και δεν είναι συμβατό με το `camera_control` (έλεγχος κίνησης κάμερας).
- `action`: Η ενέργεια αυτής της εργασίας δημιουργίας βίντεο, που περιλαμβάνει κυρίως τρεις ενέργειες: κείμενο σε βίντεο (`text2video`), εικόνα σε βίντεο (`image2video`), επέκταση βίντεο (`extend`).
- `start_image_url`: Όταν επιλέγετε την ενέργεια εικόνα σε βίντεο `image2video`, απαιτείται ο σύνδεσμος της μεταφορτωμένης εικόνας αναφοράς πρώτου καρέ.
- `end_image_url`: Προαιρετικό για εικόνα σε βίντεο, καθορίζει το τελευταίο καρέ.
- `duration`: Διάρκεια βίντεο, σε δευτερόλεπτα. Τα `kling-v3` και `kling-v3-omni` υποστηρίζουν ακέραια διάρκεια 3-15 δευτερολέπτων· το `kling-o1` υποστηρίζει μόνο 5 δευτερόλεπτα· τα άλλα μοντέλα υποστηρίζουν 5 ή 10 δευτερόλεπτα.
- `generate_audio`: Εάν θα δημιουργηθεί ταυτόχρονα ήχος, προαιρετικό, λογική τιμή. Υποστηρίζεται από τα `kling-v3`, `kling-v3-omni` και `kling-v2-6` (μόνο σε λειτουργία pro). Η προεπιλογή είναι `false`.
- `aspect_ratio`: Αναλογία πλάτους προς ύψος βίντεο, προαιρετικό, υποστηρίζει `16:9`, `9:16`, `1:1`, προεπιλογή `16:9`.
- `cfg_scale`: Ένταση συσχέτισης, εύρος [0,1], όσο μεγαλύτερη είναι τόσο πιο πιστά ακολουθεί το prompt.
- `camera_control`: Προαιρετικό, παράμετρος αντικειμένου για τον έλεγχο της κίνησης της κάμερας, υποστηρίζει προκαθορισμένα type/simple καθώς και ρυθμίσεις όπως horizontal, vertical, pan, tilt, roll, zoom.
- `negative_prompt`: Προαιρετικό, αρνητικό prompt για στοιχεία που δεν επιθυμείτε να εμφανιστούν, έως 200 χαρακτήρες.
- `image_list`: Λίστα εικόνων αναφοράς Omni, εφαρμόζεται στα μοντέλα `kling-o1` και `kling-v3-omni`, για τη χρήση δείτε παρακάτω «Πανίσχυρη αναφορά Omni».
- `video_list`: Λίστα βίντεο αναφοράς Omni (υποστηρίζει επεξεργασία βίντεο), εφαρμόζεται στα μοντέλα `kling-o1` και `kling-v3-omni`, για τη χρήση δείτε παρακάτω «Πανίσχυρη αναφορά Omni».
- `prompt`: Prompt.
- `callback_url`: URL για το αποτέλεσμα callback.
- `async`: Προαιρετικό, όταν ορίζεται σε `true`, η διεπαφή επιστρέφει αμέσως `task_id`, χωρίς να χρειάζεται να παρέχετε `callback_url`, και στη συνέχεια λαμβάνετε το αποτέλεσμα μέσω polling από την αντίστοιχη διεπαφή αναζήτησης εργασίας.

Μετά την επιλογή, μπορείτε να διαπιστώσετε ότι δημιουργήθηκε επίσης ο αντίστοιχος κώδικας στη δεξιά πλευρά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/3yjql0.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για δοκιμή. Όπως φαίνεται στην παραπάνω εικόνα, εδώ λάβαμε το ακόλουθο αποτέλεσμα:

```json
{
  "success": true,
  "video_id": "900798310464749610",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "duration": "5.041",
  "state": "succeed",
  "task_id": "6c68c267-065b-4423-b66b-a0e4c59ee0d5"
}
```

Το επιστρεφόμενο αποτέλεσμα περιλαμβάνει πολλαπλά πεδία, τα οποία παρουσιάζονται ως εξής:

- `success`, η κατάσταση της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `task_id`, το ID της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `video_id`, το ID βίντεο της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `video_url`, ο σύνδεσμος βίντεο της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `duration`, η διάρκεια του συνδέσμου βίντεο της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `state`, η κατάσταση της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.

Μπορούμε να δούμε ότι λάβαμε ικανοποιητικές πληροφορίες βίντεο· χρειάζεται μόνο να αποκτήσουμε το δημιουργημένο βίντεο Kling σύμφωνα με τη διεύθυνση συνδέσμου βίντεο του `data` στο αποτέλεσμα.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα ενσωμάτωσης, μπορείτε να τον αντιγράψετε απευθείας. Για παράδειγμα, ο κώδικας CURL είναι ο εξής:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v3",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## Πίνακας δυνατοτήτων μοντέλων

### Χρέωση βίντεο αναφοράς O1 και Omni

Το `kling-o1` χρεώνεται ανάλογα με τη λειτουργία και το αν παρέχεται `video_list`. Ακολουθούν οι τιμές για ένα τελικό βίντεο 5 δευτερολέπτων:

| Λειτουργία | Χωρίς βίντεο αναφοράς | Με βίντεο αναφοράς |
| --- | ------------: | ------------: |
| std | 4.005 Credits | 6.010 Credits |
| pro | 5.340 Credits | 8.010 Credits |
`kling-o1` και `kling-v3-omni` με βίντεο αναφοράς χρεώνουν τα επιτυχημένα αιτήματα με βάση τα χρεώσιμα δευτερόλεπτα: το std είναι **1.202 Credits/δευτερόλεπτο**, το pro είναι **1.602 Credits/δευτερόλεπτο**. Για παράδειγμα, η δημιουργία 5 δευτερολέπτων σε λειτουργία std κοστίζει 6.010 Credits. Η παράλειψη του `video_list` δεν ενεργοποιεί το επίπεδο βίντεο αναφοράς· το `image_list`, καθώς και οι εικόνες πρώτου και τελευταίου καρέ, επίσης δεν θεωρούνται βίντεο αναφοράς. Το βίντεο αναφοράς δεν μπορεί να χρησιμοποιηθεί ταυτόχρονα με `generate_audio=true`.

Η επεξεργασία βίντεο με `refer_type=base` (προεπιλογή) ενδέχεται να ακολουθεί τη διάρκεια του βίντεο αναφοράς και τελικά χρεώνεται με βάση την πραγματική διάρκεια του παραγόμενου βίντεο, στρογγυλοποιημένη στο πλησιέστερο ακέραιο δευτερόλεπτο: για παράδειγμα, 5.708 δευτερόλεπτα χρεώνονται ως 6 δευτερόλεπτα και 5.041 δευτερόλεπτα ως 5 δευτερόλεπτα. Το `refer_type=feature` χρησιμοποιεί το ζητούμενο `duration`. Το `usage.reference_video_seconds` στην απόκριση παρέχει τα τελικά χρεώσιμα δευτερόλεπτα· η εκτιμώμενη τιμή κατά το αίτημα μπορεί να διαφέρει από την τελική χρέωση.

Τα διαφορετικά μοντέλα διαφέρουν σημαντικά ως προς την υποστήριξη παραμέτρων. Ο παρακάτω πίνακας προέρχεται από την [επίσημη τεκμηρίωση video models του Kling](https://app.klingai.com/global/dev/document-api/apiReference/model/videoModels). Πριν από την κλήση, ελέγξτε αν ο τρέχων συνδυασμός `model` / `mode` / `duration` υποστηρίζει τη λειτουργία που χρειάζεστε, διαφορετικά θα επιστραφούν σφάλματα όπως `model/mode/duration(...) is not supported with image_tail`.

| Μοντέλο                  | Λειτουργία             | `end_image_url`（πρώτο και τελευταίο καρέ） | `generate_audio`（ήχος） | `camera_control`（κίνηση κάμερας） | Παρατηρήσεις                                           |
| ------------------- | -------------- | -------------------- | -------------------- | -------------------- | -------------------------------------------- |
| `kling-v1`          | std / pro      | ✅ μόνο `duration=5`     | ❌                    | ✅ μόνο `duration=5`     | Το `extend` δεν υποστηρίζει `negative_prompt` και `cfg_scale` |
| `kling-v1-6`        | std            | ❌                    | ❌                    | ❌                    | Η δημιουργία βίντεο από πολλαπλές εικόνες και το `extend` είναι διαθέσιμα σε όλες τις λειτουργίες                         |
| `kling-v1-6`        | pro            | ✅                    | ❌                    | ❌                    |                                              |
| `kling-v2-master`   | —              | ❌                    | ❌                    | ❌                    | Μοναδική λειτουργία, μόνο `duration=5/10`                       |
| `kling-v2-1-master` | —              | ❌                    | ❌                    | ❌                    | Μοναδική λειτουργία, μόνο `duration=5/10`                       |
| `kling-v2-5-turbo`  | std            | ❌                    | ❌                    | ❌                    |                                              |
| `kling-v2-5-turbo`  | pro            | ✅                    | ❌                    | ❌                    |                                              |
| `kling-v2-6`        | std            | ❌                    | ❌                    | ❌                    |                                              |
| `kling-v2-6`        | pro            | ✅                    | ✅                    | ❌                    | Το μοναδικό μοντέλο εκτός v3 που υποστηρίζει ταυτόχρονα ήχο                             |
| `kling-v3`          | std / pro      | ✅                    | ✅                    | ✅                    | Εύρος `duration` 3–15 δευτερόλεπτα                         |
| `kling-v3`          | 4k             | ✅                    | ✅                    | ❌                    | Η λειτουργία 4K δεν είναι συμβατή με κίνηση κάμερας                                  |
| `kling-v3-omni`     | std / pro / 4k | ✅                    | ✅                    | ❌                    |                                              |
| `kling-o1`          | std / pro      | ✅                    | ❌                    | ❌                    | Υποστηρίζει μόνο `duration=5`                             |

Σημειώσεις:

- Το `mode=4k` υποστηρίζεται μόνο από τα `kling-v3` και `kling-v3-omni`· και είναι αμοιβαία αποκλειόμενο με το `camera_control` (κίνηση κάμερας).
- Το `end_image_url` μπορεί να χρησιμοποιηθεί μόνο μαζί με το `start_image_url` όταν `action=image2video`. Η αποστολή μόνο του `end_image_url` (χωρίς `start_image_url`) θα απορριφθεί.
- Τα `kling-v3` / `kling-v3-omni` δέχονται οποιοδήποτε ακέραιο `duration` από 3–15 δευτερόλεπτα· το `kling-o1` δέχεται μόνο 5· τα υπόλοιπα μοντέλα δέχονται μόνο 5 ή 10.
- Το `generate_audio` είναι `false` από προεπιλογή. Υποστηρίζεται μόνο από τα `kling-v3`, `kling-v3-omni` και `kling-v2-6` (λειτουργία pro).

## Λειτουργία επέκτασης βίντεο

Αν θέλετε να συνεχίσετε τη δημιουργία ενός ήδη δημιουργημένου βίντεο Kling, μπορείτε να ορίσετε την παράμετρο `action` σε `extend` και να εισαγάγετε το ID του βίντεο που πρέπει να συνεχίσει να δημιουργείται. Το ID του βίντεο λαμβάνεται σύμφωνα με τη βασική χρήση, όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Τότε μπορείτε να δείτε ότι το ID του βίντεο είναι:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

> Σημείωση: το `video_id` εδώ είναι το ID του βίντεο μετά τη δημιουργία. Αν δεν γνωρίζετε πώς να δημιουργήσετε βίντεο, μπορείτε να ανατρέξετε στην παραπάνω βασική χρήση για να δημιουργήσετε βίντεο.

Στη συνέχεια, πρέπει να συμπληρώσουμε την προτροπή που απαιτείται για την επέκταση στο επόμενο βήμα, ώστε να προσαρμόσουμε το παραγόμενο βίντεο. Μπορείτε να ορίσετε το ακόλουθο περιεχόμενο:

- `model`：Το μοντέλο για τη δημιουργία βίντεο, κυρίως τα μοντέλα `kling-v1` 、`kling-v1-5` και `kling-v1-6`.
- `mode`：Η λειτουργία για τη δημιουργία βίντεο, με διαθέσιμες τιμές την τυπική λειτουργία `std`, τη λειτουργία υψηλής ταχύτητας `pro` και την εγγενή λειτουργία 4K `4k` (υποστηρίζεται μόνο από τα `kling-v3` και `kling-v3-omni`, και δεν είναι συμβατή με τον έλεγχο κίνησης κάμερας).
- `duration`：Η διάρκεια βίντεο αυτής της εργασίας δημιουργίας βίντεο, η οποία περιλαμβάνει κυρίως 5s και 10s.
- `start_image_url`：Όταν επιλέγετε τη συμπεριφορά δημιουργίας βίντεο από εικόνα `image2video`, απαιτείται ο σύνδεσμος της εικόνας αναφοράς για το πρώτο καρέ που πρέπει να μεταφορτωθεί.
- `prompt`：Η προτροπή.

Ένα παράδειγμα συμπλήρωσης είναι το ακόλουθο:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" className="m-auto" /></p>

Αφού ολοκληρωθεί η συμπλήρωση, ο κώδικας δημιουργείται αυτόματα ως εξής:

<p><img src="https://cdn.acedata.cloud/52x4u5.png" width="500" className="m-auto" /></p>

Ο αντίστοιχος κώδικας Python:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Κάντε κλικ στην εκτέλεση και μπορείτε να διαπιστώσετε ότι θα λάβετε ένα αποτέλεσμα, ως εξής:

```json
{
  "success": true,
  "video_id": "bbc3b105-ac72-4de2-8390-0cb37dc7d41e",
  "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": "9.6",
  "state": "succeed",
  "task_id": "3ece87e6-3ee3-4f5e-bd70-5ae5eca89a23"
}
```
Όπως φαίνεται, το περιεχόμενο του αποτελέσματος είναι συνεπές με το παραπάνω, γεγονός που υλοποιεί επίσης τη λειτουργία επέκτασης βίντεο του βίντεο.

## Omni καθολική αναφορά (επεξεργασία βίντεο / βίντεο αναφοράς / αναφορά πολλαπλών εικόνων)

Τα `kling-o1` και `kling-v3-omni` είναι δύο ανεξάρτητα μοντέλα, και τα δύο υποστηρίζουν τη δυνατότητα «καθολικής αναφοράς». Με βάση τη δημιουργία βίντεο από κείμενο (`action=text2video`), μπορούν να μεταβιβαστούν επιπλέον εικόνες αναφοράς ή βίντεο αναφοράς, ώστε να επιτευχθούν **αναφορά πολλαπλών εικόνων, βίντεο αναφοράς και άμεση επεξεργασία υπαρχόντων βίντεο**.

**Βασική σύμβαση**: Τα υλικά αναφοράς πρέπει να αναφέρονται στο `prompt` με τη μορφή `&lt;&lt;<image_1>>>`, `&lt;&lt;<video_1>>>` (η αρίθμηση ξεκινά από το 1), αντιστοιχώντας στα υλικά στις αντίστοιχες θέσεις του `image_list` / `video_list`, ώστε το μοντέλο να εφαρμόσει αυτές τις αναφορές. Εάν μεταβιβαστούν μόνο υλικά χωρίς να αναφέρονται στο prompt, τα υλικά θα αγνοηθούν.

> Σημείωση ασφαλείας: Το τρέχον API δεν παρέχει το `element_list`. Τα ID του Kling Element Library δεν είναι απομονωμένα ανά μισθωτή· πριν παρέχεται API διαχείρισης στοιχείων με απομόνωση ανά μισθωτή, χρησιμοποιήστε το `image_list` για να μεταβιβάσετε εικόνες αναφοράς υποκειμένων.

Τα αιτήματα Omni δεν υποστηρίζουν `negative_prompt`, `cfg_scale` ή `camera_control`, ούτε μπορούν να χρησιμοποιήσουν `mode=4k`. Όταν περιλαμβάνεται βίντεο αναφοράς, το `generate_audio` πρέπει να είναι `false`.

### Βίντεο αναφοράς και επεξεργασία βίντεο (`video_list`)

Το `video_list` χρησιμοποιείται για τη μεταβίβαση βίντεο αναφοράς και είναι το συνηθέστερο σενάριο αυτής της δυνατότητας. Τα πεδία των στοιχείων του πίνακα είναι τα εξής:

- `video_url`: Σύνδεσμος βίντεο αναφοράς, δεν μπορεί να είναι κενός. Μέχρι 1 βίντεο MP4/MOV, μέγεθος αρχείου ≤200MB, ρυθμός καρέ 24–60fps. Το `kling-o1` απαιτεί διάρκεια 3–10 δευτερόλεπτα και πλάτος και ύψος από 700–2160px το καθένα· το `kling-v3-omni` απαιτεί διάρκεια 3–15.5 δευτερόλεπτα, πλάτος και ύψος από 700–4553px το καθένα, συνολικά pixel ≤8,294,400 και αναλογία διαστάσεων 0.4–2.
- `refer_type`: Τύπος αναφοράς, προαιρετικά `base` (προεπιλογή, **το βασικό βίντεο προς επεξεργασία**, δηλαδή «άμεση επεξεργασία του βίντεο», όπου μπορούν να προστεθούν/αφαιρεθούν ή να τροποποιηθούν στοιχεία, να αλλάξει η σύνθεση, το στυλ, τα χρώματα, ο καιρός κ.λπ.) ή `feature` (**αναφορά χαρακτηριστικών**, αναφορά του στυλ / της κίνησης κάμερας / συνέχιση λήψης του επόμενου πλάνου).
- `keep_original_sound`: Εάν θα διατηρηθεί ο ήχος του αρχικού βίντεο, προαιρετικά `yes` (διατήρηση) ή `no` (αφαίρεση).

> Σημείωση: Όταν υπάρχει βίντεο αναφοράς, το `generate_audio` πρέπει να είναι `false`. Για βίντεο με `refer_type=base` δεν μπορούν να καθοριστούν επιπλέον αρχικό καρέ / τελικό καρέ.

Παράδειγμα CURL για την επεξεργασία υπάρχοντος βίντεο (μετατροπή του βίντεο σε στυλ anime) είναι το εξής:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-o1",
  "mode": "std",
  "duration": 5,
  "prompt": "把 <<<video_1>>> 改成电影级动漫风格，保留原有的运动和构图",
  "video_list": [
    {
      "video_url": "https://cdn.acedata.cloud/your-reference-video.mp4",
      "refer_type": "base",
      "keep_original_sound": "no"
    }
  ]
}'
```

### Αναφορά πολλαπλών εικόνων (`image_list`)

Το `image_list` χρησιμοποιείται για τη μεταβίβαση εικόνων αναφοράς (στοιχεία / σκηνές / στυλ κ.λπ.). Τα πεδία των στοιχείων του πίνακα είναι τα εξής:

- `image_url`: Σύνδεσμος εικόνας αναφοράς, δεν μπορεί να είναι κενός. Απαιτήσεις: μορφή .jpg/.jpeg/.png· μέγεθος αρχείου ≤10MB· μικρότερη πλευρά ≥300px· αναλογία διαστάσεων 1:2.5 ~ 2.5:1.
- `type`: Προαιρετικό. Εάν δεν μεταβιβαστεί, χρησιμοποιείται ως καθαρή εικόνα αναφοράς· όταν μεταβιβαστεί `first_frame` / `end_frame`, χρησιμοποιείται αντίστοιχα ως αρχικό καρέ / τελικό καρέ (ισοδύναμο με `start_image_url` / `end_image_url`).

Κατά τη χρήση, πρέπει να γίνεται αναφορά στο `prompt` με `&lt;&lt;<image_1>>>`, `&lt;&lt;<image_2>>>`. Περιορισμοί πλήθους: όταν δεν υπάρχει βίντεο αναφοράς, οι εικόνες αναφοράς ≤ 7· όταν υπάρχει βίντεο αναφοράς, οι εικόνες αναφοράς ≤ 4. Όταν μεταβιβάζονται μόνο αρχικό / τελικό καρέ, μπορούν επίσης να χρησιμοποιηθούν απευθείας τα `start_image_url` / `end_image_url`, αλλά το τελικό καρέ πρέπει να χρησιμοποιείται μαζί με το αρχικό καρέ.

> Σημείωση: Εάν μεταβιβαστούν ταυτόχρονα `start_image_url` / `end_image_url` και `image_list`, τα αρχικά / τελικά καρέ θα τοποθετηθούν πριν από το `image_list`, κάτι που ενδέχεται να επηρεάσει την αντιστοίχιση αρίθμησης του `&lt;&lt;<image_N>>>`. Συνιστάται να επιλέξετε ένα από τα δύο: όταν χρειάζεστε αρχικό / τελικό καρέ, καθορίστε απευθείας το `type` στο `image_list` και μην το συνδυάζετε με `start_image_url` / `end_image_url`.

Παράδειγμα CURL για δημιουργία βίντεο με αναφορά πολλαπλών εικόνων:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-o1",
  "mode": "std",
  "duration": 5,
  "prompt": "让 <<<image_1>>> 里的人物站在 <<<image_2>>> 的场景中，电影感光线",
  "image_list": [
    { "image_url": "https://cdn.acedata.cloud/subject.png" },
    { "image_url": "https://cdn.acedata.cloud/scene.png" }
  ]
}'
```

## Ασύγχρονη επανάκληση

Επειδή ο χρόνος δημιουργίας του Kling Videos Generation API είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, εάν το API δεν αποκρίνεται για μεγάλο χρονικό διάστημα, το αίτημα HTTP θα διατηρεί συνεχώς τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος, γι' αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη επανάκληση.

Η συνολική διαδικασία είναι η εξής: όταν ο πελάτης ξεκινά ένα αίτημα, καθορίζει επιπλέον ένα πεδίο `callback_url`. Αφού ο πελάτης ξεκινήσει το αίτημα API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα, που περιλαμβάνει πληροφορίες για ένα πεδίο `task_id`, το οποίο αντιπροσωπεύει το ID της τρέχουσας εργασίας. Αφού ολοκληρωθεί η εργασία, το αποτέλεσμα του παραγόμενου βίντεο θα σταλεί μέσω POST JSON στο `callback_url` που καθόρισε ο πελάτης, συμπεριλαμβάνοντας επίσης το πεδίο `task_id`, ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Παρακάτω θα κατανοήσουμε μέσω ενός παραδείγματος πώς ακριβώς να το χειριστούμε.

Αρχικά, η επανάκληση Webhook είναι μια υπηρεσία που μπορεί να δέχεται αιτήματα HTTP και ο προγραμματιστής πρέπει να την αντικαταστήσει με το URL του δικού του διακομιστή HTTP. Εδώ, για διευκόλυνση της επίδειξης, χρησιμοποιείται ένας δημόσιος ιστότοπος παραδείγματος Webhook, το https://webhook.site/· ανοίγοντας αυτόν τον ιστότοπο μπορείτε να λάβετε ένα URL Webhook, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/tbcnai.png)

Αντιγράψτε αυτό το URL και μπορεί να χρησιμοποιηθεί ως Webhook· το παράδειγμα εδώ είναι το `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`.

Στη συνέχεια, μπορούμε να ορίσουμε το πεδίο `callback_url` στο παραπάνω URL Webhook και ταυτόχρονα να συμπληρώσουμε τις αντίστοιχες παραμέτρους· το συγκεκριμένο περιεχόμενο φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" className="m-auto" /></p>

Κάντε κλικ στην εκτέλεση και θα διαπιστώσετε ότι λαμβάνετε αμέσως ένα αποτέλεσμα, ως εξής:

```
{
  "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```
Περιμένετε λίγο, μπορούμε να παρατηρήσουμε το αποτέλεσμα του παραγόμενου βίντεο στο `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/zv5u2q.png)

Το περιεχόμενο είναι το ακόλουθο:

```json
{
    "success": true,
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
    "duration": "5.1",
    "state": "succeed",
    "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"

```

Μπορούμε να δούμε ότι υπάρχει ένα πεδίο `task_id` στο αποτέλεσμα, τα υπόλοιπα πεδία είναι παρόμοια με τα παραπάνω και η συσχέτιση της εργασίας μπορεί να υλοποιηθεί μέσω αυτού του πεδίου.

## Χειρισμός σφαλμάτων

Κατά την κλήση του API, εάν παρουσιαστεί σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`：Μη έγκυρο αίτημα, πιθανώς λόγω ελλειπόντων ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Μη έγκυρο αίτημα, πιθανώς λόγω ελλειπόντων ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλείπον διακριτικό εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο συχνότητας.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα απόκρισης σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Συμπέρασμα

Μέσω αυτού του εγγράφου, έχετε ήδη κατανοήσει πώς να χρησιμοποιείτε το Kling Videos Generation API για να δημιουργείτε βίντεο εισάγοντας προτροπές και εικόνες αναφοράς πρώτου καρέ. Ελπίζουμε ότι αυτό το έγγραφο μπορεί να σας βοηθήσει να ενσωματώσετε και να χρησιμοποιήσετε καλύτερα αυτό το API. Εάν έχετε οποιεσδήποτε ερωτήσεις, επικοινωνήστε μαζί μας ανά πάσα στιγμή με την ομάδα τεχνικής υποστήριξής μας.

### Kling 3.0 Turbo

Το `model="kling-v3-turbo"` υποστηρίζει δημιουργία βίντεο από κείμενο και δημιουργία βίντεο από εικόνα πρώτου καρέ, με διάρκεια ακέραιου αριθμού δευτερολέπτων από 3–15. Το `mode="std"` εξάγει 720p, ενώ το `mode="pro"` εξάγει 1080p. Αυτό το μοντέλο διαθέτει ενσωματωμένο εγγενή ήχο και δεν παρέχει διακόπτη απενεργοποίησης· παραλείψτε το `generate_audio` ή ορίστε το σε `true`. Αυτό το μοντέλο δεν υποστηρίζει τελευταίο καρέ, αντικείμενα κίνησης κάμερας, ανεξάρτητες αρνητικές προτροπές ή `cfg_scale`. Περιγράψτε απευθείας στο `prompt` το περιεχόμενο που χρειάζεται ή πρέπει να αποφευχθεί.

### Βίντεο πολλαπλών λήψεων

Τα `kling-v3` και `kling-v3-omni` υποστηρίζουν `multi_shot=true`. Το `shot_type="intelligence"` δημιουργεί αυτόματα λήψεις βάσει του `prompt`· το `shot_type="customize"` παρέχει 1–6 λήψεις μέσω του `multi_prompt`, όπου κάθε στοιχείο περιλαμβάνει ένα `index` που αυξάνεται συνεχόμενα ξεκινώντας από το 1, ένα `prompt` έως 512 χαρακτήρων και ένα ακέραιο `duration` τουλάχιστον 1 δευτερολέπτου. Το άθροισμα της διάρκειας όλων των λήψεων πρέπει να ισούται με το συνολικό `duration`. Οι προσαρμοσμένες λήψεις δεν χρησιμοποιούν το καθολικό `prompt`. Οι πολλαπλές λήψεις χρεώνονται σύμφωνα με το επιλεγμένο μοντέλο, την ποιότητα εικόνας, τη διαμόρφωση ήχου και τη συνολική διάρκεια.
