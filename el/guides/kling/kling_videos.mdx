Αυτό το άρθρο θα παρουσιάσει μια μέθοδο ενσωμάτωσης του Kling Videos Generation API, η οποία μπορεί να δημιουργήσει επίσημα βίντεο του Kling μέσω της εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Kling Videos Generation API, αποκτήστε πρώτα το API Token σας από την [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση προσφέρει δωρεάν μονάδες χρήσης, για δωρεάν δοκιμή· όταν οι μονάδες δεν επαρκούν, μπορείτε να φορτίσετε το γενικό υπόλοιπο από την [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Kling Videos Generation API →](https://platform.acedata.cloud/documents/kling-videos)

## Βασική χρήση

Αρχικά, ας κατανοήσουμε τον βασικό τρόπο χρήσης: δηλαδή, εισάγοντας τη λέξη-κλειδί `prompt`, την ενέργεια δημιουργίας `action`, την εικόνα αναφοράς πρώτου καρέ `start_image_url` και το μοντέλο `model`, μπορείτε να λάβετε το επεξεργασμένο αποτέλεσμα. Πρώτα χρειάζεται να περάσετε απλά ένα πεδίο `action`, του οποίου η τιμή είναι `text2video`. Αυτό περιλαμβάνει κυρίως τρεις ενέργειες: δημιουργία βίντεο από κείμενο (`text2video`), δημιουργία βίντεο από εικόνα (`image2video`), δημιουργία επέκτασης βίντεο (`extend`). Έπειτα, χρειάζεται επίσης να εισαγάγουμε το μοντέλο `model`. Προς το παρόν, υπάρχουν κυρίως τα μοντέλα `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-o1`, και το συγκεκριμένο περιεχόμενο είναι ως εξής:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ ρυθμίζουμε τα Request Headers, τα οποία περιλαμβάνουν:

- `accept`: Τη μορφή του αποτελέσματος απόκρισης που θέλετε να λάβετε. Εδώ συμπληρώνεται ως `application/json`, δηλαδή μορφή JSON.
- `authorization`: Το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, ρυθμίζουμε το Request Body, το οποίο περιλαμβάνει:

- `model`: Το μοντέλο για τη δημιουργία βίντεο, κυρίως τα μοντέλα `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-o1`.
- `mode`: Η λειτουργία δημιουργίας βίντεο, με προαιρετικές τιμές την τυπική λειτουργία `std`, τη λειτουργία υψηλής ταχύτητας `pro` και τη λειτουργία εγγενούς 4K `4k`. Μεταξύ αυτών, το `4k` υποστηρίζεται μόνο από τα `kling-v3` και `kling-v3-omni`, και δεν είναι συμβατό με το `camera_control` (έλεγχος κίνησης κάμερας).
- `action`: Η ενέργεια της τρέχουσας εργασίας δημιουργίας βίντεο, η οποία περιλαμβάνει κυρίως τρεις ενέργειες: δημιουργία βίντεο από κείμενο (`text2video`), δημιουργία βίντεο από εικόνα (`image2video`), δημιουργία επέκτασης βίντεο (`extend`).
- `start_image_url`: Ο σύνδεσμος της εικόνας αναφοράς πρώτου καρέ που πρέπει να μεταφορτωθεί όταν επιλέγεται η ενέργεια δημιουργίας βίντεο από εικόνα `image2video`.
- `end_image_url`: Προαιρετικό κατά τη δημιουργία βίντεο από εικόνα, καθορίζει το τελευταίο καρέ.
- `duration`: Η διάρκεια του βίντεο, σε δευτερόλεπτα. Τα `kling-v3` και `kling-v3-omni` υποστηρίζουν ακέραιες διάρκειες 3-15 δευτερολέπτων· το `kling-o1` υποστηρίζει μόνο 5 δευτερόλεπτα· τα άλλα μοντέλα υποστηρίζουν 5 ή 10 δευτερόλεπτα.
- `generate_audio`: Αν θα δημιουργηθεί συγχρόνως ήχος, προαιρετικό, δυαδική τιμή. Υποστηρίζεται από τα `kling-v3`, `kling-v3-omni` και `kling-v2-6` (μόνο λειτουργία pro). Η προεπιλογή είναι `false`.
- `aspect_ratio`: Η αναλογία πλάτους-ύψους του βίντεο, προαιρετική, υποστηρίζει `16:9`, `9:16`, `1:1`, με προεπιλογή `16:9`.
- `cfg_scale`: Η ένταση συσχέτισης, εύρος [0,1], όσο μεγαλύτερη είναι τόσο περισσότερο αντιστοιχεί στη λέξη-κλειδί.
- `camera_control`: Προαιρετικό, παράμετροι αντικειμένου που ελέγχουν την κίνηση της κάμερας, υποστηρίζοντας προκαθορισμένες ρυθμίσεις type/simple και διαμορφώσεις όπως horizontal, vertical, pan, tilt, roll, zoom.
- `negative_prompt`: Προαιρετικό, αρνητική λέξη-κλειδί που δεν επιθυμείτε να εμφανιστεί, έως 200 χαρακτήρες.
- `image_list`: Λίστα εικόνων αναφοράς Omni, κατάλληλη για τα μοντέλα `kling-o1` και `kling-v3-omni`, για χρήση δείτε παρακάτω «Πανίσχυρη αναφορά Omni».
- `video_list`: Λίστα βίντεο αναφοράς Omni (υποστηρίζει επεξεργασία βίντεο), κατάλληλη για τα μοντέλα `kling-o1` και `kling-v3-omni`, για χρήση δείτε παρακάτω «Πανίσχυρη αναφορά Omni».
- `prompt`: Λέξη-κλειδί.
- `callback_url`: Το URL που χρειάζεται να λάβει το αποτέλεσμα επανάκλησης.
- `async`: Προαιρετικό, όταν οριστεί σε `true`, η διεπαφή επιστρέφει αμέσως `task_id`, χωρίς να απαιτείται η παροχή `callback_url`, και στη συνέχεια το αποτέλεσμα λαμβάνεται με περιοδικό έλεγχο μέσω της αντίστοιχης διεπαφής αναζήτησης εργασιών.

Μετά την επιλογή, μπορείτε να διαπιστώσετε ότι δημιουργείται επίσης ο αντίστοιχος κώδικας στη δεξιά πλευρά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/3yjql0.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για δοκιμή. Όπως φαίνεται στην παραπάνω εικόνα, εδώ λαμβάνουμε το ακόλουθο αποτέλεσμα:

```json
{
  "success": true,
  "video_id": "900798310464749610",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "duration": "5.041",
  "state": "succeed",
  "task_id": "6c68c267-065b-4423-b66b-a0e4c59ee0d5"
}
```

Το αποτέλεσμα επιστροφής περιλαμβάνει πολλά πεδία, τα οποία παρουσιάζονται ως εξής:

- `success`, η κατάσταση της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `task_id`, το ID της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `video_id`, το ID βίντεο της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `video_url`, ο σύνδεσμος βίντεο της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `duration`, η διάρκεια του συνδέσμου βίντεο της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `state`, η κατάσταση της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.

Μπορείτε να δείτε ότι λάβαμε ικανοποιητικές πληροφορίες βίντεο. Χρειάζεται μόνο να αποκτήσουμε το δημιουργημένο βίντεο Kling σύμφωνα με τη διεύθυνση συνδέσμου βίντεο του `data` στο αποτέλεσμα.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα ενσωμάτωσης, μπορείτε να τον αντιγράψετε απευθείας, για παράδειγμα, ο κώδικας CURL είναι ο εξής:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v3",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## Πίνακας δυνατοτήτων μοντέλων

Τα διαφορετικά μοντέλα παρουσιάζουν μεγάλες διαφορές στην υποστήριξη παραμέτρων. Ο παρακάτω πίνακας οργανώθηκε από την [επίσημη τεκμηρίωση video models του Kling](https://app.klingai.com/global/dev/document-api/apiReference/model/videoModels). Πριν από την κλήση, ελέγξτε πρώτα αν ο τρέχων συνδυασμός `model` / `mode` / `duration` υποστηρίζει τη λειτουργία που χρειάζεστε, διαφορετικά θα επιστραφούν σφάλματα όπως `model/mode/duration(...) is not supported with image_tail`.
| Μοντέλο                  | Λειτουργία             | `end_image_url`（πρώτο και τελευταίο καρέ） | `generate_audio`（συνοδευτικός ήχος） | `camera_control`（έλεγχος κάμερας） | Σημειώσεις                                           |
| ------------------- | -------------- | -------------------- | -------------------- | -------------------- | -------------------------------------------- |
| `kling-v1`          | std / pro      | ✅ μόνο `duration=5`     | ❌                    | ✅ μόνο `duration=5`     | Το `extend` δεν υποστηρίζει `negative_prompt` και `cfg_scale` |
| `kling-v1-6`        | std            | ❌                    | ❌                    | ❌                    | Βίντεο από πολλαπλές εικόνες, το `extend` είναι διαθέσιμο σε όλες τις λειτουργίες                         |
| `kling-v1-6`        | pro            | ✅                    | ❌                    | ❌                    |                                              |
| `kling-v2-master`   | —              | ❌                    | ❌                    | ❌                    | Ενιαία λειτουργία, μόνο `duration=5/10`                       |
| `kling-v2-1-master` | —              | ❌                    | ❌                    | ❌                    | Ενιαία λειτουργία, μόνο `duration=5/10`                       |
| `kling-v2-5-turbo`  | std            | ❌                    | ❌                    | ❌                    |                                              |
| `kling-v2-5-turbo`  | pro            | ✅                    | ❌                    | ❌                    |                                              |
| `kling-v2-6`        | std            | ❌                    | ❌                    | ❌                    |                                              |
| `kling-v2-6`        | pro            | ✅                    | ✅                    | ❌                    | Το μοναδικό μοντέλο εκτός v3 που υποστηρίζει ταυτόχρονα συνοδευτικό ήχο                             |
| `kling-v3`          | std / pro      | ✅                    | ✅                    | ✅                    | Εύρος `duration` 3–15 δευτερόλεπτα                         |
| `kling-v3`          | 4k             | ✅                    | ✅                    | ❌                    | Η λειτουργία 4K δεν είναι συμβατή με τον έλεγχο κάμερας                                  |
| `kling-v3-omni`     | std / pro / 4k | ✅                    | ✅                    | ❌                    |                                              |
| `kling-o1`          | std / pro      | ✅                    | ❌                    | ❌                    | Υποστηρίζει μόνο `duration=5`                             |

Σημειώσεις:

- Το `mode=4k` υποστηρίζεται μόνο από τα `kling-v3` και `kling-v3-omni`· και είναι αμοιβαία αποκλειόμενο με το `camera_control`（έλεγχος κάμερας）.
- Το `end_image_url` μπορεί να χρησιμοποιηθεί μόνο μαζί με το `start_image_url` όταν `action=image2video`. Η αποστολή μόνο του `end_image_url`（χωρίς `start_image_url`）θα απορριφθεί.
- Τα `kling-v3` / `kling-v3-omni` δέχονται οποιοδήποτε ακέραιο `duration` από 3–15 δευτερόλεπτα· το `kling-o1` δέχεται μόνο 5· τα υπόλοιπα μοντέλα δέχονται μόνο 5 ή 10.
- Το `generate_audio` είναι `false` από προεπιλογή. Υποστηρίζεται μόνο από τα `kling-v3`、`kling-v3-omni` και `kling-v2-6`（λειτουργία pro）.

## Λειτουργία επέκτασης βίντεο

Αν θέλετε να συνεχίσετε τη δημιουργία ενός ήδη δημιουργημένου βίντεο Kling, μπορείτε να ορίσετε την παράμετρο `action` σε `extend` και να εισαγάγετε το ID του βίντεο που χρειάζεται να συνεχιστεί. Το ID του βίντεο λαμβάνεται σύμφωνα με τη βασική χρήση, όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Σε αυτό το σημείο μπορείτε να δείτε ότι το ID του βίντεο είναι:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

> Σημειώστε ότι το `video_id` στο βίντεο εδώ είναι το ID του βίντεο μετά τη δημιουργία. Αν δεν γνωρίζετε πώς να δημιουργήσετε βίντεο, μπορείτε να ανατρέξετε στη βασική χρήση παραπάνω για να δημιουργήσετε βίντεο.

Στη συνέχεια, πρέπει να συμπληρώσουμε το prompt που χρειάζεται να επεκταθεί στο επόμενο βήμα για να προσαρμόσουμε το δημιουργημένο βίντεο, και μπορούμε να καθορίσουμε το ακόλουθο περιεχόμενο:

- `model`：Το μοντέλο για τη δημιουργία βίντεο, κυρίως τα μοντέλα `kling-v1`、`kling-v1-5` και `kling-v1-6`.
- `mode`：Η λειτουργία για τη δημιουργία βίντεο, με διαθέσιμες τιμές την τυπική λειτουργία `std`、τη γρήγορη λειτουργία `pro` και την εγγενή λειτουργία 4K `4k`（υποστηρίζεται μόνο από τα `kling-v3` και `kling-v3-omni`, δεν είναι συμβατή με τον έλεγχο κίνησης κάμερας）.
- `duration`：Η διάρκεια βίντεο αυτής της εργασίας δημιουργίας βίντεο, που περιλαμβάνει κυρίως 5s και 10s.
- `start_image_url`：Όταν επιλέγεται η ενέργεια δημιουργίας βίντεο από εικόνα `image2video`, είναι απαραίτητος ο σύνδεσμος της εικόνας αναφοράς για το πρώτο καρέ που πρέπει να μεταφορτωθεί.
- `prompt`：Το prompt.

Το παράδειγμα συμπλήρωσης είναι το ακόλουθο:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" className="m-auto" /></p>

Αφού ολοκληρωθεί η συμπλήρωση, ο κώδικας δημιουργείται αυτόματα ως εξής:

<p><img src="https://cdn.acedata.cloud/52x4u5.png" width="500" className="m-auto" /></p>

Ο αντίστοιχος κώδικας Python:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Κάντε κλικ στην εκτέλεση και μπορείτε να διαπιστώσετε ότι θα λάβετε ένα αποτέλεσμα, ως εξής:

```json
{
  "success": true,
  "video_id": "bbc3b105-ac72-4de2-8390-0cb37dc7d41e",
  "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": "9.6",
  "state": "succeed",
  "task_id": "3ece87e6-3ee3-4f5e-bd70-5ae5eca89a23"
}
```

Μπορεί να φανεί ότι το περιεχόμενο του αποτελέσματος είναι συνεπές με το παραπάνω, και έτσι υλοποιείται η λειτουργία επέκτασης βίντεο.

## Omni καθολική αναφορά（επεξεργασία βίντεο / βίντεο αναφοράς / αναφορά πολλαπλών εικόνων）

Τα `kling-o1` και `kling-v3-omni` είναι δύο ανεξάρτητα μοντέλα, και αμφότερα υποστηρίζουν τη δυνατότητα «καθολικής αναφοράς». Με βάση τη δημιουργία βίντεο από κείμενο（`action=text2video`）, μπορούν επιπλέον να εισαχθούν εικόνες αναφοράς ή βίντεο αναφοράς, για την υλοποίηση **αναφοράς πολλαπλών εικόνων, βίντεο αναφοράς και άμεσης επεξεργασίας υπαρχόντων βίντεο**.

**Βασική σύμβαση**：Το υλικό αναφοράς πρέπει να αναφέρεται στο `prompt` με τη μορφή `&lt;&lt;<image_1>>>`、`&lt;&lt;<video_1>>>`（η αρίθμηση ξεκινά από το 1）στα στοιχεία της αντίστοιχης θέσης στα `image_list` / `video_list`, ώστε το μοντέλο να εφαρμόσει αυτές τις αναφορές. Αν μεταδοθεί μόνο υλικό χωρίς να αναφέρεται στο prompt, το υλικό θα αγνοηθεί.

> Επεξήγηση ασφαλείας：Το τρέχον API δεν ανοίγει το `element_list`. Τα ID της Kling Element Library δεν είναι απομονωμένα ανά μισθωτή· πριν παρέχεται το Element Management API με απομόνωση ανά μισθωτή, χρησιμοποιήστε το `image_list` για να μεταδώσετε εικόνες αναφοράς του θέματος.

Το αίτημα Omni δεν υποστηρίζει `negative_prompt`、`cfg_scale` ή `camera_control`, και επίσης δεν μπορεί να χρησιμοποιήσει `mode=4k`. Όταν περιλαμβάνεται βίντεο αναφοράς, το `generate_audio` πρέπει να είναι `false`.

### Βίντεο αναφοράς και επεξεργασία βίντεο（`video_list`）
Το `video_list` χρησιμοποιείται για την εισαγωγή βίντεο αναφοράς και είναι το συνηθέστερα χρησιμοποιούμενο σενάριο αυτής της δυνατότητας. Τα πεδία των στοιχείων του πίνακα είναι τα εξής:

- `video_url`: Σύνδεσμος βίντεο αναφοράς, δεν μπορεί να είναι κενός. Έως 1 βίντεο MP4/MOV, μέγεθος αρχείου ≤200MB, ρυθμός καρέ 24–60fps. Το `kling-o1` απαιτεί διάρκεια 3–10 δευτερόλεπτα και πλάτος και ύψος από 700–2160px το καθένα· το `kling-v3-omni` απαιτεί διάρκεια 3–15.5 δευτερόλεπτα, πλάτος και ύψος από 700–4553px το καθένα, συνολικά pixel ≤8,294,400 και αναλογία διαστάσεων 0.4–2.
- `refer_type`: Τύπος αναφοράς, προαιρετικά `base` (προεπιλογή, **βασικό βίντεο προς επεξεργασία**, δηλαδή «άμεση επεξεργασία του βίντεο», όπου μπορούν να προστεθούν/αφαιρεθούν ή να τροποποιηθούν στοιχεία, να αλλάξει η σύνθεση, το στυλ, το χρώμα, ο καιρός κ.λπ.) ή `feature` (**αναφορά χαρακτηριστικών**, αναφορά στο στυλ / στην κίνηση της κάμερας / στη συνέχιση λήψης του επόμενου πλάνου).
- `keep_original_sound`: Αν θα διατηρηθεί ο ήχος του αρχικού βίντεο, προαιρετικά `yes` (διατήρηση) ή `no` (αφαίρεση).

> Σημείωση: Όταν υπάρχει βίντεο αναφοράς, το `generate_audio` πρέπει να είναι `false`. Για βίντεο με `refer_type=base` δεν μπορεί να οριστεί ξανά αρχικό καρέ / τελικό καρέ.

Παρακάτω είναι ένα παράδειγμα CURL για την επεξεργασία υπάρχοντος βίντεο (μετατροπή του βίντεο σε στυλ anime):

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-o1",
  "mode": "std",
  "duration": 5,
  "prompt": "把 <<<video_1>>> 改成电影级动漫风格，保留原有的运动和构图",
  "video_list": [
    {
      "video_url": "https://cdn.acedata.cloud/your-reference-video.mp4",
      "refer_type": "base",
      "keep_original_sound": "no"
    }
  ]
}'
```

### Αναφορά πολλαπλών εικόνων (`image_list`)

Το `image_list` χρησιμοποιείται για την εισαγωγή εικόνων αναφοράς (στοιχεία / σκηνές / στυλ κ.λπ.). Τα πεδία των στοιχείων του πίνακα είναι τα εξής:

- `image_url`: Σύνδεσμος εικόνας αναφοράς, δεν μπορεί να είναι κενός. Απαιτήσεις: μορφή .jpg/.jpeg/.png· μέγεθος αρχείου ≤10MB· μικρότερη πλευρά ≥300px· αναλογία διαστάσεων 1:2.5 ~ 2.5:1.
- `type`: Προαιρετικό. Όταν δεν παρέχεται, χρησιμοποιείται ως καθαρή εικόνα αναφοράς· όταν παρέχεται `first_frame` / `end_frame`, χρησιμοποιείται αντίστοιχα ως αρχικό καρέ / τελικό καρέ (ισοδύναμο με `start_image_url` / `end_image_url`).

Κατά τη χρήση, πρέπει να γίνεται αναφορά στο `prompt` με `&lt;&lt;<image_1>>>`, `&lt;&lt;<image_2>>>`. Περιορισμός ποσότητας: όταν δεν υπάρχει βίντεο αναφοράς, οι εικόνες αναφοράς ≤ 7· όταν υπάρχει βίντεο αναφοράς, οι εικόνες αναφοράς ≤ 4. Όταν παρέχονται μόνο αρχικό / τελικό καρέ, μπορούν επίσης να χρησιμοποιηθούν απευθείας τα `start_image_url` / `end_image_url`, αλλά το τελικό καρέ πρέπει να χρησιμοποιείται μαζί με το αρχικό καρέ.

> Σημείωση: Εάν παρέχονται ταυτόχρονα `start_image_url` / `end_image_url` και `image_list`, τα αρχικά / τελικά καρέ θα τοποθετηθούν πριν από το `image_list`, κάτι που μπορεί να επηρεάσει την αντιστοίχιση των αριθμών `&lt;&lt;<image_N>>>`. Συνιστάται να επιλέξετε ένα από τα δύο: όταν χρειάζεστε αρχικό / τελικό καρέ, ορίστε απευθείας το `type` στο `image_list` και μην το αναμειγνύετε με `start_image_url` / `end_image_url`.

Παράδειγμα CURL για δημιουργία βίντεο με αναφορά πολλαπλών εικόνων:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-o1",
  "mode": "std",
  "duration": 5,
  "prompt": "让 <<<image_1>>> 里的人物站在 <<<image_2>>> 的场景中，电影感光线",
  "image_list": [
    { "image_url": "https://cdn.acedata.cloud/subject.png" },
    { "image_url": "https://cdn.acedata.cloud/scene.png" }
  ]
}'
```

## Ασύγχρονη επανάκληση

Επειδή ο χρόνος δημιουργίας του Kling Videos Generation API είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, εάν το API δεν ανταποκρίνεται για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί συνεχώς τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος. Επομένως, αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη επανάκληση.

Η συνολική διαδικασία είναι η εξής: όταν ο πελάτης ξεκινά ένα αίτημα, ορίζει επιπλέον ένα πεδίο `callback_url`. Αφού ο πελάτης ξεκινήσει το αίτημα API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα, το οποίο περιλαμβάνει πληροφορία πεδίου `task_id` που αντιπροσωπεύει το ID της τρέχουσας εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα του παραγόμενου βίντεο θα σταλεί με τη μορφή POST JSON στο `callback_url` που έχει ορίσει ο πελάτης, το οποίο περιλαμβάνει επίσης το πεδίο `task_id`, ώστε τα αποτελέσματα της εργασίας να μπορούν να συσχετιστούν μέσω του ID.

Παρακάτω θα κατανοήσουμε τη συγκεκριμένη διαδικασία μέσω ενός παραδείγματος.

Αρχικά, η επανάκληση Webhook είναι μια υπηρεσία που μπορεί να λάβει αιτήματα HTTP, και ο προγραμματιστής πρέπει να την αντικαταστήσει με το URL του HTTP διακομιστή που έχει δημιουργήσει ο ίδιος. Εδώ, για ευκολία επίδειξης, χρησιμοποιείται ένας δημόσιος ιστότοπος παραδείγματος Webhook, https://webhook.site/. Ανοίγοντας αυτόν τον ιστότοπο, μπορείτε να λάβετε ένα URL Webhook, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/tbcnai.png)

Αντιγράψτε αυτό το URL για να το χρησιμοποιήσετε ως Webhook. Το παράδειγμα εδώ είναι `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`.

Στη συνέχεια, μπορούμε να ορίσουμε το πεδίο `callback_url` στο παραπάνω URL Webhook και ταυτόχρονα να συμπληρώσουμε τις αντίστοιχες παραμέτρους. Το συγκεκριμένο περιεχόμενο φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" className="m-auto" /></p>

Κάντε κλικ στην εκτέλεση και θα διαπιστώσετε ότι λαμβάνετε αμέσως ένα αποτέλεσμα, ως εξής:

```
{
  "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Περιμένετε λίγο και μπορούμε να παρατηρήσουμε το αποτέλεσμα του παραγόμενου βίντεο στο `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/zv5u2q.png)

Το περιεχόμενο είναι το εξής:

```json
{
    "success": true,
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
    "duration": "5.1",
    "state": "succeed",
    "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
```

Μπορείτε να δείτε ότι υπάρχει ένα πεδίο `task_id` στο αποτέλεσμα. Τα υπόλοιπα πεδία είναι παρόμοια με τα παραπάνω, και η συσχέτιση εργασιών μπορεί να υλοποιηθεί μέσω αυτού του πεδίου.

## Χειρισμός σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και μήνυμα. Για παράδειγμα:

- `400 token_mismatched`: Μη έγκυρο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Μη έγκυρο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
### Παράδειγμα απόκρισης σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Συμπέρασμα

Μέσω αυτού του εγγράφου, έχετε ήδη μάθει πώς να χρησιμοποιείτε το Kling Videos Generation API για να δημιουργείτε βίντεο μέσω εισαγωγής προτροπών καθώς και εικόνων αναφοράς πρώτου καρέ. Ελπίζουμε αυτό το έγγραφο να σας βοηθήσει να ενσωματώσετε και να χρησιμοποιήσετε καλύτερα αυτό το API. Εάν έχετε οποιεσδήποτε ερωτήσεις, παρακαλούμε επικοινωνήστε ανά πάσα στιγμή με την ομάδα τεχνικής υποστήριξής μας.

### Kling 3.0 Turbo

Το `model="kling-v3-turbo"` υποστηρίζει δημιουργία βίντεο από κείμενο και δημιουργία βίντεο από εικόνα πρώτου καρέ, με διάρκεια ακέραιου αριθμού δευτερολέπτων από 3–15 δευτερόλεπτα. Το `mode="std"` εξάγει 720p, ενώ το `mode="pro"` εξάγει 1080p. Αυτό το μοντέλο διαθέτει εγγενή ήχο και δεν παρέχει διακόπτη απενεργοποίησης· παραλείψτε το `generate_audio` ή ορίστε το σε `true`. Αυτό το μοντέλο δεν υποστηρίζει τελικό καρέ, αντικείμενα κίνησης κάμερας, ανεξάρτητες αρνητικές προτροπές ή `cfg_scale`. Παρακαλούμε περιγράψτε απευθείας στο `prompt` το περιεχόμενο που χρειάζεται ή που θέλετε να αποφύγετε να εμφανιστεί.

### Βίντεο πολλαπλών λήψεων

Τα `kling-v3` και `kling-v3-omni` υποστηρίζουν `multi_shot=true`. Το `shot_type="intelligence"` δημιουργεί αυτόματα λήψεις βάσει του `prompt`· το `shot_type="customize"` παρέχει 1–6 λήψεις μέσω του `multi_prompt`, όπου κάθε στοιχείο περιλαμβάνει ένα `index` που αυξάνεται συνεχόμενα ξεκινώντας από το 1, ένα `prompt` έως 512 χαρακτήρων και ένα ακέραιο `duration` τουλάχιστον 1 δευτερολέπτου. Το άθροισμα των διάρκειων όλων των λήψεων πρέπει να ισούται με το συνολικό `duration`. Οι προσαρμοσμένες λήψεις δεν χρησιμοποιούν το καθολικό `prompt`. Οι πολλαπλές λήψεις χρεώνονται βάσει του επιλεγμένου μοντέλου, της ποιότητας εικόνας, της διαμόρφωσης ήχου και της συνολικής διάρκειας.
