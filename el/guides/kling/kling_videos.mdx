Αυτό το έγγραφο παρουσιάζει τις οδηγίες ενσωμάτωσης του Kling Videos Generation API, το οποίο επιτρέπει τη δημιουργία επίσημων βίντεο Kling μέσω εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να κάνετε αίτηση για την αντίστοιχη υπηρεσία στη σελίδα [Kling Videos Generation API](https://platform.acedata.cloud/documents/3b921a16-a411-4557-8335-53f21d3f9e46). Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για εγγραφή και σύνδεση. Μετά τη σύνδεση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, παρέχεται δωρεάν όριο χρήσης, ώστε να μπορείτε να χρησιμοποιήσετε το API δωρεάν.

## Βασική Χρήση

Αρχικά, κατανοήστε τον βασικό τρόπο χρήσης: εισάγετε το πεδίο `prompt` (προτροπή), το `action` (ενέργεια δημιουργίας), το `start_image_url` (URL αρχικής εικόνας αναφοράς) και το `model` (μοντέλο), και λαμβάνετε το επεξεργασμένο αποτέλεσμα. Πρέπει να περάσετε απλά το πεδίο `action` με τιμή `text2video`. Υπάρχουν τρεις βασικές ενέργειες: δημιουργία βίντεο από κείμενο (`text2video`), δημιουργία βίντεο από εικόνα (`image2video`) και επέκταση βίντεο (`extend`). Επιπλέον, πρέπει να εισάγετε το μοντέλο `model`. Τα κύρια διαθέσιμα μοντέλα είναι: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1`. Αναλυτικά:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" className="m-auto" /></p>

Εδώ ορίζουμε τα Request Headers, τα οποία περιλαμβάνουν:

- `accept`: Τον τύπο μορφής που θέλουμε να λάβουμε στην απόκριση, εδώ ορίζεται σε `application/json` (μορφή JSON).
- `authorization`: Το κλειδί πρόσβασης για το API, το οποίο επιλέγεται μετά την αίτηση.

Επιπλέον, ορίζουμε το Request Body, που περιλαμβάνει:

- `model`: Το μοντέλο δημιουργίας βίντεο, όπως τα `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1`.
- `mode`: Λειτουργία δημιουργίας βίντεο, με επιλογές: τυπική λειτουργία `std`, γρήγορη λειτουργία `pro` και εγγενής 4K λειτουργία `4k`. Η λειτουργία `4k` υποστηρίζεται μόνο από τα `kling-v3` και `kling-v3-omni` και δεν είναι συμβατή με το `camera_control` (έλεγχο κάμερας).
- `action`: Η ενέργεια της τρέχουσας εργασίας δημιουργίας βίντεο, με τις τρεις βασικές επιλογές: `text2video`, `image2video`, `extend`.
- `start_image_url`: Απαιτείται όταν η ενέργεια είναι `image2video`, δηλαδή το URL της αρχικής εικόνας αναφοράς.
- `end_image_url`: Προαιρετικό για `image2video`, καθορίζει την τελική εικόνα.
- `duration`: Διάρκεια βίντεο σε δευτερόλεπτα. Τα μοντέλα `kling-v3` και `kling-v3-omni` υποστηρίζουν ευέλικτη διάρκεια 3-15 δευτερολέπτων (ακέραιοι), ενώ τα υπόλοιπα μοντέλα υποστηρίζουν 5 ή 10 δευτερόλεπτα.
- `generate_audio`: Προαιρετικό boolean για ταυτόχρονη δημιουργία ήχου. Υποστηρίζεται από τα `kling-v3`, `kling-v3-omni` και `kling-v2-6` (μόνο σε λειτουργία pro). Προεπιλογή `false`.
- `aspect_ratio`: Αναλογία διαστάσεων βίντεο, επιλογές: `16:9`, `9:16`, `1:1`. Προεπιλογή `16:9`.
- `cfg_scale`: Ένταση συσχέτισης, εύρος [0,1], όσο μεγαλύτερο τόσο πιο πιστό στην προτροπή.
- `camera_control`: Προαιρετικό, παράμετροι ελέγχου κίνησης κάμερας, υποστηρίζει προκαθορισμένες τιμές type/simple και ρυθμίσεις horizontal, vertical, pan, tilt, roll, zoom κλπ.
- `negative_prompt`: Προαιρετικό, αρνητική προτροπή που δεν θέλετε να εμφανιστεί, έως 200 χαρακτήρες.
- `element_list`: Λίστα αναφοράς αντικειμένων, μόνο για το μοντέλο `kling-video-o1`. Για λεπτομέρειες δείτε την [επίσημη τεκμηρίωση](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `video_list`: Βίντεο αναφοράς μέσω URL, μόνο για το μοντέλο `kling-video-o1`. Αναλυτικά στην [επίσημη τεκμηρίωση](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `prompt`: Η προτροπή.
- `callback_url`: URL για callback αποτελεσμάτων.

Μετά την επιλογή, παράγεται ο αντίστοιχος κώδικας δεξιά, όπως φαίνεται:

<p><img src="https://cdn.acedata.cloud/3yjql0.png" width="500" className="m-auto" /></p>

Πατώντας το κουμπί «Try» μπορείτε να δοκιμάσετε. Το αποτέλεσμα είναι:

```json
{
  "success": true,
  "video_id": "af9a1af0-9aa0-4638-81c1-d41d6143c508",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7485378259/text2video/Cjil4mfBfs0AAAAAAKbMQQ-0_raw_video_1.mp4",
  "duration": "5.1",
  "state": "succeed",
  "task_id": "e3a575aa-a4bd-49c8-9b12-cde38d5462e0"
}
```

Τα πεδία της απόκρισης είναι:

- `success`: Κατάσταση εργασίας δημιουργίας βίντεο.
- `task_id`: Αναγνωριστικό εργασίας.
- `video_id`: Αναγνωριστικό βίντεο.
- `video_url`: Σύνδεσμος βίντεο.
- `duration`: Διάρκεια βίντεο.
- `state`: Κατάσταση εργασίας.

Μπορείτε να λάβετε το δημιουργημένο βίντεο Kling μέσω του πεδίου `video_url` στο `data`.

Επίσης, μπορείτε να αντιγράψετε τον κώδικα ενσωμάτωσης, π.χ. CURL:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v1",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## Πίνακας Δυνατοτήτων Μοντέλων

Τα μοντέλα διαφέρουν σημαντικά στην υποστήριξη παραμέτρων. Ο παρακάτω πίνακας προέρχεται από την [επίσημη τεκμηρίωση των μοντέλων βίντεο Kling](https://app.klingai.com/global/dev/document-api/apiReference/model/videoModels). Πριν την κλήση, ελέγξτε αν ο συνδυασμός `model` / `mode` / `duration` υποστηρίζει τις απαιτούμενες λειτουργίες, αλλιώς θα λάβετε σφάλματα όπως `model/mode/duration(...) is not supported with image_tail`.

| Μοντέλο | Λειτουργία | `end_image_url` (Αρχική/Τελική εικόνα) | `generate_audio` (Ήχος) | `camera_control` (Έλεγχος κάμερας) | Σημειώσεις |
|---|---|---|---|---|---|
| `kling-v1` | std / pro | ✅ Μόνο `duration=5` | ❌ | ✅ Μόνο `duration=5` | Το `extend` δεν υποστηρίζει `negative_prompt` και `cfg_scale` |
| `kling-v1-6` | std | ❌ | ❌ | ❌ | Υποστηρίζει πολλαπλά `image2video` και πλήρη λειτουργία `extend` |
| `kling-v1-6` | pro | ✅ | ❌ | ❌ | |
| `kling-v2-master` | — | ❌ | ❌ | ❌ | Μόνο μία λειτουργία, `duration=5/10` |
| `kling-v2-1-master` | — | ❌ | ❌ | ❌ | Μόνο μία λειτουργία, `duration=5/10` |
| `kling-v2-5-turbo` | std | ❌ | ❌ | ❌ | |
| `kling-v2-5-turbo` | pro | ✅ | ❌ | ❌ | |
| `kling-v2-6` | std | ❌ | ❌ | ❌ | |
| `kling-v2-6` | pro | ✅ | ✅ | ❌ | Το μόνο μη v3 μοντέλο που υποστηρίζει ήχο |
| `kling-v3` | std / pro | ✅ | ✅ | ✅ | Διάρκεια 3–15 δευτερόλεπτα |
| `kling-v3` | 4k | ✅ | ✅ | ❌ | 4K λειτουργία δεν συμβαδίζει με έλεγχο κάμερας |
| `kling-v3-omni` | std / pro / 4k | ✅ | ✅ | ❌ | |
| `kling-video-o1` | std / pro | ✅ | ❌ | ❌ | Μόνο `duration=5/10` |

Σημειώσεις:

- Η λειτουργία `mode=4k` υποστηρίζεται μόνο από `kling-v3` και `kling-v3-omni` και είναι ασύμβατη με `camera_control`.
- Το `end_image_url` χρησιμοποιείται μόνο με `action=image2video` μαζί με `start_image_url`. Η αποστολή μόνο `end_image_url` απορρίπτεται.
- Τα μοντέλα `kling-v3` και `kling-v3-omni` δέχονται οποιαδήποτε ακέραια διάρκεια 3–15 δευτερολέπτων, τα υπόλοιπα μοντέλα δέχονται μόνο 5 ή 10.
- Το `generate_audio` έχει προεπιλογή `false` και υποστηρίζεται μόνο από `kling-v3`, `kling-v3-omni` και `kling-v2-6` (pro).

## Λειτουργία Επέκτασης Βίντεο

Για να συνεχίσετε τη δημιουργία ενός ήδη παραχθέντος βίντεο Kling, ορίστε το `action` σε `extend` και εισάγετε το ID του βίντεο που θέλετε να επεκτείνετε. Το ID βίντεο λαμβάνεται από τη βασική χρήση, όπως φαίνεται:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Το ID βίντεο είναι:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

> Σημείωση: Το `video_id` εδώ αναφέρεται στο ID του παραχθέντος βίντεο. Εάν δεν γνωρίζετε πώς να δημιουργήσετε βίντεο, ανατρέξτε στην ενότητα βασικής χρήσης.

Στη συνέχεια, πρέπει να εισάγετε την προτροπή επέκτασης για να προσαρμόσετε τη δημιουργία βίντεο, με τις παρακάτω παραμέτρους:

- `model`: Μοντέλο δημιουργίας βίντεο, κυρίως `kling-v1`, `kling-v1-5` και `kling-v1-6`.
- `mode`: Λειτουργία βίντεο, επιλογές: `std`, `pro`, `4k` (μόνο για `kling-v3` και `kling-v3-omni`, μη συμβατή με έλεγχο κάμερας).
- `duration`: Διάρκεια βίντεο, κυρίως 5 ή 10 δευτερόλεπτα.
- `start_image_url`: Απαιτείται για `image2video`, URL αρχικής εικόνας.
- `prompt`: Προτροπή.

Παράδειγμα συμπλήρωσης:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" className="m-auto" /></p>

Μετά τη συμπλήρωση, παράγεται αυτόματα ο κώδικας:

<p><img src="https://cdn.acedata.cloud/52x4u5.png" width="500" className="m-auto" /></p>

Παράδειγμα Python κώδικα:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Μετά την εκτέλεση, λαμβάνετε αποτέλεσμα όπως:

```json
{
  "success": true,
  "video_id": "bbc3b105-ac72-4de2-8390-0cb37dc7d41e",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/extendVideo/Cjil4mfBfs0AAAAAAKhr6A-0_raw_video_1.mp4",
  "duration": "9.6",
  "state": "succeed",
  "task_id": "3ece87e6-3ee3-4f5e-bd70-5ae5eca89a23"
}
```

Το αποτέλεσμα είναι όμοιο με το προηγούμενο, επιτυγχάνοντας τη λειτουργία επέκτασης βίντεο.

## Ασύγχρονο Callback

Η δημιουργία βίντεο μέσω του Kling Videos Generation API διαρκεί περίπου 1-2 λεπτά. Εάν το API δεν ανταποκριθεί άμεσα, η HTTP σύνδεση παραμένει ανοιχτή, καταναλώνοντας πόρους συστήματος. Γι' αυτό, το API υποστηρίζει ασύγχρονο callback.

Η διαδικασία είναι: ο πελάτης στέλνει αίτημα με επιπλέον πεδίο `callback_url`. Το API επιστρέφει άμεσα ένα αποτέλεσμα με το `task_id` της εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα αποστέλλεται μέσω POST JSON στο `callback_url` που ορίσατε, περιλαμβάνοντας το `task_id` για συσχέτιση.

Παρακάτω ένα παράδειγμα:

Το Webhook callback είναι μια υπηρεσία που δέχεται HTTP αιτήματα. Ο προγραμματιστής πρέπει να χρησιμοποιήσει το URL του δικού του HTTP server. Για επίδειξη, χρησιμοποιούμε το δημόσιο Webhook site https://webhook.site/, όπου λαμβάνετε ένα Webhook URL, όπως:

![](https://cdn.acedata.cloud/tbcnai.png)

Αντιγράψτε το URL, π.χ. `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`, και ορίστε το ως `callback_url` μαζί με τις άλλες παραμέτρους:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" className="m-auto" /></p>

Μετά την εκτέλεση, λαμβάνετε άμεσα:

```
{
  "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Μετά από λίγο, στο https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3 θα δείτε το αποτέλεσμα δημιουργίας βίντεο:

![](https://cdn.acedata.cloud/zv5u2q.png)

Περιεχόμενο:

```json
{
    "success": true,
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/text2video/CjJzzGfBfqcAAAAAAKdVMQ-0_raw_video_1.mp4",
    "duration": "5.1",
    "state": "succeed",
    "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Το πεδίο `task_id` επιτρέπει τη συσχέτιση των αποτελεσμάτων με την εργασία.

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, σε περίπτωση σφάλματος, επιστρέφονται κωδικοί και μηνύματα σφάλματος, όπως:

- `400 token_mismatched`: Κακό αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακό αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, άκυρο ή ελλιπές token.
- `429 too_many_requests`: Υπερβολικός αριθμός αιτημάτων, υπερβήκατε το όριο.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.

### Παράδειγμα απόκρισης σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
