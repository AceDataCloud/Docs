Αυτό το έγγραφο παρουσιάζει έναν οδηγό ενσωμάτωσης για το Kling Videos Generation API, το οποίο επιτρέπει τη δημιουργία επίσημων βίντεο Kling μέσω εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να υποβάλετε αίτηση για την αντίστοιχη υπηρεσία στη σελίδα [Kling Videos Generation API](https://platform.acedata.cloud/documents/3b921a16-a411-4557-8335-53f21d3f9e46). Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά τη σύνδεση ή εγγραφή, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, παρέχεται δωρεάν όριο χρήσης, επιτρέποντας δωρεάν χρήση του API.

## Βασική Χρήση

Αρχικά, κατανοήστε τον βασικό τρόπο χρήσης: εισάγετε το πεδίο `prompt` (προτροπή), `action` (ενέργεια δημιουργίας), `start_image_url` (URL αρχικής εικόνας αναφοράς) και `model` (μοντέλο), για να λάβετε το επεξεργασμένο αποτέλεσμα. Πρέπει να περάσετε απλά το πεδίο `action` με τιμή `text2video`, το οποίο περιλαμβάνει τρεις βασικές ενέργειες: δημιουργία βίντεο από κείμενο (`text2video`), δημιουργία βίντεο από εικόνα (`image2video`) και επέκταση βίντεο (`extend`). Επιπλέον, πρέπει να επιλέξετε το μοντέλο `model`. Τα διαθέσιμα μοντέλα είναι: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1`. Αναλυτικά:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" className="m-auto" /></p>

Εδώ ορίζουμε τα Request Headers, τα οποία περιλαμβάνουν:

- `accept`: τον τύπο μορφής που θέλουμε να λάβουμε ως απάντηση, εδώ `application/json` (μορφή JSON).
- `authorization`: το κλειδί πρόσβασης για το API, το οποίο επιλέγεται μετά την αίτηση.

Επιπλέον, ορίζουμε το Request Body, το οποίο περιλαμβάνει:

- `model`: το μοντέλο δημιουργίας βίντεο, όπως τα παραπάνω.
- `mode`: λειτουργία δημιουργίας βίντεο, με επιλογές `std` (τυπική), `pro` (γρήγορη) και `4k` (γνήσιο 4K). Η λειτουργία `4k` υποστηρίζεται μόνο από τα μοντέλα `kling-v3` και `kling-v3-omni` και δεν είναι συμβατή με το `camera_control` (έλεγχο κάμερας).
- `action`: η ενέργεια της εργασίας δημιουργίας βίντεο, όπως αναφέρθηκε.
- `start_image_url`: απαιτείται για την ενέργεια `image2video` ως URL της αρχικής εικόνας αναφοράς.
- `end_image_url`: προαιρετικό για `image2video`, καθορίζει την τελική εικόνα.
- `duration`: διάρκεια βίντεο σε δευτερόλεπτα. Τα μοντέλα `kling-v3` και `kling-v3-omni` υποστηρίζουν ευέλικτη διάρκεια 3-15 δευτερολέπτων (ακέραια), ενώ τα υπόλοιπα μοντέλα υποστηρίζουν 5 ή 10 δευτερόλεπτα.
- `generate_audio`: προαιρετικό boolean για ταυτόχρονη δημιουργία ήχου. Υποστηρίζεται από `kling-v3`, `kling-v3-omni` και `kling-v2-6` (μόνο σε λειτουργία pro). Προεπιλογή `false`.
- `aspect_ratio`: αναλογία διαστάσεων βίντεο, επιλογές `16:9`, `9:16`, `1:1`, προεπιλογή `16:9`.
- `cfg_scale`: ένταση συσχέτισης, εύρος [0,1], μεγαλύτερη τιμή σημαίνει πιο πιστή στην προτροπή.
- `camera_control`: προαιρετικό, παράμετροι ελέγχου κίνησης κάμερας, υποστηρίζει προεπιλογές τύπου/simple και ρυθμίσεις όπως horizontal, vertical, pan, tilt, roll, zoom.
- `negative_prompt`: προαιρετικό, αρνητικές προτροπές που δεν θέλετε να εμφανιστούν, έως 200 χαρακτήρες.
- `element_list`: λίστα αναφοράς αντικειμένων, μόνο για το μοντέλο `kling-video-o1`. Αναλυτικές οδηγίες στο [επίσημο έγγραφο](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `video_list`: λίστα αναφοράς βίντεο μέσω URL, μόνο για το μοντέλο `kling-video-o1`. Αναλυτικές οδηγίες στο ίδιο έγγραφο.
- `prompt`: η προτροπή.
- `callback_url`: URL για callback αποτελεσμάτων.

Μετά την επιλογή, δεξιά εμφανίζεται ο αντίστοιχος κώδικας, όπως στην εικόνα:

<p><img src="https://cdn.acedata.cloud/3yjql0.png" width="500" className="m-auto" /></p>

Πατώντας το κουμπί «Try» μπορείτε να δοκιμάσετε, και θα λάβετε το παρακάτω αποτέλεσμα:

```json
{
  "success": true,
  "video_id": "af9a1af0-9aa0-4638-81c1-d41d6143c508",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7485378259/text2video/Cjil4mfBfs0AAAAAAKbMQQ-0_raw_video_1.mp4",
  "duration": "5.1",
  "state": "succeed",
  "task_id": "e3a575aa-a4bd-49c8-9b12-cde38d5462e0"
}
```

Τα πεδία της απάντησης είναι:

- `success`: κατάσταση της εργασίας δημιουργίας βίντεο.
- `task_id`: ID της εργασίας.
- `video_id`: ID του βίντεο που δημιουργήθηκε.
- `video_url`: σύνδεσμος προς το βίντεο.
- `duration`: διάρκεια του βίντεο.
- `state`: κατάσταση της εργασίας.

Έτσι λαμβάνετε τις πληροφορίες του βίντεο και μπορείτε να κατεβάσετε το δημιουργημένο βίντεο Kling από το πεδίο `video_url` μέσα στο `data`.

Επιπλέον, μπορείτε να αντιγράψετε τον αντίστοιχο κώδικα για την ενσωμάτωση, όπως το CURL παράδειγμα:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v1",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## Λειτουργία Επέκτασης Βίντεο

Για να συνεχίσετε τη δημιουργία σε ήδη υπάρχον βίντεο Kling, ορίστε το `action` σε `extend` και εισάγετε το ID του βίντεο που θέλετε να επεκτείνετε. Το ID βίντεο λαμβάνεται από τη βασική χρήση, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Το ID βίντεο είναι:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

> Σημείωση: Το `video_id` είναι το ID του βίντεο μετά τη δημιουργία. Αν δεν γνωρίζετε πώς να δημιουργήσετε βίντεο, ανατρέξτε στην ενότητα βασικής χρήσης.

Στη συνέχεια, πρέπει να συμπληρώσετε την προτροπή επέκτασης για να προσαρμόσετε τη δημιουργία βίντεο, με τα εξής πεδία:

- `model`: μοντέλο δημιουργίας βίντεο, κυρίως `kling-v1`, `kling-v1-5` και `kling-v1-6`.
- `mode`: λειτουργία δημιουργίας, επιλογές `std`, `pro` και `4k` (μόνο για `kling-v3` και `kling-v3-omni`, μη συμβατή με `camera_control`).
- `duration`: διάρκεια βίντεο, 5 ή 10 δευτερόλεπτα.
- `start_image_url`: απαιτείται για `image2video`.
- `prompt`: προτροπή.

Παράδειγμα συμπλήρωσης:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" className="m-auto" /></p>

Μετά τη συμπλήρωση, ο κώδικας δημιουργείται αυτόματα:

<p><img src="https://cdn.acedata.cloud/52x4u5.png" width="500" className="m-auto" /></p>

Παράδειγμα Python κώδικα:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Μετά την εκτέλεση, λαμβάνετε αποτέλεσμα όπως:

```json
{
  "success": true,
  "video_id": "bbc3b105-ac72-4de2-8390-0cb37dc7d41e",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/extendVideo/Cjil4mfBfs0AAAAAAKhr6A-0_raw_video_1.mp4",
  "duration": "9.6",
  "state": "succeed",
  "task_id": "3ece87e6-3ee3-4f5e-bd70-5ae5eca89a23"
}
```

Το αποτέλεσμα είναι παρόμοιο με το προηγούμενο, επιτυγχάνοντας έτσι τη λειτουργία επέκτασης βίντεο.

## Ασύγχρονο Callback

Επειδή η δημιουργία βίντεο μέσω του Kling Videos Generation API διαρκεί περίπου 1-2 λεπτά, και για να αποφευχθεί η παρατεταμένη σύνδεση HTTP που καταναλώνει πόρους, το API υποστηρίζει ασύγχρονο callback.

Η διαδικασία είναι: ο πελάτης προσθέτει το πεδίο `callback_url` στο αίτημα. Το API επιστρέφει άμεσα ένα αποτέλεσμα με το πεδίο `task_id` που αντιπροσωπεύει το ID της εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα αποστέλλεται με POST σε μορφή JSON στο `callback_url`, περιλαμβάνοντας επίσης το `task_id` για συσχέτιση.

Παρακάτω ένα παράδειγμα λειτουργίας.

Το Webhook callback είναι μια υπηρεσία που δέχεται HTTP αιτήματα. Ο προγραμματιστής πρέπει να αντικαταστήσει το URL με το δικό του HTTP server. Για επίδειξη, χρησιμοποιούμε την δημόσια ιστοσελίδα Webhook https://webhook.site/, όπου λαμβάνετε ένα URL Webhook, όπως στην εικόνα:

![](https://cdn.acedata.cloud/tbcnai.png)

Αντιγράψτε το URL, π.χ. `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`, και χρησιμοποιήστε το ως `callback_url`.

Στη συνέχεια, ορίστε το πεδίο `callback_url` με το παραπάνω URL και συμπληρώστε τις υπόλοιπες παραμέτρους, όπως στην εικόνα:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" className="m-auto" /></p>

Πατώντας εκτέλεση, λαμβάνετε άμεσα αποτέλεσμα:

```
{
  "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Μετά από λίγο, μπορείτε να δείτε το αποτέλεσμα της δημιουργίας βίντεο στο `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`, όπως στην εικόνα:

![](https://cdn.acedata.cloud/zv5u2q.png)

Το περιεχόμενο είναι:

```json
{
    "success": true,
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/text2video/CjJzzGfBfqcAAAAAAKdVMQ-0_raw_video_1.mp4",
    "duration": "5.1",
    "state": "succeed",
    "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Παρατηρείτε το πεδίο `task_id`, που επιτρέπει τη συσχέτιση με την εργασία, ενώ τα υπόλοιπα πεδία είναι παρόμοια με τα προηγούμενα.

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, αν προκύψει σφάλμα, το API επιστρέφει τον αντίστοιχο κωδικό και μήνυμα. Παραδείγματα:

- `400 token_mismatched`: Κακό αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακό αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές token.
- `429 too_many_requests`: Πάρα πολλά αιτήματα, υπερβήκατε το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.

### Παράδειγμα Απάντησης Σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
