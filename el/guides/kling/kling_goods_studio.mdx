Υποβάλετε μια εργασία μέσω `POST /kling/goods-studio` και χρησιμοποιήστε το υπάρχον `POST /kling/tasks` για να ελέγξετε την κατάσταση της εργασίας στην πλατφόρμα.

## Είσοδος

Παρέχετε 1–5 εικόνες προϊόντος και έναν τίτλο προϊόντος έως 200 χαρακτήρες· η περιγραφή προϊόντος είναι προαιρετική, έως 2000 χαρακτήρες. Η διάρκεια μπορεί προαιρετικά να είναι 15, 30 ή 60 δευτερόλεπτα.

Ακολουθεί ένα παράδειγμα δομής αιτήματος· αντικαταστήστε το URL του υλικού πριν από την κλήση.

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "Ο τίτλος του προϊόντος σας ή το περιεχόμενο της προφορικής παρουσίασης"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## Αποτελέσματα και χρέωση

Η σύγχρονη λειτουργία επιστρέφει το αποτέλεσμα δημιουργίας· η ασύγχρονη λειτουργία επιστρέφει πρώτα το `task_id`, ενώ το ολοκληρωμένο αποτέλεσμα περιλαμβάνει στο `data` συνδέσμους βίντεο ή εικόνων και το `usage` που υπολογίζεται από τον διακομιστή. Το `callback_url` χρησιμοποιείται για ειδοποίηση ολοκλήρωσης· το αίτημα με `watermark=true` επιστρέφει ταυτόχρονα και την έκδοση με υδατογράφημα.

720p: 2.38 Credits/δευτερόλεπτο· 1080p: 2.8 Credits/δευτερόλεπτο. Τα βίντεο χρεώνονται βάσει της πραγματικής διάρκειας που δημιουργήθηκε· η βασική τιμή ανά δευτερόλεπτο πριν από τη δημιουργία δεν αντιπροσωπεύει τη συνολική τιμή ολόκληρης της εργασίας. Οι αποτυχημένες εργασίες δεν χρεώνονται με κόστος δημιουργίας.
