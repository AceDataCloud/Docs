Αυτό το έγγραφο θα παρουσιάσει τις οδηγίες σύνδεσης του API Γεννήτριας Κίνησης Kling, το οποίο μπορεί να δημιουργήσει βίντεο από την επίσημη Kling μέσω εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [API Γεννήτριας Κίνησης Kling](https://platform.acedata.cloud/documents/d3f2c369-102d-4856-9565-702ac5f2df63) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να χρησιμοποιήσετε το API δωρεάν.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τις λέξεις-κλειδιά `prompt`, τη διεύθυνση εικόνας `image_url` και τον σύνδεσμο βίντεο `video_url`, για να λάβετε το επεξεργασμένο αποτέλεσμα. Στη συνέχεια, πρέπει να εισάγουμε το μοντέλο `mode`, το οποίο αυτή τη στιγμή περιλαμβάνει κυρίως τα μοντέλα `std` και `pro`, με τις λεπτομέρειες όπως παρακάτω:

<p><img src="https://cdn.acedata.cloud/5qlpjt.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `image_url`: η αναφορά εικόνας, οι χαρακτήρες, το φόντο και άλλα στοιχεία στο βίντεο θα βασίζονται στην αναφορά εικόνας.
- `video_url`: ο σύνδεσμος για την αναφορά βίντεο. Οι κινήσεις των χαρακτήρων στο βίντεο θα είναι σύμφωνες με το αναφερόμενο βίντεο.
- `mode`: η λειτουργία δημιουργίας βίντεο, κυρίως με τις επιλογές τυπικής λειτουργίας `std` και ταχύτητας `pro`.
- `keep_original_sound`: μπορείτε να επιλέξετε αν θα διατηρήσετε τον αρχικό ήχο του βίντεο, με τιμές: yes, no.
- `character_orientation`: η κατεύθυνση των χαρακτήρων στο βίντεο, μπορείτε να επιλέξετε να είναι σύμφωνη με την εικόνα ή το βίντεο, με τιμές: image, video.
- `prompt`: οι λέξεις-κλειδιά.
- `callback_url`: η διεύθυνση URL για την επιστροφή αποτελεσμάτων.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

## Ασύγχρονη Επιστροφή

Δεδομένου ότι ο χρόνος δημιουργίας του API Γεννήτριας Κίνησης Kling είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, εάν το API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος. Έτσι, αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη επιστροφή.

Η συνολική διαδικασία είναι: όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`. Μετά την υποβολή του API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα που περιλαμβάνει ένα πεδίο `task_id`, το οποίο αντιπροσωπεύει το τρέχον ID της διαδικασίας. Όταν ολοκληρωθεί η διαδικασία, το αποτέλεσμα του παραγόμενου βίντεο θα αποσταλεί μέσω POST JSON στη διεύθυνση `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της διαδικασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε αυτό μέσω ενός παραδείγματος.

Αρχικά, η επιστροφή Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα. Οι προγραμματιστές θα πρέπει να αντικαταστήσουν με τη διεύθυνση URL του HTTP διακομιστή που έχουν δημιουργήσει. Για ευκολία, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να λάβετε μια διεύθυνση Webhook URL, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/tbcnai.png)
Αντιγράψτε αυτό το URL, ώστε να το χρησιμοποιήσετε ως Webhook, το παρακάτω παράδειγμα είναι `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`.

Στη συνέχεια, μπορούμε να ρυθμίσουμε το πεδίο `callback_url` στο παραπάνω Webhook URL, ενώ ταυτόχρονα να συμπληρώσουμε τις αντίστοιχες παραμέτρους, οι λεπτομέρειες είναι όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" className="m-auto" /></p>

Κάνοντας κλικ στην εκτέλεση, μπορούμε να παρατηρήσουμε ότι θα λάβουμε αμέσως ένα αποτέλεσμα, όπως παρακάτω:

```

}
```

Μετά από λίγο, μπορούμε να παρατηρήσουμε το αποτέλεσμα της δημιουργίας του βίντεο στο `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/zv5u2q.png)

Το περιεχόμενο είναι το εξής:

```json
{
    "success": true,
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/text2video/CjJzzGfBfqcAAAAAAKdVMQ-0_raw_video_1.mp4",
    "duration": "5.1",
```

Μπορούμε να δούμε ότι το αποτέλεσμα περιέχει ένα πεδίο `task_id`, τα υπόλοιπα πεδία είναι παρόμοια με τα παραπάνω, μέσω αυτού του πεδίου μπορούμε να επιτύχουμε τη συσχέτιση των εργασιών.

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
