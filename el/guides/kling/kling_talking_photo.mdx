title: "API Φωτογραφίας που Μιλάει Kling (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Με ένα κλικ μετατρέψτε **μία φωτογραφία + ένα απόσπασμα ήχου** σε ένα «βίντεο που μιλάει». Η υπηρεσία ολοκληρώνει αυτόματα δύο βήματα εσωτερικά: πρώτα χρησιμοποιεί image2video για να ζωντανέψει τη φωτογραφία και, στη συνέχεια, lip-sync για συγχρονισμό των χειλιών με τον ήχο. Χρειάζεται να καλέσετε **μόνο μία φορά**.

- **Διεύθυνση διεπαφής**：`POST https://api.acedata.cloud/kling/talking-photo`
- **Χρέωση**：ανά διάρκεια, 5 δευτερόλεπτα **16.45 Credits**、10 δευτερόλεπτα **30.45 Credits**(= συνδυασμένη τιμή image2video + lip-sync)

## Κεφαλίδες αιτήματος

| Πεδίο              | Τιμή                   |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## Παράμετροι αιτήματος

| Παράμετρος             | Τύπος      | Υποχρεωτικό  | Προεπιλογή                  | Περιγραφή                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | Ναι   | —                   | Δημόσιο URL της φωτογραφίας προσώπου, συνιστάται καθαρή μετωπική λήψη                    |
| `audio_url`    | string  | Ναι   | —                   | Δημόσιο URL του ήχου οδήγησης（.mp3/.wav/.m4a/.aac,≤5MB） |
| `prompt`       | string  | Όχι   | —                   | Prompt για κινήσεις/εκφράσεις στο στάδιο κινουμένων σχεδίων της φωτογραφίας                      |
| `model`        | string  | Όχι   | `kling-v2-1-master` | Μοντέλο Kling που χρησιμοποιείται για την εμψύχωση της φωτογραφίας                     |
| `duration`     | integer | Όχι   | `5`                 | Διάρκεια βίντεο（5 ή 10 δευτερόλεπτα）                        |
| `mode`         | string  | Όχι   | `pro`               | Ποιότητα εμψύχωσης（std/pro）                        |
| `callback_url` | string  | Όχι   | —                   | Εάν παρέχεται ή `async=true`, επιστρέφει ασύγχρονα task_id        |
| `async`        | boolean | Όχι   | `false`             | Ασύγχρονη λειτουργία, χρησιμοποιείται με polling ή callback του `/kling/tasks`          |

## Παράδειγμα αιτήματος

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Παράδειγμα απόκρισης

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Πεδίο                 | Περιγραφή                        |
| ------------------ | ------------------------- |
| `video_url`        | Το τελικό βίντεο που μιλάει（έχει ήδη αποθηκευτεί στο CDN αυτής της πλατφόρμας）      |
| `source_video_url` | Το ενδιάμεσο βίντεο εμψύχωσης της φωτογραφίας（αποτέλεσμα image2video） |
| `video_id`         | ID βίντεο Kling                   |

## Σημειώσεις

- Συνιστάται η φωτογραφία να είναι καθαρή, μετωπική και με ένα άτομο.
- Συνιστάται η διάρκεια ήχου να μην υπερβαίνει τη διάρκεια του βίντεο（5s/10s）。
- Η χρέωση πραγματοποιείται σε περίπτωση επιτυχίας· αποτυχία επικύρωσης παραμέτρων（4xx）δεν χρεώνεται.
- Ο χρόνος δημιουργίας είναι περίπου 4–6 λεπτά（δύο βήματα), συνιστάται η χρήση `async=true` + polling του `/kling/tasks`.
