Υποβάλετε μια εργασία μέσω `POST /kling/video-commerce` και χρησιμοποιήστε το υπάρχον `POST /kling/tasks` για να ελέγξετε την κατάσταση της εργασίας στην πλατφόρμα.

## Είσοδος

Ανεβάστε μία εικόνα προσώπου και καθορίστε `voice_id`, ή χρησιμοποιήστε ένα προεπιλεγμένο `avatar_id` (τα δύο αλληλοαποκλείονται και για τα προεπιλεγμένα πρόσωπα δεν μπορεί να καθοριστεί επιπλέον `voice_id`). Πρέπει να παρέχεται ένα `speech_script` έως 2000 χαρακτήρες. Κατά την παροχή πληροφοριών προϊόντος, απαιτούνται τουλάχιστον μία `ref_image` και ένα `goods_title`; το εμπορικό voice-over προϊόντος δεν υποστηρίζει `speech_rate`. Το συνηθισμένο voice-over προσώπου υποστηρίζει ταχύτητα ομιλίας 0,8, 1,0 ή 1,2 φορές.

Ακολουθεί ένα παράδειγμα δομής αιτήματος· αντικαταστήστε τα URL των υλικών πριν την κλήση.

```json
{
  "contents": [
    {
      "type": "avatar_image",
      "url": "https://your-cdn.example/person.jpg"
    },
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    },
    {
      "type": "speech_script",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "voice_id": "male_calm_informative"
  },
  "async": true
}
```

## Αποτελέσματα και χρέωση

Η σύγχρονη λειτουργία επιστρέφει το αποτέλεσμα δημιουργίας· η ασύγχρονη λειτουργία επιστρέφει πρώτα `task_id`, και το ολοκληρωμένο αποτέλεσμα περιλαμβάνει τους συνδέσμους βίντεο ή εικόνας στο `data` και το `usage` που υπολογίζεται από τον διακομιστή. Το `callback_url` χρησιμοποιείται για ειδοποίηση ολοκλήρωσης· ένα αίτημα με `watermark=true` επιστρέφει ταυτόχρονα και έκδοση με υδατογράφημα.

Συνηθισμένο voice-over προσώπου: 1,4 Credits/δευτερόλεπτο για 720p και 1,68 Credits/δευτερόλεπτο για 1080p· εμπορικό voice-over προϊόντος: 1,96 Credits/δευτερόλεπτο για 720p και 2,24 Credits/δευτερόλεπτο για 1080p. Τα βίντεο χρεώνονται βάσει της πραγματικής παραγόμενης διάρκειας· η βασική τιμή ανά δευτερόλεπτο πριν από τη δημιουργία δεν αντιπροσωπεύει τη συνολική τιμή ολόκληρης της εργασίας. Οι αποτυχημένες εργασίες δεν χρεώνονται με κόστος δημιουργίας.
