Η κύρια λειτουργία του API Kling Tasks είναι να ελέγχει την κατάσταση εκτέλεσης ενός έργου μέσω του ID έργου που παράγεται από το API Kling Videos Generation.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες σύνδεσης του API Kling Tasks, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του API Kling Tasks, μπορείτε εύκολα να ελέγξετε την κατάσταση εκτέλεσης των έργων του API Kling Videos Generation.

## Διαδικασία Αίτησης

### Ρύθμιση Επικεφαλίδων Αίτησης και Σώματος Αίτησης

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `id`: το ID του έργου που ανεβάσατε.
- `action`: ο τρόπος λειτουργίας του έργου.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/kling/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/kling/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 错误处理

在调用 API 时，如果遇到错误，API 会返回相应的错误代码和信息。例如：

- `400 token_mismatched`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
