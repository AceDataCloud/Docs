Τα MiMo 2.6 Pro και MiMo 2.6 Flash είναι μοντέλα της σειράς Xiaomi MiMo. Αυτή η διεπαφή χρησιμοποιεί τη μορφή OpenAI Chat Completions και χρεώνει με βάση τα token εισόδου, εξόδου και επιτυχιών cache.

## Μοντέλα και διεπαφές

| Μοντέλο                | Τοποθέτηση           |
| ----------------- | ------------ |
| `mimo-v2.6-pro`   | Σύνθετη ανάλυση, συλλογιστική και κλήση εργαλείων |
| `mimo-v2.6-flash` | Καθημερινός διάλογος και ελαφριές εργασίες    |

Ενεργοποιήστε το MiMo και αποκτήστε τα αντίστοιχα διαπιστευτήρια API, στέλνοντας αιτήματα στο `https://api.acedata.cloud/mimo/chat/completions`. Το `base_url` του OpenAI SDK μπορεί να οριστεί σε `https://api.acedata.cloud/mimo`. Η ενιαία είσοδος `/v1/chat/completions` απαιτεί επίσης τα αντίστοιχα δικαιώματα υπηρεσίας.

Το αρχικό εύρος διεπαφών είναι Text Chat Completions· εικόνες, ήχος, βίντεο, διαδικτυακή αναζήτηση, Responses, Messages, Batch και UltraSpeed δεν περιλαμβάνονται σε αυτήν την έκδοση.

## Παράδειγμα Python

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ACEDATACLOUD_API_KEY"],
    base_url="https://api.acedata.cloud/mimo",
)
response = client.chat.completions.create(
    model="mimo-v2.6-pro",
    messages=[{"role": "user", "content": "解释彩虹形成的原因。"}],
    max_completion_tokens=256,
    extra_body={"thinking": {"type": "disabled"}},
)
print(response.choices[0].message.content)
print(response.usage)
```

Το παράδειγμα παρουσιάζει τον τρόπο σύνταξης του αιτήματος· πραγματικά παραδείγματα απόκρισης θα προστεθούν μετά την επαλήθευση της υπηρεσίας.

## Ροή, συλλογιστική και κλήση εργαλείων

Ορίστε `stream=true` για να λάβετε SSE· εάν χρειάζεστε την τελική χρήση, περάστε `stream_options={"include_usage": true}`. Ο πελάτης θα πρέπει να χειρίζεται αυξήσεις περιεχομένου, περιεχομένου συλλογιστικής και κλήσεων εργαλείων, καθώς και το τελικό συμβάν usage.

Χρησιμοποιήστε `thinking.type=enabled` για να ενεργοποιήσετε τη συλλογιστική και `disabled` για να την απενεργοποιήσετε. Το `reasoning_content` και το τελικό `content` επιστρέφονται ξεχωριστά· κατά τη συνέχιση κλήσεων εργαλείων, διατηρήστε το περιεχόμενο συλλογιστικής στο μήνυμα του βοηθού, το πλήρες `tool_calls` και το αντίστοιχο `tool_call_id`.

Υποβάλετε μόνο δηλώσεις εργαλείων `type=function`, ενώ το `tool_choice` υποστηρίζει μόνο `auto`. Η εφαρμογή είναι υπεύθυνη για την εκτέλεση των εργαλείων και την επιστροφή των αποτελεσμάτων· η επιστροφή κλήσης εργαλείου από το μοντέλο δεν σημαίνει ότι το εργαλείο έχει ήδη εκτελεστεί. Η ενσωματωμένη διαδικτυακή αναζήτηση της υπηρεσίας δεν είναι ακόμη διαθέσιμη.

## Χρέωση

Το `prompt_tokens` περιλαμβάνει εισόδους που πέτυχαν στην cache· το `prompt_tokens_details.cached_tokens` υπολογίζεται με την τιμή cache, ενώ οι υπόλοιπες είσοδοι υπολογίζονται με την κανονική τιμή εισόδου. Το `completion_tokens` περιλαμβάνει την έξοδο συλλογιστικής, μην αθροίζετε ξανά τα token συλλογιστικής. Οι κλήσεις ροής χρεώνονται επίσης με βάση την τελική πραγματική χρήση.

Οι τιμές υπόκεινται στην κονσόλα και το κόστος σε δολάρια του Credit εξαρτάται από το πακέτο αγοράς. Τα αποτυχημένα αιτήματα δεν θα πρέπει να θεωρούνται ότι ολοκληρώθηκαν επιτυχώς· εάν χρειάζεται να επαληθεύσετε τη χρέωση, παρέχετε το αναγνωριστικό παρακολούθησης στην απόκριση.

## Χειρισμός σφαλμάτων

Για σφάλματα παραμέτρων, ελέγξτε τη μορφή του αιτήματος· για σφάλματα ταυτοποίησης ή δικαιωμάτων, ελέγξτε τα διαπιστευτήρια και την ενεργοποίηση της υπηρεσίας· εάν συναντήσετε 429, επαναλάβετε με backoff. Εάν δεν υπάρχει υγιής χωρητικότητα μοντέλου, ενδέχεται να επιστραφεί 503. Όταν προκύπτει διακοπή μετά την έναρξη μιας απόκρισης ροής, ελέγξτε πρώτα τα ήδη ληφθέντα αποτελέσματα και τη χρήση, ώστε να αποφύγετε την τυφλή επανάληψη του αιτήματος.
