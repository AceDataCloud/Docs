Αυτό το API βασίζεται στο [επίσημο Model API του Fish Audio](https://docs.fish.audio/resources/api-reference/model) και χρησιμοποιείται για τη **δημιουργία ενός μοντέλου κλωνοποιημένης φωνής που μπορεί να επαναχρησιμοποιείται μακροπρόθεσμα με βάση ένα δείγμα ήχου**. Η διεύθυνση είναι `POST https://api.acedata.cloud/fish/model`.

> Όταν χρειάζεται να χρησιμοποιήσετε μια φωνή αναφοράς μόνο προσωρινά, δεν χρειάζεται να δημιουργήσετε μοντέλο· μπορείτε να χρησιμοποιήσετε απευθείας την εφάπαξ άμεση κλωνοποίηση `references` του [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts). Για σελιδοποιημένη αναζήτηση υπαρχόντων χροιών φωνής, ανατρέξτε στο [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query)· για αναζήτηση λεπτομερειών μιας μεμονωμένης χροιάς φωνής βάσει `_id`, ανατρέξτε στο [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Fish Model API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να λάβετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση παρέχει δωρεάν υπόλοιπο για δωρεάν δοκιμή· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να προσθέσετε κοινό υπόλοιπο μέσω της [κονσόλας](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Πεδία σώματος αιτήματος

| Πεδίο                      | Τύπος       | Υποχρεωτικό  | Περιγραφή                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | Ναι   | Όνομα χροιάς φωνής, που χρησιμοποιείται για αναγνώριση στη λίστα της κονσόλας.                                                             |
| `voices`                | string   | Ναι   | HTTP(S) URL του δείγματος ήχου (**μεμονωμένο string**, όχι πίνακας). Αυτό το API δεν υποστηρίζει multipart/δυαδική μεταφόρτωση· τοποθετήστε πρώτα τον ήχο σε οποιαδήποτε δημόσια προσβάσιμη αποθήκευση αντικειμένων. |
| `description`           | string   | Όχι   | Περιγραφή χροιάς φωνής.                                                                         |
| `cover_image`           | string   | Όχι   | HTTP(S) URL εικόνας εξωφύλλου.                                                              |
| `tags`                  | string[] | Όχι   | Ετικέτες αναζήτησης για τη δημόσια βιβλιοθήκη, για παράδειγμα `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | Όχι   | Κείμενα αναφοράς που αντιστοιχούν στα δείγματα (χρησιμοποιούνται για διόρθωση προφοράς).                                                           |
| `enhance_audio_quality` | boolean  | Όχι   | Αν θα γίνει βελτίωση ποιότητας ήχου στο δείγμα πριν από την εκπαίδευση.                                                                |
| `generate_sample`       | boolean  | Όχι   | Αν θα δημιουργηθεί αυτόματα ένα δείγμα ήχου μετά την ολοκλήρωση της εκπαίδευσης.                                                            |

> Για περισσότερες πληροφορίες σχετικά με τα μοντέλα χροιάς φωνής, ανατρέξτε στην [επίσημη τεκμηρίωση του Fish](https://docs.fish.audio/resources/api-reference/model).

> Οι δημιουργημένες χροιές φωνής αποθηκεύονται δημόσια μακροπρόθεσμα και άλλοι χρήστες ενδέχεται να τις αναζητήσουν και να τις χρησιμοποιήσουν. Δεν χρειάζεται να περάσετε το `visibility`· ακόμη και αν περάσετε `private` ή `unlist`, το τρέχον API δεν θα αλλάξει το δημόσιο εύρος βάσει αυτού.

## Παράδειγμα: Δημιουργία ενός δημόσιου κλωνοποιημένου φωνητικού προφίλ

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的中文音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Σημείωση: Το `voices` πρέπει να είναι **συμβολοσειρά** (ένα μεμονωμένο URL ήχου), όχι πίνακας. Δεν υποστηρίζεται η εισαγωγή του `["..."]`. Συνιστάται η χρήση άμεσων συνδέσμων με κατάληξη `.mp3` ή `.wav`, που είναι δημόσια διαθέσιμοι για λήψη.

Η επιτυχής απόκριση επιστρέφει απευθείας το αντικείμενο ModelEntity της πλατφόρμας Fish (το παρακάτω παράδειγμα είναι το ελάχιστο λειτουργικό φωνητικό προφίλ που έχουμε δοκιμάσει· ορισμένα μεγάλα πεδία έχουν αφαιρεθεί για ευκολότερη ανάγνωση):

```json
{
  "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
  "type": "tts",
  "title": "copilot-smoke-test",
  "description": "smoke test from api.acedata.cloud",
  "cover_image": "coverimage/e5c6db52c3ed417f9cb2e5a33fb04667",
  "train_mode": "fast",
  "state": "trained",
  "tags": [],
  "samples": [
    {
      "title": "Default Sample",
      "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
      "task_id": "6a1bf398dfae49dca0e23159214342a0",
      "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
    }
  ],
  "created_at": "2026-05-10T03:52:55.601000Z",
  "updated_at": "2026-05-10T03:52:55.601000Z",

  "default_text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
  "like_count": 0,

    "nickname": "Penny Conrad",

  }

```

Το `_id` μπορεί να χρησιμοποιηθεί ως η τιμή του πεδίου `reference_id` στο επόμενο [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts), για σύνθεση ομιλίας με αυτό το κλωνοποιημένο φωνητικό προφίλ:

Τα φωνητικά προφίλ που δημιουργούνται επιτυχώς αποθηκεύονται δημόσια. Μπορείτε να χρησιμοποιήσετε το `self=true` του [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query) για να αναζητήσετε τα φωνητικά προφίλ που έχει δημιουργήσει ο τρέχων χρήστης μέσω αυτής της πλατφόρμας. Το `self=true` φιλτράρει μόνο τη λίστα και δεν περιορίζει τη χρήση αυτού του φωνητικού προφίλ από άλλους χρήστες.

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，这是一段使用我刚创建的克隆音色合成的语音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Απαιτήσεις δείγματος

Συστάσεις αναφοράς (δείτε την [επίσημη τεκμηρίωση του Fish](https://docs.fish.audio/resources/api-reference/model) για λεπτομέρειες):

- Συνιστάται διάρκεια άνω των 30 δευτερολέπτων, με βέλτιστα αποτελέσματα εντός 5 λεπτών· πέραν των 10 λεπτών, το οριακό όφελος είναι μικρό.
- Ρυθμός δειγματοληψίας 16 kHz ή υψηλότερος· επιτρέπεται μονοφωνικός ή στερεοφωνικός ήχος.
- Το περιεχόμενο πρέπει να είναι όσο το δυνατόν καθαρό: χωρίς μουσική υπόκρουση, ηχώ ή εμφανή περιβαλλοντικό θόρυβο· ο ίδιος ομιλητής.
- Συνιστώμενες μορφές: `mp3` / `wav`.

Εάν δεν είστε βέβαιοι για την ποιότητα του δείγματος, μπορείτε επίσης να υποβάλετε το `enhance_audio_quality: true` για να ενεργοποιήσετε τη βελτίωση ποιότητας ήχου.

## Οδηγίες χρέωσης
Η δημιουργία ενός μοντέλου κλωνοποίησης φωνής (`POST /fish/model`) είναι δωρεάν, χωρίς καμία χρέωση· τα API ερωτημάτων φωνής ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)、[Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) επίσης δεν χρεώνονται. Χρεώσεις προκύπτουν μόνο κατά την επακόλουθη κλήση του [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) για σύνθεση ομιλίας, ανάλογα με τη χρήση.

## Χειρισμός σφαλμάτων

- `400 token_mismatched`: Οι παράμετροι του αιτήματος λείπουν ή δεν είναι έγκυρες (συνηθέστερα το `voices` δεν είναι URL ή έχει δοθεί ως πίνακας).
- `400`: Όταν ο ήχος αναφοράς δεν μπορεί να ληφθεί, η διάρκειά του είναι πολύ μικρή ή η μορφή του δεν μπορεί να αναγνωριστεί, ελέγξτε το URL του ήχου και τη μορφή αρχείου.
- `401 invalid_token`: Το token πιστοποίησης δεν υπάρχει ή δεν είναι έγκυρο.
- `429 too_many_requests`: Ενεργοποιήθηκε το όριο ρυθμού του λογαριασμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.

Παράδειγμα απόκρισης σφάλματος:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Συμπέρασμα

Για την κλήση αυτού του API χρειάζεται μόνο να προετοιμάσετε ένα δημόσια προσβάσιμο URL δείγματος ήχου, να το τοποθετήσετε στο πεδίο `voices` για να λάβετε το `_id`, και στη συνέχεια να το δώσετε στο `reference_id` του `/fish/tts`, ολοκληρώνοντας έτσι τη ροή «κλωνοποίηση → σύνθεση» από άκρο σε άκρο. Ένα συνηθισμένο σημείο προσοχής είναι ότι το `voices` πρέπει να είναι συμβολοσειρά και δεν μπορεί να είναι πίνακας.

## Δημιουργία και επαναχρησιμοποίηση φωνών μέσω MCP

Καλέστε στο Fish MCP
`fish_create_model(title="Η φωνή μου", voices="https://example.com/authorized-voice.wav")`.
Το `voices` είναι ένα μεμονωμένο HTTP(S) URL ήχου· μπορούν επίσης να περαστούν τα `description`, `cover_image`, `tags`,
`texts`, `enhance_audio_quality`, `generate_sample`.

Αυτό το εργαλείο θα αποθηκεύει δημόσιες φωνές μακροπρόθεσμα και άλλοι χρήστες ενδέχεται να τις ανακαλύψουν και να τις χρησιμοποιήσουν· χρησιμοποιείτε μόνο
ηχητικό υλικό του οποίου η επεξεργασία και δημοσίευση έχει εγκριθεί. Το εργαλείο δεν διαθέτει ιδιωτική ή μη δημόσια επιλογή. Το `_id` που επιστρέφεται μετά από επιτυχή δημιουργία χρησιμοποιείται ως
`reference_id` για το `fish_generate_audio`, ενώ το `fish_list_models(self=true)` μπορεί να αναζητήσει τις φωνές που
έχετε αποθηκεύσει. Όταν χρειάζεστε ήχο αναφοράς μόνο μία φορά, χρησιμοποιήστε το `references` του `fish_generate_audio`,
χωρίς να χρειάζεται να δημιουργήσετε μακροχρόνια φωνή.
