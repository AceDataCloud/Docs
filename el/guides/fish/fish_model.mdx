Αυτή η διεπαφή βασίζεται στο [Fish Audio επίσημο Model API](https://docs.fish.audio/resources/api-reference/model) και χρησιμοποιείται για **τη δημιουργία ενός επαναχρησιμοποιήσιμου κλώνου ήχου με βάση ένα δείγμα ήχου**. Η διεύθυνση είναι `POST https://api.acedata.cloud/fish/model`.

> Εάν χρειάζεστε προσωρινά να χρησιμοποιήσετε αναφορά ήχου, δεν χρειάζεται να δημιουργήσετε μοντέλο, μπορείτε να χρησιμοποιήσετε απευθείας το [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) με το `references` για άμεσο κλωνοποίηση. Για να αναζητήσετε υπάρχουσες φωνές, ανατρέξτε στο [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query)· για να αναζητήσετε λεπτομέρειες για μια συγκεκριμένη φωνή με βάση το `_id`, ανατρέξτε στο [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Fish Model API, πρώτα επισκεφθείτε το [Ace Data Cloud κονσόλα](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη σελίδα που βρίσκεστε.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, δεν χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πίστωση για να δοκιμάσετε· όταν η πίστωση εξαντληθεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Πεδία Σώματος Αίτησης

| Πεδίο                    | Τύπος     | Υποχρεωτικό | Περιγραφή                                                                        |
| ----------------------- | -------- | --------- | ----------------------------------------------------------------------------- |
| `title`                 | string   | Ναι       | Όνομα φωνής, χρησιμοποιείται για αναγνώριση στη λίστα της κονσόλας.                     |
| `voices`                | string   | Ναι       | HTTP(S) URL του δείγματος ήχου (**μοναδική συμβολοσειρά**, όχι πίνακας). Αυτή η διεπαφή δεν υποστηρίζει multipart/δυαδική μεταφόρτωση, παρακαλώ τοποθετήστε τον ήχο σε οποιαδήποτε δημόσια προσβάσιμη αποθήκη αντικειμένων. |
| `description`           | string   | Όχι       | Περιγραφή φωνής.                                                                   |
| `cover_image`           | string   | Όχι       | HTTP(S) URL της εικόνας εξωφύλλου.                                               |
| `tags`                  | string[] | Όχι       | Ετικέτες αναζήτησης δημόσιας βιβλιοθήκης, π.χ. `["male","narration","zh"]`.                |
| `texts`                 | string[] | Όχι       | Αναφορές κειμένου που αντιστοιχούν στο δείγμα (για διόρθωση προφοράς).                     |
| `enhance_audio_quality` | boolean  | Όχι       | Εάν θα γίνει ενίσχυση ποιότητας ήχου πριν από την εκπαίδευση.                          |
| `generate_sample`       | boolean  | Όχι       | Εάν θα παραχθεί αυτόματα ένα δείγμα ήχου μετά την ολοκλήρωση της εκπαίδευσης.            |

> Τα πεδία είναι ακριβώς τα ίδια με τα upstream, παρακαλώ ανατρέξτε ταυτόχρονα στο [Fish επίσημο έγγραφο](https://docs.fish.audio/resources/api-reference/model).

## Παράδειγμα: Δημιουργία μιας ιδιωτικής κλωνοποιημένης φωνής

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "Η κλωνοποιημένη φωνή μου",
    "description": "Κλωνοποιημένη κινεζική φωνή από μια ηχογράφηση podcast",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Σημείωση: το `voices` πρέπει να είναι **συμβολοσειρά** (μοναδικό URL ήχου), όχι πίνακας. Εάν μεταφερθεί ως `["..."]`, το upstream θα το απορρίψει.

Η επιτυχής απάντηση επιστρέφει απευθείας το αντικείμενο ModelEntity της πλατφόρμας Fish (το παρακάτω είναι το ελάχιστο διαθέσιμο δείγμα φωνής που έχουμε δοκιμάσει, μερικά μακροχρόνια πεδία έχουν αφαιρεθεί για ευκολία ανάγνωσης):

```json
{
  "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
  "type": "tts",
  "title": "copilot-smoke-test",
  "description": "smoke test from api.acedata.cloud",
  "cover_image": "coverimage/e5c6db52c3ed417f9cb2e5a33fb04667",
  "train_mode": "fast",
  "state": "trained",

      "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
    }
  ],

  "updated_at": "2026-05-10T03:52:55.601000Z",
  "languages": ["zh"],
```

Το `_id` μπορεί να χρησιμοποιηθεί ως τιμή για το πεδίο `reference_id` στο επόμενο [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) για τη σύνθεση φωνής με αυτήν την κλωνοποιημένη φωνή:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，这是一段使用我刚创建的克隆音色合成的语音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Απαιτήσεις Δείγματος

Εμπειρικές τιμές (σύμφωνα με το upstream, μπορείτε να ανατρέξετε στο [Fish επίσημο έγγραφο](https://docs.fish.audio/resources/api-reference/model)):

- Η διάρκεια προτείνεται να είναι πάνω από 30 δευτερόλεπτα και κάτω από 5 λεπτά για καλύτερα αποτελέσματα· πάνω από 10 λεπτά η περιθωριακή απόδοση δεν είναι μεγάλη.
- Ρυθμός δειγματοληψίας 16 kHz και άνω, μπορεί να είναι μονοφωνικός ή στερεοφωνικός.
- Το περιεχόμενο πρέπει να είναι όσο το δυνατόν καθαρό: χωρίς υπόκρουση μουσικής, ηχώ, προφανή περιβαλλοντικά θόρυβο· από τον ίδιο ομιλητή.
- Συνιστώμενη μορφή `mp3` / `wav`.

Εάν δεν είστε σίγουροι για την ποιότητα του δείγματος, μπορείτε να στείλετε ταυτόχρονα `enhance_audio_quality: true` για να επιτρέψετε στο upstream να κάνει πρώτα την ενίσχυση ποιότητας ήχου.

## Διευκρίνιση Χρέωσης

Η δημιουργία κλώνου φωνής ( `POST /fish/model`) είναι δωρεάν, δεν χρεώνεται καμία αμοιβή· οι διεπαφές αναζήτησης φωνών ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query), [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) επίσης δεν χρεώνονται. Χρεώσεις προκύπτουν μόνο κατά την επόμενη κλήση του [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) για τη σύνθεση φωνής.

## Διαχείριση Σφαλμάτων
- `400 token_mismatched`：Η παράμετρος αιτήματος λείπει ή είναι μη έγκυρη (το πιο συχνό είναι ότι το `voices` δεν είναι URL ή έχει μεταφερθεί ως πίνακας).
- `401 invalid_token`：Το token εξουσιοδότησης δεν υπάρχει ή είναι μη έγκυρο.
- `429 too_many_requests`：Ενεργοποιήθηκε ο περιορισμός ρυθμού του λογαριασμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή.

Παράδειγμα σφάλματος απόκρισης:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Συμπέρασμα

Για να καλέσετε αυτήν την διεπαφή, χρειάζεται απλώς να προετοιμάσετε ένα δείγμα URL ήχου που να είναι δημόσια προσβάσιμο, να το τοποθετήσετε στο πεδίο `voices` και θα λάβετε το `_id`, το οποίο στη συνέχεια θα δώσετε στο `reference_id` του `/fish/tts` για να ολοκληρώσετε τη διαδικασία «κλωνοποίηση → σύνθεση». Συνηθισμένο λάθος είναι ότι το `voices` πρέπει να είναι συμβολοσειρά, δεν μπορεί να είναι πίνακας.
