Αυτό το έγγραφο παρουσιάζει τις οδηγίες ενσωμάτωσης του Fish Model API, το οποίο είναι πλήρως συμβατό με το [επίσημο OpenAPI του Fish Audio](https://docs.fish.audio/resources/api-reference/model) και περιλαμβάνει:

- `POST /fish/model`: Δημιουργία ενός νέου κλωνοποιημένου φωνητικού μοντέλου (Voice Model) βασισμένου σε δείγματα ήχου.
- `GET /fish/model`: Πληροφορίες σελίδων με λίστα φωνητικών μοντέλων ορατών στον τρέχοντα λογαριασμό ή σε όλη την πλατφόρμα.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να κάνετε αίτηση για την αντίστοιχη υπηρεσία στη σελίδα [Fish Model API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509). Μετά την είσοδο στη σελίδα, κάντε κλικ στο κουμπί «Acquire».

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε ή να συνδεθείτε. Μετά τη σύνδεση ή εγγραφή, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, παρέχεται δωρεάν όριο χρήσης για το API.

## Διαφορές από το Επίσημο API

- **Μέθοδος Εξουσιοδότησης**: Χρήση `Authorization: Bearer {token}`, όπου το `{token}` είναι το κλειδί που αποκτήθηκε από την πλατφόρμα μας.
- **Αποστολή Δειγμάτων κατά τη Δημιουργία Μοντέλου**: Αυτή η διεπαφή υποστηρίζει μόνο υποβολή σε μορφή JSON, με το πεδίο `voices` να περιέχει URLs των δειγμάτων ήχου. Το επίσημο Fish υποστηρίζει multipart/msgpack για απευθείας αποστολή δυαδικών δεδομένων, κάτι που δεν έχει υλοποιηθεί ακόμα στην πλατφόρμα μας. Η μορφή URL καλύπτει περίπου το 80% των κοινών περιπτώσεων.
- **Δομή Απάντησης**: Τα `POST /fish/model` και `GET /fish/model` μεταβιβάζουν απευθείας την απάντηση από το Fish χωρίς επιπλέον περιτύλιγμα (envelope) της πλατφόρμας. Σε περίπτωση σφάλματος χρησιμοποιείται η τυπική δομή της πλατφόρμας `{success:false, error:{code,message}, trace_id}`.

## Δημιουργία Φωνής (POST /fish/model)

Η ελάχιστη αίτηση δημιουργίας απαιτεί τα πεδία `title` και `voices`. Το `voices` είναι λίστα URLs δειγμάτων ήχου, συνιστάται κάθε αρχείο να έχει διάρκεια άνω των 30 δευτερολέπτων και ρυθμό δειγματοληψίας 16kHz ή μεγαλύτερο.

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的音色",
    "voices": [
      "https://example.com/sample-voice.mp3"
    ],
    "cover_image": "https://example.com/cover.png",
    "visibility": "private"
  }'
```

Η επιτυχημένη απάντηση επιστρέφει απευθείας το αντικείμενο ModelEntity της πλατφόρμας Fish:

```json
{
  "_id": "d7900c21663f485ab63ebdb7e5905036",
  "type": "tts",
  "title": "我的克隆音色",
  "description": "用一段播客录音克隆的音色",
  "cover_image": "https://example.com/cover.png",
  "train_mode": "fast",
  "state": "trained",
  "tags": [],
  "samples": [],
  "created_at": "2025-05-09T12:34:56.789Z",
  "updated_at": "2025-05-09T12:34:56.789Z",
  "languages": ["zh", "en"],
  "visibility": "private",
  "lock_visibility": false,
  "like_count": 0,
  "mark_count": 0,
  "shared_count": 0,
  "task_count": 0,
  "author": {
    "_id": "user_id",
    "nickname": "user_nickname",
    "avatar": "user_avatar"
  }
}
```

Το επιστρεφόμενο `_id` μπορεί να χρησιμοποιηθεί ως τιμή του πεδίου `reference_id` στο επόμενο `POST /fish/tts` για σύνθεση φωνής με το κλωνοποιημένο μοντέλο.

## Αναζήτηση Λίστας Φωνών (GET /fish/model)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=10' \
  --data-urlencode 'page_number=1' \
  --data-urlencode 'self=true'
```

Διαθέσιμες παράμετροι αναζήτησης (ίδιες με το επίσημο Fish):

- `page_size`: Αριθμός εγγραφών ανά σελίδα, προεπιλογή 10.
- `page_number`: Αριθμός σελίδας, ξεκινά από 1.
- `title`: Αναζήτηση με ασαφή αντιστοίχιση τίτλου.
- `tag`: Φιλτράρισμα κατά ετικέτα.
- `self`: Αν είναι `true`, επιστρέφει μόνο φωνές που δημιουργήθηκαν από τον τρέχοντα λογαριασμό.
- `author_id`: Φιλτράρισμα κατά δημιουργό.
- `language`: Φιλτράρισμα κατά γλώσσα φωνής.
- `title_language`: Φιλτράρισμα κατά γλώσσα τίτλου.

Η επιτυχημένη απάντηση μεταβιβάζει απευθείας τη δομή σελίδων της πλατφόρμας Fish:

```json
{
  "items": [
    {
      "_id": "d7900c21663f485ab63ebdb7e5905036",
      "title": "我的克隆音色",
      "description": "用一段播客录音克隆的音色",
      "cover_image": "https://example.com/cover.png",
      "type": "tts",
      "state": "trained",
      "tags": [],
      "languages": ["zh", "en"],
      "visibility": "private",
      "created_at": "2025-05-09T12:34:56.789Z",
      "updated_at": "2025-05-09T12:34:56.789Z"
    }
  ],
  "total": 1
}
```

## Πληρωμές

Αυτή η διεπαφή χρεώνει μόνο κατά τη δημιουργία φωνής (`POST /fish/model` με το πεδίο `voices` στο σώμα της αίτησης). Η αναζήτηση λίστας φωνών (`GET /fish/model`) δεν χρεώνεται.

## Διαχείριση Σφαλμάτων

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.

### Παράδειγμα Απάντησης Σφάλματος


## Συμπέρασμα

Το Fish Model API είναι πλήρως συμβατό με το επίσημο OpenAPI ModelEntity του Fish Audio, επιτρέποντας τη μετάβαση του υπάρχοντος κώδικα διαχείρισης κλωνοποιημένων φωνών χωρίς καμία αλλαγή. Το δημιουργημένο `_id` μπορεί να χρησιμοποιηθεί απευθείας ως τιμή του πεδίου `reference_id` στο [Fish TTS API](https://platform.acedata.cloud/documents/77adcb84-d59f-5ef9-b8a0-8b35eb42a71d) για σύνθεση φωνής.
