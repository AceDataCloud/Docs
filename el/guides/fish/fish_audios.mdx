Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο σύνδεσης με το Fish Audios Generation API, το οποίο μπορεί να κλωνοποιήσει τη φωνή σας μέσω εισαγωγής προτροπών.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [Fish Audios Generation API](https://platform.acedata.cloud/documents/e681b715-54fd-4464-a59a-d7f14500e095) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να χρησιμοποιήσετε το API δωρεάν.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε την προτροπή `prompt`, τη δράση `action`, το ID φωνής `voice_id` και το μοντέλο `model`, για να λάβετε το επεξεργασμένο αποτέλεσμα. Πρώτα, πρέπει να περάσετε ένα πεδίο `action`, της οποίας η τιμή είναι `generate`, και στη συνέχεια πρέπει να εισάγουμε το μοντέλο `model`, το οποίο είναι κυρίως το μοντέλο `fish-tts`, με τις λεπτομέρειες όπως παρακάτω:

<p><img src="https://cdn.acedata.cloud/0jnfqb.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `model`: το μοντέλο κλωνοποίησης φωνής, κυρίως το μοντέλο `fish-tts`.
- `action`: η δράση της τρέχουσας κλωνοποίησης φωνής.
- `prompt`: η προτροπή που χρειάζεται να κλωνοποιηθεί.
- `voice_id`: το ID φωνής για την κλωνοποίηση.
- `callback_url`: το URL για την επιστροφή αποτελεσμάτων.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/8uyos2.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να δοκιμάσετε, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "success": true,
  "task_id": "5872ab00-3cf4-4040-a798-8510aaa16756",
  "trace_id": "5eda3694-448a-4b72-af33-2acb3851ffe1",
  "data": [
    {
      "audio_url": "https://platform.r2.fish.audio/task/8a72ff9840234006a9f74cb2fa04f978.mp3"
    }
  ]
}
```

Η επιστροφή αποτελεσμάτων περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `success`, η κατάσταση της τρέχουσας κλωνοποίησης φωνής.
  - `data`, το αποτέλεσμα της κλωνοποίησης φωνής
    - `audio_url`, το αποτέλεσμα του συνδέσμου ήχου της τρέχουσας κλωνοποίησης φωνής.

Μπορείτε να δείτε ότι έχουμε λάβει ικανοποιητικές πληροφορίες ήχου, απλά πρέπει να αποκτήσουμε τη φωνή που κλωνοποιήθηκε σύμφωνα με τη διεύθυνση του μουσικού συνδέσμου στο `data`.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο παρακάτω κώδικας CURL:

```shell
curl -X POST 'https://api.acedata.cloud/fish/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "speech",
  "prompt": "a white siamese cat",
  "model": "fish-tts",
  "voice_id": "d7900c21663f485ab63ebdb7e5905036"
}'
```

## Ασύγχρονη Επιστροφή

Δεδομένου ότι ο χρόνος δημιουργίας του Fish Audios Generation API είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, εάν το API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος. Έτσι, αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη επιστροφή.

Η συνολική διαδικασία είναι: όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`. Μετά την υποβολή του αιτήματος API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα που περιλαμβάνει ένα πεδίο `task_id`, το οποίο αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα της δημιουργίας θα αποσταλεί μέσω POST JSON στη διεύθυνση `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε αυτό μέσω ενός παραδείγματος.

Αρχικά, η επιστροφή Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα, οι προγραμματιστές θα πρέπει να την αντικαταστήσουν με το URL του HTTP διακομιστή που έχουν δημιουργήσει. Για ευκολία, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να λάβετε ένα Webhook URL, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/tbcnai.png)

Αντιγράψτε αυτό το URL και μπορείτε να το χρησιμοποιήσετε ως Webhook, το παράδειγμα εδώ είναι `https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34`.

Στη συνέχεια, μπορούμε να ρυθμίσουμε το πεδίο `callback_url` στο παραπάνω Webhook URL, ενώ συμπληρώνουμε τα αντίστοιχα παραμέτρους, οι λεπτομέρειες είναι όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/8rv4te.png" width="500" className="m-auto" /></p>

Κάντε κλικ για εκτέλεση και μπορείτε να δείτε ότι θα λάβετε αμέσως ένα αποτέλεσμα, όπως παρακάτω:

```
{
  "task_id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5"
}
```

Μετά από λίγο, μπορείτε να παρακολουθήσετε το αποτέλεσμα της δημιουργίας εργασίας στο `https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34`, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/9utzve.png)

Το περιεχόμενο είναι ως εξής:

```json
{
    "success": true,
    "task_id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5",
    "trace_id": "e2d308bc-4df8-4c69-9369-a60f3c54f2b3",
    "data": [
        {
            "audio_url": "https://platform.r2.fish.audio/task/b627c2f7d38a4083a837570ba6d0962f.mp3"
        }
    ]
}
```

Μπορείτε να δείτε ότι το αποτέλεσμα περιλαμβάνει ένα πεδίο `task_id`, τα υπόλοιπα πεδία είναι παρόμοια με τα παραπάνω, και μέσω αυτού του πεδίου μπορείτε να συσχετίσετε την εργασία.

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές κλειδί εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
