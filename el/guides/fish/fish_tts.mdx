Αυτό το API παρέχει μετατροπή κειμένου σε ομιλία, κλήση αποθηκευμένων φωνών και εφάπαξ άμεση κλωνοποίηση φωνής, στη διεύθυνση `POST https://api.acedata.cloud/fish/tts`.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Fish TTS API, αποκτήστε πρώτα το API Token σας από την [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να απαιτείται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση παρέχει δωρεάν υπόλοιπο για δωρεάν δοκιμή· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να φορτίσετε το γενικό υπόλοιπο από την [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Fish TTS API →](https://platform.acedata.cloud/services/fish)

## Κεφαλίδες αιτήματος

| Header          | Υποχρεωτικό  | Περιγραφή                                                                                                     |
| --------------- | --- | ------------------------------------------------------------------------------------------------------ |
| `authorization` | Ναι   | `Bearer {token}`，το `{token}` είναι το κλειδί που αποκτήθηκε σε αυτήν την πλατφόρμα。                                                                 |
| `content-type`  | Ναι   | `application/json`。                                                                                    |
| `accept`        | Όχι   | `application/json`。                                                                                    |
| `model`         | Όχι   | Μοντέλο TTS, διαθέσιμες επιλογές `s1`、`s2-pro` ή `s2.1-pro`, προεπιλογή `s2-pro`。Το `s2.1-pro` είναι η νεότερη γενιά, το `s2-pro` έχει ισχυρή εκφραστικότητα· το `s1` είναι πιο σταθερό και λιγότερο επιρρεπές σε αποκλίσεις σε μεγάλα κείμενα。Και τα τρία έχουν την ίδια τιμή。 |

## Πεδία σώματος αιτήματος

| Πεδίο             | Τύπος                 | Υποχρεωτικό  | Περιγραφή                                                                                                                                                                                                     |
| -------------- | ------------------ | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `text`         | string             | Ναι   | Το κείμενο προς σύνθεση, μη κενή συμβολοσειρά。                                                                                                                                                                                          |
| `format`       | string             | Όχι   | Μορφή εξαγόμενου ήχου, διαθέσιμες επιλογές `mp3`（προεπιλογή）、`wav`、`pcm`。Τα `wav` και `pcm` επιστρέφουν και τα δύο δοχείο WAV。Το `opus` δεν υποστηρίζεται και η εισαγωγή του επιστρέφει απευθείας `400`。                                                                                                                  |
| `reference_id` | string \| string[] | Όχι   | ID μοντέλου αποθηκευμένης ή δημόσιας φωνής, το οποίο μπορεί να δημιουργηθεί μέσω του [Fish Model API](https://platform.acedata.cloud/documents/fish-model) ή να αναζητηθεί στο [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)。Δεν μπορεί να χρησιμοποιηθεί ταυτόχρονα με το `references`。 |
| `references`   | object[]           | Όχι   | Εφάπαξ άμεση κλωνοποίηση φωνής, υποστηρίζει μόνο ένα δείγμα `{audio, text}`: το `audio` είναι δημόσιο HTTPS MP3/WAV URL και το `text` είναι η ακριβής κατά λέξη απομαγνητοφώνηση του ήχου。Δεν μπορεί να χρησιμοποιηθεί ταυτόχρονα με το `reference_id`。                                                                                             |
| `sample_rate`  | integer            | Όχι   | Ρυθμός δειγματοληψίας, συνήθεις τιμές `16000`、`22050`、`44100`。Το `format=mp3` έχει προεπιλογή 44100。                                                                                                                                                  |
| `mp3_bitrate`  | integer            | Όχι   | Ρυθμός bit MP3, διαθέσιμες επιλογές `64`、`128`、`192`。Ισχύει μόνο για `format=mp3`。                                                                                                                                                          |
| `prosody`      | object             | Όχι   | Παράκαμψη προσωδίας, υποστηρίζει `speed`（ταχύτητα ομιλίας, 1.0 είναι η αρχική ταχύτητα）και `volume`（ενίσχυση έντασης dB）。Για παράδειγμα `{"speed":1.2,"volume":0}`。                                                                                                                          |
| `chunk_length` | integer            | Όχι   | Μήκος τμήματος ανάντη, καθορίζεται από ανάντη από προεπιλογή。                                                                                                                                                                                         |
| `temperature`  | number             | Όχι   | Θερμοκρασία δειγματοληψίας, εύρος περίπου 0.0–1.0。                                                                                                                                                                                      |
| `top_p`        | number             | Όχι   | Παράμετρος δειγματοληψίας top-p。                                                                                                                                                                                            |
| `latency`      | string             | Όχι   | `normal` ή `balanced`, αν παραλειφθεί το API συμπληρώνει αυτόματα `normal`（η άμεση αποστολή κενής συμβολοσειράς θα απορριφθεί από ανάντη）。                                                                                                                                                |
| `normalize`    | boolean            | Όχι   | Αν θα γίνει κανονικοποίηση του κειμένου。                                                                                                                                                                                             |
| `callback_url` | string             | Όχι   | Διεύθυνση ασύγχρονης επανάκλησης, δείτε παρακάτω «Ασύγχρονη επανάκληση»。**Αυτή είναι επέκταση σε σχέση με το επίσημο API**。                                                                                                                                                                     |

> Η εφάπαξ κλωνοποίηση δέχεται μόνο HTTPS URL ήχου, και δεν δέχεται MessagePack、Base64、data URI ή URL με διαπιστευτήρια。Ο προτεινόμενος ήχος αναφοράς είναι 10–270 δευτερόλεπτα· το Studio χρησιμοποιεί το πιο συντηρητικό εύρος 10–60 δευτερολέπτων。

## Παράδειγμα 1: Ελάχιστο αίτημα（`text` + `format=mp3`）

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hello world.",
    "format": "mp3"
  }'
```

Επιστροφή（δοκιμασμένο）：

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/e2ffcc06-18da-4a8c-b9aa-9337d0f9ec1d-230825dfc559.mp3"
}
```

Το `audio_url` δείχνει στο CDN αυτής της πλατφόρμας και μπορεί να ληφθεί απευθείας με GET ή να αναπαραχθεί σε `<audio>`。Η τελική επιτυχής απόκριση επιστρέφει επίσης κορυφαίου επιπέδου `cost`, όπου το `amount` είναι τα Credits που αφαιρέθηκαν πραγματικά αυτή τη φορά· αν υπάρχει έκπτωση λογαριασμού, το `list_amount` υποδεικνύει το υπόλοιπο πριν από την έκπτωση。Ο σύνδεσμος παραμένει διαθέσιμος μακροπρόθεσμα, αλλά εξακολουθεί να συνιστάται να διατηρείτε ένα αντίγραφο στον δικό σας χώρο αποθήκευσης。

## Παράδειγμα 2: Χρήση κλωνοποιημένου χρώματος φωνής `reference_id`

Παρακάτω χρησιμοποιείται ένα δημόσιο ισπανικό χρώμα φωνής στην πλατφόρμα Fish（το `_id` μπορεί να ληφθεί μέσω αναζήτησης στο [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)）：

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

Επιστροφή（δοκιμασμένο）：

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/b6f161f2-a100-4818-add2-47694f234659-6532864739de.mp3"
}
```

## Παράδειγμα 3: Εφάπαξ άμεση κλωνοποίηση φωνής（`references`）

Τοποθετήστε τον ήχο αναφοράς σε δημόσια διεύθυνση HTTPS και παρέχετε το ακριβές πρωτότυπο κείμενο που εκφωνείται σε αυτόν。Αυτή η φωνή χρησιμοποιείται μόνο για την τρέχουσα σύνθεση και δεν θα δημιουργήσει μακροχρόνιο μοντέλο：

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s2-pro' \
  -d '{
    "text": "新的旅程从这一刻开始，让我们一起向前。",
    "format": "mp3",
    "references": [{
      "audio": "https://cdn.acedata.cloud/assets/examples/fish/6220d605-39d0-4d43-9e58-0f12949dc9b9-570cfdf96ad9.mp3",
      "text": "春天的清晨，阳光穿过树叶，落在安静的小路上。"
    }]
  }'
```
Επιτυχής απόκριση από πραγματική δοκιμή:

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/995dfe37-b187-474d-8323-b08d6678ed8f-6359be9f8873.mp3",
  "cost": {"amount": 0.007609319999999999, "currency": "credit"}
}
```

| Τρόπος             | Κύκλος ζωής       | Εφαρμόσιμο σενάριο                          |
| -------------- | ---------- | ----------------------------- |
| `references`   | Μόνο για το τρέχον αίτημα TTS | Προσωρινή χρήση ή διαφορετική φωνή κάθε φορά                   |
| `reference_id` | Επαναχρησιμοποιήσιμο      | Δημόσιες φωνές ή μακροχρόνιες φωνές που δημιουργούνται μέσω του `/fish/model` |

## Παράδειγμα 3: Ρύθμιση ταχύτητας ομιλίας / έντασης (`prosody`)

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Faster speech with prosody overrides.",
    "prosody": { "speed": 1.2, "volume": 0 },
    "format": "mp3"
  }'
```

Επιστρέφει (πραγματική δοκιμή):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
}
```

Το `speed` μεγαλύτερο από 1 επιταχύνει, μικρότερο από 1 επιβραδύνει· η μονάδα του `volume` είναι dB, το 0 σημαίνει καμία αλλαγή, οι θετικοί αριθμοί ενίσχυση και οι αρνητικοί εξασθένηση.

## Παράδειγμα 5: Αλλαγή μοντέλου + έλεγχος ρυθμού bit

Αλλάξτε στο μοντέλο σταθερού τύπου μέσω της κεφαλίδας HTTP `model: s1`, και προσθέστε `mp3_bitrate: 128` στο σώμα του αιτήματος για να ελέγξετε τον ρυθμό bit MP3:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s1' \
  -d '{
    "text": "high bitrate mp3",
    "format": "mp3",
    "mp3_bitrate": 128
  }'
```

Επιστρέφει (πραγματική δοκιμή):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/7e7abf3d-3d72-4c9f-8eb6-8af932d7c96e-6f11bf2f30e9.mp3"
}
```

## Παράδειγμα 6: Ακατέργαστη κυματομορφή PCM

Για σενάρια όπου απαιτείται σύνθεση σε πραγματικό χρόνο στο πρόγραμμα περιήγησης ή μεταγενέστερη επεξεργασία στον πελάτη (μίξη, αλλαγή ταχύτητας), συνιστάται η χρήση `pcm`:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "hi",
    "format": "pcm",
    "sample_rate": 16000
  }'
```

Επιστρέφει (πραγματική δοκιμή):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/64adc04b-c196-4a0f-9070-222ba101ce6c-fc50de38c165.wav"
}
```

> Η επέκταση του συνδέσμου ακολουθεί το `format` στο αίτημα: το `mp3` δίνει `.mp3`, ενώ τα `wav` και `pcm` δίνουν `.wav` (κοντέινερ WAV, 16 bit PCM).

## Ασύγχρονη επανάκληση (`callback_url`)

Η σύνθεση μεγάλου κειμένου με μία φορά ενδέχεται να απαιτεί από δέκα έως δεκάδες δευτερόλεπτα· εάν η σύνδεση διακοπεί, απαιτείται επανάληψη. Αφού περάσετε `callback_url` στο σώμα του αιτήματος, η διεπαφή θα επιστρέψει αμέσως `{task_id, started_at}`. Όταν η διεργασία ανάντη ολοκληρωθεί πραγματικά, θα στείλει μέσω επανάκλησης το πλήρες αποτέλεσμα σε μορφή POST JSON σε αυτό το URL, με το ίδιο `task_id` και το τελικό κορυφαίου επιπέδου `cost` που χρεώνεται για αυτή τη φορά στο σώμα του αιτήματος. Η αρχική επιβεβαίωση εργασίας δεν έχει ακόμη ολοκληρώσει τη σύνθεση, επομένως δεν περιλαμβάνει `cost`.

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "今天天气真好，我们一起出去散散步吧。",
    "format": "mp3",
    "callback_url": "https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34"
  }'
```

Επιστρέφει αμέσως (πραγματική δοκιμή):

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "started_at": 1778462584.742
}
```

Λίγο αργότερα, το `callback_url` θα λάβει κάτι της μορφής:

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/bd66b8c5-7543-4557-b684-baa72407e336-52f2e79732f2.mp3"
}
```

Μπορείτε επίσης να χρησιμοποιήσετε το [Fish Tasks API](https://platform.acedata.cloud/documents/fish-tasks) για να ανακτήσετε ενεργά το αποτέλεσμα με βάση το `task_id`· το `response.cost` της εγγραφής τελικής κατάστασης είναι συνεπές με το `cost` στην επανάκληση, δείτε το έγγραφο για λεπτομέρειες.

## Χειρισμός σφαλμάτων

- `400 token_mismatched`: Οι παράμετροι του αιτήματος λείπουν ή δεν είναι έγκυρες (συνηθέστερα το `text` είναι κενό ή το `format` έχει τιμή άλλη από `mp3`/`wav`/`pcm`).
- `401 invalid_token`: Το token ελέγχου ταυτότητας δεν υπάρχει ή δεν είναι έγκυρο.
- `429 too_many_requests`: Ενεργοποιήθηκε ο περιορισμός ρυθμού του λογαριασμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.

Παράδειγμα απόκρισης σφάλματος:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

Τα σφάλματα επικύρωσης παραμέτρων θα αναφέρουν το μη έγκυρο πεδίο στο πεδίο `message`, για παράδειγμα:

```json
{
  "status": 400,
  "message": "[{\"type\":\"literal_error\",\"loc\":[\"format\"],\"msg\":\"Input should be 'pcm' or 'mp3'\",\"input\":\"wav\"}]"
}
```

## Συμπέρασμα

Το ελάχιστο κόστος για την ενσωμάτωση του Fish TTS είναι: στον υπάρχοντα κώδικα που καλεί `api.fish.audio/v1/tts`, αντικαταστήστε τον έλεγχο ταυτότητας με το token αυτής της πλατφόρμας και συμπεριλάβετε **ρητά** `format: "mp3"` στο σώμα του αιτήματος. Για σενάρια μεγάλου κειμένου, συνιστάται η ασύγχρονη επανάκληση `callback_url`· για την ανακάλυψη του `reference_id` της κλωνοποιημένης χροιάς φωνής, χρησιμοποιήστε σε συνδυασμό τα [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) και [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get).
