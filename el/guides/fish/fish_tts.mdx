Αυτό το έγγραφο παρουσιάζει τις οδηγίες ενσωμάτωσης του Fish TTS API, το οποίο είναι πλήρως συμβατό με το [επίσημο OpenAPI του Fish Audio](https://docs.fish.audio/text-to-speech/text-to-speech). Μπορείτε να μεταφέρετε απευθείας τον υπάρχοντα κώδικα που καλεί το `https://api.fish.audio/v1/tts` στο `https://api.acedata.cloud/fish/tts`, απλά αντικαθιστώντας τα στοιχεία πιστοποίησης, χωρίς να χρειάζεται να τροποποιήσετε τη δομή του αιτήματος.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να κάνετε αίτηση για την αντίστοιχη υπηρεσία στη σελίδα του [Fish TTS API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509). Μετά την είσοδο στη σελίδα, κάντε κλικ στο κουμπί «Acquire».

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά τη σύνδεση ή εγγραφή, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση παρέχεται δωρεάν όριο χρήσης, επιτρέποντας τη δωρεάν χρήση του API.

## Διαφορές από το Επίσημο API

Αυτό το API διατηρεί τα πεδία αιτήσεων και απαντήσεων του επίσημου Fish Audio, προσθέτοντας μικρές βελτιώσεις για καλύτερη ενσωμάτωση στην πλατφόρμα μας:

- **Μέθοδος Πιστοποίησης**: Χρησιμοποιεί `Authorization: Bearer {token}`, όπου το `{token}` είναι το κλειδί που αποκτάτε από την πλατφόρμα μας και όχι το επίσημο κλειδί του Fish.
- **Επιλογή Μοντέλου TTS**: Καθορίζεται μέσω της κεφαλίδας HTTP `model`, με επιλογές `s1` ή `s2-pro`, προεπιλεγμένο το `s2-pro`. Αυτό είναι σύμφωνο με το επίσημο Fish.
- **Προεπιλεγμένη Τιμή `latency`**: Το upstream `/fish/v1/tts` επιστρέφει σφάλμα αν δεν δοθεί `latency`. Αυτό το API συμπληρώνει αυτόματα `latency=normal` αν λείπει, διατηρώντας τη συμπεριφορά του Fish.
- **Ασύγχρονη Επιστροφή Κλήσης (Επέκταση Πλατφόρμας)**: Αν στο σώμα του αιτήματος δοθεί επιπλέον πεδίο `callback_url`, το API επιστρέφει άμεσα `{task_id, started_at}` και όταν ολοκληρωθεί η επεξεργασία, στέλνει το πλήρες αποτέλεσμα `{audio_url, ...}` με POST JSON στο URL αυτό. Το επίσημο API δεν υποστηρίζει αυτό το πεδίο και η χρήση του ενεργοποιεί μόνο τη δική μας ασύγχρονη διαδικασία.

Εκτός από τις παραπάνω διαφορές, όλα τα πεδία στο σώμα του αιτήματος TTS (`text`, `reference_id`, `references`, `prosody`, `format`, `sample_rate`, `mp3_bitrate`, `chunk_length`, `temperature`, `top_p` κ.ά.) προωθούνται απευθείας στο upstream, με συμπεριφορά πλήρως συμβατή με την επίσημη τεκμηρίωση.

## Βασική Χρήση

Το ελάχιστο αίτημα απαιτεί μόνο το πεδίο `text`. Παράδειγμα CURL:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s2-pro' \
  -d '{
    "text": "今天天气真好，我们一起出去散散步吧。"
  }'
```

Παράδειγμα απάντησης:

```json
{
  "audio_url": "https://platform.r2.fish.audio/task/8a72ff9840234006a9f74cb2fa04f978.mp3"
}
```

Η απάντηση περιλαμβάνει τα επίσημα πεδία του Fish, όπως:

- `audio_url`: URL του παραγόμενου ήχου, διαθέσιμο για άμεση λήψη ή αναπαραγωγή.
- `latency_ms` (προαιρετικό): Χρόνος επεξεργασίας upstream σε χιλιοστά του δευτερολέπτου.

Για χρήση κλωνοποιημένης φωνής, προσθέστε το `reference_id` στο σώμα του αιτήματος:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s2-pro' \
  -d '{
    "text": "今天天气真好，我们一起出去散散步吧。",
    "reference_id": "d7900c21663f485ab63ebdb7e5905036",
    "format": "mp3",
    "sample_rate": 44100
  }'
```

## Ασύγχρονη Επιστροφή Κλήσης

Επειδή η παραγωγή ήχου για μεγάλα κείμενα μπορεί να διαρκέσει, η διατήρηση μακροχρόνιας σύνδεσης καταναλώνει πόρους συστήματος. Αυτό το API παρέχει δυνατότητα ασύγχρονης επιστροφής κλήσης (επέκταση σε σχέση με το επίσημο Fish).

Η διαδικασία είναι η εξής: ο πελάτης προσθέτει το πεδίο `callback_url` στο σώμα του αιτήματος. Το API επιστρέφει άμεσα απάντηση με `task_id`. Όταν ολοκληρωθεί η παραγωγή, το τελικό αποτέλεσμα (`audio_url` κ.ά.) αποστέλλεται με POST JSON στο `callback_url`, περιλαμβάνοντας το ίδιο `task_id` για συσχέτιση.

Παράδειγμα αιτήματος:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s2-pro' \
  -d '{
    "text": "今天天气真好，我们一起出去散散步吧。",
    "callback_url": "https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34"
  }'
```

Άμεση απάντηση:

```json
{
  "task_id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5",
  "started_at": "2025-05-09T12:34:56.789Z"
}
```

Μετά από λίγο, το `callback_url` θα λάβει το πλήρες αποτέλεσμα:

```json
{
  "task_id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5",
  "audio_url": "https://platform.r2.fish.audio/task/b627c2f7d38a4083a837570ba6d0962f.mp3"
}
```

Εναλλακτικά, μπορείτε να χρησιμοποιήσετε το [Fish Tasks API](https://platform.acedata.cloud/documents/fc541fac-a941-47fd-b6f7-48d6cb9da523) για ενεργό polling της κατάστασης εργασίας μέσω `task_id`.

## Διαχείριση Σφαλμάτων

Η απάντηση σφαλμάτων διατηρεί τους επίσημους HTTP κωδικούς του Fish, αλλά το σώμα απάντησης χρησιμοποιεί ενιαίο φορμάτ της πλατφόρμας για συνέπεια με τις σειρές `/fish/audios` και `/fish/voices`:

- `400 token_mismatched`: Κακό αίτημα, πιθανόν λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακό αίτημα, πιθανόν λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`: Πολύ μεγάλο πλήθος αιτήσεων, υπερβήκατε το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.

### Παράδειγμα Απάντησης Σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Συμπέρασμα

Το Fish TTS API είναι πλήρως συμβατό με το επίσημο OpenAPI του Fish Audio, επιτρέποντας τη μετάβαση σε υπάρχοντα έργα χωρίς αλλαγές στον κώδικα, ενώ παράλληλα παρέχει ενιαία πιστοποίηση, καταγραφή χρήσης και δυνατότητα ασύγχρονης επιστροφής κλήσης. Συνιστάται η χρήση ασύγχρονης επιστροφής για μεγάλα κείμενα, ώστε να αποφευχθεί η κατανάλωση πόρων από μακροχρόνιες συνδέσεις.
