Αυτό το έγγραφο παρουσιάζει τις οδηγίες ενσωμάτωσης για το Fish Model Get API (`GET /fish/model/{id}`), το οποίο είναι πλήρως συμβατό με το [επίσημο OpenAPI του Fish Audio](https://docs.fish.audio/resources/api-reference/model) και χρησιμοποιείται για **την ανάκτηση πλήρων λεπτομερειών ενός μεμονωμένου κλωνοποιημένου ηχητικού προφίλ βάσει του ID του ήχου**.

> Για τη δημιουργία ηχητικού προφίλ, ανατρέξτε στο [Fish Model Create API](https://platform.acedata.cloud/documents/62fdf4f1-6a05-4d92-bb15-1bf78b27a14a), και για σελιδοποιημένη λίστα αναζήτησης, δείτε το [Fish Model Query API](https://platform.acedata.cloud/documents/5a9b3e03-2896-5606-a6b9-d9f4469f0e9d).

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να κάνετε αίτηση για την αντίστοιχη υπηρεσία στη σελίδα [Fish Model API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509). Αφού μπείτε στη σελίδα, πατήστε το κουμπί «Acquire».

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά τη σύνδεση ή εγγραφή, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, παρέχεται δωρεάν όριο χρήσης, επιτρέποντας τη δωρεάν χρήση του API.

## Διαφορές από το Επίσημο API

- **Μέθοδος Πιστοποίησης**: Χρησιμοποιείται `Authorization: Bearer {token}`, όπου το `{token}` είναι το κλειδί που αποκτήθηκε από την πλατφόρμα μας.
- **Δομή Απάντησης**: Μεταβιβάζεται απευθείας το αντικείμενο ModelEntity από το Fish upstream, χωρίς περιτύλιγμα (envelope) της πλατφόρμας. Σε περίπτωση σφάλματος, χρησιμοποιείται η τυπική δομή της πλατφόρμας `{success:false, error:{code,message}, trace_id}`.
- **Παράμετροι Διαδρομής**: Το `{id}` είναι το `_id` του ηχητικού προφίλ, το οποίο επιστρέφεται κατά τη δημιουργία μέσω του [Fish Model Create API](https://platform.acedata.cloud/documents/62fdf4f1-6a05-4d92-bb15-1bf78b27a14a) ή λαμβάνεται μέσω σελιδοποιημένης αναζήτησης από το [Fish Model Query API](https://platform.acedata.cloud/documents/5a9b3e03-2896-5606-a6b9-d9f4469f0e9d).

## Παράδειγμα Αιτήματος

```shell
curl 'https://api.acedata.cloud/fish/model/d7900c21663f485ab63ebdb7e5905036' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}'
```

Απλά αντικαταστήστε το `{id}` στη διαδρομή URL με το συγκεκριμένο ID του ηχητικού προφίλ. Δεν απαιτούνται παράμετροι ερωτήματος ή σώμα αιτήματος.

## Πληροφορίες Χρέωσης

Αυτό το API δεν χρεώνεται — η ανάκτηση λεπτομερειών ηχητικού προφίλ μέσω ID είναι δωρεάν λειτουργία. Χρέωση γίνεται μόνο στο `POST /fish/model` όταν δημιουργείται νέο ηχητικό προφίλ με το πεδίο `voices` στο σώμα του αιτήματος.

## Διαχείριση Σφαλμάτων

- `400 token_mismatched`: Λείπουν ή είναι μη έγκυρες παράμετροι αιτήματος.
- `400 api_not_implemented`: Ο τρέχων τρόπος αιτήματος ή παράμετροι δεν υποστηρίζονται.
- `401 invalid_token`: Λείπει ή είναι άκυρη η πληροφορία πιστοποίησης.
- `404 not_found`: Το συγκεκριμένο `_id` δεν υπάρχει ή δεν είναι ορατό στον τρέχοντα λογαριασμό.
- `429 too_many_requests`: Υπερβλήθηκε το όριο ρυθμού του τρέχοντος λογαριασμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.

## Συμπέρασμα

Το Fish Model Get API παρέχει πλήρη συμβατότητα με το επίσημο Fish Audio για την ανάκτηση λεπτομερειών ενός μεμονωμένου ηχητικού προφίλ. Αφού λάβετε το ID του ηχητικού προφίλ, μπορείτε να χρησιμοποιήσετε αυτό το API για να αντλήσετε το πλήρες αντικείμενο ModelEntity (συμπεριλαμβανομένων δειγμάτων, κατάστασης, ορατότητας, στατιστικών πεδίων κ.ά.) και στη συνέχεια να ολοκληρώσετε τη διαδικασία κλωνοποίησης και σύνθεσης φωνής με το [Fish TTS API](https://platform.acedata.cloud/documents/77adcb84-d59f-5ef9-b8a0-8b35eb42a71d).
