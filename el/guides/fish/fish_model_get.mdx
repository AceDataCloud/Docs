Αυτή η διεπαφή βασίζεται στο [Fish Audio επίσημο Model API](https://docs.fish.audio/resources/api-reference/model) και χρησιμοποιείται για **να αναζητήσετε τις πλήρεις λεπτομέρειες ενός κλώνου ήχου με βάση το `_id`**. Η διεύθυνση είναι `GET https://api.acedata.cloud/fish/model/{id}`.

> Για τη δημιουργία ήχου, ανατρέξτε στο [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model)· για αναζήτηση με σελίδες, ανατρέξτε στο [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query).

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Fish Model API, πρώτα επισκεφθείτε το [Ace Data Cloud κονσόλα](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη σελίδα που βρίσκεστε.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πίστωση για να δοκιμάσετε· όταν η πίστωση εξαντληθεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Παράμετροι Διαδρομής

| Παράμετρος | Υποχρεωτική | Περιγραφή                                                                                                                                                                                                |
| --------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`      | Ναι      | Το `_id` του ήχου (32-ψηφιαία δεκαεξαδική συμβολοσειρά). Μπορεί να επιστραφεί κατά τη δημιουργία μέσω του [Fish Model Create](https://platform.acedata.cloud/documents/fish-model) ή να ανακτηθεί μέσω του [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query). |

Χωρίς σώμα αιτήματος, χωρίς παραμέτρους ερωτήματος.

## Παράδειγμα: Ανάκτηση πλήρων λεπτομερειών ενός δημόσιου ισπανικού ήχου

```shell
curl 'https://api.acedata.cloud/fish/model/8d2c17a9b26d4d83888ea67a1ee565b2' \
  -H 'authorization: Bearer {token}'
```

Το `_id` που αποκτήθηκε μπορεί να δοθεί απευθείας στο `reference_id` του [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) για να συνθέσετε φωνή με τον ίδιο ήχο:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

## Διαφορές με τη διεπαφή λίστας

| Πεδίο                                               | `GET /fish/model` (λίστα) | `GET /fish/model/{id}` (λεπτομέρειες) |
| -------------------------------------------------- | --------------------- | -------------------------- |
| `samples[].audio`                                  | Βραχυπρόθεσμος R2 cache URL          | Άμεσος σύνδεσμος R2 (με υπογραφή query)      |
| `unliked` / `liked` / `marked` / `dmca_taken_down` | Υπάρχουν επίσης                  | Υπάρχουν επίσης                       |
| `default_text` / `lock_visibility`                 | Υπάρχουν επίσης                  | Υπάρχουν επίσης                       |

Εάν απλώς θέλετε να ακούσετε, το `samples[].audio` στη διεπαφή λίστας είναι ήδη αρκετό· για πιο σταθερούς συνδέσμους λήψης, προτείνεται να χρησιμοποιήσετε αυτή τη διεπαφή.

## Πεδίο απάντησης (αποσπάσματα)

| Πεδίο            | Τύπος       | Περιγραφή                                          |
| ------------- | -------- | ------------------------------------------- |
| `_id`         | string   | ID ήχου (χρησιμοποιείται για το `/fish/tts` `reference_id`).     |
| `type`        | string   | Τύπος μοντέλου, συνήθως `tts`.                             |
| `title`       | string   | Όνομα ήχου.                                       |
| `description` | string   | Μακρά περιγραφή.                                        |
| `state`       | string   | Κατάσταση εκπαίδευσης: `trained` σημαίνει διαθέσιμο, `training` σημαίνει ότι είναι ακόμα σε εκπαίδευση.      |
| `tags`        | string[] | Ετικέτες δημόσιας βιβλιοθήκης.                                      |
| `samples`     | object[] | Προεπιλεγμένα δείγματα, περιλαμβάνοντας `title`, `text`, `task_id`, `audio` άμεσους συνδέσμους. |
| `languages`   | string[] | Κωδικοί γλωσσών που ειδικεύεται ο ήχος.                                  |
| `visibility`  | string   | `public` ή `private`.                       |
| `like_count`  | integer  | Αριθμός "μου αρέσει" στη δημόσια βιβλιοθήκη.                                     |
| `task_count`  | integer  | Ιστορικός αριθμός συνθέσεων (μπορεί να χρησιμοποιηθεί για αναφορά δημοτικότητας).                          |
| `author`      | object   | Πληροφορίες συγγραφέα: `_id` / `nickname` / `avatar`.       |
| `created_at`  | string   | ISO 8601 ημερομηνία δημιουργίας.                              |
| `updated_at`  | string   | ISO 8601 ημερομηνία τελευταίας ενημέρωσης.                            |

## Σημείωση Χρέωσης

Αυτή η διεπαφή δεν χρεώνεται — η αναζήτηση λεπτομερειών ενός ήχου με βάση το ID είναι δωρεάν λειτουργία. Η δημιουργία ήχου ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) είναι επίσης δωρεάν, οι χρεώσεις προκύπτουν μόνο κατά την κλήση του [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) για τη σύνθεση φωνής.

## Διαχείριση Σφαλμάτων
- `400 token_mismatched`：Το `id` στη διαδρομή δεν είναι έγκυρη μορφή ή η ανώτερη αναφορά λέει «Μοντέλο δεν βρέθηκε».
- `401 invalid_token`：Το token εξουσιοδότησης δεν υπάρχει ή είναι άκυρο.
- `404 not_found`：Το καθορισμένο `_id` δεν είναι ορατό στην ανώτερη αναφορά Fish (ο ήχος έχει διαγραφεί, είναι ιδιωτικός ή ανήκει σε άλλο λογαριασμό).
- `429 too_many_requests`：Ενεργοποιήθηκε ο περιορισμός ρυθμού του λογαριασμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή.

Όταν ζητείται ένα ανύπαρκτο ID, η ανώτερη αναφορά επιστρέφει άμεσα `400 Model not found` (δοκιμασμένο):

```shell
curl 'https://api.acedata.cloud/fish/model/test123' \
  -H 'authorization: Bearer {token}'
```

Επιστροφή:

```json
{ "status": 400, "message": "Model not found" }
```

Παράδειγμα σφάλματος απόκρισης:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Συμπέρασμα

Γνωρίζοντας το `_id` του ήχου, χρησιμοποιήστε απευθείας αυτή τη διεπαφή για να αποκτήσετε το πλήρες ModelEntity. Οι πιο συχνές χρήσεις είναι: (1) Δοκιμή `samples[].audio`, (2) Δώστε το `_id` στο `reference_id` του `/fish/tts` για να ολοκληρώσετε τη σύνθεση. Εάν έχετε μόνο τίτλο ή ετικέτες, παρακαλώ χρησιμοποιήστε πρώτα την [Αναζήτηση Μοντέλου Fish](https://platform.acedata.cloud/documents/fish-model-query).
