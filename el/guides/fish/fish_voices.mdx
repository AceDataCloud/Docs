Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο σύνδεσης με το Fish Voices Generation API, το οποίο μπορεί να δημιουργήσει τη δική σας φωνή εισάγοντας έναν σύνδεσμο ήχου.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα του [Fish Voices Generation API](https://platform.acedata.cloud/documents/55e61b64-ac7d-4710-a7f1-57a4ba786b17) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις, ώστε να μπορείτε να χρησιμοποιήσετε το API δωρεάν.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τον σύνδεσμο ήχου `voice_url`, για να λάβετε το επεξεργασμένο αποτέλεσμα. Οι λεπτομέρειες είναι οι εξής:

<p><img src="https://cdn.acedata.cloud/278ikr.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: τη μορφή της απάντησης που θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `voice_url`: τον σύνδεσμο ήχου που ανεβάσατε.
- `title`: τις πληροφορίες τίτλου της φωνής.
- `image_urls`: την εικόνα εξωφύλλου της φωνής.
- `description`: τις πληροφορίες περιγραφής της φωνής.
- `callback_url`: τη διεύθυνση URL για την επιστροφή αποτελεσμάτων.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

```shell

-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \

  "title": "test",
  "description": "test"

```

## Ασύγχρονη Επιστροφή

Δεδομένου ότι ο χρόνος δημιουργίας του Fish Voices Generation API είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, εάν το API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος. Έτσι, αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη επιστροφή.

Η συνολική διαδικασία είναι: όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`. Μετά την υποβολή του αιτήματος API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα που περιλαμβάνει ένα πεδίο `task_id`, το οποίο αντιπροσωπεύει το ID της τρέχουσας εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα της δημιουργίας θα αποσταλεί μέσω POST JSON στη διεύθυνση URL `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί με το ID.

Ας δούμε πώς να το κάνουμε αυτό μέσω ενός παραδείγματος.

Αρχικά, η επιστροφή Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα, και οι προγραμματιστές θα πρέπει να την αντικαταστήσουν με τη διεύθυνση URL του HTTP διακομιστή που έχουν δημιουργήσει. Για λόγους ευκολίας, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να λάβετε μια διεύθυνση URL Webhook, όπως φαίνεται στην εικόνα:

## 错误处理

在调用 API 时，如果遇到错误，API 会返回相应的错误代码和信息。例如：

- `400 token_mismatched`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### 错误响应示例

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
