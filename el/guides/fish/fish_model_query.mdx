Αυτό το έγγραφο παρουσιάζει τις οδηγίες ενσωμάτωσης για το Fish Model Query API (`GET /fish/model`), το οποίο είναι πλήρως συμβατό με το [Fish Audio επίσημο OpenAPI](https://docs.fish.audio/resources/api-reference/model) και χρησιμοποιείται για **σελιδοποιημένη αναζήτηση** της λίστας κλωνοποιημένων φωνών που είναι ορατές στον τρέχοντα λογαριασμό ή σε ολόκληρη την πλατφόρμα.

> Για τη δημιουργία φωνών, ανατρέξτε στο [Fish Model Create API](https://platform.acedata.cloud/documents/62fdf4f1-6a05-4d92-bb15-1bf78b27a14a). Για αναζήτηση λεπτομερειών μιας φωνής με βάση το `_id`, δείτε το [Fish Model Get API](https://platform.acedata.cloud/documents/dabdffe7-254b-5a3f-9eca-425d614d82b9).

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να υποβάλετε αίτηση για την αντίστοιχη υπηρεσία στη σελίδα [Fish Model API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509). Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire».

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε ή να συνδεθείτε. Μετά τη σύνδεση ή εγγραφή, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, παρέχεται δωρεάν όριο χρήσης για το API.

## Διαφορές από το Επίσημο API

- **Τρόπος Πιστοποίησης**: Χρησιμοποιείται `Authorization: Bearer {token}`, όπου το `{token}` είναι το κλειδί που αποκτήθηκε από την πλατφόρμα μας.
- **Δομή Απάντησης**: Η σελιδοποιημένη απάντηση από το Fish μεταδίδεται απευθείας χωρίς περιτύλιγμα (envelope) της πλατφόρμας. Σε περίπτωση σφάλματος, χρησιμοποιείται η τυπική δομή της πλατφόρμας `{success:false, error:{code,message}, trace_id}`.

## Παράδειγμα Αιτήματος

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=10' \
  --data-urlencode 'page_number=1' \
  --data-urlencode 'self=true'
```

## Παράμετροι Αναζήτησης

Συμβατές με το επίσημο Fish API:

- `page_size`: Αριθμός εγγραφών ανά σελίδα, προεπιλογή 10.
- `page_number`: Αριθμός σελίδας, ξεκινά από 1.
- `title`: Αναζήτηση με βάση τον τίτλο (ασαφής αναζήτηση).
- `tag`: Φιλτράρισμα με βάση ετικέτες.
- `self`: Εάν περαστεί `true`, επιστρέφονται μόνο οι φωνές που δημιουργήθηκαν από τον τρέχοντα λογαριασμό.
- `author_id`: Φιλτράρισμα με βάση τον δημιουργό.
- `language`: Φιλτράρισμα με βάση τη γλώσσα της φωνής.
- `title_language`: Φιλτράρισμα με βάση τη γλώσσα του τίτλου.

## Παράδειγμα Απάντησης

Η επιτυχημένη απάντηση μεταδίδει απευθείας τη σελιδοποιημένη δομή της πλατφόρμας Fish:

```json
{
  "items": [
    {
      "_id": "d7900c21663f485ab63ebdb7e5905036",
      "title": "我的克隆音色",
      "description": "用一段播客录音克隆的音色",
      "cover_image": "https://example.com/cover.png",
      "type": "tts",
      "state": "trained",
      "tags": [],
      "languages": ["zh", "en"],
      "visibility": "private",
      "created_at": "2025-05-09T12:34:56.789Z",
      "updated_at": "2025-05-09T12:34:56.789Z"
    }
  ],
  "total": 1
}
```

Το επιστρεφόμενο `_id` μπορεί να χρησιμοποιηθεί ως τιμή του πεδίου `reference_id` στο [Fish TTS API](https://platform.acedata.cloud/documents/77adcb84-d59f-5ef9-b8a0-8b35eb42a71d) για σύνθεση φωνής με τη συγκεκριμένη κλωνοποιημένη φωνή.

## Πληροφορίες Χρέωσης

Αυτό το API δεν χρεώνεται — η σελιδοποιημένη αναζήτηση της λίστας φωνών είναι δωρεάν. Μόνο το `POST /fish/model` με το πεδίο `voices` στο σώμα του αιτήματος για δημιουργία νέας φωνής χρεώνεται.

## Διαχείριση Σφαλμάτων

- `400 token_mismatched`: Ελλιπή ή μη έγκυρα παραμέτρους αιτήματος.
- `400 api_not_implemented`: Ο τρόπος αιτήματος ή οι παράμετροι δεν υποστηρίζονται προς το παρόν.
- `401 invalid_token`: Απουσία ή μη έγκυρες πληροφορίες πιστοποίησης.
- `429 too_many_requests`: Υπέρβαση ορίου ρυθμού αιτήσεων του τρέχοντος λογαριασμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.

### Παράδειγμα Απάντησης Σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Συμπέρασμα

Το Fish Model Query API παρέχει πλήρως συμβατή με το επίσημο Fish Audio δυνατότητα αναζήτησης φωνών, επιτρέποντας τη διαχείριση μιας προσωπικής βιβλιοθήκης κλωνοποιημένων φωνών στην πλατφόρμα μας. Σε συνδυασμό με το [Fish Model Get API](https://platform.acedata.cloud/documents/dabdffe7-254b-5a3f-9eca-425d614d82b9), μπορείτε να λάβετε πλήρεις λεπτομέρειες μιας φωνής με βάση το ID.
