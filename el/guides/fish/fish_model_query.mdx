Αυτή η διεπαφή βασίζεται στο [Fish Audio επίσημο Model API](https://docs.fish.audio/resources/api-reference/model) και χρησιμοποιείται για **σελιδοποίηση αναζήτησης της δημόσιας βιβλιοθήκης ήχων Fish ή των κλωνοποιημένων ήχων κάτω από τον τρέχοντα λογαριασμό**. Η διεύθυνση είναι `GET https://api.acedata.cloud/fish/model`.

> Για τη δημιουργία ήχων, ανατρέξτε στο [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model)· για να αναζητήσετε λεπτομέρειες ενός μεμονωμένου ήχου με βάση το `_id`, ανατρέξτε στο [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Fish Model API, πρώτα επισκεφθείτε το [Ace Data Cloud κονσόλα](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε· όταν οι πιστώσεις εξαντληθούν, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Παράμετροι Ερωτήματος

| Παράμετρος       | Τύπος    | Προεπιλογή | Περιγραφή                                  |
| ---------------- | ------- | -------- | --------------------------------------- |
| `page_size`      | integer | 10       | Αριθμός στοιχείων ανά σελίδα.                  |
| `page_number`    | integer | 1        | Αριθμός σελίδας που ξεκινά από το 1.           |
| `title`          | string  | —        | Αναζήτηση με βάση τον τίτλο.                   |
| `tag`            | string  | —        | Φιλτράρισμα με βάση μία ετικέτα.               |
| `self`           | boolean | —        | Όταν είναι `true`, επιστρέφει μόνο τους ήχους που έχει δημιουργήσει ο τρέχων λογαριασμός, χωρίς επιπλέον προϋποθέσεις. |
| `author_id`      | string  | —        | Φιλτράρισμα με βάση το `_id` του ανώτερου χρήστη. |
| `language`       | string  | —        | Φιλτράρισμα με βάση τη γλώσσα του ήχου, όπως `en`, `zh`, `es`. |
| `title_language` | string  | —        | Φιλτράρισμα με βάση τη γλώσσα του τίτλου.       |
| `sort_by`        | string  | —        | Πεδίο ταξινόμησης, όπως `created_at`, `task_count`. |

> Οι ονομασίες παραμέτρων είναι ακριβώς οι ίδιες με αυτές του ανώτερου `GET https://api.fish.audio/model`, δείτε [Fish επίσημη τεκμηρίωση](https://docs.fish.audio/resources/api-reference/model).

## Παράδειγμα 1: Προεπιλεγμένη σελιδοποίηση (με βάση το `page_size`)

```shell

  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=2'
```

## Παράδειγμα 2: Αναζήτηση με βάση τον τίτλο (με `title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Επιστροφή (πραγματική μέτρηση):

```json
{
  "total": 161,
  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",
      "type": "tts",
      "title": "Miles Morales ( Narration Paw )",
      "tags": ["male", "middle-aged", "entertainment", "storytelling", "Children's Content"],
      "languages": ["en"],
      "visibility": "public",
      "task_count": 770
    },
    {
      "_id": "76b55591c758444cb95253708696dfad",
      "type": "tts",
      "title": "Joe NARRATION",
      "tags": ["male", "middle-aged", "narration", "deep", "raspy"],
      "languages": ["en"],
      "visibility": "public"
    }
  ],
  "has_more": null
}
```

Σημειώστε ότι το `title` είναι «παγκόσμια ασαφής αντιστοίχιση», θα χτυπήσει ταυτόχρονα όλους τους ήχους της δημόσιας βιβλιοθήκης Fish (όχι μόνο τους δικούς σας).

## Παράδειγμα 3: Λίστα μόνο των ήχων που έχει δημιουργήσει ο εαυτός σας (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Επιστροφή (πραγματική μέτρηση, κάτω από τον τρέχοντα λογαριασμό υπάρχει μόνο 1 ήχος):

      "state": "trained",
      "languages": ["zh"],

## Παράδειγμα 4: Φιλτράρισμα με βάση τη γλώσσα + ετικέτα
```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> Ο upstream θα επιστρέψει αποτελέσματα και για `tag` που δεν είναι στο λεξικό ετικετών, αλλά η αντιστοίχιση είναι σχετικά χαλαρή. Εάν ο αριθμός των επιτυχιών είναι 0, προτείνεται να χρησιμοποιήσετε την ασαφή αντιστοίχιση με το `title`.

## Πεδία Απόκρισης

Κάθε στοιχείο στο `items[]` είναι ένα πλήρες αντικείμενο ModelEntity, με τα συνηθισμένα πεδία:

| Πεδίο          | Τύπος     | Περιγραφή                                            |
| ------------- | -------- | ------------------------------------------------- |
| `_id`         | string   | ID ήχου, ως τιμή του `reference_id` στο `/fish/tts`.         |
| `type`        | string   | Τύπος μοντέλου, συνήθως `tts`.                                   |
| `title`       | string   | Όνομα ήχου.                                             |
| `description` | string   | Περιγραφή ήχου.                                         |
| `state`       | string   | Κατάσταση εκπαίδευσης: `trained` σημαίνει διαθέσιμο.                              |
| `tags`        | string[] | Ετικέτες δημόσιας βιβλιοθήκης.                                            |
| `languages`   | string[] | Γλώσσες που ειδικεύεται ο ήχος.                                          |
| `visibility`  | string   | `public` ή `private`.                             |
| `samples`     | object[] | Προκαθορισμένα δείγματα (συμπεριλαμβανομένου του `audio` απευθείας σύνδεσης).                               |
| `like_count`  | integer  | Αριθμός "μου αρέσει" στη δημόσια βιβλιοθήκη.                                           |
| `task_count`  | integer  | Ιστορικός αριθμός συνθέσεων.                                           |
| `author`      | object   | Πληροφορίες συγγραφέα upstream: `_id` / `nickname` / `avatar`.             |
| `total` (ανώτερου επιπέδου)   | integer  | Συνολικός αριθμός που πληροί τις προϋποθέσεις.                                         |
| `has_more`    | boolean? | Δείκτης σελίδας upstream, μπορεί να είναι `null`. Συνιστάται να υπολογίσετε τον συνολικό αριθμό σελίδων με `total / page_size`. |

## Περιγραφή Χρέωσης

Αυτή η διεπαφή δεν χρεώνεται — η σελιδοποίηση της λίστας ήχων είναι δωρεάν λειτουργία. Η δημιουργία ήχου ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) είναι επίσης δωρεάν, το κόστος προκύπτει μόνο κατά την κλήση του [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) για τη σύνθεση φωνής.

## Διαχείριση Σφαλμάτων

- `400 token_mismatched`: Λείπουν ή είναι μη έγκυρες παράμετροι αιτήματος.
- `401 invalid_token`: Το token εξουσιοδότησης δεν υπάρχει ή είναι μη έγκυρο.
- `429 too_many_requests`: Ενεργοποίηση περιορισμού ρυθμού λογαριασμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.

Παράδειγμα σφάλματος απόκρισης:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Συμπέρασμα

Για να επιλέξετε ήχο από τη δημόσια βιβλιοθήκη Fish για να το δώσετε στο `reference_id` του `/fish/tts`, πρώτα χρησιμοποιήστε αυτή τη διεπαφή σε συνδυασμό με `title` / `tag` / `language` για να αναζητήσετε, να εντοπίσετε το στόχο `_id`, και στη συνέχεια χρησιμοποιήστε το [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) για να πάρετε δείγματα για ακρόαση. Για να καταγράψετε τους ήχους που δημιουργήσατε, απλά περάστε `self=true`.
