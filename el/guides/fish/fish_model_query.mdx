Αυτή η διεπαφή βασίζεται στο [επίσημο Model API του Fish Audio](https://docs.fish.audio/resources/api-reference/model) και χρησιμοποιείται για **σελιδοποιημένη αναζήτηση στη δημόσια βιβλιοθήκη φωνών του Fish ή στις κλωνοποιημένες φωνές του τρέχοντος λογαριασμού**. Η διεύθυνση είναι `GET https://api.acedata.cloud/fish/model`.

> Για τη δημιουργία φωνής, ανατρέξτε στο [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model)· για την αναζήτηση λεπτομερειών μίας φωνής βάσει `_id`, ανατρέξτε στο [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Fish Model API, αποκτήστε πρώτα το API Token σας από την [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) και κρατήστε το για χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης, όπου θα σας ζητηθεί να εγγραφείτε και να συνδεθείτε. Μετά την ολοκλήρωση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση παρέχει δωρεάν ποσό χρήσης, ώστε να μπορείτε να το δοκιμάσετε δωρεάν· όταν το ποσό δεν επαρκεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο από την [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Παράμετροι ερωτήματος

| Παράμετρος               | Τύπος      | Προεπιλογή  | Περιγραφή                                              |
| ---------------- | ------- | --- | ----------------------------------------------- |
| `page_size`      | integer | 10  | Αριθμός εγγραφών ανά σελίδα.                                           |
| `page_number`    | integer | 1   | Αριθμός σελίδας που ξεκινά από το 1.                                         |
| `title`          | string  | —   | Ασαφής αναζήτηση βάσει τίτλου.                                        |
| `tag`            | string  | —   | Φιλτράρισμα βάσει μίας ετικέτας.                                        |
| `self`           | boolean | —   | Όταν είναι `true`, επιστρέφει μόνο φωνές που δημιουργήθηκαν και αποθηκεύτηκαν μέσω αυτής της πλατφόρμας από τον λογαριασμό που πραγματοποιεί την τρέχουσα κλήση.                 |
| `author_id`      | string  | —   | Φιλτράρισμα βάσει ID δημιουργού της φωνής.                                    |
| `language`       | string  | —   | Φιλτράρισμα βάσει γλώσσας της φωνής, όπως `en`, `zh`, `es`.                       |
| `title_language` | string  | —   | Φιλτράρισμα βάσει γλώσσας τίτλου στη δημόσια βιβλιοθήκη φωνών.                                 |
| `sort_by`        | string  | —   | Πεδίο ταξινόμησης· όταν `self=true`, υποστηρίζονται τα `created_at`, `task_count`. |

> Η ονομασία των παραμέτρων είναι ακριβώς ίδια με την ανάντη `GET https://api.fish.audio/model`. Για λεπτομέρειες, ανατρέξτε στην [επίσημη τεκμηρίωση του Fish](https://docs.fish.audio/resources/api-reference/model).

## Παράδειγμα 1: Προεπιλεγμένη σελιδοποίηση (βάσει `page_size`)

```shell

  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=2'
```

## Παράδειγμα 2: Ασαφής αναζήτηση βάσει τίτλου (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Επιστροφή (δοκιμασμένο):

```json
{
  "total": 161,
  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",
      "type": "tts",
      "title": "Miles Morales ( Narration Paw )",
      "tags": ["male", "middle-aged", "entertainment", "storytelling", "Children's Content"],
      "languages": ["en"],
      "visibility": "public",
      "task_count": 770
    },
    {
      "_id": "76b55591c758444cb95253708696dfad",
      "type": "tts",
      "title": "Joe NARRATION",
      "tags": ["male", "middle-aged", "narration", "deep", "raspy"],
      "languages": ["en"],
      "visibility": "public"
    }
  ],
  "has_more": null
}
```

Σημειώστε ότι το `title` είναι «καθολική ασαφής αντιστοίχιση» και θα αντιστοιχίσει ταυτόχρονα όλες τις φωνές στη δημόσια βιβλιοθήκη του Fish (όχι μόνο τις δικές σας).

## Παράδειγμα 3: Εμφάνιση μόνο των φωνών που δημιουργήσατε εσείς (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Παράδειγμα επιστροφής:

```json
{
  "total": 1,
  "items": [
    {
      "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
      "type": "tts",
      "title": "copilot-smoke-test",
      "description": "smoke test from api.acedata.cloud",
      "state": "trained",
      "languages": ["zh"],
      "visibility": "public",
      "samples": [
        {
          "title": "Default Sample",
          "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
          "task_id": "6a1bf398dfae49dca0e23159214342a0",
          "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
        }
      ],
      "created_at": "2026-05-10T03:52:55.601000Z",
      "author": {
        "_id": "780f2b2f862d41a08c0507bbbda77eb6",
        "nickname": "Penny Conrad"
      }
    }
  ],
  "has_more": false
}
```
Το `self=true` παραθέτει τις φωνές που δημιουργήθηκαν και αποθηκεύτηκαν μέσω αυτής της πλατφόρμας από τον λογαριασμό που πραγματοποιεί την κλήση· φωνές που δημιουργήθηκαν από τον ίδιο λογαριασμό με διαφορετικά API Token θα παρατεθούν επίσης μαζί. Τα αποτελέσματα σελιδοποιούνται σε φθίνουσα σειρά χρόνου δημιουργίας και το `author_id` μπορεί να φιλτράρει περαιτέρω το ID συγγραφέα αυτών των φωνών. Αυτή η παράμετρος φιλτράρει μόνο τη λίστα· οι φωνές παραμένουν δημόσια διαθέσιμες.

Το `self=true` δεν υποστηρίζει το `title_language`· αν χρειάζεται αναζήτηση βάσει γλώσσας τίτλου, αναζητήστε στη δημόσια βιβλιοθήκη φωνών.

## Παράδειγμα 4: Φιλτράρισμα κατά γλώσσα + ετικέτα

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> Το ανάντη σύστημα επιστρέφει επίσης αποτελέσματα για `tag` που δεν υπάρχουν στο λεξικό ετικετών, αλλά η αντιστοίχιση είναι σχετικά χαλαρή· αν ο αριθμός αντιστοιχιών είναι 0, συνιστάται η χρήση ασαφούς αντιστοίχισης με `title`.

## Πεδία απόκρισης

Κάθε στοιχείο στο `items[]` είναι ένα πλήρες αντικείμενο ModelEntity, με συνήθη πεδία:

| Πεδίο            | Τύπος       | Περιγραφή                                        |
| ------------- | -------- | ----------------------------------------- |
| `_id`         | string   | ID φωνής, ως τιμή του `reference_id` στο `/fish/tts`. |
| `type`        | string   | Τύπος μοντέλου, συνήθως `tts`.                           |
| `title`       | string   | Όνομα φωνής.                                     |
| `description` | string   | Περιγραφή φωνής.                                     |
| `state`       | string   | Κατάσταση εκπαίδευσης: το `trained` υποδηλώνει ότι είναι διαθέσιμο.                      |
| `tags`        | string[] | Ετικέτες δημόσιας βιβλιοθήκης.                                    |
| `languages`   | string[] | Γλώσσες στις οποίες η φωνή εξειδικεύεται.                                  |
| `visibility`  | string   | `public` ή `private`.                     |
| `samples`     | object[] | Προκαθορισμένα δείγματα (συμπεριλαμβανομένου άμεσου συνδέσμου `audio`).                       |
| `like_count`  | integer  | Αριθμός επισημάνσεων «Μου αρέσει» στη δημόσια βιβλιοθήκη.                                   |
| `task_count`  | integer  | Αριθμός ιστορικών συνθέσεων.                                   |
| `author`      | object   | Πληροφορίες συγγραφέα φωνής: `_id` / `nickname` / `avatar`.     |
| `total`（ανώτατο επίπεδο）   | integer  | Συνολικός αριθμός στοιχείων που πληρούν τις προϋποθέσεις.                                 |
| `has_more`    | boolean? | Είναι δυαδική τιμή όταν `self=true`· τα ερωτήματα στη δημόσια βιβλιοθήκη φωνών μπορεί να είναι `null`.      |

## Περιγραφή χρέωσης

Αυτή η διεπαφή δεν χρεώνεται — η σελιδοποιημένη αναζήτηση της λίστας φωνών είναι δωρεάν ενέργεια. Η δημιουργία φωνών ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) είναι επίσης δωρεάν· χρεώσεις προκύπτουν μόνο κατά τη σύνθεση ομιλίας μέσω του [Fish TTS](https://platform.acedata.cloud/documents/fish-tts), βάσει χρήσης.

## Χειρισμός σφαλμάτων

- `400 token_mismatched`: Οι παράμετροι αιτήματος λείπουν ή δεν είναι έγκυρες.
- `401 invalid_token`: Το token αυθεντικοποίησης δεν υπάρχει ή δεν είναι έγκυρο.
- `429 too_many_requests`: Ενεργοποιήθηκε το όριο ρυθμού του λογαριασμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.

Παράδειγμα απόκρισης σφάλματος:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Συμπέρασμα

Για να επιλέξετε μια φωνή από τη δημόσια βιβλιοθήκη Fish και να τη δώσετε στο `reference_id` του `/fish/tts`, χρησιμοποιήστε πρώτα αυτή τη διεπαφή σε συνδυασμό με `title` / `tag` / `language` για αναζήτηση, εντοπίστε το στόχο `_id` και έπειτα χρησιμοποιήστε το [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) για να λάβετε δείγματα για ακρόαση. Για να παραθέσετε τις φωνές που δημιουργήσατε εσείς, απλώς περάστε `self=true`.
