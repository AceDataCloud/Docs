Αυτό το έγγραφο θα παρουσιάσει μια Ψηφιακή Αγγλική Επιβεβαίωση CAPTCHA API Σύνδεση Οδηγίες, η οποία βασίζεται σε τεχνολογία βαθιάς μάθησης και μπορεί να χρησιμοποιηθεί για την αναγνώριση μεταβλητού μήκους αγγλικών ψηφιακών CAPTCHA. Εισάγετε το περιεχόμενο της εικόνας CAPTCHA και εξάγετε το αποτέλεσμα CAPTCHA.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [Ψηφιακή Αγγλική Επιβεβαίωση CAPTCHA API](https://platform.acedata.cloud/documents/cd1f56dc-e9c9-4293-9c68-80fa560c9087) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε την εικόνα του μεταβλητού μήκους αγγλικού ψηφιακού CAPTCHA που χρειάζεται επεξεργασία, για να λάβετε το επεξεργασμένο αποτέλεσμα. Πρέπει απλώς να μεταφέρετε ένα πεδίο `image`, το οποίο είναι η συγκεκριμένη εικόνα του αγγλικού ψηφιακού CAPTCHA, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/c50hi9.png" width="500" className="m-auto" /></p>

Στη συνέχεια, πρέπει να μετατρέψουμε την εικόνα CAPTCHA σε κωδικοποίηση Base64. Συνιστάται να χρησιμοποιήσετε το πρόσθετο του Google Chrome FeHelper για τη μετατροπή. Μπορείτε να ανατρέξετε στην παρακάτω εικόνα για λεπτομέρειες σχετικά με τη χρήση:

<p><img src="https://cdn.acedata.cloud/zy2jwh.png" width="500" className="m-auto" /></p>

<p><img src="https://cdn.acedata.cloud/pr73gn.png" width="500" className="m-auto" /></p>

<p><img src="https://cdn.acedata.cloud/ic4dbw.png" width="500" className="m-auto" /></p>

Μετά, μπορείτε να αντιγράψετε την κωδικοποίηση Base64 που αποκτήσατε από το πρόσθετο FeHelper του Google Chrome, θυμηθείτε ότι δεν περιλαμβάνει το πρόθεμα data:image/png;base64. Το περιεχόμενο είναι το εξής:

<p><img src="https://cdn.acedata.cloud/5h4x4w.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, συμπεριλαμβανομένων:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, συμπεριλαμβανομένων:

- `image`: η κωδικοποιημένη σε Base64 εικόνα CAPTCHA (χωρίς το πρόθεμα data:image/png;base64).

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/202y3d.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "text": "7364"
}
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, τα οποία περιγράφονται παρακάτω:

- `text`, το περιεχόμενο κειμένου της εργασίας επεξεργασίας της εικόνας του μεταβλητού μήκους αγγλικού ψηφιακού CAPTCHA.

Μπορείτε να δείτε ότι έχουμε λάβει το αποτέλεσμα επεξεργασίας της εικόνας του μεταβλητού μήκους αγγλικού ψηφιακού CAPTCHA. Χρειάζεται απλώς να βασιστείτε στο περιεχόμενο του κειμένου `text` για να περάσετε την επαλήθευση.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο παρακάτω κώδικας CURL:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/image2text' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX..."
}'
```

Ο κώδικας σύνδεσης Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/image2text"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX..."
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
