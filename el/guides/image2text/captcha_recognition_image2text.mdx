Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο σύνδεσης API αναγνώρισης ψηφιακού αγγλικού CAPTCHA, η οποία βασίζεται σε τεχνολογία βαθιάς μάθησης και μπορεί να χρησιμοποιηθεί για την αναγνώριση μεταβλητού μήκους αγγλικών ψηφιακών CAPTCHA. Εισάγετε το περιεχόμενο της εικόνας CAPTCHA και εξάγετε το αποτέλεσμα CAPTCHA.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API αναγνώρισης ψηφιακού αγγλικού CAPTCHA, πρώτα επισκεφθείτε την [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε. Αφού ολοκληρώσετε, θα επιστρέψετε αυτόματα στη σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να υποβάλετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν. Όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό σας υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [API Αναγνώρισης Ψηφιακού Αγγλικού CAPTCHA →](https://platform.acedata.cloud/documents/captcha-recognition-image2text)

## Βασική Χρήση

Πρώτα, ας κατανοήσουμε τη βασική μέθοδο χρήσης, δηλαδή εισάγοντας την εικόνα του μεταβλητού μήκους αγγλικού ψηφιακού CAPTCHA, μπορείτε να αποκτήσετε το επεξεργασμένο αποτέλεσμα. Αρχικά, χρειάζεται να περάσετε ένα πεδίο `image`, το οποίο είναι η συγκεκριμένη εικόνα του αγγλικού ψηφιακού CAPTCHA, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/c50hi9.png" width="500" className="m-auto" /></p>

Στη συνέχεια, πρέπει να μετατρέψουμε την εικόνα CAPTCHA σε κωδικοποίηση Base64. Συνιστάται να χρησιμοποιήσετε το πρόσθετο του Google Chrome FeHelper για τη μετατροπή. Μπορείτε να ανατρέξετε στην παρακάτω εικόνα για λεπτομέρειες:

<p><img src="https://cdn.acedata.cloud/zy2jwh.png" width="500" className="m-auto" /></p>

<p><img src="https://cdn.acedata.cloud/pr73gn.png" width="500" className="m-auto" /></p>

<p><img src="https://cdn.acedata.cloud/ic4dbw.png" width="500" className="m-auto" /></p>

Μετά, μπορείτε να αντιγράψετε την κωδικοποίηση Base64 που αποκτήσατε από το πρόσθετο FeHelper, θυμηθείτε ότι δεν περιλαμβάνει το πρόθεμα data:image/png;base64. Το περιεχόμενο είναι το εξής:

<p><img src="https://cdn.acedata.cloud/5h4x4w.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί API για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `image`: η κωδικοποιημένη σε Base64 εικόνα CAPTCHA (χωρίς το πρόθεμα data:image/png;base64).

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/202y3d.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και θα λάβετε το εξής αποτέλεσμα:

```json
{
  "text": "7364",
  "elapsed": 31.6
}
```

Η απάντηση περιέχει πολλά πεδία, που περιγράφονται ως εξής:

- `text`, το περιεχόμενο κειμένου της επεξεργασίας της εικόνας του μεταβλητού μήκους αγγλικού ψηφιακού CAPTCHA.
- `started_at`, `finished_at`: η ώρα έναρξης και ολοκλήρωσης της επεξεργασίας της τρέχουσας αίτησης, Unix timestamp (δευτερόλεπτα, κινητής υποδιαστολής).
- `elapsed`: ο συνολικός χρόνος επεξεργασίας (δευτερόλεπτα).

Μπορείτε να δείτε ότι έχουμε λάβει το αποτέλεσμα της επεξεργασίας της εικόνας του μεταβλητού μήκους αγγλικού ψηφιακού CAPTCHA, και απλά πρέπει να επιβεβαιώσουμε την επαλήθευση με το περιεχόμενο του πεδίου `text`.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο παρακάτω κώδικας CURL:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/image2text' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX..."
}'
```

Ο κώδικας σύνδεσης Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/image2text"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX..."
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Ασύγχρονη Λειτουργία (async)

Από προεπιλογή, το API είναι συγχρονισμένο και μπλοκαρισμένο: μια αίτηση θα περιμένει μέχρι να ολοκληρωθεί η επεξεργασία του αποτελέσματος αναγνώρισης. Εάν κάνετε εναλλαγή πολλών αναγνωριστών (multi-solver rotation) και θέλετε να «υποβάλετε την εργασία και να λάβετε αμέσως το task_id, να προγραμματίσετε άλλους αναγνωριστές και αργότερα να επιστρέψετε για να διαβάσετε το αποτέλεσμα», μπορείτε να περάσετε το `async: true` στο σώμα της αίτησης.

Αφού περάσετε το `async: true`, η διεπαφή θα επιστρέψει αμέσως ένα `task_id`, χωρίς να μπλοκάρει την αναμονή:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/image2text' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX...",
  "async": true
}'
```

```json
{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

Εάν θέλετε να ελέγξετε την πρόοδο, μπορείτε να χρησιμοποιήσετε το `task_id` για να ελέγξετε το `POST /captcha/tasks` (συνιστάται κάθε 3~5 δευτερόλεπτα). Αυτή η διεπαφή δεν θα ενεργοποιήσει ή θα προχωρήσει την επεξεργασία της εργασίας. Ακόμα και αν δεν ελέγξετε, διακοπεί η σύνδεση ή αποσυνδεθείτε από τον πελάτη, ο διακομιστής θα συνεχίσει την επεξεργασία:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002"
}'
```

Κατά την επεξεργασία θα επιστραφεί `status: processing`:

```json
{ "success": true, "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002", "status": "processing" }
```

Όταν ολοκληρωθεί η επεξεργασία, θα επιστραφεί `status: ready` και το αποτέλεσμα αναγνώρισης `text` (η δομή των πεδίων είναι απολύτως ίδια με τη συγχρονισμένη λειτουργία):

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "ready",
  "text": "7364"
}
```

Πληροφορίες χρέωσης: Στην ασύγχρονη λειτουργία, η δημιουργία εργασίας και η ανάγνωση της κατάστασης «σε επεξεργασία» δεν χρεώνονται. **Η χρέωση γίνεται μία φορά όταν ο πελάτης διαβάσει επιτυχώς το αποτέλεσμα** (σύμφωνα με την υπάρχουσα συμπεριφορά και την τιμή της συγχρονισμένης λειτουργίας). Ο διακομιστής θα προχωρήσει αυτόματα την εργασία, αλλά δεν θα χρεώσει νωρίτερα επειδή η εργασία ολοκληρώθηκε στο παρασκήνιο. Εάν η εργασία δεν ολοκληρωθεί εντός 120 δευτερολέπτων, θα τερματιστεί με HTTP 504 `timeout`, χωρίς χρέωση. Το `/captcha/tasks` δεν είναι υπεύθυνο για την προώθηση της εργασίας.

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:
- `400 token_mismatched`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παραδείγματα σφαλμάτων

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
