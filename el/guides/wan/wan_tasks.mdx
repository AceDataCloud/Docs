`POST https://api.acedata.cloud/wan/tasks` χρησιμοποιείται για την αναζήτηση, μαζική αναζήτηση ή διαγραφή βίντεο εργασιών Wan. Η αναζήτηση εργασιών δεν χρεώνει ξανά το κόστος παραγωγής.

## Αναζήτηση μεμονωμένης εργασίας

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Η `response.data.video_url` της ολοκληρωμένης εργασίας είναι μόνιμη διεύθυνση CDN; η `response.usage` περιλαμβάνει ανάλυση, δευτερόλεπτα εισόδου/εξόδου βίντεο, ρυθμό καρέ και αναλογία; το `response.cost` είναι η εκκαθάριση της εργασίας παραγωγής.

## Μαζική αναζήτηση

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Επιστρέφει `{ "items": [...], "count": 2 }`. Κατά τη διάρκεια της εργασίας μπορεί να μην υπάρχουν ακόμη `finished_at` και τελική `response`.

## Διαγραφή ιστορικού εργασίας

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

Η διαγραφή επηρεάζει μόνο το ιστορικό εργασιών, δεν θα διαγράψει τα ήδη παραγόμενα βίντεο CDN.
