Η κύρια λειτουργία του API Wan Tasks είναι να ελέγχει την κατάσταση εκτέλεσης ενός έργου μέσω του ID έργου που παράγεται από το API Wan Videos Generation.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες σύνδεσης του API Wan Tasks, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του API Wan Tasks, μπορείτε εύκολα να ελέγξετε την κατάσταση εκτέλεσης των έργων του API Wan Videos Generation.

### Ρύθμιση κεφαλίδων αιτήματος και σώματος αιτήματος

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `id`: το ID του έργου που ανεβάσατε.
- `action`: ο τρόπος λειτουργίας του έργου.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "a4bca552-d964-46a1-8ff7-fd922f916582",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/wan/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "a4bca552-d964-46a1-8ff7-fd922f916582",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Σφάλματα

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
