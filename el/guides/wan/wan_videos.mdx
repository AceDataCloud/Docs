Το `POST https://api.acedata.cloud/wan/videos` υποστηρίζει ταυτόχρονα τα υπάρχοντα μοντέλα Wan 2.6 και το `wan3.0-video`. Το Wan 3 αναγνωρίζει αυτόματα τη λειτουργία κειμένου, πρώτου και τελευταίου καρέ ή υλικού αναφοράς βάσει του `media`.

## Δημιουργία βίντεο από κείμενο Wan 3

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "A paper boat drifting through a neon city at night",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Το Wan 3 υποστηρίζει ακέραιες διάρκειες 2–30 δευτερολέπτων ή έξυπνη διάρκεια `-1`, με αναλύσεις `480P`, `720P`, `1080P`.

## Αναφορές πολυμέσων

```json
{
  "model": "wan3.0-video",
  "prompt": "Create a cinematic product reveal",
  "media": [
    {"type":"first_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"},
    {"type":"last_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460-a2a2c1afbf39.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

Το `media.type` υποστηρίζει:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

Η λειτουργία πρώτου και τελευταίου καρέ και η λειτουργία υλικού αναφοράς δεν μπορούν να χρησιμοποιηθούν μαζί. Τα βίντεο αναφοράς χρεώνονται τελικά με βάση τα πραγματικά δευτερόλεπτα του εισαγόμενου βίντεο συν τα δευτερόλεπτα του επιτυχώς παραγόμενου βίντεο· οι είσοδοι κειμένου, εικόνας και ήχου δεν αυξάνουν τα δευτερόλεπτα βίντεο.

## Επίσημες τυπικές τιμές

| Ανάλυση   |      Τιμή |
| ----- | ------: |
| 480P  | $0.05/δευτερόλεπτο |
| 720P  | $0.10/δευτερόλεπτο |
| 1080P | $0.20/δευτερόλεπτο |

## Συμβατότητα Wan 2.6

Τα υπάρχοντα `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` και οι παραλλαγές flash συνεχίζουν να χρησιμοποιούν παραμέτρους όπως `action`, `image_url`, `reference_video_urls`, ενώ η διαδρομή κλήσης παραμένει αμετάβλητη.

## Ασύγχρονη εκτέλεση και αποτελέσματα

Αφού οριστεί το `async: true`, λαμβάνεται αμέσως το `task_id`, και η τελική κατάσταση λαμβάνεται μέσω του `/wan/tasks`. Τα επιτυχημένα βίντεο θα μεταφερθούν στο AceDataCloud CDN και στην απόκριση θα επιστραφούν το πραγματικό usage και cost.
