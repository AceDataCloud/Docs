Αυτό το άρθρο θα παρουσιάσει μια μέθοδο σύνδεσης με το Wan Videos Generation API, το οποίο μπορεί να δημιουργήσει επίσημα βίντεο του Tongyi Wanxiang μέσω της εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [Wan Videos Generation API](https://platform.acedata.cloud/documents/52b0f490-1bbf-4fe5-b60e-96626d333d2c) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή την εισαγωγή του προτροπής `prompt`, της ενέργειας `action`, της αναφοράς εικόνας `image_url` και του μοντέλου `model`, για να αποκτήσετε το επεξεργασμένο αποτέλεσμα. Πρώτα, πρέπει να περάσετε ένα πεδίο `action`, του οποίου η τιμή είναι `text2video`. Αυτό περιλαμβάνει κυρίως δύο τύπους ενεργειών: δημιουργία βίντεο από κείμενο (`text2video`) και δημιουργία βίντεο από εικόνα (`image2video`). Στη συνέχεια, πρέπει να εισάγουμε το μοντέλο `model`, το οποίο περιλαμβάνει κυρίως τα μοντέλα `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`, `wan2.6-t2v`, με τις λεπτομέρειες όπως παρακάτω:

<p><img src="https://cdn.acedata.cloud/03gqdz.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `model`: το μοντέλο για τη δημιουργία του βίντεο, κυρίως τα μοντέλα `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`, `wan2.6-t2v`.
- `action`: η ενέργεια της τρέχουσας εργασίας δημιουργίας βίντεο, που περιλαμβάνει κυρίως τρεις ενέργειες: δημιουργία βίντεο από κείμενο (`text2video`), δημιουργία βίντεο από εικόνα (`image2video`). Όταν είναι δημιουργία βίντεο από κείμενο, υποστηρίζεται μόνο το μοντέλο `wan2.6-t2v`. Όταν είναι δημιουργία βίντεο από εικόνα, υποστηρίζονται μόνο τα μοντέλα `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`.
- `image_url`: όταν επιλέγεται η ενέργεια δημιουργίας βίντεο από εικόνα `image2video`, απαιτείται να ανεβάσετε τη σύνδεση της αναφοράς εικόνας. Αυτή τη στιγμή υποστηρίζονται μόνο τα μοντέλα `wan2.6-i2v`, `wan2.6-i2v-flash`.
- `reference_video_urls`: προαιρετικό κατά τη δημιουργία βίντεο από εικόνα, καθορίζει τη σύνδεση του βίντεο αναφοράς για τη δημιουργία. Αυτή τη στιγμή υποστηρίζεται μόνο το μοντέλο `wan2.6-r2v`.
- `size`: καθορίζει την ανάλυση του παραγόμενου βίντεο, με μορφή πλάτος*ύψος. Η προεπιλεγμένη τιμή και οι διαθέσιμες τιμές εξαρτώνται από την παράμετρο μοντέλου, οι συγκεκριμένοι κανόνες μπορούν να αναφέρονται στην [επίσημη τεκμηρίωση](https://modelstudio.console.alibabacloud.com/ap-southeast-1/?tab=api#/api/?type=model&url=2865250).
- `duration`: η διάρκεια του παραγόμενου βίντεο, υποστηρίζει κυρίως 5, 10, 15.
- `shot_type`: προαιρετικό, καθορίζει τον τύπο λήψης του παραγόμενου βίντεο, δηλαδή αν το βίντεο αποτελείται από μία συνεχόμενη λήψη ή πολλές εναλλασσόμενες λήψεις. Ισχύει μόνο όταν το "prompt_extend": true. Προτεραιότητα παραμέτρων: shot_type > prompt. Για παράδειγμα, εάν το shot_type ρυθμιστεί σε "single", ακόμη και αν το prompt περιλαμβάνει "δημιουργία βίντεο πολλαπλών λήψεων", το μοντέλο θα παράγει βίντεο με μία μόνο λήψη. Οι συγκεκριμένοι κανόνες μπορούν να αναφέρονται στην [επίσημη τεκμηρίωση](https://modelstudio.console.alibabacloud.com/ap-southeast-1/?tab=api#/api/?type=model&url=2865250).
- `negative_prompt`: προαιρετικό, αντίστροφη προτροπή, για να περιγράψει περιεχόμενο που δεν θέλετε να δείτε στην εικόνα του βίντεο, μπορεί να περιορίσει την εικόνα του βίντεο. Υποστηρίζει κινέζικα και αγγλικά, με μήκος που δεν υπερβαίνει τους 500 χαρακτήρες, τυχόν επιπλέον θα κοπεί αυτόματα. Παράδειγμα τιμών: χαμηλή ανάλυση, σφάλματα, χειρότερη ποιότητα, χαμηλή ποιότητα, ελλιπή, περιττά δάχτυλα, κακή αναλογία κ.λπ.
- `resolution`: καθορίζει την κατηγορία ανάλυσης του παραγόμενου βίντεο, για να ρυθμίσει την καθαρότητα του βίντεο (συνολικοί πίξελ). Το μοντέλο θα κλιμακώσει αυτόματα σε κοντινούς συνολικούς πίξελ ανάλογα με την επιλεγμένη κατηγορία ανάλυσης, η αναλογία πλάτους προς ύψος του βίντεο θα προσπαθήσει να διατηρήσει την αναλογία πλάτους προς ύψος της εισαγόμενης εικόνας img_url. Περισσότερες λεπτομέρειες μπορείτε να δείτε στην [επίσημη τεκμηρίωση](https://modelstudio.console.alibabacloud.com/ap-southeast-1/?tab=api#/api/?type=model&url=2867393).
- `audio_url`: URL του αρχείου ήχου, το μοντέλο θα χρησιμοποιήσει αυτόν τον ήχο για να δημιουργήσει το βίντεο. Η μέθοδος χρήσης αναφέρεται στην [επίσημη τεκμηρίωση](https://modelstudio.console.alibabacloud.com/ap-southeast-1/?tab=api#/api/?type=model&url=2867393).
- `audio`: εάν θα παραχθεί βίντεο με ήχο. Προτεραιότητα παραμέτρων: audio > audio_url. Όταν audio=false, ακόμη και αν εισαχθεί audio_url, η έξοδος θα είναι βίντεο χωρίς ήχο και η χρέωση θα υπολογίζεται ως βίντεο χωρίς ήχο, η προεπιλεγμένη τιμή είναι true.
- `prompt_extend`: εάν θα ενεργοποιηθεί η έξυπνη αναδιατύπωση του prompt. Όταν είναι ενεργοποιημένο, χρησιμοποιεί μεγάλο μοντέλο για να αναδιατυπώσει έξυπνα το εισαγόμενο prompt. Για σύντομα prompts, η ποιότητα παραγωγής βελτιώνεται σημαντικά, αλλά θα αυξήσει τον χρόνο εκτέλεσης, η προεπιλεγμένη τιμή είναι true.
- `prompt`: προτροπή.
- `callback_url`: URL για την επιστροφή αποτελεσμάτων.

Αφού επιλέξετε, μπορείτε να δείτε ότι στα δεξιά έχει παραχθεί ο αντίστοιχος κώδικας, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/03gqdz.png" width="500" class="m-auto"></p>

Κάντε κλικ στο κουμπί «Try» για να δοκιμάσετε, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
  "state": "completed",
```

Η επιστροφή αποτελεσμάτων περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `success`, η κατάσταση της τρέχουσας εργασίας δημιουργίας βίντεο.
- `task_id`, το ID της τρέχουσας εργασίας δημιουργίας βίντεο.
- `video_url`, η σύνδεση του βίντεο της τρέχουσας εργασίας δημιουργίας βίντεο.
- `state`, η κατάσταση της τρέχουσας εργασίας δημιουργίας βίντεο.

Μπορείτε να δείτε ότι έχουμε λάβει ικανοποιητικές πληροφορίες βίντεο, απλά πρέπει να αποκτήσουμε το παραγόμενο βίντεο του Tongyi Wanxiang μέσω της διεύθυνσης σύνδεσης `video_url` του αποτελέσματος.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο παρακάτω κώδικας CURL:

```shell
curl -X POST 'https://api.acedata.cloud/wan/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "wan2.6-t2v",
  "prompt": "Astronauts shuttle from space to volcano",
  "duration": 5
}'
```

## Λειτουργία Δημιουργίας Βίντεο από Εικόνα
Αν θέλετε να δημιουργήσετε ένα βίντεο με βάση μια αναφορά εικόνας ή βίντεο, μπορείτε να ρυθμίσετε την παράμετρο `action` σε `image2video` και να εισάγετε τον σύνδεσμο της αναφοράς εικόνας ή του βίντεο. Στη συνέχεια, πρέπει να συμπληρώσουμε τις επόμενες προτάσεις που χρειάζονται για να προσαρμόσουμε τη δημιουργία του βίντεο, όπως παρακάτω:

- `model`: Το μοντέλο για τη δημιουργία του βίντεο, κυρίως υπάρχουν τα μοντέλα `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`, `wan2.6-t2v`.
- `image_url`: Όταν επιλέγετε τη συμπεριφορά εικόνας σε βίντεο `image2video`, πρέπει να ανεβάσετε τον σύνδεσμο της πρώτης εικόνας αναφοράς, αυτή τη στιγμή υποστηρίζονται μόνο τα μοντέλα `wan2.6-i2v`, `wan2.6-i2v-flash`.
- `reference_video_urls`: Προαιρετικό κατά τη δημιουργία βίντεο από εικόνα, καθορίζει τον σύνδεσμο του αναφοράς βίντεο για τη δημιουργία, αυτή τη στιγμή υποστηρίζεται μόνο το μοντέλο `wan2.6-r2v`.
- `prompt`: Προτάσεις.

Ένα παράδειγμα συμπλήρωσης είναι το εξής:

<p><img src="https://cdn.acedata.cloud/94l0kk.png" width="500" class="m-auto"></p>

Αφού συμπληρωθεί, δημιουργείται αυτόματα ο παρακάτω κώδικας:

<p><img src="https://cdn.acedata.cloud/b5q8tt.png" width="500" class="m-auto"></p>

Ο αντίστοιχος κώδικας Python:

```python
import requests

url = "https://api.acedata.cloud/wan/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "image2video",
    "model": "wan2.6-i2v",
    "prompt": "Astronauts shuttle from space to volcano",
    "duration": 5,
    "image_url": "https://cdn.acedata.cloud/r9vsv9.png",
    "callback_url": "https://www.baidu.com/"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```json
  "video_url": "https://dashscope-result-sh.oss-accelerate.aliyuncs.com/1d/db/20260124/da477ba2/0d2042f9-ba8d-496d-8ab5-182617e28f9e.mp4?Expires=1769349278&OSSAccessKeyId=LTAI5tKPD3TMqf2Lna1fASuh&Signature=SjBa4wRcDVx3SSYu/x7BYCFQk0s=",
  "state": "completed",
  "task_id": "a4bca552-d964-46a1-8ff7-fd922f916582"
}
```

Μπορείτε να δείτε ότι το περιεχόμενο του αποτελέσματος είναι συνεπές με το παραπάνω κείμενο, επιτυγχάνοντας έτσι τη λειτουργία επέκτασης βίντεο.

## Ασύγχρονη κλήση

Δεδομένου ότι ο χρόνος δημιουργίας του API Wan Videos Generation είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, αν το API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος. Έτσι, αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη κλήση.

Η συνολική διαδικασία είναι: Όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`. Μετά την υποβολή του API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα που περιλαμβάνει ένα πεδίο `task_id`, το οποίο αντιπροσωπεύει το ID της τρέχουσας εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα του δημιουργημένου βίντεο θα αποσταλεί μέσω POST JSON στη διεύθυνση `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε με ένα παράδειγμα.

Πρώτα, η κλήση Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα, οι προγραμματιστές θα πρέπει να την αντικαταστήσουν με το URL του HTTP διακομιστή που έχουν δημιουργήσει. Για ευκολία, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να λάβετε ένα Webhook URL, όπως φαίνεται στην εικόνα:

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, αν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
