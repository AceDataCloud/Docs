Αυτό το άρθρο παρουσιάζει την ενσωμάτωση και χρήση του API δημιουργίας βίντεο MiniMax H3. Αυτή η διεπαφή υποστηρίζει δημιουργία βίντεο από κείμενο, έλεγχο πρώτου και τελευταίου καρέ, καθώς και δημιουργία βίντεο με πολυτροπικές αναφορές, χρησιμοποιώντας την ενιαία πολυτροπική δομή `content` V2 για τη δημιουργία εργασιών.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το API δημιουργίας βίντεο MiniMax H3, αρχικά μεταβείτε στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση παρέχει δωρεάν πίστωση για δωρεάν δοκιμή· όταν η πίστωση δεν επαρκεί, μπορείτε να προσθέσετε γενικό υπόλοιπο από την [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [API δημιουργίας βίντεο MiniMax H3 →](https://platform.acedata.cloud/documents/minimax-videos-integration)

Συνιστάται να αποθηκεύσετε το Token ως μεταβλητή περιβάλλοντος και να μην το γράψετε στον πηγαίο κώδικα ή να το υποβάλετε στο αποθετήριο εκδόσεων:

```bash
export ACEDATACLOUD_API_KEY="YOUR_API_KEY"
```

## Επισκόπηση διεπαφής

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /minimax/videos`
- **Μέθοδος πιστοποίησης**：Στο HTTP Header συμπεριλάβετε `authorization: Bearer {token}`
- **Κεφαλίδες αιτήματος**：
  - `accept: application/json`
  - `content-type: application/json`
- **Μοντέλο（model）**：`MiniMax-H3`
- **Δομή εισόδου**：Εισαγάγετε ενιαία κείμενο, εικόνες, βίντεο και ήχο μέσω του `content`
- **Λειτουργία εξόδου**：Από προεπιλογή, αναμένει συγχρονισμένα την ολοκλήρωση της δημιουργίας και επιστρέφει πλήρες `task`· όταν περάσετε `async: true` ή `callback_url`, επιστρέφει αμέσως `task_id` και `trace_id`
- **Αναζήτηση αποτελεσμάτων**：Λάβετε την κατάσταση και το τελικό βίντεο μέσω του [API αναζήτησης εργασιών MiniMax H3](https://platform.acedata.cloud/documents/minimax-tasks-integration)
- **Ασύγχρονο callback**：Προαιρετικό, λαμβάνει το τελικό αποτέλεσμα της εργασίας μέσω `callback_url`

Δεν χρειάζεται να περάσετε `action` για να επιλέξετε λειτουργία δημιουργίας, η διεπαφή θα κρίνει αυτόματα τη χρήση βάσει του τύπου υλικού και του `role` στο `content`.

## Για ποια σενάρια είναι κατάλληλο

| Σενάριο         | Συνδυασμός εισόδου                  | Συνήθεις χρήσεις                      |
| ---------- | --------------------- | ------------------------- |
| Δημιουργία βίντεο από κείμενο       | Κείμενο                    | Διαφημιστικές ιδέες, προεπισκόπηση storyboard, σύντομα βίντεο, ατμοσφαιρικά πλάνα        |
| Δημιουργία βίντεο από εικόνα πρώτου καρέ     | Κείμενο + εικόνα πρώτου καρέ             | Κάντε φυσικά να κινηθούν εικόνες προϊόντων, αφίσες, φωτογραφίες προσώπων ή εικονογραφήσεις      |
| Βίντεο τελευταίου καρέ / πρώτου και τελευταίου καρέ | Κείμενο + τελευταίο καρέ, ή κείμενο + πρώτο καρέ + τελευταίο καρέ | Έλεγχος αρχής και τέλους, μεταβάσεων, αλλαγών ανάπτυξης και συγκρίσεων πριν και μετά      |
| Δημιουργία βίντεο με πολυτροπικές αναφορές   | Κείμενο + εικόνα / βίντεο / ήχος αναφοράς   | Διατήρηση συνέπειας χαρακτήρων και προϊόντων, αναπαραγωγή κινήσεων, κινήσεων κάμερας, χροιάς ή ρυθμού μοντάζ |

## Ροή κλήσης

Όταν δεν περνάτε `async` από προεπιλογή, το `/minimax/videos` θα περιμένει να ολοκληρωθεί η δημιουργία και θα επιστρέψει απευθείας το πλήρες `task`. Όταν χρειάζεται να απελευθερώσετε αμέσως τη σύνδεση, περάστε `async: true` ή `callback_url`:

1. Αποθηκεύστε τα `task_id` και `trace_id` στην άμεση απόκριση.
2. Όταν δεν έχει ρυθμιστεί callback, καλέστε το `/minimax/tasks` περίπου κάθε 10 δευτερόλεπτα για μία αναζήτηση.
3. Όταν το `task.status` γίνει `succeeded`, λάβετε το βίντεο από το `task.content.url`.
4. Όταν η κατάσταση είναι `failed` ή `cancelled`, σταματήστε την αναζήτηση και διαβάστε το `task.error`.

## Παράμετροι αιτήματος ανώτατου επιπέδου

| Παράμετρος             | Τύπος       | Υποχρεωτικό   | Προεπιλεγμένη τιμή        | Περιγραφή                                                |
| -------------- | -------- | ---- | ---------- | ------------------------------------------------- |
| `model`        | string   | Ναι    | -          | Σταθερά `MiniMax-H3`                                  |
| `content`      | object[] | Ναι    | -          | Πολυτροπικός πίνακας περιεχομένου, πρέπει να περιλαμβάνει ένα μη κενό στοιχείο `text`                         |
| `resolution`   | string   | Ναι    | -          | `768P` ή `2K`                                     |
| `duration`     | integer  | Ναι    | -          | Διάρκεια δημιουργίας, ακέραιος 4-15 δευτερολέπτων                                     |
| `ratio`        | string   | Υποχρεωτικό υπό όρους | `adaptive` | `adaptive`、`21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16` |
| `async`        | boolean  | Όχι    | `false`    | Όταν είναι `true`, επιστρέφει αμέσως το αναγνωριστικό εργασίας και λαμβάνει αποτελέσματα μέσω της διεπαφής εργασιών                       |
| `callback_url` | string   | Όχι    | -          | Δημόσια προσβάσιμο URL callback που λαμβάνει το τελικό αποτέλεσμα της εργασίας· μετά την παροχή του ενεργοποιεί αυτόματα την ασύγχρονη λειτουργία                     |

Οι κανόνες του `ratio` εξαρτώνται από τη ροή εργασίας:

- **Δημιουργία βίντεο από κείμενο**：Υποχρεωτικό και δεν μπορεί να είναι `adaptive`.
- **Βίντεο πρώτου καρέ, τελευταίου καρέ ή πρώτου και τελευταίου καρέ**：Οι αναλογίες καθορίζονται από τις εικόνες εισόδου· συνιστάται να το παραλείψετε ή να περάσετε `adaptive`.
- **Δημιουργία βίντεο με πολυτροπικές αναφορές**：Μπορεί να παραλειφθεί, η προεπιλογή είναι `adaptive`· μπορείτε επίσης να καθορίσετε ρητά μία σταθερή αναλογία.

Η διεπαφή δεν δέχεται παλαιότερα ή συμβατά πεδία, όπως `prompt`, `image_urls`, `audio_urls`, `messages` και `first_frame_image`. Όταν λαμβάνετε σφάλματα για τέτοιες παραμέτρους, διαγράψτε τα παλιά πεδία και μεταφέρετέ τα στο `content`· για παράδειγμα, αλλάξτε το `"prompt": "一只猫挥手"` σε `"content": [{"type": "text", "text": "一只猫挥手"}]`。Μην στέλνετε ταυτόχρονα και τις δύο μορφές, νέα και παλιά.

## Παράμετροι στοιχείων περιεχομένου content

Κάθε στοιχείο περιεχομένου πρέπει να έχει `type`, ενώ τα υπόλοιπα πεδία καθορίζονται από τον τύπο:

| `type`      | Πεδίο δεδομένων            | `role`            | Περιγραφή                                     |
| ----------- | --------------- | ----------------- | -------------------------------------- |
| `text`      | `text`          | Δεν περνάει                | Κάθε αίτημα πρέπει να περιλαμβάνει ένα μη κενό στοιχείο κειμένου, έως 7000 χαρακτήρες             |
| `image_url` | `image_url.url` | `first_frame`     | Εικόνα πρώτου καρέ· όταν υπάρχει μόνο μία εικόνα και παραλείπεται το `role`, αντιμετωπίζεται επίσης ως πρώτο καρέ         |
| `image_url` | `image_url.url` | `last_frame`      | Εικόνα τελευταίου καρέ· μπορεί να χρησιμοποιηθεί μόνη της ή σε συνδυασμό με `first_frame` για έλεγχο αρχής και τέλους |
| `image_url` | `image_url.url` | `reference_image` | Αναφορά θέματος, χαρακτήρα, προϊόντος, ενδυμασίας, σκηνής ή στυλ                    |
| `video_url` | `video_url.url` | `reference_video` | Αναφορά κινήσεων, κινήσεων κάμερας, ερμηνείας ή δομής μοντάζ                        |
| `audio_url` | `audio_url.url` | `reference_audio` | Αναφορά χροιάς, διαλόγου, μουσικής ή ρυθμού                          |

Οι διευθύνσεις μέσων υποστηρίζουν τρεις μορφές:

- Δημόσια προσβάσιμο HTTPS URL, συνιστάται για μεγάλα αρχεία.
- `mm_file://{file_id}`, αναφορά σε ήδη ανεβασμένο ή υπάρχον αρχείο αποτελέσματος.
- Base64 data URI του αντίστοιχου τύπου μέσου. Το Base64 αυξάνει το μέγεθος κατά περίπου ένα τρίτο· βεβαιωθείτε ότι ολόκληρο το σώμα αιτήματος δεν υπερβαίνει τα 64 MB.

## Προδιαγραφές υλικού και όρια ποσότητας
| Υλικό | Μορφή | Όριο ανά αρχείο | Διαστάσεις / Διάρκεια | Όριο ποσότητας |
| --- | ------------------------------------------- | --------- | --------------------------------------------------------------- | --------------------------- |
| Εικόνα | JPG、JPEG、PNG、WEBP、HEIC、HEIF | Όχι πάνω από 30 MB | Τόσο το πλάτος όσο και το ύψος είναι 256-5760 px；αναλογία πλάτους-ύψους 0.4-2.5 | Πρώτο καρέ έως 1 εικόνα、τελικό καρέ έως 1 εικόνα、εικόνες αναφοράς έως 9 |
| Βίντεο | MP4、MOV；H.264/AVC ή H.265/HEVC；κομμάτι ήχου AAC ή MP3 | Όχι πάνω από 50 MB | Κάθε τμήμα 2-15 δευτερόλεπτα, συνολικά όχι πάνω από 15 δευτερόλεπτα；τόσο το πλάτος όσο και το ύψος είναι 256-5760 px；αναλογία πλάτους-ύψους 0.4-2.5；23.976-60 fps | Έως 3 βίντεο αναφοράς |
| Ήχος | WAV、MP3 | Όχι πάνω από 15 MB | Κάθε τμήμα 2-15 δευτερόλεπτα, συνολικά όχι πάνω από 15 δευτερόλεπτα | Έως 3 ηχητικά αναφοράς |

Οι εικόνες, τα βίντεο και τα ηχητικά σε σενάρια πολυτροπικής αναφοράς ανέρχονται συνολικά σε έως 12 αρχεία. Το σενάριο πρώτου και τελευταίου καρέ και το σενάριο υλικών αναφοράς είναι αμοιβαία αποκλειόμενα: μόλις χρησιμοποιηθεί `reference_image`、`reference_video` ή `reference_audio`, δεν μπορούν πλέον να χρησιμοποιηθούν `first_frame` ή `last_frame`, και αντίστροφα.

## Επίδειξη δυνατοτήτων επιπέδου παραγωγής

Τα παρακάτω δεν είναι εννοιολογικές εικόνες ή υλικά-προσωρινά υποκατάστατα, αλλά πραγματικές είσοδοι αναφοράς και πραγματικές έξοδοι βίντεο από επίσημα δείγματα δυνατοτήτων επιπέδου παραγωγής του MiniMax H3. Οι τρεις ομάδες περιπτώσεων καλύπτουν αντίστοιχα διαφημιστικές ταινίες επωνυμίας, αφηγήσεις με πραγματικούς ανθρώπους και ηλεκτρονικό εμπόριο μόδας, κατάλληλες για την αξιολόγηση των πιο κρίσιμων δυνατοτήτων του μοντέλου στην εμπορική παραγωγή.

| Δυνατότητα | Κύρια σημεία παρατήρησης |
| -------- | --------------------------- |
| Συνέπεια χαρακτήρα και προσώπου | Εάν τα χαρακτηριστικά προσώπου, το χτένισμα, το μακιγιάζ και η προσωπικότητα του χαρακτήρα παραμένουν σταθερά μετά από εναλλαγές πολλαπλών πλάνων |
| Εκφράσεις προσώπου | Το βλέμμα, οι μικροεκφράσεις, η συναισθηματική ένταση και η φυσική κίνηση του κεφαλιού σε κοντινά πλάνα |
| Διατήρηση δομής προϊόντος | Το περίγραμμα, το υλικό, η σχέση χρήσης και οι κατοπτρικές αντανακλάσεις προϊόντων όπως γυαλιά και τσάντες |
| Εκτέλεση οπτικής ταυτότητας επωνυμίας | Εάν η ατμόσφαιρα της σκηνής, ο κινηματογραφικός κόκκος, τα χρώματα, το Logo και ο ρυθμός μοντάζ είναι ενοποιημένα |
| Κινηματογραφική αφήγηση | Εάν οι αλλαγές μεγέθους πλάνου, η σκηνοθεσία των χαρακτήρων, η κίνηση κάμερας, ο ρυθμός και ο ήχος μπορούν να σχηματίσουν ένα ολοκληρωμένο απόσπασμα |

Εδώ, η «δυνατότητα προσώπου» αναφέρεται στη συνέπεια εμφάνισης χαρακτήρων, στις λεπτομέρειες προσώπου και στον έλεγχο ερμηνείας στη δημιουργία βίντεο, και όχι στην αναγνώριση ταυτότητας, στη σύγκριση προσώπων ή σε διεπαφές αλλαγής προσώπου.

## Βίντεο από κείμενο

Όταν υπάρχει μόνο ένα στοιχείο κειμένου, πρόκειται για βίντεο από κείμενο. Είναι κατάλληλο για την άμεση δημιουργία εικόνων από δημιουργικές ιδέες, σενάρια ή περιγραφές πλάνων. Το prompt μπορεί να οργανωθεί με τη σειρά «θέμα + ενέργεια + σκηνή + κάμερα + φωτισμός + ήχος».

```bash
curl -X POST 'https://api.acedata.cloud/minimax/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MiniMax-H3",
    "content": [
      {
        "type": "text",
        "text": "15 秒电影级香水广告：清晨海岸的黑色礁石上，透明香水瓶被薄雾与海浪环绕。微距展现瓶身水珠和玻璃折射，镜头从产品特写缓慢拉升到广阔海面；银蓝色调，真实自然光，高级克制，结尾定格产品。"
      }
    ],
    "resolution": "2K",
    "duration": 15,
    "ratio": "16:9"
  }'
```

Η προεπιλεγμένη σύγχρονη λειτουργία επιστρέφει την πλήρη εργασία μετά την ολοκλήρωση της δημιουργίας:

```json
{
  "task": {
    "id": "f5977217-ed2c-40da-adbe-93d08235618f",
    "model": "MiniMax-H3",
    "status": "succeeded",
    "content": { "url": "https://cdn.acedata.cloud/minimax/f5977217.mp4" },
    "resolution": "2K",
    "duration": 15,
    "ratio": "16:9"
  }
}
```

Εάν προστεθεί το `"async": true` στο αίτημα, η διεπαφή επιστρέφει αμέσως:

```json
{
  "task_id": "f5977217-ed2c-40da-adbe-93d08235618f",
  "trace_id": "trace_7f8c2b1a"
}
```

## Βίντεο από εικόνα πρώτου καρέ

Σημειώστε την εικόνα ως `first_frame` και το μοντέλο θα αρχίσει να δημιουργεί από αυτό το πλάνο. Είναι κατάλληλο για να δώσει φυσική κίνηση σε αφίσες, εικόνες προϊόντων, εικόνες σχεδιασμού χαρακτήρων και φωτογραφικά έργα.

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "人物自然呼吸并看向窗外，衣角被微风吹动，镜头缓慢推进"
    },
    {
      "type": "image_url",
      "image_url": {
        "url": "https://cdn.acedata.cloud/b1c82e4937.png"
      },
      "role": "first_frame"
    }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "adaptive"
}
```

## Τελευταίο καρέ και βίντεο με πρώτο και τελευταίο καρέ
Η παροχή μόνο του `last_frame` επιτρέπει στο μοντέλο να δημιουργήσει φυσικά έως το καθορισμένο πλάνο· η ταυτόχρονη παροχή `first_frame` και `last_frame` επιτρέπει τον σαφή έλεγχο του σημείου έναρξης και λήξης. Κατάλληλο για μεταβάσεις, αλλαγές μορφής, διαδικασίες ανάπτυξης ή συγκρίσεις προϊόντων πριν και μετά.

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "女孩从童年自然成长为青年，时间流逝平滑，人物始终位于画面中央"
    },
    {
      "type": "image_url",
      "image_url": { "url": "YOUR_FIRST_FRAME_URL" },
      "role": "first_frame"
    },
    {
      "type": "image_url",
      "image_url": { "url": "YOUR_LAST_FRAME_URL" },
      "role": "last_frame"
    }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "adaptive"
}
```

Οι διαστάσεις και η αναλογία πλάτους-ύψους του πρώτου και του τελευταίου καρέ θα πρέπει να είναι όσο το δυνατόν πιο συνεπείς, ενώ οι διαφορές στη θέση του κύριου θέματος, τη σύνθεση και τον φωτισμό δεν θα πρέπει να είναι υπερβολικά μεγάλες· έτσι είναι ευκολότερο να επιτευχθεί μια φυσική μετάβαση.

## Δημιουργία βίντεο με πολυτροπικές αναφορές

Τα υλικά αναφοράς μπορούν να χρησιμοποιηθούν συνδυαστικά: οι εικόνες αναφοράς ελέγχουν την εμφάνιση χαρακτήρων ή προϊόντων, τα βίντεο αναφοράς ελέγχουν τις κινήσεις και την κίνηση της κάμερας, και ο ήχος αναφοράς ελέγχει τη χροιά των διαλόγων, τη μουσική ή τον ρυθμό μοντάζ. Στο prompt θα πρέπει να αναφέρεται σαφώς τι πρέπει να ελέγχει κάθε είδος υλικού, ώστε να αποφεύγεται η απλή μεταφόρτωση υλικών χωρίς να δίνεται σχέση μεταξύ τους.

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "保持参考人物的五官、发型与服装一致，按照参考视频中的表演动作完成时尚短片；镜头节奏跟随参考音频，近景突出自然面部表情"
    },
    {
      "type": "image_url",
      "image_url": { "url": "YOUR_CHARACTER_IMAGE_URL" },
      "role": "reference_image"
    },
    {
      "type": "video_url",
      "video_url": { "url": "YOUR_PERFORMANCE_VIDEO_URL" },
      "role": "reference_video"
    },
    {
      "type": "audio_url",
      "audio_url": { "url": "YOUR_AUDIO_URL" },
      "role": "reference_audio"
    }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "adaptive"
}
```

## Ειδοποίηση callback

Η παροχή `callback_url` ενεργοποιεί αυτόματα την ασύγχρονη λειτουργία: το API δημιουργίας επιστρέφει αμέσως `task_id` και `trace_id` και, μετά την ολοκλήρωση της εργασίας, αποστέλλει μέσω POST το τελικό αποτέλεσμα σε αυτήν τη διεύθυνση, με δομή ίδια με την απόκριση ερωτήματος εργασίας.

Οι τελικές καταστάσεις στο callback είναι `succeeded`, `failed` ή `cancelled`. Ακόμη και αν χρησιμοποιείται callback, συνιστάται η αποθήκευση του `task_id`, ώστε να είναι δυνατή η ενεργή αναζήτηση ή η αντιστάθμιση ειδοποιήσεων που δεν ελήφθησαν.

## Συνήθη σφάλματα

| Κωδικός κατάστασης HTTP | Σημασία | Προτεινόμενος χειρισμός |
| -------- | ------------ | ------------------------------ |
| `400`    | Σφάλμα παραμέτρων ή μη έγκυρος συνδυασμός υλικών | Ελέγξτε τα υποχρεωτικά πεδία, το `role`, τον αριθμό και τη μορφή των υλικών |
| `401`    | Το Token λείπει ή δεν είναι έγκυρο | Ελέγξτε το `Authorization: Bearer ...` |
| `402`    | Ανεπαρκές υπόλοιπο ή όριο | Προσθέστε γενικό υπόλοιπο στην κονσόλα |
| `422`    | Αποτυχία ελέγχου ασφάλειας περιεχομένου | Προσαρμόστε το prompt ή τα υλικά και υποβάλετε ξανά |
| `429`    | Τα αιτήματα είναι υπερβολικά συχνά | Επαναλάβετε μετά από εκθετική υποχώρηση· συνιστάται διάστημα περίπου 10 δευτερολέπτων για την αναζήτηση εργασιών |
| `500`    | Η υπηρεσία είναι προσωρινά μη διαθέσιμη | Διατηρήστε τις πληροφορίες του αιτήματος και προσπαθήστε ξανά αργότερα |

Το `task.status: succeeded` στη σύγχρονη απόκριση υποδεικνύει ότι το βίντεο έχει δημιουργηθεί· η ασύγχρονη επιβεβαίωση σημαίνει μόνο ότι η εργασία έχει εισέλθει στην ουρά. Χρέωση γίνεται μόνο όταν η εργασία ολοκληρωθεί επιτυχώς· το ίδιο το ερώτημα εργασίας είναι δωρεάν και δεν θα υπάρξει επαναλαμβανόμενη χρέωση.

### H3 Max

Το `MiniMax-H3-Max` υποστηρίζει 480P ή 768P και ακέραια διάρκεια 5–15 δευτερολέπτων. Η είσοδος ήχου δεν χρεώνεται επιπλέον, οι πρώτες 2 εικόνες είναι δωρεάν και το επιπλέον μέρος χρεώνεται ανά εικόνα· τα βίντεο αναφοράς χρεώνονται βάσει της πραγματικής διάρκειας εισόδου. Αυτό το μοντέλο δεν υποστηρίζει 2K.
