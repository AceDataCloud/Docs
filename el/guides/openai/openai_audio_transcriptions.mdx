title: "OpenAI API αναγνώρισης ομιλίας (/v1/audio/transcriptions)"
description: "OpenAI generation API guide - Ace Data Cloud"
---

Μετατρέπει τον ήχο σε κείμενο, **εντελώς συμβατό με το OpenAI `/v1/audio/transcriptions`**. Οποιοδήποτε OpenAI SDK απλά χρειάζεται να ορίσει το `base_url` σε `https://api.acedata.cloud` και να αντικαταστήσει το κλειδί με το AceData Token σας για άμεση χρήση. Υποστηρίζει κανονική πλήρη απάντηση, καθώς και SSE αυξανόμενη μεταγραφή για το `gpt-transcribe`.

- **Διεύθυνση αιτήματος**: `POST https://api.acedata.cloud/v1/audio/transcriptions` (ψευδώνυμο `POST /openai/audio/transcriptions`)
- **Εξουσιοδότηση**: Επικεφαλίδα αιτήματος `Authorization: Bearer {token}`
- **Μορφή αιτήματος**: `multipart/form-data`
- **Χρέωση**: Χρεώνεται ανά διάρκεια ήχου (βλ. παρακάτω πίνακα), λιγότερο από 1 δευτερόλεπτο χρεώνεται ως 1 δευτερόλεπτο.

## Παράμετροι αιτήματος

| Πεδίο                          | Τύπος      | Υποχρεωτικό  | Περιγραφή                                                                                         |
| --------------------------- | ------- | --- | ------------------------------------------------------------------------------------------ |
| `file`                      | file    | Ναι   | Το αρχείο ήχου που θα μεταγραφεί, μέγιστο 25 MB. Υποστηρίζει `flac`, `mp3`, `mp4`, `mpeg`, `mpga`, `m4a`, `ogg`, `wav`, `webm`.            |
| `model`                     | string  | Όχι   | `whisper-1` (προεπιλογή) ή `gpt-transcribe`, διαφορές ικανοτήτων βλ. παρακάτω πίνακα.                                                 |
| `language`                  | string  | Όχι   | Γλώσσα ήχου, κωδικός ISO-639-1 (π.χ. `zh`, `en`). Συμπλήρωση μπορεί να βελτιώσει την ακρίβεια και την ταχύτητα· αν αφεθεί κενό, αναγνωρίζεται αυτόματα.                                        |
| `prompt`                    | string  | Όχι   | Λέξεις-κλειδιά για καθοδήγηση στυλ γραφής ή παροχή ειδικών ονομάτων, όρων για βελτίωση της ακρίβειας αναγνώρισης.                                                           |
| `response_format`           | string  | Όχι   | `whisper-1`: `json` (προεπιλογή), `text`, `srt`, `verbose_json`, `vtt`; `gpt-transcribe`: μόνο `json`, `text`. |
| `temperature`               | number  | Όχι   | Θερμοκρασία δειγματοληψίας 0–1, προεπιλογή 0.                                                                             |
| `timestamp_granularities[]` | array   | Όχι   | Λεπτομέρεια χρονικών σημάνσεων, `word` ή `segment`, πρέπει να χρησιμοποιείται με `response_format=verbose_json`.                            |
| `languages[]`               | array   | Όχι   | Υποψήφιες γλώσσες (ISO-639-1), **μόνο `gpt-transcribe`**. Αντίθετες με το `language`, μην στέλνετε και τα δύο ταυτόχρονα.                              |
| `keywords[]`                | array   | Όχι   | Λέξεις-κλειδιά/όροι, **μόνο `gpt-transcribe`**, μπορεί να βελτιώσει σημαντικά την ακρίβεια αναγνώρισης ονομάτων και εμπορικών σημάτων.                                        |
| `stream`                    | boolean | Όχι   | Όταν το `gpt-transcribe` είναι `true`, επιστρέφει SSE αυξανόμενα γεγονότα· το `whisper-1` θα αγνοήσει αυτή την παράμετρο και θα επιστρέψει πλήρη αποτελέσματα (σύμφωνα με τη συμπεριφορά του OpenAI).        |

## Ποιο μοντέλο να επιλέξετε

|                              | `whisper-1`      | `gpt-transcribe`      |
| ---------------------------- | ---------------- | --------------------- |
| Τιμή                           | $0.0078 / λεπτό     | **$0.0059 / λεπτό** (φθηνότερο) |
| Ακρίβεια αναγνώρισης                        | Καλή               | **Καλύτερη**, ειδικά για ονόματα εμπορικών σημάτων και ειδικά ονόματα    |
| Έξοδος υποτίτλων (`srt`/`vtt`)            | ✅                | ❌                     |
| Χρονικές σημάνσεις λέξεων                        | ✅                | ❌                     |
| `languages[]` / `keywords[]` | ❌                | ✅                     |
| Επιστροφή ανιχνευόμενης γλώσσας                     | απαιτεί `verbose_json` | προεπιλογή επιστροφής                  |
| SSE αυξανόμενη επιστροφή                     | ❌ (η `stream` αγνοείται)  | ✅                     |

**Χρειάζεστε υποτίτλους ή χρονικές σημάνσεις λέξεων → `whisper-1`; για άλλες περιπτώσεις προτείνεται το `gpt-transcribe`** (πιο ακριβές και φθηνότερο).

## Παράδειγμα

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/transcriptions' \
  -H 'authorization: Bearer {token}' \
  -F file=@audio.mp3 \
  -F model=whisper-1
```

Επιστροφή:

```json
{
  "text": "Η πλατφόρμα Ace Data Cloud δοκιμάζει το σημείο αναγνώρισης ομιλίας. Η γρήγορη καφέ αλεπού πηδά πάνω από τον τεμπέλη σκύλο."
}
```

Η κινεζική ηχητική υποστηρίζεται επίσης, χωρίς να χρειάζεται να καθορίσετε γλώσσα:

```json
{
  "text": "Καλώς ήρθατε στην πλατφόρμα AceData Cloud, δοκιμάζουμε το API αναγνώρισης ομιλίας, σήμερα είναι 31 Ιουλίου."
}
```

### Δημιουργία υποτίτλων

Ορίστε το `response_format` σε `srt` ή `vtt` για να λάβετε άμεσα ένα αρχείο υποτίτλων:

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/transcriptions' \
  -H 'authorization: Bearer {token}' \
  -F file=@audio.mp3 \
  -F model=whisper-1 \
  -F response_format=srt \
  -o subtitle.srt
```

Επιστροφή περιεχομένου ( `Content-Type: text/plain` ):

```
1
00:00:00,000 --> 00:00:03,800
Η πλατφόρμα Ace Data Cloud δοκιμάζει το σημείο αναγνώρισης ομιλίας.

2
00:00:03,800 --> 00:00:06,280
Η γρήγορη καφέ αλεπού πηδά πάνω από τον τεμπέλη σκύλο.
```

### Χρονικές σημάνσεις λέξεων

Αν χρειάζεστε την αρχή και το τέλος κάθε λέξης, χρησιμοποιήστε το `verbose_json` σε συνδυασμό με `timestamp_granularities[]=word`:

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/transcriptions' \
  -H 'authorization: Bearer {token}' \
  -F file=@audio.mp3 \
  -F model=whisper-1 \
  -F response_format=verbose_json \
  -F 'timestamp_granularities[]=word'
```

Επιστροφή:

```json
{
  "task": "transcribe",
  "language": "english",
  "duration": 6.29,
  "text": "Η πλατφόρμα Ace Data Cloud δοκιμάζει το σημείο αναγνώρισης ομιλίας. Η γρήγορη καφέ αλεπού πηδά πάνω από τον τεμπέλη σκύλο.",
  "words": [
    {
      "word": "Η",
      "start": 0.0,
      "end": 0.32
    },
    {
      "word": "πλατφόρμα",
      "start": 0.32,
      "end": 0.54
    },
    {
      "word": "Ace",
      "start": 0.54,
      "end": 0.86
    }
  ]
}
```

### Ροή μεταγραφής

Το `gpt-transcribe` μπορεί να επιστρέψει `Content-Type: text/event-stream` μέσω του `stream=true`. Η υπηρεσία θα στείλει γεγονότα συμβατά με το OpenAI:
`transcript.text.delta` φέρει αυξανόμενο κείμενο, `transcript.text.done` φέρει το πλήρες κείμενο και `usage` και δηλώνει κανονική ολοκλήρωση.

```shell
curl -N -X POST 'https://api.acedata.cloud/v1/audio/transcriptions' \
  -H 'authorization: Bearer {token}' \
  -F file=@audio.mp3 \
  -F model=gpt-transcribe \
  -F stream=true
```

Παράδειγμα ροής γεγονότων:

```text
data: {"type":"transcript.text.delta","delta":"Γειά"}

data: {"type":"transcript.text.done","text":"Γειά σου κόσμε","usage":{"type":"tokens","input_tokens":14,"output_tokens":3,"total_tokens":17}}
```

Η λήψη του `transcript.text.done` δηλώνει κανονική ολοκλήρωση. Αν η επεξεργασία αποτύχει μετά την εγκαθίδρυση της ροής, η σύνδεση θα τερματιστεί μετά το γεγονός `event: error`; η ενεργή αποσύνδεση από τον πελάτη θα ακυρώσει την τρέχουσα επεξεργασία και δεν θα συνεχίσει στο παρασκήνιο. Το `whisper-1` θα επιστρέψει κανονικά μη ροή απάντηση, ακόμη και αν παρασχεθεί `stream=true`.

### Χρήση επίσημου SDK
```python
from openai import OpenAI

client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
with open("audio.mp3", "rb") as f:
    result = client.audio.transcriptions.create(model="whisper-1", file=f)
print(result.text)
```

## Τιμές

| Μοντέλο            | Τιμή στην πλατφόρμα |
| ---------------- | ----------------- |
| `whisper-1`      | $0.0078 / λεπτό   |
| `gpt-transcribe` | $0.0059 / λεπτό   |

> Χρέωση με βάση τη πραγματική διάρκεια του ήχου, λιγότερο από 1 δευτερόλεπτο χρεώνεται ως 1 δευτερόλεπτο, η μέγιστη διάρκεια ανά αίτηση είναι 1 ώρα.

## Σημειώσεις

- Το μέγιστο μέγεθος αρχείου είναι **25 MB**. Αν υπερβαίνει, παρακαλώ χωρίστε το ή συμπιέστε το (συνήθως η μείωση του ρυθμού μετάδοσης αρκεί, η αναγνώριση ομιλίας δεν απαιτεί υψηλή ποιότητα ήχου).
- Το `gpt-transcribe` υποστηρίζει `stream=true` SSE; το `whisper-1` θα αγνοήσει το `stream` και θα επιστρέψει το πλήρες αποτέλεσμα.
- Οι παράμετροι παραμένουν συνεπείς με το επίσημο OpenAI `/v1/audio/transcriptions`, το επίσημο SDK χρειάζεται μόνο να αλλάξει το `base_url` για να χρησιμοποιηθεί.
- Οι παράμετροι `include[]`, `chunking_strategy`, `known_speaker_names[]`, `known_speaker_references[]` ανήκουν σε μοντέλα μεταγραφής που δεν έχουμε διαθέσει, η εισαγωγή τους θα επιστρέψει 400 αντί να αγνοηθεί σιωπηλά. Οι ειδικές παράμετροι του μοντέλου (`timestamp_granularities[]` για το `whisper-1`, `languages[]`/`keywords[]` για το `gpt-transcribe`) θα επιστρέψουν επίσης 400 αν δοθούν σε μοντέλα που δεν τις υποστηρίζουν.
- Οι αιτήσεις είναι χρονοβόρες, προτείνεται η ρύθμιση χρόνου λήξης του πελάτη να μην είναι μικρότερη από 300 δευτερόλεπτα.

## Κωδικοί σφαλμάτων

| Κωδικός κατάστασης | code                    | Περιγραφή                                                                                                                                                   |
| ---------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 400              | `bad_request`           | Δεν παρέχεται `file`, το αρχείο δεν μπορεί να αναλυθεί, ή οι παράμετροι είναι μη έγκυρες (`model`/`response_format` μη υποστηριζόμενες τιμές, `temperature` εκτός 0–1, `timestamp_granularities[]` χωρίς `verbose_json`, εισαγωγή παραμέτρων που δεν υποστηρίζονται από το `whisper-1`). |
| 401              | `authentication_failed` | Το token είναι μη έγκυρο.                                                                                                                                            |
| 403              | `used_up`               | Υπόλοιπο ανεπαρκές.                                                                                                                                                |
| 413              | `request_too_large`     | Το αρχείο ήχου υπερβαίνει το όριο των 25 MB.                                                                                                                                     |
| 429              | `too_many_requests`     | Οι αιτήσεις είναι πολύ συχνές, παρακαλώ δοκιμάστε ξανά αργότερα.                                                                                                                                        |
| 500              | `api_error`             | Εσωτερικό σφάλμα υπηρεσίας, παρακαλώ δοκιμάστε ξανά αργότερα.                                                                                                                                        |
