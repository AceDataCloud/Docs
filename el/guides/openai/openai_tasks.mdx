OpenAI Tasks API χρησιμοποιείται για την αναζήτηση των αποτελεσμάτων των εργασιών που υποβλήθηκαν προηγουμένως στο OpenAI εικόνας μέσω **callback mode**. Όταν δεν μπορείτε να περιμένετε για συγχρονισμένη HTTP απάντηση ή θέλετε να ελέγξετε ξανά την εργασία αργότερα, χρησιμοποιήστε αυτή τη διεπαφή.

Στη λειτουργία callback, **η αρχική διεπαφή εικόνας θα επιστρέψει αμέσως ένα `task_id`** αφού επεξεργαστεί το αίτημα, και μπορείτε να κρατήσετε αυτό το `task_id` και να το χρησιμοποιήσετε για να ελέγξετε αυτή τη διεπαφή όποτε χρειαστεί, χωρίς να χρειάζεται να περάσετε επιπλέον προσαρμοσμένο `trace_id` (μόνο αν θέλετε να το συσχετίσετε με το δικό σας αναγνωριστικό επιχείρησης).

> Μόνο όταν το αρχικό αίτημα εικόνας περιλαμβάνει `callback_url`, η εργασία θα διατηρηθεί. Τα αιτήματα που καλούνται με συγχρονισμένο (μη callback) τρόπο δεν θα αποθηκευτούν.

## Διαδικασία αίτησης

Η OpenAI Tasks API μοιράζεται την εξουσιοδότηση με τις υπάρχουσες υπηρεσίες OpenAI. Εάν έχετε ήδη υποβάλει αίτηση για OpenAI Images Generations, μπορείτε να χρησιμοποιήσετε το ίδιο token για να καλέσετε αυτή τη διεπαφή, χωρίς να χρειάζεται να υποβάλετε επιπλέον αίτηση.

Οι νέοι χρήστες έχουν δωρεάν πιστώσεις κατά την πρώτη τους αίτηση.

## Διεύθυνση διεπαφής

```
POST https://api.acedata.cloud/openai/tasks
```

Υποστηριζόμενη `action`:

| Ενέργεια          | Περιγραφή                                                   |
| ---------------- | ---------------------------------------------------------- |
| `retrieve`       | Αναζητήστε μία εργασία μέσω `id` ή `trace_id`                     |
| `retrieve_batch` | Αναζητήστε μαζικά μέσω `ids` / `trace_ids` / `application_id` / `user_id` |

## Κεφαλίδες αιτήματος

- `accept: application/json`
- `authorization: Bearer {token}`
- `content-type: application/json`

## Ερώτημα για μία εργασία (`retrieve`)

### Σώμα αιτήματος

| Πεδίο         | Τύπος     | Υποχρεωτικό | Περιγραφή                                  |
| ---------- | ------ | --- | ----------------------------------- |
| `action`   | string | Ναι   | Σταθερό ως `retrieve`                      |
| `id`       | string | Δύο επιλογές | Το ID της εργασίας που επιστράφηκε στη συγχρονισμένη απάντηση κατά την υποβολή του αιτήματος εικόνας (συνιστάται η χρήση)          |
| `trace_id` | string | Δύο επιλογές | Χρειάζεται μόνο αν έχετε περάσει ρητά ένα προσαρμοσμένο `trace_id` στην αρχική αίτηση |

Πρέπει να περάσετε τουλάχιστον ένα από τα `id` και `trace_id`. Σε γενικές γραμμές, μπορείτε να χρησιμοποιήσετε απευθείας το `id` που επιστράφηκε στην απάντηση υποβολής, το `trace_id` χρειάζεται μόνο αν θέλετε να το συσχετίσετε με το δικό σας αναγνωριστικό επιχείρησης.

### Παράδειγμα κώδικα

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/openai/tasks' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "action": "retrieve",
    "id": "7489df4c-ef03-4de0-b598-e9a590793434"
  }'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/openai/tasks"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "action": "retrieve",
    "id": "7489df4c-ef03-4de0-b598-e9a590793434",
}
response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

### Περιγραφή πεδίων

- `id`: Το ID της εργασίας που δημιουργήθηκε κατά την επεξεργασία του αρχικού αιτήματος εικόνας.
- `trace_id`: Το προσαρμοσμένο αναγνωριστικό παρακολούθησης που περάστηκε στην αρχική αίτηση, διευκολύνοντας τη συσχέτιση με την επιχείρηση του πελάτη.
- `type`: Ο τύπος της εργασίας. Οι εργασίες που καταχωρούνται στη σειρά `gpt-image` (όπως `gpt-image-2`) είναι `images`; οι `gpt-image-1`, nano-banana κ.λπ. χρησιμοποιούν `images_generations` / `images_edits`, και ορισμένες διεπαφές συνομιλίας είναι `chat_completions_image`.
- `request`: Το πλήρες σώμα του αρχικού αιτήματος.
- `response`: Το τελικό σώμα της απάντησης που επιστρέφεται όταν ολοκληρωθεί το callback.
- `created_at` / `started_at` / `finished_at`: Unix χρονικές σφραγίδες (δευτερόλεπτα, κινητής υποδιαστολής).
- `elapsed`: Ο χρόνος εκτέλεσης (δευτερόλεπτα, κινητής υποδιαστολής).
- `application_id` / `user_id` / `credential_id`: Το ID της εφαρμογής, του τελικού χρήστη και των πιστοποιητικών.

## Μαζική αναζήτηση (`retrieve_batch`)

### Σώμα αιτήματος

| Πεδίο               | Τύπος       | Περιγραφή                                                       |
| ---------------- | -------- | -------------------------------------------------------- |
| `action`         | string   | Σταθερό ως `retrieve_batch`                                     |
| `ids`            | string[] | Αναζητήστε με βάση τη λίστα ID εργασιών                                              |
| `trace_ids`      | string[] | Αναζητήστε με βάση τη λίστα `trace_id`                                        |
| `application_id` | string   | Αναζητήστε όλες τις εργασίες με βάση την εφαρμογή                                                |
| `user_id`        | string   | Αναζητήστε όλες τις εργασίες με βάση τον τελικό χρήστη                                              |
| `type`           | string   | Φιλτράρετε με βάση τον τύπο εργασίας (τιμές: `images`, `images_generations`, `images_edits`) |
| `offset`         | int      | Αρχικό σημείο σελίδας, προεπιλογή `0`                                              |
| `limit`          | int      | Αριθμός ανά σελίδα, προεπιλογή `12`                                             |
| `created_at_min` | float    | Αρχική χρονική σφραγίδα (Unix δευτερόλεπτα)                                            |
| `created_at_max` | float    | Τελική χρονική σφραγίδα (Unix δευτερόλεπτα)                                            |

Πρέπει να περάσετε τουλάχιστον ένα από τα `ids` / `trace_ids` / `application_id` / `user_id` ή το χρονικό παράθυρο `created_at_*`.

## Παράδειγμα από άκρο σε άκρο: Υποβολή και polling

Το API των Tasks εξυπηρετεί κυρίως ασύγχρονες ροές σε λειτουργία callback. Σε λειτουργία callback, το endpoint υποβολής **επιστρέφει άμεσα συγχρονισμένα ένα `task_id`** (δηλαδή το αναγνωριστικό της εργασίας), και στη συνέχεια μπορείτε απλά να χρησιμοποιήσετε αυτό το `task_id` για polling στο endpoint των Tasks, χωρίς να χρειάζεται να δημιουργήσετε εσείς `trace_id`.

```python
import os, time, requests

API = "https://api.acedata.cloud"
HEADERS = {
    "authorization": f"Bearer {os.environ['ACEDATA_API_KEY']}",
    "content-type": "application/json",
}

# 1. Υποβολή εργασίας δημιουργίας εικόνας (λειτουργία callback: με το callback_url επιστρέφει αμέσως task_id)
submit = requests.post(
    f"{API}/openai/images/generations",
    headers=HEADERS,
    json={
        "model": "gpt-image-1",
        "prompt": "Μια γάτα σε υδατοχρωματικό στυλ που κάθεται πάνω σε ένα τραπέζι",
        "callback_url": "https://webhook.site/your-uuid",
    },
).json()
print("submitted:", submit)

task_id = submit["task_id"]

# 2. Χρησιμοποιήστε απευθείας το task_id από την απάντηση υποβολής για polling στο endpoint Tasks, μέχρι να ολοκληρωθεί η εργασία
while True:
    task = requests.post(
        f"{API}/openai/tasks",
        headers=HEADERS,
        json={"action": "retrieve", "id": task_id},
    ).json()
    if task and task.get("response"):
        print("finished:", task["response"])
        break
    time.sleep(3)
```

## Σημειώσεις

- Το endpoint Tasks **δεν χρεώνεται**, μπορείτε να κάνετε polling με ασφάλεια. Μόνο οι αρχικές αιτήσεις δημιουργίας/επεξεργασίας εικόνας χρεώνονται.
- Μόνο όταν η αρχική αίτηση περιλαμβάνει `callback_url`, καταγράφεται η εργασία· οι συγχρονισμένες κλήσεις δεν δημιουργούν εργασίες που μπορούν να ελεγχθούν.
- Οι εγγραφές εργασιών που ξεπερνούν την περίοδο διατήρησης της πλατφόρμας ενδέχεται να διαγραφούν.
