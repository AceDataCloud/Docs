## 1. Αποκτήστε API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), εισέλθετε σε μια διαθέσιμη εφαρμογή και αντιγράψτε το API Key.

![Αποκτήστε το Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Στείλτε το πρώτο αίτημα

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Η εικόνα της επιτυχημένης απόκρισης βρίσκεται στο `data[].url`. Ακολουθεί το αποτέλεσμα 1024×1536 που προέκυψε από πραγματικό αίτημα μέσω του Ace Data Cloud στις 8 Σεπτεμβρίου 2026 (εργασία `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Λευκή κούπα που δημιουργήθηκε από το GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Συνήθεις παράμετροι

| Πεδίο                | Περιγραφή                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (προτεινόμενο από προεπιλογή), `gpt-image-2.5-flare` (ταχύτερο) ή `gpt-image-2.5-sunburst` (υψηλότερη πιστότητα και έλεγχος)· και τα τρία μπορούν να επιλέξουν την αντίστοιχη παραλλαγή `:official`, ενώ το `gpt-image-2` υποστηρίζει επίσης το `:reverse` |
| `prompt`          | Περιγραφή εικόνας, έως 32.000 χαρακτήρες                                                                                                                     |
| `size`            | `auto` ή `WIDTHxHEIGHT`· το πλάτος και το ύψος πρέπει να είναι πολλαπλάσια του 16, η μεγάλη πλευρά δεν πρέπει να υπερβαίνει τα 3840, τα συνολικά pixel είναι 655.360–8.294.400 και ο λόγος διαστάσεων δεν πρέπει να υπερβαίνει το 3:1                                                       |
| `n`               | 1–10· όταν `response_format=b64_json`, υποστηρίζεται μόνο το 1                                                                                                 |
| `quality`         | Τα μοντέλα GPT Image υποστηρίζουν `auto`, `low`, `medium`, `high`· τα 2.5 / 2.6 Flare / Sunburst (συμπεριλαμβανομένου του `:official`) υποστηρίζουν επιπλέον `xhigh`, `max`. Το επίσημο κανάλι χρεώνει βάσει της πραγματικής χρήσης Token             |
| `response_format` | `url` ή `b64_json`                                                                                                                     |
| `callback_url`    | Προαιρετικό· αποστέλλει αποτελέσματα σε αυτήν τη διεύθυνση μετά την ολοκλήρωση μακροχρόνιων εργασιών                                                                                                                      |

Συνήθεις διαστάσεις:

| Αναλογία   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

Το `size: "auto"` επιλέγει το μέγεθος καμβά βάσει της αναλογίας, των pixel και της πρόθεσης διάταξης στο prompt· όταν απαιτούνται ακριβή pixel, συμπληρώστε απευθείας τις διαστάσεις.

## 4. Δημιουργία πολλαπλών εικόνων

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
Τα `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` και τα ψευδώνυμά τους `:reverse` χρεώνονται ανά επιτυχημένη εικόνα· τα `gpt-image-2:official`, `gpt-image-2.5-flare:official` και `gpt-image-2.5-sunburst:official` χρεώνονται βάσει των πραγματικών Token της εισόδου κειμένου και της εξόδου εικόνας στην απόκριση. Η τιμή στη σελίδα είναι εκτίμηση πριν από το αίτημα· η τελική χρέωση βασίζεται στα αρχεία χρήσης.

## 5. Ασύγχρονη επανάκληση

Αφού προστεθεί το `callback_url` στο σώμα του αιτήματος, η διεπαφή θα επιστρέψει πρώτα `{"task_id": "..."}` και, όταν ολοκληρωθεί, θα στείλει το τελικό αποτέλεσμα με POST σε αυτό το URL· τα σύγχρονα αιτήματα εξακολουθούν να επιστρέφουν `created` και `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Ο παραλήπτης της επανάκλησης θα πρέπει να χρησιμοποιεί το `task_id` για αποδιπλοποίηση και να επαληθεύει την προέλευση του αιτήματος και τη μορφή των δεδομένων.

## 6. Αντιμετώπιση προβλημάτων

| Κατάσταση | Έλεγχος |
| --- | --------------------------------------------------- |
| 400 | Συνδυασμός `model`, `prompt`, μορφής διαστάσεων, `n` και `response_format` |
| 401 | Αν το API Key είναι πλήρες, αν το Header είναι `Authorization: Bearer ...` |
| 429 | Τα αιτήματα είναι υπερβολικά συχνά, δοκιμάστε ξανά αργότερα |
| 504 | Λήξη χρονικού ορίου σύγχρονης δημιουργίας· χρησιμοποιήστε `callback_url` |

Οι αποκρίσεις σφάλματος περιλαμβάνουν `error.code`, `error.message` και `trace_id`. Όταν αναφέρετε κάποιο πρόβλημα, παρέχετε το `trace_id`, όχι το API Key.

Για τα πλήρη πεδία και τις απαριθμήσεις σε πραγματικό χρόνο, ανατρέξτε στη σελίδα [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Για επεξεργασία εικόνων, δείτε [GPT Image 2 / 2.5 / 2.6 Επεξεργασία εικόνων](https://platform.acedata.cloud/documents/openai-images-edits).

## GPT Image 2.6

Το GPT Image 2.6 συνεχίζει να χρησιμοποιεί τις διεπαφές δημιουργίας, επεξεργασίας, ασύγχρονων εργασιών και χρέωσης του 2.5:

| Μοντέλο | Χρέωση |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/εικόνα |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/εικόνα |
| `gpt-image-2.6-flare:official`                              | Ίδια με το 2.5 official, χρέωση βάσει πραγματικής χρήσης Token |
| `gpt-image-2.6-sunburst:official`                           | Ίδια με το 2.5 official, χρέωση βάσει πραγματικής χρήσης Token |

Η ποιότητα μπορεί να είναι `auto`, `low`, `medium`, `high`, `xhigh`, `max`· για τις διαστάσεις χρησιμοποιήστε `auto` ή `WIDTHxHEIGHT` που συμμορφώνεται με τους παραπάνω περιορισμούς. Αυτή η διεπαφή υποστηρίζει `png`, `jpeg`, `webp`· το GPT Image 2.6 υποστηρίζει επίσης εγγενή κινούμενα σχέδια `gif`, ενώ προς το παρόν δεν υποστηρίζει SVG. Η επεξεργασία υποστηρίζει URL εικόνων JSON και μεταφόρτωση αρχείων multipart. Το `:reverse` είναι ρητό ψευδώνυμο της κανονικής έκδοσης με το ίδιο όνομα. Χρησιμοποιήστε το πλήρες μοντέλο, μην στέλνετε `gpt-image-2.6`.

### Κινούμενα GIF GPT Image 2.6

Οι κανονικές εκδόσεις, οι εκδόσεις `:reverse` και οι εκδόσεις `:official` των GPT Image 2.6 Flare και Sunburst μπορούν όλες να χρησιμοποιούν `output_format: "gif"`. Τα καρέ της κίνησης, οι πληροφορίες επανάληψης και η διάρκεια αναπαραγωγής διατηρούνται· το `frame_count` δηλώνει τον αριθμό καρέ, το `frame_duration_ms` δηλώνει τα χιλιοστά του δευτερολέπτου ανά καρέ, ο αριθμός καρέ πρέπει να είναι ακέραιος από 2–16, η διάρκεια κάθε καρέ πρέπει να είναι ακέραιος από 20–655350 χιλιοστά του δευτερολέπτου και χρησιμοποιείται μόνο για GIF· η κωδικοποίηση στρογγυλοποιεί στο πλησιέστερο 10ms. Όταν δεν καθορίζονται, οι προεπιλογές είναι 9 καρέ και 200 χιλιοστά του δευτερολέπτου ανά καρέ· όταν το `size` για GIF παραλείπεται ή είναι auto, χρησιμοποιείται η προεπιλογή 512x512.

Συνιστάται να χρησιμοποιήσετε πρώτα `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. Τα GIF έχουν ανεξάρτητους περιορισμούς διαστάσεων και αριθμού καρέ και δεν μπορούν να χρησιμοποιούν απευθείας τις προδιαγραφές στατικών εικόνων 4K· ορισμένα μοντέλα προσαρμόζουν τις πραγματικές διαστάσεις εξόδου. Το `n` δηλώνει τον αριθμό των αρχείων GIF που επιστρέφονται, όχι τον αριθμό των καρέ της κίνησης. Η κανονική έκδοση και το `:reverse` εξακολουθούν να χρεώνονται βάσει του αριθμού επιτυχημένων αρχείων, ενώ η επίσημη έκδοση χρεώνεται βάσει της πραγματικής χρήσης Token.

```json
{
  "model": "gpt-image-2.6-flare",
  "prompt": "A small red ball moves left and right on a white background, seamless looping animation, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### Στατικές εικόνες 4K GPT Image 2.6

Τα Flare, Sunburst και οι παραλλαγές τους `:reverse`, `:official` μπορούν όλα να χρησιμοποιούν τις προαναφερθείσες προεπιλογές pixel 4K, όπως `3840x2160` και `2160x3840`. Τόσο η δημιουργία όσο και η επεξεργασία περνούν συγκεκριμένα pixel μέσω του `size`· το `4K` δεν είναι έγκυρη τιμή `size`, ενώ το `4096x4096` υπερβαίνει επίσης το τρέχον ανώτατο όριο pixel. Οι παραπάνω προδιαγραφές 4K ισχύουν για στατικά PNG/JPEG/WebP· για GIF χρησιμοποιήστε τις ειδικές παραμέτρους του.

### Πολυπλοκότητα σύνθεσης GPT Image 2.6

Το `complexity` μπορεί να είναι `low`, `medium`, `high`, ενώ όταν παραλείπεται χρησιμοποιείται η προεπιλογή μοντέλου `high`. Ελέγχει την πολυπλοκότητα σχεδιασμού και είναι ανεξάρτητο από την ποιότητα απόδοσης `quality`· δεν χρεώνεται επιπλέον ανά αίτημα και η επίσημη έκδοση εξακολουθεί να χρεώνεται βάσει των πραγματικών Token. Άλλα μοντέλα δεν υποστηρίζουν αυτή την παράμετρο.

Τα GIF δεν υποστηρίζουν mask, εικόνες σχολιασμού, προσαρμοσμένη συμπίεση, επανεγγραφή prompt ή μερική ροή εικόνας· ασύμβατοι συνδυασμοί απορρίπτονται πριν από τη δημιουργία. Οι διαστάσεις, ο αριθμός καρέ και η ποσότητα υπόκεινται από κοινού στον περιορισμό προϋπολογισμού pixel του μοντέλου· έχει επαληθευτεί ότι το `1024x1024`, 2 καρέ του κανονικού Flare λειτουργεί, αλλά αυτό το συμπέρασμα δεν μπορεί να επεκταθεί σε όλους τους συνδυασμούς 1K ή σε GIF 4K.
