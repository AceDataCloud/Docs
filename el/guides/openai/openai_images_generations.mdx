Το OpenAI Images Generations API υποστηρίζει επί του παρόντος πολλαπλά μοντέλα δημιουργίας εικόνων, συμπεριλαμβανομένων των κλασικών `dall-e-3`, του `gpt-image-1` με ισχυρότερη ικανότητα απόδοσης κειμένου, της τελευταίας γενιάς **`gpt-image-2`**, καθώς και της σειράς μοντέλων **`nano-banana` / `nano-banana-2` / `nano-banana-pro`** που ενσωματώνονται μέσω της ίδιας διεπαφής. Όλα αυτά μπορούν να δημιουργήσουν εικόνες υψηλής ποιότητας βάσει περιγραφής κειμένου.

Αυτό το έγγραφο παρουσιάζει κυρίως τη διαδικασία χρήσης του OpenAI Images Generations API, που μας επιτρέπει να χρησιμοποιούμε εύκολα τις λειτουργίες δημιουργίας εικόνων της σειράς OpenAI.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το OpenAI Images Generations API, μπορείτε πρώτα να μεταβείτε στη σελίδα [OpenAI Images Generations API](https://platform.acedata.cloud/documents/fd932485-90c7-45d6-8394-1e14b6f07b2b) και να κάνετε κλικ στο κουμπί «Acquire» για να λάβετε τα διαπιστευτήρια που απαιτούνται για το αίτημα:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για εγγραφή και σύνδεση. Μετά τη σύνδεση ή εγγραφή, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, παρέχεται δωρεάν όριο χρήσης, επιτρέποντας δωρεάν χρήση του API.

## Μοντέλο GPT-Image-2

Το `gpt-image-2` είναι το νέο μοντέλο δημιουργίας εικόνων της OpenAI, με σαφή βελτίωση σε σχέση με τα `dall-e-3` και `gpt-image-1` στα εξής σημεία:

- **Ικανότητα ακριβούς εκτέλεσης εντολών**: Μπορεί να κατανοήσει με ακρίβεια σύνθετες δομημένες εντολές όπως σύνθεση, μέτρηση, χωρικές σχέσεις.
- **Καθαρότερη απόδοση κειμένου**: Σκηνές όπως αφίσες, μενού, διαγράμματα, λογότυπα εμφανίζουν αγγλικά και αριθμούς σχεδόν χωρίς λάθη.
- **Πλουσιότερη έκφραση στυλ**: Υποστηρίζει εγγενώς πολλές αισθητικές όπως κινηματογραφικά πορτρέτα, ρετρό αφίσες, παιδικές εικονογραφήσεις, φωτογράφιση προϊόντων, διαγράμματα.
- **Εγγενής υποστήριξη πολλαπλών αναλογιών + υψηλής ανάλυσης**: Καλύπτει 5 αναλογίες (1:1, 4:3, 3:4, 16:9, 9:16) με 3 επίπεδα ανάλυσης (1K / 2K / 4K).

Ο τρόπος κλήσης είναι ακριβώς ίδιος με τα άλλα μοντέλα, απλά ορίζετε το πεδίο `model` σε `gpt-image-2`. Το πεδίο `url` στο αποτέλεσμα επιστρέφει έναν μόνιμο σύνδεσμο εικόνας που φιλοξενείται στο `platform.cdn.acedata.cloud`, ο οποίος μπορεί να ανοίξει απευθείας σε πρόγραμμα περιήγησης ή να ενσωματωθεί σε ιστοσελίδα.

### Υποστηριζόμενες τιμές `size` και επίπεδα χρέωσης

Το `gpt-image-2` ελέγχει μόνο τη μορφή του `size`: αν δεν είναι `auto` ή κενό, πρέπει να ταιριάζει με το πρότυπο `WIDTHxHEIGHT` (π.χ. `1024x1024`, `2048x1152`, `800x600`). Οποιαδήποτε άλλη μορφή επιστρέφει 400. Η χρέωση χωρίζεται σε δύο επίπεδα:

- **Τυπική τιμή 1K**: Εισαγωγή οποιουδήποτε από τα προτεινόμενα μεγέθη 1K στον παρακάτω πίνακα ή κοινά ψευδώνυμα 1K (`1254x1254`, `1672x941`, `941x1672` — αυτά είναι τα πραγματικά μεγέθη που επιστρέφονται από το upstream και δεν προκαλούν αλλαγή τιμής).
- **Άλλα επίπεδα (1.5×)**: Οποιοδήποτε μέγεθος εκτός της παραπάνω συλλογής 1K, συμπεριλαμβανομένων των προτεινόμενων 2K / 4K και οποιουδήποτε προσαρμοσμένου `WIDTHxHEIGHT`.

Οι αυστηροί περιορισμοί του upstream για προσαρμοσμένα μεγέθη είναι: πλάτος και ύψος πολλαπλάσια του 16, μέγιστη πλευρά ≤ 3840, συνολικοί εικονοστοιχεία ≤ 8.294.400. Υπερβάσεις απορρίπτονται με σφάλμα 4xx.

| Αναλογία | 1K (Τυπική τιμή) | 2K Προτεινόμενο (×1.5) | 4K Προτεινόμενο (×1.5) |
| --- | --- | --- | --- |
| 1:1 | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3 | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4 | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

> Μπορείτε επίσης να περάσετε `size: "auto"` ή να **παραλείψετε το πεδίο `size`**, οπότε το μοντέλο θα επιλέξει αυτόματα το προεπιλεγμένο μέγεθος και η χρέωση θα είναι στο επίπεδο 1K.
>
> Στο επίπεδο 1K, το μέγεθος που επιστρέφει το upstream δεν εγγυάται αυστηρή ευθυγράμμιση pixel — π.χ. αν περάσετε `1024x1024`, μπορεί να λάβετε `1254x1254` με διατήρηση αναλογίας. Αν το ξαναχρησιμοποιήσετε ως `size`, η χρέωση παραμένει 1K.
>
> Μια κλήση 4K συνήθως διαρκεί 4–8 λεπτά, συνιστάται η χρήση του `callback_url` για ασύγχρονη επιστροφή.

> **Σχετικά με την παράμετρο `n`**
>
> Το `gpt-image-2` **δεν υποστηρίζει `n > 1`**: η παράμετρος αγνοείται σιωπηρά, ανεξαρτήτως αν περάσετε `n=1` ή `n=10`, κάθε αίτημα επιστρέφει μόνο 1 εικόνα και χρεώνεται ως 1. Αν θέλετε πολλαπλές εικόνες, πρέπει να κάνετε πολλαπλά παράλληλα αιτήματα (συνιστάται να χρησιμοποιείτε διαφορετικά `prompt` ή `seed` για ποικιλία). Ο ίδιος περιορισμός ισχύει για `gpt-image-1` / `gpt-image-1.5` και τη σειρά `nano-banana`. Το `dall-e-2` είναι το μόνο μοντέλο που υποστηρίζει εγγενώς `n > 1`, ενώ το `dall-e-3` υποστηρίζει μόνο `n = 1`.

Παρακάτω παρουσιάζονται πραγματικά παραδείγματα που αναδεικνύουν τις δυνατότητες του `gpt-image-2`.

### Σκηνή 1: Κινηματογραφικό πορτρέτο

Στο prompt μπορείτε να χρησιμοποιήσετε κινηματογραφικούς όρους (φιλμ 35mm, ρηχό βάθος πεδίου, νέον κ.ά.) για ακριβή έλεγχο ατμόσφαιρας και υφής.

Παράδειγμα κλήσης Python:

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-image-2",
    "prompt": "A cinematic portrait of a young woman standing in a convenience store at night, illuminated by soft pink and cyan neon signs through the window. Shot on 35mm film, shallow depth of field, slight grain, melancholic mood.",
    "size": "1024x1536"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Παράδειγμα επιστρεφόμενου αποτελέσματος:

### Ασύγχρονη κλήση και επιστροφή

Η κλήση `gpt-image-2` συνήθως διαρκεί 60–90 δευτερόλεπτα. Αν δεν θέλετε να κρατάτε ανοιχτή σύνδεση, μπορείτε να χρησιμοποιήσετε τον μηχανισμό ασύγχρονης επιστροφής μέσω `callback_url`, με διαδικασία ίδια με τα άλλα μοντέλα.

## Σειρά Μοντέλων Nano Banana

Η σειρά `nano-banana` βασίζεται στο Gemini και ενσωματώνεται μέσω της ίδιας διεπαφής `/openai/images/generations`, χωρίς αλλαγή endpoint. Απλά αλλάξτε το `model` σε οποιοδήποτε από τα παρακάτω:

| Μοντέλο | Χρέωση (Credits / κλήση) | Κατάλληλο σενάριο |
| --- | --- | --- |
| `nano-banana` | 0.14 | Κανονική δημιουργία εικόνων, ταχύτερο και φθηνότερο |
| `nano-banana-2` | 0.28 | Βελτίωση ποιότητας και λεπτομερειών |
| `nano-banana-pro` | 0.35 | Ναυαρχίδα της σειράς, καλύτερη σύνθεση, λεπτομέρεια, κείμενο |

> **Σημαντικό: Υποστηριζόμενες παράμετροι**
>
> Το Nano Banana προσαρμόζει το πρωτόκολλο OpenAI και υποστηρίζει μόνο τις παραμέτρους: `model`, `prompt`, `size`.
>
> - Το `size` αντιστοιχίζεται εσωτερικά σε `aspect_ratio` ως εξής, άλλες διαστάσεις υποβαθμίζονται σε `1:1`:
>   - `1024x1024` / `512x512` / `256x256` → `1:1`
>   - `1792x1024` → `16:9`
>   - `1024x1792` → `9:16`
> - Δεν υποστηρίζονται `n`, `quality`, `style`, `response_format`, `background`, `output_format` κ.ά., και αγνοούνται αν δοθούν.
> - Η δομή επιστροφής ακολουθεί το OpenAI format (`data[].url`), αλλά το `created` είναι πάντα `0`, δεν επιστρέφεται `b64_json` και το `revised_prompt` ισούται πάντα με το αρχικό `prompt`.

### Βασική Κλήση

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "nano-banana",
    "prompt": "a small red apple on a white table, photoreal",
    "size": "1024x1024"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Βασική Χρήση

Μπορείτε να συμπληρώσετε τα αντίστοιχα πεδία στη διεπαφή, όπως φαίνεται στην εικόνα:

Δεξιά εμφανίζεται ο αντίστοιχος κώδικας κλήσης, τον οποίο μπορείτε να αντιγράψετε και να εκτελέσετε ή να πατήσετε το κουμπί «Try» για δοκιμή.

<p><img src="https://cdn.acedata.cloud/c0ps6i.png" width="500" className="m-auto" /></p>

import requests

url = "https://api.acedata.cloud/openai/images/generations"

## Ασύγχρονη Επιστροφή

Επειδή η δημιουργία εικόνων μέσω OpenAI Images Generations API μπορεί να διαρκέσει αρκετά, αν το API δεν απαντήσει άμεσα, το HTTP αίτημα παραμένει ανοιχτό, καταναλώνοντας πόρους. Γι’ αυτό το API υποστηρίζει ασύγχρονη επιστροφή.

Η διαδικασία είναι: ο πελάτης στέλνει αίτημα με επιπλέον πεδίο `callback_url`. Το API επιστρέφει αμέσως ένα αποτέλεσμα με `task_id` που αναγνωρίζει την εργασία. Όταν ολοκληρωθεί η δημιουργία, το αποτέλεσμα αποστέλλεται με POST JSON στο `callback_url` που ορίσατε, περιλαμβάνοντας το ίδιο `task_id` για συσχέτιση.

Παρακάτω ένα παράδειγμα:

Το Webhook callback είναι μια υπηρεσία που δέχεται HTTP αιτήματα. Αντικαταστήστε το URL με το δικό σας HTTP server. Για επίδειξη, χρησιμοποιούμε το δημόσιο https://webhook.site/, όπου μπορείτε να πάρετε ένα Webhook URL, όπως φαίνεται:

![](https://cdn.acedata.cloud/cjjfly.png)

Αντιγράψτε το URL, π.χ. `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`.

Ορίστε το πεδίο `callback_url` με το παραπάνω URL και στείλτε το αίτημα:

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "dall-e-3",
    "prompt": "A cute baby sea otter",
    "callback_url": "https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Αμέσως λαμβάνετε:

```json
{
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c"
}
```

Μετά από λίγο, στο Webhook URL βλέπετε το αποτέλεσμα:

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": {
    "created": 1721626477,
    "data": [
      {
        "revised_prompt": "A delightful image showcasing a young sea otter...",
        "url": "https://dalleprodsec.blob.core.windows.net/private/images/..."
      }
    ]
  }
}
```

Το `task_id` επιτρέπει τη συσχέτιση της εργασίας με το αποτέλεσμα.

## Διαχείριση Σφαλμάτων

Σε περίπτωση σφάλματος, το API επιστρέφει κωδικό και μήνυμα σφάλματος, π.χ.:

- `400 token_mismatched`: Κακό αίτημα, πιθανόν λόγω ελλιπών ή λανθασμένων παραμέτρων.
- `400 api_not_implemented`: Κακό αίτημα, πιθανόν λόγω ελλιπών ή λανθασμένων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, άκυρο ή ελλιπές token.
- `429 too_many_requests`: Πολλές αιτήσεις, υπερβήκατε το όριο.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.
