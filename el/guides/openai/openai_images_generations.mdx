DALL-E 3 είναι ένα μοντέλο δημιουργίας εικόνας που έχει αναπτυχθεί από την OpenAI, το οποίο μπορεί να δημιουργήσει εικόνες υψηλής ποιότητας με βάση περιγραφές κειμένου.

Αυτό το έγγραφο περιγράφει τη διαδικασία χρήσης του OpenAI Images Generations API, επιτρέποντάς μας να χρησιμοποιήσουμε εύκολα τη λειτουργία δημιουργίας εικόνας του επίσημου OpenAI DALL-E.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το OpenAI Images Generations API, μπορείτε πρώτα να επισκεφθείτε τη σελίδα [OpenAI Images Generations API](https://platform.acedata.cloud/documents/fd932485-90c7-45d6-8394-1e14b6f07b2b) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να χρησιμοποιήσετε το API δωρεάν.

## Βασική Χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε τα αντίστοιχα πεδία στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/zv58ug.png" width="500" class="m-auto"></p>

Κατά την πρώτη χρήση αυτού του API, πρέπει τουλάχιστον να συμπληρώσετε τρία πεδία: το ένα είναι το `authorization`, το οποίο μπορείτε να επιλέξετε απευθείας από τη λίστα. Το άλλο πεδίο είναι το `model`, το οποίο είναι η κατηγορία μοντέλου που επιλέγουμε να χρησιμοποιήσουμε από την επίσημη ιστοσελίδα του OpenAI DALL-E. Εδώ έχουμε κυρίως 1 μοντέλο, λεπτομέρειες μπορείτε να δείτε στα μοντέλα που παρέχουμε. Το τελευταίο πεδίο είναι το `prompt`, το οποίο είναι η λέξη-κλειδί που εισάγουμε για να δημιουργήσουμε την εικόνα.

Μπορείτε επίσης να παρατηρήσετε ότι στα δεξιά υπάρχει ο αντίστοιχος κώδικας κλήσης που μπορείτε να αντιγράψετε και να εκτελέσετε, ή μπορείτε να κάνετε κλικ στο κουμπί «Try» για να δοκιμάσετε.

<p><img src="https://cdn.acedata.cloud/pbss4f.png" width="500" class="m-auto"></p>

Παράδειγμα κώδικα κλήσης Python:

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "dall-e-3",
    "prompt": "A cute baby sea otter"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Παράμετροι Ποιότητας Εικόνας `quality`

Στη συνέχεια, θα περιγράψουμε πώς να ρυθμίσετε κάποιες λεπτομέρειες σχετικά με τα αποτελέσματα δημιουργίας εικόνας, όπου η παράμετρος ποιότητας εικόνας `quality` περιλαμβάνει δύο επιλογές: η πρώτη `standard` σημαίνει ότι δημιουργείται μια τυπική εικόνα, ενώ η άλλη `hd` σημαίνει ότι η δημιουργούμενη εικόνα έχει πιο λεπτομερείς λεπτομέρειες και μεγαλύτερη συνοχή.

## Ασύγχρονη κλήση

Δεδομένου ότι η API Generations Images της OpenAI μπορεί να χρειαστεί αρκετό χρόνο για να δημιουργήσει εικόνες, αν η API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση συστημικών πόρων, γι' αυτό η API παρέχει επίσης υποστήριξη για ασύγχρονη κλήση.

Η συνολική διαδικασία είναι: Όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`, μετά την υποβολή του API αίτημα, η API θα επιστρέψει αμέσως ένα αποτέλεσμα που περιλαμβάνει μια πληροφορία πεδίου `task_id`, που αντιπροσωπεύει το τρέχον ID εργασίας. Όταν η εργασία ολοκληρωθεί, το αποτέλεσμα της δημιουργίας εικόνας θα αποσταλεί μέσω POST JSON στη διεύθυνση `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε αυτό μέσω ενός παραδείγματος.

Πρώτον, η κλήση Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα, οι προγραμματιστές θα πρέπει να την αντικαταστήσουν με το URL του HTTP διακομιστή που έχουν δημιουργήσει. Για ευκολία, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να αποκτήσετε ένα URL Webhook, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/cjjfly.png)

Αντιγράψτε αυτό το URL και μπορείτε να το χρησιμοποιήσετε ως Webhook, το παράδειγμα εδώ είναι `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`.

Στη συνέχεια, μπορούμε να ρυθμίσουμε το πεδίο `callback_url` στο παραπάνω URL Webhook, ενώ συμπληρώνουμε τις αντίστοιχες παραμέτρους, όπως φαίνεται στον παρακάτω κώδικα:

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "dall-e-3",
    "prompt": "Ένα χαριτωμένο μωρό θαλάσσιο ενυδρίδιο",
    "callback_url": "https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Κάντε κλικ για εκτέλεση και μπορείτε να δείτε ότι θα λάβετε αμέσως ένα αποτέλεσμα, όπως παρακάτω:

```json
{
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c"
}
```

Μετά από λίγο, μπορούμε να παρατηρήσουμε το αποτέλεσμα της δημιουργίας εικόνας στη διεύθυνση URL Webhook, το περιεχόμενο είναι το εξής:

```json
{

  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",

  "data": {
```

Μπορείτε να δείτε ότι το αποτέλεσμα περιλαμβάνει ένα πεδίο `task_id`, το πεδίο `data` περιέχει τα αποτελέσματα δημιουργίας εικόνας όπως και στην συγχρονισμένη κλήση, μέσω του πεδίου `task_id` μπορεί να επιτευχθεί η συσχέτιση της εργασίας.

## Διαχείριση σφαλμάτων

Κατά την κλήση της API, αν προκύψουν σφάλματα, η API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
