## 1. Λήψη API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), εισέλθετε σε μια διαθέσιμη εφαρμογή και αντιγράψτε το API Key.

![Λήψη Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Αποστολή του πρώτου αιτήματος

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Η εικόνα της επιτυχημένης απόκρισης βρίσκεται στο `data[].url`. Παρακάτω είναι το αποτέλεσμα 1024×1536 που λήφθηκε μέσω πραγματικού αιτήματος από το Ace Data Cloud στις 8 Σεπτεμβρίου 2026 (εργασία `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Λευκή κούπα που δημιουργήθηκε από το GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Συνήθεις παράμετροι

| Πεδίο                | Περιγραφή                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (συνιστάται από προεπιλογή), `gpt-image-2.5-flare` (ταχύτερο) ή `gpt-image-2.5-sunburst` (υψηλότερη πιστότητα και έλεγχος)· και τα τρία μπορούν να επιλέξουν την αντίστοιχη παραλλαγή `:official`, ενώ το `gpt-image-2` υποστηρίζει επίσης `:reverse` |
| `prompt`          | Περιγραφή εικόνας, έως 32.000 χαρακτήρες                                                                                                                     |
| `size`            | `auto` ή `WIDTHxHEIGHT`· το πλάτος και το ύψος πρέπει να είναι πολλαπλάσια του 16, η μεγάλη πλευρά δεν πρέπει να υπερβαίνει τα 3840, τα συνολικά pixel πρέπει να είναι 655.360–8.294.400 και ο λόγος διαστάσεων δεν πρέπει να υπερβαίνει το 3:1                                                       |
| `n`               | 1–10· όταν `response_format=b64_json`, υποστηρίζεται μόνο το 1                                                                                                 |
| `quality`         | `low`, `medium`, `high` ή `auto`· η υποστήριξη και η χρέωση διαφέρουν ανάλογα με το κανάλι                                                                                          |
| `response_format` | `url` ή `b64_json`                                                                                                                     |
| `callback_url`    | Προαιρετικό· στέλνει αποτελέσματα σε αυτή τη διεύθυνση μετά την ολοκλήρωση μακροχρόνιων εργασιών                                                                                                                      |

Συνήθεις διαστάσεις:

| Αναλογία   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

Το `size: "auto"` επιλέγει διαστάσεις καμβά με βάση την αναλογία, τα pixel και την πρόθεση διάταξης στο prompt· όταν απαιτούνται ακριβή pixel, συμπληρώστε απευθείας τις διαστάσεις.

### Μοντέλα και μέθοδοι χρέωσης

| Μοντέλο                                | Εφαρμόσιμα σενάρια και μέθοδος χρέωσης                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Προεπιλεγμένο αντίστροφο κανάλι, σταθερή χρέωση ανά αριθμό επιτυχημένων εικόνων                        |
| `gpt-image-2:reverse`             | Ρητή επιλογή αντίστροφου καναλιού, σταθερή χρέωση ανά αριθμό επιτυχημένων εικόνων                      |
| `gpt-image-2:official`            | Επίσημο κανάλι API, υψηλότερη σταθερότητα, χρέωση βάσει πραγματικής χρήσης Token            |
| `gpt-image-2.5-flare`             | Εστιάζει στην ταχύτητα δημιουργίας, σταθερή χρέωση ανά αριθμό επιτυχημένων εικόνων                        |
| `gpt-image-2.5-flare:official`    | Επίσημο κανάλι API, υψηλότερη σταθερότητα και εστίαση στην ταχύτητα δημιουργίας, χρέωση βάσει πραγματικής χρήσης Token     |
| `gpt-image-2.5-sunburst`          | Εστιάζει στην υψηλή πιστότητα και τον λεπτομερή έλεγχο, σταθερή χρέωση ανά αριθμό επιτυχημένων εικόνων                    |
| `gpt-image-2.5-sunburst:official` | Επίσημο κανάλι API, υψηλότερη σταθερότητα και εστίαση στην υψηλή πιστότητα και τον λεπτομερή έλεγχο, χρέωση βάσει πραγματικής χρήσης Token |

Η τιμή στη σελίδα για το επίσημο κανάλι API είναι εκτίμηση πριν από το αίτημα· το τελικό ποσό βασίζεται στην πραγματική χρήση Token στην απόκριση και στα αρχεία χρήσης.

## 4. Δημιουργία πολλών εικόνων

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

Τα `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` και `gpt-image-2:reverse` χρεώνονται ανά αριθμό επιτυχημένων εικόνων· τα `gpt-image-2:official`, `gpt-image-2.5-flare:official` και `gpt-image-2.5-sunburst:official` χρεώνονται βάσει των πραγματικών Token εισόδου κειμένου και εξόδου εικόνας στην απόκριση. Η τιμή στη σελίδα είναι εκτίμηση πριν από το αίτημα· το τελικό ποσό βασίζεται στα αρχεία χρήσης.

## 5. Ασύγχρονο callback

Μετά την προσθήκη του `callback_url` στο σώμα του αιτήματος, η διεπαφή επιστρέφει πρώτα `{"task_id": "..."}` και, όταν ολοκληρωθεί, στέλνει το τελικό αποτέλεσμα με POST σε αυτό το URL· τα σύγχρονα αιτήματα εξακολουθούν να επιστρέφουν `created` και `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Ο παραλήπτης του callback πρέπει να χρησιμοποιεί το `task_id` για αποδιπλοποίηση και να επαληθεύει την προέλευση του αιτήματος και τη μορφή των δεδομένων.

## 6. Αντιμετώπιση σφαλμάτων

| Κατάσταση  | Έλεγχος                                                  |
| --- | --------------------------------------------------- |
| 400 | Συνδυασμός `model`, `prompt`, μορφής διαστάσεων, `n` και `response_format`    |
| 401 | Αν το API Key είναι πλήρες και αν το Header είναι `Authorization: Bearer ...` |
| 429 | Τα αιτήματα είναι υπερβολικά συχνά, δοκιμάστε ξανά αργότερα                                         |
| 504 | Λήξη χρονικού ορίου σύγχρονης δημιουργίας· χρησιμοποιήστε `callback_url`                            |

Οι αποκρίσεις σφάλματος περιλαμβάνουν `error.code`, `error.message` και `trace_id`. Όταν αναφέρετε ένα πρόβλημα, δώστε το `trace_id`, όχι το API Key.

Για τα πλήρη πεδία και τις ενημερωμένες απαριθμήσεις, ανατρέξτε στη σελίδα [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Για επεξεργασία εικόνων, ανατρέξτε στο [GPT Image 2 / 2.5 επεξεργασία εικόνων](https://platform.acedata.cloud/documents/openai-images-edits).
