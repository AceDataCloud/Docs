## 1. Αποκτήστε API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), εισέλθετε σε μια διαθέσιμη εφαρμογή και αντιγράψτε το API Key.

![Λήψη Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Στείλτε το πρώτο αίτημα

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Η εικόνα της επιτυχούς απόκρισης βρίσκεται στο `data[].url`. Ακολουθεί το αποτέλεσμα 1024×1536 που προέκυψε από πραγματικό αίτημα μέσω του Ace Data Cloud στις 8 Σεπτεμβρίου 2026 (εργασία `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Λευκή κούπα που δημιουργήθηκε από το GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Συνηθισμένες παράμετροι

| Πεδίο                | Περιγραφή                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (προεπιλεγόμενο και προτεινόμενο), `gpt-image-2.5-flare` (ταχύτερο) ή `gpt-image-2.5-sunburst` (υψηλότερη πιστότητα και έλεγχος)· και τα τρία μπορούν να επιλέξουν την αντίστοιχη παραλλαγή `:official`, ενώ το `gpt-image-2` υποστηρίζει επίσης το `:reverse` |
| `prompt`          | Περιγραφή εικόνας, έως 32.000 χαρακτήρες                                                                                                                     |
| `size`            | `auto` ή `WIDTHxHEIGHT`· το πλάτος και το ύψος πρέπει να είναι πολλαπλάσια του 16, η μεγάλη πλευρά δεν πρέπει να υπερβαίνει τα 3840, τα συνολικά pixel είναι 655,360–8,294,400 και ο λόγος διαστάσεων δεν πρέπει να υπερβαίνει το 3:1                                                       |
| `n`               | 1–10· όταν `response_format=b64_json`, υποστηρίζεται μόνο το 1                                                                                                 |
| `quality`         | Τα μοντέλα GPT Image υποστηρίζουν `auto`, `low`, `medium`, `high`· τα 2.5 / 2.6 Flare / Sunburst (συμπεριλαμβανομένου του `:official`) υποστηρίζουν επιπλέον `xhigh`, `max`. Το επίσημο κανάλι χρεώνει βάσει της πραγματικής χρήσης Token             |
| `response_format` | `url` ή `b64_json`                                                                                                                     |
| `callback_url`    | Προαιρετικό· αποστέλλει αποτελέσματα σε αυτήν τη διεύθυνση μετά την ολοκλήρωση μακροχρόνιων εργασιών                                                                                                                      |

Συνηθισμένες διαστάσεις:

| Αναλογία   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

Το `size: "auto"` επιλέγει τις διαστάσεις με βάση την αναλογία, τα pixel και την πρόθεση διάταξης στο prompt· όταν απαιτούνται ακριβή pixel, συμπληρώστε απευθείας τις διαστάσεις.

Η τιμή στη σελίδα του επίσημου καναλιού API είναι εκτίμηση πριν από το αίτημα· το τελικό ποσό βασίζεται στην πραγματική χρήση Token και στα αρχεία χρήσης της απόκρισης.

## 4. Δημιουργία πολλαπλών εικόνων

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
Τα `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` και τα ψευδώνυμα `:reverse` τους χρεώνονται ανά επιτυχημένη εικόνα· τα `gpt-image-2:official`, `gpt-image-2.5-flare:official` και `gpt-image-2.5-sunburst:official` χρεώνονται βάσει των πραγματικών Token εισόδου κειμένου και εξόδου εικόνας στην απόκριση. Η τιμή στη σελίδα είναι εκτίμηση πριν από το αίτημα· τελικά υπερισχύουν τα αρχεία χρήσης.

## 5. Ασύγχρονη επανάκληση

Αφού προστεθεί το `callback_url` στο σώμα του αιτήματος, η διεπαφή θα επιστρέψει πρώτα `{"task_id": "..."}` και, όταν ολοκληρωθεί, θα στείλει με POST το τελικό αποτέλεσμα σε αυτό το URL· τα σύγχρονα αιτήματα εξακολουθούν να επιστρέφουν `created` και `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Ο παραλήπτης της επανάκλησης θα πρέπει να χρησιμοποιεί το `task_id` για αποδιπλοποίηση και να επαληθεύει την προέλευση του αιτήματος και τη μορφή των δεδομένων.

## 6. Αντιμετώπιση σφαλμάτων

| Κατάσταση  | Έλεγχος                                                  |
| --- | --------------------------------------------------- |
| 400 | Ο συνδυασμός των `model`, `prompt`, μορφής διαστάσεων, `n` και `response_format`    |
| 401 | Αν το API Key είναι πλήρες, αν το Header είναι `Authorization: Bearer ...` |
| 429 | Τα αιτήματα είναι υπερβολικά συχνά, δοκιμάστε ξανά αργότερα                                         |
| 504 | Λήξη χρονικού ορίου σύγχρονης δημιουργίας· χρησιμοποιήστε `callback_url`                            |

Οι αποκρίσεις σφάλματος θα περιλαμβάνουν `error.code`, `error.message` και `trace_id`. Όταν αναφέρετε προβλήματα, παρέχετε το `trace_id`, μην παρέχετε το API Key.

Για τα πλήρη πεδία και τις απαριθμήσεις σε πραγματικό χρόνο, ανατρέξτε στη σελίδα [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Για επεξεργασία εικόνων, ανατρέξτε στο [GPT Image 2 / 2.5 / 2.6 Επεξεργασία εικόνων](https://platform.acedata.cloud/documents/openai-images-edits).

## GPT Image 2.6

Το GPT Image 2.6 χρησιμοποιεί τις διεπαφές δημιουργίας, επεξεργασίας, ασύγχρονων εργασιών και χρέωσης του 2.5:

| Μοντέλο                                                          | Χρέωση                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/εικόνα                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/εικόνα                   |
| `gpt-image-2.6-flare:official`                              | Ίδια με το 2.5 official, χρέωση βάσει πραγματικής χρήσης Token |
| `gpt-image-2.6-sunburst:official`                           | Ίδια με το 2.5 official, χρέωση βάσει πραγματικής χρήσης Token |

Οι διαθέσιμες ποιότητες είναι `auto`, `low`, `medium`, `high`, `xhigh`, `max`· για διαστάσεις χρησιμοποιήστε `auto` ή `WIDTHxHEIGHT` που συμμορφώνεται με τους παραπάνω περιορισμούς. Αυτή η διεπαφή υποστηρίζει `png`, `jpeg`, `webp`· το GPT Image 2.6 υποστηρίζει επίσης εγγενείς κινούμενες εικόνες `gif`, ενώ το SVG δεν υποστηρίζεται προς το παρόν. Η επεξεργασία υποστηρίζει JSON URL εικόνας και μεταφόρτωση αρχείων multipart. Το `:reverse` είναι ρητό ψευδώνυμο της κανονικής έκδοσης με το ίδιο όνομα. Χρησιμοποιήστε το πλήρες μοντέλο, μην στέλνετε `gpt-image-2.6`.

### Κινούμενες εικόνες GIF του GPT Image 2.6

Η κανονική έκδοση, το `:reverse`, το `:official` του Flare, καθώς και το `gpt-image-2.6-sunburst:official` μπορούν να χρησιμοποιήσουν `output_format: "gif"`. Η κανονική έκδοση του Sunburst και το `:reverse` δεν παρέχουν ακόμη GIF, αλλά εξακολουθούν να υποστηρίζουν δημιουργία και επεξεργασία στατικών εικόνων. Τα καρέ κίνησης, οι πληροφορίες επανάληψης και η διάρκεια αναπαραγωγής διατηρούνται· το `frame_count` δηλώνει τον αριθμό καρέ, το `frame_duration_ms` δηλώνει τα χιλιοστά του δευτερολέπτου ανά καρέ, και αμφότερα πρέπει να είναι θετικοί ακέραιοι και χρησιμοποιούνται μόνο για GIF. Όταν δεν καθορίζονται, η προεπιλογή είναι 9 καρέ, 200 χιλιοστά του δευτερολέπτου ανά καρέ· όταν το size του GIF παραλείπεται ή είναι auto, χρησιμοποιείται η προρύθμιση 512x512.

Συνιστάται να χρησιμοποιείτε πρώτα `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. Τα GIF έχουν ανεξάρτητους περιορισμούς διαστάσεων και αριθμού καρέ και δεν μπορούν να χρησιμοποιούν απευθείας τις προδιαγραφές στατικών εικόνων 4K· ορισμένα μοντέλα θα προσαρμόσουν τις πραγματικές διαστάσεις εξόδου. Το `n` δηλώνει τον αριθμό των αρχείων GIF που επιστρέφονται, όχι τον αριθμό των καρέ κίνησης. Η κανονική έκδοση και το `:reverse` εξακολουθούν να χρεώνονται βάσει του αριθμού επιτυχημένων αρχείων, ενώ η επίσημη έκδοση χρεώνεται βάσει της πραγματικής χρήσης Token.

```json
{
  "model": "gpt-image-2.6-flare",
  "prompt": "A small red ball moves left and right on a white background, seamless looping animation, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### Στατικές εικόνες 4K του GPT Image 2.6

Το Flare, το Sunburst και οι παραλλαγές `:reverse`, `:official` τους μπορούν όλα να χρησιμοποιούν τις προαναφερθείσες προρυθμίσεις pixel 4K, όπως `3840x2160` και `2160x3840`. Τόσο η δημιουργία όσο και η επεξεργασία περνούν συγκεκριμένα pixel μέσω του `size`· το `4K` δεν είναι έγκυρη τιμή `size`, ενώ το `4096x4096` υπερβαίνει επίσης το τρέχον ανώτατο όριο pixel. Οι παραπάνω προδιαγραφές 4K ισχύουν για στατικά PNG/JPEG/WebP· για GIF χρησιμοποιήστε τις ειδικές παραμέτρους του.
