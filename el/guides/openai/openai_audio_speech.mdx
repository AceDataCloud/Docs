Συνθέτει κείμενο σε φυσική ομιλία, **εντελώς συμβατό με το OpenAI `/v1/audio/speech`**. Οποιοδήποτε OpenAI SDK απλώς πρέπει να κατευθύνει το `base_url` προς το `https://api.acedata.cloud` και να αντικαταστήσει το κλειδί με το AceData Token σας για άμεση χρήση. Η διεπαφή επιστρέφει συγχρόνως ροή byte ήχου.

- **Διεύθυνση αιτήματος**: `POST https://api.acedata.cloud/v1/audio/speech` (ψευδώνυμο `POST /openai/audio/speech`)
- **Εξουσιοδότηση**: Κεφαλίδα αιτήματος `Authorization: Bearer {token}`
- **Χρέωση**: Χρεώνεται με βάση τον αριθμό byte του κειμένου αιτήματος, περίπου 85% της επίσημης τιμής του OpenAI (βλ. παρακάτω πίνακα).

## Παράμετροι αιτήματος

| Πεδίο              | Τύπος   | Υποχρεωτικό | Περιγραφή                                                      |
| ----------------- | ------ | --------- | ----------------------------------------------------------- |
| `input`           | string | Ναι       | Το κείμενο που θα συντεθεί.                                   |
| `model`           | string | Όχι       | `tts-1` (ταχύτερο) ή `tts-1-hd` (υψηλότερη ποιότητα, προεπιλογή). |
| `voice`           | string | Όχι       | Ένα από τα `alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`, προεπιλογή `alloy`. |
| `response_format` | string | Όχι       | `mp3` (προεπιλογή), `opus`, `aac`, `flac`, `wav`, `pcm`.    |
| `speed`           | number | Όχι       | Ταχύτητα ομιλίας 0.25–4.0, προεπιλογή 1.0.                   |

## Παράδειγμα

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/speech' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -o speech.mp3 \
  -d '{
    "model": "tts-1-hd",
    "input": "What if one API gave you every AI video model?",
    "voice": "nova",
    "response_format": "mp3"
  }'
```

Η επιστροφή είναι το ίδιο το αρχείο ήχου (`Content-Type: audio/mpeg`), γράφεται απευθείας στο `speech.mp3` για αναπαραγωγή.

Με το επίσημο OpenAI Python SDK:

```python
from openai import OpenAI
client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
client.audio.speech.create(model="tts-1-hd", voice="nova", input="Hello from AceData.").stream_to_file("speech.mp3")
```

## Τιμές

| Μοντέλο       | Επίσημη τιμή OpenAI | Τιμή στην πλατφόρμα (περίπου 85% έκπτωση) |
| ------------ | ------------------ | ------------------------------------- |
| `tts-1`      | $15 / 1 εκατομμύριο χαρακτήρες | περίπου $12.75 / 1 εκατομμύριο χαρακτήρες |
| `tts-1-hd`   | $30 / 1 εκατομμύριο χαρακτήρες | περίπου $25.5 / 1 εκατομμύριο χαρακτήρες  |

> Χρεώνεται με βάση τον αριθμό byte του κειμένου αιτήματος; το πεδίο `official_price` εμφανίζει την επίσημη τιμή του OpenAI για σύγκριση.

## Κωδικοί σφαλμάτων

| Κωδικός κατάστασης | code                    | Περιγραφή               |
| ----------------- | ----------------------- | ---------------------- |
| 400               | `bad_request`           | `input` είναι κενό ή παράμετρος μη έγκυρη. |
| 401               | `authentication_failed` | το token είναι μη έγκυρο.        |
| 403               | `used_up`               | ανεπαρκές υπόλοιπο.            |
| 429               | `too_many_requests`     | υπερβολικά συχνά αιτήματα.          |
| 500               | `api_error`             | Σφάλμα upstream/εσωτερικό.         |
