OpenAI ChatGPT είναι ένα πολύ ισχυρό σύστημα AI συνομιλίας, το οποίο μπορεί να παράγει ομαλές και φυσικές απαντήσεις σε λίγα δευτερόλεπτα απλά εισάγοντας λέξεις-κλειδιά. Το ChatGPT ξεχωρίζει στη βιομηχανία για την εξαιρετική του ικανότητα κατανόησης και παραγωγής γλώσσας, και σήμερα, το ChatGPT έχει ευρεία εφαρμογή σε διάφορους τομείς και βιομηχανίες, με την επιρροή του να γίνεται ολοένα και πιο σημαντική. Είτε πρόκειται για καθημερινές συνομιλίες, δημιουργική συγγραφή, είτε για επαγγελματική συμβουλευτική και προγραμματισμό κώδικα, το ChatGPT μπορεί να προσφέρει εκπληκτική έξυπνη βοήθεια, αυξάνοντας σημαντικά την παραγωγικότητα και τη δημιουργικότητα των ανθρώπων.

Αυτό το έγγραφο περιγράφει κυρίως τη διαδικασία χρήσης του OpenAI Chat Completion 4o Image API, επιτρέποντάς μας να χρησιμοποιήσουμε εύκολα τη λειτουργία πολυτροπικής συνομιλίας του επίσημου OpenAI ChatGPT.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το OpenAI Chat Completion 4o Image API, μπορείτε πρώτα να επισκεφθείτε τη σελίδα [OpenAI Chat Completion 4o Image API](https://platform.acedata.cloud/documents/1bcf3bba-102b-495d-9bba-47cd96717e45) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να σας προσκαλέσουν να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## GPT-4o Μοντέλο Σχεδίασης

### Δημιουργία εικόνας βάσει αναφοράς

Ακολουθεί ένα παράδειγμα δημιουργίας εικόνας προσαρμοσμένου στυλ βάσει μιας εικόνας. Ας δούμε πρώτα την εικόνα που εισάγουμε, όπως φαίνεται παρακάτω:

![](https://cdn.acedata.cloud/qzx2z1.png)

Μπορούμε να δούμε ότι η εικόνα αναφοράς είναι μια φωτογραφία ενός πραγματικού ανθρώπου. Μπορούμε να την αλλάξουμε σε ένα στυλ, όπως να την κάνουμε εικόνα anime, με το συγκεκριμένο δείγμα αιτήματος:

```json
{
  "model": "gpt-4o-image",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "生成动漫风格的图片，并且带上个帽子"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

Δείγμα αποτελέσματος:

### Δημιουργία εικόνας μόνο με κείμενο

Μπορούμε να χρησιμοποιήσουμε μια λέξη-κλειδί για να δημιουργήσουμε μια εικόνα και να την επιστρέψουμε σε μορφή συνομιλίας. Ακολουθεί ένα παράδειγμα με το `δημιουργία μιας εικόνας με ηλιοβασίλεμα σε μια μελλοντική πόλη`, με το συγκεκριμένο παράδειγμα:

```json
{
  "model": "gpt-4o-image",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "生成动漫风格的图片，并且带上个帽子"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
```

## 错误处理

在调用 API 时，如果遇到错误，API 会返回相应的错误代码和信息。例如：

- `400 token_mismatched`：Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`：Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`：Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`：Too many requests, you have exceeded the rate limit.
- `500 api_error`：Internal server error, something went wrong on the server.

### 错误响应示例

```
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
