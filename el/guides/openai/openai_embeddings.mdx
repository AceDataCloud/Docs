Η υπηρεσία λέξεων OpenAI χρησιμοποιείται για τη δημιουργία λέξεων που αντιπροσωπεύουν τα αποτελέσματα του εισαγόμενου κειμένου.

Αυτό το έγγραφο περιγράφει κυρίως τη διαδικασία χρήσης του OpenAI Embeddings API, με το οποίο μπορούμε να δημιουργήσουμε ενσωματωμένα διανύσματα που αντιπροσωπεύουν το εισαγόμενο κείμενο.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το OpenAI Embeddings API, πρώτα πηγαίνετε στο [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη σελίδα που βρίσκεστε.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν. Όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό σας υπόλοιπο στο [Console](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [OpenAI Embeddings API →](https://platform.acedata.cloud/documents/openai-embeddings)

## Βασική Χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/4qtbvr.png" width="500" className="m-auto" /></p>

Κατά την πρώτη χρήση αυτής της διεπαφής, πρέπει τουλάχιστον να συμπληρώσετε τρία περιεχόμενα, ένα είναι το `authorization`, το οποίο μπορείτε να επιλέξετε απευθείας από τη λίστα. Ένα άλλο παράμετρο είναι το `model`, το `model` είναι η κατηγορία μοντέλου που επιλέγουμε να χρησιμοποιήσουμε από την επίσημη ιστοσελίδα του OpenAI, εδώ έχουμε κυρίως 3 μοντέλα, περισσότερες λεπτομέρειες μπορείτε να δείτε στα μοντέλα που παρέχουμε. Η τελευταία παράμετρος είναι το `input`, το `input` είναι το κείμενο που θέλουμε να μετατρέψουμε σε λέξεις.

Μπορείτε επίσης να παρατηρήσετε ότι στα δεξιά υπάρχει η αντίστοιχη γεννήτρια κώδικα κλήσης, μπορείτε να αντιγράψετε τον κώδικα και να τον εκτελέσετε απευθείας ή να κάνετε κλικ στο κουμπί «Δοκιμή» για να το δοκιμάσετε.

Προαιρετικές παράμετροι:

- `dimensions`: Κόβει τις διαστάσεις του διανύσματος, η προεπιλεγμένη έξοδος είναι η πλήρης διάσταση.
- `encoding_format`: Μορφή επιστροφής, μπορεί να είναι `float` ή `base64`.

<p><img src="https://cdn.acedata.cloud/gqulm9.png" width="500" className="m-auto" /></p>

Παράδειγμα κώδικα κλήσης Python:

```python
import requests

url = "https://api.acedata.cloud/openai/embeddings"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "The food was delicious and the waiter...",
    "model": "text-embedding-ada-002",
    "encoding_format": "float"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Το αποτέλεσμα επιστροφής περιλαμβάνει πολλά πεδία, τα οποία περιγράφονται ως εξής:

- `model`, το μοντέλο που χρησιμοποιήθηκε για τη μετατροπή του κειμένου σε λέξεις.
- `usage`, οι πληροφορίες token που χρησιμοποιήθηκαν για τη μετατροπή του κειμένου σε λέξεις.
- `data`, το αποτέλεσμα των λέξεων που προήλθε από τη μετατροπή του κειμένου.

Το `data` περιέχει τις συγκεκριμένες πληροφορίες των λέξεων που αντιστοιχούν στο κείμενο, όπου το `embedding` είναι το συγκεκριμένο αποτέλεσμα των λέξεων που δημιουργήθηκαν.

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και τις πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές token εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
