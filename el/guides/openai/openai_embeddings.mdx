Η υπηρεσία διανυσμάτων λέξεων του OpenAI χρησιμοποιείται για τη δημιουργία αποτελεσμάτων διανυσμάτων λέξεων που αναπαριστούν το εισαγόμενο κείμενο.

Αυτό το έγγραφο παρουσιάζει κυρίως τη διαδικασία χρήσης των λειτουργιών του OpenAI Embeddings API, με το οποίο μπορούμε να δημιουργήσουμε διανύσματα ενσωμάτωσης που αναπαριστούν το εισαγόμενο κείμενο。。

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το OpenAI Embeddings API, μεταβείτε πρώτα στην [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Με την πρώτη αίτηση προσφέρεται δωρεάν πίστωση για δωρεάν δοκιμή· όταν η πίστωση δεν επαρκεί, μπορείτε να φορτίσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [OpenAI Embeddings API →](https://platform.acedata.cloud/documents/openai-embeddings)

## Βασική χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε το αντίστοιχο περιεχόμενο στη διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/4qtbvr.png" width="500" className="m-auto" /></p>

Κατά την πρώτη χρήση αυτής της διεπαφής, χρειάζεται να συμπληρώσουμε τουλάχιστον τρία πεδία. Το ένα είναι το `authorization`, το οποίο μπορεί να επιλεγεί απευθείας από την αναπτυσσόμενη λίστα. Μια άλλη παράμετρος είναι το `model`, όπου το `model` είναι η κατηγορία μοντέλου του επίσημου ιστότοπου OpenAI που επιλέγουμε να χρησιμοποιήσουμε. Τα διαθέσιμα μοντέλα επί του παρόντος είναι τα `text-embedding-3-small` και `text-embedding-3-large`. Το `text-embedding-ada-002` δεν παρέχεται πλέον· εάν ένα υπάρχον ευρετήριο διανυσμάτων χρησιμοποιεί αυτό το παλιό μοντέλο, δεν μπορούν να αναμειχθούν απευθείας τα διανύσματα του νέου μοντέλου και πρέπει να δημιουργηθεί ξανά το ευρετήριο. Η τελευταία παράμετρος είναι το `input`, όπου το `input` είναι το κείμενο που χρειαζόμαστε να μετατρέψουμε σε διανύσματα λέξεων.

Ταυτόχρονα, μπορείτε να παρατηρήσετε ότι στα δεξιά δημιουργείται ο αντίστοιχος κώδικας κλήσης. Μπορείτε να αντιγράψετε τον κώδικα και να τον εκτελέσετε απευθείας, ή να κάνετε απευθείας κλικ στο κουμπί «Try» για δοκιμή.

Προαιρετικές παράμετροι:

- `dimensions`: περικοπή των διαστάσεων του διανύσματος, με προεπιλογή την έξοδο των πλήρων διαστάσεων.
- `encoding_format`: μορφή επιστροφής, με επιλογές `float` ή `base64`.

<p><img src="https://cdn.acedata.cloud/gqulm9.png" width="500" className="m-auto" /></p>

Δείγμα κώδικα κλήσης Python:

```python
import requests

url = "https://api.acedata.cloud/openai/embeddings"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "The food was delicious and the waiter...",
    "model": "text-embedding-3-small",
    "encoding_format": "float"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Το αποτέλεσμα επιστροφής περιέχει συνολικά πολλαπλά πεδία, τα οποία παρουσιάζονται παρακάτω:

- `model`, το μοντέλο που χρησιμοποιήθηκε για τη μετατροπή του κειμένου σε διανύσματα λέξεων αυτή τη φορά.
- `usage`, οι πληροφορίες token που χρησιμοποιήθηκαν για τη μετατροπή του κειμένου σε διανύσματα λέξεων αυτή τη φορά.
- `data`, το αποτέλεσμα των διανυσμάτων λέξεων μετά τη μετατροπή του κειμένου.

Μεταξύ αυτών, το `data` περιέχει τις συγκεκριμένες πληροφορίες για τα διανύσματα λέξεων που αντιστοιχούν στο κείμενο, και το `embedding` μέσα σε αυτό είναι το συγκεκριμένο αποτέλεσμα των παραγόμενων διανυσμάτων λέξεων.

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν παρουσιαστεί σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και τις σχετικές πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές token εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
