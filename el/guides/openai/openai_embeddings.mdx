Η υπηρεσία λέξεων OpenAI χρησιμοποιείται για τη δημιουργία λέξεων που αντιπροσωπεύουν τα αποτελέσματα του εισαγόμενου κειμένου.

Αυτό το έγγραφο περιγράφει κυρίως τη διαδικασία χρήσης του OpenAI Embeddings API, με το οποίο μπορούμε να δημιουργήσουμε ενσωματωμένα διανύσματα που αντιπροσωπεύουν το εισαγόμενο κείμενο.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το OpenAI Embeddings API, μπορείτε πρώτα να επισκεφθείτε τη σελίδα [OpenAI Embeddings API](https://platform.acedata.cloud/documents/0f2e63fa-5890-4bdd-84f0-1706b5c9a387) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/4qtbvr.png" width="500" class="m-auto"></p>

Κατά την πρώτη χρήση αυτού του API, πρέπει τουλάχιστον να συμπληρώσετε τρία περιεχόμενα: το ένα είναι το `authorization`, το οποίο μπορείτε να επιλέξετε απευθείας από τη λίστα. Ένα άλλο παράμετρο είναι το `model`, το οποίο είναι η κατηγορία μοντέλου που επιλέγουμε να χρησιμοποιήσουμε από την επίσημη ιστοσελίδα του OpenAI. Εδώ έχουμε κυρίως 3 μοντέλα, λεπτομέρειες μπορείτε να δείτε στα μοντέλα που παρέχουμε. Η τελευταία παράμετρος είναι το `input`, το οποίο είναι το κείμενο που θέλουμε να μετατρέψουμε σε λέξεις.

Μπορείτε επίσης να παρατηρήσετε ότι στα δεξιά υπάρχει η αντίστοιχη γεννήτρια κώδικα κλήσης, μπορείτε να αντιγράψετε τον κώδικα και να τον εκτελέσετε απευθείας ή να κάνετε κλικ στο κουμπί «Try» για να δοκιμάσετε.

Προαιρετικές παράμετροι:

- `dimensions`: Κόβει τις διαστάσεις του διανύσματος, η προεπιλεγμένη έξοδος είναι η πλήρης διάσταση.
- `encoding_format`: Μορφή επιστροφής, επιλέξιμο `float` ή `base64`.

<p><img src="https://cdn.acedata.cloud/gqulm9.png" width="500" class="m-auto"></p>

Παράδειγμα κώδικα κλήσης Python:

```python
import requests

url = "https://api.acedata.cloud/openai/embeddings"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "The food was delicious and the waiter...",
    "model": "text-embedding-ada-002",
    "encoding_format": "float"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Το αποτέλεσμα επιστροφής περιλαμβάνει πολλαπλά πεδία, τα οποία περιγράφονται ως εξής:

- `model`, το μοντέλο που χρησιμοποιήθηκε για τη μετατροπή του κειμένου σε λέξεις.
- `usage`, οι πληροφορίες token που χρησιμοποιήθηκαν για τη μετατροπή του κειμένου σε λέξεις.
- `data`, το αποτέλεσμα των λέξεων που προήλθε από τη μετατροπή του κειμένου.

Το `data` περιέχει τις συγκεκριμένες πληροφορίες των λέξεων που αντιστοιχούν στο κείμενο, με το `embedding` να είναι το συγκεκριμένο αποτέλεσμα των λέξεων που δημιουργήθηκαν.

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και τις πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
