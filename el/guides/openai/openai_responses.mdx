Η OpenAI πρόσφατα παρέχει μια διεπαφή για τη δημιουργία απαντήσεων μοντέλου. Παρέχει κείμενο ή εικόνα εισόδου για να παραγάγει κείμενο ή εικόνα εξόδου. Επιτρέπει στο μοντέλο να καλέσει τον δικό σας προσαρμοσμένο κώδικα ή να χρησιμοποιήσει ενσωματωμένα εργαλεία, όπως αναζητήσεις στο διαδίκτυο ή αναζητήσεις αρχείων, για να χρησιμοποιήσει τα δικά σας δεδομένα ως είσοδο για την απάντηση του μοντέλου.

Αυτό το έγγραφο περιγράφει κυρίως τη διαδικασία χρήσης του OpenAI Responses API, επιτρέποντάς μας να χρησιμοποιήσουμε εύκολα τη λειτουργία δημιουργίας απαντήσεων μοντέλου της επίσημης OpenAI.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το OpenAI Responses API, μπορείτε πρώτα να επισκεφθείτε τη σελίδα [OpenAI Responses API](https://platform.acedata.cloud/documents/81e285a6-d010-4a2d-a3a8-ca113d4ef82a) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα διαπιστευτήρια που απαιτούνται για την αίτηση:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε τα αντίστοιχα περιεχόμενα στην διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/8lu8di.png" width="400" class="m-auto"></p>

Κατά την πρώτη χρήση αυτής της διεπαφής, πρέπει τουλάχιστον να συμπληρώσουμε τρία περιεχόμενα, ένα είναι το `authorization`, το οποίο μπορείτε να επιλέξετε απευθείας από τη λίστα. Ένα άλλο παράμετρο είναι το `model`, το `model` είναι η κατηγορία μοντέλου που επιλέγουμε να χρησιμοποιήσουμε από την επίσημη ιστοσελίδα του OpenAI ChatGPT, εδώ έχουμε κυρίως 20 μοντέλα, για λεπτομέρειες μπορείτε να δείτε τα μοντέλα που παρέχουμε. Η τελευταία παράμετρος είναι το `input`, το `input` είναι ο πίνακας των ερωτήσεων που εισάγουμε, είναι ένας πίνακας που δηλώνει ότι μπορείτε να ανεβάσετε πολλές ερωτήσεις ταυτόχρονα, κάθε ερώτηση περιλαμβάνει το `role` και το `content`, όπου το `role` δηλώνει τον ρόλο του ερωτώντος, παρέχουμε τρεις ταυτότητες, δηλαδή `user`, `assistant`, `system`. Το άλλο `content` είναι το συγκεκριμένο περιεχόμενο της ερώτησής μας.

Μπορείτε επίσης να παρατηρήσετε ότι στα δεξιά υπάρχει ο αντίστοιχος κώδικας κλήσης που μπορείτε να αντιγράψετε και να εκτελέσετε απευθείας, ή μπορείτε να κάνετε κλικ στο κουμπί «Try» για να δοκιμάσετε.

Συνηθισμένες προαιρετικές παράμετροι:

- `max_tokens`: περιορίζει τον μέγιστο αριθμό tokens για μία απάντηση.
- `temperature`: δημιουργεί τυχαιότητα, μεταξύ 0-2, όσο μεγαλύτερη είναι η τιμή, τόσο πιο διασκορπισμένη είναι η απάντηση.
- `n`: πόσες υποψήφιες απαντήσεις θα παραχθούν ταυτόχρονα.
- `response_format`: ρύθμιση μορφής επιστροφής.
- `tools`: ορισμός κλήσεων συναρτήσεων/εργαλείων.
- `background`: αν θα εκτελείται ασύγχρονα στο παρασκήνιο.

## Ροή Απαντήσεων

Αυτή η διεπαφή υποστηρίζει επίσης ροή απαντήσεων, κάτι που είναι πολύ χρήσιμο για την ενσωμάτωσή της σε ιστοσελίδες, καθώς μπορεί να επιτρέψει την εμφάνιση των αποτελεσμάτων λέξη προς λέξη.

Εάν θέλετε να επιστρέψετε την απάντηση σε ροή, μπορείτε να αλλάξετε την παράμετρο `stream` στην κεφαλίδα αίτησης σε `true`.

Η αλλαγή φαίνεται στην εικόνα, αλλά ο κώδικας κλήσης χρειάζεται να έχει τις αντίστοιχες αλλαγές για να υποστηρίξει τη ροή απαντήσεων.

<p><img src="https://cdn.acedata.cloud/xidnao.png" width="400" class="m-auto"></p>

Αφού αλλάξετε το `stream` σε `true`, το API θα επιστρέφει γραμμή προς γραμμή τα αντίστοιχα δεδομένα JSON, και σε επίπεδο κώδικα θα χρειαστεί να κάνουμε τις αντίστοιχες αλλαγές για να αποκτήσουμε τα αποτελέσματα γραμμή προς γραμμή.

Παράδειγμα κώδικα κλήσης σε Python:

```python
import requests

url = "https://api.acedata.cloud/openai/responses"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

- `model`, το μοντέλο OpenAI ChatGPT που επιλέχθηκε.
- `delta`, οι πληροφορίες απάντησης που παρέχει το ChatGPT για την ερώτηση.

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer b82d32f570bc434d9ba9923aa0e7dce0",
    "content-type": "application/json",
  },
  body: JSON.stringify({

    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/responses", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

import requests

url = "https://api.acedata.cloud/openai/responses"

## Οπτικό μοντέλο

Το gpt-4o είναι ένα πολυδιάστατο μεγάλο γλωσσικό μοντέλο που αναπτύχθηκε από την OpenAI, το οποίο προσθέτει ικανότητες οπτικής κατανόησης πάνω στη βάση του GPT-4. Αυτό το μοντέλο μπορεί να επεξεργάζεται ταυτόχρονα κείμενα και εικόνες, επιτυγχάνοντας διασυνοριακή κατανόηση και παραγωγή.

Η επεξεργασία κειμένου με το μοντέλο gpt-4o είναι σύμφωνη με το περιεχόμενο της βασικής χρήσης που αναφέρθηκε παραπάνω, παρακάτω θα παρουσιαστεί συνοπτικά πώς να χρησιμοποιήσετε την ικανότητα επεξεργασίας εικόνας του μοντέλου.

Η ικανότητα επεξεργασίας εικόνας του μοντέλου gpt-4o βασίζεται στην προσθήκη ενός πεδίου `type` στο υπάρχον περιεχόμενο `content`, μέσω του οποίου μπορείτε να γνωρίζετε αν το περιεχόμενο που ανεβάζετε είναι κείμενο ή εικόνα, έτσι ώστε να χρησιμοποιήσετε την ικανότητα επεξεργασίας εικόνας του μοντέλου gpt-4o. Παρακάτω θα περιγραφούν οι δύο τρόποι κλήσης αυτής της λειτουργίας μέσω Curl και Python.

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [
      {
        "role": "user",
        "content": [
          {"type": "input_text", "text": "τι υπάρχει σε αυτή την εικόνα;"},
          {
            "type": "input_image",
            "image_url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
          }
        ]
      }
    ]
  }

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```
