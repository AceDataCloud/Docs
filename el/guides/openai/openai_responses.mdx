Τα συμβατά αιτήματα μοντέλων που δέχεται η πλατφόρμα χρεώνονται με βάση τη χρήση εισόδου, εξόδου και cache του μοντέλου. Η συνολική ποσότητα εισόδου των Responses περιλαμβάνει τα αναφερόμενα cache token, ενώ το τμήμα της cache χρεώνεται σύμφωνα με την αντίστοιχη τιμή cache· η αλλαγή μορφής διεπαφής δεν μετατρέπεται σε χρέωση σταθερού αριθμού χρήσεων. Οι χρεώσεις βασίζονται στις τρέχουσες τιμές μοντέλων της κονσόλας και στο response usage.cost.

Η OpenAI πρόσφατα παρείχε μια διεπαφή για τη δημιουργία αποκρίσεων μοντέλου. Παρέχετε είσοδο κειμένου ή εικόνας για να δημιουργήσετε έξοδο κειμένου ή εικόνας. Επιτρέψτε στο μοντέλο να καλεί τον δικό σας προσαρμοσμένο κώδικα ή να χρησιμοποιεί ενσωματωμένα εργαλεία, όπως αναζήτηση web ή αναζήτηση αρχείων, ώστε να χρησιμοποιεί τα δικά σας δεδομένα ως είσοδο για την απόκριση του μοντέλου.

Αυτό το έγγραφο παρουσιάζει κυρίως τη διαδικασία χρήσης των λειτουργιών του OpenAI Responses API. Με αυτό, μπορούμε εύκολα να χρησιμοποιήσουμε την επίσημη λειτουργία δημιουργίας αποκρίσεων μοντέλου της OpenAI.

## GPT-6.1 Terra

Χρησιμοποιήστε `model: "gpt-6.1-terra"` για να επιλέξετε αυτό το μοντέλο. Υποστηρίζει εισόδους κειμένου και εικόνας, ροή εξόδου, εργαλεία συναρτήσεων και δομημένη έξοδο. Τα επίπεδα συλλογισμού υποστηρίζουν `low`, `medium`, `high`, `xhigh` και `max`, και προτείνεται να ξεκινήσετε με `reasoning: {"effort": "low"}`· δεν υποστηρίζονται τα `none` ή `minimal`. Όταν η είσοδος υπερβαίνει τα 272,000 tokens, εφαρμόζεται τιμολόγηση μεγάλου περιβάλλοντος· η πραγματική χρέωση βασίζεται στις τρέχουσες τιμές της κονσόλας και στη χρήση στην απόκριση.

## GPT-6.1 Sol

Χρησιμοποιήστε `model: "gpt-6.1-sol"` για να επιλέξετε αυτό το μοντέλο. Υποστηρίζει ροή εξόδου, κλήσεις συναρτήσεων, δομημένη έξοδο και εισόδους εικόνας. Κατά την πρώτη εβδομάδα διάθεσης, είναι διαθέσιμο μόνο σε επαληθευμένους κατόχους ACE T1+ (τουλάχιστον 100,000 ACE) ή εξουσιοδοτημένους χρήστες· ο συγκεκριμένος χρόνος διάθεσης εξαρτάται από την ειδοποίηση πρόσβασης στην κονσόλα.

Τα επίπεδα συλλογισμού υποστηρίζουν `low`, `medium`, `high`, `xhigh` και `max`, ενώ προς το παρόν δεν υποστηρίζονται τα `none` ή `minimal`. Προτείνεται να ξεκινήσετε με `reasoning: {"effort": "low"}`. Όταν η είσοδος υπερβαίνει τα 272,000 tokens, εφαρμόζεται τιμολόγηση μεγάλου περιβάλλοντος σε ολόκληρο το αίτημα και η χρέωση βασίζεται στις τρέχουσες τιμές της κονσόλας.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το OpenAI Responses API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να λάβετε το API Token σας και κρατήστε το ως αντίγραφο ασφαλείας.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης, όπου θα σας προσκληθεί να εγγραφείτε και να συνδεθείτε· μετά την ολοκλήρωση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση παρέχει δωρεάν υπόλοιπο, ώστε να μπορείτε να το δοκιμάσετε δωρεάν· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να επαναφορτίσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

## Βασική χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε το αντίστοιχο περιεχόμενο στη διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/8lu8di.png" width="400" className="m-auto" /></p>

Κατά την πρώτη χρήση αυτής της διεπαφής, χρειάζεται να συμπληρώσουμε τουλάχιστον τρία στοιχεία. Το ένα είναι το `authorization`, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα. Μια άλλη παράμετρος είναι το `model`, το `model` είναι η κατηγορία μοντέλου του επίσημου ιστότοπου OpenAI ChatGPT που επιλέγουμε να χρησιμοποιήσουμε· εδώ διαθέτουμε κυρίως 20 μοντέλα και μπορείτε να δείτε λεπτομέρειες στα μοντέλα που παρέχουμε. Η τελευταία παράμετρος είναι το `input`, το `input` είναι ο πίνακας των ερωτημάτων που εισάγουμε· είναι ένας πίνακας, που υποδηλώνει ότι μπορούν να μεταφορτωθούν ταυτόχρονα πολλαπλά ερωτήματα, και κάθε ερώτημα περιλαμβάνει `role` και `content`, όπου το `role` δηλώνει τον ρόλο του ερωτώντος. Παρέχουμε τρεις ταυτότητες, συγκεκριμένα `user`, `assistant`, `system`. Το άλλο, το `content`, είναι το συγκεκριμένο περιεχόμενο της ερώτησής μας.

Ταυτόχρονα, μπορείτε να παρατηρήσετε ότι στα δεξιά δημιουργείται ο αντίστοιχος κώδικας κλήσης· μπορείτε να αντιγράψετε τον κώδικα και να τον εκτελέσετε απευθείας ή να κάνετε απευθείας κλικ στο κουμπί «Try» για δοκιμή.

Συνήθεις προαιρετικές παράμετροι:

- `max_tokens`：Περιορίζει τον μέγιστο αριθμό token σε μία απάντηση.
- `temperature`：Τυχαιότητα δημιουργίας, μεταξύ 0-2· όσο μεγαλύτερη είναι η τιμή, τόσο πιο αποκλίνουσα είναι.
- `n`：Πόσες υποψήφιες απαντήσεις θα δημιουργούνται κάθε φορά.
- `response_format`：Ρύθμιση μορφής επιστροφής.
- `tools`：Ορισμός κλήσης συνάρτησης/εργαλείου.
- `background`：Αν θα εκτελείται ασύγχρονα στο παρασκήνιο.

## Απόκριση ροής

Αυτή η διεπαφή υποστηρίζει επίσης απόκριση ροής, κάτι που είναι πολύ χρήσιμο για τη διασύνδεση ιστοσελίδων και επιτρέπει στην ιστοσελίδα να επιτυγχάνει εφέ εμφάνισης χαρακτήρα προς χαρακτήρα.

Αν θέλετε να επιστρέψετε μια απόκριση ροής, μπορείτε να αλλάξετε την παράμετρο `stream ` στην κεφαλίδα αιτήματος σε `true`.

Η τροποποίηση φαίνεται στην εικόνα, αλλά ο κώδικας κλήσης χρειάζεται τις αντίστοιχες αλλαγές για να υποστηρίζει απόκριση ροής.
<p><img src="https://cdn.acedata.cloud/xidnao.png" width="400" className="m-auto" /></p>

Αφού τροποποιήσετε το `stream` σε `true`, το API θα επιστρέφει τα αντίστοιχα δεδομένα JSON γραμμή προς γραμμή και σε επίπεδο κώδικα χρειάζεται να κάνουμε τις αντίστοιχες τροποποιήσεις για να λάβουμε τα αποτελέσματα γραμμή προς γραμμή.

Δείγμα κώδικα κλήσης Python:

```python
import requests

url = "https://api.acedata.cloud/openai/responses"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Όπως μπορείτε να δείτε, στην απόκριση υπάρχουν πολλά `data`, και το `delta` μέσα στο `data` είναι το πιο πρόσφατο περιεχόμενο απάντησης, το οποίο συμφωνεί με το περιεχόμενο που παρουσιάστηκε παραπάνω. Το `delta` είναι το νέο περιεχόμενο απάντησης· μπορείτε να το χρησιμοποιήσετε για να το ενσωματώσετε στο σύστημά σας σύμφωνα με το αποτέλεσμα. Η ροϊκή απόκριση χρησιμοποιεί το `response.completed` ή το `response.incomplete` ως τελική κατάσταση· το `usage` στην τελική κατάσταση είναι η τελική χρήση token για αυτό το αίτημα και αποτελεί επίσης τη βάση χρέωσης.

Εάν ο πελάτης αποσυνδεθεί πριν φτάσει η τελική κατάσταση, αυτό το αίτημα καταγράφεται ως ο πελάτης έκλεισε (499) και δεν θα χρεωθεί με βάση την τοπική εκτίμηση token· εάν η σύνδεση τερματιστεί κανονικά αλλά δεν ληφθούν η τελική κατάσταση και το τελικό `usage`, αυτό το αίτημα καταγράφεται ως ελλιπής απόκριση (502) και επίσης δεν θα χρεωθεί με βάση την εκτίμηση token. Όταν αντιμετωπίζετε αυτές τις δύο περιπτώσεις, παρακαλούμε υποβάλετε ξανά το αίτημα.

Το επιστρεφόμενο αποτέλεσμα `data` έχει συνολικά πολλά πεδία, τα οποία παρουσιάζονται ως εξής:

- `item_id`, το ID που δημιουργείται για αυτή την εργασία συνομιλίας, το οποίο χρησιμοποιείται για τη μοναδική αναγνώριση αυτής της εργασίας συνομιλίας.
- `type`, ο τύπος της εργασίας Responses που δημιουργείται για αυτή τη συνομιλία.
- `model `, το επιλεγμένο μοντέλο από τον επίσημο ιστότοπο του OpenAI ChatGPT.
- `delta`, οι πληροφορίες απάντησης που δίνει το ChatGPT για τη λέξη ερώτησης.

Υποστηρίζεται επίσης JavaScript, για παράδειγμα, ο κώδικας ροϊκής κλήσης του Node.js είναι ο εξής:

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer b82d32f570bc434d9ba9923aa0e7dce0",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4.1",
    input: [{ role: "user", content: "Hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/responses", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

Η επεξεργασία κειμένου με το μοντέλο gpt-4o είναι συνεπής με το περιεχόμενο βασικής χρήσης που αναφέρθηκε παραπάνω. Παρακάτω θα παρουσιαστεί συνοπτικά πώς να χρησιμοποιήσετε τις δυνατότητες επεξεργασίας εικόνας του μοντέλου.

## Χειρισμός σφαλμάτων

Κατά την κλήση του API, εάν παρουσιαστεί σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και τις σχετικές πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλειπόντων ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλειπόντων ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλείπον διακριτικό εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
