## 2. Επεξεργασία με χρήση URL εικόνας

Αρχική εικόνα:

![Αρχική εικόνα για επεξεργασία GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash

  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
```

## 3. Μεταφόρτωση τοπικής εικόνας

Χρησιμοποιήστε `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

Μπορείτε να περάσετε επανειλημμένα το `image`, ενώ η σειρά GPT Image υποστηρίζει έως 16 εικόνες αναφοράς. Το `image` σε αιτήματα JSON μπορεί να είναι ένα μεμονωμένο URL ή ένας πίνακας URL· τα τοπικά αρχεία μεταφορτώνονται με multipart.

| `gpt-image-2.6-flare`             | Εστιασμένο στην ταχύτητα δημιουργίας, σταθερή χρέωση ανά αριθμό επιτυχών εικόνων                               |
| `gpt-image-2.5-flare:reverse`     | Ρητό αντίστροφο ψευδώνυμο, ισοδύναμο με το `gpt-image-2.5-flare`, σταθερή χρέωση ανά αριθμό επιτυχών εικόνων    |

| `gpt-image-2.6-sunburst`          | Εστιασμένο στην υψηλή πιστότητα και τον λεπτομερή έλεγχο, σταθερή χρέωση ανά αριθμό επιτυχών εικόνων                           |
| `gpt-image-2.5-sunburst:reverse`  | Ρητό αντίστροφο ψευδώνυμο, ισοδύναμο με το `gpt-image-2.5-sunburst`, σταθερή χρέωση ανά αριθμό επιτυχών εικόνων |
| `gpt-image-2.6-sunburst:reverse`  | Ρητό αντίστροφο ψευδώνυμο, ισοδύναμο με το `gpt-image-2.6-sunburst`, σταθερή χρέωση ανά αριθμό επιτυχών εικόνων |
| `gpt-image-2.5-sunburst:official` | Επίσημο κανάλι API, υψηλότερη σταθερότητα και έμφαση στην υψηλή πιστότητα και τον λεπτομερή έλεγχο, χρέωση βάσει της πραγματικής χρήσης Token        |
| `gpt-image-2.6-sunburst:official` | Επίσημο κανάλι API, υψηλότερη σταθερότητα και έμφαση στην υψηλή πιστότητα και τον λεπτομερή έλεγχο, χρέωση βάσει της πραγματικής χρήσης Token        |

Τα αντίστροφα μοντέλα 2.0 / 2.5 (συμπεριλαμβανομένων των ψευδωνύμων `:reverse`) ενδέχεται να χρησιμοποιούν το GPT Image 2.5 Flare για την ολοκλήρωση αιτημάτων κατά την αυτόματη αποκατάσταση· το μοντέλο του αιτήματος και ο τρόπος χρέωσης ανά αριθμό επιτυχών εικόνων παραμένουν αμετάβλητα.

Οι τιμές σελίδας του επίσημου καναλιού API αποτελούν εκτίμηση πριν από το αίτημα· υπερισχύουν η πραγματική χρήση Token στην απόκριση και τα αρχεία χρήσης.

Το `quality` υποστηρίζει `auto`, `low`, `medium`, `high`· τα 2.5 / 2.6 Flare και Sunburst (συμπεριλαμβανομένων των παραλλαγών `:reverse` και `:official`) υποστηρίζουν επιπλέον `xhigh`, `max`. Αυτό το πεδίο μπορεί να περαστεί τόσο στην επεξεργασία URL εικόνας JSON όσο και στην επεξεργασία αρχείου multipart· το επίσημο κανάλι χρεώνει βάσει της πραγματικής χρήσης Token.

## 4. Τοπική επεξεργασία με χρήση μάσκας

Η επίσημη διεπαφή Images Edit καθορίζει την περιοχή που επιτρέπεται να τροποποιηθεί μέσω του `mask`. Τα μοντέλα `:official` του Ace Data Cloud ακολουθούν το ίδιο συμβόλαιο multipart:

- Το `mask` πρέπει να είναι PNG με κανάλι Alpha, μεγέθους έως 4MB·
- Οι διαστάσεις της μάσκας πρέπει να είναι ακριβώς ίδιες με την πρώτη `image`·
- Τα διαφανή εικονοστοιχεία με Alpha ίσο με `0` υποδεικνύουν ότι επιτρέπεται η επεξεργασία, ενώ τα μη διαφανή εικονοστοιχεία υποδεικνύουν ότι πρέπει να διατηρηθούν·
- Εικόνες RGB που είναι μόνο ασπρόμαυρες αλλά δεν διαθέτουν κανάλι διαφάνειας δεν μπορούν να χρησιμοποιηθούν ως έγκυρες μάσκες·
- Το prompt θα πρέπει να περιγράφει την πλήρη επιθυμητή εικόνα, ενώ παράλληλα να δηλώνει σαφώς την τοπική τροποποίηση και το περιεχόμενο που πρέπει να παραμείνει αμετάβλητο.

Παρακάτω δημιουργείται πρώτα μια μάσκα από την αρχική εικόνα. Το παράδειγμα ορίζει το κεντρικό ορθογώνιο ως διαφανές, επιτρέποντας στο μοντέλο να τροποποιήσει μόνο αυτή την περιοχή:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Στη συνέχεια, μεταφορτώστε μαζί την αρχική εικόνα και τη μάσκα:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Μπορείτε επίσης να συνεχίσετε να χρησιμοποιείτε τον τρόπο κλήσης `images.edit` του επίσημου Python SDK της OpenAI· αρκεί να ορίσετε το `base_url` στο Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Όταν χρησιμοποιείτε `mask`, η αρχική εικόνα και η μάσκα πρέπει να μεταφορτώνονται ξεχωριστά στο ίδιο multipart αίτημα μέσω των `image=@input.png` και `mask=@mask.png`. Μη συνδυάζετε εικόνα αρχικού URL με τοπικό αρχείο μάσκας· τα αιτήματα επεξεργασίας μόνο με URL δεν υποστηρίζουν την προσθήκη τοπικού αρχείου `mask`. Η μάσκα θα περιορίσει την περιοχή επεξεργασίας, αλλά το μοντέλο δημιουργίας μπορεί και πάλι να εφαρμόσει φυσική συγχώνευση στα άκρα· όταν απαιτούνται αυστηρά όρια, πρέπει να χρησιμοποιούνται καθαρές άκρες Alpha και να επαναλαμβάνεται στο prompt ποιο περιεχόμενο πρέπει να παραμείνει αμετάβλητο.

Οι παραπάνω τρόποι κλήσης είναι συνεπείς με τα παραδείγματα μάσκας του [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) και του [επίσημου Cookbook του GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Συνήθεις παράμετροι

| Πεδίο                | Περιγραφή                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (ταχύτερο) ή `gpt-image-2.5-sunburst` (υψηλότερη πιστότητα και έλεγχος)· και τα τρία μπορούν να επιλέξουν την αντίστοιχη παραλλαγή `:official`, ενώ το `gpt-image-2` υποστηρίζει επίσης το `:reverse` |
| `image`           | Το JSON χρησιμοποιεί ένα μεμονωμένο URL ή έναν πίνακα έως 16 URL· το multipart χρησιμοποιεί ένα ή περισσότερα πεδία αρχείου `image`. Όταν χρησιμοποιείται `mask`, πρέπει να μεταφορτωθεί τοπικό αρχείο εικόνας                                              |
| `mask`            | Προαιρετική μάσκα PNG, μόνο για μεταφόρτωση αρχείων multipart· πρέπει να διαθέτει κανάλι Alpha, να έχει το ίδιο μέγεθος με την πρώτη `image` και να μην υπερβαίνει τα 4MB                                                                 |
| `prompt`          | Οδηγία επεξεργασίας                                                                                                                             |
| `size`            | `auto` ή `WIDTHxHEIGHT` που συμμορφώνεται με τους περιορισμούς                                                                                                     |
| `n`               | 1–10· όταν `response_format=b64_json`, υποστηρίζεται μόνο το 1                                                                                           |
| `response_format` | `url` ή `b64_json`                                                                                                               |
| `callback_url`    | Προαιρετική διεύθυνση ασύγχρονης επανάκλησης                                                                                                                         |

Οι κανόνες μεγέθους είναι ίδιοι με τη διεπαφή δημιουργίας: το πλάτος και το ύψος πρέπει να είναι πολλαπλάσια του 16, η μεγάλη πλευρά δεν πρέπει να υπερβαίνει τα 3840, τα συνολικά pixel πρέπει να είναι 655,360–8,294,400 και ο λόγος διαστάσεων δεν πρέπει να υπερβαίνει το 3:1. Όταν παραλείπεται το `size` ή χρησιμοποιείται το `auto`, το μοντέλο θα επιλέξει το κάδρο συνδυάζοντας το prompt και την πρώτη εικόνα αναφοράς.

Τα `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` και τα ψευδώνυμα `:reverse` τους χρεώνονται ανά επιτυχημένη εικόνα· τα `gpt-image-2:official`, `gpt-image-2.5-flare:official` και `gpt-image-2.5-sunburst:official` χρεώνονται βάσει των πραγματικών Token της εισόδου κειμένου, της εισόδου εικόνας αναφοράς και της εξόδου εικόνας, με τελικό σημείο αναφοράς τα αρχεία χρήσης.

## 6. Ασύγχρονες επανακλήσεις και αντιμετώπιση σφαλμάτων

Σε μεγάλες εργασίες μπορείτε να προσθέσετε στο αίτημα:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Η ασύγχρονη απάντηση 200 είναι `{"task_id": "..."}`· μετά την ολοκλήρωση, γίνεται επανάκληση με το τελικό αποτέλεσμα. Τα συγχρονισμένα αιτήματα επιστρέφουν `created` και `data`.

| Κατάσταση  | Έλεγχος                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Μορφή/πλήθος εικόνων, συνδυασμός παραμέτρων και μορφή διαστάσεων· όταν χρησιμοποιείται `mask`, ελέγξτε το κανάλι PNG Alpha, το όριο των 4MB και αν οι διαστάσεις του είναι ίδιες με την πρώτη αρχική εικόνα |
| 401 | API Key και Bearer Header                                           |
| 429 | Συχνότητα αιτημάτων                                                              |
| 504 | Χρησιμοποιήστε ασύγχρονη επανάκληση                                                            |

Οι απαντήσεις σφάλματος θα περιλαμβάνουν `trace_id`. Όταν αναφέρετε προβλήματα, παρέχετε αυτό το ID, όχι το API Key.

Για τα πλήρη πεδία και τις ενημερωμένες απαριθμήσεις, ανατρέξτε στη σελίδα [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Για δημιουργία εικόνων μόνο από κείμενο, δείτε [Δημιουργία εικόνων GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

Το GPT Image 2.6 διατηρεί τις διεπαφές δημιουργίας, επεξεργασίας, ασύγχρονων εργασιών και χρέωσης του 2.5:

| Μοντέλο                                                          | Χρέωση                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/εικόνα                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/εικόνα                   |
| `gpt-image-2.6-flare:official`                              | Ίδια με το 2.5 official, χρέωση βάσει πραγματικής χρήσης Token |
| `gpt-image-2.6-sunburst:official`                           | Ίδια με το 2.5 official, χρέωση βάσει πραγματικής χρήσης Token |

Η ποιότητα μπορεί να επιλεγεί ως `auto`, `low`, `medium`, `high`, `xhigh`, `max`· για το μέγεθος χρησιμοποιήστε `auto` ή `WIDTHxHEIGHT` που συμμορφώνεται με τους παραπάνω περιορισμούς. Αυτή η διεπαφή υποστηρίζει `png`, `jpeg`, `webp`, ενώ προς το παρόν δεν υποστηρίζει SVG/GIF. Η επεξεργασία υποστηρίζει URL εικόνων JSON και μεταφόρτωση αρχείων multipart. Το `:reverse` είναι το ρητό ψευδώνυμο της κανονικής έκδοσης με το ίδιο όνομα. Χρησιμοποιήστε τον πλήρη κωδικό μοντέλου· μην στέλνετε `gpt-image-2.6`.
