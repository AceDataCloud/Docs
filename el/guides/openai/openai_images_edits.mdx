## 2. Επεξεργασία με χρήση URL εικόνας

Αρχική εικόνα:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
```

## 3. Μεταφόρτωση τοπικής εικόνας

Χρησιμοποιήστε `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

Το `image` μπορεί να υποβληθεί επανειλημμένα και η σειρά GPT Image υποστηρίζει έως 16 εικόνες αναφοράς. Το `image` σε αιτήματα JSON μπορεί να είναι ένα μεμονωμένο URL ή ένας πίνακας URL· τα τοπικά αρχεία μεταφορτώνονται με multipart.

### Μοντέλα και τρόποι χρέωσης

| Μοντέλο                                | Κατάλληλα σενάρια και τρόπος χρέωσης                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Προεπιλεγμένο αντίστροφο κανάλι, σταθερή χρέωση ανά αριθμό επιτυχημένων εικόνων                        |
| `gpt-image-2:reverse`             | Ρητή επιλογή αντίστροφου καναλιού, σταθερή χρέωση ανά αριθμό επιτυχημένων εικόνων                      |
| `gpt-image-2:official`            | Επίσημο κανάλι API, υψηλότερη σταθερότητα, χρέωση βάσει πραγματικής κατανάλωσης Token            |
| `gpt-image-2.5-flare`             | Εστίαση στην ταχύτητα δημιουργίας, σταθερή χρέωση ανά αριθμό επιτυχημένων εικόνων                        |
| `gpt-image-2.5-flare:official`    | Επίσημο κανάλι API, υψηλότερη σταθερότητα και εστίαση στην ταχύτητα δημιουργίας, χρέωση βάσει πραγματικής κατανάλωσης Token     |
| `gpt-image-2.5-sunburst`          | Εστίαση στην υψηλή πιστότητα και τον λεπτομερή έλεγχο, σταθερή χρέωση ανά αριθμό επιτυχημένων εικόνων                    |
| `gpt-image-2.5-sunburst:official` | Επίσημο κανάλι API, υψηλότερη σταθερότητα και εστίαση στην υψηλή πιστότητα και τον λεπτομερή έλεγχο, χρέωση βάσει πραγματικής κατανάλωσης Token |

Η τιμή στη σελίδα του επίσημου καναλιού API είναι εκτίμηση πριν από το αίτημα· το τελικό ποσό βασίζεται στην πραγματική κατανάλωση Token στην απόκριση και στα αρχεία χρήσης.

## 4. Χρήση μάσκας για τοπική επεξεργασία

Η επίσημη διεπαφή Images Edit καθορίζει την περιοχή που επιτρέπεται να τροποποιηθεί μέσω του `mask`. Τα μοντέλα `:official` του Ace Data Cloud ακολουθούν το ίδιο multipart συμβόλαιο:

- Το `mask` πρέπει να είναι PNG με κανάλι Alpha και μέγεθος έως 4MB·
- Οι διαστάσεις της μάσκας πρέπει να είναι ακριβώς ίδιες με την πρώτη `image`·
- Τα διαφανή pixel με Alpha `0` υποδεικνύουν ότι επιτρέπεται η επεξεργασία, ενώ τα μη διαφανή pixel υποδεικνύουν ότι πρέπει να διατηρηθούν·
- Μια RGB εικόνα που είναι μόνο ασπρόμαυρη αλλά δεν διαθέτει κανάλι διαφάνειας δεν μπορεί να χρησιμοποιηθεί ως έγκυρη μάσκα·
- Το prompt θα πρέπει να περιγράφει την πλήρη επιθυμητή εικόνα, ενώ ταυτόχρονα να διευκρινίζει την τοπική αλλαγή και το περιεχόμενο που πρέπει να παραμείνει αμετάβλητο.

Παρακάτω δημιουργείται πρώτα μια μάσκα από την αρχική εικόνα. Το παράδειγμα ορίζει το κεντρικό ορθογώνιο ως διαφανές, επιτρέποντας στο μοντέλο να τροποποιήσει μόνο αυτήν την περιοχή:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Στη συνέχεια, μεταφορτώστε μαζί την αρχική εικόνα και τη μάσκα:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Μπορείτε επίσης να συνεχίσετε να χρησιμοποιείτε τον τρόπο κλήσης `images.edit` του επίσημου Python SDK της OpenAI· αρκεί να κατευθύνετε το `base_url` προς το Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Κατά τη χρήση του `mask`, η αρχική εικόνα και η μάσκα πρέπει να μεταφορτωθούν στο ίδιο multipart αίτημα μέσω των `image=@input.png` και `mask=@mask.png`, αντίστοιχα. Μη συνδυάζετε αρχική εικόνα URL με τοπικό αρχείο μάσκας· τα αιτήματα επεξεργασίας μόνο με URL δεν υποστηρίζουν την προσθήκη τοπικού αρχείου `mask`. Η μάσκα περιορίζει την περιοχή επεξεργασίας, αλλά το μοντέλο δημιουργίας ενδέχεται να εξακολουθεί να εκτελεί φυσική ανάμειξη στα άκρα· όταν απαιτούνται αυστηρά όρια, θα πρέπει να χρησιμοποιούνται καθαρά άκρα Alpha και να επαναλαμβάνεται στο prompt ποιο περιεχόμενο πρέπει να παραμείνει αμετάβλητο.

Οι παραπάνω τρόποι κλήσης συνάδουν με τα παραδείγματα μάσκας του [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) και του [επίσημου Cookbook του GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).
## 5. Συνήθεις παράμετροι

| Πεδίο                | Περιγραφή                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (ταχύτερο) ή `gpt-image-2.5-sunburst` (υψηλότερη πιστότητα και έλεγχος)· και τα τρία μπορούν να επιλέξουν την αντίστοιχη παραλλαγή `:official`, ενώ το `gpt-image-2` υποστηρίζει επίσης το `:reverse` |
| `image`           | Το JSON χρησιμοποιεί ένα μεμονωμένο URL ή έναν πίνακα έως 16 URL· το multipart χρησιμοποιεί ένα ή περισσότερα πεδία αρχείου `image`. Κατά τη χρήση `mask`, πρέπει να μεταφορτωθεί ένα τοπικό αρχείο εικόνας                                              |
| `mask`            | Προαιρετική μάσκα PNG, μόνο για μεταφόρτωση αρχείου multipart· πρέπει να διαθέτει κανάλι Alpha, να έχει το ίδιο μέγεθος με την πρώτη `image` και να μην υπερβαίνει τα 4MB                                                                 |
| `prompt`          | Οδηγία επεξεργασίας                                                                                                                             |
| `size`            | `auto` ή `WIDTHxHEIGHT` που συμμορφώνεται με τους περιορισμούς                                                                                                     |
| `n`               | 1–10· όταν `response_format=b64_json`, υποστηρίζεται μόνο το 1                                                                                           |
| `response_format` | `url` ή `b64_json`                                                                                                               |
| `callback_url`    | Προαιρετική διεύθυνση ασύγχρονης επανάκλησης                                                                                                                         |

Οι κανόνες διαστάσεων είναι ίδιοι με τη διεπαφή δημιουργίας: το πλάτος και το ύψος πρέπει να είναι πολλαπλάσια του 16, η μεγαλύτερη πλευρά δεν πρέπει να υπερβαίνει τα 3840, τα συνολικά pixel πρέπει να είναι 655,360–8,294,400 και η αναλογία διαστάσεων δεν πρέπει να υπερβαίνει το 3:1. Όταν παραλείπεται το `size` ή χρησιμοποιείται το `auto`, το μοντέλο επιλέγει κάδρο με βάση το prompt και την πρώτη εικόνα αναφοράς.

Τα `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` και `gpt-image-2:reverse` χρεώνονται ανά αριθμό επιτυχημένων εικόνων· τα `gpt-image-2:official`, `gpt-image-2.5-flare:official` και `gpt-image-2.5-sunburst:official` χρεώνονται σύμφωνα με τα πραγματικά Token της εισαγωγής κειμένου, της εισαγωγής εικόνας αναφοράς και της εξαγωγής εικόνας, με τελικό σημείο αναφοράς το ιστορικό χρήσης.

## 6. Ασύγχρονη επανάκληση και αντιμετώπιση σφαλμάτων

Για μεγάλες εργασίες, μπορεί να προστεθεί στο αίτημα:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Η ασύγχρονη απόκριση 200 είναι `{"task_id": "..."}`· μετά την ολοκλήρωση, γίνεται επανάκληση με το τελικό αποτέλεσμα. Τα σύγχρονα αιτήματα επιστρέφουν `created` και `data`.

| Κατάσταση  | Έλεγχος                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Μορφή/αριθμός εικόνων, συνδυασμός παραμέτρων και μορφή διαστάσεων· κατά τη χρήση `mask`, ελέγξτε το κανάλι Alpha PNG, το όριο 4MB και αν οι διαστάσεις του είναι ίδιες με της πρώτης αρχικής εικόνας |
| 401 | API Key και Bearer Header                                           |
| 429 | Συχνότητα αιτημάτων                                                              |
| 504 | Χρησιμοποιήστε ασύγχρονη επανάκληση                                                            |

Οι αποκρίσεις σφάλματος περιλαμβάνουν `trace_id`. Όταν αναφέρετε ένα πρόβλημα, παρέχετε αυτό το ID και όχι το API Key.

Για τα πλήρη πεδία και τις ενημερωμένες απαριθμήσεις, ανατρέξτε στη σελίδα [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Για δημιουργία εικόνων μόνο από κείμενο, δείτε [Δημιουργία εικόνων GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
