## 3. Μεταφόρτωση τοπικής εικόνας

Χρησιμοποιήστε `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

Το `image` μπορεί να αποσταλεί επανειλημμένα· η σειρά GPT Image υποστηρίζει έως 16 εικόνες αναφοράς. Το `image` σε αιτήματα JSON μπορεί να είναι ένα μεμονωμένο URL ή ένας πίνακας URL· τα τοπικά αρχεία μεταφορτώνονται με multipart.

## 4. Τοπική επεξεργασία με χρήση μάσκας

Η επίσημη διεπαφή Images Edit καθορίζει την περιοχή που επιτρέπεται να τροποποιηθεί μέσω του `mask`. Τα μοντέλα `:official` του Ace Data Cloud ακολουθούν το ίδιο συμβόλαιο multipart:

- Το `mask` πρέπει να είναι PNG με κανάλι Alpha και μέγεθος που δεν υπερβαίνει τα 4MB·
- Οι διαστάσεις της μάσκας πρέπει να είναι ακριβώς ίδιες με την πρώτη `image`·
- Τα διαφανή pixel με Alpha ίσο με `0` υποδεικνύουν ότι επιτρέπεται η επεξεργασία, ενώ τα μη διαφανή pixel υποδεικνύουν ότι πρέπει να διατηρηθούν·
- Εικόνες RGB που έχουν μόνο μαύρο και λευκό χρώμα, αλλά δεν διαθέτουν κανάλι διαφάνειας, δεν μπορούν να χρησιμοποιηθούν ως έγκυρες μάσκες·
- Το prompt θα πρέπει να περιγράφει την πλήρη επιθυμητή εικόνα, ενώ παράλληλα να διευκρινίζει τις τοπικές τροποποιήσεις και το περιεχόμενο που πρέπει να παραμείνει αμετάβλητο.

Παρακάτω, δημιουργείται πρώτα μια μάσκα από την αρχική εικόνα. Το παράδειγμα ορίζει το κεντρικό ορθογώνιο ως διαφανές, επιτρέποντας στο μοντέλο να τροποποιήσει μόνο αυτή την περιοχή:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Στη συνέχεια, μεταφορτώστε μαζί την αρχική εικόνα και τη μάσκα:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Μπορείτε επίσης να συνεχίσετε να χρησιμοποιείτε τον τρόπο κλήσης `images.edit` του επίσημου Python SDK της OpenAI· αρκεί να ορίσετε το `base_url` στο Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Όταν χρησιμοποιείτε `mask`, η αρχική εικόνα και η μάσκα πρέπει να μεταφορτώνονται ξεχωριστά μέσω `image=@input.png` και `mask=@mask.png` στο ίδιο multipart αίτημα. Μη μεταβιβάζετε μαζί μια αρχική εικόνα URL και ένα τοπικό αρχείο μάσκας· τα αιτήματα επεξεργασίας μόνο με URL δεν υποστηρίζουν την επιπλέον προσάρτηση τοπικού αρχείου `mask`. Η μάσκα περιορίζει την περιοχή επεξεργασίας, αλλά το μοντέλο δημιουργίας μπορεί και πάλι να εφαρμόσει φυσική ανάμειξη στα άκρα· όταν απαιτούνται αυστηρά όρια, θα πρέπει να χρησιμοποιείτε καθαρά άκρα Alpha και να επαναλαμβάνετε στην προτροπή ποιο περιεχόμενο πρέπει να παραμείνει αμετάβλητο.

Οι παραπάνω τρόποι κλήσης είναι συνεπείς με τα παραδείγματα μάσκας του [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) και του [επίσημου Cookbook του GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Συνήθεις παράμετροι

| Πεδίο                | Περιγραφή                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (ταχύτερο) ή `gpt-image-2.5-sunburst` (υψηλότερη πιστότητα και έλεγχος)· και τα τρία μπορούν να επιλέξουν την αντίστοιχη παραλλαγή `:official`, ενώ το `gpt-image-2` υποστηρίζει επίσης το `:reverse` |
| `image`           | Το JSON χρησιμοποιεί ένα μεμονωμένο URL ή έναν πίνακα έως 16 URL· το multipart χρησιμοποιεί ένα ή περισσότερα πεδία αρχείου `image`. Κατά τη χρήση `mask`, πρέπει να μεταφορτωθεί τοπικό αρχείο εικόνας                                              |
| `mask`            | Προαιρετική μάσκα PNG, μόνο για μεταφόρτωση αρχείων multipart· πρέπει να διαθέτει κανάλι Alpha, να έχει το ίδιο μέγεθος με την πρώτη `image` και να μην υπερβαίνει τα 4MB                                                                 |
| `prompt`          | Εντολή επεξεργασίας                                                                                                                             |
| `size`            | `auto` ή `WIDTHxHEIGHT` που συμμορφώνεται με τους περιορισμούς                                                                                                     |
| `n`               | 1–10· όταν `response_format=b64_json`, υποστηρίζεται μόνο το 1                                                                                           |
| `response_format` | `url` ή `b64_json`                                                                                                               |
| `callback_url`    | Προαιρετική διεύθυνση ασύγχρονης επανάκλησης                                                                                                                         |

Οι κανόνες μεγέθους είναι ίδιοι με τη διεπαφή δημιουργίας: το πλάτος και το ύψος πρέπει να είναι πολλαπλάσια του 16, η μεγάλη πλευρά δεν πρέπει να υπερβαίνει τα 3840, το σύνολο των pixel είναι 655,360–8,294,400 και ο λόγος διαστάσεων δεν πρέπει να υπερβαίνει το 3:1. Όταν παραλείπεται το `size` ή χρησιμοποιείται το `auto`, το μοντέλο επιλέγει τις αναλογίες καμβά συνδυάζοντας την προτροπή και την πρώτη εικόνα αναφοράς.

Τα `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` και τα ψευδώνυμα `:reverse` τους χρεώνονται ανά επιτυχημένη εικόνα· τα `gpt-image-2:official`, `gpt-image-2.5-flare:official` και `gpt-image-2.5-sunburst:official` χρεώνονται βάσει των πραγματικών Token της εισόδου κειμένου, της εισόδου εικόνας αναφοράς και της εξόδου εικόνας, με τελική αναφορά τα αρχεία χρήσης.

## 6. Ασύγχρονες επανακλήσεις και αντιμετώπιση σφαλμάτων

Για μεγάλες εργασίες, μπορείτε να προσθέσετε στο αίτημα:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Η ασύγχρονη απόκριση 200 είναι `{"task_id": "..."}`· μετά την ολοκλήρωση, γίνεται επανάκληση με το τελικό αποτέλεσμα. Τα σύγχρονα αιτήματα επιστρέφουν `created` και `data`.

| Κατάσταση  | Έλεγχος                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Μορφή/πλήθος εικόνων, συνδυασμός παραμέτρων και μορφή μεγέθους· κατά τη χρήση `mask`, ελέγξτε το κανάλι PNG Alpha, το όριο 4MB και αν οι διαστάσεις του είναι ίδιες με την πρώτη αρχική εικόνα |
| 401 | API Key και Bearer Header                                           |
| 429 | Συχνότητα αιτημάτων                                                              |
| 504 | Χρησιμοποιήστε ασύγχρονη επανάκληση                                                            |

Οι αποκρίσεις σφάλματος περιλαμβάνουν `trace_id`. Όταν αναφέρετε προβλήματα, παρέχετε αυτό το ID και όχι το API Key.

Για τα πλήρη πεδία και τις ενημερωμένες απαριθμήσεις, ανατρέξτε στη σελίδα [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Για δημιουργία εικόνων από απλό κείμενο, ανατρέξτε στο [GPT Image 2 / 2.5 / 2.6 δημιουργία εικόνων](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

Το GPT Image 2.6 συνεχίζει να χρησιμοποιεί τις διεπαφές δημιουργίας, επεξεργασίας, ασύγχρονων εργασιών και χρέωσης του 2.5:

| Μοντέλο                                                          | Χρέωση                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/εικόνα                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/εικόνα                   |
| `gpt-image-2.6-flare:official`                              | Ίδια με το 2.5 official, χρέωση βάσει της πραγματικής χρήσης Token |
| `gpt-image-2.6-sunburst:official`                           | Ίδια με το 2.5 official, χρέωση βάσει της πραγματικής χρήσης Token |

Η ποιότητα μπορεί να είναι `auto`, `low`, `medium`, `high`, `xhigh`, `max`· για το μέγεθος χρησιμοποιήστε `auto` ή `WIDTHxHEIGHT` που συμμορφώνεται με τους παραπάνω περιορισμούς. Αυτή η διεπαφή υποστηρίζει `png`, `jpeg`, `webp`· το GPT Image 2.6 υποστηρίζει επίσης εγγενώς κινούμενα `gif`, ενώ το SVG δεν υποστηρίζεται προς το παρόν. Η επεξεργασία υποστηρίζει URL εικόνων JSON και μεταφόρτωση αρχείων multipart. Το `:reverse` είναι το ρητό ψευδώνυμο της κανονικής έκδοσης με το ίδιο όνομα. Χρησιμοποιήστε τον πλήρη τύπο μοντέλου· μην μεταβιβάζετε `gpt-image-2.6`.

### GPT Image 2.6 Μετατροπή εικόνας σε κινούμενο GIF
Το GPT Image 2.6 Flare, η κανονική έκδοση του Sunburst, τα `:reverse`, `:official` μπορούν όλα να χρησιμοποιούν `output_format: "gif"`. Τα καρέ της κινούμενης εικόνας, οι πληροφορίες επανάληψης και η διάρκεια αναπαραγωγής διατηρούνται· το `frame_count` δηλώνει τον αριθμό καρέ, το `frame_duration_ms` δηλώνει τα χιλιοστά του δευτερολέπτου ανά καρέ, ο αριθμός καρέ πρέπει να είναι ακέραιος από 2–16, η διάρκεια κάθε καρέ πρέπει να είναι ακέραιος από 20–655350 χιλιοστά του δευτερολέπτου και χρησιμοποιείται μόνο για GIF· η κωδικοποίηση στρογγυλοποιείται στα πλησιέστερα 10ms. Όταν δεν καθορίζεται, η προεπιλογή είναι 9 καρέ, 200 χιλιοστά του δευτερολέπτου ανά καρέ· όταν το `size` του GIF παραλείπεται ή είναι auto, χρησιμοποιείται η προεπιλογή 512x512.

Συνιστάται να χρησιμοποιήσετε πρώτα `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. Τα GIF έχουν ανεξάρτητους περιορισμούς μεγέθους και αριθμού καρέ και δεν μπορούν να χρησιμοποιούν απευθείας τις προδιαγραφές στατικών 4K· ορισμένα μοντέλα θα προσαρμόσουν το πραγματικό μέγεθος εξόδου. Το `n` δηλώνει τον αριθμό των αρχείων GIF που επιστρέφονται, όχι τον αριθμό των καρέ της κινούμενης εικόνας. Η κανονική έκδοση και το `:reverse` εξακολουθούν να χρεώνονται με βάση τον αριθμό των επιτυχημένων αρχείων, ενώ η επίσημη έκδοση χρεώνεται με βάση την πραγματική χρήση Token.

```json
{
  "model": "gpt-image-2.6-flare",
  "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
  "prompt": "Animate the mug gently moving left and right. Keep its appearance and the background, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### GPT Image 2.6 Στατικές εικόνες 4K

Το Flare, το Sunburst και οι παραλλαγές τους `:reverse`, `:official` μπορούν όλα να χρησιμοποιούν τις προαναφερθείσες προεπιλογές pixel 4K, όπως `3840x2160` και `2160x3840`. Τόσο η δημιουργία όσο και η επεξεργασία λαμβάνουν συγκεκριμένα pixel μέσω του `size`· το `4K` δεν είναι έγκυρη τιμή `size`, ενώ το `4096x4096` επίσης υπερβαίνει το τρέχον όριο pixel. Οι παραπάνω προδιαγραφές 4K ισχύουν για στατικά PNG/JPEG/WebP· για GIF χρησιμοποιήστε τις ειδικές παραμέτρους του.

### Πολυπλοκότητα σύνθεσης GPT Image 2.6

Το `complexity` μπορεί προαιρετικά να είναι `low`, `medium`, `high`, ενώ όταν παραλείπεται χρησιμοποιείται η προεπιλογή του μοντέλου `high`. Ελέγχει την πολυπλοκότητα σχεδιασμού και είναι ανεξάρτητο από την ποιότητα απόδοσης `quality`· δεν χρεώνεται επιπλέον ανά αίτημα και η επίσημη έκδοση εξακολουθεί να χρεώνεται με βάση την πραγματική κατανάλωση Token. Άλλα μοντέλα δεν υποστηρίζουν αυτή την παράμετρο.

Το GIF δεν υποστηρίζει mask, εικόνες επισήμανσης, προσαρμοσμένη συμπίεση, επανεγγραφή prompt ή μερική ροή εικόνας· ασύμβατοι συνδυασμοί απορρίπτονται πριν από τη δημιουργία. Το μέγεθος, ο αριθμός καρέ και η ποσότητα περιορίζονται από κοινού από τον προϋπολογισμό pixel του μοντέλου· για το κανονικό Flare έχει επαληθευτεί ότι λειτουργεί το `1024x1024` με 2 καρέ, αλλά αυτό το συμπέρασμα δεν μπορεί να επεκταθεί σε όλους τους συνδυασμούς 1K ή σε GIF 4K.

### Επεξεργασία με καθοδήγηση επισήμανσης

Η στατική επεξεργασία GPT Image 2.6 υποστηρίζει `markup`. Ανεβάστε ένα διαφανές PNG με το ίδιο μέγεθος με την πρώτη εικόνα αναφοράς, κυκλώστε σε ανεξάρτητο επίπεδο τη θέση που θέλετε να τροποποιήσετε και περιγράψτε τις απαιτήσεις τροποποίησης στο `prompt`. Το επίπεδο επισήμανσης πρέπει να περιέχει διαφανή pixel· καθεμία από τις δύο εικόνες δεν πρέπει να υπερβαίνει τα 16777216 pixel και η εικόνα επισήμανσης δεν πρέπει να υπερβαίνει τα 40MB. Το JSON μπορεί να μεταφέρει URL HTTPS, PNG base64 data URL ή `{ "image_url": "https://..." }`· το multipart ανεβάζει το αρχείο μέσω `markup`. Η πλατφόρμα μεταβιβάζει το επίπεδο επισήμανσης ως αρχείο. Το `markup` δεν μπορεί να χρησιμοποιηθεί μαζί με `mask`, GIF ή `prompt_rewriter`, και δεν υποστηρίζει `file_id`.

Το `input_fidelity` δεν εφαρμόζεται στο GPT Image 2.6, παραλείψτε το.
