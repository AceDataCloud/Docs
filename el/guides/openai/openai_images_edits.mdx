Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), εισέλθετε στη διαθέσιμη εφαρμογή και αντιγράψτε το API Key.

## 2. Επεξεργασία με URL εικόνας

Αρχική εικόνα:

![Αρχική εικόνα επεξεργασίας GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",

```

## 3. Μεταφόρτωση τοπικής εικόνας

Χρησιμοποιήστε `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

Το `image` μπορεί να εισαχθεί επανειλημμένα και η σειρά GPT Image υποστηρίζει έως 16 εικόνες αναφοράς. Το `image` σε αιτήματα JSON μπορεί να είναι ένα μεμονωμένο URL ή ένας πίνακας URL· τα τοπικά αρχεία μεταφορτώνονται με multipart.

### Μοντέλα και τρόποι χρέωσης

| Μοντέλο                                | Κατάλληλα σενάρια και τρόπος χρέωσης                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Προεπιλεγμένο αντίστροφο κανάλι, σταθερή χρέωση ανά αριθμό επιτυχημένων εικόνων                        |
| `gpt-image-2:reverse`             | Ρητή επιλογή αντίστροφου καναλιού, σταθερή χρέωση ανά αριθμό επιτυχημένων εικόνων                      |
| `gpt-image-2:official`            | Επίσημο κανάλι API, υψηλότερη σταθερότητα, χρέωση βάσει της πραγματικής χρήσης Token            |
| `gpt-image-2.5-flare`             | Έμφαση στην ταχύτητα δημιουργίας, σταθερή χρέωση ανά αριθμό επιτυχημένων εικόνων                        |
| `gpt-image-2.5-flare:official`    | Επίσημο κανάλι API, υψηλότερη σταθερότητα και έμφαση στην ταχύτητα δημιουργίας, χρέωση βάσει της πραγματικής χρήσης Token     |
| `gpt-image-2.5-sunburst`          | Έμφαση στην υψηλή πιστότητα και τον λεπτομερή έλεγχο, σταθερή χρέωση ανά αριθμό επιτυχημένων εικόνων                    |
| `gpt-image-2.5-sunburst:official` | Επίσημο κανάλι API, υψηλότερη σταθερότητα και έμφαση στην υψηλή πιστότητα και τον λεπτομερή έλεγχο, χρέωση βάσει της πραγματικής χρήσης Token |

Η τιμή στη σελίδα για το επίσημο κανάλι API είναι εκτίμηση πριν από το αίτημα· τελικά υπερισχύουν η πραγματική χρήση Token στην απόκριση και τα αρχεία χρήσης.

Το `quality` υποστηρίζει `auto`, `low`, `medium`, `high`· μόνο τα `gpt-image-2.5-flare` και `gpt-image-2.5-sunburst` (συμπεριλαμβανομένων των παραλλαγών `:official`) υποστηρίζουν επιπλέον `xhigh`, `max`. Τόσο η επεξεργασία URL εικόνας JSON όσο και η επεξεργασία αρχείων multipart μπορούν να λάβουν αυτό το πεδίο· το επίσημο κανάλι χρεώνει βάσει της πραγματικής χρήσης Token.

## 4. Χρήση μάσκας για τοπική επεξεργασία

Η επίσημη διεπαφή Images Edit καθορίζει την περιοχή που επιτρέπεται να τροποποιηθεί μέσω του `mask`. Τα μοντέλα `:official` του Ace Data Cloud ακολουθούν το ίδιο συμβόλαιο multipart:

- Το `mask` πρέπει να είναι PNG με κανάλι Alpha και μέγεθος που δεν υπερβαίνει τα 4MB·
- Οι διαστάσεις της μάσκας πρέπει να είναι ακριβώς ίδιες με την πρώτη `image`·
- Τα διαφανή εικονοστοιχεία με Alpha ίσο με `0` υποδεικνύουν ότι επιτρέπεται η επεξεργασία, ενώ τα μη διαφανή εικονοστοιχεία υποδεικνύουν ότι πρέπει να διατηρηθούν·
- Εικόνες RGB που έχουν μόνο μαύρο και λευκό χρώμα, αλλά δεν έχουν κανάλι διαφάνειας, δεν μπορούν να χρησιμοποιηθούν ως έγκυρες μάσκες·
- Το prompt πρέπει να περιγράφει την πλήρη επιθυμητή εικόνα, ενώ παράλληλα να καθορίζει ξεκάθαρα την τοπική τροποποίηση και το περιεχόμενο που πρέπει να παραμείνει αμετάβλητο.

Παρακάτω δημιουργείται πρώτα μια μάσκα από την αρχική εικόνα. Το παράδειγμα ορίζει το κεντρικό ορθογώνιο ως διαφανές, επιτρέποντας στο μοντέλο να τροποποιήσει μόνο αυτή την περιοχή:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Στη συνέχεια, μεταφορτώστε μαζί την αρχική εικόνα και τη μάσκα:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Μπορείτε επίσης να συνεχίσετε να χρησιμοποιείτε τον τρόπο κλήσης `images.edit` του επίσημου Python SDK της OpenAI· απλώς ορίστε το `base_url` να δείχνει στο Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```
Όταν χρησιμοποιείτε `mask`, η αρχική εικόνα και η μάσκα πρέπει να μεταφορτώνονται ξεχωριστά στο ίδιο multipart αίτημα μέσω `image=@input.png` και `mask=@mask.png`. Μην αναμειγνύετε μια αρχική εικόνα URL με ένα τοπικό αρχείο μάσκας· τα αιτήματα επεξεργασίας μόνο με URL δεν υποστηρίζουν την επιπλέον επισύναψη τοπικού αρχείου `mask`. Η μάσκα θα περιορίσει την περιοχή επεξεργασίας, αλλά το μοντέλο δημιουργίας ενδέχεται να εξακολουθεί να εκτελεί φυσική ανάμειξη στα άκρα· όταν απαιτούνται αυστηρά όρια, θα πρέπει να χρησιμοποιούνται καθαρές άκρες Alpha και να επαναλαμβάνεται στο prompt ποιο περιεχόμενο πρέπει να παραμείνει αμετάβλητο.

Η παραπάνω μέθοδος κλήσης συνάδει με τα παραδείγματα μασκών του [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) και του [επίσημου GPT Image Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Συνήθεις παράμετροι

| Πεδίο                | Περιγραφή                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (ταχύτερο) ή `gpt-image-2.5-sunburst` (υψηλότερη πιστότητα και έλεγχος)· και τα τρία μπορούν να επιλέξουν την αντίστοιχη παραλλαγή `:official`, ενώ το `gpt-image-2` υποστηρίζει επίσης το `:reverse` |
| `image`           | Το JSON χρησιμοποιεί ένα μεμονωμένο URL ή έναν πίνακα έως 16 URL· το multipart χρησιμοποιεί ένα ή περισσότερα πεδία αρχείου `image`. Κατά τη χρήση `mask`, πρέπει να μεταφορτώνεται τοπικό αρχείο εικόνας                                              |
| `mask`            | Προαιρετική μάσκα PNG, μόνο για μεταφόρτωση αρχείων multipart· πρέπει να διαθέτει κανάλι Alpha, να έχει τις ίδιες διαστάσεις με την πρώτη `image` και να μην υπερβαίνει τα 4MB                                                                 |
| `prompt`          | Οδηγίες επεξεργασίας                                                                                                                             |
| `size`            | `auto` ή `WIDTHxHEIGHT` που συμμορφώνεται με τους περιορισμούς                                                                                                     |
| `n`               | 1–10· όταν `response_format=b64_json`, υποστηρίζεται μόνο το 1                                                                                           |
| `response_format` | `url` ή `b64_json`                                                                                                               |
| `callback_url`    | Προαιρετική διεύθυνση ασύγχρονης επανάκλησης                                                                                                                         |

Οι κανόνες διαστάσεων είναι ίδιοι με το API δημιουργίας: το πλάτος και το ύψος πρέπει να είναι πολλαπλάσια του 16, η μεγάλη πλευρά δεν πρέπει να υπερβαίνει τα 3840, τα συνολικά pixel πρέπει να είναι 655,360–8,294,400 και η αναλογία διαστάσεων δεν πρέπει να υπερβαίνει το 3:1. Όταν παραλείπεται το `size` ή χρησιμοποιείται το `auto`, το μοντέλο θα επιλέξει το κάδρο βάσει του prompt και της πρώτης εικόνας αναφοράς.

Τα `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` και `gpt-image-2:reverse` χρεώνονται ανά επιτυχημένο αριθμό εικόνων· τα `gpt-image-2:official`, `gpt-image-2.5-flare:official` και `gpt-image-2.5-sunburst:official` χρεώνονται βάσει των πραγματικών Token της εισόδου κειμένου, της εισόδου εικόνας αναφοράς και της εξόδου εικόνας, με τελική αναφορά τα αρχεία χρήσης.

## 6. Ασύγχρονη επανάκληση και αντιμετώπιση σφαλμάτων

Για μακροχρόνιες εργασίες, μπορείτε να προσθέσετε στο αίτημα:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Η ασύγχρονη απόκριση 200 είναι `{"task_id": "..."}`· μετά την ολοκλήρωση, γίνεται επανάκληση του τελικού αποτελέσματος. Τα σύγχρονα αιτήματα επιστρέφουν `created` και `data`.

| Κατάσταση  | Έλεγχος                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Μορφή/αριθμός εικόνων, συνδυασμοί παραμέτρων και μορφή διαστάσεων· κατά τη χρήση `mask`, ελέγξτε το κανάλι PNG Alpha, το όριο των 4MB και αν οι διαστάσεις της είναι ίδιες με την πρώτη αρχική εικόνα |
| 401 | API Key και Bearer Header                                           |
| 429 | Συχνότητα αιτημάτων                                                              |
| 504 | Χρησιμοποιήστε ασύγχρονη επανάκληση                                                            |

Οι αποκρίσεις σφάλματος θα περιλαμβάνουν `trace_id`. Όταν αναφέρετε ένα πρόβλημα, παρέχετε αυτό το ID, όχι το API Key.

Για τα πλήρη πεδία και τις ενημερωμένες απαριθμήσεις, ανατρέξτε στη σελίδα [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Για δημιουργία εικόνων μόνο από κείμενο, ανατρέξτε στο [GPT Image 2 / 2.5 δημιουργία εικόνων](https://platform.acedata.cloud/documents/openai-images-generations).
