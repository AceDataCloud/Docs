Η υπηρεσία επεξεργασίας εικόνας OpenAI επιτρέπει την εισαγωγή οποιουδήποτε αριθμού εικόνων και εντολών, εξάγοντας τις τροποποιημένες εικόνες.

Αυτό το έγγραφο περιγράφει τη διαδικασία χρήσης του OpenAI Images Edits API, επιτρέποντάς μας να χρησιμοποιούμε εύκολα τη λειτουργία επεξεργασίας εικόνας της επίσημης OpenAI.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το OpenAI Images Edits API, μπορείτε πρώτα να επισκεφθείτε τη σελίδα [OpenAI Images Edits API](https://platform.acedata.cloud/documents/251f1efa-aaa6-462e-8af4-66854b1bc94d) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να χρησιμοποιήσετε δωρεάν αυτό το API.

## Βασική Χρήση

Στη συνέχεια, μπορείτε να χρησιμοποιήσετε κώδικα για να κάνετε κλήσεις, παρακάτω είναι η κλήση μέσω CURL:

```curl
curl -s -D >(grep -i x-request-id >&2) \
  -o >(jq -r '.data[0].b64_json' | base64 --decode > gift-basket.png) \
  -X POST "https://api.acedata.cloud/v1/images/edits" \
  -H "Authorization: Bearer {token}" \
  -F "model=gpt-image-1" \
  -F "image[]=@test.png" \
  -F 'prompt=Create a lovely gift basket with these this items in it'
```

Κατά την πρώτη χρήση αυτού του API, πρέπει τουλάχιστον να συμπληρώσετε τέσσερα στοιχεία: το ένα είναι το `authorization`, το οποίο μπορείτε να επιλέξετε απευθείας από τη λίστα. Ένα άλλο παράμετρο είναι το `model`, το οποίο είναι η κατηγορία μοντέλου που επιλέγουμε να χρησιμοποιήσουμε από την επίσημη OpenAI, εδώ έχουμε κυρίως 1 μοντέλο, λεπτομέρειες μπορείτε να δείτε στα μοντέλα που παρέχουμε. Ένα άλλο παράμετρο είναι το `prompt`, το οποίο είναι η προτροπή που εισάγουμε για να δημιουργήσουμε την εικόνα. Τέλος, η παράμετρος `image`, η οποία απαιτεί τη διαδρομή της εικόνας που πρέπει να επεξεργαστεί, όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/jw9iwu.png" width="500" className="m-auto" /></p>

Παράδειγμα κώδικα κλήσης σε Python με παρόμοιο αποτέλεσμα:

```python
import base64
from openai import OpenAI
client = OpenAI()

prompt = """
Generate a photorealistic image of a gift basket on a white background 
labeled 'Relax & Unwind' with a ribbon and handwriting-like font, 
containing all the items in the reference pictures.
"""

result = client.images.edit(
    model="gpt-image-1",
    image=[
        open("test.png", "rb")
    ],
    prompt=prompt
)

image_base64 = result.data[0].b64_json
image_bytes = base64.b64decode(image_base64)

# Save the image to a file
with open("gift-basket.png", "wb") as f:
    f.write(image_bytes)
```

Για να κάνουμε κλήσεις με Python, πρέπει πρώτα να εισάγουμε δύο μεταβλητές περιβάλλοντος, μία `OPENAI_BASE_URL`, η οποία μπορεί να ρυθμιστεί σε `https://api.acedata.cloud/openai`, και μία μεταβλητή πιστοποίησης `OPENAI_API_KEY`, η οποία είναι η τιμή που αποκτήθηκε από το `authorization`. Στο Mac OS, μπορείτε να ρυθμίσετε τις μεταβλητές περιβάλλοντος με την παρακάτω εντολή:

```shell
export OPENAI_BASE_URL=https://api.acedata.cloud/openai
export OPENAI_API_KEY={token} 
```

Μετά την κλήση, θα παρατηρήσετε ότι θα δημιουργηθεί μια εικόνα `gift-basket.png` στον τρέχοντα κατάλογο, το συγκεκριμένο αποτέλεσμα είναι το εξής:

<p><img src="https://cdn.acedata.cloud/574s8h.png" width="500" className="m-auto" /></p>

Έτσι ολοκληρώσαμε τη διαδικασία επεξεργασίας εικόνας. Αυτή τη στιγμή, η επίσημη εργασία Edits υποστηρίζει μόνο δύο μοντέλα: `dall-e-2`, `gpt-image-1`.

## Ασύγχρονη Επιστροφή

Δεδομένου ότι η επεξεργασία εικόνας μέσω του OpenAI Images Edits API μπορεί να διαρκέσει αρκετά, εάν το API δεν απαντά για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος. Έτσι, αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη επιστροφή.

Η συνολική διαδικασία είναι: όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`. Μετά την υποβολή του API αίτηματος, το API θα επιστρέψει αμέσως ένα αποτέλεσμα που περιλαμβάνει ένα πεδίο `task_id`, το οποίο αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα της επεξεργασίας εικόνας θα αποσταλεί μέσω POST JSON στη διεύθυνση `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί με το ID.

Ας δούμε πώς να το κάνουμε με ένα παράδειγμα.

Πρώτα, η επιστροφή Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα, οι προγραμματιστές θα πρέπει να την αντικαταστήσουν με το URL του HTTP διακομιστή που έχουν δημιουργήσει. Για ευκολία, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να αποκτήσετε ένα Webhook URL, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/cjjfly.png)

Αντιγράψτε αυτό το URL και μπορείτε να το χρησιμοποιήσετε ως Webhook, το παρακάτω παράδειγμα είναι `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`.

Στη συνέχεια, μπορούμε να ρυθμίσουμε το πεδίο `callback_url` στο παραπάνω Webhook URL, συμπληρώνοντας τα αντίστοιχα παραμέτρους, όπως φαίνεται στον παρακάτω κώδικα:

```shell
curl -X POST "https://api.acedata.cloud/v1/images/edits" \
  -H "Authorization: Bearer {token}" \
  -F "model=gpt-image-1" \
  -F "image[]=@test.png" \
  -F "prompt=Create a lovely gift basket with these items in it" \
  -F "callback_url=https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab"
```

Μετά την κλήση, μπορείτε να παρατηρήσετε ότι θα λάβετε αμέσως ένα αποτέλεσμα, όπως παρακάτω:

```json
{
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c"
}
```

Μετά από λίγο, μπορείτε να παρατηρήσετε το αποτέλεσμα της επεξεργασίας εικόνας στη διεύθυνση Webhook, το περιεχόμενο είναι το εξής:

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": {
    "created": 1721626477,
    "data": [
      {
        "b64_json": "iVBORw0KGgo..."
      }
    ]
  }
}
```

Μπορείτε να δείτε ότι το αποτέλεσμα περιλαμβάνει ένα πεδίο `task_id`, το πεδίο `data` περιέχει το ίδιο αποτέλεσμα επεξεργασίας εικόνας όπως και στην συγχρονισμένη κλήση, μέσω του πεδίου `task_id` μπορείτε να συσχετίσετε την εργασία.

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
