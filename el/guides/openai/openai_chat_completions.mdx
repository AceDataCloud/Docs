Το OpenAI ChatGPT είναι ένα πολύ ισχυρό σύστημα διαλόγου AI. Αρκεί να εισαγάγετε προτροπές και μπορεί να δημιουργήσει ομαλές και φυσικές απαντήσεις μέσα σε λίγα δευτερόλεπτα. Το ChatGPT ξεχωρίζει στον κλάδο χάρη στις εξαιρετικές του δυνατότητες κατανόησης και δημιουργίας γλώσσας. Σήμερα, το ChatGPT χρησιμοποιείται ήδη ευρέως σε διάφορους κλάδους και τομείς, με την επιρροή του να γίνεται όλο και πιο σημαντική. Είτε πρόκειται για καθημερινές συνομιλίες, δημιουργική γραφή, επαγγελματικές συμβουλές ή προγραμματισμό κώδικα, το ChatGPT μπορεί να παρέχει εκπληκτική έξυπνη υποστήριξη, βελτιώνοντας σημαντικά την αποδοτικότητα εργασίας και τη δημιουργικότητα των ανθρώπων.

Το παρόν έγγραφο παρουσιάζει κυρίως τη διαδικασία χρήσης του OpenAI Chat Completion API. Με τη χρήση του, μπορούμε εύκολα να χρησιμοποιήσουμε τη λειτουργία διαλόγου του επίσημου OpenAI ChatGPT.

## GPT-6.1 Sol

Χρησιμοποιήστε `model: "gpt-6.1-sol"` για να επιλέξετε αυτό το μοντέλο. Υποστηρίζει ροή εξόδου, κλήσεις συναρτήσεων, δομημένη έξοδο και εισαγωγή εικόνων. Κατά την πρώτη εβδομάδα διάθεσης, είναι διαθέσιμο μόνο σε επαληθευμένους κατόχους ACE T1+ (τουλάχιστον 100.000 ACE) ή εξουσιοδοτημένους χρήστες· ο συγκεκριμένος χρόνος διάθεσης εξαρτάται από την ένδειξη πρόσβασης στην κονσόλα.

Τα επίπεδα συλλογισμού υποστηρίζουν `low`, `medium`, `high`, `xhigh` και `max`, ενώ προς το παρόν δεν υποστηρίζονται τα `none` ή `minimal`. Συνιστάται να ξεκινήσετε με `reasoning_effort: "low"`. Όταν η είσοδος υπερβαίνει τα 272.000 tokens, εφαρμόζεται τιμολόγηση μεγάλου πλαισίου για ολόκληρο το αίτημα και η χρέωση εξαρτάται από την τρέχουσα τιμή στην κονσόλα.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το OpenAI Chat Completion API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να λάβετε το API Token σας και κρατήστε το ως εφεδρικό.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης, όπου θα σας προσκληθεί να εγγραφείτε και να συνδεθείτε. Μετά την ολοκλήρωση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση παρέχει δωρεάν πίστωση για δωρεάν δοκιμή· όταν η πίστωση δεν επαρκεί, μπορείτε να επαναφορτίσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

## Βασική χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε το αντίστοιχο περιεχόμενο στη διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

Κατά την πρώτη χρήση αυτής της διεπαφής, χρειάζεται να συμπληρώσουμε τουλάχιστον τρία στοιχεία. Το ένα είναι το `authorization`, το οποίο μπορεί να επιλεγεί απευθείας από την αναπτυσσόμενη λίστα. Η άλλη παράμετρος είναι το `model`, το `model` είναι η κατηγορία μοντέλου του επίσημου ιστότοπου OpenAI ChatGPT που επιλέγουμε να χρησιμοποιήσουμε. Εδώ διαθέτουμε κυρίως 20 μοντέλα και μπορείτε να δείτε λεπτομέρειες στα μοντέλα που παρέχουμε. Η τελευταία παράμετρος είναι το `messages`, το `messages` είναι ο πίνακας των ερωτημάτων που εισάγουμε. Είναι ένας πίνακας, που υποδεικνύει ότι μπορούν να μεταφορτωθούν ταυτόχρονα πολλαπλά ερωτήματα. Κάθε ερώτημα περιλαμβάνει τα `role` και `content`, όπου το `role` υποδηλώνει τον ρόλο του ερωτώντος. Παρέχουμε τρεις ταυτότητες, συγκεκριμένα τις `user`, `assistant`, `system`. Το άλλο, το `content`, είναι το συγκεκριμένο περιεχόμενο της ερώτησής μας.

Ταυτόχρονα, μπορείτε να παρατηρήσετε ότι στη δεξιά πλευρά δημιουργείται ο αντίστοιχος κώδικας κλήσης. Μπορείτε να αντιγράψετε τον κώδικα και να τον εκτελέσετε απευθείας ή να κάνετε απευθείας κλικ στο κουμπί «Try» για δοκιμή.

Συνήθεις προαιρετικές παράμετροι:

- `max_tokens`: Περιορίζει τον μέγιστο αριθμό token σε μία απάντηση.
- `temperature`: Τυχαιότητα δημιουργίας, μεταξύ 0-2· όσο μεγαλύτερη είναι η τιμή, τόσο πιο αποκλίνουσα είναι.
- `n`: Πόσες υποψήφιες απαντήσεις δημιουργούνται κάθε φορά.
- `response_format`: Ρύθμιση μορφής επιστροφής.

<p><img src="https://cdn.acedata.cloud/mthuu2.png" width="400" className="m-auto" /></p>

Το επιστρεφόμενο αποτέλεσμα περιλαμβάνει πολλά πεδία, τα οποία παρουσιάζονται ως εξής:

- `model `, το επιλεγμένο μοντέλο του επίσημου ιστότοπου OpenAI ChatGPT.
- `choices`, οι πληροφορίες απάντησης που παρέχει το ChatGPT για το ερώτημα.
- `usage `: Στατιστικές πληροφορίες token για αυτήν την ερώτηση και απάντηση.

Μεταξύ αυτών, το `choices` περιλαμβάνει τις πληροφορίες απάντησης του ChatGPT, και το `choices` μέσα σε αυτό είναι το ChatGPT, όπως φαίνεται στην εικόνα.

## Απόκριση ροής

Αυτή η διεπαφή υποστηρίζει επίσης απόκριση ροής, κάτι που είναι πολύ χρήσιμο για διασύνδεση με ιστοσελίδες και επιτρέπει την υλοποίηση εφέ εμφάνισης χαρακτήρα προς χαρακτήρα σε ιστοσελίδες.

Εάν θέλετε να επιστρέψετε την απόκριση ως ροή, μπορείτε να αλλάξετε την παράμετρο `stream ` στην κεφαλίδα του αιτήματος σε `true`.

Η τροποποίηση φαίνεται στην εικόνα, αλλά ο κώδικας κλήσης χρειάζεται αντίστοιχες αλλαγές για να υποστηρίζει απόκριση ροής.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

Αφού τροποποιήσετε το `stream` σε `true`, το API θα επιστρέφει τα αντίστοιχα δεδομένα JSON γραμμή προς γραμμή. Σε επίπεδο κώδικα, χρειάζεται να κάνουμε τις αντίστοιχες τροποποιήσεις για να λάβουμε τα αποτελέσματα γραμμή προς γραμμή.

Δείγμα κώδικα κλήσης Python:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Υποστηρίζεται επίσης η JavaScript, για παράδειγμα, ο κώδικας ροϊκής κλήσης για Node.js είναι ο εξής:

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4",
    messages: [{ role: "user", content: "hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

Δείγμα κώδικα Java:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "gpt-4");
jsonObject.put("messages", [{"role":"user","content":"hello"}]);
jsonObject.put("stream", true);
MediaType mediaType = "application/json; charset=utf-8".toMediaType();
RequestBody body = jsonObject.toString().toRequestBody(mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/openai/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.print(response.body!!.string())
```

Άλλες γλώσσες μπορούν επίσης να προσαρμοστούν ξεχωριστά, η αρχή είναι η ίδια.

## Συνομιλία πολλαπλών γύρων

Αν θέλετε να ενσωματώσετε λειτουργία συνομιλίας πολλαπλών γύρων, πρέπει να ανεβάσετε πολλαπλές λέξεις ερώτησης στο πεδίο `messages`. Το συγκεκριμένο παράδειγμα πολλαπλών λέξεων ερώτησης εμφανίζεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/oz4mar.png" width="400" className="m-auto" /></p>

Κώδικας δείγματος κλήσης Python:
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"Hello"},{"role":"assistant","content":"Hi! How can I assist you today?"},{"role":"user","content":"What I say just now?"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Με την υποβολή πολλαπλών ερωτήσεων, μπορείτε εύκολα να υλοποιήσετε συνομιλίες πολλαπλών γύρων και να λάβετε την ακόλουθη απάντηση:

```json
{
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "You said, \"Hello.\""
      },
      "finish_reason": "stop"
    }
  ],
  "created": 1721323012,
  "id": "chatcmpl-NWZmOTA5MDlkZjBjNDRjNGEwMzRjYzA5NmM1MzQwMWY",
  "model": "gpt-4",
  "object": "chat.completion.chunk",
  "recipient": "all",
  "usage": {
    "prompt_tokens": 31,
    "completion_tokens": 6,
```

Μπορείτε να δείτε ότι οι πληροφορίες που περιλαμβάνονται στο `choices` είναι συνεπείς με το περιεχόμενο της βασικής χρήσης. Αυτό περιλαμβάνει το συγκεκριμένο περιεχόμενο της απάντησης του ChatGPT σε πολλαπλές συνομιλίες, ώστε να μπορούν να απαντηθούν οι αντίστοιχες ερωτήσεις με βάση το περιεχόμενο πολλαπλών συνομιλιών.

## Ενσωμάτωση με OpenAI-Python

Το OpenAI Chat Completion API παραμένει συμβατό με την επίσημη διεπαφή OpenAI και μπορεί να ενσωματωθεί απευθείας χρησιμοποιώντας το επίσημο SDK [OpenAI-Python](https://github.com/openai/openai-python). Αυτό το άρθρο θα παρουσιάσει συνοπτικά τον τρόπο χρήσης του.

1. Αρχικά, χρειάζεται να ρυθμίσετε ένα τοπικό περιβάλλον `Python`. Μπορείτε να αναζητήσετε αυτή τη διαδικασία στο Google.
2. Κατεβάστε και εγκαταστήστε ένα περιβάλλον ανάπτυξης, για παράδειγμα τον επεξεργαστή VSCode.
3. Ρυθμίστε τις μεταβλητές περιβάλλοντος `OpenAI`.

- Στον φάκελο του έργου, δημιουργήστε ένα αρχείο με όνομα `.env` και αποθηκεύστε το
- Περιεχόμενο του αρχείου `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # 再次提醒：如果你使用官网OpenAI的key，不要用这个地址。
```

Αντικαταστήστε το `sk-xxx` με το δικό σας key. Το `OPENAI_BASE_URL` είναι η διαμεσολαβητική διεπαφή για πρόσβαση στο OpenAI.

4. Εγκαταστήστε τα πακέτα από τα οποία εξαρτάται το έργο

```shell
pip install openai
```

Στο Mac OS η εντολή είναι:

```shell
pip3 install openai
```

5. Δημιουργήστε ένα αρχείο πηγαίου κώδικα παραδείγματος

Ας υποθέσουμε ότι δημιουργήσαμε έναν κώδικα παραδείγματος `index.py`, με το συγκεκριμένο περιεχόμενο ως εξής:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Μοντέλο όρασης

Το gpt-4o είναι ένα πολυτροπικό μεγάλο γλωσσικό μοντέλο που αναπτύχθηκε από το OpenAI. Προσθέτει δυνατότητες οπτικής κατανόησης πάνω στη βάση του GPT-4. Αυτό το μοντέλο μπορεί να επεξεργάζεται ταυτόχρονα εισόδους κειμένου και εικόνας, επιτυγχάνοντας διατροπική κατανόηση και δημιουργία.

Η επεξεργασία κειμένου με το μοντέλο gpt-4o είναι συνεπής με το περιεχόμενο βασικής χρήσης που αναφέρθηκε παραπάνω. Παρακάτω θα παρουσιαστεί συνοπτικά ο τρόπος χρήσης των δυνατοτήτων επεξεργασίας εικόνας του μοντέλου.

Η χρήση των δυνατοτήτων επεξεργασίας εικόνας του μοντέλου gpt-4o γίνεται κυρίως με την προσθήκη ενός πεδίου `type` στο αρχικό περιεχόμενο `content`. Μέσω αυτού του πεδίου μπορεί να προσδιοριστεί αν έχει υποβληθεί κείμενο ή εικόνα, ώστε να χρησιμοποιηθούν οι δυνατότητες επεξεργασίας εικόνας του μοντέλου gpt-4o. Παρακάτω περιγράφονται κυρίως δύο τρόποι κλήσης αυτής της λειτουργίας, με Curl και Python.

- Μέθοδος σεναρίου Curl

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

- Μέθοδος σεναρίου Python
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
                    }
                },
            ],
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Εκτός από το gpt-4o, υπάρχει επίσης ένα μοντέλο χαμηλότερου κόστους, που ονομάζεται gpt-4o-mini. Το gpt-4o-mini είναι η νεότερη γενιά μεγάλου γλωσσικού μοντέλου που αναπτύχθηκε από την OpenAI. ## Χειρισμός σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
