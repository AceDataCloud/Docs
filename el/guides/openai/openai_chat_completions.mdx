OpenAI ChatGPT είναι ένα πολύ ισχυρό σύστημα AI συνομιλίας, το οποίο μπορεί να παράγει ομαλές και φυσικές απαντήσεις σε λίγα δευτερόλεπτα απλά εισάγοντας λέξεις-κλειδιά. Το ChatGPT ξεχωρίζει στη βιομηχανία για την εξαιρετική του ικανότητα κατανόησης και παραγωγής γλώσσας, και σήμερα έχει ευρεία εφαρμογή σε διάφορους τομείς και βιομηχανίες, με την επιρροή του να γίνεται ολοένα και πιο σημαντική. Είτε πρόκειται για καθημερινές συνομιλίες, δημιουργική συγγραφή, είτε για επαγγελματική συμβουλευτική και προγραμματισμό κώδικα, το ChatGPT μπορεί να προσφέρει εκπληκτική έξυπνη βοήθεια, αυξάνοντας σημαντικά την παραγωγικότητα και τη δημιουργικότητα των ανθρώπων.

Αυτό το έγγραφο περιγράφει κυρίως τη διαδικασία χρήσης του OpenAI Chat Completion API, επιτρέποντάς μας να χρησιμοποιήσουμε εύκολα τη λειτουργία συνομιλίας του επίσημου OpenAI ChatGPT.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το OpenAI Chat Completion API, μπορείτε πρώτα να επισκεφθείτε τη σελίδα [OpenAI Chat Completion API](https://platform.acedata.cloud/documents/1bcf3bba-102b-495d-9bba-47cd96717e45) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να σας προσκαλέσουν να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" class="m-auto"></p>

Κατά την πρώτη χρήση αυτού του API, πρέπει τουλάχιστον να συμπληρώσουμε τρία περιεχόμενα, το ένα είναι το `authorization`, το οποίο μπορείτε να επιλέξετε απευθείας από τη λίστα. Ένα άλλο παράμετρο είναι το `model`, το οποίο είναι η κατηγορία μοντέλου που επιλέγουμε να χρησιμοποιήσουμε από την επίσημη ιστοσελίδα του OpenAI ChatGPT. Εδώ έχουμε κυρίως 20 μοντέλα, για λεπτομέρειες μπορείτε να δείτε τα μοντέλα που παρέχουμε. Η τελευταία παράμετρος είναι το `messages`, το οποίο είναι ο πίνακας των ερωτήσεων που εισάγουμε, και είναι ένας πίνακας που επιτρέπει την ταυτόχρονη αποστολή πολλών ερωτήσεων, κάθε ερώτηση περιλαμβάνει το `role` και το `content`, όπου το `role` δηλώνει τον ρόλο του ερωτώντος, και παρέχουμε τρεις ταυτότητες: `user`, `assistant`, `system`. Το άλλο `content` είναι το συγκεκριμένο περιεχόμενο της ερώτησής μας.

Μπορείτε επίσης να παρατηρήσετε ότι στα δεξιά υπάρχει ο αντίστοιχος κώδικας κλήσης που μπορείτε να αντιγράψετε και να εκτελέσετε απευθείας, ή μπορείτε να κάνετε κλικ στο κουμπί «Try» για να δοκιμάσετε.

Συνηθισμένες προαιρετικές παράμετροι:

- `max_tokens`: περιορίζει τον μέγιστο αριθμό tokens για μία απάντηση.
- `temperature`: δημιουργεί τυχαιότητα, από 0-2, όσο μεγαλύτερη είναι η τιμή, τόσο πιο διασκορπισμένες είναι οι απαντήσεις.
- `n`: πόσες υποψήφιες απαντήσεις θα παραχθούν ταυτόχρονα.
- `response_format`: ρύθμιση μορφής επιστροφής.

- `choices`, οι πληροφορίες απάντησης που παρέχει το ChatGPT για τις ερωτήσεις.
- `usage`: στατιστικά στοιχεία σχετικά με τα tokens για αυτή την ερώτηση-απάντηση.

## Ροή Αντίκτυπου

Αυτή η διεπαφή υποστηρίζει επίσης ροή αντίκτυπου, κάτι που είναι πολύ χρήσιμο για την ενσωμάτωσή της σε ιστοσελίδες, καθώς επιτρέπει την εμφάνιση των αποτελεσμάτων λέξη προς λέξη.

Εάν θέλετε να επιστρέψετε την απάντηση με ροή, μπορείτε να αλλάξετε την παράμετρο `stream` στην κεφαλίδα του αιτήματος σε `true`.

Η αλλαγή φαίνεται στην εικόνα, αλλά ο κώδικας κλήσης χρειάζεται να έχει τις αντίστοιχες αλλαγές για να υποστηρίξει τη ροή.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" class="m-auto"></p>

Αφού αλλάξετε το `stream` σε `true`, το API θα επιστρέφει γραμμή προς γραμμή τα αντίστοιχα δεδομένα JSON, και σε επίπεδο κώδικα θα χρειαστεί να κάνουμε τις κατάλληλες αλλαγές για να αποκτήσουμε τα αποτελέσματα γραμμή προς γραμμή.

Παράδειγμα κώδικα κλήσης σε Python:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```javascript

  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

```java

```

## Διασύνδεση OpenAI-Python

Η υπηρεσία OpenAI Chat Completion API είναι ανώτερη της επίσημης υπηρεσίας OpenAI, μπορείς να δεις περισσότερα στην επίσημη [OpenAI-Python](https://github.com/openai/openai-python), σε αυτό το άρθρο θα παρουσιαστεί συνοπτικά πώς να χρησιμοποιήσεις την υπηρεσία που παρέχεται από την επίσημη πηγή.

1. Πρώτα πρέπει να στήσεις το τοπικό περιβάλλον `Python`, αυτή η διαδικασία μπορείς να την αναζητήσεις στο Google.
2. Κατέβασε και εγκατέστησε το αναπτυξιακό περιβάλλον, όπως το VSCode.
3. Ρύθμισε τις μεταβλητές περιβάλλοντος `OpenAI`.

- Στον φάκελο του έργου, δημιούργησε ένα αρχείο με όνομα `.env` και αποθήκευσέ το.
- Περιεχόμενο του αρχείου `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # Υπενθυμίζω: αν χρησιμοποιείς το κλειδί της επίσημης OpenAI, μην χρησιμοποιήσεις αυτή τη διεύθυνση.
```

Αντικατέστησε το `sk-xxx` με το δικό σου κλειδί. Το `OPENAI_BASE_URL` είναι η διεπαφή proxy για την πρόσβαση στο OpenAI.

4. Εγκατέστησε τα πακέτα εξάρτησης του έργου

```shell
pip install openai
```

Στο Mac OS η εντολή είναι:

```shell
pip3 install openai
```

5. Δημιούργησε ένα αρχείο παραδείγματος πηγαίου κώδικα

Ας υποθέσουμε ότι δημιουργήσαμε ένα αρχείο παραδείγματος `index.py`, το περιεχόμενο είναι το εξής:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "γεια",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

Μπορείς να δεις ότι οι πληροφορίες απάντησης μέσα στο `choices` προέρχονται από διαδικτυακή αναζήτηση και παρέχουν επίσης σχετικούς συνδέσμους, οι πληροφορίες απάντησης μέσα στο `choices` πρέπει να αποδοθούν μέσω της σύνταξης `markdown` για να αποκτήσεις την καλύτερη εμπειρία, και αυτό τελικά αναδεικνύει τη μεγάλη δύναμη της διαδικτυακής λειτουργίας του μοντέλου μας.

## Οπτικό μοντέλο

Το gpt-4o είναι ένα πολυδιάστατο μεγάλο γλωσσικό μοντέλο που αναπτύχθηκε από την OpenAI, το οποίο προσθέτει ικανότητες οπτικής κατανόησης πάνω στη βάση του GPT-4. Αυτό το μοντέλο μπορεί να επεξεργάζεται ταυτόχρονα κείμενα και εικόνες, επιτυγχάνοντας διασυνοριακή κατανόηση και παραγωγή.

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "Τι υπάρχει σε αυτή την εικόνα;"

                {

                    }

            ],
        }
    ]

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση σφαλμάτων

Κατά την κλήση της API, εάν προκύψουν σφάλματα, η API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
