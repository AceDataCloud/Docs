---

Το `POST https://api.acedata.cloud/qwen-image/images` ολοκληρώνει τη δημιουργία εικόνας από κείμενο και την επεξεργασία με 1–3 εικόνες αναφοράς μέσω της ίδιας διεπαφής, υποστηρίζοντας τα `qwen-image-3.0` και `qwen-image-3.0-pro`.

## Επιλογή μοντέλου

| Μοντέλο                   | Κατάλληλα σενάρια       | Επίσημη τυπική τιμή                   |
| -------------------- | ---------- | ----------------------- |
| `qwen-image-3.0`     | Μαζική δημιουργία, γρήγορες επαναλήψεις  | Έξοδος $0.030/εικόνα             |
| `qwen-image-3.0-pro` | Σύνθετη διάταξη, παραγωγή υψηλής ακρίβειας | 1K $0.040/εικόνα· 2K $0.075/εικόνα |

Οι εικόνες αναφοράς χρεώνονται με βάση τον πραγματικό αριθμό εισόδων, με επίσημη τυπική τιμή $0.003/εικόνα.

## Σύγχρονη δημιουργία

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "A simple red circle centered on a clean white background.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

Η επιτυχής απόκριση περιλαμβάνει μόνιμη διεύθυνση εικόνας CDN, πραγματικό usage και το κόστος αυτής της φοράς:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Επεξεργασία εικόνας αναφοράς

Προσθέστε το `image_urls`, υποστηρίζοντας 1–3 δημόσια προσβάσιμες εικόνες:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "保留主体，将背景改成暖色电影海报风格",
  "image_urls": ["https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

Το `prompt_extend_mode=agent` χρησιμοποιείται μόνο για δημιουργία εικόνας από κείμενο. Το εύρος του `n` είναι 1–6· ο λόγος διαστάσεων πρέπει να βρίσκεται μεταξύ 1:8 και 8:1.

## Ασύγχρονες εργασίες

Αφού οριστεί το `async: true`, η διεπαφή επιστρέφει αμέσως το `task_id`. Χρησιμοποιήστε το `/qwen-image/tasks` για να ελέγξετε την τελική κατάσταση ή εισαγάγετε `callback_url` για να λάβετε ειδοποίηση ολοκλήρωσης. Η δημιουργία χρεώνεται μόνο μία φορά και τα ερωτήματα εργασιών δεν χρεώνονται επανειλημμένα.
