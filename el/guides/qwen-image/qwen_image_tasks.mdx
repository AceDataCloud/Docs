`POST https://api.acedata.cloud/qwen-image/tasks` χρησιμοποιείται για την αναζήτηση, μαζική αναζήτηση ή διαγραφή ασύγχρονων εργασιών Qwen Image. Αυτή η διεπαφή δεν παράγει επιπλέον κατανάλωση API.

## Αναζήτηση μεμονωμένης εργασίας

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Αφού ολοκληρωθεί η εργασία, το `response.data` περιέχει τη μόνιμη διεύθυνση CDN εικόνας, το `response.usage` περιέχει τον πραγματικό αριθμό εισόδων/εξόδων, και το `response.cost` είναι οι πληροφορίες χρέωσης της δημιουργίας της εργασίας.

## Μαζική αναζήτηση

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Επιστρέφει `{ "items": [...], "count": 2 }`. Η αναζήτηση λίστας υποστηρίζει επίσης φιλτράρισμα κατά χρήστη, εφαρμογή και χρονικό εύρος δημιουργίας.

## Διαγραφή καταγραφών εργασίας

```json
{"action":"delete","id":"TASK_ID"}
```

Η διαγραφή επηρεάζει μόνο την ιστορικότητα των εργασιών και δεν θα διαγράψει τα ήδη παραγόμενα αρχεία CDN.
