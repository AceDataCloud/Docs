title: "Οδηγίες ενσωμάτωσης API μεταφόρτωσης ήχου αναφοράς Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Το Producer μας επιτρέπει να μεταφορτώνουμε ήχο αναφοράς για δευτερογενή δημιουργία· αυτό το έγγραφο εξηγεί τη μέθοδο ενσωμάτωσης του σχετικού API.

Αυτό το API έχει μόνο μία παράμετρο εισόδου, την `audio_url`, η οποία είναι μια δημόσια προσβάσιμη διεύθυνση CDN και υποστηρίζει την κατάληξη mp3.

Η `audio_url` που εισάγουμε εδώ είναι η `https://cdn.acedata.cloud/suno_demo.mp3`, η οποία είναι μια δημόσια προσβάσιμη διεύθυνση CDN.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Το αποτέλεσμα είναι το εξής:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Soft female vocals, bright and cheerful]\n\n[Verse 1]\n阳光洒在海边\n浪花笑得灿烂\n你和我在沙滩\n钟表停止转\n冰淇淋在融化\n手牵手去散步\n风儿轻轻吹过\n心跳不停跳\n\n[Chorus]\n夏天夏天\n时间停在这一天\n笑声回荡\n蔚蓝天空在身旁",
    "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
  }
}
```

Όπως φαίνεται, το πεδίο `audio_id` του `data` είναι το ID του τραγουδιού μετά τη μεταφόρτωση.

Αφού έχουμε το ID του τραγουδιού, μπορούμε να χρησιμοποιήσουμε το [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration) για προσαρμοσμένη δημιουργία τραγουδιών. Για παράδειγμα, αν περάσουμε το `upload_extend` στο `action` και ταυτόχρονα περάσουμε το επιστρεφόμενο ID του τραγουδιού στο `audio_id`, μπορούμε να δημιουργήσουμε νέο τραγούδι βάσει του ήχου αναφοράς.
