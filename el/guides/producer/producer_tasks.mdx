Η κύρια λειτουργία του Producer Tasks API είναι η αναζήτηση της κατάστασης εκτέλεσης μιας εργασίας εισάγοντας το ID εργασίας που δημιουργήθηκε από το Producer Audios Generation API.

Αυτό το έγγραφο θα παρουσιάσει λεπτομερώς τις οδηγίες ενσωμάτωσης του Producer Tasks API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τις ισχυρές δυνατότητες αυτού του API. Μέσω του Producer Tasks API, μπορείτε εύκολα να υλοποιήσετε την αναζήτηση της κατάστασης εκτέλεσης εργασιών του Producer Audios Generation API.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Producer Audios Generation API, μεταβείτε πρώτα στην [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση προσφέρει δωρεάν πίστωση για δωρεάν δοκιμή· όταν η πίστωση δεν επαρκεί, μπορείτε να φορτίσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Producer Audios Generation API →](https://platform.acedata.cloud/documents/producer-audios)

## Παράδειγμα αιτήματος

Το Producer Tasks API μπορεί να χρησιμοποιηθεί για την αναζήτηση των αποτελεσμάτων του Producer Audios Generation API. Για το πώς να χρησιμοποιήσετε το Producer Audios Generation API, ανατρέξτε στην τεκμηρίωση [Producer Audios Generation API ](https://platform.acedata.cloud/documents/producer-audios-integration)。

Θα χρησιμοποιήσουμε ως παράδειγμα ένα ID εργασίας που επιστράφηκε από την υπηρεσία Producer Audios Generation API, για να δείξουμε πώς να χρησιμοποιήσετε αυτό το API. Ας υποθέσουμε ότι έχουμε ένα ID εργασίας: 1a6ac2ad-10f2-4e2b-b500-66ec27fe82ad, στη συνέχεια θα δείξουμε πώς να περάσετε ένα ID εργασίας.

### Ρύθμιση κεφαλίδων αιτήματος και σώματος αιτήματος

Τα **Request Headers** περιλαμβάνουν:

- `accept`: Καθορίζει ότι λαμβάνονται αποτελέσματα απόκρισης σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: Το κλειδί για την κλήση του API, το οποίο μπορεί να επιλεγεί απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Το **Request Body** περιλαμβάνει:

- `id`: Το ID της μεταφορτωμένης εργασίας.
- `action`: Ο τρόπος λειτουργίας στην εργασία.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/producer/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "1a6ac2ad-10f2-4e2b-b500-66ec27fe82ad",
  "action": "retrieve"
}'
```

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και τις πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

## Συμπέρασμα

Μέσω αυτού του εγγράφου, έχετε ήδη κατανοήσει πώς να χρησιμοποιείτε το Producer Tasks API για την αναζήτηση όλων των συγκεκριμένων λεπτομερών πληροφοριών μιας μεμονωμένης ή μαζικής εργασίας. Ελπίζουμε ότι αυτό το έγγραφο θα σας βοηθήσει να ενσωματώσετε και να χρησιμοποιήσετε καλύτερα αυτό το API. Εάν έχετε οποιεσδήποτε ερωτήσεις, επικοινωνήστε ανά πάσα στιγμή με την ομάδα τεχνικής υποστήριξής μας.
