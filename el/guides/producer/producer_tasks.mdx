Η κύρια λειτουργία του Producer Tasks API είναι να επιτρέπει την αναζήτηση της εκτέλεσης ενός έργου μέσω του ID έργου που έχει παραχθεί από το Producer Audios Generation API.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες διασύνδεσης του Producer Tasks API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του Producer Tasks API, μπορείτε εύκολα να ελέγξετε την κατάσταση εκτέλεσης των έργων του Producer Audios Generation API.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Producer Tasks API, πρέπει πρώτα να επισκεφθείτε τη σελίδα αίτησης [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios) για να ζητήσετε την αντίστοιχη υπηρεσία, και στη συνέχεια να αντιγράψετε το ID έργου του Producer Audios Generation API, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Τέλος, επισκεφθείτε τη σελίδα Tasks API [Producer Tasks API](https://platform.acedata.cloud/documents/622626b1-30a7-4799-a772-4946e1df3ac0) για να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![Σελίδα Αίτησης](https://cdn.acedata.cloud/rci31i.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη [σελίδα σύνδεσης](https://platform.acedata.cloud) για να σας προσκαλέσει να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Παράδειγμα Αίτησης

Το Producer Tasks API μπορεί να χρησιμοποιηθεί για να ελέγξει τα αποτελέσματα του Producer Audios Generation API. Για πληροφορίες σχετικά με το πώς να χρησιμοποιήσετε το Producer Audios Generation API, ανατρέξτε στο έγγραφο [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration).

Θα χρησιμοποιήσουμε ένα παράδειγμα με το ID έργου που επιστρέφεται από την υπηρεσία Producer Audios Generation API. Ας υποθέσουμε ότι έχουμε ένα ID έργου: 1a6ac2ad-10f2-4e2b-b500-66ec27fe82ad, και στη συνέχεια θα δείξουμε πώς να το χρησιμοποιήσουμε περνώντας ένα ID έργου.

### Ρύθμιση Κεφαλίδων Αίτησης και Σώματος Αίτησης

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί API που θα χρησιμοποιηθεί, μπορείτε να το επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `id`: το ID του έργου που έχει ανέβει.
- `action`: ο τρόπος λειτουργίας του έργου.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/producer/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "1a6ac2ad-10f2-4e2b-b500-66ec27fe82ad",
  "action": "retrieve"
}'
```

## Διαχείριση σφαλμάτων

Κατά την κλήση της API, αν προκύψει σφάλμα, η API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
