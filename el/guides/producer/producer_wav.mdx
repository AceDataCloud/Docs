---
title: "Οδηγίες ενσωμάτωσης API λήψης WAV του Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Το Producer μας επιτρέπει να κατεβάζουμε αρχεία WAV που σχετίζονται με τραγούδια. Αυτό το έγγραφο εξηγεί τη μέθοδο ενσωμάτωσης του σχετικού API.

Αυτό το API έχει μόνο μία παράμετρο εισόδου, το `audio_id`, το οποίο είναι το μοναδικό ID του τραγουδιού.

Το `audio_id` που εισάγουμε εδώ είναι `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, και είναι ένα ID τραγουδιού που δημιουργήθηκε από το Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/wav' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Το αποτέλεσμα είναι το εξής:

```
{
  "success": true,
  "task_id": "44963173-b6c5-463c-915f-96730d14ec63",
  "trace_id": "f75d6a27-54bc-49fd-a40e-6d4cd0427764",
  "data": [
    {
      "title": "Woke up with the sun in my eyes",
      "file_url": "https://cdn.acedata.cloud/assets/examples/fish/64adc04b-c196-4a0f-9070-222ba101ce6c-fc50de38c165.wav"
    }
  ]
}
```

Όπως φαίνεται, το πεδίο `file_url` του `data` είναι ο σύνδεσμος λήψης του WAV.
