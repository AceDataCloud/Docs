Ο Producer μας επιτρέπει να κατεβάσουμε τα σχετικά WAV αρχεία τραγουδιών, αυτό το έγγραφο εξηγεί τη μέθοδο σύνδεσης με το σχετικό API.

Αυτό το API έχει μόνο μία είσοδο παράμετρο, το `audio_id`, το οποίο είναι το μοναδικό ID του τραγουδιού.

Εδώ εισάγουμε το `audio_id` που είναι `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, είναι ένα ID τραγουδιού που έχει δημιουργηθεί από τον Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/wav' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Το αποτέλεσμα είναι το εξής:

```
{
  "success": true,
  "task_id": "44963173-b6c5-463c-915f-96730d14ec63",
  "trace_id": "f75d6a27-54bc-49fd-a40e-6d4cd0427764",
  "data": [
    {
      "title": "Woke up with the sun in my eyes",
      "file_url": "https://cdn.ttapi.io/other/2025-12-30/a1508051-a6b8-4867-8cbb-32273a99c2ae.wav"
    }
  ]
}
```

Μπορούμε να δούμε ότι το πεδίο `file_url` του `data` είναι ο σύνδεσμος για τη λήψη του WAV.
