Ο Producer μας επιτρέπει να κατεβάσουμε βίντεο που σχετίζονται με τραγούδια, αυτό το έγγραφο εξηγεί τη μέθοδο σύνδεσης με το σχετικό API.

Αυτό το API έχει μόνο μία παράμετρο εισόδου, το `audio_id`, το οποίο είναι το μοναδικό ID του τραγουδιού.

Εδώ εισάγουμε το `audio_id` που είναι `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, το οποίο είναι ένα ID τραγουδιού που έχει δημιουργηθεί από τον Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Το αποτέλεσμα είναι το εξής:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://storage.googleapis.com/corpusant-app-public/song-videos/a54609c6-13e2-4176-be0f-4d7eebc68e1f:5178f294b214798f7d38b810ac289be75306659be24af88900a633efce334012.mp4"
  }
}
```

Μπορούμε να δούμε ότι το πεδίο `video_url` του `data` είναι ο σύνδεσμος για τη λήψη του βίντεο.
