---
title: "Οδηγίες ενσωμάτωσης API λήψης βίντεο Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Το Producer μας επιτρέπει να κατεβάζουμε βίντεο σχετικά με τραγούδια· αυτό το έγγραφο εξηγεί τη μέθοδο ενσωμάτωσης του σχετικού API.

Αυτό το API έχει μόνο μία παράμετρο εισόδου, το `audio_id`, το οποίο είναι το μοναδικό ID του τραγουδιού.

Εδώ, το `audio_id` που εισάγουμε είναι το `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, το οποίο είναι ένα ID τραγουδιού που δημιουργήθηκε από το Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Το αποτέλεσμα είναι το εξής:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4"
  }
}
```

Μπορείτε να δείτε ότι το πεδίο `video_url` του `data` είναι ο σύνδεσμος του βίντεο προς λήψη.
