## 1. Απόκτηση API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), μπείτε στις διαθέσιμες εφαρμογές και αντιγράψτε το API Key.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Εγκατάσταση Codex

```bash
npm install -g @openai/codex
```

## 3. Ρύθμιση API Key

macOS / Linux：

```bash
export ACEDATACLOUD_API_KEY="το API Key σας"
```

Για μακροχρόνια ισχύ, προσθέστε αυτή τη γραμμή στο `~/.zshrc` ή `~/.bashrc`. Windows PowerShell χρησιμοποιεί:

```powershell
setx ACEDATACLOUD_API_KEY "το API Key σας"
```

Μετά τη ρύθμιση, κλείστε και ξανανοίξτε το τερματικό.

## 4. Ρύθμιση AceDataCloud

Επεξεργαστείτε το `~/.codex/config.toml` (για Windows είναι το `%USERPROFILE%\.codex\config.toml`), προσθέστε:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Για Windows αλλάξτε τις τελευταίες δύο γραμμές σε:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Δεν χρειάζεται να συμπληρώσετε το `model`; Αφού ξεκινήσει, μπορείτε να επιλέξετε το μοντέλο στο Codex. Υπάρχουσες ρυθμίσεις μπορούν να διατηρηθούν, μην δημιουργείτε ξανά provider με το ίδιο όνομα.

## 5. Εκκίνηση

```bash
cd /path/to/your/project
codex
```

Μπαίνοντας στο Codex, εκτελέστε το `/model`, επιβεβαιώστε ότι ο Provider είναι `acedatacloud`, και στη συνέχεια επιλέξτε το απαιτούμενο μοντέλο. Οι καταγραφές κλήσεων και το υπόλοιπο μπορούν να προβληθούν στην [ιστορία χρήσης](https://platform.acedata.cloud/console/usages) και στη [λίστα εφαρμογών](https://platform.acedata.cloud/console/applications).

Εάν σας ζητηθεί να λείπει το Key ή επιστρέψει 401, επιβεβαιώστε ότι η μεταβλητή περιβάλλοντος έχει ρυθμιστεί και κλείστε εντελώς το τερματικό και το Codex πριν το ξανανοίξετε.
