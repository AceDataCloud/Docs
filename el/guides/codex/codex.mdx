Οι Codex CLI, Desktop και η επέκταση VS Code μοιράζονται το `~/.codex/config.toml`. Ρυθμίστε μία φορά τον πάροχο `acedatacloud` και μπορείτε να χρησιμοποιήσετε το Codex μέσω του Ace Data Cloud.

| Τρόπος Χρήσης     | Οδηγός Ρύθμισης                                                                                   |
| -------------- | --------------------------------------------------------------------------------------- |
| Terminal / CLI | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)        |
| Desktop        | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)     |
| VS Code        | [Codex for VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)  |
| Γραφική Εναλλαγή | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration) |

Οι κοινές ρυθμίσεις είναι μόνο τρεις:

- Πάροχος: `acedatacloud`
- Βασική Διεύθυνση URL: `https://api.acedata.cloud/v1`
- Κλειδί API: Λάβετε το από τη [λίστα εφαρμογών](https://platform.acedata.cloud/console/applications) και αποθηκεύστε το στο `ACEDATACLOUD_API_KEY`

Δεν χρειάζεται να καθορίσετε σταθερό μοντέλο στις ρυθμίσεις σύνδεσης; Αφού εκκινήσετε το Codex, μπορείτε να επιλέξετε απευθείας το μοντέλο.

Επιστρέψτε στο [Κέντρο Ρύθμισης Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
