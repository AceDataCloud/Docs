Η επέκταση Codex VS Code μοιράζεται το `~/.codex/config.toml` με το Codex CLI.

## 1. Απόκτηση API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), μπείτε στις διαθέσιμες εφαρμογές και αντιγράψτε το API Key.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Εγκατάσταση επέκτασης

Εγκαταστήστε την **Codex – OpenAI's coding agent** από την αγορά επεκτάσεων του VS Code ή εκτελέστε:

```bash
code --install-extension openai.chatgpt
```

## 3. Ρύθμιση API Key

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="το API Key σας"
```

Για μακροχρόνια ισχύ, προσθέστε αυτή τη γραμμή στο `~/.zshrc` ή `~/.bashrc`. Στο Windows PowerShell χρησιμοποιήστε:

```powershell
setx ACEDATACLOUD_API_KEY "το API Key σας"
```

## 4. Ρύθμιση AceDataCloud

Επεξεργαστείτε το `~/.codex/config.toml` (για Windows είναι το `%USERPROFILE%\.codex\config.toml`), προσθέστε:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Για Windows αλλάξτε τις τελευταίες δύο γραμμές σε:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Δεν χρειάζεται να συμπληρώσετε το `model`; μπορείτε να επιλέξετε το μοντέλο από τον πίνακα Codex.

## 5. Επανεκκίνηση και επιβεβαίωση

Κλείστε εντελώς το VS Code και ανοίξτε το ξανά, στη συνέχεια ανοίξτε τον πίνακα Codex. Εκτελέστε `/model`, επιβεβαιώστε ότι ο Provider είναι `acedatacloud`, και στη συνέχεια στείλτε ένα απλό μήνυμα; οι καταγραφές κλήσεων μπορούν να προβληθούν στην [ιστορία χρήσης](https://platform.acedata.cloud/console/usages).

Εάν η επέκταση δεν μπορεί να διαβάσει το Key, ξεκινήστε το VS Code από το τερματικό όπου έχετε ρυθμίσει τις μεταβλητές περιβάλλοντος ή ρυθμίστε τις μεταβλητές περιβάλλοντος σε επίπεδο συστήματος και επανεκκινήστε το VS Code. Το Remote SSH, WSL και το Dev Container χρειάζονται ξεχωριστή ρύθμιση στο περιβάλλον όπου εκτελείται η επέκταση.
