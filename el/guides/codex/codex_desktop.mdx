Το Codex Desktop μοιράζεται το `~/.codex/config.toml` με το Codex CLI.

## 1. Απόκτηση API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), μπείτε στις διαθέσιμες εφαρμογές και αντιγράψτε το API Key.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Ρύθμιση API Key

macOS：

```bash
launchctl setenv ACEDATACLOUD_API_KEY "το API Key σας"
```

Windows PowerShell：

```powershell
setx ACEDATACLOUD_API_KEY "το API Key σας"
```

## 3. Ρύθμιση AceDataCloud

Επεξεργαστείτε το `~/.codex/config.toml` (για Windows είναι το `%USERPROFILE%\.codex\config.toml`), προσθέστε:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Για Windows αλλάξτε τις τελευταίες δύο γραμμές σε:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Δεν χρειάζεται να συμπληρώσετε το `model`; Ανοίξτε το Codex και επιλέξτε απευθείας το μοντέλο.

## 4. Επανεκκίνηση και επιβεβαίωση

Αποσυνδεθείτε εντελώς και επανεκκινήστε το Codex Desktop, δημιουργήστε μια τοπική εργασία και στείλτε ένα απλό μήνυμα. Ο πάροχος θα πρέπει να εμφανίζεται ως `acedatacloud`; οι πραγματικές κλήσεις μπορούν να ελεγχθούν στην [ιστορία χρήσης](https://platform.acedata.cloud/console/usages).

Εάν η ρύθμιση δεν έχει εφαρμοστεί, επιβεβαιώστε ότι έχετε τροποποιήσει το `~/.codex/config.toml` του τρέχοντος χρήστη, ότι η μεταβλητή περιβάλλοντος έχει ρυθμιστεί και στη συνέχεια επανεκκινήστε πλήρως την εφαρμογή. Οι εργασίες στο cloud ή η αυτοματοποίηση που εκτελούνται σε διαφορετικά περιβάλλοντα απαιτούν ξεχωριστή ρύθμιση του Key σε κάθε αντίστοιχο περιβάλλον.
