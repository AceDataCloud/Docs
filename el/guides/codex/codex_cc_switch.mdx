---
title: "Οδηγός Ρύθμισης CC Switch"
description: "Codex API guide - Ace Data Cloud"
---

Το CC Switch μπορεί να διαχειριστεί τους παρόχους και το API Key του Codex μέσω γραφικής διεπαφής.

## 1. Απόκτηση API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), μπείτε στις διαθέσιμες εφαρμογές και αντιγράψτε το API Key.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Εγκατάσταση CC Switch

Κατεβάστε και εγκαταστήστε από [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), ή εκτελέστε στο macOS:

```bash
brew install --cask cc-switch
```

## 3. Προσθήκη παρόχου

1. Ανοίξτε το CC Switch, μεταβείτε στο **Codex**.
2. Κάντε κλικ στο **Add Provider**, επιλέξτε **Custom**.
3. Συμπληρώστε:

| Πεδίο     | Περιεχόμενο                       |
| -------- | ------------------------------ |
| Name     | `acedatacloud`                 |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | Το πρόσφατα αντιγραμμένο Ace Data Cloud API Key   |

Εάν το CC Switch παρέχει επεξεργαστή προσαρμοσμένων ρυθμίσεων, η ρύθμιση θα πρέπει να παραμείνει ως εξής:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"
requires_openai_auth = true
```

Το CC Switch θα αποθηκεύσει το API Key στο `~/.codex/auth.json`:

```json
{
  "OPENAI_API_KEY": "{token}"
}
```

Μην προσθέσετε `env_key` ή `[model_providers.acedatacloud.auth]` στον παραπάνω πάροχο; η χειροκίνητη ρύθμιση και η ρύθμιση του CC Switch είναι εναλλακτικές. Δεν χρειάζεται να ορίσετε σταθερό `model`, μπορείτε να το επιλέξετε απευθείας στο Codex.

## 4. Ενεργοποίηση και επαλήθευση

Ενεργοποιήστε τον πάροχο `acedatacloud`, κλείστε εντελώς και επανεκκινήστε το Codex ή το VS Code. Εκτελέστε το `/model`, επιβεβαιώστε ότι ο Πάροχος είναι `acedatacloud`, στη συνέχεια επιλέξτε το μοντέλο και στείλτε ένα απλό μήνυμα.

Εάν επιστραφεί 401, επιβεβαιώστε ότι είναι ενεργοποιημένος ο `acedatacloud` και ελέγξτε αν το `OPENAI_API_KEY` στο `~/.codex/auth.json` είναι το πρόσφατα αντιγραμμένο Ace Data Cloud API Key. Οι καταγραφές κλήσεων μπορούν να προβληθούν στην [ιστορία χρήσης](https://platform.acedata.cloud/console/usages).
