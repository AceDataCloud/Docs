Η κύρια λειτουργία του Τοπικού Μεταφραστικού API είναι να αποκτάτε το μεταφρασμένο κείμενο μέσω της εισαγωγής του κειμένου που χρειάζεται μετάφραση, ενώ η γλώσσα της μετάφρασης μπορεί να προσαρμοστεί, και τα αποτελέσματα της μετάφρασης μπορούν να παραχθούν σε δύο κύριες μορφές: `json` και `markdown`.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες σύνδεσης του Μεταφραστικού API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του Μεταφραστικού API, μπορείτε εύκολα να μεταφράσετε το εισαγόμενο κείμενο σε συγκεκριμένη γλώσσα και να υποστηρίξετε συγκεκριμένους τρόπους για την παραγωγή των αποτελεσμάτων της μετάφρασης.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Τοπικό Μεταφραστικό API, πρέπει πρώτα να επισκεφθείτε τη σελίδα αίτησης [Τοπικό Μεταφραστικό API](https://platform.acedata.cloud/documents/6dcc60d0-a973-4ad2-92d8-11f4d3775532) για να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Απόκτηση», όπως φαίνεται στην εικόνα:

![Σελίδα Αίτησης](https://cdn.acedata.cloud/rci31i.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη [σελίδα σύνδεσης](https://platform.acedata.cloud) για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Παράδειγμα Αίτησης

Ας πάρουμε ένα παράδειγμα με αγγλικό κείμενο για να δείξουμε πώς να χρησιμοποιήσετε αυτό το API. Ας υποθέσουμε ότι η αγγλική περιγραφή είναι: `# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.`, και στη συνέχεια θα δείξουμε πώς να ανεβάσετε την αγγλική περιγραφή και να αποκτήσετε το μεταφρασμένο αποτέλεσμα στα κινέζικα, ενώ θα το παρουσιάσουμε σε μορφή markdown.

### Ρύθμιση Επικεφαλίδων και Σώματος Αίτησης

**Επικεφαλίδες Αίτησης** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

**Σώμα Αίτησης** περιλαμβάνει:

- `input`: το κείμενο που χρειάζεται μετάφραση.
- `locale`: η γλώσσα της μετάφρασης που προσαρμόζεται.
- `extension`: η μορφή παρουσίασης του αποτελέσματος της μετάφρασης.
- `model`: το μεγάλο μοντέλο που χρησιμοποιείται για τη μετάφραση, προεπιλεγμένο είναι το gpt-3.5.

### Παράδειγμα Κώδικα

Μπορείτε να παρατηρήσετε ότι στη δεξιά πλευρά της σελίδας έχουν παραχθεί αυτόματα διάφορες γλώσσες κώδικα, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/tn5nno.png" width="500" className="m-auto" /></p>

Ορισμένα παραδείγματα κώδικα είναι τα εξής:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/localization/translate' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "input": "# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.",
  "locale": "zh-CN",
  "extension": "md"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/localization/translate"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.",
    "locale": "zh-CN",
    "extension": "md"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Παράδειγμα Απόκρισης

Αφού η αίτηση είναι επιτυχής, το API θα επιστρέψει τις πληροφορίες του αποτελέσματος της μετάφρασης. Για παράδειγμα:

```json
{
  "data": "# 标题 1\n\n这是一个段落。\n\n## 标题 2\n\n这是另一个段落。",
  "usage": {
    "prompt_tokens": 172,
    "completion_tokens": 25
  },
  "model": "gpt-3.5-turbo-16k",
  "locale": "zh-CN"
}
```

Μπορείτε να δείτε ότι το αποτέλεσμα περιλαμβάνει ένα πεδίο `data`, το οποίο περιέχει τη μεταφρασμένη κινεζική έκδοση, ενώ επιστρέφεται σε μορφή markdown. Άλλες πληροφορίες είναι οι εξής:

- `data`, το αποτέλεσμα της μετάφρασης.
- `model`, το μεγάλο γλωσσικό μοντέλο που χρησιμοποιήθηκε για τη μετάφραση.
- `locale`, ο τύπος γλώσσας της μετάφρασης.

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και τις πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
