Η κύρια λειτουργία του Τοπικού Μεταφραστικού API είναι να αποκτάτε το μεταφρασμένο κείμενο μέσω της εισαγωγής του κειμένου που χρειάζεται μετάφραση, ενώ η γλώσσα της μετάφρασης μπορεί να προσαρμοστεί, και τα αποτελέσματα της μετάφρασης μπορούν να παραχθούν σε δύο κύριες μορφές: `json` και `markdown`.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες σύνδεσης του Μεταφραστικού API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του Μεταφραστικού API, μπορείτε εύκολα να μεταφράσετε το εισαγόμενο κείμενο σε συγκεκριμένη γλώσσα και υποστηρίζει συγκεκριμένους τρόπους για την παραγωγή των αποτελεσμάτων της μετάφρασης.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Τοπικό Μεταφραστικό API, πρώτα επισκεφθείτε την [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να ζητήσετε ξεχωριστά για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν; όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό σας υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Τοπικό Μεταφραστικό API →](https://platform.acedata.cloud/documents/localization-translate)

## Παράδειγμα Αίτησης

Ας δούμε ένα παράδειγμα με αγγλικό κείμενο, για να δείξουμε πώς να χρησιμοποιήσετε αυτό το API. Ας υποθέσουμε ότι η αγγλική περιγραφή είναι: `# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.`, και στη συνέχεια θα δείξουμε πώς να ανεβάσετε την αγγλική περιγραφή και να αποκτήσετε το μεταφρασμένο αποτέλεσμα στα κινέζικα, παρουσιάζοντας το σε μορφή markdown.

### Ρύθμιση Κεφαλίδων και Σώματος Αίτησης

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `input`: το περιεχόμενο που χρειάζεται μετάφραση. Όταν `extension=md`, στέλνετε μια συμβολοσειρά, όταν `extension=json`, στέλνετε ένα αντικείμενο JSON.
- `locale`: η γλώσσα της μετάφρασης που προσαρμόζεται.
- `extension`: η μορφή του εισαγόμενου περιεχομένου, μπορεί να είναι `md` ή `json`.
- `model`: το μεγάλο μοντέλο που χρησιμοποιείται για τη μετάφραση, προεπιλογή είναι το gpt-3.5.

| `extension` | Τύπος `input` | Παράδειγμα                                   |
| ----------- | ---------- | ------------------------------------------ |
| `md`        | string     | `"# Title\n\nParagraph"`                   |
| `json`      | object     | `{"title": "Hello", "button": "Submit"}` |

Η `extension` πρέπει να ταιριάζει με τον τύπο του `input`; η συμβολοσειρά δεν μπορεί να χρησιμοποιήσει `json`, και το αντικείμενο JSON δεν μπορεί να χρησιμοποιήσει `md`.

### Παράδειγμα Κώδικα

Μπορείτε να παρατηρήσετε ότι στη δεξιά πλευρά της σελίδας έχουν παραχθεί αυτόματα διάφορες γλώσσες κώδικα, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/tn5nno.png" width="500" className="m-auto" /></p>

Ορισμένα παραδείγματα κώδικα είναι τα εξής:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/localization/translate' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "input": "# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.",
  "locale": "zh-CN",
  "extension": "md"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/localization/translate"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.",
    "locale": "zh-CN",
    "extension": "md"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Παράδειγμα Απόκρισης

Αφού η αίτηση είναι επιτυχής, το API θα επιστρέψει τις πληροφορίες του αποτελέσματος της μετάφρασης. Για παράδειγμα:

```json
{
  "data": "# 标题 1\n\n这是一个段落。\n\n## 标题 2\n\n这是另一个段落。",
  "usage": {
    "prompt_tokens": 172,
    "completion_tokens": 25
  },
  "model": "gpt-3.5-turbo-16k",
  "locale": "zh-CN"
}
```

Μπορείτε να δείτε ότι το αποτέλεσμα περιλαμβάνει ένα πεδίο `data`, το οποίο περιέχει τη μεταφρασμένη κινεζική έκδοση, επιστρέφοντας ταυτόχρονα σε μορφή markdown, ενώ οι άλλες πληροφορίες είναι οι εξής:

- `data`, το αποτέλεσμα της μετάφρασης.
- `model`, το μεγάλο γλωσσικό μοντέλο που χρησιμοποιήθηκε για αυτή τη μετάφραση.
- `locale`, ο τύπος γλώσσας της μετάφρασης για αυτή τη μετάφραση.

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και τις πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
