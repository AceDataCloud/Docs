Αυτό το έγγραφο θα παρουσιάσει μια οδηγία για την αναγνώριση εικόνας Recaptcha2 API, η οποία μπορεί να αναγνωρίσει το περιεχόμενο που εισάγει ο χρήστης και την εικόνα του Recaptcha2 captcha, επιστρέφοντας τελικά τις συντεταγμένες της μικρής εικόνας που πρέπει να κάνετε κλικ για να ολοκληρώσετε την επαλήθευση.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [Recaptcha2 API αναγνώρισης εικόνας](https://platform.acedata.cloud/documents/b9bf7d07-b178-4881-ae45-a852ec40f53e) για να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική χρήση

Αρχικά, ας κατανοήσουμε τη βασική μέθοδο χρήσης. Πρέπει να αποκόψουμε την εικόνα του Recaptcha2 captcha από τον ιστότοπο. Η διεύθυνση URL του παραδείγματος ιστότοπου είναι: `https://www.google.com/recaptcha/api2/demo`, η συγκεκριμένη σελίδα φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/3mgkjk.png" width="500" className="m-auto" /></p>

Πρέπει να κάνουμε κλικ στο πλαίσιο ελέγχου του captcha για να εμφανιστεί η εικόνα captcha. Στην παραπάνω εικόνα, το κίτρινο βέλος δείχνει ένα κομμάτι κειμένου, το οποίο είναι η τιμή του `question` που θα αναφερθεί παρακάτω. Πρέπει πρώτα να περάσουμε ένα πεδίο `image`, το οποίο είναι η συγκεκριμένη εικόνα του Recaptcha2 captcha, αυτή η εικόνα είναι η εικόνα που δείχνει το κόκκινο βέλος στην παραπάνω εικόνα, και πρέπει να κλιμακωθεί σε τυπικό μέγεθος (100x100, 300x300, 450x450), έτσι ώστε η υπηρεσία να μπορεί να προσδιορίσει τον τύπο της εικόνας. Η συμπίεση της εικόνας πρέπει να γίνει από εσάς, και προτείνουμε έναν [ιστότοπο συμπίεσης](https://www.photopea.com/) όπου μπορείτε να συμπιέσετε τις διαστάσεις και το μέγεθος της εικόνας. Το αποτέλεσμα της συμπίεσης φαίνεται στην παρακάτω εικόνα:

![](https://cdn.acedata.cloud/l7aotl.png)

Από τα παραπάνω, μπορούμε να ορίσουμε την παράμετρο `question` ως την αντίστοιχη `/m/01pns0` για τον πυροσβεστήρα, με το περιεχόμενο όπως φαίνεται παρακάτω:

<p><img src="https://cdn.acedata.cloud/d53oc3.png" width="500" className="m-auto" /></p>

Μπορούμε να δούμε ότι εδώ έχουμε ορίσει τα Request Headers, συμπεριλαμβανομένων:

- `accept`: ποια μορφή απάντησης θέλουμε να λάβουμε, εδώ συμπληρώνουμε `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί API για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, έχουμε ορίσει το Request Body, συμπεριλαμβανομένων:

- `image`: η εικόνα captcha κωδικοποιημένη σε Base64.
- `question`: ID ερώτησης, παρακαλώ ανατρέξτε στον πίνακα, ξεκινά με /m/.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/bsp8g9.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμές, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "solution": {
    "size": 300,
    "label": "/m/01pns0",
    "confidences": [
      0,
      0.0007,
      1,
      0.0003,
      0.0046,
      1,
      0,
      1,
      0
    ],
    "objects": [
      2,
      5,
      7
    ],
    "type": "multi"
  }
}
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, τα οποία περιγράφονται παρακάτω:

- `solution`, το αποτέλεσμα της επαλήθευσης μετά την επεξεργασία της εικόνας Recaptcha2 captcha.
  - `size`, το μέγεθος της εικόνας Recaptcha2 captcha.
  - `label`, το περιεχόμενο που αναγνωρίστηκε από την εικόνα Recaptcha2 captcha.
  - `confidences`, η εμπιστοσύνη της αναγνώρισης περιοχών της εικόνας Recaptcha2 captcha, οι περιοχές ξεκινούν από το 0.
  - `objects`, οι περιοχές που πληρούν τις απαιτήσεις αναγνώρισης από την εικόνα Recaptcha2 captcha, οι περιοχές ξεκινούν από το 0.
  - `type`, ο τύπος της εργασίας της εικόνας Recaptcha2 captcha, όταν υπάρχουν πολλές περιοχές είναι `multi`.

Μπορούμε να δούμε ότι έχουμε λάβει το αποτέλεσμα της επαλήθευσης της εικόνας Recaptcha2 captcha. Πρώτα, θα χωρίσουμε την εικόνα captcha σε περιοχές, όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/2d6qhx.png" width="500" className="m-auto" /></p>

Μπορούμε να δούμε ότι οι περιοχές ξεκινούν από το 0. Από το αποτέλεσμα `objects`, έχουμε λάβει 2, 5, 7, και απλώς χρειάζεται να προσομοιώσουμε το κλικ σε αυτές τις τρεις περιοχές για να περάσουμε την επαλήθευση.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε απλά να αντιγράψετε τον παραγόμενο κώδικα, όπως ο κώδικας CURL παρακάτω:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/recaptcha2' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "question": "/m/01pns0",
  "image": "iVBORw0KGgoAAAANSUhEUgAAASoAAAEsCAIAAAD7AWllAAAAAX..."
}'
```

Ο κώδικας σύνδεσης Python είναι όπως παρακάτω:
```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/recaptcha2"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "question": "/m/01pns0",
    "image": "iVBORw0KGgoAAAANSUhEUgAAASoAAAEsCAIAAAD7AWllAAAAAX..."
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
