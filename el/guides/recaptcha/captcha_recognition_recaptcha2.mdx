Αυτό το άρθρο θα παρουσιάσει μια οδηγία για την ενσωμάτωση του API αναγνώρισης εικόνας Recaptcha2, το οποίο μπορεί να αναγνωρίσει το περιεχόμενο που εισάγει ο χρήστης και την εικόνα του Recaptcha2, επιστρέφοντας τελικά τις συντεταγμένες της μικρής εικόνας που πρέπει να κάνετε κλικ για να ολοκληρώσετε την επαλήθευση.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το API αναγνώρισης εικόνας Recaptcha2, πρώτα πηγαίνετε στο [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, δεν χρειάζεται να κάνετε ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν. Όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό σας υπόλοιπο στο [Console](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [API αναγνώρισης εικόνας Recaptcha2 →](https://platform.acedata.cloud/documents/captcha-recognition-recaptcha2)

## Βασική χρήση

Αρχικά, ας κατανοήσουμε τη βασική μέθοδο χρήσης. Πρέπει να αποκόψουμε την εικόνα του Recaptcha2 από τον ιστότοπο, το URL του παραδείγματος είναι: `https://www.google.com/recaptcha/api2/demo`, η συγκεκριμένη σελίδα φαίνεται όπως παρακάτω:

<p><img src="https://cdn.acedata.cloud/3mgkjk.png" width="500" className="m-auto" /></p>

Πρέπει να κάνουμε κλικ στο πλαίσιο ελέγχου του Recaptcha για να εμφανιστεί η εικόνα του Recaptcha. Στην παραπάνω εικόνα, το κίτρινο βέλος δείχνει ένα κομμάτι κειμένου, το οποίο είναι η τιμή του `question` που θα χρησιμοποιηθεί παρακάτω. Πρέπει πρώτα να περάσουμε ένα πεδίο `image`, το οποίο είναι η συγκεκριμένη εικόνα του Recaptcha2, αυτή είναι η εικόνα που δείχνει το κόκκινο βέλος στην παραπάνω εικόνα, και πρέπει να κλιμακωθεί σε τυπικό μέγεθος (100x100, 300x300, 450x450), έτσι ώστε η υπηρεσία να μπορεί να προσδιορίσει τον τύπο της εικόνας. Η συμπίεση της εικόνας πρέπει να γίνει από εσάς, προτείνουμε έναν [ιστότοπο συμπίεσης](https://www.photopea.com/), όπου μπορείτε να συμπιέσετε τις διαστάσεις και το μέγεθος της εικόνας, το αποτέλεσμα της συμπίεσης φαίνεται παρακάτω:

![](https://cdn.acedata.cloud/l7aotl.png)

Επιπλέον, πρέπει να εισάγουμε την παράμετρο αναγνώρισης που σχετίζεται με την εικόνα του Recaptcha, `question`, παρέχουμε μόνο τον παρακάτω πίνακα περιεχομένων ως αναφορά:

Από τα παραπάνω, μπορούμε να ορίσουμε την παράμετρο `question` ως `/m/01pns0` που αντιστοιχεί σε πυροσβεστική βρύση, το περιεχόμενο είναι όπως παρακάτω:

<p><img src="https://cdn.acedata.cloud/d53oc3.png" width="500" className="m-auto" /></p>

Μπορούμε να δούμε ότι εδώ έχουμε ορίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλουμε να λάβουμε, εδώ συμπληρώνουμε `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί API για την κλήση του API, μπορείτε να το επιλέξετε από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ορίσει το Request Body, που περιλαμβάνει:

- `image`: η εικόνα του Recaptcha σε κωδικοποίηση Base64.
- `question`: το ID της ερώτησης, παρακαλώ ανατρέξτε στον πίνακα, αρχίζει με /m/.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/bsp8g9.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και έτσι λάβαμε το παρακάτω αποτέλεσμα:

```json
{
  "solution": {
    "size": 300,
    "label": "/m/01pns0",
    "confidences": [
      0,
      0.0007,
      1,
      0.0003,
      0.0046,
      1,
      0,
      1,
      0
    ],
    "objects": [
      2,
      5,
      7
    ],
    "type": "multi"
  }
}
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, που περιγράφονται παρακάτω:

- `solution`, το αποτέλεσμα της επαλήθευσης της επεξεργασίας της εικόνας Recaptcha2.
    - `size`, το μέγεθος της εικόνας Recaptcha2.
    - `label`, το περιεχόμενο που αναγνωρίστηκε από την εικόνα Recaptcha2.
    - `confidences`, η εμπιστοσύνη της αναγνώρισης περιοχών στην εικόνα Recaptcha2, οι περιοχές ξεκινούν από το 0.
    - `objects`, οι περιοχές που πληρούν το περιεχόμενο αναγνώρισης στην εικόνα Recaptcha2, οι περιοχές ξεκινούν από το 0.
    - `type`, ο τύπος της εργασίας της εικόνας Recaptcha2, αν υπάρχουν πολλές περιοχές είναι `multi`.
- `started_at`, `finished_at`: η ώρα έναρξης και ολοκλήρωσης της επεξεργασίας της τρέχουσας αίτησης, Unix timestamp (δευτερόλεπτα, float).
- `elapsed`: ο συνολικός χρόνος επεξεργασίας (δευτερόλεπτα).

Μπορούμε να δούμε ότι λάβαμε το αποτέλεσμα της επαλήθευσης της εικόνας Recaptcha2, πρώτα θα χωρίσουμε την εικόνα του Recaptcha σε περιοχές, όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/2d6qhx.png" width="500" className="m-auto" /></p>

Μπορούμε να δούμε ότι οι περιοχές ξεκινούν από το 0, από το αποτέλεσμα `objects` έχουμε 2,5,7, απλά πρέπει να προσομοιώσουμε το κλικ σε αυτές τις τρεις περιοχές για να περάσουμε την επαλήθευση.

Επιπλέον, αν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα ενσωμάτωσης, μπορείτε απλά να αντιγράψετε τον παραγόμενο κώδικα, όπως ο κώδικας CURL παρακάτω:
```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/recaptcha2' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "question": "/m/01pns0",
  "image": "iVBORw0KGgoAAAANSUhEUgAAASoAAAEsCAIAAAD7AWllAAAAAX..."
}'
```

Ο κώδικας σύνδεσης Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/recaptcha2"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "question": "/m/01pns0",
    "image": "iVBORw0KGgoAAAANSUhEUgAAASoAAAEsCAIAAAD7AWllAAAAAX..."
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Ασύγχρονη λειτουργία (async)

Από προεπιλογή, το API είναι συγχρονισμένο και μπλοκαρισμένο: μια αίτηση θα περιμένει μέχρι να ολοκληρωθεί η επεξεργασία του αποτελέσματος αναγνώρισης. Εάν κάνετε εναλλαγή πολλών αναγνωριστών (multi-solver rotation) και θέλετε «να λάβετε αμέσως το task_id μετά την υποβολή της εργασίας, να προγραμματίσετε άλλους αναγνωριστές και αργότερα να επιστρέψετε για να διαβάσετε το αποτέλεσμα», μπορείτε να περάσετε `async: true` στο σώμα της αίτησης.

Αφού περάσετε `async: true`, η διεπαφή θα επιστρέψει αμέσως ένα `task_id`, χωρίς να μπλοκάρει την αναμονή:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/recaptcha2' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "question": "/m/01pns0",
  "image": "iVBORw0KGgoAAAANSUhEUgAAASoAAAEsCAIAAAD7AWllAAAAAX...",
  "async": true
}'
```

```json
{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

Για να ελέγξετε ενεργά την πρόοδο, μπορείτε να χρησιμοποιήσετε το `task_id` για να ελέγξετε `POST /captcha/tasks` (συνιστάται κάθε 3~5 δευτερόλεπτα). Αυτή η διεπαφή δεν θα ενεργοποιήσει ή θα προχωρήσει την επεξεργασία της εργασίας. Ακόμα και αν δεν ελέγξετε, διακοπεί η σύνδεση ή αποσυνδεθείτε από τον πελάτη, ο διακομιστής θα συνεχίσει να επεξεργάζεται:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002"
}'
```

Κατά την επεξεργασία θα επιστραφεί `status: processing`:

```json
{ "success": true, "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002", "status": "processing" }
```

Όταν ολοκληρωθεί η επεξεργασία, θα επιστραφεί `status: ready` και το αποτέλεσμα αναγνώρισης `solution` (η δομή πεδίου είναι απολύτως ίδια με τη συγχρονισμένη λειτουργία):

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "ready",
  "solution": {
    "size": 300,
    "label": "/m/01pns0",
    "objects": [2, 5, 7],
    "type": "multi"
  }
}
```

Πληροφορίες χρέωσης: Στη λειτουργία ασύγχρονης, η δημιουργία εργασίας και η ανάγνωση της κατάστασης «σε επεξεργασία» δεν χρεώνονται. **Η χρέωση γίνεται μία φορά όταν ο πελάτης διαβάσει επιτυχώς το αποτέλεσμα** (σύμφωνα με τη συμπεριφορά και την τιμή της συγχρονισμένης λειτουργίας). Ο διακομιστής θα προχωρήσει αυτόματα την εργασία, αλλά δεν θα χρεώσει νωρίτερα επειδή η εργασία ολοκληρώθηκε στο παρασκήνιο. Εάν η εργασία δεν ολοκληρωθεί επιτυχώς εντός 120 δευτερολέπτων, θα τερματιστεί με HTTP 504 `timeout`, χωρίς χρέωση. Το `/captcha/tasks` δεν είναι υπεύθυνο για την προώθηση της εργασίας.

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα απόκρισης σφάλματος

```json
{
  "success": false,

    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
