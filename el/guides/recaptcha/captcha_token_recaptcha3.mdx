Αυτό το άρθρο θα παρουσιάσει μια μέθοδο σύνδεσης API αναγνώρισης πρωτοκόλλου Recaptcha3, η οποία επιτρέπει στους χρήστες να ολοκληρώνουν την επαλήθευση χωρίς να αναγνωρίζουν και να επιλέγουν τις εικόνες κωδικών επαλήθευσης Recaptcha3, απλά υποβάλλοντας το Website Key για αυτόματη αποκωδικοποίηση στο παρασκήνιο.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API αναγνώρισης πρωτοκόλλου Recaptcha3, πρώτα πηγαίνετε στην [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη σελίδα που βρίσκεστε.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν; όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [API Αναγνώρισης Πρωτοκόλλου Recaptcha3 →](https://platform.acedata.cloud/documents/captcha-token-recaptcha3)

## Βασική Χρήση

Πρώτα απ' όλα, ας κατανοήσουμε τη βασική μέθοδο χρήσης. Σε σύγκριση με το Recaptcha2, χρειάζεται να περάσουμε μια επιπλέον παράμετρο `page_action`, η οποία πρέπει να αποκτηθεί από τον κώδικα. Η URL ταχύτητας δικτύου που θα παρουσιαστεί είναι: `https://recaptcha-demo.appspot.com/recaptcha-v3-request-scores.php`, παρακάτω παρουσιάζεται μια μέθοδος για την απόκτησή της:

### Γρήγορη Μέθοδος:

Ανοίξτε το f12 και στη συνέχεια αναζητήστε στην καρτέλα Element το `.execute(`. Στην κόκκινη περιοχή μπορούμε να δούμε την παράμετρο `action`, ενώ μετά το execute ακολουθεί μια σειρά από χαρακτήρες, η οποία είναι επίσης το περιεχόμενο που χρειάζεται παρακάτω, όπως φαίνεται στην παρακάτω εικόνα.

<p><img src="https://cdn.acedata.cloud/imwlto.png" width="500" className="m-auto" /></p>

Στη συνέχεια, χρειάζεται να εισάγετε την URL του ιστότοπου που χρειάζεται επεξεργασία κωδικών επαλήθευσης, για να αποκτήσετε το επεξεργασμένο αποτέλεσμα. Πρώτα πρέπει να περάσετε απλά ένα πεδίο `website_url`, και στο τέλος χρειάζεται να εισάγετε την παράμετρο `website_key`, η οποία μπορεί να αποκτηθεί παραπάνω, είναι επίσης μια σειρά χαρακτήρων μετά το execute. Στη συνέχεια, μπορούμε να συμπληρώσουμε τα αντίστοιχα περιεχόμενα στην διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/1hw2uo.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, συμπεριλαμβανομένων:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί API για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, το οποίο περιλαμβάνει:

- `page_action`: πρέπει να αποκτηθεί από τον κώδικα του ιστότοπου με τον κωδικό επαλήθευσης.
- `website_url`: η URL του ιστότοπου που χρειάζεται επεξεργασία κωδικών επαλήθευσης.
- `website_key`: ο αναγνωριστικός κωδικός του ιστότοπου στο Recaptcha3.

Μπορούμε να δούμε ότι λάβαμε το αποτέλεσμα επεξεργασίας του Recaptcha3 captcha, το οποίο μπορούμε να χρησιμοποιήσουμε για POST ή GET προσομοίωση υποβολής στον στόχο ιστότοπο, μιας χρήσης, με διάρκεια 120 δευτερόλεπτα, προτείνεται να χρησιμοποιηθεί εντός 60 δευτερολέπτων. Ακολουθεί μια σύντομη περιγραφή ενός τρόπου για να υποβάλουμε το παραγόμενο token στον στόχο ιστότοπο:

Κλήση του κώδικα Python που αντιστοιχεί στην επαλήθευση του token:

```python
import requests

url = "https://recaptcha-demo.appspot.c/recaptcha-v3-verify.php?action=examples/v3scores&token='{token}'"

r = requests.get(url)
if r.status_code == 200:
    return r.text
```

Έτσι μπορούμε να λάβουμε το αποτέλεσμα:

```json

```
可以看到，其中 `success` 表示此处验证的处理结果，所有我们成功通过Recaptcha3验证码的验证。

```shell
  "website_url": "https://recaptcha-demo.appspot.com/recaptcha-v3-request-scores.php",
  "website_key": "6LdKlZEpAAAAAAOQjzC2v_d36tWxCl6dWsozdSy9",
  "page_action": "examples/v3scores"
}'
```

Python 的对接代码如下：

```python
import requests

url = "https://api.acedata.cloud/captcha/token/recaptcha3"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "website_url": "https://recaptcha-demo.appspot.com/recaptcha-v3-request-scores.php",
    "website_key": "6LdKlZEpAAAAAAOQjzC2v_d36tWxCl6dWsozdSy9",
    "page_action": "examples/v3scores"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 异步模式（async）

默认情况下 API 是同步阻塞的：一次请求会一直等待，直到 token 处理完成才返回。如果你在做多打码器轮换（multi-solver rotation），希望「提交任务后立即拿到 task_id，先去调度其他打码器，稍后再回来读取结果」，可以在请求体中传入 `async: true`。

传入 `async: true` 后，接口会立即返回一个 `task_id`，而不会阻塞等待：

```shell
curl -X POST 'https://api.acedata.cloud/captcha/token/recaptcha3' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "website_url": "https://recaptcha-demo.appspot.com/recaptcha-v3-request-scores.php",
  "website_key": "6LdKlZEpAAAAAAOQjzC2v_d36tWxCl6dWsozdSy9",
  "page_action": "examples/v3scores",
  "async": true
}'
```

```json
{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

如需主动查看进度，可使用该 `task_id` 查询 `POST /captcha/tasks`（建议每 3~5 秒一次）。本接口不会触发或推进任务处理；即使不查询、断网或退出客户端，服务器仍会继续处理：

```shell
curl -X POST 'https://api.acedata.cloud/captcha/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002"
}'
```

处理中会返回 `status: processing`：

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "processing"
}
```

处理完成会返回 `status: ready` 和 token：

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "ready",
  "token": "03AFcWeA5mfdNlQD0RGX9PTWPs0l65QukjwbYObCue5hygRuA6......"
}
```

计费说明：异步模式下，创建任务和读取「处理中」状态都不计费；**客户端首次读取成功结果时计费一次**（与现有行为及同步模式价格一致）。服务器会自主推进任务，但不会因为后台先完成就提前扣费。任务在 120 秒内未成功会终止为 HTTP 504 `timeout`，不计费。`/captcha/tasks` 不负责推进任务。

## 错误处理

在调用 API 时，如果遇到错误，API 会返回相应的错误代码和信息。例如：

- `400 token_mismatched`：Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`：Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`：Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`：Too many requests, you have exceeded the rate limit.
- `500 api_error`：Internal server error, something went wrong on the server.

### 错误响应示例

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
