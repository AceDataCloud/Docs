Αυτό το άρθρο θα παρουσιάσει μια μέθοδο σύνδεσης API αναγνώρισης πρωτοκόλλου Recaptcha3, η οποία επιτρέπει στους χρήστες να ολοκληρώνουν την επαλήθευση χωρίς να αναγνωρίζουν και να επιλέγουν τις εικόνες κωδικών Recaptcha3, απλά υποβάλλοντας το Website Key για αυτόματη αποκωδικοποίηση στο παρασκήνιο.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [API Αναγνώρισης Πρωτοκόλλου Recaptcha3](https://platform.acedata.cloud/documents/1083df69-f2f3-4c13-901e-e5336b0dbe3d) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να σας προσκαλέσουν να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης. Σε σύγκριση με το Recaptcha2, πρέπει να περάσουμε μια επιπλέον παράμετρο `page_action`, η οποία πρέπει να αποκτηθεί από τον κώδικα. Η διεύθυνση URL που θα χρησιμοποιήσουμε για την επίδειξη είναι: `https://recaptcha-demo.appspot.com/recaptcha-v3-request-scores.php`. Ακολουθεί μια μέθοδος για την απόκτησή της:

### Γρήγορη Μέθοδος:

Ανοίξτε το f12 και στη σελίδα Element αναζητήστε `.execute(`. Στην κόκκινη περιοχή μπορούμε να δούμε την παράμετρο `action`, ενώ μετά το execute ακολουθεί μια σειρά από χαρακτήρες, που είναι επίσης το περιεχόμενο που χρειαζόμαστε, όπως φαίνεται στην παρακάτω εικόνα.

<p><img src="https://cdn.acedata.cloud/imwlto.png" width="500" className="m-auto" /></p>

Στη συνέχεια, πρέπει να εισάγουμε τη διεύθυνση URL της ιστοσελίδας που χρειάζεται επεξεργασία κωδικών, για να αποκτήσουμε το επεξεργασμένο αποτέλεσμα. Πρώτα, πρέπει να περάσουμε απλά ένα πεδίο `website_url`, και τέλος, πρέπει να εισάγουμε την παράμετρο `website_key`, η οποία μπορεί να αποκτηθεί από το παραπάνω κείμενο, επίσης μια σειρά χαρακτήρων μετά το execute. Στη συνέχεια, μπορούμε να συμπληρώσουμε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/1hw2uo.png" width="500" className="m-auto" /></p>

Μπορούμε να δούμε ότι εδώ έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλουμε να λάβουμε, εδώ συμπληρώνουμε `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί API που χρησιμοποιούμε, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `page_action`: πρέπει να αποκτηθεί από τον κώδικα της ιστοσελίδας με τον κωδικό.
- `website_url`: η διεύθυνση URL της ιστοσελίδας που χρειάζεται επεξεργασία κωδικών.
- `website_key`: ο αναγνωριστικός κωδικός της ιστοσελίδας στο Recaptcha3.

Η επιστροφή αποτελεσμάτων περιλαμβάνει πολλαπλά πεδία, όπως περιγράφεται παρακάτω:

- `token`, το αποτέλεσμα της επεξεργασίας του Recaptcha3 captcha.

Μπορούμε να δούμε ότι λάβαμε το αποτέλεσμα της επεξεργασίας του Recaptcha3 captcha, το οποίο μπορούμε να χρησιμοποιήσουμε για POST ή GET προσομοίωση υποβολής στον στόχο ιστότοπο, για μία μόνο χρήση, με διάρκεια 120 δευτερόλεπτα, προτείνεται να χρησιμοποιηθεί εντός 60 δευτερολέπτων. Ακολουθεί μια σύντομη περιγραφή ενός τρόπου για να υποβάλουμε το παραγόμενο token στον στόχο ιστότοπο:

Κλήση του κώδικα Python που αντιστοιχεί στην επαλήθευση του token:

```python
import requests

url = "https://recaptcha-demo.appspot.c/recaptcha-v3-verify.php?action=examples/v3scores&token='{token}'"

r = requests.get(url)
if r.status_code == 200:
    return r.text
```

Έτσι μπορούμε να λάβουμε το αποτέλεσμα:

```json
{
  "success": true,
  "hostname": "recaptcha-demo.appspot.com",
  "challenge_ts": "2024-09-14T08:52:26Z",
  "apk_package_name": null,
  "score": 0.9,
  "action": "examples/v3scores",
  "error-codes": []
}
```

Μπορούμε να δούμε ότι το `success` δηλώνει το αποτέλεσμα της επαλήθευσης, επομένως περάσαμε επιτυχώς την επαλήθευση του Recaptcha3 captcha.

Επιπλέον, αν θέλουμε να δημιουργήσουμε τον αντίστοιχο κώδικα σύνδεσης, μπορούμε να τον αντιγράψουμε απευθείας, όπως ο κώδικας CURL παρακάτω:
```shell
curl -X POST 'https://api.acedata.cloud/captcha/token/recaptcha3' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "website_url": "https://recaptcha-demo.appspot.com/recaptcha-v3-request-scores.php",
  "website_key": "6LdKlZEpAAAAAAOQjzC2v_d36tWxCl6dWsozdSy9",
  "page_action": "examples/v3scores"
}'
```

Ο κώδικας σύνδεσης Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/recaptcha3"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "website_url": "https://recaptcha-demo.appspot.com/recaptcha-v3-request-scores.php",
    "website_key": "6LdKlZEpAAAAAAOQjzC2v_d36tWxCl6dWsozdSy9",
    "page_action": "examples/v3scores"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
