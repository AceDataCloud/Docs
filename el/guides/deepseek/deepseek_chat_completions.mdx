Το DeepSeek είναι ένα πολύ ισχυρό σύστημα AI συνομιλίας, το οποίο μπορεί να παράγει ομαλές και φυσικές απαντήσεις σε λίγα δευτερόλεπτα απλά εισάγοντας λέξεις-κλειδιά. Το DeepSeek-V3 ξεχωρίζει στη βιομηχανία για την εξαιρετική του ικανότητα κατανόησης και παραγωγής γλώσσας, και σήμερα, το DeepSeek-V3 έχει ήδη ευρέως εφαρμοστεί σε διάφορους τομείς και βιομηχανίες, με την επιρροή του να γίνεται ολοένα και πιο σημαντική. Είτε πρόκειται για καθημερινές συνομιλίες, δημιουργική γραφή, είτε για επαγγελματική συμβουλευτική και προγραμματισμό κώδικα, το DeepSeek-V3 μπορεί να προσφέρει εκπληκτική έξυπνη βοήθεια, αυξάνοντας σημαντικά την παραγωγικότητα και τη δημιουργικότητα των ανθρώπων.

Αυτό το έγγραφο περιγράφει κυρίως τη διαδικασία χρήσης του DeepSeek Chat Completion API, επιτρέποντάς μας να χρησιμοποιήσουμε εύκολα τη λειτουργία συνομιλίας του επίσημου DeepSeek.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το DeepSeek Chat Completion API, μπορείτε πρώτα να επισκεφθείτε τη σελίδα [DeepSeek Chat Completion API](https://platform.acedata.cloud/documents/2d6a9bae-9a70-4aaa-bd72-28e5bd60fa67) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να σας προσκαλέσουν να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/m9kxkz.png" width="400" className="m-auto" /></p>

Κατά την πρώτη χρήση αυτού του API, πρέπει τουλάχιστον να συμπληρώσουμε τρία περιεχόμενα: το ένα είναι το `authorization`, το οποίο μπορείτε να επιλέξετε απευθείας από τη λίστα. Ένα άλλο παράμετρο είναι το `model`, το οποίο είναι η κατηγορία μοντέλου που επιλέγουμε να χρησιμοποιήσουμε από την επίσημη ιστοσελίδα του DeepSeek. Εδώ έχουμε κυρίως 4 μοντέλα, οι λεπτομέρειες μπορούν να βρεθούν στα μοντέλα που παρέχουμε. Η τελευταία παράμετρος είναι το `messages`, το οποίο είναι ο πίνακας των ερωτήσεων που εισάγουμε. Είναι ένας πίνακας που επιτρέπει την ταυτόχρονη αποστολή πολλών ερωτήσεων, κάθε ερώτηση περιλαμβάνει το `role` και το `content`, όπου το `role` δηλώνει τον ρόλο του ερωτώντος. Παρέχουμε τρεις ταυτότητες: `user`, `assistant`, `system`. Το άλλο `content` είναι το συγκεκριμένο περιεχόμενο της ερώτησής μας.

Μπορείτε επίσης να παρατηρήσετε ότι στα δεξιά υπάρχει ο αντίστοιχος κώδικας κλήσης που μπορείτε να αντιγράψετε και να εκτελέσετε απευθείας, ή μπορείτε να κάνετε κλικ στο κουμπί «Try» για να δοκιμάσετε.

Συνηθισμένες προαιρετικές παράμετροι:

- `max_tokens`: περιορίζει τον μέγιστο αριθμό tokens για μία απάντηση.
- `temperature`: καθορίζει την τυχαιότητα της παραγωγής, από 0-2, με μεγαλύτερη τιμή να σημαίνει μεγαλύτερη διασπορά.
- `n`: πόσες υποψήφιες απαντήσεις θα παραχθούν ταυτόχρονα.
- `response_format`: ρύθμιση της μορφής επιστροφής.

Μετά την κλήση, παρατηρούμε ότι το αποτέλεσμα επιστροφής είναι το εξής:

```json
{
  "id": "chatcmpl-050bf20a-ebcd-498a-bf6e-63ee0738013b",
  "object": "chat.completion",
  "created": 1764846609,
  "model": "deepseek-v3.2-exp",
  "usage": {
    "prompt_tokens": 8,
    "completion_tokens": 11,
    "total_tokens": 19
  },
  "choices": [
    {
      "index": 0,
      "message": {
        "content": "Hello! 😊 How can I help you today?",
        "role": "assistant"
      },
      "refs": null,
      "logprobs": null,
      "finish_reason": "stop",
      "service_tier": null
    }
  ]
}
```

Το αποτέλεσμα επιστροφής περιλαμβάνει πολλαπλά πεδία, τα οποία περιγράφονται ως εξής:

- `id`, το ID της τρέχουσας συνομιλίας, που χρησιμοποιείται για την μοναδική αναγνώριση της τρέχουσας συνομιλίας.
- `created`, πληροφορίες σχετικά με την ώρα δημιουργίας της τρέχουσας συνομιλίας.
- `model`, το επιλεγμένο μοντέλο από την επίσημη ιστοσελίδα του DeepSeek.
- `choices`, οι πληροφορίες απάντησης που παρέχει το DeepSeek για τις ερωτήσεις.
- `usage`: στατιστικά στοιχεία σχετικά με τα tokens για αυτή την ερώτηση-απάντηση.

Το `choices` περιλαμβάνει τις πληροφορίες απάντησης του DeepSeek, όπου μπορείτε να δείτε τις απαντήσεις του DeepSeek, όπως φαίνεται στην εικόνα.

<p><img src="https://cdn.acedata.cloud/0pd4q5.png" width="400" className="m-auto" /></p>

Μπορείτε να δείτε ότι το πεδίο `content` μέσα στο `choices` περιλαμβάνει το συγκεκριμένο περιεχόμενο της απάντησης του DeepSeek.

## Ροή Απόκρισης

Αυτή η διεπαφή υποστηρίζει επίσης ροή απόκρισης, κάτι που είναι πολύ χρήσιμο για την ενσωμάτωσή της σε ιστοσελίδες, καθώς επιτρέπει την εμφάνιση αποτελεσμάτων λέξη προς λέξη.

Εάν θέλετε να επιστρέψετε την απόκριση σε ροή, μπορείτε να αλλάξετε την παράμετρο `stream` στην κεφαλίδα του αιτήματος σε `true`.

Η αλλαγή είναι όπως φαίνεται στην εικόνα, αλλά ο κώδικας κλήσης χρειάζεται να έχει τις αντίστοιχες αλλαγές για να υποστηρίξει τη ροή απόκρισης.

<p><img src="https://cdn.acedata.cloud/dsoiqw.png" width="400" className="m-auto" /></p>

Αφού αλλάξετε το `stream` σε `true`, το API θα επιστρέφει γραμμή προς γραμμή τα αντίστοιχα δεδομένα JSON, και σε επίπεδο κώδικα θα χρειαστεί να κάνουμε τις κατάλληλες αλλαγές για να αποκτήσουμε τα αποτελέσματα γραμμή προς γραμμή.

Παράδειγμα κώδικα κλήσης σε Python:

```python
import requests

url = "https://api.acedata.cloud/deepseek/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "deepseek-v3",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```javascript
const options = {

  .then(response => response.json())
  .then(response => console.log(response))
  .catch(err => console.error(err));
```

## Πολλαπλοί γύροι συνομιλίας

```python

url = "https://api.acedata.cloud/deepseek/chat/completions"

    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
```

## Διαχείριση σφαλμάτων

Κατά την κλήση της API, εάν προκύψει σφάλμα, η API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
