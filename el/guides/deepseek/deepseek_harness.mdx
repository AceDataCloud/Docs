[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) είναι ένας προγραμματιστικός πράκτορας που εκτελείται τοπικά. Διαβάζει τον χώρο εργασίας, καλεί εργαλεία και εκτελεί εντολές, και στη συνέχεια καλεί το μοντέλο μέσω του OpenAI-compatible Chat Completions API.

> Αυτό το άρθρο ισχύει για `deepseek-harness-sdk==0.1.0rc6` και `deepseek-harness-runtime-bin==0.1.0rc6`. Μετά την αναβάθμιση του πελάτη, παρακαλώ ολοκληρώστε ξανά τη δοκιμή του αρχείου μόνο για ανάγνωση παρακάτω.

## Υποστηριζόμενη περιοχή

| Έργο           | Ρύθμιση                                     |
| ------------ | -------------------------------------- |
| API Base URL | `https://api.acedata.cloud/v1`         |
| Μοντέλο           | `deepseek-v4-pro`                      |
| Πρωτόκολλο           | OpenAI-compatible Chat Completions (streaming) |
| Δυνατότητες           | Κείμενο, διαδικασία λογισμού, κλήσεις εργαλείων, τοπικός κύκλος εργαλείων Bash, στατιστικά χρήσης   |

Ο κατάλογος μοντέλων θα αλλάξει. Πριν την εκτέλεση, ελέγξτε τον τρέχοντα κατάλογο με το ειδικό κλειδί του Coding Plan:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY"
```

Επιβεβαιώστε ότι η απάντηση περιλαμβάνει το `deepseek-v4-pro`. Μην θεωρείτε το `deepseek-v4-flash` ως ισοδύναμο υποκατάστατο για τη λειτουργία εργαλείων αυτού του άρθρου; Στην τρέχουσα επικύρωση σταθερής έκδοσης, η ιστορία πολλαπλής λογιστικής του και η αναπαραγωγή εργαλείων δεν πέρασαν.

## 1. Προετοιμάστε το ειδικό κλειδί

Ανοίξτε την [εφαρμογή Coding Plan](https://platform.acedata.cloud/console/applications), μεταβείτε στην αγορασμένη Coding Application, δημιουργήστε ή αντιγράψτε το ειδικό API Key της εφαρμογής. Το Coding Plan δεν χρησιμοποιεί γενικό υπόλοιπο, τα κλειδιά άλλων εφαρμογών δεν μπορούν να εκπροσωπήσουν τα δικαιώματα του πακέτου.

Βάλτε το κλειδί μόνο στο τρέχον shell:

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_CODING_KEY_HERE"
export DEEPSEEK_BASE_URL="https://api.acedata.cloud/v1"
export DEEPSEEK_API_KEY="$ACEDATACLOUD_API_KEY"
```

Μην γράφετε το πραγματικό κλειδί σε σενάρια, αποθετήρια ρυθμίσεων, στιγμιότυπα οθόνης ή καταγραφές συνεδρίας.

## 2. Δημιουργήστε απομονωμένο χώρο εργασίας

Ο bundled runtime του Harness περιλαμβάνει τοπικά εργαλεία Bash. Κατά την πρώτη επικύρωση, μην δείχνετε σε πραγματικά έργα ή στον κύριο κατάλογο; Δημιουργήστε έναν προσωρινό κατάλογο χωρίς μυστικά:

```bash
mkdir -p /tmp/deepseek-harness-demo/workspace
mkdir -p /tmp/deepseek-harness-demo/sessions
printf 'compatibility fixture\n' > /tmp/deepseek-harness-demo/workspace/fixture.txt
python3 -m venv /tmp/deepseek-harness-demo/venv
/tmp/deepseek-harness-demo/venv/bin/pip install \
  "deepseek-harness-sdk==0.1.0rc6"
```

Εάν το εταιρικό δίκτυο χρησιμοποιεί ιδιωτική εικόνα PyPI, παρακαλώ επιβεβαιώστε πρώτα ότι η ίδια έκδοση του `deepseek-harness-runtime-bin` υπάρχει στην εικόνα. Μην χρησιμοποιείτε το `danger-full-access` για να επεκτείνετε την πρόσβαση στα αρχεία; Το παράδειγμα αυτού του άρθρου μεταφέρει μόνο τον προσωρινό κατάλογο στο `cwd`.

## 3. Εκτελέστε το επίσημο Python SDK

Αποθηκεύστε το παρακάτω περιεχόμενο ως `/tmp/deepseek-harness-demo/run.py`:

```python
import os

from deepseek_harness import DeepSeekHarness

with DeepSeekHarness(
    provider="deepseek-official",
    model="deepseek-v4-pro",
    max_tokens=160,
    cwd="/tmp/deepseek-harness-demo/workspace",
    session_root="/tmp/deepseek-harness-demo/sessions",
    base_url=os.environ["DEEPSEEK_BASE_URL"],
    api_key=os.environ["DEEPSEEK_API_KEY"],
    request_timeout_seconds=180,
) as harness:
    result = harness.run(
        "Read fixture.txt once, then reply with exactly: sdk-harness-ok",
        session_id="acedatacloud-compat",
    )

print(result.final_response)
print(result.finish_reason)
```

Εκτελέστε:

```bash
/tmp/deepseek-harness-demo/venv/bin/python \
  /tmp/deepseek-harness-demo/run.py
```

Αναμενόμενο αποτέλεσμα:

```text
sdk-harness-ok
completed
```

Αυτό το βήμα επικυρώνει ταυτόχρονα την εξουσιοδότηση Bearer, το `/v1/chat/completions`, το SSE, το περιεχόμενο λογισμού, τις κλήσεις εργαλείων και την επιστροφή αποτελεσμάτων εργαλείων. Μετά την ολοκλήρωση, μπορείτε να διαγράψετε το `/tmp/deepseek-harness-demo`; εάν ο κατάλογος συνεδρίας περιέχει το πλαίσιο του έργου, θα πρέπει επίσης να φυλάσσεται με την ίδια ευαισθησία όπως το αποθετήριο κώδικα.

## Συχνές ερωτήσεις

- **401**: Ελέγξτε αν το `ACEDATACLOUD_API_KEY` έχει εξαχθεί στο ίδιο shell που εκτελεί το Python.
- **403 ή προειδοποίηση πίστωσης**: Επιβεβαιώστε ότι το κλειδί ανήκει στην τρέχουσα Coding Application, το πακέτο είναι ακόμα σε ισχύ και έχει υπόλοιπο.
- **Μοντέλο μη διαθέσιμο**: Επαναλάβετε την αναζήτηση στο `/v1/models`, μην μαντεύετε το όνομα του μοντέλου με βάση παλιές στιγμιότυπα.
- **Σφάλμα `reasoning_content` / αναπαραγωγής εργαλείων**: Επιβεβαιώστε ότι το SDK/runtime είναι και οι δύο στην σταθερή έκδοση αυτού του άρθρου και χρησιμοποιήστε το `deepseek-v4-pro`.
- **Ανωμαλία στον αριθμό εκτελέσεων εργαλείων**: Σταματήστε την εκτέλεση εργασιών που μπορεί να προκαλέσουν παρενέργειες, πρώτα ελέγξτε την τρέχουσα έκδοση υπηρεσίας με το μόνο αναγνώσιμο fixture αυτού του άρθρου.
- **Αποτυχία εγκατάστασης**: Επιβεβαιώστε ότι το Python 3.10+, η αρχιτεκτονική του λειτουργικού συστήματος υποστηρίζεται από το τρέχον wheel και ελέγξτε την ομοιομορφία των εκδόσεων SDK/runtime.

## Όρια δυνατοτήτων

Αυτό το άρθρο επικυρώνει μόνο το τοπικό Python SDK προς το Chat Completions για κείμενο και κύκλους εργαλείων. Εικόνες, Files API, `/v1/responses`, `/v1/messages`, απομακρυσμένοι χώροι εργασίας και φιλοξενούμενα sandbox δεν περιλαμβάνονται στην υποσχεμένη περιοχή αυτού του οδηγού; Τα δικαιώματα του χώρου εργασίας και οι κίνδυνοι τοπικών εντολών είναι ευθύνη της μηχανής και της ρύθμισης που εκτελεί το Harness.
