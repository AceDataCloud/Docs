Claude Code είναι ένα εργαλείο **Agentic Coding** που κυκλοφόρησε από την Anthropic, και θεωρείται ένα από τα πιο ισχυρά προγραμματιστικά Agents στον κόσμο. Η επιτραπέζια εφαρμογή Claude Code προσφέρει μια ανεξάρτητη γραφική διεπαφή, υποστηρίζει λειτουργίες Diff αναθεώρησης, παράλληλες συνεδρίες (μέσω απομόνωσης Git Worktree), απομακρυσμένες συνεδρίες και άλλα, χωρίς να εξαρτάται από οποιοδήποτε IDE.

Αυτό το έγγραφο περιγράφει κυρίως πώς να ρυθμίσετε και να χρησιμοποιήσετε την επιτραπέζια εφαρμογή Claude Code μέσω της υπηρεσίας proxy του AceData Cloud.

> **Σημείωση**: Η επιτραπέζια εφαρμογή Claude Code είναι αυτή τη στιγμή σε φάση προεπισκόπησης (Preview) και υποστηρίζει μόνο macOS και Windows.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Claude Code, μπορείτε πρώτα να επισκεφθείτε τη [σελίδα υπηρεσιών Claude Messages](https://platform.acedata.cloud/documents/claude-messages) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την εγγραφή ή σύνδεση θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν την υπηρεσία Claude Code.

## Εγκατάσταση Επιτραπέζιας Εφαρμογής

### Απαιτήσεις Συστήματος

- macOS (Intel και Apple Silicon) ή Windows (x64 / ARM64)
- Linux δεν υποστηρίζει προς το παρόν την επιτραπέζια εφαρμογή

### Λήψη και Εγκατάσταση

Επισκεφθείτε τη [σελίδα λήψης του Claude](https://claude.ai) για να κατεβάσετε το πακέτο εγκατάστασης για την αντίστοιχη πλατφόρμα:

- **macOS**: Κατεβάστε το αρχείο `.dmg` και σύρετέ το στον φάκελο Applications
- **Windows x64**: Κατεβάστε το πακέτο εγκατάστασης `.exe` και ακολουθήστε τις οδηγίες εγκατάστασης
- **Windows ARM64**: Κατεβάστε την έκδοση ARM64 (σημειώστε: η ARM64 δεν υποστηρίζει τοπικές συνεδρίες, απαιτεί απομακρυσμένες συνεδρίες)

![Σελίδα λήψης επιτραπέζιας εφαρμογής Claude](https://cdn.acedata.cloud/c3c8c57264.png)

Αφού ολοκληρωθεί η εγκατάσταση, εκκινήστε το Claude από τον φάκελο Applications (macOS) ή από το μενού Έναρξης (Windows).

## Ρύθμιση AceData Cloud API

Αφού εκκινήσετε την επιτραπέζια εφαρμογή, θα χρειαστεί να συνδεθείτε με τον λογαριασμό Anthropic. Μπορούμε να χρησιμοποιήσουμε το API proxy του AceData Cloud ρυθμίζοντας μεταβλητές περιβάλλοντος, **χωρίς επίσημη συνδρομή**.

Η επιτραπέζια εφαρμογή διαβάζει τις μεταβλητές περιβάλλοντος από το περιβάλλον Shell σας, επομένως πρέπει να τις ρυθμίσετε στο αρχείο ρύθμισης του Shell.

### Ρύθμιση Μεταβλητών Περιβάλλοντος

**Χρήστες macOS**

Προσθέστε το παρακάτω περιεχόμενο στο `~/.zshrc` (ή `~/.bashrc`), αντικαθιστώντας το `{token}` με το API token σας:

```bash
# AceData Cloud - Ρύθμιση proxy Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Αποθηκεύστε και εκτελέστε:

```bash
source ~/.zshrc
```

**Χρήστες Windows**

Προσθέστε τις παρακάτω συστημικές μεταβλητές περιβάλλοντος μέσω «Ιδιότητες Συστήματος → Προχωρημένα → Μεταβλητές Περιβάλλοντος»:

| Όνομα Μεταβλητής          | Τιμή                           |
| ---------------------- | ----------------------------- |
| `ANTHROPIC_AUTH_TOKEN` | `{token}` (αντικαταστήστε με το API token σας) |
| `ANTHROPIC_BASE_URL`   | `https://api.acedata.cloud`  |

Ή χρησιμοποιήστε το PowerShell:

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**Μπορείτε επίσης να ρυθμίσετε μέσω του settings.json**

Επεξεργαστείτε το `~/.claude/settings.json` (δημιουργήστε το αν δεν υπάρχει):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Υπόδειξη**: Το API token μπορεί να προβληθεί στον [Πίνακα Ελέγχου AceData Cloud](https://platform.acedata.cloud/console). Μετά την ολοκλήρωση της ρύθμισης, απαιτείται **επανεκκίνηση της επιτραπέζιας εφαρμογής** για να ισχύσουν οι μεταβλητές περιβάλλοντος.

## Βασική Χρήση

### Άνοιγμα Έργου

1. Εκκινήστε την επιτραπέζια εφαρμογή Claude
2. Κάντε κλικ στην καρτέλα **Code** στην κορυφή
3. Επιλέξτε τη λειτουργία εκτέλεσης **Local**
4. Κάντε κλικ στο **Select folder** για να επιλέξετε τον φάκελο του έργου σας

### Ξεκινήστε Συνομιλία

Εισάγετε στο πεδίο κειμένου μια φυσική γλώσσα για να περιγράψετε τις ανάγκες σας:

- «Βρείτε τα σχόλια TODO και διορθώστε τα»
- «Προσθέστε δοκιμές στη κύρια συνάρτηση»
- «Εξηγήστε την αρχιτεκτονική αυτού του έργου»

Ο Claude θα αναλύσει τη βιβλιοθήκη κώδικα σας, θα προτείνει τροποποιήσεις και θα εμφανίσει τις αλλαγές σε μορφή Diff.

### Λειτουργία Δικαιωμάτων

Αλλάξτε τη λειτουργία μέσω του επιλογέα δίπλα στο κουμπί αποστολής:

| Λειτουργία   | Περιγραφή                     |
| ----------- | ---------------------------- |
| **Ask**     | Ρωτάει επιβεβαίωση πριν από κάθε τροποποίηση (συνιστάται για αρχάριους) |
| **Code**    | Αυτόματα αποδέχεται την επεξεργασία αρχείων, αλλά οι εντολές τερματικού απαιτούν επιβεβαίωση |
| **Plan**    | Καταρτίζει πρώτα λεπτομερή σχέδιο και περιμένει έγκριση πριν εκτελέσει |

### Παράλληλες Συνεδρίες

Κάντε κλικ στο **+ New session** στην πλαϊνή μπάρα για να ξεκινήσετε πολλές παράλληλες συνεδρίες. Για τα Git repositories, κάθε συνεδρία θα αποκτήσει ανεξάρτητο αντίγραφο του έργου μέσω του Worktree, χωρίς αλληλεπίδραση.

Το Worktree αποθηκεύεται προεπιλεγμένα στον φάκελο `~/.claude-worktrees/`.

### Diff Αναθεώρηση

Όταν ο Claude τροποποιήσει αρχεία, θα εμφανίσει στατιστικά αλλαγών (π.χ. `+12 -1`), κάνοντας κλικ μπορείτε να ανοίξετε τον αναθεωρητή Diff και να ελέγξετε τις τροποποιήσεις ανά αρχείο. Μπορείτε επίσης να κάνετε κλικ σε συγκεκριμένες γραμμές κώδικα για να προσθέσετε σχόλια, και ο Claude θα προσαρμόσει τις αλλαγές με βάση την ανατροφοδότησή σας.

## Σύνδεση με Εξωτερικά Εργαλεία

Πριν ξεκινήσετε τη συνεδρία, κάντε κλικ στο κουμπί **⋯**, επιλέξτε **Connectors** για να προσθέσετε εξωτερικές ενσωματώσεις:

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- Περισσότερα...

Αφού συνδεθείτε, ο Claude μπορεί να διαβάσει απευθείας το ημερολόγιο, να στείλει μηνύματα, να δημιουργήσει Issues κ.λπ.

## Σχέση με CLI

Η επιτραπέζια εφαρμογή και το CLI χρησιμοποιούν την ίδια υποκείμενη μηχανή, μοιράζονται τις παρακάτω ρυθμίσεις:

- Αρχεία μνήμης έργου `CLAUDE.md` / `CLAUDE.local.md`
- Ρυθμίσεις διακομιστή MCP στο `~/.claude.json` / `.mcp.json`
- Ρυθμίσεις στο `~/.claude/settings.json`
- Ρυθμίσεις Hooks και Skills

Και οι δύο μπορούν να εκτελούνται ταυτόχρονα στο ίδιο έργο, διατηρώντας ανεξάρτητο ιστορικό συνεδριών.

## Συχνές Ερωτήσεις

### Τι να κάνω αν η σύνδεση αποτύχει;

1. Ελέγξτε αν το αρχείο `~/.claude/config.json` έχει δημιουργηθεί σωστά
2. Επιβεβαιώστε ότι οι μεταβλητές περιβάλλοντος έχουν ρυθμιστεί σωστά (επανεκκινήστε την επιτραπέζια εφαρμογή για να ισχύσουν)
3. Επιβεβαιώστε ότι το API token είναι έγκυρο (μπορείτε να το δείτε στον [Πίνακα Ελέγχου](https://platform.acedata.cloud/console))
4. Εάν χρησιμοποιείτε το `settings.json` για να ρυθμίσετε τις μεταβλητές περιβάλλοντος, επιβεβαιώστε ότι η μορφή του αρχείου είναι σωστή

### Τι να κάνω αν δεν μπορώ να βρω τα εγκατεστημένα εργαλεία;

Εάν ο Claude δεν μπορεί να βρει εντολές όπως `npm`, `node` κ.λπ.:

1. Επιβεβαιώστε ότι αυτά τα εργαλεία λειτουργούν κανονικά σε μια κανονική κονσόλα
2. Ελέγξτε αν το αρχείο ρύθμισης του Shell σας (`~/.zshrc`, `~/.bashrc`) έχει ρυθμιστεί σωστά το PATH
3. Επανεκκινήστε την επιτραπέζια εφαρμογή για να επαναφορτώσετε τις μεταβλητές περιβάλλοντος

### Πώς να ελέγξω την υπόλοιπη πίστωση;

Συνδεθείτε στον [Πίνακα Ελέγχου AceData Cloud](https://platform.acedata.cloud/console) για να δείτε την τρέχουσα υπόλοιπη πίστωση και την κατάσταση χρήσης.
