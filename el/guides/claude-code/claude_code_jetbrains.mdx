## 1. Απόκτηση API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), μπείτε στις διαθέσιμες εφαρμογές και αντιγράψτε το API Key.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Εγκατάσταση CLI και πρόσθετου

Αρχικά, εγκαταστήστε το Claude Code CLI.

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

Στη συνέχεια, εγκαταστήστε το πρόσθετο **Claude Code** από το JetBrains Marketplace και επανεκκινήστε το IDE. Το πρόσθετο καλεί την εντολή `claude` του τοπικού συστήματος. Αν εμφανιστεί μήνυμα ότι δεν βρέθηκε η εντολή, συμπληρώστε την πλήρη διαδρομή της στο **Settings → Tools → Claude Code**.

## 3. Ρύθμιση Ace Data Cloud

Ρυθμίστε στο περιβάλλον εκκίνησης του JetBrains backend.

macOS / Linux / WSL:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="το API Key σας"
unset ANTHROPIC_API_KEY
```

Windows PowerShell:

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "το API Key σας"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

Μπορείτε επίσης να χρησιμοποιήσετε το `.claude/settings.local.json` που έχει αγνοηθεί στο έργο:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "το API Key σας"
  }
}
```

Για την Απομακρυσμένη Ανάπτυξη, πρέπει να ρυθμίσετε και να εγκαταστήσετε το πρόσθετο στον απομακρυσμένο Host. Οι χρήστες WSL μπορούν να ορίσουν την εντολή Claude ως `wsl -d Ubuntu -- bash -lic "claude"`.

## 4. Επαλήθευση

Εκτελέστε την εντολή `claude` από το ενσωματωμένο τερματικό του IDE ή ξεκινήστε ένα εξωτερικό τερματικό και πληκτρολογήστε `/ide`. Αφού συνδεθείτε επιτυχώς, ζητήστε από τον Claude να απαντήσει `OK`, στη συνέχεια διαβάστε ένα δοκιμαστικό αρχείο και ελέγξτε το αίτημα στην ιστοσελίδα χρήσης του Ace Data Cloud [χρήση ιστορικού](https://platform.acedata.cloud/console/usages).

Αν το πρόσθετο δεν μπορεί να ξεκινήσει, εκτελέστε πρώτα την εντολή `claude --version` στο ίδιο τερματικό. Αν δείτε 401, ελέγξτε τις πραγματικές κληρονομούμενες μεταβλητές περιβάλλοντος του backend και το παλιό `ANTHROPIC_API_KEY`.
