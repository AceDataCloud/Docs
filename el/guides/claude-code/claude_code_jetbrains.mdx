Το Claude Code είναι ένα εργαλείο **Agentic Coding** που κυκλοφόρησε η Anthropic, και θεωρείται ένα από τα πιο ισχυρά προγραμματιστικά Agents στον κόσμο. Το Claude Code προσφέρει ένα ειδικό plugin για JetBrains IDE, υποστηρίζοντας ολόκληρη τη σειρά JetBrains IDE όπως IntelliJ IDEA, PyCharm, WebStorm, GoLand, PhpStorm, Android Studio κ.λπ.

Αυτό το έγγραφο περιγράφει κυρίως πώς να ρυθμίσετε και να χρησιμοποιήσετε το Claude Code μέσω της υπηρεσίας proxy του AceData Cloud στο JetBrains IDE.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Claude Code, μπορείτε πρώτα να επισκεφθείτε τη σελίδα υπηρεσιών [Claude Messages](https://platform.acedata.cloud/documents/claude-messages) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την εγγραφή θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση για να δοκιμάσετε δωρεάν την υπηρεσία Claude Code.

## Υποστηριζόμενα IDE

| IDE                | Υποστηριζόμενες γλώσσες/σενάρια      |
| ------------------ | --------------------- |
| **IntelliJ IDEA**  | Java, Kotlin, Scala κ.λπ.   |
| **PyCharm**        | Python                |

| **PhpStorm**       | PHP                   |
| **Android Studio** | Ανάπτυξη Android            |
| **Άλλα**             | Οι περισσότερες JetBrains IDE υποστηρίζονται |

## Εγκατάσταση

### Προαπαιτούμενα

Το plugin Claude Code JetBrains εξαρτάται από το Claude Code CLI, παρακαλώ βεβαιωθείτε ότι έχετε εγκαταστήσει το CLI:

```bash
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# Ή χρησιμοποιώντας το Homebrew
brew install claude-code
```

Μετά την ολοκλήρωση της εγκατάστασης, μπορείτε να επιβεβαιώσετε:

```bash
claude --version
```

### Εγκατάσταση του plugin

![Plugin Claude Code στο JetBrains Marketplace](https://cdn.acedata.cloud/de78fd305b.png)

1. Ανοίξτε το JetBrains IDE
2. Μεταβείτε στο **Settings** → **Plugins** → **Marketplace**
3. Αναζητήστε **Claude Code**
4. Κάντε κλικ στο **Install** για να εγκαταστήσετε το plugin
5. Επανεκκινήστε το IDE

Ή επισκεφθείτε απευθείας το [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/27310-claude-code-beta-) για online εγκατάσταση.

> **Σημαντικό**: Μετά την εγκατάσταση του plugin, απαιτείται **πλήρης επανεκκίνηση του IDE** (μπορεί να χρειαστεί να επανεκκινήσετε πολλές φορές) για να ισχύσει.

## Ρύθμιση AceData Cloud API

Το plugin Claude Code JetBrains εκτελεί την εντολή `claude` μέσω του ενσωματωμένου τερματικού, επομένως η ρύθμιση των μεταβλητών περιβάλλοντος είναι η ίδια με αυτή του CLI.

### Βήμα 1: Δημιουργία του config.json

Δημιουργήστε το αρχείο ρυθμίσεων για το Claude Code:

| Σύστημα            | Διαδρομή                                   |
| ----------------- | ------------------------------------ |
| **macOS / Linux** | `~/.claude/config.json`              |
| **Windows**       | `C:\Users\{όνομα χρήστη}\.claude\config.json` |

Γράψτε το παρακάτω περιεχόμενο σε αυτό το αρχείο και αποθηκεύστε το:

```json
{
  "primaryApiKey": "self"
}
```

Γρήγορη εντολή δημιουργίας για macOS / Linux:

```bash
mkdir -p ~/.claude && echo '{"primaryApiKey": "self"}' > ~/.claude/config.json
```

### Βήμα 2: Ρύθμιση μεταβλητών περιβάλλοντος

**Μέθοδος 1: Ρύθμιση στο αρχείο ρυθμίσεων του Shell (συνιστάται)**

Προσθέστε το παρακάτω περιεχόμενο στο `~/.zshrc` ή `~/.bashrc`, αντικαθιστώντας το `{token}` με το API token σας:

```bash
# AceData Cloud - Ρύθμιση proxy Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Μετά την τροποποίηση, εκτελέστε `source ~/.zshrc` για να ισχύσουν οι ρυθμίσεις, και στη συνέχεια **επανεκκινήστε το JetBrains IDE**.

**Μέθοδος 2: Ρύθμιση στο settings.json του Claude Code**

Επεξεργαστείτε το `~/.claude/settings.json` (δημιουργήστε το αν δεν υπάρχει):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Σημείωση**: Το API token μπορεί να προβληθεί στην [κονσόλα AceData Cloud](https://platform.acedata.cloud/console).

## Βασική Χρήση

### Εκκίνηση από το ενσωματωμένο τερματικό του IDE

Ανοίξτε το ενσωματωμένο τερματικό του JetBrains IDE και εκτελέστε:

```bash
claude
```

Όταν εκτελείτε από το ενσωματωμένο τερματικό του IDE, όλες οι ενσωματωμένες λειτουργίες (προβολή Diff, επιλογή συμφραζομένων κ.λπ.) θα ενεργοποιηθούν αυτόματα.

### Σύνδεση από εξωτερικό τερματικό

Εάν εκτελείτε το Claude Code από εξωτερικό τερματικό, μπορείτε να χρησιμοποιήσετε την εντολή `/ide` για να συνδεθείτε στο JetBrains IDE:

```bash
claude
> /ide
```

Βεβαιωθείτε ότι εκκινείτε το Claude Code από την ίδια διαδρομή με τη ρίζα του έργου IDE, έτσι ώστε το Claude να έχει πρόσβαση στα ίδια αρχεία.

### Συντομεύσεις

| Συντόμευση                                          | Λειτουργία                  |
| ------------------------------------------------ | ----------------------- |
| `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux)        | Γρήγορη εκκίνηση του Claude Code        |
| `Cmd+Option+K` (Mac) / `Alt+Ctrl+K` (Windows/Linux) | Εισαγωγή αναφοράς αρχείου (π.χ. `@File#L1-99`) |

### Ενσωματωμένες Λειτουργίες

Το plugin Claude Code JetBrains προσφέρει τις εξής ενσωματωμένες λειτουργίες:

- **Προβολή Diff**: Οι αλλαγές κώδικα εμφανίζονται απευθείας στον προβολέα Diff του IDE
- **Επιλογή Συμφραζομένων**: Ο τρέχων επιλεγμένος κώδικας και οι καρτέλες θα μοιράζονται αυτόματα με το Claude
- **Αναφορές Αρχείων**: Χρησιμοποιήστε συντομεύσεις για γρήγορη αναφορά αρχείων και αριθμών γραμμών
- **Κοινοποίηση Διαγνωστικών**: Οι πληροφορίες διαγνωστικών όπως Lint, συντακτικά σφάλματα κ.λπ. μοιράζονται αυτόματα με το Claude

## Ρυθμίσεις Plugin

Μπορείτε να ρυθμίσετε στο **Settings** → **Tools** → **Claude Code [Beta]**:

| Ρύθμιση                        | Περιγραφή                                     |
| ----------------------------- | ------------------------------------------ |
| **Claude command**            | Προσαρμογή διαδρομής εντολής Claude (π.χ. `/usr/local/bin/claude`) |
| **Enable automatic updates**  | Αυτόματη έλεγχος και εγκατάσταση ενημερώσεων plugin                                |
| **Enable using Option+Enter** | Χρήση Option+Enter στο macOS για αλλαγή γραμμής στο παράθυρο προτροπής             |

### Ρυθμίσεις Χρηστών WSL

Εάν χρησιμοποιείτε σε περιβάλλον WSL, πρέπει να ρυθμίσετε την εντολή Claude ως εξής:

```
wsl -d Ubuntu -- bash -lic "claude"
```

(Αντικαταστήστε το `Ubuntu` με το όνομα της διανομής WSL σας)

## Συχνές Ερωτήσεις

### Τι να κάνω αν η σύνδεση αποτύχει;

1. Ελέγξτε αν το αρχείο `~/.claude/config.json` έχει δημιουργηθεί σωστά
2. Επιβεβαιώστε ότι οι μεταβλητές περιβάλλοντος έχουν ρυθμιστεί σωστά
3. Επιβεβαιώστε ότι το API token είναι έγκυρο (μπορείτε να το δείτε στην [κονσόλα](https://platform.acedata.cloud/console))
4. Επανεκκινήστε το JetBrains IDE και δοκιμάστε ξανά

### Τι να κάνω αν το plugin δεν λειτουργεί;

1. Βεβαιωθείτε ότι εκτελείτε το Claude Code από τη ρίζα του έργου
2. Ελέγξτε αν το plugin είναι ενεργοποιημένο στις ρυθμίσεις του IDE
3. Πραγματοποιήστε πλήρη επανεκκίνηση του IDE (μπορεί να χρειαστεί να επανεκκινήσετε πολλές φορές)
4. Εάν χρησιμοποιείτε απομακρυσμένη λειτουργία ανάπτυξης, βεβαιωθείτε ότι το plugin είναι εγκατεστημένο στον απομακρυσμένο υπολογιστή (Settings → Plugin (Host))

### Τι να κάνω αν το IDE δεν ανιχνεύεται;

1. Επιβεβαιώστε ότι το plugin έχει εγκατασταθεί και είναι ενεργοποιημένο
2. Επανεκκινήστε το IDE
3. Βεβαιωθείτε ότι εκτελείτε το Claude Code από το ενσωματωμένο τερματικό
4. Οι χρήστες WSL παρακαλούνται να ανατρέξουν στον [Οδηγό Αντιμετώπισης WSL](https://code.claude.com/docs/en/troubleshooting#jetbrains-ide-not-detected-on-wsl2)

### command not found

Εάν κάνετε κλικ στο εικονίδιο Claude και εμφανίζεται το μήνυμα "command not found":

1. Επιβεβαιώστε ότι το CLI έχει εγκατασταθεί: `which claude`
2. Ρυθμίστε τη διαδρομή της εντολής Claude στις ρυθμίσεις του plugin
3. Οι χρήστες WSL να χρησιμοποιούν τη μορφή εντολής WSL που αναφέρθηκε παραπάνω
### Πώς να δείτε το υπόλοιπο;

Συνδεθείτε στο [AceData Cloud Console](https://platform.acedata.cloud/console) για να δείτε το τρέχον υπόλοιπο και την κατάσταση χρήσης του λογαριασμού σας.
