## 1. Απόκτηση API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), μπείτε στις διαθέσιμες εφαρμογές και αντιγράψτε το API Key.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Στο **Settings → Secrets and variables → Actions** του στόχου GitHub αποθετηρίου, δημιουργήστε ένα νέο Secret:

```text
ACEDATACLOUD_API_KEY
```

## 2. Εγκατάσταση GitHub App

Εγκαταστήστε την [Claude GitHub App](https://github.com/apps/claude) και δώστε άδεια στο στόχο αποθετήριο. Αυτή η επίσημη εφαρμογή θα ζητήσει ένα σταθερό σύνολο πλήρων δικαιωμάτων; μεταξύ των οποίων η Claude Code Action χρησιμοποιεί πραγματικά τα δικαιώματα Contents, Issues και Pull requests, η σελίδα εγκατάστασης του GitHub δεν μπορεί να επιλέξει μόνο αυτές τις τρεις επιλογές. Εάν η οργάνωση απαιτεί ελάχιστα δικαιώματα, παρακαλώ δημιουργήστε μια προσαρμοσμένη GitHub App σύμφωνα με την επίσημη τεκμηρίωση.

## 3. Προσθήκη Workflow

Δημιουργήστε το `.github/workflows/claude.yml`:

```yaml
name: Claude Code

on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  claude:
    if: contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      actions: read
      id-token: write
    env:
      ANTHROPIC_BASE_URL: https://api.acedata.cloud
      ANTHROPIC_CUSTOM_HEADERS: "Authorization: Bearer ${{ secrets.ACEDATACLOUD_API_KEY }}"
    steps:
      - uses: actions/checkout@v6
        with:
          fetch-depth: 1
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: dummy-not-used
```

Η `claude-code-action` απαιτεί μη κενή είσοδο `anthropic_api_key`; η τιμή χώρου εδώ δεν θα χρησιμοποιηθεί για την πιστοποίηση της πλατφόρμας. Η `ANTHROPIC_CUSTOM_HEADERS` θα αντικαταστήσει την απαιτούμενη Bearer Header για το Ace Data Cloud, το πραγματικό Key προέρχεται μόνο από το GitHub Secret.

## 4. Επαλήθευση

Αφού υποβάλετε το Workflow, στείλτε σε σχόλιο Issue ή PR:

```text
@claude Reply only OK
```

Εάν είναι επιτυχές, το Actions workflow θα ολοκληρωθεί και θα ενημερώσει το αντίστοιχο Issue/PR με το αποτέλεσμα. Εάν η Action υποδείξει ότι λείπουν τα διαπιστευτήρια, επιβεβαιώστε ότι το `dummy-not-used` εξακολουθεί να υπάρχει; εάν είναι 401, ελέγξτε το Secret `ACEDATACLOUD_API_KEY`. Μην εκτυπώνετε το Secret στα logs. Μπορείτε να ρυθμίσετε το `claude_args` κατά βούληση για να ορίσετε το `--max-turns` ή να επιλέξετε το τρέχον διαθέσιμο μοντέλο, αλλά η σύνδεση με το πρότυπο δεν είναι σταθερού μοντέλου.
