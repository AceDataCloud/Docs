Το Claude Code είναι ένα εργαλείο **Agentic Coding** που κυκλοφόρησε η Anthropic, και θεωρείται ένα από τα πιο ισχυρά προγραμματιστικά Agents στον κόσμο. Το Claude Code GitHub Actions μπορεί να ενσωματώσει τις δυνατότητες προγραμματισμού AI στη ροή εργασίας του GitHub σας, απλά με το να αναφέρετε `@claude` σε PR ή Issue, επιτρέποντας στο Claude να αναλύσει αυτόματα τον κώδικα, να δημιουργήσει PR, να υλοποιήσει λειτουργίες και να διορθώσει σφάλματα.

Αυτό το έγγραφο περιγράφει κυρίως πώς να ρυθμίσετε και να χρησιμοποιήσετε το Claude Code GitHub Actions μέσω της υπηρεσίας proxy της AceData Cloud.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Claude Code, μπορείτε πρώτα να επισκεφθείτε τη σελίδα υπηρεσιών [Claude Messages](https://platform.acedata.cloud/documents/claude-messages) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την εγγραφή θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν την υπηρεσία Claude Code.

## Χαρακτηριστικά

- **Άμεση Δημιουργία PR**: Περιγράψτε τις απαιτήσεις, το Claude δημιουργεί αυτόματα ένα πλήρες Pull Request
- **Αυτόματη Υλοποίηση Κώδικα**: Στο Issue, αναφέρετε `@claude`, και το Issue μετατρέπεται σε εκτελέσιμο κώδικα
- **Συμμόρφωση με τις Προδιαγραφές του Έργου**: Διαβάζει αυτόματα το `CLAUDE.md`, τηρώντας το στυλ κώδικα και τις προδιαγραφές του έργου σας
- **Ασφαλές και Αξιόπιστο**: Ο κώδικας εκτελείται στον Runner του GitHub, εξασφαλίζοντας την ασφάλεια των δεδομένων

## Βήματα Ρύθμισης

### Βήμα 1: Εγκατάσταση της Claude GitHub App

Μεταβείτε στο [https://github.com/apps/claude](https://github.com/apps/claude) και εγκαταστήστε την Claude GitHub App στο αποθετήριο σας.

![Σελίδα Εγκατάστασης GitHub Claude App](https://cdn.acedata.cloud/ba4b8df66d.png)

Η App απαιτεί τις παρακάτω άδειες αποθετηρίου:

| Άδεια              | Επίπεδο       | Περιγραφή          |
| ----------------- | ------------ | ----------------- |
| **Contents**      | Read & Write | Τροποποίηση αρχείων αποθετηρίου |
| **Issues**        | Read & Write | Αντίκρισμα Issue  |
| **Pull requests** | Read & Write | Δημιουργία PR και αποστολή αλλαγών |

### Βήμα 2: Προσθήκη API Κλειδιού

Προσθέστε το API κλειδί της AceData Cloud ως μυστικό του αποθετηρίου:

1. Μεταβείτε στις **Ρυθμίσεις** του αποθετηρίου → **Μυστικά και μεταβλητές** → **Δράσεις**
2. Κάντε κλικ στο **Νέο μυστικό αποθετηρίου**
3. Στο Name συμπληρώστε `ANTHROPIC_API_KEY`, και στο Value εισάγετε το API token που αποκτήσατε από την AceData Cloud
4. Κάντε κλικ στο **Προσθήκη μυστικού** για αποθήκευση

> **Σημείωση**: Το API token μπορεί να προβληθεί στην [Κονσόλα AceData Cloud](https://platform.acedata.cloud/console).

### Βήμα 3: Δημιουργία Αρχείου Workflow

Δημιουργήστε το αρχείο `.github/workflows/claude.yml` στο αποθετήριο:

```yaml
name: Claude Code
on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]
  issues:
    types: [opened, assigned]
  pull_request:
    types: [opened, synchronize]

jobs:
  claude:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
```

Εάν χρειάζεται να χρησιμοποιήσετε το API endpoint της AceData Cloud, θα πρέπει επίσης να ρυθμίσετε τις μεταβλητές περιβάλλοντος στο Workflow:

```yaml
name: Claude Code
on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  claude:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
        env:
          ANTHROPIC_BASE_URL: "https://api.acedata.cloud"
```

## Τρόπος Χρήσης

### Χρήση σε Σχόλια Issue ή PR

Αφού ολοκληρωθεί η ρύθμιση, σε οποιοδήποτε σχόλιο Issue ή PR, αναφέρετε `@claude`, και το Claude θα απαντήσει αυτόματα:

```
@claude Υλοποιήστε τη λειτουργία σύμφωνα με την περιγραφή αυτού του Issue
@claude Ελέγξτε την ασφάλεια του κώδικα αυτού του PR
@claude Διορθώστε το TypeError στο component του user dashboard
@claude Πώς πρέπει να υλοποιηθεί η πιστοποίηση χρηστών σε αυτό το endpoint;
```

### Αυτόματη Ανασκόπηση Κώδικα

Δημιουργήστε ένα Workflow που εκτελεί αυτόματα ανασκόπηση κώδικα όταν ανοίγει ένα PR:

```yaml
name: Code Review
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          prompt: "/review"
          claude_args: "--max-turns 5"
        env:
          ANTHROPIC_BASE_URL: "https://api.acedata.cloud"
```

### Αυτοματοποίηση Προγραμματισμένων Εργασιών

Δημιουργήστε αυτοματοποιημένες εργασίες που εκτελούνται προγραμματισμένα:

```yaml
name: Daily Report
on:
  schedule:
    - cron: "0 9 * * *"

jobs:
  report:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          prompt: "Δημιουργήστε μια περίληψη των υποβολών της προηγούμενης ημέρας και μια αναφορά για τα ανοιχτά Issues"
        env:
          ANTHROPIC_BASE_URL: "https://api.acedata.cloud"
```

## Περιγραφή Παραμέτρων Action

| Παράμετρος            | Περιγραφή                              | Υποχρεωτική  |
| ------------------- | ----------------------------------- | --------- |
| `anthropic_api_key` | API κλειδί                          | Ναι       |
| `prompt`            | Οδηγία προς το Claude (κείμενο ή Skill όπως `/review`) | Όχι       |
| `claude_args`       | Παράμετροι που μεταφέρονται στο CLI του Claude Code | Όχι       |
| `github_token`      | GitHub Token                        | Όχι       |
| `trigger_phrase`    | Προσαρμοσμένη φράση ενεργοποίησης (προεπιλογή `@claude`) | Όχι       |

### Συνηθισμένες Παράμετροι claude_args

```yaml
claude_args: "--max-turns 5 --model claude-sonnet-4-5-20250929"
```

| Παράμετρος          | Περιγραφή            |
| ----------------- | ----------------- |
| `--max-turns`     | Μέγιστος αριθμός διαλόγων (προεπιλογή 10) |
| `--model`         | Το μοντέλο που χρησιμοποιείται |
| `--mcp-config`    | Διαδρομή αρχείου ρύθμισης MCP |
| `--allowed-tools` | Επιτρεπόμενα εργαλεία (χωρισμένα με κόμμα) |
| `--debug`         | Ενεργοποίηση εξόδου αποσφαλμάτωσης |

## Καλές Πρακτικές

### Ρύθμιση του CLAUDE.md

Δημιουργήστε το αρχείο `CLAUDE.md` στον ριζικό κατάλογο του αποθετηρίου, καθορίζοντας τις οδηγίες στυλ κώδικα, τα πρότυπα ανασκόπησης και τις προδιαγραφές του έργου, και το Claude θα τηρεί αυτόματα αυτούς τους κανόνες.

### Προφυλάξεις Ασφαλείας

- **Ποτέ μην** γράφετε το API κλειδί απευθείας στο αρχείο Workflow
- Χρησιμοποιείτε πάντα τα GitHub Secrets (όπως `${{ secrets.ANTHROPIC_API_KEY }}`)
- Περιορίστε τις άδειες του Action στο ελάχιστο απαραίτητο εύρος
- Ελέγξτε χειροκίνητα τις προτάσεις του Claude πριν από την συγχώνευση

### Έλεγχος Κόστους

- Χρησιμοποιήστε σαφείς οδηγίες `@claude` για να μειώσετε τις περιττές κλήσεις API
- Ρυθμίστε λογικούς περιορισμούς `--max-turns` για τον αριθμό διαλόγων
- Ορίστε χρόνο λήξης σε επίπεδο Workflow
- Χρησιμοποιήστε τον έλεγχο ταυτόχρονης εκτέλεσης του GitHub για να περιορίσετε τον αριθμό παράλληλων εκτελέσεων

## Συχνές Ερωτήσεις

### Γιατί το Claude δεν απαντά στην εντολή @claude;

1. Επιβεβαιώστε ότι η Claude GitHub App έχει εγκατασταθεί σωστά
2. Ελέγξτε αν το Workflow είναι ενεργοποιημένο
3. Επιβεβαιώστε ότι το API κλειδί έχει ρυθμιστεί ως μυστικό του αποθετηρίου
4. Βεβαιωθείτε ότι χρησιμοποιείτε `@claude` στο σχόλιο (όχι `/claude`)
### Σφάλμα πιστοποίησης;

1. Επιβεβαιώστε ότι το API κλειδί είναι έγκυρο και έχει επαρκή δικαιώματα
2. Ελέγξτε αν το όνομα του Secret είναι σωστό (`ANTHROPIC_API_KEY`)
3. Εάν χρησιμοποιείτε το `ANTHROPIC_BASE_URL`, επιβεβαιώστε ότι το URL είναι σωστό

### Πώς να δείτε το υπόλοιπο;

Συνδεθείτε στην [Κονσόλα AceData Cloud](https://platform.acedata.cloud/console) για να δείτε το τρέχον υπόλοιπο και την κατάσταση χρήσης του λογαριασμού σας.
