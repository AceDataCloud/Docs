## 1. Απόκτηση API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), μπείτε στις διαθέσιμες εφαρμογές και αντιγράψτε το API Key.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Εγκατάσταση Claude Code

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
```

Ελέγξτε μετά την εγκατάσταση:

```bash
claude --version
```

## 3. Ρύθμιση Ace Data Cloud

Για παγκόσμια χρήση, προσθέστε τις παρακάτω μεταβλητές στο `~/.zshrc` ή `~/.bashrc`：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="το API Key σας"
unset ANTHROPIC_API_KEY
```

Ανοίξτε ξανά το τερματικό ή `source` το αντίστοιχο αρχείο ρύθμισης.

Για να ισχύει μόνο για το τρέχον έργο, μπορείτε να δημιουργήσετε το `.claude/settings.local.json` που έχει προστεθεί στο `.gitignore`：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "το API Key σας"
  }
}
```

Επιλέξτε μία από τις δύο μεθόδους. Μην γράφετε το πραγματικό Key σε κοινόχρηστο `.claude/settings.json` της ομάδας; αν υπάρχει ήδη `ANTHROPIC_API_KEY` στο περιβάλλον, θα πρέπει να το ακυρώσετε πραγματικά και όχι να το ορίσετε ως κενή συμβολοσειρά.

## 4. Εκκίνηση και Επαλήθευση

```bash
cd /path/to/your/project
claude
```

Μέσα, στείλτε μια εργασία μόνο για ανάγνωση, όπως "διαβάστε το README.md και συνοψίστε το σε μία πρόταση". Οι καταγραφές κλήσεων και το υπόλοιπο μπορούν να ελεγχθούν στην [ιστορία χρήσης](https://platform.acedata.cloud/console/usages) και στη [λίστα εφαρμογών](https://platform.acedata.cloud/console/applications).

Αν επιστρέψει 401, ελέγξτε αν το Key είναι πλήρες, αν το παλιό `ANTHROPIC_API_KEY` έχει ακυρωθεί και επανεκκινήστε πλήρως το Claude Code. Το μοντέλο δεν χρειάζεται να είναι σταθερό στη ρύθμιση σύνδεσης, μπορείτε να επιλέξετε το τρέχον διαθέσιμο μοντέλο στο Claude Code.
