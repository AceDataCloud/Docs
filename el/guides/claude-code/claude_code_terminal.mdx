Claude Code είναι ένα εργαλείο **Agentic Coding** που κυκλοφόρησε από την Anthropic, και θεωρείται ένα από τα πιο ισχυρά προγραμματιστικά Agents στον κόσμο. Το τερματικό CLI είναι η κύρια εμπειρία του Claude Code, όπου μπορείτε να εκτελέσετε την εντολή `claude` σε οποιοδήποτε τερματικό και να συνεργαστείτε με την AI μέσω φυσικής γλώσσας.

Αυτό το έγγραφο περιγράφει κυρίως πώς να εγκαταστήσετε, να ρυθμίσετε και να χρησιμοποιήσετε το Claude Code CLI μέσω της υπηρεσίας proxy της AceData Cloud.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Claude Code, μπορείτε πρώτα να επισκεφθείτε τη [σελίδα υπηρεσιών Claude Messages](https://platform.acedata.cloud/documents/claude-messages) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την εγγραφή θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση για να δοκιμάσετε δωρεάν την υπηρεσία Claude Code.

## Εγκατάσταση Claude Code

### Απαιτήσεις Συστήματος

- macOS, Linux ή Windows (συμπεριλαμβανομένου του WSL)
- Το Node.js δεν είναι απαραίτητο, η εγγενής μέθοδος εγκατάστασης θα διαχειριστεί αυτόματα τις εξαρτήσεις

### Μέθοδοι Εγκατάστασης

Το Claude Code υποστηρίζει πολλές μεθόδους εγκατάστασης:

**Μέθοδος 1: Εγγενής Εγκατάσταση (Συνιστάται)**

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows CMD:

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**Μέθοδος 2: Homebrew (macOS / Linux)**

```bash
brew install claude-code
```

**Μέθοδος 3: WinGet (Windows)**

```cmd
winget install Claude.ClaudeCode
```

Η εγγενής εγκατάσταση θα ενημερώνεται αυτόματα στο παρασκήνιο, διατηρώντας πάντα την πιο πρόσφατη έκδοση.

## Ρύθμιση AceData Cloud API

Αφού ολοκληρωθεί η εγκατάσταση, θα σας ζητηθεί να συνδεθείτε με τον επίσημο λογαριασμό της Anthropic. Μπορούμε να χρησιμοποιήσουμε την υπηρεσία proxy της AceData Cloud ρυθμίζοντας τις μεταβλητές περιβάλλοντος, **χωρίς επίσημη συνδρομή**.

### Ρύθμιση Μεταβλητών Περιβάλλοντος

Υπάρχουν δύο τρόποι για να ρυθμίσετε τις μεταβλητές περιβάλλοντος, μπορείτε να επιλέξετε οποιονδήποτε.

**Μέθοδος 1: Ρύθμιση στο αρχείο ρύθμισης του Shell (Συνιστάται)**

Προσθέστε το παρακάτω περιεχόμενο στο αρχείο ρύθμισης του Shell σας (`~/.zshrc`, `~/.bashrc` ή `~/.bash_profile`), αντικαθιστώντας το `{token}` με το API token που αποκτήσατε από τον πίνακα ελέγχου της AceData Cloud:

```bash
# AceData Cloud - Ρύθμιση Proxy Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Μετά την τροποποίηση, εκτελέστε την παρακάτω εντολή για να ενεργοποιήσετε τη ρύθμιση:

```bash
source ~/.zshrc  # ή source ~/.bashrc
```

**Μέθοδος 2: Ρύθμιση στο αρχείο settings.json του Claude Code**

Επεξεργαστείτε το `~/.claude/settings.json` (δημιουργήστε το αν δεν υπάρχει) και προσθέστε τη ρύθμιση `env`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Το πλεονέκτημα αυτής της μεθόδου είναι ότι οι μεταβλητές περιβάλλοντος ισχύουν μόνο για το Claude Code και δεν επηρεάζουν άλλα προγράμματα.

> **Σημείωση**: Το API token μπορεί να προβληθεί στον [πίνακα ελέγχου της AceData Cloud](https://platform.acedata.cloud/console). Η τιμή του `ANTHROPIC_AUTH_TOKEN` θα προστεθεί αυτόματα με το πρόθεμα `Bearer` κατά την αποστολή στον διακομιστή.

## Ξεκινώντας

### Εκκίνηση Διαδραστικής Λειτουργίας

Ανοίξτε το τερματικό, μεταβείτε στον κατάλογο του έργου σας και εκτελέστε:

```bash
cd /path/to/your/project
claude
```

Θα δείτε την οθόνη καλωσορίσματος του Claude Code, απλά πληκτρολογήστε φυσική γλώσσα για να ξεκινήσετε την αλληλεπίδραση.

### Συχνές Εντολές

| Εντολή               | Περιγραφή          | Παράδειγμα                   |
| ---------------- | ----------- | -------------------- |
| `claude`         | Εκκίνηση διαδραστικής λειτουργίας      | `claude`             |
| `claude "εργασία"`    | Εκτέλεση μιας εφάπαξ εργασίας     | `claude "Διόρθωση σφάλματος κατασκευής"`    |
| `claude -p "ερώτηση"` | Εκτέλεση ερώτησης και έξοδος     | `claude -p "Εξήγησε αυτή τη συνάρτηση"` |
| `claude -c`      | Συνεχίστε την πιο πρόσφατη συνομιλία στον τρέχοντα κατάλογο | `claude -c`          |
| `claude -r`      | Επαναφορά προηγούμενης συνομιλίας     | `claude -r`          |
| `claude commit`  | Δημιουργία Git commit   | `claude commit`      |

### Εντολές Διαδραστικής Λειτουργίας

Στη διαδραστική λειτουργία, μπορείτε να χρησιμοποιήσετε τις παρακάτω ενσωματωμένες εντολές:

| Εντολή                | Λειτουργία        |
| ----------------- | --------- |
| `/help`           | Εμφάνιση πληροφοριών βοήθειας    |
| `/clear`          | Εκκαθάριση ιστορικού συνομιλίας    |
| `/config`         | Άνοιγμα πίνακα ρυθμίσεων    |
| `/model`          | Εναλλαγή μοντέλου      |
| `/mcp`            | Διαχείριση υπηρεσίας MCP |
| `/compact`        | Συμπίεση συμφραζομένων     |
| `/memory`         | Διαχείριση μνήμης      |
| `/login`          | Εναλλαγή λογαριασμού      |
| `exit` ή `Ctrl+C` | Έξοδος        |

### Παραδείγματα Διαλόγου

```bash
# Ανάλυση έργου
> τι κάνει αυτό το έργο;

# Διόρθωση σφάλματος
> υπάρχει ένα σφάλμα όπου οι χρήστες μπορούν να υποβάλουν κενές φόρμες - διόρθωσέ το

# Δημιουργία δοκιμών
> γράψε μονάδες δοκιμών για τις συναρτήσεις του υπολογιστή

# Αναδιάρθρωση κώδικα
> αναδιάρθρωσε τη μονάδα αυθεντικοποίησης για να χρησιμοποιεί async/await

# Ενέργειες Git
> κάνε commit τις αλλαγές μου με μια περιγραφική μήνυμα
> δημιούργησε ένα pr για αυτή τη δυνατότητα
```

## Προχωρημένες Χρήσεις

### Pipelines και Σενάριο

Το Claude Code ακολουθεί τη φιλοσοφία του Unix, υποστηρίζοντας pipelines και σενάριο:

```bash
# Παρακολούθηση καταγραφών και αυτόματη ειδοποίηση
tail -f app.log | claude -p "Εάν εντοπιστεί ανωμαλία, ειδοποίησέ με"

# Αυτόματη μετάφραση νέου κειμένου
claude -p "Εάν υπάρχουν νέες συμβολοσειρές κειμένου, μετάφρασέ τες στα γαλλικά και δημιούργησε PR"

# Ανασκόπηση κώδικα
git diff main | claude -p "Ανασκόπησε αυτές τις αλλαγές"
```

### Αναφορά Μεταβλητών Περιβάλλοντος

Ακολουθούν οι κοινές μεταβλητές περιβάλλοντος που υποστηρίζει το Claude Code:

| Μεταβλητή                           | Περιγραφή                                    |
| ---------------------------- | ------------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`       | Προσαρμοσμένη τιμή για την κεφαλίδα Authorization (προσαρτάται αυτόματα το πρόθεμα Bearer) |
| `ANTHROPIC_API_KEY`          | API κλειδί (αποστέλλεται ως κεφαλίδα X-Api-Key)              |
| `ANTHROPIC_BASE_URL`         | Βασικό URL API                            |
| `ANTHROPIC_MODEL`            | Επικαλύπτει το προεπιλεγμένο μοντέλο                                |
| `ANTHROPIC_SMALL_FAST_MODEL` | Μοντέλο επιπέδου Haiku (για εργασίες παρασκηνίου)                     |
| `MAX_THINKING_TOKENS`        | Ρύθμιση προϋπολογισμού Token σκέψης (ορίστε σε 0 για να απενεργοποιήσετε τη λειτουργία σκέψης)            |
| `DISABLE_COST_WARNINGS`      | Ορίστε σε 1 για να απενεργοποιήσετε τις προειδοποιήσεις κόστους                           |

### Αποθήκευση Μνήμης Έργου CLAUDE.md

Δημιουργήστε το αρχείο `CLAUDE.md` στον ριζικό κατάλογο του έργου για να παρέχετε συγκεκριμένες οδηγίες και συμφραζόμενα για το Claude Code. Ο Claude θα φορτώσει αυτό το αρχείο αυτόματα κατά την εκκίνηση.

```markdown
# Περιγραφή Έργου
Αυτό είναι ένα πλήρες έργο Django + Vue.js.

## Κωδικοί Κανόνες
- Χρησιμοποιήστε Python 3.12
- Ακολουθήστε το στυλ κώδικα PEP 8
- Όλα τα API πρέπει να έχουν μονάδες δοκιμών
```

## Συχνές Ερωτήσεις

### Τι να κάνω αν η σύνδεση αποτύχει;
1. Ελέγξτε αν το αρχείο `~/.claude/config.json` έχει δημιουργηθεί σωστά, με περιεχόμενο `{"primaryApiKey": "self"}`
2. Επιβεβαιώστε ότι οι μεταβλητές περιβάλλοντος έχουν ρυθμιστεί σωστά:
   ```bash
   echo $ANTHROPIC_AUTH_TOKEN
   echo $ANTHROPIC_BASE_URL
   ```
3. Επιβεβαιώστε ότι το API token είναι έγκυρο (μπορείτε να το δείτε στην [κονσόλα](https://platform.acedata.cloud/console))
4. Δοκιμάστε να επανεκκινήσετε το τερματικό

### command not found: claude

Εάν μετά την εγκατάσταση εμφανιστεί το μήνυμα `command not found`, δοκιμάστε:

1. Κλείστε και ανοίξτε ξανά το τερματικό
2. Ελέγξτε το PATH: `echo $PATH`
3. Επανεγκαταστήστε: `curl -fsSL https://claude.ai/install.sh | bash`

### Πώς να δείτε το υπόλοιπο;

Συνδεθείτε στην [κονσόλα AceData Cloud](https://platform.acedata.cloud/console) για να δείτε το τρέχον υπόλοιπο και τη χρήση του λογαριασμού σας.
