Το Claude Code συνδέεται με το Coding Plan μέσω του πρωτοκόλλου Anthropic Messages, παρέχοντας αυτή τη στιγμή δύο σημεία πρόσβασης: τερματικό και VS Code.

| Χρήση Σημείου Πρόσβασης | Οδηγίες Ρύθμισης                                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------ |
| Τερματικό / CLI    | [Ρύθμιση τερματικού Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code            | [Ρύθμιση Claude Code για VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## Κοινές Ρυθμίσεις

- Βασική Διεύθυνση URL: `https://api.acedata.cloud`
- API Token: Λάβετε από την Εφαρμογή Coding και ρυθμίστε το μέσω του `ANTHROPIC_AUTH_TOKEN` στις οδηγίες
- ID Μοντέλου: Επιλέξτε από τον κατάλογο ζωντανών μοντέλων
- Μετά την τροποποίηση των ρυθμίσεων: Επανεκκινήστε το Claude Code; Οι χρήστες του VS Code πρέπει να ανανεώσουν το παράθυρο

Μην διατηρείτε ταυτόχρονα το παλιό `ANTHROPIC_API_KEY`, ούτε να γράφετε το πραγματικό Token σε κοινά αρχεία ομάδας.

Επιστρέψτε στο [Κέντρο Ρυθμίσεων Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
