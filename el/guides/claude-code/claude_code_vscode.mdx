Claude Code είναι ένα εργαλείο **Agentic Coding** που κυκλοφόρησε από την Anthropic, και θεωρείται ένας από τους πιο ισχυρούς προγραμματιστικούς πράκτορες στον κόσμο. Η επέκταση Claude Code για το VS Code προσφέρει μια εγγενή γραφική διεπαφή, υποστηρίζει inline Diff προβολές, αναφορές `@`-mentions, προγραμματισμένες αναθεωρήσεις και άλλες δυνατότητες, και είναι ο προτεινόμενος τρόπος χρήσης του Claude Code στο VS Code.

Αυτό το έγγραφο περιγράφει κυρίως πώς να ρυθμίσετε και να χρησιμοποιήσετε την επέκταση Claude Code στο VS Code μέσω της υπηρεσίας proxy της AceData Cloud.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Claude Code, μπορείτε πρώτα να επισκεφθείτε τη σελίδα υπηρεσιών [Claude Messages](https://platform.acedata.cloud/documents/claude-messages) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την εγγραφή ή σύνδεση θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση για να δοκιμάσετε δωρεάν την υπηρεσία Claude Code.

## Εγκατάσταση Πρόσθετου

### Απαιτήσεις Συστήματος

- VS Code 1.98.0 ή νεότερη έκδοση (υποστηρίζει επίσης το Cursor)

### Βήματα Εγκατάστασης

Στο κατάστημα επεκτάσεων του VS Code / Cursor, πατήστε `Cmd+Shift+X` (Mac) ή `Ctrl+Shift+X` (Windows/Linux) για να ανοίξετε την προβολή επεκτάσεων, αναζητήστε **Claude Code**, βρείτε το πρόσθετο που δημοσιεύθηκε από την Anthropic και κάντε κλικ στο «Install» για να το εγκαταστήσετε:

![Claude Code πρόσθετο στο VS Code Marketplace](https://cdn.acedata.cloud/10ddf71320.png)

Μπορείτε επίσης να το εγκαταστήσετε απευθείας μέσω των παρακάτω συνδέσμων:

- [Σύνδεσμος εγκατάστασης VS Code](vscode:extension/anthropic.claude-code)
- [Σύνδεσμος εγκατάστασης Cursor](cursor:extension/anthropic.claude-code)

Μετά την εγκατάσταση, επιλέξτε εμπιστοσύνη στην αναδυόμενη ειδοποίηση για να ολοκληρώσετε την εγκατάσταση.

> Εάν το πρόσθετο δεν εμφανίζεται μετά την εγκατάσταση, επανεκκινήστε το VS Code ή εκτελέστε την εντολή «Developer: Reload Window» από την εντολή πίνακα.

## Ρύθμιση AceData Cloud API

Κατά την πρώτη φορά που ανοίγετε το πρόσθετο, θα σας ζητηθεί να συνδεθείτε στον επίσημο λογαριασμό της Anthropic. Μπορούμε να παραλείψουμε τη σύνδεση μέσω της ρύθμισης του API proxy της AceData Cloud, **χωρίς επίσημη συνδρομή**.

### Βήμα 1: Ρύθμιση Μεταβλητών Περιβάλλοντος

Μπορείτε να επιλέξετε να ρυθμίσετε τις μεταβλητές περιβάλλοντος σε οποιαδήποτε από τις παρακάτω τοποθεσίες:

**Επιλογή A: Ρύθμιση σε επίπεδο χρήστη (ισχύει για όλα τα έργα)**

Επεξεργαστείτε το `~/.claude/settings.json` (εάν δεν υπάρχει, δημιουργήστε το), προσθέστε τη ρύθμιση `env`, αντικαθιστώντας το `{token}` με το API token που αποκτήσατε από την κονσόλα AceData Cloud:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

**Επιλογή B: Ρύθμιση σε επίπεδο έργου (μόνο για το τρέχον έργο)**

Δημιουργήστε το `.claude/settings.json` (κοινή ρύθμιση) ή το `.claude/settings.local.json` (προσωπική ρύθμιση, gitignored) στον ριζικό φάκελο του έργου:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Σημείωση**: Το API token μπορεί να προβληθεί στην [κονσόλα AceData Cloud](https://platform.acedata.cloud/console). Η τιμή του `ANTHROPIC_AUTH_TOKEN` θα προστεθεί αυτόματα με το πρόθεμα `Bearer` που θα σταλεί στον διακομιστή. Η ρύθμιση σε επίπεδο έργου έχει προτεραιότητα έναντι της ρύθμισης σε επίπεδο χρήστη. Συνιστάται να χρησιμοποιείτε το `.claude/settings.json` για κοινές ρυθμίσεις σε ομαδικά έργα, ενώ οι προσωπικές ευαίσθητες πληροφορίες να τοποθετούνται στο `.claude/settings.local.json`.

### Βήμα 2: Απενεργοποίηση Υπενθύμισης Σύνδεσης (προαιρετικό)

Εάν δεν θέλετε να βλέπετε την υπενθύμιση σύνδεσης κάθε φορά που ανοίγετε, μπορείτε να επιλέξετε την επιλογή **Disable Login Prompt** στις ρυθμίσεις του VS Code:

Στις ρυθμίσεις, αναζητήστε «Claude Code login», βρείτε την επιλογή **Disable Login Prompt** και επιλέξτε την.

Αφού ολοκληρώσετε τη ρύθμιση, ανοίξτε ξανά τον πίνακα του πρόσθετου Claude Code για να αρχίσετε να το χρησιμοποιείτε κανονικά.

## Άνοιγμα Πίνακα Claude Code

Αφού ολοκληρώσετε την εγκατάσταση και τη ρύθμιση, υπάρχουν πολλοί τρόποι για να ανοίξετε το Claude Code:

| Τρόπος         | Ενέργεια                                             |
| ---------- | ---------------------------------------------- |
| **Εργαλειοθήκη Επεξεργαστή** | Κάντε κλικ στο εικονίδιο ✦ Spark στην επάνω δεξιά γωνία του επεξεργαστή (χρειάζεται να έχετε ανοίξει ένα αρχείο)                 |
| **Γραμμή Κατάστασης**    | Κάντε κλικ στο «✱ Claude Code» στα δεξιά της κάτω γραμμής κατάστασης (δεν χρειάζεται να έχετε ανοίξει αρχείο)              |
| **Πίνακας Εντολών**   | `Cmd+Shift+P` / `Ctrl+Shift+P`, αναζητήστε «Claude Code» |
| **Συντόμευση**    | `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux) για εναλλαγή εστίασης  |

Σε αντίθεση με εργαλεία όπως το Cursor / Copilot που χρησιμοποιούν πλαϊνές μπάρες, το Claude Code χρησιμοποιεί προεπιλεγμένα την **προβολή περιοχής επεξεργασίας** ως περιοχή συνομιλίας, προσφέροντας μεγαλύτερη ορατότητα και πλουσιότερη παρουσίαση περιεχομένου. Μπορείτε επίσης να σύρετε τον πίνακα στην πλαϊνή μπάρα ή σε άλλη θέση.

![Πίνακας Claude Code στο VS Code](https://cdn.acedata.cloud/b84b878420.jpg)

## Βασική Χρήση

### Διάλογος και Αλληλεπίδραση

Μπορείτε να εισάγετε φυσική γλώσσα απευθείας στον πίνακα του Claude Code για να αλληλεπιδράσετε με τον Claude. Για παράδειγμα:

- «Βοήθησέ με να αναλύσω τη συνολική αρχιτεκτονική αυτού του έργου»
- «Αυτή η γραμμή κώδικα έχει Bug, βοήθησέ με να το διορθώσω»
- «Αναδιάρθρωσε αυτή τη συνάρτηση για να βελτιώσεις την αναγνωσιμότητα»
- «Γράψε μονάδες δοκιμών για αυτό το module»

Ο Claude Code θα κατανοήσει αυτόματα το πλαίσιο του κώδικα σας, αναλύοντας και επεξεργαζόμενος διασυνοριακά αρχεία. Όταν ο Claude χρειάζεται να τροποποιήσει αρχεία, θα εμφανίσει την προβολή Diff, όπου μπορείτε να επιλέξετε να αποδεχθείτε ή να απορρίψετε τις τροποποιήσεις.

![Διάλογος και Υποδείξεις του Claude Code στο VS Code](https://cdn.acedata.cloud/650377f5cc.png)

### Αναφορές Πλαισίου

Μπορείτε να χρησιμοποιήσετε το σύμβολο `@` για να αναφέρετε συγκεκριμένα αρχεία ή πλαίσια κατά τη διάρκεια του διαλόγου:

- `@filename.py` — Αναφορά σε συγκεκριμένο αρχείο (υποστηρίζει ασαφή αντιστοίχιση)
- `@src/components/` — Αναφορά σε ολόκληρο τον φάκελο (χρειάζεται κάθετο στο τέλος)
- `@terminal:name` — Αναφορά σε έξοδο τερματικού

Αφού επιλέξετε τον κώδικα στον επεξεργαστή, πατήστε `Option+K` (Mac) / `Alt+K` (Windows/Linux) για να εισάγετε γρήγορα την αναφορά `@` (π.χ. `@app.ts#5-10`).

### Εντολές Σλάσας

Κάντε κλικ στο εικονίδιο `/` στο πλαίσιο διαλόγου ή απλά πληκτρολογήστε `/` για να χρησιμοποιήσετε πλούσιες ενσωματωμένες δυνατότητες:

Οι συχνά χρησιμοποιούμενες εντολές περιλαμβάνουν:

| Εντολή         | Λειτουργία           |
| ---------- | ------------ |
| `/new`     | Δημιουργία νέου διαλόγου         |
| `/model`   | Εναλλαγή μοντέλου         |
| `/compact` | Συμπίεση πλαισίου        |
| `/mcp`     | Ρύθμιση υπηρεσίας MCP    |
| `/config`  | Άνοιγμα ρυθμίσεων         |
| `/usage`   | Προβολή χρήσης         |
| `/memory`  | Διαχείριση μνήμης του Claude |
| `/help`    | Εμφάνιση πληροφοριών βοήθειας       |

### Προβολή Ιστορικού Διαλόγου

Κάντε κλικ στο αναπτυσσόμενο μενού στην κορυφή του πίνακα για να δείτε το ιστορικό διαλόγου, υποστηρίζει αναζήτηση με λέξεις-κλειδιά και περιήγηση κατά χρονικά διαστήματα (Σήμερα, Χθες, Τελευταίες 7 ημέρες κ.λπ.), διευκολύνοντας την αναδρομή προηγούμενων αλληλεπιδράσεων. Κάντε κλικ σε οποιονδήποτε διάλογο για να επαναφέρετε την πλήρη ιστορία μηνυμάτων.

### Αναθεώρηση Αλλαγών Κώδικα

Όταν ο Claude χρειάζεται να τροποποιήσει αρχεία, θα εμφανίσει την προβολή Diff, δείχνοντας τη σύγκριση του αρχικού κώδικα με τις τροποποιήσεις. Μπορείτε να επιλέξετε να αποδεχθείτε ή να απορρίψετε κάθε τροποποίηση, ή μπορείτε να πείτε στον Claude πώς θέλετε να γίνει διαφορετικά:
![VS Code 中的 Diff 对比视图](https://cdn.acedata.cloud/c42381ea9f.png)

### Μοντέλο Δικαιωμάτων

Μπορείτε να αλλάξετε διαφορετικά μοντέλα δικαιωμάτων μέσω του δείκτη μοντέλου στο κάτω μέρος του πίνακα:

| Μοντέλο                | Περιγραφή                  |
| --------------------- | ----------------------- |
| **Default（Ask）**      | Ρωτά επιβεβαίωση πριν από κάθε ενέργεια (προεπιλογή)           |
| **Plan**              | Ο Claude πρώτα καταρτίζει σχέδιο και περιμένει έγκριση, εκτελεί μόνο μετά την επιβεβαίωση |
| **acceptEdits**       | Αυτόματη αποδοχή επεξεργασιών αρχείων, αλλά οι εντολές τερματικού απαιτούν επιβεβαίωση      |
| **bypassPermissions** | Παράκαμψη όλων των προειδοποιήσεων δικαιωμάτων, πλήρης αυτοματοποίηση (χρησιμοποιήστε με προσοχή)    |

### Παράλληλες Συνεδρίες

Χρησιμοποιώντας την εντολή **Open in New Tab** ή **Open in New Window** από τον πίνακα εντολών μπορείτε να ξεκινήσετε πολλές ανεξάρτητες συνομιλίες, κάθε μία διατηρεί τη δική της ιστορία και συμφραζόμενα, επιτρέποντας την παράλληλη επεξεργασία διαφορετικών εργασιών.

## Άλλες Ρυθμίσεις

### Αλλαγή Μοντέλου

Ο Claude Code υποστηρίζει την αλλαγή διαφορετικών μοντέλων, όπως Claude Sonnet, Claude Opus κ.λπ. Μπορείτε να το ρυθμίσετε μέσω της εντολής `/model` ή στις ρυθμίσεις του πρόσθετου στην επιλογή **Selected Model**.

### Αυτόματο Μοντέλο

Στις ρυθμίσεις του πρόσθετου μπορείτε να ορίσετε το **Initial Permission Mode** σε `bypassPermissions`, έτσι ώστε ο Claude Code να εκτελεί επεξεργασίες αρχείων, εντολές τερματικού κ.λπ. χωρίς να ζητά επιβεβαίωση κάθε φορά, επιτυγχάνοντας πλήρη αυτοματοποίηση.

Μπορείτε επίσης να το ορίσετε σε `acceptEdits` για να επιτύχετε αυτόματη αποδοχή επεξεργασιών, αλλά οι εντολές τερματικού θα απαιτούν ακόμη επιβεβαίωση.

> **Σημείωση**: Πριν ενεργοποιήσετε το αυτόματο μοντέλο, βεβαιωθείτε ότι κατανοείτε τους κινδύνους του, συνιστάται να το χρησιμοποιείτε σε αξιόπιστα περιβάλλοντα έργου.

### Χρήση CLI στο Τερματικό

Αν προτιμάτε στυλ γραμμής εντολών, μπορείτε να επιλέξετε **Use Terminal** στις ρυθμίσεις του VS Code, ο Claude Code θα τρέχει σε λειτουργία CLI στο ενσωματωμένο τερματικό. Μπορείτε επίσης να ανοίξετε απευθείας το ενσωματωμένο τερματικό του VS Code και να εκτελέσετε την εντολή `claude`.

## Συχνές Ερωτήσεις

### Τι να κάνω αν η σύνδεση αποτύχει;

1. Βεβαιωθείτε ότι οι ρυθμίσεις περιβάλλοντος στο `~/.claude/settings.json` ή `.claude/settings.json` είναι σωστές, ειδικά το `ANTHROPIC_AUTH_TOKEN` και το `ANTHROPIC_BASE_URL`
2. Βεβαιωθείτε ότι το API token είναι έγκυρο (μπορείτε να το δείτε στην [κονσόλα](https://platform.acedata.cloud/console))
3. Ελέγξτε αν η σύνδεση στο διαδίκτυο είναι καλή, βεβαιωθείτε ότι μπορείτε να αποκτήσετε πρόσβαση στο `https://api.acedata.cloud`
4. Επανεκκινήστε το VS Code και δοκιμάστε ξανά

### Το εικονίδιο Spark δεν εμφανίζεται;

1. Βεβαιωθείτε ότι έχετε ανοίξει ένα αρχείο (μόνο το άνοιγμα φακέλου δεν αρκεί)
2. Βεβαιωθείτε ότι η έκδοση του VS Code είναι 1.98.0 ή υψηλότερη
3. Εκτελέστε την εντολή «Developer: Reload Window» από τον πίνακα εντολών
4. Ή απλά κάντε κλικ στο εικονίδιο «✱ Claude Code» στη κάτω γραμμή κατάστασης

### Πώς να ελέγξω το υπόλοιπο;

Συνδεθείτε στην [κονσόλα AceData Cloud](https://platform.acedata.cloud/console) για να δείτε το τρέχον υπόλοιπο και την κατάσταση χρήσης του λογαριασμού σας.
