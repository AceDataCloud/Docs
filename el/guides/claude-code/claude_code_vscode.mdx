Το Claude Code είναι ένα εργαλείο προγραμματισμού που κυκλοφόρησε η Anthropic, και θεωρείται ένας από τους πιο ισχυρούς προγραμματιστικούς πράκτορες στον κόσμο. Η επέκταση του Claude Code για το VS Code προσφέρει μια εγγενή γραφική διεπαφή και είναι ο προτεινόμενος τρόπος χρήσης του Claude Code στο VS Code.

Αυτό το έγγραφο περιγράφει κυρίως πώς να ρυθμίσετε και να χρησιμοποιήσετε την επέκταση του Claude Code στο VS Code μέσω της υπηρεσίας proxy του Ace Data Cloud.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Claude Code, μπορείτε πρώτα να επισκεφθείτε την [κονσόλα του Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε για να δοκιμάσετε δωρεάν την υπηρεσία Claude Code.

## Εγκατάσταση της Επέκτασης Claude Code

Στην αγορά επεκτάσεων του VS Code, αναζητήστε **Claude Code**, επιβεβαιώστε ότι ο εκδότης είναι **Anthropic** και στη συνέχεια εγκαταστήστε την. Μετά την ολοκλήρωση της εγκατάστασης, θα εμφανιστεί η είσοδος του Claude Code στην γραμμή εργαλείων.

## Ρύθμιση του Ace Data Cloud API

Κατά την πρώτη φορά που ανοίγετε την επέκταση, θα σας ζητηθεί να συνδεθείτε με τον επίσημο λογαριασμό της Anthropic. Μπορούμε να παραλείψουμε την επίσημη σύνδεση και να χρησιμοποιήσουμε την υπηρεσία proxy API του Ace Data Cloud, χωρίς να απαιτείται επίσημη συνδρομή.

Η επέκταση και το τερματικό CLI διαβάζουν την ίδια σειρά ρυθμίσεων του Claude Code. Για πλήρη πιστοποίηση, διαχείριση συγκρούσεων διαπιστευτηρίων και παγκόσμιες ρυθμίσεις, δείτε τον [Οδηγό Ρύθμισης Τερματικού Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration). Εάν θέλετε να ισχύει μόνο για το τρέχον έργο, δημιουργήστε ένα αρχείο `.claude/settings.local.json` στον ριζικό φάκελο του έργου που έχει προστεθεί στο `.gitignore`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Όπου `{token}` είναι το API Key που μόλις αντιγράψατε. Εάν στο περιβάλλον εκκίνησης του VS Code υπάρχει ήδη παλιό `ANTHROPIC_API_KEY`, παρακαλώ πρώτα να εκτελέσετε `unset ANTHROPIC_API_KEY` σε αυτό το περιβάλλον; Μην χρησιμοποιείτε κενή συμβολοσειρά για καθαρισμό και μην τοποθετείτε το πραγματικό Key σε κοινόχρηστο αρχείο `.claude/settings.json`.

Ακολουθεί η ρύθμιση που ολοκληρώθηκε τοπικά με το VS Code 1.136.1 και την επέκταση Claude Code 2.1.251. Η εικόνα χρησιμοποιεί κλειδί θέσης για να αποφευχθεί η διαρροή πραγματικών διαπιστευτηρίων:

![Ρύθμιση του Ace Data Cloud Claude Code στο VS Code](https://cdn.acedata.cloud/f925e9e9597b.png)

Μετά την ολοκλήρωση της ρύθμισης, επανεκκινήστε το VS Code.

> Σημείωση: Η παραπάνω ρύθμιση ισχύει μόνο για το τρέχον έργο και συνιστάται να προσθέσετε τη διαδρομή του αρχείου ρυθμίσεων `.claude/settings.local.json` στο αρχείο `.gitignore`, για να αποφευχθεί η μεταφορά στο απομακρυσμένο αποθετήριο.

Εάν θέλετε να ισχύει για όλα τα έργα, μπορείτε να τοποθετήσετε αυτή τη ρύθμιση απευθείας στον φάκελο χρήστη. Η αντίστοιχη διαδρομή είναι `~/.claude/settings.json`,

> Σημείωση: Μετά την ολοκλήρωση της ρύθμισης, παρακαλώ επανεκκινήστε ή επαναφορτώστε το VS Code για να ισχύσουν οι παραπάνω ρυθμίσεις.

## Βασική Χρήση

Αφού ρυθμιστεί, στείλτε μια απλή αναγνωστική εργασία στον πίνακα του Claude Code, όπως "Διαβάστε το README.md και συνοψίστε το σε μία πρόταση". Μετά την επιτυχία της εργασίας, μπορείτε να ελέγξετε αυτή την κλήση στην [Ιστορία Χρήσης](https://platform.acedata.cloud/console/usages).

## Πώς να δείτε την υπόλοιπη πίστωση

Μέσω της [κονσόλας του Ace Data Cloud - Λίστα Εφαρμογών](https://platform.acedata.cloud/console/applications), μπορείτε να δείτε την υπόλοιπη πίστωση του τρέχοντος λογαριασμού.

Μέσω της [κονσόλας του Ace Data Cloud - Ιστορία Χρήσης](https://platform.acedata.cloud/console/usages) μπορείτε να δείτε όλη την ιστορία χρήσης και τις λεπτομέρειες χρέωσης.
