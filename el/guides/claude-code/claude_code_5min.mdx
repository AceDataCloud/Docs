Αυτό το έγγραφο έχει έναν μόνο στόχο: να σας βοηθήσει **εντός 5 λεπτών** να εκτελέσετε την πρώτη εντολή Claude Code μέσω του proxy του AceData Cloud. Ο πλήρης οδηγός βρίσκεται στα υποέγγραφα για κάθε IDE ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations))· εδώ ακολουθούμε μόνο την ταχύτερη διαδρομή «**τερματικό CLI** + **επέκταση VS Code**».

> **Γιατί να χρησιμοποιήσετε το proxy του AceData Cloud για Claude Code**:
> - Άμεση σύνδεση στην Κίνα, χωρίς ανάγκη VPN
> - Χαμηλότερο κόστος σε σύγκριση με την επίσημη πλατφόρμα (χρέωση ανά Token)
> - Το ίδιο κλειδί υποστηρίζει ταυτόχρονα Claude Messages API + πρωτόκολλο Claude Code Token

## 1ο Λεπτό: Αίτηση Πιστοποιητικών

Ανοίξτε τη σελίδα [Claude Messages](https://platform.acedata.cloud/documents/claude-messages) και κάντε κλικ στο κουμπί «**Acquire**»:

![](https://cdn.acedata.cloud/nyq0xz.png)

Η πλατφόρμα θα δημιουργήσει αυτόματα μια Εφαρμογή και θα σας δώσει δωρεάν όρια. Καταγράψτε τα δύο στοιχεία **Base URL** + **API Token** από τη σελίδα λεπτομερειών — θα τα χρειαστείτε για τα επόμενα 5 βήματα.

| Πεδίο | Τιμή | Χρήση |
|------|------|------|
| `BASE_URL` | `https://api.acedata.cloud/claude` | Συμβατό σημείο εισόδου Claude Messages |
| `API_TOKEN` | `sk-...` (αντιγράψιμο από τη σελίδα) | Κεφαλίδα αυθεντικοποίησης συμβατή με Anthropic |

## 2ο Λεπτό: Εγκατάσταση Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Μετά την εγκατάσταση, ανοίξτε νέο τερματικό και επιβεβαιώστε την εκτέλεση:

```bash
claude --version
```

> Θα δείτε τον αριθμό έκδοσης. Το Claude Code περιλαμβάνει το Node.js runtime, δεν εξαρτάται από την έκδοση Node στο μηχάνημά σας.

## 3ο Λεπτό: Ρύθμιση Μεταβλητών Περιβάλλοντος για AceData Cloud

Μην ακολουθήσετε τη διαδικασία `claude login` της επίσημης πλατφόρμας, αλλά αντικαταστήστε με μεταβλητές περιβάλλοντος. Επιλέξτε μία από τις δύο μεθόδους:

**Μέθοδος Α: προσωρινή (μόνο για την τρέχουσα συνεδρία Shell)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud/claude"
export ANTHROPIC_AUTH_TOKEN="sk-το-Token-σας"
```

**Μέθοδος Β: μόνιμη (συνιστάται)**

Προσθέστε τις δύο παραπάνω γραμμές στο `~/.zshrc` ή `~/.bashrc` και μετά κάντε `source`.

> **Συχνά λάθη**: Το όνομα της μεταβλητής πρέπει να είναι `ANTHROPIC_AUTH_TOKEN`, όχι `ANTHROPIC_API_KEY`. Αν χρησιμοποιήσετε λάθος όνομα, το Claude Code θα επιστρέψει στο επίσημο endpoint και θα λάβετε σφάλμα 401.

## 4ο Λεπτό: Εκτέλεση της Πρώτης Εντολής

Μπείτε σε οποιοδήποτε Git αποθετήριο και τρέξτε:

```bash
claude
```

Αν σας ζητηθεί να συνδεθείτε την πρώτη φορά, πατήστε `Esc` για να παρακάμψετε. Έπειτα πληκτρολογήστε:

```
列出当前项目的依赖，并简要解释每个的用途。
```

Κανονικά, θα δείτε το Claude να χρησιμοποιεί εργαλεία όπως `read_file` / `glob` / `grep` για να περιηγηθεί στο αποθετήριο και να εμφανίσει τη λίστα. Η γραμμή κατάστασης στο κάτω μέρος θα δείχνει `connected to api.acedata.cloud` — αυτό είναι το κρίσιμο σημάδι ότι ο proxy λειτουργεί.

## 5ο Λεπτό: Σύνδεση της Επέκτασης VS Code

1. Ανοίξτε το VS Code → Πίνακας Επεκτάσεων → Αναζητήστε `Claude Code` και εγκαταστήστε την επίσημη επέκταση της Anthropic.
2. Πατήστε **Cmd+Shift+P** → Πληκτρολογήστε `Claude Code: Set Custom API Endpoint`.
3. Εισάγετε `https://api.acedata.cloud/claude` και πατήστε Enter.
4. Εκτελέστε ξανά `Claude Code: Set API Token` και εισάγετε το Token σας.

Με επιτυχία, θα εμφανιστεί το πάνελ Claude Code στην πλαϊνή μπάρα, όπου μπορείτε να σύρετε αρχεία για ερωτήσεις ή να κάνετε `@-mention` σε αρχεία για προτάσεις αλλαγών. Όλη η χρέωση γίνεται μέσω AceData Cloud.

## Επαλήθευση ότι χρησιμοποιείτε τον proxy

Πληκτρολογήστε στη συνομιλία Claude Code:

```
访问 https://api.acedata.cloud/whoami 并告诉我返回了什么
```

Αν λάβετε τις πληροφορίες του λογαριασμού σας (`{user_id, plan, ...}`), σημαίνει ότι το αίτημα περνάει όντως από το edge του AceData Cloud. Αν δείτε σφάλμα 401 με επίσημο domain, ελέγξτε ξανά το όνομα των μεταβλητών περιβάλλοντος στο 3ο λεπτό.

## 5 Συχνές Ερωτήσεις

**Ε: Έτρεξα `claude login` και μετά άλλαξα τις μεταβλητές περιβάλλοντος για AceData, γιατί δεν λειτουργεί;**  
Α: Το `claude login` γράφει το επίσημο token στο `~/.claude/.credentials.json`, το οποίο έχει **προτεραιότητα έναντι των μεταβλητών περιβάλλοντος**. Διαγράψτε αυτό το αρχείο και κάντε `source ~/.zshrc` ξανά.

**Ε: Μπορώ να χρησιμοποιήσω μοντέλα όπως `--model claude-opus-4-7`;**  
Α: Ναι. Ο proxy του AceData Cloud προωθεί το πεδίο model, υποστηρίζοντας όλα τα δημόσια μοντέλα Anthropic καθώς και τα επεκταμένα `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5`.

**Ε: Μπορώ να ρυθμίσω πολλαπλά προφίλ (προσωπικό + εταιρικό);**  
Α: Ναι. Το Claude Code υποστηρίζει πολλαπλά προφίλ στο `~/.claude/settings.json`. Εναλλακτικά, δημιουργήστε δύο shell functions `claude_personal` / `claude_work` που κάνουν export διαφορετικά `ANTHROPIC_AUTH_TOKEN` και καλούν `claude $@`.

**Ε: Μπορώ να το τρέξω σε GitHub Actions;**  
Α: Ναι. Δείτε τον οδηγό [Claude Code GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**Ε: Τι γίνεται όταν εξαντληθούν τα δωρεάν όρια;**  
Α: Μεταβείτε στο [Διαχείριση Εφαρμογών](https://platform.acedata.cloud/applications) → επιλέξτε την εφαρμογή Claude → κάντε Topup (χρέωση ανά Token) ή μεταβείτε σε συνδρομή με πόντους.
