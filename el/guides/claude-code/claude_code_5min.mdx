Αυτό το έγγραφο έχει έναν μόνο στόχο: να σε βοηθήσει **εντός 5 λεπτών** να εκτελέσεις την πρώτη εντολή Claude Code χρησιμοποιώντας τον proxy AceData Cloud. Για πλήρεις οδηγίες, δες τα υποέγγραφα για κάθε IDE ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)). Αυτό το άρθρο ακολουθεί μόνο την ταχύτερη διαδρομή «**τερματικό CLI** + **επέκταση VS Code**».

> **Γιατί να χρησιμοποιήσεις τον proxy AceData Cloud για Claude Code**:
> - Άμεση σύνδεση στην Κίνα, χωρίς να χρειάζεται VPN
> - Χαμηλότερο κόστος σε σύγκριση με την επίσημη υπηρεσία (χρέωση ανά token πλατφόρμας)
> - Το ίδιο κλειδί υποστηρίζει ταυτόχρονα το Claude Messages API και το πρωτόκολλο Claude Code Token

## 1ο Λεπτό: Αίτηση Πιστοποιητικών

Άνοιξε τη σελίδα [Claude Messages](https://platform.acedata.cloud/documents/claude-messages) και πάτησε το κουμπί «**Acquire**»:

![](https://cdn.acedata.cloud/nyq0xz.png)

Η πλατφόρμα θα δημιουργήσει αυτόματα μια Εφαρμογή και θα σου δώσει δωρεάν όρια. Κατέγραψε τα **Base URL** και **API Token** από τη σελίδα λεπτομερειών — θα τα χρειαστείς στα επόμενα 5 βήματα.

| Πεδίο | Τιμή | Χρήση |
|------|------|------|
| `BASE_URL` | `https://api.acedata.cloud` | Συμβατό σημείο εισόδου Claude Messages |
| `API_TOKEN` | `sk-...` (αντιγράφεται από τη σελίδα λεπτομερειών) | Κεφαλίδα ταυτοποίησης συμβατή με Anthropic |

## 2ο Λεπτό: Εγκατάσταση Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Μετά την εγκατάσταση, άνοιξε νέο τερματικό και επιβεβαίωσε ότι τρέχει:

```bash
claude --version
```

> Θα δεις τον αριθμό έκδοσης. Το Claude Code περιλαμβάνει το Node.js runtime, δεν εξαρτάται από την έκδοση Node της μηχανής σου.

## 3ο Λεπτό: Ορισμός Μεταβλητών Περιβάλλοντος για AceData Cloud

Μην ακολουθήσεις τη διαδικασία `claude login` της επίσημης υπηρεσίας, αλλά αντικατέστησε με μεταβλητές περιβάλλοντος. Διάλεξε μία από τις δύο μεθόδους:

**Μέθοδος Α: προσωρινή (μόνο για την τρέχουσα συνεδρία Shell)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-το-Token-σου"
```

**Μέθοδος Β: μόνιμη (συνιστάται)**

Πρόσθεσε τις παραπάνω δύο γραμμές στο `~/.zshrc` ή `~/.bashrc` και μετά τρέξε `source` στο αρχείο.

> **Συνηθισμένο λάθος**: η μεταβλητή πρέπει να λέγεται `ANTHROPIC_AUTH_TOKEN`, όχι `ANTHROPIC_API_KEY`. Αν χρησιμοποιήσεις λάθος όνομα, το Claude Code θα επιστρέψει 401 από το επίσημο endpoint.

## 4ο Λεπτό: Εκτέλεση της Πρώτης Εντολής

Μπες σε οποιοδήποτε αποθετήριο Git και τρέξε:

```bash
claude
```

Αν ζητηθεί σύνδεση την πρώτη φορά, πάτησε `Esc` για να παρακάμψεις. Στη συνέχεια, πληκτρολόγησε:

```
Λίστα με τις εξαρτήσεις του τρέχοντος έργου και σύντομη εξήγηση της χρήσης κάθε μίας.
```

Κανονικά θα δεις το Claude να χρησιμοποιεί εργαλεία όπως `read_file` / `glob` / `grep` για να εξερευνήσει το αποθετήριο και να σου δώσει τη λίστα. Αν το μοντέλο ανταποκριθεί σωστά και δεν επιστρέψει 401, σημαίνει ότι ο proxy λειτουργεί.

## 5ο Λεπτό: Σύνδεση της Επέκτασης VS Code

1. Άνοιξε το VS Code → Πίνακας Επεκτάσεων → Αναζήτησε `Claude Code` και εγκατέστησε την επίσημη επέκταση Anthropic.
2. Επανεκκίνησε το VS Code ή εκτέλεσε `Developer: Reload Window` από το Command Palette για να φορτωθεί η ρύθμιση `~/.claude/settings.json` που όρισες στο 3ο λεπτό.
3. Πάτησε το εικονίδιο ✦ Spark πάνω δεξιά στον επεξεργαστή ή το «✱ Claude Code» στη γραμμή κατάστασης για να ανοίξεις το πάνελ.
4. Την πρώτη φορά θα ζητηθεί σύνδεση με τον επίσημο λογαριασμό, πάτησε `Esc` για να παρακάμψεις — η επέκταση θα χρησιμοποιήσει αυτόματα τις ρυθμίσεις `ANTHROPIC_BASE_URL` και `ANTHROPIC_AUTH_TOKEN` που όρισες.

> **Συμβουλή**: Η επέκταση VS Code και το CLI μοιράζονται το ίδιο αρχείο ρυθμίσεων `~/.claude/settings.json`, οπότε δεν χρειάζεται να ρυθμίσεις ξανά μέσα στο VS Code. Αν θέλεις ρυθμίσεις σε επίπεδο έργου, δημιούργησε `.claude/settings.local.json` στον ριζικό φάκελο του αποθετηρίου (έχει προστεθεί στο gitignore).

Μετά την επιτυχία, μπορείς να σύρεις αρχεία στο πάνελ για ερωτήσεις και να χρησιμοποιείς `@-mention` για να αναφέρεις αρχεία και να προτείνεις αλλαγές. Όλη η χρέωση γίνεται μέσω AceData Cloud.

## Επαλήθευση ότι χρησιμοποιείς τον proxy

Τρέξε με το flag `--debug` για να δεις αν τα αιτήματα πηγαίνουν στο AceData Cloud:

```bash
claude --debug -p "say hi" 2>&1 | grep -iE 'base.?url|api\.acedata|anthropic\.com' | head
```

Αν δεις το `https://api.acedata.cloud`, ο proxy λειτουργεί. Αν εμφανιστεί `api.anthropic.com` ή λάθος 401, έλεγξε ξανά το όνομα της μεταβλητής περιβάλλοντος (πρέπει να είναι `ANTHROPIC_AUTH_TOKEN`, όχι `ANTHROPIC_API_KEY`) και βεβαιώσου ότι το αρχείο `~/.claude/.credentials.json` δεν περιέχει το επίσημο token (διαγράψ’ το αν υπάρχει).

## 5 Συχνές Ερωτήσεις

**Ε: Έτρεξα `claude login` και μετά άλλαξα τις μεταβλητές περιβάλλοντος για AceData, γιατί δεν λειτουργεί;**  
Α: Το `claude login` γράφει το επίσημο token στο `~/.claude/.credentials.json`, το οποίο έχει προτεραιότητα πάνω από τις μεταβλητές περιβάλλοντος. Διαγράψε αυτό το αρχείο και τρέξε `source ~/.zshrc` ξανά.

**Ε: Μπορώ να χρησιμοποιήσω μοντέλα όπως `--model claude-opus-4-7`;**  
Α: Ναι. Ο proxy AceData Cloud προωθεί το πεδίο model, υποστηρίζοντας όλα τα δημόσια μοντέλα Anthropic καθώς και τα επεκταμένα `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5`.

**Ε: Μπορώ να έχω πολλαπλά profiles (προσωπικό + εταιρικό);**  
Α: Ναι. Το Claude Code υποστηρίζει πολλαπλά profiles στο `~/.claude/settings.json`. Εναλλακτικά, δημιούργησε δύο shell functions `claude_personal` / `claude_work` που κάνουν export διαφορετικά `ANTHROPIC_AUTH_TOKEN` και καλούν `claude $@`.

**Ε: Μπορώ να τρέξω σε GitHub Actions;**  
Α: Ναι. Δες τον οδηγό [Claude Code GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**Ε: Τι γίνεται όταν τελειώσουν τα δωρεάν όρια;**  
Α: Πήγαινε στο [Διαχείριση Εφαρμογών](https://platform.acedata.cloud/applications) → επίλεξε την εφαρμογή Claude → φόρτισε λογαριασμό (χρέωση ανά token) ή άλλαξε σε συνδρομή με πόντους.
