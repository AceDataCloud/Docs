## 1. Απόκτηση API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), μπείτε στις διαθέσιμες εφαρμογές και αντιγράψτε το API Key.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Εγκατάσταση CC Switch

Κατεβάστε από [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), μπορεί να τρέξει και σε macOS:

```bash
brew install --cask cc-switch
```

## 3. Προσθήκη Provider

Ανοίξτε το CC Switch, επιλέξτε **Claude Code → Add Provider → Custom**, συμπληρώστε:

| Πεδίο       | Τιμή                          |
| ----------- | ----------------------------- |
| Name        | `Ace Data Cloud`             |
| Base URL    | `https://api.acedata.cloud`  |
| API Key     | Το API Key που μόλις αντιγράψατε |
| API Format  | `Anthropic Messages`         |

Αν χρειαστεί να χρησιμοποιήσετε τον επεξεργαστή JSON, ρυθμίστε το ως εξής:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

Το CC Switch θα γράψει τη ρύθμιση στις ρυθμίσεις χρήστη του Claude Code. Μην αποθηκεύετε το πραγματικό Key σε αποθετήριο ομάδας και μην διατηρείτε ταυτόχρονα το παλιό `ANTHROPIC_API_KEY`.

## 4. Ενεργοποίηση και Επαλήθευση

Αφού αποθηκεύσετε, ενεργοποιήστε το **Ace Data Cloud**, κλείστε και ξανανοίξτε το Claude Code. Στείλτε μια απλή εργασία μόνο για ανάγνωση και ελέγξτε την κλήση στην [ιστορία χρήσης](https://platform.acedata.cloud/console/usages). Αν μετά την αλλαγή εξακολουθεί να χρησιμοποιεί την παλιά ρύθμιση, κλείστε εντελώς το Claude Code και το CC Switch και δοκιμάστε ξανά.
