Το Aider συνδέεται με το OpenAI-compatible API μέσω του προθέματος μοντέλου `openai/` του LiteLLM.

## Ρύθμιση

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

Αντικαταστήστε το `MODEL_ID` με το μοντέλο που επιλέξατε στον οδηγό ρύθμισης Coding. Μπορείτε επίσης να γράψετε τις αντίστοιχες επιλογές τοπικά στο `.env` ή στο `.aider.conf.yml`, αλλά μην υποβάλετε το πραγματικό Token.

## Επαλήθευση

```bash
aider --model openai/MODEL_ID --message "Reply only OK"
```

Κατά την πρώτη χρήση ενός άγνωστου μοντέλου, το Aider μπορεί να υποδείξει ότι λείπουν τα μεταδεδομένα του μοντέλου; αυτό δεν ισοδυναμεί με αποτυχία πιστοποίησης. Ο έλεγχος 401 ελέγχει το Token, ο έλεγχος 404 ελέγχει το ID του μοντέλου και το Base URL `/v1`.
