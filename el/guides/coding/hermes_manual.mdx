## 1. Απόκτηση API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), εισέλθετε σε μια διαθέσιμη εφαρμογή και αντιγράψτε το API Key.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Αποθήκευση Key

Γράψτε στο `~/.hermes/.env`:

```dotenv
ACEDATACLOUD_API_KEY=το API Key σας
```

## 3. Ρύθμιση Provider

Προσθέστε στο `~/.hermes/config.yaml`:

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

Μεταβείτε στον [κατάλογο μοντέλων](https://platform.acedata.cloud/models) για να δείτε τα ονόματα των μοντέλων (για παράδειγμα `claude-opus-5`, `gpt-6-sol`) και αντικαταστήστε όλα τα `MODEL_ID` με το ίδιο όνομα· για ακριβή επαλήθευση, χρησιμοποιήστε ως αναφορά την τιμή `id` στην απόκριση του `/v1/models`. Αυτή η τιμή είναι το όνομα του μοντέλου που χρησιμοποιεί η παράμετρος API `model`, όχι το UUID της υπηρεσίας ή του API. Μην γράφετε το πραγματικό Key στο YAML και μην υποβάλλετε το `.env`.

## 4. Επαλήθευση

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

Εάν επιστραφεί 401, ελέγξτε το `~/.hermes/.env`· εάν η ρύθμιση δεν εφαρμοστεί, κλείστε εντελώς και επανεκκινήστε το Hermes.
