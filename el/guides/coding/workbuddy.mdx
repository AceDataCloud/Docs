## 1. Λήψη API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), εισέλθετε σε μια διαθέσιμη εφαρμογή και αντιγράψτε το API Key.

![Λήψη Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Προσθήκη μοντέλου

Στο WorkBuddy μεταβείτε στις **Ρυθμίσεις → Μοντέλα → Προσαρμοσμένα μοντέλα → Προσθήκη μοντέλου**, και στη συνέχεια συμπληρώστε:

| Πεδίο       | Τιμή                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------ |
| Provider | `Custom`                                                                                         |
| Διεύθυνση διεπαφής     | `https://api.acedata.cloud/v1`                                                                   |
| API Key  | Το API Key που μόλις αντιγράφηκε                                                                                    |
| Όνομα μοντέλου     | Μεταβείτε στον [κατάλογο μοντέλων](https://platform.acedata.cloud/models) για να το δείτε και συμπληρώστε αυτούσιο το όνομα του μοντέλου που θέλετε να καλέσετε, για παράδειγμα `claude-opus-5`, `gpt-6-sol` |
| Προσαρμοσμένο πρωτόκολλο    | Απενεργοποιημένο                                                                                               |

![Διεπαφή διαμόρφωσης WorkBuddy Custom Provider](https://cdn.acedata.cloud/189027b68722.png)

> Το `id` εδώ είναι το όνομα του μοντέλου που χρησιμοποιείται στην παράμετρο `model` του αιτήματος API, δεν είναι το UUID της υπηρεσίας, του API ή της Application, ούτε ένα προσαρμοσμένο εμφανιζόμενο όνομα. Μόνο όταν ο κατάλογος σε πραγματικό χρόνο επιστρέφει `{"id":"ds-4.0"}` μπορείτε να συμπληρώσετε `ds-4.0`· αν δεν υπάρχει στον κατάλογο, σημαίνει ότι δεν είναι διαθέσιμο επί του παρόντος, μην κάνετε εικασίες ή συντομεύσεις.

Μπορείτε πρώτα να δείτε τα διαθέσιμα μοντέλα στον [κατάλογο μοντέλων](https://platform.acedata.cloud/models)· εάν χρειάζεται να επιβεβαιώσετε το ακριβές όνομα που μπορεί να καλέσει το τρέχον Coding διαπιστευτήριο, χρησιμοποιήστε το API Key που μόλις αντιγράφηκε για να υποβάλετε ερώτημα στον κατάλογο API:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Στον πίνακα `data` της απόκρισης βρείτε το μοντέλο-στόχο και αντιγράψτε αυτούσια την τιμή του `id` του. Ρυθμίστε τους διακόπτες δυνατοτήτων σύμφωνα με την πραγματική υποστήριξη του μοντέλου.

Όταν διατηρείτε το «Προσαρμοσμένο πρωτόκολλο» απενεργοποιημένο, το WorkBuddy θα συμπληρώνει τη διαδρομή σύμφωνα με τους κανόνες OpenAI Chat Completions. Οι διακόπτες προηγμένων δυνατοτήτων (εργαλεία, εικόνες, συλλογισμός) ενεργοποιούνται μόνο σύμφωνα με τις πραγματικές δυνατότητες του επιλεγμένου μοντέλου· όταν δεν είστε βέβαιοι, διατηρήστε πρώτα τις προεπιλογές.

## 3. Επαλήθευση

Μετά την αποθήκευση, επιλέξτε το μοντέλο που μόλις προσθέσατε στον επιλογέα μοντέλων συνομιλίας και στείλτε `Reply only OK`. Στη συνέχεια, εκτελέστε άλλη μία εργασία αρχείου μόνο για ανάγνωση ή εργαλείου, για να επιβεβαιώσετε ότι οι απαιτούμενες δυνατότητες είναι διαθέσιμες· τα αρχεία κλήσεων μπορούν να προβληθούν στο [ιστορικό χρήσης](https://platform.acedata.cloud/console/usages).

Εάν το μοντέλο δεν εμφανίζεται, επιβεβαιώστε ότι η διαμόρφωση έχει αποθηκευτεί και ενεργοποιηθεί· για 401 ελέγξτε το Key· για 404 ελέγξτε εάν το συμπληρωμένο όνομα μοντέλου είναι απολύτως ίδιο με το `id` στον κατάλογο, καθώς και εάν η διεύθυνση διεπαφής είναι σωστή. Οι επίσημες οδηγίες του WorkBuddy αναφέρουν ότι το Key αποθηκεύεται στην τοπική διαμόρφωση, αλλά το περιεχόμενο των αιτημάτων θα εξακολουθεί να αποστέλλεται στην υπηρεσία μοντέλου που έχει διαμορφωθεί.
