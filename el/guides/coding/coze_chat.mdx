Coze επίσημη τεκμηρίωση προσαρμοσμένων μοντέλων υποστηρίζει το OpenAI Chat API. Διαφορετικές εκδόσεις ενοικιαστών Coze μπορεί να διαχειρίζονται τη σύνθεση διαδρομών, τη ροή εξόδου και τις κλήσεις εργαλείων διαφορετικά, παρακαλώ ελέγξτε κάθε στοιχείο παρακάτω κατά την πρώτη σύνδεση.

## Ρύθμιση

1. Εισέλθετε στη διαχείριση μοντέλων Coze και προσθέστε ένα νέο προσαρμοσμένο μοντέλο.
2. Επιλέξτε το πρωτόκολλο OpenAI Chat API.
3. Συμπληρώστε το Base API URL με `https://api.acedata.cloud/v1`.
4. Συμπληρώστε το API Key με το Ace Data Cloud API Token σας.
5. Συμπληρώστε το Model με το ακριβές ID μοντέλου που υποστηρίζει Chat Completions στον κατάλογο μοντέλων.
6. Αποθηκεύστε και ολοκληρώστε τη δοκιμή σύνδεσης του Coze.
7. Στείλτε `Reply only OK` στο Bot/Agent και δοκιμάστε ξανά την κλήση εργαλείου.

## Τρέχοντα όρια

- Διαφορετικές περιοχές, εκδόσεις ή πακέτα Coze μπορεί να εμφανίζουν διαφορετικές φόρμες.
- Το Base API URL θα πρέπει να χρησιμοποιεί τη βάση, μην προσθέτετε ξανά `/chat/completions`; αν η τρέχουσα διεπαφή απαιτεί σαφώς το πλήρες API URL, ακολουθήστε τις υποδείξεις της φόρμας.
- Τα Chat Completions, Responses και Anthropic Messages είναι τρεις ανεξάρτητες διαδρομές και δεν μπορούν να αντικαταστήσουν η μία την άλλη για επαλήθευση.
