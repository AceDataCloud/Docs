## 1. Απόκτηση API Key

Άνοιγμα της [λίστας εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), εισέλθετε στις διαθέσιμες εφαρμογές και αντιγράψτε το API Key.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Ρύθμιση

Το Kilo CLI διαβάζει το `kilo.jsonc` και διαβάζει το API Key από το shell που εκκινεί το CLI.

Στο `~/.config/kilo/kilo.jsonc` γράψτε:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Στη συνέχεια, εξάγετε το Token στο τρέχον shell:

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
```

## 3. Επαλήθευση

```bash
kilo run -m acedatacloud/MODEL_ID "Reply only OK"
```

Εάν το CLI δεν μπορεί να διαβάσει το Token, επιβεβαιώστε ότι η μεταβλητή έχει ήδη `export`, και όχι απλώς γραμμένη σε ένα μη φορτωμένο αρχείο `.env`.
