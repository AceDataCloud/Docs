## 1. Λήψη API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), μεταβείτε στη διαθέσιμη εφαρμογή και αντιγράψτε το API Key.

![Λήψη Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Εγκατάσταση του Kimi Code

macOS / Linux：

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

Μπορείτε επίσης να το εγκαταστήσετε μέσω npm：

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. Διαμόρφωση του AceDataCloud

Επεξεργαστείτε το `~/.kimi/config.toml` και προσθέστε την ακόλουθη διαμόρφωση：

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "το API Key σας"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

Μεταβείτε στον [κατάλογο μοντέλων](https://platform.acedata.cloud/models) για να δείτε τα ονόματα μοντέλων (για παράδειγμα `claude-opus-5`, `gpt-6-sol`) και αντικαταστήστε όλα τα `MODEL_ID` με το ίδιο όνομα· για ακριβή επαλήθευση, χρησιμοποιήστε την τιμή `id` στην απόκριση του `/v1/models`. Αυτή η τιμή είναι το όνομα μοντέλου που χρησιμοποιείται από την παράμετρο API `model`, όχι το UUID της υπηρεσίας ή του API. Το `type = "openai"` χρησιμοποιεί το πρωτόκολλο OpenAI Chat Completions.

Το αρχείο διαμόρφωσης περιέχει το Key· για macOS / Linux συνιστάται ο περιορισμός των δικαιωμάτων：

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. Επαλήθευση και εκκίνηση

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

Αφού εισέλθετε στο έργο, εκτελέστε το `kimi` για να ξεκινήσετε τη χρήση. Εάν επιστραφεί 401, ελέγξτε το API Key· εάν εμφανιστεί model not found, επιβεβαιώστε ότι το `default_model`, το όνομα πίνακα μοντέλου και το πεδίο `model` χρησιμοποιούν το ίδιο ID.
