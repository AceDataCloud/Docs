Το Qwen Code χρησιμοποιεί τη ρύθμιση `modelProviders` στο `~/.qwen/settings.json` για να προσαρμόσει τον Provider. Εδώ χρησιμοποιούμε σταθερά το πρωτόκολλο συμβατό με το OpenAI.

## Ρύθμιση

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

Το `modelProviders.acedatacloud` πρέπει να είναι πίνακας. Οι καταχωρήσεις του Provider είναι ανεξάρτητες ρυθμίσεις και δεν θα κληρονομήσουν αυτόματα άλλες παραμέτρους ανώτερου επιπέδου, Header ή body.

## Επικύρωση

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Reply only OK"
```

Μπαίνοντας, στείλτε `Reply only OK`, και στη συνέχεια εκτελέστε ξανά το εργαλείο ανάγνωσης αρχείων. Εάν το αυστηρά συμβατό σημείο απορρίψει τη μορφή αποτελεσμάτων του εργαλείου, παρακαλώ ελέγξτε την τρέχουσα έκδοση του Qwen Code και τις επίσημες οδηγίες συμβατότητας.
