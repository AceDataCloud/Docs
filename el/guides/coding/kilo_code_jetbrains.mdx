## 1. Απόκτηση API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), μπείτε στις διαθέσιμες εφαρμογές και αντιγράψτε το API Key.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Διαμόρφωση Provider

Ο JetBrains plugin του Kilo Code χρησιμοποιεί τη μορφή Provider `kilo.jsonc`. Η διαμόρφωση πρέπει να βρίσκεται στο περιβάλλον του χρήστη όπου εκτελείται το plugin. Κατά την απομακρυσμένη ανάπτυξη, συνήθως είναι ο απομακρυσμένος κεντρικός υπολογιστής.

Στο `~/.config/kilo/kilo.jsonc` γράψτε:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Στο περιβάλλον εκκίνησης του backend του JetBrains, εξάγετε το `ACEDATACLOUD_API_KEY`, και στη συνέχεια επανεκκινήστε το IDE ή τον απομακρυσμένο backend.

## 3. Επαλήθευση

Επιλέξτε `acedatacloud/MODEL_ID`, στείλτε `Reply only OK`, και στη συνέχεια αφήστε τον Agent να διαβάσει ένα δοκιμαστικό αρχείο. Εάν λειτουργεί τοπικά αλλά αποτυγχάνει απομακρυσμένα, ελέγξτε πρώτα αν το αρχείο διαμόρφωσης και οι μεταβλητές περιβάλλοντος είναι γραμμένες στον απομακρυσμένο υπολογιστή.
