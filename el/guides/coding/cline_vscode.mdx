## 1. Λήψη API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), εισέλθετε σε μια διαθέσιμη εφαρμογή και αντιγράψτε το API Key.

![Λήψη Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Ρύθμιση του Cline

Εγκαταστήστε και ανοίξτε το Cline στο VS Code, έπειτα εισέλθετε στη ρύθμιση Provider μέσω του κουμπιού ρυθμίσεων στον πίνακα Cline και συμπληρώστε:

| Πεδίο                                | Τιμή                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| API Provider                      | `OpenAI Compatible`                                                                            |
| Base URL                          | `https://api.acedata.cloud/v1`                                                                 |
| API Key                           | Το API Key που μόλις αντιγράψατε                                                                                  |
| Model ID                          | Μεταβείτε στον [κατάλογο μοντέλων](https://platform.acedata.cloud/models) για προβολή και συμπληρώστε αυτούσιο το όνομα του επιθυμητού μοντέλου, για παράδειγμα `claude-opus-5`、`gpt-6-sol` |
| Custom Headers                    | Αφήστε κενό                                                                                             |
| Set Azure API version             | Αφήστε κενό                                                                                             |
| Use Azure Identity Authentication | Απενεργοποιήστε                                                                                             |

![Διεπαφή ρύθμισης Cline OpenAI Compatible](https://cdn.acedata.cloud/8f356c2f1378.png)

Το `Model ID` είναι το όνομα μοντέλου που χρησιμοποιείται στην παράμετρο `model` των αιτημάτων API, δεν είναι το UUID της υπηρεσίας ή του API, ούτε μπορεί να συντμηθεί αυθαίρετα. Μπορείτε πρώτα να το δείτε στον [κατάλογο μοντέλων](https://platform.acedata.cloud/models)· εάν απαιτείται ακριβής επαλήθευση, χρησιμοποιήστε το τρέχον API Key για να ζητήσετε `GET https://api.acedata.cloud/v1/models` και αντιγράψτε την τιμή `id` του επιθυμητού μοντέλου από τον πίνακα `data` της απόκρισης.

Διατηρήστε αρχικά τις υπόλοιπες ρυθμίσεις δυνατοτήτων μοντέλου στις προεπιλεγμένες τιμές· όταν χρειάζεστε εικόνες ή μεγαλύτερο πλαίσιο, προσαρμόστε τες σύμφωνα με τις πραγματικές δυνατότητες του επιλεγμένου μοντέλου.

## 3. Επαλήθευση

Μετά την αποθήκευση, δημιουργήστε μια νέα εργασία και στείλτε `Reply only OK`. Στη συνέχεια, ζητήστε από το Cline να διαβάσει ένα δοκιμαστικό αρχείο, ώστε να επιβεβαιώσετε ότι το μοντέλο υποστηρίζει κλήση εργαλείων· το ιστορικό κλήσεων μπορεί να προβληθεί στο [ιστορικό χρήσης](https://platform.acedata.cloud/console/usages).

Το 401 συνήθως υποδεικνύει λανθασμένο Key· το 404 συνήθως υποδεικνύει ότι το Base URL δεν είναι σωστό ή ότι το Model ID που συμπληρώθηκε δεν αντιστοιχεί πλήρως στο `id` του καταλόγου. Εάν το μοντέλο μπορεί να συνομιλεί αλλά δεν μπορεί να χειριστεί αρχεία, ελέγξτε τη δυνατότητα κλήσης εργαλείων του μοντέλου.
