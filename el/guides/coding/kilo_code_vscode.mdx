## 1. Αποκτήστε API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), εισέλθετε σε μια διαθέσιμη εφαρμογή και αντιγράψτε το API Key.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Προσθέστε Custom provider

Ανοίξτε **Settings → Providers** στο Kilo Code, κάντε κλικ στο **Custom provider** και, στη συνέχεια, συμπληρώστε:

| Πεδίο           | Τιμή                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------- |
| Provider ID  | `acedatacloud`                                                                                 |
| Display name | `AceDataCloud`                                                                                 |
| Provider API | `OpenAI Compatible`                                                                            |
| Base URL     | `https://api.acedata.cloud/v1`                                                                 |
| API key      | Το API Key που μόλις αντιγράψατε                                                                 |
| Models       | Μεταβείτε στον [κατάλογο μοντέλων](https://platform.acedata.cloud/models) για προβολή και προσθέστε το όνομα του μοντέλου που θέλετε να χρησιμοποιήσετε, για παράδειγμα `claude-opus-5`、`gpt-6-sol` |

![Διεπαφή διαμόρφωσης Kilo Code Custom provider](https://cdn.acedata.cloud/94eb5abd7a6f.png)

Το `id` του μοντέλου εδώ είναι το όνομα μοντέλου που χρησιμοποιείται στην παράμετρο `model` του αιτήματος API, όχι το UUID της υπηρεσίας ή του API. Μπορείτε πρώτα να το ελέγξετε στον [κατάλογο μοντέλων](https://platform.acedata.cloud/models)· για ακριβή επαλήθευση, αντιγράψτε το αυτούσιο από τον πίνακα `data` της απόκρισης `/v1/models`, χωρίς να το μαντέψετε ή να το συντομεύσετε μόνοι σας.

Κάντε κλικ στο **Submit** και το μοντέλο θα εμφανιστεί στον επιλογέα. Όταν απαιτείται κοινή χρήση από την ομάδα ή λεπτομερέστερη διαμόρφωση, μπορείτε επίσης να επεξεργαστείτε, σύμφωνα με την επίσημη τεκμηρίωση, το αρχείο σε επίπεδο χρήστη `~/.config/kilo/kilo.jsonc` ή σε επίπεδο έργου `./kilo.jsonc`.

## 3. Επαλήθευση

Επιλέξτε `acedatacloud/MODEL_ID` και στείλτε `Reply only OK`, έπειτα εκτελέστε μία λειτουργία αρχείου μόνο για ανάγνωση. Εάν το μοντέλο δεν εμφανίζεται, ελέγξτε εάν ο Provider έχει υποβληθεί, εάν το όνομα του μοντέλου είναι ακριβώς ίδιο με το `id` στον κατάλογο και εάν το Base URL είναι σωστό.
