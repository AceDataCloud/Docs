Το Continue υποστηρίζει το API συμβατό με το OpenAI. Για να σταθεροποιηθεί η χρήση των Chat Completions, πρέπει να ρυθμιστεί ρητά το `useResponsesApi: false`.

## Ρύθμιση

Στην τοπική YAML ρύθμιση του Continue προσθέστε:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Αποθηκεύστε το `ACEDATACLOUD_API_KEY` στη διαχείριση μυστικών του Continue, μην υποβάλετε το πραγματικό Token στη ρύθμιση του έργου. Η JSON ρύθμιση του Continue έχει καταργηθεί, η νέα ρύθμιση χρησιμοποιεί YAML.

## Επαλήθευση

Επαναφορτώστε το VS Code, ανοίξτε την πλαϊνή μπάρα του Continue, επιλέξτε το μοντέλο από την Τοπική Ρύθμιση και στείλτε `Reply only OK`; εκτελέστε ξανά την εργασία μόνο για ανάγνωση αρχείων. Εάν η αίτηση σταλεί λανθασμένα στο `/responses`, ελέγξτε αν το `useResponsesApi: false` βρίσκεται εντός της καταχώρισης αυτού του μοντέλου.
