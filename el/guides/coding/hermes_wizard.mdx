## 1. Λήψη API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), εισέλθετε στη διαθέσιμη εφαρμογή και αντιγράψτε το API Key.

![Λήψη Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Εκτέλεση του οδηγού

```bash
hermes model
```

Επιλέξτε **Custom endpoint** και συμπληρώστε διαδοχικά:

| Πεδίο             | Τιμή                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | Το API Key που μόλις αντιγράψατε                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | Μεταβείτε στον [κατάλογο μοντέλων](https://platform.acedata.cloud/models) για να δείτε και συμπληρώστε αυτούσιο το όνομα του μοντέλου-στόχου, για παράδειγμα `claude-opus-5`, `gpt-6-sol` |
| Context length | Αφήστε κενό για αυτόματη ανίχνευση ή συμπληρώστε σύμφωνα με τον κατάλογο μοντέλων                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

Το `Model` είναι το όνομα μοντέλου που χρησιμοποιείται στην παράμετρο `model` του αιτήματος API, όχι το UUID της υπηρεσίας ή του API. Μπορείτε πρώτα να το δείτε στον [κατάλογο μοντέλων](https://platform.acedata.cloud/models)· εάν απαιτείται ακριβής επαλήθευση, χρησιμοποιήστε έπειτα το τρέχον API Key για να ζητήσετε `GET https://api.acedata.cloud/v1/models` και αντιγράψτε την τιμή `id` του μοντέλου-στόχου από τον πίνακα `data` της απόκρισης.

Ο οδηγός θα γράψει στο `~/.hermes/config.yaml` και στο τοπικό αρχείο διαπιστευτηρίων.

## 3. Επαλήθευση

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

Εάν ο οδηγός δεν αποθηκεύσει τη διαμόρφωση, μπορείτε να εκτελέσετε `hermes model --reset` και να προσπαθήσετε ξανά· το 401 υποδηλώνει ότι το API Key δεν είναι έγκυρο ή δεν διαβάζεται από τη διαμόρφωση του τρέχοντος χρήστη.
