Αυτό το έγγραφο θα παρουσιάσει μια API σύνδεση για την αλλαγή ηλικίας προσώπου, η οποία μπορεί να αλλάξει την ηλικία του προσώπου σε μια εικόνα εισάγοντας μια εικόνα και μια ηλικία. Η βασική χρήση είναι ότι ο χρήστης ανεβάζει μια εικόνα προσώπου και, με βάση τους αλγόριθμους επεξεργασίας και δημιουργίας προσώπου, εξάγει μια εικόνα του προσώπου που φαίνεται πιο ηλικιωμένο ή πιο νέο, υποστηρίζοντας την αλλαγή της ηλικίας του προσώπου.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε την API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [API Αλλαγής Ηλικίας Προσώπου](https://platform.acedata.cloud/documents/0c5b4165-25ba-4dc2-8f02-e3cd74ab4238) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να χρησιμοποιήσετε την API δωρεάν.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τη διεύθυνση URL της εικόνας και τις πληροφορίες ηλικίας, για να λάβετε την επεξεργασμένη εικόνα. Πρέπει πρώτα να περάσετε ένα πεδίο `image_url`, η εικόνα προσώπου φαίνεται παρακάτω:

<p><img src="https://cdn.acedata.cloud/f5687u.png" width="500" class="m-auto"></p>

Στη συνέχεια, πρέπει να ανεβάσουμε τις παραμέτρους πληροφοριών ηλικίας προσώπου `age_infos`, οι οποίες είναι ένας πίνακας και μπορούμε να περάσουμε πολλές πληροφορίες. Στη συνέχεια, μπορούμε να συμπληρώσουμε τα αντίστοιχα περιεχόμενα στην διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/cn95e8.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, συμπεριλαμβανομένων:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση της API, το οποίο μπορείτε να επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, το οποίο περιλαμβάνει:

- `image_url`: τη διεύθυνση URL της εικόνας προσώπου που χρειάζεται επεξεργασία.
- `age_infos`: πληροφορίες σχετικά με την ηλικία και την περιοχή του προσώπου, όπου η ηλικία είναι υποχρεωτική παράμετρος.

Αφού επιλέξετε, μπορείτε να δείτε ότι στα δεξιά έχει παραχθεί ο αντίστοιχος κώδικας, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/zk8qkl.png" width="500" class="m-auto"></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "image_url": "https://faceeffect-1254418846.cos.ap-guangzhou.myqcloud.com/ft/ChangeAgePic/1256437459/bfce1ab8-5fd7-464d-8878-b38433f84d0e"
}
```

Μπορείτε να δείτε ότι το αποτέλεσμα που επιστρέφεται περιλαμβάνει ένα πεδίο `image_url`, το οποίο είναι η εικόνα του προσώπου που έχει αλλάξει σύμφωνα με την εισαγόμενη ηλικία. Οι πληροφορίες του προσώπου μετά την αλλαγή φαίνονται παρακάτω:

<p><img src="https://cdn.acedata.cloud/01rmiv.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι το πρόσωπο στην εικόνα έχει αλλάξει σύμφωνα με την εισαγόμενη ηλικία.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, για παράδειγμα, ο κώδικας CURL είναι ως εξής:

```shell
curl -X POST 'https://api.acedata.cloud/face/change-age' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "age_infos": [{"age":60}],
  "image_url": "https://cdn.acedata.cloud/f5687u.png"
}'
```

Ο κώδικας σύνδεσης Python είναι ως εξής:

```python
import requests

url = "https://api.acedata.cloud/face/change-age"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "age_infos": [{"age":60}],
    "image_url": "https://cdn.acedata.cloud/f5687u.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση Σφαλμάτων

Κατά την κλήση της API, εάν προκύψουν σφάλματα, η API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
