Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο σύνδεσης με το API μετατροπής φύλου προσώπου, το οποίο μπορεί να παράγει μια εικόνα μετατροπής φύλου προσώπου με βάση την εικόνα προσώπου που ανεβάζει ο χρήστης, χρησιμοποιώντας αλγόριθμους επεξεργασίας και δημιουργίας προσώπου. Η μετατροπή από άντρα σε γυναίκα μπορεί να επιτύχει εφέ ομορφιάς, ελαφρύ μακιγιάζ, προσθήκη φράντζας και μακριών μαλλιών. Η μετατροπή από γυναίκα σε άντρα μπορεί να επιτύχει προσθήκη γενειάδας και κοντών μαλλιών.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα του [API μετατροπής φύλου προσώπου](https://platform.acedata.cloud/documents/0e4e5318-060e-4976-8d3a-171301240f8c) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να χρησιμοποιήσετε το API δωρεάν.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τον σύνδεσμο της εικόνας και τις πληροφορίες φύλου, για να λάβετε την επεξεργασμένη εικόνα. Πρέπει πρώτα να περάσετε ένα πεδίο `image_url`, η εικόνα προσώπου φαίνεται παρακάτω:

<p><img src="https://cdn.acedata.cloud/lrbtcn.jpg" width="500" class="m-auto"></p>

Στη συνέχεια, πρέπει να ανεβάσουμε τις παραμέτρους πληροφοριών φύλου προσώπου `gender_infos`, οι οποίες είναι ένας πίνακας και μπορούμε να περάσουμε πολλές πληροφορίες. Στη συνέχεια, μπορούμε να συμπληρώσουμε τις αντίστοιχες πληροφορίες στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/j22eg4.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `image_url`: τον σύνδεσμο της εικόνας προσώπου που χρειάζεται επεξεργασία.
- `gender_infos`: πληροφορίες σχετικά με το φύλο και την περιοχή του προσώπου, όπου το φύλο είναι υποχρεωτική παράμετρος, 0 σημαίνει μετατροπή από άντρα σε γυναίκα, 1 σημαίνει μετατροπή από γυναίκα σε άντρα.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/5kwudj.png" width="500" class="m-auto"></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "image_url": "https://faceeffect-1254418846.cos.ap-guangzhou.myqcloud.com/ft/SwapGenderPic/1256437459/1d85ceb9-6847-41ec-a9fd-7a20ddbd13b6"
}
```

Μπορείτε να δείτε ότι το αποτέλεσμα που επιστρέφεται περιλαμβάνει ένα πεδίο `image_url`, το οποίο είναι η εικόνα του προσώπου που έχει αλλάξει σύμφωνα με τις παραμέτρους αλλαγής φύλου που εισάγατε. Οι πληροφορίες του προσώπου μετά την αλλαγή φαίνονται παρακάτω:

<p><img src="https://cdn.acedata.cloud/hm7w44.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι το πρόσωπο στην εικόνα έχει αλλάξει σύμφωνα με το εισαγόμενο φύλο.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, για παράδειγμα, ο κώδικας CURL είναι ο εξής:

```shell
curl -X POST 'https://api.acedata.cloud/face/change-gender' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg",
  "gender_infos": [{"gender":1}]
}'
```

Ο κώδικας σύνδεσης Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/face/change-gender"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg",
    "gender_infos": [{"gender":1}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
