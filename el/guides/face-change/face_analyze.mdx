Αυτό το άρθρο θα παρουσιάσει μια μέθοδο σύνδεσης API για τον εντοπισμό προσώπου, η οποία μπορεί να εντοπίσει τα χαρακτηριστικά του προσώπου (γνωστός και ως εντοπισμός κρίσιμων σημείων προσώπου) μέσω της εισαγωγής εικόνας, υπολογίζοντας 90 σημεία που σχηματίζουν το περίγραμμα του προσώπου, συμπεριλαμβανομένων των φρυδιών (8 σημεία αριστερά και 8 δεξιά), των ματιών (8 σημεία αριστερά και 8 δεξιά), της μύτης (13 σημεία), του στόματος (22 σημεία), του περιγράμματος του προσώπου (21 σημεία) και της κόρης (2 σημεία).

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [API Εντοπισμού Προσώπου](https://platform.acedata.cloud/documents/20945baf-b263-457b-be5f-0332c2180a57) για να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να χρησιμοποιήσετε το API δωρεάν.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τον σύνδεσμο της εικόνας για να λάβετε την επεξεργασμένη εικόνα. Πρέπει απλώς να περάσετε ένα πεδίο `image_url`, η εικόνα του προσώπου φαίνεται παρακάτω:

<p><img src="https://cdn.acedata.cloud/lrbtcn.jpg" width="500" className="m-auto" /></p>

Στη συνέχεια, μπορούμε να συμπληρώσουμε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/y3g837.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, συμπεριλαμβανομένων:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, συμπεριλαμβανομένων:

- `image_url`: ο σύνδεσμος της εικόνας προσώπου που χρειάζεται επεξεργασία.
- `mode`: η λειτουργία ανίχνευσης. 0 για ανίχνευση όλων των εμφανών προσώπων, 1 για ανίχνευση του μεγαλύτερου προσώπου. Η προεπιλογή είναι 0.
- `face_model_version`: η έκδοση του αλγορίθμου μοντέλου που χρησιμοποιείται για την υπηρεσία αναγνώρισης προσώπου, η προεπιλογή είναι `3.0`.
- `need_rotate_detection`: αν θα ενεργοποιηθεί η υποστήριξη αναγνώρισης περιστροφής εικόνας. 0 για απενεργοποίηση, 1 για ενεργοποίηση. Η προεπιλογή είναι 0.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/2ceul8.png" width="500" className="m-auto" /></p>

Επιπλέον, αν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα διασύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο κώδικας CURL παρακάτω:

```shell
curl -X POST 'https://api.acedata.cloud/face/analyze' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg"
}'
```

Ο κώδικας διασύνδεσης Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/face/analyze"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, αν συναντήσετε σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα απόκρισης σφάλματος
