Η κύρια λειτουργία του Face Swap API είναι να αλλάξει το πρόσωπο της στοχευμένης εικόνας με το πρόσωπο της πηγής εικόνας, εισάγοντας μια πηγή εικόνα και μια στοχευμένη εικόνα.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες διασύνδεσης του Face Swap API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του Face Swap API, μπορείτε εύκολα να πραγματοποιήσετε την αλλαγή του προσώπου της στοχευμένης εικόνας με το πρόσωπο της πηγής εικόνας.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Face Swap API, πρέπει πρώτα να επισκεφθείτε τη σελίδα αίτησης [Face Swap API](https://platform.acedata.cloud/documents/d10df07a-66a6-4c37-b114-3a003fc9bd55) για να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![Σελίδα αίτησης](https://cdn.acedata.cloud/rci31i.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη [σελίδα σύνδεσης](https://platform.acedata.cloud) για να σας προσκαλέσει να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

Θα χρησιμοποιήσουμε δύο εικόνες ως παράδειγμα για να δείξουμε πώς να χρησιμοποιήσετε αυτό το API. Ας υποθέσουμε ότι η πηγή εικόνα είναι η παρακάτω:

Στη συνέχεια, θα δείξουμε πώς να αλλάξετε το πρόσωπο της στοχευμένης εικόνας με το πρόσωπο της πηγής εικόνας.

### Ρύθμιση κεφαλίδων αιτήματος και σώματος αιτήματος

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `source_image_url`: ο σύνδεσμος της ανεβασμένης πηγής εικόνας.
- `target_image_url`: ο σύνδεσμος της ανεβασμένης στοχευμένης εικόνας.
- `timeout`: προαιρετικό, ο χρόνος υπερβολής επεξεργασίας (δευτερόλεπτα), σε περίπτωση υπερβολής θα επιστραφεί άμεσα.

Ρυθμίστε όπως φαίνεται στην παρακάτω εικόνα:

### Παράδειγμα κώδικα

Μπορείτε να παρατηρήσετε ότι στη δεξιά πλευρά της σελίδας έχουν ήδη παραχθεί αυτόματα διάφορες γλώσσες κώδικα, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/t8gsls.png" width="500" className="m-auto" /></p>

Ορισμένα παραδείγματα κώδικα είναι τα εξής:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/face/swap' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "source_image_url": "https://cdn.acedata.cloud/n1lmd8.png",
  "target_image_url": "https://cdn.acedata.cloud/3np95r.png"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/face/swap"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "source_image_url": "https://cdn.acedata.cloud/n1lmd8.png",
    "target_image_url": "https://cdn.acedata.cloud/3np95r.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Παράδειγμα απάντησης

Αφού το αίτημα είναι επιτυχές, το API θα επιστρέψει πληροφορίες σχετικά με την εικόνα αποτελέσματος μετά την αλλαγή προσώπου. Για παράδειγμα:

```json
{
  "image_url": "https://platform.cdn.acedata.cloud/face/4b13bdeb-1b19-4ea5-bddf-c2da14ba72e3.png",
  "image_width": 2008,
  "image_height": 1942,
  "image_size": 4006213,
  "task_id": "4b13bdeb-1b19-4ea5-bddf-c2da14ba72e3"
}
```

Μπορείτε να δείτε ότι το αποτέλεσμα περιλαμβάνει ένα πεδίο `image_url`, το οποίο περιέχει τον σύνδεσμο της εικόνας μετά την αλλαγή του προσώπου της στοχευμένης εικόνας με το πρόσωπο της πηγής εικόνας, οι άλλες πληροφορίες φαίνονται στην παρακάτω εικόνα:

- `image_url`, ο σύνδεσμος της παραγόμενης εικόνας.
- `image_width`, το πλάτος της παραγόμενης εικόνας.
- `image_height`, το ύψος της παραγόμενης εικόνας.
- `image_size`, το μέγεθος της παραγόμενης εικόνας.
- `task_id`, το ID της τρέχουσας παραγγελίας.

Το αποτέλεσμα της παραγόμενης εικόνας είναι:

<p><img src="https://cdn.acedata.cloud/soa3lk.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι η εικόνα έχει επιτυχώς αλλάξει το πρόσωπο της στοχευμένης εικόνας με το πρόσωπο της πηγής εικόνας.

## Ασύγχρονη κλήση

Δεδομένου ότι ο χρόνος παραγωγής του Face Swap είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, εάν το API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος. Έτσι, αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη κλήση.

Η συνολική διαδικασία είναι: όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`. Μετά την υποβολή του αιτήματος API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα που περιλαμβάνει ένα πεδίο `task_id`, το οποίο αντιπροσωπεύει το ID της τρέχουσας εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα του Face Swap θα αποσταλεί μέσω POST JSON στη διεύθυνση `callback_url` που έχει καθορίσει ο πελάτης, το οποίο περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε αυτό μέσω παραδείγματος.

Πρώτον, η κλήση Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα, οι προγραμματιστές θα πρέπει να την αντικαταστήσουν με το URL του HTTP διακομιστή που έχουν δημιουργήσει. Για ευκολία, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να αποκτήσετε ένα Webhook URL, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/r8wyb7.png)

Αντιγράψτε αυτό το URL και μπορείτε να το χρησιμοποιήσετε ως Webhook, το παρακάτω παράδειγμα είναι https://webhook.site/3b76eba5-4573-432a-b607-3000b87afc06.

Στη συνέχεια, μπορούμε να ρυθμίσουμε το πεδίο `callback_url` στο παραπάνω Webhook URL, ενώ συμπληρώνουμε τα αντίστοιχα παραμέτρους, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/xx08i2.png" width="500" className="m-auto" /></p>

Κάνοντας κλικ στην εκτέλεση, μπορείτε να παρατηρήσετε ότι θα λάβετε αμέσως ένα αποτέλεσμα, όπως παρακάτω:

```json
{
  "task_id": "9cba9d36-3b14-43c9-85b6-86f6dfc3b096"
}
```

Μετά από λίγο, μπορείτε να παρατηρήσετε το αποτέλεσμα του Face Swap στο https://webhook.site/3b76eba5-4573-432a-b607-3000b87afc06, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/col42s.png)

Το περιεχόμενο είναι το εξής:

```json
{
  "success": true,
  "task_id": "9cba9d36-3b14-43c9-85b6-86f6dfc3b096",
  "image_url": "https://platform.cdn.acedata.cloud/face/9cba9d36-3b14-43c9-85b6-86f6dfc3b096.png",
  "image_width": 2008,
  "image_height": 1942,
  "image_size": 4006481
}
```

Μπορείτε να δείτε ότι το αποτέλεσμα περιλαμβάνει ένα πεδίο `task_id`, τα άλλα πεδία είναι παρόμοια με τα παραπάνω, μέσω αυτού του πεδίου μπορείτε να συσχετίσετε την εργασία.

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:
- `400 token_mismatched`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
