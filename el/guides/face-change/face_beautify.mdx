Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο σύνδεσης με το API ομορφιάς προσώπου, το οποίο μπορεί να εντοπίσει με ακρίβεια τα χαρακτηριστικά του προσώπου μέσω της ανάρτησης μιας εικόνας προσώπου από τον χρήστη (μπορεί να επεξεργαστεί έως πέντε πρόσωπα στην ίδια εικόνα), επιτυγχάνοντας λειτουργίες ομορφιάς όπως η βελτίωση της επιδερμίδας, η φωτεινότητα και η αφαίρεση ακμής.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα του [API Ομορφιάς Προσώπου](https://platform.acedata.cloud/documents/29641bfa-8e71-4d63-8b35-7c9e647c18ba) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να χρησιμοποιήσετε το API δωρεάν.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τον σύνδεσμο της εικόνας και τις πληροφορίες ομορφιάς, για να αποκτήσετε την επεξεργασμένη εικόνα. Πρέπει πρώτα να μεταβιβάσετε ένα πεδίο `image_url`, η εικόνα προσώπου φαίνεται παρακάτω:

<p><img src="https://cdn.acedata.cloud/ohgrs3.png" width="500" class="m-auto"></p>

Στη συνέχεια, πρέπει να ανεβάσουμε τις παραμέτρους πληροφοριών ομορφιάς προσώπου, οι οποίες αναφέρονται παρακάτω στο σώμα του αιτήματος. Μπορούμε να συμπληρώσουμε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/gjzkwv.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τις Επικεφαλίδες Αιτήματος, οι οποίες περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Σώμα Αιτήματος, το οποίο περιλαμβάνει:

- `image_url`: ο σύνδεσμος της εικόνας προσώπου που χρειάζεται επεξεργασία.
- `smoothing`: βαθμός λείανσης, εύρος τιμών [0,100]. 0 σημαίνει χωρίς λείανση, 100 σημαίνει μέγιστη λείανση. Προεπιλεγμένη τιμή 10.
- `whitening`: βαθμός λεύκανσης, εύρος τιμών [0,100]. 0 σημαίνει χωρίς λεύκανση, 100 σημαίνει μέγιστη λεύκανση. Προεπιλεγμένη τιμή 30.
- `face_lifting`: βαθμός αδυνατίσματος προσώπου, εύρος τιμών [0,100]. 0 σημαίνει χωρίς αδυνάτισμα, 100 σημαίνει μέγιστο αδυνάτισμα. Προεπιλεγμένη τιμή 70.
- `eye_enlarging`: βαθμός μεγέθυνσης ματιών, εύρος τιμών [0,100]. 0 σημαίνει χωρίς μεγέθυνση, 100 σημαίνει μέγιστη μεγέθυνση. Προεπιλεγμένη τιμή 70.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/nhq282.png" width="500" class="m-auto"></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "image_url": "https://faceeffect-1254418846.cos.ap-guangzhou.myqcloud.com/fmu/BeautifyPic/1256437459/1a68c13b-b03c-4c7b-92a1-e4a9b5f1d7ec"
}
```

Μπορείτε να δείτε ότι το αποτέλεσμα που επιστρέφεται περιλαμβάνει ένα πεδίο `image_url`, το οποίο είναι η εικόνα προσώπου μετά τις αλλαγές ομορφιάς που εισάγατε. Οι πληροφορίες του προσώπου μετά τις αλλαγές φαίνονται παρακάτω:

<p><img src="https://cdn.acedata.cloud/g809b1.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι το πρόσωπο στην εικόνα έχει αλλάξει σύμφωνα με τις πληροφορίες ομορφιάς που εισάγατε.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο κώδικας CURL παρακάτω:

```shell
curl -X POST 'https://api.acedata.cloud/face/beautify' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg",
  "smoothing": 50,
  "whitening": 50,
  "face_lifting": 50,
  "eye_enlarging": 50
}'
```

Ο κώδικας σύνδεσης Python είναι ως εξής:

```python
import requests

url = "https://api.acedata.cloud/face/beautify"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg",
    "smoothing": 50,
    "whitening": 50,
    "face_lifting": 50,
    "eye_enlarging": 50
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα Απόκρισης Σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
