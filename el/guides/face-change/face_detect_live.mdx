Αυτό το έγγραφο θα εισάγει την ανάλυση API για την ανίχνευση στατικής ζωντανής εικόνας προσώπου (έκδοση υψηλής ακρίβειας), η οποία μπορεί να χρησιμοποιηθεί για την ανίχνευση ζωντανής εικόνας σε στατικές φωτογραφίες που ανεβάζουν οι χρήστες, προκειμένου να προσδιοριστεί αν είναι φωτογραφίες που έχουν τραβηχτεί από άλλη φωτογραφία.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [Ανίχνευσης Στατικής Ζωντανής Εικόνας Προσώπου (έκδοση υψηλής ακρίβειας) API](https://platform.acedata.cloud/documents/df41d411-6ba8-41d3-a56f-3f6ec9acaa36) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις, ώστε να μπορείτε να χρησιμοποιήσετε δωρεάν αυτό το API.

## Βασική χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τον σύνδεσμο της εικόνας, ώστε να αποκτήσετε την επεξεργασμένη εικόνα αποτελέσματος. Πρέπει απλώς να μεταβιβάσετε ένα πεδίο `image_url`, η εικόνα προσώπου φαίνεται παρακάτω:

<p><img src="https://cdn.acedata.cloud/lrbtcn.jpg" width="500" class="m-auto"></p>

Στη συνέχεια, μπορούμε να συμπληρώσουμε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/c975uf.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `image_url`: τον σύνδεσμο της εικόνας προσώπου που χρειάζεται επεξεργασία.
- `face_model_version`: την έκδοση του αλγορίθμου μοντέλου που χρησιμοποιείται για την υπηρεσία αναγνώρισης προσώπου. Αυτή τη στιγμή, οι παράμετροι υποστηρίζουν την "3.0".

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/nkcvet.png" width="500" class="m-auto"></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "score": 0,
  "face_model_version": "3.0"
}
```

Μπορείτε να δείτε ότι έχουμε λάβει το αποτέλεσμα της ανίχνευσης στατικής ζωντανής εικόνας προσώπου, το οποίο περιλαμβάνει το περιεχόμενο της βαθμολογίας ζωντανής εικόνας.

Η περιγραφή των πεδίων είναι ως εξής:

- `score`: βαθμολογία ζωντανής εικόνας, με εύρος τιμών [0,100], σύμφωνα με το εύρος του κατωφλίου της βαθμολογίας ζωντανής εικόνας για να προσδιοριστεί αν είναι φωτογραφία που έχει τραβηχτεί από άλλη φωτογραφία. Αυτή τη στιγμή, τα κατώφλια μπορούν να χωριστούν σε [5,10,40,70,90], με προτεινόμενο κατώφλι το 40.
- `face_model_version`: η έκδοση του αλγορίθμου μοντέλου που χρησιμοποιείται για την αναγνώριση προσώπου.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο κώδικας CURL παρακάτω:

```shell
curl -X POST 'https://api.acedata.cloud/face/detect-live' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg"
}'
```

Ο κώδικας σύνδεσης Python είναι ως εξής:

```python
import requests

url = "https://api.acedata.cloud/face/detect-live"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

```json
    "message": "fetch failed"

}
```
