xAI Grok είναι ένα πολύ ισχυρό σύστημα AI συνομιλίας, απλά εισάγοντας λέξεις-κλειδιά, μπορεί να δημιουργήσει ομαλές και φυσικές απαντήσεις σε λίγα δευτερόλεπτα. Το Grok ξεχωρίζει στη βιομηχανία με το μοναδικό του χιούμορ και την ικανότητά του να αποκτά πληροφορίες σε πραγματικό χρόνο από το διαδίκτυο, και σήμερα, το Grok έχει αναδειχθεί σε πολλούς καινοτόμους τομείς, με την επιρροή του να επεκτείνεται γρήγορα. Είτε πρόκειται για καθημερινές συνομιλίες, δημιουργική γραφή, είτε για τεχνική ανάλυση και αποσφαλμάτωση κώδικα, το Grok μπορεί να προσφέρει διορατική και έξυπνη βοήθεια, παρέχοντας στους χρήστες υποστήριξη σε νέες διαστάσεις για τις αποφάσεις και τις δημιουργίες τους.

Αυτό το έγγραφο περιγράφει κυρίως τη διαδικασία χρήσης του Grok Chat Completion API, επιτρέποντάς μας να χρησιμοποιήσουμε εύκολα τη λειτουργία συνομιλίας του επίσημου Grok.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Grok Chat Completion API, μπορείτε πρώτα να επισκεφθείτε τη σελίδα [Grok Chat Completion API](https://platform.acedata.cloud/documents/faf08b59-36aa-4d26-b5d9-a18f113cc2be) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να σας προσκαλέσει να εγγραφείτε και να συνδεθείτε, και μετά την εγγραφή και σύνδεση θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/vunnjf.png" width="400" class="m-auto"></p>

Κατά την πρώτη χρήση αυτού του API, πρέπει τουλάχιστον να συμπληρώσουμε τρία περιεχόμενα, ένα είναι το `authorization`, το οποίο μπορείτε να επιλέξετε απευθείας από τη λίστα. Ένα άλλο παράμετρο είναι το `model`, το `model` είναι η κατηγορία μοντέλου που επιλέγουμε να χρησιμοποιήσουμε από την επίσημη ιστοσελίδα του Grok, εδώ έχουμε κυρίως 8 μοντέλα, περισσότερες λεπτομέρειες μπορείτε να δείτε στα μοντέλα που παρέχουμε. Η τελευταία παράμετρος είναι το `messages`, το `messages` είναι ο πίνακας των ερωτήσεων που εισάγουμε, είναι ένας πίνακας που δηλώνει ότι μπορείτε να ανεβάσετε πολλές ερωτήσεις ταυτόχρονα, κάθε ερώτηση περιλαμβάνει το `role` και το `content`, όπου το `role` δηλώνει το ρόλο του ερωτώντος, παρέχουμε τρεις ταυτότητες, δηλαδή `user`, `assistant`, `system`. Το άλλο `content` είναι το συγκεκριμένο περιεχόμενο της ερώτησής μας.

Ταυτόχρονα, μπορείτε να παρατηρήσετε ότι στα δεξιά υπάρχει ο αντίστοιχος κώδικας κλήσης που δημιουργείται, μπορείτε να αντιγράψετε τον κώδικα και να τον εκτελέσετε απευθείας ή να κάνετε κλικ στο κουμπί «Try» για να δοκιμάσετε.

Συνηθισμένες προαιρετικές παράμετροι:

- `max_tokens`: περιορίζει τον μέγιστο αριθμό tokens για μία απάντηση.
- `temperature`: δημιουργεί τυχαιότητα, μεταξύ 0-2, όσο μεγαλύτερη είναι η τιμή, τόσο πιο διασκορπισμένες είναι οι απαντήσεις.
- `n`: πόσες υποψήφιες απαντήσεις θα παραχθούν ταυτόχρονα.

Το αποτέλεσμα επιστροφής περιλαμβάνει πολλά πεδία, τα οποία περιγράφονται ως εξής:

- `model`, το επιλεγμένο μοντέλο από την επίσημη ιστοσελίδα του Grok.
- `choices`, οι πληροφορίες απάντησης που παρέχει το Grok για τις ερωτήσεις.
- `usage`: στατιστικά στοιχεία σχετικά με τα tokens για αυτήν την ερώτηση-απάντηση.

Όπου το `choices` περιλαμβάνει τις πληροφορίες απάντησης του Grok, μπορείτε να δείτε τις συγκεκριμένες πληροφορίες απάντησης του Grok όπως φαίνεται στην εικόνα.

## Ροή Απόκρισης

Αυτό το API υποστηρίζει επίσης ροή απόκρισης, κάτι που είναι πολύ χρήσιμο για την ενσωμάτωσή του σε ιστοσελίδες, καθώς μπορεί να επιτρέψει την εμφάνιση αποτελεσμάτων λέξη προς λέξη.

Εάν θέλετε να επιστρέψετε την απόκριση σε ροή, μπορείτε να αλλάξετε την παράμετρο `stream` στην κεφαλίδα του αιτήματος σε `true`.

Η αλλαγή είναι όπως φαίνεται στην εικόνα, αλλά ο κώδικας κλήσης χρειάζεται να έχει τις αντίστοιχες αλλαγές για να υποστηρίξει τη ροή απόκρισης.

<p><img src="https://cdn.acedata.cloud/k883qa.png" width="400" class="m-auto"></p>

Αφού αλλάξετε το `stream` σε `true`, το API θα επιστρέφει γραμμή προς γραμμή τα αντίστοιχα δεδομένα JSON, και σε επίπεδο κώδικα θα χρειαστεί να κάνουμε τις αντίστοιχες αλλαγές για να αποκτήσουμε τα αποτελέσματα γραμμή προς γραμμή.

Παράδειγμα κώδικα κλήσης σε Python:

```python
import requests

url = "https://api.acedata.cloud/grok/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "grok-3",
    "messages": [{"role":"user","content":"Γειά σου"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

- `id`, το ID που δημιουργεί αυτή τη συνομιλία, χρησιμοποιείται για την μοναδική αναγνώριση αυτής της συνομιλίας.
- `model`, το επιλεγμένο μοντέλο από την ιστοσελίδα του Grok.
- `choices`, οι πληροφορίες απάντησης που παρέχει το Grok για τις ερωτήσεις.

Η JavaScript υποστηρίζεται επίσης, για παράδειγμα, ο κωδικός ροής κλήσης του Node.js είναι ως εξής:

```javascript
const options = {
  method: "post",
  headers: {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    "model": "grok-3",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": true
  })
};

fetch("https://api.acedata.cloud/grok/chat/completions", options)
  .then(response => response.json())
  .then(response => console.log(response))
  .catch(err => console.error(err));
```

```java

```

## Διαχείριση σφαλμάτων

Κατά την κλήση της API, αν συναντήσετε σφάλματα, η API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
