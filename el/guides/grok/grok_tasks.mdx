Η κύρια λειτουργία του Grok Tasks API είναι να ελέγχει την κατάσταση εκτέλεσης ενός έργου μέσω του ID έργου που δημιουργήθηκε από το Grok Videos Generation API.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες διασύνδεσης του Grok Tasks API, βοηθώντας σας να ενσωματώσετε και να ελέγξετε εύκολα την κατάσταση εκτέλεσης των έργων του Grok Videos Generation API.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Grok Videos Generation API, πρώτα επισκεφθείτε το [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη σελίδα που βρίσκεστε.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν. Όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό σας υπόλοιπο στο [Console](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Grok Videos Generation API →](https://platform.acedata.cloud/documents/grok-videos)

## Παράδειγμα αιτήματος

Το Grok Tasks API μπορεί να χρησιμοποιηθεί για να ελέγξει τα αποτελέσματα του Grok Videos Generation API.

### Ρύθμιση κεφαλίδων αιτήματος και σώματος αιτήματος

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `id`: το ID του έργου που θέλετε να ελέγξετε.
- `action`: ο τρόπος λειτουργίας του έργου, για μεμονωμένο έλεγχο συμπληρώστε `retrieve`.

### Παράδειγμα κώδικα CURL

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Παράδειγμα απάντησης

Αφού η αίτηση είναι επιτυχής, το API θα επιστρέψει τις λεπτομέρειες του έργου εδώ. Το πεδίο `request` είναι το σώμα της αίτησης κατά την εκκίνηση του έργου, το πεδίο `response` είναι το σώμα της απάντησης που επιστρέφεται μετά την ολοκλήρωση του έργου, για παράδειγμα:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262729.623,
  "elapsed": 7.8,
  "request": {
    "prompt": "Μια κινηματογραφική λήψη ενός γατιού που κυνηγάει μια πεταλούδα σε έναν ηλιόλουστο κήπο",
    "model": "grok-imagine-video-1.5-fast:reverse",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video-1.5-fast:reverse:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Η περιγραφή των πεδίων είναι η εξής:

- `id`: το ID του έργου που δημιουργήθηκε, χρησιμοποιείται για την μοναδική αναγνώριση αυτού του έργου.
- `request`: πληροφορίες αίτησης στο έργο.
- `response`: πληροφορίες απάντησης στο έργο.
- `created_at`: χρόνος δημιουργίας του έργου, Unix timestamp (δευτερόλεπτα, δεκαδικό).
- `started_at`: χρόνος έναρξης εκτέλεσης του έργου, Unix timestamp (δευτερόλεπτα, δεκαδικό).
- `finished_at`: χρόνος ολοκλήρωσης του έργου, Unix timestamp (δευτερόλεπτα, δεκαδικό). Δεν επιστρέφεται αυτό το πεδίο αν το έργο δεν έχει ολοκληρωθεί.
- `elapsed`: χρόνος εκτέλεσης του έργου, μονάδα σε δευτερόλεπτα (δεκαδικό, διατηρεί 3 δεκαδικά ψηφία). Δεν επιστρέφεται αυτό το πεδίο αν το έργο δεν έχει ολοκληρωθεί.

## Μαζικές λειτουργίες ελέγχου

Για να ελέγξετε λεπτομέρειες έργων για πολλαπλά ID έργων, ορίστε το `action` σε `retrieve_batch` και περάστε τον πίνακα ID έργων μέσω του `ids`:

**Request Body** περιλαμβάνει:

- `ids`: πίνακας ID έργων που θέλετε να ελέγξετε.
- `action`: ο τρόπος λειτουργίας του έργου, για μαζικό έλεγχο συμπληρώστε `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
