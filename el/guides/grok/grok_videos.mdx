Αυτό το έγγραφο θα παρουσιάσει τις οδηγίες σύνδεσης του API Δημιουργίας Βίντεο Grok, το οποίο μπορεί να δημιουργήσει βίντεο Grok Imagine (xAI) μέσω εισαγωγής κειμένων, εικόνων και προαιρετικών αναφορών εικόνας.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API Δημιουργίας Βίντεο Grok, πρώτα επισκεφθείτε την [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν. Όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό σας υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [API Δημιουργίας Βίντεο Grok →](https://platform.acedata.cloud/documents/grok-videos)

## Περιγραφή Μοντέλου

Αυτό το API επιλέγει το upstream endpoint μέσω του επιθέματος του ονόματος του μοντέλου: `:reverse` για γρήγορο/τυπικό endpoint (φθηνότερο), `:official` για επίσημο endpoint (υψηλότερη ποιότητα εικόνας, χρέωση ανά δευτερόλεπτο εξόδου). Υποστηρίζει συνολικά τέσσερα μοντέλα:

- `grok-imagine-video-1.5-fast:reverse` (προεπιλογή): Υποστηρίζει βίντεο από κείμενο (μόνο `prompt`) και βίντεο από εικόνα (παρέχοντας `image_url`), διάρκεια 6–30 δευτερόλεπτα, χρέωση ανά διάρκεια, η φθηνότερη επιλογή.
- `grok-imagine-video:reverse`: Υποστηρίζει βίντεο από κείμενο και εικόνα, διάρκεια 1–15 δευτερόλεπτα, χρέωση ανά δευτερόλεπτο εξόδου.
- `grok-imagine-video:official`: Επίσημο endpoint, υποστηρίζει βίντεο από κείμενο και εικόνα, διάρκεια 1–15 δευτερόλεπτα, χρέωση ανά δευτερόλεπτο εξόδου, υψηλότερη ποιότητα εικόνας.
- `grok-imagine-video-1.5:official`: Επίσημο endpoint, **υποστηρίζει μόνο βίντεο από εικόνα**, **πρέπει** να παρέχεται `image_url`, διάρκεια 1–15 δευτερόλεπτα, υποστηρίζει μέγιστη ανάλυση `1080p`, χρέωση ανά δευτερόλεπτο εξόδου.

## Βασική Χρήση

Πρώτα κατανοήστε τη βασική μέθοδο χρήσης, εισάγοντας τις παραμέτρους `prompt`, `model` κ.λπ., μπορείτε να δημιουργήσετε το αντίστοιχο βίντεο.

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: Τι μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: Το κλειδί API για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `prompt`: Κείμενο που περιγράφει το περιεχόμενο του βίντεο που θέλετε να δημιουργήσετε. Απαιτείται για βίντεο από κείμενο; προαιρετικό όταν παρέχεται `image_url`.
- `model`: Το μοντέλο για τη δημιουργία του βίντεο, μπορεί να είναι `grok-imagine-video-1.5-fast:reverse` (προεπιλογή), `grok-imagine-video:reverse`, `grok-imagine-video:official` ή `grok-imagine-video-1.5:official`.
- `image_url`: Σύνδεσμος της εισαγόμενης εικόνας για βίντεο από εικόνα. Απαιτείται όταν το `model` είναι `grok-imagine-video-1.5:official`.
- `reference_image_urls`: Προαιρετικός πίνακας συνδέσμων αναφοράς εικόνας, για να καθοδηγήσει το στυλ ή το περιεχόμενο του βίντεο.
- `aspect_ratio`: Η αναλογία διαστάσεων του παραγόμενου βίντεο, μπορεί να είναι `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`.
- `resolution`: Η ανάλυση εξόδου, μπορεί να είναι `480p` (προεπιλογή), `720p` ή `1080p`.
- `duration`: Η διάρκεια του παραγόμενου βίντεο (δευτερόλεπτα). Το `grok-imagine-video-1.5-fast:reverse` έχει εύρος τιμών 6–30, τα υπόλοιπα μοντέλα έχουν εύρος 1–15, προεπιλογή 6. Συνιστάται η χρήση 6 δευτερολέπτων ή 10 δευτερολέπτων, αυτές οι δύο τυπικές διάρκειες είναι σχετικά σταθερές.
- `callback_url`: Διεύθυνση ασύγχρονης επιστροφής κλήσης, αφού ρυθμιστεί, το API θα επιστρέψει αμέσως το `task_id`, και όταν ολοκληρωθεί η εργασία, θα στείλει το αποτέλεσμα σε αυτή τη διεύθυνση.
- `async`: Προαιρετικό, αν οριστεί σε `true`, η διεπαφή επιστρέφει αμέσως το `task_id`, χωρίς να χρειάζεται να παρέχετε `callback_url`, και στη συνέχεια μπορείτε να ελέγξετε τα αποτελέσματα μέσω της αντίστοιχης διεπαφής αναζήτησης εργασιών.

Κάντε κλικ στο κουμπί «Δοκιμή» για να κάνετε μια δοκιμή, και το αποτέλεσμα θα είναι παρόμοιο με το παρακάτω:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video-1.5-fast:reverse:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
      "state": "succeeded"
    }
  ]
}
```

Το επιστρεφόμενο αποτέλεσμα περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `success`: Εάν η αίτηση δημιουργίας βίντεο ήταν επιτυχής.
- `task_id`: Το ID της τρέχουσας εργασίας δημιουργίας βίντεο.
- `trace_id`: Το ID παρακολούθησης της τρέχουσας αίτησης, για την επίλυση προβλημάτων.
- `data`: Λίστα αποτελεσμάτων του παραγόμενου βίντεο.
  - `id`: Μοναδική ταυτότητα του παραγόμενου βίντεο.
  - `video_url`: Σύνδεσμος του παραγόμενου βίντεο.
  - `state`: Κατάσταση της εργασίας δημιουργίας βίντεο, μπορεί να είναι `pending` / `succeeded` / `failed`.

Απλώς χρειάζεται να αποκτήσετε το παραγόμενο βίντεο μέσω του συνδέσμου `video_url` από το αποτέλεσμα `data`.

Ο αντίστοιχος κώδικας CURL είναι ο εξής:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast:reverse",
  "resolution": "480p",
  "duration": 6
}'
```

Ο αντίστοιχος κώδικας Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video-1.5-fast:reverse",
    "resolution": "480p",
    "duration": 6
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Βίντεο από Εικόνα

Εάν θέλετε να δημιουργήσετε βίντεο με βάση μια εισαγόμενη εικόνα, μπορείτε να παρέχετε `image_url`. Όταν χρησιμοποιείτε το `grok-imagine-video-1.5:official`, πρέπει να παρέχετε αυτό το πεδίο:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5:official",
  "image_url": "https://cdn.acedata.cloud/5hmkdg.jpg",
  "resolution": "720p",
  "duration": 6
}
```

## Καθοδήγηση με Αναφορές Εικόνας

Εάν θέλετε να χρησιμοποιήσετε μία ή περισσότερες αναφορές εικόνας για να καθοδηγήσετε το στυλ ή το περιεχόμενο του βίντεο, μπορείτε να παρέχετε έναν πίνακα συνδέσμων εικόνας στο `reference_image_urls`:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video-1.5-fast:reverse",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/vunnjf.png"
  ]
}
```

## Ασύγχρονη Επιστροφή Κλήσης
Η δημιουργία βίντεο απαιτεί κάποιο χρόνο επεξεργασίας. Εάν δεν επιθυμείτε να διατηρήσετε μια μακρά σύνδεση αναμονής, μπορείτε να περάσετε το `callback_url`, οπότε η API θα επιστρέψει αμέσως το `task_id`, και αφού ολοκληρωθεί η εργασία, θα στείλει το τελικό αποτέλεσμα POST σε αυτή τη διεύθυνση:

```json
{
  "prompt": "Μια κινηματογραφική λήψη ενός γατάκι που κυνηγάει μια πεταλούδα σε έναν ηλιόλουστο κήπο",
  "model": "grok-imagine-video-1.5-fast:reverse",
  "duration": 6,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

Η άμεση επιστροφή του αποτελέσματος είναι η εξής:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Έλεγχος αποτελέσματος εργασίας

Εάν χρησιμοποιήσατε ασύγχρονη κλήση ή επιθυμείτε να ελέγξετε ενεργά την κατάσταση της εργασίας, μπορείτε να χρησιμοποιήσετε το [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) για να ελέγξετε την τελευταία κατάσταση και το αποτέλεσμα της εργασίας με βάση το `task_id`.

## Περιγραφή χρέωσης

Ο τρόπος χρέωσης αυτής της υπηρεσίας καθορίζεται από το `model`:

- `grok-imagine-video-1.5-fast:reverse`: χρεώνεται ανά διάρκεια, ανεξάρτητα από την ανάλυση — `6–10` δευτερόλεπτα, `11–20` δευτερόλεπτα, `21–30` δευτερόλεπτα αντιστοιχούν σε διαφορετικές τιμές.
- `grok-imagine-video:reverse`: χρεώνεται ανά «δευτερόλεπτα εξόδου», συνολική τιμή = μονάδα τιμής × `duration`.
- `grok-imagine-video:official` και `grok-imagine-video-1.5:official`: επίσημοι τελικοί, χρεώνονται ανά «δευτερόλεπτα εξόδου», όσο υψηλότερη η ανάλυση τόσο υψηλότερη η μονάδα τιμής; τα επίσημα μοντέλα χρεώνονται ακόμη και αν η αναθεώρηση περιεχομένου αποτύχει.

Η συγκεκριμένη μονάδα τιμής ισχύει σύμφωνα με τη σελίδα τιμολόγησης. Οι αποτυχημένες αιτήσεις δεν χρεώνονται και δεν καταναλώνουν δωρεάν πιστώσεις.

## Διαχείριση σφαλμάτων

Όταν προκύψει πρόβλημα με την αίτηση, η API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και περιγραφή, οι συνηθισμένοι είναι οι εξής:

- `400`: Λάθος παράμετροι αίτησης, όπως η έλλειψη `prompt` για τη δημιουργία βίντεο, ή η έλλειψη `image_url` για το `grok-imagine-video-1.5:official`, ή η διάρκεια εκτός ορίων (για το `grok-imagine-video-1.5-fast:reverse` είναι 6–30, για τα υπόλοιπα μοντέλα είναι 1–15).
- `401`: Αποτυχία αυθεντικοποίησης, το token είναι άκυρο ή δεν ταιριάζει με την API.
- `403`: Ανεπαρκές υπόλοιπο ή η προτροπή περιεχομένου απορρίφθηκε από την αναθεώρηση περιεχομένου.
- `429`: Πολύ συχνές αιτήσεις, παρακαλώ δοκιμάστε ξανά αργότερα.
- `500`: Αποτυχία δημιουργίας βίντεο ή σφάλμα υπηρεσίας.
