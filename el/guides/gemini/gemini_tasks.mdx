Η κύρια λειτουργία του Gemini Tasks API είναι να ελέγχει την κατάσταση εκτέλεσης ενός έργου μέσω του ID έργου που δημιουργήθηκε από το Gemini Videos Generation API.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες διασύνδεσης του Gemini Tasks API, βοηθώντας σας να ενσωματώσετε και να ελέγξετε εύκολα την κατάσταση εκτέλεσης των έργων του Gemini Videos Generation API.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Gemini Videos Generation API, πρώτα πηγαίνετε στο [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν. Όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στο [Console](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Παράδειγμα αιτήματος

Το Gemini Tasks API μπορεί να χρησιμοποιηθεί για να ελέγξει τα αποτελέσματα του Gemini Videos Generation API.

### Ρύθμιση κεφαλίδων αιτήματος και σώματος αιτήματος

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `id`: το ID του έργου που θέλετε να ελέγξετε.
- `action`: ο τρόπος λειτουργίας του έργου, για μεμονωμένο έλεγχο συμπληρώστε `retrieve`.

### Παράδειγμα κώδικα CURL

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Παράδειγμα απάντησης

Αφού το αίτημα είναι επιτυχές, το API θα επιστρέψει τις λεπτομέρειες αυτού του έργου. Το πεδίο `request` είναι το σώμα του αιτήματος κατά την εκκίνηση του έργου, το πεδίο `response` είναι το σώμα της απάντησης που επιστρέφεται μετά την ολοκλήρωση του έργου, για παράδειγμα:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262730.723,
  "elapsed": 8.9,
  "request": {
    "prompt": "Μια κινηματογραφική λήψη ενός γατιού που κυνηγάει μια πεταλούδα σε έναν ηλιόλουστο κήπο",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
        "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Η περιγραφή των πεδίων είναι ως εξής:

- `id`: το ID του έργου που δημιουργήθηκε, χρησιμοποιείται για την μοναδική αναγνώριση αυτού του έργου.
- `request`: πληροφορίες αιτήματος στο έργο.
- `response`: πληροφορίες απάντησης στο έργο.
- `created_at`: χρόνος δημιουργίας του έργου, Unix timestamp (δευτερόλεπτα, δεκαδικό).
- `started_at`: χρόνος έναρξης εκτέλεσης του έργου, Unix timestamp (δευτερόλεπτα, δεκαδικό).
- `finished_at`: χρόνος ολοκλήρωσης του έργου, Unix timestamp (δευτερόλεπτα, δεκαδικό). Δεν επιστρέφεται αυτό το πεδίο αν το έργο δεν έχει ολοκληρωθεί.
- `elapsed`: χρόνος εκτέλεσης του έργου, μονάδα σε δευτερόλεπτα (δεκαδικό, με 3 δεκαδικά ψηφία). Δεν επιστρέφεται αυτό το πεδίο αν το έργο δεν έχει ολοκληρωθεί.

## Ομαδική λειτουργία ελέγχου

Για να ελέγξετε λεπτομέρειες πολλών ID έργων, ορίστε το `action` σε `retrieve_batch` και περάστε τον πίνακα ID έργων μέσω του `ids`:

**Request Body** περιλαμβάνει:

- `ids`: πίνακας ID έργων που θέλετε να ελέγξετε.
- `action`: ο τρόπος λειτουργίας του έργου, για ομαδικό έλεγχο συμπληρώστε `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
