Το Google Gemini είναι ένα πολύ ισχυρό σύστημα διαλόγου AI, το οποίο μπορεί να δημιουργήσει ομαλές και φυσικές απαντήσεις μέσα σε λίγα δευτερόλεπτα, αρκεί να εισαγάγετε μια προτροπή. Το Gemini μπορεί να παρέχει εκπληκτική έξυπνη βοήθεια, βελτιώνοντας σημαντικά την αποδοτικότητα και τη δημιουργικότητα των ανθρώπων στην εργασία.

Αυτό το έγγραφο παρουσιάζει κυρίως τη διαδικασία χρήσης των λειτουργιών του Gemini Chat Completion API. Με αυτό, μπορούμε εύκολα να χρησιμοποιήσουμε τη λειτουργία διαλόγου του επίσημου Gemini.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Gemini Chat Completion API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης, όπου θα σας ζητηθεί να εγγραφείτε και να συνδεθείτε. Μετά την ολοκλήρωση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας· δεν χρειάζεται να υποβάλετε ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση παρέχει δωρεάν υπόλοιπο για δωρεάν δοκιμή· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να επαναφορτίσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

## Βασική χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε το αντίστοιχο περιεχόμενο στη διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/f6ksts.png" width="400" className="m-auto" /></p>

Κατά την πρώτη χρήση αυτής της διεπαφής, χρειάζεται να συμπληρώσουμε τουλάχιστον τρία στοιχεία. Το πρώτο είναι το `authorization`, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα. Μια άλλη παράμετρος είναι το `model`, όπου το `model` είναι η κατηγορία μοντέλου του Gemini που επιλέγουμε να χρησιμοποιήσουμε· τα διαθέσιμα μοντέλα υπόκεινται στην απαρίθμηση `model` στην τεκμηρίωση της διεπαφής. Η τελευταία παράμετρος είναι το `messages`, όπου το `messages` είναι ο πίνακας των ερωτημάτων που εισάγουμε. Είναι ένας πίνακας, που υποδηλώνει ότι μπορούν να μεταφορτωθούν ταυτόχρονα πολλαπλά ερωτήματα. Κάθε ερώτημα περιλαμβάνει τα `role` και `content`, όπου το `role` υποδηλώνει τον ρόλο του ερωτώντος. Παρέχουμε τρεις ρόλους, συγκεκριμένα `user`, `assistant`, `system`. Το άλλο, το `content`, είναι το συγκεκριμένο περιεχόμενο της ερώτησής μας.

Ταυτόχρονα, μπορείτε να παρατηρήσετε ότι υπάρχει αντίστοιχη δημιουργία κώδικα κλήσης στη δεξιά πλευρά. Μπορείτε να αντιγράψετε τον κώδικα και να τον εκτελέσετε απευθείας, ή μπορείτε επίσης να κάνετε απευθείας κλικ στο κουμπί «Try» για δοκιμή.

<p><img src="https://cdn.acedata.cloud/a3mdgy.png" width="400" className="m-auto" /></p>

> **Συμβουλή**: Τα flash της σειράς `gemini-3.x` είναι μοντέλα συλλογισμού και θα καταναλώσουν πρώτα reasoning tokens· ορίστε το `max_tokens` πάνω από 512, διαφορετικά ενδέχεται να επιστρέφεται μόνο κενό περιεχόμενο. Το `gemini-3.8-flash` είναι το τρέχον προτεινόμενο μοντέλο Flash, υποστηρίζει έως 1 εκατομμύριο Token συμφραζομένων, είσοδο εικόνας, κλήση εργαλείων και αποκρίσεις ροής· προς το παρόν καλείται μέσω της διεπαφής Chat Completions.

Το `gemini-4-argon` μπορεί επίσης να χρησιμοποιηθεί για Chat Completions και υποστηρίζει κανονικές και ροϊκές απαντήσεις κειμένου. Ενδέχεται να χρησιμοποιεί μέρος του προϋπολογισμού εξόδου για συλλογισμό· για σύνθετες εργασίες, αφήστε επαρκή χώρο για το `max_tokens`. ## Κατανόηση εικόνων (πολυτροπική είσοδος)

Το Gemini είναι εγγενώς πολυτροπικό μοντέλο και μπορεί να «δει εικόνες» απευθείας. Για να εισαγάγετε μια εικόνα, αλλάξτε το `content` ενός μηνύματος από συμβολοσειρά σε **πίνακα μπλοκ περιεχομένου**, και τοποθετήστε ταυτόχρονα στον πίνακα μπλοκ `text` και μπλοκ `image_url`—αυτό είναι πλήρως συνεπές με το OpenAI, καθώς και με τη μορφή συμβατότητας OpenAI του επίσημου Gemini.

Το `image_url.url` υποστηρίζει δύο μορφές:
- **base64 `data:` URI（συνιστάται, πιο σταθερό）**：Η μορφή είναι `data:&lt;τύπος μέσου>;base64,&lt;δεδομένα>`，για παράδειγμα `data:image/jpeg;base64,/9j/4AAQ...`。**Ο τύπος μέσου（MIME）έχει ήδη γραφτεί στο πρόθεμα `data:`**，επομένως δεν χρειάζεται, ούτε υπάρχει ξεχωριστό πεδίο `media_type`。
- **Δημόσια προσβάσιμο URL εικόνας**：για παράδειγμα `https://cdn.acedata.cloud/4hfydw.jpg`。

Υποστηριζόμενοι τύποι εικόνας：`png`、`jpeg`、`webp`、`heic`、`heif`。

Δείγμα κώδικα κλήσης Python（base64 data URI）：

```python
import base64
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

# Διαβάστε την τοπική εικόνα ως base64 data URI
with open("image.jpg", "rb") as f:
    base64_image = base64.b64encode(f.read()).decode("utf-8")
data_uri = f"data:image/jpeg;base64,{base64_image}"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-3.1-pro-preview",
    "messages": [
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "Περιγράψτε αυτήν την εικόνα με μία πρόταση."},
                {"type": "image_url", "image_url": {"url": data_uri}}
            ]
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Ροϊκή απόκριση

Αυτή η διεπαφή υποστηρίζει επίσης ροϊκή απόκριση, κάτι που είναι πολύ χρήσιμο για τη σύνδεση με ιστοσελίδες και μπορεί να επιτρέψει στην ιστοσελίδα να υλοποιήσει εφέ εμφάνισης χαρακτήρα προς χαρακτήρα。

Εάν θέλετε να επιστρέφεται η απόκριση ροϊκά, μπορείτε να αλλάξετε την παράμετρο `stream ` στην κεφαλίδα του αιτήματος σε `true`。

Η τροποποίηση φαίνεται στην εικόνα, ωστόσο ο κώδικας κλήσης χρειάζεται αντίστοιχες αλλαγές για να υποστηρίξει τη ροϊκή απόκριση。

<p><img src="https://cdn.acedata.cloud/o2blmi.png" width="400" className="m-auto" /></p>

Αφού αλλάξετε το `stream` σε `true`，το API θα επιστρέφει τα αντίστοιχα δεδομένα JSON γραμμή προς γραμμή, και σε επίπεδο κώδικα χρειάζεται να κάνουμε τις αντίστοιχες αλλαγές για να λάβουμε αποτελέσματα γραμμή προς γραμμή。

Δείγμα κώδικα κλήσης Python：

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-2.5-pro",
    "messages": [{"role":"user","content":"Hello,What model are you?"}],
    "stream": True,
    "stream_options": {"include_usage": True}
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

- `choices`, οι πληροφορίες απάντησης που παρέχει το Gemini για την ερώτηση.

Υποστηρίζεται επίσης η JavaScript, για παράδειγμα, ο κώδικας κλήσης ροής για Node.js είναι ο εξής:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "gemini-2.5-pro",
    messages: [{ role: "user", content: "Hello, what model are you?" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/gemini/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

## Συνομιλία πολλαπλών γύρων

Εάν θέλετε να ενσωματώσετε λειτουργία συνομιλίας πολλαπλών γύρων, πρέπει να υποβάλετε πολλαπλές ερωτήσεις στο πεδίο `messages`. Ένα συγκεκριμένο παράδειγμα πολλαπλών ερωτήσεων εμφανίζεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/qvzu06.png" width="400" className="m-auto" /></p>

Παράδειγμα κώδικα κλήσης Python:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"

payload = {
    "model": "gemini-2.5-pro",

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, αν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
