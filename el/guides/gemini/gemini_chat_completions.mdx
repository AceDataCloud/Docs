Το Google Gemini είναι ένα πολύ ισχυρό σύστημα συνομιλίας AI, το οποίο μπορεί να δημιουργήσει ομαλές και φυσικές απαντήσεις μέσα σε λίγα δευτερόλεπτα, αρκεί να εισαγάγετε μια προτροπή. Το Gemini μπορεί να παρέχει εντυπωσιακή έξυπνη υποστήριξη, βελτιώνοντας σημαντικά την αποδοτικότητα εργασίας και τη δημιουργικότητα των ανθρώπων.

Αυτό το έγγραφο παρουσιάζει κυρίως τη διαδικασία χρήσης του Gemini Chat Completion API· με αυτό μπορούμε να χρησιμοποιούμε εύκολα τη λειτουργία συνομιλίας του επίσημου Gemini.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Gemini Chat Completion API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση προσφέρει δωρεάν υπόλοιπο για δωρεάν δοκιμή· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να φορτίσετε κοινό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Gemini Chat Completion API →](https://platform.acedata.cloud/documents/gemini-chat-completions)

## Βασική χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε το αντίστοιχο περιεχόμενο στη διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/f6ksts.png" width="400" className="m-auto" /></p>

Κατά την πρώτη χρήση αυτής της διεπαφής, χρειάζεται τουλάχιστον να συμπληρώσουμε τρία στοιχεία. Το ένα είναι το `authorization`, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα. Μια άλλη παράμετρος είναι το `model`, το `model` είναι η κατηγορία μοντέλου του επίσημου ιστότοπου Gemini που επιλέγουμε να χρησιμοποιήσουμε, ενώ τα διαθέσιμα μοντέλα καθορίζονται από την απαρίθμηση `model` στην τεκμηρίωση της διεπαφής. Η τελευταία παράμετρος είναι το `messages`, το `messages` είναι ο πίνακας των προτροπών που εισάγουμε· είναι ένας πίνακας που υποδεικνύει ότι μπορούν να υποβληθούν ταυτόχρονα πολλές προτροπές, και κάθε προτροπή περιλαμβάνει `role` και `content`, όπου το `role` δηλώνει τον ρόλο του ερωτώντος. Παρέχουμε τρεις ταυτότητες: `user`, `assistant`, `system`. Το άλλο, `content`, είναι το συγκεκριμένο περιεχόμενο της ερώτησής μας.

Ταυτόχρονα, μπορείτε να παρατηρήσετε ότι στα δεξιά δημιουργείται ο αντίστοιχος κώδικας κλήσης· μπορείτε να αντιγράψετε τον κώδικα και να τον εκτελέσετε απευθείας, ή να κάνετε απευθείας κλικ στο κουμπί «Try» για δοκιμή.

<p><img src="https://cdn.acedata.cloud/a3mdgy.png" width="400" className="m-auto" /></p>

> **Συμβουλή**: Τα flash της σειράς `gemini-3.x` είναι μοντέλα συλλογισμού και καταναλώνουν πρώτα reasoning tokens· ορίστε το `max_tokens` πάνω από 512, διαφορετικά μπορεί να επιστραφεί μόνο κενό περιεχόμενο. Το `gemini-3.8-flash` είναι το τρέχον προτεινόμενο μοντέλο Flash, υποστηρίζει έως 1 εκατομμύριο Token συμφραζομένων, εισαγωγή εικόνων, κλήση εργαλείων και αποκρίσεις ροής· επί του παρόντος καλείται μέσω της διεπαφής Chat Completions.

## Κατανόηση εικόνων (πολυτροπική είσοδος)

Το Gemini είναι ένα εγγενώς πολυτροπικό μοντέλο και μπορεί να «δει εικόνες» απευθείας. Για να εισαγάγετε μια εικόνα, αλλάξτε το `content` ενός μηνύματος από συμβολοσειρά σε **πίνακα μπλοκ περιεχομένου**, και τοποθετήστε ταυτόχρονα στον πίνακα ένα μπλοκ `text` και ένα μπλοκ `image_url` — αυτό είναι απολύτως συνεπές με το OpenAI, καθώς και με τη μορφή συμβατή με OpenAI του επίσημου Gemini.

Το `image_url.url` υποστηρίζει δύο συντακτικούς τρόπους:

- **base64 `data:` URI (συνιστάται, το πιο σταθερό)**: Η μορφή είναι `data:&lt;τύπος μέσου>;base64,&lt;δεδομένα>`, για παράδειγμα `data:image/jpeg;base64,/9j/4AAQ...`. **Ο τύπος μέσου (MIME) έχει ήδη γραφτεί στο πρόθεμα `data:`**, επομένως δεν χρειάζεται, ούτε υπάρχει, ξεχωριστό πεδίο `media_type`.
- **Δημόσια προσβάσιμο URL εικόνας**: Για παράδειγμα `https://cdn.acedata.cloud/4hfydw.jpg`.

Υποστηριζόμενοι τύποι εικόνων: `png`, `jpeg`, `webp`, `heic`, `heif`.

Δείγμα κώδικα κλήσης Python (base64 data URI):
```python
import base64
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

# 把本地图片读成 base64 data URI
with open("image.jpg", "rb") as f:
    base64_image = base64.b64encode(f.read()).decode("utf-8")
data_uri = f"data:image/jpeg;base64,{base64_image}"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-3.1-pro-preview",
    "messages": [
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "请用一句话描述这张图片。"},
                {"type": "image_url", "image_url": {"url": data_uri}}
            ]
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Μπορείτε επίσης να μεταβιβάσετε απευθείας ένα δημόσια προσβάσιμο URL εικόνας:

## Ροϊκές αποκρίσεις

Αυτή η διεπαφή υποστηρίζει επίσης ροϊκές αποκρίσεις, κάτι που είναι πολύ χρήσιμο για ενσωμάτωση σε ιστοσελίδες και επιτρέπει την υλοποίηση εφέ εμφάνισης χαρακτήρα προς χαρακτήρα.

Αν θέλετε να επιστρέφετε αποκρίσεις σε ροή, μπορείτε να αλλάξετε την παράμετρο `stream ` στην κεφαλίδα του αιτήματος σε `true`.

Τροποποιήστε το όπως φαίνεται στην εικόνα, ωστόσο ο κώδικας κλήσης χρειάζεται αντίστοιχες αλλαγές για να υποστηρίζει ροϊκές αποκρίσεις.

<p><img src="https://cdn.acedata.cloud/o2blmi.png" width="400" className="m-auto" /></p>

Αφού τροποποιήσετε το `stream` σε `true`, το API θα επιστρέφει τα αντίστοιχα δεδομένα JSON γραμμή προς γραμμή· σε επίπεδο κώδικα πρέπει να κάνουμε τις αντίστοιχες τροποποιήσεις για να λάβουμε τα αποτελέσματα γραμμή προς γραμμή.

Δείγμα κώδικα κλήσης Python:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-2.5-pro",
    "messages": [{"role":"user","content":"Hello,What model are you?"}],
    "stream": True,
    "stream_options": {"include_usage": True}
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Μπορείτε να δείτε ότι στην απόκριση υπάρχουν πολλά `data`, και το `choices` μέσα στο `data` είναι το πιο πρόσφατο περιεχόμενο απάντησης, σύμφωνα με όσα παρουσιάστηκαν παραπάνω. Το `choices` είναι το νέο περιεχόμενο απάντησης και μπορείτε να το ενσωματώσετε στο σύστημά σας βάσει του αποτελέσματος. Ταυτόχρονα, το τέλος της ροϊκής απόκρισης κρίνεται από το περιεχόμενο του `data`: αν το περιεχόμενο είναι `[DONE]`, αυτό υποδηλώνει ότι η απάντηση της ροϊκής απόκρισης έχει ολοκληρωθεί πλήρως. - `model `，το μοντέλο Gemini του επίσημου ιστότοπου που επιλέχθηκε.
- `choices`，οι πληροφορίες απάντησης που παρέχει το Gemini για το ερώτημα.

Υποστηρίζεται επίσης το JavaScript, για παράδειγμα, ο κώδικας ροής κλήσης του Node.js είναι ο εξής:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "gemini-2.5-pro",
    messages: [{ role: "user", content: "Hello, what model are you?" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/gemini/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

## Χειρισμός σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και τις σχετικές πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

    "message": "fetch failed"

}
