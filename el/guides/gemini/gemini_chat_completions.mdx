Το Google Gemini είναι ένα πολύ ισχυρό σύστημα AI συνομιλίας, το οποίο μπορεί να δημιουργήσει ομαλές και φυσικές απαντήσεις σε λίγα δευτερόλεπτα απλά εισάγοντας λέξεις-κλειδιά. Το Gemini μπορεί να προσφέρει εκπληκτική έξυπνη βοήθεια, αυξάνοντας σημαντικά την αποδοτικότητα και τη δημιουργικότητα των ανθρώπων.

Αυτό το έγγραφο περιγράφει κυρίως τη διαδικασία χρήσης του Gemini Chat Completion API, επιτρέποντάς μας να χρησιμοποιήσουμε εύκολα τη λειτουργία συνομιλίας του επίσημου Gemini.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Gemini Chat Completion API, μπορείτε πρώτα να επισκεφθείτε τη σελίδα [Gemini Chat Completion API](https://platform.acedata.cloud/documents/ae54bf9b-af41-4072-b969-3756b6d66834) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να σας προσκαλέσουν να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/f6ksts.png" width="400" className="m-auto" /></p>

Κατά την πρώτη χρήση αυτού του API, πρέπει τουλάχιστον να συμπληρώσουμε τρία περιεχόμενα, ένα είναι το `authorization`, το οποίο μπορείτε να επιλέξετε απευθείας από τη λίστα. Ένα άλλο παράμετρο είναι το `model`, το οποίο είναι η κατηγορία μοντέλου που επιλέγουμε να χρησιμοποιήσουμε από την επίσημη ιστοσελίδα του Gemini. Εδώ έχουμε κυρίως 6 μοντέλα, λεπτομέρειες μπορείτε να δείτε στα μοντέλα που παρέχουμε. Η τελευταία παράμετρος είναι το `messages`, το οποίο είναι ο πίνακας των ερωτήσεων που εισάγουμε, είναι ένας πίνακας που δηλώνει ότι μπορείτε να ανεβάσετε πολλές ερωτήσεις ταυτόχρονα, κάθε ερώτηση περιλαμβάνει το `role` και το `content`, όπου το `role` δηλώνει τον ρόλο του ερωτώντος, παρέχουμε τρεις ταυτότητες, δηλαδή `user`, `assistant`, `system`. Το άλλο `content` είναι το συγκεκριμένο περιεχόμενο της ερώτησής μας.

Μπορείτε επίσης να παρατηρήσετε ότι στα δεξιά υπάρχει η αντίστοιχη γεννήτρια κώδικα κλήσης, μπορείτε να αντιγράψετε τον κώδικα και να τον εκτελέσετε απευθείας ή να κάνετε κλικ στο κουμπί «Try» για να δοκιμάσετε.

## Ροή Αντίκτυπου

Αυτή η διεπαφή υποστηρίζει επίσης ροή απάντησης, η οποία είναι πολύ χρήσιμη για την ενσωμάτωσή της σε ιστοσελίδες, επιτρέποντας την εμφάνιση των αποτελεσμάτων λέξη προς λέξη.

Εάν θέλετε να επιστρέψετε την απάντηση με ροή, μπορείτε να αλλάξετε την παράμετρο `stream` στην κεφαλίδα του αιτήματος σε `true`.

Η αλλαγή είναι όπως φαίνεται στην εικόνα, αλλά ο κώδικας κλήσης χρειάζεται να έχει τις αντίστοιχες αλλαγές για να υποστηρίξει τη ροή απάντησης.

<p><img src="https://cdn.acedata.cloud/o2blmi.png" width="400" className="m-auto" /></p>

Αφού αλλάξετε το `stream` σε `true`, το API θα επιστρέφει γραμμή προς γραμμή τα αντίστοιχα δεδομένα JSON, και σε επίπεδο κώδικα θα χρειαστεί να κάνουμε τις αντίστοιχες αλλαγές για να αποκτήσουμε τα αποτελέσματα γραμμή προς γραμμή.

Παράδειγμα κώδικα κλήσης σε Python:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-2.5-pro",
    "messages": [{"role":"user","content":"Γειά σου, ποιο μοντέλο είσαι;"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Η JavaScript υποστηρίζεται επίσης, όπως φαίνεται στον παρακάτω κώδικα ροής κλήσης Node.js:

```javascript
const options = {
  method: "post",
  headers: {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
  },

    "model": "gemini-2.5-pro",

    "stream": true
  })
};

fetch("https://api.acedata.cloud/gemini/chat/completions", options)
  .then(response => response.json())
  .then(response => console.log(response))
  .catch(err => console.error(err));
```

## Πολυδιάστατος Διάλογος

Αν θέλετε να ενσωματώσετε τη λειτουργία πολυδιάστατου διαλόγου, πρέπει να ανεβάσετε πολλαπλά ερωτήματα στο πεδίο `messages`, τα συγκεκριμένα παραδείγματα ερωτημάτων είναι όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/qvzu06.png" width="400" className="m-auto" /></p>

Παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-2.5-pro",
    "messages": [{"role":"user","content":"Γειά σου"},{"role":"assistant","content":"Γειά σου! Πώς μπορώ να σε βοηθήσω σήμερα;"},{"role":"user","content":"Ποιο μοντέλο είσαι;"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση σφαλμάτων

Κατά την κλήση της API, εάν προκύψει σφάλμα, η API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε ξεπεράσει το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
