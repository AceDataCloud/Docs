Το Google Gemini είναι ένα πολύ ισχυρό σύστημα διαλόγου AI, το οποίο μπορεί να δημιουργήσει ομαλές και φυσικές απαντήσεις μέσα σε λίγα δευτερόλεπτα μέσω της εισαγωγής προτροπών. Αυτό το έγγραφο περιγράφει κυρίως τη μέθοδο χρήσης του Gemini Generate Content API, το οποίο είναι η επίσημη εγγενής μορφή API της Google και υποστηρίζει τα δύο endpoints `generateContent` και `streamGenerateContent`.

## Διαφορές από το Chat Completions API

Το Gemini Generate Content API χρησιμοποιεί την επίσημη εγγενή μορφή αιτήματος της Google (πεδίο `contents`), αντί για τη συμβατή με OpenAI μορφή (πεδίο `messages`). Εάν χρησιμοποιείτε ήδη το Google Gemini SDK ή είστε εξοικειωμένοι με την επίσημη μορφή API, μπορείτε να χρησιμοποιήσετε απευθείας αυτό το API χωρίς να τροποποιήσετε τη μορφή αιτήματος.

## Τρέχον υποστηριζόμενο εύρος

Η διεπαφή δέχεται εισόδους κειμένου, εικόνας, βίντεο και ήχου (`inlineData` ή `fileData`), ρυθμίσεις σκέψης και δηλώσεις προσαρμοσμένων συναρτήσεων. Η έξοδος ήχου, τα ενσωματωμένα εργαλεία και τα εγγενή πεδία όπως η ρητή προσωρινή αποθήκευση περιβάλλοντος δεν έχουν ακόμη εγγυημένη ενιαία διαθεσιμότητα· ανατρέξτε στην πραγματική απόκριση του συγκεκριμένου μοντέλου.

Όταν υποβάλλετε αρχεία όπως ήχο χρησιμοποιώντας `fileData.fileUri`, βεβαιωθείτε ότι το αρχείο είναι άμεσα προσβάσιμο μέσω HTTPS, δεν εξαρτάται από κατάσταση σύνδεσης και ότι η περίοδος ισχύος του υπογεγραμμένου συνδέσμου καλύπτει ολόκληρο τον χρόνο επεξεργασίας του αιτήματος. Η μη ροϊκή ανάλυση ήχου επιστρέφει αποτέλεσμα μόνο αφού το μοντέλο ολοκληρώσει την επεξεργασία, και μπορεί να διαρκέσει πάνω από 90 δευτερόλεπτα· ο πελάτης θα πρέπει να ορίζει επαρκώς μεγάλο συνολικό χρονικό όριο ανάλογα με το μέγεθος του αρχείου και το επιχειρηματικό σενάριο, ώστε να αποφεύγεται η αποσύνδεση ενώ ο διακομιστής εξακολουθεί να επεξεργάζεται.

## Διαδικασία αίτησης

Πριν χρησιμοποιήσετε το Gemini Generate Content API, επισκεφθείτε πρώτα τη σελίδα [Gemini Generate Content API](https://platform.acedata.cloud/documents/gemini-generate-content-api) και κάντε κλικ στο κουμπί "Λήψη" για να αποκτήσετε τα διαπιστευτήρια που απαιτούνται για το αίτημα.

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης. Η πρώτη αίτηση περιλαμβάνει δωρεάν ποσό χρήσης.

## Βασική χρήση

### Non-Streaming（μη ροϊκή）

Στείλτε αίτημα POST στο `/v1beta/models/{model}:generateContent`:

> **Σημείωση**：Η σειρά `gemini-3.x` flash είναι μοντέλα σκέψης και θα καταναλώσει πρώτα reasoning tokens· ορίστε το `generationConfig.maxOutputTokens` πάνω από 512, διαφορετικά ενδέχεται να επιστραφεί μόνο κενό περιεχόμενο.

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "你好，请介绍一下你自己"
          }
        ]
      }
    ]
  }'
```

Παράδειγμα επιστρεφόμενου αποτελέσματος:

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [{"text": "你好！很高兴与你交流。"}]
      },
      "finishReason": "MAX_TOKENS"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 6,
    "candidatesTokenCount": 19,
    "thoughtsTokenCount": 489,
    "totalTokenCount": 514
  },
  "usage": {
    "prompt_tokens": 6,
    "completion_tokens": 19,
    "total_tokens": 514,
    "thoughts_tokens": 489,
    "cost": {
      "amount": 0.008860916380159999,
      "currency": "credit",
      "list_amount": 0.009631430847999998
    }
  },
  "modelVersion": "gemini-3.5-flash",
  "model": "gemini-3.5-flash"
}
```

Τα πεδία token στο `usageMetadata` χρεώνονται σύμφωνα με την εγγενή σημασιολογία του Gemini:

- Το `promptTokenCount` περιλαμβάνει το `cachedContentTokenCount` και το τμήμα που επιτυγχάνει προσωρινή αποθήκευση υπολογίζεται με την τιμή ανάγνωσης cache, χωρίς να υπολογίζεται ξανά ως κανονική είσοδος.
- Τα `promptTokensDetails` και `cacheTokensDetails` κανονικοποιούνται σε `text_tokens`, `image_tokens`, `video_tokens`, `audio_tokens` και στις αντίστοιχες λεπτομέρειες `cached_*` κάτω από το `usage.prompt_tokens_details`. Αυτές οι τιμές περιλαμβάνονται αντίστοιχα στα `prompt_tokens` και `cached_tokens`· διαφορετικές τροπικότητες επανυπολογίζονται μόνο με βάση τις αντίστοιχες τιμές τους και δεν χρεώνονται διπλά.
- Τα `candidatesTokenCount` και `thoughtsTokenCount` υπολογίζονται και τα δύο με την τιμή output token.
- Το `toolUsePromptTokenCount` είναι ανεξάρτητο tool input token και υπολογίζεται με την τιμή input token.

Το Ace Data Cloud επιστρέφει επιπλέον το κανονικοποιημένο αντικείμενο `usage`, και το κόστος αυτής της κλήσης διαβάζεται ενιαία μεταξύ πρωτοκόλλων μοντέλων από το `usage.cost`. Το `cost` είναι μια προαιρετική προεπισκόπηση κόστους· όταν η προεπισκόπηση τιμής δεν είναι προσωρινά διαθέσιμη, η απόκριση του μοντέλου θα επιστρέφεται κανονικά, αλλά ενδέχεται να μην περιλαμβάνει αυτό το πεδίο. Η τελική χρέωση βασίζεται στα αρχεία χρήσης.

### Streaming（ροϊκή）

Στείλτε αίτημα POST στο `/v1beta/models/{model}:streamGenerateContent?alt=sse`:

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "写一首关于春天的诗"
          }
        ]
      }
    ]
  }'
```

Η ροϊκή επιστροφή θα επιστρέφει σταδιακά περιεχόμενο σε μορφή SSE（Server-Sent Events）. Τα ενδιάμεσα συμβάντα συνήθως περιλαμβάνουν μόνο αυξητικό περιεχόμενο· το συμβάν τελικής κατάστασης που περιέχει την έγκυρη χρήση θα περιλαμβάνει `usageMetadata` και κανονικοποιημένο `usage`, ενώ το κόστος παραμένει στο `usage.cost`:

```text
data: {"candidates":[{"content":{"parts":[{"text":"Hello!"}],"role":"model"},"index":0}],"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

data: {"candidates":[{"content":{"parts":[],"role":"model"},"finishReason":"STOP","index":0}],"usageMetadata":{"promptTokenCount":7,"candidatesTokenCount":89,"totalTokenCount":96},"usage":{"prompt_tokens":7,"completion_tokens":89,"total_tokens":96,"cost":{"amount":0.00026161075472,"currency":"credit","list_amount":0.000284359516}},"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

```

Το κλείσιμο της σύνδεσης υποδηλώνει το τέλος της ροής· η εγγενής ροή Gemini δεν αποστέλλει `data: [DONE]`. Εάν η προεπισκόπηση τελικής τιμής δεν είναι προσωρινά διαθέσιμη, το `usage` θα εξακολουθεί να επιστρέφει τη χρήση token, αλλά θα παραλείπει το `cost`.

### Εσωτερική σκέψη και περίληψη σκέψης

Η εσωτερική σκέψη του μοντέλου και η επιστροφή περίληψης σκέψης στον καλούντα είναι δύο ανεξάρτητες ρυθμίσεις:

- Τα `thinkingBudget` ή `thinkingLevel` ελέγχουν τον προϋπολογισμό ή το βάθος της εσωτερικής σκέψης του μοντέλου· τα υποστηριζόμενα πεδία και τιμές εξαρτώνται από το μοντέλο.
- Το `includeThoughts` ελέγχει εάν επιστρέφεται περίληψη σκέψης και η προεπιλεγμένη τιμή είναι `false`. Όταν παραλείπεται αυτό το πεδίο ή περνάει το `false`, ούτε οι κανονικές JSON ούτε οι αποκρίσεις ροής SSE επιστρέφουν κείμενο με σήμανση `thought: true`· αυτά τα κείμενα διατηρούνται μόνο όταν περνάει ρητά η τιμή Boolean `true`.

Όταν το αίτημα δεν ορίζει το `includeThoughts`, το API περνάει από προεπιλογή το `false` στα μοντέλα δημιουργίας που υποστηρίζουν διαμόρφωση σκέψης, αποφεύγοντας περιλήψεις που δεν χρειάζεται το αίτημα· οι τιμές, ο προϋπολογισμός σκέψης και τα επίπεδα που περνάει ρητά ο πελάτης διατηρούνται. Το γνωστό `gemini-2.5-flash-image`, το οποίο δεν υποστηρίζει διαμόρφωση σκέψης, δεν θα λάβει αυτόματα αυτό το πεδίο, ενώ ούτε στα αιτήματα `countTokens` θα προστεθεί διαμόρφωση δημιουργίας.

Η απενεργοποίηση της περίληψης δεν ισοδυναμεί με απενεργοποίηση της εσωτερικής σκέψης, ούτε εγγυάται μείωση των token εσωτερικής σκέψης. Εάν η απόκριση εξακολουθεί να περιέχει μη ζητημένο κείμενο σκέψης, οι έξοδοι κανονικού JSON και SSE θα το φιλτράρουν περαιτέρω, διατηρώντας την κανονική απάντηση, τις υπογραφές και την πραγματική χρήση.

Όταν χρειάζεται να προβάλετε την περίληψη, ενεργοποιήστε τη ρητά με τον ακόλουθο τρόπο. Όταν το μοντέλο δεν έχει δημιουργήσει διαθέσιμη περίληψη, ενδέχεται να μην υπάρχει κείμενο σκέψης ακόμη και αν είναι ενεργοποιημένη:

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "解释量子纠缠"}]
    }
  ],
  "generationConfig": {
    "thinkingConfig": {
      "includeThoughts": true
    }
  }
}
```

Το `thoughtSignature` είναι κρυπτογραφημένη κατάσταση που απαιτείται για τους επόμενους γύρους, όχι κείμενο περίληψης σκέψης, και δεν ελέγχεται από τον διακόπτη `includeThoughts`. Η υπογραφή μπορεί να βρίσκεται σε κανονική απάντηση, κλήση συνάρτησης ή κενό Part κειμένου· όταν φιλτράρεται το κείμενο σκέψης, διατηρούνται η υπογραφή και άλλα πεδία του ίδιου Part, επομένως η απόκριση μπορεί να εξακολουθεί να περιέχει Part που φέρουν μόνο υπογραφή και έχουν κενό κείμενο. Κατά τη χειροκίνητη διατήρηση ιστορικού πολλών γύρων, πρέπει να διατηρείται η σειρά αυτών των Part και η θέση των υπογραφών· μην μετακινείτε τις υπογραφές και μην τις συγχωνεύετε.

Τα `usageMetadata` και `usage` εξακολουθούν να καταγράφουν την πραγματική χρήση. Η απόκρυψη της περίληψης δεν μηδενίζει το `thoughtsTokenCount` και η χρέωση εξακολουθεί να υπολογίζεται με βάση την πραγματική χρήση και τους τρέχοντες κανόνες τιμολόγησης.

Ανατρέξτε στην επίσημη [τεκμηρίωση της Google για τη σκέψη και τις περιλήψεις σκέψης](https://firebase.google.com/docs/ai-logic/thinking) και στους [κανόνες υπογραφών σκέψης](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/thinking/thought-signatures).

## Ρυθμίσεις ασφάλειας

Το φιλτράρισμα περιεχομένου μπορεί να ελεγχθεί μέσω του `safetySettings`:

```json
{
  "contents": [...],
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_ONLY_HIGH"
    }
  ]
}
```

## Χειρισμός σφαλμάτων

| Κωδικός κατάστασης HTTP | Σημασία             |
| -------- | -------------- |
| 400      | Μη έγκυρες παράμετροι αιτήματος         |
| 401      | Αποτυχία ελέγχου ταυτότητας, ελέγξτε το Token |
| 403      | Το περιεχόμενο αποκλείστηκε από το φίλτρο ασφαλείας     |
| 429      | Τα αιτήματα είναι υπερβολικά συχνά         |
| 500      | Εσωτερικό σφάλμα διακομιστή        |
