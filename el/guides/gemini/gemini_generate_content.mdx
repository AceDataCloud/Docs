Το Google Gemini είναι ένα πολύ ισχυρό σύστημα διαλόγου AI, το οποίο μπορεί να δημιουργήσει ομαλές και φυσικές απαντήσεις μέσα σε λίγα δευτερόλεπτα μέσω της εισαγωγής προτροπών. Αυτό το έγγραφο περιγράφει κυρίως τη μέθοδο χρήσης του Gemini Generate Content API. Πρόκειται για τη μορφή εγγενούς API της Google και υποστηρίζει τα δύο endpoints `generateContent` και `streamGenerateContent`.

## Διαφορές από το Chat Completions API

Το Gemini Generate Content API χρησιμοποιεί την επίσημη εγγενή μορφή αιτήματος της Google (πεδίο `contents`), αντί για τη συμβατή με OpenAI μορφή (πεδίο `messages`). Εάν χρησιμοποιείτε ήδη το Google Gemini SDK ή είστε εξοικειωμένοι με την επίσημη μορφή API, μπορείτε να χρησιμοποιήσετε αυτό το API απευθείας χωρίς να τροποποιήσετε τη μορφή του αιτήματος.

## Τρέχον εύρος υποστήριξης

Η διεπαφή δέχεται εισόδους κειμένου, εικόνων, βίντεο και ήχου (`inlineData` ή `fileData`), ρυθμίσεις σκέψης και δηλώσεις προσαρμοσμένων συναρτήσεων. Η έξοδος ήχου, τα ενσωματωμένα εργαλεία και τα εγγενή πεδία όπως η ρητή προσωρινή αποθήκευση περιβάλλοντος δεν έχουν ακόμη εγγυημένη ενιαία διαθεσιμότητα· ανατρέξτε στην πραγματική απόκριση του συγκεκριμένου μοντέλου.

Όταν υποβάλλετε αρχεία όπως ήχο χρησιμοποιώντας `fileData.fileUri`, βεβαιωθείτε ότι το αρχείο είναι απευθείας προσβάσιμο μέσω HTTPS, δεν εξαρτάται από κατάσταση σύνδεσης, και ότι η περίοδος ισχύος του υπογεγραμμένου συνδέσμου καλύπτει ολόκληρο τον χρόνο επεξεργασίας του αιτήματος. Η μη ροϊκή ανάλυση ήχου επιστρέφει αποτελέσματα μόνο αφού το μοντέλο ολοκληρώσει την επεξεργασία, και μπορεί να διαρκέσει πάνω από 90 δευτερόλεπτα· ο πελάτης θα πρέπει να ορίσει επαρκώς μεγάλο συνολικό χρονικό όριο ανάλογα με το μέγεθος του αρχείου και το επιχειρηματικό σενάριο, ώστε να αποφευχθεί η διακοπή της σύνδεσης ενώ ο διακομιστής εξακολουθεί να επεξεργάζεται.

## Διαδικασία αίτησης

Πριν χρησιμοποιήσετε το Gemini Generate Content API, επισκεφθείτε πρώτα τη σελίδα [Gemini Generate Content API](https://platform.acedata.cloud/documents/gemini-generate-content-api) και κάντε κλικ στο κουμπί «Λήψη» για να αποκτήσετε τα διαπιστευτήρια που απαιτούνται για το αίτημα.

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης. Η πρώτη αίτηση περιλαμβάνει δωρεάν ποσό χρήσης.

## Βασική χρήση

### Non-Streaming (μη ροϊκή)

Στείλτε ένα αίτημα POST στο `/v1beta/models/{model}:generateContent`:

> **Συμβουλή**: Η σειρά `gemini-3.x` flash αποτελεί μοντέλο σκέψης και θα καταναλώσει πρώτα reasoning tokens· ορίστε το `generationConfig.maxOutputTokens` πάνω από 512, διαφορετικά ενδέχεται να επιστραφεί μόνο κενό περιεχόμενο.

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "你好，请介绍一下你自己"
          }
        ]
      }
    ]
  }'
```

Παράδειγμα αποτελέσματος επιστροφής:

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [{"text": "你好！很高兴与你交流。"}]
      },
      "finishReason": "MAX_TOKENS"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 6,
    "candidatesTokenCount": 19,
    "thoughtsTokenCount": 489,
    "totalTokenCount": 514
  },
  "usage": {
    "prompt_tokens": 6,
    "completion_tokens": 19,
    "total_tokens": 514,
    "thoughts_tokens": 489,
    "cost": {
      "amount": 0.008860916380159999,
      "currency": "credit",
      "list_amount": 0.009631430847999998
    }
  },
  "modelVersion": "gemini-3.5-flash",
  "model": "gemini-3.5-flash"
}
```

Τα πεδία token στο `usageMetadata` χρεώνονται σύμφωνα με τη εγγενή σημασιολογία του Gemini:

- Το `promptTokenCount` περιλαμβάνει το `cachedContentTokenCount`· το τμήμα που επιτυγχάνει προσωρινή αποθήκευση υπολογίζεται με την τιμή ανάγνωσης cache και δεν υπολογίζεται ξανά ως κανονική είσοδος.
- Τα `promptTokensDetails` και `cacheTokensDetails` κανονικοποιούνται σε `text_tokens`, `image_tokens`, `video_tokens`, `audio_tokens` και στα αντίστοιχα στοιχεία `cached_*` κάτω από το `usage.prompt_tokens_details`. Αυτές οι τιμές περιλαμβάνονται αντίστοιχα στα `prompt_tokens` και `cached_tokens`· διαφορετικές μορφές πολυμέσων επανυπολογίζονται μόνο με τις αντίστοιχες τιμές τους και δεν χρεώνονται διπλά.
- Τα `candidatesTokenCount` και `thoughtsTokenCount` υπολογίζονται και τα δύο με την τιμή των output token.
- Το `toolUsePromptTokenCount` είναι ανεξάρτητο token εισόδου εργαλείου και υπολογίζεται με την τιμή των input token.

Το Ace Data Cloud επιστρέφει επιπλέον το κανονικοποιημένο αντικείμενο `usage`, και το κόστος αυτής της κλήσης διαβάζεται ενιαία μεταξύ πρωτοκόλλων μοντέλων από το `usage.cost`. Το `cost` είναι μια προαιρετική προεπισκόπηση κόστους· όταν η προεπισκόπηση τιμής δεν είναι προσωρινά διαθέσιμη, η απόκριση του μοντέλου εξακολουθεί να επιστρέφεται κανονικά, αλλά ενδέχεται να μην περιλαμβάνει αυτό το πεδίο. Η τελική χρέωση βασίζεται στα αρχεία χρήσης.

### Streaming (ροϊκή)

Στείλτε ένα αίτημα POST στο `/v1beta/models/{model}:streamGenerateContent?alt=sse`:

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "写一首关于春天的诗"
          }
        ]
      }
    ]
  }'
```

Η ροϊκή επιστροφή θα επιστρέφει σταδιακά περιεχόμενο σε μορφή SSE (Server-Sent Events). Τα ενδιάμεσα συμβάντα συνήθως περιλαμβάνουν μόνο αυξητικό περιεχόμενο· το τελικό συμβάν με την έγκυρη χρήση θα περιλαμβάνει `usageMetadata` και κανονικοποιημένο `usage`, ενώ το κόστος εξακολουθεί να βρίσκεται στο `usage.cost`:

```text
data: {"candidates":[{"content":{"parts":[{"text":"Hello!"}],"role":"model"},"index":0}],"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

data: {"candidates":[{"content":{"parts":[],"role":"model"},"finishReason":"STOP","index":0}],"usageMetadata":{"promptTokenCount":7,"candidatesTokenCount":89,"totalTokenCount":96},"usage":{"prompt_tokens":7,"completion_tokens":89,"total_tokens":96,"cost":{"amount":0.00026161075472,"currency":"credit","list_amount":0.000284359516}},"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

```

Το κλείσιμο της σύνδεσης υποδηλώνει το τέλος της ροής· η εγγενής ροή Gemini δεν στέλνει `data: [DONE]`. Εάν η τελική προεπισκόπηση τιμής δεν είναι προσωρινά διαθέσιμη, το `usage` θα εξακολουθεί να επιστρέφει τη χρήση token, αλλά θα παραλείπει το `cost`.

## Προηγμένες λειτουργίες

### Οδηγίες συστήματος

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "你好"}]
    }
  ],
  "systemInstruction": {
    "parts": [{"text": "你是一个专业的诗人，所有回复都用诗歌形式。"}]
  }
}
```

### Διαμόρφωση δημιουργίας

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "讲一个故事"}]
    }
  ],
  "generationConfig": {
    "temperature": 0.7,
    "maxOutputTokens": 1024,
    "topP": 0.9,
    "topK": 40
  }
}
```

### Λειτουργία JSON

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {
          "text": "列出三个中国城市及其人口"
        }
      ]
    }
  ],
  "generationConfig": {
    "responseMimeType": "application/json",
    "responseSchema": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "city": {
            "type": "string"
          },
          "population": {
            "type": "integer"
          }
        }
      }
    }
  }
}
```

### Λειτουργία σκέψης (Thinking)

Τα μοντέλα που υποστηρίζουν τη λειτουργία σκέψης (όπως gemini-2.5-flash, gemini-2.5-pro) μπορούν να ενεργοποιήσουν τη λειτουργία σκέψης:

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "解释量子纠缠"}]
    }
  ],
  "generationConfig": {
    "thinkingConfig": {
      "includeThoughts": true,
      "thinkingBudget": 2048
    }
  }
}
```

### Κλήση συναρτήσεων

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "北京现在的天气怎么样？"}]
    }
  ],
  "tools": [
    {
      "functionDeclarations": [
        {
          "name": "get_weather",
          "description": "获取指定城市的天气信息",
          "parameters": {
            "type": "object",
            "properties": {
              "city": {
                "type": "string",
                "description": "城市名称"
              }
            },
            "required": ["city"]
          }
        }
      ]
    }
  ]
}
```

### Συνομιλία πολλαπλών γύρων

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "你好，我叫小明"}]
    },
    {
      "role": "model",
      "parts": [{"text": "你好小明！很高兴认识你。"}]
    },
    {
      "role": "user",
      "parts": [{"text": "我叫什么名字？"}]
    }
  ]
}
```

### Κατανόηση εικόνων

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {"text": "描述这张图片"},
        {
          "inlineData": {
            "mimeType": "image/jpeg",
            "data": "base64_encoded_image_data..."
          }
        }
      ]
    }
  ]
}
```

## Ρυθμίσεις ασφάλειας

Το φιλτράρισμα περιεχομένου μπορεί να ελεγχθεί μέσω του `safetySettings`:

```json
{
  "contents": [...],
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_ONLY_HIGH"
    }
  ]
}
```

## Διαχείριση σφαλμάτων

| Κωδικός κατάστασης HTTP | Σημασία             |
| -------- | -------------- |
| 400      | Μη έγκυρες παράμετροι αιτήματος         |
| 401      | Αποτυχία πιστοποίησης, ελέγξτε το Token |
| 403      | Το περιεχόμενο αποκλείστηκε από το φίλτρο ασφαλείας     |
| 429      | Τα αιτήματα είναι υπερβολικά συχνά         |
| 500      | Εσωτερικό σφάλμα διακομιστή        |
