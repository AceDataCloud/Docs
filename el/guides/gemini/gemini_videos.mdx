Το παρόν θα παρουσιάσει τις οδηγίες ενσωμάτωσης του Gemini Videos Generation API, το οποίο μπορεί να δημιουργεί βίντεο Google Gemini (omni-flash) μέσω της εισαγωγής κειμένου prompt (καθώς και προαιρετικών εικόνων αναφοράς).

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Gemini Videos Generation API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση παρέχει δωρεάν πίστωση, ώστε να μπορείτε να το δοκιμάσετε δωρεάν· όταν η πίστωση δεν επαρκεί, μπορείτε να φορτίσετε το γενικό υπόλοιπο από την [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Βασική χρήση

Ας κατανοήσουμε πρώτα τη βασική μέθοδο χρήσης: εισάγοντας το prompt `prompt`, το μοντέλο `model` και την αναλογία διαστάσεων `aspect_ratio`, μπορείτε να δημιουργήσετε το αντίστοιχο βίντεο.

Μπορείτε να δείτε ότι εδώ έχουμε ορίσει τα Request Headers, συμπεριλαμβανομένων των:

- `accept`: Τη μορφή του αποτελέσματος απόκρισης που θέλετε να λάβετε· εδώ συμπληρώνεται ως `application/json`, δηλαδή μορφή JSON.
- `authorization`: Το κλειδί για την κλήση του API, το οποίο μετά την αίτηση μπορεί να επιλεγεί απευθείας από την αναπτυσσόμενη λίστα.

Επιπλέον, έχουν οριστεί τα Request Body, συμπεριλαμβανομένων των:

- `prompt`: Το κείμενο prompt που περιγράφει το περιεχόμενο του βίντεο που θέλετε να δημιουργήσετε, **υποχρεωτικό**.
- `model`: Το μοντέλο για τη δημιουργία βίντεο· προς το παρόν υποστηρίζεται μόνο το `omni-flash`, και η προεπιλογή είναι επίσης `omni-flash`.
- `aspect_ratio`: Η αναλογία διαστάσεων του παραγόμενου βίντεο· μπορείτε να επιλέξετε `16:9` (οριζόντιο) ή `9:16` (κάθετο), με προεπιλογή το `16:9`.
- `resolution`: Η προαιρετική ανάλυση εξόδου· μπορείτε να επιλέξετε `720p` ή `1080p`, με προεπιλογή το `720p`.
- `image_urls`: Προαιρετικός πίνακας συνδέσμων εικόνων αναφοράς, που χρησιμοποιείται για την καθοδήγηση της δημιουργίας βίντεο· τα κενά στοιχεία θα αγνοηθούν. Όταν χρησιμοποιείται το `video_urls` για επεξεργασία βίντεο, αυτή η παράμετρος είναι υποχρεωτική (τουλάχιστον μία εικόνα).
- `video_urls`: Προαιρετικός πίνακας συνδέσμων βίντεο αναφοράς (έως 1), που χρησιμοποιείται για **επεξεργασία βίντεο / αναφορά βίντεο**· όταν παρέχεται, πρέπει ταυτόχρονα να παρέχεται τουλάχιστον μία `image_urls`.
- `callback_url`: Διεύθυνση ασύγχρονης επιστροφής κλήσης· μετά τη ρύθμιση, το API θα επιστρέψει αμέσως το `task_id`, και όταν ολοκληρωθεί η εργασία θα κάνει POST το αποτέλεσμα σε αυτή τη διεύθυνση.
- `async`: Προαιρετικό· όταν οριστεί σε `true`, το endpoint επιστρέφει αμέσως το `task_id`, χωρίς να χρειάζεται να παρέχετε `callback_url`, και στη συνέχεια μπορείτε να λαμβάνετε το αποτέλεσμα μέσω polling από το αντίστοιχο endpoint αναζήτησης εργασίας.

Κάντε κλικ στο κουμπί «Try» για να εκτελέσετε τη δοκιμή· το αποτέλεσμα που λαμβάνεται είναι παρόμοιο με το ακόλουθο:

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904-418c13e0605f.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden"
    }
  ],
  "started_at": 1784112953.856,
  "finished_at": 1784113021.328,
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Το επιστρεφόμενο αποτέλεσμα περιέχει πολλά πεδία, τα οποία παρουσιάζονται ως εξής:

- `success`: Αν το αίτημα δημιουργίας βίντεο αυτή τη φορά ήταν επιτυχές.
- `task_id`: Το ID της εργασίας δημιουργίας βίντεο αυτή τη φορά.
- `trace_id`: Το ID παρακολούθησης του τρέχοντος αιτήματος, που χρησιμοποιείται για την αντιμετώπιση προβλημάτων.
- `data`: Η λίστα αποτελεσμάτων των παραγόμενων βίντεο.
  - `id`: Το μοναδικό αναγνωριστικό του παραγόμενου βίντεο.
  - `video_url`: Η διεύθυνση συνδέσμου του παραγόμενου βίντεο (είναι `null` όταν το `state` είναι `pending`).
  - `state`: Η κατάσταση της εργασίας δημιουργίας βίντεο· μπορείτε να επιλέξετε `pending` / `succeeded` / `failed`.
  - `aspect_ratio`: Η αναλογία διαστάσεων αυτού του βίντεο, ίδια με την παράμετρο αιτήματος.
  - `prompt`: Το prompt που χρησιμοποιήθηκε για τη δημιουργία αυτού του βίντεο.

Στη σύγχρονη επιστροφή, στο ανώτερο επίπεδο θα περιλαμβάνονται επίσης πεδία όπως `started_at`, `finished_at`, `elapsed` (χρόνος που απαιτήθηκε, δευτερόλεπτα) και `cost` (χρέωση αυτή τη φορά, μονάδα Credit).

Χρειάζεται μόνο να λάβουμε το παραγόμενο βίντεο σύμφωνα με τη διεύθυνση συνδέσμου `video_url` στο `data` του αποτελέσματος.

Ο αντίστοιχος κώδικας CURL είναι ο ακόλουθος:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Ο αντίστοιχος κώδικας Python είναι ο ακόλουθος:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Δημιουργία βίντεο από εικόνα

Αν θέλετε να δημιουργήσετε βίντεο βάσει εικόνων αναφοράς, μπορείτε να περάσετε έναν ή περισσότερους συνδέσμους εικόνων στο `image_urls`, για να καθοδηγήσετε τη δημιουργία βίντεο:

```json
{
  "prompt": "The woman slowly turns around and smiles at the camera, gentle breeze",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/assets/examples/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3-5ccb6e83b402.png"
  ]
}
```

## Επεξεργασία βίντεο / βίντεο αναφοράς (είσοδος βίντεο, δημιουργία βίντεο)

Υποστηρίζεται η άμεση «εισαγωγή ενός βίντεο και δημιουργία ενός νέου βίντεο»: περάστε έναν σύνδεσμο βίντεο αναφοράς στο `video_urls` (έως 1), και **ταυτόχρονα** παρέχετε τουλάχιστον μία εικόνα αναφοράς στο `image_urls` (υποχρεωτική απαίτηση του upstream), και έπειτα χρησιμοποιήστε το `prompt` για να περιγράψετε το επιθυμητό αποτέλεσμα επεξεργασίας (αλλαγή στυλ, αλλαγή σκηνής, προσθήκη ή αφαίρεση στοιχείων κ.λπ.).

Παρακάτω είναι ένα πλήρες πραγματικό παράδειγμα—μετατροπή ενός βίντεο με ηλιόλουστη παραλία σε χειμωνιάτικη σκηνή με πυκνή χιονόπτωση, διατηρώντας ταυτόχρονα τη διάταξη της παραλίας, των φοινίκων και της μικρής βάρκας. Η επεξεργασία βίντεο απαιτεί περισσότερο χρόνο (σε αυτό το παράδειγμα περίπου 6,5 λεπτά), επομένως υποβάλλεται ασύγχρονα με `async: true`:
```json
{
  "prompt": "Turn this sunny tropical beach into a snowy winter scene with heavy falling snow and overcast sky; keep the same beach, palm trees and boat layout.",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://cdn.acedata.cloud/assets/examples/seedance/dd3dc063-3383-4f29-bedc-e771a096758c-044e05281a2a.mp4"
  ],
  "async": true
}
```

Μετά την υποβολή, το API επιστρέφει αμέσως το `task_id`:

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

Στη συνέχεια, χρησιμοποιήστε αυτό το `task_id` ως `id` για περιοδικό έλεγχο του [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks). Αφού ολοκληρωθεί η εργασία, μπορείτε να λάβετε το νέο βίντεο που δημιουργήθηκε (αυτό είναι το πραγματικό αποτέλεσμα επιστροφής αυτού του παραδείγματος):

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://cdn.acedata.cloud/assets/examples/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284-c5603ef983da.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "Turn this sunny tropical beach into a snowy winter scene with heavy falling snow and overcast sky; keep the same beach, palm trees and boat layout."
    }
  ],
  "started_at": 1784084482.914,
  "finished_at": 1784084877.09,
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Για αποτέλεσμα υψηλότερης ανάλυσης, μπορείτε να ορίσετε το `resolution` σε `1080p` (οι υπόλοιπες παράμετροι παραμένουν αμετάβλητες).

> Σημείωση: Οι σύνδεσμοι εισόδου / εξόδου πολυμέσων στο παράδειγμα είναι όλοι πραγματικά παραγόμενα αποτελέσματα. **Οι σύνδεσμοι για βίντεο και εικόνες που δημιουργούνται από την πλατφόρμα έχουν περίοδο διατήρησης και θα καταστούν άκυροι μετά τη λήξη τους**, επομένως κατεβάστε και αποθηκεύστε τα έγκαιρα στον δικό σας χώρο αποθήκευσης αφού λάβετε τα αποτελέσματα.

> Προσοχή: Επιτρέπεται το πολύ 1 βίντεο αναφοράς· και όταν παρέχεται `video_urls`, πρέπει να παρέχεται τουλάχιστον μία `image_urls`, διαφορετικά θα επιστραφεί το ακόλουθο σφάλμα παραμέτρων:

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (at least one reference image) is required when video_urls is provided."
  }
}
```

## Ασύγχρονη επανάκληση

Η δημιουργία βίντεο απαιτεί ορισμένο χρόνο επεξεργασίας. Εάν δεν θέλετε να διατηρείτε μια μακρά σύνδεση σε αναμονή, μπορείτε να περάσετε το `callback_url`, οπότε το API θα επιστρέψει αμέσως το `task_id` και, αφού ολοκληρωθεί η εργασία, θα στείλει το τελικό αποτέλεσμα με POST σε αυτήν τη διεύθυνση:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Το αποτέλεσμα που επιστρέφεται αμέσως είναι το εξής:

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## Ερώτημα αποτελέσματος εργασίας

Εάν χρησιμοποιήσατε ασύγχρονη επανάκληση ή θέλετε να ελέγξετε ενεργά την κατάσταση της εργασίας, μπορείτε να χρησιμοποιήσετε το [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) για να ελέγξετε την πιο πρόσφατη κατάσταση και το αποτέλεσμα της εργασίας βάσει του `task_id`. Στο σώμα του αιτήματος, περάστε το `task_id` που επιστράφηκε κατά τη δημιουργία του βίντεο ως `id`:

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

Το αποτέλεσμα που επιστρέφεται μετά την ολοκλήρωση της εργασίας είναι παρόμοιο με το ακόλουθο· η δομή του `response.data` είναι ίδια με εκείνη κατά τη σύγχρονη δημιουργία (κατά τη δημιουργία, το `state` είναι `pending` και το `video_url` είναι `null`):

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
  "type": "videos",
  "request": {
    "model": "omni-flash",
    "prompt": "A time-lapse of clouds over snow mountains at sunrise",
    "aspect_ratio": "16:9",
    "async": true
  },
  "response": {
    "success": true,
    "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
    "data": [
      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
        "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
        "state": "succeeded",
        "aspect_ratio": "16:9",
        "prompt": "A time-lapse of clouds over snow mountains at sunrise"
      }
    ],
    "elapsed": 96.716,
    "cost": {
      "amount": 1.932,
      "currency": "credit",
      "list_amount": 2.1
    }
  }
}
```

## Διαχείριση σφαλμάτων

Όταν παρουσιαστεί πρόβλημα με το αίτημα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και περιγραφή. Τα συνηθισμένα είναι τα εξής:

- `400`: Λανθασμένες παράμετροι αιτήματος, για παράδειγμα λείπει το `prompt` ή η τιμή του `aspect_ratio` δεν είναι έγκυρη.
- `401`: Αποτυχία ελέγχου ταυτότητας, το token είναι άκυρο ή δεν αντιστοιχεί στο API.
- `403`: Ανεπαρκές υπόλοιπο ή το prompt απορρίφθηκε επειδή ενεργοποίησε τον έλεγχο περιεχομένου.
- `500`: Εσωτερικό σφάλμα διακομιστή ή αποτυχία δημιουργίας από τον πάροχο.
