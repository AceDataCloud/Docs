Η κύρια λειτουργία του Hailuo Tasks API είναι να ερωτά την κατάσταση εκτέλεσης ενός έργου μέσω της εισαγωγής του ID έργου που έχει παραχθεί από το Hailuo Videos Generation API.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες διασύνδεσης του Hailuo Tasks API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του Hailuo Tasks API, μπορείτε εύκολα να ελέγξετε την κατάσταση εκτέλεσης των έργων του Hailuo Videos Generation API.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Hailuo Videos Generation API, πρώτα επισκεφθείτε την [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να ζητήσετε ξεχωριστά για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πίστωση, ώστε να μπορείτε να δοκιμάσετε δωρεάν. Όταν η πίστωση εξαντληθεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Hailuo Videos Generation API →](https://platform.acedata.cloud/documents/hailuo-videos-integration)

## Παράδειγμα αιτήματος

Το Hailuo Tasks API μπορεί να χρησιμοποιηθεί για να ελέγξει τα αποτελέσματα του Hailuo Videos Generation API. Για πληροφορίες σχετικά με το πώς να χρησιμοποιήσετε το Hailuo Videos Generation API, ανατρέξτε στην τεκμηρίωση [Hailuo Videos Generation API](https://platform.acedata.cloud/documents/hailuo-videos-generation-integration).

### Ρύθμιση κεφαλίδων αιτήματος και σώματος αιτήματος

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `id`: το ID του έργου που έχει ανέβει.
- `action`: ο τρόπος λειτουργίας του έργου.

Ρυθμίστε όπως φαίνεται στην παρακάτω εικόνα:

Μπορείτε να παρατηρήσετε ότι στη δεξιά πλευρά της σελίδας έχουν παραχθεί αυτόματα διάφοροι κώδικες σε γλώσσες, όπως φαίνεται στην εικόνα:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/hailuo/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "58cc618b-9639-4ee7-add2-d2fcf260d9a3",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/hailuo/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "58cc618b-9639-4ee7-add2-d2fcf260d9a3",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, το πεδίο request είναι το σώμα της αίτησης κατά την εκκίνηση του έργου, ενώ το πεδίο response είναι το σώμα της απάντησης που επιστρέφεται μετά την ολοκλήρωση του έργου. Η περιγραφή των πεδίων είναι ως εξής.

- `id`, το ID που δημιουργεί αυτό το έργο βίντεο, χρησιμοποιείται για την μοναδική αναγνώριση αυτού του έργου παραγωγής βίντεο.
- `request`, πληροφορίες αιτήματος στο έργο βίντεο.
- `response`, πληροφορίες απάντησης στο έργο βίντεο.
- `created_at`, χρόνος δημιουργίας του έργου, Unix χρονική σφραγίδα (δευτερόλεπτα, κινητής υποδιαστολής).
- `started_at`, χρόνος έναρξης εκτέλεσης του έργου, Unix χρονική σφραγίδα (δευτερόλεπτα, κινητής υποδιαστολής).
- `finished_at`, χρόνος ολοκλήρωσης του έργου, Unix χρονική σφραγίδα (δευτερόλεπτα, κινητής υποδιαστολής). Το πεδίο αυτό δεν επιστρέφεται αν το έργο δεν έχει ολοκληρωθεί.
- `elapsed`, χρόνος εκτέλεσης του έργου, μονάδα σε δευτερόλεπτα (κινητής υποδιαστολής, διατηρεί 3 δεκαδικά ψηφία). Το πεδίο αυτό δεν επιστρέφεται αν το έργο δεν έχει ολοκληρωθεί.

## Σφάλματα

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
