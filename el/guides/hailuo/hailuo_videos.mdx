Αυτό το άρθρο θα παρουσιάσει μια μέθοδο σύνδεσης με το Hailuo Videos Generation API, το οποίο μπορεί να δημιουργήσει επίσημα βίντεο Hailuo μέσω της εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Hailuo Videos Generation API, πρώτα πηγαίνετε στο [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν. Όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό σας υπόλοιπο στο [Console](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Hailuo Videos Generation API →](https://platform.acedata.cloud/documents/hailuo-videos-integration)

## Βασική Χρήση

Πρώτα πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τη λέξη-κλειδί `prompt`, τη δράση `action`, την αναφορά της πρώτης εικόνας `first_image_url` και το μοντέλο `model`, για να αποκτήσετε το επεξεργασμένο αποτέλεσμα. Πρώτα χρειάζεται να περάσετε ένα πεδίο `action`, της οποίας η τιμή είναι `generate`, και στη συνέχεια πρέπει να εισάγουμε το μοντέλο, το οποίο είναι κυρίως το μοντέλο βίντεο από εικόνα `minimax-i2v` και το μοντέλο βίντεο από κείμενο `minimax-t2v`, οι λεπτομέρειες είναι οι εξής:

<p><img src="https://cdn.acedata.cloud/7jyu0n.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `model`: το μοντέλο για τη δημιουργία του βίντεο, κυρίως τα μοντέλα βίντεο από εικόνα `minimax-i2v` και βίντεο από κείμενο `minimax-t2v`.
- `action`: η δράση της τρέχουσας εργασίας δημιουργίας βίντεο.
- `first_image_url`: όταν επιλέγετε το μοντέλο βίντεο από εικόνα `minimax-i2v`, πρέπει να ανεβάσετε τη σύνδεση της πρώτης εικόνας αναφοράς, δεν υποστηρίζει κωδικοποίηση Base64.
- `prompt`: η λέξη-κλειδί.
- `callback_url`: η διεύθυνση URL για την επιστροφή του αποτελέσματος.
- `async`: προαιρετικό, αν οριστεί σε `true`, η διεπαφή επιστρέφει αμέσως το `task_id`, χωρίς να χρειάζεται να παρέχετε `callback_url`, και στη συνέχεια μπορείτε να ελέγξετε το αποτέλεσμα μέσω της αντίστοιχης διεπαφής αναζήτησης εργασιών.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/8psuxw.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Δοκιμή» για να κάνετε μια δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "success": true,
  "task_id": "baf1034c-684c-46be-ae6d-89ebb89b690d",
  "trace_id": "3221eb74-1a25-447a-ba69-7d9b310e306c",
  "data": [
    {
      "id": "0pv8yhe4fdrge0cmckpv23pd2g",
      "model": "minimax-t2v",
      "prompt": "Internal heat",
      "video_url": "https://platform.cdn.acedata.cloud/czjl/qoueLWBokF3ud6tdVD6VJTZuXTnK5HaMO2qAOS46Ef8VSBFUA/tmp9e3u11c1.output.mp4",
      "state": "succeeded"
    }
  ]
}
```

Η επιστροφή του αποτελέσματος περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `success`, η κατάσταση της τρέχουσας εργασίας δημιουργίας βίντεο.
- `task_id`, το ID της τρέχουσας εργασίας δημιουργίας βίντεο.
- `trace_id`, το ID παρακολούθησης της τρέχουσας εργασίας δημιουργίας βίντεο.
- `data`, η λίστα αποτελεσμάτων της τρέχουσας εργασίας δημιουργίας βίντεο.
    - `id`, το ID του βίντεο της τρέχουσας εργασίας δημιουργίας βίντεο.
    - `prompt`, η λέξη-κλειδί της τρέχουσας εργασίας δημιουργίας βίντεο.
    - `model`, η σύνδεση του εξωφύλλου της τρέχουσας εργασίας δημιουργίας βίντεο.
    - `video_url`, η σύνδεση του βίντεο της τρέχουσας εργασίας δημιουργίας βίντεο.
    - `state`, η κατάσταση της τρέχουσας εργασίας δημιουργίας βίντεο.

Μπορείτε να δείτε ότι έχουμε λάβει ικανοποιητικές πληροφορίες βίντεο, απλά πρέπει να αποκτήσουμε το παραγόμενο βίντεο Hailuo μέσω της διεύθυνσης URL του βίντεο στο `data`.

Επιπλέον, αν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο παρακάτω κώδικας CURL:

```shell
curl -X POST 'https://api.acedata.cloud/hailuo/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "prompt": "Internal heat"
}'
```

## Ασύγχρονη Επιστροφή

Δεδομένου ότι ο χρόνος δημιουργίας του Hailuo Videos Generation API είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, αν το API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος. Έτσι, αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη επιστροφή.

Η συνολική διαδικασία είναι: όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`. Μετά την υποβολή του API αίτημα, το API θα επιστρέψει αμέσως ένα αποτέλεσμα που περιλαμβάνει ένα πεδίο `task_id`, το οποίο αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα του παραγόμενου βίντεο θα αποσταλεί μέσω POST JSON στη διεύθυνση URL `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε αυτό μέσω ενός παραδείγματος.

Πρώτα, η επιστροφή Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα, οι προγραμματιστές θα πρέπει να την αντικαταστήσουν με τη διεύθυνση URL του HTTP διακομιστή που έχουν δημιουργήσει. Για ευκολία, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να αποκτήσετε μια διεύθυνση Webhook URL, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/cjjfly.png)

Αντιγράψτε αυτή τη διεύθυνση URL και μπορείτε να τη χρησιμοποιήσετε ως Webhook, το παράδειγμα εδώ είναι `https://webhook.site/580b81f5-596e-4321-b03f-606770b0bb83`.

Στη συνέχεια, μπορούμε να ρυθμίσουμε το πεδίο `callback_url` στην παραπάνω διεύθυνση Webhook, ενώ συμπληρώνουμε τις αντίστοιχες παραμέτρους, οι λεπτομέρειες είναι όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/odabh3.png" width="500" className="m-auto" /></p>

Κάντε κλικ στην εκτέλεση και μπορείτε να δείτε ότι θα λάβετε αμέσως ένα αποτέλεσμα, όπως παρακάτω:

```
{
  "task_id": "05aff65c-5e84-442b-8e29-3a5d27130840"
}
```

Μετά από λίγο, μπορείτε να παρακολουθήσετε το αποτέλεσμα του παραγόμενου βίντεο στη διεύθυνση `https://webhook.site/580b81f5-596e-4321-b03f-606770b0bb83`, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/7jngb4.png)

Το περιεχόμενο είναι ως εξής:
```json
{
    "success": true,
    "task_id": "05aff65c-5e84-442b-8e29-3a5d27130840",
    "trace_id": "b9856b8a-725d-45c9-befe-e789d9fd9ffb",
    "data": [
        {
            "id": "t80jhsf96srg80cmcm6b0rk8gm",
            "model": "minimax-t2v",
            "prompt": "Εσωτερική θερμότητα",
            "video_url": "https://platform.cdn.acedata.cloud/czjl/YPaUz2DcwpJqItTXAG9XHAoEoj3dbF0XPU69LT5nefCMzBFUA/tmp8s_59jez.output.mp4",
            "state": "επιτυχία"
        }
    ]
}
```

Μπορείτε να δείτε ότι το αποτέλεσμα περιέχει ένα πεδίο `task_id`, ενώ τα υπόλοιπα πεδία είναι παρόμοια με τα παραπάνω, και μέσω αυτού του πεδίου μπορείτε να συνδέσετε τις εργασίες.

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα απόκρισης σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "η λήψη απέτυχε"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
