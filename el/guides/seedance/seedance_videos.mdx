Αυτό το άρθρο θα παρουσιάσει μια οδηγία ενσωμάτωσης SeeDance Videos Generation API, η οποία μπορεί να δημιουργήσει τα επίσημα βίντεο του SeeDance μέσω εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το SeeDance Videos Generation API, αρχικά μεταβείτε στην [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να λάβετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε· μετά την ολοκλήρωση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Με την πρώτη αίτηση προσφέρεται δωρεάν υπόλοιπο, ώστε να μπορείτε να το δοκιμάσετε δωρεάν· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να φορτίσετε το γενικό υπόλοιπο στην [Κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [SeeDance Videos Generation API →](https://platform.acedata.cloud/documents/seedance-videos)

## Βασική χρήση

Αρχικά ας κατανοήσουμε τη βασική μέθοδο χρήσης: εισάγοντας το κείμενο προτροπής `content.text`, τον τύπο `content.type=text` και το μοντέλο `model`, μπορείτε να λάβετε το επεξεργασμένο αποτέλεσμα· οι συγκεκριμένες λεπτομέρειες είναι οι εξής:

<p><img src="https://cdn.acedata.cloud/seedance_parameters.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ ορίσαμε τα Request Headers, που περιλαμβάνουν:

- `accept`: τη μορφή του αποτελέσματος απόκρισης που θέλετε να λάβετε· εδώ συμπληρώνεται ως `application/json`, δηλαδή μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορεί να επιλεγεί απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, ορίσαμε το Request Body, που περιλαμβάνει:

- `model`: το μοντέλο για τη δημιουργία βίντεο.
  - **Σειρά Seedance 1.x**: `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`, `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-lite-t2v-250428`, `doubao-seedance-1-0-lite-i2v-250428`.
  - **Σειρά Seedance 2.0** (υποστηρίζει πολυτροπικές αναφορές χαρακτήρων και ήχου/βίντεο): `doubao-seedance-2-0-260128` (τυπικό), `doubao-seedance-2-0-fast-260128` (γρήγορο), `doubao-seedance-2-0-mini-260615` (ελαφρύ).
  - **Seedance 2.5**: `doubao-seedance-2-5-260628`, υποστηρίζει έως 30 δευτερόλεπτα, αναφορά αποκλειστικά ήχου, περισσότερα υλικά, επεξεργασία και επέκταση βίντεο.
- `content`: πίνακας περιεχομένου εισόδου, το `type` μπορεί να είναι `text` (κείμενο προτροπής), `image_url` (εικόνα αναφοράς), `audio_url` (ήχος αναφοράς), `video_url` (βίντεο αναφοράς). Η χρήση της εικόνας μπορεί να καθοριστεί μέσω του `role`: `first_frame` (πρώτο καρέ) / `last_frame` (τελευταίο καρέ) / `reference_image` (αναφορά χαρακτήρα / θέματος).
- `resolution`: ανάλυση εξόδου, διαθέσιμες επιλογές `480p` / `720p` / `1080p` / `4k`. Το 2.5 υποστηρίζει 480p, 720p, 1080p· τα 2.0 Fast/Mini υποστηρίζουν 480p, 720p· το 2.0 Standard υποστηρίζει έως 4k.
- `ratio`: αναλογία διαστάσεων, διαθέσιμες επιλογές `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive`.
- `duration`: διάρκεια βίντεο (δευτερόλεπτα, ακέραιος). Η σειρά 1.0 είναι 2–12· το 1.5 Pro 4–12· η σειρά 2.0 4–15· το 2.5 είναι 4–30. Τα 1.5/2.x υποστηρίζουν `-1` (αυτόματη διάρκεια).
- `seed`: τυχαίος σπόρος, ακέραιος, από -1 έως 4294967295.
- `camerafixed`: εάν η κάμερα είναι σταθερή, `true` / `false`.
- `watermark`: εάν θα προστεθεί υδατογράφημα, `true` / `false`.
- `generate_audio`: εάν θα δημιουργηθεί βίντεο με ήχο, `true` / `false`, υποστηρίζεται από το Seedance 1.5 Pro και τη σειρά 2.x.
- `return_last_frame`: εάν θα επιστρέφεται στο αποτέλεσμα το URL της εικόνας του τελευταίου καρέ του βίντεο.
- `omni_reference_task_type`: μόνο για 2.5· `auto` / `reference` / `edit` / `extend`.
- `output_format`: μόνο για 2.5· `mp4` / `mov`, προεπιλογή `mp4`.
- `tools`: μόνο για 2.5· προς το παρόν υποστηρίζεται το εργαλείο διαδικτυακής αναζήτησης `web_search`, το οποίο μπορεί να περιορίσει τον αριθμό αποτελεσμάτων, τον αριθμό λέξεων-κλειδιών και τις πηγές αναζήτησης.
- `priority`: προαιρετική προτεραιότητα εργασίας για 2.5, ακέραιος 0–9, προεπιλογή 0.
- `safety_identifier`: σταθερό ανώνυμο αναγνωριστικό τελικού χρήστη έως 64 χαρακτήρες· χρησιμοποιήστε hash ή εσωτερικό ανώνυμο ID, μην εισάγετε όνομα, email ή αριθμό κινητού.
- `execution_expires_after`: χρόνος λήξης εργασίας (δευτερόλεπτα), εύρος 3600–259200.
- `callback_url`: διεύθυνση ασύγχρονου callback· μετά τη ρύθμιση, το API επιστρέφει αμέσως `task_id` και, όταν ολοκληρωθεί η εργασία, θα κάνει POST το αποτέλεσμα σε αυτή τη διεύθυνση.
- `async`: προαιρετικό· όταν οριστεί σε `true`, η διεπαφή επιστρέφει αμέσως `task_id`, χωρίς να χρειάζεται να παρέχετε `callback_url`, και στη συνέχεια λαμβάνετε το αποτέλεσμα μέσω polling από την αντίστοιχη διεπαφή αναζήτησης εργασίας.

Μετά την επιλογή, μπορείτε να διαπιστώσετε ότι δημιουργείται επίσης ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

Το επιστρεφόμενο αποτέλεσμα περιέχει πολλά πεδία, τα οποία παρουσιάζονται ως εξής:

- `task_id`, το ID της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `trace_id`, το ID παρακολούθησης της δημιουργίας βίντεο αυτή τη στιγμή.
- `data`, η λίστα αποτελεσμάτων της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
  - `task_id`, το ID διακομιστή της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
  - `video_url`, ο σύνδεσμος βίντεο της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
  - `status`, η κατάσταση της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
    - `model`, το μοντέλο που χρησιμοποιείται για τη δημιουργία βίντεο.

Μπορείτε να δείτε ότι λάβαμε ικανοποιητικές πληροφορίες βίντεο· χρειάζεται μόνο να λάβουμε το δημιουργημένο βίντεο SeeDance από τη διεύθυνση συνδέσμου βίντεο στο `data` του αποτελέσματος.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα ενσωμάτωσης, μπορείτε να τον αντιγράψετε απευθείας· για παράδειγμα, ο κώδικας CURL είναι ο εξής:

## Περιγραφή ενσωματωμένων παραμέτρων

Στο τέλος της προτροπής `content[].text`, μπορούν να μεταβιβαστούν παράμετροι δημιουργίας με την προσθήκη της μορφής `--parameter value` (παλαιός τρόπος, ασθενής επικύρωση, χρησιμοποιούνται αυτόματα οι προεπιλεγμένες τιμές όταν η συμπλήρωση είναι λανθασμένη). Η πλήρης λίστα παραμέτρων είναι η εξής:

| Ενσωματωμένη παράμετρος       | Αντιστοιχούμενο πεδίο              | Περιγραφή      | Εύρος τιμών                                                          |
| ---------- | ----------------- | ------- | ------------------------------------------------------------- |
| `--rs`     | `resolution`      | Ανάλυση εξόδου   | `480p` / `720p` / `1080p`                                     |
| `--rt`     | `ratio`           | Αναλογία διαστάσεων     | `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` |
| `--dur`    | `duration`        | Διάρκεια βίντεο (δευτερόλεπτα) | 2–12                                                          |
| `--frames` | `frames`          | Αριθμός καρέ βίντεο    | Ακέραιοι στο [29, 289] που ικανοποιούν 25+4n (**υποστηρίζεται μόνο από τη σειρά 1.0**)                       |
| `--fps`    | `framespersecond` | Ρυθμός καρέ      | Υποστηρίζεται μόνο το `24`                                                      |
| `--seed`   | `seed`            | Τυχαίος σπόρος    | -1 έως 4294967295                                               |
| `--cf`     | `camerafixed`     | Αν η κάμερα είναι σταθερή | `true` / `false`                                              |
| `--wm`     | `watermark`       | Αν θα προστεθεί υδατογράφημα  | `true` / `false`                                              |

> **Συνιστώμενη πρακτική**：Χρησιμοποιήστε απευθείας τα αντίστοιχα πεδία ανώτατου επιπέδου στο Request Body (όπως `resolution`, `ratio` κ.λπ.), τα οποία λειτουργούν σε λειτουργία αυστηρής επικύρωσης· όταν η συμπλήρωση των παραμέτρων είναι λανθασμένη, θα επιστρέφεται σαφής ειδοποίηση σφάλματος, διευκολύνοντας τον εντοπισμό προβλημάτων.

## Δημιουργία βίντεο με ήχο

Το Seedance 1.5 Pro και η σειρά 2.x υποστηρίζουν τη δημιουργία βίντεο με ήχο μέσω της παραμέτρου `generate_audio`:

```json
{
  "model": "doubao-seedance-1-5-pro-251215",
  "content": [
    {
      "type": "text",
      "text": "A girl holds a fox, the wind blows her hair, you can hear the sound of the wind"
    }
  ],
  "generate_audio": true,
  "ratio": "16:9",
  "duration": 5
}
```

Η σειρά 1.0 δεν υποστηρίζει αυτήν την παράμετρο.

## Seedance 2.5 πολυτροπική δημιουργία, επεξεργασία και επέκταση

Το `doubao-seedance-2-5-260628` υποστηρίζει 480p / 720p / 1080p, 4–30 δευτερόλεπτα ή αυτόματη διάρκεια, και αυξάνει το όριο υλικού σε 30 εικόνες αναφοράς, 10 βίντεο αναφοράς και 10 ήχους αναφοράς (έως 50 συνολικά). Το 2.5 υποστηρίζει επίσης την υποβολή μόνο ήχου αναφοράς, χωρίς να απαιτείται πλέον ταυτόχρονη παροχή εικόνας ή βίντεο.

Η συνήθης πολυτροπική δημιουργία μπορεί να παραλείψει το `omni_reference_task_type`, να το ορίσει σε `auto`, ή να το ορίσει ρητά σε `reference`. Η επεξεργασία και η επέκταση βίντεο πρέπει να περιλαμβάνουν `reference_video`:

```json
{
  "model": "doubao-seedance-2-5-260628",
  "content": [
    {"type": "text", "text": "Replace the sky with a warm sunset while preserving the subject and camera motion."},
    {"type": "video_url", "role": "reference_video", "video_url": {"url": "https://cdn.acedata.cloud/input.mp4"}}
  ],
  "resolution": "720p",
  "ratio": "adaptive",
  "duration": -1,
  "omni_reference_task_type": "edit",
  "output_format": "mov"
}
```

- `reference`：Υποβάλετε τουλάχιστον ένα `reference_image`, `reference_video` ή `reference_audio`· το 2.5 υποστηρίζει την υποβολή μόνο ήχου αναφοράς.
- `edit`：Πρέπει να χρησιμοποιούνται `ratio: adaptive` και `duration: -1`· η διάρκεια εξόδου χρεώνεται σύμφωνα με το πραγματικό αποτέλεσμα.
- `extend`：Πρέπει να χρησιμοποιείται `ratio: adaptive`· το `duration` μπορεί να είναι 4–30 ή `-1`.
- `auto`：Το μοντέλο επιλέγει αυτόματα δημιουργία, επεξεργασία ή επέκταση βάσει της προτροπής και του υλικού.
- Όταν ο τύπος εργασίας δεν αντιστοιχεί με το υλικό ή την προτροπή, η εργασία θα αποτύχει και θα επιστρέψει εντοπίσιμο σφάλμα παραμέτρου· προσαρμόστε και υποβάλετε ξανά σύμφωνα με τους παραπάνω περιορισμούς.

## Πρώτο καρέ βίντεο από εικόνα

Αν θέλετε μια εργασία βίντεο από εικόνα, πρώτα η παράμετρος `content` πρέπει να περιλαμβάνει στοιχείο με `type` ίσο με `image_url`, και το πεδίο `image_url` πρέπει να είναι σε μορφή αντικειμένου: `{"url": "https://..."}` ή σε μορφή Base64 `{"url": "data:image/png;base64,..."}`.

> **Σημείωση**：Το `image_url` δεν υποστηρίζει απευθείας μεταβίβαση σε μορφή συμβολοσειράς (όπως `"image_url": "https://cdn.acedata.cloud/e724d7f13d.png"`), και πρέπει να χρησιμοποιείται η μορφή αντικειμένου `"image_url": {"url": "https://..."}`· διαφορετικά θα επιστρέφεται σφάλμα 400.

Ο αντίστοιχος κώδικας:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": [
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/i2v_foxrgirl.png"
            }
        },
        {
            "type": "text",
            "text": "A girl holds a fox in her arms. She opens her eyes and gazes tenderly at the camera, while the fox affectionately holds her back. As the camera slowly pulls away, her hair is gently blown by the wind. --ratio adaptive  --dur 5"
        }
    ],
    "model": "doubao-seedance-1-0-pro-250528"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Κάνοντας κλικ για εκτέλεση, μπορείτε να διαπιστώσετε ότι θα λάβετε αμέσως ένα αποτέλεσμα, ως εξής:

```
{
  "success": true,
  "task_id": "dc7cceb5-3c12-4de7-a5f4-abcbba3e8e39",
  "trace_id": "b3b09de3-b7fa-4bb0-88b5-aad4b4a96fd4",
  "data": {
    "task_id": "cgt-20251222072003-x2259",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/6afb78b8-5ba8-424f-adcd-69423a700b50.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

Μπορείτε να δείτε ότι το παραγόμενο αποτέλεσμα είναι βίντεο που δημιουργείται από εικόνα, και το αποτέλεσμα είναι παρόμοιο με το παραπάνω.

## Πρώτο και τελευταίο καρέ βίντεο από εικόνα

Αν θέλετε πρώτο και τελευταίο καρέ για βίντεο από εικόνα, πρώτα η παράμετρος `content` πρέπει να μεταβιβάσει τον τύπο `image_url`, και να ορίσει αντίστοιχα το `role` ως `first_frame` και `last_frame`, ώστε να μπορείτε να καθορίσετε το ακόλουθο περιεχόμενο:

- role：Καθορίζει το πρώτο ή το τελευταίο καρέ.
- image_url
  - url Σύνδεσμος εικόνας
    Ταυτόχρονα, το `content` πρέπει επίσης να εισάγει τύπο `text` ως προτροπή prompt

Ο αντίστοιχος κώδικας:
```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
   "model": "doubao-seedance-1-0-pro-250528",
    "content": [
         {
            "type": "text",
            "text": "360-degree shot"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_first_frame.jpeg"
            },
            "role": "first_frame"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_last_frame.jpeg"
            },
            "role": "last_frame"
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Κάντε κλικ στην εκτέλεση και μπορείτε να διαπιστώσετε ότι θα λάβετε αμέσως ένα αποτέλεσμα, ως εξής:

```
  "data": {
    "task_id": "cgt-20251222073134-54qcw",

    "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",

  }

```

Μπορείτε να δείτε ότι το παραγόμενο αποτέλεσμα είναι βίντεο δημιουργίας χαρακτήρα, και το αποτέλεσμα είναι παρόμοιο με το παραπάνω.

## Αναφορά χαρακτήρα και πολυτροπική αναφορά ήχου-βίντεο (Seedance 2.0)

Η **σειρά Seedance 2.0** (`doubao-seedance-2-0-260128`, `doubao-seedance-2-0-fast-260128`, `doubao-seedance-2-0-mini-260615`) υποστηρίζει `reference_image`, `reference_audio` και `reference_video`. Μπορείτε να χρησιμοποιήσετε δικό σας ή εξουσιοδοτημένο υλικό για να διατηρήσετε τη συνέπεια σε χαρακτήρες, υποκείμενα, κινήσεις, κίνηση κάμερας, ήχο και ρυθμό.

> Παρακαλούμε ανεβάζετε μόνο δικό σας ή εξουσιοδοτημένο υλικό πραγματικών προσώπων και χαρακτήρων. Διαφορετικά μοντέλα υποστηρίζουν το υλικό πραγματικών προσώπων με διαφορετικούς τρόπους· η μορφή του αιτήματος παραμένει αμετάβλητη και, εάν το υλικό δεν πληροί τις απαιτήσεις, θα επιστραφεί σαφές σφάλμα.

Βασικά σημεία χρήσης:

- Μόνο τα μοντέλα της **σειράς Seedance 2.0** υποστηρίζουν `reference_image`· για μοντέλα 1.x χρησιμοποιήστε `first_frame` / `last_frame` (πρώτο και τελευταίο καρέ για δημιουργία βίντεο από εικόνα).
- Το πρώτο καρέ για δημιουργία βίντεο από εικόνα, το πρώτο και τελευταίο καρέ για δημιουργία βίντεο από εικόνα και η αναφορά πλήρους πολυτροπικότητας είναι τρία αμοιβαία αποκλειόμενα σενάρια: τα `first_frame` / `last_frame` δεν μπορούν να χρησιμοποιηθούν μαζί με τα `reference_image` / `reference_video` / `reference_audio`.
- Εάν θέλετε να ορίσετε το πρώτο και τελευταίο καρέ στην αναφορά πλήρους πολυτροπικότητας, επισημάνετε τις εικόνες ως `reference_image` και γράψτε στην προτροπή «η εικόνα 1 ως πρώτο καρέ» ή «η εικόνα 2 ως τελευταίο καρέ»· εάν χρειάζεται αυστηρό κλείδωμα του πρώτου και τελευταίου καρέ, χρησιμοποιήστε μόνο `first_frame` / `last_frame`.
- Ανώτατο όριο πολυτροπικών αναφορών: έως **9** `image_url`· η έκδοση 2.0 υποστηρίζει επίσης `audio_url` (`role` ως `reference_audio`, έως 3 εγγραφές) και `video_url` (`role` ως `reference_video`, έως 3 εγγραφές).
- **Απαιτήσεις υλικού αναφοράς ήχου (`audio_url`)**: μορφή `wav` / `mp3`· **διάρκεια κάθε εγγραφής 2~15 δευτερόλεπτα**, έως 3 εγγραφές και **συνολική διάρκεια που δεν υπερβαίνει τα 15 δευτερόλεπτα**· κάθε εγγραφή δεν υπερβαίνει τα 15 MB. Η υπέρβαση του εύρους διάρκειας θα αποτύχει στο στάδιο επεξεργασίας υλικού.
- **Απαιτήσεις υλικού αναφοράς βίντεο (`video_url`)**: μορφή `mp4` / `mov`· **διάρκεια κάθε εγγραφής 2~15 δευτερόλεπτα**, έως 3 εγγραφές και **συνολική διάρκεια που δεν υπερβαίνει τα 15 δευτερόλεπτα**.
- Για εικόνες αναφοράς, συνιστάται η χρήση φωτογραφιών με **ένα άτομο, πρόσωπο από μπροστά, καθαρό, χωρίς εμπόδια**· όσο πιο καθαρό είναι το πρόσωπο, τόσο μεγαλύτερη είναι η ομοιότητα.

### Παράδειγμα ένα: Κοντινό πλάνο που διατηρεί την εμφάνιση του ατόμου

Περάστε μία φωτογραφία προσώπου και αφήστε το άτομο να χαμογελάσει και να χαιρετήσει την κάμερα. Ο αντίστοιχος κώδικας:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedance-2-0-fast-260128",
    "content": [
        {
            "type": "text",
            "text": "The woman looks at the camera, gives a warm natural smile and waves her hand, soft studio lighting, gentle camera push-in."
        },
        {
            "type": "image_url",
            "role": "reference_image",
            "image_url": {
                "url": "https://cdn.acedata.cloud/assets/examples/nanobanana/8e075897-0f50-4443-8500-666751791c6c-4346f66287c0.jpg"
            }
        }
    ],
    "resolution": "480p",
    "ratio": "9:16",
    "duration": 5
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Το επιστρεφόμενο αποτέλεσμα είναι ως εξής, και το άτομο στο παραγόμενο βίντεο παραμένει συνεπές με τη φωτογραφία αναφοράς:

```json

  "success": true,
  "task_id": "895eb5ea-bbe1-41a3-a9e9-48608e03f93a",
  "trace_id": "83544791-7a84-44de-b8d2-afe171a1c0e4",
  "data": {
    "task_id": "458abf29-cc39-4fd0-bcea-24f89a70d8de",

    "video_url": "https://cdn.acedata.cloud/assets/examples/seedance/e71d3cc5-27e7-4719-be34-1f0e254eccaf-a56b2736a4e0.mp4",
```

### Παράδειγμα δύο: Τοποθέτηση του ίδιου ατόμου σε ένα εντελώς νέο σκηνικό

Η ισχύς του `reference_image` έγκειται στο ότι διατηρεί μόνο την **ταυτότητα του ατόμου**, ενώ το σκηνικό, η ενδυμασία και η κίνηση καθορίζονται εξ ολοκλήρου από την προτροπή. Παρακάτω χρησιμοποιείται η ίδια φωτογραφία προσώπου, ώστε το άτομο να περπατά σε ένα φθινοπωρινό πάρκο φορώντας ένα μπεζ παλτό:

```json
{
  "model": "doubao-seedance-2-0-fast-260128",
  "content": [
    {
      "type": "text",
      "text": "The same woman wearing a beige coat walks through a sunny autumn park, golden leaves falling around her, she smiles softly at the camera, cinematic tracking shot."
    },
    {
      "type": "image_url",
      "role": "reference_image",
      "image_url": {
        "url": "https://cdn.acedata.cloud/assets/examples/nanobanana/8e075897-0f50-4443-8500-666751791c6c-4346f66287c0.jpg"
```

Το επιστρεφόμενο αποτέλεσμα είναι ως εξής, η εμφάνιση του ατόμου διατηρείται, ενώ το σκηνικό έχει αλλάξει σε φθινοπωρινό πάρκο:

## Ασύγχρονη επανάκληση

Επειδή το SeeDance Videos Generation API απαιτεί σχετικά μεγάλο χρόνο δημιουργίας (περίπου 1-2 λεπτά), μπορείτε να χρησιμοποιήσετε ασύγχρονη λειτουργία μέσω του πεδίου `callback_url`, ώστε να αποφύγετε τη μακροχρόνια δέσμευση της σύνδεσης HTTP.

Συνολική ροή: ο πελάτης καθορίζει το `callback_url` κατά την υποβολή του αιτήματος και το API επιστρέφει αμέσως μια απόκριση που περιλαμβάνει το `task_id`· μετά την ολοκλήρωση της εργασίας, η πλατφόρμα αποστέλλει το αποτέλεσμα δημιουργίας στο `callback_url` με τη μορφή POST JSON, και το αποτέλεσμα περιλαμβάνει επίσης το `task_id` για συσχέτιση.

```json
{
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd"
}
```

Όταν ολοκληρωθεί η εργασία, το περιεχόμενο που προωθεί η πλατφόρμα στο `callback_url` είναι το εξής:

```json
{
  "success": true,
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd",
  "trace_id": "4a4a3721-00fb-43d2-aff2-3b516ac01a8a",
  "data": {
    "task_id": "cgt-20251222073134-54qcw",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

Το πεδίο `task_id` στο αποτέλεσμα είναι ίδιο με εκείνο που επιστράφηκε κατά το αίτημα, και μέσω αυτού του πεδίου μπορεί να πραγματοποιηθεί η συσχέτιση της εργασίας.

## Χειρισμός σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και μήνυμα. Για παράδειγμα:

- `400 token_mismatched`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
