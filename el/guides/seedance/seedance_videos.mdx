Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο σύνδεσης με το API Δημιουργίας Βίντεο SeeDance, το οποίο μπορεί να δημιουργήσει επίσημα βίντεο SeeDance μέσω εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [API Δημιουργίας Βίντεο SeeDance](https://platform.acedata.cloud/documents/seedance-videos) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε την προτροπή `content.text`, τον τύπο `content.type=text` και το μοντέλο `model`, για να λάβετε το επεξεργασμένο αποτέλεσμα. Οι συγκεκριμένες λεπτομέρειες είναι οι εξής:

<p><img src="https://cdn.acedata.cloud/seedance_parameters.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, τα οποία περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, το οποίο περιλαμβάνει:

- `model`: το μοντέλο για τη δημιουργία του βίντεο, οι διαθέσιμες επιλογές είναι: `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`, `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-lite-t2v-250428`, `doubao-seedance-1-0-lite-i2v-250428`.
- `content`: πίνακας εισαγωγής περιεχομένου, ο `type` μπορεί να είναι `text` ή `image_url`.
- `resolution`: έξοδος ανάλυσης, διαθέσιμες επιλογές `480p` / `720p` / `1080p`.
- `ratio`: αναλογία διαστάσεων, διαθέσιμες επιλογές `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive`.
- `duration`: διάρκεια βίντεο (δευτερόλεπτα), εύρος 2–12.
- `seed`: τυχαίος σπόρος, ακέραιος, -1 έως 4294967295.
- `camerafixed`: αν η κάμερα είναι σταθερή, `true` / `false`.
- `watermark`: αν θα προστεθεί υδατογράφημα, `true` / `false`.
- `generate_audio`: αν θα παραχθεί βίντεο με ήχο, `true` / `false`, **μόνο το `doubao-seedance-1-5-pro-251215` υποστηρίζει**.
- `service_tier`: τρόπος συμπερασμού, `default` (online) ή `flex` (offline, τιμή 50% της online).
- `return_last_frame`: αν θα επιστραφεί η URL της τελευταίας εικόνας του βίντεο στο αποτέλεσμα.
- `execution_expires_after`: χρόνος λήξης της εργασίας (δευτερόλεπτα), εύρος 3600–259200.
- `callback_url`: διεύθυνση ασύγχρονης κλήσης, αφού ρυθμιστεί, το API επιστρέφει άμεσα το `task_id`, και όταν ολοκληρωθεί η εργασία, θα στείλει το αποτέλεσμα σε αυτή τη διεύθυνση.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/seedance_request.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "success": true,
  "task_id": "ec22ae22-0140-4033-8c86-a48b536da595",
  "trace_id": "1cc87db0-8ee5-4436-969b-35cc571a9fd5",
  "data": {
    "task_id": "cgt-20251222005129-62fhb",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/f592800a-b87c-4705-8796-cbb8018cae35.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, τα οποία περιγράφονται ως εξής:

- `success`, η κατάσταση της εργασίας δημιουργίας βίντεο.
- `task_id`, το ID της εργασίας δημιουργίας βίντεο.
- `trace_id`, το ID παρακολούθησης της εργασίας δημιουργίας βίντεο.
- `data`, η λίστα αποτελεσμάτων της εργασίας δημιουργίας βίντεο.
  - `task_id`, το ID της εργασίας δημιουργίας βίντεο στον διακομιστή.
  - `video_url`, ο σύνδεσμος του βίντεο που δημιουργήθηκε.
  - `status`, η κατάσταση της εργασίας δημιουργίας βίντεο.
    - `model`, το μοντέλο που χρησιμοποιήθηκε για τη δημιουργία του βίντεο.

Μπορείτε να δείτε ότι έχουμε λάβει ικανοποιητικές πληροφορίες βίντεο, απλώς πρέπει να αποκτήσουμε το παραγόμενο βίντεο SeeDance μέσω της διεύθυνσης URL του βίντεο στο `data`.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο παρακάτω κώδικας CURL:

```shell
curl -X POST 'https://api.acedata.cloud/seedance/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "content": [{"text":"A kitten yawning at the camera. --rs 720p --rt 16:9 --dur 5 --fps 24 --wm true --seed 11 --cf false","type":"text"}],
  "model": "doubao-seedance-1-0-pro-250528"
}'
```

## Περιγραφή Ενσωματωμένων Παραμέτρων

Στο τέλος της προτροπής `content[].text`, μπορείτε να προσθέσετε παραμέτρους δημιουργίας με τη μορφή `--parameter value` (παλιά μέθοδος, αδύνατη επαλήθευση, σε περίπτωση λανθασμένης συμπλήρωσης χρησιμοποιούνται αυτόματα οι προεπιλεγμένες τιμές). Η πλήρης λίστα παραμέτρων είναι η εξής:

| Ενσωματωμένη Παράμετρος | Αντίστοιχο Πεδίο      | Περιγραφή      | Εύρος Τιμών                                                          |
| --------------------- | ----------------- | ------- | ------------------------------------------------------------- |
| `--rs`                | `resolution`      | Έξοδος ανάλυσης   | `480p` / `720p` / `1080p`                                     |
| `--rt`                | `ratio`           | Αναλογία διαστάσεων     | `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` |
| `--dur`               | `duration`        | Διάρκεια βίντεο (δευτερόλεπτα) | 2–12                                                          |
| `--frames`            | `frames`          | Αριθμός καρέ βίντεο    | [29, 289] που ικανοποιεί 25+4n ακέραιους                                       |
| `--fps`               | `framespersecond` | Ρυθμός καρέ      | Υποστηρίζεται μόνο `24`                                                      |
| `--seed`              | `seed`            | Τυχαίος σπόρος    | -1 έως 4294967295                                               |
| `--cf`                | `camerafixed`     | Αν η κάμερα είναι σταθερή | `true` / `false`                                              |
| `--wm`                | `watermark`       | Αν θα προστεθεί υδατογράφημα  | `true` / `false`                                              |

> **Συνιστώμενη Πρακτική**: Χρησιμοποιήστε απευθείας τα αντίστοιχα κορυφαία πεδία στο Request Body (όπως `resolution`, `ratio` κ.λπ.), για να έχετε ισχυρή επαλήθευση, σε περίπτωση λανθασμένης συμπλήρωσης παραμέτρων θα επιστραφεί σαφής μήνυμα σφάλματος, διευκολύνοντας την ανίχνευση προβλημάτων.

## Δημιουργία Βίντεο με Ήχο

Το `doubao-seedance-1-5-pro-251215` υποστηρίζει τη δημιουργία βίντεο με ήχο μέσω της παραμέτρου `generate_audio`:

```json
{
  "model": "doubao-seedance-1-5-pro-251215",
  "content": [
    {
      "type": "text",
      "text": "A girl holds a fox, the wind blows her hair, you can hear the sound of the wind"
    }
  ],
  "generate_audio": true,
  "ratio": "16:9",
  "duration": 5
}
```
其他 μοντέλα δεν υποστηρίζουν αυτή την παράμετρο, και θα αγνοηθούν αν περαστούν.

## Γεννήτρια βίντεο από εικόνα - Πρώτο καρέ

Αν θέλετε να δημιουργήσετε βίντεο από εικόνα, πρώτα η παράμετρος `content` πρέπει να περιέχει στοιχείο με `type` ίσο με `image_url`, το πεδίο `image_url` πρέπει να είναι σε μορφή αντικειμένου: `{"url": "https://..."}` ή σε μορφή Base64 `{"url": "data:image/png;base64,..."}`.

> **Σημείωση**: Το `image_url` δεν υποστηρίζει την άμεση εισαγωγή σε μορφή συμβολοσειράς (όπως `"image_url": "https://..."`), πρέπει να χρησιμοποιείται η μορφή αντικειμένου `"image_url": {"url": "https://..."}`, αλλιώς θα επιστραφεί σφάλμα 400.

Αντίστοιχος κώδικας:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": [
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/i2v_foxrgirl.png"
            }
        },
        {
            "type": "text",
            "text": "A girl holds a fox in her arms. She opens her eyes and gazes tenderly at the camera, while the fox affectionately holds her back. As the camera slowly pulls away, her hair is gently blown by the wind. --ratio adaptive  --dur 5"
        }
    ],
    "model": "doubao-seedance-1-0-pro-250528"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Κάνοντας κλικ για εκτέλεση, μπορείτε να δείτε ότι θα λάβετε αμέσως ένα αποτέλεσμα, όπως παρακάτω:

```
{
    "success": true,
    "task_id": "dc7cceb5-3c12-4de7-a5f4-abcbba3e8e39",
    "trace_id": "b3b09de3-b7fa-4bb0-88b5-aad4b4a96fd4",
    "data": {
        "task_id": "cgt-20251222072003-x2259",
        "status": "succeeded",
        "video_url": "https://platform.cdn.acedata.cloud/seedance/6afb78b8-5ba8-424f-adcd-69423a700b50.mp4",
        "model": "doubao-seedance-1-0-pro-250528"
    }
}
```

Μπορείτε να δείτε ότι το παραγόμενο αποτέλεσμα είναι βίντεο που δημιουργήθηκε από εικόνα, το αποτέλεσμα είναι παρόμοιο με το παραπάνω.

## Γεννήτρια βίντεο από εικόνα - Πρώτο και τελευταίο καρέ

Αν θέλετε να δημιουργήσετε βίντεο από το πρώτο και τελευταίο καρέ, πρώτα η παράμετρος `content` πρέπει να περιέχει τύπο `image_url`, και να ορίσετε αντίστοιχα το `role` σε `first_frame` και `last_frame`, μπορείτε να καθορίσετε τα εξής περιεχόμενα:

- role: καθορίζει το πρώτο ή το τελευταίο καρέ.
- image_url
  - url σύνδεσμος εικόνας
    Ταυτόχρονα, το `content` πρέπει επίσης να εισάγει τύπο `text` ως prompt.

Αντίστοιχος κώδικας:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
   "model": "doubao-seedance-1-0-pro-250528",
    "content": [
         {
            "type": "text",
            "text": "360-degree shot"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_first_frame.jpeg"
            },
            "role": "first_frame"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_last_frame.jpeg"
            },
            "role": "last_frame"
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Κάνοντας κλικ για εκτέλεση, μπορείτε να δείτε ότι θα λάβετε αμέσως ένα αποτέλεσμα, όπως παρακάτω:

    "trace_id": "4a4a3721-00fb-43d2-aff2-3b516ac01a8a",
    "data": {
        "task_id": "cgt-20251222073134-54qcw",
        "status": "succeeded",
        "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",

Μπορείτε να δείτε ότι το παραγόμενο αποτέλεσμα είναι βίντεο που δημιουργήθηκε από χαρακτήρες, το αποτέλεσμα είναι παρόμοιο με το παραπάνω.

## Ασύγχρονη κλήση

Δεδομένου ότι η API Γεννήτριας Βίντεο SeeDance χρειάζεται αρκετό χρόνο (περίπου 1-2 λεπτά), μπορείτε να χρησιμοποιήσετε το πεδίο `callback_url` για να ενεργοποιήσετε τη ασύγχρονη λειτουργία, αποφεύγοντας τη μακροχρόνια κατανάλωση της σύνδεσης HTTP.

Συνολική διαδικασία: Όταν ο πελάτης υποβάλει αίτημα, καθορίζει το `callback_url`, η API επιστρέφει αμέσως μια απάντηση που περιέχει το `task_id`; Αφού ολοκληρωθεί η εργασία, η πλατφόρμα θα στείλει τα αποτελέσματα με POST JSON μορφή στο `callback_url`, τα αποτελέσματα περιλαμβάνουν επίσης το `task_id` για να διευκολύνουν τη σύνδεση.

```json
{
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd"
}
```

Όταν ολοκληρωθεί η εργασία, το περιεχόμενο που στέλνει η πλατφόρμα στο `callback_url` είναι το εξής:

```json
{
  "success": true,
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd",
  "trace_id": "4a4a3721-00fb-43d2-aff2-3b516ac01a8a",
  "data": {
    "task_id": "cgt-20251222073134-54qcw",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

Το πεδίο `task_id` στα αποτελέσματα είναι το ίδιο με αυτό που επιστράφηκε κατά την υποβολή του αιτήματος, μέσω αυτού του πεδίου μπορείτε να συνδέσετε τις εργασίες.

## Διαχείριση σφαλμάτων

Κατά την κλήση της API, αν προκύψουν σφάλματα, η API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα απόκρισης σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
