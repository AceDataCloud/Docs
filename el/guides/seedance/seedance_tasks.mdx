Η κύρια λειτουργία του SeeDance Tasks API είναι να ερωτά την κατάσταση εκτέλεσης ενός έργου μέσω του ID έργου που έχει παραχθεί από το SeeDance Video Generation API.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες διασύνδεσης του SeeDance Tasks API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του SeeDance Tasks API, μπορείτε εύκολα να ελέγξετε την κατάσταση εκτέλεσης των έργων του SeeDance Video Generation API.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το SeeDance Video Generation API, πρώτα επισκεφθείτε την [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να ζητήσετε ξεχωριστά για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πίστωση για να δοκιμάσετε δωρεάν. Όταν η πίστωση εξαντληθεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [SeeDance Video Generation API →](https://platform.acedata.cloud/documents/seedance-videos)

### Ρύθμιση Επικεφαλίδων Αίτησης και Σώματος Αίτησης

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `id`: το ID του έργου που έχει ανέβει.
- `action`: ο τρόπος λειτουργίας του έργου.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/seedance/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "a6e0d456-189b-4c78-9232-2fe72166ab39",
  "action": "retrieve"
}'
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, το πεδίο request είναι το σώμα της αίτησης κατά την εκκίνηση του έργου, ενώ το πεδίο response είναι το σώμα της απάντησης που επιστρέφεται μετά την ολοκλήρωση του έργου. Η περιγραφή των πεδίων είναι ως εξής.

- `id`, το ID του έργου που δημιουργήθηκε, χρησιμοποιείται για την μοναδική αναγνώριση αυτού του έργου.
- `request`, πληροφορίες αίτησης στο έργο.
- `response`, πληροφορίες απάντησης στο έργο.
- `created_at`, η ώρα δημιουργίας του έργου, Unix timestamp (δευτερόλεπτα, δεκαδικό).
- `started_at`, η ώρα έναρξης εκτέλεσης του έργου, Unix timestamp (δευτερόλεπτα, δεκαδικό).
- `finished_at`, η ώρα ολοκλήρωσης του έργου, Unix timestamp (δευτερόλεπτα, δεκαδικό). Δεν επιστρέφεται αυτό το πεδίο αν το έργο δεν έχει ολοκληρωθεί.
- `elapsed`, ο χρόνος εκτέλεσης του έργου, σε δευτερόλεπτα (δεκαδικό, με 3 δεκαδικά ψηφία). Δεν επιστρέφεται αυτό το πεδίο αν το έργο δεν έχει ολοκληρωθεί.

## 错误处理

在调用 API 时，如果遇到错误，API 会返回相应的错误代码和信息。例如：

- `400 token_mismatched`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλές αιτήσεις, έχετε ξεπεράσει το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### 错误响应示例

  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
