Η κύρια λειτουργία του SeeDance Tasks API είναι να ελέγχει την κατάσταση εκτέλεσης ενός έργου μέσω του ID έργου που δημιουργήθηκε από το SeeDance Video Generation API.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες διασύνδεσης του SeeDance Tasks API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του SeeDance Tasks API, μπορείτε εύκολα να ελέγξετε την κατάσταση εκτέλεσης των έργων του SeeDance Video Generation API.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το SeeDance Tasks API, πρέπει πρώτα να επισκεφθείτε τη σελίδα αίτησης [SeeDance Video Generation API](https://platform.acedata.cloud/documents/seedance-videos) για να ζητήσετε την αντίστοιχη υπηρεσία και στη συνέχεια να αντιγράψετε το ID έργου του SeeDance Video Generation API, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" class="m-auto"></p>

Τέλος, επισκεφθείτε τη σελίδα Tasks API [SeeDance Tasks API](https://platform.acedata.cloud/documents/seedance-tasks) για να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![Σελίδα Αίτησης](https://cdn.acedata.cloud/rci31i.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη [σελίδα σύνδεσης](https://platform.acedata.cloud) για να σας προσκαλέσει να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις, ώστε να μπορείτε να χρησιμοποιήσετε δωρεάν αυτό το API.

## Παράδειγμα Αίτησης

Το SeeDance Tasks API μπορεί να χρησιμοποιηθεί για να ελέγξει τα αποτελέσματα του SeeDance Video Generation API. Για πληροφορίες σχετικά με το πώς να χρησιμοποιήσετε το SeeDance Video Generation API, ανατρέξτε στο έγγραφο [SeeDance Video Generation API](https://platform.acedata.cloud/documents/seedance-videos-integration).

Θα χρησιμοποιήσουμε ένα παράδειγμα με ένα ID έργου που επιστρέφεται από την υπηρεσία SeeDance Video Generation API. Ας υποθέσουμε ότι έχουμε ένα ID έργου: 20068983-0cc9-4c6a-aeb6-9c6a3c668be0, και στη συνέχεια θα δείξουμε πώς να το χρησιμοποιήσουμε περνώντας ένα ID έργου.

### Ρύθμιση Επικεφαλίδων και Σώματος Αίτησης

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε απαντήσεις σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί API που θα χρησιμοποιηθεί, μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `id`: το ID του έργου που ανεβάσατε.
- `action`: ο τρόπος λειτουργίας του έργου.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/seedance/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "a6e0d456-189b-4c78-9232-2fe72166ab39",
  "action": "retrieve"
}'
```

## Διαχείριση Σφαλμάτων

Κατά την κλήση της API, εάν προκύψει σφάλμα, η API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
