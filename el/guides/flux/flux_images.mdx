Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο σύνδεσης με το API Δημιουργίας Εικόνων Flux, το οποίο μπορεί να δημιουργήσει εικόνες της Flux μέσω της εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [Flux Images Generation API](https://platform.acedata.cloud/documents/6b9197c5-7a3f-4878-a43f-7f94e7e66394) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις, ώστε να μπορείτε να χρησιμοποιήσετε δωρεάν αυτό το API.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τη λέξη-κλειδί `prompt`, τη δράση `action`, και τις διαστάσεις της εικόνας `size`, για να λάβετε το επεξεργασμένο αποτέλεσμα. Πρώτα, πρέπει να περάσετε ένα πεδίο `action`, του οποίου η τιμή είναι `generate`, και στη συνέχεια πρέπει να εισάγουμε τη λέξη-κλειδί, οι λεπτομέρειες είναι οι εξής:

<p><img src="https://cdn.acedata.cloud/wz85jt.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `action`: η δράση της τρέχουσας εργασίας δημιουργίας εικόνας.
- `size`: το μέγεθος της παραγόμενης εικόνας.
- `count`: ο αριθμός των εικόνων που θα παραχθούν, η προεπιλεγμένη τιμή είναι 1, αυτή η παράμετρος είναι έγκυρη μόνο για εργασίες δημιουργίας εικόνας, είναι άκυρη για εργασίες επεξεργασίας.
- `prompt`: η λέξη-κλειδί.
- `model`: το μοντέλο δημιουργίας, προεπιλογή `flux-dev`.
- `callback_url`: το URL στο οποίο χρειάζεται να επιστραφούν τα αποτελέσματα.

Η παράμετρος `size` έχει κάποιους ειδικούς περιορισμούς, κυρίως διαχωρίζεται σε δύο τύπους: αναλογία πλάτους x ύψους και αναλογία εικόνας x:y, οι λεπτομέρειες είναι οι εξής:

| Μοντέλο              | Εύρος                                 |
| ------------------ | ---------------------------------- |
| flux-2-flex        | Υποστηρίζει αναλογία πλάτους x >= 64, πρέπει να είναι πολλαπλάσιο του 32          |
| flux-2-pro         | Υποστηρίζει αναλογία πλάτους x >= 64, πρέπει να είναι πολλαπλάσιο του 32          |
| flux-2-max         | Υποστηρίζει αναλογία πλάτους x >= 64, πρέπει να είναι πολλαπλάσιο του 32          |
| flux-pro-1.1       | Υποστηρίζει αναλογία πλάτους 256 <= x <= 1440, πρέπει να είναι πολλαπλάσιο του 32 |
| flux-dev           | Υποστηρίζει αναλογία πλάτους 256 <= x <= 1440, πρέπει να είναι πολλαπλάσιο του 32 |
| flux-pro-1.1-ultra | Δεν υποστηρίζει αναλογία πλάτους, υποστηρίζει αναλογία εικόνας                     |
| flux-kontext-pro   | Δεν υποστηρίζει αναλογία πλάτους, υποστηρίζει αναλογία εικόνας                     |
| flux-kontext-max   | Δεν υποστηρίζει αναλογία πλάτους, υποστηρίζει αναλογία εικόνας                     |

Αναφορές αναλογιών εικόνας: "1:1", "16:9", "21:9", "3:2", "2:3", "4:5", "5:4", "3:4", "4:3", "9:16", "9:21",

Αφού επιλέξετε, μπορείτε να δείτε ότι στα δεξιά έχει παραχθεί ο αντίστοιχος κώδικας, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/8q7aux.png" width="500" className="m-auto" /></p>

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `success`, η κατάσταση της τρέχουσας εργασίας δημιουργίας βίντεο.
- `task_id`, το ID της τρέχουσας εργασίας δημιουργίας βίντεο.
- `trace_id`, το ID παρακολούθησης της τρέχουσας εργασίας δημιουργίας βίντεο.
- `data`, η λίστα αποτελεσμάτων της τρέχουσας εργασίας δημιουργίας εικόνας.
  - `image_url`, ο σύνδεσμος της τρέχουσας εργασίας δημιουργίας εικόνας.
  - `prompt`, η λέξη-κλειδί.

Μπορείτε να δείτε ότι έχουμε λάβει ικανοποιητικές πληροφορίες εικόνας, απλά πρέπει να αποκτήσουμε την παραγόμενη εικόνα Flux από τη διεύθυνση URL της εικόνας στο `data`.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο παρακάτω κώδικας CURL:

```shell
curl -X POST 'https://api.acedata.cloud/flux/images' \
-H 'authorization: Bearer {token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "prompt": "a white siamese cat",
  "model": "flux-kontext-pro",
  "count": 2
}'
```

## Επεξεργασία Εργασίας Εικόνας

Εάν θέλετε να επεξεργαστείτε μια συγκεκριμένη εικόνα, πρώτα η παράμετρος `image_url` πρέπει να περιλαμβάνει τη διεύθυνση URL της εικόνας που χρειάζεται επεξεργασία, σε αυτή την περίπτωση η `action` υποστηρίζει μόνο `edit`, και μπορείτε να καθορίσετε τα εξής περιεχόμενα:

- model: το μοντέλο που χρησιμοποιείται για την τρέχουσα εργασία επεξεργασίας εικόνας, αυτή η εργασία υποστηρίζει προς το παρόν `flux-kontext-max`, `flux-kontext-pro`.
- image_url: η εικόνα που χρειάζεται να επεξεργαστεί.

Το παράδειγμα συμπλήρωσης είναι ως εξής:

<p><img src="https://cdn.acedata.cloud/jn9da5.png" width="500" className="m-auto" /></p>

Αφού συμπληρωθεί, έχει παραχθεί αυτόματα ο παρακάτω κώδικας:

<p><img src="https://cdn.acedata.cloud/6cwxb8.png" width="500" className="m-auto" /></p>

Ο αντίστοιχος κώδικας:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "edit",
    "prompt": "a white siamese cat",
    "model": "flux-kontext-pro",
    "image_url": "https://cdn.acedata.cloud/ytj2qy.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Κάνοντας κλικ για εκτέλεση, μπορείτε να δείτε ότι θα λάβετε αμέσως ένα αποτέλεσμα, όπως παρακάτω:

```json
{

  "task_id": "2a7979ff-1f77-4380-92c6-a2dc37c3b4c8",
  "trace_id": "732b65c0-48d9-49f7-b568-64e5acffe4c0",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://fal.media/files/monkey/aEUXJZ6Faj9YXUCQVs01Q_af0cea56c558441c9ba8df67b200812d.png",
      "timings": 1752744073
    }
  ]
}
```

Μπορείτε να δείτε ότι το παραγόμενο αποτέλεσμα είναι η επεξεργασία της αρχικής εικόνας, το αποτέλεσμα είναι παρόμοιο με το προηγούμενο.

## Ασύγχρονη Επιστροφή
Λόγω του ότι η API δημιουργίας εικόνων Flux Images Generation χρειάζεται σχετικά μεγάλο χρόνο, περίπου 1-2 λεπτά, αν η API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων του συστήματος. Γι' αυτό, αυτή η API παρέχει επίσης υποστήριξη για ασύγχρονη κλήση.

Η συνολική διαδικασία είναι: Όταν ο πελάτης υποβάλλει ένα αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`. Μετά την υποβολή του αιτήματος API, η API θα επιστρέψει αμέσως ένα αποτέλεσμα που περιλαμβάνει μια πληροφορία πεδίου `task_id`, που αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα της δημιουργίας εικόνας θα αποσταλεί μέσω POST JSON στη διεύθυνση `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε αυτό μέσω ενός παραδείγματος.

Αρχικά, η κλήση Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα, οι προγραμματιστές θα πρέπει να την αντικαταστήσουν με το URL του HTTP διακομιστή που έχουν δημιουργήσει. Για λόγους ευκολίας, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να αποκτήσετε ένα Webhook URL, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/cjjfly.png)

Στη συνέχεια, μπορούμε να ρυθμίσουμε το πεδίο `callback_url` στο παραπάνω Webhook URL, ενώ συμπληρώνουμε τις αντίστοιχες παραμέτρους, οι λεπτομέρειες φαίνονται στην εικόνα:

## Διαχείριση σφαλμάτων

Κατά την κλήση της API, αν προκύψει σφάλμα, η API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
