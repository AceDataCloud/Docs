Αυτό το άρθρο θα παρουσιάσει έναν τρόπο ενσωμάτωσης του Flux Images Generation API, το οποίο μπορεί να δημιουργήσει επίσημες εικόνες Flux μέσω εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Flux Images Generation API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το ως εφεδρικό.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Με την πρώτη αίτηση θα λάβετε δωρεάν υπόλοιπο για δωρεάν δοκιμή· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να επαναφορτίσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Flux Images Generation API →](https://platform.acedata.cloud/documents/flux-images)

## Βασική χρήση

Αρχικά, ας κατανοήσουμε τον βασικό τρόπο χρήσης: εισάγετε την προτροπή `prompt`, την ενέργεια δημιουργίας `action` και το μέγεθος εικόνας `size`, και μπορείτε να λάβετε το επεξεργασμένο αποτέλεσμα. Πρώτα χρειάζεται να περάσετε απλά ένα πεδίο `action`, με τιμή `generate`, και έπειτα πρέπει να εισαγάγουμε την προτροπή· το συγκεκριμένο περιεχόμενο είναι το εξής:

<p><img src="https://cdn.acedata.cloud/wz85jt.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ έχουμε ορίσει τα Request Headers, συμπεριλαμβανομένων των:

- `accept`: Τη μορφή του αποτελέσματος απόκρισης που θέλετε να λάβετε· εδώ συμπληρώνεται ως `application/json`, δηλαδή μορφή JSON.
- `authorization`: Το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουν οριστεί τα Request Body, συμπεριλαμβανομένων των:

- `action`: Η ενέργεια αυτής της εργασίας δημιουργίας εικόνας.
- `size`: Οι διαστάσεις του αποτελέσματος δημιουργίας εικόνας. **Οι σειρές `flux-2-flex` / `flux-2-pro` / `flux-2-max` πρέπει να λαμβάνουν αναλογία εικόνας (όπως `1:1`, `16:9`), δεν δέχονται διαστάσεις σε pixel όπως `1024x1024`, και αν παραλειφθεί θα επιστραφεί 400.**
- `count`: Ο αριθμός των εικόνων που θα δημιουργηθούν, η προεπιλεγμένη τιμή είναι 1· αυτή η παράμετρος ισχύει μόνο για εργασίες δημιουργίας εικόνων και δεν ισχύει για εργασίες επεξεργασίας.
- `prompt`: Η προτροπή.
- `model`: Το μοντέλο δημιουργίας, με προεπιλογή το `flux-dev`· τα νεότερα κορυφαία μοντέλα είναι τα `flux-2-pro`, `flux-2-max` (υψηλότερη ποιότητα εικόνας, απαιτείται χρήση μαζί με την αναλογία εικόνας `size`).
- `callback_url`: Το URL που χρειάζεται να λάβει το αποτέλεσμα callback.
- `async`: Προαιρετικό· όταν οριστεί σε `true`, η διεπαφή επιστρέφει αμέσως `task_id`, χωρίς να χρειάζεται να παρέχεται `callback_url`, και στη συνέχεια το αποτέλεσμα λαμβάνεται μέσω polling από την αντίστοιχη διεπαφή αναζήτησης εργασιών.

Η παράμετρος `size` έχει ορισμένους ειδικούς περιορισμούς, οι οποίοι χωρίζονται κυρίως σε δύο τύπους: αναλογία πλάτους και ύψους `width x height` και αναλογία εικόνας `x:y`, συγκεκριμένα ως εξής:

| Μοντέλο               | Εύρος                                         |
| ---------------- | ------------------------------------------ |
| flux-dev         | Υποστηρίζει αναλογία πλάτους και ύψους 1024x1024, 1024x1792, 1792x1024 ή αναλογία εικόνας |
| flux-pro         | Υποστηρίζει αναλογία πλάτους και ύψους 1024x1024, 1024x1792, 1792x1024 ή αναλογία εικόνας |
| flux-2-flex      | Υποστηρίζει μόνο αναλογία εικόνας                                    |
| flux-2-pro       | Υποστηρίζει μόνο αναλογία εικόνας                                    |
| flux-2-max       | Υποστηρίζει μόνο αναλογία εικόνας                                    |
| flux-kontext-pro | Υποστηρίζει μόνο αναλογία εικόνας                                    |
| flux-kontext-max | Υποστηρίζει μόνο αναλογία εικόνας                                    |

Ενδεικτικές αναλογίες εικόνας: "21:9", "16:9", "4:3", "3:2", "1:1", "2:3", "3:4", "9:16", "9:21".

Μετά την επιλογή παραμέτρων, ο αντίστοιχος κώδικας θα δημιουργηθεί αυτόματα στη δεξιά πλευρά. Πριν την αντιγραφή, επιβεβαιώστε ότι η κεφαλίδα εξουσιοδότησης χρησιμοποιεί το δικό σας API Key και ότι στην τεκμηρίωση και στα στιγμιότυπα οθόνης δεν εμφανίζονται πραγματικά διαπιστευτήρια.

Κάντε κλικ στο κουμπί «Try» για δοκιμή και εδώ λάβαμε το ακόλουθο αποτέλεσμα:

```json
{
  "success": true,
  "task_id": "5456c749-3bbb-4f10-9eb8-cfbcac297500",
  "trace_id": "ae4eecb8-1dd6-45b4-bfb3-a1c48872536e",
  "data": [
    {
      "image_url": "https://cdn.acedata.cloud/assets/examples/flux/5456c749-3bbb-4f10-9eb8-cfbcac297500-d0ef60485f73.jpg"
    }
  ]
}
```

Το επιστρεφόμενο αποτέλεσμα περιλαμβάνει πολλαπλά πεδία, τα οποία περιγράφονται ως εξής:

- `success`, η κατάσταση της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `task_id`, το ID της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `trace_id`, το ID παρακολούθησης δημιουργίας βίντεο αυτή τη στιγμή.
- `data`, η λίστα αποτελεσμάτων της εργασίας δημιουργίας εικόνας αυτή τη στιγμή.
  - `image_url`, ο σύνδεσμος της εργασίας δημιουργίας εικόνας αυτή τη στιγμή.
  - `prompt`, η προτροπή.

Μπορείτε να δείτε ότι λάβαμε ικανοποιητικές πληροφορίες εικόνας· χρειάζεται μόνο να αποκτήσουμε τη δημιουργημένη εικόνα Flux σύμφωνα με τη διεύθυνση συνδέσμου εικόνας του `data` στο αποτέλεσμα.

Επιπλέον, αν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα ενσωμάτωσης, μπορείτε να αντιγράψετε απευθείας τον παραγόμενο κώδικα, για παράδειγμα ο κώδικας CURL είναι ο εξής:

```shell
curl -X POST 'https://api.acedata.cloud/flux/images' \
-H 'authorization: Bearer {token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "prompt": "A photorealistic studio product shot of a frosted-glass perfume bottle on wet black slate, single softbox key light, water droplets, dark moody background, 85mm macro.",
  "model": "flux-2-pro",
  "size": "1:1"
}'
```

## Εργασία επεξεργασίας εικόνας

Αν θέλετε να επεξεργαστείτε μια εικόνα, πρώτα η παράμετρος `image_url` πρέπει να περιλαμβάνει τον σύνδεσμο της εικόνας που χρειάζεται επεξεργασία. Σε αυτήν την περίπτωση, το `action` υποστηρίζει μόνο `edit`, και μπορείτε να ορίσετε το ακόλουθο περιεχόμενο:

- model: Το μοντέλο που χρησιμοποιείται για αυτήν την εργασία επεξεργασίας εικόνας· υποστηρίζει `flux-dev`, `flux-pro`, `flux-kontext-pro`, `flux-kontext-max`, `flux-2-flex`, `flux-2-pro`, `flux-2-max`.
- image_url: Ανεβάστε την εικόνα που χρειάζεται επεξεργασία.

Το παράδειγμα συμπλήρωσης είναι το εξής:

<p><img src="https://cdn.acedata.cloud/jn9da5.png" width="500" className="m-auto" /></p>

Μετά τη συμπλήρωση, δημιουργείται αυτόματα ο ακόλουθος κώδικας:

<p><img src="https://cdn.acedata.cloud/6cwxb8.png" width="500" className="m-auto" /></p>

Ο αντίστοιχος κώδικας:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "edit",
    "prompt": "a white siamese cat",
    "model": "flux-kontext-pro",
    "image_url": "https://cdn.acedata.cloud/ytj2qy.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Κάντε κλικ στην εκτέλεση και θα διαπιστώσετε ότι θα λάβετε αμέσως ένα αποτέλεσμα, ως εξής:

```json
{
  "success": true,
  "task_id": "2a7979ff-1f77-4380-92c6-a2dc37c3b4c8",
  "trace_id": "732b65c0-48d9-49f7-b568-64e5acffe4c0",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "timings": 1752744073
    }
  ]
}
```
Όπως φαίνεται, το παραγόμενο αποτέλεσμα είναι η επεξεργασία της αρχικής εικόνας και το αποτέλεσμα είναι παρόμοιο με το παραπάνω.

## Ασύγχρονη επανάκληση

Δεδομένου ότι ο χρόνος δημιουργίας του Flux Images Generation API είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, εάν το API δεν ανταποκρίνεται για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί συνεχώς τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος, επομένως αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη επανάκληση.

Η συνολική διαδικασία είναι: όταν ο πελάτης ξεκινά ένα αίτημα, καθορίζει επιπλέον ένα πεδίο `callback_url`, αφού ο πελάτης ξεκινήσει το αίτημα API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα, που περιλαμβάνει πληροφορίες πεδίου `task_id`, το οποίο αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα της παραγόμενης εικόνας θα σταλεί στο `callback_url` που καθορίζεται από τον πελάτη με τη μορφή POST JSON, το οποίο περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Παρακάτω θα κατανοήσουμε μέσω ενός παραδείγματος πώς να το χειριστούμε συγκεκριμένα.

Αρχικά, η επανάκληση Webhook είναι μια υπηρεσία που μπορεί να λάβει αιτήματα HTTP, και οι προγραμματιστές θα πρέπει να την αντικαταστήσουν με το URL του HTTP διακομιστή που έχουν δημιουργήσει οι ίδιοι. Εδώ, για ευκολία επίδειξης, χρησιμοποιείται ένας δημόσιος ιστότοπος δείγματος Webhook https://webhook.site/· ανοίγοντας αυτόν τον ιστότοπο μπορείτε να λάβετε ένα URL Webhook, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/cjjfly.png)

Αντιγράψτε αυτό το URL και μπορείτε να το χρησιμοποιήσετε ως Webhook· το δείγμα εδώ είναι `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`.

Στη συνέχεια, μπορούμε να ορίσουμε το πεδίο `callback_url` ως το παραπάνω URL Webhook, ενώ παράλληλα να συμπληρώσουμε τις αντίστοιχες παραμέτρους, το συγκεκριμένο περιεχόμενο φαίνεται στην εικόνα:

Κάντε κλικ στην εκτέλεση και μπορείτε να διαπιστώσετε ότι θα λάβετε αμέσως ένα αποτέλεσμα, ως εξής:

Περιμένετε λίγο και μπορούμε να παρατηρήσουμε το αποτέλεσμα της παραγόμενης εικόνας στο `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`, όπως φαίνεται στην εικόνα:

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα απόκρισης σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
