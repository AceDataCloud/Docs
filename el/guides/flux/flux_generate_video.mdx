Το Flux Videos API χρησιμοποιεί `POST /flux/videos` για την ολοκλήρωση δημιουργίας βίντεο, δημιουργίας βίντεο από εικόνα βασικών καρέ, συνέχισης βίντεο και βελτίωσης προσχεδίων. Το `action=generate` (προεπιλογή), το `mode` επιλέγει τη λειτουργία δημιουργίας· για την αναζήτηση αποτελεσμάτων χρησιμοποιείται ενιαία το υπάρχον `POST /flux/tasks`.

> Αυτή τη στιγμή βρίσκεται σε Beta. Η δημιουργία βίντεο από κείμενο, η δημιουργία βίντεο από εικόνα, η συνέχιση βίντεο και η βελτίωση προσχεδίων είναι διαθέσιμες. Το HTTP 200 και το ID εργασίας υποδηλώνουν μόνο ότι η εργασία έγινε αποδεκτή· πρέπει να συνεχίσετε την αναζήτηση για το τελικό αποτέλεσμα.

## 1. Λήψη API Token

1. Εγγραφείτε ή συνδεθείτε στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications), δημιουργήστε μια εφαρμογή και αποκτήστε API Token. Ένα γενικό API Token μπορεί να καλεί υπηρεσίες της πλατφόρμας· επιβεβαιώστε ότι η εφαρμογή έχει δικαιώματα κλήσης της υπηρεσίας Flux και διαθέσιμο υπόλοιπο.
2. Δείτε τα πακέτα και τις τιμές κάθε λειτουργίας στη [σελίδα υπηρεσίας Flux](https://platform.acedata.cloud/services/flux?tab=pricing). Όταν το υπόλοιπο δεν επαρκεί, πραγματοποιήστε φόρτιση στη [σελίδα υπολοίπου της κονσόλας](https://platform.acedata.cloud/console/coin).
3. Τα αιτήματα χρησιμοποιούν `Authorization: Bearer &lt;το Token σας>`. Το Token πρέπει να αποθηκεύεται σε μεταβλητές περιβάλλοντος του διακομιστή, μην το γράφετε σε σελίδες frontend, δημόσια αποθετήρια, στιγμιότυπα οθόνης ή URL callback.

![Αίτηση API Token από την κονσόλα](https://cdn.acedata.cloud/dvc3cg.jpg)

Ο κώδικας αυτού του άρθρου διαβάζει ενιαία τη μεταβλητή περιβάλλοντος:

```bash
export ACEDATACLOUD_API_TOKEN='替换为你自己的 API Token'
```

| Στοιχείο      | Τιμή                                               |
| ------- | ----------------------------------------------- |
| Βασική διεύθυνση API | `https://api.acedata.cloud`                     |
| Υποβολή εργασίας βίντεο  | `POST /flux/videos`                             |
| Αναζήτηση υπάρχουσας εργασίας  | `POST /flux/tasks`                              |
| Πιστοποίηση      | `Authorization: Bearer $ACEDATACLOUD_API_TOKEN` |
| Μορφή αιτήματος    | `Content-Type: application/json`                |

Για πλήρη πεδία και online δοκιμές, δείτε το [Flux Videos API](https://platform.acedata.cloud/documents/flux-videos), και για αναζήτηση εργασιών, δείτε το [Flux Tasks API](https://platform.acedata.cloud/documents/flux-tasks).

## 2. Επιλογή λειτουργίας και εισόδου

| action                      | mode            | Είσοδος                       | Αποτέλεσμα            |
| --------------------------- | --------------- | ------------------------ | ------------- |
| `generate`（προεπιλεγμένη τιμή όταν παραλείπεται το action） | `t2v`           | `prompt`                 | Δημιουργία βίντεο από κείμενο       |
| `generate`                  | `i2v`           | `prompt`、`keyframes`     | Δημιουργία βίντεο από ένα ή περισσότερα βασικά καρέ |
| `generate`                  | `v2v`           | `prompt`、`start_video`   | Συνέχιση βάσει του βίντεο εισόδου      |
| `generate`                  | `draft_enhance` | `draft_task_id` του δικού σας ολοκληρωμένου προσχεδίου | Βελτίωση αυτού του προσχεδίου         |

Το μοντέλο δημιουργίας είναι `flux-3`, το `action` είναι `generate` (προεπιλογή). Επιλέξτε δημιουργία βίντεο από κείμενο, δημιουργία βίντεο από εικόνα, συνέχιση βίντεο ή βελτίωση προσχεδίου μέσω του `mode`.

### Κοινές παράμετροι δημιουργίας

| Παράμετρος                 | Περιγραφή                                                           |
| ------------------ | ------------------------------------------------------------ |
| `mode`             | Υποχρεωτικό· `t2v`、`i2v`、`v2v` ή `draft_enhance`                       |
| `prompt`           | Υποχρεωτικό για κανονική δημιουργία· η βελτίωση προσχεδίου δεν επιτρέπει την αντικατάσταση του αρχικού prompt                                        |
| `duration`         | Για t2v/i2v είναι ακέραιος 5–20 δευτερολέπτων, για v2v ακέραιος 5–15 δευτερολέπτων, ή `auto`· η τελική διάρκεια εξόδου ενδέχεται να διαφέρει ελαφρώς από την ζητούμενη τιμή |
| `resolution`       | `hd`、`fhd`、`qhd`、`uhd`· η κανονική δημιουργία έχει προεπιλογή `hd`, ενώ η βελτίωση προσχεδίου έχει προεπιλογή `fhd`              |
| `aspect_ratio`     | `auto`、`21:9`、`2:1`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`9:21`   |
| `draft`            | Αν θα δημιουργηθεί πρώτα προσχέδιο· τα προσχέδια υποστηρίζουν μόνο `hd`                                           |
| `generate_audio`   | Αν θα δημιουργηθεί συγχρονισμένος ήχος· το `false` είναι έγκυρη τιμή, διατηρήστε τη ρητή τιμή boolean                               |
| `safety_tolerance` | Προαιρετικό· ακέραιος από 0–4                                                   |
| `async`            | Συνιστάται να οριστεί σε `true`, επιστρέφει άμεσα το ID εργασίας της πλατφόρμας και κατόπιν γίνεται επαναληπτική αναζήτηση αποτελεσμάτων                                |
| `callback_url`     | Προαιρετικό· διεύθυνση HTTP(S) που λαμβάνει το τελικό αποτέλεσμα JSON· μετά τη ρύθμισή της, η εργασία γίνεται επίσης δεκτή ασύγχρονα                        |

Τα URL των πόρων πρέπει να είναι προσβάσιμα από την υπηρεσία. Εάν χρησιμοποιείτε προσωρινά υπογεγραμμένα URL, θα πρέπει να προβλέψετε επαρκή χρόνο ισχύος για λήψη και επεξεργασία. Μη χρησιμοποιείτε διευθύνσεις ιστοσελίδων ως διευθύνσεις αρχείων εικόνας ή βίντεο.

## 3. Δημιουργία βίντεο από κείμενο: πλήρες δοκιμασμένο αίτημα και αποτέλεσμα

Το παρακάτω αίτημα εκτελέστηκε με επιτυχία στη διεπαφή παραγωγής πριν από την αναπροσαρμογή τιμών στις 2026-10-02. Η παράλειψη του `action` επαλήθευσε την προεπιλεγμένη συμπεριφορά δημιουργίας· το `async=true` αποφεύγει την πολύωρη αναμονή της σύνδεσης HTTP.

```bash
curl -X POST 'https://api.acedata.cloud/flux/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light, steady camera, no text.",
    "duration": 5,
    "resolution": "hd",
    "draft": true,
    "async": true
  }'
```

Απόκριση αποδοχής (πραγματικό ID εργασίας):

```json
{
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607"
}
```

Αποθηκεύστε το `task_id` από τη δική σας απόκριση και συνεχίστε την αναζήτηση· μη χρησιμοποιείτε το ID εργασίας του παραδείγματος τεκμηρίωσης για να αναζητήσετε αποτελέσματα άλλων λογαριασμών.

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"替换为本次返回的 task_id"}'
```

Το πεδίο `response` που επιστρέφεται από την αναζήτηση εργασίας περιέχει το τελικό επιχειρησιακό αποτέλεσμα. Ακολουθεί το `response` που ολοκληρώθηκε επιτυχώς στην παρούσα δοκιμή, με τα εξωτερικά μεταδεδομένα εργασίας να έχουν παραλειφθεί. Το URL βίντεο στην τεκμηρίωση έχει αντικατασταθεί με αντίγραφο του ίδιου αρχείου σε CDN μακράς διάρκειας για το παράδειγμα (ίδιο SHA-256)· η πραγματική κλήση θα επιστρέψει το URL αποτελέσματος της δικής σας εργασίας:
```json
{
  "success": true,
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607",
  "data": [
    {
      "id": "4341eb66-3845-4972-bb86-712a6cfae845",
      "model": "flux-3",
      "video_url": "https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4",
      "seconds": 5.041667,
      "width": 1280,
      "height": 704,
      "fps": 24,
      "draft_task_id": "4341eb66-3845-4972-bb86-712a6cfae845"
    }
  ],
  "usage": {
    "action": "generate",
    "seconds": 5.041667,
    "output_mp_seconds": 4.3326825781250005,
    "mode": "t2v",
    "resolution": "hd",
    "draft": true
  },
  "cost": {
    "amount": 2.6884689277500002,
    "currency": "credit",
    "list_amount": 2.9871876975000005
  }
}
```

[Προβολή του βίντεο αυτής της δοκιμής](https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4)。Ο έλεγχος πολυμέσων επιβεβαιώνει ότι η έξοδος είναι MP4 1280×704, 24 fps, 5.041667 δευτερολέπτων, με μέγεθος αρχείου 2,607,276 bytes.

| Πεδίο απόκρισης                              | Χρήση                                       |
| --------------------------------- | ---------------------------------------- |
| `success`                         | Εάν η τελική εργασία ολοκληρώθηκε επιτυχώς· η επιστροφή task_id στο στάδιο αποδοχής δεν ισοδυναμεί με success=true |
| `task_id`                         | ID εργασίας πλατφόρμας, χρησιμοποιείται για polling και αδρανή επεξεργασία επιχειρησιακών λειτουργιών                      |
| `trace_id`                        | Παρέχεται στο προσωπικό υποστήριξης κατά την αντιμετώπιση προβλημάτων                             |
| `data[].video_url`                | Διεύθυνση προσβάσιμου αποτελέσματος βίντεο                               |
| `data[].seconds/width/height/fps` | Η πραγματική διάρκεια εξόδου, διαστάσεις και ρυθμός καρέ που μετρήθηκαν από τον διακομιστή                       |
| `data[].draft_task_id`            | ID εισόδου για ενίσχυση προσχεδίου· εμφανίζεται μόνο όταν επιστρέφεται επαναχρησιμοποιήσιμο προσχέδιο                  |
| `usage`                           | Τελική χρεώσιμη χρήση· μην χρησιμοποιείτε το request duration για να αντικαταστήσετε τα πραγματικά seconds      |
| `cost.amount`                     | Τα Credits που χρεώθηκαν τελικά αυτή τη φορά· `currency=credit` δεν είναι δολάρια ΗΠΑ   |
| `cost.list_amount`                | Credits πριν από την έκπτωση κατανάλωσης του χρήστη της εφαρμογής· επιστρέφεται όταν ισχύει                 |

Αυτή είναι ιστορική πραγματική δοκιμή πριν από την αναπροσαρμογή τιμής: `list_amount=2.9871876975` Credits, ο λογαριασμός είχε τότε έκπτωση κατανάλωσης 10%, και το πραγματικό `amount=2.68846892775` Credits. Η νέα τιμή της 2026-10-02 έχει μειωθεί κατά περίπου 6.33%· το ίδιο προσχέδιο 5.041667 δευτερολέπτων στην τρέχουσα τιμή είναι 2.798125185 Credits (πριν από την έκπτωση κατανάλωσης), ή 2.5183126665 Credits εάν εξακολουθεί να ισχύει έκπτωση κατανάλωσης 10%. Οι λογαριασμοί ιστορικών εργασιών δεν υπολογίζονται εκ νέου. Τα πακέτα και οι εκπτώσεις άλλων λογαριασμών ενδέχεται να διαφέρουν· αυτή δεν είναι σταθερή τιμή σε δολάρια ΗΠΑ για όλους τους χρήστες.

## 4. Εικόνα σε βίντεο: κανονικό και με χρονικά βασικά καρέ

Ακολουθούν παραδείγματα παραμέτρων· πρέπει να αντικατασταθούν τα URL των υλικών και δεν αποτελούν δήλωση ότι το παράδειγμα έχει ήδη εκτελεστεί επιτυχώς. Μετά την ολοκλήρωση της δημιουργίας, υποβάλετε ερώτημα σύμφωνα με την παραπάνω διαδικασία· η δομή του αποτελέσματος είναι η ίδια.

Για μία ή δύο εικόνες χρησιμοποιήστε έναν κανονικό πίνακα:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "The camera slowly moves around the product in soft studio light.",
  "keyframes": ["https://example.com/first-frame.jpg"],
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "async": true
}
```

Κατά τον καθορισμό χρονικών στιγμών βασικών καρέ, χρησιμοποιήστε ζεύγη `[δευτερόλεπτα, URL εικόνας]`:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "A smooth transition from morning light to a warm sunset.",
  "keyframes": [[0, "https://example.com/start.jpg"], [5, "https://example.com/end.jpg"]],
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

Επιτρέπονται 1–10 βασικά καρέ. Ο χρονικός πίνακας πρέπει να είναι σε αύξουσα σειρά χρόνου, ο χρόνος είναι 0–20 δευτερόλεπτα και δεν επιτρέπεται η ανάμειξη κανονικών URL και στοιχείων με χρόνο. Για τρία ή περισσότερα κανονικά βασικά καρέ πρέπει να καθορίζεται ρητά το duration και δεν μπορεί να χρησιμοποιηθεί το auto.

### Πραγματική έξοδος δοκιμής εικόνας σε βίντεο

Η αντίστοιχη είσοδος αυτής της δοκιμής είναι η ακόλουθη (μόνο το πλήρες base64 αντικαθίσταται με περιγραφικό κείμενο· τα υπόλοιπα πεδία είναι το πραγματικό request):

```json
  "action": "generate",
  "model": "flux-3",
  "prompt": "The toy sailboat drifts slowly across calm water. A steady camera, gentle daylight, no people or text.",
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "draft": false,
  "mode": "i2v",
  "keyframes": [
    "<下图 PNG 文件的原始 base64 字符串>"
  ]
}
```

## 5. Συνέχιση βίντεο

Το `start_video` δέχεται διεύθυνση υπάρχοντος αρχείου βίντεο, `mode=v2v`, με μέγιστη διάρκεια 15 δευτερόλεπτα.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "v2v",
  "prompt": "Continue the sailboat drifting forward with the same steady camera.",
  "start_video": "https://example.com/source.mp4",
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

## 6. Πρώτα προσχέδιο, έπειτα ενίσχυση

1. Δημιουργήστε ένα προσχέδιο με `draft=true`, `resolution=hd` και περιμένετε την επιτυχία.
2. Πάρτε το ID προσχεδίου της πλατφόρμας από το τελικό `data[0].draft_task_id`.
3. Υποβάλετε αίτημα ενίσχυσης με τα διαπιστευτήρια εφαρμογής της ίδιας ιδιοκτησίας:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "draft_enhance",
  "draft_task_id": "替换为自己的已完成草稿 ID",
  "resolution": "fhd",
  "async": true
}
```

Η ενίσχυση προσχεδίου δεν μπορεί να λάβει `prompt`, `duration`, `aspect_ratio`, `version`, `generate_audio`, `draft`, `keyframes`, `start_video` για την αντικατάσταση του αρχικού περιεχομένου. Η προσωρινή μνήμη προσχεδίων είναι προσωρινός πόρος, παρακαλούμε ενισχύστε εγκαίρως· δεν εγγυάται μόνιμη αποθήκευση ή σταθερό αριθμό ημερών διατήρησης. Προσχέδια που δεν ανήκουν σε εσάς/στην τρέχουσα εφαρμογή, μη ολοκληρωμένα προσχέδια και ληγμένες προσωρινές μνήμες δεν μπορούν να επαναχρησιμοποιηθούν. Το προσχέδιο και η ενίσχυση είναι δύο εργασίες και χρεώνονται ξεχωριστά μετά την επιτυχία.

## 7. Κλήση Python από άκρο σε άκρο

Εγκαταστήστε το `requests`, ορίστε το δικό σας Token και εκτελέστε το παρακάτω script για να ολοκληρώσετε «μία υποβολή → polling → έξοδο URL βίντεο». Τόσο τα ερωτήματα όσο και οι επαναλήψεις δικτύου πρέπει να χρησιμοποιούν το αρχικό task_id, ώστε να αποφεύγεται η επαναλαμβανόμενη υποβολή χρεώσιμων εργασιών.
```python
import os
import time
import requests

base_url = "https://api.acedata.cloud"
headers = {
    "Authorization": "Bearer " + os.environ["ACEDATACLOUD_API_TOKEN"],
    "Accept": "application/json",
}
payload = {
    "action": "generate",
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light.",
    "duration": 5,
    "resolution": "hd",
    "draft": True,
    "async": True,
}
submitted = requests.post(base_url + "/flux/videos", json=payload, headers=headers, timeout=120)
submitted.raise_for_status()
accepted = submitted.json()
if accepted.get("error"):
    raise RuntimeError(accepted["error"])
task_id = accepted["task_id"]
print("Task ID:", task_id)  # 持久化保存，用于恢复轮询

# 30 分钟是本示例的客户端等待上限，不是服务的完成时限承诺。
deadline = time.monotonic() + 30 * 60
while time.monotonic() < deadline:
    polled = requests.post(
        base_url + "/flux/tasks",
        json={"action": "retrieve", "id": task_id},
        headers=headers,
        timeout=30,
    )
    polled.raise_for_status()
    task = polled.json()
    if task.get("error"):
        raise RuntimeError(task["error"])
    result = task.get("response") or task.get("result")
    if isinstance(result, dict) and result.get("success") is True:
        print("Video:", result["data"][0]["video_url"])
        print("Usage:", result.get("usage"))
        print("Cost:", result.get("cost"))
        break
    if isinstance(result, dict) and result.get("error"):
        raise RuntimeError(result["error"])
    time.sleep(10)
else:
    raise TimeoutError("Still processing; resume polling with task_id=" + task_id)
```

Μετά από χρονικό όριο δικτύου, μην αντιμετωπίζετε μια άγνωστη κατάσταση ως αποτυχία και μην υποβάλλετε αμέσως ξανά το αίτημα. Εάν έχει ήδη ληφθεί `task_id`, συνεχίστε την αναζήτηση αυτής της εργασίας· καταγράψτε τα `task_id` και `trace_id` για διευκόλυνση της διερεύνησης. Το ίδιο το API δημοσκόπησης δεν χρεώνει τέλη δημιουργίας.

## 8. Χρήση callback

Προσθέστε `callback_url` κατά την υποβολή· μετά την ολοκλήρωση της εργασίας, θα γίνει POST του τελικού αποτελέσματος JSON σε αυτήν τη διεύθυνση. Η δομή επιτυχίας είναι ίδια με την προηγούμενη response, ενώ σε περίπτωση αποτυχίας περιλαμβάνεται error.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "t2v",
  "prompt": "A small sailboat on calm water.",
  "duration": 5,
  "resolution": "hd",
  "draft": true,
  "callback_url": "https://your-server.example/flux-callback"
}
```

Η διεύθυνση callback θα πρέπει να είναι προσβάσιμη από το δημόσιο διαδίκτυο. Μετά τη λήψη της ειδοποίησης, επεξεργαστείτε ιδεμποτικά βάσει `task_id` και επιστρέψτε 2xx το συντομότερο δυνατό· η επιχειρηματική επεξεργασία μπορεί να τοποθετηθεί σε ουρά. Το παρόν κείμενο δεν δηλώνει ότι το callback διαθέτει έλεγχο ταυτότητας μέσω υπογραφής: πριν από ευαίσθητες ενέργειες, όπως η παροχή επιχειρηματικών προνομίων, χρησιμοποιήστε το δικό σας Token για να αναζητήσετε την ίδια εργασία και να επαληθεύσετε το αποτέλεσμα. Εάν δεν ληφθεί το callback, μπορείτε επίσης να συνεχίσετε τη δημοσκόπηση· μην δημιουργήσετε ξανά.

## 9. Τρέχουσα χρέωση και πίνακας τιμών

Ενημέρωση 2026-10-02: οι τιμές μονάδας για κάθε βαθμίδα αυτού του API βίντεο μειώθηκαν κατά περίπου 6,33%, ενώ ο τρόπος μέτρησης, τα πακέτα και οι κανόνες εκπτώσεων κατανάλωσης παραμένουν αμετάβλητοι. Το cost στα ιστορικά μετρημένα response που αναφέρονται προηγουμένως είναι ο λογαριασμός κατά την ολοκλήρωση της εργασίας και δεν αντιπροσωπεύει την τρέχουσα προσφορά.

Η δημιουργία βίντεο χρεώνεται με βάση τα **πραγματικά δευτερόλεπτα εξόδου**. Παρακάτω είναι οι τρέχουσες τιμές μονάδας Credits χωρίς εφαρμογή εκπτώσεων κατανάλωσης λογαριασμού, σύμφωνες με τους κανόνες της [σελίδας τιμών Flux](https://platform.acedata.cloud/services/flux?tab=pricing).

| Ενέργεια/λειτουργία              | Ανάλυση | Τιμή μονάδας Credits |
| ------------------ | --- | ---------: |
| Πρόχειρο t2v / i2v       | hd  |  0.555 / δευτερόλεπτο |
| Πρόχειρο v2v             | hd  |   1.11 / δευτερόλεπτο |
| t2v / i2v / αντίστοιχη ενίσχυση προχείρου | hd  | 1.5725 / δευτερόλεπτο |
| Όπως παραπάνω                 | fhd | 2.6825 / δευτερόλεπτο |
| Όπως παραπάνω                 | qhd |    3.7 / δευτερόλεπτο |
| Όπως παραπάνω                 | uhd |    7.4 / δευτερόλεπτο |
| v2v / αντίστοιχη ενίσχυση προχείρου       | hd  | 3.7925 / δευτερόλεπτο |
| Όπως παραπάνω                 | fhd | 4.9025 / δευτερόλεπτο |
| Όπως παραπάνω                 | qhd | 6.0125 / δευτερόλεπτο |
| Όπως παραπάνω                 | uhd | 8.7875 / δευτερόλεπτο |

Μετατροπή σε δολάρια ΗΠΑ: `πραγματικό κόστος（USD）= cost.amount（Credits）× τιμή πακέτου / ποσότητα πακέτου`. Τα επίπεδα ανανέωσης και οι εκπτώσεις κατανάλωσης επηρεάζουν την πραγματική τιμή· τα Credits δεν μπορούν να θεωρηθούν απευθείας ως USD. Οι αποτυχημένες εργασίες δεν χρεώνονται με τέλη δημιουργίας· το τελικό ποσό υπόκειται στο αποτέλεσμα ολοκλήρωσης και στα αρχεία κλήσεων της κονσόλας.

## 10. Συχνές ερωτήσεις και αντιμετώπιση προβλημάτων

| Περίπτωση                       | Πρόταση                                                   |
| ------------------------ | ---------------------------------------------------- |
| Σφάλμα παραμέτρων（400）                | Ελέγξτε action=generate, mode, duration και τη μορφή keyframe· μην αναμειγνύετε πεδία διαφορετικών λειτουργιών δημιουργίας |
| Σφάλμα ελέγχου ταυτότητας（401）                | Ελέγξτε εάν το Bearer Token, τα δικαιώματα εφαρμογής και τα διαπιστευτήρια είναι έγκυρα                          |
| Απόρριψη ελέγχου περιεχομένου（403）              | Προσαρμόστε το υλικό και το prompt· μην υποβάλλετε επανειλημμένα ακριβώς το ίδιο                                    |
| Περιορισμός ρυθμού（429）                  | Μειώστε την ταυτόχρονη εκτέλεση και επαναλάβετε με εκθετική αναμονή                                            |
| service_unavailable（503） | Η τρέχουσα ενέργεια δεν είναι διαθέσιμη· οι ήδη αποδεκτές ασύγχρονες εργασίες μπορεί να αναφέρουν αυτό το σφάλμα στο τελικό response                |
| Το task_id έχει επιστραφεί αλλά δεν υπάρχει ακόμη βίντεο        | Συνεχίστε την αναζήτηση του response· μην θεωρείτε το HTTP 200 ως ολοκλήρωση δημιουργίας                     |
| Το πρόχειρο δεν μπορεί να επαναχρησιμοποιηθεί                   | Επιβεβαιώστε τον ίδιο χρήστη/την τρέχουσα εφαρμογή, ότι η εργασία έχει ολοκληρωθεί, ότι το αρχικό αίτημα είχε draft=true, και ελέγξτε εάν η προσωρινή cache εξακολουθεί να είναι έγκυρη          |

Κατά την υποβολή αναφοράς, παρέχετε `task_id`, `trace_id`, χρόνο αιτήματος και αποπροσωποποιημένες παραμέτρους· μην στέλνετε API Token. Για περισσότερες μεθόδους, δείτε τον [Οδηγό ενσωμάτωσης Flux MCP](https://platform.acedata.cloud/documents/flux-mcp).
