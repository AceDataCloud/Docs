Η κύρια λειτουργία του Flux Tasks API είναι η αναζήτηση της κατάστασης εκτέλεσης της εργασίας μέσω του αναγνωριστικού εργασίας πλατφόρμας που επιστρέφεται από το Flux Images Generation API ή το Flux Videos API.

Αυτό το έγγραφο θα παρουσιάσει λεπτομερώς τις οδηγίες ενσωμάτωσης του Flux Tasks API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τις ισχυρές δυνατότητες αυτού του API. Μέσω του Flux Tasks API, μπορείτε εύκολα να υλοποιήσετε την αναζήτηση της κατάστασης εκτέλεσης εργασιών του Flux Images Generation API.

Για ένα πλήρες παράδειγμα υποβολής και polling βίντεο, ανατρέξτε στον [Οδηγό ενσωμάτωσης Flux Videos API](https://platform.acedata.cloud/documents/flux-videos-integration). Η αναζήτηση υπαρχουσών εργασιών δεν επιβαρύνεται με πρόσθετο κόστος δημιουργίας.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Flux Images Generation API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να λάβετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση προσφέρει δωρεάν πίστωση, για δωρεάν δοκιμή· όταν η πίστωση δεν επαρκεί, μπορείτε να επαναφορτίσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Flux Images Generation API →](https://platform.acedata.cloud/documents/flux-images)

Το Flux Tasks API μπορεί να χρησιμοποιηθεί για την αναζήτηση των αποτελεσμάτων του Flux Images Generation API. Για το πώς να χρησιμοποιήσετε το Flux Images Generation API, ανατρέξτε στην τεκμηρίωση [Flux Images Generation API ](https://platform.acedata.cloud/documents/flux-images-integration).

Θα χρησιμοποιήσουμε ως παράδειγμα ένα αναγνωριστικό εργασίας που επιστρέφεται από την υπηρεσία Flux Images Generation API, για να δείξουμε πώς να χρησιμοποιήσετε αυτό το API. ### Ορισμός κεφαλίδων αιτήματος και σώματος αιτήματος

Τα **Request Headers** περιλαμβάνουν:

- `accept`: Καθορίζει τη λήψη αποτελεσμάτων απόκρισης σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: Το κλειδί για την κλήση του API, μετά την αίτηση μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα.

Το **Request Body** περιλαμβάνει:

- `id`: Το αναγνωριστικό της ανεβασμένης εργασίας.
- `action`: Ο τρόπος λειτουργίας πάνω στην εργασία.

Οι ρυθμίσεις είναι όπως φαίνονται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/fiasxz.png" width="500" className="m-auto" /></p>

### Παράδειγμα κώδικα

Μπορείτε να διαπιστώσετε ότι στη δεξιά πλευρά της σελίδας έχουν ήδη δημιουργηθεί αυτόματα κώδικες σε διάφορες γλώσσες, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/j6gn86.png" width="500" className="m-auto" /></p>

Ορισμένα παραδείγματα κώδικα είναι τα εξής:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "2c454ff3-4f8f-47f0-8147-acb29a84d1c2",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/flux/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "2c454ff3-4f8f-47f0-8147-acb29a84d1c2",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Το αποτέλεσμα επιστροφής περιλαμβάνει συνολικά πολλά πεδία, το πεδίο request είναι το request body κατά την έναρξη της εργασίας, ενώ το πεδίο response είναι το response body που επιστρέφεται μετά την ολοκλήρωση της εργασίας. Η περιγραφή των πεδίων είναι η εξής.

- `id`, το ID που δημιουργεί αυτή την εργασία εικόνας, χρησιμοποιείται για τη μοναδική αναγνώριση αυτής της εργασίας δημιουργίας εικόνας.

- `response`, οι πληροφορίες επιστροφής στην αναζήτηση εργασίας εικόνας.

- `started_at`, χρόνος έναρξης εκτέλεσης εργασίας, Unix timestamp (δευτερόλεπτα, κινητής υποδιαστολής).
- `finished_at`, χρόνος ολοκλήρωσης εργασίας, Unix timestamp (δευτερόλεπτα, κινητής υποδιαστολής). Αυτό το πεδίο δεν επιστρέφεται όταν η εργασία δεν έχει ολοκληρωθεί.
- `elapsed`, χρόνος εκτέλεσης εργασίας, σε δευτερόλεπτα (κινητής υποδιαστολής, με διατήρηση 3 δεκαδικών ψηφίων). Αυτό το πεδίο δεν επιστρέφεται όταν η εργασία δεν έχει ολοκληρωθεί.

## Χειρισμός σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`：Υπερβολικά πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
