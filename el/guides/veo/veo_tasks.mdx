Η κύρια λειτουργία του Veo Tasks API είναι να ελέγχει την κατάσταση εκτέλεσης ενός έργου μέσω της εισαγωγής του ID έργου που έχει παραχθεί από το Veo Videos Generation API.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες διασύνδεσης του Veo Tasks API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του Veo Tasks API, μπορείτε εύκολα να ελέγξετε την κατάσταση εκτέλεσης των έργων του Veo Videos Generation API.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Veo Videos Generation API, πρώτα επισκεφθείτε την [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να ζητήσετε ξεχωριστά για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν. Όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό σας υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Veo Videos Generation API →](https://platform.acedata.cloud/documents/veo-videos)

Το Veo Tasks API μπορεί να χρησιμοποιηθεί για να ελέγξει τα αποτελέσματα του Veo Videos Generation API. Για πληροφορίες σχετικά με το πώς να χρησιμοποιήσετε το Veo Videos Generation API, ανατρέξτε στην τεκμηρίωση [Veo Videos Generation API](https://platform.acedata.cloud/documents/veo-videos).

Θα χρησιμοποιήσουμε ένα παράδειγμα με το ID έργου που επιστρέφεται από την υπηρεσία Veo Videos Generation API. Ας υποθέσουμε ότι έχουμε ένα ID έργου: 1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed, και στη συνέχεια θα δείξουμε πώς να το χρησιμοποιήσουμε περνώντας ένα ID έργου.

### Ρύθμιση κεφαλίδων αιτήματος και σώματος αιτήματος

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `id`: το ID του έργου που έχει ανέβει.
- `action`: ο τρόπος λειτουργίας του έργου.

Μπορείτε να παρατηρήσετε ότι στη δεξιά πλευρά της σελίδας έχουν παραχθεί αυτόματα διάφοροι κώδικες σε γλώσσες, όπως φαίνεται στην εικόνα:

Ορισμένα παραδείγματα κώδικα είναι τα εξής:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/veo/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/veo/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, το πεδίο request είναι το request body που υποβλήθηκε κατά την εκκίνηση του έργου, ενώ το πεδίο response είναι το response body που επιστρέφεται μετά την ολοκλήρωση του έργου. Η περιγραφή των πεδίων είναι ως εξής.

- `id`, το ID που δημιουργεί αυτό το έργο βίντεο, χρησιμοποιείται για την μοναδική αναγνώριση αυτού του έργου παραγωγής βίντεο.
- `request`, πληροφορίες αιτήματος στο έργο βίντεο.
- `response`, πληροφορίες επιστροφής στο έργο βίντεο.
- `created_at`, η ώρα δημιουργίας του έργου, Unix timestamp (δευτερόλεπτα, float).
- `started_at`, η ώρα έναρξης εκτέλεσης του έργου, Unix timestamp (δευτερόλεπτα, float).
- `finished_at`, η ώρα ολοκλήρωσης του έργου, Unix timestamp (δευτερόλεπτα, float). Δεν επιστρέφεται αυτό το πεδίο αν το έργο δεν έχει ολοκληρωθεί.
- `elapsed`, ο χρόνος εκτέλεσης του έργου, σε δευτερόλεπτα (float, με 3 δεκαδικά ψηφία). Δεν επιστρέφεται αυτό το πεδίο αν το έργο δεν έχει ολοκληρωθεί.

## 错误处理

在调用 API 时，如果遇到错误，API 会返回相应的错误代码和信息。例如：

- `400 token_mismatched`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλές αιτήσεις, έχετε ξεπεράσει το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### 错误响应示例
