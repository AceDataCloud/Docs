Αυτό το άρθρο θα παρουσιάσει έναν τρόπο ενσωμάτωσης του Veo Videos Generation API, το οποίο μπορεί να δημιουργεί επίσημα βίντεο Veo μέσω εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Veo Videos Generation API, αποκτήστε πρώτα το API Token σας από την [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Με την πρώτη αίτηση θα λάβετε δωρεάν μονάδες για δωρεάν δοκιμή· όταν οι μονάδες δεν επαρκούν, μπορείτε να επαναφορτίσετε το γενικό υπόλοιπο από την [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Veo Videos Generation API →](https://platform.acedata.cloud/documents/veo-videos)

## Βασική χρήση

Αρχικά, ας κατανοήσουμε τη βασική μέθοδο χρήσης: εισάγοντας το prompt `prompt`, την ενέργεια δημιουργίας `action`, τον πίνακα εικόνων αναφοράς πρώτου και τελευταίου καρέ `image_urls`, καθώς και το μοντέλο `model`, μπορείτε να λάβετε το επεξεργασμένο αποτέλεσμα. Πρώτα χρειάζεται απλώς να περάσετε ένα πεδίο `action`, με τιμή `text2video`. Περιλαμβάνει κυρίως τρεις ενέργειες: δημιουργία βίντεο από κείμενο (`text2video`), δημιουργία βίντεο από εικόνα (`image2video`), λήψη βίντεο 1080p (`get1080p`). Στη συνέχεια, χρειάζεται επίσης να εισαγάγουμε το μοντέλο `model`. Προς το παρόν, τα κύρια μοντέλα είναι τα `veo31-fast`, `veo3`, `veo31`, `veo3-fast` και `veo31-fast-ingredients`, και το συγκεκριμένο περιεχόμενο είναι ως εξής:

<p><img src="https://cdn.acedata.cloud/vv5pe8.png" width="500" className="m-auto" /></p>

Μπορούμε να δούμε ότι εδώ έχουμε ορίσει τα Request Headers, συμπεριλαμβανομένων:

- `accept`: τη μορφή του αποτελέσματος απόκρισης που θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, μετά την αίτηση μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα.

Επιπλέον, έχουν οριστεί τα Request Body, συμπεριλαμβανομένων:

- `model`: το μοντέλο για τη δημιουργία βίντεο, κυρίως τα μοντέλα `veo31-fast`, `veo3`, `veo31`, `veo3-fast` και `veo31-fast-ingredients`.
- `action`: η ενέργεια αυτής της εργασίας δημιουργίας βίντεο, περιλαμβάνει κυρίως τρεις ενέργειες: δημιουργία βίντεο από κείμενο (`text2video`), δημιουργία βίντεο από εικόνα (`image2video`), λήψη βίντεο 1080p (`get1080p`).
- `image_urls`: ο σύνδεσμος της εικόνας αναφοράς που πρέπει να μεταφορτωθεί όταν επιλεγεί η ενέργεια δημιουργίας βίντεο από εικόνα `image2video`. Το `veo31-fast-ingredients` υποστηρίζει έως 3 εικόνες (συγχώνευση πολλών εικόνων), ενώ τα υπόλοιπα μοντέλα υποστηρίζουν έως 2 εικόνες (λειτουργία πρώτου και τελευταίου καρέ).
- `resolution`: επιλέγει την ανάλυση του βίντεο που θα δημιουργηθεί. Το μοντέλο veo31 υποστηρίζει ανάλυση 4k, ενώ τα άλλα μοντέλα δεν την υποστηρίζουν. Όλα τα μοντέλα υποστηρίζουν ανάλυση 1080p και gif. Εάν δεν περάσετε αυτή την τιμή, χρησιμοποιείται από προεπιλογή ανάλυση 720p. Οι κύριες επιλογές είναι: `1080p`, `gif`, `4k`.
- `prompt`: η προτροπή.
- `callback_url`: το URL στο οποίο απαιτείται επιστροφή αποτελέσματος μέσω callback.
- `async`: προαιρετικό, όταν οριστεί σε `true`, η διεπαφή επιστρέφει αμέσως το `task_id`, χωρίς να χρειάζεται να παρέχετε `callback_url`, και στη συνέχεια λαμβάνετε το αποτέλεσμα με polling μέσω της αντίστοιχης διεπαφής ερωτήματος εργασίας.

### 🔑 Περιγραφή βασικών κανόνων

1. **Γενική λογική**:
   - **Χωρίς εισαγωγή εικόνας** → Ενεργοποιεί αυτόματα τη λειτουργία δημιουργίας βίντεο από κείμενο.
   - **Με εισαγωγή εικόνας** → Ενεργοποιεί τη λειτουργία δημιουργίας βίντεο από εικόνα (η συγκεκριμένη συμπεριφορά καθορίζεται από τον αριθμό των εικόνων).
2. **Τύποι λειτουργίας δημιουργίας βίντεο από εικόνα**:
   - **Λειτουργία πρώτου καρέ** (1 εικόνα): το πρώτο καρέ ορίζεται σταθερά ως η εικόνα εισόδου.
   - **Λειτουργία πρώτου και τελευταίου καρέ** (2 εικόνες): το πρώτο και το τελευταίο καρέ ορίζονται σταθερά ως οι εικόνες εισόδου.
   - **Λειτουργία συγχώνευσης πολλών εικόνων** (1-3 εικόνες): υποστηρίζεται μόνο από το `veo31-fast-ingredients`, συγχωνεύει το περιεχόμενο πολλών εικόνων για να δημιουργήσει βίντεο.
3. **Κατηγοριοποίηση λειτουργιών**:

  - **Λειτουργία Fast**: `veo3-fast`, `veo31-fast`, `veo31-fast-ingredients`.
   - **Λειτουργία Quality**: `veo3`, `veo31` (υψηλότερη ποιότητα δημιουργίας).

## Λειτουργία δημιουργίας βίντεο από εικόνα

Εάν θέλετε να δημιουργήσετε βίντεο με βάση εικόνες πρώτου και τελευταίου καρέ, μπορείτε να ορίσετε την παράμετρο `action` σε `image2video` και να εισαγάγετε τον πίνακα συνδέσμων εικόνων πρώτου και τελευταίου καρέ `image_urls`.

Στη συνέχεια πρέπει να συμπληρώσουμε τις προτροπές που χρειάζονται για επέκταση στο επόμενο βήμα, για να προσαρμόσουμε τη δημιουργία βίντεο, και μπορούμε να καθορίσουμε το ακόλουθο περιεχόμενο:

- `model`: το μοντέλο για τη δημιουργία βίντεο, κυρίως `veo31-fast`, `veo3`, `veo31`, `veo3-fast` και `veo31-fast-ingredients`.
- `image_urls`: όταν επιλέγετε τη λειτουργία δημιουργίας βίντεο από εικόνα `image2video`, απαιτούνται οι σύνδεσμοι των εικόνων αναφοράς που πρέπει να μεταφορτωθούν.
- `prompt`: η προτροπή.

Το παράδειγμα συμπλήρωσης είναι το εξής:

<p><img src="https://cdn.acedata.cloud/8wvlqd.png" width="500" className="m-auto" /></p>

Αφού ολοκληρωθεί η συμπλήρωση, δημιουργείται αυτόματα ο παρακάτω κώδικας:

<p><img src="https://cdn.acedata.cloud/tgzfxi.png" width="500" className="m-auto" /></p>

Ο αντίστοιχος κώδικας Python:

```python
import requests

url = "https://api.acedata.cloud/veo/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "image2video",
    "model": "veo31-fast",
    "prompt": "Let it dance",
    "image_urls": ["https://cdn.acedata.cloud/7p1jhy.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Ασύγχρονη επανάκληση

Καθώς ο χρόνος δημιουργίας του Veo Videos Generation API είναι σχετικά μεγάλος, απαιτώντας περίπου 1-2 λεπτά, εάν το API δεν αποκρίνεται για μεγάλο χρονικό διάστημα, το αίτημα HTTP θα διατηρεί συνεχώς τη σύνδεση, προκαλώντας πρόσθετη κατανάλωση πόρων συστήματος, επομένως αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονες επανακλήσεις.

Η συνολική ροή είναι: όταν ο πελάτης ξεκινά ένα αίτημα, καθορίζει επιπλέον ένα πεδίο `callback_url`, αφού ο πελάτης ξεκινήσει το αίτημα API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα, που περιλαμβάνει πληροφορίες πεδίου `task_id`, το οποίο αντιπροσωπεύει το τρέχον ID εργασίας. Όταν η εργασία ολοκληρωθεί, το αποτέλεσμα του δημιουργημένου βίντεο θα σταλεί με τη μορφή POST JSON στο `callback_url` που έχει καθορίσει ο πελάτης, όπου περιλαμβάνεται επίσης το πεδίο `task_id`, ώστε τα αποτελέσματα της εργασίας να μπορούν να συσχετιστούν μέσω του ID.

Παρακάτω θα κατανοήσουμε μέσω ενός παραδείγματος πώς ακριβώς γίνεται η λειτουργία.

Αρχικά, η επανάκληση Webhook είναι μια υπηρεσία που μπορεί να λαμβάνει αιτήματα HTTP, και ο προγραμματιστής θα πρέπει να την αντικαταστήσει με το URL του HTTP διακομιστή που έχει δημιουργήσει ο ίδιος. Εδώ, για ευκολία επίδειξης, χρησιμοποιείται ένας δημόσιος ιστότοπος δείγματος Webhook https://webhook.site/· ανοίγοντας αυτόν τον ιστότοπο μπορείτε να λάβετε ένα URL Webhook, όπως φαίνεται στην εικόνα:

## Χειρισμός σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

```json
    "message": "fetch failed"
  },

}
```
