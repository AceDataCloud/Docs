## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [API Δημιουργίας Βίντεο Veo](https://platform.acedata.cloud/documents/63e01dc3-eb21-499e-8049-3025c460058f) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή την εισαγωγή του προτροπής `prompt`, της ενέργειας `action`, του πίνακα αναφοράς εικόνας `image_urls` και του μοντέλου `model`, για να αποκτήσετε το επεξεργασμένο αποτέλεσμα. Πρώτα, πρέπει να περάσετε ένα πεδίο `action`, του οποίου η τιμή είναι `text2video`. Αυτό περιλαμβάνει τρεις κύριες ενέργειες: Δημιουργία βίντεο από κείμενο (`text2video`), Δημιουργία βίντεο από εικόνα (`image2video`), Λήψη βίντεο 1080p (`get1080p`). Στη συνέχεια, πρέπει να εισάγουμε το μοντέλο `model`, το οποίο περιλαμβάνει κυρίως τα μοντέλα `veo2`, `veo2-fast`, `veo3`, `veo31`, `veo31-fast`, `veo31-fast-ingredients` και `veo3-fast`, με τις λεπτομέρειες όπως παρακάτω:

<p><img src="https://cdn.acedata.cloud/vv5pe8.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: Τι μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: Το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `model`: Το μοντέλο για τη δημιουργία του βίντεο, κυρίως `veo2`, `veo2-fast`, `veo3`, `veo31`, `veo31-fast`, `veo31-fast-ingredients` και `veo3-fast`.
- `action`: Η ενέργεια της τρέχουσας εργασίας δημιουργίας βίντεο, που περιλαμβάνει τρεις κύριες ενέργειες: Δημιουργία βίντεο από κείμενο (`text2video`), Δημιουργία βίντεο από εικόνα (`image2video`), Λήψη βίντεο 1080p (`get1080p`).
- `image_urls`: Όταν επιλέγετε την ενέργεια Δημιουργίας βίντεο από εικόνα `image2video`, πρέπει να ανεβάσετε τους συνδέσμους των εικόνων αναφοράς για την αρχική και την τελική εικόνα, με μέγιστο τρεις εικόνες αναφοράς.
- `resolution`: Επιλέξτε την ανάλυση του παραγόμενου βίντεο, όπου το μοντέλο veo31 υποστηρίζει ανάλυση 4k, ενώ τα άλλα μοντέλα δεν την υποστηρίζουν. Όλα τα μοντέλα υποστηρίζουν 1080p και gif ανάλυση. Αν δεν περάσετε αυτή την τιμή, θα χρησιμοποιηθεί προεπιλεγμένα η ανάλυση 720p, κυρίως: `1080p`, `gif`, `4k`.
- `prompt`: Η προτροπή.
- `callback_url`: Η διεύθυνση URL για την επιστροφή των αποτελεσμάτων.

1. **Γενική Λογική**:
   - **Χωρίς είσοδο εικόνας** → Αυτόματα ενεργοποιείται η λειτουργία δημιουργίας βίντεο από κείμενο.

   - **Μοντέλο αρχικής εικόνας** (1 εικόνα): Η αρχική εικόνα είναι σταθερή.

## Λειτουργία Δημιουργίας Βίντεο από Εικόνες

Αν θέλετε να δημιουργήσετε βίντεο με βάση τις εικόνες αρχής και τέλους, μπορείτε να ρυθμίσετε την παράμετρο `action` σε `image2video` και να εισάγετε τον πίνακα διευθύνσεων εικόνας `image_urls`.

Στη συνέχεια, πρέπει να συμπληρώσουμε την επόμενη βήμα με τις επεκτάσεις των προτροπών για να προσαρμόσουμε τη δημιουργία του βίντεο, ώστε να καθορίσουμε τα εξής περιεχόμενα:

- `model`：το μοντέλο δημιουργίας βίντεο, κυρίως `veo2`, `veo2-fast`, `veo3` και `veo3-fast`.
- `image_urls`：όταν επιλέγετε τη συμπεριφορά δημιουργίας βίντεο `image2video`, πρέπει να ανεβάσετε τις διευθύνσεις εικόνας αναφοράς αρχής και τέλους.
- `prompt`：προτροπή.

Το δείγμα συμπλήρωσης είναι το εξής:

<p><img src="https://cdn.acedata.cloud/8wvlqd.png" width="500" className="m-auto" /></p>

Αφού συμπληρωθεί, δημιουργήθηκε αυτόματα ο κώδικας όπως παρακάτω:

<p><img src="https://cdn.acedata.cloud/tgzfxi.png" width="500" className="m-auto" /></p>

Ο αντίστοιχος κώδικας Python:

```python
import requests

url = "https://api.acedata.cloud/veo/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "image2video",
    "model": "veo2",
    "prompt": "Αφήστε το να χορέψει",
    "image_urls": ["https://cdn.acedata.cloud/7p1jhy.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Ασύγχρονη Επιστροφή

Δεδομένου ότι ο χρόνος δημιουργίας μέσω του API Veo Videos Generation είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, αν το API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος, γι' αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη επιστροφή.

Η συνολική διαδικασία είναι: όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`, μετά την υποβολή του API αιτήματος, το API θα επιστρέψει αμέσως ένα αποτέλεσμα που περιλαμβάνει πληροφορίες πεδίου `task_id`, που αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα του δημιουργημένου βίντεο θα αποσταλεί μέσω POST JSON στη διεύθυνση `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε αυτό μέσω ενός παραδείγματος.

Αρχικά, η επιστροφή Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα, οι προγραμματιστές θα πρέπει να την αντικαταστήσουν με το URL του HTTP διακομιστή που έχουν δημιουργήσει. Για λόγους ευκολίας, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να αποκτήσετε ένα Webhook URL, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/tbcnai.png)

Αντιγράψτε αυτό το URL και μπορείτε να το χρησιμοποιήσετε ως Webhook, το παρακάτω παράδειγμα είναι `https://webhook.site/aed5cd28-f8aa-4dca-9480-8ec9b42137dc`.

Στη συνέχεια, μπορούμε να ρυθμίσουμε το πεδίο `callback_url` στο παραπάνω Webhook URL, ενώ συμπληρώνουμε τις αντίστοιχες παραμέτρους, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/rgivs2.png" width="500" className="m-auto" /></p>

Κάνοντας κλικ στην εκτέλεση, μπορούμε να διαπιστώσουμε ότι θα λάβουμε αμέσως ένα αποτέλεσμα, όπως παρακάτω:

```json

  "task_id": "1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed"
}
```

Μετά από λίγο, μπορούμε να παρατηρήσουμε το αποτέλεσμα του δημιουργημένου βίντεο στη διεύθυνση `https://webhook.site/aed5cd28-f8aa-4dca-9480-8ec9b42137dc`, όπως φαίνεται στην εικόνα:

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

```json
}
```
