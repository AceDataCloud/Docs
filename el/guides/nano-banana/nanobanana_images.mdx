Το παρόν άρθρο παρουσιάζει την ενσωμάτωση και τη χρήση του Nano Banana Images API. Αυτό το API υποστηρίζει δύο δυνατότητες: **Δημιουργία εικόνων (generate)** και **Επεξεργασία εικόνων (edit)**.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Nano Banana Images API, μεταβείτε πρώτα στην [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και να το φυλάξετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης, όπου θα σας ζητηθεί να εγγραφείτε και να συνδεθείτε. Μόλις ολοκληρωθεί η διαδικασία, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται να υποβάλετε ξεχωριστή αίτηση για κάθε υπηρεσία.** Κατά την πρώτη αίτηση παρέχεται δωρεάν πίστωση, ώστε να μπορείτε να δοκιμάσετε την υπηρεσία δωρεάν. Όταν το διαθέσιμο υπόλοιπο δεν επαρκεί, μπορείτε να προσθέσετε γενικό υπόλοιπο μέσω της [Κονσόλας](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## Επισκόπηση API

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **Μέθοδος ελέγχου ταυτότητας**：Μεταφέρετε το `authorization: Bearer {token}` στην κεφαλίδα HTTP.
- **Κεφαλίδες αιτήματος**：
  - `accept: application/json`
  - `content-type: application/json`
- **Ενέργεια (action)**：
  - `generate`：Δημιουργία εικόνων βάσει κειμενικών προτροπών.
  - `edit`：Επεξεργασία βάσει των παρεχόμενων εικόνων.
- **Μοντέλο (model)**（προαιρετικό）：
  - `nano-banana`（προεπιλογή）：Βασίζεται στο Gemini 2.5 Flash Image, με υψηλή ταχύτητα και χαμηλό κόστος.
  - `nano-banana-2-lite`：Βασίζεται στο Gemini 3.1 Flash Lite Image, υποστηρίζει μόνο 1K και προσφέρει γρήγορη δημιουργία εικόνων.
  - `nano-banana-2`：Βασίζεται στο Gemini 3.1 Flash Image Preview, με ποιότητα επιπέδου Pro και ταχύτητα Flash.
  - `nano-banana-2.1`：Μοντέλο εικόνας νέας γενιάς υψηλής απόδοσης, που υποστηρίζει δημιουργία και επεξεργασία εικόνων σε 1K, 2K και 4K.
  - `nano-banana-pro`：Βασίζεται στο Gemini 3 Pro Image Preview, με την υψηλότερη ποιότητα.
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`：Οι επίσημες εκδόσεις των αντίστοιχων μοντέλων, με καλύτερη ποιότητα εικόνας και σταθερότητα, αλλά με διαφορετική χρέωση.
- **Ασύγχρονη επανάκληση (callback)**：Προαιρετική, μέσω του `callback_url` για τη λήψη ειδοποιήσεων ολοκλήρωσης εργασιών και των αποτελεσμάτων.
- **Αριθμός εικόνων**：Προαιρετικά, καθορίστε 1–4 εικόνες μέσω του `count`, με προεπιλεγμένη τιμή 1. Κάθε εικόνα ολοκληρώνεται μέσω ανεξάρτητης κλήσης δημιουργίας. Μια συνηθισμένη τεχνική αποτυχία ή μια απόρριψη ασφαλείας από τον πάροχο επηρεάζει μόνο την αντίστοιχη κλήση, ενώ οι υπόλοιπες επιτυχημένες εικόνες επιστρέφονται κανονικά. Η χρέωση γίνεται σύμφωνα με τον πραγματικό αριθμό των εικόνων που δημιουργήθηκαν επιτυχώς.

## Γρήγορη εκκίνηση: Δημιουργία εικόνων (`action=generate`)

**Ελάχιστες απαιτούμενες παράμετροι**：`action`、`prompt`

Όταν θέλετε απλώς να δημιουργήσετε μια εικόνα απευθείας βάσει μιας προτροπής, αρκεί να ορίσετε το `action` σε `generate` και να παρέχετε ένα σαφές `prompt`.

### Παράδειγμα αιτήματος (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Παράδειγμα αιτήματος (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Επεξήγηση πεδίων

- `success`：Εάν το συγκεκριμένο αίτημα ήταν επιτυχές.
- `task_id`：Αναγνωριστικό εργασίας.
- `trace_id`：Αναγνωριστικό ιχνηλάτησης της αλυσίδας, το οποίο διευκολύνει τη διερεύνηση προβλημάτων.
- `count`：Ο αριθμός των εικόνων που ζητήθηκε να δημιουργηθούν ή να επεξεργαστούν. Υποστηρίζονται 1–4 εικόνες, με προεπιλεγμένη τιμή 1. Το `data` περιλαμβάνει μόνο τις εικόνες που δημιουργήθηκαν επιτυχώς και η χρέωση γίνεται σύμφωνα με τον πραγματικό αριθμό των εικόνων που επιστράφηκαν. Κάθε κλήση δημιουργίας χρησιμοποιεί υποχρεωτικά την εγγενή πολιτική ασφαλείας του παρόχου. Η απόρριψη μιας κλήσης δεν επηρεάζει τις υπόλοιπες επιτυχημένες κλήσεις. Εάν απορριφθούν όλες οι κλήσεις, επιστρέφεται το σφάλμα 403.
- `data[]`：Λίστα αποτελεσμάτων.
  - `prompt`：Η προτροπή που χρησιμοποιήθηκε για τη δημιουργία (επιστρεφόμενη τιμή).
  - `image_url`：Ο απευθείας σύνδεσμος URL της εικόνας που δημιουργήθηκε.

> Σημείωση: Για τη δημιουργία εικόνων μέσω του `/nano-banana/images`, απαιτούνται μόνο τα `action` και `prompt`.

## Επεξεργασία εικόνων (`action=edit`)

Όταν θέλετε να επεξεργαστείτε μια υπάρχουσα εικόνα, ορίστε το `action` σε `edit` και μεταφέρετε τη λίστα συνδέσμων των εικόνων προς επεξεργασία (μία ή περισσότερες) μέσω του `image_urls`, παρέχοντας ταυτόχρονα το `prompt` που περιγράφει τον στόχο της επεξεργασίας.

Για παράδειγμα, εδώ παρέχουμε μία φωτογραφία ενός ατόμου και μία φωτογραφία ενός ρούχου, ώστε το άτομο να φορέσει αυτό το ρούχο. Μπορούμε να μεταφέρουμε ταυτόχρονα τους συνδέσμους των εικόνων και να ορίσουμε το action σε `edit`. Το URL μπορεί να είναι HTTP URL, δηλαδή ένας δημόσια προσβάσιμος σύνδεσμος με πρωτόκολλο `https` ή `http`, ή μπορεί επίσης να είναι μια εικόνα κωδικοποιημένη σε Base64, όπως `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Παράδειγμα αιτήματος (cURL)
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

## Ασύγχρονη επανάκληση (προαιρετική, συνιστάται)

Η δημιουργία ή η επεξεργασία ενδέχεται να απαιτήσει κάποιο χρόνο. Για να αποφευχθεί η δέσμευση πόρων από μακροχρόνιες συνδέσεις, συνιστάται η χρήση **Webhook επανάκλησης** μέσω του `callback_url`:

1. Προσθέστε το `callback_url` στο σώμα του αιτήματος, για παράδειγμα τη διεύθυνση Webhook του διακομιστή σας (πρέπει να είναι δημόσια προσβάσιμη και να υποστηρίζει POST JSON).
2. Το API θα **επιστρέψει αμέσως** μια απόκριση που περιλαμβάνει το `task_id` (ή βασικά αποτελέσματα).
3. Όταν ολοκληρωθεί η εργασία, η πλατφόρμα θα στείλει ολόκληρο το JSON στο `callback_url` μέσω `POST`. Μπορείτε να συσχετίσετε το αίτημα με το αποτέλεσμα μέσω του `task_id`.

**Παράδειγμα φορτίου επανάκλησης** (η δομή των πεδίων είναι ίδια με εκείνη της σύγχρονης επιτυχούς απόκρισης):

## Διαχείριση σφαλμάτων

Σε περίπτωση αποτυχίας της κλήσης, επιστρέφεται τυπική μορφή σφάλματος μαζί με ένα αναγνωριστικό ιχνηλάτησης. Τα συνηθισμένα σφάλματα είναι τα εξής:

- **400 `token_mismatched`**: Μη έγκυρο αίτημα ή σφάλμα παραμέτρων.
- **400 `api_not_implemented`**: Το API δεν έχει υλοποιηθεί (επικοινωνήστε με την υποστήριξη).
- **401 `invalid_token`**: Αποτυχία ελέγχου ταυτότητας ή απουσία Token.
- **403 `forbidden`**: Η εγγενής πολιτική ασφαλείας του παρόχου απέρριψε το αίτημα ή το αποτέλεσμα της δημιουργίας. Αυτή η κλήση δεν θα επιστρέψει εικόνα ούτε θα χρεωθεί· τα αιτήματα πολλαπλών εικόνων μπορούν και πάλι να επιστρέψουν και να χρεωθούν για άλλες επιτυχημένες κλήσεις.
- **429 `too_many_requests`**: Υπέρβαση του ορίου συχνότητας αιτημάτων.
- **500 `api_error`**: Σφάλμα διακομιστή.

## Αντιστοίχιση παραμέτρων και σημειώσεις

- **Υποχρεωτικά**: `action`, `prompt`
- **Αποκλειστικά για επεξεργασία**: `image_urls` (πίνακας, τουλάχιστον 1 στοιχείο)
- **Προαιρετικά**: `model` (προεπιλογή `nano-banana`, με δυνατότητα επιλογής των `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-2.1`, `nano-banana-pro`· εκτός από το `nano-banana-2.1`, υπάρχουν επίσης αντίστοιχες επίσημες εκδόσεις καναλιού με κατάληξη `:official`), `aspect_ratio` (`auto` ή συγκεκριμένη αναλογία διαστάσεων, όπως `1:1`, `16:9`), `resolution` (ανάλυση, όπως `1K`, `2K`, `4K`· το `nano-banana-2-lite` υποστηρίζει μόνο `1K`), `callback_url` (για ασύγχρονες επανακλήσεις)
- **Headers**: Πρέπει να παρέχεται το `authorization: Bearer {token}`· συνιστάται η ρύθμιση του `accept` σε `application/json`
- **Προσβασιμότητα εικόνων**: Τα `image_urls` πρέπει να είναι άμεσοι σύνδεσμοι δημόσια προσβάσιμοι (HTTP/HTTPS), συνιστάται η χρήση HTTPS
- **Idempotency και ιχνηλάτηση**: Διατηρήστε τα `task_id` και `trace_id` για τη διευκόλυνση της αντιμετώπισης προβλημάτων και της συσχέτισης αποτελεσμάτων

Η ρητή αποστολή του `"aspect_ratio": "auto"` επιλέγει την πλησιέστερη προκαθορισμένη αναλογία με βάση την αναλογία, τον προσανατολισμό ή τη διάταξη που αναφέρεται στο prompt, και είναι κατάλληλη τόσο για δημιουργία όσο και για επεξεργασία. Για παράδειγμα, αν το prompt αναφέρει «μικρογραφία YouTube», μπορεί να επιλεγεί η αναλογία `16:9`. Όταν το prompt δεν περιλαμβάνει απαιτήσεις διαστάσεων ή η αυτόματη αναγνώριση δεν είναι διαθέσιμη, η δημιουργία εικόνας από κείμενο χρησιμοποιεί την προεπιλεγμένη αναλογία, ενώ η επεξεργασία εικόνας ακολουθεί την πρώτη εικόνα αναφοράς και χρησιμοποιεί την πλησιέστερη υποστηριζόμενη αναλογία. Εάν παραλειφθεί αυτό το πεδίο, χρησιμοποιείται η προεπιλεγμένη αναλογία ή η αναλογία της εικόνας αναφοράς. Όταν υπάρχει ήδη σαφής απαίτηση για την αναλογία εικόνας, μεταβιβάστε απευθείας τη συγκεκριμένη αναλογία.
