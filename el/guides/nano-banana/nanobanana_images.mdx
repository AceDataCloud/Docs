Αυτό το έγγραφο περιγράφει τη σύνδεση και τη χρήση του Nano Banana Images API. Αυτή η διεπαφή υποστηρίζει δύο δυνατότητες: **δημιουργία εικόνας (generate)** και **επεξεργασία εικόνας (edit)**.

## Διαδικασία Αίτησης

Πριν τη χρήση, παρακαλώ επισκεφθείτε την πλατφόρμα Ace Data Cloud και εισέλθετε στο [Nano Banana Images API](https://platform.acedata.cloud/documents/23985a11-d713-41d1-ad84-24b021805b3d) και κάντε κλικ στο Acquire για να ζητήσετε την ενεργοποίηση. Η πρώτη αίτηση συνήθως έχει διαθέσιμη δωρεάν πίστωση. Αφού ολοκληρωθεί η ενεργοποίηση, μπορείτε να αποκτήσετε το Bearer Token που απαιτείται για την κλήση του API.

## Επισκόπηση Διεπαφής

- **Base URL**: `https://api.acedata.cloud`
- **Endpoint**: `POST /nano-banana/images`
- **Μέθοδος Πιστοποίησης**: HTTP Header με `authorization: Bearer {token}`
- **Αίτημα Header**:
  - `accept: application/json`
  - `content-type: application/json`
- **Δράση (action)**:
  - `generate`: Δημιουργία εικόνας με βάση το κείμενο
  - `edit`: Επεξεργασία με βάση την παρεχόμενη εικόνα
- **Μοντέλο (model)** (προαιρετικό):
  - `nano-banana` (προεπιλογή): Βασισμένο στο Gemini 2.5 Flash Image, γρήγορο και οικονομικό
  - `nano-banana-2`: Βασισμένο στο Gemini 3.1 Flash Image Preview, ποιότητα Pro + ταχύτητα Flash
  - `nano-banana-pro`: Βασισμένο στο Gemini 3 Pro Image Preview, μέγιστη ποιότητα
- **Ασύγχρονη Επιστροφή**: Προαιρετικό, μέσω `callback_url` για λήψη ειδοποιήσεων ολοκλήρωσης εργασίας και αποτελεσμάτων

## Γρήγορη Έναρξη: Δημιουργία Εικόνας (`action=generate`)

**Ελάχιστες απαιτούμενες παράμετροι**: `action`, `prompt`
Όταν θέλετε να δημιουργήσετε μια εικόνα με βάση το κείμενο, ορίστε το `action` σε `generate` και παρέχετε ένα σαφές `prompt`.

### Παράδειγμα Αίτησης (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Παράδειγμα Αίτησης (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Επεξήγηση Πεδίων

- `success`: Εάν η αίτηση ήταν επιτυχής.
- `task_id`: ID εργασίας.
- `trace_id`: ID ιχνηλάτη, για διευκόλυνση της ανίχνευσης προβλημάτων.
- `data[]`: Λίστα αποτελεσμάτων.
  - `prompt`: Ο προτροπή που χρησιμοποιήθηκε για τη δημιουργία (ανακτήθηκε).
  - `image_url`: Άμεσο URL της παραγόμενης εικόνας.

> Σημείωση: `/nano-banana/images` απαιτεί μόνο `action` και `prompt` για τη δημιουργία εικόνας

## Επεξεργασία Εικόνας (`action=edit`)

Όταν θέλετε να επεξεργαστείτε μια υπάρχουσα εικόνα, ορίστε το `action` σε `edit` και παρέχετε τη λίστα με τους συνδέσμους των εικόνων που θέλετε να επεξεργαστείτε (1 ή περισσότερες), καθώς και την περιγραφή του στόχου επεξεργασίας στο `prompt`.

Για παράδειγμα, μπορείτε να παρέχετε μια φωτογραφία ενός ατόμου και μια φωτογραφία ρούχου, ώστε το άτομο να φορέσει αυτό το ρούχο, και μπορείτε να στείλετε τους συνδέσμους των εικόνων, ορίζοντας το action σε `edit`. Οι διευθύνσεις URL μπορούν να είναι δημόσιες προσβάσιμες μέσω πρωτοκόλλου `https` ή `http`, ή μπορεί να είναι εικόνες κωδικοποιημένες σε Base64, όπως `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Παράδειγμα Αίτησης (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

## Ασύγχρονη κλήση επιστροφής (προαιρετική, συνιστώμενη)

Η δημιουργία ή η επεξεργασία μπορεί να χρειαστεί κάποιο χρόνο. Για να αποφευχθεί η μακροχρόνια σύνδεση που καταναλώνει πόρους, προτείνεται η χρήση **Webhook κλήσης επιστροφής** μέσω του `callback_url`:

1. Προσθέστε το `callback_url` στο σώμα του αιτήματος, για παράδειγμα τη διεύθυνση Webhook του διακομιστή σας (πρέπει να είναι προσβάσιμη από το δημόσιο δίκτυο, υποστηρίζει POST JSON).
2. Η API θα **επιστρέψει αμέσως** μια απάντηση που περιέχει το `task_id` (ή περιέχει βασικά αποτελέσματα).
3. Όταν ολοκληρωθεί η εργασία, η πλατφόρμα θα στείλει το πλήρες JSON στο `callback_url` με τη μέθοδο `POST`. Μπορείτε να συσχετίσετε το αίτημα με το αποτέλεσμα μέσω του `task_id`.

**Παράδειγμα φορτίου κλήσης επιστροφής** (η δομή πεδίων είναι ίδια με την επιτυχία συγχρονισμού):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "μια λευκή σιαμέζα γάτα",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Διαχείριση σφαλμάτων

Όταν η κλήση αποτύχει, θα επιστραφεί η τυπική μορφή σφάλματος και το ID παρακολούθησης. Συνηθισμένα σφάλματα είναι τα εξής:

- **400 `token_mismatched`**: Το αίτημα είναι μη έγκυρο ή οι παράμετροι είναι λανθασμένοι.
- **400 `api_not_implemented`**: Η διεπαφή δεν έχει υλοποιηθεί (παρακαλώ επικοινωνήστε με την υποστήριξη).
- **401 `invalid_token`**: Αποτυχία αυθεντικοποίησης ή έλλειψη Token.
- **429 `too_many_requests`**: Υπερβολική συχνότητα αιτημάτων.
- **500 `api_error`**: Σφάλμα στον διακομιστή.

```json
  "success": false,

  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
```

## Αντιστοίχιση παραμέτρων και σημειώσεις

- **Υποχρεωτικά**: `action`, `prompt`
- **Ειδικά για επεξεργασία**: `image_urls` (πίνακας, τουλάχιστον 1 στοιχείο)
- **Προαιρετικά**: `model` (προεπιλογή `nano-banana`, προαιρετικά `nano-banana-2` ή `nano-banana-pro`), `aspect_ratio` (αναλογία διαστάσεων, όπως `1:1`, `16:9`), `resolution` (ανάλυση, όπως `1K`, `2K`, `4K`), `callback_url` (για ασύγχρονη κλήση επιστροφής)
- **Headers**: Πρέπει να παρέχετε `authorization: Bearer {token}`; το `accept` συνιστάται να είναι `application/json`
- **Προσβασιμότητα εικόνας**: Το `image_urls` πρέπει να είναι άμεσοι σύνδεσμοι προσβάσιμοι από το δημόσιο δίκτυο (HTTP/HTTPS), συνιστάται η χρήση HTTPS
- **Ικανότητα και παρακολούθηση**: Διατηρήστε το `task_id` και το `trace_id`, για εύκολη ανίχνευση σφαλμάτων και συσχέτιση αποτελεσμάτων
