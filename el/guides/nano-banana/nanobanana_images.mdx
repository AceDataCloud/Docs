Αυτό το έγγραφο παρουσιάζει την ενσωμάτωση και χρήση του Nano Banana Images API. Αυτή η διεπαφή υποστηρίζει δύο δυνατότητες: **δημιουργία εικόνων (generate)** και **επεξεργασία εικόνων (edit)**.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Nano Banana Images API, αρχικά μεταβείτε στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης, όπου θα σας προσκληθεί να εγγραφείτε και να συνδεθείτε· μετά την ολοκλήρωση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Με την πρώτη αίτηση θα λάβετε δωρεάν υπόλοιπο για δωρεάν δοκιμή· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## Επισκόπηση διεπαφής

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **Μέθοδος πιστοποίησης**：Μεταφέρετε `authorization: Bearer {token}` στο HTTP Header
- **Κεφαλίδες αιτήματος**：
  - `accept: application/json`
  - `content-type: application/json`
- **Ενέργειες (action)**：
  - `generate`：Δημιουργία εικόνας βάσει προτροπής κειμένου
  - `edit`：Επεξεργασία βάσει δεδομένης εικόνας
- **Μοντέλα (model)**（προαιρετικό）：
  - `nano-banana`（προεπιλογή）：Βασισμένο στο Gemini 2.5 Flash Image, γρήγορο και χαμηλού κόστους
  - `nano-banana-2-lite`：Βασισμένο στο Gemini 3.1 Flash Lite Image, υποστηρίζει μόνο 1K, με γρήγορη δημιουργία
  - `nano-banana-2`：Βασισμένο στο Gemini 3.1 Flash Image Preview, ποιότητα επιπέδου Pro + ταχύτητα Flash
  - `nano-banana-pro`：Βασισμένο στο Gemini 3 Pro Image Preview, η υψηλότερη ποιότητα
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`：Εκδόσεις επίσημου καναλιού των αντίστοιχων μοντέλων, με καλύτερη ποιότητα εικόνας και σταθερότητα, με διαφορετική χρέωση
- **Ασύγχρονη επανάκληση**：Προαιρετική, λάβετε ειδοποίηση ολοκλήρωσης εργασίας και αποτέλεσμα μέσω `callback_url`
- **Αριθμός εικόνων**：Προαιρετικό, καθορίστε 1–4 εικόνες μέσω `count`, η προεπιλογή είναι 1· κάθε εικόνα ολοκληρώνεται με ανεξάρτητη κλήση δημιουργίας· συνηθισμένες τεχνικές αποτυχίες ή απορρίψεις ασφαλείας από τον πάροχο επηρεάζουν μόνο την αντίστοιχη κλήση, ενώ οι υπόλοιπες επιτυχημένες εικόνες επιστρέφονται κανονικά και χρεώνονται βάσει του πραγματικού αριθμού επιτυχημένων εικόνων

## Γρήγορη εκκίνηση: Δημιουργία εικόνων（`action=generate`）

**Ελάχιστες απαιτούμενες παράμετροι**：`action`、`prompt`
Όταν θέλετε μόνο να δημιουργήσετε άμεσα εικόνα βάσει της προτροπής, ορίστε το `action` σε `generate` και παρέχετε ένα σαφές `prompt`.

### Παράδειγμα αιτήματος（cURL）

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Παράδειγμα αιτήματος（Python）

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Περιγραφή πεδίων

- `success`：Εάν αυτό το αίτημα ήταν επιτυχές.
- `task_id`：ID εργασίας.
- `trace_id`：ID παρακολούθησης διαδρομής, που διευκολύνει την επίλυση προβλημάτων.
- `count`：Ο αριθμός των εικόνων που ζητούνται για δημιουργία ή επεξεργασία, υποστηρίζει 1–4, με προεπιλογή το 1. Το `data` περιλαμβάνει μόνο τις εικόνες που δημιουργήθηκαν επιτυχώς και η χρέωση γίνεται βάσει του πραγματικού αριθμού εικόνων που επιστρέφονται. Κάθε κλήση δημιουργίας χρησιμοποιεί υποχρεωτικά την εγγενή πολιτική ασφαλείας του παρόχου· η απόρριψη μιας κλήσης δεν επηρεάζει τις άλλες επιτυχημένες κλήσεις και, όταν απορρίπτονται όλες οι κλήσεις, επιστρέφεται 403.
- `data[]`：Λίστα αποτελεσμάτων.
  - `prompt`：Η προτροπή που χρησιμοποιήθηκε για τη δημιουργία (επανεμφάνιση).
  - `image_url`：URL άμεσου συνδέσμου της δημιουργημένης εικόνας.

> Σημείωση：Το `/nano-banana/images` χρειάζεται μόνο `action` και `prompt` για να δημιουργήσει εικόνες

## Επεξεργασία εικόνων（`action=edit`）

Όταν θέλετε να επεξεργαστείτε βάσει υπαρχουσών εικόνων, ορίστε το `action` σε `edit`, περάστε μέσω `image_urls` τη λίστα συνδέσμων των εικόνων προς επεξεργασία (1 ή περισσότερες εικόνες) και ταυτόχρονα παρέχετε ένα `prompt` που περιγράφει τον στόχο επεξεργασίας.

Για παράδειγμα, εδώ παρέχουμε μία φωτογραφία προσώπου και μία φωτογραφία ρούχου, και θέλουμε το πρόσωπο να φορέσει αυτό το ρούχο· μπορείτε να περάσετε ταυτόχρονα τους συνδέσμους εικόνων και να ορίσετε το action σε `edit`. Το URL μπορεί να είναι HTTP URL, ένας δημόσια προσβάσιμος σύνδεσμος με πρωτόκολλο `https` ή `http`, ή μια εικόνα κωδικοποιημένη σε Base64, όπως `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Παράδειγμα αιτήματος（cURL）
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

url = "https://api.acedata.cloud/nano-banana/images"

## Ασύγχρονη επανάκληση (προαιρετική, συνιστάται)

Η δημιουργία ή η επεξεργασία μπορεί να χρειαστεί κάποιο χρόνο. Για να αποφευχθεί η δέσμευση πόρων από μακρόχρονες συνδέσεις, συνιστάται η χρήση **Webhook επανάκλησης** μέσω `callback_url`:

1. Προσθέστε `callback_url` στο σώμα του αιτήματος, για παράδειγμα τη διεύθυνση Webhook του διακομιστή σας (πρέπει να είναι δημόσια προσβάσιμη και να υποστηρίζει POST JSON).
2. Το API θα **επιστρέψει αμέσως** μια απόκριση που περιλαμβάνει `task_id` (ή περιλαμβάνει βασικά αποτελέσματα).
3. Όταν ολοκληρωθεί η εργασία, η πλατφόρμα θα στείλει το πλήρες JSON στο `callback_url` μέσω `POST`. Μπορείτε να συσχετίσετε το αίτημα με το αποτέλεσμα μέσω του `task_id`.

**Παράδειγμα ωφέλιμου φορτίου επανάκλησης** (η δομή των πεδίων είναι ίδια με την επιστροφή επιτυχούς συγχρονισμένης απόκρισης):

## Χειρισμός σφαλμάτων

Όταν η κλήση αποτυγχάνει, επιστρέφεται τυπική μορφή σφάλματος και ID παρακολούθησης. Τα συνήθη σφάλματα είναι τα εξής:

- **400 `token_mismatched`**: Το αίτημα δεν είναι έγκυρο ή υπάρχει σφάλμα παραμέτρων.
- **400 `api_not_implemented`**: Η διεπαφή δεν έχει υλοποιηθεί (επικοινωνήστε με την υποστήριξη).
- **401 `invalid_token`**: Αποτυχία ελέγχου ταυτότητας ή λείπει Token.
- **403 `forbidden`**: Η εγγενής πολιτική ασφάλειας του παρόχου απέρριψε το αίτημα ή το αποτέλεσμα δημιουργίας. Αυτή η κλήση δεν θα επιστρέψει εικόνα ούτε θα χρεωθεί· τα αιτήματα πολλαπλών εικόνων μπορούν ακόμη να επιστρέψουν και να χρεώσουν άλλες επιτυχημένες κλήσεις.
- **429 `too_many_requests`**: Υπέρβαση ορίου συχνότητας αιτημάτων.
- **500 `api_error`**: Εξαίρεση διακομιστή.

## Αντιστοίχιση παραμέτρων και σημειώσεις

- **Απαιτούμενα**: `action`, `prompt`
- **Αποκλειστικά για επεξεργασία**: `image_urls` (πίνακας, τουλάχιστον 1 στοιχείο)
- **Προαιρετικά**: `model` (προεπιλογή `nano-banana`, προαιρετικά `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-pro`, ή οι αντίστοιχες εκδόσεις επίσημου καναλιού `:official`), `aspect_ratio` (αναλογία πλάτους-ύψους, όπως `1:1`, `16:9`), `resolution` (ανάλυση, όπως `1K`, `2K`, `4K`· το `nano-banana-2-lite` υποστηρίζει μόνο `1K`), `callback_url` (για ασύγχρονη επανάκληση)
- **Headers**: Πρέπει να παρέχεται `authorization: Bearer {token}`· συνιστάται το `accept` να οριστεί σε `application/json`
- **Προσβασιμότητα εικόνων**: Τα `image_urls` πρέπει να είναι άμεσοι σύνδεσμοι προσβάσιμοι δημόσια στο διαδίκτυο (HTTP/HTTPS), συνιστάται η χρήση HTTPS
- **Ιδιομορφία και παρακολούθηση**: Διατηρήστε τα `task_id` και `trace_id` για διευκόλυνση της αντιμετώπισης προβλημάτων και της συσχέτισης αποτελεσμάτων
