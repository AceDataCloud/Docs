Το Kimi είναι μια σειρά μοντέλων AI που κυκλοφόρησε από τη Moonshot AI. Προς το παρόν προτείνεται το `kimi-k3.1-pro`, κατάλληλο για προγραμματισμό μεγάλης διάρκειας, σύνθετη συλλογιστική, οπτική κατανόηση και εργασία γνώσης· το `kimi-k3` εξακολουθεί να είναι διαθέσιμο. Κλήση μέσω του OpenAI-συμβατού Chat Completions API.

Το παρόν έγγραφο παρουσιάζει κυρίως τη διαδικασία χρήσης του Kimi Chat Completion API, με το οποίο μπορούμε εύκολα να χρησιμοποιήσουμε τη λειτουργία συνομιλίας του επίσημου Kimi.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Kimi Chat Completion API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να λάβετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης, όπου θα σας ζητηθεί να εγγραφείτε και να συνδεθείτε· μετά την ολοκλήρωση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να απαιτείται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση παρέχει δωρεάν μονάδες, ώστε να μπορείτε να το δοκιμάσετε δωρεάν· όταν οι μονάδες δεν επαρκούν, μπορείτε να ανανεώσετε το γενικό υπόλοιπο από την [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Kimi Chat Completion API →](https://platform.acedata.cloud/documents/kimi-chat-completions)

## Βασική χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε το αντίστοιχο περιεχόμενο στη διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/ej5ozg.png" width="400" className="m-auto" /></p>

Κατά την πρώτη χρήση αυτής της διεπαφής, χρειάζεται να συμπληρώσετε τουλάχιστον τρία στοιχεία: το `authorization` μπορεί να επιλεγεί απευθείας από την αναπτυσσόμενη λίστα· το `model` χρησιμοποιείται για την επιλογή του μοντέλου Kimi και προτείνεται η χρήση του `kimi-k3.1-pro`· το `messages` είναι ένας πίνακας μηνυμάτων συνομιλίας, όπου κάθε μήνυμα περιλαμβάνει `role` και `content`, και το `role` υποστηρίζει `user`, `assistant`, `system` και `tool`.

Παράλληλα, μπορείτε να παρατηρήσετε ότι στα δεξιά δημιουργείται ο αντίστοιχος κώδικας κλήσης. Μπορείτε να αντιγράψετε τον κώδικα και να τον εκτελέσετε απευθείας ή να κάνετε απευθείας κλικ στο κουμπί «Try» για δοκιμή.

<p><img src="https://cdn.acedata.cloud/six7e3.png" width="400" className="m-auto" /></p>

Ακολουθεί μια πραγματική απόκριση K3 που λήφθηκε με τη χρήση `reasoning_effort: max` (παραλείπονται τα αχρησιμοποίητα πεδία επέκτασης):

```json
{
  "id": "msg_2D4Btbg1WgvkNE3tCYkR4xGA",
  "object": "chat.completion",
  "created": 1784466588,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 86,
    "completion_tokens": 206,
    "total_tokens": 292
  }
}
```

Το αποτέλεσμα επιστροφής περιλαμβάνει πολλά πεδία, τα οποία παρουσιάζονται παρακάτω:

- `id`, το ID που δημιουργείται για αυτήν την εργασία συνομιλίας και χρησιμοποιείται για τη μοναδική αναγνώρισή της.
- `model `, το επιλεγμένο μοντέλο από τον επίσημο ιστότοπο του Kimi.
- `choices`, οι πληροφορίες απάντησης που παρέχει το Kimi για την ερώτηση.
- `usage `: στατιστικές πληροφορίες για τα token αυτής της ερώτησης και απάντησης.

Το `choices` περιλαμβάνει τις πληροφορίες απάντησης του Kimi, και το `choices` μέσα σε αυτό είναι οι συγκεκριμένες πληροφορίες της απάντησης του Kimi, όπως φαίνεται στην εικόνα.

<p><img src="https://cdn.acedata.cloud/tv9rul.png" width="400" className="m-auto" /></p>

Μπορείτε να δείτε ότι το πεδίο `content` μέσα στο `choices` περιλαμβάνει το συγκεκριμένο περιεχόμενο της απάντησης του Kimi· το K3 μπορεί επίσης να επιστρέψει `reasoning_content`, το οποίο χρησιμοποιείται για την αναπαράσταση της διαδικασίας συλλογιστικής.

## Ένταση συλλογιστικής K3.1 Pro

Το `kimi-k3.1-pro` έχει πάντα ενεργοποιημένη τη συλλογιστική. Μπορείτε να ορίσετε το `reasoning_effort` στο ανώτατο επίπεδο του σώματος αιτήματος ως `low`, `high` ή `max`· μην εισάγετε ρυθμίσεις που απενεργοποιούν τη συλλογιστική. Το μοντέλο υποστηρίζει περιβάλλον έως 1.048.576 token, αλλά το πραγματικό όριο αιτήματος εξακολουθεί να εξαρτάται από την τρέχουσα διεπαφή. Η τιμολόγηση υπολογίζεται βάσει χρήσης εισόδου, εξόδου και επιτυχημένων επιτυχιών cache· για λεπτομέρειες, ανατρέξτε στην κάρτα Pricing του καταλόγου μοντέλων.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3.1-pro",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "low"
  }'
```

Το ακόλουθο παράδειγμα K3 διατηρείται για υπάρχουσες ενσωματώσεις και η απόκριση του παραδείγματος προήλθε πράγματι από αίτημα K3.

## Ένταση συλλογιστικής K3

Το `kimi-k3` έχει πάντα ενεργοποιημένη τη συλλογιστική. Το ανώτατο επίπεδο του σώματος αιτήματος υποστηρίζει το πεδίο `reasoning_effort`, και η μόνη υποστηριζόμενη τιμή αυτή τη στιγμή είναι η `max`· όταν το πεδίο παραλείπεται, χρησιμοποιείται επίσης η `max`. Οι `standard`, `high` ή άλλες συμβολοσειρές μπορεί να γίνονται χαλαρά αποδεκτές από ορισμένα συμβατά upstream, αλλά δεν εγγυάται ότι αλλάζουν τη συμπεριφορά συλλογιστικής, επομένως μην βασίζεστε σε αυτές.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "max"
  }'
```

Όταν χρησιμοποιείτε το OpenAI SDK, μπορείτε να μεταβιβάσετε αυτό το πεδίο απευθείας:

```python
response = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "设计一个可靠的任务队列"}],
    reasoning_effort="max",
)
```

Σε συνομιλίες πολλών γύρων και κλήσεις εργαλείων, παρακαλούμε επιστρέψτε το πλήρες μήνυμα `assistant` του προηγούμενου γύρου στο `messages`, συμπεριλαμβανομένων των `reasoning_content` και `tool_calls`.

### Επίσημες αναφορές

- [Thinking Effort](https://platform.kimi.ai/docs/guide/use-thinking-effort)：εξηγεί ότι το Kimi K3 έχει πάντα ενεργοποιημένη τη συλλογιστική και ότι η μόνη υποστηριζόμενη τιμή του `reasoning_effort` αυτή τη στιγμή είναι η `max`.
- [Model Parameter Reference](https://platform.kimi.ai/docs/api/models-overview)：συγκρίνει τις παραμέτρους συλλογιστικής, τα παράθυρα περιβάλλοντος και τις διαφορές στις κλήσεις εργαλείων μεταξύ των σειρών K3 και K2.
- [Create Chat Completion](https://platform.kimi.ai/docs/api/chat)：αιτήματα, αποκρίσεις και ορισμοί πεδίων OpenAPI του επίσημου Chat Completions της Moonshot.

## Ροϊκές αποκρίσεις

Αυτή η διεπαφή υποστηρίζει επίσης ροϊκές αποκρίσεις, κάτι που είναι πολύ χρήσιμο για ενσωμάτωση σε ιστοσελίδες, καθώς επιτρέπει την εμφάνιση χαρακτήρα προς χαρακτήρα.

Αν θέλετε να επιστρέφεται μια απόκριση σε ροή, μπορείτε να αλλάξετε την παράμετρο `stream ` στην κεφαλίδα του αιτήματος σε `true`.

Η τροποποίηση φαίνεται στην εικόνα, αλλά ο κώδικας κλήσης χρειάζεται τις αντίστοιχες αλλαγές για να υποστηρίζει ροϊκές αποκρίσεις.

<p><img src="https://cdn.acedata.cloud/a3nzpw.png" width="400" className="m-auto" /></p>

Αφού αλλάξετε το `stream` σε `true`, το API θα επιστρέφει τα αντίστοιχα δεδομένα JSON γραμμή προς γραμμή και, σε επίπεδο κώδικα, χρειάζεται να κάνουμε τις αντίστοιχες αλλαγές για να λάβουμε τα αποτελέσματα γραμμή προς γραμμή.

Δείγμα κώδικα κλήσης Python:
```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"user","content":"Hello"}],
    "reasoning_effort": "max",
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Παρακάτω παρατίθενται αποσπάσματα από τα μπλοκ δεδομένων έναρξης, συλλογισμού, κύριου κειμένου, λήξης και χρήσης της ίδιας πραγματικής ροϊκής απόκρισης K3 Max:

```json
data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"","role":"assistant"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"reasoning_content":"The"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"Hello"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{},"finish_reason":"stop"}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[],"usage":{"prompt_tokens":172,"completion_tokens":168,"total_tokens":340}}

data: [DONE]
```

Όπως φαίνεται, η απόκριση περιέχει πολλά `data`, και το `choices` μέσα στο `data` είναι το πιο πρόσφατο περιεχόμενο απάντησης, σύμφωνα με όσα παρουσιάστηκαν παραπάνω. Το `choices` είναι το νέο περιεχόμενο απάντησης και μπορείτε να το ενσωματώσετε στο σύστημά σας βάσει των αποτελεσμάτων. Ταυτόχρονα, το τέλος της ροϊκής απόκρισης κρίνεται με βάση το περιεχόμενο του `data`: αν το περιεχόμενο είναι `[DONE]`, αυτό υποδηλώνει ότι η ροϊκή απόκριση έχει ολοκληρωθεί πλήρως. Το επιστρεφόμενο αποτέλεσμα `data` περιέχει συνολικά πολλά πεδία, τα οποία παρουσιάζονται ως εξής:

- `id`, το ID που δημιουργείται για αυτήν την εργασία συνομιλίας και χρησιμοποιείται για τη μοναδική αναγνώρισή της.
- `model `, το μοντέλο Kimi που επιλέχθηκε από τον επίσημο ιστότοπο.
- `choices`, οι πληροφορίες απάντησης που παρέχει το Kimi για το ερώτημα.

Υποστηρίζεται επίσης το JavaScript, για παράδειγμα ο κώδικας ροϊκής κλήσης σε Node.js είναι ο εξής:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "kimi-k3",
    messages: [{ role: "user", content: "Hello" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

Δείγμα κώδικα Java:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "kimi-k3");
jsonObject.put("messages", new JSONArray().put(new JSONObject().put("role", "user").put("content", "Hello")));
jsonObject.put("stream", true);
MediaType mediaType = MediaType.parse("application/json; charset=utf-8");
RequestBody body = RequestBody.create(jsonObject.toString(), mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/kimi/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.println(response.body().string());
```

Άλλες γλώσσες μπορούν επίσης να προσαρμοστούν ξεχωριστά, καθώς η αρχή είναι η ίδια.

## Πολυγυρική συνομιλία

Αν θέλετε να ενσωματώσετε λειτουργία πολυγυρικής συνομιλίας, χρειάζεται να υποβάλετε πολλαπλά ερωτήματα στο πεδίο `messages`. Συγκεκριμένο παράδειγμα πολλαπλών ερωτημάτων παρουσιάζεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/g85v2a.png" width="400" className="m-auto" /></p>

Δείγμα κώδικα κλήσης Python:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"assistant","content":"Hello! How can I help you today?"},{"role":"user","content":"What model are you?"}],
    "reasoning_effort": "max"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Με την υποβολή πολλαπλών ερωτημάτων, μπορείτε να υλοποιήσετε εύκολα πολυγυρική συνομιλία. Ακολουθεί η πραγματική απόκριση K3 Max που έλαβε αυτό το αίτημα (παραλείπονται τα αχρησιμοποίητα επεκτατικά πεδία):

```json
{

  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "I’m Kimi, an AI assistant developed by Moonshot AI (月之暗面). I don’t have a specific public model version identifier to share from here."
```

Όπως φαίνεται, οι πληροφορίες που περιέχει το `choices` είναι συνεπείς με το περιεχόμενο της βασικής χρήσης. Περιλαμβάνει το συγκεκριμένο περιεχόμενο της απάντησης του Kimi σε πολλαπλές συνομιλίες, ώστε να μπορούν να απαντώνται τα αντίστοιχα ερωτήματα βάσει του περιεχομένου πολλαπλών συνομιλιών.

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, αν παρουσιαστεί σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό και μήνυμα σφάλματος. Για παράδειγμα:

- `400 token_mismatched`：Μη έγκυρο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Μη έγκυρο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
