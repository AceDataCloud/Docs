Kimi είναι μια σειρά AI μοντέλων που κυκλοφόρησε από το Moonshot. Το τρέχον προτεινόμενο `kimi-k3` απευθύνεται σε μακροχρόνιο προγραμματισμό, Agent, σύνθετη λογική και γνώση εργασίας, και μπορεί να κληθεί μέσω του API Chat Completions συμβατού με το OpenAI.

Αυτό το έγγραφο περιγράφει κυρίως τη διαδικασία χρήσης του Kimi Chat Completion API, επιτρέποντάς μας να χρησιμοποιήσουμε εύκολα τη λειτουργία συνομιλίας του επίσημου Kimi.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Kimi Chat Completion API, πρώτα πηγαίνετε στο [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν; όταν οι πιστώσεις εξαντληθούν, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στο [console](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Kimi Chat Completion API →](https://platform.acedata.cloud/documents/kimi-chat-completions)

## Βασική Χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/ej5ozg.png" width="400" className="m-auto" /></p>

Κατά την πρώτη χρήση αυτού του API, πρέπει τουλάχιστον να συμπληρώσετε τρία περιεχόμενα: `authorization` μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα; `model` χρησιμοποιείται για την επιλογή του μοντέλου Kimi, προτείνεται η χρήση του `kimi-k3`; `messages` είναι ο πίνακας μηνυμάτων συνομιλίας, κάθε μήνυμα περιλαμβάνει `role` και `content`, όπου το `role` υποστηρίζει `user`, `assistant`, `system` και `tool`.

Μπορείτε επίσης να παρατηρήσετε ότι στα δεξιά υπάρχει η αντίστοιχη γεννήτρια κώδικα κλήσης, μπορείτε να αντιγράψετε τον κώδικα και να τον εκτελέσετε απευθείας ή να κάνετε κλικ στο κουμπί «Δοκιμή» για να κάνετε δοκιμές.

<p><img src="https://cdn.acedata.cloud/six7e3.png" width="400" className="m-auto" /></p>

Ακολουθεί η πραγματική απόκριση K3 που αποκτήθηκε χρησιμοποιώντας `reasoning_effort: max` (παραλείποντας τα μη χρησιμοποιούμενα πεδία):

```json
{
  "id": "msg_2D4Btbg1WgvkNE3tCYkR4xGA",
  "object": "chat.completion",
  "created": 1784466588,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Γειά σου! Πώς μπορώ να σε βοηθήσω σήμερα;"
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 86,
    "completion_tokens": 206,
    "total_tokens": 292
  }
}
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, τα οποία περιγράφονται ως εξής:

- `id`, το ID που δημιουργήθηκε για αυτήν την εργασία συνομιλίας, χρησιμοποιείται για την μοναδική αναγνώριση αυτής της εργασίας συνομιλίας.
- `model`, το επιλεγμένο μοντέλο από την επίσημη ιστοσελίδα του Kimi.
- `choices`, οι πληροφορίες απάντησης που παρέχει το Kimi για την ερώτηση.
- `usage`: στατιστικά στοιχεία σχετικά με τα tokens για αυτήν την ερώτηση-απάντηση.

Το `choices` περιλαμβάνει τις πληροφορίες απάντησης του Kimi, και μέσα σε αυτό το `choices` βρίσκονται οι συγκεκριμένες πληροφορίες απάντησης του Kimi, όπως φαίνεται στην εικόνα.

<p><img src="https://cdn.acedata.cloud/tv9rul.png" width="400" className="m-auto" /></p>

Μπορείτε να δείτε ότι το πεδίο `content` μέσα στο `choices` περιλαμβάνει το συγκεκριμένο περιεχόμενο της απάντησης του Kimi; το K3 μπορεί επίσης να επιστρέψει το `reasoning_content`, το οποίο χρησιμοποιείται για να δηλώσει τη διαδικασία λογικής.

## Κ3 Ικανότητα Λογικής

Το `kimi-k3` έχει πάντα ενεργοποιημένη τη λογική. Το ανώτερο επίπεδο του σώματος αιτήματος υποστηρίζει το πεδίο `reasoning_effort`, η τρέχουσα μοναδική υποστηριζόμενη τιμή είναι `max`; αν παραλειφθεί αυτό το πεδίο, χρησιμοποιείται επίσης το `max`. Οι τιμές `standard`, `high` ή άλλες συμβολοσειρές μπορεί να γίνουν αποδεκτές από ορισμένες συμβατές ανώτερες εκδόσεις, αλλά δεν εγγυώνται ότι θα αλλάξουν τη συμπεριφορά της λογικής, παρακαλώ μην βασίζεστε σε αυτό.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3",
    "messages": [{"role": "user", "content": "Ελέγξτε αυτόν τον κώδικα και δώστε προτάσεις διόρθωσης"}],
    "reasoning_effort": "max"
  }'
```

Κατά τη χρήση του OpenAI SDK, μπορείτε να περάσετε απευθείας αυτό το πεδίο:

```python
response = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "Σχεδιάστε μια αξιόπιστη ουρά εργασιών"}],
    reasoning_effort="max",
)
```

Κατά τη διάρκεια πολλαπλών γύρων συνομιλίας και κλήσεων εργαλείων, παρακαλώ επιστρέψτε το πλήρες μήνυμα του assistant από τον προηγούμενο γύρο στο `messages`, συμπεριλαμβανομένων των `reasoning_content` και `tool_calls`.

### Επίσημες Αναφορές

- [Thinking Effort](https://platform.kimi.ai/docs/guide/use-thinking-effort): εξηγεί ότι το Kimi K3 έχει πάντα ενεργοποιημένη τη λογική, η τρέχουσα μοναδική υποστηριζόμενη τιμή για το `reasoning_effort` είναι `max`.
- [Model Parameter Reference](https://platform.kimi.ai/docs/api/models-overview): συγκρίνει τις παραμέτρους λογικής, το παράθυρο συμφραζομένων και τις διαφορές κλήσεων εργαλείων μεταξύ K3 και K2.
- [Create Chat Completion](https://platform.kimi.ai/docs/api/chat): επίσημο αίτημα Chat Completions του Moonshot, απαντήσεις και ορισμοί πεδίων OpenAPI.

## Ροή Απόκρισης

Αυτό το API υποστηρίζει επίσης ροή απόκρισης, κάτι που είναι πολύ χρήσιμο για την ενσωμάτωσή του σε ιστοσελίδες, καθώς επιτρέπει την εμφάνιση αποτελεσμάτων λέξη προς λέξη.

Εάν θέλετε να επιστρέψετε την απόκριση σε ροή, μπορείτε να αλλάξετε την παράμετρο `stream` στην κεφαλίδα του αιτήματος σε `true`.

Η αλλαγή φαίνεται στην εικόνα, αλλά ο κώδικας κλήσης χρειάζεται να έχει τις αντίστοιχες αλλαγές για να υποστηρίξει τη ροή απόκρισης.

<p><img src="https://cdn.acedata.cloud/a3nzpw.png" width="400" className="m-auto" /></p>

Αφού αλλάξετε το `stream` σε `true`, το API θα επιστρέφει γραμμή προς γραμμή τα αντίστοιχα δεδομένα JSON, και σε επίπεδο κώδικα θα χρειαστεί να κάνουμε τις κατάλληλες αλλαγές για να αποκτήσουμε τα αποτελέσματα γραμμή προς γραμμή.

Παράδειγμα κώδικα κλήσης σε Python:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"user","content":"Γειά σου"}],
    "reasoning_effort": "max",
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Ακολουθούν αποσπάσματα από την αρχή, τη λογική, το σώμα, την ολοκλήρωση και τα δεδομένα χρήσης από μια πραγματική ροή απόκρισης K3 Max:
```json
data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"","role":"assistant"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"reasoning_content":"Το"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"Γειά σου"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{},"finish_reason":"stop"}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[],"usage":{"prompt_tokens":172,"completion_tokens":168,"total_tokens":340}}

data: [DONE]
```

Μπορείτε να δείτε ότι η απάντηση περιέχει πολλά `data`, το `data` περιέχει τις τελευταίες απαντήσεις περιεχομένου, που είναι σύμφωνες με την προηγούμενη περιγραφή. Το `choices` είναι το νέο περιεχόμενο απάντησης, μπορείτε να το συνδέσετε με το σύστημά σας. Επίσης, η λήξη της ροής απάντησης καθορίζεται από το περιεχόμενο του `data`, αν το περιεχόμενο είναι `[DONE]`, τότε σημαίνει ότι η ροή απάντησης έχει ολοκληρωθεί. Τα επιστρεφόμενα αποτελέσματα `data` περιέχουν πολλά πεδία, που περιγράφονται παρακάτω:

- `id`, το ID που δημιουργήθηκε για αυτήν την εργασία συνομιλίας, χρησιμοποιείται για την μοναδική αναγνώριση αυτής της εργασίας συνομιλίας.
- `model`, το επιλεγμένο μοντέλο Kimi από την επίσημη ιστοσελίδα.
- `choices`, οι πληροφορίες απάντησης που παρέχονται από την Kimi για την ερώτηση.

Η JavaScript υποστηρίζεται επίσης, για παράδειγμα, ο κώδικας ροής κλήσης Node.js είναι ως εξής:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "kimi-k3",
    messages: [{ role: "user", content: "Γειά σου" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

Παράδειγμα κώδικα Java:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "kimi-k3");
jsonObject.put("messages", new JSONArray().put(new JSONObject().put("role", "user").put("content", "Γειά σου")));
jsonObject.put("stream", true);
MediaType mediaType = MediaType.parse("application/json; charset=utf-8");
RequestBody body = RequestBody.create(jsonObject.toString(), mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/kimi/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.println(response.body().string());
```

Άλλες γλώσσες μπορούν να τροποποιηθούν ανάλογα, η αρχή είναι η ίδια.

## Πολυδιάστατη συνομιλία

Αν θέλετε να ενσωματώσετε τη λειτουργία πολυδιάστατης συνομιλίας, πρέπει να ανεβάσετε πολλαπλές ερωτήσεις στο πεδίο `messages`, τα παραδείγματα πολλαπλών ερωτήσεων φαίνονται παρακάτω:

<p><img src="https://cdn.acedata.cloud/g85v2a.png" width="400" className="m-auto" /></p>

Παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
```

## Διαχείριση σφαλμάτων

Κατά την κλήση της API, αν προκύψουν σφάλματα, η API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
