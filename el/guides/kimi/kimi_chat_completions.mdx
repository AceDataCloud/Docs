Το Kimi είναι μια σειρά μοντέλων τεχνητής νοημοσύνης που κυκλοφόρησε η Moonshot. Επί του παρόντος, το προτεινόμενο μοντέλο είναι το `kimi-k3.1-pro`, το οποίο είναι κατάλληλο για μακροχρόνιο προγραμματισμό, σύνθετη συλλογιστική, οπτική κατανόηση και εργασίες γνώσης· το `kimi-k3` εξακολουθεί να είναι διαθέσιμο. Η κλήση πραγματοποιείται μέσω του συμβατού με OpenAI API Chat Completions.

Αυτό το έγγραφο παρουσιάζει κυρίως τη διαδικασία χρήσης του Kimi Chat Completion API. Μέσω αυτού, μπορούμε να χρησιμοποιήσουμε εύκολα τις λειτουργίες συνομιλίας του επίσημου Kimi.

## Υποστηριζόμενα μοντέλα

Επί του παρόντος υποστηρίζονται τέσσερα μοντέλα: `kimi-k3.1-pro`, `kimi-k3`, `kimi-k2.6` και `kimi-k2.7-code`. Το K2.7 Code προορίζεται για σενάρια προγραμματισμού και κλήσης εργαλείων και χρεώνεται στην ίδια κατηγορία τιμών με το K2.6· μην του μεταβιβάζετε τον διακόπτη `thinking` ή το `reasoning_effort` στα αιτήματα. Η υποστήριξη για τα υπόλοιπα μοντέλα Kimi έχει διακοπεί. Επιλέξτε ρητά ένα από αυτά τα τέσσερα μοντέλα στον client.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Kimi Chat Completion API, μεταβείτε πρώτα στην [κονσόλα του Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και να το κρατήσετε για μελλοντική χρήση.

![]()

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης, όπου θα σας ζητηθεί να εγγραφείτε και να συνδεθείτε. Μόλις ολοκληρωθεί η διαδικασία, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Κατά την πρώτη αίτηση παρέχεται δωρεάν υπόλοιπο, ώστε να μπορείτε να δοκιμάσετε την υπηρεσία χωρίς χρέωση· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να αναπληρώσετε το γενικό υπόλοιπο μέσω της [κονσόλας](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Kimi Chat Completion API →](https://platform.acedata.cloud/documents/kimi-chat-completions)

## Βασική χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε τα αντίστοιχα πεδία στη διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/ej5ozg.png" width="400" className="m-auto" /></p>

Την πρώτη φορά που χρησιμοποιείτε αυτό το API, πρέπει να συμπληρώσετε τουλάχιστον τρία πεδία: το `authorization` μπορεί να επιλεγεί απευθείας από την αναπτυσσόμενη λίστα· το `model` χρησιμοποιείται για την επιλογή του μοντέλου Kimi, με προτεινόμενο το `kimi-k3.1-pro`· το `messages` είναι ένας πίνακας μηνυμάτων συνομιλίας, όπου κάθε μήνυμα περιλαμβάνει τα πεδία `role` και `content`, και το `role` υποστηρίζει τις τιμές `user`, `assistant`, `system` και `tool`.

Ταυτόχρονα, μπορείτε να παρατηρήσετε ότι στα δεξιά δημιουργείται ο αντίστοιχος κώδικας κλήσης. Μπορείτε να αντιγράψετε τον κώδικα και να τον εκτελέσετε απευθείας ή να κάνετε κλικ στο κουμπί «Try» για δοκιμή.

<p><img src="https://cdn.acedata.cloud/six7e3.png" width="400" className="m-auto" /></p>

Ακολουθεί μια πραγματική απόκριση του K3 που λήφθηκε με τη χρήση του `reasoning_effort: max` (παραλείπονται τα μη χρησιμοποιούμενα πρόσθετα πεδία):

```json
{
  "id": "msg_2D4Btbg1WgvkNE3tCYkR4xGA",
  "object": "chat.completion",
  "created": 1784466588,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 86,
    "completion_tokens": 206,
    "total_tokens": 292
  }
}
```

Το αποτέλεσμα επιστροφής περιλαμβάνει συνολικά πολλά πεδία, τα οποία παρουσιάζονται παρακάτω:

- `id`: Το αναγνωριστικό της εργασίας συνομιλίας που δημιουργήθηκε, το οποίο χρησιμοποιείται για τη μοναδική αναγνώριση της συγκεκριμένης εργασίας συνομιλίας.
- `model `: Το μοντέλο Kimi του επίσημου ιστότοπου που επιλέχθηκε.
- `choices`: Οι πληροφορίες απάντησης που παρέχει το Kimi για την υποβληθείσα ερώτηση.
- `usage `: Οι στατιστικές πληροφορίες σχετικά με τη χρήση των token για την παρούσα ανταλλαγή ερωτήσεων και απαντήσεων.

Μεταξύ αυτών, το `choices` περιλαμβάνει τις πληροφορίες απάντησης του Kimi. Το `choices` στο εσωτερικό του περιέχει τις συγκεκριμένες πληροφορίες της απάντησης του Kimi, όπως φαίνεται στην εικόνα.

<p><img src="https://cdn.acedata.cloud/tv9rul.png" width="400" className="m-auto" /></p>

Όπως μπορείτε να δείτε, το πεδίο `content` μέσα στο `choices` περιέχει το συγκεκριμένο περιεχόμενο της απάντησης του Kimi· το K3 μπορεί επίσης να επιστρέψει το `reasoning_content`, το οποίο χρησιμοποιείται για την αναπαράσταση της διαδικασίας συλλογιστικής.

## Ένταση συλλογιστικής του K3.1 Pro

Το `kimi-k3.1-pro` έχει πάντα ενεργοποιημένη τη συλλογιστική. Μπορείτε να ορίσετε το `reasoning_effort` στο ανώτατο επίπεδο του σώματος του αιτήματος ως `low`, `high` ή `max`· μην μεταβιβάζετε ρυθμίσεις που απενεργοποιούν τη συλλογιστική. Το μοντέλο υποστηρίζει παράθυρο περιβάλλοντος έως και 1.048.576 token, αλλά το πραγματικό όριο κάθε αιτήματος εξακολουθεί να εξαρτάται από την τρέχουσα διεπαφή API. Η τιμολόγηση υπολογίζεται με βάση τη χρήση εισόδου, εξόδου και επιτυχημένων προσβάσεων στην προσωρινή μνήμη. Για λεπτομέρειες, ανατρέξτε στην κάρτα Pricing του καταλόγου μοντέλων.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3.1-pro",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "low"
  }'
```

Το παρακάτω παράδειγμα K3 διατηρείται για υπάρχουσες ενσωματώσεις. Το παράδειγμα απόκρισης προέρχεται πράγματι από αίτημα K3.

## Ένταση συλλογιστικής του K3

Το `kimi-k3` έχει πάντα ενεργοποιημένη τη συλλογιστική. Το ανώτατο επίπεδο του σώματος του αιτήματος υποστηρίζει το πεδίο `reasoning_effort`, του οποίου η μοναδική υποστηριζόμενη τιμή αυτή τη στιγμή είναι `max`· εάν παραλειφθεί αυτό το πεδίο, χρησιμοποιείται επίσης η τιμή `max`. Χρησιμοποιήστε τις υποστηριζόμενες τιμές.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "max"
  }'
```

Όταν χρησιμοποιείτε το OpenAI SDK, μπορείτε να μεταβιβάσετε απευθείας αυτό το πεδίο:

```python
response = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "设计一个可靠的任务队列"}],
    reasoning_effort="max",
)
```

Σε συνομιλίες πολλαπλών γύρων και κατά την κλήση εργαλείων, επιστρέψτε ολόκληρο το μήνυμα assistant του προηγούμενου γύρου στο `messages`, συμπεριλαμβανομένων των `reasoning_content` και `tool_calls`.

### Επίσημες αναφορές

- [Thinking Effort](https://platform.kimi.ai/docs/guide/use-thinking-effort): Εξηγεί ότι το Kimi K3 έχει πάντα ενεργοποιημένη τη συλλογιστική και ότι η μοναδική υποστηριζόμενη τιμή του `reasoning_effort` αυτή τη στιγμή είναι `max`.
- [Model Parameter Reference](https://platform.kimi.ai/docs/api/models-overview): Συγκρίνει τις παραμέτρους συλλογιστικής, τα παράθυρα περιβάλλοντος και τις διαφορές στην κλήση εργαλείων μεταξύ των σειρών K3 και K2.
- [Create Chat Completion](https://platform.kimi.ai/docs/api/chat): Ορίζει τα πεδία αιτημάτων, αποκρίσεων και OpenAPI του επίσημου Chat Completions API της Moonshot.

## Αποκρίσεις σε ροή

Αυτή η διεπαφή υποστηρίζει επίσης αποκρίσεις σε ροή, κάτι που είναι ιδιαίτερα χρήσιμο για την ενσωμάτωση σε ιστοσελίδες, καθώς επιτρέπει την εμφάνιση του κειμένου στην ιστοσελίδα σταδιακά, χαρακτήρα προς χαρακτήρα.

Εάν θέλετε να επιστρέφεται η απόκριση σε ροή, μπορείτε να αλλάξετε την παράμετρο `stream ` στην κεφαλίδα του αιτήματος σε `true`.

Τροποποιήστε τη ρύθμιση όπως φαίνεται στην εικόνα. Ωστόσο, ο κώδικας κλήσης πρέπει επίσης να τροποποιηθεί αντίστοιχα, ώστε να υποστηρίζει τις αποκρίσεις σε ροή.

<p><img src="https://cdn.acedata.cloud/a3nzpw.png" width="400" className="m-auto" /></p>
Αφού αλλάξετε το `stream` σε `true`, το API θα επιστρέφει τα αντίστοιχα δεδομένα JSON γραμμή προς γραμμή. Σε επίπεδο κώδικα, πρέπει να κάνουμε τις αντίστοιχες τροποποιήσεις για να λαμβάνουμε τα αποτελέσματα γραμμή προς γραμμή.

Παράδειγμα κώδικα κλήσης σε Python:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"user","content":"Hello"}],
    "reasoning_effort": "max",
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Παρακάτω παρατίθενται αποσπάσματα από τα αρχικά, συλλογιστικά, κύρια, τελικά και δεδομένα χρήσης μιας πραγματικής ροής απόκρισης K3 Max της ίδιας κλήσης:

```json
data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"","role":"assistant"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"reasoning_content":"The"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"Hello"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{},"finish_reason":"stop"}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[],"usage":{"prompt_tokens":172,"completion_tokens":168,"total_tokens":340}}

data: [DONE]
```

Όπως μπορείτε να δείτε, η απόκριση περιέχει πολλά `data`, και το `choices` μέσα στο `data` αντιστοιχεί στο πιο πρόσφατο περιεχόμενο της απάντησης, σύμφωνα με όσα παρουσιάστηκαν παραπάνω. Το `choices` περιέχει το νέο περιεχόμενο της απάντησης, το οποίο μπορείτε να ενσωματώσετε στο σύστημά σας σύμφωνα με τα αποτελέσματα. Ταυτόχρονα, ο τερματισμός της ροής απόκρισης καθορίζεται από το περιεχόμενο του `data`. Εάν το περιεχόμενο είναι `[DONE]`, αυτό σημαίνει ότι η απάντηση της ροής έχει ολοκληρωθεί πλήρως. Τα δεδομένα `data` που επιστρέφονται περιέχουν συνολικά πολλά πεδία, τα οποία παρουσιάζονται παρακάτω:

- `id`, το ID της εργασίας που δημιουργήθηκε για αυτήν τη συνομιλία, το οποίο χρησιμοποιείται για τη μοναδική αναγνώριση της συγκεκριμένης εργασίας συνομιλίας.
- `model `, το μοντέλο του επίσημου ιστότοπου Kimi που επιλέχθηκε.
- `choices`, οι πληροφορίες απάντησης που παρέχει το Kimi στο ερώτημα.

Υποστηρίζεται επίσης η JavaScript, για παράδειγμα, ο κώδικας κλήσης ροής στο Node.js είναι ο εξής:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "kimi-k3",
    messages: [{ role: "user", content: "Hello" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

Παράδειγμα κώδικα σε Java:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "kimi-k3");
jsonObject.put("messages", new JSONArray().put(new JSONObject().put("role", "user").put("content", "Hello")));
jsonObject.put("stream", true);
MediaType mediaType = MediaType.parse("application/json; charset=utf-8");
RequestBody body = RequestBody.create(jsonObject.toString(), mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/kimi/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.println(response.body().string());
```

Για άλλες γλώσσες, μπορείτε να προσαρμόσετε τον κώδικα μόνοι σας. Η αρχή λειτουργίας είναι η ίδια.

## Συνομιλία πολλαπλών γύρων

Εάν θέλετε να ενσωματώσετε τη λειτουργία συνομιλίας πολλαπλών γύρων, πρέπει να υποβάλετε πολλαπλά ερωτήματα στο πεδίο `messages`. Ένα συγκεκριμένο παράδειγμα πολλαπλών ερωτημάτων παρουσιάζεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/g85v2a.png" width="400" className="m-auto" /></p>

Παράδειγμα κώδικα κλήσης σε Python:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"assistant","content":"Hello! How can I help you today?"},{"role":"user","content":"What model are you?"}],
    "reasoning_effort": "max"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Υποβάλλοντας πολλαπλά ερωτήματα, μπορείτε εύκολα να υλοποιήσετε συνομιλίες πολλαπλών γύρων. Ακολουθεί η πραγματική απόκριση K3 Max που λήφθηκε από αυτό το αίτημα (παραλείπονται τα μη χρησιμοποιούμενα πρόσθετα πεδία):

Όπως μπορείτε να δείτε, οι πληροφορίες που περιλαμβάνει το `choices` είναι ίδιες με εκείνες της βασικής χρήσης. Περιλαμβάνουν το συγκεκριμένο περιεχόμενο των απαντήσεων που παρέχει το Kimi σε πολλαπλές συνομιλίες, ώστε να μπορείτε να απαντάτε στα αντίστοιχα ερωτήματα με βάση το περιεχόμενο των πολλαπλών συνομιλιών.

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν παρουσιαστεί κάποιο σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό και τις σχετικές πληροφορίες σφάλματος. Για παράδειγμα:

- `400 token_mismatched`: Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`: Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`: Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`: Too many requests, you have exceeded the rate limit.
- `500 api_error`: Internal server error, something went wrong on the server.
