`POST https://api.acedata.cloud/webextrator/extract`

Το API έξυπνης εξαγωγής WebExtrator μετατρέπει ένα URL σε **τυποποιημένο δομημένο αποτέλεσμα** — άρθρα, προϊόντα,
συνταγές, βίντεο, συζητήσεις, θέσεις εργασίας κ.ά. — και παρέχει επίσης καθαρισμένο Markdown και απλό κείμενο. Όταν θέλετε «καθαρά δομημένα δεδομένα» αντί για ακατέργαστο HTML, αυτή είναι η κατάλληλη διεπαφή.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε τη σελίδα υπηρεσιών WebExtrator, πρώτα πηγαίνετε στο [Ace Data Cloud κονσόλα](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, δεν χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις, μπορείτε να το δοκιμάσετε δωρεάν; όταν οι πιστώσεις είναι ανεπαρκείς, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [WebExtrator σελίδα υπηρεσιών →](https://platform.acedata.cloud/service/webextrator)

## Αυθεντικοποίηση

```
Authorization: Bearer YOUR_API_KEY
Content-Type:  application/json
```

## Παράμετροι αιτήματος

Το Extract δέχεται **όλες** τις παραμέτρους του [Render API](/el/guides/webextrator/webextrator_render)
（`url`、`user_agent`、`timeout`、`wait_until`、`delay`、`wait_for_selector`、
`block_resources`、`headers`、`cookies`、`callback_url`、`bypass_cache`、
`cache_ttl_seconds`、`async`）, καθώς και δύο πεδία αποκλειστικά για το Extract:

| Πεδίο | Τύπος | Υποχρεωτικό | Προεπιλογή | Περιγραφή |
|------|------|:----:|------|------|
| `expected_type` | enum | ❌ | Αυτόματος προσδιορισμός | Υπόδειξη τύπου σελίδας: `product` / `article` / `general`. Καθορίζει τον αναμενόμενο τύπο αποτελέσματος. |
| `enable_llm` | boolean | ❌ | `false` | Επιτρέπει την κλήση του LLM για εξαγωγή όταν δεν υπάρχει αντιστοίχιση στο schema.org. Σε σελίδες χωρίς JSON-LD, όπως Amazon / HN / Greenhouse, πρέπει να ενεργοποιηθεί για να ληφθούν τυποποιημένα αποτελέσματα. |

### Πεδία ανώτατου επιπέδου

| Πεδίο | Τύπος | Περιγραφή |
|------|------|------|
| `kind` | string | Σταθερό `"extract"`. |
| `url` | string | Το URL που υποβάλατε. |
| `finalUrl` | string | Το τελικό URL μετά τις ανακατευθύνσεις. |
| `contentType` | enum | Τύπος σελίδας: `product` / `article` / `general`. |
| `title` | string | Τίτλος σελίδας. |
| `description` | string? | Περιγραφή ή σύνοψη σελίδας. |
| `byline` | string? | Συγγραφέας, κανάλι ή εταιρεία. |
| `language` | string? | `<html lang>`.  |
| `siteName` | string? | `og:site_name`.  |
| `publishedAt` | string? | Χρόνος δημοσίευσης, σε μορφή ISO 8601. |
| `images` | string[] | Έως 50 `<img src />`, αναλυμένα σε απόλυτα URL, χωρίς διπλότυπα και με απόρριψη URI `data:`. |
| `links` | string[] | Έως 100 εξωτερικοί σύνδεσμοι, με φιλτραρισμένα αποσπάσματα / `javascript:` / `mailto:` / `tel:`. |
| `markdown` | string | Το περιεχόμενο Markdown της σελίδας. |
| `text` | string | Απλό κείμενο της σελίδας. |
| `structured` | object | Πλήρες δομημένο αποτέλεσμα, βλ. παρακάτω. |
| `rawSignals` | object | Διαγνωστικές πληροφορίες για αποσφαλμάτωση. |
| `cached` | boolean? | `true` όταν υπάρχει επιτυχία στην προσωρινή μνήμη. |
| `cacheStoredAt` | number? | Χρονική σήμανση Unix σε χιλιοστά του δευτερολέπτου όταν η εγγραφή της προσωρινής μνήμης γράφτηκε για πρώτη φορά. |

### Υποπεδία `data.structured`

| Υποπεδίο | Πότε εμφανίζεται | Περιγραφή |
|--------|---------|------|
| `schemaOrg` | Πάντα | `{ primary, breadcrumbs, all }`. Το `primary` είναι η τυποποιημένη οντότητα με την υψηλότερη προτεραιότητα· όταν δεν βρίσκεται, χρησιμοποιείται το `null`. |
| `openGraph` | Πάντα | `{ title, description, image, type }`, προερχόμενο από το `<meta property="og:*" />`. |
| `jsonLd` | Πάντα | Ακατέργαστος πίνακας JSON όλων των μπλοκ `<script type="application/ld+json">`. |
| `llm` | Όταν το LLM εκτελείται και επιτυγχάνει | `{ kind, data, model, promptCharCount }`, τυποποιημένο αποτέλεσμα. |
| `llmError` | Όταν το LLM εκτελείται αλλά αποτυγχάνει | `{ kind, error, model }`, το αίτημα μπορεί να επιστρέψει και άλλα εξαγμένα πεδία. |
| `amazon` | Όταν το URL είναι `amazon.*` | Αποτελέσματα παλαιού τύπου της επέκτασης Amazon· για νέες ενσωματώσεις, χρησιμοποιήστε τυποποιημένα αποτελέσματα. |

## Τύποι αποτελεσμάτων schema.org

Το `structured.schemaOrg.primary` υποστηρίζει τους ακόλουθους τύπους αποτελεσμάτων:

| Τύπος schema.org | kind | Πεδία εξόδου |
|----------------|----------|----------|
| `Product` | product | `name, sku, gtin, model, color, brand, url, images, offer.{price,currency,availability,condition,seller}, rating.{value,count}, reviews[], properties[]` |
| `Recipe` | recipe | `name, description, image, datePublished, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords, recipeCategory, recipeCuisine` |
| `VideoObject` | video | `name, description, thumbnailUrl, uploadDate, duration, embedUrl, contentUrl, channel, interactionCount` |
| `JobPosting` | job | `title, description, datePosted, validThrough, hiringOrganization, jobLocation, baseSalary, employmentType` |
| `Event` (συμπεριλαμβανομένου του `*Event`) | event | `name, description, startDate, endDate, location.{name,address}, organizer, offer.{url,price,currency}` |
| `Article` / `NewsArticle` / `BlogPosting` / `ScholarlyArticle` / `TechArticle` / `Report` / `*NewsArticle` | article | `subtype, headline, description, datePublished, dateModified, author, publisher, image[], url, sameAs[]` |
| `FAQPage` | faq | `questions[{question, answer}]` |
| `BreadcrumbList` | (προσαρτημένο σε sibling) | Η έξοδος γίνεται πάντα στο `structured.schemaOrg.breadcrumbs[]` και ποτέ ως primary. |

## Τύποι αποτελεσμάτων LLM

Όταν `enable_llm: true` και η σελίδα δεν διαθέτει αξιοποιήσιμα δομημένα δεδομένα schema.org, μπορούν να επιστραφούν τα ακόλουθα είδη εξαγμένων αποτελεσμάτων:

| Kind | Υποχρεωτικά πεδία | Προαιρετικά πεδία |
|------|---------|---------|
| `article` | `headline` | `description, byline, publishedAt, language, topics[], sections[{heading,summary}]` |
| `product` | `name` | `description, brand, sku, price, currency, availability, rating.{value,count}, bullets[], specifications[{name,value}]` |
| `discussion` | `title` | `author, postedAt, points, commentCount, body, url` |
| `recipe` | `name` | `description, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords[]` |
| `video` | `name` | `description, channel, uploadDate, duration, viewCount, likeCount, thumbnailUrl, transcript` |
| `job` | `title` | `description, company, location, remote, employmentType, datePosted, validThrough, salaryMin, salaryMax, salaryCurrency, salaryPeriod, responsibilities[], qualifications[]` |

## Προσωρινή αποθήκευση

Το ίδιο URL, οι παράμετροι αιτήματος, το `cookies` και το `headers` μπορούν να επαναχρησιμοποιήσουν αποθηκευμένα αποτελέσματα στην προσωρινή μνήμη· τα `async`, `bypass_cache` και `cache_ttl_seconds` χρησιμοποιούνται για τον έλεγχο του τρόπου εκτέλεσης και της συμπεριφοράς της προσωρινής αποθήκευσης.

| Πεδίο | Αποτέλεσμα |
|------|------|
| `bypass_cache: true` | Παράλειψη ανάγνωσης· το αποτέλεσμα αυτής της φοράς θα εξακολουθήσει να εγγράφεται στην προσωρινή μνήμη, ώστε το ίδιο αίτημα να μπορεί να εξυπηρετηθεί από αυτήν την επόμενη φορά. |
| `cache_ttl_seconds: 0` | Η απόκριση αυτής της φοράς **δεν αποθηκεύεται στην προσωρινή μνήμη**. |
| `cache_ttl_seconds: N` | Προσαρμόστε το TTL αυτής της καταχώρισης (προεπιλογή: 3600 δευτερόλεπτα). |

Οι αποκρίσεις που προέρχονται από την προσωρινή μνήμη θα περιλαμβάνουν τα `data.cached: true` και `data.cacheStoredAt: <unix-ms>`.

## 异步模式与回调

设置 `async: true` 进入异步模式（提供 `callback_url` 也会自动进入）。平台立即返回（HTTP 200）：

```json
{
  "success": true,
  "task_id": "550e8400-...",
  "trace_id": "6ba7b810-...",
  "started_at": 1777717800.123
}
```

任务完成时把完整 envelope `POST` 到你的 `callback_url`（如果配置了）。也可以事
后通过 [`/webextrator/tasks`](/el/guides/webextrator/webextrator_tasks) 主动查询。

### Python (requests)

```python
import os, requests

API_KEY = os.environ["ACEDATA_API_KEY"]

resp = requests.post(
    "https://api.acedata.cloud/webextrator/extract",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "url": "https://en.wikipedia.org/wiki/Diffbot",
        "expected_type": "article",
    },
    timeout=120,
)
resp.raise_for_status()
data = resp.json()["data"]

primary = (data.get("structured") or {}).get("schemaOrg", {}).get("primary")
print("contentType:", data["contentType"])
print("title:      ", data["title"])
print("byline:     ", data.get("byline"))
print("publishedAt:", data.get("publishedAt"))
if primary and primary["kind"] == "article":
    print("headline:    ", primary["headline"])
    print("dateModified:", primary.get("dateModified"))
```

### Node.js (fetch)

```js
const apiKey = process.env.ACEDATA_API_KEY;

const res = await fetch('https://api.acedata.cloud/webextrator/extract', {
  method: 'POST',

const { data } = await res.json();
const recipe = data?.structured?.schemaOrg?.primary;
console.log(recipe.name, recipe.cookTime, recipe.ingredients.length, 'είδη συστατικών');
```

## Συμβουλές και παγίδες

- **Όταν χρειάζεται να καθορίσετε τον τύπο σελίδας, περάστε το `expected_type`.** Για παράδειγμα, για σελίδες άρθρων χρησιμοποιήστε το `article` και για σελίδες προϊόντων το `product`.
- **Το `enable_llm: true` είναι δωρεάν σε σελίδες που αντιστοιχούν στο schema.org.** Το LLM καλείται μόνο όταν το schema.org
  δεν έχει primary, επομένως είναι ασφαλές να παραμένει ενεργοποιημένο από προεπιλογή.
- **Κατά την αποσφαλμάτωση, ελέγξτε πρώτα το `rawSignals.hasJsonLd`.** Αν είναι `true` αλλά το `structured.schemaOrg.primary`
  είναι `null`, σημαίνει ότι το `@type` της σελίδας δεν υποστηρίζεται ακόμη· μπορείτε να μας ενημερώσετε.
- **Το `structured.llmError` είναι ενημερωτικό.** Το αίτημα μπορεί και πάλι να επιστρέψει επιτυχώς άλλα εξαγμένα πεδία. Ελέγξτε το
  `llmError.error` για να εντοπίσετε την αιτία (λήξη χρονικού ορίου, αποτυχία ανάλυσης JSON, αποτυχία επικύρωσης δομής).
- **Το `links[]` για σελίδες που δεν είναι άρθρα δεν ταξινομείται κατά συνάφεια.** Γίνεται μόνο καθαρισμός βέλτιστης προσπάθειας με βάση το «όριο 100 στοιχείων + φιλτράρισμα μη έγκυρων πρωτοκόλλων».
  με καθαρισμό βέλτιστης προσπάθειας.
- **Οι επιτυχίες προσωρινής μνήμης χρεώνονται επίσης.**
