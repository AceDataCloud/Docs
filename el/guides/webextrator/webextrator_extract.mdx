`POST https://api.acedata.cloud/webextrator/extract`

Εξαγωγή περιεχομένου βασισμένη στο `/webextrator/render`. Εκτός από όλες τις παραμέτρους του render endpoint, υποστηρίζονται επιπλέον:

| Πεδίο | Τύπος | Υποχρεωτικό | Προεπιλογή | Περιγραφή |
|-------|-------|:-----------:|------------|----------|
| `expected_type` | string | ❌ | `markdown` | Αναμενόμενο αποτέλεσμα εξαγωγής: `markdown` / `article` / `text` / `links` / `structured` |
| `enable_llm` | boolean | ❌ | false | Ενεργοποίηση επεξεργασίας LLM (κατάλληλο για `article` / `structured`) |
| `instruction` | string | ❌ | - | Οδηγία εξαγωγής LLM, π.χ. «εξαγωγή τίτλου προϊόντος, τιμής, προδιαγραφών» |

## Συγχρονική Απόκριση

```json
{
  "success": true,
  "task_id": "550e8400-...",
  "trace_id": "550e8400-...",
  "started_at": "2026-05-02T10:30:00.123Z",
  "finished_at": "2026-05-02T10:30:08.789Z",
  "elapsed": 8.666,
  "data": {
    "kind": "extract",
    "expected_type": "article",
    "url": "https://example.com/post/1",
    "title": "Παράδειγμα Άρθρου",
    "author": "Ζανγκ Σαν",
    "published_at": "2026-05-01",
    "content": "# Παράδειγμα Άρθρου\n\nΚείμενο ...",
    "summary": "Αυτό το άρθρο παρουσιάζει ..."
  }
}
```

Η ασύγχρονη λειτουργία, οι κωδικοί σφαλμάτων και οι κανόνες χρέωσης είναι απολύτως ίδιοι με το `/webextrator/render`.

## Παράδειγμα: Εξαγωγή Κειμένου Άρθρου (με ενεργοποίηση LLM)

```bash
curl -X POST https://api.acedata.cloud/webextrator/extract \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/news/1",
    "expected_type": "article",
    "enable_llm": true
  }'
```

## Παράδειγμα: Ασύγχρονη Λειτουργία + Προσαρμοσμένη Δομημένη Εξαγωγή

```bash
curl -X POST https://api.acedata.cloud/webextrator/extract \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://shop.example.com/item/123",
    "expected_type": "structured",
    "enable_llm": true,
    "instruction": "εξαγωγή τίτλου προϊόντος, τιμής, αποθέματος, URL 3 κύριων εικόνων",
    "callback_url": "https://your-domain.com/wbx-callback"
  }'
```
