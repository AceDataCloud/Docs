Το API URL MP3 Suno δημιουργεί μια διαδρομή για υπάρχουσα μουσική που καταλήγει σε `.mp3`, κατάλληλη για περιπτώσεις όπου οι παλιές συνδέσεις λήψης έχουν αποτύχει, για αναπαραγωγή σε κινητές συσκευές ή όταν χρειάζεται να αποκτηθεί ξανά η δημόσια διεύθυνση ήχου.

Η υποχρεωτική παράμετρος `audio_id` είναι το ID ήχου που επιστρέφει το API δημιουργίας ήχου Suno. Κάθε κλήση δημιουργεί μια ανεξάρτητη εργασία URL MP3, δεν θα τροποποιήσει την αρχική εργασία δημιουργίας μουσικής και δεν θα αλλάξει το αρχικό ID ήχου.

## Συγχρονισμένη Κλήση

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={
        "accept": "application/json",
        "authorization": "Bearer <YOUR_API_TOKEN>",
        "content-type": "application/json"
    },
    json={"audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f"},
    timeout=240
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["file_url"])
```

Σε περίπτωση επιτυχίας, το `data[0].file_url` είναι η διεύθυνση αναπαραγωγής ήχου. Το API θα προσπαθήσει πρώτα να αποθηκεύσει στο `https://cdn.acedata.cloud/suno/{audio_id}.mp3`; αν η αποθήκευση αποτύχει, θα επιστρέψει τη διαθέσιμη αρχική διεύθυνση μέσου.

## Ασύγχρονη Κλήση

Όταν ο χρόνος επεξεργασίας είναι μεγαλύτερος, μπορείτε να περάσετε `async: true`:

```python
submission = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={"authorization": "Bearer <YOUR_API_TOKEN>"},
    json={
        "audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f",
        "async": True
    }
).json()

export_task_id = submission["task_id"]
```

Στη συνέχεια, μπορείτε να ελέγξετε το `export_task_id` μέσω του `/suno/tasks`. Μπορείτε επίσης να παρέχετε `callback_url`, για να λάβετε το τελικό αποτέλεσμα μόλις ολοκληρωθεί η εργασία. Η συγχρονισμένη απάντηση, η αναζήτηση εργασίας και η κλήση επιστροφής χρησιμοποιούν την ίδια δομή δεδομένων τελικής κατάστασης.

## Σημειώσεις

- Το `audio_id` πρέπει να προέρχεται από αναγνωρίσιμο ήχο Suno.
- Οι εργασίες URL MP3 είναι ανεξάρτητες από τις αρχικές εργασίες δημιουργίας μουσικής.
- Η αποτυχία αποθήκευσης δεν θα μπλοκάρει το αποτέλεσμα, θα επιστρέψει στην αρχική διεύθυνση μέσου; παρακαλώ κατεβάστε το εγκαίρως.
- Συνιστάται η πλευρά της επιχείρησης να κατεβάσει εγκαίρως τα αποτελέσματα και να τα αποθηκεύσει σύμφωνα με τη στρατηγική διατήρησης δεδομένων της.
