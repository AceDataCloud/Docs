title: "API Ελέγχου Διαθεσιμότητας Ήχου Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

`POST /suno/availability` αναζητά, βάσει του `audio_id`, θετικές ενδείξεις ότι ο ήχος μπορεί να συνεχίσει να υποβάλλεται σε επεξεργασία στην τρέχουσα γραμμή. Μπορεί να κληθεί πριν από ενέργειες όπως συνέχιση συγγραφής, διασκευή κ.λπ.· το αποτέλεσμα αντικατοπτρίζει μόνο την κατάσταση κατά τον χρόνο του ελέγχου και δεν εγγυάται ότι μια συγκεκριμένη ενέργεια θα επιτύχει οπωσδήποτε. Αυτή η διεπαφή επιστρέφει συγχρονισμένα, απαιτεί API Token και προς το παρόν δεν χρεώνει Credits.

Το `audio_id` είναι το ID του τραγουδιού που επιστρέφεται από μια ολοκληρωμένη εργασία Suno, όχι το `task_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

Παράδειγμα επιτυχούς απόκρισης:

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

Όταν ο έλεγχος είναι επιτυχής, το `data.available` θα είναι μόνο `true`. Η κατάσταση «εκτός σύνδεσης» που επιστρέφεται από ορισμένες γραμμές δεν μπορεί να αποδείξει ότι επακόλουθες ενέργειες, όπως η συνέχιση συγγραφής, δεν μπορούν να επιτύχουν· επομένως, αυτή η διεπαφή επιστρέφει `503 availability_unknown` όταν δεν μπορεί να επιβεβαιώσει, και δεν επιστρέφει `false`. Λανθασμένη μορφή `audio_id` επιστρέφει 400, ενώ ο περιορισμός ρυθμού ή η αποτυχία του ανάντη συστήματος επιστρέφουν επίσης απόκριση σφάλματος. Η κατάσταση ενδέχεται να αλλάξει μεταξύ της ολοκλήρωσης του ελέγχου και της πραγματικής ενέργειας.
