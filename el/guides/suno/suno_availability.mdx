Το `POST /suno/availability` δέχεται ένα ID πόρου. Για έλεγχο τραγουδιού στείλτε `audio_id`, για έλεγχο φωνής στείλτε `persona_id`, και ένα από τα δύο είναι υποχρεωτικό. Ο έλεγχος ολοκληρώνεται συγχρονισμένα, απαιτεί API Token και προς το παρόν δεν χρεώνει Credits.

## Αίτημα

Το `audio_id` προέρχεται από μια ολοκληρωμένη εργασία τραγουδιού και μπορεί να χρησιμοποιηθεί για έλεγχο πριν από συνέχιση ή διασκευή.

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

Το `persona_id` προέρχεται από το αποτέλεσμα δημιουργίας φωνής. Χρησιμοποιήστε την αρχική εφαρμογή και την ταυτότητα του καλούντος, και στείλτε το ακόλουθο σώμα αιτήματος σε μια διαδρομή δημιουργίας που υποστηρίζει ερωτήματα φωνής.

```json
{"persona_id":"33333333-3333-4333-8333-333333333333"}
```

## Απόκριση

Και τα δύο είδη αιτημάτων χρησιμοποιούν την ίδια επιτυχή απόκριση. Το `data.id` είναι το ID πόρου αυτού του ερωτήματος.

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

Το `available: true` σημαίνει ότι αυτός ο έλεγχος έλαβε θετικά στοιχεία. Για τις φωνές, ο έλεγχος επαληθεύει την ιδιοκτησία δημιουργίας και επιβεβαιώνει ότι ο συσχετισμένος λογαριασμός αναφέρεται επί του παρόντος ως συνδεδεμένος. Το πραγματικό αποτέλεσμα δημιουργίας εξακολουθεί να καθορίζεται από την εργασία δημιουργίας.

Οι ιδιωτικές κλωνοποιημένες φωνές που δημιουργούνται μέσω του `/suno/voices` εξαρτώνται από τον λογαριασμό δημιουργίας. Όταν επιβεβαιώνεται ότι αυτός ο λογαριασμός είναι επί του παρόντος εκτός σύνδεσης, η διεπαφή επιστρέφει HTTP 200, με το `data` ως εξής.

```json
{"id":"33333333-3333-4333-8333-333333333333","available":false}
```

Ο πελάτης μπορεί να επισημάνει αυτή τη φωνή ως επί του παρόντος μη διαθέσιμη και να ελέγξει ξανά αργότερα.

Όταν δεν μπορεί να γίνει επιβεβαίωση, επιστρέφονται HTTP 503 και `availability_unknown`, για παράδειγμα όταν δεν βρίσκεται ο πόρος, όταν λείπει η διαδρομή δημιουργίας από παλιές εγγραφές ή όταν λήγει το χρονικό όριο του ερωτήματος. Τα δημόσια στυλ τραγουδιστών μπορούν να χρησιμοποιηθούν μεταξύ λογαριασμών και επίσης επιστρέφουν 503 όταν ο λογαριασμός δημιουργίας είναι εκτός σύνδεσης. Τα ερωτήματα τραγουδιών εξακολουθούν να επιστρέφουν `available: true` μόνο όταν επιβεβαιώνεται η διαθεσιμότητα.

Κάθε αίτημα στέλνει μόνο ένα έγκυρο UUID. Όλες οι διαδρομές επιστρέφουν HTTP 400 όταν λαμβάνουν αιτήματα με διπλά ID ή με απουσία και των δύο ID. Οι διαδρομές που υποστηρίζουν μόνο ερωτήματα τραγουδιών επιστρέφουν HTTP 400 όταν λαμβάνουν αιτήματα που περιέχουν μόνο `persona_id`. Σε περίπτωση HTTP 429, μειώστε τη συχνότητα των ερωτημάτων.
