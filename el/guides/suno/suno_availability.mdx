title: "API ελέγχου διαθεσιμότητας ήχου Suno"

---

Το `POST /suno/availability` αναζητά, βάσει του `audio_id`, θετικές ενδείξεις ότι ο ήχος μπορεί να συνεχίσει να υποβάλλεται σε επεξεργασία στην τρέχουσα διαδρομή. Μπορεί να κληθεί πριν από ενέργειες όπως συνέχιση ή διασκευή· το αποτέλεσμα αντικατοπτρίζει μόνο την κατάσταση κατά τον χρόνο του ελέγχου και δεν εγγυάται ότι μια συγκεκριμένη ενέργεια θα επιτύχει. Αυτό το endpoint επιστρέφει σύγχρονα αποτελέσματα, απαιτεί API Token και προς το παρόν δεν χρεώνει Credits.

Το `audio_id` είναι το ID τραγουδιού που επιστρέφεται από μια ολοκληρωμένη εργασία Suno, όχι το `task_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

Ενδεικτική επιτυχής απόκριση:

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

Όταν ο έλεγχος είναι επιτυχής, το `data.available` είναι `true`· όταν δεν είναι δυνατή η επιβεβαίωση, επιστρέφεται `503 availability_unknown` και δεν επιστρέφεται το `false`. Εσφαλμένη μορφή του `audio_id` επιστρέφει 400, ενώ η υπέρβαση ορίου αιτημάτων ή οι ανωμαλίες της υπηρεσίας επιστρέφουν επίσης απόκριση σφάλματος. Η κατάσταση ενδέχεται να αλλάξει μεταξύ της ολοκλήρωσης του ελέγχου και της πραγματικής ενέργειας.
