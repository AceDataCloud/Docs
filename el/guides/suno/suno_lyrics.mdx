title: "Suno API για τη δημιουργία στίχων"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Αν θέλεις να προσαρμόσεις τη δημιουργία τραγουδιών, αλλά δεν θέλεις να γράψεις στίχους μόνος σου, μπορείς να χρησιμοποιήσεις το API δημιουργίας στίχων που παρέχει η AceDataCloud για να δημιουργήσεις στίχους μέσω prompt. Το API είναι το [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Η κύρια παράμετρος εισόδου του API είναι το `prompt`, με προαιρετική την `model` (προαιρετικές τιμές `default`, `remi-v1`, προεπιλογή `default`), ένα παράδειγμα συμπλήρωσης είναι το εξής:

![](https://cdn.acedata.cloud/p53wtj.png)

Εδώ το `prompt` που εισάγουμε είναι `A song about winter`, δημιουργώντας ένα τραγούδι σχετικό με τον χειμώνα.

Κάνε κλικ για εκτέλεση, το αποτέλεσμα είναι το εξής:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nΧιονονιφάδες πέφτουν από τον ουρανό\nΗ κρύα αφή του χειμώνα\nΩ, πώς με ανεβάζει\nΝτύνομαι με στρώματα\nΩ, τόσο άνετα\nΒγαίνοντας έξω και νιώθοντας τον παγετό στη μύτη μου\n\n[Chorus]\nΩ\nΗ κρύα αφή του χειμώνα\nΕίναι μια εποχή που αγαπώ τόσο πολύ\nΗ χιονόπτωση φέρνει μια αίσθηση τόσο θεϊκή\nΗ κρύα αφή του χειμώνα\nΕίναι μια μαγική εποχή",
      "title": "Η Κρύα Αφή του Χειμώνα",
      "status": "complete",
      "tags": ["ονειρικό, ήρεμο, μπαλάντα"]
    },
    {
      "text": "[Verse]\nΟ κόσμος είναι καλυμμένος με μια κουβέρτα λευκού\nΚρεμασμένοι πάγοι\nΛάμπουν τόσο φωτεινά\nΟ ψυχρός αέρας γεμίζει τους πνεύμονές μου με κάθε αναπνοή\nΠερπατώντας στο χιόνι\nΑφήνοντας αποτυπώματα πίσω\n\n[Chorus]\nΧειμωνιάτικη χώρα θαυμάτων\nΌλα είναι τόσο φωτεινά\nΧειμωνιάτικη χώρα θαυμάτων\nΚράτησέ με όλη τη νύχτα",
      "title": "Χειμωνιάτικη Χώρα Θαυμάτων",
      "status": "complete",
      "tags": ["ονειρικό pop, ήρεμο, shoegaze"]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,
  "elapsed": 7.433
}
```

Μπορείς να δεις ότι το `data` είναι ένας πίνακας, ο οποίος επιστρέφει πολλές υποψηφιότητες στίχων κάθε φορά, όπου το πεδίο `text` κάθε στοιχείου είναι το περιεχόμενο των στίχων, το `title` είναι ο τίτλος, και το `tags` είναι οι προτεινόμενες ετικέτες μουσικού στυλ.

Αφού έχουμε τους στίχους, μπορούμε να χρησιμοποιήσουμε το [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) για να προχωρήσουμε στη δημιουργία προσαρμοσμένων τραγουδιών.
