Αν θέλετε να δημιουργήσετε προσαρμοσμένα τραγούδια, αλλά δεν θέλετε ιδιαίτερα να γράψετε μόνοι σας τους στίχους, μπορείτε να χρησιμοποιήσετε το API δημιουργίας στίχων που παρέχει το AceDataCloud για να δημιουργήσετε στίχους μέσω prompt. Το API είναι το [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Χρέωση: Μετά από επιτυχή δημιουργία, το τυπικό κόστος για κάθε αίτημα είναι **0.08 Credits**. Όταν ένα αίτημα επιστρέφει πολλαπλούς υποψηφίους στίχων, εξακολουθεί να χρεώνεται μόνο ως ένα αίτημα· οι ισχύουσες εκπτώσεις κατανάλωσης υπόκεινται στον πραγματικό λογαριασμό και τα αποτυχημένα αιτήματα δεν χρεώνονται.

Η κύρια παράμετρος εισόδου αυτού του API είναι το `prompt`, με προαιρετικό το `model` (προαιρετικές τιμές `default`, `remi-v1`, προεπιλογή `default`), και ένα παράδειγμα συμπλήρωσης είναι το εξής:

![](https://cdn.acedata.cloud/p53wtj.png)

Εδώ, το `prompt` που εισάγουμε είναι `A song about winter`, για να δημιουργήσουμε ένα τραγούδι σχετικό με τον χειμώνα.

Κάντε κλικ στην εκτέλεση και το αποτέλεσμα είναι το εξής:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nSnowflakes falling from the sky\nWinter's cold touch\nOh how it gets me high\nI bundle up in layers\nOh so cozy\nStepping out and feeling the frost on my nose\n\n[Chorus]\nOh\nWinter's cold touch\nIt's a season that I love so much\nSnowfall brings a feeling so divine\nWinter's cold touch\nIt's a magical time",
      "title": "Winter's Cold Touch",
      "status": "complete",
      "tags": ["dreamy, mellow, ballad"]
    },
    {
      "text": "[Verse]\nThe world is covered in a blanket of white\nIcicles hanging\nShimmering so bright\nThe chilly air fills my lungs with every breath\nWalking in the snow\nLeaving footprints behind\n\n[Chorus]\nWinter wonderland\nEverything is so bright\nWinter wonderland\nHold me through the night",
      "title": "Winter Wonderland",
      "status": "complete",
      "tags": ["dream pop, mellow, shoegaze"]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,
  "elapsed": 7.433
}
```

Μπορείτε να δείτε ότι το `data` είναι ένας πίνακας και κάθε φορά επιστρέφονται πολλαπλοί υποψήφιοι στίχων, όπου το πεδίο `text` κάθε στοιχείου είναι το περιεχόμενο των στίχων, το `title` είναι ο τίτλος και το `tags` είναι οι προτεινόμενες ετικέτες μουσικού ύφους.

Αφού έχουμε τους στίχους, μπορούμε να χρησιμοποιήσουμε το [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) για να πραγματοποιήσουμε προσαρμοσμένη δημιουργία τραγουδιών.
