title: "Suno API για τη δημιουργία στίχων"

---

Αν θέλεις να προσαρμόσεις τη δημιουργία τραγουδιών, αλλά δεν θέλεις να γράψεις στίχους μόνος σου, μπορείς να χρησιμοποιήσεις το API δημιουργίας στίχων που παρέχει η AceDataCloud για να δημιουργήσεις στίχους μέσω prompt. Το API είναι το [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/514d82dc-f7ab-4638-9f21-8b9275916b08).

Η κύρια παράμετρος εισόδου του API είναι το `prompt`, με προαιρετική την `model` (προεπιλογή chirp-v3), ένα παράδειγμα συμπλήρωσης είναι το εξής:

![](https://cdn.acedata.cloud/p53wtj.png)

Εδώ το `prompt` που εισάγουμε είναι `A song about winter`, δημιουργώντας ένα τραγούδι σχετικό με τον χειμώνα.

Κάνε κλικ για εκτέλεση, το αποτέλεσμα είναι το εξής:

```
{
  "success": true,
  "task_id": "57e8ce3a-39cb-41a2-802f-e70a324f4d0a",
  "data": {
    "text": "[Verse]\nSnowflakes falling from the sky\nWinter's cold touch\nOh how it gets me high\nI bundle up in layers\nOh so cozy\nStepping out and feeling the frost on my nose\nSee\n\n[Verse 2]\nThe world is covered in a blanket of white\nIcicles hanging\nShimmering so bright\nThe chilly air fills my lungs with every breath\nWalking in the snow\nLeaving footprints that won't be left\n\n[Chorus]\nOh\nWinter's cold touch\nIt's a season that I love so much\nSnowfall brings a feeling so divine\nWinter's cold touch\nIt's a magical time",
    "title": "Winter's Cold Touch",
    "status": "complete"
  }
}
```

Μπορείς να δεις ότι το πεδίο `text` του `data` είναι οι πληροφορίες στίχων.

Αφού έχουμε τους στίχους, μπορούμε να χρησιμοποιήσουμε το [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) για να προχωρήσουμε στη δημιουργία προσαρμοσμένου τραγουδιού.
