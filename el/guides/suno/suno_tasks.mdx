Η κύρια λειτουργία του Suno Tasks API είναι η αναζήτηση της κατάστασης εκτέλεσης μιας εργασίας μέσω της εισαγωγής του ID εργασίας που δημιουργείται από το Suno Audios Generation API ή το Suno Lyrics Generation API.

Αυτό το έγγραφο θα παρουσιάσει λεπτομερώς τις οδηγίες ενσωμάτωσης του Suno Tasks API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τις ισχυρές δυνατότητες αυτού του API. Μέσω του Suno Tasks API, μπορείτε εύκολα να πραγματοποιήσετε αναζήτηση της κατάστασης εκτέλεσης εργασιών του Suno Lyrics Generation API ή του Suno Audios Generation API.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Suno Audios Generation API, αρχικά μεταβείτε στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, και κρατήστε το για εφεδρεία.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να σας προσκαλέσει να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να υποβάλετε αίτηση ξεχωριστά για κάθε υπηρεσία.** Η πρώτη αίτηση θα προσφέρει δωρεάν υπόλοιπο, ώστε να μπορείτε να το δοκιμάσετε δωρεάν· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να επαναφορτίσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## Παράδειγμα αιτήματος

Το Suno Tasks API μπορεί να χρησιμοποιηθεί για την αναζήτηση των αποτελεσμάτων των δύο API, Suno Audios Generation API και Suno Lyrics Generation API. Σχετικά με το πώς να χρησιμοποιήσετε το Suno Audios Generation API, ανατρέξτε στην τεκμηρίωση [Suno Audios Generation API ](https://platform.acedata.cloud/documents/suno-audios-integration). Σχετικά με το πώς να χρησιμοποιήσετε το Suno Lyrics Generation API, ανατρέξτε στο [Suno Lyrics Generation API ](https://platform.acedata.cloud/documents/suno-lyrics-generation-integration).

Ας υποθέσουμε ότι έχουμε ένα ID εργασίας: eae26f89-b64b-404d-a80c-761996660b1c, στη συνέχεια θα δείξουμε πώς μέσω της εισαγωγής ενός ID εργασίας να.

### Ρύθμιση κεφαλίδων αιτήματος και σώματος αιτήματος

Τα **Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει τη λήψη αποτελεσμάτων απόκρισης σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, μετά την αίτηση μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα.

Το **Request Body** περιλαμβάνει:

- `id`: το ID της μεταφορτωμένης εργασίας.
- `action`: τον τρόπο λειτουργίας για την εργασία.

### Παράδειγμα κώδικα

Μπορείτε να διαπιστώσετε ότι στη δεξιά πλευρά της σελίδας έχουν ήδη δημιουργηθεί αυτόματα κώδικες σε διάφορες γλώσσες, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/p6vi9o.png" width="500" className="m-auto" /></p>

Μερικά παραδείγματα κώδικα είναι τα εξής:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/suno/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "eae26f89-b64b-404d-a80c-761996660b1c",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "eae26f89-b64b-404d-a80c-761996660b1c",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Επιστρεφόμενο αποτέλεσμα περιέχει συνολικά πολλαπλά πεδία, όπου το `items` περιλαμβάνει τις συγκεκριμένες πληροφορίες λεπτομερειών των εργασιών μαζικών τραγουδιών, και οι συγκεκριμένες πληροφορίες κάθε εργασίας τραγουδιού είναι ίδιες με τα πεδία που αναφέρονται παραπάνω. Οι πληροφορίες πεδίων είναι οι εξής.

- `items`, όλες οι συγκεκριμένες πληροφορίες λεπτομερειών των εργασιών μαζικών τραγουδιών. Είναι ένας πίνακας, και κάθε στοιχείο του πίνακα έχει την ίδια μορφή με το αποτέλεσμα επιστροφής για την αναζήτηση μίας μεμονωμένης εργασίας που αναφέρεται παραπάνω.
- `count`, ο αριθμός των εργασιών τραγουδιών στο παρόν μαζικό ερώτημα.

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
