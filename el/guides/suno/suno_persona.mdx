---
title: "Οδηγίες ενσωμάτωσης API προσαρμοσμένου στυλ τραγουδιστή Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Το SUNO μας επιτρέπει να ορίσουμε στυλ τραγουδιστή για τραγούδια που έχουν ήδη δημιουργηθεί και στη συνέχεια να πραγματοποιήσουμε δευτερογενή δημιουργία βάσει αυτού. Αυτό το έγγραφο εξηγεί τη μέθοδο ενσωμάτωσης του σχετικού API.

Το `GET /suno/persona` για αναζήτηση λίστας και το `DELETE /suno/persona` για διαγραφή εγγραφών δεν χρεώνονται και δεν απαιτούν πρόσθετη κεφαλίδα αιτήματος απαλλαγής από χρέωση. Η λειτουργία δημιουργίας `POST /suno/persona` εξακολουθεί να χρεώνεται σύμφωνα με τους κανόνες τιμολόγησης της διεπαφής.

Στις διαδρομές δημιουργίας που υποστηρίζουν αναζήτηση φωνητικού χρώματος, μπορείτε να χρησιμοποιήσετε την αρχική εφαρμογή και την ταυτότητα του καλούντος για να μεταβιβάσετε το `persona_id` από το αποτέλεσμα δημιουργίας στο `POST /suno/availability`. Όταν επιβεβαιωθεί ότι είναι διαθέσιμο, επιστρέφεται `data.available=true`.[Οδηγός ελέγχου διαθεσιμότητας φωνητικού χρώματος](https://platform.acedata.cloud/documents/suno-availability-integration)

Αυτό το API έχει μόνο τρεις παραμέτρους εισόδου: πρώτα το `audio_id`, το οποίο είναι το ID ενός τραγουδιού που έχει ήδη δημιουργηθεί επιτυχώς επίσημα, και έπειτα τα `name`, `description`, που είναι ένα όνομα και μια περιγραφή για το στυλ τραγουδιστή.

Εδώ το `audio_id` που εισάγουμε είναι `https://cdn.acedata.cloud/2qhzs3.png`. Μπορείτε να ανατρέξετε στο [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) για να πραγματοποιήσετε προσαρμοσμένη δημιουργία τραγουδιού και τελικά να λάβετε το `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Το αποτέλεσμα είναι το εξής:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Μπορείτε να δείτε ότι το πεδίο `persona_id` του `data` είναι το ID του στυλ τραγουδιστή μετά τη δημιουργία.

Αφού έχουμε το ID του στυλ τραγουδιστή, μπορούμε να χρησιμοποιήσουμε το [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) για να πραγματοποιήσουμε προσαρμοσμένη δημιουργία τραγουδιού. Για παράδειγμα, μεταβιβάστε `artist_consistency` στο `action`, ενώ μεταβιβάστε το ID του μεταφορτωμένου τραγουδιού στο `audio_id`, και πρέπει επίσης να μεταφορτώσετε την παράμετρο `persona_id`. Αυτή η τιμή είναι το ID του στυλ τραγουδιστή που επιστράφηκε παραπάνω, και έτσι μπορείτε να δημιουργήσετε νέο τραγούδι βάσει του στυλ τραγουδιστή αναφοράς.
