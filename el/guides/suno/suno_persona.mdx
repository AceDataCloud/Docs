---
title: "Suno API Οδηγίες Σύνδεσης για Προσαρμοσμένο Στυλ Καλλιτέχνη"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

Το SUNO μας επιτρέπει να ορίσουμε το στυλ του καλλιτέχνη για ήδη παραγόμενα τραγούδια και στη συνέχεια να προχωρήσουμε σε δευτερεύουσα δημιουργία. Αυτό το έγγραφο εξηγεί τη μέθοδο σύνδεσης με το σχετικό API.

Αυτό το API έχει μόνο τρεις παραμέτρους εισόδου, πρώτα το `audio_id`, το οποίο είναι ένα ID τραγουδιού που έχει ήδη παραχθεί επιτυχώς από την επίσημη πηγή, και στη συνέχεια το `name` και το `description`, που είναι ένα όνομα και μια περιγραφή του στυλ του καλλιτέχνη.

Εδώ, το `audio_id` που εισάγουμε είναι `https://cdn.acedata.cloud/2qhzs3.png`, το οποίο μπορεί να αναφερθεί στο [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) για τη δημιουργία προσαρμοσμένων τραγουδιών, και τελικά μπορούμε να αποκτήσουμε το `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Το αποτέλεσμα είναι το εξής:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Μπορούμε να δούμε ότι το πεδίο `persona_id` στο `data` είναι το ID του στυλ του καλλιτέχνη που έχει παραχθεί.

Αφού αποκτήσουμε το ID του στυλ του καλλιτέχνη, μπορούμε να χρησιμοποιήσουμε το [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) για να δημιουργήσουμε προσαρμοσμένα τραγούδια, για παράδειγμα, περνώντας το `action` ως `artist_consistency`, ενώ το `audio_id` θα είναι το ID του ανεβασμένου τραγουδιού, και θα χρειαστεί να ανεβάσουμε την παράμετρο `persona_id`, η οποία είναι η τιμή του ID του στυλ του καλλιτέχνη που επιστράφηκε παραπάνω, και έτσι μπορούμε να δημιουργήσουμε νέα τραγούδια με βάση το αναφερόμενο στυλ του καλλιτέχνη.
