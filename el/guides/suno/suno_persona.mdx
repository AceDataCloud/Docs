---
title: "Οδηγίες ενσωμάτωσης API προσαρμοσμένου στυλ τραγουδιστή Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Το SUNO μάς επιτρέπει να ορίσουμε ένα στυλ τραγουδιστή για τραγούδια που έχουν ήδη δημιουργηθεί και στη συνέχεια να πραγματοποιήσουμε δευτερογενή δημιουργία βάσει αυτού. Αυτό το έγγραφο εξηγεί τη μέθοδο ενσωμάτωσης των σχετικών API.

Η αναζήτηση λίστας με `GET /suno/persona` και η διαγραφή εγγραφών με `DELETE /suno/persona` δεν χρεώνονται και δεν απαιτούν επιπλέον κεφαλίδες αιτημάτων χωρίς χρέωση. Η λειτουργία δημιουργίας με `POST /suno/persona` εξακολουθεί να χρεώνεται σύμφωνα με τους κανόνες τιμολόγησης της διεπαφής.

Αυτό το API έχει μόνο τρεις παραμέτρους εισόδου: πρώτα το `audio_id`, το οποίο είναι το ID ενός τραγουδιού που έχει ήδη δημιουργηθεί επιτυχώς επίσημα, και έπειτα τα `name`, `description`, τα οποία είναι μια ονομασία και περιγραφή για το στυλ τραγουδιστή.

Εδώ, το `audio_id` που εισάγουμε είναι το `https://cdn.acedata.cloud/2qhzs3.png`. Μπορείτε να ανατρέξετε στο [API Δημιουργίας Ηχητικών Suno](https://platform.acedata.cloud/documents/suno-audios) για να πραγματοποιήσετε προσαρμοσμένη δημιουργία τραγουδιού και τελικά να λάβετε το `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Το αποτέλεσμα είναι το εξής:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Μπορείτε να δείτε ότι το πεδίο `persona_id` του `data` είναι το ID του στυλ τραγουδιστή μετά τη δημιουργία.

Αφού έχουμε το ID του στυλ τραγουδιστή, μπορούμε να χρησιμοποιήσουμε το [API Δημιουργίας Ηχητικών Suno](https://platform.acedata.cloud/documents/suno-audios) για να πραγματοποιήσουμε προσαρμοσμένη δημιουργία τραγουδιού. Για παράδειγμα, αν περάσουμε το `artist_consistency` στο `action`, ενώ στο `audio_id` περάσουμε το ID του μεταφορτωμένου τραγουδιού, πρέπει επίσης να μεταφορτώσουμε την παράμετρο `persona_id`, της οποίας η τιμή είναι το ID του στυλ τραγουδιστή που επιστράφηκε παραπάνω, και έτσι μπορούμε να δημιουργήσουμε νέο τραγούδι βάσει του στυλ τραγουδιστή αναφοράς.
