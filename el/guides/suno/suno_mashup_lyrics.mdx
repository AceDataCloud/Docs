Αν θέλεις να χρησιμοποιήσεις τους στίχους δύο τραγουδιών για να δημιουργήσεις ένα μικτό τραγούδι, μπορείς πρώτα να χρησιμοποιήσεις αυτήν την API για να δημιουργήσεις τους αντίστοιχους στίχους, η API είναι [Suno MashupLyrics Generation API](https://platform.acedata.cloud/documents/suno-mashup-lyrics).

Η κύρια είσοδος παραμέτρων της API είναι `lyrics_a`, `lyrics_b`, συμπληρώνοντας το παράδειγμα όπως παρακάτω:

![](https://cdn.acedata.cloud/g9n3t6.png)

Κάνε κλικ για εκτέλεση, το αποτέλεσμα είναι το εξής:

```
{
  "success": true,
  "task_id": "80aa3cd3-ca87-4ca3-82d2-1830e3d8f53a",
  "data": {
    "text": "Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nSambuy come, Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \nSambuy come back",
    "title": "Lyrics Mashup",
    "tags": [],
    "status": "complete"
  }
}
```

Μπορείς να δεις ότι το πεδίο `text` του `data` είναι οι πληροφορίες στίχων.

Αφού έχουμε τους στίχους, μπορούμε να χρησιμοποιήσουμε την [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) για να προχωρήσουμε στη δημιουργία προσαρμοσμένου τραγουδιού.
