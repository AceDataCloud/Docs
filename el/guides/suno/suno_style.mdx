Το SUNO μας επιτρέπει να εισάγουμε προτροπές για να δημιουργήσουμε ενισχυμένο στυλ τραγουδιών. Αυτό το έγγραφο εξηγεί τη μέθοδο σύνδεσης με το σχετικό API.

Αυτό το API έχει μόνο μία παράμετρο εισόδου, που είναι το `prompt`, το οποίο είναι η προτροπή στυλ που χρειάζεται βελτιστοποίηση.

Εδώ η προτροπή που εισάγουμε είναι `A song for Christmas`.

```python
import requests

url = "https://api.acedata.cloud/suno/style"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A song for Christmas"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```
