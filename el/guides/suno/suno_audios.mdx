Με την ευρεία εφαρμογή της AI, διάφορα προγράμματα AI έχουν σταδιακά γίνει δημοφιλή. Η AI έχει βαθιά διεισδύσει σε όλες τις πτυχές της εργασιακής και καθημερινής ζωής των ανθρώπων. Οι τομείς που εμπλέκονται με την AI αυξάνονται συνεχώς, από την αρχική συγγραφή, στην ιατρική εκπαίδευση, μέχρι τη μουσική σήμερα.

Το Suno είναι μια επαγγελματική και υψηλής ποιότητας πλατφόρμα δημιουργίας τραγουδιών και μουσικής με AI, όπου οι χρήστες απλώς εισάγουν απλές κειμενικές προτροπές και μπορούν να δημιουργήσουν τραγούδια με φωνητικά σύμφωνα με το στυλ και τους στίχους. Αυτός ο γεννήτορας μουσικής AI έχει αναπτυχθεί από μέλη ομάδων γνωστών τεχνολογικών εταιρειών όπως η Meta, η TikTok και η Kensho, με στόχο να επιτρέψει σε όλους να δημιουργούν υπέροχη μουσική χωρίς την ανάγκη εργαλείων μουσικής.

Ακολουθεί η πρόοδος των ενημερώσεων του μοντέλου:

| Έκδοση  | μοντέλο          | Ημερομηνία κυκλοφορίας | περιορισμός prompt | περιορισμός στυλ | μέγιστη διάρκεια τραγουδιού |
| ----- | --------------- | ---------- | --------- | -------- | ------ |
| v5    | chirp-v5        | 2025.09.23 | 5000      | 1000     | 8 λεπτά   |
| v4.5+ | chirp-v4-5-plus | 2025.07.17 | 5000      | 1000     | 8 λεπτά   |
| v4.5  | chirp-v4-5      | 2025.05.03 | 5000      | 1000     | 4 λεπτά   |
| v4    | chirp-v4        | 2024.12.17 | 3000      | 200      | 150 δευτερόλεπτα  |
| v3.5  | chirp-v3-5      | ---        | 3000      | 200      | 120 δευτερόλεπτα  |

Το Suno έχει αναβαθμίσει το μοντέλο δημιουργίας μουσικής στην έκδοση V5, και για να καλέσετε την τελευταία V5, απλώς αλλάξτε την παράμετρο model σε `chirp-v5`, και μπορείτε να δημιουργήσετε τραγούδια διάρκειας 9 λεπτών.

Ωστόσο, η επίσημη Suno δεν παρέχει API, η AceDataCloud προσφέρει ένα σύνολο API του Suno, προσομοιώνοντας την επίσημη σύνδεση του Suno, διευκολύνοντας τη γρήγορη δημιουργία της επιθυμητής μουσικής.

## Αίτηση και Χρήση

Για να χρησιμοποιήσετε το Suno Audios API, μπορείτε πρώτα να επισκεφθείτε τη σελίδα [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα απαραίτητα διαπιστευτήρια:

![](https://cdn.acedata.cloud/nyq0xz.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να σας προσκαλέσουν να εγγραφείτε και να συνδεθείτε, και μετά την εγγραφή και σύνδεση θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Για να σκεφτείτε κάποια τραγούδια, μπορείτε να εισάγετε οποιοδήποτε κείμενο, για παράδειγμα, αν θέλετε να δημιουργήσετε ένα τραγούδι για τα Χριστούγεννα, μπορείτε να εισάγετε `a song for Christmas`, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `action`: η ενέργεια της τρέχουσας μουσικής δημιουργίας, προεπιλεγμένη είναι `generate`, που περιλαμβάνει κυρίως: `extend`, `upload_extend`, `cover`, `upload_cover`, `replace_section`, `concat`, `stems`, `all_stems`, `remaster`.
- `prompt`: η προτροπή της έμπνευσης από την επίσημη Suno.
- `model`: το μοντέλο της τρέχουσας μουσικής δημιουργίας, προεπιλεγμένο είναι `chirp-v3-5`, που περιλαμβάνει κυρίως: `chirp-v3`, `chirp-v4`, `chirp-v3-5`, `chirp-v4-5`, `chirp-v4-5-plus`, `chirp-v5`.
- `lyric`: το περιεχόμενο των στίχων της προσαρμοσμένης λειτουργίας της Suno.
- `custom`: αν θα χρησιμοποιηθεί η προσαρμοσμένη λειτουργία, προεπιλεγμένο είναι: `false`.
- `instrumental`: η επιλογή καθαρής μουσικής της έμπνευσης από την Suno.
- `title`: ο τίτλος της μουσικής της προσαρμοσμένης λειτουργίας της Suno.
- `style`: το στυλ της μουσικής της προσαρμοσμένης λειτουργίας της Suno.
- `style_negative`: το στυλ που αποκλείεται από την προσαρμοσμένη λειτουργία της Suno.
- `audio_weight`: το ποσοστό του αναφερόμενου ήχου, εύρος 0-1, όσο μεγαλύτερο, τόσο περισσότερο εξαρτάται από τον αναφερόμενο ήχο.
- `audio_id`: το ID της αναφερόμενης μουσικής.
- `overpainting_start`/`overpainting_end`: η αρχή και το τέλος του χρόνου για την προσθήκη φωνητικών σε υπάρχουσα καθαρή μουσική, μονάδα δευτερόλεπτα.
- `underpainting_start`/`underpainting_end`: η αρχή και το τέλος του χρόνου για την προσθήκη συνοδείας σε καθαρή φωνή, μονάδα δευτερόλεπτα.
- `persona_id`: το ID του καλλιτέχνη του τραγουδιού.
- `continue_at`: ο χρόνος σε δευτερόλεπτα για να συνεχίσετε την υπάρχουσα μουσική. Για παράδειγμα, 213.5 σημαίνει να συνεχίσετε μέχρι 3 λεπτά και 33.5 δευτερόλεπτα.
- `style_influence`: οι προηγμένες παράμετροι `style_influence`.
- `replace_section_end`: ο τελικός χρόνος του τμήματος που θα αντικατασταθεί.
- `replace_section_start`: ο αρχικός χρόνος του τμήματος που θα αντικατασταθεί.
- `vocal_gender`: έλεγχος του φύλου της φωνής, γυναικεία φωνή `f`, ανδρική φωνή `m`, ισχύει για μοντέλα 4.5 και άνω.
- `weirdness`: οι προηγμένες παράμετροι `weirdness`.
- `lyric_prompt`: η προτροπή για τη δημιουργία στίχων, ισχύει μόνο όταν `custom` είναι `true` και δεν έχει μεταδοθεί `lyric`.
- `callback_url`: το URL για την επιστροφή των αποτελεσμάτων.

## Προσαρμοσμένη Δημιουργία

Αν θέλετε να προσαρμόσετε τη δημιουργία στίχων, μπορείτε να εισάγετε στίχους:

Αυτή τη στιγμή το πεδίο `lyric` μπορεί να μεταφέρει περιεχόμενο όπως το παρακάτω:

```
[Verse]\nΧιονονιφάδες πέφτουν παντού\nΛαμπερό λευκό\nΚαλύπτοντας το έδαφος\nΠαιδιά γελούν\nΓεμάτα απόλαυση\nΣε αυτό το χειμερινό θαύμα απόψε\nΗ έλκηθρο του Άγιου Βασίλη\nΣτον ουρανό\nΗ μύτη του Ρούντολφ λάμπει φωτεινά\nΩ Θεέ μου\nΆκου τα καμπανάκια\nΝα χτυπούν καθαρά\nΦέρνοντας χαρά και γιορτινή διάθεση\n[Verse 2]\nΨήσιμο κάστανων από τη λάμψη της φωτιάς\nΧριστουγεννιάτικα φώτα\nΛάμπουν και δείχνουν\nΟικογένειες συγκεντρώνονται με αγάπη και χαρά\nΔιαδίδοντας ζεστασιά σε όλους κοντά
```

> Σημειώστε ότι οι στίχοι εδώ `\n` είναι χαρακτήρας αλλαγής γραμμής, αν δεν ξέρετε πώς να δημιουργήσετε στίχους, μπορείτε να χρησιμοποιήσετε το API δημιουργίας στίχων που παρέχει η AceDataCloud για να δημιουργήσετε στίχους μέσω prompt, το API είναι [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/514d82dc-f7ab-4638-9f21-8b9275916b08).

Στη συνέχεια, πρέπει να προσαρμόσουμε τη δημιουργία τραγουδιού με βάση τους στίχους, τον τίτλο, το στυλ, μπορείτε να καθορίσετε τα παρακάτω περιεχόμενα:

- lyric: κείμενο στίχων
- custom: συμπληρώστε ως `true`, που σημαίνει προσαρμοσμένη δημιουργία, αυτή η παράμετρος είναι προεπιλεγμένη false, που σημαίνει ότι χρησιμοποιείται η δημιουργία μέσω `prompt`.
- title: τίτλος του τραγουδιού.
- style: στυλ του τραγουδιού, προαιρετικό.

## Λειτουργία Δημιουργίας με Προσαρμοσμένο Στυλ Καλλιτέχνη
如果 θέλετε να χρησιμοποιήσετε το στυλ ενός καλλιτέχνη για να δημιουργήσετε ένα τραγούδι, πρώτα μέσω της βασικής χρήσης που αναφέρθηκε παραπάνω, δημιουργήστε ένα τραγούδι. Στο τέλος, θα χρειαστεί να ρυθμίσετε αυτό το τραγούδι στο στυλ του καλλιτέχνη και θα πρέπει να εισέλθετε στο [Suno Persona API](https://platform.acedata.cloud/documents/78bb6c62-6ce0-490f-a7df-e89d80ec0583) για να δημιουργήσετε μια παράμετρο id καλλιτέχνη `persona_id` με βάση το μουσικό ID `audio_id` που έχει παραχθεί από την επίσημη πηγή. Οι συγκεκριμένες παράμετροι φαίνονται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/pmzo3l.png" width="500" className="m-auto" /></p>

Αφού συμπληρωθούν, δημιουργείται αυτόματα ο παρακάτω κώδικας:

<p><img src="https://cdn.acedata.cloud/a5g0nj.png" width="500" className="m-auto" /></p>

Αντίστοιχος κώδικας Python:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "name": "test"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Αν κάνετε κλικ για εκτέλεση, μπορείτε να δείτε ότι θα λάβετε ένα αποτέλεσμα, όπως παρακάτω:

```json
{
  "success": true,
  "task_id": "7628b754-4fe7-4e79-bda4-806d0dd8bf6e",
  "data": {
    "persona_id": "e0d7319e-aa2a-44cb-b00a-916218d7cb0b"
  }
}
```

## Συνέχεια Δημιουργίας

Αν θέλετε να συνεχίσετε τη δημιουργία ενός ήδη παραγόμενου τραγουδιού Suno, μπορείτε να ρυθμίσετε την παράμετρο `action` σε `extend` και να εισάγετε το ID του τραγουδιού που θέλετε να συνεχίσετε να δημιουργείτε. Το ID του τραγουδιού μπορεί να αποκτηθεί μέσω της βασικής χρήσης, όπως αναφέρθηκε παραπάνω, και μπορείτε να δείτε ότι το ID του τραγουδιού είναι:

Αν θέλετε να συνεχίσετε τη δημιουργία ενός τραγουδιού που έχετε ανεβάσει, μπορείτε να ρυθμίσετε την παράμετρο `action` σε `upload_extend` και να εισάγετε το ID του τραγουδιού που θέλετε να συνεχίσετε να δημιουργείτε. - lyric: κείμενο στίχων

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v4-5",

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Ασύγχρονη Επιστροφή

Δεδομένου ότι η δημιουργία μουσικής από το Suno διαρκεί σχετικά πολύ, περίπου 1-2 λεπτά, αν το API δεν απαντά για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος, γι' αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη επιστροφή.

Η συνολική διαδικασία είναι: όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`, μετά την υποβολή του API αίτημα, το API θα επιστρέψει αμέσως ένα αποτέλεσμα, που περιλαμβάνει μια πληροφορία πεδίου `task_id`, που αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα της δημιουργίας μουσικής θα αποσταλεί μέσω POST JSON στη διεύθυνση `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε συγκεκριμένα μέσω παραδείγματος.

Καταρχάς, η επιστροφή Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα, οι προγραμματιστές θα πρέπει να την αντικαταστήσουν με το URL του HTTP διακομιστή που έχουν δημιουργήσει.
