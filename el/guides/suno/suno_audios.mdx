Με την ευρύτερη εφαρμογή της AI, διάφορα προγράμματα AI έχουν σταδιακά διαδοθεί. Η AI έχει σταδιακά διεισδύσει σε κάθε πτυχή της εργασίας και της ζωής των ανθρώπων. Και οι κλάδοι που εμπλέκονται με την AI γίνονται ολοένα και περισσότεροι, από την αρχική συγγραφή, έως την ιατρική και την εκπαίδευση, και τώρα τη μουσική.

Το Suno είναι μια επαγγελματική πλατφόρμα υψηλής ποιότητας για δημιουργία τραγουδιών και μουσικής με AI. Οι χρήστες χρειάζεται μόνο να εισαγάγουν απλές προτροπές κειμένου και μπορούν να δημιουργήσουν τραγούδια με φωνητικά βάσει του είδους, του ύφους και των στίχων. Αυτός ο δημιουργός μουσικής με AI αναπτύχθηκε από μέλη ομάδων γνωστών τεχνολογικών εταιρειών όπως οι Meta, TikTok και Kensho, με στόχο να μη χρειάζονται καθόλου μουσικά όργανα, ώστε όλοι να μπορούν να δημιουργούν υπέροχη μουσική.

Ακολουθεί η πρόοδος των ενημερώσεων του μοντέλου:

| Έκδοση      | model           | Ημερομηνία κυκλοφορίας | Περιορισμός lyric | Περιορισμός style | Μέγιστη διάρκεια τραγουδιού |
| ------- | --------------- | ---------- | -------- | -------- | ------ |
| v6      | chirp-v6        | 2026.09.09 | —        | —        | —      |
| v6 Wild | chirp-v6-wild   | 2026.09.09 | —        | —        | —      |
| v6 Mini | chirp-v6-mini   | 2026.09.09 | —        | —        | —      |
| v5.5    | chirp-v5-5      | 2026.03.27 | 5000     | 1000     | 8 λεπτά   |
| v5      | chirp-v5        | 2025.09.23 | 5000     | 1000     | 8 λεπτά   |
| v4.5+   | chirp-v4-5-plus | 2025.07.17 | 5000     | 1000     | 8 λεπτά   |
| v4.5    | chirp-v4-5      | 2025.05.03 | 5000     | 1000     | 4 λεπτά   |
| v4      | chirp-v4        | 2024.12.17 | 3000     | 200      | 150 δευτερόλεπτα  |
| v3.5    | chirp-v3-5      | ---        | 3000     | 200      | 120 δευτερόλεπτα  |

> Οι περιορισμοί `lyric` και `style` στον παραπάνω πίνακα είναι τα ανώτατα όρια στη λειτουργία προσαρμογής (όταν το `custom` είναι `true`). Στη μη προσαρμοσμένη λειτουργία έμπνευσης (όταν το `custom` είναι `false`) συμπληρώνεται μόνο το `prompt`, με μέγιστο μήκος 500 χαρακτήρες (ίδιο για όλα τα μοντέλα).

Το Suno υποστηρίζει πλέον τα `chirp-v6`, `chirp-v6-wild` και `chirp-v6-mini`. Συνιστάται η χρήση του `chirp-v6`· τα ονόματα των παλαιότερων μοντέλων συνεχίζουν να είναι συμβατά.

Ωστόσο, η επίσημη Suno δεν παρέχει API, ενώ το AceDataCloud παρέχει ένα σύνολο API για το Suno, προσομοιώνοντας τη σύνδεση με το επίσημο Suno, ώστε να μπορείτε να δημιουργείτε εύκολα και γρήγορα τη μουσική που θέλετε.

## Αίτηση και χρήση

Για να χρησιμοποιήσετε το Suno Audios Generation API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να λάβετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης, όπου θα σας προσκληθεί να εγγραφείτε και να συνδεθείτε· μετά την ολοκλήρωση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση προσφέρει δωρεάν υπόλοιπο, για δωρεάν δοκιμή· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## Βασική χρήση

Για όποιο τραγούδι θέλετε να δημιουργήσετε, μπορείτε να εισαγάγετε οποιοδήποτε κομμάτι κειμένου. Για παράδειγμα, αν θέλω να δημιουργήσω ένα τραγούδι για τα Χριστούγεννα, μπορώ να εισαγάγω `a song for Christmas`, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ ορίσαμε τα Request Headers, που περιλαμβάνουν:

- `accept`: τη μορφή στην οποία θέλετε να λαμβάνετε το αποτέλεσμα απόκρισης· εδώ συμπληρώνεται ως `application/json`, δηλαδή μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, ορίστηκε το Request Body, που περιλαμβάνει:
- `action`: τύπος εργασίας ήχου, προεπιλογή είναι `generate`. Υποστηρίζει λειτουργίες όπως δημιουργία, συνέχιση, διασκευή, μίξη, διαχωρισμό κομματιών, προσθήκη κομματιών ήχου, εξαγωγή καθορισμένων κομματιών ήχου, δημιουργία ηχητικών εφέ και προσαρμογή ταχύτητας, όλες μέσω της κλήσης `POST /suno/audios`.
- `prompt`: προτροπή λειτουργίας έμπνευσης του επίσημου Suno (ισχύει όταν το `custom` είναι `false`), έως 500 χαρακτήρες.
- `model`: το μοντέλο για αυτή την εργασία δημιουργίας μουσικής. Η σειρά v6 περιλαμβάνει τα `chirp-v6`, `chirp-v6-wild` και `chirp-v6-mini`· τα παλαιά ονόματα μοντέλων συνεχίζουν να είναι συμβατά.
- `max_mode`: λειτουργία ενισχυμένης δημιουργίας. Το `generate` ενεργοποιείται μόνο όταν και τα `custom` και `max_mode` είναι `true`, με κόστος 1.12 Credits· το `add_stem` μπορεί να ενεργοποιηθεί απευθείας, με κόστος 1.344 Credits. Όταν είναι απενεργοποιημένο ή παραλείπεται, το κόστος είναι αντίστοιχα 0.56 και 0.672 Credits.
- `variety`: ένταση ποικιλομορφίας των αποτελεσμάτων δημιουργίας, με επιλογές `off`, `normal`, `high`, `extra`, `max`. Χρησιμοποιείται μόνο για `generate` και `add_stem`· η χρήση του με άλλα action θα επιστρέψει 400.
- `lyric`: περιεχόμενο στίχων για τη λειτουργία προσαρμογής του επίσημου Suno. Τα `chirp-v3-5` και `chirp-v4` έχουν μέγιστο 3000 χαρακτήρες· το `chirp-v4-5` και νεότερα (συμπεριλαμβανομένων των `chirp-v5`, `chirp-v5-5`) έχουν μέγιστο 5000 χαρακτήρες.
- `custom`: αν θα χρησιμοποιηθεί η λειτουργία προσαρμογής, η προεπιλογή είναι: `false`.
- `instrumental`: επιλογή ορχηστρικής μουσικής στη λειτουργία έμπνευσης του επίσημου Suno.
- `title`: τίτλος μουσικής στη λειτουργία προσαρμογής του επίσημου Suno. Τα `chirp-v3-5`, `chirp-v4` έχουν μέγιστο 80 χαρακτήρες· το `chirp-v4-5` και νεότερα έχουν μέγιστο 100 χαρακτήρες.
- `style`: μουσικό ύφος στη λειτουργία προσαρμογής του επίσημου Suno. Τα `chirp-v3-5` και `chirp-v4` έχουν μέγιστο 200 χαρακτήρες· το `chirp-v4-5` και νεότερα (συμπεριλαμβανομένων των `chirp-v5`, `chirp-v5-5`) έχουν μέγιστο 1000 χαρακτήρες.
- `negative_tags`: μουσικά ύφη ή είδη που επιθυμείτε να αποκλείσετε κατά την προσαρμοσμένη δημιουργία, μπορεί επίσης να χρησιμοποιηθεί για `replace_section`. Αυτή η διεπαφή επί του παρόντος δεν ορίζει σταθερό ανώτατο όριο χαρακτήρων για αυτό το πεδίο· υπερβολικά μεγάλο περιεχόμενο ενδέχεται να μην μπορεί να υποβληθεί σε επεξεργασία, συνιστάται να διατηρείτε την περιγραφή σύντομη.
- `audio_weight`: βάρος επιρροής των χαρακτηριστικών ήχου ή φωνής, εύρος 0-1, και το `0` είναι επίσης έγκυρη τιμή. Μπορεί να χρησιμοποιηθεί για λειτουργίες όπως δημιουργία, συνέχιση, διασκευή, προσθήκη κομματιών ήχου και συνέπεια φωνής· όταν δεν υπάρχει ήχος αναφοράς ή χαρακτηριστικό φωνής, το μοντέλο μπορεί να μειώσει ή να αγνοήσει αυτή την τιμή.
- `audio_id`: το ID της μουσικής αναφοράς, χρησιμοποιείται για επόμενες λειτουργίες όπως διασκευή, συνέχιση και διαχωρισμός κομματιών. Το αρχείο ήχου μπορεί ακόμα να ληφθεί, αλλά αυτό δεν σημαίνει ότι η επεξεργασία αυτού του ID θα είναι πάντα διαθέσιμη· εάν επιστραφεί `suno_processing_unavailable`, διατηρήστε τα `task_id` και `trace_id` και επικοινωνήστε με την υποστήριξη.
- `overpainting_start`/`overpainting_end`: χρόνοι έναρξης και λήξης για την προσθήκη φωνητικών σε υπάρχουσα ορχηστρική μουσική, σε δευτερόλεπτα.
- `underpainting_start`/`underpainting_end`: χρόνοι έναρξης και λήξης για την προσθήκη συνοδείας σε a cappella, σε δευτερόλεπτα.
- `persona_id`: το ID φωνής που λαμβάνεται μέσω της διεπαφής δημιουργίας Persona ή φωνής, δεν είναι το `audio_id` ενός τραγουδιού.
- `continue_at`: όριο συνέχισης, σε δευτερόλεπτα. Για παράδειγμα, το 213.5 σημαίνει ότι θα ξεκινήσει η δημιουργία του επόμενου αποσπάσματος από το 3ο λεπτό και 33.5ο δευτερόλεπτο. Τα `lyric` και `style` καθοδηγούν μόνο το νέο περιεχόμενο μετά το όριο και δεν θα αντικαταστήσουν τους στίχους ή το τραγούδισμα πριν από το όριο στον πηγαίο ήχο.
- `style_influence`: επιρροή ύφους στη λειτουργία προσαρμογής, εύρος 0-1, όσο μεγαλύτερη είναι τόσο συνήθως ταιριάζει περισσότερο με το επιλεγμένο ύφος· το `0` θα μεταβιβαστεί ως έγκυρη τιμή.
- `replace_section_end`: ο τελικός χρόνος του αποσπάσματος αντικατάστασης.
- `replace_section_start`: ο χρόνος έναρξης του αποσπάσματος αντικατάστασης.
- `vocal_gender`: ελέγχει την προτίμηση για γυναικεία ή ανδρική φωνή, γυναικεία φωνή `f`, ανδρική φωνή `m`, ισχύει για μοντέλα 4.5 και νεότερα· είναι στοιχείο προτίμησης και δεν εγγυάται αυστηρή τήρηση.
- `weirdness`: βαθμός παραδοξότητας στη λειτουργία προσαρμογής, εύρος 0-1, όσο μεγαλύτερος είναι τόσο συνήθως πιο δημιουργικό και πειραματικό είναι το αποτέλεσμα· το `0` θα μεταβιβαστεί ως έγκυρη τιμή.
- `duration`: επιθυμητή διάρκεια τραγουδιού, σε δευτερόλεπτα, πρέπει να είναι ακέραιος, με εύρος τιμών από 10 έως 360. Προς το παρόν μόνο το `generate` χρησιμοποιεί αυτή την παράμετρο και το συγκεκριμένο αποτέλεσμα εξαρτάται από τη λειτουργία και το μοντέλο. Είναι μια ενδεικτική προτροπή και όχι αυστηρός περιορισμός: το μοντέλο θα τη λάβει υπόψη, αλλά δεν εγγυάται ότι θα την επιτύχει· η πραγματική διάρκεια του τελικού αποτελέσματος υπερισχύει στο πεδίο `duration` της απόκρισης και συνήθως είναι μικρότερη από την επιθυμητή τιμή.

### Πεδίο εφαρμογής του ID φωνής

Τα `generate`, `cover`, `upload_cover`, `artist_consistency`, `artist_consistency_vox` μπορούν να χρησιμοποιούν `persona_id`. Τα δύο τελευταία action πρέπει να παρέχουν `persona_id`· μπορούν επίσης να παρέχουν ταυτόχρονα το `audio_id` του τραγουδιού που χρησιμοποιήθηκε κατά τη δημιουργία αυτού του Persona.

Τα `extend`, `upload_extend` δεν χρησιμοποιούν επιπλέον `persona_id`. Το αν τα `mashup`, `inspo` υποστηρίζουν ID φωνής εξαρτάται από το επιλεγμένο κανάλι υπηρεσίας· τα άλλα action δεν εγγυώνται την εφαρμογή αυτού του πεδίου, χρησιμοποιήστε το σύμφωνα με τις οδηγίες κάθε λειτουργίας. Το `vocal_gender` είναι μια προαιρετική προτίμηση φύλου και δεν μπορεί να αντικαταστήσει το ID φωνής.

Οι επόμενες λειτουργίες δημιουργίας απαιτούν έγκυρο πηγαίο `audio_id`· το `mashup` απαιτεί τουλάχιστον δύο `mashup_audio_ids`. Όταν λείπουν απαιτούμενες πηγές ή παράμετροι χρόνου, θα επιστραφεί HTTP 400.

### Πεδίο εφαρμογής προηγμένων παραμέτρων
| Παράμετρος                | Τιμή                                          | Υποστηριζόμενα action                              | Περιγραφή                                |
| ----------------- | ------------------------------------------- | --------------------------------------- | --------------------------------- |
| `weirdness`       | 0-1                                         | Προαιρετικό                                      | Ρυθμίζει την πειραματικότητα, το `0` είναι έγκυρη τιμή· το αποτέλεσμα εξαρτάται από τη λειτουργία, τη λειτουργία και το μοντέλο      |
| `style_influence` | 0-1                                         | Προαιρετικό                                      | Ρυθμίζει την τάση τήρησης του στυλ, το `0` είναι έγκυρη τιμή· το αποτέλεσμα εξαρτάται από τη λειτουργία, τη λειτουργία και το μοντέλο   |
| `audio_weight`    | 0-1                                         | Προαιρετικό                                      | Ρυθμίζει την επίδραση των χαρακτηριστικών ήχου ή φωνής· ενδέχεται να αγνοηθεί από το μοντέλο όταν δεν υπάρχουν πληροφορίες αναφοράς        |
| `variety`         | `off` / `normal` / `high` / `extra` / `max` | `generate`、`add_stem`                   | Ρυθμίζει τη στιλιστική ποικιλομορφία μεταξύ των αποτελεσμάτων                       |
| `max_mode`        | boolean                                     | `generate`（απαιτεί `custom=true`）、`add_stem` | Ενισχύει τη συνέπεια και χρεώνει σύμφωνα με την ενισχυμένη λειτουργία                     |
| `vocal_gender`    | `f` / `m`                                   | Λειτουργίες δημιουργίας που υποστηρίζουν έλεγχο φωνητικών                             | Προτίμηση, δεν εγγυάται αυστηρή τήρηση                       |
| `duration`        | Ακέραιος 10-360                                   | `generate`                              | Επιθυμητή διάρκεια· άλλα action δεν χρησιμοποιούν προς το παρόν αυτό το πεδίο, η πραγματική διάρκεια καθορίζεται από το αποτέλεσμα |

Η πλατφόρμα θα επικυρώσει τους τύπους παραμέτρων και τα εύρη τιμών, αλλά δεν θα απορρίψει αυτά τα προαιρετικά στοιχεία ρύθμισης μόνο λόγω διαφορετικού action· το συγκεκριμένο αποτέλεσμα καθορίζεται από τη λειτουργία, τη λειτουργία και το μοντέλο.

- `lyric_prompt`：το prompt για τη δημιουργία στίχων, ισχύει μόνο όταν το `custom` είναι `true` και δεν έχει μεταβιβαστεί το `lyric`.
- `callback_url`：το URL που απαιτείται για την επιστροφή αποτελεσμάτων μέσω callback.
- `async`：προαιρετικό, όταν οριστεί σε `true`, η διεπαφή επιστρέφει αμέσως το `task_id`, χωρίς να απαιτείται η παροχή `callback_url`, και στη συνέχεια τα αποτελέσματα λαμβάνονται με polling μέσω της αντίστοιχης διεπαφής ερωτήματος εργασιών.

    - error：αποτυχία
  - id：ID τραγουδιού
  - title：ο τίτλος του τραγουδιού
  - image_url：η εικόνα εξωφύλλου του τραγουδιού

  - audio_url：η διεύθυνση τελικού ήχου του τραγουδιού. Η πλατφόρμα θα επιστρέψει κατά προτεραιότητα τη διεύθυνση Ace Data Cloud CDN· εάν η μόνιμη αποθήκευση αποτύχει, ενδέχεται να επιστραφεί η αρχική διεύθυνση πολυμέσων, παρακαλούμε κατεβάστε την έγκαιρα.

## Λειτουργία συνέχισης δημιουργίας
Εάν θέλετε να συνεχίσετε να δημιουργείτε ένα ήδη παραγόμενο τραγούδι Suno, μπορείτε να ορίσετε την παράμετρο `action` σε `extend` και να εισαγάγετε το ID του τραγουδιού που χρειάζεται να συνεχίσει να δημιουργείται. Η λήψη του ID τραγουδιού γίνεται σύμφωνα με τη βασική χρήση. Από τα παραπάνω φαίνεται ότι αυτή τη στιγμή μπορείτε να δείτε ότι το ID του τραγουδιού είναι:

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> Σημείωση: το `id` στους στίχους εδώ είναι το ID του τραγουδιού μετά τη δημιουργία. Εάν δεν γνωρίζετε πώς να δημιουργήσετε ένα τραγούδι, μπορείτε να ανατρέξετε στη βασική χρήση παραπάνω για να δημιουργήσετε ένα τραγούδι.

Εάν θέλετε να συνεχίσετε να δημιουργείτε ένα τραγούδι που έχετε ανεβάσει εσείς, μπορείτε να ορίσετε την παράμετρο `action` σε `upload_extend` και να εισαγάγετε το ID του προσαρμοσμένου ανεβασμένου τραγουδιού που χρειάζεται να συνεχίσει να δημιουργείται. Η λήψη του ID τραγουδιού γίνεται με τη χρήση του [Suno Upload Generation API](https://platform.acedata.cloud/documents/suno-upload), όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" className="m-auto" /></p>

Στη συνέχεια, πρέπει να συμπληρώσετε τους στίχους του τμήματος συνέχειας και μπορείτε να καθορίσετε το στυλ:

- lyric：χρησιμοποιείται μόνο για την καθοδήγηση των στίχων του νέου παραγόμενου τμήματος μετά το `continue_at` και δεν θα αντικαταστήσει τους στίχους πριν από αυτό το χρονικό σημείο στο αρχικό ήχο.
- custom：συμπληρώστε `true`, που αντιπροσωπεύει προσαρμοσμένη δημιουργία. Η προεπιλεγμένη τιμή αυτής της παραμέτρου είναι false, που αντιπροσωπεύει δημιουργία με χρήση του `prompt`.
- style：το στυλ τραγουδιού του τμήματος συνέχειας, προαιρετικό.
- continue_at：το όριο συνέχειας, σε δευτερόλεπτα. Για παράδειγμα, το 213.5 υποδεικνύει ότι το επόμενο τμήμα θα δημιουργηθεί από το σημείο των 3 λεπτών και 33.5 δευτερολέπτων.

Το `continue_at` των `extend` και `upload_extend` πρέπει να είναι μεγαλύτερο από 0 και υποστηρίζει δεκαδικά δευτερόλεπτα, για παράδειγμα `30.792`· δεν γίνεται στρογγυλοποίηση κατά την υποβολή.

> Το `extend` χρησιμοποιείται για να συνεχίσετε τη δημιουργία μετά από ένα υπάρχον τραγούδι και δεν χρησιμοποιείται για την αλλαγή των στίχων ολόκληρου του τραγουδιού. Εάν επιθυμείτε να χρησιμοποιήσετε νέους στίχους για ολόκληρο το τραγούδι από την αρχή, χρησιμοποιήστε το `generate` για να το δημιουργήσετε ξανά· εάν επιθυμείτε να επανερμηνεύσετε ένα υπάρχον τραγούδι ως αναφορά, μπορείτε να χρησιμοποιήσετε το `cover`. Όταν εισάγετε ένα σύνολο νέων στίχων για ολόκληρο το τραγούδι, οι αρχικοί στίχοι πριν από το `continue_at` δεν θα αντικατασταθούν.

Το παράδειγμα συμπλήρωσης είναι το εξής:

<p><img src="https://cdn.acedata.cloud/zp9s42.png" width="500" className="m-auto" /></p>

Αφού ολοκληρωθεί η συμπλήρωση, ο κώδικας δημιουργείται αυτόματα ως εξής:

<p><img src="https://cdn.acedata.cloud/wwpw78.png" width="500" className="m-auto" /></p>

## Λήψη πλήρους τραγουδιού
Το αποτέλεσμα του `extend` του τρέχοντος μοντέλου συνήθως περιλαμβάνει ήδη τον αρχικό ήχο πριν από το `continue_at` και το νέο περιεχόμενο μετά το όριο. Αρχικά, καθορίστε εάν πρόκειται ήδη για ένα πλήρες τραγούδι με βάση την πραγματική διάρκεια και το περιεχόμενο του ήχου που επιστρέφεται. Εάν επιστρέφεται ένα ανεξάρτητο τμήμα συνέχισης ή εάν πρέπει να συγχωνεύσετε ρητά το ιστορικό πολλαπλών συνεχίσεων σε ένα τραγούδι, χρησιμοποιήστε τη λειτουργία συνένωσης:

- action：η τιμή είναι `concat`.
- audio_id：το ID του τελευταίου τμήματος συνέχισης.

Για παράδειγμα, εάν το ID του τραγουδιού μετά την επέκταση είναι: 0a1e1b10-c36a-41c9-9bfb-b26d9d25db98, τότε μπορείτε να ορίσετε τις παραμέτρους ως εξής:

```json
{
  "action": "concat",
  "audio_id": "0a1e1b10-c36a-41c9-9bfb-b26d9d25db98"
}
```

Οι άλλες παράμετροι παραμένουν αμετάβλητες και αυτό που επιστρέφεται είναι ένα πλήρες τραγούδι, δηλαδή το αποτέλεσμα της συνένωσης όλων των τμημάτων του τραγουδιού, αλλά το αποτέλεσμα περιέχει μόνο ένα τραγούδι, όπως στο ακόλουθο παράδειγμα:

## Μουσική διασκευή

Όταν συνεχίζετε να δημιουργείτε ένα τραγούδι με βάση ένα υπάρχον τραγούδι, το ύφος του τραγουδιού που επιστρέφεται ενδέχεται να μην είναι ιδιαίτερα κατάλληλο. Εάν θέλετε να δημιουργήσετε μια διασκευή του τραγουδιού που είχε δημιουργηθεί προηγουμένως (υποστηρίζεται επίσης μουσική που έχει μεταφορτωθεί προσαρμοσμένα), πρέπει να χρησιμοποιήσετε τη μέθοδο μουσικής διασκευής και μπορείτε να ορίσετε το ακόλουθο περιεχόμενο:

- action：η τιμή είναι `cover`, ενώ όταν πραγματοποιείτε λειτουργία διασκευής σε μουσική που έχει μεταφορτωθεί προσαρμοσμένα, πρέπει να ορίσετε την τιμή ως: `upload_cover`.
- audio_id：το ID του τραγουδιού που δημιουργήθηκε προηγουμένως.

Εάν χρειάζεται να χρησιμοποιήσετε καθορισμένη φωνή για διασκευή, μπορείτε ταυτόχρονα να περάσετε το `persona_id`. Για ιδιωτικές φωνές που δημιουργούνται μέσω του `/suno/voices`, πρέπει πρώτα να μεταφορτώσετε το αρχικό τραγούδι στο `/suno/upload` με το ίδιο `persona_id` και, στη συνέχεια, να χρησιμοποιήσετε το επιστρεφόμενο `audio_id` για `upload_cover`. Όλα τα βήματα πρέπει να χρησιμοποιούν το ίδιο κανάλι υπηρεσίας. Δεν χρειάζεται να ορίσετε επιπλέον το `vocal_gender`· η προτίμηση φύλου δεν μπορεί να αντικαταστήσει το ID φωνής.

## Αντικατάσταση τμήματος

Όταν, μετά τη δημιουργία ενός τραγουδιού, απαιτείται δευτερογενής δημιουργία με ξεχωριστή λειτουργία αντικατάστασης τμήματος τραγουδιού, μπορείτε να πραγματοποιήσετε λειτουργία αντικατάστασης σε ένα συγκεκριμένο τμήμα του τραγουδιού.
> ⚠️ **Σημείωση**: Το `replace_section_result_mode` έχει ως προεπιλογή το `full_song`: το σύστημα θα ενώσει αντίστοιχα 2 νεοδημιουργημένους υποψηφίους και θα επιστρέψει 2 πλήρη τραγούδια. Αν χρειάζεστε μόνο υποψηφίους τμημάτων αντικατάστασης που δεν έχουν ακόμη ενωθεί, ορίστε ρητά το `candidates` και, στη συνέχεια, επιλέξτε έναν υποψήφιο για να καλέσετε τη [συγχώνευση μουσικής](#音乐拼接).

Οι παράμετροι περιγράφονται ως εξής:

- action: Η τιμή είναι `replace_section`.
- audio_id: Το ID του αρχικού τραγουδιού (του τραγουδιού πηγής που αντικαθίσταται).
- model: Μοντέλο δημιουργίας τραγουδιού.
- lyric: Οι πλήρεις στίχοι μετά την αντικατάσταση (συμπεριλαμβανομένου του αντικατεστημένου τμήματος και του περιβάλλοντός του, σε συμφωνία με το περιεχόμενο στο `prompt`).
- prompt: Οι νέοι στίχοι για το τμήμα που πρέπει να αντικατασταθεί.
- style: Το ύφος του τραγουδιού, προαιρετικό.
- negative_tags: Ύφη ή είδη που θέλετε να εξαιρέσετε, προαιρετικό.
- replace_section_start: Ο χρόνος έναρξης του αντικατεστημένου τμήματος στο αρχικό τραγούδι (δευτερόλεπτα), υποχρεωτικό και δεν πρέπει να είναι μικρότερο από 0.
- replace_section_end: Ο χρόνος λήξης του αντικατεστημένου τμήματος στο αρχικό τραγούδι (δευτερόλεπτα), υποχρεωτικό και πρέπει να είναι μεγαλύτερος από τον χρόνο έναρξης.
- replace_section_result_mode: Λειτουργία επιστροφής, με προεπιλογή το `full_song`. Το `full_song` ενώνει αντίστοιχα 2 υποψηφίους και επιστρέφει 2 πλήρη τραγούδια· το `candidates` επιστρέφει 2 υποψήφια τμήματα που δεν έχουν ακόμη ενωθεί.

## Έλεγχος διάρκειας τραγουδιού

Από προεπιλογή, η διάρκεια του παραγόμενου τραγουδιού καθορίζεται από το ίδιο το μοντέλο, συνήθως μεταξύ 30 δευτερολέπτων και 4 λεπτών. Εάν χρειάζεστε μεγαλύτερο ή μικρότερο τελικό αποτέλεσμα, μπορείτε να καθορίσετε την επιθυμητή διάρκεια μέσω της παραμέτρου `duration`, με μονάδα τα δευτερόλεπτα και τιμή ακέραιο μεταξύ 10 και 360.

Αυτή η παράμετρος χρησιμοποιείται για τη δημιουργία τραγουδιών σε προσαρμοσμένη λειτουργία (όταν το `custom` είναι `true`). Πρέπει να διευκρινιστεί ιδιαίτερα ότι το `duration` είναι μια **ενδεικτική υπόδειξη και όχι ένας αυστηρός περιορισμός**: το μοντέλο θα αναφέρεται σε αυτή την τιμή κατά τη δημιουργία, αλλά δεν εγγυάται ότι θα την επιτύχει· στις δοκιμές, η πραγματική διάρκεια είναι συνήθως εμφανώς μικρότερη από την επιθυμητή τιμή, ενώ οι διάρκειες των δύο τραγουδιών που επιστρέφονται από το ίδιο αίτημα μπορεί επίσης να διαφέρουν κατά πολλές φορές. Ακόμη και για εντελώς ίδια αιτήματα, οι διάρκειες που λαμβάνονται από πολλαπλές υποβολές μπορεί να έχουν μεγάλες διαφορές. Επομένως, μην το χρησιμοποιείτε ως ακριβή έλεγχο διάρκειας· εάν η επιχειρησιακή χρήση απαιτεί σταθερή διάρκεια, περικόψτε ή επαναλάβετε την προσπάθεια μόνοι σας αφού λάβετε το τελικό αποτέλεσμα.

Ο αντίστοιχος κώδικας Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "Under the City Lights",
    "style": "lo-fi piano",
    "lyric": "[Verse]\nSunrise creepin\nGold on the floor\n[Chorus]\nUnder the city lights\n",
    "duration": 330
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Πρέπει να σημειωθεί ότι το `duration` στο αίτημα είναι η **επιθυμητή διάρκεια**, ενώ το πεδίο `duration` κάθε τραγουδιού στο `data` της απόκρισης είναι η **πραγματική διάρκεια** αυτού του τραγουδιού. Τα δύο έχουν το ίδιο όνομα αλλά διαφορετική σημασία, και η πραγματική διάρκεια δεν εγγυάται ότι είναι ίση με την επιθυμητή τιμή. Το μήκος των στίχων είναι ένας από τους κύριους παράγοντες που επηρεάζουν τη διάρκεια του τελικού αποτελέσματος· εάν χρειάζεστε μεγαλύτερο τελικό αποτέλεσμα, συνιστάται να παρέχετε ταυτόχρονα πιο ολοκληρωμένους στίχους.

Η διεπαφή θα ελέγξει ότι το `duration` πρέπει να είναι ακέραιος από 10 έως 360· εξακολουθεί να είναι μόνο στόχος δημιουργίας και όχι εγγύηση μήκους του τελικού αποτελέσματος.

## Λειτουργία δημιουργίας έμπνευσης Inspo

Η λειτουργία δημιουργίας έμπνευσης Inspo μπορεί να δημιουργήσει νέα μουσική βάσει 1 έως 4 πλήρων ηχητικών αναφορών και υποστηρίζει μεταφορά και απόθεση ή μεταφόρτωση ήχου ως πηγή έμπνευσης. Το API χρησιμοποιεί την υπάρχουσα ενέργεια `inspo`: ο πελάτης παρέχει δημόσια προσβάσιμα URL ήχου και η υπηρεσία ολοκληρώνει αυτόματα την προετοιμασία των ηχητικών αναφορών και τη δημιουργία, χωρίς να χρειάζεται ο πελάτης να διαβάσει ξεχωριστά τους στίχους, το ύφος ή τη διάρκεια και έπειτα να συνθέσει το αίτημα. Διαφέρει από τη δειγματοληψία τμήματος που αναφέρθηκε παραπάνω, καθώς και από το Cover που αναπαράγει το ύφος του πρωτότυπου τραγουδιού. Κατά τη χρήση, πρέπει να συμπληρωθούν οι παρακάτω παράμετροι:

- action：το περιεχόμενο είναι `inspo`。
- audio_urls：λίστα URL των ηχητικών αναφορών, πρέπει να παρέχονται 1 έως 4 δημόσια προσβάσιμες διευθύνσεις ήχου。
- model：το μοντέλο που χρησιμοποιείται, συνιστάται το `chirp-v6`。
- prompt：στίχοι ή προτροπή δημιουργίας (προαιρετικό)。
- instrumental：όταν οριστεί σε `true`, η δημιουργία ζητείται ως αμιγώς οργανική μουσική, χωρίς χρήση στίχων。
- persona_id：χρήση της καθορισμένης φωνής σε κανάλια υπηρεσίας που υποστηρίζουν αυτόν τον συνδυασμό· οι ηχητικές αναφορές θα συνδεθούν, κατά το στάδιο προετοιμασίας, με το περιβάλλον πόρων που απαιτείται για αυτήν τη φωνή。
- lyric_prompt：όταν `custom=true` και δεν παρέχεται `lyric`, χρησιμοποιείται για την αυτόματη δημιουργία στίχων。

> Σημείωση：οι ηχητικές αναφορές πρέπει να είναι δημόσια προσβάσιμα αρχεία ήχου. Εάν μια ηχητική αναφορά ταιριάζει ακριβώς με μια γνωστή ηχογράφηση στη μουσική βιβλιοθήκη της πλατφόρμας, το Suno ενδέχεται να απορρίψει τη δημιουργία λόγω ελέγχου πνευματικών δικαιωμάτων· συνιστάται να χρησιμοποιείτε δικό σας ήχο ή ήχο που δημιουργήθηκε από το Suno ως πηγή έμπνευσης。

## Ασύγχρονη επανάκληση

Επειδή ο χρόνος που χρειάζεται το Suno για να δημιουργήσει μουσική είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, εάν το API δεν αποκρίνεται για μεγάλο χρονικό διάστημα, το αίτημα HTTP θα διατηρεί συνεχώς τη σύνδεση, οδηγώντας σε επιπλέον κατανάλωση πόρων του συστήματος, επομένως αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονες επανακλήσεις.

Η συνολική διαδικασία είναι: όταν ο πελάτης ξεκινά ένα αίτημα, καθορίζει επιπλέον ένα πεδίο `callback_url`, αφού ο πελάτης ξεκινήσει το αίτημα API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα, το οποίο περιλαμβάνει πληροφορίες για ένα πεδίο `task_id`, που αντιπροσωπεύει το τρέχον αναγνωριστικό εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα της δημιουργίας μουσικής θα σταλεί με τη μορφή POST JSON στο `callback_url` που καθορίζεται από τον πελάτη, στο οποίο περιλαμβάνεται επίσης το πεδίο `task_id`, ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Παρακάτω θα κατανοήσουμε μέσω ενός παραδείγματος πώς ακριβώς να το χειριστούμε.

Εδώ, για ευκολία επίδειξης, χρησιμοποιείται ένας δημόσιος ιστότοπος παραδείγματος Webhook https://webhook.site/· ανοίγοντας αυτόν τον ιστότοπο μπορείτε να λάβετε ένα URL Webhook, όπως φαίνεται στην εικόνα:
