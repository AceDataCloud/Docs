Καθώς η εφαρμογή της AI διευρύνεται, διάφορα προγράμματα AI έχουν σταδιακά διαδοθεί. Η AI έχει σταδιακά διεισδύσει σε κάθε πτυχή της εργασίας και της ζωής των ανθρώπων. Και οι κλάδοι που αφορούν την AI γίνονται όλο και περισσότεροι, από την αρχική συγγραφή, έως την ιατρική και την εκπαίδευση, και τώρα τη μουσική.

Το Suno είναι μια επαγγελματική πλατφόρμα υψηλής ποιότητας για δημιουργία τραγουδιών και μουσικής με AI. Οι χρήστες χρειάζεται μόνο να εισαγάγουν απλές προτροπές κειμένου και μπορούν να δημιουργήσουν τραγούδια με φωνητικά βάσει του είδους, του στυλ και των στίχων. Αυτή η γεννήτρια μουσικής AI αναπτύχθηκε από μέλη ομάδων από γνωστές εταιρείες τεχνολογίας όπως οι Meta, TikTok και Kensho, με στόχο να μην απαιτούνται μουσικά όργανα ή εργαλεία, ώστε όλοι να μπορούν να δημιουργούν υπέροχη μουσική.

Ακολουθεί η πρόοδος των ενημερώσεων του μοντέλου:

| Έκδοση      | model           | Ημερομηνία κυκλοφορίας | Όριο lyric | Όριο style | Μέγιστη διάρκεια τραγουδιού |
| ------- | --------------- | ---------- | -------- | -------- | ------ |
| v6      | chirp-v6        | 2026.09.09 | —        | —        | —      |
| v6 Wild | chirp-v6-wild   | 2026.09.09 | —        | —        | —      |
| v6 Mini | chirp-v6-mini   | 2026.09.09 | —        | —        | —      |
| v5.5    | chirp-v5-5      | 2026.03.27 | 5000     | 1000     | 8 λεπτά   |
| v5      | chirp-v5        | 2025.09.23 | 5000     | 1000     | 8 λεπτά   |
| v4.5+   | chirp-v4-5-plus | 2025.07.17 | 5000     | 1000     | 8 λεπτά   |

| v3.5    | chirp-v3-5      | ---        | 3000     | 200      | 120 δευτερόλεπτα  |

> Τα όρια `lyric` και `style` στον παραπάνω πίνακα είναι τα ανώτατα όρια στη λειτουργία προσαρμογής (όταν το `custom` είναι `true`). Στη μη προσαρμοσμένη λειτουργία έμπνευσης (όταν το `custom` είναι `false`) συμπληρώνεται μόνο το `prompt`, με μέγιστο μήκος 500 χαρακτήρες (ίδιο για όλα τα μοντέλα).

Το Suno υποστηρίζει πλέον τα `chirp-v6`, `chirp-v6-wild` και `chirp-v6-mini`. Συνιστάται η χρήση του `chirp-v6`· τα ονόματα των παλαιότερων μοντέλων συνεχίζουν να είναι συμβατά.

Ωστόσο, το Suno επίσημα δεν παρέχει API. Το AceDataCloud παρέχει ένα σύνολο API για το Suno, προσομοιώνοντας την ενσωμάτωση με το επίσημο Suno, ώστε να μπορείτε να δημιουργείτε εύκολα και γρήγορα τη μουσική που επιθυμείτε.

## Αίτηση και χρήση

Για να χρησιμοποιήσετε το Suno Audios Generation API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Με την πρώτη αίτηση παρέχεται δωρεάν πίστωση για δωρεάν δοκιμή· όταν η πίστωση δεν επαρκεί, μπορείτε να προσθέσετε κοινό υπόλοιπο μέσω της [κονσόλας](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## Βασική χρήση

Όποιο τραγούδι κι αν θέλετε, μπορείτε να εισαγάγετε ελεύθερα ένα κείμενο. Για παράδειγμα, αν θέλω να δημιουργήσω ένα τραγούδι για τα Χριστούγεννα, μπορώ να εισαγάγω `a song for Christmas`, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ έχουμε ορίσει τα Request Headers, συμπεριλαμβανομένων των:

- `accept`: τη μορφή στην οποία θέλετε να λάβετε το αποτέλεσμα απόκρισης, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, ορίστηκε το Request Body, που περιλαμβάνει:
- `action`: τύπος εργασίας ήχου, η προεπιλογή είναι `generate`. Υποστηρίζει λειτουργίες όπως δημιουργία, συνέχιση, διασκευή, συγκόλληση, διαχωρισμό κομματιών, προσθήκη ηχητικού κομματιού, εξαγωγή καθορισμένου ηχητικού κομματιού, δημιουργία ηχητικών εφέ και προσαρμογή ταχύτητας κ.λπ., οι οποίες καλούνται ενιαία μέσω `POST /suno/audios`.
- `prompt`: προτροπή λειτουργίας έμπνευσης του Suno (ισχύει όταν το `custom` είναι `false`), έως 500 χαρακτήρες.
- `model`: το μοντέλο για αυτήν την εργασία δημιουργίας μουσικής. Η σειρά v6 περιλαμβάνει τα `chirp-v6`, `chirp-v6-wild` και `chirp-v6-mini`· τα παλαιά ονόματα μοντέλων συνεχίζουν να υποστηρίζονται.
- `max_mode`: λειτουργία ενισχυμένης δημιουργίας. Το `generate` ενεργοποιείται μόνο όταν και τα `custom` και `max_mode` είναι `true`, με κόστος 1.12 Credits· το `add_stem` μπορεί να ενεργοποιηθεί απευθείας, με κόστος 1.344 Credits. Όταν είναι απενεργοποιημένο ή παραλείπεται, το κόστος είναι αντίστοιχα 0.56 και 0.672 Credits.
- `variety`: ένταση ποικιλομορφίας των αποτελεσμάτων δημιουργίας, με επιλογές `off`, `normal`, `high`, `extra`, `max`. Χρησιμοποιείται μόνο για `generate` και `add_stem`· η αποστολή του σε άλλα action θα επιστρέψει 400.
- `lyric`: περιεχόμενο στίχων για την προσαρμοσμένη λειτουργία του Suno. Τα `chirp-v3-5` και `chirp-v4` έχουν μέγιστο όριο 3000 χαρακτήρων· τα `chirp-v4-5` και νεότερα (συμπεριλαμβανομένων των `chirp-v5`, `chirp-v5-5`) έχουν μέγιστο όριο 5000 χαρακτήρων.
- `custom`: αν θα χρησιμοποιηθεί προσαρμοσμένη λειτουργία, η προεπιλογή είναι: `false`.
- `instrumental`: η επιλογή ορχηστρικής μουσικής στη λειτουργία έμπνευσης του Suno.
- `title`: τίτλος μουσικής για την προσαρμοσμένη λειτουργία του Suno. Τα `chirp-v3-5`, `chirp-v4` έχουν μέγιστο όριο 80 χαρακτήρων· τα `chirp-v4-5` και νεότερα έχουν μέγιστο όριο 100 χαρακτήρων.
- `style`: μουσικό ύφος για την προσαρμοσμένη λειτουργία του Suno. Τα `chirp-v3-5` και `chirp-v4` έχουν μέγιστο όριο 200 χαρακτήρων· τα `chirp-v4-5` και νεότερα (συμπεριλαμβανομένων των `chirp-v5`, `chirp-v5-5`) έχουν μέγιστο όριο 1000 χαρακτήρων.
- `negative_tags`: μουσικά στυλ ή είδη που επιθυμείτε να εξαιρεθούν από τα αποτελέσματα δημιουργίας στην προσαρμοσμένη λειτουργία (όταν το `custom` είναι `true`).
- `audio_weight`: βάρος επιρροής των χαρακτηριστικών ήχου ή φωνής, εύρος 0-1, και το `0` είναι επίσης έγκυρη τιμή. Μπορεί να χρησιμοποιηθεί για λειτουργίες όπως δημιουργία, συνέχιση, διασκευή, προσθήκη ηχητικού κομματιού και συνέπεια φωνής· όταν δεν υπάρχει ήχος αναφοράς ή χαρακτηριστικά φωνής, το μοντέλο ενδέχεται να αποδυναμώσει ή να αγνοήσει αυτήν την τιμή.
- `audio_id`: το ID της μουσικής αναφοράς.
- `overpainting_start`/`overpainting_end`: χρόνοι έναρξης και λήξης για την προσθήκη φωνητικών σε υπάρχουσα ορχηστρική μουσική, σε δευτερόλεπτα.
- `underpainting_start`/`underpainting_end`: χρόνοι έναρξης και λήξης για την προσθήκη συνοδείας σε a cappella, σε δευτερόλεπτα.
- `persona_id`: το ID τραγουδιού του καλλιτέχνη.
- `continue_at`: όριο συνέχισης, σε δευτερόλεπτα. Για παράδειγμα, το 213.5 υποδεικνύει τη δημιουργία του επόμενου τμήματος από το 3ο λεπτό και 33.5ο δευτερόλεπτο. Τα `lyric` και `style` καθοδηγούν μόνο το νέο περιεχόμενο μετά το όριο και δεν αντικαθιστούν τους στίχους ή το τραγούδι πριν από το όριο στον αρχικό ήχο.
- `style_influence`: επιρροή ύφους στην προσαρμοσμένη λειτουργία, εύρος 0-1· όσο μεγαλύτερη είναι, τόσο περισσότερο συνήθως αντιστοιχεί στο επιλεγμένο ύφος· το `0` μεταβιβάζεται ως έγκυρη τιμή.
- `replace_section_end`: ο τελικός χρόνος του τμήματος αντικατάστασης.
- `replace_section_start`: ο χρόνος έναρξης του τμήματος αντικατάστασης.
- `vocal_gender`: ελέγχει την προτίμηση για γυναικεία ή ανδρική φωνή, γυναικεία φωνή `f`, ανδρική φωνή `m`, ισχύει για μοντέλα 4.5 και νεότερα· είναι στοιχείο προτίμησης και δεν εγγυάται αυστηρή τήρηση.
- `weirdness`: βαθμός παραξενιάς στην προσαρμοσμένη λειτουργία, εύρος 0-1· όσο μεγαλύτερος είναι, τόσο πιο δημιουργικό και πειραματικό είναι συνήθως το αποτέλεσμα· το `0` μεταβιβάζεται ως έγκυρη τιμή.
- `duration`: επιθυμητή διάρκεια τραγουδιού, σε δευτερόλεπτα, πρέπει να είναι ακέραιος, με εύρος τιμών από 10 έως 360. Αυτή η παράμετρος χρησιμοποιείται για δημιουργία τραγουδιών στην προσαρμοσμένη λειτουργία (όταν το `custom` είναι `true`). Είναι μια ενδεικτική προτροπή και όχι αυστηρός περιορισμός: το μοντέλο θα την λάβει υπόψη, αλλά δεν εγγυάται ότι θα την πετύχει· η πραγματική διάρκεια του τελικού αποτελέσματος καθορίζεται από το πεδίο `duration` στην απόκριση και συνήθως είναι μικρότερη από την επιθυμητή τιμή.

### Πεδίο εφαρμογής προηγμένων παραμέτρων

| Παράμετρος                | Τιμές                                          | Υποστηριζόμενα action                              | Περιγραφή                              |
| ----------------- | ------------------------------------------- | --------------------------------------- | ------------------------------- |
| `weirdness`       | 0-1                                         | Προαιρετικό                                      | Ρυθμίζει την πειραματικότητα, το `0` είναι έγκυρη τιμή· το αποτέλεσμα εξαρτάται από τη λειτουργία, τη λειτουργία και το μοντέλο    |
| `style_influence` | 0-1                                         | Προαιρετικό                                      | Ρυθμίζει την τάση τήρησης του ύφους, το `0` είναι έγκυρη τιμή· το αποτέλεσμα εξαρτάται από τη λειτουργία, τη λειτουργία και το μοντέλο |
| `audio_weight`    | 0-1                                         | Προαιρετικό                                      | Ρυθμίζει την επιρροή των χαρακτηριστικών ήχου ή φωνής· χωρίς πληροφορίες αναφοράς μπορεί να αγνοηθεί από το μοντέλο      |
| `variety`         | `off` / `normal` / `high` / `extra` / `max` | `generate`, `add_stem`                   | Ρυθμίζει την ποικιλομορφία ύφους μεταξύ των αποτελεσμάτων                     |
| `max_mode`        | boolean                                     | `generate` (απαιτεί `custom=true`), `add_stem` | Ενισχύει τη συνέπεια και χρεώνεται σύμφωνα με την ενισχυμένη λειτουργία                   |
| `vocal_gender`    | `f` / `m`                                   | Λειτουργίες δημιουργίας που υποστηρίζουν έλεγχο φωνητικών                             | Στοιχείο προτίμησης, δεν εγγυάται αυστηρή τήρηση                     |
| `duration`        | Ακέραιος 10-360                                   | Προαιρετικό                                      | Επιθυμητή διάρκεια· η συγκεκριμένη λειτουργία, η λειτουργία ή το μοντέλο ενδέχεται να το αγνοήσουν             |

Η πλατφόρμα θα ελέγχει τους τύπους παραμέτρων και τα εύρη τιμών, αλλά δεν θα απορρίπτει αυτά τα προαιρετικά στοιχεία προσαρμογής μόνο λόγω διαφορετικού action· το συγκεκριμένο αποτέλεσμα καθορίζεται από τη λειτουργία, τη λειτουργία και το μοντέλο.

- `lyric_prompt`: prompt για τη δημιουργία στίχων, ισχύει μόνο όταν το `custom` είναι `true` και δεν έχει μεταβιβαστεί το `lyric`.
- `callback_url`: URL στο οποίο απαιτείται επανάκληση των αποτελεσμάτων.
- `async`: προαιρετικό, όταν οριστεί σε `true`, η διεπαφή επιστρέφει αμέσως το `task_id`, χωρίς να απαιτείται παροχή `callback_url`, και στη συνέχεια τα αποτελέσματα λαμβάνονται μέσω polling από την αντίστοιχη διεπαφή αναζήτησης εργασιών.

## Προσαρμοσμένη δημιουργία

Αν θέλετε να δημιουργήσετε προσαρμοσμένους στίχους, μπορείτε να εισαγάγετε στίχους:

Αυτή τη στιγμή το πεδίο `lyric` μπορεί να λάβει περιεχόμενο όπως το ακόλουθο:

```
[Verse]\nSnowflakes falling all around\nGlistening white\nCovering the ground\nChildren laughing\nFull of delight\nIn this winter wonderland tonight\nSanta's sleigh\nUp in the sky\nRudolph's nose shining bright\nOh my\nHear the jingle bells\nRinging so clear\nBringing joy and holiday cheer\n[Verse 2]\nRoasting chestnuts by the fire's glow\nChristmas lights\nThey twinkle and show\nFamilies gathering with love and cheer\nSpreading warmth to everyone near
```

> Σημείωση, στους στίχους εδώ το `\n` είναι χαρακτήρας αλλαγής γραμμής· αν δεν γνωρίζετε πώς να δημιουργήσετε στίχους, μπορείτε να χρησιμοποιήσετε το API δημιουργίας στίχων που παρέχεται από το AceDataCloud για να δημιουργήσετε στίχους μέσω prompt, το API είναι το [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

## Λειτουργία συνέχισης δημιουργίας

Αν θέλετε να συνεχίσετε τη δημιουργία ενός ήδη δημιουργημένου τραγουδιού Suno, μπορείτε να ορίσετε την παράμετρο `action` ως `extend` και να εισαγάγετε το ID του τραγουδιού που χρειάζεται να συνεχίσει να δημιουργείται. Το ID του τραγουδιού λαμβάνεται μέσω της βασικής χρήσης· από τα παραπάνω γνωρίζουμε ότι αυτή τη στιγμή μπορείτε να δείτε πως το ID του τραγουδιού είναι:

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> Σημείωση: εδώ το `id` στους στίχους είναι το ID του τραγουδιού μετά τη δημιουργία. Αν δεν γνωρίζετε πώς να δημιουργήσετε ένα τραγούδι, μπορείτε να ανατρέξετε στη βασική χρήση παραπάνω για να δημιουργήσετε ένα τραγούδι.

Αν θέλετε να συνεχίσετε τη δημιουργία ενός τραγουδιού που ανεβάσατε εσείς, μπορείτε να ορίσετε την παράμετρο `action` ως `upload_extend` και να εισαγάγετε το ID του τραγουδιού που ανεβάσατε προσαρμοσμένα και χρειάζεται να συνεχίσει να δημιουργείται. Το ID του τραγουδιού λαμβάνεται χρησιμοποιώντας το [Suno Upload Generation API](https://platform.acedata.cloud/documents/suno-upload), όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" className="m-auto" /></p>

Στη συνέχεια πρέπει να συμπληρώσετε τους στίχους του τμήματος συνέχισης και μπορείτε να καθορίσετε το στυλ:

- lyric: Χρησιμοποιείται μόνο για να καθοδηγήσει τους στίχους του νέου δημιουργημένου τμήματος μετά το `continue_at` και δεν θα αντικαταστήσει τους στίχους πριν από αυτό το χρονικό σημείο στο αρχικό ήχο.
- custom: Συμπληρώστε `true`, που αντιπροσωπεύει την προσαρμοσμένη δημιουργία. Η προεπιλεγμένη τιμή αυτής της παραμέτρου είναι false, που αντιπροσωπεύει τη δημιουργία με χρήση `prompt`.
- style: Το μουσικό στυλ του τμήματος συνέχισης, προαιρετικό.
- continue_at: Το όριο συνέχισης, σε δευτερόλεπτα. Για παράδειγμα, το 213.5 υποδηλώνει ότι η δημιουργία του επόμενου τμήματος ξεκινά από το 3ο λεπτό και 33.5ο δευτερόλεπτο.

> Το `extend` χρησιμοποιείται για τη συνέχιση της δημιουργίας μετά από ένα υπάρχον τραγούδι, όχι για την αλλαγή των στίχων ολόκληρου του τραγουδιού. Αν θέλετε ολόκληρο το τραγούδι να χρησιμοποιεί νέους στίχους από την αρχή, χρησιμοποιήστε το `generate` για να το δημιουργήσετε ξανά· αν θέλετε να επανερμηνεύσετε ένα τραγούδι με αναφορά σε ένα υπάρχον τραγούδι, μπορείτε να χρησιμοποιήσετε το `cover`. Όταν μεταβιβάζετε νέους στίχους για ένα ολόκληρο τραγούδι, οι αρχικοί στίχοι πριν από το `continue_at` δεν θα αντικατασταθούν.

Το παράδειγμα συμπλήρωσης είναι ως εξής:

<p><img src="https://cdn.acedata.cloud/zp9s42.png" width="500" className="m-auto" /></p>

Αφού συμπληρωθούν, δημιουργείται αυτόματα ο ακόλουθος κώδικας:
<p><img src="https://cdn.acedata.cloud/wwpw78.png" width="500" className="m-auto" /></p>

Παρακάτω διατηρείται ένα στιγμιότυπο πραγματικής ιστορικής κλήσης, όπου το `continue_at` είναι 2 δευτερόλεπτα, επομένως μόνο τα πρώτα 2 δευτερόλεπτα ανήκουν στο αρχικό περιεχόμενο πριν από το όριο συνέχισης. Όταν γίνεται συνέχιση κοντά στο πραγματικό τέλος του τραγουδιού, αυτή η τιμή θα πρέπει να οριστεί στα δευτερόλεπτα όπου αναμένεται να ξεκινήσει η συνέχιση, και στο `lyric` θα πρέπει να παρέχεται μόνο το νέο τμήμα που θα τραγουδηθεί μετά το όριο.

## Διασκευή μουσικής

Όταν συνεχίζεται η δημιουργία ενός τραγουδιού με βάση το αρχικό τραγούδι, το ύφος του τραγουδιού που επιστρέφεται ενδέχεται να μην είναι πολύ κατάλληλο. Εάν θέλετε να δημιουργήσετε διασκευή του αρχικά δημιουργημένου τραγουδιού (υποστηρίζεται επίσης και μουσική που μεταφορτώθηκε προσαρμοσμένα), πρέπει να χρησιμοποιήσετε τη μέθοδο διασκευής μουσικής, όπου μπορείτε να καθορίσετε το ακόλουθο περιεχόμενο:

- action：Το περιεχόμενο είναι `cover`· όταν εκτελείται διασκευή σε προσαρμοσμένα μεταφορτωμένη μουσική, το περιεχόμενο πρέπει να καθοριστεί ως：`upload_cover`。
- audio_id：Το ID του τραγουδιού που δημιουργήθηκε προηγουμένως.

Για παράδειγμα, εάν το ID του τραγουδιού που δημιουργήθηκε αρχικά είναι：0a1e1b10-c36a-41c9-9bfb-b26d9d25db98, τότε μπορείτε να ορίσετε τις παραμέτρους ως εξής：

```json
{
  "action": "cover",
  "audio_id": "0a1e1b10-c36a-41c9-9bfb-b26d9d25db98",
  "prompt": "A song for Christmas",
  "model": "chirp-v4-5"
}
```

## Αντικατάσταση τμήματος

Όταν, μετά τη δημιουργία ενός τραγουδιού, απαιτείται δευτερογενής δημιουργία με ξεχωριστή λειτουργία αντικατάστασης τμημάτων του τραγουδιού, μπορείτε να αντικαταστήσετε ένα συγκεκριμένο τμήμα του τραγουδιού.

> ⚠️ **Σημείωση**：Το `replace_section_result_mode` είναι από προεπιλογή `full_song`：Το σύστημα θα συνενώσει αντίστοιχα 2 νεοδημιουργημένους υποψηφίους και θα επιστρέψει 2 πλήρη τραγούδια. Εάν χρειάζεστε μόνο υποψήφια τμήματα αντικατάστασης που δεν έχουν ακόμη συνενωθεί, ορίστε ρητά το σε `candidates`, και στη συνέχεια επιλέξτε έναν υποψήφιο για να καλέσετε τη [Συνένωση μουσικής](#音乐拼接).

Οι παράμετροι περιγράφονται ως εξής：

- action：Το περιεχόμενο είναι `replace_section`。
- audio_id：Το ID του αρχικού τραγουδιού (του τραγουδιού πηγής που αντικαθίσταται)。
- model: Μοντέλο δημιουργίας τραγουδιού。
- lyric: Οι πλήρεις στίχοι μετά την αντικατάσταση (συμπεριλαμβανομένου του αντικατασταθέντος τμήματος και του περιβάλλοντός του, διατηρώντας συνέπεια με το περιεχόμενο στο `prompt`)。
- prompt：Οι νέοι στίχοι για το τμήμα που χρειάζεται να αντικατασταθεί。
- style：Το ύφος του τραγουδιού, προαιρετικό。
- replace_section_start：Ο χρόνος έναρξης του αντικατασταθέντος τμήματος στο αρχικό τραγούδι (δευτερόλεπτα)。
- replace_section_end：Ο χρόνος λήξης του αντικατασταθέντος τμήματος στο αρχικό τραγούδι (δευτερόλεπτα)。
- replace_section_result_mode：Λειτουργία επιστροφής, με προεπιλογή `full_song`。Το `full_song` συνενώνει αντίστοιχα 2 υποψηφίους και επιστρέφει 2 πλήρη τραγούδια· το `candidates` επιστρέφει 2 υποψήφια τμήματα που δεν έχουν ακόμη συνενωθεί。

## Έλεγχος διάρκειας τραγουδιού

Από προεπιλογή, η διάρκεια του παραγόμενου τραγουδιού αποφασίζεται από το ίδιο το μοντέλο, συνήθως μεταξύ 30 δευτερολέπτων και 4 λεπτών. Εάν απαιτείται μεγαλύτερο ή μικρότερο τελικό προϊόν, μπορεί να καθοριστεί η επιθυμητή διάρκεια μέσω της παραμέτρου `duration`, η μονάδα είναι δευτερόλεπτα και οι τιμές είναι ακέραιοι από 10 έως 360.

Αυτή η παράμετρος χρησιμοποιείται για δημιουργία τραγουδιών σε προσαρμοσμένη λειτουργία (`custom` είναι `true`). Χρειάζεται ιδιαίτερα να διευκρινιστεί ότι το `duration` είναι μια **ενδεικτική προτροπή και όχι ένας αυστηρός περιορισμός**: το μοντέλο θα αναφερθεί σε αυτήν την τιμή κατά τη δημιουργία, αλλά δεν εγγυάται ότι θα την επιτύχει· στις δοκιμές, η πραγματική διάρκεια είναι συνήθως εμφανώς μικρότερη από την επιθυμητή τιμή, και οι διάρκειες των δύο τραγουδιών που επιστρέφονται από το ίδιο αίτημα μπορεί επίσης να διαφέρουν κατά πολλαπλάσιο. Ακόμη και για εντελώς ίδια αιτήματα, οι διάρκειες που λαμβάνονται από πολλαπλές υποβολές μπορεί επίσης να έχουν μεγάλες διαφορές. Επομένως, μην το χρησιμοποιείτε ως ακριβή έλεγχο διάρκειας· εάν απαιτείται σταθερή διάρκεια για την επιχείρηση, περικόψτε ή επαναλάβετε την προσπάθεια μόνοι σας αφού λάβετε το τελικό προϊόν.

Ο αντίστοιχος κώδικας Python:
```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "Under the City Lights",
    "style": "lo-fi piano",
    "lyric": "[Verse]\nSunrise creepin\nGold on the floor\n[Chorus]\nUnder the city lights\n",
    "duration": 330
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Πρέπει να σημειωθεί ότι το `duration` στο αίτημα είναι η **επιθυμητή διάρκεια**, ενώ το πεδίο `duration` για κάθε τραγούδι στο `data` της απόκρισης είναι η **πραγματική διάρκεια** του συγκεκριμένου τραγουδιού. Τα δύο έχουν το ίδιο όνομα αλλά διαφορετική σημασία, και η πραγματική διάρκεια δεν είναι εγγυημένο ότι θα ισούται με την επιθυμητή τιμή. Το μήκος των στίχων είναι ένας από τους κύριους παράγοντες που επηρεάζουν τη διάρκεια του τελικού προϊόντος· εάν χρειάζεστε μεγαλύτερο τελικό προϊόν, συνιστάται να παρέχετε ταυτόχρονα πιο ολοκληρωμένους στίχους.

Η διεπαφή θα επαληθεύσει ότι το `duration` πρέπει να είναι ακέραιος από 10 έως 360· εξακολουθεί να είναι μόνο στόχος δημιουργίας και όχι εγγύηση για το μήκος του τελικού προϊόντος.

## Λειτουργία δημιουργίας έμπνευσης Inspo

Η λειτουργία δημιουργίας έμπνευσης Inspo μπορεί να δημιουργήσει νέα μουσική βάσει 1 έως 4 πλήρων ηχητικών αναφορών, και υποστηρίζει μεταφορά και απόθεση ή μεταφόρτωση ήχου ως πηγή έμπνευσης. Το API χρησιμοποιεί την υπάρχουσα ενέργεια `inspo`: ο πελάτης παρέχει δημόσια προσβάσιμα URL ήχου, και η υπηρεσία ολοκληρώνει αυτόματα την προετοιμασία των ηχητικών αναφορών και τη δημιουργία, χωρίς να χρειάζεται ο πελάτης να διαβάζει ξεχωριστά τους στίχους, το ύφος ή τη διάρκεια και έπειτα να συνθέτει το αίτημα. Διαφέρει από τη δειγματοληψία διαστήματος που αναφέρθηκε παραπάνω, και επίσης από το Cover που αναπαράγει το ύφος του πρωτότυπου τραγουδιού. Κατά τη χρήση, πρέπει να συμπληρωθούν οι ακόλουθες παράμετροι:

- action：Το περιεχόμενο είναι `inspo`.
- audio_urls：Η λίστα URL των ηχητικών αναφορών, όπου πρέπει να παρέχονται 1 έως 4 δημόσια προσβάσιμες διευθύνσεις ήχου.
- model：Το μοντέλο που χρησιμοποιείται, προτείνεται το `chirp-v6`.
- prompt：Στίχοι ή προτροπή δημιουργίας (προαιρετικό).

> Σημείωση：Τα ηχητικά αναφοράς πρέπει να είναι δημόσια προσβάσιμα αρχεία ήχου. Εάν το ηχητικό αναφοράς ταιριάζει πλήρως με γνωστή ηχογράφηση στη μουσική βιβλιοθήκη της πλατφόρμας, το Suno ενδέχεται να αρνηθεί τη δημιουργία λόγω ελέγχου πνευματικών δικαιωμάτων· συνιστάται να χρησιμοποιείτε δικό σας ήχο ή ήχο που έχει δημιουργηθεί από το Suno ως πηγή έμπνευσης.

## Ασύγχρονη επανάκληση

Επειδή ο χρόνος που χρειάζεται το Suno για να δημιουργήσει μουσική είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, εάν το API δεν αποκρίνεται για μεγάλο χρονικό διάστημα, το αίτημα HTTP θα διατηρεί συνεχώς τη σύνδεση, οδηγώντας σε επιπλέον κατανάλωση πόρων του συστήματος, επομένως αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονες επανακλήσεις.

Η συνολική διαδικασία είναι η εξής: όταν ο πελάτης υποβάλλει ένα αίτημα, καθορίζει επιπλέον ένα πεδίο `callback_url`. Αφού ο πελάτης υποβάλει το αίτημα API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα, το οποίο περιλαμβάνει ένα πεδίο `task_id`, που αντιπροσωπεύει το αναγνωριστικό της τρέχουσας εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα της δημιουργίας μουσικής θα σταλεί με τη μορφή POST JSON στο `callback_url` που έχει καθορίσει ο πελάτης, το οποίο περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Παρακάτω θα δούμε τη συγκεκριμένη διαδικασία μέσω ενός παραδείγματος.

Αρχικά, η επανάκληση Webhook είναι μια υπηρεσία που μπορεί να λαμβάνει αιτήματα HTTP, και ο προγραμματιστής θα πρέπει να την αντικαταστήσει με το URL του δικού του διακομιστή HTTP. Εδώ, για ευκολία επίδειξης, χρησιμοποιείται ένας δημόσιος ιστότοπος παραδείγματος Webhook https://webhook.site/· ανοίγοντας αυτόν τον ιστότοπο μπορείτε να λάβετε ένα Webhook URL, όπως φαίνεται στην εικόνα:
