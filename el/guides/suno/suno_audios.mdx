Καθώς η εφαρμογή της AI γίνεται ευρύτερη, διάφορα προγράμματα AI έχουν σταδιακά διαδοθεί. Η AI έχει σταδιακά διεισδύσει σε κάθε πτυχή της εργασίας και της ζωής των ανθρώπων. Και οι κλάδοι που εμπλέκονται με την AI γίνονται επίσης όλο και περισσότεροι, από την αρχική συγγραφή, έως την ιατρική και την εκπαίδευση, και τώρα τη μουσική.

Το Suno είναι μια επαγγελματική, υψηλής ποιότητας πλατφόρμα δημιουργίας τραγουδιών και μουσικής με AI. Οι χρήστες χρειάζεται μόνο να εισαγάγουν απλές προτροπές κειμένου για να δημιουργήσουν τραγούδια με φωνητικά βάσει του είδους, του ύφους και των στίχων. Αυτός ο δημιουργός μουσικής με AI αναπτύχθηκε από μέλη ομάδων γνωστών εταιρειών τεχνολογίας όπως οι Meta, TikTok και Kensho, με στόχο να μη χρειάζονται καθόλου μουσικά όργανα, ώστε όλοι να μπορούν να δημιουργούν όμορφη μουσική.

Ακολουθεί η πρόοδος των ενημερώσεων του μοντέλου:

| Έκδοση      | model           | Ημερομηνία κυκλοφορίας | Όριο lyric | Όριο style | Μέγιστη διάρκεια τραγουδιού |
| ------- | --------------- | ---------- | -------- | -------- | ------ |
| v6      | chirp-v6        | 2026.09.09 | —        | —        | —      |
| v6 Wild | chirp-v6-wild   | 2026.09.09 | —        | —        | —      |
| v6 Mini | chirp-v6-mini   | 2026.09.09 | —        | —        | —      |
| v5.5    | chirp-v5-5      | 2026.03.27 | 5000     | 1000     | 8 λεπτά   |
| v5      | chirp-v5        | 2025.09.23 | 5000     | 1000     | 8 λεπτά   |
| v4.5+   | chirp-v4-5-plus | 2025.07.17 | 5000     | 1000     | 8 λεπτά   |
| v4.5    | chirp-v4-5      | 2025.05.03 | 5000     | 1000     | 4 λεπτά   |
| v4      | chirp-v4        | 2024.12.17 | 3000     | 200      | 150 δευτερόλεπτα  |
| v3.5    | chirp-v3-5      | ---        | 3000     | 200      | 120 δευτερόλεπτα  |

> Τα όρια `lyric` και `style` στον παραπάνω πίνακα είναι τα ανώτατα όρια στη λειτουργία προσαρμογής (όταν το `custom` είναι `true`). Στη μη προσαρμοσμένη λειτουργία έμπνευσης (όταν το `custom` είναι `false`) συμπληρώνεται μόνο το `prompt`, με ανώτατο όριο μήκους 500 χαρακτήρων (ίδιο για όλα τα μοντέλα).

Το Suno υποστηρίζει πλέον τα `chirp-v6`, `chirp-v6-wild` και `chirp-v6-mini`. Συνιστάται η χρήση του `chirp-v6`· τα ονόματα των παλαιών μοντέλων παραμένουν συμβατά.

Ωστόσο, η επίσημη Suno δεν παρέχει API. Το AceDataCloud παρέχει ένα σύνολο API για το Suno, προσομοιώνοντας την ενσωμάτωση με την επίσημη Suno, ώστε να μπορείτε να δημιουργείτε εύκολα και γρήγορα τη μουσική που θέλετε.

## Αίτηση και χρήση

Για να χρησιμοποιήσετε το Suno Audios Generation API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση παρέχει δωρεάν πίστωση για δωρεάν δοκιμή· όταν η πίστωση δεν επαρκεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## Βασική χρήση

Για όποιο τραγούδι θέλετε να δημιουργήσετε, μπορείτε να εισαγάγετε οποιοδήποτε κείμενο. Για παράδειγμα, αν θέλω να δημιουργήσω ένα τραγούδι για τα Χριστούγεννα, μπορώ να εισαγάγω `a song for Christmas`, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ ορίσαμε τα Request Headers, που περιλαμβάνουν:

- `accept`：τη μορφή του αποτελέσματος απόκρισης που θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή μορφή JSON.
- `authorization`：το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, ορίσαμε το Request Body, που περιλαμβάνει:
- `action`: τύπος εργασίας ήχου, προεπιλογή είναι `generate`. Υποστηρίζει λειτουργίες όπως δημιουργία, συνέχιση, διασκευή, συγχώνευση, διαχωρισμό κομματιών, προσθήκη ηχητικού κομματιού, εξαγωγή καθορισμένου ηχητικού κομματιού, δημιουργία ηχητικών εφέ και προσαρμογή ταχύτητας, όλες μέσω της κλήσης `POST /suno/audios`.
- `prompt`: η προτροπή λειτουργίας έμπνευσης του Suno (ισχύει όταν το `custom` είναι `false`), έως 500 χαρακτήρες.
- `model`: το μοντέλο για αυτή την εργασία δημιουργίας μουσικής. Η σειρά v6 περιλαμβάνει τα `chirp-v6`, `chirp-v6-wild` και `chirp-v6-mini`· τα ονόματα παλαιών μοντέλων συνεχίζουν να είναι συμβατά.
- `max_mode`: λειτουργία ενισχυμένης δημιουργίας. Το `generate` ενεργοποιείται μόνο όταν τόσο το `custom` όσο και το `max_mode` είναι `true`, με κόστος 1.12 Credits· το `add_stem` μπορεί να ενεργοποιηθεί απευθείας, με κόστος 1.344 Credits. Όταν είναι απενεργοποιημένο ή παραλείπεται, το κόστος είναι αντίστοιχα 0.56 και 0.672 Credits.
- `variety`: ένταση ποικιλομορφίας των αποτελεσμάτων δημιουργίας, με επιλογές `off`, `normal`, `high`, `extra`, `max`. Χρησιμοποιείται μόνο για `generate` και `add_stem`· η αποστολή της σε άλλα action θα επιστρέψει 400.
- `lyric`: το περιεχόμενο στίχων της προσαρμοσμένης λειτουργίας του Suno. Τα `chirp-v3-5` και `chirp-v4` υποστηρίζουν έως 3000 χαρακτήρες· το `chirp-v4-5` και νεότερα (συμπεριλαμβανομένων των `chirp-v5`, `chirp-v5-5`) υποστηρίζουν έως 5000 χαρακτήρες.
- `custom`: αν θα χρησιμοποιηθεί η προσαρμοσμένη λειτουργία, η προεπιλογή είναι: `false`.
- `instrumental`: η επιλογή ορχηστρικής μουσικής της λειτουργίας έμπνευσης του Suno.
- `title`: ο τίτλος μουσικής της προσαρμοσμένης λειτουργίας του Suno. Τα `chirp-v3-5`, `chirp-v4` υποστηρίζουν έως 80 χαρακτήρες· το `chirp-v4-5` και νεότερα υποστηρίζουν έως 100 χαρακτήρες.
- `style`: το μουσικό ύφος της προσαρμοσμένης λειτουργίας του Suno. Τα `chirp-v3-5` και `chirp-v4` υποστηρίζουν έως 200 χαρακτήρες· το `chirp-v4-5` και νεότερα (συμπεριλαμβανομένων των `chirp-v5`, `chirp-v5-5`) υποστηρίζουν έως 1000 χαρακτήρες.
- `negative_tags`: μουσικά ύφη ή είδη που επιθυμείτε να αποκλείσετε κατά την προσαρμοσμένη δημιουργία, και μπορεί επίσης να χρησιμοποιηθεί για `replace_section`. Αυτή η διεπαφή δεν έχει επί του παρόντος ορίσει σταθερό ανώτατο όριο χαρακτήρων για αυτό το πεδίο· υπερβολικά μεγάλο περιεχόμενο ενδέχεται να μην μπορεί να υποβληθεί σε επεξεργασία, επομένως συνιστάται η διατήρηση συνοπτικών περιγραφών.
- `audio_weight`: το βάρος επιρροής των χαρακτηριστικών ήχου ή φωνής, εύρος 0-1, και το `0` είναι επίσης έγκυρη τιμή. Μπορεί να χρησιμοποιηθεί σε λειτουργίες όπως δημιουργία, συνέχιση, διασκευή, προσθήκη ηχητικού κομματιού και συνέπεια φωνής· χωρίς αναφορικό ήχο ή χαρακτηριστικά φωνής, το μοντέλο μπορεί να αποδυναμώσει ή να αγνοήσει αυτή την τιμή.
- `audio_id`: το ID της αναφορικής μουσικής, χρησιμοποιείται για επόμενες λειτουργίες όπως διασκευή, συνέχιση και διαχωρισμό κομματιών. Το αρχείο ήχου μπορεί ακόμη να ληφθεί και αυτό δεν σημαίνει ότι η επεξεργασία αυτού του ID παραμένει πάντα διαθέσιμη· εάν επιστραφεί `suno_processing_unavailable`, διατηρήστε τα `task_id` και `trace_id` και επικοινωνήστε με την υποστήριξη.
- `overpainting_start`/`overpainting_end`: οι χρόνοι έναρξης και λήξης για την προσθήκη φωνητικών σε υπάρχουσα ορχηστρική μουσική, σε δευτερόλεπτα.
- `underpainting_start`/`underpainting_end`: οι χρόνοι έναρξης και λήξης για την προσθήκη συνοδείας σε a cappella, σε δευτερόλεπτα.
- `persona_id`: το ID φωνής που λαμβάνεται μέσω της διεπαφής δημιουργίας Persona ή φωνής, δεν είναι το `audio_id` ενός τραγουδιού.
- `continue_at`: το όριο συνέχισης, σε δευτερόλεπτα. Για παράδειγμα, το 213.5 σημαίνει ότι δημιουργείται το επόμενο τμήμα από το 3ο λεπτό και 33.5 δευτερόλεπτα. Τα `lyric` και `style` καθοδηγούν μόνο το νέο περιεχόμενο μετά το όριο και δεν θα αντικαταστήσουν τους στίχους ή το τραγούδισμα πριν από το όριο στον πηγαίο ήχο.
- `style_influence`: η επιρροή ύφους στην προσαρμοσμένη λειτουργία, εύρος 0-1· όσο μεγαλύτερη είναι, τόσο περισσότερο συνήθως ταιριάζει με το επιλεγμένο ύφος· το `0` θα μεταβιβαστεί ως έγκυρη τιμή.
- `replace_section_end`: ο τελικός χρόνος του τμήματος αντικατάστασης.
- `replace_section_start`: ο χρόνος έναρξης του τμήματος αντικατάστασης.
- `vocal_gender`: ελέγχει την προτίμηση για γυναικεία ή ανδρική φωνή, γυναικεία φωνή `f`, ανδρική φωνή `m`, ισχύει για μοντέλα 4.5 και άνω· είναι στοιχείο προτίμησης και δεν εγγυάται αυστηρή τήρηση.
- `weirdness`: ο βαθμός παραδοξότητας στην προσαρμοσμένη λειτουργία, εύρος 0-1· όσο μεγαλύτερος είναι, τόσο συνήθως πιο δημιουργικό και πειραματικό είναι το αποτέλεσμα· το `0` θα μεταβιβαστεί ως έγκυρη τιμή.
- `duration`: η επιθυμητή διάρκεια τραγουδιού, σε δευτερόλεπτα, πρέπει να είναι ακέραιος, με εύρος τιμών από 10 έως 360. Προς το παρόν μόνο το `generate` χρησιμοποιεί αυτή την παράμετρο και το συγκεκριμένο αποτέλεσμα εξαρτάται από τη λειτουργία και το μοντέλο. Είναι μια ενδεικτική προτροπή και όχι αυστηρός περιορισμός: το μοντέλο θα τη λάβει υπόψη, αλλά δεν εγγυάται ότι θα την επιτύχει· η πραγματική διάρκεια του τελικού αποτελέσματος υπερισχύει στο πεδίο `duration` της απόκρισης και συνήθως είναι μικρότερη από την επιθυμητή τιμή.

### Πεδίο εφαρμογής του ID φωνής

Τα `generate`, `cover`, `upload_cover`, `artist_consistency`, `artist_consistency_vox` μπορούν να χρησιμοποιήσουν το `persona_id`. Τα δύο τελευταία action πρέπει να παρέχουν `persona_id`· μπορούν επίσης να παρέχουν ταυτόχρονα το `audio_id` του τραγουδιού που χρησιμοποιήθηκε κατά τη δημιουργία αυτού του Persona.

Τα `extend`, `upload_extend` δεν χρησιμοποιούν πρόσθετο `persona_id`. Το αν τα `mashup`, `inspo` υποστηρίζουν ID φωνής εξαρτάται από το επιλεγμένο κανάλι υπηρεσίας· τα άλλα action δεν εγγυώνται την εφαρμογή αυτού του πεδίου, χρησιμοποιήστε το σύμφωνα με τις οδηγίες κάθε λειτουργίας. Το `vocal_gender` είναι μια προαιρετική προτίμηση φύλου και δεν μπορεί να αντικαταστήσει το ID φωνής.

Οι επόμενες δημιουργικές λειτουργίες απαιτούν έγκυρο πηγαίο `audio_id`· το `mashup` απαιτεί τουλάχιστον δύο `mashup_audio_ids`. Εάν λείπουν απαραίτητες πηγές ή παράμετροι χρόνου, θα επιστραφεί HTTP 400.

### Πεδίο εφαρμογής προηγμένων παραμέτρων
| Παράμετρος                | Τιμή                                          | Υποστηριζόμενα action                              | Περιγραφή                                |
| ----------------- | ------------------------------------------- | --------------------------------------- | --------------------------------- |
| `weirdness`       | 0-1                                         | Προαιρετικό                                      | Ρυθμίζει την πειραματικότητα, το `0` είναι έγκυρη τιμή· το αποτέλεσμα εξαρτάται από τη λειτουργία, τη λειτουργία και το μοντέλο      |
| `style_influence` | 0-1                                         | Προαιρετικό                                      | Ρυθμίζει την τάση τήρησης του στυλ, το `0` είναι έγκυρη τιμή· το αποτέλεσμα εξαρτάται από τη λειτουργία, τη λειτουργία και το μοντέλο   |
| `audio_weight`    | 0-1                                         | Προαιρετικό                                      | Ρυθμίζει την επιρροή των χαρακτηριστικών ήχου ή φωνής· ενδέχεται να αγνοηθεί από το μοντέλο όταν δεν υπάρχουν πληροφορίες αναφοράς        |
| `variety`         | `off` / `normal` / `high` / `extra` / `max` | `generate`、`add_stem`                   | Ρυθμίζει τη στυλιστική ποικιλομορφία μεταξύ των αποτελεσμάτων                       |
| `max_mode`        | boolean                                     | `generate`（απαιτεί `custom=true`）、`add_stem` | Ενισχύει τη συνέπεια και χρεώνει σύμφωνα με την ενισχυμένη λειτουργία                     |
| `vocal_gender`    | `f` / `m`                                   | Λειτουργίες δημιουργίας που υποστηρίζουν έλεγχο φωνητικών                             | Επιλογή προτίμησης, δεν εγγυάται αυστηρή τήρηση                       |
| `duration`        | Ακέραιος 10-360                                   | `generate`                              | Επιθυμητή διάρκεια· άλλα action προς το παρόν δεν χρησιμοποιούν αυτό το πεδίο, το πραγματικό μήκος εξαρτάται από το αποτέλεσμα |

Η πλατφόρμα θα ελέγχει τους τύπους παραμέτρων και τα εύρη τιμών, αλλά δεν θα απορρίπτει αυτά τα προαιρετικά στοιχεία ρύθμισης μόνο λόγω διαφορετικού action· το συγκεκριμένο αποτέλεσμα καθορίζεται από τη λειτουργία, τη λειτουργία και το μοντέλο.

- `lyric_prompt`：το prompt για τη δημιουργία στίχων, ισχύει μόνο όταν το `custom` είναι `true` και δεν έχει σταλεί το `lyric`.
- `callback_url`：το URL που απαιτείται για την επιστροφή αποτελεσμάτων μέσω callback.
- `async`：προαιρετικό, όταν οριστεί σε `true` η διεπαφή επιστρέφει αμέσως το `task_id`, χωρίς να απαιτείται η παροχή `callback_url`, και στη συνέχεια το αποτέλεσμα λαμβάνεται με polling μέσω της αντίστοιχης διεπαφής ερωτήματος εργασίας.

  - title：ο τίτλος του τραγουδιού
  - image_url：η εικόνα εξωφύλλου του τραγουδιού
  - lyric：οι στίχοι του τραγουδιού
  - audio_url：η διεύθυνση τελικού ήχου του τραγουδιού. Η πλατφόρμα θα επιστρέφει κατά προτεραιότητα διεύθυνση Ace Data Cloud CDN· αν η μονιμοποίηση αποτύχει, ενδέχεται να επιστραφεί η αρχική διεύθυνση πολυμέσων, παρακαλούμε κατεβάστε την έγκαιρα.
  - video_url：το αρχείο βίντεο του τραγουδιού, ανοίγοντάς το εμφανίζεται ένα βίντεο mp4.
  - created_at：ο χρόνος δημιουργίας

  - style：το στυλ

## Λειτουργία συνέχισης δημιουργίας
Εάν θέλετε να συνεχίσετε τη δημιουργία ενός ήδη δημιουργημένου τραγουδιού Suno, μπορείτε να ορίσετε την παράμετρο `action` σε `extend` και να εισαγάγετε το ID του τραγουδιού που χρειάζεται να συνεχίσει να δημιουργείται. Η λήψη του ID του τραγουδιού γίνεται σύμφωνα με τη βασική χρήση. Όπως φαίνεται παραπάνω, σε αυτό το σημείο μπορείτε να δείτε ότι το ID του τραγουδιού είναι:

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> Σημείωση: το `id` στους στίχους εδώ είναι το ID του τραγουδιού μετά τη δημιουργία. Εάν δεν γνωρίζετε πώς να δημιουργήσετε ένα τραγούδι, μπορείτε να ανατρέξετε στη βασική χρήση παραπάνω για να δημιουργήσετε ένα τραγούδι.

Εάν θέλετε να συνεχίσετε τη δημιουργία ενός τραγουδιού που ανεβάσατε εσείς, μπορείτε να ορίσετε την παράμετρο `action` σε `upload_extend` και να εισαγάγετε το ID του προσαρμοσμένου ανεβασμένου τραγουδιού που χρειάζεται να συνεχίσει να δημιουργείται. Η λήψη του ID του τραγουδιού γίνεται χρησιμοποιώντας το [Suno Upload Generation API](https://platform.acedata.cloud/documents/suno-upload), όπως φαίνεται στην παρακάτω εικόνα:

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" className="m-auto" /></p>

Στη συνέχεια, πρέπει να συμπληρώσετε τους στίχους του τμήματος συνέχειας και μπορείτε να καθορίσετε το στυλ:

- lyric: Χρησιμοποιείται μόνο για την καθοδήγηση των στίχων του νέου τμήματος που δημιουργείται μετά το `continue_at` και δεν θα αντικαταστήσει τους στίχους πριν από αυτό το χρονικό σημείο στο αρχικό ήχο.
- custom: Συμπληρώστε `true`, που αντιπροσωπεύει προσαρμοσμένη δημιουργία. Η προεπιλεγμένη τιμή αυτής της παραμέτρου είναι false, που αντιπροσωπεύει δημιουργία με χρήση του `prompt`.
- style: Το μουσικό στυλ του τμήματος συνέχειας, προαιρετικό.
- continue_at: Το όριο συνέχειας, σε δευτερόλεπτα. Για παράδειγμα, το 213.5 υποδεικνύει ότι το επόμενο τμήμα θα δημιουργηθεί από το 3ο λεπτό και 33.5 δευτερόλεπτα.

Το `continue_at` των `extend` και `upload_extend` πρέπει να είναι μεγαλύτερο από 0 και υποστηρίζει κλασματικά δευτερόλεπτα, για παράδειγμα `30.792`. Δεν θα γίνει στρογγυλοποίηση κατά την υποβολή.

> Το `extend` χρησιμοποιείται για να συνεχίσετε τη δημιουργία μετά από ένα υπάρχον τραγούδι και όχι για να αλλάξετε τους στίχους ολόκληρου του τραγουδιού. Εάν θέλετε ολόκληρο το τραγούδι να χρησιμοποιεί νέους στίχους από την αρχή, χρησιμοποιήστε το `generate` για να το δημιουργήσετε ξανά. Εάν θέλετε να επανερμηνεύσετε ένα υπάρχον τραγούδι ως αναφορά, μπορείτε να χρησιμοποιήσετε το `cover`. Όταν περνάτε νέους στίχους για ολόκληρο τραγούδι, οι αρχικοί στίχοι πριν από το `continue_at` εξακολουθούν να μην αντικαθίστανται.

Ένα παράδειγμα συμπλήρωσης είναι το εξής:

<p><img src="https://cdn.acedata.cloud/zp9s42.png" width="500" className="m-auto" /></p>

Αφού ολοκληρωθεί η συμπλήρωση, ο κώδικας δημιουργείται αυτόματα ως εξής:

<p><img src="https://cdn.acedata.cloud/wwpw78.png" width="500" className="m-auto" /></p>

Όταν η συνέχεια γίνεται στην πράξη κοντά στο τέλος του τραγουδιού, αυτή η τιμή θα πρέπει να ορίζεται στο δευτερόλεπτο όπου αναμένεται να ξεκινήσει η συνέχεια και να παρέχεται στο `lyric` μόνο το νέο τμήμα που πρέπει να τραγουδηθεί μετά το όριο.

## Μουσική διασκευή

Όταν συνεχίζετε να δημιουργείτε ένα τραγούδι με βάση ένα υπάρχον τραγούδι, το ύφος του τραγουδιού που επιστρέφεται μπορεί να μην είναι ιδιαίτερα κατάλληλο. Εάν θέλετε να δημιουργήσετε διασκευή του αρχικά παραγόμενου τραγουδιού (υποστηρίζεται επίσης και για προσαρμοσμένη μεταφορτωμένη μουσική), πρέπει να χρησιμοποιήσετε τη μέθοδο μουσικής διασκευής και μπορείτε να ορίσετε το ακόλουθο περιεχόμενο:

- action：η τιμή είναι `cover`· όταν εκτελείτε λειτουργία διασκευής σε προσαρμοσμένη μεταφορτωμένη μουσική, πρέπει να ορίσετε την τιμή ως: `upload_cover`.

Εάν χρειάζεται να χρησιμοποιήσετε καθορισμένη φωνή για ερμηνεία, μπορείτε επίσης να περάσετε το `persona_id`. Οι ιδιωτικές φωνές που δημιουργούνται μέσω του `/suno/voices` πρέπει πρώτα να χρησιμοποιήσουν το ίδιο `persona_id` για τη μεταφόρτωση του αρχικού τραγουδιού στο `/suno/upload` και, στη συνέχεια, να χρησιμοποιηθεί το επιστρεφόμενο `audio_id` για `upload_cover`. ## Αντικατάσταση τμήματος

Το `replace_section` δημιουργεί ξανά το επιλεγμένο τμήμα με βάση το χρονικό διάστημα του αρχικού τραγουδιού και ενσωματώνει το αποτέλεσμα ξανά στο αρχικό κομμάτι. Το `replace_section_result_mode` είναι από προεπιλογή `full_song`, επιστρέφοντας 2 πλήρη τραγούδια που μπορούν να αναπαραχθούν απευθείας, χωρίς να χρειάζεται να κληθεί ξανά το `concat`.

### Πώς να συμπληρώσετε την είσοδο
- `action`: `replace_section`.
- `audio_id`: Το πλήρες ID του τραγουδιού προς επεξεργασία. Κατά την εκ νέου επεξεργασία, χρησιμοποιήστε το `data[].id` του πλήρους τραγουδιού που επιλέχθηκε την προηγούμενη φορά, όχι το `task_id`.
- `model`: Το μοντέλο δημιουργίας τραγουδιού, για παράδειγμα `chirp-v6`.
- `lyric`: Οι **τοπικοί νέοι στίχοι** που πρέπει να τραγουδηθούν στο επιλεγμένο διάστημα. Δεν χρειάζεται να εισαγάγετε ολόκληρους τους στίχους του τραγουδιού για να λάβετε το πλήρες τραγούδι.
- `prompt`: Καθορίζει ρητά τους τοπικούς νέους στίχους αυτής της αντικατάστασης. Κατά την αλλαγή στίχων, συνιστάται να συμπληρώνεται το ίδιο περιεχόμενο με το `lyric`, ώστε να αποφεύγεται η έκφραση διαφορετικών στίχων από τα δύο πεδία. Τα υπάρχοντα αιτήματα που μεταβιβάζουν μόνο το τοπικό `lyric` και παραλείπουν το `prompt` μπορούν ακόμη να χρησιμοποιηθούν, αλλά η προσθήκη του `prompt` από μόνη της δεν εγγυάται την επιτυχία της αλλαγής στίχων.
- `style`, `negative_tags`: Προαιρετικές περιγραφές ύφους και στοιχεία προς αποκλεισμό· το `prompt` σε αυτήν την ενέργεια δεν είναι η συνήθης περιγραφή έμπνευσης για τη δημιουργία τραγουδιού.
- `replace_section_start`, `replace_section_end`: Οι χρόνοι έναρξης και λήξης της επιλογής στο τρέχον τραγούδι-πηγή, σε δευτερόλεπτα, με υποστήριξη δεκαδικών. Το σημείο έναρξης δεν πρέπει να είναι μικρότερο από 0, και το σημείο λήξης πρέπει να είναι μεγαλύτερο από το σημείο έναρξης και να μην υπερβαίνει τη διάρκεια του τραγουδιού-πηγής.
- `replace_section_result_mode`: Το `full_song` (προεπιλογή) επιστρέφει 2 πλήρη τραγούδια· το `candidates` επιστρέφει 2 υποψήφια αντικατάστασης που δεν έχουν ακόμη συγχωνευτεί.

Μην θεωρείτε ως γενική χρήση ότι «το `lyric` πρέπει να είναι οι πλήρεις στίχοι μετά την αντικατάσταση και το `prompt` πρέπει να είναι οι τοπικοί στίχοι». Η εισαγωγή πλήρων στίχων σε ορισμένες εργασίες μπορεί να παράγει υπερβολικά μεγάλο περιεχόμενο αντικατάστασης, κάνοντας ολόκληρο το τραγούδι σημαντικά μεγαλύτερο μετά τη συγχώνευση. Η τοπική εισαγωγή επίσης δεν εγγυάται σταθερή διάρκεια ή κατά λέξη τήρηση των στίχων· πρόκειται για παραγωγική επεξεργασία και πρέπει να ελέγξετε το πραγματικό ηχητικό αποτέλεσμα.

### Έναρξη εργασίας και λήψη πλήρους τραγουδιού

Παρακάτω είναι ένα παράδειγμα μορφής αιτήματος. Αντικαταστήστε το `YOUR_COMPLETED_AUDIO_ID` και το χρονικό διάστημα με το δικό σας ID τραγουδιού-πηγής και την πραγματική επιλογή· το παράδειγμα υποθέτει ότι τα 30–50 δευτερόλεπτα αντιστοιχούν στους παρακάτω τέσσερις στίχους.

```json
{
  "action": "replace_section",
  "audio_id": "YOUR_COMPLETED_AUDIO_ID",
  "model": "chirp-v6",
  "custom": false,
  "instrumental": false,
  "lyric": "晚风吹过安静的街巷\n绿色风筝停在我身旁\n我们沿着河岸轻轻唱\n把今天的故事放心上",
  "prompt": "晚风吹过安静的街巷\n绿色风筝停在我身旁\n我们沿着河岸轻轻唱\n把今天的故事放心上",
  "replace_section_start": 30.0,
  "replace_section_end": 50.0,
  "replace_section_result_mode": "full_song",
  "async": true
}
```

Μετά την υποβολή, χρησιμοποιήστε το επιστρεφόμενο `task_id` για να ερωτήσετε το `/suno/tasks`, με σώμα αιτήματος `{"action":"retrieve","id":"YOUR_TASK_ID"}`. Μετά την ολοκλήρωση της εργασίας, λάβετε το `id`, το `audio_url` και το `duration` των δύο πλήρων τραγουδιών από το `response.data` στην απόκριση της εργασίας, ακούστε τα και επιλέξτε ένα από αυτά. Το `success: true` σημαίνει ότι η εργασία εκτελέστηκε επιτυχώς, όχι ότι οι νέοι στίχοι έχουν τραγουδηθεί κατά λέξη ή ότι η διάρκεια ανταποκρίνεται στην αναμενόμενη.

### Επιλογή διαστήματος, έλεγχος αποτελέσματος και εκ νέου επεξεργασία

1. Ακούστε πρώτα το τραγούδι-πηγή και, στη συνέχεια, χρησιμοποιήστε τις χρονικές πληροφορίες του `/suno/timing` για να καθορίσετε την επιλογή, προσπαθώντας να καλύψετε πλήρεις μουσικές φράσεις. Μην επιλέγετε το διάστημα βάσει σταθερών δεικτών του πίνακα στίχων και μην χρησιμοποιείτε μερικούς στίχους για να αντικαταστήσετε ένα διάστημα που περιλαμβάνει περισσότερες μουσικές φράσεις, αναμένοντας ότι ο ρυθμός θα παραμείνει ακριβώς ίδιος.
2. Ο αριθμός των στίχων, των χαρακτήρων και ο ρυθμός των νέων στίχων πρέπει να προσεγγίζουν όσο το δυνατόν περισσότερο το υπάρχον περιεχόμενο της επιλογής. Ακόμη και η αλλαγή λίγων μόνο χαρακτήρων απαιτεί επαλήθευση με ακρόαση και δεν μπορεί να εγγυηθεί επιτυχία βάσει αυτού.
3. Ελέγξτε αν οι νέοι στίχοι τραγουδιούνται στο στοχευμένο διάστημα, αν η μετάβαση πριν και μετά είναι φυσική και αν η διάρκεια ολόκληρου του τραγουδιού είναι εύλογη. Το `full_song` σημαίνει ότι επιστρέφεται πλήρες τραγούδι, όχι ότι έχει το ίδιο μήκος με το πρωτότυπο· όταν το τμήμα αντικατάστασης γίνεται μεγαλύτερο, το δεύτερο μισό μετακινείται αντίστοιχα αργότερα. Η παράμετρος αιτήματος `duration` χρησιμοποιείται μόνο για συνηθισμένη δημιουργία και δεν μπορεί να κλειδώσει τη διάρκεια του τμήματος αντικατάστασης.
4. Το επιστρεφόμενο `lyric` είναι μεταδεδομένα στίχων· η λειτουργία πλήρους τραγουδιού συνδυάζει πλήρεις στίχους όταν μπορούν να ληφθούν χρονικές πληροφορίες στίχων από την πηγή· όταν δεν μπορούν να ληφθούν, ενδέχεται να είναι κενό. Δεν είναι μεταγραφή ήχου· η εμφάνιση νέων στίχων δεν αποδεικνύει ότι ο ήχος έχει τραγουδήσει τους νέους στίχους. Οι πληροφορίες χρονικού συγχρονισμού πρέπει επίσης να επαληθεύονται με ακρόαση, ιδιαίτερα για παραγόμενα αποτελέσματα που έχουν ήδη υποστεί επεξεργασία.
5. Κατά την εκ νέου επεξεργασία, χρησιμοποιήστε το επιλεγμένο **πλήρες ID τελικού προϊόντος** ως νέο `audio_id` και ελέγξτε ξανά τη διάρκεια και την επιλογή αυτού του τελικού προϊόντος. Μην αντιγράφετε απλώς τις χρονικές συντεταγμένες πριν από την επεξεργασία και μην χρησιμοποιείτε απευθείας ολόκληρο το `lyric` που επιστράφηκε την προηγούμενη φορά ως τοπική εισαγωγή αυτής της φοράς.

Εάν η εργασία έχει ολοκληρωθεί αλλά εξακολουθούν να τραγουδιούνται οι παλιοί στίχοι, λείπουν στίχοι ή το τραγούδι γίνεται σημαντικά μεγαλύτερο, ελέγξτε πρώτα το ID του τραγουδιού-πηγής, την επιλογή και τους τοπικούς στίχους και έπειτα ελέγξτε το άλλο αποτέλεσμα. Η αύξηση της συχνότητας ερωτημάτων της εργασίας δεν θα αλλάξει το ήδη παραγόμενο περιεχόμενο. Εάν το πρόβλημα παραμένει, διατηρήστε το `task_id`, το ID τραγουδιού-πηγής, τα πεδία του αιτήματος, την επιλογή και τον ήχο αποτελέσματος, για να διευκολύνετε τον έλεγχο.

### Προαιρετικά: λάβετε πρώτα υποψηφίους και, έπειτα, συγχωνεύστε χειροκίνητα

Μόνο όταν χρειάζεται να επιλέξετε μόνοι σας έναν υποψήφιο αντικατάστασης, ορίστε `replace_section_result_mode: "candidates"`. Οι υποψήφιοι μπορεί να περιλαμβάνουν περιεχόμενο πλαισίου και δεν μπορείτε να τους θεωρήσετε πλήρη τραγούδια μόνο βάσει της διάρκειάς τους. Μετά την επιλογή, καλέστε το `concat` με το `data[].id` του υποψηφίου και, στη συνέχεια, λάβετε το πλήρες τελικό προϊόν.

Το προεπιλεγμένο `full_song` έχει ήδη ολοκληρώσει τη συγχώνευση και δεν χρειάζεται να εκτελέσετε αυτό το βήμα.

## Έλεγχος διάρκειας τραγουδιού

Από προεπιλογή, η διάρκεια του παραγόμενου τραγουδιού καθορίζεται από το ίδιο το μοντέλο και συνήθως είναι μεταξύ 30 δευτερολέπτων και 4 λεπτών. Εάν χρειάζεστε μεγαλύτερο ή μικρότερο τελικό αποτέλεσμα, μπορείτε να καθορίσετε την επιθυμητή διάρκεια μέσω της παραμέτρου `duration`, με μονάδα τα δευτερόλεπτα και τιμή ακέραιο από 10 έως 360.

Αυτή η παράμετρος χρησιμοποιείται για παραγωγή τραγουδιών σε προσαρμοσμένη λειτουργία (όταν το `custom` είναι `true`). Πρέπει να διευκρινιστεί ιδιαίτερα ότι το `duration` είναι μια **ενδεικτική προτροπή και όχι αυστηρός περιορισμός**: το μοντέλο θα αναφέρεται σε αυτήν την τιμή κατά τη δημιουργία, αλλά δεν εγγυάται ότι θα την επιτύχει. Σε πρακτικές δοκιμές, η πραγματική διάρκεια είναι συνήθως εμφανώς μικρότερη από την επιθυμητή τιμή και οι διάρκειες των δύο τραγουδιών που επιστρέφονται από το ίδιο αίτημα μπορεί επίσης να διαφέρουν κατά πολλές φορές. Ακόμη και για απολύτως ίδια αιτήματα, οι διάρκειες που λαμβάνονται από πολλαπλές υποβολές μπορεί να έχουν μεγάλες διαφορές. Επομένως, μην το χρησιμοποιείτε ως ακριβή έλεγχο διάρκειας· εάν η λειτουργία σας απαιτεί σταθερή διάρκεια, περικόψτε ή επαναλάβετε την προσπάθεια μόνοι σας αφού λάβετε το τελικό αποτέλεσμα.

Ο αντίστοιχος κώδικας Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "Under the City Lights",
    "style": "lo-fi piano",
    "lyric": "[Verse]\nSunrise creepin\nGold on the floor\n[Chorus]\nUnder the city lights\n",
    "duration": 330
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Πρέπει να σημειωθεί ότι το `duration` στο αίτημα είναι η **επιθυμητή διάρκεια**, ενώ το πεδίο `duration` για κάθε τραγούδι στο `data` της απόκρισης είναι η **πραγματική διάρκεια** αυτού του τραγουδιού. Έχουν το ίδιο όνομα αλλά διαφορετική σημασία και η πραγματική διάρκεια δεν εγγυάται ότι ισούται με την επιθυμητή τιμή. Το μήκος των στίχων είναι ένας από τους κύριους παράγοντες που επηρεάζουν τη διάρκεια του τελικού αποτελέσματος· εάν χρειάζεστε μεγαλύτερο τελικό αποτέλεσμα, συνιστάται να παρέχετε ταυτόχρονα πιο ολοκληρωμένους στίχους.

Η διεπαφή θα επικυρώσει ότι το `duration` πρέπει να είναι ακέραιος από 10 έως 360· εξακολουθεί να είναι μόνο στόχος παραγωγής και όχι εγγύηση για το μήκος του τελικού αποτελέσματος.

## Λειτουργία δημιουργίας έμπνευσης Inspo

Η λειτουργία δημιουργίας έμπνευσης Inspo μπορεί να δημιουργήσει νέα μουσική με βάση 1 έως 4 πλήρη ηχητικά αρχεία αναφοράς και υποστηρίζει τη μεταφορά και απόθεση ή τη μεταφόρτωση ήχου ως πηγή έμπνευσης. Το API χρησιμοποιεί την υπάρχουσα ενέργεια `inspo`: ο πελάτης παρέχει ένα δημόσια προσβάσιμο URL ήχου και η υπηρεσία ολοκληρώνει αυτόματα την προετοιμασία του ηχητικού αναφοράς και τη δημιουργία, χωρίς να χρειάζεται ο πελάτης να διαβάσει ξεχωριστά τους στίχους, το ύφος ή τη διάρκεια και έπειτα να συνθέσει το αίτημα. Διαφέρει από τη δειγματοληψία τμήματος που αναφέρθηκε παραπάνω, καθώς και από το Cover που αναπαράγει το ύφος του πρωτότυπου τραγουδιού. Κατά τη χρήση, πρέπει να συμπληρωθούν οι ακόλουθες παράμετροι:

- action：το περιεχόμενο είναι `inspo`。
- audio_urls：λίστα URL των ηχητικών αναφοράς, πρέπει να παρέχονται 1 έως 4 δημόσια προσβάσιμες διευθύνσεις ήχου。
- model：το μοντέλο που χρησιμοποιείται, συνιστάται το `chirp-v6`。
- prompt：στίχοι ή προτροπή δημιουργίας (προαιρετικό)。
- instrumental：όταν οριστεί σε `true`, η δημιουργία ζητείται ως αμιγώς οργανική μουσική, χωρίς χρήση στίχων。
- persona_id：χρήση της καθορισμένης φωνής σε κανάλι υπηρεσίας που υποστηρίζει αυτόν τον συνδυασμό· το ηχητικό αναφοράς θα συνδεθεί κατά το στάδιο προετοιμασίας με το περιβάλλον πόρων που απαιτεί αυτή η φωνή。
- lyric_prompt：όταν `custom=true` και δεν παρέχεται `lyric`, χρησιμοποιείται για την αυτόματη δημιουργία στίχων。

> Σημείωση：το ηχητικό αναφοράς πρέπει να είναι δημόσια προσβάσιμο αρχείο ήχου. Εάν το ηχητικό αναφοράς ταιριάζει πλήρως με μια γνωστή ηχογράφηση στη μουσική βιβλιοθήκη της πλατφόρμας, το Suno ενδέχεται να απορρίψει τη δημιουργία λόγω ελέγχου πνευματικών δικαιωμάτων· συνιστάται να χρησιμοποιείτε δικό σας ή ήχο που έχει δημιουργηθεί από το Suno ως πηγή έμπνευσης。

Ο αντίστοιχος κώδικας Python:


## Ασύγχρονη επανάκληση

Επειδή ο χρόνος που χρειάζεται το Suno για να δημιουργήσει μουσική είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, εάν το API δεν αποκρίνεται για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί συνεχώς τη σύνδεση, οδηγώντας σε επιπλέον κατανάλωση πόρων του συστήματος, επομένως αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονες επανακλήσεις.

Η συνολική διαδικασία είναι: όταν ο πελάτης ξεκινά ένα αίτημα, καθορίζει επιπλέον ένα πεδίο `callback_url`, αφού ο πελάτης ξεκινήσει το αίτημα API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα, το οποίο περιλαμβάνει πληροφορίες για ένα πεδίο `task_id`, που αντιπροσωπεύει το τρέχον αναγνωριστικό εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα της δημιουργίας μουσικής θα σταλεί με τη μορφή POST JSON στο `callback_url` που καθόρισε ο πελάτης, το οποίο επίσης περιλαμβάνει το πεδίο `task_id`, ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Παρακάτω θα κατανοήσουμε μέσω παραδειγμάτων πώς ακριβώς να το χειριστούμε.

Αρχικά, η επανάκληση Webhook είναι μια υπηρεσία που μπορεί να λαμβάνει αιτήματα HTTP, και ο προγραμματιστής θα πρέπει να την αντικαταστήσει με το URL του HTTP διακομιστή που έχει δημιουργήσει ο ίδιος.
