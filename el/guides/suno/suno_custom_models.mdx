Το αποκλειστικό μουσικό μοντέλο μπορεί να μάθει συνεπή μουσικά χαρακτηριστικά από 6 έως 24 αδειοδοτημένα αρχεία ήχου και να χρησιμοποιηθεί για μετέπειτα δημιουργία τραγουδιών. Η δημιουργία είναι ασύγχρονη λειτουργία· συνιστάται η χρήση 24 αρχείων ήχου με συνεπές ύφος και καθαρή ποιότητα ήχου για πιο σταθερά αποτελέσματα.

> Μπορείτε να υποβάλετε μόνο αρχεία ήχου για τα οποία έχετε νόμιμο δικαίωμα χρήσης ή έχετε λάβει άδεια για τη δημιουργία του μοντέλου και τη μετέπειτα παραγωγή. Μην ανεβάζετε μουσική ή ηχητικό υλικό χωρίς άδεια.

## Δημιουργία μοντέλου

Καλέστε `POST /suno/custom-models` και ορίστε `action=create`:

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

Το API επιστρέφει αμέσως το ID μοντέλου της πλατφόρμας και το ID εργασίας. Μετά την ολοκλήρωση της δημιουργίας, το `status` στο callback ή στο αποτέλεσμα ερωτήματος θα αλλάξει σε `ready`. Χρεώνονται **10 Credits** μόνο αν η δημιουργία του μοντέλου ολοκληρωθεί επιτυχώς· η αποτυχημένη δημιουργία δεν χρεώνεται.

## Ερώτημα μοντέλου

Ερώτημα για ένα μεμονωμένο μοντέλο:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Σελιδοποιημένο ερώτημα για τα μοντέλα της τρέχουσας εφαρμογής:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Όλα τα μοντέλα ανήκουν στην εφαρμογή Suno που τα δημιούργησε. Η εναλλαγή διαπιστευτηρίων API δεν αλλάζει την ιδιοκτησία του μοντέλου και άλλες εφαρμογές δεν μπορούν να ερωτήσουν ή να χρησιμοποιήσουν το μοντέλο.

## Χρήση του μοντέλου για δημιουργία τραγουδιών

Αφού η κατάσταση του μοντέλου γίνει `ready`, καλέστε ξανά `POST /suno/custom-models` και ορίστε `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

Το `id` πρέπει να είναι ένα αποκλειστικό μουσικό μοντέλο με κατάσταση `ready` στην τρέχουσα εφαρμογή. Το αίτημα θα αποτύχει όταν το μοντέλο δεν είναι διαθέσιμο και δεν θα χρησιμοποιηθεί αυτόματα κάποιο άλλο μοντέλο. Το `persona_id` και το αποκλειστικό μουσικό μοντέλο αλληλοαποκλείονται· όταν υποβάλλονται ταυτόχρονα, το API επιστρέφει HTTP 400 πριν σταλεί το αίτημα στην υπηρεσία δημιουργίας και δεν θα υπάρξει χρέωση. Αν χρειάζεται να χρησιμοποιήσετε Persona, χρησιμοποιήστε αντί αυτού τις λειτουργίες `artist_consistency` ή `artist_consistency_vox` του `/suno/audios`.

Η επιτυχής δημιουργία τραγουδιού καταναλώνει **0.90 Credits**· η αποτυχημένη δημιουργία δεν χρεώνεται. Η αναζήτηση και η αρχειοθέτηση μοντέλων είναι δωρεάν.

## Αρχειοθέτηση μοντέλου

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Η τρέχουσα έκδοση Beta αρχειοθετεί το μοντέλο και απαγορεύει τη συνέχιση της χρήσης του· το `capacity_released=false` στην απόκριση υποδηλώνει ότι η αρχειοθέτηση δεν εγγυάται την απελευθέρωση χωρητικότητας μοντέλου. Η λειτουργία αρχειοθέτησης μπορεί να κληθεί επανειλημμένα και δεν θα χρεωθεί περισσότερες από μία φορές.
