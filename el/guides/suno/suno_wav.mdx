SUNO επιτρέπει την απόκτηση αρχείων μουσικής σε μορφή wav. Αυτό το έγγραφο εξηγεί τη μέθοδο διασύνδεσης με τα σχετικά API.

Η κύρια είσοδος του API είναι η παράμετρος `audio_id`, η οποία είναι το επίσημα παραγόμενο ID του τραγουδιού. Επιπλέον, υποστηρίζεται προαιρετικά η διεύθυνση `callback_url` για ασύγχρονη επιστροφή.

Εδώ, το `audio_id` που εισάγουμε είναι `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer YOUR_API_KEY",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Το αποτέλεσμα είναι το εξής:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://cdn.acedata.cloud/suno/41572926-1a7a-41bc-adb8-9431e494c144.wav"
    }
  ]
}
```

Μπορείτε να δείτε ότι το πεδίο `file_url` του `data` είναι το wav αρχείο της μουσικής που αποκτήθηκε, το οποίο είναι μια διεύθυνση CDN που μπορεί να προσπελαστεί δημόσια.

> **Σχετικά με την επιμονή του WAV συνδέσμου**
> Η πλατφόρμα θα επιμείνει να αποθηκεύει το τελικό WAV αρχείο στο Ace Data Cloud CDN πριν από την επιστροφή. Η παραπάνω διεύθυνση URL απλώς δείχνει τη μορφή της απάντησης και δεν αντιπροσωπεύει ένα πραγματικό αντικείμενο που υπάρχει μακροπρόθεσμα. Μόνο εάν η επιμονή του CDN δεν έχει ολοκληρωθεί και η αρχική διεύθυνση μέσων έχει ελεγχθεί άμεσα και μπορεί να κατέβει ένα έγκυρο WAV αρχείο, το `file_url` μπορεί να διατηρήσει αυτή τη διεύθυνση. Εάν η διεύθυνση έχει λήξει ή η επαλήθευση του αρχείου αποτύχει, το αίτημα θα επιστρέψει αποτυχία ή χρονικό όριο και δεν θα θεωρήσει τη μη κατεβάσιμη διεύθυνση ως επιτυχές αποτέλεσμα. Παρακαλώ κατεβάστε και αποθηκεύστε εγκαίρως μετά την ολοκλήρωση της εργασίας, η συγκεκριμένη περίοδος διατήρησης εξαρτάται από την τρέχουσα στρατηγική αποθήκευσης της πλατφόρμας.
