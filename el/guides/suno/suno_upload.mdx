Το SUNO μάς επιτρέπει να μεταφορτώνουμε ηχητικά αναφοράς για δευτερογενή δημιουργία. Αυτό το έγγραφο εξηγεί τη μέθοδο ενσωμάτωσης των σχετικών API.

Για κανονική μεταφόρτωση απαιτείται μόνο το `audio_url`, το οποίο είναι μια δημόσια προσβάσιμη διεύθυνση CDN ήχου. Το `mode` είναι από προεπιλογή `standard`, επομένως οι υπάρχουσες κλήσεις δεν χρειάζονται τροποποίηση. Η επιτυχημένη κανονική μεταφόρτωση καταναλώνει **0.06 Credits**· η αποτυχημένη μεταφόρτωση δεν χρεώνεται.

Το `audio_url` που εισάγουμε εδώ είναι το `https://cdn.acedata.cloud/suno_demo.mp3`, το οποίο είναι μια δημόσια προσβάσιμη διεύθυνση CDN.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Όπως φαίνεται, το `data` είναι πάντα αντικείμενο και το `audio_id` είναι το ID του τραγουδιού μετά τη μεταφόρτωση. Τα αποτελέσματα ανάλυσης όπως `lyric`, `style`, `duration`, ο τίτλος και τα URL πολυμέσων είναι προαιρετικά πεδία και ισχύει το περιεχόμενο που επιστρέφεται.

Αφού αποκτήσετε το ID του τραγουδιού, μπορείτε να καλέσετε το [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) για λειτουργίες που απαιτούν `audio_id`, όπως `upload_extend`, `upload_cover` ή δειγματοληψία διαστήματος. Εάν θέλετε να δημιουργήσετε νέα μουσική βάσει 1 έως 4 πλήρων ηχητικών αναφοράς μέσω της λειτουργίας δημιουργίας έμπνευσης Inspo, καλέστε απευθείας το `action=inspo` και περάστε τη λίστα των αρχικών δημόσιων URL ήχου· η υπηρεσία θα ολοκληρώσει αυτόματα τη μεταφόρτωση και την ανάλυση, χωρίς να χρειάζεται ο πελάτης να συνθέσει metadata ήχου.

## Μεταφόρτωση πρωτότυπου τραγουδιού για διασκευή με ιδιωτική φωνή

Όταν γίνεται διασκευή με ιδιωτική φωνή που έχει δημιουργηθεί με το `/suno/voices`, περάστε το `persona_id` αυτής της φωνής στο αίτημα κανονικής μεταφόρτωσης, ώστε να συσχετιστεί το πρωτότυπο τραγούδι με τη φωνή:

```json
{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "mode": "standard",
  "persona_id": "<声音创建接口返回的 persona_id>"
}
```

Μετά την επιτυχημένη μεταφόρτωση, χρησιμοποιήστε το επιστρεφόμενο `data.audio_id` για να καλέσετε το `/suno/audios`, ορίστε `action: "upload_cover"` και περάστε το ίδιο `persona_id`. Μη συνεχίσετε να χρησιμοποιείτε το προηγούμενο ID ήχου που δεν είχε συσχετιστεί με αυτή τη φωνή.

Το `persona_id` υποστηρίζεται μόνο για κανονική μεταφόρτωση και δεν μπορεί να χρησιμοποιηθεί ταυτόχρονα με `mode: "enhanced"`. Δεν χρειάζεται να οριστεί επιπλέον `vocal_gender`· η προτίμηση φύλου δεν μπορεί να αντικαταστήσει το ID φωνής. Η δημιουργία φωνής, η μεταφόρτωση πρωτότυπου τραγουδιού και η διασκευή πρέπει να χρησιμοποιούν το ίδιο κανάλι υπηρεσίας.

## Ενισχυμένη λειτουργία μεταφόρτωσης

> Το `audio_url` είναι η διεύθυνση εισόδου και θα παραδοθεί απευθείας στη ροή επεξεργασίας ήχου· δεν θα μεταφερθεί εκ των προτέρων από την υπηρεσία μόνιμης αποθήκευσης πολυμέσων τελικής κατάστασης. Βεβαιωθείτε ότι παραμένει δημόσια προσβάσιμο κατά τη διάρκεια επεξεργασίας της εργασίας.

Όταν η κανονική μεταφόρτωση δεν μπορεί να επεξεργαστεί ήχο που σας ανήκει ή για τον οποίο έχετε λάβει άδεια χρήσης, μπορείτε να ορίσετε το `mode` σε `enhanced`. Αυτή η λειτουργία πρέπει επίσης να παρέχει ένα `name` από 1 έως 100 χαρακτήρες και να χρησιμοποιεί ένα δημόσια προσβάσιμο HTTPS `audio_url`.

Η ενισχυμένη μεταφόρτωση χρησιμοποιεί υποχρεωτικά ασύγχρονη επεξεργασία και συνήθως απαιτεί 2 λεπτά ή περισσότερο. Η επιτυχημένη επεξεργασία καταναλώνει **1.87 Credits**· η αποτυχημένη επεξεργασία δεν χρεώνεται.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

Η διεπαφή θα επιστρέψει αμέσως `task_id` και `trace_id`. Χρησιμοποιήστε το [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) για να ελέγξετε την εργασία και, μετά την επιτυχία, διαβάστε το ID του μεταφορτωμένου ήχου από το `response.data.audio_id`. Μπορείτε επίσης να παρέχετε ένα HTTPS `callback_url` για να λαμβάνετε την τελική κατάσταση.
Το `audio_id` που λαμβάνεται από την ενισχυμένη μεταφόρτωση μπορεί να χρησιμοποιηθεί για Cover, Samples και Mashup. Η εξαγωγή συνοδείας και MIDI, ο διαχωρισμός όλων των κομματιών, καθώς και ο διαχωρισμός φωνητικών/συνοδείας ενδέχεται να εξακολουθούν να υπόκεινται σε περιορισμούς βάσει του λογαριασμού στον οποίο ανήκει ο ήχος· για λειτουργίες που δεν αναφέρονται δεν εγγυάται η χρήση μεταξύ λογαριασμών. Όσο πιο σύντομος είναι ο ήχος, τόσο υψηλότερο είναι συνήθως το ποσοστό επιτυχίας της επεξεργασίας.
