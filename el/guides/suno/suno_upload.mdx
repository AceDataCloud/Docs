Το SUNO μάς επιτρέπει να μεταφορτώνουμε αναφορικό ήχο για δευτερογενή δημιουργία· αυτό το έγγραφο εξηγεί τη μέθοδο ενσωμάτωσης του σχετικού API.

Για την κανονική μεταφόρτωση απαιτείται μόνο το `audio_url`, το οποίο είναι μια δημόσια προσβάσιμη διεύθυνση audio CDN. Το `mode` είναι από προεπιλογή `standard`, επομένως οι υπάρχουσες κλήσεις δεν χρειάζονται τροποποίηση. Η επιτυχής κανονική μεταφόρτωση καταναλώνει **0.06 Credits**· η αποτυχία μεταφόρτωσης δεν χρεώνεται.

Εδώ, το `audio_url` που εισάγουμε είναι το `https://cdn.acedata.cloud/suno_demo.mp3`, μια δημόσια προσβάσιμη διεύθυνση CDN.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Μπορείτε να δείτε ότι το `data` είναι πάντα αντικείμενο και το `audio_id` είναι το ID του τραγουδιού μετά τη μεταφόρτωση. Τα αποτελέσματα ανάλυσης, όπως `lyric`, `style`, `duration`, ο τίτλος και τα media URL, είναι προαιρετικά πεδία· οι λεπτομέρειες εξαρτώνται από το περιεχόμενο της απόκρισης.

Αφού αποκτήσετε το ID του τραγουδιού, μπορείτε μέσω του [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) να καλέσετε λειτουργίες που απαιτούν `audio_id`, όπως `upload_extend`, `upload_cover` ή δειγματοληψία εύρους. Εάν θέλετε να δημιουργήσετε νέα μουσική μέσω της λειτουργίας δημιουργίας έμπνευσης Inspo, με βάση 1 έως 4 πλήρη αναφορικά ηχητικά αρχεία, καλέστε απευθείας το `action=inspo` και περάστε τη λίστα των αρχικών δημόσιων audio URL· η υπηρεσία θα ολοκληρώσει αυτόματα τη μεταφόρτωση και την ανάλυση, χωρίς να απαιτείται από τον πελάτη η σύνθεση audio metadata.

## Βελτιωμένη λειτουργία μεταφόρτωσης

> Το `audio_url` είναι η διεύθυνση εισόδου και θα παραδοθεί απευθείας στη ροή επεξεργασίας ήχου· δεν θα μεταφερθεί εκ των προτέρων από την υπηρεσία μόνιμης αποθήκευσης τελικών media. Βεβαιωθείτε ότι είναι δημόσια προσβάσιμο κατά τη διάρκεια επεξεργασίας της εργασίας.

Όταν η κανονική μεταφόρτωση δεν μπορεί να επεξεργαστεί ήχο που σας ανήκει ή για τον οποίο έχετε λάβει άδεια χρήσης, μπορείτε να ορίσετε το `mode` σε `enhanced`. Αυτή η λειτουργία πρέπει επίσης να παρέχει ένα `name` από 1 έως 100 χαρακτήρες και να χρησιμοποιεί ένα δημόσια προσβάσιμο HTTPS `audio_url`.

Η βελτιωμένη μεταφόρτωση χρησιμοποιεί υποχρεωτικά ασύγχρονη επεξεργασία και συνήθως απαιτεί 2 λεπτά ή περισσότερο. Η επιτυχής επεξεργασία καταναλώνει **1.87 Credits**· η αποτυχία επεξεργασίας δεν χρεώνεται.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

Η διεπαφή θα επιστρέψει αμέσως τα `task_id` και `trace_id`. Χρησιμοποιήστε το [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) για να ελέγξετε την εργασία και, μετά την επιτυχία, διαβάστε το ID του μεταφορτωμένου ήχου από το `response.data.audio_id`. Μπορείτε επίσης να παρέχετε ένα HTTPS `callback_url` για να λάβετε την τελική κατάσταση.

Το `audio_id` που λαμβάνεται από τη βελτιωμένη μεταφόρτωση μπορεί να χρησιμοποιηθεί για Cover, Samples και Mashup. Η εξαγωγή συνοδευτικής μουσικής και MIDI, ο πλήρης διαχωρισμός κομματιών, καθώς και ο διαχωρισμός φωνητικών/συνοδευτικής μουσικής ενδέχεται να εξακολουθούν να περιορίζονται από τον λογαριασμό στον οποίο ανήκει ο ήχος· δεν εγγυάται η υποστήριξη χρήσης μεταξύ λογαριασμών για λειτουργίες που δεν αναφέρονται. Όσο πιο σύντομος είναι ο ήχος, τόσο υψηλότερο είναι συνήθως το ποσοστό επιτυχούς επεξεργασίας.
