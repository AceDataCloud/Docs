SUNO μας επιτρέπει να δημιουργήσουμε την νέα έκδοση Persona-v2-vox: στυλ τραγουδιστή, που διαφέρει από την παλιά έκδοση και απαιτεί πρώτα να αποκτήσουμε την τιμή παραμέτρου `vox_audio_id`. Αυτό το έγγραφο εξηγεί τη μέθοδο σύνδεσης για τη δημιουργία της νέας έκδοσης Persona-v2-vox.

Πρώτα χρειάζεται να χρησιμοποιήσουμε το API για να αποκτήσουμε την τιμή παραμέτρου `vox_audio_id`, το οποίο μπορεί να δέχεται πολλαπλές παραμέτρους εισόδου, όπως `audio_id`, `vocal_start`, `vocal_end`, που αναφέρονται στο ID του τραγουδιού και στην επιλεγμένη χρονική περίοδο.

Εδώ η `audio_id` που εισάγουμε είναι `42599b24-fb14-4cd3-a444-e15ffde3661b`.

```python
import requests

url = "https://api.acedata.cloud/suno/vox"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Μπορούμε να δούμε ότι το πεδίο `id` του `data` είναι το `vox_audio_id` που θέλουμε, και στη συνέχεια πηγαίνουμε στο [Persona API](https://platform.acedata.cloud/documents/78bb6c62-6ce0-490f-a7df-e89d80ec0583) για να δημιουργήσουμε την νέα έκδοση Persona-v2-vox: στυλ τραγουδιστή, οι συγκεκριμένες είσοδοι είναι οι εξής:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "test",
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20,
    "vox_audio_id": "24f0827e-5847-4011-b9b7-fc0b62032b65"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Μετά την κλήση, λαμβάνουμε το εξής αποτέλεσμα:

```json
{
  "success": true,
  "task_id": "e04b06a1-ff61-48e2-9fcc-15284bd18481",
  "data": {
    "persona_id": "49bef16d-6a09-49d1-8c24-a81663698b98"
  }
}
```

Στη συνέχεια, μπορούμε να δημιουργήσουμε τη νέα έκδοση Persona-v2-vox: στυλ τραγουδιστή με βάση την τιμή `persona_id` που αναφέρθηκε παραπάνω, η συγκεκριμένη μέθοδος δημιουργίας είναι ίδια με την [Σύνδεση API Δημιουργίας Τραγουδιών Suno](https://platform.acedata.cloud/documents/suno-audios-integration#%E8%87%AA%E5%AE%9A%E4%B9%89%E6%AD%8C%E6%89%8B%E9%A3%8E%E6%A0%BC%E7%94%9F%E6%88%90%E5%8A%9F%E8%83%BD), και στο τέλος μπορούμε να χρησιμοποιήσουμε το Suno Vox API για να δημιουργήσουμε τραγούδια με τη νέα έκδοση Persona-v2-vox: στυλ τραγουδιστή.
