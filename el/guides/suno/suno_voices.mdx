Το SUNO μας επιτρέπει να δημιουργούμε προσαρμοσμένους χαρακτήρες φωνής μέσω οποιουδήποτε αρχείου ήχου, υλοποιώντας κλωνοποίηση φωνής για τη δημιουργία μουσικής. Σε αντίθεση με το υπάρχον Persona API (που χρησιμοποιεί `audio_id` δημιουργημένο από το Suno), αυτό το API δέχεται ένα δημόσια προσβάσιμο `audio_url`, δηλαδή τη δική σας ηχογράφηση φωνής. Αυτό το έγγραφο εξηγεί τον τρόπο ενσωμάτωσης του API κλωνοποίησης φωνής.

## Πρώτο βήμα: Δημιουργία χαρακτήρα φωνής

Αυτό το API έχει τρεις παραμέτρους εισόδου: το `audio_url` (υποχρεωτικό), το οποίο είναι ένα δημόσια προσβάσιμο URL αρχείου ήχου σε μορφή MP3 ή WAV που περιέχει καθαρή ανθρώπινη φωνή ενός ατόμου· και τα `name` και `description` (προαιρετικά), που είναι το όνομα και η περιγραφή του χαρακτήρα φωνής.

> **Απαιτήσεις αρχείου ήχου**
> - Η μορφή ήχου πρέπει να είναι `WAV` ή `MP3`
> - Η διάρκεια ήχου πρέπει να είναι μεταξύ `10~240 δευτερολέπτων`, και συνιστάται η χρήση καθαρού υλικού ξηρής φωνής ενός ατόμου διάρκειας `30~60 δευτερολέπτων`
> - Ο ήχος πρέπει να περιέχει **καθαρή, αναγνωρίσιμη ομιλία ή τραγούδι ενός ατόμου**
> - Παρακαλούμε φροντίστε να αποφύγετε **θόρυβο περιβάλλοντος, συνοδεία, ηχώ, αντήχηση**· ολοκληρωμένα τραγούδια με συνοδεία συνήθως δεν μπορούν να περάσουν την επαλήθευση φωνητικού αποτυπώματος
> - Μην περιλαμβάνετε **πολλούς ομιλητές** ή **πολλαπλές φωνές**
> - Υλικό με πολύ χαμηλή ένταση, ασαφή ομιλία ή υπερβολικό θόρυβο ενδέχεται να οδηγήσει σε **αποτυχία κλωνοποίησης** ή **χαμηλότερη ποιότητα αποτελέσματος**
> **Περιγραφή περιορισμών χρήσης**
> - Οι χαρακτήρες φωνής που δημιουργούνται μέσω μεταφόρτωσης ήχου είναι **ιδιωτικοί πόροι**
> - Αυτός ο χαρακτήρας φωνής **δεν υποστηρίζει επαναχρησιμοποίηση μεταξύ λογαριασμών**
> - Συνιστάται να χρησιμοποιείται το συντομότερο δυνατό μετά την επιτυχή δημιουργία· η μακροχρόνια μη χρήση μπορεί να προκαλέσει **λήξη ισχύος ή μη διαθεσιμότητα**
> - Το επιστρεφόμενο `name` δημιουργείται αυτόματα από το σύστημα· παρακαλούμε χρησιμοποιήστε ως αναφορά το επιστρεφόμενο `persona_id`

> **Σε περίπτωση αποτυχίας κλήσης, δοκιμάστε πρώτα ξανά**
> Η κλωνοποίηση φωνής είναι μια εργασία με υψηλές απαιτήσεις υπολογιστικής ισχύος και, ακόμη και αν το υλικό είναι πλήρως συμβατό, υπάρχει ορισμένη πιθανότητα περιστασιακής αποτυχίας, με συχνές επιστροφές όπως
> `voices_sound_different` (η επαλήθευση φωνητικού αποτυπώματος δεν πέρασε) κ.λπ. **Αυτού του είδους η αποτυχία δεν σχετίζεται με την ποιότητα του ήχου και η επανάληψη με το ίδιο υλικό συνήθως επιτυγχάνει**,
> συνιστάται κατά την ενσωμάτωση να υλοποιήσετε 1~2 αυτόματες επαναλήψεις για αποτυχημένα αποτελέσματα. Τα αποτυχημένα αιτήματα δεν χρεώνονται.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Το παραπάνω `https://cdn.acedata.cloud/suno_demo.mp3` είναι δείγμα υλικού που μπορεί να κληθεί απευθείας (MP3, 41 δευτερόλεπτα, ξηρή φωνή ενός ατόμου).
> Εάν χρειάζεστε δείγμα σε μορφή `WAV`, μπορείτε να χρησιμοποιήσετε
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 δευτερόλεπτα, μονοφωνικό 44.1kHz).

Το αποτέλεσμα είναι το ακόλουθο:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Όπως φαίνεται, το πεδίο `persona_id` του `data` είναι το ID του δημιουργημένου χαρακτήρα φωνής. Το πεδίο `is_public` είναι πάντα `false`, επειδή οι χαρακτήρες φωνής που δημιουργούνται μέσω μεταφόρτωσης ήχου είναι ιδιωτικοί. Σημειώστε ότι το επιστρεφόμενο `name` δημιουργείται αυτόματα από το σύστημα· στη συνέχεια χρησιμοποιήστε το `persona_id` για να αναφέρεστε σε αυτόν τον χαρακτήρα φωνής.

## Δεύτερο βήμα: Χρήση του χαρακτήρα φωνής για δημιουργία μουσικής

Αφού έχουμε το ID του χαρακτήρα φωνής, μπορούμε να χρησιμοποιήσουμε το [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) για τη δημιουργία μουσικής. Ορίστε το `action` σε `generate` και το `persona_id` στο ID του χαρακτήρα φωνής που επιστράφηκε παραπάνω· το τραγούδι που θα δημιουργηθεί θα τραγουδιέται με την κλωνοποιημένη φωνή.

> **Σημείωση:** Η κλωνοποίηση φωνής υποστηρίζει μόνο μοντέλα `chirp-v4-5` και νεότερα (όπως `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), και δεν υποστηρίζει το `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Το αποτέλεσμα είναι το ακόλουθο:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

Το `persona_id` μπορεί να χρησιμοποιηθεί για δημιουργία `generate`, καθώς και για διασκευές `cover` / `upload_cover`. Κατά τον καθορισμό φωνής δεν χρειάζεται να συμπληρώνεται ταυτόχρονα το `vocal_gender`· η ομοιότητα φωνής εξακολουθεί να εξαρτάται από το υλικό αναφοράς και το αποτέλεσμα που δημιουργείται.

Οι φωνές που δημιουργούνται μέσω αυτής της διεπαφής είναι ιδιωτικοί πόροι. Πριν διασκευάσετε ένα υπάρχον τραγούδι, καλέστε πρώτα το `/suno/upload`, περνώντας το `audio_url` του πρωτότυπου τραγουδιού και το `persona_id` αυτής της φωνής· μετά την επιτυχή μεταφόρτωση, καλέστε το `/suno/audios` με το επιστρεφόμενο `data.audio_id` και το ίδιο `persona_id`:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

Η δημιουργία φωνής, η μεταφόρτωση του πρωτότυπου τραγουδιού και η διασκευή πρέπει να χρησιμοποιούν το ίδιο κανάλι υπηρεσίας. Μην επαναχρησιμοποιείτε απευθείας ID τραγουδιών που προηγουμένως δεν είχαν συσχετιστεί με αυτή την ιδιωτική φωνή· για λεπτομέρειες, δείτε [Suno μεταφόρτωση ηχητικού αναφοράς](https://platform.acedata.cloud/documents/suno-upload).
