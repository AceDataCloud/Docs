Το SUNO μας επιτρέπει να δημιουργούμε προσαρμοσμένους χαρακτήρες φωνής μέσω οποιουδήποτε αρχείου ήχου, υλοποιώντας κλωνοποίηση φωνής για παραγωγή μουσικής. Σε αντίθεση με το υπάρχον Persona API (που χρησιμοποιεί `audio_id` που δημιουργείται από το Suno), αυτό το API δέχεται ένα δημόσια προσβάσιμο `audio_url`, δηλαδή τη δική σας ηχογράφηση ανθρώπινης φωνής. Αυτό το έγγραφο εξηγεί τη μέθοδο ενσωμάτωσης του API κλωνοποίησης φωνής.

## Πρώτο βήμα: Δημιουργία χαρακτήρα φωνής

Αυτό το API έχει τρεις παραμέτρους εισόδου: `audio_url` (υποχρεωτική), η οποία είναι ένα δημόσια προσβάσιμο URL αρχείου ήχου σε μορφή MP3 ή WAV, που περιέχει καθαρή ανθρώπινη φωνή ενός ατόμου· `name` και `description` (προαιρετικές), που είναι το όνομα και η περιγραφή του χαρακτήρα φωνής.

> **Απαιτήσεις αρχείου ήχου**
> - Η μορφή ήχου πρέπει να είναι `WAV` ή `MP3`
> - Η διάρκεια του ήχου πρέπει να είναι μεταξύ `10~240 δευτερολέπτων`, συνιστάται η χρήση καθαρού υλικού ξηρής φωνής ενός ατόμου διάρκειας `30~60 δευτερολέπτων`
> - Ο ήχος πρέπει να περιέχει **καθαρή, αναγνωρίσιμη ομιλία ή τραγούδι ενός ατόμου**
> - Φροντίστε να αποφύγετε **θόρυβο υποβάθρου, συνοδεία, ηχώ, αντήχηση**· ολοκληρωμένα τραγούδια με συνοδεία συνήθως δεν μπορούν να περάσουν τον έλεγχο φωνητικού αποτυπώματος
> - Μην περιλαμβάνετε **πολλαπλούς ομιλητές** ή **πολλαπλές φωνές**
> - Υλικό με πολύ χαμηλή ένταση, ασαφή φωνή ή υπερβολικό θόρυβο μπορεί να οδηγήσει σε **αποτυχία κλωνοποίησης** ή **χαμηλότερη ποιότητα παραγόμενου αποτελέσματος**
> **Επεξήγηση περιορισμών χρήσης**
> - Οι χαρακτήρες φωνής που δημιουργούνται μέσω μεταφόρτωσης ήχου είναι **ιδιωτικοί πόροι**
> - Αυτός ο χαρακτήρας φωνής **δεν υποστηρίζει επαναχρησιμοποίηση μεταξύ λογαριασμών**
> - Συνιστάται η χρήση του αμέσως μετά την επιτυχή δημιουργία· η παρατεταμένη αχρησία μπορεί να προκαλέσει **λήξη ισχύος ή μη διαθεσιμότητα**
> - Το επιστρεφόμενο `name` δημιουργείται αυτόματα από το σύστημα· χρησιμοποιήστε το επιστρεφόμενο `persona_id` ως αναφορά

> **Παρακαλούμε επαναλάβετε πρώτα την προσπάθεια όταν η κλήση αποτύχει**
> Η κλωνοποίηση φωνής είναι εργασία εντατικής υπολογιστικής ισχύος· ακόμη και όταν το υλικό συμμορφώνεται πλήρως, υπάρχει κάποια πιθανότητα περιστασιακής αποτυχίας, με συνήθεις επιστροφές όπως
> `voices_sound_different` (ο έλεγχος φωνητικού αποτυπώματος δεν πέρασε) κ.λπ. **Αυτού του είδους η αποτυχία δεν σχετίζεται με την ποιότητα του ήχου· η επανάληψη με το ίδιο υλικό συνήθως επιτυγχάνει**,
> συνιστάται κατά την ενσωμάτωση να υλοποιήσετε 1~2 αυτόματες επαναλήψεις για αποτυχημένα αποτελέσματα. Τα αποτυχημένα αιτήματα δεν χρεώνονται.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Το παραπάνω `https://cdn.acedata.cloud/suno_demo.mp3` είναι υλικό παραδείγματος που μπορεί να κληθεί απευθείας (MP3, 41 δευτερόλεπτα, ξηρή φωνή ενός ατόμου).
> Εάν χρειάζεστε παράδειγμα σε μορφή `WAV`, μπορείτε να χρησιμοποιήσετε
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 δευτερόλεπτα, μονοφωνικό 44.1kHz).

Το αποτέλεσμα είναι το εξής:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Μπορείτε να δείτε ότι το πεδίο `persona_id` του `data` είναι το ID του δημιουργημένου χαρακτήρα φωνής. Το πεδίο `is_public` είναι πάντα `false`, επειδή οι χαρακτήρες φωνής που δημιουργούνται μέσω μεταφόρτωσης ήχου είναι ιδιωτικοί. Σημειώστε ότι το επιστρεφόμενο `name` δημιουργείται αυτόματα από το σύστημα· στη συνέχεια, χρησιμοποιήστε το `persona_id` για να αναφερθείτε σε αυτόν τον χαρακτήρα φωνής.

## Δεύτερο βήμα: Χρήση χαρακτήρα φωνής για παραγωγή μουσικής

Αφού έχουμε το ID του χαρακτήρα φωνής, μπορούμε να χρησιμοποιήσουμε το [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) για παραγωγή μουσικής. Ορίστε το `action` σε `generate` και το `persona_id` στο ID του χαρακτήρα φωνής που επιστράφηκε παραπάνω· το παραγόμενο τραγούδι θα τραγουδηθεί με την κλωνοποιημένη φωνή.

> **Σημείωση:** Η κλωνοποίηση φωνής υποστηρίζει μόνο μοντέλα `chirp-v4-5` και νεότερα (όπως `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`) και δεν υποστηρίζει το `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Το αποτέλεσμα είναι το εξής:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

Μπορείτε να δείτε ότι το παραγόμενο τραγούδι τραγουδιέται με την κλωνοποιημένη φωνή. Το `persona_id` μπορεί επίσης να χρησιμοποιηθεί με την ενέργεια `cover`, για την επανεκτέλεση υπαρχόντων τραγουδιών με την κλωνοποιημένη φωνή.
