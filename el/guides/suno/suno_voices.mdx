---
title: "Suno ήχου κλωνοποίησης API διασύνδεση οδηγίες"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

Το SUNO μας επιτρέπει να δημιουργούμε προσαρμοσμένους φωνητικούς χαρακτήρες μέσω οποιουδήποτε αρχείου ήχου, επιτυγχάνοντας κλωνοποίηση φωνής για τη μουσική παραγωγή. Σε αντίθεση με το υπάρχον Persona API (χρησιμοποιώντας το `audio_id` που δημιουργήθηκε από το Suno), αυτή η API δέχεται μια δημόσια προσβάσιμη `audio_url`, δηλαδή την ηχογράφηση της δικής σας φωνής. Αυτό το έγγραφο εξηγεί τη μέθοδο διασύνδεσης της φωνητικής κλωνοποίησης API.

Αυτή η API έχει τρεις παραμέτρους εισόδου: `audio_url` (υποχρεωτική), που είναι μια δημόσια προσβάσιμη διεύθυνση URL αρχείου ήχου σε μορφή MP3 ή WAV, η οποία περιέχει καθαρή φωνή ενός ατόμου; `name` και `description` (προαιρετικά), που είναι το όνομα και η περιγραφή του φωνητικού χαρακτήρα.

**Απαιτήσεις αρχείου ήχου:**

- Μορφή: MP3 ή WAV
- Διάρκεια: τουλάχιστον 10 δευτερόλεπτα
- Περιεχόμενο: καθαρή φωνή ενός ατόμου, με όσο το δυνατόν λιγότερο θόρυβο φόντου ή μουσική

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://example.com/my-vocal-recording.mp3",
  "name": "My Voice",
  "description": "A warm male voice"
}'
```

Το αποτέλεσμα είναι το εξής:

```json
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dde0be60-5280-4bd2-89a0-4020ddd3db52",
    "name": "My Voice",
    "is_public": false
  }
}
```

Μπορείτε να δείτε ότι το πεδίο `persona_id` του `data` είναι το ID του δημιουργηθέντος φωνητικού χαρακτήρα. Το πεδίο `is_public` είναι πάντα `false`, καθώς οι φωνητικοί χαρακτήρες που δημιουργούνται μέσω της ανάρτησης ήχου είναι ιδιωτικοί.

Αφού αποκτήσουμε το ID του φωνητικού χαρακτήρα, μπορούμε να χρησιμοποιήσουμε την [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) για τη μουσική παραγωγή. Ορίστε το `action` σε `vox` και το `persona_id` στην τιμή που επιστράφηκε παραπάνω, και το παραγόμενο τραγούδι θα χρησιμοποιεί την κλωνοποιημένη φωνή για την εκτέλεση.
