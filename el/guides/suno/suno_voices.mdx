Το SUNO μάς επιτρέπει να δημιουργούμε προσαρμοσμένους χαρακτήρες φωνής μέσω οποιουδήποτε αρχείου ήχου, υλοποιώντας κλωνοποίηση φωνής για δημιουργία μουσικής. Σε αντίθεση με το υπάρχον Persona API (που χρησιμοποιεί το `audio_id` που δημιουργείται από το Suno), αυτό το API δέχεται ένα δημόσια προσβάσιμο `audio_url`, δηλαδή τη δική σας ηχογράφηση ανθρώπινης φωνής. Αυτό το έγγραφο εξηγεί τη μέθοδο ενσωμάτωσης του API κλωνοποίησης φωνής.

Στη διαδρομή δημιουργίας που υποστηρίζει έλεγχο διαθεσιμότητας χροιάς, μπορείτε να χρησιμοποιήσετε την αρχική εφαρμογή και την ταυτότητα του καλούντος για να περάσετε το `persona_id` από το αποτέλεσμα δημιουργίας στο `POST /suno/availability`. Όταν ο συσχετισμένος λογαριασμός είναι online, επιστρέφεται `data.available=true`, ενώ όταν επιβεβαιώνεται ότι είναι offline, επιστρέφεται `data.available=false`. [Οδηγός ελέγχου διαθεσιμότητας χροιάς](https://platform.acedata.cloud/documents/suno-availability-integration)

## Βήμα πρώτο: Δημιουργία χαρακτήρα φωνής

Χρέωση: Μετά την επιτυχή δημιουργία του χαρακτήρα φωνής, η τυπική χρέωση για κάθε αίτημα είναι **0.15 Credits**. Οι ισχύουσες εκπτώσεις κατανάλωσης υπόκεινται στον πραγματικό λογαριασμό χρέωσης και τα αποτυχημένα αιτήματα δεν χρεώνονται.

Αυτό το API έχει τρεις παραμέτρους εισόδου: `audio_url` (υποχρεωτικό), το οποίο είναι ένα URL δημόσια προσβάσιμου αρχείου ήχου σε μορφή MP3 ή WAV που περιέχει καθαρή ανθρώπινη φωνή ενός ατόμου· `name` και `description` (προαιρετικά), που είναι το όνομα και η περιγραφή του χαρακτήρα φωνής.

> **Απαιτήσεις αρχείου ήχου**
> - Η μορφή ήχου πρέπει να είναι `WAV` ή `MP3`
> - Η διάρκεια του ήχου πρέπει να είναι μεταξύ `10~240 δευτερολέπτων`, ενώ συνιστάται καθαρό υλικό ξηρής φωνής ενός ατόμου διάρκειας `30~60 δευτερολέπτων`
> - Ο ήχος θα πρέπει να περιέχει **καθαρή, αναγνωρίσιμη ομιλία ή τραγούδι ενός ατόμου**
> - Φροντίστε να αποφεύγετε **θόρυβο υποβάθρου, συνοδεία, ηχώ, αντήχηση**· πλήρη τραγούδια με συνοδεία συνήθως δεν μπορούν να περάσουν την επαλήθευση φωνητικού αποτυπώματος
> - Μην περιλαμβάνετε **πολλούς ομιλητές** ή **πολλαπλές φωνές**
> - Υλικό με πολύ χαμηλή ένταση, ασαφή ομιλία ή υπερβολικό θόρυβο μπορεί να οδηγήσει σε **αποτυχία κλωνοποίησης** ή **χαμηλότερη ποιότητα αποτελέσματος**
> **Επεξήγηση περιορισμών χρήσης**
> - Οι χαρακτήρες φωνής που δημιουργούνται μέσω μεταφόρτωσης ήχου είναι **ιδιωτικοί πόροι**
> - Αυτός ο χαρακτήρας φωνής **δεν υποστηρίζει επαναχρησιμοποίηση μεταξύ λογαριασμών**
> - Συνιστάται να τον χρησιμοποιήσετε το συντομότερο δυνατό μετά την επιτυχή δημιουργία· η παρατεταμένη αχρησία μπορεί να προκαλέσει **λήξη ισχύος ή μη διαθεσιμότητα**
> - Το επιστρεφόμενο `name` δημιουργείται αυτόματα από το σύστημα· βασιστείτε στο επιστρεφόμενο `persona_id`

> **Χειρισμός αποτυχιών σύμφωνα με τη σαφή ένδειξη επανάληψης**
> Το `retryable` στο αντικείμενο σφάλματος είναι προαιρετικό πεδίο boolean. Όταν το `error.retryable` είναι `true`, υποδηλώνει ότι αυτή η αποτυχία επιτρέπει νέα υποβολή αργότερα με το ίδιο υλικό και τις ίδιες παραμέτρους. Η ρητά μη αποδεκτή υπερφόρτωση υπηρεσίας ή ορισμένες προσωρινές αποτυχίες επαλήθευσης φωνητικού αποτυπώματος μπορεί να φέρουν αυτή την ένδειξη· συνιστάται η χρήση διαστημάτων αναμονής με εκθετική αύξηση και ο περιορισμός του αριθμού επαναλήψεων.
> Όταν το `retryable` είναι `false` ή το πεδίο λείπει, μην επαναλαμβάνετε αυτόματα το αίτημα μόνο βάσει HTTP 500, `busy` ή του κειμένου σφάλματος. Προβλήματα μορφής, διάρκειας, καθαρότητας, διπλών ηχογραφήσεων και ελέγχου περιεχομένου πρέπει πρώτα να διορθωθούν· όταν η υποβολή λήγει χρονικά, η σύνδεση διακόπτεται ή το αποτέλεσμα δημιουργίας δεν είναι σαφές, θα πρέπει να χρησιμοποιείται κατά προτεραιότητα το αρχικό `task_id` για αναζήτηση της εργασίας, ώστε να αποφεύγεται η διπλή δημιουργία χροιάς. Τα αποτυχημένα αιτήματα δεν χρεώνονται και τα επιτυχημένα αιτήματα επανάληψης χρεώνονται σύμφωνα με τους κανονικούς κανόνες.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Το παραπάνω `https://cdn.acedata.cloud/suno_demo.mp3` είναι υλικό παραδείγματος που μπορεί να κληθεί απευθείας (MP3, 41 δευτερόλεπτα, ξηρή φωνή ενός ατόμου).
> Εάν χρειάζεστε παράδειγμα σε μορφή `WAV`, μπορείτε να χρησιμοποιήσετε
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 δευτερόλεπτα, μονοφωνικό 44.1kHz).

Το αποτέλεσμα είναι το εξής:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Όπως φαίνεται, το πεδίο `persona_id` του `data` είναι το ID του δημιουργημένου χαρακτήρα φωνής. Το πεδίο `is_public` είναι πάντα `false`, επειδή οι χαρακτήρες φωνής που δημιουργούνται μέσω μεταφόρτωσης ήχου είναι ιδιωτικοί. Σημειώστε ότι το επιστρεφόμενο `name` δημιουργείται αυτόματα από το σύστημα· στη συνέχεια χρησιμοποιήστε το `persona_id` για να αναφερθείτε σε αυτόν τον χαρακτήρα φωνής.

## Βήμα δεύτερο: Χρήση του χαρακτήρα φωνής για δημιουργία μουσικής

Αφού αποκτήσουμε το ID του χαρακτήρα φωνής, μπορούμε να χρησιμοποιήσουμε το [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) για δημιουργία μουσικής. Ορίστε το `action` σε `generate` και το `persona_id` στο ID του χαρακτήρα φωνής που επιστράφηκε παραπάνω· τα παραγόμενα τραγούδια θα τραγουδιούνται με την κλωνοποιημένη φωνή.

> **Σημείωση:** Η κλωνοποίηση φωνής υποστηρίζει μόνο μοντέλα `chirp-v4-5` και νεότερα (όπως `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`) και δεν υποστηρίζει το `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Το αποτέλεσμα είναι το εξής:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

Το `persona_id` μπορεί να χρησιμοποιηθεί για δημιουργία με `generate`, καθώς και για διασκευές `cover` / `upload_cover`. Δεν χρειάζεται να συμπληρώνετε ταυτόχρονα το `vocal_gender` κατά τον καθορισμό φωνής· η ομοιότητα φωνής εξακολουθεί να εξαρτάται από το υλικό αναφοράς και το παραγόμενο αποτέλεσμα.

Οι φωνές που δημιουργούνται μέσω αυτής της διεπαφής είναι ιδιωτικοί πόροι. Πριν διασκευάσετε ένα υπάρχον τραγούδι, καλέστε πρώτα το `/suno/upload`, περνώντας το `audio_url` του αρχικού τραγουδιού και το `persona_id` αυτής της φωνής· μετά την επιτυχή μεταφόρτωση, καλέστε το `/suno/audios` με το επιστρεφόμενο `data.audio_id` και το ίδιο `persona_id`:
```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

Η δημιουργία φωνής, η μεταφόρτωση του πρωτότυπου τραγουδιού και η διασκευή πρέπει να χρησιμοποιούν το ίδιο κανάλι υπηρεσίας. Μην επαναχρησιμοποιείτε απευθείας ένα ID τραγουδιού που προηγουμένως δεν είχε συσχετιστεί με αυτή την ιδιωτική φωνή· για λεπτομέρειες, δείτε [Αναφορά ήχου μεταφόρτωσης Suno](https://platform.acedata.cloud/documents/suno-upload).
