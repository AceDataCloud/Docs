Η SUNO μας επιτρέπει να δημιουργούμε προσαρμοσμένους χαρακτήρες φωνής μέσω οποιουδήποτε αρχείου ήχου, πραγματοποιώντας κλωνοποίηση φωνής για τη δημιουργία μουσικής. Σε αντίθεση με το υπάρχον Persona API (που χρησιμοποιεί το `audio_id` που δημιουργείται από το Suno), αυτό το API δέχεται ένα δημόσια προσβάσιμο `audio_url`, δηλαδή τη δική σας ηχογράφηση φωνής. Αυτό το έγγραφο εξηγεί τον τρόπο ενσωμάτωσης του API κλωνοποίησης φωνής.

## Βήμα 1: Δημιουργία Χαρακτήρα Φωνής

Το API έχει τρεις παραμέτρους εισόδου: `audio_url` (υποχρεωτικό), που είναι ένα δημόσια προσβάσιμο URL αρχείου ήχου σε μορφή MP3 ή WAV, το οποίο περιέχει καθαρή φωνή ενός ατόμου· `name` και `description` (προαιρετικά), που είναι το όνομα και η περιγραφή του χαρακτήρα φωνής.

**Απαιτήσεις αρχείου ήχου:**
- Μορφή: MP3 ή WAV
- Διάρκεια: τουλάχιστον 10 δευτερόλεπτα
- Περιεχόμενο: καθαρή φωνή ενός ατόμου, με ελάχιστο θόρυβο υποβάθρου ή μουσική

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

Το αποτέλεσμα είναι:

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

Όπως φαίνεται, το πεδίο `persona_id` μέσα στο `data` είναι το ID του δημιουργημένου χαρακτήρα φωνής. Το πεδίο `is_public` είναι πάντα `false`, επειδή οι χαρακτήρες φωνής που δημιουργούνται μέσω ανέβασματος ήχου είναι ιδιωτικοί.

## Βήμα 2: Χρήση Χαρακτήρα Φωνής για Δημιουργία Μουσικής

Αφού έχουμε το ID του χαρακτήρα φωνής, μπορούμε να χρησιμοποιήσουμε το [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) για τη δημιουργία μουσικής. Ορίζουμε το `action` σε `generate` και το `persona_id` στο παραπάνω επιστρεφόμενο ID χαρακτήρα φωνής· το τραγούδι που θα παραχθεί θα ερμηνευτεί με την κλωνοποιημένη φωνή.

> **Σημείωση:** Η κλωνοποίηση φωνής υποστηρίζεται μόνο από τα μοντέλα `chirp-v4-5` και νεότερα (όπως `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), δεν υποστηρίζεται από το `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

Το αποτέλεσμα είναι:

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

Όπως φαίνεται, το παραγόμενο τραγούδι ερμηνεύεται με την κλωνοποιημένη φωνή. Το `persona_id` μπορεί επίσης να χρησιμοποιηθεί σε συνδυασμό με τη δράση `cover` για να γίνει επανεκτέλεση υπαρχόντων τραγουδιών με την κλωνοποιημένη φωνή.
