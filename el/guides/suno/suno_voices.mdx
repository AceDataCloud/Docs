Το SUNO μας επιτρέπει να δημιουργούμε προσαρμοσμένους χαρακτήρες φωνής μέσω οποιουδήποτε αρχείου ήχου, επιτυγχάνοντας κλωνοποίηση φωνής για παραγωγή μουσικής. Σε αντίθεση με το υπάρχον Persona API (που χρησιμοποιεί το `audio_id` που δημιουργείται από το Suno), αυτό το API δέχεται ένα δημόσια προσβάσιμο `audio_url`, δηλαδή τη δική σας ηχογράφηση φωνής. Αυτό το έγγραφο εξηγεί πώς να ενσωματώσετε το API κλωνοποίησης φωνής.

## Βήμα 1: Δημιουργία Χαρακτήρα Φωνής

Αυτό το API έχει τρεις παραμέτρους εισόδου: `audio_url` (υποχρεωτικό), που είναι ένα δημόσια προσβάσιμο URL αρχείου ήχου σε μορφή MP3 ή WAV, που περιέχει καθαρή φωνή ενός ατόμου· `name` και `description` (προαιρετικά), που είναι το όνομα και η περιγραφή του χαρακτήρα φωνής.

**Απαιτήσεις αρχείου ήχου:**
- Μορφή: MP3 ή WAV
- Διάρκεια: τουλάχιστον 10 δευτερόλεπτα
- Περιεχόμενο: καθαρή φωνή ενός ατόμου, με ελάχιστο θόρυβο υποβάθρου ή μουσική

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "http://cos.aitutu.cc/mp4/ru-user-voice.mp3",
  "name": "RU User Voice Test",
  "description": "用户语音录音示例"
}'
```

Το αποτέλεσμα είναι:

```json
{
  "success": true,
  "task_id": "b9150e51-d87c-4556-a55e-100947a63bdf",
  "data": {
    "persona_id": "e95013f8-eaee-4741-a42f-1d559a9d0b2b",
    "name": "RU User Voice Test",
    "is_public": false
  }
}
```

Όπως βλέπετε, το πεδίο `persona_id` μέσα στο `data` είναι το ID του δημιουργημένου χαρακτήρα φωνής. Το πεδίο `is_public` είναι πάντα `false`, επειδή οι χαρακτήρες φωνής που δημιουργούνται μέσω ανέβασμα αρχείου είναι ιδιωτικοί.

## Βήμα 2: Χρήση Χαρακτήρα Φωνής για Παραγωγή Μουσικής

Αφού έχετε το ID του χαρακτήρα φωνής, μπορείτε να χρησιμοποιήσετε το [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) για παραγωγή μουσικής. Ορίστε το `action` σε `generate` και το `persona_id` στο ID του χαρακτήρα φωνής που λάβατε παραπάνω. Το τραγούδι που θα παραχθεί θα τραγουδηθεί με την κλωνοποιημένη φωνή.

> **Σημείωση:** Η κλωνοποίηση φωνής υποστηρίζεται μόνο από τα μοντέλα `chirp-v4-5` και νεότερα (όπως `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), όχι από το `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "e95013f8-eaee-4741-a42f-1d559a9d0b2b"
}'
```

Το αποτέλεσμα είναι:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn1.suno.ai/16463960-077c-4700-bbb3-3c7897b943d3.mp3",
      "image_url": "https://cdn2.suno.ai/image_16463960-077c-4700-bbb3-3c7897b943d3.jpeg",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

Όπως βλέπετε, το παραγόμενο τραγούδι τραγουδιέται με την κλωνοποιημένη φωνή. Το `persona_id` μπορεί επίσης να χρησιμοποιηθεί με τη δράση `cover` για να ξανατραγουδήσετε υπάρχοντα τραγούδια με την κλωνοποιημένη φωνή.
