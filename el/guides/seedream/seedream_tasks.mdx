Η κύρια λειτουργία του SeeDream Tasks API είναι να ερωτά την κατάσταση εκτέλεσης ενός έργου μέσω του ID έργου που έχει παραχθεί από το SeeDream Images Generation API.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες διασύνδεσης του SeeDream Tasks API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του SeeDream Tasks API, μπορείτε εύκολα να ελέγξετε την κατάσταση εκτέλεσης των έργων του SeeDream Images Generation API.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το SeeDream Images Generation API, πρώτα επισκεφθείτε την [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να ζητήσετε ξεχωριστά για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν; όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό σας υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [SeeDream Images Generation API →](https://platform.acedata.cloud/documents/seedream-images)

## Παράδειγμα Αίτησης

Το SeeDream Tasks API μπορεί να χρησιμοποιηθεί για να ελέγξει τα αποτελέσματα του SeeDream Images Generation API. Για το πώς να χρησιμοποιήσετε το SeeDream Images Generation API, ανατρέξτε στην τεκμηρίωση [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images-integration).

Θα χρησιμοποιήσουμε ένα παράδειγμα με το ID έργου που επιστρέφει η υπηρεσία SeeDream Images Generation API. Ας υποθέσουμε ότι έχουμε ένα ID έργου: 20068983-0cc9-4c6a-aeb6-9c6a3c668be0, και στη συνέχεια θα δείξουμε πώς να το περάσουμε.

### Ρύθμιση Επικεφαλίδων Αίτησης και Σώματος Αίτησης

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `id`: το ID του έργου που έχει ανέβει.
- `action`: ο τρόπος λειτουργίας του έργου.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/seedream/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "a6e0d456-189b-4c78-9232-2fe72166ab39",
  "action": "retrieve"
}'
```

### Παράδειγμα Απόκρισης

Αφού η αίτηση είναι επιτυχής, το API θα επιστρέψει τις λεπτομέρειες του έργου εδώ. Για παράδειγμα:

```json
{
  "success": true,
  "task_id": "84d1544a-9043-4dde-a98b-e889dacd75f6",
  "trace_id": "176acf03-7ca7-4fc6-85db-e3724d4f59eb",
  "data": [
    {
      "prompt": "a white siamese cat",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/6e5f9085-cc4a-4801-b77b-31550129ff19.jpg"
    }
  ]
}
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, τα οποία περιγράφονται ως εξής:

- `success`, η κατάσταση του έργου δημιουργίας βίντεο αυτή τη στιγμή.
- `task_id`, το ID του έργου δημιουργίας βίντεο αυτή τη στιγμή.
- `trace_id`, το ID παρακολούθησης του έργου δημιουργίας βίντεο αυτή τη στιγμή.
- `data`, η λίστα των αποτελεσμάτων του έργου δημιουργίας εικόνας αυτή τη στιγμή.
  - `image_url`, ο σύνδεσμος του έργου δημιουργίας εικόνας αυτή τη στιγμή.
  - `prompt`, η προτροπή.
  - `size`: η ανάλυση της παραγόμενης εικόνας.

- `items`, όλες οι λεπτομέρειες των μαζικών εργασιών. Είναι ένας πίνακας, κάθε στοιχείο του πίνακα έχει την ίδια μορφή με το αποτέλεσμα της ερώτησης για μία μόνο εργασία.

Κάθε αντικείμενο εργασίας στο μαζικό αποτέλεσμα έχει επίσης τα παρακάτω πεδία χρονομέτρησης.

- `created_at`, η ώρα δημιουργίας της εργασίας, Unix timestamp (δευτερόλεπτα, κινητή).
- `started_at`, η ώρα έναρξης εκτέλεσης της εργασίας, Unix timestamp (δευτερόλεπτα, κινητή).
- `finished_at`, η ώρα ολοκλήρωσης της εργασίας, Unix timestamp (δευτερόλεπτα, κινητή). Αν η εργασία δεν έχει ολοκληρωθεί, αυτό το πεδίο δεν επιστρέφεται.
- `elapsed`, ο χρόνος εκτέλεσης της εργασίας, μονάδα σε δευτερόλεπτα (κινητή, διατηρεί 3 δεκαδικά). Αν η εργασία δεν έχει ολοκληρωθεί, αυτό το πεδίο δεν επιστρέφεται.

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα σφάλματος

}
