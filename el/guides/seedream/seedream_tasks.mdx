Η κύρια λειτουργία του SeeDream Tasks API είναι να ερωτά την κατάσταση εκτέλεσης ενός έργου μέσω του ID έργου που έχει παραχθεί από το SeeDream Images Generation API.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες διασύνδεσης του SeeDream Tasks API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του SeeDream Tasks API, μπορείτε εύκολα να ελέγξετε την κατάσταση εκτέλεσης των έργων του SeeDream Images Generation API.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το SeeDream Tasks API, πρέπει πρώτα να επισκεφθείτε τη σελίδα αίτησης [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images) για να ζητήσετε την αντίστοιχη υπηρεσία, και στη συνέχεια να αντιγράψετε το ID έργου του SeeDream Images Generation API, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" class="m-auto"></p>

Τέλος, επισκεφθείτε τη σελίδα Tasks API [SeeDream Tasks API](https://platform.acedata.cloud/documents/seedream-tasks) για να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![Σελίδα Αίτησης](https://cdn.acedata.cloud/rci31i.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη [σελίδα σύνδεσης](https://platform.acedata.cloud) για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις, ώστε να μπορείτε να χρησιμοποιήσετε δωρεάν αυτό το API.

## Παράδειγμα Αίτησης

Το SeeDream Tasks API μπορεί να χρησιμοποιηθεί για να ελέγξει τα αποτελέσματα του SeeDream Images Generation API. Για πληροφορίες σχετικά με το πώς να χρησιμοποιήσετε το SeeDream Images Generation API, ανατρέξτε στο έγγραφο [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images-integration).

### Ρύθμιση Επικεφαλίδων και Σώματος Αίτησης

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε απαντήσεις σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `id`: το ID του έργου που έχει ανέβει.
- `action`: ο τρόπος λειτουργίας του έργου.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/seedream/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "a6e0d456-189b-4c78-9232-2fe72166ab39",
  "action": "retrieve"
}'
```

### Παράδειγμα Απόκρισης

Αφού η αίτηση είναι επιτυχής, το API θα επιστρέψει τις λεπτομέρειες αυτού του έργου. Για παράδειγμα:

```json
{
  "success": true,
  "task_id": "84d1544a-9043-4dde-a98b-e889dacd75f6",
  "trace_id": "176acf03-7ca7-4fc6-85db-e3724d4f59eb",
  "data": [
    {
      "prompt": "a white siamese cat",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/6e5f9085-cc4a-4801-b77b-31550129ff19.jpg"
    }
  ]
}
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, τα οποία περιγράφονται ως εξής:

- `success`, η κατάσταση του έργου δημιουργίας βίντεο.
- `task_id`, το ID του έργου δημιουργίας βίντεο.
- `trace_id`, το ID παρακολούθησης του έργου δημιουργίας βίντεο.
- `data`, η λίστα των αποτελεσμάτων του έργου δημιουργίας εικόνας.
  - `image_url`, ο σύνδεσμος του έργου δημιουργίας εικόνας.
  - `prompt`, η προτροπή.
  - `size`: η ανάλυση της παραγόμενης εικόνας.

## Λειτουργία Μαζικής Ερώτησης

**Request Body** περιλαμβάνει:

- `ids`: τον πίνακα των ID έργων που έχουν ανέβει.
- `action`: ο τρόπος λειτουργίας του έργου.

## Σφάλματα

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
