Αυτό το άρθρο θα παρουσιάσει μια μέθοδο σύνδεσης με το API Δημιουργίας Εικόνων SeeDream, το οποίο μπορεί να δημιουργήσει εικόνες της επίσημης SeeDream μέσω εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [API Δημιουργίας Εικόνων SeeDream](https://platform.acedata.cloud/documents/seedream-images) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τη λέξη-κλειδί `prompt`, τη δράση `action`, και τις διαστάσεις της εικόνας `size`, για να λάβετε το επεξεργασμένο αποτέλεσμα. Πρώτα, πρέπει να περάσετε ένα πεδίο `action`, του οποίου η τιμή είναι `generate`, και στη συνέχεια πρέπει να εισάγουμε τη λέξη-κλειδί, οι λεπτομέρειες είναι οι εξής:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `prompt`: λέξη-κλειδί.
- `model`: μοντέλο δημιουργίας, προεπιλογή `doubao-seedream-4.0`.
- `image`: πληροφορίες εικόνας εισόδου, υποστηρίζει URL ή κωδικοποίηση Base64. Εδώ, τα `doubao-seedream-4.5`, `doubao-seedream-4.0` υποστηρίζουν είσοδο με μία ή περισσότερες εικόνες, ενώ τα `doubao-seededit-3.0-i2i` υποστηρίζουν μόνο μία εικόνα, και τα `doubao-seededit-3.0-t2i` δεν υποστηρίζουν αυτή την παράμετρο.
- `size`: καθορίζει τις διαστάσεις της παραγόμενης εικόνας, υποστηρίζει τους εξής δύο τρόπους, δεν μπορούν να συνδυαστούν. Τρόπος 1 | Καθορίστε την ανάλυση της παραγόμενης εικόνας και περιγράψτε την αναλογία πλάτους-ύψους, το σχήμα ή τη χρήση της εικόνας στη λέξη-κλειδί, τελικά το μοντέλο θα κρίνει το μέγεθος της παραγόμενης εικόνας. Τρόπος 2 | Καθορίστε τις τιμές πλάτους και ύψους σε pixel: προεπιλεγμένη τιμή: `2048x2048`, η προεπιλεγμένη τιμή διαφέρει ανάλογα με το μοντέλο.
- `seed`: σπόρος τυχαίων αριθμών, χρησιμοποιείται για τον έλεγχο της τυχαιότητας του περιεχομένου που παράγει το μοντέλο. Το εύρος τιμών είναι [-1, 2147483647]. Μόνο τα `doubao-seedream-3.0-t2i`, `doubao-seededit-3.0-i2i` υποστηρίζουν αυτή την παράμετρο.
- `sequential_image_generation`: ομάδα εικόνων: μια ομάδα σχετικών εικόνων που δημιουργούνται με βάση το περιεχόμενο που εισάγατε. Μόνο τα `doubao-seedream-4.5`, `doubao-seedream-4.0` υποστηρίζουν αυτή την παράμετρο, προεπιλογή `disabled`.
- `stream`: ελέγχει αν θα ενεργοποιηθεί η λειτουργία ροής εξόδου. Μόνο τα `doubao-seedream-4.5`, `doubao-seedream-4.0` υποστηρίζουν αυτή την παράμετρο, προεπιλογή `false`.
- `guidance_scale`: βαθμός συμφωνίας του αποτελέσματος του μοντέλου με τη λέξη-κλειδί, η ελευθερία της παραγόμενης εικόνας, γνωστή και ως βάρος κειμένου; όσο μεγαλύτερη είναι η τιμή, τόσο μικρότερη είναι η ελευθερία του μοντέλου και τόσο μεγαλύτερη είναι η συσχέτιση με τη λέξη-κλειδί του χρήστη. Το εύρος τιμών είναι: [1, 10]. Η προεπιλεγμένη τιμή για το `doubao-seedream-3.0-t2i` είναι 2.5, για το `doubao-seededit-3.0-i2i` είναι 5.5, οι άλλες δεν υποστηρίζουν.
- `response_format`: καθορίζει τη μορφή επιστροφής της παραγόμενης εικόνας. Προεπιλογή είναι `url`, υποστηρίζει επίσης `b64_json`.
- `watermark`: αν θα προστεθεί υδατογράφημα στην παραγόμενη εικόνα. Προεπιλογή είναι `true`.
- `callback_url`: το URL στο οποίο χρειάζεστε την επιστροφή αποτελεσμάτων.

Αφού επιλέξετε, μπορείτε να δείτε ότι στα δεξιά έχει παραχθεί ο αντίστοιχος κώδικας, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "success": true,
  "task_id": "25027ba3-0430-4a1b-91c8-d2297f19ba73",
  "trace_id": "8043a9e9-692f-43b0-82f7-5890f798be38",
  "data": [
    {
      "prompt": "a white siamese cat",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/3c060029-69b1-406f-a957-fcd55ddc9386.jpg"
    }
  ]
}
```

Η επιστροφή αποτελέσματος περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `success`, η κατάσταση της τρέχουσας εργασίας δημιουργίας βίντεο.
- `task_id`, το ID της τρέχουσας εργασίας δημιουργίας βίντεο.
- `trace_id`, το ID παρακολούθησης της τρέχουσας εργασίας δημιουργίας βίντεο.
- `data`, η λίστα αποτελεσμάτων της τρέχουσας εργασίας δημιουργίας εικόνας.
  - `image_url`, ο σύνδεσμος της τρέχουσας εργασίας δημιουργίας εικόνας.
  - `prompt`, λέξη-κλειδί.
  - `size`: τα pixel της παραγόμενης εικόνας.

Μπορείτε να δείτε ότι έχουμε λάβει ικανοποιητικές πληροφορίες εικόνας, απλώς πρέπει να αποκτήσουμε την παραγόμενη εικόνα SeeDream μέσω της διεύθυνσης URL της εικόνας στο `data`.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο παρακάτω κώδικας CURL:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-4-0-250828",
  "prompt": "a white siamese cat"
}'
```

## Επεξεργασία Εικόνας

Εάν θέλετε να επεξεργαστείτε μια συγκεκριμένη εικόνα, πρώτα η παράμετρος `image` πρέπει να περιλαμβάνει τον σύνδεσμο της εικόνας που χρειάζεται επεξεργασία.

- model: το μοντέλο που χρησιμοποιείται για την επεξεργασία της εικόνας, αυτή η εργασία υποστηρίζει προς το παρόν τα `doubao-seedream-4.5`, `doubao-seedream-4.0` που υποστηρίζουν είσοδο με μία ή περισσότερες εικόνες, ενώ το `doubao-seededit-3.0-i2i` υποστηρίζει μόνο μία εικόνα.
- image: ανεβάστε την εικόνα που χρειάζεται επεξεργασία, μία ή περισσότερες.

Το παράδειγμα συμπλήρωσης είναι το εξής:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Ο αντίστοιχος κώδικας:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```json

    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Διατηρήστε τη στάση του μοντέλου και το σχήμα του ρευστού ενδύματος αμετάβλητο. Αλλάξτε το υλικό του ρούχου από ασημένιο μέταλλο σε εντελώς διαφανές νερό (ή γυαλί). Μέσα από τη ροή του υγρού, οι λεπτομέρειες του δέρματος του μοντέλου είναι ορατές. Το εφέ φωτός και σκιάς μετατοπίζεται από την αντανάκλαση στη διάθλαση.",
            "size": "2048x2048",

```

Μπορείτε να δείτε ότι το αποτέλεσμα είναι η επεξεργασία της αρχικής εικόνας, το αποτέλεσμα είναι παρόμοιο με το παραπάνω κείμενο.

## Ασύγχρονη κλήση

Δεδομένου ότι ο χρόνος δημιουργίας εικόνας του SeeDream Images Generation API είναι σχετικά μεγάλος, χρειάζεται περίπου 1-2 λεπτά. Εάν το API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος. Έτσι, αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη κλήση.

Η συνολική διαδικασία είναι: Όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`. Μετά την υποβολή του API αίτημα, το API θα επιστρέψει αμέσως ένα αποτέλεσμα που περιλαμβάνει μια πληροφορία πεδίου `task_id`, που αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα της δημιουργίας εικόνας θα αποσταλεί μέσω POST JSON στη διεύθυνση `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε αυτό μέσω ενός παραδείγματος.

Κάντε κλικ για εκτέλεση και μπορείτε να δείτε ότι θα λάβετε αμέσως ένα αποτέλεσμα, όπως παρακάτω:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

Το περιεχόμενο είναι το εξής:

```json
{

    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Διατηρήστε τη στάση του μοντέλου και το σχήμα του ρευστού ενδύματος αμετάβλητο. Αλλάξτε το υλικό του ρούχου από ασημένιο μέταλλο σε εντελώς διαφανές νερό (ή γυαλί). Μέσα από τη ροή του υγρού, οι λεπτομέρειες του δέρματος του μοντέλου είναι ορατές. Το εφέ φωτός και σκιάς μετατοπίζεται από την αντανάκλαση στη διάθλαση.",
            "size": "2048x2048",
```

Μπορείτε να δείτε ότι το αποτέλεσμα περιλαμβάνει ένα πεδίο `task_id`, τα υπόλοιπα πεδία είναι παρόμοια με το παραπάνω κείμενο, μέσω αυτού του πεδίου μπορείτε να συσχετίσετε την εργασία.

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
