Αυτό το έγγραφο παρουσιάζει έναν οδηγό ενσωμάτωσης για το SeeDream Images Generation API, το οποίο επιτρέπει τη δημιουργία επίσημων εικόνων SeeDream μέσω εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να κάνετε αίτηση για την αντίστοιχη υπηρεσία στη σελίδα [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images). Μόλις μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά τη σύνδεση ή εγγραφή, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, παρέχεται δωρεάν όριο χρήσης, επιτρέποντας τη δωρεάν χρήση του API.

## Βασική Χρήση

Αρχικά, ας δούμε τον βασικό τρόπο χρήσης: εισάγετε το πεδίο `prompt` (λέξη-κλειδί), τη δράση `action` και το μέγεθος εικόνας `size` για να λάβετε το επεξεργασμένο αποτέλεσμα. Πρέπει να περάσετε το πεδίο `action` με τιμή `generate` και να εισάγετε το prompt. Η δομή είναι η εξής:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Εδώ ορίζουμε τα Request Headers, τα οποία περιλαμβάνουν:

- `accept`: Τον τύπο της απάντησης που θέλουμε να λάβουμε, εδώ `application/json` για μορφή JSON.
- `authorization`: Το κλειδί πρόσβασης στο API, το οποίο επιλέγεται από το dropdown μετά την αίτηση.

Επιπλέον, ορίζουμε το Request Body, που περιλαμβάνει:

- `prompt`: Η λέξη-κλειδί.
- `model`: Το μοντέλο δημιουργίας, προεπιλογή `doubao-seedream-5.0-lite`. Υποστηρίζονται τα `doubao-seedream-5.0-lite` (νεότερο), `doubao-seedream-4.5`, `doubao-seedream-4.0`, `doubao-seedream-3.0-t2i`, `doubao-seededit-3.0-i2i`.
- `image`: Πληροφορίες εισαγωγής εικόνας, υποστηρίζεται URL ή κωδικοποίηση Base64. Τα `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0` υποστηρίζουν μία ή πολλές εικόνες, το `doubao-seededit-3.0-i2i` μόνο μία εικόνα, ενώ το `doubao-seedream-3.0-t2i` δεν υποστηρίζει αυτό το πεδίο.
- `size`: Καθορισμός διαστάσεων εικόνας με δύο μη συμβατές μεταξύ τους μεθόδους. Μέθοδος 1 | Καθορισμός ανάλυσης (π.χ. `2K`, `3K`, `4K`) και περιγραφή λόγου διαστάσεων στο prompt με φυσική γλώσσα. Μέθοδος 2 | Καθορισμός ακριβών διαστάσεων σε pixels, προεπιλογή `2048x2048`, με διαφορετικά όρια ανά μοντέλο.
- `seed`: Σπόρος τυχαίων αριθμών για έλεγχο τυχαιότητας στη δημιουργία. Εύρος τιμών [-1, 2147483647]. Υποστηρίζεται μόνο από `doubao-seedream-3.0-t2i` και `doubao-seededit-3.0-i2i`.
- `sequential_image_generation`: Δημιουργία σειράς εικόνων σχετικών με το περιεχόμενο. Υποστηρίζεται από `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0`, προεπιλογή `disabled`.
- `stream`: Έλεγχος ενεργοποίησης λειτουργίας ροής εξόδου. Υποστηρίζεται από `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0`, προεπιλογή `false`.
- `guidance_scale`: Βαθμός συμφωνίας αποτελέσματος μοντέλου με το prompt, μεγαλύτερη τιμή σημαίνει μεγαλύτερη συσχέτιση. Εύρος [1, 10]. Προεπιλογές: 2.5 για `doubao-seedream-3.0-t2i`, 5.5 για `doubao-seededit-3.0-i2i`, μη υποστηριζόμενο από άλλα μοντέλα.
- `response_format`: Μορφή επιστροφής της εικόνας. Προεπιλογή `url`, υποστηρίζεται και `b64_json`.
- `watermark`: Εάν θα προστεθεί υδατογράφημα στην εικόνα. Προεπιλογή `true`.
- `output_format`: Μορφή αρχείου εικόνας, υποστηρίζονται `jpeg` (προεπιλογή) και `png`. Υποστηρίζεται μόνο από `doubao-seedream-5.0-lite`.
- `tools`: Εργαλεία που καλεί το μοντέλο, προς το παρόν υποστηρίζεται μόνο `web_search` (αναζήτηση στο διαδίκτυο). Υποστηρίζεται μόνο από `doubao-seedream-5.0-lite`.
- `callback_url`: URL για callback αποτελεσμάτων.

Μετά την επιλογή, στην δεξιά πλευρά δημιουργείται ο αντίστοιχος κώδικας, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να δοκιμάσετε. Στο παράδειγμα, λάβαμε το εξής αποτέλεσμα:

```json
{
  "success": true,
  "task_id": "25027ba3-0430-4a1b-91c8-d2297f19ba73",
  "trace_id": "8043a9e9-692f-43b0-82f7-5890f798be38",
  "data": [
    {
      "prompt": "a white siamese cat",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/3c060029-69b1-406f-a957-fcd55ddc9386.jpg"
    }
  ]
}
```

Τα πεδία επιστροφής είναι:

- `success`: Κατάσταση της εργασίας δημιουργίας εικόνας.
- `task_id`: Αναγνωριστικό εργασίας.
- `trace_id`: Αναγνωριστικό παρακολούθησης.
- `data`: Λίστα αποτελεσμάτων εργασίας δημιουργίας εικόνας.
  - `image_url`: Σύνδεσμος εικόνας.
  - `prompt`: Λέξη-κλειδί.
  - `size`: Διαστάσεις εικόνας σε pixels.

Έχουμε λάβει την επιθυμητή εικόνα και μπορούμε να την κατεβάσουμε μέσω του συνδέσμου `image_url` στο πεδίο `data`.

Επιπλέον, μπορείτε να αντιγράψετε τον αντίστοιχο κώδικα για ενσωμάτωση, π.χ. CURL:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-4-0-250828",
  "prompt": "a white siamese cat"
}'
```

## Εργασία Επεξεργασίας Εικόνας

Για επεξεργασία εικόνας, το πεδίο `image` πρέπει να περιέχει το σύνδεσμο της εικόνας προς επεξεργασία.

- `model`: Το μοντέλο που χρησιμοποιείται για την επεξεργασία. Τα `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0` υποστηρίζουν μία ή πολλές εικόνες, το `doubao-seededit-3.0-i2i` μόνο μία.
- `image`: Η εικόνα ή οι εικόνες προς επεξεργασία.

Παράδειγμα συμπλήρωσης:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Αντίστοιχος κώδικας:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Με την εκτέλεση, λαμβάνουμε άμεσα το αποτέλεσμα:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Το αποτέλεσμα δείχνει την επεξεργασμένη εικόνα, παρόμοια με το προηγούμενο παράδειγμα.

## Ασύγχρονο Callback

Επειδή η δημιουργία εικόνων με το SeeDream Images Generation API διαρκεί περίπου 1-2 λεπτά, για να αποφευχθεί η μακροχρόνια σύνδεση HTTP που καταναλώνει πόρους, το API υποστηρίζει ασύγχρονο callback.

Η διαδικασία είναι η εξής: κατά την αποστολή του αιτήματος, ο πελάτης ορίζει το πεδίο `callback_url`. Το API επιστρέφει αμέσως ένα αποτέλεσμα με το `task_id` που αντιπροσωπεύει την εργασία. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα αποστέλλεται μέσω POST σε μορφή JSON στο `callback_url`, συμπεριλαμβανομένου του `task_id` για συσχέτιση.

Παράδειγμα απόκρισης κατά την υποβολή:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

Περιεχόμενο callback:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Το πεδίο `task_id` επιτρέπει τη συσχέτιση του αποτελέσματος με την εργασία.

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, σε περίπτωση σφάλματος, επιστρέφεται αντίστοιχος κωδικός και μήνυμα, π.χ.:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένη πρόσβαση, άκυρο ή ελλιπές token.
- `429 too_many_requests`: Πολύ συχνά αιτήματα, υπερβήκατε το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.

### Παράδειγμα Απόκρισης Σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
