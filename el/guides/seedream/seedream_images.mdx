Αυτό το άρθρο θα παρουσιάσει έναν τρόπο ενσωμάτωσης του SeeDream Images Generation API, το οποίο μπορεί να δημιουργεί επίσημες εικόνες SeeDream μέσω εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το SeeDream Images Generation API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να προσκληθείτε να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση προσφέρει δωρεάν πίστωση για δωρεάν δοκιμή· όταν η πίστωση δεν επαρκεί, μπορείτε να επαναφορτίσετε το γενικό υπόλοιπο από την [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [SeeDream Images Generation API →](https://platform.acedata.cloud/documents/seedream-images)

## Βασική χρήση

Αρχικά, ας κατανοήσουμε τον βασικό τρόπο χρήσης: εισάγοντας την προτροπή `prompt`, την ενέργεια δημιουργίας `action` και το μέγεθος εικόνας `size`, μπορείτε να λάβετε το επεξεργασμένο αποτέλεσμα. Πρώτα χρειάζεται να περάσετε απλά ένα πεδίο `action`, με τιμή `generate`, και έπειτα πρέπει να εισαγάγετε την προτροπή. Το συγκεκριμένο περιεχόμενο είναι ως εξής:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ έχουμε ορίσει τα Request Headers, συμπεριλαμβανομένων των εξής:

- `accept`: Ποια μορφή αποτελέσματος απόκρισης θέλετε να λαμβάνετε· εδώ συμπληρώνεται ως `application/json`, δηλαδή μορφή JSON.
- `authorization`: Το κλειδί για την κλήση του API, το οποίο μπορεί να επιλεγεί απευθείας από αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουν οριστεί τα Request Body, συμπεριλαμβανομένων των εξής:

- `prompt`: Προτροπή.
- `model`: Μοντέλο δημιουργίας, προεπιλογή `doubao-seedream-5-0-lite-260128` (SeeDream 5.0 Lite, πιο πρόσφατο). Υποστηρίζονται τα `doubao-seedream-5-0-pro-260628`, `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`. Μεταξύ αυτών, το `doubao-seedream-5-0-pro-260628` (SeeDream 5.0 Pro) είναι το κορυφαίο μοντέλο μίας εικόνας, δημιουργεί μόνο μία εικόνα και **δεν υποστηρίζει ομάδες εικόνων (`sequential_image_generation`), ροή (`stream`) και διαδικτυακή αναζήτηση (`tools`)**. **Το `model` πρέπει να περάσει με την πλήρη συμβολοσειρά μοντέλου (όπως `doubao-seedream-5-0-lite-260128`), η σύντομη μορφή όπως `doubao-seedream-5.0-lite` θα επιστρέψει 400.**
- `image`: Πληροφορίες της εισαγόμενης εικόνας, υποστηρίζει URL ή κωδικοποίηση Base64. Το `doubao-seedream-5-0-pro-260628` υποστηρίζει είσοδο μίας ή πολλαπλών εικόνων (έως 10), τα `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` υποστηρίζουν είσοδο μίας ή πολλαπλών εικόνων.
- `size`: Καθορίζει τις πληροφορίες διαστάσεων της παραγόμενης εικόνας, υποστηρίζει τους παρακάτω δύο τρόπους, οι οποίοι δεν μπορούν να χρησιμοποιηθούν μαζί. Τρόπος 1 | Καθορίζει την ανάλυση της παραγόμενης εικόνας και περιγράφει τον λόγο διαστάσεων της εικόνας σε φυσική γλώσσα στο prompt. **Οι προεπιλογές που υποστηρίζει κάθε μοντέλο διαφέρουν**: το `doubao-seedream-5-0-pro-260628` υποστηρίζει `1K`/`1.5K`/`2K`· το `doubao-seedream-5-0-lite-260128` υποστηρίζει `2K`/`3K`/`4K`· το `doubao-seedream-4-5-251128` υποστηρίζει μόνο `2K`/`4K`· το `doubao-seedream-4-0-250828` υποστηρίζει `1K`/`2K`/`4K`. Τρόπος 2 | Καθορίζει τις τιμές pixel πλάτους και ύψους της παραγόμενης εικόνας: η προεπιλογή είναι `2048x2048`, το συνολικό εύρος pixel και ο λόγος διαστάσεων διαφέρουν ανάλογα με το μοντέλο (για παράδειγμα, το εύρος συνολικών pixel του 5.0 Pro είναι [921600, 4624220], το κατώτατο όριο συνολικών pixel για 5.0 Lite / 4.5 είναι 3,686,400 και για 4.0 είναι 921,600).
- `sequential_image_generation`: Ομάδα εικόνων: μια ομάδα παραγόμενων εικόνων με συσχετισμένο περιεχόμενο, βάσει του περιεχομένου που εισαγάγατε. Τα `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` υποστηρίζουν αυτή την παράμετρο, με προεπιλογή `disabled`.
- `stream`: Ελέγχει αν θα ενεργοποιηθεί η λειτουργία εξόδου ροής. Τα `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` υποστηρίζουν αυτή την παράμετρο, με προεπιλογή `false`.
- `response_format`: Καθορίζει τη μορφή επιστροφής της παραγόμενης εικόνας. Η προεπιλογή είναι `url`, και υποστηρίζεται επίσης το `b64_json`.
- `watermark`: Αν θα προστεθεί υδατογράφημα στην παραγόμενη εικόνα. Η προεπιλογή είναι `true`.
- `output_format`: Καθορίζει τη μορφή αρχείου της παραγόμενης εικόνας, υποστηρίζει `jpeg` (προεπιλογή) και `png`. Υποστηρίζεται μόνο από τα `doubao-seedream-5-0-pro-260628` και `doubao-seedream-5-0-lite-260128`.
- `tools`: Ρυθμίζει τα εργαλεία που πρέπει να καλέσει το μοντέλο, προς το παρόν υποστηρίζει `web_search` (διαδικτυακή αναζήτηση). Υποστηρίζεται μόνο από το Seedream 5.0 Lite.
- `optimize_prompt_options`: Ρύθμιση βελτιστοποίησης προτροπής. Το 5.0 Pro υποστηρίζει `standard`/`fast`· τα 5.0 Lite και 4.5 υποστηρίζουν μόνο `standard`· το 4.0 υποστηρίζει `standard`/`fast`.
- `background`: Υποστηρίζεται μόνο από την επεξεργασία μίας εικόνας του 5.0 Pro. Το `transparent` απαιτεί την εισαγωγή μιας PNG με κανάλι διαφάνειας και το `output_format` πρέπει να είναι `png`· το `opaque` είναι ένα συνηθισμένο αδιαφανές φόντο.
- `layer_decomposition`: Υποστηρίζεται μόνο από το 5.0 Pro. Όταν οριστεί σε `true`, πρέπει να εισαχθεί μία PNG/JPEG, το `prompt` μπορεί να παραληφθεί για αυτόματο διαχωρισμό ή να χρησιμοποιηθεί φυσική γλώσσα/`<bbox>` για τον καθορισμό στοιχείων· το `size` υποστηρίζει `auto`/`1K`/`1.5K`/`2K`. Αυτή η λειτουργία δεν μπορεί να χρησιμοποιηθεί μαζί με ομάδες εικόνων, ροή, διαδικτυακή αναζήτηση ή `background`.
- `callback_url`: Το URL που χρειάζεται για την επιστροφή αποτελέσματος μέσω callback.
- `async`: Αν θα γίνει επεξεργασία σε ασύγχρονη λειτουργία. Όταν οριστεί σε `true`, η διεπαφή επιστρέφει αμέσως `task_id`, χωρίς να χρειάζεται να παρέχετε `callback_url`, και στη συνέχεια λαμβάνει το αποτέλεσμα μέσω polling στο `/seedream/tasks`.

Μετά την επιλογή, μπορείτε να διαπιστώσετε ότι δημιουργήθηκε και ο αντίστοιχος κώδικας στη δεξιά πλευρά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να πραγματοποιήσετε δοκιμή. Όπως φαίνεται στην παραπάνω εικόνα, εδώ λάβαμε το ακόλουθο αποτέλεσμα:
```json

  "success": true,
  "task_id": "80ceeed1-17d4-4eb7-82e0-18b34290f36e",
  "trace_id": "96b7fdc8-0fc8-4e2e-82a9-83c0a82f0a08",
  "data": [
    {
      "prompt": "A single matte blue cube centered on a clean white studio background, neutral lighting",
      "size": "2048x2048",
      "image_url": "https://cdn.acedata.cloud/assets/examples/seedream/db93b46e-c302-4676-8a11-63f0ba638a27-1c6f66f6b7e8.jpg"
    }
  ]
}
```

Το αποτέλεσμα επιστροφής περιλαμβάνει συνολικά πολλαπλά πεδία, τα οποία περιγράφονται ως εξής:

- `success`, η κατάσταση της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `task_id`, το ID της εργασίας δημιουργίας βίντεο αυτή τη στιγμή.
- `trace_id`, το ID παρακολούθησης της δημιουργίας βίντεο αυτή τη στιγμή.
- `data`, η λίστα αποτελεσμάτων της εργασίας δημιουργίας εικόνων αυτή τη στιγμή.
  - `image_url`, ο σύνδεσμος της εργασίας δημιουργίας εικόνων αυτή τη στιγμή.
  - `prompt`, η προτροπή.
  - `size`: τα pixel της παραγόμενης εικόνας

Μπορούμε να δούμε ότι λάβαμε ικανοποιητικές πληροφορίες εικόνας· χρειάζεται μόνο να λάβουμε τη δημιουργημένη εικόνα SeeDream μέσω της διεύθυνσης συνδέσμου εικόνας στο `data` του αποτελέσματος.

Επιπλέον, αν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα ενσωμάτωσης, μπορείτε να τον αντιγράψετε απευθείας για δημιουργία, για παράδειγμα, ο κώδικας CURL είναι ο εξής:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-5-0-lite-260128",
  "prompt": "A single matte blue cube centered on a clean white studio background, neutral lighting"
}'
```

## Εργασία επεξεργασίας εικόνας

Αν θέλετε να επεξεργαστείτε μια εικόνα, πρώτα η παράμετρος `image` πρέπει να περιλαμβάνει τον σύνδεσμο της εικόνας που χρειάζεται επεξεργασία

- model：το μοντέλο που χρησιμοποιείται για αυτή την εργασία επεξεργασίας εικόνας, τα `doubao-seedream-5-0-pro-260628`, `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` υποστηρίζουν όλα εισαγωγή εικόνας.
- image：ανεβάστε την εικόνα που χρειάζεται επεξεργασία, μία ή περισσότερες

Το παράδειγμα συμπλήρωσης είναι το εξής:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Ο αντίστοιχος κώδικας:

```python
import requests

url = "https://api.acedata.cloud/seedream/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```json
  "data": [
    {
      "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
      "size": "2048x2048",
```

Μπορούμε να δούμε ότι το παραγόμενο αποτέλεσμα είναι το αποτέλεσμα επεξεργασίας της αρχικής εικόνας, και το αποτέλεσμα είναι παρόμοιο με το παραπάνω.

## Διαχωρισμός επιπέδων (Seedream 5.0 Pro)

Ο διαχωρισμός επιπέδων διαχωρίζει μία εικόνα εισόδου σε 1 εικόνα φόντου και έως 16 ανεξάρτητα επεξεργάσιμα διαφανή επίπεδα PNG. Το παρακάτω αίτημα επιτρέπει στο μοντέλο να αναγνωρίζει αυτόματα τα κύρια στοιχεία· αν χρειάζεται να καθορίσετε στοιχεία, μπορείτε να προσθέσετε `prompt`, και μπορείτε επίσης να χρησιμοποιήσετε κανονικοποιημένες συντεταγμένες `<bbox>` στην προτροπή.

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "model": "doubao-seedream-5-0-pro-260628",
  "image": "https://example.com/poster.png",
  "layer_decomposition": true,
  "size": "2K",
  "watermark": false
}'
```

Το επιστρεφόμενο `data` ταξινομείται από κάτω προς τα πάνω σύμφωνα με το `z_index`. Το `z_index` της εικόνας φόντου είναι 0· τα επίπεδα περιλαμβάνουν επίσης `name`, `description` και `bounding_box.absolute`/`normalized`. Όταν ανασυνθέτετε χρησιμοποιώντας απόλυτες συντεταγμένες, κλιμακώστε τα επίπεδα σε `[right-left, bottom-top]`, τοποθετήστε τα στο `[left, top]` και έπειτα στοιβάξτε τα σε αύξουσα σειρά `z_index`. Όταν η δημιουργία οποιουδήποτε επιπέδου αποτυγχάνει, αποτυγχάνει ολόκληρος ο διαχωρισμός.

## Ροϊκή έξοδος

Όταν τα Lite/4.x ορίζονται με `stream: true`, η κεφαλίδα αιτήματος χρησιμοποιεί `accept: application/x-ndjson`. Η διεπαφή επιστρέφει γραμμή προς γραμμή `image_generation.partial_succeeded` ή `image_generation.partial_failed` και τελικά επιστρέφει το μοναδικό συμβάν `image_generation.completed` και την τελική `usage`· μόνο το συμβάν ολοκλήρωσης ενεργοποιεί μία χρέωση. Η ροϊκή λειτουργία δεν μπορεί να χρησιμοποιηθεί μαζί με `async` ή `callback_url`.

## Ασύγχρονη επανάκληση

Επειδή ο χρόνος δημιουργίας του SeeDream Images Generation API είναι σχετικά μεγάλος, απαιτώντας περίπου 1-2 λεπτά, αν το API δεν ανταποκρίνεται για μεγάλο χρονικό διάστημα, το αίτημα HTTP θα διατηρεί συνεχώς τη σύνδεση, προκαλώντας πρόσθετη κατανάλωση πόρων συστήματος, επομένως αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη επανάκληση.

Η συνολική διαδικασία είναι: όταν ο πελάτης ξεκινά ένα αίτημα, καθορίζει επιπλέον ένα πεδίο `callback_url`, μετά την έναρξη του αιτήματος API από τον πελάτη, το API θα επιστρέψει αμέσως ένα αποτέλεσμα, το οποίο περιλαμβάνει πληροφορίες πεδίου `task_id`, που αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα της δημιουργίας εικόνας θα σταλεί στο `callback_url` που καθορίζεται από τον πελάτη μέσω POST JSON, στο οποίο περιλαμβάνεται επίσης το πεδίο `task_id`, ώστε τα αποτελέσματα της εργασίας να μπορούν να συσχετιστούν μέσω του ID.

Αν δεν έχετε μια δημόσια διεύθυνση διαθέσιμη για επανάκληση, μπορείτε επίσης να μην καθορίσετε `callback_url`, αλλά να ορίσετε το πεδίο `async` σε `true` στο αίτημα. Σε αυτή την περίπτωση η διεπαφή θα επιστρέψει επίσης αμέσως το `task_id`, αλλά δεν θα προωθήσει το αποτέλεσμα· πρέπει να μεταφέρετε αυτό το `task_id` για να καλέσετε τη διεπαφή `/seedream/tasks` και να ελέγχετε περιοδικά την κατάσταση της εργασίας ώστε να λάβετε το τελικό αποτέλεσμα.

Παρακάτω θα κατανοήσουμε μέσω παραδείγματος πώς ακριβώς να το χειριστούμε.

Κάντε κλικ στην εκτέλεση και θα διαπιστώσετε ότι λαμβάνετε αμέσως ένα αποτέλεσμα, ως εξής:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

Το περιεχόμενο είναι το εξής:
```json

    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
```

Μπορείτε να δείτε ότι υπάρχει ένα πεδίο `task_id` στο αποτέλεσμα, ενώ τα άλλα πεδία είναι παρόμοια με τα παραπάνω. Μέσω αυτού του πεδίου μπορεί να επιτευχθεί η συσχέτιση εργασιών.

## Χειρισμός σφαλμάτων

Κατά την κλήση του API, εάν προκύψει κάποιο σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό και μήνυμα σφάλματος. Για παράδειγμα:

- `400 token_mismatched`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα απόκρισης σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Συμπέρασμα
