title: "Επεξεργασία μοντέλων Tripo"

Χρησιμοποιήστε το `POST /tripo/models` για να επεξεργαστείτε ένα υπάρχον μοντέλο, παρέχοντας την απαιτούμενη `action`. Η σύγχρονη και ασύγχρονη λειτουργία, οι επανακλήσεις, η σύνδεση με λογαριασμό και η αναζήτηση εργασιών είναι ίδιες με εκείνες της δημιουργίας 3D.

| action  | Είσοδος | Αποτέλεσμα |
| ------- | ------- | ---------- |
| import  | `model_url`, δημόσιο αρχείο GLB, GLTF, FBX, OBJ ή STL μέσω HTTPS, μέγιστο μέγεθος 150 MiB | ID μοντέλου που μπορεί να χρησιμοποιηθεί σε επόμενες αναφορές και GLB· όταν υπάρχουν δεδομένα, επιστρέφονται τα `normalize_scale` και `normalize_translation` |
| texture | `model_id` ή `model_url`· προαιρετικά, ένα από τα `prompt`, `image_url`, `image_urls` | Νέο μοντέλο, υφή και προαιρετική προεπισκόπηση |
| convert | `model_id` ή `model_url`, καθώς και η επιθυμητή `format` | Το αρχείο του μοντέλου μετά τη μετατροπή |

```json
{"action":"texture","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","prompt":"蓝色哑光表面","texture_quality":"standard","async":true}
```

Η ποιότητα υφής υποστηρίζει τις τιμές `fast`, `standard`, `detailed`, `extreme`. Όταν χρησιμοποιείται προτροπή κειμένου, μπορεί να προστεθεί το `style_image_url`· οι εικόνες και οι αναφορές πολλαπλών όψεων ακολουθούν τη μορφή της διεπαφής δημιουργίας. Για περισσότερες παραμέτρους υφής, ανατρέξτε στο OpenAPI.

Η μετατροπή υποστηρίζει τα `GLTF`, `FBX`, `USDZ`, `OBJ`, `STL` και `3MF`. Το `format` του επιστρεφόμενου στοιχείου δηλώνει την πραγματική μορφή παράδοσης· για παράδειγμα, ένα αίτημα GLTF μπορεί να παραδώσει δυαδικό GLB. Το OBJ συσκευάζει τα υλικά και τους χάρτες υφής σε ZIP. Όταν ζητείται FBX, ορίστε `texture_packaging: "zip"` για να λάβετε ξεχωριστούς χάρτες υφής· το συσκευασμένο αποτέλεσμα φέρει την ένδειξη `container: "ZIP"`. Η ενεργοποίηση μη προεπιλεγμένων ρυθμίσεων πλέγματος ή υφής ενδέχεται να χρεωθεί ως προηγμένη μετατροπή· για λεπτομέρειες, ανατρέξτε στις τιμές της υπηρεσίας.

Χρησιμοποιήστε το `data[0].id` για να αναφερθείτε σε μοντέλο αυτού του λογαριασμού· ο μετασχηματισμός κανονικοποίησης του εισαγόμενου μοντέλου ικανοποιεί τη σχέση `normalized = original × normalize_scale + normalize_translation`. Η διεύθυνση λήψης του μοντέλου βρίσκεται στο `data[0].model_url`.
