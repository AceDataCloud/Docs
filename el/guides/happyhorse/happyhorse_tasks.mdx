HappyHorse Tasks API χρησιμοποιείται για την αναζήτηση των εργασιών δημιουργίας ή επεξεργασίας βίντεο που δημιουργούνται από το HappyHorse Videos API.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το HappyHorse Videos API, πρώτα πηγαίνετε στο [Ace Data Cloud κονσόλα](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, δεν χρειάζεται να κάνετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν; όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό σας υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Παράδειγμα αιτήματος

HappyHorse Tasks API μπορεί να χρησιμοποιηθεί για την αναζήτηση των αποτελεσμάτων του HappyHorse Videos API.

### Ρύθμιση κεφαλίδων αιτήματος και σώματος αιτήματος

**Request Headers** περιλαμβάνει:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `id`: το ID της εργασίας που θέλετε να αναζητήσετε.
- `action`: ο τρόπος λειτουργίας της εργασίας, για μεμονωμένη αναζήτηση συμπληρώστε `retrieve`.

### Παράδειγμα κώδικα CURL

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Παράδειγμα απάντησης

Αφού το αίτημα είναι επιτυχές, το API θα επιστρέψει τις λεπτομέρειες της εργασίας. Το πεδίο `request` είναι το σώμα του αιτήματος κατά τη δημιουργία της εργασίας, το πεδίο `response` είναι το σώμα της απάντησης που επιστρέφεται μετά την ολοκλήρωση της εργασίας, για παράδειγμα:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262774.423,
  "elapsed": 52.6,
  "request": {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic shot of a white horse running across a moonlit beach",
    "resolution": "720P",
    "duration": 5
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "1469cfc3-3004-4d9e-ab10-xxxxxx",
        "video_url": "https://cdn.acedata.cloud/happyhorse/c8cbf53aa0.mp4",
        "state": "succeeded",
        "duration": 5,
        "resolution": "720P",
        "ratio": "16:9"
      }
    ]
  }
}
```

Η περιγραφή των πεδίων είναι ως εξής:

- `id`: το ID της εργασίας δημιουργίας, που χρησιμοποιείται για την μοναδική αναγνώριση αυτής της εργασίας.
- `request`: οι πληροφορίες του αιτήματος κατά τη δημιουργία της εργασίας.
- `response`: οι τρέχουσες ή τελικές πληροφορίες επιστροφής της εργασίας.
- `created_at`: η ώρα δημιουργίας της εργασίας, Unix χρονική σφραγίδα (δευτερόλεπτα, κινητό).
- `started_at`: η ώρα έναρξης εκτέλεσης της εργασίας, Unix χρονική σφραγίδα (δευτερόλεπτα, κινητό).
- `finished_at`: η ώρα ολοκλήρωσης της εργασίας, Unix χρονική σφραγίδα (δευτερόλεπτα, κινητό). Δεν επιστρέφεται αυτό το πεδίο αν η εργασία δεν έχει ολοκληρωθεί.
- `elapsed`: ο χρόνος εκτέλεσης της εργασίας, μονάδα σε δευτερόλεπτα (κινητό, διατηρεί 3 δεκαδικά). Δεν επιστρέφεται αυτό το πεδίο αν η εργασία δεν έχει ολοκληρωθεί.

## Μαζική αναζήτηση εργασιών

Για να αναζητήσετε λεπτομέρειες εργασιών για πολλαπλά ID εργασιών, ρυθμίστε το `action` σε `retrieve_batch` και περάστε τον πίνακα ID εργασιών μέσω του `ids`:

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```

Στο αποτέλεσμα επιστροφής θα περιλαμβάνονται τα πεδία `items` και `count`, όπου το `items` είναι ο πίνακας λεπτομερειών εργασίας και το `count` είναι ο αριθμός των εργασιών που ταιριάζουν αυτή τη φορά.
