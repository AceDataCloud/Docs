Αυτό το έγγραφο παρουσιάζει τον τρόπο ενσωμάτωσης του API HappyHorse Videos. Η διεπαφή υποστηρίζει δημιουργία βίντεο από κείμενο, δημιουργία βίντεο από εικόνα πρώτου καρέ, δημιουργία βίντεο από εικόνες αναφοράς και επεξεργασία βίντεο μέσω της ενοποιημένης εισόδου `/happyhorse/videos` και της παραμέτρου `action`.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το API HappyHorse Videos, αποκτήστε πρώτα το API Token σας από την [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης, όπου θα σας προσκληθεί να εγγραφείτε και να συνδεθείτε· μετά την ολοκλήρωση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να απαιτείται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση προσφέρει δωρεάν υπόλοιπο για δωρεάν δοκιμή· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να επαναφορτίσετε το γενικό υπόλοιπο από την [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Τύποι ενεργειών

Το `action` καθορίζει τη λειτουργία δημιουργίας για αυτό το αίτημα:

- `generate`: δημιουργία βίντεο από κείμενο, η προεπιλεγμένη ενέργεια, υποστηρίζει `happyhorse-1.0-t2v` και `happyhorse-1.1-t2v`, και πρέπει να παρέχεται το `prompt`.
- `image_to_video`: δημιουργία βίντεο από εικόνα πρώτου καρέ, υποστηρίζει `happyhorse-1.0-i2v` και `happyhorse-1.1-i2v`, και πρέπει να παρέχεται το `image_url`.
- `reference_to_video`: δημιουργία βίντεο από εικόνες αναφοράς, υποστηρίζει `happyhorse-1.0-r2v` και `happyhorse-1.1-r2v`, και πρέπει να παρέχονται το `prompt` και 1–9 `image_urls`.
- `video_edit`: επεξεργασία βίντεο, υποστηρίζει `happyhorse-1.0-video-edit`, και πρέπει να παρέχονται το `prompt` και το `video_url`, ενώ μπορούν προαιρετικά να παρέχονται 0–5 εικόνες αναφοράς `image_urls`.

Κάθε ενέργεια χρησιμοποιεί από προεπιλογή το μοντέλο 1.1· το `video_edit` διαθέτει προς το παρόν μόνο το `happyhorse-1.0-video-edit`.

## Βασική χρήση

Η δημιουργία βίντεο από κείμενο απαιτεί μόνο την παροχή του `prompt`, ενώ μπορούν επίσης να καθοριστούν παράμετροι όπως `resolution`, `ratio`, `duration` κ.λπ.:

```json
{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

Ένα παράδειγμα επιστρεφόμενου αποτελέσματος είναι το ακόλουθο:

```json
{
  "success": true,
  "task_id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
  "trace_id": "6071ab5e-2f37-46f0-9e07-f1e378112e69",
  "data": [
    {
      "id": "9650580f-6d9e-4bc1-823a-29011790c5cb",
      "video_url": "https://cdn.acedata.cloud/assets/examples/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1-2c108ce23554.mp4",
      "state": "succeeded",
      "duration": 5,
      "resolution": "720P",
      "ratio": null
    }
  ]
}
```

Περιγραφή πεδίων:

- `success`: αν αυτό το αίτημα ολοκληρώθηκε με επιτυχία.
- `task_id`: το ID εργασίας στην πλευρά του Ace Data Cloud, το οποίο μπορεί να χρησιμοποιηθεί για την αναζήτηση της κατάστασης της εργασίας.
- `trace_id`: το ID παρακολούθησης αυτού του αιτήματος, που χρησιμοποιείται για την αντιμετώπιση προβλημάτων.
- `data`: η λίστα αποτελεσμάτων βίντεο.
  - `id`: το ID εργασίας στην πλευρά του HappyHorse.
  - `video_url`: η διεύθυνση συνδέσμου CDN του παραγόμενου βίντεο.
  - `state`: η κατάσταση της εργασίας, με πιθανές τιμές `pending` / `succeeded` / `error`.
  - `duration`: η χρεώσιμη διάρκεια βίντεο, σε δευτερόλεπτα· για το `video_edit` είναι το άθροισμα της διάρκειας του βίντεο εισόδου και εξόδου.
  - `resolution`: η ανάλυση εξόδου.
  - `ratio`: η αναλογία διαστάσεων εξόδου.

Ο αντίστοιχος κώδικας CURL είναι ο ακόλουθος:

```shell
curl -X POST 'https://api.acedata.cloud/happyhorse/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}'
```

Ο αντίστοιχος κώδικας Python είναι ο ακόλουθος:

```python
import requests

url = "https://api.acedata.cloud/happyhorse/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
    "resolution": "720P",
    "ratio": "16:9",
    "duration": 5,
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Δημιουργία βίντεο από εικόνα πρώτου καρέ

Κατά τη χρήση του `image_to_video`, το `image_url` χρησιμοποιείται ως το πρώτο καρέ του βίντεο. Η αναλογία διαστάσεων εξόδου θα ακολουθεί όσο το δυνατόν περισσότερο την εικόνα του πρώτου καρέ, επομένως αυτή η ενέργεια δεν απαιτεί την παροχή του `ratio`.

```json
{
  "action": "image_to_video",
  "model": "happyhorse-1.1-i2v",
  "image_url": "https://cdn.acedata.cloud/b1c82e4937.png",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "1080P",
  "duration": 5
}
```

## Δημιουργία βίντεο από εικόνες αναφοράς

Κατά τη χρήση του `reference_to_video`, τα `image_urls` μπορούν να περιλαμβάνουν 1–9 εικόνες αναφοράς. Στο prompt, μπορείτε να αναφέρεστε στις εικόνες της αντίστοιχης σειράς με τρόπους όπως `character1`, `character2` κ.λπ.

```json
{
  "action": "reference_to_video",
  "model": "happyhorse-1.1-r2v",
  "prompt": "character1 walks forward through a sunrise meadow with the warm leather and gold trim style from character2",
  "image_urls": [
    "https://cdn.acedata.cloud/b1c82e4937.png",
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

## Επεξεργασία βίντεο

Η διάρκεια εξόδου και το κάδρο του `video_edit` κληρονομούνται από το αρχικό βίντεο· η παροχή `duration` ή `ratio` δεν θα τα αλλάξει· το κάδρο του βίντεο από εικόνα κληρονομείται επίσης από την αρχική εικόνα. Το κόστος επεξεργασίας υπολογίζεται με βάση το άθροισμα της διάρκειας των βίντεο εισόδου και εξόδου.

Κατά τη χρήση του `video_edit`, πρέπει να παρέχονται το βίντεο προς επεξεργασία `video_url` και η πρόθεση επεξεργασίας `prompt`. Τα προαιρετικά `image_urls` χρησιμοποιούνται ως εικόνες αναφοράς, για παράδειγμα για αλλαγή ενδυμασίας, μεταφορά στυλ ή τοπική αντικατάσταση. Το `audio_setting` μπορεί προαιρετικά να είναι `auto` ή `origin`, όπου το `origin` σημαίνει διατήρηση του ήχου του αρχικού βίντεο.
```json
{
  "action": "video_edit",
  "model": "happyhorse-1.0-video-edit",
  "prompt": "Apply the warm leather and gold trim style from the reference image while preserving the original camera motion",
  "video_url": "https://cdn.acedata.cloud/assets/examples/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1-2c108ce23554.mp4",
  "image_urls": [
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "audio_setting": "auto"
}
```

## Ασύγχρονη επανάκληση

Η δημιουργία βίντεο απαιτεί ορισμένο χρόνο επεξεργασίας. Εάν δεν επιθυμείτε να διατηρήσετε μια μακρά σύνδεση σε αναμονή, μπορείτε να περάσετε το `callback_url`, οπότε το API θα επιστρέψει αμέσως το `task_id` και, μετά την ολοκλήρωση της εργασίας, θα κάνει POST το τελικό αποτέλεσμα σε αυτή τη διεύθυνση:

```json
{
  "action": "generate",
  "prompt": "A horse running through a snowy forest",
  "duration": 5,
  "callback_url": "https://your-domain.com/callback/happyhorse"
}
```

Το αποτέλεσμα που επιστρέφεται αμέσως είναι το εξής:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

Εάν επιθυμείτε μόνο δημοσκόπηση, χωρίς να χρειάζεστε επανάκληση, μπορείτε επίσης να περάσετε το `"async": true` και στη συνέχεια να ελέγξετε το αποτέλεσμα της εργασίας μέσω του [HappyHorse Tasks API](https://platform.acedata.cloud/documents/happyhorse-tasks).

## Επεξήγηση χρέωσης

Το HappyHorse χρεώνει ανάλογα με τα δευτερόλεπτα του παραγόμενου βίντεο και την ανάλυση:

- `720P`: από περίπου $0.105 / δευτερόλεπτο.
- `1080P`: από περίπου $0.18 / δευτερόλεπτο.
- `video_edit`: χρεώνεται με βάση το άθροισμα της διάρκειας του βίντεο εισόδου και του βίντεο εξόδου· η πραγματική χρεώσιμη διάρκεια βασίζεται στα στατιστικά μετά την ολοκλήρωση της εργασίας.

Οι αποτυχημένες εργασίες δεν χρεώνονται και δεν καταναλώνουν το δωρεάν όριο.

## Χειρισμός σφαλμάτων

Όταν υπάρχει πρόβλημα με το αίτημα, το API επιστρέφει τον αντίστοιχο κωδικό σφάλματος και περιγραφή· τα συνηθισμένα είναι τα εξής:

- `400`: Λανθασμένες παράμετροι αιτήματος, για παράδειγμα το action δεν αντιστοιχεί στο model, λείπει το `prompt` / `image_url` / `video_url`, ή το `duration` υπερβαίνει το εύρος 3–15 δευτερολέπτων.
- `401`: Αποτυχία ελέγχου ταυτότητας, το token είναι μη έγκυρο ή δεν αντιστοιχεί στο API.
- `403`: Ανεπαρκές υπόλοιπο ή η προτροπή απορρίφθηκε επειδή ενεργοποίησε τον έλεγχο περιεχομένου.
- `429`: Τα αιτήματα είναι υπερβολικά συχνά, ενεργοποιήθηκε ο περιορισμός ρυθμού· δοκιμάστε ξανά αργότερα.
- `500`: Εσωτερικό σφάλμα διακομιστή ή αποτυχία δημιουργίας.
