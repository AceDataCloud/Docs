Αυτό το άρθρο παρουσιάζει τον τρόπο ενσωμάτωσης του HappyHorse Videos API. Αυτό το API υποστηρίζει δημιουργία βίντεο από κείμενο, δημιουργία βίντεο από εικόνα πρώτου καρέ, δημιουργία βίντεο από εικόνες αναφοράς και επεξεργασία βίντεο μέσω του ενιαίου σημείου εισόδου `/happyhorse/videos` και της παραμέτρου `action`.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το HappyHorse Videos API, αποκτήστε πρώτα το API Token σας από την [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση παρέχει δωρεάν υπόλοιπο για δωρεάν δοκιμή· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να φορτίσετε κοινό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Τύποι ενεργειών

Το `action` καθορίζει τη λειτουργία δημιουργίας για αυτό το αίτημα:

- `generate`: δημιουργία βίντεο από κείμενο, η προεπιλεγμένη ενέργεια, υποστηρίζει `happyhorse-1.0-t2v` και `happyhorse-1.1-t2v`, απαιτεί την παροχή του `prompt`.
- `image_to_video`: δημιουργία βίντεο από εικόνα πρώτου καρέ, υποστηρίζει `happyhorse-1.0-i2v` και `happyhorse-1.1-i2v`, απαιτεί την παροχή του `image_url`.
- `reference_to_video`: δημιουργία βίντεο από εικόνες αναφοράς, υποστηρίζει `happyhorse-1.0-r2v` και `happyhorse-1.1-r2v`, απαιτεί την παροχή του `prompt` και 1–9 `image_urls`.
- `video_edit`: επεξεργασία βίντεο, υποστηρίζει `happyhorse-1.0-video-edit`, απαιτεί την παροχή του `prompt` και του `video_url`, και μπορεί προαιρετικά να λάβει 0–5 εικόνες αναφοράς `image_urls`.

Κάθε ενέργεια χρησιμοποιεί από προεπιλογή το μοντέλο 1.1· το `video_edit` διαθέτει προς το παρόν μόνο το `happyhorse-1.0-video-edit`.

## Βασική χρήση

Η δημιουργία βίντεο από κείμενο απαιτεί μόνο την παροχή του `prompt`, ενώ μπορείτε επίσης να καθορίσετε παραμέτρους όπως `resolution`, `ratio`, `duration`:

```json
{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

Ένα παράδειγμα του επιστρεφόμενου αποτελέσματος είναι το εξής:

```json
{
  "success": true,
  "task_id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
  "trace_id": "6071ab5e-2f37-46f0-9e07-f1e378112e69",
  "data": [
    {
      "id": "9650580f-6d9e-4bc1-823a-29011790c5cb",
      "video_url": "https://cdn.acedata.cloud/assets/examples/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1-2c108ce23554.mp4",
      "state": "succeeded",
      "duration": 5,
      "resolution": "720P",
      "ratio": null
    }
  ]
}
```

Περιγραφή πεδίων:

- `success`: εάν αυτό το αίτημα ήταν επιτυχές.
- `task_id`: το ID εργασίας στην πλευρά του Ace Data Cloud, το οποίο μπορεί να χρησιμοποιηθεί για την αναζήτηση της κατάστασης της εργασίας.
- `trace_id`: το ID παρακολούθησης αυτού του αιτήματος, που χρησιμοποιείται για την αντιμετώπιση προβλημάτων.
- `data`: η λίστα αποτελεσμάτων βίντεο.
  - `id`: το ID εργασίας στην πλευρά του HappyHorse.
  - `video_url`: η διεύθυνση συνδέσμου CDN του παραγόμενου βίντεο.
  - `state`: η κατάσταση της εργασίας, διαθέσιμες τιμές `pending` / `succeeded` / `error`.
  - `duration`: η χρεώσιμη διάρκεια βίντεο, σε δευτερόλεπτα· για το `video_edit` είναι το άθροισμα της διάρκειας του βίντεο εισόδου και εξόδου.
  - `resolution`: η ανάλυση εξόδου.
  - `ratio`: η αναλογία διαστάσεων εξόδου.

Ο αντίστοιχος κώδικας CURL είναι ο εξής:

```shell
curl -X POST 'https://api.acedata.cloud/happyhorse/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}'
```

Ο αντίστοιχος κώδικας Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/happyhorse/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
    "resolution": "720P",
    "ratio": "16:9",
    "duration": 5,
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Δημιουργία βίντεο από εικόνα πρώτου καρέ

Κατά τη χρήση του `image_to_video`, το `image_url` θα χρησιμοποιηθεί ως το πρώτο καρέ του βίντεο. Η αναλογία διαστάσεων εξόδου θα ακολουθεί όσο το δυνατόν περισσότερο την εικόνα του πρώτου καρέ, επομένως αυτή η ενέργεια δεν χρειάζεται την παροχή του `ratio`.

```json
{
  "action": "image_to_video",
  "model": "happyhorse-1.1-i2v",
  "image_url": "https://cdn.acedata.cloud/b1c82e4937.png",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "1080P",
  "duration": 5
}
```

## Δημιουργία βίντεο από εικόνες αναφοράς

Κατά τη χρήση του `reference_to_video`, το `image_urls` μπορεί να λάβει 1–9 εικόνες αναφοράς. Στο κείμενο προτροπής, μπορείτε να χρησιμοποιήσετε `character1`, `character2` και παρόμοιες αναφορές για να παραπέμπετε στις εικόνες με την αντίστοιχη σειρά.

```json
{
  "action": "reference_to_video",
  "model": "happyhorse-1.1-r2v",
  "prompt": "character1 walks forward through a sunrise meadow with the warm leather and gold trim style from character2",
  "image_urls": [
    "https://cdn.acedata.cloud/b1c82e4937.png",
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

## Επεξεργασία βίντεο

Κατά τη χρήση του `video_edit`, πρέπει να παρέχετε το βίντεο προς επεξεργασία `video_url` και την πρόθεση επεξεργασίας `prompt`. Τα προαιρετικά `image_urls` θα χρησιμοποιηθούν ως εικόνες αναφοράς, για παράδειγμα για αλλαγή ενδυμασίας, μεταφορά στυλ ή τοπική αντικατάσταση. Το `audio_setting` μπορεί προαιρετικά να είναι `auto` ή `origin`, όπου το `origin` σημαίνει διατήρηση του αρχικού ήχου του βίντεο.

```json
{
  "action": "video_edit",
  "model": "happyhorse-1.0-video-edit",
  "prompt": "Apply the warm leather and gold trim style from the reference image while preserving the original camera motion",
  "video_url": "https://cdn.acedata.cloud/assets/examples/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1-2c108ce23554.mp4",
  "image_urls": [
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "audio_setting": "auto"
}
```

## Ασύγχρονη επανάκληση
Η δημιουργία βίντεο απαιτεί ορισμένο χρόνο επεξεργασίας. Εάν δεν επιθυμείτε να διατηρείτε μια μακρά σύνδεση σε αναμονή, μπορείτε να περάσετε το `callback_url`, οπότε το API θα επιστρέψει αμέσως το `task_id` και, μετά την ολοκλήρωση της εργασίας, θα κάνει POST το τελικό αποτέλεσμα σε αυτήν τη διεύθυνση:

```json
{
  "action": "generate",
  "prompt": "A horse running through a snowy forest",
  "duration": 5,
  "callback_url": "https://your-domain.com/callback/happyhorse"
}
```

Το αποτέλεσμα που επιστρέφεται αμέσως είναι το εξής:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

Εάν επιθυμείτε μόνο polling και δεν χρειάζεστε callback, μπορείτε επίσης να περάσετε το `"async": true` και στη συνέχεια να ερωτήσετε το αποτέλεσμα της εργασίας μέσω του [HappyHorse Tasks API](https://platform.acedata.cloud/documents/happyhorse-tasks).

## Πληροφορίες χρέωσης

Το HappyHorse χρεώνει με βάση τα δευτερόλεπτα του παραγόμενου βίντεο και την ανάλυση:

- `720P`: από περίπου $0.105 / δευτερόλεπτο.
- `1080P`: από περίπου $0.18 / δευτερόλεπτο.
- `video_edit`: χρεώνεται με βάση το συνολικό μήκος του βίντεο εισόδου και του βίντεο εξόδου· η πραγματική χρεώσιμη διάρκεια βασίζεται στα στατιστικά μετά την ολοκλήρωση της εργασίας.

Οι αποτυχημένες εργασίες δεν χρεώνονται και δεν καταναλώνουν το δωρεάν όριο.

## Χειρισμός σφαλμάτων

Όταν υπάρχει πρόβλημα με το αίτημα, το API επιστρέφει τον αντίστοιχο κωδικό σφάλματος και περιγραφή· τα συνήθη είναι τα εξής:

- `400`: Λανθασμένες παράμετροι αιτήματος, για παράδειγμα το action δεν ταιριάζει με το model, λείπει το `prompt` / `image_url` / `video_url`, ή το `duration` είναι εκτός του εύρους 3–15 δευτερολέπτων.
- `401`: Αποτυχία αυθεντικοποίησης, το token είναι μη έγκυρο ή δεν αντιστοιχεί στο API.
- `403`: Ανεπαρκές υπόλοιπο ή το prompt απορρίφθηκε επειδή ενεργοποίησε τον έλεγχο περιεχομένου.
- `429`: Τα αιτήματα είναι υπερβολικά συχνά, ενεργοποιήθηκε ο περιορισμός ρυθμού, δοκιμάστε ξανά αργότερα.
- `500`: Εσωτερικό σφάλμα διακομιστή ή αποτυχία δημιουργίας.
