Το Claude Messages Count Tokens API μπορεί, χωρίς να δημιουργεί πραγματικά μηνύματα, να υπολογίζει τον αριθμό των εισερχόμενων Token ενός Message, συμπεριλαμβανομένης της καταμέτρησης Token για εργαλεία, εικόνες και έγγραφα και άλλο περιεχόμενο. Αυτό είναι πολύ χρήσιμο όταν χρειάζεται να εκτιμηθεί το κόστος ή να ελεγχθεί αν η είσοδος υπερβαίνει το όριο περιβάλλοντος του μοντέλου.

Αυτό το έγγραφο παρουσιάζει κυρίως τη διαδικασία χρήσης του Claude Messages Count Tokens API.

Το `claude-fable-5-2` δεν παρέχει προς το παρόν διεπαφή Count Tokens. Η τελική χρήση για αιτήματα δημιουργίας μπορεί να προβληθεί από το `usage` στην απόκριση Messages· μην χρησιμοποιείτε τα αποτελέσματα καταμέτρησης άλλων μοντέλων ως υποκατάστατο της ακριβούς χρήσης αυτού του μοντέλου.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Claude Messages Count Tokens API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να λάβετε το API Token σας, και κρατήστε το ως εφεδρικό.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης, η οποία θα σας προσκαλέσει να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση προσφέρει δωρεάν υπόλοιπο, ώστε να μπορείτε να δοκιμάσετε δωρεάν· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να επαναφορτίσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Βασική χρήση

Η διαδρομή αιτήματος του Claude Messages Count Tokens API είναι `/v1/messages/count_tokens`, παραμένοντας συνεπής με το επίσημο API της Anthropic. Πρέπει τουλάχιστον να παρέχουμε δύο υποχρεωτικές παραμέτρους:

- `model`: Συμπληρώστε το πλήρες ID μοντέλου από τη λίστα μοντέλων αυτής της διεπαφής και χρησιμοποιήστε το ίδιο μοντέλο με τα επόμενα αιτήματα Messages.
- `messages`: Ο πίνακας εισερχόμενων μηνυμάτων, όπου κάθε μήνυμα περιλαμβάνει `role` (ρόλος) και `content` (περιεχόμενο).

Συνήθεις προαιρετικές παράμετροι:

- `system`: Προτροπή συστήματος, η οποία θα συμπεριληφθεί στον αριθμό Token.
- `tools`: Ορισμοί εργαλείων, οι οποίοι θα συμπεριληφθούν στον αριθμό Token.
- `thinking`: Διαμόρφωση εκτεταμένης σκέψης.
- `tool_choice`: Διαμόρφωση επιλογής εργαλείου.
- `cache_control`: Διαμόρφωση ελέγχου προσωρινής αποθήκευσης ανώτατου επιπέδου ή επιπέδου μπλοκ περιεχομένου.

Τα `messages`, `system`, η επανάληψη κλήσεων εργαλείων, οι εικόνες URL και τα μπλοκ περιεχομένου document/PDF χρησιμοποιούν την ίδια σταθερή δομή αιτήματος με το Messages API.

### Παράδειγμα cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Παράδειγμα Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Παράδειγμα αποτελέσματος επιστροφής:

```json
{
  "input_tokens": 11
}
```

### Χρήση του Anthropic SDK

Το Claude Messages Count Tokens API δέχεται τη σταθερή δομή αιτήματος του Anthropic SDK και μπορεί να κληθεί μέσω της βιβλιοθήκης `anthropic`. Η διεπαφή υπολογίζει τα εισερχόμενα Token βάσει του επιλεγμένου μοντέλου και μπορεί να χρησιμοποιηθεί για τον έλεγχο της κλίμακας εισόδου πριν από την αποστολή ενός αιτήματος Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Καταμέτρηση Token που περιλαμβάνει εργαλεία

Αν το αίτημά σας περιλαμβάνει ορισμούς εργαλείων, αυτά τα εργαλεία θα συμπεριληφθούν επίσης στον αριθμό Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Καταμέτρηση Token που περιλαμβάνει προτροπή συστήματος

Η προτροπή συστήματος θα συμπεριληφθεί επίσης στον αριθμό Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Σημειώσεις

- Αυτό το API υπολογίζει μόνο τον αριθμό των εισερχόμενων Token και δεν θα παράγει καμία έξοδο μοντέλου.
- Τα αποτελέσματα καταμέτρησης Token μπορούν να χρησιμοποιηθούν για την εκτίμηση της κλίμακας εισόδου και τον έλεγχο του παραθύρου περιβάλλοντος· η τελική χρέωση βασίζεται στο `usage` στην πραγματική απόκριση Messages.
- Οι εικόνες, τα PDF, οι ορισμοί εργαλείων, οι προτροπές συστήματος και η διαμόρφωση thinking θα συμπεριληφθούν στο αποτέλεσμα σύμφωνα με τους κανόνες εισόδου του επιλεγμένου μοντέλου.
- Αυτό το API είναι εντελώς δωρεάν και δεν καταναλώνει κανένα υπόλοιπο.
