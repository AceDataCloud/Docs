Claude Messages Count Tokens API μπορεί να υπολογίσει τον αριθμό των εισερχόμενων Token ενός μηνύματος χωρίς να δημιουργήσει πραγματικά το μήνυμα, συμπεριλαμβανομένων των Token που σχετίζονται με εργαλεία, εικόνες και έγγραφα. Αυτό είναι πολύ χρήσιμο όταν χρειάζεται να εκτιμήσετε το κόστος ή να ελέγξετε αν η είσοδος υπερβαίνει τα όρια του μοντέλου.

Αυτό το έγγραφο περιγράφει τη διαδικασία χρήσης του Claude Messages Count Tokens API.

## 申请流程

Για να χρησιμοποιήσετε το Claude Messages Count Tokens API, μπορείτε πρώτα να επισκεφθείτε τη σελίδα [Claude Messages Count Tokens API](https://platform.acedata.cloud/documents/claude-messages-count-tokens) και να κάνετε κλικ στο κουμπί «Acquire» για να αποκτήσετε τα διαπιστευτήρια που απαιτούνται για την αίτηση.

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να σας προσκαλέσουν να εγγραφείτε και να συνδεθείτε, και μετά την εγγραφή και σύνδεση θα επιστρέψετε αυτόματα στη σελίδα.

Αυτή η API είναι εντελώς δωρεάν, χωρίς καμία κατανάλωση πίστωσης.

## 基本使用

Η διαδρομή αίτησης του Claude Messages Count Tokens API είναι `/v1/messages/count_tokens`, διατηρώντας τη συμφωνία με την επίσημη API της Anthropic. Πρέπει τουλάχιστον να παρέχουμε δύο υποχρεωτικές παραμέτρους:

- `model`: Επιλέξτε το μοντέλο Claude που θα χρησιμοποιήσετε, όπως `claude-sonnet-4-5-20250929`, `claude-opus-4-20250514` κ.λπ.
- `messages`: Πίνακας μηνυμάτων εισόδου, όπου κάθε μήνυμα περιλαμβάνει `role` (ρόλος) και `content` (περιεχόμενο).

Συνηθισμένες προαιρετικές παράμετροι:

- `system`: Σύστημα προτροπής, θα υπολογιστεί στον αριθμό των Token.
- `tools`: Ορισμός εργαλείων, θα υπολογιστεί στον αριθμό των Token.
- `thinking`: Ρυθμίσεις επεκταμένης σκέψης.

### cURL 示例

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-sonnet-4-5-20250929",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python 示例

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-sonnet-4-5-20250929",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

返回结果示例：

```json
{
  "input_tokens": 11
}
```

### 使用 Anthropic SDK

Το Claude Messages Count Tokens API είναι πλήρως συμβατό με το επίσημο SDK της Anthropic και μπορείτε να χρησιμοποιήσετε απευθείας τη βιβλιοθήκη `anthropic` για να το καλέσετε.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-sonnet-4-5-20250929",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## 包含工具的 Token 计数

Εάν η αίτησή σας περιλαμβάνει ορισμούς εργαλείων, αυτά τα εργαλεία θα υπολογιστούν επίσης στον αριθμό των Token:

```python
result = client.messages.count_tokens(
    model="claude-sonnet-4-5-20250929",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## 包含系统提示词的 Token 计数

Οι προτροπές συστήματος θα υπολογιστούν επίσης στον αριθμό των Token:

```python
result = client.messages.count_tokens(
    model="claude-sonnet-4-5-20250929",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## 注意事项

- Αυτή η API υπολογίζει μόνο τον αριθμό των εισερχόμενων Token και δεν θα παράγει καμία έξοδο μοντέλου.
- Τα αποτελέσματα του υπολογισμού Token μπορούν να χρησιμοποιηθούν για την εκτίμηση του κόστους κλήσης της Claude Messages API.
- Ο τρόπος Tokenization μπορεί να διαφέρει μεταξύ διαφορετικών μοντέλων, παρακαλώ χρησιμοποιήστε την παράμετρο model που είναι ίδια με αυτήν που θα χρησιμοποιήσετε στην πραγματική κλήση.
- Αυτή η API είναι εντελώς δωρεάν και δεν καταναλώνει καμία πίστωσή.
