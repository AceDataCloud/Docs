Το Claude Messages Count Tokens API μπορεί να υπολογίζει τον αριθμό των Token εισόδου ενός Message χωρίς να δημιουργεί πραγματικά μηνύματα, συμπεριλαμβανομένης της καταμέτρησης Token για εργαλεία, εικόνες και έγγραφα. Αυτό είναι πολύ χρήσιμο όταν χρειάζεται να εκτιμήσετε το κόστος ή να ελέγξετε αν η είσοδος υπερβαίνει το όριο συμφραζομένων του μοντέλου.

Αυτό το έγγραφο παρουσιάζει κυρίως τη διαδικασία χρήσης του Claude Messages Count Tokens API.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Claude Messages Count Tokens API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης, όπου θα σας προσκληθεί να εγγραφείτε και να συνδεθείτε· μετά την ολοκλήρωση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση προσφέρει δωρεάν πίστωση, ώστε να μπορείτε να το δοκιμάσετε δωρεάν· όταν η πίστωση δεν επαρκεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Βασική χρήση

Η διαδρομή αιτήματος του Claude Messages Count Tokens API είναι `/v1/messages/count_tokens`, παραμένοντας συνεπής με το επίσημο API της Anthropic. Χρειάζεται τουλάχιστον να παρέχουμε δύο υποχρεωτικές παραμέτρους:

- `model`: Επιλέξτε το μοντέλο Claude που θα χρησιμοποιηθεί· το `claude-opus-5-5` μπορεί να χρησιμοποιηθεί για Messages Token Count, όπως και το νεότερο κορυφαίο `claude-fable-5-1`· το προηγούμενο `claude-fable-5` παραμένει συμβατό. Το `claude-sonnet-5-5` έχει προστεθεί στη εγγενή διεπαφή της σειράς Messages, υποστηρίζοντας είσοδο εικόνας και προσαρμοστική σκέψη· οι επίσημες τιμές αναφοράς για την είσοδο, την έξοδο και την ανάγνωση cache είναι αντίστοιχα 2, 10 και 0,20 δολάρια ΗΠΑ ανά ένα εκατομμύριο Token.
- `messages`: Ο πίνακας των μηνυμάτων εισόδου, όπου κάθε μήνυμα περιλαμβάνει `role` (ρόλο) και `content` (περιεχόμενο).

Συνήθεις προαιρετικές παράμετροι:

- `system`: Η προτροπή συστήματος, η οποία θα υπολογιστεί στον αριθμό Token.
- `tools`: Ορισμοί εργαλείων, οι οποίοι θα υπολογιστούν στον αριθμό Token.
- `thinking`: Διαμόρφωση εκτεταμένης σκέψης.
- `tool_choice`: Διαμόρφωση επιλογής εργαλείου.
- `cache_control`: Διαμόρφωση ελέγχου cache επιπέδου κορυφής ή επιπέδου μπλοκ περιεχομένου.

Τα μπλοκ περιεχομένου `messages`, `system`, αναπαραγωγής κλήσεων εργαλείων, εικόνων URL και document/PDF χρησιμοποιούν την ίδια σταθερή δομή αιτήματος με το Messages API.

### Παράδειγμα cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Παράδειγμα Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Παράδειγμα αποτελέσματος επιστροφής:

```json
{
  "input_tokens": 11
}
```

### Χρήση του Anthropic SDK

Το Claude Messages Count Tokens API δέχεται τη σταθερή δομή αιτήματος του Anthropic SDK και μπορεί να κληθεί μέσω της βιβλιοθήκης `anthropic`. Η διεπαφή χρησιμοποιεί την εγγενή δυνατότητα Count Tokens που αντιστοιχεί στο επιλεγμένο μοντέλο για να υπολογίσει την είσοδο και μπορεί να χρησιμοποιηθεί για τον έλεγχο της κλίμακας εισόδου πριν από την αποστολή αιτήματος Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Καταμέτρηση Token που περιλαμβάνει εργαλεία

Αν το αίτημά σας περιλαμβάνει ορισμούς εργαλείων, αυτά τα εργαλεία θα υπολογιστούν επίσης στον αριθμό Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Καταμέτρηση Token που περιλαμβάνει προτροπές συστήματος

Οι προτροπές συστήματος θα υπολογιστούν επίσης στον αριθμό Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Σημειώσεις

- Αυτό το API υπολογίζει μόνο τον αριθμό των Token εισόδου και δεν θα παράγει καμία έξοδο μοντέλου.
- Τα αποτελέσματα καταμέτρησης Token μπορούν να χρησιμοποιηθούν για την εκτίμηση της κλίμακας εισόδου και τον έλεγχο του παραθύρου συμφραζομένων· η τελική χρέωση βασίζεται στο `usage` στην πραγματική απόκριση Messages.
- Οι εικόνες, τα PDF, οι ορισμοί εργαλείων, οι προτροπές συστήματος και η διαμόρφωση thinking θα υπολογιστούν στο αποτέλεσμα σύμφωνα με τους κανόνες εισόδου του επιλεγμένου μοντέλου.
- Αυτό το API είναι εντελώς δωρεάν και δεν καταναλώνει καμία πίστωση.
