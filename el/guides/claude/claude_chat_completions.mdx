Το Anthropic Claude είναι ένα πολύ ισχυρό σύστημα διαλόγου AI· αρκεί να εισαγάγετε ένα prompt και μπορεί να δημιουργήσει ομαλές και φυσικές απαντήσεις μέσα σε λίγα δευτερόλεπτα. Το Claude ξεχωρίζει στον κλάδο για τις εξαιρετικές του ικανότητες κατανόησης και παραγωγής γλώσσας· σήμερα, το Claude χρησιμοποιείται ήδη ευρέως σε διάφορους κλάδους και τομείς, με την επιρροή του να γίνεται ολοένα και πιο εμφανής. Είτε πρόκειται για καθημερινό διάλογο, δημιουργική συγγραφή, είτε για επαγγελματική συμβουλευτική και προγραμματισμό κώδικα, το Claude μπορεί να παρέχει εκπληκτική έξυπνη βοήθεια, βελτιώνοντας σημαντικά την αποδοτικότητα και τη δημιουργικότητα των ανθρώπων.

Το παρόν έγγραφο παρουσιάζει κυρίως τη διαδικασία χρήσης των λειτουργιών του Claude Chat Completion API, με το οποίο μπορούμε να χρησιμοποιήσουμε εύκολα τη λειτουργία διαλόγου του επίσημου Claude.

## Claude Fable 5.2

Χρησιμοποιήστε το πλήρες μοντέλο `claude-fable-5-2`. Αυτό το μοντέλο είναι κατάλληλο για σύνθετη συλλογιστική και μακροχρόνιες εργασίες· όταν απαιτούνται εγγενή μπλοκ περιεχομένου σκέψης και αλληλεπίδραση με εργαλεία, προτιμήστε τα Messages. Η προσαρμοστική σκέψη είναι συνεχώς ενεργοποιημένη, παραλείψτε τα `temperature`, `top_p`, `top_k`, χρησιμοποιήστε `auto` για την επιλογή εργαλείου και μην καθορίζετε αναγκαστικά εργαλεία. Το `max_tokens` καλύπτει ταυτόχρονα τη σκέψη και το τελικό κείμενο. Προς το παρόν δεν παρέχονται διεπαφές Responses και Count Tokens για αυτό το μοντέλο.

Με βάση το τρέχον μέγιστο πακέτο (142,800 Credits／$13,584), η κανονική είσοδος του Fable 5.2 είναι $3.20 και η έξοδος $16／ανά εκατομμύριο token· η ανάγνωση cache είναι $0.08, ενώ η εγγραφή cache για 5 λεπτά／1 ώρα είναι αντίστοιχα $4／$6.40／ανά εκατομμύριο token. Οι παραπάνω τιμές είναι το 40% της επίσημης τυπικής τιμής μονάδας API (60% φθηνότερα)· για άλλα πακέτα και πρόσθετες εκπτώσεις λογαριασμού, ανατρέξτε στη σελίδα τιμολόγησης μοντέλων και στον λογαριασμό χρέωσης.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση παρέχει δωρεάν υπόλοιπο, ώστε να μπορείτε να το δοκιμάσετε δωρεάν· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να επαναφορτίσετε το κοινό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

## Βασική χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε το αντίστοιχο περιεχόμενο στη διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/ejeq57.png" width="400" className="m-auto" /></p>

Κατά την πρώτη χρήση αυτής της διεπαφής, χρειάζεται να συμπληρώσουμε τουλάχιστον τρία στοιχεία: το ένα είναι το `authorization`, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα. Μια άλλη παράμετρος είναι το `model`, όπου μπορείτε να επιλέξετε δημόσια μοντέλα όπως `claude-opus-5-5`, `claude-fable-5-1`· το αρχικό `claude-fable-5` μπορεί ακόμη να συνεχίσει να καλείται. Η τελευταία παράμετρος είναι το `messages`, το οποίο είναι ένας πίνακας μηνυμάτων ερωτήσεων και κάθε στοιχείο περιλαμβάνει `role` και `content`· το `role` υποστηρίζει `user`, `assistant`, `system`, ενώ το `content` είναι το συγκεκριμένο περιεχόμενο. Όταν απαιτούνται πλήρη μπλοκ περιεχομένου σκέψης του Claude, υπογραφές και εγγενής σημασιολογία εργαλείων, συνεχίστε να χρησιμοποιείτε το Messages API.

Ταυτόχρονα, μπορείτε να παρατηρήσετε ότι στα δεξιά υπάρχει η δημιουργία του αντίστοιχου κώδικα κλήσης· μπορείτε να αντιγράψετε τον κώδικα και να τον εκτελέσετε απευθείας ή να κάνετε απευθείας κλικ στο κουμπί «Try» για δοκιμή.

Συνήθεις προαιρετικές παράμετροι:

- `max_tokens`: Περιορίζει τον μέγιστο αριθμό token για μία απάντηση.
- `temperature`: Η τυχαιότητα της παραγωγής, μεταξύ 0-2· όσο μεγαλύτερη είναι η τιμή, τόσο πιο αποκλίνουσα είναι.
- `n`: Πόσες υποψήφιες απαντήσεις παράγονται κάθε φορά.
- `response_format`: Ρύθμιση μορφής επιστροφής.

Το `claude-opus-5-5` υποστηρίζει κανονικά και streaming Chat Completions· αυτό το μοντέλο επιτρέπει μόνο `n=1`. Μην ορίζετε για αυτό `temperature` χαμηλότερο από 1 ή μη προεπιλεγμένο `top_p`, για κλήση εργαλείων χρησιμοποιήστε `tool_choice: "auto"` και μην καθορίζετε αναγκαστικά εργαλεία. Η συμβατή διεπαφή Chat δεν επιστρέφει εγγενή μπλοκ περιεχομένου σκέψης.

<p><img src="https://cdn.acedata.cloud/v6lbjo.png" width="400" className="m-auto" /></p>

Μετά την κλήση, διαπιστώνουμε ότι το αποτέλεσμα επιστροφής είναι το εξής:

```json
{
  "id": "msg_bdrk_01Q6WN27v95ypCa1kbanAQ6K",
  "model": "claude-opus-4-8",
  "object": "chat.completion",
  "created": 1768619365,
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 8,
    "completion_tokens": 12,
    "total_tokens": 20,
    "prompt_tokens_details": {
      "cached_tokens": 0,
      "cache_write_tokens": 0
    },
    "completion_tokens_details": {
      "reasoning_tokens": 0
    }
  }
}
```

Το αποτέλεσμα επιστροφής έχει πολλαπλά πεδία, τα οποία παρουσιάζονται ως εξής:

- `id`, το ID που δημιουργείται για αυτήν την εργασία διαλόγου και χρησιμοποιείται για τη μοναδική αναγνώρισή της.
- `model `, το επιλεγμένο μοντέλο από την επίσημη ιστοσελίδα του Claude.
- `choices`, οι πληροφορίες απάντησης που δίνει το Claude για το prompt ερώτησης.
- `usage `: στατιστικές πληροφορίες για τα token αυτής της ερώτησης και απάντησης.

Στη μορφή Chat Completions, το `usage.prompt_tokens` είναι ο συνολικός όγκος εισόδου· τα `prompt_tokens_details.cached_tokens` και `prompt_tokens_details.cache_write_tokens` καταγράφουν αντίστοιχα τις λεπτομέρειες ανάγνωσης και εγγραφής cache. Το `completion_tokens_details.reasoning_tokens` είναι υποσύνολο του `completion_tokens` και δεν πρέπει να προστεθεί ξανά κατά τον υπολογισμό του συνολικού όγκου ή του κόστους. Οι μη-streaming απαντήσεις μπορεί επίσης να επιστρέφουν το αντικείμενο `usage.cost`, όπου το `amount` είναι η πραγματική κατανάλωση υπολοίπου, το `currency` είναι η μονάδα μέτρησης και το `list_amount` είναι το ποσό πριν από την έκπτωση (εάν υπάρχει).

Το όνομα πεδίου του Chat-compatible είναι `reasoning_tokens`· το εγγενές Messages API χρησιμοποιεί `output_tokens_details.thinking_tokens`. Τα wire schema των δύο πρωτοκόλλων είναι διαφορετικά και ο client δεν πρέπει να αναμειγνύει τα ονόματα πεδίων.

Μεταξύ αυτών, το `choices` περιλαμβάνει τις πληροφορίες απάντησης του Claude, και το `choices` μέσα σε αυτό είναι οι συγκεκριμένες πληροφορίες της απάντησης του Claude, όπως φαίνεται στην εικόνα.

<p><img src="https://cdn.acedata.cloud/2ulyhw.png" width="400" className="m-auto" /></p>

Μπορείτε να δείτε ότι το πεδίο `content` μέσα στο `choices` περιλαμβάνει το συγκεκριμένο περιεχόμενο της απάντησης του Claude.

## Streaming απόκριση

Αυτή η διεπαφή υποστηρίζει επίσης streaming απόκριση, κάτι που είναι πολύ χρήσιμο για ενσωμάτωση σε ιστοσελίδες και επιτρέπει την υλοποίηση εφέ εμφάνισης χαρακτήρα προς χαρακτήρα.

Αν θέλετε η απόκριση να επιστρέφεται ως stream, μπορείτε να αλλάξετε την παράμετρο `stream ` στην κεφαλίδα αιτήματος σε `true`.

Η τροποποίηση φαίνεται στην εικόνα, ωστόσο ο κώδικας κλήσης χρειάζεται τις αντίστοιχες αλλαγές για να υποστηρίξει streaming απόκριση.

<p><img src="https://cdn.acedata.cloud/ueugot.png" width="400" className="m-auto" /></p>
Αφού τροποποιήσετε το `stream` σε `true`, το API θα επιστρέφει τα αντίστοιχα δεδομένα JSON γραμμή προς γραμμή και χρειάζεται να κάνουμε τις αντίστοιχες τροποποιήσεις σε επίπεδο κώδικα για να λάβουμε τα αποτελέσματα γραμμή προς γραμμή.

Παράδειγμα κώδικα κλήσης Python:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "claude-opus-4-20250514",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Εκτενής σκέψη

Τα μοντέλα Claude νέας γενιάς ενδέχεται να εκτελούν συλλογισμό σύμφωνα με την προεπιλεγμένη στρατηγική του μοντέλου, χωρίς να απαιτείται ενεργοποίηση μέσω του επιθήματος μοντέλου `-thinking`. Οι αποκρίσεις συμβατές με Chat χρησιμοποιούν το πεδίο usage συμβατό με OpenAI `completion_tokens_details.reasoning_tokens`. Το `reasoning_tokens` περιλαμβάνεται ήδη στο `completion_tokens`, μην το προσθέτετε ξανά. Ο συλλογισμός και το ορατό κυρίως κείμενο μοιράζονται το ανώτατο όριο token εξόδου, επομένως όταν το `max_tokens` είναι μικρό, το κυρίως κείμενο μπορεί να είναι κενό ή να περικοπεί· σε αυτήν την περίπτωση, αυξήστε τον προϋπολογισμό εξόδου ή, όταν υποστηρίζεται από το χρησιμοποιούμενο μοντέλο, επιλέξτε χαμηλότερη ένταση συλλογισμού.

Εάν χρειάζεστε εγγενές `thinking`, `output_config.effort`, μπλοκ περιεχομένου thinking και επιστροφή υπογραφής, χρησιμοποιήστε το `/v1/messages`. Το αντίστοιχο πεδίο usage των Messages είναι το `output_tokens_details.thinking_tokens`, μην το συγχέετε με το `completion_tokens_details.reasoning_tokens` του Chat-compatible.

## Μοντέλο όρασης

Το claude-sonnet-4-20250514 είναι ένα πολυτροπικό μεγάλο γλωσσικό μοντέλο που αναπτύχθηκε από το Claude, και προσθέτει δυνατότητα οπτικής κατανόησης πάνω στη βάση του claude-4. Αυτό το μοντέλο μπορεί να επεξεργάζεται ταυτόχρονα εισόδους κειμένου και εικόνας, επιτυγχάνοντας διατροπική κατανόηση και δημιουργία.

Η επεξεργασία κειμένου με το μοντέλο claude-sonnet-4-20250514 είναι συνεπής με το περιεχόμενο βασικής χρήσης παραπάνω, και παρακάτω θα παρουσιαστεί συνοπτικά ο τρόπος χρήσης της δυνατότητας επεξεργασίας εικόνων του μοντέλου.

Η χρήση της δυνατότητας επεξεργασίας εικόνων του μοντέλου claude-sonnet-4-20250514 γίνεται κυρίως με την προσθήκη ενός πεδίου `type` στο αρχικό περιεχόμενο `content`. Μέσω αυτού του πεδίου μπορεί να γίνει γνωστό εάν αυτό που μεταφορτώνεται είναι κείμενο ή εικόνα, ώστε να χρησιμοποιηθεί η δυνατότητα επεξεργασίας εικόνων του μοντέλου claude-sonnet-4-20250514. Παρακάτω περιγράφονται κυρίως δύο τρόποι κλήσης αυτής της λειτουργίας, με Curl και Python.

- Μέθοδος σεναρίου Python

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "claude-sonnet-4-20250514",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://cdn.acedata.cloud/ueugot.png"
                    }
                },
            ],
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Χειρισμός σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό και μήνυμα σφάλματος. Για παράδειγμα:

- `400 token_mismatched`：Μη έγκυρο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Μη έγκυρο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές token εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
