Το Anthropic Claude είναι ένα εξαιρετικά ισχυρό σύστημα διαλόγου AI, το οποίο μπορεί να δημιουργήσει ομαλές και φυσικές απαντήσεις μέσα σε λίγα δευτερόλεπτα, αρκεί να εισαγάγετε μια προτροπή. Το Claude ξεχωρίζει στον κλάδο χάρη στις εξαιρετικές του δυνατότητες κατανόησης και παραγωγής γλώσσας. Σήμερα, το Claude χρησιμοποιείται ήδη ευρέως σε διάφορους κλάδους και τομείς, με την επιρροή του να γίνεται ολοένα και πιο σημαντική. Είτε πρόκειται για καθημερινές συνομιλίες, δημιουργική γραφή, είτε για επαγγελματικές συμβουλές και προγραμματισμό κώδικα, το Claude μπορεί να παρέχει εντυπωσιακή έξυπνη υποστήριξη, βελτιώνοντας σημαντικά την αποδοτικότητα και τη δημιουργικότητα των ανθρώπων.

Αυτό το έγγραφο παρουσιάζει κυρίως τη διαδικασία χρήσης των λειτουργιών του Claude Chat Completion API. Με αυτό μπορούμε να χρησιμοποιήσουμε εύκολα τη λειτουργία συνομιλίας του επίσημου Claude.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Claude Chat Completion API, μεταβείτε αρχικά στην [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης, όπου θα σας προσκληθεί να εγγραφείτε και να συνδεθείτε. Μετά την ολοκλήρωση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να απαιτείται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση προσφέρει δωρεάν υπόλοιπο για δωρεάν δοκιμή· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Claude Chat Completion API →](https://platform.acedata.cloud/documents/claude-chat-completions)

## Βασική χρήση

Στη συνέχεια, μπορείτε να συμπληρώσετε το αντίστοιχο περιεχόμενο στη διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/ejeq57.png" width="400" className="m-auto" /></p>

Κατά την πρώτη χρήση αυτής της διεπαφής, πρέπει να συμπληρώσουμε τουλάχιστον τρία στοιχεία. Το πρώτο είναι το `authorization`, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα. Η άλλη παράμετρος είναι το `model`, και συνιστάται η χρήση του νεότερου κορυφαίου μοντέλου `claude-fable-5-1`· το αρχικό `claude-fable-5` μπορεί επίσης να συνεχίσει να καλείται. Η τελευταία παράμετρος είναι το `messages`, το οποίο είναι ένας πίνακας ερωτήσεων, όπου κάθε στοιχείο περιλαμβάνει τα `role` και `content`· το `role` υποστηρίζει τα `user`, `assistant`, `system`, και το `content` είναι το συγκεκριμένο περιεχόμενο. Το Claude Fable 5.1 υποστηρίζει πλαίσιο 1 εκατομμυρίου Token και μέγιστη έξοδο 128K Token.

Παράλληλα, μπορείτε να παρατηρήσετε ότι στα δεξιά υπάρχει η αντίστοιχη δημιουργία κώδικα κλήσης. Μπορείτε να αντιγράψετε τον κώδικα και να τον εκτελέσετε απευθείας ή να κάνετε κλικ απευθείας στο κουμπί «Try» για δοκιμή.

Συνήθεις προαιρετικές παράμετροι:

- `max_tokens`：Περιορίζει τον μέγιστο αριθμό token για μία απάντηση.
- `temperature`：Τυχαιότητα παραγωγής, μεταξύ 0-2· όσο μεγαλύτερη είναι η τιμή, τόσο πιο αποκλίνουσα είναι η έξοδος.
- `n`：Πόσες υποψήφιες απαντήσεις παράγονται κάθε φορά.
- `response_format`：Ρύθμιση μορφής επιστροφής.

<p><img src="https://cdn.acedata.cloud/v6lbjo.png" width="400" className="m-auto" /></p>

Μετά την κλήση, διαπιστώνουμε ότι το αποτέλεσμα επιστροφής είναι το εξής:

```json
{
  "id": "msg_bdrk_01Q6WN27v95ypCa1kbanAQ6K",
  "model": "claude-opus-4-8",
  "object": "chat.completion",
  "created": 1768619365,
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 8,
    "completion_tokens": 12,
    "total_tokens": 20,
    "prompt_tokens_details": {
      "cached_tokens": 0,
      "cache_write_tokens": 0
    },
    "completion_tokens_details": {
      "reasoning_tokens": 0
    }
  }
}
```

Το αποτέλεσμα επιστροφής περιλαμβάνει πολλά πεδία, τα οποία παρουσιάζονται παρακάτω:

- `id`，Το ID που δημιουργείται για αυτήν την εργασία συνομιλίας και χρησιμοποιείται για τη μοναδική αναγνώρισή της.
- `model `，Το μοντέλο Claude του επίσημου ιστότοπου που επιλέχθηκε.
- `choices`，Οι πληροφορίες απάντησης που παρέχει το Claude για την προτροπή.
- `usage `：Στατιστικές πληροφορίες token για αυτήν την ερώτηση και απάντηση.

Στη μορφή Chat Completions, το `usage.prompt_tokens` είναι ο συνολικός όγκος εισόδου· τα `prompt_tokens_details.cached_tokens` και `prompt_tokens_details.cache_write_tokens` καταγράφουν αντίστοιχα τις λεπτομέρειες ανάγνωσης και εγγραφής της προσωρινής μνήμης. Το `completion_tokens_details.reasoning_tokens` είναι υποσύνολο του `completion_tokens` και δεν πρέπει να προστεθεί ξανά κατά τον υπολογισμό του συνολικού όγκου ή του κόστους. Οι μη ροϊκές αποκρίσεις ενδέχεται επίσης να επιστρέφουν ένα αντικείμενο `usage.cost`, όπου το `amount` είναι η πραγματική κατανάλωση υπολοίπου, το `currency` είναι η μονάδα μέτρησης και το `list_amount` είναι το ποσό πριν από την έκπτωση (εάν υπάρχει).

Το όνομα πεδίου συμβατό με Chat είναι `reasoning_tokens`· το εγγενές Messages API χρησιμοποιεί το `output_tokens_details.thinking_tokens`. Το wire schema των δύο πρωτοκόλλων διαφέρει και ο πελάτης δεν πρέπει να αναμειγνύει τα ονόματα πεδίων.

Μεταξύ αυτών, το `choices` περιλαμβάνει τις πληροφορίες απάντησης του Claude, και το `choices` στο εσωτερικό του είναι η συγκεκριμένη πληροφορία της απάντησης του Claude, όπως φαίνεται στην εικόνα.

<p><img src="https://cdn.acedata.cloud/2ulyhw.png" width="400" className="m-auto" /></p>

Μπορείτε να δείτε ότι το πεδίο `content` μέσα στο `choices` περιλαμβάνει το συγκεκριμένο περιεχόμενο της απάντησης του Claude.

## Ροϊκή απόκριση

Αυτή η διεπαφή υποστηρίζει επίσης ροϊκές αποκρίσεις, κάτι που είναι ιδιαίτερα χρήσιμο για τη σύνδεση με ιστοσελίδες, καθώς επιτρέπει την υλοποίηση εφέ εμφάνισης χαρακτήρα προς χαρακτήρα.

Εάν θέλετε να επιστρέφεται ροϊκά η απόκριση, μπορείτε να αλλάξετε την παράμετρο `stream ` στην κεφαλίδα του αιτήματος σε `true`.

Η τροποποίηση φαίνεται στην εικόνα, αλλά ο κώδικας κλήσης χρειάζεται τις αντίστοιχες αλλαγές για να υποστηρίζει ροϊκές αποκρίσεις.

<p><img src="https://cdn.acedata.cloud/ueugot.png" width="400" className="m-auto" /></p>

Αφού αλλάξετε το `stream` σε `true`, το API θα επιστρέφει τα αντίστοιχα δεδομένα JSON γραμμή προς γραμμή. Σε επίπεδο κώδικα, πρέπει να κάνουμε τις αντίστοιχες τροποποιήσεις για να λάβουμε τα αποτελέσματα ανά γραμμή.

Δείγμα κώδικα κλήσης Python:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "claude-opus-4-20250514",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Βαθιά σκέψη
Η νέα γενιά μοντέλων Claude ενδέχεται να πραγματοποιεί συλλογισμό σύμφωνα με την προεπιλεγμένη πολιτική του μοντέλου, χωρίς να χρειάζεται να ενεργοποιηθεί μέσω του επιθήματος μοντέλου `-thinking`. Οι αποκρίσεις συμβατές με Chat χρησιμοποιούν το πεδίο usage συμβατό με OpenAI `completion_tokens_details.reasoning_tokens`. Το `reasoning_tokens` περιλαμβάνεται ήδη στο `completion_tokens`, μην το προσθέτετε ξανά. Ο συλλογισμός και το ορατό κυρίως κείμενο μοιράζονται το ανώτατο όριο token εξόδου, επομένως όταν το `max_tokens` είναι μικρό, το κυρίως κείμενο ενδέχεται να είναι κενό ή να περικόπτεται· σε αυτήν την περίπτωση αυξήστε τον προϋπολογισμό εξόδου ή, όταν υποστηρίζεται από το μοντέλο που χρησιμοποιείται, επιλέξτε χαμηλότερη ένταση συλλογισμού.

Εάν χρειάζεστε εγγενές `thinking`, `output_config.effort`, μπλοκ περιεχομένου thinking και επιστροφή υπογραφής, χρησιμοποιήστε το `/v1/messages`. Το αντίστοιχο πεδίο usage των Messages είναι `output_tokens_details.thinking_tokens`, μην το συγχέετε με το `completion_tokens_details.reasoning_tokens` του Chat-compatible.

## Μοντέλο όρασης

Το claude-sonnet-4-20250514 είναι ένα πολυτροπικό μεγάλο γλωσσικό μοντέλο που αναπτύχθηκε από την Claude, και προσθέτει δυνατότητες οπτικής κατανόησης με βάση το claude-4. Αυτό το μοντέλο μπορεί να επεξεργάζεται ταυτόχρονα εισόδους κειμένου και εικόνων, επιτυγχάνοντας διατροπική κατανόηση και παραγωγή.

Η επεξεργασία κειμένου με το μοντέλο claude-sonnet-4-20250514 είναι συνεπής με το βασικό περιεχόμενο χρήσης που αναφέρθηκε παραπάνω. Παρακάτω θα παρουσιαστεί συνοπτικά ο τρόπος χρήσης των δυνατοτήτων επεξεργασίας εικόνων του μοντέλου.

Η χρήση των δυνατοτήτων επεξεργασίας εικόνων του μοντέλου claude-sonnet-4-20250514 γίνεται κυρίως με την προσθήκη ενός πεδίου `type` στο αρχικό περιεχόμενο `content`. Μέσω αυτού του πεδίου μπορεί να προσδιοριστεί εάν αυτό που μεταφορτώνεται είναι κείμενο ή εικόνα, ώστε να χρησιμοποιηθούν οι δυνατότητες επεξεργασίας εικόνων του μοντέλου claude-sonnet-4-20250514. Παρακάτω περιγράφεται κυρίως η κλήση αυτής της λειτουργίας με Curl και Python.

-d '{
    "model": "claude-sonnet-4-20250514",

      {
        "role": "user",

          {
            "type": "text",

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
