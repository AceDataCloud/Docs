Αυτός ο οδηγός ρυθμίζει το **Third-Party Inference Gateway** του Claude Desktop, όχι το Claude Code, ούτε το MCP Connector του Claude Desktop.

## 1. Απόκτηση API Key

Ανοίξτε τη [λίστα εφαρμογών Ace Data Cloud](https://platform.acedata.cloud/console/applications), εισέλθετε σε μια διαθέσιμη εφαρμογή και αντιγράψτε το API Key.

![Απόκτηση Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Άνοιγμα ρυθμίσεων συμπερασμού τρίτου μέρους

Στη σελίδα σύνδεσης του Claude Desktop, ανοίξτε διαδοχικά **Help → Troubleshooting → Enable Developer Mode** και, στη συνέχεια, επιλέξτε **Developer → Configure Third-Party Inference…**.

![Άνοιγμα Third-Party Inference στο Claude Desktop](https://cdn.acedata.cloud/713ffd7104a3.png)

> Η εικόνα προέρχεται από το αποθετήριο Bifrost Apache-2.0 και χρησιμοποιείται μόνο για τον εντοπισμό του μενού του Claude Desktop· η διεπαφή ενδέχεται να διαφέρει ελαφρώς μεταξύ διαφορετικών εκδόσεων.

## 3. Ρύθμιση Gateway

Επιλέξτε **Gateway** και, στη συνέχεια, συμπληρώστε:

| Πεδίο                  | Τιμή                           |
| ------------------- | --------------------------- |
| Gateway base URL    | `https://api.acedata.cloud` |
| Gateway API key     | Το API Key που μόλις αντιγράψατε               |
| Gateway auth scheme | `bearer`                    |
| Credential kind     | `Static API key`            |

![Διεπαφή ρύθμισης Gateway του Claude Desktop](https://cdn.acedata.cloud/68d41fe682cb.png)

Κάντε κλικ στο **Apply Changes** και, στη συνέχεια, στο **Save & Restart**.

## 4. Επαλήθευση

Μετά την επανεκκίνηση, επιλέξτε ένα διαθέσιμο μοντέλο, δημιουργήστε μια νέα συνομιλία και στείλτε `Reply only OK`, έπειτα εκτελέστε μια απλή εργασία εργαλείου. Τα αρχεία κλήσεων μπορούν να προβληθούν στο [ιστορικό χρήσης](https://platform.acedata.cloud/console/usages).

Το Ace Data Cloud Gateway υποστηρίζει τα `/v1/models` που χρησιμοποιεί το Claude Desktop, τη ροή `/v1/messages` με πιστοποίηση Bearer, τις κλήσεις εργαλείων και τη συνέχιση του `tool_result`. Τα πεδία προσωρινής αποθήκευσης προτροπών διατηρούνται· όταν οι τιμές εγγραφής και ανάγνωσης της προσωρινής αποθήκευσης είναι και οι δύο 0, αυτό δεν σημαίνει ότι έγινε επιτυχής εύρεση στην προσωρινή αποθήκευση.

Το 401 συνήθως σημαίνει ότι το Key δεν είναι σωστό· όταν δεν βρίσκεται μοντέλο, ελέγξτε ξανά τις ρυθμίσεις και επανεκκινήστε πλήρως το Claude Desktop. Όταν αναφέρετε προβλήματα, παρέχετε το trace ID από τα αρχεία κλήσεων, αλλά μην παρέχετε το API Key.
