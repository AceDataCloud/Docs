Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο διασύνδεσης API ελέγχου κατάστασης αριθμού κινητού, η οποία μπορεί να χρησιμοποιηθεί για την επαλήθευση της κατάστασης ενός αριθμού κινητού, μπορείτε να εισάγετε τον αριθμό κινητού για να κάνετε την αναζήτηση.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [API Ελέγχου Κατάστασης Αριθμού Κινητού](https://platform.acedata.cloud/documents/037e2b5b-d0c0-425c-9e13-955ac64d1e07) και να ζητήσετε την αντίστοιχη υπηρεσία, αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά την εγγραφή και σύνδεση θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Πρώτα πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τον αριθμό κινητού, ώστε να λάβετε το επεξεργασμένο αποτέλεσμα, πρώτα χρειάζεται να περάσετε απλά ένα πεδίο `mobile`. Στη συνέχεια, μπορούμε να συμπληρώσουμε τα αντίστοιχα περιεχόμενα στην διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/r17llo.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `mobile`: ο αριθμός κινητού που χρειάζεται επεξεργασία, είναι υποχρεωτική παράμετρος.
- `encryption`: προαιρετικό, παράμετρος κρυπτογράφησης ευαίσθητων πεδίων (εάν χρειάζεται να στείλετε κρυπτογραφημένα δεδομένα).

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/dpun55.png" width="500" class="m-auto"></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "result": "0",
  "description": "Επιτυχία",
  "status_code": 0
}
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `result`, κωδικός αποτελέσματος πιστοποίησης, οι χρεώσεις είναι οι εξής.
  - Κωδικοί χρέωσης:
    - 0: Επιτυχία
  - Κωδικοί χωρίς χρέωση:
    - -1: Δεν βρέθηκε αποτέλεσμα
    - -2: Μη έγκυρη μορφή αριθμού κινητού
    - -3: Υπηρεσία πιστοποίησης απασχολημένη
- `description`, περιγραφή αποτελέσματος επιχείρησης.
- `status_code`, κωδικός κατάστασης:
  - 0: Κανονικό
  - 1: Διακοπή
  - 2: Ακύρωση αριθμού
  - 3: Κενός αριθμός
  - 4: Εκτός δικτύου
  - 99: Άγνωστη κατάσταση

Μπορείτε να δείτε ότι η κατάσταση αυτού του αριθμού κινητού έχει ήδη ελεγχθεί.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα διασύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, για παράδειγμα, ο κώδικας CURL είναι ως εξής:

```shell
curl -X POST 'https://api.acedata.cloud/identity/phone/check-1e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "mobile": "***"
}'
```

Ο κώδικας διασύνδεσης Python είναι ως εξής:

```python
import requests

url = "https://api.acedata.cloud/identity/phone/check-1e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "mobile": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
