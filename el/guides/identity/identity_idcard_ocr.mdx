Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο αναγνώρισης ταυτότητας και επαλήθευσης πληροφοριών API, η οποία μπορεί να ελέγξει την αυθεντικότητα και τη συνέπεια του ονόματος και του αριθμού ταυτότητας εισάγοντας μια εικόνα ταυτότητας ή το όνομα και τον αριθμό ταυτότητας. Αυτό το API χρησιμοποιείται για την επαλήθευση της αυθεντικότητας και της συνέπειας του ονόματος και του αριθμού ταυτότητας, μπορείτε να παρέχετε τις απαιτούμενες πληροφορίες επαλήθευσης εισάγοντας το όνομα και τον αριθμό ταυτότητας ή μεταφέροντας μια φωτογραφία της ταυτότητας.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το API αναγνώρισης ταυτότητας και επαλήθευσης πληροφοριών, πρώτα πηγαίνετε στην [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, δεν χρειάζεται να κάνετε ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πίστωση, μπορείτε να το δοκιμάσετε δωρεάν. Όταν η πίστωση εξαντληθεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [API αναγνώρισης ταυτότητας και επαλήθευσης πληροφοριών →](https://platform.acedata.cloud/documents/identity-idcard-ocr)

## Βασική χρήση

Πρώτα πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή εισάγοντας τον σύνδεσμο της εικόνας ταυτότητας, μπορείτε να αποκτήσετε το αποτέλεσμα επαλήθευσης μετά την επεξεργασία. Πρέπει πρώτα να περάσετε ένα πεδίο `image_url`, και στη συνέχεια μπορούμε να συμπληρώσουμε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/qxy9rh.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `image_url`: τον σύνδεσμο της εικόνας ταυτότητας που χρειάζεται επεξεργασία.
- `encryption`: προαιρετικό, παράμετρος κρυπτογράφησης ευαίσθητων πεδίων (εάν χρειάζεται να στείλετε κρυπτογραφημένα δεδομένα).

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/uw90il.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Δοκιμή» για να κάνετε μια δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "result": "0",
  "description": "Το όνομα και ο αριθμός ταυτότητας είναι συνεπή",
  "name": "Όνομα στην ταυτότητα",
  "id_card": "Αριθμός ταυτότητας",
  "sex": "Φύλο στην ταυτότητα",
  "nation": "Εθνότητα στην ταυτότητα",
  "birth": "Ημερομηνία γέννησης στην ταυτότητα",
  "address": "Διεύθυνση κατοικίας στην ταυτότητα"
}
```

Το αποτέλεσμα περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `result`, κωδικός αποτελέσματος πιστοποίησης, οι χρεώσεις είναι οι εξής.
    - Κωδικοί χρέωσης:
        - 0: Το όνομα και ο αριθμός ταυτότητας είναι συνεπή
        - -1: Το όνομα και ο αριθμός ταυτότητας δεν είναι συνεπή
    - Κωδικοί χωρίς χρέωση:
        - -2: Μη έγκυρος αριθμός ταυτότητας (μήκος, ψηφίο ελέγχου κ.λπ. δεν είναι σωστά)
        - -3: Μη έγκυρο όνομα (μήκος, μορφή κ.λπ. δεν είναι σωστά)
        - -4: Σφάλμα υπηρεσίας βάσης δεδομένων εγγράφων
        - -5: Δεν υπάρχει καταχώρηση αυτού του αριθμού ταυτότητας στη βάση δεδομένων
        - -6: Το σύστημα αυθεντίας είναι σε αναβάθμιση, παρακαλώ δοκιμάστε ξανά αργότερα
        - -7: Ο αριθμός πιστοποίησης υπερβαίνει το ημερήσιο όριο.
- `description`, το αποτέλεσμα της επαλήθευσης του ονόματος και του αριθμού ταυτότητας.
- `name`, οι πληροφορίες ονόματος στην ταυτότητα, αν δεν έχει μεταφορτωθεί εικόνα ταυτότητας είναι κενό.
- `id_card`, οι πληροφορίες αριθμού ταυτότητας στην ταυτότητα, αν δεν έχει μεταφορτωθεί εικόνα ταυτότητας είναι κενό.
- `sex`, οι πληροφορίες φύλου στην ταυτότητα, αν δεν έχει μεταφορτωθεί εικόνα ταυτότητας είναι κενό.
- `nation`, οι πληροφορίες εθνότητας στην ταυτότητα, αν δεν έχει μεταφορτωθεί εικόνα ταυτότητας είναι κενό.
- `birth`, οι πληροφορίες ημερομηνίας γέννησης στην ταυτότητα, αν δεν έχει μεταφορτωθεί εικόνα ταυτότητας είναι κενό.
- `address`, οι πληροφορίες διεύθυνσης κατοικίας στην ταυτότητα, αν δεν έχει μεταφορτωθεί εικόνα ταυτότητας είναι κενό.

Μπορείτε να δείτε ότι οι πληροφορίες του ονόματος και του αριθμού ταυτότητας στην ταυτότητα είναι συνεπείς και έγκυρες, ενώ έχουν χρησιμοποιηθεί τεχνολογίες OCR για την εξαγωγή άλλων πληροφοριών και την παρουσίασή τους.

Επιπλέον, αν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα διασύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο κώδικας CURL παρακάτω:

```shell
curl -X POST 'https://api.acedata.cloud/identity/idcard/ocr' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": {image_url}
}'
```

Ο κώδικας διασύνδεσης Python είναι ως εξής:

```python
import requests

url = "https://api.acedata.cloud/identity/idcard/ocr"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": {image_url}
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Επαλήθευση προσαρμοσμένων πληροφοριών

Προσφέρουμε επίσης μια μέθοδο επαλήθευσης που δεν αποκαλύπτει τις πληροφορίες της εικόνας ταυτότητας, μπορείτε να περάσετε μόνο το όνομα `name` και τον αριθμό ταυτότητας `id_card` για να ελέγξετε την αυθεντικότητα και τη συνέπεια του ονόματος και του αριθμού ταυτότητας. Ακολουθούν οι συγκεκριμένες πληροφορίες που συμπληρώθηκαν:

<p><img src="https://cdn.acedata.cloud/mc5bbw.png" width="500" className="m-auto" /></p>

Αφού κάνετε κλικ στην εκτέλεση, θα λάβετε το εξής αποτέλεσμα:

```json
{
    "address": "",
    "birth": "",
    "description": "Το όνομα και ο αριθμός ταυτότητας είναι συνεπή",
    "id_card": "Αριθμός ταυτότητας",
    "name": "Όνομα στην ταυτότητα",
    "nation": "",
    "result": "0",
    "sex": ""
 }
```

Έτσι, από το αποτέλεσμα δεν αποκαλύπτονται άλλες πληροφορίες ιδιωτικότητας, και αυτό μπορεί επίσης να ολοκληρώσει την επαλήθευση της αυθεντικότητας και της συνέπειας του ονόματος και του αριθμού ταυτότητας.

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα σφάλματος απόκρισης

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
