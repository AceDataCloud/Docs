Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο για την αναγνώριση ταυτότητας και την επαλήθευση πληροφοριών μέσω API, η οποία μπορεί να ελέγξει την αυθεντικότητα και τη συνέπεια του ονόματος και του αριθμού ταυτότητας εισάγοντας μια εικόνα ταυτότητας ή το όνομα και τον αριθμό ταυτότητας. Αυτό το API χρησιμοποιείται για την επαλήθευση της αυθεντικότητας και της συνέπειας του ονόματος και του αριθμού ταυτότητας, μπορείτε να παρέχετε τις απαιτούμενες πληροφορίες επαλήθευσης εισάγοντας το όνομα και τον αριθμό ταυτότητας ή μεταφέροντας μια φωτογραφία της ταυτότητας.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [Ταυτότητα αναγνώρισης και πληροφορίες API](https://platform.acedata.cloud/documents/67f96afa-60b8-4cbb-a4bf-0cbfcf139a23) για να ζητήσετε την αντίστοιχη υπηρεσία, αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά την εγγραφή και σύνδεση θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τον σύνδεσμο εικόνας ταυτότητας, για να αποκτήσετε το αποτέλεσμα επαλήθευσης μετά την επεξεργασία. Πρέπει πρώτα να μεταφέρετε ένα πεδίο `image_url`, και στη συνέχεια μπορούμε να συμπληρώσουμε τα αντίστοιχα περιεχόμενα στην διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/qxy9rh.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, συμπεριλαμβανομένων:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, συμπεριλαμβανομένων:

- `image_url`: ο σύνδεσμος της εικόνας ταυτότητας που χρειάζεται επεξεργασία.
- `encryption`: προαιρετικό, παράμετρος κρυπτογράφησης ευαίσθητων πεδίων (εάν χρειάζεται να στείλετε κρυπτογραφημένα δεδομένα).

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/uw90il.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "result": "0",
  "description": "Το όνομα και ο αριθμός ταυτότητας είναι συνεπή",
  "name": "Όνομα στην ταυτότητα",
  "id_card": "Αριθμός ταυτότητας",
  "sex": "Φύλο στην ταυτότητα",
  "nation": "Εθνότητα στην ταυτότητα",
  "birth": "Ημερομηνία γέννησης στην ταυτότητα",
  "address": "Διεύθυνση κατοικίας στην ταυτότητα"
}
```

Το αποτέλεσμα περιλαμβάνει πολλά πεδία, τα οποία περιγράφονται ως εξής:

- `result`, κωδικός αποτελέσματος πιστοποίησης, οι χρεώσεις είναι οι εξής.
  - Κωδικοί χρέωσης:
    - 0: Το όνομα και ο αριθμός ταυτότητας είναι συνεπή
    - -1: Το όνομα και ο αριθμός ταυτότητας δεν είναι συνεπή
  - Κωδικοί χωρίς χρέωση:
    - -2: Μη έγκυρος αριθμός ταυτότητας (μήκος, ψηφίο ελέγχου κ.λπ. μη σωστά)
    - -3: Μη έγκυρο όνομα (μήκος, μορφή κ.λπ. μη σωστά)
    - -4: Σφάλμα υπηρεσίας βάσης δεδομένων εγγράφων
    - -5: Δεν υπάρχει καταχώρηση αυτού του αριθμού ταυτότητας στη βάση δεδομένων
    - -6: Το σύστημα αυθεντίας αναβαθμίζεται, παρακαλώ δοκιμάστε ξανά αργότερα
    - -7: Ο αριθμός πιστοποίησης υπερβαίνει το ημερήσιο όριο.
- `description`, το αποτέλεσμα της επαλήθευσης του ονόματος και του αριθμού ταυτότητας.
- `name`, οι πληροφορίες ονόματος στην ταυτότητα, αν δεν έχει μεταφορτωθεί εικόνα ταυτότητας είναι κενό.
- `id_card`, οι πληροφορίες αριθμού ταυτότητας στην ταυτότητα, αν δεν έχει μεταφορτωθεί εικόνα ταυτότητας είναι κενό.
- `sex`, οι πληροφορίες φύλου στην ταυτότητα, αν δεν έχει μεταφορτωθεί εικόνα ταυτότητας είναι κενό.
- `nation`, οι πληροφορίες εθνότητας στην ταυτότητα, αν δεν έχει μεταφορτωθεί εικόνα ταυτότητας είναι κενό.
- `birth`, οι πληροφορίες ημερομηνίας γέννησης στην ταυτότητα, αν δεν έχει μεταφορτωθεί εικόνα ταυτότητας είναι κενό.
- `address`, οι πληροφορίες διεύθυνσης κατοικίας στην ταυτότητα, αν δεν έχει μεταφορτωθεί εικόνα ταυτότητας είναι κενό.

Μπορείτε να δείτε ότι οι πληροφορίες του ονόματος και του αριθμού ταυτότητας στην ταυτότητα είναι συνεπείς και έγκυρες, ενώ έχουν χρησιμοποιηθεί τεχνολογίες OCR για την εξαγωγή άλλων πληροφοριών και την παρουσίασή τους.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα διασύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, για παράδειγμα, ο κώδικας CURL είναι ως εξής:

```shell
curl -X POST 'https://api.acedata.cloud/identity/idcard/ocr' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": {image_url}
}'
```

Ο κώδικας διασύνδεσης Python είναι ως εξής:

```python
import requests

url = "https://api.acedata.cloud/identity/idcard/ocr"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": {image_url}
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Επαλήθευση προσαρμοσμένων πληροφοριών

Προσφέρουμε επίσης μια μέθοδο επαλήθευσης που δεν αποκαλύπτει τις πληροφορίες της εικόνας ταυτότητας, μπορείτε να εισάγετε μόνο το όνομα `name` και τον αριθμό ταυτότητας `id_card` για να ελέγξετε την αυθεντικότητα και τη συνέπεια του ονόματος και του αριθμού ταυτότητας. Ακολουθούν οι συγκεκριμένες πληροφορίες που συμπληρώθηκαν:

<p><img src="https://cdn.acedata.cloud/mc5bbw.png" width="500" className="m-auto" /></p>

Αφού κάνετε κλικ στην εκτέλεση, θα λάβετε το εξής αποτέλεσμα:

```json
{
    "address": "",
    "birth": "",
    "description": "Το όνομα και ο αριθμός ταυτότητας είναι συνεπή",
    "id_card": "Αριθμός ταυτότητας",
    "name": "Όνομα στην ταυτότητα",
    "nation": "",
    "result": "0",
    "sex": ""
 }
```

Έτσι, από το αποτέλεσμα δεν αποκαλύπτονται άλλες προσωπικές πληροφορίες, και αυτό μπορεί να ολοκληρώσει την επαλήθευση της αυθεντικότητας και της συνέπειας του ονόματος και του αριθμού ταυτότητας.

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα σφάλματος απόκρισης

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
