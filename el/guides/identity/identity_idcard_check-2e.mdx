Αυτό το έγγραφο θα παρουσιάσει μια ταυτότητα πληροφορίες και έλεγχο ικανότητας API σύνδεση οδηγίες, που μπορεί να χρησιμοποιηθεί για την επαλήθευση της αυθεντικότητας και της συνέπειας του ονόματος, του αριθμού ταυτότητας και της ημερομηνίας λήξης της ταυτότητας.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [Ταυτότητα Πληροφορίες και Έλεγχος Ικανότητας API](https://platform.acedata.cloud/documents/667017a4-017f-4af0-870e-807034f70632) για να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Πρώτα απ' όλα, ας κατανοήσουμε τη βασική μέθοδο χρήσης, δηλαδή εισάγοντας τον σύνδεσμο εικόνας της ταυτότητας, μπορείτε να αποκτήσετε το αποτέλεσμα επαλήθευσης μετά την επεξεργασία. Πρώτα χρειάζεται να περάσετε ένα πεδίο `name`, και στη συνέχεια μπορούμε να συμπληρώσουμε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/llvy1l.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `name`: όνομα.
- `id_card`: αριθμός ταυτότητας.
- `image_url`: σύνδεσμος εικόνας προσώπου που χρειάζεται επεξεργασία.
- `validity_end`: ημερομηνία λήξης της ταυτότητας, μορφή: YYYYMMDD, για μακροχρόνια χρήση χρησιμοποιήστε "00000000";
- `validity_begin`: ημερομηνία έναρξης της ταυτότητας, μορφή: YYYYMMDD.
- `encryption`: προαιρετικό, παράμετρος κρυπτογράφησης ευαίσθητων πεδίων (εάν χρειάζεται να στείλετε κρυπτογραφημένα δεδομένα).

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/l77q0u.png" width="500" class="m-auto"></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "result": "0",
  "description": "Συμφωνία"
}
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `result`, κωδικός αποτελέσματος πιστοποίησης, οι χρεώσεις είναι οι εξής.
  - Κωδικοί χρέωσης:
    - 0: Το όνομα και ο αριθμός ταυτότητας συμφωνούν
    - -1: Το όνομα και ο αριθμός ταυτότητας δεν συμφωνούν
  - Κωδικοί χωρίς χρέωση:
    - -2: Μη έγκυρος αριθμός ταυτότητας (μήκος, ψηφίο ελέγχου κ.λπ. δεν είναι σωστά)
    - -3: Μη έγκυρο όνομα (μήκος, μορφή κ.λπ. δεν είναι σωστά)
    - -4: Σφάλμα υπηρεσίας βάσης δεδομένων εγγράφων
    - -5: Δεν υπάρχει καταχώρηση αυτού του αριθμού ταυτότητας στη βάση δεδομένων
    - -6: Το σύστημα αυθεντίας αναβαθμίζεται, παρακαλώ δοκιμάστε ξανά αργότερα
    - -7: Ο αριθμός πιστοποίησης υπερβαίνει το ημερήσιο όριο.
- `description`, το αποτέλεσμα της επαλήθευσης του ονόματος και του αριθμού ταυτότητας.

Μπορείτε να δείτε ότι το όνομα, ο αριθμός ταυτότητας και η ημερομηνία λήξης της ταυτότητας έχουν αυθεντικότητα και συνέπεια.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, για παράδειγμα, ο κώδικας CURL είναι ως εξής:

```shell
curl -X POST 'https://api.acedata.cloud/identity/idcard/check-2e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "***",
  "id_card": "***",
  "validity_begin": "***",
  "validity_end": "***"
}'
```

Ο κώδικας σύνδεσης Python είναι ως εξής:

```python
import requests

url = "https://api.acedata.cloud/identity/idcard/check-2e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "***",
    "id_card": "***",
    "validity_begin": "***",
    "validity_end": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα Σφάλματος Απόκρισης

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
