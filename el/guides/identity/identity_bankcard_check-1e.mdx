Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο για την ένταξη του API ελέγχου βασικών πληροφοριών τραπεζικών καρτών, το οποίο μπορεί να χρησιμοποιηθεί για την αναζήτηση βασικών πληροφοριών τραπεζικών καρτών.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [API ελέγχου βασικών πληροφοριών τραπεζικών καρτών](https://platform.acedata.cloud/documents/3523988d-acba-4362-9def-105657991eb4) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τον αριθμό της τραπεζικής κάρτας για να λάβετε το αποτέλεσμα επεξεργασίας και επαλήθευσης. Πρέπει πρώτα να περάσετε ένα πεδίο `bank_card`, και στη συνέχεια μπορείτε να συμπληρώσετε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/h41nrh.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `bank_card`: αριθμός τραπεζικής κάρτας.
- `encryption`: προαιρετικό, παράμετρος κρυπτογράφησης ευαίσθητων πεδίων (εάν χρειάζεται να στείλετε κρυπτογραφημένα δεδομένα).

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/grfra7.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ λάβαμε το εξής αποτέλεσμα:

```json
{
  "result": "0",
  "description": "Επιτυχής αναζήτηση",
  "account_bank": "Βιομηχανική Τράπεζα της Κίνας",
  "account_type": 1
}
```

Τα αποτελέσματα περιλαμβάνουν πολλά πεδία, τα οποία περιγράφονται ως εξής:

- `result`, κωδικός αποτελέσματος επαλήθευσης, οι χρεώσεις είναι οι εξής.
  - Κωδικοί χρέωσης:
    - 0: Επιτυχής αναζήτηση
    - -1: Δεν βρέθηκαν πληροφορίες
  - Κωδικοί χωρίς χρέωση:
    - -2: Υπηρεσία επαλήθευσης απασχολημένη
    - -3: Η τραπεζική κάρτα δεν υπάρχει
- `description`, περιγραφή αποτελέσματος υπηρεσίας.
- `account_bank`, τράπεζα που διατηρεί τον λογαριασμό.
- `account_type`, τύπος κάρτας: 1. Χρεωστική κάρτα; 2. Πιστωτική κάρτα; 3. Προπληρωμένη κάρτα; 4. Κάρτα με δυνατότητα πιστώσεων.

Μπορείτε να δείτε ότι οι βασικές πληροφορίες της τραπεζικής κάρτας έχουν ανακτηθεί.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα ένταξης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο κώδικας CURL παρακάτω:

```shell
curl -X POST 'https://api.acedata.cloud/identity/bankcard/check-1e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "bank_card": "****"
}'
```

Ο κώδικας ένταξης Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/identity/bankcard/check-1e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "bank_card": "****"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

```json
}
```
