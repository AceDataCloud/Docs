Αυτό το έγγραφο θα παρουσιάσει μια Διευκρίνιση Επαλήθευσης Δύο Στοιχείων Τηλεφώνου API, η οποία μπορεί να χρησιμοποιηθεί για την επαλήθευση της γνησιότητας και της συνέπειας του αριθμού τηλεφώνου και του ονόματος.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API Επαλήθευσης Δύο Στοιχείων Τηλεφώνου, πρώτα πηγαίνετε στο [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης που σας προσκαλεί να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη σελίδα που βρίσκεστε.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, δεν χρειάζεται να ζητήσετε ξεχωριστά για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε δωρεάν; όταν οι πιστώσεις εξαντληθούν, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στο [Console](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [API Επαλήθευσης Δύο Στοιχείων Τηλεφώνου →](https://platform.acedata.cloud/documents/identity-phone-check-2e)

## Βασική Χρήση

Πρώτα πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τον αριθμό τηλεφώνου για να λάβετε το επεξεργασμένο αποτέλεσμα, χρειάζεται πρώτα να περάσετε ένα πεδίο `mobile`. Στη συνέχεια, μπορούμε να συμπληρώσουμε τα αντίστοιχα περιεχόμενα στην διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/v6k96j.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `name`: το όνομα του χρήστη που χρειάζεται επεξεργασία, είναι υποχρεωτική παράμετρος.
- `mobile`: ο αριθμός τηλεφώνου που χρειάζεται επεξεργασία, είναι υποχρεωτική παράμετρος.
- `encryption`: προαιρετικό, παράμετρος κρυπτογράφησης ευαίσθητων πεδίων (εάν χρειάζεται να στείλετε κρυπτογραφημένα δεδομένα).

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/lq800o.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "result": "0",
  "description": "Η επαλήθευση είναι συνεπής"
}
```

Τα αποτελέσματα περιλαμβάνουν πολλαπλά πεδία, που περιγράφονται ως εξής:

- `result`, κωδικός αποτελέσματος επαλήθευσης, οι χρεώσεις είναι οι εξής.
    - Κωδικοί χρέωσης:
        - 0: Η επαλήθευση είναι συνεπής
        - 1: Η επαλήθευση δεν είναι συνεπής
    - Κωδικοί χωρίς χρέωση:
        - -1: Δεν βρέθηκαν αρχεία
        - -2: Άγνωστο σφάλμα μηχανής
        - -3: Ασυνήθιστη υπηρεσία μηχανής
        - -4: Η επαλήθευση του ονόματος απέτυχε
        - -5: Ο αριθμός τηλεφώνου δεν είναι έγκυρος
        - -6: Ο αριθμός επαληθεύσεων έχει ξεπεράσει το ημερήσιο όριο, παρακαλώ δοκιμάστε ξανά αύριο
- `description`, περιγραφή του επιχειρηματικού αποτελέσματος.

Μπορείτε να δείτε ότι η γνησιότητα και η συνέπεια του αριθμού τηλεφώνου και του ονόματος έχουν ελεγχθεί.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα διασύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, για παράδειγμα, ο κώδικας CURL είναι ο εξής:

```shell
curl -X POST 'https://api.acedata.cloud/identity/phone/check-2e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "***",
  "mobile": "***"
}'
```

Ο κώδικας διασύνδεσης Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/identity/phone/check-2e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "***",
    "mobile": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε ξεπεράσει το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
