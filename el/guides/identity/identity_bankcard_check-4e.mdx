Αυτό το έγγραφο θα εισαγάγει μια μέθοδο σύνδεσης API επαλήθευσης τεσσάρων στοιχείων κάρτας τράπεζας, η οποία μπορεί να χρησιμοποιηθεί για την εισαγωγή αριθμού κάρτας τράπεζας, ονόματος, αριθμού ταυτότητας και αριθμού κινητού τηλεφώνου, για την επαλήθευση της γνησιότητας και της συνέπειας των πληροφοριών.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [API Επαλήθευσης Τεσσάρων Στοιχείων Κάρτας Τράπεζας](https://platform.acedata.cloud/documents/02f77369-ec7b-4218-a956-d7a84982a626) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να σας προσκαλέσουν να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τις πληροφορίες του αριθμού κάρτας τράπεζας, για να λάβετε την επεξεργασμένη εικόνα αποτελέσματος. Πρέπει πρώτα να μεταβιβάσετε ένα πεδίο `bank_card`. Στη συνέχεια, μπορούμε να συμπληρώσουμε τις αντίστοιχες πληροφορίες στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/1pl0y5.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `bank_card`: οι πληροφορίες του αριθμού κάρτας τράπεζας που χρειάζονται επεξεργασία, είναι υποχρεωτική παράμετρος.
- `id_card`: αριθμός ταυτότητας, είναι υποχρεωτική παράμετρος.
- `name`: το όνομα του χρήστη, είναι υποχρεωτική παράμετρος.
- `phone`: αριθμός κινητού τηλεφώνου.
- `cert_type`: τύπος ταυτότητας, πρέπει να είναι συμβατός με την ταυτότητα.
- `encryption`: προαιρετικό, παράμετρος κρυπτογράφησης ευαίσθητων πεδίων (εάν απαιτείται αποστολή κρυπτογραφημένων δεδομένων).

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/slajgv.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "result": "0",
  "description": "Πιστοποίηση επιτυχής"
}
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `result`, κωδικός αποτελέσματος πιστοποίησης, οι χρεώσεις είναι οι εξής.
  - Κωδικοί χρέωσης:
    - 0: Πιστοποίηση επιτυχής
    - -1: Πιστοποίηση αποτυχημένη
    - -4: Λάθος πληροφορίες κατόχου κάρτας
    - -5: Δεν έχει ενεργοποιηθεί η πληρωμή χωρίς κάρτα
    - -6: Αυτή η κάρτα έχει κατασχεθεί
    - -7: Μη έγκυρος αριθμός κάρτας
    - -8: Αυτή η κάρτα δεν έχει αντίστοιχη τράπεζα εκδότρια
    - -9: Αυτή η κάρτα δεν έχει αρχικοποιηθεί ή είναι ανενεργή
    - -10: Κάρτα απάτης, κατάσχεση κάρτας
    - -11: Αυτή η κάρτα έχει δηλωθεί ως χαμένη
    - -12: Αυτή η κάρτα έχει λήξει
    - -13: Περιορισμένη κάρτα
    - -14: Υπερβολικές αποτυχημένες προσπάθειες κωδικού
    - -15: Η τράπεζα εκδότρια δεν υποστηρίζει αυτή τη συναλλαγή
  - Κωδικοί χωρίς χρέωση:
    - -2: Αποτυχία επαλήθευσης ονόματος
    - -3: Λάθος αριθμός κάρτας τράπεζας
    - -16: Υπηρεσία επαλήθευσης απασχολημένη
    - -17: Υπερβολικές προσπάθειες επαλήθευσης, παρακαλώ δοκιμάστε ξανά την επόμενη μέρα
- `description`, περιγραφή αποτελέσματος υπηρεσίας.

Μπορείτε να δείτε ότι ο αριθμός κάρτας τράπεζας, το όνομα, ο αριθμός ταυτότητας και ο αριθμός κινητού τηλεφώνου αυτής της κάρτας έχουν γνησιότητα και συνέπεια.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, για παράδειγμα, ο κώδικας CURL είναι ως εξής:

```shell
curl -X POST 'https://api.acedata.cloud/identity/bankcard/check-4e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "***",
  "phone": "***",
  "id_card": "***",
  "bank_card": "***"
}'
```

Ο κώδικας σύνδεσης Python είναι ως εξής:

```python
import requests

url = "https://api.acedata.cloud/identity/bankcard/check-4e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "胡印福",
    "phone": "***",
    "id_card": "***",
    "bank_card": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

```json
}
```
