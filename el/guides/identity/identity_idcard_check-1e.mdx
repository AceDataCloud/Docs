Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο σύνδεσης API για τον έλεγχο φωτογραφίας ταυτότητας, η οποία μπορεί να χρησιμοποιηθεί για την εισαγωγή φωτογραφίας της ταυτότητας, την αναγνώριση των πληροφοριών στη φωτογραφία της ταυτότητας και τη σύγκριση του ονόματος, του αριθμού ταυτότητας και της φωτογραφίας της ταυτότητας με τις φωτογραφίες από αξιόπιστες βάσεις δεδομένων, προκειμένου να επαληθευτεί αν ανήκουν στο ίδιο άτομο και να επιβεβαιωθεί η αυθεντικότητα των πληροφοριών της ταυτότητας.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API ελέγχου φωτογραφίας ταυτότητας, πρώτα επισκεφθείτε την [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη σελίδα που βρίσκεστε.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να ζητήσετε ξεχωριστά για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πιστώσεις για να δοκιμάσετε την υπηρεσία δωρεάν. Όταν οι πιστώσεις σας εξαντληθούν, μπορείτε να ανανεώσετε το γενικό σας υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [API Ελέγχου Φωτογραφίας Ταυτότητας →](https://platform.acedata.cloud/documents/identity-idcard-check-1e)

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, η οποία είναι να εισάγετε τον σύνδεσμο της φωτογραφίας της ταυτότητας, ώστε να λάβετε το αποτέλεσμα επεξεργασίας και επαλήθευσης. Πρέπει πρώτα να περάσετε ένα πεδίο `image_url`, και στη συνέχεια μπορείτε να συμπληρώσετε τα αντίστοιχα περιεχόμενα στην διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/zjxg3k.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `image_url`: τον σύνδεσμο της φωτογραφίας της ταυτότητας που χρειάζεται επεξεργασία.
- `config`: προαιρετική ρύθμιση, πεδίο boolean, με προεπιλεγμένη τιμή false, υποστηρίζει `copy_warn`, `border_check_warn`, `reshoot_warn`, `detect_ps_warn`, `temp_id_warn`, `quality` (όριο 0-100).

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/4yh23p.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Δοκιμή» για να κάνετε μια δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "sim": 99.76,
  "result": "Success",
  "description": "Επιτυχία",
  "name": "Όνομα Ταυτότητας",
  "sex": "Φύλο Ταυτότητας",
  "nation": "Εθνότητα Ταυτότητας",
  "birth": "Ημερομηνία Γέννησης Ταυτότητας",
  "address": "Διεύθυνση Ταυτότητας",
  "id_num": "Αριθμός Ταυτότητας",
  "portrait": "/9j/4AAQSkZJRgABAQAAAQABAAD/2wBDAAEBAQEBAQEBAQEBAQEBAQEBAQEBA.....DEhE2lbPMcOtG3f/DLT/yX8if7Kxn/AD7h85wdttPifRf1e6//2Q==",
  "warnings": "",
  "quality": 0,
  "encryption": null
}
```

Το αποτέλεσμα περιέχει πολλά πεδία, τα οποία περιγράφονται ως εξής:

- `sim`, ομοιότητα, εύρος τιμών [0.00, 100.00]. Συνιστάται η ομοιότητα να είναι μεγαλύτερη ή ίση με 70 για να θεωρείται το ίδιο άτομο, μπορείτε να προσαρμόσετε το όριο ανάλογα με την συγκεκριμένη περίπτωση (το ποσοστό ψευδούς αποδοχής για όριο 70 είναι 0.1%, για όριο 80 είναι 0.01%).
- `result`, κωδικός σφάλματος επιχείρησης, σε περίπτωση επιτυχίας επιστρέφει Success, σε περίπτωση σφάλματος ανατρέξτε στην ενότητα FailedOperation της λίστας κωδικών σφαλμάτων παρακάτω.
- `description`, το αποτέλεσμα της επαλήθευσης του ονόματος και του αριθμού ταυτότητας.
- `name`, οι πληροφορίες ονόματος στην ταυτότητα, αν δεν έχει ανέβει φωτογραφία ταυτότητας είναι κενό.
- `sex`, οι πληροφορίες φύλου στην ταυτότητα, αν δεν έχει ανέβει φωτογραφία ταυτότητας είναι κενό.
- `nation`, οι πληροφορίες εθνότητας στην ταυτότητα, αν δεν έχει ανέβει φωτογραφία ταυτότητας είναι κενό.
- `birth`, οι πληροφορίες ημερομηνίας γέννησης στην ταυτότητα, αν δεν έχει ανέβει φωτογραφία ταυτότητας είναι κενό.
- `address`, οι πληροφορίες διεύθυνσης στην ταυτότητα, αν δεν έχει ανέβει φωτογραφία ταυτότητας είναι κενό.
- `id_num`, οι πληροφορίες αριθμού ταυτότητας στην ταυτότητα, αν δεν έχει ανέβει φωτογραφία ταυτότητας είναι κενό.
- `portrait`, η base64 κωδικοποίηση της φωτογραφίας της ταυτότητας, αν η αποκοπή της εικόνας αποτύχει, θα χρησιμοποιηθεί η ολόκληρη φωτογραφία της ταυτότητας για σύγκριση και θα επιστραφεί κενό.
- `warnings`, πληροφορίες προειδοποίησης, όταν έχει ρυθμιστεί προειδοποίηση στην Config, η σύγκριση προσώπου θα σταματήσει, το Result θα επιστρέψει σφάλμα (FailedOperation.OcrWarningOccurred) και θα έχει αυτή την προειδοποίηση.
- `quality`, βαθμολογία ποιότητας εικόνας, όταν έχει ρυθμιστεί προειδοποίηση θολότητας στην Config, αυτή η παράμετρος έχει νόημα, εύρος τιμών (0-100), το προεπιλεγμένο όριο είναι 50, κάτω από 50 θα ενεργοποιήσει προειδοποίηση θολότητας.
- `encryption`, πληροφορίες κρυπτογράφησης ευαίσθητων δεδομένων.

Μπορείτε να δείτε ότι οι πληροφορίες της ταυτότητας έχουν πολύ υψηλή αυθεντικότητα.

Επιπλέον, αν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, για παράδειγμα, ο κώδικας CURL είναι ως εξής:

```shell
curl -X POST 'https://api.acedata.cloud/identity/idcard/check-1e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": {image_url}
}'
```

Ο κώδικας σύνδεσης Python είναι ως εξής:

```python
import requests

url = "https://api.acedata.cloud/identity/idcard/check-1e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": {image_url}
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές token εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
