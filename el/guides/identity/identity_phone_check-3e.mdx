Αυτό το άρθρο θα παρουσιάσει μια μέθοδο σύνδεσης API επαλήθευσης τριών στοιχείων τηλεφώνου, η οποία μπορεί να χρησιμοποιηθεί για την επαλήθευση της γνησιότητας και της συνέπειας του αριθμού τηλεφώνου, του ονόματος και του αριθμού ταυτότητας.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [API Επαλήθευσης Τριών Στοιχείων Τηλεφώνου](https://platform.acedata.cloud/documents/b4c50108-dda5-4ddb-ba84-776060fb0151) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τον αριθμό τηλεφώνου για να λάβετε το επεξεργασμένο αποτέλεσμα. Πρέπει πρώτα να μεταβιβάσετε ένα πεδίο `phone`. Στη συνέχεια, μπορείτε να συμπληρώσετε τα αντίστοιχα περιεχόμενα στην διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/3xbffj.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `name`: το όνομα του χρήστη που πρέπει να επεξεργαστεί, είναι υποχρεωτική παράμετρος.
- `phone`: ο αριθμός τηλεφώνου που πρέπει να επεξεργαστεί, είναι υποχρεωτική παράμετρος.
- `id_card`: ο αριθμός ταυτότητας του χρήστη που πρέπει να επεξεργαστεί, είναι υποχρεωτική παράμετρος.
- `verify_mode`: τρόπος επαλήθευσης (μακρύς/σύντομος).
- `encrypt_list`/`ciphertext_blob`/`iv`: προαιρετικές κρυπτογραφικές παράμετροι, κρυπτογραφείτε ευαίσθητα πεδία κατά ανάγκη.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/0cp9z1.png" width="500" class="m-auto"></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "result": "0",
  "description": "Πιστοποίηση επιτυχής",
  "isp": "Κινητή",
  "result_detail": null
}
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `result`, κωδικός αποτελέσματος πιστοποίησης, οι χρεώσεις είναι οι εξής.
  - Κωδικοί χρέωσης:
    - 0: Το αποτέλεσμα επαλήθευσης είναι συνεπές
    - 1: Το αποτέλεσμα επαλήθευσης δεν είναι συνεπές
  - Κωδικοί χωρίς χρέωση:
    - -1: Δεν βρέθηκαν αρχεία
    - -2: Άγνωστο σφάλμα μηχανής
    - -3: Ασυνήθιστη υπηρεσία μηχανής
    - -4: Η επαλήθευση ονόματος δεν πέρασε
    - -5: Ο αριθμός τηλεφώνου δεν είναι έγκυρος
    - -6: Ο αριθμός πιστοποίησης υπερβαίνει το ημερήσιο όριο, παρακαλώ δοκιμάστε ξανά αύριο
- `description`, περιγραφή επιχειρηματικού αποτελέσματος.

Μπορείτε να δείτε ότι οι πληροφορίες σχετικά με την γνησιότητα και τη συνέπεια του αριθμού τηλεφώνου, του ονόματος και του αριθμού ταυτότητας έχουν ήδη ανακτηθεί.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, για παράδειγμα, ο κώδικας CURL είναι ως εξής:

```shell
curl -X POST 'https://api.acedata.cloud/identity/phone/check-3e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "***",
  "phone": "***",
  "id_card": "***"
}'
```

Ο κώδικας σύνδεσης Python είναι ως εξής:

```python
import requests

url = "https://api.acedata.cloud/identity/phone/check-3e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "***",
    "phone": "***",
    "id_card": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

```json
}
```
