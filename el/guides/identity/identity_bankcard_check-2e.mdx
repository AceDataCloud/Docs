Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο σύνδεσης API επαλήθευσης δεύτερου στοιχείου τραπεζικής κάρτας, η οποία μπορεί να χρησιμοποιηθεί για την επαλήθευση της γνησιότητας και της συνέπειας του ονόματος και του αριθμού τραπεζικής κάρτας.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [API Επαλήθευσης Δεύτερου Στοιχείου Τραπεζικής Κάρτας](https://platform.acedata.cloud/documents/06efe2aa-5443-4dcc-af2f-28236bfb2158) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τις πληροφορίες του αριθμού της τραπεζικής κάρτας, για να λάβετε την επεξεργασμένη εικόνα αποτελέσματος. Πρέπει πρώτα να μεταφέρετε ένα πεδίο `bank_card`. Στη συνέχεια, μπορούμε να συμπληρώσουμε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/u9bugq.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `bank_card`: οι πληροφορίες του αριθμού τραπεζικής κάρτας που χρειάζονται επεξεργασία, είναι υποχρεωτική παράμετρος.
- `name`: το όνομα του χρήστη, είναι υποχρεωτική παράμετρος.
- `encryption`: προαιρετικό, παράμετρος κρυπτογράφησης ευαίσθητων πεδίων (εάν χρειάζεται να στείλετε κρυπτογραφημένα δεδομένα).

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/yn8yxf.png" width="500" class="m-auto"></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json
{
  "result": "0",
  "description": "认证通过"
}
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `result`, κωδικός αποτελέσματος επαλήθευσης, οι χρεώσεις είναι οι εξής.
  - Κωδικοί χρέωσης:
    - 0: Επαλήθευση επιτυχής
    - -1: Επαλήθευση αποτυχημένη
    - -4: Λάθος πληροφορίες κατόχου κάρτας
    - -5: Δεν έχει ενεργοποιηθεί η πληρωμή χωρίς κάρτα
    - -6: Αυτή η κάρτα έχει κατασχεθεί
    - -7: Μη έγκυρος αριθμός κάρτας
    - -8: Αυτή η κάρτα δεν έχει αντίστοιχη τράπεζα εκδότρια
    - -9: Αυτή η κάρτα δεν έχει αρχικοποιηθεί ή είναι σε κατάσταση ύπνου
    - -10: Κάρτα απάτης, κατάσχεση κάρτας
    - -11: Αυτή η κάρτα έχει δηλωθεί ως χαμένη
    - -12: Αυτή η κάρτα έχει λήξει
    - -13: Κάρτα με περιορισμούς
    - -14: Υπερβολικές αποτυχημένες προσπάθειες κωδικού
    - -15: Η τράπεζα εκδότρια δεν υποστηρίζει αυτή τη συναλλαγή
  - Κωδικοί χωρίς χρέωση:
    - -2: Η επαλήθευση του ονόματος απέτυχε
    - -3: Λάθος αριθμός τραπεζικής κάρτας
    - -16: Υπηρεσία επαλήθευσης απασχολημένη
    - -17: Υπερβολικές προσπάθειες επαλήθευσης, παρακαλώ δοκιμάστε ξανά την επόμενη μέρα
- `description`, περιγραφή αποτελέσματος επιχείρησης.

Μπορείτε να δείτε ότι η γνησιότητα και η συνέπεια του ονόματος και του αριθμού τραπεζικής κάρτας έχουν επαληθευτεί.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, για παράδειγμα, ο κώδικας CURL είναι ο εξής:

```shell
curl -X POST 'https://api.acedata.cloud/identity/bankcard/check-2e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "***",
  "bank_card": "***"
}'
```

Ο κώδικας σύνδεσης Python είναι ο εξής:

```python
curl -X POST 'https://api.acedata.cloud/identity/bankcard/check-2e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "***",
  "bank_card": "***"
}'
```

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Υπερβολικές αιτήσεις, έχετε ξεπεράσει το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα Απόκρισης Σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
