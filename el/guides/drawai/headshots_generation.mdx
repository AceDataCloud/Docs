Αυτό το έγγραφο θα παρουσιάσει μια μέθοδο για τη σύνδεση με το API δημιουργίας ταυτότητας AI, το οποίο μπορεί να χρησιμοποιηθεί για τη δημιουργία διαφόρων στυλ ταυτοτήτων μέσω της εισαγωγής URL φωτογραφίας πορτρέτου και του αγαπημένου σας προτύπου.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [AI Δημιουργία Ταυτότητας API](https://platform.acedata.cloud/documents/bf7214a3-8447-4157-8a75-f5bb39d5ed1b) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να χρησιμοποιήσετε το API δωρεάν.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε την εικόνα πορτρέτου που χρειάζεται επεξεργασία και το αγαπημένο σας πρότυπο AI ταυτότητας, για να λάβετε το επεξεργασμένο αποτέλεσμα. Πρέπει πρώτα να περάσετε ένα πεδίο `image_urls`, το οποίο είναι ο πίνακας των συνδέσμων εικόνας πορτρέτου που χρειάζεται επεξεργασία, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.zhishuyun.com/2024-11-03-d23744954ca4819503469f04f2268aa0.jpg" width="500" class="m-auto"></p>

Στη συνέχεια, πρέπει να εισάγουμε το αγαπημένο μας πρότυπο. Αυτό το έγγραφο παρέχει οκτώ δημοφιλή πρότυπα, τα οποία μπορείτε να ανατρέξετε παρακάτω:

```json
{
   "male_portrait":  Ανδρική εικόνα
   "male_portrait2":  Ανδρική εικόνα (άλλη έκδοση)
   "kindergarten":  Φωτογραφία εισόδου νηπιαγωγείου
   "logo_tshirt": Φωτογραφία T-shirt με λογότυπο επιχείρησης
   "wedding":  Φωτογραφία γάμου
   "business_photo":  Επαγγελματική φωτογραφία
   "bob_suit": Μαύρο κοστούμι με καρέ μαλλιά
   "female_portrait":  Γυναικεία εικόνα
}
```

Στη συνέχεια, μπορούμε να καθορίσουμε την παράμετρο ταχύτητας παραγωγής `mode`, η οποία γενικά χωρίζεται σε δύο τύπους: αργή `relax` και γρήγορη `fast`, οι λεπτομέρειες είναι οι εξής:

<p><img src="https://cdn.acedata.cloud/73xbla.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `mode`: η διαδρομή παραγωγής της ταυτότητας, κυρίως γρήγορη `fast` και αργή `relax`. Όταν χρησιμοποιείτε `relax`, συνιστάται έντονα να χρησιμοποιήσετε την παράμετρο `callback_url` παρακάτω.
- `template`: το στυλ του προτύπου ταυτότητας.
- `image_urls`: οι σύνδεσμοι εικόνας πορτρέτου που χρειάζεται να ανεβούν.
- `callback_url`: το URL για την επιστροφή αποτελεσμάτων.

Αφού επιλέξετε, μπορείτε να δείτε ότι στα δεξιά έχει παραχθεί ο αντίστοιχος κώδικας, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/yp49hc.png" width="500" class="m-auto"></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και θα λάβετε το εξής αποτέλεσμα:

```json
{
  "success": true,
  "task_id": "ae1e4948-dba1-4a6f-87af-67961b647428",
  "data": [
    {
      "id": "202411031951124776",
      "image_url": "https://platform.cdn.acedata.cloud/headshots/ae1e4948-dba1-4a6f-87af-67961b647428.png",
      "template": "Ανδρική εικόνα"
    },
    {
      "id": "202411031951128490",
      "image_url": "https://platform.cdn.acedata.cloud/headshots/ae1e4948-dba1-4a6f-87af-67961b647428.png",
      "template": "Ανδρική εικόνα"
    }
  ]
}
```

Το επιστρεφόμενο αποτέλεσμα περιλαμβάνει πολλά πεδία, τα οποία περιγράφονται ως εξής:

- `success`, η κατάσταση της αποστολής της εργασίας δημιουργίας ταυτότητας.
- `task_id`, το ID της εργασίας δημιουργίας ταυτότητας.
- `data`, η λίστα αποτελεσμάτων της εργασίας δημιουργίας ταυτότητας.
  - `id`, το ID της φωτογραφίας της εργασίας δημιουργίας ταυτότητας.
  - `image_url`, ο σύνδεσμος της εικόνας της εργασίας δημιουργίας ταυτότητας.
  - `template`, το όνομα του προτύπου ταυτότητας της εργασίας δημιουργίας ταυτότητας.

Μπορείτε να δείτε ότι λάβαμε ικανοποιητικές πληροφορίες ταυτότητας με βάση το πρότυπο και την εικόνα πορτρέτου. Χρειάζεται μόνο να αποκτήσουμε την ταυτότητα μέσω της διεύθυνσης URL της εικόνας στο πεδίο `data`.

Επιπλέον, εάν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο παρακάτω κώδικας CURL:

```shell
curl -X POST 'https://api.acedata.cloud/headshots/generate' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "mode": "fast",
  "template": "male_portrait",
  "image_urls": ["https://cdn.zhishuyun.com/2024-11-03-d23744954ca4819503469f04f2268aa0.jpg"]
}'
```

## Ασύγχρονη Επιστροφή

Δεδομένου ότι ο χρόνος δημιουργίας ταυτότητας AI είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, εάν το API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος. Έτσι, αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη επιστροφή.

Η συνολική διαδικασία είναι: όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`. Μετά την υποβολή του API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα που περιλαμβάνει ένα πεδίο `task_id`, το οποίο αντιπροσωπεύει το ID της τρέχουσας εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα δημιουργίας ταυτότητας θα αποσταλεί μέσω POST JSON στη διεύθυνση `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε αυτό μέσω ενός παραδείγματος.

Αρχικά, η επιστροφή Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα. Οι προγραμματιστές θα πρέπει να αντικαταστήσουν με το URL του HTTP διακομιστή που έχουν δημιουργήσει. Για ευκολία, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να λάβετε ένα Webhook URL, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/sb4p3v.png)

Αντιγράψτε αυτό το URL και μπορείτε να το χρησιμοποιήσετε ως Webhook. Το παρακάτω παράδειγμα είναι `https://webhook.site/00f38b26-4289-4899-83d6-0cea7308850a`.

Στη συνέχεια, μπορούμε να ρυθμίσουμε το πεδίο `callback_url` στο παραπάνω Webhook URL, ενώ θα εισάγουμε τον σύνδεσμο της εικόνας πορτρέτου και το πρότυπο. Αυτό το έγγραφο συνιστά να χρησιμοποιείτε την ασύγχρονη επιστροφή όταν η παράμετρος `mode` είναι `relax`, οι λεπτομέρειες είναι όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/opt326.png" width="500" class="m-auto"></p>

Κάνοντας κλικ στην εκτέλεση, μπορείτε να δείτε ότι θα λάβετε αμέσως ένα αποτέλεσμα, όπως το εξής:

```
{
  "task_id": "763b1450-8804-434f-acc7-d713be73a28f"
}
```

Μετά από λίγο, μπορείτε να παρακολουθήσετε το αποτέλεσμα δημιουργίας στο `https://webhook.site/00f38b26-4289-4899-83d6-0cea7308850a`, όπως φαίνεται στην εικόνα:
![](https://cdn.acedata.cloud/ym6fw1.png)

Το περιεχόμενο είναι το εξής:

```json
{
    "success": true,
    "task_id": "763b1450-8804-434f-acc7-d713be73a28f",
    "data": [
        {
            "id": "202411032010131366",
            "image_url": "https://platform.cdn.acedata.cloud/headshots/763b1450-8804-434f-acc7-d713be73a28f.png",
            "template": "Ανδρική εικόνα"
        },
        {
            "id": "202411032010132420",
            "image_url": "https://platform.cdn.acedata.cloud/headshots/763b1450-8804-434f-acc7-d713be73a28f.png",
            "template": "Ανδρική εικόνα"
        }
    ]
}
```

Μπορείτε να δείτε ότι το αποτέλεσμα περιέχει ένα πεδίο `task_id`, τα άλλα πεδία είναι παρόμοια με τα παραπάνω, μέσω αυτού του πεδίου μπορείτε να επιτύχετε τη σύνδεση της εργασίας.

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα απόκρισης σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "η λήψη απέτυχε"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
