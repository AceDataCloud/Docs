Η Google SERP (Σελίδα Αποτελεσμάτων Μηχανής Αναζήτησης) είναι η σελίδα αποτελεσμάτων που βλέπει ο χρήστης μετά την εισαγωγή ενός ερωτήματος στη μηχανή αναζήτησης Google. Εμφανίζει φυσικά αποτελέσματα αναζήτησης, διαφημίσεις, χαρακτηριστικά αποσπάσματα, γραφήματα γνώσης καθώς και διάφορα περιεχόμενα όπως εικόνες και βίντεο, με στόχο να παρέχει στους χρήστες τις πιο σχετικές πληροφορίες.

Αυτό το άρθρο θα παρουσιάσει λεπτομερώς το Google SERP API, το οποίο μπορεί να παρέχει αποτελέσματα για ερωτήματα που εισάγονται στη μηχανή αναζήτησης Google, με περιεχόμενο που περιλαμβάνει πολλές κατηγορίες, όπως χαρακτηριστικά αποσπάσματα, γραφήματα γνώσης και εικόνες.

Αυτό το έγγραφο θα περιγράψει τις οδηγίες σύνδεσης του Google SERP API.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Google SERP API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [Google SERP API](https://platform.acedata.cloud/documents/44c86226-8eaa-49bf-85f3-1fae8d2e23f1) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή εισάγοντας τον τύπο πόρου αναζήτησης και τις λέξεις-κλειδιά, μπορείτε να αποκτήσετε αποτελέσματα αναζήτησης, απλά μεταβιβάζοντας το πεδίο `query` και καθορίζοντας το αντίστοιχο μοντέλο.

Για παράδειγμα, για να βρείτε πληροφορίες σχετικά με την «apple inc», μπορείτε να συμπληρώσετε τα αντίστοιχα περιεχόμενα στην οθόνη, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι εδώ έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί API που χρησιμοποιείτε, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `type`: τον τύπο του πόρου αναζήτησης, αυτή τη στιγμή υποστηρίζονται μόνο έξι τύποι, με προεπιλογή το `search`.
- `query`: τις λέξεις-κλειδιά αναζήτησης.
- `country`: την προσαρμοσμένη χώρα των αποτελεσμάτων αναζήτησης, με προεπιλογή τις Ηνωμένες Πολιτείες (US).
- `language`: την προσαρμοσμένη γλώσσα των αποτελεσμάτων αναζήτησης, με προεπιλογή τα αγγλικά (en).
- `range`: την προσαρμοσμένη χρονική περίοδο των αποτελεσμάτων αναζήτησης, με προεπιλογή χωρίς περιορισμούς.
- `number`: το μέγεθος της σελίδας των αποτελεσμάτων αναζήτησης, με προεπιλογή 10.
- `page`: τον αριθμό της σελίδας των αποτελεσμάτων αναζήτησης, με προεπιλογή 1.

## Προσαρμογή σελίδων αποτελεσμάτων αναζήτησης

Αυτή η API υποστηρίζει επίσης την προσαρμογή της εμφάνισης των αποτελεσμάτων αναζήτησης σε σελίδες, το `number` και το `page` δηλώνουν το μέγεθος της σελίδας και τον αριθμό της σελίδας, σε αυτό το κείμενο θα ορίσουμε ότι σε μία σελίδα υπάρχουν 20 αποτελέσματα αναζήτησης για την εμφάνιση σελίδων, οι συγκεκριμένες πληροφορίες είναι όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/dqla1e.png" width="500" className="m-auto" /></p>

> Σημείωση: Όταν τα αποτελέσματα ανά σελίδα υπερβαίνουν τα 10, οι πόντοι που αφαιρούνται θα διπλασιαστούν.

Ο κώδικας είναι ο εξής:
```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc",
  "number": 20,
  "page": 1
}'
```
