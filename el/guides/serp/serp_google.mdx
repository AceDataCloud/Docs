Το Google SERP (Search Engine Results Page) είναι η σελίδα αποτελεσμάτων που βλέπουν οι χρήστες αφού εισαγάγουν ένα ερώτημα στη μηχανή αναζήτησης Google. Εμφανίζει φυσικά αποτελέσματα αναζήτησης, διαφημίσεις, επιλεγμένα αποσπάσματα, γράφο γνώσης, καθώς και διάφορους τύπους περιεχομένου όπως εικόνες και βίντεο, με στόχο να παρέχει στους χρήστες τις πιο σχετικές πληροφορίες.

Αυτό το άρθρο θα παρουσιάσει λεπτομερώς το Google SERP API, το οποίο μπορεί να παρέχει αποτελέσματα για ερωτήματα που εισάγονται στη μηχανή αναζήτησης Google, και το περιεχόμενο των αποτελεσμάτων περιλαμβάνει επίσης πολλούς τύπους, όπως επιλεγμένα αποσπάσματα, γράφο γνώσης και εικόνες.

Αυτό το έγγραφο θα παρουσιάσει τις οδηγίες ενσωμάτωσης του Google SERP API.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Google SERP API, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση προσφέρει δωρεάν πίστωση, ώστε να μπορείτε να το δοκιμάσετε δωρεάν· όταν η πίστωση δεν επαρκεί, μπορείτε να προσθέσετε γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [Google SERP API →](https://platform.acedata.cloud/documents/serp-google)

## Βασική χρήση

Εισαγάγετε λέξεις-κλειδιά και τύπο πόρου αναζήτησης για να λάβετε αποτελέσματα: χρησιμοποιήστε το `query` για να μεταφέρετε λέξεις-κλειδιά και το `type` για να επιλέξετε τύπους αναζήτησης όπως ιστοσελίδες, εικόνες και ειδήσεις· αυτή η διεπαφή δεν απαιτεί τη μεταφορά του `model`.

Για παράδειγμα, για αναζήτηση: πληροφοριών σχετικά με το “apple inc”, μπορούμε στη συνέχεια να συμπληρώσουμε το αντίστοιχο περιεχόμενο στη διεπαφή, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

Μπορούμε να δούμε ότι εδώ ρυθμίσαμε τα Request Headers, τα οποία περιλαμβάνουν:

- `accept`: τη μορφή των αποτελεσμάτων απόκρισης που θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορεί να επιλεγεί απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

Επιπλέον, ρυθμίσαμε το Request Body, το οποίο περιλαμβάνει:

- `type`: τον τύπο του πόρου αναζήτησης, προς το παρόν υποστηρίζονται μόνο έξι τύποι και η προεπιλογή είναι `search`.
- `query`: τη λέξη-κλειδί της αναζήτησης.
- `country`: τη χώρα όπου βρίσκονται τα προσαρμοσμένα αποτελέσματα αναζήτησης, με προεπιλογή τις Ηνωμένες Πολιτείες (US).
- `language`: τη γλώσσα των προσαρμοσμένων αποτελεσμάτων αναζήτησης, με προεπιλογή τα αγγλικά (en).
- `range`: το χρονικό εύρος των προσαρμοσμένων αποτελεσμάτων αναζήτησης, με προεπιλογή χωρίς περιορισμό.
- `number`: το μέγεθος σελίδας της σελιδοποίησης των προσαρμοσμένων αποτελεσμάτων αναζήτησης, με προεπιλογή το 10.
- `page`: τον αριθμό σελίδας της σελιδοποίησης των προσαρμοσμένων αποτελεσμάτων αναζήτησης, με προεπιλογή το 1.

Επιπλέον, αν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα ενσωμάτωσης, μπορείτε να τον αντιγράψετε απευθείας για δημιουργία, για παράδειγμα, ο κώδικας CURL είναι ο εξής:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc"
}'
```

Ο κώδικας ενσωμάτωσης Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/serp/google"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "query": "apple inc"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Προσαρμοσμένος τύπος αναζήτησης

Αν προσαρμόσετε τον τύπο των πόρων αναζήτησης, μπορούμε να τροποποιήσουμε την παράμετρο `type`, η οποία περιλαμβάνει αντίστοιχα τους συνηθισμένους πόρους `search`, τους πόρους εικόνων `images`, τους πόρους ειδήσεων `news`, τους πόρους χαρτών `maps`, τους τοπικούς πόρους `places` και τους πόρους βίντεο `videos`. Αυτό το άρθρο θα χρησιμοποιήσει τους πόρους βίντεο `videos` ως παράδειγμα.

Παρακάτω θα παρουσιάσουμε τις συγκεκριμένες ενέργειες.

Αρχικά, ορίστε την παράμετρο `type` σε `videos` και μεταβιβάστε κανονικά την παράμετρο `query`, όπως φαίνεται στην εικόνα:
<p><img src="https://cdn.acedata.cloud/czlt12.png" width="500" className="m-auto" /></p>

Ο αντίστοιχος κώδικας είναι ο εξής:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "videos",
  "query": "apple inc"
}'
```

## Προσαρμογή χρονικού εύρους αποτελεσμάτων αναζήτησης
Εδώ μπορείτε επίσης να προσαρμόσετε το χρονικό εύρος των αποτελεσμάτων αναζήτησης, συμπεριλαμβανομένων πέντε επιλογών: `qdr:h` (την τελευταία ώρα), `qdr:d` (την τελευταία ημέρα), `qdr:w` (την τελευταία εβδομάδα), `qdr:m` (τον τελευταίο μήνα), και χωρίς περιορισμό από προεπιλογή. Μπορούμε να περάσουμε το αντίστοιχο χρονικό εύρος μέσω του `range`. Για παράδειγμα, εδώ ορίζεται ως `qdr:d`, που σημαίνει αναζήτηση αποτελεσμάτων της τελευταίας ημέρας, επομένως η εισαγωγή είναι η ακόλουθη:

curl -X POST 'https://api.acedata.cloud/serp/google' \

-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "range": "qdr:d",
