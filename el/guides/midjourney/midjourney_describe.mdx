Η κύρια λειτουργία του Midjourney Describe API είναι να αποκτά περιγραφή μιας εικόνας μέσω της ανάρτησής της. Χρησιμοποιώντας αυτό το API, χρειάζεται απλώς να μεταφέρετε τη διεύθυνση του αρχείου εικόνας, και το API θα επιστρέψει μια λεπτομερή περιγραφή της εικόνας. Δεν απαιτούνται περίπλοκες ρυθμίσεις παραμέτρων για να αποκτήσετε περιγραφές εικόνας υψηλής ποιότητας.

Υποστηρίζει πολλές μορφές εικόνας: είτε είναι JPEG, PNG ή GIF, όλες οι κύριες μορφές εικόνας μπορούν να αναγνωριστούν και να επεξεργαστούν εύκολα.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες διασύνδεσης του Midjourney Describe API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του Midjourney Describe API, μπορείτε να αυτοματοποιήσετε την περιγραφή εικόνας και να αυξήσετε την αποδοτικότητα της επιχείρησής σας.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Midjourney Describe API, πρέπει πρώτα να επισκεφθείτε τη σελίδα αίτησης [Midjourney Describe API](https://platform.acedata.cloud/documents/870e973b-712a-4686-ab8b-beae27f129ce) για να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![Σελίδα αίτησης](https://cdn.acedata.cloud/rci31i.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη [σελίδα σύνδεσης](https://platform.acedata.cloud) που σας προσκαλεί να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που θα σας επιτρέπει να χρησιμοποιήσετε δωρεάν αυτό το API.

## Παράδειγμα αιτήματος

Ας πάρουμε μια εικόνα ως παράδειγμα για να δείξουμε πώς να χρησιμοποιήσουμε αυτό το API. Ας υποθέσουμε ότι έχουμε μια εικόνα τοπίου, και στη συνέχεια θα δείξουμε πώς να ανεβάσουμε αυτή την εικόνα και να αποκτήσουμε περιγραφή.

### Παράδειγμα εικόνας αιτήματος

![Εικόνα παραδείγματος](https://cdn.acedata.cloud/kg7xp3.png)

### Ρύθμιση κεφαλίδων αιτήματος και σώματος αιτήματος

**Request Headers** περιλαμβάνει:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `image_url`: τη διεύθυνση του αρχείου εικόνας που ανεβάσατε.

Ρυθμίστε όπως φαίνεται στην παρακάτω εικόνα:

![](https://cdn.acedata.cloud/eeui10.png)

### Παράδειγμα κώδικα

Μπορείτε να παρατηρήσετε ότι στη δεξιά πλευρά της σελίδας έχουν ήδη παραχθεί αυτόματα διάφορες γλώσσες κώδικα, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/8edj9z.png" width="400" class="m-auto"></p>

Ορισμένα παραδείγματα κώδικα είναι τα εξής:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/midjourney/describe' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/kg7xp3.png"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/midjourney/describe"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/kg7xp3.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές κλειδί εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
