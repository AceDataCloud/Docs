Αυτό το άρθρο θα παρουσιάσει μια μέθοδο σύνδεσης με το Midjourney Edits API, το οποίο μπορεί να επεξεργαστεί τις εισερχόμενες εικόνες με την εισαγωγή προτροπών.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [Midjourney Edits API](https://platform.acedata.cloud/documents/midjourney-edits) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να χρησιμοποιήσετε το API δωρεάν.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή την εισαγωγή προτροπής `prompt`, τη δράση `action`, και τη διεύθυνση εικόνας `image_url`, για να αποκτήσετε το επεξεργασμένο αποτέλεσμα. Πρέπει πρώτα να περάσετε ένα πεδίο `action`, του οποίου η τιμή είναι `generate`, με τις λεπτομέρειες όπως παρακάτω:

<p><img src="https://cdn.acedata.cloud/m44i6n.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `mask`: μπορείτε να καθορίσετε τη θέση της μάσκας της περιοχής της εικόνας για επεξεργασία και αναδημιουργία.
- `split_images`: διαχωρίζει την παραγόμενη εικόνα σε πολλές εικόνες, επιστρέφοντας μέσω του πεδίου sub_image_urls. Από προεπιλογή είναι false.
- `action`: η δράση της τρέχουσας επεξεργασίας εικόνας, προεπιλεγμένη είναι `generate`.
- `image_url`: ο σύνδεσμος της εικόνας που χρειάζεται επεξεργασία.
- `prompt`: η προτροπή.
- `mode`: η λειτουργία παραγωγής, επιλέξιμες οι `fast`/`relax`/`turbo`.
- `callback_url`: η διεύθυνση URL για την επιστροφή αποτελεσμάτων.

Αφού επιλέξετε, μπορείτε να δείτε ότι στα δεξιά έχει παραχθεί ο αντίστοιχος κώδικας, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/9wed3b.png" width="500" className="m-auto" /></p>

Κάντε κλικ στο κουμπί «Try» για να κάνετε δοκιμή, όπως φαίνεται στην παραπάνω εικόνα, και εδώ έχουμε λάβει το εξής αποτέλεσμα:

```json

    "https://cdn.midjourney.com/88e16dab-ef48-43a5-af73-bf24065287bc/0_1.png",
    "https://cdn.midjourney.com/88e16dab-ef48-43a5-af73-bf24065287bc/0_2.png",
    "https://cdn.midjourney.com/88e16dab-ef48-43a5-af73-bf24065287bc/0_3.png"
  ],
  "image_url": "https://storage.fonedis.cc/attachments/1372468820912115716/1391371957878132849/cat_sitting_table_88e16dab-ef48-43a5-af73-bf24065287bc.png?ex=686ba79d&is=686a561d&hm=ad005d06f6673d6152456e04c3cbec39d062bd9df10448623fae27ddaf8b8a80&",
  "image_width": 960,
  "image_height": 1200,
  "raw_image_url": "https://storage.fonedis.cc/attachments/1372468820912115716/1391371957878132849/cat_sitting_table_88e16dab-ef48-43a5-af73-bf24065287bc.png?ex=686ba79d&is=686a561d&hm=ad005d06f6673d6152456e04c3cbec39d062bd9df10448623fae27ddaf8b8a80&",
  "raw_image_width": 960,
  "raw_image_height": 1200,
  "progress": 100,
  "image_id": "1391372193836826624",
  "task_id": "26c39859-f54a-4998-9e42-3da96eceee8c",
  "success": true
}
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `success`, η κατάσταση της τρέχουσας επεξεργασίας εικόνας.
- `task_id`, το ID της τρέχουσας επεξεργασίας εικόνας.
- `image_id`, το ID της εικόνας της τρέχουσας επεξεργασίας.
- `sub_image_urls`, τα αποτελέσματα της επεξεργασίας εικόνας.
- `image_url`, ο σύνδεσμος της παραγόμενης εικόνας.
- `image_width`, το πλάτος της παραγόμενης εικόνας.
- `image_height`, το ύψος της παραγόμενης εικόνας.
- `progress`, το πεδίο προόδου της τρέχουσας επεξεργασίας εικόνας.

Μπορείτε να δείτε ότι έχουμε λάβει ικανοποιητικές πληροφορίες εικόνας, και απλά χρειάζεται να αποκτήσουμε την παραγόμενη εικόνα μέσω της διεύθυνσης `image_url`.

Επιπλέον, εάν θέλετε να παραγάγετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο παρακάτω κώδικας CURL:

```shell
curl -X POST 'https://api.acedata.cloud/midjourney/edits' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cat sitting on a table",
  "split_images": true,
  "image_url": "https://cdn.acedata.cloud/jgo1cw.jpg",
  "action": "generate"
}'
```

## Ασύγχρονη Επιστροφή

Δεδομένου ότι ο χρόνος παραγωγής του Midjourney Edits API είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, εάν το API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος. Έτσι, αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη επιστροφή.

Η συνολική διαδικασία είναι: όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`. Μετά την υποβολή του αιτήματος API, το API θα επιστρέψει αμέσως ένα αποτέλεσμα που περιλαμβάνει ένα πεδίο `task_id`, το οποίο αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα της παραγόμενης εικόνας θα αποσταλεί μέσω POST JSON στη διεύθυνση URL `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε αυτό μέσω ενός παραδείγματος.

Αρχικά, η επιστροφή Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα. Οι προγραμματιστές θα πρέπει να αντικαταστήσουν με τη διεύθυνση URL του HTTP διακομιστή που έχουν δημιουργήσει. Για ευκολία, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να αποκτήσετε μια διεύθυνση Webhook URL, όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/hfrbzw.png)

Αντιγράψτε αυτή τη διεύθυνση URL και μπορείτε να τη χρησιμοποιήσετε ως Webhook. Το παράδειγμα εδώ είναι `https://webhook.site/556e6971-b41f-4fa8-9151-6e91acd0399f`.

Στη συνέχεια, μπορούμε να ρυθμίσουμε το πεδίο `callback_url` στην παραπάνω διεύθυνση Webhook, ενώ συμπληρώνουμε τα αντίστοιχα παραμέτρους, με τις λεπτομέρειες όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/q3fnhv.png" width="500" className="m-auto" /></p>

Κάνοντας κλικ στην εκτέλεση, μπορείτε να δείτε ότι θα λάβετε αμέσως ένα αποτέλεσμα, όπως παρακάτω:

```

  "task_id": "b8b7fdc2-628e-40dd-bc0c-671c3ddac9e9"
}
```

Μετά από λίγο, μπορείτε να παρακολουθήσετε το αποτέλεσμα της παραγόμενης εικόνας στη διεύθυνση `https://webhook.site/556e6971-b41f-4fa8-9151-6e91acd0399f`, όπως φαίνεται στην εικόνα:

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα Απόκρισης Σφάλματος

{

    "message": "fetch failed"
