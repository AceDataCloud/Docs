Αυτό το άρθρο θα παρουσιάσει μια μέθοδο σύνδεσης με το API Midjourney Videos, το οποίο μπορεί να χρησιμοποιηθεί για τη δημιουργία βίντεο από την επίσημη πλατφόρμα Midjourney μέσω εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [Midjourney Videos API](https://platform.acedata.cloud/documents/midjourney-videos) και να υποβάλετε αίτηση για την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη σελίδα.

Κατά την πρώτη αίτηση, θα λάβετε δωρεάν πιστώσεις για να χρησιμοποιήσετε το API χωρίς χρέωση.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, η οποία περιλαμβάνει την εισαγωγή της λέξης-κλειδί `prompt`, της ενέργειας `action`, και του πίνακα αναφοράς εικόνας για την αρχική και την τελική καρέ `image_url`, για να λάβετε το επεξεργασμένο αποτέλεσμα. Πρέπει πρώτα να περάσετε ένα πεδίο `action`, του οποίου η τιμή είναι `generate`. Αυτό περιλαμβάνει δύο τύπους ενεργειών: δημιουργία βίντεο (`generate`), επέκταση βίντεο (`extend`), με τις λεπτομέρειες όπως παρακάτω:

<p><img src="https://cdn.acedata.cloud/pi72m9.png" width="500" class="m-auto"></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί API για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `image_url`: το σύνδεσμο της εικόνας αναφοράς για την αρχική καρέ του βίντεο.
- `end_image_url`: προαιρετικό, καθορίζει την εικόνα αναφοράς για την τελική καρέ του βίντεο.
- `video_id`: απαιτείται για την επέκταση του βίντεο.
- `video_index`: απαιτείται για να καθορίσετε ποιο συγκεκριμένο βίντεο από το `video_id`, ο δείκτης ξεκινά από το 0, προεπιλογή είναι το 0.
- `action`: η ενέργεια της τρέχουσας εργασίας δημιουργίας βίντεο, που περιλαμβάνει δύο τύπους ενεργειών: δημιουργία βίντεο (`generate`), επέκταση βίντεο (`extend`).
- `prompt`: λέξη-κλειδί.
- `mode`: ταχύτητα δημιουργίας βίντεο, προεπιλογή είναι το fast.
- `resolution`: ανάλυση βίντεο, προεπιλογή είναι το 720p.
- `loop`: αν θα δημιουργηθεί βίντεο σε βρόχο, προεπιλογή είναι το false.
- `callback_url`: το URL για την επιστροφή αποτελεσμάτων.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

Η επιστροφή αποτελέσματος περιλαμβάνει πολλά πεδία, που περιγράφονται ως εξής:

- `success`, η κατάσταση της τρέχουσας εργασίας δημιουργίας βίντεο.
- `task_id`, το ID της τρέχουσας εργασίας δημιουργίας βίντεο.
- `image_url`, η εικόνα εξωφύλλου της τρέχουσας εργασίας δημιουργίας βίντεο.
- `image_width`, το πλάτος της εικόνας εξωφύλλου της τρέχουσας εργασίας δημιουργίας βίντεο.
- `image_height`, το ύψος της εικόνας εξωφύλλου της τρέχουσας εργασίας δημιουργίας βίντεο.
- `video_id`, το ID του βίντεο της τρέχουσας εργασίας δημιουργίας βίντεο.
- `video_urls`, ο πίνακας συνδέσμων του βίντεο της τρέχουσας εργασίας δημιουργίας βίντεο.

Μπορείτε να δείτε ότι έχουμε λάβει ικανοποιητικές πληροφορίες βίντεο, και απλά πρέπει να αποκτήσουμε το παραγόμενο βίντεο Midjourney από τη διεύθυνση του βίντεο στο `video_urls`.

Επιπλέον, αν θέλετε να δημιουργήσετε τον αντίστοιχο κώδικα σύνδεσης, μπορείτε να τον αντιγράψετε απευθείας, όπως ο παρακάτω κώδικας CURL:

```shell
curl -X POST 'https://api.acedata.cloud/midjourney/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "prompt": "A cat sitting on a table",
  "image_url": "https://cdn.acedata.cloud/jgo1cw.jpg"
}'
```

## Λειτουργία Επέκτασης Βίντεο

Αν θέλετε να συνεχίσετε τη δημιουργία ενός ήδη παραγόμενου βίντεο Kling, μπορείτε να ρυθμίσετε την παράμετρο `action` σε `extend` και να εισάγετε το ID του βίντεο που θέλετε να συνεχίσετε. Το ID του βίντεο μπορεί να αποκτηθεί από τη βασική χρήση.

Αυτή τη στιγμή, μπορείτε να δείτε ότι το ID του βίντεο από το προηγούμενο κείμενο είναι:

```
"video_id": "1751816807896311"
```

> Σημειώστε ότι το `video_id` εδώ είναι το ID του βίντεο που παραγέθηκε. Αν δεν ξέρετε πώς να δημιουργήσετε βίντεο, μπορείτε να ανατρέξετε στη βασική χρήση παραπάνω.

Στη συνέχεια, πρέπει να συμπληρώσετε την επόμενη λέξη-κλειδί που χρειάζεται για να προσαρμόσετε τη δημιουργία του βίντεο, καθορίζοντας τα εξής περιεχόμενα:

- `video_index`: επιλέξτε τον δείκτη του βίντεο που θα επεκταθεί, ο οποίος είναι ο δείκτης από το `video_urls` που παραγέθηκε παραπάνω, ξεκινά από το 0, προεπιλογή είναι το 0.
- `video_id`: το ID του βίντεο που θα επεκταθεί.
- `action`: η ενέργεια της τρέχουσας επέκτασης βίντεο, είναι `extend`.
- `prompt`: λέξη-κλειδί.

Ένα παράδειγμα συμπλήρωσης είναι το εξής:

<p><img src="https://cdn.acedata.cloud/855hnj.png" width="500" class="m-auto"></p>

Αφού συμπληρώσετε, θα παραχθεί αυτόματα ο παρακάτω κώδικας:

<p><img src="https://cdn.acedata.cloud/p58w39.png" width="500" class="m-auto"></p>

Ο αντίστοιχος κώδικας Python είναι:

```python
import requests

url = "https://api.acedata.cloud/midjourney/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "prompt": "A cat sitting on a table",
    "video_id": "1751816807896311",
    "video_index": 1
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Ασύγχρονη κλήση

Δεδομένου ότι ο χρόνος δημιουργίας του API βίντεο Midjourney είναι σχετικά μεγάλος, περίπου 1-2 λεπτά, εάν το API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος, γι' αυτό το API παρέχει επίσης υποστήριξη για ασύγχρονη κλήση.

Η συνολική διαδικασία είναι: όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`, μετά την υποβολή του API αίτημα, το API θα επιστρέψει αμέσως ένα αποτέλεσμα που περιλαμβάνει μια πληροφορία πεδίου `task_id`, που αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα του δημιουργημένου βίντεο θα αποσταλεί μέσω POST JSON στη διεύθυνση `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε αυτό μέσω ενός παραδείγματος.

Αρχικά, η κλήση Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα, οι προγραμματιστές θα πρέπει να την αντικαταστήσουν με το URL του HTTP διακομιστή που έχουν δημιουργήσει. Εδώ, για λόγους ευκολίας, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να αποκτήσετε ένα Webhook URL, όπως φαίνεται στην εικόνα:

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψουν σφάλματα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα απόκρισης σφάλματος

    "message": "fetch failed"

}
