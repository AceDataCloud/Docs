Η κύρια λειτουργία του Midjourney Tasks API είναι να ερωτά την κατάσταση εκτέλεσης ενός έργου μέσω του ID έργου που παράγεται από το Midjourney Imagine API ή το Midjourney Describe API.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες διασύνδεσης του Midjourney Tasks API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του Midjourney Tasks API, μπορείτε εύκολα να ελέγξετε την κατάσταση εκτέλεσης των έργων του Midjourney Imagine API ή του Midjourney Describe API.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Midjourney Tasks API, πρέπει πρώτα να επισκεφθείτε τη σελίδα αίτησης [Midjourney Imagine API](https://platform.acedata.cloud/documents/e52c028d-897a-4d51-b110-60fccbe6118d) για να ζητήσετε την αντίστοιχη υπηρεσία και στη συνέχεια να αντιγράψετε το ID έργου του Imagine API, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/lx4mwb.png" width="500" className="m-auto" /></p>

Τέλος, επισκεφθείτε τη σελίδα Tasks API [Midjourney Tasks API](https://platform.acedata.cloud/documents/58ea7cc1-c685-40c3-a619-f29f9ac5d8f4) για να ζητήσετε την αντίστοιχη υπηρεσία, και αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![Σελίδα αίτησης](https://cdn.acedata.cloud/rci31i.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη [σελίδα σύνδεσης](https://platform.acedata.cloud) για να σας προσκαλέσει να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Παράδειγμα αιτήματος

Το Midjourney Tasks API μπορεί να χρησιμοποιηθεί για να ελέγξει τα αποτελέσματα των δύο API, Midjourney Imagine API και Midjourney Describe API. Για πληροφορίες σχετικά με το πώς να χρησιμοποιήσετε το Midjourney Imagine API, ανατρέξτε στο έγγραφο [Midjourney Imagine API](https://platform.acedata.cloud/documents/b0e32002-2707-41cc-b103-a15b1f1efdc1). Για πληροφορίες σχετικά με το πώς να χρησιμοποιήσετε το Midjourney Describe, ανατρέξτε στο [Midjourney Describe API](https://platform.acedata.cloud/documents/d2a04242-507c-4a49-a17a-01bc382c5756).

Ας πάρουμε ένα παράδειγμα με το ID έργου που επιστρέφει η υπηρεσία Midjourney Imagine API, για να δείξουμε πώς να χρησιμοποιήσετε αυτό το API. Ας υποθέσουμε ότι έχουμε ένα ID έργου: 7489df4c-ef03-4de0-b598-e9a590793434, και στη συνέχεια θα δείξουμε πώς να το περάσουμε.

### Ρύθμιση κεφαλίδων αιτήματος και σώματος αιτήματος

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `id`: το ID του έργου που ανεβάσατε.
- `ids`: πίνακας ID έργων για μαζική αναζήτηση.
- `action`: ο τρόπος λειτουργίας του έργου, υποστηρίζει `retrieve` (μοναδική αναζήτηση) και `retrieve_batch` (μαζική αναζήτηση).

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/midjourney/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "7489df4c-ef03-4de0-b598-e9a590793434",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/midjourney/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "7489df4c-ef03-4de0-b598-e9a590793434",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Η επιστρεφόμενη απάντηση περιλαμβάνει πολλά πεδία, το πεδίο request είναι το σώμα του αιτήματος κατά την εκκίνηση του έργου, ενώ το πεδίο response είναι το σώμα της απάντησης που επιστρέφεται μετά την ολοκλήρωση του έργου. - `type`, εάν type = imagine σημαίνει ότι είναι το αποτέλεσμα του Midjourney Imagine API, εάν type = describe σημαίνει ότι είναι το αποτέλεσμα του Midjourney Describe API.
- `job_id`, το ID του έργου που δημιουργεί αυτή την αναζήτηση εικόνας, χρησιμοποιείται για να προσδιορίσει μοναδικά αυτή την αναζήτηση εικόνας.

- `request`, οι πληροφορίες του αιτήματος στην αναζήτηση της εικόνας.
- `response`, οι πληροφορίες της απάντησης στην αναζήτηση της εικόνας.

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
