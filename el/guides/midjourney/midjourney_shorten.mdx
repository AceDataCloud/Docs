Η κύρια λειτουργία του Midjourney Shorten API είναι η πρόσβαση στην επίσημη εντολή `/shorten` (Ανάλυση Prompt) του Midjourney, για την ανάλυση ενός Prompt, την αναγνώριση των λέξεων-κλειδιών με το υψηλότερο βάρος και τη δημιουργία 5 πιο συνοπτικών υποψήφιων Prompt. Αυτή η διεπαφή είναι ιδιαίτερα κατάλληλη για:

- Τη συμπίεση μεγάλων Prompt πριν από την κλήση της εντολής `imagine`, βελτιώνοντας τη συνάφεια της εικόνας.
- Την αντίστροφη κατανόηση του βάρους κάθε token από το Midjourney μέσω των υποψήφιων Prompt, διευκολύνοντας την επεξεργασία Prompt.
- Τον συνδυασμό με αυτοματοποιημένες ροές εργασίας για τη συγχώνευση και συμπίεση λέξεων-κλειδιών από τα Prompt που εισάγουν οι χρήστες.

Αυτό το έγγραφο παρέχει λεπτομερείς οδηγίες για την ενσωμάτωση του Midjourney Shorten API, βοηθώντας σας να το ενσωματώσετε εύκολα.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το Midjourney Shorten API, πρέπει πρώτα να κάνετε αίτηση στην σελίδα [Midjourney Shorten API](https://platform.acedata.cloud/documents/f0c6be1d-c084-43ac-bde6-44ef9cf824a2). Μόλις μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire».

Αν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη [σελίδα σύνδεσης](https://platform.acedata.cloud) για εγγραφή και σύνδεση. Μετά τη σύνδεση ή εγγραφή, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, παρέχεται δωρεάν όριο χρήσης, επιτρέποντας τη δωρεάν χρήση του API.

## Παράδειγμα Αιτήματος

Θα χρησιμοποιήσουμε ένα σχετικά μεγάλο Prompt ως παράδειγμα για να δείξουμε πώς να το αναλύσετε και να το συμπτύξετε με το API.

### Ρύθμιση Headers και Σώματος Αιτήματος

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι αναμένεται απάντηση σε μορφή JSON, οπότε ορίζεται σε `application/json`.
- `authorization`: το κλειδί πρόσβασης για το API, το οποίο επιλέγεται μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `prompt`: το κείμενο του Prompt που θα αναλυθεί και συμπτυχθεί, συνιστάται να είναι στα αγγλικά.

### Παράδειγμα Κώδικα

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/midjourney/shorten' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "a serene mountain lake at sunrise, mist rising from the water, towering pine trees on the shore, golden hour lighting, ultra detailed, cinematic, 35mm film photography style, masterpiece --ar 16:9 --v 6"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/midjourney/shorten"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "prompt": (
        "a serene mountain lake at sunrise, mist rising from the water, "
        "towering pine trees on the shore, golden hour lighting, ultra "
        "detailed, cinematic, 35mm film photography style, masterpiece "
        "--ar 16:9 --v 6"
    )
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

### Παράδειγμα Απάντησης

Μετά από επιτυχή αίτηση, το API επιστρέφει έως και 5 συμπτυγμένα υποψήφια Prompt. Για παράδειγμα:

```json
{
  "prompts": [
    "a serene mountain lake at sunrise, mist rising from the water, golden hour lighting --ar 16:9",
    "mountain lake sunrise with mist, golden light --ar 16:9 --v 6",
    "tranquil alpine lake, dawn mist, warm golden tones, cinematic --ar 16:9",
    "sunrise over a misty mountain lake, rich golden hour photography --ar 16:9 --style raw",
    "misty lake at dawn, mountains in background, golden sunrise --ar 16:9"
  ]
}
```

Όπως φαίνεται, το πεδίο `prompts` περιέχει αρκετά συμπτυγμένα υποψήφια Prompt, όπου κάθε ένα διατηρεί τις λέξεις-κλειδιά με το υψηλότερο βάρος από το εσωτερικό του Midjourney, αφαιρώντας επαναλήψεις ή περιττές περιγραφές.

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, αν παρουσιαστεί σφάλμα, το API επιστρέφει τον αντίστοιχο κωδικό και μήνυμα σφάλματος. Παραδείγματα:

- `400 token_mismatched`: Κακό αίτημα, πιθανόν λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακό αίτημα, πιθανόν λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές token εξουσιοδότησης.
- `429 too_many_requests`: Υπερβολικός αριθμός αιτήσεων, έχετε ξεπεράσει το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, προέκυψε πρόβλημα στον διακομιστή.
