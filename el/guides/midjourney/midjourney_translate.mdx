Η κύρια λειτουργία του Midjourney Translate API είναι να αποκτά αγγλικές περιγραφές μέσω της εισαγωγής κινεζικών περιγραφικών λέξεων.

Αυτό το έγγραφο θα περιγράψει λεπτομερώς τις οδηγίες διασύνδεσης του Midjourney Translate API, βοηθώντας σας να ενσωματώσετε εύκολα και να αξιοποιήσετε πλήρως τη δύναμη αυτού του API. Μέσω του Midjourney Translate API, μπορείτε εύκολα να μετατρέψετε τις κινεζικές περιγραφικές λέξεις σε αγγλικές περιγραφές.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το Midjourney Translate API, πρέπει πρώτα να επισκεφθείτε τη σελίδα αίτησης [Midjourney Translate API](https://platform.acedata.cloud/documents/e067d19b-7a66-4458-a45f-0fe88c1d5d34) για να ζητήσετε την αντίστοιχη υπηρεσία. Αφού εισέλθετε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![Σελίδα αίτησης](https://cdn.acedata.cloud/rci31i.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη [σελίδα σύνδεσης](https://platform.acedata.cloud) για να σας προσκαλέσει να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Παράδειγμα αιτήματος

Ας πάρουμε ένα κινεζικό περιγραφικό λέξη ως παράδειγμα για να δείξουμε πώς να χρησιμοποιήσετε αυτό το API. Ας υποθέσουμε ότι η κινεζική περιγραφή είναι: 精致，无暇，洁白的天使, και στη συνέχεια θα δείξουμε πώς να ανεβάσετε την κινεζική περιγραφή και να αποκτήσετε την αγγλική περιγραφή.

### Ρύθμιση κεφαλίδων αιτήματος και σώματος αιτήματος

**Request Headers** περιλαμβάνουν:

- `accept`: καθορίζει ότι θα δεχθείτε την απάντηση σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

**Request Body** περιλαμβάνει:

- `content`: οι ανεβασμένες κινεζικές περιγραφικές λέξεις.

> Μόνο αυτό το πεδίο είναι απαραίτητο για να ολοκληρωθεί η μετάφραση, παρακαλώ βεβαιωθείτε ότι το `content` χρησιμοποιεί κινεζικές περιγραφικές λέξεις.

Ρυθμίστε όπως φαίνεται στην παρακάτω εικόνα:

![](https://cdn.acedata.cloud/db8lrn.png)

### Παράδειγμα κώδικα

Μπορείτε να παρατηρήσετε ότι στη δεξιά πλευρά της σελίδας έχουν παραχθεί αυτόματα διάφορες γλώσσες κώδικα, όπως φαίνεται στην εικόνα:

<p><img src="https://cdn.acedata.cloud/oj1cck.png" width="500" class="m-auto"></p>

Ορισμένα παραδείγματα κώδικα είναι τα εξής:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/midjourney/translate' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "content": "精致，无暇，洁白的天使"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/midjourney/translate"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": "精致，无暇，洁白的天使"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Παράδειγμα απάντησης

Αφού το αίτημα είναι επιτυχές, το API θα επιστρέψει μία περιγραφή που έχει μεταφραστεί από τις κινεζικές περιγραφές. Για παράδειγμα:

```json
{
  "content": "Exquisite, flawless, pure white angel"
}
```

Μπορείτε να δείτε ότι το αποτέλεσμα περιλαμβάνει ένα πεδίο `content`, το οποίο περιέχει την μεταφρασμένη αγγλική περιγραφή, η οποία είναι το αντίστοιχο αποτέλεσμα της κινεζικής περιγραφής.

- `content`, δημιουργεί την αντίστοιχη αγγλική περιγραφή, η οποία μπορεί να χρησιμοποιηθεί για περιγραφές εργασιών δημιουργίας εικόνας.

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
