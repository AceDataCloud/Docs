Το Maestro είναι μια διεπαφή παραγωγής βίντεο **εγγενής σε Agent**: χρησιμοποιείτε ένα φυσικής γλώσσας `prompt` για να περιγράψετε το βίντεο που θέλετε (προαιρετικά επισυνάπτετε εικόνες / βίντεο / ήχο αναφοράς με `file_urls`), και ένας ακέφαλος «AI σκηνοθέτης» θα ολοκληρώσει αυτόματα την επιλογή θέματος, τη συγγραφή σεναρίου, τη δημιουργία εικόνων, τη φωνητική αφήγηση, τη μουσική επένδυση, τη σύνθεση και την απόδοση, παράγοντας τελικά ένα ολοκληρωμένο βίντεο με υπότιτλους και ανεβάζοντάς το σε CDN.

Αυτό το άρθρο θα παρουσιάσει λεπτομερώς τις οδηγίες ενσωμάτωσης του API δημιουργίας βίντεο Maestro, βοηθώντας σας να το ενσωματώσετε γρήγορα και να αξιοποιήσετε πλήρως τις δυνατότητες αυτού του API.

Αυτή είναι μια διεπαφή **ασύγχρονης εργασίας**: μετά την υποβολή επιστρέφει αμέσως `task_id`, και στη συνέχεια λαμβάνετε το αποτέλεσμα μέσω περιοδικής ερώτησης από το [API ερωτήματος εργασιών Maestro](/el/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (οι ερωτήσεις είναι δωρεάν και δεν χρεώνονται). Για να συνεχίσετε την επανάληψη πάνω σε υπάρχον βίντεο, μπορείτε να χρησιμοποιήσετε `action: remix` / `edit` / `extend` σε συνδυασμό με `ref_task_id`.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το API δημιουργίας βίντεο Maestro, αρχικά μεταβείτε στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης, όπου θα σας ζητηθεί να εγγραφείτε και να συνδεθείτε· μετά την ολοκλήρωση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση παρέχει δωρεάν πίστωση για δωρεάν δοκιμή· όταν η πίστωση δεν επαρκεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο από την [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [API δημιουργίας βίντεο Maestro →](https://platform.acedata.cloud/documents/maestro-videos)

## Βασική χρήση

`POST https://api.acedata.cloud/maestro/videos`

Η πιο βασική χρήση απαιτεί μόνο την εισαγωγή ενός φυσικής γλώσσας `prompt`, και ο AI σκηνοθέτης θα αποφασίσει αυτόματα το σενάριο, τα πλάνα, τη φωνητική αφήγηση και το μοντάζ. Εδώ θα δούμε πρώτα τις κεφαλίδες αιτήματος και το σώμα αιτήματος που πρέπει να οριστούν.

Τα **Request Headers** περιλαμβάνουν:

- `accept`: τη μορφή στην οποία θέλετε να λάβετε το αποτέλεσμα απόκρισης· εδώ συμπληρώνεται `application/json`, δηλαδή μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.
- `content-type`: τη μορφή του σώματος αιτήματος· εδώ συμπληρώνεται `application/json`.

Το **Request Body** περιλαμβάνει κυρίως:

- `prompt`: περιγράψτε με φυσική γλώσσα το βίντεο που θέλετε να δημιουργήσετε (θέμα, τι να παρουσιάζει, στυλ, κοινό).
- `langs`: πίνακας γλωσσών του ολοκληρωμένου βίντεο, περνάτε μόνο μία κάθε φορά, όπως `["zh-cn"]`, με προεπιλογή `["zh-cn"]`.
- `aspect`: αναλογία εικόνας, `9:16` (προεπιλογή) / `16:9` / `1:1`.
- `duration`: στοχευόμενη διάρκεια (δευτερόλεπτα), προεπιλογή 30.

Όλα τα πεδία του σώματος αιτήματος εμφανίζονται στον παρακάτω πίνακα:

| Πεδίο            | Τύπος       | Υποχρεωτικό  | Περιγραφή                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Ναι   | Περιγράψτε με φυσική γλώσσα το βίντεο που θέλετε να δημιουργήσετε (θέμα, τι να παρουσιάζει, στυλ, κοινό). Το σενάριο, τα πλάνα, η φωνητική αφήγηση και το μοντάζ αποφασίζονται όλα από την AI                                                                                                                                                                             |
| `action`      | string   | Όχι   | `generate` (προεπιλογή, δημιουργία νέου βίντεο) / `remix` / `edit` / `extend` (επανάληψη πάνω σε υπάρχον βίντεο, απαιτεί συνδυασμό με `ref_task_id`)                                                                                                                                                |
| `ref_task_id` | string   | Όχι   | Υποχρεωτικό όταν το `action` είναι remix / edit / extend: το ιστορικό `task_id` της εργασίας που χρησιμοποιείται ως αφετηρία                                                                                                                                                                   |
| `file_urls`   | string[] | Όχι   | Μέσα αναφοράς (εικόνα / βίντεο / URL ήχου), για παράδειγμα εικόνα προϊόντος, logo που πρέπει να εμφανιστεί ή απόσπασμα υλικού στο οποίο πρέπει να προστεθούν υπότιτλοι                                                                                                                                                                             |
| `langs`       | string[] | Όχι   | Γλώσσα ολοκληρωμένου βίντεο, μπορεί να περαστεί μόνο μία κάθε φορά, όπως `["zh-cn"]`, με προεπιλογή `["zh-cn"]`                                                                                                                                                                                    |
| `aspect`      | string   | Όχι   | `9:16` (προεπιλογή) / `16:9` / `1:1`, ενιαία έξοδος 1080p/30fps                                                                                                                                                                                  |
| `duration`    | int      | Όχι   | Στοχευόμενη διάρκεια (δευτερόλεπτα), προεπιλογή 30, υποστηρίζει **5–300 δευτερόλεπτα**. Η χρέωση γίνεται βάσει της πραγματικής διάρκειας του ολοκληρωμένου βίντεο, αλλά δεν θα υπερβαίνει τη ζητούμενη διάρκεια                                                                                                                                                                             |
| `scenario`    | string   | Όχι   | Τύπος βίντεο: `auto` / `narrated` / `captions` / `avatar` / `drama`. Το `captions` απαιτεί βίντεο πηγής, το `avatar` απαιτεί πορτρέτο                                                                                                                                    |
| `style`       | string   | Όχι   | Προεπιλογή οπτικού στυλ: `auto` (προεπιλογή) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`, δέχεται επίσης ελεύθερο κείμενο ως ήπια υπόδειξη. Είναι ανεξάρτητο από το `scenario` και δεν αλλάζει τη δρομολόγηση |
| `voice`       | string   | Όχι   | Χροιά φωνητικής αφήγησης (ανεξάρτητη από τη γλώσσα, κοινή μεταξύ γλωσσών): `auto` (προεπιλογή) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`                                    |

Παρακάτω παρουσιάζουμε μέσω ενός συγκεκριμένου παραδείγματος. Ας υποθέσουμε ότι θέλουμε να δημιουργήσουμε ένα κινεζικό, κάθετο, 20-δευτερολέπτων σύντομο εκπαιδευτικό βίντεο, ο αντίστοιχος κώδικας CURL είναι ο εξής:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

Ο αντίστοιχος κώδικας Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Κάντε κλικ στην εκτέλεση και θα διαπιστώσετε ότι λαμβάνετε αμέσως ένα αποτέλεσμα, ως εξής:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Η εισαγωγή των πεδίων του αποτελέσματος επιστροφής είναι η εξής:
- `success`：Εάν αυτή η εργασία υποβλήθηκε επιτυχώς.
- `task_id`：Το ID αυτής της εργασίας δημιουργίας βίντεο, το οποίο θα χρησιμοποιηθεί στη συνέχεια για την ανάκτηση αποτελεσμάτων μέσω του [Maestro API ερωτημάτων εργασιών](/el/guides/maestro/maestro_tasks).
- `trace_id`：Το ID ιχνηλάτησης αυτού του αιτήματος, το οποίο μπορεί να παρασχεθεί στην τεχνική υποστήριξη για εντοπισμό σε περίπτωση προβλημάτων.

Καθώς η παραγωγή βίντεο απαιτεί αρκετό χρόνο, το API **επιστρέφει αμέσως το `task_id`** εδώ και δεν περιμένει να ολοκληρωθεί η απόδοση του βίντεο. Στη συνέχεια, πρέπει να χρησιμοποιήσετε το `task_id` για να ελέγχετε περιοδικά το αποτέλεσμα· δείτε την ενότητα «Λήψη αποτελεσμάτων» για λεπτομέρειες.

## Καθορισμός τύπου και στυλ βίντεο（scenario / style）

Όταν δεν μεταβιβάζεται το `scenario`, καθορίζεται αυτόματα από το AI（ισοδυναμεί με `auto`）· αν θέλετε να ορίσετε το βίντεο σε συγκεκριμένο τύπο, μεταβιβάστε το ρητά. Για παράδειγμα, για τη δημιουργία ενός **σύντομου κάθετου δράματος**, μπορείτε να καθορίσετε τα εξής:

- `scenario`：Τύπος βίντεο, ορίζεται εδώ ως `drama`（σύντομο δράμα με χαρακτήρες + διαλόγους）.
- `style`：Οπτικό στυλ, ορίζεται εδώ ως `cinematic`（κινηματογραφική αίσθηση）.

Το CURL παράδειγμα συμπλήρωσης είναι το εξής:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Συνήθεις τρόποι συνδυασμού:

- Σύντομο βίντεο αφήγησης：`scenario: "narrated"`。
- Αυτόματοι υπότιτλοι：`scenario: "captions"`，απαιτείται η μεταβίβαση του αρχικού βίντεο με `file_urls`。
- Ψηφιακό άβαταρ / προφορική παρουσίαση：`scenario: "avatar"`，απαιτείται η μεταβίβαση μιας εικόνας προσώπου με `file_urls`。
- Σύντομο δράμα：`scenario: "drama"`（χαρακτήρες + διάλογοι）。
- Το `style` είναι προεπιλογή οπτικού στυλ（όπως `modern` / `neon` / `luxury`），δεν αλλάζει τον τύπο και επηρεάζει μόνο την εμφάνιση.
- Το `voice` χρησιμοποιείται για τον καθορισμό της χροιάς της αφήγησης（όπως `warm-female` / `deep-male`），είναι ανεξάρτητο από τη γλώσσα και χρησιμοποιείται σε όλες τις γλώσσες.

Το αποτέλεσμα επιστροφής είναι ίδιο με τη «Βασική χρήση», δηλαδή επιστρέφεται επίσης αμέσως το `task_id`.

## Γλώσσα τελικού βίντεο

Μία εργασία παραδίδει μόνο ένα τελικό βίντεο σε μία γλώσσα. Το `langs` μπορεί να περιέχει μόνο έναν κωδικό γλώσσας, όπως `["zh-cn"]` ή `["en"]`· η μεταβίβαση πολλών γλωσσών θα επιστρέψει 400. Εάν χρειάζεστε βίντεο σε διαφορετικές γλώσσες, δημιουργήστε ξεχωριστές εργασίες. Η επιλογή γλώσσας δεν αλλάζει την τιμή ανά δευτερόλεπτο.

## Επανάληψη σε υπάρχον βίντεο（remix / edit / extend）

Μεταβιβάστε το `action` και το `ref_task_id` της προηγούμενης εργασίας για να κάνετε σταδιακές τροποποιήσεις βάσει του αρχικού έργου（όπως «αλλάξτε τον τίτλο της 2ης σκηνής」「αλλάξτε την αφήγηση」「σκουρύνετε το σύνολο」）。Οι μικρές αλλαγές είναι γρήγορες, ενώ οι μεγάλες αλλαγές θα απαιτήσουν επαναδημιουργία:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`：Επαναδημιουργία βάσει της αρχικής δομής του βίντεο（διατηρεί το θέμα και προσαρμόζει την παρουσίαση）.
- `edit`：Λεπτομερής επεξεργασία καθορισμένου τμήματος（όπως αλλαγή τίτλου, αλλαγή αφήγησης, χρωματική διόρθωση）.
- `extend`：Επέκταση του περιεχομένου βάσει του αρχικού βίντεο.

Το αποτέλεσμα επιστροφής είναι επίσης η άμεση επιστροφή ενός νέου `task_id`, το οποίο μπορείτε να χρησιμοποιήσετε για περιοδικό έλεγχο ώστε να λάβετε το τελικό βίντεο μετά την επανάληψη.

## Λήψη αποτελεσμάτων

Καθώς η παραγωγή βίντεο απαιτεί αρκετό χρόνο, αυτό το API επιστρέφει αμέσως το `task_id` μετά την υποβολή και πρέπει να το χρησιμοποιήσετε για να ελέγχετε περιοδικά το αποτέλεσμα μέσω του [Maestro API ερωτημάτων εργασιών](/el/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Όταν ολοκληρωθεί η εργασία, θα επιστραφεί μία πληροφορία τελικού βίντεο（βρίσκεται στον πίνακα `variants`）。Το `status` θα περάσει από `pending → planning → producing → succeeded`（ή `failed`），**ο περιοδικός έλεγχος είναι δωρεάν και δεν καταναλώνει μονάδες**。Για την πλήρη μορφή απόκρισης και την αναζήτηση λίστας ιστορικού, ανατρέξτε στις [Οδηγίες ενσωμάτωσης Maestro API ερωτημάτων εργασιών](/el/guides/maestro/maestro_tasks)。

## Χρέωση

**Μετά την επιτυχή ολοκλήρωση της εργασίας, η χρέωση γίνεται με βάση την πραγματική διάρκεια του παραδιδόμενου τελικού βίντεο· σε περίπτωση αποτυχίας δεν υπάρχει χρέωση.** Η διάρκεια χρέωσης υπολογίζεται σε ακέραια δευτερόλεπτα και δεν υπερβαίνει την αιτούμενη διάρκεια· όταν δεν είναι δυνατή η ανάγνωση της διάρκειας του τελικού βίντεο, χρησιμοποιείται ως εναλλακτική η αιτούμενη διάρκεια. Η ίδια η υποβολή εργασίας δεν χρεώνεται ξεχωριστά και ο περιοδικός έλεγχος `/maestro/tasks` είναι δωρεάν.

```
Μονάδες = πραγματικά χρεώσιμα δευτερόλεπτα × 0.7
```

Όλα τα σενάρια, οι ενέργειες και οι γλώσσες χρησιμοποιούν την ίδια τιμή, χωρίς πολλαπλασιαστή σεναρίου ή επιπλέον χρέωση γλώσσας. Κάθε εργασία παραδίδει μόνο ένα τελικό βίντεο σε μία γλώσσα. Η αιτούμενη διάρκεια υποστηρίζει 5–300 δευτερόλεπτα, με ενιαία έξοδο 1080p / 30fps.

| Πραγματική χρεώσιμη διάρκεια              |  Μονάδες |
| ------------------- | --: |
| 30 δευτερόλεπτα                |  21 |
| 60 δευτερόλεπτα                |  42 |
| 120 δευτερόλεπτα               |  84 |
| 300 δευτερόλεπτα               | 210 |
| Περιοδικός έλεγχος `/maestro/tasks` |  Δωρεάν |

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό και μήνυμα σφάλματος. Για παράδειγμα:

- `400 invalid_request`：Μη έγκυρο αίτημα, πιθανώς λόγω ελλείποντος `prompt` ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλείπον διακριτικό εξουσιοδότησης.
- `403 forbidden`：Απαγορεύεται, ανεπαρκές υπόλοιπο ή πρόσβαση.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα απόκρισης σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Συμπέρασμα

Μέσω αυτού του εγγράφου, έχετε ήδη κατανοήσει πώς να χρησιμοποιείτε το Maestro API δημιουργίας βίντεο: με μόνο ένα `prompt` φυσικής γλώσσας, μπορείτε να ολοκληρώσετε αυτόματα το σενάριο, το υλικό, την αφήγηση, τη μουσική επένδυση, το μοντάζ, τους υπότιτλους και την απόδοση του τελικού βίντεο, ενώ υποστηρίζεται επίσης ο καθορισμός τύπου βίντεο, στυλ, χροιάς φωνής, γλώσσας τελικού βίντεο και η επανάληψη σε υπάρχον βίντεο. Ελπίζουμε ότι αυτό το έγγραφο θα σας βοηθήσει να ενσωματώσετε και να χρησιμοποιήσετε καλύτερα αυτό το API. Εάν έχετε οποιαδήποτε ερώτηση, επικοινωνήστε με την ομάδα τεχνικής υποστήριξής μας ανά πάσα στιγμή.
