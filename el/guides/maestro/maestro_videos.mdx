Το Maestro είναι μια **εγγενής διεπαφή παραγωγής βίντεο**: χρησιμοποιείτε μια φυσική γλώσσα `prompt` για να περιγράψετε το βίντεο που θέλετε (προαιρετικά μπορείτε να επισυνάψετε `file_urls` με αναφορές εικόνων / βίντεο / ήχου), και ένας «AI σκηνοθέτης» θα ολοκληρώσει αυτόματα την επιλογή θέματος, τη συγγραφή σεναρίου, τη δημιουργία εικόνας, τη φωνητική αφήγηση, τη μουσική, τη σύνθεση και την απόδοση, παράγοντας τελικά ένα βίντεο με υπότιτλους και ανεβάζοντάς το στο CDN.

Αυτό το άρθρο θα περιγράψει λεπτομερώς τις οδηγίες ενσωμάτωσης του API δημιουργίας βίντεο Maestro, βοηθώντας σας να ενσωματώσετε γρήγορα και να αξιοποιήσετε πλήρως τις δυνατότητες αυτού του API.

Αυτή είναι μια **ασύγχρονη διεπαφή εργασιών**: μετά την υποβολή θα επιστραφεί αμέσως το `task_id`, και στη συνέχεια μπορείτε να ελέγξετε τα αποτελέσματα μέσω του [API Ερωτήσεων Εργασιών Maestro](/el/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (η αναζήτηση είναι δωρεάν και δεν χρεώνεται). Για να συνεχίσετε την επεξεργασία σε υπάρχον βίντεο, μπορείτε να χρησιμοποιήσετε `action: remix` / `edit` / `extend` σε συνδυασμό με `ref_task_id`.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API δημιουργίας βίντεο Maestro, πρώτα επισκεφθείτε την [Κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας, το οποίο θα κρατήσετε για μελλοντική χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά θα επιστρέψετε αυτόματα στη σελίδα.

**Ένα API Token αρκεί για να καλέσετε όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται να υποβάλετε ξεχωριστές αιτήσεις για κάθε υπηρεσία.** Η πρώτη αίτηση θα σας δώσει δωρεάν πίστωση για να δοκιμάσετε δωρεάν. Όταν η πίστωση εξαντληθεί, μπορείτε να ανανεώσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [API Δημιουργίας Βίντεο Maestro →](https://platform.acedata.cloud/documents/maestro-videos)

## Βασική Χρήση

`POST https://api.acedata.cloud/maestro/videos`

Η πιο βασική χρήση απαιτεί μόνο την εισαγωγή ενός φυσικού γλώσσας `prompt`, και ο AI σκηνοθέτης θα αποφασίσει αυτόματα το σενάριο, τις εικόνες, τη φωνητική αφήγηση και την επεξεργασία. Ας δούμε πρώτα τις κεφαλίδες και το σώμα του αιτήματος που πρέπει να ρυθμιστούν.

**Request Headers** περιλαμβάνουν:

- `accept`: τη μορφή της απάντησης που θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, μπορείτε να το επιλέξετε απευθείας μετά την αίτηση.
- `content-type`: τη μορφή του σώματος του αιτήματος, εδώ συμπληρώνεται ως `application/json`.

**Request Body** περιλαμβάνει κυρίως:

- `prompt`: περιγράψτε το βίντεο που θέλετε να δημιουργήσετε με φυσική γλώσσα (θέμα, τι να δείξετε, στυλ, κοινό).
- `langs`: πίνακας γλωσσών εξόδου, όπως `["zh-cn", "en"]`, προεπιλογή `["zh-cn"]`.
- `aspect`: αναλογία εικόνας, `9:16` (προεπιλογή) / `16:9` / `1:1`.
- `duration`: στοχευμένη διάρκεια (δευτερόλεπτα), προεπιλογή 30.

Όλα τα πεδία του σώματος του αιτήματος φαίνονται στον παρακάτω πίνακα:

| Πεδίο          | Τύπος     | Υποχρεωτικό | Περιγραφή                                                                                                                                                                                                                           |
| ------------- | -------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Ναι      | Περιγράψτε το βίντεο που θέλετε να δημιουργήσετε με φυσική γλώσσα (θέμα, τι να δείξετε, στυλ, κοινό). Το σενάριο, οι εικόνες, η φωνητική αφήγηση και η επεξεργασία καθορίζονται από τον AI.                                                                 |
| `action`      | string   | Όχι      | `generate` (προεπιλογή, δημιουργία νέου βίντεο) / `remix` / `edit` / `extend` (επικαιροποίηση σε υπάρχον βίντεο, απαιτεί `ref_task_id`).                                                                                       |
| `ref_task_id` | string   | Όχι      | Υποχρεωτικό όταν το `action` είναι remix / edit / extend: το ιστορικό `task_id` που χρησιμοποιείται ως σημείο εκκίνησης.                                                                                                   |
| `file_urls`   | string[] | Όχι      | Αναφορές μέσων (εικόνες / βίντεο / ήχου URL), όπως εικόνες προϊόντων, λογότυπα ή αποσπάσματα που χρειάζονται υπότιτλους.                                                                                                     |
| `langs`       | string[] | Όχι      | Γλώσσες εξόδου, όπως `["zh-cn", "en"]`, προεπιλογή `["zh-cn"]`. Η πρώτη είναι η κύρια γλώσσα. Κάθε επιπλέον γλώσσα επαναχρησιμοποιεί τις εικόνες, προσθέτει μόνο φωνητική αφήγηση + απόδοση, **κάθε επιπλέον +6 πόντους**. |
| `aspect`      | string   | Όχι      | `9:16` (προεπιλογή) / `16:9` / `1:1`, ομοιόμορφη έξοδος 1080p/30fps.                                                                                                                                                       |
| `duration`    | int      | Όχι      | Στοχευμένη διάρκεια (δευτερόλεπτα), προεπιλογή 30, υποστηρίζει **5–300 δευτερόλεπτα**. Χρεώνεστε με βάση τη διάρκεια του τελικού βίντεο, αλλά δεν θα υπερβεί τη ζητούμενη διάρκεια.                                               |
| `scenario`    | string   | Όχι      | Τύπος βίντεο: `auto` / `narrated` / `captions` / `avatar` / `drama`. Το `captions` απαιτεί το αρχικό βίντεο, το `avatar` απαιτεί εικόνα προσώπου.                                                                                 |
| `style`       | string   | Όχι      | Προεπιλεγμένο οπτικό στυλ: `auto` (προεπιλογή) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`, δέχεται επίσης ελεύθερο κείμενο ως μαλακή προτροπή. Δεν αλλάζει τη διαδρομή. |
| `voice`       | string   | Όχι      | Τόνος φωνής (ανεξάρτητο από τη γλώσσα, κοινό για όλες τις γλώσσες): `auto` (προεπιλογή) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`. |

Ακολουθεί ένα συγκεκριμένο παράδειγμα. Ας υποθέσουμε ότι θέλουμε να δημιουργήσουμε ένα δίγλωσσο (Κινέζικα και Αγγλικά), κατακόρυφο, 20 δευτερολέπτων βίντεο επιστημονικής ενημέρωσης, ο αντίστοιχος κώδικας CURL είναι ο εξής:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn", "en"],
  "aspect": "9:16",
  "duration": 20
}'
```

Ο αντίστοιχος κώδικας Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn", "en"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Αν κάνετε κλικ για εκτέλεση, θα δείτε ότι θα λάβετε αμέσως ένα αποτέλεσμα, όπως παρακάτω:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Η περιγραφή των πεδίων της επιστροφής είναι ως εξής:
- `success`：Εάν η τρέχουσα εργασία υποβλήθηκε με επιτυχία.
- `task_id`：Το ID της τρέχουσας εργασίας δημιουργίας βίντεο, το οποίο θα χρησιμοποιηθεί στη συνέχεια για να ερωτηθεί το αποτέλεσμα μέσω του [Maestro API ερωτήσεων εργασιών](/el/guides/maestro/maestro_tasks).
- `trace_id`：Το ID παρακολούθησης της τρέχουσας αίτησης, το οποίο μπορεί να παρασχεθεί στην τεχνική υποστήριξη για εντοπισμό προβλημάτων.

Δεδομένου ότι η παραγωγή βίντεο απαιτεί αρκετό χρόνο, η διεπαφή επιστρέφει **άμεσα το `task_id`** και δεν περιμένει την ολοκλήρωση της απόδοσης του βίντεο. Στη συνέχεια, χρειάζεται να χρησιμοποιήσετε το `task_id` για να ερωτηθείτε το αποτέλεσμα, δείτε την ενότητα «Λήψη αποτελεσμάτων».

## Καθορισμός τύπου και στυλ βίντεο (scenario / style)

Εάν δεν παρασχεθεί το `scenario`, η AI θα το κρίνει αυτόματα (ισοδύναμο με `auto`); εάν θέλετε να καθορίσετε το βίντεο σε έναν συγκεκριμένο τύπο, παρακαλώ παραδώστε το ρητά. Για παράδειγμα, για να δημιουργήσετε ένα **κατακόρυφο σύντομο δράμα**, μπορείτε να καθορίσετε τα εξής:

- `scenario`：Τύπος βίντεο, εδώ ορίζεται ως `drama` (σύντομο δράμα με χαρακτήρες + διαλόγους).
- `style`：Οπτικό στυλ, εδώ ορίζεται ως `cinematic` (κινηματογραφική αίσθηση).

Ο κωδικός CURL του παραδείγματος είναι ως εξής:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Δύο συγκάτοικοι τσακώνονται και ξανασμίγουν λόγω μιας γάτας, τρεις ανατροπές, το τέλος είναι ζεστό",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Συνηθισμένοι συνδυασμοί:

- Σύντομο βίντεο αφήγησης: `scenario: "narrated"`, υποστηρίζεται από Lite / Standard / Pro.
- Αυτόματοι υπότιτλοι: `scenario: "captions"`, απαιτεί `file_urls` για την πηγή βίντεο, υποστηρίζεται από Lite / Standard / Pro.
- Ψηφιακός άνθρωπος / αφήγηση: `scenario: "avatar"`, απαιτεί `file_urls` για μια εικόνα προσώπου, υποστηρίζεται από Standard / Pro.
- Σύντομο δράμα: `scenario: "drama"` (χαρακτήρες + διάλογοι), υποστηρίζεται μόνο από Pro.
- `style` είναι προεπιλεγμένο οπτικό στυλ (όπως `modern` / `neon` / `luxury`), δεν αλλάζει τον τύπο, επηρεάζει μόνο την οπτική εμπειρία.
- `voice` χρησιμοποιείται για να καθορίσει τον τόνο της αφήγησης (όπως `warm-female` / `deep-male`), δεν σχετίζεται με τη γλώσσα, είναι διαπολιτισμικό.

Η επιστροφή αποτελεσμάτων είναι ίδια με την «Βασική χρήση», επιστρέφει επίσης άμεσα το `task_id`.

## Πολυγλωσσική έξοδος

Στο `langs` μπορείτε να παραδώσετε πολλές γλώσσες για να παραχθούν ταυτόχρονα πολυγλωσσικές εκδόσεις. Η πρώτη είναι η κύρια γλώσσα, και κάθε επιπλέον γλώσσα θα **χρησιμοποιήσει την ίδια σειρά εικόνων**, μόνο με επιπλέον φωνητική απόδοση + απόδοση, επομένως **κάθε επιπλέον γλώσσα προσθέτει μόνο +6 πόντους**. Παράδειγμα:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Παρουσιάστε το προϊόν έξυπνης εξυπηρέτησης πελατών μας, τονίζοντας 3 βασικά σημεία",
  "langs": ["zh-cn", "en", "ja"],
  "aspect": "16:9",
  "duration": 30
}'
```

Αφού ολοκληρωθεί η εργασία, κάθε γλώσσα θα αντιστοιχεί σε ένα `variant` στα αποτελέσματα (βλ. [Maestro API ερωτήσεων εργασιών](/el/guides/maestro/maestro_tasks)).

## Επανάληψη σε υπάρχον βίντεο (remix / edit / extend)

Παραδώστε το `action` και το `ref_task_id` της τελευταίας εργασίας, για να κάνετε διαφοροποιημένες τροποποιήσεις στη βάση του αρχικού έργου (όπως «αλλάξτε τον τίτλο της 2ης σκηνής», «αλλάξτε τη φωνή», «γενικά σκοτεινότερο»). Μικρές αλλαγές γίνονται γρήγορα, μεγάλες αλλαγές θα απαιτήσουν επαναδημιουργία:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "Αλλάξτε τον τίτλο της αρχής σε μια πιο εντυπωσιακή φράση, γενικά πιο σκούρα χρώματα"
}'
```

- `remix`：Επαναλαμβάνει τη δομή του αρχικού βίντεο (διατηρεί το θέμα, προσαρμόζει την παρουσίαση).
- `edit`：Κάνει λεπτομερείς διορθώσεις σε συγκεκριμένα μέρη (όπως αλλαγή τίτλου, αλλαγή φωνής, ρύθμιση χρωμάτων).
- `extend`：Επεκτείνει το περιεχόμενο με βάση το αρχικό βίντεο.

Η επιστροφή αποτελεσμάτων είναι επίσης άμεσα με ένα νέο `task_id`, το οποίο μπορείτε να χρησιμοποιήσετε για να ερωτηθείτε για το τελικό προϊόν.

## Λήψη αποτελεσμάτων

Δεδομένου ότι η παραγωγή βίντεο απαιτεί αρκετό χρόνο, αυτή η διεπαφή επιστρέφει άμεσα το `task_id` μετά την υποβολή, χρειάζεται να το χρησιμοποιήσετε για να ερωτηθείτε το αποτέλεσμα μέσω του [Maestro API ερωτήσεων εργασιών](/el/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Όταν ολοκληρωθεί η εργασία, θα επιστραφούν οι πληροφορίες του τελικού προϊόντος (κάθε γλώσσα αντιστοιχεί σε ένα `variant`). Η `status` θα περάσει από `pending → planning → producing → succeeded` (ή `failed`), **η ερώτηση είναι δωρεάν, δεν καταναλώνει πόντους**. Για την πλήρη μορφή απόκρισης και την αναζήτηση ιστορικών λιστών, παρακαλώ ανατρέξτε στις [Οδηγίες σύνδεσης του Maestro API ερωτήσεων εργασιών](/el/guides/maestro/maestro_tasks).

## Χρέωση

**Η χρέωση γίνεται μετά την ολοκλήρωση της εργασίας με βάση το πραγματικό παραδοθέν προϊόν, οι αποτυχημένες εργασίες δεν χρεώνονται.** Η χρέωση βασίζεται στη διάρκεια του παραδοθέντος προϊόντος και τον αριθμό γλωσσών, και η διάρκεια χρέωσης δεν θα υπερβαίνει τη διάρκεια της αίτησης. Εάν μια γλώσσα δεν παραχθεί τελικά, δεν θα χρεωθεί η επιπλέον χρέωση των +6 πόντων για αυτή τη γλώσσα. Η υποβολή της εργασίας δεν χρεώνεται ξεχωριστά, η ερώτηση `/maestro/tasks` είναι δωρεάν.

Οι πόντοι για ένα παραδοθέν προϊόν υπολογίζονται ως εξής:

```
πόντοι = διάρκεια παραδοθέντος προϊόντος σε δευτερόλεπτα × 0.60 × πολλαπλασιαστής σκηνής + 6 × max(αριθμός γλωσσών − 1, 0)
```

Η Maestro χρεώνει **0.60 πόντους/πραγματικά δευτερόλεπτα παραδοθέντος προϊόντος**, υποστηρίζει 5–300 δευτερόλεπτα, έως 4 γλώσσες και 1080p / 30fps έξοδο; Όλες οι ενέργειες και οι σκηνές είναι διαθέσιμες.

Πολλαπλασιαστής σκηνής: `drama` 1.35× / `avatar` 1.15× / άλλες 1×.

| Παράδειγμα                  |  Πόντοι |
| ------------------- | --: |
| Lite 30 δευτερόλεπτα           |   6 |
| Standard 30 δευτερόλεπτα       |  18 |
| Standard 60 δευτερόλεπτα       |  36 |
| Standard 120 δευτερόλεπτα      |  72 |
| Pro 30 δευτερόλεπτα            |  36 |
| Pro 300 δευτερόλεπτα           | 360 |
| Κάθε επιπλέον γλώσσα που παραδίδεται          |  +6 |
| Ερώτηση `/maestro/tasks` |  Δωρεάν |

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 invalid_request`：Κακή αίτηση, πιθανώς λόγω ελλείποντος `prompt` ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλείπον διαπιστευτήριο εξουσιοδότησης.
- `403 forbidden`：Απαγορευμένο, ανεπαρκές υπόλοιπο ή πρόσβαση.
- `429 too_many_requests`：Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα απόκρισης σφάλματος
```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "η λήψη απέτυχε"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Συμπέρασμα

Μέσω αυτού του εγγράφου, έχετε κατανοήσει πώς να χρησιμοποιήσετε το API δημιουργίας βίντεο Maestro: απλά με μία φυσική γλώσσα `prompt`, μπορείτε να ολοκληρώσετε αυτόματα το σενάριο, το υλικό, τη φωνητική αφήγηση, τη μουσική, το μοντάζ, τους υπότιτλους και την απόδοση του τελικού βίντεο, υποστηρίζοντας επίσης τον καθορισμό τύπου βίντεο, στυλ, τόνο, πολυγλωσσική έξοδο και επανάληψη σε υπάρχον βίντεο. Ελπίζουμε αυτό το έγγραφο να σας βοηθήσει να συνδεθείτε και να χρησιμοποιήσετε καλύτερα αυτό το API. Εάν έχετε οποιαδήποτε ερώτηση, παρακαλούμε επικοινωνήστε με την τεχνική μας υποστήριξη.

## Σχετικά API

- [Οδηγίες σύνδεσης API ερωτήσεων εργασιών Maestro](/el/guides/maestro/maestro_tasks): χρησιμοποιήστε το `POST /maestro/videos` για να επιστρέψετε το `task_id` και να ελέγξετε την κατάσταση και τα αποτελέσματα της εργασίας, ή να ανακτήσετε τη λίστα ιστορικών εργασιών (polling δωρεάν).
