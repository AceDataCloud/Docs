Το Maestro είναι μια διεπαφή παραγωγής βίντεο **εγγενής για Agent**: χρησιμοποιείτε ένα `prompt` φυσικής γλώσσας για να περιγράψετε το βίντεο που θέλετε (προαιρετικά επισυνάπτετε εικόνες / βίντεο / ήχο αναφοράς με `file_urls`), και ένας ακέφαλος «AI σκηνοθέτης» ολοκληρώνει αυτόματα την επιλογή θέματος, τη συγγραφή σεναρίου, τη δημιουργία εικόνων, την αφήγηση, τη μουσική επένδυση, τη σύνθεση και την απόδοση, παράγοντας τελικά ένα ολοκληρωμένο βίντεο με υπότιτλους και ανεβάζοντάς το σε CDN.

Αυτό το έγγραφο θα παρουσιάσει λεπτομερώς τις οδηγίες ενσωμάτωσης του API δημιουργίας βίντεο Maestro, βοηθώντας σας να το ενσωματώσετε γρήγορα και να αξιοποιήσετε πλήρως τις δυνατότητες του API.

Αυτό είναι ένα API **ασύγχρονων εργασιών**: μετά την υποβολή επιστρέφεται αμέσως ένα `task_id`, και στη συνέχεια λαμβάνετε το αποτέλεσμα μέσω polling με το [API ερωτήματος εργασιών Maestro](/el/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (το polling είναι δωρεάν και δεν χρεώνεται). Για να συνεχίσετε την επανάληψη πάνω σε υπάρχον βίντεο, μπορείτε να χρησιμοποιήσετε `action: remix` / `edit` / `extend` σε συνδυασμό με `ref_task_id`.

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το API δημιουργίας βίντεο Maestro, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να λάβετε το API Token σας και κρατήστε το διαθέσιμο για χρήση.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Αν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token αρκεί για την κλήση όλων των υπηρεσιών της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Με την πρώτη αίτηση παρέχεται δωρεάν πίστωση για δωρεάν δοκιμή· όταν η πίστωση δεν επαρκεί, μπορείτε να φορτίσετε το γενικό υπόλοιπο από την [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [API δημιουργίας βίντεο Maestro →](https://platform.acedata.cloud/documents/maestro-videos)

## Βασική χρήση

`POST https://api.acedata.cloud/maestro/videos`

Η πιο βασική χρήση απαιτεί μόνο την εισαγωγή ενός `prompt` φυσικής γλώσσας, και ο AI σκηνοθέτης θα αποφασίσει αυτόματα το σενάριο, την εικόνα, την αφήγηση και το μοντάζ. Εδώ ας δούμε πρώτα τις κεφαλίδες αιτήματος και το σώμα αιτήματος που πρέπει να οριστούν.

Τα **Request Headers** περιλαμβάνουν:

- `accept`: τη μορφή στην οποία θέλετε να λάβετε το αποτέλεσμα απόκρισης· εδώ συμπληρώνεται ως `application/json`, δηλαδή μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από την αναπτυσσόμενη λίστα μετά την αίτηση.
- `content-type`: τη μορφή του σώματος αιτήματος, που εδώ συμπληρώνεται ως `application/json`.

Το **Request Body** περιλαμβάνει κυρίως:

- `prompt`: περιγράψτε με φυσική γλώσσα το βίντεο που θέλετε να δημιουργήσετε (θέμα, τι θέλετε να παρουσιαστεί, στυλ, κοινό).
- `langs`: πίνακας γλωσσών του τελικού βίντεο, μεταδίδεται μόνο μία γλώσσα κάθε φορά, όπως `["zh-cn"]`, προεπιλογή `["zh-cn"]`.
- `aspect`: αναλογία εικόνας, `9:16` (προεπιλογή) / `16:9` / `1:1`.
- `duration`: επιθυμητή διάρκεια (δευτερόλεπτα), προεπιλογή 30.

Όλα τα πεδία του σώματος αιτήματος παρουσιάζονται στον παρακάτω πίνακα:

| Πεδίο            | Τύπος       | Υποχρεωτικό  | Περιγραφή                                                                                                                                                                                                                                    |
| ------------- | -------- | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Ναι   | Περιγράψτε με φυσική γλώσσα το βίντεο που θέλετε να δημιουργήσετε (θέμα, τι θέλετε να παρουσιαστεί, στυλ, κοινό). Το σενάριο, η εικόνα, η αφήγηση και το μοντάζ αποφασίζονται όλα από το AI                                                                                                                                                                                      |
| `action`      | string   | Όχι   | `generate` (προεπιλογή, δημιουργία νέου βίντεο) / `remix` / `edit` / `extend` (επανάληψη πάνω σε υπάρχον βίντεο, απαιτεί συνδυασμό με `ref_task_id`)                                                                                                                                                         |
| `ref_task_id` | string   | Όχι   | Υποχρεωτικό όταν το `action` είναι remix / edit / extend: το ιστορικό `task_id` που χρησιμοποιείται ως αφετηρία                                                                                                                                                                            |
| `file_urls`   | string[] | Όχι   | Μέσα αναφοράς (URL εικόνων / βίντεο / ήχου), για παράδειγμα εικόνα προϊόντος ή logo που πρέπει να εμφανιστεί, ή απόσπασμα υλικού στο οποίο πρέπει να προστεθούν υπότιτλοι                                                                                                                                                                                      |
| `langs`       | string[] | Όχι   | Γλώσσα τελικού βίντεο, μπορεί να μεταδοθεί μόνο μία γλώσσα κάθε φορά, όπως `["zh-cn"]`, προεπιλογή `["zh-cn"]`                                                                                                                                                                                             |
| `aspect`      | string   | Όχι   | `9:16` (προεπιλογή) / `16:9` / `1:1`, ενιαία έξοδος 1080p/30fps                                                                                                                                                                                           |
| `duration`    | int      | Όχι   | Επιθυμητή διάρκεια (δευτερόλεπτα), προεπιλογή 30, υποστηρίζει **5–300 δευτερόλεπτα**. Η χρέωση γίνεται βάσει της πραγματικής διάρκειας του τελικού βίντεο, αλλά δεν θα υπερβαίνει τη διάρκεια που ζητήθηκε                                                                                                                                                                                      |
| `scenario`    | string   | Όχι   | Τύπος βίντεο: `auto` / `narrated` / `captions` / `avatar` / `drama`. Το `captions` απαιτεί μετάδοση του βίντεο πηγής, ενώ το `avatar` απαιτεί μετάδοση πορτρέτου                                                                                                                                             |
| `style`       | string   | Όχι   | Προεπιλογές οπτικού στυλ: `auto` (προεπιλογή) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`, ενώ δέχεται επίσης ελεύθερο κείμενο ως ήπια υπόδειξη. Είναι ορθογώνιο προς το `scenario` και δεν αλλάζει τη δρομολόγηση          |
| `voice`       | string   | Όχι   | Χροιά αφήγησης (ανεξάρτητη από τη γλώσσα, καθολική μεταξύ γλωσσών): `auto` (προεπιλογή) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`· υποστηρίζει επίσης 32ψήφιο δεκαεξαδικό `reference_id` χροιάς, ενώ άλλο ελεύθερο κείμενο δεν είναι έγκυρο ID χροιάς |

Παρακάτω θα το παρουσιάσουμε με ένα συγκεκριμένο παράδειγμα. Ας υποθέσουμε ότι θέλουμε να δημιουργήσουμε ένα κινεζικό, κάθετο, επιστημονικό σύντομο βίντεο 20 δευτερολέπτων· ο αντίστοιχος κώδικας CURL είναι ο εξής:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

Ο αντίστοιχος κώδικας Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Κάντε κλικ στην εκτέλεση και θα διαπιστώσετε ότι λαμβάνετε αμέσως ένα αποτέλεσμα, ως εξής:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Η εισαγωγή των πεδίων του αποτελέσματος επιστροφής είναι η εξής:
- `success`：αν η συγκεκριμένη εργασία υποβλήθηκε επιτυχώς.
- `task_id`：το ID της συγκεκριμένης εργασίας δημιουργίας βίντεο, χρησιμοποιήστε το αργότερα στο [API ερωτήματος εργασιών Maestro](/el/guides/maestro/maestro_tasks) για να ελέγχετε περιοδικά το αποτέλεσμα.
- `trace_id`：το ID ιχνηλάτησης του συγκεκριμένου αιτήματος, το οποίο μπορείτε να παρέχετε στην τεχνική υποστήριξη για εντοπισμό σε περίπτωση προβλήματος.

Επειδή η παραγωγή βίντεο απαιτεί αρκετό χρόνο, η διεπαφή **επιστρέφει αμέσως το `task_id`** εδώ και δεν περιμένει να ολοκληρωθεί η απόδοση του βίντεο. Στη συνέχεια, πρέπει να χρησιμοποιήσετε το `task_id` για να ελέγχετε περιοδικά το αποτέλεσμα· δείτε λεπτομέρειες στην ενότητα «Λήψη αποτελεσμάτων».

## Καθορισμός τύπου και στυλ βίντεο (scenario / style)

Όταν δεν μεταβιβάζεται το `scenario`, καθορίζεται αυτόματα από το AI (ισοδυναμεί με `auto`)· αν θέλετε να ορίσετε το βίντεο σε συγκεκριμένο τύπο, μεταβιβάστε το ρητά. Για παράδειγμα, για τη δημιουργία μιας **κάθετης σύντομης δραματικής ταινίας**, μπορείτε να καθορίσετε τα εξής:

- `scenario`：τύπος βίντεο, ορίστε εδώ σε `drama` (σύντομη δραματική ταινία με χαρακτήρες + διαλόγους).
- `style`：οπτικό στυλ, ορίστε εδώ σε `cinematic` (κινηματογραφική αίσθηση).

Το CURL παράδειγμα συμπλήρωσης είναι το εξής:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Συνήθεις τρόποι συνδυασμού:

- Σύντομο βίντεο αφήγησης: `scenario: "narrated"`.
- Αυτόματοι υπότιτλοι: `scenario: "captions"`, απαιτείται η μεταβίβαση του πηγαίου βίντεο μέσω `file_urls`.
- Ψηφιακό avatar / προφορική παρουσίαση: `scenario: "avatar"`, απαιτείται η μεταβίβαση μιας εικόνας προσώπου μέσω `file_urls`.
- Σύντομη δραματική ταινία: `scenario: "drama"` (χαρακτήρες + διάλογοι).
- Το `style` είναι προεπιλογή οπτικού στυλ (όπως `modern` / `neon` / `luxury`), δεν αλλάζει τον τύπο και επηρεάζει μόνο την εμφάνιση.
- Το `voice` χρησιμοποιείται για τον καθορισμό της χροιάς της αφήγησης (όπως `warm-female` / `deep-male`), είναι ανεξάρτητο από τη γλώσσα και εφαρμόζεται σε όλες τις γλώσσες.

Το αποτέλεσμα επιστροφής είναι ίδιο με τη «Βασική χρήση», και επίσης επιστρέφει αμέσως το `task_id`.

## Γλώσσα τελικού βίντεο

Μία εργασία παραδίδει μόνο ένα τελικό βίντεο σε μία γλώσσα. Το `langs` μπορεί να περιέχει μόνο έναν κωδικό γλώσσας, όπως `["zh-cn"]` ή `["en"]`· η μεταβίβαση πολλών γλωσσών θα επιστρέψει 400. Αν χρειάζεστε βίντεο σε διαφορετικές γλώσσες, δημιουργήστε ξεχωριστές εργασίες. Η επιλογή γλώσσας δεν αλλάζει την τιμή ανά δευτερόλεπτο.

## Επανάληψη σε υπάρχον βίντεο (remix / edit / extend)

Μεταβιβάστε το `action` και το `ref_task_id` της προηγούμενης εργασίας για να κάνετε σταδιακές τροποποιήσεις βάσει του αρχικού έργου (όπως «αλλάξτε τον τίτλο της 2ης σκηνής», «αλλάξτε την αφήγηση», «κάντε το συνολικά πιο σκοτεινό»). Οι μικρές αλλαγές είναι γρήγορες, ενώ οι μεγάλες αλλαγές θα απαιτήσουν επαναδημιουργία:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`：νέα απόδοση βάσει της αρχικής δομής βίντεο (διατηρεί το θέμα, προσαρμόζει την παρουσίαση).
- `edit`：λεπτομερής επεξεργασία συγκεκριμένου τμήματος (όπως αλλαγή τίτλου, αλλαγή αφήγησης, χρωματική διόρθωση).
- `extend`：επέκταση περιεχομένου βάσει του αρχικού βίντεο.

Το αποτέλεσμα επιστροφής είναι επίσης η άμεση επιστροφή ενός νέου `task_id`, το οποίο μπορείτε να χρησιμοποιήσετε για περιοδικό έλεγχο και λήψη του τελικού βίντεο μετά την επανάληψη.

## Λήψη αποτελεσμάτων

Επειδή η παραγωγή βίντεο απαιτεί αρκετό χρόνο, αυτή η διεπαφή επιστρέφει αμέσως το `task_id` μετά την υποβολή· πρέπει να το χρησιμοποιήσετε στο [API ερωτήματος εργασιών Maestro](/el/guides/maestro/maestro_tasks) για να ελέγχετε περιοδικά το αποτέλεσμα:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Όταν ολοκληρωθεί η εργασία, επιστρέφονται πληροφορίες για ένα τελικό βίντεο (βρίσκονται στον πίνακα `variants`). Το `status` θα περάσει από `pending → planning → producing → succeeded` (ή `failed`), **ο περιοδικός έλεγχος είναι δωρεάν και δεν καταναλώνει μονάδες**. Για την πλήρη μορφή απόκρισης και το ερώτημα λίστας ιστορικού, ανατρέξτε στις [Οδηγίες ενσωμάτωσης API ερωτήματος εργασιών Maestro](/el/guides/maestro/maestro_tasks).

## Χρέωση

**Μετά την επιτυχή ολοκλήρωση της εργασίας, η χρέωση γίνεται βάσει της πραγματικής διάρκειας του παραδοθέντος τελικού βίντεο· δεν υπάρχει χρέωση σε περίπτωση αποτυχίας.** Η χρεώσιμη διάρκεια υπολογίζεται σε ακέραια δευτερόλεπτα και δεν υπερβαίνει τη ζητούμενη διάρκεια· όταν δεν είναι δυνατή η ανάγνωση της διάρκειας του τελικού βίντεο, χρησιμοποιείται ως εναλλακτική η ζητούμενη διάρκεια. Η υποβολή εργασίας αυτή καθαυτή δεν χρεώνεται ξεχωριστά και ο περιοδικός έλεγχος στο `/maestro/tasks` είναι δωρεάν.

```
Μονάδες = πραγματικά χρεώσιμα δευτερόλεπτα × 0.7
```

Όλα τα σενάρια, οι ενέργειες και οι γλώσσες χρησιμοποιούν την ίδια τιμή, χωρίς πολλαπλασιαστή σεναρίου ή επιπλέον χρέωση γλώσσας. Κάθε εργασία παραδίδει μόνο ένα τελικό βίντεο σε μία γλώσσα. Η ζητούμενη διάρκεια υποστηρίζει 5–300 δευτερόλεπτα, με ενιαία έξοδο 1080p / 30fps.

| Πραγματική χρεώσιμη διάρκεια              |  Μονάδες |
| ------------------- | --: |
| 30 δευτερόλεπτα                |  21 |
| 60 δευτερόλεπτα                |  42 |
| 120 δευτερόλεπτα               |  84 |
| 300 δευτερόλεπτα               | 210 |
| Περιοδικός έλεγχος `/maestro/tasks` |  Δωρεάν |

## Διαχείριση σφαλμάτων

Κατά την κλήση του API, αν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό και μήνυμα σφάλματος. Για παράδειγμα:

- `400 invalid_request`：Εσφαλμένο αίτημα, πιθανώς λόγω ελλιπούς `prompt` ή μη έγκυρων παραμέτρων.
- `401 invalid_token`：Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό εξουσιοδότησης.
- `403 forbidden`：Απαγορεύεται, ανεπαρκές υπόλοιπο ή πρόσβαση.
- `429 too_many_requests`：Πάρα πολλά αιτήματα, έχετε υπερβεί το όριο συχνότητας.
- `500 api_error`：Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.

### Παράδειγμα απόκρισης σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Συμπέρασμα

Μέσω αυτού του εγγράφου, έχετε ήδη κατανοήσει πώς να χρησιμοποιείτε το API δημιουργίας βίντεο Maestro: με μόνο ένα `prompt` σε φυσική γλώσσα, μπορείτε να ολοκληρώσετε αυτόματα το σενάριο, τα υλικά, την αφήγηση, τη μουσική επένδυση, το μοντάζ, τους υπότιτλους και την απόδοση του τελικού βίντεο, ενώ υποστηρίζεται ο καθορισμός τύπου βίντεο, στυλ, χροιάς, γλώσσας τελικού βίντεο και επανάληψης σε υπάρχον βίντεο. Ελπίζουμε ότι αυτό το έγγραφο θα σας βοηθήσει να ενσωματώσετε και να χρησιμοποιήσετε καλύτερα αυτό το API. Αν έχετε οποιεσδήποτε ερωτήσεις, επικοινωνήστε ανά πάσα στιγμή με την ομάδα τεχνικής υποστήριξής μας.
