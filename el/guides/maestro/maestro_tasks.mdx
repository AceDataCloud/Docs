Η κύρια λειτουργία του API ερωτήματος εργασιών Maestro είναι να χρησιμοποιεί το ID εργασίας που επιστρέφεται από το [API δημιουργίας βίντεο Maestro](/el/guides/maestro/maestro_videos) (`POST /maestro/videos`) για να ερωτά την κατάσταση εκτέλεσης και το τελικό αποτέλεσμα της εργασίας.

Αυτό το έγγραφο θα παρουσιάσει λεπτομερώς τις οδηγίες ενσωμάτωσης του API ερωτήματος εργασιών Maestro. Επειδή η δημιουργία βίντεο είναι μια ασύγχρονη εργασία, μετά την υποβολή χρειάζεται να χρησιμοποιήσετε αυτό το endpoint για περιοδικό έλεγχο της προόδου και του τελικού βίντεο, **ο περιοδικός έλεγχος είναι δωρεάν και δεν καταναλώνει μονάδες.**

`POST https://api.acedata.cloud/maestro/tasks`

## Διαδικασία αίτησης

Για να χρησιμοποιήσετε το API ερωτήματος εργασιών Maestro, μεταβείτε πρώτα στην [κονσόλα Ace Data Cloud](https://platform.acedata.cloud/console/applications) για να αποκτήσετε το API Token σας και κρατήστε το για χρήση αργότερα.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Εάν δεν έχετε ακόμη συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε, και μετά την ολοκλήρωση θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

**Ένα API Token μπορεί να καλέσει όλες τις υπηρεσίες της πλατφόρμας, χωρίς να χρειάζεται ξεχωριστή αίτηση για κάθε υπηρεσία.** Η πρώτη αίτηση παρέχει δωρεάν υπόλοιπο για δωρεάν δοκιμή· όταν το υπόλοιπο δεν επαρκεί, μπορείτε να επαναφορτίσετε το γενικό υπόλοιπο στην [κονσόλα](https://platform.acedata.cloud/console/coin).

> 📘 Πλήρης τεκμηρίωση: [API ερωτήματος εργασιών Maestro →](https://platform.acedata.cloud/documents/maestro-tasks)

## Ερώτημα μίας εργασίας

Για τον τρόπο δημιουργίας μιας εργασίας βίντεο, ανατρέξτε στην τεκμηρίωση [API δημιουργίας βίντεο Maestro](/el/guides/maestro/maestro_videos). Χρησιμοποιούμε ως παράδειγμα ένα ID εργασίας που επιστρέφει: `f57e99c4f60f4373a15517742ce2357d`, για να δείξουμε πώς να ερωτήσετε την κατάσταση και το αποτέλεσμά του.

### Ορισμός κεφαλίδων και σώματος αιτήματος

Οι **Κεφαλίδες Αιτήματος** περιλαμβάνουν:

- `accept`: καθορίζει ότι λαμβάνονται αποτελέσματα απόκρισης σε μορφή JSON, εδώ συμπληρώνεται ως `application/json`.
- `authorization`: το κλειδί για την κλήση του API, μετά την αίτηση μπορείτε να το επιλέξετε απευθείας από την αναπτυσσόμενη λίστα.
- `content-type`: η μορφή του σώματος αιτήματος, εδώ συμπληρώνεται ως `application/json`.

Το **Σώμα Αιτήματος** περιλαμβάνει:

| Πεδίο       | Τύπος     | Υποχρεωτικό κατά την ερώτηση μίας εργασίας | Περιγραφή                                                |
| -------- | ------ | --------- | ------------------------------------------------- |
| `id`     | string | Ναι | Το `task_id` που επιστρέφεται από το `POST /maestro/videos`              |
| `action` | string | Όχι         | `retrieve` (προεπιλογή, ερώτημα μίας εργασίας)· κατά την ερώτηση ιστορικού λίστας ορίζεται σταθερά σε `retrieve_batch` |

### Παράδειγμα κώδικα

Ο αντίστοιχος κώδικας CURL είναι ο εξής:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d",
  "action": "retrieve"
}'
```

Ο αντίστοιχος κώδικας Python είναι ο εξής:

```python
import requests

url = "https://api.acedata.cloud/maestro/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "f57e99c4f60f4373a15517742ce2357d",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Παράδειγμα απόκρισης

Μετά από επιτυχημένο αίτημα, το API θα επιστρέψει την κατάσταση και το αποτέλεσμα αυτής της εργασίας βίντεο. Το παράδειγμα απόκρισης όταν ολοκληρωθεί η εργασία είναι το εξής (κάθε γλώσσα αντιστοιχεί σε ένα `variant`):

```json
{
  "id": "f57e99c4f60f4373a15517742ce2357d",
  "started_at": 1769262721.823,
  "finished_at": 1769264698.3,
  "elapsed": 1976.477,
  "status": "succeeded",
  "progress": {
    "percent": 100,
    "stage": "producing",
    "message": "rendering scene 2"
  },
  "request": {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": [
      "zh-cn",
      "en"
    ],
    "aspect": "9:16",
    "duration": 20
  },
  "response": {
    "success": true,
    "data": {
      "variants": [
        {
          "lang": "zh-cn",
          "aspect": "9:16",
          "kind": "video",
          "title": "什么是向量数据库",
          "output_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4?example=video-001"
        },
        {
          "lang": "en",
          "aspect": "9:16",
          "kind": "video",
          "title": "What is a vector database",
          "output_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4?example=video-002"
        }
      ],
      "project": {
        "tarball_url": null,
        "outputs": [
          "https://…/zh.mp4",
          "https://…/en.mp4"
        ]
      },
      "percent": 100,
      "stage": "producing",
      "progress": [
        {
          "stage": "producing",
          "message": "rendering scene 2",
          "pct": 60,
          "t": 1750000000
        }
      ]
    }
  }
}
```

Η περιγραφή των πεδίων του αποτελέσματος επιστροφής είναι η εξής:

- `id`: το ID αυτής της εργασίας βίντεο, χρησιμοποιείται για τη μοναδική αναγνώριση αυτής της εργασίας δημιουργίας βίντεο.
- `status`: η κατάσταση της εργασίας, οι τιμές είναι `pending → planning → producing → succeeded` (ή `failed`). Το αν η εργασία έχει ολοκληρωθεί καθορίζεται από αυτό το ανώτατου επιπέδου `status`.
- `elapsed`: ο χρόνος που έχει ήδη διαρκέσει η εργασία (δευτερόλεπτα).
- `progress`: αντικείμενο προόδου ανώτατου επιπέδου, το `percent` (0–100) ορίζεται εφεδρικά σε 100 μετά την επιτυχία της εργασίας· τα `stage` και `message` αντικατοπτρίζουν το πιο πρόσφατο συμβάν προόδου του AI σκηνοθέτη (επομένως μετά την επιτυχία το `stage` μπορεί να παραμένει το τελευταίο στάδιο εκτέλεσης, όπως `producing`), και μπορούν να χρησιμοποιηθούν απευθείας για την εμφάνιση της γραμμής προόδου.
- `request`: το σώμα αιτήματος κατά την έναρξη της εργασίας.
- `response`: οι πληροφορίες απόκρισης της εργασίας.
  - `success`: αν η εργασία ήταν επιτυχής.
  - `data.variants`: κάθε γλώσσα αντιστοιχεί σε ένα αντικείμενο τελικού βίντεο, που περιλαμβάνει `lang`, `aspect`, `title`, `output_url` (διεύθυνση λήψης τελικού βίντεο) κ.λπ.
  - `data.project`: το αποτέλεσμα ολόκληρου του έργου, που περιλαμβάνει `tarball_url` (πακέτο έργου) και `outputs` (όλους τους συνδέσμους τελικών βίντεο).
  - `data.progress`: πίνακας συμβάντων προόδου που προστίθενται ανά στάδιο (append-only log), μπορεί να χρησιμοποιηθεί για την εμφάνιση λεπτομερούς προόδου σε πραγματικό χρόνο.
- `created_at`: ο χρόνος δημιουργίας της εργασίας, χρονική σήμανση Unix (δευτερόλεπτα).
- `started_at`: ο χρόνος έναρξης εκτέλεσης της εργασίας, χρονική σήμανση Unix (δευτερόλεπτα). Είναι null όταν η εργασία δεν έχει ακόμη ξεκινήσει.
- `finished_at`: ο χρόνος ολοκλήρωσης της εργασίας, χρονική σήμανση Unix (δευτερόλεπτα). Είναι null όταν η εργασία δεν έχει ολοκληρωθεί.

## Ερώτημα ιστορικού λίστας

Περάστε `action: retrieve_batch` για να λάβετε τις πρόσφατες εργασίες του τρέχοντος συνδεδεμένου εκτελεστή (σε φθίνουσα σειρά χρόνου δημιουργίας), και μπορεί να χρησιμοποιηθεί για τη σελίδα λίστας «Τα βίντεό μου». Η λίστα ιστορικού είναι απομονωμένη ανά ταυτότητα σύνδεσης.

Το **Σώμα Αιτήματος** περιλαμβάνει:
| Πεδίο               | Τύπος     | Υποχρεωτικό  | Περιγραφή                              |
| ---------------- | ------ | --- | ------------------------------- |
| `action`         | string | Ναι   | Σταθερά ορίζεται ως `retrieve_batch`            |
| `limit`          | int    | Όχι   | Αριθμός επιστρεφόμενων εγγραφών, προεπιλογή 20· το έγκυρο εύρος είναι 1–100          |
| `created_at_max` | int    | Όχι   | Επιστρέφει μόνο εργασίες αυστηρά προγενέστερες από αυτήν τη χρονοσήμανση Unix (χωρίς την οριακή τιμή, για σελιδοποίηση) |
| `created_at_min` | int    | Όχι   | Επιστρέφει μόνο εργασίες αυστηρά μεταγενέστερες από αυτήν τη χρονοσήμανση Unix (χωρίς την οριακή τιμή)     |

### Παράδειγμα κώδικα

Ο αντίστοιχος κώδικας CURL είναι ο εξής:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "retrieve_batch",
  "limit": 20
}'
```

### Παράδειγμα απόκρισης

Αφού το αίτημα ολοκληρωθεί με επιτυχία, το API θα επιστρέψει τη λίστα ιστορικών εργασιών του τρέχοντος χρήστη:

```json
{
  "count": 2,
  "items": [
    {
      "id": "f57e99c4f60f4373a15517742ce2357d",
      "started_at": 1769262721.823,
      "finished_at": 1769264698.3,
      "elapsed": 1976.477,
      "status": "succeeded",
      "progress": {
        "percent": 100,
        "stage": "producing",
        "message": "rendering scene 2"
      },
      "request": {
        "prompt": "…",
        "langs": [
          "zh-cn",
          "en"
        ],
        "aspect": "9:16",
        "duration": 20
      },
      "response": {
        "success": true,
        "data": {
          "variants": [
            {
              "lang": "zh-cn",
              "output_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4?example=video-003"
            }
          ]
        }
      }
    }
  ]
}
```

Η περιγραφή των πεδίων των επιστρεφόμενων αποτελεσμάτων είναι η εξής:

- `count`: Ο συνολικός αριθμός εργασιών που είναι ορατές στον τρέχοντα συνδεδεμένο εκτελεστή, ανεξάρτητα από τις χρονικές συνθήκες ή το `limit`.
- `items`: Ο πίνακας εργασιών που έχουν φιλτραριστεί βάσει των χρονικών συνθηκών και του `limit`, ταξινομημένος κατά φθίνουσα σειρά χρόνου δημιουργίας· η μορφή κάθε στοιχείου είναι ίδια με το επιστρεφόμενο αποτέλεσμα της «Ερώτησης μίας μεμονωμένης εργασίας».

## Προτάσεις για polling

Επειδή η παραγωγή βίντεο απαιτεί αρκετό χρόνο, το `status` θα περάσει από `pending → planning → producing → succeeded` (ή `failed`). Συνιστάται polling κάθε 5–10 δευτερόλεπτα, μέχρι το `status` να γίνει `succeeded` ή `failed`. Μπορείτε να χρησιμοποιήσετε το ανώτατου επιπέδου `progress.percent` για να εμφανίσετε μια γραμμή προόδου σε πραγματικό χρόνο. **Το polling αυτού του API είναι δωρεάν και δεν καταναλώνει μονάδες.**

## Χειρισμός σφαλμάτων

Κατά την κλήση του API, εάν παρουσιαστεί σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό και μήνυμα σφάλματος. Για παράδειγμα:

- `401 invalid_token`: Unauthorized, invalid or missing authorization token.
- `404 not_found`: Task not found, the given task_id does not exist.
- `429 too_many_requests`: Too many requests, you have exceeded the rate limit.
- `500 api_error`: Internal server error, something went wrong on the server.

### Παράδειγμα απόκρισης σφάλματος

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
