Αυτό το έγγραφο παρουσιάζει τις οδηγίες ενσωμάτωσης του Sora Videos Generation API, μέσω του οποίου μπορείτε να εισάγετε προσαρμοσμένες παραμέτρους για να δημιουργήσετε επίσημα βίντεο Sora. Το API υποστηρίζει δύο εκδόσεις λειτουργίας:

- **Έκδοση 1 (Κλασική λειτουργία)**: Υποστηρίζει τις παραμέτρους `duration` (10/15/25 δευτερόλεπτα), `orientation` (οριζόντια/κατακόρυφη), `size` (small/large ανάλυση), αναφορικές εικόνες `image_urls`, και σύνδεσμο χαρακτήρα `character_url` κ.ά.
- **Έκδοση 2 (Λειτουργία συνεργάτη)**: Υποστηρίζει τις παραμέτρους `seconds` (4/8/12 δευτερόλεπτα), ανάλυση σε επίπεδο pixel `size` (π.χ. 1280x720), αναφορικές εικόνες `input_reference` κ.ά.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να κάνετε αίτηση στην αντίστοιχη σελίδα του [Sora Videos Generation API](https://platform.acedata.cloud/documents/99a24421-2e22-4028-8201-e19cb834b67e). Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα ανακατευθυνθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά τη σύνδεση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, παρέχεται δωρεάν όριο χρήσης για το API.

## Βασική Χρήση (Έκδοση 1)

Αρχικά, κατανοήστε τον βασικό τρόπο χρήσης της Έκδοσης 1, όπου εισάγετε το πεδίο `prompt`, έναν πίνακα με συνδέσμους αναφορικών εικόνων `image_urls` και το μοντέλο `model` για να λάβετε το επεξεργασμένο αποτέλεσμα. Αναλυτικά:

<p><img src="https://cdn.acedata.cloud/h8dyz3.png" width="500" className="m-auto" /></p>

Εδώ ορίζουμε τα Request Headers, που περιλαμβάνουν:

- `accept`: Τον τύπο της απάντησης που θέλουμε να λάβουμε, εδώ `application/json` για μορφή JSON.
- `authorization`: Το κλειδί πρόσβασης στο API, το οποίο επιλέγεται μετά την αίτηση.

Επιπλέον, ορίζουμε το Request Body, που περιλαμβάνει:

- `model`: Το μοντέλο δημιουργίας βίντεο, υποστηρίζει `sora-2` (τυπική λειτουργία) και `sora-2-pro` (υψηλή ανάλυση). Το `sora-2-pro` υποστηρίζει βίντεο διάρκειας 25 δευτερολέπτων, ενώ το `sora-2` μόνο 10 ή 15 δευτερόλεπτα.
- `size`: Ανάλυση βίντεο, `small` για τυπική ανάλυση και `large` για HD (μόνο Έκδοση 1).
- `duration`: Διάρκεια βίντεο, υποστηρίζει 10, 15, 25 δευτερόλεπτα, όπου τα 25 δευτερόλεπτα υποστηρίζονται μόνο από το `sora-2-pro` (μόνο Έκδοση 1).
- `orientation`: Προσανατολισμός εικόνας, υποστηρίζει `landscape` (οριζόντιο) και `portrait` (κατακόρυφο) (μόνο Έκδοση 1).
- `image_urls`: Πίνακας συνδέσμων αναφορικών εικόνων για δημιουργία βίντεο από εικόνες (μόνο Έκδοση 1).
- `character_url`: Σύνδεσμος χαρακτήρα, το βίντεο δεν πρέπει να περιέχει πραγματικούς ανθρώπους (μόνο Έκδοση 1).
- `character_start`/`character_end`: Χρονικά όρια εμφάνισης χαρακτήρα σε δευτερόλεπτα, με εύρος 1-3 δευτερόλεπτα (μόνο Έκδοση 1).
- `prompt`: Λέξη-κλειδί ή φράση για το βίντεο (υποχρεωτικό).
- `callback_url`: URL για ασύγχρονη επιστροφή αποτελεσμάτων.
- `version`: Έκδοση API, `"1.0"` (προεπιλογή) ή `"2.0"`.

## Δημιουργία Βίντεο από Εικόνες (Έκδοση 1)

Για να δημιουργήσετε βίντεο από εικόνες, πρέπει να περάσετε την παράμετρο `image_urls` με έναν πίνακα συνδέσμων αναφορικών εικόνων, όπως:

- `image_urls`: Πίνακας συνδέσμων αναφορικών εικόνων για τη δημιουργία βίντεο. Προσοχή να μην περιλαμβάνονται εικόνες με πραγματικά πρόσωπα, γιατί μπορεί να αποτύχει η εργασία.

Παράδειγμα συμπλήρωσης:

<p><img src="https://cdn.acedata.cloud/ch7x3t.png" width="500" className="m-auto" /></p>

Μετά τη συμπλήρωση, ο κώδικας δημιουργείται αυτόματα:

<p><img src="https://cdn.acedata.cloud/z1ud8l.png" width="500" className="m-auto" /></p>

Παράδειγμα κώδικα Python:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "large",
    "duration": 15,
    "orientation": "landscape",
    "prompt": "cat running on the river",
    "model": "sora-2",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Δημιουργία Βίντεο Χαρακτήρα (Έκδοση 1)

Για να δημιουργήσετε βίντεο με χαρακτήρα, πρέπει να περάσετε την παράμετρο `character_url` με σύνδεσμο βίντεο που χρησιμοποιείται για τη δημιουργία χαρακτήρα. Προσοχή, το βίντεο δεν πρέπει να περιέχει πραγματικούς ανθρώπους, αλλιώς η εργασία θα αποτύχει. Μπορείτε να ορίσετε:

- `character_url`: Σύνδεσμος βίντεο για τη δημιουργία χαρακτήρα, χωρίς πραγματικούς ανθρώπους.

Παράδειγμα συμπλήρωσης:

## Λειτουργία Έκδοσης 2.0

Εκτός από την Έκδοση 1.0, το API υποστηρίζει και την Έκδοση 2.0, η οποία ενεργοποιείται ορίζοντας την παράμετρο `version` σε `"2.0"`. Η Έκδοση 2.0 υποστηρίζει μικρότερης διάρκειας βίντεο και έλεγχο ανάλυσης σε επίπεδο pixel.

### Περιγραφή Παραμέτρων Έκδοσης 2.0

| Παράμετρος | Τύπος | Υποχρεωτική | Περιγραφή |
|------------|-------|-------------|-----------|
| `version` | string | Ναι | Ορισμός σε `"2.0"` |
| `prompt` | string | Ναι | Λέξη-κλειδί για δημιουργία βίντεο |
| `model` | string | Όχι | `sora-2` (προεπιλογή) ή `sora-2-pro` |
| `duration` | integer | Όχι | Διάρκεια βίντεο: `4` (προεπιλογή), `8`, `12` δευτερόλεπτα |
| `size` | string | Όχι | Ανάλυση: `720x1280` (προεπιλογή), `1280x720`, `1024x1792`, `1792x1024` |
| `image_urls` | array | Όχι | Πίνακας URL αναφορικών εικόνων, χρησιμοποιείται μόνο η πρώτη εικόνα, η ανάλυση της οποίας πρέπει να ταιριάζει με το `size` |
| `callback_url` | string | Όχι | URL για ασύγχρονη επιστροφή αποτελεσμάτων |

### Χρήση Αναφορικών Εικόνων (Έκδοση 2.0)

Στην Έκδοση 2.0, μπορείτε να περάσετε την παράμετρο `image_urls` για να καθοδηγήσετε τη δημιουργία βίντεο με αναφορικές εικόνες (χρησιμοποιείται μόνο η πρώτη εικόνα):

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "version": "2.0",
    "prompt": "a person walking through a beautiful garden",
    "model": "sora-2",
    "duration": 4,
    "size": "1280x720",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

> **Σημείωση**: Η ανάλυση της αναφορικής εικόνας πρέπει να ταιριάζει με την παράμετρο `size`, π.χ. αν `size` είναι `1280x720`, η εικόνα πρέπει να έχει διαστάσεις 1280×720.

### Σύγκριση Παραμέτρων Έκδοσης 1.0 και 2.0

| Παράμετρος | Έκδοση 1.0 | Έκδοση 2.0 |
|------------|------------|------------|
| `version` | 1.0 (προεπιλογή) | 2.0 |
| `prompt` | ✅ | ✅ |
| `model` | ✅ sora-2 / sora-2-pro | ✅ sora-2 / sora-2-pro |
| `duration` | ✅ 10/15/25 δευτ. | ✅ 4/8/12 δευτ. |
| `orientation` | ✅ landscape/portrait | ❌ |
| `size` | ✅ small/large | ✅ 720x1280/1280x720/1024x1792/1792x1024 |
| `image_urls` | ✅ Πολλαπλές εικόνες | ✅ Μόνο πρώτη εικόνα |
| `character_url` | ✅ | ❌ |
| `callback_url` | ✅ | ✅ |

## Ασύγχρονη Επιστροφή Αποτελεσμάτων (Callback)

Επειδή η δημιουργία βίντεο με το Sora Videos Generation API μπορεί να διαρκέσει 1-2 λεπτά, το API παρέχει υποστήριξη για ασύγχρονη επιστροφή αποτελεσμάτων μέσω callback.

Η διαδικασία είναι: ο πελάτης στέλνει το αίτημα με την παράμετρο `callback_url`. Το API επιστρέφει άμεσα ένα αποτέλεσμα με το πεδίο `task_id` που αναγνωρίζει την εργασία. Όταν η εργασία ολοκληρωθεί, το API στέλνει μέσω POST JSON το αποτέλεσμα στο `callback_url` που ορίστηκε, συμπεριλαμβανομένου του `task_id`, ώστε να συσχετιστεί η εργασία με το αποτέλεσμα.

Παρακάτω παρουσιάζεται παράδειγμα χρήσης.

Το Webhook callback είναι μια υπηρεσία που δέχεται HTTP αιτήματα. Ο προγραμματιστής πρέπει να αντικαταστήσει το URL με το δικό του HTTP server. Για επίδειξη, χρησιμοποιούμε την δημόσια υπηρεσία https://webhook.site/, όπου μπορείτε να λάβετε ένα Webhook URL, όπως στην εικόνα:

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, σε περίπτωση σφάλματος, επιστρέφονται κωδικοί και μηνύματα σφάλματος, όπως:

- `400 token_mismatched`: Κακό αίτημα, πιθανόν λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακό αίτημα, πιθανόν λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διακριτικό πρόσβασης.
- `429 too_many_requests`: Πολλές αιτήσεις, υπερβήκατε το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.

### Παράδειγμα Απάντησης Σφάλματος

```json
  },

}
```
