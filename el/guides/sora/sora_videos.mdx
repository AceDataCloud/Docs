Αυτό το άρθρο θα παρουσιάσει μια μέθοδο σύνδεσης με το API Δημιουργίας Βίντεο Sora, το οποίο μπορεί να δημιουργήσει βίντεο από την επίσημη Sora μέσω εισαγωγής προσαρμοσμένων παραμέτρων.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να επισκεφθείτε τη σελίδα [API Δημιουργίας Βίντεο Sora](https://platform.acedata.cloud/documents/99a24421-2e22-4028-8201-e19cb834b67e) και να ζητήσετε την αντίστοιχη υπηρεσία. Αφού μπείτε στη σελίδα, κάντε κλικ στο κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά την εγγραφή και τη σύνδεση, θα επιστρέψετε αυτόματα στη τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, θα υπάρχει δωρεάν πίστωση που μπορείτε να χρησιμοποιήσετε δωρεάν για αυτό το API.

## Βασική Χρήση

Αρχικά, πρέπει να κατανοήσετε τη βασική μέθοδο χρήσης, δηλαδή να εισάγετε τη λέξη-κλειδί `prompt`, τον πίνακα διευθύνσεων εικόνας `image_urls` και το μοντέλο `model`, για να λάβετε το επεξεργασμένο αποτέλεσμα. Οι λεπτομέρειες είναι οι εξής:

<p><img src="https://cdn.acedata.cloud/h8dyz3.png" width="500" className="m-auto" /></p>

Μπορείτε να δείτε ότι έχουμε ρυθμίσει τα Request Headers, που περιλαμβάνουν:

- `accept`: ποια μορφή απάντησης θέλετε να λάβετε, εδώ συμπληρώνεται ως `application/json`, δηλαδή σε μορφή JSON.
- `authorization`: το κλειδί για την κλήση του API, το οποίο μπορείτε να επιλέξετε απευθείας από το αναπτυσσόμενο μενού μετά την αίτηση.

Επιπλέον, έχουμε ρυθμίσει το Request Body, που περιλαμβάνει:

- `model`: το μοντέλο για τη δημιουργία του βίντεο, κυρίως `sora-2`, `sora-2-pro`, αυτή τη στιγμή τα `sora-2`, `sora-2-pro` μπορούν να επιλέξουν παραμέτρους `size`, `duration`, όπου το `sora-2-pro` υποστηρίζει βίντεο διάρκειας 25 δευτερολέπτων, ενώ το `sora-2` υποστηρίζει μόνο βίντεο 10 και 15 δευτερολέπτων.
- `size`: η ανάλυση της τρέχουσας εργασίας δημιουργίας βίντεο, που μπορεί να είναι `small` ή `large`.
- `image_urls`: οι διευθύνσεις εικόνας που πρέπει να ανεβούν ή ο πίνακας κωδικοποίησης Base64.
- `duration`: η διάρκεια της τρέχουσας εργασίας δημιουργίας βίντεο, που μπορεί να είναι 10s, 15s, 25s, αυτή τη στιγμή μόνο το `sora-2-pro` υποστηρίζει 25s.
- `character_start`/`character_end`: η αρχική και τελική θέση του χαρακτήρα στην οθόνη (0-1), για τον έλεγχο της θέσης του κύριου θέματος.
- `orientation`: η κατεύθυνση της εικόνας, υποστηρίζει `landscape`, `portrait`, `square`.
- `prompt`: η λέξη-κλειδί.
- `callback_url`: η διεύθυνση URL για την επιστροφή αποτελεσμάτων.

Αφού επιλέξετε, μπορείτε να δείτε ότι έχει παραχθεί ο αντίστοιχος κώδικας στα δεξιά, όπως φαίνεται στην εικόνα:

## Δημιουργία Βίντεο από Εικόνες

Εάν θέλετε να δημιουργήσετε βίντεο από εικόνες, πρώτα η παράμετρος `image_urls` πρέπει να περιλαμβάνει τις διευθύνσεις των αναφερόμενων εικόνων, ώστε να μπορείτε να καθορίσετε τα εξής περιεχόμενα:

- image_urls: ο πίνακας διευθύνσεων εικόνας που χρησιμοποιείται για τη δημιουργία του βίντεο.

Ένα παράδειγμα συμπλήρωσης είναι το εξής:

<p><img src="https://cdn.acedata.cloud/ch7x3t.png" width="500" className="m-auto" /></p>

Αφού συμπληρώσετε, έχει παραχθεί αυτόματα ο παρακάτω κώδικας:

<p><img src="https://cdn.acedata.cloud/z1ud8l.png" width="500" className="m-auto" /></p>

Ο αντίστοιχος κώδικας:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "large",
    "duration": 15,
    "orientation": "landscape",
    "prompt": "cat running on the river",
    "model": "sora-2",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Δημιουργία βίντεο χαρακτήρα

Αν θέλετε να δημιουργήσετε βίντεο χαρακτήρα, πρώτα η παράμετρος `character_url` πρέπει να περιλαμβάνει τον σύνδεσμο βίντεο που απαιτείται για τη δημιουργία του χαρακτήρα, προσέξτε ότι στο βίντεο δεν πρέπει να εμφανίζεται κανένας άνθρωπος, αλλιώς θα αποτύχει, μπορείτε να καθορίσετε τα εξής περιεχόμενα:

- character_url: Ο σύνδεσμος βίντεο που απαιτείται για τη δημιουργία του χαρακτήρα, προσέξτε ότι στο βίντεο δεν πρέπει να εμφανίζεται κανένας άνθρωπος, αλλιώς θα αποτύχει.

Το παράδειγμα συμπλήρωσης είναι το εξής:

<p><img src="https://cdn.acedata.cloud/2nhdr2.png" width="500" className="m-auto" /></p>

Αφού συμπληρωθεί, δημιουργήθηκε αυτόματα ο παρακάτω κώδικας:

<p><img src="https://cdn.acedata.cloud/xp8scl.png" width="500" className="m-auto" /></p>

Ο αντίστοιχος κώδικας:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "small",
    "duration": 10,
    "orientation": "landscape",
    "prompt": "cat running on the river",
    "character_url": "https://cdn.acedata.cloud/pdidf5.mp4",

## Ασύγχρονη κλήση επιστροφής

Δεδομένου ότι η API δημιουργίας βίντεο Sora χρειάζεται σχετικά μεγάλο χρόνο, περίπου 1-2 λεπτά, αν η API δεν απαντήσει για μεγάλο χρονικό διάστημα, το HTTP αίτημα θα διατηρεί τη σύνδεση, προκαλώντας επιπλέον κατανάλωση πόρων συστήματος, γι' αυτό η API παρέχει επίσης υποστήριξη για ασύγχρονη κλήση επιστροφής.

Η συνολική διαδικασία είναι: όταν ο πελάτης υποβάλλει το αίτημα, προσδιορίζει επιπλέον ένα πεδίο `callback_url`, μετά την υποβολή του API αίτημα, η API θα επιστρέψει αμέσως ένα αποτέλεσμα, που περιλαμβάνει ένα πεδίο `task_id`, που αντιπροσωπεύει το τρέχον ID εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα του παραγόμενου βίντεο θα αποσταλεί μέσω POST JSON στη διεύθυνση `callback_url` που έχει καθορίσει ο πελάτης, η οποία περιλαμβάνει επίσης το πεδίο `task_id`, έτσι ώστε το αποτέλεσμα της εργασίας να μπορεί να συσχετιστεί μέσω του ID.

Ας δούμε πώς να το κάνουμε με ένα παράδειγμα.

Πρώτα, η κλήση Webhook είναι μια υπηρεσία που μπορεί να δέχεται HTTP αιτήματα, οι προγραμματιστές θα πρέπει να την αντικαταστήσουν με το URL του HTTP διακομιστή που έχουν δημιουργήσει. Για ευκολία επίδειξης, χρησιμοποιούμε έναν δημόσιο ιστότοπο παραδείγματος Webhook https://webhook.site/, ανοίγοντας αυτόν τον ιστότοπο μπορείτε να λάβετε ένα Webhook URL, όπως φαίνεται στην εικόνα:

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, εάν προκύψει σφάλμα, το API θα επιστρέψει τον αντίστοιχο κωδικό σφάλματος και πληροφορίες. Για παράδειγμα:

- `400 token_mismatched`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανώς λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένο, μη έγκυρο ή ελλιπές διαπιστευτήριο εξουσιοδότησης.
- `429 too_many_requests`: Πάρα πολλές αιτήσεις, έχετε υπερβεί το όριο ρυθμού.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή, κάτι πήγε στραβά στον διακομιστή.
