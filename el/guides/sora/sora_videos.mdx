Αυτό το έγγραφο παρουσιάζει τις οδηγίες ενσωμάτωσης του Sora Videos Generation API, μέσω του οποίου μπορείτε να εισάγετε προσαρμοσμένες παραμέτρους για να δημιουργήσετε επίσημα βίντεο Sora. Το API υποστηρίζει δύο εκδόσεις λειτουργίας:

- **Έκδοση 1 (Κλασική λειτουργία)**: Υποστηρίζει τις παραμέτρους `duration` (10/15/25 δευτερόλεπτα), `orientation` (οριζόντιο/κατακόρυφο), `size` (small/large ανάλυση), αναφορικές εικόνες `image_urls`, σύνδεσμο χαρακτήρα `character_url` κ.ά.
- **Έκδοση 2 (Λειτουργία συνεργάτη)**: Υποστηρίζει τις παραμέτρους `seconds` (4/8/12 δευτερόλεπτα), ανάλυση σε επίπεδο pixel `size` (π.χ. 1280x720), αναφορικές εικόνες `input_reference` κ.ά.

## Διαδικασία Αίτησης

Για να χρησιμοποιήσετε το API, πρέπει πρώτα να κάνετε αίτηση στην αντίστοιχη σελίδα του [Sora Videos Generation API](https://platform.acedata.cloud/documents/99a24421-2e22-4028-8201-e19cb834b67e). Μόλις μπείτε στη σελίδα, πατήστε το κουμπί «Acquire», όπως φαίνεται στην εικόνα:

![](https://cdn.acedata.cloud/q6ytrc.png)

Εάν δεν έχετε συνδεθεί ή εγγραφεί, θα μεταφερθείτε αυτόματα στη σελίδα σύνδεσης για να εγγραφείτε και να συνδεθείτε. Μετά τη σύνδεση, θα επιστρέψετε αυτόματα στην τρέχουσα σελίδα.

Κατά την πρώτη αίτηση, παρέχεται δωρεάν όριο χρήσης για το API.

## Βασική Χρήση (Έκδοση 1)

Αρχικά, η βασική χρήση της Έκδοσης 1 είναι να εισάγετε την προτροπή `prompt`, έναν πίνακα με συνδέσμους αναφορικών εικόνων `image_urls` και το μοντέλο `model`, για να λάβετε το επεξεργασμένο αποτέλεσμα. Αναλυτικά:

<p><img src="https://cdn.acedata.cloud/h8dyz3.png" width="500" className="m-auto" /></p>

Εδώ ορίζουμε τα Request Headers, που περιλαμβάνουν:

- `accept`: Τον τύπο της απάντησης που θέλουμε να λάβουμε, εδώ `application/json` (μορφή JSON).
- `authorization`: Το κλειδί πρόσβασης στο API, το οποίο επιλέγεται μετά την αίτηση.

Επιπλέον, ορίζουμε το Request Body, που περιλαμβάνει:

- `model`: Το μοντέλο δημιουργίας βίντεο, υποστηρίζει `sora-2` (τυπική λειτουργία) και `sora-2-pro` (υψηλή ανάλυση). Το `sora-2-pro` υποστηρίζει βίντεο διάρκειας 25 δευτερολέπτων, ενώ το `sora-2` μόνο 10 ή 15 δευτερόλεπτα.
- `size`: Ανάλυση βίντεο, `small` για τυπική και `large` για HD ανάλυση (μόνο Έκδοση 1).
- `duration`: Διάρκεια βίντεο, 10, 15 ή 25 δευτερόλεπτα (25 δευτερόλεπτα μόνο με `sora-2-pro`, μόνο Έκδοση 1).
- `orientation`: Προσανατολισμός βίντεο, `landscape` (οριζόντιο) ή `portrait` (κατακόρυφο) (μόνο Έκδοση 1).
- `image_urls`: Πίνακας συνδέσμων αναφορικών εικόνων για δημιουργία βίντεο από εικόνα (μόνο Έκδοση 1).
- `character_url`: Σύνδεσμος χαρακτήρα, στο βίντεο δεν πρέπει να εμφανίζεται πραγματικό πρόσωπο (μόνο Έκδοση 1).
- `character_start`/`character_end`: Χρονικά όρια εμφάνισης χαρακτήρα σε δευτερόλεπτα, με εύρος 1-3 δευτερόλεπτα (μόνο Έκδοση 1).
- `prompt`: Η προτροπή (υποχρεωτικό).
- `callback_url`: URL για ασύγχρονη επιστροφή αποτελεσμάτων.
- `version`: Έκδοση API, `1` (προεπιλογή) ή `2`.

## Δημιουργία Βίντεο από Εικόνα (Έκδοση 1)

Για να δημιουργήσετε βίντεο από εικόνα, πρέπει να περάσετε την παράμετρο `image_urls` με συνδέσμους αναφορικών εικόνων, όπως:

- `image_urls`: Πίνακας συνδέσμων αναφορικών εικόνων για το βίντεο. Μην χρησιμοποιείτε εικόνες με πραγματικά πρόσωπα για να αποφύγετε αποτυχίες.

Παράδειγμα συμπλήρωσης:

<p><img src="https://cdn.acedata.cloud/ch7x3t.png" width="500" className="m-auto" /></p>

Ο αυτόματος παραγόμενος κώδικας:

<p><img src="https://cdn.acedata.cloud/z1ud8l.png" width="500" className="m-auto" /></p>

Κώδικας Python:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "large",
    "duration": 15,
    "orientation": "landscape",
    "prompt": "cat running on the river",
    "model": "sora-2",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]

print(response.text)
```

## Δημιουργία Βίντεο Χαρακτήρα (Έκδοση 1)

Για να δημιουργήσετε βίντεο με χαρακτήρα, πρέπει να περάσετε την παράμετρο `character_url` με σύνδεσμο βίντεο για τη δημιουργία χαρακτήρα. Σημειώστε ότι το βίντεο δεν πρέπει να περιέχει πραγματικά πρόσωπα, αλλιώς η εργασία θα αποτύχει.

- `character_url`: Σύνδεσμος βίντεο για δημιουργία χαρακτήρα, χωρίς πραγματικά πρόσωπα.

Παράδειγμα συμπλήρωσης:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"
```

## Λειτουργία Έκδοσης 2

Εκτός από την Έκδοση 1, το API υποστηρίζει και την Έκδοση 2, ενεργοποιούμενη με την παράμετρο `version` ίση με `2`. Η Έκδοση 2 υποστηρίζει μικρότερης διάρκειας βίντεο και έλεγχο ανάλυσης σε επίπεδο pixel.

### Παράμετροι Έκδοσης 2

| Παράμετρος | Τύπος | Υποχρεωτική | Περιγραφή |
|------------|-------|-------------|-----------|
| `version` | ακέραιος | Ναι | Ορίζεται σε `2` |
| `prompt` | συμβολοσειρά | Ναι | Προτροπή για δημιουργία βίντεο |
| `model` | συμβολοσειρά | Όχι | `sora-2` (προεπιλογή) ή `sora-2-pro` |
| `duration` | ακέραιος | Όχι | Διάρκεια βίντεο: `4` (προεπιλογή), `8`, `12` δευτερόλεπτα |
| `size` | συμβολοσειρά | Όχι | Ανάλυση: `720x1280` (προεπιλογή), `1280x720`, `1024x1792`, `1792x1024` |
| `image_urls` | πίνακας | Όχι | Πίνακας URL αναφορικών εικόνων, χρησιμοποιείται μόνο η πρώτη εικόνα, διαστάσεις πρέπει να ταιριάζουν με `size` |
| `callback_url` | συμβολοσειρά | Όχι | URL για ασύγχρονη επιστροφή αποτελεσμάτων |

### Χρήση Αναφορικών Εικόνων (Έκδοση 2)

Στην Έκδοση 2, μπορείτε να περάσετε αναφορικές εικόνες μέσω της παραμέτρου `image_urls` για καθοδήγηση της δημιουργίας βίντεο (χρησιμοποιείται μόνο η πρώτη εικόνα):

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "version": 2,
    "prompt": "a person walking through a beautiful garden",
    "model": "sora-2",
    "duration": 4,
    "size": "1280x720",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]

```

> **Σημείωση**: Οι διαστάσεις της αναφορικής εικόνας πρέπει να ταιριάζουν με την παράμετρο `size`. Για παράδειγμα, αν `size` είναι `1280x720`, η εικόνα πρέπει να έχει διαστάσεις 1280×720.

| Παράμετρος | Έκδοση 1 | Έκδοση 2 |
|------------|----------|----------|
| `version` | 1 (προεπιλογή) | 2 |
| `prompt` | ✅ | ✅ |
| `model` | ✅ sora-2 / sora-2-pro | ✅ sora-2 / sora-2-pro |
| `duration` | ✅ 10/15/25 δευτ. | ✅ 4/8/12 δευτ. |
| `orientation` | ✅ landscape/portrait | ❌ |
| `size` | ✅ small/large | ✅ 720x1280/1280x720/1024x1792/1792x1024 |
| `image_urls` | ✅ πολλαπλές εικόνες | ✅ μόνο η πρώτη εικόνα |
| `character_url` | ✅ | ❌ |
| `callback_url` | ✅ | ✅ |

## Ασύγχρονη Επιστροφή Αποτελεσμάτων (Callback)

Η δημιουργία βίντεο μέσω του Sora Videos Generation API απαιτεί σχετικά μεγάλο χρόνο (περίπου 1-2 λεπτά). Εάν το API δεν απαντήσει άμεσα, το HTTP αίτημα παραμένει ανοιχτό, προκαλώντας επιπλέον κατανάλωση πόρων. Για το λόγο αυτό, το API υποστηρίζει ασύγχρονη επιστροφή αποτελεσμάτων μέσω callback.

Η διαδικασία είναι η εξής: ο πελάτης στέλνει αίτημα με την παράμετρο `callback_url`. Το API επιστρέφει άμεσα ένα αποτέλεσμα που περιλαμβάνει το `task_id` της εργασίας. Όταν ολοκληρωθεί η εργασία, το αποτέλεσμα αποστέλλεται μέσω POST σε μορφή JSON στο `callback_url`, περιλαμβάνοντας το ίδιο `task_id` για συσχέτιση.

## Διαχείριση Σφαλμάτων

Κατά την κλήση του API, αν προκύψει σφάλμα, το API επιστρέφει κωδικό και μήνυμα σφάλματος, π.χ.:

- `400 token_mismatched`: Κακή αίτηση, πιθανόν λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `400 api_not_implemented`: Κακή αίτηση, πιθανόν λόγω ελλιπών ή μη έγκυρων παραμέτρων.
- `401 invalid_token`: Μη εξουσιοδοτημένη πρόσβαση, μη έγκυρο ή ελλιπές token.
- `429 too_many_requests`: Υπερβολικός αριθμός αιτημάτων, υπερβήκατε το όριο.
- `500 api_error`: Εσωτερικό σφάλμα διακομιστή.
