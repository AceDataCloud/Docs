**Πριν επιβεβαιώσετε και συμφωνήσετε με αυτούς τους όρους υπηρεσίας (εφεξής "Συμφωνία"), οι χρήστες πρέπει να διαβάσουν προσεκτικά το περιεχόμενο στο σύνολό του, ιδιαίτερα τα τμήματα που είναι επισημασμένα με έντονα γράμματα, συμπεριλαμβανομένων των περιορισμών ή των ρητρών απαλλαγής ευθύνης για τις υποχρεώσεις των χρηστών.**

Η Ace Data Cloud παρέχει υπηρεσίες σχετικές με API και proxy (εφεξής "Υπηρεσίες") μόνο σε χρήστες που έχουν ολοκληρώσει την εγγραφή τους και έχουν υποβάλει αίτημα ενεργοποίησης υπηρεσίας. Κάνοντας κλικ στο κουμπί "Αίτηση" και συμφωνώντας με αυτή τη Συμφωνία, δηλώνετε ότι έχετε διαβάσει, κατανοήσει και αποδεχθεί όλους τους όρους και συμφωνείτε να δεσμευθείτε νομικά από αυτούς. Εάν δεν συμφωνείτε με αυτή τη Συμφωνία ή δεν μπορείτε να κατανοήσετε πλήρως το περιεχόμενό της, παρακαλούμε μην συνεχίσετε την εγγραφή ή την αίτηση για τις υπηρεσίες που παρέχει η Ace Data Cloud.

## Πεδίο Υπηρεσιών

Αυτή η Συμφωνία δεσμεύει τη χρήση σας των υπηρεσιών API και proxy της Ace Data Cloud, οι οποίες είναι προϊόντα θυγατρικών της **Germey Technology, LLC**.

Αυτή η Συμφωνία είναι συμπληρωματική της "Συμφωνίας Υπηρεσιών Χρηστών" και αποτελεί αναπόσπαστο μέρος της. Σε περίπτωση σύγκρουσης μεταξύ αυτής της Συμφωνίας και της "Συμφωνίας Υπηρεσιών Χρηστών", υπερισχύει αυτή η Συμφωνία. Η Ace Data Cloud μπορεί να ενημερώνει ή να δημοσιεύει συνεχώς κανόνες, πολιτικές, δηλώσεις και οδηγίες σχετικές με τις υπηρεσίες, οι οποίες θα γίνονται μέρος αυτής της Συμφωνίας κατά την δημοσίευσή τους.

**Εάν δεν πληροίτε τις προϋποθέσεις αυτής της Συμφωνίας, η Ace Data Cloud διατηρεί το δικαίωμα να αναστείλει ή να τερματίσει τη χρήση των υπηρεσιών σας ανά πάσα στιγμή. Επιπλέον, η Ace Data Cloud μπορεί να προσαρμόσει το πεδίο των υπηρεσιών κατά την κρίση της και να ανακοινώσει τις αλλαγές χωρίς να φέρει καμία ευθύνη.**

## Μορφή και Περιεχόμενο Υπηρεσιών

Οι υπηρεσίες που παρέχει η Ace Data Cloud περιλαμβάνουν υπηρεσίες API, υπηρεσίες HTTP proxy και υπηρεσίες παροχής δεδομένων σε μαζική κλίμακα. Με την έναρξη ισχύος αυτής της Συμφωνίας, οι χρήστες πρέπει να προπληρώσουν το αντίστοιχο κόστος υπηρεσίας. Μετά την παραλαβή της προπληρωμής, η Ace Data Cloud θα ενεργοποιήσει τις υπηρεσίες.

Οι χρήστες πρέπει να εξουσιοδοτήσουν την Ace Data Cloud να αλληλεπιδράσει εκ μέρους τους με τρίτους για την επαλήθευση των πηγών πληροφοριών υπηρεσίας. Οι χρήστες συμφωνούν ότι η Ace Data Cloud μπορεί να επιλέξει συγκεκριμένες πηγές πληροφοριών για την παροχή υπηρεσιών επαλήθευσης με βάση παράγοντες όπως η ποιότητα και η τεχνική ικανότητα. Εάν η πηγή πληροφοριών δεν είναι διαθέσιμη, η Ace Data Cloud θα παρέχει εναλλακτική πηγή.

## Ενεργοποίηση Υπηρεσιών, Πληρωμή και Χρεώσεις

Η υπηρεσία API απαιτεί προπληρωμή. Οι χρήστες μπορούν να επιλέξουν και να προπληρώσουν το αντίστοιχο πακέτο προϊόντων ανάλογα με τις ανάγκες τους. Η τιμή ανά πακέτο μπορεί να κυμαίνεται ανάλογα με τις συνθήκες της αγοράς. Οι χρήστες πρέπει να διασφαλίσουν ότι το υπόλοιπο του λογαριασμού τους και οι υπόλοιπες κλήσεις είναι επαρκή, ώστε να αποφευχθεί η διακοπή υπηρεσίας.

**Οι χρήστες πρέπει να διασφαλίσουν ότι η πηγή χρηματοδότησης για την πληρωμή είναι νόμιμη. Εάν διαπιστωθεί παράνομη δραστηριότητα, η Ace Data Cloud διατηρεί το δικαίωμα να τερματίσει τη συνεργασία και να λάβει νομικά μέτρα.**

Ακολουθούν οι νέες ενότητες για την αναφορά σας, οι οποίες έχουν συνταχθεί με επαγγελματικό ύφος:

## Πολιτική Επιστροφών, Επιστροφών και Ακυρώσεων

**Πολιτική Επιστροφών**
Όλα τα εικονικά προϊόντα και οι υπηρεσίες που παρέχονται από την Ace Data Cloud δεν επιστρέφονται μόλις πωληθούν υπό κανονικές συνθήκες. Μόνο σε περίπτωση τεχνικής βλάβης ή άλλων ανωτέρας βίας που καθιστούν αδύνατη τη συνέχιση της κανονικής παροχής υπηρεσιών, οι χρήστες μπορούν να υποβάλουν αίτηση για επιστροφή χρημάτων, αφού επιβεβαιωθεί η κατάσταση. Το συγκεκριμένο ποσό επιστροφής και οι προϋποθέσεις θα καθοριστούν από την Ace Data Cloud με βάση την πραγματική κατάσταση.

**Διαδικασία Αίτησης Επιστροφής**
Για να υποβάλετε αίτηση επιστροφής, οι χρήστες παρακαλούνται να υποβάλουν αίτηση μέσω των καναλιών υποστήριξης πελατών της επίσημης ιστοσελίδας και να παρέχουν λεπτομερείς αποδείξεις για τη διακοπή ή τη βλάβη της υπηρεσίας. Μετά την επιβεβαίωση, οι αιτήσεις επιστροφής που πληρούν τις προϋποθέσεις θα επεξεργαστούν εντός εύλογου χρονικού διαστήματος.

**Πολιτική Ακύρωσης**
Για τις υπηρεσίες συνδρομής, οι χρήστες μπορούν να ακυρώσουν την υπηρεσία οποιαδήποτε στιγμή. Η επιστροφή των προπληρωμένων ποσών θα εξεταστεί μόνο εάν η υπηρεσία δεν μπορεί να παρασχεθεί κανονικά λόγω τεχνικών προβλημάτων ή άλλων ανωτέρας βίας. Εκτός από τις παραπάνω περιπτώσεις, η ακύρωση της υπηρεσίας δεν θα επιστραφεί.

**Πολιτική Παράδοσης και Παροχής**
Δεδομένου ότι όλα τα προϊόντα και οι υπηρεσίες παραδίδονται ψηφιακά, δεν ισχύει πολιτική παράδοσης ή παροχής για φυσικά αγαθά.

**Πολιτική Επιστροφής**
Λόγω της ειδικής φύσης των εικονικών προϊόντων, τα πωληθέντα προϊόντα δεν γίνονται αποδεκτά για επιστροφή. Εάν έχετε οποιαδήποτε ερώτηση ή πρόβλημα σχετικά με τα προϊόντα ή τις υπηρεσίες, παρακαλούμε επικοινωνήστε άμεσα με την υποστήριξη πελατών, και θα παρέχουμε τις αντίστοιχες λύσεις ανάλογα με την κατάσταση.

Αυτή η πολιτική επιστροφών, επιστροφών και ακυρώσεων θα ενημερώνεται κατά καιρούς σύμφωνα με τις ισχύουσες νομικές διατάξεις και τις ανάγκες λειτουργίας της εταιρείας. Η συνέχιση της χρήσης των υπηρεσιών υποδηλώνει τη συμφωνία σας να συμμορφώνεστε με τους τρέχοντες όρους πολιτικής.

## Δικαιώματα και Υποχρεώσεις Χρηστών

**Οι χρήστες είναι υπεύθυνοι για όλα τα νομικά ζητήματα που προκύπτουν από τη χρήση των υπηρεσιών.** Οι χρήστες πρέπει να διασφαλίσουν ότι η χρήση των υπηρεσιών τους συμμορφώνεται με τον "Νόμο για την Προστασία Προσωπικών Δεδομένων" και ότι έχουν λάβει την κατάλληλη εξουσιοδότηση για την επεξεργασία προσωπικών πληροφοριών. Οι χρήστες πρέπει να παρέχουν αποδεικτικά στοιχεία εξουσιοδότησης και να συνεργάζονται με τη διαδικασία επαλήθευσης της Ace Data Cloud.

**Οι χρήστες δεν επιτρέπεται να αναδιανέμουν, να πωλούν ή να μεταβιβάζουν τις υπηρεσίες.** Πρέπει να χρησιμοποιούν τις υπηρεσίες μόνο για εξουσιοδοτημένους σκοπούς και εντός του συμφωνηθέντος πλαισίου.

## Δικαιώματα και Υποχρεώσεις της Ace Data Cloud

**Η Ace Data Cloud έχει το δικαίωμα να αποδέχεται ή να απορρίπτει τα αιτήματα των χρηστών με βάση την πραγματική κατάσταση ή τα ιστορικά συναλλαγών.** Η Ace Data Cloud μπορεί να χρεώνει τους χρήστες για τις υπηρεσίες και έχει το δικαίωμα να αναστείλει τις υπηρεσίες λόγω καθυστερημένων πληρωμών.

Η Ace Data Cloud θα παρέχει στους χρήστες την απαραίτητη τεχνική υποστήριξη, διασφαλίζοντας την ασφάλεια και τη σωστή λειτουργία του συστήματος. Ωστόσο, η Ace Data Cloud δεν φέρει ευθύνη για διακοπές υπηρεσίας που προκαλούνται από εξωτερικούς παράγοντες.

**Εκτός εάν απαιτείται από το νόμο ή ορίζεται διαφορετικά σε αυτή τη Συμφωνία, η Ace Data Cloud υποχρεούται να διατηρεί την εμπιστευτικότητα των δεδομένων και των ιστορικών συναλλαγών των χρηστών.**

## Ευθύνη για Παραβίαση και Απαλλαγή Ευθύνης

**Οι αλλαγές στους νόμους, τους κανονισμούς και τις πολιτικές μπορεί να επηρεάσουν την εκτέλεση αυτής της Συμφωνίας.** Σε αυτή την περίπτωση, οι δύο πλευρές θα πρέπει να διαπραγματευτούν για την προσαρμογή. Εάν δεν επιτευχθεί συμφωνία, οποιαδήποτε από τις δύο πλευρές μπορεί να τερματίσει αυτή τη Συμφωνία χωρίς να φέρει ευθύνη για παραβίαση.

**Οι χρήστες πρέπει να διατηρούν τη σταθερότητα και την ασφάλεια της πλατφόρμας και του συστήματός τους.** Η Ace Data Cloud δεν φέρει ευθύνη για οποιαδήποτε ζημία προκύψει από κενά ασφαλείας ή ακατάλληλα μέτρα ασφαλείας.

## Συμπληρωματικοί Όροι

**Αυτή η Συμφωνία τίθεται σε ισχύ όταν οι χρήστες εγγράφονται στην Ace Data Cloud και συμφωνούν με αυτή τη Συμφωνία.** Εάν αυτή η Συμφωνία διαφέρει από τη γραπτή σύμβαση που έχει υπογραφεί από τον χρήστη και την Ace Data Cloud, υπερισχύει η γραπτή σύμβαση. Για θέματα που δεν καλύπτονται από τη γραπτή σύμβαση, οι διαδικτυακοί κανόνες που συμφωνήθηκαν κατά την εγγραφή και τη χρήση των υπηρεσιών της Ace Data Cloud θα ισχύουν.
