Η Germey Technology, LLC (εφεξής "εμείς" ή "μας"), η οποία είναι η εταιρεία πίσω από το Ace Data Cloud, δεσμεύεται να προστατεύει την ιδιωτικότητά σας. Αυτή η πολιτική απορρήτου εξηγεί πώς συλλέγουμε, χρησιμοποιούμε, αποκαλύπτουμε και προστατεύουμε τις πληροφορίες σας όταν επισκέπτεστε την πλατφόρμα μας Ace Data Cloud. Παρακαλούμε διαβάστε προσεκτικά αυτή την πολιτική απορρήτου. Η χρήση αυτής της πλατφόρμας σημαίνει ότι συμφωνείτε με τους όρους αυτής της πολιτικής απορρήτου.

## Πληροφορίες που συλλέγουμε

Συλλέγουμε διάφορους τύπους πληροφοριών για να σας παρέχουμε και να βελτιώσουμε τις υπηρεσίες μας:

1. **Προσωπικές πληροφορίες**: Πληροφορίες που μπορούν να σας ταυτοποιήσουν, όπως το όνομά σας, η διεύθυνση ηλεκτρονικού ταχυδρομείου, ο αριθμός τηλεφώνου, οι πληροφορίες πληρωμής και άλλα παρόμοια δεδομένα.
2. **Μη προσωπικές πληροφορίες**: Πληροφορίες που δεν μπορούν να σας ταυτοποιήσουν, συμπεριλαμβανομένων αλλά όχι περιορισμένων σε τη διεύθυνση IP σας, τον τύπο του προγράμματος περιήγησης, το λειτουργικό σύστημα, το URL παραπομπής και τις σχετικές πληροφορίες σχετικά με τη χρήση της πλατφόρμας μας.
3. **Τεχνικά δεδομένα**: Δεδομένα σχετικά με τη χρήση του API μας, συμπεριλαμβανομένου του αριθμού αιτημάτων, του τύπου δεδομένων αιτημάτων και σχετικών μεταδεδομένων.

## Σκοποί Χρήσης

Οι πληροφορίες που συλλέγουμε χρησιμοποιούνται για διάφορους σκοπούς:

1. **Παροχή και συντήρηση υπηρεσιών**: Λειτουργία και συντήρηση της πλατφόρμας μας, συμπεριλαμβανομένης της επεξεργασίας συναλλαγών και της παροχής υποστήριξης πελατών.
2. **Βελτίωση της πλατφόρμας μας**: Κατανόηση του τρόπου που χρησιμοποιείτε την πλατφόρμα μας και βελτίωση και ενίσχυση των λειτουργιών και της εμπειρίας χρήστη.
3. **Επικοινωνία μαζί σας**: Αποστολή ενημερώσεων, διαφημιστικού υλικού και άλλων πληροφοριών που μπορεί να σας ενδιαφέρουν. Μπορείτε να επιλέξετε να διαγραφείτε από αυτές τις επικοινωνίες οποιαδήποτε στιγμή.
4. **Εξασφάλιση ασφάλειας**: Παρακολούθηση και ανάλυση της χρήσης και των τάσεων δραστηριότητας για να διασφαλίσουμε την ασφάλεια και την ακεραιότητα της πλατφόρμας μας.
5. **Συμμόρφωση με νομικές υποχρεώσεις**: Συμμόρφωση με τις εφαρμοστέες νόμους, κανονισμούς και νομικές διαδικασίες.

## Αποκάλυψη Πληροφοριών

Μπορεί να αποκαλύψουμε τις πληροφορίες σας στις εξής περιπτώσεις:

1. **Πάροχοι υπηρεσιών**: Μπορεί να μοιραστούμε τις πληροφορίες σας με τρίτους παρόχους υπηρεσιών που ενεργούν εκ μέρους μας, όπως επεξεργασία πληρωμών, ανάλυση δεδομένων, αποστολή ηλεκτρονικών μηνυμάτων, υπηρεσίες φιλοξενίας και υποστήριξη πελατών.
2. **Νομικές απαιτήσεις**: Εάν απαιτείται από το νόμο ή ως απάντηση σε έγκυρο αίτημα δημόσιων αρχών (όπως δικαστήριο ή κυβερνητικός οργανισμός), μπορεί να αποκαλύψουμε τις πληροφορίες σας.
3. **Μεταφορά επιχείρησης**: Σε περίπτωση συγχώνευσης, πώλησης εταιρικών περιουσιακών στοιχείων, χρηματοδότησης ή πώλησης όλων ή μέρους της επιχείρησής μας σε άλλη εταιρεία, ή κατά τη διάρκεια διαπραγματεύσεων για τέτοιες συναλλαγές, μπορεί να αποκαλύψουμε ή να μεταφέρουμε τις πληροφορίες σας.
4. **Η συγκατάθεσή σας**: Με την ρητή συγκατάθεσή σας, μπορεί να αποκαλύψουμε τις πληροφορίες σας για άλλους σκοπούς.

## Μέτρα Ασφαλείας

Εφαρμόζουμε λογικά μέτρα ασφαλείας για να προστατεύσουμε τις πληροφορίες σας από μη εξουσιοδοτημένη πρόσβαση, χρήση, τροποποίηση και αποκάλυψη. Αυτά τα μέτρα περιλαμβάνουν:

1. **Κρυπτογράφηση δεδομένων**: Χρησιμοποιούμε τεχνολογία κρυπτογράφησης βιομηχανικών προτύπων για να προστατεύσουμε τα δεδομένα που μεταφέρονται προς και από την πλατφόρμα μας.
2. **Έλεγχος πρόσβασης**: Η πρόσβαση στις προσωπικές σας πληροφορίες περιορίζεται μόνο σε εξουσιοδοτημένα άτομα που χρειάζονται αυτές τις πληροφορίες για να εκτελέσουν τα καθήκοντά τους.
3. **Τακτικοί έλεγχοι**: Διενεργούμε τακτικούς ελέγχους στα συστήματα και τις διαδικασίες ασφαλείας μας για να διασφαλίσουμε τη συμμόρφωση με τα βιομηχανικά πρότυπα και τις βέλτιστες πρακτικές.
4. **Ασφαλής αποθήκευση**: Αποθηκεύουμε τις προσωπικές πληροφορίες σε ασφαλές περιβάλλον, αποτρέποντας τη μη εξουσιοδοτημένη πρόσβαση, χρήση ή αποκάλυψη.

### Δικαιώματά σας

Έχετε το δικαίωμα:

1. **Πρόσβαση στις πληροφορίες σας**: Να ζητήσετε πρόσβαση στις προσωπικές πληροφορίες που διατηρούμε για εσάς.
2. **Διόρθωση των πληροφοριών σας**: Να ζητήσετε τη διόρθωση οποιωνδήποτε ανακριβών ή ελλιπών προσωπικών πληροφοριών.
3. **Διαγραφή των πληροφοριών σας**: Με ορισμένες νομικές εξαιρέσεις, μπορείτε να ζητήσετε τη διαγραφή των προσωπικών σας πληροφοριών. Εάν επιθυμείτε να διαγραφούν οι πληροφορίες σας, παρακαλούμε επικοινωνήστε με την ομάδα υποστήριξής μας - office@acedata.cloud.
4. **Επιλογή εξόδου**: Να επιλέξετε να διαγραφείτε από τις διαφημιστικές μας επικοινωνίες ακολουθώντας τις οδηγίες διαγραφής που περιλαμβάνονται σε αυτές τις επικοινωνίες.
