Η Germey Technology, LLC (εφεξής «εμείς» ή «μας»), η εταιρεία πίσω από το Ace Data Cloud, δεσμεύεται να προστατεύει το απόρρητό σας. Αυτή η Πολιτική Απορρήτου εξηγεί πώς συλλέγουμε, χρησιμοποιούμε, αποκαλύπτουμε και προστατεύουμε τις πληροφορίες σας όταν επισκέπτεστε την πλατφόρμα του Ace Data Cloud. Παρακαλούμε διαβάστε προσεκτικά αυτή την Πολιτική Απορρήτου. Η χρήση της πλατφόρμας συνεπάγεται την αποδοχή των όρων αυτής της Πολιτικής Απορρήτου.

## Πληροφορίες που συλλέγουμε

Συλλέγουμε διάφορους τύπους πληροφοριών για να σας παρέχουμε και να βελτιώνουμε τις υπηρεσίες μας:

1. **Προσωπικές πληροφορίες**: Πληροφορίες που μπορούν να χρησιμοποιηθούν για την ταυτοποίησή σας, όπως το όνομά σας, διεύθυνση ηλεκτρονικού ταχυδρομείου, αριθμός τηλεφώνου, πληροφορίες πληρωμής και άλλα παρόμοια δεδομένα.

2. **Μη προσωπικές πληροφορίες**: Πληροφορίες που δεν μπορούν να χρησιμοποιηθούν για την ταυτοποίησή σας, συμπεριλαμβανομένων, αλλά όχι περιοριστικά, της διεύθυνσης IP, τύπου προγράμματος περιήγησης, λειτουργικού συστήματος, URL παραπομπής και σχετικών πληροφοριών σχετικά με τη χρήση της πλατφόρμας μας.

3. **Τεχνικά δεδομένα**: Δεδομένα σχετικά με τη χρήση του API μας, όπως αριθμός αιτημάτων, τύποι δεδομένων αιτημάτων και σχετικά μεταδεδομένα.

## Σκοπός χρήσης

Οι πληροφορίες που συλλέγουμε χρησιμοποιούνται για τους εξής σκοπούς:

1. **Παροχή και συντήρηση υπηρεσιών**: Λειτουργία και συντήρηση της πλατφόρμας μας, συμπεριλαμβανομένης της επεξεργασίας συναλλαγών και της παροχής υποστήριξης πελατών.

2. **Βελτίωση της πλατφόρμας μας**: Κατανόηση του τρόπου χρήσης της πλατφόρμας μας και βελτίωση και ενίσχυση των λειτουργιών και της εμπειρίας χρήστη.

3. **Επικοινωνία μαζί σας**: Αποστολή ενημερώσεων, προωθητικού υλικού και άλλων πληροφοριών που μπορεί να σας ενδιαφέρουν. Μπορείτε να επιλέξετε να διαγραφείτε από αυτές τις επικοινωνίες ανά πάσα στιγμή.

4. **Διασφάλιση ασφάλειας**: Παρακολούθηση και ανάλυση της χρήσης και των τάσεων δραστηριότητας για να διασφαλίσουμε την ασφάλεια και την ακεραιότητα της πλατφόρμας μας.

5. **Συμμόρφωση με νομικές υποχρεώσεις**: Συμμόρφωση με ισχύοντες νόμους, κανονισμούς και νομικές διαδικασίες.

## Αποκάλυψη πληροφοριών

Μπορούμε να αποκαλύψουμε τις πληροφορίες σας στις ακόλουθες περιπτώσεις:

1. **Πάροχοι υπηρεσιών**: Μπορεί να μοιραστούμε τις πληροφορίες σας με τρίτους παρόχους υπηρεσιών που ενεργούν εκ μέρους μας, όπως επεξεργασία πληρωμών, ανάλυση δεδομένων, αποστολή email, υπηρεσίες φιλοξενίας και υποστήριξη πελατών.

2. **Νομικές απαιτήσεις**: Εάν απαιτείται από το νόμο ή σε απόκριση έγκυρων αιτημάτων δημόσιων αρχών (π.χ. δικαστήρια ή κυβερνητικές υπηρεσίες), μπορεί να αποκαλύψουμε τις πληροφορίες σας.

3. **Μεταβίβαση επιχειρήσεων**: Σε περίπτωση συγχώνευσης, πώλησης εταιρικών περιουσιακών στοιχείων, χρηματοδότησης ή πώλησης ολόκληρης ή μέρους της επιχείρησής μας σε άλλη εταιρεία, ή κατά τη διάρκεια διαπραγματεύσεων τέτοιων συναλλαγών, μπορεί να αποκαλύψουμε ή να μεταβιβάσουμε τις πληροφορίες σας.

4. **Συγκατάθεσή σας**: Με την ρητή συγκατάθεσή σας, μπορεί να αποκαλύψουμε τις πληροφορίες σας για άλλους σκοπούς.

## Μέτρα ασφαλείας

Εφαρμόζουμε λογικά μέτρα ασφαλείας για να προστατεύσουμε τις πληροφορίες σας από μη εξουσιοδοτημένη πρόσβαση, χρήση, αλλοίωση και αποκάλυψη. Αυτά τα μέτρα περιλαμβάνουν:

1. **Κρυπτογράφηση δεδομένων**: Χρησιμοποιούμε τεχνολογίες κρυπτογράφησης βιομηχανικού επιπέδου για την προστασία των δεδομένων που μεταφέρονται προς και από την πλατφόρμα μας.

2. **Έλεγχος πρόσβασης**: Η πρόσβαση στις προσωπικές σας πληροφορίες περιορίζεται σε εξουσιοδοτημένα άτομα που χρειάζονται αυτές τις πληροφορίες για να εκπληρώσουν τα καθήκοντά τους.

3. **Τακτικοί έλεγχοι**: Διεξάγουμε τακτικούς ελέγχους των συστημάτων και διαδικασιών ασφαλείας μας για να διασφαλίσουμε τη συμμόρφωση με τα βιομηχανικά πρότυπα και τις βέλτιστες πρακτικές.

4. **Ασφαλής αποθήκευση**: Αποθηκεύουμε τις προσωπικές πληροφορίες σε ασφαλές περιβάλλον, αποτρέποντας μη εξουσιοδοτημένη πρόσβαση, χρήση ή αποκάλυψη.

### Τα δικαιώματά σας

Έχετε το δικαίωμα να:

1. **Πρόσβαση στις πληροφορίες σας**: Αιτηθείτε πρόσβαση στις προσωπικές πληροφορίες που κατέχουμε για εσάς.

2. **Διόρθωση των πληροφοριών σας**: Αιτηθείτε τη διόρθωση οποιωνδήποτε ανακριβών ή ελλιπών προσωπικών πληροφοριών.

3. **Διαγραφή των πληροφοριών σας**: Υπό ορισμένες νομικές εξαιρέσεις, μπορείτε να αιτηθείτε τη διαγραφή των προσωπικών σας πληροφοριών. Εάν επιθυμείτε τη διαγραφή των πληροφοριών σας, παρακαλούμε επικοινωνήστε με την ομάδα υποστήριξής μας - office@acedata.cloud.

4. **Απόρριψη**: Επιλέξτε να μην λαμβάνετε τις προωθητικές μας επικοινωνίες ακολουθώντας τις οδηγίες διαγραφής που περιλαμβάνονται σε αυτές τις επικοινωνίες.

## Πολιτική δεδομένων χρήστη Google API (Περιορισμένη χρήση)

Όταν επιλέγετε να συνδέσετε το Ace Data Cloud με υπηρεσίες Google (συμπεριλαμβανομένων των Google Workspace API, Google Drive, Gmail, Google Calendar κ.ά.), η χρήση και μεταφορά οποιωνδήποτε πληροφοριών λαμβάνονται από το Google API συμμορφώνεται πλήρως με την [Πολιτική δεδομένων χρήστη Google API](https://developers.google.com/terms/api-services-user-data-policy), συμπεριλαμβανομένων των απαιτήσεων **Περιορισμένης Χρήσης (Limited Use)**. Συγκεκριμένα:

1. **Χρήση μόνο για τις λειτουργίες που ζητάτε**: Προσπελαύνουμε τα δεδομένα σας Google μόνο όταν ενεργοποιείτε ενεργά μια λειτουργία (π.χ. ανάγνωση αρχείων Drive, αποστολή προσκλήσεων ημερολογίου, οργάνωση μηνυμάτων Gmail) και μόνο για την υλοποίηση αυτής της λειτουργίας.

2. **Δεν χρησιμοποιούνται για διαφήμιση**: Δεν χρησιμοποιούμε ποτέ τα δεδομένα που λαμβάνονται από το Google API για διαφημιστικούς σκοπούς, στόχευση διαφημίσεων ή μάρκετινγκ τρίτων.

3. **Δεν πωλούνται σε τρίτους**: Δεν πουλάμε ποτέ τα δεδομένα χρηστών που λαμβάνονται από το Google API.

4. **Δεν μεταβιβάζονται σε τρίτους**: Δεν μεταβιβάζουμε τα δεδομένα που λαμβάνονται από το Google API σε άλλους, εκτός αν: (α) είναι απαραίτητο για την παροχή ή βελτίωση λειτουργιών απευθείας προς τον χρήστη· (β) για λόγους ασφαλείας (π.χ. διερεύνηση κατάχρησης)· (γ) για συμμόρφωση με το νόμο· ή (δ) ως μέρος συγχώνευσης, εξαγοράς ή πώλησης περιουσιακών στοιχείων, με επιβεβαίωση και συναίνεση του χρήστη.

5. **Απαγόρευση χειροκίνητης ανάγνωσης**: Δεν επιτρέπουμε σε κανένα ανθρώπινο προσωπικό να διαβάζει τα δεδομένα που λαμβάνονται από το Google API, εκτός αν: (α) έχει λάβει ρητή συγκατάθεσή σας· (β) για λόγους ασφαλείας (π.χ. διερεύνηση κατάχρησης)· (γ) για συμμόρφωση με το νόμο· ή (δ) τα δεδομένα έχουν συγκεντρωθεί και ανωνυμοποιηθεί και χρησιμοποιούνται μόνο για εσωτερική λειτουργία.

Εάν επιθυμείτε να ανακαλέσετε οποιαδήποτε στιγμή την πρόσβαση του Ace Data Cloud στον λογαριασμό σας Google, μπορείτε να το κάνετε μέσω της σελίδας [Εφαρμογές συνδεδεμένες με τον λογαριασμό Google](https://myaccount.google.com/connections).
