## Επισκόπηση

Η δημιουργία βίντεο με AI είναι η πιο δημοφιλής κατεύθυνση τεχνολογίας AI για το 2024-2025. Μέσω του Ace Data Cloud, μπορείτε να χρησιμοποιήσετε διάφορα μοντέλα δημιουργίας βίντεο όπως Sora, Luma, Kling, για να δημιουργήσετε μια αυτοματοποιημένη ροή παραγωγής βίντεο.

## Εμπλεκόμενες Υπηρεσίες

- **Sora**: `POST https://api.acedata.cloud/sora/videos`
- **Luma**: `POST https://api.acedata.cloud/luma/videos`
- **Kling**: `POST https://api.acedata.cloud/kling/videos`

## Τεχνική Λύση

### Προαπαιτούμενα

1. Εγγραφή λογαριασμού στο [Ace Data Cloud](https://platform.acedata.cloud)
2. Απόκτηση API Token
3. Εγκατάσταση Python 3.7+ και της βιβλιοθήκης requests

### Βήματα Υλοποίησης

### Βήμα 1: Επιλογή Μοντέλου Βίντεο

Το Sora είναι κατάλληλο για ποιότητα κινηματογραφικού επιπέδου, το Luma υποστηρίζει έλεγχο των αρχικών και τελικών καρέ, ενώ το Kling προσφέρει γρήγορη δημιουργία.

### Βήμα 2: Υποβολή Εργασίας Δημιουργίας

Το Sora χρησιμοποιεί το `/sora/videos`, το Luma το `/luma/videos` και το Kling το `/kling/videos`.

### Βήμα 3: Έλεγχος Κατάστασης Εργασίας

Όλα τα API βίντεο υποστηρίζουν την παρακολούθηση προόδου μέσω του endpoint `/tasks`.

## Παράδειγμα Κώδικα

Παρακάτω είναι ένα πλήρες παράδειγμα Python που χρησιμοποιεί το Sora:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_sora():
    response = requests.post(
        "https://api.acedata.cloud/sora/videos",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
},
    )
    return response.json()

result = call_sora()
print(result)
```

## Καλές Πρακτικές

- **Επαναπροσπάθεια σε Σφάλματα**: Εφαρμογή εκθετικής υποχώρησης σε σφάλματα 429 (περιορισμός ρυθμού) και 5xx
- **Ασύγχρονη Διαχείριση**: Για χρονοβόρες εργασίες (δημιουργία εικόνων/βίντεο), χρήση callback_url για ασύγχρονη λήψη αποτελεσμάτων
- **Έλεγχος Κόστους**: Παρακολούθηση χρήσης και κόστους μέσω του πίνακα ελέγχου του Ace Data Cloud
- **Ασφάλεια Token**: Αποθήκευση του API Token σε μεταβλητές περιβάλλοντος, αποφυγή σκληροκωδικοποίησης στον κώδικα
