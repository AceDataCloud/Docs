## Τι είναι το OpenAI Συμβατό Interface

Η μορφή του Chat Completions API της OpenAI έχει γίνει το de facto πρότυπο της βιομηχανίας. Πολλά μεγάλα γλωσσικά μοντέλα προσφέρουν διεπαφές συμβατές με το OpenAI, επιτρέποντας στους προγραμματιστές να χρησιμοποιούν τον ίδιο κώδικα για πρόσβαση σε διαφορετικά μοντέλα.

Η Ace Data Cloud παρέχει OpenAI συμβατές διεπαφές Chat Completions για μοντέλα όπως Claude, Gemini, DeepSeek, Grok, Kimi κ.ά., όπου η αλλαγή της βασικής διεύθυνσης URL και του ονόματος του μοντέλου αρκεί για να γίνει η εναλλαγή.

## Υποστηριζόμενα Μοντέλα

| Υπηρεσία | Endpoint | Παραδείγματα Μοντέλων |
|----------|----------|----------------------|
| Claude   | `POST /v1/chat/completions` | claude-sonnet-4-6 |
| OpenAI   | `POST /openai/chat/completions` | gpt-4o |
| Gemini   | `POST /gemini/chat/completions` | gemini-2.5-flash |
| DeepSeek | `POST /deepseek/chat/completions` | deepseek-r1 |
| Grok     | `POST /grok/chat/completions` | grok-3 |
| Kimi     | `POST /kimi/chat/completions` | kimi-k2.5 |

## Ενιαίος Τρόπος Κλήσης

Όλα τα μοντέλα συνομιλίας χρησιμοποιούν το ίδιο φορμάτ αιτήματος:

```python
import requests

def chat(endpoint, model, message):
    return requests.post(
        f"https://api.acedata.cloud{endpoint}",
        headers={
            "Authorization": "Bearer YOUR_API_TOKEN",
            "Content-Type": "application/json",
        },
        json={
            "model": model,
            "messages": [{"role": "user", "content": message}],
            "max_tokens": 1024,
            "temperature": 0.7,
        },
    ).json()

# Κλήση διαφορετικών μοντέλων - αρκεί να αλλάξετε endpoint και όνομα μοντέλου
claude = chat("/v1/chat/completions", "claude-sonnet-4-6", "你好")
gpt = chat("/openai/chat/completions", "gpt-4o", "你好")
gemini = chat("/gemini/chat/completions", "gemini-2.5-flash", "你好")
deepseek = chat("/deepseek/chat/completions", "deepseek-r1", "你好")
```

## Ροή Εξόδου (Streaming)

Όλα τα API συνομιλίας υποστηρίζουν ροή εξόδου (Server-Sent Events):

```python
data = {
    "model": "claude-sonnet-4-6",
    "messages": [{"role": "user", "content": "写一首诗"}],
    "stream": True,
}

response = requests.post(
    "https://api.acedata.cloud/v1/chat/completions",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json=data,
    stream=True,
)

for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Συμβατότητα με το OpenAI SDK

Εξαιτίας της συμβατότητας της διεπαφής, μπορείτε να χρησιμοποιήσετε απευθείας το επίσημο OpenAI SDK, απλώς αλλάζοντας το base_url:

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_TOKEN",
    base_url="https://api.acedata.cloud/v1",  # Claude
    # base_url="https://api.acedata.cloud/openai",  # OpenAI
    # base_url="https://api.acedata.cloud/gemini",  # Gemini
)

response = client.chat.completions.create(
    model="claude-sonnet-4-6",
    messages=[{"role": "user", "content": "你好"}],
)
print(response.choices[0].message.content)
```
