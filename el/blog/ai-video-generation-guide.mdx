## Επισκόπηση

Η δημιουργία βίντεο με AI αναπτύσσεται ραγδαία. Η Ace Data Cloud προσφέρει 7 τύπους API δημιουργίας βίντεο, καλύπτοντας σενάρια από κείμενο σε βίντεο έως εικόνα σε βίντεο.

## Διαθέσιμες Υπηρεσίες Δημιουργίας Βίντεο

| Υπηρεσία | Endpoint | Μοντέλο | Χαρακτηριστικά |
|----------|----------|---------|----------------|
| Sora     | `POST /sora/videos` | sora-2, sora-2-pro | Παραγωγή OpenAI, ποιότητα κινηματογραφική |
| Veo      | `POST /veo/videos`  | veo3, veo3-fast | Παραγωγή Google, υποστήριξη 4K |
| Kling    | `POST /kling/videos`| kling-v2-5-turbo | Παραγωγή Kuaishou, γρήγορη ταχύτητα |
| Luma     | `POST /luma/videos` | —       | Έλεγχος πρώτου και τελευταίου καρέ |
| Hailuo   | `POST /hailuo/videos`| minimax-t2v | Παραγωγή MiniMax |
| Seedance | `POST /seedance/videos` | doubao-seedance-1-0-pro-250528 | Παραγωγή ByteDance |
| Wan      | `POST /wan/videos`  | wan2.6-t2v | Παραγωγή Alibaba |

## Γρήγορη Εκκίνηση

### Δημιουργία Βίντεο με Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A cat playing in a sunny garden",
        "model": "sora-2",
        "duration": 10,
        "orientation": "landscape",
    },
)
print(response.json())
```

### Δημιουργία Βίντεο με Kling

```python
response = requests.post(
    "https://api.acedata.cloud/kling/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A white cat walking in the snow",
        "model": "kling-v2-5-turbo",
        "duration": 5,
        "aspect_ratio": "16:9",
    },
)
print(response.json())
```

### Δημιουργία Βίντεο με Veo

```python
response = requests.post(
    "https://api.acedata.cloud/veo/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",

```

## Διαχείριση Ασύγχρονων Εργασιών

Η δημιουργία βίντεο συνήθως απαιτεί χρόνο. Όλα τα API βίντεο υποστηρίζουν:

1. **Ειδοποίηση μέσω Callback**: Ορισμός `callback_url` στο αίτημα, για αυτόματη αποστολή αποτελέσματος μετά την ολοκλήρωση
2. **Polling**: Ερώτηση προόδου εργασίας μέσω του endpoint `/tasks`

```python
# Χρήση callback URL
data = {
    "prompt": "A sunrise over mountains",
    "model": "sora-2",
    "callback_url": "https://your-server.com/webhook",
}

# Ή polling κατάστασης εργασίας
task_response = requests.post("https://api.acedata.cloud/sora/tasks",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json={"task_id": "your-task-id"})
```
