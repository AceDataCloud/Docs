## Τι είναι το MCP

Το Model Context Protocol (MCP) είναι ένα ανοιχτό πρωτόκολλο που επιτρέπει σε βοηθούς AI (όπως Claude, Cursor) να καλούν απευθείας εξωτερικά εργαλεία και API. Μέσω του MCP, το AI δεν περιορίζεται μόνο στην απάντηση ερωτήσεων, αλλά μπορεί να εκτελεί και πραγματικές ενέργειες.

## MCP Server που παρέχεται από το Ace Data Cloud

| MCP Server | Όνομα πακέτου PyPI | Λειτουργία |
|------------|--------------------|------------|
| MCPSuno | mcp-suno | Δημιουργία μουσικής AI |
| MCPSerp | mcp-serp | Αναζήτηση Google |
| MCPMidjourney | mcp-midjourney | Δημιουργία εικόνων AI |
| MCPLuma | mcp-luma | Δημιουργία βίντεο AI |
| MCPSora | mcp-sora | Δημιουργία βίντεο AI |
| MCPVeo | mcp-veo | Δημιουργία βίντεο AI |
| MCPNanoBanana | mcp-nano-banana | Δημιουργία εικόνων AI |

## Εγκατάσταση και Χρήση

### Εγκατάσταση

```bash
pip install mcp-suno  # ή άλλο MCP Server
```

### Ρύθμιση μεταβλητών περιβάλλοντος

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### Ρύθμιση στο Cursor

Προσθέστε στις ρυθμίσεις MCP του Cursor:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### Ρύθμιση στο Claude Desktop

Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop και προσθέστε τη διαμόρφωση MCP Server.

## Σενάρια Χρήσης

1. **Δημιουργία μουσικής στο Cursor**: Πείτε στο AI "Δημιούργησε ένα χαρούμενο τραγούδι με το Suno" και το AI θα καλέσει απευθείας το API  
2. **Αναζήτηση σε πραγματικό χρόνο**: Το AI μπορεί να αναζητήσει τις πιο πρόσφατες πληροφορίες μέσω του MCP Server SERP  
3. **Δημιουργία υλικού έργου**: Το AI μπορεί να καλέσει το Midjourney για να δημιουργήσει εικόνες που χρειάζονται για το έργο

## MCP έναντι Άμεσης Κλήσης API

- **MCP**: Κατάλληλο για χρήση σε εργαλεία προγραμματισμού AI, όπου το AI καλεί αυτόματα  
- **API**: Κατάλληλο για ενσωμάτωση σε δικές σας εφαρμογές με προγραμματιστικό έλεγχο

Και οι δύο χρησιμοποιούν το ίδιο Ace Data Cloud API Token και καλούν τα ίδια API endpoints.

## Σύνοψη

Το MCP επιτρέπει στους βοηθούς AI να καλούν απευθείας διάφορα API του Ace Data Cloud. Όλοι οι MCP Servers έχουν δημοσιευτεί στο PyPI, η εγκατάσταση και ρύθμιση είναι απλή, κάνοντας τα εργαλεία AI σας πιο ισχυρά.

Επισκεφθείτε το [platform.acedata.cloud](https://platform.acedata.cloud) για να αποκτήσετε το API Token σας.
