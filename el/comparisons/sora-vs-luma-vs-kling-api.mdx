## Αναλυτική ανάλυση

### Λειτουργίες

Τα Sora, Luma και Kling καλούνται μέσω της ενοποιημένης πλατφόρμας API του Ace Data Cloud, υποστηρίζοντας τυπικό REST interface και πιστοποίηση Bearer Token.

**Sora** κύριο endpoint: `POST https://api.acedata.cloud/sora/videos`, υποστηρίζει δημιουργία βίντεο από κείμενο, διάφορες διάρκειες, οριζόντια/κάθετη προβολή, έλεγχο χαρακτήρων κ.ά. Παρέχει επίσης endpoints όπως `/sora/tasks`.

**Luma** κύριο endpoint: `POST https://api.acedata.cloud/luma/videos`, υποστηρίζει δημιουργία βίντεο από κείμενο, δημιουργία βίντεο από εικόνα, συνέχεια βίντεο, έλεγχο πρώτου και τελευταίου καρέ κ.ά. Παρέχει επίσης endpoints όπως `/luma/tasks`.

**Kling** κύριο endpoint: `POST https://api.acedata.cloud/kling/videos`, υποστηρίζει δημιουργία βίντεο από κείμενο, δημιουργία βίντεο από εικόνα, συνέχεια βίντεο, διάφορες διάρκειες κ.ά. Παρέχει επίσης endpoints όπως `/kling/tasks`, `/kling/motion`.

## Παραδείγματα κώδικα

Τα παρακάτω παραδείγματα δείχνουν πώς να καλέσετε τα Sora, Luma και Kling μέσω του Ace Data Cloud API. Όλα τα αιτήματα χρησιμοποιούν το ίδιο Base URL (`https://api.acedata.cloud`) και μέθοδο πιστοποίησης.

### Κλήση Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
},
)
print(response.json())
```
