[MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι το πρωτόκολλο μοντέλου συμφραζομένων που προτάθηκε από την Anthropic, επιτρέποντας στα AI μοντέλα (όπως Claude, GPT κ.λπ.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένων διεπαφών. Μέσω του Suno MCP Server που παρέχεται από το AceData Cloud, μπορείτε να δημιουργήσετε μουσική, στίχους και να διαχειριστείτε ηχητικά έργα απευθείας σε AI πελάτες όπως Claude Desktop, VS Code, Cursor κ.λπ.

## Επισκόπηση Λειτουργιών

Ο Suno MCP Server προσφέρει τις εξής βασικές λειτουργίες:

- **Δημιουργία μουσικής** — Δημιουργία AI μουσικής μέσω κειμενικών υποδείξεων
- **Προσαρμοσμένη δημιουργία** — Πλήρης έλεγχος στους στίχους, τον τίτλο και το μουσικό στυλ
- **Συνέχεια τραγουδιού** — Συνεχίστε από οποιοδήποτε σημείο μια υπάρχουσα μουσική
- **Διασκευή/Μίξη** — Δημιουργία διασκευών σε διαφορετικά στυλ
- **Δημιουργία στίχων** — Δημιουργία δομημένων στίχων βάσει περιγραφής
- **Φωνητικοί ρόλοι** — Αποθήκευση και επαναχρησιμοποίηση στυλ φωνής
- **Μετατροπή μέσων** — Λήψη MP4, WAV, MIDI, απομόνωση φωνής κ.λπ.
- **Βελτιστοποίηση στυλ** — Βελτιστοποίηση ετικετών μουσικού στυλ
- **Ερωτήματα εργασιών** — Παρακολούθηση προόδου δημιουργίας και λήψη αποτελεσμάτων

## Προαπαιτούμενα

Πριν τη χρήση, πρέπει να αποκτήσετε το AceData Cloud API Token:

1. Εγγραφείτε ή συνδεθείτε στην [πλατφόρμα AceData Cloud](https://platform.acedata.cloud)
2. Μεταβείτε στη σελίδα [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Κάντε κλικ στο «Acquire» για να αποκτήσετε το API Token (η πρώτη αίτηση προσφέρει δωρεάν πιστώσεις)

## Εγκατάσταση και Ρύθμιση

### Μέθοδος 1: Εγκατάσταση με pip (συνιστάται)

```bash
pip install mcp-suno
```

### Μέθοδος 2: Εγκατάσταση από πηγή

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

Αφού ολοκληρωθεί η εγκατάσταση, μπορείτε να χρησιμοποιήσετε την εντολή `mcp-suno` για να ξεκινήσετε την υπηρεσία.

## Χρήση στο Claude Desktop

Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Προσθέστε την παρακάτω ρύθμιση:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αν χρησιμοποιείτε το `uvx` (χωρίς να χρειάζεται να εγκαταστήσετε πακέτα εκ των προτέρων):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αποθηκεύστε τις ρυθμίσεις και επανεκκινήστε το Claude Desktop για να χρησιμοποιήσετε τα σχετικά εργαλεία Suno στη συνομιλία.

## Χρήση στο VS Code / Cursor

Δημιουργήστε το αρχείο `.vscode/mcp.json` στον ριζικό φάκελο του έργου:

```json
{
  "servers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Ή χρησιμοποιήστε το `uvx`:

```json
{
  "servers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

## Λίστα Διαθέσιμων Εργαλείων

| Όνομα εργαλείου                  | Περιγραφή           |
| ---------------------------- | ------------ |
| `suno_generate_music`        | Δημιουργία μουσικής μέσω κειμενικών υποδείξεων  |
| `suno_generate_custom_music` | Δημιουργία μουσικής με προσαρμοσμένους στίχους και στυλ |
| `suno_extend_music`          | Συνέχεια τραγουδιού από καθορισμένο σημείο   |
| `suno_cover_music`           | Δημιουργία διασκευής       |
| `suno_concat_music`          | Σύνθεση κομματιών       |
| `suno_generate_with_persona` | Δημιουργία μουσικής με καθορισμένο φωνητικό ρόλο |
| `suno_remaster_music`        | Επαναληπτική επεξεργασία       |
| `suno_stems_music`           | Διαχωρισμός ηχογραφημάτων (φωνή/συνοδεία)  |
| `suno_replace_section`       | Αντικατάσταση καθορισμένου τμήματος τραγουδιού   |
| `suno_upload_extend`         | Ανέβασμα ήχου και συνέχεια      |
| `suno_upload_cover`          | Ανέβασμα ήχου και διασκευή      |
| `suno_mashup_music`          | Μίξη πολλών τραγουδιών       |
| `suno_generate_lyrics`       | Δημιουργία στίχων βάσει περιγραφής     |
| `suno_create_persona`        | Δημιουργία φωνητικού ρόλου       |
| `suno_get_mp4`               | Λήψη MP4 βίντεο τραγουδιού  |
| `suno_get_timing`            | Λήψη χρονοδιαγράμματος στίχων      |
| `suno_extract_vocals`        | Εξαγωγή φωνής         |
| `suno_get_wav`               | Λήψη υψηλής ποιότητας WAV    |
| `suno_get_midi`              | Λήψη αρχείου MIDI   |
| `suno_optimize_style`        | Βελτιστοποίηση ετικετών μουσικού στυλ     |
| `suno_mashup_lyrics`         | Μίξη στίχων         |
| `suno_upload_audio`          | Ανέβασμα προσαρμοσμένου ήχου      |
| `suno_get_task`              | Έλεγχος κατάστασης μεμονωμένης εργασίας     |
| `suno_get_tasks_batch`       | Μαζικός έλεγχος κατάστασης εργασιών     |

## Παραδείγματα Χρήσης

Αφού ολοκληρωθούν οι ρυθμίσεις, μπορείτε να καλέσετε αυτές τις λειτουργίες απευθείας με φυσική γλώσσα στους AI πελάτες, για παράδειγμα:

- «Βοήθησέ με να δημιουργήσω ένα ποπ τραγούδι για το καλοκαίρι»
- «Διασκεύασε αυτό το τραγούδι σε τζαζ στυλ»
- «Συνέχισε αυτό το τραγούδι από το 30ο δευτερόλεπτο»
- «Δημιούργησε στίχους στα κινέζικα με θέμα το ταξίδι»
- «Διαχώρισε τη φωνή από αυτό το τραγούδι»
- «Βοήθησέ με να μετατρέψω αυτό το τραγούδι σε μορφή MIDI»
