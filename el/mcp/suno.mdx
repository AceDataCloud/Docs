Το [MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι ένα πρωτόκολλο περιβάλλοντος μοντέλου που κυκλοφόρησε από την Anthropic και επιτρέπει σε μοντέλα AI (όπως Claude, GPT κ.λπ.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένων διεπαφών. Μέσω του Suno MCP Server που παρέχεται από το AceData Cloud, μπορείτε να δημιουργείτε απευθείας μουσική, στίχους και να διαχειρίζεστε έργα ήχου σε προγράμματα-πελάτες AI όπως Claude Desktop, VS Code, Cursor κ.λπ.

## Επισκόπηση λειτουργιών

Ο Suno MCP Server παρέχει τις ακόλουθες βασικές λειτουργίες:

- **Δημιουργία μουσικής** — Δημιουργία μουσικής AI μέσω προτροπών κειμένου
- **Προσαρμοσμένη δημιουργία** — Πλήρης έλεγχος των στίχων, του τίτλου και του μουσικού ύφους
- **Συνέχιση τραγουδιού** — Συνέχιση και επέκταση ενός υπάρχοντος τραγουδιού από οποιοδήποτε χρονικό σημείο
- **Διασκευή/μίξη** — Δημιουργία εκδόσεων διασκευής με διαφορετικά ύφη
- **Δημιουργία στίχων** — Δημιουργία δομημένων στίχων βάσει περιγραφής
- **Ρόλοι φωνής** — Αποθήκευση και επαναχρησιμοποίηση φωνητικών στυλ
- **Μετατροπή πολυμέσων** — Λήψη MP4, WAV, MIDI, διαχωρισμένων φωνητικών κ.λπ.
- **Βελτιστοποίηση ύφους** — Βελτιστοποίηση ετικετών μουσικού ύφους
- **Ερώτημα εργασιών** — Παρακολούθηση της προόδου δημιουργίας και λήψη αποτελεσμάτων

## Προετοιμασία

Πριν από τη χρήση, πρέπει να αποκτήσετε ένα AceData Cloud API Token:

1. Εγγραφείτε ή συνδεθείτε στην [πλατφόρμα AceData Cloud](https://platform.acedata.cloud)
2. Μεταβείτε στη σελίδα [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Κάντε κλικ στο «Acquire» για να αποκτήσετε API Token (η πρώτη αίτηση περιλαμβάνει δωρεάν μονάδες)

## Μέθοδος 1: Χρήση φιλοξενούμενου MCP Server (συνιστάται, χωρίς εγκατάσταση)

Το AceData Cloud έχει ήδη φιλοξενήσει τον **Suno MCP Server** στο cloud, **χωρίς να απαιτείται η τοπική εγκατάσταση οποιωνδήποτε εξαρτήσεων**. Απλώς συμπληρώστε το παρακάτω URL στο πρόγραμμα-πελάτη AI για να τον χρησιμοποιήσετε:

```
https://suno.mcp.acedata.cloud/mcp
```

Μέθοδος πιστοποίησης: απλώς προσθέστε `Authorization: Bearer το API Token σας` στην κεφαλίδα αιτήματος (το Claude.ai το ολοκληρώνει αυτόματα μέσω OAuth, χωρίς να χρειάζεται να συμπληρώσετε χειροκίνητα Token).

### Claude.ai (έκδοση web, σύνδεση OAuth, το απλούστερο)

1. Ανοίξτε το [Claude.ai](https://claude.ai) → κάτω αριστερά **Customize** → **Connectors** → **Add More**
2. Στο URL συμπληρώστε: `https://suno.mcp.acedata.cloud/mcp`
3. Ολοκληρώστε τη σύνδεση εξουσιοδότησης OAuth (αυτόματη ανακατεύθυνση στη σελίδα σύνδεσης του AceData Cloud)
4. Επιστρέψτε στη διεπαφή συνομιλίας και το εργαλείο θα είναι διαθέσιμο για χρήση

### Claude Desktop

Επεξεργαστείτε το αρχείο διαμόρφωσης:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Αποθηκεύστε και επανεκκινήστε το Claude Desktop για να εφαρμοστούν οι αλλαγές.

### Claude Code (τερματικό γραμμής εντολών)

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Άλλα προγράμματα-πελάτες που υποστηρίζουν MCP

Οποιοδήποτε πρόγραμμα-πελάτης που υποστηρίζει το πρωτόκολλο MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant κ.λπ.) μπορεί να συνδεθεί συμπληρώνοντας τα ακόλουθα δύο στοιχεία:

- **URL**: `https://suno.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer το API Token σας`

## Μέθοδος 2: Τοπική εκτέλεση (εγκατάσταση pip / uvx)

Εάν χρειάζεστε εκτέλεση εκτός σύνδεσης, προσαρμοσμένο κώδικα ή ανάπτυξη σε εσωτερικό δίκτυο, μπορείτε να εγκαταστήσετε τον MCP Server τοπικά και να τον εκκινήσετε μέσω stdio.

### Εγκατάσταση

Εγκατάσταση με pip (συνιστάται):

```bash
pip install mcp-suno
```

Ή εγκατάσταση από τον πηγαίο κώδικα:

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

Μετά την ολοκλήρωση της εγκατάστασης, μπορείτε να χρησιμοποιήσετε την εντολή `mcp-suno` για να εκκινήσετε την υπηρεσία.

### Χρήση στο Claude Desktop (τοπικά)

Επεξεργαστείτε το αρχείο διαμόρφωσης του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Προσθέστε την ακόλουθη διαμόρφωση:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Εάν χρησιμοποιείτε `uvx` (δεν χρειάζεται να εγκαταστήσετε το πακέτο εκ των προτέρων):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Αποθηκεύστε τη διαμόρφωση και επανεκκινήστε το Claude Desktop για να εφαρμοστούν οι αλλαγές.

### Χρήση σε VS Code / Cursor (τοπικά)

## Παραδείγματα χρήσης

Αφού ολοκληρωθεί η διαμόρφωση, μπορείτε να καλείτε απευθείας αυτές τις λειτουργίες στον πελάτη AI χρησιμοποιώντας φυσική γλώσσα, για παράδειγμα:

- «Βοήθησέ με να δημιουργήσω ένα ποπ τραγούδι για το καλοκαίρι»
- «Κάνε μια διασκευή αυτού του τραγουδιού σε τζαζ ύφος»
- «Συνέχισε αυτό το τραγούδι, ξεκινώντας από το 30ό δευτερόλεπτο»
- «Δημιούργησε στίχους στα κινέζικα, με θέμα το ταξίδι»
- «Διαχώρισε τα φωνητικά από αυτό το τραγούδι»
- «Βοήθησέ με να μετατρέψω αυτό το τραγούδι σε μορφή MIDI»

## Προηγμένος έλεγχος και έργα Studio

Το `suno_generate_music` υποστηρίζει `variety`· το `suno_generate_custom_music` υποστηρίζει επιπλέον
`max_mode` και `audio_weight`. Το `max_mode` χρησιμοποιεί υψηλότερη βαθμίδα χρέωσης API, δεν ενεργοποιείται από προεπιλογή,
και θα πρέπει να ορίζεται αφού ο χρήστης επιλέξει ρητά ενισχυμένη λειτουργία. Οι τρέχουσες τιμές υπόκεινται στη σελίδα υπηρεσιών της πλατφόρμας.

Το `suno_generate_with_custom_model` μπορεί να χρησιμοποιήσει `instrumental=true` για τη δημιουργία καθαρής μουσικής ή να χρησιμοποιήσει
`lyric_prompt` για την αυτόματη δημιουργία στίχων· διαφορετικά παρέχεται `lyric`. Ο τίτλος και το ύφος μπορούν να παραλειφθούν, ενώ μπορούν επίσης να περαστούν
`negative_tags`, `vocal_gender`, `weirdness`, `style_influence`, `duration` και
`callback_url`. Οι ρητές τιμές ελέγχου `0` θα διατηρηθούν.

Το `request.action` του `suno_manage_project` μπορεί να είναι `create`, `retrieve`, `save`,
`upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`,
`remove_track`, `render`. Η είσοδος διαφέρει ανάλογα με την ενέργεια, και οι τροποποιήσεις του έργου θα πρέπει να χρησιμοποιούν το πιο πρόσφατα ανακτημένο `version_id`·
κατά την αποθήκευση, περάστε την πλήρη `state`, διατηρώντας τα υπάρχοντα κομμάτια και πεδία.

Εκτός από το `retrieve`, κάθε κλήση πρέπει να παρέχει `idempotency_key`. Για νέες ενέργειες εγγραφής χρησιμοποιήστε νέο κλειδί·
όταν υπάρχει χρονικό όριο ή το αποτέλεσμα αποδοχής είναι αβέβαιο, διατηρήστε το αρχικό κλειδί και επαναλάβετε με ακριβώς το ίδιο αίτημα, ή ελέγξτε την αρχική εργασία, χωρίς να
αλλάξετε αυτόματα κλειδί για να επαναστείλετε χρεώσιμη δημιουργία. Τα διαστήματα ήχου προέλευσης χρησιμοποιούν δευτερόλεπτα, ενώ τα διαστήματα χρονογραμμής του έργου χρησιμοποιούν αριθμό χτύπων. Η δημιουργία δημιουργεί μόνο υποψηφίους,
και απαιτείται η επιλογή υποψηφίου και η κλήση του `commit_candidate` για να εγγραφεί στο κομμάτι.

Το `task_id` ασύγχρονης αποδοχής ελέγχεται με το `suno_get_task`. Όταν το `finished_at` είναι κενό, συνεχίστε να περιμένετε,
και μετά την τελική κατάσταση ελέγξτε το `response.success` και τα σφάλματα· μην αντιμετωπίζετε την επιτυχία αποδοχής ως επιτυχία δημιουργίας, υποβολής ή εξαγωγής.
Το `suno_get_tasks_batch` επιστρέφει πλήρεις εγγραφές εργασιών JSON, διατηρώντας προσαρμοσμένα αντικείμενα μοντέλου, κατάσταση έργου,
υποψηφίους και κάθε είδους αποτελέσματα, συμπεριλαμβανομένων MIDI. Για την πλήρη ροή εργασίας, δείτε τον [Οδηγό έργων Studio](https://platform.acedata.cloud/documents/suno-projects-integration).
