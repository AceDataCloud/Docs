Το [MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι ένα πρωτόκολλο περιβάλλοντος μοντέλου που κυκλοφόρησε από την Anthropic, το οποίο επιτρέπει σε μοντέλα AI (όπως Claude, GPT κ.λπ.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένων διεπαφών. Μέσω του Flux MCP Server που παρέχεται από το AceData Cloud, μπορείτε να δημιουργείτε και να επεξεργάζεστε εικόνες AI απευθείας σε πελάτες AI όπως Claude Desktop, VS Code, Cursor κ.λπ.

## Επισκόπηση λειτουργιών

Ο Flux MCP Server παρέχει τις ακόλουθες βασικές λειτουργίες:

- **Δημιουργία εικόνας από κείμενο** — Δημιουργία εικόνων υψηλής ποιότητας μέσω προτροπών κειμένου
- **Επεξεργασία εικόνας** — Επεξεργασία υπαρχουσών εικόνων βάσει οδηγιών κειμένου
- **Υποστήριξη πολλαπλών μοντέλων** — Υποστήριξη διαφόρων μοντέλων, όπως Flux Pro, Flux Dev, Flux 2, Flux Kontext κ.λπ.
- **Ερώτημα μοντέλων** — Προβολή όλων των διαθέσιμων μοντέλων και των δυνατοτήτων τους
- **Ερώτημα εργασιών** — Παρακολούθηση της προόδου δημιουργίας και λήψη αποτελεσμάτων

## Προετοιμασία

Πριν από τη χρήση, πρέπει να αποκτήσετε ένα AceData Cloud API Token:

1. Εγγραφείτε ή συνδεθείτε στην [πλατφόρμα AceData Cloud](https://platform.acedata.cloud)
2. Μεταβείτε στη σελίδα [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Κάντε κλικ στο «Acquire» για να αποκτήσετε API Token (η πρώτη αίτηση περιλαμβάνει δωρεάν πίστωση)

## Μέθοδος 1: Χρήση φιλοξενούμενου MCP Server (συνιστάται, μηδενική εγκατάσταση)

Το AceData Cloud έχει ήδη φιλοξενήσει τον **Flux MCP Server** στο cloud, και **δεν απαιτείται να εγκαταστήσετε τοπικά οποιεσδήποτε εξαρτήσεις**. Απλώς συμπληρώστε το παρακάτω URL στον πελάτη AI για να τον χρησιμοποιήσετε:

```
https://flux.mcp.acedata.cloud/mcp
```

Μέθοδος πιστοποίησης: προσθέστε `Authorization: Bearer το API Token σας` στην κεφαλίδα αιτήματος (το Claude.ai ολοκληρώνει αυτόματα μέσω OAuth, χωρίς να χρειάζεται να συμπληρώσετε χειροκίνητα Token).

### Claude.ai (έκδοση web, σύνδεση OAuth, το απλούστερο)

1. Ανοίξτε το [Claude.ai](https://claude.ai) → κάτω αριστερά **Customize** → **Connectors** → **Add More**
2. Συμπληρώστε στο URL: `https://flux.mcp.acedata.cloud/mcp`
3. Ολοκληρώστε τη σύνδεση εξουσιοδότησης OAuth (αυτόματη ανακατεύθυνση στη σελίδα σύνδεσης AceData Cloud)
4. Επιστρέψτε στη διεπαφή συνομιλίας και το εργαλείο θα είναι διαθέσιμο για χρήση

### Claude Desktop

Επεξεργαστείτε το αρχείο ρυθμίσεων:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Αποθηκεύστε και επανεκκινήστε το Claude Desktop για να εφαρμοστούν οι ρυθμίσεις.

### Claude Code (γραμμή εντολών τερματικού)

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Άλλοι πελάτες που υποστηρίζουν MCP

Οποιοσδήποτε πελάτης που υποστηρίζει το πρωτόκολλο MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant κ.λπ.) μπορεί να συνδεθεί συμπληρώνοντας τα ακόλουθα δύο στοιχεία:

- **URL**: `https://flux.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer το API Token σας`

## Μέθοδος 2: Τοπική εκτέλεση (εγκατάσταση pip / uvx)

Εάν χρειάζεστε εκτέλεση εκτός σύνδεσης, προσαρμοσμένο κώδικα ή ανάπτυξη σε εσωτερικό δίκτυο, μπορείτε να εγκαταστήσετε τον MCP Server τοπικά και να τον εκκινήσετε μέσω stdio.

### Εγκατάσταση

Εγκατάσταση με pip (συνιστάται):

```bash
pip install mcp-flux-pro
```

Ή εγκατάσταση από τον πηγαίο κώδικα:

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Μετά την ολοκλήρωση της εγκατάστασης, μπορείτε να χρησιμοποιήσετε την εντολή `mcp-flux-pro` για να εκκινήσετε την υπηρεσία.

### Χρήση στο Claude Desktop (τοπικά)

Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Προσθέστε την ακόλουθη ρύθμιση:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Εάν χρησιμοποιείτε `uvx` (δεν απαιτείται προηγούμενη εγκατάσταση του πακέτου):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Αποθηκεύστε τη ρύθμιση και επανεκκινήστε το Claude Desktop για να εφαρμοστεί.

### Χρήση σε VS Code / Cursor (τοπικά)

## Λίστα διαθέσιμων εργαλείων

| Όνομα εργαλείου                    | Περιγραφή                       |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | Δημιουργία εικόνας μέσω προτροπής κειμένου              |
| `flux_edit_image`      | Επεξεργασία υπάρχουσας εικόνας βάσει οδηγιών κειμένου             |
| `flux_generate_video`  | Δημιουργία FLUX 3 από κείμενο/εικόνα/βίντεο και βελτίωση υπαρχόντων προσχεδίων |
| `flux_get_task`        | Ερώτημα κατάστασης μεμονωμένης εργασίας                 |
| `flux_get_tasks_batch` | Μαζικό ερώτημα κατάστασης εργασιών                 |
| `flux_list_models`     | Καταχώριση όλων των διαθέσιμων μοντέλων και των δυνατοτήτων τους             |
| `flux_list_actions`    | Καταχώριση όλων των διαθέσιμων εργαλείων και παραδειγμάτων ροής εργασίας           |

- «Βοήθησέ με να δημιουργήσω με το Flux μια αστική νυχτερινή σκηνή σε cyberpunk στυλ»

## Περιορισμοί μοντέλων και διαστάσεων
Τα μοντέλα `flux-2-flex`, `flux-2-pro`, `flux-2-max` και Kontext πρέπει να χρησιμοποιούν
αναλογία για το `size`, για παράδειγμα `1:1` ή `16:9`, και δεν μπορούν να χρησιμοποιούν διαστάσεις σε pixel όπως `1024x1024`.
Το `flux-2-klein` υποστηρίζει μόνο δημιουργία και δεν περιλαμβάνεται στα διαθέσιμα μοντέλα του `flux_edit_image`.

Το `flux_generate_video` διακρίνει τα `t2v`, `i2v`, `v2v` και
`draft_enhance` μέσω του `request.mode`, και οι είσοδοι εμφανίζονται ανάλογα με τη λειτουργία. Η βελτίωση προσχεδίου πρέπει να αναφέρεται στο δικό της προσωρινό `draft_task_id`.
Η υποβολή είναι ασύγχρονη από προεπιλογή· διατηρήστε το αναγνωριστικό εργασίας που επιστρέφεται και χρησιμοποιήστε το `flux_get_task` για να διαβάσετε τα αποτελέσματα.
