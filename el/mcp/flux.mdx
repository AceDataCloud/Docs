Το [MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι ένα πρωτόκολλο συμφραζομένων μοντέλου που έχει αναπτύξει η Anthropic, το οποίο επιτρέπει σε μοντέλα AI (όπως Claude, GPT κ.ά.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένης διεπαφής. Μέσω του Flux MCP Server που παρέχεται από το AceData Cloud, μπορείτε να δημιουργείτε και να επεξεργάζεστε AI εικόνες απευθείας σε πελάτες AI όπως Claude Desktop, VS Code, Cursor κ.ά.

## Επισκόπηση Λειτουργιών

Ο Flux MCP Server προσφέρει τις ακόλουθες βασικές λειτουργίες:

- **Δημιουργία εικόνων από κείμενο** — Δημιουργία υψηλής ποιότητας εικόνων μέσω κειμενικών εντολών
- **Επεξεργασία εικόνων** — Επεξεργασία υπαρχουσών εικόνων βάσει κειμενικών οδηγιών
- **Υποστήριξη πολλαπλών μοντέλων** — Υποστήριξη διαφόρων μοντέλων όπως Flux Pro, Flux Dev, Flux Schnell, Flux Kontext κ.ά.
- **Ερωτήματα μοντέλων** — Προβολή όλων των διαθέσιμων μοντέλων και των δυνατοτήτων τους
- **Ερωτήματα εργασιών** — Παρακολούθηση προόδου δημιουργίας και λήψη αποτελεσμάτων

## Προαπαιτούμενα

Πριν τη χρήση, χρειάζεται να αποκτήσετε το AceData Cloud API Token:

1. Εγγραφείτε ή συνδεθείτε στην [πλατφόρμα AceData Cloud](https://platform.acedata.cloud)
2. Μεταβείτε στη σελίδα [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Κάντε κλικ στο «Acquire» για να λάβετε το API Token (παρέχεται δωρεάν όριο στην πρώτη αίτηση)

## Εγκατάσταση και Ρύθμιση

### Μέθοδος 1: Εγκατάσταση με pip (Συνιστάται)

```bash
pip install mcp-flux-pro
```

### Μέθοδος 2: Εγκατάσταση από πηγαίο κώδικα

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Μετά την εγκατάσταση, μπορείτε να ξεκινήσετε την υπηρεσία με την εντολή `mcp-flux-pro`.

## Χρήση στο Claude Desktop

Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Προσθέστε την παρακάτω ρύθμιση:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Εάν χρησιμοποιείτε `uvx` (χωρίς ανάγκη προεγκατάστασης πακέτων):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αποθηκεύστε τις ρυθμίσεις και επανεκκινήστε το Claude Desktop για να χρησιμοποιήσετε τα εργαλεία Flux στις συνομιλίες.

## Λίστα Διαθέσιμων Εργαλείων

| Όνομα Εργαλείου          | Περιγραφή                            |
|--------------------------|------------------------------------|
| `flux_generate_image`     | Δημιουργία εικόνας από κειμενική εντολή |
| `flux_edit_image`         | Επεξεργασία υπάρχουσας εικόνας βάσει κειμένου |
| `flux_get_task`           | Ερώτημα κατάστασης μεμονωμένης εργασίας |
| `flux_get_tasks_batch`    | Μαζικό ερώτημα καταστάσεων εργασιών |
| `flux_list_models`        | Λίστα όλων των διαθέσιμων μοντέλων και δυνατοτήτων |
| `flux_list_actions`       | Λίστα όλων των διαθέσιμων εργαλείων και παραδειγμάτων ροών εργασίας |

## Παραδείγματα Χρήσης
