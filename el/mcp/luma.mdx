[MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι το πρωτόκολλο μοντέλου συμφραζομένων που προτάθηκε από την Anthropic, επιτρέποντας στα AI μοντέλα (όπως Claude, GPT κ.λπ.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένων διεπαφών. Μέσω του Luma MCP Server που παρέχεται από το AceData Cloud, μπορείτε να δημιουργήσετε απευθείας AI βίντεο σε AI πελάτες όπως Claude Desktop, VS Code, Cursor κ.λπ.

## Επισκόπηση Λειτουργιών

Ο Luma MCP Server προσφέρει τις εξής βασικές λειτουργίες:

- **Δημιουργία βίντεο από κείμενο** — Δημιουργία υψηλής ποιότητας βίντεο μέσω κειμενικών προτροπών
- **Δημιουργία βίντεο από εικόνα** — Δημιουργία βίντεο με αφετηρία ή προορισμό μια εικόνα
- **Συνέχεια βίντεο** — Συνέχεια από το τελευταίο καρέ ενός υπάρχοντος βίντεο
- **Πολλαπλές αναλογίες εικόνας** — Υποστήριξη αναλογιών 16:9, 9:16, 1:1 κ.λπ.
- **Ενίσχυση εικόνας** — Προαιρετική λειτουργία ενίσχυσης οπτικής ποιότητας
- **Ερώτηση εργασιών** — Παρακολούθηση προόδου δημιουργίας και λήψη αποτελεσμάτων

## Προαπαιτούμενα

Πριν τη χρήση, πρέπει να αποκτήσετε το AceData Cloud API Token:

1. Εγγραφείτε ή συνδεθείτε στην [πλατφόρμα AceData Cloud](https://platform.acedata.cloud)
2. Μεταβείτε στη σελίδα [Luma Videos API](https://platform.acedata.cloud/documents/luma-videos)
3. Κάντε κλικ στο «Acquire» για να αποκτήσετε το API Token (η πρώτη αίτηση προσφέρει δωρεάν πιστώσεις)

## Εγκατάσταση και Ρύθμιση

### Μέθοδος 1: Εγκατάσταση με pip (συνιστάται)

```bash
pip install mcp-luma
```

### Μέθοδος 2: Εγκατάσταση από πηγή

```bash
git clone https://github.com/AceDataCloud/LumaMCP.git
cd LumaMCP
pip install -e .
```

Αφού ολοκληρωθεί η εγκατάσταση, μπορείτε να χρησιμοποιήσετε την εντολή `mcp-luma` για να ξεκινήσετε την υπηρεσία.

## Χρήση στο Claude Desktop

Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Προσθέστε την παρακάτω ρύθμιση:

```json
{
  "mcpServers": {
    "luma": {
      "command": "mcp-luma",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αν χρησιμοποιείτε το `uvx` (χωρίς να χρειάζεται να εγκαταστήσετε πακέτο εκ των προτέρων):

```json
{
  "mcpServers": {
    "luma": {
      "command": "uvx",
      "args": ["mcp-luma"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αποθηκεύστε τις ρυθμίσεις και επανεκκινήστε το Claude Desktop, ώστε να μπορείτε να χρησιμοποιήσετε τα σχετικά εργαλεία Luma στη συνομιλία.

## Χρήση στο VS Code / Cursor

Δημιουργήστε το αρχείο `.vscode/mcp.json` στον ριζικό φάκελο του έργου:

```json
{
  "servers": {
    "luma": {
      "command": "mcp-luma",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Ή χρησιμοποιήστε το `uvx`:

```json
{
  "servers": {
    "luma": {
      "command": "uvx",
      "args": ["mcp-luma"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

## Λίστα διαθέσιμων εργαλείων

| Όνομα εργαλείου                       | Περιγραφή               |
| ----------------------------------- | --------------------- |
| `luma_generate_video`               | Δημιουργία βίντεο μέσω κειμενικών προτροπών    |
| `luma_generate_video_from_image`    | Δημιουργία βίντεο από εικόνα        |
| `luma_extend_video`                 | Συνέχεια υπάρχοντος βίντεο         |
| `luma_extend_video_from_url`        | Συνέχεια από βίντεο που καθορίζεται μέσω URL |
| `luma_get_task`                     | Ερώτηση κατάστασης μεμονωμένης εργασίας       |
| `luma_get_tasks_batch`              | Μαζική ερώτηση κατάστασης εργασιών       |

## Παραδείγματα χρήσης

Αφού ολοκληρωθούν οι ρυθμίσεις, μπορείτε να καλέσετε αυτές τις λειτουργίες απευθείας με φυσική γλώσσα στους AI πελάτες, όπως:

- «Βοήθησέ με να δημιουργήσω ένα βίντεο με ηλιοβασίλεμα στην παραλία»
- «Χρησιμοποίησε αυτή την εικόνα ως πρώτο καρέ, για να δημιουργήσεις ένα βίντεο 5 δευτερολέπτων»
- «Συνέχισε αυτό το βίντεο, επεκτείνοντάς το»
- «Δημιούργησε ένα βίντεο σε κατακόρυφη διάσταση, αναλογία 9:16»
