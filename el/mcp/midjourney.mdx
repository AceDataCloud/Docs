[MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι το πρωτόκολλο μοντέλου συμφραζομένων που προτάθηκε από την Anthropic, επιτρέποντας στα AI μοντέλα (όπως Claude, GPT κ.λπ.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένων διεπαφών. Μέσω του Midjourney MCP Server που παρέχεται από το AceData Cloud, μπορείτε να δημιουργείτε και να επεξεργάζεστε AI εικόνες απευθείας σε AI πελάτες όπως Claude Desktop, VS Code, Cursor κ.λπ.

## Επισκόπηση Λειτουργιών

Ο Midjourney MCP Server προσφέρει τις εξής βασικές λειτουργίες:

- **Δημιουργία εικόνας (Imagine)** — Δημιουργία υψηλής ποιότητας εικόνας μέσω κειμενικών προτροπών
- **Επεξεργασία εικόνας** — Τοπικές τροποποιήσεις σε ήδη δημιουργημένες εικόνες
- **Μετασχηματισμός εικόνας** — Μεγέθυνση, σμίκρυνση, μετακίνηση υπαρχουσών εικόνων
- **Μίξη εικόνας (Blend)** — Συνδυασμός πολλών εικόνων σε νέα εικόνα
- **Δημιουργία αναφοράς εικόνας** — Χρήση αναφοράς εικόνας για καθοδήγηση στη δημιουργία
- **Περιγραφή εικόνας (Describe)** — Δημιουργία κειμενικής περιγραφής βάσει εικόνας
- **Μετάφραση προτροπών** — Μετάφραση κινεζικών προτροπών στα αγγλικά
- **Απόκτηση σπόρου** — Απόκτηση της τιμής seed της εικόνας για αναπαραγωγή
- **Δημιουργία βίντεο** — Δημιουργία δυναμικού βίντεο βάσει εικόνας
- **Ερώτηση εργασιών** — Παρακολούθηση προόδου δημιουργίας και απόκτηση αποτελεσμάτων

## Προαπαιτούμενα

Πριν τη χρήση, πρέπει να αποκτήσετε το AceData Cloud API Token:

1. Εγγραφείτε ή συνδεθείτε στην [πλατφόρμα AceData Cloud](https://platform.acedata.cloud)
2. Μεταβείτε στη σελίδα [Midjourney Imagine API](https://platform.acedata.cloud/documents/midjourney-imagine)
3. Κάντε κλικ στο «Acquire» για να αποκτήσετε το API Token (η πρώτη αίτηση προσφέρει δωρεάν πίστωση)

## Εγκατάσταση και Ρύθμιση

### Μέθοδος 1: Εγκατάσταση με pip (συνιστάται)

```bash
pip install mcp-midjourney
```

### Μέθοδος 2: Εγκατάσταση από πηγή

```bash
git clone https://github.com/AceDataCloud/MCPMidjourney.git
cd MCPMidjourney
pip install -e .
```

Αφού ολοκληρωθεί η εγκατάσταση, μπορείτε να χρησιμοποιήσετε την εντολή `mcp-midjourney` για να ξεκινήσετε την υπηρεσία.

## Χρήση στο Claude Desktop

Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Προσθέστε την παρακάτω ρύθμιση:

```json
{
  "mcpServers": {
    "midjourney": {
      "command": "mcp-midjourney",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Εάν χρησιμοποιείτε το `uvx` (χωρίς να χρειάζεται να εγκαταστήσετε πακέτα εκ των προτέρων):

```json
{
  "mcpServers": {
    "midjourney": {
      "command": "uvx",
      "args": ["mcp-midjourney"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αποθηκεύστε τις ρυθμίσεις και επανεκκινήστε το Claude Desktop, ώστε να μπορείτε να χρησιμοποιήσετε τα σχετικά εργαλεία του Midjourney στη συνομιλία.

## Χρήση στο VS Code / Cursor

Δημιουργήστε το αρχείο `.vscode/mcp.json` στον ριζικό φάκελο του έργου:

```json
{
  "servers": {
    "midjourney": {
      "command": "mcp-midjourney",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Ή χρησιμοποιήστε το `uvx`:

```json
{
  "servers": {
    "midjourney": {
      "command": "uvx",
      "args": ["mcp-midjourney"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

## Λίστα διαθέσιμων εργαλείων

| Όνομα εργαλείου                  | Περιγραφή           |
| ---------------------------- | ------------ |
| `midjourney_imagine`         | Δημιουργία εικόνας μέσω κειμενικών προτροπών  |
| `midjourney_edit`            | Επεξεργασία τοπικών περιοχών σε υπάρχουσες εικόνες  |
| `midjourney_transform`       | Μεγέθυνση, σμίκρυνση, μετακίνηση υπαρχουσών εικόνων |
| `midjourney_blend`           | Συνδυασμός πολλών εικόνων σε μία   |
| `midjourney_with_reference`  | Δημιουργία εικόνας με χρήση αναφοράς    |
| `midjourney_describe`        | Δημιουργία κειμενικής περιγραφής βάσει εικόνας   |
| `midjourney_translate`       | Μετάφραση προτροπών στα αγγλικά     |
| `midjourney_get_seed`        | Απόκτηση της τιμής seed της εικόνας |
| `midjourney_generate_video`  | Δημιουργία βίντεο βάσει εικόνας     |
| `midjourney_extend_video`    | Επέκταση υπάρχοντος βίντεο       |
| `midjourney_get_task`        | Ερώτηση κατάστασης μεμονωμένης εργασίας     |
| `midjourney_get_tasks_batch` | Μαζική ερώτηση κατάστασης εργασιών     |

## Παραδείγματα χρήσης

Αφού ολοκληρωθούν οι ρυθμίσεις, μπορείτε να καλείτε αυτές τις λειτουργίες απευθείας με φυσική γλώσσα στους AI πελάτες, όπως:

- «Βοήθησέ με να δημιουργήσω μια εικόνα με στυλ cyberpunk μιας νυχτερινής πόλης»
- «Αλλάξτε το φόντο αυτής της εικόνας σε παραλία»
- «Συνδυάστε αυτές τις τέσσερις εικόνες σε μία»
- «Περιγράψτε το περιεχόμενο αυτής της εικόνας»
- «Δημιουργήστε ένα βίντεο από αυτή την εικόνα»
- «Μεγαλώστε τη δεύτερη παραλλαγή αυτής της εικόνας»
