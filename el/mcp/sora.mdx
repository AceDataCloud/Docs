[MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι το πρωτόκολλο μοντέλου συμφραζομένων που προτάθηκε από την Anthropic, επιτρέποντας στα AI μοντέλα (όπως Claude, GPT κ.λπ.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένων διεπαφών. Μέσω του Sora MCP Server που παρέχεται από το AceData Cloud, μπορείτε να χρησιμοποιήσετε απευθείας το OpenAI Sora για τη δημιουργία AI βίντεο σε AI πελάτες όπως Claude Desktop, VS Code, Cursor κ.λπ.

## Επισκόπηση Λειτουργιών

Ο Sora MCP Server παρέχει τις εξής βασικές λειτουργίες:

- **Δημιουργία βίντεο από κείμενο** — Δημιουργία βίντεο υψηλής ποιότητας μέσω κειμενικών προτροπών
- **Δημιουργία βίντεο από εικόνα** — Δημιουργία βίντεο με βάση εικόνες
- **Δημιουργία βίντεο με συνέπεια χαρακτήρα** — Διατήρηση συνέπειας χαρακτήρα χρησιμοποιώντας αναφορές εικόνας
- **Ασύγχρονη δημιουργία** — Υποστήριξη υποβολής ασύγχρονων εργασιών και ερωτήσεων αποτελεσμάτων
- **Πολλές κατευθύνσεις εικόνας** — Υποστήριξη οριζόντιας (landscape) και κατακόρυφης (portrait) διάταξης
- **Ερώτηση εργασιών** — Παρακολούθηση προόδου δημιουργίας και λήψη αποτελεσμάτων

## Προαπαιτούμενα

Πριν τη χρήση, πρέπει να αποκτήσετε το AceData Cloud API Token:

1. Εγγραφείτε ή συνδεθείτε στην [πλατφόρμα AceData Cloud](https://platform.acedata.cloud)
2. Μεταβείτε στη σελίδα [Sora Videos API](https://platform.acedata.cloud/documents/sora-videos)
3. Κάντε κλικ στο «Acquire» για να αποκτήσετε το API Token (η πρώτη αίτηση προσφέρει δωρεάν πιστώσεις)

## Εγκατάσταση και Ρύθμιση

### Μέθοδος 1: Εγκατάσταση με pip (συνιστάται)

```bash
pip install mcp-sora
```

### Μέθοδος 2: Εγκατάσταση από πηγή

```bash
git clone https://github.com/AceDataCloud/SoraMCP.git
cd SoraMCP
pip install -e .
```

Αφού ολοκληρωθεί η εγκατάσταση, μπορείτε να χρησιμοποιήσετε την εντολή `mcp-sora` για να ξεκινήσετε την υπηρεσία.

## Χρήση στο Claude Desktop

Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Προσθέστε την παρακάτω ρύθμιση:

```json
{
  "mcpServers": {
    "sora": {
      "command": "mcp-sora",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Εάν χρησιμοποιείτε το `uvx` (χωρίς να χρειάζεται να εγκαταστήσετε πακέτα εκ των προτέρων):

```json
{
  "mcpServers": {
    "sora": {
      "command": "uvx",
      "args": ["mcp-sora"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αποθηκεύστε τις ρυθμίσεις και επανεκκινήστε το Claude Desktop, ώστε να μπορείτε να χρησιμοποιήσετε τα σχετικά εργαλεία Sora στη συνομιλία.

## Χρήση στο VS Code / Cursor

Δημιουργήστε το αρχείο `.vscode/mcp.json` στον ριζικό φάκελο του έργου:

```json
{
  "servers": {
    "sora": {
      "command": "mcp-sora",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Ή χρησιμοποιήστε το `uvx`:

```json
{
  "servers": {
    "sora": {
      "command": "uvx",
      "args": ["mcp-sora"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

## Λίστα διαθέσιμων εργαλείων

| Όνομα εργαλείου                          | Περιγραφή                     |
| ------------------------------------ | --------------------------- |
| `sora_generate_video`                | Δημιουργία βίντεο μέσω κειμενικών προτροπών    |
| `sora_generate_video_from_image`     | Δημιουργία βίντεο με βάση εικόνες     |
| `sora_generate_video_with_character` | Δημιουργία βίντεο με συνέπεια χαρακτήρα χρησιμοποιώντας αναφορές εικόνας |
| `sora_generate_video_async`          | Ασύγχρονη υποβολή εργασιών δημιουργίας βίντεο     |
| `sora_get_task`                      | Ερώτηση κατάστασης μεμονωμένης εργασίας       |
| `sora_get_tasks_batch`               | Μαζική ερώτηση κατάστασης εργασιών       |

## Παραδείγματα χρήσης

Αφού ολοκληρωθούν οι ρυθμίσεις, μπορείτε να καλέσετε αυτές τις λειτουργίες απευθείας με φυσική γλώσσα στους AI πελάτες, όπως:

- «Βοήθησέ με να δημιουργήσω ένα βίντεο με μια γάτα να τρέχει στο γρασίδι με το Sora»
- «Δημιούργησε ένα βίντεο με αυτή τη φωτογραφία προσώπου, διατηρώντας τη συνέπεια του χαρακτήρα»
- «Δημιούργησε ένα κατακόρυφο βίντεο με θέμα την ανατολή του ήλιου στην πόλη»
- «Δημιούργησε ένα βίντεο ασύγχρονα και ρώτησε αργότερα για τα αποτελέσματα»
