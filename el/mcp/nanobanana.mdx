[MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι το πρωτόκολλο μοντέλου συμφραζομένων που προτάθηκε από την Anthropic, επιτρέποντας στα AI μοντέλα (όπως Claude, GPT κ.λπ.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένων διεπαφών. Μέσω του Nano Banana MCP Server που παρέχεται από το AceData Cloud, μπορείτε να δημιουργείτε και να επεξεργάζεστε AI εικόνες απευθείας σε AI πελάτες όπως Claude Desktop, VS Code, Cursor κ.λπ.

## Επισκόπηση Λειτουργιών

Ο Nano Banana MCP Server προσφέρει τις εξής βασικές λειτουργίες:

- **Δημιουργία εικόνας** — Δημιουργία υψηλής ποιότητας εικόνας μέσω κειμενικών προτροπών
- **Επεξεργασία εικόνας** — Τροποποίηση υπαρχουσών εικόνων ή συνδυασμός πολλών εικόνων
- **Εικονική δοκιμή ρούχων** — Τοποθέτηση ρούχων σε φωτογραφίες προσώπων
- **Ενσωμάτωση προϊόντων** — Τοποθέτηση προϊόντων σε πραγματικά σκηνικά
- **Υποστήριξη πολλών μοντέλων** — Υποστήριξη των μοντέλων nano-banana, nano-banana-2 και nano-banana-pro
- **Ερώτηση εργασιών** — Παρακολούθηση προόδου δημιουργίας και λήψη αποτελεσμάτων

## Προαπαιτούμενα

Πριν τη χρήση, πρέπει να αποκτήσετε το AceData Cloud API Token:

1. Εγγραφείτε ή συνδεθείτε στην [πλατφόρμα AceData Cloud](https://platform.acedata.cloud)
2. Μεταβείτε στη σελίδα [Nano Banana Images API](https://platform.acedata.cloud/documents/nano-banana-images)
3. Κάντε κλικ στο «Acquire» για να αποκτήσετε το API Token (η πρώτη αίτηση προσφέρει δωρεάν πιστώσεις)

## Εγκατάσταση και Ρύθμιση

### Μέθοδος 1: Εγκατάσταση με pip (συνιστάται)

```bash
pip install mcp-nanobanana-pro
```

### Μέθοδος 2: Εγκατάσταση από πηγή

```bash
git clone https://github.com/AceDataCloud/NanoBananaMCP.git
cd NanoBananaMCP
pip install -e .
```

Αφού ολοκληρωθεί η εγκατάσταση, μπορείτε να χρησιμοποιήσετε την εντολή `mcp-nanobanana-pro` για να ξεκινήσετε την υπηρεσία.

## Χρήση στο Claude Desktop

Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Προσθέστε την παρακάτω ρύθμιση:

```json
{
  "mcpServers": {
    "nanobanana": {
      "command": "mcp-nanobanana-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αν χρησιμοποιείτε το `uvx` (χωρίς να χρειάζεται να εγκαταστήσετε πακέτα εκ των προτέρων):

```json
{
  "mcpServers": {
    "nanobanana": {
      "command": "uvx",
      "args": ["mcp-nanobanana-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αποθηκεύστε τις ρυθμίσεις και επανεκκινήστε το Claude Desktop, ώστε να μπορείτε να χρησιμοποιήσετε τα σχετικά εργαλεία Nano Banana στη συνομιλία.

## Χρήση στο VS Code / Cursor

Δημιουργήστε το αρχείο `.vscode/mcp.json` στον ριζικό φάκελο του έργου:

```json
{
  "servers": {
    "nanobanana": {
      "command": "mcp-nanobanana-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Ή χρησιμοποιήστε το `uvx`:

```json
{
  "servers": {
    "nanobanana": {
      "command": "uvx",
      "args": ["mcp-nanobanana-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

## Λίστα διαθέσιμων εργαλείων

| Όνομα εργαλείου                  | Περιγραφή          |
| ---------------------------- | ----------- |
| `nanobanana_generate_image`  | Δημιουργία εικόνας μέσω κειμενικών προτροπών |
| `nanobanana_edit_image`      | Επεξεργασία ή συνδυασμός υπαρχουσών εικόνων   |
| `nanobanana_get_task`        | Ερώτηση κατάστασης μεμονωμένης εργασίας    |
| `nanobanana_get_tasks_batch` | Μαζική ερώτηση κατάστασης εργασιών    |

## Παραδείγματα χρήσης

Αφού ολοκληρωθούν οι ρυθμίσεις, μπορείτε να καλείτε αυτές τις λειτουργίες απευθείας με φυσική γλώσσα στους AI πελάτες, όπως:

- «Βοήθησέ με να δημιουργήσω μια εικόνα τοπίου σε στυλ υδατογραφίας»
- «Τοποθέτησε αυτό το ρούχο σε αυτή την φωτογραφία προσώπου»
- «Τοποθέτησε αυτό το προϊόν σε ένα σκηνικό καφετέριας»
- «Δημιούργησε μια υψηλής ποιότητας πορτραίτο με το μοντέλο nano-banana-pro»
