Το [MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι ένα πρωτόκολλο πλαισίου μοντέλου που έχει αναπτύξει η Anthropic, το οποίο επιτρέπει σε μοντέλα AI (όπως Claude, GPT κ.ά.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένων διεπαφών. Μέσω του Seedance MCP Server που παρέχεται από το AceData Cloud, μπορείτε να χρησιμοποιήσετε απευθείας το Seedance της ByteDance για δημιουργία AI βίντεο σε πελάτες AI όπως Claude Desktop, VS Code, Cursor κ.ά.

## Επισκόπηση Λειτουργιών

Ο Seedance MCP Server προσφέρει τις ακόλουθες βασικές λειτουργίες:

- **Δημιουργία βίντεο από κείμενο** — Δημιουργία βίντεο υψηλής ποιότητας μέσω κειμενικών εντολών
- **Δημιουργία βίντεο από εικόνα** — Δημιουργία βίντεο με βάση εικόνα ως αναφορά (πρωτότυπο καρέ, τελικό καρέ, πρότυπο εικόνας κ.ά.)
- **Υποστήριξη πολλαπλών μοντέλων** — Υποστήριξη Seedance 1.5 Pro, 1.0 Pro, 1.0 Lite και άλλων μοντέλων
- **Πολλαπλές αναλύσεις** — Υποστήριξη 480p, 720p, 1080p και άλλων αναλύσεων
- **Πολλαπλές αναλογίες εικόνας** — Υποστήριξη αναλογιών 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 κ.ά.
- **Ευέλικτη διάρκεια** — Υποστήριξη βίντεο διάρκειας 2-12 δευτερολέπτων
- **Δημιουργία ήχου** — Ορισμένα μοντέλα υποστηρίζουν ταυτόχρονη δημιουργία ήχου
- **Ερωτήματα εργασιών** — Παρακολούθηση προόδου δημιουργίας και λήψη αποτελεσμάτων

## Προαπαιτούμενα

Πριν τη χρήση, πρέπει να αποκτήσετε το AceData Cloud API Token:

1. Εγγραφείτε ή συνδεθείτε στην [Πλατφόρμα AceData Cloud](https://platform.acedata.cloud)
2. Μεταβείτε στη σελίδα [Seedance Videos API](https://platform.acedata.cloud/documents/seedance-videos)
3. Πατήστε «Acquire» για να λάβετε το API Token (η πρώτη αίτηση παρέχει δωρεάν όριο)

## Εγκατάσταση και Ρύθμιση

### Μέθοδος 1: Εγκατάσταση μέσω pip (συνιστάται)

```bash
pip install mcp-seedance
```

### Μέθοδος 2: Εγκατάσταση από πηγαίο κώδικα

```bash
git clone https://github.com/AceDataCloud/MCPSeedance.git
cd MCPSeedance
pip install -e .
```

Μετά την εγκατάσταση, μπορείτε να εκκινήσετε την υπηρεσία με την εντολή `mcp-seedance`.

## Χρήση στο Claude Desktop

Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Προσθέστε την παρακάτω ρύθμιση:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αν χρησιμοποιείτε `uvx` (χωρίς να απαιτείται προεγκατάσταση πακέτου):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αποθηκεύστε τις ρυθμίσεις και επανεκκινήστε το Claude Desktop για να χρησιμοποιήσετε τα εργαλεία Seedance στις συνομιλίες.

## Χρήση στο VS Code / Cursor

Δημιουργήστε το αρχείο `.vscode/mcp.json` στον ριζικό φάκελο του έργου:

```json
{

    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
```

Ή χρησιμοποιήστε `uvx`:

## Λίστα Διαθέσιμων Εργαλείων

| Όνομα Εργαλείου                  | Περιγραφή                         |
|---------------------------------|----------------------------------|
| `seedance_generate_video`        | Δημιουργία βίντεο από κείμενο    |
| `seedance_generate_video_from_image` | Δημιουργία βίντεο με βάση εικόνα |
| `seedance_get_task`              | Ερώτημα κατάστασης μεμονωμένης εργασίας |
| `seedance_get_tasks_batch`       | Μαζικό ερώτημα καταστάσεων εργασιών |
| `seedance_list_models`           | Λίστα διαθέσιμων μοντέλων και δυνατοτήτων |
| `seedance_list_resolutions`      | Λίστα διαθέσιμων αναλύσεων και αναλογιών εικόνας |
| `seedance_list_actions`          | Λίστα διαθέσιμων εργαλείων και παραδειγμάτων ροών εργασίας |

## Παραδείγματα Χρήσης

Αφού ολοκληρώσετε τη ρύθμιση, μπορείτε να καλέσετε αυτές τις λειτουργίες απευθείας με φυσική γλώσσα στους πελάτες AI, π.χ.:

- «Βοήθησέ με να δημιουργήσω ένα βίντεο timelapse αστικού δρόμου με το Seedance»
- «Χρησιμοποίησε αυτή την εικόνα ως πρώτο καρέ και δημιούργησε ένα βίντεο 8 δευτερολέπτων»
- «Δημιούργησε ένα βίντεο 1080p σε κατακόρυφη μορφή 9:16»
- «Χρησιμοποίησε το μοντέλο Seedance 1.5 Pro για να δημιουργήσεις βίντεο με ήχο»
