Το [MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι ένα πρωτόκολλο πλαισίου μοντέλου που κυκλοφόρησε από την Anthropic, το οποίο επιτρέπει σε μοντέλα AI (όπως Claude, GPT κ.λπ.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένων διεπαφών. Μέσω του Seedance MCP Server που παρέχεται από το AceData Cloud, μπορείτε να χρησιμοποιήσετε απευθείας το Seedance της ByteDance για τη δημιουργία βίντεο AI σε πελάτες AI όπως Claude Desktop, VS Code, Cursor κ.λπ.

## Επισκόπηση λειτουργιών

Ο Seedance MCP Server παρέχει τις ακόλουθες βασικές λειτουργίες:

- **Δημιουργία βίντεο από κείμενο** — Δημιουργία βίντεο υψηλής ποιότητας μέσω προτροπών κειμένου
- **Δημιουργία βίντεο από εικόνα** — Δημιουργία βίντεο με αναφορά σε εικόνες (λειτουργίες πρώτου καρέ, τελευταίου καρέ, εικόνας αναφοράς κ.λπ.)
- **Υποστήριξη πολλαπλών μοντέλων** — Υποστηρίζει Seedance 1.x, 1.5, 2.0 και 2.5
- **Πολλαπλές αναλύσεις** — Υποστηρίζει 480p, 720p, 1080p, ενώ ορισμένα μοντέλα υποστηρίζουν 4k
- **Πολλαπλές αναλογίες εικόνας** — Υποστηρίζει 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 και adaptive
- **Ευέλικτη διάρκεια** — 2–30 δευτερόλεπτα ή αυτόματη διάρκεια, ανάλογα με την υποστήριξη του μοντέλου
- **Πολυτροπικά βίντεο** — Υποστηρίζει δημιουργία ήχου, ήχο/βίντεο αναφοράς, καθώς και επεξεργασία και επέκταση βίντεο στο 2.5
- **Ερώτηση εργασιών** — Παρακολούθηση προόδου δημιουργίας και λήψη αποτελεσμάτων

## Προτεινόμενο: Εξουσιοδότηση OAuth με φιλοξενούμενο MCP

Προσθέστε τη διεύθυνση διακομιστή σε πελάτες που υποστηρίζουν απομακρυσμένο MCP OAuth:

```text
https://seedance.mcp.acedata.cloud/mcp
```

Επιλέξτε σύνδεση ή είσοδο, συνδεθείτε στο Ace Data Cloud, ελέγξτε τα δικαιώματα και εξουσιοδοτήστε, και στη συνέχεια ενεργοποιήστε τα εργαλεία. Αυτή η διαδρομή δεν απαιτεί να δημιουργήσετε ή να αντιγράψετε εκ των προτέρων API Token. Η υπηρεσία υποστηρίζει OAuth discovery, δυναμική εγγραφή πελάτη (DCR) και S256 PKCE· το DCR εγγράφει τον πελάτη, ενώ ο χρήστης εξακολουθεί να χρειάζεται να συνδεθεί και να εξουσιοδοτήσει· η χρήση του API χρεώνεται κανονικά.

| Πελάτης                            | Τρόπος ενσωμάτωσης και προϋποθέσεις                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Έκδοση ιστού Claude ή εκδόσεις Desktop που παρέχουν απομακρυσμένους συνδέσμους | Προσθέστε την παραπάνω διεύθυνση στη διεπαφή συνδέσμων και εξουσιοδοτήστε· η πρόσβαση εξαρτάται από την έκδοση και το πρόγραμμα. Μην γράφετε απομακρυσμένη διαμόρφωση HTTP σε τοπικά αρχεία διαμόρφωσης stdio.                      |
| VS Code με υποστήριξη εγγενούς απομακρυσμένου MCP OAuth     | Εκτελέστε **MCP: Add Server**, επιλέξτε HTTP, συμπληρώστε τη διεύθυνση και συνδεθείτε ακολουθώντας τις οδηγίες· η αποκλειστική επέκταση AceDataCloud χρησιμοποιεί ανεξάρτητη ρύθμιση API Key. |
| Άλλοι πελάτες                          | Επιβεβαιώστε ότι η τρέχουσα έκδοση υποστηρίζει απομακρυσμένο HTTP, OAuth/DCR και χρησιμοποιήστε τις οδηγίες διαμόρφωσης του συγκεκριμένου πελάτη. Οι μορφές αρχείων διαμόρφωσης δεν είναι καθολικά συμβατές μεταξύ διαφορετικών πελατών.                     |

## Εναλλακτική διαδρομή με API Token

Τοπικό stdio, αυτοφιλοξενία ή πελάτες που δεν υποστηρίζουν απομακρυσμένο OAuth χρησιμοποιούν API Token. Συνδεθείτε στην [πλατφόρμα Ace Data Cloud](https://platform.acedata.cloud), επιλέξτε την υπηρεσία και δημιουργήστε διαπιστευτήρια API με τα απαιτούμενα δικαιώματα. Αποθηκεύστε το Token στις ρυθμίσεις διαπιστευτηρίων του πελάτη ή σε τοπικές μεταβλητές περιβάλλοντος· μην το τοποθετείτε σε URL, περιεχόμενο συνομιλιών ή αποθετήρια εκδόσεων. Η διαμόρφωση HTTP Header διαφορετικών πελατών πρέπει να συμπληρώνεται σύμφωνα με τις οδηγίες της εκάστοτε έκδοσής τους.

Η εγκατάσταση του MCP ανοιχτού κώδικα ή η ολοκλήρωση της εξουσιοδότησης δεν σημαίνει ότι λαμβάνετε δωρεάν μονάδες, ούτε εγγυάται χρόνο δημιουργίας ή δικαιώματα εμπορικής χρήσης. Πριν από τη δημιουργία, ελέγξτε τις τρέχουσες τιμές υπηρεσίας, το υπόλοιπο και τους ισχύοντες όρους.

## Μέθοδος δύο: Τοπική εκτέλεση (εγκατάσταση pip / uvx)

Αν χρειάζεστε τοπικό stdio, προσαρμοσμένο κώδικα ή αυτοφιλοξενία, μπορείτε να εκκινήσετε τον MCP Server τοπικά. Η δημιουργία εξακολουθεί να απαιτεί σύνδεση στο διαδίκτυο για την κλήση του API και δεν είναι offline inference.

### Εγκατάσταση

Εγκατάσταση με pip (συνιστάται):

```bash
pip install mcp-seedance
```

Ή εγκατάσταση από πηγαίο κώδικα:

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Μετά την ολοκλήρωση της εγκατάστασης, μπορείτε να χρησιμοποιήσετε την εντολή `mcp-seedance` για να εκκινήσετε την υπηρεσία.

### Χρήση στο Claude Desktop (τοπικά)

Επεξεργαστείτε το αρχείο διαμόρφωσης του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Προσθέστε την ακόλουθη διαμόρφωση:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αν χρησιμοποιείτε `uvx` (δεν απαιτείται να εγκαταστήσετε το πακέτο εκ των προτέρων):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αποθηκεύστε τη διαμόρφωση και επανεκκινήστε το Claude Desktop για να εφαρμοστεί.

### Χρήση στο VS Code (τοπικά)

Δημιουργήστε το `.vscode/mcp.json` στον ριζικό κατάλογο του έργου:

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Ή χρησιμοποιήστε `uvx`:

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Για άλλους τοπικούς πελάτες, συμπληρώστε τα command, args και env σύμφωνα με τις οδηγίες διαμόρφωσης stdio της τρέχουσας έκδοσής τους· μην θεωρείτε απευθείας τη διαμόρφωση του VS Code ως καθολική μορφή.

## Επαλήθευση αποτελεσμάτων και συνηθισμένες αποτυχίες

Ζητήστε από τον πελάτη να δημιουργήσει ένα απλό έργο βίντεο, διατηρήστε τον αριθμό εργασίας και υποβάλετε ερώτημα για την ίδια εργασία έως ότου ολοκληρωθεί επιτυχώς, και στη συνέχεια ανοίξτε ή αναπαραγάγετε τον τελικό σύνδεσμο. Η επιτυχής σύνδεση, η φόρτωση της λίστας εργαλείων, το HTTP 200, ο αριθμός εργασίας και η προεπισκόπηση κατά την επεξεργασία δεν αντιπροσωπεύουν το τελικό παραγόμενο αποτέλεσμα.

Σε περίπτωση 401, συνδεθείτε ξανά ή ελέγξτε το Token και τα δικαιώματα· αν το υπόλοιπο δεν επαρκεί, ελέγξτε τη χρέωση· όταν η εργασία βρίσκεται σε επεξεργασία, συνεχίστε την υποβολή ερωτημάτων· σε περίπτωση τελικής αποτυχίας, διαβάστε το σφάλμα και αποφασίστε αν θα επαναλάβετε την προσπάθεια· η νέα δημιουργία ενδέχεται να χρεωθεί ξανά.

## Λίστα διαθέσιμων εργαλείων

| Όνομα εργαλείου                                  | Περιγραφή             |
| ------------------------------------ | -------------- |
| `seedance_generate_video`            | Δημιουργία βίντεο μέσω προτροπών κειμένου    |
| `seedance_generate_video_from_image` | Δημιουργία βίντεο με αναφορά σε εικόνα     |
| `seedance_get_task`                  | Ερώτηση κατάστασης μεμονωμένης εργασίας       |
| `seedance_get_tasks_batch`           | Μαζική ερώτηση κατάστασης εργασιών       |
| `seedance_list_models`               | Καταχώριση όλων των διαθέσιμων μοντέλων και δυνατοτήτων τους   |
| `seedance_list_resolutions`          | Καταχώριση διαθέσιμων αναλύσεων και αναλογιών εικόνας   |
| `seedance_list_actions`              | Καταχώριση όλων των διαθέσιμων εργαλείων και παραδειγμάτων ροών εργασίας |

## Παραδείγματα χρήσης

Μετά την ολοκλήρωση της διαμόρφωσης, μπορείτε να καλείτε απευθείας αυτές τις λειτουργίες με φυσική γλώσσα στον πελάτη AI, για παράδειγμα:

- «Βοήθησέ με να δημιουργήσω με το Seedance ένα βίντεο time-lapse από έναν δρόμο πόλης»
- «Χρησιμοποίησε αυτή τη φωτογραφία ως πρώτο καρέ και δημιούργησε ένα βίντεο 8 δευτερολέπτων»
- «Δημιούργησε ένα σύντομο κατακόρυφο βίντεο 1080p σε αναλογία 9:16»
- «Χρησιμοποίησε το μοντέλο Seedance 1.5 Pro για να δημιουργήσεις βίντεο με ήχο»
