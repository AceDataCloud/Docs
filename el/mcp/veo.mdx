[MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι το πρωτόκολλο μοντέλου συμφραζομένων που προτάθηκε από την Anthropic, επιτρέποντας στα AI μοντέλα (όπως Claude, GPT κ.λπ.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένων διεπαφών. Μέσω του Veo MCP Server που παρέχεται από το AceData Cloud, μπορείτε να χρησιμοποιήσετε απευθείας το Google Veo για τη δημιουργία AI βίντεο σε AI πελάτες όπως Claude Desktop, VS Code, Cursor κ.λπ.

## Επισκόπηση Λειτουργιών

Ο Veo MCP Server προσφέρει τις εξής βασικές λειτουργίες:

- **Δημιουργία βίντεο από κείμενο** — Δημιουργία βίντεο υψηλής ποιότητας μέσω κειμενικών προτροπών
- **Δημιουργία βίντεο από εικόνα** — Δημιουργία βίντεο με βάση εικόνες
- **Υποστήριξη πολλών μοντέλων** — Υποστήριξη μοντέλων όπως το veo3, veo2, veo31-fast-ingredient κ.λπ.
- **Ποικιλία αναλύσεων** — Υποστήριξη εξόδων σε 4K, 1080p, GIF κ.λπ.
- **Ποικιλία αναλογιών** — Υποστήριξη αναλογιών 16:9, 9:16 κ.λπ.
- **Αναβάθμιση σε 1080p** — Αναβάθμιση ήδη δημιουργημένων βίντεο σε 1080p
- **Ερώτηση εργασιών** — Παρακολούθηση προόδου δημιουργίας και λήψη αποτελεσμάτων

## Προαπαιτούμενα

Πριν τη χρήση, πρέπει να αποκτήσετε το AceData Cloud API Token:

1. Εγγραφείτε ή συνδεθείτε στην [πλατφόρμα AceData Cloud](https://platform.acedata.cloud)
2. Μεταβείτε στη σελίδα [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos)
3. Κάντε κλικ στο «Acquire» για να αποκτήσετε το API Token (η πρώτη αίτηση προσφέρει δωρεάν πιστώσεις)

## Εγκατάσταση και Ρύθμιση

### Μέθοδος 1: Εγκατάσταση με pip (συνιστάται)

```bash
pip install mcp-veo
```

### Μέθοδος 2: Εγκατάσταση από πηγή

```bash
git clone https://github.com/AceDataCloud/VeoMCP.git
cd VeoMCP
pip install -e .
```

Αφού ολοκληρωθεί η εγκατάσταση, μπορείτε να χρησιμοποιήσετε την εντολή `mcp-veo` για να ξεκινήσετε την υπηρεσία.

## Χρήση στο Claude Desktop

Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Προσθέστε την παρακάτω ρύθμιση:

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Εάν χρησιμοποιείτε το `uvx` (χωρίς να χρειάζεται να εγκαταστήσετε πακέτα εκ των προτέρων):

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αποθηκεύστε τις ρυθμίσεις και επανεκκινήστε το Claude Desktop, ώστε να μπορείτε να χρησιμοποιήσετε τα σχετικά εργαλεία Veo στη συνομιλία.

## Χρήση στο VS Code / Cursor

Δημιουργήστε το αρχείο `.vscode/mcp.json` στον ριζικό φάκελο του έργου:

```json
{
  "servers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Ή χρησιμοποιήστε το `uvx`:

```json
{
  "servers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

## Λίστα διαθέσιμων εργαλείων

| Όνομα εργαλείου          | Περιγραφή           |
| --------------------- | ------------ |
| `veo_text_to_video`   | Δημιουργία βίντεο μέσω κειμενικών προτροπών  |
| `veo_image_to_video`  | Δημιουργία βίντεο με βάση εικόνες   |
| `veo_get_1080p`       | Αναβάθμιση βίντεο σε 1080p |
| `veo_get_task`        | Έλεγχος κατάστασης μεμονωμένης εργασίας     |
| `veo_get_tasks_batch` | Μαζικός έλεγχος κατάστασης εργασιών     |

## Παραδείγματα Χρήσης

Αφού ολοκληρωθούν οι ρυθμίσεις, μπορείτε να καλέσετε αυτές τις λειτουργίες απευθείας με φυσική γλώσσα στους AI πελάτες, όπως:

- «Βοήθησέ με να δημιουργήσω ένα βίντεο με αστέρια με το Veo»
- «Δημιούργησε ένα 4K βίντεο από αυτή τη φωτογραφία τοπίου»
- «Δημιούργησε ένα κάθετο βίντεο 9:16»
- «Αναβάθμισε αυτό το βίντεο σε 1080p»
