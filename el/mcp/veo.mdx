Το [MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι ένα πρωτόκολλο πλαισίου μοντέλου που αναπτύχθηκε από την Anthropic, το οποίο επιτρέπει σε μοντέλα AI (όπως Claude, GPT κ.ά.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένων διεπαφών. Μέσω του Veo MCP Server που παρέχεται από το AceData Cloud, μπορείτε να χρησιμοποιείτε απευθείας το Google Veo για τη δημιουργία βίντεο AI σε πελάτες AI όπως Claude Desktop, VS Code, Cursor κ.ά.

## Επισκόπηση Λειτουργιών

Ο Veo MCP Server προσφέρει τις εξής βασικές λειτουργίες:

- **Μετατροπή κειμένου σε βίντεο** — Δημιουργία βίντεο υψηλής ποιότητας από κείμενα προτροπής
- **Μετατροπή εικόνας σε βίντεο** — Δημιουργία βίντεο βασισμένου σε εικόνες
- **Υποστήριξη πολλαπλών μοντέλων** — Υποστήριξη μοντέλων όπως veo3, veo2, veo31-fast-ingredients κ.ά.
- **Πολλαπλές αναλύσεις** — Υποστήριξη εξόδου σε 4K, 1080p, GIF κ.ά.
- **Πολλαπλές αναλογίες εικόνας** — Υποστήριξη αναλογιών 16:9, 9:16 κ.ά.
- **Αναβάθμιση σε 1080p** — Αναβάθμιση ήδη δημιουργημένων βίντεο σε 1080p
- **Ερωτήματα εργασιών** — Παρακολούθηση προόδου δημιουργίας και λήψη αποτελεσμάτων

## Προαπαιτούμενα

Πριν τη χρήση, πρέπει να αποκτήσετε το API Token του AceData Cloud:

1. Εγγραφείτε ή συνδεθείτε στην [πλατφόρμα AceData Cloud](https://platform.acedata.cloud)
2. Μεταβείτε στη σελίδα [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos)
3. Κάντε κλικ στο «Acquire» για να λάβετε το API Token (παρέχεται δωρεάν όριο κατά την πρώτη αίτηση)

## Εγκατάσταση και Ρύθμιση

### Μέθοδος 1: Εγκατάσταση μέσω pip (Συνιστάται)

```bash
pip install mcp-veo
```

### Μέθοδος 2: Εγκατάσταση από πηγαίο κώδικα

```bash
git clone https://github.com/AceDataCloud/VeoMCP.git
cd VeoMCP
pip install -e .
```

Μετά την εγκατάσταση, μπορείτε να ξεκινήσετε την υπηρεσία με την εντολή `mcp-veo`.

## Χρήση στο Claude Desktop

Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Προσθέστε την παρακάτω ρύθμιση:

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αν χρησιμοποιείτε `uvx` (χωρίς ανάγκη προεγκατάστασης πακέτων):

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αποθηκεύστε τις ρυθμίσεις και επανεκκινήστε το Claude Desktop για να χρησιμοποιήσετε τα εργαλεία Veo στις συνομιλίες.

## Χρήση στο VS Code / Cursor

Δημιουργήστε το αρχείο `.vscode/mcp.json` στον ριζικό φάκελο του έργου:

```json
{
  "servers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Ή χρησιμοποιήστε `uvx`:

```json
{

      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
```

## Λίστα Διαθέσιμων Εργαλείων

| Όνομα Εργαλείου          | Περιγραφή                         |
|--------------------------|----------------------------------|
| `veo_text_to_video`       | Δημιουργία βίντεο από κείμενο    |
| `veo_image_to_video`      | Δημιουργία βίντεο από εικόνα     |
| `veo_get_1080p`           | Αναβάθμιση βίντεο σε 1080p       |
| `veo_get_task`            | Ερώτημα κατάστασης μεμονωμένης εργασίας |
| `veo_get_tasks_batch`     | Μαζικό ερώτημα καταστάσεων εργασιών |

## Παραδείγματα Χρήσης

Μετά τη ρύθμιση, μπορείτε να καλέσετε αυτές τις λειτουργίες με φυσική γλώσσα στον πελάτη AI, π.χ.:

- «Βοήθησέ με να δημιουργήσω ένα βίντεο time-lapse του νυχτερινού ουρανού με το Veo»
- «Δημιούργησε ένα βίντεο 4K από αυτή τη φωτογραφία τοπίου»
- «Δημιούργησε ένα σύντομο βίντεο σε κατακόρυφη μορφή 9:16»
- «Αναβάθμισε αυτό το βίντεο σε 1080p»
