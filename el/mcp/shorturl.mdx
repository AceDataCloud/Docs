Το [MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι ένα πρωτόκολλο πλαισίου μοντέλου που έχει αναπτύξει η Anthropic και επιτρέπει στα μοντέλα AI (όπως Claude, GPT κ.ά.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένης διεπαφής. Μέσω του ShortURL MCP Server που παρέχεται από το AceData Cloud, μπορείτε να δημιουργείτε απευθείας σύντομους συνδέσμους σε πελάτες AI όπως Claude Desktop, VS Code, Cursor κ.ά.

## Επισκόπηση Λειτουργιών

Ο ShortURL MCP Server προσφέρει τις ακόλουθες βασικές λειτουργίες:

- **Σύντμηση μεμονωμένου συνδέσμου** — Μετατροπή μακρών URL σε σύντομους και εύκολους στη διαμοίραση συνδέσμους  
- **Μαζική σύντμηση συνδέσμων** — Σύντμηση πολλαπλών URL ταυτόχρονα (έως 10)  
- **Οδηγός χρήσης** — Λήψη πλήρους οδηγού χρήσης και βέλτιστων πρακτικών  
- **Πληροφορίες API** — Προβολή λεπτομερειών υπηρεσίας API και κωδικών σφαλμάτων  

## Προαπαιτούμενα

Πριν τη χρήση, πρέπει να αποκτήσετε το AceData Cloud API Token:

1. Εγγραφείτε ή συνδεθείτε στην [πλατφόρμα AceData Cloud](https://platform.acedata.cloud)  
2. Μεταβείτε στη σελίδα [ShortURL API](https://platform.acedata.cloud/documents/short-url)  
3. Πατήστε «Acquire» για να λάβετε το API Token (η πρώτη αίτηση παρέχει δωρεάν όριο)  

## Εγκατάσταση και Ρύθμιση

### Μέθοδος 1: Εγκατάσταση μέσω pip (συνιστάται)

```bash
pip install mcp-shorturl
```

### Μέθοδος 2: Εγκατάσταση από πηγαίο κώδικα

```bash
git clone https://github.com/AceDataCloud/ShortURLMCP.git
cd ShortURLMCP
pip install -e .
```

Μετά την εγκατάσταση, μπορείτε να ξεκινήσετε την υπηρεσία με την εντολή `mcp-shorturl`.

## Χρήση στο Claude Desktop

Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`  
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`  

Προσθέστε την παρακάτω ρύθμιση:

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αν χρησιμοποιείτε το `uvx` (χωρίς να απαιτείται προεγκατάσταση πακέτων):

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "uvx",
      "args": ["mcp-shorturl"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αποθηκεύστε τις ρυθμίσεις και επανεκκινήστε το Claude Desktop για να χρησιμοποιήσετε τα εργαλεία ShortURL στις συνομιλίες.

## Χρήση στο VS Code / Cursor

Δημιουργήστε το αρχείο `.vscode/mcp.json` στον ριζικό φάκελο του έργου:

```json

    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"

    }
  }
}
```

Ή χρησιμοποιήστε το `uvx`:

```json
{
  "servers": {

      "command": "uvx",
      "args": ["mcp-shorturl"],
```

## Λίστα Διαθέσιμων Εργαλείων

| Όνομα Εργαλείου          | Περιγραφή                                   |
|--------------------------|--------------------------------------------|
| `shorturl_create`        | Σύντμηση μεμονωμένου URL                   |
| `shorturl_batch_create`  | Μαζική σύντμηση πολλαπλών URL (έως 10)    |
| `shorturl_get_usage_guide` | Λήψη πλήρους οδηγού χρήσης                |
| `shorturl_get_api_info`  | Λήψη λεπτομερειών υπηρεσίας API            |

## Παραδείγματα Χρήσης

Μετά τη ρύθμιση, μπορείτε να καλείτε αυτές τις λειτουργίες απευθείας με φυσική γλώσσα στον πελάτη AI, π.χ.:

- «Βοήθησέ με να συντομεύσω αυτόν τον σύνδεσμο»  
- «Συντόμευσε αυτούς τους 5 συνδέσμους μαζικά»  
- «Δημιούργησε έναν σύντομο σύνδεσμο για διαμοιρασμό»
