[MCP (Model Context Protocol)](https://modelcontextprotocol.io) είναι το πρωτόκολλο μοντέλου συμφραζομένων που προτάθηκε από την Anthropic, επιτρέποντας στα AI μοντέλα (όπως Claude, GPT κ.λπ.) να καλούν εξωτερικά εργαλεία μέσω τυποποιημένων διεπαφών. Μέσω του SERP MCP Server που παρέχεται από το AceData Cloud, μπορείτε να πραγματοποιείτε άμεσες αναζητήσεις στο Google σε AI πελάτες όπως Claude Desktop, VS Code, Cursor κ.λπ., αποκτώντας αποτελέσματα αναζητήσεων για ιστοσελίδες, εικόνες, ειδήσεις, βίντεο, τοποθεσίες κ.λπ.

## Επισκόπηση Λειτουργιών

Ο SERP MCP Server παρέχει τις εξής βασικές λειτουργίες:

- **Αναζήτηση Ιστοσελίδων** — Αναζητήστε αποτελέσματα ιστοσελίδων Google
- **Αναζήτηση Εικόνων** — Αναζητήστε εικόνες Google
- **Αναζήτηση Ειδήσεων** — Αναζητήστε ειδήσεις Google
- **Αναζήτηση Βίντεο** — Αναζητήστε βίντεο Google
- **Αναζήτηση Τοποθεσιών** — Αναζητήστε πληροφορίες τοποθεσιών Google
- **Αναζήτηση Χαρτών** — Αναζητήστε χάρτες Google
- **Πολυγλωσσική και Πολυπεριοχική Υποστήριξη** — Υποστηρίζει προσαρμοσμένες παραμέτρους χώρας και γλώσσας
- **Φιλτράρισμα Χρονικών Διαστημάτων** — Φιλτράρετε αποτελέσματα κατά ημέρα, εβδομάδα, μήνα, έτος

## Προαπαιτούμενα

Πριν τη χρήση, πρέπει να αποκτήσετε το AceData Cloud API Token:

1. Εγγραφείτε ή συνδεθείτε στην [πλατφόρμα AceData Cloud](https://platform.acedata.cloud)
2. Μεταβείτε στη σελίδα [Google SERP API](https://platform.acedata.cloud/documents/serp-google)
3. Κάντε κλικ στο «Acquire» για να αποκτήσετε το API Token (η πρώτη αίτηση προσφέρει δωρεάν πιστώσεις)

## Εγκατάσταση και Ρύθμιση

### Μέθοδος 1: Εγκατάσταση με pip (συνιστάται)

```bash
pip install mcp-serp
```

### Μέθοδος 2: Εγκατάσταση από πηγή

```bash
git clone https://github.com/AceDataCloud/MCPSerp.git
cd MCPSerp
pip install -e .
```

Αφού ολοκληρωθεί η εγκατάσταση, μπορείτε να χρησιμοποιήσετε την εντολή `mcp-serp` για να ξεκινήσετε την υπηρεσία.

## Χρήση στο Claude Desktop

Επεξεργαστείτε το αρχείο ρυθμίσεων του Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Προσθέστε την παρακάτω ρύθμιση:

```json
{
  "mcpServers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Εάν χρησιμοποιείτε το `uvx` (χωρίς να χρειάζεται να εγκαταστήσετε πακέτα εκ των προτέρων):

```json
{
  "mcpServers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Αποθηκεύστε τις ρυθμίσεις και επανεκκινήστε το Claude Desktop, ώστε να μπορείτε να χρησιμοποιήσετε τα σχετικά εργαλεία αναζήτησης Google στη συνομιλία.

## Χρήση στο VS Code / Cursor

Δημιουργήστε το αρχείο `.vscode/mcp.json` στον ριζικό φάκελο του έργου:

```json
{
  "servers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

Ή χρησιμοποιήστε το `uvx`:

```json
{
  "servers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "το API Token σας"
      }
    }
  }
}
```

## Λίστα Διαθέσιμων Εργαλείων

| Όνομα Εργαλείου         | Περιγραφή          |
| -------------------- | ----------- |
| `serp_google_search` | Αναζήτηση ιστοσελίδων Google |
| `serp_google_images` | Αναζήτηση εικόνων Google |
| `serp_google_news`   | Αναζήτηση ειδήσεων Google |
| `serp_google_videos` | Αναζήτηση βίντεο Google |
| `serp_google_places` | Αναζήτηση τοποθεσιών Google |
| `serp_google_maps`   | Αναζήτηση χαρτών Google |

## Παραδείγματα Χρήσης

Αφού ολοκληρωθούν οι ρυθμίσεις, μπορείτε να καλείτε αυτές τις λειτουργίες απευθείας με φυσική γλώσσα στους AI πελάτες, όπως:

- «Βοήθησέ με να αναζητήσω τις πιο πρόσφατες εργασίες AI»

- «Βρες καφετέριες κοντά στον χάρτη»
