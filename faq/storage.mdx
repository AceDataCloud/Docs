## 生成结果保存多久？

| 类型 | 保留时长 |
|---|---|
| Midjourney / Flux / Seedream 图像 URL | **30 天** |
| Sora / Veo / Kling / Hailuo / Luma 视频 URL | **30 天** |
| Suno / Producer 音乐 URL | **90 天** |
| Fish Audio TTS 临时 URL | **24 小时** |

<Note>
  **不要把我们的 URL 当永久存储**。生产环境务必在收到结果后**立刻下载**到你自己的对象存储（S3 / OSS / COS / R2）。
</Note>

## 拿到 URL 后多快下载？

下载本身**不收费、不计入额度**。建议：

- 收到 Webhook 或 `success` 后**立即异步触发**下载
- 失败重试 3 次（指数退避 2s, 4s, 8s）
- 把你自己的 URL 落库，旧的我们 URL 字段仅做备份

## 文件上传到我们用

很多接口需要传图（图生图、图生视频、人脸编辑）。**推荐做法**：

1. 你的应用上传到你自己的对象存储（S3 / OSS / COS / R2）
2. 拿到公网可访问的 URL
3. 把 URL 传给我们的 API

要求：

- 协议 HTTPS（HTTP 在部分上游会被拒）
- URL 在请求生命周期内可访问（最好长期可用）
- 文件 < 25 MB（图）或 < 200 MB（视频参考）
- 无强 Referer / 防盗链

## 没有自己的存储怎么办？

平台提供**临时上传接口**（OAuth 登录后用）：

```bash
POST https://api.acedata.cloud/files/upload
Authorization: Bearer YOUR_API_TOKEN
Content-Type: multipart/form-data

file=@/path/to/local.png
```

返回：

```json
{
  "success": true,
  "url": "https://cdn.acedata.cloud/uploads/.../local.png",
  "expires_at": "2026-01-15T10:30:00Z"
}
```

限制：

- 上传文件 ≤ 25 MB
- URL 7 天有效
- 仅用于本人 Token 的后续调用

## COS 加速 / 全球分发

- 我们的 CDN 是基于 EdgeOne / 多供应商组合的全球分发
- 默认从最近节点拉取，**首次访问可能有 ~500ms 的 cold start**
- 高频访问的关键资产建议**回源 + 自托管缓存**

## 内容审核与归档

- 我们**不会**长期归档你的 prompt、输入图、生成结果
- 出于合规要求会保留 **30 天**的访问日志（仅 metadata）
- 内容被审核拒绝时**不留底**，立刻丢弃

## 删除我的内容

如果你需要彻底清除某条历史记录：

1. 找到该任务的 `task_id`
2. 发邮件到 `privacy@acedata.cloud`，附 `task_id` 列表
3. 通常 24 小时内处理完毕
