## Credits 怎么换算 USD？

- 控制台展示使用 USD 作为参考币种
- 实际扣减以 **Credits** 为单位
- 不同套餐的「Credits ↔ USD」比例不一样，购买时以套餐价为准

通用公式：

$$
\text{USD} = \text{Credits} \times \frac{\text{package.price}}{\text{package.amount}}
$$

当前主流套餐的换算比例约为 **$0.095215 / Credit**。

## 什么时候扣费？

| 调用类型 | 扣费时机 |
|---|---|
| 同步 API（Chat / Embedding 等） | 响应返回时即按 token / 字符 / 次数扣 |
| 异步任务（图像 / 视频 / 音频） | 任务最终 success 时扣费 |
| 任务 failed | 一般不扣费（以服务详情页约定为准） |
| 网关 5xx / 上游超时 | 不扣费 |
| 4xx 认证 / 参数错误 | 不扣费 |
| 内容审核拒绝（`forbidden` / `403`） | 不扣费 |

## 服务额度和全局余额谁先扣？

- **服务额度**：订阅某服务套餐时分配，只能用于该服务
- **全局余额**：可用于全部服务
- 扣减顺序：**服务额度 → 全局余额**

如果创建凭证时绑定了某个服务，但全局余额开关打开，则该服务额度用完后会回落到全局余额扣费。

## 余额耗尽时 API 会返回什么？

```json
{
  "error": {
    "code": "used_up",
    "message": "Your balance is not sufficient for current request, please buy more in Ace Data Cloud https://platform.acedata.cloud"
  },
  "trace_id": "..."
}
```

HTTP 状态码是 **403**（不是 402）。请在控制台续费后再调用。

## 失败请求会扣费吗？

不会扣费的情况：

- 网关层 4xx（`bad_request`、`invalid_token`、`used_up` 等）
- 上游 5xx
- 网关 / 上游超时
- 内容审核拒绝（`forbidden`）
- 异步任务最终 `failed`

**会扣费**的情况：

- 任务最终 `success`
- 同步成功响应

## 怎么退款？

按量套餐通常**不支持已使用的退款**。具体以购买时的套餐条款 / 控制台公告为准。如确有特殊情况（例如服务长时间不可用），请联系 `support@acedata.cloud` 并提供：

- 凭证 ID（不要发送 Token 全文）
- 受影响时段
- 相关请求的 `trace_id` 列表

## 用量怎么查？

控制台「Usage」页可以按服务、时间区间、凭证维度查看用量。每条记录都带 `trace_id`，方便定位具体调用。

## 可以共享 Token 吗？

**不建议**。原因：

- 出问题时无法定位是哪个使用方
- 一旦泄漏需要撤销整个 Token
- 用量按 Token 归集，无法分账

请为每个使用方 / 环境创建独立凭证。
