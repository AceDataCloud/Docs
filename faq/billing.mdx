## Credits 和 USD 是什么关系？

平台用 **Credits** 作为扣费单位，控制台同时展示 USD 参考价。

- 套餐购买时按当时的「Credits ↔ USD」汇率折算
- 当前参考汇率约 `$0.095215 / Credit`（即 ~10.5 Credits = $1）
- 汇率会定期调整，**已购套餐不受新汇率影响**

公式：

```
所需 Credits = USD 报价 / (套餐 price / 套餐 amount)
```

## 扣费什么时候发生？

| 调用类型 | 扣费时机 |
|---|---|
| 同步 LLM（chat completions） | 响应返回时按 `usage.total_tokens` 扣 |
| 异步生成（image / video / audio） | **任务 `success` 时**扣，失败不扣 |
| 内容审核拒绝（HTTP 403） | 不扣费 |
| 上游 5xx / 超时 | 不扣费 |
| 4xx（请求参数错） | 不扣费 |
| 任务轮询（`/tasks` 端点） | 永远免费 |

## 余额优先级

1. **服务额度** —— 订阅套餐附带，只能用于该服务
2. **全局余额** —— 通用，跨所有已订阅服务

满足条件时：

- 优先扣服务额度
- 服务额度耗尽 → 自动用全局余额（前提是该 Application 开启了 `allow_consume_global`）
- 全部耗尽 → 返回 `402 insufficient_balance`

## 我能退款吗？

- **任务失败 / 服务故障**：自动不扣费，无需退款流程
- **误操作 / 调错 prompt**：成功完成的不退；用 [统一响应格式](/concepts/responses) 里的 `trace_id` 申诉，会人工 case-by-case 处理
- **批量错误（如上游集体故障）**：上报 `trace_id` 列表，确认后**全额返还**

申诉入口：`support@acedata.cloud`，请附 `trace_id`。

## 扣费精度

- 内部用浮点保留 6 位小数 Credits
- 单次扣减小于 `0.000001 Credit` 时按 `0.000001` 计
- 账单展示按 4 位小数取整

## 怎么估算单月成本？

去 [platform.acedata.cloud](https://platform.acedata.cloud) → 「用量」面板，提供：

- 按服务分维度统计
- 按日 / 按周折线
- 按 `task_id` / 时间窗口的明细导出（CSV）

## 折扣怎么拿？

- **质押 $ACE 代币**：自动叠加，详见 [代币计划](https://platform.acedata.cloud/coin)
- **大客户阶梯**：月消耗超过 $5,000 自动获 5%–15% 折扣；月超 $50,000 联系 `sales@acedata.cloud` 议价
- **公益 / 教育**：单独邮件申请

## 没用完的额度会过期吗？

- **套餐额度（Period 类型）**：到期作废
- **套餐额度（Usage 类型）**：用完为止，不过期
- **全局余额**：不过期
