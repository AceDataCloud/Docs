本文将介绍一种 Sora Videos Generation API 对接说明，它是可以通过输入自定义参数来生成Sora官方的视频。

## 申请流程

要使用 API，需要先到 [Sora Videos Generation API](https://platform.acedata.cloud/documents/99a24421-2e22-4028-8201-e19cb834b67e) 对应页面申请对应的服务，进入页面之后，点击「Acquire」按钮，如图所示：

![](https://cdn.acedata.cloud/q6ytrc.png)

如果你尚未登录或注册，会自动跳转到登录页面邀请您来注册和登录，登录注册之后会自动返回当前页面。

在首次申请时会有免费额度赠送，可以免费使用该 API。

## 基本使用

首先先了解下基本的使用方式，就是输入提示词 `prompt`、参考图片链接数组 `image_urls` 以及模型 `model`，便可获得处理后的结果，具体的内容如下：

<p><img src="https://cdn.acedata.cloud/h8dyz3.png" width="500" className="m-auto" /></p>

可以看到这里我们设置了 Request Headers，包括：

- `accept`：想要接收怎样格式的响应结果，这里填写为 `application/json`，即 JSON 格式。
- `authorization`：调用 API 的密钥，申请之后可以直接下拉选择。

另外设置了 Request Body，包括：

- `model`：生成视频的模型，主要有`sora-2`、`sora-2-pro`，目前 `sora-2`、`sora-2-pro`可以自主选择`size`、`duration`参数的视频，其中`sora-2-pro`可以支持`duration`为25s的视频，而`sora-2`只支持10、15秒的视频。
- `size`：此次视频生成任务的清晰度，分别有 `small` 、 `large`。
- `image_urls`：需要上传的参考图片链接或者Base64编码数组。
- `duration`：此次视频生成任务的时长，分别有10s、15s、25s，目前只有`sora-2-pro`支持25s。
- `character_start`/`character_end`：角色在画面中的起止位置（0-1），用于控制主体位置。
- `orientation`：画幅方向，支持 `landscape`、`portrait`、`square`。
- `prompt`：提示词。
- `callback_url`：需要回调结果的URL。

```shell
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "size": "large",
  "duration": 15,
  "orientation": "landscape",
  "prompt": "cat running on the river",
  "model": "sora-2"
}'
```

如果想图生视频任务任务， 首先参数`image_urls`必须传入参考图片链接，就可以指定如下内容：

- image_urls：该图生视频任务采用的参考图链接数组，。

填写样例如下：

<p><img src="https://cdn.acedata.cloud/ch7x3t.png" width="500" className="m-auto" /></p>

<p><img src="https://cdn.acedata.cloud/z1ud8l.png" width="500" className="m-auto" /></p>

```python
import requests

    "accept": "application/json",

    "content-type": "application/json"
```

## Version 2 模式

除了上述 Version 1 模式之外，本 API 还支持 Version 2 模式，通过设置 `version` 参数为 `2` 即可启用。Version 2 模式支持不同的参数配置，包括精确的时长控制和像素级的分辨率设置。

### Version 2 参数说明

Version 2 模式下可用的参数如下：

- `version`：设置为 `2` 以启用 Version 2 模式。
- `prompt`（必填）：生成视频的提示词。
- `model`：生成视频的模型，支持 `sora-2`（默认）和 `sora-2-pro`。
- `seconds`：视频时长，支持 `4`、`8`、`12` 秒，默认为 `4` 秒。
- `size`：视频分辨率，支持 `720x1280`、`1280x720`、`1024x1792`、`1792x1024`，默认 `720x1280`。
- `input_reference`：可选的参考图片 URL，用于引导视频生成。注意图片尺寸需要与 `size` 参数一致。
- `callback_url`：需要回调结果的 URL。

### 基本示例

```shell
curl -X POST 'https://api.acedata.cloud/sora/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "version": 2,
  "prompt": "cat running on the river",
  "model": "sora-2",
  "seconds": 8,
  "size": "1280x720"
}'
```

对应的 Python 代码：

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "version": 2,
    "prompt": "cat running on the river",
    "model": "sora-2",
    "seconds": 8,
    "size": "1280x720"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

返回结果格式与 Version 1 相同：


### 使用参考图片（Version 2）

在 Version 2 模式下，可以通过 `input_reference` 参数传入一张参考图片来引导视频生成：

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "version": 2,
    "prompt": "a person walking through a beautiful garden",
    "model": "sora-2",
    "seconds": 4,
    "size": "1280x720",
    "input_reference": "https://cdn.acedata.cloud/11wfp4.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

> **注意**：`input_reference` 图片的尺寸应与 `size` 参数保持一致，例如 `size` 为 `1280x720` 时，参考图片尺寸应为 1280×720。

### Version 1 与 Version 2 参数对比

| 参数 | Version 1 | Version 2 |
|------|-----------|-----------|
| `version` | 1（默认） | 2 |
| `prompt` | ✅ | ✅ |
| `model` | ✅ sora-2 / sora-2-pro | ✅ sora-2 / sora-2-pro |
| `duration` | ✅ 10/15/25 秒 | ❌ |
| `seconds` | ❌ | ✅ 4/8/12 秒 |
| `orientation` | ✅ landscape/portrait | ❌ |
| `size` | ✅ small/large | ✅ 720x1280/1280x720/1024x1792/1792x1024 |
| `image_urls` | ✅ | ❌ |
| `input_reference` | ❌ | ✅ |
| `character_url` | ✅ | ❌ |
| `callback_url` | ✅ | ✅ |

## 异步回调

由于 Sora Videos Generation API生成的时间相对较长，大约需要 1-2 分钟，如果 API 长时间无响应，HTTP 请求会一直保持连接，导致额外的系统资源消耗，所以本 API 也提供了异步回调的支持。

整体流程是：客户端发起请求的时候，额外指定一个 `callback_url` 字段，客户端发起 API 请求之后，API 会立马返回一个结果，包含一个 `task_id` 的字段信息，代表当前的任务 ID。当任务完成之后，生成视频的结果会通过 POST JSON 的形式发送到客户端指定的 `callback_url`，其中也包括了 `task_id` 字段，这样任务结果就可以通过 ID 关联起来了。

## 错误处理

在调用 API 时，如果遇到错误，API 会返回相应的错误代码和信息。例如：

- `400 token_mismatched`：Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`：Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`：Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`：Too many requests, you have exceeded the rate limit.
- `500 api_error`：Internal server error, something went wrong on the server.

### 错误响应示例

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
