本文将介绍 Veo Upsample API 的对接说明。该接口用于对一段已经生成的 Veo 视频进行升采样或者输出动图预览。

## 申请流程

要使用 API，需要先到 Veo 服务对应页面申请。如果你尚未登录或注册，会自动跳转到登录页面。

## 基本使用

调用本接口需要传入两个参数：

- `video_id`：来源视频的任务 ID。可以是 `/veo/videos`、`/veo/extend`、`/veo/reshoot`、`/veo/objects` 任意接口生成的视频 ID。
- `action`：升采样动作，支持以下三种：
  - `1080p`：把视频升采样到 1080p 分辨率。
  - `4k`：把视频升采样到 4K 分辨率。
  - `gif`：把视频转换为动图（GIF）预览。

请求示例：

```shell
curl -X POST 'https://api.acedata.cloud/veo/upsample' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "4k"
  }'
```

返回结果与 `/veo/videos` 相同，仍然是异步任务结构，可以通过 `task_id` 在 `/veo/tasks` 接口查询任务状态：

```json
{
  "success": true,
  "task_id": "8f5a90ae-3f86-4c4f-86f7-7126f5e92c76",
  "trace_id": "0f3e09c2-4c2e-46ea-9cdc-a31ec48b7c12",
  "data": [
    {
      "id": "253eedc47f1c4eb2a370ed2312168f4b",
      "video_url": "https://platform.cdn.acedata.cloud/veo/8f5a90ae.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

返回字段说明：

- `success`：升采样任务是否提交成功。
- `task_id`：本次升采样任务的 ID。
- `data`：升采样后的视频结果。
  - `video_url`：升采样后的视频地址。

## 计费说明

- `action=1080p`：0.16 Credit / 次
- `action=4k`：0.50 Credit / 次
- `action=gif`：0.13 Credit / 次

如果传入的 `action` 不在以上枚举内，会被默认计费为 0.50 Credit。建议显式传入支持的值。

## 异步回调

接口同样支持异步模式，传入 `callback_url` 即可在任务完成后通过 POST 请求回调结果。
