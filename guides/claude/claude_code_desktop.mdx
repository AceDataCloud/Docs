Claude Code 是 Anthropic 推出的一款 **Agentic Coding** 工具，也被称为世界最强编程 Agent 之一。Claude Code 桌面应用提供了独立的图形化界面，支持 Diff 审查、并行会话（通过 Git Worktree 隔离）、远程会话等功能，无需依赖任何 IDE。

本文档主要介绍如何通过 AceData Cloud 的代理服务，在 Claude Code 桌面应用中配置和使用。

> **注意**：Claude Code 桌面应用目前处于预览阶段（Preview），仅支持 macOS 和 Windows。

## 申请流程

要使用 Claude Code，首先可以到 [Claude Messages 服务页面](https://platform.acedata.cloud/documents/claude-messages) 点击「Acquire」按钮，获取请求所需要的凭证：

![](https://cdn.acedata.cloud/nyq0xz.png)

如果你尚未登录或注册，会自动跳转到登录页面邀请您来注册和登录，登录注册之后会自动返回当前页面。

在首次申请时会有免费额度赠送，可以免费体验 Claude Code 服务。

## 安装桌面应用

### 系统要求

- macOS（Intel 和 Apple Silicon）或 Windows（x64 / ARM64）
- Linux 暂不支持桌面应用

### 下载安装

前往 [Claude 官方下载页面](https://claude.ai) 下载对应平台的安装包：

- **macOS**：下载 `.dmg` 文件，拖入 Applications 文件夹
- **Windows x64**：下载 `.exe` 安装包，按提示安装
- **Windows ARM64**：下载 ARM64 版本（注意：ARM64 不支持本地会话，需使用远程会话）

![Claude 桌面应用下载页面](https://cdn.acedata.cloud/c3c8c57264.png)

安装完成后，从 Applications 文件夹（macOS）或开始菜单（Windows）启动 Claude。

## 配置 AceData Cloud API

桌面应用启动后需要登录 Anthropic 账号。我们可以通过配置环境变量来使用 AceData Cloud 的代理 API，**无需官方订阅**。

桌面应用从你的 Shell 环境中读取环境变量，因此需要在 Shell 配置文件中进行设置。

### 配置环境变量

**macOS 用户**

将以下内容添加到 `~/.zshrc`（或 `~/.bashrc`）中，将 `{token}` 替换为你的 API 令牌：

```bash
# AceData Cloud - Claude Code 代理配置
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

保存后执行：

```bash
source ~/.zshrc
```

**Windows 用户**

通过「系统属性 → 高级 → 环境变量」添加以下系统环境变量：

| 变量名 | 值 |
|--------|-----|
| `ANTHROPIC_AUTH_TOKEN` | `{token}`（替换为你的 API 令牌） |
| `ANTHROPIC_BASE_URL` | `https://api.acedata.cloud` |

或者使用 PowerShell：

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**也可以通过 settings.json 配置**

编辑 `~/.claude/settings.json`（如不存在则创建）：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **提示**：API 令牌可在 [AceData Cloud 控制台](https://platform.acedata.cloud/console) 中查看。配置完成后需要**重启桌面应用**使环境变量生效。

## 基本使用

### 打开项目

1. 启动 Claude 桌面应用
2. 点击顶部的 **Code** 标签页
3. 选择 **Local** 运行模式
4. 点击 **Select folder** 选择你的项目目录

### 开始对话

在输入框中输入自然语言描述你的需求：

- 「找到 TODO 注释并修复它」
- 「为主函数添加测试」
- 「解释这个项目的架构」

Claude 会分析你的代码库，提出修改方案，并以 Diff 视图展示变更。

### 权限模式

通过发送按钮旁边的模式选择器切换：

| 模式 | 说明 |
|------|------|
| **Ask** | 每次修改前询问确认（推荐新手使用） |
| **Code** | 自动接受文件编辑，但终端命令仍需确认 |
| **Plan** | 先制定详细计划等待审批，确认后才执行 |

### 并行会话

点击侧边栏的 **+ New session** 可以启动多个并行会话。对于 Git 仓库，每个会话会通过 Worktree 获得独立的项目副本，互不干扰。

Worktree 默认存储在 `~/.claude-worktrees/` 目录。

### Diff 审查

当 Claude 修改了文件后，会显示变更统计（如 `+12 -1`），点击可以打开 Diff 查看器，逐文件审查修改。你还可以点击具体代码行添加评论，Claude 会根据你的反馈进行调整。

## 连接外部工具

在开始会话前，点击 **⋯** 按钮，选择 **Connectors** 可以添加外部集成：

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- 更多...

连接后，Claude 可以直接读取日历、发送消息、创建 Issue 等。

## 与 CLI 的关系

桌面应用和 CLI 使用相同的底层引擎，共享以下配置：

- `CLAUDE.md` / `CLAUDE.local.md` 项目记忆文件
- `~/.claude.json` / `.mcp.json` 中的 MCP 服务器配置
- `~/.claude/settings.json` 中的设置
- Hooks 和 Skills 配置

两者可以同时运行在同一个项目上，各自维护独立的会话历史。

## 常见问题

### 连接失败怎么办？

1. 检查 `~/.claude/config.json` 文件是否正确创建
2. 确认环境变量已正确设置（重启桌面应用使之生效）
3. 确认 API 令牌有效（可在 [控制台](https://platform.acedata.cloud/console) 查看）
4. 如果使用 `settings.json` 配置环境变量，确认文件格式正确

### 找不到安装的工具？

如果 Claude 无法找到 `npm`、`node` 等命令：

1. 确认这些工具在普通终端中能正常使用
2. 检查你的 Shell 配置文件（`~/.zshrc`、`~/.bashrc`）是否正确设置了 PATH
3. 重启桌面应用以重新加载环境变量

### 如何查看剩余额度？

登录 [AceData Cloud 控制台](https://platform.acedata.cloud/console)，即可查看当前账户的剩余额度和使用情况。
