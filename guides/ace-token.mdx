## 什么是 ACE 代币

ACE 是 Ace Data Cloud 在 **Solana 链**上发行的 SPL 代币。持有 ACE 代币即可自动获得平台 API 调用折扣，无需消耗代币——只需持有即可享受权益。

<Info>

</Info>

## 工作原理

```
您的 Solana 钱包（持有 $ACE）
    ↓ 平台定期读取链上余额
CoinInfo（记录您的地址和余额）
    ↓ 匹配 CoinPolicy 等级阈值
ConsumptionDiscount（写入折扣记录）
    ↓ API 调用时自动应用
API 账单自动减免折扣金额
```

- 平台**仅读取**链上余额，不会移动或消耗您的 ACE 代币
- 余额变化会在下一个检查周期自动更新折扣等级
- 折扣适用于所有已支持的 API 服务
