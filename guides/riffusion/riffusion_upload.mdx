---
title: "Riffusion 上传参考音频 API 对接说明"
description: "Integration guide for Riffusion on Ace Data Cloud"
---

Riffusion 允许我们上传参考音频进行二次创作，本文档讲解相关 API 的对接方法。

该 API 只有一个输入参数，就是 `audio_url`，它是一个可以公开访问的 CDN 地址，支持 mp3 后缀。

这里我们输入的 `audio_url` 是 `https://cdn.acedata.cloud/suno_demo.mp3`，是一个可以公开访问的 CDN 地址。

```bash
curl -X POST 'https://api.acedata.cloud/riffusion/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

结果如下：

```
{
  "success": true,
  "task_id": "57e8ce3a-39cb-41a2-802f-e70a324f4d0a",
  "data": {
    "audio_id": "eae26f89-b64b-404d-a80c-761996660b1c"
  }
}
```

可以看到，`data` 的 `audio_id` 字段就是上传后的歌曲 ID。

有了歌曲 ID 之后，我们便可以使用 [Riffusion Audios Generation API](https://platform.acedata.cloud/documents/riffusion-audios-integration) 来进行自定义歌曲生成了，比如说 `action` 传入 `upload_extend`，同时 `audio_id` 传入返回的歌曲 ID，就可以根据参考音频生成新的歌曲了。
