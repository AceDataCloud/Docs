---
title: "Pixverse 创建角色ID API 对接说明"
description: "Integration guide for Pixverse on Ace Data Cloud"
---

Pixverse 允许我们上传参考图片来设置角色，然后根据这个角色ID来生成视频，本文档讲解相关 API 的对接方法。

该 API 只有一个输入参数，就是 `images`，它是一个可以公开访问的 CDN 图片地址，本文将介绍以下人物图片为角色示例：

<p><img src="https://cdn.acedata.cloud/8bai0n.png" width="500" class="m-auto"></p>

这里我们输入的 `images` 是 `https://cdn.acedata.cloud/8bai0n.png`，是一个可以公开访问的 CDN 地址。

```bash
curl -X POST 'https://api.acedata.cloud/pixverse/character' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "images": ["https://cdn.acedata.cloud/8bai0n.png"]
}'
```

结果如下：

```
{
  "success": true,
  "task_id": "5b9c0493-0033-431b-a799-fb5e04b4ae19",
  "data": {
    "asset_id": 317383895242880
  }
}
```

可以看到，`data` 的 `asset_id` 字段就是参考图片上传后的角色 ID。

有了角色 ID 之后，我们便可以使用 [Pixverse Videos Generation API](https://platform.acedata.cloud/documents/00f200b3-709d-4783-ac56-3d27cc70b73d) 来进行自定义视频生成了，比如说 `action` 传入 `generate`，同时 `asset_id` 传入返回的角色 ID，就可以根据角色ID来生成新的视频了。
