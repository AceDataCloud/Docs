本文将介绍 Fish Model Get API（`GET /fish/model/{id}`）的对接说明，该接口与 [Fish Audio 官方 OpenAPI](https://docs.fish.audio/resources/api-reference/model) 完全兼容，用于**按音色 ID 查询单个克隆音色的完整详情**。

> 创建音色请参考 [Fish Model Create API](https://platform.acedata.cloud/documents/62fdf4f1-6a05-4d92-bb15-1bf78b27a14a)，分页列表查询请参考 [Fish Model Query API](https://platform.acedata.cloud/documents/5a9b3e03-2896-5606-a6b9-d9f4469f0e9d)。

## 申请流程

要使用 API，需要先到 [Fish Model API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509) 对应页面申请对应的服务，进入页面之后，点击「Acquire」按钮。

如果你尚未登录或注册，会自动跳转到登录页面邀请您来注册和登录，登录注册之后会自动返回当前页面。

在首次申请时会有免费额度赠送，可以免费使用该 API。

## 与官方 API 的差异

- **鉴权方式**：使用 `Authorization: Bearer {token}`，其中 `{token}` 是在本平台申请的密钥。
- **响应结构**：直接透传 Fish 上游的 ModelEntity 对象，不做平台 envelope 包装；错误时使用 `{success:false, error:{code,message}, trace_id}` 的平台标准结构。
- **路径参数**：`{id}` 即音色的 `_id`，可由 [Fish Model Create API](https://platform.acedata.cloud/documents/62fdf4f1-6a05-4d92-bb15-1bf78b27a14a) 创建时返回，也可由 [Fish Model Query API](https://platform.acedata.cloud/documents/5a9b3e03-2896-5606-a6b9-d9f4469f0e9d) 分页查询时获得。

## 请求示例

```shell
curl 'https://api.acedata.cloud/fish/model/d7900c21663f485ab63ebdb7e5905036' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}'
```

只需要把 URL 路径里的 `{id}` 替换成具体音色 ID，无需任何查询参数或请求体。

## 计费说明

本接口不计费——按 ID 查询音色详情是免费操作，仅 `POST /fish/model` 在请求体携带 `voices` 字段创建新音色时计费。

## 错误处理

- `400 token_mismatched`：请求参数缺失或不合法。
- `400 api_not_implemented`：请求方式或参数当前不被支持。
- `401 invalid_token`：鉴权信息缺失或无效。
- `404 not_found`：指定 `_id` 对应的音色不存在或对当前账号不可见。
- `429 too_many_requests`：超过当前账号的速率限制。
- `500 api_error`：服务器内部错误。

### 错误响应示例

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 结论

Fish Model Get API 提供与 Fish Audio 官方完全兼容的单个音色详情查询能力。在拿到音色 ID 后，可以用本接口拉取完整的 ModelEntity 对象（包括样本、状态、可见性、统计字段等），再配合 [Fish TTS API](https://platform.acedata.cloud/documents/77adcb84-d59f-5ef9-b8a0-8b35eb42a71d) 完成端到端的克隆 + 合成流程。
