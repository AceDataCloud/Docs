本文将介绍 Fish Model API 的对接说明，该接口与 [Fish Audio 官方 OpenAPI](https://docs.fish.audio/resources/api-reference/model) 完全兼容，包含：

- `POST /fish/model`：基于音频样本创建一个新的克隆音色（Voice Model）。
- `GET /fish/model`：分页查询当前账号或全平台可见的音色列表。

## 申请流程

要使用 API，需要先到 [Fish Model API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509) 对应页面申请对应的服务，进入页面之后，点击「Acquire」按钮。

如果你尚未登录或注册，会自动跳转到登录页面邀请您来注册和登录，登录注册之后会自动返回当前页面。

在首次申请时会有免费额度赠送，可以免费使用该 API。

## 与官方 API 的差异

- **鉴权方式**：使用 `Authorization: Bearer {token}`，其中 `{token}` 是在本平台申请的密钥。
- **创建模型时的样本上传**：本接口当前仅支持以 JSON 形式提交，并通过 `voices` 字段传入音频样本的 URL。Fish 官方支持 multipart/msgpack 直接上传二进制，本平台暂未实现，URL 形式覆盖了大约 80% 的常见场景。
- **响应结构**：`POST /fish/model` 与 `GET /fish/model` 都直接透传 Fish 上游的响应，不做平台 envelope 包装，错误时使用 `{success:false, error:{code,message}, trace_id}` 的平台标准结构。

## 创建音色（POST /fish/model）

最小创建请求需要 `title` 与 `voices` 两个字段。`voices` 是音频样本 URL 列表，建议每个文件 30 秒以上，采样率 16k 及以上。

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的音色",
    "voices": [
      "https://example.com/sample-voice.mp3"
    ],
    "cover_image": "https://example.com/cover.png",
    "visibility": "private"
  }'
```

成功响应直接返回 Fish 平台的 ModelEntity 对象：

```json
{
  "_id": "d7900c21663f485ab63ebdb7e5905036",
  "type": "tts",
  "title": "我的克隆音色",
  "description": "用一段播客录音克隆的音色",
  "cover_image": "https://example.com/cover.png",
  "train_mode": "fast",
  "state": "trained",
  "tags": [],
  "samples": [],
  "created_at": "2025-05-09T12:34:56.789Z",
  "updated_at": "2025-05-09T12:34:56.789Z",
  "languages": ["zh", "en"],
  "visibility": "private",
  "lock_visibility": false,
  "like_count": 0,
  "mark_count": 0,
  "shared_count": 0,
  "task_count": 0,
  "author": {
    "_id": "user_id",
    "nickname": "user_nickname",
    "avatar": "user_avatar"
  }
}
```

返回的 `_id` 即可作为后续 `POST /fish/tts` 中 `reference_id` 字段的值，用于使用该克隆音色进行语音合成。

## 查询音色列表（GET /fish/model）

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=10' \
  --data-urlencode 'page_number=1' \
  --data-urlencode 'self=true'
```

可用查询参数（与 Fish 官方一致）：

- `page_size`：每页条数，默认 10。
- `page_number`：页码，从 1 开始。
- `title`：按标题模糊搜索。
- `tag`：按标签过滤。
- `self`：传 `true` 时仅返回当前账号创建的音色。
- `author_id`：按创建者过滤。
- `language`：按音色语种过滤。
- `title_language`：按标题语种过滤。

成功响应同样直接透传 Fish 平台的分页结构：

```json
{
  "items": [
    {
      "_id": "d7900c21663f485ab63ebdb7e5905036",
      "title": "我的克隆音色",
      "description": "用一段播客录音克隆的音色",
      "cover_image": "https://example.com/cover.png",
      "type": "tts",
      "state": "trained",
      "tags": [],
      "languages": ["zh", "en"],
      "visibility": "private",
      "created_at": "2025-05-09T12:34:56.789Z",
      "updated_at": "2025-05-09T12:34:56.789Z"
    }
  ],
  "total": 1
}
```

## 计费说明

本接口仅在「创建音色」时计费（`POST /fish/model` 且请求体携带 `voices` 字段），「查询音色列表」（`GET /fish/model`）不计费。

## 错误处理

- `400 token_mismatched`：Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`：Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`：Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`：Too many requests, you have exceeded the rate limit.
- `500 api_error`：Internal server error, something went wrong on the server.

### 错误响应示例

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 结论

Fish Model API 与 Fish Audio 官方 OpenAPI 的 ModelEntity 接口完全兼容，可在零代码改动的前提下迁移已有的克隆音色管理代码。创建出的音色 `_id` 可以直接喂给 [Fish TTS API](https://platform.acedata.cloud/documents/77adcb84-d59f-5ef9-b8a0-8b35eb42a71d) 的 `reference_id` 字段进行语音合成。
