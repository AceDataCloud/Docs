本文将介绍 Fish Model Query API（`GET /fish/model`）的对接说明，该接口与 [Fish Audio 官方 OpenAPI](https://docs.fish.audio/resources/api-reference/model) 完全兼容，用于**分页查询**当前账号或全平台可见的克隆音色列表。

> 创建音色请参考 [Fish Model Create API](https://platform.acedata.cloud/documents/62fdf4f1-6a05-4d92-bb15-1bf78b27a14a)，按 `_id` 查询单个音色详情请参考 [Fish Model Get API](https://platform.acedata.cloud/documents/dabdffe7-254b-5a3f-9eca-425d614d82b9)。

## 申请流程

要使用 API，需要先到 [Fish Model API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509) 对应页面申请对应的服务，进入页面之后，点击「Acquire」按钮。

如果你尚未登录或注册，会自动跳转到登录页面邀请您来注册和登录，登录注册之后会自动返回当前页面。

在首次申请时会有免费额度赠送，可以免费使用该 API。

## 与官方 API 的差异

- **鉴权方式**：使用 `Authorization: Bearer {token}`，其中 `{token}` 是在本平台申请的密钥。
- **响应结构**：直接透传 Fish 上游的分页响应，不做平台 envelope 包装；错误时使用 `{success:false, error:{code,message}, trace_id}` 的平台标准结构。

## 请求示例

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=10' \
  --data-urlencode 'page_number=1' \
  --data-urlencode 'self=true'
```

## 查询参数

与 Fish 官方一致：

- `page_size`：每页条数，默认 10。
- `page_number`：页码，从 1 开始。
- `title`：按标题模糊搜索。
- `tag`：按标签过滤。
- `self`：传 `true` 时仅返回当前账号创建的音色。
- `author_id`：按创建者过滤。
- `language`：按音色语种过滤。
- `title_language`：按标题语种过滤。

## 响应示例

成功响应直接透传 Fish 平台的分页结构：

```json
{
  "items": [
    {
      "_id": "d7900c21663f485ab63ebdb7e5905036",
      "title": "我的克隆音色",
      "description": "用一段播客录音克隆的音色",
      "cover_image": "https://example.com/cover.png",
      "type": "tts",
      "state": "trained",
      "tags": [],
      "languages": ["zh", "en"],
      "visibility": "private",
      "created_at": "2025-05-09T12:34:56.789Z",
      "updated_at": "2025-05-09T12:34:56.789Z"
    }
  ],
  "total": 1
}
```

返回的 `_id` 即可作为后续 [Fish TTS API](https://platform.acedata.cloud/documents/77adcb84-d59f-5ef9-b8a0-8b35eb42a71d) 中 `reference_id` 字段的值，用于使用该克隆音色进行语音合成。

## 计费说明

本接口不计费——分页查询音色列表是免费操作，仅 `POST /fish/model` 在请求体携带 `voices` 字段创建新音色时计费。

## 错误处理

- `400 token_mismatched`：请求参数缺失或不合法。
- `400 api_not_implemented`：请求方式或参数当前不被支持。
- `401 invalid_token`：鉴权信息缺失或无效。
- `429 too_many_requests`：超过当前账号的速率限制。
- `500 api_error`：服务器内部错误。

### 错误响应示例

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 结论

Fish Model Query API 提供与 Fish Audio 官方完全兼容的音色检索能力，可用来在本平台维护一个属于自己的克隆音色库。配合 [Fish Model Get API](https://platform.acedata.cloud/documents/dabdffe7-254b-5a3f-9eca-425d614d82b9) 可以按 ID 拿到单个音色的完整详情。
