这篇文档目标只有一个：让你**在 5 分钟之内**，用 AceData Cloud 代理跑通第一条 Claude Code 命令。完整教程见各 IDE 子文档（[VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)）；本文只走「**终端 CLI** + **VS Code 扩展**」最快路径。

> **为什么用 AceData Cloud 代理 Claude Code**：
> - 国内直连，无需自配 VPN
> - 价格相比官方更低（按平台 Token 计费）
> - 同一把 Key 同时支持 Claude Messages API + Claude Code Token 协议

## 第 1 分钟：申请凭证

打开 [Claude Messages 服务页](https://platform.acedata.cloud/documents/claude-messages) 点击「**Acquire**」按钮：

![](https://cdn.acedata.cloud/nyq0xz.png)

平台会自动给你创建一个 Application 并赠送免费额度。把详情页里的 **Base URL** + **API Token** 两项记下来 —— 后续 5 步都要用。

| 字段 | 值 | 用途 |
|------|------|------|
| `BASE_URL` | `https://api.acedata.cloud/claude` | Claude Messages 兼容入口 |
| `API_TOKEN` | `sk-...`（详情页可复制） | Anthropic 兼容鉴权头 |

## 第 2 分钟：安装 Claude Code

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows（原生 PowerShell）：

```powershell
irm https://claude.ai/install.ps1 | iex
```

安装结束后，新开一个终端，确认能跑：

```bash
claude --version
```

> 看到版本号即可。Claude Code 自带 Node.js 运行时，不依赖你机器上的 Node 版本。

## 第 3 分钟：把环境变量指向 AceData Cloud

不要走官方 `claude login` 流程，而是用环境变量覆写。两种做法任选其一：

**做法 A：临时（仅当前 Shell 会话）**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud/claude"
export ANTHROPIC_AUTH_TOKEN="sk-你的-Token"
```

**做法 B：持久化（推荐）**

把上面两行追加到 `~/.zshrc` 或 `~/.bashrc`，然后 `source` 一下。

> **常见踩坑**：环境变量名是 `ANTHROPIC_AUTH_TOKEN`，不是 `ANTHROPIC_API_KEY`；用错名字时 Claude Code 会回退到官方端点报 401。

## 第 4 分钟：跑第一条命令

进任意 Git 仓库，跑：

```bash
claude
```

第一次启动时若提示登录，按 `Esc` 跳过。然后输入：

```
列出当前项目的依赖，并简要解释每个的用途。
```

正常会看到 Claude 调用 `read_file` / `glob` / `grep` 等工具浏览仓库，然后给出列表。屏幕底部状态栏会显示 `connected to api.acedata.cloud` —— 这是关键标志，看到它就说明代理已生效。

## 第 5 分钟：把 VS Code 扩展也接上

1. 打开 VS Code → 扩展面板 → 搜 `Claude Code`，安装 Anthropic 官方那个；
2. **Cmd+Shift+P** → 输入 `Claude Code: Set Custom API Endpoint`；
3. 填入 `https://api.acedata.cloud/claude` 然后回车；
4. 再次执行 `Claude Code: Set API Token` 填入你的 Token。

成功后侧边栏会出现 Claude Code 面板，可以拖文件进去问、可以 `@-mention` 一个文件做修改提案。所有计费都走 AceData Cloud。

## 验证你确实在走代理

在 Claude Code 对话里输入：

```
访问 https://api.acedata.cloud/whoami 并告诉我返回了什么
```

如果返回了你自己的账号信息（`{user_id, plan, ...}`），说明请求确实经过 AceData Cloud 边缘。如果跳到官方域名报 401，回到第 3 分钟检查环境变量名。

## 5 个最常被问的问题

**Q：跑了 `claude login` 后又把环境变量改成了 AceData，怎么不生效？**
A：`claude login` 会在 `~/.claude/.credentials.json` 写入官方 token，**优先级高于环境变量**。删除该文件后再 `source ~/.zshrc` 即可。

**Q：能用 `--model claude-opus-4-7` 这种模型名吗？**
A：能。AceData Cloud 代理透传 model 字段，所有 Anthropic 公开模型 + 我们扩展的 `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5` 都支持。

**Q：能配多个 Profile（个人 + 公司）吗？**
A：能。Claude Code 支持 `~/.claude/settings.json` 多 profile；或者最简单：写两个 shell 函数 `claude_personal` / `claude_work`，分别 export 不同的 `ANTHROPIC_AUTH_TOKEN` 后调 `claude $@`。

**Q：能在 GitHub Actions 里跑吗？**
A：能。详见 [Claude Code GitHub Actions 配置教程](https://platform.acedata.cloud/documents/claude-code-github-actions-integration)。

**Q：免费额度用完之后？**
A：到 [应用管理](https://platform.acedata.cloud/applications) → 选这个 Claude Application → Topup 充值（按 Token 实际消耗扣费），或者切换到积分订阅。
