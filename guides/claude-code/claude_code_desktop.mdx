Claude Code 是 Anthropic 推出的一款 **Agentic Coding** 工具，也被称为世界最强编程 Agent 之一。Claude Code 桌面应用提供了独立的图形化界面，支持 Diff 审查、并行会话（通过 Git Worktree 隔离）、远程会话等功能，无需依赖任何 IDE。

> **重要提示**：Claude Code 桌面应用**不支持**第三方 API 代理（包括 AceData Cloud）。桌面应用仅支持 Anthropic 官方订阅（Pro、Max、Teams、Enterprise）进行身份验证。`ANTHROPIC_API_KEY` 和 `ANTHROPIC_AUTH_TOKEN` 等环境变量**不会**在桌面应用中生效。
>
> 如果你需要通过 AceData Cloud 代理使用 Claude Code，请选择以下方式：
> - [终端 CLI 配置教程](https://platform.acedata.cloud/documents/claude-code-terminal-integration)（推荐）
> - [VS Code 扩展配置教程](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)
> - [JetBrains IDE 配置教程](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)

## 桌面应用概述

### 系统要求

- macOS（Intel 和 Apple Silicon）或 Windows（x64 / ARM64）
- Linux 暂不支持桌面应用
- 需要 Anthropic 官方订阅（Pro、Max、Teams 或 Enterprise）

### 下载安装

前往 [Claude 官方下载页面](https://claude.ai) 下载对应平台的安装包：

- **macOS**：下载 `.dmg` 文件，拖入 Applications 文件夹
- **Windows x64**：下载 `.exe` 安装包，按提示安装
- **Windows ARM64**：下载 ARM64 版本（注意：ARM64 不支持本地会话，需使用远程会话）

![Claude 桌面应用下载页面](https://cdn.acedata.cloud/c3c8c57264.png)

安装完成后，从 Applications 文件夹（macOS）或开始菜单（Windows）启动 Claude。

## 功能介绍

桌面应用在标准 Claude Code 体验之上增加了以下能力：

- **可视化 Diff 审查**：带内联评论的代码变更审查
- **应用预览**：内置开发服务器实时预览
- **PR 监控**：GitHub PR 状态监控，支持自动修复和自动合并
- **并行会话**：通过 Git Worktree 自动隔离的多会话支持
- **定时任务**：周期性自动运行 Claude 任务
- **连接器**：GitHub、Slack、Linear、Notion 等外部集成
- **多环境**：本地、SSH、云端三种运行环境

### 权限模式

| 模式 | 说明 |
|------|------|
| **Ask** | 每次修改前询问确认（推荐新手使用） |
| **Code** | 自动接受文件编辑，但终端命令仍需确认 |
| **Plan** | 先制定详细计划等待审批，确认后才执行 |

### 连接外部工具

在开始会话前，点击 **+** 按钮选择 **Connectors** 可以添加外部集成：

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- 更多...

### 与 CLI 的关系

桌面应用和 CLI 使用相同的底层引擎，共享以下配置：

- `CLAUDE.md` / `CLAUDE.local.md` 项目记忆文件
- `~/.claude.json` / `.mcp.json` 中的 MCP 服务器配置
- `~/.claude/settings.json` 中的设置
- Hooks 和 Skills 配置

两者可以同时运行在同一个项目上，各自维护独立的会话历史。
