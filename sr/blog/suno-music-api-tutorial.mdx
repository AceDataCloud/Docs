## Uvod u Suno

Suno je jedna od najmoćnijih AI platformi za generisanje muzike. Korišćenjem Suno API-ja preko Ace Data Cloud-a, možete jednostavnim API pozivima kreirati visokokvalitetnu muziku.

## API krajnje tačke

| Krajnja tačka | Funkcija |
|---------------|----------|
| `POST /suno/audios` | Generisanje muzike (glavna krajnja tačka) |
| `POST /suno/lyrics` | Generisanje tekstova pesama |
| `POST /suno/persona` | Upravljanje stilovima pevača |
| `POST /suno/wav` | Preuzimanje u WAV formatu |
| `POST /suno/mp4` | Preuzimanje u MP4 formatu |
| `POST /suno/tasks` | Provera statusa zadataka |

## Osnovno generisanje

### Generisanje na osnovu tekstualnog opisa

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### Generisanje prilagođenih tekstova pesama

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\n夏日的阳光洒满了海岸\n微风中传来浪花的声音\n\n[Chorus]\n让我们一起去远方\n追逐那自由的梦想",
        "style": "pop upbeat",
        "title": "夏日冒险",
    },
)
```

## Napredne funkcije

### Produženje pesme

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### Generisanje tekstova pesama

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "写一首关于冬天的歌",
    },
)
```

## Dostupni modeli

| Model      | Karakteristike       |
|------------|---------------------|
| chirp-v5   | Najnovija verzija, najbolji kvalitet zvuka |
| v4-5-plus  | Poboljšana verzija   |
| v4-5       | Stabilna verzija     |
| v4         | Klasična verzija     |

## Zaključak

Suno API, dostupan preko Ace Data Cloud platforme, pruža kompletne mogućnosti za generisanje muzike. Bilo da je u pitanju jednostavno generisanje na osnovu teksta ili kreiranje prilagođenih tekstova pesama, sve se može postići sa samo nekoliko linija koda.

Registrujte se i isprobajte na [platform.acedata.cloud](https://platform.acedata.cloud).
