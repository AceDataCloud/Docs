## Šta je OpenAI kompatibilni interfejs

OpenAI Chat Completions API format postao je industrijski de facto standard. Mnogi veliki jezički modeli nude OpenAI kompatibilni interfejs, što omogućava programerima da koriste isti kod za pristup različitim modelima.

Ace Data Cloud pruža OpenAI kompatibilni Chat Completions interfejs za modele kao što su Claude, Gemini, DeepSeek, Grok, Kimi i drugi, gde je potrebno samo promeniti Base URL i ime modela za prelazak između njih.

## Podržani modeli

| Usluga | Endpoint | Primer modela |
|--------|----------|---------------|
| Claude | `POST /v1/chat/completions` | claude-sonnet-4-6 |
| OpenAI | `POST /openai/chat/completions` | gpt-4o |
| Gemini | `POST /gemini/chat/completions` | gemini-2.5-flash |
| DeepSeek | `POST /deepseek/chat/completions` | deepseek-r1 |
| Grok | `POST /grok/chat/completions` | grok-3 |
| Kimi | `POST /kimi/chat/completions` | kimi-k2.5 |

## Jedinstveni način poziva

Svi chat modeli koriste isti format zahteva:

```python
import requests

def chat(endpoint, model, message):
    return requests.post(
        f"https://api.acedata.cloud{endpoint}",
        headers={
            "Authorization": "Bearer YOUR_API_TOKEN",
            "Content-Type": "application/json",
        },
        json={
            "model": model,
            "messages": [{"role": "user", "content": message}],
            "max_tokens": 1024,
            "temperature": 0.7,
        },
    ).json()

# Pozivanje različitih modela - samo promenite endpoint i ime modela
claude = chat("/v1/chat/completions", "claude-sonnet-4-6", "你好")
gpt = chat("/openai/chat/completions", "gpt-4o", "你好")
gemini = chat("/gemini/chat/completions", "gemini-2.5-flash", "你好")
deepseek = chat("/deepseek/chat/completions", "deepseek-r1", "你好")
```

## Streaming izlaz

Svi chat API-jevi podržavaju streaming izlaz (Server-Sent Events):

```python
data = {
    "model": "claude-sonnet-4-6",
    "messages": [{"role": "user", "content": "写一首诗"}],
    "stream": True,
}

response = requests.post(
    "https://api.acedata.cloud/v1/chat/completions",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json=data,
    stream=True,
)

for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Kompatibilnost sa OpenAI SDK

Zbog kompatibilnog formata interfejsa, možete direktno koristiti OpenAI zvanični SDK, samo promenite base_url:

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_TOKEN",
    base_url="https://api.acedata.cloud/v1",  # Claude
    # base_url="https://api.acedata.cloud/openai",  # OpenAI
    # base_url="https://api.acedata.cloud/gemini",  # Gemini
)

response = client.chat.completions.create(
    model="claude-sonnet-4-6",
    messages=[{"role": "user", "content": "你好"}],
)
print(response.choices[0].message.content)
```
