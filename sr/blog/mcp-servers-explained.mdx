## Шта је MCP

Model Context Protocol (MCP) је отворени протокол који омогућава AI асистентима (као што су Claude, Cursor) да директно позивају спољне алате и API-је. Помоћу MCP-а, AI не само да може да одговара на питања, већ и да извршава стварне операције.

## MCP Server који пружа Ace Data Cloud

| MCP Server       | PyPI пакет | Функција          |
|------------------|------------|-------------------|
| MCPSuno          | mcp-suno   | AI генерисање музике |
| MCPSerp          | mcp-serp   | Google претрага   |
| MCPMidjourney    | mcp-midjourney | AI генерисање слика |
| MCPLuma          | mcp-luma   | AI генерисање видео записа |
| MCPSora          | mcp-sora   | AI генерисање видео записа |
| MCPVeo           | mcp-veo    | AI генерисање видео записа |
| MCPNanoBanana    | mcp-nano-banana | AI генерисање слика |

## Инсталација и коришћење

### Инсталација

```bash
pip install mcp-suno  # или други MCP Server
```

### Подешавање променљивих окружења

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### Конфигурација у Cursor-у

Додајте у MCP подешавања Cursor-а:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### Конфигурација у Claude Desktop-у

Измените конфигурациони фајл Claude Desktop-а и додајте MCP Server подешавања.

## Сценарији коришћења

1. **Генерисање музике у Cursor-у**: Реците AI-ју "генериши веселу песму помоћу Suno", AI ће директно позвати API
2. **Претрага актуелних информација**: AI може користити SERP MCP Server за претрагу најновијих информација
3. **Генерисање материјала за пројекат**: AI може позвати Midjourney за генерисање слика потребних за пројекат

## MCP у односу на директне API позиве

- **MCP**: погодан за коришћење у AI алатима за програмирање, где AI аутоматски позива
- **API**: погодан за интеграцију у сопствене апликације, контролисано програмирање

Оба користе исти Ace Data Cloud API Token и позивају исте API крајње тачке.

## Резиме

MCP омогућава AI асистентима да директно позивају разне API-је Ace Data Cloud-а. Сви MCP Server-и су објављени на PyPI-ју, инсталација и конфигурација су једноставни, што чини ваше AI алатке моћнијим.

Посетите [platform.acedata.cloud](https://platform.acedata.cloud) за добијање API Token-а.
