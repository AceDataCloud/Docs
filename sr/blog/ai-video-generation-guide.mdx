## Pregled

Generisanje video zapisa pomoću AI brzo napreduje. Ace Data Cloud nudi 7 različitih API-ja za generisanje video zapisa, pokrivajući različite scenarije od teksta do videa do slike do videa.

## Dostupne usluge za generisanje video zapisa

| Usluga | Endpoint | Model | Karakteristike |
|--------|----------|-------|----------------|
| Sora   | `POST /sora/videos` | sora-2, sora-2-pro | Proizvod OpenAI, filmski kvalitet slike |
| Veo    | `POST /veo/videos` | veo3, veo3-fast | Proizvod Google, podrška za 4K |
| Kling  | `POST /kling/videos` | kling-v2-5-turbo | Proizvod Kuaishou, velika brzina |
| Luma   | `POST /luma/videos` | — | Kontrola početnog i završnog frejma |
| Hailuo | `POST /hailuo/videos` | minimax-t2v | Proizvod MiniMax |
| Seedance | `POST /seedance/videos` | doubao-seedance-1-0-pro-250528 | Proizvod ByteDance |
| Wan    | `POST /wan/videos` | wan2.6-t2v | Proizvod Alibaba |

## Brzi početak

### Generisanje video zapisa sa Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A cat playing in a sunny garden",
        "model": "sora-2",
        "duration": 10,
        "orientation": "landscape",
    },
)
print(response.json())
```

### Generisanje video zapisa sa Kling

```python
response = requests.post(
    "https://api.acedata.cloud/kling/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A white cat walking in the snow",
        "model": "kling-v2-5-turbo",
        "duration": 5,
        "aspect_ratio": "16:9",
    },
)
print(response.json())
```

### Generisanje video zapisa sa Veo

```python
response = requests.post(
    "https://api.acedata.cloud/veo/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A coffee mug rotating on a marble counter",
        "model": "veo3",
    },
)
print(response.json())
```

## Obrada asinhronih zadataka

Generisanje video zapisa obično zahteva duže vreme. Svi video API-ji podržavaju:

1. **Obaveštenja putem callback-a**: postavite `callback_url` u zahtevu, rezultat će biti automatski poslat po završetku generisanja
2. **Provera statusa putem polling-a**: proveravajte napredak zadatka preko `/tasks` endpointa

```python
# Korišćenje callback URL-a
data = {
    "prompt": "A sunrise over mountains",
    "model": "sora-2",
    "callback_url": "https://your-server.com/webhook",
}

# Ili proveravanje statusa zadatka putem polling-a
task_response = requests.post("https://api.acedata.cloud/sora/tasks",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json={"task_id": "your-task-id"})
```
