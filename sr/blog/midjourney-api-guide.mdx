## Pregled

Midjourney je trenutno jedan od najpopularnijih AI alata za generisanje slika. Ace Data Cloud pruža kompletan Midjourney API koji podržava funkcije kao što su generisanje slika, uređivanje, opisivanje i video.

## API krajnje tačke

| Krajnja tačka | Funkcija |
|---------------|----------|
| `POST /midjourney/imagine` | Generisanje slike (glavna krajnja tačka) |
| `POST /midjourney/edits` | Uređivanje slike |
| `POST /midjourney/describe` | Opis slike |
| `POST /midjourney/videos` | Slika u video |
| `POST /midjourney/seed` | Dobijanje Seed vrednosti |
| `POST /midjourney/translate` | Prevod promptova |
| `POST /midjourney/tasks` | Provera statusa zadataka |

## Osnovno generisanje slika

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/midjourney/imagine",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A serene Japanese garden with cherry blossoms, ultra detailed --ar 16:9",
        "action": "generate",
        "mode": "fast",
    },
)
result = response.json()
print(result)
```

## Uređivanje slika

### Uvećavanje (Upscale)

```python
response = requests.post(
    "https://api.acedata.cloud/midjourney/imagine",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "upscale",
        "image_id": "your-image-id",
    },
)
```

### Varijacija (Variation)

```python
response = requests.post(
    "https://api.acedata.cloud/midjourney/imagine",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "variation",
        "image_id": "your-image-id",
    },
)
```

## Opis slike

Generisanje tekstualnog opisa iz slike:

```python
response = requests.post(
    "https://api.acedata.cloud/midjourney/describe",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "image_url": "https://example.com/your-image.jpg",
    },
)
```

## Saveti za promptove

- Koristite `--ar 16:9` za kontrolu odnosa širine i visine
- Koristite `--q 2` za povećanje kvaliteta
- Koristite `--style raw` za realističniji efekat
- Postavite `translation: true` za automatski prevod kineskih promptova na engleski

## Asinhroni callback

Generisanje slika zahteva vreme, preporučuje se korišćenje callback URL-a:

```python
response = requests.post(
    "https://api.acedata.cloud/midjourney/imagine",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A futuristic cityscape at night",
        "callback_url": "https://your-server.com/webhook",
    },
)
```
