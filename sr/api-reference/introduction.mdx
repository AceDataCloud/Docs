## Osnovni URL

Osnovna adresa za sve API krajnje tačke:

```
https://api.acedata.cloud
```

## Autentifikacija

Sve krajnje tačke zahtevaju Bearer Token autentifikaciju:

```
Authorization: Bearer YOUR_API_TOKEN
```

## Online testiranje

Svaka krajnja tačka u ovoj referenci sadrži interaktivni sandbox. Unesite API Token da biste direktno testirali zahteve u pregledaču.

<Note title="Tip">
  Nabavite API Token na [platform.acedata.cloud](https://platform.acedata.cloud).
</Note>
