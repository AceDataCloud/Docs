Svi Ace Data Cloud API-ji koriste **Bearer Token** za autentifikaciju.

## Dobijanje Tokena

Prijavite se na stranicu [Applications](https://platform.acedata.cloud/console/applications?lang=sr&utm_source=docs&utm_medium=referral&utm_campaign=evergreen) i otvorite **General Application**. Ako pri prvom pristupu aplikacija nije prikazana, izaberite **Initialize General Application**. Pored polja **API KEY** kliknite na dugme za kopiranje označeno brojem **1**.

![Dugme za kopiranje ključa aplikacije označeno brojem 1](https://raw.githubusercontent.com/AceDataCloud/NanoBananaDify/2522b2f57210597af2db866445319334a1677a23/_assets/tutorial/get-api-key-en.png)

Čuvajte ključ na serveru i u primeru zamenite `YOUR_API_TOKEN` kopiranom vrednošću.

## Korišćenje Tokena

Uključite Token u `Authorization` zaglavlje svakog zahteva:

```bash
Authorization: Bearer YOUR_API_TOKEN
```


## Ograničenje brzine

Ograničenje brzine zavisi od usluge i nivoa pretplate. Kada se prekorači limit, API vraća `429 Too Many Requests`.

## Najbolje bezbednosne prakse

- Ne izlažite API Token u klijentskom kodu
- Čuvajte Token u promenljivim okruženja
- Redovno rotirajte Tokene
- Koristite različite Tokene za razvojno i produkciono okruženje
