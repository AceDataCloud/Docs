---
title: "Autentikacija"
description: "Kako koristiti Ace Data Cloud API za autentikaciju"
---

Svi Ace Data Cloud API koriste **Bearer Token** za autentikaciju.

## Dobijanje Tokena

1. Registrujte nalog na [platform.acedata.cloud](https://platform.acedata.cloud)
2. Pretplatite se na potrebne usluge
3. Kreirajte kredencijale (API Token) za svaku uslugu

## Korišćenje Tokena

Uključite Token u `Authorization` zaglavlje svakog zahteva:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Tip">
  Svaki Token je vezan za određenu pretplatu na uslugu. Različite usluge koriste različite Tokene, ili kreirajte **globalne** kredencijale za korišćenje preko usluga.
</Note>

## Ograničenje brzine

Ograničenje brzine zavisi od usluge i nivoa pretplate. Kada se prekorači limit, API vraća `429 Too Many Requests`.

## Najbolje sigurnosne prakse

- Ne izlažite API Token u klijentskom kodu
- Čuvajte Token u promenljivim okruženja
- Redovno rotirajte Tokene
- Koristite različite Tokene za razvojno i produkcijsko okruženje
