[MCP (Model Context Protocol)](https://modelcontextprotocol.io) je protokol za kontekst modela koji je razvio Anthropic, a omogućava AI modelima (kao što su Claude, GPT i drugi) da pozivaju spoljne alate putem standardizovanog interfejsa. Korišćenjem ShortURL MCP Servera koji pruža AceData Cloud, možete direktno generisati kratke linkove u AI klijentima kao što su Claude Desktop, VS Code, Cursor i drugi.

## Pregled funkcionalnosti

ShortURL MCP Server pruža sledeće ključne funkcije:

- **Skraćivanje pojedinačnih linkova** — Pretvaranje dugih URL-ova u kratke i lako deljive linkove
- **Skraćivanje linkova u seriji** — Istovremeno skraćivanje više URL-ova (do 10)
- **Uputstvo za korišćenje** — Dobijanje kompletnih uputstava i najboljih praksi
- **API informacije** — Pregled detalja API servisa i opisa kodova grešaka

## Preduslovi

Pre korišćenja potrebno je da nabavite AceData Cloud API Token:

1. Registrujte se ili prijavite na [AceData Cloud platformu](https://platform.acedata.cloud)
2. Posetite stranicu [ShortURL API](https://platform.acedata.cloud/documents/short-url)
3. Kliknite na „Acquire“ da biste dobili API Token (prvi zahtev donosi besplatan kredit)

## Instalacija i konfiguracija

### Metod 1: instalacija preko pip-a (preporučeno)

```bash
pip install mcp-shorturl
```

### Metod 2: instalacija iz izvornog koda

```bash
git clone https://github.com/AceDataCloud/ShortURLMCP.git
cd ShortURLMCP
pip install -e .
```

Nakon instalacije, možete pokrenuti servis komandom `mcp-shorturl`.

## Korišćenje u Claude Desktop-u

Izmenite konfiguracioni fajl Claude Desktop-a:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodajte sledeću konfiguraciju:

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tvoj API Token"
      }
    }
  }
}
```

Ako koristite `uvx` (nije potrebna prethodna instalacija paketa):

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "uvx",
      "args": ["mcp-shorturl"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tvoj API Token"
      }
    }
  }
}
```

Sačuvajte konfiguraciju i restartujte Claude Desktop da biste koristili ShortURL alate u razgovoru.

## Korišćenje u VS Code / Cursor-u

U korenskom direktorijumu projekta kreirajte `.vscode/mcp.json` fajl:

```json
      "env": {
```

Ili koristite `uvx`:


## Lista dostupnih alata

| Naziv alata           | Opis                               |
|-----------------------|-----------------------------------|
| `shorturl_create`     | Skraćivanje pojedinačnog URL-a    |
| `shorturl_batch_create` | Skraćivanje više URL-ova (do 10) |
| `shorturl_get_usage_guide` | Dobijanje kompletnog uputstva   |
| `shorturl_get_api_info` | Dobijanje detalja o API servisu   |

## Primer korišćenja

Nakon konfiguracije, u AI klijentu možete direktno koristiti ove funkcije prirodnim jezikom, na primer:

- „Skraćuj mi ovaj link“
- „Skraćuj ovih 5 URL-ova u seriji“
- „Generiši kratki link za deljenje“
