[MCP（Model Context Protocol）](https://modelcontextprotocol.io) је протокол контекста модела који је развио Anthropic, а омогућава AI моделима (као што су Claude, GPT итд.) да позивају спољне алате преко стандардизованог интерфејса. Кроз Veo MCP Server који пружа AceData Cloud, можете директно користити Google Veo за генерисање AI видео записа у AI клијентима као што су Claude Desktop, VS Code, Cursor.

## Преглед функција

Veo MCP Server пружа следеће основне функције:

- **Генерација видео записа из текста** — генерисање видео записа високе квалитета на основу текстуалних упита
- **Генерација видео записа из слика** — генерисање видео записа на основу слика
- **Подршка за више модела** — подршка за модели као што су veo3, veo2, veo31-fast-ingredient итд.
- **Различите резолуције** — подршка за 4K, 1080p, GIF и друге излазне формате
- **Различити аспекти** — подршка за 16:9, 9:16 и друге аспекте
- **Унапређење на 1080p** — унапређење већ генерисаних видео записа на 1080p
- **Питања о задацима** — праћење напредовања генерисања и добијање резултата

## Предуслови

Пре коришћења, потребно је да добијете AceData Cloud API Token:

1. Региструјте се или пријавите на [AceData Cloud платформу](https://platform.acedata.cloud)
2. Идите на страницу [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos)
3. Кликните на „Acquire“ да бисте добили API Token (первом пријавом добијате бесплатан кредит)

## Инсталација и конфигурација

### Опција 1: pip инсталација (препоручено)

```bash
pip install mcp-veo
```

### Опција 2: инсталација из извора

```bash
git clone https://github.com/AceDataCloud/MCPVeo.git
cd MCPVeo
pip install -e .
```

Након завршене инсталације, можете користити команду `mcp-veo` за покретање сервиса.

## Користите у Claude Desktop

Уредите конфигурациону датотеку Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додајте следећу конфигурацију:

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Ако користите `uvx` (без потребе за претходном инсталацијом пакета):

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Сачувајте конфигурацију и поново покрените Claude Desktop, а затим можете користити Veo алате у разговору.

## Листа доступних алата

| Име алата               | Опис           |
| --------------------- | ------------ |
| `veo_text_to_video`   | Генерисање видео записа из текстуалних упита  |
| `veo_image_to_video`  | Генерисање видео записа на основу слика   |
| `veo_get_1080p`       | Унапређење видео записа на 1080p |
| `veo_get_task`        | Провера статуса појединачног задатка     |
| `veo_get_tasks_batch` | Масовна провера статуса задатака     |

## Примери коришћења

Након конфигурације, можете директно користити ове функције у AI клијенту на природном језику, на пример:

- „Помози ми да генеришем видео о звезданом небу помоћу Veo“
- „Генериши 4K видео на основу ове слике пејзажа“
- „Генериши кратки видео у вертикалном формату 9:16“
- „Унапређи овај видео на 1080p“
