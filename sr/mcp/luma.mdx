[MCP（Model Context Protocol）](https://modelcontextprotocol.io) је модел протокол контекста који је развио Anthropic, а омогућава AI моделима (као што су Claude, GPT итд.) да позивају спољне алате преко стандардизованог интерфејса. Кроз Luma MCP Server који пружа AceData Cloud, можете директно генерисати AI видео у AI клијентима као што су Claude Desktop, VS Code, Cursor итд.

## Преглед функција

Luma MCP Server пружа следеће основне функције:

- **Генерација видео записа из текста** — генерисање видео записа високе квалитета из текстуалних упита
- **Генерација видео записа из слике** — генерисање видео записа почевши или завршавајући са сликом
- **Наставак видео записа** — настављање генерисања од последњег кадра постојећег видео записа
- **Различити аспекти** — подршка за различите аспекте као што су 16:9, 9:16, 1:1 итд.
- **Побољшање слике** — опционална функција за побољшање визуелног квалитета
- **Питања о задацима** — праћење напредовања генерисања и добијање резултата

## Предуслови

Пре коришћења, потребно је да добијете AceData Cloud API Token:

1. Региструјте се или пријавите на [AceData Cloud платформу](https://platform.acedata.cloud)
2. Идите на страницу [Luma Videos API](https://platform.acedata.cloud/documents/luma-videos)
3. Кликните на „Acquire“ да бисте добили API Token (первог пута добијате бесплатан кредит)

## Инсталација и конфигурација

### Опција 1: pip инсталација (препоручено)

```bash
pip install mcp-luma
```

### Опција 2: инсталација из извора

```bash
git clone https://github.com/AceDataCloud/MCPLuma.git
cd MCPLuma
pip install -e .
```

Након завршене инсталације, можете користити команду `mcp-luma` за покретање сервиса.

## Користите у Claude Desktop

Уредите конфигурациону датотеку Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додајте следећу конфигурацију:

```json
{
  "mcpServers": {
    "luma": {
      "command": "mcp-luma",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Ако користите `uvx` (без потребе за претходном инсталацијом пакета):

```json
{
  "mcpServers": {
    "luma": {
      "command": "uvx",
      "args": ["mcp-luma"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Сачувајте конфигурацију и поново покрените Claude Desktop, а затим можете користити Luma повезане алате у разговору.

## Листа доступних алата

| Име алата                          | Опис             |
| ---------------------------------- | -------------- |
| `luma_generate_video`              | Генерисање видео записа из текстуалних упита    |
| `luma_generate_video_from_image`   | Генерисање видео записа из слике        |
| `luma_extend_video`                | Наставак постојећег видео записа         |
| `luma_extend_video_from_url`       | Наставак видео записа из URL адресе |
| `luma_get_task`                    | Провера статуса појединачног задатка       |
| `luma_get_tasks_batch`             | Масовна провера статуса задатака       |

## Примери коришћења

Након конфигурације, можете директно користити природни језик за позивање ових функција у AI клијентима, на пример:

- „Помози ми да генеришем видео заласка сунца на обали“
- „Користи ову слику као први кадар, генериши видео од 5 секунди“
- „Настави овај видео, продужи га“
- „Генериши видео у вертикалном формату, однос 9:16“
