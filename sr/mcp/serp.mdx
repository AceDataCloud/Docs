[MCP (Model Context Protocol)](https://modelcontextprotocol.io) је протокол контекста модела који је развио Anthropic, који омогућава AI моделима (као што су Claude, GPT итд.) да позивају спољне алате преко стандардизованог интерфејса. Кроз SERP MCP сервер који пружа AceData Cloud, можете директно извршити Google претрагу у AI клијентима као што су Claude Desktop, VS Code, Cursor и добити резултате претраге као што су веб странице, слике, вести, видео записи, локације итд.

## Преглед функција

SERP MCP сервер пружа следеће основне функције:

- **претрага веба** — претраживање Google веб резултата
- **претрага слика** — претраживање Google слика
- **претрага вести** — претраживање Google вести
- **претрага видео записа** — претраживање Google видео записа
- **претрага локација** — претраживање Google информација о локацијама
- **претрага мапа** — претраживање Google мапа
- **више језика и региона** — подршка за прилагођене параметре земље и језика
- **филтрирање по временском распону** — филтрирање резултата по данима, недељама, месецима, годинама

## Предуслови

Пре коришћења, потребно је да добијете AceData Cloud API токен:

1. Региструјте се или пријавите на [AceData Cloud платформу](https://platform.acedata.cloud)
2. Идите на [Google SERP API](https://platform.acedata.cloud/documents/serp-google) страницу
3. Кликните на „Acquire“ да добијете API токен (первом пријавом добијате бесплатан кредит)

## Инсталација и конфигурација

### Опција 1: pip инсталација (препоручено)

```bash
pip install mcp-serp
```

### Опција 2: инсталација из извора

```bash
git clone https://github.com/AceDataCloud/SerpMCP.git
cd SerpMCP
pip install -e .
```

Након завршене инсталације, можете користити `mcp-serp` команду за покретање сервиса.

## Користите у Claude Desktop

Уредите конфигурациону датотеку Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додајте следећу конфигурацију:

```json
{
  "mcpServers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API токен"
      }
    }
  }
}
```

Ако користите `uvx` (без потребе за претходном инсталацијом пакета):

```json
{
  "mcpServers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API токен"
      }
    }
  }
}
```

Сачувајте конфигурацију и поново покрените Claude Desktop, и можете користити Google претрагу у разговору.

## Листа доступних алата

| Име алата                | Опис          |
| -------------------- | ----------- |
| `serp_google_search` | Google веб претрага |
| `serp_google_images` | Google претрага слика |
| `serp_google_news`   | Google претрага вести |
| `serp_google_videos` | Google претрага видео записа |
| `serp_google_places` | Google претрага локација |
| `serp_google_maps`   | Google претрага мапа |

## Примери коришћења

- „Помози ми да пронађем најновије AI радове“

- „Претражи данашње технолошке вести“
- „Пронађи оближње кафане на мапи“
