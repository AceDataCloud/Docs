[MCP (Model Context Protocol)](https://modelcontextprotocol.io) je protokol konteksta modela koji je pokrenuo Anthropic i omogućava AI modelima (kao što su Claude, GPT itd.) da pozivaju spoljne alate putem standardizovanih interfejsa. Putem Flux MCP Server-a koji pruža AceData Cloud, možete direktno generisati i uređivati AI slike u AI klijentima kao što su Claude Desktop, VS Code, Cursor i drugi.

## Pregled funkcionalnosti

Flux MCP Server pruža sledeće osnovne funkcije:

- **Generisanje slike iz teksta** — Generisanje visokokvalitetnih slika putem tekstualnih promptova
- **Uređivanje slika** — Uređivanje postojećih slika na osnovu tekstualnih instrukcija
- **Podrška za više modela** — Podržava više modela, kao što su Flux Pro, Flux Dev, Flux 2, Flux Kontext i drugi
- **Upit modela** — Pregled svih dostupnih modela i njihovih mogućnosti
- **Upit zadataka** — Praćenje napretka generisanja i preuzimanje rezultata

## Preduslovi

Pre korišćenja, potrebno je da dobijete AceData Cloud API Token:

1. Registrujte se ili prijavite na [AceData Cloud platformu](https://platform.acedata.cloud)
2. Idite na stranicu [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Kliknite na „Acquire“ da biste dobili API Token (prva prijava uključuje besplatan kredit)

## Metod jedan: korišćenje hostovanog MCP Server-a (preporučeno, bez instalacije)

AceData Cloud je već hostovao **Flux MCP Server** u oblaku, **bez potrebe za lokalnom instalacijom bilo kakvih zavisnosti**; samo unesite sledeći URL direktno u AI klijentu i možete ga koristiti:

```
https://flux.mcp.acedata.cloud/mcp
```

Metod autentifikacije: samo dodajte `Authorization: Bearer vaš API Token` u zaglavlje zahteva (Claude.ai to automatski završava putem OAuth-a, bez potrebe za ručnim unosom Token-a).

### Claude.ai (veb verzija, OAuth prijava, najjednostavnije)

1. Otvorite [Claude.ai](https://claude.ai) → **Customize** u donjem levom uglu → **Connectors** → **Add More**
2. U polje URL unesite: `https://flux.mcp.acedata.cloud/mcp`
3. Završite OAuth autorizaciju prijavljivanjem (automatsko preusmeravanje na AceData Cloud stranicu za prijavu)
4. Vratite se na interfejs razgovora i alat će biti dostupan za korišćenje

### Claude Desktop

Uredite konfiguracioni fajl:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Sačuvajte i ponovo pokrenite Claude Desktop da bi stupilo na snagu.

### Claude Code (komandna linija terminala)

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Ostali klijenti koji podržavaju MCP

Svaki klijent koji podržava MCP Streamable HTTP protokol (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant itd.) može se povezati popunjavanjem sledeće dve stavke:

- **URL**: `https://flux.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer vaš API Token`

## Metod dva: lokalno pokretanje (pip / uvx instalacija)

Ako vam je potrebno oflajn pokretanje, prilagođavanje koda ili postavljanje na internu mrežu, možete instalirati MCP Server lokalno i pokrenuti ga putem stdio-a.

### Instalacija

Instalacija putem pip-a (preporučeno):

```bash
pip install mcp-flux-pro
```

Ili instalacija iz izvornog koda:

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Nakon završetka instalacije, možete koristiti komandu `mcp-flux-pro` za pokretanje servisa.

### Korišćenje u Claude Desktop-u (lokalno)

Uredite konfiguracioni fajl za Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodajte sledeću konfiguraciju:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Ako koristite `uvx` (bez potrebe za prethodnom instalacijom paketa):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Sačuvajte konfiguraciju i ponovo pokrenite Claude Desktop da bi stupilo na snagu.

## Lista dostupnih alata

| Naziv alata                    | Opis                       |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | Generisanje slike putem tekstualnog prompta              |
| `flux_edit_image`      | Uređivanje postojeće slike na osnovu tekstualne instrukcije             |
| `flux_generate_video`  | FLUX 3 generisanje videa iz teksta/slike i poboljšanje postojećih nacrta |
| `flux_get_task`        | Upit statusa pojedinačnog zadatka                 |
| `flux_get_tasks_batch` | Grupni upit statusa zadataka                 |
| `flux_list_models`     | Prikaz svih dostupnih modela i njihovih mogućnosti             |
| `flux_list_actions`    | Prikaz svih dostupnih alata i primera radnih tokova           |

## Ograničenja modela i dimenzija
`flux-2-flex`, `flux-2-pro`, `flux-2-max` i Kontext modeli za `size` moraju koristiti
odnose, na primer `1:1` ili `16:9`, ne mogu koristiti dimenzije u pikselima poput `1024x1024`.
`flux-2-klein` podržava samo generisanje i nije među opcionalnim modelima u `flux_edit_image`.

`flux_generate_video` razlikuje `t2v`, `i2v`, `v2v` i
`draft_enhance` preko `request.mode`, a ulaz se prikazuje prema režimu. Poboljšanje nacrta mora referencirati sopstveni privremeni `draft_task_id`.
Slanje je podrazumevano asinhrono, sačuvajte vraćeni ID zadatka i koristite `flux_get_task` za čitanje rezultata.
