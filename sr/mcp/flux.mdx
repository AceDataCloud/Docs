[MCP (Model Context Protocol)](https://modelcontextprotocol.io) je protokol za kontekst modela koji je razvio Anthropic, omogućavajući AI modelima (kao što su Claude, GPT i drugi) da pozivaju spoljne alate putem standardizovanog interfejsa. Korišćenjem Flux MCP Servera koji pruža AceData Cloud, možete direktno generisati i uređivati AI slike u AI klijentima kao što su Claude Desktop, VS Code, Cursor i drugi.

## Pregled funkcionalnosti

Flux MCP Server pruža sledeće ključne funkcije:

- **Generisanje slika iz teksta** — kreiranje visokokvalitetnih slika na osnovu tekstualnih upita
- **Uređivanje slika** — uređivanje postojećih slika na osnovu tekstualnih instrukcija
- **Podrška za više modela** — podržava Flux Pro, Flux Dev, Flux Schnell, Flux Kontext i druge modele
- **Upit o modelima** — pregled svih dostupnih modela i njihovih mogućnosti
- **Upit o zadacima** — praćenje napretka generisanja i dobijanje rezultata

## Preduslovi

Pre korišćenja potrebno je da dobijete AceData Cloud API Token:

1. Registrujte se ili prijavite na [AceData Cloud platformu](https://platform.acedata.cloud)
2. Posetite stranicu [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Kliknite na „Acquire“ da biste dobili API Token (prvi zahtev donosi besplatni kredit)

## Instalacija i konfiguracija

### Metod 1: instalacija putem pip (preporučeno)

```bash
pip install mcp-flux-pro
```

### Metod 2: instalacija iz izvornog koda

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Nakon instalacije, možete pokrenuti servis koristeći komandu `mcp-flux-pro`.

## Korišćenje u Claude Desktop-u

Izmenite konfiguracioni fajl Claude Desktop-a:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodajte sledeću konfiguraciju:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tvoj API Token"
      }
    }
  }
}
```

Ako koristite `uvx` (nije potrebno prethodno instalirati pakete):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tvoj API Token"
      }
    }
  }
}
```

Sačuvajte konfiguraciju i restartujte Claude Desktop da biste koristili Flux alate u razgovoru.

## Korišćenje u VS Code / Cursor-u

U korenskom direktorijumu projekta kreirajte `.vscode/mcp.json`:

```json

      "command": "mcp-flux-pro",
      "env": {

    }
  }

```

Ili koristite `uvx`:


## Lista dostupnih alata

| Naziv alata           | Opis                                   |
|-----------------------|---------------------------------------|
| `flux_generate_image`  | Generisanje slike na osnovu tekstualnog upita |
| `flux_edit_image`      | Uređivanje postojeće slike na osnovu tekstualnih instrukcija |
| `flux_get_task`        | Provera statusa pojedinačnog zadatka  |
| `flux_get_tasks_batch` | Grupna provera statusa zadataka       |
| `flux_list_models`     | Prikaz svih dostupnih modela i njihovih mogućnosti |
| `flux_list_actions`    | Prikaz svih dostupnih alata i primera radnih tokova |
