[MCP (Model Context Protocol)](https://modelcontextprotocol.io) је протокол контекста модела који је развио Anthropic, који омогућава АИ моделима (као што су Claude, GPT итд.) да позивају спољне алате преко стандардизованог интерфејса. Кроз Nano Banana MCP Server који пружа AceData Cloud, можете директно генерисати и уређивати АИ слике у АИ клијентима као што су Claude Desktop, VS Code, Cursor итд.

## Преглед функција

Nano Banana MCP Server пружа следеће основне функције:

- **Генерација слика** — генерисање висококвалитетних слика на основу текстуалних упутстава
- **Уређивање слика** — измена постојећих слика или комбиновање више слика
- **Виртуално пробање** — стављање одеће на фотографије људи
- **Продуктно уметање** — постављање производа у реалне сцене
- **Подршка за више модела** — подршка за моделе nano-banana, nano-banana-2 и nano-banana-pro
- **Питања о задацима** — праћење напредовања генерисања и добијање резултата

## Предуслови

Пре коришћења, потребно је да добијете AceData Cloud API Token:

1. Региструјте се или пријавите на [AceData Cloud платформу](https://platform.acedata.cloud)
2. Идите на страницу [Nano Banana Images API](https://platform.acedata.cloud/documents/nano-banana-images)
3. Кликните на „Acquire“ да бисте добили API Token (первом пријавом добијате бесплатан кредит)

## Инсталација и конфигурација

### Опција 1: pip инсталација (препоручено)

```bash
pip install mcp-nanobanana-pro
```

### Опција 2: инсталација из извора

```bash
git clone https://github.com/AceDataCloud/MCPNanoBanana.git
cd MCPNanoBanana
pip install -e .
```

Након завршене инсталације, можете користити команду `mcp-nanobanana-pro` за покретање сервиса.

## Користите у Claude Desktop

Уредите конфигурациону датотеку Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додајте следећу конфигурацију:

```json
{
  "mcpServers": {
    "nanobanana": {
      "command": "mcp-nanobanana-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Ако користите `uvx` (без потребе за претходном инсталацијом пакета):

```json
{
  "mcpServers": {
    "nanobanana": {
      "command": "uvx",
      "args": ["mcp-nanobanana-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Након чувања конфигурације, поново покрените Claude Desktop и можете користити Nano Banana алате у разговору.

## Користите у VS Code / Cursor

У корену пројекта креирајте `.vscode/mcp.json`:

```json
{
  "servers": {
    "nanobanana": {
      "command": "mcp-nanobanana-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Или користите `uvx`:

```json
{
  "servers": {
    "nanobanana": {
      "command": "uvx",
      "args": ["mcp-nanobanana-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

## Листа доступних алата

| Име алата                      | Опис          |
| ---------------------------- | ----------- |
| `nanobanana_generate_image`  | Генерисање слика на основу текстуалних упутстава |
| `nanobanana_edit_image`      | Уређивање или комбиновање постојећих слика   |
| `nanobanana_get_task`        | Провера статуса појединачног задатка    |
| `nanobanana_get_tasks_batch` | Масовна провера статуса задатака    |

## Примери коришћења
