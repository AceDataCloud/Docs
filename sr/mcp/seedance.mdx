[MCP (Model Context Protocol)](https://modelcontextprotocol.io) je protokol konteksta modela koji je predstavio Anthropic i koji omogućava AI modelima (kao što su Claude, GPT itd.) da pozivaju eksterne alate putem standardizovanih interfejsa. Putem Seedance MCP Server-a koji pruža AceData Cloud, možete direktno koristiti ByteDance Seedance za generisanje AI video zapisa u AI klijentima kao što su Claude Desktop, VS Code, Cursor i drugi.

## Pregled funkcija

Seedance MCP Server pruža sledeće ključne funkcije:

- **Generisanje videa iz teksta** — Generisanje visokokvalitetnih video zapisa putem tekstualnih upita
- **Generisanje videa iz slike** — Generisanje video zapisa sa slikom kao referencom (prvi kadar, poslednji kadar, referentna slika i drugi režimi)
- **Podrška za više modela** — Podržava Seedance 1.x, 1.5, 2.0 i 2.5
- **Više rezolucija** — Podržava 480p, 720p, 1080p, a neki modeli podržavaju 4k
- **Više odnosa stranica** — Podržava 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 i adaptive
- **Fleksibilno trajanje** — U zavisnosti od modela, podržava 2–30 sekundi ili automatsko trajanje
- **Multimodalni video** — Podržava generisanje zvuka, referentni zvuk/video, kao i uređivanje i produžavanje videa u verziji 2.5
- **Upit zadataka** — Nadgledanje napretka generisanja i preuzimanje rezultata

## Preporučeno: OAuth autorizacija pomoću hostovanog MCP-a

Dodajte adresu servera u klijente koji podržavaju udaljeni MCP OAuth:

```text
https://seedance.mcp.acedata.cloud/mcp
```

Izaberite povezivanje ili prijavu, prijavite se na Ace Data Cloud, pregledajte dozvole i autorizujte, a zatim omogućite alate. Ovaj put ne zahteva prethodno kreiranje ili kopiranje API Token-a. Servis već podržava OAuth discovery, dinamičku registraciju klijenata (DCR) i S256 PKCE; DCR registruje klijenta, korisnik se i dalje mora prijaviti i autorizovati, a API se naplaćuje kao i obično.

| Klijent                            | Način integracije i uslovi                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Claude veb verzija ili Desktop verzija koja pruža udaljene konektore | Dodajte gorenavedenu adresu i autorizujte u interfejsu konektora; pristup zavisi od verzije i paketa. Ne upisujte udaljenu HTTP konfiguraciju u lokalnu stdio konfiguracionu datoteku.                      |
| VS Code sa podrškom za izvorni udaljeni MCP OAuth     | Pokrenite **MCP: Add Server**, izaberite HTTP, unesite adresu i prijavite se prema uputstvima; namensko AceDataCloud proširenje koristi zasebno podešavanje API Key-a. |
| Drugi klijenti                          | Potvrdite da trenutna verzija podržava udaljeni HTTP, OAuth/DCR i koristite uputstva za konfiguraciju tog klijenta. Formati konfiguracionih datoteka ne mogu se univerzalno koristiti između različitih klijenata.                     |

## Alternativni put putem API Token-a

Lokalni stdio, samostalno hostovanje ili klijenti koji ne podržavaju udaljeni OAuth koriste API Token. Prijavite se na [Ace Data Cloud platformu](https://platform.acedata.cloud), izaberite servis i kreirajte API akreditive sa potrebnim dozvolama. Sačuvajte Token u podešavanjima akreditiva klijenta ili u lokalnim promenljivama okruženja, nemojte ga stavljati u URL, sadržaj razgovora ili repozitorijum verzija. HTTP Header konfiguraciju različitih klijenata treba popuniti prema uputstvima za njihove verzije.

Instaliranje MCP-a otvorenog koda ili završavanje autorizacije ne znači dobijanje besplatnog kredita, niti garantuje vreme generisanja ili prava na komercijalnu upotrebu. Pre generisanja proverite trenutne cene servisa, stanje računa i primenljive uslove.

## Drugi način: lokalno pokretanje (pip / uvx instalacija)

Ako vam je potreban lokalni stdio, prilagođeni kod ili samostalno hostovanje, možete lokalno pokrenuti MCP Server. Generisanje i dalje zahteva mrežno pozivanje API-ja, to nije offline inferencija.

### Instalacija

Instalacija putem pip-a (preporučeno):

```bash
pip install mcp-seedance
```

Ili instalacija iz izvornog koda:

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Nakon završetka instalacije, možete koristiti komandu `mcp-seedance` za pokretanje servisa.

### Korišćenje u Claude Desktop-u (lokalno)

Uredite Claude Desktop konfiguracionu datoteku:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodajte sledeću konfiguraciju:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "vaš API Token"
      }
    }
  }
}
```

Ako koristite `uvx` (nije potrebno unapred instalirati paket):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "vaš API Token"
      }
    }
  }
}
```

Nakon čuvanja konfiguracije, ponovo pokrenite Claude Desktop da bi ona stupila na snagu.

### Korišćenje u VS Code-u (lokalno)

Kreirajte `.vscode/mcp.json` u korenskom direktorijumu projekta:

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "vaš API Token"
      }
    }
  }
}
```

Ili koristite `uvx`:

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "vaš API Token"
      }
    }
  }
}
```

Za druge lokalne klijente popunite command, args i env prema stdio uputstvima njihove trenutne verzije; nemojte direktno tretirati VS Code konfiguraciju kao univerzalni format.

## Provera rezultata i česti neuspehi

Zatražite od klijenta da generiše jednostavan video rad, sačuvajte broj zadatka i proveravajte isti zadatak dok ne dostigne uspešno završno stanje, a zatim otvorite ili reprodukujte konačni link. Uspešno povezivanje, učitavanje liste alata, HTTP 200, broj zadatka i pregled tokom obrade ne predstavljaju konačni proizvod.

Ako naiđete na 401, ponovo se prijavite ili proverite Token i dozvole; kada nema dovoljno sredstava, proverite naplatu; tokom obrade zadatka nastavite sa upitima; kod konačnog neuspeha pročitajte grešku pre nego što odlučite da li ćete pokušati ponovo, jer novo generisanje može biti ponovo naplaćeno.

## Lista dostupnih alata

| Naziv alata                                  | Opis             |
| ------------------------------------ | -------------- |
| `seedance_generate_video`            | Generisanje videa putem tekstualnog upita    |
| `seedance_generate_video_from_image` | Generisanje videa sa slikom kao referencom     |
| `seedance_get_task`                  | Upit statusa pojedinačnog zadatka       |
| `seedance_get_tasks_batch`           | Grupni upit statusa zadataka       |
| `seedance_list_models`               | Izlistavanje svih dostupnih modela i njihovih mogućnosti   |
| `seedance_list_resolutions`          | Izlistavanje dostupnih rezolucija i odnosa stranica   |
| `seedance_list_actions`              | Izlistavanje svih dostupnih alata i primera radnih tokova |
