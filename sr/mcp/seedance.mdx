[MCP (Model Context Protocol)](https://modelcontextprotocol.io) je protokol za kontekst modela koji je razvio Anthropic, omogućavajući AI modelima (kao što su Claude, GPT i drugi) da pozivaju spoljne alate putem standardizovanog interfejsa. Korišćenjem Seedance MCP Server-a koji pruža AceData Cloud, možete direktno koristiti ByteDance Seedance za generisanje AI video zapisa u AI klijentima kao što su Claude Desktop, VS Code, Cursor i drugi.

## Pregled funkcionalnosti

Seedance MCP Server pruža sledeće ključne funkcije:

- **Generisanje videa iz teksta** — kreiranje visokokvalitetnih video zapisa na osnovu tekstualnih upita
- **Generisanje videa iz slike** — kreiranje videa koristeći slike kao referencu (prvi kadar, poslednji kadar, referentni režimi)
- **Podrška za više modela** — podržava Seedance 1.5 Pro, 1.0 Pro, 1.0 Lite i druge modele
- **Više rezolucija** — podržava rezolucije 480p, 720p, 1080p i druge
- **Različiti aspektni odnosi** — podržava 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 i druge odnose
- **Fleksibilna dužina** — podržava video zapise u trajanju od 2 do 12 sekundi
- **Generisanje zvuka** — neki modeli podržavaju simultano generisanje audio zapisa
- **Praćenje zadataka** — nadzor napretka generisanja i dobijanje rezultata

## Preduslovi

Pre upotrebe, potrebno je da pribavite AceData Cloud API Token:

1. Registrujte se ili prijavite na [AceData Cloud platformu](https://platform.acedata.cloud)
2. Posetite stranicu [Seedance Videos API](https://platform.acedata.cloud/documents/seedance-videos)
3. Kliknite na „Acquire“ da biste dobili API Token (prvi zahtev donosi besplatni kredit)

## Instalacija i konfiguracija

### Metod 1: instalacija preko pip (preporučeno)

```bash
pip install mcp-seedance
```

### Metod 2: instalacija iz izvornog koda

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Nakon instalacije, možete pokrenuti servis koristeći komandu `mcp-seedance`.

## Korišćenje u Claude Desktop-u

Izmenite konfiguracioni fajl Claude Desktop-a:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodajte sledeću konfiguraciju:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tvoj API Token"
      }
    }
  }
}
```

Ako koristite `uvx` (nije potrebno prethodno instalirati pakete):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tvoj API Token"
      }
    }
  }
}
```

Sačuvajte konfiguraciju i restartujte Claude Desktop da biste koristili Seedance alate u razgovoru.

## Lista dostupnih alata

| Naziv alata                    | Opis                              |
|-------------------------------|----------------------------------|
| `seedance_generate_video`      | Generisanje videa iz tekstualnih upita |
| `seedance_generate_video_from_image` | Generisanje videa koristeći slike kao referencu |
| `seedance_get_task`            | Provera statusa pojedinačnog zadatka |
| `seedance_get_tasks_batch`     | Grupna provera statusa zadataka  |
| `seedance_list_models`         | Prikaz svih dostupnih modela i njihovih mogućnosti |
| `seedance_list_resolutions`    | Prikaz dostupnih rezolucija i aspekata slike |
| `seedance_list_actions`        | Prikaz svih dostupnih alata i primera radnih tokova |
