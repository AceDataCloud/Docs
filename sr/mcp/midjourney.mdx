[MCP (Model Context Protocol)](https://modelcontextprotocol.io) je protokol konteksta modela koji je uveo Anthropic, omogućavajući AI modelima (kao što su Claude, GPT itd.) da pozivaju spoljne alate putem standardizovanih interfejsa. Kroz Midjourney MCP Server koji pruža AceData Cloud, možete direktno generisati i uređivati AI slike u AI klijentima kao što su Claude Desktop, VS Code, Cursor itd.

## Pregled funkcija

Midjourney MCP Server pruža sledeće osnovne funkcije:

- **Generisanje slika (Imagine)** — generisanje visokokvalitetnih slika putem tekstualnih upita
- **Uređivanje slika** — lokalne izmene na već generisanim slikama
- **Transformacija slika** — uvećavanje, smanjivanje, pomeranje postojećih slika
- **Mešanje slika (Blend)** — spajanje više slika u novu sliku
- **Generisanje referentnih slika** — korišćenje referentnih slika za vođenje generisanja
- **Opis slika (Describe)** — generisanje tekstualnog opisa na osnovu slike
- **Prevod upita** — prevođenje kineskih upita na engleski
- **Dobijanje semena** — dobijanje seed vrednosti slike za reprodukciju
- **Generisanje videa** — generisanje dinamičkog videa na osnovu slika
- **Upit zadataka** — praćenje napretka generisanja i dobijanje rezultata

## Priprema

Pre korišćenja, potrebno je da dobijete AceData Cloud API Token:

1. Registrujte se ili prijavite na [AceData Cloud platformu](https://platform.acedata.cloud)
2. Idite na [Midjourney Imagine API](https://platform.acedata.cloud/documents/midjourney-imagine) stranicu
3. Kliknite na „Acquire“ da dobijete API Token (prvi put prijave donosi besplatnu kvotu)

## Instalacija i konfiguracija

### Metoda 1: pip instalacija (preporučeno)

```bash
pip install mcp-midjourney
```

### Metoda 2: instalacija iz izvornog koda

```bash
git clone https://github.com/AceDataCloud/MidjourneyMCP.git
cd MidjourneyMCP
pip install -e .
```

Nakon završetka instalacije, možete pokrenuti uslugu koristeći komandu `mcp-midjourney`.

## Korišćenje u Claude Desktop-u

Uredite konfiguracioni fajl Claude Desktop-a:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodajte sledeću konfiguraciju:

```json
{
  "mcpServers": {
    "midjourney": {
      "command": "mcp-midjourney",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tvoj API Token"
      }
    }
  }
}
```

Ako koristite `uvx` (nije potrebno prethodno instalirati paket):

```json
{
  "mcpServers": {
    "midjourney": {
      "command": "uvx",
      "args": ["mcp-midjourney"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tvoj API Token"
      }
    }
  }
}
```

Sačuvajte konfiguraciju i restartujte Claude Desktop, kako biste mogli koristiti Midjourney alate u razgovoru.

## Lista dostupnih alata

| Ime alata                      | Opis           |
| ---------------------------- | ------------ |
| `midjourney_imagine`         | Generisanje slika putem tekstualnih upita  |
| `midjourney_edit`            | Uređivanje lokalnih delova postojećih slika  |
| `midjourney_transform`       | Uvećavanje, smanjivanje, pomeranje postojećih slika |
| `midjourney_blend`           | Mešanje više slika u jednu   |
| `midjourney_with_reference`  | Generisanje slika koristeći referentne slike    |
| `midjourney_describe`        | Generisanje tekstualnog opisa na osnovu slike   |
| `midjourney_translate`       | Prevođenje upita na engleski     |
| `midjourney_get_seed`        | Dobijanje seed vrednosti slike |
| `midjourney_generate_video`  | Generisanje videa na osnovu slika     |
| `midjourney_extend_video`    | Produžavanje postojećeg videa       |
| `midjourney_get_task`        | Upit o statusu pojedinačnog zadatka     |
| `midjourney_get_tasks_batch` | Batch upit o statusu zadataka     |
