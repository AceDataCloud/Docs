[MCP (Model Context Protocol)](https://modelcontextprotocol.io) je protokol konteksta modela koji je predstavio Anthropic i koji omogućava AI modelima (kao što su Claude, GPT itd.) da pozivaju spoljne alate putem standardizovanih interfejsa. Putem Suno MCP Server-a koji pruža AceData Cloud, možete direktno generisati muziku, tekstove i upravljati audio projektima u AI klijentima kao što su Claude Desktop, VS Code, Cursor i drugi.

## Pregled funkcija

Suno MCP Server pruža sledeće ključne funkcije:

- **Generisanje muzike** — Generisanje AI muzike putem tekstualnih upita
- **Prilagođeno stvaranje** — Potpuna kontrola nad tekstovima, naslovima i muzičkim stilovima
- **Nastavljanje pesme** — Nastavljanje i produžavanje postojeće pesme od bilo koje vremenske tačke
- **Obrada/Remiks** — Kreiranje obrada u različitim stilovima
- **Generisanje tekstova** — Generisanje strukturisanih tekstova na osnovu opisa
- **Vokalni likovi** — Čuvanje i ponovna upotreba stilova glasa
- **Konverzija medija** — Preuzimanje MP4, WAV, MIDI, izdvojenih vokala i slično
- **Optimizacija stila** — Optimizacija oznaka muzičkog stila
- **Upit zadatka** — Praćenje napretka generisanja i dobijanje rezultata

## Preduslovi

Pre korišćenja, potrebno je da dobijete AceData Cloud API Token:

1. Registrujte se ili se prijavite na [AceData Cloud platformu](https://platform.acedata.cloud)
2. Idite na stranicu [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Kliknite na „Acquire“ da biste dobili API Token (prva prijava dobija besplatne kredite)

## Metod jedan: korišćenje hostovanog MCP Server-a (preporučeno, bez instalacije)

AceData Cloud je već hostovao **Suno MCP Server** u oblaku, **bez potrebe za lokalnom instalacijom bilo kakvih zavisnosti**; dovoljno je direktno uneti sledeći URL u AI klijent:

```
https://suno.mcp.acedata.cloud/mcp
```

Metod autentifikacije: dovoljno je dodati `Authorization: Bearer vaš API Token` u zaglavlje zahteva (Claude.ai to automatski završava putem OAuth-a, bez potrebe za ručnim unosom Token-a).

### Claude.ai (veb verzija, OAuth prijava, najjednostavnije)

1. Otvorite [Claude.ai](https://claude.ai) → dole levo **Customize** → **Connectors** → **Add More**
2. U polje URL unesite: `https://suno.mcp.acedata.cloud/mcp`
3. Završite OAuth autorizaciju prijavljivanjem (automatsko preusmeravanje na AceData Cloud stranicu za prijavu)
4. Vratite se na interfejs za razgovor i alat će biti dostupan

### Claude Desktop

Izmenite konfiguracioni fajl:

- macOS：`~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows：`%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Nakon čuvanja, ponovo pokrenite Claude Desktop da bi promene stupile na snagu.

### Claude Code (terminalska komandna linija)

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

## Metod dva: lokalno pokretanje (pip / uvx instalacija)

Ako vam je potrebno oflajn pokretanje, prilagođavanje koda ili postavljanje u internu mrežu, možete instalirati MCP Server lokalno i pokrenuti ga putem stdio-a.

### Instalacija

Instalacija putem pip-a (preporučeno):

```bash
pip install mcp-suno
```

Ili instalacija iz izvornog koda:

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

Nakon završetka instalacije, možete koristiti komandu `mcp-suno` za pokretanje usluge.

### Korišćenje u Claude Desktop-u (lokalno)

Izmenite konfiguracioni fajl Claude Desktop-a:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodajte sledeću konfiguraciju:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Ako koristite `uvx` (bez potrebe za prethodnom instalacijom paketa):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Nakon čuvanja konfiguracije, ponovo pokrenite Claude Desktop da bi promene stupile na snagu.

## Napredna kontrola i Studio projekti

`suno_generate_music` podržava `variety`; `suno_generate_custom_music` dodatno podržava
`max_mode` i `audio_weight`. `max_mode` koristi viši API tarifni nivo i podrazumevano nije omogućen,
treba ga postaviti nakon što korisnik izričito izabere poboljšani režim. Trenutne cene su one na stranici platformskih usluga.

`suno_generate_with_custom_model` može koristiti `instrumental=true` za generisanje instrumentalne muzike ili koristiti
`lyric_prompt` za automatsko generisanje teksta pesme; u suprotnom pružite `lyric`. Naslov i stil mogu biti izostavljeni, a mogu se proslediti i
`negative_tags`, `vocal_gender`, `weirdness`, `style_influence`, `duration` i
`callback_url`. Eksplicitne kontrolne vrednosti `0` će biti zadržane.

`suno_manage_project` podržava opcione vrednosti `create`, `retrieve`, `save`,
`upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`,
`remove_track`, `render` za `request.action`. Ulaz se razlikuje prema radnji, a izmene projekta treba da koriste poslednji pročitani `version_id`;
pri čuvanju prosledite kompletan `state`, zadržavajući postojeće numere i polja.

Osim za `retrieve`, za svaki poziv mora biti naveden `idempotency_key`. Za nove operacije upisivanja koristite novi ključ;
kada istekne vreme ili je rezultat prijema neizvestan, zadržite originalni ključ i ponovite sa potpuno istim zahtevom, ili proverite originalni zadatak, nemojte automatski
menjati ključ i ponovo slati naplatnu generaciju. Intervali izvornog zvuka koriste sekunde, a intervali vremenske ose projekta koriste broj taktova. Generisanje samo kreira kandidate,
potrebno je odabrati kandidata i pozvati `commit_candidate` da bi se upisao u numeru.

Za asinhrono prihvaćeni `task_id` koristite `suno_get_task` za upit. Kada je `finished_at` prazan, nastavite da čekate,
a nakon završnog stanja proverite `response.success` i greške; nemojte uspešan prijem smatrati uspešnim generisanjem, potvrđivanjem ili izvozom.
`suno_get_tasks_batch` vraća kompletne JSON zapise zadataka, čuvajući objekte prilagođenih modela, stanja projekata,
kandidate i različite rezultate poput MIDI-ja. Za kompletan tok rada pogledajte [Vodič za Studio projekte](https://platform.acedata.cloud/documents/suno-projects-integration).
