[MCP (Model Context Protocol)](https://modelcontextprotocol.io) je protokol modela konteksta koji je uveo Anthropic, omogućavajući AI modelima (kao što su Claude, GPT itd.) da pozivaju spoljne alate putem standardizovanih interfejsa. Kroz Suno MCP Server koji pruža AceData Cloud, možete direktno generisati muziku, tekstove i upravljati audio projektima u AI klijentima kao što su Claude Desktop, VS Code, Cursor.

## Pregled Funkcija

Suno MCP Server pruža sledeće osnovne funkcije:

- **Generisanje muzike** — generisanje AI muzike putem tekstualnih upita
- **Prilagođeno stvaranje** — potpuna kontrola nad tekstovima, naslovima i muzičkim stilovima
- **Produžavanje pesama** — nastavak postojećih pesama od bilo koje tačke
- **Obrade/Remiks** — kreiranje obrade u različitim stilovima
- **Generisanje tekstova** — generisanje strukturiranih tekstova prema opisu
- **Vokalni likovi** — čuvanje i ponovna upotreba stilova glasa
- **Konverzija medija** — dobijanje MP4, WAV, MIDI, odvajanje vokala itd.
- **Optimizacija stila** — optimizacija oznaka muzičkog stila
- **Upit zadataka** — praćenje napretka generisanja i dobijanje rezultata

## Priprema

Pre korišćenja, potrebno je da dobijete AceData Cloud API Token:

1. Registrujte se ili prijavite na [AceData Cloud platformu](https://platform.acedata.cloud)
2. Idite na stranicu [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Kliknite na „Acquire“ da dobijete API Token (prvi put se dodeljuje besplatna količina)

## Instalacija i Konfiguracija

### Metoda 1: pip instalacija (preporučeno)

```bash
pip install mcp-suno
```

### Metoda 2: Instalacija iz izvora

```bash
git clone https://github.com/AceDataCloud/MCPSuno.git
cd MCPSuno
pip install -e .
```

Nakon završetka instalacije, možete koristiti komandu `mcp-suno` za pokretanje usluge.

## Korišćenje u Claude Desktop-u

Uredite konfiguracioni fajl Claude Desktop-a:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodajte sledeću konfiguraciju:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tvoj API Token"
      }
    }
  }
}
```

Ako koristite `uvx` (nije potrebno prethodno instalirati paket):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tvoj API Token"
      }
    }
  }
}
```

Sačuvajte konfiguraciju i restartujte Claude Desktop, kako biste mogli koristiti Suno alate u razgovoru.

## Korišćenje u VS Code / Cursor-u

## Lista dostupnih alata

| Ime alata                     | Opis           |
| ----------------------------- | -------------- |
| `suno_generate_music`        | Generisanje muzike putem tekstualnih upita  |
| `suno_generate_custom_music` | Generisanje muzike sa prilagođenim tekstovima i stilovima |
| `suno_extend_music`          | Produžavanje pesama od određene tačke   |
| `suno_cover_music`           | Kreiranje obrade pesme       |
| `suno_concat_music`          | Spajanje delova pesama       |
| `suno_generate_with_persona` | Generisanje muzike sa određenim vokalnim likom |
| `suno_remaster_music`        | Ponovno masterovanje       |
| `suno_stems_music`           | Odvajanje audio traka (vokal/aranžman)  |
| `suno_replace_section`       | Zamena određenih delova pesme   |
| `suno_generate_lyrics`       | Generisanje tekstova prema opisu     |
| `suno_create_persona`        | Kreiranje vokalnog lika       |
| `suno_get_mp4`               | Dobijanje MP4 videa pesme  |
| `suno_get_timing`            | Dobijanje vremenske osovine za tekst      |
| `suno_extract_vocals`        | Ekstrakcija vokala         |
| `suno_get_wav`               | Dobijanje visokokvalitetnog WAV    |
| `suno_get_midi`              | Dobijanje MIDI fajla   |
| `suno_optimize_style`        | Optimizacija oznaka muzičkog stila     |
| `suno_mashup_lyrics`         | Kombinovanje tekstova         |
| `suno_upload_audio`          | Učitavanje prilagođene muzike      |
| `suno_get_task`              | Upit o statusu pojedinačnog zadatka     |
| `suno_get_tasks_batch`       | Grupni upit o statusu zadataka     |

## Primeri korišćenja

Nakon završene konfiguracije, možete direktno koristiti ove funkcije u AI klijentima putem prirodnog jezika, na primer:

- „Pomozi mi da generišem pesmu o letu“
- „Obradi ovu pesmu u džez stilu“
- „Produži ovu pesmu, počevši od 30. sekunde“
- „Generiši tekst na kineskom, tema je putovanje“
- „Odvoji vokale iz ove pesme“
- „Pomozi mi da ovu pesmu konvertujem u MIDI format“
