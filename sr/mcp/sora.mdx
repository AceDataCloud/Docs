[MCP（Model Context Protocol）](https://modelcontextprotocol.io) је модел протокол контекста који је развио Anthropic, који омогућава AI моделима (као што су Claude, GPT итд.) да позивају спољне алате преко стандардизованог интерфејса. Кроз Sora MCP Server који пружа AceData Cloud, можете директно користити OpenAI Sora за генерисање AI видео записа у AI клијентима као што су Claude Desktop, VS Code, Cursor.

## Преглед функција

Sora MCP Server пружа следеће основне функције:

- **Генерација видео записа из текста** — генерисање видео записа високе квалитета на основу текстуалних упита
- **Генерација видео записа из слика** — генерисање видео записа на основу слика
- **Видео записи са доследношћу ликова** — одржавање доследности ликова користећи референтне слике
- **Асимптотска генерација** — подршка за асинхроно подношење задатака и упит резултата
- **Различите оријентације слике** — подршка за хоризонталну (landscape) и вертикалну (portrait) оријентацију
- **Упит задатака** — праћење напредовања генерације и добијање резултата

## Предуслови

Пре коришћења, потребно је да добијете AceData Cloud API Token:

1. Региструјте се или пријавите на [AceData Cloud платформу](https://platform.acedata.cloud)
2. Идите на страницу [Sora Videos API](https://platform.acedata.cloud/documents/sora-videos)
3. Кликните на „Acquire“ да бисте добили API Token (перви пут добијате бесплатан кредит)

## Инсталација и конфигурација

### Опција 1: pip инсталација (препоручено)

```bash
pip install mcp-sora
```

### Опција 2: инсталација из извора

```bash
git clone https://github.com/AceDataCloud/SoraMCP.git
cd SoraMCP
pip install -e .
```

Након инсталације, можете користити команду `mcp-sora` за покретање сервиса.

## Користите у Claude Desktop

Уредите конфигурациону датотеку Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Додајте следећу конфигурацију:

```json
{
  "mcpServers": {
    "sora": {
      "command": "mcp-sora",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Ако користите `uvx` (без потребе за претходном инсталацијом пакета):

```json
{
  "mcpServers": {
    "sora": {
      "command": "uvx",
      "args": ["mcp-sora"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Након чувања конфигурације, поново покрените Claude Desktop да бисте могли да користите Sora алате у разговору.

## Листа доступних алата

| Име алата                              | Опис             |
| ------------------------------------ | -------------- |
| `sora_generate_video`                | Генерисање видео записа на основу текстуалних упита    |
| `sora_generate_video_from_image`     | Генерисање видео записа на основу слика     |
| `sora_generate_video_with_character` | Генерисање доследног видео записа користећи референтне слике |
| `sora_generate_video_async`          | Асимптотско подношење задатака за генерисање видео записа     |
| `sora_get_task`                      | Упит статуса појединачног задатка       |
| `sora_get_tasks_batch`               | Пакетни упит статуса задатака       |

## Примери коришћења

Након конфигурације, можете директно користити ове функције у AI клијенту на природном језику, на пример:

- „Помози ми да генеришем видео мачке која трчи по трави користећи Sora“
- „Генериши видео на основу ове фотографије особе, одржавајући доследност лика“
- „Генериши видео у вертикалној оријентацији, садржај је излазак сунца у граду“
- „Асимптотски генериши видео и касније провери резултате“
