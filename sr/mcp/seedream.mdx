[MCP (Model Context Protocol)](https://modelcontextprotocol.io) je protokol za kontekst modela koji je razvio Anthropic, omogućavajući AI modelima (kao što su Claude, GPT i drugi) da pozivaju spoljne alate putem standardizovanog interfejsa. Korišćenjem Seedream MCP Server-a koji pruža AceData Cloud, možete direktno koristiti ByteDance Seedream za generisanje i uređivanje AI slika u AI klijentima kao što su Claude Desktop, VS Code, Cursor i drugi.

## Pregled funkcionalnosti

Seedream MCP Server nudi sledeće ključne funkcije:

- **Generisanje slika iz teksta** — generisanje visokokvalitetnih slika pomoću tekstualnih upita (podržani su kineski i engleski)
- **Uređivanje slika** — modifikacija postojećih slika u pogledu stila, pozadine, atributa i slično
- **Virtuelno probavanje odeće** — postavljanje odeće na fotografije ljudi
- **Podrška za više modela** — podržani su Seedream v4.5, v4.0, v3.0 T2I, SeedEdit v3.0 I2I i drugi modeli
- **Više rezolucija** — podrška za 1K, 2K, 4K i adaptivne rezolucije
- **Kontrola semena (seed)** — reproduktivni rezultati generisanja pomoću parametra seed
- **Praćenje zadataka** — nadzor napretka generisanja i dobijanje rezultata

## Preduslovi

Pre upotrebe potrebno je da dobijete AceData Cloud API Token:

1. Registrujte se ili prijavite na [AceData Cloud platformu](https://platform.acedata.cloud)
2. Posetite stranicu [Seedream Images API](https://platform.acedata.cloud/documents/seedream-images)
3. Kliknite na „Acquire“ da biste dobili API Token (prvi zahtev donosi besplatan kredit)

## Instalacija i konfiguracija

### Metod 1: instalacija preko pip-a (preporučeno)

```bash
pip install mcp-seedream-pro
```

### Metod 2: instalacija iz izvornog koda

```bash
git clone https://github.com/AceDataCloud/MCPSeedream.git
cd MCPSeedream
pip install -e .
```

Nakon instalacije, možete pokrenuti servis komandom `mcp-seedream-pro`.

## Korišćenje u Claude Desktop-u

Izmenite konfiguracioni fajl Claude Desktop-a:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodajte sledeću konfiguraciju:

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tvoj API Token"
      }
    }
  }
}
```

Ako koristite `uvx` (nije potrebno prethodno instalirati pakete):

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tvoj API Token"
      }
    }
  }
}
```

Sačuvajte konfiguraciju i restartujte Claude Desktop da biste koristili Seedream alate u razgovoru.

## Lista dostupnih alata

| Naziv alata               | Opis                          |
|---------------------------|-------------------------------|
| `seedream_generate_image` | Generisanje slike iz tekstualnog upita |
| `seedream_edit_image`     | Uređivanje ili modifikacija postojeće slike |
| `seedream_get_task`       | Provera statusa pojedinačnog zadatka |
| `seedream_get_tasks_batch`| Grupna provera statusa zadataka |
| `seedream_list_models`    | Prikaz svih dostupnih modela i njihovih mogućnosti |
| `seedream_list_sizes`     | Prikaz dostupnih dimenzija i opcija rezolucije slika |
