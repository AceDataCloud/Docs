Glavna funkcija SeeDream Tasks API je da omogućava upit o statusu izvršenja zadatka putem ID-a zadatka generisanog kroz SeeDream Images Generation API.

Ovaj dokument će detaljno opisati integraciju SeeDream Tasks API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz SeeDream Tasks API, možete lako ostvariti upit o statusu izvršenja zadatka iz SeeDream Images Generation API.

## Proces prijave

Da biste koristili SeeDream Images Generation API, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, koji čuvate za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozvati sve usluge platforme, bez potrebe da se za svaku uslugu posebno prijavljujete.** Prvi put kada se prijavite, dobićete besplatnu kvotu za korišćenje; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Potpuna dokumentacija: [SeeDream Images Generation API →](https://platform.acedata.cloud/documents/seedream-images)

SeeDream Tasks API može se koristiti za upit o rezultatima SeeDream Images Generation API. O tome kako koristiti SeeDream Images Generation API, molimo vas da se obratite dokumentaciji [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images-integration).

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se šalje.
- `action`: način operacije nad zadatkom.

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na različitim jezicima, kao što je prikazano na slici:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/seedream/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "a6e0d456-189b-4c78-9232-2fe72166ab39",
  "action": "retrieve"
}'
```

### Primer odgovora

Ako je zahtev uspešan, API će vratiti detaljne informacije o ovom zadatku. Na primer:

```json
{
  "success": true,
  "task_id": "84d1544a-9043-4dde-a98b-e889dacd75f6",
  "trace_id": "176acf03-7ca7-4fc6-85db-e3724d4f59eb",
  "data": [
    {
      "prompt": "bela sijamska mačka",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/6e5f9085-cc4a-4801-b77b-31550129ff19.jpg"
    }
  ]
}
```

Vraćeni rezultati sadrže više polja, koja su opisana kao:

- `success`, status trenutnog zadatka generisanja videa.
- `task_id`, ID trenutnog zadatka generisanja videa.
- `trace_id`, ID trenutnog praćenja videa.
- `data`, lista rezultata trenutnog zadatka generisanja slika.
  - `image_url`, link do trenutnog zadatka generisanja slike.
  - `prompt`, upit.
  - `size`: pikseli generisane slike.

- `elapsed`，vreme trajanja izvršenja zadatka, u sekundama (decimalni, sa 3 decimalna mesta). Ova stavka se ne vraća ako zadatak nije završen.

## 错误处理

U slučaju greške prilikom pozivanja API-ja, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Loš zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Loš zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neautorizovano, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste limit brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.

### 错误响应示例

```json

    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"

```
