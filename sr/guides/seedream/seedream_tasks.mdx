Главна функција SeeDream Tasks API је да омогући проверу статуса извршења задатка путем ID-a задатка генерисаног помоћу SeeDream Images Generation API.

Овај документ ће детаљно описати упутство за интеграцију SeeDream Tasks API, помажући вам да лако интегришете и у потпуности искористите моћне функције овог API. Користећи SeeDream Tasks API, можете лако проверити статус извршења задатака из SeeDream Images Generation API.

## Процес пријаве

Да бисте користили SeeDream Tasks API, прво морате да посетите страницу за пријаву [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images) и затражите одговарајућу услугу, а затим копирајте ID задатка из SeeDream Images Generation API, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

На крају, идите на страницу Tasks API [SeeDream Tasks API](https://platform.acedata.cloud/documents/seedream-tasks) и затражите одговарајућу услугу, а након уласка на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![страница за пријаву](https://cdn.acedata.cloud/rci31i.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на [страницу за пријаву](https://platform.acedata.cloud) која вас позива да се региструјете и пријавите, а након пријаве и регистрације аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну количину, коју можете користити без накнаде.

## Пример захтева

SeeDream Tasks API може се користити за проверу резултата SeeDream Images Generation API. За информације о томе како користити SeeDream Images Generation API, молимо вас да се упутите на документ [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images-integration).

Узмимо за пример ID задатка који је вратила услуга SeeDream Images Generation API и демонстрирајмо како користити овај API. Хајде да претпоставимо да имамо ID задатка: 20068983-0cc9-4c6a-aeb6-9c6a3c668be0, а затим ћемо демонстрирати како да пренесемо ID задатка.

### Подешавање заглавља захтева и тела захтева

**Request Headers** укључује:

- `accept`: одређује да се примају одговори у JSON формату, овде се попуњава као `application/json`.
- `authorization`: кључ за позивање API, након захтева можете директно изабрати из падајућег менија.

**Request Body** укључује:

- `id`: ID задатка који се преноси.
- `action`: начин операције над задатком.

Подешавање је као на слици испод:

<p><img src="https://cdn.acedata.cloud/yuyte9.png" width="500" className="m-auto" /></p>

### Пример кода

Можете приметити да су на десној страни странице аутоматски генерисани кодови на различитим језицима, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/b0wt0d.png" width="500" className="m-auto" /></p>

Делимични примери кода су следећи:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/seedream/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "a6e0d456-189b-4c78-9232-2fe72166ab39",
  "action": "retrieve"
}'
```

### Пример одговора

Након успешног захтева, API ће вратити детаље о овом задатку. На пример:

```json
{
  "success": true,
  "task_id": "84d1544a-9043-4dde-a98b-e889dacd75f6",
  "trace_id": "176acf03-7ca7-4fc6-85db-e3724d4f59eb",
  "data": [
    {
      "prompt": "бела сијамска мачка",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/6e5f9085-cc4a-4801-b77b-31550129ff19.jpg"
    }
  ]
}
```

Враћени резултат има више поља, описаних као:

- `success`, статус тренутног задатка за генерисање видеа.
- `task_id`, ID тренутног задатка за генерисање видеа.
- `trace_id`, ID за праћење тренутног видеа.
- `data`, списак резултата тренутног задатка за генерисање слика.
  - `image_url`, линк за тренутни задатак за генерисање слика.
  - `prompt`, упутство.
  - `size`: пиксели генерисане слике.

## Операција масовног упита

**Request Body** укључује:

- `ids`: низ ID-ова задатака који се преносе.
- `action`: начин операције над задатком.

## Greška u obradi

U slučaju greške prilikom pozivanja API-ja, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Loš zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Loš zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neautorizovano, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste limit brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.

### Primer greške u odgovoru
