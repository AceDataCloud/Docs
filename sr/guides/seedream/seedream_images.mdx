Ovaj dokument predstavlja uputstvo za integraciju SeeDream Images Generation API, koji omogućava generisanje slika putem unosa prilagođenih parametara koristeći zvanične SeeDream slike.

## Proces prijave

Da biste koristili API, potrebno je prvo da se prijavite na odgovarajuću stranicu [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images). Nakon ulaska na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ukoliko niste prijavljeni ili registrovani, bićete automatski preusmereni na stranicu za prijavu gde možete da se registrujete i prijavite. Nakon prijave ili registracije, bićete vraćeni na trenutnu stranicu.

Prilikom prve prijave dobijate besplatan kredit koji omogućava besplatno korišćenje API-ja.

## Osnovna upotreba

Prvo je potrebno razumeti osnovni način korišćenja, koji podrazumeva unos prompta `prompt`, akcije `action` i dimenzija slike `size` da biste dobili obrađeni rezultat. Potrebno je poslati polje `action` sa vrednošću `generate`, kao i prompt. Detalji su sledeći:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Ovde su definisani Request Headers, uključujući:

- `accept`: format odgovora koji želite da primite, ovde je `application/json` (JSON format).
- `authorization`: API ključ za pozivanje API-ja, koji možete izabrati nakon prijave.

Takođe, podešava se Request Body koji uključuje:

- `prompt`: tekstualni prompt.
- `model`: model za generisanje, podrazumevano `doubao-seedream-5.0-lite`. Podržani modeli su `doubao-seedream-5.0-lite` (najnoviji), `doubao-seedream-4.5`, `doubao-seedream-4.0`, `doubao-seedream-3.0-t2i`, `doubao-seededit-3.0-i2i`.
- `image`: ulazna slika, podržani su URL ili Base64 kodiranje. Modeli `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0` podržavaju unos jedne ili više slika, `doubao-seededit-3.0-i2i` podržava samo jednu sliku, dok `doubao-seedream-3.0-t2i` ne podržava ovaj parametar.
- `size`: dimenzije generisane slike, podržane su dve opcije koje se ne smeju kombinovati. Opcija 1 | definisanje rezolucije (npr. `2K`, `3K`, `4K`) uz opis odnosa širine i visine u promptu. Opcija 2 | precizne dimenzije u pikselima, podrazumevano `2048x2048`, sa različitim opsegom u zavisnosti od modela.
- `seed`: seme za generisanje nasumičnosti modela, vrednosti u opsegu [-1, 2147483647]. Podržano samo za `doubao-seedream-3.0-t2i` i `doubao-seededit-3.0-i2i`.
- `sequential_image_generation`: generisanje serije povezanih slika na osnovu unosa. Podržano za `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0`, podrazumevano `disabled`.
- `stream`: kontrola režima strimovanja izlaza. Podržano za `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0`, podrazumevano `false`.
- `guidance_scale`: stepen usklađenosti izlaza modela sa promptom, veća vrednost znači veću povezanost. Opseg [1, 10]. Podrazumevana vrednost za `doubao-seedream-3.0-t2i` je 2.5, za `doubao-seededit-3.0-i2i` 5.5, ostali modeli ne podržavaju ovaj parametar.
- `response_format`: format povratne vrednosti slike, podrazumevano `url`, podržano i `b64_json`.
- `watermark`: da li da se doda vodeni žig na generisanu sliku, podrazumevano `true`.
- `output_format`: format fajla generisane slike, podržani su `jpeg` (podrazumevano) i `png`. Podržano samo za `doubao-seedream-5.0-lite`.
- `tools`: konfiguracija alata koje model može koristiti, trenutno podržava `web_search` (pretraga na mreži). Podržano samo za `doubao-seedream-5.0-lite`.
- `callback_url`: URL za povratni poziv sa rezultatima.

Nakon izbora, sa desne strane se generiše odgovarajući kod, kao što je prikazano:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

Klikom na dugme „Try“ možete testirati API. Kao na slici, dobijen je sledeći rezultat:

```json
{
  "success": true,
  "task_id": "25027ba3-0430-4a1b-91c8-d2297f19ba73",
  "trace_id": "8043a9e9-692f-43b0-82f7-5890f798be38",
  "data": [
    {
      "prompt": "a white siamese cat",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/3c060029-69b1-406f-a957-fcd55ddc9386.jpg"
    }
  ]
}
```

Povratni odgovor sadrži sledeća polja:

- `success`: status zadatka generisanja slike.
- `task_id`: ID zadatka generisanja slike.
- `trace_id`: ID za praćenje zadatka.
- `data`: lista rezultata generisanja slike.
  - `image_url`: URL generisane slike.
  - `prompt`: prompt koji je korišćen.
  - `size`: dimenzije generisane slike u pikselima.

Dobijena je zadovoljavajuća slika i potrebno je samo preuzeti generisanu SeeDream sliku preko linka u `data`.

Takođe, možete direktno kopirati generisani kod za integraciju, na primer CURL primer:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-4-0-250828",
  "prompt": "a white siamese cat"
}'
```

## Zadatak uređivanja slike

Ukoliko želite da uredite postojeću sliku, parametar `image` mora sadržati URL slike koju želite da izmenite.

- `model`: model koji se koristi za uređivanje, `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0` podržavaju unos jedne ili više slika, dok `doubao-seededit-3.0-i2i` podržava samo jednu sliku.
- `image`: slika ili slike koje se uređuju.

Primer unosa:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Odgovarajući kod:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Klikom na pokretanje dobijate rezultat odmah, na primer:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Rezultat predstavlja izmenjenu verziju originalne slike, slično kao u prethodnom primeru.

## Asinhroni povratni poziv

Pošto generisanje slika putem SeeDream Images Generation API traje oko 1-2 minuta, a HTTP zahtev može dugo ostati otvoren, što troši sistemske resurse, API podržava asinhroni povratni poziv.

Proces je sledeći: klijent prilikom slanja zahteva dodatno navodi polje `callback_url`. API odmah vraća odgovor sa poljem `task_id` koje predstavlja ID zadatka. Kada je zadatak završen, rezultat generisanja slike se šalje POST JSON zahtevom na navedeni `callback_url`, uključujući i `task_id` za povezivanje rezultata sa zadatkom.

Primer dobijen odmah nakon slanja zahteva:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

Primer sadržaja povratnog poziva:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Rezultat sadrži `task_id` koji omogućava povezivanje sa originalnim zadatkom.

## Obrada grešaka

Prilikom poziva API-ja, u slučaju greške, API vraća odgovarajući kod i poruku. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Nije autorizovano, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, prekoračen limit.
- `500 api_error`: Interna greška servera.

### Primer odgovora sa greškom

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
