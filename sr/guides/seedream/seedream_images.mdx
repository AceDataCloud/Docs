Овај чланак ће представити упутство за интеграцију SeeDream Images Generation API, који може генерисати SeeDream званичне слике уношењем прилагођених параметара.

## Процес пријаве

Да бисте користили API, прво морате да одете на [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images) одговарајућу страницу и затражите одговарајућу услугу, након уласка на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, након пријаве и регистрације аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, коју можете користити за API.

## Основна употреба

Прво, потребно је разумети основни начин коришћења, а то је унос кључне речи `prompt`, акције `action`, величине слике `size`, и добићете обрађени резултат. Прво је потребно једноставно проследити поље `action`, чија вредност је `generate`, а затим треба да унесемо кључну реч, конкретан садржај је следећи:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Можете видети да смо подесили Request Headers, укључујући:

- `accept`: каквог формата желите да примите одговор, овде је написано `application/json`, тј. JSON формат.
- `authorization`: кључ за позивање API, након захтева можете директно изабрати из падајућег менија.

Такође смо подесили Request Body, укључујући:

- `prompt`: кључна реч.
- `model`: модел генерисања, подразумевано `doubao-seedream-4.0`.
- `image`: информације о унетој слици, подржава URL или Base64 кодирање. Међу њима, `doubao-seedream-4.5`, `doubao-seedream-4.0` подржавају унос једне или више слика, `doubao-seededit-3.0-i2i` подржава само унос једне слике, `doubao-seededit-3.0-t2i` не подржава овај параметар.
- `size`: одређује информације о величини генерисане слике, подржава следеће две методе, не може се комбиновати. Метод 1 | Одредите резолуцију генерисане слике и у `prompt` на природном језику опишите однос ширине и висине слике, облик слике или сврху слике, на крају модел одређује величину генерисане слике. Метод 2 | Одредите ширину и висину у пикселима: подразумевана вредност: `2048x2048`, у зависности од модела подразумеване вредности су различите.
- `seed`: семе случајног броја, користи се за контролу случајности садржаја генерисаног моделом. Опсег вредности је [-1, 2147483647]. Само `doubao-seedream-3.0-t2i`, `doubao-seededit-3.0-i2i` подржавају овај параметар.
- `sequential_image_generation`: група слика: на основу вашег уноса, генерише се група слика повезаних са садржајем. Само `doubao-seedream-4.5`, `doubao-seedream-4.0` подржавају овај параметар, подразумевано `disabled`.
- `stream`: контролише да ли да се укључи режим стримовања. Само `doubao-seedream-4.5`, `doubao-seedream-4.0` подржавају овај параметар, подразумевано је `false`.
- `guidance_scale`: степен сагласности резултата модела са `prompt`, слобода генерисања слике, позната и као тежина текста; што је већа вредност, модел има мању слободу, а корелација са унетом кључном речју је јача. Опсег вредности: [1, 10]. `doubao-seedream-3.0-t2i` подразумевана вредност 2.5, `doubao-seededit-3.0-i2i` подразумевана вредност 5.5, остали не подржавају.
- `response_format`: одређује формат повратка генерисане слике. Подразумевано је `url`, такође подржава `b64_json`.
- `watermark`: да ли да се дода водени жиг на генерисану слику. Подразумевано је `true`.
- `callback_url`: URL на који је потребно вратити резултат.

Након избора, можете приметити да је на десној страни генерисан одговарајући код, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

Кликните на дугме „Try“ да бисте извршили тест, као што је приказано на горњој слици, овде смо добили следећи резултат:

```json
{
  "success": true,
  "task_id": "25027ba3-0430-4a1b-91c8-d2297f19ba73",
  "trace_id": "8043a9e9-692f-43b0-82f7-5890f798be38",
  "data": [
    {
      "prompt": "a white siamese cat",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/3c060029-69b1-406f-a957-fcd55ddc9386.jpg"
    }
  ]
}
```

Враћени резултат има више поља, описана као:

- `success`, статус тренутног задатка генерисања видеа.
- `task_id`, ID тренутног задатка генерисања видеа.
- `trace_id`, ID за праћење тренутног генерисања видеа.
- `data`, листа резултата тренутног задатка генерисања слика.
  - `image_url`, линк за тренутни задатак генерисања слике.
  - `prompt`, кључна реч.
  - `size`: пиксели генерисане слике.

Можете видети да смо добили задовољавајуће информације о слици, само треба да добијемо генерисану SeeDream слику према адреси линка слике у `data`.

Ако желите да генеришете одговарајући код за интеграцију, можете га директно копирати, на пример, CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-4-0-250828",
  "prompt": "a white siamese cat"
}'
```

## Уређивање слике

Ако желите да уредите неку слику, прво параметар `image` мора да садржи линк на слику коју желите да уредите.

- model: модел који се користи за ову уредбу слике, овај задатак тренутно подржава `doubao-seedream-4.5`, `doubao-seedream-4.0` подржава унос једне или више слика, `doubao-seededit-3.0-i2i` подржава само унос једне слике.
- image: учитајте слику коју желите да уредите, једну или више.

Пример попуњавања је следећи:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Одговарајући код:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Кликните на „Рун“ и можете приметити да ћете одмах добити резултат, као што је следеће:

Može se videti da je generisani efekat rezultat uređivanja originalne slike, a rezultat je sličan prethodnom tekstu.

## Asinhroni povratni poziv

Zbog toga što vreme generisanja SeeDream Images Generation API-a relativno dugo traje, otprilike 1-2 minuta, ako API dugo ne odgovara, HTTP zahtev će zadržati vezu, što dovodi do dodatne potrošnje sistemskih resursa, pa ovaj API takođe pruža podršku za asinhroni povratni poziv.

Celokupni proces je: kada klijent pokrene zahtev, dodatno se navodi polje `callback_url`, nakon što klijent pokrene API zahtev, API će odmah vratiti rezultat, koji sadrži informaciju o polju `task_id`, što predstavlja trenutni ID zadatka. Kada zadatak bude završen, rezultat generisane slike biće poslat klijentu na navedeni `callback_url` putem POST JSON-a, koji takođe uključuje polje `task_id`, tako da se rezultati zadatka mogu povezati putem ID-a.

U nastavku ćemo kroz primer razumeti kako konkretno postupiti.

Klikom na pokretanje, može se primetiti da odmah dobijate rezultat, kao što je prikazano u nastavku:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

Sadržaj je sledeći:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Zadržite poziciju modela i oblik tečnog odela nepromenjenim. Promenite materijal odeće sa srebrnog metala na potpuno prozirnu vodu (ili staklo). Kroz tečni tok, detalji kože modela su vidljivi. Efekat svetlosti i senke prelazi iz refleksije u prelamanje.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Može se videti da rezultat sadrži polje `task_id`, dok su ostala polja slična prethodnom tekstu, a putem ovog polja može se ostvariti povezanost zadatka.

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neautorizovano, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### Primer odgovora na grešku

```json
{
  "success": false,
  "error": {

    "message": "fetch failed"
  },

}
```
