Maestro je **Agent nativni** interfejs za video produkciju: jednom rečenicom prirodnog jezika `prompt` opišete video koji želite (po želji priložite referentne slike / video-zapise / audio putem `file_urls`), a bezglavi „AI režiser” će automatski završiti odabir teme, pisanje scenarija, generisanje vizuala, sinhronizaciju glasa, muziku, kompoziciju i renderovanje, te na kraju proizvesti gotov video sa titlovima i otpremiti ga na CDN.

Ovaj članak će detaljno predstaviti uputstvo za integraciju Maestro API-ja za generisanje videa, kako bi vam pomogao da se brzo integrišete i u potpunosti iskoristite mogućnosti ovog API-ja.

Ovo je interfejs za **asinhrone zadatke**: nakon slanja odmah se vraća `task_id`, a zatim se rezultat dobija anketiranjem putem [Maestro API-ja za upit zadataka](/sr/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (anketiranje je besplatno i ne naplaćuje se). Za nastavak iteracije na postojećem videu možete koristiti `action: remix` / `edit` / `extend` zajedno sa `ref_task_id`.

## Proces prijave

Da biste koristili Maestro API za generisanje videa, najpre preuzmite svoj API Token u [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications) i sačuvajte ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, bićete automatski preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite; po završetku ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe za zasebnom prijavom za svaku uslugu.** Prva prijava donosi besplatan kredit, tako da možete besplatno isprobati uslugu; kada kredit nije dovoljan, možete dopuniti zajednički saldo u [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Maestro API za generisanje videa →](https://platform.acedata.cloud/documents/maestro-videos)

## Osnovna upotreba

`POST https://api.acedata.cloud/maestro/videos`

Za najosnovniju upotrebu potrebno je samo proslediti opis na prirodnom jeziku u `prompt`, a AI režiser će automatski odlučiti o scenariju, vizuelnom sadržaju, naraciji i montaži. Ovde ćemo najpre pogledati zaglavlja i telo zahteva koja je potrebno podesiti.

**Zaglavlja zahteva** uključuju:

- `accept`: format u kojem želite da primite odgovor; ovde unesite `application/json`, odnosno JSON format.
- `authorization`: ključ za pozivanje API-ja, koji nakon dobijanja možete direktno izabrati iz padajuće liste.
- `content-type`: format tela zahteva; ovde unesite `application/json`.

**Telo zahteva** uglavnom uključuje:

- `prompt`: opis video-zapisa koji želite da napravite na prirodnom jeziku (tema, šta treba prikazati, stil, publika).
- `langs`: niz jezika završnog video-zapisa; pri svakom zahtevu prosleđuje se samo jedan, kao što je `["zh-cn"]`; podrazumevana vrednost je `["zh-cn"]`.
- `aspect`: odnos stranica, `9:16` (podrazumevano) / `16:9` / `1:1`.
- `duration`: ciljano trajanje (u sekundama); podrazumevana vrednost je 30.

Sva polja tela zahteva prikazana su u tabeli ispod:

| Polje | Tip | Obavezno | Opis |
|---|---|---|---|
| `prompt` | string | Da | Opišite video-zapis koji želite da napravite na prirodnom jeziku (tema, šta treba prikazati, stil, publika). AI odlučuje o scenariju, vizuelnom sadržaju, naraciji i montaži. |
| `action` | string | Ne | `generate` (podrazumevano, generisanje novog video-zapisa) / `remix` / `edit` / `extend` (iteracija na postojećem video-zapisu; mora se koristiti zajedno sa `ref_task_id`) |
| `ref_task_id` | string | Ne | Obavezno kada je `action` postavljen na remix / edit / extend: `task_id` istorijskog zadatka koji se koristi kao polazna tačka. |
| `file_urls` | string[] | Ne | Referentni mediji (URL slike / video-zapisa / zvuka), na primer slika proizvoda ili logo koji treba prikazati, ili segment materijala kojem treba dodati titlove. |
| `langs` | string[] | Ne | Jezik gotovog videa; svaki put se može proslediti samo jedan, npr. `["zh-cn"]`. Podrazumevana vrednost je `["zh-cn"]` |
| `aspect` | string | Ne | `9:16` (podrazumevano) / `16:9` / `1:1`; jedinstveni izlaz je 1080p/30 fps |
| `duration` | int | Ne | Ciljano trajanje (sekunde), podrazumevano 30; podržava **5–300 sekundi**. Naplata se vrši prema stvarnom trajanju gotovog videa, ali ne prelazi zatraženo trajanje |
| `scenario` | string | Ne | Tip videa: `auto` / `narrated` / `captions` / `avatar` / `drama`. Za `captions` potrebno je proslediti izvorni video, a za `avatar` portret |
| `style` | string | Ne | Unapred podešeni vizuelni stilovi: `auto` (podrazumevano) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`; prihvata se i slobodan tekst kao blagi upit. Može se podesiti nezavisno od `scenario` |
| `voice` | string | Ne | Boja glasa naratora (nezavisna od jezika, univerzalna za više jezika): `auto` (podrazumevano) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`; podržan je i 32-bitni heksadecimalni reference_id boje glasa, dok drugi slobodni tekstovi nisu važeći ID-ovi boje glasa |

U nastavku je prikazan konkretan primer. Pretpostavimo da želimo da generišemo kineski naučno-popularni kratki video u vertikalnom formatu, u trajanju od 20 sekundi. Odgovarajući CURL kôd je sledeći:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

Odgovarajući Python kôd je sledeći:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kliknite na pokretanje i videćete da odmah dobijate rezultat, kao u nastavku:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Polja u rezultatu odgovora opisana su u nastavku:

- `success`: Da li je ovaj zadatak uspešno poslat.
- `task_id`: ID ovog zadatka generisanja videa. Kasnije ga koristite za proveru rezultata putem [Maestro API-ja za upite o zadacima](/sr/guides/maestro/maestro_tasks).
- `trace_id`: ID za praćenje ovog zahteva, koji možete dati tehničkoj podršci radi dijagnostike problema.

Pošto produkcija videa traje duže, API ovde **odmah vraća `task_id`** i ne čeka da se renderovanje videa završi. Zatim je potrebno koristiti `task_id` za proveru rezultata, detalje pogledajte u odeljku „Preuzimanje rezultata“.

## Navođenje tipa i stila videa (scenario / style)

Kada se `scenario` ne prosledi, AI ga automatski određuje (ekvivalentno `auto`); ako želite da video vežete za određeni tip, prosledite ga eksplicitno. Na primer, za izradu **kratke drame u vertikalnom formatu**, možete navesti sledeće:

- `scenario`: Tip videa, ovde postavljen na `drama` (kratka drama sa likovima + dijalozima).
- `style`: Vizuelni stil, ovde postavljen na `cinematic` (filmski izgled).

CURL kod primera za popunjavanje je sledeći:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Uobičajeni načini kombinovanja:

- Kratki video sa naracijom: `scenario: "narrated"`.
- Automatski titlovi: `scenario: "captions"`, potrebno je proslediti izvorni video putem `file_urls`.
- Digitalni avatar / govorni video: `scenario: "avatar"`, potrebno je proslediti jednu sliku portreta putem `file_urls`.
- Kratka drama: `scenario: "drama"` (likovi + dijalozi).
- `style` je unapred podešeni vizuelni stil (kao što su `modern` / `neon` / `luxury`), ne menja tip, već utiče samo na vizuelni utisak.
- `voice` se koristi za navođenje boje glasa naratora (kao što su `warm-female` / `deep-male`), nezavisno je od jezika i univerzalno za različite jezike.

Rezultat povratne vrednosti je isti kao kod „Osnovnog korišćenja“, takođe se odmah vraća `task_id`.

## Jezik gotovog videa

Jedan zadatak isporučuje samo jedan gotov video na jednom jeziku. `langs` može sadržati samo jedan jezički kod, kao što je `["zh-cn"]` ili `["en"]`; prosleđivanje više jezika vraća 400. Ako su vam potrebni video-zapisi na različitim jezicima, kreirajte zasebne zadatke. Izbor jezika ne menja cenu po sekundi.

## Iteriranje na postojećem videu (remix / edit / extend)

Prosledite `action` i `ref_task_id` prethodnog zadatka da biste izvršili inkrementalne izmene na osnovu originalnog projekta (kao što su „promeni naslov 2. scene“, „promeni sinhronizaciju“, „zatamni celinu“). Male izmene su brze, dok će velike izmene zahtevati ponovnu izradu:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: Ponovno interpretiranje na strukturi originalnog videa (zadržava temu, prilagođava prikaz).
- `edit`: Fina obrada određenog dela (kao što su promena naslova, sinhronizacije ili korekcija boja).
- `extend`: Proširivanje sadržaja na osnovu originalnog videa.

Rezultat povratne vrednosti takođe odmah vraća novi `task_id`, koji možete koristiti za anketiranje kako biste dobili iterirani gotov video.

## Preuzimanje rezultata

Zbog dužeg vremena potrebnog za produkciju videa, ovaj interfejs odmah vraća `task_id` nakon slanja, a potrebno je da ga koristite za anketiranje rezultata putem [API-ja za upit Maestro zadataka](/sr/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Kada se zadatak završi, vraćaju se informacije o jednom gotovom videu (nalaze se u nizu `variants`). `status` prolazi kroz `pending → planning → producing → succeeded` (ili `failed`), **anketiranje je besplatno i ne troši kredite**. Za kompletan format odgovora i upit liste istorije pogledajte [uputstvo za integraciju API-ja za upit Maestro zadataka](/sr/guides/maestro/maestro_tasks).

## Naplata

**Nakon uspešnog završetka zadatka, naplata se vrši prema stvarnom trajanju isporučenog gotovog videa; neuspešni zadaci se ne naplaćuju.** Trajanje za naplatu računa se u celim sekundama i ne prelazi zahtevano trajanje; ako nije moguće pročitati trajanje gotovog videa, koristi se zahtevano trajanje. Samo slanje zadatka se ne naplaćuje zasebno, a anketiranje `/maestro/tasks` je besplatno.

```
Krediti = stvarni broj sekundi za naplatu × 0.7
```

Svi scenariji, radnje i jezici koriste istu cenu, bez množitelja za scenarije ili doplate za jezik. Svaki zadatak isporučuje samo jedan gotov video na jednom jeziku. Zahtevano ciljano trajanje podržava 5–300 sekundi, uz jedinstveni izlaz 1080p / 30fps.

| Stvarno trajanje za naplatu | Krediti |
| ------------------- | --: |
| 30 sekundi          |  21 |
| 60 sekundi          |  42 |
| 120 sekundi         |  84 |
| 300 sekundi         | 210 |
| Anketiranje `/maestro/tasks` | besplatno |

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API vraća odgovarajući kod i poruku greške. Na primer:

- `400 invalid_request`: Neispravan zahtev, moguće zbog nedostajućeg `prompt`-a ili nevažećih parametara.
- `401 invalid_token`: Neovlašćeno, nevažeći ili nedostajući autorizacioni token.
- `403 forbidden`: Zabranjeno, nedovoljno sredstava ili pristupa.
- `429 too_many_requests`: Previše zahteva, prekoračili ste ograničenje stope.
- `500 api_error`: Interna greška servera, nešto je pošlo po zlu na serveru.

### Primer odgovora greške

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
