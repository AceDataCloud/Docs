Maestro je **Agent nativni** interfejs za produkciju videa: jednom rečenicom prirodnog jezika u `prompt` opišete video koji želite (opciono uz `file_urls` priložite referentne slike / video / audio), a „AI režiser” bez interfejsa će automatski završiti izbor teme, pisanje scenarija, generisanje vizuala, naraciju, muziku, kompoziciju i renderovanje, te na kraju proizvesti gotov video sa titlovima i otpremiti ga na CDN.

Ovaj dokument će detaljno predstaviti uputstvo za integraciju Maestro API-ja za generisanje videa, kako bi vam pomogao da ga brzo integrišete i u potpunosti iskoristite mogućnosti ovog API-ja.

Ovo je interfejs za **asinhrone zadatke**: nakon slanja će odmah vratiti `task_id`, a rezultat se zatim dobija anketiranjem putem [Maestro API-ja za upit zadataka](/sr/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (anketiranje je besplatno i ne naplaćuje se). Za nastavak iteracije na postojećem videu možete koristiti `action: remix` / `edit` / `extend` zajedno sa `ref_task_id`.

## Proces prijave

Da biste koristili Maestro API za generisanje videa, prvo preuzmite svoj API Token na [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications) i sačuvajte ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon završetka ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe da se posebno prijavljujete za svaku uslugu.** Prva prijava donosi besplatan kredit za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti univerzalni saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Maestro API za generisanje videa →](https://platform.acedata.cloud/documents/maestro-videos)

## Osnovna upotreba

`POST https://api.acedata.cloud/maestro/videos`

Najosnovnija upotreba zahteva samo unošenje `prompt` na prirodnom jeziku, a AI režiser će automatski odlučiti o scenariju, vizualima, naraciji i montaži. Ovde ćemo najpre upoznati zaglavlja zahteva i telo zahteva koja je potrebno postaviti.

**Request Headers** uključuju:

- `accept`: format rezultata odgovora koji želite da primite; ovde se unosi `application/json`, odnosno JSON format.
- `authorization`: ključ za pozivanje API-ja, koji se nakon prijave može direktno izabrati iz padajućeg menija.
- `content-type`: format tela zahteva; ovde se unosi `application/json`.

**Request Body** uglavnom uključuje:

- `prompt`: prirodnim jezikom opišite video koji treba napraviti (tema, šta treba prikazati, stil, publika).
- `langs`: niz jezika gotovog videa, svaki put se prenosi samo jedan, kao `["zh-cn"]`; podrazumevano je `["zh-cn"]`.
- `aspect`: odnos stranica slike, `9:16` (podrazumevano) / `16:9` / `1:1`.
- `duration`: ciljno trajanje (sekunde), podrazumevano 30.

Sva polja tela zahteva prikazana su u sledećoj tabeli:

| Polje            | Tip       | Obavezno  | Opis                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Da   | Prirodnim jezikom opišite video koji treba napraviti (tema, šta treba prikazati, stil, publika). O scenariju, vizualima, naraciji i montaži odlučuje AI                                                                                                                                                                             |
| `action`      | string   | Ne   | `generate` (podrazumevano, generisanje novog videa) / `remix` / `edit` / `extend` (iteracija na postojećem videu, zahteva korišćenje sa `ref_task_id`)                                                                                                                                                |
| `ref_task_id` | string   | Ne   | Obavezno kada je `action` remix / edit / extend: `task_id` istorijskog zadatka koji služi kao početna tačka                                                                                                                                                                   |
| `file_urls`   | string[] | Ne   | Referentni mediji (slika / video / audio URL), na primer slika proizvoda ili logo koji treba da se pojavi u videu, ili segment materijala kojem treba dodati titlove                                                                                                                                                                             |
| `langs`       | string[] | Ne   | Jezik gotovog videa; svaki put se može preneti samo jedan, kao `["zh-cn"]`; podrazumevano je `["zh-cn"]`                                                                                                                                                                                    |
| `aspect`      | string   | Ne   | `9:16` (podrazumevano) / `16:9` / `1:1`, jedinstveni izlaz 1080p/30fps                                                                                                                                                                                  |
| `duration`    | int      | Ne   | Ciljno trajanje (sekunde), podrazumevano 30, podržava **5–300 sekundi**. Naplata se vrši prema stvarnom trajanju gotovog videa, ali neće premašiti traženo trajanje                                                                                                                                                                             |
| `scenario`    | string   | Ne   | Tip videa: `auto` / `narrated` / `captions` / `avatar` / `drama`. Za `captions` je potrebno poslati izvorni video, a za `avatar` portret                                                                                                                                    |
| `style`       | string   | Ne   | Unapred podešeni vizuelni stil: `auto` (podrazumevano) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`; prihvata i slobodan tekst kao blagi signal. Ortogonalan je sa `scenario` i ne menja rutiranje |
| `voice`       | string   | Ne   | Boja glasa naracije (nezavisna od jezika, univerzalna za različite jezike): `auto` (podrazumevano) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`                                    |

U nastavku ćemo prikazati kroz konkretan primer. Pretpostavimo da želimo da generišemo kineski, vertikalni, 20-sekundni kratki edukativni video; odgovarajući CURL kod je sledeći:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

Odgovarajući Python kod je sledeći:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Klikom na pokretanje, može se videti da se odmah dobija rezultat, kao što je prikazano u nastavku:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Uvod u polja rezultata odgovora je sledeći:
- `success`：da li je ovaj zadatak uspešno poslat.
- `task_id`：ID ovog zadatka za generisanje videa, naknadno ga koristite za anketiranje rezultata putem [Maestro API-ja za upit zadataka](/sr/guides/maestro/maestro_tasks).
- `trace_id`：ID za praćenje ovog zahteva, koji se može dostaviti tehničkoj podršci radi lociranja problema.

Pošto produkcija videa traje duže, interfejs ovde **odmah vraća `task_id`** i neće čekati da se renderovanje videa završi. Zatim je potrebno koristiti `task_id` za anketiranje rezultata, detalje pogledajte u odeljku „Preuzimanje rezultata“.

## Određivanje tipa i stila videa (scenario / style)

Kada se `scenario` ne prosledi, AI ga automatski određuje (jednako `auto`); ako želite da video fiksirate na određeni tip, prosledite ga eksplicitno. Na primer, za kreiranje **vertikalne kratke drame**, možete navesti sledeći sadržaj:

- `scenario`：tip videa, ovde postavljen na `drama` (kratka drama sa likovima + dijalozima).
- `style`：vizuelni stil, ovde postavljen na `cinematic` (filmski utisak).

CURL kod primera popunjavanja je sledeći:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Uobičajeni načini kombinovanja:

- Kratki video sa naracijom: `scenario: "narrated"`.
- Automatski titlovi: `scenario: "captions"`, potrebno je koristiti `file_urls` za prosleđivanje izvornog videa.
- Digitalni avatar / obraćanje u kameru: `scenario: "avatar"`, potrebno je koristiti `file_urls` za prosleđivanje jedne fotografije osobe.
- Kratka drama: `scenario: "drama"` (likovi + dijalozi).
- `style` je unapred podešeni vizuelni stil (kao što su `modern` / `neon` / `luxury`), ne menja tip, već utiče samo na vizuelni utisak.
- `voice` se koristi za određivanje boje glasa naratora (kao što su `warm-female` / `deep-male`), nije povezan sa jezikom i univerzalan je za različite jezike.

Rezultat vraćanja je isti kao kod „Osnovne upotrebe“, takođe odmah vraća `task_id`.

## Jezik gotovog videa

Jedan zadatak isporučuje samo jedan gotov video na jednom jeziku. `langs` može sadržati samo jedan jezički kod, kao `["zh-cn"]` ili `["en"]`; prosleđivanje više jezika vraća 400. Ako su vam potrebni video-zapisi na različitim jezicima, kreirajte zadatke zasebno. Izbor jezika ne menja cenu po sekundi.

## Iteracija nad postojećim videom (remix / edit / extend)

Prosledite `action` i `ref_task_id` prethodnog zadatka da biste izvršili inkrementalne izmene na osnovu originalnog projekta (kao što su „promeni naslov 2. scene“, „zameni sinhronizaciju“, „potamni celinu“). Male izmene su brze, dok će velike izmene biti ponovo urađene:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`：ponovno interpretiranje na osnovu strukture originalnog videa (zadržava temu, prilagođava prikaz).
- `edit`：fina obrada određenog dela (kao što su zamena naslova, zamena sinhronizacije, korekcija boja).
- `extend`：proširivanje sadržaja na osnovu originalnog videa.

Rezultat vraćanja takođe odmah vraća novi `task_id`, koristite ga za anketiranje da biste dobili gotov video nakon iteracije.

## Preuzimanje rezultata

Pošto produkcija videa traje duže, ovaj interfejs odmah vraća `task_id` nakon slanja, potrebno je da ga koristite za anketiranje rezultata putem [Maestro API-ja za upit zadataka](/sr/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Kada se zadatak završi, vraća se informacija o jednom gotovom videu (nalazi se u nizu `variants`). `status` će prolaziti kroz `pending → planning → producing → succeeded` (ili `failed`), **anketiranje je besplatno i ne troši kredite**. Za potpuni format odgovora i upit istorijske liste pogledajte [uputstvo za integraciju Maestro API-ja za upit zadataka](/sr/guides/maestro/maestro_tasks).

## Naplata

**Nakon uspešnog zadatka, naplata se vrši prema stvarnom trajanju isporučenog gotovog videa, neuspešni zadaci se ne naplaćuju.** Trajanje za naplatu računa se u celim sekundama i ne prelazi zahtevano trajanje; kada nije moguće pročitati trajanje gotovog videa, vraća se na zahtevano trajanje. Samo slanje zadatka se ne naplaćuje posebno, anketiranje putem `/maestro/tasks` je besplatno.

```
Krediti = stvarni broj sekundi za naplatu × 0.7
```

Svi scenariji, radnje i jezici koriste istu cenu, bez multiplikatora za scenario ili dodatne naplate za jezik. Svaki zadatak isporučuje samo jedan gotov video na jednom jeziku. Zahtevano ciljno trajanje podržava 5–300 sekundi, a izlaz je uvek 1080p / 30fps.

| Stvarno trajanje za naplatu       | Krediti |
| ------------------- | --: |
| 30 sekundi          |  21 |
| 60 sekundi          |  42 |
| 120 sekundi         |  84 |
| 300 sekundi         | 210 |
| Anketiranje `/maestro/tasks` | besplatno |

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API vraća odgovarajući kôd greške i poruku. Na primer:

- `400 invalid_request`：Neispravan zahtev, moguće zbog nedostajućeg `prompt`-a ili nevažećih parametara.
- `401 invalid_token`：Neovlašćeno, nevažeći ili nedostajući autorizacioni token.
- `403 forbidden`：Zabranjeno, nedovoljan saldo ili pristup.
- `429 too_many_requests`：Previše zahteva, prekoračili ste ograničenje učestalosti.
- `500 api_error`：Interna greška servera, nešto je pošlo po zlu na serveru.

### Primer odgovora na grešku

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Zaključak

Kroz ovaj dokument ste već saznali kako da koristite Maestro API za generisanje videa: potrebna je samo jedna rečenica prirodnog jezika `prompt`, da bi se automatski završili scenario, materijali, sinhronizacija, muzika, montaža, titlovi i renderovanje gotovog videa, uz podršku za određivanje tipa videa, stila, boje glasa, jezika gotovog videa, kao i iteraciju nad postojećim videom. Nadamo se da vam ovaj dokument može pomoći da bolje integrišete i koristite ovaj API. Ako imate bilo kakvih pitanja, slobodno kontaktirajte naš tim tehničke podrške.
