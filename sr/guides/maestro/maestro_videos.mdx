Maestro je **Agent nativni** interfejs za proizvodnju videa: opisujete željeni video koristeći prirodni jezik `prompt` (opciono možete dodati `file_urls` sa referentnim slikama / videima / zvucima), a bezglavi „AI reditelj“ automatski završava izbor teme, piše skriptu, generiše slike, snima glas, dodaje muziku, kombinuje i renderuje, a na kraju proizvodi gotov video sa titlovima i učitava ga na CDN.

Ovaj dokument će detaljno opisati uputstvo za integraciju Maestro API za generisanje videa, pomažući vam da brzo integrišete i u potpunosti iskoristite mogućnosti ovog API-ja.

Ovo je **asinkroni zadatak** interfejs: nakon slanja odmah će se vratiti `task_id`, a zatim možete koristiti [Maestro API za pretragu zadataka](/sr/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) za dobijanje rezultata (pretraga je besplatna i ne naplaćuje se). Da biste nastavili iteraciju na postojećem videu, možete koristiti `action: remix` / `edit` / `extend` u kombinaciji sa `ref_task_id`.

## Proces prijave

Da biste koristili Maestro API za generisanje videa, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, koji čuvate za kasnije.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozvati sve usluge platforme, nije potrebno da se posebno prijavljujete za svaku uslugu.** Prvi put kada se prijavite dobićete besplatnu kvotu, koju možete besplatno isprobati; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Puna dokumentacija: [Maestro API za generisanje videa →](https://platform.acedata.cloud/documents/maestro-videos)

## Osnovna upotreba

`POST https://api.acedata.cloud/maestro/videos`

Najosnovnija upotreba zahteva samo da se prosledi prirodni jezik `prompt`, a AI reditelj će automatski odlučiti o skripti, slikama, glasu i montaži. Ovde ćemo prvo upoznati zaglavlja zahteva i telo zahteva.

**Zaglavlja zahteva** uključuju:

- `accept`: kakav format odgovora želite da primite, ovde se unosi `application/json`, tj. JSON format.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete direktno izabrati.
- `content-type`: format tela zahteva, ovde se unosi `application/json`.

**Telo zahteva** uglavnom uključuje:

- `prompt`: opisuje video koji želite da napravite (tema, šta treba prikazati, stil, publika).
- `langs`: niz izlaznih jezika, kao što su `["zh-cn", "en"]`, podrazumevano `["zh-cn"]`.
- `aspect`: odnos slike, `9:16` (podrazumevano) / `16:9` / `1:1`.
- `duration`: ciljana dužina (sekundi), podrazumevano 30.

Svi polja tela zahteva su prikazana u sledećoj tabeli:

| Polje          | Tip      | Obavezno | Objašnjenje                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Da   | Opisuje video koji želite da napravite (tema, šta treba prikazati, stil, publika). Skripta, slike, glas i montaža su određeni od strane AI-a.                                                                                                                                                                             |
| `action`      | string   | Ne   | `generate` (podrazumevano, generiše novi video) / `remix` / `edit` / `extend` (iteracija na postojećem videu, mora se koristiti sa `ref_task_id`).                                                                                                                                                |
| `ref_task_id` | string   | Ne   | Kada je `action` remix / edit / extend, obavezno: istorijski `task_id` koji se koristi kao početna tačka.                                                                                                                                                                   |
| `file_urls`   | string[] | Ne   | Referentni mediji (URL-ovi slika / videa / zvuka), na primer, slike proizvoda, logo ili delovi materijala kojima treba dodati titlove.                                                                                                                                                                             |
| `langs`       | string[] | Ne   | Izlazni jezici, kao što su `["zh-cn", "en"]`, podrazumevano `["zh-cn"]`. Prvi je glavni jezik; za svaki dodatni jezik se ponovo koristi slika, samo se dodaje glas + renderovanje, **za svaki dodatni +6 bodova**.                                                                                                                                          |
| `aspect`      | string   | Ne   | `9:16` (podrazumevano) / `16:9` / `1:1`, jedinstveni izlaz 1080p/30fps.                                                                                                                                                                                  |
| `duration`    | int      | Ne   | Ciljana dužina (sekundi), podrazumevano 30, podržava **5–300 sekundi**. Naplaćuje se prema stvarnoj dužini videa, ali ne može biti duža od tražene dužine.                                                                                                                                                                             |
| `scenario`    | string   | Ne   | Tip videa: `auto` / `narrated` / `captions` / `avatar` / `drama`. `captions` zahteva izvorni video, `avatar` zahteva sliku lica.                                                                                                                                    |
| `style`       | string   | Ne   | Predložak vizuelnog stila: `auto` (podrazumevano) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`, takođe prihvata slobodan tekst kao meki podsticaj. Ne menja rutu. |
| `voice`       | string   | Ne   | Ton naracije (ne zavisi od jezika, univerzalno za sve jezike): `auto` (podrazumevano) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`.                                    |

Sledeći primer će prikazati konkretan slučaj. Pretpostavimo da želimo da generišemo kratki video o nauci na kineskom i engleskom jeziku, u vertikalnom formatu, dužine 20 sekundi, odgovarajući CURL kod je sledeći:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn", "en"],
  "aspect": "9:16",
  "duration": 20
}'
```

Odgovarajući Python kod je sledeći:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn", "en"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kada kliknete na pokretanje, možete primetiti da odmah dobijate rezultat, kao što je prikazano u nastavku:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Objašnjenje polja u vraćenom rezultatu je sledeće:
- `success`：Da li je zadatak uspešno poslat.
- `task_id`：ID zadatka za generisanje videa, koristiće se za [Maestro API za upit zadataka](/sr/guides/maestro/maestro_tasks) da bi se proverili rezultati.
- `trace_id`：ID za praćenje ovog zahteva, može se dostaviti tehničkoj podršci u slučaju problema.

Zbog dužeg vremena potrebnog za proizvodnju videa, API **odmah vraća `task_id`**, i ne čeka da se video završi sa renderovanjem. Sledeće je potrebno koristiti `task_id` za proveru rezultata, više informacija u odeljku „Preuzmi rezultate“.

## Određivanje tipa i stila videa (scenario / style)

Ako se ne prosledi `scenario`, AI će automatski odrediti (jednako `auto`); ako želite da video bude određenog tipa, eksplicitno ga prosledite. Na primer, za pravljenje **vertikalnog kratkog filma**, možete odrediti sledeće:

- `scenario`：tip videa, ovde postavljen na `drama` (kratki film sa likovima + dijalog).
- `style`：vizuelni stil, ovde postavljen na `cinematic` (filmski kvalitet).

Primer CURL koda je sledeći:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Dva cimeri se posvađaju zbog mačke, a zatim se pomire, tri preokreta, završetak topao",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Uobičajeni načini kombinovanja:

- Narativni kratki film: `scenario: "narrated"`, Lite / Standard / Pro podržavaju.
- Automatski titlovi: `scenario: "captions"`, potrebno je proslediti `file_urls` sa izvorom videa, Lite / Standard / Pro podržavaju.
- Digitalna osoba / glas: `scenario: "avatar"`, potrebno je proslediti `file_urls` sa slikom osobe, Standard / Pro podržavaju.
- Kratki film: `scenario: "drama"` (likovi + dijalog), samo Pro podržava.
- `style` je unapred definisan vizuelni stil (kao što su `modern` / `neon` / `luxury`), ne menja tip, samo utiče na vizuelni doživljaj.
- `voice` se koristi za određivanje tona naracije (kao što su `warm-female` / `deep-male`), nezavisno od jezika, univerzalno za sve jezike.

Vraćeni rezultati su isti kao u „Osnovnoj upotrebi“, takođe odmah vraćaju `task_id`.

## Višejezički izlaz

Prosledite više jezika u `langs` da biste jednom generisali višejezičke verzije. Prvi je glavni jezik, a svaka dodatna jezik će **ponovo koristiti istu set slika**, samo dodatno sinhronizovati glas i renderovati, stoga **svaki dodatni jezik samo +6 bodova**. Primer:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Predstavite naš proizvod pametnog korisničkog servisa, ističući 3 ključne tačke",
  "langs": ["zh-cn", "en", "ja"],
  "aspect": "16:9",
  "duration": 30
}'
```

Nakon završetka zadatka, svaka vrsta jezika će odgovarati jednom `variant` u rezultatu (vidi [Maestro API za upit zadataka](/sr/guides/maestro/maestro_tasks)).

## Iteracija na postojećem videu (remix / edit / extend)

Prosledite `action` i `ref_task_id` prethodnog zadatka, kako biste izvršili diferencijalne izmene na osnovu originalnog projekta (kao što su „promeniti naslov 2. čina“ „promeniti glas“ „ukupno smanjiti osvetljenje“). Male izmene su brze, velike izmene će se ponovo raditi:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "Zameniti uvodni naslov sa nečim što ima veći uticaj, ukupna paleta boja neka bude tamnija"
}'
```

- `remix`：Ponovno izvođenje na osnovu strukture originalnog videa (zadržavanje teme, prilagođavanje izraza).
- `edit`：Precizno uređivanje određenih delova (kao što su promena naslova, promena glasa, podešavanje boja).
- `extend`：Proširenje sadržaja na osnovu originalnog videa.

Vraćeni rezultati takođe odmah vraćaju novi `task_id`, koji se koristi za proveru rezultata nakon iteracije.

## Preuzmi rezultate

Zbog dužeg vremena potrebnog za proizvodnju videa, ovaj API odmah vraća `task_id` nakon slanja, potrebno je koristiti ga za [Maestro API za upit zadataka](/sr/guides/maestro/maestro_tasks) da biste proverili rezultate:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Kada je zadatak završen, vraća se informacija o gotovom videu (svaki jezik odgovara jednom `variant`). `status` će proći kroz `pending → planning → producing → succeeded` (ili `failed`), **proveravanje je besplatno, ne troši bodove**. Potpuni format odgovora i upit za istorijsku listu, molimo vas da se obratite [Maestro API za upit zadataka](/sr/guides/maestro/maestro_tasks).

## Naplata

**Nakon završetka zadatka, naplaćuje se prema stvarnom gotovom videu, neuspešni zadaci se ne naplaćuju.** Naplata se vrši prema stvarnoj dužini gotovog videa i broju jezika, a dužina naplate neće premašiti dužinu zahteva. Ako neki jezik na kraju nije proizveden, neće se naplatiti dodatnih +6 za taj jezik. Slanje zadatka se ne naplaćuje posebno, `/maestro/tasks` proveravanje je besplatno.

Bodovi za jedan gotov video se računaju prema sledećoj formuli:

```
Bodovi = Dužina gotovog videa u sekundama × 0.60 × Faktor scenarija + 6 × max(Broj jezika − 1, 0)
```

Maestro naplaćuje **0.60 bodova/sekundi stvarnog videa**, podržava 5–300 sekundi, najviše 4 jezika i 1080p / 30fps izlaz; sve radnje i scenariji su dostupni.

Faktor scenarija: `drama` 1.35× / `avatar` 1.15× / ostali 1×.

| Primer                  |  Bodovi |
| ------------------- | --: |
| Lite 30 sekundi           |   6 |
| Standard 30 sekundi       |  18 |
| Standard 60 sekundi       |  36 |
| Standard 120 sekundi      |  72 |
| Pro 30 sekundi            |  36 |
| Pro 300 sekundi           | 360 |
| Svaki dodatni jezik koji se isporučuje          |  +6 |
| `/maestro/tasks` proveravanje |  Besplatno |

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 invalid_request`：Neispravan zahtev, moguće zbog nedostatka `prompt` ili neispravnih parametara.
- `401 invalid_token`：Neovlašćeno, neispravan ili nedostajući autorizacioni token.
- `403 forbidden`：Zabranjeno, nedovoljno sredstava ili pristupa.
- `429 too_many_requests`：Previše zahteva, premašili ste limit brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.

### Primer greške u odgovoru
```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "preuzimanje nije uspelo"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Zaključak

Kroz ovaj dokument, već ste saznali kako koristiti Maestro video generisanje API: samo jedna prirodna jezička `prompt` automatski završava skriptu, materijale, glasovne snimke, muziku, montažu, titlove i renderovanje gotovog videa, i podržava određivanje tipa videa, stila, tona, višelingvalni izlaz, kao i iteraciju na postojećim videima.
