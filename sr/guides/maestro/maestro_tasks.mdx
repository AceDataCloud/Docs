Glavna funkcija Maestro API-ja za upit zadataka je da, putem ID-ja zadatka vraćenog od strane [Maestro API-ja za generisanje videa](/sr/guides/maestro/maestro_videos) (`POST /maestro/videos`), upita status izvršavanja i konačni rezultat tog zadatka.

Ovaj dokument će detaljno predstaviti uputstvo za integraciju Maestro API-ja za upit zadataka. Pošto je generisanje videa asinhroni zadatak, nakon slanja je potrebno koristiti ovaj interfejs za anketiranje i dobijanje napretka i gotovog videa, **anketiranje je besplatno i ne troši kredite.**

`POST https://api.acedata.cloud/maestro/tasks`

## Proces prijave

Da biste koristili Maestro API za upit zadataka, prvo idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications) da preuzmete svoj API Token, i sačuvajte ga za kasnije.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu gde ćete biti pozvani da se registrujete i prijavite, a nakon završetka automatski ćete se vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, nije potrebno podnositi posebnu prijavu za svaku uslugu.** Prva prijava će vam dodeliti besplatni limit, koji možete koristiti za besplatno isprobavanje; kada limit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Maestro API za upit zadataka →](https://platform.acedata.cloud/documents/maestro-tasks)

## Upit jednog zadatka

Za informacije o tome kako kreirati video zadatak, pogledajte dokument [Maestro API za generisanje videa](/sr/guides/maestro/maestro_videos). Uzećemo kao primer jedan ID zadatka koji on vraća: `f57e99c4f60f4373a15517742ce2357d`, da pokažemo kako upitati njegov status i rezultat.

### Podešavanje zaglavlja zahteva i tela zahteva

**Request Headers** uključuje:

- `accept`: određuje primanje rezultata odgovora u JSON formatu, ovde se popunjava sa `application/json`.
- `authorization`: ključ za pozivanje API-ja, nakon prijave može se direktno izabrati iz padajuće liste.
- `content-type`: format tela zahteva, ovde se popunjava sa `application/json`.

**Request Body** uključuje:

| Polje       | Tip     | Obavezno        | Opis                                                |
| -------- | ------ | --------- | ------------------------------------------------- |
| `id`     | string | Obavezno pri upitu jednog zadatka | `task_id` vraćen od `POST /maestro/videos`              |
| `action` | string | Ne         | `retrieve` (podrazumevano, upit jednog zadatka); pri upitu istorijske liste fiksno je `retrieve_batch` |

### Primer koda

Odgovarajući CURL kod je sledeći:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d",
  "action": "retrieve"
}'
```

Odgovarajući Python kod je sledeći:

```python
import requests

url = "https://api.acedata.cloud/maestro/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "f57e99c4f60f4373a15517742ce2357d",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Primer odgovora

Nakon uspešnog zahteva, API će vratiti status i rezultat tog video zadatka. Primer vraćenog rezultata kada je zadatak završen je sledeći (svaki jezik odgovara jednom `variant`):

```json
        }

```

Opis polja vraćenog rezultata je sledeći:

- `id`: ID ovog video zadatka, koristi se za jedinstvenu identifikaciju ovog zadatka generisanja videa.
- `status`: status zadatka, vrednosti su `pending → planning → producing → succeeded` (ili `failed`). Da li je zadatak završen određuje se prema ovom najvišem nivou `status`.
- `elapsed`: vreme koje je zadatak do sada trajao (sekunde).
- `progress`: objekat napretka najvišeg nivoa, `percent` (0–100) će nakon uspeha zadatka biti dopunjen na 100; `stage` i `message` odražavaju najnoviji događaj napretka AI reditelja (zbog toga nakon uspeha `stage` može i dalje biti poslednja faza izvršavanja kao što je `producing`), i mogu se direktno koristiti za prikaz trake napretka.
- `request`: telo zahteva pri pokretanju zadatka.
- `response`: povratne informacije zadatka.
  - `success`: da li je zadatak uspešan.
  - `data.variants`: svaki jezik odgovara jednom objektu gotovog videa, koji sadrži `lang`, `aspect`, `title`, `output_url` (adresa za preuzimanje gotovog videa) i drugo.
  - `data.project`: proizvod celog projekta, koji sadrži `tarball_url` (paket projekta) i `outputs` (sve veze ka gotovim videozapisima).
  - `data.progress`: niz događaja napretka koji se dodaju po fazama (append-only dnevnik), može se koristiti za prikaz detaljnog napretka u realnom vremenu.
- `created_at`: vreme kreiranja zadatka, Unix vremenska oznaka (sekunde).
- `started_at`: vreme početka izvršavanja zadatka, Unix vremenska oznaka (sekunde). Kada zadatak još nije započet, vrednost je null.
- `finished_at`: vreme završetka zadatka, Unix vremenska oznaka (sekunde). Kada zadatak nije završen, vrednost je null.

## Upit istorijske liste

Prosledite `action: retrieve_batch` da biste dobili najnovije zadatke trenutnog prijavljenog izvršioca (sortirano opadajuće po vremenu kreiranja), što se može koristiti za stranicu liste „Moji videozapisi“. Istorijska lista je izolovana prema identitetu prijave.

**Request Body** uključuje:
| Polje               | Tip     | Obavezno  | Opis                              |
| ---------------- | ------ | --- | ------------------------------- |
| `action`         | string | Da   | Fiksirano na `retrieve_batch`            |
| `limit`          | int    | Ne   | Broj vraćenih stavki, podrazumevano 20; važeći opseg je 1–100          |
| `created_at_max` | int    | Ne   | Vraća samo zadatke koji su strogo raniji od ove Unix vremenske oznake (ne uključuje graničnu vrednost, za paginaciju) |
| `created_at_min` | int    | Ne   | Vraća samo zadatke koji su strogo kasniji od ove Unix vremenske oznake (ne uključuje graničnu vrednost)     |

### Primer koda

Odgovarajući CURL kod je sledeći:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "retrieve_batch",
  "limit": 20
}'
```

Polja vraćenog rezultata opisana su u nastavku:

- `count`: Ukupan broj zadataka vidljivih trenutno prijavljenom izvršiocu, na koji ne utiču vremenski uslovi niti `limit`.
- `items`: Niz zadataka filtriranih prema vremenskim uslovima i `limit` vrednosti, poređan obrnutim redosledom po vremenu kreiranja; format svakog elementa je isti kao rezultat vraćen pri „upitu pojedinačnog zadatka“.

## Preporuke za anketiranje

Pošto produkcija videa traje duže, `status` će prolaziti kroz `pending → planning → producing → succeeded` (ili `failed`). Preporučuje se anketiranje svakih 5–10 sekundi, dok se `status` ne promeni u `succeeded` ili `failed`. Za prikaz trake napretka u realnom vremenu može se koristiti `progress.percent` na najvišem nivou. **Anketiranje ovog interfejsa je besplatno i ne troši kredite.**

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i poruku. Na primer:

- `401 invalid_token`: Unauthorized, invalid or missing authorization token.
- `404 not_found`: Task not found, the given task_id does not exist.
- `429 too_many_requests`: Too many requests, you have exceeded the rate limit.
- `500 api_error`: Internal server error, something went wrong on the server.

### Primer odgovora greške

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
