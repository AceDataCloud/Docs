Ovaj dokument će predstaviti uputstvo za integraciju API za prepoznavanje digitalnih engleskih CAPTCHA, koji se zasniva na tehnologiji dubokog učenja i može se koristiti za prepoznavanje promenljivih engleskih numeričkih CAPTCHA. Unesite sadržaj CAPTCHA slike, a izlaz će biti rezultat CAPTCHA.

## Proces prijave

Da biste koristili API, prvo idite na [API za prepoznavanje digitalnih engleskih CAPTCHA](https://platform.acedata.cloud/documents/cd1f56dc-e9c9-4293-9c68-80fa560c9087) i zatražite odgovarajuću uslugu. Kada uđete na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite. Nakon prijave ili registracije, automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Osnovna upotreba

Prvo, upoznajte se sa osnovnim načinom korišćenja, što podrazumeva unos slike promenljive engleske numeričke CAPTCHA, kako biste dobili obrađeni rezultat. Prvo je potrebno jednostavno proslediti polje `image`, što je konkretna slika engleske numeričke CAPTCHA, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/c50hi9.png" width="500" className="m-auto" /></p>

Zatim je potrebno konvertovati sliku CAPTCHA u Base64 kodiranu sliku CAPTCHA. Preporučuje se korišćenje Google Chrome ekstenzije FeHelper za konverziju, a konkretan način korišćenja možete videti na sledećim slikama:

<p><img src="https://cdn.acedata.cloud/zy2jwh.png" width="500" className="m-auto" /></p>

<p><img src="https://cdn.acedata.cloud/pr73gn.png" width="500" className="m-auto" /></p>

<p><img src="https://cdn.acedata.cloud/ic4dbw.png" width="500" className="m-auto" /></p>

Nakon toga, možete kopirati Base64 kod koji ste dobili iz Google Chrome ekstenzije FeHelper, zapamtite da ne uključuje prefiks data:image/png;base64, konkretan sadržaj je sledeći:

<p><img src="https://cdn.acedata.cloud/5h4x4w.png" width="500" className="m-auto" /></p>

Možete primetiti da smo ovde postavili Request Headers, uključujući:

- `accept`: format odgovora koji želite da primite, ovde je uneto `application/json`, što znači JSON format.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

Takođe je postavljen Request Body, uključujući:

- `image`: Base64 kodirana slika CAPTCHA (bez prefiksa data:image/png;base64).

Nakon izbora, možete primetiti da je sa desne strane generisan odgovarajući kod, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/202y3d.png" width="500" className="m-auto" /></p>

Kliknite na dugme „Try“ da biste izvršili testiranje, kao što je prikazano na gornjoj slici, ovde smo dobili sledeći rezultat:

```json
{
  "text": "7364"
}
```

Vraćeni rezultat ima više polja, a opisi su sledeći:

- `text`, tekstualni sadržaj obrađene slike promenljive engleske numeričke CAPTCHA.

Možete primetiti da smo dobili rezultat obrade slike promenljive engleske numeričke CAPTCHA, a samo treba da se oslonimo na tekstualni sadržaj u rezultatu `text` da bismo prošli verifikaciju.

Takođe, ako želite da generišete odgovarajući kod za integraciju, možete ga direktno kopirati, na primer, CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/image2text' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX..."
}'
```

Python kod za integraciju je sledeći:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/image2text"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX..."
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
