Ovaj dokument će predstaviti uputstvo za integraciju API za prepoznavanje digitalnih engleskih CAPTCHA, koji se zasniva na tehnologiji dubokog učenja i može se koristiti za prepoznavanje promenljivih engleskih numeričkih CAPTCHA. Unesite sadržaj CAPTCHA slike, a izlaz će biti rezultat CAPTCHA.

## Proces prijave

Da biste koristili API za prepoznavanje digitalnih engleskih CAPTCHA, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, koji čuvate za kasnije.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može se koristiti za pozivanje svih usluga na platformi, bez potrebe da se za svaku uslugu posebno prijavljujete.** Prilikom prve prijave dobijate besplatnu kvotu za korišćenje; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Puna dokumentacija: [API za prepoznavanje digitalnih engleskih CAPTCHA →](https://platform.acedata.cloud/documents/captcha-recognition-image2text)

## Osnovna upotreba

Prvo se upoznajte sa osnovnim načinom korišćenja, što podrazumeva unos slike promenljive engleske numeričke CAPTCHA, kako biste dobili obrađeni rezultat. Prvo je potrebno jednostavno proslediti polje `image`, što je konkretna slika engleske numeričke CAPTCHA, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/c50hi9.png" width="500" className="m-auto" /></p>

Zatim treba da konvertujete sliku CAPTCHA u Base64 kodiranu sliku CAPTCHA. Preporučuje se korišćenje Google Chrome ekstenzije FeHelper za konverziju, a konkretan način korišćenja možete videti na sledećim slikama:

<p><img src="https://cdn.acedata.cloud/zy2jwh.png" width="500" className="m-auto" /></p>

<p><img src="https://cdn.acedata.cloud/pr73gn.png" width="500" className="m-auto" /></p>

<p><img src="https://cdn.acedata.cloud/ic4dbw.png" width="500" className="m-auto" /></p>

Nakon toga možete kopirati Base64 kod koji ste dobili iz Google Chrome ekstenzije FeHelper, zapamtite da ne uključuje prefiks data:image/png;base64, konkretan sadržaj je sledeći:

<p><img src="https://cdn.acedata.cloud/5h4x4w.png" width="500" className="m-auto" /></p>

Možete primetiti da smo postavili Request Headers, uključujući:

- `accept`: format odgovora koji želite da primite, ovde je uneto `application/json`, što znači JSON format.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

Takođe je postavljen Request Body, uključujući:

- `image`: Base64 kodirana slika CAPTCHA (bez prefiksa data:image/png;base64).

Nakon izbora, možete primetiti da je sa desne strane generisan odgovarajući kod, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/202y3d.png" width="500" className="m-auto" /></p>

Kliknite na dugme „Try“ da biste izvršili test, kao što je prikazano na gornjoj slici, ovde smo dobili sledeći rezultat:

```json
{
  "text": "7364",
  "elapsed": 31.6
}
```

Vraćeni rezultat ima više polja, koja su opisana kao:

- `text`, tekstualni sadržaj obrađene slike promenljive engleske numeričke CAPTCHA.
- `started_at`, `finished_at`: vreme kada je ova zahtev počela da se obrađuje i kada je rezultat proizveden, Unix vremenski pečat (sekunde, decimalni).
- `elapsed`: ukupno vreme obrade (sekunde).

Možete primetiti da smo dobili rezultat obrade slike promenljive engleske numeričke CAPTCHA, a samo treba da se oslonimo na tekstualni sadržaj u polju `text` da bismo prošli verifikaciju.

Takođe, ako želite da generišete odgovarajući kod za integraciju, možete ga direktno kopirati, na primer, CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/image2text' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX..."
}'
```

Python kod za integraciju je sledeći:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/image2text"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX..."
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asinhroni režim (async)

Podrazumevano, API je sinhrono blokirajući: jedan zahtev će čekati dok se ne završi obrada rezultata pre nego što se vrati. Ako radite sa više rešenja (multi-solver rotation) i želite da „odmah dobijete task_id nakon slanja zadatka, a zatim pređete na raspoređivanje drugih rešenja, a kasnije se vratite da pročitate rezultate“, možete u telu zahteva proslediti `async: true`.

Kada prosledite `async: true`, interfejs će odmah vratiti `task_id`, a neće blokirati čekajući:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/image2text' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX...",
  "async": true
}'
```

```json
{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

Ako želite da aktivno pratite napredak, možete koristiti taj `task_id` za upit `POST /captcha/tasks` (preporučuje se svake 3-5 sekundi). Ovaj interfejs neće pokrenuti ili ubrzati obradu zadatka; čak i ako ne proveravate, prekinete vezu ili napustite klijenta, server će nastaviti sa obradom:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002"
}'
```

Tokom obrade biće vraćeno `status: processing`:

```json
{ "success": true, "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002", "status": "processing" }
```

Kada se obrada završi, biće vraćeno `status: ready` i rezultat prepoznavanja `text` (struktura polja je potpuno identična onoj u sinhronom režimu):

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "ready",
  "text": "7364"
}
```

Objašnjenje naplate: u asinhronom režimu, kreiranje zadatka i čitanje statusa „u obradi“ se ne naplaćuje; **klijent se naplaćuje samo kada prvi put uspešno pročita rezultat** (što je u skladu sa postojećim ponašanjem i cenama u sinhronom režimu). Server će samostalno napredovati u obradi zadatka, ali neće naplatiti unapred samo zato što je pozadinski zadatak završen. Ako zadatak ne uspe u roku od 120 sekundi, biće prekinut sa HTTP 504 `timeout`, bez naplate. `/captcha/tasks` ne odgovara za napredovanje zadatka.

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:
- `400 token_mismatched`：Loša zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Loša zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neovlašćeno, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste limit brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.

### Primer greške u odgovoru

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
