Овај документ углавном описује процес коришћења ADSL Proxy API, помоћу којег можемо лако извући ADSL IP и додати IP белу листу за ADSL Proxy.

## Процес пријаве

Да бисте користили извлачење ADSL IP и додали IP белу листу за ADSL Proxy, прво можете отићи на [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/d8426c17-d22c-449a-b6bf-0a7790928e4d) и [ADSL Proxy Whitelist API](https://platform.acedata.cloud/documents/c21534fe-1f62-424b-9b10-a805cb473dd1) страницу и кликнути на дугме „Acquire“ да бисте добили потребне креденцијале:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након пријаве и регистрације аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, коју можете бесплатно користити.

## Извлачење ADSL IP

Након тога можете попунити одговарајуће садржаје на интерфејсу [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/d8426c17-d22c-449a-b6bf-0a7790928e4d), а следи демонстрација како да извучете ADSL IP.

### Постављање заглавља захтева и тела захтева

**Request Headers** укључује:

- `accept`: одређује да примите JSON формат одговора, овде се попуњава као `application/json`.
- `authorization`: кључ за позивање API, након захтева можете директно изабрати из падајућег менија.

**Request Body** укључује:

- `number`: број извучених ADSL IP адреса, подразумевано 1.
- `type`: тип извучених ADSL IP адреса, углавном се дели на `http` и `socks`, подразумевано `http`.
- `province`: провинција у којој се налази IP, подразумевано је насумично.
- `city`: град у којем се налази IP, подразумевано је насумично.

### Primer koda

Može se primetiti da su na desnoj strani stranice automatski generisani kodovi na raznim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/e2rmr0.png" width="500" class="m-auto"></p>

Neki primeri koda su sledeći:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/adsl/extract' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "province": "浙江",
  "city": "温州"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "province": "浙江",
    "city": "温州"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Primer odgovora

Nakon uspešnog zahteva, API će vratiti informacije o rezultatu slike sa promenjenim licem. Na primer:

```json
{
  "success": true,
  "data": [
    {
      "ip": "115.219.4.171",
      "port": 23456,
      "proxy": "115.219.4.171:23456",
      "outbound_ip": "115.219.4.171",
      "province": "浙江",
      "city": "温州",
      "expire_at": 1721877364.588,
      "dialed_at": 1721876984.588
    }
  ],
  "trace_id": "406465b0-f086-4a12-87a7-cdf05a3930a1"
}
```

Može se primetiti da u rezultatu postoji polje `data`, koje sadrži detalje o zadatku ekstrakcije IP adrese, a ostale informacije su prikazane na slici ispod:

- `success`, status rezultata zadatka ekstrakcije ADSL IP adrese.
- `data`, detaljne informacije o ekstraktovanoj ADSL IP adresi.

Iz `data` se može jasno videti detaljna informacija o ovoj IP adresi, gde `ip` predstavlja IP adresu koja je ekstraktovana, a ostale informacije su sledeće:

- `ip`, IP adresa ekstraktovana iz ADSL.
- `port`, informacija o portu ADSL IP adrese.
- `proxy`, kompletne informacije o ADSL IP proxyju.
- `province`, provincija ADSL IP adrese.
- `city`, grad ADSL IP adrese.

Može se primetiti da možemo lako koristiti gornji `proxy` za sledeći korak u radu sa IP proxyjem.

Prvo, pre nego što koristimo IP proxy, potrebno je dodati svoju mrežnu IP adresu (metod za dobijanje lokalne mrežne IP adrese potražite sami) u belu listu u nastavku, a zatim ćemo objasniti kako koristiti IP proxy:

### Korišćenje proxyja

> Napomena: Pre nego što koristite ekstraktovani proxy IP, obavezno dodajte IP u belu listu, inače nećete moći da ga koristite. O objašnjenju dodavanja bele liste pogledajte u nastavku.

Curl primer koda:

```shell
curl -x 115.219.4.171:23456 myip.vpsnb.net # http proxy
curl --socks5 115.219.3.54:23457 myip.vpsnb.net # socks proxy
```

Python primer proxyja:

```python
import requests
import socks
import socket
import time

def test_http_proxy(proxy):
    try:
        start_time = time.time()
        response = requests.get(
            'http://httpbin.org/ip', proxies={'http': proxy, 'https': proxy}, timeout=100)
        elapsed_time = time.time() - start_time
        print(response)
        if response.status_code == 200:
            print(f"HTTP Proxy {proxy} success. time: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"HTTP Proxy {proxy} failed. code: {response.status_code}")
    except Exception as e:
        print(f"HTTP Proxy {proxy} failed: {str(e)}")

def test_socks_proxy(proxy):
    proxy_parts = proxy.split(':')
    if len(proxy_parts) != 2:
        print(f"SOCKS failed: {proxy}")
        return

    host, port = proxy_parts
    port = int(port)

    try:
        start_time = time.time()
        socks.set_default_proxy(socks.SOCKS5, host, port)
        socket.socket = socks.socksocket
        response = requests.get('http://httpbin.org/ip', timeout=10)
        elapsed_time = time.time() - start_time

        if response.status_code == 200:
            print(f"SOCKS Proxy {proxy} success. time: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"SOCKS Proxy {proxy} failed. code: {response.status_code}")
    except Exception as e:
        print(f"SOCKS Proxy {proxy} failed: {str(e)}")
    finally:
        socks.set_default_proxy()
        socket.socket = socket.socket

if __name__ == "__main__":
    # HTTP Proxy
    http_proxy = "http://115.219.4.171:23456"
    test_http_proxy(http_proxy)

    # SOCKS Proxy
    socks_proxy = "115.219.3.54:23457"
    test_socks_proxy(socks_proxy)

```

## 添加 IP 白名单

接下来就可以在界面上填写对应的内容，如图所示：

<p><img src="https://cdn.acedata.cloud/wz4obo.png" width="500" class="m-auto"></p>

在第一次使用该接口时，我们至少需要填写三个内容，一个是 `authorization`，直接在下拉列表里面选择即可。另一个参数是 `ip`， `ip` 就是我们需要使用上文提取到的 IP 代理的本机网络地址。最后一个参数是`action`，`action` 是我们对白名单进行的操作，这里是对白名单进行添加的操作。

同时您可以注意到右侧有对应的调用代码生成，您可以复制代码直接运行，也可以直接点击「Try」按钮进行测试。

<p><img src="https://cdn.acedata.cloud/cs5ib2.png" width="500" class="m-auto"></p>

Python 样例调用代码：

```python
import requests

url = "https://api.acedata.cloud/adsl/whitelist"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "ip": "113.112.122.132",
    "action": "add"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

调用之后，我们发现返回结果如下：

```json
{
  "success": true
}
```

返回结果一共有一个字段，介绍如下：

- `success `，此处操作结果的状态。

其中 `success` 是包含了操作结果的状态，我们可以看到将 IP `113.112.122.132` 已经成功添加到白名单内。
