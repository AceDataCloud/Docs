GLM（General Language Model）je nova generacija serije velikih jezičkih modela koju je lansirao Zhipu AI (智谱 AI / Z.ai), koja ima snažne sposobnosti razumevanja i generisanja na kineskom i engleskom jeziku, sa izvanrednim performansama u kineskim scenarijima, generisanju koda, zaključivanju i višekratnim razgovorima. Nove generacije modela kao što su GLM-5.3, GLM-5.2, GLM-4.7 su optimizovane za duge kontekste, pozivanje alata i zadatke sa kodom, i mogu se široko primeniti u scenarijima kao što su pametno odgovaranje, kreiranje sadržaja, pomoć pri kodiranju, chatbotovi itd.

Ovaj dokument uglavnom opisuje proces korišćenja GLM Chat Completion API, koji vam omogućava da lako pozivate GLM seriju modela putem jedinstvenog OpenAI kompatibilnog interfejsa.

## Proces prijave

Da biste koristili GLM Chat Completion API, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, koji čuvate za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozvati sve usluge na platformi, nije potrebno posebno se prijavljivati za svaku uslugu.** Prilikom prve prijave dobijate besplatnu kvotu, koju možete besplatno isprobati; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Potpuna dokumentacija: [GLM Chat Completion API →](https://platform.acedata.cloud/documents/glm-chat-completions)

## Osnovna upotreba

GLM Chat Completion API adresa zahteva je `https://api.acedata.cloud/glm/chat/completions`, koristi Bearer Token za autentifikaciju, a telo zahteva je kompatibilno sa OpenAI Chat Completions protokolom.

Prilikom prve upotrebe ovog interfejsa, potrebno je da popunite najmanje tri sadržaja:

- `authorization`: jednostavno odaberite Bearer Token iz padajuće liste.
- `model`: odaberite GLM model koji želite da pozovete, trenutno podržani modeli uključuju:
  - `glm-5.3`: najnoviji flagship model, podržava 1M konteksta i najduži 128K izlaz, pogodan za složeno zaključivanje, kod i Agent zadatke. Zaključivanje je uvek uključeno, možete izabrati `reasoning_effort` kao `low`, `high` ili `max`.
  - `glm-5.2`: prethodni flagship model, snažnih sveobuhvatnih sposobnosti.
  - `glm-5.1`: zreo flagship model, pogodan za opšte složene zadatke.
  - `glm-4.7`: izvanredan u zaključivanju, pozivanju alata i zadacima sa kodom.
  - `glm-4.6`: opšti model za razgovor, balansira efikasnost i troškove.
  - `glm-3-turbo`: klasični model za razgovor, pogodan za opšte zadatke generisanja teksta.
- `messages`: niz poruka, svaka poruka sadrži `role` i `content`, `role` podržava tri vrste uloga: `user`, `assistant`, `system`.

Uobičajeni opcioni parametri:

- `max_tokens`: ograničava maksimalan broj tokena u jednom odgovoru.
- `temperature`: generiše slučajnost, između 0-2, veća vrednost znači veću disperziju.
- `top_p`: parametar za uzorkovanje jezgra, kontroliše kumulativnu verovatnoću kandidata tokena.
- `n`: koliko kandidatskih odgovora generisati odjednom.
- `stream`: da li omogućiti strimovano odgovaranje, podrazumevano `false`.
- `stop`: prilagođena sekvenca za zaustavljanje.

Evo najjednostavnijeg primera poziva u Python-u:

```python
import requests

url = "https://api.acedata.cloud/glm/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "glm-5.2",
    "messages": [
        {"role": "user", "content": "hello"}
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Nakon poziva, otkrili smo da je rezultat vraćen kao:

```json
{
  "id": "msg_202604262252030313862701a04e33",
  "model": "glm-5.2",
  "object": "chat.completion",
  "created": 1777215124,
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! 👋 How can I assist you today?"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 10,
    "completion_tokens": 23,
    "total_tokens": 33
  }
}
```

Objašnjenje glavnih polja vraćenog rezultata je sledeće:

- `id`: jedinstveni ID ovog razgovora.
- `created`: vreme kreiranja ovog razgovora (Unix vremenska oznaka, u sekundama).
- `model`: naziv GLM modela koji je zapravo pozvan.
- `choices`: lista odgovora generisanih od strane modela. `choices[i].message.content` je konkretan tekst odgovora modela, `finish_reason` označava razlog završetka (`stop`, `length`, `tool_calls`, `content_filter` itd.).
- `usage`: statistika korišćenja tokena za ovaj zahtev, uključuje `prompt_tokens`, `completion_tokens`, `total_tokens`.

## Strimovano odgovaranje

Ovaj interfejs podržava strimovano odgovaranje (Server-Sent Events), što je veoma korisno za integraciju sa web stranicama, omogućavajući stranicama da postignu efekat prikazivanja reči po reč.

Ako želite da se odgovor vraća strimovano, jednostavno postavite `stream` parametar u telu zahteva na `true`.

Python primer poziva:

```python
import requests

url = "https://api.acedata.cloud/glm/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "glm-4.7",
    "messages": [{"role": "user", "content": "hi"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode("utf-8"))
```

Izlaz izgleda ovako (izdvojeno):
```text

Možete videti da u odgovoru ima mnogo `data`, svaka `data` sadrži jedan inkrementalni deo. `choices[i].delta.content` je trenutni deo teksta koji je dodat u chunk, možete spojiti te delove da formirate potpuni odgovor. Kada je sadržaj `data` `[DONE]`, to označava kraj strimovanog odgovora. Poslednji deo koji sadrži `usage` će sumirati potrošnju tokena za ovu zahtev.

JavaScript (Node.js) primer:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "glm-4.7",
    messages: [{ role: "user", content: "hi" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/glm/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

Java primer koda:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "glm-4.7");
jsonObject.put("messages", new JSONArray().put(new JSONObject().put("role", "user").put("content", "hi")));

MediaType mediaType = MediaType.parse("application/json; charset=utf-8");

  .build();

OkHttpClient client = new OkHttpClient();

```

Ostali jezici mogu biti prepisani na sličan način, princip je isti.

## Višekratni dijalog

Ako želite da implementirate funkcionalnost višekratnog dijaloga, potrebno je da stavite istoriju dijaloga u `messages` niz, zadržavajući redosled naizmeničnog pojavljivanja `user` i `assistant`.

Python primer poziva koda:

```python
import requests

url = "https://api.acedata.cloud/glm/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "glm-4.7",
    "messages": [
        {"role": "user", "content": "Zdravo"},
        {"role": "assistant", "content": "Zdravo! Kako mogu da ti pomognem danas?"},
        {"role": "user", "content": "Šta sam upravo rekao?"}
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Postavljanjem više pitanja, lako možete ostvariti višekratni dijalog i dobiti sledeći odgovor:

```json
{
  "id": "msg_20260426225208b95324e9945a48d3",
  "model": "glm-4.7",
  "object": "chat.completion",
  "created": 1777215128,
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Rekao si: **\"Zdravo\"** 😊\n\nJavi mi ako ti treba još nešto!"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 48,
    "completion_tokens": 37,
    "total_tokens": 85
  }
}
```

Možete primetiti da informacije u `choices` ostaju dosledne osnovnoj upotrebi, model daje odgovor na osnovu kompletne istorije dijaloga, omogućavajući višekratnu kontekstualnu interakciju.

## Sistem poruke (System Prompt)

Možete dodati poruku sa `role` kao `system` na početak `messages` niza, kako biste ograničili ulogu, stil ili ponašanje modela:

```python
payload = {
    "model": "glm-4.7",
    "messages": [
        {"role": "system", "content": "Ti si iskusni pomoćnik za pisanje na kineskom, molim te odgovaraj sa sažetim i profesionalnim tonom."},
        {"role": "user", "content": "Molim te, predstavi GLM model u tri rečenice."}
    ]
}
```

## Pozivanje alata (Function Calling)

GLM model podržava OpenAI kompatibilno pozivanje funkcija, možete deklarisati pozive funkcija putem `tools` parametra, model će, kada je potrebno, vratiti strukturirane informacije o pozivu funkcije u `choices[i].message.tool_calls`.

```python
payload = {
    "model": "glm-4.7",
    "messages": [
        {"role": "user", "content": "Kako je vreme u Pekingu danas?"}
    ],
    "tools": [
        {
            "type": "function",
            "function": {
                "name": "get_weather",
                "description": "Proveri vreme u određenom gradu",
                "parameters": {
                    "type": "object",
                    "properties": {
                        "city": {"type": "string", "description": "Naziv grada"}
                    },
                    "required": ["city"]
                }
            }
        }
    ]
}
```

Ako model odluči da pozove alat, razlog završetka u rezultatu će se promeniti u `tool_calls`, i u `message.tool_calls` će biti navedeno ime funkcije i parametri u JSON string formatu. Možete izvršiti tu funkciju i vratiti rezultat kao poruku sa `role` kao `tool` modelu, čime se završava kompletan krug pozivanja alata.

## Обрада грешака

Када позивате АПИ, ако наиђете на грешку, АПИ ће вратити одговарајући код грешке и информације. На пример:

- `400 token_mismatched`：Недостају или неважећи параметри захтева.
- `400 api_not_implemented`：Користили сте неподржане параметре или модел.
- `401 invalid_token`：Није овлашћен, Bearer Token недостаје или је неважећи.
- `429 too_many_requests`：Активирана ограничења учесталости, молимо покушајте поново касније.
- `500 api_error`：Унутрашња грешка сервера или горњи ток је привремено недоступан.

### Пример одговора на грешку

```json
&#123;
  "trace_id": "69ea9bcf-c5da-41a3-be97-c80912a08523",
  "error": &#123;
    "code": "api_error",
    "message": "Сервис је привремено недоступан, молимо покушајте поново касније."
  &#125;
&#125;
```

Када се врати `api_error` и порука гласи `Сервис је привремено недоступан, молимо покушајте поново касније.`, обично то значи да је горњи GLM сервис привремено недоступан, препоручује се да се поново покуша са експоненцијалним повлачењем или да се прелази на друге доступне GLM моделе (на пример, привремено прелазак са `glm-5.1` на `glm-4.7` или `glm-4.6`).
