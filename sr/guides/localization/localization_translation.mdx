Glavna funkcija Localization Translate API je da dobijete preveden tekst unosom teksta koji treba prevesti, pri čemu se jezik na koji se prevodi može prilagoditi, a rezultati prevođenja mogu se isporučiti u dva glavna formata: `json` i `markdown`.

Ovaj dokument će detaljno opisati uputstva za integraciju Translate API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Translate API, možete lako prevesti uneseni tekst na određeni jezik, uz podršku za specifične načine isporuke rezultata prevođenja.

## Proces prijave

Da biste koristili Localization Translate API, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, koji čuvate za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozvati sve usluge platforme, bez potrebe da se za svaku uslugu posebno prijavljujete.** Prvi put kada se prijavite, dobićete besplatnu kvotu za probu; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Potpuna dokumentacija: [Localization Translate API →](https://platform.acedata.cloud/documents/localization-translate)

## Primer zahteva

Uzećemo primer sa engleskim unosom da prikažemo kako koristiti ovaj API. Pretpostavimo da je engleski opis: `# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.`, a zatim ćemo prikazati kako da otpremite engleski opis i dobijete prevod na kineski, prikazan u markdown formatu.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se prihvata odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

**Telo zahteva** uključuje:

- `input`: sadržaj koji treba prevesti. Kada je `extension=md`, šalje se string, a kada je `extension=json`, šalje se JSON objekat.
- `locale`: prilagođeni jezik prevođenja.
- `extension`: format unosa, može biti `md` ili `json`.
- `model`: veliki model koji se koristi za prevođenje, podrazumevano je gpt-3.5.

| `extension` | `input` tip | Primer                                      |
| ----------- | ---------- | ------------------------------------------ |
| `md`        | string     | `"# Title\n\nParagraph"`                   |
| `json`      | object     | `{"title": "Hello", "button": "Submit"}` |

`extension` mora odgovarati tipu `input`; string ne može koristiti `json`, a JSON objekat ne može koristiti `md`.

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani različiti kodovi, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/tn5nno.png" width="500" className="m-auto" /></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/localization/translate' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "input": "# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.",
  "locale": "zh-CN",
  "extension": "md"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/localization/translate"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.",
    "locale": "zh-CN",
    "extension": "md"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Primer odgovora

Kada je zahtev uspešan, API će vratiti informacije o rezultatu ovog zadatka prevođenja. Na primer:

```json
{
  "data": "# 标题 1\n\n这是一个段落。\n\n## 标题 2\n\n这是另一个段落。",
  "usage": {
    "prompt_tokens": 172,
    "completion_tokens": 25
  },
  "model": "gpt-3.5-turbo-16k",
  "locale": "zh-CN"
}
```

Možete primetiti da rezultat sadrži polje `data`, koje uključuje prevedeni tekst na kineskom, a takođe se vraća u markdown formatu, dok su ostale informacije prikazane kao:

- `data`, rezultat ovog zadatka prevođenja.
- `model`, veliki jezički model korišćen za ovaj zadatak prevođenja.
- `locale`, tip jezika za prevođenje ovog zadatka.

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
