Знамо да интеграција неких API за питања и одговоре на тржишту није баш тако лака, као што је OpenAI-ов Chat Completions API, који има поље `messages`. Да бисмо завршили континуирани разговор, морамо пренети сву историју контекста, а такође морамо решити проблем прекорачења ограничења токена.

AI API за питања и одговоре који пружа AceDataCloud оптимизован је за горе наведене ситуације, тако да, уз одржавање квалитета одговора, имплементација континуираног разговора је обавијена, и током интеграције не морате да бринете о преносу `messages`, нити о проблемима прекорачења ограничења токена (API то аутоматски обрађује), а такође пружа функције за упит, измену разговора и друге, што значајно поједностављује целокупну интеграцију.

Овај документ ће представити упутство за интеграцију AI API за питања и одговоре.

## Процес пријаве

Да бисте користили AI API за питања и одговоре, прво идите на [Ace Data Cloud контролни панел](https://platform.acedata.cloud/console/applications) да добијете ваш API токен, који ћете задржати за резерву.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након тога ћете бити аутоматски враћени на тренутну страницу.

**Један API токен је довољан за позивање свих услуга платформе, није потребно да се за сваку услугу посебно пријављујете.** При првом захтеву добићете бесплатну квоту, можете бесплатно да искористите; када вам квота понестане, можете допунити општи баланс на [контролном панелу](https://platform.acedata.cloud/console/coin).

> 📘 Пуна документација: [AI API за питања и одговоре →](https://platform.acedata.cloud/documents/aichat-conversations)

## Основна употреба

Прво, упознајте се са основним начином коришћења, а то је уношење питања и добијање одговора, потребно је само једноставно пренети поље `question` и одредити одговарајући модел.

На пример, ако питате: „Како се зовеш?“, можемо у интерфејсу унети одговарајући садржај, као на слици:

![](https://cdn.acedata.cloud/xqxda4.png)

Можете видети да смо овде подесили заглавља захтева, укључујући:

- `accept`: каквог формата желите да примите одговор, овде је написано `application/json`, што значи JSON формат.
- `authorization`: кључ за позивање API-а, након пријаве можете директно изабрати из падајућег менија.

Такође смо подесили тело захтева, укључујући:

- `model`: избор модела, као што су популарни GPT 3.5, GPT 4 итд.
- `question`: питање које желите да поставите, може бити било који чисти текст.

Након избора, можете приметити да је на десној страни генерисан одговарајући код, као на слици:

<p><img src="https://cdn.acedata.cloud/dvkps6.png" width="500" className="m-auto" /></p>

Кликните на дугме „Пробај“ да бисте тестирали, као што је приказано на горњој слици, овде смо добили следећи резултат:

```json
{
  "answer": "Ja sam AI jezički model razvijen od strane OpenAI i nemam lično ime. Međutim, možete me zvati GPT ili jednostavno Chatbot. Kako mogu da vam pomognem danas?"
}
```

Можете видети да у враћеном резултату постоји поље `answer`, што је одговор на то питање. Можете унети било које питање и добити било који одговор.

Ако вам не треба подршка за више рунди разговора, овај API може значајно олакшати вашу интеграцију.

Ако желите да генеришете одговарајући код за интеграцију, можете директно копирати генерисани код, на пример, CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "question": "Kako se зовеш?"
}'
```

Python код за интеграцију изгледа овако:

```python
import requests

url = "https://api.acedata.cloud/aichat/conversations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-3.5",
    "question": "Kako se зовеш?"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Више рунди разговора

Ако желите да интегришете функцију више рунди разговора, потребно је да пренесете додатни параметар `stateful`, чија вредност је `true`, а сваки следећи захтев мора да садржи тај параметар. Након преношења параметра `stateful`, API ће додатно вратити параметар `id`, који представља ID тренутног разговора, а касније само треба да пренесете тај ID као параметар да бисте лако реализовали више рунди разговора.

Хајде да демонстрирамо конкретну операцију.

Први захтев, поставите параметар `stateful` на `true`, и нормално пренесите параметре `model` и `question`, као на слици:

![](https://cdn.acedata.cloud/fn4bi9.png)

Одговарајући код изгледа овако:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "question": "Kako se зовеш?",
  "stateful": true
}'
```

Можете добити следећи одговор:

```json
{
  "answer": "Ja sam AI jezički model koji je kreirao OpenAI i nemam lično ime. Možete me jednostavno zvati OpenAI ili ChatGPT. Kako mogu da vam pomognem danas?",
  "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"
}
```

Други захтев, пренесите `id` поље враћено из првог захтева као параметар, а параметар `stateful` и даље поставите на `true`, питајући „Шта сам вас управо питао?“, као на слици:

![](https://cdn.acedata.cloud/46a6kd.png)

Одговарајући код изгледа овако:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "stateful": true,
  "id": "7cdb293b-2267-4979-a1ec-48d9ad149916",
  "question": "Шта сам вас управо питао?"
}'
```

Резултат је следећи:

```json
{
  "answer": "Питали сте ме како се зовем. Као AI језички модел, немам лични идентитет, па немам специфично име. Међутим, можете ме назвати OpenAI или ChatGPT, именима која се користе за овај AI модел. Има ли нешто друго с чим могу да вам помогнем?",
  "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"
}
```

Можете видети да можете одговорити на одговарајућа питања на основу контекста.

## Стриминг одговора

Овај интерфејс такође подржава стриминг одговора, што је веома корисно за веб интеграцију, јер омогућава веб страници да реализује ефекат приказивања по словима.

Ако желите да стриминг одговор буде враћен, можете променити параметар `accept` у заглављу захтева на `application/x-ndjson`.

Измените као на слици, али код позива треба да има одговарајуће измене да би подржао стриминг одговор.

![](https://cdn.acedata.cloud/axt1aa.png)

Након што промените `accept` на `application/x-ndjson`, API ће враћати одговарајуће JSON податке ред по ред. На нивоу кода, морамо направити одговарајуће измене да бисмо добили редне резултате.

Python пример кода за позив:
```python
import requests

url = "https://api.acedata.cloud/aichat/conversations"

headers = {
    "accept": "application/x-ndjson",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-3.5",
    "stateful": True,
    "id": "7cdb293b-2267-4979-a1ec-48d9ad149916",
    "question": "Zdravo"
}

response = requests.post(url, json=payload, headers=headers, stream=True)
for line in response.iter_lines():
    print(line.decode())
```

Izlaz izgleda ovako:

```json
{"answer": "Zdravo", "delta_answer": "Zdravo", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Zdravo!", "delta_answer": "!", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Zdravo! Kako", "delta_answer": " Kako", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Zdravo! Kako mogu", "delta_answer": " mogu", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Zdravo! Kako mogu da", "delta_answer": " da", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Zdravo! Kako mogu da pomognem", "delta_answer": " pomognem", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Zdravo! Kako mogu da pomognem vama", "delta_answer": " vama", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Zdravo! Kako mogu da pomognem vama danas", "delta_answer": " danas", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Zdravo! Kako mogu da pomognem vama danas?", "delta_answer": "?", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
```

Možete videti da je odgovor u `answer` najnoviji odgovor, dok je `delta_answer` nova dodata sadržina odgovora, možete se osloniti na rezultate da ih povežete sa vašim sistemom.

JavaScript takođe podržava, na primer, kod za strimovanje u Node.js izgleda ovako:

```javascript
const axios = require("axios");

const url = "https://api.acedata.cloud/aichat/conversations";
const headers = {
  "Content-Type": "application/json",
  Accept: "application/x-ndjson",
  Authorization: "Bearer {token}",
};
const body = {
  question: "Zdravo",
  model: "gpt-3.5",
  stateful: true,
};

axios
  .post(url, body, { headers: headers, responseType: "stream" })
  .then((response) => {
    console.log(response.status);
    response.data.on("data", (chunk) => {
      console.log(chunk.toString());
    });
  })
  .catch((error) => {
    console.error(error);
  });
```

Java primer koda:

```java
String url = "https://api.acedata.cloud/aichat/conversations";
OkHttpClient client = new OkHttpClient();
MediaType mediaType = MediaType.parse("application/json");
RequestBody body = RequestBody.create(mediaType, "{\"question\": \"Zdravo\", \"stateful\": true, \"model\": \"gpt-3.5\"}");
Request request = new Request.Builder()
        .url(url)
        .post(body)
        .addHeader("Content-Type", "application/json")
        .addHeader("Accept", "application/x-ndjson")
        .addHeader("Authorization", "Bearer {token}")
        .build();

client.newCall(request).enqueue(new Callback() {
    @Override
    public void onFailure(Call call, IOException e) {
        e.printStackTrace();
    }

    @Override
    public void onResponse(Call call, Response response) throws IOException {
        if (!response.isSuccessful()) throw new IOException("Neočekivani kod " + response);
        try (BufferedReader br = new BufferedReader(
                new InputStreamReader(response.body().byteStream(), "UTF-8"))) {
            String responseLine;
            while ((responseLine = br.readLine()) != null) {
                System.out.println(responseLine);
            }
        }
    }
});
```

Ostale jezike možete prepraviti sami, princip je isti.

## Modeli postavke

Znamo da OpenAI povezani API imaju odgovarajući koncept `system_prompt`, što je postavljanje unapred za ceo model, kao što je njegovo ime itd. Ovaj AI Q&A API takođe izlaže ovaj parametar, koji se zove `preset`, koristeći ga možemo dodati unapred postavke modelu, isprobajmo to na primeru:

Ovde dodatno dodajemo `preset` polje, sadržaj je `Ti si profesionalni umetnik`, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/ird6i9.png)

Odgovarajući kod izgleda ovako:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "stateful": true,
  "question": "Šta možeš da mi pomogneš?",
  "preset": "Ti si profesionalni umetnik"
}'
```

Rezultat izgleda ovako:

```python
{
    "answer": "Kao profesionalni umetnik, mogu ponuditi niz usluga i pomoći u zavisnosti od vaših specifičnih potreba. Evo nekoliko načina na koje mogu da vam pomognem:\n\n1. Prilagođene umetničke radove: Ako imate specifičnu viziju ili ideju, mogu stvoriti prilagođene umetničke radove za vas. To može uključivati slike, crteže, digitalnu umetnost ili bilo koji drugi medij koji preferirate.\n\n2. Komisijski radovi: Ako imate specifičnu temu ili koncept na umu, mogu stvoriti komisijske umetničke radove prilagođene vašim preferencama. Ovo može biti za lično uživanje ili kao jedinstveni poklon za nekoga posebnog.\n\n3. Umetnička konsultacija: Ako vam je potrebna pomoć oko izbora umetnosti, unutrašnjeg dizajna ili kako da prikažete i izložite umetnost u vašem prostoru, mogu pružiti profesionalne savete kako bih poboljšao vaš estetski osećaj i stvorio koherentan izgled."
}
```

Možete videti da smo ovde rekli GPT-u da je robot, a zatim ga pitali šta može da uradi za nas, on može da igra ulogu robota da odgovara na pitanja.

## Prepoznavanje slika

Ovaj AI takođe može podržati dodavanje priloga za prepoznavanje slika, putem `references` prosledite odgovarajući link slike, na primer, ovde imam sliku jabuke, kao što je prikazano:

![](https://cdn.acedata.cloud/ht05g0.png)

Link te slike je [https://cdn.acedata.cloud/ht05g0.png](https://cdn.acedata.cloud/ht05g0.png), jednostavno ćemo ga proslediti kao `references` parametar, takođe treba napomenuti da model mora biti odabran da podrži vizuelno prepoznavanje, trenutno podržan je `gpt-4-vision`, tako da unos izgleda ovako:

![](https://cdn.acedata.cloud/cstrbq.png)

Odgovarajući kod izgleda ovako:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-4-vision",
  "question": "Koliko jabuka ima na slici?",
  "references": ["https://cdn.acedata.cloud/ht05g0.png"]
}'
```

Rezultat izgleda ovako:

```json
{
  "answer": "Na slici se nalazi 5 jabuka."
}
```

Možete videti da smo uspešno dobili odgovor na osnovu slike.

## Pitanja i odgovori putem interneta

Ovaj API takođe podržava modele povezane na internet, uključujući GPT-3.5 i GPT-4, koji mogu podržati, u pozadini API-a postoji automatska pretraga interneta i sažimanje, možemo odabrati model `gpt-3.5-browsing` da isprobamo, kao što je prikazano:

![](https://cdn.acedata.cloud/x5i8np.png)

Kod izgleda ovako:
```
```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer &#123;token&#125;' \
-H 'content-type: application/json' \
-d '&#123;
  "model": "gpt-3.5-browsing",
  "question": "Kakvo je vreme u Njujorku danas?"
&#125;'
```

Rezultat je sledeći:

```json
&#123;
  "answer": "Vreme u Njujorku danas je sledeće:\n- Trenutna temperatura: 16°C (60°F)\n- Maksimalna: 16°C (60°F)\n- Minimalna: 10°C (50°F)\n- Vlažnost: 47%\n- UV indeks: 6 od 11\n- Izlazak sunca: 5:42 am\n- Zalazak sunca: 8:02 pm\n\nOblačno je sa mogućnošću povremenih pljuskova tokom noći, a verovatnoća kiše je 50%.\nZa više detalja, možete posetiti [The Weather Channel](https://weather.com/weather/tenday/l/96f2f84af9a5f5d452eb0574d4e4d8a840c71b05e22264ebdc0056433a642c84).\n\nDa li želite da znate još nešto?"
&#125;
```

Može se primetiti da je automatski pretražio sajt The Weather Channel i dobio informacije sa njega, a zatim dalje vratio trenutne rezultate.

> Ako imate veće zahteve za kvalitet odgovora modela, možete promeniti model u `gpt-4-browsing`, efekat odgovora će biti bolji.
