MiMo 2.6 Pro i MiMo 2.6 Flash su modeli iz Xiaomi MiMo serije. Ovaj interfejs koristi format OpenAI Chat Completions i naplaćuje se prema ulaznim, izlaznim i tokenima pogođenim keš memorijom.

## Modeli i interfejsi

| Model                | Namena           |
| ----------------- | ------------ |
| `mimo-v2.6-pro`   | Složena analiza, rezonovanje i pozivanje alata |
| `mimo-v2.6-flash` | Svakodnevni razgovori i laki zadaci    |

Aktivirajte MiMo i pribavite odgovarajuće API akreditive, zatim pošaljite zahtev na `https://api.acedata.cloud/mimo/chat/completions`. `base_url` za OpenAI SDK može biti postavljen na `https://api.acedata.cloud/mimo`. Objedinjeni `/v1/chat/completions` ulaz takođe zahteva odgovarajuće dozvole za uslugu.

Početni opseg interfejsa je tekstualni Chat Completions; slike, zvuk, video, pretraga interneta, Responses, Messages, Batch i UltraSpeed nisu obuhvaćeni ovim izdanjem.

## Python primer

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ACEDATACLOUD_API_KEY"],
    base_url="https://api.acedata.cloud/mimo",
)
response = client.chat.completions.create(
    model="mimo-v2.6-pro",
    messages=[{"role": "user", "content": "解释彩虹形成的原因。"}],
    max_completion_tokens=256,
    extra_body={"thinking": {"type": "disabled"}},
)
print(response.choices[0].message.content)
print(response.usage)
```

Primer prikazuje način pisanja zahteva; stvarni primer odgovora biće dopunjen nakon verifikacije usluge.

## Strimovanje, rezonovanje i pozivanje alata

Postavite `stream=true` za primanje SSE-a; ako je potrebna konačna upotreba, prosledite `stream_options={"include_usage": true}`. Klijent treba da obradi sadržaj, sadržaj rezonovanja i inkremente pozivanja alata, kao i završni usage događaj.

Koristite `thinking.type=enabled` za uključivanje rezonovanja, a `disabled` za isključivanje. `reasoning_content` i konačni `content` vraćaju se odvojeno; pri nastavljanju pozivanja alata sačuvajte sadržaj rezonovanja u poruci asistenta, kompletne `tool_calls` i odgovarajući `tool_call_id`.

Podnosite samo deklaracije alata sa `type=function`, a `tool_choice` podržava samo `auto`. Aplikacija je odgovorna za izvršavanje alata i vraćanje rezultata; samo vraćanje pozivanja alata od strane modela ne znači da je alat izvršen. Uslužna ugrađena pretraga interneta još nije otvorena.

## Naplata

`prompt_tokens` uključuje ulaze pogođene keš memorijom; `prompt_tokens_details.cached_tokens` se obračunava po ceni keš memorije, a ostali ulazi po redovnoj ulaznoj ceni. `completion_tokens` uključuje izlaz rezonovanja, nemojte dvostruko sabirati tokene rezonovanja. Strimovani pozivi se takođe obračunavaju prema konačnoj stvarnoj upotrebi.

Cene su merodavne prema kontrolnoj tabli, a dolarski trošak Credit-a zavisi od kupljenog paketa. Neuspešne zahteve ne treba smatrati uspešno završenim; ako je potrebno proveriti naplatu, dostavite identifikator praćenja iz odgovora.

## Obrada grešaka

Za greške parametara proverite format zahteva; za greške autentifikacije ili dozvola proverite akreditive i status aktivacije usluge; u slučaju 429 izvršite ponovno pokušavanje uz odlaganje. Kada nema kapaciteta zdravog modela, može biti vraćen 503. Ako do prekida dođe nakon početka strimovanog odgovora, najpre proverite već primljene rezultate i upotrebu, kako biste izbegli nasumično ponavljanje zahteva.
