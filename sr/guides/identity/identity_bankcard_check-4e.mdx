Овај документ ће представити упутство за интеграцију API за проверу четири елемента банковне картице, који се може користити за унос броја банковне картице, имена, броја личне карте и броја телефона, како би се проверила истинитост и доследност информација.

## Процес пријаве

Да бисте користили API, прво морате да одете на страницу [API за проверу четири елемента банковне картице](https://platform.acedata.cloud/documents/02f77369-ec7b-4218-a956-d7a84982a626) и затражите одговарајућу услугу. Након што уђете на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите. Након пријаве или регистрације, аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, коју можете користити за API.

## Основна употреба

Прво, упознајте се са основним начином коришћења, а то је унос информација о броју банковне картице, након чега ћете добити обрађену слику резултата. Прво је потребно једноставно проследити поље `bank_card`. Након тога можемо попунити одговарајуће садржаје на интерфејсу, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/1pl0y5.png" width="500" class="m-auto"></p>

Можете видети да смо овде подесили Request Headers, укључујући:

- `accept`: у каквом формату желите да примите одговор, овде је написано `application/json`, што значи JSON формат.
- `authorization`: кључ за позивање API, који можете директно изабрати након захтева.

Такође смо подесили Request Body, укључујући:

- `bank_card`: информације о броју банковне картице, обавезан параметар.
- `id_card`: број личне карте, обавезан параметар.
- `name`: име корисника, обавезан параметар.
- `phone`: резервисани број телефона.
- `cert_type`: тип личне карте, који мора бити у складу са личном картом.
- `encryption`: опционално, параметар за шифровање осетљивих поља (ако је потребно послати шифровани текст).

Након избора, можете приметити да је на десној страни генерисан одговарајући код, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/slajgv.png" width="500" class="m-auto"></p>

Кликните на дугме „Try“ да бисте извршили тест, као што је приказано на горњој слици, и добили смо следећи резултат:

```json
{
  "result": "0",
  "description": "Аутентификација успешна"
}
```

Враћени резултат има више поља, а описује се као:

- `result`, код резултата аутентификације, накнаде су следеће.
  - Кодови резултата накнаде:
    - 0: Аутентификација успешна
    - -1: Аутентификација није успела
    - -4: Информације о власнику картице су нетачне
    - -5: Нису омогућене трансакције без картице
    - -6: Ова картица је одузета
    - -7: Неважећи број картице
    - -8: Ова картица нема одговарајућу банку
    - -9: Ова картица није иницијализована или је спавала
    - -10: Картица за превару, задржана картица
    - -11: Ова картица је пријављена као изгубљена
    - -12: Ова картица је истекла
    - -13: Ограничена картица
    - -14: Прекорачен број покушаја уноса лозинке
    - -15: Банка не подржава ову трансакцију
  - Кодови резултата без накнаде:
    - -2: Провера имена није успела
    - -3: Број банковне картице је нетачан
    - -16: Услуга проверног центра је заузета
    - -17: Прекорачен број покушаја провере, покушајте поново сутра
- `description`, опис резултата пословања.

Може се видети да број банковне картице, име, број личне карте и број телефона имају истинитост и доследност.

Ако желите да генеришете одговарајући код за интеграцију, можете га директно копирати, на пример, CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/identity/bankcard/check-4e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "***",
  "phone": "***",
  "id_card": "***",
  "bank_card": "***"
}'
```

Python код за интеграцију је следећи:

```python
import requests

url = "https://api.acedata.cloud/identity/bankcard/check-4e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "Ху Јинфу",
    "phone": "***",
    "id_card": "***",
    "bank_card": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Обрада грешака

Када позивате API, ако наиђете на грешку, API ће вратити одговарајући код грешке и информације. На пример:

- `400 token_mismatched`: Лош захтев, могуће због недостајућих или неважећих параметара.
- `400 api_not_implemented`: Лош захтев, могуће због недостајућих или неважећих параметара.
- `401 invalid_token`: Неовлашћено, неважећи или недостајући ауторизациони токен.
- `429 too_many_requests`: Превише захтева, превазишли сте лимит.
- `500 api_error`: Унутрашња грешка сервера, нешто није у реду на серверу.

### Пример одговора на грешку

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "подаци нису могли бити преузети"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
