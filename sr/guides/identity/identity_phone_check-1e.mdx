Ovaj dokument će predstaviti API za proveru statusa mobilnog broja, koji se može koristiti za verifikaciju statusa mobilnog broja, možete uneti mobilni broj za proveru.

## Proces prijave

Da biste koristili API za proveru statusa mobilnog broja, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, koji čuvate za kasnije.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozvati sve usluge platforme, nije potrebno posebno se prijavljivati za svaku uslugu.** Prvi put kada se prijavite dobićete besplatnu kvotu, možete besplatno isprobati; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Puna dokumentacija: [API za proveru statusa mobilnog broja →](https://platform.acedata.cloud/documents/identity-phone-check-1e)

## Osnovna upotreba

Prvo se upoznajte sa osnovnim načinom korišćenja, to jest, unosom mobilnog broja, možete dobiti obrađeni rezultat, prvo je potrebno jednostavno proslediti polje `mobile`. Zatim možemo popuniti odgovarajući sadržaj na interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/r17llo.png" width="500" className="m-auto" /></p>

Možete videti da smo ovde postavili Request Headers, uključujući:

- `accept`: kakav format odgovora želite da primite, ovde je uneto `application/json`, tj. JSON format.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete direktno izabrati sa padajuće liste.

Takođe je postavljen Request Body, uključujući:

- `mobile`: mobilni broj koji treba obraditi, obavezno polje.
- `encryption`: opcionalno, parametar za enkripciju osetljivih polja (ako je potrebno poslati šifrovani tekst).

Nakon izbora, možete primetiti da je sa desne strane generisan odgovarajući kod, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/dpun55.png" width="500" className="m-auto" /></p>

Kliknite na dugme „Try“ da biste izvršili test, kao što je prikazano na gornjoj slici, ovde smo dobili sledeći rezultat:

```json
{
  "result": "0",
  "description": "Uspešno",
  "status_code": 0
}
```

Vraćeni rezultat ima više polja, opisana kao:

- `result`, kod rezultata verifikacije, naplata je sledeća.
    - Kodovi rezultata naplate:
        - 0: Uspešno
    - Kodovi rezultata bez naplate:
        - -1: Nema rezultata
        - -2: Neispravan format mobilnog broja
        - -3: Usluga verifikacionog centra je zauzeta
- `description`, opis poslovnog rezultata.
- `status_code`, kod statusa:
    - 0: Normalno
    - 1: Isključen
    - 2: Otkazan broj
    - 3: Prazan broj
    - 4: Nije u mreži
    - 99: Nepoznat status

Može se primetiti da je status ovog mobilnog broja već proveren.

Takođe, ako želite da generišete odgovarajući kod za integraciju, možete ga direktno kopirati, na primer, CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/identity/phone/check-1e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "mobile": "***"
}'
```

Python kod za integraciju je sledeći:

```python
import requests

url = "https://api.acedata.cloud/identity/phone/check-1e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "mobile": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili neispravnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili neispravnih parametara.
- `401 invalid_token`: Neautorizovano, neispravan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
