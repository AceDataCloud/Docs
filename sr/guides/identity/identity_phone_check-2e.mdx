Ovaj dokument će predstaviti API za verifikaciju dva faktora mobilnog broja, koji se može koristiti za proveru autentičnosti i usklađenosti mobilnog broja i imena.

## Proces prijave

Da biste koristili API za verifikaciju dva faktora mobilnog broja, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, koji čuvate za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozvati sve usluge platforme, bez potrebe da se za svaku uslugu posebno prijavljujete.** Prilikom prve prijave dobijate besplatnu kvotu, koju možete besplatno isprobati; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Puna dokumentacija: [API za verifikaciju dva faktora mobilnog broja →](https://platform.acedata.cloud/documents/identity-phone-check-2e)

## Osnovna upotreba

Prvo se upoznajte sa osnovnim načinom korišćenja, što podrazumeva unos mobilnog broja kako biste dobili obrađeni rezultat, a prvo je potrebno jednostavno proslediti polje `mobile`. Zatim možemo popuniti odgovarajući sadržaj na interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/v6k96j.png" width="500" className="m-auto" /></p>

Možete videti da smo ovde postavili Request Headers, uključujući:

- `accept`: format odgovora koji želite da primite, ovde je uneto `application/json`, što znači JSON format.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

Takođe smo postavili Request Body, uključujući:

- `name`: ime korisnika koje treba obraditi, obavezno polje.
- `mobile`: mobilni broj koji treba obraditi, obavezno polje.
- `encryption`: opcionalno, parametar za enkripciju osetljivih podataka (ako je potrebno poslati šifrovani tekst).

Nakon izbora, možete primetiti da je sa desne strane generisan odgovarajući kod, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/lq800o.png" width="500" className="m-auto" /></p>

Klikom na dugme „Try“ možete izvršiti testiranje, kao što je prikazano na gornjoj slici, ovde smo dobili sledeći rezultat:

```json
{
  "result": "0",
  "description": "Verifikacija rezultata je usklađena"
}
```

Vraćeni rezultat ima više polja, koja su opisana u nastavku:

- `result`, kod rezultata verifikacije, troškovi su sledeći.
    - Kodovi rezultata sa troškovima:
        - 0: Verifikacija rezultata je usklađena
        - 1: Verifikacija rezultata nije usklađena
    - Kodovi rezultata bez troškova:
        - -1: Nema podataka
        - -2: Nepoznata greška u motoru
        - -3: Abnormalna usluga motora
        - -4: Verifikacija imena nije prošla
        - -5: Mobilni broj nije validan
        - -6: Broj verifikacija premašuje dnevno ograničenje, molimo pokušajte ponovo sutra
- `description`, opis poslovnog rezultata.

Može se primetiti da su autentičnost i usklađenost mobilnog broja i imena već provereni.

Takođe, ako želite da generišete odgovarajući kod za integraciju, možete ga direktno kopirati, na primer, CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/identity/phone/check-2e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "***",
  "mobile": "***"
}'
```

Python kod za integraciju je sledeći:

```python
import requests

url = "https://api.acedata.cloud/identity/phone/check-2e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "***",
    "mobile": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### Primer greške u odgovoru

```json
}
```
