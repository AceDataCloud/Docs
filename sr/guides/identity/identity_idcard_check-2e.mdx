Овај документ ће представити упутство за интеграцију API за проверу идентификационих информација и важења, који се може користити за проверу истинитости и доследности имена, броја личне карте и периода важења личне карте.

## Процес пријаве

Да бисте користили API за проверу идентификационих информација и важења, прво идите на [Ace Data Cloud контролни панел](https://platform.acedata.cloud/console/applications) да бисте добили ваш API токен, који ћете задржати за каснију употребу.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након тога ћете бити аутоматски враћени на тренутну страницу.

**Један API токен може да позове све услуге платформе, без потребе да се за сваку услугу посебно пријављујете.** При првом захтеву добијате бесплатан кредит, који можете бесплатно испробати; када вам кредит буде недовољан, можете допунити општи баланс на [контролном панелу](https://platform.acedata.cloud/console/coin).

> 📘 Пуна документација: [API за проверу идентификационих информација и важења →](https://platform.acedata.cloud/documents/identity-idcard-check-2e)

## Основна употреба

Прво, упознајте се са основним начином коришћења, а то је унос линка до слике личне карте, након чега можете добити обрађене резултате верификације. Прво је потребно једноставно проследити поље `name`, а затим можемо унети одговарајуће садржаје на интерфејсу, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/llvy1l.png" width="500" className="m-auto" /></p>

Можете видети да смо овде подесили заглавља захтева, укључујући:

- `accept`: у ком формату желите да примите одговор, овде је написано `application/json`, што значи JSON формат.
- `authorization`: кључ за позивање API, који можете директно изабрати након пријаве.

Такође смо подесили тело захтева, укључујући:

- `name`: име.
- `id_card`: број личне карте.
- `image_url`: линк до слике лица која треба да се обради.
- `validity_end`: датум истека важења личне карте, формат: YYYYMMDD, за дугорочно користите "00000000";
- `validity_begin`: датум почетка важења личне карте, формат: YYYYMMDD.
- `encryption`: опционално, параметар за шифровање осетљивих података (ако је потребно послати шифроване податке).

Након избора, можете приметити да је на десној страни генерисан одговарајући код, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/l77q0u.png" width="500" className="m-auto" /></p>

Кликните на дугме „Пробај“ да бисте извршили тест, као што је приказано на горњој слици, и добили смо следећи резултат:

```json
{
  "result": "0",
  "description": "Доследно"
}
```

Враћени резултат има више поља, а описује се као:

- `result`, код резултата верификације, наплата је следећа.
    - Кодови наплате:
        - 0: Име и број личне карте се слажу
        - -1: Име и број личне карте се не слажу
    - Кодови без наплате:
        - -2: Неправилан број личне карте (дужина, контролна цифра итд. нису исправни)
        - -3: Неправилно име (дужина, формат итд. нису исправни)
        - -4: Аномалија у служби базе докумената
        - -5: У бази докумената нема записа о овој личној карти
        - -6: Ауторитетни систем за упоређивање се надограђује, покушајте поново касније
        - -7: Број верификација је прешао дневно ограничење.
- `description`, резултат верификације имена и броја личне карте.

Можете видети да име, број личне карте и период важења у личној карти имају истинитост и доследност.

Ако желите да генеришете одговарајући код за интеграцију, можете га директно копирати, на пример, CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/identity/idcard/check-2e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "***",
  "id_card": "***",
  "validity_begin": "***",
  "validity_end": "***"
}'
```

Python код за интеграцију је следећи:

```python
import requests

url = "https://api.acedata.cloud/identity/idcard/check-2e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "***",
    "id_card": "***",
    "validity_begin": "***",
    "validity_end": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Обрада грешака

Када позивате API, ако наиђете на грешку, API ће вратити одговарајући код грешке и информације. На пример:

- `400 token_mismatched`: Лош захтев, могуће због недостајућих или неважећих параметара.
- `400 api_not_implemented`: Лош захтев, могуће због недостајућих или неважећих параметара.
- `401 invalid_token`: Неправилно, неважећи или недостајући ауторизациони токен.
- `429 too_many_requests`: Превише захтева, прешли сте лимит.
- `500 api_error`: Унутрашња грешка сервера, нешто није у реду на серверу.

### Пример одговора на грешку

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "подаци нису могли да се преузму"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
