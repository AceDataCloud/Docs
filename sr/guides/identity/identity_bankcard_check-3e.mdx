Овај документ ће представити упутство за интеграцију API за проверу три елемента банковне картице, који се може користити за верификацију истинитости и доследности информација о броју банковне картице, имену и броју идентификационог документа.

## Процес пријаве

Да бисте користили API, прво морате да одете на страницу [API за проверу три елемента банковне картице](https://platform.acedata.cloud/documents/eb9c6677-68db-4549-a207-41f8a1084634) и затражите одговарајућу услугу. Када уђете на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите. Након пријаве или регистрације, аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, коју можете користити за API.

## Основна употреба

Прво, упознајте се са основним начином коришћења, а то је уношење информација о броју банковне картице, након чега ћете добити обрађену слику резултата. Прво је потребно једноставно проследити поље `bank_card`. Након тога можемо попунити одговарајуће садржаје на интерфејсу, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/3kh6i2.png" width="500" className="m-auto" /></p>

Можете видети да смо овде подесили Request Headers, укључујући:

- `accept`: у каквом формату желите да примите одговор, овде је написано `application/json`, што значи JSON формат.
- `authorization`: кључ за позивање API, након захтева можете директно изабрати из падајућег менија.

Такође смо подесили Request Body, укључујући:

- `bank_card`: информације о броју банковне картице, обавезан параметар.
- `id_card`: број идентификационог документа, обавезан параметар.
- `name`: име корисника, обавезан параметар.
- `cert_type`: тип идентификационог документа, мора бити у складу са идентификационим документом, у противном неће бити могућа верификација.
- `encryption`: опционално, параметар за шифровање осетљивих поља (ако је потребно послати шифровани текст).

Након избора, можете приметити да је на десној страни генерисан одговарајући код, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/cpvguu.png" width="500" className="m-auto" /></p>

Кликните на дугме „Try“ да бисте извршили тест, као што је приказано на горњој слици, и добили смо следећи резултат:

```json
{
  "result": "0",
  "description": "Аутентификација успешна"
}
```

Враћени резултат има више поља, описаних у наставку:

- `result`, код резултата аутентификације, накнаде су следеће.
  - Кодови резултата накнаде:
    - 0: Аутентификација успешна
    - -1: Аутентификација није успела
    - -4: Информације о власнику картице су нетачне
    - -5: Нема могућности плаћања без картице
    - -6: Ова картица је одузета
    - -7: Неважећи број картице
    - -8: Ова картица нема одговарајућу издавачку банку
    - -9: Ова картица није иницијализована или је спавала
    - -10: Картица за превару, задржана картица
    - -11: Ова картица је пријављена као изгубљена
    - -12: Ова картица је истекла
    - -13: Ограничена картица
    - -14: Прекорачен број покушаја уноса лозинке
    - -15: Издавачка банка не подржава ову трансакцију
  - Кодови резултата без накнаде:
    - -2: Провера имена није успела
    - -3: Број банковне картице је нетачан
    - -16: Услуга верификационог центра је заузета
    - -17: Прекорачен број верификација, покушајте поново сутра
- `description`, опис пословног резултата.

Може се видети да су информације о броју банковне картице, имену и броју идентификационог документа прошле проверу истинитости и доследности.

Ако желите да генеришете одговарајући код за интеграцију, можете га директно копирати, на пример, CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/identity/bankcard/check-3e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "***",
  "bank_card": "***",
  "id_card": "***"
}'
```

Python код за интеграцију је следећи:

```python
import requests

url = "https://api.acedata.cloud/identity/bankcard/check-3e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "***",
    "bank_card": "***",
    "id_card": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Обрада грешака

Када позивате API, ако наиђете на грешку, API ће вратити одговарајући код грешке и информације. На пример:

- `400 token_mismatched`: Лош захтев, могуће због недостајућих или неважећих параметара.
- `400 api_not_implemented`: Лош захтев, могуће због недостајућих или неважећих параметара.
- `401 invalid_token`: Неправилно, неважећи или недостајући ауторизациони токен.
- `429 too_many_requests`: Превише захтева, превазишли сте лимит.
- `500 api_error`: Унутрашња грешка сервера, нешто није у реду на серверу.

### Пример одговора на грешку

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "подаци нису могли бити преузети"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
