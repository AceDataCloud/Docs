Ovaj dokument će predstaviti API za pretragu osnovnih informacija o bankovnim karticama, koji se može koristiti za pretragu osnovnih informacija o bankovnim karticama.

## Proces prijave

Da biste koristili API, prvo idite na [API za pretragu osnovnih informacija o bankovnim karticama](https://platform.acedata.cloud/documents/3523988d-acba-4362-9def-105657991eb4) i zatražite odgovarajuću uslugu. Kada uđete na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite. Nakon prijave ili registracije, automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatni kredit koji možete koristiti za ovaj API.

## Osnovna upotreba

Prvo, potrebno je razumeti osnovni način korišćenja, što podrazumeva unos broja bankovne kartice kako biste dobili obrađene rezultate verifikacije. Prvo je potrebno jednostavno proslediti polje `bank_card`, a zatim možemo uneti odgovarajući sadržaj na interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/h41nrh.png" width="500" className="m-auto" /></p>

Možete videti da smo ovde postavili Request Headers, uključujući:

- `accept`: format odgovora koji želite da primite, ovde je uneto `application/json`, što znači JSON format.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

Takođe smo postavili Request Body, uključujući:

- `bank_card`: broj bankovne kartice.
- `encryption`: opcionalno, parametar za enkripciju osetljivih podataka (ako je potrebno poslati šifrovane podatke).

Nakon izbora, možete primetiti da je sa desne strane generisan odgovarajući kod, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/grfra7.png" width="500" className="m-auto" /></p>

Kliknite na dugme „Try“ da biste izvršili testiranje, kao što je prikazano na gornjoj slici, ovde smo dobili sledeći rezultat:

```json
{
  "result": "0",
  "description": "查询成功",
  "account_bank": "工商银行",
  "account_type": 1
}
```

Vraćeni rezultati sadrže više polja, koja su opisana kao:

- `result`, kod rezultata verifikacije, naplata je sledeća.
  - Kodovi rezultata naplate:
    - 0: Pretraga uspešna
    - -1: Nema pronađenih informacija
  - Kodovi bez naplate:
    - -2: Servis verifikacionog centra je zauzet
    - -3: Bankovna kartica ne postoji
- `description`, opis poslovnog rezultata.
- `account_bank`, banka u kojoj je otvoren račun.
- `account_type`, vrsta kartice: 1. Debitna kartica; 2. Kreditna kartica; 3. Predplaćena kartica; 4. Kartica sa odobrenim kreditom.

Može se primetiti da su osnovne informacije o bankovnoj kartici već pretražene.

Takođe, ako želite da generišete odgovarajući kod za integraciju, možete ga direktno kopirati, na primer, CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/identity/bankcard/check-1e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "bank_card": "****"
}'
```

Python kod za integraciju je sledeći:

```python
import requests

url = "https://api.acedata.cloud/identity/bankcard/check-1e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "bank_card": "****"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
