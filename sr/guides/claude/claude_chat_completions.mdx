Anthropic Claude je veoma moćan AI sistem za razgovor, koji može generisati tečne i prirodne odgovore za samo nekoliko sekundi nakon unosa prompta. Claude se izdvaja u industriji svojim izuzetnim sposobnostima razumevanja i generisanja jezika. Danas je Claude već široko primenjen u različitim industrijama i oblastima, a njegov uticaj postaje sve značajniji. Bilo da se radi o svakodnevnim razgovorima, kreativnom pisanju, profesionalnim konsultacijama ili programiranju koda, Claude može pružiti zadivljujuću inteligentnu pomoć, značajno povećavajući radnu efikasnost i kreativnost ljudi.

Ovaj dokument uglavnom predstavlja proces korišćenja Claude Chat Completion API operacija, uz pomoć kojeg možemo lako koristiti zvaničnu Claude funkciju za razgovor.

## Claude Fable 5.2

Koristite puni naziv modela `claude-fable-5-2`. Ovaj model je pogodan za složeno rezonovanje i dugoročne zadatke; kada su potrebni izvorni blokovi sadržaja za razmišljanje i interakcija sa alatima, prednost dajte Messages API-ju. Adaptivno razmišljanje je stalno uključeno, izostavite `temperature`, `top_p`, `top_k`, za izbor alata koristite `auto`, nemojte prisilno određivati alat. `max_tokens` istovremeno pokriva razmišljanje i konačni tekst. Trenutno nisu dostupni Responses i Count Tokens interfejsi za ovaj model.

Preračunato prema trenutnom najvećem paketu (142,800 Credits／$13,584), za Fable 5.2 običan ulaz iznosi $3.20, a izlaz $16／milion tokena; čitanje iz keša iznosi $0.08, dok upis u keš od 5 minuta／1 sata iznosi $4／$6.40／milion tokena. Navedene cene su 40% zvaničnih standardnih API jediničnih cena (60% jeftinije); za ostale pakete i dodatne popuste na nalogu, pogledajte stranicu sa cenama modela i obračun.

## Osnovno korišćenje

Zatim možete popuniti odgovarajući sadržaj u interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/ejeq57.png" width="400" className="m-auto" /></p>

Pri prvom korišćenju ovog interfejsa, potrebno je da popunimo najmanje tri stavke. Jedna je `authorization`, koju možete direktno izabrati sa padajuće liste. Drugi parametar je `model`, gde možete izabrati javno dostupne modele kao što su `claude-opus-5-5`, `claude-fable-5-1` itd.; originalni `claude-fable-5` se i dalje može pozivati. Poslednji parametar je `messages`, to je niz upita, pri čemu svaki element sadrži `role` i `content`; `role` podržava `user`, `assistant`, `system`, a `content` je konkretan sadržaj. Kada su potrebni kompletni Claude blokovi sadržaja za razmišljanje, potpisi i izvorna semantika alata, i dalje koristite Messages API.

Istovremeno možete primetiti da se sa desne strane generiše odgovarajući pozivni kod, možete kopirati kod i direktno ga pokrenuti, ili direktno kliknuti na dugme „Try“ radi testiranja.

Često korišćeni opcioni parametri:

- `max_tokens`: ograničava maksimalan broj tokena u jednom odgovoru.
- `temperature`: nasumičnost generisanja, između 0 i 2, što je vrednost veća, rezultat je raspršeniji.
- `n`: koliko kandidata za odgovor se generiše odjednom.
- `response_format`: podešavanje formata povratne vrednosti.

`claude-opus-5-5` podržava obične i strimovane Chat Completions; ovaj model dozvoljava samo `n=1`. Nemojte za njega postavljati `temperature` manji od 1 niti `top_p` koji nije podrazumevan, za pozivanje alata koristite `tool_choice: "auto"`, nemojte prisilno određivati alat. Chat kompatibilni interfejs neće vratiti izvorne blokove sadržaja za razmišljanje.

<p><img src="https://cdn.acedata.cloud/v6lbjo.png" width="400" className="m-auto" /></p>

Povratni rezultat ima više polja, koja su predstavljena u nastavku:

- `id`, ID generisanog zadatka razgovora, koji se koristi za jedinstvenu identifikaciju ovog zadatka razgovora.
- `model `, izabrani Claude model sa zvaničnog sajta.
- `choices`, informacije o odgovoru koji Claude daje na upit.
- `usage `: statističke informacije o tokenima za ovaj par pitanja i odgovora.

U Chat Completions formatu, `usage.prompt_tokens` je ukupan ulaz; `prompt_tokens_details.cached_tokens` i `prompt_tokens_details.cache_write_tokens` redom beleže detalje čitanja i upisa u keš. `completion_tokens_details.reasoning_tokens` je podskup `completion_tokens`, nemojte ga ponovo sabirati pri izračunavanju ukupne količine ili troška. Nestrimovani odgovori takođe mogu vratiti objekat `usage.cost`, gde je `amount` stvarno utrošeni kredit, `currency` merna jedinica, a `list_amount` iznos pre popusta (ako postoji).

Naziv polja za Chat-compatible je `reasoning_tokens`; izvorni Messages API koristi `output_tokens_details.thinking_tokens`. Wire schema ova dva protokola se razlikuje, klijent ne bi trebalo da meša nazive polja.

Među njima, `choices` sadrži Claude informacije o odgovoru, a `choices` unutar njega su konkretne informacije o Claude odgovoru, kao što se može videti na slici.

<p><img src="https://cdn.acedata.cloud/2ulyhw.png" width="400" className="m-auto" /></p>

Može se videti da polje `content` unutar `choices` sadrži konkretan sadržaj Claude odgovora.

## Strimovani odgovor

Ovaj interfejs takođe podržava strimovane odgovore, što je veoma korisno za povezivanje sa veb-stranicama i omogućava efekat prikazivanja slovo po slovo na stranici.

Ako želite da odgovor vraćate strimovano, možete izmeniti parametar `stream ` u zaglavlju zahteva na `true`.

Izmena je prikazana na slici, ali pozivni kod mora imati odgovarajuće izmene kako bi podržavao strimovane odgovore.

<p><img src="https://cdn.acedata.cloud/ueugot.png" width="400" className="m-auto" /></p>
Nakon izmene `stream` na `true`, API će vraćati odgovarajuće JSON podatke red po red, a na nivou koda potrebno je da izvršimo odgovarajuće izmene kako bismo dobili rezultate red po red.

Primer Python koda za pozivanje:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "claude-opus-4-20250514",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Duboko razmišljanje

Nova generacija Claude modela može zaključivati prema podrazumevanoj strategiji modela, bez potrebe za aktiviranjem putem sufiksa modela `-thinking`. Chat-compatible odgovori koriste OpenAI kompatibilno usage polje `completion_tokens_details.reasoning_tokens`. `reasoning_tokens` je već uključen u `completion_tokens`, nemojte ih sabirati duplo. Zaključivanje i vidljivi glavni tekst dele ograničenje izlaznih tokena, stoga se pri malom `max_tokens` može pojaviti prazan ili skraćen glavni tekst; u tom slučaju povećajte izlazni budžet ili, kada korišćeni model to podržava, izaberite manji intenzitet zaključivanja.

Ako su vam potrebni izvorni `thinking`, `output_config.effort`, thinking sadržajni blokovi i povrat potpisa, koristite `/v1/messages`. Usage polje za Messages je `output_tokens_details.thinking_tokens`, nemojte ga mešati sa `completion_tokens_details.reasoning_tokens` iz Chat-compatible interfejsa.

## Vizuelni model

claude-sonnet-4-20250514 je multimodalni veliki jezički model koji je razvio Claude, on na osnovu claude-4 dodaje mogućnost vizuelnog razumevanja. Ovaj model može istovremeno obrađivati tekstualne i slikovne unose, ostvarujući razumevanje i generisanje između modaliteta.

Obrada teksta korišćenjem modela claude-sonnet-4-20250514 ista je kao sadržaj osnovne upotrebe iznad, u nastavku će biti ukratko predstavljeno kako koristiti mogućnost obrade slika modela.

Mogućnost obrade slika modela claude-sonnet-4-20250514 uglavnom se koristi dodavanjem polja `type` na osnovu originalnog sadržaja `content`, preko ovog polja se može znati da li se otprema tekst ili slika, čime se koristi mogućnost obrade slika modela claude-sonnet-4-20250514, u nastavku se uglavnom opisuje pozivanje ove funkcije na dva načina, pomoću Curl i Python-a.

- Curl skriptni način

```
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "claude-sonnet-4-20250514",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://cdn.acedata.cloud/ueugot.png"
            }
          }
        ]
      }
    ]
  }'
```

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neovlašćeno, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste ograničenje broja zahteva.
- `500 api_error`: Interna greška servera, nešto je pošlo po zlu na serveru.
