Anthropic Claude је веома моћан AI систем за разговор, који може генерисати текуће и природне одговоре у року од неколико секунди само уношењем упитника. Claude се истиче у индустрији својом изванредном способношћу разумевања и генерисања језика, а данас је већ широко примењен у различитим индустријама и областима, а његов утицај постаје све значајнији. Без обзира на то да ли је у питању свакодневни разговор, креативно писање или стручне консултације и програмирање, Claude може пружити импресивну интелигентну помоћ, значајно повећавајући људску продуктивност и креативност.

Овај документ углавном описује процес коришћења Claude Chat Completion API, који нам омогућава да лако користимо званичне функције разговора Claude.

## Процес пријаве

Да бисте користили Claude Chat Completion API, прво можете отићи на [Claude Chat Completion API](https://platform.acedata.cloud/documents/280928a2-2dce-419c-adb5-1ea835e8183a) страницу и кликнути на дугме „Acquire“ да бисте добили акредитиве потребне за захтев:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након пријаве или регистрације аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, што вам омогућава да бесплатно користите овај API.

## Основна употреба

Након тога можете попунити одговарајуће садржаје на интерфејсу, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/ejeq57.png" width="400" class="m-auto"></p>

Када први пут користите овај интерфејс, потребно је да попуните најмање три садржаја, један је `authorization`, који можете директно изабрати из падајућег менија. Други параметар је `model`, `model` је категорија модела коју одаберете на званичној страници Claude, овде имамо 20 различитих модела, детаље можете видети у моделима које пружамо. Последњи параметар је `messages`, `messages` је низ упитника који уносимо, представља низ који може истовремено да пошаље више упитника, сваки упитник садржи `role` и `content`, где `role` представља улогу питаоца, а ми пружамо три идентификације: `user`, `assistant`, `system`. Други `content` је конкретан садржај нашег питања.

Такође можете приметити да се на десној страни генерише одговарајући код за позив, можете копирати код и директно га покренути, или можете директно кликнути на дугме „Try“ за тестирање.

Често коришћени опционални параметри:

- `max_tokens`: ограничава максималан број токена у једном одговору.
- `temperature`: генерише случајност, између 0-2, већа вредност значи веће распршивање.
- `n`: колико кандидата одговора генерисати одједном.
- `response_format`: подешавање формата повратка.

## Стриминг одговора

Овај интерфејс такође подржава стриминг одговора, што је веома корисно за веб интеграцију, јер омогућава веб страници да реализује ефекат приказивања по словима.

Ако желите да добијете одговор у стриминг формату, можете променити параметар `stream` у заглављу захтева на `true`.

Измените као што је приказано на слици, али код позива мора бити одговарајуће изменен да би подржао стриминг одговор.

<p><img src="https://cdn.acedata.cloud/ueugot.png" width="400" class="m-auto"></p>

Након што промените `stream` на `true`, API ће враћати одговарајуће JSON податке ред по ред. На нивоу кода, потребно је направити одговарајуће измене да бисте добили редне резултате.

Python пример кода за позив:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "claude-opus-4-20250514",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Možete videti da u odgovoru ima mnogo `data`, a `data` unutar `choices` predstavlja najnoviji odgovor, u skladu sa prethodno navedenim sadržajem. `choices` su novi odgovori koje možete povezati sa vašim sistemom. Vraćeni `data` rezultati imaju više polja, a opisi su sledeći:

- `choices`, informacije o odgovorima koje je Claude dao na postavljena pitanja.

JavaScript takođe podržava, na primer, kod za strimovano pozivanje u Node.js je sledeći:

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "claude-opus-4-20250514",
    messages: [{ role: "user", content: "Zdravo" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/v1/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

JSONObject jsonObject = new JSONObject();

## Vizuelni model

claude-sonnet-4-20250514 je multimodalni veliki jezički model koji je razvio Claude, a koji je na osnovu claude-4 modela dobio sposobnost vizuelnog razumevanja. Ovaj model može istovremeno obraditi tekstualne i slikovne ulaze, omogućavajući međumodalno razumevanje i generisanje.

Obrada teksta pomoću claude-sonnet-4-20250514 modela je u skladu sa osnovnom upotrebom opisanom ranije, a u nastavku će biti ukratko objašnjeno kako koristiti sposobnosti obrade slika modela.

Obrada slika pomoću claude-sonnet-4-20250514 modela se uglavnom vrši dodavanjem `type` polja u osnovni `content`, putem kojeg se može saznati da li je učitan tekst ili slika, čime se koristi sposobnost obrade slika modela claude-sonnet-4-20250514. U nastavku će biti opisane dve metode za pozivanje ove funkcionalnosti, koristeći Curl i Python.

- Curl skripta

```
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "claude-sonnet-4-20250514",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "Šta je na ovoj slici?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://cdn.acedata.cloud/ueugot.png"
            }
          }
        ]
      }
    ]
  }'
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
