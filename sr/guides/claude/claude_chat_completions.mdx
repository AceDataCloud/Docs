Anthropic Claude je veoma moćan AI sistem za razgovor, koji može da generiše tečne i prirodne odgovore za samo nekoliko sekundi čim se unesu prompt reči. Claude se izdvaja u industriji svojim izuzetnim sposobnostima razumevanja i generisanja jezika, a danas je već široko primenjen u različitim industrijama i oblastima, pri čemu njegov uticaj postaje sve značajniji. Bilo da se radi o svakodnevnim razgovorima, kreativnom pisanju, profesionalnim konsultacijama ili programiranju koda, Claude može da pruži zapanjujuću inteligentnu pomoć, značajno povećavajući radnu efikasnost i kreativnost ljudi.

Ovaj dokument uglavnom predstavlja proces korišćenja Claude Chat Completion API operacija, pomoću kojeg možemo lako koristiti funkciju razgovora zvaničnog Claude-a.

## Proces prijave

Da biste koristili Claude Chat Completion API, prvo preuzmite svoj API Token na [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications) i sačuvajte ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, bićete automatski preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a nakon završetka automatski ćete se vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe za posebnom prijavom za svaku uslugu.** Prilikom prve prijave dobijate besplatan iznos kredita za besplatno isprobavanje; kada iznos kredita nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Claude Chat Completion API →](https://platform.acedata.cloud/documents/claude-chat-completions)

## Osnovno korišćenje

Zatim možete popuniti odgovarajući sadržaj u interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/ejeq57.png" width="400" className="m-auto" /></p>

Prilikom prvog korišćenja ovog interfejsa, potrebno je da popunimo najmanje tri stavke, jedna je `authorization`, koju možete direktno izabrati na padajućoj listi. Drugi parametar je `model`, a mogu se izabrati javni modeli kao što su `claude-opus-5-5`, `claude-fable-5-1` i drugi; originalni `claude-fable-5` se i dalje može pozivati. Poslednji parametar je `messages`, to je niz upitnih reči, a svaki element sadrži `role` i `content`; `role` podržava `user`, `assistant`, `system`, dok je `content` konkretan sadržaj. Kada su potrebni kompletni Claude blokovi sadržaja razmišljanja, potpisi i semantika izvornih alata, i dalje koristite Messages API.

Istovremeno možete primetiti da se sa desne strane generiše odgovarajući kod poziva, možete kopirati kod i direktno ga pokrenuti, a možete i direktno kliknuti na dugme „Try“ radi testiranja.

Često korišćeni opcioni parametri:

- `max_tokens`: ograničava maksimalan broj tokena jednog odgovora.
- `temperature`: nasumičnost generisanja, između 0 i 2, što je vrednost veća, to je rezultat divergentniji.
- `n`: koliko kandidatnih odgovora se generiše odjednom.
- `response_format`: podešavanje formata povratne vrednosti.

`claude-opus-5-5` podržava obične i strimovane Chat Completions; ovaj model dozvoljava samo `n=1`. Nemojte za njega postavljati `temperature` manji od 1 niti `top_p` koji nije podrazumevan, za pozivanje alata koristite `tool_choice: "auto"`, nemojte prisilno navoditi alat. Chat kompatibilni interfejs ne vraća izvorne blokove sadržaja razmišljanja.

<p><img src="https://cdn.acedata.cloud/v6lbjo.png" width="400" className="m-auto" /></p>

Nakon poziva, vidimo da je rezultat povratne vrednosti sledeći:


Rezultat povratne vrednosti ima više polja, koja su predstavljena u nastavku:

- `id`, ID generisanog zadatka ovog razgovora, koristi se za jedinstvenu identifikaciju ovog zadatka razgovora.
- `model `, izabrani model sa zvaničnog Claude sajta.
- `choices`, informacije o odgovorima koje Claude daje na upitne reči.
- `usage `: statističke informacije o tokenima za ovaj razgovor pitanja i odgovora.

U Chat Completions formatu, `usage.prompt_tokens` je ukupan unos; `prompt_tokens_details.cached_tokens` i `prompt_tokens_details.cache_write_tokens` redom beleže detalje čitanja i upisivanja keša. `completion_tokens_details.reasoning_tokens` je podskup `completion_tokens`, nemojte ga ponovo sabirati prilikom izračunavanja ukupnog broja ili troškova. Nestrimovani odgovori takođe mogu vratiti objekat `usage.cost`, gde je `amount` stvarna potrošnja kredita, `currency` je merna jedinica, a `list_amount` je iznos pre popusta (ako postoji).

Naziv polja za Chat-compatible je `reasoning_tokens`; izvorni Messages API koristi `output_tokens_details.thinking_tokens`. Wire schema za dva protokola je različita i klijent ne bi trebalo da meša nazive polja.

Među njima, `choices` sadrži Claude informacije o odgovorima, a `choices` unutar njega su konkretne informacije Claude odgovora, što se može videti kao na slici.

<p><img src="https://cdn.acedata.cloud/2ulyhw.png" width="400" className="m-auto" /></p>

Može se videti da polje `content` unutar `choices` sadrži konkretan sadržaj Claude odgovora.

## Strimovani odgovor

Ovaj interfejs takođe podržava strimovane odgovore, što je veoma korisno za povezivanje sa veb-stranicama i može omogućiti veb-stranici efekat prikazivanja znak po znak.

Ako želite da odgovore vraćate strimovano, možete izmeniti parametar `stream ` u zaglavlju zahteva na `true`.

Izmena je prikazana na slici, ali kod poziva mora imati odgovarajuće izmene kako bi podržavao strimovane odgovore.

<p><img src="https://cdn.acedata.cloud/ueugot.png" width="400" className="m-auto" /></p>

Nakon izmene `stream` na `true`, API će vraćati odgovarajuće JSON podatke red po red, a na nivou koda potrebno je da napravimo odgovarajuće izmene kako bismo dobili rezultate red po red.

Primer Python koda za poziv:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "claude-opus-4-20250514",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```javascript
  .catch((err) => console.error(err));
```

## Duboko razmišljanje
Nova generacija Claude modela može da rezonuje prema podrazumevanoj strategiji modela, bez potrebe za aktiviranjem putem sufiksa modela `-thinking`. Chat-compatible odgovori koriste OpenAI kompatibilno usage polje `completion_tokens_details.reasoning_tokens`. `reasoning_tokens` je već uključen u `completion_tokens`, nemojte ih sabirati duplo. Rezonovanje i vidljivi glavni tekst dele gornju granicu izlaznih tokena, pa se pri manjem `max_tokens` može pojaviti prazan ili skraćen glavni tekst; u tom slučaju povećajte izlazni budžet ili, kada korišćeni model to podržava, izaberite manji intenzitet rezonovanja.

Ako su vam potrebni nativni `thinking`, `output_config.effort`, thinking blokovi sadržaja i povrat potpisa, koristite `/v1/messages`. Odgovarajuće usage polje za Messages je `output_tokens_details.thinking_tokens`; nemojte ga mešati sa Chat-compatible poljem `completion_tokens_details.reasoning_tokens`.

## Vizuelni modeli

claude-sonnet-4-20250514 je multimodalni veliki jezički model koji je razvio Claude, koji na osnovu claude-4 dodaje mogućnost vizuelnog razumevanja. Ovaj model može istovremeno da obrađuje tekstualne i slikovne ulaze, ostvarujući razumevanje i generisanje između modaliteta.

Obrada teksta korišćenjem modela claude-sonnet-4-20250514 je u skladu sa osnovnim sadržajem korišćenja iznad, a u nastavku ćemo ukratko predstaviti kako koristiti mogućnost obrade slika ovog modela.

Mogućnost obrade slika modela claude-sonnet-4-20250514 uglavnom se koristi dodavanjem polja `type` na osnovu originalnog sadržaja `content`; kroz ovo polje može se saznati da li se otprema tekst ili slika, čime se koristi mogućnost obrade slika modela claude-sonnet-4-20250514. U nastavku se uglavnom opisuje pozivanje ove funkcije na dva načina, putem Curl-a i Python-a.

- Metod Curl skripte

```

-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "claude-sonnet-4-20250514",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://cdn.acedata.cloud/ueugot.png"

      }

  }'
```

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neovlašćeno, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste ograničenje stope.
- `500 api_error`: Interna greška servera, nešto je pošlo po zlu na serveru.
