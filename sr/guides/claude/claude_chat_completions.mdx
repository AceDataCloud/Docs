Anthropic Claude je veoma moćan AI sistem za razgovor, koji može generisati tečne i prirodne odgovore za samo nekoliko sekundi nakon unosa prompta. Claude se izdvaja u industriji svojim izvanrednim sposobnostima razumevanja i generisanja jezika; danas se Claude već široko koristi u raznim industrijama i oblastima, a njegov uticaj postaje sve značajniji. Bilo da je reč o svakodnevnim razgovorima, kreativnom pisanju, profesionalnim konsultacijama ili programiranju koda, Claude može pružiti zadivljujuću inteligentnu pomoć, u velikoj meri povećavajući radnu efikasnost i kreativnost ljudi.

Ovaj dokument uglavnom predstavlja proces korišćenja Claude Chat Completion API operacija, uz pomoć kojeg možemo lako koristiti funkciju razgovora zvaničnog Claude-a.

## Proces prijave

Da biste koristili Claude Chat Completion API, najpre idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications) da biste dobili svoj API Token i sačuvali ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a nakon završetka automatski ćete se vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe za zasebnom prijavom za svaku uslugu.** Prilikom prve prijave dobijate besplatan kredit za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti univerzalni saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Claude Chat Completion API →](https://platform.acedata.cloud/documents/claude-chat-completions)

## Osnovno korišćenje

Zatim možete popuniti odgovarajući sadržaj u interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/ejeq57.png" width="400" className="m-auto" /></p>

Prilikom prvog korišćenja ovog interfejsa, potrebno je da popunimo najmanje tri stavke, jedna je `authorization`, koju možete direktno izabrati sa padajuće liste. Drugi parametar je `model`, preporučuje se korišćenje najnovijeg vodećeg modela `claude-fable-5-1`; prethodni `claude-fable-5` se i dalje može pozivati. Poslednji parametar je `messages`, to je niz upita, pri čemu svaki element sadrži `role` i `content`; `role` podržava `user`, `assistant`, `system`, a `content` je konkretan sadržaj. Claude Fable 5.1 podržava kontekst od 1 milion Token-a i maksimalni izlaz od 128K Token-a.

Istovremeno možete primetiti da se sa desne strane generiše odgovarajući pozivni kod, možete kopirati kod i direktno ga pokrenuti, a možete i direktno kliknuti na dugme „Try“ za testiranje.

Često korišćeni opcioni parametri:

- `max_tokens`: ograničava maksimalan broj token-a u jednom odgovoru.
- `temperature`: slučajnost generisanja, između 0 i 2, što je vrednost veća, rezultat je raznovrsniji.
- `n`: koliko kandidatskih odgovora se generiše odjednom.
- `response_format`: podešavanje formata povratne vrednosti.

<p><img src="https://cdn.acedata.cloud/v6lbjo.png" width="400" className="m-auto" /></p>

Povratni rezultat ima više polja, koja su predstavljena u nastavku:

- `id`, ID generisanog zadatka ovog razgovora, koristi se za jedinstvenu identifikaciju ovog zadatka razgovora.
- `model `, izabrani model sa zvaničnog Claude sajta.
- `choices`, informacije o odgovoru koji Claude daje na upit.
- `usage `: statističke informacije o token-ima za ovaj par pitanja i odgovora.

U Chat Completions formatu, `usage.prompt_tokens` je ukupan unos; `prompt_tokens_details.cached_tokens` i `prompt_tokens_details.cache_write_tokens` redom beleže detalje čitanja iz keša i upisivanja u keš. `completion_tokens_details.reasoning_tokens` je podskup `completion_tokens`, te ga nemojte ponovo sabirati prilikom izračunavanja ukupne količine ili troška. Odgovori koji nisu strimovani takođe mogu vratiti objekat `usage.cost`, gde je `amount` stvarna potrošnja kredita, `currency` je jedinica obračuna, a `list_amount` je iznos pre popusta (ako postoji).

Naziv polja kompatibilan sa Chat-om je `reasoning_tokens`; izvorni Messages API koristi `output_tokens_details.thinking_tokens`. Wire schema ova dva protokola se razlikuje, klijent ne bi trebalo da meša nazive polja.

Među njima, `choices` sadrži Claude-ove informacije o odgovoru, a `choices` unutar njega su konkretne informacije o Claude-ovom odgovoru, kao što se može videti na slici.

<p><img src="https://cdn.acedata.cloud/2ulyhw.png" width="400" className="m-auto" /></p>

Može se videti da polje `content` unutar `choices` sadrži konkretan sadržaj Claude-ovog odgovora.

## Strimovani odgovor

Ovaj interfejs takođe podržava strimovane odgovore, što je veoma korisno za povezivanje sa veb stranicama i omogućava veb stranici da ostvari efekat prikazivanja znak po znak.

Ako želite da odgovor bude vraćen strimovano, možete promeniti parametar `stream ` u zaglavlju zahteva na `true`.

Izmena je prikazana na slici, ali pozivni kod zahteva odgovarajuće izmene kako bi podržao strimovani odgovor.

<p><img src="https://cdn.acedata.cloud/ueugot.png" width="400" className="m-auto" /></p>

Nakon što se `stream` izmeni na `true`, API će vraćati odgovarajuće JSON podatke red po red, a na nivou koda potrebno je da izvršimo odgovarajuće izmene kako bismo dobili rezultate red po red.

Primer Python pozivnog koda:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "claude-opus-4-20250514",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Duboko razmišljanje
Nova generacija Claude modela može da rezonuje prema podrazumevanoj strategiji modela, bez potrebe za aktiviranjem putem sufiksa modela `-thinking`. Chat-compatible odgovori koriste OpenAI kompatibilno usage polje `completion_tokens_details.reasoning_tokens`. `reasoning_tokens` je već uključen u `completion_tokens`, nemojte ga sabirati dvaput. Rezonovanje i vidljivi glavni tekst dele ograničenje izlaznih tokena, stoga se pri manjem `max_tokens` može pojaviti prazan ili skraćen glavni tekst; u tom slučaju povećajte izlazni budžet ili, kada korišćeni model to podržava, izaberite manji napor rezonovanja.

Ako su vam potrebni izvorni `thinking`, `output_config.effort`, thinking blokovi sadržaja i povrat potpisa, koristite `/v1/messages`. Odgovarajuće usage polje za Messages je `output_tokens_details.thinking_tokens`, nemojte ga mešati sa Chat-compatible `completion_tokens_details.reasoning_tokens`.

## Vizuelni modeli

claude-sonnet-4-20250514 je multimodalni veliki jezički model koji je razvio Claude, a na osnovu claude-4 dodaje mogućnost vizuelnog razumevanja. Ovaj model može istovremeno da obrađuje tekstualne i slikovne ulaze, ostvarujući međumodalno razumevanje i generisanje.

Tekstualna obrada korišćenjem modela claude-sonnet-4-20250514 je u skladu sa osnovnim načinom korišćenja iz prethodnog teksta, a u nastavku će ukratko biti predstavljeno kako koristiti mogućnosti obrade slika modela.

Mogućnost obrade slika modela claude-sonnet-4-20250514 uglavnom se koristi dodavanjem polja `type` na osnovu postojećeg sadržaja `content`, putem ovog polja se može saznati da li je otpremljen tekst ili slika, čime se koristi mogućnost obrade slika modela claude-sonnet-4-20250514, a u nastavku se uglavnom opisuje pozivanje ove funkcije na dva načina, putem Curl-a i Python-a.

- Način putem Curl skripte

```

-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "claude-sonnet-4-20250514",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },

            "type": "image_url",
            "image_url": {
              "url": "https://cdn.acedata.cloud/ueugot.png"

        ]
      }
    ]
  }'
```

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kôd greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, verovatno zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, verovatno zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neovlašćeno, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste ograničenje broja zahteva.
- `500 api_error`: Interna greška servera, nešto je pošlo po zlu na serveru.
