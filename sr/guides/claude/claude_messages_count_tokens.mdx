Claude Messages Count Tokens API može, bez stvarnog kreiranja poruke, izračunati broj ulaznih Tokena jedne Message poruke, uključujući brojanje Tokena za sadržaje poput alata, slika i dokumenata. Ovo je veoma korisno kada je potrebno proceniti troškove ili proveriti da li unos premašuje ograničenje konteksta modela.

Ovaj dokument uglavnom predstavlja postupak korišćenja Claude Messages Count Tokens API-ja.

`claude-fable-5-2` trenutno ne pruža Count Tokens interfejs. Konačna potrošnja zahteva generisanja može se videti u `usage` odgovora Messages; nemojte koristiti rezultate brojanja drugih modela kao zamenu za tačnu potrošnju ovog modela.

## Postupak prijave

Da biste koristili Claude Messages Count Tokens API, prvo idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications) da biste dobili svoj API Token, i sačuvajte ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, bićete automatski preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a po završetku ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, nije potrebno posebno podnositi prijavu za svaku uslugu.** Prva prijava donosi besplatni kredit, što omogućava besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Osnovno korišćenje

Putanja zahteva za Claude Messages Count Tokens API je `/v1/messages/count_tokens`, što je usklađeno sa zvaničnim Anthropic API-jem. Potrebno je da obezbedimo najmanje dva obavezna parametra:

- `model`: popunite potpuni ID modela iz liste modela ovog interfejsa i koristite isti model kao u naknadnim Messages zahtevima.
- `messages`: niz ulaznih poruka, pri čemu svaka poruka sadrži `role` (ulogu) i `content` (sadržaj).

Često korišćeni opcioni parametri:

- `system`: sistemski prompt, uračunava se u broj Tokena.
- `tools`: definicije alata, uračunavaju se u broj Tokena.
- `thinking`: konfiguracija proširenog razmišljanja.
- `tool_choice`: konfiguracija izbora alata.
- `cache_control`: konfiguracija kontrole keširanja na najvišem nivou ili nivou bloka sadržaja.

`messages`, `system`, reprodukcija poziva alata, URL slike i blokovi sadržaja document/PDF koriste istu stabilnu strukturu zahteva kao Messages API.

### cURL primer

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python primer

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Primer rezultata vraćanja:

```json
{
  "input_tokens": 11
}
```

### Korišćenje Anthropic SDK-a

Claude Messages Count Tokens API prihvata stabilnu strukturu zahteva Anthropic SDK-a i može se pozvati putem biblioteke `anthropic`. Interfejs broji ulazne Tokene prema izabranom modelu i može se koristiti za proveru obima unosa pre slanja Messages zahteva.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Brojanje Tokena sa uključenim alatima

Ako vaš zahtev sadrži definicije alata, i ti alati će biti uračunati u broj Tokena:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Brojanje Tokena sa uključenim sistemskim promptom

Sistemski prompt će takođe biti uračunat u broj Tokena:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Napomene

- Ovaj API računa samo broj ulaznih Tokena i neće proizvesti nikakav izlaz modela.
- Rezultati brojanja Tokena mogu se koristiti za procenu obima unosa i proveru prozora konteksta; konačna naplata se zasniva na `usage` u stvarnom Messages odgovoru.
- Slike, PDF-ovi, definicije alata, sistemski promptovi i konfiguracija thinking biće uračunati u rezultat prema pravilima unosa izabranog modela.
- Ovaj API je potpuno besplatan i ne troši nikakav kredit.
