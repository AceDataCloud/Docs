Claude Messages Count Tokens API može izračunati broj ulaznih Token-a za poruku bez stvaranja stvarne poruke, uključujući Token broj za alate, slike i dokumente. Ovo je veoma korisno kada je potrebno proceniti troškove ili proveriti da li ulaz premašuje ograničenja konteksta modela.

Ovaj dokument uglavnom opisuje proces korišćenja Claude Messages Count Tokens API.

## Proces prijave

Da biste koristili Claude Messages Count Tokens API, prvo možete otići na [Claude Messages Count Tokens API](https://platform.acedata.cloud/documents/claude-messages-count-tokens) stranicu i kliknuti na dugme „Acquire“ da biste dobili potrebne akreditive za zahtev.

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon prijave ili registracije automatski ćete se vratiti na trenutnu stranicu.

Ovaj API je potpuno besplatan za korišćenje, ne troši resurse.

## Osnovna upotreba

Putanja zahteva za Claude Messages Count Tokens API je `/v1/messages/count_tokens`, u skladu sa zvaničnim Anthropic API-jem. Potrebno je da obezbedimo najmanje dva obavezna parametra:

- `model`: odaberite Claude model koji koristite, kao što su `claude-sonnet-4-5-20250929`, `claude-opus-4-20250514` itd.
- `messages`: niz ulaznih poruka, svaka poruka sadrži `role` (ulogu) i `content` (sadržaj).

Uobičajeni opcioni parametri:

- `system`: sistemska uputstva, koja se računaju u broj Token-a.
- `tools`: definicija alata, koja se takođe računa u broj Token-a.
- `thinking`: konfiguracija proširenog razmišljanja.

### cURL primer

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-sonnet-4-5-20250929",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python primer

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-sonnet-4-5-20250929",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Primer rezultata:

```json
{
  "input_tokens": 11
}
```

### Korišćenje Anthropic SDK

Claude Messages Count Tokens API je potpuno kompatibilan sa zvaničnim Anthropic SDK-jem, možete direktno koristiti `anthropic` biblioteku za pozivanje.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-sonnet-4-5-20250929",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Broj Token-a koji uključuje alate

Ako vaš zahtev uključuje definiciju alata, ti alati će se takođe računati u broj Token-a:

```python
result = client.messages.count_tokens(
    model="claude-sonnet-4-5-20250929",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Broj Token-a koji uključuje sistemska uputstva

Sistemska uputstva će se takođe računati u broj Token-a:

```python
result = client.messages.count_tokens(
    model="claude-sonnet-4-5-20250929",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Napomene

- Ovaj API samo računa broj ulaznih Token-a, ne generiše nikakve izlaze modela.
- Rezultati brojanja Token-a mogu se koristiti za procenu troškova pozivanja Claude Messages API.
- Različiti modeli mogu imati različite načine tokenizacije, molimo koristite isti model parametar kao u stvarnom pozivu.
- Ovaj API je potpuno besplatan, ne troši nikakve resurse.
