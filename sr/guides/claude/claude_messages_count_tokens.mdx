Claude Messages Count Tokens API može, bez stvarnog kreiranja poruke, da izračuna broj ulaznih Tokena jedne Message poruke, uključujući brojanje Tokena za sadržaje kao što su alati, slike i dokumenti. Ovo je veoma korisno kada je potrebno proceniti trošak ili proveriti da li unos prelazi ograničenje konteksta modela.

Ovaj dokument uglavnom predstavlja proces korišćenja Claude Messages Count Tokens API-ja.

## Proces prijave

Da biste koristili Claude Messages Count Tokens API, prvo preuzmite svoj API Token na [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications) i sačuvajte ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu, gde ćete biti pozvani da se registrujete i prijavite; nakon završetka automatski ćete se vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe za zasebnom prijavom za svaku uslugu.** Prva prijava uključuje besplatan kredit za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Osnovno korišćenje

Putanja zahteva za Claude Messages Count Tokens API je `/v1/messages/count_tokens`, usklađena sa zvaničnim Anthropic API-jem. Potrebno je da navedemo najmanje dva obavezna parametra:

- `model`: bira Claude model koji se koristi; `claude-opus-5-5` se može koristiti za Messages Token Count, kao i najnoviji vodeći `claude-fable-5-1`; prethodni `claude-fable-5` je i dalje kompatibilan i zadržan. `claude-sonnet-5-5` je dodat izvornom interfejsu Messages serije, podržava unos slika i adaptivno razmišljanje; njegove zvanične referentne cene za ulaz, izlaz i čitanje iz keša su 2, 10 i 0,20 USD po milionu Tokena.
- `messages`: niz ulaznih poruka, pri čemu svaka poruka sadrži `role` (ulogu) i `content` (sadržaj).

Često korišćeni opcioni parametri:

- `system`: sistemski prompt, koji se uračunava u broj Tokena.
- `tools`: definicije alata, koje se uračunavaju u broj Tokena.
- `thinking`: konfiguracija proširenog razmišljanja.
- `tool_choice`: konfiguracija izbora alata.
- `cache_control`: konfiguracija kontrole keširanja na najvišem nivou ili na nivou bloka sadržaja.

`messages`, `system`, reprodukcija poziva alata, URL slike i blokovi sadržaja document/PDF koriste istu stabilnu strukturu zahteva kao Messages API.

### cURL primer

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python primer

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Primer rezultata odgovora:

```json
{
  "input_tokens": 11
}
```

### Korišćenje Anthropic SDK-a

Claude Messages Count Tokens API prihvata stabilnu strukturu zahteva Anthropic SDK-a i može se pozivati putem biblioteke `anthropic`. Interfejs koristi izvornu Count Tokens mogućnost koja odgovara izabranom modelu za brojanje ulaza i može se koristiti za proveru veličine unosa pre slanja Messages zahteva.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Brojanje Tokena koje uključuje alate

Ako vaš zahtev sadrži definicije alata, i ti alati će biti uračunati u broj Tokena:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Brojanje Tokena koje uključuje sistemski prompt

Sistemski prompt se takođe uračunava u broj Tokena:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Napomene

- Ovaj API računa samo broj ulaznih Tokena i neće generisati nikakav izlaz modela.
- Rezultat brojanja Tokena može se koristiti za procenu veličine unosa i proveru prozora konteksta; konačna naplata se zasniva na `usage` u stvarnom Messages odgovoru.
- Slike, PDF-ovi, definicije alata, sistemski promptovi i konfiguracija thinking uračunavaju se u rezultat prema pravilima unosa izabranog modela.
- Ovaj API je potpuno besplatan i ne troši nikakav kredit.
