Ovaj vodič konfiguriše **Third-Party Inference Gateway** za Claude Desktop, nije Claude Code, niti MCP Connector za Claude Desktop.

## 1. Preuzmite API Key

Otvorite [listu Ace Data Cloud aplikacija](https://platform.acedata.cloud/console/applications), uđite u dostupnu aplikaciju i kopirajte API Key.

![Preuzimanje Ace Data Cloud API Key-a](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Otvorite konfiguraciju zaključivanja treće strane

Na stranici za prijavu u Claude Desktop redom otvorite **Help → Troubleshooting → Enable Developer Mode**, zatim izaberite **Developer → Configure Third-Party Inference…**.

![Otvaranje Third-Party Inference u Claude Desktop-u](https://cdn.acedata.cloud/713ffd7104a3.png)

> Slika je iz Bifrost Apache-2.0 repozitorijuma i koristi se samo za lociranje Claude Desktop menija; interfejs različitih verzija može se neznatno razlikovati.

## 3. Konfigurišite Gateway

Izaberite **Gateway**, zatim popunite:

| Polje                  | Vrednost                           |
| ------------------- | --------------------------- |
| Gateway base URL    | `https://api.acedata.cloud` |
| Gateway API key     | Upravo kopirani API Key               |
| Gateway auth scheme | `bearer`                    |
| Credential kind     | `Static API key`            |

![Ekran konfiguracije Claude Desktop Gateway-a](https://cdn.acedata.cloud/68d41fe682cb.png)

Kliknite na **Apply Changes**, zatim kliknite na **Save & Restart**.

## 4. Verifikacija

Nakon ponovnog pokretanja izaberite dostupan model, kreirajte novi razgovor i pošaljite `Reply only OK`, zatim izvršite jednostavan zadatak alata. Zapise poziva možete pogledati u [istoriji korišćenja](https://platform.acedata.cloud/console/usages).

Ace Data Cloud Gateway podržava `/v1/models` koji koristi Claude Desktop, `/v1/messages` sa Bearer autentifikacijom i strimovanjem, pozivanje alata i nastavak `tool_result`. Polja za keširanje promptova će biti sačuvana; kada su vrednosti upisivanja i čitanja keša obe 0, to ne znači da je došlo do pogotka keša.

401 obično znači da Key nije ispravan; kada model nije pronađen, ponovo proverite konfiguraciju i potpuno ponovo pokrenite Claude Desktop. Kada prijavljujete problem, navedite trace ID iz zapisa poziva, nemojte navoditi API Key.
