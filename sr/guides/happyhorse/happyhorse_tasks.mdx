HappyHorse Tasks API се користи за упит о HappyHorse Videos API-ју за креирање видео генерисања или уређивања задатака.

## Процес пријаве

Да бисте користили HappyHorse Videos API, прво идите на [Ace Data Cloud контролни панел](https://platform.acedata.cloud/console/applications) да добијете ваш API токен, за резерву.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након тога ћете бити аутоматски враћени на тренутну страницу.

**Један API токен је довољан за позивање свих услуга платформе, није потребно посебно пријављивати за сваку услугу.** При првом захтеву добијате бесплатан кредит, можете бесплатно испробати; када вам кредит буде недовољан, можете допунити општи баланс на [контролном панелу](https://platform.acedata.cloud/console/coin).

> 📘 Пуна документација: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Пример захтева

HappyHorse Tasks API може се користити за упит о резултатима HappyHorse Videos API-ја.

### Постављање заглавља захтева и тела захтева

**Request Headers** укључује:

- `accept`：одређује пријем JSON формата одговора, овде се попуњава као `application/json`.
- `authorization`：кључ за позивање API-ја, након пријаве можете директно изабрати из падајућег менија.

**Request Body** укључује:

- `id`：ид задатка који желите да упитате.
- `action`：начин операције над задатком, за појединачни упит попуните `retrieve`.

### CURL код пример

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Пример одговора

Након успешног захтева, API ће вратити детаље о том задатку. У томе, поље `request` је тело захтева при креирању задатка, а поље `response` је тело одговора након завршетка задатка, на пример:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262774.423,
  "elapsed": 52.6,
  "request": {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic shot of a white horse running across a moonlit beach",
    "resolution": "720P",
    "duration": 5
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "1469cfc3-3004-4d9e-ab10-xxxxxx",
        "video_url": "https://cdn.acedata.cloud/happyhorse/c8cbf53aa0.mp4",
        "state": "succeeded",
        "duration": 5,
        "resolution": "720P",
        "ratio": "16:9"
      }
    ]
  }
}
```

Објашњење поља је следеће:

- `id`：ид генерисаног задатка, користи се за јединствено идентификовање овог генерисаног задатка.
- `request`：информације о захтеву при креирању задатка.
- `response`：тренутне или коначне информације о повратку задатка.
- `created_at`：време креирања задатка, Unix временски жиг (секунде, флотант).
- `started_at`：време почетка извршења задатка, Unix временски жиг (секунде, флотант).
- `finished_at`：време завршетка задатка, Unix временски жиг (секунде, флотант). Ово поље се не враћа ако задатак није завршен.
- `elapsed`：време извршења задатка, у секундама (флотант, задржава 3 децималне). Ово поље се не враћа ако задатак није завршен.

## Пакетни упит

Када упитате детаље о више задатака по ID-ју, поставите `action` на `retrieve_batch`, и пренесите низ ID-јева задатака преко `ids`:

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```

У повратном резултату биће укључена поља `items` и `count`, где `items` представља низ детаља о задацима, а `count` представља број задатака који су пронађени у овом упиту.
