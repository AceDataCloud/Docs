Ovaj dokument predstavlja način integracije HappyHorse Videos API-ja. Ovaj interfejs podržava generisanje videa iz teksta, generisanje videa iz slike prvog kadra, generisanje videa iz referentne slike i uređivanje videa putem jedinstvenog ulaza `/happyhorse/videos` i parametra `action`.

## Postupak prijave

Da biste koristili HappyHorse Videos API, prvo preuzmite svoj API Token u [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications) i sačuvajte ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu, koja će vas pozvati da se registrujete i prijavite; nakon završetka automatski ćete se vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe da ga posebno zahtevate za svaku uslugu.** Prva prijava donosi besplatni kredit za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti zajednički saldo u [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Tipovi operacija

`action` određuje režim generisanja ovog zahteva:

- `generate`: generisanje videa iz teksta, podrazumevani action, podržava `happyhorse-1.0-t2v` i `happyhorse-1.1-t2v`, obavezno je proslediti `prompt`.
- `image_to_video`: generisanje videa iz slike prvog kadra, podržava `happyhorse-1.0-i2v` i `happyhorse-1.1-i2v`, obavezno je proslediti `image_url`.
- `reference_to_video`: generisanje videa iz referentne slike, podržava `happyhorse-1.0-r2v` i `happyhorse-1.1-r2v`, obavezno je proslediti `prompt` i 1–9 slika `image_urls`.
- `video_edit`: uređivanje videa, podržava `happyhorse-1.0-video-edit`, obavezno je proslediti `prompt` i `video_url`, a dodatno se može proslediti 0–5 referentnih slika `image_urls`.

Sve radnje podrazumevano koriste model 1.1; `video_edit` trenutno ima samo `happyhorse-1.0-video-edit`.

## Osnovna upotreba

Za generisanje videa iz teksta potrebno je samo navesti `prompt`, a mogu se navesti i parametri kao što su `resolution`, `ratio`, `duration` i drugi:

```json
{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

Primer vraćenog rezultata je sledeći:

```json
{
  "success": true,
  "task_id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
  "trace_id": "6071ab5e-2f37-46f0-9e07-f1e378112e69",
  "data": [
    {
      "id": "9650580f-6d9e-4bc1-823a-29011790c5cb",
      "video_url": "https://cdn.acedata.cloud/assets/examples/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1-2c108ce23554.mp4",
      "state": "succeeded",
      "duration": 5,
      "resolution": "720P",
      "ratio": null
    }
  ]
}
```

Objašnjenje polja:

- `success`: da li je ovaj zahtev uspešan.
- `task_id`: ID zadatka na strani Ace Data Cloud-a, može se koristiti za proveru statusa zadatka.
- `trace_id`: ID praćenja ovog zahteva, koristi se za rešavanje problema.
- `data`: lista rezultata videa.
  - `id`: ID zadatka na strani HappyHorse-a.
  - `video_url`: CDN adresa veze generisanog videa.
  - `state`: status zadatka, opcije su `pending` / `succeeded` / `error`.
  - `duration`: trajanje videa za naplatu, u sekundama; za `video_edit` predstavlja zbir trajanja ulaznog i izlaznog videa.
  - `resolution`: izlazna rezolucija.
  - `ratio`: izlazni odnos širine i visine.

Odgovarajući CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/happyhorse/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}'
```

Odgovarajući Python kod je sledeći:

```python
import requests

url = "https://api.acedata.cloud/happyhorse/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
    "resolution": "720P",
    "ratio": "16:9",
    "duration": 5,
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Generisanje videa iz slike prvog kadra

Kada se koristi `image_to_video`, `image_url` će se koristiti kao prvi kadar videa. Izlazni odnos širine i visine će se što je više moguće prilagoditi slici prvog kadra, zato za ovu radnju nije potrebno proslediti `ratio`.

```json
{
  "action": "image_to_video",
  "model": "happyhorse-1.1-i2v",
  "image_url": "https://cdn.acedata.cloud/b1c82e4937.png",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "1080P",
  "duration": 5
}
```

## Generisanje videa iz referentne slike

Kada se koristi `reference_to_video`, u `image_urls` se može proslediti 1–9 referentnih slika. U tekstu upita možete koristiti `character1`, `character2` i slične oznake za upućivanje na slike odgovarajućim redosledom.

```json
{
  "action": "reference_to_video",
  "model": "happyhorse-1.1-r2v",
  "prompt": "character1 walks forward through a sunrise meadow with the warm leather and gold trim style from character2",
  "image_urls": [
    "https://cdn.acedata.cloud/b1c82e4937.png",
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

## Uređivanje videa

Izlazno trajanje i format kadra za `video_edit` nasleđuju izvorni video; prosleđivanje `duration` ili `ratio` ih neće promeniti; format kadra za video generisan iz slike takođe nasleđuje izvornu sliku. Naknada za uređivanje računa se na osnovu ukupnog trajanja ulaznog i izlaznog videa.

Kada se koristi `video_edit`, obavezno je proslediti video za uređivanje `video_url` i nameru uređivanja `prompt`. Opcioni `image_urls` će se koristiti kao referentne slike, na primer za promenu odeće, prenos stila ili lokalnu zamenu. `audio_setting` može biti `auto` ili `origin`, pri čemu `origin` označava zadržavanje originalnog zvuka videa.
```json
{
  "action": "video_edit",
  "model": "happyhorse-1.0-video-edit",
  "prompt": "Apply the warm leather and gold trim style from the reference image while preserving the original camera motion",
  "video_url": "https://cdn.acedata.cloud/assets/examples/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1-2c108ce23554.mp4",
  "image_urls": [
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "audio_setting": "auto"
}
```

## Asinhroni povratni poziv

Generisanje videa zahteva određeno vreme obrade. Ako ne želite da održavate dugu vezu i čekate, možete proslediti `callback_url`, u tom slučaju će API odmah vratiti `task_id`, a nakon završetka zadatka će POST metodom poslati konačni rezultat na tu adresu:

```json
{
  "action": "generate",
  "prompt": "A horse running through a snowy forest",
  "duration": 5,
  "callback_url": "https://your-domain.com/callback/happyhorse"
}
```

Odmah vraćeni rezultat je sledeći:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

Ako želite samo anketiranje, bez potrebe za povratnim pozivom, možete takođe proslediti `"async": true`, a zatim putem [HappyHorse Tasks API-ja](https://platform.acedata.cloud/documents/happyhorse-tasks) upitati rezultat zadatka.

## Objašnjenje naplate

HappyHorse naplaćuje prema broju sekundi izlaznog videa i rezoluciji:

- `720P`: već od približno $0.105 / sekundi.
- `1080P`: već od približno $0.18 / sekundi.
- `video_edit`: naplaćuje se prema zbirnom trajanju ulaznog i izlaznog videa, a stvarno naplaćeno trajanje zasniva se na statistici nakon završetka zadatka.

Neuspešni zadaci se ne naplaćuju i ne zauzimaju besplatnu kvotu.

## Obrada grešaka

Kada dođe do problema sa zahtevom, API će vratiti odgovarajući kod greške i opis, a uobičajeni su sledeći:

- `400`: parametri zahteva su neispravni, na primer action i model se ne podudaraju, nedostaje `prompt` / `image_url` / `video_url`, ili `duration` prelazi opseg od 3–15 sekundi.
- `401`: autentifikacija nije uspela, token je nevažeći ili se ne podudara sa API-jem.
- `403`: nedovoljno sredstava ili je zahtev odbijen jer je upit pogodio proveru sadržaja.
- `429`: zahtevi su previše učestali, ograničenje brzine je aktivirano, pokušajte ponovo kasnije.
- `500`: interna greška servera ili neuspeh generisanja.
