Ovaj članak predstavlja način integracije HappyHorse Videos API-ja. Ovaj interfejs podržava generisanje videa iz teksta, generisanje videa iz slike prvog kadra, generisanje videa iz referentne slike i uređivanje videa kroz jedinstveni ulaz `/happyhorse/videos` i parametar `action`.

## Proces prijave

Da biste koristili HappyHorse Videos API, najpre preuzmite svoj API Token na [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications) i sačuvajte ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu gde ćete biti pozvani da se registrujete i prijavite, nakon čega ćete automatski biti vraćeni na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe za zasebnim prijavljivanjem za svaku uslugu.** Prilikom prve prijave dobijate besplatni kredit za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Tipovi operacija

`action` određuje režim generisanja za ovaj zahtev:

- `generate`: generisanje videa iz teksta, podrazumevani action, podržava `happyhorse-1.0-t2v` i `happyhorse-1.1-t2v`, obavezno je proslediti `prompt`.
- `image_to_video`: generisanje videa iz slike prvog kadra, podržava `happyhorse-1.0-i2v` i `happyhorse-1.1-i2v`, obavezno je proslediti `image_url`.
- `reference_to_video`: generisanje videa iz referentne slike, podržava `happyhorse-1.0-r2v` i `happyhorse-1.1-r2v`, obavezno je proslediti `prompt` i 1–9 `image_urls` slika.
- `video_edit`: uređivanje videa, podržava `happyhorse-1.0-video-edit`, obavezno je proslediti `prompt` i `video_url`, a dodatno se može proslediti 0–5 referentnih slika `image_urls`.

Sve akcije podrazumevano koriste model 1.1; `video_edit` trenutno ima samo `happyhorse-1.0-video-edit`.

## Osnovna upotreba

Za generisanje videa iz teksta potrebno je samo obezbediti `prompt`, a možete navesti i parametre kao što su `resolution`, `ratio`, `duration`:

```json
{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

Primer vraćenog rezultata je sledeći:

```json
{
  "success": true,
  "task_id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
  "trace_id": "6071ab5e-2f37-46f0-9e07-f1e378112e69",
  "data": [
    {
      "id": "9650580f-6d9e-4bc1-823a-29011790c5cb",
      "video_url": "https://cdn.acedata.cloud/assets/examples/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1-2c108ce23554.mp4",
      "state": "succeeded",
      "duration": 5,
      "resolution": "720P",
      "ratio": null
    }
  ]
}
```

Opis polja:

- `success`: da li je ovaj zahtev uspešan.
- `task_id`: ID zadatka na Ace Data Cloud strani, može se koristiti za proveru statusa zadatka.
- `trace_id`: ID praćenja ovog zahteva, koristi se za rešavanje problema.
- `data`: lista video rezultata.
  - `id`: ID zadatka na HappyHorse strani.
  - `video_url`: CDN adresa veze za generisani video.
  - `state`: status zadatka, opcionalno `pending` / `succeeded` / `error`.
  - `duration`: naplativo trajanje videa, u sekundama; za `video_edit` predstavlja zbir trajanja ulaznog i izlaznog videa.
  - `resolution`: izlazna rezolucija.
  - `ratio`: odnos širine i visine izlaza.

Odgovarajući CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/happyhorse/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}'
```

Odgovarajući Python kod je sledeći:

```python
import requests

url = "https://api.acedata.cloud/happyhorse/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
    "resolution": "720P",
    "ratio": "16:9",
    "duration": 5,
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Generisanje videa iz slike prvog kadra

Kada se koristi `image_to_video`, `image_url` će se koristiti kao prvi kadar videa. Odnos širine i visine izlaza će se u najvećoj mogućoj meri prilagoditi slici prvog kadra, zato za ovu akciju nije potrebno proslediti `ratio`.

```json
{
  "action": "image_to_video",
  "model": "happyhorse-1.1-i2v",
  "image_url": "https://cdn.acedata.cloud/b1c82e4937.png",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "1080P",
  "duration": 5
}
```

## Generisanje videa iz referentne slike

Kada se koristi `reference_to_video`, `image_urls` može sadržati 1–9 referentnih slika. U tekstu upita možete koristiti `character1`, `character2` i slično za upućivanje na slike odgovarajućeg redosleda.

```json
{
  "action": "reference_to_video",
  "model": "happyhorse-1.1-r2v",
  "prompt": "character1 walks forward through a sunrise meadow with the warm leather and gold trim style from character2",
  "image_urls": [
    "https://cdn.acedata.cloud/b1c82e4937.png",
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

## Uređivanje videa

Kada se koristi `video_edit`, obavezno je proslediti video za uređivanje `video_url` i nameru uređivanja `prompt`. Opcionalni `image_urls` će se koristiti kao referentne slike, na primer za promenu odeće, prenos stila ili lokalnu zamenu. `audio_setting` može biti `auto` ili `origin`, pri čemu `origin` označava zadržavanje originalnog zvuka videa.

```json
{
  "action": "video_edit",
  "model": "happyhorse-1.0-video-edit",
  "prompt": "Apply the warm leather and gold trim style from the reference image while preserving the original camera motion",
  "video_url": "https://cdn.acedata.cloud/assets/examples/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1-2c108ce23554.mp4",
  "image_urls": [
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "audio_setting": "auto"
}
```

## Asinhroni povratni poziv
Generisanje videa zahteva određeno vreme obrade. Ako ne želite da održavate dugu vezu tokom čekanja, možete proslediti `callback_url`, u kom slučaju će API odmah vratiti `task_id`, a nakon završetka zadatka će POST metodom poslati konačni rezultat na tu adresu:

```json
{
  "action": "generate",
  "prompt": "A horse running through a snowy forest",
  "duration": 5,
  "callback_url": "https://your-domain.com/callback/happyhorse"
}
```

Odmah vraćeni rezultat je sledeći:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

Ako želite samo anketiranje, bez potrebe za povratnim pozivom, možete takođe proslediti `"async": true`, a zatim putem [HappyHorse Tasks API](https://platform.acedata.cloud/documents/happyhorse-tasks) upitati rezultat zadatka.

## Objašnjenje naplate

HappyHorse naplaćuje prema broju sekundi izlaznog videa i rezoluciji:

- `720P`: već od približno $0.105 / sekundi.
- `1080P`: već od približno $0.18 / sekundi.
- `video_edit`: naplaćuje se prema zbirnom trajanju ulaznog i izlaznog videa, a stvarno naplaćeno trajanje se određuje prema statistici nakon završetka zadatka.

Neuspešni zadaci se ne naplaćuju i ne zauzimaju besplatni limit.

## Obrada grešaka

Kada dođe do problema sa zahtevom, API će vratiti odgovarajući kôd greške i objašnjenje, a uobičajeni su sledeći:

- `400`: parametri zahteva su pogrešni, na primer action i model se ne podudaraju, nedostaje `prompt` / `image_url` / `video_url`, ili je `duration` van opsega od 3–15 sekundi.
- `401`: autentifikacija nije uspela, token je nevažeći ili ne odgovara API-ju.
- `403`: nedovoljno sredstava ili je upit odbijen jer je pogodio proveru sadržaja.
- `429`: zahtevi su prečesti, aktivirano je ograničenje protoka, pokušajte ponovo kasnije.
- `500`: interna greška servera ili neuspeh generisanja.
