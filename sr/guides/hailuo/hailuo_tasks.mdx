Hailuo Tasks API glavna funkcija je da omogućava praćenje statusa izvršenja zadatka putem ID-a zadatka generisanog Hailuo Videos Generation API.

Ovaj dokument će detaljno opisati integraciju Hailuo Tasks API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Hailuo Tasks API, možete lako pratiti status izvršenja zadataka Hailuo Videos Generation API.

## Proces prijave

Da biste koristili Hailuo Videos Generation API, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, koji čuvate za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozvati sve usluge platforme, bez potrebe da se za svaku uslugu posebno prijavljujete.** Prva prijava donosi besplatnu kvotu, koju možete besplatno isprobati; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Potpuna dokumentacija: [Hailuo Videos Generation API →](https://platform.acedata.cloud/documents/hailuo-videos-integration)

## Primer zahteva

Hailuo Tasks API može se koristiti za praćenje rezultata Hailuo Videos Generation API. O tome kako koristiti Hailuo Videos Generation API, molimo vas da se obratite dokumentaciji [Hailuo Videos Generation API](https://platform.acedata.cloud/documents/hailuo-videos-generation-integration).

Uzmimo kao primer jedan ID zadatka koji je vratio Hailuo Videos Generation API, i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: 58cc618b-9639-4ee7-add2-d2fcf260d9a3, a zatim ćemo prikazati kako da ga prosledimo.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se učitava.
- `action`: način operacije na zadatku.

Postavite kao što je prikazano na sledećoj slici:

<p><img src="https://cdn.acedata.cloud/e9btl5.png" width="500" className="m-auto" /></p>

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na raznim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/tfn261.png" width="500" className="m-auto" /></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/hailuo/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "58cc618b-9639-4ee7-add2-d2fcf260d9a3",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/hailuo/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "58cc618b-9639-4ee7-add2-d2fcf260d9a3",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Vraćeni rezultati sadrže više polja, polje request predstavlja telo zahteva prilikom pokretanja zadatka, dok polje response predstavlja telo odgovora nakon završetka zadatka. Opis polja je sledeći.

- `id`, ID koji generiše ovaj video zadatak, koristi se za jedinstvenu identifikaciju ovog zadatka generisanja videa.
- `request`, informacije o zahtevu u video zadatku.
- `response`, informacije o odgovoru u video zadatku.
- `created_at`, vreme kreiranja zadatka, Unix vremenska oznaka (sekunde, decimalno).
- `started_at`, vreme kada je zadatak počeo da se izvršava, Unix vremenska oznaka (sekunde, decimalno).
- `finished_at`, vreme kada je zadatak završen, Unix vremenska oznaka (sekunde, decimalno). Ovo polje se ne vraća kada zadatak nije završen.
- `elapsed`, vreme trajanja izvršenja zadatka, u sekundama (decimalno, sa 3 decimale). Ovo polje se ne vraća kada zadatak nije završen.

## Greška u obradi

U slučaju da dođe do greške prilikom pozivanja API-ja, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Loš zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Loš zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neautorizovano, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste limit brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.
