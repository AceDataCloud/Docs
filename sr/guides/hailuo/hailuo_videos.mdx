Овај документ ће представити упутство за интеграцију Hailuo Videos Generation API, који може генерисати Hailuo званичне видео записе уношењем прилагођених параметара.

## Процес пријаве

Да бисте користили API, прво морате да одете на [Hailuo Videos Generation API](https://platform.acedata.cloud/documents/ee06377b-9185-438f-ac84-3376bcb1275e) одговарајућу страницу и затражите одговарајућу услугу, након уласка на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, након пријаве и регистрације, аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, коју можете користити за API.

## Основна употреба

Прво, потребно је разумети основни начин коришћења, а то је унос кључне речи `prompt`, акције `action`, URL-а прве слике `first_image_url` и модела `model`, како бисте добили обрађени резултат. Прво је потребно једноставно проследити поље `action`, чија вредност је `generate`, а затим треба унети модел, који тренутно укључује модел за генерисање видео записа из слика `minimax-i2v` и модел за генерисање видео записа из текста `minimax-t2v`, конкретно садржај је следећи:

<p><img src="https://cdn.acedata.cloud/7jyu0n.png" width="500" className="m-auto" /></p>

Можете видети да смо подесили Request Headers, укључујући:

- `accept`: каквог формата желите да примите одговор, овде је написано `application/json`, тј. JSON формат.
- `authorization`: кључ за позивање API, који можете директно изабрати након захтева.

Такође смо подесили Request Body, укључујући:

- `model`: модел за генерисање видео записа, углавном два модела: модел за генерисање видео записа из слика `minimax-i2v` и модел за генерисање видео записа из текста `minimax-t2v`.
- `action`: акција за ову генерисање видео записа.
- `first_image_url`: када изаберете модел за генерисање видео записа из слика `minimax-i2v`, потребно је да отпремите URL прве слике, не подржава Base64 кодирање.
- `prompt`: кључна реч.
- `callback_url`: URL на који треба да се врати резултат.

Након избора, можете приметити да је на десној страни генерисан одговарајући код, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/8psuxw.png" width="500" className="m-auto" /></p>

Кликните на дугме „Try“ да бисте извршили тест, као што је приказано на горњој слици, добили смо следећи резултат:

```json
{
  "success": true,
  "task_id": "baf1034c-684c-46be-ae6d-89ebb89b690d",
  "trace_id": "3221eb74-1a25-447a-ba69-7d9b310e306c",
  "data": [
    {
      "id": "0pv8yhe4fdrge0cmckpv23pd2g",
      "model": "minimax-t2v",
      "prompt": "Internal heat",
      "video_url": "https://file.aigpai.com/czjl/qoueLWBokF3ud6tdVD6VJTZuXTnK5HaMO2qAOS46Ef8VSBFUA/tmp9e3u11c1.output.mp4",
      "state": "succeeded"
    }
  ]
}
```

Враћени резултат има више поља, описаних као:

- `success`, статус генерисања видео записа у овом тренутку.
- `task_id`, ID генерисања видео записа у овом тренутку.
- `trace_id`, ID праћења генерисања видео записа у овом тренутку.
- `data`, листа резултата генерисања видео записа у овом тренутку.
  - `id`, ID видео записа у овом тренутку.
  - `prompt`, кључна реч за генерисање видео записа у овом тренутку.
  - `model`, линк за корицу генерисања видео записа у овом тренутку.
  - `video_url`, линк за видео генерисање у овом тренутку.
  - `state`, статус генерисања видео записа у овом тренутку.

Можете видети да смо добили задовољавајуће информације о видео запису, потребно је само да добијете генерисани Hailuo видео на основу URL адресе видео записа из `data`.

Ако желите да генеришете одговарајући код за интеграцију, можете га директно копирати, на пример, CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/hailuo/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "prompt": "Internal heat"
}'
```

## Асинхрони повратни позив

Пошто време генерисања Hailuo Videos Generation API-а траје релативно дуго, око 1-2 минута, ако API дуго не одговара, HTTP захтев ће задржати везу, што доводи до додатне потрошње системских ресурса, па овај API такође пружа подршку за асинхрони повратни позив.

Целокупни процес је: клијент покреће захтев, додатно одређујући поље `callback_url`, након што клијент покрене API захтев, API ће одмах вратити резултат, који садржи информације о пољу `task_id`, што представља ID тренутног задатка. Када задатак буде завршен, резултат генерисања видео записа ће бити послат на клијентом одређени `callback_url` у POST JSON формату, који такође укључује поље `task_id`, тако да се резултати задатка могу повезати преко ID-а.

Испод ћемо видети пример како конкретно извршити операцију.

Прво, Webhook повратни позив је услуга која може примати HTTP захтеве, програмери би требало да замените URL своје HTTP серверске инсталације. Овде, ради лакшег демонстрирања, користићемо јавни Webhook пример са веб странице https://webhook.site/, отворите ову страницу да бисте добили Webhook URL, као што је приказано на слици:

![](https://cdn.acedata.cloud/cjjfly.png)

Копирајте овај URL, можете га користити као Webhook, а пример овде је `https://webhook.site/580b81f5-596e-4321-b03f-606770b0bb83`.

Након тога, можемо подесити поље `callback_url` на горњи Webhook URL, истовремено уносећи одговарајуће параметре, конкретан садржај је приказан на слици:

<p><img src="https://cdn.acedata.cloud/odabh3.png" width="500" className="m-auto" /></p>

Кликните на покретање, можете приметити да одмах добијате резултат, као што је следеће:

```
{
  "task_id": "05aff65c-5e84-442b-8e29-3a5d27130840"
}
```

Након кратког чекања, можете наћи резултат генерисања видео записа на `https://webhook.site/580b81f5-596e-4321-b03f-606770b0bb83`, као што је приказано на слици:

![](https://cdn.acedata.cloud/7jngb4.png)

Садржај је следећи:

```json
{
    "success": true,
    "task_id": "05aff65c-5e84-442b-8e29-3a5d27130840",
    "trace_id": "b9856b8a-725d-45c9-befe-e789d9fd9ffb",
    "data": [
        {
            "id": "t80jhsf96srg80cmcm6b0rk8gm",
            "model": "minimax-t2v",
            "prompt": "Internal heat",
            "video_url": "https://file.aigpai.com/czjl/YPaUz2DcwpJqItTXAG9XHAoEoj3dbF0XPU69LT5nefCMzBFUA/tmp8s_59jez.output.mp4",
            "state": "succeeded"
        }
    ]
}
```

Можете видети да у резултату постоји поље `task_id`, а остала поља су слична као у претходном тексту, а преко овог поља можете реализовати повезивање задатка.

## Обрада грешака
При позиву API, ако наиђете на грешку, API ће вратити одговарајући код грешке и информације. На пример:

- `400 token_mismatched`：Лош захтев, могуће због недостајућих или неважећих параметара.
- `400 api_not_implemented`：Лош захтев, могуће због недостајућих или неважећих параметара.
- `401 invalid_token`：Неовлашћен, неважећи или недостајући токен за ауторизацију.
- `429 too_many_requests`：Превише захтева, превазишли сте лимит брзине.
- `500 api_error`：Унутрашња грешка сервера, нешто је пошло наопако на серверу.

### Пример одговора на грешку

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
