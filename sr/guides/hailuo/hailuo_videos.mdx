Овај документ ће представити упутство за интеграцију Hailuo Videos Generation API, који може генерисати Hailuo званичне видео записе уношењем прилагођених параметара.

## Процес пријаве

Да бисте користили Hailuo Videos Generation API, прво идите на [Ace Data Cloud контролни панел](https://platform.acedata.cloud/console/applications) да бисте добили ваш API токен, који ћете задржати за каснију употребу.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након тога ћете бити аутоматски враћени на тренутну страницу.

**Један API токен је довољан за позивање свих услуга платформе, без потребе да се за сваку услугу посебно пријављујете.** При првом захтеву добићете бесплатну квоту, коју можете бесплатно испробати; када вам квота понестане, можете допунити општи баланс на [контролном панелу](https://platform.acedata.cloud/console/coin).

> 📘 Пуна документација: [Hailuo Videos Generation API →](https://platform.acedata.cloud/documents/hailuo-videos-integration)

## Основна употреба

Прво, потребно је разумети основни начин коришћења, а то је унос упитника `prompt`, генерисање акције `action`, прва референтна слика `first_image_url` и модел `model`, што ће вам омогућити да добијете обрађени резултат. Прво је потребно једноставно проследити поље `action`, чија вредност је `generate`, а затим треба унети модел, који тренутно укључује модел за генерисање видео записа из слика `minimax-i2v` и модел за генерисање видео записа из текста `minimax-t2v`, конкретно садржај је следећи:

<p><img src="https://cdn.acedata.cloud/7jyu0n.png" width="500" className="m-auto" /></p>

Можете видети да смо овде поставили Request Headers, укључујући:

- `accept`: каквог формата желите да примите одговор, овде је написано `application/json`, што значи JSON формат.
- `authorization`: кључ за позивање API, који можете директно изабрати након пријаве.

Такође смо поставили Request Body, укључујући:

- `model`: модел за генерисање видео записа, углавном два модела: модел за генерисање видео записа из слика `minimax-i2v` и модел за генерисање видео записа из текста `minimax-t2v`.
- `action`: акција за ову генерисање видео записа.
- `first_image_url`: када изаберете модел за генерисање видео записа из слика `minimax-i2v`, потребно је да отпремите референтну слику, не подржава Base64 кодирање.
- `prompt`: упитник.
- `callback_url`: URL на који треба да се врати резултат.
- `async`: опционално, ако је подешено на `true`, интерфејс одмах враћа `task_id`, без потребе да се пружи `callback_url`, а затим можете добити резултате путем одговарајућег интерфејса за упит задатка.

Након избора, можете приметити да је на десној страни генерисан одговарајући код, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/8psuxw.png" width="500" className="m-auto" /></p>

Кликните на дугме „Пробај“ да бисте тестирали, као што је приказано на горњој слици, добили смо следећи резултат:

```json
{
  "success": true,
  "task_id": "baf1034c-684c-46be-ae6d-89ebb89b690d",
  "trace_id": "3221eb74-1a25-447a-ba69-7d9b310e306c",
  "data": [
    {
      "id": "0pv8yhe4fdrge0cmckpv23pd2g",
      "model": "minimax-t2v",
      "prompt": "Internal heat",
      "video_url": "https://platform.cdn.acedata.cloud/czjl/qoueLWBokF3ud6tdVD6VJTZuXTnK5HaMO2qAOS46Ef8VSBFUA/tmp9e3u11c1.output.mp4",
      "state": "succeeded"
    }
  ]
}
```

Враћени резултат има више поља, описаних као:

- `success`, статус генерисања видео записа у овом тренутку.
- `task_id`, ID генерисања видео записа у овом тренутку.
- `trace_id`, ID праћења генерисања видео записа у овом тренутку.
- `data`, листа резултата генерисања видео записа у овом тренутку.
    - `id`, ID видео записа у овом тренутку.
    - `prompt`, упитник за генерисање видео записа у овом тренутку.
    - `model`, линк за корицу генерисања видео записа у овом тренутку.
    - `video_url`, линк за видео генерисање у овом тренутку.
    - `state`, статус генерисања видео записа у овом тренутку.

Можете видети да смо добили задовољавајуће информације о видео запису, а ми само треба да добијемо генерисани Hailuo видео на основу адресе видео линка из `data`.

Ако желите да генеришете одговарајући код за интеграцију, можете га директно копирати, на пример, CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/hailuo/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "prompt": "Internal heat"
}'
```

## Асинхрони повратни позив

Пошто време генерисања Hailuo Videos Generation API-а траје релативно дуго, око 1-2 минута, ако API дуго не одговара, HTTP захтев ће задржати везу, што доводи до додатне потрошње системских ресурса, па овај API такође пружа подршку за асинхрони повратни позив.

Целокупни процес је: када клијент покрене захтев, додатно одређује поље `callback_url`, након што клијент покрене API захтев, API ће одмах вратити резултат, који садржи информације о пољу `task_id`, што представља ID тренутног задатка. Када задатак буде завршен, резултат генерисаног видео записа ће бити послат на `callback_url` који је одредио клијент, у формату POST JSON, који такође укључује поље `task_id`, тако да се резултати задатка могу повезати преко ID.

Испод ћемо видети пример како конкретно извршити операцију.

Прво, Webhook повратни позив је услуга која може примити HTTP захтеве, програмери би требало да замените URL вашег HTTP сервера. Овде, ради лакшег демонстрирања, користи се јавни Webhook пример веб сајта https://webhook.site/, отворите тај сајт да бисте добили Webhook URL, као што је приказано на слици:

![](https://cdn.acedata.cloud/cjjfly.png)

Копирајте овај URL и можете га користити као Webhook, пример је `https://webhook.site/580b81f5-596e-4321-b03f-606770b0bb83`.

Након тога, можемо подесити поље `callback_url` на горњи Webhook URL, а затим унети одговарајуће параметре, конкретно садржај је као на слици:

<p><img src="https://cdn.acedata.cloud/odabh3.png" width="500" className="m-auto" /></p>

Кликните на „Покрени“, можете приметити да ћете одмах добити резултат, као што је:

```
{
  "task_id": "05aff65c-5e84-442b-8e29-3a5d27130840"
}
```

Након кратког чекања, можете на `https://webhook.site/580b81f5-596e-4321-b03f-606770b0bb83` посматрати резултат генерисаног видео записа, као што је приказано на слици:

![](https://cdn.acedata.cloud/7jngb4.png)

Садржај је следећи:
```json
{
    "success": true,
    "task_id": "05aff65c-5e84-442b-8e29-3a5d27130840",
    "trace_id": "b9856b8a-725d-45c9-befe-e789d9fd9ffb",
    "data": [
        {
            "id": "t80jhsf96srg80cmcm6b0rk8gm",
            "model": "minimax-t2v",
            "prompt": "Unutrašnja toplota",
            "video_url": "https://platform.cdn.acedata.cloud/czjl/YPaUz2DcwpJqItTXAG9XHAoEoj3dbF0XPU69LT5nefCMzBFUA/tmp8s_59jez.output.mp4",
            "state": "uspešno"
        }
    ]
}
```

Možete videti da u rezultatu postoji polje `task_id`, dok su ostala polja slična prethodnim, putem ovog polja se može ostvariti povezanost zadatka.

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### Primer odgovora na grešku

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "preuzimanje nije uspelo"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
