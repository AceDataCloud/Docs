Kako primena AI-ja postaje sve šira, različiti AI programi su postepeno postali rasprostranjeni. AI je postepeno prodro u sve aspekte rada i života ljudi. A industrija koje AI obuhvata takođe je sve više, od prvobitnog pisanja, preko medicinskog obrazovanja, pa sve do sadašnjih videa.

Luma je profesionalna platforma za generisanje visokokvalitetnih videa, korisnici samo treba da otpreme materijale i mogu automatski generisati visokokvalitetne videozapise prema različitim stilovima i efektima. Ovaj AI generator videa razvili su članovi tima iz poznatih tehnoloških kompanija, sa ciljem da bez složenih alata za uređivanje svako može lako kreirati izvanredne videozapise.

Međutim, Luma zvanično ne pruža API, AceDataCloud pruža skup Luma API-ja, simulira integraciju sa zvaničnim Suno-om, i može praktično i brzo generisati željene videozapise.

## Prijava i korišćenje

Da biste koristili Luma Videos Generation API, prvo preuzmite svoj API Token u [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications), i sačuvajte ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

**Jedan API Token može pozivati sve usluge platforme, nema potrebe za zasebnim prijavljivanjem za svaku uslugu.** Prva prijava poklanja besplatni kredit, koji možete koristiti za besplatno iskustvo; kada kredit nije dovoljan, možete dopuniti opšti saldo u [konzoli](https://platform.acedata.cloud/console/coin).

## Osnovna upotreba

Koji god video želite da generišete, možete proizvoljno uneti deo teksta, na primer ako želim da generišem video o astronautima koji putuju između svemira i vulkana, mogu uneti `Astronauts shuttle from space to volcano`, kao što je prikazano na slici:

Generisani kod je sledeći:

Glavni parametri zahteva:

- `prompt`: Ključne reči za generisanje videa.
- `aspect_ratio`: Odnos širine i visine videa, podrazumevano 16:9.
- `end_image_url`: Opciono, određuje završni kadar.
- `enhancement`: Opciono, prekidač za poboljšanje jasnoće.
- `loop`: Da li se generiše video u petlji, podrazumevano false.
- `timeout`: Opciono, broj sekundi prekoračenja vremena.
- `callback_url`: Adresa asinhronog povratnog poziva.
- `async`: Opciono, kada se postavi na `true`, interfejs odmah vraća `task_id`, nije potrebno pružiti `callback_url`, a zatim se rezultat dobija anketiranjem putem odgovarajućeg interfejsa za upit zadataka.

## Generisanje sa prilagođenim početnim i završnim kadrovima

Ako želite da generišete video putem prilagođenih početnih i završnih kadrova videa, možete uneti veze slika početnog i završnog kadra:

U ovom trenutku, polje početnog kadra videa `start_image_url` može proslediti sledeću sliku kao početni kadar videa:

![Početni kadar](https://cdn.acedata.cloud/r9vsv9.png)

Zatim želimo da prilagođeno generišemo video na osnovu početnog i završnog kadra, ključnih reči, pa možemo navesti sledeći sadržaj:

- action: Radnja zadatka za generisanje videa, obično je to obično generisanje `generate` i prošireno generisanje `extend`, podrazumevano je `generate`.
- start_image_url: Određuje početni kadar generisanog videa.
- end_image_url: Određuje završni kadar generisanog videa.
- prompt: Sadržaj ključnih reči za generisanje videa.

Primer popunjavanja je sledeći:

<p><img src="https://cdn.acedata.cloud/zvzydx.png" width="500" className="m-auto" /></p>

Nakon popunjavanja, automatski se generiše sledeći kod:

<p><img src="https://cdn.acedata.cloud/tx80pu.png" width="500" className="m-auto" /></p>

Odgovarajući kod:

```python
import requests

url = "https://api.acedata.cloud/luma/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "start_image_url": "https://cdn.acedata.cloud/r9vsv9.png",
    "action": "generate",
    "prompt": "Astronauts shuttle from space to volcano"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Funkcija proširenja videa

Ako želite da nastavite generisanje generisanog videa, možete postaviti parametar `action` na `extend` i uneti ID videa koji treba nastaviti generisati ili vezu ka videu, ID videa i veza ka videu dobijaju se prema osnovnoj upotrebi, kao što je prikazano na slici ispod:

<p><img src="https://cdn.acedata.cloud/fwknj4.png" width="500" className="m-auto" /></p>

U ovom trenutku se može videti da je ID videa:

```
"video_id": "0105c090-03a5-425a-8026-523341cd575b",
"video_url": "https://platform.cdn.acedata.cloud/luma/12a18694-fd4b-47e7-9c50-34f30862cff6.mp4"
```

> Napomena, ovde su `video_id` i `video_url` u videu ID i veza generisanog videa, ako ne znate kako da generišete video, možete se pozvati na osnovnu upotrebu iznad za generisanje videa.

Da biste nastavili generisanje videa, morate otpremiti vezu ka videu ili ID videa, u nastavku je prikazana upotreba ID-a videa za proširenje, zatim moramo popuniti ključne reči za prilagođeno generisanje videa, te se može navesti sledeći sadržaj:

- action：ponašanje proširenja videa u ovom trenutku, ovde treba biti `extend` .
- prompt：ključne reči za video koji treba proširiti.
- video_url：veza ka videu koji treba proširiti i generisati.
- video_id：jedinstveni ID videa koji treba proširiti i generisati.
- end_image_url：veza ka slici završnog kadra koja se može navesti za prošireni generisani video, opcioni parametar.

## Asinhroni povratni poziv

Pošto Luma relativno dugo generiše video, potrebno je otprilike 1–2 minuta, ako API dugo ne odgovara, HTTP zahtev će stalno održavati vezu, što dovodi do dodatne potrošnje sistemskih resursa, stoga ovaj API takođe pruža podršku za asinhroni povratni poziv.
Celokupan proces je sledeći: kada klijent pokrene zahtev, dodatno navodi polje `callback_url`, nakon što klijent pokrene API zahtev, API će odmah vratiti rezultat, koji uključuje informaciju o polju `task_id`, koje predstavlja ID trenutnog zadatka. Kada se zadatak završi, rezultat generisanja muzike će biti poslat putem POST JSON formata na `callback_url` koji je klijent naveo, pri čemu takođe uključuje polje `task_id`, tako da se rezultat zadatka može povezati putem ID-ja.

U nastavku ćemo kroz primer saznati kako se konkretno koristi.

Pre svega, Webhook povratni poziv je servis koji može primati HTTP zahteve, a programer treba da ga zameni URL-om sopstvenog postavljenog HTTP servera. Radi lakše demonstracije, ovde se koristi javna Webhook primer veb-lokacija https://webhook.site/; otvaranjem te veb-lokacije može se dobiti Webhook URL, kao što je prikazano na slici:
