Glavna funkcija Luma Tasks API je da omogućava praćenje statusa izvršenja zadatka putem ID-a zadatka generisanog Luma Videos Generation API.

Ovaj dokument će detaljno opisati integraciju Luma Tasks API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Luma Tasks API, možete lako pratiti status izvršenja zadataka Luma Videos Generation API.

## Proces prijave

Da biste koristili Luma Videos Generation API, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, koji čuvate za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozvati sve usluge platforme, bez potrebe da se za svaku uslugu posebno prijavljujete.** Prilikom prve prijave dobijate besplatnu kvotu za korišćenje; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Potpuna dokumentacija: [Luma Videos Generation API →](https://platform.acedata.cloud/documents/luma-videos)

## Primer zahteva

Luma Tasks API može se koristiti za praćenje rezultata Luma Videos Generation API. O tome kako koristiti Luma Videos Generation API, molimo vas da se obratite dokumentaciji [Luma Videos Generation API](https://platform.acedata.cloud/documents/luma-videos-integration).

Uzmimo za primer jedan ID zadatka koji je vratio Luma Videos Generation API i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: 50fc6182-fa86-4c7d-ac12-2fa27ec2f151, a zatim ćemo prikazati kako ga proslediti.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se šalje.
- `action`: način operacije na zadatku.

Postavite kao što je prikazano na slici ispod:

<p><img src="https://cdn.acedata.cloud/g6ev5b.png" width="500" className="m-auto" /></p>

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na različitim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/i4fxqf.png" width="500" className="m-auto" /></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/luma/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "50fc6182-fa86-4c7d-ac12-2fa27ec2f151",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/luma/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "50fc6182-fa86-4c7d-ac12-2fa27ec2f151",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Vraćeni rezultat ima više polja, polje request je telo zahteva koje je poslato prilikom pokretanja zadatka, dok je polje response odgovor koji se vraća nakon završetka zadatka, a njegovi rezultati su u skladu sa zahtevima i odgovorima Luma Videos Generation API. Opis polja je sledeći.

- `id`, ID koji generiše ovaj video zadatak, koristi se za jedinstvenu identifikaciju ovog zadatka generisanja videa.
- `video_id`, jedinstvena identifikacija videa u ovom video zadatku, koja je potrebna za proširenje operacija na videu u budućnosti.
- `request`, informacije o zahtevu u video zadatku.
- `response`, informacije o odgovoru u video zadatku.
- `created_at`, vreme kreiranja zadatka, Unix vremenska oznaka (sekunde, decimalno).
- `started_at`, vreme početka izvršenja zadatka, Unix vremenska oznaka (sekunde, decimalno).
- `finished_at`, vreme završetka zadatka, Unix vremenska oznaka (sekunde, decimalno). Ova polja se ne vraćaju ako zadatak nije završen.
- `elapsed`, vreme trajanja izvršenja zadatka, u sekundama (decimalno, sa 3 decimale). Ova polja se ne vraćaju ako zadatak nije završen.

## Greška u obradi

U slučaju da se prilikom poziva API-a javi greška, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Neispravna zahtev, moguće zbog nedostajućih ili neispravnih parametara.
- `400 api_not_implemented`：Neispravna zahtev, moguće zbog nedostajućih ili neispravnih parametara.
- `401 invalid_token`：Neovlašćeno, neispravan ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste limit brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.
