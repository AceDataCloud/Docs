Glavna funkcija Luma Tasks API je da omogućava praćenje statusa izvršenja zadatka putem ID-a zadatka generisanog Luma Videos Generation API.

Ovaj dokument će detaljno opisati integraciju Luma Tasks API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Luma Tasks API, možete lako pratiti status izvršenja zadataka Luma Videos Generation API.

## Proces prijave

Da biste koristili Luma Tasks API, prvo treba da odete na stranicu za prijavu [Luma Videos Generation API](https://platform.acedata.cloud/documents/5bd3597d-1ff8-44ad-a580-b66b48393e7f) i zatražite odgovarajuću uslugu, a zatim kopirajte ID zadatka Luma Videos Generation API, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/ynk4ow.png)

Na kraju, idite na stranicu Tasks API [Luma Tasks API](https://platform.acedata.cloud/documents/7d32369c-4ead-4364-a4c5-652bc768b3ff) i zatražite odgovarajuću uslugu, nakon ulaska na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![Stranica za prijavu](https://cdn.acedata.cloud/rci31i.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na [stranicu za prijavu](https://platform.acedata.cloud) koja vas poziva da se registrujete i prijavite, a nakon prijave ili registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatni kredit koji možete koristiti za ovaj API.

## Primer zahteva

Luma Tasks API može se koristiti za praćenje rezultata Luma Videos Generation API. O tome kako koristiti Luma Videos Generation API, molimo vas da se obratite dokumentu [Luma Videos Generation API](https://platform.acedata.cloud/documents/16bb0108-1f09-45b3-97ac-16a668750a8c).

Uzmimo jedan ID zadatka koji je vratio Luma Videos Generation API kao primer i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: 50fc6182-fa86-4c7d-ac12-2fa27ec2f151, a zatim ćemo prikazati kako da ga prosledimo.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se šalje.
- `action`: način operacije na zadatku.

Postavite kao što je prikazano na slici ispod:

<p><img src="https://cdn.acedata.cloud/g6ev5b.png" width="500" class="m-auto"></p>

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na različitim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/i4fxqf.png" width="500" class="m-auto"></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/luma/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "50fc6182-fa86-4c7d-ac12-2fa27ec2f151",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/luma/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "50fc6182-fa86-4c7d-ac12-2fa27ec2f151",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 错误处理

U slučaju da se prilikom pozivanja API-a jave greške, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Loš zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Loš zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neautorizovano, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste limit brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.

### 错误响应示例
