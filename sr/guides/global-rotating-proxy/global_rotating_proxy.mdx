Овај документ углавном описује упутство за повезивање Ace Data Cloud глобалних代理ја, укључујући методе пријаве, практичне методе и друге конкретне садржаје.

## Метод пријаве

Да бисте користили глобалне услуге, можете прво отићи на „[страницу за пријаву](https://platform.acedata.cloud/services/87ae4a5a-59d9-4c50-86d4-c0b5d393e5af)“ да бисте се пријавили, прва пријава доноси 1 бесплатну поену.

![](https://cdn.acedata.cloud/cyzvmz.png)

Ако се још нисте пријавили, аутоматски ћете бити преусмерени на страницу за пријаву, након пријаве можете наставити са пријавом.

## Метод коришћења

Након што завршите пријаву, можете отићи у „конзолу“ да бисте видели резултате своје пријаве, као на слици:

![](https://cdn.acedata.cloud/y9boi5.png)

Кликните на „Credentials“ да бисте видели корисничко име и лозинку за коришћење глобалних代理ја, одвојене двотачком, где је корисничко име 8 знакова, а лозинка 32 знака, као на слици:

![](https://cdn.acedata.cloud/ixwm85.png)

Овај代理 је ротациони代理 (Rotating Proxy), тако да приликом коришћења треба само подесити фиксну адресу代理ја и порт, а адреса и порт代理ја су `global.proxy.acedata.cloud` и `30007`, овај代理 је HTTP/HTTPS/SOCKS代理 и може се користити за захтеве HTTP и HTTPS протокола.

> Напомена: Овај代理 може се користити само у мрежном окружењу ван Кине, у Кини није доступан.

## Тестирање команди

Када имате корисничко име и лозинку代理ја, најлакши начин за тестирање је коришћење curl командне линије, ако није инсталирано, молимо вас да се упутите на [https://curl.se/](https://curl.se/) за инсталацију.

Ако су тренутно корисничко име и лозинка代理ја `1f78266a:eff0896726224fa2a99fe82dd1f07562`, можемо тестирати помоћу следеће curl команде:

```shell
curl -x 1f78266a:eff0896726224fa2a99fe82dd1f07562@global.proxy.acedata.cloud:30007 https://ipinfo.io
```

Овде користимо curl параметар `-x` да одредимо адресу代理ја, подразумевани протокол代理ја је HTTP/HTTPS, а URL који захтевамо је [https://ipinfo.io](https://ipinfo.io), овај сајт може вратити праву IP адресу и локацију IP адресе која захтева тај сајт.

> Напомена: Наведени корисничко име и лозинка могу бити неважећи, молимо вас да их замените својим корисничким именом и лозинком.

Резултат је следећи:

```json
{
  "ip": "66.206.249.77",
  "hostname": "host-66-206-249-77.public.eastlink.ca",
  "city": "Kirkland Lake",
  "region": "Ontario",
```

Можете видети да је враћени резултат земља CA, што представља Канаду. Ако поново покренете, можете добити различите резултате, сви захтеви су случајни IP излази.

## Кодирање повезивања

У наставку је пример подешавања代理ја у Python-у:

```python
import requests

proxy = 'http://{proxy_username}:{proxy_password}@global.proxy.acedata.cloud:30007'

proxies = {
    'http': proxy,
    'https': proxy
}

for _ in range(3):
    resp = requests.get('https://ipinfo.io', proxies=proxies)
    print(resp.text)
```

Овде прво декларишемо URL代理ја и дефинишемо као променљиву proxy, протокол је http, а затим следи корисничко име и лозинка тунел代理ја (тј. корисничко име и лозинка приказани у конзоли, одвојени двотачком), а затим следи `@` симбол, а затим адреса и порт代理ја.

> Напомена: Морате заменити `{proxy_username}:{proxy_password}` у горњем коду својим корисничким именом и лозинком代理ја, коначни резултат ће изгледати као `proxy = 'http://1f78266a:eff0896726224fa2a99fe82dd1f07562@global.proxy.acedata.cloud:30007'`, напомена без `{` и `}` знакова.

Затим декларишемо променљиву proxies, конфигуришемо два парова кључ-вредност, где су имена кључева http и https, а вредности су proxy, што представља да за HTTP и HTTPS протоколе, оба користе代理 дефинисану променљивом proxy за захтеве. Након тога дефинишемо три пута циклус за тестирање代理ја.

Наравно, горњи начин подешавања代理ја је заправо релативно једноставан начин подешавања.

У ствари, горњи код је еквивалентан подешавању додатних заглавља - Proxy Authorization током захтева, тако да се горњи код може прерадити на следећи начин:

```python
import requests
import base64

proxy_host = 'global.proxy.acedata.cloud'
proxy_port = '30007'
proxy_username = '{proxy_username}' # 8 знакова корисничко име
proxy_password = '{proxy_password}' # 32 знака лозинка

credentials = base64.b64encode(
    f'{proxy_username}:{proxy_password}'.encode()).decode()

proxies = {
    'http': f'http://{proxy_host}:{proxy_port}',
    'https': f'http://{proxy_host}:{proxy_port}'
}

headers = {
    'Proxy-Authorization': f'Basic {credentials}'
}

for _ in range(3):
    resp = requests.get('https://ipinfo.io',
                        proxies=proxies, headers=headers)
    print(resp.text)

```

Можете видети да смо овде додатно подесили корисничко име и лозинку代理ја преко заглавља Proxy-Authorization (које треба кодирати у Base64), а ефекат извршавања таквог кода је исти.

За друге језике, као што је JavaScript са axios, такође можете користити сличан начин подешавања:
```javascript
const axios = require("axios");
const base64 = require("base64");

const proxy_host = "global.proxy.acedata.cloud";
const proxy_port = "30007";
const proxy_username = "{proxy_username}"; // 8-значно корисничко име
const proxy_password = "{proxy_password}"; // 32-значна лозинка

const credentials = base64.encode(`${proxy_username}:${proxy_password}`);

const proxies = {
  http: `http://${proxy_host}:${proxy_port}`,
  https: `http://${proxy_host}:${proxy_port}`,
};

const headers = {
  "Proxy-Authorization": `Basic ${credentials}`,
};

for (let i = 0; i < 3; i++) {
  axios
    .get("https://ipinfo.io", { proxies, headers })
    .then((resp) => console.log(resp.data))
    .catch((err) => console.error(err));
}
```

Резултати су увек исти.

За методе подешавања на другим језицима, молимо вас да се позовете на горњи текст и сами прерадите.

## IP Фиксирање

Као и у горњем садржају, можемо реализовати фиксирање IP адресе на одређено време додавањем `session` у корисничко име и додавањем 5-цифреног фиксног броја, који важи отприлике 10 минута.

На пример, ако желите да реализујете фиксирање IP адресе на одређено време, оригинално корисничко име је `1f78266a`, можете променити корисничко име у `1f78266a-session-12345`, где ако `12345` остане исти, IP адреса ће остати иста на одређено време, а горњи curl може бити преобликован на следећи начин:

```
curl -x 1f78266a-session-12345:eff0896726224fa2a99fe82dd1f07562@global.proxy.acedata.cloud:30007 https://ipinfo.io
```

## Куповина више

Ако је ваш пакет већ потрошен, потребно је да купите више да бисте наставили да користите ту прокси услугу.

Да бисте купили више, идите на „[страницу за пријаву](https://platform.acedata.cloud/services/87ae4a5a-59d9-4c50-86d4-c0b5d393e5af)“ и директно кликните на дугме „Купи више“ да бисте изабрали, једнократна куповина више, цена по јединици је јефтинија.
