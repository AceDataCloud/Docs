U kontekstu sve intenzivnije borbe između web skrepera i anti-skrepera, kontrola rizika na raznim sajtovima i aplikacijama postaje sve jača, a jedan od načina na koji se to postiže je blokiranje IP adresa.

Da bi se rešio problem blokiranja IP adresa, jedan od efikasnih načina je postavljanje proxy-a. Kada se postavi proxy, skreper može koristiti IP adresu proxy-a da prikrije svoju pravu IP adresu, čime se prevazilaze ograničenja anti-skrepera.

Međutim, kvalitet proxy-a varira; na primer, besplatni proxy-i dostupni na tržištu su u velikoj meri neupotrebljivi ili su već blokirani, dok su neki plaćeni obični proxy-i takođe postali deo crne liste kontrola rizika na raznim sajtovima i aplikacijama. Stoga, sada je sve manje proxy-a koji se mogu koristiti za prikupljanje visokokvalitetnih podataka, a trenutno su na tržištu najkvalitetniji proxy-i: ekskluzivni proxy-i, ADSL proxy-i i mobilni ćelijski proxy-i.

Ova usluga proxy-a zasniva se na rotacionoj proxy usluzi mobilne ćelijske mreže (4G, 5G), a ovaj dokument će predstaviti način prijave i korišćenja ove usluge.

## Mobilni ćelijski proxy

Mobilni ćelijski proxy je zapravo proxy usluga zasnovana na mobilnom internetu, pri čemu su sve proxy IP adrese stvarne IP adrese mobilnih telefona. Ova vrsta proxy-a se relativno retko koristi u oblasti skrepera, pa je verovatnoća da će biti blokirani manja, što ovu vrstu proxy-a čini veoma efikasnom za prikupljanje podataka sa sajtova i aplikacija sa jakim kontrolama rizika.

Ova proxy usluga se oslanja na veliku bazu mobilnih telefona, a sav saobraćaj se preusmerava putem pravog mobilnog interneta, podržavajući gotovo sve zahteve za podacima sa sajtova i aplikacija na tržištu, sa izuzetno visokim kvalitetom proxy-a, što značajno smanjuje verovatnoću kontrole rizika.

## Testiranje komandi

Kada dobijete korisničko ime i lozinku za proxy, najlakši način za testiranje je korišćenje curl komandne linije. Ako još nije instaliran, molimo vas da se pozovete na [https://curl.se/](https://curl.se/) za instalaciju.

Ako su trenutni korisničko ime i lozinka proxy-a `1f78266a:eff0896726224fa2a99fe82dd1f07562`, možemo koristiti sledeću curl komandu za testiranje:

```shell
curl -x 1f78266a:eff0896726224fa2a99fe82dd1f07562@cellular.proxy.acedata.cloud:30000 https://ipinfo.io
```

Ovde koristimo curl-ovu `-x` opciju da odredimo adresu proxy-a, a podrazumevani protokol proxy-a je HTTP/HTTPS. URL koji se zahteva je [https://ipinfo.io](https://ipinfo.io), a ovaj sajt može vratiti pravu IP adresu i lokaciju IP adrese koja je zahtevala pristup.

## Integracija koda

U nastavku je prikazan primer kako postaviti ovu rotacionu ćelijsku proxy uslugu koristeći Python:

```python
import requests

proxy = 'http://{proxy_username}:{proxy_password}@cellular.proxy.acedata.cloud:30000'

proxies = {
    'http': proxy,
    'https': proxy
}

for _ in range(3):
    resp = requests.get('https://ipinfo.io', proxies=proxies)
    print(resp.text)

```

Ovde prvo definišemo URL proxy-a i dodeljujemo ga proxy varijabli, protokol je http, a zatim sledi korisničko ime i lozinka rotacionog proxy-a (tj. korisničko ime i lozinka prikazani na kontrolnoj tabli, odvojeni dvotačkom), a zatim dodajemo `@` simbol i adresu i port proxy-a.

Zatim definišemo varijablu proxies, koja sadrži dva ključna para, gde su ključevi http i https, a vrednosti su proxy, što znači da se za sajtove koji koriste HTTP i HTTPS protokole koristi proxy definisan varijablom proxy.

Nakon toga definišemo tri petlje za testiranje proxy-a, a URL koji se zahteva je [https://ipinfo.io](https://ipinfo.io), a ovaj sajt može vratiti pravu IP adresu i lokaciju IP adrese koja je zahtevala pristup.

Naravno, način postavljanja proxy-a koji je gore prikazan je zapravo relativno jednostavan.

U suštini, gornji kod je ekvivalentan postavljanju dodatnog zaglavlja - Proxy Authorization prilikom zahteva, tako da se gornji kod može prepraviti na sledeći način:

```python
import requests
import base64

proxy_host = 'cellular.proxy.acedata.cloud'
proxy_port = '30000'
proxy_username = '{proxy_username}' # 8-znamenkasti korisnički naziv
proxy_password = '{proxy_password}' # 32-znamenkasta lozinka

credentials = base64.b64encode(
    f'{proxy_username}:{proxy_password}'.encode()).decode()

proxies = {
    'http': f'http://{proxy_host}:{proxy_port}',
    'https': f'http://{proxy_host}:{proxy_port}'
}

headers = {
    'Proxy-Authorization': f'Basic {credentials}'
}

for _ in range(3):
    resp = requests.get('https://ipinfo.io',
                        proxies=proxies, headers=headers)
    print(resp.text)

```

Može se videti da ovde dodatno postavljamo korisničko ime i lozinku za proxy putem zaglavlja Proxy-Authorization (koje treba kodirati u Base64), a efekat izvršenja takvog koda je isti.

Za druge jezike, kao što je JavaScript sa axios, takođe se može koristiti sličan način postavljanja:

```javascript
const axios = require("axios");
const base64 = require("base64");

const proxy_host = "cellular.proxy.acedata.cloud";
const proxy_port = "30000";
const proxy_username = "{proxy_username}"; // 8-znamenkasti korisnički naziv
const proxy_password = "{proxy_password}"; // 32-znamenkasta lozinka

const credentials = base64.encode(`${proxy_username}:${proxy_password}`);

const proxies = {
  http: `http://${proxy_host}:${proxy_port}`,
  https: `http://${proxy_host}:${proxy_port}`,
};

const headers = {
  "Proxy-Authorization": `Basic ${credentials}`,
};

for (let i = 0; i < 3; i++) {
  axios
    .get("https://ipinfo.io", { proxies, headers })
    .then((resp) => console.log(resp.data))
    .catch((err) => console.error(err));
}
```

Efekat izvršenja je isti.

Za metode postavljanja u drugim jezicima, molimo vas da se pozovete na gornji tekst i prepravite sami.
