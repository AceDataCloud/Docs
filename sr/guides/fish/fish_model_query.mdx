Овај интерфејс се заснива на [Fish Audio званичном Model API](https://docs.fish.audio/resources/api-reference/model) и служи за **пагинацију у претрази Fish јавне библиотеке звукова или клонираних звукова под тренутним налогом**. Адреса је `GET https://api.acedata.cloud/fish/model`.

> За креирање звука погледајте [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); за упит детаља о појединачном звуку по `_id` погледајте [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Процес пријаве

Да бисте користили Fish Model API, прво идите на [Ace Data Cloud контролни панел](https://platform.acedata.cloud/console/applications) да добијете ваш API Token, за резерву.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ако нисте пријављени или регистровани, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након тога ћете бити аутоматски враћени на тренутну страницу.

**Један API Token је довољан за позивање свих услуга платформе, није потребно посебно пријављивати за сваку услугу.** При првом захтеву добијате бесплатну квоту, можете бесплатно да искористите; када квота буде недовољна, можете допунити општи баланс на [контролном панелу](https://platform.acedata.cloud/console/coin).

> 📘 Пуна документација: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Параметри упита

| Параметар        | Тип      | Подразумевано | Објашњење                               |
| ---------------- | ------- | ------------- | --------------------------------------- |
| `page_size`      | integer | 10            | Број ставки по страници.                |
| `page_number`    | integer | 1             | Нумерација страница почиње од 1.       |
| `title`          | string  | —             | Фуззна претрага по наслову.             |
| `tag`            | string  | —             | Филтрирање по једној ознаци.            |
| `self`           | boolean | —             | Када је `true`, враћа само звукове које је креирао тренутни налог, без додатних услова. |
| `author_id`      | string  | —             | Филтрирање по `_id` узводног корисника. |
| `language`       | string  | —             | Филтрирање по језику звука, као што су `en`, `zh`, `es`. |
| `title_language` | string  | —             | Филтрирање по језику наслова.           |
| `sort_by`        | string  | —             | Поље за сортирање, као што су `created_at`, `task_count`. |

> Имена параметара су потпуно идентична као у узводном `GET https://api.fish.audio/model`, детаљи у [Fish званичној документацији](https://docs.fish.audio/resources/api-reference/model).

## Пример 2: Фуззна претрага по наслову (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Враћање (тестирано):

```json
{
  "total": 161,
  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",
      "type": "tts",
      "title": "Miles Morales ( Narration Paw )",
      "tags": ["male", "middle-aged", "entertainment", "storytelling", "Children's Content"],
      "languages": ["en"],
      "visibility": "public",
      "task_count": 770
    },
    {
      "_id": "76b55591c758444cb95253708696dfad",
      "type": "tts",
      "title": "Joe NARRATION",

```

Напомена: `title` је „глобално фуззно подударање“, обухвата све звукове у Fish јавnoj библиотеци (не само ваше).

## Пример 3: Само листа звукова које сте креирали (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Враћање (тестирано, тренутни налог има само 1 звук):

```json
{
  "total": 1,
  "items": [
    {
      "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
      "type": "tts",
      "title": "copilot-smoke-test",
      "description": "smoke test from api.acedata.cloud",
      "state": "trained",
      "languages": ["zh"],
      "visibility": "public",
      "samples": [
        {
          "title": "Default Sample",
          "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
          "task_id": "6a1bf398dfae49dca0e23159214342a0",
          "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
        }
      ],
      "created_at": "2026-05-10T03:52:55.601000Z",
      "author": {
        "_id": "780f2b2f862d41a08c0507bbbda77eb6",
        "nickname": "Penny Conrad"
      }
    }

  "has_more": null

```

`self=true` је еквивалентно филтрирању `author_id == тренутни узводни ID`, што је уобичајени улаз за „листу мојих звукова“.

## Пример 4: Филтрирање по језику + ознакама
```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> Uzvodno će se rezultati vratiti i za `tag` koji nije u rečniku oznaka, ali je podudaranje relativno labavo; ako je broj pogodaka 0, preporučuje se korišćenje `title` za neprecizno podudaranje.

## Polja odgovora

Svaki element u `items[]` je kompletan ModelEntity objekat, često korišćena polja:

| Polje          | Tip       | Objašnjenje                                          |
| ------------- | -------- | ------------------------------------------------- |
| `_id`         | string   | ID tona, kao vrednost `reference_id` u `/fish/tts`.         |
| `type`        | string   | Tip modela, obično `tts`.                                   |
| `title`       | string   | Naziv tona.                                             |
| `description` | string   | Opis tona.                                             |
| `state`       | string   | Status obuke: `trained` označava da je dostupan.                              |
| `tags`        | string[] | Oznake javne biblioteke.                                            |
| `languages`   | string[] | Jezici u kojima je ton stručan.                                          |
| `visibility`  | string   | `public` ili `private`.                             |
| `samples`     | object[] | Ugrađeni uzorci (uključujući direktne linkove za `audio`).                               |
| `like_count`  | integer  | Broj lajkova u javnoj biblioteci.                                           |
| `task_count`  | integer  | Broj istorijskih sinteza.                                           |
| `author`      | object   | Informacije o autoru uzvodno: `_id` / `nickname` / `avatar`.             |
| `total` (gornji nivo)   | integer  | Ukupan broj stavki koje zadovoljavaju uslove.                                         |
| `has_more`    | boolean? | Indikator paginacije uzvodno, može biti `null`. Preporučuje se korišćenje `total / page_size` za izračunavanje ukupnog broja stranica. |

## Objašnjenje naplate

Ovaj interfejs se ne naplaćuje — paginacija upita liste tonova je besplatna operacija. Kreiranje tonova ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) je takođe besplatno, troškovi se javljaju samo prilikom pozivanja [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) za sintezu glasa.

## Obrada grešaka

- `400 token_mismatched`: Nedostaju ili su nevažeći parametri zahteva.
- `401 invalid_token`: Token za autentifikaciju ne postoji ili je nevažeći.
- `429 too_many_requests`: Aktivirana brzinska ograničenja naloga.
- `500 api_error`: Interna greška servera.

Primer greške u odgovoru:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Zaključak

Da biste odabrali ton iz javne biblioteke Fish za `/fish/tts` `reference_id`, prvo koristite ovaj interfejs u kombinaciji sa `title` / `tag` / `language` za pretragu, locirajte cilj `_id`, a zatim koristite [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) da dobijete uzorke za slušanje. Da biste naveli tonove koje ste sami kreirali, jednostavno prosledite `self=true`.
