Ovaj dokument opisuje uputstvo za integraciju Fish Model Query API-ja (`GET /fish/model`), koji je potpuno kompatibilan sa [Fish Audio zvaničnim OpenAPI](https://docs.fish.audio/resources/api-reference/model) i koristi se za **paginirano pretraživanje** liste kloniranih glasova vidljivih za trenutni nalog ili celu platformu.

> Za kreiranje glasova pogledajte [Fish Model Create API](https://platform.acedata.cloud/documents/62fdf4f1-6a05-4d92-bb15-1bf78b27a14a), a za pretragu detalja pojedinačnog glasa po `_id` pogledajte [Fish Model Get API](https://platform.acedata.cloud/documents/dabdffe7-254b-5a3f-9eca-425d614d82b9).

## Proces prijave

Da biste koristili API, potrebno je da se prijavite za odgovarajuću uslugu na stranici [Fish Model API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509). Nakon ulaska na stranicu, kliknite na dugme „Acquire“.

Ukoliko niste prijavljeni ili registrovani, bićete automatski preusmereni na stranicu za prijavu gde se možete registrovati i prijaviti, nakon čega ćete biti vraćeni na trenutnu stranicu.

Prilikom prve prijave dobijate besplatan kredit koji omogućava besplatno korišćenje API-ja.

## Razlike u odnosu na zvanični API

- **Metod autentifikacije**: koristi se `Authorization: Bearer {token}`, gde je `{token}` ključ dobijen na ovoj platformi.
- **Struktura odgovora**: direktno se prosleđuje paginirani odgovor sa Fish platforme, bez dodatnog omotača platforme; u slučaju greške koristi se standardna struktura platforme `{success:false, error:{code,message}, trace_id}`.

## Primer zahteva

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=10' \
  --data-urlencode 'page_number=1' \
  --data-urlencode 'self=true'
```

## Parametri upita

Isti kao kod Fish zvaničnog API-ja:

- `page_size`: broj stavki po stranici, podrazumevano 10.
- `page_number`: broj stranice, počinje od 1.
- `title`: pretraga po naslovu (fuzzy pretraga).
- `tag`: filtriranje po oznakama.
- `self`: ako je `true`, vraćaju se samo glasovi kreirani od strane trenutnog naloga.
- `author_id`: filtriranje po autoru.
- `language`: filtriranje po jeziku glasa.
- `title_language`: filtriranje po jeziku naslova.

## Primer odgovora

Uspešan odgovor direktno prosleđuje paginiranu strukturu sa Fish platforme:

```json
{
  "items": [
    {
      "_id": "d7900c21663f485ab63ebdb7e5905036",
      "title": "我的克隆音色",
      "description": "用一段播客录音克隆的音色",
      "cover_image": "https://example.com/cover.png",
      "type": "tts",
      "state": "trained",
      "tags": [],
      "languages": ["zh", "en"],
      "visibility": "private",
      "created_at": "2025-05-09T12:34:56.789Z",
      "updated_at": "2025-05-09T12:34:56.789Z"
    }

```

Vraćeni `_id` može se koristiti kao vrednost polja `reference_id` u [Fish TTS API-ju](https://platform.acedata.cloud/documents/77adcb84-d59f-5ef9-b8a0-8b35eb42a71d) za sintezu govora koristeći taj klonirani glas.

## Objašnjenje naplate

Ovaj API nije naplaćen — paginirana pretraga liste glasova je besplatna operacija, naplata se vrši samo za `POST /fish/model` kada se u telu zahteva šalje polje `voices` za kreiranje novog glasa.

## Obrada grešaka

- `400 token_mismatched`: nedostaju ili su neispravni parametri zahteva.
- `400 api_not_implemented`: zahtevani metod ili parametri trenutno nisu podržani.
- `401 invalid_token`: nedostaju ili su nevažeći podaci za autentifikaciju.
- `429 too_many_requests`: prekoračen je limit zahteva za trenutni nalog.
- `500 api_error`: interna greška servera.

### Primer odgovora sa greškom

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Zaključak

Fish Model Query API pruža potpuno kompatibilnu funkcionalnost pretraživanja glasova sa Fish Audio zvaničnog API-ja i može se koristiti za održavanje sopstvene biblioteke kloniranih glasova na ovoj platformi. U kombinaciji sa [Fish Model Get API-jem](https://platform.acedata.cloud/documents/dabdffe7-254b-5a3f-9eca-425d614d82b9) omogućava dobijanje detaljnih informacija o pojedinačnom glasu po ID-ju.
