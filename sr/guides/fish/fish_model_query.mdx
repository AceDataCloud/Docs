Ovaj interfejs je zasnovan na [zvaničnom Fish Audio Model API-ju](https://docs.fish.audio/resources/api-reference/model) i koristi se za **straničeno pretraživanje Fish javne biblioteke glasova ili kloniranih glasova pod trenutnim nalogom**. Adresa je `GET https://api.acedata.cloud/fish/model`.

> Za kreiranje glasa pogledajte [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); za upit detalja pojedinačnog glasa po `_id` pogledajte [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Proces prijave

Da biste koristili Fish Model API, prvo idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications) da biste dobili svoj API Token i sačuvali ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a po završetku ćete automatski biti vraćeni na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe da se posebno prijavljujete za svaku uslugu.** Prva prijava uključuje besplatni kredit, koji omogućava besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti univerzalni saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Parametri upita

| Parametar               | Tip      | Podrazumevano  | Opis                                              |
| ---------------- | ------- | --- | ----------------------------------------------- |
| `page_size`      | integer | 10  | Broj stavki po stranici.                                           |
| `page_number`    | integer | 1   | Broj stranice počevši od 1.                                         |
| `title`          | string  | —   | Pretraga po naslovu sa delimičnim podudaranjem.                                        |
| `tag`            | string  | —   | Filtriranje po jednoj oznaci.                                        |
| `self`           | boolean | —   | Kada je `true`, vraćaju se samo glasovi koje je trenutni nalog pozivaoca kreirao i sačuvao putem ove platforme.                 |
| `author_id`      | string  | —   | Filtriranje po ID-u autora glasa.                                    |
| `language`       | string  | —   | Filtriranje po jeziku glasa, kao što su `en`, `zh`, `es`.                       |
| `title_language` | string  | —   | Filtriranje po jeziku naslova u javnoj biblioteci glasova.                                 |
| `sort_by`        | string  | —   | Polje za sortiranje; kada je `self=true`, podržani su `created_at`, `task_count`. |

> Nazivi parametara su potpuno isti kao uzvodni `GET https://api.fish.audio/model`; za detalje pogledajte [Fish zvaničnu dokumentaciju](https://docs.fish.audio/resources/api-reference/model).

## Primer 1: Podrazumevano listanje po stranicama (prema `page_size`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=2'
```

## Primer 2: Pretraga po naslovu sa delimičnim podudaranjem (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Povratni rezultat (testirano u praksi):

```json

  "items": [
```

Imajte na umu da je `title` „globalno delimično podudaranje“, koje će istovremeno pogoditi sve glasove u Fish javnoj biblioteci (ne samo sopstvene).

## Primer 3: Prikaži samo glasove koje ste sami kreirali (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Primer povratnog rezultata:

```json

  "items": [

      "state": "trained",
```

`self=true` navodi glasove kreirane i sačuvane putem ove platforme prema stvarnom pozivajućem nalogu; zajedno će biti navedeni i glasovi koje je isti nalog kreirao korišćenjem različitih API tokena. Rezultati se paginiraju po opadajućem vremenu kreiranja, a `author_id` može dodatno filtrirati ID autora ovih glasova. Ovaj parametar filtrira samo listu, glasovi i dalje ostaju javno dostupni.

`self=true` ne podržava `title_language`; ako je potrebno pretraživati prema jeziku naslova, upitajte javnu biblioteku glasova.

## Primer 4: Filtriranje prema jeziku + oznakama

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> Uzvodni servis vraća rezultate i za `tag` koji nije u rečniku oznaka, ali je podudaranje relativno labavo; ako je broj pogodaka 0, preporučuje se korišćenje nejasnog podudaranja `title`.

## Polja odgovora

Svaka stavka u `items[]` je kompletan objekat ModelEntity, često korišćena polja:

| Polje            | Tip       | Opis                                        |
| ------------- | -------- | ----------------------------------------- |
| `_id`         | string   | ID glasa, kao vrednost `reference_id` u `/fish/tts`. |
| `type`        | string   | Tip modela, obično `tts`.                           |
| `title`       | string   | Naziv glasa.                                     |
| `description` | string   | Opis glasa.                                     |
| `state`       | string   | Status treniranja: `trained` označava da je dostupan.                      |
| `tags`        | string[] | Oznake javne biblioteke.                                    |
| `languages`   | string[] | Jezici za koje je glas posebno pogodan.                                  |
| `visibility`  | string   | `public` ili `private`.                     |
| `samples`     | object[] | Unapred podešeni uzorci (uključujući direktni `audio` link).                       |
| `like_count`  | integer  | Broj sviđanja u javnoj biblioteci.                                   |
| `task_count`  | integer  | Broj istorijskih sinteza.                                   |
| `author`      | object   | Informacije o autoru glasa: `_id` / `nickname` / `avatar`.     |
| `total`（najviši nivo）   | integer  | Ukupan broj stavki koje ispunjavaju uslove.                                 |
| `has_more`    | boolean? | Kada je `self=true`, to je Bulova vrednost; upit javne biblioteke glasova može biti `null`.      |

## Objašnjenje naplate

Ovaj interfejs se ne naplaćuje — paginirani upit liste glasova je besplatna operacija. Kreiranje glasa ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) je takođe besplatno, troškovi nastaju samo prema korišćenju pri pozivanju [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) za sintezu govora.

## Obrada grešaka

- `400 token_mismatched`: Parametri zahteva nedostaju ili nisu validni.
- `401 invalid_token`: Token za autentifikaciju ne postoji ili je nevažeći.
- `429 too_many_requests`: Aktivirano je ograničenje stope naloga.
- `500 api_error`: Interna greška servera.

Primer odgovora greške:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Zaključak

Da biste iz Fish javne biblioteke odabrali glas koji ćete proslediti u `reference_id` za `/fish/tts`, najpre koristite ovaj interfejs zajedno sa `title` / `tag` / `language` za pretragu, pronađite ciljni `_id`, a zatim koristite [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) da preuzmete uzorke za preslušavanje. Da biste naveli glasove koje ste sami kreirali, dovoljno je proslediti `self=true`.
