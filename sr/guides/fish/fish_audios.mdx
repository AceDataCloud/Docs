Овај документ ће представити упутство за интеграцију Fish Audios Generation API, који може клонирати ваш глас уношењем кључних речи.

## Процес пријаве

Да бисте користили API, прво морате да одете на страницу [Fish Audios Generation API](https://platform.acedata.cloud/documents/e681b715-54fd-4464-a59a-d7f14500e095) и затражите одговарајућу услугу. Када уђете на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите. Након пријаве или регистрације, аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну количину, што вам омогућава да бесплатно користите овај API.

## Основна употреба

Прво, потребно је да разумете основни начин коришћења, а то је уношење кључне речи `prompt`, акције `action`, ID-а гласа `voice_id` и модела `model`, како бисте добили обрађени резултат. Прво, потребно је да једноставно пренесете поље `action`, чија вредност је `generate`, а затим треба да унесете модел `model`, који тренутно укључује модел `fish-tts`, а конкретни садржај је следећи:

<p><img src="https://cdn.acedata.cloud/0jnfqb.png" width="500" class="m-auto"></p>

Можете видети да смо овде подесили Request Headers, укључујући:

- `accept`: у каквом формату желите да примите одговор, овде је написано `application/json`, што значи JSON формат.
- `authorization`: кључ за позивање API-а, који можете директно изабрати након пријаве.

Такође смо подесили Request Body, укључујући:

- `model`: модел за клонирање гласа, углавном `fish-tts` модел.
- `action`: акција за клонирање гласа.
- `prompt`: кључна реч коју треба клонирати.
- `voice_id`: ID гласа за клонирање.
- `callback_url`: URL на који треба да се врати резултат.

Након избора, можете приметити да је на десној страни генерисан одговарајући код, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/8uyos2.png" width="500" class="m-auto"></p>

Кликните на дугме „Try“ да бисте тестирали, као што је приказано на горњој слици, и добићете следећи резултат:

```json
{
  "success": true,
  "task_id": "5872ab00-3cf4-4040-a798-8510aaa16756",
  "trace_id": "5eda3694-448a-4b72-af33-2acb3851ffe1",
  "data": [
    {
      "audio_url": "https://platform.r2.fish.audio/task/8a72ff9840234006a9f74cb2fa04f978.mp3"
    }
  ]
}
```

Враћени резултат има више поља, која су описана као:

- `success`, статус клонирања гласа.
  - `data`, резултат клонирања гласа
    - `audio_url`, линк на аудио резултат клонирања гласа.

Можете видети да смо добили задовољавајуће информације о гласу, а ми само треба да добијемо клонирани глас према линку у `data`.

Ако желите да генеришете одговарајући код за интеграцију, можете га директно копирати, на пример, CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/fish/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "speech",
  "prompt": "a white siamese cat",
  "model": "fish-tts",
  "voice_id": "d7900c21663f485ab63ebdb7e5905036"
}'
```

## Асинхрони повратни позив

Пошто време генерисања Fish Audios Generation API-а може бити релативно дуго, око 1-2 минута, ако API дуго не одговара, HTTP захтев ће задржати везу, што може довести до додатне потрошње системских ресурса, па овај API такође пружа подршку за асинхрони повратни позив.

Целокупни процес је: када клијент покрене захтев, додатно одређује поље `callback_url`. Након што клијент покрене API захтев, API ће одмах вратити резултат, који садржи поље `task_id`, што представља ID тренутног задатка. Када задатак буде завршен, резултат генерисања задатка ће бити послат на `callback_url` у POST JSON формату, који такође укључује поље `task_id`, тако да се резултати задатка могу повезати преко ID-а.

Испод ћемо кроз пример објаснити како конкретно да поступите.

Прво, Webhook повратни позив је услуга која може примати HTTP захтеве, а програмери би требало да замените URL своје HTTP серверске инсталације. Овде, ради лакшег демонстрирања, користићемо јавни Webhook пример са веб странице https://webhook.site/, отворите ту страницу и добићете Webhook URL, као што је приказано на слици:

![](https://cdn.acedata.cloud/tbcnai.png)

Копирајте овај URL и можете га користити као Webhook, а пример овде је `https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34`.

Након тога, можемо подесити поље `callback_url` на горњи Webhook URL, а затим унети одговарајуће параметре, конкретан садржај је приказан на слици:

<p><img src="https://cdn.acedata.cloud/8rv4te.png" width="500" class="m-auto"></p>

Кликните на „Run“, и одмах ћете добити резултат, као што је следеће:

```
{
  "task_id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5"
}
```

Након кратког чекања, можете наћи резултат генерисања задатка на `https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34`, као што је приказано на слици:

![](https://cdn.acedata.cloud/9utzve.png)

Садржај је следећи:

```json
{
    "success": true,
    "task_id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5",
    "trace_id": "e2d308bc-4df8-4c69-9369-a60f3c54f2b3",
    "data": [
        {
            "audio_url": "https://platform.r2.fish.audio/task/b627c2f7d38a4083a837570ba6d0962f.mp3"
        }
    ]
}
```

Можете видети да у резултату постоји поље `task_id`, а остала поља су слична као у претходном тексту, а преко овог поља можете повезати задатке.

## Обрада грешака

Када позивате API, ако наиђете на грешку, API ће вратити одговарајући код грешке и информације. На пример:

- `400 token_mismatched`: Лош захтев, могуће због недостајућих или неважећих параметара.
- `400 api_not_implemented`: Лош захтев, могуће због недостајућих или неважећих параметара.
- `401 invalid_token`: Неправилно, неважећи или недостајући ауторизациони токен.
- `429 too_many_requests`: Превише захтева, прелазите лимит.
- `500 api_error`: Унутрашња грешка сервера, нешто није у реду на серверу.

### Пример одговора на грешку

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
