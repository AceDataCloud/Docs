Glavna funkcija Fish Tasks API je da omogućava upit o statusu izvršenja zadatka putem ID-a zadatka generisanog putem Fish Audios Generation API.

Ovaj dokument će detaljno opisati integraciju Fish Tasks API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Fish Tasks API, možete lako ostvariti upit o statusu izvršenja zadatka iz Fish Audios Generation API.

## Proces prijave

Da biste koristili Fish Tasks API, prvo treba da odete na stranicu za prijavu [Fish Audios Generation API](https://platform.acedata.cloud/documents/e681b715-54fd-4464-a59a-d7f14500e095) i zatražite odgovarajuću uslugu, a zatim kopirajte ID zadatka iz Fish Audios Generation API, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/jxvue8.png" width="500" className="m-auto" /></p>

Na kraju, idite na stranicu Tasks API [Fish Tasks API](https://platform.acedata.cloud/documents/44c93949-1419-4a45-8db5-8a8335de7151) i zatražite odgovarajuću uslugu, nakon ulaska na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![Stranica za prijavu](https://cdn.acedata.cloud/rci31i.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na [stranicu za prijavu](https://platform.acedata.cloud) koja vas poziva da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Primer zahteva

Fish Tasks API može se koristiti za upit o rezultatima Fish Audios Generation API. O tome kako koristiti Fish Audios Generation API, molimo vas da se obratite dokumentu [Fish Videos Generation API](https://platform.acedata.cloud/documents/fish-audios-integration).

Uzmimo jedan ID zadatka koji je vratio Fish Audios Generation API kao primer i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: 2725a2d3-f87e-4905-9c53-9988d5a7b2f5, a zatim ćemo prikazati kako da ga prosledimo.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se šalje.
- `action`: način operacije nad zadatkom.

Postavite kao što je prikazano na slici:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/fish/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5",
  "action": "retrieve"
}'
```

## 错误处理

在调用 API 时，如果遇到错误，API 会返回相应的错误代码和信息。例如：

- `400 token_mismatched`：Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`：Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`：Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`：Too many requests, you have exceeded the rate limit.
- `500 api_error`：Internal server error, something went wrong on the server.

### 错误响应示例

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
