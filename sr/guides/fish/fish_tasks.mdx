Glavna funkcija Fish Tasks API-ja je da preko ID-ja zadatka generisanog pomoću Fish Audios Generation API-ja upita status izvršavanja tog zadatka.

Ovaj dokument će detaljno predstaviti uputstva za integraciju Fish Tasks API-ja, pomažući vam da lako integrišete i u potpunosti iskoristite moćne funkcije ovog API-ja. Putem Fish Tasks API-ja možete lako realizovati upit statusa izvršavanja zadataka Fish Audios Generation API-ja.

## Proces prijave

Da biste koristili Fish Audios Generation API, najpre preuzmite svoj API Token na [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications) i sačuvajte ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu, gde ćete biti pozvani da se registrujete i prijavite; nakon završetka automatski ćete se vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe za posebnom prijavom za svaku uslugu.** Prva prijava uključuje besplatni kredit za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Fish Audios Generation API →](https://platform.acedata.cloud/documents/fish-tts)

## Primer zahteva

Fish Tasks API može se koristiti za upit rezultata Fish Audios Generation API-ja. Za informacije o tome kako koristiti Fish Audios Generation API, pogledajte dokumentaciju [Fish Videos Generation API ](https://platform.acedata.cloud/documents/fish-tts-integration).

Uzećemo kao primer jedan ID zadatka vraćen od usluge Fish Audios Generation API i pokazati kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: 2725a2d3-f87e-4905-9c53-9988d5a7b2f5, a zatim ćemo pokazati kako preko prosleđivanja jednog ID-ja zadatka.

### Podešavanje zaglavlja zahteva i tela zahteva

**Request Headers** uključuje:

- `accept`: određuje da se primaju rezultati odgovora u JSON formatu, ovde unesite `application/json`.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete ga direktno izabrati iz padajuće liste.

**Request Body** uključuje:

- `id`: ID otpremljenog zadatka.
- `action`: način operacije nad zadatkom.

Podesite kao što je prikazano na slici ispod:

<p><img src="https://cdn.acedata.cloud/xc5ejq.png" width="500" className="m-auto" /></p>

### Primer koda

Možete primetiti da je na desnoj strani stranice automatski generisan kod za različite jezike, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/851zv2.png" width="500" className="m-auto" /></p>

Neki primeri koda su sledeći:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/fish/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5",
  "action": "retrieve"
}'
```


Vraćeni rezultat sadrži više polja, polje `request` je request body prilikom pokretanja zadatka, dok je polje `response` response body vraćen nakon završetka zadatka. Opis polja je sledeći.

- `id`, ID generisan za ovaj zadatak, koristi se za jedinstvenu identifikaciju ovog generisanog zadatka.
- `request`, informacije o zahtevu u zadatku upita.
- `response`, informacije o odgovoru u zadatku upita; kada je konačno uspešan, `cost.amount` u njemu predstavlja Credits stvarno oduzete za ovu sintezu.
- `created_at`, vreme kreiranja zadatka, Unix vremenska oznaka (sekunde, decimalni broj).
- `started_at`, vreme početka izvršavanja zadatka, Unix vremenska oznaka (sekunde, decimalni broj).
- `finished_at`, vreme završetka zadatka, Unix vremenska oznaka (sekunde, decimalni broj). Ovo polje se ne vraća kada zadatak nije završen.
- `elapsed`, trajanje izvršavanja zadatka, u sekundama (decimalni broj, zadržava 3 decimale). Ovo polje se ne vraća kada zadatak nije završen.

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Neispravan zahtev, verovatno zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Neispravan zahtev, verovatno zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Nije autorizovano, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, prekoračili ste ograničenje broja zahteva.
- `500 api_error`：Interna greška servera, nešto je pošlo po zlu na serveru.

### Primer odgovora o grešci
