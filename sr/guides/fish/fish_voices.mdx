Овај документ ће представити упутство за интеграцију Fish Voices Generation API, који вам омогућава да креирате свој тон уношењем линка на аудио.

## Процес пријаве

Да бисте користили API, прво морате да одете на [Fish Voices Generation API](https://platform.acedata.cloud/documents/55e61b64-ac7d-4710-a7f1-57a4ba786b17) одговарајућу страницу и затражите одговарајућу услугу, након што уђете на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, након пријаве или регистрације, аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, коју можете користити за API.

## Основна употреба

Прво, упознајте се са основним начином коришћења, а то је уношење линка на аудио `voice_url`, чиме добијате обрађени резултат, конкретан садржај је следећи:

<p><img src="https://cdn.acedata.cloud/278ikr.png" width="500" className="m-auto" /></p>

Можете видети да смо подесили Request Headers, укључујући:

- `accept`: каквог формата желите да примите одговор, овде је написано `application/json`, што значи JSON формат.
- `authorization`: кључ за позивање API, након захтева можете директно изабрати из падајућег менија.

Такође смо подесили Request Body, укључујући:

- `voice_url`: линк на аудио тон.
- `title`: информације о наслову тог тона.
- `image_urls`: слика насловне стране тог тона.
- `description`: информације о опису тог тона.
- `callback_url`: URL на који треба да се врати резултат.

Након избора, можете приметити да је на десној страни генерисан одговарајући код, као што је приказано на слици:

Ако желите да генеришете одговарајући код за интеграцију, можете га директно копирати, на пример CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/fish/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "voice_url": "https://platform.r2.fish.audio/task/604133d7b3c7430385382470f67770e8.mp3",
  "title": "test",
  "description": "test"
}'
```

## Асинхрони повратни позив

Пошто време генерисања Fish Voices Generation API траје релативно дуго, око 1-2 минута, ако API дуго не одговара, HTTP захтев ће задржати везу, што доводи до додатне потрошње системских ресурса, па овај API такође пружа подршку за асинхрони повратни позив.

Целокупни процес је: када клијент покрене захтев, додатно одређује поље `callback_url`, након што клијент покрене API захтев, API ће одмах вратити резултат, који садржи информације о пољу `task_id`, што представља ID тренутног задатка. Када задатак буде завршен, резултат генерисања задатка ће бити послат на `callback_url` који је клијент одредио у POST JSON формату, а који такође укључује поље `task_id`, тако да се резултат задатка може повезати преко ID.

Хајде да погледамо пример како конкретно извршити операцију.

Прво, Webhook повратни позив је услуга која може примити HTTP захтев, програмери би требало да замените URL своје HTTP серверске инсталације. Овде, ради лакшег демонстрирања, користићемо јавни Webhook пример са веб странице https://webhook.site/, отворите ту страницу и добићете Webhook URL, као што је приказано на слици:

![](https://cdn.acedata.cloud/tbcnai.png)

Копирајте овај URL и можете га користити као Webhook, пример овде је `https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34`.

Након тога, можемо подесити поље `callback_url` на горњи Webhook URL, истовремено уносећи одговарајуће параметре, конкретан садржај је као на слици:

<p><img src="https://cdn.acedata.cloud/ecbq1s.png" width="500" className="m-auto" /></p>

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neautorizovano, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### Primer odgovora na grešku

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
