Овај интерфејс се заснива на [Fish Audio званичном Model API](https://docs.fish.audio/resources/api-reference/model) и служи за **креирање модела звука који се може дугорочно користити на основу аудио узорка**. Адреса је `POST https://api.acedata.cloud/fish/model`.

> Ако вам је потребно само привремено коришћење референтног звука, није потребно креирати модел, можете директно користити [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) `references` за једнократну моменталну клонирање. За пагинацију постојећих тонова, молимо вас да се упутите на [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query); за упит детаља о појединачном тону по `_id`, молимо вас да се упутите на [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Процес пријаве

Да бисте користили Fish Model API, прво идите на [Ace Data Cloud контролни панел](https://platform.acedata.cloud/console/applications) да добијете ваш API токен, за резерву.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након тога ћете бити аутоматски враћени на тренутну страницу.

**Један API токен је довољан за позивање свих услуга платформе, није потребно посебно пријављивати за сваку услугу.** При првом захтеву добићете бесплатну квоту за пробу; ако вам квота недостаје, можете допунити општи баланс на [контролном панелу](https://platform.acedata.cloud/console/coin).

> 📘 Пуна документација: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Полиња захтева

| Полиње                  | Тип       | Обавезно | Објашњење                                                                        |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | Да   | Име звука, користи се за идентификацију у списку на контролном панелу.                     |
| `voices`                | string   | Да   | HTTP(S) URL аудио узорка (**један стринг**, није низ). Овај интерфејс не подржава multipart/бинарно учитавање, молимо вас да прво поставите аудио у било који јавни објекат за складиштење. |
| `description`           | string   | Не   | Опис звука.                                                                       |
| `cover_image`           | string   | Не   | HTTP(S) URL слике на корици.                                                    |
| `tags`                  | string[] | Не   | Тагови за претрагу у јавном каталогу, на пример `["male","narration","zh"]`.                     |
| `texts`                 | string[] | Не   | Референтни текстови који одговарају узорцима (за корекцију изговора).                     |
| `enhance_audio_quality` | boolean  | Не   | Да ли побољшати квалитет звука пре обуке.                                          |
| `generate_sample`       | boolean  | Не   | Да ли аутоматски генерисати пример аудио записа након завршене обуке.                  |

> Полиња су потпуно идентична са upstream-ом, молимо вас да се упутите на [Fish званичну документацију](https://docs.fish.audio/resources/api-reference/model).

## Пример: Креирање приватног клонираног звука

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "Мој клонирани звук",
    "description": "Клонирани кинески звук из подкаст записа",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Напомена: `voices` мора бити **стринг** (један аудио URL), а не низ. Ако се пошаље као `["..."]`, upstream ће одбити.

Успешан одговор директно враћа ModelEntity објекат Fish платформе (доле је пример минималног доступног звука који смо тестирали, уклонили смо неке дуге поља ради читања):

`_id` може се користити као вредност за поље `reference_id` у [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) за синтезу говора користећи овај клонирани звук:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，这是一段使用我刚创建的克隆音色合成的语音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Захтеви за узорке

Искуство (исто као и upstream, можете се упутити на [Fish званичну документацију](https://docs.fish.audio/resources/api-reference/model)):

- Дужина се препоручује 30 секунди или више, а најбоље је до 5 минута; преко 10 минута маргинална добит није велика.
- Учесталост узорковања 16 kHz или више, моно или стерео.
- Садржај треба да буде што чистији: без позадинске музике, еха, очигледне буке из окружења; исти говорник.
- Формат се препоручује `mp3` / `wav`.

Ако нисте сигурни у квалитет узорка, можете истовремено послати `enhance_audio_quality: true` да би upstream прво побољшао квалитет звука.

## Објашњење наплате

Креирање модела клонираног звука (`POST /fish/model`) је бесплатно, не наплаћује се; интерфејси за упит звука ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query), [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) такође не наплаћују. Наплата се јавља само при каснијем позиву [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) за синтезу говора.

## Обрада грешака
- `400 token_mismatched`：Parametri zahteva su nedostajući ili nevažeći (najčešće je `voices` nije URL, ili je prosleđen kao niz).
- `401 invalid_token`：Token za autentifikaciju ne postoji ili je nevažeći.
- `429 too_many_requests`：Aktiviran je limit brzine naloga.
- `500 api_error`：Interna greška servera.

Primer greške u odgovoru:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices je obavezan i mora biti HTTP(S) URL koji upućuje na audio fajl"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Zaključak

Za pozivanje ovog interfejsa potrebno je pripremiti javno dostupnu URL adresu uzorka audio zapisa, staviti je u polje `voices` i tako dobiti `_id`, a zatim ga proslediti `reference_id` za `/fish/tts` kako bi se završio proces „kloniranja → sinteze“. Uobičajena zamka je da `voices` mora biti string, ne može biti niz.
