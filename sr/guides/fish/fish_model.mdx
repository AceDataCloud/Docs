Ovaj dokument opisuje uputstvo za integraciju Fish Model API-ja, koji je potpuno kompatibilan sa [Fish Audio zvaničnim OpenAPI-jem](https://docs.fish.audio/resources/api-reference/model). API uključuje:

- `POST /fish/model`: Kreiranje novog kloniranog glasa (Voice Model) baziranog na audio uzorku.
- `GET /fish/model`: Paginarano pretraživanje liste glasova vidljivih na trenutnom nalogu ili celoj platformi.

## Proces prijave

Da biste koristili API, potrebno je da se prijavite za odgovarajuću uslugu na stranici [Fish Model API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509). Nakon ulaska na stranicu, kliknite na dugme „Acquire“.

Ukoliko niste prijavljeni ili registrovani, bićete preusmereni na stranicu za prijavu i registraciju. Nakon uspešne prijave ili registracije, bićete vraćeni na prethodnu stranicu.

Prilikom prve prijave dobijate besplatan kredit za korišćenje API-ja.

## Razlike u odnosu na zvanični API

- **Metod autentifikacije**: Koristi se `Authorization: Bearer {token}`, gde je `{token}` ključ dobijen na ovoj platformi.
- **Slanje uzoraka prilikom kreiranja modela**: Ovaj API trenutno podržava samo JSON format sa URL-ovima audio uzoraka prosleđenim kroz polje `voices`. Zvanični Fish API podržava multipart/msgpack direktno slanje binarnih podataka, što na ovoj platformi još nije implementirano. URL forma pokriva oko 80% uobičajenih slučajeva.
- **Struktura odgovora**: `POST /fish/model` i `GET /fish/model` direktno prosleđuju odgovore sa Fish platforme, bez dodatnog omotača. U slučaju greške koristi se standardna struktura platforme `{success:false, error:{code,message}, trace_id}`.

## Kreiranje glasa (POST /fish/model)

Minimalni zahtev za kreiranje sadrži polja `title` i `voices`. `voices` je lista URL-ova audio uzoraka, preporučeno je da svaki fajl traje najmanje 30 sekundi sa uzorkovanjem od 16kHz ili više.

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的音色",
    "voices": [
      "https://example.com/sample-voice.mp3"
    ],
    "cover_image": "https://example.com/cover.png",
    "visibility": "private"
  }'
```

Uspešan odgovor vraća ModelEntity objekat sa Fish platforme:

```json
{
  "_id": "d7900c21663f485ab63ebdb7e5905036",
  "type": "tts",
  "title": "我的克隆音色",
  "description": "用一段播客录音克隆的音色",
  "cover_image": "https://example.com/cover.png",
  "train_mode": "fast",
  "state": "trained",
  "tags": [],
  "samples": [],
  "created_at": "2025-05-09T12:34:56.789Z",
  "updated_at": "2025-05-09T12:34:56.789Z",
  "languages": ["zh", "en"],
  "visibility": "private",
  "lock_visibility": false,
  "like_count": 0,
  "mark_count": 0,
  "shared_count": 0,
  "task_count": 0,
  "author": {
    "_id": "user_id",
    "nickname": "user_nickname",
    "avatar": "user_avatar"
  }
}
```

Vraćeni `_id` se koristi kao vrednost polja `reference_id` u narednim pozivima `POST /fish/tts` za sintezu glasa sa ovim kloniranim glasom.

## Pretraga liste glasova (GET /fish/model)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=10' \
  --data-urlencode 'page_number=1' \
  --data-urlencode 'self=true'
```

Dostupni parametri za pretragu (isti kao kod Fish zvaničnog API-ja):

- `page_size`: broj stavki po strani, podrazumevano 10.
- `page_number`: broj strane, počinje od 1.
- `title`: pretraga po naslovu sa delimičnim poklapanjem.
- `tag`: filtriranje po oznakama.
- `self`: ako je `true`, vraćaju se samo glasovi kreirani na trenutnom nalogu.
- `author_id`: filtriranje po autoru.
- `language`: filtriranje po jeziku glasa.
- `title_language`: filtriranje po jeziku naslova.

Uspešan odgovor direktno prosleđuje paginiranu strukturu sa Fish platforme:

```json
{
  "items": [
    {
      "_id": "d7900c21663f485ab63ebdb7e5905036",
      "title": "我的克隆音色",
      "description": "用一段播客录音克隆的音色",
      "cover_image": "https://example.com/cover.png",
      "type": "tts",
      "state": "trained",
      "tags": [],
      "languages": ["zh", "en"],
      "visibility": "private",
      "created_at": "2025-05-09T12:34:56.789Z",
      "updated_at": "2025-05-09T12:34:56.789Z"
    }
  ],
  "total": 1
}
```

## Naplata

Ovaj API naplaćuje samo kreiranje glasa (`POST /fish/model` sa poljem `voices` u telu zahteva). Pretraga liste glasova (`GET /fish/model`) nije naplaćena.

## Obrada grešaka

- `400 token_mismatched`: Loš zahtev, moguće nedostaju ili su neispravni parametri.
- `400 api_not_implemented`: Loš zahtev, moguće nedostaju ili su neispravni parametri.
- `401 invalid_token`: Nije autorizovano, nevažeći ili nedostajući token.
- `429 too_many_requests`: Previše zahteva, prekoračen limit.
- `500 api_error`: Interna greška servera.

### Primer odgovora sa greškom

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Zaključak

Fish Model API je potpuno kompatibilan sa ModelEntity interfejsom zvaničnog Fish Audio OpenAPI-ja, što omogućava migraciju postojećeg koda za upravljanje kloniranim glasovima bez izmene koda. Kreirani `_id` glasa može se direktno koristiti kao vrednost polja `reference_id` u [Fish TTS API-ju](https://platform.acedata.cloud/documents/77adcb84-d59f-5ef9-b8a0-8b35eb42a71d) za sintezu govora.
