Ово ће описати инструкције за интеграцију Fish TTS API, који је потпуно компатибилан са [Fish Audio званичним OpenAPI-jem](https://docs.fish.audio/text-to-speech/text-to-speech), што омогућава директно преношење кода који позива `https://api.fish.audio/v1/tts` на `https://api.acedata.cloud/fish/tts`, уз само замену информација о ауторизацији, без измена у структури захтева.

## Процес пријаве

Да бисте користили API, потребно је да прво аплицирате за одговарајућу услугу на страници [Fish TTS API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509). Након уласка на страницу, кликните на дугме „Acquire“.

Ако нисте пријављени или регистровани, бићете аутоматски преусмерени на страницу за пријаву/регистрацију, а након пријаве или регистрације бићете враћени на тренутну страницу.

При првој апликацији добићете бесплатни кредит за тестирање API-ја.

## Разлике у односу са званичним API-јем

Овај API задржава све поља захтева и одговора из Fish Audio званичног API-а, али има следећа мала унапређења ради боље интеграције на нашој платформи:

- **Начин аутентификације**: користи `Authorization: Bearer {token}`, где је `{token}` кључ који добијате на нашој платформи, а не Fish званични кључ.
- **Избор TTS модела**: путем HTTP заглавља `model`, могуће је изабрати `s1` или `s2-pro`, са подразумеваном вредношћу `s2-pro`. Ово је у складу са Fish-ом.
- **Подешавање `latency`**: ако у захтеву не доставите `latency`, оригинални `/fish/v1/tts` ће враћати грешку. Овај API ће у таквим случајевима аутоматски додати `latency=normal`, што је у складу са подразумеваним понашањем Fish-а.
- **Асимптотски позиви (екстерна проширења)**: ако у телу захтева пошаљете додатно поље `callback_url`, API ће одмах вратити `{task_id, started_at}`; након што оригинални процес заврши, резултат у виду `{audio_url, ...}` ће бити послан POST-ом у `callback_url` у JSON формату, са истим `task_id`. Fish API не подржава овај појам, али ми га користимо за асинхроно обрађивање.

Остала поља у телу захтева (`text`, `reference_id`, `references`, `prosody`, `format`, `sample_rate`, `mp3_bitrate`, `chunk_length`, `temperature`, `top_p` итд.) се директно прослеђују оригиналном API-ју, без измена.

## Основна употреба

Најминималнији захтев садржи само поље `text`. Пример CURL:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s2-pro' \
  -d '{
    "text": "Данас је леп дан, изађимо у шетњу."
  }'
```

Резултат:

```json
{
  "audio_url": "https://platform.r2.fish.audio/task/8a72ff9840234006a9f74cb2fa04f978.mp3"
}
```

Резултат садржи званично поље `audio_url`, које можете директно преузети или репродуковати.

Ако желите да користите клонирање гласова, у тело захтева додајте `reference_id`:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s2-pro' \
  -d '{
    "text": "Данас је леп дан, изађимо у шетњу.",
    "reference_id": "d7900c21663f485ab63ebdb7e5905036",
    "format": "mp3",
    "sample_rate": 44100
  }'
```

## Асимптотски позиви (callback)

Пошто је процес генерисања дугих текстова можда дуготрајан, овај API подржава асинхроно позивање (што је проширење у односу на званични Fish API).

Процес је следећи: ако у телу захтева пошаљете `callback_url`, API ће одмах вратити `{task_id, started_at}`; након што процес заврши, резултат у виду `audio_url` и осталих поља ће бити послат POST-ом у `callback_url`, уз `task_id` за идентификацију.

Пример захтева:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s2-pro' \
  -d '{
    "text": "Данас је леп дан, изађимо у шетњу.",
    "callback_url": "https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34"
  }'
```

Одговор:

```json
{
  "task_id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5",
  "started_at": "2025-05-09T12:34:56.789Z"
}
```

Након неког времена, `callback_url` ће добити потпуни резултат:

```json
{
  "task_id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5",
  "audio_url": "https://platform.r2.fish.audio/task/b627c2f7d38a4083a837570ba6d0962f.mp3"
}
```

Можете такође користити [Fish Tasks API](https://platform.acedata.cloud/documents/fc541fac-a941-47fd-b6f7-48d6cb9da523) за активну проверу статуса по `task_id`.

## Обрада грешака

Грешке у овом API-ју задржавају званичне HTTP статусе Fish-а, али тело одговора има унифицирани формат како би било усклађено са `/fish/audios`, `/fish/voices` серијама:

- `400 token_mismatched` — лош захтев, могуће да недостаје или је неважећи параметар
- `400 api_not_implemented` — лош захтев, могуће да је функција недоступна
- `401 invalid_token` — неовлашћен, неважећи или недостајући токен
- `429 too_many_requests` — превише захтева, достигнут лимит
- `500 api_error` — унутрашња грешка сервера

Пример одговора на грешку:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Закључак

Fish TTS API је потпуно компатибилан са Fish Audio званичним OpenAPI-jem, што омогућава миграцију без измена у коду. Такође, коришћењем платформских могућности добијате унифицирану аутентификацију, праћење коришћења и асинхроно обрађивање. За дуге текстове препоручује се коришћење асинхроних позива како би се избегло оптерећење везе.
