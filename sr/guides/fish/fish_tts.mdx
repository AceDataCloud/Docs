Ovaj interfejs pruža pretvaranje teksta u govor, pozivanje sačuvanih glasova i jednokratno trenutno kloniranje glasa, a adresa je `POST https://api.acedata.cloud/fish/tts`.

## Postupak prijave

Da biste koristili Fish TTS API, prvo idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications) da biste dobili svoj API Token, i sačuvajte ga za kasnije.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a po završetku ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe da se posebno prijavljuje za svaku uslugu.** Prva prijava daje besplatan kredit, koji možete besplatno isprobati; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Fish TTS API →](https://platform.acedata.cloud/services/fish)

## Zaglavlja zahteva

| Header          | Obavezno  | Objašnjenje                                                                                                     |
| --------------- | --- | ------------------------------------------------------------------------------------------------------ |
| `authorization` | Da   | `Bearer {token}`, gde je `{token}` ključ prijavljen na ovoj platformi.                                                                 |
| `content-type`  | Da   | `application/json`.                                                                                    |
| `accept`        | Ne   | `application/json`.                                                                                    |
| `model`         | Ne   | TTS model, opcionalno `s1`, `s2-pro` ili `s2.1-pro`, podrazumevano `s2-pro`. `s2.1-pro` je najnovija generacija, `s2-pro` ima snažnu izražajnost; `s1` je stabilniji i manje odstupa kod dugog teksta. Sva tri imaju istu cenu. |

## Polja tela zahteva

| Polje             | Tip                 | Obavezno  | Objašnjenje                                                                                                                                                                                                     |
| -------------- | ------------------ | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `text`         | string             | Da   | Tekst koji treba sintetizovati, neprazan string.                                                                                                                                                                                          |
| `format`       | string             | Ne   | Format izlaznog zvuka, opcionalno `mp3` (podrazumevano), `wav`, `pcm`. I `wav` i `pcm` vraćaju WAV kontejner. `opus` nije podržan, a njegovo prosleđivanje direktno vraća `400`.                                                                                                                  |
| `reference_id` | string \| string[] | Ne   | ID modela sačuvanog ili javnog glasa, može se kreirati putem [Fish Model API](https://platform.acedata.cloud/documents/fish-model), ili pretražiti u [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query). Ne može se koristiti istovremeno sa `references`. |
| `references`   | object[]           | Ne   | Jednokratno trenutno kloniranje glasa, podržava samo jedan uzorak `{audio, text}`: `audio` je javni HTTPS MP3/WAV URL, a `text` je tačan doslovni transkript zvuka. Ne može se koristiti istovremeno sa `reference_id`.                                                                                             |
| `sample_rate`  | integer            | Ne   | Frekvencija uzorkovanja, često se koriste `16000`, `22050`, `44100`. Podrazumevana vrednost za `format=mp3` je 44100.                                                                                                                                                  |
| `mp3_bitrate`  | integer            | Ne   | MP3 bitska brzina, opcionalno `64`, `128`, `192`. Važi samo za `format=mp3`.                                                                                                                                                          |
| `prosody`      | object             | Ne   | Nadjačavanje prozodije, podržava `speed` (brzina govora, 1.0 je originalna brzina) i `volume` (pojačanje jačine zvuka u dB). Na primer `{"speed":1.2,"volume":0}`.                                                                                                                          |
| `chunk_length` | integer            | Ne   | Dužina uzvodnog segmenta, podrazumevano određuje uzvodna strana.                                                                                                                                                                                         |
| `temperature`  | number             | Ne   | Temperatura uzorkovanja, opseg je približno 0.0–1.0.                                                                                                                                                                                      |
| `top_p`        | number             | Ne   | Parametar top-p uzorkovanja.                                                                                                                                                                                            |
| `latency`      | string             | Ne   | `normal` ili `balanced`, ako je izostavljeno, ovaj interfejs automatski dodaje `normal` (direktno prosleđivanje praznog stringa uzvodna strana će odbiti).                                                                                                                                                |
| `normalize`    | boolean            | Ne   | Da li normalizovati tekst.                                                                                                                                                                                             |
| `callback_url` | string             | Ne   | Adresa asinhronog povratnog poziva, detalje pogledajte u nastavku pod „Asinhroni povratni poziv“. **Ovo je proširenje u odnosu na zvanični interfejs**.                                                                                                                                                                     |

> Jednokratno kloniranje prihvata samo HTTPS URL-ove zvuka, ne prihvata MessagePack, Base64, data URI ili URL-ove sa akreditivima. Preporučuje se da referentni zvuk traje 10–270 sekundi; Studio koristi konzervativniji opseg od 10–60 sekundi.

## Primer 1: minimalni zahtev (`text` + `format=mp3`)

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hello world.",
    "format": "mp3"
  }'
```

Odgovor (testirano):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/e2ffcc06-18da-4a8c-b9aa-9337d0f9ec1d-230825dfc559.mp3"
}
```

`audio_url` pokazuje na CDN ove platforme, može se direktno preuzeti putem GET-a ili reprodukovati u `<audio>`. Konačni uspešni odgovor će takođe vratiti `cost` na najvišem nivou, gde je `amount` stvarno odbijeni broj Credits za ovaj put; ako postoji popust na nalogu, `list_amount` predstavlja kredit pre popusta. Veza je dugoročno dostupna, ali se ipak preporučuje da zadržite kopiju u sopstvenom skladištu.

## Primer 2: korišćenje kloniranog glasa `reference_id`

U nastavku se koristi javni španski glas na Fish platformi (`_id` se može dobiti pretragom putem [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)):

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

Odgovor (testirano):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/b6f161f2-a100-4818-add2-47694f234659-6532864739de.mp3"
}
```

## Primer 3: jednokratno trenutno kloniranje glasa (`references`)

Postavite referentni zvuk na javnu HTTPS adresu i navedite tačan originalni tekst koji je zaista izgovoren u njemu. Ovaj glas se koristi samo za ovu sintezu i neće kreirati dugoročni model:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s2-pro' \
  -d '{
    "text": "新的旅程从这一刻开始，让我们一起向前。",
    "format": "mp3",
    "references": [{
      "audio": "https://cdn.acedata.cloud/assets/examples/fish/6220d605-39d0-4d43-9e58-0f12949dc9b9-570cfdf96ad9.mp3",
      "text": "春天的清晨，阳光穿过树叶，落在安静的小路上。"
    }]
  }'
```
Uspešan odgovor iz testiranja:

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/995dfe37-b187-474d-8323-b08d6678ed8f-6359be9f8873.mp3",
  "cost": {"amount": 0.007609319999999999, "currency": "credit"}
}
```

| Metod             | Životni ciklus       | Primenljivi scenariji                          |
| -------------- | ---------- | ----------------------------- |
| `references`   | Samo za ovaj TTS zahtev | Privremena upotreba ili drugačiji glas pri svakom pozivu                   |
| `reference_id` | Može se ponovo koristiti      | Javni glasovi ili dugoročni glasovi kreirani putem `/fish/model` |

## Primer 3: Podešavanje brzine govora / jačine zvuka (`prosody`)

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Faster speech with prosody overrides.",
    "prosody": { "speed": 1.2, "volume": 0 },
    "format": "mp3"
  }'
```

Povratna vrednost (testirano):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
}
```

`speed` veći od 1 ubrzava, manji od 1 usporava; jedinica za `volume` je dB, 0 označava bez promene, pozitivan broj pojačanje, negativan broj prigušenje.

## Primer 5: Promena modela + kontrola bitrejt-a

Prebacite se na stabilni model putem HTTP zaglavlja `model: s1`, a u telo zahteva dodajte `mp3_bitrate: 128` za kontrolu MP3 bitrejt-a:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s1' \
  -d '{
    "text": "high bitrate mp3",
    "format": "mp3",
    "mp3_bitrate": 128
  }'
```

Povratna vrednost (testirano):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/7e7abf3d-3d72-4c9f-8eb6-8af932d7c96e-6f11bf2f30e9.mp3"
}
```

## Primer 6: PCM sirovi talasni oblik

Za scenarije gde je potrebno vršiti spajanje u realnom vremenu u pregledaču ili naknadnu obradu na klijentu (miksovanje, promena brzine), preporučuje se korišćenje `pcm`:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "hi",
    "format": "pcm",
    "sample_rate": 16000
  }'
```

Povratna vrednost (testirano):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/64adc04b-c196-4a0f-9070-222ba101ce6c-fc50de38c165.wav"
}
```

> Ekstenzija linka prati `format` u zahtevu: `mp3` daje `.mp3`, a `wav` i `pcm` daju `.wav` (WAV kontejner, 16-bitni PCM).

## Asinhroni povratni poziv (`callback_url`)

Jednokratna sinteza dugog teksta može trajati od desetak do nekoliko desetina sekundi, a ako se veza prekine potrebno je ponoviti pokušaj. Nakon prosleđivanja `callback_url` u telu zahteva, interfejs će odmah vratiti `{task_id, started_at}`, a kada nadređeni sistem stvarno završi, kompletan rezultat će biti poslat kao POST JSON povratni poziv na taj URL, sa istim `task_id` i najvišim nivoom `cost` za konačnu naplatu ovog puta. Početna potvrda zadatka još nije završila sintezu, stoga ne uključuje `cost`.

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "今天天气真好，我们一起出去散散步吧。",
    "format": "mp3",
    "callback_url": "https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34"
  }'
```

Odmah vraća (testirano):

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "started_at": 1778462584.742
}
```

Kasnije će `callback_url` primiti nešto poput:

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/bd66b8c5-7543-4557-b684-baa72407e336-52f2e79732f2.mp3"
}
```

Takođe možete aktivno preuzeti rezultat po `task_id` koristeći [Fish Tasks API](https://platform.acedata.cloud/documents/fish-tasks); `response.cost` zapisa u završnom stanju je isti kao `cost` u povratnom pozivu, detalje pogledajte u toj dokumentaciji.

## Obrada grešaka

- `400 token_mismatched`: Parametri zahteva nedostaju ili nisu validni (najčešće je `text` prazan ili je za `format` prosleđena vrednost koja nije `mp3`/`wav`/`pcm`).
- `401 invalid_token`: Token za autentifikaciju ne postoji ili je nevažeći.
- `429 too_many_requests`: Aktivirano je ograničenje brzine naloga.
- `500 api_error`: Interna greška servera.

Primer odgovora na grešku:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

Greške validacije parametara će u polju `message` navesti nevažeće polje, na primer:

```json
{
  "status": 400,
  "message": "[{\"type\":\"literal_error\",\"loc\":[\"format\"],\"msg\":\"Input should be 'pcm' or 'mp3'\",\"input\":\"wav\"}]"
}
```

## Zaključak

Minimalni trošak integracije Fish TTS-a je: u postojećem kodu koji poziva `api.fish.audio/v1/tts` zamenite autentifikaciju tokenom ove platforme i u telu zahteva **eksplicitno navedite** `format: "mp3"`. Za scenarije sa dugim tekstom preporučuje se asinhroni povratni poziv putem `callback_url`; za pronalaženje kloniranog glasa `reference_id`, koristite [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) i [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get).
