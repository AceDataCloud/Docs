Ovaj dokument opisuje uputstvo za integraciju Fish Model Get API-ja (`GET /fish/model/{id}`), koji je potpuno kompatibilan sa [Fish Audio zvaničnim OpenAPI](https://docs.fish.audio/resources/api-reference/model) i koristi se za **dobijanje kompletnog detalja pojedinačnog kloniranog tona na osnovu ID-ja tona**.

> Za kreiranje tona pogledajte [Fish Model Create API](https://platform.acedata.cloud/documents/62fdf4f1-6a05-4d92-bb15-1bf78b27a14a), a za paginirano listanje koristite [Fish Model Query API](https://platform.acedata.cloud/documents/5a9b3e03-2896-5606-a6b9-d9f4469f0e9d).

## Proces Zahteva

Da biste koristili API, potrebno je da se prijavite za odgovarajuću uslugu na stranici [Fish Model API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509), zatim kliknite na dugme „Acquire“.

Ako niste prijavljeni ili registrovani, bićete automatski preusmereni na stranicu za prijavu gde možete da se registrujete i prijavite, a nakon toga bićete vraćeni na trenutnu stranicu.

Prilikom prve prijave dobijate besplatan kredit za korišćenje API-ja.

## Razlike u Odnosu na Zvanični API

- **Metod autentifikacije**: koristi se `Authorization: Bearer {token}`, gde je `{token}` ključ dobijen na ovoj platformi.
- **Struktura odgovora**: direktno se prosleđuje ModelEntity objekat sa Fish platforme, bez dodatnog omotača; u slučaju greške koristi se standardna struktura platforme `{success:false, error:{code,message}, trace_id}`.
- **Parametar u putanji**: `{id}` je `_id` tona, koji se može dobiti prilikom kreiranja preko [Fish Model Create API](https://platform.acedata.cloud/documents/62fdf4f1-6a05-4d92-bb15-1bf78b27a14a) ili paginiranog pretraživanja preko [Fish Model Query API](https://platform.acedata.cloud/documents/5a9b3e03-2896-5606-a6b9-d9f4469f0e9d).

## Primer Zahteva

```shell
curl 'https://api.acedata.cloud/fish/model/d7900c21663f485ab63ebdb7e5905036' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}'
```

Potrebno je samo zameniti `{id}` u URL putanji sa konkretnim ID-jem tona, bez dodatnih parametara upita ili tela zahteva.

## Informacije o Naplati

Ovaj API nije naplaćen — pretraga tona po ID-ju je besplatna, naplata se vrši samo za `POST /fish/model` kada se u telu zahteva šalje polje `voices` za kreiranje novog tona.

## Obrada Grešaka

- `400 token_mismatched`: nedostaju ili su neispravni parametri zahteva.
- `400 api_not_implemented`: zahtevani metod ili parametri trenutno nisu podržani.
- `401 invalid_token`: nedostaju ili su nevažeći podaci za autentifikaciju.
- `404 not_found`: ton sa zadatim `_id` ne postoji ili nije vidljiv za trenutni nalog.
- `429 too_many_requests`: prekoračena je brzinska granica za trenutni nalog.
- `500 api_error`: interna greška servera.

### Primer Odgovora sa Greškom

```json
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Zaključak

Fish Model Get API pruža potpuno kompatibilnu funkcionalnost sa Fish Audio zvaničnim API-jem za dobijanje detalja pojedinačnog tona. Nakon dobijanja ID-ja tona, ovaj API omogućava preuzimanje kompletnog ModelEntity objekta (uključujući uzorke, status, vidljivost, statističke podatke itd.), koji se može koristiti zajedno sa [Fish TTS API](https://platform.acedata.cloud/documents/77adcb84-d59f-5ef9-b8a0-8b35eb42a71d) za kompletan proces kloniranja i sinteze glasa.
