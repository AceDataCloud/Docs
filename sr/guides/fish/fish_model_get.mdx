Овај интерфејс се заснива на [Fish Audio званичном Model API](https://docs.fish.audio/resources/api-reference/model) и служи за **према `_id` упит за комплетне детаље о једној клонској боји гласа**. Адреса је `GET https://api.acedata.cloud/fish/model/{id}`.

> За креирање боје гласа, молимо вас да се упутите на [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); за пагинацију, молимо вас да се упутите на [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query).

## Процес пријаве

Да бисте користили Fish Model API, прво идите на [Ace Data Cloud контролну таблу](https://platform.acedata.cloud/console/applications) да добијете ваш API токен, за резерву.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ако нисте пријављени или регистровани, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након тога ћете бити аутоматски враћени на тренутну страницу.

**Један API токен је довољан за позивање свих услуга платформе, није потребно посебно пријављивати за сваку услугу.** При првом захтеву добијате бесплатан кредит, можете бесплатно да искористите; када вам кредит буде недовољан, можете допунити општи баланс на [контролној табли](https://platform.acedata.cloud/console/coin).

> 📘 Пуна документација: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Параметри пута

| Параметар | Обавезно | Објашњење                                                                                                                                                                                                |
| --------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`      | Да       | `_id` боје гласа (32-цифрени хексадецимални низ). Можете га добити када креирате [Fish Model Create](https://platform.acedata.cloud/documents/fish-model) или га добити преко [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query). |

Нема тела захтева, нема параметара упита.

## Пример: преузимање комплетних детаља о јавном шпанском гласу

```shell
curl 'https://api.acedata.cloud/fish/model/8d2c17a9b26d4d83888ea67a1ee565b2' \
  -H 'authorization: Bearer {token}'
```

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

## Разлике у односу на интерфејс списка

| Поље                                               | `GET /fish/model` (лист) | `GET /fish/model/{id}` (детаљи) |
| -------------------------------------------------- | ------------------------- | -------------------------------- |
| `samples[].audio`                                  | Краткорочни R2 кеш URL    | Тренутна R2 директна веза (са потписом) |
| `unliked` / `liked` / `marked` / `dmca_taken_down` | Такође постоји            | Такође постоји                   |
| `default_text` / `lock_visibility`                 | Такође постоји            | Такође постоји                   |

Ако само желите да чујете, `samples[].audio` у интерфејсу списка је довољно; за стабилније линкове за преузимање, препоручује се коришћење овог интерфејса.

## Polja odgovora (izvod)

| Polje          | Tip     | Opis                                                                |
| ------------- | -------- | ------------------------------------------------------------------- |
| `_id`         | string   | ID boje glasa (koristi se za `reference_id` u okviru `/fish/tts`).                     |
| `type`        | string   | Tip modela, obično `tts`.                                           |
| `title`       | string   | Naziv boje glasa.                                                          |
| `description` | string   | Detaljan opis.                                                            |
| `state`       | string   | Status obuke: `trained` znači da je dostupan, a `training` znači da se još obučava.              |
| `tags`        | string[] | Oznake javne biblioteke.                                                        |
| `samples`     | object[] | Unapred postavljeni uzorci, uključujući direktne veze za `title`, `text`, `task_id` i `audio`.              |
| `languages`   | string[] | Jezički kodovi za koje je glas najprikladniji.                                                |
| `visibility`  | string   | `public` ili `private`.                                             |
| `like_count`  | integer  | Broj sviđanja u javnoj biblioteci.                                                      |
| `task_count`  | integer  | Broj istorijskih sinteza (može se koristiti kao referenca za rangiranje po popularnosti).                                |
| `author`      | object   | Informacije o autoru: `_id` / `nickname` / `avatar`.                       |
| `created_at`  | string   | Vreme kreiranja u formatu ISO 8601.                                                  |
| `updated_at`  | string   | Vreme poslednjeg ažuriranja u formatu ISO 8601.                                              |

## Објашњење наплате

Овај интерфејс не наплаћује - упит за детаље о једној боји гласа по ID-у је бесплатна операција. Креирање боје гласа ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) је такође бесплатно, трошкови се јављају само када позивате [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) за синтезу гласа.

## Rukovanje greškama

- `400 token_mismatched`: `id` u putanji nije u važećem formatu ili glas ne postoji.
- `401 invalid_token`: Token za autentifikaciju ne postoji ili nije važeći.
- `404 not_found`: Glas koji odgovara navedenom `_id` nije dostupan (glas je obrisan, privatan je ili pripada drugom nalogu).
- `429 too_many_requests`: Aktivirano je ograničenje brzine naloga.
- `500 api_error`: Interna greška servera.

Pri zahtevu za nepostojećim ID-jem može se vratiti `400 Model not found` (testirano):

```shell
curl 'https://api.acedata.cloud/fish/model/test123' \
  -H 'authorization: Bearer {token}'
```

Odgovor:

```json
{ "status": 400, "message": "Model not found" }
```

Primer odgovora sa greškom:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Zaključak

Kada znate ton `_id`, direktno koristite ovaj interfejs za dobijanje kompletnog ModelEntity, najčešća upotreba je: (1) preslušavanje `samples[].audio`, (2) prosledite `_id` `/fish/tts` kao `reference_id` za završavanje sinteze. Ako imate samo naslov ili oznake, prvo koristite [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) za pretragu.
