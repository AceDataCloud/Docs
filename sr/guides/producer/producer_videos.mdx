---
title: "Uputstvo za integraciju Producer API-ja za preuzimanje videa"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer nam omogućava preuzimanje video zapisa povezanih sa pesmama, a ovaj dokument objašnjava metod integracije relevantnog API-ja.

Ovaj API ima samo jedan ulazni parametar, a to je `audio_id`, koji predstavlja jedinstveni ID pesme.

Ovde unosimo `audio_id` kao `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, što je ID pesme generisane od strane Producer-a.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Rezultat je sledeći:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4"
  }
}
```

Može se videti da je polje `video_url` u okviru `data` link za preuzimanje videa.
