---

Producer nam omogućava da preuzmemo videe povezane sa pesmama, ovaj dokument objašnjava metodu integracije relevantnog API-ja.

Ovaj API ima samo jedan ulazni parametar, a to je `audio_id`, koji je jedinstveni ID pesme.

Ovde unosimo `audio_id` koji je `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, što je ID pesme generisan od strane Producenta.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Rezultat je sledeći:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://storage.googleapis.com/corpusant-app-public/song-videos/a54609c6-13e2-4176-be0f-4d7eebc68e1f:5178f294b214798f7d38b810ac289be75306659be24af88900a633efce334012.mp4"
  }
}
```

Može se videti da je `data` polje `video_url` link za preuzimanje videa.
