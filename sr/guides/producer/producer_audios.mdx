Ovaj članak će predstaviti uputstvo za integraciju Producer Audios Generation API-ja, koji može generisati zvaničnu Producer muziku unosom prilagođenih parametara.

## Proces prijave

Da biste koristili Producer Audios Generation API, prvo idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications) da biste dobili svoj API Token i sačuvali ga za kasnije.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, bićete automatski preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a nakon završetka ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe za zasebnim prijavljivanjem za svaku uslugu.** Prilikom prve prijave dobijate besplatni kredit koji možete koristiti za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Producer Audios Generation API →](https://platform.acedata.cloud/documents/producer-audios)

## Osnovna upotreba

Za koju god pesmu razmišljate, možete proizvoljno uneti deo teksta, na primer, ako želim da generišem pesmu o Božiću, mogu uneti `a song for Christmas`, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/lg9bb0.png" width="600" className="m-auto" /></p>

Ovde možemo videti da smo postavili Request Headers, uključujući:

- `accept`: format rezultata odgovora koji želite da primite, ovde se unosi `application/json`, odnosno JSON format.
- `authorization`: ključ za pozivanje API-ja, nakon prijave ga možete direktno izabrati iz padajuće liste.

Pored toga, parametri u Request Body uključuju:

- `action`: radnja ovog zadatka generisanja muzike, za generisanje pesme je `generate`.
- `model`: model koji se koristi za kreiranje pesme, trenutno uglavnom postoje: **FUZZ-2.0 Pro**, **FUZZ-2.0**, **FUZZ-2.0 Raw**,**FUZZ-1.1 Pro**, **FUZZ-1.0 Pro**, **FUZZ-1.0**, **FUZZ-1.1**, **FUZZ-0.8**.
- `lyric`: sadržaj teksta pesme.
- `custom`: da li se koristi prilagođeni način za generisanje pesme.
- `prompt`: upit u režimu inspiracije.
- `title`: informacije o naslovu pesme.
- `audio_id`: ID referentne pesme, koristi se za operacije poput nastavljanja/presnimavanja.
- `continue_at`: nastavite pisanje pesme od navedenog broja sekundi.
- `replace_section_start`/`replace_section_end`: vreme početka i završetka segmenta za zamenu, u sekundama.
- `lyrics_strength`: jačina teksta, predstavlja stepen uticaja teksta na generisanje zvuka, izbor između 0 i 1, podrazumevano 0.7.
- `sound_strength`: jačina zvučnog upita, izbor između 0.2 i 1, podrazumevano 0.7.
- `cover_strength`: jačina obrade, između 0.2 i 1, podrazumevano 1.
- `weirdness`: stepen neobičnosti stila, izbor između 0 i 1, podrazumevano 0.5
- `callback_url`: URL na koji je potrebno poslati rezultat povratnim pozivom.
- `async`: opciono, kada se postavi na `true`, interfejs odmah vraća `task_id`, bez potrebe za navođenjem `callback_url`, a rezultat se zatim dobija anketiranjem odgovarajućeg interfejsa za upit zadataka.
- `instrumental`: da li je režim bez teksta.

Pored toga, ako želite da generišete odgovarajući kod za integraciju, možete ga direktno kopirati, na primer CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/producer/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "FUZZ-2.0 Pro",
  "prompt": "A song for Christmas"
}'
```

## Obrada pesme

Ako želite da izvršite obradu već generisane pesme, možete uneti gore generisanu pesmu za obradu; zatim ćemo prilagođeno generisati pesmu na osnovu teksta i naslova.

Ako želite da nastavite obradu pesme koju ste sami otpremili, možete postaviti parametar `action` na `upload_cover` i uneti ID pesme koja treba da se nastavi obrađivati, a ID pesme se dobija korišćenjem [Producer Upload API](https://platform.acedata.cloud/documents/producer-upload), kao što je prikazano na slici ispod:

<p><img src="https://cdn.acedata.cloud/z7r5fd.png" width="500" className="m-auto" /></p>

Tada možete navesti sledeći sadržaj:

- action：radnja ovog zadatka pesme, trenutno podržava: generate、cover、extend、upload_cover、upload_extend、replace_section、swap_vocals、swap_instrumentals、variation; za ovu obradu koristi se parametar `cover`.
- lyric：tekst pesme
- title：naslov pesme.
- custom：da li se generiše korišćenjem prilagođenog režima, podrazumevano je false.
- audio_id：ID pesme koju treba obraditi.

## Asinhroni povratni poziv

Pošto vreme generisanja putem Producer Audios Generation API-ja ponekad može biti relativno dugo, ako API dugo ne odgovara, HTTP zahtev će stalno održavati vezu, što dovodi do dodatne potrošnje sistemskih resursa, stoga ovaj API takođe pruža podršku za asinhrone povratne pozive.

Celokupan proces je: kada klijent pokreće zahtev, dodatno navodi polje `callback_url`, nakon što klijent pokrene API zahtev, API će odmah vratiti rezultat, koji sadrži informaciju o polju `task_id`, koje predstavlja trenutni ID zadatka. Kada se zadatak završi, rezultat generisanog zadatka će biti poslat u obliku POST JSON-a na `callback_url` koji je klijent naveo, pri čemu takođe uključuje polje `task_id`, tako da se rezultati zadatka mogu povezati putem ID-ja.

U nastavku ćemo kroz primer saznati kako se konkretno postupa.

Najpre, Webhook povratni poziv je usluga koja može da prima HTTP zahteve, programeri bi trebalo da ga zamene URL-om HTTP servera koji su sami postavili. Ovde se radi lakšeg prikaza koristi javna Webhook ogledna veb-lokacija [https://webhook.site/](https://webhook.site/), otvaranjem te veb-lokacije možete dobiti Webhook URL, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/tbcnai.png)

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neovlašćeno, nevažeći ili nedostajući token za autorizaciju.
- `429 too_many_requests`：Previše zahteva, premašili ste ograničenje broja zahteva.
- `500 api_error`：Interna greška servera, nešto je pošlo po zlu na serveru.

### Primer odgovora na grešku

  "success": false,
  "error": {

    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
