Ovaj dokument će predstaviti uputstvo za integraciju Producer Audios Generation API, koji može generisati zvukove zvanične muzike Producer-a putem unosa prilagođenih parametara.

## Proces prijave

Da biste koristili API, prvo idite na [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios) odgovarajuću stranicu da biste zatražili odgovarajuću uslugu. Kada uđete na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite. Nakon prijave ili registracije, automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Osnovna upotreba

Šta god da želite da generišete, možete uneti bilo koji tekst, na primer, ako želim da generišem pesmu o Božiću, mogu uneti `a song for Christmas`, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/lg9bb0.png" width="600" className="m-auto" /></p>

Možete videti da smo ovde postavili Request Headers, uključujući:

- `accept`: kakav format odgovora želite da primite, ovde je uneto `application/json`, što znači JSON format.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

Pored toga, parametri Request Body uključuju:

- `action`: ponašanje ovog zadatka generisanja muzike, generisanje pesme je `generate`.
- `model`: model koji se koristi za kreiranje pesme, trenutno su dostupni: **FUZZ-2.0 Pro**, **FUZZ-2.0**, **FUZZ-2.0 Raw**, **FUZZ-1.1 Pro**, **FUZZ-1.0 Pro**, **FUZZ-1.0**, **FUZZ-1.1**, **FUZZ-0.8**.
- `lyric`: sadržaj stihova pesme.
- `custom`: da li se koristi prilagođeni način generisanja pesme.
- `prompt`: ključne reči u režimu inspiracije.
- `title`: informacija o naslovu pesme.
- `audio_id`: ID referentne pesme, koristi se za nastavak/ponavljanje itd.
- `continue_at`: nastavak pesme od određenog broja sekundi.
- `replace_section_start`/`replace_section_end`: vreme početka i kraja zamene segmenta, u sekundama.
- `lyrics_strength`: jačina stihova, koja označava stepen uticaja stihova u generisanju zvuka, može biti između 0-1, podrazumevano 0.7.
- `sound_strength`: jačina ključnih reči zvuka, može biti između 0.2-1, podrazumevano 0.7.
- `cover_strength`: jačina obrade pesme, između 0.2-1, podrazumevano 1.
- `weirdness`: stepen neobičnosti stila, može biti između 0-1, podrazumevano 0.5.
- `callback_url`: URL na koji treba poslati rezultate.
- `instrumental`: da li je u režimu bez stihova.

Pored toga, ako želite da generišete odgovarajući kod za integraciju, možete jednostavno kopirati generisani kod, na primer, CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/producer/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "FUZZ-2.0 Pro",
  "prompt": "A song for Christmas"
}'
```

## Prekrivanje pesama

Ako želite da izvršite prekrivanje već generisane pesme, možete uneti prethodno generisanu pesmu za prekrivanje, a zatim ćemo na osnovu teksta pesme i naslova prilagoditi generisanje pesme.

Ako želite da nastavite sa prekrivanjem pesme koju ste sami otpremili, možete postaviti parametar `action` na `upload_cover` i uneti ID pesme koju želite da nastavite sa prekrivanjem, a ID pesme se dobija korišćenjem [Producer Upload API](https://platform.acedata.cloud/documents/7fd2cb52-772e-4cc4-a018-e2626ff6f447) kao što je prikazano na sledećem slici:

<p><img src="https://cdn.acedata.cloud/z7r5fd.png" width="500" className="m-auto" /></p>

Možete odrediti sledeće sadržaje:

- action: ponašanje zadatka pesme, trenutno podržava: generate, cover, extend, upload_cover, upload_extend, replace_section, swap_vocals, swap_instrumentals, variation, za ovo prekrivanje koristi se `cover` parametar.
- lyric: tekst pesme
- title: naslov pesme.
- custom: da li se koristi prilagođeni način generisanja, podrazumevano je false.
- audio_id: ID pesme koju treba prekriti.

## Asinhroni povratni poziv

Zbog toga što vreme generisanja putem Producer Audios Generation API ponekad može biti relativno dugo, ako API dugo ne odgovara, HTTP zahtev će zadržati vezu, što dovodi do dodatne potrošnje sistemskih resursa, pa ovaj API takođe pruža podršku za asinhroni povratni poziv.

Celokupni proces je: kada klijent pokrene zahtev, dodatno se navodi polje `callback_url`, nakon što klijent pokrene API zahtev, API će odmah vratiti rezultat koji sadrži informaciju o polju `task_id`, što predstavlja trenutni ID zadatka. Kada zadatak bude završen, rezultat generisanog zadatka biće poslat putem POST JSON forme na klijentom navedeni `callback_url`, koji takođe uključuje polje `task_id`, tako da se rezultati zadatka mogu povezati putem ID-a.

Pogledajmo kako to konkretno funkcioniše kroz primer.

Prvo, Webhook povratni poziv je usluga koja može primati HTTP zahteve, programeri bi trebali zameniti URL svoje HTTP servera. Ovde, radi lakšeg prikazivanja, koristi se javni Webhook uzorak sa sajta [https://webhook.site/](https://webhook.site/), otvaranjem tog sajta dobijate Webhook URL, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/tbcnai.png)

## Обрада грешака

Када позивате API, ако наиђете на грешку, API ће вратити одговарајући код грешке и информације. На пример:

- `400 token_mismatched`：Лош захтев, могуће због недостајућих или неважећих параметара.
- `400 api_not_implemented`：Лош захтев, могуће због недостајућих или неважећих параметара.
- `401 invalid_token`：Није овлашћено, неважећи или недостајући токен за ауторизацију.
- `429 too_many_requests`：Превише захтева, превазишли сте лимит.
- `500 api_error`：Унутрашња грешка сервера, нешто није у реду на серверу.

### Пример одговора на грешку

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
