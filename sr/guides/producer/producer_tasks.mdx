Glavna funkcija Producer Tasks API je da omogućava upit o statusu izvršenja zadatka putem ID-a zadatka generisanog od strane Producer Audios Generation API.

Ovaj dokument će detaljno opisati uputstva za integraciju Producer Tasks API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Producer Tasks API, možete lako ostvariti upit o statusu izvršenja zadatka iz Producer Audios Generation API.

## Proces prijave

Da biste koristili Producer Tasks API, prvo treba da odete na stranicu za prijavu [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios) i zatražite odgovarajuću uslugu, a zatim kopirajte ID zadatka iz Producer Audios Generation API, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" class="m-auto"></p>

Na kraju, idite na stranicu Tasks API [Producer Tasks API](https://platform.acedata.cloud/documents/622626b1-30a7-4799-a772-4946e1df3ac0) da zatražite odgovarajuću uslugu, a nakon ulaska na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![Stranica za prijavu](https://cdn.acedata.cloud/rci31i.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na [stranicu za prijavu](https://platform.acedata.cloud) koja vas poziva da se registrujete i prijavite, a nakon prijave ili registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Primer zahteva

Producer Tasks API može se koristiti za upit o rezultatima Producer Audios Generation API. O tome kako koristiti Producer Audios Generation API, molimo vas da se obratite dokumentu [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration).

Uzmimo jedan primer ID-a zadatka koji je vratio Producer Audios Generation API i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: 1a6ac2ad-10f2-4e2b-b500-66ec27fe82ad, a zatim ćemo prikazati kako da ga prosledimo.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se šalje.
- `action`: način operacije na zadatku.

Postavite kao što je prikazano na slici ispod:

<p><img src="https://cdn.acedata.cloud/bfe4ww.png" width="500" class="m-auto"></p>

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na različitim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/u4pb2f.png" width="500" class="m-auto"></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/producer/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "1a6ac2ad-10f2-4e2b-b500-66ec27fe82ad",
  "action": "retrieve"
}'
```

- `ids`: низ ID-јева задатака који се шаљу.

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili neispravnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili neispravnih parametara.
- `401 invalid_token`: Neautorizovano, neispravan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### Primer odgovora na grešku

```json

}
```
