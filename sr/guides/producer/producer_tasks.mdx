Glavna funkcija Producer Tasks API-ja je da putem unosa ID-ja zadatka generisanog od strane Producer Audios Generation API-ja proveri status izvršavanja tog zadatka.

Ovaj dokument će detaljno predstaviti uputstva za integraciju Producer Tasks API-ja, pomažući vam da lako integrišete i u potpunosti iskoristite moćne funkcije ovog API-ja. Putem Producer Tasks API-ja možete lako ostvariti proveru statusa izvršavanja zadataka Producer Audios Generation API-ja.

## Proces prijave

Da biste koristili Producer Audios Generation API, najpre idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications) da preuzmete svoj API Token i sačuvate ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, bićete automatski preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a po završetku ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe za zasebnim prijavljivanjem za svaku uslugu.** Pri prvoj prijavi dobićete besplatan kredit za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Producer Audios Generation API →](https://platform.acedata.cloud/documents/producer-audios)

## Primer zahteva

Producer Tasks API može se koristiti za proveru rezultata Producer Audios Generation API-ja. O tome kako koristiti Producer Audios Generation API, pogledajte dokumentaciju [Producer Audios Generation API ](https://platform.acedata.cloud/documents/producer-audios-integration).

Uzećemo kao primer jedan ID zadatka koji vraća usluga Producer Audios Generation API i prikazati kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: 1a6ac2ad-10f2-4e2b-b500-66ec27fe82ad, u nastavku ćemo prikazati kako putem unosa jednog ID-ja zadatka.

### Podešavanje zaglavlja zahteva i tela zahteva

**Request Headers** uključuju:

- `accept`: određuje da se prihvataju rezultati odgovora u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete ga direktno odabrati iz padajuće liste.

**Request Body** uključuje:

- `id`: ID otpremljenog zadatka.
- `action`: način operacije nad zadatkom.

Podešavanja su prikazana na sledećoj slici:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/producer/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "1a6ac2ad-10f2-4e2b-b500-66ec27fe82ad",
  "action": "retrieve"
}'
```

- `id`，ID zadatka generisanja, koristi se za jedinstvenu identifikaciju ovog zadatka generisanja.
- `request`，informacije o zahtevu u zadatku upita.
- `response`，informacije o povratnim podacima u zadatku upita.
- `created_at`，vreme kreiranja zadatka, Unix vremenska oznaka (sekunde, decimalni broj).
- `started_at`，vreme početka izvršavanja zadatka, Unix vremenska oznaka (sekunde, decimalni broj).
- `finished_at`，vreme završetka zadatka, Unix vremenska oznaka (sekunde, decimalni broj). Ovo polje se ne vraća kada zadatak nije završen.
- `elapsed`，trajanje izvršavanja zadatka, jedinica je sekunda (decimalni broj, zadržava 3 decimale). Ovo polje se ne vraća kada zadatak nije završen.

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i poruku. Na primer:

- `400 token_mismatched`：Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neovlašćeno, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, prekoračili ste ograničenje broja zahteva.
- `500 api_error`：Interna greška servera, nešto je pošlo po zlu na serveru.

### Primer odgovora na grešku

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
