---
title: "Uputstvo za integraciju Producer API-ja za otpremanje referentnog zvuka"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer nam omogućava da otpremimo referentni zvuk za sekundarno stvaranje, a ovaj dokument objašnjava način integracije povezanog API-ja.

Ovaj API ima samo jedan ulazni parametar, a to je `audio_url`, koji je javno dostupna CDN adresa i podržava mp3 ekstenziju.

`audio_url` koji ovde unosimo je `https://cdn.acedata.cloud/suno_demo.mp3`, javno dostupna CDN adresa.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Rezultat je sledeći:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Soft female vocals, bright and cheerful]\n\n[Verse 1]\n阳光洒在海边\n浪花笑得灿烂\n你和我在沙滩\n钟表停止转\n冰淇淋在融化\n手牵手去散步\n风儿轻轻吹过\n心跳不停跳\n\n[Chorus]\n夏天夏天\n时间停在这一天\n笑声回荡\n蔚蓝天空在身旁",
    "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
  }
}
```

Može se videti da je polje `audio_id` u `data` ID otpremljene pesme.

Nakon što dobijemo ID pesme, možemo koristiti [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration) za prilagođeno generisanje pesama. Na primer, ako se za `action` prosledi `upload_extend`, a za `audio_id` vrati ID pesme, može se generisati nova pesma na osnovu referentnog zvuka.
