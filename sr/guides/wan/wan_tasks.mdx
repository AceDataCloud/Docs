`POST https://api.acedata.cloud/wan/tasks` se koristi za upit, masovni upit ili brisanje Wan video zadataka. Upit za zadatke ne naplaćuje ponovo troškove generisanja.

## Upit za jedan zadatak

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Završeni zadatak `response.data.video_url` je trajna CDN adresa; `response.usage` sadrži rezoluciju, ulazne/izlazne video sekunde, frekvenciju i odnos; `response.cost` je obračun troškova generisanja zadatka.

## Masovni upit

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Vraća `{ "items": [...], "count": 2 }`. Kada su zadaci u toku, možda još uvek neće biti `finished_at` i konačnog `response`.

## Brisanje zapisa o zadatku

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

Brisanje utiče samo na istoriju zadataka, neće obrisati već generisane CDN video zapise.
