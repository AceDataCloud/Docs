Glavna funkcija Wan Tasks API je da omogućava upit o statusu izvršenja zadatka putem ID-a zadatka generisanog putem Wan Videos Generation API.

Ovaj dokument će detaljno opisati integraciju Wan Tasks API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Wan Tasks API, možete lako ostvariti upit o statusu izvršenja zadatka iz Wan Videos Generation API.

## Proces prijave

Da biste koristili Wan Tasks API, prvo treba da odete na stranicu za prijavu [Wan Videos Generation API](https://platform.acedata.cloud/documents/52b0f490-1bbf-4fe5-b60e-96626d333d2c) i zatražite odgovarajuću uslugu, a zatim kopirajte ID zadatka iz Wan Videos Generation API, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Na kraju, idite na stranicu Tasks API [Wan Tasks API](https://platform.acedata.cloud/documents/240ef446-cbec-461c-a633-4a64178d7018) da zatražite odgovarajuću uslugu, a nakon ulaska na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![Stranica za prijavu](https://cdn.acedata.cloud/rci31i.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na [stranicu za prijavu](https://platform.acedata.cloud) koja vas poziva da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Primer zahteva

Wan Tasks API može se koristiti za upit o rezultatima Wan Videos Generation API. O tome kako koristiti Wan Videos Generation API, molimo vas da se obratite dokumentu [Wan Videos Generation API](https://platform.acedata.cloud/documents/52b0f490-1bbf-4fe5-b60e-96626d333d2c).

Uzmimo jedan ID zadatka koji je vratio Wan Videos Generation API kao primer i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: a4bca552-d964-46a1-8ff7-fd922f916582, a zatim ćemo prikazati kako da ga prosledimo.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se šalje.
- `action`: način operacije na zadatku.

Postavite kao što je prikazano na slici ispod:

<p><img src="https://cdn.acedata.cloud/vr3hxw.png" width="500" className="m-auto" /></p>

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na raznim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/ehmsdi.png" width="500" className="m-auto" /></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "a4bca552-d964-46a1-8ff7-fd922f916582",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/wan/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "a4bca552-d964-46a1-8ff7-fd922f916582",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Greška u obradi

U slučaju greške prilikom pozivanja API-ja, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`：Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`：Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste limit brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.
