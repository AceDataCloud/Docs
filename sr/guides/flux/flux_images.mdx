Ovaj tekst će predstaviti uputstvo za integraciju Flux Images Generation API-ja, koji može da generiše zvanične Flux slike unosom prilagođenih parametara.

## Proces prijave

Da biste koristili Flux Images Generation API, prvo preuzmite svoj API Token na [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications) i sačuvajte ga za kasnije.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, bićete automatski preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a po završetku ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može da poziva sve usluge platforme, bez potrebe za zasebnom prijavom za svaku uslugu.** Prilikom prve prijave dobićete besplatan kredit za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Flux Images Generation API →](https://platform.acedata.cloud/documents/flux-images)

## Osnovna upotreba

Najpre se upoznajmo sa osnovnim načinom korišćenja: unosom prompta `prompt`, radnje generisanja `action` i veličine slike `size` možete dobiti obrađeni rezultat. Najpre je potrebno jednostavno proslediti polje `action` čija je vrednost `generate`, a zatim je potrebno uneti prompt, pri čemu je konkretan sadržaj sledeći:

<p><img src="https://cdn.acedata.cloud/wz85jt.png" width="500" className="m-auto" /></p>

Ovde možemo videti da smo postavili Request Headers, uključujući:

- `accept`: format odgovora koji želite da primite, ovde se unosi `application/json`, odnosno JSON format.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete ga direktno izabrati iz padajuće liste.

Pored toga, postavljen je Request Body, uključujući:

- `action`: radnja ovog zadatka generisanja slike.
- `size`: veličina rezultata generisanja slike. **Serije `flux-2-flex` / `flux-2-pro` / `flux-2-max` moraju proslediti odnos stranica slike (kao što su `1:1`, `16:9`), ne prihvataju veličine u pikselima poput `1024x1024`, a u slučaju izostavljanja vraćaju 400.**
- `count`: broj slika koje se generišu, podrazumevana vrednost je 1; ovaj parametar važi samo za zadatke generisanja slika, a ne važi za zadatke uređivanja.
- `prompt`: prompt.
- `model`: model za generisanje, podrazumevano je `flux-dev`; najnoviji vodeći modeli su `flux-2-pro` i `flux-2-max` (viši kvalitet slike, potrebno je koristiti odnos stranica slike `size`).
- `callback_url`: URL na koji je potrebno poslati rezultat povratnim pozivom.
- `async`: opciono, kada se postavi na `true`, interfejs odmah vraća `task_id`, bez potrebe za prosleđivanjem `callback_url`, a zatim se rezultat dobija anketiranjem putem odgovarajućeg interfejsa za upit zadatka.

Parametar `size` ima neka posebna ograničenja, uglavnom se deli na dve vrste: odnos širine i visine `width x height` i odnos slike `x:y`, konkretno kako sledi:

| Model               | Opseg                                      |
| ---------------- | ------------------------------------------ |
| flux-dev         | Podržava odnos širine i visine 1024x1024, 1024x1792, 1792x1024 ili odnos slike |
| flux-pro         | Podržava odnos širine i visine 1024x1024, 1024x1792, 1792x1024 ili odnos slike |
| flux-2-flex      | Podržava samo odnos slike                                    |
| flux-2-pro       | Podržava samo odnos slike                                    |
| flux-2-max       | Podržava samo odnos slike                                    |
| flux-kontext-pro | Podržava samo odnos slike                                    |
| flux-kontext-max | Podržava samo odnos slike                                    |

Referentni odnosi slika: "21:9", "16:9", "4:3", "3:2", "1:1", "2:3", "3:4", "9:16", "9:21".

Nakon izbora parametara, odgovarajući kod će se automatski generisati sa desne strane. Pre kopiranja potvrdite da zaglavlje autorizacije koristi vaš sopstveni API Key i da se stvarni kredencijali ne pojavljuju u dokumentaciji i snimcima ekrana.

Kliknite na dugme „Try“ da biste izvršili testiranje, ovde smo dobili sledeći rezultat:

```json
{
  "success": true,
  "task_id": "5456c749-3bbb-4f10-9eb8-cfbcac297500",
  "trace_id": "ae4eecb8-1dd6-45b4-bfb3-a1c48872536e",
  "data": [
    {
      "image_url": "https://cdn.acedata.cloud/assets/examples/flux/5456c749-3bbb-4f10-9eb8-cfbcac297500-d0ef60485f73.jpg"
    }
  ]
}
```

Rezultat vraća više polja, predstavljenih u nastavku:

- `success`, status zadatka generisanja videa u ovom trenutku.
- `task_id`, ID zadatka generisanja videa u ovom trenutku.
- `trace_id`, ID praćenja generisanja videa u ovom trenutku.
- `data`, lista rezultata zadatka generisanja slike u ovom trenutku.
  - `image_url`, veza zadatka generisanja slike u ovom trenutku.
  - `prompt`, prompt.

Možemo videti da smo dobili zadovoljavajuće informacije o slici, potrebno je samo da preuzmemo generisanu Flux sliku prema adresi veze slike u rezultatu `data`.

Pored toga, ako želite da generišete odgovarajući kod za integraciju, možete ga direktno kopirati, na primer CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/flux/images' \
-H 'authorization: Bearer {token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "prompt": "A photorealistic studio product shot of a frosted-glass perfume bottle on wet black slate, single softbox key light, water droplets, dark moody background, 85mm macro.",
  "model": "flux-2-pro",
  "size": "1:1"
}'
```

## Zadatak uređivanja slike

Ako želite da uredite određenu sliku, najpre parametar `image_url` mora proslediti vezu slike koju je potrebno urediti; u ovom trenutku `action` podržava samo `edit`, pa možete navesti sledeći sadržaj:

- model: model koji se koristi za ovaj zadatak uređivanja slike, podržava `flux-dev`, `flux-pro`, `flux-kontext-pro`, `flux-kontext-max`, `flux-2-flex`, `flux-2-pro`, `flux-2-max`.
- image_url: otpremite sliku koju je potrebno urediti.

Primer popunjavanja je sledeći:

<p><img src="https://cdn.acedata.cloud/jn9da5.png" width="500" className="m-auto" /></p>

Nakon popunjavanja, kod se automatski generiše na sledeći način:

<p><img src="https://cdn.acedata.cloud/6cwxb8.png" width="500" className="m-auto" /></p>

Odgovarajući kod:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "edit",
    "prompt": "a white siamese cat",
    "model": "flux-kontext-pro",
    "image_url": "https://cdn.acedata.cloud/ytj2qy.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kliknite na pokretanje i možete videti da ćete odmah dobiti rezultat, kao što sledi:

```json
{
  "success": true,
  "task_id": "2a7979ff-1f77-4380-92c6-a2dc37c3b4c8",
  "trace_id": "732b65c0-48d9-49f7-b568-64e5acffe4c0",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "timings": 1752744073
    }
  ]
}
```
Može se videti da je generisani efekat efekat uređivanja originalne slike, a rezultat je sličan gore navedenom.

## Asinhroni povratni poziv

Pošto Flux Images Generation API zahteva relativno dugo vreme za generisanje, otprilike 1-2 minuta, ako API dugo ne odgovara, HTTP zahtev će stalno održavati vezu, što dovodi do dodatne potrošnje sistemskih resursa, zato ovaj API takođe pruža podršku za asinhrone povratne pozive.

Celokupan proces je: kada klijent pokrene zahtev, dodatno navodi polje `callback_url`, nakon što klijent pokrene API zahtev, API će odmah vratiti rezultat koji sadrži informaciju polja `task_id`, koje predstavlja ID trenutnog zadatka. Kada se zadatak završi, rezultat generisanja slike će biti poslat u obliku POST JSON-a na `callback_url` koji je naveo klijent, a on takođe uključuje polje `task_id`, tako da rezultat zadatka može biti povezan putem ID-a.

U nastavku ćemo kroz primer saznati kako konkretno postupati.

Pre svega, Webhook povratni poziv je servis koji može da prima HTTP zahteve, a programer bi trebalo da ga zameni URL-om sopstvenog postavljenog HTTP servera. Ovde se radi lakšeg prikaza koristi javna Webhook primer veb-lokacija https://webhook.site/; otvaranjem te veb-lokacije možete dobiti Webhook URL, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/cjjfly.png)

Kopirajte ovaj URL i možete ga koristiti kao Webhook; primer ovde je `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`.

Zatim možemo postaviti polje `callback_url` na gore navedeni Webhook URL, istovremeno unoseći odgovarajuće parametre, a konkretan sadržaj je prikazan na slici:

<p><img src="https://cdn.acedata.cloud/wm6caw.png" width="500" className="m-auto" /></p>

Kliknite na pokretanje i videćete da ćete odmah dobiti rezultat, kao što sledi:

```
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c"
}
```

Sačekajte trenutak, pa možete na `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab` videti rezultat generisanja slike, kao što je prikazano na slici:

Može se videti da rezultat sadrži polje `task_id`, dok su ostala polja slična gore navedenim; putem ovog polja može se ostvariti povezivanje zadataka.

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i poruku. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neovlašćeno, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, prekoračili ste ograničenje broja zahteva.
- `500 api_error`: Interna greška servera, nešto je pošlo po zlu na serveru.

### Primer odgovora greške

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
