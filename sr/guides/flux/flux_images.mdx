Овај документ ће представити упутство за интеграцију Flux Images Generation API, који може генерисати слике Flux-а уношењем прилагођених параметара.

## Процес пријаве

Да бисте користили API, прво морате да одете на [Flux Images Generation API](https://platform.acedata.cloud/documents/6b9197c5-7a3f-4878-a43f-7f94e7e66394) страницу и затражите одговарајућу услугу. Када уђете на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите. Након пријаве или регистрације, аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, коју можете користити за API.

## Основна употреба

Прво, потребно је разумети основни начин коришћења, а то је унос кључне речи `prompt`, акције `action`, и величине слике `size`, како бисте добили обрађени резултат. Прво, потребно је једноставно проследити поље `action`, чија вредност је `generate`, а затим треба унети кључну реч, конкретно садржај је следећи:

<p><img src="https://cdn.acedata.cloud/wz85jt.png" width="500" className="m-auto" /></p>

Можете видети да смо подесили Request Headers, укључујући:

- `accept`: у ком формату желите да примите одговор, овде је написано `application/json`, што значи JSON формат.
- `authorization`: кључ за позивање API-а, који можете директно изабрати након захтева.

Такође смо подесили Request Body, укључујући:

- `action`: акција генерисања слике.
- `size`: величина резултата генерисане слике.
- `count`: број генерисаних слика, подразумевана вредност је 1, овај параметар је валидан само за генерисање слика, а не за уређивање.
- `prompt`: кључна реч.
- `model`: модел генерисања, подразумевано `flux-dev`.
- `callback_url`: URL на који треба да се врати резултат.

Параметар `size` има нека посебна ограничења, углавном подељена у две врсте: `width x height` однос ширине и висине, и `x:y` однос слике, конкретно:

| Модел                 | Опсег                                 |
| ------------------ | ---------------------------------- |
| flux-2-flex        | Подржава однос ширине и висине x >= 64 мора бити кратко 32          |
| flux-2-pro         | Подржава однос ширине и висине x >= 64 мора бити кратко 32          |
| flux-2-max         | Подржава однос ширине и висине x >= 64 мора бити кратко 32          |
| flux-pro-1.1       | Подржава однос ширине и висине 256 &lt;= x &lt;= 1440 мора бити кратко 32 |
| flux-dev           | Подржава однос ширине и висине 256 &lt;= x &lt;= 1440 мора бити кратко 32 |
| flux-pro-1.1-ultra | Не подржава однос ширине и висине, подржава однос слике                     |
| flux-kontext-pro   | Не подржава однос ширине и висине, подржава однос слике                     |
| flux-kontext-max   | Не подржава однос ширине и висине, подржава однос слике                     |

Референтни односи слика: "1:1", "16:9", "21:9", "3:2", "2:3", "4:5", "5:4", "3:4", "4:3", "9:16", "9:21",

Након избора, можете видети да је десно генерисан одговарајући код, као што је приказано на слици:

Кликните на дугме „Try“ да бисте тестирали, као што је приказано на горњој слици, добили смо следећи резултат:

```json
    }

```

Враћени резултат има више поља, описаних као:

- `success`, статус тренутног задатка генерисања слике.
- `task_id`, ID тренутног задатка генерисања слике.
- `trace_id`, ID за праћење тренутног задатка генерисања слике.
- `data`, листа резултата тренутног задатка генерисања слике.
  - `image_url`, линк за тренутни задатак генерисања слике.
  - `prompt`, кључна реч.

Можете видети да смо добили задовољавајуће информације о слици, само треба да добијемо генерисану Flux слику према адреси линка у `data`.

Ако желите да генеришете одговарајући код за интеграцију, можете га директно копирати, на пример, CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/flux/images' \
-H 'authorization: Bearer {token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "prompt": "a white siamese cat",
  "model": "flux-kontext-pro",
  "count": 2
}'
```

## Уређивање задатка слике

Ако желите да уредите неку слику, прво поље `image_url` мора да садржи линк до слике коју желите да уредите, у овом случају `action` подржава само `edit`, и можете одредити следеће садржаје:

- model: модел који се користи за уређивање слике, овај задатак тренутно подржава `flux-kontext-max`, `flux-kontext-pro`.
- image_url: линк до слике коју треба уредити.

Пример попуњавања је следећи:

<p><img src="https://cdn.acedata.cloud/jn9da5.png" width="500" className="m-auto" /></p>

Након попуњавања, аутоматски је генерисан код као што је приказано:

<p><img src="https://cdn.acedata.cloud/6cwxb8.png" width="500" className="m-auto" /></p>

Одговарајући код:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "edit",
    "prompt": "a white siamese cat",
    "model": "flux-kontext-pro",
    "image_url": "https://cdn.acedata.cloud/ytj2qy.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Када кликнете на „Рун“, можете видети да ћете одмах добити резултат, као што је следеће:

```json

  "trace_id": "732b65c0-48d9-49f7-b568-64e5acffe4c0",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://fal.media/files/monkey/aEUXJZ6Faj9YXUCQVs01Q_af0cea56c558441c9ba8df67b200812d.png",
      "timings": 1752744073
```

Можете видети да је генерисани ефекат уређивање оригиналне слике, а резултат је сличан претходном.

## Асинхроно повратно обавештење
Zbog relativno dugog vremena generisanja putem Flux Images Generation API, koje traje oko 1-2 minuta, ako API dugo ne odgovara, HTTP zahtev će zadržati vezu, što dovodi do dodatne potrošnje sistemskih resursa, pa ovaj API takođe pruža podršku za asinhrone povratne pozive.

Celokupni proces je: kada klijent pokrene zahtev, dodatno se navodi polje `callback_url`, nakon što klijent pošalje API zahtev, API će odmah vratiti rezultat koji sadrži informaciju o polju `task_id`, što predstavlja trenutni ID zadatka. Kada zadatak bude završen, rezultat generisanja slika biće poslat na `callback_url` koji je klijent odredio, u POST JSON formatu, a takođe uključuje i polje `task_id`, tako da se rezultati zadatka mogu povezati putem ID-a.

U nastavku ćemo kroz primer razumeti kako konkretno postupiti.

Prvo, Webhook povratni poziv je usluga koja može primati HTTP zahteve, programeri bi trebali zameniti URL-om HTTP servera koji su sami postavili. Ovde, radi lakšeg prikaza, koristi se javni Webhook uzorak sa sajta https://webhook.site/, otvaranjem tog sajta dobijate Webhook URL, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/cjjfly.png)

Kopirajte ovaj URL, i možete ga koristiti kao Webhook, ovde je uzorak `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`.

Zatim, možemo postaviti polje `callback_url` na navedeni Webhook URL, dok istovremeno popunjavamo odgovarajuće parametre, konkretni sadržaj je prikazan na slici:

<p><img src="https://cdn.acedata.cloud/wm6caw.png" width="500" className="m-auto" /></p>

Klikom na pokretanje, može se primetiti da odmah dobijamo rezultat, kao što je prikazano:

```
{
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c"
}
```

Nakon kratkog čekanja, možemo na `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab` posmatrati rezultat generisanja slika, kao što je prikazano:

![](https://cdn.acedata.cloud/v23lot.png)

Sadržaj je sledeći:

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://sf-maas-uat-prod.oss-cn-shanghai.aliyuncs.com/outputs/f4f8d407-377a-408a-82d0-427a5a836f09_0.png",
      "seed": 1698551532,
      "timings": {
        "inference": 3.328
      }
    }
  ]
}
```

Može se primetiti da u rezultatu postoji polje `task_id`, a ostala polja su slična onima iz prethodnog teksta, putem ovog polja se može ostvariti povezanost zadatka.

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### Primer greške u odgovoru

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
