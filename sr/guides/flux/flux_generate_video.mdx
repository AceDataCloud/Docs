Flux Videos API koristi `POST /flux/videos` za generisanje videa, generisanje videa iz ključnih kadrova, nastavak videa i poboljšanje nacrta. `action=generate` (podrazumevano), `mode` bira režim generisanja; za upit rezultata se jedinstveno koristi postojeći `POST /flux/tasks`.

> Trenutno je u Beta fazi. Generisanje videa iz teksta, generisanje videa iz slike, nastavak videa i poboljšanje nacrta su otvoreni. HTTP 200 i ID zadatka samo označavaju da je zadatak prihvaćen; morate nastaviti sa upitom konačnog rezultata.

## 1. Dobijanje API Tokena

1. Registrujte se ili prijavite na [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications), kreirajte aplikaciju i preuzmite API Token. Jedan univerzalni API Token može pozivati usluge platforme; potvrdite da aplikacija ima dozvolu za pozivanje Flux usluge i raspoloživ saldo.
2. Na [stranici Flux usluge](https://platform.acedata.cloud/services/flux?tab=pricing) pogledajte pakete i cene pojedinačnih operacija. Kada saldo nije dovoljan, dopunite ga na [stranici salda konzole](https://platform.acedata.cloud/console/coin).
3. Zahtevi koriste `Authorization: Bearer <vaš Token>`. Token treba čuvati u promenljivama okruženja na serverskoj strani, nemojte ga upisivati na frontend stranice, javne repozitorijume, snimke ekrana ili callback URL-ove.

![Zahtevanje API Tokena u konzoli](https://cdn.acedata.cloud/dvc3cg.jpg)

Kod u ovom tekstu jedinstveno čita promenljivu okruženja:

```bash
export ACEDATACLOUD_API_TOKEN='zamenite svojim API Tokenom'
```

| Stavka      | Vrednost                                        |
| ------- | ----------------------------------------------- |
| API osnovna adresa | `https://api.acedata.cloud`                     |
| Slanje video zadatka  | `POST /flux/videos`                             |
| Upit postojećeg zadatka  | `POST /flux/tasks`                              |
| Autentikacija      | `Authorization: Bearer $ACEDATACLOUD_API_TOKEN` |
| Format zahteva    | `Content-Type: application/json`                |

Za kompletna polja i online testiranje pogledajte [Flux Videos API](https://platform.acedata.cloud/documents/flux-videos), a za upit zadataka pogledajte [Flux Tasks API](https://platform.acedata.cloud/documents/flux-tasks).

## 2. Izbor operacije i unosa

| action                      | mode            | Unos                       | Rezultat            |
| --------------------------- | --------------- | ------------------------ | ------------- |
| `generate` (podrazumevana vrednost kada se action izostavi) | `t2v`           | `prompt`                 | Generisanje videa iz teksta       |
| `generate`                  | `i2v`           | `prompt`、`keyframes`     | Generisanje videa iz jednog ili više ključnih kadrova |
| `generate`                  | `v2v`           | `prompt`、`start_video`   | Nastavak na osnovu ulaznog videa      |
| `generate`                  | `draft_enhance` | `draft_task_id` sopstvenog završenog nacrta | Poboljšanje tog nacrta         |

Model za generisanje je `flux-3`, `action` je `generate` (podrazumevano). Putem `mode` birate generisanje videa iz teksta, generisanje videa iz slike, nastavak videa ili poboljšanje nacrta.

### Opšti parametri generisanja

| Parametar                 | Opis                                                           |
| ------------------ | ------------------------------------------------------------ |
| `mode`             | Obavezno; `t2v`, `i2v`, `v2v` ili `draft_enhance`                       |
| `prompt`           | Obavezno za standardno generisanje; poboljšanje nacrta ne dozvoljava prepisivanje originalnog upita                                        |
| `duration`         | Za t2v/i2v je ceo broj od 5–20 sekundi, za v2v ceo broj od 5–15 sekundi, ili `auto`; konačno trajanje izlaza može se neznatno razlikovati od zahtevane vrednosti |
| `resolution`       | `hd`, `fhd`, `qhd`, `uhd`; podrazumevano za standardno generisanje je `hd`, a za poboljšanje nacrta `fhd`              |
| `aspect_ratio`     | `auto`, `21:9`, `2:1`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `9:21`   |
| `draft`            | Da li prvo generisati nacrt; nacrt podržava samo `hd`                                           |
| `generate_audio`   | Da li generisati sinhronizovani audio; `false` je važeća vrednost, zadržite eksplicitnu Bulovu vrednost                               |
| `safety_tolerance` | Opcionalno; ceo broj od 0–4                                                   |
| `async`            | Preporučuje se postaviti na `true`, odmah vraća ID zadatka platforme, zatim se rezultat periodično proverava                                |
| `callback_url`     | Opcionalno; HTTP(S) adresa koja prima konačni JSON rezultat; nakon postavljanja se takođe prihvata asinhrono                        |

URL materijala mora biti dostupan servisu za čitanje. Ako koristite privremeni potpisani URL, rezervišite dovoljno vremena važenja za preuzimanje i obradu. Nemojte koristiti adresu web stranice kao adresu datoteke slike ili videa.

## 3. Generisanje videa iz teksta: kompletan testirani zahtev i rezultat

Sledeći zahtev je uspešno izvršen na produkcionom interfejsu pre promene cena 2026-10-02. Izostavljanje `action` potvrdilo je podrazumevano ponašanje generisanja; `async=true` izbegava dugo čekanje HTTP veze.

```bash
curl -X POST 'https://api.acedata.cloud/flux/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light, steady camera, no text.",
    "duration": 5,
    "resolution": "hd",
    "draft": true,
    "async": true
  }'
```

Odgovor o prihvatanju (stvarni ID zadatka):

```json
{
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607"
}
```

Sačuvajte `task_id` iz sopstvenog odgovora i nastavite sa upitom; nemojte koristiti ID zadatka iz primera dokumentacije za upit rezultata drugih naloga.

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"zamenite task_id-jem vraćenim ovog puta"}'
```

Polje `response` vraćeno upitom zadatka sadrži konačni poslovni rezultat. Sledeće je `response` uspešnog rezultata ovog testiranja, pri čemu su izostavljeni metapodaci spoljnog zadatka. URL videa u dokumentaciji je zamenjen kopijom iste datoteke na dugoročnom primer CDN-u (SHA-256 je isti); stvarni poziv će vratiti URL rezultata sopstvenog zadatka ovog puta:

  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607",
  "data": [
    {
      "id": "4341eb66-3845-4972-bb86-712a6cfae845",
      "model": "flux-3",
      "video_url": "https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4",
      "seconds": 5.041667,
      "width": 1280,
      "height": 704,
      "fps": 24,
      "draft_task_id": "4341eb66-3845-4972-bb86-712a6cfae845"
    }
  ],
  "usage": {
    "action": "generate",
    "seconds": 5.041667,
    "output_mp_seconds": 4.3326825781250005,

[Pogledajte video iz ovog praktičnog testiranja](https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4)。Provera medija potvrđuje da je izlaz MP4 od 1280×704, 24 fps i 5.041667 sekundi, veličine datoteke 2,607,276 bajtova.

| Polje odgovora                              | Namena                                       |
| --------------------------------- | ---------------------------------------- |
| `success`                         | Da li je konačni zadatak uspešan; `task_id` vraćen u fazi prihvatanja ne znači `success=true` |
| `task_id`                         | ID zadatka platforme, koristi se za anketiranje i idempotentnu poslovnu obradu                      |
| `trace_id`                        | Dostavlja se osoblju podrške prilikom rešavanja problema                             |
| `data[].video_url`                | Adresa rezultata videa kojoj se može pristupiti                               |
| `data[].seconds/width/height/fps` | Stvarno trajanje izlaza, dimenzije i broj kadrova u sekundi koje je izmerio server                       |
| `data[].draft_task_id`            | Ulazni ID za poboljšanje nacrta; pojavljuje se samo kada se vrati nacrt koji se može ponovo koristiti                  |
| `usage`                           | Konačna naplativa potrošnja; ne koristite zahtevani `duration` da biste prepisali stvarni `seconds`      |
| `cost.amount`                     | Credits konačno naplaćeni ovom prilikom; `currency=credit` nije američki dolar   |
| `cost.list_amount`                | Credits pre popusta na potrošnju za korisnike aplikacije; vraća se kada je primenljivo                 |

Ovo je istorijsko praktično testiranje pre promene cena: `list_amount=2.9871876975` Credits, nalog je tada imao popust od 10% na potrošnju, a stvarni `amount=2.68846892775` Credits. Nova cena od 2026-10-02 smanjena je za približno 6.33%; isti nacrt od 5.041667 sekundi po trenutnoj ceni iznosi 2.798125185 Credits (pre popusta na potrošnju), a ako i dalje postoji popust od 10% na potrošnju, iznosi 2.5183126665 Credits. Računi za istorijske zadatke se ne obračunavaju ponovo. Paketi i popusti drugih naloga mogu biti drugačiji; ovo nije fiksna cena u američkim dolarima za sve korisnike.

## 4. Slika u video: obični i sa vremenskim ključnim kadrovima

Slede primeri parametara, potrebno je zameniti URL-ove materijala, i ne predstavljaju tvrdnju da je ovaj primer već uspešno izvršen. Nakon završetka generisanja, izvršite upit prema gorenavedenom procesu, struktura rezultata je ista.

Jedna ili dve slike koriste običan niz:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "The camera slowly moves around the product in soft studio light.",
  "keyframes": ["https://example.com/first-frame.jpg"],
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "async": true
}
```

Kada se navodi trenutak ključnog kadra, koristite par `[broj sekundi, URL slike]`:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "A smooth transition from morning light to a warm sunset.",
  "keyframes": [[0, "https://example.com/start.jpg"], [5, "https://example.com/end.jpg"]],
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

Dozvoljeno je 1–10 ključnih kadrova. Nizovi sa vremenom moraju biti u rastućem redosledu vremena, vreme je od 0–20 sekundi, a obični URL-ovi i stavke sa vremenom ne mogu se kombinovati. Za tri ili više običnih ključnih kadrova mora se eksplicitno navesti `duration`, ne može se koristiti `auto`.

## 6. Prvo nacrt, zatim poboljšanje

1. Generišite nacrt pomoću `draft=true`、`resolution=hd` i sačekajte uspešan završetak.
2. Preuzmite ID nacrta platforme iz konačnog `data[0].draft_task_id`.
3. Koristite akreditive aplikacije istog vlasništva za slanje zahteva za poboljšanje:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "draft_enhance",
  "draft_task_id": "替换为自己的已完成草稿 ID",
  "resolution": "fhd",
  "async": true
}
```

Poboljšanje nacrta ne može primiti `prompt`、`duration`、`aspect_ratio`、`version`、`generate_audio`、`draft`、`keyframes`、`start_video` za prepisivanje originalnog sadržaja. Keš nacrta je privremeni resurs, poboljšajte ga na vreme; ne garantuje se trajno čuvanje ili fiksan broj dana zadržavanja. Nacrti koji nisu vaši/nacrti trenutne aplikacije, nezavršeni nacrti i istekli keš ne mogu se ponovo koristiti. Nacrt i poboljšanje su dva zadatka i naplaćuju se zasebno nakon uspešnog završetka.

## 7. Python poziv od početka do kraja

Instalirajte `requests`, podesite sopstveni Token i pokrenite skriptu ispod da biste dovršili „jedno slanje → anketiranje → izlaz video URL-a“. I upiti i mrežni ponovni pokušaji treba da koriste originalni task_id, kako bi se izbeglo ponavljanje slanja zadataka koji se naplaćuju.
```python
import os
import time
import requests

base_url = "https://api.acedata.cloud"
headers = {
    "Authorization": "Bearer " + os.environ["ACEDATACLOUD_API_TOKEN"],
    "Accept": "application/json",
}
payload = {
    "action": "generate",
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light.",
    "duration": 5,
    "resolution": "hd",
    "draft": True,
    "async": True,
}
submitted = requests.post(base_url + "/flux/videos", json=payload, headers=headers, timeout=120)
submitted.raise_for_status()
accepted = submitted.json()
if accepted.get("error"):
    raise RuntimeError(accepted["error"])
task_id = accepted["task_id"]
print("Task ID:", task_id)  # 持久化保存，用于恢复轮询

# 30 分钟是本示例的客户端等待上限，不是服务的完成时限承诺。
deadline = time.monotonic() + 30 * 60
while time.monotonic() < deadline:
    polled = requests.post(
        base_url + "/flux/tasks",
        json={"action": "retrieve", "id": task_id},
        headers=headers,
        timeout=30,
    )
    polled.raise_for_status()
    task = polled.json()
    if task.get("error"):
        raise RuntimeError(task["error"])
    result = task.get("response") or task.get("result")
    if isinstance(result, dict) and result.get("success") is True:
        print("Video:", result["data"][0]["video_url"])
        print("Usage:", result.get("usage"))
        print("Cost:", result.get("cost"))
        break
    if isinstance(result, dict) and result.get("error"):
        raise RuntimeError(result["error"])
    time.sleep(10)
else:
    raise TimeoutError("Still processing; resume polling with task_id=" + task_id)
```

Nakon mrežnog vremenskog ograničenja, ne tretirajte nepoznato stanje kao neuspeh i ne šaljite odmah ponovo zahtev. Ako je `task_id` već dobijen, nastavite da upitujete taj zadatak; zabeležite `task_id` i `trace_id` radi otklanjanja problema. Sam interfejs za anketiranje ne naplaćuje troškove generisanja.

## 8. Korišćenje povratnog poziva

Prilikom slanja dodajte `callback_url`; nakon završetka zadatka, konačni JSON rezultat će biti poslat POST zahtevom na tu adresu, struktura uspeha je ista kao prethodno navedeni response, dok neuspeh sadrži error.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "t2v",
  "prompt": "A small sailboat on calm water.",
  "duration": 5,
  "resolution": "hd",
  "draft": true,
  "callback_url": "https://your-server.example/flux-callback"
}
```

Adresa povratnog poziva treba da bude dostupna sa javnog interneta. Nakon prijema obaveštenja, obradite ga idempotentno prema `task_id`, što pre vratite 2xx; poslovna obrada može biti stavljena u red. Ovaj tekst ne navodi da povratni poziv ima autentifikaciju potpisom: pre osetljivih operacija kao što je dodela poslovnih prava, koristite sopstveni Token da upitate isti zadatak i proverite rezultat. Ako povratni poziv nije primljen, možete nastaviti sa anketiranjem, nemojte ponovo generisati.

## 9. Trenutna naplata i cenovnik

Ažurirano 2026-10-02: jedinične cene svih nivoa ovog video interfejsa snižene su za približno 6,33%, dok način merenja, paketi i pravila popusta na potrošnju ostaju nepromenjeni. Cost u prethodnim istorijskim stvarnim response primerima je račun u trenutku završetka zadatka i ne predstavlja trenutnu ponudu.

Generisanje videa se naplaćuje prema **stvarnom broju izlaznih sekundi**. U nastavku su trenutne jedinične cene u Credits bez primenjenog popusta na potrošnju naloga, u skladu sa pravilima na [Flux stranici sa cenama](https://platform.acedata.cloud/services/flux?tab=pricing).

| ------------------ | --- | ---------: |
| t2v / i2v nacrt       | hd  |  0.555 / sekundi |
| v2v nacrt             | hd  |   1.11 / sekundi |
| t2v / i2v / poboljšanje odgovarajućeg nacrta | hd  | 1.5725 / sekundi |

Preračunavanje u američke dolare: `stvarni trošak (USD) = cost.amount (Credits) × price paketa / amount paketa`. Za neuspele zadatke se ne naplaćuje trošak generisanja; konačni iznos zavisi od rezultata završetka i evidencije poziva u kontrolnoj tabli.

## 10. Česta pitanja i otklanjanje problema

| Situacija                       | Preporuka                                                   |
| ------------------------ | ---------------------------------------------------- |
| Greška parametra (400)                | Proverite action=generate, mode, duration, format ključnih kadrova; ne mešajte polja različitih režima generisanja |
| Greška autentifikacije (401)                | Proverite Bearer Token, dozvole aplikacije i da li su akreditivi važeći                          |
| Odbijeno zbog moderacije sadržaja (403)              | Prilagodite materijale i prompt, ne šaljite više puta identičan zahtev                                    |
| Ograničenje učestalosti (429)                  | Smanjite konkurentnost, ponovite pokušaj uz eksponencijalno čekanje                                            |
| service_unavailable（503） | Trenutna operacija nije dostupna; već prihvaćeni asinhroni zadaci mogu prijaviti ovu grešku u konačnom response-u                |
| task_id je vraćen, ali video još ne postoji        | Nastavite da upitujete response, ne tretirajte HTTP 200 kao završetak generisanja                     |
| Nacrt se ne može ponovo koristiti                   | Potvrdite sopstveni/trenutni aplikacioni nalog, da je zadatak završen, da je originalni zahtev imao draft=true, i proverite da li je privremena keš memorija još važeća          |

Prilikom slanja povratnih informacija navedite `task_id`, `trace_id`, vreme zahteva i maskirane parametre, ne šaljite API Token. Za više načina pogledajte [Flux MCP vodič za integraciju](https://platform.acedata.cloud/documents/flux-mcp).
