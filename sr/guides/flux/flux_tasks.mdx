Glavna funkcija Flux Tasks API-ja je da kroz unos ID-ja zadatka platforme koji vraća Flux Images Generation API ili Flux Videos API, upita status izvršavanja tog zadatka.

Ovaj dokument će detaljno predstaviti uputstva za integraciju Flux Tasks API-ja, pomažući vam da lako integrišete i u potpunosti iskoristite moćne funkcije ovog API-ja. Putem Flux Tasks API-ja, možete lako realizovati upit o statusu izvršavanja zadataka Flux Images Generation API-ja.

Za potpuni primer slanja videa i anketiranja, pogledajte [Vodič za integraciju Flux Videos API-ja](https://platform.acedata.cloud/documents/flux-videos-integration). Upit postojećih zadataka ne naplaćuje dodatne troškove generisanja.

## Proces prijave

Da biste koristili Flux Images Generation API, najpre preuzmite svoj API Token na [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications), i sačuvajte ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon završetka ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe za zasebnom prijavom za svaku uslugu.** Pri prvoj prijavi dobićete besplatni kredit, koji možete koristiti za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Potpuna dokumentacija: [Flux Images Generation API →](https://platform.acedata.cloud/documents/flux-images)

## Primer zahteva

Flux Tasks API se može koristiti za upit rezultata Flux Images Generation API-ja. O tome kako koristiti Flux Images Generation API, pogledajte dokumentaciju [Flux Images Generation API](https://platform.acedata.cloud/documents/flux-images-integration).

Uzećemo jedan ID zadatka koji vraća usluga Flux Images Generation API kao primer, da prikažemo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: 2db0168c-2373-4367-8d9a-9dc778802e8a, u nastavku se prikazuje kako kroz prosleđivanje jednog ID-ja zadatka.

### Podešavanje zaglavlja zahteva i tela zahteva

**Request Headers** uključuje:

- `accept`: određuje primanje rezultata odgovora u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, nakon prijave može se direktno izabrati iz padajućeg menija.

**Request Body** uključuje:

- `id`: ID otpremljenog zadatka.
- `action`: način operacije nad zadatkom.

Podešavanje je prikazano na sledećoj slici:

### Primer koda

Možete primetiti da je na desnoj strani stranice automatski generisan kod na različitim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/j6gn86.png" width="500" className="m-auto" /></p>

Neki primeri koda su sledeći:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "2c454ff3-4f8f-47f0-8147-acb29a84d1c2",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/flux/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "2c454ff3-4f8f-47f0-8147-acb29a84d1c2",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Vraćeni rezultat ukupno ima više polja, polje request je request body prilikom pokretanja zadatka, dok je polje response response body vraćen nakon završetka zadatka. Opis polja je sledeći.

- `id`, ID generisanog zadatka slike, koristi se za jedinstvenu identifikaciju ovog zadatka generisanja slike.
- `request`, informacije o zahtevu u upitu zadatka slike.
- `response`, informacije o odgovoru u upitu zadatka slike.
- `created_at`, vreme kreiranja zadatka, Unix vremenska oznaka (sekunde, decimalni broj).
- `started_at`, vreme početka izvršavanja zadatka, Unix vremenska oznaka (sekunde, decimalni broj).
- `finished_at`, vreme završetka zadatka, Unix vremenska oznaka (sekunde, decimalni broj). Ovo polje se ne vraća kada zadatak nije završen.
- `elapsed`, vreme trajanja izvršavanja zadatka, jedinica je sekunda (decimalni broj, zadržava 3 decimale). Ovo polje se ne vraća kada zadatak nije završen.

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neovlašćeno, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, prekoračili ste ograničenje brzine.
- `500 api_error`：Interna greška servera, nešto je pošlo po zlu na serveru.
