Glavna funkcija Flux Tasks API je da omogućava praćenje statusa izvršenja zadatka putem ID-a zadatka generisanog Flux Images Generation API.

Ovaj dokument će detaljno opisati integraciju Flux Tasks API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Flux Tasks API, možete lako pratiti status izvršenja zadatka Flux Images Generation API.

## Proces prijave

Da biste koristili Flux Tasks API, prvo treba da odete na stranicu za prijavu [Flux Images Generation API](https://platform.acedata.cloud/documents/6b9197c5-7a3f-4878-a43f-7f94e7e66394) i zatražite odgovarajuću uslugu, a zatim kopirajte ID zadatka Flux Images Generation API, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/7furhb.png" width="500" class="m-auto"></p>

Na kraju, idite na stranicu Flux Tasks API [Flux Tasks API](https://platform.acedata.cloud/documents/39b38bbe-60f3-40da-b2b6-5ce1e091852b) da zatražite odgovarajuću uslugu, a nakon ulaska na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici.

![Stranica za prijavu](https://cdn.acedata.cloud/rci31i.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na [stranicu za prijavu](https://platform.acedata.cloud) koja vas poziva da se registrujete i prijavite. Nakon prijave ili registracije, automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatni kredit koji možete koristiti za ovaj API.

## Primer zahteva

Flux Tasks API može se koristiti za praćenje rezultata Flux Images Generation API. O tome kako koristiti Flux Images Generation API, molimo vas da se obratite dokumentu [Flux Images Generation API](https://platform.acedata.cloud/documents/flux-images-integration).

Uzmimo jedan ID zadatka koji je vratio Flux Images Generation API kao primer i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: 2db0168c-2373-4367-8d9a-9dc778802e8a, a zatim ćemo prikazati kako da ga prosledimo.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se šalje.
- `action`: način na koji se operiše sa zadatkom.

Postavite kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/fiasxz.png" width="500" class="m-auto"></p>

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na raznim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/j6gn86.png" width="500" class="m-auto"></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "2c454ff3-4f8f-47f0-8147-acb29a84d1c2",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/flux/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "2c454ff3-4f8f-47f0-8147-acb29a84d1c2",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Greška u obradi

U slučaju da dođe do greške prilikom pozivanja API-ja, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`：Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`：Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste limit brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.
