Pretvara audio u tekst, **potpuno kompatibilan sa OpenAI-ovim `/v1/audio/transcriptions`**. Bilo koji OpenAI SDK samo treba da postavi `base_url` na `https://api.acedata.cloud`, a ključ zameni svojim AceData Token-om i može se direktno koristiti. Podržava obične potpune odgovore, kao i SSE inkrementalno prepisivanje za `gpt-transcribe`.

- **URL zahteva**: `POST https://api.acedata.cloud/v1/audio/transcriptions` (alias `POST /openai/audio/transcriptions`)
- **Autentifikacija**: zaglavlje zahteva `Authorization: Bearer {token}`
- **Format zahteva**: `multipart/form-data`
- **Naplaćivanje**: naplaćuje se prema dužini audio zapisa (vidi tabelu ispod), manje od 1 sekunde se naplaćuje kao 1 sekunda.

## Parametri zahteva

| Polje                        | Tip      | Obavezno | Objašnjenje                                                                                     |
| --------------------------- | ------- | --- | ------------------------------------------------------------------------------------------ |
| `file`                      | file    | Da   | Audio fajl koji treba prepisati, maksimalno 25 MB. Podržava `flac`, `mp3`, `mp4`, `mpeg`, `mpga`, `m4a`, `ogg`, `wav`, `webm`.            |
| `model`                     | string  | Ne   | `whisper-1` (podrazumevano) ili `gpt-transcribe`, razlike u sposobnostima vidi u tabeli ispod.                                                 |
| `language`                  | string  | Ne   | Jezik audio zapisa, ISO-639-1 kod (npr. `zh`, `en`). Popunjavanje može poboljšati tačnost i brzinu; ako je prazno, automatski se prepoznaje.                                        |
| `prompt`                    | string  | Ne   | Uputstvo za vođenje stila pisanja, ili pružanje specijalnih imena, termina za poboljšanje tačnosti prepoznavanja.                                                           |
| `response_format`           | string  | Ne   | `whisper-1`: `json` (podrazumevano), `text`, `srt`, `verbose_json`, `vtt`; `gpt-transcribe`: samo `json`, `text`. |
| `temperature`               | number  | Ne   | Temperatura uzorkovanja 0–1, podrazumevano 0.                                                                             |
| `timestamp_granularities[]` | array   | Ne   | Granularnost vremenskih oznaka, `word` ili `segment`, mora se koristiti sa `response_format=verbose_json`.                            |
| `languages[]`               | array   | Ne   | Kandidati jezika (ISO-639-1), **samo `gpt-transcribe`**. Sukob sa `language`, ne šaljite oba.                              |
| `keywords[]`                | array   | Ne   | Specijalna imena/termini, **samo `gpt-transcribe`**, može značajno poboljšati tačnost prepoznavanja brendova i imena.                                        |
| `stream`                    | boolean | Ne   | Kada je `gpt-transcribe` postavljeno na `true`, vraća SSE inkrementalne događaje; `whisper-1` će ignorisati ovaj parametar i vratiti potpuni rezultat (u skladu sa zvaničnim ponašanjem OpenAI).        |

## Koji model izabrati

|                              | `whisper-1`      | `gpt-transcribe`      |
| ---------------------------- | ---------------- | --------------------- |
| Cena                           | $0.0078 / minut     | **$0.0059 / minut** (jeftinije) |
| Tačnost prepoznavanja            | Dobra               | **Bolja**, posebno za brendove i specijalna imena    |
| Izlaz titlova (`srt`/`vtt`)        | ✅                | ❌                     |
| Vremenske oznake po rečima        | ✅                | ❌                     |
| `languages[]` / `keywords[]` | ❌                | ✅                     |
| Vraća prepoznati jezik             | zahteva `verbose_json` | podrazumevano vraća                  |
| SSE inkrementalni povratak       | ❌ ( `stream` se ignoriše)  | ✅                     |

**Potrebni titlovi ili vremenske oznake po rečima → `whisper-1`; za ostale scenarije preporučuje se `gpt-transcribe`** (tačnije i jeftinije).

## Primer

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/transcriptions' \
  -H 'authorization: Bearer {token}' \
  -F file=@audio.mp3 \
  -F model=whisper-1
```

Povratak:

```json
{
  "text": "Ace Data Cloud Platform is testing the speech recognition endpoint. The quick brown fox jumps over the lazy dog."
}
```

Kineski audio takođe podržava, bez potrebe za navođenjem jezika:

```json
{
  "text": "欢迎使用 AceData Cloud 平台,我们正在测试语音识别接口,今天是 7 月 31 号。"
}
```

### Generisanje titlova

Postavite `response_format` na `srt` ili `vtt`, da biste direktno dobili upotrebljivu titlovanu datoteku:

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/transcriptions' \
  -H 'authorization: Bearer {token}' \
  -F file=@audio.mp3 \
  -F model=whisper-1 \
  -F response_format=srt \
  -o subtitle.srt
```

Povratni sadržaj (`Content-Type: text/plain`):

```
1
00:00:00,000 --> 00:00:03,800
Ace Data Cloud Platform is testing the speech recognition endpoint.

2
00:00:03,800 --> 00:00:06,280
The quick brown fox jumps over the lazy dog.
```

### Vremenske oznake po rečima

Ako su potrebna vremena početka i završetka za svaku reč, koristite `verbose_json` u kombinaciji sa `timestamp_granularities[]=word`:

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/transcriptions' \
  -H 'authorization: Bearer {token}' \
  -F file=@audio.mp3 \
  -F model=whisper-1 \
  -F response_format=verbose_json \
  -F 'timestamp_granularities[]=word'
```

Povratak:

```json
{
  "task": "transcribe",
  "language": "english",
  "duration": 6.29,
  "text": "Ace Data Cloud Platform is testing the speech recognition endpoint. The quick brown fox jumps over the lazy dog.",
  "words": [
    {
      "word": "Ace",
      "start": 0.0,
      "end": 0.32
    },
    {
      "word": "Data",
      "start": 0.32,
      "end": 0.54
    },
    {
      "word": "Cloud",
      "start": 0.54,
      "end": 0.86
    }
  ]
}
```

### Stream prepisivanje

`gpt-transcribe` može da vrati `Content-Type: text/event-stream` putem `stream=true`. Usluga će slati OpenAI kompatibilne događaje:
`transcript.text.delta` nosi inkrementalni tekst, `transcript.text.done` nosi kompletan tekst i `usage` i označava normalno završavanje.

```shell
curl -N -X POST 'https://api.acedata.cloud/v1/audio/transcriptions' \
  -H 'authorization: Bearer {token}' \
  -F file=@audio.mp3 \
  -F model=gpt-transcribe \
  -F stream=true
```

Primer događaja:

```text
data: {"type":"transcript.text.delta","delta":"Hello"}

data: {"type":"transcript.text.done","text":"Hello world","usage":{"type":"tokens","input_tokens":14,"output_tokens":3,"total_tokens":17}}
```

Primanje `transcript.text.done` označava normalno završavanje. Ako dođe do greške nakon uspostavljanja toka, veza će se završiti nakon `event: error` događaja; ako klijent aktivno prekine, to će otkazati trenutnu obradu i neće se nastaviti u pozadini. `whisper-1` će, čak i ako se prosledi `stream=true`, i dalje vraćati običan ne-streaming odgovor.

### Korišćenje zvaničnog SDK-a
```python
from openai import OpenAI

client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
with open("audio.mp3", "rb") as f:
    result = client.audio.transcriptions.create(model="whisper-1", file=f)
print(result.text)
```

## Cene

| Model              | Cena na platformi  |
| ------------------ | ------------------ |
| `whisper-1`       | $0.0078 / minut    |
| `gpt-transcribe`  | $0.0059 / minut    |

> Naplata se vrši prema stvarnom trajanju audio zapisa, a ako je manje od 1 sekunde, naplaćuje se kao 1 sekunda, a maksimalno trajanje po jednom zahtevu je 1 sat.

## Napomene

- Maksimalna veličina pojedinačnog fajla je **25 MB**. Ako je veći, prvo ga podelite ili kompresujte (smanjenje bitrate-a obično je dovoljno, a zahtevi za kvalitetom zvuka nisu visoki).
- `gpt-transcribe` podržava `stream=true` SSE; `whisper-1` će ignorisati `stream` i vratiti potpuni rezultat.
- Parametri su u skladu sa OpenAI zvaničnim `/v1/audio/transcriptions`, zvanični SDK samo treba da promeni `base_url` da bi se koristio.
- `include[]`, `chunking_strategy`, `known_speaker_names[]`, `known_speaker_references[]` su naši modeli transkripcije koji nisu dostupni, njihovo prosleđivanje će vratiti 400 umesto da bude tiho ignorisano. Parametri specifični za modele (`timestamp_granularities[]` za `whisper-1`, `languages[]`/`keywords[]` za `gpt-transcribe`) takođe će vratiti 400 kada se proslede modelima koji ih ne podržavaju.
- Zahtevi su prilično vremenski zahtevni, preporučuje se da klijentska vremenska ograničenja budu postavljena na najmanje 300 sekundi.

## Kodovi grešaka

| Status kod | code                    | Opis                                                                                                                                                   |
| ---------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 400        | `bad_request`           | `file` nije pružen, fajl se ne može obraditi, ili su parametri neispravni (`model`/`response_format` nisu podržani, `temperature` van 0–1, `timestamp_granularities[]` nije u skladu sa `verbose_json`, prosleđeni su parametri koji nisu podržani od strane `whisper-1`). |
| 401        | `authentication_failed` | token je nevažeći.                                                                                                                                   |
| 403        | `used_up`               | Nedovoljno sredstava.                                                                                                                                 |
| 413        | `request_too_large`     | Audio fajl premašuje gornju granicu od 25 MB.                                                                                                         |
| 429        | `too_many_requests`     | Previše zahteva, molimo pokušajte ponovo kasnije.                                                                                                     |
| 500        | `api_error`             | Interna greška na serveru, molimo pokušajte ponovo kasnije.                                                                                           |
