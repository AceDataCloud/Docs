OpenAI je nedavno pružio interfejs za kreiranje odgovora modela. Obezbedite tekstualni ili slikovni unos za generisanje tekstualnog ili slikovnog izlaza. Omogućite modelu da poziva vaš sopstveni prilagođeni kod ili koristi ugrađene alate, kao što su web pretraga ili pretraga datoteka, kako bi koristio vaše sopstvene podatke kao ulaz za odgovor modela.

Ovaj dokument uglavnom predstavlja proces korišćenja OpenAI Responses API operacija, uz pomoć kojeg možemo lako koristiti zvaničnu OpenAI funkciju za kreiranje odgovora modela.

## GPT-6.1 Sol

Koristite `model: "gpt-6.1-sol"` da biste izabrali ovaj model. Podržava strimovani izlaz, pozivanje funkcija, strukturisani izlaz i slikovni unos. Tokom prve nedelje od otvaranja, dostupan je samo verifikovanim ACE T1+ vlasnicima (najmanje 100.000 ACE) ili ovlašćenim korisnicima; konkretno vreme dostupnosti zavisi od obaveštenja o pristupu u konzoli.

Nivoi rezonovanja podržavaju `low`, `medium`, `high`, `xhigh` i `max`, dok `none` ili `minimal` trenutno nisu podržani. Preporučuje se da počnete sa `reasoning: {"effort": "low"}`. Kada unos premaši 272.000 tokena, cena dugog konteksta primenjuje se na ceo zahtev, a troškovi zavise od trenutne cene u konzoli.

## Proces prijave

Da biste koristili OpenAI Responses API, najpre idite u [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications) da biste dobili svoj API Token i sačuvali ga kao rezervu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon završetka automatski ćete biti vraćeni na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe da se prijavljujete posebno za svaku uslugu.** Prva prijava donosi besplatan kredit, koji možete koristiti za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti opšti saldo u [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [OpenAI Responses API →](https://platform.acedata.cloud/documents/openai-responses)

## Osnovno korišćenje

Zatim možete popuniti odgovarajući sadržaj u interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/8lu8di.png" width="400" className="m-auto" /></p>

Kada prvi put koristimo ovaj interfejs, potrebno je da popunimo najmanje tri stavke, jedna je `authorization`, koju možete direktno izabrati sa padajuće liste. Drugi parametar je `model`, `model` je kategorija modela sa zvaničnog OpenAI ChatGPT sajta koju biramo da koristimo, ovde uglavnom imamo 20 modela, a detalje možete pogledati u modelima koje nudimo. Poslednji parametar je `input`, `input` je niz upita koje unosimo, to je niz koji označava da se može istovremeno otpremiti više upita, svaki upit sadrži `role` i `content`, pri čemu `role` označava ulogu osobe koja postavlja pitanje, nudimo tri identiteta, a to su `user`, `assistant`, `system`. Drugi, `content`, predstavlja konkretan sadržaj našeg pitanja.

Istovremeno možete primetiti da se sa desne strane generiše odgovarajući kod za pozivanje, možete kopirati kod i direktno ga pokrenuti, ili direktno kliknuti na dugme „Try“ radi testiranja.

Često korišćeni opcioni parametri:

- `max_tokens`: ograničava maksimalni broj tokena u jednom odgovoru.
- `temperature`: slučajnost generisanja, između 0 i 2, što je vrednost veća, rezultat je raspršeniji.
- `n`: koliko kandidata odgovora se generiše odjednom.
- `response_format`: podešavanje formata povratne vrednosti.
- `tools`: definicija pozivanja funkcija/alata.
- `background`: da li se asinhrono izvršava u pozadini.

## Strimovani odgovor

Ovaj interfejs takođe podržava strimovane odgovore, što je veoma korisno za povezivanje sa veb-stranicama i može omogućiti efekat prikazivanja reč po reč na veb-stranici.

Ako želite da vratite odgovor strimovano, možete promeniti parametar `stream ` u zaglavlju zahteva na `true`.

Izmena je prikazana na slici, ali kod za pozivanje mora imati odgovarajuće izmene kako bi podržao strimovani odgovor.

<p><img src="https://cdn.acedata.cloud/xidnao.png" width="400" className="m-auto" /></p>

Nakon što se `stream` promeni na `true`, API će vraćati odgovarajuće JSON podatke red po red, a na nivou koda potrebno je da napravimo odgovarajuće izmene kako bismo dobili rezultat red po red.

Primer Python koda za pozivanje:

```python
import requests

url = "https://api.acedata.cloud/openai/responses"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Može se videti da se u odgovoru nalazi mnogo `data` stavki, a `delta` unutar `data` je najnoviji sadržaj odgovora, što je u skladu sa prethodno predstavljenim sadržajem. `delta` je novododati sadržaj odgovora, možete ga na osnovu rezultata povezati sa svojim sistemom. Striming odgovor ima `response.completed` ili `response.incomplete` kao krajnje stanje; `usage` u krajnjem stanju je konačna potrošnja tokena za ovaj zahtev, a ujedno je i osnova za naplatu.

Ako klijent prekine vezu pre dolaska krajnjeg stanja, ovaj zahtev se beleži kao zatvoren od strane klijenta (499) i neće se naplaćivati na osnovu lokalno procenjenih tokena; ako se veza normalno završi, ali krajnje stanje i konačni `usage` nisu primljeni, ovaj zahtev se beleži kao nepotpun odgovor (502), i takođe se neće naplaćivati na osnovu procenjenih tokena. Kada se susretnete sa ove dve situacije, ponovo pokrenite zahtev.

Vraćeni rezultat `data` ukupno ima više polja, koja su predstavljena u nastavku:

- `item_id`, ID generisanog zadatka ovog razgovora, koji se koristi za jedinstvenu identifikaciju ovog zadatka razgovora.
- `type`, tip generisanog Responses zadatka ovog razgovora.
- `model `, izabrani model sa zvaničnog sajta OpenAI ChatGPT-a.
- `delta`, informacije odgovora koje ChatGPT daje na upit.

JavaScript je takođe podržan, na primer, kod za striming poziv u Node.js-u je sledeći:

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer b82d32f570bc434d9ba9923aa0e7dce0",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4.1",
    input: [{ role: "user", content: "Hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/responses", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

Primer Java koda:

```java
JSONObject jsonObject = new JSONObject();

  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.print(response.body!!.string())
```

## Vizuelni model

gpt-4o je multimodalni veliki jezički model koji je razvio OpenAI i koji, na osnovi GPT-4, dodaje sposobnost vizuelnog razumevanja. Ovaj model može istovremeno da obrađuje tekstualne i slikovne unose, ostvarujući međumodalno razumevanje i generisanje.
Obrada teksta korišćenjem modela gpt-4o ista je kao osnovni sadržaj korišćenja iznad, u nastavku će biti ukratko predstavljeno kako koristiti sposobnost modela za obradu slika.

Sposobnost obrade slika modela gpt-4o uglavnom se koristi dodavanjem polja `type` na osnovu originalnog sadržaja `content`; preko ovog polja može se znati da li se otprema tekst ili slika, kako bi se koristila sposobnost obrade slika modela gpt-4o. U nastavku se uglavnom opisuje pozivanje ove funkcije na dva načina: Curl i Python.

- Način Curl skripte

```
curl -X POST 'https://api.acedata.cloud/openai/responses' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4.1",
    "input": [
      {
        "role": "user",
        "content": [
          {"type": "input_text", "text": "what is in this image?"},
          {
            "type": "input_image",
            "image_url": "https://cdn.acedata.cloud/e724d7f13d.png"
          }
        ]
      }
    ]
  }'
```

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i poruku. Na primer:

- `400 token_mismatched`：Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neovlašćeno, nevažeći ili nedostajući token za autorizaciju.
- `429 too_many_requests`：Previše zahteva, prekoračili ste ograničenje broja zahteva.
- `500 api_error`：Interna greška servera, nešto je pošlo po zlu na serveru.
