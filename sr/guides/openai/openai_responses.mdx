Zahtevi za kompatibilne modele koje platforma prihvata naplaćuju se prema korišćenju ulaza, izlaza i keša modela. Ukupan obim Responses ulaza uključuje prijavljene keš tokene, a keš deo se obračunava prema odgovarajućoj ceni keša; promena formata interfejsa neće preći na naplatu po fiksnom broju poziva. Troškovi se određuju prema trenutnim cenama modela u kontrolnoj tabli i response usage.cost.

OpenAI je nedavno obezbedio interfejs za kreiranje odgovora modela. Obezbedite tekstualni ili slikovni ulaz za generisanje tekstualnog ili slikovnog izlaza. Omogućite modelu da poziva vaš sopstveni prilagođeni kod ili koristi ugrađene alate, kao što su web pretraga ili pretraga datoteka, kako bi koristio vaše sopstvene podatke kao ulaz za odgovor modela.

Ovaj dokument uglavnom predstavlja proces korišćenja OpenAI Responses API-ja, pomoću kojeg možemo lako koristiti zvaničnu OpenAI funkciju za kreiranje odgovora modela.

## GPT-6.1 Terra

Koristite `model: "gpt-6.1-terra"` da izaberete ovaj model. Podržava tekstualni i slikovni ulaz, strimovani izlaz, funkcijske alate i strukturisani izlaz. Nivoi rezonovanja podržavaju `low`, `medium`, `high`, `xhigh` i `max`, preporučuje se da počnete sa `reasoning: {"effort": "low"}`; `none` ili `minimal` nisu podržani. Kada ulaz premaši 272,000 tokena, primenjuje se cena za dugačak kontekst, a stvarni troškovi zavise od trenutne cene u kontrolnoj tabli i korišćenja u odgovoru.

## GPT-6.1 Sol

Koristite `model: "gpt-6.1-sol"` da izaberete ovaj model. Podržava strimovani izlaz, pozivanje funkcija, strukturisani izlaz i slikovni ulaz. Tokom prve nedelje nakon otvaranja, dostupan je samo verifikovanim ACE T1+ vlasnicima (najmanje 100,000 ACE) ili ovlašćenim korisnicima; konkretno vreme dostupnosti zavisi od obaveštenja o pristupu u kontrolnoj tabli.

Nivoi rezonovanja podržavaju `low`, `medium`, `high`, `xhigh` i `max`, dok `none` ili `minimal` trenutno nisu podržani. Preporučuje se da počnete sa `reasoning: {"effort": "low"}`. Kada ulaz premaši 272,000 tokena, na ceo zahtev se primenjuje cena za dugačak kontekst, a troškovi zavise od trenutne cene u kontrolnoj tabli.

## Proces prijave

Da biste koristili OpenAI Responses API, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da biste dobili svoj API Token, koji sačuvajte kao rezervu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a nakon završetka automatski ćete se vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe da se posebno prijavljujete za svaku uslugu.** Pri prvoj prijavi dobićete besplatan kredit, koji možete besplatno isprobati; kada kredit nije dovoljan, možete dopuniti opšti saldo u [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [OpenAI Responses API →](https://platform.acedata.cloud/documents/openai-responses)

## Osnovno korišćenje

Zatim možete popuniti odgovarajući sadržaj u interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/8lu8di.png" width="400" className="m-auto" /></p>

Pri prvom korišćenju ovog interfejsa, potrebno je da popunimo najmanje tri sadržaja, jedan je `authorization`, koji se može direktno izabrati u padajućoj listi. Drugi parametar je `model`, `model` predstavlja kategoriju modela na zvaničnom OpenAI ChatGPT sajtu koju biramo da koristimo, ovde uglavnom imamo 20 vrsta modela, a detalje možete pogledati u modelima koje nudimo. Poslednji parametar je `input`, `input` je niz upita koji unosimo, to je niz, što znači da se može istovremeno otpremiti više upita, svaki upit sadrži `role` i `content`, pri čemu `role` predstavlja ulogu osobe koja postavlja pitanje, nudimo tri identiteta, odnosno `user`, `assistant`, `system`. Drugi `content` je konkretan sadržaj pitanja koje postavljamo.

Istovremeno možete primetiti da se na desnoj strani generiše odgovarajući kod za pozivanje, možete kopirati kod i direktno ga pokrenuti, ili možete direktno kliknuti na dugme „Try“ radi testiranja.

Često korišćeni opcioni parametri:

- `max_tokens`: ograničava maksimalan broj tokena jednog odgovora.
- `temperature`: slučajnost generisanja, između 0-2, što je vrednost veća, to je rezultat razuđeniji.
- `n`: koliko kandidata za odgovor se generiše odjednom.
- `response_format`: podešavanje formata povratne vrednosti.
- `tools`: definicija pozivanja funkcija/alata.
- `background`: da li se asinhrono pokreće u pozadini.

## Strimovani odgovor

Ovaj interfejs takođe podržava strimovane odgovore, što je veoma korisno za povezivanje sa veb-stranicama i može omogućiti efekat prikazivanja slovo po slovo na veb-stranici.

Ako želite da odgovor vraćate strimovano, možete izmeniti parametar `stream ` u zaglavlju zahteva na `true`.

Izmena je prikazana na slici, ali kod za pozivanje mora imati odgovarajuće izmene da bi podržavao strimovane odgovore.
<p><img src="https://cdn.acedata.cloud/xidnao.png" width="400" className="m-auto" /></p>

Nakon izmene `stream` na `true`, API će vraćati odgovarajuće JSON podatke red po red, a na nivou koda potrebno je da izvršimo odgovarajuće izmene kako bismo dobili rezultate red po red.

Primer Python koda za pozivanje:

```python
import requests

url = "https://api.acedata.cloud/openai/responses"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Može se videti da se u odgovoru nalazi mnogo `data`, a `delta` unutar `data` je najnoviji sadržaj odgovora, što je u skladu sa sadržajem predstavljenim iznad. `delta` je novo dodati sadržaj odgovora, a vi možete na osnovu rezultata da ga povežete sa svojim sistemom. Strimovani odgovor koristi `response.completed` ili `response.incomplete` kao završno stanje; `usage` u završnom stanju je konačna potrošnja tokena za ovaj zahtev, a ujedno je i osnova za naplatu.

Ako klijent prekine vezu pre nego što stigne završno stanje, ovaj zahtev se beleži kao klijent je zatvorio vezu (499) i neće se naplaćivati na osnovu lokalno procenjenih tokena; ako se veza normalno završi, ali završno stanje i konačni `usage` nisu primljeni, ovaj zahtev se beleži kao nepotpun odgovor (502), i takođe se neće naplaćivati na osnovu procenjenih tokena. Kada se susretnete sa ove dve situacije, ponovo pokrenite zahtev.

Vraćeni rezultat `data` ima više polja, koja su predstavljena u nastavku:

- `item_id`, ID generisanog zadatka ovog razgovora, koji se koristi za jedinstveno označavanje ovog zadatka razgovora.
- `type`, tip generisanog Responses zadatka ovog razgovora.
- `model `, izabrani model sa zvaničnog sajta OpenAI ChatGPT-a.
- `delta`, informacije o odgovoru koje ChatGPT daje na upit.

JavaScript je takođe podržan, na primer, kod za strimovani poziv u Node.js-u je sledeći:

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer YOUR_API_TOKEN",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4.1",
    input: [{ role: "user", content: "Hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/responses", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

Primer Java koda:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "gpt-4.1");
jsonObject.put("input", [{"role":"user","content":"Hello"}]);
jsonObject.put("stream", true);

  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer YOUR_API_TOKEN")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.print(response.body!!.string())
```

Ostali jezici se mogu zasebno prilagoditi, princip je isti.

## Vizuelni model

gpt-4o je multimodalni veliki jezički model koji je razvio OpenAI, a na osnovu GPT-4 dodaje mogućnost vizuelnog razumevanja. Ovaj model može istovremeno da obrađuje tekstualne i slikovne unose, ostvarujući razumevanje i generisanje između modaliteta.

Obrada teksta korišćenjem modela gpt-4o je u skladu sa sadržajem osnovne upotrebe iznad, a u nastavku će ukratko biti predstavljeno kako koristiti mogućnost obrade slika modela.

Mogućnost obrade slika modela gpt-4o uglavnom se koristi dodavanjem polja `type` na osnovu originalnog sadržaja `content`, preko ovog polja se može znati da li je otpremljen tekst ili slika, čime se koristi mogućnost obrade slika modela gpt-4o, a u nastavku se uglavnom opisuje pozivanje ove funkcije na dva načina, putem Curl-a i Python-a.

- Curl skriptni način

```
curl -X POST 'https://api.acedata.cloud/openai/responses' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4.1",
    "input": [
      {
        "role": "user",
        "content": [
          {"type": "input_text", "text": "what is in this image?"},
          {
            "type": "input_image",
            "image_url": "https://cdn.acedata.cloud/e724d7f13d.png"
          }
        ]
      }
    ]
  }'
```

- Python skriptni način

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [
      {
        "role": "user",
        "content": [
          {"type": "input_text", "text": "what is in this image?"},
          {
            "type": "input_image",
            "image_url": "https://cdn.acedata.cloud/e724d7f13d.png"
          }
        ]
      }
    ]
  }

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i poruku. Na primer:

- `400 token_mismatched`: Neispravan zahtev, verovatno zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, verovatno zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neovlašćeno, nevažeći ili nedostajući token za autorizaciju.
- `429 too_many_requests`: Previše zahteva, premašili ste ograničenje učestalosti.
- `500 api_error`: Interna greška servera, nešto je pošlo po zlu na serveru.
