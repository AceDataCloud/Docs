OpenAI usluga vektora reči, koristi se za generisanje rezultata vektora reči koji predstavljaju ulazni tekst.

Ovaj dokument uglavnom predstavlja tok korišćenja OpenAI Embeddings API operacija, pomoću kojih možemo kreirati ugrađene vektore koji predstavljaju ulazni tekst。。

## Proces prijave

Da biste koristili OpenAI Embeddings API, prvo idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications) da biste dobili svoj API Token i sačuvali ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, bićete automatski preusmereni na stranicu za prijavu gde ćete biti pozvani da se registrujete i prijavite, a po završetku ćete automatski biti vraćeni na trenutnu stranicu.

**Jedan API Token može da poziva sve usluge platforme, bez potrebe za posebnom prijavom za svaku uslugu.** Prilikom prve prijave dobijate besplatan kredit koji možete koristiti za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [OpenAI Embeddings API →](https://platform.acedata.cloud/documents/openai-embeddings)

## Osnovna upotreba

Zatim možete popuniti odgovarajući sadržaj u interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/4qtbvr.png" width="500" className="m-auto" /></p>

Prilikom prvog korišćenja ovog interfejsa, potrebno je da popunimo najmanje tri stavke, jedna je `authorization`, koju možete direktno izabrati sa padajuće liste. Drugi parametar je `model`, `model` predstavlja kategoriju modela sa zvaničnog OpenAI sajta koju biramo da koristimo, trenutno dostupni modeli su `text-embedding-3-small` i `text-embedding-3-large`. `text-embedding-ada-002` se više ne pruža; ako postojeći vektorski indeks koristi ovaj stari model, vektori novog modela se ne mogu direktno kombinovati sa njim i indeks je potrebno ponovo izgraditi. Poslednji parametar je `input`, `input` je tekst vektora reči koji treba da konvertujemo.

Istovremeno možete primetiti da se na desnoj strani generiše odgovarajući kod za pozivanje, možete kopirati kod i direktno ga pokrenuti, ili možete direktno kliknuti na dugme „Try“ radi testiranja.

Opcioni parametri:

- `dimensions`: skraćivanje dimenzija vektora, podrazumevano se vraćaju pune dimenzije.
- `encoding_format`: format povratne vrednosti, opcije su `float` ili `base64`.

<p><img src="https://cdn.acedata.cloud/gqulm9.png" width="500" className="m-auto" /></p>

Primer Python koda za pozivanje:

```python
import requests

url = "https://api.acedata.cloud/openai/embeddings"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "The food was delicious and the waiter...",
    "model": "text-embedding-3-small",
    "encoding_format": "float"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Povratni rezultat ima više polja, koja su opisana u nastavku:

- `model`, model korišćen za konvertovanje ovog teksta u vektore reči.
- `usage`, informacije o tokenima korišćenim za konvertovanje ovog teksta u vektore reči.
- `data`, rezultat vektora reči nakon konvertovanja teksta.

Među njima, `data` sadrži konkretne informacije o vektorima reči koji odgovaraju tekstu, a `embedding` unutar njega predstavlja konkretan generisani rezultat vektora reči.

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neovlašćeno, nevažeći ili nedostajući token za autorizaciju.
- `429 too_many_requests`: Previše zahteva, prekoračili ste ograničenje broja zahteva.
- `500 api_error`: Interna greška servera, nešto je pošlo po zlu na serveru.
