---
title: "OpenAI API za sintezu govora (/v1/audio/speech)"
description: "OpenAI generation API guide - Ace Data Cloud"
---

Pretvara tekst u prirodni govor, **potpuno kompatibilan sa OpenAI-ovim `/v1/audio/speech`**. Bilo koji OpenAI SDK samo treba da postavi `base_url` na `https://api.acedata.cloud`, a ključ zameni sa svojim AceData Token-om i može se direktno koristiti. Interfejs sinhrono vraća audio bajt tok.

- **Zahtev adresa**: `POST https://api.acedata.cloud/v1/audio/speech` (alias `POST /openai/audio/speech`)
- **Autentifikacija**: zaglavlje zahteva `Authorization: Bearer {token}`
- **Naplaćivanje**: naplaćuje se prema broju bajtova zahtevanog teksta, otprilike 85% zvanične cene OpenAI (vidi tabelu ispod).

## Parametri zahteva

| Polje              | Tip     | Obavezno | Objašnjenje                                                      |
| ----------------- | ------ | --- | ------------------------------------------------------------- |
| `input`           | string | Da   | Tekst koji treba da se sintetizuje.                               |
| `model`           | string | Ne   | `tts-1` (brže) ili `tts-1-hd` (bolji kvalitet zvuka, podrazumevano). |
| `voice`           | string | Ne   | Jedan od `alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`, podrazumevano `alloy`. |
| `response_format` | string | Ne   | `mp3` (podrazumevano), `opus`, `aac`, `flac`, `wav`, `pcm`.        |
| `speed`           | number | Ne   | Brzina govora 0.25–4.0, podrazumevano 1.0.                       |

## Primer

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/speech' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -o speech.mp3 \
  -d '{
    "model": "tts-1-hd",
    "input": "Šta ako jedan API pruži svaki AI video model?",
    "voice": "nova",
    "response_format": "mp3"
  }'
```

Vraća se audio fajl sam ( `Content-Type: audio/mpeg`), direktno se zapisuje u `speech.mp3` i može se reprodukovati.

Koristeći zvanični OpenAI Python SDK:

```python
from openai import OpenAI
client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
client.audio.speech.create(model="tts-1-hd", voice="nova", input="Pozdrav iz AceData.").stream_to_file("speech.mp3")
```

## Cene

| Model         | Zvanična cena OpenAI    | Cena na ovoj platformi (otprilike 85% popusta) |
| ---------- | ------------- | ------------------ |
| `tts-1`    | $15 / 1 milion karaktera | otprilike $12.75 / 1 milion karaktera |
| `tts-1-hd` | $30 / 1 milion karaktera | otprilike $25.5 / 1 milion karaktera  |

> Naplaćuje se prema broju bajtova zahtevanog teksta; polje `official_price` prikazuje zvaničnu cenu OpenAI radi poređenja.

## Kodovi grešaka

| Status kod | code                    | Objašnjenje         |
| --- | ----------------------- | ---------------- |
| 400 | `bad_request`           | `input` je prazan ili parametri su neispravni. |
| 401 | `authentication_failed` | token je nevažeći.      |
| 403 | `used_up`               | Nedovoljno sredstava.        |
| 429 | `too_many_requests`     | Previše čestih zahteva.      |
| 500 | `api_error`             | Greška na serveru/unutrašnja greška.         |
