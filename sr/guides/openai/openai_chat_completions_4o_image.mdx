OpenAI ChatGPT је веома моћан AI систем за разговор, који може генерисати текуће и природне одговоре у само неколико секунди, само уношењем упитника. ChatGPT се истиче у индустрији својом изванредном способношћу разумевања и генерисања језика, а данас се већ широко примењује у различитим индустријама и областима, а његов утицај постаје све значајнији. Без обзира на то да ли је у питању свакодневни разговор, креативно писање или стручне консултације и програмирање, ChatGPT може пружити импресивну интелигентну помоћ, значајно повећавајући људску продуктивност и креативност.

Овај документ углавном описује процес коришћења OpenAI Chat Completion 4o Image API, који нам омогућава да лако користимо званичну OpenAI ChatGPT мултимодалну функцију разговора.

## Процес пријаве

Да бисте користили OpenAI Chat Completion 4o Image API, прво можете отићи на [OpenAI Chat Completion 4o Image API](https://platform.acedata.cloud/documents/1bcf3bba-102b-495d-9bba-47cd96717e45) страницу и кликнути на дугме „Acquire“ да бисте добили акредитиве потребне за захтев:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након пријаве и регистрације аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, која вам омогућава да бесплатно користите овај API.

## GPT-4o модел за цртање

### Генерисање слике на основу референтне слике

Испод је пример генерисања слике у прилагођеном стилу на основу једне слике, прво да видимо слику коју смо унели, као што је приказано на слици испод:

![](https://cdn.acedata.cloud/qzx2z1.png)

Можемо видети да је референтна слика слика стварне особе, можемо је променити у неки стил, на пример, да постане слика у аниме стилу, конкретан пример захтева:

```json
{
  "model": "gpt-4o-image",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "Генериши слику у аниме стилу и додај капу"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

Резултат примера:

### Генерисање слике само текстом

```json

  "model": "gpt-4o-image",

      "role": "user",
```

## Обрада грешака

Када позивате АПИ, ако наиђете на грешку, АПИ ће вратити одговарајући код грешке и информације. На пример:

- `400 token_mismatched`：Лош захтев, могуће због недостајућих или неважећих параметара.
- `400 api_not_implemented`：Лош захтев, могуће због недостајућих или неважећих параметара.
- `401 invalid_token`：Неовлашћен, неважећи или недостајући токен за ауторизацију.
- `429 too_many_requests`：Превише захтева, превазишли сте лимит.
- `500 api_error`：Унутрашња грешка сервера, нешто није у реду на серверу.

### Пример одговора на грешку

```
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
