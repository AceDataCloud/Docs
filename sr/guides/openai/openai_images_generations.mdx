DALL-E 3 је модел генерације слика који је развио OpenAI, а који може генерисати слике високе квалитета на основу текстуалних описâ.

Овај документ углавном описује процес коришћења OpenAI Images Generations API, који нам омогућава да лако користимо званичну функцију генерације слика OpenAI DALL-E.

## Пријава

Да бисте користили OpenAI Images Generations API, прво можете отићи на [OpenAI Images Generations API](https://platform.acedata.cloud/documents/fd932485-90c7-45d6-8394-1e14b6f07b2b) страницу и кликнути на дугме „Acquire“ да бисте добили потребне креденцијале за захтев:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након пријаве или регистрације аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, што вам омогућава да бесплатно користите овај API.

## Основна употреба

Након тога можете попунити одговарајуће садржаје на интерфејсу, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/zv58ug.png" width="500" class="m-auto"></p>

Када први пут користите овај интерфејс, потребно је да попуните најмање три садржаја: један је `authorization`, који можете директно изабрати из падајућег менија. Други параметар је `model`, `model` је категорија модела коју одаберете да користите на званичном сајту OpenAI DALL-E, а овде имамо углавном 1 модел, детаље можете видети у моделима које пружамо. Последњи параметар је `prompt`, `prompt` је реч која уносимо да бисмо генерисали слику.

Такође можете приметити да се на десној страни генерише одговарајући код за позив, можете копирати код и директно га покренути, или можете директно кликнути на дугме „Try“ за тестирање.

<p><img src="https://cdn.acedata.cloud/pbss4f.png" width="500" class="m-auto"></p>

Python пример кода за позив:

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "dall-e-3",
    "prompt": "A cute baby sea otter"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Параметар квалитета слике `quality`

Након тога ћемо описати како да подесите неке детаљне параметре резултата генерације слика, где параметар квалитета слике `quality` садржи две опције: прва `standard` означава генерисање стандардне слике, а друга `hd` означава да слика има финије детаље и већу доследност.

Испод је подешен параметар квалитета слике на `standard`, конкретна подешавања су приказана на слици:

## Asinhroni povratni poziv

Zbog toga što vreme generisanja slika putem OpenAI Images Generations API može biti relativno dugo, ako API dugo ne odgovara, HTTP zahtev će zadržati vezu, što dovodi do dodatne potrošnje sistemskih resursa, tako da ovaj API takođe pruža podršku za asinhroni povratni poziv.

Celokupni proces je: kada klijent pokrene zahtev, dodatno se navodi polje `callback_url`, nakon što klijent pošalje API zahtev, API odmah vraća rezultat koji sadrži informaciju o polju `task_id`, što predstavlja trenutni ID zadatka. Kada zadatak bude završen, rezultat generisane slike će biti poslat putem POST JSON forme na klijentom određeni `callback_url`, koji takođe uključuje polje `task_id`, tako da se rezultati zadatka mogu povezati putem ID-a.

Pogledajmo kako to konkretno funkcioniše kroz primer.

Prvo, Webhook povratni poziv je usluga koja može primati HTTP zahteve, programeri bi trebali zameniti sa URL-om HTTP servera koji su sami postavili. Ovde, radi lakšeg prikazivanja, koristi se javni Webhook uzorak sa sajta https://webhook.site/, otvaranjem tog sajta dobijate Webhook URL, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/cjjfly.png)

Kopirajte ovaj URL, i možete ga koristiti kao Webhook, ovde je uzorak `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`.

Zatim, možemo postaviti polje `callback_url` na navedeni Webhook URL, kao i uneti odgovarajuće parametre, kao što je prikazano u sledećem kodu:

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "dall-e-3",
    "prompt": "Slatka beba morski vidar",
    "callback_url": "https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Klikom na pokretanje, možete primetiti da odmah dobijate rezultat, kao što je prikazano u sledećem:

```json
{
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c"
}
```

Nakon kratkog čekanja, možemo na Webhook URL-u posmatrati rezultat generisane slike, sadržaj je sledeći:

```json

  "success": true,

  "data": {
    "created": 1721626477,

      {
        "revised_prompt": "Divna slika koja prikazuje mladog morskog vidra...",

```

Može se primetiti da rezultat sadrži polje `task_id`, a polje `data` sadrži rezultate generisanja slika kao i kod sinhronog poziva, putem polja `task_id` može se ostvariti povezanost zadatka.

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu na serveru.
