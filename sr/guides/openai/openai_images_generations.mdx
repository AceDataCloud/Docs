OpenAI Images Generations API тренутно подржава бројне моделе за генерисање слика, укључујући класични `dall-e-3`, моћнији `gpt-image-1`, најновији **`gpt-image-2`**, као и серију модела **`nano-banana` / `nano-banana-2` / `nano-banana-pro`** који се приступају преко истог интерфејса. Сви они могу генерисати висококвалитетне слике на основу текстуалних описа.

Овај документ описује процес коришћења OpenAI Images Generations API-а, омогућавајући лако искоришћавање OpenAI серије за генерисање слика.

## Процедура пријаве

Да бисте користили OpenAI Images Generations API, најпре посетите страницу [OpenAI Images Generations API](https://platform.acedata.cloud/documents/fd932485-90c7-45d6-8394-1e14b6f07b2b) и кликните на дугме „Acquire“ да бисте добили потребне привилегије или токен:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ако нисте улоговани или регистровани, бићете аутоматски преусмерени на страницу за пријаву. Након логовања или регистрације, повратак ће се обавити аутоматски.

При првој пријави добићете бесплатни кредите који вам омогућавају привремено коришћење API-а без трошкова.

## Модел `gpt-image-2`

`gpt-image-2` је нова генерација модела за генерисање слика од OpenAI, са јасним унапређењима у односу на `dall-e-3` и `gpt-image-1`:

- **Још боља способност следења упутстава**: прецизније разумевање сложених структура као што су бројеви, позиције, композиција.
- **Више јасна текстурна приказивања**: одлични резултати у сценама као што су плакати, менији, иконице и сликовне инфографике.
- **Разноврснији стилови**: подржава кинастички, ретро, филмски портрети, производну фотографију, приказе у стилу информационих графика.
- **Вишеструка разинска подршка од 1К, 2К до 4К**, као и подршка за различите пропорције (1:1, 4:3, 3:4, 16:9, 9:16).

Позиви су слични као и за друге моделе — једноставно поставите `'model': 'gpt-image-2'`. Резултати садрже URL који је трајно хостован на `platform.cdn.acedata.cloud` и може се слободно отварати у прегледачу или засећи у веб страницу.

### Вриједности parameter `size` и тарифе

`gpt-image-2` валидира `size` формат, избегавајте `auto` или празне вредности — потребно је праћење формата `WIDTHxHEIGHT` (нпр. `1024x1024`). Уколико је формат исправан, цена се дели у две категорије:

- **Стандардна цена за 1К**: за препоручене размере у табели и уобичајене вишеструке од 1К.
- **Додатна цена (1.5×)**: за све друге величине, укључујући 2К, 4К, као и све личне величине које корисник унесе.

Минимална ограничења за личне величине су: ширина и висина су делиоци 16, максимално 3840 по димензији, укупна количина пиксела ≤ 8.294.400.

| Резолуција | 1К (стандардна цена) | 2К (×1.5) | 4К (×1.5) |
| --- | --- | --- | --- |
| 1:1 | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3 | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4 | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

> 可以传入 `size: "auto"` 或不填写`size`，模型会自主选择默认尺寸，按1К价付费。  
> 注意：上游可能返回尺寸略有偏差（比如传入`1024x1024`，实际可能获得`1254x1254`），比例保持一致，重复传入也不影响计费。  
> 建议在一次调用内，配合后文介绍的 `callback_url` 异步机制。

> **关于参数 `n`**
>
> `gpt-image-2` 不支持 `n > 1`：参数会被静默忽略，无论传 `n=1` 还是 `n=10`，每次请求只会返回一张图，且只按一张计费。若需获取多候选图，请自行发起多个请求（建议不同 prompts 或种子参数以得到多样结果，避免高度相似）。  
> 其他模型（如 `dall-e-2` 支持 `n > 1`，`dall-e-3` 支持 `n=1`）。

### 案例一：电影风格人物肖像

提示词可以使用电影专业术语（如35mm胶片、浅景深、霓虹光等）精准控制氛围。

Python 示例：

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-image-2",
    "prompt": "A cinematic portrait of a young woman standing in a convenience store at night, illuminated by soft pink and cyan neon signs through the window. Shot on 35mm film, shallow depth of field, slight grain, melancholic mood.",
    "size": "1024x1536"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Резултат: URL слика и JSON одговор слични као у примеру.

### Асимптонска и асинхрона употреба (callback_url)

Обично један позив траје 60-90 секунди. За избегавање затварања веза, могуће је користити `callback_url` — он омогућава примање пада через POST када је резултат спреман.

Процедура: у позиву укључите `callback_url` (нпр. на посебном Webhook серверу), а API ће одмах одговорити `task_id` који је идентификатор задатка. Након генерисања, резултат ће стићи на наведени URL.

Пример:

```python
import requests

# Webhook URL (на пример https://webhook.site/...)
webhook_url = "https://webhook.site/..."
payload = {
    "model": "dall-e-3",
    "prompt": "A cute baby sea otter",
    "callback_url": webhook_url
}
response = requests.post(url, json=payload, headers=headers)
print(response.json())  # Овај одговор садржи task_id
```

Када се догађај заврши, резултат стиже у вебхук у формату:

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "data": {
    "created": 1721626477,
    "data": [
      {
        "revised_prompt": "...",
        "url": "https://..."
      }
    ]
  }
}
```

## Управљање грешкама

При грешци API враћа статус кодове и поруке. На пример:

- `400 token_mismatched` — погрешни параметри 
- `401 invalid_token` — нерегистрирани или неисправни токен
- `429 too_many_requests` — премашен лимит
- `500 api_error` — интерна грешка сервера

Примери одговора:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  }
}
```
