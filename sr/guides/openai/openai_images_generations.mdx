## 1. Dobijanje API ključa

Otvorite [listu Ace Data Cloud aplikacija](https://platform.acedata.cloud/console/applications), uđite u dostupnu aplikaciju i kopirajte API ključ.

![Dobijanje Ace Data Cloud API ključa](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Slanje prvog zahteva

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Slika iz uspešnog odgovora nalazi se u `data[].url`. U nastavku je rezultat 1024×1536 stvarno dobijen zahtevom preko Ace Data Cloud 8. septembra 2026. godine (zadatak `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Bela šolja koju je generisao GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Često korišćeni parametri

| Polje                | Opis                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (podrazumevano preporučeno), `gpt-image-2.5-flare` (brže) ili `gpt-image-2.5-sunburst` (veća vernost i kontrola); sva tri mogu izabrati odgovarajuću varijantu `:official`, a `gpt-image-2` takođe podržava `:reverse` |
| `prompt`          | Opis slike, najviše 32.000 znakova                                                                                                                     |
| `size`            | `auto` ili `WIDTHxHEIGHT`; širina i visina moraju biti višekratnici od 16, duža stranica ne sme prelaziti 3840, ukupan broj piksela je 655.360–8.294.400, a odnos širine i visine ne sme prelaziti 3:1                                                       |
| `n`               | 1–10; kada je `response_format=b64_json`, podržano je samo 1                                                                                                 |
| `quality`         | GPT Image modeli podržavaju `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare / Sunburst (uključujući `:official`) dodatno podržavaju `xhigh`, `max`. Zvanični kanal se naplaćuje prema stvarnoj potrošnji Tokena             |
| `response_format` | `url` ili `b64_json`                                                                                                                     |
| `callback_url`    | Opcionalno; šalje rezultat na ovu adresu nakon završetka dugog zadatka                                                                                                                      |

Često korišćene dimenzije:

| Odnos   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` bira format platna prema odnosu, pikselima i nameri rasporeda u promptu; kada su potrebni precizni pikseli, direktno unesite dimenzije.

Obrnuti modeli 2.0 / 2.5 (uključujući alias `:reverse`) mogu pri automatskom oporavku koristiti GPT Image 2.5 Flare za završavanje zahteva; model zahteva i način naplate po broju uspešno generisanih slika ostaju nepromenjeni.

Cene na stranici zvaničnog API kanala su procene pre zahteva, a konačna cena zavisi od stvarne potrošnje Tokena u odgovoru i evidencije korišćenja.

## 4. Generisanje više slika

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` i njihovi `:reverse` aliasi se naplaćuju prema broju uspešno generisanih slika; `gpt-image-2:official`, `gpt-image-2.5-flare:official` i `gpt-image-2.5-sunburst:official` se obračunavaju na osnovu stvarnog broja Tokena za tekstualni unos i izlaz slike u odgovoru. Cena na stranici je procena pre zahteva, a konačna cena se određuje prema evidenciji korišćenja.

## 5. Asinhroni povratni poziv

Nakon dodavanja `callback_url` u telo zahteva, interfejs će prvo vratiti `{"task_id": "..."}`, a po završetku će POST metodom poslati konačni rezultat na taj URL; sinhroni zahtevi i dalje vraćaju `created` i `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Primalac povratnog poziva treba da koristi `task_id` za deduplikaciju i da proveri izvor zahteva i format podataka.

## 6. Otklanjanje grešaka

| Status  | Proverite                                                  |
| --- | --------------------------------------------------- |
| 400 | kombinaciju `model`, `prompt`, formata dimenzija, `n` i `response_format`    |
| 401 | da li je API Key potpun i da li je Header `Authorization: Bearer ...` |
| 429 | zahtevi su previše česti, pokušajte ponovo kasnije                                         |
| 504 | vremensko ograničenje sinhronog generisanja je isteklo; koristite `callback_url`                            |

Odgovor o grešci sadrži `error.code`, `error.message` i `trace_id`. Kada prijavljujete problem, navedite `trace_id`, ali nemojte navoditi API Key.

Za potpuna polja i enumeracije u realnom vremenu pogledajte stranicu [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Za uređivanje slika pogledajte [GPT Image 2 / 2.5 / 2.6 uređivanje slika](https://platform.acedata.cloud/documents/openai-images-edits).

## GPT Image 2.6

GPT Image 2.6 koristi iste interfejse za generisanje, uređivanje, asinhrone zadatke i naplatu kao 2.5:

| Model                                                          | Naplata                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/slika                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/slika                   |
| `gpt-image-2.6-flare:official`                              | Isto kao 2.5 official, naplaćuje se prema stvarnoj upotrebi Tokena |
| `gpt-image-2.6-sunburst:official`                           | Isto kao 2.5 official, naplaćuje se prema stvarnoj upotrebi Tokena |

Kvalitet može biti `auto`, `low`, `medium`, `high`, `xhigh`, `max`; za dimenzije koristite `auto` ili `WIDTHxHEIGHT` koji ispunjava gore navedena ograničenja. Ovaj interfejs podržava `png`, `jpeg`, `webp`, a SVG/GIF trenutno nisu podržani. Uređivanje podržava JSON URL slike i multipart otpremanje datoteka. `:reverse` je eksplicitni alias obične verzije istog naziva. Koristite potpuni naziv modela, nemojte slati `gpt-image-2.6`.
