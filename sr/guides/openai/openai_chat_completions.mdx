OpenAI ChatGPT je veoma moćan AI sistem za razgovor; dovoljno je uneti prompt i on može da generiše tečan i prirodan odgovor za samo nekoliko sekundi. ChatGPT se izdvaja u industriji svojim izuzetnim sposobnostima razumevanja i generisanja jezika. Danas se ChatGPT već široko koristi u različitim industrijama i oblastima, a njegov uticaj postaje sve značajniji. Bilo da je reč o svakodnevnim razgovorima, kreativnom pisanju, profesionalnim konsultacijama ili programiranju koda, ChatGPT može pružiti zapanjujuću inteligentnu pomoć, značajno povećavajući ljudsku radnu efikasnost i kreativnost.

Ovaj dokument uglavnom predstavlja proces korišćenja OpenAI Chat Completion API operacija, pomoću kojeg možemo lako koristiti funkciju razgovora zvaničnog OpenAI ChatGPT-a.

Zahtevi za kompatibilne modele koje platforma prihvata naplaćuju se prema korišćenju ulaza, izlaza i keša tog modela. `prompt_tokens` za Chat Completions uključuje keširane tokene, a prijavljeni keširani deo obračunava se po odgovarajućoj ceni za keš; promena formata interfejsa ne pretvara naplatu u fiksni broj korišćenja. Naknade se određuju prema trenutnim cenama modela u kontrolnoj tabli i odgovoru `usage.cost`.

## GPT-6.1 Terra

Koristite `model: "gpt-6.1-terra"` da izaberete ovaj model. Podržava unos teksta i slika, kao i striming izlaz; funkcijske alate i strukturisani izlaz pozivajte prema formatu parametara ovog interfejsa. Nivoi rezonovanja podržavaju `low`, `medium`, `high`, `xhigh` i `max`, preporučuje se da počnete sa `reasoning_effort: "low"`; `none` i `minimal` nisu podržani. Kada unos premaši 272,000 tokena, primenjuje se cena za dugačak kontekst, a stvarna naknada zavisi od trenutne cene u kontrolnoj tabli i korišćenja u odgovoru.

## GPT-6.1 Sol

Koristite `model: "gpt-6.1-sol"` da izaberete ovaj model. Podržava striming izlaz, pozivanje funkcija, strukturisani izlaz i unos slika. Tokom prve nedelje nakon otvaranja, dostupan je samo verifikovanim ACE T1+ vlasnicima (najmanje 100,000 ACE) ili ovlašćenim korisnicima; za konkretno vreme dostupnosti pogledajte obaveštenje o pristupu u kontrolnoj tabli.

Nivoi rezonovanja podržavaju `low`, `medium`, `high`, `xhigh` i `max`; `none` i `minimal` trenutno nisu podržani. Preporučuje se da počnete sa `reasoning_effort: "low"`. Kada unos premaši 272,000 tokena, cena za dugačak kontekst primenjuje se na ceo zahtev, a naknade zavise od trenutne cene u kontrolnoj tabli.

## Osnovno korišćenje

Zatim možete popuniti odgovarajući sadržaj u interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

Prilikom prvog korišćenja ovog interfejsa, potrebno je da popunimo najmanje tri stavke. Jedna je `authorization`, koju možete direktno izabrati sa padajuće liste. Drugi parametar je `model`; `model` predstavlja kategoriju modela sa zvaničnog OpenAI ChatGPT sajta koju biramo za korišćenje. Ovde uglavnom imamo 20 vrsta modela, a detalje možete pogledati u modelima koje nudimo. Poslednji parametar je `messages`; `messages` je niz promptova koje unosimo. To je niz, što znači da se može istovremeno otpremiti više promptova. Svaki prompt sadrži `role` i `content`, pri čemu `role` predstavlja ulogu osobe koja postavlja pitanje. Nudimo tri identiteta: `user`, `assistant` i `system`. Drugi, `content`, predstavlja konkretan sadržaj našeg pitanja.

Istovremeno možete primetiti da se sa desne strane generiše odgovarajući kod za pozivanje; možete kopirati kod i direktno ga pokrenuti, ili direktno kliknuti na dugme „Try“ radi testiranja.

Često korišćeni opcioni parametri:

- `max_tokens`: ograničava maksimalan broj tokena u jednom odgovoru.
- `temperature`: slučajnost generisanja, između 0 i 2; što je vrednost veća, rezultat je raznovrsniji.
- `n`: koliko kandidata za odgovor se generiše odjednom.
- `response_format`: podešavanje formata povratne vrednosti.

## Striming odgovor

Ovaj interfejs takođe podržava striming odgovor, što je veoma korisno za povezivanje sa veb stranicama i omogućava postizanje efekta prikazivanja znak po znak.

Ako želite da odgovor vraćate putem striminga, možete izmeniti parametar `stream ` u zaglavlju zahteva na `true`.

Izmena je prikazana na slici, ali kod za pozivanje mora biti odgovarajuće izmenjen da bi podržavao striming odgovor.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

Nakon što se `stream` izmeni u `true`, API će vraćati odgovarajuće JSON podatke red po red, a na nivou koda potrebno je da napravimo odgovarajuće izmene kako bismo dobili rezultate red po red.

Primer Python koda za pozivanje:
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Integracija sa OpenAI-Python

OpenAI Chat Completion API je kompatibilan sa zvaničnim OpenAI interfejsom, možete direktno koristiti zvanični SDK [OpenAI-Python](https://github.com/openai/openai-python) za integraciju, a ovaj tekst će ukratko predstaviti način korišćenja.

1. Prvo je potrebno postaviti lokalno `Python` okruženje, ovaj proces možete pretražiti na Google-u.
2. Preuzmite i instalirajte razvojno okruženje, na primer VSCode uređivač.
3. Konfigurišite `OpenAI` promenljive okruženja.

- U fascikli projekta kreirajte datoteku pod nazivom `.env` i sačuvajte je
- Sadržaj datoteke `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # 再次提醒：如果你使用官网OpenAI的key，不要用这个地址。
```

Zamenite `sk-xxx` svojim key-em. `OPENAI_BASE_URL` je proxy interfejs za pristup OpenAI-u.

4. Instalirajte pakete od kojih projekat zavisi

```shell
pip install openai
```

U Mac OS-u komanda je:

```shell
pip3 install openai
```

5. Kreirajte datoteku izvornog koda primera

Pretpostavimo da smo kreirali primer koda `index.py`, konkretan sadržaj je sledeći:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Vizuelni model

gpt-4o je multimodalni veliki jezički model koji je razvio OpenAI, on je na osnovi GPT-4 dodao sposobnost vizuelnog razumevanja. Ovaj model može istovremeno obrađivati tekstualne i slikovne unose, ostvarujući razumevanje i generisanje između modaliteta.

Obrada teksta korišćenjem modela gpt-4o ista je kao sadržaj osnovne upotrebe iznad, u nastavku će biti ukratko predstavljeno kako koristiti sposobnost modela za obradu slika.

Sposobnost obrade slika modela gpt-4o uglavnom se koristi dodavanjem polja `type` na osnovu originalnog sadržaja `content`, putem ovog polja može se znati da li je otpremljen tekst ili slika, čime se koristi sposobnost obrade slika modela gpt-4o, u nastavku se uglavnom opisuje pozivanje ove funkcije na dva načina, pomoću Curl-a i Python-a.

- Curl skriptni način

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neovlašćeno, nevažeći ili nedostajući token za autorizaciju.
- `429 too_many_requests`: Previše zahteva, premašili ste ograničenje stope.
- `500 api_error`: Interna greška servera, nešto je pošlo po zlu na serveru.
