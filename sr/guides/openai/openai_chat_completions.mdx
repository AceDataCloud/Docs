OpenAI ChatGPT је веома моћан AI систем за разговор, који може генерисати текуће и природне одговоре у само неколико секунди, само уношењем упитника. ChatGPT се истиче у индустрији својом изванредном способношћу разумевања и генерисања језика, а данас се широко примењује у различитим индустријама и областима, а његов утицај постаје све значајнији. Без обзира на то да ли је у питању свакодневни разговор, креативно писање или стручне консултације и програмирање, ChatGPT може пружити импресивну интелигентну помоћ, значајно повећавајући људску продуктивност и креативност.

Овај документ углавном описује процес коришћења OpenAI Chat Completion API, који нам омогућава да лако користимо функцију разговора званичног OpenAI ChatGPT.

## Процес пријаве

Да бисте користили OpenAI Chat Completion API, прво можете отићи на [OpenAI Chat Completion API](https://platform.acedata.cloud/documents/1bcf3bba-102b-495d-9bba-47cd96717e45) страницу и кликнути на дугме „Acquire“ да бисте добили акредитиве потребне за захтев:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након пријаве и регистрације аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, која вам омогућава да бесплатно користите овај API.

## Основна употреба

Након тога можете попунити одговарајуће садржаје на интерфејсу, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" class="m-auto"></p>

Када први пут користите овај интерфејс, морамо попунити најмање три садржаја, један је `authorization`, који можете директно изабрати из падајућег менија. Други параметар је `model`, `model` је категорија модела коју изаберемо за коришћење званичног OpenAI ChatGPT, овде имамо 20 различитих модела, детаље можете видети у моделима које пружамо. Последњи параметар је `messages`, `messages` је низ упитника који уносимо, представља низ који може истовремено учитати више упитника, сваки упитник садржи `role` и `content`, где `role` представља улогу питаоца, а ми смо пружили три идентификације: `user`, `assistant`, `system`. Други `content` је конкретан садржај нашег питања.

Такође можете приметити да се на десној страни генерише одговарајући код за позив, можете копирати код и директно га покренути, или можете директно кликнути на дугме „Try“ за тестирање.

Често коришћени опциони параметри:

- `max_tokens`: ограничава максималан број токена у једном одговору.
- `temperature`: генерише случајност, између 0-2, већа вредност значи веће распршивање.
- `n`: колико кандидата одговора генерише одједном.
- `response_format`: подешавање формата повратка.

## Стриминг одговора

Овај интерфејс такође подржава стриминг одговора, што је веома корисно за веб интеграцију, јер омогућава веб страници да реализује ефекат приказивања по речима.

Ако желите да добијете одговор у стриминг формату, можете променити параметар `stream` у заглављу захтева на `true`.

Измените као што је приказано на слици, али код позива треба да има одговарајуће измене да би подржао стриминг одговор.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" class="m-auto"></p>

Када промените `stream` на `true`, API ће враћати одговарајуће JSON податке ред по ред. На нивоу кода, потребно је направити одговарајуће измене да бисте добили резултате ред по ред.

Python пример кода за позив:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Vraćeni `data` rezultati imaju više polja, opisi su sledeći:

- `id`, ID generisan za ovu konverzaciju, koji jedinstveno identifikuje ovu konverzaciju.
- `model`, izabrani OpenAI ChatGPT model.
- `choices`, informacije o odgovorima koje je ChatGPT dao na postavljena pitanja.

JavaScript takođe podržava, na primer, kod za strimovano pozivanje u Node.js je sledeći:

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4",
    messages: [{ role: "user", content: "zdravo" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

Java uzorak koda:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "gpt-4");
jsonObject.put("messages", [{"role":"user","content":"zdravo"}]);
jsonObject.put("stream", true);
MediaType mediaType = "application/json; charset=utf-8".toMediaType();
RequestBody body = jsonObject.toString().toRequestBody(mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/openai/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.print(response.body!!.string())
```

Ostali jezici mogu se prepraviti na sličan način, princip je isti.

## Povezivanje sa OpenAI-Python

OpenAI Chat Completion API usluga je povezana sa zvaničnom OpenAI uslugom, a detalje možete pogledati na zvaničnom [OpenAI-Python](https://github.com/openai/openai-python), u ovom tekstu će biti ukratko objašnjeno kako koristiti zvanično pružene usluge.

1. Prvo je potrebno postaviti lokalno `Python` okruženje, ovaj proces možete pretražiti na Guglu.
2. Preuzmite i instalirajte razvojno okruženje, na primer, instalirajte VSCode editor.
3. Konfigurišite `OpenAI` promenljive okruženja.

- U projektu, kreirajte datoteku pod imenom `.env` i sačuvajte je.
- Sadržaj `.env` datoteke:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # Ponovo napominjem: ako koristite OpenAI ključ, ne koristite ovu adresu.
```

Zamenite `sk-xxx` sa svojim ključem. `OPENAI_BASE_URL` je adresa za pristup OpenAI proxy interfejsu.

4. Instalirajte zavisne pakete projekta

```shell
pip install openai
```

Na Mac OS, komanda je:

```shell
pip3 install openai
```

5. Kreirajte primer izvornog koda

Pretpostavimo da smo kreirali primer koda `index.py`, konkretan sadržaj je sledeći:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "zdravo",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Vizuelni modeli

gpt-4o je multimodalni veliki jezički model koji je razvio OpenAI, koji je na osnovu GPT-4 dodao sposobnost vizuelnog razumevanja. Ovaj model može istovremeno obraditi tekstualne i slikovne ulaze, ostvarujući međumodalno razumevanje i generisanje.

Obrada teksta pomoću gpt-4o modela je u skladu sa osnovnim sadržajem korišćenja iz prethodnog dela, a u nastavku će biti ukratko objašnjeno kako koristiti sposobnosti obrade slika modela.

Korišćenje sposobnosti obrade slika gpt-4o modela se uglavnom vrši dodavanjem `type` polja na osnovu postojećeg `content` sadržaja, putem kojeg se može znati da li je učitan tekst ili slika, čime se koristi sposobnost obrade slika gpt-4o modela. U nastavku će biti opisane dve metode za pozivanje ove funkcionalnosti, koristeći Curl i Python.

- Curl skripta

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "Šta se nalazi na ovoj slici?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

```

Možete videti da je sadržaj odgovora zasnovan na slici, stoga se kroz gornje dve metode može lako koristiti gpt-4-vision model za obradu teksta i slika.

Pored gpt-4o, postoji i jeftiniji model, nazvan gpt-4o-mini. gpt-4o-mini je najnovija generacija velikog jezičkog modela koji je razvio OpenAI, koji ne samo da ima bržu brzinu odgovora, već je i jeftiniji, a takođe podržava multimodalnost. Korišćenje vizuelnih funkcija može se referencirati na sadržaj korišćenja gpt-4o modela.

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
