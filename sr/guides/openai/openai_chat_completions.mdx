OpenAI ChatGPT je veoma moćan AI sistem za razgovor, koji može generisati tečne i prirodne odgovore za samo nekoliko sekundi čim unesete prompt. ChatGPT se izdvaja u industriji svojim izvanrednim sposobnostima razumevanja i generisanja jezika, a danas je ChatGPT već široko primenjen u različitim industrijama i oblastima, pri čemu njegov uticaj postaje sve značajniji. Bilo da je reč o svakodnevnim razgovorima, kreativnom pisanju, profesionalnim konsultacijama ili programiranju koda, ChatGPT može pružiti zadivljujuću inteligentnu pomoć, značajno poboljšavajući radnu efikasnost i kreativnost ljudi.

Ovaj dokument uglavnom predstavlja proces korišćenja OpenAI Chat Completion API operacija, pomoću kojeg možemo lako koristiti funkciju razgovora zvaničnog OpenAI ChatGPT-a.

## GPT-6.1 Sol

Koristite `model: "gpt-6.1-sol"` da izaberete ovaj model. Podržava strimovani izlaz, pozivanje funkcija, strukturisani izlaz i unos slika. Tokom prve nedelje od otvaranja, dostupan je samo verifikovanim ACE T1+ vlasnicima (najmanje 100.000 ACE) ili ovlašćenim korisnicima; konkretno vreme dostupnosti zavisi od obaveštenja o pristupu u konzoli.

Nivoi rezonovanja podržavaju `low`, `medium`, `high`, `xhigh` i `max`, dok `none` ili `minimal` trenutno nisu podržani. Preporučuje se da počnete sa `reasoning_effort: "low"`. Kada unos premaši 272.000 tokena, cena dugog konteksta se primenjuje na ceo zahtev, a naknada zavisi od trenutne cene u konzoli.

## Osnovno korišćenje

Zatim možete popuniti odgovarajući sadržaj u interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

Prilikom prvog korišćenja ovog interfejsa, potrebno je da popunimo najmanje tri sadržaja, jedan je `authorization`, koji se može direktno izabrati sa padajuće liste. Drugi parametar je `model`, `model` je kategorija modela sa zvaničnog OpenAI ChatGPT sajta koju biramo da koristimo, ovde uglavnom imamo 20 vrsta modela, detalje možete pogledati u modelima koje pružamo. Poslednji parametar je `messages`, `messages` je niz upitnih reči koje unosimo, to je niz, što znači da se može istovremeno otpremiti više upitnih reči, svaka upitna reč sadrži `role` i `content`, gde `role` označava ulogu osobe koja postavlja pitanje, nudimo tri identiteta, odnosno `user`, `assistant`, `system`. Drugi `content` je konkretan sadržaj našeg pitanja.

Istovremeno možete primetiti da se na desnoj strani generiše odgovarajući kod za pozivanje, možete kopirati kod i direktno ga pokrenuti, ili možete direktno kliknuti na dugme „Try“ radi testiranja.

Često korišćeni opcioni parametri:

- `max_tokens`: ograničava maksimalan broj tokena u jednom odgovoru.
- `temperature`: nasumičnost generisanja, između 0 i 2, što je vrednost veća, rezultat je divergentniji.
- `n`: koliko kandidata odgovora se generiše odjednom.
- `response_format`: podešavanje formata povratne vrednosti.

## Strimovani odgovor

Ovaj interfejs takođe podržava strimovane odgovore, što je veoma korisno za povezivanje sa veb-stranicama i može omogućiti efekat prikazivanja reč po reč na veb-stranici.

Ako želite da odgovor bude vraćen strimovano, možete promeniti parametar `stream ` u zaglavlju zahteva na `true`.

Izmena je prikazana na slici, ali kod za pozivanje mora imati odgovarajuće izmene da bi podržao strimovani odgovor.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

Nakon izmene `stream` na `true`, API će vraćati odgovarajuće JSON podatke red po red, a na nivou koda potrebno je da izvršimo odgovarajuće izmene kako bismo dobili rezultat red po red.

Python primer koda za pozivanje:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4",
    messages: [{ role: "user", content: "hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

## Povezivanje sa OpenAI-Python

OpenAI Chat Completion API ostaje kompatibilan sa zvaničnim OpenAI interfejsom i može se direktno povezati pomoću zvaničnog SDK-a [OpenAI-Python](https://github.com/openai/openai-python), ovaj tekst će ukratko predstaviti način korišćenja.

1. Najpre je potrebno postaviti lokalno `Python` okruženje, ovaj proces možete potražiti na Google-u.
2. Preuzmite i instalirajte razvojno okruženje, na primer VSCode editor.
3. Konfigurišite `OpenAI` promenljive okruženja.

- U fascikli projekta kreirajte datoteku pod nazivom `.env` i sačuvajte je.
- Sadržaj datoteke `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # 再次提醒：如果你使用官网OpenAI的key，不要用这个地址。
```

Zamenite `sk-xxx` sopstvenim key-om. `OPENAI_BASE_URL` je posrednički interfejs za pristup OpenAI-ju.

4. Instalirajte pakete od kojih projekat zavisi

```shell
pip install openai
```

Komanda u Mac OS-u je:

```shell
pip3 install openai
```

5. Kreirajte datoteku izvornog koda primera

Pretpostavimo da smo kreirali primer koda `index.py`, a konkretan sadržaj je sledeći:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Vizuelni model

gpt-4o je multimodalni veliki jezički model koji je razvio OpenAI, a na osnovu GPT-4 dodaje mogućnost vizuelnog razumevanja. Ovaj model može istovremeno obrađivati tekstualne i slikovne ulaze, ostvarujući međumodalno razumevanje i generisanje.

Obrada teksta pomoću modela gpt-4o ista je kao osnovno korišćenje navedeno iznad, a u nastavku će ukratko biti predstavljeno kako koristiti mogućnost obrade slika modela.

Mogućnost obrade slika modela gpt-4o uglavnom se koristi dodavanjem polja `type` na osnovu originalnog sadržaja `content`, preko ovog polja može se znati da li se otprema tekst ili slika, čime se koristi mogućnost obrade slika modela gpt-4o. U nastavku se uglavnom opisuje pozivanje ove funkcije na dva načina, Curl i Python.

- Način putem Curl skripte

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

- Način putem Python skripte
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
                    }
                },
            ],
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Pored gpt-4o, postoji i model sa nižim troškovima, koji se zove gpt-4o-mini. gpt-4o-mini je najnovija generacija velikog jezičkog modela koji je razvio OpenAI; ne samo da ima brzu brzinu odgovora, već je i jeftiniji, a takođe podržava multimodalnost. Za korišćenje vision funkcije možete pogledati sadržaj o korišćenju gpt-4o modela iznad.

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kôd greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neovlašćeno, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, prekoračili ste ograničenje broja zahteva.
- `500 api_error`: Interna greška servera, nešto je pošlo po zlu na serveru.
