## 2. Uređivanje korišćenjem URL-a slike

Originalna slika:

![GPT Image 2 originalna slika za uređivanje](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",

    "size": "1024x1536"
  }'
```

## 3. Otpremanje lokalne slike

Koristite `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` se može proslediti više puta, a GPT Image serija podržava najviše 16 referentnih slika. `image` u JSON zahtevu može biti jedan URL ili niz URL-ova; lokalne datoteke se otpremaju korišćenjem multipart-a.

### Modeli i način naplate

| Model                                | Primenljivi scenariji i način naplate                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | Podrazumevani reverzni kanal, fiksna naplata po broju uspešno generisanih slika                               |
| `gpt-image-2:reverse`             | Eksplicitno bira reverzni kanal, fiksna naplata po broju uspešno generisanih slika                             |
| `gpt-image-2:official`            | Zvanični API kanal, veća stabilnost, naplata prema stvarnoj potrošnji Tokena                   |
| `gpt-image-2.5-flare`             | Fokus na brzinu generisanja, fiksna naplata po broju uspešno generisanih slika                               |
| `gpt-image-2.5-flare:reverse`     | Eksplicitni reverzni alias, ekvivalentan `gpt-image-2.5-flare`, fiksna naplata po broju uspešno generisanih slika    |
| `gpt-image-2.5-flare:official`    | Zvanični API kanal, veća stabilnost i fokus na brzinu generisanja, naplata prema stvarnoj potrošnji Tokena            |
| `gpt-image-2.5-sunburst`          | Fokus na visoku vernost i preciznu kontrolu, fiksna naplata po broju uspešno generisanih slika                           |
| `gpt-image-2.5-sunburst:reverse`  | Eksplicitni reverzni alias, ekvivalentan `gpt-image-2.5-sunburst`, fiksna naplata po broju uspešno generisanih slika |
| `gpt-image-2.5-sunburst:official` | Zvanični API kanal, veća stabilnost i fokus na visoku vernost i preciznu kontrolu, naplata prema stvarnoj potrošnji Tokena        |

Reverzni modeli (uključujući `:reverse` aliase) mogu koristiti GPT Image 2.5 Flare za završavanje zahteva tokom automatskog oporavka; model zahteva i način naplate po broju uspešno generisanih slika ostaju nepromenjeni.

Cene na stranici za zvanični API kanal predstavljaju procenu pre zahteva, a konačna cena se zasniva na stvarnoj potrošnji Tokena u odgovoru i evidenciji korišćenja.

`quality` podržava `auto`, `low`, `medium`, `high`; samo `gpt-image-2.5-flare` i `gpt-image-2.5-sunburst` (uključujući varijante `:reverse` i `:official`) dodatno podržavaju `xhigh`, `max`. Ovo polje se može proslediti i za JSON uređivanje slike putem URL-a i za multipart uređivanje datoteke; zvanični kanal naplaćuje prema stvarnoj potrošnji Tokena.

## 4. Lokalno uređivanje korišćenjem maske

Zvanični Images Edit interfejs koristi `mask` za određivanje oblasti u kojima su izmene dozvoljene. Ace Data Cloud `:official` modeli poštuju isti multipart ugovor:

- `mask` mora biti PNG sa Alpha kanalom, veličine najviše 4 MB;
- dimenzije maske moraju biti potpuno iste kao prve slike `image`;
- providni pikseli sa Alpha vrednošću `0` označavaju da je uređivanje dozvoljeno, a neprovidni pikseli označavaju da treba da ostanu sačuvani;
- RGB slike koje su samo crno-bele, ali nemaju kanal providnosti, ne mogu se koristiti kao važeće maske;
- prompt treba da opiše kompletnu željenu sliku, uz jasno navođenje lokalnih izmena i sadržaja koji treba da ostane nepromenjen.

U nastavku se prvo generiše maska od originalne slike. Primer postavlja centralni pravougaonik kao providan, dozvoljavajući modelu da menja samo tu oblast:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Zatim zajedno otpremite originalnu sliku i masku:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Možete koristiti i način pozivanja `images.edit` iz zvaničnog OpenAI Python SDK-a, samo je potrebno usmeriti `base_url` na Ace Data Cloud:
```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Kada se koristi `mask`, originalna slika i maska moraju biti otpremljene zasebno u istom multipart zahtevu putem `image=@input.png` i `mask=@mask.png`. Nemojte kombinovati originalnu sliku preko URL-a i lokalnu datoteku maske; zahtevi za uređivanje isključivo preko URL-a ne podržavaju dodatno prilaganje lokalne datoteke `mask`. Maska će ograničiti oblast uređivanja, ali generativni model i dalje može prirodno spojiti ivice; kada su potrebne stroge granice, treba koristiti jasne Alpha ivice i u promptu ponoviti koji sadržaj mora ostati nepromenjen.

Gorenavedeni način pozivanja je u skladu sa primerima maski u [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) i [zvaničnom GPT Image Cookbook-u](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Uobičajeni parametri

| Polje                | Opis                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (brži) ili `gpt-image-2.5-sunburst` (veća vernost i kontrola); sva tri mogu odabrati odgovarajuću varijantu `:official`, a `gpt-image-2` takođe podržava `:reverse` |
| `image`           | JSON koristi jedan URL ili niz od najviše 16 URL-ova; multipart koristi jedno ili više polja datoteke `image`. Kada se koristi `mask`, lokalna datoteka slike mora biti otpremljena                                              |
| `mask`            | Opcionalna PNG maska, ograničena samo na multipart otpremanje datoteka; mora imati Alpha kanal, biti iste veličine kao prva `image` slika i ne prelaziti 4 MB                                                                 |
| `prompt`          | Uputstvo za uređivanje                                                                                                                             |
| `size`            | `auto` ili `WIDTHxHEIGHT` koji je u skladu sa ograničenjima                                                                                                     |
| `n`               | 1–10; kada je `response_format=b64_json`, podržano je samo 1                                                                                           |
| `response_format` | `url` ili `b64_json`                                                                                                               |
| `callback_url`    | Opcionalna adresa za asinhroni povratni poziv                                                                                                                         |

Pravila za dimenzije su ista kao za interfejs za generisanje: širina i visina moraju biti višekratnici od 16, duža stranica ne sme prelaziti 3840, ukupan broj piksela je 655.360–8.294.400, a odnos širine i visine ne sme prelaziti 3:1. Kada se `size` izostavi ili se koristi `auto`, model će odabrati format na osnovu prompta i prve referentne slike.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` i njihovi aliasi `:reverse` naplaćuju se prema broju uspešno generisanih slika; `gpt-image-2:official`, `gpt-image-2.5-flare:official` i `gpt-image-2.5-sunburst:official` obračunavaju se prema stvarnim Tokenima tekstualnog unosa, unosa referentnih slika i izlaznih slika, a konačni obračun zavisi od evidencije korišćenja.

## 6. Asinhroni povratni pozivi i otklanjanje grešaka

Dugi zadaci mogu u zahtev uključiti:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asinhroni odgovor 200 je `{"task_id": "..."}`; nakon završetka, povratni poziv vraća konačni rezultat. Sinhroni zahtevi vraćaju `created` i `data`.

| Status  | Provera                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Format/broj slika, kombinacija parametara i format dimenzija; kada se koristi `mask`, proverite PNG Alpha kanal, ograničenje od 4 MB i da li njegove dimenzije odgovaraju prvoj originalnoj slici |
| 401 | API Key i Bearer Header                                           |
| 429 | Učestalost zahteva                                                              |
| 504 | Pređite na asinhroni povratni poziv                                                            |

Odgovori sa greškom sadrže `trace_id`. Kada prijavljujete problem, navedite taj ID, ali nemojte navoditi API Key.

Za potpuna polja i aktuelne enumeracije pogledajte stranicu [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Za generisanje slika isključivo iz teksta pogledajte [GPT Image 2 / 2.5 generisanje slika](https://platform.acedata.cloud/documents/openai-images-generations).
