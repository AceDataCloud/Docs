## 2. Uređivanje korišćenjem URL-a slike

Originalna slika:

  -H "Content-Type: application/json" \
  -d '{

## 3. Otpremanje lokalne slike

Koristite `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` se može proslediti više puta, a GPT Image serija podržava najviše 16 referentnih slika. `image` u JSON zahtevu može biti jedan URL ili niz URL-ova; lokalne datoteke se otpremaju korišćenjem multipart-a.

### Modeli i način naplate

| Model                                | Primenljivi scenariji i način naplate                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | Podrazumevani obrnuti kanal, fiksna naplata po broju uspešno generisanih slika                               |
| `gpt-image-2:reverse`             | Eksplicitno bira obrnuti kanal, fiksna naplata po broju uspešno generisanih slika                             |
| `gpt-image-2:official`            | Zvanični API kanal, veća stabilnost, naplata prema stvarnoj potrošnji Tokena                   |
| `gpt-image-2.5-flare`             | Fokus na brzinu generisanja, fiksna naplata po broju uspešno generisanih slika                               |
| `gpt-image-2.6-flare`             | Fokus na brzinu generisanja, fiksna naplata po broju uspešno generisanih slika                               |
| `gpt-image-2.5-flare:reverse`     | Eksplicitni obrnuti alias, ekvivalentan sa `gpt-image-2.5-flare`, fiksna naplata po broju uspešno generisanih slika    |
| `gpt-image-2.6-flare:reverse`     | Eksplicitni obrnuti alias, ekvivalentan sa `gpt-image-2.6-flare`, fiksna naplata po broju uspešno generisanih slika    |
| `gpt-image-2.5-flare:official`    | Zvanični API kanal, veća stabilnost i fokus na brzinu generisanja, naplata prema stvarnoj potrošnji Tokena            |
| `gpt-image-2.6-flare:official`    | Zvanični API kanal, veća stabilnost i fokus na brzinu generisanja, naplata prema stvarnoj potrošnji Tokena            |
| `gpt-image-2.5-sunburst`          | Fokus na visoku vernost i preciznu kontrolu, fiksna naplata po broju uspešno generisanih slika                           |
| `gpt-image-2.6-sunburst`          | Fokus na visoku vernost i preciznu kontrolu, fiksna naplata po broju uspešno generisanih slika                           |
| `gpt-image-2.5-sunburst:reverse`  | Eksplicitni obrnuti alias, ekvivalentan sa `gpt-image-2.5-sunburst`, fiksna naplata po broju uspešno generisanih slika |
| `gpt-image-2.6-sunburst:reverse`  | Eksplicitni obrnuti alias, ekvivalentan sa `gpt-image-2.6-sunburst`, fiksna naplata po broju uspešno generisanih slika |
| `gpt-image-2.5-sunburst:official` | Zvanični API kanal, veća stabilnost i fokus na visoku vernost i preciznu kontrolu, naplata prema stvarnoj potrošnji Tokena        |
| `gpt-image-2.6-sunburst:official` | Zvanični API kanal, veća stabilnost i fokus na visoku vernost i preciznu kontrolu, naplata prema stvarnoj potrošnji Tokena        |

Obrnuti modeli 2.0 / 2.5 (uključujući `:reverse` aliase) mogu koristiti GPT Image 2.5 Flare za završavanje zahteva tokom automatskog oporavka; model zahteva i način naplate po broju uspešno generisanih slika ostaju nepromenjeni.

Cene na stranici zvaničnog API kanala su procene pre zahteva, a konačna cena se zasniva na stvarnoj potrošnji Tokena u odgovoru i zapisima o korišćenju.

`quality` podržava `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare i Sunburst (uključujući varijante `:reverse` i `:official`) dodatno podržavaju `xhigh`, `max`. Ovo polje se može proslediti i za JSON uređivanje URL-a slike i za multipart uređivanje datoteke; zvanični kanal naplaćuje prema stvarnoj potrošnji Tokena.

## 4. Lokalno uređivanje korišćenjem maske

Zvanični Images Edit interfejs koristi `mask` za određivanje oblasti koje je dozvoljeno menjati. Ace Data Cloud modeli `:official` prate isti multipart ugovor:

- `mask` mora biti PNG sa Alpha kanalom, veličine najviše 4MB;
- veličina maske mora biti potpuno ista kao prva `image`;
- providni pikseli čiji je Alpha `0` označavaju da je uređivanje dozvoljeno, a neprovidni pikseli označavaju da ih treba zadržati;
- RGB slike koje su samo crno-bele, ali nemaju kanal transparentnosti, ne mogu se koristiti kao validne maske;
- prompt treba da opiše kompletnu željenu sliku, uz jasno navođenje lokalnih izmena i sadržaja koji treba da ostane nepromenjen.

U nastavku se prvo generiše maska od originalne slike. Primer postavlja centralni pravougaonik kao providan, dozvoljavajući modelu da menja samo tu oblast:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Zatim zajedno otpremite originalnu sliku i masku:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Možete koristiti i način pozivanja `images.edit` iz zvaničnog OpenAI Python SDK-a, samo treba da usmerite `base_url` na Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Kada koristite `mask`, originalna slika i maska moraju biti otpremljene u istom multipart zahtevu putem `image=@input.png` i `mask=@mask.png`. Nemojte kombinovati originalnu sliku putem URL-a i lokalnu datoteku maske; zahtevi za uređivanje samo putem URL-a ne podržavaju dodatno prilaganje lokalne datoteke `mask`. Maska će ograničiti oblast uređivanja, ali generativni model i dalje može prirodno stopiti ivice; kada su potrebne stroge granice, treba koristiti jasne Alpha ivice i u upitu ponoviti koje sadržaje je neophodno zadržati neizmenjenim.

Gorenavedeni način pozivanja usklađen je sa primerima maski u [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) i [zvaničnom GPT Image Cookbook-u](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Uobičajeni parametri

| Polje                | Opis                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (brže) ili `gpt-image-2.5-sunburst` (veća vernost i kontrola); sva tri mogu odabrati odgovarajuću varijantu `:official`, a `gpt-image-2` podržava i `:reverse` |
| `image`           | JSON koristi jedan URL ili niz od najviše 16 URL-ova; multipart koristi jedno ili više polja datoteke `image`. Kada se koristi `mask`, lokalna datoteka slike mora biti otpremljena                                              |
| `mask`            | Opciona PNG maska, samo za multipart otpremanje datoteka; mora imati Alpha kanal, biti iste veličine kao prva `image` slika i ne prelaziti 4 MB                                                                 |
| `prompt`          | Uputstvo za uređivanje                                                                                                                             |
| `size`            | `auto` ili `WIDTHxHEIGHT` koji ispunjava ograničenja                                                                                                     |
| `n`               | 1–10; kada je `response_format=b64_json`, podržano je samo 1                                                                                           |
| `response_format` | `url` ili `b64_json`                                                                                                               |
| `callback_url`    | Opciona adresa za asinhroni povratni poziv                                                                                                                         |

Pravila za dimenzije su ista kao za interfejs generisanja: širina i visina moraju biti višekratnici od 16, duža strana ne sme prelaziti 3840, ukupan broj piksela je 655.360–8.294.400, a odnos širine i visine ne sme prelaziti 3:1. Kada se `size` izostavi ili se koristi `auto`, model će odabrati format na osnovu upita i prve referentne slike.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` i njihovi pseudonimi `:reverse` naplaćuju se prema broju uspešno generisanih slika; `gpt-image-2:official`, `gpt-image-2.5-flare:official` i `gpt-image-2.5-sunburst:official` obračunavaju se prema stvarnim Tokenima tekstualnog unosa, unosa referentne slike i izlaza slike, a konačna vrednost zavisi od evidencije korišćenja.

## 6. Asinhroni povratni pozivi i otklanjanje grešaka

Dugim zadacima možete dodati sledeće u zahtev:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asinhroni odgovor 200 je `{"task_id": "..."}`; nakon završetka, povratni poziv vraća konačni rezultat. Sinhroni zahtevi vraćaju `created` i `data`.

| Status  | Provera                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Format/broj slika, kombinacija parametara i format dimenzija; kada se koristi `mask`, proverite PNG Alpha kanal, ograničenje od 4 MB i da li su njegove dimenzije iste kao kod prve originalne slike |
| 401 | API Key i Bearer Header                                           |
| 429 | Učestalost zahteva                                                              |
| 504 | Pređite na asinhroni povratni poziv                                                            |

Odgovor sa greškom sadrži `trace_id`. Kada prijavljujete problem, navedite taj ID, a nemojte navoditi API Key.

Za potpuna polja i aktuelne enumeracije pogledajte stranicu [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Za generisanje slika iz čistog teksta pogledajte [GPT Image 2 / 2.5 / 2.6 generisanje slika](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

GPT Image 2.6 koristi iste interfejse za generisanje, uređivanje, asinhrone zadatke i naplatu kao 2.5:

| Model                                                          | Naplata                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0,22 Credits/slika                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0,22 Credits/slika                   |
| `gpt-image-2.6-flare:official`                              | Isto kao 2.5 official, naplaćuje se prema stvarnoj potrošnji Tokena |
| `gpt-image-2.6-sunburst:official`                           | Isto kao 2.5 official, naplaćuje se prema stvarnoj potrošnji Tokena |

Kvalitet može biti `auto`, `low`, `medium`, `high`, `xhigh`, `max`; za dimenzije koristite `auto` ili `WIDTHxHEIGHT` koji ispunjava gorenavedena ograničenja. Ovaj interfejs podržava `png`, `jpeg`, `webp`, a SVG/GIF trenutno nisu podržani. Uređivanje podržava JSON URL-ove slika i multipart otpremanje datoteka. `:reverse` je eksplicitni pseudonim istoimene obične verzije. Koristite puni naziv modela, nemojte slati `gpt-image-2.6`.
