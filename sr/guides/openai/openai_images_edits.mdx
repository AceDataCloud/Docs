## 2. Uređivanje korišćenjem URL-a slike

Originalna slika:

![GPT Image 2 originalna slika za uređivanje](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",

    "size": "1024x1536"
  }'
```

## 3. Otpremanje lokalne slike

Koristite `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` se može proslediti više puta, a serija GPT Image podržava najviše 16 referentnih slika. `image` u JSON zahtevu može biti jedan URL ili niz URL-ova; lokalne datoteke se otpremaju putem multipart-a.

### Modeli i način naplate

| Model                                | Primena i način naplate                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | Podrazumevani obrnuti kanal, fiksna naplata po broju uspešno generisanih slika                               |
| `gpt-image-2:reverse`             | Eksplicitno bira obrnuti kanal, fiksna naplata po broju uspešno generisanih slika                             |
| `gpt-image-2:official`            | Zvanični API kanal, veća stabilnost, naplata prema stvarnoj potrošnji Tokena                   |
| `gpt-image-2.5-flare`             | Fokus na brzinu generisanja, fiksna naplata po broju uspešno generisanih slika                               |
| `gpt-image-2.6-flare`             | Fokus na brzinu generisanja, fiksna naplata po broju uspešno generisanih slika                               |
| `gpt-image-2.5-flare:reverse`     | Eksplicitni obrnuti alias, ekvivalentan `gpt-image-2.5-flare`, fiksna naplata po broju uspešno generisanih slika    |
| `gpt-image-2.6-flare:reverse`     | Eksplicitni obrnuti alias, ekvivalentan `gpt-image-2.6-flare`, fiksna naplata po broju uspešno generisanih slika    |
| `gpt-image-2.5-flare:official`    | Zvanični API kanal, veća stabilnost i fokus na brzinu generisanja, naplata prema stvarnoj potrošnji Tokena            |
| `gpt-image-2.6-flare:official`    | Zvanični API kanal, veća stabilnost i fokus na brzinu generisanja, naplata prema stvarnoj potrošnji Tokena            |
| `gpt-image-2.5-sunburst`          | Fokus na visoku vernost i preciznu kontrolu, fiksna naplata po broju uspešno generisanih slika                           |
| `gpt-image-2.6-sunburst`          | Fokus na visoku vernost i preciznu kontrolu, fiksna naplata po broju uspešno generisanih slika                           |
| `gpt-image-2.5-sunburst:reverse`  | Eksplicitni obrnuti alias, ekvivalentan `gpt-image-2.5-sunburst`, fiksna naplata po broju uspešno generisanih slika |
| `gpt-image-2.6-sunburst:reverse`  | Eksplicitni obrnuti alias, ekvivalentan `gpt-image-2.6-sunburst`, fiksna naplata po broju uspešno generisanih slika |
| `gpt-image-2.5-sunburst:official` | Zvanični API kanal, veća stabilnost i fokus na visoku vernost i preciznu kontrolu, naplata prema stvarnoj potrošnji Tokena        |
| `gpt-image-2.6-sunburst:official` | Zvanični API kanal, veća stabilnost i fokus na visoku vernost i preciznu kontrolu, naplata prema stvarnoj potrošnji Tokena        |

Obrnuti modeli 2.0 / 2.5 (uključujući `:reverse` aliase) mogu tokom automatskog oporavka koristiti GPT Image 2.5 Flare za završavanje zahteva; model zahteva i način naplate po broju uspešno generisanih slika ostaju nepromenjeni.

Prikazane cene zvaničnog API kanala su procene pre zahteva, a konačna cena se određuje prema stvarnoj potrošnji Tokena u odgovoru i zapisima o korišćenju.

`quality` podržava `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare i Sunburst (uključujući varijante `:reverse` i `:official`) dodatno podržavaju `xhigh`, `max`. Ovo polje se može proslediti i za JSON uređivanje URL-a slike i za multipart uređivanje datoteka; zvanični kanal se naplaćuje prema stvarnoj potrošnji Tokena.

## 4. Lokalno uređivanje pomoću maske

Zvanični Images Edit interfejs koristi `mask` za određivanje oblasti u kojoj su dozvoljene izmene. Modeli `:official` platforme Ace Data Cloud prate isti multipart ugovor:

- `mask` mora biti PNG sa Alpha kanalom, veličine najviše 4 MB;
- Dimenzije maske moraju biti potpuno iste kao dimenzije prve `image` slike;
- Providni pikseli čiji je Alpha `0` označavaju da je uređivanje dozvoljeno, dok neprovidni pikseli označavaju da treba da se zadrže;
- RGB slike koje su samo crno-bele, ali nemaju kanal transparentnosti, ne mogu se koristiti kao važeće maske;
- Prompt treba da opiše kompletnu željenu sliku, uz jasno navođenje lokalnih izmena i sadržaja koji treba da ostane nepromenjen.

U nastavku se prvo generiše maska iz originalne slike. Primer postavlja centralni pravougaonik kao providan, dozvoljavajući modelu da menja samo tu oblast:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Zatim zajedno otpremite originalnu sliku i masku:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Možete koristiti i način pozivanja `images.edit` iz zvaničnog OpenAI Python SDK-a; potrebno je samo da `base_url` usmerite na Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Kada koristite `mask`, originalna slika i maska moraju biti otpremljene u istom multipart zahtevu putem `image=@input.png` i `mask=@mask.png`. Nemojte kombinovati originalnu sliku preko URL-a i lokalnu datoteku maske; zahtevi za uređivanje samo preko URL-a ne podržavaju dodatnu lokalnu datoteku `mask`. Maska ograničava oblast uređivanja, ali generativni model i dalje može prirodno spojiti ivice; kada su potrebne stroge granice, treba koristiti jasne Alpha ivice i u upitu ponoviti koji sadržaj mora ostati neizmenjen.

Gorenavedeni način pozivanja je u skladu sa primerima maski u [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) i [zvaničnom GPT Image Cookbook-u](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Uobičajeni parametri

| Polje                | Opis                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (brže) ili `gpt-image-2.5-sunburst` (veća vernost i kontrola); sva tri mogu odabrati odgovarajuću varijantu `:official`, a `gpt-image-2` podržava i `:reverse` |
| `image`           | JSON koristi jedan URL ili niz od najviše 16 URL-ova; multipart koristi jedno ili više polja datoteka `image`. Kada se koristi `mask`, lokalna datoteka slike mora biti otpremljena                                              |
| `mask`            | Opciona PNG maska, ograničena samo na multipart otpremanje datoteka; mora imati Alpha kanal, biti iste veličine kao prva `image` slika i ne prelaziti 4 MB                                                                 |
| `prompt`          | Uputstvo za uređivanje                                                                                                                             |
| `size`            | `auto` ili `WIDTHxHEIGHT` koji ispunjava ograničenja                                                                                                     |
| `n`               | 1–10; kada je `response_format=b64_json`, podržano je samo 1                                                                                           |
| `response_format` | `url` ili `b64_json`                                                                                                               |
| `callback_url`    | Opciona adresa za asinhroni povratni poziv                                                                                                                         |

Pravila veličine su ista kao za interfejs za generisanje: širina i visina moraju biti višekratnici broja 16, duža stranica ne sme prelaziti 3840, ukupan broj piksela je 655.360–8.294.400, a odnos širine i visine ne sme prelaziti 3:1. Kada se `size` izostavi ili se koristi `auto`, model će na osnovu upita i prve referentne slike odabrati format kadra.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` i njihovi pseudonimi `:reverse` naplaćuju se prema broju uspešno generisanih slika; `gpt-image-2:official`, `gpt-image-2.5-flare:official` i `gpt-image-2.5-sunburst:official` obračunavaju se prema stvarnim Tokenima za tekstualni unos, unos referentnih slika i izlazne slike, a konačna evidencija korišćenja je merodavna.

## 6. Asinhroni povratni poziv i otklanjanje grešaka

Dugim zadacima možete dodati sledeće u zahtev:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asinhroni odgovor 200 je `{"task_id": "..."}`; po završetku se putem povratnog poziva šalje konačni rezultat. Sinhroni zahtevi vraćaju `created` i `data`.

| Status  | Provera                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Format/broj slika, kombinacije parametara i format veličine; pri korišćenju `mask` proverite PNG Alpha kanal, ograničenje od 4 MB i da li njena veličina odgovara prvoj originalnoj slici |
| 401 | API Key i Bearer Header                                           |
| 429 | Učestalost zahteva                                                              |
| 504 | Pređite na asinhroni povratni poziv                                                            |

Odgovori sa greškom sadrže `trace_id`. Kada prijavljujete problem, navedite taj ID, a ne API Key.

Za potpuna polja i aktuelne enumeracije pogledajte stranicu [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Za generisanje slika iz čistog teksta pogledajte [GPT Image 2 / 2.5 / 2.6 generisanje slika](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

GPT Image 2.6 koristi iste interfejse za generisanje, uređivanje, asinhrone zadatke i naplatu kao 2.5:

| Model                                                          | Naplata                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/slika                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/slika                   |
| `gpt-image-2.6-flare:official`                              | Isto kao 2.5 official, naplata prema stvarnoj potrošnji Tokena |
| `gpt-image-2.6-sunburst:official`                           | Isto kao 2.5 official, naplata prema stvarnoj potrošnji Tokena |

Kvalitet može biti `auto`, `low`, `medium`, `high`, `xhigh`, `max`; za veličinu koristite `auto` ili `WIDTHxHEIGHT` koji ispunjava gore navedena ograničenja. Ovaj interfejs podržava `png`, `jpeg`, `webp`; GPT Image 2.6 podržava i nativne `gif` animacije, dok SVG trenutno nije podržan. Uređivanje podržava URL-ove slika u JSON-u i multipart otpremanje datoteka. `:reverse` je eksplicitni pseudonim istoimene standardne verzije. Koristite puni naziv modela, nemojte slati `gpt-image-2.6`.

### GPT Image 2.6 pretvaranje slika u GIF animacije
Obična verzija Flare-a, `:reverse`, `:official`, kao i `gpt-image-2.6-sunburst:official` mogu koristiti `output_format: "gif"`. Obična verzija Sunburst-a i `:reverse` za sada ne omogućavaju GIF, i dalje podržavaju generisanje i uređivanje statičnih slika. Frejmovi animacije, informacije o petlji i trajanje reprodukcije će biti sačuvani; `frame_count` označava broj frejmova, a `frame_duration_ms` označava broj milisekundi po frejmu, oba moraju biti pozitivni celi brojevi i koriste se samo za GIF. Kada nisu navedeni, podrazumevano je 9 frejmova i 200 milisekundi po frejmu; kada je `size` za GIF izostavljen ili je auto, koristi se unapred podešena vrednost 512x512.

Preporučuje se da se prvo koristi `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. GIF ima nezavisna ograničenja veličine i broja frejmova, te se specifikacije za statične 4K slike ne mogu direktno primeniti; neki modeli će prilagoditi stvarnu izlaznu veličinu. `n` označava broj vraćenih GIF datoteka, a ne broj frejmova animacije. Obična verzija i `:reverse` se i dalje naplaćuju prema broju uspešno generisanih datoteka, dok se zvanična verzija naplaćuje prema stvarnoj potrošnji Tokena.

```json
{
  "model": "gpt-image-2.6-flare",
  "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
  "prompt": "Animate the mug gently moving left and right. Keep its appearance and the background, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### GPT Image 2.6 4K statične slike

Flare, Sunburst i njihove varijante `:reverse`, `:official` mogu koristiti prethodno navedene 4K unapred podešene pikselne vrednosti, kao što su `3840x2160` i `2160x3840`. I generisanje i uređivanje prosleđuju konkretne piksele putem `size`; `4K` nije važeća vrednost za `size`, a `4096x4096` takođe prelazi trenutno ograničenje piksela. Gore navedene 4K specifikacije primenjuju se na statične PNG/JPEG/WebP slike, a za GIF koristite njegove namenske parametre.
