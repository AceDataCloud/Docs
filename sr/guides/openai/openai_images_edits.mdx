## 2. Uređivanje pomoću URL-a slike

Originalna slika:

curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",

## 3. Otpremanje lokalne slike

Koristite `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

Možete ponovljeno proslediti `image`; GPT Image serija podržava najviše 16 referentnih slika. `image` u JSON zahtevu može biti jedan URL ili niz URL-ova; lokalne datoteke se otpremaju pomoću multipart-a.

### Modeli i način naplate

| Model                                | Primenjivi scenariji i način naplate                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Podrazumevani reverzni kanal, fiksna naplata po broju uspešnih slika                        |
| `gpt-image-2:reverse`             | Izričit izbor reverznog kanala, fiksna naplata po broju uspešnih slika                      |
| `gpt-image-2:official`            | Zvanični API kanal, veća stabilnost, naplata prema stvarnoj upotrebi Tokena            |
| `gpt-image-2.5-flare`             | Fokus na brzini generisanja, fiksna naplata po broju uspešnih slika                        |
| `gpt-image-2.5-flare:official`    | Zvanični API kanal, veća stabilnost i fokus na brzini generisanja, naplata prema stvarnoj upotrebi Tokena     |
| `gpt-image-2.5-sunburst`          | Fokus na visokoj vernosti i preciznoj kontroli, fiksna naplata po broju uspešnih slika                    |
| `gpt-image-2.5-sunburst:official` | Zvanični API kanal, veća stabilnost i fokus na visokoj vernosti i preciznoj kontroli, naplata prema stvarnoj upotrebi Tokena |

Cene na stranici za zvanični API kanal predstavljaju procenu pre zahteva; konačna cena se određuje prema stvarnoj upotrebi Tokena u odgovoru i evidenciji korišćenja.

## 4. Lokalno uređivanje pomoću maske

Zvanični Images Edit interfejs koristi `mask` za određivanje oblasti koje je dozvoljeno menjati. Ace Data Cloud `:official` modeli prate isti multipart ugovor:

- `mask` mora biti PNG sa Alpha kanalom, veličine najviše 4 MB;
- Veličina maske mora biti potpuno ista kao prva `image`;
- Providni pikseli sa Alpha vrednošću `0` označavaju da je uređivanje dozvoljeno, dok neprovidni pikseli označavaju da ih treba zadržati;
- RGB slike koje su samo crno-bele, ali nemaju kanal transparentnosti, ne mogu se koristiti kao važeće maske;
- Prompt treba da opisuje kompletnu željenu sliku, uz jasno navođenje lokalnih izmena i sadržaja koji treba da ostane nepromenjen.

U nastavku se najpre generiše maska iz originalne slike. Primer postavlja centralni pravougaonik kao providan i dozvoljava modelu da menja samo tu oblast:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Zatim zajedno otpremite originalnu sliku i masku:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Takođe možete nastaviti da koristite način pozivanja `images.edit` iz zvaničnog OpenAI Python SDK-a; potrebno je samo da `base_url` usmerite na Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Kada koristite `mask`, originalna slika i maska moraju biti otpremljene u istom multipart zahtevu, zasebno preko `image=@input.png` i `mask=@mask.png`. Nemojte mešati originalnu sliku putem URL-a sa lokalnom datotekom maske; zahtevi za uređivanje isključivo putem URL-a ne podržavaju dodatno prilaganje lokalne datoteke `mask`. Maska će ograničiti oblast uređivanja, ali generativni model i dalje može prirodno uklapati ivice; kada su potrebne stroge granice, treba koristiti jasne Alpha ivice i u promptu ponoviti koje stavke moraju ostati nepromenjene.

Navedeni način pozivanja je u skladu sa primerima maski iz [OpenAI Image Edit API-ja](https://developers.openai.com/api/reference/python/resources/images/methods/edit) i [zvaničnog GPT Image Cookbook-a](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).
## 5. Uobičajeni parametri

| Polje                | Objašnjenje                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (brži) ili `gpt-image-2.5-sunburst` (veća vernost i kontrola); sva tri mogu odabrati odgovarajuću varijantu `:official`, a `gpt-image-2` takođe podržava `:reverse` |
| `image`           | JSON koristi jedan URL ili niz od najviše 16 URL-ova; multipart koristi jedno ili više polja datoteka `image`. Kada se koristi `mask`, mora se otpremiti lokalna slikovna datoteka                                              |
| `mask`            | Opcionalna PNG maska, ograničena samo na multipart otpremanje datoteka; mora imati Alpha kanal, biti istih dimenzija kao prva `image` slika i ne prelaziti 4 MB                                                                 |
| `prompt`          | Uputstvo za uređivanje                                                                                                                             |
| `size`            | `auto` ili `WIDTHxHEIGHT` koji odgovara ograničenjima                                                                                                     |
| `n`               | 1–10; kada je `response_format=b64_json`, podržan je samo 1                                                                                           |
| `response_format` | `url` ili `b64_json`                                                                                                               |
| `callback_url`    | Opcionalna adresa za asinhroni povratni poziv                                                                                                                         |

Pravila dimenzija su ista kao za interfejs generisanja: širina i visina moraju biti višekratnici broja 16, duža strana ne sme prelaziti 3840, ukupan broj piksela iznosi 655,360–8,294,400, a odnos širine i visine ne sme prelaziti 3:1. Kada se `size` izostavi ili se koristi `auto`, model će odabrati format kadra na osnovu prompta i prve referentne slike.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` i `gpt-image-2:reverse` naplaćuju se prema broju uspešnih slika; `gpt-image-2:official`, `gpt-image-2.5-flare:official` i `gpt-image-2.5-sunburst:official` obračunavaju se prema stvarnim Tokenima tekstualnog unosa, unosa referentnih slika i izlaza slika, pri čemu je konačna vrednost zasnovana na evidenciji korišćenja.

## 6. Asinhroni povratni pozivi i otklanjanje grešaka

Za duge zadatke možete dodati u zahtev:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asinhroni odgovor 200 je `{"task_id": "..."}`; nakon završetka, povratni poziv vraća konačni rezultat. Sinhroni zahtevi vraćaju `created` i `data`.

| Status  | Provera                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Format/broj slika, kombinacije parametara i format dimenzija; kada se koristi `mask`, proverite PNG Alpha kanal, ograničenje od 4 MB i da li njegove dimenzije odgovaraju prvoj originalnoj slici |
| 401 | API Key i Bearer Header                                           |
| 429 | Učestalost zahteva                                                              |
| 504 | Pređite na asinhroni povratni poziv                                                            |

Odgovor o grešci sadrži `trace_id`. Kada prijavljujete problem, navedite taj ID, a nemojte navoditi API Key.

Za kompletna polja i enumeracije u realnom vremenu, pogledajte stranicu [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Za generisanje slika isključivo iz teksta, pogledajte [GPT Image 2 / 2.5 generisanje slika](https://platform.acedata.cloud/documents/openai-images-generations).
