OpenAI servis za uređivanje slika omogućava unošenje proizvoljnog broja slika i instrukcija, a zatim vraća izmenjene slike. Trenutno interfejs podržava `dall-e-2`, `gpt-image-1`, najnoviji **`gpt-image-2`**, kao i modele iz serije **`nano-banana` / `nano-banana-2` / `nano-banana-pro`** koji su integrisani kroz isti interfejs.

Ovaj dokument uglavnom opisuje proces korišćenja OpenAI Images Edits API-ja, koji nam omogućava lako korišćenje zvanične OpenAI funkcionalnosti za uređivanje slika.

## Proces prijave

Da biste koristili OpenAI Images Edits API, prvo posetite stranicu [OpenAI Images Edits API](https://platform.acedata.cloud/documents/251f1efa-aaa6-462e-8af4-66854b1bc94d) i kliknite na dugme „Acquire“ da biste dobili potrebne akreditive za zahteve:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ako niste prijavljeni ili registrovani, bićete automatski preusmereni na stranicu za prijavu gde se možete registrovati i prijaviti, nakon čega ćete biti vraćeni na trenutnu stranicu.

Prilikom prve prijave dobijate besplatni kredit koji omogućava besplatno korišćenje API-ja.

## GPT-Image-2 model

`gpt-image-2` donosi značajna poboljšanja u odnosu na `gpt-image-1` u scenarijima uređivanja slika:

- **Stabilnija struktura**: Promena kože, boje ili pozadine gotovo da ne narušava originalni raspored i kompoziciju slike.
- **Preciznije očuvanje teksta**: Tekst na infografikama, posterima, menijima i sličnim slikama ostaje jasan i čitljiv nakon uređivanja.
- **Podrška za direktan unos URL-a**: Pored tradicionalnog `multipart/form-data` upload-a fajlova, `gpt-image-2` dodatno podržava unošenje URL-a slike u JSON formatu, bez potrebe za prethodnim preuzimanjem slike lokalno, što je idealno za serverske pipeline integracije.
- **Podrška za uređivanje visokih rezolucija**: Možete poslati 1K originalnu sliku i preko parametra `size` zatražiti 2K ili 4K izlaz, model će tokom uređivanja izvršiti i skaliranje.

### Podržane vrednosti `size` i cenovni razredi

Ograničenja za `size` u uređivačkom interfejsu su ista kao i u generativnom — `gpt-image-2` prihvata `size` kao `auto`, prazno ili u formatu `WIDTHxHEIGHT`. Bilo koja druga vrednost vraća grešku 400. Cena se deli na dva nivoa, nezavisno od rezolucije originalne slike, već samo na osnovu vrednosti `size`:

- **1K standardna cena**: bilo koja od preporučenih 1K dimenzija iz tabele ili uobičajeni 1K aliasi (`1254x1254`, `1672x941`, `941x1672`).
- **Ostali nivoi (1.5×)**: uključuju preporučene 2K i 4K dimenzije iz tabele, kao i bilo koju korisnički definisanu dimenziju u formatu `WIDTHxHEIGHT`.

Takođe važe ograničenja upstream servisa: širina i visina moraju biti deljivi sa 16, duža strana ≤ 3840, ukupni broj piksela ≤ 8,294,400.

| Odnos | 1K (standardna cena) | 2K preporučeno (×1.5) | 4K preporučeno (×1.5) |
| --- | --- | --- | --- |
| 1:1 | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3 | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4 | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

> Na primer: ako je original `1024x1024`, a `size` je `2048x2048`, model će izmeniti i vratiti 2K sliku i naplatiti po „ostalom“ nivou; ako je `size` `3840x2160`, izlaz je 4K pejzaž i takođe se naplaćuje po „ostalom“ nivou; ako je `auto` ili izostavljeno, naplaćuje se po 1K standardnoj ceni.

> **O parametru `n`**
>
> Trenutno `gpt-image-2` uređivački interfejs **ne podržava `n > 1`**: ovaj parametar se ignoriše, bez obzira da li je `n=1` ili `n=10`, vraća se samo jedna slika i naplaćuje se kao jedna. Ako vam treba više kandidata, morate sami paralelno slati više zahteva. Ovo ograničenje važi i za `gpt-image-1` / `gpt-image-1.5` i `nano-banana` seriju. `dall-e-2` je jedini uređivački model koji nativno podržava `n > 1`.

Ispod su dva stvarna primera koja prikazuju uređivačke mogućnosti `gpt-image-2`.

### Način poziva 1: JSON + URL slike (preporučeno)

Pošaljite zahtev sa `application/json` tipom, u polje `image` unesite URL slike, model će preuzeti sliku i izmeniti je prema `prompt` instrukciji.

Na primer, originalna slika ispod je infografik generisan `gpt-image-2` modelom:

<p><img src="https://platform.cdn.acedata.cloud/gpt-image/5c9fa635-8794-4c6d-88f8-584d7f4716c6_0.png" width="500" className="m-auto" /></p>

Želimo da je prebacimo u „noćni režim“ boja. Poziv izgleda ovako:

```shell
curl -X POST "https://api.acedata.cloud/openai/images/edits" \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform.cdn.acedata.cloud/gpt-image/5c9fa635-8794-4c6d-88f8-584d7f4716c6_0.png",
    "prompt": "Convert this infographic to dark mode: dark navy background, light cream text, deep gray rounded module cards with soft shadows. Keep all layout, structure, and module arrangement identical — only invert the color scheme.",
    "size": "1024x1536"
  }'
```

Ili u Pythonu:

```python
import requests

url = "https://api.acedata.cloud/openai/images/edits"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-image-2",
    "image": "https://platform.cdn.acedata.cloud/gpt-image/5c9fa635-8794-4c6d-88f8-584d7f4716c6_0.png",
    "prompt": "Convert this infographic to dark mode: dark navy background, light cream text, deep gray rounded module cards with soft shadows. Keep all layout, structure, and module arrangement identical — only invert the color scheme.",
    "size": "1024x1536"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```json
  "created": 1777048863,
  "data": [
    {
      "revised_prompt": "Convert this infographic to dark mode: dark navy background, light cream text, deep gray rounded module cards with soft shadows. Keep all layout, structure, and module arrangement identical — only invert the color scheme.",
      "url": "https://platform.cdn.acedata.cloud/gpt-image/cb104e35-af1f-45be-9fac-b62e2b256753_0.png"
```

<p><img src="https://platform.cdn.acedata.cloud/gpt-image/cb104e35-af1f-45be-9fac-b62e2b256753_0.png" width="500" className="m-auto" /></p>

### Način poziva 2: JSON + više referentnih slika

`gpt-image-2` može koristiti više slika kao referencu za generisanje konačnog rezultata, na primer spajanje više proizvoda u jednu poklon korpu:

```python

    "image": [
```

### Način poziva 3: multipart/form-data (kompatibilno sa OpenAI SDK)

Ako koristite zvanični OpenAI Python SDK, možete koristiti i tradicionalni `multipart/form-data` upload, samo zamenite `model` u `gpt-image-2`:

```python
import base64
from openai import OpenAI
client = OpenAI()

result = client.images.edit(
    model="gpt-image-2",
    image=[open("test.png", "rb")],
    prompt="Convert this image to dark mode while keeping the layout intact."
)

image_base64 = result.data[0].b64_json
image_bytes = base64.b64decode(image_base64)
with open("edited.png", "wb") as f:
    f.write(image_bytes)
```

Za korišćenje SDK-ja potrebno je prethodno postaviti dva environment varijable, `OPENAI_BASE_URL` na `https://api.acedata.cloud/openai` i `OPENAI_API_KEY` na dobijeni token:

```shell
export OPENAI_BASE_URL=https://api.acedata.cloud/openai
export OPENAI_API_KEY={token}
```

## Nano Banana serija modela

`nano-banana` serija je takođe integrisana u `/openai/images/edits` endpoint, samo promenite `model` u jedan od sledećih:

| Model | Cena (krediti / poziv) | Scenariji upotrebe |
| --- | --- | --- |
| `nano-banana` | 0.14 | Standardno uređivanje slika, najbrže i najjeftinije |
| `nano-banana-2` | 0.28 | Poboljšan kvalitet i detalji |
| `nano-banana-pro` | 0.35 | Flagship model serije, najbolje očuvanje strukture, teksta i stila |

> **Važno: podržani parametri**
>
> Nano Banana koristi adapter sloj za OpenAI protokol i podržava samo sledeće parametre: `model`, `prompt`, `image`.
>
> - `image` može biti fajl upload preko `multipart/form-data` (unutar worker-a konvertuje u `data:<mime>;base64,...` za upstream) ili URL kao string u formi.
> - Nisu podržani parametri `mask`, `n`, `size`, `response_format` i slično; biće ignorisani ako se pošalju.
> - Povratna struktura prati OpenAI format (`data[].url`), ali `created` je uvek 0, ne vraća se `b64_json`, a `revised_prompt` je uvek isti kao originalni `prompt`.

### Poziv preko forme + URL slike

```shell
curl -X POST "https://api.acedata.cloud/openai/images/edits" \
  -H "Authorization: Bearer {token}" \
  -F "model=nano-banana" \
  -F "prompt=add a green leaf on top of the apple" \
  -F "image=https://platform.cdn.acedata.cloud/nanobanana/6870b330-65c4-436c-bb80-819fdae7a7a4.png"
```

Odgovor:

```json

      "url": "https://platform.cdn.acedata.cloud/nanobanana/311e95b6-5eb1-4c4a-8ee6-0cb03ee44f61.jpeg",
      "revised_prompt": "add a green leaf on top of the apple"

```

Izmenjena slika:

<p><img src="https://platform.cdn.acedata.cloud/nanobanana/311e95b6-5eb1-4c4a-8ee6-0cb03ee44f61.jpeg" width="500" className="m-auto" /></p>

### Poziv preko forme + lokalni fajl

```python
import requests

url = "https://api.acedata.cloud/openai/images/edits"

headers = {
    "authorization": "Bearer {token}"
}

files = {
    "image": open("apple.png", "rb"),
}
data = {
    "model": "nano-banana-pro",
    "prompt": "add a green leaf on top of the apple"
}

response = requests.post(url, headers=headers, files=files, data=data)
print(response.text)
```

### Asinhroni callback

Mogućnost asinhronog poziva `callback_url` važi i za nano-banana modele, proces je isti kao i za ostale modele, vidi odeljak [Asinhroni callback](#asinhroni-callback).

## Osnovna upotreba

Sada možemo pozvati API iz koda, primer korišćenja CURL:

```curl
curl -s -D >(grep -i x-request-id >&2) \
  -o >(jq -r '.data[0].b64_json' | base64 --decode > gift-basket.png) \
  -X POST "https://api.acedata.cloud/v1/images/edits" \
  -H "Authorization: Bearer {token}" \
  -F "model=gpt-image-1" \
  -F "image[]=@test.png" \
  -F 'prompt=Create a lovely gift basket with these this items in it'
```

Prilikom prvog korišćenja potrebno je uneti četiri parametra: `authorization` (birate iz padajućeg menija), `model` (izaberite model sa liste, detalji u dokumentu), `prompt` (tekstualni opis za generisanje slike) i `image` (putanja do slike za uređivanje). Primer slike za uređivanje:

<p><img src="https://cdn.acedata.cloud/jw9iwu.png" width="500" className="m-auto" /></p>

Isti poziv u Pythonu:

```python
import base64
from openai import OpenAI
client = OpenAI()

prompt = """
Generate a photorealistic image of a gift basket on a white background 
labeled 'Relax & Unwind' with a ribbon and handwriting-like font, 
containing all the items in the reference pictures.
"""

result = client.images.edit(
    model="gpt-image-1",
    image=[
        open("test.png", "rb")
    ],
    prompt=prompt
)

image_base64 = result.data[0].b64_json
image_bytes = base64.b64decode(image_base64)

# Sačuvaj sliku u fajl
with open("gift-basket.png", "wb") as f:
    f.write(image_bytes)
```

Za Python pozive potrebno je postaviti dva environment varijable: `OPENAI_BASE_URL` na `https://api.acedata.cloud/openai` i `OPENAI_API_KEY` na dobijeni token:

```shell
export OPENAI_BASE_URL=https://api.acedata.cloud/openai
export OPENAI_API_KEY={token} 
```

Nakon poziva, u trenutnom direktorijumu će biti kreirana slika `gift-basket.png`, primer rezultata:

<p><img src="https://cdn.acedata.cloud/574s8h.png" width="500" className="m-auto" /></p>

Na ovaj način završavamo uređivanje slike. Trenutno Edits endpoint podržava tri modela: `dall-e-2`, `gpt-image-1` i `gpt-image-2`, pri čemu je `gpt-image-2` preporučeni model, vidi [GPT-Image-2 model](#gpt-image-2-model).

## Asinhroni callback

Pošto uređivanje slika može potrajati, a HTTP zahtev bi u međuvremenu držao vezu otvorenom što troši resurse, API podržava asinhroni callback.

Proces je sledeći: klijent šalje zahtev sa dodatnim poljem `callback_url`. API odmah vraća odgovor sa `task_id` koji identifikuje zadatak. Kada je zadatak završen, rezultat uređivanja se šalje POST JSON zahtevom na `callback_url`, uključujući i `task_id` za povezivanje.

Primer:

Webhook callback je HTTP servis koji može primati zahteve. Za testiranje možete koristiti javni sajt https://webhook.site/, koji generiše URL za primanje webhook zahteva:

![](https://cdn.acedata.cloud/cjjfly.png)

Kopirajte URL, na primer `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`, i koristite ga kao `callback_url`:

```shell
curl -X POST "https://api.acedata.cloud/v1/images/edits" \
  -H "Authorization: Bearer {token}" \
  -F "model=gpt-image-1" \
  -F "image[]=@test.png" \
  -F "prompt=Create a lovely gift basket with these items in it" \
  -F "callback_url=https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab"
```

Odmah dobijate odgovor:

```json
{
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c"
}
```

Nakon kraćeg vremena, na Webhook URL-u možete videti rezultat:

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": {
    "created": 1721626477,
    "data": [
      {
        "b64_json": "iVBORw0KGgo..."
      }
    ]
  }
}
```

Rezultat sadrži `task_id` i polje `data` sa istim podacima kao i sinhroni poziv, što omogućava povezivanje rezultata sa zadatkom.

## Obrada grešaka

Ako dođe do greške, API vraća odgovarajući kod i poruku, na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće nedostaju parametri ili su nevalidni.
- `400 api_not_implemented`: Neispravan zahtev, moguće nedostaju parametri ili su nevalidni.
- `401 invalid_token`: Neautorizovan pristup, neispravan ili nedostajući token.
- `429 too_many_requests`: Previše zahteva, prekoračen limit.
- `500 api_error`: Interna greška servera.

### Primer greške

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
