OpenAI услуга за uređivanje slika omogućava unos neograničenog broja slika i instrukcija, a izlaz su izmenjene slike.

Ovaj dokument uglavnom opisuje proces korišćenja OpenAI Images Edits API, koristeći ga možemo lako koristiti zvanične OpenAI funkcije za uređivanje slika.

## 申请流程

Da biste koristili OpenAI Images Edits API, prvo možete otići na [OpenAI Images Edits API](https://platform.acedata.cloud/documents/251f1efa-aaa6-462e-8af4-66854b1bc94d) stranicu i kliknuti na dugme „Acquire“ da biste dobili potrebne akreditive:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu, koju možete besplatno koristiti za ovaj API.

## 基本使用

Sledeće možete koristiti kod za pozivanje, ispod je poziv putem CURL-a:

```curl
curl -s -D >(grep -i x-request-id >&2) \
  -o >(jq -r '.data[0].b64_json' | base64 --decode > gift-basket.png) \
  -X POST "https://api.acedata.cloud/v1/images/edits" \
  -H "Authorization: Bearer {token}" \
  -F "model=gpt-image-1" \
  -F "image[]=@test.png" \
  -F 'prompt=Create a lovely gift basket with these this items in it'
```

Prilikom prvog korišćenja ovog interfejsa, potrebno je da popunite najmanje četiri sadržaja, jedan je `authorization`, koji možete direktno izabrati iz padajuće liste. Drugi parametar je `model`, `model` je kategorija modela koju biramo da koristimo sa OpenAI zvanične stranice, ovde imamo uglavnom 1 model, detalje možete videti u modelima koje pružamo. Treći parametar je `prompt`, `prompt` je reč koja opisuje sliku koju želimo da generišemo. Poslednji parametar je `image`, ovaj parametar zahteva putanju do slike koja treba da se uređuje, slike koje treba da se uređuju su prikazane ispod:

<p><img src="https://cdn.acedata.cloud/jw9iwu.png" width="500" className="m-auto" /></p>

Primer poziva u Python-u sa istim efektom:

```python
import base64
from openai import OpenAI
client = OpenAI()

prompt = """
Generate a photorealistic image of a gift basket on a white background 
labeled 'Relax & Unwind' with a ribbon and handwriting-like font, 
containing all the items in the reference pictures.
"""

result = client.images.edit(
    model="gpt-image-1",
    image=[
        open("test.png", "rb")
    ],
    prompt=prompt
)

image_base64 = result.data[0].b64_json
image_bytes = base64.b64decode(image_base64)

# Save the image to a file
with open("gift-basket.png", "wb") as f:
    f.write(image_bytes)
```

Kada koristimo Python za pozivanje, prvo moramo da uvezemo dve promenljive okruženja, jednu `OPENAI_BASE_URL`, koju možemo postaviti na `https://api.acedata.cloud/openai`, i drugu promenljivu za akreditive `OPENAI_API_KEY`, čija vrednost dolazi iz `authorization`, na Mac OS-u možete postaviti promenljive okruženja pomoću sledeće komande:

```shell
export OPENAI_BASE_URL=https://api.acedata.cloud/openai
export OPENAI_API_KEY={token} 
```

Nakon poziva, otkrićemo da je u trenutnom direktorijumu generisana slika `gift-basket.png`, konkretni rezultat je prikazan ispod:

<p><img src="https://cdn.acedata.cloud/574s8h.png" width="500" className="m-auto" /></p>

Tako smo završili operaciju uređivanja slike, trenutno zvanični Edits zadatak podržava samo dva modela, a to su: `dall-e-2`, `gpt-image-1`.

## 异步回调

Pošto vreme potrebno za uređivanje slika putem OpenAI Images Edits API može biti relativno dugo, ako API dugo ne odgovara, HTTP zahtev će zadržati vezu, što dovodi do dodatne potrošnje sistemskih resursa, tako da ovaj API takođe pruža podršku za asinhrone povratne informacije.

Celokupni proces je: kada klijent pokrene zahtev, dodatno se navodi polje `callback_url`, nakon što klijent pošalje API zahtev, API odmah vraća rezultat koji sadrži informaciju o `task_id`, koja predstavlja trenutni ID zadatka. Kada zadatak bude završen, rezultat uređene slike biće poslat na `callback_url` koji je klijent odredio, u formatu POST JSON, a takođe uključuje i polje `task_id`, tako da se rezultati zadatka mogu povezati putem ID-a.

Pogledajmo kako to konkretno funkcioniše kroz primer.

Prvo, Webhook povratna informacija je usluga koja može primati HTTP zahteve, programeri bi trebali zameniti URL svoje HTTP servera. Ovde, radi lakšeg prikazivanja, koristi se javni Webhook uzorak sa sajta https://webhook.site/, otvaranjem tog sajta dobijate Webhook URL, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/cjjfly.png)

Kopirajte ovaj URL i možete ga koristiti kao Webhook, uzorak ovde je `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`.

Sledeće, možemo postaviti polje `callback_url` na navedeni Webhook URL, a takođe popuniti odgovarajuće parametre, kao što je prikazano u sledećem kodu:

```shell
curl -X POST "https://api.acedata.cloud/v1/images/edits" \
  -H "Authorization: Bearer {token}" \
  -F "model=gpt-image-1" \
  -F "image[]=@test.png" \
  -F "prompt=Create a lovely gift basket with these items in it" \
  -F "callback_url=https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab"
```

Nakon poziva, odmah dobijamo rezultat, kao što je prikazano ispod:

```json
{
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c"
}
```

Nakon nekoliko trenutaka, možemo na Webhook URL-u primetiti rezultat uređene slike, sadržaj je sledeći:

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": {
    "created": 1721626477,
    "data": [
      {
        "b64_json": "iVBORw0KGgo..."
      }
    ]
  }
}
```

Možemo videti da rezultat sadrži polje `task_id`, a polje `data` uključuje rezultate uređivanja slika kao i kod sinhronog poziva, putem polja `task_id` možemo ostvariti povezanost zadatka.

## 错误处理

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### 错误响应示例

}
