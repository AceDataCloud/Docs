## 2. Uređivanje korišćenjem URL-a slike

Originalna slika:

![GPT Image 2 originalna slika za uređivanje](https://cdn.acedata.cloud/18240dc44b9c.png)

curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",

## 3. Otpremanje lokalne slike

Koristite `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` se može proslediti više puta, GPT Image serija podržava najviše 16 referentnih slika. `image` u JSON zahtevu može biti jedan URL ili niz URL-ova; lokalne datoteke se otpremaju putem multipart-a.

### Modeli i način naplate

| Model                                | Primenljivi scenariji i način naplate                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | Podrazumevani obrnuti kanal, fiksna naplata prema broju uspešno generisanih slika                               |
| `gpt-image-2:reverse`             | Eksplicitno bira obrnuti kanal, fiksna naplata prema broju uspešno generisanih slika                             |
| `gpt-image-2:official`            | Zvanični API kanal, veća stabilnost, naplata prema stvarnoj potrošnji Token-a                   |
| `gpt-image-2.5-flare`             | Fokus na brzinu generisanja, fiksna naplata prema broju uspešno generisanih slika                               |
| `gpt-image-2.6-flare`             | Fokus na brzinu generisanja, fiksna naplata prema broju uspešno generisanih slika                               |
| `gpt-image-2.5-flare:reverse`     | Eksplicitni obrnuti alias, ekvivalentan sa `gpt-image-2.5-flare`, fiksna naplata prema broju uspešno generisanih slika    |
| `gpt-image-2.6-flare:reverse`     | Eksplicitni obrnuti alias, ekvivalentan sa `gpt-image-2.6-flare`, fiksna naplata prema broju uspešno generisanih slika    |
| `gpt-image-2.5-flare:official`    | Zvanični API kanal, veća stabilnost i fokus na brzinu generisanja, naplata prema stvarnoj potrošnji Token-a            |

| `gpt-image-2.5-sunburst`          | Fokus na visoku vernost i preciznu kontrolu, fiksna naplata prema broju uspešno generisanih slika                           |

| `gpt-image-2.6-sunburst:reverse`  | Eksplicitni obrnuti alias, ekvivalentan sa `gpt-image-2.6-sunburst`, fiksna naplata prema broju uspešno generisanih slika |
| `gpt-image-2.5-sunburst:official` | Zvanični API kanal, veća stabilnost i fokus na visoku vernost i preciznu kontrolu, naplata prema stvarnoj potrošnji Token-a        |
| `gpt-image-2.6-sunburst:official` | Zvanični API kanal, veća stabilnost i fokus na visoku vernost i preciznu kontrolu, naplata prema stvarnoj potrošnji Token-a        |

Cene na stranici za zvanični API kanal su procene pre zahteva, a konačna cena se zasniva na stvarnoj potrošnji Token-a u odgovoru i zapisima o korišćenju.

`quality` podržava `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare i Sunburst (uključujući varijante `:reverse` i `:official`) dodatno podržavaju `xhigh`, `max`. I JSON uređivanje URL-a slike i multipart uređivanje datoteke mogu proslediti ovo polje; zvanični kanal naplaćuje prema stvarnoj potrošnji Token-a.

## 4. Lokalno uređivanje korišćenjem maske

Zvanični Images Edit interfejs određuje oblast u kojoj su izmene dozvoljene putem `mask`. `:official` modeli Ace Data Cloud-a prate isti multipart ugovor:

- `mask` mora biti PNG sa Alpha kanalom, veličine ne veće od 4MB;
- veličina maske mora biti potpuno ista kao prva `image`;
- providni pikseli čiji je Alpha `0` označavaju da je uređivanje dozvoljeno, a neprovidni pikseli označavaju da ih treba zadržati;
- RGB slike koje su samo crno-bele, ali nemaju kanal transparentnosti, ne mogu se koristiti kao važeće maske;
- prompt treba da opiše kompletnu željenu sliku, uz jasno navođenje lokalnih izmena i sadržaja koji treba da ostane nepromenjen.

U nastavku se prvo generiše maska od originalne slike. Primer postavlja centralni pravougaonik kao providan, dozvoljavajući modelu da menja samo tu oblast:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Zatim zajedno otpremite originalnu sliku i masku:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Možete koristiti i način poziva `images.edit` iz zvaničnog OpenAI Python SDK-a, potrebno je samo da `base_url` usmerite na Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Kada koristite `mask`, originalna slika i maska moraju biti otpremljene u istom multipart zahtevu, zasebno putem `image=@input.png` i `mask=@mask.png`. Nemojte mešati originalnu sliku preko URL-a i lokalnu datoteku maske; zahtevi za uređivanje samo putem URL-a ne podržavaju dodatno prilaganje lokalne datoteke `mask`. Maska će ograničiti oblast uređivanja, ali generativni model i dalje može prirodno spojiti ivice; kada su potrebne stroge granice, koristite jasne Alpha ivice i u promptu ponovite koje sadržaje je neophodno zadržati neizmenjenim.

Gorenavedeni način poziva je u skladu sa primerima maski u [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) i [zvaničnom GPT Image Cookbook-u](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Uobičajeni parametri

| Polje                | Opis                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (brži) ili `gpt-image-2.5-sunburst` (veća vernost i kontrola); sva tri mogu odabrati odgovarajuću varijantu `:official`, a `gpt-image-2` podržava i `:reverse` |
| `image`           | JSON koristi jedan URL ili niz od najviše 16 URL-ova; multipart koristi jedno ili više polja datoteka `image`. Kada se koristi `mask`, obavezno je otpremiti lokalnu datoteku slike                                              |
| `mask`            | Opcionalna PNG maska, samo za multipart otpremanje datoteka; mora imati Alpha kanal, biti istih dimenzija kao prva `image` slika i ne prelaziti 4 MB                                                                 |
| `prompt`          | Uputstvo za uređivanje                                                                                                                             |
| `size`            | `auto` ili `WIDTHxHEIGHT` koji ispunjava ograničenja                                                                                                     |
| `n`               | 1–10; kada je `response_format=b64_json`, podržano je samo 1                                                                                           |
| `response_format` | `url` ili `b64_json`                                                                                                               |
| `callback_url`    | Opcionalna adresa za asinhroni povratni poziv                                                                                                                         |

Pravila za dimenzije su ista kao za interfejs za generisanje: širina i visina moraju biti višekratnici od 16, duža stranica ne sme prelaziti 3840, ukupan broj piksela je 655.360–8.294.400, a odnos širine i visine ne sme prelaziti 3:1. Kada se `size` izostavi ili se koristi `auto`, model će odabrati format na osnovu prompta i prve referentne slike.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` i njihovi pseudonimi `:reverse` naplaćuju se prema broju uspešno generisanih slika; `gpt-image-2:official`, `gpt-image-2.5-flare:official` i `gpt-image-2.5-sunburst:official` obračunavaju se prema stvarnim Tokenima za tekstualni unos, unos referentne slike i izlaznu sliku, a konačna evidencija korišćenja je merodavna.

## 6. Asinhroni povratni pozivi i otklanjanje grešaka

Dugim zadacima možete dodati sledeće u zahtev:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asinhroni odgovor 200 je `{"task_id": "..."}`; po završetku povratni poziv vraća konačan rezultat. Sinhroni zahtevi vraćaju `created` i `data`.

| Status  | Provera                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Format/broj slika, kombinacija parametara i format dimenzija; kada se koristi `mask`, proverite PNG Alpha kanal, ograničenje od 4 MB i da li su njegove dimenzije iste kao kod prve originalne slike |
| 401 | API Key i Bearer Header                                           |
| 429 | Učestalost zahteva                                                              |
| 504 | Pređite na asinhroni povratni poziv                                                            |

Odgovori o grešci sadrže `trace_id`. Kada prijavljujete problem, navedite taj ID, a ne API Key.

Za potpuna polja i aktuelne enumeracije pogledajte stranicu [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Za generisanje slika iz čistog teksta pogledajte [GPT Image 2 / 2.5 / 2.6 generisanje slika](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

GPT Image 2.6 koristi iste interfejse za generisanje, uređivanje, asinhrone zadatke i naplatu kao 2.5:

| Model                                                          | Naplata                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/slika                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/slika                   |
| `gpt-image-2.6-flare:official`                              | Isto kao 2.5 official, naplaćuje se prema stvarnoj potrošnji Tokena |
| `gpt-image-2.6-sunburst:official`                           | Isto kao 2.5 official, naplaćuje se prema stvarnoj potrošnji Tokena |

Kvalitet može biti `auto`, `low`, `medium`, `high`, `xhigh`, `max`; za dimenzije koristite `auto` ili `WIDTHxHEIGHT` koji ispunjava gore navedena ograničenja. Ovaj interfejs podržava `png`, `jpeg`, `webp`; GPT Image 2.6 takođe podržava izvorne `gif` animacije, dok SVG trenutno nije podržan. Uređivanje podržava JSON URL-ove slika i multipart otpremanje datoteka. `:reverse` je eksplicitni pseudonim istoimene obične verzije. Koristite potpuni naziv modela, nemojte slati `gpt-image-2.6`.

### GPT Image 2.6 pretvaranje slike u GIF animaciju
GPT Image 2.6 Flare, Sunburst u standardnoj verziji, `:reverse`, `:official` svi mogu koristiti `output_format: "gif"`. Animacioni frejmovi, informacije o petlji i trajanje reprodukcije će biti sačuvani; `frame_count` označava broj frejmova, `frame_duration_ms` označava broj milisekundi po frejmu, broj frejmova mora biti ceo broj od 2–16, trajanje svakog frejma mora biti ceo broj od 20–655350 milisekundi i koristi se samo za GIF; kodiranje se zaokružuje na najbližih 10 ms. Kada nije navedeno, podrazumevano je 9 frejmova i 200 milisekundi po frejmu; kada je `size` za GIF izostavljen ili je auto, koristi se unapred podešena veličina 512x512.

Preporučuje se da prvo koristite `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. GIF ima nezavisna ograničenja veličine i broja frejmova, te se statičke 4K specifikacije ne mogu direktno primeniti; neki modeli će prilagoditi stvarnu izlaznu veličinu. `n` označava broj vraćenih GIF datoteka, a ne broj animacionih frejmova. Standardna verzija i `:reverse` se i dalje naplaćuju prema broju uspešno generisanih datoteka, dok se zvanična verzija naplaćuje prema stvarnoj upotrebi Tokena.

```json
{
  "model": "gpt-image-2.6-flare",
  "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
  "prompt": "Animate the mug gently moving left and right. Keep its appearance and the background, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### GPT Image 2.6 4K statične slike

Flare, Sunburst i njihove varijante `:reverse`, `:official` mogu koristiti prethodno navedene 4K unapred podešene pikselne vrednosti, kao što su `3840x2160` i `2160x3840`. I generisanje i uređivanje prenose konkretne piksele kroz `size`; `4K` nije važeća vrednost za `size`, a `4096x4096` takođe premašuje trenutno ograničenje piksela. Navedene 4K specifikacije važe za statične PNG/JPEG/WebP slike, dok GIF treba da koristi svoje namenske parametre.

### Složenost kompozicije GPT Image 2.6

`complexity` može biti `low`, `medium`, `high`, a kada je izostavljen koristi se podrazumevana vrednost modela `high`. On kontroliše složenost planiranja i nezavisan je od kvaliteta renderovanja `quality`; ne naplaćuje se dodatno po pozivu, a zvanična verzija se i dalje obračunava prema stvarnim Tokenima. Drugi modeli ne podržavaju ovaj parametar.

GIF ne podržava mask, sliku sa oznakama, prilagođenu kompresiju, prepisivanje prompta ili delimičan striming izlaza slike; nekompatibilne kombinacije će biti odbijene pre generisanja. Veličina, broj frejmova i količina zajedno podležu ograničenju budžeta piksela modela; za standardni Flare je potvrđeno da `1024x1024`, 2 frejma radi, ali se ovaj zaključak ne može proširiti na sve 1K kombinacije ili 4K GIF-ove.

### Uređivanje vođeno oznakama

Statičko uređivanje GPT Image 2.6 podržava `markup`. Otpremite transparentni PNG istih dimenzija kao prva referentna slika, na zasebnom sloju zaokružite mesto koje treba izmeniti i u `prompt` navedite zahteve za izmenu. Sloj sa oznakama mora sadržati transparentne piksele; obe slike ne smeju prelaziti 16777216 piksela, a slika sa oznakama ne sme prelaziti 40MB. JSON može proslediti HTTPS URL, PNG base64 data URL ili `{ "image_url": "https://..." }`; multipart otprema datoteku putem `markup`. Platforma će sloj sa oznakama proslediti u obliku datoteke. `markup` se ne može koristiti zajedno sa `mask`, GIF-om ili `prompt_rewriter`, a `file_id` nije podržan.

`input_fidelity` nije primenljiv na GPT Image 2.6, molimo izostavite ga.
