OpenAI Tasks API se koristi za upit rezultata zadataka koji su prethodno poslati OpenAI slikovnom interfejsu u **callback modu**. Kada ne možete da čekate sinhroni HTTP odgovor, ili želite da ponovo upitate zadatak kasnije, koristite ovaj interfejs.

U callback modu, **originalni slikovni interfejs odmah nakon obrade zahteva vraća `task_id`**. Vi direktno posedujete ovaj `task_id`, i kada vam zatreba, možete ga koristiti za upit na ovom interfejsu, bez potrebe za dodatnim prosleđivanjem prilagođenog `trace_id` (samo kada želite da povežete sa sopstvenim poslovnim identifikatorom).

> Samo kada originalni slikovni zahtev sadrži `callback_url`, zadatak će biti trajno sačuvan. Zahtevi pozvani sinhrono (ne u callback modu) neće biti sačuvani.

## Proces prijave

OpenAI Tasks API deli autorizaciju sa postojećim OpenAI uslugama. Ako ste već zatražili OpenAI generacije slika, možete direktno koristiti isti token za pozivanje ovog interfejsa, bez dodatne prijave.

Novi korisnici imaju besplatni limit prilikom prve prijave.

## Adresa interfejsa

```
POST https://api.acedata.cloud/openai/tasks
```

Podržane `action`:

| Operacija         | Opis                                                         |
| ---------------- | ---------------------------------------------------------- |
| `retrieve`       | Upit za jedan zadatak putem `id` ili `trace_id`                                |
| `retrieve_batch` | Masovni upit putem `ids` / `trace_ids` / `application_id` / `user_id` |

## Zahtevni headeri

- `accept: application/json`
- `authorization: Bearer {token}`
- `content-type: application/json`

## Upit za jedan zadatak (`retrieve`)

### Telo zahteva

| Polje         | Tip     | Obavezno  | Opis                                  |
| ---------- | ------ | --- | ----------------------------------- |
| `action`   | string | Da   | Fiksno postavljeno na `retrieve`                      |
| `id`       | string | Opcionalno | ID zadatka koji se vraća u sinhronom odgovoru prilikom slanja slikovnog zahteva (preporučuje se korišćenje)          |
| `trace_id` | string | Opcionalno | Samo kada ste u originalnom zahtevu eksplicitno prosledili prilagođeni `trace_id` |

`id` i `trace_id` treba proslediti bar jedan. Uobičajeno je koristiti `id` iz odgovora prilikom slanja, dok se `trace_id` prosleđuje samo kada želite da povežete sa prilagođenim poslovnim identifikatorom.

### Primer koda

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/openai/tasks' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "action": "retrieve",
    "id": "7489df4c-ef03-4de0-b598-e9a590793434"
  }'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/openai/tasks"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "action": "retrieve",
    "id": "7489df4c-ef03-4de0-b598-e9a590793434",
}
response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

### Objašnjenje polja

- `id`: ID zadatka generisan prilikom obrade originalnog slikovnog zahteva.
- `trace_id`: Prilagođeni identifikator za praćenje prosleđen u originalnom zahtevu, olakšava povezivanje sa poslovanjem klijenta.
- `type`: Tip zadatka. Zadaci napisani u `gpt-image` seriji (kao što je `gpt-image-2`) su `images`; `gpt-image-1`, nano-banana itd. koriste `images_generations` / `images_edits`, dok su neki chat interfejsi `chat_completions_image`.
- `request`: Puno telo originalnog zahteva.
- `response`: Konačno telo odgovora vraćeno kada je callback završen.
- `created_at` / `started_at` / `finished_at`: Unix vremenski pečat (sekunde, decimalni).
- `elapsed`: Vreme izvršenja (sekunde, decimalni).
- `application_id` / `user_id` / `credential_id`: ID aplikacije, krajnjeg korisnika, i ID kredencijala.

## Masovni upit (`retrieve_batch`)

### Telo zahteva

| Polje               | Tip       | Opis                                                       |
| ---------------- | -------- | -------------------------------------------------------- |
| `action`         | string   | Fiksno postavljeno na `retrieve_batch`                                     |
| `ids`            | string[] | Upit po listi ID zadataka                                              |
| `trace_ids`      | string[] | Upit po listi `trace_id`                                        |
| `application_id` | string   | Upit za sve zadatke po aplikaciji                                                |
| `user_id`        | string   | Upit za sve zadatke po krajnjem korisniku                                              |
| `type`           | string   | Filtriranje po tipu zadatka (moguće vrednosti: `images`, `images_generations`, `images_edits`) |
| `offset`         | int      | Početna tačka za paginaciju, podrazumevano `0`                                              |
| `limit`          | int      | Broj stavki po strani, podrazumevano `12`                                             |
| `created_at_min` | float    | Početni vremenski pečat (Unix sekunde)                                            |
| `created_at_max` | float    | Krajnji vremenski pečat (Unix sekunde)                                            |

`ids` / `trace_ids` / `application_id` / `user_id` ili `created_at_*` vremenski prozori mogu se proslediti jedan od njih.

## End-to-end primer: podnošenje i praćenje

Tasks API uglavnom služi za asinkrone procese u režimu povratnog poziva. U režimu povratnog poziva, interfejs za podnošenje će **odmah sinhrono vratiti `task_id`** (tj. ID zadatka), nakon čega jednostavno uzmite ovaj `task_id` da biste pratili Tasks interfejs, bez potrebe da sami generišete `trace_id`.

```python
import os, time, requests

API = "https://api.acedata.cloud"
HEADERS = {
    "authorization": f"Bearer {os.environ['ACEDATA_API_KEY']}",
    "content-type": "application/json",
}

# 1. Podnošenje zadatka za generisanje slika (režim povratnog poziva: dodajte callback_url da biste odmah dobili task_id)
submit = requests.post(
    f"{API}/openai/images/generations",
    headers=HEADERS,
    json={
        "model": "gpt-image-1",
        "prompt": "Mačka u akvarel stilu sedi na stolu",
        "callback_url": "https://webhook.site/your-uuid",
    },
).json()
print("podnet:", submit)

task_id = submit["task_id"]

# 2. Direktno koristite task_id iz odgovora na podnošenje da biste pratili Tasks interfejs, dok zadatak ne bude završen
while True:
    task = requests.post(
        f"{API}/openai/tasks",
        headers=HEADERS,
        json={"action": "retrieve", "id": task_id},
    ).json()
    if task and task.get("response"):
        print("završeno:", task["response"])
        break
    time.sleep(3)
```

## Napomene

- Tasks interfejs sam po sebi **ne naplaćuje** troškove, možete slobodno pratiti. Samo originalni zahtevi za generisanje/uređivanje slika će se naplatiti.
- Samo kada originalni zahtev sadrži `callback_url`, biće upisani u evidenciju zadataka; sinhroni pozivi neće generisati zadatke koji se mogu pretraživati.
- Zapisnici zadataka koji su premašili period zadržavanja platforme mogu biti obrisani.
