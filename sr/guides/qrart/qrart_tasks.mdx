Glavna funkcija Artistic QR Tasks API je da omogućava proveru statusa izvršenja zadatka putem ID-a zadatka generisanog putem Artistic QR Generation API.

Ovaj dokument će detaljno opisati uputstva za integraciju Artistic QR Tasks API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Artistic QR Tasks API, možete lako proveriti status izvršenja zadatka iz Artistic QR Generation API.

## Proces prijave

Da biste koristili Artistic QR Tasks API, prvo treba da odete na stranicu za prijavu [Artistic QR Generation API](https://platform.acedata.cloud/documents/ee085d2a-a0b9-4f0e-8b4d-8da407345138) i zatražite odgovarajuću uslugu, a zatim kopirajte ID zadatka iz Artistic QR Generation API, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/2wicjy.png" width="500" class="m-auto"></p>

Na kraju, idite na stranicu Artistic QR Tasks API [Artistic QR Tasks API](https://platform.acedata.cloud/documents/21de9d76-6e39-4ac3-b8b9-20e7194c02b4) da zatražite odgovarajuću uslugu, a nakon ulaska na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![Stranica za prijavu](https://cdn.acedata.cloud/rci31i.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na [stranicu za prijavu](https://platform.acedata.cloud) koja vas poziva da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Primer zahteva

Artistic QR Tasks API može se koristiti za proveru rezultata jednog API-ja iz Artistic QR Generation API. O tome kako koristiti Artistic QR Generation API, molimo vas da se obratite dokumentu [Artistic QR Generation API](https://platform.acedata.cloud/documents/ee085d2a-a0b9-4f0e-8b4d-8da407345138).

Uzmimo za primer jedan ID zadatka koji je vratio usluga Artistic QR Generation API i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: e2c65b20-a970-431e-99c1-76721e799df8, a zatim ćemo prikazati kako da ga prosledimo.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se šalje.
- `action`: način operacije na zadatku.

Postavite kao što je prikazano na slici ispod:

<p><img src="https://cdn.acedata.cloud/use825.png" width="500" class="m-auto"></p>

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na raznim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/jejwy6.png" width="500" class="m-auto"></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/qrart/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "e2c65b20-a970-431e-99c1-76721e799df8",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/qrart/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "e2c65b20-a970-431e-99c1-76721e799df8",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Greška u obradi

U slučaju da se prilikom pozivanja API-ja javi greška, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`：Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`：Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste limit brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.
