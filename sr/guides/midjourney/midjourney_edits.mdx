Овај документ ће представити упутство за интеграцију Midjourney Edits API, који омогућава уређивање унетих слика путем улазних упутстава.

## Процес пријаве

Да бисте користили API, прво морате да одете на [Midjourney Edits API](https://platform.acedata.cloud/documents/midjourney-edits) страницу и затражите одговарајућу услугу. Када уђете на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ако још нисте пријављени или регистровани, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите. Након пријаве или регистрације, аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну количину, коју можете користити без накнаде.

## Основна употреба

Прво, потребно је разумети основни начин коришћења, а то је унос упутства `prompt`, акције `action`, и референтне слике `image_url`, како бисте добили обрађени резултат. Прво је потребно једноставно проследити поље `action`, чија вредност је `generate`, а конкретан садржај је следећи:

<p><img src="https://cdn.acedata.cloud/m44i6n.png" width="500" class="m-auto"></p>

Можете видети да смо подесили Request Headers, укључујући:

- `accept`: каквог формата желите да примите одговор, овде је написано `application/json`, што значи JSON формат.
- `authorization`: кључ за позивање API, који можете директно изабрати након захтева.

Такође смо подесили Request Body, укључујући:

- `mask`: можете одредити позицију маске области слике за уређивање и поновно генерисање.
- `split_images`: дели генерисану слику на више слика, враћајући их преко sub_image_urls поља. По подразумеваној вредности, false.
- `action`: акција уређивања слике, подразумевано је `generate`.
- `image_url`: линк до слике која се уређује.
- `prompt`: упутство.
- `mode`: режим генерисања, опционално `fast`/`relax`/`turbo`.
- `callback_url`: URL на који треба да се врати резултат.

Након избора, можете приметити да је на десној страни генерисан одговарајући код, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/9wed3b.png" width="500" class="m-auto"></p>

Кликните на дугме „Try“ да бисте извршили тест, као што је приказано на горњој слици, и добићете следећи резултат:

```json
{
  "sub_image_urls": [
    "https://cdn.midjourney.com/88e16dab-ef48-43a5-af73-bf24065287bc/0_0.png",
    "https://cdn.midjourney.com/88e16dab-ef48-43a5-af73-bf24065287bc/0_1.png",
    "https://cdn.midjourney.com/88e16dab-ef48-43a5-af73-bf24065287bc/0_2.png",
    "https://cdn.midjourney.com/88e16dab-ef48-43a5-af73-bf24065287bc/0_3.png"
  ],
  "image_url": "https://storage.fonedis.cc/attachments/1372468820912115716/1391371957878132849/cat_sitting_table_88e16dab-ef48-43a5-af73-bf24065287bc.png?ex=686ba79d&is=686a561d&hm=ad005d06f6673d6152456e04c3cbec39d062bd9df10448623fae27ddaf8b8a80&",
  "image_width": 960,
  "image_height": 1200,
  "raw_image_url": "https://storage.fonedis.cc/attachments/1372468820912115716/1391371957878132849/cat_sitting_table_88e16dab-ef48-43a5-af73-bf24065287bc.png?ex=686ba79d&is=686a561d&hm=ad005d06f6673d6152456e04c3cbec39d062bd9df10448623fae27ddaf8b8a80&",
  "raw_image_width": 960,
  "raw_image_height": 1200,
  "progress": 100,
  "image_id": "1391372193836826624",
  "task_id": "26c39859-f54a-4998-9e42-3da96eceee8c",
  "success": true
}
```

Враћени резултат има више поља, а описују се као:

- `success`, статус тренутне слике уређивања.
- `task_id`, ID тренутне слике уређивања.
- `image_id`, ID слике у овој уређивачкој акцији.
- `sub_image_urls`, више резултата слике из уређивачке акције.
- `image_url`, линк до генерисане слике.
- `image_width`, ширина генерисане слике.
- `image_height`, висина генерисане слике.
- `progress`, напредак тренутне слике уређивања.

Можете видети да смо добили задовољавајуће информације о слици, и све што треба да урадимо је да добијемо генерисану слику преко линка `image_url`.

Ако желите да генеришете одговарајући код за интеграцију, можете га директно копирати, на пример, CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/midjourney/edits' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cat sitting on a table",
  "split_images": true,
  "image_url": "https://cdn.acedata.cloud/jgo1cw.jpg",
  "action": "generate"
}'
```

## Асинхроно повратно обавештење

Пошто време генерисања Midjourney Edits API може бити релативно дуго, око 1-2 минута, ако API дуго не одговара, HTTP захтев ће задржати везу, што може довести до додатне потрошње системских ресурса. Због тога овај API такође пружа подршку за асинхроно повратно обавештење.

Целокупни процес је: када клијент покрене захтев, додатно одређује поље `callback_url`. Након што клијент покрене API захтев, API ће одмах вратити резултат, који садржи поље `task_id`, што представља ID тренутног задатка. Када задатак буде завршен, резултат генерисања видеа ће бити послат на клијентом одређени `callback_url` у POST JSON формату, који такође укључује поље `task_id`, тако да се резултати задатка могу повезати преко ID.

Хајде да погледамо пример како то функционише.

Прво, Webhook повратно обавештење је услуга која може примати HTTP захтеве, а програмери би требало да замените URL сопственог HTTP сервера. Овде, ради лакшег демонстрирања, користићемо јавни Webhook пример са веб странице https://webhook.site/, отворите ту страницу да бисте добили Webhook URL, као што је приказано на слици:

![](https://cdn.acedata.cloud/hfrbzw.png)

Копирајте овај URL и можете га користити као Webhook, а пример овде је `https://webhook.site/556e6971-b41f-4fa8-9151-6e91acd0399f`.

Након тога, можемо подесити поље `callback_url` на горњи Webhook URL, а затим унети одговарајуће параметре, конкретан садржај је као на слици:

<p><img src="https://cdn.acedata.cloud/q3fnhv.png" width="500" class="m-auto"></p>

Кликните на „Run“, и одмах ћете добити резултат, као што је следеће:

```

  "task_id": "b8b7fdc2-628e-40dd-bc0c-671c3ddac9e9"
}
```

Након кратког чекања, можете наћи резултат генерисања видеа на `https://webhook.site/556e6971-b41f-4fa8-9151-6e91acd0399f`, као што је приказано на слици:

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, neispravan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### Primer odgovora na grešku

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
