Glavna funkcija Midjourney Tasks API je da omogućava upit o statusu izvršenja zadatka putem ID-a zadatka generisanog putem Midjourney Imagine API ili Midjourney Describe API.

Ovaj dokument će detaljno opisati integraciju Midjourney Tasks API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Midjourney Tasks API, možete lako ostvariti upit o statusu izvršenja zadatka iz Midjourney Imagine API ili Midjourney Describe API.

## Proces prijave

Da biste koristili Midjourney Tasks API, prvo treba da odete na stranicu za prijavu [Midjourney Imagine API](https://platform.acedata.cloud/documents/e52c028d-897a-4d51-b110-60fccbe6118d) i zatražite odgovarajuću uslugu, a zatim kopirajte ID zadatka iz Imagine API, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/lx4mwb.png" width="500" class="m-auto"></p>

Na kraju, idite na stranicu Tasks API [Midjourney Tasks API](https://platform.acedata.cloud/documents/58ea7cc1-c685-40c3-a619-f29f9ac5d8f4) da zatražite odgovarajuću uslugu, a nakon ulaska na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![Stranica za prijavu](https://cdn.acedata.cloud/rci31i.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na [stranicu za prijavu](https://platform.acedata.cloud) koja vas poziva da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Primer zahteva

Midjourney Tasks API može se koristiti za upit o rezultatima Midjourney Imagine API i Midjourney Describe API. O tome kako koristiti Midjourney Imagine API, molimo vas da se obratite dokumentu [Midjourney Imagine API](https://platform.acedata.cloud/documents/b0e32002-2707-41cc-b103-a15b1f1efdc1). O tome kako koristiti Midjourney Describe, molimo vas da se obratite [Midjourney Describe API](https://platform.acedata.cloud/documents/d2a04242-507c-4a49-a17a-01bc382c5756).

Uzmimo za primer jedan ID zadatka koji je vraćen od strane Midjourney Imagine API, i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: 7489df4c-ef03-4de0-b598-e9a590793434, a zatim ćemo prikazati kako da ga prosledimo.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se prihvata odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete ga direktno izabrati.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se šalje.
- `ids`: niz ID-ova zadataka za masovno pretraživanje.
- `action`: način operacije na zadatku, podržava `retrieve` (jedan upit) i `retrieve_batch` (masovno).

Postavite kao što je prikazano na slici:

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na raznim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/46ookb.png" width="500" class="m-auto"></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/midjourney/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "7489df4c-ef03-4de0-b598-e9a590793434",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/midjourney/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "7489df4c-ef03-4de0-b598-e9a590793434",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili neispravnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili neispravnih parametara.
- `401 invalid_token`: Neautorizovano, neispravan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
