Овај документ ће представити упутство за интеграцију Midjourney Videos API, који може генерисати званичне видео записе Midjourney уношењем прилагођених параметара.

## Процес пријаве

Да бисте користили API, прво морате да одете на [Midjourney Videos API](https://platform.acedata.cloud/documents/midjourney-videos) одговарајућу страницу и затражите услугу. Када уђете на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите. Након пријаве или регистрације, аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, коју можете користити за API.

## Основна употреба

Прво, потребно је разумети основни начин коришћења, а то је уношење кључне речи `prompt`, акције `action`, и низа референтних слика за прву и последњу слику `image_url`, како бисте добили обрађени резултат. Прво је потребно једноставно проследити поље `action`, чија вредност је `generate`. Ово углавном укључује две акције: генерисање видеа (`generate`), проширење видеа (`extend`), а конкретан садржај је следећи:

<p><img src="https://cdn.acedata.cloud/pi72m9.png" width="500" className="m-auto" /></p>

Можете видети да смо подесили Request Headers, укључујући:

- `accept`: каквог формата желите да примите одговор, овде је написано `application/json`, што значи JSON формат.
- `authorization`: кључ за позивање API, који можете директно изабрати након захтева.

Такође смо подесили Request Body, укључујући:

- `image_url`: линк на референтну слику за прву слику видеа.
- `end_image_url`: опционално, одређује референтну слику за последњу слику видеа.
- `video_id`: потребно је одредити ID видеа при проширењу видеа.
- `video_index`: потребно је одредити конкретан видео из `video_id`, индекс почиње од 0, подразумевано је 0.
- `action`: акција генерисања видеа, углавном укључује две акције: генерисање видеа (`generate`), проширење видеа (`extend`).
- `prompt`: кључна реч.
- `mode`: режим брзине генерисања видеа, подразумевано fast.
- `resolution`: резолуција видеа, подразумевано 720p.
- `loop`: да ли да генерише видео у петљи, подразумевано false.
- `callback_url`: URL на који треба да се врати резултат.

Након избора, можете приметити да је на десној страни генерисан одговарајући код, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/y0cw0p.png" width="500" className="m-auto" /></p>

Кликните на дугме „Try“ да бисте тестирали, као што је приказано на горњој слици, и добићете следећи резултат:

```json

  "image_width": 560,
  "image_height": 688,
  "progress": 100,

  "video_urls": [
    "https://storage.fonedis.cc//video/1c67c36c-8177-4f19-ad72-1dc1567265a6/0_0.mp4",
    "https://storage.fonedis.cc//video/1c67c36c-8177-4f19-ad72-1dc1567265a6/0_1.mp4",
    "https://storage.fonedis.cc//video/1c67c36c-8177-4f19-ad72-1dc1567265a6/0_2.mp4",
    "https://storage.fonedis.cc//video/1c67c36c-8177-4f19-ad72-1dc1567265a6/0_3.mp4"
```

Враћени резултат има више поља, описаних као:

- `success`, статус тренутне акције генерисања видеа.
- `task_id`, ID тренутне акције генерисања видеа.
- `image_url`, слика насловне слике тренутне акције генерисања видеа.
- `image_width`, ширина насловне слике тренутне акције генерисања видеа.
- `image_height`, висина насловне слике тренутне акције генерисања видеа.
- `video_id`, ID видеа тренутне акције генерисања видеа.
- `video_urls`, низ линкова на видео записе тренутне акције генерисања видеа.

Можете видети да смо добили задовољавајуће информације о видеу, и само треба да добијемо генерисани Midjourney видео на основу адреса видео линкова из `video_urls`.

Ако желите да генеришете одговарајући код за интеграцију, можете га директно копирати, на пример, CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/midjourney/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "prompt": "A cat sitting on a table",
  "image_url": "https://cdn.acedata.cloud/jgo1cw.jpg"
}'
```

## Проширење функције видеа

Ако желите да наставите генерисање већ створеног Kling видеа, можете подесити параметар `action` на `extend` и унети ID видеа који желите да наставите. ID видеа можете добити на основу основне употребе.

Тада можете видети да је ID видеа из горњег текста:

```
"video_id": "1751816807896311"
```

> Напомена: Овде је `video_id` ID видеа након генерисања. Ако не знате како да генеришете видео, можете се позвати на основну употребу из горњег текста.

Следеће, морате попунити следећу акцију за проширење кључне речи за прилагођавање генерисања видеа, и можете одредити следеће садржаје:

- `video_index`: изаберите индекс видеа за проширење, тај индекс је из `video_urls` из горњег текста, индекс почиње од 0, подразумевана вредност је 0.
- `video_id`: ID видеа који се одређује за проширење.
- `action`: акција проширења видеа, која је `extend`.
- `prompt`: кључна реч.

Пример попуњавања је следећи:

<p><img src="https://cdn.acedata.cloud/855hnj.png" width="500" className="m-auto" /></p>

Након попуњавања, аутоматски је генерисан код као што је приказано:

<p><img src="https://cdn.acedata.cloud/p58w39.png" width="500" className="m-auto" /></p>

Одговарајући Python код:

```python
import requests

url = "https://api.acedata.cloud/midjourney/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "prompt": "A cat sitting on a table",
    "video_id": "1751816807896311",
    "video_index": 1
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asinhroni povratni poziv

Zbog relativno dugog vremena generisanja Midjourney Videos API, koje traje oko 1-2 minuta, ako API dugo ne odgovara, HTTP zahtev će zadržati vezu, što dovodi do dodatne potrošnje sistemskih resursa, pa ovaj API takođe pruža podršku za asinhrone povratne pozive.

Celokupni proces je: kada klijent pokrene zahtev, dodatno se navodi polje `callback_url`, nakon što klijent pokrene API zahtev, API će odmah vratiti rezultat, koji sadrži informaciju o polju `task_id`, što predstavlja trenutni ID zadatka. Kada zadatak bude završen, rezultat generisanog videa biće poslat na `callback_url` koji je klijent odredio, putem POST JSON forme, a koji takođe uključuje polje `task_id`, tako da se rezultati zadatka mogu povezati putem ID-a.

U nastavku ćemo kroz primer razumeti kako konkretno postupiti.

Prvo, Webhook povratni poziv je usluga koja može primati HTTP zahteve, programeri bi trebali zameniti URL svoje HTTP servera. Ovde, radi lakšeg prikaza, koristi se javni Webhook uzorak sa sajta https://webhook.site/, otvaranjem tog sajta dobijate Webhook URL, kao što je prikazano na slici:

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### Primer odgovora greške
