Glavna funkcija Midjourney Shorten API-ja je povezivanje sa zvaničnom Midjourney `/shorten` (analiza prompta) komandom, koja analizira dati prompt, prepoznaje ključne reči sa najvišom težinom i generiše 5 sažetih predloga prompta. Ovaj interfejs je posebno pogodan za:

- Smanjivanje dužih promptova pre poziva `imagine` kako bi se povećala relevantnost generisanih slika;
- Razumevanje težine pojedinačnih tokena u Midjourney kroz predložene promptove, što olakšava inženjering promptova;
- Automatsku obradu promptova korisnika kroz objedinjavanje i sažimanje ključnih reči u automatizovanim tokovima rada.

Ovaj dokument detaljno opisuje kako se povezuje Midjourney Shorten API i pomaže vam da ga lako integrišete.

## Proces prijave

Da biste koristili Midjourney Shorten API, potrebno je da se prijavite na stranici [Midjourney Shorten API](https://platform.acedata.cloud/documents/f0c6be1d-c084-43ac-bde6-44ef9cf824a2). Nakon ulaska na stranicu, kliknite na dugme „Acquire“.

Ukoliko niste prijavljeni ili registrovani, bićete preusmereni na [stranicu za prijavu](https://platform.acedata.cloud) gde se možete registrovati i prijaviti. Nakon prijave, bićete automatski vraćeni na prethodnu stranicu.

Prilikom prve prijave dobijate besplatan kredit za korišćenje API-ja.

## Primer zahteva

Uzećemo primer dužeg prompta da pokažemo kako koristiti API za analizu i sažimanje.

### Podešavanje zaglavlja i tela zahteva

**Request Headers** uključuju:

- `accept`: definiše da se očekuje odgovor u JSON formatu, ovde se postavlja na `application/json`.
- `authorization`: API ključ za pozivanje, koji se može izabrati nakon prijave.

**Request Body** uključuje:

- `prompt`: tekst prompta koji se analizira i sažima, preporučuje se unos na engleskom jeziku.

### Primer koda

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/midjourney/shorten' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "a serene mountain lake at sunrise, mist rising from the water, towering pine trees on the shore, golden hour lighting, ultra detailed, cinematic, 35mm film photography style, masterpiece --ar 16:9 --v 6"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/midjourney/shorten"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "prompt": (
        "a serene mountain lake at sunrise, mist rising from the water, "
        "towering pine trees on the shore, golden hour lighting, ultra "
        "detailed, cinematic, 35mm film photography style, masterpiece "
        "--ar 16:9 --v 6"
    )
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

### Primer odgovora

Nakon uspešnog zahteva, API vraća do 5 sažetih predloga prompta. Na primer:

```json
{
  "prompts": [
    "a serene mountain lake at sunrise, mist rising from the water, golden hour lighting --ar 16:9",
    "mountain lake sunrise with mist, golden light --ar 16:9 --v 6",
    "tranquil alpine lake, dawn mist, warm golden tones, cinematic --ar 16:9",
    "sunrise over a misty mountain lake, rich golden hour photography --ar 16:9 --style raw",
    "misty lake at dawn, mountains in background, golden sunrise --ar 16:9"
  ]
}
```

Vidimo da je u rezultatu polje `prompts` koje sadrži nekoliko sažetih predloga prompta, od kojih svaki zadržava ključne reči sa najvišom težinom iz Midjourney sistema, dok su uklonjeni duplikati i suvišni opisi.

## Rukovanje greškama

U slučaju greške prilikom poziva API-ja, vraća se odgovarajući kod i poruka o grešci. Na primer:

- `400 token_mismatched`: Loš zahtev, moguće zbog nedostajućih ili neispravnih parametara.
- `400 api_not_implemented`: Loš zahtev, moguće zbog nedostajućih ili neispravnih parametara.
- `401 invalid_token`: Neautorizovano, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, prekoračen je limit učestalosti.
- `500 api_error`: Interna greška servera.

### Primer odgovora sa greškom

```
}
```
