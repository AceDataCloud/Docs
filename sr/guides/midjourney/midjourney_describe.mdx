Glavna funkcija Midjourney Describe API-ja je da, putem otpremanja slika, dobije opis slika. Da biste koristili ovaj API, potrebno je samo da prosledite adresu datoteke slike, a API će vratiti detaljan opis slike. Nema potrebe za složenim podešavanjima parametara, već možete dobiti visokokvalitetan opis slike.

Podržava više formata slika: bez obzira da li su u JPEG, PNG ili GIF formatu, svi popularni formati se lako prepoznaju i obrađuju.

Ovaj dokument će detaljno opisati integraciju Midjourney Describe API-ja, pomažući vam da lako integrišete i u potpunosti iskoristite moćne funkcije ovog API-ja. Kroz Midjourney Describe API, možete lako automatizovati opisivanje slika i povećati poslovnu efikasnost.

## Proces prijave

Da biste koristili Midjourney Describe API, prvo idite na stranicu za prijavu [Midjourney Describe API](https://platform.acedata.cloud/documents/870e973b-712a-4686-ab8b-beae27f129ce) i zatražite odgovarajuću uslugu. Kada uđete na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![Stranica za prijavu](https://cdn.acedata.cloud/rci31i.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na [stranicu za prijavu](https://platform.acedata.cloud) koja vas poziva da se registrujete i prijavite. Nakon prijave ili registracije, automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Primer zahteva

Uzmimo sliku kao primer i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo sliku pejzaža, a zatim ćemo prikazati kako otpremiti tu sliku i dobiti opis.

### Primer slike zahteva

![Primer slike](https://cdn.acedata.cloud/kg7xp3.png)

### Podešavanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se prihvata odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete direktno izabrati.

**Telo zahteva** uključuje:

- `image_url`: adresa datoteke slike koja se otprema.

Podešavanje je prikazano na sledećoj slici:

![](https://cdn.acedata.cloud/eeui10.png)

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na različitim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/8edj9z.png" width="400" class="m-auto"></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/midjourney/describe' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/kg7xp3.png"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/midjourney/describe"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/kg7xp3.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
