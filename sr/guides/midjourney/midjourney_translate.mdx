Главна функција Midjourney Translate API је да добијете енглеске описне речи на основу унетих кинеских описних речи.

Овај документ ће детаљно описати упутство за интеграцију Midjourney Translate API, помажући вам да лако интегришете и у потпуности искористите моћне функције овог API. Користећи Midjourney Translate API, можете лако претворити кинеске описне речи у енглеске описне речи.

## Процес пријаве

Да бисте користили Midjourney Translate API, прво морате да одете на страницу за пријаву [Midjourney Translate API](https://platform.acedata.cloud/documents/e067d19b-7a66-4458-a45f-0fe88c1d5d34) и затражите одговарајућу услугу. Након што уђете на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![Страница за пријаву](https://cdn.acedata.cloud/rci31i.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на [страницу за пријаву](https://platform.acedata.cloud) која вас позива да се региструјете и пријавите. Након пријаве или регистрације, аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, коју можете користити за бесплатну употребу овог API.

## Пример захтева

Узмимо кинеску описну реч као пример и демонстрирамо како да користите овај API. Хајде да претпоставимо да је кинеска описна реч: 精致，无暇，洁白的天使, а затим ћемо демонстрирати како да отпремите кинеске описне речи и добијете енглеске описне речи.

### Подешавање заглавља захтева и тела захтева

**Request Headers** укључује:

- `accept`: одређује да ли се примају резултати у JSON формату, овде се попуњава као `application/json`.
- `authorization`: кључ за позивање API, који можете директно изабрати након пријаве.

**Request Body** укључује:

- `content`: отпремљене кинеске описне речи.

> Само овај један параметар је довољан за завршетак превода, молимо вас да осигурите да `content` користи кинеске описне речи.

### Пример кода

Можете приметити да су на десној страни странице аутоматски генерисани различити кодови на различитим језицима, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/oj1cck.png" width="500" class="m-auto"></p>

Неколико примера кода је испод:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/midjourney/translate' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "content": "精致，无暇，洁白的天使"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/midjourney/translate"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": "精致，无暇，洁白的天使"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Пример одговора

Након успешног захтева, API ће вратити 1 описну информацију преведену из кинеских описних речи. На пример:

```json
{
  "content": "Exquisite, flawless, pure white angel"
}
```

Можете видети да у резултату постоји поље `content`, које садржи преведене енглеске описне речи, што је превод одговарајућих кинеских описних речи.

- `content`, генерише одговарајуће енглеске описне речи, које се могу користити за описне речи у задацима генерисања слика.

## Обрада грешака

Када позивате API, ако наиђете на грешку, API ће вратити одговарајући код грешке и информације. На пример:

- `400 token_mismatched`: Лош захтев, могуће због недостајућих или неважећих параметара.
- `400 api_not_implemented`: Лош захтев, могуће због недостајућих или неважећих параметара.
- `401 invalid_token`: Неправилно, неважећи или недостајући ауторизациони токен.
- `429 too_many_requests`: Превише захтева, прелазите лимит.
- `500 api_error`: Унутрашња грешка сервера, нешто није у реду на серверу.
