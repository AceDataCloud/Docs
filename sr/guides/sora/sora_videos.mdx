Овај документ ће представити упутство за интеграцију Sora Videos Generation API, који може генерисати Sora званичне видео записе уношењем прилагођених параметара.

## Процес пријаве

Да бисте користили API, прво морате да одете на [Sora Videos Generation API](https://platform.acedata.cloud/documents/99a24421-2e22-4028-8201-e19cb834b67e) одговарајућу страницу и затражите одговарајућу услугу, након уласка на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, након пријаве или регистрације аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, коју можете користити за API.

## Основна употреба

Прво, упознајте се са основним начином коришћења, а то је уношење кључне речи `prompt`, низа референтних слика `image_urls` и модела `model`, чиме добијате обрађени резултат, конкретно садржај је следећи:

<p><img src="https://cdn.acedata.cloud/h8dyz3.png" width="500" className="m-auto" /></p>

Можете видети да смо овде подесили Request Headers, укључујући:

- `accept`: каквог формата желите да примите одговор, овде је написано `application/json`, што значи JSON формат.
- `authorization`: кључ за позивање API, након захтева можете директно изабрати из падајућег менија.

Такође смо подесили Request Body, укључујући:

- `model`: модел за генерисање видео записа, главни модели су `sora-2`, `sora-2-pro`, тренутно `sora-2` и `sora-2-pro` могу самостално да biraju параметре `size` и `duration`, при чему `sora-2-pro` подржава видео записе трајања 25с, док `sora-2` подржава само 10 и 15 секунди.
- `size`: резолуција видео генерисања, постоје `small` и `large`.
- `image_urls`: референтне слике које треба да се отпреме или низ Base64 кодираних слика.
- `duration`: трајање видео генерисања, постоје 10с, 15с, 25с, тренутно само `sora-2-pro` подржава 25с.
- `character_start`/`character_end`: почетна и крајња позиција лика у кадру (0-1), за контролу позиције главног објекта.
- `orientation`: оријентација кадра, подржава `landscape`, `portrait`, `square`.
- `prompt`: кључна реч.
- `callback_url`: URL на који треба да се пошаље резултат.

Ако желите да генеришете одговарајући код за интеграцију, можете га директно копирати, на пример, CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/sora/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "size": "large",
  "duration": 15,
  "orientation": "landscape",
  "prompt": "cat running on the river",
  "model": "sora-2"
}'
```

## Генерација видео записа из слике

Ако желите да генеришете видео запис из слике, прво параметар `image_urls` мора бити прослеђен референтним сликама, чиме можете одредити следећи садржај:

- image_urls: низ референтних слика које се користе за генерисање видео записа.

Пример попуњавања је следећи:

<p><img src="https://cdn.acedata.cloud/ch7x3t.png" width="500" className="m-auto" /></p>

Након попуњавања, аутоматски је генерисан код као што следи:

<p><img src="https://cdn.acedata.cloud/z1ud8l.png" width="500" className="m-auto" /></p>

Одговарајући код:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "large",
    "duration": 15,
    "orientation": "landscape",
    "prompt": "cat running on the river",
    "model": "sora-2",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Generisanje video zadatka sa likovima

Ako želite da generišete video zadatak sa likovima, prvo parametar `character_url` mora sadržati link do videa koji je potreban za kreiranje lika, imajte na umu da u videu ne sme biti pravih ljudi, inače će doći do greške, možete odrediti sledeće sadržaje:

- character_url: link do videa koji je potreban za kreiranje lika, imajte na umu da u videu ne sme biti pravih ljudi, inače će doći do greške.

Primer popunjavanja je sledeći:

<p><img src="https://cdn.acedata.cloud/2nhdr2.png" width="500" className="m-auto" /></p>

Nakon popunjavanja automatski je generisan kod kao što je prikazano ispod:

<p><img src="https://cdn.acedata.cloud/xp8scl.png" width="500" className="m-auto" /></p>

Odgovarajući kod:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "small",
    "duration": 10,
    "orientation": "landscape",
    "prompt": "mačka trči pored reke",
    "character_url": "https://cdn.acedata.cloud/pdidf5.mp4",
    "model": "sora-2",
    "character_end": 3,
    "character_start": 1
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asinhroni povratni poziv

Pošto vreme generisanja Sora Videos Generation API-a traje relativno dugo, otprilike 1-2 minuta, ako API dugo ne odgovara, HTTP zahtev će zadržati vezu, što dovodi do dodatne potrošnje sistemskih resursa, tako da ovaj API takođe pruža podršku za asinhrone povratne pozive.

Celokupni proces je: kada klijent pokrene zahtev, dodatno se navodi polje `callback_url`, nakon što klijent pokrene API zahtev, API će odmah vratiti rezultat, koji sadrži informaciju o polju `task_id`, što predstavlja trenutni ID zadatka. Kada zadatak bude završen, rezultat generisanog videa biće poslat POST JSON-om na klijentom određeni `callback_url`, koji takođe uključuje polje `task_id`, tako da se rezultati zadatka mogu povezati putem ID-a.

U nastavku ćemo kroz primer razumeti kako konkretno postupiti.

Prvo, Webhook povratni poziv je usluga koja može primati HTTP zahteve, programeri bi trebali zameniti URL svoje HTTP servera. Ovde, radi lakšeg prikazivanja, koristi se javni Webhook sajt https://webhook.site/, otvaranjem tog sajta dobijate Webhook URL, kao što je prikazano na slici:

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### Primer odgovora na grešku

```json

    "message": "fetch failed"
  },
