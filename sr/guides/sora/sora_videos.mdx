Ovaj dokument opisuje uputstvo za integraciju Sora Videos Generation API, putem kojeg je moguće generisati zvanične Sora video zapise unosom prilagođenih parametara. Ovaj API podržava dva režima rada:

- **Verzija 1 (klasični režim)**: podržava parametre `duration` (10/15/25 sekundi), `orientation` (horizontalni/vertikalni prikaz), `size` (small/large rezolucija), referentne slike `image_urls`, link ka liku `character_url` i druge.
- **Verzija 2 (partner režim)**: podržava parametre `seconds` (4/8/12 sekundi), rezoluciju u pikselima `size` (npr. 1280x720), referentne slike `input_reference` i druge.

## Proces prijave

Da biste koristili API, potrebno je da se prijavite na odgovarajuću stranicu [Sora Videos Generation API](https://platform.acedata.cloud/documents/99a24421-2e22-4028-8201-e19cb834b67e). Nakon ulaska na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ukoliko niste prijavljeni ili registrovani, bićete preusmereni na stranicu za prijavu gde možete da se registrujete i prijavite. Nakon prijave, automatski ćete biti vraćeni na prethodnu stranicu.

Prilikom prve prijave dobijate besplatni kredit za korišćenje API-ja.

## Osnovna upotreba (Verzija 1)

Prvo je potrebno razumeti osnovni način korišćenja Verzije 1, gde se unose parametri `prompt` (tekstualni opis), niz referentnih slika `image_urls` i model `model`, da bi se dobio rezultat. Detalji su sledeći:

<p><img src="https://cdn.acedata.cloud/h8dyz3.png" width="500" className="m-auto" /></p>

Ovde su podešeni Request Headers, uključujući:

- `accept`: format odgovora koji želite da primite, ovde je `application/json` (JSON format).
- `authorization`: API ključ za pozivanje API-ja, koji se može izabrati nakon prijave.

Takođe, podešen je Request Body koji uključuje:

- `model`: model za generisanje videa, podržani su `sora-2` (standardni režim) i `sora-2-pro` (HD režim). `sora-2-pro` podržava video dužine do 25 sekundi, dok `sora-2` podržava samo 10 i 15 sekundi.
- `size`: rezolucija videa, `small` za standardnu, `large` za HD (samo Verzija 1).
- `duration`: trajanje videa, podržano 10, 15 i 25 sekundi, pri čemu 25 sekundi podržava samo `sora-2-pro` (samo Verzija 1).
- `orientation`: orijentacija kadra, `landscape` (horizontalno) ili `portrait` (vertikalno) (samo Verzija 1).
- `image_urls`: niz URL-ova referentnih slika za generisanje videa (samo Verzija 1).
- `character_url`: link ka liku, video ne sme sadržavati stvarne ljude (samo Verzija 1).
- `character_start`/`character_end`: vreme pojavljivanja lika u sekundama, interval 1-3 sekunde (samo Verzija 1).
- `prompt`: tekstualni opis (obavezno).
- `callback_url`: URL za asinhroni povratni poziv.
- `version`: verzija API-ja, `"1.0"` (podrazumevano) ili `"2.0"`.

```shell
curl -X POST 'https://api.acedata.cloud/sora/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "size": "large",
  "duration": 15,
  "orientation": "landscape",
  "prompt": "cat running on the river",
  "model": "sora-2"
}'
```

## Generisanje videa iz slika (Verzija 1)

Za zadatke generisanja videa iz slika, potrebno je proslediti parametar `image_urls` sa nizom URL-ova referentnih slika, sa sledećim napomenama:

- `image_urls`: niz URL-ova referentnih slika za generisanje videa. Ne smeju se koristiti slike stvarnih ljudi sa vidljivim licima, jer može doći do neuspeha zadatka.

Primer unosa:

<p><img src="https://cdn.acedata.cloud/ch7x3t.png" width="500" className="m-auto" /></p>

Automatski generisani kod:

<p><img src="https://cdn.acedata.cloud/z1ud8l.png" width="500" className="m-auto" /></p>

Primer koda:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "large",
    "duration": 15,
    "orientation": "landscape",
    "prompt": "cat running on the river",
    "model": "sora-2",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Generisanje videa sa likom (Verzija 1)

Za zadatke generisanja videa sa likom, potrebno je proslediti parametar `character_url` sa linkom ka video snimku koji se koristi za kreiranje lika. Važno je da u videu ne sme biti stvarnih ljudi, jer će u suprotnom zadatak biti neuspešan.

- `character_url`: link ka video snimku za kreiranje lika, bez stvarnih ljudi.

## Režim Verzija 2.0

Pored Verzije 1.0, API podržava i Verziju 2.0, koja se aktivira podešavanjem parametra `version` na `"2.0"`. Verzija 2.0 podržava kraće video zapise i preciznu kontrolu rezolucije u pikselima.

### Parametri Verzije 2.0

| Parametar       | Tip     | Obavezno | Opis                                            |
|-----------------|---------|----------|-------------------------------------------------|
| `version`       | string  | Da       | Postaviti na `"2.0"`                            |
| `prompt`        | string  | Da       | Tekstualni opis za generisanje videa           |
| `model`         | string  | Ne       | `sora-2` (podrazumevano) ili `sora-2-pro`      |
| `duration`      | integer | Ne       | Dužina videa: `4` (podrazumevano), `8`, `12` sekundi |
| `size`          | string  | Ne       | Rezolucija: `720x1280` (podrazumevano), `1280x720`, `1024x1792`, `1792x1024` |
| `image_urls`    | array   | Ne       | Niz URL-ova referentnih slika, koristi se samo prva slika, dimenzije moraju odgovarati `size` |
| `callback_url`  | string  | Ne       | URL za asinhroni povratni poziv                 |

### Osnovni primer

```shell
curl -X POST 'https://api.acedata.cloud/sora/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "version": "2.0",
  "prompt": "cat running on the river",
  "model": "sora-2",

```

### Korišćenje referentnih slika (Verzija 2.0)

U Verziji 2.0 moguće je koristiti parametar `image_urls` za unošenje referentnih slika koje će usmeriti generisanje videa (koristi se samo prva slika):

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "version": "2.0",
    "prompt": "a person walking through a beautiful garden",
    "model": "sora-2",
    "duration": 4,
    "size": "1280x720",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

> **Napomena**: Dimenzije referentne slike treba da budu iste kao i vrednost parametra `size`, na primer, ako je `size` `1280x720`, referentna slika treba da bude dimenzija 1280×720.

### Poređenje parametara Verzije 1.0 i 2.0

| Parametar       | Verzija 1.0           | Verzija 2.0                           |
|-----------------|-----------------------|-------------------------------------|
| `version`       | 1.0 (podrazumevano)   | 2.0                                 |
| `prompt`        | ✅                    | ✅                                  |
| `model`         | ✅ sora-2 / sora-2-pro | ✅ sora-2 / sora-2-pro               |
| `duration`      | ✅ 10/15/25 sekundi    | ✅ 4/8/12 sekundi                    |
| `orientation`   | ✅ landscape/portrait  | ❌                                  |
| `size`          | ✅ small/large         | ✅ 720x1280/1280x720/1024x1792/1792x1024 |
| `image_urls`    | ✅ više slika          | ✅ samo prva slika                   |
| `character_url` | ✅                     | ❌                                  |
| `callback_url`  | ✅                     | ✅                                  |

## Asinhroni povratni poziv (callback)

Pošto generisanje videa preko Sora Videos Generation API traje oko 1-2 minuta, a HTTP zahtev može dugo ostati otvoren što troši resurse, API podržava asinhroni povratni poziv.

Proces je sledeći: klijent prilikom slanja zahteva navodi dodatni parametar `callback_url`. API odmah vraća odgovor sa `task_id` koji predstavlja ID zadatka. Kada je zadatak završen, rezultat se šalje POST JSON zahtevom na navedeni `callback_url`, uključujući i `task_id` za povezivanje rezultata.

Webhook callback je HTTP servis koji može da prima zahteve. Za demonstraciju se koristi javni Webhook servis https://webhook.site/, gde se dobija jedinstveni URL, kao što je prikazano:

![](https://cdn.acedata.cloud/cjjfly.png)

## Obrada grešaka

U slučaju greške, API vraća odgovarajući kod i poruku o grešci, na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neautorizovan zahtev, nevažeći ili nedostajući token.
- `429 too_many_requests`: Previše zahteva, prekoračen limit.
- `500 api_error`: Interna greška servera.

### Primer odgovora sa greškom

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
