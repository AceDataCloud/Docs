Ovaj članak predstavlja integraciju i korišćenje MiniMax H3 API-ja za upite zadataka. Ovaj interfejs se koristi za upit, grupno izlistavanje ili brisanje asinhronih zadataka kreiranih putem [MiniMax H3 API-ja za generisanje videa](https://platform.acedata.cloud/documents/minimax-videos-integration).

## Postupak prijave

Da biste koristili MiniMax H3 API za upite zadataka, najpre idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications) da biste dobili svoj API Token, sačuvajte ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a nakon završetka ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, nije potrebno podnositi posebnu prijavu za svaku uslugu.** Prva prijava donosi besplatan kredit, koji možete koristiti za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [MiniMax H3 API za upite zadataka →](https://platform.acedata.cloud/documents/minimax-tasks-integration)

Prilikom upita zadatka treba koristiti isti Token kojim je taj zadatak kreiran. Preporučuje se da Token sačuvate kao promenljivu okruženja, nemojte ga upisivati u izvorni kod niti slati u repozitorijum verzija:

```bash
export ACEDATACLOUD_API_KEY="YOUR_API_KEY"
```

## Pregled interfejsa

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /minimax/tasks`
- **Način autentifikacije**：u HTTP Header-u se prenosi `authorization: Bearer {token}`
- **Zaglavlja zahteva**：
  - `accept: application/json`
  - `content-type: application/json`
- **Upit pojedinačnog zadatka**：`action=retrieve`, prosledite `id`
- **Grupni upit zadataka**：`action=retrieve_batch`, može se filtrirati prema ID-u zadatka, vremenskom opsegu i uslovima paginacije
- **Brisanje zadatka**：`action=delete`, prosledite `id`
- **Napomena o naplati**：upiti zadataka su besplatni i neće proizvesti ponovljenu naplatu

Nakon kreiranja videa, morate sačuvati `task_id`. Preporučuje se da upit izvršavate otprilike svakih 10 sekundi, sve dok zadatak ne uđe u konačno stanje.

## Parametri zahteva

| Parametar               | Tip       | Obavezno   | Primenjiva radnja                | Opis                                                   |
| ---------------- | -------- | ---- | ------------------- | ---------------------------------------------------- |
| `action`         | string   | Ne    | Sve                  | `retrieve`, `retrieve_batch` ili `delete`; podrazumevano je `retrieve` |
| `id`             | string   | Uslovno obavezno | `retrieve`, `delete` | ID pojedinačnog zadatka                                              |
| `ids`            | string[] | Ne    | `retrieve_batch`    | Vraća samo navedene ID-jeve zadataka; kada se izostavi, izlistava zadatke prema drugim uslovima                              |
| `limit`          | integer  | Ne    | `retrieve_batch`    | Najveći broj zadataka vraćenih ovim putem                                          |
| `offset`         | integer  | Ne    | `retrieve_batch`    | Broj zadataka koji se preskaču na listi rezultata, koristi se za paginaciju                                   |
| `created_at_min` | number   | Ne    | `retrieve_batch`    | Donja granica vremena kreiranja, Unix vremenska oznaka, u sekundama                                 |
| `created_at_max` | number   | Ne    | `retrieve_batch`    | Gornja granica vremena kreiranja, Unix vremenska oznaka, u sekundama                                 |

Namene tri radnje su sledeće:

| `action`         | Namena                 | Neophodni parametri                           | Struktura odgovora                                  |
| ---------------- | ------------------ | ------------------------------ | ------------------------------------- |
| `retrieve`       | Upit statusa i rezultata jednog zadatka       | `id`                           | `{ "task": {...} }`                   |
| `retrieve_batch` | Grupni upit prema ID-ju zadatka, vremenu i uslovima paginacije | Opcioni `ids`, vremenski opseg, `offset`, `limit` | `{ "items": [...], "total": number }` |
| `delete`         | Otkazivanje ili brisanje zapisa zadatka prema trenutnom statusu zadatka  | `id`                           | `{ "id": "...", "deleted": true }`    |

## Upit pojedinačnog zadatka

```bash
curl -X POST 'https://api.acedata.cloud/minimax/tasks' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "action": "retrieve",
    "id": "f5977217-ed2c-40da-adbe-93d08235618f"
  }'
```

U nastavku je odgovor jednog stvarno uspešnog zadatka:

## Status zadatka

| `status`    | Značenje         | Obrada klijenta                      |
| ----------- | ---------- | -------------------------- |
| `queued`    | Ušao je u red čekanja, čeka izvršavanje | Nastavite anketiranje                       |
| `running`   | Generisanje je u toku       | Nastavite anketiranje                       |
| `succeeded` | Generisanje je uspešno       | Pročitajte `task.content.url`, zaustavite anketiranje |
| `failed`    | Generisanje nije uspelo       | Pročitajte `task.error`, zaustavite anketiranje       |
| `cancelled` | Zadatak je otkazan      | Zaustavite anketiranje                       |

`succeeded`, `failed` i `cancelled` su sva konačna stanja. Nemojte nastaviti anketiranje nakon ulaska u konačno stanje.

## Polja odgovora `task`

| Polje                        | Tip      | Opis                              |
| ------------------------- | ------- | ------------------------------- |
| `id`                      | string  | ID zadatka                           |
| `model`                   | string  | Model koji zadatak koristi, trenutno `MiniMax-H3`        |
| `status`                  | string  | Trenutni status zadatka                          |
| `error.code`              | string  | Kod greške pri neuspehu, vraća se samo pri neuspehu                    |
| `error.message`           | string  | Razlog neuspeha, vraća se samo pri neuspehu                     |
| `created_at`              | integer | Vreme kreiranja, Unix vremenska oznaka, u sekundama              |
| `updated_at`              | integer | Vreme poslednjeg ažuriranja statusa, Unix vremenska oznaka, u sekundama        |
| `content.url`             | string  | Adresa videa nakon uspeha                        |
| `resolution`              | string  | Izlazna rezolucija, `768P` ili `2K`             |
| `duration`                | integer | Trajanje izlaznog videa, u sekundama                     |
| `usage.total_seconds`     | integer | Ukupna obračunska količina, jednaka zbiru sekundi ulaznog i izlaznog videa           |
| `usage.input_seconds`     | integer | Obračunska količina nastala unosom referentnog videa                   |
| `usage.output_seconds`    | integer | Obračunska količina nastala izlaznim videom                     |
| `usage.input_image_count` | integer | Broj ulaznih slika u statistici naplate                    |
| `ratio`                   | string  | Stvarni izlazni odnos širine i visine; kada se koristi `adaptive`, oslonite se na rezultat ovde |
| `task_type`               | string  | Za zadatak generisanja videa je `generation`            |
| `modality`                | string  | Za video zadatak je `video`                   |
## Kompletan primer Python anketiranja

Sledeći kod čita Token iz promenljive okruženja, a nakon kreiranja zadatka proverava ga svakih 10 sekundi:

```python
import os
import time

import requests

BASE_URL = "https://api.acedata.cloud"
HEADERS = {
    "Authorization": f"Bearer {os.environ['ACEDATACLOUD_API_KEY']}",
    "Content-Type": "application/json",
}

create_response = requests.post(
    f"{BASE_URL}/minimax/videos",
    headers=HEADERS,
    json={
        "model": "MiniMax-H3",
        "content": [
            {
                "type": "text",
                "text": "清晨的海边，一艘白色帆船驶过平静海面，镜头缓慢横移",
            }
        ],
        "resolution": "768P",
        "duration": 4,
        "ratio": "16:9",
    },
    timeout=30,
)
create_response.raise_for_status()
task_id = create_response.json()["task_id"]

while True:
    time.sleep(10)
    query_response = requests.post(
        f"{BASE_URL}/minimax/tasks",
        headers=HEADERS,
        json={"action": "retrieve", "id": task_id},
        timeout=30,
    )
    query_response.raise_for_status()
    task = query_response.json()["task"]
    print(f"task={task_id} status={task['status']}")

    if task["status"] == "succeeded":
        print(f"video_url={task['content']['url']}")
        break
    if task["status"] in ("failed", "cancelled"):
        raise RuntimeError(task.get("error") or task["status"])
```

U produkcionom okruženju treba postaviti ukupno vremensko ograničenje za anketiranje i koristiti eksponencijalno povlačenje za `429` i privremene `5xx`. Mrežno vremensko ograničenje nije isto što i neuspeh generisanja; možete nastaviti sa upitima koristeći isti `task_id`.

## Grupni upit

Navedite više ID-jeva zadataka:

```bash
curl -X POST 'https://api.acedata.cloud/minimax/tasks' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "action": "retrieve_batch",
    "ids": ["TASK_ID_1", "TASK_ID_2"],
    "offset": 0,
    "limit": 20
  }'
```

Navedite zadatke po stranicama prema vremenskom opsegu:

```json
{
  "action": "retrieve_batch",
  "created_at_min": 1786000000,
  "created_at_max": 1786200000,
  "offset": 0,
  "limit": 20
}
```

`items` u grupnom odgovoru koriste ista task polja kao upit jednog zadatka, a `total` je ukupan broj zadataka koji odgovaraju uslovima filtriranja:

```json
{
  "items": [
    {
      "id": "TASK_ID_1",
      "model": "MiniMax-H3",
      "status": "running",
      "resolution": "2K",
      "duration": 5,
      "ratio": "adaptive",
      "task_type": "generation",
      "modality": "video"
    }
  ],
  "total": 1
}
```

Prozor za upite zadataka obuhvata poslednjih 7 dana. `task_id` van tog prozora može vratiti nevažeći zadatak; poslovni sistem treba da sačuva ID prilikom kreiranja zadatka i da pravovremeno trajno sačuva URL rezultata nakon uspeha.

## Otkazivanje ili brisanje zadatka

```bash
curl -X POST 'https://api.acedata.cloud/minimax/tasks' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "action": "delete",
    "id": "YOUR_TASK_ID"
  }'
```

Radnja zavisi od trenutnog statusa zadatka:

| Trenutni status | Ponašanje |
| ----------- | ------------- |
| `queued`    | Otkazuje zadatak koji još nije započet |
| `succeeded` | Briše zapis zadatka |
| `failed`    | Briše zapis zadatka |
| `running`   | Brisanje ili otkazivanje nije dozvoljeno, vraća grešku |
| `cancelled` | Ponovljena radnja nije dozvoljena, vraća grešku |

Primer uspešnog brisanja:

```json
{
  "id": "YOUR_TASK_ID",
  "deleted": true
}
```

Brisanje zapisa zadatka ne poništava već izvršenu naplatu, niti može garantovati da će sačuvane kopije videa takođe biti obrisane.

## Odgovori o neuspehu i rešavanje problema

Neuspešni zadaci i dalje vraćaju task objekat sa HTTP 200, a razlog se navodi u `task.error`:

```json
{
  "task": {
    "id": "YOUR_TASK_ID",
    "model": "MiniMax-H3",
    "status": "failed",
    "error": {
      "code": "1026",
      "message": "video description contains sensitive content"
    },
    "task_type": "generation",
    "modality": "video"
  }
}
```

Kada sam interfejs vrati `400`, treba proveriti `action` i parametre uslova; `401` označava da je Token nevažeći, `429` označava da su upiti prečesti, a `500` označava da je usluga privremeno nedostupna. Neuspešno generisani zadaci se ne naplaćuju; uspešni zadaci beleže potrošnju prema konačnom `usage`.
