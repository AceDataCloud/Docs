Овај текст ће представити упутство за интеграцију Recaptcha3 протокола идентификације API, које омогућава корисницима да не морају да идентификују и кликну на Recaptcha3 CAPTCHA слике, већ само да поднесу Website Key како би се реализовала аутоматска декодирања у позадини и завршила верификација.

## Процес пријаве

Да бисте користили API, прво морате да одете на [Recaptcha3 протокол идентификације API](https://platform.acedata.cloud/documents/1083df69-f2f3-4c13-901e-e5336b0dbe3d) одговарајућу страницу и затражите одговарајућу услугу, након уласка на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, након пријаве и регистрације аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, можете бесплатно користити овај API.

## Основна употреба

Прво, упознајте се са основним начином коришћења, у поређењу са Recaptcha2, потребно је додатно проследити параметар `page_action`, овај параметар се мора добити из кода, URL мреже који се овде приказује је: `https://recaptcha-demo.appspot.com/recaptcha-v3-request-scores.php`, испод је приказан један од начина за добијање:

### Брзи метод:

Отворите f12, а затим у Element страници претражите `.execute(`, у области обележеној црвеним оквиром можемо видети параметар `action`, а такође и низ знакова који следи после execute, што је такође садржај који ће нам бити потребан, конкретно, као што је приказано на слици испод.

<p><img src="https://cdn.acedata.cloud/imwlto.png" width="500" class="m-auto"></p>

Затим је потребно унети URL веб странице на којој се обрађује CAPTCHA, како бисте добили обрађени резултат, прво је потребно једноставно проследити поље `website_url`, а на крају је потребно унети параметар `website_key`, овај садржај можете добити из горњег текста, такође је низ знакова који следи после execute. Сада можемо попунити одговарајуће садржаје на интерфејсу, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/1hw2uo.png" width="500" class="m-auto"></p>

Можете видети да смо овде подесили Request Headers, укључујући:

- `accept`: каквог формата желите да примите одговор, овде је написано `application/json`, тј. JSON формат.
- `authorization`: кључ за позивање API, након пријаве можете директно изабрати из падајућег менија.

Такође смо подесили Request Body, укључујући:

- `page_action`: потребно је добити из кода веб странице на којој се обрађује CAPTCHA.
- `website_url`: URL веб странице на којој се обрађује CAPTCHA.
- `website_key`: идентификатор веб кључа у Recaptcha3.

Možemo videti da smo dobili rezultat obrade Recaptcha3 verifikacije, koji možemo koristiti za POST ili GET simulaciju slanja ka ciljanom sajtu, jednokratna upotreba, važenje 120s, preporučuje se korišćenje u roku od 60s. U nastavku ćemo ukratko opisati jedan način kako da pošaljemo generisani token ka ciljanom sajtu:

Pozivamo Python kod koji odgovara verifikaciji tokena:

```python
import requests

url = "https://recaptcha-demo.appspot.c/recaptcha-v3-verify.php?action=examples/v3scores&token='{token}'"

r = requests.get(url)
if r.status_code == 200:
    return r.text
```

Tako možemo dobiti rezultat:

```json
{
  "success": true,
  "hostname": "recaptcha-demo.appspot.com",
  "challenge_ts": "2024-09-14T08:52:26Z",
  "apk_package_name": null,
  "score": 0.9,
  "action": "examples/v3scores",
  "error-codes": []
}
```

Možemo primetiti da `success` označava rezultat obrade verifikacije, što znači da smo uspešno prošli verifikaciju Recaptcha3.

Takođe, ako želite da generišete odgovarajući kod za integraciju, možete jednostavno kopirati generisani kod, na primer CURL kod je sledeći:
```shell
curl -X POST 'https://api.acedata.cloud/captcha/token/recaptcha3' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "website_url": "https://recaptcha-demo.appspot.com/recaptcha-v3-request-scores.php",
  "website_key": "6LdKlZEpAAAAAAOQjzC2v_d36tWxCl6dWsozdSy9",
  "page_action": "examples/v3scores"
}'
```

Python код за интеграцију изгледа овако:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/recaptcha3"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "website_url": "https://recaptcha-demo.appspot.com/recaptcha-v3-request-scores.php",
    "website_key": "6LdKlZEpAAAAAAOQjzC2v_d36tWxCl6dWsozdSy9",
    "page_action": "examples/v3scores"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, neispravan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
