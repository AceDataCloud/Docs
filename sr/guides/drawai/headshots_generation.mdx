Ovaj dokument će predstaviti uputstvo za integraciju AI izrade ličnih dokumenata API, koji omogućava izradu različitih stilova ličnih dokumenata putem unosa URL-a fotografije i odabranog šablona.

## Proces prijave

Da biste koristili API, prvo treba da odete na [AI izrada ličnih dokumenata API](https://platform.acedata.cloud/documents/bf7214a3-8447-4157-8a75-f5bb39d5ed1b) stranicu i zatražite odgovarajuću uslugu. Kada uđete na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ako niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite. Nakon prijave ili registracije, automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Osnovna upotreba

Prvo, potrebno je razumeti osnovni način korišćenja, što podrazumeva unos potrebne fotografije za obradu i odabranog AI šablona za lične dokumente, kako biste dobili obrađeni rezultat. Prvo je potrebno jednostavno proslediti polje `image_urls`, koje predstavlja niz linkova do fotografija koje treba obraditi, kao što je prikazano na slici:

<p><img src="https://cdn.zhishuyun.com/2024-11-03-d23744954ca4819503469f04f2268aa0.jpg" width="500" className="m-auto" /></p>

Zatim, potrebno je uneti i odabrani šablon. Ovaj dokument nudi osam popularnih šablona, a konkretni šabloni su navedeni u nastavku:

```json
{
   "male_portrait":  Muška slika
   "male_portrait2":  Muška slika (druga verzija)
   "kindergarten":  Slika za upis u vrtić
   "logo_tshirt": Slika sa logotipom na majici
   "wedding":  Slika za venčanje
   "business_photo":  Poslovna fotografija
   "bob_suit": Crno odelo sa bob frizurom
   "female_portrait":  Ženska slika
}
```

Nakon toga, možemo odrediti parametar brzine generisanja `mode`, koji se obično deli na dva tipa: spor `relax` i brz `fast`, a konkretni sadržaj je prikazan u nastavku:

<p><img src="https://cdn.acedata.cloud/73xbla.png" width="500" className="m-auto" /></p>

Možemo videti da smo ovde postavili Request Headers, uključujući:

- `accept`: format odgovora koji želite da primite, ovde je uneto `application/json`, što znači JSON format.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

Takođe, postavili smo Request Body, uključujući:

- `mode`: kanal za generisanje ličnih dokumenata, koji se uglavnom deli na fast (brzo) i relax (sporo). Kada koristite relax, toplo preporučujemo korišćenje parametra `callback_url`.
- `template`: stil šablona ličnih dokumenata.
- `image_urls`: linkovi do slika ličnih dokumenata koje treba otpremiti.
- `callback_url`: URL za povratne informacije.

Nakon izbora, možete primetiti da je sa desne strane generisan odgovarajući kod, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/yp49hc.png" width="500" className="m-auto" /></p>

Kliknite na dugme „Try“ da biste izvršili test, kao što je prikazano na gornjoj slici, i dobićemo sledeći rezultat:

```json
{
  "success": true,
  "task_id": "ae1e4948-dba1-4a6f-87af-67961b647428",
  "data": [
    {
      "id": "202411031951124776",
      "image_url": "https://platform.cdn.acedata.cloud/headshots/ae1e4948-dba1-4a6f-87af-67961b647428.png",
      "template": "Muška slika"
    },
    {
      "id": "202411031951128490",
      "image_url": "https://platform.cdn.acedata.cloud/headshots/ae1e4948-dba1-4a6f-87af-67961b647428.png",
      "template": "Muška slika"
    }
  ]
}
```

Vraćeni rezultat sadrži više polja, koja su objašnjena u nastavku:

- `success`, status trenutnog zadatka za generisanje ličnih dokumenata.
- `task_id`, ID trenutnog zadatka za generisanje ličnih dokumenata.
- `data`, lista rezultata trenutnog zadatka za generisanje ličnih dokumenata.
  - `id`, ID fotografije trenutnog zadatka za generisanje ličnih dokumenata.
  - `image_url`, link do slike trenutnog zadatka za generisanje ličnih dokumenata.
  - `template`, naziv šablona trenutnog zadatka za generisanje ličnih dokumenata.

Možemo primetiti da smo dobili zadovoljavajuće informacije o ličnim dokumentima na osnovu šablona i slike, a sve što treba da uradimo je da preuzmemo lični dokument putem linka iz `data` rezultata.

Takođe, ako želite da generišete odgovarajući kod za integraciju, možete ga direktno kopirati, na primer, CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/headshots/generate' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "mode": "fast",
  "template": "male_portrait",
  "image_urls": ["https://cdn.zhishuyun.com/2024-11-03-d23744954ca4819503469f04f2268aa0.jpg"]
}'
```

## Asinhroni povratni poziv

S obzirom na to da vreme generisanja AI ličnih dokumenata može biti relativno dugo, otprilike 1-2 minuta, ako API dugo ne odgovara, HTTP zahtev će zadržati vezu, što može dovesti do dodatne potrošnje sistemskih resursa. Stoga, ovaj API takođe pruža podršku za asinhroni povratni poziv.

Celokupni proces je: kada klijent pokrene zahtev, dodatno se navodi polje `callback_url`. Nakon što klijent pošalje API zahtev, API odmah vraća rezultat koji sadrži informaciju o `task_id`, koja predstavlja trenutni ID zadatka. Kada zadatak bude završen, rezultat generisanja ličnih dokumenata biće poslat putem POST JSON-a na klijentom navedeni `callback_url`, a takođe će uključivati i polje `task_id`, tako da se rezultati zadatka mogu povezati putem ID-a.

U nastavku ćemo kroz primer objasniti kako to konkretno funkcioniše.

Prvo, Webhook povratni poziv je usluga koja može primati HTTP zahteve, a programeri bi trebali zameniti URL svoje HTTP servera. Ovde, radi lakšeg prikazivanja, koristićemo javni Webhook sajt https://webhook.site/, otvaranjem ovog sajta dobićete Webhook URL, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/sb4p3v.png)

Kopirajte ovaj URL i možete ga koristiti kao Webhook, a primer ovde je `https://webhook.site/00f38b26-4289-4899-83d6-0cea7308850a`.

Nakon toga, možemo postaviti polje `callback_url` na navedeni Webhook URL, kao i uneti link do slike i šablon. Ovaj dokument preporučuje korišćenje asinhronog povratnog poziva kada je parametar `mode` postavljen na `relax`, a konkretni sadržaj je prikazan na slici:

<p><img src="https://cdn.acedata.cloud/opt326.png" width="500" className="m-auto" /></p>

Kliknite na pokretanje, i odmah ćete dobiti rezultat, kao što je prikazano:

```
{
  "task_id": "763b1450-8804-434f-acc7-d713be73a28f"
}
```

Nakon nekoliko trenutaka, možemo na `https://webhook.site/00f38b26-4289-4899-83d6-0cea7308850a` posmatrati rezultate generisanja, kao što je prikazano na slici:
![](https://cdn.acedata.cloud/ym6fw1.png)

Sadržaj je sledeći:

```json
{
    "success": true,
    "task_id": "763b1450-8804-434f-acc7-d713be73a28f",
    "data": [
        {
            "id": "202411032010131366",
            "image_url": "https://platform.cdn.acedata.cloud/headshots/763b1450-8804-434f-acc7-d713be73a28f.png",
            "template": "Muška slika"
        },
        {
            "id": "202411032010132420",
            "image_url": "https://platform.cdn.acedata.cloud/headshots/763b1450-8804-434f-acc7-d713be73a28f.png",
            "template": "Muška slika"
        }
    ]
}
```

Može se videti da u rezultatu postoji polje `task_id`, a druga polja su slična prethodnim, putem ovog polja se može ostvariti povezanost zadatka.

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### Primer odgovora greške

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "preuzimanje nije uspelo"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
