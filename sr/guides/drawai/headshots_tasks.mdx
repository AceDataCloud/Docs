AI ID fotografija Task API ima glavnu funkciju da omogućava praćenje statusa izvršenja zadatka putem unosa ID-a zadatka generisanog od strane AI ID fotografija API.

Ovaj dokument će detaljno opisati integraciju AI ID fotografija Task API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz AI ID fotografija Task API, možete lako ostvariti praćenje statusa izvršenja zadatka AI ID fotografija API.

## Proces prijave

Da biste koristili AI ID fotografija Task API, prvo treba da odete na stranicu za prijavu [AI ID fotografija API](https://platform.acedata.cloud/documents/bf7214a3-8447-4157-8a75-f5bb39d5ed1b) i zatražite odgovarajuću uslugu, a zatim kopirajte ID zadatka AI ID fotografija API, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/7ezmmn.png" width="500" class="m-auto"></p>

Na kraju, idite na stranicu Tasks API [AI ID fotografija Task API](https://platform.acedata.cloud/documents/3a23ee34-8689-406b-9042-7954224348ad) da zatražite odgovarajuću uslugu, a nakon ulaska na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![Stranica za prijavu](https://cdn.acedata.cloud/rci31i.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na [stranicu za prijavu](https://platform.acedata.cloud) koja vas poziva da se registrujete i prijavite, a nakon prijave bićete automatski vraćeni na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Primer zahteva

AI ID fotografija Task API može se koristiti za praćenje rezultata AI ID fotografija API. O tome kako koristiti AI ID fotografija API, molimo vas da se obratite dokumentu [AI ID fotografija API](https://platform.acedata.cloud/documents/d6ea75a4-836e-490a-aee5-7ca911a808fd).

Uzmimo jedan ID zadatka koji je vratio AI ID fotografija API kao primer i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: `16f96e95-d95c-46ef-b183-139b9bd1aebd`, a zatim ćemo prikazati kako da ga prosledimo.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se šalje.
- `action`: način operacije na zadatku.

Postavite kao što je prikazano na slici ispod:

<p><img src="https://cdn.acedata.cloud/ezsyyd.png" width="500" class="m-auto"></p>

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na raznim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/x99wu2.png" width="500" class="m-auto"></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/headshots/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "16f96e95-d95c-46ef-b183-139b9bd1aebd",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/headshots/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "16f96e95-d95c-46ef-b183-139b9bd1aebd",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Greška u obradi

U slučaju da dođe do greške prilikom pozivanja API-ja, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`：Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`：Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste limit brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.
