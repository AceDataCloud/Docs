Pošaljite zadatak putem `POST /kling/video-commerce`, a koristite postojeći `POST /kling/tasks` za proveru statusa zadatka na platformi.

## Unos

Otpremite jednu sliku osobe i navedite voice_id, ili koristite unapred podešeni avatar_id (ovo dvoje se međusobno isključuje; za unapred podešenu osobu nije moguće dodatno navesti voice_id). Obavezno je dostaviti speech_script od najviše 2000 znakova. Kada pružate informacije o proizvodu, potrebni su najmanje jedna ref_image i jedan goods_title; govorni sadržaj za proizvod ne podržava speech_rate. Običan govorni sadržaj za osobu podržava brzinu govora od 0.8, 1.0 ili 1.2 puta.

Sledeći je primer strukture zahteva, zamenite URL materijala pre poziva.

```json
{
  "contents": [
    {
      "type": "avatar_image",
      "url": "https://your-cdn.example/person.jpg"
    },
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    },
    {
      "type": "speech_script",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "voice_id": "male_calm_informative"
  },
  "async": true
}
```

## Rezultati i naplata

Sinhroni režim vraća rezultat generisanja; asinhroni režim prvo vraća `task_id`, a završeni rezultat sadrži video ili link slike u `data` i `usage` koji izračunava server. `callback_url` se koristi za obaveštenje o završetku; zahtev sa `watermark=true` istovremeno vraća verziju sa vodenim žigom.

Običan govorni sadržaj za osobu: 720p iznosi 1.4 Credits/sekundi, a 1080p iznosi 1.68 Credits/sekundi; govorni sadržaj za proizvod: 720p iznosi 1.96 Credits/sekundi, a 1080p iznosi 2.24 Credits/sekundi. Video se naplaćuje prema stvarno generisanom trajanju, a osnovna cena po sekundi pre generisanja ne predstavlja ukupnu cenu celog zadatka. Za neuspešne zadatke se ne naplaćuje naknada za generisanje.
