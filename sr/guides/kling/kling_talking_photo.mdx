---
title: "Kling API za fotografije koje govore (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Jednim klikom pretvorite **jednu fotografiju + jedan audio zapis** u „video koji govori“. Servis interno automatski završava dva koraka: prvo koristi image2video da pokrene fotografiju, zatim koristi lip-sync da uskladi pokrete usana prema zvuku. Potrebno je da pozovete samo **jednom**.

- **Adresa interfejsa**：`POST https://api.acedata.cloud/kling/talking-photo`
- **Naplata**：prema trajanju, 5 sekundi **16.45 Credits**、10 sekundi **30.45 Credits**(= objedinjena cena za image2video + lip-sync)

## Zaglavlja zahteva

| Polje              | Vrednost                   |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## Parametri zahteva

| Parametar             | Tip      | Obavezno  | Podrazumevano                  | Opis                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | Da   | —                   | Javni URL fotografije osobe, preporučuje se jasno lice sprijeda                    |
| `audio_url`    | string  | Da   | —                   | Javni URL audio zapisa koji pokreće video（.mp3/.wav/.m4a/.aac,≤5MB） |
| `prompt`       | string  | Ne   | —                   | Prompt za pokrete/izraze lica u fazi animiranja fotografije                      |
| `model`        | string  | Ne   | `kling-v2-1-master` | Kling model koji se koristi za animiranje fotografije                     |
| `duration`     | integer | Ne   | `5`                 | Trajanje videa（5 ili 10 sekundi）                        |
| `mode`         | string  | Ne   | `pro`               | Kvalitet animiranja（std/pro）                        |
| `callback_url` | string  | Ne   | —                   | Ako se prosledi ili je `async=true`, asinhrono vraća task_id        |
| `async`        | boolean | Ne   | `false`             | Asinhroni režim, koristi se uz anketiranje `/kling/tasks` ili povratni poziv          |

## Primer zahteva

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Primer odgovora

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Polje                 | Opis                        |
| ------------------ | ------------------------- |
| `video_url`        | Konačni video koji govori（već sačuvan na CDN-u ove platforme）      |
| `source_video_url` | Međuvideo animirane fotografije（image2video rezultat） |
| `video_id`         | Kling video ID                   |

## Napomene

- Za fotografiju se preporučuje jasno lice sprijeda, sa jednom osobom.
- Preporučuje se da trajanje audio zapisa ne prelazi trajanje videa（5 s/10 s）。
- Naplata se vrši pri uspehu; neuspešna validacija parametara（4xx）se ne naplaćuje。
- Generisanje traje oko 4–6 minuta（dva koraka）, preporučuje se korišćenje `async=true` + anketiranje `/kling/tasks`.
