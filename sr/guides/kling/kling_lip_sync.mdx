Нека један **постојећи 可灵 видео** (5 секунди или 10 секунди) „проговори” према аудио-запису или тексту — односно синхронизација усана (Lip Sync). У комбинацији са `image2video` из `/kling/videos` (да би се фотографија покренула), може се повезати у комплетан процес „**фотографија која говори / дигитални човек који говори**”.

> Овај интерфејс је једнократно практично паковање које пружа AceDataCloud, намењено уобичајеним сценаријима покретаним аудио-записом/текстом; он није пресликавање поља Kling-овог званичног вишекорачног интерфејса „препознавање лица → Advanced Lip Sync”. Молимо користите табелу параметара на овој страници као референцу.

- **Адреса интерфејса**：`POST https://api.acedata.cloud/kling/lip-sync`
- **Формат захтева**：`application/json`
- **Формат одговора**：`application/json`
- **Наплата**：сваки успешан позив **2.45 Credits**（фиксно）

## Заглавља захтева（Request Headers）

| Поље              | Вредност                   | Опис                                               |
| --------------- | ------------------- | ------------------------------------------------ |
| `authorization` | `Bearer ${API_KEY}` | Ваш API кључ，[адреса за добијање](https://platform.acedata.cloud) |
| `content-type`  | `application/json`  | Формат тела захтева                                            |
| `accept`        | `application/json`  | Формат одговора                                             |

## Параметри захтева（Request Body）

| Параметар               | Тип      | Обавезно  | Подразумевано      | Опис                                                                                                                       |
| ---------------- | ------- | --- | ------- | ------------------------------------------------------------------------------------------------------------------------ |
| `mode`           | string  | Да   | —       | Режим генерисања. Набрајање：`audio2video`（покретано аудио-записом）、`text2video`（покретано текстом）                                                                           |
| `video_id`       | string  | Једно од два | —       | ID видеа генерисаног помоћу 可灵 (на пример, `video_id` који враћа image2video из `/kling/videos`). **Подржани су само 5s/10s видеозаписи генерисани у последњих 30 дана**。`video_id` и `video_url` су једно од два и не могу се проследити истовремено |
| `video_url`      | string  | Једно од два | —       | Јавно доступна веза ка видеу. Ограничења：`.mp4`/`.mov`，≤100MB，трајање 2–10s，само 720p/1080p，дужина странице 720–1920px。Једно од два са `video_id`                                  |
| `audio_url`      | string  | Условно  | —       | URL за преузимање покретачког аудио-записа, обавезно када је `audio2video` + `audio_type=url`. Формати `.mp3`/`.wav`/`.m4a`/`.aac`，≤5MB                                     |
| `audio_type`     | string  | Не   | `url`   | Начин преноса аудио-записа. Набрајање：`url`、`file`（важи када је `audio2video`）                                                                                |
| `audio_file`     | string  | Условно  | —       | Base64 аудио-датотеке, обавезно када је `audio_type=file`. Исти формати као горе，≤5MB                                                                             |
| `text`           | string  | Условно  | —       | Текст који треба прочитати, обавезно када је `text2video`，**највише 120 знакова**                                                                                     |
| `voice_id`       | string  | Условно  | —       | ID боје гласа, обавезно када је `text2video`                                                                                                   |
| `voice_language` | string  | Не   | `zh`    | Језик боје гласа. Набрајање：`zh`、`en`（важи када је `text2video`）                                                                                      |
| `voice_speed`    | float   | Не   | `1.0`   | Брзина говора, опсег `0.8`–`2.0`, прецизно на једну децималу（важи када је `text2video`）                                                                              |
| `callback_url`   | string  | Не   | —       | Адреса повратног позива. Прослеђивањем ове ставке или `async=true` активира се **асинхрони режим**：одмах враћа `task_id`, повратни позив након генерисања резултата                                                                 |
| `async`          | boolean | Не   | `false` | Да ли је асинхроно. Када је `true`, одмах враћа `task_id`, уз анкетирање преко `/kling/tasks` или повратни позив преко `callback_url`                                                      |

## Пример захтева

### 1）Покретано аудио-записом（audio2video）

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2）Покретано текстом（text2video）

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "哥，好久不见，我一切都好，你要照顾好自己。",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## Пример одговора（синхрони успех）

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| Поље          | Тип      | Опис                                         |
| ----------- | ------- | ------------------------------------------ |
| `success`   | boolean | Да ли је успешно                                       |
| `task_id`   | string  | ID овог задатка（може се користити за упит преко `/kling/tasks`）             |
| `video_id`  | string  | 可灵 ID генерисаног видеа（може се користити као улаз за следећи `extend`/`lip-sync`） |
| `video_url` | string  | URL генерисаног видеа који говори（већ сачуван на CDN-у ове платформе, дугорочно важи）              |
| `duration`  | string  | Трајање видеа（секунде）                                    |
| `state`     | string  | Статус задатка：`succeed` / `failed`                  |

## Асинхрони режим и упит

Када се проследи `callback_url` или `async: true`, интерфејс **одмах враћа** `task_id`；након тога можете：

- **Анкетирање**：`POST /kling/tasks`，body `{ "action": "retrieve", "id": "<task_id>" }`（бесплатно）
- **Повратни позив**：након завршетка генерисања, резултат се POST-ује на ваш `callback_url`

## Комплетан процес：фотографија која говори（image2video → lip-sync）
```bash
# Korak 1: Pokrenite fotografiju, preuzmite video_id
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"look at camera, natural","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# Korak 2: Sinhronizujte usne pomoću zvuka
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"}'
# → { "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4", ... }
```

## Odgovor o grešci

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "one of video_id or video_url is required" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | code                    | Značenje                                                 |
| ---- | ----------------------- | ------------------------------------------------------- |
| 400  | `bad_request`           | Parametar nedostaje ili je nevažeći (npr. mode nije prosleđen, sukob između video i audio opcije „jedno od dva“, text prelazi 120 znakova) |
| 401  | `authorization_missing` | API ključ nedostaje ili je nevažeći                     |
| 403  | `forbidden`             | Sadržaj je blokiran kontrolom rizika                    |
| 429  | `too_many_requests`     | Ograničenje istovremenih zahteva uzvodno, pokušajte ponovo kasnije |
| 500  | `api_error`             | Uzvodna ili interna greška                               |

## Napomene

- `video_id` mora biti video generisan u Kling-u u okviru **30 dana** i mora trajati **5 s ili 10 s**; u suprotnom prosledite video koji ispunjava ograničenja pomoću `video_url`.
- Preporučuje se da ulazni video ima **jasno lice sprijeda i jednu osobu**, za najbolji efekat sinhronizacije usana.
- Trajanje zvuka/teksta treba da odgovara trajanju videa (zvuk ne sme biti duži od videa).
- Naplata se vrši pri **uspehu** (2,45 Credits/put); neuspeh validacije parametara (4xx) se ne naplaćuje.
