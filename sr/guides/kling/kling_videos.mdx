Овај документ ће представити упутство за интеграцију Kling Videos Generation API, који може генерисати Kling званичне видео записе уношењем прилагођених параметара.

## Процес пријаве

Да бисте користили API, прво морате да одете на [Kling Videos Generation API](https://platform.acedata.cloud/documents/3b921a16-a411-4557-8335-53f21d3f9e46) страницу и затражите одговарајућу услугу. Када уђете на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите. Након пријаве или регистрације, аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, коју можете користити за API.

## Основна употреба

Прво, потребно је разумети основни начин коришћења, а то је унос упитника `prompt`, акције `action`, URL адресе референтне слике `start_image_url` и модела `model`, како бисте добили обрађени резултат. Прво је потребно једноставно проследити поље `action`, чија вредност је `text2video`. Ово углавном укључује три врсте акција: видео из текста (`text2video`), видео из слике (`image2video`), и проширени видео (`extend`). Затим, потребно је унети модел `model`, који тренутно укључује `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`, а конкретни садржај је следећи:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" class="m-auto"></p>

Можете видети да смо подесили Request Headers, укључујући:

- `accept`: формат одговора који желите да примите, овде је написано `application/json`, што значи JSON формат.
- `authorization`: кључ за позивање API, који можете директно изабрати након захтева.

Такође смо подесили Request Body, укључујући:

- `model`: модел за генерисање видео записа, углавном `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`.
- `mode`: режим генерисања видео записа, углавном стандардни режим `std` и режим велике брзине `pro`.
- `action`: акција генерисања видео записа, која укључује три врсте акција: видео из текста (`text2video`), видео из слике (`image2video`), и проширени видео (`extend`).
- `start_image_url`: када изаберете акцију видео из слике `image2video`, потребно је да отпремите URL референтне слике.
- `end_image_url`: опционално, за видео из слике, одређује крајњу слику.
- `aspect_ratio`: однос ширине и висине видео записа, опционално, подржава `16:9`, `9:16`, `1:1`, подразумевано `16:9`.
- `cfg_scale`: интензитет корелације, опсег [0,1], што је веће, то је ближе упитнику.
- `camera_control`: опционално, параметри за контролу покрета камере, подржавајући type/simple предлоге као и horizontal, vertical, pan, tilt, roll, zoom и друге конфигурације.
- `negative_prompt`: опционално, реверзни упитници које не желите да се појаве, до 200 знакова.
- `element_list`: референтна листа елемената, примењује се само на модел `kling-video-o1`, конкретан начин коришћења овог параметра можете видети у [документацији](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `video_list`: референтни видео, добијен путем URL-а, примењује се само на модел `kling-video-o1`, конкретан начин коришћења овог параметра можете видети у [документацији](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `prompt`: упитник.
- `callback_url`: URL на који треба да се врати резултат.

Након избора, можете видети да је на десној страни генерисан одговарајући код, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/3yjql0.png" width="500" class="m-auto"></p>

Кликните на дугме „Try“ да бисте тестирали, као што је приказано на слици, и добићете следећи резултат:

```json
{
  "success": true,
  "video_id": "af9a1af0-9aa0-4638-81c1-d41d6143c508",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7485378259/text2video/Cjil4mfBfs0AAAAAAKbMQQ-0_raw_video_1.mp4",
  "duration": "5.1",
  "state": "succeed",
  "task_id": "e3a575aa-a4bd-49c8-9b12-cde38d5462e0"
}
```

Резултат садржи више поља, која су описана као:

- `success`, статус тренутне видео генерисања.
- `task_id`, ID тренутне видео генерисања.
- `video_id`, ID видео записа тренутне видео генерисања.
- `video_url`, линк на видео тренутне видео генерисања.
- `duration`, трајање видео записа тренутне видео генерисања.
- `state`, статус тренутне видео генерисања.

Можете видети да смо добили задовољавајуће информације о видео запису, и само треба да добијемо генерисани Kling видео на основу URL адресе видео записа у `data`.

Ако желите да генеришете одговарајући код за интеграцију, можете га директно копирати, на пример, CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v1",
  "prompt": "Бели керамички шоља за кафу на сјајној мермерној површини са јутарњом светлошћу из прозора. Камера полако ротира 360 степени око шоље, кратко се заустављајући на дршци."
}'
```

## Проширена видео функција

Ако желите да наставите генерисање већ створеног Kling видео записа, можете подесити параметар `action` на `extend` и унети ID видео записа који желите да наставите. ID видео записа добија се на основу основне употребе, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" class="m-auto"></p>

Тада можете видети да је ID видео записа:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

> Напомена: Овде је `video_id` ID генерисаног видео записа. Ако не знате како да генеришете видео, можете се упутити на основну употребу описану горе.

Након тога, морамо унети следећи корак потребан за проширење упитника за прилагођено генерисање видео записа, и можемо одредити следећи садржај:
- `model`：модел за генерисање видео записа, главни модели су `kling-v1`, `kling-v1-5` и `kling-v1-6`.
- `mode`：мод за генерисање видео записа, главne опције су стандардни режим `std` и супер брзи режим `pro`.
- `duration`：дужина видео записа за ову генерисање, углавном укључује 5с и 10с.
- `start_image_url`：када се изабере акција генерисања видео записа `image2video`, потребно је да се отпреми линк за референтну слику првог кадра.
- `prompt`：упутство.

Испуните пример као што је наведено:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" class="m-auto"></p>

Након попуњавања, аутоматски се генерише код као што је наведено:

<p><img src="https://cdn.acedata.cloud/52x4u5.png" width="500" class="m-auto"></p>

Одговарајући Python код:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Када кликнете на покретање, можете приметити да добијате резултат као што је наведено:

```json
{
  "success": true,
  "video_id": "bbc3b105-ac72-4de2-8390-0cb37dc7d41e",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/extendVideo/Cjil4mfBfs0AAAAAAKhr6A-0_raw_video_1.mp4",
  "duration": "9.6",
  "state": "succeed",
  "task_id": "3ece87e6-3ee3-4f5e-bd70-5ae5eca89a23"
}
```

Можете видети да је садржај резултата у складу са горњим текстом, што реализује функцију проширења видео записа.

## Асинхрони повратни позив

Пошто време генерисања видео записа преко Kling Videos Generation API-а траје релативно дуго, око 1-2 минута, ако API дуго не одговара, HTTP захтев ће задржати везу, што доводи до додатне потрошње системских ресурса, па овај API такође пружа подршку за асинхрони повратни позив.

Целокупни процес је: када клијент покреће захтев, додатно одређује поље `callback_url`, након што клијент покрене API захтев, API ће одмах вратити резултат, који садржи информације о пољу `task_id`, што представља ID тренутног задатка. Када задатак буде завршен, резултат генерисаног видео записа ће бити послат на `callback_url` који је одредио клијент, у којем ће такође бити укључено поље `task_id`, тако да се резултати задатка могу повезати преко ID-а.

Испод ћемо видети пример како конкретно извршити операцију.

Прво, Webhook повратни позив је услуга која може примати HTTP захтеве, програмери би требало да замену са URL-ом HTTP сервера који су сами подигли. Овде, ради лакшег демонстрирања, користи се јавни Webhook пример веб сајта https://webhook.site/, отворите тај сајт и добићете Webhook URL, као што је приказано на слици:

![](https://cdn.acedata.cloud/tbcnai.png)

Копирајте овај URL и можете га користити као Webhook, пример овде је `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`.

Након тога, можемо подесити поље `callback_url` на горњи Webhook URL, истовремено попуњавајући одговарајуће параметре, конкретан садржај је приказан на слици:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" class="m-auto"></p>

Када кликнете на покретање, можете одмах добити резултат као што је наведено:

```
{
  "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Након кратког чекања, можемо на `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3` посматрати резултат генерисаног видео записа, као што је приказано на слици:

![](https://cdn.acedata.cloud/zv5u2q.png)

Садржај је следећи:

```json
{
    "success": true,
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/text2video/CjJzzGfBfqcAAAAAAKdVMQ-0_raw_video_1.mp4",
    "duration": "5.1",
    "state": "succeed",
    "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Можете видети да у резултату постоји поље `task_id`, а остала поља су слична као у горњем тексту, а преко овог поља можете реализовати повезивање задатка.

## Обрада грешака

Када позивате API, ако наиђете на грешку, API ће вратити одговарајући код грешке и информације. На пример:

- `400 token_mismatched`：Лош захтев, могуће због недостајућих или неважећих параметара.
- `400 api_not_implemented`：Лош захтев, могуће због недостајућих или неважећих параметара.
- `401 invalid_token`：Неовлашћено, неважећи или недостајући ауторизациони токен.
- `429 too_many_requests`：Превише захтева, прелазите лимит.
- `500 api_error`：Унутрашња грешка сервера, нешто није у реду на серверу.

### Пример одговора на грешку

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
