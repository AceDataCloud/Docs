Ово ће описати начин интеграције Kling Videos Generation API, који омогућава генерисање видео снимака са званичног Kling користећи унос прилагођених параметара.

## Процес пријаве

Да бисте користили API, прво треба да аплицирате за одговарајућу услугу на страници [Kling Videos Generation API](https://platform.acedata.cloud/documents/3b921a16-a411-4557-8335-53f21d3f9e46). После приступа страници, кликните на дугме „Acquire“, као на слици:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ако нисте пријављени или регистровани, аутоматски ћете бити преусмерени на страницу за пријаву. Након регистрације и пријаве, бићете враћени на исту страницу.

Током прве апликације добићете бесплатни бонус који омогућава коришћење API без трошкова.

## Основна употреба

Најпре, упознајмо се са основним начином рада: уносом корисничког упућивања `prompt`, акције `action`, првог биланса референтне слике `start_image_url` и моделом `model`. Уз ове параметре, добићете обрађени резултат. За почетак, потребно је само да поставите поља `action` са вредношћу `text2video`, што означава процес генерисања видеа. Постоје три типа акција: текстом управљани видео (`text2video`), сликом управљани видео (`image2video`) и проширења видеа (`extend`). 

Затим одаберемо модел `model`. Тек current подржани модели су: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1`. Погледајмо у наставку слику:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" className="m-auto" /></p>

У примерима су приказане поставке у заглављу захтева:

- `accept`: формат одговора. Поштује се `application/json`.
- `authorization`: API кључ, који се може одабрати у падућем менију након апликације.

Код за тело захтева укључује:

- `model`: модел за генерисање видеа.
- `mode`: режим рада — `std` (стандард), `pro` (брз) или `4k` (опрежљени 4К у `kling-v3` и `kling-v3-omni`). `4k` подржава само `kling-v3` и `kling-v3-omni`.
- `action`: акција, једна од `text2video`, `image2video` или `extend`.
- `start_image_url`: линк за прву слику уколико је акција `image2video`.
- `end_image_url`: уколико је потребно, линк за последњи кадрови.
- `duration`: дужина видеа у секунди (3-15 за `kling-v3` и `kling-v3-omni`, 5 или 10 секунди за друге модел.
- `generate_audio`: да ли генерише аудио. Подржано за `kling-v3`, `kling-v3-omni`, `kling-v2-6` у про режиму. Подешено на `false` по подразумевану.
- `aspect_ratio`: однос ширине и висине видеа (нпр. `16:9`, `9:16`, `1:1`). У default-у је `16:9`.
- `cfg_scale`: степен релевантности, у интервалу [0,1], где веће вредности боље одговарају улазу.
- `camera_control`: опционални параметар за контролу кретања камере, укључујући `type/simple` подешавања и параметре као `horizontal`, `vertical`, `pan`, `tilt`, `roll`, `zoom`.
- `negative_prompt`: негативни упућивачи, до 200 карактера.
- `element_list`: списак референтних елемената за модел `kling-video-o1`, више информација на [офиц. документацији](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `video_list`: референтни видео записи преко URL-а, иста ограничења као за `element_list`.
- `prompt`: уласка упутство.
- `callback_url`: URL за повратак резултата.

Када одаберете параметре, са десне стране ће се генерисати пример кода као на слици:

Клик на „Try“ омогућава тестирање, и у резултату ћете добити нешто овако:

```json
{
```

Објашњење појединачних поља:

- `success`: статус задатка.
- `task_id`: ID задатка.

- `video_url`: линк до видеа.
- `duration`: трајање видеа.
- `state`: статус процеса.

Лако можете използовати `video_url` за преузимање резултата.

За интеграцију у ваш систем, можете директно копирати пример CURL позива:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v1",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## Проширење функционалности видеа

Ако желите да наставите рад сачињеног видеа, ставите `action` у `extend`, а унесите `video_id` добијен из претходног корака. 

Пример слике добијања ID видеа:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Приступ примером:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

Обавезно, `video_id` је идентификатор видеа након креирања. 

Затим можете дефинисати нови упућивач `prompt`, модел, дужину и други параметар као у примеру:

- `model`: `kling-v1`, `kling-v1-5`, `kling-v1-6`.
- `mode`: `std`, `pro`, `4k`.
- `duration`: 5 или 10 секунди.
- `start_image_url`: за `image2video`.
- `prompt`: упутство.

Пример попуњеног захтева:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" className="m-auto" /></p>

Код за позив у Python-у:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Резултат је сличан првобитном, али са новим `video_id` и положајем за проширење видеа. Једноставно можете наставити руковање истим процесом.

## Асимптомски повратак (Callback)

Имајући у виду да време израде видеа може трајати око 1-2 минута, API подржава асинхроно враћање резултата кроз `callback_url`. 

Код је: при позиву API-ја, поставите `callback_url`. API одмах враћа `task_id`. Када је посао завршен, резултат ће бити послат на `callback_url` у JSON формату, са `task_id` за идентификацију.

Пример:

- Створите свој webхук (нпр. https://webhook.site/). При приступу добићете URL попут `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`.
- Прихватите овај URL као `callback_url`.
- Упошљавате захтев са овим `callback_url`.
- Резултат добијате у web хук-у.

Пример упутства и резултата:

```json
{
  "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

И после неколико минута, можете у примеру вредности на вебхуку видети резултат са `video_url` и осталим параметрима.

## Обрада грешака

Ако се јаве грешке, API ће вратити одговарајући код и информацију:

- `400 token_mismatched` — лош захтев, недостају параметри или су неисправни.
- `401 invalid_token` — неисправан или missing токен.
- `429 too_many_requests` — пренепотребан број захтева у одређеном периоду.
- `500 api_error` — серверска грешка.

Пример одговора:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
