Pošaljite zadatak putem `POST /kling/goods-studio`, a koristite postojeći `POST /kling/tasks` za upit statusa zadatka na platformi.

## Ulaz

Navedite 1–5 slika proizvoda i naslov proizvoda od najviše 200 znakova; opis proizvoda je opcionalan, do najviše 2000 znakova. Trajanje može biti 15, 30 ili 60 sekundi.

U nastavku je primer strukture zahteva, pozovite nakon zamene URL-a materijala.

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## Rezultati i naplata

Sinhroni režim vraća rezultat generisanja; asinhroni režim prvo vraća `task_id`, a završeni rezultat sadrži video ili slikovne veze u `data` i serverski izračunat `usage`. `callback_url` se koristi za obaveštenje o završetku; zahtev sa `watermark=true` istovremeno vraća verziju sa vodenim žigom.

720p: 2,38 Credits/sekundi; 1080p: 2,8 Credits/sekundi. Video-zapisi se naplaćuju prema stvarno generisanom trajanju, osnovna cena po sekundi pre generisanja ne predstavlja ukupnu cenu celog zadatka. Neuspešni zadaci ne naplaćuju troškove generisanja.
