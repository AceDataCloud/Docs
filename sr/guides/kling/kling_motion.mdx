Ovaj tekst će predstaviti uputstvo za integraciju Kling Motion Generation API-ja, koji omogućava generisanje zvaničnih Kling videozapisa unosom prilagođenih parametara.

## Postupak prijave

Da biste koristili Kling Motion Generation API, prvo preuzmite svoj API Token na [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications) i sačuvajte ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu gde ćete biti pozvani da se registrujete i prijavite, a po završetku ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe za zasebnim podnošenjem zahteva za svaku uslugu.** Prva prijava donosi besplatan kredit za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti univerzalni saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Kling Motion Generation API →](https://platform.acedata.cloud/documents/kling-motion)

## Osnovna upotreba

Prvo se upoznajmo sa osnovnim načinom korišćenja: unosom prompta `prompt`, referentne slike `image_url` i linka referentnog videa `video_url` možete dobiti obrađeni rezultat, a zatim je potrebno uneti i model `mode`; trenutno su glavni modeli `std` i `pro`, a konkretan sadržaj je sledeći:

<p><img src="https://cdn.acedata.cloud/5qlpjt.png" width="500" className="m-auto" /></p>

Možete videti da smo ovde postavili Request Headers, uključujući:

- `accept`: format odgovora koji želite da primite; ovde se unosi `application/json`, odnosno JSON format.
- `authorization`: ključ za pozivanje API-ja, koji nakon prijave možete direktno izabrati iz padajuće liste.

Pored toga, postavljen je Request Body, uključujući:

- `image_url`: URL referentne slike izgleda osobe. Podržani su JPG/JPEG/PNG, fajl ≤50MB, širina i visina su obe ≥300px, odnos širine i visine je 1:2.5～2.5:1; osoba treba jasno da prikazuje gornji deo tela ili celo telo i glavu.
- `video_url`: URL referentnog videa pokreta. Podržani su MP4/MOV, fajl ≤100MB, širina i visina su po 340–3850px, najmanje 3 sekunde; kada je `character_orientation=image`, najduže 10 sekundi, a kada je `character_orientation=video`, najduže 30 sekundi. Preporučuje se korišćenje kontinuiranog videa iz jednog kadra u kojem je osoba stalno u kadru.
- `mode`: režim za generisanje videa, uglavnom postoje standardni režim `std` i režim velike brzine `pro`.
- `keep_original_sound`: možete izabrati da li ćete zadržati originalni zvuk videa, vrednosti enumeracije: yes, no.
- `character_orientation`: orijentacija osobe u generisanom videu; možete izabrati da bude ista kao na slici ili ista kao u videu, vrednosti enumeracije: image, video.
- `prompt`: prompt.
- `callback_url`: URL na koji je potrebno poslati rezultat povratnim pozivom.
- `async`: opcionalno, kada se postavi na `true`, interfejs odmah vraća `task_id`, bez potrebe za navođenjem `callback_url`, a rezultat se zatim dobija anketiranjem putem odgovarajućeg interfejsa za upit zadatka.

Nakon izbora, možete primetiti da je odgovarajući kod takođe generisan sa desne strane, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/buwczd.png" width="500" className="m-auto" /></p>

Kliknite na dugme „Try“ da biste izvršili test; kao što je prikazano iznad, ovde smo dobili sledeći rezultat:

```json
{
  "success": true,
  "video_id": "842578800134742051",
  "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": "5.066",
  "state": "succeed",
  "task_id": "363c7a84-e880-472e-a4d4-098e50cfc292"
}
```

Povratni rezultat ima više polja, koja su predstavljena u nastavku:

- `success`, status zadatka generisanja videa u ovom trenutku.
- `task_id`, ID zadatka generisanja videa u ovom trenutku.
- `video_id`, ID videa zadatka generisanja videa u ovom trenutku.
- `video_url`, link videa zadatka generisanja videa u ovom trenutku.
- `duration`, trajanje video linka zadatka generisanja videa u ovom trenutku.
- `state`, stanje zadatka generisanja videa u ovom trenutku.

Možete videti da smo dobili zadovoljavajuće informacije o videu; potrebno je samo da preuzmemo generisani Kling video prema adresi video linka iz `data` u rezultatu.

Pored toga, ako želite da generišete odgovarajući kod za integraciju, možete ga direktno kopirati i generisati, na primer CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/kling/motion' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
  "video_url": "https://cdn.acedata.cloud/odwfm5.mp4",
  "prompt": "让画面生动起来",
  "mode": "std",
  "character_orientation": "image"
}'
```

## Asinhroni povratni poziv

Pošto Kling Motion Generation API zahteva relativno dugo vreme za generisanje, približno 1–2 minuta, ako API dugo ne odgovara, HTTP zahtev će stalno održavati vezu, što dovodi do dodatne potrošnje sistemskih resursa, stoga ovaj API takođe pruža podršku za asinhrone povratne pozive.

Celokupan proces je sledeći: kada klijent pokrene zahtev, dodatno navodi polje `callback_url`; nakon što klijent pokrene API zahtev, API će odmah vratiti rezultat koji sadrži informacije o polju `task_id`, koje predstavlja trenutni ID zadatka. Kada se zadatak završi, rezultat generisanog videa će biti poslat putem POST JSON-a na `callback_url` koji je odredio klijent, a takođe uključuje polje `task_id`, tako da se rezultat zadatka može povezati putem ID-ja.

U nastavku ćemo kroz primer saznati kako se konkretno radi.

Najpre, Webhook povratni poziv je usluga koja može da primi HTTP zahteve, a programeri treba da ga zamene URL-om svog postavljenog HTTP servera. Radi lakše demonstracije, ovde se koristi javna Webhook primer stranica https://webhook.site/; otvaranjem ove stranice možete dobiti Webhook URL, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/tbcnai.png)

Kopirajte ovaj URL i možete ga koristiti kao Webhook; primer ovde je `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`.

Zatim možemo postaviti polje `callback_url` na gore navedeni Webhook URL, istovremeno unoseći odgovarajuće parametre; konkretan sadržaj je prikazan na slici:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" className="m-auto" /></p>

Kliknite na pokretanje i možete primetiti da se odmah dobija rezultat, kao u nastavku:

```
{
  "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Sačekajte trenutak, pa možemo na `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3` posmatrati rezultat generisanog videa, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/zv5u2q.png)

Sadržaj je sledeći:
```json
{
    "success": true,
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
    "duration": "5.1",
    "state": "succeed",
    "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Može se videti da u rezultatu postoji polje `task_id`, ostala polja su slična onima iznad, a povezivanje zadataka se može ostvariti putem ovog polja.

## Rukovanje greškama

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neovlašćeno, nevažeći ili nedostajući token za autorizaciju.
- `429 too_many_requests`: Previše zahteva, prekoračili ste ograničenje učestalosti.
- `500 api_error`: Interna greška servera, nešto je pošlo po zlu na serveru.

### Primer odgovora na grešku

```json
}
```
