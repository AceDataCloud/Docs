Glavna funkcija Kling Tasks API-ja je da putem unosa ID-ja zadatka generisanog od strane Kling Videos Generation API-ja upita status izvršavanja tog zadatka.

Ovaj dokument će detaljno predstaviti uputstva za integraciju Kling Tasks API-ja, pomažući vam da lako integrišete i u potpunosti iskoristite moćne funkcije ovog API-ja. Putem Kling Tasks API-ja možete lako ostvariti upit statusa izvršavanja zadataka Kling Videos Generation API-ja.

## Proces prijave

Da biste koristili Kling Videos Generation API, prvo preuzmite svoj API Token na [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications), i sačuvajte ga za rezervu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a nakon završetka automatski ćete se vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, nije potrebno podnositi zasebnu prijavu za svaku uslugu.** Prva prijava će vam dodeliti besplatni kredit, koji možete besplatno isprobati; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Kling Videos Generation API →](https://platform.acedata.cloud/documents/kling-videos)

## Primer zahteva

Kling Tasks API može se koristiti za upit rezultata Kling Videos Generation API-ja. Za način korišćenja Kling Videos Generation API-ja, pogledajte dokumentaciju [Kling Videos Generation API ](https://platform.acedata.cloud/documents/kling-videos).

Uzećemo kao primer jedan ID zadatka koji vraća usluga Kling Videos Generation API i pokazati kako se koristi ovaj API. Pretpostavimo da imamo ID zadatka: 20068983-0cc9-4c6a-aeb6-9c6a3c668be0, u nastavku ćemo pokazati kako putem prosleđivanja ID-ja zadatka.

### Podešavanje zaglavlja zahteva i tela zahteva

**Request Headers** uključuju:

- `accept`: određuje primanje rezultata odgovora u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete ga direktno izabrati iz padajuće liste.

**Request Body** uključuje:

- `id`: otpremljeni ID zadatka.
- `action`: način operacije nad zadatkom.

Podešavanje je prikazano na slici ispod:

### Primer koda

Možete videti da su na desnoj strani stranice automatski generisani kodovi na različitim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/bsqh3i.png" width="500" className="m-auto" /></p>

Neki primeri koda su sledeći:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/kling/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/kling/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Vraćeni rezultat ima više polja, polje request je request body prilikom pokretanja zadatka, dok je polje response response body vraćen nakon završetka zadatka. Opis polja je sledeći.

- `id`, ID koji generiše ovaj video zadatak, koristi se za jedinstvenu identifikaciju ovog zadatka generisanja videa.
- `request`, informacije o zahtevu u upitu video zadatka.
- `response`, informacije o odgovoru u upitu video zadatka.
- `created_at`, vreme kreiranja zadatka, Unix vremenska oznaka (sekunde, decimalni broj).
- `started_at`, vreme početka izvršavanja zadatka, Unix vremenska oznaka (sekunde, decimalni broj).
- `finished_at`, vreme završetka zadatka, Unix vremenska oznaka (sekunde, decimalni broj). Ovo polje se ne vraća kada zadatak nije završen.
- `elapsed`, trajanje izvršavanja zadatka, jedinica je sekunda (decimalni broj, zadržava 3 decimale). Ovo polje se ne vraća kada zadatak nije završen.

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kôd greške i poruku. Na primer:

- `400 token_mismatched`：Neispravan zahtev, verovatno zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Neispravan zahtev, verovatno zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neovlašćeno, nevažeći ili nedostajući token za autorizaciju.
- `429 too_many_requests`：Previše zahteva, prekoračili ste ograničenje broja zahteva.
- `500 api_error`：Interna greška servera, nešto je pošlo po zlu na serveru.

### Primer odgovora na grešku
