Ovaj dokument će predstaviti način integracije API za anime transformaciju portreta, koji može generisati personalizovane anime likove na osnovu unete fotografije lica, što se može koristiti za kreiranje jedinstvenih avatara, zabavne aktivnosti, aplikacije sa efektima i druge scenarije, poboljšavajući iskustvo društvene zabave.

## Proces prijave

Da biste koristili API, prvo treba da odete na [API za anime transformaciju portreta](https://platform.acedata.cloud/documents/6b6313f1-f398-4d29-933d-5a652cfa1c37) i zatražite odgovarajuću uslugu. Kada uđete na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite. Nakon prijave ili registracije, automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Osnovna upotreba

Prvo, upoznajte se sa osnovnim načinom korišćenja, što podrazumeva unos linka slike, kako biste dobili obrađenu sliku rezultata. Prvo je potrebno jednostavno proslediti polje `image_url`, a slika lica je prikazana na sledećoj slici:

<p><img src="https://cdn.acedata.cloud/lrbtcn.jpg" width="500" class="m-auto"></p>

Sledeće, možemo popuniti odgovarajući sadržaj na interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/gflhrl.png" width="500" class="m-auto"></p>

Možete primetiti da smo ovde postavili Request Headers, uključujući:

- `accept`: format odgovora koji želite da primite, ovde je postavljeno na `application/json`, tj. JSON format.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

Takođe je postavljen Request Body, uključujući:

- `image_url`: link do slike lica koja treba da se obradi.

Nakon izbora, možete primetiti da je sa desne strane generisan odgovarajući kod, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/rwbicp.png" width="500" class="m-auto"></p>

Kliknite na dugme „Try“ da biste izvršili testiranje, kao što je prikazano na slici, i ovde smo dobili sledeći rezultat:

```json
{
  "image_url": "https://faceeffect-1254418846.cos.ap-guangzhou.myqcloud.com/ft/FaceCartoonPic/1256437459/8567833b-7831-406c-9ff5-890e5f7e020e"
}
```

Možete primetiti da u vraćenom rezultatu postoji polje `image_url`, koje sadrži promenjenu sliku karikature lica. Promenjene informacije o licu su prikazane na sledećoj slici:

<p><img src="https://cdn.acedata.cloud/qkyga1.png" width="500" class="m-auto"></p>

Možete primetiti da je na slici lice već generisano kao personalizovani anime lik.

Takođe, ako želite da generišete odgovarajući kod za integraciju, možete ga direktno kopirati, na primer, CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/face/cartoon' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg"
}'
```

Python kod za integraciju je sledeći:

```python
import requests

url = "https://api.acedata.cloud/face/cartoon"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
