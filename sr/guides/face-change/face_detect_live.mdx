Ovaj dokument će predstaviti uputstvo za integraciju API-ja za detekciju statičkog živog lica (visoka preciznost), koji se može koristiti za detekciju živog lica na statičkim slikama koje korisnici postavljaju, kako bi se utvrdilo da li je slika preuzeta.

## Proces prijave

Da biste koristili API, prvo idite na [API za detekciju statičkog živog lica (visoka preciznost)](https://platform.acedata.cloud/documents/df41d411-6ba8-41d3-a56f-3f6ec9acaa36) i zatražite odgovarajuću uslugu. Kada uđete na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite. Nakon prijave ili registracije, automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Osnovna upotreba

Prvo, upoznajte se sa osnovnim načinom korišćenja, što podrazumeva unos linka slike, nakon čega ćete dobiti obrađenu sliku rezultata. Prvo je potrebno jednostavno proslediti polje `image_url`, a slika lica je prikazana na sledećoj slici:

<p><img src="https://cdn.acedata.cloud/lrbtcn.jpg" width="500" className="m-auto" /></p>

Sledeće, možemo popuniti odgovarajući sadržaj na interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/c975uf.png" width="500" className="m-auto" /></p>

Možete primetiti da smo ovde postavili Request Headers, uključujući:

- `accept`: format odgovora koji želite da primite, ovde je postavljeno na `application/json`, tj. JSON format.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete direktno izabrati iz padajućeg menija.

Takođe smo postavili Request Body, uključujući:

- `image_url`: link do slike lica koja treba da se obradi.
- `face_model_version`: verzija algoritma modela koja se koristi za uslugu prepoznavanja lica. Trenutno podržava ulaz „3.0“.

Nakon izbora, možete primetiti da je sa desne strane generisan odgovarajući kod, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/nkcvet.png" width="500" className="m-auto" /></p>

Kliknite na dugme „Try“ da biste izvršili testiranje, kao što je prikazano na gornjoj slici, ovde smo dobili sledeći rezultat:

```json
{
  "score": 0,
  "face_model_version": "3.0"
}
```

Možete primetiti da smo u ovom trenutku dobili rezultat detekcije statičkog živog lica, uključujući sadržaj ocene živog lica.

Objašnjenje polja je sledeće:

- `score`: ocena živog lica, opseg vrednosti [0,100], na osnovu praga koji odgovara oceni živog lica da bi se utvrdilo da li je slika preuzeta. Trenutni pragovi su [5,10,40,70,90], pri čemu je preporučeni prag 40.
- `face_model_version`: verzija algoritma modela koja se koristi za prepoznavanje lica.

Takođe, ako želite da generišete odgovarajući kod za integraciju, možete ga direktno kopirati, na primer, CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/face/detect-live' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg"
}'
```

Python kod za integraciju je sledeći:

```python
import requests

url = "https://api.acedata.cloud/face/detect-live"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
