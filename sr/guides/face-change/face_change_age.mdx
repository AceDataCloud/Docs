Ovaj dokument će predstaviti API za promenu godina lica, koji može promeniti godine na licu u slici na osnovu unete slike i godina. Osnovna upotreba je da korisnik otpremi sliku lica, a na osnovu algoritama za uređivanje i generisanje lica, izlaz je slika lica koja izgleda starije ili mlađe, podržava promene godina lica.

## Proces prijave

Da biste koristili API, prvo idite na [API za promenu godina lica](https://platform.acedata.cloud/documents/0c5b4165-25ba-4dc2-8f02-e3cd74ab4238) i prijavite se za odgovarajuću uslugu. Kada uđete na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite. Nakon prijave ili registracije, automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Osnovna upotreba

Prvo, potrebno je razumeti osnovni način korišćenja, što podrazumeva unos linka slike i informacija o godinama, kako biste dobili obrađenu sliku. Prvo je potrebno jednostavno proslediti polje `image_url`, a slika lica je prikazana na sledećoj slici:

<p><img src="https://cdn.acedata.cloud/f5687u.png" width="500" className="m-auto" /></p>

Zatim, potrebno je uneti informacije o godinama lica u parametru `age_infos`, koji je niz i možemo uneti više informacija. Sledeće možemo popuniti odgovarajući sadržaj na interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/cn95e8.png" width="500" className="m-auto" /></p>

Možemo videti da smo postavili Request Headers, uključujući:

- `accept`: u kojem formatu želite da primite odgovor, ovde je uneto `application/json`, što znači JSON format.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

Takođe, postavili smo Request Body, uključujući:

- `image_url`: link do slike lica koja treba da se obradi.
- `age_infos`: informacije o godinama lica i regionu, pri čemu je godina obavezan parametar.

Nakon izbora, možemo primetiti da je sa desne strane generisan odgovarajući kod, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/zk8qkl.png" width="500" className="m-auto" /></p>

Kliknite na dugme „Try“ da biste izvršili testiranje, kao što je prikazano na slici, i ovde smo dobili sledeći rezultat:

```json
{
  "image_url": "https://faceeffect-1254418846.cos.ap-guangzhou.myqcloud.com/ft/ChangeAgePic/1256437459/bfce1ab8-5fd7-464d-8878-b38433f84d0e"
}
```

Možemo videti da u vraćenom rezultatu postoji polje `image_url`, koje sadrži sliku lica nakon promene godina na osnovu unetih godina. Informacije o promenjenom licu su prikazane na sledećoj slici:

<p><img src="https://cdn.acedata.cloud/01rmiv.png" width="500" className="m-auto" /></p>

Možemo primetiti da se lice na slici promenilo prema unetim godinama.

Takođe, ako želite da generišete odgovarajući kod za integraciju, možete ga jednostavno kopirati, na primer, CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/face/change-age' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "age_infos": [{"age":60}],
  "image_url": "https://cdn.acedata.cloud/f5687u.png"
}'
```

Python kod za integraciju je sledeći:

```python
import requests

url = "https://api.acedata.cloud/face/change-age"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "age_infos": [{"age":60}],
    "image_url": "https://cdn.acedata.cloud/f5687u.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
