Glavna funkcija Face Swap API je da zameni lice na izvornoj slici licem sa ciljne slike, koristeći jednu izvoru sliku i jednu ciljnu sliku.

Ovaj dokument će detaljno opisati uputstva za integraciju Face Swap API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Face Swap API, možete lako zameniti lice sa ciljne slike licem sa izvorne slike.

## Proces prijave

Da biste koristili Face Swap API, prvo treba da odete na stranicu za prijavu [Face Swap API](https://platform.acedata.cloud/documents/d10df07a-66a6-4c37-b114-3a003fc9bd55) i zatražite odgovarajuću uslugu. Kada uđete na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![Stranica za prijavu](https://cdn.acedata.cloud/rci31i.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na [stranicu za prijavu](https://platform.acedata.cloud) koja vas poziva da se registrujete i prijavite. Nakon prijave ili registracije, automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava da besplatno koristite ovaj API.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se prihvata odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

**Telo zahteva** uključuje:

- `source_image_url`: link do otpremljene izvorne slike.
- `target_image_url`: link do otpremljene ciljne slike.
- `timeout`: opcionalno, vreme za obradu (u sekundama), nakon kojeg će se automatski vratiti odgovor.

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na raznim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/t8gsls.png" width="500" class="m-auto"></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/face/swap' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "source_image_url": "https://cdn.acedata.cloud/n1lmd8.png",
  "target_image_url": "https://cdn.acedata.cloud/3np95r.png"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/face/swap"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "source_image_url": "https://cdn.acedata.cloud/n1lmd8.png",
    "target_image_url": "https://cdn.acedata.cloud/3np95r.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

- `image_width`, širina generisane slike.

## Asinhroni povratni poziv

Zbog dužeg vremena generisanja Face Swap-a, koje traje oko 1-2 minuta, ako API dugo ne odgovara, HTTP zahtev će zadržati vezu, što dovodi do dodatne potrošnje sistemskih resursa, pa ovaj API takođe pruža podršku za asinhrone povratne pozive.

Celokupni proces je: kada klijent pokrene zahtev, dodatno se određuje polje `callback_url`, nakon što klijent pokrene API zahtev, API će odmah vratiti rezultat koji sadrži polje `task_id`, koje predstavlja trenutni ID zadatka. Kada zadatak bude završen, rezultat generisanja Face Swap-a biće poslat POST JSON-om na klijentom određeni `callback_url`, koji takođe uključuje polje `task_id`, tako da se rezultati zadatka mogu povezati putem ID-a.

Pogledajmo kako to konkretno funkcioniše kroz primer.

Prvo, Webhook povratni poziv je usluga koja može primati HTTP zahteve, a programeri bi trebali zameniti URL-om svog HTTP servera. Ovde, radi lakšeg prikazivanja, koristićemo javni Webhook sajt https://webhook.site/, otvaranjem ovog sajta dobićete Webhook URL, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/r8wyb7.png)

Kopirajte ovaj URL i možete ga koristiti kao Webhook, a primer ovde je https://webhook.site/3b76eba5-4573-432a-b607-3000b87afc06.

Sledeće, možemo postaviti polje `callback_url` na navedeni Webhook URL, kao i uneti odgovarajuće parametre, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/xx08i2.png" width="500" class="m-auto"></p>

Kliknite na pokretanje, i možete odmah dobiti rezultat, kao što je prikazano:

```json
{
  "task_id": "9cba9d36-3b14-43c9-85b6-86f6dfc3b096"
}
```

Nakon nekoliko trenutaka, možemo posmatrati rezultat generisanja Face Swap-a na https://webhook.site/3b76eba5-4573-432a-b607-3000b87afc06, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/col42s.png)

Sadržaj je:

```json

  "success": true,
  "task_id": "9cba9d36-3b14-43c9-85b6-86f6dfc3b096",
  "image_url": "https://platform.cdn.acedata.cloud/face/9cba9d36-3b14-43c9-85b6-86f6dfc3b096.png",
  "image_width": 2008,
  "image_height": 1942,
  "image_size": 4006481

```

Možete primetiti da rezultat sadrži polje `task_id`, a ostala polja su slična onima iz prethodnog dela, a putem ovog polja možete ostvariti povezanost zadatka.

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:
- `400 token_mismatched`：Loša zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Loša zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neautorizovano, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste ograničenje brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.
