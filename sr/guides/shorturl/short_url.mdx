Ovaj dokument će predstaviti uputstvo za integraciju Kratak URL API, koji može pretvoriti duže URL-ove u kratke URL-ove.

## Proces prijave

Da biste koristili API, prvo idite na [Kratak URL API](https://platform.acedata.cloud/documents/a2303356-6672-4eb8-9778-75f55c998fe9) odgovarajuću stranicu i zatražite odgovarajuću uslugu, nakon što uđete na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, nakon prijave ili registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu, koju možete besplatno koristiti za ovaj API.

## Osnovna upotreba

Prvo, potrebno je razumeti osnovni način korišćenja, a to je da unesete duži URL koji treba pretvoriti, i dobićete obrađeni rezultat, prvo je potrebno jednostavno proslediti polje `content`. Zatim možemo popuniti odgovarajući sadržaj na interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/4ascb2.png" width="500" class="m-auto"></p>

Možete videti da smo postavili Request Headers, uključujući:

- `accept`: kakav format odgovora želite da primite, ovde je uneto `application/json`, tj. JSON format.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete direktno izabrati.

Takođe je postavljen Request Body, uključujući:

- `content`: sadržaj URL-a koji treba skratiti.

Nakon izbora, možete primetiti da je sa desne strane generisan odgovarajući kod, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/r3uakb.png" width="500" class="m-auto"></p>

Kliknite na dugme „Try“ da biste izvršili test, kao što je prikazano na gornjoj slici, ovde smo dobili sledeći rezultat:

```json
{
  "success": true,
  "data": {
    "url": "https://surl.id/1uHCs01xa5"
  }
}
```

Vraćeni rezultat ima više polja, opisana kao:

- `success`, status da li je zadatak uspešan.
- `data`, sadrži konvertovani URL.

Može se primetiti da je prvobitni duži URL `https://platform.acedata.cloud/documents/a2303356-6672-4eb8-9778-75f55c998fe9` uspešno konvertovan u kratak URL `https://surl.id/1uHCs01xa5`.

Takođe, ako želite da generišete odgovarajući kod za integraciju, možete ga direktno kopirati, na primer, CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/shorturl' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "content": "https://platform.acedata.cloud/documents/a2303356-6672-4eb8-9778-75f55c998fe9"
}'
```

Python kod za integraciju je sledeći:

```python
import requests

url = "https://api.acedata.cloud/shorturl"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": "https://platform.acedata.cloud/documents/a2303356-6672-4eb8-9778-75f55c998fe9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### Primer greške u odgovoru
