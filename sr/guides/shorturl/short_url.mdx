Ovaj dokument će predstaviti način integracije Kratak URL API, koji može pretvoriti duže URL-ove u kratke URL-ove.

## Proces prijave

Da biste koristili Kratak URL API, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, koji čuvate za kasnije.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozvati sve usluge platforme, nije potrebno posebno se prijavljivati za svaku uslugu.** Prva prijava donosi besplatnu kvotu, možete besplatno isprobati; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Puna dokumentacija: [Kratak URL API →](https://platform.acedata.cloud/documents/shorturl)

## Osnovna upotreba

Prvo se upoznajte sa osnovnim načinom korišćenja, što podrazumeva unos dužeg URL-a koji treba pretvoriti, kako biste dobili obrađeni rezultat, prvo je potrebno jednostavno proslediti polje `content`. Zatim možemo popuniti odgovarajući sadržaj na interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/4ascb2.png" width="500" className="m-auto" /></p>

Možete videti da smo ovde postavili Request Headers, uključujući:

- `accept`: kakav format odgovora želite da primite, ovde je uneto `application/json`, što znači JSON format.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete direktno izabrati sa padajuće liste.

Takođe je postavljen Request Body, uključujući:

- `content`: sadržaj URL-a koji treba skratiti.

Nakon izbora, možete primetiti da je sa desne strane generisan odgovarajući kod, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/r3uakb.png" width="500" className="m-auto" /></p>

Kliknite na dugme „Try“ da biste izvršili test, kao što je prikazano na gornjoj slici, ovde smo dobili sledeći rezultat:

```json
{
  "success": true,
  "data": {
    "url": "https://surl.id/1uHCs01xa5"
  }
}
```

Vraćeni rezultat ima više polja, opisana kao:

- `success`, status da li je zadatak uspešan.
- `data`, sadrži konvertovani URL.

Može se primetiti da je prvobitni duži URL `https://platform.acedata.cloud/documents/shorturl` uspešno konvertovan u kratak URL `https://surl.id/1uHCs01xa5`.

Takođe, ako želite da generišete odgovarajući kod za integraciju, možete ga direktno kopirati, na primer, CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/shorturl' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "content": "https://platform.acedata.cloud/documents/shorturl"
}'
```

Python kod za integraciju je sledeći:

```python
import requests

url = "https://api.acedata.cloud/shorturl"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": "https://platform.acedata.cloud/documents/shorturl"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### Primer greške u odgovoru

```json
  },

}
```
