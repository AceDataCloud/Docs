Glavna funkcija Veo Tasks API je da omogućava upit o statusu izvršenja zadatka putem ID-a zadatka generisanog pomoću Veo Videos Generation API.

Ovaj dokument će detaljno opisati integraciju Veo Tasks API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Veo Tasks API, možete lako ostvariti upit o statusu izvršenja zadatka Veo Videos Generation API.

## Proces prijave

Da biste koristili Veo Videos Generation API, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, koji čuvate za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozvati sve usluge platforme, bez potrebe da se za svaku uslugu posebno prijavljujete.** Prva prijava donosi besplatnu kvotu, koju možete besplatno isprobati; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Puna dokumentacija: [Veo Videos Generation API →](https://platform.acedata.cloud/documents/veo-videos)

## Primer zahteva

Veo Tasks API može se koristiti za upit o rezultatima Veo Videos Generation API. O tome kako koristiti Veo Videos Generation API, molimo vas da se obratite dokumentaciji [Veo Videos Generation API](https://platform.acedata.cloud/documents/veo-videos).

Uzmimo za primer jedan ID zadatka koji je vratio Veo Videos Generation API i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: 1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed, a zatim ćemo prikazati kako proći kroz unos jednog ID-a zadatka.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno odabrati nakon prijave.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se prenosi.
- `action`: način operacije na zadatku.

Postavite kao što je prikazano na sledećoj slici:

<p><img src="https://cdn.acedata.cloud/xztiqi.png" width="500" className="m-auto" /></p>

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na raznim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/bsqh3i.png" width="500" className="m-auto" /></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/veo/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/veo/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Greška u obradi

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Loš zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Loš zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neautorizovano, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste limit brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.
