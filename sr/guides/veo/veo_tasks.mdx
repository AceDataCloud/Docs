Glavna funkcija Veo Tasks API je da omogućava praćenje statusa izvršenja zadatka putem ID-a zadatka generisanog putem Veo Videos Generation API.

Ovaj dokument će detaljno opisati integraciju Veo Tasks API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Veo Tasks API, možete lako pratiti status izvršenja zadataka iz Veo Videos Generation API.

## Proces prijave

Da biste koristili Veo Tasks API, prvo treba da odete na stranicu za prijavu [Veo Videos Generation API](https://platform.acedata.cloud/documents/63e01dc3-eb21-499e-8049-3025c460058f) i zatražite odgovarajuću uslugu, a zatim kopirajte ID zadatka iz Veo Videos Generation API, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/txlg6g.png" width="500" className="m-auto" /></p>

Na kraju, idite na stranicu Tasks API [Veo Tasks API](https://platform.acedata.cloud/documents/52778f8b-93ce-4db3-a62c-bcf0a92e5f3c) i zatražite odgovarajuću uslugu, a nakon ulaska na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![Stranica za prijavu](https://cdn.acedata.cloud/rci31i.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na [stranicu za prijavu](https://platform.acedata.cloud) koja vas poziva da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Primer zahteva

Veo Tasks API može se koristiti za praćenje rezultata Veo Videos Generation API. O tome kako koristiti Veo Videos Generation API, molimo vas da se obratite dokumentu [Veo Videos Generation API](https://platform.acedata.cloud/documents/63e01dc3-eb21-499e-8049-3025c460058f).

Uzmimo jedan ID zadatka koji je vratio Veo Videos Generation API kao primer i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: 1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed, a zatim ćemo prikazati kako da ga prosledimo.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se šalje.
- `action`: način na koji se operiše sa zadatkom.

Postavite kao što je prikazano na slici ispod:

<p><img src="https://cdn.acedata.cloud/xztiqi.png" width="500" className="m-auto" /></p>

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na različitim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/bsqh3i.png" width="500" className="m-auto" /></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/veo/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/veo/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Ошибка обработки

При pozivu API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`：Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`：Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste limit brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.

### Пример ошибки ответа

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
