Ovaj članak će predstaviti uputstvo za integraciju Veo Videos Generation API-ja, koji omogućava generisanje zvaničnih Veo videozapisa unosom prilagođenih parametara.

## Proces prijave

Da biste koristili Veo Videos Generation API, najpre preuzmite svoj API Token sa [Ace Data Cloud konzole](https://platform.acedata.cloud/console/applications) i sačuvajte ga za kasnije.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu gde ćete biti pozvani da se registrujete i prijavite, a nakon završetka ćete automatski biti vraćeni na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe za posebnom prijavom za svaku uslugu.** Prva prijava donosi besplatan kredit za besplatno iskustvo; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Veo Videos Generation API →](https://platform.acedata.cloud/documents/veo-videos)

## Osnovna upotreba

Najpre pogledajmo osnovni način korišćenja: unosom prompta `prompt`, radnje generisanja `action`, niza referentnih slika za početni i završni kadar `image_urls` i modela `model`, možete dobiti obrađeni rezultat. Najpre je potrebno jednostavno proslediti polje `action`, čija je vrednost `text2video`; ono uglavnom obuhvata tri radnje: generisanje videa iz teksta (`text2video`), generisanje videa iz slike (`image2video`) i dobijanje 1080p videa (`get1080p`). Zatim je potrebno uneti model `model`; trenutno su glavni modeli `veo31-fast`, `veo3`, `veo31`, `veo3-fast` i `veo31-fast-ingredients`, a konkretan sadržaj je sledeći:

<p><img src="https://cdn.acedata.cloud/vv5pe8.png" width="500" className="m-auto" /></p>

Možete videti da smo ovde podesili Request Headers, uključujući:

- `accept`: format odgovora koji želite da primite; ovde se unosi `application/json`, odnosno JSON format.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati iz padajuće liste nakon prijave.

Pored toga, podešen je Request Body, uključujući:

- `model`: model za generisanje videa, uglavnom uključuje modele `veo31-fast`, `veo3`, `veo31`, `veo3-fast` i `veo31-fast-ingredients`.
- `action`: radnja ovog zadatka generisanja videa, uglavnom obuhvata tri radnje: generisanje videa iz teksta (`text2video`), generisanje videa iz slike (`image2video`) i dobijanje 1080p videa (`get1080p`).
- `image_urls`: veza do referentne slike koja se mora otpremiti kada se izabere radnja generisanja videa iz slike `image2video`. `veo31-fast-ingredients` podržava najviše 3 slike (spajanje više slika), dok ostali modeli podržavaju najviše 2 slike (režim početnog i završnog kadra).
- `resolution`: odabir rezolucije generisanog videa; model veo31 podržava 4k rezoluciju, ostali modeli je ne podržavaju, svi modeli podržavaju 1080p i gif rezolucije. Ako se ova vrednost ne prosledi, podrazumevano se koristi 720p rezolucija, a glavne opcije su: `1080p`, `gif`, `4k`.
- `prompt`: prompt.
- `callback_url`: URL za povratni poziv rezultata.
- `async`: opciono; kada se postavi na `true`, interfejs odmah vraća `task_id`, bez potrebe za prosleđivanjem `callback_url`, a rezultat se zatim dobija anketiranjem odgovarajućeg interfejsa za upit zadatka.

### 📌 Sažetak opisa modela

| **Naziv modela**                   | **Podržani režimi**                          | **Pravila za unos slika**                        |
| -------------------------- | --------------------------------- | --------------------------------- |
| **veo3-fast**              | Generisanje videa iz teksta (bez slike)<br />Režim generisanja videa iz slike (sa slikom)           | **1 slika** → režim početnog kadra<br />**2 slike** → režim početnog i završnog kadra |
| **veo31-fast**             | Generisanje videa iz teksta (bez slike)<br />Režim generisanja videa iz slike (sa slikom)           | **1 slika** → režim početnog kadra<br />**2 slike** → režim početnog i završnog kadra |
| **veo31-fast-ingredients** | ❌ Generisanje videa iz teksta (nije podržano)<br />✅ **obavezno spajanje više slika** (slike se moraju proslediti) | **1-3 slike** → režim spajanja više slika (najviše 3 slike)        |
| **veo3**                   | Generisanje videa iz teksta (bez slike)<br />Režim generisanja videa iz slike (sa slikom)           | **1 slika** → režim početnog kadra<br />**2 slike** → režim početnog i završnog kadra |
| **veo31**                  | Generisanje videa iz teksta (bez slike)<br />Režim generisanja videa iz slike (sa slikom)           | **1 slika** → režim početnog kadra<br />**2 slike** → režim početnog i završnog kadra |

---

### 🔑 Objašnjenje ključnih pravila

1. **Opšta logika**:
   - **Bez unosa slike** → automatski se aktivira režim generisanja videa iz teksta.
   - **Sa unosom slike** → aktivira se režim generisanja videa iz slike (konkretno ponašanje određuje broj slika).
2. **Tipovi režima generisanja videa iz slike**:
   - **Režim početnog kadra** (1 slika): početni kadar je fiksiran kao ulazna slika.
   - **Režim početnog i završnog kadra** (2 slike): početni i završni kadar su fiksirani kao ulazne slike.
   - **Režim spajanja više slika** (1-3 slike): podržava ga samo `veo31-fast-ingredients`, koji spaja sadržaj više slika radi generisanja videa.
3. **Klasifikacija režima**:

  - **Fast režim**: `veo3-fast`, `veo31-fast`, `veo31-fast-ingredients`.
   - **Quality režim**: `veo3`, `veo31` (viši kvalitet generisanja).

---

### ⚠️ Napomene

- **Jedini model koji obavezno zahteva slike**: `veo31-fast-ingredients` mora primiti slike (1-3 slike), u suprotnom ne može da se pokrene.
- **Ograničenje broja slika**:
  - `veo31-fast-ingredients` podržava unos **1-3 slike** (režim spajanja više slika).
  - Ostali modeli podržavaju najviše unos **2 slike** (režim početnog i završnog kadra).

```shell
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "veo31-fast",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## Funkcija generisanja videa iz slike

Ako želite da generišete video na osnovu slika prvog i poslednjeg kadra, možete postaviti parametar `action` na `image2video` i uneti niz linkova slika prvog i poslednjeg kadra `image_urls`.

Zatim moramo obavezno popuniti proširene promptove potrebne u sledećem koraku za prilagođeno generisanje videa, pa se može navesti sledeći sadržaj:

- `model`: model za generisanje videa, uglavnom uključuje `veo31-fast`, `veo3`, `veo31`, `veo3-fast` i `veo31-fast-ingredients`.
- `image_urls`: kada se odabere ponašanje generisanja videa iz slike `image2video`, obavezno su potrebni linkovi referentnih slika za otpremanje.
- `prompt`: prompt.

Primer popunjavanja je sledeći:

<p><img src="https://cdn.acedata.cloud/8wvlqd.png" width="500" className="m-auto" /></p>

Nakon popunjavanja, automatski se generiše sledeći kod:

<p><img src="https://cdn.acedata.cloud/tgzfxi.png" width="500" className="m-auto" /></p>

Odgovarajući Python kod:

```python
import requests

url = "https://api.acedata.cloud/veo/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "image2video",
    "model": "veo31-fast",
    "prompt": "Let it dance",
    "image_urls": ["https://cdn.acedata.cloud/7p1jhy.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asinhroni povratni poziv

Pošto je vreme generisanja putem Veo Videos Generation API-ja relativno dugo, približno 1–2 minuta, ako API ne odgovara duže vreme, HTTP zahtev će stalno održavati vezu, što dovodi do dodatne potrošnje sistemskih resursa, stoga ovaj API takođe pruža podršku za asinhrone povratne pozive.

Celokupan proces je sledeći: kada klijent pokrene zahtev, dodatno navodi polje `callback_url`, nakon što klijent pokrene API zahtev, API će odmah vratiti rezultat koji sadrži informacije o polju `task_id`, koje predstavlja trenutni ID zadatka. Kada se zadatak završi, rezultat generisanog video zapisa će biti poslat putem POST JSON formata na `callback_url` koji je naveo klijent, pri čemu će takođe biti uključeno polje `task_id`, tako da se rezultati zadataka mogu povezati putem ID-ja.

U nastavku ćemo kroz primer saznati kako se konkretno postupa.

Najpre, Webhook povratni poziv je servis koji može da prima HTTP zahteve, a programeri treba da ga zamene URL-om sopstvenog postavljenog HTTP servera. ## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i poruku. Na primer:

- `400 token_mismatched`：Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neovlašćeno, nevažeći ili nedostajući token za autorizaciju.
- `429 too_many_requests`：Previše zahteva, prekoračili ste ograničenje učestalosti.
- `500 api_error`：Interna greška servera, nešto je pošlo po zlu na serveru.

### Primer odgovora na grešku
