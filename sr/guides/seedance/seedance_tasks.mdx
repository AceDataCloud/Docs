Главна функција SeeDance Tasks API је да омогући проверу статуса извршења задатка путем ID-a задатка генерисаног од SeeDance Video Generation API.

Овај документ ће детаљно описати упутство за интеграцију SeeDance Tasks API, помажући вам да лако интегришете и максимално искористите моћне функције овог API. Користећи SeeDance Tasks API, можете лако проверити статус извршења задатка SeeDance Video Generation API.

## Процес пријаве

Да бисте користили SeeDance Tasks API, прво морате да се пријавите на страници [SeeDance Video Generation API](https://platform.acedata.cloud/documents/seedance-videos) за одговарајућу услугу, а затим копирајте ID задатка SeeDance Video Generation API, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" class="m-auto"></p>

На крају, идите на страницу Tasks API [SeeDance Tasks API](https://platform.acedata.cloud/documents/seedance-tasks) да бисте затражили одговарајућу услугу, а након уласка на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![Пријавна страница](https://cdn.acedata.cloud/rci31i.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на [страницу за пријаву](https://platform.acedata.cloud) која вас позива да се региструјете и пријавите, а након пријаве или регистрације аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, коју можете користити без накнаде.

## Пример захтева

SeeDance Tasks API може се користити за проверу резултата SeeDance Video Generation API. За информације о томе како користити SeeDance Video Generation API, молимо вас да се упутите на документ [SeeDance Video Generation API](https://platform.acedata.cloud/documents/seedance-videos-integration).

Узмимо за пример ID задатка који је вратила услуга SeeDance Video Generation API, и демонстрираћемо како користити овај API. Хајде да претпоставимо да имамо ID задатка: 20068983-0cc9-4c6a-aeb6-9c6a3c668be0, а затим ћемо демонстрирати како да пренесемо ID задатка.

### Постављање заглавља захтева и тела захтева

**Request Headers** укључује:

- `accept`: одређује да се примају одговори у JSON формату, овде се попуњава као `application/json`.
- `authorization`: кључ за позивање API, који можете директно изабрати након пријаве.

**Request Body** укључује:

- `id`: ID задатка који се шаље.
- `action`: начин операције над задатком.

Поставите као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/yuyte9.png" width="500" class="m-auto"></p>

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/seedance/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "a6e0d456-189b-4c78-9232-2fe72166ab39",
  "action": "retrieve"
}'
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### Primer greške u odgovoru
