Ovaj dokument će predstaviti uputstvo za integraciju SeeDance Videos Generation API-ja, koji može generisati zvanične SeeDance video zapise unosom prilagođenih parametara.

## Proces prijave

Da biste koristili SeeDance Videos Generation API, najpre preuzmite svoj API Token na [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications) i sačuvajte ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a nakon završetka ćete automatski biti vraćeni na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe za zasebnim podnošenjem zahteva za svaku uslugu.** Pri prvoj prijavi dobićete besplatni kredit za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [SeeDance Videos Generation API →](https://platform.acedata.cloud/documents/seedance-videos)

## Osnovna upotreba

Najpre upoznajmo osnovni način upotrebe: unosom prompta `content.text`, tipa `content.type=text` i modela `model`, možete dobiti obrađeni rezultat; konkretan sadržaj je sledeći:

<p><img src="https://cdn.acedata.cloud/seedance_parameters.png" width="500" className="m-auto" /></p>

Može se videti da smo ovde postavili Request Headers, uključujući:

- `accept`: format rezultata odgovora koji želite da primite; ovde se unosi `application/json`, odnosno JSON format.
- `authorization`: ključ za pozivanje API-ja, koji se nakon prijave može direktno izabrati iz padajuće liste.

Takođe smo postavili Request Body, uključujući:

- `model`: model za generisanje videa.
  - **Seedance 1.x serija**: `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`, `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-lite-t2v-250428`, `doubao-seedance-1-0-lite-i2v-250428`.
  - **Seedance 2.0 serija** (podržava multimodalne reference likova i audio-videa): `doubao-seedance-2-0-260128` (standardni), `doubao-seedance-2-0-fast-260128` (brzi), `doubao-seedance-2-0-mini-260615` (lagani).
  - **Seedance 2.5**: `doubao-seedance-2-5-260628`, podržava najviše 30 sekundi, reference samo na audio, više materijala, uređivanje i produžavanje videa.
- `content`: niz ulaznog sadržaja, `type` može biti `text` (prompt), `image_url` (referentna slika), `audio_url` (referentni audio), `video_url` (referentni video). Slici se putem `role` može odrediti namena: `first_frame` (prvi frejm) / `last_frame` (poslednji frejm) / `reference_image` (referenca lika / subjekta).
- `resolution`: izlazna rezolucija, opcije su `480p` / `720p` / `1080p` / `4k`. 2.5 podržava 480p, 720p, 1080p; 2.0 Fast/Mini podržava 480p, 720p; 2.0 Standard podržava najviše 4k.
- `ratio`: odnos širine i visine, opcije su `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive`.
- `duration`: trajanje videa (sekunde, ceo broj). 1.0 serija 2–12; 1.5 Pro 4–12; 2.0 serija 4–15; 2.5 je 4–30. 1.5/2.x podržavaju `-1` (automatsko trajanje).
- `seed`: nasumično seme, ceo broj, od -1 do 4294967295.
- `camerafixed`: da li je kamera fiksirana, `true` / `false`.
- `watermark`: da li se dodaje vodeni žig, `true` / `false`.
- `generate_audio`: da li se generiše video sa zvukom, `true` / `false`, podržavaju Seedance 1.5 Pro i 2.x serija.
- `return_last_frame`: da li se u rezultatu vraća URL slike poslednjeg frejma videa.
- `omni_reference_task_type`: samo za 2.5; `auto` / `reference` / `edit` / `extend`.
- `output_format`: samo za 2.5; `mp4` / `mov`, podrazumevano je `mp4`.
- `tools`: samo za 2.5; trenutno podržava alat za mrežnu pretragu `web_search`, kojim se može ograničiti broj rezultata, broj ključnih reči i izvori pretrage.
- `priority`: opciona prioritetna razina zadatka za 2.5, ceo broj 0–9, podrazumevano 0.
- `safety_identifier`: stabilan anonimni identifikator krajnjeg korisnika od najviše 64 znaka; koristite heš ili interni anonimni ID, ne unosite ime, e-mail ili broj telefona.
- `execution_expires_after`: vreme isteka zadatka (sekunde), opseg 3600–259200.
- `callback_url`: adresa asinhronog povratnog poziva; nakon postavljanja API odmah vraća `task_id`, a po završetku zadatka rezultat se šalje metodom POST na ovu adresu.
- `async`: opciono; kada se postavi na `true`, interfejs odmah vraća `task_id`, bez potrebe za pružanjem `callback_url`, a zatim se rezultat dobija anketiranjem putem odgovarajućeg interfejsa za upit zadataka.

## Objašnjenje inline parametara

Na kraju prompta `content[].text`, parametri generisanja mogu se proslediti dodavanjem u obliku `--parameter value` (stari način, slaba validacija, pri pogrešnom unosu automatski se koriste podrazumevane vrednosti). Potpuna lista parametara je sledeća:

| Inline parametar       | Odgovarajuće polje              | Opis      | Opseg vrednosti                                                          |
| ---------- | ----------------- | ------- | ------------------------------------------------------------- |
| `--rs`     | `resolution`      | Izlazna rezolucija   | `480p` / `720p` / `1080p`                                     |
| `--rt`     | `ratio`           | Odnos širine i visine     | `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` |
| `--dur`    | `duration`        | Trajanje videa (sekunde) | 2–12                                                          |
| `--frames` | `frames`          | Broj frejmova videa    | Celi broj iz [29, 289] koji zadovoljava 25+4n (**podržava samo serija 1.0**)                       |
| `--fps`    | `framespersecond` | Broj frejmova u sekundi      | Podržava samo `24`                                                      |
| `--seed`   | `seed`            | Nasumično seme    | -1 do 4294967295                                               |
| `--cf`     | `camerafixed`     | Da li je kamera fiksirana | `true` / `false`                                              |
| `--wm`     | `watermark`       | Da li dodati vodeni žig  | `true` / `false`                                              |

> **Preporučena praksa**: direktno koristite odgovarajuća polja najvišeg nivoa u Request Body-ju (kao što su `resolution`, `ratio` itd.); ovo je režim stroge validacije i, kada su parametri pogrešno uneti, vraćaće jasne poruke o grešci, što olakšava rešavanje problema.

## Generisanje videa sa zvukom

Seedance 1.5 Pro i serija 2.x podržavaju generisanje videa sa zvukom putem parametra `generate_audio`:

```json
{
  "model": "doubao-seedance-1-5-pro-251215",
  "content": [
    {
      "type": "text",
      "text": "A girl holds a fox, the wind blows her hair, you can hear the sound of the wind"
    }
  ],
  "generate_audio": true,
  "ratio": "16:9",
  "duration": 5
}
```

Serija 1.0 ne podržava ovaj parametar.

## Seedance 2.5 multimodalno generisanje, uređivanje i produžavanje

`doubao-seedance-2-5-260628` podržava 480p / 720p / 1080p, 4–30 sekundi ili automatsko trajanje, i povećava ograničenje materijala na 30 referentnih slika, 10 referentnih videa i 10 referentnih audio zapisa (ukupno najviše 50). Verzija 2.5 takođe podržava prosleđivanje samo referentnog audio zapisa, bez više zahteva za istovremenim pružanjem slike ili videa.

Za obično multimodalno generisanje može se izostaviti `omni_reference_task_type`, postaviti na `auto` ili eksplicitno postaviti na `reference`. Uređivanje i produžavanje videa moraju proslediti `reference_video`:

```json
{
  "model": "doubao-seedance-2-5-260628",
  "content": [
    {"type": "text", "text": "Replace the sky with a warm sunset while preserving the subject and camera motion."},
    {"type": "video_url", "role": "reference_video", "video_url": {"url": "https://cdn.acedata.cloud/input.mp4"}}
  ],
  "resolution": "720p",
  "ratio": "adaptive",
  "duration": -1,
  "omni_reference_task_type": "edit",
  "output_format": "mov"
}
```

- `reference`: prosledite najmanje jedan `reference_image`, `reference_video` ili `reference_audio`; verzija 2.5 podržava prosleđivanje samo referentnog audio zapisa.
- `edit`: morate koristiti `ratio: adaptive` i `duration: -1`; trajanje izlaza se naplaćuje prema stvarnom rezultatu.
- `extend`: morate koristiti `ratio: adaptive`; `duration` može biti 4–30 ili `-1`.
- `auto`: model automatski bira generisanje, uređivanje ili produžavanje na osnovu prompta i materijala.
- Kada se tip zadatka ne podudara sa materijalom ili promptom, zadatak neće uspeti i vratiće grešku parametra koju je moguće locirati; prilagodite prema navedenim ograničenjima i ponovo pošaljite.

## Prvi frejm videa iz slike

Ako želite zadatak video-iz-slike, parametar `content` prvo mora sadržati stavku čiji je `type` `image_url`, a polje `image_url` mora biti u formatu objekta: `{"url": "https://..."}` ili Base64 formatu `{"url": "data:image/png;base64,..."}`.

> **Napomena**: `image_url` ne podržava direktno prosleđivanje formata stringa (kao što je `"image_url": "https://cdn.acedata.cloud/e724d7f13d.png"`), već se mora koristiti format objekta `"image_url": {"url": "https://..."}`, u suprotnom će biti vraćena greška 400.

Odgovarajući kod:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": [
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/i2v_foxrgirl.png"
            }
        },
        {
            "type": "text",
            "text": "A girl holds a fox in her arms. She opens her eyes and gazes tenderly at the camera, while the fox affectionately holds her back. As the camera slowly pulls away, her hair is gently blown by the wind. --ratio adaptive  --dur 5"
        }
    ],
    "model": "doubao-seedance-1-0-pro-250528"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Prvi i poslednji frejm videa iz slike

Ako želite prvi i poslednji frejm videa iz slike, parametar `content` prvo mora proslediti tip `image_url`, i zasebno postaviti `role` na `first_frame` i `last_frame`, tada možete navesti sledeći sadržaj:

- role: određuje prvi ili poslednji frejm.
- image_url
  - url link slike
    Istovremeno, `content` takođe treba da unese tip `text` kao prompt

Odgovarajući kod:
```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
   "model": "doubao-seedance-1-0-pro-250528",
    "content": [
         {
            "type": "text",
            "text": "360-degree shot"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_first_frame.jpeg"
            },
            "role": "first_frame"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_last_frame.jpeg"
            },
            "role": "last_frame"
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Referenca lika i audio-video multimodalna referenca (Seedance 2.0)

**Serija Seedance 2.0** (`doubao-seedance-2-0-260128`, `doubao-seedance-2-0-fast-260128`, `doubao-seedance-2-0-mini-260615`) podržava `reference_image`, `reference_audio` i `reference_video`. Mogu se koristiti sopstveni ili odobreni materijali za održavanje doslednosti lika, subjekta, radnje, kretanja kamere, zvuka i ritma.

> Otpremajte samo sopstvene ili odobrene materijale stvarnih osoba i likova. Različiti modeli na različite načine podržavaju materijale stvarnih osoba; format zahteva ostaje nepromenjen, a ako materijal ne ispunjava zahteve, biće vraćena jasna greška.

Ključne tačke upotrebe:

- Samo modeli **serije Seedance 2.0** podržavaju `reference_image`; za modele 1.x koristite `first_frame` / `last_frame` (prvi i poslednji kadar za generisanje videa iz slike).
- Prvi kadar za generisanje videa iz slike, prvi i poslednji kadar za generisanje videa iz slike i referenca svih modaliteta su tri međusobno isključiva scenarija: `first_frame` / `last_frame` se ne mogu kombinovati sa `reference_image` / `reference_video` / `reference_audio`.
- Ako želite da navedete prvi i poslednji kadar u referenci svih modaliteta, označite slike kao `reference_image` i u promptu navedite „slika 1 kao prvi kadar“ ili „slika 2 kao poslednji kadar“; ako je potrebno strogo zaključati prvi i poslednji kadar, koristite samo `first_frame` / `last_frame`.
- Ograničenje broja multimodalnih referenci: najviše **9** `image_url` slika; 2.0 takođe podržava `audio_url` (`role` je `reference_audio`, najviše 3 stavke) i `video_url` (`role` je `reference_video`, najviše 3 stavke).
- **Zahtevi za materijale referentnog zvuka (`audio_url`)**: format `wav` / `mp3`; **trajanje pojedinačne stavke 2~15 sekundi**, najviše 3 stavke i **ukupno trajanje ne duže od 15 sekundi**; pojedinačna stavka ne sme biti veća od 15 MB. Prekoračenje opsega trajanja će dovesti do neuspeha u fazi obrade materijala.
- **Zahtevi za materijale referentnog videa (`video_url`)**: format `mp4` / `mov`; **trajanje pojedinačne stavke 2~15 sekundi**, najviše 3 stavke i **ukupno trajanje ne duže od 15 sekundi**.
- Za referentne slike preporučuje se korišćenje fotografija sa **jednom osobom, licem spreda, jasnih i bez prepreka**, što je lice jasnije, sličnost je veća.

### Primer jedan: krupan plan koji zadržava izgled osobe

Prosledite fotografiju lica kako bi se osoba nasmešila i mahnula ka kameri. Odgovarajući kod:

```python

    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedance-2-0-fast-260128",
    "content": [
        {
            "type": "text",
            "text": "The woman looks at the camera, gives a warm natural smile and waves her hand, soft studio lighting, gentle camera push-in."
        },
        {
            "type": "image_url",
            "role": "reference_image",

    ],
    "resolution": "480p",
    "ratio": "9:16",
    "duration": 5
}

response = requests.post(url, json=payload, headers=headers)

```

## Asinhroni povratni poziv

Pošto SeeDance Videos Generation API zahteva duže vreme generisanja (oko 1–2 minuta), možete koristiti asinhroni režim putem polja `callback_url`, kako biste izbegli dugotrajno zauzimanje HTTP veze.

Ukupan proces: klijent prilikom pokretanja zahteva navodi `callback_url`, API odmah vraća odgovor koji sadrži `task_id`; nakon završetka zadatka, platforma šalje rezultat generisanja na `callback_url` u obliku POST JSON-a, a rezultat takođe sadrži `task_id` radi povezivanja.

```json
{
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd"
}
```

Kada je zadatak završen, sadržaj koji platforma šalje na `callback_url` je sledeći:

```json
{
  "success": true,
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd",
  "trace_id": "4a4a3721-00fb-43d2-aff2-3b516ac01a8a",
  "data": {
    "task_id": "cgt-20251222073134-54qcw",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

Polje `task_id` u rezultatu je isto kao ono vraćeno prilikom zahteva, a povezivanje zadataka može se ostvariti putem tog polja.

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Neispravan zahtev, verovatno zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Neispravan zahtev, verovatno zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neovlašćeno, nevažeći ili nedostajući token za autorizaciju.
- `429 too_many_requests`：Previše zahteva, prekoračili ste ograničenje broja zahteva.
- `500 api_error`：Interna greška servera, nešto je pošlo po zlu na serveru.

### Primer odgovora sa greškom

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
