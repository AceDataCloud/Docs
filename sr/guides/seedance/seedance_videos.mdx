Овај документ ће представити упутство за интеграцију SeeDance Videos Generation API, који може генерисати званичне SeeDance видео записе уношењем прилагођених параметара.

## Процес пријаве

Да бисте користили API, прво идите на [SeeDance Videos Generation API](https://platform.acedata.cloud/documents/seedance-videos) страницу и затражите одговарајућу услугу, након уласка на страницу, кликните на дугме „Acquire“, као што је приказано на слици:

![](https://cdn.acedata.cloud/q6ytrc.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, након пријаве и регистрације аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, коју можете користити за API.

## Основна употреба

Прво, упознајте се са основним начином коришћења, што подразумева унос кључних речи `content.text`, типа `content.type=text` и модела `model`, чиме добијате обрађени резултат, конкретан садржај је следећи:

<p><img src="https://cdn.acedata.cloud/seedance_parameters.png" width="500" class="m-auto"></p>

Можете видети да смо подесили Request Headers, укључујући:

- `accept`: у каквом формату желите да примите одговор, овде је написано `application/json`, што значи JSON формат.
- `authorization`: кључ за позивање API, након захтева можете директно изабрати из падајућег менија.

Такође смо подесили Request Body, укључујући:

- `model`: модел за генерисање видео записа, доступне вредности: `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`, `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-lite-t2v-250428`, `doubao-seedance-1-0-lite-i2v-250428`.
- `content`: низ унетих садржаја, `type` може бити `text` или `image_url`.
- `resolution`: резолуција излаза, доступне вредности `480p` / `720p` / `1080p`.
- `ratio`: однос ширине и висине, доступне вредности `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive`.
- `duration`: трајање видео записа (секунде), опсег 2–12.
- `seed`: случајно семе, цело число, -1 до 4294967295.
- `camerafixed`: да ли је камера фиксна, `true` / `false`.
- `watermark`: да ли да се дода водени жиг, `true` / `false`.
- `generate_audio`: да ли да се генерише видео са звуком, `true` / `false`, **само `doubao-seedance-1-5-pro-251215` подржава**.
- `service_tier`: режим инферирања, `default` (онлајн) или `flex` (офлајн, цена је 50% онлајн).
- `return_last_frame`: да ли да се у резултату врати URL последњег кадра видео записа.
- `execution_expires_after`: време истека задатка (секунде), опсег 3600–259200.
- `callback_url`: адреса асинхроног повратка, након подешавања API одмах враћа `task_id`, а када се задатак заврши, резултат ће бити POST-ован на ту адресу.

Након избора, можете приметити да је на десној страни генерисан одговарајући код, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/seedance_request.png" width="500" class="m-auto"></p>

Кликните на дугме „Try“ да бисте тестирали, као што је приказано на горњој слици, добили смо следећи резултат:

```json
{
  "success": true,
  "task_id": "ec22ae22-0140-4033-8c86-a48b536da595",
  "trace_id": "1cc87db0-8ee5-4436-969b-35cc571a9fd5",
  "data": {
    "task_id": "cgt-20251222005129-62fhb",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/f592800a-b87c-4705-8796-cbb8018cae35.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

Враћени резултат има више поља, описана су као:

- `success`, статус тренутног задатка за генерисање видео записа.
- `task_id`, ID тренутног задатка за генерисање видео записа.
- `trace_id`, ID за праћење тренутног задатка за генерисање видео записа.
- `data`, списак резултата тренутног задатка за генерисање видео записа.
  - `task_id`, серверски ID тренутног задатка за генерисање видео записа.
  - `video_url`, линк до тренутног задатка за генерисање видео записа.
  - `status`, статус тренутног задатка за генерисање видео записа.
    - `model`, модел коришћен за генерисање видео записа.

Можете видети да смо добили задовољавајуће информације о видео запису, само треба да добијемо генерисани SeeDance видео на основу URL адресе видео записа у `data`.

Ако желите да генеришете одговарајући код за интеграцију, можете га директно копирати, на пример CURL код је следећи:

```shell
curl -X POST 'https://api.acedata.cloud/seedance/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "content": [{"text":"A kitten yawning at the camera. --rs 720p --rt 16:9 --dur 5 --fps 24 --wm true --seed 11 --cf false","type":"text"}],
  "model": "doubao-seedance-1-0-pro-250528"
}'
```

## Опис параметара унутар текста

На крају кључне речи `content[].text`, можете додати `--parameter value` у формату за пренос параметара (стари начин, слаба валидација, уколико је унос погрешан, аутоматски ће се користити подразумевана вредност). Комплетна листа параметара је следећа:

| Унутрашњи параметар | Одговарајуће поље     | Опис      | Опсег вредности                                                      |
| ------------------- | --------------------- | --------- | ------------------------------------------------------------------- |
| `--rs`              | `resolution`          | Резолуција излаза   | `480p` / `720p` / `1080p`                                         |
| `--rt`              | `ratio`               | Однос ширине и висине     | `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive`   |
| `--dur`             | `duration`            | Трајање видео записа (секунде) | 2–12                                                              |
| `--frames`          | `frames`              | Број кадрова видео записа    | [29, 289] који задовољава 25+4n целих бројева                       |
| `--fps`             | `framespersecond`     | Фрејмова у секунди      | Подржава само `24`                                                  |
| `--seed`            | `seed`                | Случајно семе    | -1 до 4294967295                                                   |
| `--cf`             | `camerafixed`         | Да ли је камера фиксна | `true` / `false`                                                  |
| `--wm`              | `watermark`           | Да ли да се дода водени жиг  | `true` / `false`                                                  |

> **Препоручена пракса**: директно у Request Body користите одговарајућа поља на врху (као што су `resolution`, `ratio` итд.), за режим чврсте валидације, уколико су параметри погрешно унети, враћаће се јасна порука о грешци, што олакшава решавање проблема.

## Генерисање видео записа са звуком

`doubao-seedance-1-5-pro-251215` подржава генерисање видео записа са звуком путем параметра `generate_audio`:

```json
{
  "model": "doubao-seedance-1-5-pro-251215",
  "content": [
    {
      "type": "text",
      "text": "A girl holds a fox, the wind blows her hair, you can hear the sound of the wind"
    }
  ],
  "generate_audio": true,
  "ratio": "16:9",
  "duration": 5
}
```
其他模型 не подржава овај параметар, пренет ће бити игнорисан.

## Слика у видео прва слика

Ако желите да генеришете видео из слике, прво `content` параметар мора да садржи `type` као `image_url`, а `image_url` поље мора бити у формату објекта: `{"url": "https://..."}` или Base64 формат `{"url": "data:image/png;base64,..."}`.

> **Напомена**: `image_url` не подржава директно преношење у формату стринга (као `"image_url": "https://..."`), мора се користити формат објекта `"image_url": {"url": "https://..."}`, у противном ће се вратити 400 грешка.

Одговарајући код:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": [
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/i2v_foxrgirl.png"
            }
        },
        {
            "type": "text",
            "text": "Девојка држи лисицу у рукама. Отвара очи и нежно гледа у камеру, док лисица љубавно држи њу. Како камера полако одмиче, њена коса се нежно помера на ветру. --ratio adaptive  --dur 5"
        }
    ],
    "model": "doubao-seedance-1-0-pro-250528"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Када кликнете на покретање, можете одмах добити резултат, као што је:

```
{
    "success": true,
    "task_id": "dc7cceb5-3c12-4de7-a5f4-abcbba3e8e39",
    "trace_id": "b3b09de3-b7fa-4bb0-88b5-aad4b4a96fd4",
    "data": {
        "task_id": "cgt-20251222072003-x2259",
        "status": "succeeded",
        "video_url": "https://platform.cdn.acedata.cloud/seedance/6afb78b8-5ba8-424f-adcd-69423a700b50.mp4",
        "model": "doubao-seedance-1-0-pro-250528"
    }
}
```

Можете видети да је генерисани ефекат видео из слике, резултат је сличан горњем.

## Слика у видео прва и последња слика

Ако желите да генеришете видео прву и последњу слику, прво параметар `content` мора да пренесе тип `image_url`, и да се одреде `role` као `first_frame` и `last_frame`, можете одредити следећи садржај:

- role: одређује прву или последњу слику.
- image_url
  - url линк на слику
    Такође `content` треба да укључи тип `text` као prompt упутство

Одговарајући код:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
   "model": "doubao-seedance-1-0-pro-250528",
    "content": [
         {
            "type": "text",
            "text": "Снимак из 360 степени"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_first_frame.jpeg"
            },
            "role": "first_frame"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_last_frame.jpeg"
            },
            "role": "last_frame"
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Када кликнете на покретање, можете одмах добити резултат, као што је:

```
{
    "success": true,
    "task_id": "f7096c6c-9430-4392-8201-d259632d7afd",
    "trace_id": "4a4a3721-00fb-43d2-aff2-3b516ac01a8a",
    "data": {
        "task_id": "cgt-20251222073134-54qcw",
        "status": "succeeded",
        "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",
        "model": "doubao-seedance-1-0-pro-250528"
    }
}
```

Можете видети да је генерисани ефекат видео са улогама, резултат је сличан горњем.

## Асинхрони повратни позив

Пошто SeeDance Videos Generation API генерише дуго (око 1-2 минута), можете користити `callback_url` поље за асинхрони режим, избегавајући дуго заузеће HTTP везе.

Целокупни процес: Клијент покреће захтев са одређеним `callback_url`, API одмах враћа одговор који садржи `task_id`; након завршетка задатка, платформа ће генерисати резултат у POST JSON формату и послати на `callback_url`, резултат такође садржи `task_id` ради повезивања.

```json
{
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd"
}
```

Када се задатак заврши, садржај који платформа шаље на `callback_url` је следећи:

```json
{
  "success": true,
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd",
  "trace_id": "4a4a3721-00fb-43d2-aff2-3b516ac01a8a",
  "data": {
    "task_id": "cgt-20251222073134-54qcw",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

Поље `task_id` у резултату је исто као оно које је враћено при захтеву, путем овог поља можете повезати задатке.

## Обрада грешака

Када позивате API, ако наиђете на грешку, API ће вратити одговарајући код грешке и информације. На пример:

- `400 token_mismatched`: Лош захтев, могуће због недостајућих или неважећих параметара.
- `400 api_not_implemented`: Лош захтев, могуће због недостајућих или неважећих параметара.
- `401 invalid_token`: Неправилно, неважећи или недостајући ауторизациони токен.
- `429 too_many_requests`: Превише захтева, прелазите лимит.
- `500 api_error`: Унутрашња грешка сервера, нешто није у реду на серверу.

### Пример грешке у одговору

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
