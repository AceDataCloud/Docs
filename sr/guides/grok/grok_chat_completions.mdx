xAI Grok је веома моћан AI систем за разговор, који може генерисати текуће и природне одговоре у року од неколико секунди само уношењем упитника. Grok се истиче својим јединственим хумористичним стилом и способношћу да добија информације у реалном времену, а данас је Grok постао видљив у многим иновационим областима, а његов утицај се брзо шири. Без обзира на то да ли се ради о свакодневном разговору, креативном писању или техничкој анализи и дебаговању кода, Grok може пружити увидну интелигентну помоћ, доносећи нову димензију подршке у одлучивању и креацији корисника.

Овај документ углавном описује процес коришћења Grok Chat Completion API, који нам омогућава лако коришћење званичних Grok функција за разговор.

## Процес пријаве

Да бисте користили Grok Chat Completion API, прво идите на [Ace Data Cloud контролни панел](https://platform.acedata.cloud/console/applications) да бисте добили ваш API токен, који ћете задржати за резерву.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након тога ћете бити аутоматски враћени на тренутну страницу.

**Један API токен је довољан за позивање свих услуга платформе, без потребе да се за сваку услугу посебно пријављујете.** При првом пријављивању добијате бесплатну квоту, коју можете бесплатно испробати; када вам квота понестане, можете допунити општи баланс на [контролном панелу](https://platform.acedata.cloud/console/coin).

> 📘 Пуна документација: [Grok Chat Completion API →](https://platform.acedata.cloud/documents/grok-chat-completions)

## Основна употреба

Сада можете попунити одговарајуће садржаје на интерфејсу, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/vunnjf.png" width="400" className="m-auto" /></p>

Када први пут користите овај интерфејс, потребно је да попуните најмање три садржаја, један је `authorization`, који можете директно изабрати из падајућег менија. Други параметар је `model`, `model` је категорија модела коју одаберете да користите са Grok званичне веб странице, овде имамо 8 различитих модела, детаље можете видети у моделима које пружамо. Последњи параметар је `messages`, `messages` је низ упитника који уносимо, представља низ који може истовремено да пошаље више упитника, сваки упитник садржи `role` и `content`, где `role` представља улогу питаоца, а ми пружамо три идентификације: `user`, `assistant`, `system`. Други `content` је конкретан садржај нашег питања.

Такође можете приметити да се на десној страни генерише одговарајући код за позив, можете копирати код и директно га покренути, или можете директно кликнути на дугме „Пробај“ за тестирање.

Често коришћени опционални параметри:

- `max_tokens`: ограничава максималан број токена у једном одговору.
- `temperature`: генерише случајност, између 0-2, већа вредност значи веће распршивање.
- `n`: колико кандидата одговора се генерише одједном.

Повратни резултат има више поља, описаних као:

- `id`, ID генерисаног задатка разговора, који служи за јединствено идентификовање овог задатка разговора.
- `model`, одабрани Grok модел.
- `choices`, информације о одговору које Grok даје на упитник.
- `usage`: статистичке информације о токенима за овај упит и одговор.

Унутар `choices` налази се информација о одговору Grok, а унутар `choices` су конкретне информације о одговору Grok, што можете видети на слици.

Можете видети да поље `content` унутар `choices` садржи конкретан садржај одговора Grok.

## Стриминг одговора

Овај интерфејс такође подржава стриминг одговора, што је веома корисно за веб интеграцију, јер омогућава веб страници да реализује ефекат приказивања по словима.

Ако желите да добијете одговор у стриминг формату, можете променити параметар `stream` у заглављу захтева на `true`.

Промените као што је приказано на слици, али код позива мора бити одговарајуће модификован да подржи стриминг одговор.

<p><img src="https://cdn.acedata.cloud/k883qa.png" width="400" className="m-auto" /></p>

Када промените `stream` на `true`, API ће редом враћати одговарајуће JSON податке, а на кодном нивоу морамо направити одговарајуће измене да добијемо редне резултате.

Python пример кода за позив:

```python
import requests

url = "https://api.acedata.cloud/grok/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "grok-3",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Može se videti da u odgovoru postoji mnogo `data`, a `choices` unutar `data` predstavlja najnoviji sadržaj odgovora, što je u skladu sa prethodnim opisom. `choices` su novi sadržaji odgovora, koje možete integrisati u vaš sistem na osnovu rezultata. Takođe, kraj strimovanog odgovora se određuje na osnovu sadržaja `data`; ako je sadržaj `[DONE]`, to znači da je strimovani odgovor u potpunosti završen. Vraćeni `data` rezultat sadrži više polja, koja su opisana na sledeći način:

- `id`, ID generisan za ovaj zadatak dijaloga, koristi se za jedinstvenu identifikaciju ovog zadatka.
- `model`, izabrani Grok model sa zvaničnog sajta.
- `choices`, informacije o odgovoru koje Grok daje na postavljeno pitanje.

JavaScript je takođe podržan, na primer, kod za strimovani poziv u Node.js izgleda ovako:

```javascript
const options = {
  method: "post",
  headers: {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    "model": "grok-3",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": true
  })
};

fetch("https://api.acedata.cloud/grok/chat/completions", options)
  .then(response => response.json())
  .then(response => console.log(response))
  .catch(err => console.error(err));
```

Java primer koda:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "grok-3");
jsonObject.put("messages", [{"role":"user","content":"Hello"}]);
jsonObject.put("stream", true);
MediaType mediaType = "application/json; charset=utf-8".toMediaType();
RequestBody body = jsonObject.toString().toRequestBody(mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/grok/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.print(response.body!!.string())
```

Ostali jezici mogu biti prilagođeni samostalno, princip je isti.

## Višerundni dijalog

Ako želite da integrišete funkciju višerundnog dijaloga, potrebno je da u polje `messages` pošaljete više pitanja, primer sa više pitanja je prikazan na slici ispod:

<p><img src="https://cdn.acedata.cloud/t8cya8.png" width="400" className="m-auto" /></p>

Python primer poziva:

```python
import requests

url = "https://api.acedata.cloud/grok/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "grok-3",
    "messages": [{"role":"user","content":"Hello"},{"role":"assistant","content":"What model are you?"},{"role":"user","content":"What did I just say?"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Obrada grešaka

Prilikom poziva API-ja, ako dođe do greške, API vraća odgovarajući kod greške i poruku. Na primer:

- `400 token_mismatched`: Loš zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Loš zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neautorizovano, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, prekoračen je limit zahteva.
- `500 api_error`: Interna greška servera, nešto je pošlo po zlu na serveru.
