xAI Grok je veoma moćan AI sistem za razgovor, koji može generisati tečne i prirodne odgovore u samo nekoliko sekundi jednostavnim unosom ključnih reči. Grok se izdvaja u industriji svojom jedinstvenom humorističnom stilom i sposobnošću prikupljanja informacija u realnom vremenu, a danas se Grok ističe u više inovativnih oblasti, a njegov uticaj se brzo širi. Bilo da se radi o svakodnevnom razgovoru, kreativnom pisanju, tehničkoj analizi ili debagovanju koda, Grok može pružiti uvidom bogatu inteligentnu pomoć, donoseći novu dimenziju podrške korisničkim odlukama i kreacijama.

Ovaj dokument uglavnom opisuje proces korišćenja Grok Chat Completion API, omogućavajući nam da lako koristimo zvanične Grok funkcije razgovora.

## Proces prijave

Da biste koristili Grok Chat Completion API, prvo možete otići na [Grok Chat Completion API](https://platform.acedata.cloud/documents/faf08b59-36aa-4d26-b5d9-a18f113cc2be) stranicu i kliknuti na dugme „Acquire“ da dobijete potrebne akreditive za zahtev:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Osnovna upotreba

Sledeće možete popuniti odgovarajući sadržaj na interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/vunnjf.png" width="400" className="m-auto" /></p>

Prilikom prve upotrebe ovog interfejsa, potrebno je da popunite najmanje tri sadržaja, jedan je `authorization`, koji možete direktno odabrati iz padajuće liste. Drugi parametar je `model`, `model` je kategorija modela koju biramo da koristimo sa Grok zvanične stranice, ovde imamo 8 vrsta modela, a više detalja možete videti u modelima koje pružamo. Poslednji parametar je `messages`, `messages` je niz naših unosa pitanja, koji predstavlja niz koji može istovremeno učitati više pitanja, a svako pitanje sadrži `role` i `content`, pri čemu `role` označava ulogu postavljača pitanja, a mi pružamo tri identiteta: `user`, `assistant`, `system`. Drugi `content` je konkretan sadržaj našeg pitanja.

Takođe možete primetiti da se sa desne strane generiše odgovarajući kod za pozivanje, koji možete kopirati i direktno pokrenuti, ili možete jednostavno kliknuti na dugme „Try“ za testiranje.

Uobičajeni opcioni parametri:

- `max_tokens`: ograničava maksimalan broj tokena za jedan odgovor.
- `temperature`: generiše slučajnost, između 0-2, veća vrednost znači veću disperziju.
- `n`: koliko kandidatskih odgovora generisati odjednom.

Vraćeni rezultat sadrži više polja, koja su opisana u nastavku:

- `id`, ID generisanog zadatka razgovora, koji se koristi za jedinstvenu identifikaciju ovog zadatka razgovora.
- `model`, odabrani Grok model.
- `choices`, informacije o odgovorima koje Grok daje na postavljena pitanja.
- `usage`: statističke informacije o tokenima za ovaj Q&A.

U okviru `choices` se nalaze informacije o odgovorima Groka, a unutar `choices` su konkretne informacije o odgovorima Groka, što možete videti na slici.

Možete primetiti da `content` polje unutar `choices` sadrži konkretan sadržaj odgovora Groka.

## Tok odgovora

Ovaj interfejs takođe podržava tok odgovora, što je veoma korisno za integraciju sa web stranicama, omogućavajući da se efekat prikazuje reč po reč.

Ako želite da dobijete odgovor u toku, možete promeniti `stream` parametar u zaglavlju zahteva na `true`.

Izmena je prikazana na slici, ali kod poziva mora biti odgovarajuće izmenjen da bi podržao tok odgovora.

<p><img src="https://cdn.acedata.cloud/k883qa.png" width="400" className="m-auto" /></p>

Nakon što promenite `stream` na `true`, API će vraćati odgovarajuće JSON podatke red po red, a na kodnom nivou moramo napraviti odgovarajuće izmene da bismo dobili rezultate red po red.

Python uzorak koda za poziv:

```python
import requests

url = "https://api.acedata.cloud/grok/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "grok-3",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Možete videti da u odgovoru ima mnogo `data`, a `data` unutar `choices` predstavlja najnoviji sadržaj odgovora, koji je u skladu sa prethodno predstavljenim sadržajem. `choices` su novi odgovori, koje možete povezati sa vašim sistemom. Takođe, završetak strimovanog odgovora se određuje na osnovu sadržaja `data`, ako je sadržaj `[DONE]`, to znači da je strimovani odgovor potpuno završen. Vraćeni `data` rezultati imaju više polja, koja su objašnjena u nastavku:

- `id`, ID koji generiše ovu razgovornu zadatak, koristi se za jedinstveno identifikovanje ovog razgovora.
- `model`, odabrani Grok model sa zvanične stranice.
- `choices`, informacije o odgovorima koje Grok daje na postavljena pitanja.

JavaScript je takođe podržan, na primer, kod za strimovano pozivanje u Node.js je sledeći:

```javascript
const options = {
  method: "post",
  headers: {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    "model": "grok-3",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": true
  })
};

fetch("https://api.acedata.cloud/grok/chat/completions", options)
  .then(response => response.json())
  .then(response => console.log(response))
  .catch(err => console.error(err));
```

Java uzorak koda:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "grok-3");
jsonObject.put("messages", [{"role":"user","content":"Hello"}]);
jsonObject.put("stream", true);
MediaType mediaType = "application/json; charset=utf-8".toMediaType();
RequestBody body = jsonObject.toString().toRequestBody(mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/grok/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.print(response.body!!.string())
```

Ostali jezici mogu se prepraviti na sličan način, princip je isti.

## Višekratni razgovor

Ako želite da povežete funkciju višekratnog razgovora, potrebno je da u `messages` polje pošaljete više pitanja, konkretni primeri više pitanja su prikazani na sledećoj slici:

<p><img src="https://cdn.acedata.cloud/t8cya8.png" width="400" className="m-auto" /></p>

Python uzorak poziva:

```python
import requests

url = "https://api.acedata.cloud/grok/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "grok-3",
    "messages": [{"role":"user","content":"Hello"},{"role":"assistant","content":"What model are you?"},{"role":"user","content":"What did I just say?"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
