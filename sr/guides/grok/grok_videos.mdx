Овај документ ће представити упутство за интеграцију Grok Videos Generation API, који може генерисати Grok Imagine (xAI) видео записе на основу унетих текстуалних упутстава, унетих слика и опционалних референтних слика.

## Процес пријаве

Да бисте користили Grok Videos Generation API, прво идите на [Ace Data Cloud контролни панел](https://platform.acedata.cloud/console/applications) да добијете ваш API токен, који ћете задржати за каснију употребу.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након тога ћете бити аутоматски враћени на тренутну страницу.

**Један API токен је довољан за позивање свих услуга платформе, није потребно посебно пријављивати за сваку услугу.** При првом пријављивању добијате бесплатну квоту, можете бесплатно тестирати; када вам квота понестане, можете допунити општи баланс на [контролном панелу](https://platform.acedata.cloud/console/coin).

> 📘 Пуна документација: [Grok Videos Generation API →](https://platform.acedata.cloud/documents/grok-videos)

## Опис модела

Овај API бира горње крајње тачке на основу суфикса имена модела: `:reverse` иде на брзу/стандардну крајњу тачку (јефтиније), `:official` иде на званичну крајњу тачку (виша квалитета, наплаћује се по секунди излаза). Подржава четири модела:

- `grok-imagine-video-1.5-fast:reverse` (подразумевано): подржава видео генерисан текстом (само пренесите `prompt`) и видео генерисан сликом (пренесите `image_url`), трајање 6–30 секунди, наплаћује се по трајању, најјефтиније.
- `grok-imagine-video:reverse`: подржава видео генерисан текстом и сликом, трајање 1–15 секунди, наплаћује се по секунди излаза.
- `grok-imagine-video:official`: званична крајња тачка, подржава видео генерисан текстом и сликом, трајање 1–15 секунди, наплаћује се по секунди излаза, виша квалитета.
- `grok-imagine-video-1.5:official`: званична крајња тачка, **подржава само видео генерисано сликом**, **мора** се пренети `image_url`, трајање 1–15 секунди, подржава до `1080p`, наплаћује се по секунди излаза.

## Основна употреба

Прво се упознајте са основним начином коришћења, унесите упутства `prompt`, модел `model` и друге параметре, и можете генерисати одговарајући видео.

Можете видети да смо овде поставили заглавља захтева, укључујући:

- `accept`: каквог формата желите да примите одговор, овде је написано `application/json`, што значи JSON формат.
- `authorization`: кључ за позивање API-а, након пријаве можете директно изабрати.

Такође смо поставили тело захтева, укључујући:

- `prompt`: текстуално упутство које описује садржај видео записа који желите да генеришете. Обавезно за видео генерисан текстом; опционално када преносите `image_url`.
- `model`: модел за генерисање видео записа, опционално `grok-imagine-video-1.5-fast:reverse` (подразумевано), `grok-imagine-video:reverse`, `grok-imagine-video:official` или `grok-imagine-video-1.5:official`.
- `image_url`: линк на улазну слику за видео генерисано сликом. Када је `model` `grok-imagine-video-1.5:official`, **обавезно**.
- `reference_image_urls`: опционални низ линкова на референтне слике, који се користе за усмеравање стила или садржаја видео записа.
- `aspect_ratio`: однос ширине и висине генерисаног видео записа, опционално `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`.
- `resolution`: излазна резолуција, опционално `480p` (подразумевано), `720p` или `1080p`.
- `duration`: трајање генерисаног видео записа (секунде). `grok-imagine-video-1.5-fast:reverse` опсег 6–30, остали модели опсег 1–15, подразумевано 6. Препоручује се коришћење 6 секунди или 10 секунди, ова два стандардна трајања су релативно стабилна.
- `callback_url`: адреса за асинхрони повратни позив, након подешавања API ће одмах вратити `task_id`, а када се задатак заврши, резултат ће бити послат на ту адресу.
- `async`: опционално, ако је подешено на `true`, интерфејс одмах враћа `task_id`, без потребе за пружањем `callback_url`, а затим можете добити резултате путем одговарајућег интерфејса за упит задатка.

Кликните на дугме „Пробај“ да бисте тестирали, а добијени резултат ће изгледати слично следећем:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video-1.5-fast:reverse:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
      "state": "succeeded"
    }
  ]
}
```

Враћени резултат има више поља, описана као:

- `success`: да ли је захтев за генерисање видео записа био успешан.
- `task_id`: ID задатка за генерисање видео записа.
- `trace_id`: ID за праћење овог захтева, коришћен за решавање проблема.
- `data`: листа резултата генерисаног видео записа.
  - `id`: јединствени идентификатор генерисаног видео записа.
  - `video_url`: линк на генерисани видео.
  - `state`: статус задатка за генерисање видео записа, опционално `pending` / `succeeded` / `failed`.

Потребно је само да добијете генерисани видео на основу линка `video_url` из `data` у резултату.

Одговарајући CURL код изгледа овако:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Кинематографска сцена мачића који јури лептира у осунчаном врту",
  "model": "grok-imagine-video-1.5-fast:reverse",
  "resolution": "480p",
  "duration": 6
}'
```

Одговарајући Python код изгледа овако:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "Кинематографска сцена мачића који јури лептира у осунчаном врту",
    "model": "grok-imagine-video-1.5-fast:reverse",
    "resolution": "480p",
    "duration": 6
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Видео генерисан сликом

Ако желите да генеришете видео на основу улазне слике, можете пренети `image_url`. Када користите `grok-imagine-video-1.5:official`, овај параметар мора бити обезбеђен:

```json
{
  "prompt": "Лик се полако окреће и осмехује се камери",
  "model": "grok-imagine-video-1.5:official",
  "image_url": "https://cdn.acedata.cloud/5hmkdg.jpg",
  "resolution": "720p",
  "duration": 6
}
```

## Упутство за референтне слике

Ако желите да користите једну или више референтних слика за усмеравање стила или садржаја генерисаног видео записа, можете пренети низ линкова на слике у `reference_image_urls`:

```json
{
  "prompt": "Лик плеше у истом уметничком стилу",
  "model": "grok-imagine-video-1.5-fast:reverse",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/vunnjf.png"
  ]
}
```

## Асинхрони повратни позив
Video generisanje zahteva određeno vreme obrade. Ako ne želite da zadržavate dug povezivanje čekajući, možete proslediti `callback_url`, u tom slučaju API će odmah vratiti `task_id`, a kada zadatak bude završen, konačni rezultat će biti POST-ovan na tu adresu:

```json
{
  "prompt": "Kinematografski kadar mačića koji juri leptira u osunčanom vrtu",
  "model": "grok-imagine-video-1.5-fast:reverse",
  "duration": 6,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

Odmah vraćeni rezultat je sledeći:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Proveravanje rezultata zadatka

Ako ste koristili asinhroni povratni poziv ili želite aktivno da proverite status zadatka, možete putem [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) na osnovu `task_id` proveriti najnoviji status i rezultat zadatka.

## Objašnjenje naplate

Način naplate za ovu uslugu zavisi od `model`:

- `grok-imagine-video-1.5-fast:reverse`: naplaćuje se po dužini, nezavisno od rezolucije — `6–10` sekundi, `11–20` sekundi, `21–30` sekundi odgovaraju različitim cenovnim razredima.
- `grok-imagine-video:reverse`: naplaćuje se po „izlaznim sekundama“, ukupna cena = jedinična cena × `duration`.
- `grok-imagine-video:official` i `grok-imagine-video-1.5:official`: zvanične tačke, naplaćuje se po „izlaznim sekundama“, što je viša rezolucija, to je viša jedinična cena; zvanični modeli će se naplatiti čak i ako revizija sadržaja ne uspe.

Specifične jedinične cene su navedene na stranici sa cenama. Neuspešni zahtevi se ne naplaćuju i ne koriste besplatne kvote.

## Obrada grešaka

Kada dođe do problema sa zahtevom, API će vratiti odgovarajući kod greške i objašnjenje, a najčešći su:

- `400`: Parametri zahteva su pogrešni, na primer, video generisanje nedostaje `prompt`, ili `grok-imagine-video-1.5:official` nedostaje `image_url`, ili je `duration` van opsega (za `grok-imagine-video-1.5-fast:reverse` je 6–30, ostali modeli su 1–15).
- `401`: Neuspešna autentifikacija, token je nevažeći ili se ne poklapa sa API-jem.
- `403`: Nedovoljno sredstava, ili ključne reči su odbijene zbog revizije sadržaja.
- `429`: Previše čestih zahteva, molimo pokušajte ponovo kasnije.
- `500`: Neuspešno generisanje videa ili greška u usluzi.
