Главна функција Grok Tasks API је да омогући проверу статуса извршења задатка путем ID-a задатка генерисаног помоћу Grok Videos Generation API.

Овај документ ће детаљно описати упутства за интеграцију Grok Tasks API, помажући вам да лако интегришете и проверите статус извршења задатака Grok Videos Generation API.

## Процес пријаве

Да бисте користили Grok Videos Generation API, прво идите на [Ace Data Cloud контролни панел](https://platform.acedata.cloud/console/applications) да бисте добили ваш API Token, који ћете задржати за каснију употребу.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након тога ћете бити аутоматски враћени на тренутну страницу.

**Један API Token је довољан за позивање свих услуга платформе, без потребе да се за сваку услугу посебно пријављујете.** При првом захтеву добићете бесплатну квоту, коју можете бесплатно испробати; када вам квота понестане, можете допунити општи баланс на [контролном панелу](https://platform.acedata.cloud/console/coin).

> 📘 Пуна документација: [Grok Videos Generation API →](https://platform.acedata.cloud/documents/grok-videos)

## Пример захтева

Grok Tasks API може се користити за проверу резултата Grok Videos Generation API.

### Постављање заглавља захтева и тела захтева

**Request Headers** укључује:

- `accept`：одређује да се примају одговори у JSON формату, овде се попуњава `application/json`.
- `authorization`：кључ за позивање API-а, након пријаве можете директно изабрати.

**Request Body** укључује:

- `id`：ID задатка који желите да проверите.
- `action`：начин операције над задатком, за појединачну проверу попуните `retrieve`.

### CURL код пример

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Пример одговора

Након успешног захтева, API ће вратити детаље о овом задатку. У томе, поље `request` је тело захтева при покретању задатка, а поље `response` је тело одговора након завршетка задатка, на пример:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262729.623,
  "elapsed": 7.8,
  "request": {
    "prompt": "Kinematografski kadar mačića koji juri leptira u osunčanom vrtu",
    "model": "grok-imagine-video-1.5-fast:reverse",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video-1.5-fast:reverse:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Опис поља је следећи:

- `id`：ID генерисаног задатка, који служи за јединствено идентификовање овог генерисаног задатка.
- `request`：информације о захтеву у задатку.
- `response`：информације о одговору у задатку.
- `created_at`：време креирања задатка, Unix временски жиг (секунде, флотантно).
- `started_at`：време почетка извршења задатка, Unix временски жиг (секунде, флотантно).
- `finished_at`：време завршетка задатка, Unix временски жиг (секунде, флотантно). Ово поље се не враћа ако задатак није завршен.
- `elapsed`：време извршења задатка, у секундама (флотантно, задржава 3 децималне места). Ово поље се не враћа ако задатак није завршен.

## Пакетна операција упита

Када желите да проверите детаље за више ID-a задатака, поставите `action` на `retrieve_batch`, и пренесите низ ID-a задатака преко `ids`:

**Request Body** укључује:

- `ids`：низ ID-a задатака које желите да проверите.
- `action`：начин операције над задатком, за пакетну проверу попуните `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
