## 1. Dobijanje API ključa

Otvorite [Ace Data Cloud listu aplikacija](https://platform.acedata.cloud/console/applications), uđite u dostupne aplikacije i kopirajte API ključ.

![Dobijanje Ace Data Cloud API ključa](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Konfiguracija

Kilo CLI čita `kilo.jsonc`, i uzima API ključ iz shell-a u kojem je pokrenut CLI.

U `~/.config/kilo/kilo.jsonc` upišite:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Zatim u trenutnom shell-u izvezite Token:

```bash
export ACEDATACLOUD_API_KEY="LEPITE_VAŠ_ACEDATACLOUD_API_TOKEN_OVDE"
```

## 3. Verifikacija

```bash
kilo run -m acedatacloud/MODEL_ID "Odgovori samo OK"
```

Ako CLI ne može da pročita Token, proverite da li je promenljiva već `export`-ovana, a ne samo napisana u nepokrenutom `.env` fajlu.
