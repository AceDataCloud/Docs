## 1. Preuzimanje API ključa

Otvorite [listu aplikacija Ace Data Cloud](https://platform.acedata.cloud/console/applications), uđite u dostupnu aplikaciju i kopirajte API ključ.

![Preuzimanje Ace Data Cloud API ključa](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Konfiguracija

Roo Code zvanično pruža OpenAI-compatible Provider i zahteva da model podržava nativno OpenAI tools/function calling.

1. Otvorite Roo Code podešavanja u VS Code-u.
2. Postavite **API Provider** na **OpenAI Compatible**.
3. Popunite:

| Polje       | Vrednost                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | Upravo kopirani API ključ                  |
| Model ID | ID modela izabran u čarobnjaku za Coding konfiguraciju         |

![Roo Code OpenAI Compatible interfejs za konfiguraciju](https://cdn.acedata.cloud/b6a0e7156438.png)

Zatim podesite context, max output, sliku i computer-use opcije prema stvarnim mogućnostima modela. Na kraju sačuvajte konfiguraciju i ponovo učitajte VS Code.

## 3. Provera

Prvo pošaljite `Reply only OK`, zatim neka Roo Code pročita test fajl. Ako je običan razgovor uspešan, ali Agent alat ne uspe, zamenite model onim koji podržava nativni tool calling i potvrdite da kompatibilni endpoint može ispravno strimovati parametre i rezultate alata.
