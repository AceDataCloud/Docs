Continue podržava OpenAI-kompatibilni API. Da bi se fiksirao put do Chat Completions, potrebno je eksplicitno postaviti `useResponsesApi: false`.

## Konfiguracija

U lokalnu YAML konfiguraciju Continue dodajte:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

U Continue-ovom upravljanju tajnama sačuvajte `ACEDATACLOUD_API_KEY`, ne šaljite pravi Token u konfiguraciju projekta. JSON konfiguracija Continue-a je već zastarela, nova konfiguracija koristi YAML.

## Verifikacija

Ponovo učitajte VS Code, otvorite Continue bočnu traku, izaberite model u Local Config i pošaljite `Reply only OK`; zatim ponovo izvršite zadatak za čitanje datoteka. Ako je zahtev greškom poslat na `/responses`, proverite da li se `useResponsesApi: false` nalazi unutar te stavke modela.
