Qwen Code koristi `~/.qwen/settings.json` za konfiguraciju prilagođenog provajdera `modelProviders`. Ovdje se fiksno koristi OpenAI-kompatibilni protokol.

## Konfiguracija

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud` mora biti niz. Stavke provajdera su nezavisno konfigurirane i neće automatski naslediti druge gornje kontekste, zaglavlja ili parametre tela.

## Verifikacija

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Reply only OK"
```

Uđite i pošaljite `Reply only OK`, zatim ponovo pokrenite alat za čitanje datoteka. Strogo kompatibilni krajnji tački ako odbiju format rezultata alata, proverite trenutnu verziju Qwen Code-a i zvanične upute o kompatibilnosti.
