## 1. Preuzmite API Key

Otvorite [listu Ace Data Cloud aplikacija](https://platform.acedata.cloud/console/applications), uđite u dostupnu aplikaciju i kopirajte API Key.

![Preuzimanje Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Dodajte Custom provider

U Kilo Code otvorite **Settings → Providers**, kliknite na **Custom provider**, a zatim popunite:

| Polje           | Vrednost                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------- |
| Provider ID  | `acedatacloud`                                                                                 |
| Display name | `AceDataCloud`                                                                                 |
| Provider API | `OpenAI Compatible`                                                                            |
| Base URL     | `https://api.acedata.cloud/v1`                                                                 |
| API key      | Upravo kopirani API Key                                                                        |
| Models       | Idite u [katalog modela](https://platform.acedata.cloud/models) da pogledate i dodate naziv modela koji želite da koristite, na primer `claude-opus-5`, `gpt-6-sol` |

![Interfejs za konfiguraciju Kilo Code Custom provider](https://cdn.acedata.cloud/94eb5abd7a6f.png)

Ovde je `id` modela naziv modela koji koristi parametar `model` u API zahtevu, a ne UUID usluge ili API-ja. Možete ga prvo pogledati u [katalogu modela](https://platform.acedata.cloud/models); pri preciznoj proveri, kopirajte ga tačno iz niza `data` u odgovoru `/v1/models`, nemojte ga sami nagađati ili skraćivati.

Kliknite na **Submit**, a model će se pojaviti u biraču. Kada je potrebno deljenje u timu ili detaljnija konfiguracija, možete i da uredite korisnički `~/.config/kilo/kilo.jsonc` ili projektni `./kilo.jsonc` prema zvaničnoj dokumentaciji.

## 3. Provera

Izaberite `acedatacloud/MODEL_ID` i pošaljite `Reply only OK`, a zatim izvršite još jednu operaciju samo za čitanje datoteke. Ako se model ne pojavi, proverite da li je Provider poslat, da li se naziv modela potpuno podudara sa `id` iz kataloga i da li je Base URL ispravan.
