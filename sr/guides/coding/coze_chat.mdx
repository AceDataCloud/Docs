Coze zvanična dokumentacija za prilagođene modele podržava OpenAI Chat API. Različite verzije Coze zakupaca mogu imati različite načine obrade putanja, strimskog izlaza i poziva alata, pa molimo proverite stavku po stavku prilikom prvog povezivanja.

## Konfiguracija

1. Uđite u upravljanje modelima Coze i dodajte prilagođeni model.
2. Protokol odaberite OpenAI Chat API.
3. Osnovni API URL unesite `https://api.acedata.cloud/v1`.
4. API ključ unesite svoj Ace Data Cloud API token.
5. Model unesite tačan ID modela koji podržava Chat Completions u direktorijumu modela.
6. Sačuvajte i završite testiranje veze sa Coze.
7. U Bot/Agent pošaljite `Reply only OK`, a zatim ponovo testirajte poziv alata.

## Trenutne granice

- Različite Coze oblasti, verzije ili paketi mogu prikazivati različite obrasce.
- Osnovni API URL treba koristiti osnovni, nemojte ponovo dodavati `/chat/completions`; ako trenutni UI jasno zahteva potpuni API URL, oslonite se na uputstva obrasca.
- Chat Completions, Responses i Anthropic Messages su tri nezavisne rute i ne mogu se međusobno zamenjivati za verifikaciju.
