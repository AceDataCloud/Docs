## 1. Preuzmite API Key

Otvorite [listu aplikacija Ace Data Cloud](https://platform.acedata.cloud/console/applications), uđite u dostupnu aplikaciju i kopirajte API Key.

![Preuzmite Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalirajte OpenCode

```bash
curl -fsSL https://opencode.ai/install | bash
```

Možete koristiti i npm:

```bash
npm install -g opencode-ai
```

## 3. Postavite API Key

```bash
export ACEDATACLOUD_API_KEY="vaš API Key"
```

Ako želite da važi dugoročno, dodajte ovaj red u `~/.zshrc` ili `~/.bashrc`, a zatim ponovo otvorite terminal.

## 4. Konfigurišite Provider

Uredite `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ace Data Cloud",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  }
}
```

Posetite [katalog modela](https://platform.acedata.cloud/models) da biste videli nazive modela (na primer `claude-opus-5`, `gpt-6-sol`) i zamenite sve `MODEL_ID` istim nazivom; za preciznu proveru, koristite vrednost `id` iz odgovora `/v1/models`. Ta vrednost je naziv modela koji koristi API parametar `model`, a nije UUID usluge ili API-ja. Ace Data Cloud ovde koristi Chat Completions, pa je adapter `@ai-sdk/openai-compatible`.

## 5. Proverite i pokrenite

```bash
opencode auth list
opencode models acedatacloud
opencode run --model acedatacloud/MODEL_ID "Reply only OK"
```

Zatim pokrenite `opencode` u direktorijumu projekta. Ako se model ne pojavi, proverite putanju konfiguracione datoteke, JSON sintaksu i promenljive okruženja; 401 znači da je Key nevažeći ili nije izvezen.

IDE ekstenzija ponovo koristi istu OpenCode runtime konfiguraciju, pogledajte [OpenCode IDE Extension](https://platform.acedata.cloud/documents/opencode-ide-integration).
