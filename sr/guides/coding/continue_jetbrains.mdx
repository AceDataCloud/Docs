Continue-ов JetBrains додатак користи исти YAML формат модела као и VS Code; конфигурација и тајне морају припадати кориснику који покреће JetBrains додатак.

## Конфигурација

У Continue-овој локалној YAML конфигурацији додајте:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

У Continue тајнама сачувајте `ACEDATACLOUD_API_KEY`. За Remote Development сценарије, конфигурација мора бити на хосту на коме се додатак заиста извршава.

## Верификација

Рестартујте JetBrains IDE, отворите Continue алатну траку, изаберите Local Config модел и пошаљите `Reply only OK`; затим поново извршите задатак само за читање датотека. Ако и даље користите стари модел, рестартујте удаљени backend и проверите YAML увлачење.
