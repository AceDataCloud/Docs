## 1. Preuzimanje API ključa

Otvorite [listu aplikacija Ace Data Cloud](https://platform.acedata.cloud/console/applications), uđite u dostupnu aplikaciju i kopirajte API Key.

![Preuzimanje Ace Data Cloud API ključa](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Dodavanje modela

U WorkBuddy-ju idite na **Podešavanja → Modeli → Prilagođeni modeli → Dodaj model**, a zatim popunite:

| Polje       | Vrednost                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------ |
| Provider | `Custom`                                                                                         |
| Adresa interfejsa     | `https://api.acedata.cloud/v1`                                                                   |
| API Key  | Upravo kopirani API Key                                                                                    |
| Naziv modela     | Idite u [katalog modela](https://platform.acedata.cloud/models) da pogledate i tačno unesite naziv modela koji želite da pozovete, na primer `claude-opus-5` ili `gpt-6-sol` |
| Prilagođeni protokol    | Isključeno                                                                                               |

![Interfejs za konfiguraciju WorkBuddy Custom Provider-a](https://cdn.acedata.cloud/189027b68722.png)

> `id` ovde je naziv modela koji se koristi za parametar `model` u API zahtevu, a nije UUID usluge, API-ja ili Application-a, niti prilagođeni prikazani naziv. `ds-4.0` možete uneti samo kada katalog u realnom vremenu vrati `{"id":"ds-4.0"}`; ako ga nema u katalogu, trenutno nije dostupan, nemojte nagađati niti skraćivati.

Najpre možete pogledati dostupne modele u [katalogu modela](https://platform.acedata.cloud/models); ako je potrebno da potvrdite tačan naziv koji mogu pozvati trenutni Coding kredencijali, zatim upotrebite upravo kopirani API Key da upitate API katalog:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

U nizu `data` u odgovoru pronađite ciljni model i doslovno kopirajte njegovu vrednost `id`. Prekidače za mogućnosti konfigurišite prema stvarnoj podršci tog modela.

Kada je „prilagođeni protokol” isključen, WorkBuddy će dopuniti putanju prema pravilima OpenAI Chat Completions. Napredne prekidače za mogućnosti (alati, slike, rezonovanje) uključite samo prema stvarnim mogućnostima izabranog modela; ako niste sigurni, najpre zadržite podrazumevane vrednosti.

## 3. Provera

Nakon čuvanja, u biraču modela za razgovor izaberite upravo dodati model i pošaljite `Odgovori samo OK`. Zatim izvršite zadatak samo za čitanje datoteka ili alata da potvrdite da su potrebne mogućnosti dostupne; zapise poziva možete pogledati u [istoriji korišćenja](https://platform.acedata.cloud/console/usages).

Ako se model ne pojavi, potvrdite da je konfiguracija sačuvana i omogućena; za 401 proverite Key; za 404 proverite da li se uneti naziv modela potpuno podudara sa `id` iz kataloga, kao i da li je adresa interfejsa ispravna. Zvanično uputstvo za WorkBuddy navodi da se Key čuva u lokalnoj konfiguraciji, ali se sadržaj zahteva i dalje šalje konfigurisanoj usluzi modela.
