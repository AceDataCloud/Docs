Coze zvanična dokumentacija za prilagođene modele podržava Anthropic Messages API. Različite verzije Coze zakupaca mogu drugačije obraditi Header, putanju, streaming i pozive alata, pa molimo proverite svaki deo u nastavku prilikom prvog povezivanja.

## Konfiguracija

1. Uđite u upravljanje modelima Coze i dodajte novi prilagođeni model.
2. Protokol odaberite Anthropic Messages API.
3. Osnovni API URL unesite `https://api.acedata.cloud`.
4. API ključ unesite svoj Ace Data Cloud API Token.
5. Model unesite tačan ID modela koji podržava Anthropic Messages u direktorijumu modela.
6. Sačuvajte i završite testiranje veze sa Coze.
7. U Bot/Agent pošaljite `Reply only OK`, a zatim ponovo testirajte poziv alata.

## Trenutne granice

- Različite Coze oblasti, verzije ili paketi mogu prikazivati različite obrasce.
- Osnovni API URL ne bi trebao ponovo dodavati `/v1/messages`; ako trenutni UI jasno zahteva potpuni API URL, oslonite se na uputstva obrasca.
- Poruke, Chat Completions i Odgovori su tri nezavisne rute i ne mogu se međusobno zameniti za verifikaciju.
