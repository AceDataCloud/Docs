## 1. Preuzimanje API ključa

Otvorite [listu Ace Data Cloud aplikacija](https://platform.acedata.cloud/console/applications), uđite u dostupnu aplikaciju i kopirajte API ključ.

![Preuzimanje Ace Data Cloud API ključa](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Konfigurisanje Cline-a

Instalirajte i otvorite Cline u VS Code-u, zatim preko dugmeta za podešavanja u Cline panelu uđite u konfiguraciju Provider-a i popunite:

| Polje                                | Vrednost                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| API Provider                      | `OpenAI Compatible`                                                                            |
| Base URL                          | `https://api.acedata.cloud/v1`                                                                 |
| API Key                           | Upravo kopirani API ključ                                                                                  |
| Model ID                          | Idite u [katalog modela](https://platform.acedata.cloud/models) da proverite i unesite naziv ciljnog modela bez izmene, na primer `claude-opus-5`、`gpt-6-sol` |
| Custom Headers                    | Ostavite prazno                                                                                             |
| Set Azure API version             | Ostavite prazno                                                                                             |
| Use Azure Identity Authentication | Isključite                                                                                             |

![Cline OpenAI Compatible interfejs za konfiguraciju](https://cdn.acedata.cloud/8f356c2f1378.png)

`Model ID` je naziv modela koji se koristi u parametru `model` u API zahtevu, a nije UUID usluge ili API-ja i ne može se samostalno skraćivati. Najpre ga možete proveriti u [katalogu modela](https://platform.acedata.cloud/models); ako je potrebna precizna provera, zatim koristite trenutni API ključ da pošaljete zahtev `GET https://api.acedata.cloud/v1/models` i iz niza `data` u odgovoru kopirajte vrednost `id` ciljnog modela.

Ostala podešavanja mogućnosti modela za sada ostavite podrazumevana; kada su potrebne slike ili veći kontekst, zatim ih prilagodite stvarnim mogućnostima izabranog modela.

## 3. Verifikacija

Nakon čuvanja kreirajte novi zadatak i pošaljite `Odgovori samo sa OK`. Zatim zatražite od Cline-a da pročita test fajl, kako biste potvrdili da model podržava pozivanje alata; evidencija poziva može se pogledati u [istoriji korišćenja](https://platform.acedata.cloud/console/usages).

401 obično znači da je ključ pogrešan; 404 obično znači da Base URL nije ispravan ili da uneti Model ID nije potpuno isti kao `id` u katalogu. Ako model može da razgovara, ali ne može da upravlja fajlovima, proverite mogućnost tog modela za pozivanje alata.
