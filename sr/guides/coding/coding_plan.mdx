## Dinamički katalog modela

Možete prvo otvoriti [katalog modela](https://platform.acedata.cloud/models) da biste videli trenutne nazive modela, na primer `claude-opus-5`, `gpt-6-sol`. Kada je potrebno potvrditi da li se Coding akreditivi i API protokol podudaraju, koristite važeće akreditive Coding Application za zahtev:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

Katalog modela se neprestano menja; ovaj dokument ne održava fiksni broj niti statičku listu modela. `id` svakog unosa u odgovoru je **naziv modela** koji se može direktno proslediti API parametru `model`, na primer `{"id":"deepseek-v4-pro"}` odgovara unosu `deepseek-v4-pro`; to nije UUID usluge, API-ja ili Application-a. `/v1/models` vraća globalni katalog modela i neće se automatski filtrirati prema Coding akreditivima; pre konfiguracije je i dalje potrebno unakrsno potvrditi API scope akreditiva, izabrani protokol i opseg kompatibilnosti klijenta.

## Uobičajeno otklanjanje problema

- **Nedovoljno sredstava**: idite u [Applications konzolu](https://platform.acedata.cloud/console/applications), pronađite Coding Application i aktivno obnovite kupovinu.
- **Klijent i dalje zahteva originalnu adresu**: potvrdite da konfiguracija pripada istom korisniku i radnom prostoru koji pokreće klijenta, pa potpuno zatvorite i ponovo pokrenite klijent.
- **Naziv modela nije dostupan**: ponovo zatražite `/v1/models`, proverite da li se uneseni naziv modela u potpunosti podudara sa `id` iz kataloga, API scope akreditiva i protokolom koji klijent podržava.
- **Token ne može da pozove interfejs**: potvrdite da akreditivi pripadaju Coding Application-u i proverite `allowed_api_ids` i API dozvole aplikacije.
