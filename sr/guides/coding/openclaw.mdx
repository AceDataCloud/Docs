## 1. Добијање API кључа

Отворите [Ace Data Cloud списак апликација](https://platform.acedata.cloud/console/applications), уђите у доступне апликације и копирајте API кључ.

![Добијање Ace Data Cloud API кључа](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Инсталирање OpenClaw и додатка

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

Додатак захтева OpenClaw `2026.4.2` или новију верзију, тренутно нативно пружа Chat и Web Search способности.

## 3. Конфигурација кључа

Препоручује се коришћење onboarding:

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "ваш API кључ"
```

Такође можете користити променљиве окружења:

```bash
export ACEDATACLOUD_API_KEY="ваш API кључ"
```

## 4. Опционално: Ручна конфигурација

Када не користите onboarding, у `~/.openclaw/openclaw.json` омогућите додатак и подесите подразумевани модел:

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

Не стављајте API кључ у овај фајл; наставите да користите променљиве окружења.

## 5. Избор модела и верификација

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "Одговорите само OK"
```

Замените `MODEL_ID` моделом који тренутно пружа Coding Plan. Када треба да се подеси као подразумевани модел, покрените:

```bash
openclaw models set acedatacloud/MODEL_ID
```

Записи позива могу се видети на [историји коришћења](https://platform.acedata.cloud/console/usages). 401 означава да је кључ неважећи; ако модел не постоји, прво проверите тачан ID и верзију додатка. `cost: 0` у директоријуму додатка само означава да OpenClaw не процењује поново, стварни трошкови и даље се бележе од стране Ace Data Cloud.

## Web Search

```bash
openclaw infer web search \
  --provider acedatacloud --query "најновији AI агенти оквири" --limit 5
```

Тренутно не сматрајте способности приказане у опису додатка, као што су слике, видео или музика, као нативне способности OpenClaw провајдера.
