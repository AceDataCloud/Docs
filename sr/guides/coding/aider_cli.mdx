Aider se povezuje sa OpenAI-kompatibilnim API-jem putem LiteLLM-ovog `openai/` model prefiksa.

## Konfiguracija

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

Zamenite `MODEL_ID` sa modelom koji ste odabrali u vodiču za konfiguraciju kodiranja. Takođe možete upisati odgovarajuće opcije u lokalni `.env` ili `.aider.conf.yml`, ali nemojte slati pravi Token.

## Verifikacija

```bash
aider --model openai/MODEL_ID --message "Odgovori samo OK"
```

Prvi put kada koristite nepoznati model, Aider može da vas obavesti o nedostatku metapodataka modela; to nije isto što i neuspeh autentifikacije. 401 proverava Token, 404 proverava ID modela i `/v1` osnovni URL.
