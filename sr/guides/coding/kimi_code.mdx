## 1. Preuzimanje API Key-a

Otvorite [listu aplikacija Ace Data Cloud](https://platform.acedata.cloud/console/applications), uđite u dostupnu aplikaciju i kopirajte API Key.

![Preuzimanje Ace Data Cloud API Key-a](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalacija Kimi Code-a

macOS / Linux：

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

Može se instalirati i putem npm-a：

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. Konfigurisanje AceDataCloud-a

Uredite `~/.kimi/config.toml` i dodajte sledeću konfiguraciju：

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "你的 API Key"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

Idite u [katalog modela](https://platform.acedata.cloud/models) da biste videli nazive modela (na primer `claude-opus-5`, `gpt-6-sol`), i zamenite sve `MODEL_ID` istim nazivom; za preciznu proveru, koristite vrednost `id` iz odgovora `/v1/models`. Ova vrednost je naziv modela koji koristi API parametar `model`, a nije UUID servisa ili API-ja. `type = "openai"` koristi OpenAI Chat Completions protokol.

Konfiguraciona datoteka sadrži Key, za macOS / Linux preporučuje se ograničavanje dozvola：

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. Provera i pokretanje

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

Nakon ulaska u projekat, pokrenite `kimi` da biste počeli sa korišćenjem. Ako se vrati 401, proverite API Key; ako se prikaže `model not found`, potvrdite da `default_model`, naziv modela u tabeli i polje `model` koriste isti ID.
