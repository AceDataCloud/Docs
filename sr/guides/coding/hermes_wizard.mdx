## 1. Preuzimanje API Key-a

Otvorite [listu aplikacija Ace Data Cloud](https://platform.acedata.cloud/console/applications), uđite u dostupnu aplikaciju i kopirajte API Key.

![Preuzimanje Ace Data Cloud API Key-a](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Pokretanje čarobnjaka

```bash
hermes model
```

Izaberite **Custom endpoint**, a zatim redom popunite:

| Polje             | Vrednost                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | Upravo kopirani API Key                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | Idite u [katalog modela](https://platform.acedata.cloud/models) da pogledate i unesite naziv ciljnog modela bez izmena, na primer `claude-opus-5`, `gpt-6-sol` |
| Context length | Ostavite prazno radi automatskog otkrivanja ili popunite prema katalogu modela                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model` je naziv modela koji se koristi za parametar `model` u API zahtevu, a nije UUID usluge ili API-ja. Možete ga prvo pogledati u [katalogu modela](https://platform.acedata.cloud/models); ako je potrebna precizna provera, zatim koristite trenutni API Key da zatražite `GET https://api.acedata.cloud/v1/models` i kopirajte vrednost `id` ciljnog modela iz niza `data` u odgovoru.

Čarobnjak će upisati u `~/.hermes/config.yaml` i lokalnu datoteku sa akreditivima.

## 3. Provera

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

Ako čarobnjak nije sačuvao konfiguraciju, možete pokrenuti `hermes model --reset` i zatim pokušati ponovo; 401 označava da je API Key nevažeći ili da ga trenutna korisnička konfiguracija ne čita.
