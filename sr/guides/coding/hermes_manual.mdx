## 1. Preuzmite API Key

Otvorite [listu Ace Data Cloud aplikacija](https://platform.acedata.cloud/console/applications), uđite u dostupnu aplikaciju i kopirajte API Key.

![Preuzmite Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Sačuvajte Key

Upišite u `~/.hermes/.env`:

```dotenv
ACEDATACLOUD_API_KEY=vaš API Key
```

## 3. Konfigurišite Provider

Dodajte u `~/.hermes/config.yaml`:

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

Idite u [katalog modela](https://platform.acedata.cloud/models) da biste videli nazive modela (na primer `claude-opus-5`, `gpt-6-sol`) i zamenite sve `MODEL_ID` istim nazivom; za preciznu proveru, oslonite se na vrednost `id` u odgovoru `/v1/models`. Ta vrednost je naziv modela koji koristi API parametar `model`, a ne UUID usluge ili API-ja. Nemojte upisivati stvarni Key u YAML niti slati `.env`.

## 4. Verifikacija

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

Ako se vrati 401, proverite `~/.hermes/.env`; ako konfiguracija nije stupila na snagu, potpuno izađite iz Hermes-a i ponovo ga pokrenite.
