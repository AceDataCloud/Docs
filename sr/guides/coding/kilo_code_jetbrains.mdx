## 1. Dobijanje API Ključa

Otvorite [Ace Data Cloud aplikacija lista](https://platform.acedata.cloud/console/applications), uđite u dostupne aplikacije i kopirajte API ključ.

![Dobijanje Ace Data Cloud API Ključa](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Konfiguracija Provajdera

Kilo Code JetBrains dodatak koristi `kilo.jsonc` Provajder format. Konfiguracija mora biti smeštena u korisničkom okruženju gde se dodatak zapravo pokreće; tokom daljinskog razvoja obično je to daljinski backend host.

U `~/.config/kilo/kilo.jsonc` upišite:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

U okruženju gde se pokreće JetBrains backend, izvezite `ACEDATACLOUD_API_KEY`, a zatim ponovo pokrenite IDE ili daljinski backend.

## 3. Verifikacija

Izaberite `acedatacloud/MODEL_ID`, pošaljite `Reply only OK`, a zatim neka Agent pročita test fajl. Ako lokalno funkcioniše, a daljinski ne, prvo proverite da li su konfiguracione datoteke i promenljive okruženja napisane na daljinskom hostu.
