Овај документ има само један циљ: да ти омогући да **у року од 5 минута** покренеш прву Claude Code команду преко AceData Cloud проксија. Комплетан туторијал је доступан у поддокументима за различите IDE-ове ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); овај текст прати најбржи пут „**терминал CLI** + **VS Code екстензија**“.

> **Зашто користити AceData Cloud прокси за Claude Code**:
> - Директна веза унутар земље, није потребан VPN
> - Цена је нижа у односу на званичну (плаћање по токену на платформи)
> - Иста кључ подржава Claude Messages API и Claude Code Token протокол

## Први минут: Захтев за креденцијале

Отвори [Claude Messages страницу](https://platform.acedata.cloud/documents/claude-messages) и кликни на дугме „**Acquire**“:

![](https://cdn.acedata.cloud/nyq0xz.png)

Платформа ће аутоматски креирати Application и доделити бесплатни кредит. Запамти две вредности из детаља: **Base URL** и **API Token** — користићеш их у следећих 5 корака.

| Поље | Вредност | Намена |
|------|----------|--------|
| `BASE_URL` | `https://api.acedata.cloud` | Улазна тачка компатибилна са Claude Messages |
| `API_TOKEN` | `sk-...` (копира се са странице) | Заглавље за аутентификацију компатибилно са Anthropic |

## Други минут: Инсталирање Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (нативни PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

По завршетку инсталације отвори нови терминал и провери да ли ради:

```bash
claude --version
```

> Ако видиш верзију, све је у реду. Claude Code долази са уграђеним Node.js окружењем, не зависи од Node верзије на твом рачунару.

## Трећи минут: Подешавање окружења да користи AceData Cloud

Не користи званични `claude login` процес, већ препиши вредности помоћу окружењских променљивих. Изабери један од два начина:

**Опција А: Привремено (само за тренутну Shell сесију)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-твој-Token"
```

**Опција Б: Перзистентно (препоручено)**

Додај горње две линије у `~/.zshrc` или `~/.bashrc`, па покрени `source`.

> **Честа замка**: Име променљиве мора бити `ANTHROPIC_AUTH_TOKEN`, не `ANTHROPIC_API_KEY`; ако је погрешно, Claude Code ће се вратити на званични крајњи тачку и пријавити 401 грешку.

## Четврти минут: Покрени прву команду

Уђи у било који Git репозиторијум и покрени:

```bash
claude
```

Ако те први пут затражи да се пријавиш, притисни `Esc` да прескочиш. Затим унеси:

```
Наведи зависности тренутног пројекта и кратко објасни сваку.
```

Уобичајено ћеш видети како Claude користи алате као што су `read_file` / `glob` / `grep` за преглед репозиторијума и даје листу. Ако модел одговори исправно и нема 401 грешку, прокси ради.

## Пети минут: Повежи и VS Code екстензију

1. Отвори VS Code → панел за екстензије → претражи „Claude Code“ и инсталирај званичну Anthropic екстензију;
2. Рестартуј VS Code или у командној палети покрени `Developer: Reload Window` да екстензија учита `~/.claude/settings.json` који си подесио у 3. минуту;
3. Кликни на ✦ Spark иконицу у горњем десном углу уређивача или на „✱ Claude Code“ у статус бару да отвори панел;
4. Први пут ће те питати да се пријавиш на званични налог, притисни `Esc` да прескочиш — екстензија ће аутоматски користити `ANTHROPIC_BASE_URL` и `ANTHROPIC_AUTH_TOKEN` из 3. минута.

> **Напомена**: VS Code екстензија и CLI деле исти `~/.claude/settings.json`, тако да није потребно посебно подешавање у VS Code-у. Ако желиш конфигурацију по пројекту, направи `.claude/settings.local.json` у корену репозиторијума (фајл је у `.gitignore`).

Када све ради, можеш у панелу превући фајлове за питања и користити `@-mention` за референцу и предлоге измена. Све наплате иду преко AceData Cloud.

## Провера да ли користиш прокси

Покрени са `--debug` да видиш да ли захтеви иду преко AceData Cloud:

```bash
claude --debug -p "say hi" 2>&1 | grep -iE 'base.?url|api\.acedata|anthropic\.com' | head
```

Ако видиш `https://api.acedata.cloud`, прокси ради; ако се појави `api.anthropic.com` или добијеш 401, врати се на 3. минут и провери да ли је променљива исправно именована (`ANTHROPIC_AUTH_TOKEN`, не `ANTHROPIC_API_KEY`) и да ли `~/.claude/.credentials.json` не садржи званични токен (обриши тај фајл ако јесте).

## 5 најчешће постављаних питања

**П: Покренуо сам `claude login`, па сам променио окружење на AceData, али не ради?**  
О: `claude login` уписује званични токен у `~/.claude/.credentials.json`, који има предност над окружењским променљивим. Обриши тај фајл и поново покрени `source ~/.zshrc`.

**П: Могу ли користити модел као `--model claude-opus-4-7`?**  
О: Можеш. AceData Cloud прокси прослеђује model параметар, подржава све јавне Anthropic моделе и наше проширене `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5`.

**П: Могу ли имати више профила (лични + пословни)?**  
О: Можеш. Claude Code подржава више профила у `~/.claude/settings.json`; или једноставно направи две shell функције `claude_personal` / `claude_work` које постављају различите `ANTHROPIC_AUTH_TOKEN` и позивају `claude $@`.

**П: Могу ли користити у GitHub Actions?**  
О: Можеш. Погледај [Claude Code GitHub Actions туторијал](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**П: Шта после што потрошим бесплатни кредит?**  
О: Иди на [управљање апликацијама](https://platform.acedata.cloud/applications) → изабери Claude Application → Topup за допуну (плаћање по стварној потрошњи токена) или пређи на претплату са поенима.
