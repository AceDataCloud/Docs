Cilj ovog dokumenta je jasan: da **za 5 minuta** pokrenete prvu Claude Code komandu koristeći AceData Cloud proxy. Kompletan tutorijal je dostupan u poddokumentima za različite IDE-ove ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); ovaj vodič prati najbrži put: „**Terminal CLI** + **VS Code ekstenzija**“.

> **Zašto koristiti AceData Cloud proxy za Claude Code**:
> - Direktna konekcija unutar zemlje, bez potrebe za VPN-om
> - Cena je niža u poređenju sa zvaničnim (naplata po tokenu platforme)
> - Isti ključ podržava Claude Messages API i Claude Code Token protokol

## Prvi minut: Prijava za kredencijale

Otvorite [Claude Messages stranicu](https://platform.acedata.cloud/documents/claude-messages) i kliknite na dugme „**Acquire**“:

![](https://cdn.acedata.cloud/nyq0xz.png)

Platforma će automatski kreirati Application i dodeliti vam besplatni kredit. Zapišite **Base URL** i **API Token** sa detaljne stranice — koristiće vam u narednih 5 koraka.

| Polje | Vrednost | Namena |
|-------|----------|--------|
| `BASE_URL` | `https://api.acedata.cloud/claude` | Ulazna tačka kompatibilna sa Claude Messages |
| `API_TOKEN` | `sk-...` (kopira se sa detaljne stranice) | Autentifikacioni token kompatibilan sa Anthropic |

## Drugi minut: Instalacija Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Nakon instalacije, otvorite novi terminal i proverite verziju:

```bash
claude --version
```

> Ako vidite broj verzije, instalacija je uspešna. Claude Code dolazi sa sopstvenim Node.js runtime-om, ne zavisi od verzije Node na vašem računaru.

## Treći minut: Podesite promenljive okruženja da koriste AceData Cloud

Nemojte koristiti zvanični `claude login` proces, već prepišite vrednosti preko promenljivih okruženja. Izaberite jedan od dva načina:

**Opcija A: Privremeno (samo za trenutnu shell sesiju)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud/claude"
export ANTHROPIC_AUTH_TOKEN="sk-ваш-Token"
```

**Opcija B: Trajno (preporučeno)**

Dodajte gornje dve linije u `~/.zshrc` ili `~/.bashrc`, zatim pokrenite `source` na odgovarajućem fajlu.

> **Česta greška**: promenljiva mora biti `ANTHROPIC_AUTH_TOKEN`, a ne `ANTHROPIC_API_KEY`; pogrešan naziv će uzrokovati da Claude Code padne na zvanični endpoint i prijavi grešku 401.

## Četvrti minut: Pokrenite prvu komandu

Uđite u bilo koji Git repozitorijum i pokrenite:

```bash
claude
```

Ako prvi put traži prijavu, pritisnite `Esc` da preskočite. Zatim unesite:

```
Nabroj trenutne zavisnosti projekta i ukratko objasni svrhu svake.
```

Treba da vidite kako Claude koristi alate poput `read_file` / `glob` / `grep` da pregleda repozitorijum i zatim daje listu. Na dnu ekrana u statusnoj traci treba da piše `connected to api.acedata.cloud` — to je ključni znak da proxy radi.

## Peti minut: Povežite i VS Code ekstenziju

1. Otvorite VS Code → panel za ekstenzije → potražite `Claude Code` i instalirajte zvaničnu Anthropic ekstenziju;
2. Pritisnite **Cmd+Shift+P**, unesite `Claude Code: Set Custom API Endpoint`;
3. Unesite `https://api.acedata.cloud/claude` i pritisnite Enter;
4. Ponovo pokrenite komandu `Claude Code: Set API Token` i unesite vaš token.

Ako je uspešno, u bočnoj traci pojaviće se Claude Code panel gde možete prevlačiti fajlove da pitate, ili koristiti `@-mention` za predloge izmena. Sav obračun ide preko AceData Cloud.

## Proverite da li zaista koristite proxy

U Claude Code razgovoru unesite:

```
Poseti https://api.acedata.cloud/whoami i reci mi šta vraća
```

Ako dobijete informacije o svom nalogu (`{user_id, plan, ...}`), znači da je zahtev prošao kroz AceData Cloud edge. Ako dobijete grešku 401 sa zvanične domene, vratite se na treći minut i proverite naziv promenljive okruženja.

## 5 najčešćih pitanja

**P: Pokrenuo sam `claude login`, pa sam promenio promenljive na AceData, ali ne radi?**  
O: `claude login` čuva token u `~/.claude/.credentials.json`, koji ima prioritet nad promenljivim okruženja. Obrišite taj fajl i ponovo učitajte shell konfiguraciju (`source ~/.zshrc`).

**P: Mogu li koristiti modele kao `--model claude-opus-4-7`?**  
O: Možete. AceData Cloud proxy prosleđuje polje modela, podržavajući sve javne Anthropic modele plus naše dodatke kao što su `claude-opus-4-7`, `claude-haiku-4-5`, `claude-sonnet-4-5`.

**P: Mogu li imati više profila (lični + poslovni)?**  
O: Možete. Claude Code podržava više profila u `~/.claude/settings.json`; ili najjednostavnije, napravite dva shell funkcije `claude_personal` i `claude_work` koje eksportuju različite `ANTHROPIC_AUTH_TOKEN` i pozivaju `claude $@`.

**P: Mogu li koristiti Claude Code u GitHub Actions?**  
O: Mogu. Pogledajte [Claude Code GitHub Actions tutorijal](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**P: Šta ako potrošim besplatni kredit?**  
O: Idite na [Upravljanje aplikacijama](https://platform.acedata.cloud/applications) → izaberite Claude Application → Topup za dopunu (naplata po stvarnoj potrošnji tokena), ili pređite na pretplatu sa poenima.
