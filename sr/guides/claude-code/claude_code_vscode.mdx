Claude Code је алат за **Agentic Coding** који је представио Anthropic, и сматра се једним од најмоћнијих програмских агената на свету. VS Code екстензија за Claude Code нуди нативни графички интерфејс, подржава инлајн Diff преглед, `@`-mentions референце, планирање прегледа и друге функције, и представља препоручени начин коришћења Claude Code у VS Code-у.

Овај документ углавном описује како да конфигуришете и користите Claude Code екстензију у VS Code-у преко прокси услуге AceData Cloud.

## Процес пријаве

Да бисте користили Claude Code, прво можете отићи на [Claude Messages услужну страницу](https://platform.acedata.cloud/documents/claude-messages) и кликнути на дугме „Acquire“ да бисте добили потребне креденцијале:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ако нисте пријављени или регистровани, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након пријаве или регистрације, аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, што вам омогућава да бесплатно испробате Claude Code услугу.

## Инсталација додатка

### Системски захтеви

- VS Code 1.98.0 или новија верзија (такође подржава Cursor)

### Степен инсталације

У VS Code / Cursor екстензионном тржишту, притисните `Cmd+Shift+X` (Mac) или `Ctrl+Shift+X` (Windows/Linux) да отворите преглед екстензија, потражите **Claude Code**, пронађите званични додатак који је објавио Anthropic и кликните на „Install“ да бисте инсталирали:

![Claude Code додатак у VS Code Marketplace](https://cdn.acedata.cloud/10ddf71320.png)

Такође можете директно инсталирати преко следећих линкова:

- [Линк за инсталацију VS Code](vscode:extension/anthropic.claude-code)
- [Линк за инсталацију Cursor](cursor:extension/anthropic.claude-code)

Након инсталације, изаберите поверење у обавештењу које се појави, и инсталација ће бити завршена.

> Ако се додатак не појави након инсталације, поново покрените VS Code или извршите „Developer: Reload Window“ у командној табели.

## Конфигурација AceData Cloud API

Када први пут отворите додатак, биће вам предложено да се пријавите на званични Anthropic налог. Можете прескочити званичну пријаву и користити конфигурацију AceData Cloud прокси API, **без званичне претплате**.

### Степен 1: Конфигурисање променљивих окружења

Можете изабрати да конфигуришете променљиве окружења на било којој од следећих локација:

**Опција А: Конфигурација на нивоу корисника (погодно за све пројекте)**

Уредите `~/.claude/settings.json` (ако не постоји, креирајте) и додајте `env` конфигурацију, замените `{token}` са API токеном који сте добили у AceData Cloud конзоли:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

**Опција Б: Конфигурација на нивоу пројекта (само за тренутни пројекат)**

У корену пројекта креирајте `.claude/settings.json` (заједничка конфигурација) или `.claude/settings.local.json` (лична конфигурација, gitignored):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Напомена**: API токен можете видети у [AceData Cloud конзоли](https://platform.acedata.cloud/console). Вредност `ANTHROPIC_AUTH_TOKEN` ће бити аутоматски додата `Bearer` префикс и послата серверу. Конфигурација на нивоу пројекта има већи приоритет од конфигурације на нивоу корисника. Препоручује се да у тимским пројектима користите `.claude/settings.json` за заједничку конфигурацију, а личне осетљиве информације ставите у `.claude/settings.local.json`.

### Степен 2: Онемогућите упит за пријаву (опционално)

Ако не желите да сваки пут видите упит за пријаву, можете у VS Code подешавањима означити **Disable Login Prompt**:

У подешавањима потражите „Claude Code login“, пронађите опцију **Disable Login Prompt** и означите је.

Након завршене конфигурације, поново отворите Claude Code панел и можете нормално почети да користите.

## Отворите Claude Code панел

Након инсталације и конфигурације, постоји више начина да отворите Claude Code:

| Начин         | Операција                                             |
| ---------- | ---------------------------------------------- |
| **Тулбар у едитору** | Кликните на ✦ Spark икону у горњем десном углу едитора (потребно је отворити датотеку)                 |
| **Статусна трака**    | Кликните на „✱ Claude Code“ на десној страни доњег статусног трака (без потребе за отварањем датотеке)              |
| **Командна табла**   | `Cmd+Shift+P` / `Ctrl+Shift+P`, потражите „Claude Code“ |
| **Пречица**    | `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux) за прелазак фокуса  |

За разлику од алата као што су Cursor / Copilot који користе бочну траку, Claude Code подразумевано користи **поглед у едитору** као област за ћаскање, што пружа већи видни простор и богатије приказивање садржаја. Такође можете повући панел у бочну траку или на друго место.

![Claude Code панел у VS Code](https://cdn.acedata.cloud/b84b878420.jpg)

## Основна употреба

### Дијалог интеракција

У Claude Code панелу можете директно унети природни језик да бисте комуницирали са Claude-ом. На пример:

- „Помози ми да анализирам целокупну архитектуру овог пројекта“
- „Овај код има Bug, поправи га“
- „Рефакториши ову функцију да побољшаш читљивост“
- „Напиши јединичне тестове за овај модул“

Claude Code ће аутоматски разумети контекст вашег кода, анализирати и уредити преко датотека. Када Claude треба да измени датотеку, биће приказан Diff преглед, а ви можете изабрати да прихватите или одбијете измене.

![Дијалог и упутства у Claude Code у VS Code](https://cdn.acedata.cloud/650377f5cc.png)

### Референце у контексту

У дијалогу можете користити `@` симбол да бисте реферисали на одређене датотеке или контекст:

- `@filename.py` — референца на одређену датотеку (подржава нејасно подударање)
- `@src/components/` — референца на цео директоријум (потребан је коси црта на крају)
- `@terminal:name` — референца на терминалски излаз

Када изаберете код у едитору, притиском на `Option+K` (Mac) / `Alt+K` (Windows/Linux) можете брзо уметнути `@` референцу (нпр. `@app.ts#5-10`).

### Команде са косом цртом

Кликните на `/` икону у дијалогу или директно унесите `/` да бисте користили богате уграђене функције:

Често коришћене команде укључују:

| Команда         | Функција           |
| ---------- | ------------ |
| `/new`     | Нова ћаска         |
| `/model`   | Промена модела         |
| `/compact` | Смањите контекст        |
| `/mcp`     | Конфигуришите MCP услугу    |
| `/config`  | Отворите подешавања         |
| `/usage`   | Погледајте коришћење         |
| `/memory`  | Управљање Claude меморијом |
| `/help`    | Прикажи информације о помоћи       |

### Погледајте историју дијалога

Кликните на падајући мени на врху панела да бисте видели историју дијалога, подржава претрагу по кључним речима и преглед по временским периодима (Данас, Јуче, Последњих 7 дана итд.), што олакшава повратак на претходне интеракције. Кликните на било који дијалог да бисте повратили комплетну историју порука.

### Преглед промене кода

Када Claude треба да измени датотеку, биће приказан Diff преглед, који показује поређење изворног кода и измена. Можете изабрати да прихватите или одбијете сваку измену, или можете рећи Claude-у какве промене желите:
![VS Code у Diff поређењу](https://cdn.acedata.cloud/c42381ea9f.png)

### Режим дозвола

Кроз индикатор режима на дну панела можете прелазити између различитих режима дозвола:

| Режим                  | Опис                      |
| --------------------- | ----------------------- |
| **Default (Ask)**      | Питање за потврду пре сваке операције (подразумевано)           |
| **Plan**              | Claude прво прави план и чека одобрење, извршава тек након потврде |
| **acceptEdits**       | Аутоматски прихвата измене у документу, али команде у терминалу и даље захтевају потврду      |
| **bypassPermissions** | Прескаче све упите за дозволе, потпуно аутоматизовано (користите опрезно)    |

### Вишесесијска паралелност

Користећи командни панел **Open in New Tab** или **Open in New Window** можете покренути више независних разговора, при чему сваки разговор одржава своју историју и контекст, што омогућава паралелно обављање различитих задатака.

## Остале поставке

### Прелазак на модел

Claude Code подржава прелазак на различите моделе, као што су Claude Sonnet, Claude Opus итд. Можете конфигурисати преко команде `/model` или у подешавањима додатка у **Selected Model**.

### Аутоматски режим

У подешавањима додатка можете поставити **Initial Permission Mode** на `bypassPermissions`, након чега Claude Code неће више тражити потврду за сваку операцију у вези са изменама у документу, терминалним командама итд., чиме се остварује потпуна аутоматизација радног тока.

Такође можете поставити на `acceptEdits` за полуаутоматски режим, где се измене аутоматски прихватају, али команде у терминалу и даље захтевају потврду.

> **Напомена**: Пре него што укључите аутоматски режим, уверите се да разумете ризике, препоручује се коришћење у пројектима којима верујете.

### Користите CLI у терминалу

Ако више волите стил командне линије, можете у подешавањима VS Code означити **Use Terminal**, Claude Code ће радити у CLI режиму у интегрисаном терминалу. Такође можете директно отворити интегрисани терминал у VS Code и покренути команду `claude`.

## Честа питања

### Шта да радим ако се не могу повезати?

1. Уверите се да су конфигурације у `~/.claude/settings.json` или `.claude/settings.json` исправне, посебно `ANTHROPIC_AUTH_TOKEN` и `ANTHROPIC_BASE_URL`
2. Уверите се да је API токен важећи (можете проверити на [конзоли](https://platform.acedata.cloud/console))
3. Проверите да ли је интернет веза нормална, уверите се да можете приступити `https://api.acedata.cloud`
4. Поново покрените VS Code и покушајте поново

### Шта ако се Spark икона не појави?

1. Уверите се да је отворен неки документ (само отварање фасцикле није довољно)
2. Уверите се да је верзија VS Code 1.98.0 или новија
3. Извршите „Developer: Reload Window“ у командном панелу
4. Или директно кликните на „✱ Claude Code“ у статусној траци на дну

### Како да проверим преостали кредит?

Пријавите се на [AceData Cloud конзолу](https://platform.acedata.cloud/console) да бисте видели преостали кредит и коришћење вашег налога.
