Claude Code је програмски алат који је представио Anthropic, а такође се сматра једним од најмоћнијих програмских агената на свету. Claude Code VS Code екстензија нуди нативно графичко корисничко сучеље и представља препоручени начин коришћења Claude Code у VS Code-у.

Овај документ углавном описује како да конфигуришете и користите Claude Code екстензију у VS Code-у преко прокси услуге Ace Data Cloud.

## Процес пријаве

Да бисте користили Claude Code, прво можете да одете на [Ace Data Cloud контролну таблу](https://platform.acedata.cloud/console/applications) и добијете ваш API токен, за резерву.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након пријаве и регистрације аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, што вам омогућава да бесплатно испробате Claude Code услугу.

## Инсталирање Claude Code додатка

У VS Code екстензијском тржишту потражите **Claude Code**, потврдите да је издавач **Anthropic** и инсталирајте. Након завршетка инсталације, у активном менију ће се појавити Claude Code улаз.

## Конфигурација Ace Data Cloud API

Када први пут отворите додатак, биће вам предложено да се пријавите на званични Anthropic налог. Можете прескочити званичну пријаву и користити прокси API Ace Data Cloud, без потребе за званичном претплатом.

Додатак и терминал CLI читају исту групу Claude Code подешавања. Комплетна аутентификација, обрада конфликата акредитација и глобални конфигурациони методи су описани у [Claude Code терминал конфигурационом упутству](https://platform.acedata.cloud/documents/claude-code-terminal-integration). Ако желите да подешавања важи само за тренутни пројекат, у корену пројекта креирајте `.claude/settings.local.json` који је додат у `.gitignore`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Где је `{token}` управо копирани API кључ. Ако у окружењу у којем покрећете VS Code већ имате стари `ANTHROPIC_API_KEY`, прво у том окружењу `unset ANTHROPIC_API_KEY`; не третирајте празан низ као чишћење, нити стављајте прави кључ у `.claude/settings.json` који делите са тимом.

Испод је конфигурација завршена на локалном рачунару користећи VS Code 1.136.1 и Claude Code екстензију 2.1.251. Снимак екрана користи замене за кључеве, како би се избегло откривање правих акредитација:

![Конфигурација Ace Data Cloud Claude Code у VS Code](https://cdn.acedata.cloud/f925e9e9597b.png)

Након завршене конфигурације, поново покрените VS Code.

> Напомена: горња конфигурација важи само за тренутни пројекат, а препоручује се да се пут до `.claude/settings.local.json` конфигурационог фајла дода у `.gitignore` фајл, како би се спречило да се пренесе у даљински репозиторј.

Ако желите да подешавања важи за све пројекте, можете директно поставити ту конфигурацију у директоријум корисника. Одговарајући пут је `~/.claude/settings.json`,

> Напомена: након завршене конфигурације, молимо вас да поново покренете или поново учитате VS Code да би конфигурација важила.

## Основна употреба

Након конфигурације, пошаљите један једноставан задатак за читање у Claude Code панелу, на пример "прочитај README.md и резимирај у једној реченици". Након успешног завршетка задатка, можете проверити ову позивницу у [историји коришћења](https://platform.acedata.cloud/console/usages).

## Како проверити преостalu квоту

Кроз [Ace Data Cloud контролну таблу - списак апликација](https://platform.acedata.cloud/console/applications), можете видети преосталу квоту на вашем налогу.

Кроз [Ace Data Cloud контролну таблу - историја коришћења](https://platform.acedata.cloud/console/usages) можете видети сву историју коришћења и детаље о наплати.
