Claude Code је алат за **Agentic Coding** који је представио Anthropic, а такође се сматра једним од најмоћнијих програмских агената на свету. Claude Code нуди додатак специјално за JetBrains IDE, подржавајући целу серију JetBrains IDE, укључујући IntelliJ IDEA, PyCharm, WebStorm, GoLand, PhpStorm, Android Studio и друге.

Овај документ углавном описује како да конфигуришете и користите Claude Code у JetBrains IDE преко прокси услуге AceData Cloud.

## Процес пријаве

Да бисте користили Claude Code, прво можете отићи на [Claude Messages услужну страницу](https://platform.acedata.cloud/documents/claude-messages) и кликнути на дугме „Acquire“ да бисте добили потребне креденцијале:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након пријаве и регистрације, аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, што вам омогућава да бесплатно испробате Claude Code услугу.

| IDE                | Подржани језици/сцене               |

## Инсталација

### Предуслови

Claude Code JetBrains додатак зависи од Claude Code CLI, па прво уверите се да је CLI инсталиран:

```bash
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# Или користите Homebrew
brew install claude-code
```

Након инсталације можете проверити:

```bash
claude --version
```

### Инсталација додатка

![Claude Code додатак у JetBrains Marketplace](https://cdn.acedata.cloud/de78fd305b.png)

1. Отворите JetBrains IDE
2. Идите на **Settings** → **Plugins** → **Marketplace**
3. Потражите **Claude Code**
4. Кликните на **Install** да инсталирате додатак
5. Рестартујте IDE

Или директно посетите [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/27310-claude-code-beta-) за онлајн инсталацију.

> **Важно**: Након инсталације додатка потребно је **потпуно рестартовати IDE** (можда ће бити потребно више пута рестартовати) да би се активирао.

## Конфигурација AceData Cloud API

Claude Code JetBrains додатак покреће `claude` команду преко интегрисаног терминала, тако да је конфигурација променљивих окружења иста као и за CLI.

### Корак 1: Креирање config.json

Креирајте конфигурациону датотеку за Claude Code:

| Систем                | Пут                                   |
| ----------------- | ------------------------------------ |
| **macOS / Linux** | `~/.claude/config.json`              |
| **Windows**       | `C:\Users\{корисничко_име}\.claude\config.json` |

У ту датотеку упишите следећи садржај и сачувајте:

```json
{
  "primaryApiKey": "self"
}
```

Команда за брзо креирање на macOS / Linux:

```bash
mkdir -p ~/.claude && echo '{"primaryApiKey": "self"}' > ~/.claude/config.json
```

### Корак 2: Конфигурација променљивих окружења

**Опција 1: Поставите у конфигурациону датотеку Shell (препоручено)**

Додајте следећи садржај у ваш `~/.zshrc` или `~/.bashrc`, замените `{token}` вашим API токеном:

```bash
# AceData Cloud - Claude Code прокси конфигурација
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Након измене извршите `source ~/.zshrc` да бисте активирали конфигурацију, а затим **рестартујте JetBrains IDE**.

**Опција 2: Поставите у Claude Code settings.json**

Уредите `~/.claude/settings.json` (ако не постоји, креирајте):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Напомена**: API токен можете видети у [AceData Cloud конзоли](https://platform.acedata.cloud/console).

## Основна употреба

### Покретање из интегрисаног терминала IDE

Отворите интегрисани терминал JetBrains IDE и покрените:

```bash
claude
```

Када се покреће у интегрисаном терминалу IDE, све интегрисане функције (Diff преглед, избор контекста итд.) ће се аутоматски активирати.

### Повезивање из спољног терминала

Ако покрећете Claude Code из спољног терминала, можете користити `/ide` команду за повезивање на JetBrains IDE:

```bash
claude
> /ide
```

Уверите се да покрећете Claude Code из исте путање као корен пројекта IDE, тако да Claude може да приступи истом скупу датотека.

### Пречице

| Пречица                                              | Функција                      |
| ------------------------------------------------ | ----------------------- |
| `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux)        | Брзо отварање Claude Code        |
| `Cmd+Option+K` (Mac) / `Alt+Ctrl+K` (Windows/Linux) | Уметање референце на датотеку (нпр. `@File#L1-99`) |

### Интегрисане функције

Claude Code JetBrains додатак нуди следеће интегрисане функције:

- **Diff преглед**: промене у коду се директно приказују у Diff прегледачу IDE
- **Избор контекста**: тренутно изабрани код и табови аутоматски се деле са Claude
- **Референце на датотеке**: користите пречице за брзо референцирање датотека и бројева редова
- **Дијагностика дељења**: информације о дијагностици у IDE, као што су Lint, синтаксне грешке итд., аутоматски се деле са Claude

## Подешавања додатка

У **Settings** → **Tools** → **Claude Code [Beta]** можете конфигурисати:

| Подешавање                        | Опис                                         |
| ----------------------------- | ------------------------------------------ |
| **Claude команда**            | Прилагодите пут до Claude команде (нпр. `/usr/local/bin/claude`) |
| **Омогући аутоматска ажурирања**  | Аутоматски проверавајте и инсталирајте ажурирања додатка                                |
| **Омогући коришћење Option+Enter** | коришћење Option+Enter у оквиру упита на macOS             |

### Конфигурација за WSL кориснике

Ако користите у WSL окружењу, потребно је да Claude команду поставите на:

```
wsl -d Ubuntu -- bash -lic "claude"
```

(замените `Ubuntu` именом ваше WSL дистрибуције)

## Честа питања

### Шта да радим ако се не могу повезати?

1. Проверите да ли је датотека `~/.claude/config.json` исправно креирана
2. Уверите се да су променљиве окружења исправно подешене
3. Уверите се да је API токен важећи (можете га видети у [конзоли](https://platform.acedata.cloud/console))
4. Рестартујте JetBrains IDE и покушајте поново

### Шта ако додатак не ради?

1. Уверите се да покрећете Claude Code из корена пројекта
2. Проверите да ли је додатак омогућен у подешавањима IDE
3. Потпуно рестартујте IDE (можда ће бити потребно више пута рестартовати)
4. Ако користите режим даљинског развоја, уверите се да је додатак инсталиран на даљинском хосту (Settings → Plugin (Host))

### Шта ако IDE није детектован?

1. Уверите се да је додатак инсталиран и омогућен
2. Рестартујте IDE
3. Уверите се да покрећете Claude Code у интегрисаном терминалу
4. WSL корисници, молимо вас да погледате [WSL водич за решавање проблема](https://code.claude.com/docs/en/troubleshooting#jetbrains-ide-not-detected-on-wsl2)

### command not found

Ако кликнете на Claude и добијете поруку "command not found":

1. Уверите се да је CLI инсталиран: `which claude`
2. У подешавањима додатка конфигуришите комплетан пут до Claude команде
3. WSL корисници користите горњу WSL команду формата
### Како да проверим преостали кредит?

Пријавите се на [AceData Cloud контролни панел](https://platform.acedata.cloud/console) да бисте видели тренутни преостали кредит и коришћење.
