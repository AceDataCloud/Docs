## 1. Dobijanje API Ključa

Otvorite [Ace Data Cloud aplikacija lista](https://platform.acedata.cloud/console/applications), uđite u dostupne aplikacije i kopirajte API ključ.

![Dobijanje Ace Data Cloud API Ključa](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalacija CLI i dodatka

Prvo instalirajte Claude Code CLI.

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

Zatim instalirajte **Claude Code** dodatak iz JetBrains Marketplace-a i restartujte IDE. Dodatak poziva lokalnu `claude` komandu; ako se pojavi poruka da komanda nije pronađena, unesite njen puni put u **Settings → Tools → Claude Code**.

## 3. Konfiguracija Ace Data Cloud

Postavite u okruženju za pokretanje JetBrains backend-a.

macOS / Linux / WSL:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="tvoj API ključ"
unset ANTHROPIC_API_KEY
```

Windows PowerShell:

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "tvoj API ključ"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

Takođe možete koristiti `.claude/settings.local.json` u projektu koji je ignorisan:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "tvoj API ključ"
  }
}
```

Remote Development treba da se konfiguriše i instalira dodatak na udaljenom host-u; WSL korisnici mogu postaviti Claude komandu na `wsl -d Ubuntu -- bash -lic "claude"`.

## 4. Verifikacija

Pokrenite `claude` iz integrisanog terminala IDE-a, ili pokrenite eksterni terminal i unesite `/ide`. Kada se povežete, neka Claude odgovori sa `OK`, zatim pročitajte jedan test fajl i proverite taj zahtev u Ace Data Cloud [istoriji korišćenja](https://platform.acedata.cloud/console/usages).

Ako dodatak ne može da se pokrene, prvo pokrenite `claude --version` u istom terminalu; 401 proverite stvarne nasleđene promenljive okruženja backend-a i stari `ANTHROPIC_API_KEY`.
