Claude Code je alat za **Agentic Coding** koji je razvio Anthropic, takođe poznat kao jedan od najjačih programskih agenata na svetu. Claude Code desktop aplikacija pruža nezavisno grafičko sučelje, podržava Diff reviziju, paralelne sesije (izolovane putem Git Worktree), udaljene sesije i druge funkcije, bez potrebe za oslanjanjem na bilo koji IDE.

Ovaj dokument uglavnom objašnjava kako da konfigurišete i koristite Claude Code desktop aplikaciju putem proxy usluge AceData Cloud.

> **Napomena**: Claude Code desktop aplikacija je trenutno u fazi pregleda (Preview), podržava samo macOS i Windows.

## Proces prijave

Da biste koristili Claude Code, prvo možete otići na [Claude Messages uslugu](https://platform.acedata.cloud/documents/claude-messages) i kliknuti na dugme „Acquire“ da biste dobili potrebne akreditive:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon prijave bićete automatski vraćeni na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu, što vam omogućava da besplatno isprobate Claude Code uslugu.

## Instalacija desktop aplikacije

### Sistem zahtevi

- macOS (Intel i Apple Silicon) ili Windows (x64 / ARM64)
- Linux trenutno ne podržava desktop aplikaciju

### Preuzimanje i instalacija

Posetite [Claude zvaničnu stranicu za preuzimanje](https://claude.ai) da preuzmete instalacioni paket za odgovarajuću platformu:

- **macOS**: preuzmite `.dmg` datoteku, prevucite je u Applications folder
- **Windows x64**: preuzmite `.exe` instalacioni paket, pratite uputstva za instalaciju
- **Windows ARM64**: preuzmite ARM64 verziju (napomena: ARM64 ne podržava lokalne sesije, potrebno je koristiti udaljenu sesiju)

![Claude desktop aplikacija stranica za preuzimanje](https://cdn.acedata.cloud/c3c8c57264.png)

Nakon završetka instalacije, pokrenite Claude iz Applications foldera (macOS) ili iz Start menija (Windows).

## Konfiguracija AceData Cloud API

Nakon pokretanja desktop aplikacije, potrebno je prijaviti se na Anthropic nalog. Možemo koristiti AceData Cloud proxy API konfigurisanjem promenljivih okruženja, **bez potrebe za zvaničnom pretplatom**.

Desktop aplikacija čita promenljive okruženja iz vašeg Shell okruženja, pa je potrebno izvršiti podešavanja u konfiguracionoj datoteci Shell-a.

### Konfiguracija promenljivih okruženja

**macOS korisnici**

Dodajte sledeći sadržaj u `~/.zshrc` (ili `~/.bashrc`), zamenjujući `{token}` vašim API tokenom:

```bash
# AceData Cloud - Claude Code proxy konfiguracija
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Sačuvajte i izvršite:

```bash
source ~/.zshrc
```

**Windows korisnici**

Dodajte sledeće sistemske promenljive putem „Svojstva sistema → Napredno → Promenljive okruženja“:

| Ime promenljive            | Vrednost                           |
| ---------------------- | --------------------------------- |
| `ANTHROPIC_AUTH_TOKEN` | `{token}` (zamenite vašim API tokenom)     |
| `ANTHROPIC_BASE_URL`   | `https://api.acedata.cloud` |

Ili koristite PowerShell:

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**Takođe možete konfigurirati putem settings.json**

Uredite `~/.claude/settings.json` (ako ne postoji, kreirajte):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Savjet**: API token možete videti na [AceData Cloud konzoli](https://platform.acedata.cloud/console). Nakon konfiguracije, potrebno je **ponovo pokrenuti desktop aplikaciju** da bi promenljive okruženja postale aktivne.

## Osnovna upotreba

### Otvorite projekat

1. Pokrenite Claude desktop aplikaciju
2. Kliknite na **Code** karticu na vrhu
3. Izaberite **Local** režim rada
4. Kliknite na **Select folder** da izaberete direktorijum vašeg projekta

### Započnite razgovor

U tekstualnom okviru unesite prirodni jezik koji opisuje vaše zahteve:

- „Pronađi TODO komentare i ispravi ih“
- „Dodaj test za glavnu funkciju“
- „Objasni arhitekturu ovog projekta“

Claude će analizirati vašu kodnu bazu, predložiti izmene i prikazati promene u Diff prikazu.

### Režim dozvola

Prebacite se između režima pomoću selektora pored dugmeta za slanje:

| Režim       | Opis                 |
| -------- | ------------------ |
| **Ask**  | Pita za potvrdu pre svake izmene (preporučuje se za nove korisnike)  |
| **Code** | Automatski prihvata izmene u datotekama, ali terminalne komande i dalje zahtevaju potvrdu |
| **Plan** | Prvo pravi detaljan plan i čeka odobrenje, izvršava se tek nakon potvrde |

### Paralelne sesije

Kliknite na **+ New session** u bočnoj traci da pokrenete više paralelnih sesija. Za Git repozitorijume, svaka sesija će dobiti nezavisnu kopiju projekta putem Worktree, bez međusobnog ometanja.

Worktree se po defaultu čuva u `~/.claude-worktrees/` direktorijumu.

### Diff revizija

Kada Claude izmeni datoteku, prikazaće statistiku promena (npr. `+12 -1`), kliknite da otvorite Diff preglednik i pregledate izmene po datotekama. Takođe možete kliknuti na konkretne linije koda da dodate komentare, a Claude će se prilagoditi vašim povratnim informacijama.

## Povezivanje sa spoljnim alatima

Pre nego što započnete sesiju, kliknite na **⋯** dugme, izaberite **Connectors** da dodate spoljne integracije:

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- Još...

Nakon povezivanja, Claude može direktno čitati kalendar, slati poruke, kreirati Issue i slično.

## Odnos sa CLI-jem

Desktop aplikacija i CLI koriste isti osnovni motor, dele sledeće konfiguracije:

- `CLAUDE.md` / `CLAUDE.local.md` datoteke memorije projekta
- `~/.claude.json` / `.mcp.json` konfiguracije MCP servera
- `~/.claude/settings.json` podešavanja
- Hooks i Skills konfiguracije

Obe aplikacije mogu istovremeno raditi na istom projektu, svaka održava nezavisnu istoriju sesija.

## Česta pitanja

### Šta da radim ako se povezuje neuspešno?

1. Proverite da li je `~/.claude/config.json` datoteka ispravno kreirana
2. Potvrdite da su promenljive okruženja ispravno postavljene (ponovo pokrenite desktop aplikaciju da bi postale aktivne)
3. Proverite da li je API token važeći (možete ga videti na [konzoli](https://platform.acedata.cloud/console))
4. Ako koristite `settings.json` za konfiguraciju promenljivih okruženja, proverite da li je format datoteke ispravan

### Šta ako ne mogu pronaći instalirane alate?

Ako Claude ne može da pronađe komande kao što su `npm`, `node`:

1. Proverite da li su ti alati dostupni u običnom terminalu
2. Proverite da li je vaš Shell konfiguracioni fajl (`~/.zshrc`, `~/.bashrc`) ispravno postavio PATH
3. Ponovo pokrenite desktop aplikaciju da biste ponovo učitali promenljive okruženja

### Kako da proverim preostalu kvotu?

Prijavite se na [AceData Cloud konzolu](https://platform.acedata.cloud/console) da biste videli trenutnu preostalu kvotu i korišćenje.
