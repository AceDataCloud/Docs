Claude Code је алат за **Agentic Coding** који је представио Anthropic, а такође се сматра једним од најмоћнијих програмских агената на свету. Claude Code GitHub Actions може интегрисати AI програмске способности у ваш GitHub радни ток, само треба да у PR или Issue напишете `@claude`, и Claude ће аутоматски анализирати код, креирати PR, реализовати функције, и поправити Bug.

Овај документ углавном описује како да конфигуришете и користите Claude Code GitHub Actions преко прокси услуге AceData Cloud.

## Процес пријаве

Да бисте користили Claude Code, прво можете отићи на [Claude Messages услужну страницу](https://platform.acedata.cloud/documents/claude-messages) и кликнути на дугме „Acquire“ да бисте добили потребне креденцијале:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ако нисте пријављени или регистровани, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након пријаве или регистрације, аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, што вам омогућава да бесплатно испробате Claude Code услугу.

## Карактеристике

- **Одмах креира PR**: Опишите захтев, Claude аутоматски креира комплетан Pull Request
- **Аутоматски реализује код**: У Issue напишите `@claude`, и претворите Issue у извршни код
- **Поштује пројектне стандарде**: Аутоматски чита `CLAUDE.md`, поштује ваш стил кода и пројектне стандарде
- **Сигурно и поуздано**: Код се извршава на GitHub Runner-у, подаци су безбедни

## Кораци конфигурације

### Корак 1: Инсталирајте Claude GitHub App

Идите на [https://github.com/apps/claude](https://github.com/apps/claude) и инсталирајте Claude GitHub App у вашу репозиторију.

![GitHub Claude App инсталациона страница](https://cdn.acedata.cloud/ba4b8df66d.png)

Овај App захтева следеће дозволе за репозиторију:

| Дозвола            | Ниво          | Објашњење          |
| ----------------- | ------------ | ----------------- |
| **Садржај**       | Читање и писање | Измена датотека у репозиторији |
| **Issues**        | Читање и писање | Одговор на Issue  |
| **Pull requests** | Читање и писање | Креирање PR и слање измена |

### Корак 2: Додајте API кључ

Додајте AceData Cloud API кључ као тајну у репозиторији:

1. Идите у **Settings** → **Secrets and variables** → **Actions**
2. Кликните на **New repository secret**
3. У поље Name упишите `ANTHROPIC_API_KEY`, а у поље Value унесите API токен који сте добили у AceData Cloud
4. Кликните на **Add secret** да бисте сачували

> **Напомена**: API токен можете видети у [AceData Cloud конзоли](https://platform.acedata.cloud/console).

### Корак 3: Креирајте Workflow датотеку

У репозиторији креирајте `.github/workflows/claude.yml` датотеку:

```yaml
name: Claude Code
on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]
  issues:
    types: [opened, assigned]
  pull_request:
    types: [opened, synchronize]

jobs:
  claude:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
```

Ако је потребно да користите AceData Cloud прокси API крајњу тачку, такође треба да подесите променљиве окружења у Workflow-у:

```yaml
name: Claude Code
on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  claude:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
        env:
          ANTHROPIC_BASE_URL: "https://api.acedata.cloud"
```

## Начини коришћења

### Употреба у коментарима Issue или PR

Након конфигурације, у било ком коментару Issue или PR напишите `@claude`, и Claude ће аутоматски одговорити:

```
@claude реализуј функцију према опису овог Issue
@claude прегледај безбедност кода у овом PR
@claude поправи TypeError у компоненту user dashboard
@claude како да реализујем аутентификацију корисника за овај крајњи тачку?
```

### Аутоматска прегледа кода

Креирајте Workflow који аутоматски извршава преглед кода када се PR отвори:

```yaml
name: Code Review
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          prompt: "/review"
          claude_args: "--max-turns 5"
        env:
          ANTHROPIC_BASE_URL: "https://api.acedata.cloud"
```

### Аутоматизација заказаних задатака

Креирајте аутоматизовани задатак који се извршава по распореду:

```yaml
name: Daily Report
on:
  schedule:
    - cron: "0 9 * * *"

jobs:
  report:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          prompt: "Генериши извештај о сажетку измена од јуче и непотпуном Issue"
        env:
          ANTHROPIC_BASE_URL: "https://api.acedata.cloud"
```

## Објашњење параметара Action

| Параметар              | Објашњење                              | Обавезно  |
| --------------------- | ------------------------------------- | -------- |
| `anthropic_api_key`   | API кључ                              | Да       |
| `prompt`              | Упутство за Claude (текст или Skill као `/review`) | Не       |
| `claude_args`         | Параметри за Claude Code CLI          | Не       |
| `github_token`        | GitHub токен                          | Не       |
| `trigger_phrase`      | Прилагођена фраза за активирање (подразумевано `@claude`) | Не       |

### Чести параметри claude_args

```yaml
claude_args: "--max-turns 5 --model claude-sonnet-4-5-20250929"
```

| Параметар            | Објашњење            |
| ------------------- | ------------------- |
| `--max-turns`       | Максимални број рунди (подразумевано 10) |
| `--model`           | Користи модел       |
| `--mcp-config`      | Пут до MCP конфигурационе датотеке |
| `--allowed-tools`   | Дозвољени алати (одвојени запетом) |
| `--debug`           | Омогући дебаг излаз |

## Најбоље праксе

### Конфигурисање CLAUDE.md

У корену репозиторије креирајте `CLAUDE.md` датотеку, дефинишите смернице за стил кода, стандарде прегледа и пројектне норме, Claude ће аутоматски поштовати ова правила.

### Безбедносне напомене

- **Никада не** пишите API кључеве директно у Workflow датотекама
- Увек користите GitHub Secrets (као `${{ secrets.ANTHROPIC_API_KEY }}`)
- Ограничите дозволе Action на минимални неопходни опсег
- Ручно прегледајте Claude-ове предлоге пре спајања

### Контрола трошкова

- Користите јасне `@claude` команде да смањите непотребне API позиве
- Конфигуришите разумне `--max-turns` да ограничите број рунди разговора
- Поставите временске лимите на нивоу Workflow-а
- Користите GitHub-ову контролу паралелизма да ограничите број паралелних извршавања

## Честа питања

### Claude не одговара на @claude команде?

1. Потврдите да је Claude GitHub App исправно инсталиран
2. Проверите да ли је Workflow омогућен
3. Потврдите да је API кључ подешен као тајна у репозиторији
4. Уверите се да у коментару користите `@claude` (не `/claude`)
### Ошибка аутентификации?

1. Потврдите да ли је API кључ важећи и да ли има довољно дозвола
2. Проверите да ли је име секрета исправно (`ANTHROPIC_API_KEY`)
3. Ако користите `ANTHROPIC_BASE_URL`, потврдите да ли је URL исправан

### Како да видим преостали кредит?

Пријавите се на [AceData Cloud контролну таблу](https://platform.acedata.cloud/console) да бисте видели тренутни преостали кредит и коришћење.
