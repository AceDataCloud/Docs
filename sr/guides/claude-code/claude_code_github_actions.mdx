## 1. Добити API кључ

Отворите [Ace Data Cloud списак апликација](https://platform.acedata.cloud/console/applications), уђите у доступне апликације и копирајте API кључ.

![Добити Ace Data Cloud API кључ](https://cdn.acedata.cloud/dvc3cg.jpg)

У циљном GitHub репозиторијуму у **Settings → Secrets and variables → Actions** креирајте нови Secret:

```text
ACEDATACLOUD_API_KEY
```

## 2. Инсталирајте GitHub апликацију

Инсталирајте [Claude GitHub апликацију](https://github.com/apps/claude) и овластите циљни репозиторијум. Ова званична апликација ће затражити фиксни комплет дозвола; међу њима Claude Code Action заправо користи дозволе за Contents, Issues и Pull requests, а GitHub страница за инсталацију не може само да означи ове три ставке. Ако организација захтева минималне дозволе, молимо вас да креирате прилагођену GitHub апликацију према званичној документацији.

## 3. Додајте Workflow

Креирајте `.github/workflows/claude.yml`:

```yaml
name: Claude Code

on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  claude:
    if: contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      actions: read
      id-token: write
    env:
      ANTHROPIC_BASE_URL: https://api.acedata.cloud
      ANTHROPIC_CUSTOM_HEADERS: "Authorization: Bearer ${{ secrets.ACEDATACLOUD_API_KEY }}"
    steps:
      - uses: actions/checkout@v6
        with:
          fetch-depth: 1
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: dummy-not-used
```

`claude-code-action` захтева ненулти `anthropic_api_key` унос; овде постављена вредност неће бити коришћена за аутентификацију на платформи. `ANTHROPIC_CUSTOM_HEADERS` ће заменити Bearer Header потребан за Ace Data Cloud, а прави кључ долази само из GitHub Secret.

## 4. Потврда

Након слања Workflow-а, пошаљите у коментару на Issue или PR:

```text
@claude Reply only OK
```

Успешно, Actions workflow ће се завршити и ажурирати резултате у одговарајућем Issue/PR. Ако Action пријави недостајуће акредитиве, потврдите да `dummy-not-used` и даље постоји; 401 проверава `ACEDATACLOUD_API_KEY` Secret. Не штампајте Secret у логовима. Можете користити `claude_args` за подешавање `--max-turns` или избор тренутно доступног модела, али интеграција шаблона није фиксна.
