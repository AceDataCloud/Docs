## 1. Добијање API кључа

Отворите [Ace Data Cloud списак апликација](https://platform.acedata.cloud/console/applications), уђите у доступне апликације и копирајте API кључ.

![Добијање Ace Data Cloud API кључа](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Инсталирање CC Switch

Преузмите са [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), macOS такође може да ради:

```bash
brew install --cask cc-switch
```

## 3. Додавање Провајдера

Отворите CC Switch, изаберите **Claude Code → Add Provider → Custom**, попуните:

| Поље       | Вредност                      |
| ---------- | ----------------------------- |
| Name       | `Ace Data Cloud`             |
| Base URL   | `https://api.acedata.cloud`  |
| API Key    | управо копирани API кључ      |
| API Format | `Anthropic Messages`         |

Ако желите да користите JSON уредник, конфигуришите као:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

CC Switch ће написати конфигурацију у корисничке поставке Claude Code. Не чувајте прави кључ у тимском репозиторијуму и не задржавајте стари `ANTHROPIC_API_KEY`.

## 4. Омогућите и верификујте

Након чувања, омогућите **Ace Data Cloud**, поново отворите Claude Code. Пошаљите један једноставан задатак за читање и проверите позив у [историји коришћења](https://platform.acedata.cloud/console/usages). Ако се након преласка и даље користи стара конфигурација, потпуно изађите из Claude Code и CC Switch и покушајте поново.
