Claude Code је алат за **Agentic Coding** који је представио Anthropic, и сматра се једним од најмоћнијих програмских агената на свету. Терминал CLI је основно искуство Claude Code, можете да покренете команду `claude` у било ком терминалу и да комуницирате са AI-ом на природном језику.

Овај документ углавном описује како да инсталирате, конфигуришете и користите Claude Code CLI преко прокси услуге AceData Cloud у терминалу.

## Процес пријаве

Да бисте користили Claude Code, прво можете да одете на [Claude Messages услужну страницу](https://platform.acedata.cloud/documents/claude-messages) и кликнете на дугме „Acquire“ да бисте добили потребне креденцијале:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ако нисте пријављени или регистровани, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након пријаве и регистрације, аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, што вам омогућава да бесплатно испробате Claude Code услугу.

## Инсталација Claude Code

### Системски захтеви

- macOS, Linux или Windows (укључујући WSL)
- Node.js није обавезан, нативни начин инсталације ће аутоматски обрадити зависности

### Начини инсталације

Claude Code подржава више начина инсталације:

**Начин 1: Нативна инсталација (препоручено)**

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows CMD:

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**Начин 2: Homebrew (macOS / Linux)**

```bash
brew install claude-code
```

**Начин 3: WinGet (Windows)**

```cmd
winget install Claude.ClaudeCode
```

Нативна инсталација ће аутоматски ажурирати у позадини, увек одржавајући најновију верзију.

## Конфигурација AceData Cloud API

Након инсталације, подразумевано ће вас затражити да се пријавите на званични налог Anthropic. Можемо конфигурисати променљиве окружења да користимо AceData Cloud прокси API, **без званичне претплате**.

### Конфигурација променљивих окружења

Постоје два начина за конфигурисање променљивих окружења, можете изабрати било који.

**Начин 1: Постављање у конфигурационом фајлу Shell (препоручено)**

Додајте следећи садржај у ваш Shell конфигурациони фајл (`~/.zshrc`, `~/.bashrc` или `~/.bash_profile`), замените `{token}` са API токеном који сте добили у AceData Cloud конзоли:

```bash
# AceData Cloud - Claude Code прокси конфигурација
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Након измене, извршите следећу команду да бисте активирали конфигурацију:

```bash
source ~/.zshrc  # или source ~/.bashrc
```

**Начин 2: Постављање у Claude Code settings.json**

Уредите `~/.claude/settings.json` (ако не постоји, креирајте) и додајте `env` конфигурацију:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Предност овог начина је што променљиве окружења делују само на Claude Code и не утичу на друге програме.

> **Напомена**: API токен можете видети у [AceData Cloud конзоли](https://platform.acedata.cloud/console). Вредност `ANTHROPIC_AUTH_TOKEN` ће бити аутоматски додата `Bearer` префикс и послата серверу.

## Почните са коришћењем

### Покретање интерактивног режима

Отворите терминал, идите у директоријум вашег пројекта, а затим покрените:

```bash
cd /path/to/your/project
claude
```

Видећете добродошлицу Claude Code, једноставно унесите природни језик да бисте започели интеракцију.

### Често коришћене команде

| Команда               | Опис          | Пример                   |
| ---------------- | ----------- | -------------------- |
| `claude`         | Покретање интерактивног режима      | `claude`             |
| `claude "задатак"`    | Извршавање једнократног задатка     | `claude "поправи грешку у изградњи"`    |
| `claude -p "упит"` | Извршавање упита и излазак     | `claude -p "објасни ову функцију"` |
| `claude -c`      | Настављање последњег разговора у тренутном директоријуму | `claude -c`          |
| `claude -r`      | Обнављање претходног разговора     | `claude -r`          |
| `claude commit`  | Креирање Git комита   | `claude commit`      |

### Команде интерактивног режима

У интерактивном режиму можете користити следеће уграђене команде:

| Команда                | Функција        |
| ----------------- | --------- |
| `/help`           | Приказује информације о помоћи    |
| `/clear`          | Чисти историју разговора    |
| `/config`         | Отвара панел за подешавања    |
| `/model`          | Промена модела      |
| `/mcp`            | Управља MCP услугом |
| `/compact`        | Смањује контекст     |
| `/memory`         | Управља меморијом      |
| `/login`          | Промена налога      |
| `exit` или `Ctrl+C` | Излаз        |

### Примери интеракције у разговору

```bash
# Анализа пројекта
> шта ради овај пројекат?

# Поправка грешке
> постоји грешка где корисници могу да пошаљу празне форме - поправи то

# Писање тестова
> напиши јединичне тестове за функције калкулатора

# Рефакторисање кода
> рефакториши модул за аутентификацију да користи async/await

# Git операције
> комитуј моје промене са описним поруком
> креирај PR за ову функцију
```

## Напредна употреба

### Цеви и скриптирање

Claude Code следи Unix филозофију, подржавајући цеви и скриптирање:

```bash
# Мониторисање логова и аутоматско обавештавање
tail -f app.log | claude -p "ако се открије аномалија, обавести ме"

# Аутоматско превођење новог текста
claude -p "ако постоје нови текстуални низови, преведи на француски и креирај PR"

# Ревизија кода
git diff main | claude -p "ревидирај ове промене"
```

### Референца променљивих окружења

Следеће су уобичајене променљиве окружења које Claude Code подржава:

| Променљива                           | Опис                                    |
| ---------------------------- | ------------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`       | Вредност за прилагођени Authorization хедер (аутоматски додаје Bearer префикс) |
| `ANTHROPIC_API_KEY`          | API кључ (пошаљите као X-Api-Key хедер)              |
| `ANTHROPIC_BASE_URL`         | Основни URL API                            |
| `ANTHROPIC_MODEL`            | Прекрива подразумевани модел                                |
| `ANTHROPIC_SMALL_FAST_MODEL` | Haiku ниво модел (за позадинске задатке)                     |
| `MAX_THINKING_TOKENS`        | Поставља буџет за размишљање токене (поставите на 0 да онемогућите режим размишљања)            |
| `DISABLE_COST_WARNINGS`      | Поставите на 1 да онемогућите упозорења о трошковима                           |

### CLAUDE.md пројектна меморија

У коренском директоријуму пројекта креирајте `CLAUDE.md` фајл, можете пружити специфичне инструкције и контекст за Claude Code. Claude ће аутоматски учитати овај фајл при покретању.

```markdown
# Опис пројекта
Ово је full-stack пројекат Django + Vue.js.

## Кодне норме
- Користите Python 3.12
- Поштујте PEP 8 стил кода
- Сви API морају имати написане јединичне тестове
```

## Честа питања

### Шта урадити ако се не успе успоставити веза?
1. Proverite da li je datoteka `~/.claude/config.json` ispravno kreirana, sadržaj je `{"primaryApiKey": "self"}`
2. Potvrdite da su promenljive okruženja ispravno postavljene:
   ```bash
   echo $ANTHROPIC_AUTH_TOKEN
   echo $ANTHROPIC_BASE_URL
   ```
3. Potvrdite da je API token važeći (možete ga proveriti na [kontrolnoj tabli](https://platform.acedata.cloud/console))
4. Pokušajte da ponovo pokrenete terminal

### komanda nije pronađena: claude

Ako se nakon instalacije pojavi poruka `komanda nije pronađena`, pokušajte:

1. Zatvorite i ponovo otvorite terminal
2. Proverite PATH: `echo $PATH`
3. Ponovo instalirajte: `curl -fsSL https://claude.ai/install.sh | bash`

### Kako da proverim preostalu kvotu?

Prijavite se na [AceData Cloud kontrolnu tablu](https://platform.acedata.cloud/console) da biste videli trenutnu preostalu kvotu i korišćenje.
