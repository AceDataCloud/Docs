## 1. Добијање API кључа

Отворите [Ace Data Cloud списак апликација](https://platform.acedata.cloud/console/applications), уђите у доступне апликације и копирајте API кључ.

![Добијање Ace Data Cloud API кључа](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Инсталирање Claude Code

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
```

Проверите након инсталације:

```bash
claude --version
```

## 3. Конфигурисање Ace Data Cloud

Када се користи глобално, додајте следеће променљиве у `~/.zshrc` или `~/.bashrc`:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="ваш API кључ"
unset ANTHROPIC_API_KEY
```

Поново отворите терминал или `source` одговарајући конфигурациони фајл.

Када важи само за тренутни пројекат, можете креирати `.claude/settings.local.json` који је додат у `.gitignore`:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "ваш API кључ"
  }
}
```

Изаберите један од два начина. Не стављајте прави кључ у тимом делјеном `.claude/settings.json`; ако у окружењу већ постоји `ANTHROPIC_API_KEY`, требало би га стварно уклонити, а не поставити на празан низ.

## 4. Покретање и верификација

```bash
cd /path/to/your/project
claude
```

Уђите и пошаљите задатак само за читање, на пример "прочитај README.md и резимирај у једној реченици". Запис о позивима и стању можете видети на [историји коришћења](https://platform.acedata.cloud/console/usages) и [списку апликација](https://platform.acedata.cloud/console/applications).

Ако се врати 401, проверите да ли је кључ комплетан, да ли је стари `ANTHROPIC_API_KEY` уклоњен и потпуно поново покрените Claude Code. Модел не мора бити фиксно подешен у конфигурацији, можете изабрати тренутно доступан модел у Claude Code.
