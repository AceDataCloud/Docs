title: "Claude Code конфигурациони водич"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code је програмски агент који је развио Anthropic и може се користити у различитим окружењима као што su терминал, IDE, десктоп апликације и др. Кроз AceData Cloud агент, можете користити Claude Code по нижој цени.

Молимо вас да изаберете одговарајући конфигурациони водич у зависности од вашег сценарија коришћења:

| Платформа            | Опис                                        | Линк до водича                                                                                                   |
| ------------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **Терминал (CLI)**   | Језгро искуство, покрените `claude` у било ком терминалу                | [Конфигурациони водич за терминал](https://platform.acedata.cloud/documents/claude-code-terminal-integration)                    |
| **VS Code**        | Нативна екстензија, подржава инлајн Diff, @-помене, планиране прегледе            | [Конфигурациони водич за VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)               |
| **JetBrains IDE**  | Подржава IntelliJ IDEA, PyCharm, WebStorm и све остале IDE | [Конфигурациони водич за JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)          |
| **GitHub Actions** | Користите `@claude` за аутоматизацију прегледа кода и обраду проблема             | [Конфигурациони водич за GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Напомена**: При првом захтеву можете посетити [Claude Messages сервисну страницу](https://platform.acedata.cloud/documents/claude-messages) и кликнути на „Acquire“ да бисте добили потврду, што вам доноси бесплатан кредит.
