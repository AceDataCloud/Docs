Claude Code se povezuje sa Coding Plan putem Anthropic Messages protokola, trenutno nudi dva ulaza za konfiguraciju: terminal i VS Code.

| Ulaz za korišćenje | Vodič za konfiguraciju                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------ |
| Terminal / CLI     | [Claude Code terminal konfiguracija](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code            | [Claude Code za VS Code konfiguraciju](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## Zajednička konfiguracija

- Osnovni URL: `https://api.acedata.cloud`
- API Token: dobija se iz Coding Application i konfiguriše se putem `ANTHROPIC_AUTH_TOKEN` u vodiču
- Model ID: odabrati iz direktorijuma modela u realnom vremenu
- Nakon izmene konfiguracije: ponovo pokrenuti Claude Code; korisnici VS Code treba da osveže prozor

Ne čuvajte istovremeno stari `ANTHROPIC_API_KEY`, niti upisujte pravi Token u timske deljene datoteke.

Vratite se na [Coding Plan konfiguracioni centar](https://platform.acedata.cloud/documents/coding-plan-integration).
