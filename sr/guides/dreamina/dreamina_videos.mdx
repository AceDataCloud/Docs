## Идентитетни видео генератор API

`POST https://api.acedata.cloud/dreamina/videos`

Аудио покретни дигитални људски видео генератор (OmniHuman 1.5). Пружа једну фотографију особе и један аудио запис, генеришући видео у коме особа говори, синхронизованих покрета усана.

### Заглавље захтева

| Заглавље         | Вредност                     |
| ---------------- | --------------------------- |
| `Authorization`  | `Bearer &lt;ваш API кључ>`     |
| `Content-Type`   | `application/json`          |

### Параметри захтева

| Параметар        | Тип       | Обавезно | Објашњење                                                              |
| ---------------- | --------- | -------- | --------------------------------------------------------------------- |
| `model`          | string    | Не       | Модел, подразумевано `omnihuman-1.5`                                 |
| `image_url`      | string    | Да       | Јавни URL фотографије особе, препоручује се јасна фотографија лица     |
| `audio_url`      | string    | Да       | Јавни URL аудио записа (mp3/wav), препоручује се &lt; 60 секунди       |
| `prompt`         | string    | Не       | Контрола израза, емоција, стабилности и стила                        |
| `mask_url`       | string[]  | Не       | URL маске за главни објекат, за идентификацију објекта у слици са више људи |
| `callback_url`   | string    | Не       | Ако се унесе, одмах враћа `task_id`, резултат се враћа на ту адресу   |
| `async`          | boolean   | Не       | Ако је `true`, одмах враћа `task_id`, без потребе за `callback_url`, резултати се проверавају путем `/dreamina/tasks` |

### Савети за унос

- **Слика**: Јасна, добро осветљена фотографија лица је најбоља; лице без препрека, у разумној величини у кадру.
- **Аудио**: mp3/wav, мора бити доступан на јавном интернету. Препоручена дужина је до 60 секунди (1080p препоручено ≤30 секунди, 720p ≤60 секунди).
- `image_url` и `audio_url` морају бити доступни на јавном интернету.

### Пример одговора

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",
  "data": {
    "task_id": "362b4fed67bd11f1ad1100163e57d510",
    "status": "done",
    "video_url": "https://cdn.acedata.cloud/634d760216.mp4",
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }
}
```

### Асинхроно и упит

Интерфејс подразумевано синхроно враћа коначни видео. За дужи задатак, могу се користити два асинхрона режима:

- Унесите `callback_url`: Интерфејс одмах враћа `task_id`, резултат се враћа на ту адресу.
- Унесите `async: true`: Интерфејс одмах враћа `task_id`, а затим проверава резултате путем `POST /dreamina/tasks` (бесплатно) по `task_id` или `trace_id`.

Детаљи о упитима можете видети у [Dreamina Tasks API](https://platform.acedata.cloud/documents/dreamina-tasks-integration).

### Обрада грешака

| Статус код | код                                      | Значење                               |
| ---------- | ---------------------------------------- | ------------------------------------- |
| 400        | `bad_request`                            | Недостајући или неважећи параметри (нпр. `image_url` / `audio_url`) |
| 401        | `authorization_missing` / `invalid_token` | Недостаје или је неважећи ауторизациони токен                          |
| 403        | `forbidden`                              | Недостатак средстава/квота, или неовлашћено одобрење                  |
| 429        | `too_many_requests`                      | Превише захтева, прелази ограничење брзине                            |
| 500        | `api_error`                              | Унутрашња грешка сервера          |

```json
{
  "error": {
    "code": "bad_request",
    "message": "image_url is required (a public URL of a portrait image)"
  },
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

### Наплата

Наплата се врши по дужини генерисаног видеа, максимални пакет је око **¥1/сек** (нпр. видео од 10 секунди око ¥10).
