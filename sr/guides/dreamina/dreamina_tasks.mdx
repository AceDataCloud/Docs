## Dreamina Tasks API интеграција и употреба

Dreamina Tasks API се користи за упит о резултатима извршења видео задатака дигиталних људи створених помоћу [Dreamina Video Generation API](https://platform.acedata.cloud/documents/dreamina-videos-integration). Када у интерфејс за генерисање пошаљете `callback_url` или `async: true`, интерфејс ће одмах вратити `task_id`, који можете користити за периодичну проверу статуса задатка и коначне видео адресе помоћу овог интерфејса по `task_id` или `trace_id`. **Овај интерфејс је бесплатан.**

## Процес пријаве

Да бисте користили Dreamina серију API-ја, прво идите на [Ace Data Cloud контролна табла](https://platform.acedata.cloud/console/applications) да добијете свој API токен, који ћете задржати за резерву.

Ако нисте пријављени или регистровани, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након завршетка ћете бити аутоматски враћени на тренутну страницу.

**Један API токен је довољан за позивање свих услуга платформе, без потребе да се за сваку услугу посебно пријављујете.** При првом захтеву добићете бесплатну квоту, коју можете бесплатно испробати; када квота буде недовољна, можете допунити општи баланс на [контролној табли](https://platform.acedata.cloud/console/coin).

## Параметри захтева

**Request Headers**

- `accept`：одредите да примате одговор у JSON формату, упишите `application/json`.
- `authorization`：кључ за позивање API-ја, формат `Bearer {token}`.
- `content-type`：упишите `application/json`.

**Request Body**

| Параметар   | Тип       | Обавезно | Објашњење                                           |
| ----------- | --------- | -------- | -------------------------------------------------- |
| `action`    | string    | Не       | Тип операције, `retrieve` (подразумевано, упит за један) или `retrieve_batch` (партитно упит) |
| `id`        | string    | Не       | ИД задатка који се упитује (враћен при креирању видеа)                    |
| `trace_id`  | string    | Не       | ИД за праћење задатка који се упитује, може заменити `id`                         |
| `ids`       | string[]  | Не       | Листа ИД-ова задатака за партијски упит, користи се са `retrieve_batch`             |

> При упиту за један задатак, `id` и `trace_id` морају бити најмање један.

## Упит за један задатак

### CURL

```bash
curl -X POST 'https://api.acedata.cloud/dreamina/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "retrieve",
  "id": "362b4fed-67bd-11f1-ad11-00163e57d510"
}'
```

### Python

```python
import requests

url = "https://api.acedata.cloud/dreamina/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "retrieve",
    "id": "362b4fed-67bd-11f1-ad11-00163e57d510"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Пример одговора

Када је захтев успешан, API враћа детаље о задатку. `request` је тело захтева при креирању задатка, `response` је тело одговора након завршетка задатка, где `data.video_url` представља адресу генерисаног видеа дигиталног човека:

```json
{
  "id": "362b4fed-67bd-11f1-ad11-00163e57d510",
  "started_at": 1769262721.823,
  "finished_at": 1769262769.123,
  "elapsed": 47.3,
  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",
  "request": {
    "model": "omnihuman-1.5",
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  },
  "response": {
    "success": true,
    "data": {
      "task_id": "362b4fed67bd11f1ad1100163e57d510",
      "status": "done",
      "video_url": "https://cdn.acedata.cloud/634d760216.mp4",
      "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
      "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
    }
  }
}
```

Објашњење поља:

- `id`：Јединствени ИД задатка за генерисање видеа.
- `trace_id`：ИД за праћење овог захтева, корисно за решавање проблема.
- `request`：Садржај захтева поднет при креирању задатка.
- `response`：Садржај одговора који се враћа након завршетка задатка. Када `response.data.status` буде `done`, `response.data.video_url` ће бити коначна адреса видеа.
- `created_at`：Време креирања задатка, Unix временски жиг (секунде, флотантно).
- `started_at`：Време почетка извршења задатка, Unix временски жиг (секунде, флотантно).
- `finished_at`：Време завршетка задатка, Unix временски жиг (секунде, флотантно). Када задатак није завршен, ово поље се не враћа.
- `elapsed`：Време извршења задатка, у секундама (флотантно, задржава 3 децималне места). Када задатак није завршен, ово поље се не враћа.

> Ако задатак још није завршен, `status` може бити у стању које није `done`; ако задатак не постоји или резултати још нису генерисани, интерфејс ће вратити празан објекат `{}`, молимо покушајте поново касније.

## Партитно упит задатака

Поставите `action` на `retrieve_batch` и пошаљите `ids` низ:

```bash
curl -X POST 'https://api.acedata.cloud/dreamina/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "retrieve_batch",
  "ids": [
    "362b4fed-67bd-11f1-ad11-00163e57d510",
    "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70"
  ]
}'
```

У враћеном резултату, `items` је низ детаља о партијским задацима (сваки елемент има исти формат као резултат упита за један), `count` је број задатака враћених у овом захтеву.

## Обрада грешака

Када наиђете на грешку при позивању API-ја, враћаће се одговарајући код грешке и информације:

- `400 bad_request`：Грешка у захтеву, могуће недостају `id` / `trace_id` и други неопходни параметри.
- `401 invalid_token`：Није овлашћен, овлашћени токен је неважећи или недостаје.
- `429 too_many_requests`：Превише захтева, прелазите ограничење брзине.
- `500 api_error`：Унутрашња грешка сервера.

### Пример одговора на грешку

```json
{
  "error": {
    "code": "bad_request",
    "message": "id or trace_id is required to retrieve a task"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Закључак

Кроз овај документ, већ сте упознати са тим како да користите Dreamina Tasks API за упит о резултатима задатака дигиталних људи, било појединачно или у партијама. У комбинацији са интерфејсом за генерисање `callback_url` / `async` асинхроног режима, можете реализовати стабилно периодично повлачење. Уколико имате било каквих питања, слободно контактирајте наш технички подршку.
