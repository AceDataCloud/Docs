Kimi je serija AI modela koju je lansirao Mesec u tami. Trenutno preporučeni `kimi-k3` je usmeren na dugoročno programiranje, agente, složeno rezonovanje i rad sa znanjem, a može se pozvati putem OpenAI kompatibilnog Chat Completions API.

Ovaj dokument uglavnom opisuje proces korišćenja Kimi Chat Completion API, koristeći ga možemo lako koristiti zvanične Kimi funkcije za razgovor.

## Proces prijave

Da biste koristili Kimi Chat Completion API, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, čuvajući ga za kasnije.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token je dovoljan za pozivanje svih usluga na platformi, nije potrebno posebno se prijavljivati za svaku uslugu.** Prvi put kada se prijavite dobićete besplatnu kvotu, koju možete besplatno isprobati; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Potpuna dokumentacija: [Kimi Chat Completion API →](https://platform.acedata.cloud/documents/kimi-chat-completions)

## Osnovna upotreba

Sledeće možete popuniti odgovarajući sadržaj na interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/ej5ozg.png" width="400" className="m-auto" /></p>

Prvi put kada koristite ovaj interfejs, potrebno je da popunite najmanje tri sadržaja: `authorization` možete direktno izabrati iz padajuće liste; `model` se koristi za izbor Kimi modela, preporučuje se korišćenje `kimi-k3`; `messages` je niz poruka za razgovor, svaka poruka sadrži `role` i `content`, pri čemu `role` podržava `user`, `assistant`, `system` i `tool`.

Takođe možete primetiti da se sa desne strane generiše odgovarajući kod za pozivanje, možete kopirati kod i direktno ga pokrenuti, ili jednostavno kliknuti na dugme „Try“ za testiranje.

<p><img src="https://cdn.acedata.cloud/six7e3.png" width="400" className="m-auto" /></p>

Evo stvarnog K3 odgovora dobijenog korišćenjem `reasoning_effort: max` (propuštena su neiskorišćena proširena polja):

```json
{
  "id": "msg_2D4Btbg1WgvkNE3tCYkR4xGA",
  "object": "chat.completion",
  "created": 1784466588,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 86,
    "completion_tokens": 206,
    "total_tokens": 292
  }
}
```

Vraćeni rezultat ima više polja, koja su opisana u nastavku:

- `id`, ID generisanog zadatka razgovora, koji se koristi za jedinstvenu identifikaciju ovog zadatka razgovora.
- `model`, izabrani Kimi model sa zvanične stranice.
- `choices`, informacije o odgovorima koje Kimi daje na postavljena pitanja.
- `usage`: statističke informacije o tokenima za ovaj Q&A.

Među njima, `choices` sadrži informacije o Kimi-ovim odgovorima, a unutar njega `choices` sadrži konkretne informacije o Kimi-ovim odgovorima, što možete primetiti na slici.

<p><img src="https://cdn.acedata.cloud/tv9rul.png" width="400" className="m-auto" /></p>

Možete videti da `content` polje unutar `choices` sadrži konkretan sadržaj Kimi-ovog odgovora; K3 takođe može vratiti `reasoning_content`, koje se koristi za prikazivanje procesa rezonovanja.

## K3 intenzitet rezonovanja

`kimi-k3` uvek aktivira rezonovanje. Na vrhu tela zahteva podržava se polje `reasoning_effort`, trenutno jedina podržana vrednost je `max`; ako se ovo polje izostavi, takođe se koristi `max`. `standard`, `high` ili druge string vrednosti mogu biti delimično prihvaćene od strane kompatibilnih sistema, ali ne garantuju promenu u ponašanju rezonovanja, nemojte se oslanjati na to.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3",
    "messages": [{"role": "user", "content": "Pregledajte ovaj kod i dajte rešenje"}],
    "reasoning_effort": "max"
  }'
```

Kada koristite OpenAI SDK, možete direktno proslediti ovo polje:

```python
response = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "Dizajnirajte pouzdanu red čekanja"}],
    reasoning_effort="max",
)
```

U višekratnim razgovorima i pozivima alata, molimo vas da prenesete celu prethodnu poruku asistenta u `messages`, uključujući `reasoning_content` i `tool_calls`.

### Zvanična referenca

- [Thinking Effort](https://platform.kimi.ai/docs/guide/use-thinking-effort): objašnjava da Kimi K3 uvek aktivira rezonovanje, trenutna jedina podržana vrednost za `reasoning_effort` je `max`.
- [Model Parameter Reference](https://platform.kimi.ai/docs/api/models-overview): upoređuje parametre rezonovanja, kontekstualni prozor i razlike u pozivima alata između K3 i K2 serije.
- [Create Chat Completion](https://platform.kimi.ai/docs/api/chat): zvanični zahtevi, odgovori i definicije OpenAPI za Chat Completions.

## Stream odgovori

Ovaj interfejs takođe podržava stream odgovore, što je veoma korisno za integraciju sa web stranicama, omogućavajući postizanje efekta prikazivanja reči po reč.

Ako želite da se odgovori vraćaju u stream-u, možete promeniti `stream` parametar u zaglavlju zahteva na `true`.

Izmena je prikazana na slici, ali kod poziva mora imati odgovarajuće izmene da bi podržao stream odgovore.

<p><img src="https://cdn.acedata.cloud/a3nzpw.png" width="400" className="m-auto" /></p>

Kada promenite `stream` na `true`, API će vraćati odgovarajuće JSON podatke red po red, a na kodnom nivou moramo napraviti odgovarajuće izmene da bismo dobili rezultate red po red.

Python primer poziva koda:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"user","content":"Hello"}],
    "reasoning_effort": "max",
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

U nastavku su izvučeni delovi iz stvarnog K3 Max stream odgovora, uključujući početak, rezonovanje, telo, završetak i podatke o upotrebi:
```json
data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"","role":"assistant"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"reasoning_content":"The"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"Zdravo"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{},"finish_reason":"stop"}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[],"usage":{"prompt_tokens":172,"completion_tokens":168,"total_tokens":340}}

data: [DONE]
```

Možete videti da u odgovoru ima mnogo `data`, a `data` unutar `choices` predstavlja najnoviji sadržaj odgovora, u skladu sa prethodno opisanim sadržajem. `choices` su novi odgovori, koje možete povezati sa vašim sistemom. Takođe, završetak strimovane odgovore se određuje na osnovu sadržaja `data`, ako je sadržaj `[DONE]`, to znači da je strimovani odgovor potpuno završen. Vraćeni `data` rezultati imaju više polja, opisi su sledeći:

- `id`, ID koji generiše ovu razgovornu zadatak, koristi se za jedinstvenu identifikaciju ovog razgovora.
- `model`, izabrani Kimi model sa zvanične stranice.
- `choices`, odgovori koje Kimi daje na postavljena pitanja.

JavaScript takođe podržava, na primer, kod za strimovano pozivanje u Node.js je sledeći:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "kimi-k3",
    messages: [{ role: "user", content: "Zdravo" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

Java uzorak koda:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "kimi-k3");
jsonObject.put("messages", new JSONArray().put(new JSONObject().put("role", "user").put("content", "Zdravo")));
jsonObject.put("stream", true);
MediaType mediaType = MediaType.parse("application/json; charset=utf-8");
RequestBody body = RequestBody.create(jsonObject.toString(), mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/kimi/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.println(response.body().string());
```

Ostali jezici mogu se prepraviti na sličan način, princip je isti.

## Višekratni razgovor

Ako želite da povežete funkciju višekratnog razgovora, potrebno je da u `messages` polje pošaljete više pitanja, primeri više pitanja su prikazani na slici ispod:

<p><img src="https://cdn.acedata.cloud/g85v2a.png" width="400" className="m-auto" /></p>

Python uzorak poziva:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"assistant","content":"Zdravo! Kako mogu da vam pomognem danas?"},{"role":"user","content":"Koji si model?"}],
    "reasoning_effort": "max"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Slanjem više pitanja, lako možete ostvariti višekratni razgovor. Sledeći je stvarni odgovor K3 Max (izostavljeni su neiskorišćeni prošireni podaci):


Možete primetiti da informacije unutar `choices` su u skladu sa osnovnom upotrebom, ovo sadrži konkretne odgovore Kimi na više razgovora, tako da možete odgovoriti na odgovarajuća pitanja na osnovu više razgovora.

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
