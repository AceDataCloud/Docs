Kimi je veoma moćan AI sistem za razgovor, samo unesite ključne reči i u samo nekoliko sekundi generiše tečne i prirodne odgovore. Kimi može pružiti zapanjujuću inteligentnu pomoć, značajno povećavajući ljudsku radnu efikasnost i kreativnost.

Ovaj dokument uglavnom opisuje proces korišćenja Kimi Chat Completion API, koristeći ga možemo lako koristiti zvanične Kimi funkcije razgovora.

## Proces prijave

Da biste koristili Gemini Chat Completion API, prvo možete otići na [Kimi Chat Completion API](https://platform.acedata.cloud/documents/b23bbfa3-c820-47ee-b307-6c6dedc9d0cf) stranicu i kliknuti na dugme „Acquire“ da dobijete potrebne akreditive za zahtev:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Osnovna upotreba

Sledeće možete popuniti odgovarajući sadržaj na interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/ej5ozg.png" width="400" className="m-auto" /></p>

Prilikom prvog korišćenja ovog interfejsa, potrebno je da popunite najmanje tri sadržaja, jedan je `authorization`, koji možete direktno odabrati iz padajuće liste. Drugi parametar je `model`, `model` je kategorija modela koju biramo da koristimo sa Kimi zvanične stranice, ovde imamo 7 vrsta modela, detalje možete pogledati u modelima koje pružamo. Poslednji parametar je `messages`, `messages` je niz naših unetih pitanja, to je niz koji može istovremeno preneti više pitanja, svako pitanje sadrži `role` i `content`, gde `role` označava ulogu postavljača pitanja, pružili smo tri identiteta: `user`, `assistant`, `system`. Drugi `content` je konkretan sadržaj našeg pitanja.

Takođe možete primetiti da se sa desne strane generiše odgovarajući kod za pozivanje, možete kopirati kod i direktno ga pokrenuti, ili jednostavno kliknuti na dugme „Try“ za testiranje.

## Tok odgovora

Ovaj interfejs takođe podržava tok odgovora, što je veoma korisno za integraciju sa web stranicama, omogućavajući postepeno prikazivanje efekta.

Ako želite da odgovor bude u toku, možete promeniti `stream` parametar u zaglavlju zahteva na `true`.

Izmena je prikazana na slici, ali kod poziva mora imati odgovarajuće izmene da bi podržao tok odgovora.

<p><img src="https://cdn.acedata.cloud/a3nzpw.png" width="400" className="m-auto" /></p>

Nakon što promenite `stream` na `true`, API će vraćati odgovarajući JSON podatak red po red, a na kodnom nivou moramo napraviti odgovarajuće izmene da bismo dobili rezultate red po red.

Python uzorak koda za poziv:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k2.5",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Možete videti da u odgovoru ima mnogo `data`, a `data` unutar `choices` predstavlja najnoviji sadržaj odgovora, što je u skladu sa prethodno predstavljenim sadržajem. `choices` su novi odgovori, a možete ih povezati sa vašim sistemom na osnovu rezultata. Takođe, kraj strimovanog odgovora se određuje na osnovu sadržaja `data`, ako je sadržaj `[DONE]`, to znači da je strimovani odgovor potpuno završen. Vraćeni `data` rezultati imaju više polja, koja su opisana u nastavku:

- `id`, ID generisanog zadatka razgovora, koji se koristi za jedinstvenu identifikaciju ovog zadatka razgovora.
- `model`, izabrani model sa Kimi zvanične stranice.
- `choices`, informacije o odgovorima koje Kimi daje na postavljena pitanja.

JavaScript je takođe podržan, na primer, kod za strimovano pozivanje u Node.js je sledeći:

```javascript
const options = {
  method: "post",
  headers: {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    "model": "kimi-k2.5",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": true
  })
};

fetch("https://api.acedata.cloud/kimi/chat/completions", options)
  .then(response => response.json())
  .then(response => console.log(response))
  .catch(err => console.error(err));
```

Java uzorak koda:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "kimi-k2.5");
jsonObject.put("messages", [{"role":"user","content":"Hello"}]);
jsonObject.put("stream", true);
MediaType mediaType = "application/json; charset=utf-8".toMediaType();
RequestBody body = jsonObject.toString().toRequestBody(mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/kimi/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.print(response.body!!.string())
```

Ostale jezike možete prepraviti sami, princip je isti.

## Višekratni razgovor

Ako želite da povežete funkciju višekratnog razgovora, potrebno je da u `messages` polje pošaljete više pitanja, a konkretni primeri više pitanja su prikazani na sledećoj slici:

Python uzorak pozivanja koda:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k2.5",
    "messages": [{"role":"assistant","content":"Hello! How can I help you today?"},{"role":"user","content":"What model are you?"}]

response = requests.post(url, json=payload, headers=headers)

```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
