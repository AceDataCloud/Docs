Kimi je serija AI modela koju je predstavio Moonshot AI. Trenutno se preporučuje `kimi-k3.1-pro`, pogodan za dugotrajno programiranje, složeno rezonovanje, vizuelno razumevanje i rad sa znanjem; `kimi-k3` se i dalje može koristiti. Poziva se putem OpenAI kompatibilnog Chat Completions API-ja.

Ovaj dokument uglavnom predstavlja proces korišćenja Kimi Chat Completion API operacija, pomoću kojeg možemo lako koristiti zvanične Kimi funkcije razgovora.

## Proces prijave

Da biste koristili Kimi Chat Completion API, prvo idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications) da biste dobili svoj API Token i sačuvali ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu gde ćete biti pozvani da se registrujete i prijavite, a nakon završetka automatski ćete se vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe za zasebnom prijavom za svaku uslugu.** Prilikom prve prijave dobijate besplatan kredit, koji možete besplatno isprobati; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Kimi Chat Completion API →](https://platform.acedata.cloud/documents/kimi-chat-completions)

## Osnovno korišćenje

Zatim možete popuniti odgovarajući sadržaj u interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/ej5ozg.png" width="400" className="m-auto" /></p>

Prilikom prvog korišćenja ovog interfejsa, potrebno je popuniti najmanje tri sadržaja: `authorization` se može direktno izabrati iz padajuće liste; `model` se koristi za izbor Kimi modela, preporučuje se korišćenje `kimi-k3.1-pro`; `messages` je niz poruka razgovora, pri čemu svaka poruka sadrži `role` i `content`, a `role` podržava `user`, `assistant`, `system` i `tool`.

Istovremeno možete primetiti da se na desnoj strani generiše odgovarajući kod za pozivanje, možete kopirati kod i direktno ga pokrenuti, a možete i direktno kliknuti na dugme „Try“ radi testiranja.

<p><img src="https://cdn.acedata.cloud/six7e3.png" width="400" className="m-auto" /></p>

Sledeće je stvarni K3 odgovor dobijen korišćenjem `reasoning_effort: max` (neiskorišćena proširena polja su izostavljena):

```json
{
  "id": "msg_2D4Btbg1WgvkNE3tCYkR4xGA",
  "object": "chat.completion",
  "created": 1784466588,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 86,
    "completion_tokens": 206,
    "total_tokens": 292
  }
}
```

Rezultat vraća više polja, koja su predstavljena u nastavku:

- `id`, ID generisan za ovaj zadatak razgovora, koristi se za jedinstvenu identifikaciju ovog zadatka razgovora.
- `model `, izabrani model sa zvaničnog Kimi sajta.
- `choices` informacije o odgovoru koji Kimi daje na upit.
- `usage `: statističke informacije o tokenima za ovaj par pitanja i odgovora.

Među njima, `choices` sadrži informacije o Kimi odgovoru, a `choices` unutar njega su konkretne informacije o Kimi odgovoru, kao što se može videti na slici.

<p><img src="https://cdn.acedata.cloud/tv9rul.png" width="400" className="m-auto" /></p>

Može se videti da polje `content` unutar `choices` sadrži konkretan sadržaj Kimi odgovora; K3 takođe može vratiti `reasoning_content`, koji se koristi za prikaz procesa rezonovanja.

## K3.1 Pro intenzitet rezonovanja

`kimi-k3.1-pro` uvek uključuje rezonovanje. Na najvišem nivou tela zahteva možete postaviti `reasoning_effort` na `low`, `high` ili `max`; nemojte prosleđivati konfiguraciju za isključivanje rezonovanja. Model podržava kontekst do 1.048.576 tokena, ali stvarno ograničenje zahteva i dalje zavisi od trenutnog interfejsa. Cena se obračunava prema korišćenju ulaza, izlaza i pogodaka keša, a detalje pogledajte na Pricing kartici u katalogu modela.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3.1-pro",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "low"
  }'
```

Sledeći K3 primeri su zadržani za postojeće integracije, a primeri odgovora su zaista dobijeni K3 zahtevima.

## K3 intenzitet rezonovanja

`kimi-k3` uvek uključuje rezonovanje. Najviši nivo tela zahteva podržava polje `reasoning_effort`, a trenutno jedina podržana vrednost je `max`; kada se ovo polje izostavi, takođe se koristi `max`. `standard`, `high` ili drugi stringovi mogu biti labavo prihvaćeni od strane nekih kompatibilnih uzvodnih sistema, ali nije garantovano da menjaju ponašanje rezonovanja, stoga se nemojte oslanjati na njih.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "max"
  }'
```

Kada koristite OpenAI SDK, možete direktno proslediti ovo polje:

```python
response = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "设计一个可靠的任务队列"}],
    reasoning_effort="max",
)
```

Kod višekružnog razgovora i pozivanja alata, vratite kompletnu assistant poruku iz prethodnog kruga u `messages`, uključujući `reasoning_content` i `tool_calls`.

### Zvanične reference

- [Thinking Effort](https://platform.kimi.ai/docs/guide/use-thinking-effort): objašnjava da Kimi K3 uvek uključuje rezonovanje i da je trenutno jedina podržana vrednost za `reasoning_effort` `max`.
- [Model Parameter Reference](https://platform.kimi.ai/docs/api/models-overview): poredi parametre rezonovanja, prozor konteksta i razlike u pozivanju alata između K3 i K2 serija.
- [Create Chat Completion](https://platform.kimi.ai/docs/api/chat): Moonshot zvanične definicije zahteva, odgovora i OpenAPI polja za Chat Completions.

## Strimovani odgovor

Ovaj interfejs takođe podržava strimovane odgovore, što je veoma korisno za povezivanje sa veb stranicama i može omogućiti efekat prikaza znak po znak na veb stranici.

Ako želite da odgovor bude vraćen strimovano, možete izmeniti parametar `stream ` u zaglavlju zahteva na `true`.

Izmena je prikazana na slici, ali kod za pozivanje mora imati odgovarajuće izmene da bi podržao strimovane odgovore.

<p><img src="https://cdn.acedata.cloud/a3nzpw.png" width="400" className="m-auto" /></p>

Nakon što se `stream` izmeni na `true`, API će red po red vraćati odgovarajuće JSON podatke, a na nivou koda potrebno je izvršiti odgovarajuće izmene kako bi se dobili rezultati red po red.

Primer Python koda za pozivanje:
```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"user","content":"Hello"}],
    "reasoning_effort": "max",
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

U nastavku su izdvojeni početni, rezonujući, tekstualni, završni blokovi i blokovi podataka o upotrebi iz istog stvarnog K3 Max strimovanog odgovora:

```json
data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"","role":"assistant"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"reasoning_content":"The"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"Hello"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{},"finish_reason":"stop"}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[],"usage":{"prompt_tokens":172,"completion_tokens":168,"total_tokens":340}}

data: [DONE]
```

Može se videti da u odgovoru postoji mnogo `data`, a `choices` unutar `data` predstavlja najnoviji sadržaj odgovora, što je u skladu sa prethodno predstavljenim sadržajem. `choices` je novododati sadržaj odgovora, a vi možete na osnovu rezultata da ga povežete sa svojim sistemom. Istovremeno, završetak strimovanog odgovora procenjuje se na osnovu sadržaja `data`; ako je sadržaj `[DONE]`, to znači da je odgovor strimovanog odgovora u potpunosti završen. Vraćeni rezultat `data` ukupno ima više polja, koja su predstavljena u nastavku:

- `id`, ID zadatka za generisanje ovog razgovora, koji se koristi za jedinstvenu identifikaciju ovog zadatka razgovora.
- `model `, izabrani Kimi model sa zvaničnog sajta.
- `choices`, informacije o odgovoru koje Kimi daje na upit.

JavaScript je takođe podržan, na primer, Node.js kod za strimovani poziv je sledeći:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "kimi-k3",
    messages: [{ role: "user", content: "Hello" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

Primer Java koda:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "kimi-k3");
jsonObject.put("messages", new JSONArray().put(new JSONObject().put("role", "user").put("content", "Hello")));
jsonObject.put("stream", true);
MediaType mediaType = MediaType.parse("application/json; charset=utf-8");
RequestBody body = RequestBody.create(jsonObject.toString(), mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/kimi/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.println(response.body().string());
```

Ostali jezici se mogu dodatno samostalno prepraviti, princip je isti.

## Višekružni razgovor

Ako želite da povežete funkcionalnost višekružnog razgovora, potrebno je da otpremite više upita u polje `messages`; konkretan primer više upita prikazan je na slici ispod:

<p><img src="https://cdn.acedata.cloud/g85v2a.png" width="400" className="m-auto" /></p>

Primer Python koda za poziv:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"assistant","content":"Hello! How can I help you today?"},{"role":"user","content":"What model are you?"}],
    "reasoning_effort": "max"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Otprema više upita omogućava lako ostvarivanje višekružnog razgovora. U nastavku je stvarni K3 Max odgovor dobijen ovim zahtevom (neupotrebljena proširena polja su izostavljena):

```json
{
  "id": "msg_Rqp8nPGBDHWwBlL4VpxuafOp",
  "object": "chat.completion",
  "created": 1784466628,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,

        "role": "assistant",
```

Može se videti da su informacije sadržane u `choices` u skladu sa sadržajem osnovne upotrebe; ovo sadrži konkretan sadržaj Kimi odgovora na više razgovora, tako da se na osnovu sadržaja više razgovora mogu odgovoriti odgovarajuća pitanja.

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neovlašćen pristup, nevažeći ili nedostajući token za autorizaciju.
- `429 too_many_requests`：Previše zahteva, prekoračili ste ograničenje stope.
- `500 api_error`：Interna greška servera, nešto je pošlo po zlu na serveru.
