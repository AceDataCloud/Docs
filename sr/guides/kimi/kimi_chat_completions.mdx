Kimi je serija AI modela koju je predstavila kompanija Moonshot. Trenutno se preporučuje `kimi-k3.1-pro`, pogodan za dugotrajno programiranje, složeno zaključivanje, vizuelno razumevanje i rad sa znanjem; `kimi-k3` se i dalje može koristiti. Pozivanje se vrši putem OpenAI-kompatibilnog Chat Completions API-ja.

Ovaj dokument uglavnom predstavlja postupak korišćenja Kimi Chat Completion API-ja, pomoću kojeg možemo jednostavno koristiti zvaničnu Kimi funkciju za razgovor.

## Podržani modeli

Trenutno su podržana četiri modela: `kimi-k3.1-pro`, `kimi-k3`, `kimi-k2.6` i `kimi-k2.7-code`. K2.7 Code je namenjen programiranju i scenarijima pozivanja alata, a naplaćuje se po istoj ceni kao K2.6; u zahtevima nemojte prosleđivati prekidač `thinking` niti `reasoning_effort`. Podrška za ostale Kimi modele je obustavljena, zato u klijentu eksplicitno izaberite jedan od ova četiri modela.

## Postupak prijave

Da biste koristili Kimi Chat Completion API, najpre posetite [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) i preuzmite svoj API Token kako biste ga sačuvali za kasniju upotrebu.

![]()

Ako još niste prijavljeni ili registrovani, sistem će vas automatski preusmeriti na stranicu za prijavu i registraciju. Nakon završetka postupka, automatski ćete se vratiti na trenutnu stranicu.

**Jedan API Token omogućava pozivanje svih usluga platforme, bez potrebe za zasebnim podnošenjem zahteva za svaku uslugu.** Prilikom prve prijave dobijate besplatni kredit koji možete iskoristiti za besplatno testiranje; kada kredit nije dovoljan, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Kimi Chat Completion API →](https://platform.acedata.cloud/documents/kimi-chat-completions)

## Osnovna upotreba

Zatim možete popuniti odgovarajuće podatke u interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/ej5ozg.png" width="400" className="m-auto" /></p>

Prilikom prvog korišćenja ovog API-ja potrebno je popuniti najmanje tri stavke: `authorization` možete direktno izabrati sa padajuće liste; `model` služi za izbor Kimi modela, a preporučuje se korišćenje modela `kimi-k3.1-pro`; `messages` predstavlja niz poruka razgovora, pri čemu svaka poruka sadrži `role` i `content`, a `role` podržava vrednosti `user`, `assistant`, `system` i `tool`.

Istovremeno možete primetiti da se sa desne strane automatski generiše odgovarajući kod za pozivanje. Možete kopirati kod i direktno ga pokrenuti ili kliknuti na dugme „Try“ da biste izvršili testiranje.

<p><img src="https://cdn.acedata.cloud/six7e3.png" width="400" className="m-auto" /></p>

U nastavku je stvarni odgovor modela K3 dobijen korišćenjem `reasoning_effort: max` (izostavljena su nekorišćena proširena polja):

```json
{
  "id": "msg_2D4Btbg1WgvkNE3tCYkR4xGA",
  "object": "chat.completion",
  "created": 1784466588,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 86,
    "completion_tokens": 206,
    "total_tokens": 292
  }
}
```

Vraćeni rezultat sadrži više polja, koja su predstavljena u nastavku:

- `id` predstavlja ID generisanog zadatka razgovora i koristi se za jedinstvenu identifikaciju tog zadatka.
- `model ` predstavlja izabrani model sa zvaničnog Kimi sajta.
- `choices` predstavlja informacije o odgovoru koji je Kimi dao na postavljeno pitanje.
- `usage `: statističke informacije o broju tokena korišćenih u ovom razgovoru.

Među njima, `choices` sadrži informacije o Kimi odgovoru, a `choices` unutar njega sadrži konkretne informacije o odgovoru koji je Kimi generisao, što se može videti na slici.

<p><img src="https://cdn.acedata.cloud/tv9rul.png" width="400" className="m-auto" /></p>

Može se videti da polje `content` unutar `choices` sadrži konkretan sadržaj Kimi odgovora; K3 takođe može vratiti `reasoning_content`, koji služi za prikaz procesa zaključivanja.

## Intenzitet zaključivanja modela K3.1 Pro

`kimi-k3.1-pro` uvek ima omogućeno zaključivanje. Na najvišem nivou tela zahteva možete postaviti `reasoning_effort` na `low`, `high` ili `max`; nemojte prosleđivati konfiguraciju koja isključuje zaključivanje. Model podržava kontekst do 1.048.576 tokena, ali stvarno ograničenje zahteva i dalje zavisi od trenutnog API-ja. Cena se obračunava na osnovu ulazne i izlazne potrošnje, kao i količine pogodaka u kešu. Više detalja potražite na kartici Pricing u katalogu modela.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3.1-pro",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "low"
  }'
```

Sledeći primer za K3 zadržan je radi postojećih integracija, a prikazani odgovor zaista je dobijen slanjem zahteva modelu K3.

## Intenzitet zaključivanja modela K3

`kimi-k3` uvek ima omogućeno zaključivanje. Na najvišem nivou tela zahteva podržano je polje `reasoning_effort`, a trenutno jedina podržana vrednost je `max`; ako izostavite ovo polje, takođe će se koristiti `max`. Koristite samo podržane vrednosti.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "max"
  }'
```

Prilikom korišćenja OpenAI SDK-a ovo polje možete direktno proslediti:

```python
response = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "设计一个可靠的任务队列"}],
    reasoning_effort="max",
)
```

Prilikom višekružnih razgovora i pozivanja alata, vratite kompletnu assistant poruku iz prethodnog kruga u `messages`, uključujući `reasoning_content` i `tool_calls`.

### Zvanične reference

- [Thinking Effort](https://platform.kimi.ai/docs/guide/use-thinking-effort)：Objašnjava da je zaključivanje u Kimi K3 uvek omogućeno i da je jedina trenutno podržana vrednost za `reasoning_effort` `max`.
- [Model Parameter Reference](https://platform.kimi.ai/docs/api/models-overview)：Upoređuje parametre zaključivanja, veličinu kontekstnog prozora i razlike u pozivanju alata između serija K3 i K2.
- [Create Chat Completion](https://platform.kimi.ai/docs/api/chat)：Zvanična Moonshot definicija zahteva, odgovora i OpenAPI polja za Chat Completions.

## Strimovani odgovor

Ovaj API takođe podržava strimovane odgovore, što je veoma korisno za integraciju sa veb-stranicama, jer omogućava prikazivanje teksta znak po znak.

Ako želite da odgovor bude vraćen u strimovanom obliku, promenite parametar `stream ` u zaglavljima zahteva na `true`.

Izmenite ga kao što je prikazano na slici, ali je potrebno odgovarajuće izmeniti i kod za pozivanje kako bi podržavao strimovane odgovore.

<p><img src="https://cdn.acedata.cloud/a3nzpw.png" width="400" className="m-auto" /></p>
Nakon što `stream` izmenite u `true`, API će vraćati odgovarajuće JSON podatke red po red. Na nivou koda potrebno je izvršiti odgovarajuće izmene kako bismo dobili rezultate red po red.

Primer pozivnog koda u Python-u:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"user","content":"Hello"}],
    "reasoning_effort": "max",
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

U nastavku su izdvojeni početni, misaoni, tekstualni, završni i blokovi podataka o potrošnji iz istog stvarnog K3 Max striming odgovora:

```json
data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"","role":"assistant"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"reasoning_content":"The"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"Hello"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{},"finish_reason":"stop"}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[],"usage":{"prompt_tokens":172,"completion_tokens":168,"total_tokens":340}}

data: [DONE]
```

Kao što se može videti, odgovor sadrži mnogo stavki `data`, a `choices` unutar stavke `data` predstavlja najnoviji sadržaj odgovora, što je u skladu sa prethodno opisanim sadržajem. `choices` sadrži novododati sadržaj odgovora, koji možete povezati sa svojim sistemom na osnovu dobijenih rezultata. Istovremeno, kraj striming odgovora određuje se na osnovu sadržaja stavke `data`. Ako je sadržaj `[DONE]`, to znači da je striming odgovor u potpunosti završen. Vraćeni rezultat `data` sadrži ukupno nekoliko polja, koja su opisana u nastavku:

- `id`, ID generisan za ovaj zadatak razgovora, koji se koristi za jedinstvenu identifikaciju zadatka razgovora.
- `model `, izabrani model sa zvaničnog Kimi sajta.
- `choices`, informacije o odgovoru koji Kimi daje na osnovu upita.

Podržan je i JavaScript, na primer, kod za striming poziv u Node.js-u izgleda ovako:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "kimi-k3",
    messages: [{ role: "user", content: "Hello" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

Primer koda u Javi:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "kimi-k3");
jsonObject.put("messages", new JSONArray().put(new JSONObject().put("role", "user").put("content", "Hello")));
jsonObject.put("stream", true);
MediaType mediaType = MediaType.parse("application/json; charset=utf-8");
RequestBody body = RequestBody.create(jsonObject.toString(), mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/kimi/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.println(response.body().string());
```

Za druge programske jezike možete samostalno prilagoditi kod, princip je isti.

## Višekružni razgovor

Ako želite da integrišete funkciju višekružnog razgovora, potrebno je da u polje `messages` pošaljete više upita. Konkretan primer više upita prikazan je na sledećoj slici:

<p><img src="https://cdn.acedata.cloud/g85v2a.png" width="400" className="m-auto" /></p>

Primer pozivnog koda u Python-u:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"assistant","content":"Hello! How can I help you today?"},{"role":"user","content":"What model are you?"}],
    "reasoning_effort": "max"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Slanjem više upita možete jednostavno ostvariti višekružni razgovor. U nastavku je prikazan stvarni K3 Max odgovor dobijen ovim zahtevom (izostavljena su neiskorišćena dodatna polja):

```json
{
  "id": "msg_Rqp8nPGBDHWwBlL4VpxuafOp",
  "object": "chat.completion",
  "created": 1784466628,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "I’m Kimi, an AI assistant developed by Moonshot AI (月之暗面). I don’t have a specific public model version identifier to share from here."
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 134,
    "completion_tokens": 346,
    "total_tokens": 480
  }
}
```

Kao što se može videti, informacije sadržane u `choices` iste su kao i kod osnovne upotrebe. One obuhvataju konkretan sadržaj odgovora koji Kimi daje na osnovu više poruka, tako da se odgovori na odgovarajuća pitanja mogu generisati na osnovu sadržaja više razgovora.

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`: Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`: Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`: Too many requests, you have exceeded the rate limit.
- `500 api_error`: Internal server error, something went wrong on the server.
