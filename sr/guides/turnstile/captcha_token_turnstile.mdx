Ovaj dokument će predstaviti način integracije Cloudflare Turnstile protokola prepoznavanja API, koji omogućava korisnicima da ne prepoznaju i ne klikću na Turnstile CAPTCHA, već samo da pošalju Website Key kako bi se automatski dekodirali u pozadini i završila verifikacija.

## Proces Prijave

Da biste koristili Cloudflare Turnstile protokol prepoznavanja API, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, koji treba sačuvati.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozvati sve usluge platforme, bez potrebe da se za svaku uslugu posebno prijavljujete.** Prvi put kada se prijavite, dobićete besplatnu kvotu za probu; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Puna dokumentacija: [Cloudflare Turnstile protokol prepoznavanja API →](https://platform.acedata.cloud/documents/captcha-token-turnstile)

## Osnovna Upotreba

Prvo se upoznajte sa osnovnim načinom korišćenja, što podrazumeva unos URL-a sajta koji treba obraditi sa Turnstile CAPTCHA, kako biste dobili obrađeni rezultat. Prvo je potrebno jednostavno proslediti polje `website_url`, naš primer sajta je: `https://react-turnstile.vercel.app`, a potrebno je na `website_url` stranici dobiti `website_key`. Prvo otvorite ovu stranicu, pritisnite F12 da uđete u konzolu, a zatim na Element stranici izvršite globalnu pretragu za `cf-turnstile`, gde možete pronaći kontejnerski element koji sadrži Turnstile, a niz stringova koji odgovara `data-sitekey` je vrednost `website_key`.

Podešeni Request Headers uključuju:

- `accept`: format odgovora koji želite da primite, ovde se unosi `application/json`, što znači JSON format.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno izabrati nakon prijave.

Takođe je podešen Request Body, koji uključuje:

- `website_url`: URL sajta koji treba obraditi.
- `website_key`: identifikator sajta u Cloudflare Turnstile (sitekey).
- `action`: opcioni parametar, koji se prosleđuje samo kada je ciljni sajt postavio prilagođeni `action` za Turnstile komponentu.
- `cdata`: opcioni parametar, koji se prosleđuje samo kada je ciljni sajt postavio prilagođeni `cData` za Turnstile komponentu.

Kliknite na dugme „Try“ da biste izvršili test, i ovde dobijamo sledeći rezultat:

```json
{
  "token": "0.mNQ2f9uP6mQ0y3H5Q8bqO7iM......",
  "started_at": 1784885653.0,
  "finished_at": 1784885665.4,
  "elapsed": 12.4
}
```

Vraćeni rezultat ima više polja, koja su opisana kao:

- `token`, rezultat verifikacije nakon obrade Cloudflare Turnstile CAPTCHA zadatka.
- `started_at`, `finished_at`: vreme kada je ovaj zahtev počeo da se obrađuje i kada je rezultat proizveden, Unix vremenski pečat (sekunde, decimalni).
- `elapsed`: ukupno vreme obrade (sekunde).

Možemo videti da smo dobili rezultat verifikacije za obradu Turnstile CAPTCHA, a zatim ga možemo koristiti za POST ili simulirano slanje ciljanom sajtu, jednokratno korišćenje, važenje 120s, preporučuje se korišćenje unutar 60s. Tokom slanja obično se taj token šalje kao `cf-turnstile-response` parametar zajedno sa zahtevom ka ciljanom sajtu, pozivajući odgovarajući Python kod za verifikaciju tokena:

```python
import requests

token = '{token}'

data = {
    'cf-turnstile-response': token
}

response = requests.post('https://react-turnstile.vercel.app', data=data)

if response.status_code == 200:
    print(response.text)
```

Takođe, ako želite da generišete odgovarajući kod za integraciju, možete direktno kopirati generisani kod, na primer CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/token/turnstile' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "website_key": "0x4AAAAAAADnPIDROrmt1Wwj",
  "website_url": "https://react-turnstile.vercel.app"
}'
```

Python kod za integraciju je sledeći:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/turnstile"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "website_key": "0x4AAAAAAADnPIDROrmt1Wwj",
    "website_url": "https://react-turnstile.vercel.app"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asinhroni Mod (async)

Podrazumevano, API je sinhrono blokirajući: jedan zahtev će čekati dok se token ne obradi pre nego što vrati rezultat. Ako radite sa više rešenja (multi-solver rotation) i želite da „odmah dobijete task_id nakon slanja zadatka, a zatim idete da rasporedite druge reševe, a kasnije se vratite da pročitate rezultat“, možete proslediti `async: true` u telu zahteva.

Kada prosledite `async: true`, interfejs će odmah vratiti `task_id`, a neće blokirati čekajući:

```json
{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

Ako želite da aktivno pratite napredak, možete koristiti taj `task_id` da upitite `POST /captcha/tasks` (preporučuje se svake 3~5 sekundi). Ovaj interfejs neće pokrenuti ili unaprediti obradu zadatka; čak i ako ne proveravate, prekinete vezu ili napustite klijenta, server će nastaviti sa obradom:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002"
}'
```

Tokom obrade biće vraćeno `status: processing`; kada se obrada završi, biće vraćeno `status: ready` i token:

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "ready",
  "token": "0.mNQ2f9uP6mQ0y3H5Q8bqO7iM......"
}
```

Objašnjenje naplate: u asinhronom režimu, kreiranje zadatka i čitanje statusa „u obradi“ se ne naplaćuje; **klijent se naplaćuje samo kada prvi put pročita uspešan rezultat** (što je u skladu sa postojećim ponašanjem i cenama u sinhronom režimu). Server će samostalno napredovati zadatak, ali neće naplatiti unapred samo zato što je pozadinski zadatak završen. Ako zadatak ne uspe u roku od 120 sekundi, biće prekinut sa HTTP 504 `timeout`, bez naplate. `/captcha/tasks` nije odgovoran za napredovanje zadatka.

> Napomena: Cloudflare Turnstile trenutno ne podržava dovođenje vlastitih proxy (Bring Your Own Proxy), stoga ovaj interfejs ne prihvata `proxy` parametar; ako se prosledi, biće vraćen `400 invalid_proxy`.

## Obrada Grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:
- `400 token_mismatched`：Loša zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 invalid_proxy`：Loša zahtev, proxy nije podržan za ovu vrstu captcha.
- `401 invalid_token`：Neovlašćen, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste ograničenje brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.

### Primer greške u odgovoru

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
