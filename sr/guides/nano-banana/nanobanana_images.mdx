Овај документ описује интеграцију и коришћење Nano Banana Images API. Овај интерфејс подржава две функције: **генерација слика (generate)** и **уређивање слика (edit)**.

## Процес пријаве

Пре коришћења, молимо вас да уђете на [Nano Banana Images API](https://platform.acedata.cloud/documents/23985a11-d713-41d1-ad84-24b021805b3d) на Ace Data Cloud платформи и кликнете на Acquire да бисте затражили активацију. При првом захтеву обично ће бити доступан бесплатан кредит. Након активације, можете добити Bearer Token за позивање API-а.

## Преглед интерфејса

- **Base URL**: `https://api.acedata.cloud`
- **Endpoint**: `POST /nano-banana/images`
- **Метод аутентификације**: HTTP Header садржи `authorization: Bearer {token}`
- **Захтевни хедери**:
  - `accept: application/json`
  - `content-type: application/json`
- **Акција (action)**:
  - `generate`: генерише слику на основу текстуалне поруке
  - `edit`: уређује на основу задате слике
- **Модел (model)** (опционо):
  - `nano-banana` (подразумевано): заснован на Gemini 2.5 Flash Image, брз, низак трошак
  - `nano-banana-2`: заснован на Gemini 3.1 Flash Image Preview, Pro квалитет + Flash брзина
  - `nano-banana-pro`: заснован на Gemini 3 Pro Image Preview, највиши квалитет
- **Асинхрони повратни позив**: опционално, прима обавештења о завршетку задатка и резултате преко `callback_url`

## Брзи почетак: генерисање слике (`action=generate`)

**Минимум потребни параметри**: `action`, `prompt`
Када желите да генеришете слику директно на основу поруке, поставите `action` на `generate` и пружите јасну `prompt`.

### Пример захтева (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "prompt": "Фотореалистичан крупан портрет старијег јапанског керамичара са дубоким, сунчевим борењем и топлим, знајућим осмехом. Пажљиво прегледа свеже глазирани чајник. Постављен је у његов рустични, сунцем осветљени радионици. Сцена је осветљена меком, златном светлошћу која пролази кроз прозор, истичући фину текстуру глине. Снимљено са 85mm портретним објективом, што резултира меком, замућеном позадином (боке). Укупно расположење је мирно и мајсторско. Вертикална портретна оријентација.",
    "count": 1
  }'
```

### Пример захтева (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "prompt": (
        "Фотореалистичан крупан портрет старијег јапанског керамичара "
        "са дубоким, сунчевим борењем и топлим, знајућим осмехом. Пажљиво "
        "прегледа свеже глазирани чајник. Постављен је у његов рустични, сунцем осветљени "
        "радионици. Сцена је осветљена меком, златном светлошћу која пролази кроз "
        "прозор, истичући фину текстуру глине. Снимљено са 85mm "
        "портретним објективом, што резултира меком, замућеном позадином (боке). Укупно расположење "
        "је мирно и мајсторско. Вертикална портретна оријентација."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Објашњење поља

- `success`: Да ли је овај захтев био успешан.
- `task_id`: ID задатка.
- `trace_id`: ID за праћење, ради лакшег решавања проблема.
- `data[]`: Листа резултата.
  - `prompt`: Порука коришћена за генерисање (повратна информација).
  - `image_url`: Директна URL адреса генерисане слике.

> Напомена: `/nano-banana/images` захтева само `action` и `prompt` за генерисање слике

## Уређивање слике (`action=edit`)

Када желите да уредите постојећу слику, поставите `action` на `edit` и пружите листу URL адреса слика које желите да уредите (1 или више), као и `prompt` који описује циљ уређивања.

На пример, ако имамо слику особе и слику одеће, можемо да пружимо URL адресе обе слике и да одредимо акцију као `edit`, URL може бити HTTP URL, доступан преко `https` или `http` протокола, или може бити Base64 кодирана слика, као `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Пример захтева (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "нека овај човек носи ову мајицу",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Пример захтева (Python)

```python

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
```

- Остала поља су иста као у повратку „генерисање слике“.

## Asinhroni povratni poziv (opciono, preporučeno)

Generisanje ili uređivanje može potrajati određeno vreme. Da biste izbegli dugotrajne veze koje zauzimaju resurse, preporučuje se korišćenje **Webhook povratnog poziva** putem `callback_url`:

1. U telu zahteva dodajte `callback_url`, na primer, adresu vašeg servera Webhook (mora biti javno dostupna, podržava POST JSON).
2. API će **odmah vratiti** odgovor koji sadrži `task_id` (ili osnovne rezultate).
3. Kada zadatak bude završen, platforma će putem `POST` metode poslati kompletan JSON na `callback_url`. Možete povezati zahtev sa rezultatom putem `task_id`.

**Primer povratnog tereta** (struktura polja je ista kao kod uspešnog sinhronog vraćanja):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "bela sijamska mačka",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Obrada grešaka

Kada poziv ne uspe, biće vraćen standardni format greške i ID praćenja. Uobičajene greške su:

- **400 `token_mismatched`**: Zahtev nije validan ili su parametri pogrešni.
- **400 `api_not_implemented`**: Interfejs nije implementiran (molimo kontaktirajte podršku).
- **401 `invalid_token`**: Neuspešna autentifikacija ili nedostaje Token.
- **429 `too_many_requests`**: Prekoračena frekvencija zahteva.
- **500 `api_error`**: Izuzetak na serveru.

### Primer odgovora na grešku

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Interna greška servera."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Parametri i napomene

- **Obavezno**: `action`, `prompt`
- **Samo za uređivanje**: `image_urls` (niz, najmanje 1 stavka)
- **Opcionalno**: `model` (podrazumevano `nano-banana`, opcionalno `nano-banana-2` ili `nano-banana-pro`), `aspect_ratio` (odnos širine i visine, kao `1:1`, `16:9`), `resolution` (rezolucija, kao `1K`, `2K`, `4K`), `callback_url` (za asinhroni povratni poziv)
- **Headers**: Mora se obezbediti `authorization: Bearer {token}`; `accept` se preporučuje postaviti na `application/json`
- **Pristupačnost slika**: `image_urls` mora biti direktna veza koja je javno dostupna (HTTP/HTTPS), preporučuje se korišćenje HTTPS
- **Idempotentnost i praćenje**: Čuvajte `task_id` i `trace_id` za lakše rešavanje problema i povezivanje rezultata
