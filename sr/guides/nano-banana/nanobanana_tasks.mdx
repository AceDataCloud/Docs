Glavna funkcija Nano Banana Tasks API je da omogućava upit o statusu izvršenja zadatka putem ID-a zadatka generisanog od strane Nano Banana Images API.

Ovaj dokument će detaljno opisati uputstva za integraciju Nano Banana Tasks API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Nano Banana Tasks API, možete lako ostvariti upit o statusu izvršenja zadatka iz Nano Banana Images API.

## Primer zahteva

Nano Banana Tasks API može se koristiti za upit o rezultatima Nano Banana Images API. O tome kako koristiti Nano Banana Images API, molimo vas da se obratite dokumentaciji [Nano Banana Images API](https://platform.acedata.cloud/documents/63e01dc3-eb21-499e-8049-3025c460058f).

Uzmimo za primer jedan ID zadatka koji je vratio Nano Banana Images API, i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: 4d320ead-4af4-4a55-8f3e-f2afebdf4fd0, a zatim ćemo prikazati kako da ga prosledimo.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, koji možete direktno odabrati nakon što ga zatražite.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se šalje.
- `action`: način operacije na zadatku.

Postavite kao što je prikazano na sledećoj slici:

<p><img src="https://cdn.acedata.cloud/nuiuth.png" width="500" class="m-auto"></p>

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na različitim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/r1u4vl.png" width="500" class="m-auto"></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "4d320ead-4af4-4a55-8f3e-f2afebdf4fd0",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/nano-banana/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "4d320ead-4af4-4a55-8f3e-f2afebdf4fd0",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Operacija masovnog upita

Ovo se odnosi na upit o detaljima više ID-a zadataka, a u odnosu na prethodno, potrebno je odabrati akciju `retrieve_batch`.

**Telo zahteva** uključuje:

- `ids`: niz ID-a zadataka koji se šalju.
- `action`: način operacije na zadatku.

Primer je sledeći:

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed","1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed"],
  "action": "retrieve_batch"
}'
```

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Neispravan zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`：Neispravan zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`：Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste ograničenje brzine.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.

### Primer odgovora na grešku
