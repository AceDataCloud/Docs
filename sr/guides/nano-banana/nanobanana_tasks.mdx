Главна функција Nano Banana Tasks API је да омогући проверу статуса извршења задатка путем ID-а задатка генерисаног од Nano Banana Images API.

Овај документ ће детаљно описати упутство за интеграцију Nano Banana Tasks API, помажући вам да лако интегришете и у потпуности искористите моћ овог API. Кроз Nano Banana Tasks API, можете лако реализовати проверу статуса извршења задатка Nano Banana Images API.

## Пример захтева

Nano Banana Tasks API може се користити за проверу резултата Nano Banana Images API. За информације о томе како користити Nano Banana Images API, молимо вас да се упутите на документ [Nano Banana Images API](https://platform.acedata.cloud/documents/veo-videos).

Узимамо за пример ID задатка који је вратио Nano Banana Images API, да демонстрирамо како користити овај API. Хајде да претпоставимо да имамо ID задатка: 4d320ead-4af4-4a55-8f3e-f2afebdf4fd0, а затим ћемо демонстрирати како да пренесемо ID задатка.

### Подешавање заглавља захтева и тела захтева

**Request Headers** укључује:

- `accept`: одређује да се примају одговори у JSON формату, овде се попуњава као `application/json`.
- `authorization`: кључ за позивање API, који можете директно изабрати након што га затражите.

**Request Body** укључује:

- `id`: ID задатка који се преноси.
- `action`: начин операције над задатком.

Подешавање је као на слици испод:

### Пример кода

Можете приметити да су на десној страни странице аутоматски генерисани кодови на различитим језицима, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/r1u4vl.png" width="500" className="m-auto" /></p>

Делимични примери кода су следећи:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "4d320ead-4af4-4a55-8f3e-f2afebdf4fd0",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/nano-banana/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "4d320ead-4af4-4a55-8f3e-f2afebdf4fd0",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Пример одговора

Након успешног захтева, API ће вратити детаље о овом задатку. На пример:

```json
{
  "_id": "68bc7c3c550a4144a53d0e24",
  "id": "4d320ead-4af4-4a55-8f3e-f2afebdf4fd0",
  "api_id": "9d8a117e-31ca-4322-a0fd-1771296ec610",
  "application_id": "8afd681a-2a4e-4265-aecb-43970094c019",
  "created_at": 1757183036.787,
  "started_at": 1757183036.847,
  "finished_at": 1757183048.147,
  "elapsed": 11.3,
  "credential_id": "097b2987-62f4-4ac0-b0cc-aed41e372a07",
  "request": {
    "action": "generate",
    "prompt": "a white siamese cat"
  },
  "trace_id": "7ba1f1e8-0ef8-450d-8bb2-b5c3bf1ea319",
  "type": "images",
  "user_id": "b87f67c1-b04f-4332-99a1-7a5e651331c6",
  "response": {
    "success": true,
    "task_id": "4d320ead-4af4-4a55-8f3e-f2afebdf4fd0",
    "trace_id": "7ba1f1e8-0ef8-450d-8bb2-b5c3bf1ea319",
    "data": [
      {
        "prompt": "a white siamese cat",
        "image_url": "https://platform.cdn.acedata.cloud/nanobanana/7e7bd000-698a-4e14-bb2d-3db61237e4bb.png"
      }
    ]
  }
}
```

Враћени резултат има више поља, поље request представља тело захтева при покретању задатка, док поље response представља тело одговора након завршетка задатка. Опис поља је следећи.

- `id`, ID који идентификује овај задатак, користи се за јединствено обележавање овог генерисаног задатка.
- `request`, информације о захтеву у задатку.
- `response`, информације о одговору у задатку.
- `created_at`, време креирања задатка, Unix временски жиг (секунде, флотант).
- `started_at`, време почетка извршења задатка, Unix временски жиг (секунде, флотант).
- `finished_at`, време завршетка задатка, Unix временски жиг (секунде, флотант). Ово поље се не враћа ако задатак није завршен.
- `elapsed`, време извршења задатка, у секундама (флотант, задржава 3 децималне цифре). Ово поље се не враћа ако задатак није завршен.

## Операција масовне провере

Ово је за проверу детаља више ID-ова задатака, а за разлику од горе наведеног, потребно је да се акција подеси на `retrieve_batch`.

**Request Body** укључује:

- `ids`: низ ID-ова задатака који се преносе.
- `action`: начин операције над задатком.

Пример је следећи:

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed","1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed"],
  "action": "retrieve_batch"
}'
```

返回结果一共有多个字段，其中 items 是包含了批量任务的具体详情信息，每个任务的具体信息与上文的字段一样，字段信息如下。

- `items`，批量任务的所有具体详情信息。它 je jedan niz, svaki element niza ima istu strukturu kao rezultat upita za pojedinačni zadatak.
- `count`，ovde je broj zadataka u batch upitu.

## Obrada grešaka

U slučaju greške prilikom pozivanja API-ja, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`：Loš zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`：Loš zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`：Neautorizovano, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`：Previše zahteva, premašili ste limit brzine.
- `403 forbidden`：Nativna sigurnosna politika pružaoca je odbila zahtev ili generisanje rezultata; ako su svi pozivi za generisanje odbijeni, zadatak se čuva u stanju neuspeha, ne sadrži slike i ne naplaćuje se. U višeslojnim zahtevima ostali uspešni pozivi se i dalje mogu vratiti i naplatiti prema stvarnom broju.
- `500 api_error`：Interna greška servera, nešto nije u redu sa serverom.
