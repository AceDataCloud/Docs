Ovaj dokument će predstaviti način integracije hCaptcha API za prepoznavanje slika, koji može da vrati koordinate malih slika koje treba kliknuti na osnovu sadržaja koji korisnik unese i hCaptcha verifikacione slike, čime se završava verifikacija.

## Proces prijave

Da biste koristili hCaptcha API za prepoznavanje slika, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, koji čuvate za kasnije.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može da pozove sve usluge platforme, bez potrebe da se za svaku uslugu posebno prijavljujete.** Prilikom prve prijave dobijate besplatnu kvotu, koju možete besplatno isprobati; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Puna dokumentacija: [hCaptcha API za prepoznavanje slika →](https://platform.acedata.cloud/documents/recognition-hcaptcha-integration)

## Osnovna upotreba

Prvo se upoznajte sa osnovnim načinom korišćenja, što podrazumeva unos hCaptcha verifikacione slike koja treba da se obradi, kako biste dobili obrađeni rezultat. Prvo je potrebno jednostavno proslediti polje `queries`, koje predstavlja konkretnu hCaptcha verifikacionu sliku. Moramo da snimimo ovu sliku sa sajta koji koristi hCaptcha verifikaciju, primer sajta je: `https://democaptcha.com/demo-form-eng/hcaptcha.html`, klikom na okvir za potvrdu prikazaće se konkretna puna verifikaciona slika, kao što je prikazano na slici ispod:

<p><img src="https://cdn.acedata.cloud/xryo59.png" width="500" className="m-auto" /></p>

Polje `queries` je snimak verifikacione slike iz gornjeg teksta, preporučuje se da veličina slike ne prelazi 100kb, takođe je potrebno snimiti deo slike koji je označen crvenom strelicom iznad, a takođe je potrebno da sami kompresujete veličinu slike i konvertujete je u Base64 kodiranje, kao što je prikazano na slici ispod:

<p><img src="https://cdn.acedata.cloud/g8ikkb.png" width="500" className="m-auto" /></p>

Takođe je potrebno uneti parametar prepoznavanja vezan za verifikacionu sliku `question`, koji podržava prevođenje na kineski i engleski, možete direktno uneti relevantan sadržaj prepoznavanja. Iz sadržaja slike sa prethodne stranice može se videti da bi `question` trebalo da bude `Please click on the UNIQUE object among the others.`. Konkretni sadržaj je prikazan ispod:

<p><img src="https://cdn.acedata.cloud/empncr.png" width="500" className="m-auto" /></p>

Možemo videti da smo postavili Request Headers, uključujući:

- `accept`: format odgovora koji želite da primite, ovde je uneto `application/json`, što znači JSON format.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete direktno izabrati.

Takođe je postavljen Request Body, uključujući:

- `queries`: lista verifikacionih slika u Base64 kodiranju.
- `question`: parametar prepoznavanja vezan za verifikacionu sliku, podržava direktan unos na kineskom i engleskom.

Nakon izbora, možete primetiti da je sa desne strane generisan odgovarajući kod, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/bww9b0.png" width="500" className="m-auto" /></p>

Klikom na dugme „Try“ možete izvršiti testiranje, kao što je prikazano na slici, ovde smo dobili sledeći rezultat:

```json
{
  "solution": {
    "label": "Please click on the UNIQUE object among the others",
    "box": [
      "360",
      "276"
    ],
    "confidences": 0.6354503631591797
  }
}
```

Vraćeni rezultat ima više polja, koja su opisana kao:

- `solution`, rezultat verifikacije nakon obrade hCaptcha verifikacione slike.
    - `label`, sadržaj prepoznat na hCaptcha verifikacionoj slici.
    - `box`, informacija o lokaciji rezultata prepoznavanja hCaptcha verifikacione slike, koja se sastoji od koordinatnih informacija slike.
    - `confidences`, stepen poverenja u prepoznati sadržaj nakon prepoznavanja hCaptcha verifikacione slike.
- `started_at`, `finished_at`: vreme kada je ova zahtev počela da se obrađuje i kada je rezultat proizveden, Unix vremenski pečat (sekunde, decimalni).
- `elapsed`: ukupno vreme obrade (sekunde).

Možemo videti da smo dobili rezultat verifikacije hCaptcha verifikacione slike, a sve što treba da uradimo je da simuliramo klik na područje prema informacijama o lokaciji `box` u rezultatu kako bismo prošli verifikaciju.

U nastavku će biti objašnjeno kako da kliknete na osnovu informacija o lokaciji `box`, prvo je potrebno uspostaviti pravougaoni koordinatni sistem za učitanu verifikacionu sliku, gde je centar u donjem levom uglu slike, 360 je odgovarajuća horizontalna koordinata, a 276 je odgovarajuća vertikalna koordinata. Sve što treba da uradimo je da simuliramo klik na odgovarajuće koordinate verifikacione slike, konkretne informacije o slici su prikazane ispod:

<p><img src="https://cdn.acedata.cloud/4ykvbl.png" width="500" className="m-auto" /></p>

Takođe, ako želite da generišete odgovarajući kod za integraciju, možete ga direktno kopirati, na primer, CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/hcaptcha' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "question": "Please click on the UNIQUE object among the others.",
  "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"]
}'
```

Python kod za integraciju je sledeći:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/hcaptcha"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "question": "Please click on the UNIQUE object among the others.",
    "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asinhroni režim (async)

Podrazumevano, API je sinhrono blokirajući: jedan zahtev će čekati dok se rezultat prepoznavanja ne obradi pre nego što se vrati. Ako radite sa više rotacija rešenja (multi-solver rotation) i želite da „odmah dobijete task_id nakon slanja zadatka, a zatim da rasporedite druge reševe, a kasnije se vratite da pročitate rezultate“, možete u telu zahteva proslediti `async: true`.

Kada prosledite `async: true`, interfejs će odmah vratiti `task_id`, a neće blokirati čekajući:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/hcaptcha' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "question": "Please click on the UNIQUE object among the others.",
  "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"],
  "async": true
}'
```
```json
{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

Ako želite aktivno da proverite napredak, možete koristiti `task_id` za upit `POST /captcha/tasks` (preporučuje se svake 3~5 sekundi). Ovaj interfejs neće pokrenuti ili unaprediti obradu zadatka; čak i ako ne proveravate, prekinete internet ili izađete iz klijenta, server će i dalje nastaviti sa obradom:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002"
}'
```

Tokom obrade biće vraćeno `status: processing`:

```json
{ "success": true, "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002", "status": "processing" }
```

Kada se obrada završi, biće vraćeno `status: ready` i rezultat prepoznavanja `solution` (struktura polja je potpuno identična onoj u sinhronom režimu):

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "ready",
  "solution": {
    "label": "Molimo vas da kliknete na jedinstveni objekat među ostalima",
    "box": ["360", "276"],
    "confidences": 0.6354503631591797
  }
}
```

Objašnjenje naplate: u asinhronom režimu, kreiranje zadatka i čitanje statusa "u obradi" se ne naplaćuje; **klijent se naplaćuje prvi put kada pročita uspešan rezultat** (u skladu sa postojećim ponašanjem i cenama sinhronog režima). Server će samostalno napredovati zadatak, ali neće naplatiti unapred samo zato što je pozadinski zadatak završen. Ako zadatak ne bude uspešan u roku od 120 sekundi, biće prekinut sa HTTP 504 `timeout`, bez naplate. `/captcha/tasks` nije odgovoran za napredovanje zadatka.

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevalidnih parametara.
- `401 invalid_token`: Neautorizovano, nevalidan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.

### Primer odgovora greške

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
