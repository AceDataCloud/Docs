Vraća Proxy krajnje tačke montirane na uslugu kroz paginaciju prema Service UUID-u. Kada postoji samo alias, prvo pozovite [detalje usluge](https://platform.acedata.cloud/documents/platform-service-detail) da biste dobili `id`.

## Pregled interfejsa

| Stavka   | Sadržaj                                                                |
| --- | ---------------------------------------------------------------------- |
| Metod  | `GET`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| Autentifikacija  | Javno, nije potreban token naloga                                                              |
| Paginacija  | `count` + `items`                                                      |

## Parametri

| Parametar                 | Lokacija    | Obavezno  | Opis                               |
| ------------------ | ----- | --- | -------------------------------- |
| `service_id`       | path  | Da   | Service UUID, alias nije podržan           |
| `limit` / `offset` | query | Ne   | Paginacija                               |
| `ordering`         | query | Ne   | Django izraz za sortiranje; preporučuje se `rank` ili `-rank` |

```shell
export SERVICE_ID='vaš Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## Objašnjenje odgovora

Stavke liste su serijalizovane pomoću Proxy modela, a polja potvrđena u produkciji uključuju `id`, `service_id`, `title`, `endpoint`, `price`, `stage`, `rank`, `tags`, `metadata`, `document_id`, `service` i vremenska polja.

- Polje poslovnog ulaza je `endpoint`, a ne `path`.
- Polje za cenu je `price`, a ne `cost`.
- Kada Service tip nije Proxy ili Proxy nije montiran, vraća se prazan `items`.

Javne integracije se oslanjaju samo na `endpoint` i objavljene mogućnosti i ne bi trebalo da zavise od neobjavljenih detalja implementacije.
