## 1. Preuzmite API Key

Otvorite [listu aplikacija Ace Data Cloud](https://platform.acedata.cloud/console/applications), uđite u dostupnu aplikaciju i kopirajte API Key.

![Preuzimanje Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Dodajte Provider

Otvorite Cherry Studio, idite na **Podešavanja → Model servisi → Dodaj dobavljača** i popunite:

| Polje      | Vrednost                           |
| ------- | --------------------------- |
| Naziv dobavljača   | `Ace Data Cloud`            |
| Tip dobavljača   | `OpenAI`                    |
| API Key | Upravo kopirani API Key               |
| API adresa  | `https://api.acedata.cloud` |

![Ekran konfiguracije za dodavanje Ace Data Cloud Provider-a u Cherry Studio](https://cdn.acedata.cloud/b67a927eae62.png)

Cherry Studio će automatski dopuniti `/v1/chat/completions` za OpenAI tip. Kada koristite univerzalni ulaz, nemojte dodavati `#` na kraj adrese i nema potrebe da kreirate više Provider-a prema porodici modela.

## 3. Dodajte i omogućite model

1. Kliknite **Preuzmi listu modela**; ako trenutna verzija ne podržava automatsko preuzimanje, idite u [katalog modela](https://platform.acedata.cloud/models) da pogledate, a zatim ručno dodajte naziv ciljanog modela, na primer `claude-opus-5`, `gpt-6-sol`.
2. Kliknite dugme za proveru pored API Key-a da biste potvrdili vezu.
3. Uključite prekidač **Omogući** za Provider.
4. U biraču modela za razgovor izaberite upravo dodati model.

![Cherry Studio Provider i lista modela](https://cdn.acedata.cloud/149de1d088bf.png)

> Nakon preuzimanja ili ručnog dodavanja modela, uključite prekidač Provider-a u gornjem desnom uglu.

Pošaljite `Odgovorite samo OK` i proverite poziv u [istoriji korišćenja](https://platform.acedata.cloud/console/usages). Za 401 proverite Key; kada se model ne prikazuje, proverite da li je Provider omogućen; za 404 proverite da li se ručno uneti naziv modela potpuno podudara sa `id` iz kataloga.

## O GPT Image 2

Obični prilagođeni Provider za razgovor u Cherry Studio ne može direktno da poziva Images API. Generisanje i uređivanje za `gpt-image-2` treba da koriste namenski interfejs Ace Data Cloud:

- [Generisanje slika GPT Image 2](https://platform.acedata.cloud/documents/openai-images-generations)
- [Uređivanje slika GPT Image 2](https://platform.acedata.cloud/documents/openai-images-edits)

Nemojte unositi `/openai/images/generations` u Provider za razgovor.
