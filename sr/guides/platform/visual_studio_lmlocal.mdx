LMLocal je ekstenzija za Visual Studio 2022/2026, koja zvanično podržava OpenAI-kompatibilni API i prilagođeni Base URL. Ulaz za konfiguraciju može se promeniti sa verzijom ekstenzije; prilikom prvog pristupa, molimo vas da fiksirate verziju i proverite stvarno uređivanje, pozive alata i evidenciju korišćenja.

## Konfiguracija

1. Instalirajte LMLocal iz Visual Studio Marketplace-a ili zvaničnog repozitorijuma.
2. U Providers dodajte Custom/OpenAI-kompatibilni Provider.
3. U Base URL unesite `https://api.acedata.cloud/v1`.
4. U Auth Key unesite vaš Ace Data Cloud API Token.
5. U Model unesite tačan ID modela koji podržava Chat Completions u direktorijumu modela.
6. Nakon čuvanja pošaljite `Reply only OK`, a zatim ponovo testirajte proces uređivanja projekta.

## Trenutne granice

- Ovaj vodič pokriva samo LMLocal i ne predstavlja deljenje konfiguracije sa drugim Visual Studio ekstenzijama.
- Različite verzije mogu odvojeno obraditi zahteve za chat, uređivanje, izgradnju i testiranje; svaki režim treba nezavisno verifikovati.
- Ako klijent automatski dodaje `/v1` ili endpoint putanju, izbegavajte duple putanje.
