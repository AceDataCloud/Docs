Direktno preuzmite detalje API poziva trenutnog naloga kao CSV, pogodno za finansijsko usaglašavanje, vanmrežnu analizu ili čuvanje velikog broja zapisa. Ako je potrebno samo pregledati mali broj detalja na stranici, prvo koristite [listu zapisa poziva](https://platform.acedata.cloud/documents/platform-usage-list).

Opseg upita za zapise poziva i sažetke naplate je poslednjih 60 dana; tela zahteva i odgovora se zasebno čuvaju poslednjih 30 dana. Istek tela ne menja stvarnu naplatu, potrošnju ili zbirnu statistiku tog zapisa.

## Priprema

1. Prijavite se na [AceDataCloud platformu](https://platform.acedata.cloud).
2. Kreirajte token naloga u [Account Token konzoli](https://platform.acedata.cloud/console/platform-tokens) i odmah ga sačuvajte u menadžeru lozinki ili Secret Manager-u.
3. Po potrebi preuzmite ID za filtriranje sa [liste zahteva za uslugu](https://platform.acedata.cloud/documents/platform-application-list), [liste API akreditiva](https://platform.acedata.cloud/documents/platform-credential-list) ili [liste API-ja](https://platform.acedata.cloud/documents/platform-api-list).

Za potpuno objašnjenje tokena pogledajte [upravljanje tokenima naloga](https://platform.acedata.cloud/documents/platform-token). Tokeni naloga i Credential za pozivanje poslovnog API-ja ne mogu se mešati.

```shell
export PLATFORM_TOKEN='vaš token naloga'
```

## Pregled interfejsa

| Stavka      | Sadržaj                                                    |
| ----------- | ---------------------------------------------------------- |
| Metod       | `GET`                                                      |
| URL         | `https://platform.acedata.cloud/api/v1/usage/apis/export/` |
| Autentikacija | `Authorization: Bearer ${PLATFORM_TOKEN}`                |
| OAuth Scope | `usage:read` (`platform:read` / `platform` uključuju ga)  |
| Odgovor     | `200 text/csv; charset=utf-8`                              |
| Naziv datoteke | `usages.csv`                                            |

Ovaj interfejs sinhrono strimuje CSV odgovor, ne kreira zadatak za izvoz i ne vraća JSON niti vezu za preuzimanje. Samo kada oba vremena početka i završetka nisu navedena, podrazumevano se izvoze zapisi od početka trenutnog kalendarskog meseca do trenutnog vremena; kada je navedena samo jedna granica, druga se neće automatski dopuniti granicom trenutnog meseca.

## Parametri upita

| Parametar         | Tip      | Obavezno | Podrazumevano | Opis                                    |
| ----------------- | -------- | --- | ------ | ------------------------------------------ |
| `perspective`     | string   | ne   | `both` | `billing`, `actor` ili `both`              |
| `service_id`      | UUID     | ne   | —      | Filtriranje po usluzi; podržava ponovljene parametre |
| `application_id`  | UUID     | ne   | —      | Filtriranje po Application-u; podržava ponovljene parametre |
| `api_id`          | UUID     | ne   | —      | Filtriranje po API-ju; podržava ponovljene parametre |
| `credential_id`   | UUID     | ne   | —      | Filtriranje po API akreditivu; podržava ponovljene parametre |
| `status_code`     | integer  | ne   | —      | Podržava ponovljene vrednosti ili vrednosti razdvojene zarezom |
| `created_at_from` | datetime | ne   | —      | ISO 8601 vreme početka                    |
| `created_at_to`   | datetime | ne   | —      | ISO 8601 vreme završetka                  |

Opseg izvoza je uvek ograničen na zapise vidljive trenutnom nalogu kao platiocu i/ili stvarnom pozivaocu; izvoz između naloga nije podržan.

## Primeri zahteva

Direktno sačuvajte CSV za trenutni mesec:

```shell
curl --fail-with-body --location \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

Izvoz prema Application-u, vremenu i statusnom kodu:

```shell
export APPLICATION_ID='vaš Application ID'

curl --fail-with-body --get \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'status_code=200,500' \
  --data-urlencode 'created_at_from=2026-09-01T00:00:00Z' \
  --data-urlencode 'created_at_to=2026-09-08T00:00:00Z' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

Python strimuje čuvanje i proverava integritet:

```python
import os
from pathlib import Path

import requests

url = "https://platform.acedata.cloud/api/v1/usage/apis/export/"
headers = {"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"}
params = {
    "created_at_from": "2026-09-01T00:00:00Z",
    "created_at_to": "2026-09-08T00:00:00Z",
    "perspective": "both",
}
output = Path("usages.csv")

with requests.get(url, headers=headers, params=params, stream=True, timeout=120) as response:
    response.raise_for_status()
    if not response.headers.get("content-type", "").startswith("text/csv"):
        raise RuntimeError("服务器没有返回 CSV")
    with output.open("wb") as file:
        for chunk in response.iter_content(chunk_size=64 * 1024):
            file.write(chunk)

last_line = output.read_text(encoding="utf-8").splitlines()[-1]
if last_line.startswith("# truncated:") or last_line.startswith("# error:"):
    raise RuntimeError(f"导出不完整：{last_line}")
```

## CSV kolone

Redosled CSV zaglavlja je fiksan:

```text
Usage ID,API,Status Code,Deducted Amount,Original Amount,Trace ID,Created At
```

| Kolona             | Opis                                      |
| ----------------- | ----------------------------------------- |
| `Usage ID`        | ID zapisa poziva                          |
| `API`             | Naslov API-ja; kada nije moguće upariti, može biti API ID ili prazna vrednost |
| `Status Code`     | HTTP statusni kod                         |
| `Deducted Amount` | Konačni stvarno odbijeni iznos kvote      |
| `Original Amount` | Originalni iznos kvote pre popusta aplikacije |
| `Trace ID`        | Identifikator praćenja zahteva            |
| `Created At`      | Vreme kreiranja zapisa, ISO 8601          |

Jedinicu kvote određuje `service.unit` odgovarajućeg Application-a.

## Utvrđivanje da li je izvoz potpun

Jedan put može da ispiše najviše 1.000.000 stavki podataka. Nakon što server počne da vraća CSV, greška usred procesa više ne može biti promenjena u drugi HTTP status, zato klijent mora da proveri poslednji red:

- `# truncated:`: dostignuto je ograničenje broja redova; izvozite segmentirano u manjim vremenskim intervalima.
- `# error:`: strimovano čitanje je prekinuto; nakon sužavanja opsega ponovo izvezite.

Program za usaglašavanje, kada vidi bilo koji marker, mora datoteku tretirati kao nepotpunu i ne sme je tiho knjižiti.

## Greške i ponovni pokušaji

| Situacija                    | Način postupanja                                              |
| --------------------------- | ------------------------------------------------------------- |
| `400 usage_history_expired` | Prilagodite na opseg poslednjih 60 dana koristeći `available_from` iz odgovora |
| `401 not_authenticated`     | Proverite da Account Token postoji, da je ispravan i da nije obrisan |
| Odgovor koji nije CSV       | Nemojte ga sačuvati kao uspešnu datoteku; prvo pročitajte odgovor o grešci i ispravite zahtev |
| Prekid preuzimanja ili marker | Sužite vremenski interval i ponovo izvezite koristeći strategiju povlačenja |
