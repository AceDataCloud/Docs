Direktno preuzmite detalje API poziva trenutnog naloga kao CSV, pogodno za finansijsko usaglašavanje, vanmrežnu analizu ili čuvanje velike količine zapisa. Ako je potrebno samo pregledati mali broj detalja na stranici, prvo koristite [listu evidencije poziva](https://platform.acedata.cloud/documents/platform-usage-list)。

## Pripremni radovi

1. Prijavite se na [AceDataCloud platformu](https://platform.acedata.cloud)。
2. Kreirajte token naloga u [Account Token konzoli](https://platform.acedata.cloud/console/platform-tokens) i odmah ga sačuvajte u menadžeru lozinki ili Secret Manager-u。
3. Po potrebi preuzmite ID za filtriranje iz [liste zahteva za usluge](https://platform.acedata.cloud/documents/platform-application-list), [liste API akreditiva](https://platform.acedata.cloud/documents/platform-credential-list) ili [liste API-ja](https://platform.acedata.cloud/documents/platform-api-list)。

Za potpuno objašnjenje tokena pogledajte [upravljanje tokenima naloga](https://platform.acedata.cloud/documents/platform-token)。Tokeni naloga i Credential za pozivanje poslovnog API-ja ne mogu se mešati。

```shell
export PLATFORM_TOKEN='你的账户令牌'
```

## Pregled interfejsa

| Stavka       | Sadržaj                                                    |
| ----------- | ---------------------------------------------------------- |
| Metod          | `GET`                                                      |
| URL         | `https://platform.acedata.cloud/api/v1/usage/apis/export/` |
| Autentikacija          | `Authorization: Bearer ${PLATFORM_TOKEN}`                  |
| OAuth Scope | `usage:read`（`platform:read` / `platform` mogu prošireno sadržavati）           |
| Odgovor          | `200 text/csv; charset=utf-8`                              |
| Naziv datoteke         | `usages.csv`                                               |

Ovaj interfejs sinhrono strimuje CSV povratni odgovor, ne kreira zadatak izvoza niti vraća JSON ili link za preuzimanje. Samo kada ni početno ni krajnje vreme nisu navedeni, podrazumevano se izvoze zapisi od početka trenutnog kalendarskog meseca do trenutnog vremena; kada je navedena samo jedna granica, druga strana se neće automatski dopuniti granicom ovog meseca。

## Parametri upita

| Parametar                | Tip       | Obavezno  | Podrazumevano     | Opis                         |
| ----------------- | -------- | --- | ------ | -------------------------- |
| `perspective`     | string   | ne   | `both` | `billing`、`actor` ili `both` |
| `service_id`      | UUID     | ne   | —      | Filtriranje po usluzi; podržava ponovljene parametre               |
| `application_id`  | UUID     | ne   | —      | Filtriranje po Application-u; podržava ponovljene parametre    |
| `api_id`          | UUID     | ne   | —      | Filtriranje po API-ju; podržava ponovljene parametre            |
| `credential_id`   | UUID     | ne   | —      | Filtriranje po API akreditivu; podržava ponovljene parametre          |
| `status_code`     | integer  | ne   | —      | Podržava ponovljene vrednosti ili vrednosti odvojene zarezom                 |
| `created_at_from` | datetime | ne   | —      | ISO 8601 početno vreme              |
| `created_at_to`   | datetime | ne   | —      | ISO 8601 krajnje vreme              |

Opseg izvoza je uvek ograničen na zapise vidljive trenutnom nalogu kao platiocu i/ili stvarnom pozivaocu, izvoz između naloga nije podržan。

## Primeri zahteva

Direktno sačuvajte CSV za trenutni mesec:

```shell
curl --fail-with-body --location \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

Izvoz po Application-u, vremenu i statusnom kodu:

```shell
export APPLICATION_ID='你的 Application ID'

curl --fail-with-body --get \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'status_code=200,500' \
  --data-urlencode 'created_at_from=2026-09-01T00:00:00Z' \
  --data-urlencode 'created_at_to=2026-09-08T00:00:00Z' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

Python striming čuvanje i provera integriteta:

```python
import os
from pathlib import Path

import requests

url = "https://platform.acedata.cloud/api/v1/usage/apis/export/"
headers = {"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"}
params = {
    "created_at_from": "2026-09-01T00:00:00Z",
    "created_at_to": "2026-09-08T00:00:00Z",
    "perspective": "both",
}
output = Path("usages.csv")

with requests.get(url, headers=headers, params=params, stream=True, timeout=120) as response:
    response.raise_for_status()
    if not response.headers.get("content-type", "").startswith("text/csv"):
        raise RuntimeError("服务器没有返回 CSV")
    with output.open("wb") as file:
        for chunk in response.iter_content(chunk_size=64 * 1024):
            file.write(chunk)

last_line = output.read_text(encoding="utf-8").splitlines()[-1]
if last_line.startswith("# truncated:") or last_line.startswith("# error:"):
    raise RuntimeError(f"导出不完整：{last_line}")
```

## CSV kolone

Redosled CSV zaglavlja je fiksiran na:

```text
Usage ID,API,Status Code,Deducted Amount,Original Amount,Trace ID,Created At
```

| Kolona                 | Opis                         |
| ----------------- | -------------------------- |
| `Usage ID`        | ID evidencije poziva                    |
| `API`             | API naslov; kada nije moguće upariti, može biti API ID ili prazna vrednost |
| `Status Code`     | HTTP statusni kod                   |
| `Deducted Amount` | Konačni stvarno oduzeti iznos kvote                   |
| `Original Amount` | Originalni iznos kvote pre primene popusta                 |
| `Trace ID`        | Identifikator praćenja zahteva                     |
| `Created At`      | Vreme kreiranja zapisa, ISO 8601            |

Jedinica kvote određena je sa `service.unit` odgovarajućeg Application-a。

## Utvrđivanje da li je izvoz potpun

U jednom izvozu može se prikazati najviše 1.000.000 stavki podataka. Nakon što server počne da vraća CSV, više ne može da promeni grešku usred procesa u drugi HTTP status, stoga klijent mora da proveri poslednji red:

- `# truncated:`：dostignut je limit broja redova; izvozite segmentirano u manjim vremenskim prozorima。
- `# error:`：striming čitanje je prekinuto; ponovo izvezite nakon smanjenja opsega。

Kada program za usaglašavanje vidi bilo koji marker, mora datoteku smatrati nepotpunom i ne sme je tiho evidentirati。

## Greške i ponovni pokušaji

| Situacija                          | Način postupanja                                  |
| --------------------------- | ------------------------------------- |
| `400 usage_history_expired` | Prilagodite na opseg poslednjih 60 dana koristeći `available_from` iz odgovora |
| `401 not_authenticated`     | Proverite da li Account Token postoji, da li je ispravan i da li nije obrisan          |
| Odgovor koji nije CSV                    | Ne čuvajte kao uspešnu datoteku; prvo pročitajte odgovor greške i ispravite zahtev                |
| Prekid preuzimanja ili marker                | Smanjite vremenski prozor, koristite strategiju povratnog odlaganja za ponovni izvoz                     |
