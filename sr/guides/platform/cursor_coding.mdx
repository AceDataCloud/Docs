Cursor тренутно пружа OpenAI API кључ и **Override OpenAI Base URL** подешавање, што омогућава повезивање са OpenAI-компатибилним услугама. Ова способност постоји, али различите верзије не обрађују `/chat/completions`, `/responses`, списак модела и Agent/Composer итд. на потпуно исти начин.

Опсег компатибилности различитих верзија Cursor-а, оперативних система и режима захтева може се разликовати. Молимо вас да завршите стварну проверу режима према конфигурацији на овој страници, не ослањајте се на један успешан разговор да бисте закључили да су све функције доступне.

## Шта тренутно гарантује Cursor званично BYOK

Према [Cursor званичној документацији о Bring your own API key](https://cursor.com/help/models-and-usage/api-keys):

- Подржава OpenAI, Anthropic, Google, Azure OpenAI и AWS Bedrock креденцијале;
- Прилагођени API кључ се користи само за моделе за ћаскање, Tab completion наставља да користи Cursor уграђене моделе;
- API кључ се не чува на Cursor серверу, али се при сваком захтеву кључ шаље Cursor беку, за коначну изградњу prompt-а;
- Када се користи сопствени кључ, Cursor-ова политика нулте задржавања података не важи, обрада података се придржава политике изабраног провајдера.

## Конфигурација

1. Отворите Cursor Settings → Models.
2. У OpenAI API Key унесите ваш Ace Data Cloud API Token.
3. Омогућите **Override OpenAI Base URL**, унесите `https://api.acedata.cloud/v1`.
4. Изаберите или додајте прецизан ID модела компатибилан са тренутним Cursor протоколом.
5. Прво пошаљите `Reply only OK`, а затим тестирајте Ask/Edit/Agent итд. у режимима које заиста користите.

## Тренутне границе

- Прилагођени API кључ се користи само за моделе за ћаскање, Tab completion наставља да користи Cursor уграђене моделе.
- Cursor и даље може завршити коначну изградњу prompt-а на серверу; молимо вас да комбинујете званична објашњења о приватности да бисте оценили пут података.
- Base URL Override можда покрива само делимичне захтеве, или се због промене верзије прелази између Chat Completions/Responses.
- Не би требало само на основу једног успешног захтева за ћаскање да се тврди да су Agent, Auto, Composer или позадински задаци сви повезани.

## Потпуна провера компатибилности

Ако желите да дугорочно користите у производном радном току, молимо вас да завршите следеће провере:

1. Фиксна верзија Cursor-а и оперативни систем;
2. Завршите прави smoke тест клијента за ту верзију и забележите коначни протокол и пут захтева;
3. Успешан захтев за Chat Completions за тачан модел;
4. Позиви алата и Agent захтеви заиста пролазе кроз циљни endpoint;
5. Употреба и наплата могу се проверити;
6. Јасно забележите да ли захтеви пролазе кроз Cursor сервер и одговарајућа ограничења приватности.

Након надоградње клијента, ове провере треба поново извршити, како би се потврдило да протокол захтева, позиви алата и пут података нису променили.
