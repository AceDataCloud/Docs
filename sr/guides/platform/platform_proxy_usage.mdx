Upit evidencije korišćenja trenutnog naloga za usluge tipa Proxy. Za obične API pozive koristite [Evidenciju API poziva](https://platform.acedata.cloud/documents/platform-usage-list). Ako niste sigurni u tip usluge, prvo možete pogledati `type` u [detaljima usluge](https://platform.acedata.cloud/documents/platform-service-detail).

## Priprema

1. Prijavite se na [AceDataCloud platformu](https://platform.acedata.cloud).
2. Kreirajte token naloga u [Account Token konzoli](https://platform.acedata.cloud/console/platform-tokens) i odmah ga sačuvajte u menadžeru lozinki ili Secret Manager-u.
3. Otvorite [stranicu profila](https://auth.acedata.cloud/user/profile), kopirajte UUID trenutnog naloga i sačuvajte ga kao `USER_ID`. Može se koristiti i `user_id` iz odgovora prilikom kreiranja tokena naloga.
4. Preuzmite `application_id` usluge tipa Proxy iz [liste prijava usluga](https://platform.acedata.cloud/documents/platform-application-list). Kada je potrebno filtrirati po Proxy krajnjoj tački, preuzmite `proxy_id` iz [liste Proxy-ja pod uslugom](https://platform.acedata.cloud/documents/platform-service-proxies).

Za potpuno objašnjenje tokena pogledajte [upravljanje tokenima naloga](https://platform.acedata.cloud/documents/platform-token). Ovaj interfejs koristi Account Token, a ne Credential koji se koristi za pozivanje poslovnog API-ja.

```shell
export PLATFORM_TOKEN='vaš token naloga'
export USER_ID='UUID vašeg naloga'
export APPLICATION_ID='vaš Proxy Application ID'
```

## Pregled interfejsa

| Stavka     | Sadržaj                                                      |
| ---------- | ------------------------------------------------------------ |
| Metoda     | `GET`                                                        |
| URL        | `https://platform.acedata.cloud/api/v1/usage/proxies/`       |
| Autentikacija | `Authorization: Bearer ${PLATFORM_TOKEN}`                  |
| Scope      | `usage:read`                                                 |
| Paginacija | `count` + `items`, podrazumevano 10 stavki po stranici       |

Kada vlasnik Application-a vrši upit po `application_id`, server će prvo sinhronizovati dostupne evidencije tog Application-a, a zatim vratiti listu, stoga vreme odgovora može biti duže nego za običnu listu API usage-a. Ovlašćeni korisnici mogu čitati postojeće vidljive evidencije, ali neće pokrenuti sinhronizaciju na strani vlasnika.

## Parametri upita

| Parametar         | Tip     | Obavezno za obične korisnike | Podrazumevano | Opis                                              |
| ----------------- | ------- | ---------------------------- | ------------- | ------------------------------------------------- |
| `user_id`         | UUID    | da                           | —             | UUID trenutnog naloga; drugi nalog vraća `403`    |
| `application_id`  | UUID    | preporučeno                  | —             | Filtriranje po Proxy Application-u; podržava ponovljene parametre |
| `proxy_id`        | UUID    | ne                           | —             | Filtriranje po Proxy krajnjoj tački; podržava ponovljene parametre |
| `limit`           | integer | ne                           | 10            | Broj stavki po stranici, najviše 100              |
| `offset`          | integer | ne                           | 0             | Pomak paginacije                                   |
| `ordering`        | string  | ne                           | `-created_at` | Opadajući redosled po vremenu kreiranja           |

Trenutni interfejs ne podržava direktno filtriranje po modelu, HTTP statusnom kodu, Credential-u ili vremenskom opsegu, niti podržava parametar `perspective` iz API usage interfejsa. Ne dodajte ove nepodržane parametre u zahtev i ne pretpostavljajte da su stupili na snagu.

## Primer zahteva

```shell
curl --get 'https://platform.acedata.cloud/api/v1/usage/proxies/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=-created_at' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Python primer paginacije:

```python
import os
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/usage/proxies/",
    headers={"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"},
    params={
        "user_id": os.environ["USER_ID"],
        "application_id": os.environ["APPLICATION_ID"],
        "limit": 100,
    },
    timeout=60,
)
response.raise_for_status()
data = response.json()

for usage in data["items"]:
    print(usage["created_at"], usage["deducted_amount"], usage["remaining_amount"])
```

## Ključna polja

| Polje                    | Opis                                                      |
| ------------------------ | --------------------------------------------------------- |
| `user_id`                | Nalog koji snosi ovu naplatu                              |
| `actor_user_id`          | Stvarni pozivalac; starije evidencije mogu biti prazne    |
| `application_id`         | Proxy Application koji je generisao ovu evidenciju        |
| `proxy_id`               | Odgovarajuća Proxy krajnja tačka                          |
| `credential_id`          | ID povezanog kredencijala; starije evidencije mogu biti prazne |
| `used_amount`            | Korišćenje u originalnoj evidenciji; može biti prazno     |
| `deducted_amount`        | Stvarno konačno oduzet iznos kvote                        |
| `remaining_amount`       | Preostala kvota Application-a nakon naplate               |
| `metadata`               | Javni metapodaci; mogu biti prazni                        |
| `service` / `credential` | Sažetak povezanog objekta za lakši prikaz; može biti prazan kada povezani objekat ne postoji |

Jedinica kvote određena je putem `service.unit` odgovarajućeg Application-a.

## Obrada grešaka

| HTTP | Značenje                              | Način obrade                                                     |
| ---- | ------------------------------------- | ---------------------------------------------------------------- |
| 401  | Token naloga nedostaje ili je nevažeći | Proverite Account Token, ne koristite greškom poslovni Credential |
| 403  | Nemate ovlašćenje za pregled zatraženih evidencija | Koristite Application koji pripada trenutnom nalogu, uklonite neovlašćeni `user_id` |
| 5xx  | Sinhronizacija ili upit su privremeno neuspešni | Zadržite uslove filtriranja i ponovite pokušaj uz eksponencijalno čekanje; u slučaju trajnog neuspeha pružite podršci Application ID i vreme |
