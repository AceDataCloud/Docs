[Jan](https://jan.ai/) je open-source AI desktop klijent sa prioritetom rada van mreže, koji može pokretati modele lokalno, kao i povezivati se sa OpenAI kompatibilnim krajnjim tačkama putem **Remote Engine-a**. Ovaj tekst objašnjava kako povezati Ace Data Cloud.

## Proces prijave

Da biste povezali Ace Data Cloud u Jan-u, prvo idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications), preuzmite svoj API Token i sačuvajte ga za kasnije.

![Preuzimanje Ace Data Cloud API Key-a](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobijate besplatni kredit, tako da možete besplatno isprobati usluge modela Ace Data Cloud-a.

## Preuzimanje Jan-a

Idite na [zvanični Jan sajt](https://jan.ai/) i preuzmite verziju za svoju platformu (Windows, macOS, Linux). Za Apple Silicon uređaje preuzmite arm64 paket radi najboljih performansi.

## Konfigurisanje Ace Data Cloud-a

Jan deli modele na dve vrste: **Local Engine** (lokalno pokretanje) i **Remote Engine** (API treće strane). Ace Data Cloud koristi OpenAI kompatibilni protokol i povezuje se kao Remote Engine.

Otvorite Jan, idite na **Settings → Model Providers**, pronađite karticu **OpenAI** i uredite je:

| Polje       | Vrednost                              | Objašnjenje                       |
| -------- | ------------------------------ | ------------------------ |
| API Key  | Vaš Ace Data Cloud Token        | Token kopiran iz konzole             |
| Base URL | `https://api.acedata.cloud/v1` | **Mora se završavati sa `/v1`, bez kose crte na kraju** |

> To da se Base URL mora završavati sa `/v1` je jasno pravilo u zvaničnoj Jan dokumentaciji. Ako ne želite da prepišete originalnu OpenAI konfiguraciju, možete koristiti „+ Add Provider“ da kreirate novi Provider tipa `openai-compatible` i unesete isti sadržaj.

![Jan interfejs za dodavanje AceDataCloud Provider konfiguracije](https://cdn.acedata.cloud/26017d28afa1.png)

Nakon čuvanja prilagođenog Provider-a, Jan će prvo pokušati da pozove `{Base URL}/models` kako bi preuzeo listu modela. Ako trenutna verzija ili krajnja tačka ne vrati dostupnu listu, kliknite **+ Add Model** pri dnu iste stranice za uređivanje i ručno unesite ID modela. Nakon dodavanja, model će se pojaviti u padajućem meniju u gornjem levom uglu, sa ikonom „Cloud“ radi razlikovanja udaljenih / lokalnih modela.

![Jan interfejs za upravljanje Provider modelima](https://cdn.acedata.cloud/ae485550946c.png)

> `MODEL_ID` je čuvar mesta; idite u [katalog modela](https://platform.acedata.cloud/models) da biste pregledali i zamenili ga nazivom ciljanog modela; pri preciznoj proveri, merodavna je vrednost `id` iz odgovora `/v1/models`. Ta vrednost je naziv modela koji koristi API parametar `model`, a nije UUID usluge ili API-ja.

## Izbor modela

[Katalog modela](https://platform.acedata.cloud/models) se kontinuirano ažurira. Prednost dajte listi modela koju klijent automatski učitava; kada je potreban ručni unos, prvo pošaljite zahtev `GET https://api.acedata.cloud/v1/models`, kopirajte vrednost `id` ciljanog modela iz niza `data` u odgovoru, a zatim birajte prema mogućnostima konteksta, slika i pozivanja alata koje klijent podržava.

## Provera povezivanja

Ako niste sigurni da li je problem u Jan-u ili mreži, možete prvo direktno proveriti krajnju tačku pomoću curl-a (zamenite `{token}` svojim Token-om):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Povratak OpenAI kompatibilnog `chat.completion` objekta znači da su i Token i krajnja tačka spremni; ako se vrati `HTTP 403 used_up`, to znači da je Token važeći, ali da nema dovoljno sredstava, pa ga dopunite na [konzoli](https://platform.acedata.cloud/console/applications).

## Napredno: lokalna + cloud kombinacija

Jan ima ugrađeni lokalni OpenAI kompatibilni API Server koji se može uključiti (Settings → Local API Server). Nakon uključivanja, sluša na `http://localhost:1337/v1/chat/completions` i pokreće lokalne modele koje ste preuzeli. Na ovaj način možete u okvirima kao što su LangChain / LlamaIndex usmeriti Base URL na lokalni server radi besplatnog testiranja, a zatim za složene zadatke preći na udaljene modele Ace Data Cloud-a. Kontekst razgovora se neće izgubiti prilikom promene modela.

## Česta pitanja

### Prikazuje se Connection error ili 404

Obično Base URL nema `/v1`. Promenite ga u `https://api.acedata.cloud/v1` (mora se završavati sa `/v1` i ne treba ga pisati kao `.../openai/v1`).

### Prikazuje se 401 Unauthorized

Potvrdite da je u API Key nalepljen Ace Data Cloud Token (bez prefiksa `Bearer`, bez dodatnih razmaka) i da aplikacija kojoj pripada ima dovoljno sredstava.

### Udaljeni model se ne pojavljuje u padajućem meniju

Prvo kliknite dugme za osvežavanje modela da biste pokrenuli `/v1/models`; ako automatsko otkrivanje ne uspe, ručno koristite **+ Add Model** i bez izmena dodajte vrednost `id` modela iz kataloga.

### Da li je moguće otpremiti sliku kako bi je model analizirao

Moguće je, ali je potrebno iz trenutnog kataloga modela izabrati model koji eksplicitno podržava vizuelni unos.
