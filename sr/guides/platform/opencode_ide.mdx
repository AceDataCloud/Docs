OpenCode zvanična IDE ekstenzija podržava VS Code, Cursor, Windsurf, VSCodium i druge uređivače, i ponovo koristi OpenCode lokalni runtime i konfiguraciju Provider-a. IDE ekstenzija ponovo koristi lokalni CLI Provider, ali lanac zahteva može se razlikovati između verzija uređivača; prilikom prve integracije, molimo vas da fiksirate verziju i završite minimalnu verifikaciju.

## Konfiguracija Provider-a

Prvo, prema [OpenCode Terminal konfiguraciji](https://platform.acedata.cloud/documents/opencode-terminal-integration), konfigurišite Ace Data Cloud Provider u `opencode.json` ili `opencode.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## Instalacija IDE Ekstenzije

1. U integrisanom terminalu uređivača pokrenite `opencode`, i pratite zvanični proces za automatsku instalaciju ekstenzije; takođe možete ručno instalirati iz odgovarajuće Marketplace.
2. Ponovo učitajte uređivač.
3. Iz OpenCode ekstenzije pokrenite `Reply only OK`.
4. Ponovo izvršite zahtev koji zahteva čitanje datoteka ili izmene koda, kako biste potvrdili da IDE ekstenzija koristi isti Provider i model.

## Trenutne granice

- Sposobnosti Provider-a dolaze iz OpenCode runtime-a, ne predstavljaju nativnu podršku Ace Data Cloud od strane host uređivača.
- Verzije ekstenzija za VS Code i različite fork-ove mogu se razlikovati, treba ih posebno zabeležiti.
- Uspešan običan razgovor ne može zameniti verifikaciju čitanja datoteka, uređivanja i poziva alata.
