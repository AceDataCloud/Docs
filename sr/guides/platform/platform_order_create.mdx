title: "Kreiranje naloga za dopunu na AceDataCloud platformi"

Kreirajte nalog za plaćanje na čekanju za jednu ili više Application aplikacija. Kreiranje će upisati nalog, ali neće automatski završiti plaćanje; pre plaćanja treba proveriti `price`, paket i Application u odgovoru.

## Priprema

- Kreirajte [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Preuzmite `application_id` iz [liste Application aplikacija](https://platform.acedata.cloud/documents/platform-application-list).
- Izaberite `package_id` koji odgovara tipu Application aplikacije i koji je moguće kupiti iz `packages` u [detaljima usluge](https://platform.acedata.cloud/documents/platform-service-detail).

```shell
export PLATFORM_TOKEN='tvoj nalog token'
export APPLICATION_ID='tvoj Application ID'
export PACKAGE_ID='tvoj Package ID'
```

## Pregled interfejsa

| Stavka    | Sadržaj                                              |
| ---- | ----------------------------------------------- |
| Metod   | `POST`                                          |
| URL  | `https://platform.acedata.cloud/api/v1/orders/` |
| Autentifikacija   | Account Token, OAuth token zahteva `orders:write`      |
| Body | JSON                                            |

## Telo zahteva

Nalog za jednu Application aplikaciju koristi `application_id` + `package_id`; grupni nalog koristi `application_ids` + `package_ids` odgovarajućih dužina. Obični nalozi biraju način plaćanja u naknadnom `/pay/` zahtevu. iOS nalog za kupovinu unutar aplikacije prilikom kreiranja prosleđuje `pay_way: "AppleIAP"` i može izabrati samo jedan Usage paket sa `metadata.apple_product_id` i `metadata.apple_price`. Apple kupovina unutar aplikacije koristi zasebne unapred postavljene cene u američkim dolarima, bez kombinovanja sa članskim popustima, popustima za način plaćanja ili dodatnim cenama sajta; iznos naplate u lokalnoj valuti u drugim regionima zavisi od Apple stranice za potvrdu plaćanja.

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/orders/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d "{\"application_id\":\"${APPLICATION_ID}\",\"package_id\":\"${PACKAGE_ID}\"}"
```

## Objašnjenje odgovora

Uspeh vraća `201` i novokreirani Order objekat. Ključna polja uključuju `id`, `price`, `discount`, `state`, `application_id/application_ids`, `package_id/package_ids`, `expired_at` i vremenska polja. Novi nalog je obično `Pending`, nakon čega se poziva [plaćanje naloga](https://platform.acedata.cloud/documents/platform-order-pay).

- `price` je iznos za plaćanje koji server izračunava na osnovu paketa, dodatne cene sajta i popusta; klijent ga ne treba samostalno izračunavati.
- Kada Package i Application usluga ili tip nisu usklađeni, vraća se `400`.
- Besplatni Package paketi kojima upravlja sistem ne mogu se samostalno preuzeti putem javnog interfejsa za naloge.
- Kreiranje naloga za Application aplikaciju koja ne pripada trenutnom nalogu biće odbijeno.
