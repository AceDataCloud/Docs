[ChatBox](https://chatboxai.app/) je AI klijent otvorenog koda koji podržava Windows, macOS, Linux, iOS, Android i Web. Podržava prilagođene provajdere tipa „OpenAI API“, stoga se može direktno povezati sa Ace Data Cloud-om. Ovaj članak predstavlja proces konfiguracije.

## Proces prijave

Da biste povezali Ace Data Cloud u ChatBox-u, prvo idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications), preuzmite svoj API Token i sačuvajte ga za kasnije.

![Preuzimanje Ace Data Cloud API Key-a](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobijate besplatni kredit, pa možete besplatno isprobati uslugu modela Ace Data Cloud.

## Preuzimanje ChatBox-a

Idite na [zvanični ChatBox sajt](https://chatboxai.app/) i preuzmite prema platformi, ili direktno koristite [Web verziju](https://web.chatboxai.app/) bez instalacije:

- Desktop: Windows `.exe`, macOS `.dmg` (razlikuju se Intel / Apple Silicon), Linux AppImage
- Mobilni: App Store, Google Play, direktan Android link sa zvaničnog sajta

## Konfigurisanje Ace Data Cloud-a

Pokrenite ChatBox, idite na **Podešavanja → Modeli → Dodaj prilagođeni Provider**, postavite **API Mode** na **OpenAI API Compatible**, a zatim unesite:

| Polje       | Vrednost                           | Objašnjenje                                      |
| -------- | --------------------------- | --------------------------------------- |
| API ključ   | tvoj Ace Data Cloud Token     | Token kopiran sa konzole                            |
| API Host | `https://api.acedata.cloud` | Unesite samo korenski domen, **nemojte dodavati `/openai` ili `/v1`**         |
| API Path | `/v1/chat/completions`      | Podrazumevano u ChatBox-u je `/chat/completions`, potrebno je ručno promeniti na ovo |

![Interfejs za konfiguraciju ChatBox Ace Data Cloud Provider-a](https://cdn.acedata.cloud/3789c8e3dd4d.png)

Putanja zahteva ChatBox-a je `{API Host} + {API Path}`, stoga je dovoljno uneti samo korenski domen u Host:

| API Host                              | Konačni zahtev                                                      | Rezultat                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | Ispravno                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (nema `/v1` pod `/openai`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

ChatBox neće automatski pozvati `/v1/models`; potrebno je ručno uneti ID modela (jedan po redu) u polje „Prilagođeni modeli“ pri dnu stranice sa podešavanjima modela. Nakon čuvanja, možete ga izabrati u padajućem meniju modela na interfejsu za razgovor. Prekidači mogućnosti, kontekstni prozor i ograničenje izlaza moraju biti popunjeni prema trenutnom ugovoru izabranog modela, nemojte prepisivati vrednosti drugih modela.

## Izbor modela

Katalog modela će se neprekidno ažurirati. Prednost dajte listi modela koju klijent automatski učitava; kada je potrebno ručno unošenje, prvo zatražite `GET https://api.acedata.cloud/v1/models` da biste dobili trenutne ID-jeve modela, a zatim birajte prema mogućnostima konteksta, slika i poziva alata koje klijent podržava.

## Provera povezivanja

Ako niste sigurni da li je problem u ChatBox-u ili mreži, možete prvo direktno proveriti krajnju tačku pomoću curl-a (zamenite `{token}` svojim Token-om):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Vraćanje OpenAI kompatibilnog objekta `chat.completion` znači da su Token i krajnja tačka spremni; ako se vrati `HTTP 403 used_up`, to znači da je Token važeći, ali da nema dovoljno sredstava, pa možete dopuniti sredstva na [konzoli](https://platform.acedata.cloud/console/applications).

## Česta pitanja

### Prikazuje se 404 Not Found

Obično je API Host-u dodat `/openai` ili `/v1`. U Host unesite samo `https://api.acedata.cloud`, a putanju prepustite podrazumevanoj `/v1/chat/completions`.

### Prikazuje se 401 / token_mismatched

Potvrdite da je u „API ključ“ nalepljen Ace Data Cloud Token (bez prefiksa `Bearer`, bez suvišnih razmaka) i da aplikacija kojoj pripada ima dovoljno sredstava.

### Model se ne vidi u padajućem meniju modela

ChatBox neće automatski preuzeti listu modela; morate ručno uneti ID modela u polje „Prilagođeni modeli“ i sačuvati.

### Želite da generišete slike u ChatBox-u

Generisanje slika Ace Data Cloud-a je zaseban Images API (`/openai/images/generations`), sa putanjom različitom od interfejsa za razgovor, te se ulaz za slike u ChatBox-u ne može direktno povezati. Ako želite da crtate slike, pogledajte [Images Generation API dokumentaciju](https://platform.acedata.cloud/documents/openai-images-generations) za pozivanje pomoću curl-a / SDK-a.
