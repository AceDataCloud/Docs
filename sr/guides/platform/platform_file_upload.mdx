Otpremite lokalne datoteke na AceDataCloud platformu CDN i dobijte javno dostupan URL (u stilu `https://cdn.acedata.cloud/xxxxxx.png`), koji se može odmah koristiti u parametrima kao što su `image_url`, `reference_url` drugih poslovnih API interfejsa (kao što su Midjourney, Suno, Flux).

Primjenjivi scenariji:

- Prije pozivanja Midjourney `/midjourney/imagine`, prvo otpremite referentnu sliku na CDN da biste dobili URL.
- Sačuvajte video generisan u prethodnom koraku kao keš da biste ga koristili kao ulaz u sljedećem koraku.
- Privremeno hostujte materijale koje su otpremili korisnici, bez potrebe za izgradnjom vlastitog S3.

> ℹ️ Ovaj interfejs pripada **API-ju za upravljanje AceDataCloud platformom**, sa jedinstvenim prefiksom `https://platform.acedata.cloud/api/v1/`.

## Pregled interfejsa

| Stavka            | Sadržaj                                             |
| ------------ | ---------------------------------------------- |
| Metoda           | `POST`                                         |
| URL          | `https://platform.acedata.cloud/api/v1/files/` |
| Autentifikacija           | ✅ Potreban je token naloga                                       |
| Content-Type | `multipart/form-data`（**nije JSON**）             |

## Objašnjenje autentifikacije (kako dobiti token naloga)

Zaglavlje zahtjeva:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

Način dobijanja: prijavite se na [AceDataCloud platformu](https://platform.acedata.cloud) → [Account Token konzola](https://platform.acedata.cloud/console/platform-tokens) → kliknite dugme „Kreiraj“. Za detalje pogledajte [Upravljanje tokenima naloga AceDataCloud platforme](https://platform.acedata.cloud/documents/platform-token).

## Tijelo zahtjeva (multipart/form-data)

| Polje     | Tip   | Obavezno  | Opis                        |
| ------ | ---- | --- | ------------------------- |
| `file` | file | ✅   | Binarni tok datoteke. **Podrazumijevano ograničenje za jednu datoteku je 100 MB** |

## Primjeri zahtjeva

### cURL

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/files/' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}" \
  -F 'file=@./photo.jpg'
```

### Python

```python
import os
import requests

PLATFORM_TOKEN = os.environ["PLATFORM_TOKEN"]

with open("photo.jpg", "rb") as f:
    resp = requests.post(
        "https://platform.acedata.cloud/api/v1/files/",
        headers={
            "accept": "application/json",
            "authorization": f"Bearer {PLATFORM_TOKEN}",
        },
        files={"file": ("photo.jpg", f, "image/jpeg")},
        timeout=60,
    )

data = resp.json()
print(f"✅ 上传成功：{data['file_url']}")
# 直接用于其他业务接口：
# requests.post("https://api.acedata.cloud/midjourney/imagine",
#     json={"prompt": "...", "image_urls": [data["file_url"]]}, ...)
```

### Node.js

```javascript
const fs = require('fs')
const FormData = require('form-data')

const form = new FormData()
form.append('file', fs.createReadStream('./photo.jpg'))

const r = await fetch('https://platform.acedata.cloud/api/v1/files/', {
  method: 'POST',
  headers: {
    authorization: `Bearer ${process.env.PLATFORM_TOKEN}`,
    ...form.getHeaders(),
  },
  body: form,
})
const data = await r.json()
console.log('CDN URL:', data.file_url)
```

## Primjer odgovora（HTTP 200）

```json
{
  "file_url": "https://cdn.acedata.cloud/qrd7gw.jpg"
}
```

Samo direktno koristite polje `file_url` u drugim poslovnim interfejsima — CDN URL je trenutno javno dostupan i ne zahtijeva autentifikaciju; nemojte ga smatrati obećanjem trajnog arhiviranja.

## Objašnjenje polja odgovora

| Polje         | Tip     | Opis         |
| ---------- | ------ | ---------- |
| `file_url` | string | CDN pristupni URL |

## Obrada grešaka

| HTTP | Primjer odgovora                                         | Značenje                 |
| ---- | -------------------------------------------- | ------------------ |
| 400  | `{"error":"No file provided"}`               | Polje `file` nije priloženo ili naziv polja nije ispravan |
| 401  | DRF odgovor o grešci autentifikacije                                   | Token naloga nedostaje ili je nevažeći       |
| 413  | `{"error":"File too large","max_bytes":...}` | Datoteka premašuje 100 MB（podrazumijevano）    |

## Praktični savjeti

- **Otpremanje slika kao referentnih slika**: Midjourney `image_urls`, Flux `image_url`, Veo `reference_url` svi prihvataju CDN URL, **ne** prihvataju base64. Prvo dobijanje URL-a putem ovog interfejsa je uobičajena praksa.
- **Ne otpremajte osjetljive podatke**: vraćeni URL je javno dostupan; period čuvanja zavisi od trenutne politike skladištenja platforme, za dugoročno arhiviranje koristite vlastito skladište objekata.
- **Masovno otpremanje**: kontrolišite konkurentnost i postavite vremensko ograničenje za svako otpremanje; propusnost zavisi od veličine datoteke i mrežnog okruženja.
