Coze званично подржава интеграцију прилагођених модела и пружа три протокола: OpenAI Chat API, OpenAI Responses API и Anthropic Messages API. Основни URL, путеви, заглавља, стриминг и уговори о позивима алата различити су за сва три протокола, па их је потребно конфигурисати и верификовати одвојено.

| Пут                      | Статус  | Водич                                                                                  |
| ----------------------- | --- | ----------------------------------------------------------------------------------- |
| OpenAI Chat Completions | Експериментално | [Chat конфигурација](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | Експериментално | [Responses конфигурација](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | Експериментално | [Messages конфигурација](https://platform.acedata.cloud/documents/coze-messages-integration)   |

“Експериментално” значи да су званичне способности и конфигурациони улази потврђени, али различите Coze области, верзије или пакети могу показивати различите форме, Ace Data Cloud и даље мора да заврши верификацију фиксне верзије према протоколу. Не изводите успешну примену једног протокола на друга два.

## Принципи конфигурације

- Основни API URL прво попуните основом коју даје документација; не додавајте поново путanju краја коју ће клијент аутоматски допунити.
- API кључ користите свој Ace Data Cloud API токен.
- Модел користите прецизан ID модела који је компатибилан са одабраним протоколом из каталога модела.
- Након успешног обичног текста, такође треба верификовати стриминг и позиве алата.
