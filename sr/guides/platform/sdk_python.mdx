[`acedatacloud`](https://pypi.org/project/acedatacloud/) је званични Python SDK за Ace Data Cloud, који обавија све услуге на `api.acedata.cloud` у типизоване методе као што су `client.openai.chat.completions.create(...)`, `client.images.generate(...)`, `client.search.google(...)` и друге, а истовремено пружа две верзије клијента: синхрону и асинхрону.

Основни слој се заснива на `httpx`, подржава SSE стриминг, аутоматско поновно покретање, типизоване изузетке и pydantic валидацију типова.

Изворни код и адреса пакета:

- SDK репозиторј: [https://github.com/AceDataCloud/SDK](https://github.com/AceDataCloud/SDK)
- PyPI: [https://pypi.org/project/acedatacloud/](https://pypi.org/project/acedatacloud/)

## Инсталација

```bash
pip install acedatacloud
# или uv add / poetry add
```

Ако је потребно плаћање на X402 ланцу (без API Token пута), инсталирајте још један:

```bash
pip install acedatacloud-x402
```

Излаз провере верзије чистог venv:

```text
$ python -c "import importlib.metadata as m; print(m.version('acedatacloud'))"
2026.4.26.1

$ python -c "from acedatacloud import AceDataCloud, AsyncAceDataCloud; print('ok')"
ok
```

Резултати објашњење:

- Верзија пакета је `2026.4.26.1` (CalVer, ревизија 26. априла 2026. године).
- `AceDataCloud` је синхрони клијент, `AsyncAceDataCloud` је asyncio асинхрони клијент.
- Овај SDK не зависи од `pydantic`, а тело одговора се униформно враћа као `dict`. Ово је различито од `openai-python`, па треба обратити пажњу приликом миграције.

## Припрема API Token

Погледајте [SDK преглед - захтев за API Token](https://platform.acedata.cloud/documents/acedatacloud-sdk#申请-api-token) да бисте добили токен, а затим у shell-у `export`:

```bash
export ACEDATACLOUD_API_TOKEN={token}
```

Када конструишете клијента, не преносите `api_token`, SDK ће аутоматски прочитати `ACEDATACLOUD_API_TOKEN` променљиву окружења. Ако у вашем окружењу већ постоји `ACEDATACLOUD_API_KEY` (конвенција пројектног репозиторија), молимо вас да експлицитно пренесете: `AceDataCloud(api_token=os.environ["ACEDATACLOUD_API_KEY"])`.

## Пример 1: chat.completions (синхроно)

```python
import os, time, json
from acedatacloud import AceDataCloud

client = AceDataCloud(api_token=os.environ["ACEDATACLOUD_API_KEY"])

t0 = time.time()
res = client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Reply with exactly: ADC_PY_SDK_OK"}],
    max_tokens=20,
    temperature=0,
)
print("elapsed_ms", int((time.time() - t0) * 1000))
print("id", res["id"])
print("model", res["model"])
print("content", res["choices"][0]["message"]["content"])
print("usage", json.dumps({k: v for k, v in res["usage"].items()
                            if k in ("prompt_tokens","completion_tokens","total_tokens")}))
```

Резултати програма:

```text
elapsed_ms 2963
id chatcmpl-DldFdnIlhSUXINpupgsUmZL78MnBu
model gpt-4o-mini
content ADC_PY_SDK_OK
usage {"prompt_tokens": 17, "completion_tokens": 7, "total_tokens": 24}
```

Резултати објашњење:

- `id` је ID одговора, који можете пронаћи у [историји коришћења](https://platform.acedata.cloud/console/usages).
- `content ADC_PY_SDK_OK` је фиксна идентификација коју модел заиста враћа.
- `res["usage"]` враћа `dict`, а не pydantic модел; један позив троши око 24 токена.

## Пример 2: chat.completions (SSE стриминг)

Када је `stream=True`, `create` враћа обичан генератор, који при сваком `yield` враћа парсирани chunk dict.

```python
import os, time
from acedatacloud import AceDataCloud

client = AceDataCloud(api_token=os.environ["ACEDATACLOUD_API_KEY"])

t0 = time.time()
first_chunk_ms = None
chunks = 0
collected = []

for chunk in client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Count from 1 to 5, separated by single spaces, no extra text."}],
    max_tokens=30,
    temperature=0,
    stream=True,
):
    if first_chunk_ms is None:
        first_chunk_ms = int((time.time() - t0) * 1000)
    chunks += 1
    delta = (chunk.get("choices") or [{}])[0].get("delta", {}).get("content")
    if delta:
        collected.append(delta)

print("total_elapsed_ms", int((time.time() - t0) * 1000))
print("first_chunk_ms", first_chunk_ms)
print("chunks", chunks)
print("collected", "".join(collected).strip())
```

Резултати програма:

```text
total_elapsed_ms 2111
first_chunk_ms 2104
chunks 12
collected 1 2 3 4 5
```

Резултати објашњење:

- Прва фрејм одлагање 2104 ms, а следећих 11 фрејмова је требало само 7 ms да се заврше — чим услуга почне да стримује, локално је лако конзумирати.
- chunk је обичан dict, безбедно добијање вредности по OpenAI SSE формату се може обавити помоћу `.get()`.
- У стварној производњи се препоручује да се током `yield` истовремено шаље SSE на фронт, а укупно прво одлагање је близу 2 секунде.

## Пример 3: AsyncAceDataCloud (асинхроно)

API `AsyncAceDataCloud` је потпуно симетричан синхроном верзији, само што све IO методе враћају корутине. Погодно за FastAPI / aiohttp / asyncio услуге.

```python
import os, asyncio, time
from acedatacloud import AsyncAceDataCloud

async def main():
    client = AsyncAceDataCloud(api_token=os.environ["ACEDATACLOUD_API_KEY"])
    t0 = time.time()
    res = await client.openai.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": "Reply with exactly: ADC_PY_ASYNC_OK"}],
        max_tokens=20,
        temperature=0,
    )
    print("elapsed_ms", int((time.time() - t0) * 1000))
    print("id", res["id"])
    print("content", res["choices"][0]["message"]["content"])
    await client.close()

asyncio.run(main())
```

Резултати програма:

```text
elapsed_ms 2392
id chatcmpl-DldFwRlrgtYDBpIr0T55aDQI4GlbF
content ADC_PY_ASYNC_OK
```

Резултати објашњење:

- Асинхрона верзија и синхрона верзија користе исти HTTP пут, само што је имплементација конекционог пула различита (`httpx.AsyncClient`).
- При изласку експлицитно `await client.close()` затвара конекциони пул; у услугама са дугим животним циклусом, потребно је затворити само једном пре завршетка процеса.
- Једнократно одлагање је слично синхроном, а у сценаријима са конкурентношћу асинхроност показује предност — један event loop може истовремено обављати десетине или стотине активних захтева.

## Пример 4: images.generate (NanoBanana)

NanoBanana API је синхрона услуга за генерисање слика, **не преносите `wait`** — SDK позив ће стално чекати да услуга врати 200.
```python
import os, time
from acedatacloud import AceDataCloud

client = AceDataCloud(api_token=os.environ["ACEDATACLOUD_API_KEY"])

t0 = time.time()
res = client.images.generate(
    provider="nano-banana",
    model="nano-banana",
    prompt="Minimalistički logo žute banane na beloj pozadini, ravni dizajn",
)
print("elapsed_ms", int((time.time() - t0) * 1000))
print("task_id", res.get("task_id"))
print("trace_id", res.get("trace_id"))
data = res.get("data") or []
if data:
    print("image_url", data[0].get("image_url"))
```

Rezultat programa:

```text
elapsed_ms 18977
task_id 9e71f40f-1579-480d-adf4-07a95450904f
trace_id 5aa21d7f-af84-48e6-9ce0-9c6c36c8e5d9
image_url https://platform.cdn.acedata.cloud/nanobanana/884e92df-a497-44e0-9681-35c7a00e0a6c.png
```

Objašnjenje rezultata:

- `image_url` je stabilna adresa na CDN-u, može se direktno preuzeti ili ugraditi u veb stranicu.
- U 18.9 sekundi gotovo sve je bilo modeliranje; troškovi lokalnog SDK-a su samo nekoliko milisekundi.
- Za prave asinhrone zadatke kao što su Midjourney, Sora, Veo, Suno, potrebno je koristiti `wait=True` ili ručno `TaskHandle.wait()` za polling, više informacija u [SDK zadatku polling i streaming odgovoru](https://platform.acedata.cloud/documents/sdk-tasks-and-streaming).

## Primer 5: Tipizovana obrada grešaka

```python
import os
from acedatacloud import AceDataCloud
from acedatacloud import AuthenticationError, RateLimitError, ValidationError

bad = AceDataCloud(api_token="definitely-not-a-real-token")

try:
    bad.openai.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": "hi"}],
        max_tokens=5,
    )
except AuthenticationError as err:
    print("err_class", type(err).__name__)
    print("status", err.status_code)
    print("code", err.code)
except RateLimitError as err:
    # 429, SDK automatski ponovo pokušava 2 puta pre nego što baci grešku
    print("rate limited:", err.code)
except ValidationError as err:
    # 400, na primer, nedostaje polje, ime modela ne postoji
    print("bad request:", err.code, err.message)
```

Hijerarhija grešaka je ista kao u TypeScript-u: `AuthenticationError` (401), `TokenMismatchError` (token se ne poklapa sa uslugom), `InsufficientBalanceError` (nedovoljno sredstava), `ResourceDisabledError` (usluga je onemogućena), `ValidationError` (400), `RateLimitError` (429), `ModerationError` (403 provere sadržaja), `APIError` (generalna greška), `TimeoutError` (istek vremena), `TransportError` (greška na mrežnom nivou).

## Opcije konfiguracije

```python
from acedatacloud import AceDataCloud

client = AceDataCloud(
    # Obavezno jedno: eksplicitni token ili promenljiva okruženja ACEDATACLOUD_API_TOKEN
    api_token="...",

    # Osnovna adresa API-ja platforme, podrazumevano https://api.acedata.cloud
    base_url="https://api.acedata.cloud",

    # Neki servisi (kao što su metapodaci dashboard-a) koriste platformsku domenu
    platform_base_url="https://platform.acedata.cloud",

    # Vreme čekanja za pojedinačni zahtev, u sekundama; podrazumevano 300.0
    timeout=300.0,

    # Broj automatskih ponovnih pokušaja, podrazumevano 2; uslovi za ponovni pokušaj: 408 / 409 / 429 / 5xx / mrežna greška
    max_retries=2,

    # Prilagođeni zahtevi
    headers={"x-app": "my-service/1.0"},
)
```

> Python SDK-ov `timeout` i TaskHandle-ov `poll_interval` / `max_wait` su u **sekundama**, dok TypeScript SDK koristi **milisekunde**, na to treba obratiti pažnju prilikom migracije između jezika. Više informacija u [SDK zadatku polling i streaming odgovoru](https://platform.acedata.cloud/documents/sdk-tasks-and-streaming).

> SDK podrazumevano čita promenljivu okruženja `ACEDATACLOUD_API_TOKEN`; u ovom tekstu, kako bi se uskladilo sa [Claude Code VS Code tutorijalom](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) i drugim tutorijalima, primer koristi `ACEDATACLOUD_API_KEY`, potrebno je eksplicitno uneti `api_token=os.environ["ACEDATACLOUD_API_KEY"]`.

## Napredna: X402 platni hook

```python
from acedatacloud import AceDataCloud
from acedatacloud_x402 import create_x402_payment_handler

client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=my_evm_signer,
        prefer_scheme="exact",   # ili "upto"
    )
)
```
