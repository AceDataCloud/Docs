Vraća trenutno omogućene i nezastarjele API-je ove usluge po stranicama putem Service UUID-a. Ako postoji samo alias, prvo pozovite [detalje usluge](https://platform.acedata.cloud/documents/platform-service-detail) da biste dobili `id`.

## Pregled interfejsa

| Stavka   | Sadržaj                                                             |
| --- | ------------------------------------------------------------------- |
| Metod  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| Autentifikacija  | Javno, nije potreban token naloga                                                           |
| Paginacija  | `count` + `items`                                                   |

## Parametri

| Parametar           | Pozicija    | Obavezno  | Opis                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | Da   | Service UUID, alias nije podržan           |
| `limit`      | query | Ne   | Broj stavki po stranici, najviše 100                      |
| `offset`     | query | Ne   | Pomak paginacije                            |
| `ordering`   | query | Ne   | Django izraz za sortiranje; preporučuje se `rank` ili `-rank` |

Trenutni interfejs ne podržava filtriranje po `stage`; već isključuje `Deprecated` API-je.

```shell
export SERVICE_ID='你的 Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

Stavke liste koriste istu indeksnu strukturu kao [lista API-ja platforme](https://platform.acedata.cloud/documents/platform-api-list) i trenutno sadrže `definition`. Kada je potreban stabilan ulaz za pojedinačni API, nastavite sa pozivom `/api/v1/apis/{api_id}`.

## Obrada grešaka

- Usluga ne postoji ili nije vidljiva na trenutnom sajtu: `404`.
- `service_id` mora biti UUID; alias se neće razrešavati u ovoj akciji.
