Python SDK је погодан за сервере, податке, аутоматизоване агенте и скрипте за обраду. `acedatacloud` је одговоран за API позиве, а `acedatacloud-x402` за потписивање `PAYMENT-SIGNATURE` заглавља захтева.

Изворни код и адресе пакета:

- SDK репозиторијум: [https://github.com/AceDataCloud/SDK](https://github.com/AceDataCloud/SDK)
- X402 Client репозиторијум: [https://github.com/AceDataCloud/X402Client](https://github.com/AceDataCloud/X402Client)
- PyPI SDK: [https://pypi.org/project/acedatacloud/](https://pypi.org/project/acedatacloud/)
- PyPI X402 Client: [https://pypi.org/project/acedatacloud-x402/](https://pypi.org/project/acedatacloud-x402/)

## Инсталирање зависности

```bash
pip install acedatacloud acedatacloud-x402
```

Ако желите да користите `upto`, потребно је једнократно позвати Permit2 одобрење CLI, који зависи од `web3`:

```bash
pip install 'acedatacloud-x402[cli]'
```

Излаз инсталације и провере у чистом Python venv:

```text
acedatacloud 2026.4.26.1
acedatacloud-x402 2026.5.31.3
imports_ok True True True True True True
usage: acedatacloud-x402 [-h] {approve-permit2} ...
approve-permit2  Једнократно ERC-20 одобрење (Permit2, amount) потребно пре потписивања upto плаћања.
```

Објашњење резултата:

- `acedatacloud` и `acedatacloud-x402` могу се инсталирати и увезти из PyPI.
- `pip install 'acedatacloud-x402[cli]'` ће укључити `approve-permit2` CLI, за претходно одобрење за `upto`.

## Base или SKALE пример

Следећи пример не захтева API токен. Лични кључ новчаника се само локално потписује и неће бити послат Ace Data Cloud.

```python
import os

from acedatacloud import AceDataCloud
from acedatacloud_x402 import EVMAccountSigner, create_x402_payment_handler

signer = EVMAccountSigner.from_private_key(os.environ["EVM_PRIVATE_KEY"])

client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
    )
)

res = client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)

print(res["choices"][0]["message"]["content"])
```

Python SDK тренутно враћа `dict`, па пример користи `res["choices"][0]["message"]["content"]`. Не претпостављајте директно да он има `.choices` атрибут.

Резултат програма за SKALE paid call:

```text
payer 0xd0479FA9FD8C678303d477433d24C15e3723CC1C
elapsed_ms 4786
content ADC_PY_SDK_X402_OK
id chatcmpl-DlcWajqAHOop3iebmO19XRfT5bTPz
```

Објашњење резултата:

- Програм је завршио 402 парсирање, `PAYMENT-SIGNATURE` потписивање и поновно слање оригиналног захтева.
- `content ADC_PY_SDK_X402_OK` је фиксни стринг који модел заиста враћа, што указује да је захтев прошао кроз X402 платни ланац до циљног API.
- `id chatcmpl-DlcWajqAHOop3iebmO19XRfT5bTPz` је ID одговора за ову chat completion.

Када користите SKALE, само промените име мреже:

```python
client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="skale",
        evm_signer=signer,
    )
)
```

## Solana пример

Solana користи base58 кодирани тајни кључ:

```python
import os

from acedatacloud import AceDataCloud
from acedatacloud_x402 import SolanaKeypairSigner, create_x402_payment_handler

client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="solana",
        solana_signer=SolanaKeypairSigner.from_base58(os.environ["SOLANA_SECRET_KEY"]),
    )
)

res = client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)
```

Solana пут ће конструисати и поднети SPL USDC `TransferChecked` трансакцију, а затим ставити потпис трансакције у `PAYMENT-SIGNATURE` envelope.

Solana paid retry на производном API-ју је вратио HTTP 200 и `ADC_SOLANA_E2E_OK`. Ова јавна RPC упит је наишао на ограничење, није стабилно потврдио потпис на ланцу; ако вам је потребна обрада, молимо вас да користите свој Solana RPC за упит о овој трансакцији.

## Async клијент

Исти payment handler може се користити за `AsyncAceDataCloud`:

```python
import os

from acedatacloud import AsyncAceDataCloud
from acedatacloud_x402 import EVMAccountSigner, create_x402_payment_handler

signer = EVMAccountSigner.from_private_key(os.environ["EVM_PRIVATE_KEY"])

client = AsyncAceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
    )
)

res = await client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)
```

## Користећи `upto` пост-мерење

Стварни трошкови API-а за chat комплетирање, позиве модела итд. могу се сазнати тек након завршетка одговора. У том тренутку API може истовремено вратити `exact` и `upto`. Ако желите да преферирате `upto`:

```python
client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
        prefer_scheme="upto",
    )
)
```

Резултат програма за Base `upto`:

```text
payer 0x5d4f08D5c2bb60703284bc06671Eb680fA41B105
elapsed_ms 5104
content ADC_BASE_UPTO_OK
id chatcmpl-DlcbyS4IT8kUAMo4Ri97HiIHc9T8V
settlement tx 0x4b0b836ce1cd1171cdbc37df1637150b024214ec28e7f6f2d09122f15cbfc036
settled value 3 atomic USDC
```

Потврда на ланцу:

```text
explorer https://basescan.org/tx/0x4b0b836ce1cd1171cdbc37df1637150b024214ec28e7f6f2d09122f15cbfc036
block 46726437
transfer value 3 atomic USDC
```

Објашњење резултата:

- `content ADC_BASE_UPTO_OK` указује да је захтев заиста ушао у модел API.
- `settled value 3 atomic USDC` указује да је `upto` обрачунао стварну потрошњу, а не одузео целокупни лимит.
- `settlement tx` може се отворити на BaseScan, за обраду сачувајте tx hash, payer, completion id и резиме захтева.

`upto` користи Permit2 за одобрење једног лимита, а стварни износ за обрачунавање не може прећи тај лимит. Први пут када се користи, потребно је једном одобрити USDC на циљној мрежи `approve(Permit2, amount)`.

CLI начин:

```bash
X402_PRIVATE_KEY=0x... acedatacloud-x402 approve-permit2 --network base
```

Програмски начин:

```python
from acedatacloud_x402 import EVMAccountSigner, approve_permit2

approve_permit2(
    rpc_url="https://mainnet.base.org",
    signer=EVMAccountSigner.from_private_key("0x..."),
    token_address="0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
)
```

Овај хелпер је идемпотентан. Ако је allowance већ довољан, вратиће `{"skipped": true}`, неће поново послати трансакцију на ланцу.

## Ниско-слојно потписивање
Ako ne koristite SDK, možete direktno pozvati niske funkcije za potpisivanje:

```python
import base64
import json

from acedatacloud_x402 import EVMAccountSigner, sign_evm_payment

envelope = sign_evm_payment(requirement, EVMAccountSigner.from_private_key("0x..."))
x_payment = base64.b64encode(json.dumps(envelope, separators=(",", ":")).encode()).decode()
```

Niske funkcije su pogodne za testiranje, proxy slojeve, integraciju sa gateway-ima ili neoficijalne SDK-ove. Obični poslovni kod treba da koristi `create_x402_payment_handler`.
