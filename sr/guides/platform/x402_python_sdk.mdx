Python SDK je pogodan za pozadinske servise, zadatke obrade podataka, automatizovane Agent-e i skripte za grupnu obradu. `acedatacloud` je zadužen za API pozive, a `acedatacloud-x402` je zadužen za potpisivanje zaglavlja zahteva `PAYMENT-SIGNATURE`.

Adrese izvornog koda i paketa:

- SDK repozitorijum: [https://github.com/AceDataCloud/SDK](https://github.com/AceDataCloud/SDK)
- X402 Client repozitorijum: [https://github.com/AceDataCloud/X402Client](https://github.com/AceDataCloud/X402Client)
- PyPI SDK: [https://pypi.org/project/acedatacloud/](https://pypi.org/project/acedatacloud/)
- PyPI X402 Client: [https://pypi.org/project/acedatacloud-x402/](https://pypi.org/project/acedatacloud-x402/)

## Instaliranje zavisnosti

```bash
pip install acedatacloud acedatacloud-x402
```

Ako želite da koristite `upto`, potrebno je i jednokratno pozvati Permit2 approve CLI, a taj CLI zavisi od `web3`:

```bash
pip install 'acedatacloud-x402[cli]'
```

Izlaz instalacije i provere importa u čistom Python venv-u:

```text
acedatacloud 2026.4.26.1
acedatacloud-x402 2026.5.31.3
imports_ok True True True True True True
usage: acedatacloud-x402 [-h] {approve-permit2} ...
approve-permit2  One-time ERC-20 approve(Permit2, amount) needed before signing upto payments.
```

Objašnjenje rezultata:

- `acedatacloud` i `acedatacloud-x402` mogu se instalirati i importovati sa PyPI-ja.
- `pip install 'acedatacloud-x402[cli]'` uključuje `approve-permit2` CLI, koji se koristi za prethodno odobrenje za `upto`.

## Base primer

Sledeći primer ne zahteva API Token. Privatni ključ novčanika se koristi samo za lokalno potpisivanje i neće biti poslat Ace Data Cloud-u.

```python
import os

from acedatacloud import AceDataCloud
from acedatacloud_x402 import EVMAccountSigner, create_x402_payment_handler

signer = EVMAccountSigner.from_private_key(os.environ["EVM_PRIVATE_KEY"])

client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
    )
)

res = client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)

print(res["choices"][0]["message"]["content"])
```

Python SDK trenutno vraća `dict`, zato primer koristi `res["choices"][0]["message"]["content"]`. Nemojte direktno pretpostavljati da nužno ima svojstvo `.choices`.

## Solana primer

Solana koristi secret key kodiran u base58 formatu:

```python
import os

from acedatacloud import AceDataCloud
from acedatacloud_x402 import SolanaKeypairSigner, create_x402_payment_handler

client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="solana",
        solana_signer=SolanaKeypairSigner.from_base58(os.environ["SOLANA_SECRET_KEY"]),
    )
)

res = client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)
```

Solana putanja će kreirati i poslati SPL USDC `TransferChecked` transakciju, a zatim staviti potpis transakcije u `PAYMENT-SIGNATURE` envelope.

Solana paid retry je na produkcionom API-ju već vratio HTTP 200 i `ADC_SOLANA_E2E_OK`. Javni RPC upit je ovaj put naišao na ograničenje brzine, pa nije stabilno potvrđen signature na lancu; kada je potrebno usaglašavanje, koristite sopstveni Solana RPC za upit te transakcije.

## Async klijent

Isti payment handler može se koristiti sa `AsyncAceDataCloud`:

```python
import os

from acedatacloud import AsyncAceDataCloud
from acedatacloud_x402 import EVMAccountSigner, create_x402_payment_handler

signer = EVMAccountSigner.from_private_key(os.environ["EVM_PRIVATE_KEY"])

client = AsyncAceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
    )
)

res = await client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)
```

## Korišćenje `upto` naknadnog merenja

Stvarni trošak API-ja, kao što su dopune ćaskanja i pozivi modela, možda se može saznati tek nakon završetka odgovora. U tom slučaju API može istovremeno vratiti `exact` i `upto`. Ako želite da prioritetno koristite `upto`:

```python
client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
        prefer_scheme="upto",
    )
)
```

Rezultat pokretanja Base `upto` programa:

```text
payer 0x5d4f08D5c2bb60703284bc06671Eb680fA41B105
elapsed_ms 5104
content ADC_BASE_UPTO_OK
id chatcmpl-DlcbyS4IT8kUAMo4Ri97HiIHc9T8V
settlement tx 0x4b0b836ce1cd1171cdbc37df1637150b024214ec28e7f6f2d09122f15cbfc036
settled value 3 atomic USDC
```

Potvrda na lancu:

```text
explorer https://basescan.org/tx/0x4b0b836ce1cd1171cdbc37df1637150b024214ec28e7f6f2d09122f15cbfc036
block 46726437
transfer value 3 atomic USDC
```

Objašnjenje rezultata:

- `content ADC_BASE_UPTO_OK` pokazuje da je zahtev zaista ušao u model API.
- `settled value 3 atomic USDC` pokazuje da se `upto` obračunava prema stvarnoj upotrebi, umesto da se naplati puni limit.
- `settlement tx` se može otvoriti u BaseScan-u; prilikom usaglašavanja sačuvajte tx hash, payer, completion id i sažetak zahteva.

`upto` koristi Permit2 za odobravanje limita, a stvarni iznos poravnanja ne može premašiti taj limit. Pre prve upotrebe, potrebno je jednom izvršiti `approve(Permit2, amount)` za USDC na ciljnom lancu.

CLI način:

```bash
X402_PRIVATE_KEY=0x... acedatacloud-x402 approve-permit2 --network base
```

Programski način:

```python
from acedatacloud_x402 import EVMAccountSigner, approve_permit2

approve_permit2(
    rpc_url="https://mainnet.base.org",
    signer=EVMAccountSigner.from_private_key("0x..."),
    token_address="0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
)
```

Ovaj helper je idempotentan. Ako je allowance već dovoljan, vratiće `{"skipped": true}` i neće ponovo poslati transakciju na lanac.

## Potpisivanje niskog nivoa

Ako ne koristite SDK, možete direktno pozvati funkciju za potpisivanje niskog nivoa:

```python
import base64
import json

from acedatacloud_x402 import EVMAccountSigner, sign_evm_payment

envelope = sign_evm_payment(requirement, EVMAccountSigner.from_private_key("0x..."))
x_payment = base64.b64encode(json.dumps(envelope, separators=(",", ":")).encode()).decode()
```

Funkcija niskog nivoa je pogodna za testiranje, proxy slojeve, integraciju gateway-a ili nezvanične SDK-ove. Za običan poslovni kod, prednost dajte `create_x402_payment_handler`.
