Preuzmite potpune informacije o pojedinačnoj usluzi putem ID-ja usluge (UUID) ili aliasa (alias) — polja su potpunija od onih koja vraća [Preuzimanje liste AceDataCloud platform usluga](https://platform.acedata.cloud/documents/platform-service-list), uz dodatno proširene povezane objekte kao što su `apis`, `proxies`, `datasets`, `packages` itd. Primenljivo za scenarije kao što su stranica sa detaljima usluge, stranica za poređenje cena, opis Agent alata itd.

> ℹ️ Ovaj interfejs pripada **AceDataCloud Platform Management API-ju**, sa jedinstvenim prefiksom `https://platform.acedata.cloud/api/v1/`. Kompletan indeks interfejsa pogledajte u [Preuzimanje liste AceDataCloud platform dokumenata](https://platform.acedata.cloud/documents/platform-document-list).

## Pregled interfejsa

| Stavka   | Sadržaj                                                      |
| --- | ------------------------------------------------------------- |
| Metod  | `GET`                                                         |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}` |
| Autentifikacija  | ❌ javno                                                          |

`/services/{id}` i `/services/{id}/` su trenutno oba dostupna; primeri dosledno koriste oblik bez završne kose crte.

## Objašnjenje autentifikacije

Ovaj interfejs je potpuno javan. **Međutim, nakon dodavanja naloga tokena, polje `applied` u odgovoru će odražavati stvarni status prijave trenutnog naloga**, u suprotnom je uvek `false`.

Način dobijanja nalogo tokena pogledajte u [Upravljanje tokenima AceDataCloud platform naloga](https://platform.acedata.cloud/documents/platform-token).

## Parametri putanje

| Parametar           | Tip            | Obavezno  | Opis                                                    |
| ------------ | ------------- | --- | ----------------------------------------------------- |
| `service_id` | UUID / string | ✅   | ID usluge (UUID) ili alias (`midjourney`, `openai`, `webextrator` itd.) |

## Primeri zahteva

### cURL

```shell
# 按 UUID 查询
curl 'https://platform.acedata.cloud/api/v1/services/8efa1d83-9b75-4562-b44a-af95ce563d05' \
  -H 'accept: application/json'

# 按 alias 查询
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json'

# 带账户令牌看 applied 状态
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

resp = requests.get(
    "https://platform.acedata.cloud/api/v1/services/midjourney",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
svc = resp.json()
print(f"服务: {svc['title']} ({svc['alias']})")
print(f"已申请: {svc['applied']}, 免费额度: {svc['free_amount']} {svc['unit']}")
print(f"API 数: {len(svc['apis'])}, 套餐数: {len(svc['packages'])}")
for pkg in svc["packages"]:
    print(f"  ¥{pkg['price']:>7.2f}  ->  {pkg['amount']} {svc['unit']}")
```

### Node.js

```javascript
const r = await fetch('https://platform.acedata.cloud/api/v1/services/midjourney', {
  headers: { accept: 'application/json' },
})
const svc = await r.json()
console.log(`${svc.title} - 套餐 ${svc.packages.length} 个 - API ${svc.apis.length} 个`)
```

## Objašnjenje polja odgovora

Interfejs za detalje je, pored svih polja iz [interfejsa liste](https://platform.acedata.cloud/documents/platform-service-list), dodatno proširio:

| Polje         | Tip    | Opis                                                            |
| ---------- | ----- | ------------------------------------------------------------- |
| `apis`     | array | Kompletna lista povezanih API objekata (svaki sadrži `id`, `name`, `title`, `path`, `stage`, `cost`) |
| `proxies`  | array | Kompletna lista povezanih Proxy objekata                                              |
| `datasets` | array | Povezani skupovi podataka (ako je `type=Dataset`)                                      |
| `packages` | array | Lista paketa, uključujući `type` (`Usage`/`Period`), `price`, `amount`, `duration`   |

Definicije ostalih polja pogledajte u [Preuzimanje liste AceDataCloud platform usluga → Objašnjenje polja odgovora](https://platform.acedata.cloud/documents/platform-service-list).

## Obrada grešaka

| HTTP | code        | Značenje                            |
| ---- | ----------- | ----------------------------- |
| 404  | `not_found` | `service_id` (UUID ili alias) ne postoji |
| 500  | —           | Obično je na kraju URL-a greškom dodata kosa crta; uklonite je i pokušajte ponovo          |

## Praktični saveti

- **`alias` > `UUID`**: Stabilnije je hardkodirati `alias` (kao što je `midjourney`) u kod; UUID se menja prilikom migracije okruženja.
- **Polje `apis` ne sadrži OpenAPI definiciju**: Kompletna OpenAPI 3.0 Schema nalazi se u interfejsu [Preuzimanje detalja AceDataCloud platform API-ja](https://platform.acedata.cloud/documents/platform-api-detail).
- **Preuzimanje „kompletnih mogućnosti” usluge**: Pomoću ovog interfejsa preuzmite `api_ids`, a zatim pozovite `/apis/{api_id}` za svaki od njih da preuzmete detalje.
- **Ako je `applied=true`**, možete direktno [kreirati API akreditive](https://platform.acedata.cloud/documents/platform-credential-create) da biste dobili 32-bitni Token potreban za pozivanje poslovnog interfejsa, bez ponovnog podnošenja prijave.
