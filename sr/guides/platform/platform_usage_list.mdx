Upitajte detalje poslovnih API poziva trenutnog naloga u poslednjih 60 dana, pogodno za proveru naplate, lociranje neuspelih zahteva i rešavanje problema po usluzi, Application-u, API-ju ili kredencijalu.

> Ova stranica upituje evidenciju poziva sopstvenog naloga. Ako želite da vidite samo javnu statistiku poziva određenog API-ja na celoj platformi, koristite [Statistiku API poziva](https://platform.acedata.cloud/documents/platform-api-usage).

## Priprema

### 1. Kreiranje tokena naloga

Ovaj interfejs pripada API-ju za upravljanje platformom i zahteva korišćenje **Account Token-a (tokena naloga)**:

1. Prijavite se na [AceDataCloud platformu](https://platform.acedata.cloud).
2. Otvorite [Account Token konzolu](https://platform.acedata.cloud/console/platform-tokens).
3. Kliknite na „Kreiraj“ i odmah sačuvajte token u menadžeru lozinki ili Secret Manager-u.

Za potpuno uputstvo pogledajte [Upravljanje tokenima naloga AceDataCloud platforme](https://platform.acedata.cloud/documents/platform-token). Token naloga se koristi za `platform.acedata.cloud/api/v1/**`; za pozivanje poslovnih interfejsa `api.acedata.cloud/**` koriste se API kredencijali (Credential), i ta dva se ne mogu mešati.

```shell
export PLATFORM_TOKEN='vaš token naloga'
```

Nemojte upisivati token u frontend kod, logove ili javna spremišta; ako procure, odmah ih obrišite i ponovo kreirajte u konzoli.

### 2. Priprema ID-jeva za filtriranje (opciono)

Bez prosleđivanja uslova filtriranja možete videti evidenciju za koju trenutni nalog ima ovlašćenje pregleda. Kada je potrebno suziti opseg:

- `application_id`: preuzmite iz [liste zahteva za usluge](https://platform.acedata.cloud/documents/platform-application-list);
- `credential_id`: preuzmite iz [liste API kredencijala](https://platform.acedata.cloud/documents/platform-credential-list);
- `api_id`: preuzmite iz [API liste](https://platform.acedata.cloud/documents/platform-api-list);
- `service_id`: preuzmite iz [liste usluga](https://platform.acedata.cloud/documents/platform-service-list).

Obični korisnici ne moraju prosleđivati `user_id`; ako se eksplicitno prosledi, mora odgovarati trenutnom nalogu, u suprotnom se vraća `403`. Administratori mogu koristiti ovaj parametar za filtriranje između naloga.

## Pregled interfejsa

| Stavka      | Sadržaj                                             |
| ----------- | --------------------------------------------------- |
| Metod       | `GET`                                               |
| URL         | `https://platform.acedata.cloud/api/v1/usage/apis/` |
| Autentikacija | `Authorization: Bearer ${PLATFORM_TOKEN}`         |
| OAuth opseg | `usage:read` (`platform:read` / `platform` može prošireno uključivati) |
| Paginacija  | `count` + `items`, podrazumevano 10 stavki po stranici |

## Opseg upita

| `perspective` | Značenje                    |
| ------------- | --------------------- |
| `both`        | Podrazumevana vrednost; vraća evidenciju koju trenutni nalog plaća ili je stvarno pozvao |
| `billing`     | Vraća samo evidenciju koju trenutni nalog plaća |
| `actor`       | Vraća samo evidenciju koju je trenutni nalog stvarno pozvao |

## Parametri upita

| Parametar         | Tip       | Obavezno | Podrazumevano | Opis                         |
| ----------------- | -------- | --- | ------------- | -------------------------- |
| `perspective`     | string   | Ne   | `both`        | `billing`, `actor` ili `both` |
| `user_id`         | UUID     | Ne   | —             | Samo administratori filtriraju po korisniku; podržava ponovljene parametre |
| `service_id`      | UUID     | Ne   | —             | Filtriranje po usluzi; podržava ponovljene parametre |
| `application_id`  | UUID     | Ne   | —             | Filtriranje po Application-u; podržava ponovljene parametre |
| `api_id`          | UUID     | Ne   | —             | Filtriranje po API-ju; podržava ponovljene parametre |
| `credential_id`   | UUID     | Ne   | —             | Filtriranje po API kredencijalu; podržava ponovljene parametre |
| `status_code`     | integer  | Ne   | —             | Filtriranje po HTTP statusnom kodu; podržava ponovljene vrednosti ili vrednosti razdvojene zarezima |
| `created_at_from` | datetime | Ne   | —             | Donja granica vremena kreiranja, ISO 8601 |
| `created_at_to`   | datetime | Ne   | —             | Gornja granica vremena kreiranja, ISO 8601 |
| `limit`           | integer  | Ne   | 10            | Broj stavki po stranici, najviše 100 |
| `offset`          | integer  | Ne   | 0             | Pomak paginacije |
| `ordering`        | string   | Ne   | `-created_at` | Opadajući redosled po vremenu kreiranja |

Kada je vreme zahteva ranije od poslednjih 60 dana, interfejs vraća grešku validacije polja `400`, uz poruku da se potpuni detalji poziva čuvaju samo 60 dana.

## Primeri zahteva

Upit poslednjih 100 zapisa:

```shell
curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/' \
  --data-urlencode 'perspective=both' \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=-created_at' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Filtriranje po vremenu, Application-u i statusu neuspeha:

```shell
export APPLICATION_ID='vaš Application ID'

curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'created_at_from=2026-09-01T00:00:00Z' \
  --data-urlencode 'created_at_to=2026-09-02T00:00:00Z' \
  --data-urlencode 'status_code=500' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Python primer paginacije:

```python
import os
import requests

url = "https://platform.acedata.cloud/api/v1/usage/apis/"
headers = {"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"}
params = {"perspective": "both", "limit": 100, "offset": 0}

response = requests.get(url, headers=headers, params=params, timeout=30)
response.raise_for_status()
data = response.json()

for usage in data["items"]:
    print(usage["created_at"], usage["status_code"], usage["deducted_amount"], usage["trace_id"])

if params["offset"] + len(data["items"]) < data["count"]:
    params["offset"] += len(data["items"])
```

## Ključna polja

| Polje                            | Opis                                |
| -------------------------------- | ----------------------------------- |
| `user_id`                        | Nalog koji snosi ovo terećenje                          |
| `actor_user_id`                  | Nalog koji je stvarno pokrenuo poziv; može se razlikovati od `user_id` kada se drugima odobri korišćenje akreditiva |
| `used_amount`                    | Potrošnja za ovaj poziv izračunata prema originalnim pravilima                       |
| `original_amount`                | Originalna potrošnja pre popusta aplikacije                          |
| `deducted_amount`                | Konačni stvarno oduzeti iznos                           |
| `remaining_amount`               | Preostali iznos za Application nakon završetka ovog terećenja           |
| `elapsed`                        | Trajanje poziva zabeleženo na serveru, u sekundama                     |
| `trace_id`                       | Identifikator za praćenje koji se koristi pri istrazi pojedinačnog zahteva                      |
| `metadata`                       | Javni metapodaci; lista ne vraća kompletan sadržaj zahteva ili odgovora               |
| `api` / `service` / `credential` | Sažetak povezanih objekata radi lakšeg prikaza; može biti prazan ako povezani objekat više ne postoji           |

Jedinicu iznosa određuje `service.unit` odgovarajuće Application i ne treba je podrazumevano smatrati američkim dolarima.

## Greške i ponovni pokušaji

| HTTP | `error`                   | Značenje             | Način postupanja                               |
| ---- | ------------------------- | -------------- | ---------------------------------- |
| 400  | Greška validacije polja                    | Opseg upita je raniji od perioda čuvanja od 60 dana | Prilagodite vreme početka tako da bude unutar poslednjih 60 dana                  |
| 401  | `not_authenticated`       | Token naloga nedostaje ili nije važeći      | Proverite Account Token, nemojte greškom koristiti poslovni Credential |
| 403  | `permission_denied`       | Zahtev uključuje zapise za koje nemate pravo pregleda    | Uklonite neovlašćene uslove filtriranja korisnika                       |
| 429  | `usage_query_in_progress` | Potpuno isti upit se još izvršava    | Sačekajte `Retry-After`, a zatim ponovite pokušaj uz postepeno povećanje intervala             |
| 503  | `usage_query_timeout`     | Upit je prekoračio bezbedno vremensko ograničenje servera    | Suzite vremenski opseg ili dodajte uslove filtriranja, pa pokušajte ponovo                   |

Za istu grupu parametara upita može postojati najviše jedan zahtev u toku. Za upite velikog opsega prednost dajte prozorima od jednog dana ili manjim, nemojte preklapati identične zahteve u fiksnim intervalima.
