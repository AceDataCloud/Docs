Paginirano vraća API krajnje tačke vidljive na trenutnom sajtu. Pogodno za pronalaženje API-ja prema poslovnoj putanji, servisu ili fazi objavljivanja; ako vam je potrebna samo potpuna definicija jednog API-ja, direktno pozovite [Detalje API-ja](https://platform.acedata.cloud/documents/platform-api-detail).

## Pregled interfejsa

| Stavka   | Sadržaj                                      |
| --- | --------------------------------------------- |
| Metod  | `GET`                                         |
| URL | `https://platform.acedata.cloud/api/v1/apis/` |
| Autentifikacija  | Javno, token naloga nije potreban                                     |
| Paginacija  | `count` + `items`                             |

## Parametri upita

| Parametar        | Tip      | Obavezno  | Opis                    |
| --------- | ------- | --- | --------------------- |
| `path`    | string  | Ne   | Precizno se podudara sa `path` ili `path2` |
| `service` | string  | Ne   | Alias servisa ili UUID       |
| `stage`   | string  | Ne   | Filtrira prema fazi objavljivanja; može se ponoviti za unos više vrednosti      |
| `limit`   | integer | Ne   | Broj stavki po stranici, maksimalno 100           |
| `offset`  | integer | Ne   | Pomak paginacije                 |

`id`, `service_id`, `tag` trenutno nisu parametri filtriranja liste; nakon prosleđivanja neće proizvesti odgovarajući efekat filtriranja.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/apis/' \
  --data-urlencode 'service=midjourney' \
  --data-urlencode 'stage=Production' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/apis/",
    params={"service": "midjourney", "limit": 20},
    timeout=30,
)
response.raise_for_status()
for api in response.json()["items"]:
    print(api["id"], api["method"], api["path"])
```

## Objašnjenje odgovora

Odgovor u produkciji koristi `{count, items}`. Svaka stavka liste trenutno sadrži polja API modela, kao i:

- `document_id`: ID povezanog dokumenta za programere, može biti prazan;
- `service_id` / `service`: ID glavnog servisa i sažetak, mogu biti prazni;
- `definition`: OpenAPI definicija, može biti velika;
- `method`, `path`, `path2`, `stage`, `cost`, `tags`, `metadata` itd.

Serializer liste trenutno sadrži `definition`; pri preuzimanju kompletnog direktorijuma treba koristiti paginaciju i postaviti vremensko ograničenje. Polja mogu biti dodata uz kompatibilnost unazad, a klijent treba da čita samo potrebna polja.
