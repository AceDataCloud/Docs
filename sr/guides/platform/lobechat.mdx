[LobeChat](https://lobehub.com/) je AI klijent otvorenog koda koji podržava dodatke, baze znanja i samostalno postavljanje, a može se koristiti u onlajn verziji ili postaviti putem Docker-a. Podržava prilagođene krajnje tačke kompatibilne sa OpenAI-jem, tako da se može povezati sa Ace Data Cloud-om. Ovaj članak predstavlja proces konfiguracije.

## Proces prijave

Da biste povezali Ace Data Cloud u LobeChat-u, prvo idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications), preuzmite svoj API Token i sačuvajte ga za kasnije.

![Preuzimanje Ace Data Cloud API Key-a](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobijate besplatni kredit, tako da možete besplatno isprobati model usluge Ace Data Cloud-a.

## Konfigurisanje Ace Data Cloud-a

Idite u LobeChat **Podešavanja aplikacije → Jezički modeli**, pronađite karticu **OpenAI** i omogućite je, zatim unesite:

| Polje       | Vrednost                              | Objašnjenje                         |
| -------- | ------------------------------ | -------------------------- |
| API Key  | vaš Ace Data Cloud Token        | Token kopiran sa konzole               |
| API proxy adresa | `https://api.acedata.cloud/v1` | **mora se završavati sa `/v1`**           |
| Režim zahteva klijenta  | uključeno                             | Direktno povezivanje iz pregledača, Key ne prolazi kroz LobeChat server |

![LobeChat OpenAI Provider interfejs za konfiguraciju](https://cdn.acedata.cloud/629ef9d3084a.png)

> Kada koristite Chat Completions interfejs, zadržite Responses API Specification isključenim.

LobeChat neće automatski dodati `/v1` na Base URL, a putanja zahteva je direktno `{API proxy adresa}/chat/completions`:

| API proxy adresa                              | Stvarni zahtev                                                   | Rezultat                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | Ispravno                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | Takođe se može koristiti                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (nema `/v1` ispod `/openai`) |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404 (nedostaje `/v1`)             |

LobeChat podrazumevano poziva `/v1/models` da automatski učita modele. Kada Ace Data Cloud vraća mnogo modela, interfejs može biti veoma dug, pa se preporučuje da ručno unesete allow list u „Lista modela → Prilagođena imena modela“, razdvojenu zarezima na engleskom. Ako je potrebno prilagođeno prikazano ime, možete koristiti `=`, u formatu `MODEL_ID=prikazano ime`.

## Izbor modela

Katalog modela će se kontinuirano ažurirati. Prednost dajte listi modela koju klijent automatski učitava; ako je potrebno ručno unositi, prvo pošaljite zahtev `GET https://api.acedata.cloud/v1/models` da biste dobili trenutne ID-jeve modela, a zatim birajte prema mogućnostima konteksta, slika i poziva alata koje klijent podržava.

## Provera povezivanja

Ako niste sigurni da li je problem u LobeChat-u ili mreži, možete prvo direktno proveriti krajnju tačku pomoću curl-a (zamenite `{token}` svojim Token-om):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Ako se vrati OpenAI-kompatibilni objekat `chat.completion`, to znači da su Token i krajnja tačka spremni; ako se vrati `HTTP 403 used_up`, to znači da je Token važeći, ali da nema dovoljno kredita — dopunite stanje na [konzoli](https://platform.acedata.cloud/console/applications).

## Napredno: Docker samostalno postavljanje

Ako želite postaviti privatnu verziju za korišćenje u timu, možete pokrenuti Docker jednom komandom (zamenite `{token}` svojim Token-om):

```bash
docker run -d \
  --name lobe-chat \
  -p 3210:3210 \
  -e OPENAI_API_KEY={token} \
  -e OPENAI_PROXY_URL=https://api.acedata.cloud/v1 \
  -e ACCESS_CODE=your-secret-password \
  -e OPENAI_MODEL_LIST="MODEL_ID" \
  lobehub/lobe-chat:latest
```

Otvorite `http://IP-adresa-vašeg-servera:3210`, unesite `ACCESS_CODE` i možete koristiti uslugu; članovi tima ne moraju zasebno unositi Key. Za potpuna objašnjenja promenljivih okruženja kao što su `OPENAI_API_KEY`, `OPENAI_PROXY_URL`, `OPENAI_MODEL_LIST` koje se koriste iznad, pogledajte [LobeChat dokumentaciju o promenljivama okruženja provajdera modela](https://lobehub.com/docs/self-hosting/environment-variables/model-provider). Ako koristite nginx reverzni proxy sa HTTPS-om, obavezno dodajte `proxy_buffering off;`, jer će se u suprotnom strimovani odgovori baferovati. Za više oblika postavljanja pogledajte [LobeChat uvod u samostalno postavljanje](https://lobehub.com/docs/self-hosting/start) i [Docker Compose postavljanje](https://lobehub.com/docs/self-hosting/platform/docker-compose).

## Česta pitanja

### Prikazuje se 404 Not Found

Obično je API proxy adresa uneta kao `.../openai/v1` ili nedostaje `/v1`. Promenite je u `https://api.acedata.cloud/v1`.

### Lista modela je prazna

Uključite prekidač „Režim zahteva klijenta“; ili ručno unesite allow list modela u „Prilagođena imena modela“.

### Prikazuje se 401 Unauthorized

Potvrdite da je u API Key nalepljen Ace Data Cloud Token (bez prefiksa `Bearer`, bez suvišnih razmaka), kao i da aplikacija kojoj pripada ima dovoljno kredita.
