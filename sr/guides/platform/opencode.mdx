OpenCode-ов Coding Plan модел Provider, IDE Extension и MCP су три независне способности. IDE Extension повезује локални OpenCode runtime и рециклира исту конфигурацију Provider-а; не представља изворну подршку хост едитора за Ace Data Cloud.

| Пут                            | Опис                                                      | Линк                                                                                    | Статус      |
| ----------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------- |
| Terminal / CLI / TUI Provider | Користи `opencode.json[c]` и Chat Completions                | [Provider конфигурација](https://platform.acedata.cloud/documents/opencode-terminal-integration) | Потврђена конфигурација |
| IDE Extension                 | VS Code, Cursor, Windsurf, VSCodium и други хостови повезују OpenCode runtime | [IDE конфигурација](https://platform.acedata.cloud/documents/opencode-ide-integration)           | Експериментално     |
| MCP                           | Позивање удаљених алата у OpenCode-у                                      | [MCP преглед](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | Независна способност    |

Након успешне конфигурације Provider-а, IDE Extension треба да користи исти Provider и модел. Потребно је посебно верификовати ћаскање у IDE-у, читање датотека, уређивање и позивање алата, не треба аутоматски пројектовати обичан захтев CLI-а на све способности IDE-а.

ID модела је према [реалном каталогу](https://platform.acedata.cloud/models).
