GitHub Copilot zvanična BYOK dokumentacija navodi VS Code kao podržani lokalni klijent i podržava OpenAI-kompatibilne provajdere. Verzija VS Code-a, korporativne politike i vidljivost modela utiču na konačni endpoint; prilikom prve integracije, molimo proverite stvarni zahtev u nastavku.

## Konfiguracione smernice

1. Potvrdite da je vaš GitHub Copilot nalog ili organizacija omogućila BYOK/Custom Models funkciju.
2. U upravljanju modelima Copilot-a u VS Code-u dodajte OpenAI-kompatibilnog provajdera.
3. Base URL unesite `https://api.acedata.cloud/v1`.
4. API Key unesite vaš Ace Data Cloud API Token.
5. Model unesite tačan ID modela koji je kompatibilan sa odabranim protokolom u direktorijumu modela.
6. U Copilot Chat-u pošaljite `Reply only OK`, a zatim ponovo testirajte zahtev sa kontekstom radnog prostora.

## Trenutne granice

- Copilot aplikacija, CLI, GitHub Desktop, Enterprise BYOK i konfiguracija VS Code-a imaju različite ugovore, ovaj vodič ne primenjuje korake drugih klijenata direktno na VS Code.
- Organizacione politike mogu zabraniti pojedincima da dodaju provajdere ili modele.
- Tab completion, Chat, Agent i pozadinski zadaci mogu koristiti različite putanje modela, što treba posebno proveriti.
