FreeAIr je open-source ekstenzija za Visual Studio 2022/2026, koja zvanično podržava povezivanje sa bilo kojim OpenAI-kompatibilnim API-jem. Ponašanje zahteva može se razlikovati između različitih verzija ekstenzije; prilikom prvog povezivanja, molimo vas da koristite fiksnu verziju i završite minimalnu verifikaciju u nastavku.

## Konfiguracija

1. Instalirajte FreeAIr iz Visual Studio Marketplace-a ili zvaničnog repozitorijuma.
2. Otvorite podešavanja FreeAIr-a i dodajte OpenAI-kompatibilnu vezu.
3. U Endpoint unesite `https://api.acedata.cloud/v1`.
4. U Token unesite vaš Ace Data Cloud API Token.
5. U Model unesite tačan ID modela koji podržava Chat Completions u direktorijumu modela.
6. Nakon čuvanja pošaljite `Reply only OK`, a zatim ponovo testirajte zahtev sa kontekstom projekta.

## Trenutne granice

- Ovaj vodič pokriva samo FreeAIr i ne predstavlja podršku za arbitrary Base URL u ugrađenom Copilot-u Visual Studio-a.
- Verzije ekstenzije mogu promeniti način spajanja endpoint-a; prilikom verifikacije treba proveriti konačni URL zahteva.
- Alatke i MCP mogućnosti unutar ekstenzije zahtevaju nezavisnu verifikaciju, ne mogu se zameniti uspešnim običnim razgovorom.
