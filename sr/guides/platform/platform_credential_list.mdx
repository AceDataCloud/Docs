---
title: "Preuzimanje liste API kredencijala AceDataCloud platforme"
description: "Platform API guide - Ace Data Cloud"
---

Stranično izlistava poslovne API kredencijale. Ovaj odgovor trenutno sadrži osetljiva polja Token ili Identity kredencijala i mora se obrađivati samo na serverskoj strani; zabranjeno je upisivanje u logove, analitičke platforme, trajnu memoriju frontenda ili javna spremišta.

## Priprema

Kreirajte [Account Token](https://platform.acedata.cloud/documents/platform-token) i putem `GET /api/v1/platform-tokens/me/` preuzmite UUID trenutnog naloga.

```shell
export PLATFORM_TOKEN='你的账户令牌'
export USER_ID='你的账户 UUID'
```

## Pregled interfejsa

| Stavka   | Sadržaj                                              |
| --- | ---------------------------------------------------- |
| Metoda  | `GET`                                                |
| URL | `https://platform.acedata.cloud/api/v1/credentials/` |
| Autentikacija  | Account Token, OAuth token zahteva `credentials:read`       |
| Straničenje  | `count` + `items`                                    |

Obični korisnici treba da proslede sopstveni `user_id` ili jedan autorizovani `application_id`; u suprotnom, pri nailasku na objekte za koje nemaju ovlašćenje tokom straničenja može biti vraćen `403`.

## Parametri upita

| Parametar                 | Tip      | Obavezno  | Opis                             |
| ------------------ | ------- | --- | ------------------------------ |
| `user_id`          | string  | U zavisnosti od scenarija | Vlasnik kredencijala; podržava ponovljene parametre                   |
| `application_id`   | UUID    | Ne   | Filtriranje po Application; podržava ponovljene parametre        |
| `host`             | string  | Ne   | Precizno filtriranje po host-u; podržava ponovljene parametre             |
| `name`             | string  | Ne   | Precizno filtriranje po nazivu; podržava ponovljene parametre                 |
| `granted`          | boolean | Ne   | `true` su kredencijali dodeljeni drugima, `false` su kredencijali za sopstvenu upotrebu |
| `limit` / `offset` | integer | Ne   | Straničenje                             |
| `ordering`         | string  | Ne   | `created_at` ili `-created_at`   |

`service_id`, `disabled` i `expired` trenutno nisu parametri za filtriranje.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/credentials/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## Objašnjenje odgovora

Odgovor verifikovan u produkciji je `{count, items}`. Svaka stavka sadrži `id`, `application_id`, `application`, `user_id`, `creator_id`, `name`, `type`, `limited_amount`, `used_amount`, `expired_at`, `allowed_api_ids`, `host`, `granted`, `granted_to_user_id`, `tags`, `metadata` i vremenska polja, a prema tipu vraća `token` ili `username/password`.

> Trenutni odgovor liste vraća pune osetljive vrednosti. Nemojte ih prikazivati u konzoli pregledača ili sistemima za prikupljanje podataka, niti se oslanjati na oporavak otvorenog teksta putem liste; klijent treba da bude kompatibilan sa budućim strategijama maskiranja podataka.
