[`github.com/AceDataCloud/SDK/go`](https://pkg.go.dev/github.com/AceDataCloud/SDK/go) је званични Go SDK за Ace Data Cloud, који обавија `chat completions / images / video / music / search` на `api.acedata.cloud` у методе у стилу `client.OpenAI().Chat().Completions().Create(...)`, са уграђеним SSE стримингом (на бази канала), аутоматским поновним покушајима и типизованим грешкама.

Стил је усаглашен са `context.Context` + функционалним опцијама, погодан је за сваку Go позадинску услугу или CLI.

Изворни код и документација:

- SDK репозиторј: [https://github.com/AceDataCloud/SDK](https://github.com/AceDataCloud/SDK)
- Go модул: [https://pkg.go.dev/github.com/AceDataCloud/SDK/go](https://pkg.go.dev/github.com/AceDataCloud/SDK/go)

## Инсталација

```bash
go get github.com/AceDataCloud/SDK/go
```

Излаз провере верзије чистог Go модула:

```text
$ go list -m github.com/AceDataCloud/SDK/go
github.com/AceDataCloud/SDK/go v0.0.0-20260505072132-4a3d921f9bb4
```

Објашњење резултата:

- Тренутно нема семвер ознака, `go get` преузима commit лажну верзију `v0.0.0-<timestamp>-<sha>`; ова верзија ће бити закључана у `go.sum`, чланови тима који преузимају исти код могу добити потпуно идентичне зависности.
- Go SDK тренутно има `chat.completions` (синхроно + стриминг) као главну стабилну стазу, мултимедијални ресурси (`images` / `video` / `audio`) и `TaskHandle` polling су у alpha фази. За сценарије који захтевају ове способности, молимо вас да прво изаберете [TypeScript SDK](https://platform.acedata.cloud/documents/sdk-typescript) или [Python SDK](https://platform.acedata.cloud/documents/sdk-python).

## Припрема API токена

Погледајте [SDK преглед - захтев за API токен](https://platform.acedata.cloud/documents/acedatacloud-sdk#申请-api-token) да бисте добили токен, а затим у shell-у `export`:

```bash
export ACEDATACLOUD_API_TOKEN={token}
```

Када конструишете клијента, експлицитно инјектирајте преко опције `WithAPIToken(...)`; Go SDK неће аутоматски читати променљиве окружења, потребно је да пословни код користи `os.Getenv`, тако да је у сценаријима са више налога или самопровера боље контролисано.

## Пример 1: chat.completions (нестриминг)

```go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    adc "github.com/AceDataCloud/SDK/go"
)

func main() {
    client, err := adc.NewClient(adc.WithAPIToken(os.Getenv("ACEDATACLOUD_API_TOKEN")))
    if err != nil {
        panic(err)
    }
    ctx, cancel := context.WithTimeout(context.Background(), 60*time.Second)
    defer cancel()

    t0 := time.Now()
    res, err := client.OpenAI().Chat().Completions().Create(ctx, adc.ChatCompletionRequest{
        Model:     "gpt-4o-mini",
        Messages:  []map[string]any{{"role": "user", "content": "Reply with exactly: ADC_GO_SDK_OK"}},
        MaxTokens: 20,
    })
    if err != nil {
        panic(err)
    }
    fmt.Println("elapsed_ms", time.Since(t0).Milliseconds())
    fmt.Println("id", res["id"])
    fmt.Println("model", res["model"])
    choices := res["choices"].([]any)
    msg := choices[0].(map[string]any)["message"].(map[string]any)
    fmt.Println("content", msg["content"])
    usage := res["usage"].(map[string]any)
    fmt.Printf("usage prompt=%v completion=%v total=%v\n",
        usage["prompt_tokens"], usage["completion_tokens"], usage["total_tokens"])
}
```

Резултат извршавања програма:

```text
elapsed_ms 6436
id chatcmpl-89DHExvFvBc4ciIPfolZYUOy7ivxv
model gpt-4o-mini
content ADC_GO_SDK_OK
usage prompt=16 completion=5 total=21
```

Објашњење резултата:

- `id` је OpenAI компатибилни ID одговора, може се пронаћи у конзоли [историја коришћења](https://platform.acedata.cloud/console/usages).
- `content ADC_GO_SDK_OK` је стварни излаз модела, што доказује да SDK није модификовао одговор.
- У 6.4 секунди, већина времена је потрошена на прво TLS руковање + генерисање модела, након поновне употребе инстанце клијента, латенција је слична TS / Python (око 2~3 секунде).
- Одговор је униформно `map[string]any`, потребно је самостално извршити типизацију; ово је тренутни дизајн Go SDK — не уводи генеричке структуре како би се избегла јака зависност од једне шеме одговора за више модела.

## Пример 2: chat.completions (SSE стриминг)

`CreateStream` враћа два канала: `&lt;-chan map[string]any` је постепено анализирани SSE chunk, `&lt;-chan error` ће имати читљиве елементе тек након завршетка стрима (нормално или у случају грешке).

```go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    adc "github.com/AceDataCloud/SDK/go"
)

func main() {
    client, err := adc.NewClient(adc.WithAPIToken(os.Getenv("ACEDATACLOUD_API_TOKEN")))
    if err != nil {
        panic(err)
    }
    ctx, cancel := context.WithTimeout(context.Background(), 60*time.Second)
    defer cancel()

    t0 := time.Now()
    chunks, errs := client.OpenAI().Chat().Completions().CreateStream(ctx, adc.ChatCompletionRequest{
        Model:     "gpt-4o-mini",
        Messages:  []map[string]any{{"role": "user", "content": "Count from 1 to 5 separated by spaces. Just the numbers."}},
        MaxTokens: 30,
    })

    first := int64(-1)
    cnt := 0
    collected := ""
    for chunk := range chunks {
        if first < 0 {
            first = time.Since(t0).Milliseconds()
        }
        cnt++
        if ch, ok := chunk["choices"].([]any); ok && len(ch) > 0 {
            if c0, ok := ch[0].(map[string]any); ok {
                if d, ok := c0["delta"].(map[string]any); ok {
                    if s, ok := d["content"].(string); ok {
                        collected += s
                    }
                }
            }
        }
    }
    if e, ok := <-errs; ok && e != nil {
        fmt.Println("stream_err", e)
    }
    fmt.Println("total_elapsed_ms", time.Since(t0).Milliseconds())
    fmt.Println("first_chunk_ms", first)
    fmt.Println("chunks", cnt)
    fmt.Println("collected", collected)
}
```

Резултат извршавања програма:

```text
total_elapsed_ms 1816
first_chunk_ms 1633
chunks 13
collected 1 2 3 4 5
```

Објашњење резултата:

- Прва фрејм 1633 ms, свих 13 chunk-ова је стигло за 1816 ms — последњих 12 фрејмова је захтевало само 183 ms.
- `range chunks` ће природно изаћи из петље када се стрим заврши; `errs` канал увек максимално враћа један елемент, уз `ok` проверу можете добити грешку.
- Предност овог канала је што можете директно користити `select` у комбинацији са `context.Context` за истекање времена / отказивање, без потребе за додатним обавијањем.

## Пример 3: типизовано обрађивање грешака
```go
package main

import (
    "context"
    "errors"
    "fmt"

    adc "github.com/AceDataCloud/SDK/go"
)

func main() {
    bad, _ := adc.NewClient(adc.WithAPIToken("definitely-not-a-real-token"))
    _, err := bad.OpenAI().Chat().Completions().Create(context.Background(), adc.ChatCompletionRequest{
        Model:    "gpt-4o-mini",
        Messages: []map[string]any{{"role": "user", "content": "hi"}},
        MaxTokens: 5,
    })
    if err != nil {
        var apiErr *adc.APIError
        if errors.As(err, &apiErr) {
            fmt.Println("status:", apiErr.StatusCode)
            fmt.Println("code:", apiErr.Code)
            fmt.Println("message:", apiErr.Message)
        } else {
            fmt.Println("other err:", err)
        }
    }
}
```

`adc.APIError` pokriva 401 / 403 / 404 / 422 / 429 / 5xx, poslovni kod koristi `errors.As` da dobije strukturirane podatke. HTTP status kod, server `code` i `message` ostaju nepromenjeni. Greške na mrežnom nivou (neuspeh DNS-a, odbijena konekcija itd.) koriste `context.DeadlineExceeded`, `net.OpError` i druge standardne Go greške, i neće biti progutane.

## Opcije konfiguracije (funkcionalne opcije)

```go
client, err := adc.NewClient(
    // Obavezno: API token; preporučuje se čitanje iz promenljivih okruženja
    adc.WithAPIToken(os.Getenv("ACEDATACLOUD_API_TOKEN")),

    // Osnovna adresa API platforme, podrazumevano https://api.acedata.cloud
    adc.WithBaseURL("https://api.acedata.cloud"),

    // Vreme isteka za pojedinačni zahtev, podrazumevano 5 minuta
    adc.WithTimeout(60*time.Second),

    // Broj automatskih ponovljenih pokušaja, podrazumevano 2
    adc.WithMaxRetries(2),

    // Prilagođeni zaglavlja zahteva
    adc.WithHeader("x-app", "my-service/1.0"),
)
```

`NewClient` vraća `(*Client, error)`: kada je token prazan **i** nije prosleđen `WithPaymentHandler` (X402), odmah će prijaviti grešku, što olakšava otkrivanje nedostajuće konfiguracije tokom pokretanja usluge.

## Napredno: Ponovno korišćenje Client-a

Go SDK interno koristi jedan `*http.Client` + `http.Transport`, sa ugrađenim bazenom konekcija i HTTP/2 ponovnim korišćenjem. **Preporučuje se da se tokom životnog ciklusa procesa kreira samo jedan `*adc.Client`** i da se deli između goroutine-a — sve metode su bezbedne za konkurentno korišćenje.

```go
// pkg/acelearn/client.go
var sharedClient *adc.Client

func init() {
    var err error
    sharedClient, err = adc.NewClient(adc.WithAPIToken(os.Getenv("ACEDATACLOUD_API_TOKEN")))
    if err != nil {
        log.Fatal(err)
    }
}

func Chat(ctx context.Context, model, prompt string) (string, error) {
    res, err := sharedClient.OpenAI().Chat().Completions().Create(ctx, adc.ChatCompletionRequest{
        Model:    model,
        Messages: []map[string]any{{"role": "user", "content": prompt}},
    })
    if err != nil {
        return "", err
    }
    return res["choices"].([]any)[0].(map[string]any)["message"].(map[string]any)["content"].(string), nil
}
```

## Ograničenja i planovi

Trenutno stabilno / preporučeno za proizvodnu upotrebu:

- ✅ `client.OpenAI().Chat().Completions().Create` sinhrono ne-streaming
- ✅ `client.OpenAI().Chat().Completions().CreateStream` SSE streaming
- ✅ `errors.As` + `APIError` obrada grešaka
- ✅ Automatsko ponavljanje + eksponencijalno odlaganje

Još uvek u alpha fazi:

- 🚧 `client.Images()` / `client.Video()` / `client.Audio()` — interfejs je u razvoju, preporučuje se direktno korišćenje HTTP-a
- 🚧 `TaskHandle` asinkrono praćenje — još nije izloženo na površini Go SDK-a
- 🚧 `WithPaymentHandler` (X402 plaćanje na lancu) — u planu, trenutno X402 podržava samo [TypeScript](https://platform.acedata.cloud/documents/x402-typescript-sdk) i [Python](https://platform.acedata.cloud/documents/x402-python-sdk)
