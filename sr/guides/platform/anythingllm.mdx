[AnythingLLM](https://anythingllm.com/) je klijent otvorenog koda pozicioniran kao „dokumenti → privatni ChatGPT“, čiji je ključni koncept **Workspace**——svaki Workspace je skup dokumenata, skup korisnika i skup Agent alata, nezavisno izolovan. Dizajniran je posebno za razgovor sa dokumentima i pruža desktop App i Docker u dva oblika. U **LLM Provider**-u ima ugrađenu stavku [OpenAI (Generic)](https://docs.anythingllm.com/setup/llm-configuration/cloud/openai-generic), u koju se može uneti prilagođeni Base URL, stoga se model za razgovor može direktno usmeriti na Ace Data Cloud. Ovaj članak predstavlja proces konfiguracije.

## Proces prijave

Da biste povezali Ace Data Cloud u AnythingLLM-u, najpre idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications), preuzmite svoj API Token i sačuvajte ga za kasniju upotrebu.

![Preuzimanje Ace Data Cloud API Key-a](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobijate besplatni kredit, pa možete besplatno isprobati uslugu modela Ace Data Cloud.

## Preuzimanje AnythingLLM-a

Za ličnu upotrebu možete preuzeti [desktop verziju](https://anythingllm.com/download), vektorska baza podataka (LanceDB) radi lokalno, pretraga dokumenata je potpuno van mreže, a internet je potreban samo pri pozivanju modela; za timske scenarije sa više korisnika koristite [Docker postavljanje](https://docs.anythingllm.com/installation-docker/overview).

## Konfiguracija modela za razgovor

Pokrenite AnythingLLM, idite na **Settings → LLM Preference**, izaberite Provider **OpenAI (Generic)** (ne birajte obični OpenAI, jer je on fiksno usmeren na `api.openai.com` i nema prilagođeni Base URL). Zvaničnu dokumentaciju pogledajte u [OpenAI (Generic) LLM Provider](https://docs.anythingllm.com/setup/llm-configuration/cloud/openai-generic).

| Polje                   | Vrednost                       | Objašnjenje                                       |
| -------------------- | ------------------------------ | ---------------------------------------- |
| Base URL             | `https://api.acedata.cloud/v1` | **mora se završavati sa `/v1`**                         |
| API Key              | vaš Ace Data Cloud Token        | Token kopiran sa konzole                             |
| Selected Model       | trenutni ID modela                        | prvo koristite listu automatski učitanu iz `/models`; ako nije vraćena, nakon upita prema gornjoj metodi ručno popunite |
| Model context window | popunite prema izabranom modelu                        | pročitajte gornju granicu konteksta iz trenutnog direktorijuma modela, nemojte prepisivati vrednosti drugih modela               |

![AnythingLLM Generic OpenAI interfejs za konfiguraciju](https://cdn.acedata.cloud/a155f5476de7.png)

> Mogućnosti modela i gornja granica konteksta određuju se prema trenutnom direktorijumu modela.

Obratite pažnju na pravila putanje Base URL-a:

| Base URL                              | Stvarni zahtev                                                   | Rezultat                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | Ispravno                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | Takođe može da se koristi                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (nema `/v1` ispod `/openai`) |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404 (nedostaje `/v1`)             |

## Konfiguracija Embedding modela

Suština AnythingLLM-a je RAG, za koji je potreban embedding model za vektorizaciju dokumenata. Njegovi **Embedding Preference** i LLM Preference su dva međusobno nezavisna skupa konfiguracija——pogledajte [pregled konfiguracije Embedder-a](https://docs.anythingllm.com/setup/embedder-configuration/overview). Ugrađeni **AnythingLLM Embedder (Built-in / Native)** direktno radi lokalno, spreman je za korišćenje odmah i bez konfiguracije, te je podrazumevani i preporučeni izbor:

Idite na **Settings → Embedding Preference**, dovoljno je da Provider ostane podrazumevani **AnythingLLM Embedder**, bez potrebe za unosom bilo kakvog ključa. On lokalno završava vektorizaciju dokumenata, a i originalni tekst i vektori čuvaju se u lokalnom LanceDB-u, bez slanja u oblak.

> Kandidati za Embedder u AnythingLLM-u (u oblaku: OpenAI / Azure OpenAI / Cohere; lokalno: Built-in, LM Studio, [LocalAI](https://docs.anythingllm.com/setup/embedder-configuration/local/localai), Ollama) povezuju se prema svojim fiksnim oblicima. Među njima, OpenAI embedding u oblaku je fiksno usmeren na `api.openai.com` i ne podržava prilagođeni Base URL; ako želite da koristite prilagođenu krajnju tačku, možete koristiti **Generic OpenAI** Embedder (takođe ima polje Base URL, koje može biti usmereno na Ace Data Cloud `text-embedding-3-large`) ili lokalni **LocalAI** Embedder. Model za razgovor u ovom članku koristi Ace Data Cloud, dok embedding koristi lokalni Embedder ugrađen u AnythingLLM, i ta dva ne utiču jedan na drugi.

## Izbor modela

Direktorijum modela će se kontinuirano ažurirati. Prvo koristite listu modela koju klijent automatski učitava; kada je potreban ručni unos, najpre pošaljite zahtev `GET https://api.acedata.cloud/v1/models` da biste dobili trenutni ID modela, a zatim birajte prema mogućnostima konteksta, slika i poziva alata koje klijent podržava.

## Provera povezivanja

Ako niste sigurni da li je problem u AnythingLLM-u ili mreži, možete najpre direktno proveriti krajnju tačku pomoću curl-a (zamenite `{token}` svojim Token-om):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Vraćanje OpenAI kompatibilnog objekta `chat.completion` znači da su i Token i krajnja tačka spremni; ako se vrati `HTTP 403 used_up`, to znači da je Token važeći, ali da nema dovoljno kredita, pa ga dopunite na [konzoli](https://platform.acedata.cloud/console/applications).

## Napredno: Workspace i razgovor sa dokumentima

Nakon kreiranja novog Workspace-a, otpremite PDF / Word / Markdown i druge dokumente, AnythingLLM će ih podeliti po pasusima, generisati vektore pomoću lokalnog Embedder-a i sačuvati ih u lokalnom LanceDB-u. Tokom razgovora najpre će pretražiti povezane segmente, zatim segmente zajedno sa vašim pitanjem predati modelu za razgovor (odnosno Ace Data Cloud-u) radi odgovora, i ispod odgovora označiti izvore citata. Na vrhu svakog Workspace-a možete prebacivati između režima **Query** (odgovara samo na osnovu dokumenata) i **Chat** (meša opšte znanje), a za ozbiljne scenarije preporučuje se režim Query kako bi se izbegle halucinacije. Pri Docker postavljanju možete koristiti promenljive okruženja kao što su `GENERIC_OPEN_AI_BASE_PATH`, `GENERIC_OPEN_AI_API_KEY`, `GENERIC_OPEN_AI_MODEL_PREF` za unapred postavljeno isto povezivanje modela za razgovor i uključiti režim za više korisnika.

## Česta pitanja

### Prikazuje se 404 / connection fail

Obično je Base URL upisan kao `.../openai/v1` ili nedostaje `/v1`. Promenite ga u `https://api.acedata.cloud/v1`.

### Nakon otpremanja dokumenta nije moguće razgovarati

Potvrdite da je u **Settings → Embedding Preference** izabran dostupan Embedder (podrazumevani AnythingLLM Embedder može raditi lokalno, bez dodatne konfiguracije), i ponovo otpremite dokument da biste generisali vektore.

### Prikazuje se 401 Unauthorized
Potvrdite da je u API Key nalepljen Token za Ace Data Cloud (bez prefiksa `Bearer`, bez dodatnih razmaka) i da aplikacija kojoj pripada ima dovoljno sredstava.

### Da li će lokalni dokumenti biti otpremljeni u oblak

Neće. Originalni tekst dokumenata čuva se lokalno u LanceDB-u, a modelu će biti poslati samo pronađeni relevantni isečci i vaše pitanje.
