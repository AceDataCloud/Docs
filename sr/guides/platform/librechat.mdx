[LibreChat](https://www.librechat.ai/) je visoko konfigurisani open-source AI klijent, koji koristi `librechat.yaml` za opisivanje provajdera, modela i pravila usmeravanja. Podržava prilagođene OpenAI kompatibilne krajnje tačke, tako da može da se poveže sa Ace Data Cloud-om. Ovaj članak opisuje proces konfiguracije.

## Proces prijave

Da biste se povezali sa Ace Data Cloud-om u LibreChat-u, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) i dobijte svoj API Token, koji čuvate za kasnije.

![Dobijanje Ace Data Cloud API ključa](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon prijave bićete automatski vraćeni na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu, koja vam omogućava da besplatno isprobate model usluge Ace Data Cloud.

## Postavljanje LibreChat-a

LibreChat se postavlja putem Docker Compose-a, prvo pripremite direktorijum i preuzmite zvaničnu konfiguraciju:

```bash
mkdir -p ~/librechat && cd ~/librechat
curl -O https://raw.githubusercontent.com/danny-avila/LibreChat/main/docker-compose.yml
curl -O https://raw.githubusercontent.com/danny-avila/LibreChat/main/.env.example
mv .env.example .env
```

U `.env` datoteci generišite `JWT_SECRET`, `JWT_REFRESH_SECRET`, `CREDS_KEY`, `CREDS_IV` i druge sigurnosne ključeve koristeći `openssl rand -hex 32`, i postavite `ALLOW_REGISTRATION` po potrebi.

## Konfiguracija Ace Data Cloud-a

Kreirajte `librechat.yaml`, postavite Ace Data Cloud kao prilagođenu OpenAI kompatibilnu krajnju tačku (potpuni opis polja možete naći u zvaničnoj [Custom Endpoints dokumentaciji](https://www.librechat.ai/docs/quick_start/custom_endpoints), zamenite `{token}` sa vašim Token-om):

```yaml
version: 1.0.5
cache: true

endpoints:
  custom:
    - name: "Ace Data Cloud"
      apiKey: "{token}"
      baseURL: "https://api.acedata.cloud/v1"
      models:
        default:
          - "MODEL_ID"
        fetch: true
      titleConvo: true
      titleModel: "MODEL_ID"
      modelDisplayLabel: "Ace Data Cloud"
```

U `docker-compose.yml` datoteci pod `api` servisom, povežite ovu datoteku u kontejner, a zatim pokrenite `docker compose up -d`:

```yaml
    volumes:
      - type: bind
        source: ./librechat.yaml
        target: /app/librechat.yaml
```

Obratite pažnju na pravila putanje `baseURL`:

| baseURL                               | Stvarni zahtev                                            | Rezultat                  |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`      | Ispravno                 |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`  | Takođe dostupno          |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (nema `/v1` pod `/openai`) |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`         | 404 (nedostaje `/v1`)    |

## Izbor modela

Katalog modela će se kontinuirano ažurirati. Prioritetno koristite listu modela koju klijent automatski učitava; kada je potrebno ručno popunjavanje, prvo zatražite `GET https://api.acedata.cloud/v1/models` da dobijete trenutni model ID, a zatim izaberite prema kontekstu, slikama i sposobnostima alata koje klijent podržava.

## Verifikacija integracije

Ako niste sigurni da li je problem u LibreChat-u ili mreži, možete prvo koristiti curl da direktno verifikujete krajnju tačku (zamenite `{token}` sa vašim Token-om):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Ako dobijete OpenAI kompatibilan `chat.completion` objekat, to znači da su Token i krajnja tačka spremni; ako dobijete `HTTP 403 used_up`, to znači da je Token važeći, ali nema dovoljno sredstava, pa ga možete dopuniti na [kontrolnoj tabli](https://platform.acedata.cloud/console/applications).

## Napredno: yaml konfiguracione tehnike

`librechat.yaml` podržava više grupa krajnjih tačaka, možete koristiti `apiKey: "user_provided"` da omogućite svakom korisniku da unese svoj ključ; `titleModel` određuje model koji generiše naslov razgovora; `dropParams` može da ukloni parametre koje ciljani API ne podržava. Više informacija možete naći u [detaljnom opisu librechat.yaml konfiguracije](https://www.librechat.ai/docs/configuration/librechat_yaml).

## Česta pitanja

### Nakon pokretanja ne vidim Ace Data Cloud krajnju tačku

Obično je to zbog toga što yaml nije povezan u kontejner ili je došlo do greške u uvlačenju. Proverite `docker-compose.yml` zapise i proverite uvlačenje yaml-a.

### Prikazuje 404

`baseURL` je napisan kao `.../openai/v1` ili nedostaje `/v1`. Promenite u `https://api.acedata.cloud/v1`.

### Spisak modela je prazan

`fetch: true`, ali `/v1/models` nije uspeo, promenite na `fetch: false` i ručno navedite `default`.

### Promene u yaml-u ne deluju

Potrebno je restartovati kontejner: `docker compose restart api`.
