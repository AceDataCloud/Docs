Preuzmite potpune informacije o pojedinačnom API krajnjoj tački putem API ID-ja — u poređenju sa [interfejsom za listu](https://platform.acedata.cloud/documents/platform-api-list), dodaju se polja `definition` (OpenAPI 3.0 Schema), `service` (detalji pripadajuće usluge) i `products` (povezani proizvodi).

Pogodno za scenarije kao što su automatsko generisanje SDK-a, davanje opisa alata LLM Agent-u i dinamičko renderovanje sajtova za dokumentaciju.

> ℹ️ Ovaj interfejs pripada **AceDataCloud API-ju za upravljanje platformom**, sa jedinstvenim prefiksom `https://platform.acedata.cloud/api/v1/`. Za potpuni indeks interfejsa pogledajte [Preuzimanje liste dokumenata AceDataCloud platforme](https://platform.acedata.cloud/documents/platform-document-list).

## Pregled interfejsa

| Stavka   | Sadržaj                                                    |
| --- | ----------------------------------------------------- |
| Metod  | `GET`                                                 |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}` |
| Autorizacija  | ❌ javno                                                  |

`/apis/{id}` i `/apis/{id}/` su trenutno oba dostupna; primeri dosledno koriste oblik bez završne kose crte.

## Objašnjenje autorizacije

Ovaj interfejs je **potpuno javan i ne zahteva token naloga niti stanje prijave**.

## Parametri putanje

| Parametar       | Tip   | Obavezno  | Opis                    |
| -------- | ---- | --- | --------------------- |
| `api_id` | UUID | ✅   | API ID (UUID format, pseudonimi nisu podržani) |

## Primeri zahteva

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/apis/afc7917f-d89f-4dc9-95c2-863936b02cad' \
  -H 'accept: application/json'
```

### Python

```python
import requests

api_id = "afc7917f-d89f-4dc9-95c2-863936b02cad"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/apis/{api_id}",
    headers={"accept": "application/json"},
    timeout=10,
)
api = resp.json()
print(f"API: {api['title']}")
print(f"Putanja: {api['path']}")
print(f"Pripadajuća usluga: {api['service']['title']} ({api['service']['alias']})")
print(f"Broj OpenAPI putanja: {len(api.get('definition', {}).get('paths', {}))}")
```

### Node.js

```javascript
const apiId = 'afc7917f-d89f-4dc9-95c2-863936b02cad'
const r = await fetch(`https://platform.acedata.cloud/api/v1/apis/${apiId}`)
const api = await r.json()
console.log(api.title, api.path, api.service.title)
```

## Objašnjenje polja odgovora

Interfejs za detalje, pored [polja interfejsa za listu](https://platform.acedata.cloud/documents/platform-api-list), dodatno sadrži:

| Polje           | Tip     | Opis                                                                                          |
| ------------ | ------ | ------------------------------------------------------------------------------------------- |
| `service`    | object | Osnovne informacije pripadajuće usluge: `id`, `title`, `type`, `alias`                                                       |
| `products`   | array  | Lista povezanih proizvoda (obično prazna, za korišćenje od strane operativnog tima)                                                                         |
| `definition` | object | **Potpuna definicija OpenAPI 3.0 specifikacije**, uključujući `paths`, `components`, `info` itd., koja se može direktno dati alatu `openapi-generator` za generisanje klijentskog koda |

## Obrada grešaka

| HTTP | code        | Značenje                 |
| ---- | ----------- | ------------------ |
| 400  | `invalid`   | `api_id` nije važeći UUID |
| 404  | `not_found` | API ne postoji ili je povučen        |

## Praktični saveti

- Polje **`definition` je veoma veliko**: OpenAPI Schema jednog API-ja može imati stotine redova JSON-a. Ako vam je potreban samo indeks usluga, a Schema nije potrebna, umesto toga treba koristiti [interfejs za listu](https://platform.acedata.cloud/documents/platform-api-list).
- **Uobičajena upotreba za generisanje SDK-a**:
  ```shell
  # Preuzmite OpenAPI datoteku
  curl -s 'https://platform.acedata.cloud/api/v1/apis/<api_id>' | jq '.definition' > openapi.json

  # Generišite Python klijent pomoću openapi-generator-cli
  openapi-generator-cli generate -i openapi.json -g python -o ./client
  ```
- **Praćenje promena API-ja**: Polje `updated_at` predstavlja vreme poslednje promene schema-e. Pretplata na ovo polje omogućava automatsko ponovno generisanje SDK-a kada se OpenAPI promeni.
