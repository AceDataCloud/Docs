Javno vraća uzorke zapisa poziva određenog API-ja u poslednjih 15 minuta, za brzo posmatranje nedavnog stanja. To nije interfejs za brojanje agregirano po statusnim kodovima, niti se može koristiti za lične račune, SLA ili potpunu statistiku korišćenja.

## Pregled interfejsa

| Stavka   | Sadržaj                                                           |
| --- | ------------------------------------------------------------ |
| Metod  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| Autentikacija  | Javno, nije potreban token naloga                                                    |
| Ograničenje  | Nakon spajanja nedavno kreiranih/završenih zapisa vraća se najviše 5.000 stavki                                    |

`api_id` preuzmite sa [liste API-ja](https://platform.acedata.cloud/documents/platform-api-list).

```shell
export API_ID='vaš API ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## Stvarna struktura odgovora

Odgovor je direktno niz, bez pagination envelope-a:

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| Polje            | Objašnjenje        |
| ------------- | --------- |
| `api_id`      | API ID    |
| `created_at`  | Vreme kreiranja zapisa    |
| `trace_id`    | Identifikator praćenja zahteva    |
| `status_code` | HTTP statusni kod  |
| `elapsed`     | Trajanje poziva, u sekundama |

Kada API ne postoji, trenutno takođe može biti vraćen prazan niz, jer ovaj action direktno pretražuje nedavni usage po ID-u i prethodno ne proverava API objekat. Za izračunavanje stope uspešnosti klijent mora samostalno grupisati vraćene uzorke; za proveru ličnih naplata koristite interfejs na nivou naloga.
