[Open WebUI](https://openwebui.com/) (ranije Ollama WebUI) je open-source AI klijent koji podržava više korisnika, bazu znanja, RAG i privatno postavljanje. Podržava prilagođene OpenAI-kompatibilne krajnje tačke, tako da može da se poveže sa Ace Data Cloud. Ovaj tekst predstavlja proces konfiguracije.

## Proces prijave

Da biste povezali Ace Data Cloud u Open WebUI, prvo idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications), preuzmite svoj API Token i sačuvajte ga za kasnije.

![Preuzimanje Ace Data Cloud API Key-a](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobijate besplatni kredit, tako da možete besplatno isprobati Ace Data Cloud model usluge.

## Postavljanje i konfiguracija Ace Data Cloud

Open WebUI se povezuje sa OpenAI-kompatibilnom krajnjom tačkom putem promenljivih okruženja, a može se postaviti jednom Docker komandom (zamenite `{token}` svojim Token-om):

```bash
docker run -d \
  --name open-webui \
  -p 3000:8080 \
  -e WEBUI_SECRET_KEY=$(openssl rand -base64 32) \
  -e OPENAI_API_BASE_URL=https://api.acedata.cloud/v1 \
  -e OPENAI_API_KEY={token} \
  -v open-webui:/app/backend/data \
  ghcr.io/open-webui/open-webui:main
```

| Promenljiva okruženja                              | Funkcija                                 |
| --------------------------------- | ---------------------------------- |
| `OPENAI_API_BASE_URL`             | Ace Data Cloud ulaz, **mora se završavati sa `/v1`** |
| `OPENAI_API_KEY`                  | Vaš Token                           |
| `WEBUI_SECRET_KEY`                | Ključ za šifrovanje sesije, automatski se generiše                  |
| `-v open-webui:/app/backend/data` | Trajno čuvanje razgovora / korisničkih podataka                       |

Otvorite `http://IP-vašeg-servera:3000`, prvi registrovani nalog automatski postaje administrator. Obratite pažnju na pravila putanje za Base URL:

| OPENAI_API_BASE_URL                   | Stvarni zahtev                                                   | Rezultat                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | Ispravno                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | Takođe radi                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (nema `/v1` ispod `/openai`) |

Nakon prijave idite na **Admin Panel → Settings → Connections** i kliknite na „Verify Connection“ za proveru; u **Settings → Models** možete filtrirati i Pin-ovati često korišćene modele.

> Pored korišćenja promenljivih okruženja, Open WebUI podržava i direktno dodavanje veze u interfejsu: idite na **Admin Settings → Connections**, kliknite na ➕ i unesite URL (`https://api.acedata.cloud/v1`) i API Key, a Open WebUI će automatski pozvati `/models` da preuzme listu modela. Za detalje pogledajte zvaničnu dokumentaciju [Starting With OpenAI-Compatible Servers](https://docs.openwebui.com/getting-started/quick-start/connect-a-provider/starting-with-openai-compatible).

![Interfejs za konfiguraciju Open WebUI Ace Data Cloud Connection](https://cdn.acedata.cloud/f366abfd935d.png)

> `MODEL_ID` se koristi samo za demonstraciju opcionog allow list-a; kada je prazan, prikazaće se svi modeli koje vraća `/models`.

## Izbor modela

Katalog modela će se kontinuirano ažurirati. Prioritetno koristite listu modela koju klijent automatski učitava; kada je potrebno ručno unositi, prvo zatražite `GET https://api.acedata.cloud/v1/models` da biste dobili trenutne ID-jeve modela, a zatim birajte prema kontekstu, slikama i mogućnostima pozivanja alata koje klijent podržava.

## Provera povezivanja

Ako niste sigurni da li je problem u Open WebUI ili mreži, prvo možete direktno proveriti krajnju tačku pomoću curl-a (zamenite `{token}` svojim Token-om):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Vraćanje OpenAI-kompatibilnog `chat.completion` objekta znači da su Token i krajnja tačka spremni; ako se vrati `HTTP 403 used_up`, to znači da je Token važeći, ali da nema dovoljno sredstava, pa možete dopuniti sredstva na [konzoli](https://platform.acedata.cloud/console/applications).

## Napredno: baza znanja i više korisnika

Open WebUI baza znanja (RAG) podrazumevano koristi ChromaDB za čuvanje vektora, a kao embedding model može se navesti `text-embedding-3-large` (preko Ace Data Cloud), originali dokumenata postoje samo na vašem serveru, a samo pogođeni segmenti se šalju modelu. U **Admin Panel → Users** možete upravljati korisničkim ulogama (Pending / User / Admin); preporučuje se da „Default User Role“ postavite na `pending`, tako da novi korisnici mogu da koriste sistem tek nakon odobrenja, kako biste izbegli da se bilo ko registruje i troši kredit. Ako koristite nginx reverzni proksi, dodajte `proxy_buffering off;` i `client_max_body_size 100M;`.

## Često postavljana pitanja

### Prikazuje se Connection error / 404

Obično je `OPENAI_API_BASE_URL` napisan kao `.../openai/v1` ili nedostaje `/v1`. Promenite ga na `https://api.acedata.cloud/v1`.

### Nije moguće razgovarati nakon otpremanja dokumenta

U RAG podešavanjima Admin Panel-a izaberite embedding model `text-embedding-3-large` (OpenAI provider).

### Podaci se gube nakon ponovnog pokretanja kontejnera

Prilikom pokretanja potrebno je montirati volumen podataka `-v open-webui:/app/backend/data`.
