Coze zvanična dokumentacija za prilagođene modele podržava OpenAI Responses API i pruža Base API URL, API ključ i polja modela. Različite verzije Coze zakupaca mogu imati različite načine obrade putanja, strimskog izlaza i poziva alata, pa prilikom prvog povezivanja proverite stavke u nastavku.

## Konfiguracija

1. Uđite u upravljanje modelima Coze i dodajte prilagođeni model.
2. Protokol odaberite OpenAI Responses API.
3. Base API URL unesite `https://api.acedata.cloud/v1`.
4. API ključ unesite svoj Ace Data Cloud API Token.
5. Model unesite tačan ID modela koji podržava Responses API u direktorijumu modela.
6. Sačuvajte i završite testiranje veze sa Coze.
7. U Bot/Agent pošaljite `Reply only OK`, a zatim ponovo testirajte poziv alata.

## Trenutne granice

- Različite Coze oblasti, verzije ili paketi mogu prikazivati različite obrasce.
- Base API URL treba koristiti kao osnovu, nemojte ponovo dodavati `/responses`; ako trenutni UI jasno zahteva potpuni API URL, oslonite se na uputstva obrasca.
- Chat Completions, Responses i Anthropic Messages su tri nezavisne rute i ne mogu se međusobno zameniti za verifikaciju.
