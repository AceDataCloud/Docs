---
title: "Preuzimanje detalja porudžbine sa AceDataCloud platforme"
description: "Platform API guide - Ace Data Cloud"

Pretražite porudžbinu putem ID-ja porudžbine. Ova krajnja tačka podržava dva režima čitanja: anonimni pristup vraća samo minimalna polja potrebna za stranicu plaćanja; vlasnik porudžbine sa Account Token-om dobija potpune detalje.

## Pregled interfejsa

| Stavka   | Sadržaj                                                        |
| --- | --------------------------------------------------------- |
| Metod  | `GET`                                                     |
| URL | `https://platform.acedata.cloud/api/v1/orders/{order_id}` |
| Autentifikacija  | Opciono; anonimno je minimalna projekcija, autentifikovani vlasnik je potpuna projekcija                                    |

`/orders/{id}` i `/orders/{id}/` su trenutno oba dostupna. ID porudžbine je deo linka za plaćanje i treba ga smatrati osetljivim neprozirnim identifikatorom; nemojte ga javno deliti.

## Anonimni upit

Stranica za plaćanje može direktno čitati kada se stanje prijave izgubi:

```shell
export ORDER_ID='vaš ID porudžbine'
curl "https://platform.acedata.cloud/api/v1/orders/${ORDER_ID}" \
  -H 'Accept: application/json'
```

Anonimni odgovor sadrži samo `id`, `description`, `price`, `state`, `pay_way`, `pay_url`, `expired_at`, `created_at`. Ne vraća nalog, Application, Package, interne identifikatore plaćanja ili metadata.

## Autentifikovani upit

```shell
export PLATFORM_TOKEN='vaš token naloga'
curl "https://platform.acedata.cloud/api/v1/orders/${ORDER_ID}" \
  -H 'Accept: application/json' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Vlasnik porudžbine će dobiti potpune Order detalje, uključujući `application` / `applications`, `package` / `packages`, `bank_details`, `invoice_automation` i polja modela. Ako je korisnik autentifikovan, ali nije vlasnik porudžbine, vraća se `403`; osim za super administratore.

## Ključna polja

| Polje            | Opis                                                          |
| ------------- | ----------------------------------------------------------- |
| `state`       | `Pending`, `Paid`, `Finished`, `Expired`, `Failed` ili `Refunded` |
| `pay_way`     | Trenutni način plaćanja porudžbine; naziv polja nije `payment_method`                             |
| `pay_url`     | Adresa hostovane stranice za plaćanje ili QR koda, može biti prazna                                           |
| `price`       | Konačni iznos za plaćanje porudžbine; trenutni model porudžbine ne pruža polje `final_price`                         |
| `amount`      | Količina kvote paketa; vidljiva samo u potpunom autentifikovanom odgovoru                                            |
| `finished_at` | Vreme završetka porudžbine; naziv polja nije `paid_at`                                      |

Potpuni odgovor može dodati polja u zavisnosti od načina plaćanja; klijent treba da ih čita po potrebi i uvek izbegava evidentiranje osetljivih metadata iz potpunog odgovora.

## Obrada grešaka

- `404`: ID porudžbine ne postoji.
- `403`: Prijavljeni ste, ali niste vlasnik porudžbine.
- Anonimni zahtev neće vratiti `401`; dobija samo minimalnu javnu projekciju.
