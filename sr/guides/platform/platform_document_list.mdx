Stranično vraća razvojnu dokumentaciju vidljivu na trenutnom sajtu, koja se može koristiti za pretragu, indeksiranje ili samostalnu izgradnju navigacije na klijentu. Lista trenutno sadrži `content` svake dokumentacije i informacije o ugnežđenom nadređenom elementu, odgovor može biti veliki.

## Pregled interfejsa

| Stavka   | Sadržaj                                            |
| --- | -------------------------------------------------- |
| Metoda  | `GET`                                              |
| URL | `https://platform.acedata.cloud/api/v1/documents/` |
| Autentikacija  | Javno; neadministratori ne mogu videti private dokumente                              |
| Paginacija  | `count` + `items`                                  |

## Parametri upita

| Parametar         | Tip      | Obavezno  | Podrazumevano     | Opis                           |
| ---------- | ------- | --- | ------ | ---------------------------- |
| `id`       | UUID    | Ne   | —      | Filtriranje po ID-u dokumenta; podržava ponovljene parametre             |
| `private`  | boolean | Ne   | —      | Filtriranje po private statusu; neadministratori i dalje ne mogu videti privatne dokumente |
| `type`     | string  | Ne   | —      | Precizno filtriranje po stvarnoj `type` vrednosti Document-a  |
| `tag`      | string  | Ne   | —      | Filtriranje po oznaci                        |
| `limit`    | integer | Ne   | 10     | Broj stavki po stranici, najviše 100                  |
| `offset`   | integer | Ne   | 0      | Pomak paginacije                        |
| `ordering` | string  | Ne   | `rank` | Podržava samo sortiranje po `rank`; prefiks `-` označava opadajući redosled   |

Trenutni interfejs liste ne podržava filtriranje po `alias` ili `parent_id`. Kada je alias poznat, direktno pozovite [detalje dokumenta](https://platform.acedata.cloud/documents/platform-document-detail); pri izgradnji navigacije u obliku stabla, nakon jednokratnog straničnog preuzimanja grupišite na klijentu koristeći `parent.id` svake stavke.

## Primer zahteva

```shell
curl --get 'https://platform.acedata.cloud/api/v1/documents/' \
  --data-urlencode 'tag=development' \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/documents/",
    params={"tag": "development", "limit": 100, "offset": 0},
    timeout=30,
)
response.raise_for_status()
data = response.json()
for document in data["items"]:
    parent = document.get("parent") or {}
    print(document["alias"], parent.get("alias"))
```

## Struktura odgovora

```json
{
  "count": 1,
  "items": [
    {
      "id": "00000000-0000-4000-8000-000000000001",
      "alias": "platform-token",
      "name": "Document of Platform Token",
      "title": "Upravljanje tokenom naloga AceDataCloud platforme (Account Token)",
      "content": "# Upravljanje tokenom naloga AceDataCloud platforme……",
      "type": "Text",
      "private": false,
      "primary_only": false,
      "rank": 2400,
      "tags": [
        "development"
      ],
      "parent": {
        "id": "00000000-0000-4000-8000-000000000002",
        "alias": "platform",
        "title": "AceDataCloud platforma"
      },
      "sibling": null,
      "api_id": null,
      "proxy_id": null,
      "api_method": null,
      "metadata": null,
      "created_at": "2026-01-01T00:00:00Z",
      "updated_at": "2026-01-01T00:00:00Z"
    }
  ]
}
```

Lista koristi `DocumentIndexSerializer` i trenutno vraća polja modela i ugnežđene odnose; povezana API dokumentacija može takođe sadržati `api_method`. Polja mogu biti dodata na način kompatibilan sa prethodnim verzijama, klijent treba da ih čita prema potrebi. Kada su potrebni `children`, analizirani jezik sadržaja i heš sadržaja, koristite interfejs detalja.

Za javne zapise povezane sa izvornim dokumentima, `content_source` pruža identifikator izvornog dokumenta, heš izvornog sadržaja, zahtevani jezik, vreme ažuriranja prevoda i status `ready`, `stale`, `missing`, `missing_source` ili `ambiguous`; za druge zapise ovo polje je `null`. `content_hash` kada je status `ready` odgovara prevodu na tom jeziku. Telo se i dalje prikazuje prema postojećim pravilima, uključujući jezički povratak kada prevod nedostaje; klijenti kojima je potrebna sinhronizacija dokumentacije treba istovremeno da provere status i heš, i ne mogu proceniti da je ažurirana samo na osnovu toga što telo nije prazno.

## Preporuke za korišćenje

- Odgovor sadrži telo, pri grupnoj sinhronizaciji koristite paginaciju i postavite razuman vremenski limit, nemojte paralelno preuzimati istu stranicu.
- alias je stabilni identifikator URL-a javne stranice; kada je alias poznat, direktno zahtevajte `/api/v1/documents/{alias}`.
- Trenutni interfejs ne može filtrirati po nadređenom elementu na serverskoj strani; pri izgradnji navigacije grupišite na klijentu po `parent.id`.
