Verovatno ste i sami naišli na ovu situaciju: koristite Claude Code, Cursor ili Codex, kodirate bez problema, a odjednom vam zatreba jedna ilustracija, deo pozadinske muzike, kratak video ili želite da usput proveri najnovije informacije. Tada otkrijete — sam agent to ne ume. Morate sami da pronađete API, pročitate dokumentaciju, podesite ključ, napišete kod za pozivanje, obradite asinhrono anketiranje, i dok sve to završite, inspiracija se već ohladila.

[AceKit](https://github.com/AceDataCloud/AceKit) služi da vam uštedi ceo taj niz komplikacija. Jednom komandom, on u vašeg agenta za kodiranje ugrađuje sve mogućnosti sa AceData Cloud-a, poput generisanja slika, generisanja videa, generisanja muzike, veb pretrage i LLM razgovora. Nakon instalacije samo govorite običnim jezikom, a agent će sam učitati odgovarajuću veštinu, sam izvršiti autentifikaciju, sam obaviti anketiranje i završiti posao.

## Shvatite za 30 sekundi šta radi

Pre instalacije naspram posle instalacije:

| Ono što kažete               | Pre instalacije                   | Posle instalacije (agent radi sam)                      |
| ------------------ | --------------------- | ----------------------------------- |
| "Dodaj naslovnu sliku ovom README-u" | agent to ne ume, traži da sami pronađete API za generisanje slika | Poziva NanoBanana / Flux / Midjourney za generisanje slike |
| "Pretvori ovu skriptu u video od 30 sekundi"  | ne ume                    | Poziva Sora / Veo / Kling / Seedance za generisanje videa  |
| "Dodaj deo pozadinske muzike ovom demou"  | ne ume                    | Poziva Suno za generisanje muzike                           |
| "Pretraži najnovije o X-u i zatim sažmi"     | nema pristup internetu                  | Poziva Google SERP za rezultate u realnom vremenu                 |
| "Skrati ovaj dugački link"         | ne ume                    | Poziva servis za kratke linkove i vraća surl.id link                  |

Jednom rečenicom: **vaš agent za kodiranje od „ume samo da piše kod“ postaje „ume i da generiše slike, video, muziku i pretražuje internet“.**

## Početak u tri koraka

Ceo proces se može završiti za nekoliko minuta, potreban je Node.js 18+.

**Prvi korak · Uzmite API Token.** U [kontrolnoj tabli](https://platform.acedata.cloud/console/applications) kopirajte Token — sve mogućnosti koriste taj isti token, pri prvoj prijavi dobijate besplatni kredit i možete prvo besplatno isprobati.

![Kopiranje API Token-a u kontrolnoj tabli](https://cdn.acedata.cloud/dvc3cg.jpg)

**Drugi korak · Instalirajte.** Jedna komanda:

```bash
npx acekit
```

Automatski će otkriti agente za kodiranje na računaru i instalirati kompletan skup veština. Stvarno izvršavanje izgleda ovako (na ovom računaru je instaliran samo Claude Code):

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> Kada Token nije podešen, pri prvom pokretanju će interaktivno zatražiti da ga nalepite; možete i unapred izvršiti `export ACEDATACLOUD_API_TOKEN=vaštoken` da biste instalaciju obavili potpuno bez nadzora. Broj veština će se menjati kako se mogućnosti platforme povećavaju, a aktuelna lista je ona koju prikazuje `npx acekit list`.

**Treći korak · Govorite običnim jezikom.** Ponovo učitajte agenta, a zatim mu direktno zadajte instrukciju, na primer:

```text
Koristi short-url veštinu da skratiš https://platform.acedata.cloud/services
```

Agent će sam učitati veštinu, sam pokrenuti poziv i dati vam stvaran rezultat na koji se može kliknuti.

## Stvarno pokretanje jednom (sa izlazom)

Sledeća četiri primera su svi **stvarni pozivi sa rezultatima vraćenim odmah**, a ne ilustracije. `$KEY` u komandama je vaš API Token.

**① Skraćivanje URL-a (sinhrono, odgovor za nekoliko sekundi)**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

Vraća `https://surl.id/r/1uKp2kilXQ` — otvaranjem će se putem 302 preusmeravanja vratiti na originalnu stranicu services.

**② Pretraga interneta (sinhrono)**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

Dobijaju se Google rezultati u realnom vremenu (izvod):

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ LLM razgovor (sinhrono, jedan interfejs povezuje 50+ modela)**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP je protokol za objedinjeno upravljanje i razmenu informacija o kontekstu modela.
（39 tokens，本次约 0.00007 credit）
```

**④ Generisanje slika (asinhrono, oko 20 sekundi, agent automatski vrši anketiranje dok se slika ne generiše)**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

Nakon otprilike 22 sekunde vraća stvarnu sliku (HTTP 200 · image/png · 317 KB · ovog puta oko 0.13 credit):

![Slika koju je AceKit stvarno generisao](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

Ove interfejse zapravo ne morate pamtiti — nakon instaliranja veština, agent će prema odgovarajućim `SKILL.md` fajlovima sam sastaviti ispravan zahtev, obraditi autentifikaciju i anketiranje. Gore je samo prikazano „šta radi u pozadini“.

## Šta tačno instalira

AceKit je „ulazna vrata“ za ceo AceData skup razvojnih alata, a trenutno jedna instalacija instalira **skup alata veština (Skills)**:

- **Skup Agent veština**: svaka veština je unapred napisan operativni priručnik `SKILL.md` — autentifikacija, asinhrono anketiranje, ponovno pokušavanje nakon greške i način popunjavanja parametara su jasno opisani, a agent samo treba da ih prati. Pokrenite `npx acekit list` da vidite aktuelnu listu (u vreme pisanja ovog teksta bilo ih je 19 i njihov broj se stalno povećava):
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **Jedinstveni Token**: jedan `ACEDATACLOUD_API_TOKEN` otključava sve mogućnosti, naplata prema stvarnoj potrošnji.

Klasifikovano prema mogućnostima (merodavan je `npx acekit list`):

| Tip         | Pružaoci                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ Generisanje slika      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 Generisanje videa      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 Generisanje muzike / zvuka | Suno · Producer · Fish Audio（TTS）                    |
| 💬 LLM razgovor   | Jedinstveni interfejs za 50+ modela（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 Pretraga       | Google SERP（veb · slike · vesti · mape · video）                  |
| 🔗 Alati       | Kratki linkovi · obrada lica                                            |

> AceData takođe pruža zasebne **MCP servere** za iste ove mogućnosti（Suno、Midjourney、Sora、SERP… objavljeni na PyPI / VS Code / Smithery / Docker）、**CLI komandne linije** i **Python / TypeScript SDK**, koji se po potrebi mogu koristiti zasebno。AceKit v0.2 planira da podrži instalaciju pojedinačnih mogućnosti putem `acekit add <name>`, kao i automatsko upisivanje MCP konfiguracije svakog agenta。

## Koje Agente podržava

| Agent                        | Lokacija instalacije veština                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode itd. | `~/.agents/skills`（usmerite svog agenta ovde） |

Tokom instalacije AceKit automatski detektuje agente koji su već instalirani na mašini i instalira samo u one koji su detektovani。

## Uskršnje jaje: pokrenite sam Claude Code istim Tokenom

AceData interfejs je istovremeno kompatibilan sa Anthropic formatom `/v1/messages`, tako da vam **nije potrebna zvanična Anthropic pretplata**, već možete pokrenuti Claude Code istim AceData Tokenom。U korenskom direktorijumu projekta napravite `.claude/settings.local.json`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Samo ponovo pokrenite Claude Code——on koristi čitavu Claude seriju modela, a preko AceKit-a dobija i „ruke“ za generisanje slika, videa i muzike。Za više detalja pogledajte [vodič za Claude Code integraciju](https://platform.acedata.cloud/documents/claude-code-integration)。
