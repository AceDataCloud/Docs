description: "Platform API guide - Ace Data Cloud"
---

Hermes Agent се интегрише у Ace Data Cloud преко OpenAI Chat Completions протокола. Изаберите један од начина конфигурације:

| Начин конфигурације         | Упутство                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| `hermes model` интерактивни водич | [Водич за конфигурацију](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| `config.yaml` ручна конфигурација  | [Ручна конфигурација](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| Платформска приватна инсталација              | [Управљана инсталација](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

За локалну интеграцију заједнички параметри:

- Base URL: `https://api.acedata.cloud/v1`
- Transport: `chat_completions`
- Provider: `custom:acedatacloud`
- API Key: добијте из [листе апликација](https://platform.acedata.cloud/console/applications)

Два локална начина на крају се уписују у `~/.hermes/config.yaml`, не конфигуришите поново.

Вратите се на [Coding Plan конфигурациони центар](https://platform.acedata.cloud/documents/coding-plan-integration).
