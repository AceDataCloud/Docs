Inferpal je ekstenzija za Visual Studio 2022/2026, koja zvanično podržava povezivanje sa OpenAI-kompatibilnim uslugama. Verzija ekstenzije može uticati na uređivanje, pozivanje alata i praćenje korišćenja; prilikom prvog povezivanja, molimo vas da fiksirate verziju i završite minimalnu verifikaciju u nastavku.

## Konfiguracija

1. Instalirajte Inferpal iz Visual Studio Marketplace-a ili zvaničnog repozitorijuma.
2. Otvorite Inferpal **Settings → Connection**.
3. Izaberite Provider OpenAI-kompatibilan.
4. U Base URL unesite `https://api.acedata.cloud/v1`.
5. U API Key unesite vaš Ace Data Cloud API Token.
6. U Model unesite tačan model ID koji podržava Chat Completions u direktorijumu modela.
7. Nakon što sačuvate, pošaljite `Reply only OK`, a zatim ponovo izvršite zahtev koji uključuje kontekst koda.

## Trenutne granice

- Ovaj vodič pokriva samo Inferpal i ne predstavlja podršku za iste oblasti u ugrađenom Copilotu Visual Studija ili drugim ekstenzijama.
- Različite verzije mogu automatski dodavati putanju na Base URL; ako zahtev ne uspe, prvo proverite da li konačni zahtev pada na Chat Completions endpoint.
- Ne garantujemo da su svi načini uređivanja, dopunjavanja ili pozivanja alata dostupni pre završetka fiksne verzije E2E.
