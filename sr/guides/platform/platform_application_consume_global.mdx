---
title: "Podesite deljenje globalnog stanja AceDataCloud Application-a"
description: "Platform API guide - Ace Data Cloud"
---

Podesite `allow_consume_global`. Nakon omogućavanja, Application-i po potrošnji koji ispunjavaju uslove mogu nastaviti da koriste globalno stanje naloga kada njihovo sopstveno stanje nije dovoljno.

## Pripremni radovi

- Kreirajte i bezbedno sačuvajte [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Sa [liste zahteva za uslugu](https://platform.acedata.cloud/documents/platform-application-list) preuzmite `application_id` koji posedujete.

```shell
export PLATFORM_TOKEN='tvoj token naloga'
export APPLICATION_ID='tvoj Application ID'
```

## Pregled interfejsa

| Stavka    | Sadržaj                                                                                           |
| ---- | -------------------------------------------------------------------------------------------------- |
| Metod   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Autentikacija   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

U slučaju uspeha vraća se ažurirani Application objekat. Oslonite se na `allow_consume_global` u odgovoru, umesto da pretpostavite da je vrednost zahteva sigurno sačuvana.

> Application tipa `Period` ne dozvoljava trošenje globalnog stanja. Čak i ako se zatraži `true`, server će ovo polje zadržati kao `false`.

## Obrada grešaka

- `401`: Account Token je nevažeći ili nedostaje.
- `403`: Trenutni nalog nije vlasnik ovog Application-a.
- `404`: Application ID ne postoji.

Ulaz za dopunu globalnog stanja i dostupni paketi zasnivaju se na platformskom kontrolnom panelu i stvarnim paketima vraćenim putem [kreiranja porudžbine](https://platform.acedata.cloud/documents/platform-order-create); nemojte pretpostavljati da postoji paket tipa `Wallet`.

## Aplikacije sa odobrenim prekoračenjem

Kada je polje samo za čitanje `allow_overdraft=true` aplikacije po potrošnji, ova aplikacija može nastaviti da naplaćuje iz svog sopstvenog stanja, čak i ako stanje postane negativno, i neće se prebaciti na globalni nalog zbog nedovoljnog stanja. Aplikacije bez uključenog prekoračenja i dalje prate `allow_consume_global`; nakon prebacivanja, da li je prekoračenje dozvoljeno zasniva se na podešavanju stvarnog globalnog Application-a sa kojeg se vrši naplata.
