---
title: "Podešavanje deljenja globalnog stanja AceDataCloud Application-a"
description: "Platform API guide - Ace Data Cloud"
---

Podesite `allow_consume_global`. Nakon omogućavanja, Application-i po potrošnji koji ispunjavaju uslove mogu nastaviti da koriste globalno stanje naloga kada njihovo sopstveno stanje nije dovoljno.

## Priprema

- Kreirajte i bezbedno sačuvajte [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Preuzmite `application_id` Application-a koji posedujete sa [liste zahteva za uslugu](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='你的账户令牌'
export APPLICATION_ID='你的 Application ID'
```

## Pregled interfejsa

| Stavka    | Sadržaj                                                                                            |
| ---- | -------------------------------------------------------------------------------------------------- |
| Metod   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Autentifikacija   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

Uspešno vraća ažurirani Application objekat. Oslonite se na `allow_consume_global` u odgovoru, umesto da pretpostavite da je vrednost zahteva sigurno sačuvana.

> Application-i tipa `Period` ne smeju da troše globalno stanje. Čak i ako zatražite `true`, server će ovo polje zadržati kao `false`.

## Obrada grešaka

- `401`: Account Token je nevažeći ili nedostaje.
- `403`: Trenutni nalog nije vlasnik ovog Application-a.
- `404`: Application ID ne postoji.

Ulaz za dopunu globalnog stanja i dostupni paketi podležu platformskom kontrolnom panelu i stvarnim paketima vraćenim pri [kreiranju porudžbine](https://platform.acedata.cloud/documents/platform-order-create); nemojte pretpostavljati da postoji paket tipa `Wallet`.
