Čita javne funkcionalne prekidače i određivanje države/regiona u kontekstu trenutnog zahteva. Pogodno je za odlučivanje pri pokretanju frontenda da li će funkcije biti prikazane; nije namenjeno za naziv brenda sajta, kontakt informacije ili katalog obaveštenja.

## Pregled interfejsa

| Stavka   | Sadržaj                                              |
| --- | ----------------------------------------------- |
| Metod  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Autentifikacija  | Javna; kada se prenosi stanje prijave, neki funkcionalni prekidači mogu biti izračunati po korisniku                          |

## Parametri upita i zaglavlja zahteva

| Naziv                    | Lokacija     | Opis                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | Izraz za prepisivanje funkcionalnih prekidača; važi samo za prekidače za koje je dozvoljeno prepisivanje od strane klijenta ili za super administratore |
| `X-Feature-Overrides` | header | Izvor prepisivanja isti kao `features`           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## Stvarna struktura odgovora

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| Polje         | Tip            | Opis                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Funkcionalni prekidači vidljivi trenutnom zahtevu; ključevi se menjaju u skladu sa konfiguracijom platforme, klijent treba da ih čita po potrebi i postavi bezbedne podrazumevane vrednosti za nedostajuće ključeve |
| `region`   | string / null | Kod države ili regiona otkriven na osnovu IP adrese zahteva, malim slovima; kada nije moguće prepoznati, vrednost je `null`        |

Ne čitajte naziv sajta, CDN, valutu, jezik, kontakt informacije korisničke podrške ili obaveštenja iz ovog interfejsa; ova polja ne pripadaju trenutnom ugovoru odgovora.

## Preporuke za korišćenje

- Funkcionalni prekidači se izračunavaju prema korisniku, otisku i kontekstu sajta, nemojte dugoročno deliti keš između korisnika.
- Izbor birača regiona čuva se samo na frontendu; pri prikazu prednost ima već izabrani region, u suprotnom se koristi `region` iz ovog interfejsa. Ovaj interfejs ne prihvata parametre za prepisivanje regiona.
- Neprepoznati query parametri će biti ignorisani; koristite samo parametre navedene na ovoj stranici.
