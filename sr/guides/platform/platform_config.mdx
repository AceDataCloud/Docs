Čita javne funkcionalne prekidače i procenu zemlje/regiona u kontekstu trenutnog zahteva. Pogodno je za odlučivanje prilikom pokretanja frontenda da li će se funkcija prikazati; ovo nisu brend sajta, kontakt informacije ili direktorijum obaveštenja.

## Pregled interfejsa

| Stavka   | Sadržaj                                              |
| --- | ----------------------------------------------- |
| Metod  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Autentifikacija  | Javna; kada se prenosi stanje prijave, neki funkcionalni prekidači mogu biti izračunati prema korisniku                          |

## Parametri upita i zaglavlja zahteva

| Naziv                    | Lokacija     | Opis                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | Dvoslovni ASCII kod zemlje; koristi se za nadjačavanje zemlje za prikaz u odgovoru, bez promene bezbednosne procene na strani servera |
| `features`            | query  | Izraz za nadjačavanje funkcionalnih prekidača; važi samo za prekidače kojima je dozvoljeno nadjačavanje od strane klijenta ili za super administratore        |
| `X-Feature-Overrides` | header | Izvor nadjačavanja isti kao `features`                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## Stvarna struktura odgovora

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| Polje         | Tip            | Opis                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Funkcionalni prekidači vidljivi za trenutni zahtev; ključevi se menjaju u skladu sa konfiguracijom platforme, klijent treba da ih čita po potrebi i postavi bezbedne podrazumevane vrednosti za nedostajuće ključeve |
| `country`  | string / null | Kod zemlje malim slovima; kada se ne može prepoznati, može biti `null`                     |

Nemojte čitati naziv sajta, CDN, valutu, jezik, kontakt informacije korisničke podrške ili obaveštenja iz ovog interfejsa; ova polja ne pripadaju trenutnom ugovoru odgovora.

## Preporuke za korišćenje

- Funkcionalni prekidači se izračunavaju prema korisniku, otisku i kontekstu sajta, nemojte dugoročno deliti keš između korisnika.
- `country` koji klijent prosleđuje utiče samo na povratnu vrednost i neće zaobići regionalne ili bezbednosne politike na strani servera.
- Neprepoznati query parametri će biti ignorisani; koristite samo parametre navedene na ovoj stranici.
