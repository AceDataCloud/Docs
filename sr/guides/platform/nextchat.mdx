[NextChat](https://github.com/ChatGPTNextWeb/NextChat) (ranije ChatGPT-Next-Web) je open-source AI klijent koji se može postaviti na Vercel, Cloudflare ili Docker. Podržava prilagođene krajnje tačke kompatibilne sa OpenAI-jem, pa se može povezati sa Ace Data Cloud-om. Ovaj članak predstavlja proces konfiguracije.

## Proces prijave

Da biste povezali Ace Data Cloud u NextChat-u, prvo idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications), preuzmite svoj API Token i sačuvajte ga za kasniju upotrebu.

![Preuzimanje Ace Data Cloud API Key-a](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobijate besplatni kredit, tako da možete besplatno isprobati usluge modela Ace Data Cloud-a.

## Preuzimanje NextChat-a

Možete koristiti desktop verziju (preuzmite `.exe` / `.dmg` / AppImage sa [stranice Releases](https://github.com/ChatGPTNextWeb/NextChat/releases)), [Web onlajn verziju](https://app.nextchat.club/), ili je sami postaviti na Vercel / Cloudflare / Docker (pogledajte napredni odeljak u nastavku).

## Konfigurisanje Ace Data Cloud-a

Pokrenite NextChat i idite na **Podešavanja → Usluga modela**:

| Polje          | Vrednost                           | Objašnjenje                              |
| ----------- | --------------------------- | ------------------------------- |
| Provajder usluge modela       | `OpenAI`                    | Koristi protokol kompatibilan sa OpenAI-jem                  |
| OpenAI adresa interfejsa | `https://api.acedata.cloud` | Unesite samo korenski domen, **bez `/openai`, bez `/v1`** |
| API Key     | Vaš Ace Data Cloud Token     | Token kopiran iz konzole                    |

![NextChat Ace Data Cloud interfejs za konfiguraciju](https://cdn.acedata.cloud/47e0aed34570.png)

NextChat će automatski dodati `/v1/chat/completions` iza adrese interfejsa, stoga je dovoljno uneti samo korenski domen:

| Adresa interfejsa                                  | Stvarni zahtev                                                      | Rezultat                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | Ispravno                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (nema `/v1` pod `/openai`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

U polje „Prilagođeni naziv modela” unesite modele razdvojene engleskim zarezima. NextChat podržava posebnu sintaksu: `+naziv-modela` za dodavanje, `-naziv-modela` za skrivanje, `naziv-modela=prikazani-naziv` za prilagođavanje prikazanog naziva i `-all` za prvo skrivanje svih. Preporučeni najčistiji zapis je:

```text
-all,+MODEL_ID=显示名称
```

## Izbor modela

Katalog modela se neprekidno ažurira. Prednost dajte listi modela koju klijent automatski učitava; kada je potrebno ručno uneti, prvo zatražite `GET https://api.acedata.cloud/v1/models` da biste preuzeli trenutni ID modela, a zatim birajte prema kontekstu, slikama i mogućnostima pozivanja alata koje klijent podržava.

## Provera povezivanja

Ako niste sigurni da li je problem u NextChat-u ili mreži, možete prvo direktno proveriti krajnju tačku pomoću curl-a (zamenite `{token}` svojim Token-om):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Ako se vrati OpenAI-kompatibilan `chat.completion` objekat, to znači da su Token i krajnja tačka spremni; ako se vrati `HTTP 403 used_up`, to znači da je Token važeći, ali da nema dovoljno sredstava, pa možete dopuniti sredstva na [konzoli](https://platform.acedata.cloud/console/applications).

## Napredno: postavljanje jednim klikom na sopstveni domen

NextChat podržava postavljanje sopstvene AI veb-stranice. Uzmimo Docker kao primer (zamenite `{token}` svojim Token-om):

```bash
docker run -d \
  --name nextchat \
  -p 3000:3000 \
  -e OPENAI_API_KEY={token} \
  -e BASE_URL=https://api.acedata.cloud \
  -e CODE=your-password \
  -e CUSTOM_MODELS="-all,+MODEL_ID=显示名称" \
  yidadaa/chatgpt-next-web
```

Prilikom postavljanja na Vercel / Cloudflare, dovoljno je da u promenljivama okruženja projekta konfigurišete iste `OPENAI_API_KEY`, `BASE_URL`, `CODE`, `CUSTOM_MODELS`. `CODE` podržava više pristupnih lozinki razdvojenih engleskim zarezima, što olakšava statistiku potrošnje po osobi. Za potpuno objašnjenje navedenih promenljivih okruženja (`BASE_URL` podrazumevano `https://api.openai.com`, sintaksa `+/-/=/-all/+all` za `CUSTOM_MODELS`), pogledajte [zvanični NextChat README](https://github.com/ChatGPTNextWeb/NextChat#environment-variables).

## Česta pitanja

### Prikazuje se 404 Not Found

Obično je adresa interfejsa uneta kao `.../openai` ili `.../openai/v1`. Promenite je u `https://api.acedata.cloud` i dozvolite NextChat-u da sam doda `/v1/chat/completions`.

### Dodati modeli nisu u padajućoj listi modela

Proverite format `CUSTOM_MODELS`; svaki model mora imati `+` ispred sebe; ako ste koristili `-all`, uverite se da ste nakon toga ponovo dodali potrebne modele pomoću `+`.

### Prikazuje se 401 Unauthorized

Potvrdite da je u API Key nalepljen Ace Data Cloud Token (bez prefiksa `Bearer`, bez suvišnih razmaka) i da aplikacija kojoj pripada ima dovoljno sredstava.
