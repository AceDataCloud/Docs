Ace Data Cloud нуди званичне клијент SDK за три језика: TypeScript / Python / Go, који обавијају способности као што су chat completions, images, video, music, search, x402 и друге на `api.acedata.cloud` у снажно типизоване методе, чиме се избегава ручно писање HTTP, SSE, задатка за анкету, обраду грешака и радње поновног покушаја.

Овај поглавље је организовано по редоследу правог приступа: прво добијте API токен на конзоли, затим изаберите језик и погледајте одговарајуће поглавље, а на крају погледајте напредне употребе задатка за анкету, стриминг одговора и X402 плаћања на ланцу.

## Резервни и пакети

- SDK изворни код (monorepo): [https://github.com/AceDataCloud/SDK](https://github.com/AceDataCloud/SDK)
- TypeScript: [`@acedatacloud/sdk`](https://www.npmjs.com/package/@acedatacloud/sdk)
- Python: [`acedatacloud`](https://pypi.org/project/acedatacloud/)
- Go: [`github.com/AceDataCloud/SDK/go`](https://pkg.go.dev/github.com/AceDataCloud/SDK/go)
- X402 клијент (TypeScript): [`@acedatacloud/x402-client`](https://www.npmjs.com/package/@acedatacloud/x402-client)
- X402 клијент (Python): [`acedatacloud-x402`](https://pypi.org/project/acedatacloud-x402/)

| Способност                                                      | TypeScript  | Python                  | Go                    |
| ------------------------------------------------------------ | ----------- | ----------------------- | --------------------- |

| `chat.completions.create` (SSE стриминг)                       | ✅           | ✅                       | ✅                     |
| `images.generate` (Midjourney / Flux / NanoBanana / Seedream) | ✅           | ✅                       | 🚧 (alpha)             |
| `videos.generate` (Sora / Veo / Luma / Kling / Hailuo / Wan)  | ✅           | ✅                       | 🚧 (alpha)             |
| `audios.generate` (Suno / Producer / Fish)                    | ✅           | ✅                       | 🚧 (alpha)             |
| `search.google` (Serp)                                        | ✅           | ✅                       | 🚧 (alpha)             |
| TaskHandle асинхроно анкетирање                                 | ✅ (миллисекунде) | ✅ (секунде)               | 🚧                     |
| Асинхрони клијент                                               | ✅ (Promise) | ✅ (`AsyncAceDataCloud`) | ✅ (`context.Context`) |
| Аутоматско поновно покушавање + експоненцијално одлагање         | ✅           | ✅                       | ✅                     |

> Go SDK мултимедијални ресурси и анкетирање тренутно су у alpha фази (псеудоверзија `v0.0.0-20260505072132-4a3d921f9bb4`), стабилна способност је `chat.completions`. За мултимедијалне сцене преферирајте TypeScript или Python.

## Када користити SDK / MCP / нативни HTTP / X402

| Сцена                                          | Препоручени начин                                                       |
| ------------------------------------------- | -------------------------------------------------------------------- |
| Бекенд услуге, CLI, аутоматизовани скрипти, Agent оквири | **SDK** (ово поглавље)                                                |
| Claude Desktop / Cursor / Cline и остали MCP клијенти | MCP сервери                                                        |
| Једнократна curl верификација, дебаговање, уграђена окружења која подржавају само HTTP | Нативни HTTP (брзи почетак за сваку услугу)                             |
| Не желите да креирате API токен, плаћање USDC по ланцу | [X402 интеграциони водич](https://platform.acedata.cloud/documents/x402-integration) |

SDK и X402 нису искључиви: SDK истовремено подржава „токен пут“ и „`paymentHandler` пут“, детаљи у [SDK + X402 плаћање кука](https://platform.acedata.cloud/documents/sdk-x402-payment).

## Пријава за API токен

Да бисте користили SDK, прво идите на [Ace Data Cloud конзолу - Листа апликација](https://platform.acedata.cloud/console/applications) и пријавите се за API токен:

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након пријаве и регистрације аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, што вам омогућава да бесплатно испробате различите AI услуге које пружа Ace Data Cloud.

Копирајте управо добијени токен, у даљем тексту ћемо га називати `{token}`.

## Уједначена променљива окружења

SDK-ови за три језика аутоматски читају исту променљиву окружења `ACEDATACLOUD_API_TOKEN`, препоручује се да у shell-у `export`-ујете, како би SDK аутоматски преузео:

```bash
export ACEDATACLOUD_API_TOKEN={token}
# Опционално: подразумевани https://api.acedata.cloud
# export ACEDATACLOUD_BASE_URL=https://api.acedata.cloud
```

Такође можете експлицитно проследити токен при конструкцији клијента, а имена параметара за сва три језика су:

- TypeScript: `new AceDataCloud({ apiToken: '{token}' })`
- Python: `AceDataCloud(api_token="{token}")`
- Go: `adc.NewClient(adc.WithAPIToken("{token}"))`

> Напомена: У пројекту AceDataCloud конвенционално се користи `ACEDATACLOUD_API_KEY` (у `.env` / CI), али ова три SDK сама препознају само `ACEDATACLOUD_API_TOKEN`. Ако у вашем окружењу постоји само `ACEDATACLOUD_API_KEY`, молимо вас да га експлицитно проследите при конструкцији.

## 30 секунди за три примера

Следеће три секције кода раде исту ствар: позивају `gpt-4o-mini`, да одговори само са `ADC_*_OK`. Свака секција има **стварне резултате** који се могу репродуковати са вашим токеном.

### TypeScript

```ts
import { AceDataCloud } from '@acedatacloud/sdk';

const client = new AceDataCloud({ apiToken: process.env.ACEDATACLOUD_API_KEY });

const t0 = Date.now();
const res = await client.openai.chat.completions.create({
  model: 'gpt-4o-mini',
  messages: [{ role: 'user', content: 'Reply with exactly: ADC_TS_SDK_OK' }],
  max_tokens: 20,
  temperature: 0
});
console.log('elapsed_ms', Date.now() - t0);
console.log('id', res.id);
console.log('model', res.model);
console.log('content', res.choices[0].message.content);
console.log('usage', JSON.stringify(res.usage));
```

> SDK тренутно декларише одговор као `Record<string, unknown>`, а у време извршења је обичан JSON објекат, који се може директно приступити по пољима. У строгим TS пројектима, ако наиђете на грешке у типу, можете привремено користити `as any`, или се обратити [SDK анкетирању и стриминг одговорима](https://platform.acedata.cloud/documents/sdk-tasks-and-streaming) за прилагођени типизовани обвезник.

Резултати програма:

```text
elapsed_ms 2543
id chatcmpl-DldCcLvkTFaioST8e6SjOl0wJScQA
model gpt-4o-mini
content ADC_TS_SDK_OK
usage {"prompt_tokens":16,"completion_tokens":6,"total_tokens":22}
```

### Python
```python
import os, time, json
from acedatacloud import AceDataCloud

client = AceDataCloud(api_token=os.environ["ACEDATACLOUD_API_KEY"])

t0 = time.time()
res = client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Odgovori tačno: ADC_PY_SDK_OK"}],
    max_tokens=20,
    temperature=0,
)
print("elapsed_ms", int((time.time() - t0) * 1000))
print("id", res["id"])
print("model", res["model"])
print("content", res["choices"][0]["message"]["content"])
print("usage", json.dumps({k: v for k, v in res["usage"].items()
                            if k in ("prompt_tokens","completion_tokens","total_tokens")}))
```

> Python SDK trenutno vraća `dict`, tako da se koristi `res["id"]` umesto `res.id`. Ovo se razlikuje od `openai-python`, na to treba obratiti pažnju prilikom migracije.

Rezultat programa:

```text
elapsed_ms 2963
id chatcmpl-DldFdnIlhSUXINpupgsUmZL78MnBu
model gpt-4o-mini
content ADC_PY_SDK_OK
usage {"prompt_tokens": 17, "completion_tokens": 7, "total_tokens": 24}
```

### Go

```go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    adc "github.com/AceDataCloud/SDK/go"
)

func main() {
    client, err := adc.NewClient(adc.WithAPIToken(os.Getenv("ACEDATACLOUD_API_KEY")))
    if err != nil {
        panic(err)
    }
    ctx, cancel := context.WithTimeout(context.Background(), 60*time.Second)
    defer cancel()

    t0 := time.Now()
    res, err := client.OpenAI().Chat().Completions().Create(ctx, adc.ChatCompletionRequest{
        Model:     "gpt-4o-mini",
        Messages:  []map[string]any{{"role": "user", "content": "Odgovori tačno: ADC_GO_SDK_OK"}},
        MaxTokens: 20,
    })
    if err != nil {
        panic(err)
    }
    fmt.Println("elapsed_ms", time.Since(t0).Milliseconds())
    fmt.Println("id", res["id"])
    fmt.Println("model", res["model"])
    choices := res["choices"].([]any)
    msg := choices[0].(map[string]any)["message"].(map[string]any)
    fmt.Println("content", msg["content"])
    usage := res["usage"].(map[string]any)
    fmt.Printf("usage prompt=%v completion=%v total=%v\n",
        usage["prompt_tokens"], usage["completion_tokens"], usage["total_tokens"])
}
```

> Go SDK odgovori su uniformno `map[string]any`, nema jakih tipova struktura, potrebno je samostalno vršiti tipizaciju. Svi pristupi resursima su metodski lanac: `client.OpenAI().Chat().Completions().Create(...)`.

Rezultat programa:

```text
elapsed_ms 6436
id chatcmpl-89DHExvFvBc4ciIPfolZYUOy7ivxv
model gpt-4o-mini
content ADC_GO_SDK_OK
usage prompt=16 completion=5 total=21
```

Odgovori u tri jezika `id`, `elapsed_ms`, `usage` dolaze iz istog izvora: kroz PlatformGateway autentifikaciju → ciljani OpenAI kompatibilni API → upisivanje u evidenciju troškova. Polje `content` je stvarni izlaz modela, korišćenje fiksnog identifikatora `ADC_*_OK` je da se dokaže da odgovor nije bio izmenjen od strane SDK-a.
