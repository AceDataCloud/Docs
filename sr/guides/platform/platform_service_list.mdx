Straničeno vraća katalog Service vidljiv na trenutnom sajtu, uključujući tip usluge, informacije za prikaz, besplatnu kvotu, pakete i povezane API/Proxy ID-jeve. Pogodno za izgradnju tržišta usluga ili izbor usluge za koju se podnosi zahtev.

## Pregled interfejsa

| Stavka   | Sadržaj                                           |
| --- | ------------------------------------------------- |
| Metod  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| Autentifikacija  | Javna; kada postoji prijavljeno stanje, `applied` tek tada odražava trenutni nalog |
| Straničenje  | `count` + `items`                                 |

## Parametri upita

| Parametar               | Tip      | Obavezno  | Opis                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | Ne   | Filtriranje po ID-ju usluge; podržava ponovljene parametre         |
| `private`        | boolean | Ne   | Filtriranje po javnom statusu; pravila vidljivosti sajta i dalje važe      |
| `type`           | string  | Ne   | Tip usluge; podržava ponovljene parametre              |
| `tag`            | string  | Ne   | Filtriranje po oznaci                    |
| `include_facets` | boolean | Ne   | Kada je `true`, dodaje statistiku tipova/oznaka dostupnih na trenutnom sajtu |
| `limit`          | integer | Ne   | Broj stavki po stranici, najviše 100              |
| `offset`         | integer | Ne   | Pomak straničenja                    |
| `ordering`       | string  | Ne   | Podržava samo `rank` ili `-rank`     |

Lista ne podržava filtriranje po `alias`; kada alias već postoji, direktno zatražite `/api/v1/services/{alias}`. `applied_count`, `updated_at` nisu dozvoljena polja za sortiranje.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## Objašnjenje odgovora

Odgovor je `{count, items}`; `facets` se dodaje samo kada je `include_facets=true`. Stavka usluge sadrži trenutna javna polja kao što su `id`, `alias`, `title`, `description`, `type`, `applied_count`, `free_amount`, `unit`, `private`, `need_verify`, `rank`, `tags`, `thumbnail`, `doc_url`, `demo_url`, `api_ids`, `proxy_ids`, `cost`, `packages` itd.

`applied` u anonimnoj listi ne predstavlja status prijave nekog naloga. Kada je potreban status povezan sa nalogom, treba imati važeće prijavljeno stanje i koristiti [listu prijava za usluge](https://platform.acedata.cloud/documents/platform-application-list) kao konačnu osnovu.
