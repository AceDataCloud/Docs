Paginirano vraća porudžbine za dopunu računa, pogodno za pronalaženje ID-ja porudžbine, pregled statusa plaćanja i usaglašavanje.

## Pripremni radovi

Kreirajte [Account Token](https://platform.acedata.cloud/documents/platform-token) i preuzmite UUID trenutnog računa putem `GET /api/v1/platform-tokens/me/`.

```shell
export PLATFORM_TOKEN='tvoj token računa'
export USER_ID='tvoj UUID računa'
```

## Pregled interfejsa

| Stavka   | Sadržaj                                              |
| --- | ----------------------------------------------- |
| Metod  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/orders/` |
| Autentifikacija  | Account Token, OAuth token zahteva `orders:read`       |
| Paginacija  | `count` + `items`                               |

Obični korisnici moraju proslediti sopstveni `user_id`; u suprotnom, pri paginaciji može biti vraćen `403` kada se naiđe na objekat za koji nemaju ovlašćenje.

## Parametri upita

| Parametar                    | Tip       | Obavezan     | Opis                                                        |
| --------------------- | -------- | ------ | --------------------------------------------------------- |
| `user_id`             | UUID     | Obavezan za obične korisnike | Račun kojem porudžbina pripada; podržava ponovljene parametre                                             |
| `pay_way`             | string   | Ne      | Filtriranje prema načinu plaćanja; podržava ponovljene vrednosti ili vrednosti razdvojene zarezom                                        |
| `state`               | string   | Ne      | Filtriranje prema statusu; podržava ponovljene vrednosti ili vrednosti razdvojene zarezom                                          |
| `created_at_from/to`  | datetime | Ne      | Vremenski opseg kreiranja                                                    |
| `finished_at_from/to` | datetime | Ne      | Vremenski opseg završetka                                                    |
| `limit` / `offset`    | integer  | Ne      | Paginacija                                                        |
| `ordering`            | string   | Ne      | `created_at`, `-created_at`, `finished_at` ili `-finished_at` |

Trenutna lista ne podržava filtriranje prema `application_id`, `service_id`, `package_id`, `payment_method` ili `tag`; naziv polja za način plaćanja je `pay_way`.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/orders/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode 'state=Paid,Finished' \
  --data-urlencode 'pay_way=Stripe' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## Objašnjenje odgovora

Odgovor je `{count, items}`. Stavke liste u produkciji sadrže `id`, `user_id`, `application_id/application_ids`, `package_id/package_ids`, `price`, `amount`, `discount`, `remaining_amount`, `state`, `pay_way`, `pay_id`, `pay_url`, `finished_at`, `expired_at`, `invoice`, `metadata` i vremenska polja.

- Stvarni statusi su `Pending`, `Paid`, `Finished`, `Expired`, `Failed`, `Refunded`; ne postoji `Cancelled`.
- Nazivi polja su `pay_way`, `finished_at`, `discount` i `price`, a ne `payment_method`, `paid_at`, `discount_rate` ili `final_price`.
- `price` je konačna cena zabeležena za porudžbinu; valuta i detalji obračuna mogu se nalaziti u kontrolisanim metadata podacima i ne mogu se samostalno zaključiti samo na osnovu načina plaćanja.
