Vraća javni katalog modela platforme, a odgovor koristi strukturu u OpenAI stilu `{ "object": "list", "data": [...] }`. Ovaj katalog se koristi za izbor modela i otkrivanje mogućnosti i ne predstavlja da je trenutni nalog nužno već zatražio odgovarajuću uslugu.

## Pregled interfejsa

| Stavka   | Sadržaj                                              |
| --- | ----------------------------------------------- |
| Metod  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| Autentifikacija  | Javno, nije potreban token naloga                                       |
| Paginacija  | Bez paginacije, sve odgovarajuće stavke nalaze se u `data`                              |

## Parametri upita

| Parametar             | Tip      | Obavezan  | Opis                                      |
| -------------- | ------- | --- | --------------------------------------- |
| `owned_by`     | string  | Ne   | Precizno filtriranje prema identifikatoru pružaoca modela u katalogu                        |
| `type`         | string  | Ne   | Precizno filtriranje prema tipu modela, na primer `chat`                     |
| `capability`   | string  | Ne   | Vraća samo modele čiji `capabilities` sadrži tu mogućnost, na primer `vision` |
| `with_pricing` | boolean | Ne   | Dodaje javne informacije o cenama kada je `1`, `true` ili `yes`            |

`service_id`, `tag`, `limit`, `offset` i `ordering` trenutno nisu podržani; njihovo prosleđivanje neće proizvesti odgovarajući efekat filtriranja ili paginacije.

## Primeri zahteva

```shell
# Svi javni modeli
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# chat modeli koji podržavaju vid, sa cenama
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## Stvarna struktura odgovora

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

`pricing` i `credit_usd_rate` najvišeg nivoa pojavljuju se samo kada je `with_pricing=true`; nema svaki model izračunljiv `pricing`. Za javna polja objekta modela merodavan je `config/models.json`, a klijent treba da ignoriše novododata polja.

> Polja cena su podaci za prikaz u katalogu. Stvarni poslovni pozivi i dalje podležu pravilima naplate odgovarajućeg API-ja/usluge i konačnoj evidenciji upotrebe.
