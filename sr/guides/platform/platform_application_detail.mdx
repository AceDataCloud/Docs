Preuzmite kompletan status jednog zahteva za uslugu putem Application ID-ja — u poređenju sa interfejsom liste sadrži dodatna polja kao što je kompletan objekat `service` (uključujući pakete `packages`), pogodno za stranicu detalja.

> ℹ️ Ovaj interfejs pripada **AceDataCloud API-ju za upravljanje platformom**, sa jedinstvenim prefiksom `https://platform.acedata.cloud/api/v1/`. Za kompletan indeks interfejsa pogledajte [Preuzimanje liste dokumenata AceDataCloud platforme](https://platform.acedata.cloud/documents/platform-document-list).

## Pregled interfejsa

| Stavka   | Sadržaj                                                               |
| --- | --------------------------------------------------------------------- |
| Metod  | `GET`                                                                 |
| URL | `https://platform.acedata.cloud/api/v1/applications/{application_id}` |
| Autentifikacija  | ✅ Potreban je token naloga                                                              |

`/applications/{id}` i `/applications/{id}/` su trenutno oba dostupna; primeri dosledno koriste oblik bez završne kose crte.

## Objašnjenje autentifikacije (kako dobiti token naloga)

Zaglavlje zahteva:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

Za detaljan način dobijanja pogledajte [Upravljanje tokenom naloga AceDataCloud platforme](https://platform.acedata.cloud/documents/platform-token).

> ℹ️ Za razliku od interfejsa liste, **provera dozvola interfejsa detalja vrši se direktno nad pojedinačnim objektom**, nije potrebno proslediti `?user_id=`. Međutim, ako pristupite tuđem zahtevu, dobićete `403 permission_denied`.

## Parametri putanje

| Parametar               | Tip   | Obavezno  | Opis             |
| ---------------- | ---- | --- | -------------- |
| `application_id` | UUID | ✅   | Application ID |

## Primeri zahteva

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/applications/82f57141-2323-4453-8730-60f7d833a2da' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

app_id = "82f57141-2323-4453-8730-60f7d833a2da"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/applications/{app_id}",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
app = resp.json()
print(f"服务：{app['service']['title']}")
print(f"剩余 {app['remaining_amount']} {app['service']['unit']} / 已用 {app['used_amount']}")
```

### Node.js

```javascript
const appId = '82f57141-2323-4453-8730-60f7d833a2da'
const r = await fetch(`https://platform.acedata.cloud/api/v1/applications/${appId}`, {
  headers: { authorization: `Bearer ${process.env.PLATFORM_TOKEN}` },
})
console.log(await r.json())
```

## Objašnjenje polja odgovora

Značenja polja su ista kao u [interfejsu liste](https://platform.acedata.cloud/documents/platform-application-list), uz dodatno:

| Polje        | Tip     | Opis                                                        |
| --------- | ------ | --------------------------------------------------------- |
| `service` | object | Kompletan objekat usluge (uključujući pakete `packages`, `unit`, `free_amount`), može se direktno prikazati na panelu detalja usluge |

## Obrada grešaka

| HTTP | code                | Značenje                  |
| ---- | ------------------- | ------------------- |
| 401  | `not_authenticated` | Nedostaje token naloga              |
| 403  | `permission_denied` | Ovaj Application vam ne pripada  |
| 404  | `not_found`         | Application ne postoji ili je obrisan |

## Praktični saveti

- **Za grupno praćenje prioritetno koristite listu**: nakon jednokratnog preuzimanja liste Application-a, procenite prema jedinicama i pragovima svake usluge, kako biste izbegli pojedinačne zahteve za detalje.
- **Kada treba proveriti broj akreditiva**: koristite [listu API akreditiva](https://platform.acedata.cloud/documents/platform-credential-list) za filtriranje prema `application_id`.
- **Pristup za rešavanje problema sa `disabled=true`**: proverite tikete / obaveštenja e-poštom da vidite da li je usluga obustavljena zbog kontrole rizika, neplaćenih obaveza ili neusklađenih poziva; ne može se ponovo aktivirati putem API-ja, već morate kontaktirati korisničku podršku.
