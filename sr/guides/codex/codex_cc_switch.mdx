---

CC Switch може управљати Codex-овим провајдерима и API кључем преко графичког интерфејса.

## 1. Добијање API кључа

Отворите [Ace Data Cloud списак апликација](https://platform.acedata.cloud/console/applications), уђите у доступне апликације и копирајте API кључ.

![Добијање Ace Data Cloud API кључа](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Инсталирање CC Switch

Преузмите и инсталирајте са [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), или покрените на macOS:

```bash
brew install --cask cc-switch
```

## 3. Додавање провајдера

1. Отворите CC Switch, прелите на **Codex**.
2. Кликните на **Add Provider**, изаберите **Custom**.
3. Попуните:

| Поље       | Садржај                             |
| -------- | --------------------------------- |
| Name     | `acedatacloud`                   |
| Base URL | `https://api.acedata.cloud/v1`   |
| API Key  | Управо копирани Ace Data Cloud API кључ   |

Ако CC Switch пружа уредник за прилагођену конфигурацију, конфигурација треба да остане као:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"
requires_openai_auth = true
```

CC Switch ће сачувати API кључ у `~/.codex/auth.json`:

```json
{
  "OPENAI_API_KEY": "{token}"
}
```

Не додавајте `env_key` или `[model_providers.acedatacloud.auth]` у горњи провајдер; ручна конфигурација и CC Switch конфигурација су опција. Нема потребе за фиксним `model`, можете га директно изабрати у Codex-у.

## 4. Омогућите и верификујте

Омогућите `acedatacloud` провајдер, потпуно изађите и поново покрените Codex или VS Code. Покрените `/model`, потврдите да је провајдер `acedatacloud`, а затим изаберите модел и пошаљите једну просту поруку.

Ако се врати 401, потврдите да је тренутно омогућен `acedatacloud`, и проверите да ли је `OPENAI_API_KEY` у `~/.codex/auth.json` управо копирани Ace Data Cloud API кључ. Записи позива могу се видети у [историји коришћења](https://platform.acedata.cloud/console/usages).
