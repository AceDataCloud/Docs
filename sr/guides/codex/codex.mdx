Codex CLI, Desktop и VS Code екстензије деле `~/.codex/config.toml`. Конфигуришите `acedatacloud` провајдер једном, и можете користити Codex преко Ace Data Cloud.

| Начин коришћења    | Конфигурациони водич                                                                          |
| ----------------- | --------------------------------------------------------------------------------------- |
| Терминал / CLI    | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)        |
| Десктоп           | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)     |
| VS Code           | [Codex for VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)  |
| Графичко пребацивање | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration) |

Заједничка конфигурација има само три ставке:

- Провајдер: `acedatacloud`
- Основни URL: `https://api.acedata.cloud/v1`
- API кључ: добијте из [листе апликација](https://platform.acedata.cloud/console/applications) и сачувајте у `ACEDATACLOUD_API_KEY`

Није потребно фиксно подешавати модел у конфигурацији; након покретања Codex можете директно одабрати модел.

Вратите се на [Coding Plan конфигурациони центар](https://platform.acedata.cloud/documents/coding-plan-integration).
