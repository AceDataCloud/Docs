Codex VS Code ekstenzija deli `~/.codex/config.toml` sa Codex CLI.

## 1. Dobijanje API ključa

Otvorite [Ace Data Cloud listu aplikacija](https://platform.acedata.cloud/console/applications), uđite u dostupne aplikacije i kopirajte API ključ.

![Dobijanje Ace Data Cloud API ključa](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalacija ekstenzije

U VS Code ekstenzijskoj prodavnici instalirajte **Codex – OpenAI-ov kodirajući agent**, ili pokrenite:

```bash
code --install-extension openai.chatgpt
```

## 3. Postavljanje API ključa

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="tvoj API ključ"
```

Ako želite da važi dugoročno, dodajte ovu liniju u `~/.zshrc` ili `~/.bashrc`. Windows PowerShell koristi:

```powershell
setx ACEDATACLOUD_API_KEY "tvoj API ključ"
```

## 4. Konfiguracija AceDataCloud

Uredite `~/.codex/config.toml` (Windows za `%USERPROFILE%\.codex\config.toml`), dodajte:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Windows poslednje dve linije promenite na:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Nema potrebe da popunjavate `model`; možete izabrati model u Codex panelu.

## 5. Ponovno pokretanje i verifikacija

Potpuno izađite i ponovo otvorite VS Code, zatim otvorite Codex panel. Pokrenite `/model`, potvrdite da je Provider `acedatacloud`, a zatim pošaljite jednostavnu poruku; evidencija poziva može se videti u [istoriji korišćenja](https://platform.acedata.cloud/console/usages).

Ako ekstenzija ne može da pročita ključ, pokrenite VS Code iz terminala u kojem su postavljene promenljive okruženja, ili postavite sistemske promenljive okruženja i ponovo pokrenite VS Code. Remote SSH, WSL i Dev Container treba posebno konfigurirati u okruženju u kojem se ekstenzija zapravo pokreće.
