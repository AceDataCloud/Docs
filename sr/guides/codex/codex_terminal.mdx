## 1. Добијање API кључа

Отворите [Ace Data Cloud списак апликација](https://platform.acedata.cloud/console/applications), уђите у доступне апликације и копирајте API кључ.

![Добијање Ace Data Cloud API кључа](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Инсталирање Codex-a

```bash
npm install -g @openai/codex
```

## 3. Подешавање API кључа

macOS / Linux：

```bash
export ACEDATACLOUD_API_KEY="ваш API кључ"
```

Ако желите да буде трајно, додајте ову линију у `~/.zshrc` или `~/.bashrc`. Windows PowerShell користи:

```powershell
setx ACEDATACLOUD_API_KEY "ваш API кључ"
```

Након подешавања, поново отворите терминал.

## 4. Конфигурација AceDataCloud

Уредите `~/.codex/config.toml` (за Windows `%USERPROFILE%\.codex\config.toml`), додајте:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

За Windows промените последње две линије на:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Није потребно попуњавати `model`; након покретања можете изабрати модел у Codex-у. Остале конфигурације можете задржати, не стварајте поново провајдер са истим именом.

## 5. Покретање

```bash
cd /path/to/your/project
codex
```

Када уђете у Codex, покрените `/model`, потврдите да је провајдер `acedatacloud`, а затим изаберите потребан модел. Записи о позивима и стање баланса могу се видети на [историји коришћења](https://platform.acedata.cloud/console/usages) и [списку апликација](https://platform.acedata.cloud/console/applications).

Ако се појави порука о недостајућем кључу или се врати 401, потврдите да су променљиве окружења подешене, а затим потпуно затворите и поново отворите терминал и Codex.
