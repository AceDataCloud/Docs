Codex Desktop дели `~/.codex/config.toml` са Codex CLI.

## 1. Добијање API кључа

Отворите [Ace Data Cloud списак апликација](https://platform.acedata.cloud/console/applications), уђите у доступне апликације и копирајте API кључ.

![Добијање Ace Data Cloud API кључа](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Постављање API кључа

macOS：

```bash
launchctl setenv ACEDATACLOUD_API_KEY "ваш API кључ"
```

Windows PowerShell：

```powershell
setx ACEDATACLOUD_API_KEY "ваш API кључ"
```

## 3. Конфигурација AceDataCloud

Уредите `~/.codex/config.toml` (за Windows `%USERPROFILE%\.codex\config.toml`), додајте:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

За Windows промените последње две линије на:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Није потребно попуњавати `model`; отворите Codex и директно изаберите модел.

## 4. Рестарт и верификација

Потпуно изађите и поново отворите Codex Desktop, креирајте локални задатак и пошаљите једну просту поруку. Провајдер би требало да се прикаже као `acedatacloud`; стварни позиви могу се видети у [историји коришћења](https://platform.acedata.cloud/console/usages).

Ако конфигурација није активна, уверите се да сте изменили `~/.codex/config.toml` за текућег корисника, да су променљиве окружења постављене, а затим поново потпуно рестартујте апликацију. Облачни задаци или аутоматизације које се извршавају у различитим окружењима морају бити посебно конфигурисане за кључ у одговарајућем окружењу.
