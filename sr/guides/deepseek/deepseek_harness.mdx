[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) је програмски agent који се покреће локално. Он чита радни простор, позива алате и извршава команде, а затим позива модел преко OpenAI-compatible Chat Completions интерфејса.

> Овај текст је намењен за `deepseek-harness-sdk==0.1.0rc6` и `deepseek-harness-runtime-bin==0.1.0rc6`. Након надоградње клијента, поново завршите тест читања само за читање у доњем делу.

## Подржани опсег

| Пројекат       | Конфигурација                           |
| -------------- | --------------------------------------- |
| API Base URL   | `https://api.acedata.cloud/v1`        |
| Модел          | `deepseek-v4-pro`                      |
| Протокол       | OpenAI-compatible Chat Completions (стриминг) |
| Способности    | Текст, процес разматрања, позиви функција, локални Bash алатни циклус, статистика коришћења |

Директоријум модела ће се променити. Пре покретања, прво проверите реални директоријум помоћу специјалног кључа Coding Plan:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY"
```

Потврдите да одговор садржи `deepseek-v4-pro`. Не третирајте `deepseek-v4-flash` као еквивалентну замену за алатни режим у овом тексту; у овој фиксној верзији верификације, његова историја више рунди разматрања и репродукција алата нису прошле.

## 1. Припремите специјални кључ

Отворите [Coding Plan апликацију](https://platform.acedata.cloud/console/applications), уђите у купљену Coding Application, креирајте или копирајте специјални API кључ те апликације. Coding Plan не користи општи баланс, кључеви других апликација не могу представљати права пакета.

Само ставите кључ у тренутни shell:

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_CODING_KEY_HERE"
export DEEPSEEK_BASE_URL="https://api.acedata.cloud/v1"
export DEEPSEEK_API_KEY="$ACEDATACLOUD_API_KEY"
```

Не стављајте прави кључ у скрипте, конфигурационе репозиторије, снимке терминала или записе сесија.

## 2. Креирајте изоловани радни простор

Harness-ов bundled runtime садржи локалне Bash алате. Први пут верификације не указујте на праве пројекте или главни директоријум; креирајте једнократни директоријум без тајни:

```bash
mkdir -p /tmp/deepseek-harness-demo/workspace
mkdir -p /tmp/deepseek-harness-demo/sessions
printf 'compatibility fixture\n' > /tmp/deepseek-harness-demo/workspace/fixture.txt
python3 -m venv /tmp/deepseek-harness-demo/venv
/tmp/deepseek-harness-demo/venv/bin/pip install \
  "deepseek-harness-sdk==0.1.0rc6"
```

Ако компанијска мрежа користи приватни PyPI оглед, прво потврдите да у огледу постоји иста верзија `deepseek-harness-runtime-bin`. Не користите `danger-full-access` за проширење опсега приступа датотекама; пример у овом тексту само преноси једнократни директоријум у `cwd`.

## 3. Покрените званични Python SDK

Сачувајте следећи садржај као `/tmp/deepseek-harness-demo/run.py`:

```python
import os

from deepseek_harness import DeepSeekHarness

with DeepSeekHarness(
    provider="deepseek-official",
    model="deepseek-v4-pro",
    max_tokens=160,
    cwd="/tmp/deepseek-harness-demo/workspace",
    session_root="/tmp/deepseek-harness-demo/sessions",
    base_url=os.environ["DEEPSEEK_BASE_URL"],
    api_key=os.environ["DEEPSEEK_API_KEY"],
    request_timeout_seconds=180,
) as harness:
    result = harness.run(
        "Read fixture.txt once, then reply with exactly: sdk-harness-ok",
        session_id="acedatacloud-compat",
    )

print(result.final_response)
print(result.finish_reason)
```

Покрените:

```bash
/tmp/deepseek-harness-demo/venv/bin/python \
  /tmp/deepseek-harness-demo/run.py
```

Очекујући резултат:

```text
sdk-harness-ok
completed
```

Овај корак истовремено верификује Bearer аутентификацију, `/v1/chat/completions`, SSE, садржај разматрања, позиве алата и повратак резултата алата. Након завршетка, можете обрисати `/tmp/deepseek-harness-demo`; ако директоријум сесије садржи контекст пројекта, такође би требало да се чува на истом нивоу осетљивости као код репозиторијума.

## Честа питања

- **401**: Проверите да ли је `ACEDATACLOUD_API_KEY` извозен у исти shell у коме се покреће Python.
- **403 или порука о лимиту**: Потврдите да кључ припада тренутној Coding Application, да је пакет још увек у важећем року и да има преостали лимит.
- **Модел није доступан**: Поново проверите `/v1/models`, не нагађајте име модела на основу старих снимка.
- **`reasoning_content` / грешка у репродукцији алата**: Потврдите да су SDK/runtime обе фиксне верзије из овог текста и да користите `deepseek-v4-pro`.
- **Необичан број извршења алата**: Престаните да извршавате задатке који могу имати нежељене ефекте, прво верификујте тренутну верзију услуге помоћу овог текста само за читање.
- **Неуспех инсталације**: Потврдите да је Python 3.10+, да архитектура оперативног система подржава тренутни wheel и проверите да ли су верзије SDK/runtime исте.

## Границе способности

Овај текст само верификује локални Python SDK до Chat Completions текстуалне и алатне рунде. Слике, Files API, `/v1/responses`, `/v1/messages`, удаљени радни простори и хостовани песковити не спадају у обавезе овог водича; права радног простора и ризици локалних команди су одговорност машине и конфигурације која покреће Harness.
