title: "Qwen Image задача упит API"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/tasks` се користи за упит, масовни упит или брисање Qwen Image асинхроних задатака. Овај интерфејс не генерише додатну API потрошњу.

## Упит појединачног задатка

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Након завршетка задатка, `response.data` садржи трајну CDN слику адресу, `response.usage` садржи стварни број улаза/излаза, а `response.cost` је информација о обрачуну за генерисање задатка.

## Масовни упит

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Враћа `{ "items": [...], "count": 2 }`. Листинг упит такође подржава филтрирање по кориснику, апликацији и опсегу времена креирања.

## Брисање задатка

```json
{"action":"delete","id":"TASK_ID"}
```

Брисање утиче само на историју задатака, неће обрисати већ генерисане CDN датотеке.
