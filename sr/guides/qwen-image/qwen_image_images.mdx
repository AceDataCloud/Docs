---
title: "Qwen Image API za generisanje i uređivanje"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` dovršava generisanje slike iz teksta i uređivanje sa 1–3 referentne slike putem istog interfejsa, uz podršku za `qwen-image-3.0` i `qwen-image-3.0-pro`.

## Izbor modela

| Model                | Pogodni scenariji       | Zvanična standardna cena      |
| -------------------- | ---------------------- | ----------------------------- |
| `qwen-image-3.0`     | Masovno kreiranje, brza iteracija | Izlaz $0.030/po slici |
| `qwen-image-3.0-pro` | Složeni raspored, gotov rezultat visoke preciznosti | 1K $0.040/po slici; 2K $0.075/po slici |

Referentne slike se naplaćuju prema stvarnom broju unetih slika, po zvaničnoj standardnoj ceni od $0.003/po slici.

## Sinhrono generisanje

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "A simple red circle centered on a clean white background.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

Uspešan odgovor sadrži trajnu CDN adresu slike, stvarni usage i cenu ove operacije:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Uređivanje referentnih slika

Dodajte `image_urls`, uz podršku za 1–3 javno dostupne slike:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "保留主体，将背景改成暖色电影海报风格",
  "image_urls": [
    "https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"
  ],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` se koristi samo za generisanje slike iz teksta. Opseg za `n` je 1–6; odnos širine i visine mora biti između 1:8 i 8:1.

## Asinhroni zadaci

Nakon postavljanja `async: true`, interfejs odmah vraća `task_id`. Koristite `/qwen-image/tasks` za upit o završnom stanju ili prosledite `callback_url` za primanje obaveštenja o završetku. Generisanje se naplaćuje samo jednom, a upiti zadatka se ne naplaćuju ponovo.
