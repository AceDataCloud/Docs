`POST https://api.acedata.cloud/webextrator/extract`

Izvlačenje sadržaja na osnovu `/webextrator/render`. Osim svih parametara render interfejsa, dodatno podržava:

| Polje | Tip | Obavezno | Podrazumevano | Opis |
|-------|-----|:--------:|---------------|------|
| `expected_type` | string | ❌ | `markdown` | Očekivani rezultat izvlačenja: `markdown` / `article` / `text` / `links` / `structured` |
| `enable_llm` | boolean | ❌ | false | Omogući LLM postprocesiranje (pogodno za `article` / `structured`) |
| `instruction` | string | ❌ | - | LLM instrukcije za izvlačenje, na primer „izvuci naslov proizvoda, cenu, specifikacije“ |

## Sinhroni odgovor

```json
{
  "success": true,
  "task_id": "550e8400-...",
  "trace_id": "550e8400-...",
  "started_at": "2026-05-02T10:30:00.123Z",
  "finished_at": "2026-05-02T10:30:08.789Z",
  "elapsed": 8.666,
  "data": {
    "kind": "extract",
    "expected_type": "article",
    "url": "https://example.com/post/1",
    "title": "Primer članka",
    "author": "Zhang San",
    "published_at": "2026-05-01",
    "content": "# Primer članka\n\nGlavni tekst ...",
    "summary": "Ovaj članak predstavlja ..."
  }
}
```

Asinhroni režim, kodovi grešaka i pravila naplate su potpuno isti kao kod `/webextrator/render`.

## Primer: izvlačenje teksta članka (omogućeno LLM)

```bash
curl -X POST https://api.acedata.cloud/webextrator/extract \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/news/1",
    "expected_type": "article",
    "enable_llm": true
  }'
```

## Primer: asinhrono + prilagođeno strukturirano izvlačenje

```bash
curl -X POST https://api.acedata.cloud/webextrator/extract \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://shop.example.com/item/123",
    "expected_type": "structured",
    "enable_llm": true,
    "instruction": "izvuci naslov proizvoda, cenu, stanje zaliha, URL-ove 3 glavne slike",
    "callback_url": "https://your-domain.com/wbx-callback"
  }'
```
