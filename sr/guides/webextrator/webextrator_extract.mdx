`POST https://api.acedata.cloud/webextrator/extract`

WebExtrator API za inteligentno izdvajanje pretvara URL u **tipizovane strukturirane rezultate** — članke, proizvode,
recepte, video-zapise, diskusije, oglase za posao i drugo, uz očišćeni Markdown i običan tekst. Ovo je odgovarajući interfejs kada želite „čiste strukturirane
podatke“, a ne sirovi HTML.

## Процес пријаве

Да бисте користили WebExtrator услугу, прво идите на [Ace Data Cloud контролна табла](https://platform.acedata.cloud/console/applications) да добијете ваш API токен, за резерву.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ако се нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након тога ћете бити аутоматски враћени на тренутну страницу.

**Један API токен је довољан за позивање свих услуга платформе, без потребе за посебном пријавом за сваку услугу.** При првом захтеву добијате бесплатан кредит, можете бесплатно испробати; када вам кредит недостаје, можете допунити општи баланс на [контролној табли](https://platform.acedata.cloud/console/coin).

> 📘 Пуна документација: [WebExtrator услужна страница →](https://platform.acedata.cloud/service/webextrator)

## Аутентификација

```
Authorization: Bearer YOUR_API_KEY
Content-Type:  application/json
```

## Parametri zahteva

Extract prihvata **sve** parametre [Render API-ja](/sr/guides/webextrator/webextrator_render)
（`url`、`user_agent`、`timeout`、`wait_until`、`delay`、`wait_for_selector`、
`block_resources`、`headers`、`cookies`、`callback_url`、`bypass_cache`、
`cache_ttl_seconds`、`async`），uz dva polja specifična za Extract:

| Polje | Tip | Obavezno | Podrazumevano | Opis |
|------|------|:----:|------|------|
| `expected_type` | enum | ❌ | Automatsko određivanje | Nagoveštaj tipa stranice: `product` / `article` / `general`. Navedite očekivani tip rezultata. |
| `enable_llm` | boolean | ❌ | `false` | Omogućava pozivanje LLM-a za ekstrakciju kada schema.org nema podudaranja. Na stranicama bez JSON-LD-a, kao što su Amazon / HN / Greenhouse, ovo mora biti uključeno da bi se dobili tipizirani rezultati. |

### Polja najvišeg nivoa

| Polje | Tip | Opis |
|------|------|------|
| `kind` | string | Fiksno `"extract"`. |
| `url` | string | URL koji ste poslali. |
| `finalUrl` | string | Konačni URL nakon preusmeravanja. |
| `contentType` | enum | Tip stranice: `product` / `article` / `general`. |
| `title` | string | Naslov stranice. |
| `description` | string? | Opis ili sažetak stranice. |
| `byline` | string? | Autor, kanal ili kompanija. |
| `language` | string? | `<html lang>`.  |
| `siteName` | string? | `og:site_name`.  |
| `publishedAt` | string? | Vreme objavljivanja, u ISO 8601 formatu. |
| `images` | string[] | Najviše 50 `<img src />`, razrešenih na apsolutne URL-ove, bez duplikata, uz odbacivanje `data:` URI-ja. |
| `links` | string[] | Najviše 100 spoljnih veza, uz filtriranje fragmenata / `javascript:` / `mailto:` / `tel:`. |
| `markdown` | string | Markdown sadržaj stranice. |
| `text` | string | Običan tekst stranice. |
| `structured` | object | Kompletan strukturirani rezultat, pogledajte u nastavku. |
| `rawSignals` | object | Dijagnostičke informacije za otklanjanje grešaka. |
| `cached` | boolean? | `true` kada je pogodak iz keša. |
| `cacheStoredAt` | number? | Unix vremenska oznaka u milisekundama kada je stavka keša prvi put upisana. |

### `data.structured` potpolja

| Potpolje | Kada se pojavljuje | Opis |
|--------|---------|------|
| `schemaOrg` | Uvek | `{ primary, breadcrumbs, all }`. `primary` je tipizirani entitet najvišeg prioriteta; `null` ako nije pronađen. |
| `openGraph` | Uvek | `{ title, description, image, type }`, izvedeno iz `<meta property="og:*" />`. |
| `jsonLd` | Uvek | Niz sirovog JSON-a za sve `<script type="application/ld+json">` blokove. |
| `llm` | Kada se LLM pokrene i uspe | `{ kind, data, model, promptCharCount }`, tipizirani rezultat. |
| `llmError` | Kada se LLM pokrene, ali ne uspe | `{ kind, error, model }`, zahtev i dalje može vratiti druga izdvojena polja. |
| `amazon` | Kada je URL `amazon.*` | Zastareli rezultati Amazon ekstenzije; za nove integracije koristite tipizirane rezultate. |

## Tipovi rezultata schema.org

`structured.schemaOrg.primary` podržava sledeće tipove rezultata:

| Tip schema.org | kind | Izlazna polja |
|----------------|----------|----------|
| `Product` | product | `name, sku, gtin, model, color, brand, url, images, offer.{price,currency,availability,condition,seller}, rating.{value,count}, reviews[], properties[]` |
| `Recipe` | recipe | `name, description, image, datePublished, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords, recipeCategory, recipeCuisine` |
| `VideoObject` | video | `name, description, thumbnailUrl, uploadDate, duration, embedUrl, contentUrl, channel, interactionCount` |
| `JobPosting` | job | `title, description, datePosted, validThrough, hiringOrganization, jobLocation, baseSalary, employmentType` |
| `Event` (uključujući `*Event`) | event | `name, description, startDate, endDate, location.{name,address}, organizer, offer.{url,price,currency}` |
| `Article` / `NewsArticle` / `BlogPosting` / `ScholarlyArticle` / `TechArticle` / `Report` / `*NewsArticle` | article | `subtype, headline, description, datePublished, dateModified, author, publisher, image[], url, sameAs[]` |
| `FAQPage` | faq | `questions[{question, answer}]` |
| `BreadcrumbList` | (postavljeno na sibling) | Uvek se ispisuje u `structured.schemaOrg.breadcrumbs[]` i neće se koristiti kao primary. |

## Tipovi LLM rezultata

Kada je `enable_llm: true` i stranica nema dostupne strukturirane podatke schema.org, mogu se vratiti rezultati izdvajanja sledećih tipova:

| Kind | Obavezna polja | Opciona polja |
|------|---------|---------|
| `article` | `headline` | `description, byline, publishedAt, language, topics[], sections[{heading,summary}]` |
| `product` | `name` | `description, brand, sku, price, currency, availability, rating.{value,count}, bullets[], specifications[{name,value}]` |
| `discussion` | `title` | `author, postedAt, points, commentCount, body, url` |
| `recipe` | `name` | `description, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords[]` |
| `video` | `name` | `description, channel, uploadDate, duration, viewCount, likeCount, thumbnailUrl, transcript` |
| `job` | `title` | `description, company, location, remote, employmentType, datePosted, validThrough, salaryMin, salaryMax, salaryCurrency, salaryPeriod, responsibilities[], qualifications[]` |

## Keš

Rezultati iz keša mogu se ponovo koristiti za isti URL, parametre zahteva, `cookies` i `headers`; `async`, `bypass_cache` i `cache_ttl_seconds` koriste se za kontrolu načina izvršavanja i ponašanja keša.

| Polje | Efekat |
|------|------|
| `bypass_cache: true` | Preskoči čitanje; rezultat ovog puta će ipak biti upisan u keš, pa će sledeći isti zahtev moći da pogodi keš. |
| `cache_ttl_seconds: 0` | Ovaj odgovor se **ne kešira**. |
| `cache_ttl_seconds: N` | Prilagodite TTL za ovu stavku (podrazumevano 3600 sekundi). |

Odgovori pogođeni iz keša sadržaće `data.cached: true` i `data.cacheStoredAt: <unix-ms>`.

## Асинхрони режим и повратни позив

Поставите `async: true` да уђете у асинхрони режим (пружање `callback_url` ће такође аутоматски ући у режим). Платформа одмах враћа (HTTP 200):

```json
{
  "success": true,
  "task_id": "550e8400-...",
  "trace_id": "6ba7b810-...",
  "started_at": 1777717800.123
}
```

Када се задатак заврши, целокупни пакет `POST` на ваш `callback_url` (ако је конфигурисан). Такође можете
касније активно проверити преко [`/webextrator/tasks`](/sr/guides/webextrator/webextrator_tasks).

### Python (requests)

```python
import os, requests

API_KEY = os.environ["ACEDATA_API_KEY"]

resp = requests.post(
    "https://api.acedata.cloud/webextrator/extract",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "url": "https://en.wikipedia.org/wiki/Diffbot",
        "expected_type": "članak",
    },
    timeout=120,
)
resp.raise_for_status()
data = resp.json()["data"]

primary = (data.get("structured") or {}).get("schemaOrg", {}).get("primary")
print("contentType:", data["contentType"])
print("title:      ", data["title"])
print("byline:     ", data.get("byline"))
print("publishedAt:", data.get("publishedAt"))
if primary and primary["kind"] == "članak":
    print("headline:    ", primary["headline"])
    print("dateModified:", primary.get("dateModified"))
```

### Node.js (fetch)

```js
const apiKey = process.env.ACEDATA_API_KEY;

const res = await fetch('https://api.acedata.cloud/webextrator/extract', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${apiKey}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://www.allrecipes.com/recipe/16354/easy-meatloaf/',
  }),
});
const { data } = await res.json();
const recipe = data?.structured?.schemaOrg?.primary;
console.log(recipe.name, recipe.cookTime, recipe.ingredients.length, 'vrsta sastojaka');
```

## Saveti i zamke

- **Kada treba navesti tip stranice, prosledite `expected_type`.** Na primer, za stranicu članka koristite `article`, a za stranicu proizvoda `product`.
- **`enable_llm: true` je besplatan na stranicama koje odgovaraju schema.org.** LLM se poziva samo kada schema.org
  nema primary, tako da je bezbedno ostaviti ga podrazumevano uključenim.
- **Prilikom otklanjanja grešaka prvo proverite `rawSignals.hasJsonLd`.** Ako je `true`, ali je `structured.schemaOrg.primary`
  `null`, to znači da `@type` stranice trenutno nije podržan; možete nam poslati povratne informacije.
- **`structured.llmError` je informativan.** Zahtev i dalje može uspešno vratiti druga izdvojena polja. Pogledajte
  `llmError.error` da biste utvrdili razlog (istek vremena, neuspešno JSON parsiranje, neuspešna provera strukture).
- **`links[]` za stranice koje nisu članci ne radi rangiranje po relevantnosti.** Čišćenje se u najboljoj meri vrši samo prema pravilu „najviše 100 stavki + filtriranje nevažećih protokola“
  .
- **Pogođeni odgovori iz keša se takođe naplaćuju.**
