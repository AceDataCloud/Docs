---
title: "Tripo 3D generisanje"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Pozovite `POST /tripo/generations` da biste kreirali novi model, prosleđujući tekst, jednu sliku ili više pogleda na isti objekat. Koristite AceDataCloud Token, a rezultat se podrazumevano vraća sinhrono. Kada se prosledi `async: true` ili `callback_url`, prvo se vraćaju HTTP 200 i `task_id`. Povratni poziv po završetku i sinhroni rezultat imaju istu JSON strukturu.

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

`action` je podrazumevano `generate`. Izaberite jedan od tri ulaza: `prompt` (1–1024 karaktera), `image_url` ili `image_urls`. Slike su javno dostupni HTTPS PNG/JPEG fajlovi veličine do 20 MiB. Višestruki pogledi se navode redom: spreda, sleva, otpozadi, zdesna; moraju se navesti pogled spreda i najmanje još jedan pogled, a za preskakanje pogleda između njih može se koristiti null.

`model` je podrazumevano `v3.1-20260211`, a mogu se izričito izabrati i `v3.0-20250812`, `v2.5-20250123`, `P1-20260311` ili `P2-20260801`. `texture` je podrazumevano `standard`, a za čistu geometriju koristite `none`. Različiti modeli i nivoi tekstura troše različite kvote.

Preuzmite GLB sa `data[0].model_url`, a `image_url` je opcioni pregled. Sačuvajte `data[0].id` za kasnije operacije teksturisanja, konverzije ili rada sa skeletom. Pri ponovnom pokušaju istog zahteva zadržite isti `Idempotency-Key` i telo zahteva.
