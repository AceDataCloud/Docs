SUNO нам омогућава да унесемо упитне речи за генерисање побољшаног стила песама. Овај документ објашњава методе интеграције релевантног API-ja.

Овај API има само један улазни параметар, а то је `prompt`, који представља стилске упитне речи које треба оптимизовати.

Овде уносимо `prompt` као `Pesma za Božić`.

```python
import requests

url = "https://api.acedata.cloud/suno/style"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "Pesma za Božić"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Резултат је следећи:

```json
{
  "success": true,
  "task_id": "8e887548-7185-48a9-b7cb-e51754f7b87b",
  "trace_id": "ac4ec363-4245-400b-9643-0b6fed8c6b20",
  "data": {
    "upsampled_tags": "Svetle, svečane zvona i oštra akustična gitara otvaraju, uz zvona za sanke i topli uspravni klavir koji ispunjava stih. ```
```

Може се видети да је `data` поље `upsampled_tags` оптимизовани стилски параметar на основу упитних речи.
