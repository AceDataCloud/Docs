SUNO nam omogućava sekundarnu obradu generisane muzike, dobijanje tekstova pesama i vremenske linije audio zapisa. Ovaj dokument objašnjava kako se integrišu povezani API-ji.

Ovaj API ima samo jedan ulazni parametar, a to je `audio_id`, koji predstavlja ID pesme generisane od strane zvaničnog sistema.

Ovde unosimo `audio_id` vrednost `ec13e502-d043-4eb2-92ee-e900c6da69d1`.

```python
import requests

url = "https://api.acedata.cloud/suno/timing"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "ec13e502-d043-4eb2-92ee-e900c6da69d1"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Objašnjenje polja aligned_words

Vidimo da je `data.aligned_words` niz objekata, gde svaki objekat predstavlja reč ili frazu sa vremenskim informacijama.

- `word`: stvarna reč ili fraza iz teksta pesme
- `success`: boolean vrednost koja označava da li je usklađivanje te reči bilo uspešno
- `start_s`: vreme početka reči u sekundama
- `end_s`: vreme završetka reči u sekundama
- `p_align`: verovatnoća ili skor poverenja za usklađivanje, u opsegu od 0 do 1
