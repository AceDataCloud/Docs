Glavna funkcija Suno Tasks API je da omogućava upit o statusu izvršenja zadatka putem ID-a zadatka generisanog Suno Audios Generation API ili Suno Lyrics Generation API.

Ovaj dokument će detaljno opisati uputstva za integraciju Suno Tasks API, pomažući vam da lako integrišete i maksimalno iskoristite moćne funkcije ovog API-ja. Kroz Suno Tasks API, možete lako ostvariti upit o statusu izvršenja zadatka Suno Lyrics Generation API ili Suno Audios Generation API.

## Proces prijave

Da biste koristili Suno Tasks API, prvo treba da odete na stranicu za prijavu [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) i zatražite odgovarajuću uslugu, a zatim kopirajte ID zadatka Suno Audios Generation API, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/bc6754.png" width="500" className="m-auto" /></p>

Na kraju, idite na stranicu Tasks API [Suno Tasks API](https://platform.acedata.cloud/documents/b0dd9823-0e01-4c75-af83-5a6e2e05bfed) i zatražite odgovarajuću uslugu, nakon ulaska na stranicu, kliknite na dugme „Acquire“, kao što je prikazano na slici:

![Stranica za prijavu](https://cdn.acedata.cloud/rci31i.png)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na [stranicu za prijavu](https://platform.acedata.cloud) koja vas poziva da se registrujete i prijavite, a nakon prijave i registracije automatski ćete se vratiti na trenutnu stranicu.

Prilikom prve prijave dobićete besplatnu kvotu koja vam omogućava besplatno korišćenje ovog API-ja.

## Primer zahteva

Suno Tasks API može se koristiti za upit o rezultatima oba API-ja, Suno Audios Generation API i Suno Lyrics Generation API. O tome kako koristiti Suno Audios Generation API, molimo vas da se obratite dokumentu [Suno Audios Generation API](https://platform.acedata.cloud/documents/d016ee3f-421b-4b6e-989a-8beba8701701). O tome kako koristiti Suno Lyrics Generation API, molimo vas da se obratite [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/f1c66741-a488-43ca-91fc-e53fbbda639a).

Uzmimo za primer jedan ID zadatka koji je vratio Suno Audios Generation API i prikažimo kako koristiti ovaj API. Pretpostavimo da imamo ID zadatka: eae26f89-b64b-404d-a80c-761996660b1c, a zatim ćemo prikazati kako proći kroz unos jednog ID-a zadatka.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete direktno izabrati.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se prenosi.
- `action`: način operacije na zadatku.

Postavite kao što je prikazano na slici ispod:

### Primer koda

Možete primetiti da su na desnoj strani stranice automatski generisani kodovi na raznim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/p6vi9o.png" width="500" className="m-auto" /></p>

Neki primeri koda su:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/suno/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "eae26f89-b64b-404d-a80c-761996660b1c",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "eae26f89-b64b-404d-a80c-761996660b1c",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

- `ids`：niz ID-eva zadataka koji se šalju.
- `action`：način rada sa zadatkom.

## Obrada grešaka

Kada pozivate API, ako naiđete na grešku, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravna zahtev, moguće zbog nedostajućih ili neispravnih parametara.
- `400 api_not_implemented`: Neispravna zahtev, moguće zbog nedostajućih ili neispravnih parametara.
- `401 invalid_token`: Neautorizovano, neispravan ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste limit brzine.
- `500 api_error`: Interna greška servera, nešto nije u redu sa serverom.
