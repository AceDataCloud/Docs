Glavna funkcija Suno Tasks API-ja je da, unosom ID-ja zadatka generisanog putem Suno Audios Generation API-ja ili Suno Lyrics Generation API-ja, proveri status izvršavanja tog zadatka.

Ovaj dokument će detaljno predstaviti uputstva za integraciju Suno Tasks API-ja, kako bi vam pomogao da ga lako integrišete i u potpunosti iskoristite moćne funkcionalnosti ovog API-ja. Putem Suno Tasks API-ja možete lako ostvariti proveru statusa izvršavanja zadataka Suno Lyrics Generation API-ja ili Suno Audios Generation API-ja.

## Proces prijave

Da biste koristili Suno Audios Generation API, najpre preuzmite svoj API Token u [Ace Data Cloud konzoli](https://platform.acedata.cloud/console/applications) i sačuvajte ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, bićete automatski preusmereni na stranicu za prijavu, koja će vas pozvati da se registrujete i prijavite, a nakon završetka automatski ćete se vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe za zasebnim podnošenjem prijave za svaku uslugu.** Prilikom prve prijave dobijate besplatni kredit za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti opšti saldo u [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## Primer zahteva

Suno Tasks API može se koristiti za upit rezultata oba API-ja, Suno Audios Generation API i Suno Lyrics Generation API. Za informacije o korišćenju Suno Audios Generation API-ja, pogledajte dokumentaciju [Suno Audios Generation API ](https://platform.acedata.cloud/documents/suno-audios-integration). Za informacije o korišćenju Suno Lyrics Generation API-ja, pogledajte [Suno Lyrics Generation API ](https://platform.acedata.cloud/documents/suno-lyrics-generation-integration).

Uzećemo kao primer jedan ID zadatka koji je vratila usluga Suno Audios Generation API i pokazati kako se koristi ovaj API. Pretpostavimo da imamo ID zadatka: eae26f89-b64b-404d-a80c-761996660b1c, zatim ćemo pokazati kako putem unosa jednog ID-ja zadatka.

### Postavljanje zaglavlja zahteva i tela zahteva

**Request Headers** uključuju:

- `accept`: određuje primanje rezultata odgovora u JSON formatu, ovde unesite `application/json`.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete ga direktno izabrati iz padajuće liste.

**Request Body** uključuje:

- `id`: otpremljeni ID zadatka.
- `action`: način operacije nad zadatkom.

Postavite kao što je prikazano na slici ispod:

<p><img src="https://cdn.acedata.cloud/uo7t6n.png" width="500" className="m-auto" /></p>

### Primer koda

Možete videti da su na desnoj strani stranice automatski generisani kodovi na različitim jezicima, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/p6vi9o.png" width="500" className="m-auto" /></p>

Neki primeri koda su sledeći:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/suno/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "eae26f89-b64b-404d-a80c-761996660b1c",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "eae26f89-b64b-404d-a80c-761996660b1c",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Rezultat vraćanja ukupno sadrži više polja, polje `request` je request body prilikom pokretanja zadatka, dok je polje `response` response body vraćen nakon završetka zadatka. Uvod u polja je sledeći.

- `id`, ID zadatka za generisanje ove pesme, koji se koristi za jedinstvenu identifikaciju ovog zadatka generisanja pesme.
- `request`, informacije o zahtevu u upitu zadatka pesme.
- `response`, informacije o odgovoru u upitu zadatka pesme.
- `created_at`, vreme kreiranja zadatka, Unix vremenska oznaka (sekunde, decimalni broj s pokretnim zarezom).
- `started_at`, vreme početka izvršavanja zadatka, Unix vremenska oznaka (sekunde, decimalni broj s pokretnim zarezom).
- `finished_at`, vreme završetka zadatka, Unix vremenska oznaka (sekunde, decimalni broj s pokretnim zarezom). Ovo polje se ne vraća kada zadatak nije završen.
- `elapsed`, vreme trajanja izvršavanja zadatka, u sekundama (decimalni broj s pokretnim zarezom, zadržavaju se 3 decimale). Ovo polje se ne vraća kada zadatak nije završen.

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, verovatno zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, verovatno zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neovlašćeno, nevažeći ili nedostajući autorizacioni token.
- `429 too_many_requests`: Previše zahteva, premašili ste ograničenje učestalosti.
- `500 api_error`: Interna greška servera, nešto je pošlo po zlu na serveru.
