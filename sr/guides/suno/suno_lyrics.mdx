---
title: "Suno API za generisanje tekstova pesama"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

Ako želite da prilagodite generisanje pesama, ali ne želite da sami pišete tekst, možete koristiti API za generisanje tekstova pesama koji pruža AceDataCloud kako biste generisali tekst putem prompta. API je [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/514d82dc-f7ab-4638-9f21-8b9275916b08).

Glavni ulazni parametar ovog API-ja je `prompt`, opcioni `model` (podrazumevano chirp-v3), primer popunjavanja je sledeći:

![](https://cdn.acedata.cloud/p53wtj.png)

Ovde je naš uneti `prompt` `Pesma o zimi`, generišući pesmu vezanu za zimu.

Kliknite na pokretanje, rezultat je sledeći:

```
{
  "success": true,
  "task_id": "57e8ce3a-39cb-41a2-802f-e70a324f4d0a",
  "data": {
    "text": "[Strofa]\nSnežne pahulje padaju s neba\nZimski hladan dodir\nOh kako me to uzbuđuje\nOblačim se u slojevima\nOh tako udobno\nIzađem napolje i osećam mraz na nosu\nVidi\n\n[Strofa 2]\nSvet je prekriven belim pokrivačem\nSvetlucavi ledenici\nSjaje tako sjajno\nHladan vazduh ispunjava moja pluća sa svakim udahom\nHodajući po snegu\nOstavljajući otiske koji neće biti zaboravljeni\n\n[Refren]\nOh\nZimski hladan dodir\nTo je sezona koju toliko volim\nSnežne padavine donose osećaj tako božanstven\nZimski hladan dodir\nTo je magično vreme",
    "title": "Zimski Hladan Dodir",
    "status": "complete"
  }
}
```

Možete videti da je `text` polje u `data` deo informacija o tekstu pesme.

Kada imamo tekst pesme, možemo koristiti [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) za generisanje prilagođene pesme.
