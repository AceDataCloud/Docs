---
title: "Suno API za generisanje tekstova pesama"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Ako želite da prilagodite generisanje pesama, ali ne želite da sami pišete tekstove, možete koristiti API za generisanje tekstova pesama koji pruža AceDataCloud kako biste generisali tekstove putem prompta. API je [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Glavni ulazni parametar ovog API-ja je `prompt`, opcioni `model` (opcioni vrednosti `default`, `remi-v1`, podrazumevano `default`), primer popunjavanja je sledeći:

![](https://cdn.acedata.cloud/p53wtj.png)

Ovde je naš uneti `prompt` `Pesma o zimi`, generišući pesmu vezanu za zimu.

Kliknite na pokretanje, rezultat je sledeći:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Strofa]\nSnežne pahulje padaju s neba\nZimski hladan dodir\nOh kako me to uzbuđuje\nOblačim se u slojevima\nOh tako udobno\nIzađem napolje i osećam mraz na nosu\n\n[Refren]\nOh\nZimski hladan dodir\nTo je sezona koju toliko volim\nSnežne padavine donose osećaj tako božanstven\nZimski hladan dodir\nTo je magično vreme",
      "title": "Zimski Hladan Dodir",
      "status": "complete",
      "tags": ["sanjivo, mirno, balada"]
    },
    {
      "text": "[Strofa]\nSvet je prekriven belim pokrivačem\nSvetlucavi ledenici\nSjaje tako sjajno\nHladan vazduh ispunjava moja pluća sa svakim udahom\nHodajući po snegu\nOstavljajući otiske iza sebe\n\n[Refren]\nZimska čarobna zemlja\nSve je tako svetlo\nZimska čarobna zemlja\nDrži me kroz noć",
      "title": "Zimska Čarobna Zemlja",
      "status": "complete",
      "tags": ["dream pop, mirno, shoegaze"]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,

```

Može se videti da je `data` niz, koji svaki put vraća više kandidata za tekstove, pri čemu je `text` polje svakog elementa sadržaj teksta, `title` je naslov, a `tags` su preporučene oznake žanra.

Kada imamo tekstove, možemo koristiti [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) za generisanje prilagođenih pesama.
