---
title: "Uputstvo za integraciju Suno API-ja za generisanje tekstova pesama"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Ako želite da prilagođeno generišete pesme, ali ne želite baš sami da pišete tekstove, možete koristiti API za generisanje tekstova pesama koji pruža AceDataCloud za generisanje tekstova putem prompta, API je [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Naplata: nakon uspešnog generisanja, standardna naknada za svaki zahtev je **0.08 Credits**. Kada jedan zahtev vraća više kandidata za tekst pesme, i dalje se naplaćuje samo jednom; primenljivi popusti na potrošnju podležu stvarnom računu, neuspešni zahtevi se ne naplaćuju.

Glavni ulazni parametar ovog API-ja je `prompt`, opciono `model` (opcione vrednosti `default`, `remi-v1`, podrazumevano `default`), primer popunjavanja je sledeći:

![](https://cdn.acedata.cloud/p53wtj.png)

Ovde je `prompt` koji unosimo `A song about winter`, za generisanje pesme povezane sa zimom.

Kliknite na pokretanje, rezultat je sledeći:

```json

  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nSnowflakes falling from the sky\nWinter's cold touch\nOh how it gets me high\nI bundle up in layers\nOh so cozy\nStepping out and feeling the frost on my nose\n\n[Chorus]\nOh\nWinter's cold touch\nIt's a season that I love so much\nSnowfall brings a feeling so divine\nWinter's cold touch\nIt's a magical time",

```

Može se videti da je `data` niz, svaki put vraća više kandidata za tekst pesme, pri čemu je polje `text` svakog elementa sadržaj teksta pesme, `title` je naslov, a `tags` su preporučene oznake muzičkog stila.

Nakon što imamo tekst pesme, možemo koristiti [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) za prilagođeno generisanje pesama.
