title: "Uputstvo za integraciju Suno API-ja za kloniranje glasa"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO nam omogućava da kreiramo prilagođene glasovne persone putem bilo koje audio datoteke, ostvarujući kloniranje glasa za generisanje muzike. Za razliku od postojećeg Persona API-ja (koji koristi `audio_id` generisan pomoću Suno-a), ovaj API prihvata javno dostupan `audio_url`, odnosno vaš sopstveni snimak ljudskog glasa. Ovaj dokument objašnjava način integracije API-ja za kloniranje glasa.

## Prvi korak: Kreiranje glasovne persone

Naplata: Nakon uspešnog kreiranja glasovne persone, standardna naknada za svaki zahtev iznosi **0.15 Credits**. Važeći popusti na potrošnju podležu stvarnom računu, a neuspešni zahtevi se ne naplaćuju.

Ovaj API ima tri ulazna parametra: `audio_url` (obavezan), koji predstavlja javno dostupan URL audio datoteke u MP3 ili WAV formatu koja sadrži jasan ljudski glas jedne osobe; `name` i `description` (opciono), koji predstavljaju naziv i opis glasovne persone.

> **Zahtevi za audio datoteku**
> - Audio format mora biti `WAV` ili `MP3`
> - Trajanje zvuka mora biti između `10~240 sekundi`; preporučuje se korišćenje čistog materijala suvog glasa jedne osobe u trajanju od `30~60 sekundi`
> - Zvuk treba da sadrži **jasan, prepoznatljiv govor ili pevanje jedne osobe**
> - Obavezno izbegavajte **pozadinsku buku, pratnju, eho, reverberaciju**; kompletne pesme sa pratnjom obično ne mogu proći proveru glasovnog otiska
> - Nemojte uključivati **više govornika** ili **višestruke vokale**
> - Materijal sa preniskom jačinom zvuka, nejasnim govorom ili previše buke može dovesti do **neuspešnog kloniranja** ili **lošijeg rezultata generisanja**
> **Objašnjenje ograničenja korišćenja**
> - Glasovne persone kreirane otpremanjem zvuka su **privatni resursi**
> - Ova glasovna persona **ne podržava ponovno korišćenje između naloga**
> - Preporučuje se da je koristite što pre nakon uspešnog kreiranja; ako se ne koristi duže vreme, može **isteći ili postati nedostupna**
> - Vraćeni `name` sistem generiše automatski; koristite vraćeni `persona_id` kao merodavan

> **Prvo pokušajte ponovo kada poziv ne uspe**
> Kloniranje glasa je zadatak koji intenzivno koristi računarske resurse; čak i ako materijal u potpunosti ispunjava zahteve, postoji određena verovatnoća povremenog neuspeha, sa uobičajenim povratnim vrednostima kao što je
> `voices_sound_different` (provera glasovnog otiska nije prošla) itd. **Ovakvi neuspesi nisu povezani sa kvalitetom zvuka; ponovni pokušaj sa istim materijalom obično može uspeti**,
> preporučuje se da pri integraciji implementirate 1~2 automatska ponovna pokušaja za neuspešne rezultate. Neuspešni zahtevi se ne naplaćuju.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Gorenavedeni `https://cdn.acedata.cloud/suno_demo.mp3` je primer materijala koji se može direktno pozvati (MP3, 41 sekunda, suvi glas jedne osobe).
> Ako vam je potreban primer u `WAV` formatu, možete koristiti
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 sekunda, mono 44.1kHz).

Rezultat je sledeći:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Može se videti da je polje `persona_id` u `data` upravo ID kreirane glasovne persone. Polje `is_public` je uvek `false`, zato što su glasovne persone kreirane otpremanjem zvuka privatne. Imajte na umu da sistem automatski generiše vraćeni `name`; ubuduće koristite `persona_id` za upućivanje na tu glasovnu personu.

## Drugi korak: Generisanje muzike korišćenjem glasovne persone

Nakon što dobijemo ID glasovne persone, možemo koristiti [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) za generisanje muzike. Postavite `action` na `generate`, a `persona_id` na ID glasovne persone vraćen iznad; generisana pesma će koristiti klonirani glas za pevanje.

> **Napomena:** Kloniranje glasa podržava samo modele `chirp-v4-5` i novije (kao što su `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), a ne podržava `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Rezultat je sledeći:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` se može koristiti za generisanje pomoću `generate`, a može se koristiti i za obrade `cover` / `upload_cover`. Prilikom navođenja glasa nije potrebno istovremeno popuniti `vocal_gender`; sličnost glasa i dalje zavisi od referentnog materijala i rezultata generisanja.

Glasovi kreirani putem ovog interfejsa su privatni resursi. Pre obrade postojeće pesme, prvo pozovite `/suno/upload` i prosledite `audio_url` originalne pesme i `persona_id` tog glasa; nakon uspešnog otpremanja, pozovite `/suno/audios` pomoću vraćenog `data.audio_id` i istog `persona_id`:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

Kreiranje glasa, otpremanje originalne pesme i obrada moraju koristiti isti servisni kanal. Nemojte direktno ponovo koristiti ID pesme koji prethodno nije bio povezan sa ovim privatnim glasom; za detalje pogledajte [Suno otpremanje referentnog zvuka](https://platform.acedata.cloud/documents/suno-upload).
