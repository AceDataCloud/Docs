SUNO nam omogućava kreiranje prilagođenih glasovnih likova pomoću bilo koje audio datoteke, ostvarujući kloniranje glasa za generisanje muzike. Za razliku od postojećeg Persona API-ja (koji koristi `audio_id` generisan od strane Suno), ovaj API prihvata javno dostupan `audio_url`, tj. vaš sopstveni snimak glasa. Ovaj dokument opisuje kako integrisati API za kloniranje glasa.

## Prvi korak: Kreiranje glasovnog lika

Ovaj API ima tri ulazna parametra: `audio_url` (obavezno), koji je URL javno dostupne MP3 ili WAV audio datoteke sa jasnim glasom jedne osobe; `name` i `description` (opciono), koji predstavljaju ime i opis glasovnog lika.

**Zahtevi za audio datoteku:**
- Format: MP3 ili WAV
- Trajanje: najmanje 10 sekundi
- Sadržaj: jasni glas jedne osobe, sa što manje pozadinske buke ili muzike

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

Rezultat izgleda ovako:

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

Vidimo da je vrednost `persona_id` u `data` polju ID kreiranog glasovnog lika. Polje `is_public` je uvek `false`, jer su glasovni likovi kreirani otpremanjem audio zapisa privatni.

## Drugi korak: Generisanje muzike korišćenjem glasovnog lika

Kada imamo ID glasovnog lika, možemo koristiti [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) za generisanje muzike. Postavite `action` na `generate`, a `persona_id` na prethodno dobijeni ID glasovnog lika. Generisane pesme će biti pevane kloniranim glasom.

> **Napomena:** Kloniranje glasa podržano je samo za modele `chirp-v4-5` i novije (npr. `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), nije podržano za `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

Rezultat izgleda ovako:

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

Vidimo da je generisana pesma pevana kloniranim glasom. `persona_id` se takođe može koristiti sa `cover` akcijom za pevanje postojećih pesama kloniranim glasom.
