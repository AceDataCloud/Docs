SUNO nam omogućava da putem bilo koje audio datoteke kreiramo prilagođeni glasovni lik, ostvarujući kloniranje glasa za generisanje muzike. Za razliku od postojećeg Persona API-ja (koji koristi `audio_id` generisan pomoću Suno-a), ovaj API prihvata javno dostupan `audio_url`, odnosno vaš sopstveni snimak ljudskog glasa. Ovaj dokument objašnjava metod integracije API-ja za kloniranje glasa.

## Prvi korak: Kreiranje glasovnog lika

Ovaj API ima tri ulazna parametra: `audio_url` (obavezan), koji predstavlja javno dostupan URL audio datoteke u MP3 ili WAV formatu, a koja sadrži jasan ljudski glas jedne osobe; `name` i `description` (opciono), koji predstavljaju naziv i opis glasovnog lika.

> **Zahtevi za audio datoteku**
> - Audio format mora biti `WAV` ili `MP3`
> - Trajanje zvuka mora biti između `10~240 sekundi`; preporučuje se korišćenje čistog materijala suvog glasa jedne osobe u trajanju od `30~60 sekundi`
> - Audio treba da sadrži **jasan, prepoznatljiv govor ili pevanje jedne osobe**
> - Obavezno izbegavajte **pozadinsku buku, pratnju, eho, reverberaciju**; kompletne pesme sa pratnjom obično ne mogu proći proveru glasovnog otiska
> - Nemojte uključivati **više govornika** ili **višestruke vokale**
> - Materijali sa preniskom jačinom zvuka, nejasnim govorom ili previše buke mogu dovesti do **neuspeha kloniranja** ili **lošijeg efekta generisanja**
> **Objašnjenje ograničenja korišćenja**
> - Glasovni likovi kreirani otpremanjem zvuka su **privatni resursi**
> - Ovaj glasovni lik **ne podržava ponovno korišćenje između naloga**
> - Preporučuje se da ga koristite što pre nakon uspešnog kreiranja; ako se ne koristi duže vreme, može postati **nevažeći ili nedostupan**
> - Vraćeni `name` sistem automatski generiše; merodavan je vraćeni `persona_id`

> **Kada poziv ne uspe, prvo pokušajte ponovo**
> Kloniranje glasa je zadatak koji zahteva intenzivne računarske resurse; čak i kada je materijal potpuno usklađen, postoji određena verovatnoća povremenog neuspeha, sa uobičajenim povratnim vrednostima kao što je
> `voices_sound_different` (provera glasovnog otiska nije prošla) i slično. **Ovakvi neuspesi nisu povezani sa kvalitetom zvuka; ponovno pokušavanje sa istim materijalom obično može uspeti**,
> preporučuje se implementacija 1~2 automatska ponovna pokušaja za neuspele rezultate tokom integracije. Neuspeli zahtevi se ne naplaćuju.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Gorenavedeni `https://cdn.acedata.cloud/suno_demo.mp3` predstavlja primer materijala koji se može direktno pozvati (MP3, 41 sekunda, suvi glas jedne osobe).
> Ako vam je potreban primer u formatu `WAV`, možete koristiti
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 sekunda, mono 44.1kHz).

Rezultat je sledeći:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Može se videti da je polje `persona_id` u `data` upravo ID kreiranog glasovnog lika. Polje `is_public` je uvek `false`, zato što su glasovni likovi kreirani otpremanjem zvuka privatni. Imajte na umu da sistem automatski generiše vraćeni `name`; ubuduće koristite `persona_id` za referenciranje ovog glasovnog lika.

## Drugi korak: Korišćenje glasovnog lika za generisanje muzike

Nakon što imamo ID glasovnog lika, možemo koristiti [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) za generisanje muzike. Postavite `action` na `generate`, a `persona_id` na ID glasovnog lika vraćen iznad; generisane pesme će koristiti klonirani glas za pevanje.

> **Napomena:** Kloniranje glasa podržava samo modele `chirp-v4-5` i novije (kao što su `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), a ne podržava `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Rezultat je sledeći:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` se može koristiti za generisanje `generate`, kao i za obradu `cover` / `upload_cover`. Pri određivanju glasa nije potrebno istovremeno popunjavati `vocal_gender`; sličnost glasa i dalje zavisi od referentnog materijala i rezultata generisanja.

Glasovi kreirani putem ovog interfejsa su privatni resursi. Pre obrade postojeće pesme, prvo pozovite `/suno/upload` i prosledite `audio_url` originalne pesme i `persona_id` tog glasa; nakon uspešnog otpremanja, pozovite `/suno/audios` sa vraćenim `data.audio_id` i istim `persona_id`:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

Kreiranje glasa, otpremanje originalne pesme i obrada moraju koristiti isti servisni kanal. Nemojte direktno ponovo koristiti ID pesme koji prethodno nije bio povezan sa ovim privatnim glasom; za detalje pogledajte [Suno otpremanje referentnog zvuka](https://platform.acedata.cloud/documents/suno-upload).
