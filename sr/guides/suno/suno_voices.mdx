---

SUNO nam omogućava da kreiramo prilagođene zvučne likove putem bilo kog audio fajla, ostvarujući kloniranje zvuka za generisanje muzike. Za razliku od postojećeg Persona API-ja (koji koristi `audio_id` generisan od strane Suno), ovaj API prihvata javno dostupnu `audio_url`, tj. vašu ličnu audio snimku. Ovaj dokument objašnjava način integracije API-ja za kloniranje zvuka.

Ovaj API ima tri ulazna parametra: `audio_url` (obavezno), koji je URL javno dostupnog MP3 ili WAV formata audio fajla, koji sadrži jasnu ljudsku vokalnu snimku jedne osobe; `name` i `description` (opciono), koji su naziv i opis zvučnog lika.

**Zahtevi za audio fajlove:**

- Format: MP3 ili WAV
- Trajanje: najmanje 10 sekundi
- Sadržaj: jasna ljudska vokalna snimka jedne osobe, sa minimalnom pozadinskom bukom ili muzikom

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://example.com/my-vocal-recording.mp3",
  "name": "Moj Glas",
  "description": "Topao muški glas"
}'
```

Rezultat je sledeći:

```json
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dde0be60-5280-4bd2-89a0-4020ddd3db52",
    "name": "Moj Glas",
    "is_public": false
  }
}
```

Može se primetiti da je `persona_id` polje u `data` kreiranog zvučnog lika ID. Polje `is_public` je uvek `false`, jer su zvučni likovi kreirani putem otpremanja audio fajlova privatni.

Kada dobijemo ID zvučnog lika, možemo koristiti [Suno API za generisanje audio](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) za generisanje muzike. Postavite `action` na `vox`, a `persona_id` na vrednost koja je vraćena iznad, a generisana pesma će koristiti klonirani glas za izvođenje.
