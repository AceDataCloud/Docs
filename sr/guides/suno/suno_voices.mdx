SUNO nam omogućava kreiranje prilagođenih glasovnih likova pomoću bilo koje audio datoteke, za potrebe kloniranja glasa u generisanju muzike. Za razliku od postojećeg Persona API-ja (koji koristi `audio_id` generisan od strane Suno-a), ovaj API prihvata javno dostupan `audio_url`, tj. vašu sopstvenu snimljenu ljudsku glasovnu datoteku. Ovaj dokument objašnjava kako integrisati API za kloniranje glasa.

## Prvi korak: Kreiranje glasovnog lika

Ovaj API ima tri ulazna parametra: `audio_url` (obavezno), što je URL javno dostupne MP3 ili WAV audio datoteke koja sadrži jasan glas jedne osobe; `name` i `description` (opciono), koji predstavljaju ime i opis glasovnog lika.

**Zahtevi za audio datoteku:**
- Format: MP3 ili WAV
- Trajanje: najmanje 10 sekundi
- Sadržaj: jasan glas jedne osobe, sa što manje pozadinske buke ili muzike

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "http://cos.aitutu.cc/mp4/ru-user-voice.mp3",
  "name": "RU User Voice Test",
  "description": "用户语音录音示例"
}'
```

Rezultat izgleda ovako:

```json
{
  "success": true,
  "task_id": "b9150e51-d87c-4556-a55e-100947a63bdf",
  "data": {
    "persona_id": "e95013f8-eaee-4741-a42f-1d559a9d0b2b",
    "name": "RU User Voice Test",
    "is_public": false
  }
}
```

Vidimo da je polje `persona_id` u `data` ID kreiranog glasovnog lika. Polje `is_public` je uvek `false`, jer su glasovni likovi kreirani otpremanjem audio zapisa privatni.

## Drugi korak: Generisanje muzike korišćenjem glasovnog lika

Kada imamo ID glasovnog lika, možemo koristiti [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) za generisanje muzike. Postavite `action` na `generate` i `persona_id` na prethodno dobijeni ID glasovnog lika, a generisana pesma će biti izvedena kloniranim glasom.

> **Napomena:** Kloniranje glasa podržano je samo za modele `chirp-v4-5` i novije verzije (kao što su `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), nije podržano za `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "e95013f8-eaee-4741-a42f-1d559a9d0b2b"
}'
```

Rezultat izgleda ovako:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn1.suno.ai/16463960-077c-4700-bbb3-3c7897b943d3.mp3",
      "image_url": "https://cdn2.suno.ai/image_16463960-077c-4700-bbb3-3c7897b943d3.jpeg",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

Vidimo da je generisana pesma izvedena kloniranim glasom. `persona_id` se takođe može koristiti sa akcijom `cover` za obradu postojećih pesama koristeći klonirani glas.
