SUNO nam omogućava da kreiramo novu verziju Persona-v2-vox: stil pevača, koja se razlikuje od stare verzije po tome što je potrebno prvo dobiti `vox_audio_id`. Ovaj dokument objašnjava metod integracije za kreiranje nove verzije Persona-v2-vox.

Najpre je potrebno koristiti ovaj API za dobijanje vrednosti parametra `vox_audio_id`; ovaj API može da prihvati više ulaznih parametara, kao što su `audio_id`, `vocal_start` i `vocal_end`, koji predstavljaju ID referentne pesme i izabrani vremenski opseg.

Ovde je `audio_id` koji unosimo `42599b24-fb14-4cd3-a444-e15ffde3661b`.

```python
import requests

url = "https://api.acedata.cloud/suno/vox"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Može se videti da je polje `id` u okviru `data` upravo `vox_audio_id` koji nam je potreban, a zatim idemo na [Persona API](https://platform.acedata.cloud/documents/suno-persona) da kreiramo novu verziju Persona-v2-vox: stil pevača, sa konkretnim unosom prikazanim u nastavku:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "test",
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20,
    "vox_audio_id": "24f0827e-5847-4011-b9b7-fc0b62032b65"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Nakon poziva dobija se sledeći rezultat:

```json
{
  "success": true,
  "task_id": "e04b06a1-ff61-48e2-9fcc-15284bd18481",
  "data": {
    "persona_id": "49bef16d-6a09-49d1-8c24-a81663698b98"
  }
}
```

Zatim možemo da koristimo gorenavedenu vrednost `persona_id` za kreiranje nove verzije Persona-v2-vox: stil pevača. Konkretan metod kreiranja je isti kao u [Uputstvu za integraciju Suno API-ja za generisanje pesama](https://platform.acedata.cloud/documents/suno-audios-integration#%E8%87%AA%E5%AE%9A%E4%B9%89%E6%AD%8C%E6%89%8B%E9%A3%8E%E6%A0%BC%E7%94%9F%E6%88%90%E5%8A%9F%E8%83%BD), a na kraju možemo koristiti Suno Vox API da bismo kreirali pesme sa novom verzijom Persona-v2-vox: stil pevača.
