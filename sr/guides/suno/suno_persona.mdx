---
title: "Uputstvo za integraciju Suno API-ja za prilagođeni stil pevača"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO nam omogućava da pesmama koje su već generisane postavimo stil pevača, a zatim na osnovu njega izvršimo sekundarnu kreaciju, ovaj dokument objašnjava metod integracije relevantnog API-ja.

`GET /suno/persona` upit liste i `DELETE /suno/persona` brisanje zapisa se ne naplaćuju, nije potreban dodatni zaglavlje zahteva za oslobađanje od naplate. Operacija kreiranja `POST /suno/persona` se i dalje naplaćuje prema pravilima određivanja cene interfejsa.

Ovaj API ima samo tri ulazna parametra, prvo `audio_id`, to je ID pesme koja je već uspešno generisana zvaničnim putem, zatim `name` i `description`, to su naziv i opis stila pevača.

Ovde je `audio_id` koji unosimo `https://cdn.acedata.cloud/2qhzs3.png`, za ovo možete pogledati [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) radi prilagođenog generisanja pesme, na kraju se može dobiti `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Rezultat je sledeći:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Može se videti da je polje `persona_id` u `data` ID generisanog stila pevača.

Nakon što imamo ID stila pevača, možemo koristiti [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) za prilagođeno generisanje pesme, na primer, proslediti `artist_consistency` za `action`, istovremeno proslediti ID otpremljene pesme za `audio_id`, a takođe je potrebno otpremiti parametar `persona_id`, čija je vrednost ID stila pevača vraćen iznad, pa se na osnovu referentnog stila pevača može generisati nova pesma.
