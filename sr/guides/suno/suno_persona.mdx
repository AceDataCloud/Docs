---
title: "Suno prilagođavanje stila pevača API integracija"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

SUNO nam omogućava da postavimo stil pevača za već generisane pesme, a zatim da na osnovu toga izvršimo drugu kreativnu obradu. Ovaj dokument objašnjava metode integracije relevantnog API-ja.

Ovaj API ima samo tri ulazna parametra, prvo `audio_id`, koji je ID pesme koja je uspešno generisana od strane zvanične platforme, zatim `name` i `description`, koji predstavljaju naziv i opis stila pevača.

Ovde unosimo `audio_id` kao `https://cdn.acedata.cloud/2qhzs3.png`, što možete pogledati u [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) za generisanje prilagođenih pesama, a na kraju možete dobiti `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Rezultat je sledeći:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Može se videti da je `data` polje `persona_id` ID stila pevača koji je generisan.

Kada imamo ID stila pevača, možemo koristiti [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) za generisanje prilagođenih pesama, na primer, `action` se prosledi kao `artist_consistency`, dok se `audio_id` prosledi kao ID otpremljene pesme, takođe je potrebno proslediti parametar `persona_id`, čija je vrednost ID stila pevača dobijen iz prethodnog odgovora, i tako možemo generisati nove pesme prema referentnom stilu pevača.
