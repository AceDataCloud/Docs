---
title: "Uputstvo za integraciju Suno API-ja za prilagođeni stil pevača"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO nam omogućava da postavimo stil pevača za već generisane pesme, a zatim da na osnovu njega izvršimo sekundarno stvaranje, ovaj dokument objašnjava metod integracije povezanog API-ja.

Upit liste putem `GET /suno/persona` i brisanje zapisa putem `DELETE /suno/persona` se ne naplaćuju i ne zahtevaju dodatno zaglavlje zahteva za izuzimanje od naplate. Operacija kreiranja putem `POST /suno/persona` se i dalje naplaćuje prema pravilima određivanja cene interfejsa.

Na liniji za kreiranje koja podržava upit boje glasa, možete koristiti originalnu aplikaciju i identitet pozivaoca da prosledite `persona_id` iz rezultata kreiranja u `POST /suno/availability`. Kada se potvrdi dostupnost, vraća se `data.available=true`. [Vodič za upit dostupnosti boje glasa](https://platform.acedata.cloud/documents/suno-availability-integration)

Ovaj API ima samo tri ulazna parametra, najpre `audio_id`, to je ID pesme koja je već uspešno generisana u zvaničnom sistemu, zatim `name`, `description`, oni predstavljaju naziv i opis stila pevača.

Ovde je `audio_id` koji unosimo `https://cdn.acedata.cloud/2qhzs3.png`, možete se pozvati na [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) da izvršite prilagođeno generisanje pesme, na kraju možete dobiti `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Rezultat je sledeći:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Može se videti da je polje `persona_id` u `data` ID generisanog stila pevača.

Nakon što imamo ID stila pevača, možemo koristiti [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) za prilagođeno generisanje pesme, na primer, prosledite `artist_consistency` za `action`, istovremeno prosledite ID otpremljene pesme za `audio_id`, potrebno je takođe otpremiti parametar `persona_id`, ova vrednost je ID stila pevača vraćen iznad, pa se može generisati nova pesma na osnovu referentnog stila pevača.
