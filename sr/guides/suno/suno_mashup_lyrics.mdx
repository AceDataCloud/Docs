---
title: "Suno API za generisanje mešavine tekstova pesama"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Ako želite da koristite tekstove dve pesme za generisanje mešane pesme, možete prvo koristiti ovaj API za generisanje odgovarajućih tekstova, API je [Suno MashupLyrics Generation API](https://platform.acedata.cloud/documents/suno-mashup-lyrics).

Glavni ulazni parametri ovog API-ja su `lyrics_a`, `lyrics_b`, primer popunjavanja je prikazan u nastavku:

![](https://cdn.acedata.cloud/g9n3t6.png)

Kliknite na pokretanje, rezultat je sledeći:

```
{
  "success": true,
  "task_id": "80aa3cd3-ca87-4ca3-82d2-1830e3d8f53a",
  "data": {
    "text": "Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nSambuy come, Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \nSambuy come back",
    "title": "Lyrics Mashup",
    "tags": [],
    "status": "complete"
  }
}
```

Možete videti da je `text` polje u `data` sekciji informacija o tekstu pesme.

Kada imamo tekst pesme, možemo koristiti [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) za generisanje prilagođene pesme.
