Suno MP3 URL API генерише путanju за већ постојећу музику која завршава са `.mp3`, погодна за сценарије где стари преузимајући линкови не функционишу, за репродукцију на мобилним уређајима или када је потребно поново добити јавни аудио URL.

Обавезан параметар `audio_id` је ID аудио записа који враћа Suno аудио генерисање интерфејса. Сваког пута када се позове, креираће независан MP3 URL задатак, неће модификовати оригинални музички генерисање задатак, нити ће променити оригинални аудио ID.

## Синхроно позивање

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={
        "accept": "application/json",
        "authorization": "Bearer <YOUR_API_TOKEN>",
        "content-type": "application/json"
    },
    json={"audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f"},
    timeout=240
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["file_url"])
```

Успешно, `data[0].file_url` је адреса за репродукцију аудио записа. Интерфејс ће прво покушати да сачува на `https://cdn.acedata.cloud/suno/{audio_id}.mp3`; ако упис не успе, враћа тренутно доступну оригиналну медијску адресу.

## Асинхроно позивање

Када је време обраде дуже, можете проследити `async: true`:

```python
submission = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={"authorization": "Bearer <YOUR_API_TOKEN>"},
    json={
        "audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f",
        "async": True
    }
).json()

export_task_id = submission["task_id"]
```

Након тога, можете проверити `export_task_id` преко `/suno/tasks`. Такође можете пружити `callback_url`, да примите коначни резултат након завршетка задатка. Синхрони одговори, упити задатака и повратне информације користе исту структуру података.

## Напомене

- `audio_id` мора бити из идентификованог Suno аудио записа.
- MP3 URL задаци су независни од оригиналних музичких генерисања задатака.
- Неуспех уписа неће блокирати резултат, враћаће се на оригиналну медијску адресу; молимо вас да преузмете на време.
- Препоручује се да пословна страна преузме резултате на време и сачува их према својој стратегији чувања података.
