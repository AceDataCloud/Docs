---
title: "API za proveru dostupnosti Suno zvuka"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

`POST /suno/availability` na osnovu `audio_id` traži pozitivne dokaze da se zvuk može nastaviti obrađivati na trenutnoj ruti. Može se pozvati pre operacija kao što su nastavak pisanja i obrada; rezultat odražava samo stanje u trenutku provere i ne garantuje uspeh određene operacije. Ovaj interfejs vraća rezultat sinhrono, zahteva API token i trenutno ne troši Credits.

`audio_id` je ID pesme vraćen iz završenog Suno zadatka, a ne `task_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

Primer uspešnog odgovora:

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

Kada je provera uspešna, `data.available` je `true`; kada potvrda nije moguća, vraća se `503 availability_unknown`, bez `false`. Neispravan format za `audio_id` vraća 400, a ograničenje broja zahteva ili greška servisa takođe vraćaju odgovor s greškom. Stanje se i dalje može promeniti između završetka provere i stvarne operacije.
