---
title: "API za proveru dostupnosti Suno zvuka"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

`POST /suno/availability` na osnovu `audio_id` traži pozitivne dokaze da se zvuk može nastaviti obrađivati na trenutnoj liniji. Može se pozvati pre operacija kao što su nastavak pisanja, obrada naslovne verzije itd.; rezultat odražava samo stanje u trenutku provere i ne garantuje da će određena konkretna operacija sigurno uspeti. Ovaj interfejs vraća odgovor sinhrono, zahteva API Token i trenutno ne naplaćuje Credits.

`audio_id` je ID pesme vraćen iz završenog Suno zadatka, a nije `task_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

Primer uspešnog odgovora:

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

Kada je provera uspešna, `data.available` može biti samo `true`. Status „van mreže” koji vraćaju neke linije ne može dokazati da naknadne operacije, kao što je nastavak pisanja, ne mogu uspeti, stoga ovaj interfejs vraća `503 availability_unknown` kada nije moguće potvrditi, i neće vratiti `false`. Greška formata `audio_id` vraća 400, a ograničenje protoka ili kvar uzvodnog servisa takođe vraćaju odgovor sa greškom. Stanje se i dalje može promeniti između završetka provere i stvarne operacije.
