SUNO nam omogućava da dobijemo muzičke fajlove u wav formatu, a ovaj dokument objašnjava način integracije odgovarajućeg API-ja.

Osnovni ulazni parametar ovog API-ja je `audio_id`, koji je ID pesme generisan od strane zvanične službe; opciono se podržava i `callback_url` za asinhroni povratni poziv.

Ovde je uneti `audio_id` vrednost `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer aa287fa4cc54401087a9fab3f99630af",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Rezultat je sledeći:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://platform.cdn.acedata.cloud/suno/6a5a2099-d6d3-4930-9709-a30ac5dc7de5.wav"
    }
  ]
}
```

Možemo videti da je polje `file_url` u `data` muzički fajl u wav formatu koji je dobijen, a to je javno dostupan CDN link.

> **O čuvanju i važenju WAV linka**
>
> WAV fajlovi na Suno CDN-u izvornog provajdera (`https://cdn1.suno.ai/{audio_id}.wav`) se čuvaju samo nekoliko dana, nakon čega se brišu i pristup vraća 403 grešku.
> Da bi se izbeglo istecanje linka, ovaj API automatski premešta WAV fajl sa izvornog CDN-a na naš sopstveni CDN (`https://platform.cdn.acedata.cloud/suno/{task_id}.wav`) pre nego što vrati odgovor. Povratni `file_url` je stabilna adresa premeštenog fajla i neće odmah isteći zbog isteka izvornog CDN-a.
> **Važenje premeštenog linka je 30 dana**, nakon čega se fajl periodično briše. Preporučuje se da fajl što pre preuzmete i sačuvate na sopstvenom skladištu.
> U retkim slučajevima neuspeha premeštanja, vraća se originalni izvorni URL, što je dosledno prethodnom ponašanju.
