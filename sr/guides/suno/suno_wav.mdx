SUNO nam omogućava da dobijemo muzičke fajlove u wav formatu, a ovaj dokument objašnjava metode integracije odgovarajućeg API-ja.

Osnovni ulazni parametar ovog API-ja je `audio_id`, koji predstavlja ID pesme generisan od strane zvanične službe; opciono se može koristiti i `callback_url` za asinhroni povratni poziv.

Ovde je uneti `audio_id` vrednost `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer aa287fa4cc54401087a9fab3f99630af",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Rezultat je sledeći:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://platform.cdn.acedata.cloud/suno/6a5a2099-d6d3-4930-9709-a30ac5dc7de5.wav"
    }
  ]
}
```

Možemo videti da je `file_url` polje unutar `data` adresa do wav fajla muzičkog zapisa, koja je javno dostupna CDN adresa.

> **O trajnosti WAV linka**
>
> WAV fajlovi na Suno CDN-u izvora (`https://cdn1.suno.ai/{audio_id}.wav`) se čuvaju samo nekoliko dana, nakon čega se brišu i pristup im vraća 403 grešku.
> Da bi se izbeglo istecanje linka, ovaj API automatski prebacuje WAV fajl sa izvornog CDN-a na naš sopstveni CDN (`https://platform.cdn.acedata.cloud/suno/{task_id}.wav`) pre nego što vrati odgovor. Vraćeni `file_url` je stabilna adresa prebačenog fajla i neće isteći zbog isteka izvornog CDN-a.
> U retkim slučajevima neuspeha prebacivanja, vraća se originalni URL izvornog CDN-a, što je u skladu sa prethodnim ponašanjem.
