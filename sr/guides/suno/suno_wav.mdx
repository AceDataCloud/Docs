SUNO нам омогућава да добијемо музичке wav формат фајлове, овај документ објашњава методе интеграције релевантних API-ја.

Кључни улазни параметар овог API-ја је `audio_id`, који је званично генерисани ID песме; опционално подржава и `callback_url` асинхрони повратни адреса.

Овде уносимо `audio_id` који је `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer YOUR_API_KEY",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Резултат је следећи:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://cdn.acedata.cloud/suno/41572926-1a7a-41bc-adb8-9431e494c144.wav"
    }
  ]
}
```

Можемо видети да је `data` поље `file_url` добијени музички wav формат фајл, који је јавна CDN адреса.

> **О перзистенцији WAV линка**
> Платформа ће пре враћања прво перзистирати завршни WAV фајл на Ace Data Cloud CDN. Горња URL адреса само показује формат одговора, не представља дугорочни реални објекат. Само ако перзистенција на CDN није завршена, а оригинална медијска адреса је тренутно проверена и и даље може да се преузме валидан WAV фајл, `file_url` може задржати ту адресу; ако адреса више није валидна или је проверка фајла неуспешна, захтев ће вратити неуспех или истек, неће се неприступачна адреса сматрати успешним резултатом. Молимо вас да преузмете и правилно сачувате након завршетка задатка, конкретно време чувања зависи од тренутне стратегије складиштења платформе.
