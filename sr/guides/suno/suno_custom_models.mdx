Prilagođeni muzički modeli mogu učiti dosledne muzičke karakteristike iz 6 do 24 licencirana audio zapisa i koristiti ih za naknadno stvaranje pesama. Kreiranje je asinhrona operacija; preporučuje se korišćenje 24 audio zapisa doslednog stila i jasnog kvaliteta zvuka za stabilnije rezultate.

> Mogu se poslati samo audio zapisi za koje imate zakonsko pravo korišćenja ili ste dobili ovlašćenje za kreiranje modela i naknadno generisanje. Nemojte otpremati muziku ili zvučne materijale bez dozvole.

## Kreiranje modela

Pozovite `POST /suno/custom-models` i postavite `action=create`:

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

Interfejs odmah vraća ID modela platforme i ID zadatka. Nakon završetka kreiranja, `status` u povratnom pozivu ili rezultatu upita će postati `ready`. Samo uspešno kreiranje modela se naplaćuje **10 Credits**; neuspešno kreiranje se ne naplaćuje.

## Upit modela

Upit jednog modela:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Stranični upit modela trenutne aplikacije:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Svi modeli pripadaju Suno aplikaciji koja ih je kreirala. Rotacija API akreditiva ne menja pripadnost modela, a druge aplikacije ne mogu upitati niti koristiti taj model.

## Korišćenje modela za generisanje pesama

Nakon što status modela postane `ready`, nastavite sa pozivanjem `POST /suno/custom-models` i postavite `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id` mora biti prilagođeni muzički model sa statusom `ready` u trenutnoj aplikaciji. Zahtev će neuspešno završiti kada model nije dostupan i neće automatski koristiti drugi model. `persona_id` je međusobno isključiv sa prilagođenim muzičkim modelom; kada se pošalju istovremeno, interfejs će vratiti HTTP 400 pre nego što zahtev bude poslat servisu za generisanje i neće biti naplate. Ako treba da koristite Persona, umesto toga koristite operaciju `artist_consistency` ili `artist_consistency_vox` na `/suno/audios`.

Uspešno generisanje pesme troši **0.90 Credits**; neuspešno generisanje se ne naplaćuje. Upiti i arhiviranje modela su besplatni.

## Arhiviranje modela

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Trenutna Beta verzija arhivira model i zabranjuje njegovu dalju upotrebu, a `capacity_released=false` u odgovoru označava da arhiviranje ne garantuje oslobađanje kapaciteta modela. Operacija arhiviranja može se pozvati više puta i neće biti ponovo naplaćena.
