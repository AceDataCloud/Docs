Ovaj članak će predstaviti uputstvo za integraciju Gemini Videos Generation API-ja, koji može da generiše Google Gemini (omni-flash) video zapise putem unosa tekstualnih promptova (i opcionih referentnih slika).

## Proces prijave

Da biste koristili Gemini Videos Generation API, prvo idite u [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications) da biste dobili svoj API Token i sačuvali ga za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako se još niste prijavili ili registrovali, automatski ćete biti preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a po završetku ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, nije potrebno posebno se prijavljivati za svaku uslugu.** Pri prvoj prijavi dobijate besplatni kredit za besplatno isprobavanje; kada kredit nije dovoljan, možete dopuniti opšti saldo u [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Osnovna upotreba

Hajde da prvo upoznamo osnovni način upotrebe, unesite prompt `prompt`, model `model` i odnos širine i visine `aspect_ratio`, pa možete generisati odgovarajući video.

Ovde možemo videti da smo postavili Request Headers, uključujući:

- `accept`: koji format rezultata odgovora želite da primite, ovde se unosi `application/json`, odnosno JSON format.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete ga direktno odabrati iz padajućeg menija.

Takođe smo postavili Request Body, uključujući:

- `prompt`: tekstualni prompt koji opisuje sadržaj videa koji želite da generišete, **obavezno**.
- `model`: model za generisanje videa, trenutno podržava samo `omni-flash`, podrazumevano je `omni-flash`.
- `aspect_ratio`: odnos širine i visine generisanog videa, može biti `16:9` (horizontalno) ili `9:16` (vertikalno), podrazumevano `16:9`.
- `resolution`: opciona izlazna rezolucija, može biti `720p` ili `1080p`, podrazumevano `720p`.
- `image_urls`: opcioni niz linkova referentnih slika, koristi se za usmeravanje generisanja videa, prazne stavke će biti ignorisane. Kada se `video_urls` koristi za uređivanje videa, ovaj parametar je obavezan (najmanje jedna slika).
- `video_urls`: opcioni niz linkova referentnih videa (najviše 1), koristi se za **uređivanje videa / referencu videa**; kada je naveden, mora se istovremeno navesti najmanje jedna `image_urls`.
- `callback_url`: adresa asinhronog povratnog poziva, nakon postavljanja API će odmah vratiti `task_id`, a kada se zadatak završi, rezultat će biti POST-ovan na tu adresu.
- `async`: opciono, kada se postavi na `true`, interfejs odmah vraća `task_id`, nije potrebno navesti `callback_url`, a zatim se rezultat dobija anketiranjem odgovarajućeg interfejsa za upit zadatka.

Kliknite na dugme „Try“ da biste izvršili test, a dobijeni rezultat je sličan sledećem:

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904-418c13e0605f.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden"
    }
  ],
  "started_at": 1784112953.856,
  "finished_at": 1784113021.328,
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Povratni rezultat ukupno sadrži više polja, koja su opisana kako sledi:

- `success`: da li je ovaj zahtev za generisanje videa uspešan.
- `task_id`: ID ovog zadatka generisanja videa.
- `trace_id`: ID praćenja ovog zahteva, koristi se za otklanjanje problema.
- `data`: lista rezultata generisanih videa.
  - `id`: jedinstveni identifikator generisanog videa.
  - `video_url`: adresa linka generisanog videa (kada je `state` `pending`, vrednost je `null`).
  - `state`: status zadatka generisanja videa, može biti `pending` / `succeeded` / `failed`.
  - `aspect_ratio`: odnos širine i visine ovog videa, isti kao parametar zahteva.
  - `prompt`: prompt korišćen za generisanje ovog videa.

Pri sinhronom vraćanju, najviši nivo će takođe sadržati polja kao što su `started_at`, `finished_at`, `elapsed` (trajanje, sekunde) i `cost` (naplata za ovaj put, jedinica Credit).

Potrebno je samo da preuzmemo generisani video prema adresi linka `video_url` u rezultatu `data`.

Odgovarajući CURL kod je sledeći:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Odgovarajući Python kod je sledeći:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Generisanje videa iz slike

Ako želite da generišete video na osnovu referentnih slika, možete proslediti jedan ili više linkova slika u `image_urls`, koji se koriste za usmeravanje generisanja videa:

```json
{
  "prompt": "The woman slowly turns around and smiles at the camera, gentle breeze",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/assets/examples/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3-5ccb6e83b402.png"
  ]
}
```

## Uređivanje videa / referentni video (ulazni video, generisanje videa)

Podržano je direktno „unošenje jednog videa i generisanje novog videa“: prosledite jedan link referentnog videa u `video_urls` (najviše 1), i **istovremeno** navedite najmanje jednu referentnu sliku u `image_urls` (obavezan zahtev uzvodnog sistema), zatim koristite `prompt` da opišete željeni efekat uređivanja (promena stila, promena scene, dodavanje ili uklanjanje elemenata itd.).

U nastavku je kompletan stvarni primer — promena videa sunčane plaže u zimski prizor sa obilnim snegom, uz istovremeno zadržavanje rasporeda plaže, palmi i malog čamca. Uređivanje videa traje duže (u ovom primeru oko 6,5 minuta), zato se asinhrono šalje pomoću `async: true`:
```json
{
  "prompt": "Turn this sunny tropical beach into a snowy winter scene with heavy falling snow and overcast sky; keep the same beach, palm trees and boat layout.",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://cdn.acedata.cloud/assets/examples/seedance/dd3dc063-3383-4f29-bedc-e771a096758c-044e05281a2a.mp4"
  ],
  "async": true
}
```

Nakon slanja, API odmah vraća `task_id`:

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

Zatim koristite ovaj `task_id` kao `id` za anketiranje [Gemini Tasks API-ja](https://platform.acedata.cloud/documents/gemini-tasks), a nakon što se zadatak završi možete dobiti novo generisani video (ovo je stvarni rezultat vraćen u ovom primeru):

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://cdn.acedata.cloud/assets/examples/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284-c5603ef983da.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "Turn this sunny tropical beach into a snowy winter scene with heavy falling snow and overcast sky; keep the same beach, palm trees and boat layout."
    }
  ],
  "started_at": 1784084482.914,
  "finished_at": 1784084877.09,
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Ako vam je potreban rezultat veće rezolucije, možete postaviti `resolution` na `1080p` (ostali parametri ostaju nepromenjeni).

> Napomena: Ulazni / izlazni medijski linkovi u primeru su svi stvarni generisani rezultati. **Linkovi za video-zapise i slike koje generiše platforma imaju rok čuvanja i postaće nevažeći nakon isteka**, zato ih blagovremeno preuzmite i sačuvajte u svom skladištu nakon dobijanja rezultata.

> Pažnja: Može se navesti najviše 1 referentni video; a kada se navodi `video_urls`, mora se navesti najmanje jedna stavka u `image_urls`, u suprotnom će biti vraćena sledeća greška parametara:

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (at least one reference image) is required when video_urls is provided."
  }
}
```

## Asinhroni povratni poziv

Generisanje videa zahteva određeno vreme obrade. Ako ne želite da održavate dugu vezu i čekate, možete proslediti `callback_url`; u tom slučaju API će odmah vratiti `task_id`, a nakon završetka zadatka će POST metodom poslati konačni rezultat na tu adresu:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Odmah vraćeni rezultat je sledeći:

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## Upit rezultata zadatka

Ako se koristi asinhroni povratni poziv ili želite aktivno da proveravate status zadatka, možete putem [Gemini Tasks API-ja](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) proveriti najnoviji status i rezultat zadatka na osnovu `task_id`. U telo zahteva prosledite `task_id` vraćen prilikom kreiranja videa kao `id`:

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

Rezultat vraćen nakon završetka zadatka izgleda otprilike ovako; struktura `response.data` je ista kao pri sinhronom generisanju (tokom generisanja, `state` je `pending`, a `video_url` je `null`):

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
  "type": "videos",
  "request": {
    "model": "omni-flash",
    "prompt": "A time-lapse of clouds over snow mountains at sunrise",
    "aspect_ratio": "16:9",
    "async": true
  },
  "response": {
    "success": true,
    "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
    "data": [
      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
        "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
        "state": "succeeded",
        "aspect_ratio": "16:9",
        "prompt": "A time-lapse of clouds over snow mountains at sunrise"
      }
    ],
    "elapsed": 96.716,
    "cost": {
      "amount": 1.932,
      "currency": "credit",
      "list_amount": 2.1
    }
  }
}
```

## Obrada grešaka

Kada se pojavi problem sa zahtevom, API će vratiti odgovarajući kod greške i objašnjenje, a uobičajeni su sledeći:

- `400`: Parametri zahteva su neispravni, na primer nedostaje `prompt` ili je vrednost `aspect_ratio` nevažeća.
- `401`: Autentifikacija nije uspela, token je nevažeći ili se ne podudara sa API-jem.
- `403`: Nedovoljno sredstava ili je zahtev odbijen jer je prompt pogodio proveru sadržaja.
- `500`: Interna greška servera ili neuspeh generisanja na uzvodnoj strani.
