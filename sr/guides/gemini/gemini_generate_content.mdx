Google Gemini je veoma moćan AI sistem za razgovor, koji može da generiše tečne i prirodne odgovore za nekoliko sekundi unosom upita. Ovaj dokument uglavnom opisuje način korišćenja Gemini Generate Content API-ja, što je Google-ov zvanični izvorni API format, koji podržava dve krajnje tačke: `generateContent` i `streamGenerateContent`.

## Razlika u odnosu na Chat Completions API

Gemini Generate Content API koristi Google-ov zvanični izvorni format zahteva (polje `contents`), umesto OpenAI kompatibilnog formata (polje `messages`). Ako već koristite Google Gemini SDK ili ste upoznati sa zvaničnim API formatom, možete direktno koristiti ovaj API bez izmene formata zahteva.

## Trenutno podržani opseg

Interfejs prihvata tekstualne, slikovne, video i audio ulaze (`inlineData` ili `fileData`), konfiguraciju razmišljanja i deklaracije prilagođenih funkcija. Izvorna polja kao što su audio izlaz, ugrađeni alati i eksplicitno keširanje konteksta još uvek nemaju garantovanu jedinstvenu dostupnost; oslanjajte se na stvarni odgovor konkretnog modela.

Kada koristite `fileData.fileUri` za slanje audio datoteka i drugih datoteka, uverite se da je datoteka direktno dostupna putem HTTPS-a, da ne zavisi od stanja prijave i da period važenja potpisanog linka pokriva celokupno vreme obrade zahteva. Nestriming audio analiza vraća rezultat tek nakon što model završi obradu i može trajati duže od 90 sekundi; klijent treba da postavi dovoljno dugo ukupno vremensko ograničenje prema veličini datoteke i poslovnom scenariju, kako bi se izbeglo prekidanje veze dok server još uvek obrađuje zahtev.

## Proces prijave

Pre korišćenja Gemini Generate Content API-ja, prvo posetite stranicu [Gemini Generate Content API](https://platform.acedata.cloud/documents/gemini-generate-content-api) i kliknite na dugme „Preuzmi“ da biste dobili potrebne akreditive za zahtev.

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu. Prva prijava uključuje besplatan limit.

## Osnovna upotreba

### Non-Streaming (nestriming)

Pošaljite POST zahtev na `/v1beta/models/{model}:generateContent`:

> **Napomena**: flash iz serije `gemini-3.x` je model za razmišljanje i najpre troši reasoning tokene; postavite `generationConfig.maxOutputTokens` na više od 512, u suprotnom može vratiti samo prazan sadržaj.

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "你好，请介绍一下你自己"
          }
        ]
      }
    ]
  }'
```

Primer vraćenog rezultata:

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [{"text": "你好！很高兴与你交流。"}]
      },
      "finishReason": "MAX_TOKENS"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 6,
    "candidatesTokenCount": 19,
    "thoughtsTokenCount": 489,
    "totalTokenCount": 514
  },
  "usage": {
    "prompt_tokens": 6,
    "completion_tokens": 19,
    "total_tokens": 514,
    "thoughts_tokens": 489,
    "cost": {
      "amount": 0.008860916380159999,
      "currency": "credit",
      "list_amount": 0.009631430847999998
    }
  },
  "modelVersion": "gemini-3.5-flash",
  "model": "gemini-3.5-flash"
}
```

Polja tokena u `usageMetadata` naplaćuju se prema izvornim Gemini značenjima:

- `promptTokenCount` uključuje `cachedContentTokenCount`; deo pogođen kešom obračunava se po ceni čitanja iz keša i ne računa se ponovo kao običan ulaz.
- `promptTokensDetails` i `cacheTokensDetails` normalizuju se kao `text_tokens`, `image_tokens`, `video_tokens`, `audio_tokens` i odgovarajuće stavke `cached_*` unutar `usage.prompt_tokens_details`. Ove vrednosti su redom uključene u `prompt_tokens` i `cached_tokens`; različiti modaliteti se ponovo obračunavaju samo prema sopstvenim cenama i ne naplaćuju se dvostruko.
- `candidatesTokenCount` i `thoughtsTokenCount` oba se obračunavaju po ceni izlaznih tokena.
- `toolUsePromptTokenCount` je nezavisan token za ulaz alata i obračunava se po ceni ulaznih tokena.

Ace Data Cloud dodatno vraća normalizovani objekat `usage`, a trošak ovog poziva se jedinstveno čita iz `usage.cost` kroz protokole modela. `cost` je opcionalni pregled troška; kada pregled cene privremeno nije dostupan, odgovor modela će se i dalje normalno vratiti, ali možda neće sadržati ovo polje. Konačni račun zavisi od evidencije potrošnje.

### Streaming (striming)

Pošaljite POST zahtev na `/v1beta/models/{model}:streamGenerateContent?alt=sse`:

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "写一首关于春天的诗"
          }
        ]
      }
    ]
  }'
```

Striming odgovor će postepeno vraćati sadržaj u SSE (Server-Sent Events) formatu. Međudogađaji obično sadrže samo inkrementalni sadržaj; završni događaj sa autoritativnim podacima o potrošnji sadrži `usageMetadata` i normalizovani `usage`, a trošak se i dalje nalazi u `usage.cost`:

```text
data: {"candidates":[{"content":{"parts":[{"text":"Hello!"}],"role":"model"},"index":0}],"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

data: {"candidates":[{"content":{"parts":[],"role":"model"},"finishReason":"STOP","index":0}],"usageMetadata":{"promptTokenCount":7,"candidatesTokenCount":89,"totalTokenCount":96},"usage":{"prompt_tokens":7,"completion_tokens":89,"total_tokens":96,"cost":{"amount":0.00026161075472,"currency":"credit","list_amount":0.000284359516}},"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

```

Zatvaranje veze označava kraj toka; izvorni Gemini tok ne šalje `data: [DONE]`. Ako završni pregled cene privremeno nije dostupan, `usage` će i dalje vratiti potrošnju tokena, ali će izostaviti `cost`.

## Podržani modeli
| Naziv modela             | Opis                                    |
| ------------------------ | --------------------------------------- |
| `gemini-4-argon`         | Model za duboko rezonovanje; podržava `generateContent` ovog interfejsa i strimovano generisanje teksta |
| `gemini-3.8-flash`       | Najnoviji Flash model, pogodan za univerzalne zadatke visokog kvaliteta |
| `gemini-3.7-flash`       | Flash model visokog kvaliteta za univerzalnu upotrebu |
| `gemini-3.6-flash`       | Stabilan multimodalni model visokih performansi |
| `gemini-3.5-flash`       | Multimodalni model visokog protoka |
| `gemini-3.5-flash-lite`  | Model niske latencije i niske cene |
| `gemini-3.1-flash-lite`  | Stabilna verzija laganog modela |
| `gemini-3.1-pro-preview` | Model za složeno rezonovanje i kodiranje |
| `gemini-3-flash-preview` | Gemini 3 Flash model u pregledu |
| `gemini-2.5-pro`         | Gemini 2.5 Pro model |
| `gemini-2.5-flash`       | Gemini 2.5 Flash model |
| `gemini-2.5-flash-lite`  | Gemini 2.5 Flash-Lite model |
| `gemini-3.1-flash-image` | Model za generisanje slika |
| `gemini-3-pro-image`     | Model za generisanje slika visokog kvaliteta |
| `gemini-2.5-flash-image` | Gemini 2.5 model za generisanje slika |

## Napredne funkcije

### Sistemske instrukcije

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "你好"}]
    }
  ],
  "systemInstruction": {
    "parts": [{"text": "你是一个专业的诗人，所有回复都用诗歌形式。"}]
  }
}
```

### Konfiguracija generisanja

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "讲一个故事"}]
    }
  ],
  "generationConfig": {
    "temperature": 0.7,
    "maxOutputTokens": 1024,
    "topP": 0.9,
    "topK": 40
  }
}
```

### JSON režim

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {
          "text": "列出三个中国城市及其人口"
        }
      ]
    }
  ],
  "generationConfig": {
    "responseMimeType": "application/json",
    "responseSchema": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "city": {
            "type": "string"
          },
          "population": {
            "type": "integer"
          }
        }
      }
    }
  }
}
```

### Režim razmišljanja (Thinking)

Modeli koji podržavaju funkciju razmišljanja (kao što su gemini-2.5-flash i gemini-2.5-pro) mogu da omoguće režim razmišljanja:

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "解释量子纠缠"}]
    }
  ],
  "generationConfig": {
    "thinkingConfig": {
      "includeThoughts": true,
      "thinkingBudget": 2048
    }
  }
}
```

### Pozivanje funkcija

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "北京现在的天气怎么样？"}]
    }
  ],
  "tools": [
    {
      "functionDeclarations": [
        {
          "name": "get_weather",
          "description": "获取指定城市的天气信息",
          "parameters": {
            "type": "object",
            "properties": {
              "city": {
                "type": "string",
                "description": "城市名称"
              }
            },
            "required": ["city"]
          }
        }
      ]
    }
  ]
}
```

### Višekružni razgovor

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "你好，我叫小明"}]
    },
    {
      "role": "model",
      "parts": [{"text": "你好小明！很高兴认识你。"}]
    },
    {
      "role": "user",
      "parts": [{"text": "我叫什么名字？"}]
    }
  ]
}
```

### Razumevanje slika

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {"text": "描述这张图片"},
        {
          "inlineData": {
            "mimeType": "image/jpeg",
            "data": "base64_encoded_image_data..."
          }
        }
      ]
    }
  ]
}
```

## Bezbednosna podešavanja

Filtriranje sadržaja može se kontrolisati putem `safetySettings`:

```json
{
  "contents": [...],
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_ONLY_HIGH"
    }
  ]
}
```

## Obrada grešaka

| HTTP statusni kod | Značenje             |
| -------- | -------------- |
| 400      | Nevažeći parametri zahteva         |
| 401      | Autentifikacija neuspešna, proverite Token |
| 403      | Sadržaj je blokiran bezbednosnim filterom     |
| 429      | Zahtevi su previše učestali         |
| 500      | Interna greška servera        |
