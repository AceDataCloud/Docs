Google Gemini je veoma moćan AI sistem za razgovor, koji može generisati tečne i prirodne odgovore za nekoliko sekundi putem unosa upita. Ovaj dokument uglavnom opisuje način korišćenja Gemini Generate Content API-ja, što je Google-ov zvanični izvorni API format, koji podržava dve krajnje tačke: `generateContent` i `streamGenerateContent`.

## Razlika u odnosu na Chat Completions API

Gemini Generate Content API koristi Google-ov zvanični izvorni format zahteva (polje `contents`), umesto formata kompatibilnog sa OpenAI-jem (polje `messages`). Ako već koristite Google Gemini SDK ili ste upoznati sa zvaničnim API formatom, možete direktno koristiti ovaj API bez izmene formata zahteva.

## Trenutno podržani opseg

Interfejs prihvata tekstualne, slikovne, video i audio ulaze (`inlineData` ili `fileData`), konfiguraciju razmišljanja i deklaracije prilagođenih funkcija. Izvorna polja kao što su audio izlaz, ugrađeni alati i eksplicitno keširanje konteksta još nemaju garantovanu jedinstvenu dostupnost; oslonite se na stvarni odgovor konkretnog modela.

Kada šaljete audio i druge datoteke pomoću `fileData.fileUri`, osigurajte da datoteka može biti direktno dostupna putem HTTPS-a, da ne zavisi od stanja prijave i da period važenja potpisanog linka pokriva celo vreme obrade zahteva. Nestriming analiza zvuka vraća rezultat tek nakon što model završi obradu, što može trajati duže od 90 sekundi; klijent treba da postavi dovoljno dugo ukupno vremensko ograničenje u skladu sa veličinom datoteke i poslovnim scenarijem, kako bi se izbeglo prekidanje veze dok server i dalje obrađuje zahtev.

## Proces prijave

Pre korišćenja Gemini Generate Content API-ja, prvo posetite stranicu [Gemini Generate Content API](https://platform.acedata.cloud/documents/gemini-generate-content-api), zatim kliknite na dugme „Preuzmi“ da biste dobili akreditive potrebne za zahtev.

Ako još niste prijavljeni ili registrovani, bićete automatski preusmereni na stranicu za prijavu. Prva prijava uključuje besplatni kredit.

## Osnovna upotreba

### Non-Streaming (nestriming)

Pošaljite POST zahtev na `/v1beta/models/{model}:generateContent`:

> **Napomena**: flash iz serije `gemini-3.x` su modeli za razmišljanje i prvo će potrošiti reasoning tokene; postavite `generationConfig.maxOutputTokens` na više od 512, u suprotnom je moguće da će biti vraćen samo prazan sadržaj.

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "你好，请介绍一下你自己"
          }
        ]
      }
    ]
  }'
```

Primer vraćenog rezultata:

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [{"text": "你好！很高兴与你交流。"}]
      },
      "finishReason": "MAX_TOKENS"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 6,
    "candidatesTokenCount": 19,
    "thoughtsTokenCount": 489,
    "totalTokenCount": 514
  },
  "usage": {
    "prompt_tokens": 6,
    "completion_tokens": 19,
    "total_tokens": 514,
    "thoughts_tokens": 489,
    "cost": {
      "amount": 0.008860916380159999,
      "currency": "credit",
      "list_amount": 0.009631430847999998
    }
  },
  "modelVersion": "gemini-3.5-flash",
  "model": "gemini-3.5-flash"
}
```

Token polja u `usageMetadata` se naplaćuju prema izvornom Gemini značenju:

- `promptTokenCount` uključuje `cachedContentTokenCount`, deo pogođen keširanjem izračunava se po ceni čitanja iz keša i neće se ponovo računati kao običan ulaz.
- `promptTokensDetails` i `cacheTokensDetails` će biti normalizovani kao `text_tokens`, `image_tokens`, `video_tokens`, `audio_tokens` i odgovarajući `cached_*` detalji pod `usage.prompt_tokens_details`. Ove vrednosti su uključene u `prompt_tokens` i `cached_tokens`; različiti modaliteti se ponovo izračunavaju samo prema sopstvenim cenama i neće biti dvostruko naplaćeni.
- `candidatesTokenCount` i `thoughtsTokenCount` se oba naplaćuju prema ceni izlaznih tokena.
- `toolUsePromptTokenCount` je nezavisan token ulaza alata i naplaćuje se prema ceni ulaznih tokena.

Ace Data Cloud dodatno vraća normalizovani objekat `usage`, a trošak ovog poziva se jedinstveno čita iz `usage.cost` kroz protokole različitih modela. `cost` je opcionalni pregled troška; kada pregled cena privremeno nije dostupan, odgovor modela će se i dalje normalno vratiti, ali možda neće sadržati ovo polje. Konačni račun zavisi od evidencije korišćenja.

### Streaming (striming)

Pošaljite POST zahtev na `/v1beta/models/{model}:streamGenerateContent?alt=sse`:

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "写一首关于春天的诗"
          }
        ]
      }
    ]
  }'
```

Striming odgovor će postepeno vraćati sadržaj u SSE (Server-Sent Events) formatu. Međudogađaji obično sadrže samo inkrementalni sadržaj; završni događaj sa autoritativnim korišćenjem sadržaće `usageMetadata` i normalizovani `usage`, dok se trošak i dalje nalazi u `usage.cost`:

```text
data: {"candidates":[{"content":{"parts":[{"text":"Hello!"}],"role":"model"},"index":0}],"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

data: {"candidates":[{"content":{"parts":[],"role":"model"},"finishReason":"STOP","index":0}],"usageMetadata":{"promptTokenCount":7,"candidatesTokenCount":89,"totalTokenCount":96},"usage":{"prompt_tokens":7,"completion_tokens":89,"total_tokens":96,"cost":{"amount":0.00026161075472,"currency":"credit","list_amount":0.000284359516}},"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

```

Zatvaranje veze označava kraj toka; izvorni Gemini tok ne šalje `data: [DONE]`. Ako pregled cene u završnom stanju privremeno nije dostupan, `usage` će i dalje vratiti korišćenje tokena, ali će izostaviti `cost`.

`gemini-4-carbon` i `gemini-4-hydrogen` trenutno se mogu pozivati putem Chat Completions, dok izvorni Generate Content privremeno nije dostupan. Zvanične specifikacije modela navode unos teksta, slika, videa, zvuka i PDF-a, kao i tekstualni izlaz; to ne znači da je trenutna platforma verifikovala sve tipove unosa. Nakon što se izvorno pozivanje obnovi, pošaljite zahteve u skladu sa ugovorom interfejsa na ovoj stranici i zasebno verifikujte potrebne unose i parametre. Zvanični long decode izlaz od milion Tokena nije obuhvaćen trenutnim ugovorom interfejsa. Oba podržavaju samo implicitno keširanje, Tokeni za razmišljanje obračunavaju se po izlaznoj ceni; pripremljena pravila cena koriste istu jediničnu cenu ulaznog Tokena za sve ulazne modalitete, a pogoci keša obračunavaju se po jediničnoj ceni čitanja iz keša, detalje pogledajte na trenutnoj stranici sa cenama.

### Interno razmišljanje i sažetak razmišljanja

Interno razmišljanje modela i vraćanje sažetka razmišljanja pozivaocu su dve nezavisne postavke:

- `thinkingBudget` ili `thinkingLevel` kontrolišu interni budžet ili dubinu razmišljanja modela, a podržana polja i vrednosti zavise od modela.
- `includeThoughts` kontroliše da li se vraća sažetak razmišljanja, podrazumevana vrednost je `false`. Kada se ovo polje izostavi ili se prosledi `false`, ni obični JSON ni SSE strimovani odgovori neće vratiti tekst označen kao `thought: true`; ovi tekstovi se zadržavaju samo kada se eksplicitno prosledi Bulova vrednost `true`.

Kada zahtev nema postavljeno `includeThoughts`, interfejs podrazumevano prosleđuje `false` generativnim modelima koji podržavaju konfiguraciju razmišljanja, kako bi se izbegli nepotrebni sažeci u zahtevu; vrednosti koje klijent eksplicitno prosledi, budžet razmišljanja i nivo se zadržavaju. Kod poznatog `gemini-2.5-flash-image`, koji ne podržava konfiguraciju razmišljanja, ovo polje se neće automatski dodavati, a ni zahtevima `countTokens` neće biti dodavana konfiguracija generisanja.

Isključivanje sažetaka nije isto što i isključivanje internog razmišljanja i ne garantuje smanjenje Tokena internog razmišljanja. Ako odgovor i dalje sadrži nezatraženi tekst razmišljanja, obični JSON i SSE izlazi će ga dodatno filtrirati, zadržavajući normalan odgovor, potpise i stvarnu potrošnju.

Kada je potrebno videti sažetak, eksplicitno ga uključite na sledeći način. Ako model nije generisao dostupan sažetak, možda neće biti teksta razmišljanja čak ni kada je uključen:

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "解释量子纠缠"}]
    }
  ],
  "generationConfig": {
    "thinkingConfig": {
      "includeThoughts": true
    }
  }
}
```

`thoughtSignature` je šifrovano stanje potrebno za naredne runde, a ne tekst sažetka razmišljanja, i ne kontroliše se prekidačem `includeThoughts`. Potpis može biti u normalnom odgovoru, pozivu funkcije ili praznom tekstualnom Part-u; prilikom filtriranja teksta razmišljanja, potpis i druga polja istog Part-a se zadržavaju, pa odgovor može i dalje sadržati Part-ove koji nose samo potpis i imaju prazan tekst. Kada ručno održavate istoriju u više rundi, treba zadržati redosled ovih Part-ova i položaj potpisa, nemojte premeštati potpise niti ih spajati.

`usageMetadata` i `usage` i dalje beleže stvarnu potrošnju. Sakrivanje sažetaka ne postavlja `thoughtsTokenCount` na nulu, a naplata se i dalje obračunava prema stvarnoj potrošnji i trenutnim pravilima cena.

Pogledajte Google zvanična [objašnjenja o razmišljanju i sažecima razmišljanja](https://firebase.google.com/docs/ai-logic/thinking) i [pravila za potpise razmišljanja](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/thinking/thought-signatures).

## Bezbednosna podešavanja

Filtriranje sadržaja se može kontrolisati putem `safetySettings`:

```json
{
  "contents": [...],
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_ONLY_HIGH"
    }
  ]
}
```

## Obrada grešaka

| HTTP statusni kod | Značenje                         |
| -------- | ------------------------------ |
| 400      | Nevažeći parametri zahteva      |
| 401      | Autentifikacija nije uspela, proverite Token |
| 403      | Sadržaj je blokiran bezbednosnim filterom |
| 429      | Zahtevi su previše česti        |
| 500      | Interna greška servera          |
