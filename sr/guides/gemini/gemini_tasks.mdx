Glavna funkcija Gemini Tasks API je da omogući upit o statusu izvršenja zadatka putem ID-a zadatka generisanog putem Gemini Videos Generation API.

Ovaj dokument će detaljno opisati uputstva za integraciju Gemini Tasks API, pomažući vam da lako integrišete i upitujete status izvršenja zadataka iz Gemini Videos Generation API.

## Proces prijave

Da biste koristili Gemini Videos Generation API, prvo idite na [Ace Data Cloud kontrolnu tablu](https://platform.acedata.cloud/console/applications) da dobijete svoj API Token, koji čuvate za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja vas poziva da se registrujete i prijavite, a nakon toga ćete se automatski vratiti na trenutnu stranicu.

**Jedan API Token je dovoljan za korišćenje svih usluga platforme, nije potrebno posebno aplicirati za svaku uslugu.** Prilikom prve prijave dobijate besplatnu kvotu, koju možete besplatno isprobati; kada kvota postane nedovoljna, možete dopuniti opšti saldo na [kontrolnoj tabli](https://platform.acedata.cloud/console/coin).

> 📘 Potpuna dokumentacija: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Primer zahteva

Gemini Tasks API može se koristiti za upit o rezultatima Gemini Videos Generation API.

### Postavljanje zaglavlja zahteva i tela zahteva

**Zaglavlja zahteva** uključuju:

- `accept`: određuje da se očekuje odgovor u JSON formatu, ovde se unosi `application/json`.
- `authorization`: ključ za pozivanje API-ja, nakon prijave možete direktno izabrati.

**Telo zahteva** uključuje:

- `id`: ID zadatka koji se upitujete.
- `action`: način operacije nad zadatkom, za pojedinačni upit unosi se `retrieve`.

### CURL kod primer

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Primer odgovora

Nakon uspešnog zahteva, API će vratiti detaljne informacije o ovom zadatku. Polje `request` sadrži telo zahteva prilikom pokretanja zadatka, dok polje `response` sadrži telo odgovora nakon završetka zadatka, na primer:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262730.723,
  "elapsed": 8.9,
  "request": {
    "prompt": "Kinematografski kadar mačića koji juri leptira u osunčanom vrtu",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
        "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Objašnjenje polja je sledeće:

- `id`: ID generisanog zadatka, koji se koristi za jedinstvenu identifikaciju ovog generisanog zadatka.
- `request`: informacije o zahtevu u okviru upita zadatka.
- `response`: informacije o odgovoru u okviru upita zadatka.
- `created_at`: vreme kreiranja zadatka, Unix vremenska oznaka (sekunde, decimalno).
- `started_at`: vreme kada je zadatak počeo da se izvršava, Unix vremenska oznaka (sekunde, decimalno).
- `finished_at`: vreme kada je zadatak završen, Unix vremenska oznaka (sekunde, decimalno). Ovo polje se ne vraća kada zadatak nije završen.
- `elapsed`: vreme trajanja izvršenja zadatka, u sekundama (decimalno, sa 3 decimale). Ovo polje se ne vraća kada zadatak nije završen.

## Operacija masovnog upita

Za upit o detaljima više ID-eva zadataka, postavite `action` na `retrieve_batch`, i prosledite niz ID-eva zadataka putem `ids`:

**Telo zahteva** uključuje:

- `ids`: niz ID-eva zadataka koje želite da upitujete.
- `action`: način operacije nad zadatkom, za masovni upit unosi se `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
