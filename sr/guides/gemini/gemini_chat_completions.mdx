Google Gemini је веома моћан AI систем за разговор, који може генерисати текуће и природне одговоре у року од неколико секунди само уношењем упитника. Gemini пружа импресивну интелигентну помоћ, значајно повећавајући продуктивност и креативност људи.

Овај документ углавном описује процес коришћења Gemini Chat Completion API, који нам омогућава лако коришћење званичних Gemini функција за разговор.

## Процес пријаве

Да бисте користили Gemini Chat Completion API, прво можете отићи на [Gemini Chat Completion API](https://platform.acedata.cloud/documents/ae54bf9b-af41-4072-b969-3756b6d66834) страницу и кликнути на „Acquire“ дугме да бисте добили акредитиве потребне за захтев:

![](https://cdn.acedata.cloud/nyq0xz.png)

Ако се још нисте пријавили или регистровали, аутоматски ћете бити преусмерени на страницу за пријаву која вас позива да се региструјете и пријавите, а након пријаве и регистрације аутоматски ћете се вратити на тренутну страницу.

При првом захтеву добићете бесплатну квоту, која вам омогућава да бесплатно користите овај API.

## Основна употреба

Након тога можете попунити одговарајуће садржаје на интерфејсу, као што је приказано на слици:

<p><img src="https://cdn.acedata.cloud/f6ksts.png" width="400" className="m-auto" /></p>

Када први пут користите овај интерфејс, морамо попунити најмање три садржаја, један је `authorization`, који можете директно изабрати из падајућег менија. Други параметар је `model`, `model` је категорија модела коју одаберемо да користимо са Gemini званичне странице, овде имамо 6 различитих модела, детаље можете видети у моделима које пружамо. Последњи параметар је `messages`, `messages` је низ упитника који уносимо, то је низ који представља могућност истовременог слања више упитника, сваки упитник садржи `role` и `content`, где `role` представља улогу питаоца, а ми пружамо три идентификације: `user`, `assistant`, `system`. Други `content` је конкретан садржај нашег питања.

Такође можете приметити да се на десној страни генерише одговарајући код за позив, можете копирати код и директно га покренути, или можете директно кликнути на „Try“ дугме за тестирање.

## Стриминг одговора

Овај интерфејс такође подржава стриминг одговора, што је веома корисно за веб интеграцију, јер омогућава веб страници да реализује ефекат приказивања по слово.

Ако желите да добијете одговор у стриминг формату, можете променити параметар `stream` у заглављу захтева на `true`.

Промена је приказана на слици, али код позива треба да има одговарајуће измене да би подржао стриминг одговор.

<p><img src="https://cdn.acedata.cloud/o2blmi.png" width="400" className="m-auto" /></p>

Након промене `stream` на `true`, API ће редом враћати одговарајуће JSON податке, а на кодном нивоу морамо направити одговарајуће измене да бисмо добили редне резултате.

Python пример кода за позив:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-2.5-pro",
    "messages": [{"role":"user","content":"Zdravo, koji model si?"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Možete videti da odgovor sadrži mnogo `data`, a `data` unutar `choices` predstavlja najnoviji odgovor, koji je u skladu sa prethodno opisanim sadržajem. `choices` su novi odgovori koje možete povezati sa vašim sistemom. Takođe, završetak strimovane odgovore se određuje na osnovu sadržaja `data`, a ako je sadržaj `[DONE]`, to znači da je strimovani odgovor potpuno završen. Vraćeni `data` rezultati imaju više polja, a opisi su sledeći:

- `id`, ID koji jedinstveno identifikuje ovu konverzaciju.
- `model`, izabrani model sa Gemini veb stranice.
- `choices`, odgovori koje Gemini daje na postavljene upite.

JavaScript je takođe podržan, na primer, kod za strimovano pozivanje u Node.js je sledeći:

```javascript
const options = {
  method: "post",
  headers: {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    "model": "gemini-2.5-pro",
    "messages": [{"role":"user","content":"Zdravo, koji si model?"}],
    "stream": true
  })
};

fetch("https://api.acedata.cloud/gemini/chat/completions", options)
  .then(response => response.json())
  .then(response => console.log(response))
  .catch(err => console.error(err));
```

Java uzorak koda:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "gemini-2.5-pro");
jsonObject.put("messages", [{"role":"user","content":"Zdravo, koji si model?"}]);
jsonObject.put("stream", true);
MediaType mediaType = "application/json; charset=utf-8".toMediaType();
RequestBody body = jsonObject.toString().toRequestBody(mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/gemini/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.print(response.body!!.string())
```

Ostale jezike možete prilagoditi prema sopstvenim potrebama, princip je isti.

## Gemini-3.1 Мултимодални модел

Gemini 3.1 Pro је надограђена верзија Gemini 3.0 Pro, основни модел је `gemini-3.1-pro-preview`, такође подржава текст, слике, видео и друге мултимодалне улазе, имајући јачу способност закључивања и разумевања. Начин коришћења је потпуно идентичан Gemini 3.0 Pro, само је потребно заменити параметар `model` са `gemini-3.1-pro`.

Пример захтева:

```json
{
  "model": "gemini-3.1-pro",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "Шта је садржај слике?"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

Gemini 3.1 Pro такође подржава разумевање видео записа:

```json
{
  "model": "gemini-3.1-pro",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "Шта је садржај видеа?"

          }
        }
      ]
    }
  ],
  "stream": false
}
```

Формат повратка је идентичан као код Gemini 3.0 Pro, детаљи су описани у горњем делу о Gemini-3.0 мултимодалном моделу.

## Обрада грешака

Када позивате АПИ, ако наиђете на грешку, АПИ ће вратити одговарајући код грешке и информације. На пример:

- `400 token_mismatched`：Лош захтев, могуће због недостајућих или неважећих параметара.
- `400 api_not_implemented`：Лош захтев, могуће због недостајућих или неважећих параметара.
- `401 invalid_token`：Неовлашћено, неважећи или недостајући токен за ауторизацију.
- `429 too_many_requests`：Превише захтева, прелазите лимит.
- `500 api_error`：Унутрашња грешка сервера, нешто није у реду на серверу.

### Пример одговора на грешку

```
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
