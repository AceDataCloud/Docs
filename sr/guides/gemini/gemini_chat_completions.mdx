Google Gemini je veoma moćan AI sistem za razgovor, koji može generisati tečne i prirodne odgovore za samo nekoliko sekundi nakon unosa prompta. Gemini može pružiti neverovatnu inteligentnu pomoć, značajno povećavajući radnu efikasnost i kreativnost ljudi.

Ovaj dokument uglavnom predstavlja proces korišćenja Gemini Chat Completion API operacija, pomoću kojeg možemo lako koristiti zvaničnu Gemini funkciju za razgovor.

## Proces prijave

Da biste koristili Gemini Chat Completion API, prvo idite na [Ace Data Cloud konzolu](https://platform.acedata.cloud/console/applications) da biste dobili svoj API Token, koji sačuvajte za kasniju upotrebu.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Ako još niste prijavljeni ili registrovani, automatski ćete biti preusmereni na stranicu za prijavu koja će vas pozvati da se registrujete i prijavite, a nakon završetka automatski ćete se vratiti na trenutnu stranicu.

**Jedan API Token može pozivati sve usluge platforme, bez potrebe da se posebno prijavljujete za svaku uslugu.** Prilikom prve prijave dobićete besplatni kredit, koji možete besplatno isprobati; kada kredit nije dovoljan, možete dopuniti opšti saldo na [konzoli](https://platform.acedata.cloud/console/coin).

> 📘 Kompletna dokumentacija: [Gemini Chat Completion API →](https://platform.acedata.cloud/documents/gemini-chat-completions)

## Osnovno korišćenje

Zatim možete popuniti odgovarajući sadržaj u interfejsu, kao što je prikazano na slici:

<p><img src="https://cdn.acedata.cloud/f6ksts.png" width="400" className="m-auto" /></p>

Prilikom prvog korišćenja ovog interfejsa, potrebno je da popunimo najmanje tri stavke. Jedna je `authorization`, koju možete direktno izabrati iz padajuće liste. Drugi parametar je `model`, a `model` predstavlja kategoriju modela sa zvaničnog Gemini sajta koju biramo za korišćenje; dostupni modeli zavise od enumeracije `model` u dokumentaciji interfejsa. Poslednji parametar je `messages`, `messages` je niz upita koji unosimo, to je niz koji označava da se može istovremeno poslati više upita, pri čemu svaki upit sadrži `role` i `content`, gde `role` predstavlja ulogu osobe koja postavlja pitanje, a nudimo tri identiteta, odnosno `user`, `assistant`, `system`. Drugi, `content`, predstavlja konkretan sadržaj našeg pitanja.

Istovremeno možete primetiti da se sa desne strane generiše odgovarajući kod za pozivanje; možete kopirati kod i direktno ga pokrenuti, a možete i direktno kliknuti na dugme „Try“ radi testiranja.

<p><img src="https://cdn.acedata.cloud/a3mdgy.png" width="400" className="m-auto" /></p>

> **Napomena**: Flash modeli serije `gemini-3.x` su modeli za razmišljanje i prvo troše reasoning tokene; postavite `max_tokens` na više od 512, u suprotnom se može vratiti samo prazan sadržaj. `gemini-3.8-flash` je trenutno preporučeni Flash model, podržava do 1 milion Tokena konteksta, unos slika, pozivanje alata i strimovani odgovor; trenutno se poziva putem Chat Completions interfejsa.

## Razumevanje slika (multimodalni unos)

Gemini je nativni multimodalni model i može direktno da „vidi slike“. Da biste prosledili sliku, promenite `content` određene poruke iz stringa u **niz blokova sadržaja**, pa u niz istovremeno stavite blok `text` i blok `image_url` — ovo je potpuno isto kao format kompatibilan sa OpenAI-jem i zvaničnim Gemini-jem.

`image_url.url` podržava dva načina pisanja:

- **base64 `data:` URI (preporučeno, najstabilnije)**: format je `data:<medijski tip>;base64,<podaci>`, na primer `data:image/jpeg;base64,/9j/4AAQ...`. **Medijski tip (MIME) je već naveden u prefiksu `data:`**, tako da nije potrebno, niti postoji zasebno polje `media_type`.
- **Javno dostupni URL slike**: na primer `https://cdn.acedata.cloud/4hfydw.jpg`.

Podržani tipovi slika: `png`, `jpeg`, `webp`, `heic`, `heif`.

Primer Python koda za pozivanje (base64 data URI):
```python
import base64
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

# 把本地图片读成 base64 data URI
with open("image.jpg", "rb") as f:
    base64_image = base64.b64encode(f.read()).decode("utf-8")
data_uri = f"data:image/jpeg;base64,{base64_image}"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-3.1-pro-preview",
    "messages": [
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "请用一句话描述这张图片。"},
                {"type": "image_url", "image_url": {"url": data_uri}}
            ]
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Strimovani odgovor

Ovaj interfejs takođe podržava strimovane odgovore, što je veoma korisno za povezivanje sa veb-stranicama, jer omogućava da stranica ostvari efekat prikazivanja reč po reč.

Ako želite da se odgovor vraća strimovano, možete izmeniti parametar `stream ` u zaglavlju zahteva na `true`.

Izmena je prikazana na slici, ali kod za pozivanje mora imati odgovarajuće izmene kako bi podržao strimovani odgovor.

<p><img src="https://cdn.acedata.cloud/o2blmi.png" width="400" className="m-auto" /></p>

Nakon izmene `stream` na `true`, API će vraćati odgovarajuće JSON podatke red po red, a na nivou koda potrebno je da izvršimo odgovarajuće izmene kako bismo dobili rezultate red po red.

Primer Python koda za pozivanje:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-2.5-pro",
    "messages": [{"role":"user","content":"Hello,What model are you?"}],
    "stream": True,
    "stream_options": {"include_usage": True}
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

- `model `, odabrani Gemini model sa zvaničnog sajta.
- `choices`, informacije o odgovoru koji Gemini daje na upit.

JavaScript je takođe podržan, na primer, kod za strim pozivanje u Node.js je sledeći:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "gemini-2.5-pro",
    messages: [{ role: "user", content: "Hello, what model are you?" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/gemini/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

    "accept": "application/json",

    "content-type": "application/json"

payload = {

    "messages": [{"role":"user","content":"Hello"},{"role":"assistant","content":"Hello there! How can I help you today?"},{"role":"user","content":"What model are you?"}]

response = requests.post(url, json=payload, headers=headers)

```

## Gemini-3.1 multimodalni model

`gemini-3.1-pro-preview` je trenutni zvanični ID modela Gemini 3.1 Pro, podržava multimodalne unose kao što su tekst, slike i video-zapisi, i pogodan je za složeno rezonovanje, kodiranje i zadatke razumevanja.

Primer zahteva:

```json
{
  "model": "gemini-3.1-pro-preview",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "图片的内容是什么？"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

Gemini 3.1 Pro takođe podržava razumevanje video-zapisa:

## Obrada grešaka

Prilikom pozivanja API-ja, ako dođe do greške, API će vratiti odgovarajući kod greške i informacije. Na primer:

- `400 token_mismatched`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `400 api_not_implemented`: Neispravan zahtev, moguće zbog nedostajućih ili nevažećih parametara.
- `401 invalid_token`: Neovlašćeno, nevažeći ili nedostajući token za autorizaciju.
- `429 too_many_requests`: Previše zahteva, premašili ste ograničenje broja zahteva.
- `500 api_error`: Interna greška servera, nešto je pošlo po zlu na serveru.
