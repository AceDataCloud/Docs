## Pregled

Integracijom funkcije pretrage u realnom vremenu u aplikaciju omogućava korisnicima pristup najnovijim informacijama. SERP API iz Ace Data Cloud pruža strukturirane podatke sa Google pretrage, podržavajući različite tipove pretrage kao što su web stranice, slike, vesti i dr.

## Uključene usluge

- **Google Search**: `POST https://api.acedata.cloud/serp/google`

## Tehničko rešenje

### Preduslovi

1. Registracija naloga na [Ace Data Cloud](https://platform.acedata.cloud)
2. Dobijanje API tokena
3. Instalacija Python 3.7+ i biblioteke requests

### Koraci implementacije

### Korak 1: Konfigurisanje parametara pretrage

Podesite parametre `query`, `type`, `language`, `country` i druge.

### Korak 2: Pozivanje pretraživačkog API-ja

Koristite `POST /serp/google` za slanje zahteva za pretragu.

### Korak 3: Parsiranje rezultata pretrage

Obradite vraćene strukturirane podatke i izdvojite naslove, linkove, sažetke i druge informacije.

## Primer koda

Sledeći primer prikazuje kompletan Python kod za korišćenje Google Search:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_serp():
    response = requests.post(
        "https://api.acedata.cloud/serp/google",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "query": "artificial intelligence latest news",
    "type": "search",
    "number": 10,
    "language": "en",
    "country": "US"
},
    )
    return response.json()

result = call_serp()
print(result)
```

## Najbolje prakse

- **Ponovno pokušavanje pri greškama**: Koristite eksponencijalno odlaganje za greške 429 (ograničenje zahteva) i 5xx
- **Asinhrona obrada**: Za zadatke koji traju duže (generisanje slika/video zapisa), koristite callback_url za asinhrono primanje rezultata
- **Kontrola troškova**: Pratite potrošnju i troškove putem Ace Data Cloud konzole
- **Sigurnost tokena**: Čuvajte API token u promenljivim okruženja, nemojte ga hardkodirati u kodu
