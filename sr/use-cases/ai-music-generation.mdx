## Преглед

AI генерисање музике омогућава креаторима да без стручног музичког знања креирају висококвалитетну музику. Suno и Producer представљају два различита приступа AI генерисању музике, која се позивају преко Ace Data Cloud платформе.

## Укључене услуге

- **Suno**: `POST https://api.acedata.cloud/suno/audios`
- **Producer**: `POST https://api.acedata.cloud/producer/audios`

## Техничко решење

### Претпоставке

1. Регистровати налог на [Ace Data Cloud](https://platform.acedata.cloud)
2. Преузети API Token
3. Инсталирати Python 3.7+ и библиотеку requests

### Кораци имплементације

### Корак 1: Изабрати музички мотор

Suno подржава генерисање песама у више стилова, док се Producer (FUZZ) фокусира на производњу висококвалитетне музике.

### Корак 2: Генерисати музику

Suno користи `/suno/audios`, а Producer користи `/producer/audios`.

### Корак 3: Прилагодити текст песме

Поставити `custom: true` и обезбедити поље `lyric` за генерисање музике са прилагођеним текстом.

## Пример кода

Испод је комплетан Python пример за коришћење Suno:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_suno():
    response = requests.post(
        "https://api.acedata.cloud/suno/audios",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "action": "generate",
    "prompt": "A cheerful pop song about summer vacation",
    "model": "chirp-v5",
    "custom": false
},
    )
    return response.json()

result = call_suno()
print(result)
```

## Најбоље праксе

- **Поновни покушаји при грешкама**: Користити експоненцијално одлагање за поновне покушаје код 429 (ограничење захтева) и 5xx грешака
- **Асинхроно обрађивање**: За дуготрајне задатке (генерисање слика/видео) користити callback_url за асинхроно примање резултата
- **Контрола трошкова**: Пратити потрошњу и трошкове преко Ace Data Cloud конзоле
- **Безбедност Token-а**: Чувати API Token у променљивим окружења, не убацивати га директно у код
