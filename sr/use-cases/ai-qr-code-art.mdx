## Pregled

Tradicionalni QR kodovi su uniformni, dok AI umetnički QR kodovi mogu integrisati brend elemente u dizajn QR koda, čime se povećava stopa skeniranja. Ace Data Cloud-ov QR Art API podržava više unapred definisanih umetničkih stilova.

## Uključene usluge

- **QR Art**: `POST https://api.acedata.cloud/qrart/generate`

## Tehničko rešenje

### Preduslovi

1. Registrujte nalog na [Ace Data Cloud](https://platform.acedata.cloud)
2. Nabavite API Token
3. Instalirajte Python 3.7+ i biblioteku requests

### Koraci implementacije

### Korak 1: Postavite sadržaj QR koda

Izaberite tip (link/text/email/phone) i podesite sadržaj.

### Korak 2: Izaberite umetnički stil

Koristite parametar `preset` za izbor unapred definisanog stila, kao što su sunset, floral, neon-mech.

### Korak 3: Generisanje i preuzimanje

Pozovite endpoint `/qrart/generate` za generisanje, i pratite status preko `/qrart/tasks`.

## Primer koda

U nastavku je kompletan Python primer korišćenja QR Art:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_qrart():
    response = requests.post(
        "https://api.acedata.cloud/qrart/generate",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "type": "link",
    "content": "https://platform.acedata.cloud",
    "prompt": "sunset ocean waves",
    "preset": "neon-mech"
},
    )
    return response.json()

result = call_qrart()
print(result)
```

## Najbolje prakse

- **Ponovni pokušaji pri greškama**: Koristite eksponencijalni backoff za greške 429 (ograničenje) i 5xx
- **Asinhroni procesi**: Za dugotrajne zadatke (generisanje slika/video), koristite callback_url za asinhrono primanje rezultata
- **Kontrola troškova**: Pratite upotrebu i troškove putem Ace Data Cloud konzole
- **Bezbednost tokena**: Čuvajte API Token u promenljivim okruženja, nemojte ga hardkodirati u kodu
