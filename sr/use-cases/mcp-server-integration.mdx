## Pregled

Model Context Protocol (MCP) je novi protokol koji omogućava AI programskim asistentima direktno pozivanje eksternih alata i API-ja. Ace Data Cloud pruža više MCP Servera (Suno, Midjourney, SERP itd.) koji se mogu direktno koristiti u alatima kao što su Cursor, Claude Desktop i drugi.

## Uključene usluge

- **Suno**: `POST https://api.acedata.cloud/suno/audios`
- **Midjourney**: `POST https://api.acedata.cloud/midjourney/imagine`
- **Google Search**: `POST https://api.acedata.cloud/serp/google`

## Tehničko rešenje

### Preduslovi

1. Registrujte nalog na [Ace Data Cloud](https://platform.acedata.cloud)
2. Nabavite API Token
3. Instalirajte Python 3.7+ i requests biblioteku

### Koraci implementacije

### Korak 1: Instalacija MCP Servera

Instalirajte preko pip-a: `pip install mcp-suno` (ili mcp-midjourney, mcp-serp).

### Korak 2: Konfiguracija Tokena

Podesite promenljivu okruženja `ACEDATACLOUD_API_TOKEN` na vaš API Token.

### Korak 3: Korišćenje u programskim alatima

Dodajte odgovarajući Server u MCP konfiguraciju u Cursor-u ili Claude Desktop-u.

## Primer koda

Evo kompletan Python primer za korišćenje Suno:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_suno():
    response = requests.post(
        "https://api.acedata.cloud/suno/audios",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "action": "generate",
    "prompt": "A cheerful pop song about summer vacation",
    "model": "chirp-v5",
    "custom": false
},
    )
    return response.json()

result = call_suno()
print(result)
```

## Najbolje prakse

- **Ponovni pokušaji pri greškama**: Koristite eksponencijalni backoff za greške 429 (limitiranje) i 5xx
- **Asinhrono procesiranje**: Za dugotrajne zadatke (generisanje slika/video), koristite callback_url za asinhrono primanje rezultata
- **Kontrola troškova**: Pratite potrošnju i troškove preko Ace Data Cloud konzole
- **Sigurnost Tokena**: Čuvajte API Token u promenljivim okruženja, nemojte ga hardkodirati u kodu
