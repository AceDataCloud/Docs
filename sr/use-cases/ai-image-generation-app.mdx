## Преглед

Технологија генерисања слика помоћу вештачке интелигенције мења индустрије дизајна, маркетинга и креативности. Ace Data Cloud нуди више API-ја за генерисање слика као што су Midjourney, Flux и Seedream, омогућавајући коришћење различитих мотора за генерисање слика на једној платформи.

## Укључене услуге

- **Midjourney**: `POST https://api.acedata.cloud/midjourney/imagine`
- **Flux**: `POST https://api.acedata.cloud/flux/images`
- **Seedream**: `POST https://api.acedata.cloud/seedream/images`

## Техничко решење

### Претпоставке

1. Региструјте налог на [Ace Data Cloud](https://platform.acedata.cloud)
2. Набавите API Token
3. Инсталирајте Python 3.7+ и библиотеку requests

### Кораци имплементације

### Корак 1: Избор мотора за генерисање слика

Midjourney је погодан за уметничке стилове, Flux за фотографски реалистичне слике, а Seedream је водеће домаће решење.

### Корак 2: Позив интерфејса за генерисање

Midjourney користи `/midjourney/imagine`, Flux користи `/flux/images`, а Seedream користи `/seedream/images`.

### Корак 3: Обрада асинхроног резултата

Генерисање слика обично траје од неколико секунди до десетина секунди, препоручује се коришћење callback_url за пријем резултата.

## Пример кода

Испод је комплетан пример у Python-у који користи Midjourney:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_midjourney():
    response = requests.post(
        "https://api.acedata.cloud/midjourney/imagine",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "prompt": "A serene Japanese garden with cherry blossoms",
    "action": "generate",
    "mode": "fast",
    "translation": true
},
    )
    return response.json()

result = call_midjourney()
print(result)
```

## Најбоље праксе

- **Поновни покушаји при грешкама**: користите експоненцијално одлагање за поновне покушаје код 429 (ограничење) и 5xx грешака
- **Асинхрона обрада**: за захтевније задатке (генерисање слика/видео) користите callback_url за асинхрони пријем резултата
- **Контрола трошкова**: пратите потрошњу и трошкове преко Ace Data Cloud конзоле
- **Безбедност Token-а**: чувајте API Token у променљивим окружења, немојте га убацивати директно у код
