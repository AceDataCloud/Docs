## Преглед

AI генерација видео записа је најпопуларнија AI технологија у периоду 2024-2025. Кроз Ace Data Cloud, можете користити различите моделе за генерисање видео записа као што су Sora, Luma, Kling, и изградити аутоматизовану производну линију за видео.

## Укључене услуге

- **Sora**: `POST https://api.acedata.cloud/sora/videos`
- **Luma**: `POST https://api.acedata.cloud/luma/videos`
- **Kling**: `POST https://api.acedata.cloud/kling/videos`

## Техничко решење

### Предуслови

1. Региструјте налог на [Ace Data Cloud](https://platform.acedata.cloud)
2. Добијте API Token
3. Инсталирајте Python 3.7+ и библиотеку requests

### Кораци за имплементацију

### Корак 1: Избор видео модела

Sora је специјализован за филмски квалитет слике, Luma подржава контролу почетних и завршних кадрова, Kling омогућава брзу генерацију.

### Корак 2: Подношење задатка за генерисање

Sora користи `/sora/videos`, Luma користи `/luma/videos`, Kling користи `/kling/videos`.

### Корак 3: Провера статуса задатка

Сви видео API-ји подржавају праћење напретка задатка преко `/tasks` ендпоинта.

## Пример кода

Испод је комплетан Python пример коришћења Sora:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_sora():
    response = requests.post(
        "https://api.acedata.cloud/sora/videos",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
},
    )
    return response.json()

result = call_sora()
print(result)
```

## Најбоље праксе

- **Поновни покушаји при грешкама**: Користите експоненцијално одлагање за поновне покушаје код 429 (ограничење захтева) и 5xx грешака
- **Асинхрони рад**: За дуготрајне задатке (генерисање слика/видео записа), користите callback_url за асинхрони пријем резултата
- **Контрола трошкова**: Пратите потрошњу и трошкове преко Ace Data Cloud конзоле
- **Безбедност Token-а**: Чувајте API Token у променљивим окружења, немојте га убацивати директно у код
