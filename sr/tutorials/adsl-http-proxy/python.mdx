## Увод

ADSL HTTP Proxy је мрежна прокси услуга коју пружа Ace Data Cloud, за екстракцију динамичких ADSL прокси IP адреса. Кроз јединствени API Ace Data Cloud-а, можете брзо интегрисати ADSL HTTP Proxy у Python-у и остварити функције као што су HTTP/SOCKS прокси, више оператера, више провинција, прилагођено трајање, бела листа IP адреса и друго.

## Предуслови

- Имате налог на [Ace Data Cloud](https://platform.acedata.cloud) и добијен API Token
- Python 3.7 или новији
- Инсталирана библиотека requests: `pip install requests`

## Основна употреба

Главна тачка позива ADSL HTTP Proxy API-ја је:

```
POST https://api.acedata.cloud/adsl/extract
```

Комплетан пример Python кода:

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "number": 5,
    "type": "http",
    "duration": 300,
    "province": "广东",
    "isp": "电信"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Замените `YOUR_API_TOKEN` стварним Token-ом који сте добили на платформи Ace Data Cloud.

## Обрада одговора

Након успешног позива, API враћа податке у JSON формату. Препоручује се провера HTTP статуса:

```python
if response.status_code == 200:
    result = response.json()
    print("Позив успешан:", result)
else:
    print(f"Позив није успео, статусни код: {response.status_code}")
    print(response.text)
```

## Напредна употреба

За API који подржава асинхроне задатке, резултате можете добити преко callback URL-а:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Резултати ће бити послати на ваш сервер преко callback URL-а
```

## Обрада грешака

Чести кодови грешака:

| Статусни код | Опис |
|--------------|-------|
| 401 | Аутентификација није успела, проверите API Token |
| 403 | Недовољно средстава или нема приступа |
| 429 | Прекорачење ограничења учесталости захтева |
| 500 | Унутрашња грешка сервера |
