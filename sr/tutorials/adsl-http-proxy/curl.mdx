## Uvod

ADSL HTTP Proxy je mrežna proxy usluga koju pruža Ace Data Cloud, omogućavajući ekstrakciju dinamičkih ADSL proxy IP adresa. Kroz jedinstveni API Ace Data Cloud-a, možete brzo koristiti cURL za pozivanje ADSL HTTP Proxy-ja i ostvariti funkcije kao što su HTTP/SOCKS proxy, više operatera, različite provincije, prilagođeno trajanje i IP whitelist.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Instalirano cURL okruženje u terminalu

## Osnovna upotreba

Glavna tačka za pozivanje ADSL HTTP Proxy API-ja je:

```
POST https://api.acedata.cloud/adsl/extract
```

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}'
```

Molimo zamenite `YOUR_API_TOKEN` stvarnim Tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Nakon uspešnog poziva vraćaju se podaci u JSON formatu, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiran ispis:

```bash
curl -s -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}' | jq .
```

## Obrada grešaka

Uobičajeni kodovi grešaka:

| Status kod | Objašnjenje                      |
|------------|---------------------------------|
| 401        | Autentikacija nije uspela, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera          |
