## Uvod

ADSL HTTP Proxy je mrežna proxy usluga koju pruža Ace Data Cloud, za ekstrakciju dinamičkih ADSL proxy IP adresa. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati ADSL HTTP Proxy koristeći JavaScript i ostvariti funkcije kao što su HTTP/SOCKS proxy, više operatera, više provincija, prilagođeno trajanje, IP bela lista i druge.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Node.js 18+ ili moderan pregledač

## Osnovna upotreba

Glavna tačka poziva ADSL HTTP Proxy API-ja je:

```
POST https://api.acedata.cloud/adsl/extract
```

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/adsl/extract", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "number": 5,
  "type": "http",
  "duration": 300,
  "province": "广东",
  "isp": "电信"
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se da proverite statusni kod odgovora i obradite greške:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js enkapsulacija

Preporučuje se enkapsulacija u funkciju za višekratnu upotrebu:

```javascript
async function callADSLHTTPProxy(data) {
  const response = await fetch("https://api.acedata.cloud/adsl/extract", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Česti statusni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401          | Autentifikacija neuspešna, proverite API Token |
| 403          | Nedovoljno sredstava ili nema pristupa |
| 429          | Prekoračena frekvencija zahteva |
| 500          | Interna greška servera |
