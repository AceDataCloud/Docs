## Uvod

Suno je AI audio servis koji pruža Ace Data Cloud, Suno AI generisanje muzike. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Suno koristeći Python, i ostvariti funkcije kao što su generisanje muzike iz teksta, prilagođeni tekstovi pesama, nastavak pesama, obrada pesama, izdvajanje vokala, generisanje tekstova i druge.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python okruženje verzije 3.7 ili novije
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka za pozivanje Suno API-ja je:

```
POST https://api.acedata.cloud/suno/audios
```

U ovom primeru koristi se model `chirp-v5`.
Dostupni modeli uključuju: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`.

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A cheerful pop song about summer vacation",
    "model": "chirp-v5",
    "custom": false
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv nije uspeo, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultat se može dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultat će biti poslat na vaš server putem callback URL-a
```

## Obrada grešaka

Česti kodovi grešaka:

| Status kod | Objašnjenje |
|------------|-------------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena frekvencija zahteva |
| 500 | Interna greška servera |
