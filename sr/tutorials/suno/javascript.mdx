## Uvod

Suno je AI audio servis koji pruža Ace Data Cloud, Suno AI generisanje muzike. Kroz jedinstveni API Ace Data Clouda, možete brzo integrisati Suno koristeći JavaScript i ostvariti funkcije kao što su generisanje muzike iz teksta, prilagođeni tekstovi pesama, nastavak pesama, obrada cover verzija, separacija vokala, generisanje tekstova i drugo.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Node.js 18+ ili moderan pregledač

## Osnovna upotreba

Glavna krajnja tačka za pozivanje Suno API-ja je:

```
POST https://api.acedata.cloud/suno/audios
```

Ovaj primer koristi model `chirp-v5`.
Dostupni modeli su: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`.

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/suno/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A cheerful pop song about summer vacation",
  "model": "chirp-v5",
  "custom": false
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se da proverite statusni kod odgovora i obradite greške:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv nije uspeo, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js enkapsulacija

Preporučuje se enkapsulacija u ponovo upotrebljivu funkciju:

```javascript
async function callSuno(data) {
  const response = await fetch("https://api.acedata.cloud/suno/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Česti statusni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401          | Autentifikacija nije uspela, proverite API Token |
| 403          | Nedovoljno sredstava ili nema pristupa |
| 429          | Prekoračena frekvencija zahteva |
| 500          | Interna greška servera |
