## Uvod

Suno je AI audio servis koji pruža Ace Data Cloud, Suno AI generisanje muzike. Kroz jedinstveni API Ace Data Cloud-a, možete brzo koristiti cURL za pozivanje Suno servisa i ostvariti funkcije kao što su generisanje muzike iz teksta, prilagođeni tekstovi pesama, nastavak pesama, obrada cover verzija, izdvajanje vokala i generisanje tekstova pesama.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Instalirano cURL okruženje u terminalu

## Osnovna upotreba

Glavna krajnja tačka za pozivanje Suno API-ja je:

```
POST https://api.acedata.cloud/suno/audios
```

U ovom primeru koristi se model `chirp-v5`.
Dostupni modeli su: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`.

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}'
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Uspešan poziv vraća JSON formatirane podatke, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiran i pregledan ispis:

```bash
curl -s -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}' | jq .
```

## Rukovanje greškama

Česti kodovi grešaka:

| Status kod | Objašnjenje |
|------------|-------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračenje ograničenja učestalosti zahteva |
| 500        | Interna greška servera |
