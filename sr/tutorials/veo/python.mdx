## Uvod

Veo je AI video servis koji pruža Ace Data Cloud, Google Veo model za generisanje video zapisa. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Veo koristeći Python, omogućavajući funkcije kao što su generisanje video zapisa iz teksta, generisanje video zapisa iz slika, 4K rezolucija, različiti aspekti slike i još mnogo toga.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python okruženje verzije 3.7 ili novije
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka za pozivanje Veo API-ja je:

```
POST https://api.acedata.cloud/veo/videos
```

U ovom primeru koristi se model `veo3`.
Dostupni modeli uključuju: `veo2`, `veo2-fast`, `veo3`, `veo3-fast`, `veo31`, `veo31-fast`.

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/veo/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "text2video",
    "prompt": "A coffee mug rotating slowly on a marble counter",
    "model": "veo3"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim Tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultat možete dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultat će biti poslat na vaš server putem callback URL-a
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Opis |
|------------|------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena frekvencija zahteva |
| 500 | Interna greška servera |
