## Uvod

Veo je AI video servis koji pruža Ace Data Cloud, Google Veo model za generisanje videa. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Veo koristeći JavaScript i ostvariti funkcije kao što su video generisan iz teksta, video generisan iz slika, 4K rezolucija, različiti aspekti slike i drugo.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Node.js 18+ ili moderan pregledač

## Osnovna upotreba

Glavna tačka za pozivanje Veo API-ja je:

```
POST https://api.acedata.cloud/veo/videos
```

Ovaj primer koristi model `veo3`.
Dostupni modeli su: `veo2`, `veo2-fast`, `veo3`, `veo3-fast`, `veo31`, `veo31-fast`.

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/veo/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "text2video",
  "prompt": "A coffee mug rotating slowly on a marble counter",
  "model": "veo3"
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se da proverite statusni kod odgovora i obradite greške:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv nije uspeo, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js omot

Preporučuje se enkapsulacija u funkciju za ponovnu upotrebu:

```javascript
async function callVeo(data) {
  const response = await fetch("https://api.acedata.cloud/veo/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Česti statusni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401 | Autentifikacija nije uspela, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena frekvencija zahteva |
| 500 | Interna greška servera |
