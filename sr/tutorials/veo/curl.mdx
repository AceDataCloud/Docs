title: "Veo cURL Brzi Vodič"
---

## Uvod

Veo je AI video servis koji pruža Ace Data Cloud, koristeći Google Veo model za generisanje video zapisa. Kroz jedinstveni API Ace Data Cloud-a, možete brzo pozvati Veo koristeći cURL i ostvariti funkcije kao što su generisanje videa iz teksta, generisanje videa iz slika, 4K rezolucija, različiti formati i drugi.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Okruženje sa instaliranim cURL-om

## Osnovna upotreba

Glavna tačka za pozivanje Veo API-ja je:

```
POST https://api.acedata.cloud/veo/videos
```

Ovaj primer koristi model `veo3`.
Dostupni modeli su: `veo2`, `veo2-fast`, `veo3`, `veo3-fast`, `veo31`, `veo31-fast`.

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/veo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A coffee mug rotating slowly on a marble counter", "model": "veo3"}'
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Uspešan poziv vraća podatke u JSON formatu, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiranje izlaza:

```bash
curl -s -X POST https://api.acedata.cloud/veo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A coffee mug rotating slowly on a marble counter", "model": "veo3"}' | jq .
```

## Obrada grešaka

Česti kodovi grešaka:

| Status kod | Opis                          |
|------------|-------------------------------|
| 401        | Autentifikacija nije uspela, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera         |
