## Uvod

Nano Banana je AI usluga za slike koju pruža Ace Data Cloud, zasnovana na Gemini servisu za generisanje slika. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Nano Banana koristeći JavaScript i ostvariti funkcije kao što su generisanje slika iz teksta, uređivanje slika, različiti aspekti slike i visoka rezolucija.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Node.js 18+ ili moderan pregledač

## Osnovna upotreba

Glavna tačka za pozivanje Nano Banana API-ja je:

```
POST https://api.acedata.cloud/nano-banana/images
```

U ovom primeru koristi se model `nano-banana-2`.
Dostupni modeli su: `nano-banana`, `nano-banana-2`, `nano-banana-pro`.

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/nano-banana/images", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A white siamese cat",
  "model": "nano-banana-2",
  "aspect_ratio": "1:1"
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim Tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se provera statusnog koda odgovora i obrada grešaka:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js omot

Preporučuje se enkapsulacija u funkciju za ponovnu upotrebu:

```javascript
async function callNanoBanana(data) {
  const response = await fetch("https://api.acedata.cloud/nano-banana/images", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Česti statusni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena učestalost zahteva |
| 500 | Interna greška servera |
