## Uvod

Nano Banana je AI servis za slike koji pruža Ace Data Cloud, zasnovan na Gemini servisu za generisanje slika. Kroz jedinstveni API Ace Data Cloud-a, možete brzo pozvati Nano Banana koristeći cURL i ostvariti funkcije kao što su generisanje slika iz teksta, uređivanje slika, različiti aspektni odnosi i visoke rezolucije.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Terminal okruženje sa instaliranim cURL-om

## Osnovna upotreba

Glavna krajnja tačka za pozivanje Nano Banana API-ja je:

```
POST https://api.acedata.cloud/nano-banana/images
```

U ovom primeru koristi se model `nano-banana-2`.
Dostupni modeli su: `nano-banana`, `nano-banana-2`, `nano-banana-pro`.

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat", "model": "nano-banana-2", "aspect_ratio": "1:1"}'
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Nakon uspešnog poziva vraća se JSON formatiran odgovor, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiran prikaz:

```bash
curl -s -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat", "model": "nano-banana-2", "aspect_ratio": "1:1"}' | jq .
```

## Obrada grešaka

Uobičajeni kodovi grešaka:

| Status kod | Objašnjenje |
|------------|-------------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena frekvencija zahteva |
| 500 | Interna greška servera |
