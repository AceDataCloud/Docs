## Uvod

Nano Banana je AI servis za slike koji pruža Ace Data Cloud, zasnovan na Gemini servisu za generisanje slika. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Nano Banana koristeći Python i ostvariti funkcije kao što su generisanje slika iz teksta, uređivanje slika, različiti odnosi stranica i visoka rezolucija.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Python 3.7 ili noviji
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka za pozivanje Nano Banana API-ja je:

```
POST https://api.acedata.cloud/nano-banana/images
```

U ovom primeru koristi se model `nano-banana-2`.
Dostupni modeli su: `nano-banana`, `nano-banana-2`, `nano-banana-pro`.

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A white siamese cat",
    "model": "nano-banana-2",
    "aspect_ratio": "1:1"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultat se može dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultat će biti poslat na vaš server putem callback URL-a
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Objašnjenje                      |
|------------|---------------------------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva  |
| 500        | Interna greška servera           |
