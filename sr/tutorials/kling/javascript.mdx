## Увод

Kling је AI видео услуга коју пружа Ace Data Cloud, модел за брзо генерисање видео записа. Кроз унификовани API Ace Data Cloud-а, можете брзо интегрисати Kling користећи JavaScript и реализовати функције као што су генерисање видео записа из текста, слика, продужење видео записа, различити трајања и пропорције.

## Претпоставке

- Имате налог на [Ace Data Cloud](https://platform.acedata.cloud) и добијен API Token
- Node.js 18+ или савремено прегледачко окружење

## Основна употреба

Главна тачка позива Kling API-ја је:

```
POST https://api.acedata.cloud/kling/videos
```

У овом примеру користи се модел `kling-v2-5-turbo`.
Доступни модели укључују: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`.

Комплетан пример JavaScript кода:

```javascript
const response = await fetch("https://api.acedata.cloud/kling/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "text2video",
  "prompt": "A white cat walking in the snow",
  "model": "kling-v2-5-turbo",
  "duration": 5,
  "aspect_ratio": "16:9"
}),
});

const result = await response.json();
console.log(result);
```

Замените `YOUR_API_TOKEN` стварним токеном који сте добили на платформи Ace Data Cloud.

## Обрада одговора

Препоручује се провера статуса одговора и руковање грешкама:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Позив успешан:", result);
} else {
  console.error(`Позив није успео, статусни код: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js омотач

Препоручује се да се позив омотa у поновно употребљиву функцију:

```javascript
async function callKling(data) {
  const response = await fetch("https://api.acedata.cloud/kling/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API грешка: ${response.status}`);
  return response.json();
}
```

## Руководење грешкама

Чести кодови грешака:

| Статусни код | Објашњење                      |
|--------------|-------------------------------|
| 401          | Аутентификација није успела, проверите API Token |
| 403          | Недовољно средстава или нема приступа |
| 429          | Прекорачен лимит захтева        |
| 500          | Унутрашња грешка сервера       |
