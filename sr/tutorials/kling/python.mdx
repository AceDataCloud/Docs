## Uvod

Kling je AI video servis koji pruža Ace Data Cloud, model za generisanje video zapisa na platformi Kuaishou. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Kling koristeći Python i ostvariti funkcije kao što su generisanje videa iz teksta, generisanje videa iz slika, produžavanje videa, različiti vremenski intervali i različiti aspekti slike.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python verzija 3.7 ili novija
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka poziva Kling API-ja je:

```
POST https://api.acedata.cloud/kling/videos
```

U ovom primeru koristi se model `kling-v2-5-turbo`.
Dostupni modeli uključuju: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`.

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "text2video",
    "prompt": "A white cat walking in the snow",
    "model": "kling-v2-5-turbo",
    "duration": 5,
    "aspect_ratio": "16:9"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na platformi Ace Data Cloud.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultate možete dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultati će biti poslati na vaš server putem callback URL-a
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Objašnjenje                   |
|------------|------------------------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera       |
