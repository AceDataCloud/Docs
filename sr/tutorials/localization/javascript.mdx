## Увод

Localization је алатска услуга коју пружа Ace Data Cloud, AI преводилачка услуга за локализацију. Кроз јединствени API Ace Data Cloud-а, можете брзо интегрисати Localization користећи JavaScript, омогућавајући превод Markdown-а, JSON-а, подршку за 18 језика и очување формата.

## Предуслови

- Имате [Ace Data Cloud](https://platform.acedata.cloud) налог и добијен API Token
- Node.js 18+ или савремено прегледачко окружење

## Основна употреба

Главна тачка позива Localization API-ја је:

```
POST https://api.acedata.cloud/localization/translate
```

У овом примеру користи се модел `gpt-4`.
Доступни модели укључују: `gpt-3.5`, `gpt-4`.

Комплетан пример JavaScript кода:

```javascript
const response = await fetch("https://api.acedata.cloud/localization/translate", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "input": "# 欢迎使用\n\n这是一段示例文本。",
  "locale": "en",
  "extension": "md",
  "model": "gpt-4"
}),
});

const result = await response.json();
console.log(result);
```

Молимо замените `YOUR_API_TOKEN` стварним Token-ом који сте добили на платформи Ace Data Cloud.

## Обрада одговора

Препоручује се провера статуса одговора и руковање грешкама:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Позив успешан:", result);
} else {
  console.error(`Позив није успео, статусни код: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js омотач

Препоручује се паковање у поновно употребљиву функцију:

```javascript
async function callLocalization(data) {
  const response = await fetch("https://api.acedata.cloud/localization/translate", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API грешка: ${response.status}`);
  return response.json();
}
```

## Руководство грешкама

Чести кодови грешака:

| Статусни код | Објашњење |
|--------------|-----------|
| 401          | Аутентификација није успела, проверите API Token |
| 403          | Недовољно средстава или нема приступа |
| 429          | Прекорачење ограничења учесталости захтева |
| 500          | Унутрашња грешка сервера |
