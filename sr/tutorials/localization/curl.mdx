## Uvod

Localization je alat usluga koji pruža Ace Data Cloud, AI servis za prevođenje i lokalizaciju. Kroz jedinstveni API Ace Data Cloud-a, možete brzo koristiti Localization putem cURL-a za prevođenje Markdown-a, JSON-a, na 18 jezika, uz očuvanje formata i druge funkcije.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Instaliran cURL u terminalskom okruženju

## Osnovna upotreba

Glavna krajnja tačka za pozivanje Localization API-ja je:

```
POST https://api.acedata.cloud/localization/translate
```

U ovom primeru koristi se model `gpt-4`.
Dostupni modeli uključuju: `gpt-3.5`, `gpt-4`.

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}'
```

Zamenite `YOUR_API_TOKEN` stvarnim Tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Nakon uspešnog poziva vraća se JSON format podataka, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiran izlaz:

```bash
curl -s -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}' | jq .
```

## Obrada grešaka

Česti kodovi grešaka:

| Status kod | Objašnjenje                         |
|------------|-----------------------------------|
| 401        | Autentifikacija nije uspela, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva    |
| 500        | Interna greška servera             |
