## Увод

Localization је алатска услуга коју пружа Ace Data Cloud, AI услуга за превод и локализацију. Кроз јединствени API Ace Data Cloud-а, можете брзо интегрисати Localization у Python и реализовати функције као што су превод Markdown-а, превод JSON-а, подршка за 18 језика и очување формата.

## Претпоставке

- Имате налог на [Ace Data Cloud](https://platform.acedata.cloud) и добијен API Token
- Python окружење верзије 3.7 или новије
- Инсталирана библиотека requests: `pip install requests`

## Основна употреба

Главна тачка позива Localization API-ја је:

```
POST https://api.acedata.cloud/localization/translate
```

У овом примеру користи се модел `gpt-4`.
Доступни модели укључују: `gpt-3.5`, `gpt-4`.

Комплетан пример Python кода:

```python
import requests

url = "https://api.acedata.cloud/localization/translate"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "input": "# 欢迎使用\n\n这是一段示例文本。",
    "locale": "en",
    "extension": "md",
    "model": "gpt-4"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Замените `YOUR_API_TOKEN` стварним Token-ом који сте добили на платформи Ace Data Cloud.

## Обрада одговора

Након успешног позива, API враћа податке у JSON формату. Препоручује се провера HTTP статус кода:

```python
if response.status_code == 200:
    result = response.json()
    print("Позив успешан:", result)
else:
    print(f"Позив није успео, статус код: {response.status_code}")
    print(response.text)
```

## Напредна употреба

За API који подржава асинхроне задатке, резултате можете добити преко callback URL-а:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Резултати ће бити послати на ваш сервер преко callback URL-а
```

## Обрада грешака

Чести статус кодови грешака:

| Статус код | Опис |
|------------|-------|
| 401        | Аутентификација није успела, проверите API Token |
| 403        | Недовољно средстава или нема приступа |
| 429        | Прекорачен лимит захтева |
| 500        | Унутрашња грешка сервера |
