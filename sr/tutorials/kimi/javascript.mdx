## Uvod

Kimi je AI servis za chat koji pruža Ace Data Cloud, zasnovan na velikom jezičkom modelu iz serije 月之暗面 Kimi. Korišćenjem jedinstvenog API-ja Ace Data Cloud, možete brzo integrisati Kimi u JavaScript aplikacije i ostvariti funkcije kao što su višekratni dijalozi, sistemske prompt poruke, strimovani izlaz, JSON izlazni mod i druge.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Node.js verzija 18+ ili moderan pregledač

## Osnovna upotreba

Glavna tačka poziva Kimi API-ja je:

```
POST https://api.acedata.cloud/kimi/chat/completions
```

U ovom primeru koristi se model `kimi-k2.5`.
Dostupni modeli uključuju: `kimi-k2.5`, `kimi-k2-thinking-turbo`, `kimi-k2-thinking`, `kimi-k2-instruct-0905`.

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "kimi-k2.5",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se provera statusnog koda odgovora i rukovanje greškama:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js enkapsulacija

Preporučuje se enkapsulacija u funkciju za višekratnu upotrebu:

```javascript
async function callKimi(data) {
  const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Rukovanje greškama

Česti statusni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401          | Autentifikacija neuspešna, proverite API Token |
| 403          | Nedovoljno sredstava ili nema pristupa |
| 429          | Prekoračena frekvencija zahteva |
| 500          | Interna greška servera |
