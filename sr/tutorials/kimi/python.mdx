## Uvod

Kimi je AI servis za ćaskanje koji pruža Ace Data Cloud, deo serije velikih jezičkih modela Moon's Dark Side Kimi. Korišćenjem jedinstvenog API-ja Ace Data Cloud, možete brzo integrisati Kimi u Python i ostvariti funkcije kao što su višekratni dijalog, sistemske poruke, strimovanje izlaza i JSON izlazni režim.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python verzija 3.7 ili novija
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka za pozivanje Kimi API-ja je:

```
POST https://api.acedata.cloud/kimi/chat/completions
```

U ovom primeru koristi se model `kimi-k2.5`.
Dostupni modeli uključuju: `kimi-k2.5`, `kimi-k2-thinking-turbo`, `kimi-k2-thinking`, `kimi-k2-instruct-0905`.

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "kimi-k2.5",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API za ćaskanje podržano je strimovanje izlaza radi dobijanja odgovora u realnom vremenu:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Objašnjenje                      |
|------------|---------------------------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera          |
