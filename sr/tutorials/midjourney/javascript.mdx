## Uvod

Midjourney je AI usluga za generisanje slika koju pruža Ace Data Cloud. Midjourney AI generiše slike. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Midjourney koristeći JavaScript i ostvariti funkcije kao što su generisanje slika iz teksta, uređivanje slika, opisivanje slika, generisanje video zapisa iz slika, kontrola Seed vrednosti, asinhroni callback i druge.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Node.js 18+ ili moderan pregledač

## Osnovna upotreba

Glavna tačka za pozivanje Midjourney API-ja je:

```
POST https://api.acedata.cloud/midjourney/imagine
```

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/midjourney/imagine", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "A serene Japanese garden with cherry blossoms",
  "action": "generate",
  "mode": "fast",
  "translation": true
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim Tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se da proverite statusni kod odgovora i obradite greške:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js enkapsulacija

Preporučuje se enkapsulacija u ponovo upotrebljivu funkciju:

```javascript
async function callMidjourney(data) {
  const response = await fetch("https://api.acedata.cloud/midjourney/imagine", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Uobičajeni statusni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401          | Autentifikacija neuspešna, proverite API Token |
| 403          | Nedovoljno sredstava ili nema pristupa |
| 429          | Prekoračenje limite zahteva |
| 500          | Interna greška servera |
