## Uvod

OpenAI je AI servis za ćaskanje koji pruža Ace Data Cloud, zasnovan na velikim jezičkim modelima iz OpenAI GPT serije. Kroz jedinstveni API Ace Data Cloud-a, možete brzo koristiti OpenAI putem cURL-a za višekratne dijaloge, sistemske promptove, strimovanje izlaza, JSON režim izlaza, tekstualne ugradnje, generisanje slika i druge funkcije.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Instalirano okruženje terminala sa cURL-om

## Osnovna upotreba

Glavna tačka poziva OpenAI API-ja je:

```
POST https://api.acedata.cloud/openai/chat/completions
```

U ovom primeru koristi se model `gpt-4o`.
Dostupni modeli uključuju: `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`.

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Nakon uspešnog poziva vraćaju se podaci u JSON formatu, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiranje izlaza:

```bash
curl -s -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Obrada grešaka

Uobičajeni kodovi grešaka:

| Status kod | Objašnjenje                     |
|------------|--------------------------------|
| 401        | Autentifikacija nije uspela, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera          |
