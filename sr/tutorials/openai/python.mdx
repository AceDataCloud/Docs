## Uvod

OpenAI je AI servis za ćaskanje koji pruža Ace Data Cloud, zasnovan na velikim jezičkim modelima iz OpenAI GPT serije. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati OpenAI koristeći Python i ostvariti funkcije kao što su višekratni dijalozi, sistemske upute, strimovani izlaz, JSON izlazni režim, tekstualne ugrađenosti i generisanje slika.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python okruženje verzije 3.7 ili novije
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka za pozivanje OpenAI API-ja je:

```
POST https://api.acedata.cloud/openai/chat/completions
```

U ovom primeru koristi se model `gpt-4o`.
Dostupni modeli uključuju: `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`.

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API za ćaskanje podržan je strimovani izlaz za dobijanje odgovora u realnom vremenu:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Opis                          |
|------------|-------------------------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera        |
