## Uvod

OpenAI je AI servis za ćaskanje koji pruža Ace Data Cloud, zasnovan na OpenAI GPT seriji velikih jezičkih modela. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati OpenAI koristeći JavaScript, omogućavajući višekratne razgovore, sistemske promptove, strimovanje izlaza, JSON izlazni režim, tekstualne ugradnje, generisanje slika i druge funkcionalnosti.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Node.js 18+ ili savremeno okruženje pregledača

## Osnovna upotreba

Glavna tačka poziva OpenAI API-ja je:

```
POST https://api.acedata.cloud/openai/chat/completions
```

U ovom primeru koristi se model `gpt-4o`.
Dostupni modeli uključuju: `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`.

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/openai/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "gpt-4o",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim Tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se da proverite statusni kod odgovora i obradite greške:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js omot

Preporučuje se enkapsulacija u ponovo upotrebljivu funkciju:

```javascript
async function callOpenAI(data) {
  const response = await fetch("https://api.acedata.cloud/openai/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Uobičajeni statusni kodovi grešaka:

| Statusni kod | Objašnjenje                        |
|--------------|----------------------------------|
| 401          | Autentifikacija neuspešna, proverite API Token |
| 403          | Nedovoljno sredstava ili nema pristupa |
| 429          | Prekoračenje ograničenja zahteva  |
| 500          | Interna greška servera            |
