## Uvod

AI Chat je AI servis za ćaskanje koji pruža Ace Data Cloud, sa podrškom za višestruke AI modele za dijalog. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati AI Chat u Python, omogućavajući podršku za više modela, održavanje stanja razgovora, unapred definisane uloge i druge funkcionalnosti.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python verzija 3.7 ili novija
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka za pozivanje AI Chat API-ja je:

```
POST https://api.acedata.cloud/aichat/conversations
```

U ovom primeru koristi se model `gpt-4o`.
Dostupni modeli uključuju: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Kompletan Python primer koda:

```python
import requests

url = "https://api.acedata.cloud/aichat/conversations"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gpt-4o",
    "question": "Šta je veštačka inteligencija?",
    "stateful": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se da proverite HTTP status kod:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultat možete dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultat će biti poslat na vaš server putem callback URL-a
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Objašnjenje                     |
|------------|--------------------------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera         |
