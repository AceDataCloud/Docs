## Увод

AI Chat је AI услуга за ћаскање коју пружа Ace Data Cloud, мулти-модел AI дијалог услуга. Кроз Ace Data Cloud унифицирани API, можете брзо интегрисати AI Chat користећи JavaScript, омогућавајући подршку за више модела, дијалоге са стањем и унапред подешене улоге.

## Предуслови

- Имајте налог на [Ace Data Cloud](https://platform.acedata.cloud) и добијте API Token
- Node.js 18+ или модерно прегледачко окружење

## Основна употреба

Главна тачка позива AI Chat API је:

```
POST https://api.acedata.cloud/aichat/conversations
```

Овај пример користи модел `gpt-4o`.
Доступни модели укључују: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Комплетан пример JavaScript кода:

```javascript
const response = await fetch("https://api.acedata.cloud/aichat/conversations", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "gpt-4o",
  "question": "什么是人工智能？",
  "stateful": true
}),
});

const result = await response.json();
console.log(result);
```

Замените `YOUR_API_TOKEN` стварним токеном који сте добили на Ace Data Cloud платформи.

## Обрада одговора

Препоручује се провера статуса одговора и руковање грешкама:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Позив успешан:", result);
} else {
  console.error(`Позив није успео, статусни код: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js омотач

Препоручује се паковање у поновно употребљиву функцију:

```javascript
async function callAIChat(data) {
  const response = await fetch("https://api.acedata.cloud/aichat/conversations", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Руководство грешкама

Чести кодови грешака:

| Статусни код | Објашњење |
|--------------|-----------|
| 401          | Аутентификација није успела, проверите API Token |
| 403          | Недовољно средстава или нема приступа |
| 429          | Прекорачена учесталост захтева |
| 500          | Унутрашња грешка сервера |
