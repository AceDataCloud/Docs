## Uvod

AI Chat je AI servis za razgovor koji pruža Ace Data Cloud, servis za višemodelni AI dijalog. Kroz jedinstveni API Ace Data Cloud-a, možete brzo pozvati AI Chat koristeći cURL i ostvariti podršku za više modela, dijaloge sa stanjem, unapred definisane uloge i druge funkcije.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Instalirano cURL okruženje u terminalu

## Osnovna upotreba

Glavna krajnja tačka za pozivanje AI Chat API-ja je:

```
POST https://api.acedata.cloud/aichat/conversations
```

U ovom primeru koristi se model `gpt-4o`.
Dostupni modeli uključuju: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}'
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Nakon uspešnog poziva vraćaju se podaci u JSON formatu, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiran izlaz:

```bash
curl -s -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}' | jq .
```

## Obrada grešaka

Uobičajeni kodovi grešaka:

| Status kod | Objašnjenje                      |
|------------|---------------------------------|
| 401        | Neuspešna autentifikacija, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva  |
| 500        | Interna greška servera           |
