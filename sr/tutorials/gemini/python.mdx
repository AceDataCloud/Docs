## Uvod

Gemini je AI servis za razgovor koji pruža Ace Data Cloud, zasnovan na Google Gemini seriji velikih jezičkih modela. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Gemini u Python i koristiti funkcije kao što su višekratni dijalozi, sistemske upute, strimovanje izlaza i JSON izlazni režim.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python okruženje verzije 3.7 ili novije
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka poziva Gemini API-ja je:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

U ovom primeru koristi se model `gemini-2.5-flash`.
Dostupni modeli uključuju: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Kompletan Python primer koda:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gemini-2.5-flash",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na platformi Ace Data Cloud.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API za razgovor podržano je strimovanje izlaza radi dobijanja odgovora u realnom vremenu:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Objašnjenje                       |
|------------|---------------------------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera          |
