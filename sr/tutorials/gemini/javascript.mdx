## Uvod

Gemini je AI servis za razgovor koji pruža Ace Data Cloud, zasnovan na Google Gemini seriji velikih jezičkih modela. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Gemini koristeći JavaScript i ostvariti funkcije kao što su višekratni dijalozi, sistemske upute, strimovani izlaz, JSON izlazni režim i druge.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API token
- Node.js 18+ ili savremeno okruženje pregledača

## Osnovna upotreba

Glavna tačka poziva Gemini API-ja je:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

U ovom primeru koristi se model `gemini-2.5-flash`.
Dostupni modeli uključuju: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/gemini/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "gemini-2.5-flash",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na platformi Ace Data Cloud.

## Obrada odgovora

Preporučuje se da proverite statusni kod odgovora i obradite greške:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js omot

Preporučuje se enkapsulacija u funkciju koja se može ponovo koristiti:

```javascript
async function callGemini(data) {
  const response = await fetch("https://api.acedata.cloud/gemini/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Uobičajeni statusni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401          | Autentifikacija neuspešna, proverite API token |
| 403          | Nedovoljno sredstava ili nema pristupa |
| 429          | Prekoračena frekvencija zahteva |
| 500          | Interna greška servera |
