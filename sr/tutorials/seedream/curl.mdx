---

## Uvod

Seedream je AI usluga za slike koju pruža Ace Data Cloud, zasnovana na Seedream modelu za generisanje slika kompanije ByteDance. Kroz jedinstveni API Ace Data Cloud-a, možete brzo koristiti Seedream putem cURL-a za generisanje slika iz teksta, uređivanje slika, različite rezolucije, kontrolu vodenih žigova i druge funkcije.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Instalirano cURL okruženje u terminalu

## Osnovna upotreba

Glavna krajnja tačka za pozivanje Seedream API-ja je:

```
POST https://api.acedata.cloud/seedream/images
```

U ovom primeru koristi se model `doubao-seedream-4-0-250828`. Dostupni modeli uključuju: `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`, `doubao-seedream-3-0-t2i-250415`, `doubao-seededit-3-0-i2i-250628`.

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}'
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Uspešan poziv vraća podatke u JSON formatu, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiran izlaz:

```bash
curl -s -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}' | jq .
```

## Obrada grešaka

Uobičajeni kodovi grešaka:

| Status kod | Opis                          |
|------------|-------------------------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera        |
