## Uvod

Seedream je AI servis za slike koji pruža Ace Data Cloud, koristeći Seedream model za generisanje slika kompanije ByteDance. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Seedream u Python-u i ostvariti funkcije kao što su generisanje slika iz teksta, uređivanje slika, različite rezolucije i kontrola vodenih žigova.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python okruženje verzije 3.7 ili novije
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka za pozivanje Seedream API-ja je:

```
POST https://api.acedata.cloud/seedream/images
```

U ovom primeru koristi se model `doubao-seedream-4-0-250828`.
Dostupni modeli uključuju: `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`, `doubao-seedream-3-0-t2i-250415`, `doubao-seededit-3-0-i2i-250628`.

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/seedream/images"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "бела сијамска мачка седи на прозорској дасци",
    "model": "doubao-seedream-4-0-250828",
    "size": "1K"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Molimo zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultate možete dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultati će biti poslati na vaš server putem callback URL-a
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Opis |
|------------|------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena frekvencija zahteva |
| 500 | Interna greška servera |
