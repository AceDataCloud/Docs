## Uvod

Seedream je AI servis za slike koji pruža Ace Data Cloud, zasnovan na Seedream modelu za generisanje slika kompanije ByteDance. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Seedream koristeći JavaScript i ostvariti funkcije kao što su generisanje slika iz teksta, uređivanje slika, različite rezolucije, kontrola vodenih žigova i drugo.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Node.js 18+ ili savremeno okruženje pregledača

## Osnovna upotreba

Glavna tačka poziva Seedream API-ja je:

```
POST https://api.acedata.cloud/seedream/images
```

Ovaj primer koristi model `doubao-seedream-4-0-250828`.
Dostupni modeli uključuju: `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`, `doubao-seedream-3-0-t2i-250415`, `doubao-seededit-3-0-i2i-250628`.

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/seedream/images", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "Bela sijamska mačka sedi na prozorskoj dasci",
  "model": "doubao-seedream-4-0-250828",
  "size": "1K"
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se da proverite statusni kod odgovora i obradite greške:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js omot

Preporučuje se enkapsulacija u funkciju koja se može ponovo koristiti:

```javascript
async function callSeedream(data) {
  const response = await fetch("https://api.acedata.cloud/seedream/images", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Uobičajeni statusni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena frekvencija zahteva |
| 500 | Interna greška servera |
