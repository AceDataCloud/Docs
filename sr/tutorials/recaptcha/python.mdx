## Увод

reCAPTCHA је услуга верификације коју пружа Ace Data Cloud, решење Google reCAPTCHA. Кроз унифицирани API Ace Data Cloud-а, можете брзо интегрисати reCAPTCHA користећи Python и реализовати функције као што су reCAPTCHA v2 Token, reCAPTCHA v2 препознавање, reCAPTCHA v3 Token и друге.

## Претпоставке

- Имате налог на [Ace Data Cloud](https://platform.acedata.cloud) и добијен API Token
- Python верзија 3.7 или новија
- Инсталирана библиотека requests: `pip install requests`

## Основна употреба

Главна тачка позива reCAPTCHA API-ја је:

```
POST https://api.acedata.cloud/captcha/token/recaptcha2
```

Комплетан пример Python кода:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/recaptcha2"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-",
    "website_url": "https://www.google.com/recaptcha/api2/demo"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Молимо замените `YOUR_API_TOKEN` стварним токеном који сте добили на платформи Ace Data Cloud.

## Обрада одговора

Након успешног позива, API враћа податке у JSON формату. Препоручује се провера HTTP статус кода:

```python
if response.status_code == 200:
    result = response.json()
    print("Позив успешан:", result)
else:
    print(f"Позив није успео, статус код: {response.status_code}")
    print(response.text)
```

## Напредна употреба

За API који подржава асинхроне задатке, резултате можете добити преко callback URL-а:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Резултати ће бити послати на ваш сервер преко callback URL-а
```

## Обрада грешака

Чести кодови грешака:

| Статус код | Објашњење |
|------------|-----------|
| 401 | Аутентификација није успела, проверите API Token |
| 403 | Недовољно средстава или нема приступа |
| 429 | Прекорачен лимит захтева |
| 500 | Унутрашња грешка сервера |

## Остале тачке приступа

reCAPTCHA услуга такође пружа следеће крајње тачке:

- `POST https://api.acedata.cloud/captcha/recognition/recaptcha2`
- `POST https://api.acedata.cloud/captcha/token/recaptcha3`
