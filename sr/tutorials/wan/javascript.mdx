## Uvod

Wan je AI video servis koji pruža Ace Data Cloud, model za generisanje video zapisa kompanije Alibaba Wanxiang. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Wan koristeći JavaScript i ostvariti funkcije kao što su generisanje video zapisa iz teksta, iz slika, generisanje referentnih video zapisa i podrška za različite rezolucije.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Node.js 18+ ili moderan pregledač

## Osnovna upotreba

Glavna tačka za pozivanje Wan API-ja je:

```
POST https://api.acedata.cloud/wan/videos
```

U ovom primeru koristi se model `wan2.6-t2v`. Dostupni modeli su: `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`.

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/wan/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "text2video",
  "model": "wan2.6-t2v",
  "prompt": "Astronauts shuttle from space to volcano",
  "resolution": "720P"
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se da proverite statusni kod odgovora i obradite greške:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js enkapsulacija

Preporučuje se enkapsulacija u ponovo upotrebljivu funkciju:

```javascript
async function callWan(data) {
  const response = await fetch("https://api.acedata.cloud/wan/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Česti statusni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401          | Autentifikacija neuspešna, proverite API Token |
| 403          | Nedovoljno sredstava ili nema pristupa |
| 429          | Prekoračena frekvencija zahteva |
| 500          | Interna greška servera |
