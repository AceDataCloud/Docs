---

## Uvod

Wan je AI video servis koji pruža Ace Data Cloud, model za generisanje video zapisa kompanije Alibaba Wanxiang. Kroz jedinstveni API Ace Data Cloud, možete brzo koristiti cURL za pozivanje Wan-a i ostvariti funkcije kao što su generisanje video zapisa iz teksta, slike, referentnog video zapisa, kao i različite rezolucije.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Instalirano cURL okruženje u terminalu

## Osnovna upotreba

Glavna tačka za pozivanje Wan API-ja je:

```
POST https://api.acedata.cloud/wan/videos
```

U ovom primeru koristi se model `wan2.6-t2v`.
Dostupni modeli uključuju: `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`.

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/wan/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "model": "wan2.6-t2v", "prompt": "Astronauts shuttle from space to volcano", "resolution": "720P"}'
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Nakon uspešnog poziva vraćaju se podaci u JSON formatu, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatirani prikaz:

```bash
curl -s -X POST https://api.acedata.cloud/wan/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "model": "wan2.6-t2v", "prompt": "Astronauts shuttle from space to volcano", "resolution": "720P"}' | jq .
```

## Obrada grešaka

Česti kodovi grešaka:

| Status kod | Objašnjenje                      |
|------------|---------------------------------|
| 401        | Autentifikacija nije uspela, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera          |
