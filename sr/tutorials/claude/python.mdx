## Uvod

Claude je AI servis za razgovor koji pruža Ace Data Cloud, zasnovan na velikim jezičkim modelima iz Anthropic Claude serije. Kroz jedinstveni API Ace Data Clouda, možete brzo integrisati Claude koristeći Python, omogućavajući višekratne dijaloge, sistemske promptove, strimovanje izlaza, JSON režim izlaza i druge funkcije.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API token
- Python okruženje verzije 3.7 ili novije
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna krajnja tačka za pozivanje Claude API-ja je:

```
POST https://api.acedata.cloud/v1/chat/completions
```

U ovom primeru koristi se model `claude-sonnet-4-6`.
Dostupni modeli uključuju: `claude-sonnet-4-6`, `claude-opus-4-5-20251101`, `claude-3-5-sonnet`.

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "claude-sonnet-4-6",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za chat API podržano je strimovanje izlaza radi dobijanja odgovora u realnom vremenu:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Objašnjenje                      |
|------------|---------------------------------|
| 401        | Autentifikacija neuspešna, proverite API token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera          |
