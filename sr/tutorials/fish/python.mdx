## Uvod

Fish TTS je AI audio usluga koju pruža Ace Data Cloud, Fish servis za sintezu govora. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Fish TTS koristeći Python i ostvariti funkcije kao što su konverzija teksta u govor, različiti glasovi i prilagođeni zvukovi.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Python 3.7 ili noviji
- Instalirati biblioteku requests: `pip install requests`

## Osnovna upotreba

Glavna krajnja tačka za pozivanje Fish TTS API-ja je:

```
POST https://api.acedata.cloud/fish/audios
```

U ovom primeru koristi se model `fish-tts`.
Dostupni modeli uključuju: `fish-tts`.

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/fish/audios"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "speech",
    "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务",
    "voice_id": "d7900c21663f485ab63ebdb7e5905036",
    "model": "fish-tts"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultat se može dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultat će biti poslat na vaš server putem callback URL-a
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Opis |
|------------|------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračenje ograničenja zahteva |
| 500 | Interna greška servera |
