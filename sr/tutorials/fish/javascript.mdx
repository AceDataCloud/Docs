## Uvod

Fish TTS je AI audio usluga koju pruža Ace Data Cloud, usluga sinteze govora Fish. Kroz jedinstveni API Ace Data Cloud, možete brzo integrisati Fish TTS koristeći JavaScript i ostvariti funkcije kao što su pretvaranje teksta u govor, različiti glasovi, prilagođeni zvuk i druge.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Node.js 18+ ili moderan pregledač

## Osnovna upotreba

Glavna tačka poziva Fish TTS API-ja je:

```
POST https://api.acedata.cloud/fish/audios
```

Ovaj primer koristi model `fish-tts`.
Dostupni modeli uključuju: `fish-tts`.

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/fish/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "speech",
  "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务",
  "voice_id": "d7900c21663f485ab63ebdb7e5905036",
  "model": "fish-tts"
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se provera statusnog koda odgovora i obrada grešaka:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js omot

Preporučuje se enkapsulacija u ponovo upotrebljivu funkciju:

```javascript
async function callFishTTS(data) {
  const response = await fetch("https://api.acedata.cloud/fish/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Uobičajeni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena frekvencija zahteva |
| 500 | Interna greška servera |
