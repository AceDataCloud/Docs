## Uvod

Image2Text je usluga za prepoznavanje verifikacionih kodova sa slika koju pruža Ace Data Cloud. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Image2Text koristeći JavaScript za prepoznavanje verifikacionih kodova sa slika, unos u Base64 formatu, unos putem URL-a i druge funkcije.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Node.js 18+ ili savremeno okruženje pregledača

## Osnovna upotreba

Glavna tačka poziva Image2Text API-ja je:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/captcha/recognition/image2text", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."
}),
});

const result = await response.json();
console.log(result);
```

Molimo zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se provera statusnog koda odgovora i obrada grešaka:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js enkapsulacija

Preporučuje se enkapsulacija u ponovo upotrebljivu funkciju:

```javascript
async function callImage2Text(data) {
  const response = await fetch("https://api.acedata.cloud/captcha/recognition/image2text", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Uobičajeni statusni kodovi grešaka:

| Statusni kod | Opis                          |
|--------------|-------------------------------|
| 401          | Autentifikacija neuspešna, proverite API Token |
| 403          | Nedovoljno sredstava ili nema pristupa |
| 429          | Prekoračena frekvencija zahteva |
| 500          | Interna greška servera        |
