## Uvod

Image2Text je usluga za prepoznavanje verifikacionih kodova (captcha) koju pruža Ace Data Cloud. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Image2Text koristeći Python, omogućavajući prepoznavanje verifikacionih kodova sa slika, unos u Base64 formatu, unos putem URL-a i druge funkcionalnosti.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python verzija 3.7 ili novija
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka poziva Image2Text API-ja je:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/image2text"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim Tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultate možete dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultati će biti poslati na vaš server putem callback URL-a
```

## Obrada grešaka

Uobičajeni status kodovi grešaka:

| Status kod | Opis |
|------------|------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena frekvencija zahteva |
| 500 | Interna greška servera |
