---

## Uvod

Image2Text je usluga za prepoznavanje captcha slika koju pruža Ace Data Cloud. Kroz jedinstveni API Ace Data Cloud-a, možete brzo koristiti cURL za pozivanje Image2Text i ostvariti funkcije prepoznavanja captcha slika, unos Base64 formata, unos URL-a i druge.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Instalirano cURL okruženje u terminalu

## Osnovna upotreba

Glavna krajnja tačka za pozivanje Image2Text API-ja je:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}'
```

Molimo zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Nakon uspešnog poziva vraća se JSON format podataka, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiran ispis:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}' | jq .
```

## Obrada grešaka

Česti kodovi grešaka:

| Status kod | Objašnjenje                     |
|------------|--------------------------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera         |
