## Увод

Identity је услуга аутентификације коју пружа Ace Data Cloud, за верификацију идентитета коришћењем личне карте/банкарске картице/броја мобилног телефона. Кроз унифицирани API Ace Data Cloud-а, можете користити cURL за брз позив Identity услуге, омогућавајући OCR личне карте, верификацију личне карте, банкарске картице и броја мобилног телефона.

## Претпоставке

- Имате налог на [Ace Data Cloud](https://platform.acedata.cloud) и добијен API Token
- Инсталиран cURL у вашем терминалном окружењу

## Основна употреба

Главна тачка позива Identity API-а је:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Комплетан пример cURL наредбе:

```bash
curl -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}'
```

Замените `YOUR_API_TOKEN` стварним токеном који сте добили на платформи Ace Data Cloud.

## Пример одговора

Након успешног позива враћа се JSON формат података, на пример:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Коришћење jq за обраду одговора

Препоручује се коришћење алата jq за форматирани приказ:

```bash
curl -s -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}' | jq .
```

## Обрада грешака

Чести кодови грешака:

| Код статуса | Опис                          |
|-------------|-------------------------------|
| 401         | Аутентификација није успела, проверите API Token |
| 403         | Недовољно средстава или нема приступа |
| 429         | Прекорачен лимит захтева       |
| 500         | Унутрашња грешка сервера       |
