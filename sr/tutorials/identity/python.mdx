## Uvod

Identity je usluga autentifikacije koju pruža Ace Data Cloud, za verifikaciju ličnih dokumenata kao što su lična karta, bankovna kartica i broj telefona. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Identity koristeći Python i ostvariti funkcionalnosti kao što su OCR lične karte, verifikacija lične karte, verifikacija bankovne kartice i verifikacija broja telefona.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python verzija 3.7 ili novija
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka poziva Identity API-ja je:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/identity/idcard/ocr"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "image_url": "https://example.com/idcard-front.jpg"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultat možete dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultat će biti poslat na vaš server putem callback URL-a
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Opis |
|------------|------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena frekvencija zahteva |
| 500 | Interna greška servera |

## Ostale tačke pristupa
