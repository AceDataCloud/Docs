## Увод

Identity је услуга аутентификације коју пружа Ace Data Cloud, за верификацију идентитета путем личне карте/банкарске картице/броја мобилног телефона. Кроз унифицирани API Ace Data Cloud-а, можете брзо интегрисати Identity користећи JavaScript и реализовати функције као што су OCR личне карте, верификација личне карте, банкарске картице и броја мобилног телефона.

## Предуслови

- Имате налог на [Ace Data Cloud](https://platform.acedata.cloud) и добијен API Token
- Node.js 18+ или савремено прегледачко окружење

## Основна употреба

Главна тачка позива Identity API-ја је:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Комплетан пример JavaScript кода:

```javascript
const response = await fetch("https://api.acedata.cloud/identity/idcard/ocr", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "image_url": "https://example.com/idcard-front.jpg"
}),
});

const result = await response.json();
console.log(result);
```

Молимо замените `YOUR_API_TOKEN` стварним токеном који сте добили на платформи Ace Data Cloud.

## Обрада одговора

Препоручује се провера статуса одговора и обрада грешака:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Позив успешан:", result);
} else {
  console.error(`Позив није успео, статусни код: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js омотач

Препоручује се паковање у поновно употребљиву функцију:

```javascript
async function callIdentity(data) {
  const response = await fetch("https://api.acedata.cloud/identity/idcard/ocr", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API грешка: ${response.status}`);
  return response.json();
}
```

## Обрада грешака

Чести кодови грешака:

| Статусни код | Објашњење |
|--------------|-----------|
| 401 | Аутентификација није успела, проверите API Token |
| 403 | Недовољно средстава или нема приступа |
| 429 | Прекорачење ограничења учесталости захтева |
| 500 | Унутрашња грешка сервера |
