## Uvod

hCaptcha je usluga verifikacije koju pruža Ace Data Cloud, rešenje za hCaptcha. Korišćenjem jedinstvenog API-ja Ace Data Cloud, možete brzo pozvati hCaptcha putem cURL-a, ostvarujući funkcije kao što su dobijanje hCaptcha tokena i prepoznavanje hCaptcha slika.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API token
- Terminal okruženje sa instaliranim cURL-om

## Osnovna upotreba

Glavna krajnja tačka za pozivanje hCaptcha API-ja je:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}'
```

Molimo zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na platformi Ace Data Cloud.

## Primer odgovora

Nakon uspešnog poziva vraćaju se podaci u JSON formatu, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiran ispis:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}' | jq .
```

## Obrada grešaka

Česti kodovi grešaka:

| Status kod | Objašnjenje                  |
|------------|-----------------------------|
| 401        | Autentifikacija neuspešna, proverite API token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera       |
