## Uvod

hCaptcha je usluga verifikacije koju pruža Ace Data Cloud, rešenje za hCaptcha. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati hCaptcha koristeći Python, ostvarujući funkcionalnosti kao što su dobijanje hCaptcha tokena i prepoznavanje hCaptcha slika.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API token
- Python okruženje verzije 3.7 ili novije
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka pristupa hCaptcha API-ju je:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/hcaptcha"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2",
    "website_url": "https://accounts.hcaptcha.com/demo"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Molimo zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultat se može dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultat će biti poslat na vaš server putem callback URL-a
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Objašnjenje |
|------------|-------------|
| 401 | Autentifikacija neuspešna, proverite API token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračenje ograničenja zahteva |
| 500 | Interna greška servera |
