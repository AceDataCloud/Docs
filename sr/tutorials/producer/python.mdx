## Uvod

Producer je AI audio servis koji pruža Ace Data Cloud, FUZZ Producer AI generisanje muzike. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Producer koristeći Python i ostvariti funkcije kao što su generisanje muzike iz teksta, prilagođeni tekstovi pesama, nastavak pesama, obrada cover verzija, separacija vokala, generisanje muzičkih spotova i druge.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python okruženje verzije 3.7 ili novije
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka pristupa Producer API-ju je:

```
POST https://api.acedata.cloud/producer/audios
```

U ovom primeru koristi se model `FUZZ-2.0 Pro`.
Dostupni modeli uključuju: `FUZZ-2.0 Pro`, `FUZZ-2.0`, `FUZZ-1.1 Pro`, `FUZZ-1.0 Pro`.

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/producer/audios"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A relaxing jazz piece for a coffee shop",
    "model": "FUZZ-2.0 Pro",
    "lyric": "[Verse]\nSoft piano keys in the morning light",
    "custom": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultate možete dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultati će biti poslati na vaš server putem callback URL-a
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Opis |
|------------|-------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračenje limite zahteva |
| 500 | Interna greška servera |
