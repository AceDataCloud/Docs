## Uvod

Producer je AI audio usluga koju pruža Ace Data Cloud, FUZZ Producer AI generisanje muzike. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Producer koristeći JavaScript i ostvariti funkcije kao što su generisanje muzike iz teksta, prilagođeni tekstovi pesama, nastavak pesama, obrada cover verzija, izdvajanje vokala, generisanje muzičkih spotova i druge.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Node.js 18+ ili moderan pregledač

## Osnovna upotreba

Glavna tačka poziva Producer API-ja je:

```
POST https://api.acedata.cloud/producer/audios
```

Ovaj primer koristi model `FUZZ-2.0 Pro`.
Dostupni modeli uključuju: `FUZZ-2.0 Pro`, `FUZZ-2.0`, `FUZZ-1.1 Pro`, `FUZZ-1.0 Pro`.

Kompletan JavaScript primer koda:

```javascript
const response = await fetch("https://api.acedata.cloud/producer/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A relaxing jazz piece for a coffee shop",
  "model": "FUZZ-2.0 Pro",
  "lyric": "[Verse]\nSoft piano keys in the morning light",
  "custom": true
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se da proverite statusni kod odgovora i obradite greške:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js omot

Preporučuje se enkapsulacija u funkciju za ponovnu upotrebu:

```javascript
async function callProducer(data) {
  const response = await fetch("https://api.acedata.cloud/producer/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Česti statusni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401          | Autentifikacija neuspešna, proverite API Token |
| 403          | Nedovoljno sredstava ili nema pristupa |
| 429          | Prekoračena frekvencija zahteva |
| 500          | Interna greška servera |
