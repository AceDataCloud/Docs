## Uvod

Luma je AI video servis koji pruža Ace Data Cloud, Luma Dream Machine za generisanje video zapisa. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Luma koristeći Python i ostvariti funkcije kao što su generisanje videa iz teksta, generisanje videa iz slika, produžavanje videa, kontrola početnog i završnog frejma, petljanje videa i druge.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python verzija 3.7 ili novija
- Instaliran requests paket: `pip install requests`

## Osnovna Upotreba

Glavna tačka poziva za Luma API je:

```
POST https://api.acedata.cloud/luma/videos
```

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/luma/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "Astronauts shuttle from space to volcano",
    "action": "generate",
    "enhancement": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Molimo zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada Odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se da proverite HTTP status kod:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna Upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultat možete dobiti preko callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultat će biti poslat na vaš server preko callback URL-a
```

## Obrada Grešaka

Česti status kodovi grešaka:

| Status kod | Objašnjenje |
|------------|-------------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena frekvencija zahteva |
| 500 | Interna greška servera |
