## Uvod

Luma je AI video servis koji pruža Ace Data Cloud, Luma Dream Machine za generisanje videa. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Luma koristeći JavaScript i ostvariti funkcije kao što su generisanje videa iz teksta, generisanje videa iz slika, produženje videa, kontrola početnog i završnog frejma, kružni video i druge.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Node.js 18+ ili moderan pregledač

## Osnovna upotreba

Glavna tačka poziva Luma API-ja je:

```
POST https://api.acedata.cloud/luma/videos
```

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/luma/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "Astronauts shuttle from space to volcano",
  "action": "generate",
  "enhancement": true
}),
});

const result = await response.json();
console.log(result);
```

Molimo zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se da proverite statusni kod odgovora i obradite greške:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js omot

Preporučuje se enkapsulacija u funkciju koja se može ponovo koristiti:

```javascript
async function callLuma(data) {
  const response = await fetch("https://api.acedata.cloud/luma/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Uobičajeni statusni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračenje ograničenja zahteva |
| 500 | Interna greška servera |
