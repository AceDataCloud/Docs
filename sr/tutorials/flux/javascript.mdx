## Uvod

Flux je AI servis za slike koji pruža Ace Data Cloud, model za generisanje slika Black Forest Labs Flux. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Flux koristeći JavaScript i ostvariti funkcije kao što su generisanje slika iz teksta, uređivanje slika, različiti modeli, prilagođene dimenzije i drugo.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Node.js 18+ ili moderan pregledač

## Osnovna upotreba

Glavna tačka za pozivanje Flux API-ja je:

```
POST https://api.acedata.cloud/flux/images
```

U ovom primeru koristi se model `flux-pro-1.1`.
Dostupni modeli uključuju: `flux-dev`, `flux-pro`, `flux-pro-1.1`, `flux-pro-1.1-ultra`, `flux-kontext-pro`, `flux-kontext-max`.

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/flux/images", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A white siamese cat sitting on a windowsill",
  "model": "flux-pro-1.1",
  "size": "1024x1024"
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na platformi Ace Data Cloud.

## Obrada odgovora

Preporučuje se da proverite statusni kod odgovora i obradite greške:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js enkapsulacija

Preporučuje se enkapsulacija u funkciju za ponovnu upotrebu:

```javascript
async function callFlux(data) {
  const response = await fetch("https://api.acedata.cloud/flux/images", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Česti statusni kodovi grešaka:

| Statusni kod | Objašnjenje                      |
|--------------|---------------------------------|
| 401          | Neuspešna autentifikacija, proverite API Token |
| 403          | Nedovoljno sredstava ili nema pristupa |
| 429          | Prekoračena frekvencija zahteva |
| 500          | Interna greška servera          |
