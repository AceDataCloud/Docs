## Uvod

Flux je AI servis za slike koji pruža Ace Data Cloud, koristeći Black Forest Labs Flux model za generisanje slika. Kroz jedinstveni API Ace Data Clouda, možete brzo integrisati Flux u Python aplikacije i ostvariti funkcije kao što su generisanje slika iz teksta, uređivanje slika, različiti modeli i prilagođene dimenzije.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python okruženje verzije 3.7 ili novije
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka za pozivanje Flux API-ja je:

```
POST https://api.acedata.cloud/flux/images
```

U ovom primeru koristi se model `flux-pro-1.1`.
Dostupni modeli uključuju: `flux-dev`, `flux-pro`, `flux-pro-1.1`, `flux-pro-1.1-ultra`, `flux-kontext-pro`, `flux-kontext-max`.

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/flux/images"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A white siamese cat sitting on a windowsill",
    "model": "flux-pro-1.1",
    "size": "1024x1024"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultate možete dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultati će biti poslati na vaš server putem callback URL-a
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Opis |
|------------|-------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena frekvencija zahteva |
| 500 | Interna greška servera |
