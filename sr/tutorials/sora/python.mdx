## Uvod

Sora je AI video servis koji pruža Ace Data Cloud, OpenAI Sora model za generisanje video zapisa. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Sora koristeći Python, omogućavajući funkcije kao što su generisanje video zapisa iz teksta, različite dužine, pejzažni i portretni režim, kontrola likova i referentne slike.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Python okruženje verzije 3.7 ili novije
- Instalirati requests biblioteku: `pip install requests`

## Osnovna upotreba

Glavna tačka za pozivanje Sora API-ja je:

```
POST https://api.acedata.cloud/sora/videos
```

U ovom primeru koristi se model `sora-2`.
Dostupni modeli uključuju: `sora-2`, `sora-2-pro`.

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim Tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultat možete dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultat će biti poslat na vaš server preko callback URL-a
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Opis |
|------------|------|
| 401 | Autentifikacija nije uspela, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračenje frekvencije zahteva |
| 500 | Interna greška servera |
