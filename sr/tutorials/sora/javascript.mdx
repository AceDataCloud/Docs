## Uvod

Sora je AI video servis koji pruža Ace Data Cloud, OpenAI Sora model za generisanje video zapisa. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Sora koristeći JavaScript i ostvariti funkcije kao što su generisanje video zapisa iz teksta, različiti trajanja, pejzažni i portretni režim, kontrola likova, referentne slike i druge.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Node.js 18+ ili moderan pregledač

## Osnovna upotreba

Glavna tačka poziva Sora API-ja je:

```
POST https://api.acedata.cloud/sora/videos
```

U ovom primeru koristi se model `sora-2`.
Dostupni modeli uključuju: `sora-2`, `sora-2-pro`.

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/sora/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "A cat running across a sunny meadow",
  "model": "sora-2",
  "duration": 10,
  "orientation": "landscape"
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se da proverite statusni kod odgovora i obradite greške:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js omot

Preporučuje se enkapsulacija u funkciju koja se može ponovo koristiti:

```javascript
async function callSora(data) {
  const response = await fetch("https://api.acedata.cloud/sora/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Obrada grešaka

Česti statusni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena frekvencija zahteva |
| 500 | Interna greška servera |
