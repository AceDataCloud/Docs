## Uvod

Sora je AI video servis koji pruža Ace Data Cloud, OpenAI Sora model za generisanje videa. Kroz jedinstveni API Ace Data Cloud-a, možete brzo koristiti cURL za pozivanje Sora servisa i ostvariti funkcije kao što su generisanje videa iz teksta, različite dužine, pejzažna i portretna orijentacija, kontrola likova, referentne slike i drugo.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Instalirano cURL okruženje u terminalu

## Osnovna upotreba

Glavna tačka za pozivanje Sora API-ja je:

```
POST https://api.acedata.cloud/sora/videos
```

U ovom primeru koristi se model `sora-2`.
Dostupni modeli su: `sora-2`, `sora-2-pro`.

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}'
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Nakon uspešnog poziva vraća se JSON format podataka, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiran ispis:

```bash
curl -s -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}' | jq .
```

## Obrada grešaka

Česti kodovi grešaka:

| Status kod | Objašnjenje                  |
|------------|-----------------------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa          |
| 429        | Prekoračena frekvencija zahteva                 |
| 500        | Interna greška servera                           |
