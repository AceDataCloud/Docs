## Uvod

Grok je AI chat servis koji pruža Ace Data Cloud, deo xAI Grok serije velikih jezičkih modela. Kroz jedinstveni API Ace Data Cloud-a, možete brzo koristiti Grok putem cURL-a za višekratne razgovore, sistemske promptove, strimovanje izlaza, JSON režim izlaza, vizuelno razumevanje i druge funkcije.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Terminal okruženje sa instaliranim cURL-om

## Osnovna upotreba

Glavna krajnja tačka za pozivanje Grok API-ja je:

```
POST https://api.acedata.cloud/grok/chat/completions
```

U ovom primeru koristi se model `grok-3`.
Dostupni modeli uključuju: `grok-4`, `grok-4-1-fast`, `grok-3`, `grok-3-mini`, `grok-2-vision`.

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/grok/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "grok-3", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Nakon uspešnog poziva vraća se JSON formatiran odgovor, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiran izlaz:

```bash
curl -s -X POST https://api.acedata.cloud/grok/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "grok-3", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Obrada grešaka

Česti kodovi grešaka:

| Status kod | Objašnjenje                      |
|------------|---------------------------------|
| 401        | Autentifikacija nije uspela, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera          |
