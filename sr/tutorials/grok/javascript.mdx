## Увод

Grok је AI сервис за ћаскање који пружа Ace Data Cloud, део xAI Grok серије великих језичких модела. Кроз унификовани API Ace Data Cloud-а, можете брзо интегрисати Grok користећи JavaScript, омогућавајући мулти-тур дијалоге, системске упуте, стриминг излаз, JSON излазни режим, визуелно разумевање и друге функције.

## Претпоставке

- Имате налог на [Ace Data Cloud](https://platform.acedata.cloud) и добијен API Token
- Node.js 18+ или модерно окружење прегледача

## Основна употреба

Главна тачка позива Grok API-ја је:

```
POST https://api.acedata.cloud/grok/chat/completions
```

У овом примеру користи се модел `grok-3`.
Доступни модели укључују: `grok-4`, `grok-4-1-fast`, `grok-3`, `grok-3-mini`, `grok-2-vision`.

Комплетан пример JavaScript кода:

```javascript
const response = await fetch("https://api.acedata.cloud/grok/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "grok-3",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Замените `YOUR_API_TOKEN` стварним токеном који сте добили на Ace Data Cloud платформи.

## Обрада одговора

Препоручује се провера статуса одговора и руковање грешкама:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Позив успешан:", result);
} else {
  console.error(`Позив није успео, статусни код: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js омотач

Препоручује се паковање у поновно употребљиву функцију:

```javascript
async function callGrok(data) {
  const response = await fetch("https://api.acedata.cloud/grok/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API грешка: ${response.status}`);
  return response.json();
}
```

## Руководење грешкама

Чести кодови грешака:

| Статусни код | Опис |
|--------------|------|
| 401          | Аутентификација није успела, проверите API Token |
| 403          | Недовољно средстава или нема приступа |
| 429          | Прекорачење ограничења учесталости захтева |
| 500          | Унутрашња грешка сервера |
