## Uvod

Seedance je AI video servis koji pruža Ace Data Cloud, model za generisanje video zapisa kompanije ByteDance Seedance. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Seedance koristeći JavaScript i ostvariti funkcije kao što su generisanje video zapisa iz teksta, generisanje video zapisa iz slika, generisanje zvuka i podrška za različite rezolucije.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Node.js 18+ ili moderan pregledač

## Osnovna upotreba

Glavna tačka poziva Seedance API-ja je:

```
POST https://api.acedata.cloud/seedance/videos
```

U ovom primeru koristi se model `doubao-seedance-1-0-pro-250528`.
Dostupni modeli uključuju: `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`.

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/seedance/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "doubao-seedance-1-0-pro-250528",
  "content": [
    {
      "type": "text",
      "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"
    }
  ]
}),
});

const result = await response.json();
console.log(result);
```

Molimo zamenite `YOUR_API_TOKEN` stvarnim Tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se provera statusnog koda odgovora i rukovanje greškama:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js enkapsulacija

Preporučuje se enkapsulacija u funkciju za višekratnu upotrebu:

```javascript
async function callSeedance(data) {
  const response = await fetch("https://api.acedata.cloud/seedance/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Rukovanje greškama

Česti statusni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401          | Autentifikacija neuspešna, proverite API Token |
| 403          | Nedovoljno sredstava ili nema pristupa |
| 429          | Prekoračena frekvencija zahteva |
| 500          | Interna greška servera |
