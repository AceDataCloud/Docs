## Uvod

Seedance je AI video servis koji pruža Ace Data Cloud, koristeći ByteDance Seedance model za generisanje videa. Kroz jedinstveni API Ace Data Cloud-a, možete brzo pozivati Seedance koristeći cURL za generisanje video sadržaja iz teksta, slika, audio generisanje, kao i podršku za različite rezolucije.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Terminal sa instaliranim cURL-om

## Osnovna upotreba

Glavna krajnja tačka za pozivanje Seedance API-ja je:

```
POST https://api.acedata.cloud/seedance/videos
```

U ovom primeru koristi se model `doubao-seedance-1-0-pro-250528`.
Dostupni modeli uključuju: `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`.

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/seedance/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "doubao-seedance-1-0-pro-250528", "content": [{"type": "text", "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"}]}'
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Nakon uspešnog poziva vraća se JSON formatiran odgovor, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiran ispis:

```bash
curl -s -X POST https://api.acedata.cloud/seedance/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "doubao-seedance-1-0-pro-250528", "content": [{"type": "text", "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"}]}' | jq .
```

## Obrada grešaka

Česti kodovi grešaka:

| Status kod | Objašnjenje |
|------------|-------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera |
