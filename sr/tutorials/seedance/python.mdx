## Uvod

Seedance je AI video servis koji pruža Ace Data Cloud, zasnovan na Seedance video generativnom modelu kompanije ByteDance. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Seedance koristeći Python i ostvariti funkcionalnosti kao što su generisanje videa iz teksta, generisanje videa iz slika, generisanje zvuka i podrška za različite rezolucije.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Python okruženje verzije 3.7 ili novije
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka za pozivanje Seedance API-ja je:

```
POST https://api.acedata.cloud/seedance/videos
```

U ovom primeru koristi se model `doubao-seedance-1-0-pro-250528`.
Dostupni modeli uključuju: `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`.

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "doubao-seedance-1-0-pro-250528",
    "content": [
        {
            "type": "text",
            "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"
        }
    ]
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Molimo zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultate možete dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultati će biti poslati na vaš server putem callback URL-a
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Opis |
|------------|-------|
| 401 | Autentifikacija neuspešna, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena frekvencija zahteva |
| 500 | Interna greška servera |
