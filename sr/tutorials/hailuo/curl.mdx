## Uvod

Hailuo je AI video servis koji pruža Ace Data Cloud, MiniMax model za generisanje video zapisa. Kroz jedinstveni API Ace Data Cloud-a, možete brzo koristiti cURL za pozivanje Hailuo servisa i ostvariti funkcije kao što su generisanje video zapisa iz teksta, generisanje video zapisa iz slika, režiserski mod i druge.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Instalirano cURL okruženje u terminalu

## Osnovna upotreba

Glavna tačka za pozivanje Hailuo API-ja je:

```
POST https://api.acedata.cloud/hailuo/videos
```

U ovom primeru koristi se model `minimax-t2v`. Dostupni modeli uključuju: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}'
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Nakon uspešnog poziva vraća se JSON formatiran odgovor, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiran izlaz:

```bash
curl -s -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}' | jq .
```

## Obrada grešaka

Česti kodovi grešaka:

| Status kod | Objašnjenje                     |
|------------|--------------------------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračen broj zahteva         |
| 500        | Interna greška servera          |
