## Uvod

QR Art je AI usluga za slike koju pruža Ace Data Cloud, generisanje AI umetničkih QR kodova. Kroz jedinstveni API Ace Data Cloud-a, možete brzo pozvati QR Art koristeći cURL i ostvariti funkcije kao što su QR kodovi za linkove, tekst, unapred podešeni stilovi i prilagođeni parametri.

## Preduslovi

- Imati [Ace Data Cloud](https://platform.acedata.cloud) nalog i dobiti API Token
- Instalirano cURL okruženje u terminalu

## Osnovna upotreba

Glavna krajnja tačka za pozivanje QR Art API-ja je:

```
POST https://api.acedata.cloud/qrart/generate
```

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}'
```

Molimo zamenite `YOUR_API_TOKEN` stvarnim Tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Nakon uspešnog poziva vraća se JSON format podataka, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatirani ispis:

```bash
curl -s -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}' | jq .
```

## Obrada grešaka

Česti kodovi grešaka:

| Status kod | Objašnjenje                     |
|------------|--------------------------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera          |
