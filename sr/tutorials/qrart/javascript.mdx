## Uvod

QR Art je AI usluga za generisanje umetničkih QR kodova koju pruža Ace Data Cloud. Korišćenjem jedinstvenog API-ja Ace Data Cloud, možete brzo integrisati QR Art u JavaScript, omogućavajući generisanje QR kodova za linkove, tekst, unapred podešene stilove i prilagođene parametre.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Node.js 18+ ili moderan pregledač

## Osnovna upotreba

Glavna tačka poziva za QR Art API je:

```
POST https://api.acedata.cloud/qrart/generate
```

Kompletan primer JavaScript koda:

```javascript
const response = await fetch("https://api.acedata.cloud/qrart/generate", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "type": "link",
  "content": "https://platform.acedata.cloud",
  "prompt": "sunset ocean waves",
  "preset": "neon-mech"
}),
});

const result = await response.json();
console.log(result);
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Preporučuje se provera statusnog koda odgovora i rukovanje greškama:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Poziv uspešan:", result);
} else {
  console.error(`Poziv neuspešan, statusni kod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js enkapsulacija

Preporučuje se enkapsulacija u funkciju za višekratnu upotrebu:

```javascript
async function callQRArt(data) {
  const response = await fetch("https://api.acedata.cloud/qrart/generate", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API greška: ${response.status}`);
  return response.json();
}
```

## Rukovanje greškama

Česti statusni kodovi grešaka:

| Statusni kod | Objašnjenje |
|--------------|-------------|
| 401          | Autentifikacija neuspešna, proverite API Token |
| 403          | Nedovoljno sredstava ili nema pristupa |
| 429          | Prekoračena frekvencija zahteva |
| 500          | Interna greška servera |
