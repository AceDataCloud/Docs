## Uvod

QR Art je AI usluga za slike koju pruža Ace Data Cloud, generisanje AI umetničkih QR kodova. Kroz jedinstveni API Ace Data Cloud, možete brzo integrisati QR Art koristeći Python, ostvarujući funkcije kao što su QR kodovi za linkove, tekst, unapred podešeni stilovi i prilagođeni parametri.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python okruženje verzije 3.7 ili novije
- Instalirati biblioteku requests: `pip install requests`

## Osnovna upotreba

Glavna krajnja tačka za pozivanje QR Art API-ja je:

```
POST https://api.acedata.cloud/qrart/generate
```

Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/qrart/generate"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "type": "link",
    "content": "https://platform.acedata.cloud",
    "prompt": "sunset ocean waves",
    "preset": "neon-mech"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Molimo zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se da proverite HTTP statusni kod:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, statusni kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultat možete dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultat će biti poslat na vaš server putem callback URL-a
```

## Obrada grešaka

Česti statusni kodovi:

| Statusni kod | Objašnjenje                     |
|--------------|--------------------------------|
| 401          | Autentifikacija neuspešna, proverite API Token |
| 403          | Nedovoljno sredstava ili nema pristupa |
| 429          | Prekoračena frekvencija zahteva |
| 500          | Interna greška servera         |
