## Uvod

Face Change je AI usluga za obradu slika i lica koju pruža Ace Data Cloud. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati Face Change koristeći Python i ostvariti funkcije kao što su zamena lica, ulepšavanje lica, promene starosti, promene pola, animacija u stilu crtanih filmova i analiza lica.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python okruženje verzije 3.7 ili novije
- Instalirana requests biblioteka: `pip install requests`

## Osnovna upotreba

Glavna krajnja tačka za pozivanje Face Change API-ja je:

```
POST https://api.acedata.cloud/face/swap
```



Kompletan primer Python koda:

```python
import requests

url = "https://api.acedata.cloud/face/swap"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "source_image_url": "https://example.com/source-face.jpg",
    "target_image_url": "https://example.com/target-face.jpg"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na platformi Ace Data Cloud.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv neuspešan, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je koji podržavaju asinhrone zadatke, rezultat možete dobiti putem callback URL-a:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Rezultat će biti poslat na vaš server putem callback URL-a
```

## Obrada grešaka

Česti status kodovi grešaka:

| Status kod | Objašnjenje |
|------------|-------------|
| 401 | Autentifikacija nije uspela, proverite API Token |
| 403 | Nedovoljno sredstava ili nema pristupa |
| 429 | Prekoračena frekvencija zahteva |
| 500 | Interna greška servera |
