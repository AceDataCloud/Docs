## Увод

Face Change је AI услуга за обраду слика и лица коју пружа Ace Data Cloud. Кроз унифицирани API Ace Data Cloud-а, можете брзо интегрисати Face Change користећи JavaScript и реализовати функције као што су замена лица, уљепшавање лица, промена старости, промена пола, анимација лица и анализа лица.

## Предуслови

- Имате налог на [Ace Data Cloud](https://platform.acedata.cloud) и добијен API Token
- Node.js 18+ или савремено прегледачко окружење

## Основна употреба

Главна тачка позива Face Change API-ја је:

```
POST https://api.acedata.cloud/face/swap
```

Комплетан пример JavaScript кода:

```javascript
const response = await fetch("https://api.acedata.cloud/face/swap", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "source_image_url": "https://example.com/source-face.jpg",
  "target_image_url": "https://example.com/target-face.jpg"
}),
});

const result = await response.json();
console.log(result);
```

Молимо замените `YOUR_API_TOKEN` стварним токеном који сте добили на платформи Ace Data Cloud.

## Обрада одговора

Препоручује се провера статуса одговора и руковање грешкама:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Позив успешан:", result);
} else {
  console.error(`Позив није успео, статусни код: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js омотач

Препоручује се омотавање у поновно употребљиву функцију:

```javascript
async function callFaceChange(data) {
  const response = await fetch("https://api.acedata.cloud/face/swap", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API грешка: ${response.status}`);
  return response.json();
}
```

## Руководење грешкама

Чести кодови грешака:

| Статусни код | Опис |
|--------------|-------|
| 401 | Аутентификација није успела, проверите API Token |
| 403 | Недовољно средстава или нема приступа |
| 429 | Прекорачен лимит захтева |
| 500 | Унутрашња грешка сервера |
