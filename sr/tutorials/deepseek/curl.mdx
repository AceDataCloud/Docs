## Uvod

DeepSeek je AI servis za razgovor koji pruža Ace Data Cloud, deo DeepSeek serije velikih jezičkih modela. Kroz jedinstveni API Ace Data Cloud-a, možete brzo koristiti DeepSeek putem cURL-a za višekratne dijaloge, sistemske promptove, strimovani izlaz, JSON izlazni režim, duboku dedukciju i druge funkcije.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Terminal okruženje sa instaliranim cURL-om

## Osnovna upotreba

Glavna krajnja tačka za pozivanje DeepSeek API-ja je:

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

Ovaj primer koristi model `deepseek-r1`.
Dostupni modeli uključuju: `deepseek-r1`, `deepseek-r1-0528`, `deepseek-v3`, `deepseek-v3-250324`.

Kompletan primer cURL komande:

```bash
curl -X POST https://api.acedata.cloud/deepseek/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-r1", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Zamenite `YOUR_API_TOKEN` stvarnim Tokenom koji ste dobili na Ace Data Cloud platformi.

## Primer odgovora

Nakon uspešnog poziva vraćaju se podaci u JSON formatu, na primer:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Korišćenje jq za obradu odgovora

Preporučuje se korišćenje alata jq za formatiran izlaz:

```bash
curl -s -X POST https://api.acedata.cloud/deepseek/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-r1", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Rukovanje greškama

Česti kodovi grešaka:

| Status kod | Objašnjenje                  |
|------------|------------------------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračenje ograničenja zahteva |
| 500        | Interna greška servera       |
