## Uvod

DeepSeek je AI servis za ćaskanje koji pruža Ace Data Cloud, deo DeepSeek serije velikih jezičkih modela. Kroz jedinstveni API Ace Data Cloud-a, možete brzo integrisati DeepSeek koristeći Python i ostvariti funkcionalnosti kao što su višekratni dijalozi, sistemske prompt poruke, strimovani izlaz, JSON izlazni režim i duboko zaključivanje.

## Preduslovi

- Imati nalog na [Ace Data Cloud](https://platform.acedata.cloud) i dobiti API Token
- Python okruženje verzije 3.7 ili novije
- Instaliran requests paket: `pip install requests`

## Osnovna upotreba

Glavna tačka za pozivanje DeepSeek API-ja je:

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

U ovom primeru koristi se model `deepseek-r1`.
Dostupni modeli uključuju: `deepseek-r1`, `deepseek-r1-0528`, `deepseek-v3`, `deepseek-v3-250324`.

Kompletan Python primer koda:

```python
import requests

url = "https://api.acedata.cloud/deepseek/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "deepseek-r1",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Zamenite `YOUR_API_TOKEN` stvarnim tokenom koji ste dobili na Ace Data Cloud platformi.

## Obrada odgovora

Nakon uspešnog poziva, API vraća podatke u JSON formatu. Preporučuje se provera HTTP status koda:

```python
if response.status_code == 200:
    result = response.json()
    print("Poziv uspešan:", result)
else:
    print(f"Poziv nije uspeo, status kod: {response.status_code}")
    print(response.text)
```

## Napredna upotreba

Za API-je za ćaskanje podržan je strimovani izlaz za dobijanje odgovora u realnom vremenu:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Obrada grešaka

Uobičajeni status kodovi grešaka:

| Status kod | Objašnjenje                      |
|------------|---------------------------------|
| 401        | Autentifikacija neuspešna, proverite API Token |
| 403        | Nedovoljno sredstava ili nema pristupa |
| 429        | Prekoračena frekvencija zahteva |
| 500        | Interna greška servera          |
