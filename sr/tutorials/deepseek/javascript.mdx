## Увод

DeepSeek је AI сервис за ћаскање који пружа Ace Data Cloud, део DeepSeek серије великих језичких модела. Кроз унифицирани API Ace Data Cloud-а, можете брзо интегрисати DeepSeek користећи JavaScript и реализовати функције као што су вишецртна комуникација, системске поруке, стриминг излаз, JSON излазни режим и дубока логичка анализа.

## Претпоставке

- Имате налог на [Ace Data Cloud](https://platform.acedata.cloud) и API Token
- Node.js 18+ или савремено прегледачко окружење

## Основна употреба

Главна тачка позива DeepSeek API-ја је:

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

У овом примеру користи се модел `deepseek-r1`.
Доступни модели укључују: `deepseek-r1`, `deepseek-r1-0528`, `deepseek-v3`, `deepseek-v3-250324`.

Комплетан пример JavaScript кода:

```javascript
const response = await fetch("https://api.acedata.cloud/deepseek/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "deepseek-r1",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Замените `YOUR_API_TOKEN` са стварним токеном који сте добили на платформи Ace Data Cloud.

## Обрада одговора

Препоручује се провера статуса одговора и руковање грешкама:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Позив успешан:", result);
} else {
  console.error(`Позив није успео, статусни код: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js омотач

Препоручује се паковање у поновно употребљиву функцију:

```javascript
async function callDeepSeek(data) {
  const response = await fetch("https://api.acedata.cloud/deepseek/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API грешка: ${response.status}`);
  return response.json();
}
```

## Руководство грешкама

Чести кодови грешака:

| Статусни код | Објашњење |
|--------------|-----------|
| 401          | Аутентификација није успела, проверите API Token |
| 403          | Недовољно средстава или нема приступа |
| 429          | Прекорачење ограничења учесталости захтева |
| 500          | Унутрашња грешка сервера |
