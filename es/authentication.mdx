---
title: "Autenticación"
description: "Cómo autenticar usando la API de Ace Data Cloud"
---

Todas las API de Ace Data Cloud utilizan autenticación con **Bearer Token**.

## Obtener Token

1. Regístrese en [platform.acedata.cloud](https://platform.acedata.cloud)
2. Suscríbase al servicio requerido
3. Cree credenciales (API Token) para cada servicio

## Usar Token

Incluya el Token en el encabezado `Authorization` de cada solicitud:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Tip">
  Cada Token está vinculado a una suscripción de servicio específica. Use diferentes Tokens para distintos servicios o cree credenciales **globales** para usar entre servicios.
</Note>

## Límite de tasa

El límite de tasa varía según el servicio y el nivel de suscripción. Si se excede, la API devuelve `429 Too Many Requests`.

## Mejores prácticas de seguridad

- No exponga el API Token en el código del cliente
- Use variables de entorno para almacenar el Token
- Rote los Tokens periódicamente
- Use Tokens diferentes para entornos de desarrollo y producción
