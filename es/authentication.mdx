Todas las API de Ace Data Cloud utilizan autenticación con **Bearer Token**.

## Obtener Token

Inicie sesión en [Applications](https://platform.acedata.cloud/console/applications?lang=es&utm_source=docs&utm_medium=referral&utm_campaign=evergreen) y abra **General Application**. Si aún no aparece, seleccione **Initialize General Application**. Pulse el botón de copia marcado con el número **1** junto a **API KEY**.

![Botón para copiar la clave de la aplicación, marcado con el número 1](https://raw.githubusercontent.com/AceDataCloud/NanoBananaDify/2522b2f57210597af2db866445319334a1677a23/_assets/tutorial/get-api-key-en.png)

Guarde la clave en el servidor y úsela en lugar de `YOUR_API_TOKEN` en el ejemplo.

## Usar Token

Incluya el Token en el encabezado `Authorization` de cada solicitud:

```bash
Authorization: Bearer YOUR_API_TOKEN
```


## Límite de tasa

El límite de tasa varía según el servicio y el nivel de suscripción. Si se excede, la API devuelve `429 Too Many Requests`.

## Mejores prácticas de seguridad

- No exponga el API Token en el código del cliente
- Use variables de entorno para almacenar el Token
- Rote los Tokens periódicamente
- Use Tokens diferentes para entornos de desarrollo y producción
