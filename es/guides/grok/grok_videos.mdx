Este documento presenta las instrucciones para integrar la API de Generación de Videos Grok, la cual puede generar videos Grok Imagine (xAI) mediante la entrada de texto, imágenes y, opcionalmente, imágenes de referencia.

## Proceso de solicitud

Para usar la API, primero debes solicitar el servicio en la página correspondiente de [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos). Una vez en la página, haz clic en el botón «Acquire», como se muestra en la imagen:

![](https://cdn.acedata.cloud/q6ytrc.png)

Si no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión para registrarte e iniciar sesión. Tras hacerlo, volverás automáticamente a la misma página.

En la primera solicitud, se te otorgará una cuota gratuita para usar la API sin costo.

## Descripción del modelo

La API soporta dos modelos:

- `grok-imagine-video-1.5-fast` (por defecto): soporta generación de videos a partir de texto (`prompt`) y de imágenes (`image_url`), con precio más bajo.
- `grok-imagine-video-1.5`: solo soporta generación de videos a partir de imágenes (`image_url`), **obligatorio** incluir este campo.

## Uso básico

Primero, revisa la forma básica de uso: ingresando los parámetros `prompt`, `model`, etc., para generar el video correspondiente.

Aquí configuramos los encabezados de la solicitud, incluyendo:

- `accept`: formato de respuesta deseado, en este caso `application/json` (JSON).
- `authorization`: clave de API, que puedes seleccionar directamente tras solicitarla.

También configuramos el cuerpo de la solicitud (`Request Body`), que incluye:

- `prompt`: texto descriptivo del contenido del video a generar. Es **obligatorio** cuando se usa `grok-imagine-video-1.5-fast`; opcional si se proporciona `image_url`.
- `model`: modelo para generar el video, puede ser `grok-imagine-video-1.5-fast` (por defecto) o `grok-imagine-video-1.5`.
- `image_url`: enlace a la imagen de entrada para generación basada en imagen. **Obligatorio** si `model` es `grok-imagine-video-1.5`.
- `reference_image_urls`: array opcional de enlaces a imágenes de referencia, para guiar el estilo o contenido del video.
- `aspect_ratio`: relación de aspecto del video, opcional, puede ser `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`.
- `resolution`: resolución de salida, opcional, puede ser `480p` (por defecto) o `720p`. Cuanto mayor, mayor consumo de cuota.
- `duration`: duración del video en segundos, rango 1–15, valor por defecto 8. Se cobra por segundos de salida.
- `callback_url`: URL para callback asíncrono. Si se establece, la API devolverá inmediatamente `task_id`, y al completar el proceso enviará el resultado mediante POST a esa URL.

Haz clic en «Try» para probar, y el resultado será algo como:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video-1.5-fast:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
      "state": "succeeded"
    }
  ]
}
```

Los campos principales de la respuesta son:

- `success`: indica si la solicitud fue exitosa.
- `task_id`: ID de la tarea de generación.
- `trace_id`: ID de seguimiento para diagnóstico.
- `data`: lista de resultados de videos generados.
  - `id`: identificador único del video.
  - `video_url`: enlace al video generado.
  - `state`: estado de la tarea (`pending`, `succeeded`, `failed`).

Solo necesitas usar `video_url` para obtener el video generado.

Código CURL de ejemplo:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "resolution": "480p",
  "duration": 8
}'
```

Código Python de ejemplo:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video-1.5-fast",
    "resolution": "480p",
    "duration": 8
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Generación basada en imagen

Para crear videos a partir de una imagen, debes incluir `image_url`. Cuando uses `grok-imagine-video-1.5`, este campo **obligatorio**:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5",
  "image_url": "https://cdn.acedata.cloud/5hmkdg.jpg",
  "resolution": "720p",
  "duration": 8
}
```

## Uso de imágenes de referencia

Para guiar el estilo o contenido con una o varias imágenes de referencia, incluye en `reference_image_urls` un array de enlaces:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video-1.5-fast",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/vunnjf.png"
  ]
}
```

## Callback asíncrono

La generación de videos puede tardar. Si no quieres mantener la conexión abierta, puedes usar `callback_url`. La API devolverá inmediatamente `task_id`, y al terminar enviará el resultado a esa URL mediante POST:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "duration": 8,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

Respuesta inmediata:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Consultar estado de la tarea

Para verificar el estado o resultados, si usaste callback o quieres consultarlo manualmente, usa [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) con `task_id`.

## Tarifas

El servicio se cobra según los «segundos de salida» del video generado. El precio depende del `model` y la `resolution`. La tarifa total = tarifa por segundo × `duration` (por defecto 8 segundos). `720p` es más caro que `480p`, y `grok-imagine-video-1.5` más que `grok-imagine-video-1.5-fast`. Los precios específicos están en la página de tarifas.

## Manejo de errores

En caso de errores, la API devuelve códigos y mensajes correspondientes. Los más comunes:

- `400`: parámetros incorrectos, por ejemplo, falta `prompt` en generación de texto, o falta `image_url` en `grok-imagine-video-1.5`, o `duration` fuera del rango 1–15.
- `401`: fallo de autenticación, token inválido o no coincidente.
- `403`: saldo insuficiente o contenido rechazado por revisión.
- `429`: solicitudes demasiado frecuentes, limitación por parte del sistema, intenta más tarde.
- `500`: error interno del servidor o fallo en la generación upstream.
