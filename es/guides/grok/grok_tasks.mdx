La función principal de la API de Tareas Grok es consultar el estado de ejecución de una tarea mediante el ID de tarea generado por la API de Generación de Videos Grok.

Este documento describe detalladamente las instrucciones para integrar la API de Tareas Grok, ayudándole a integrar fácilmente y consultar el estado de ejecución de las tareas de la API de Generación de Videos Grok.

## Proceso de Solicitud

Para usar la API de Tareas Grok, primero debe solicitar el servicio correspondiente en la página de solicitud [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos) y copiar el ID de tarea devuelto por la API de Generación de Videos Grok.

Luego, acceda a la página [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) para solicitar el servicio correspondiente. Una vez en la página, haga clic en el botón «Acquire».

Si aún no ha iniciado sesión o registrado, será redirigido automáticamente a la [página de inicio de sesión](https://platform.acedata.cloud) para que se registre e inicie sesión. Después de iniciar sesión o registrarse, volverá automáticamente a la página actual.

Al solicitar por primera vez, se otorgará un crédito gratuito que permite usar esta API sin costo.

## Ejemplo de Solicitud

La API de Tareas Grok se puede usar para consultar los resultados de la API de Generación de Videos Grok.

### Configuración de Encabezados y Cuerpo de la Solicitud

**Encabezados de la Solicitud** incluyen:

- `accept`: especifica que se acepta la respuesta en formato JSON, aquí se establece como `application/json`.
- `authorization`: la clave para llamar a la API, que puede seleccionarse directamente tras la solicitud.

**Cuerpo de la Solicitud** incluye:

- `id`: el ID de tarea que se desea consultar.
- `action`: la acción a realizar sobre la tarea, para consulta individual se usa `retrieve`.

### Ejemplo de Código CURL

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Ejemplo de Respuesta

Tras una solicitud exitosa, la API devolverá los detalles de la tarea. El campo `request` contiene el cuerpo de la solicitud original, y el campo `response` contiene el cuerpo de la respuesta tras la finalización de la tarea, por ejemplo:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/grok/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Descripción de los campos:

- `id`: ID de la tarea generada, usado para identificar de forma única esta tarea.
- `request`: información de la solicitud de la tarea consultada.
- `response`: información de la respuesta de la tarea consultada.

## Consulta Masiva

Para consultar detalles de múltiples tareas, establezca `action` como `retrieve_batch` y pase un arreglo de IDs de tareas mediante `ids`:

**Cuerpo de la Solicitud** incluye:

- `ids`: arreglo de IDs de tareas a consultar.
- `action`: la acción a realizar, para consulta masiva se usa `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
