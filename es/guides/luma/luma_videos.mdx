Con la creciente aplicación de la IA, diversos programas de IA se han popularizado gradualmente. La IA se ha ido introduciendo poco a poco en todos los aspectos del trabajo y la vida de las personas. Y las industrias involucradas por la IA también son cada vez más numerosas, desde la escritura inicial, hasta la medicina y la educación, y ahora los videos.

Luma es una plataforma profesional de generación de videos de alta calidad; los usuarios solo necesitan cargar materiales para generar automáticamente videos de alta calidad según diferentes estilos y efectos. Este generador de videos con IA fue desarrollado por miembros de equipos de conocidas empresas tecnológicas, con el objetivo de permitir que todos puedan crear videos excelentes fácilmente sin necesidad de herramientas de edición complejas.

Sin embargo, Luma oficialmente no proporciona una API; AceDataCloud ofrece un conjunto de API de Luma, que simula la integración con la API oficial de Suno, y permite generar de forma conveniente y rápida los videos deseados.

## Solicitud y uso

Para utilizar Luma Videos Generation API, primero obtenga su API Token en la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) y guárdelo como respaldo.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no ha iniciado sesión o no se ha registrado, será redirigido automáticamente a la página de inicio de sesión para invitarle a registrarse e iniciar sesión; al finalizar, regresará automáticamente a la página actual.

**Un API Token permite invocar todos los servicios de la plataforma, sin necesidad de solicitar uno por separado para cada servicio.** La primera solicitud incluirá créditos gratuitos, que permiten una experiencia gratuita; cuando los créditos sean insuficientes, puede recargar saldo general en la [consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [Luma Videos Generation API →](https://platform.acedata.cloud/documents/luma-videos)

## Uso básico

Para generar cualquier video, puede introducir libremente un texto; por ejemplo, si quiero generar un video sobre astronautas viajando entre el espacio y un volcán, puedo introducir `Astronauts shuttle from space to volcano`, como se muestra en la imagen:

El código generado es el siguiente:

<p><img src="https://cdn.acedata.cloud/ieq7yn.png" width="500" className="m-auto" /></p>

Principales parámetros de solicitud:

- `prompt`: Texto de indicación para generar el video.
- `aspect_ratio`: Relación de aspecto del video; el valor predeterminado es 16:9.
- `end_image_url`: Opcional; especifica el fotograma final.
- `enhancement`: Opcional; interruptor de mejora de nitidez.
- `loop`: Indica si se genera un video en bucle; el valor predeterminado es false.
- `timeout`: Opcional; número de segundos de espera.
- `callback_url`: Dirección de devolución de llamada asíncrona.
- `async`: Opcional; cuando se establece en `true`, la interfaz devuelve inmediatamente `task_id`, sin necesidad de proporcionar `callback_url`; posteriormente, se obtiene el resultado mediante sondeo a través de la interfaz de consulta de tareas correspondiente.

La descripción de los campos es la siguiente:

- success: Indica si la generación fue exitosa; si tiene éxito, es `true`; de lo contrario, es `false`
- task_id: El ID único de la tarea de generación de video aquí
- video_id: El ID único del video generado por la tarea de generación de video aquí
- prompt: Las palabras clave de la tarea de generación de video aquí
- video_url: El enlace del video resultante de la tarea de generación de video aquí
- video_height: La altura de la imagen de portada del video generado
- video_width: El ancho de la imagen de portada del video generado
- state: El estado de la tarea de generación de video aquí; si la tarea se completa, es `completed`.
- thumbnail_url: El enlace de la imagen de portada del video generado
- thumbnail_width: El ancho de la imagen de portada del video generado
- thumbnail_height: La altura de la imagen de portada del video generado

## Generación personalizada con fotogramas inicial y final

Si desea generar un video mediante la personalización de los fotogramas inicial y final del video, puede introducir los enlaces de las imágenes de los fotogramas inicial y final:

En este momento, el campo `start_image_url` del fotograma inicial del video puede recibir la siguiente imagen como fotograma inicial del video:

![Fotograma inicial](https://cdn.acedata.cloud/r9vsv9.png)

A continuación, para generar un video personalizado según los fotogramas inicial y final, y las palabras clave, se puede especificar el siguiente contenido:

- action: El comportamiento de la tarea de generación de video; normalmente es generación normal `generate` y generación extendida `extend`; el valor predeterminado es `generate`.
- start_image_url: Especifica el fotograma inicial del video generado.
- end_image_url: Especifica el fotograma final del video generado.
- prompt: Contenido de las palabras clave para generar el video.

El ejemplo de llenado es el siguiente:

<p><img src="https://cdn.acedata.cloud/zvzydx.png" width="500" className="m-auto" /></p>

Después de completar, se genera automáticamente el siguiente código:

<p><img src="https://cdn.acedata.cloud/tx80pu.png" width="500" className="m-auto" /></p>

El código correspondiente:

```python
import requests

url = "https://api.acedata.cloud/luma/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "start_image_url": "https://cdn.acedata.cloud/r9vsv9.png",
    "action": "generate",
    "prompt": "Astronauts shuttle from space to volcano"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Función de extensión de video

Si desea continuar generando el video generado, puede establecer el parámetro `action` como `extend` e introducir el ID o el enlace del video que necesita continuar generándose. La obtención del ID y del enlace del video se realiza según el uso básico, como se muestra en la siguiente imagen:

En este momento puede ver que el ID del video es:

```

"video_url": "https://platform.cdn.acedata.cloud/luma/12a18694-fd4b-47e7-9c50-34f30862cff6.mp4"
```

> Nota: aquí, `video_id` y `video_url` del video son el ID y el enlace del video generado. Si no sabe cómo generar un video, puede consultar el uso básico anterior para generar un video.

Para continuar generando el video, debe cargar el enlace o el ID del video. A continuación se demuestra el uso del ID del video para realizar la extensión. Después, debemos completar palabras clave para personalizar la generación del video, y se puede especificar el siguiente contenido:

- action: el comportamiento de extender el video en este momento; aquí debe ser `extend`.
- prompt: las palabras clave del video que se necesita extender.
- video_url: el enlace del video que se necesita extender y generar.
- video_id: el ID único del video que se necesita extender y generar.
- end_image_url: enlace de la imagen del fotograma final que se puede especificar al extender la generación del video; parámetro opcional.

import requests

    "accept": "application/json",

## Devolución de llamada asíncrona

Debido a que el tiempo que Luma tarda en generar videos es relativamente largo, aproximadamente 1-2 minutos, si la API no responde durante mucho tiempo, la solicitud HTTP mantendrá la conexión continuamente, lo que provoca un consumo adicional de recursos del sistema, por lo que esta API también proporciona soporte para devoluciones de llamada asíncronas.
El flujo general es: cuando el cliente inicia una solicitud, especifica adicionalmente un campo `callback_url`; después de que el cliente inicia la solicitud de API, la API devolverá inmediatamente un resultado, que incluye la información del campo `task_id`, que representa el ID de la tarea actual. Cuando la tarea se completa, el resultado de la música generada se enviará al `callback_url` especificado por el cliente en forma de POST JSON, que también incluye el campo `task_id`, de modo que el resultado de la tarea se puede asociar mediante el ID.

A continuación, veamos mediante un ejemplo cómo operar específicamente.
