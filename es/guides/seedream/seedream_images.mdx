Este documento presenta una guía para la integración de la API SeeDream Images Generation, que permite generar imágenes oficiales de SeeDream mediante la entrada de parámetros personalizados.

## Proceso de solicitud

Para usar la API, primero debe solicitar el servicio correspondiente en la página [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images). Al ingresar, haga clic en el botón "Acquire", como se muestra en la imagen:

![](https://cdn.acedata.cloud/q6ytrc.png)

Si aún no ha iniciado sesión o registrado, será redirigido automáticamente a la página de inicio de sesión para registrarse o ingresar. Después de iniciar sesión o registrarse, volverá automáticamente a esta página.

Al solicitar por primera vez, se otorgará un crédito gratuito para usar la API sin costo.

## Uso básico

Primero, conozcamos la forma básica de uso: ingresando el término de búsqueda `prompt`, la acción de generación `action` y el tamaño de la imagen `size`, se obtiene el resultado procesado. Inicialmente, debe enviar un campo `action` con el valor `generate`, y también ingresar el término de búsqueda. El contenido específico es el siguiente:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Aquí configuramos los encabezados de la solicitud (Request Headers), que incluyen:

- `accept`: formato deseado para la respuesta, aquí se establece en `application/json`, es decir, formato JSON.
- `authorization`: clave para llamar a la API, que puede seleccionarse directamente tras la solicitud.

Además, configuramos el cuerpo de la solicitud (Request Body), que incluye:

- `prompt`: término de búsqueda.
- `model`: modelo de generación, por defecto `doubao-seedream-5.0-lite`. Soporta `doubao-seedream-5.0-lite` (el más reciente), `doubao-seedream-4.5`, `doubao-seedream-4.0`, `doubao-seedream-3.0-t2i`, `doubao-seededit-3.0-i2i`.
- `image`: información de la imagen de entrada, soporta URL o codificación Base64. Los modelos `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0` soportan entrada de una o varias imágenes; `doubao-seededit-3.0-i2i` solo soporta una imagen; `doubao-seedream-3.0-t2i` no soporta este parámetro.
- `size`: especifica el tamaño de la imagen generada, soporta dos formas, que no pueden combinarse:
  - Forma 1 | especificar la resolución de la imagen generada (como `2K`, `3K`, `4K`) y describir la relación de aspecto en lenguaje natural en el prompt.
  - Forma 2 | especificar el ancho y alto en píxeles: valor por defecto `2048x2048`, con rangos variables según el modelo.
- `seed`: semilla aleatoria para controlar la aleatoriedad del contenido generado. Rango [-1, 2147483647]. Solo soportado por `doubao-seedream-3.0-t2i` y `doubao-seededit-3.0-i2i`.
- `sequential_image_generation`: generación de conjunto de imágenes relacionadas basadas en el contenido ingresado. Soportado por `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0`, por defecto `disabled`.
- `stream`: controla si se activa el modo de salida en streaming. Soportado por `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0`, por defecto `false`.
- `guidance_scale`: grado de coherencia entre el resultado del modelo y el prompt, cuanto mayor el valor, mayor la correlación. Rango [1, 10]. Valor por defecto 2.5 para `doubao-seedream-3.0-t2i`, 5.5 para `doubao-seededit-3.0-i2i`, no soportado por otros modelos.
- `response_format`: formato de retorno de la imagen generada. Por defecto `url`, también soporta `b64_json`.
- `watermark`: si se añade marca de agua en la imagen generada. Por defecto `true`.
- `output_format`: formato de archivo de la imagen generada, soporta `jpeg` (por defecto) y `png`. Solo soportado por `doubao-seedream-5.0-lite`.
- `tools`: configuración de herramientas que el modelo puede usar, actualmente soporta `web_search` (búsqueda en línea). Solo soportado por `doubao-seedream-5.0-lite`.
- `callback_url`: URL para recibir la devolución de resultados.

Al seleccionar, también se genera el código correspondiente a la derecha, como se muestra en la imagen:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

Haga clic en el botón "Try" para probar. Como se muestra, obtuvimos el siguiente resultado:

```json
{
  "success": true,
  "task_id": "25027ba3-0430-4a1b-91c8-d2297f19ba73",
  "trace_id": "8043a9e9-692f-43b0-82f7-5890f798be38",
  "data": [
    {
      "prompt": "a white siamese cat",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/3c060029-69b1-406f-a957-fcd55ddc9386.jpg"
    }
  ]
}
```

El resultado contiene varios campos, que se describen a continuación:

- `success`: estado de la tarea de generación de imagen.
- `task_id`: ID de la tarea de generación.
- `trace_id`: ID de seguimiento de la tarea.
- `data`: lista de resultados de la tarea de generación de imágenes.
  - `image_url`: enlace a la imagen generada.
  - `prompt`: término de búsqueda.
  - `size`: tamaño en píxeles de la imagen generada.

Como puede ver, obtuvimos la información de la imagen deseada y solo necesitamos obtener la imagen SeeDream generada a partir del enlace en `data`.

Si desea generar el código de integración correspondiente, puede copiarlo directamente, por ejemplo, el código CURL es:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-4-0-250828",
  "prompt": "a white siamese cat"
}'
```

## Tarea de edición de imágenes

Si desea editar una imagen, primero debe pasar el parámetro `image` con el enlace de la imagen a editar.

- model: modelo utilizado para la tarea de edición, `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0` soportan entrada de una o varias imágenes; `doubao-seededit-3.0-i2i` solo soporta una imagen.
- image: imagen(es) a editar, una o varias.

Ejemplo de llenado:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Código correspondiente:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Al ejecutar, verá que se obtiene un resultado inmediatamente, como sigue:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Como puede ver, el efecto generado es la edición de la imagen original, con resultados similares a los anteriores.

## Callback asíncrono

Dado que la generación con SeeDream Images Generation API puede tardar entre 1 y 2 minutos, si la API no responde durante mucho tiempo, la conexión HTTP se mantiene abierta, consumiendo recursos del sistema. Por ello, esta API también soporta callbacks asíncronos.

El flujo general es: el cliente envía la solicitud especificando un campo `callback_url`. La API responde inmediatamente con un resultado que contiene un campo `task_id`, que representa el ID de la tarea actual. Cuando la tarea se completa, el resultado de la imagen generada se envía en formato JSON mediante POST al `callback_url` especificado por el cliente, incluyendo también el campo `task_id`, para que los resultados puedan asociarse mediante este ID.

Veamos un ejemplo para entender cómo funciona.

Al ejecutar, se obtiene inmediatamente un resultado como este:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

Contenido:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Como puede ver, el resultado contiene un campo `task_id`, y los demás campos son similares a los anteriores. Este campo permite asociar los resultados con la tarea correspondiente.

## Manejo de errores

Al llamar a la API, si ocurre un error, la API devolverá un código y mensaje de error correspondiente. Por ejemplo:

- `400 token_mismatched`: Solicitud incorrecta, posiblemente por parámetros faltantes o inválidos.
- `400 api_not_implemented`: Solicitud incorrecta, posiblemente por parámetros faltantes o inválidos.
- `401 invalid_token`: No autorizado, token de autorización inválido o faltante.
- `429 too_many_requests`: Demasiadas solicitudes, ha excedido el límite de tasa.
- `500 api_error`: Error interno del servidor, algo salió mal en el servidor.

### Ejemplo de respuesta de error

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
