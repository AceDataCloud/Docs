Ace Data Cloud proporciona un acceso a la implementación privada de Hermes Agent. Este acceso es un servicio controlado, y la disponibilidad y los recursos opcionales se rigen por lo que actualmente muestra la consola.

## Pasos a seguir

1. Encuentra **Implementación Privada de Hermes Agent** en la plataforma.
2. Selecciona la configuración disponible y crea el servicio según las indicaciones de la página.
3. Espera a que la plataforma muestre el estado de listo.
4. Accede a la instancia utilizando el acceso y las credenciales proporcionadas en la página.
5. Envía primero `Reply only OK`, y luego comienza la tarea real.

El modelo, las credenciales, el almacenamiento y el comportamiento de eliminación se rigen por la página de creación y el cuadro de confirmación; no utilices directamente el YAML del tutorial local de Hermes como contrato de implementación en la plataforma. Exporta primero los datos que necesites conservar antes de eliminar.

Si la consola no muestra el acceso a la creación, significa que la cuenta actual aún no tiene habilitado este servicio, puedes optar por usar [Asistente Interactivo de Hermes](https://platform.acedata.cloud/documents/hermes-wizard-integration) o [Configuración Manual](https://platform.acedata.cloud/documents/hermes-manual-integration).
