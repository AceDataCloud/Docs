---
title: "Rotar credenciales de API de la plataforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Genera un nuevo Token o contraseña para una Credential existente. El ID de la credencial, la asociación de Application, los límites y otros campos permanecen sin cambios, y el secreto antiguo deja de ser válido inmediatamente.

> La rotación interrumpirá a los clientes que aún utilizan el secreto antiguo. Primero prepara una distribución segura y un plan de reversión, y luego ejecuta la operación de escritura.

## Resumen de la interfaz

| Elemento    | Contenido                                                                   |
| ---------- | --------------------------------------------------------------------------- |
| Método     | `POST`                                                                      |
| URL        | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}/rotate/` |
| Autenticación | Account Token                                                            |
| Body       | Ninguno o `{}`                                                              |

Obtén `credential_id` de la [lista de credenciales](https://platform.acedata.cloud/documents/platform-credential-list):

```shell
export PLATFORM_TOKEN='tu token de cuenta'
export CREDENTIAL_ID='el ID de Credential que se va a rotar'

curl -X POST \
  "https://platform.acedata.cloud/api/v1/credentials/${CREDENTIAL_ID}/rotate/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Si tiene éxito, devuelve la Credential actualizada. Cuando `type=Token`, lee el nuevo `token`; cuando `type=Identity`, lee la nueva `password`. Trata la respuesta completa como un secreto y actualiza inmediatamente a los llamadores.

## Manejo de errores

- `401`: Account Token no válido.
- `403`: No tiene permiso para administrar esta credencial.
- `404`: El ID de Credential no existe.
