---
title: "Eliminar una credencial de API de la plataforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Elimina permanentemente una credencial de API. Después de eliminarla, **no se puede recuperar inmediatamente**, y todas las interfaces de negocio que estén usando este Token recibirán `401` de inmediato.

> ℹ️ Esta interfaz pertenece a la **API de administración de la plataforma AceDataCloud**, con el prefijo unificado `https://platform.acedata.cloud/api/v1/`.

## Resumen de la interfaz

| Elemento   | Contenido                                                                  |
| --- | ------------------------------------------------------------------- |
| Método  | `DELETE`                                                            |
| URL | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}` |
| Autenticación  | ✅ Se requiere token de cuenta                                                            |

Actualmente, tanto `/credentials/{id}` como `/credentials/{id}/` están disponibles; los ejemplos usan de forma unificada el formato sin barra final.

## Instrucciones de autenticación (cómo obtener el token de cuenta)

Encabezado de solicitud:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

Consulta el método de obtención en [Administrar el token de cuenta de la plataforma AceDataCloud](https://platform.acedata.cloud/documents/platform-token).

## Parámetros de ruta

| Parámetro              | Tipo   | Obligatorio  | Descripción        |
| --------------- | ---- | --- | --------- |
| `credential_id` | UUID | ✅   | ID de la credencial que se va a eliminar |

## Ejemplos de solicitud

### cURL

```shell
curl -X DELETE 'https://platform.acedata.cloud/api/v1/credentials/df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

cred_id = "df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6"
resp = requests.delete(
    f"https://platform.acedata.cloud/api/v1/credentials/{cred_id}",
    headers={"authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"},
    timeout=10,
)
assert resp.status_code == 204, resp.text
print("✅ 已删除")
```

### Node.js

```javascript
const credId = 'df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6'
const r = await fetch(`https://platform.acedata.cloud/api/v1/credentials/${credId}`, {
  method: 'DELETE',
  headers: { authorization: `Bearer ${process.env.PLATFORM_TOKEN}` },
})
console.log('status:', r.status) // 204
```

## Respuesta

- **Éxito**: `HTTP 204 No Content`, **sin cuerpo de respuesta**.
- **Error**: devuelve un JSON de error; consulta la tabla siguiente.

## Manejo de errores

| HTTP | code                | Significado         |
| ---- | ------------------- | ---------- |
| 401  | `not_authenticated` | Falta el token de cuenta     |
| 403  | `permission_denied` | Esta credencial no te pertenece    |
| 404  | `not_found`         | La credencial no existe o ya fue eliminada |

## Consejos prácticos

- **La eliminación es irreversible**: la plataforma no conserva copias del Token. Si solo sospechas una filtración y aún deseas conservar los datos de monitoreo, debes usar [Rotar una credencial de API de la plataforma AceDataCloud](https://platform.acedata.cloud/documents/platform-credential-rotate) en lugar de eliminarla.
- **La eliminación no reembolsará la cuota ya consumida por esta credencial**. El saldo de la Application se deduce en tiempo real según el consumo, y eliminar la credencial no afecta al saldo registrado.
- Después de eliminarla, puedes volver a confirmar las credenciales restantes mediante la [lista de credenciales de API](https://platform.acedata.cloud/documents/platform-credential-list) según `application_id`.
- **Verifica primero los llamadores antes de una limpieza masiva**: la lista actualmente no tiene un campo de última hora de uso; debes combinar la configuración de implementación y los registros de llamadas para confirmar que la credencial ya no está en uso antes de eliminarlas una por una.
