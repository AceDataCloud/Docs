---
title: "Obtener los detalles del documento de la plataforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Obtenga el contenido completo y la relación de navegación de un solo documento mediante el UUID o alias del documento. Cuando se conoce el alias, se puede solicitar directamente, sin necesidad de filtrar primero desde la lista.

## Descripción general de la interfaz

| Elemento   | Contenido                                                              |
| --- | --------------------------------------------------------------- |
| Método  | `GET`                                                           |
| URL | `https://platform.acedata.cloud/api/v1/documents/{id_or_alias}` |
| Autenticación  | Pública; se puede leer directamente conociendo el UUID o alias                                       |

## Parámetros

- `id_or_alias`: UUID del documento, alias actual, o alias antiguo conservado en `redirect_from`.
- `lang`: indicación de idioma opcional; también se puede usar `Accept-Language`. El idioma final del contenido se rige por el `content_locale` de la respuesta.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/documents/platform-token' \
  --data-urlencode 'lang=zh-CN' \
  -H 'Accept: application/json'
```

## Descripción de la respuesta

Los detalles usan una respuesta de un solo objeto, que actualmente incluye:

- `id`, `alias`, `redirect_from`, `name`, `title`, `type`, `rank`, `tags`;
- `content`, `content_mode`, `content_locale`, `content_hash`;
- `parent`, `sibling` y resúmenes públicos de `children` ordenados por rank;
- asociaciones `api` / `proxy` / `dataset` / `integration`, así como `agent` (cuando existe).

La respuesta no tiene un campo `breadcrumbs`. Al construir las migas de pan, se pueden seguir leyendo los detalles de su `parent`, o utilizar las relaciones de directorio de documentos ya almacenadas en caché.

## Manejo de errores

- El ID/alias no existe o no cumple con la visibilidad actual del sitio: `404`. `private` solo controla la visibilidad en la lista, no impide que quienes conocen el enlace lo lean directamente, y no puede utilizarse como límite de confidencialidad.
- La ruta actual usa una forma sin barra final; no dependa de que la capa de proxy agregue automáticamente una barra final.
