[ChatBox](https://chatboxai.app/) es un cliente de IA de código abierto compatible con Windows, macOS, Linux, iOS, Android y Web. Es compatible con proveedores personalizados del tipo «OpenAI API», por lo que puede conectarse directamente a Ace Data Cloud. Este artículo presenta el proceso de configuración.

## Proceso de solicitud

Para conectar Ace Data Cloud en ChatBox, primero ve a la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications), obtén tu API Token y guárdalo como respaldo.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no has iniciado sesión o no te has registrado, se te redirigirá automáticamente a la página de inicio de sesión para invitarte a registrarte e iniciar sesión; después de iniciar sesión o registrarte, volverás automáticamente a la página actual.

En la primera solicitud se otorgará una cuota gratuita, con la que podrás experimentar gratuitamente los servicios de modelos de Ace Data Cloud.

## Descargar ChatBox

Ve al [sitio web oficial de ChatBox](https://chatboxai.app/) para descargar según la plataforma, o usa directamente la [versión Web](https://web.chatboxai.app/) que no requiere instalación:

- Escritorio: Windows `.exe`, macOS `.dmg` (distingue entre Intel / Apple Silicon), Linux AppImage
- Móvil: App Store, Google Play, enlace directo de Android en el sitio web oficial

## Configurar Ace Data Cloud

Inicia ChatBox, entra en **Configuración → Modelos → Añadir Provider personalizado**, establece **API Mode** como **OpenAI API Compatible** y luego completa:

| Campo       | Valor                           | Descripción                                      |
| -------- | --------------------------- | --------------------------------------- |
| Clave API   | Tu Ace Data Cloud Token     | El Token copiado desde la consola                            |
| API Host | `https://api.acedata.cloud` | Introduce solo el nombre de dominio raíz, **no incluyas `/openai` ni `/v1`**         |
| API Path | `/v1/chat/completions`      | El valor predeterminado de ChatBox es `/chat/completions`; debes cambiarlo manualmente a este |

![Interfaz de configuración de ChatBox Ace Data Cloud Provider](https://cdn.acedata.cloud/3789c8e3dd4d.png)

La ruta de solicitud de ChatBox es `{API Host} + {API Path}`, por lo que solo necesitas introducir el nombre de dominio raíz en Host:

| API Host                              | Solicitud final                                                      | Resultado                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | Correcto                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (no hay `/v1` bajo `/openai`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

ChatBox no llamará automáticamente a `/v1/models`; debes introducir manualmente los ID de modelo (uno por línea) en el cuadro «Modelo personalizado» situado en la parte inferior de la página de configuración de modelos. Después de guardar, podrás seleccionarlos en el desplegable de modelos de la interfaz de conversación. Los interruptores de capacidades, la ventana de contexto y el límite de salida deben completarse según el contrato actual del modelo seleccionado; no copies los valores de otros modelos.

## Elegir un modelo

El catálogo de modelos se actualizará continuamente. Da prioridad a la lista de modelos cargada automáticamente por el cliente; si necesitas completarlos manualmente, primero solicita `GET https://api.acedata.cloud/v1/models` para obtener los ID de modelo actuales y luego elige según las capacidades de contexto, imágenes y llamadas a herramientas compatibles con el cliente.

## Verificar la integración

Si no estás seguro de si el problema está en ChatBox o en la red, primero puedes usar curl para verificar directamente el endpoint (sustituye `{token}` por tu Token):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Que se devuelva un objeto `chat.completion` compatible con OpenAI indica que tanto el Token como el endpoint están listos; si se devuelve `HTTP 403 used_up`, significa que el Token es válido, pero el saldo es insuficiente. Solo tienes que recargar saldo en la [consola](https://platform.acedata.cloud/console/applications).

## Preguntas frecuentes

### Aparece 404 Not Found

Normalmente se debe a que se añadió `/openai` o `/v1` de más en API Host. En Host introduce solo `https://api.acedata.cloud` y deja la ruta en el valor predeterminado `/v1/chat/completions`.

### Aparece 401 / token_mismatched

Confirma que has pegado el Token de Ace Data Cloud en «Clave API» (sin el prefijo `Bearer` ni espacios adicionales) y que el saldo de la aplicación correspondiente es suficiente.

### No se ven modelos en el desplegable de modelos

ChatBox no obtiene automáticamente la lista de modelos; debes introducir manualmente los ID de modelo en el cuadro «Modelo personalizado» y guardarlos.

### Quiero generar imágenes en ChatBox

La generación de imágenes de Ace Data Cloud es una Images API independiente (`/openai/images/generations`), con una ruta diferente a la interfaz de conversación, por lo que la entrada de imágenes de ChatBox no puede conectarse directamente. Si necesitas generar imágenes, consulta la [documentación de la API de generación de imágenes](https://platform.acedata.cloud/documents/openai-images-generations) para realizar llamadas con curl / SDK.
