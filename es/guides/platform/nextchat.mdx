[NextChat](https://github.com/ChatGPTNextWeb/NextChat) (anteriormente ChatGPT-Next-Web) es un cliente de IA de código abierto que puede desplegarse en Vercel, Cloudflare o Docker. Admite puntos de conexión compatibles con OpenAI personalizados, por lo que puede integrarse con Ace Data Cloud. Este artículo presenta el proceso de configuración.

## Proceso de solicitud

Para integrar Ace Data Cloud en NextChat, primero ve a la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications), obtén tu API Token y guárdalo como respaldo.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no has iniciado sesión o te has registrado, serás redirigido automáticamente a la página de inicio de sesión para invitarte a registrarte e iniciar sesión; después de iniciar sesión o registrarte, volverás automáticamente a la página actual.

Al realizar la primera solicitud, se otorgará una cuota gratuita, con la que puedes probar gratuitamente los servicios de modelos de Ace Data Cloud.

## Descargar NextChat

Puedes usar la versión de escritorio (descarga `.exe` / `.dmg` / AppImage desde la [página de Releases](https://github.com/ChatGPTNextWeb/NextChat/releases)), la [versión web en línea](https://app.nextchat.club/), o desplegarlo tú mismo en Vercel / Cloudflare / Docker (consulta la sección avanzada más abajo).

## Configurar Ace Data Cloud

Inicia NextChat y ve a **Configuración → Servicio de modelos**:

| Campo          | Valor                           | Descripción                              |
| ----------- | --------------------------- | ------------------------------- |
| Proveedor de servicio de modelos       | `OpenAI`                    | Usar el protocolo compatible con OpenAI                  |
| Dirección de la API de OpenAI | `https://api.acedata.cloud` | Solo completa el dominio raíz, **sin `/openai`, sin `/v1`** |
| API Key     | Tu Token de Ace Data Cloud     | Token copiado desde la consola                    |

![Interfaz de configuración de Ace Data Cloud en NextChat](https://cdn.acedata.cloud/47e0aed34570.png)

NextChat añadirá automáticamente `/v1/chat/completions` después de la dirección de la API, por lo que solo debes completar el dominio raíz:

| Dirección de la API                                  | Solicitud real                                                      | Resultado                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | Correcto                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (no hay `/v1` bajo `/openai`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

En el cuadro «Nombre de modelo personalizado», completa los modelos separados por comas en inglés. NextChat admite sintaxis especial: `+nombre_del_modelo` para añadir, `-nombre_del_modelo` para ocultar, `nombre_del_modelo=nombre_mostrado` para personalizar el nombre mostrado, y `-all` para ocultar primero todos. La sintaxis más limpia recomendada es:

```text
-all,+MODEL_ID=Nombre mostrado
```

## Seleccionar modelos

El catálogo de modelos se actualizará continuamente. Prioriza la lista de modelos cargada automáticamente por el cliente; cuando necesites completarla manualmente, primero solicita `GET https://api.acedata.cloud/v1/models` para obtener el ID de modelo actual y luego selecciona según las capacidades de contexto, imágenes y llamadas a herramientas admitidas por el cliente.

## Verificar la integración

Si no estás seguro de si el problema está en NextChat o en la red, primero puedes usar curl para verificar directamente el punto de conexión (reemplaza `{token}` por tu Token):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

La devolución de un objeto `chat.completion` compatible con OpenAI indica que tanto el Token como el punto de conexión están listos; si devuelve `HTTP 403 used_up`, significa que el Token es válido, pero el saldo es insuficiente. Solo tienes que recargar saldo en la [consola](https://platform.acedata.cloud/console/applications).

## Avanzado: despliegue con un clic en tu propio dominio

NextChat admite desplegar un sitio web de IA propio. Tomando Docker como ejemplo (reemplaza `{token}` por tu Token):

```bash
docker run -d \
  --name nextchat \
  -p 3000:3000 \
  -e OPENAI_API_KEY={token} \
  -e BASE_URL=https://api.acedata.cloud \
  -e CODE=your-password \
  -e CUSTOM_MODELS="-all,+MODEL_ID=Nombre mostrado" \
  yidadaa/chatgpt-next-web
```

Al desplegar en Vercel / Cloudflare, solo configura las mismas variables de entorno `OPENAI_API_KEY`, `BASE_URL`, `CODE`, `CUSTOM_MODELS` en el proyecto. `CODE` admite varias contraseñas de acceso separadas por comas en inglés, lo que facilita contabilizar el uso por persona. Para la descripción completa de las variables de entorno anteriores (el valor predeterminado de `BASE_URL` es `https://api.openai.com`, y la sintaxis `+/-/=/-all/+all` de `CUSTOM_MODELS`), consulta el [README oficial de NextChat](https://github.com/ChatGPTNextWeb/NextChat#environment-variables).

## Preguntas frecuentes

### Aparece 404 Not Found

Normalmente se debe a que la dirección de la API se escribió como `.../openai` o `.../openai/v1`. Cámbiala a `https://api.acedata.cloud` y deja que NextChat añada por sí mismo `/v1/chat/completions`.

### El modelo añadido no aparece en el menú desplegable de modelos

Comprueba el formato de `CUSTOM_MODELS`; debe haber un `+` delante de cada modelo. Si usaste `-all`, asegúrate de volver a añadir los modelos necesarios con `+` después.

### Aparece 401 Unauthorized

Confirma que en API Key has pegado el Token de Ace Data Cloud (sin el prefijo `Bearer` y sin espacios adicionales), y que el saldo de la aplicación correspondiente es suficiente.
