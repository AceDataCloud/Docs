Coze admite oficialmente la integración de modelos personalizados y proporciona tres protocolos: OpenAI Chat API, OpenAI Responses API y Anthropic Messages API. Las tres rutas tienen diferentes Base URL, composición de rutas, Header, streaming y contratos de llamadas a herramientas, por lo que deben configurarse y verificarse por separado.

| Ruta                      | Estado  | Guía                                                                                  |
| ----------------------- | --- | ----------------------------------------------------------------------------------- |
| OpenAI Chat Completions | Experimental | [Configuración de Chat](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | Experimental | [Configuración de Responses](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | Experimental | [Configuración de Messages](https://platform.acedata.cloud/documents/coze-messages-integration)   |

“Experimental” indica que las capacidades oficiales y las entradas de configuración han sido confirmadas, pero diferentes regiones, versiones o planes de Coze pueden mostrar formularios distintos; Ace Data Cloud aún debe completar la verificación de versión fija según el protocolo. No extrapoles el éxito de un protocolo a los otros dos.

## Principios de configuración

- Para la Base API URL, prioriza completar la base proporcionada en la documentación; no añadas repetidamente la ruta del endpoint que el cliente completa automáticamente.
- Para la API Key, utiliza tu Ace Data Cloud API Token.
- Para Model, utiliza el ID de modelo exacto compatible con el protocolo seleccionado en el catálogo de modelos.
- Después de que el texto normal tenga éxito, también se deben verificar el streaming y las llamadas a herramientas.
