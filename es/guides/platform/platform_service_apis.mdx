---
title: "Obtener la lista de API bajo un servicio de la plataforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Devuelve paginadamente las API actualmente habilitadas y no obsoletas de este servicio mediante Service UUID. Si solo se tiene alias, primero llama a [detalles del servicio](https://platform.acedata.cloud/documents/platform-service-detail) para obtener `id`.

## Resumen de la interfaz

| Elemento   | Contenido                                                                  |
| --- | ------------------------------------------------------------------- |
| Método  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| Autenticación  | Pública, no requiere token de cuenta                                                           |
| Paginación  | `count` + `items`                                                   |

## Parámetros

| Parámetro           | Ubicación    | Obligatorio  | Descripción                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | Sí   | Service UUID, no admite alias           |
| `limit`      | query | No   | Número de elementos por página, máximo 100                      |
| `offset`     | query | No   | Desplazamiento de paginación                            |
| `ordering`   | query | No   | Expresión de ordenación de Django; se recomienda `rank` o `-rank` |

La interfaz actual no admite el filtrado por `stage`; ya ha excluido las API `Deprecated`.

```shell
export SERVICE_ID='你的 Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

Los elementos de la lista utilizan la misma estructura de índice que la [lista de API de la plataforma](https://platform.acedata.cloud/documents/platform-api-list), y actualmente incluyen `definition`. Cuando se necesite una entrada estable para una API individual, continúa llamando a `/api/v1/apis/{api_id}`.

## Manejo de errores

- El servicio no existe o no es visible en el sitio actual: `404`.
- `service_id` debe ser un UUID; el alias no se resolverá en esta action.
