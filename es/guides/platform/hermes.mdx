Hermes Agent se integra con Ace Data Cloud a través del protocolo OpenAI Chat Completions. Elija una de las siguientes formas de configuración:

| Forma de configuración         | Guía                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| Asistente de interacción `hermes model` | [Configuración del asistente](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| Configuración manual `config.yaml`  | [Configuración manual](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| Despliegue privado en la plataforma              | [Despliegue gestionado](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

Parámetros comunes para la integración local:

- URL base: `https://api.acedata.cloud/v1`
- Transporte: `chat_completions`
- Proveedor: `custom:acedatacloud`
- Clave API: obtener de [lista de aplicaciones](https://platform.acedata.cloud/console/applications)

Ambas formas locales se escriben finalmente en `~/.hermes/config.yaml`, no configure de nuevo.

Regresar al [Centro de Configuración de Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
