LMLocal es una extensión para Visual Studio 2022/2026, que soporta oficialmente API compatibles con OpenAI y URL base personalizadas. La entrada de configuración puede cambiar con las versiones de la extensión; para la primera integración, asegúrate de usar una versión fija y verifica la edición real, las llamadas a herramientas y el registro de uso.

## Configuración

1. Instala LMLocal desde Visual Studio Marketplace o el repositorio oficial.
2. En Providers, añade un Proveedor Custom/OpenAI-compatible.
3. En Base URL, escribe `https://api.acedata.cloud/v1`.
4. En Auth Key, introduce tu Token de API de Ace Data Cloud.
5. En Model, escribe el ID del modelo exacto que soporte Chat Completions en el directorio de modelos.
6. Después de guardar, envía `Reply only OK`, y prueba nuevamente el flujo de edición del proyecto.

## Límites actuales

- Esta guía cubre solo LMLocal y no representa la configuración compartida de otras extensiones de Visual Studio.
- Diferentes versiones pueden manejar por separado las solicitudes de chat, edición, construcción y prueba; cada modo debe ser validado de forma independiente.
- Si el cliente añade automáticamente `/v1` o el path del endpoint, evita rutas duplicadas.
