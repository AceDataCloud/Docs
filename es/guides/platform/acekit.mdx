Probablemente también te hayas encontrado con esta situación: estás usando Claude Code, Cursor o Codex, programando con fluidez, y de repente necesitas una imagen ilustrativa, un fragmento de música de fondo, un video corto, o quieres que consulte información reciente de paso. El resultado es que el agent en sí no sabe hacer estas cosas. Tienes que buscar APIs por tu cuenta, leer documentación, configurar keys, escribir código de llamadas, gestionar sondeos asíncronos; después de toda esa complicación, la inspiración ya se ha enfriado.

[AceKit](https://github.com/AceDataCloud/AceKit) viene precisamente a ahorrarte toda esta serie de complicaciones. Con una sola línea de comando, instala en tu agent de programación todas las capacidades de AceData Cloud, como generación de imágenes, generación de videos, generación de música, búsqueda web y conversaciones LLM. Después de instalarlo, simplemente hablas en lenguaje natural, y el agent cargará por sí mismo la habilidad correspondiente, se autenticará por sí mismo, realizará los sondeos por sí mismo y terminará el trabajo.

## Entiende en 30 segundos qué hace

Antes de instalar vs. después de instalar:

| Lo que dices               | Antes de instalar                   | Después de instalar (el agent lo hace por sí mismo)                      |
| ------------------ | --------------------- | ----------------------------------- |
| "Pon una imagen de portada para este README" | el agent no sabe hacerlo, te pide que busques una API de generación de imágenes | llama a NanoBanana / Flux / Midjourney para generar la imagen |
| "Convierte este script en un video corto de 30 segundos"  | no sabe hacerlo                    | llama a Sora / Veo / Kling / Seedance para generar el video  |
| "Pon una música de fondo para este demo"  | no sabe hacerlo                    | llama a Suno para generar la música                           |
| "Busca la información más reciente sobre X y luego resúmela"     | no puede conectarse a Internet                  | llama a Google SERP para obtener resultados en tiempo real                 |
| "Acorta este enlace largo"         | no sabe hacerlo                    | llama al servicio de enlaces cortos y devuelve un enlace surl.id                  |

En una frase: **tu agent de programación pasa de "solo saber escribir código" a "también saber generar imágenes, videos, música y buscar en Internet".**

## Empieza en tres pasos

Todo el proceso se completa en unos minutos y requiere Node.js 18+.

**Primer paso · Obtén un API Token.** Ve a la [consola](https://platform.acedata.cloud/console/applications) y copia el Token: todas las capacidades comparten este mismo token, la primera solicitud incluye créditos gratuitos, así que primero puedes probarlo gratis.

![Copiar el API Token en la consola](https://cdn.acedata.cloud/dvc3cg.jpg)

**Segundo paso · Instálalo.** Una línea de comando:

```bash
npx acekit
```

Detectará automáticamente los agentes de programación en tu máquina e instalará todo el conjunto de habilidades. Así se ve una ejecución real (esta máquina solo tenía instalado Claude Code):

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> Cuando no has configurado el Token, la primera ejecución te pedirá interactivamente que lo pegues; también puedes ejecutar previamente `export ACEDATACLOUD_API_TOKEN=tu_token` para instalarlo de forma completamente desatendida. La cantidad de habilidades cambiará a medida que aumenten las capacidades de la plataforma; consulta la lista actual mostrada por `npx acekit list`.

**Tercer paso · Habla en lenguaje natural.** Recarga el agent y luego da instrucciones directamente, por ejemplo:

```text
Usa la habilidad short-url para acortar https://platform.acedata.cloud/services
```

El agent cargará la habilidad por sí mismo, iniciará la llamada por sí mismo y te dará un resultado real al que se puede acceder.

## Ejecútalo de verdad una vez (con salida)

Los cuatro ejemplos siguientes son todos **llamadas reales y resultados devueltos en el momento**, no demostraciones. El `$KEY` en los comandos es tu API Token.

**① Acortar URL (síncrono, respuesta en segundos)**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

Devuelve `https://surl.id/r/1uKp2kilXQ`—al abrirlo, hará una redirección 302 de vuelta a la página original de services.

**② Búsqueda en Internet (síncrono)**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

Obtienes resultados de Google en tiempo real (extracto):

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ Conversación LLM (síncrono, un endpoint conecta con más de 50 modelos)**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP es un protocolo utilizado para gestionar e intercambiar de forma unificada información de contexto de modelos.
（39 tokens, aproximadamente 0.00007 credit en esta ocasión）
```

**④ Generación de imágenes (asíncrono, unos 20 segundos; el agent realiza automáticamente sondeos hasta obtener la imagen)**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

Unos 22 segundos después devuelve una imagen real (HTTP 200 · image/png · 317 KB · aproximadamente 0.13 credit en esta ocasión):

![Imagen generada realmente por AceKit](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

En realidad no necesitas recordar estas interfaces: después de instalar las habilidades, el agent construirá por sí mismo las solicitudes correctas según sus respectivos `SKILL.md`, y gestionará la autenticación y los sondeos. Lo anterior solo muestra claramente lo que hace entre bastidores.

## Qué instala exactamente

AceKit es la "puerta principal" de toda la superficie de herramientas para desarrolladores de AceData; actualmente, una instalación instala el **conjunto de herramientas de habilidades (Skills)**:

- **Un conjunto de habilidades de Agent**: cada habilidad es un manual de operaciones `SKILL.md` ya escrito—la autenticación, los sondeos asíncronos, los reintentos por errores y cómo completar los parámetros están explicados claramente; el agent solo tiene que seguirlo. Ejecuta `npx acekit list` para ver la lista actual (al escribir esto eran 19, y sigue aumentando):
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **Un único Token**: un `ACEDATACLOUD_API_TOKEN` desbloquea todas las capacidades, facturado según el uso real.

Clasificado por capacidad (según `npx acekit list`):

| Tipo         | Proveedores                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ Generación de imágenes      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 Generación de videos      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 Generación de música / audio | Suno · Producer · Fish Audio（TTS）                    |
| 💬 Conversación LLM   | Interfaz unificada para más de 50 modelos（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 Búsqueda       | Google SERP（web · imágenes · noticias · mapas · videos）                  |
| 🔗 Herramientas       | Enlaces cortos · procesamiento facial                                            |

> Para estas mismas capacidades, AceData también ofrece **servidores MCP** independientes（Suno、Midjourney、Sora、SERP… ya publicados en PyPI / VS Code / Smithery / Docker）、**CLI de línea de comandos** y **SDK de Python / TypeScript**, que pueden utilizarse por separado según sea necesario. AceKit v0.2 planea admitir la instalación de una sola capacidad con `acekit add <name>`, así como la escritura automática de la configuración MCP de cada agent.

## Qué Agents son compatibles

| Agent                        | Ubicación de instalación de habilidades                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode, etc. | `~/.agents/skills`（haz que tu agent apunte aquí） |

Durante la instalación, AceKit detecta automáticamente los agents ya instalados en la máquina y solo instala en los detectados.

## Huevo de Pascua: usa el mismo Token para impulsar Claude Code mismo

La interfaz de AceData también es compatible con el formato `/v1/messages` de Anthropic, por lo que **no necesitas una suscripción oficial de Anthropic**; puedes usar el mismo Token de AceData para impulsar Claude Code. Crea `.claude/settings.local.json` en el directorio raíz del proyecto:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Simplemente reinicia Claude Code: no solo utilizará toda la serie de modelos Claude, sino que también tendrá las "manos" de generación de imágenes, videos y música mediante AceKit. Para más detalles, consulta la [guía de integración de Claude Code](https://platform.acedata.cloud/documents/claude-code-integration).
