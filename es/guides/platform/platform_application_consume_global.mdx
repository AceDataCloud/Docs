---
title: "Configurar el uso compartido del saldo global de AceDataCloud Application"
description: "Platform API guide - Ace Data Cloud"
---

Configure `allow_consume_global`. Después de habilitarlo, las Application de pago por uso que cumplan las condiciones podrán seguir utilizando el saldo global de la cuenta cuando su propio saldo sea insuficiente.

## Preparativos

- Cree y guarde de forma segura el [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Obtenga el `application_id` que posee de la [lista de solicitudes de servicio](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='tu token de cuenta'
export APPLICATION_ID='tu Application ID'
```

## Resumen de la interfaz

| Elemento | Contenido                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------- |
| Método   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Autenticación   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

Si tiene éxito, devuelve el objeto Application actualizado. Tome como referencia `allow_consume_global` en la respuesta, en lugar de asumir que el valor solicitado se guardó necesariamente.

> Las Application de tipo `Period` no tienen permitido consumir el saldo global. Incluso si se solicita `true`, el servidor mantendrá este campo como `false`.

## Manejo de errores

- `401`: El Account Token no es válido o falta.
- `403`: La cuenta actual no es la propietaria de esta Application.
- `404`: El Application ID no existe.

La entrada de recarga del saldo global y los paquetes disponibles se basarán en los paquetes reales de la consola de la plataforma y los devueltos por la [creación de pedidos](https://platform.acedata.cloud/documents/platform-order-create); no asuma que existe un paquete de tipo `Wallet`.

## Aplicaciones con sobregiro autorizado

Cuando el campo de solo lectura `allow_overdraft=true` de una aplicación de pago por uso está habilitado, la aplicación puede seguir descontando cargos de su propio saldo, incluso si el saldo se vuelve negativo, y no cambiará a la cuenta global debido a saldo insuficiente. Las aplicaciones sin sobregiro habilitado siguen cumpliendo con `allow_consume_global`; después del cambio, si se permite el sobregiro se determinará según la configuración de la Application global desde la que se realiza el cobro real.
