---
title: "Configurar el uso compartido del saldo global de AceDataCloud Application"
description: "Platform API guide - Ace Data Cloud"
---

Configure `allow_consume_global`. Después de activarlo, las Application de pago por uso que cumplan las condiciones pueden seguir utilizando el saldo global de la cuenta cuando su propio saldo sea insuficiente.

## Preparativos

- Cree y guarde de forma segura el [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Obtenga el `application_id` que posee de la [lista de solicitudes de servicio](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='你的账户令牌'
export APPLICATION_ID='你的 Application ID'
```

## Resumen de la interfaz

| Elemento    | Contenido                                                                                          |
| ------- | -------------------------------------------------------------------------------------------------- |
| Método   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Autenticación   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

Si tiene éxito, devuelve el objeto Application actualizado. Tome como referencia el valor de `allow_consume_global` en la respuesta, en lugar de asumir que el valor solicitado se guardará necesariamente.

> Las Application de tipo `Period` no tienen permitido consumir el saldo global. Incluso si se solicita `true`, el servidor mantendrá este campo como `false`.

## Manejo de errores

- `401`: Account Token no válido o ausente.
- `403`: La cuenta actual no es la propietaria de esta Application.
- `404`: El ID de Application no existe.

El acceso de recarga del saldo global y los paquetes disponibles se basarán en la consola de la plataforma y en los paquetes reales devueltos por la [creación de pedidos](https://platform.acedata.cloud/documents/platform-order-create); no asuma que existe un paquete de tipo `Wallet`.
