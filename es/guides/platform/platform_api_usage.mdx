---
title: "Obtener muestras de llamadas recientes de la API de la plataforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Devuelve públicamente muestras de registros de llamadas de una determinada API dentro de los últimos 15 minutos, para observar rápidamente el estado reciente. No es una interfaz de conteo agregada por código de estado, ni puede utilizarse para facturación personal, SLA o estadísticas completas de uso.

## Resumen de la interfaz

| Elemento   | Contenido                                                           |
| --- | ------------------------------------------------------------ |
| Método  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| Autenticación  | Pública, no se requiere token de cuenta                                                    |
| Límite  | Tras combinar los registros creados/finalizados más recientes, devuelve como máximo 5.000 registros                                    |

`api_id` se obtiene de la [lista de API](https://platform.acedata.cloud/documents/platform-api-list).

```shell
export API_ID='tu ID de API'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## Estructura de respuesta real

La respuesta es directamente un arreglo, sin utilizar un envelope de paginación:

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| Campo            | Descripción        |
| ------------- | --------- |
| `api_id`      | ID de API    |
| `created_at`  | Hora de creación del registro    |
| `trace_id`    | Identificador de seguimiento de la solicitud    |
| `status_code` | Código de estado HTTP  |
| `elapsed`     | Duración de la llamada, en segundos |

Cuando la API no existe, actualmente también puede devolver un arreglo vacío, ya que esta acción consulta directamente el usage reciente por ID y no valida primero el objeto API. Para calcular la tasa de éxito, el cliente debe agrupar por sí mismo las muestras devueltas; para consultar cargos personales, utilice la interfaz a nivel de cuenta.
