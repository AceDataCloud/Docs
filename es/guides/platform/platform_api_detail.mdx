Obtiene la información completa de un único endpoint de API mediante el ID de API; en comparación con la [interfaz de lista](https://platform.acedata.cloud/documents/platform-api-list), incluye los campos adicionales `definition` (OpenAPI 3.0 Schema), `service` (detalles del servicio al que pertenece) y `products` (productos asociados).

Adecuado para escenarios como la generación automática de SDK, alimentar a un LLM Agent con descripciones de herramientas, la renderización dinámica de sitios de documentación, etc.

> ℹ️ Esta interfaz pertenece a la **API de administración de la plataforma AceDataCloud**, con el prefijo unificado `https://platform.acedata.cloud/api/v1/`. Para el índice completo de interfaces, consulta [Obtener la lista de documentos de la plataforma AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list).

## Resumen de la interfaz

| Elemento   | Contenido                                             |
| --- | ----------------------------------------------------- |
| Método  | `GET`                                                 |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}` |
| Autenticación  | ❌ Pública                                                  |

Actualmente, tanto `/apis/{id}` como `/apis/{id}/` están disponibles; los ejemplos utilizan de forma unificada la variante sin barra final.

## Descripción de autenticación

Esta interfaz es **completamente pública y no requiere token de cuenta ni sesión iniciada**.

## Parámetros de ruta

| Parámetro       | Tipo   | Obligatorio  | Descripción                    |
| -------- | ---- | --- | --------------------- |
| `api_id` | UUID | ✅   | ID de API (formato UUID; no se admiten alias) |

## Ejemplos de solicitud

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/apis/afc7917f-d89f-4dc9-95c2-863936b02cad' \
  -H 'accept: application/json'
```

### Python

```python
import requests

api_id = "afc7917f-d89f-4dc9-95c2-863936b02cad"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/apis/{api_id}",
    headers={"accept": "application/json"},
    timeout=10,
)
api = resp.json()
print(f"API: {api['title']}")
print(f"路径: {api['path']}")
print(f"所属服务: {api['service']['title']} ({api['service']['alias']})")
print(f"OpenAPI 路径数: {len(api.get('definition', {}).get('paths', {}))}")
```

### Node.js

```javascript
const apiId = 'afc7917f-d89f-4dc9-95c2-863936b02cad'
const r = await fetch(`https://platform.acedata.cloud/api/v1/apis/${apiId}`)
const api = await r.json()
console.log(api.title, api.path, api.service.title)
```

## Descripción de los campos de respuesta

La interfaz de detalles incluye adicionalmente, sobre los [campos de la interfaz de lista](https://platform.acedata.cloud/documents/platform-api-list):

| Campo           | Tipo     | Descripción                                                                                          |
| ------------ | ------ | ------------------------------------------------------------------------------------------- |
| `service`    | object | Información principal del servicio al que pertenece: `id`, `title`, `type`, `alias`                                                       |
| `products`   | array  | Lista de productos asociados (generalmente vacía; para uso del equipo de operaciones)                                                                         |
| `definition` | object | **Definición completa de la especificación OpenAPI 3.0**, incluye `paths`, `components`, `info`, etc., y puede proporcionarse directamente a `openapi-generator` para generar código cliente |

## Gestión de errores

| HTTP | code        | Significado                 |
| ---- | ----------- | ------------------ |
| 400  | `invalid`   | `api_id` no es un UUID válido |
| 404  | `not_found` | La API no existe o ha sido desactivada        |

## Consejos prácticos

- **El campo `definition` es muy grande**: el OpenAPI Schema de una sola API puede contener cientos de líneas de JSON. Si solo se necesita crear un índice de servicios y no se requiere el Schema, se debe utilizar la [interfaz de lista](https://platform.acedata.cloud/documents/platform-api-list) en su lugar.
- **Uso habitual para generar SDK**:
  ```shell
  # 拿到 OpenAPI 文件
  curl -s 'https://platform.acedata.cloud/api/v1/apis/<api_id>' | jq '.definition' > openapi.json

  # 用 openapi-generator-cli 生成 Python 客户端
  openapi-generator-cli generate -i openapi.json -g python -o ./client
  ```
- **Seguimiento de cambios de API**: el campo `updated_at` es la hora de la última modificación del schema. Suscribirse a este campo permite regenerar automáticamente el SDK cuando OpenAPI cambie.
