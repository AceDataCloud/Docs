Lee los interruptores de funciones públicos y la determinación de país/región en el contexto de la solicitud actual. Es adecuado para decidir si se muestran funciones al iniciar el frontend; no incluye la marca del sitio, la información de contacto ni el directorio de anuncios.

## Resumen de la API

| Elemento   | Contenido                                      |
| --- | ----------------------------------------------- |
| Método  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Autenticación  | Pública; al incluir un estado de inicio de sesión, algunos interruptores de funciones pueden calcularse según el usuario                          |

## Parámetros de consulta y encabezados de solicitud

| Nombre                    | Ubicación     | Descripción                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | Código de país ASCII de dos caracteres; se utiliza para sobrescribir el país mostrado en la respuesta, sin cambiar la determinación de seguridad del servidor |
| `features`            | query  | Expresión de sobrescritura de interruptores de funciones; solo es efectiva para interruptores que permiten la sobrescritura del cliente o para superadministradores        |
| `X-Feature-Overrides` | header | Fuente de sobrescritura igual que `features`                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## Estructura de respuesta real

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| Campo         | Tipo            | Descripción                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Interruptores de funciones visibles para la solicitud actual; las claves cambiarán según la configuración de la plataforma, el cliente debe leer según sea necesario y establecer valores predeterminados seguros para las claves ausentes |
| `country`  | string / null | Código de país en minúsculas; puede ser `null` cuando no se puede identificar                     |

No obtenga de esta API el nombre del sitio, CDN, moneda, idioma, información de contacto de atención al cliente ni anuncios; estos campos no pertenecen al contrato de respuesta actual.

## Recomendaciones de uso

- Los interruptores de funciones se calculan según el usuario, la huella digital y el contexto del sitio; no comparta cachés a largo plazo entre usuarios.
- El `country` proporcionado por el cliente solo afecta el valor de retorno y no evita las estrategias regionales o de seguridad del servidor.
- Los parámetros de query no reconocidos se ignorarán; use solo los parámetros enumerados en esta página.
