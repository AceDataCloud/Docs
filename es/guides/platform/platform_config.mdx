Lee los interruptores de funciones públicos y la determinación de país/región en el contexto de la solicitud actual. Es adecuado para decidir si se muestran funciones al iniciar el frontend; no es una marca del sitio, información de contacto ni un directorio de anuncios.

## Resumen de la API

| Elemento   | Contenido                                              |
| --- | ----------------------------------------------- |
| Método  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Autenticación  | Pública; al incluir el estado de inicio de sesión, algunos interruptores de funciones pueden calcularse según el usuario                          |

## Parámetros de consulta y encabezados de solicitud

| Nombre                    | Ubicación     | Descripción                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | Expresión de sobrescritura de interruptores de funciones; solo es efectiva para interruptores que permiten sobrescritura del cliente o para superadministradores |
| `X-Feature-Overrides` | header | Fuente de sobrescritura igual que `features`           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## Estructura de respuesta real

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| Campo         | Tipo            | Descripción                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Interruptores de funciones visibles para la solicitud actual; las claves cambiarán según la configuración de la plataforma, el cliente debe leer según sea necesario y establecer valores predeterminados seguros para las claves faltantes |
| `region`   | string / null | Código de país o región detectado según la IP de la solicitud, en minúsculas; es `null` cuando no se puede reconocer        |

No leas desde esta API el nombre del sitio, CDN, moneda, idioma, información de contacto de atención al cliente ni anuncios; estos campos no pertenecen al contrato de respuesta actual.

## Recomendaciones de uso

- Los interruptores de funciones se calculan según el usuario, la huella digital y el contexto del sitio; no compartas cachés a largo plazo entre usuarios.
- La selección del selector de región solo se guarda en el frontend; al mostrarla, usa prioritariamente la región ya seleccionada; de lo contrario, usa `region` de esta API. Esta API no acepta parámetros de sobrescritura de región.
- Los parámetros de query no reconocidos se ignorarán; utiliza solo los parámetros enumerados en esta página.
