El Provider de modelo Coding Plan de OpenCode, la extensión de IDE y MCP son tres capacidades independientes. La extensión de IDE se conecta al runtime local de OpenCode y reutiliza la misma configuración de Provider; no representa que el editor anfitrión admita de forma nativa Ace Data Cloud.

| Ruta                            | Descripción                                                      | Enlace                                                                                    | Estado      |
| ----------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------- |
| Terminal / CLI / TUI Provider | Usa `opencode.json[c]` y Chat Completions                | [Configuración de Provider](https://platform.acedata.cloud/documents/opencode-terminal-integration) | Contrato de configuración validado |
| Extensión de IDE                 | Anfitriones como VS Code, Cursor, Windsurf y VSCodium se conectan al runtime de OpenCode | [Configuración de IDE](https://platform.acedata.cloud/documents/opencode-ide-integration)           | Experimental     |
| MCP                           | Llama herramientas remotas dentro de OpenCode                                      | [Resumen de MCP](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | Capacidad independiente    |

Una vez que la configuración de Provider se haya realizado correctamente, la extensión de IDE debe usar el mismo Provider y modelo. Aún se deben validar por separado el chat dentro del IDE, la lectura de archivos, la edición y las llamadas a herramientas; no se debe extrapolar automáticamente una solicitud ordinaria del CLI a todas las capacidades del IDE.

Los ID de modelo se rigen por el [catálogo en tiempo real](https://platform.acedata.cloud/models).
