---
title: "Obtener la lista de servicios de la plataforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Devuelve de forma paginada el catálogo de Service visible en el sitio actual, incluidos el tipo de servicio, la información de visualización, la cuota gratuita, los planes y los ID de API/Proxy asociados. Adecuado para construir un mercado de servicios o seleccionar servicios para solicitar.

## Resumen de la interfaz

| Elemento   | Contenido                                                |
| --- | ------------------------------------------------- |
| Método  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| Autenticación  | Público; con sesión iniciada, `applied` refleja la cuenta actual                        |
| Paginación  | `count` + `items`                                 |

## Parámetros de consulta

| Parámetro               | Tipo      | Obligatorio  | Descripción                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | No   | Filtra por ID de servicio; admite parámetros repetidos         |
| `private`        | boolean | No   | Filtra por estado público; las reglas de visibilidad del sitio siguen vigentes      |
| `type`           | string  | No   | Tipo de servicio; admite parámetros repetidos              |
| `tag`            | string  | No   | Filtra por etiqueta                    |
| `include_facets` | boolean | No   | Cuando es `true`, añade estadísticas de tipos/etiquetas disponibles en el sitio actual |
| `limit`          | integer | No   | Número de elementos por página, máximo 100              |
| `offset`         | integer | No   | Desplazamiento de paginación                    |
| `ordering`       | string  | No   | Solo admite `rank` o `-rank`     |

La lista no admite filtrado por `alias`; si ya se dispone de un alias, solicite directamente `/api/v1/services/{alias}`. `applied_count` y `updated_at` no son campos de ordenación permitidos.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## Descripción de la respuesta

La respuesta es `{count, items}`; solo se añade `facets` cuando `include_facets=true`. Los elementos de servicio incluyen los campos públicos actuales como `id`, `alias`, `title`, `description`, `type`, `applied_count`, `free_amount`, `unit`, `private`, `need_verify`, `rank`, `tags`, `thumbnail`, `doc_url`, `demo_url`, `api_ids`, `proxy_ids`, `cost`, `packages`, entre otros.

`applied` en una lista anónima no representa el estado de solicitud de una cuenta determinada. Cuando se requiera un estado relacionado con la cuenta, se debe incluir una sesión iniciada válida y utilizar la [lista de solicitudes de servicio](https://platform.acedata.cloud/documents/platform-application-list) como referencia final.
