La documentación oficial de GitHub Copilot BYOK enumera a VS Code como un cliente local compatible y admite Proveedores compatibles con OpenAI. La versión de VS Code, la política empresarial y la visibilidad del modelo afectarán el endpoint final; para la primera integración, consulta la solicitud real a continuación.

## Rango de configuración

1. Confirma que tu cuenta o organización de GitHub Copilot tenga habilitada la función BYOK/Modelos Personalizados.
2. En la gestión de modelos de Copilot en VS Code, añade un Proveedor compatible con OpenAI.
3. Completa la URL base con `https://api.acedata.cloud/v1`.
4. Completa la clave API con tu Token de API de Ace Data Cloud.
5. Completa el modelo con el ID de modelo exacto compatible con el protocolo seleccionado en el directorio de modelos.
6. En Copilot Chat, envía `Reply only OK`, y luego prueba nuevamente la solicitud con el contexto del espacio de trabajo.

## Límites actuales

- La configuración de Copilot App, CLI, GitHub Desktop, Enterprise BYOK y VS Code es diferente; esta guía no aplica directamente los pasos de otros clientes a VS Code.
- La política de la organización puede prohibir que los individuos añadan Proveedores o modelos.
- La finalización de tabulaciones, Chat, Agente y tareas en segundo plano pueden usar diferentes rutas de modelo, y deben ser verificadas por separado.
