---
title: "Obtener la lista de Proxy bajo el servicio de la plataforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Devuelve paginadamente los puntos finales Proxy montados en este servicio mediante Service UUID. Si solo se dispone de alias, primero llama a los [detalles del servicio](https://platform.acedata.cloud/documents/platform-service-detail) para obtener `id`.

## Resumen de la interfaz

| Elemento   | Contenido                                                              |
| --- | ---------------------------------------------------------------------- |
| Método  | `GET`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| Autenticación  | Pública, no se requiere token de cuenta                                                              |
| Paginación  | `count` + `items`                                                      |

## Parámetros

| Parámetro                 | Ubicación    | Obligatorio  | Descripción                               |
| ------------------ | ----- | --- | -------------------------------- |
| `service_id`       | path  | Sí   | Service UUID, no admite alias           |
| `limit` / `offset` | query | No   | Paginación                               |
| `ordering`         | query | No   | Expresión de ordenación de Django; se recomienda `rank` o `-rank` |

```shell
export SERVICE_ID='tu Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## Descripción de la respuesta

Los elementos de la lista se serializan mediante el modelo Proxy; los campos verificados en línea incluyen `id`, `service_id`, `title`, `endpoint`, `price`, `stage`, `rank`, `tags`, `metadata`, `document_id`, `service` y campos de tiempo.

- El campo de entrada de negocio es `endpoint`, no `path`.
- El campo de precio es `price`, no `cost`.
- Cuando el tipo de Service no es Proxy o no tiene Proxy montados, se devuelven `items` vacíos.

Las integraciones públicas solo dependen de `endpoint` y las capacidades publicadas, y no deben depender de detalles de implementación no públicos.
