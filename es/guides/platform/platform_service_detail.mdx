Obtén la información completa de un solo servicio mediante el ID del servicio (UUID) o alias (alias): los campos devueltos son más completos que los de la [lista de servicios de la plataforma AceDataCloud](https://platform.acedata.cloud/documents/platform-service-list), y además se expanden objetos asociados como `apis`, `proxies`, `datasets`, `packages`, etc. Adecuado para escenarios como páginas de detalles de servicios, páginas de comparación de precios, descripciones de herramientas de Agent, etc.

> ℹ️ Esta interfaz pertenece a la **API de administración de la plataforma AceDataCloud**, con el prefijo unificado `https://platform.acedata.cloud/api/v1/`. Consulta el índice completo de interfaces en [obtener lista de documentos de la plataforma AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list).

## Descripción general de la interfaz

| Elemento   | Contenido                                                            |
| --- | ------------------------------------------------------------- |
| Método  | `GET`                                                         |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}` |
| Autenticación  | ❌ Pública                                                          |

Actualmente, tanto `/services/{id}` como `/services/{id}/` están disponibles; los ejemplos usan de forma unificada la forma sin barra diagonal final.

## Descripción de autenticación

Esta interfaz es completamente pública. **Sin embargo, después de incluir un token de cuenta, el campo `applied` en la respuesta reflejará el estado real de solicitud de la cuenta actual**; de lo contrario, siempre será `false`.

Consulta cómo obtener el token de cuenta en [administrar tokens de cuenta de la plataforma AceDataCloud](https://platform.acedata.cloud/documents/platform-token).

## Parámetros de ruta

| Parámetro           | Tipo            | Obligatorio  | Descripción                                                    |
| ------------ | ------------- | --- | ----------------------------------------------------- |
| `service_id` | UUID / string | ✅   | ID del servicio (UUID) o alias (`midjourney`, `openai`, `webextrator`, etc.) |

## Ejemplos de solicitud

### cURL

```shell
# 按 UUID 查询
curl 'https://platform.acedata.cloud/api/v1/services/8efa1d83-9b75-4562-b44a-af95ce563d05' \
  -H 'accept: application/json'

# 按 alias 查询
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json'

# 带账户令牌看 applied 状态
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

resp = requests.get(
    "https://platform.acedata.cloud/api/v1/services/midjourney",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
svc = resp.json()
print(f"服务: {svc['title']} ({svc['alias']})")
print(f"已申请: {svc['applied']}, 免费额度: {svc['free_amount']} {svc['unit']}")
print(f"API 数: {len(svc['apis'])}, 套餐数: {len(svc['packages'])}")
for pkg in svc["packages"]:
    print(f"  ¥{pkg['price']:>7.2f}  ->  {pkg['amount']} {svc['unit']}")
```

### Node.js

```javascript
const r = await fetch('https://platform.acedata.cloud/api/v1/services/midjourney', {
  headers: { accept: 'application/json' },
})
const svc = await r.json()
console.log(`${svc.title} - 套餐 ${svc.packages.length} 个 - API ${svc.apis.length} 个`)
```

## Descripción de los campos de respuesta

Además de todos los campos de la [interfaz de lista](https://platform.acedata.cloud/documents/platform-service-list), la interfaz de detalles expande adicionalmente:

| Campo         | Tipo    | Descripción                                                            |
| ---------- | ----- | ------------------------------------------------------------- |
| `apis`     | array | Lista completa de objetos API asociados (cada elemento incluye `id`, `name`, `title`, `path`, `stage`, `cost`) |
| `proxies`  | array | Lista completa de objetos Proxy asociados                                              |
| `datasets` | array | Conjuntos de datos asociados (si `type=Dataset`)                                      |
| `packages` | array | Lista de paquetes, incluye `type` (`Usage`/`Period`), `price`, `amount`, `duration`   |

Consulta las definiciones de los demás campos en [obtener lista de servicios de la plataforma AceDataCloud → descripción de campos de respuesta](https://platform.acedata.cloud/documents/platform-service-list).

## Manejo de errores

| HTTP | code        | Significado                            |
| ---- | ----------- | ----------------------------- |
| 404  | `not_found` | `service_id` (UUID o alias) no existe |
| 500  | —           | Generalmente se añade por error una barra diagonal al final de la URL; elimínala y vuelve a intentarlo          |

## Consejos prácticos

- **`alias` > `UUID`**: Codificar de forma fija `alias` (por ejemplo, `midjourney`) en el código es más estable; el UUID cambia al migrar entornos.
- **El campo `apis` no incluye la definición OpenAPI**: El Schema completo de OpenAPI 3.0 se encuentra en la interfaz [obtener detalles de la API de la plataforma AceDataCloud](https://platform.acedata.cloud/documents/platform-api-detail).
- **Obtener la "capacidad completa" de un servicio**: Usa esta interfaz para obtener `api_ids`, y luego llama a `/apis/{api_id}` uno por uno para obtener los detalles.
- **Si `applied=true`**, puedes [crear directamente credenciales de API](https://platform.acedata.cloud/documents/platform-credential-create) para obtener el Token de 32 caracteres necesario para llamar a las interfaces de negocio, sin necesidad de solicitarlo nuevamente.
