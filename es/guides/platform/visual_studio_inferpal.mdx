Inferpal es una extensión para Visual Studio 2022/2026, que oficialmente soporta la conexión a servicios compatibles con OpenAI. La versión de la extensión puede afectar la edición, las llamadas a herramientas y el registro de uso; para la primera conexión, por favor fija la versión y completa la mínima verificación a continuación.

## Configuración

1. Instala Inferpal desde Visual Studio Marketplace o el repositorio oficial.
2. Abre **Settings → Connection** de Inferpal.
3. Selecciona OpenAI-compatible en Provider.
4. Completa la Base URL con `https://api.acedata.cloud/v1`.
5. Completa el API Key con tu Token de API de Ace Data Cloud.
6. Completa el Model con el ID del modelo exacto que soporte Chat Completions en el directorio de modelos.
7. Después de guardar, envía `Reply only OK`, y luego ejecuta nuevamente una solicitud que incluya el contexto del código.

## Límites actuales

- Esta guía cubre solo Inferpal y no representa que Copilot integrado en Visual Studio u otras extensiones soporten los mismos campos.
- Diferentes versiones pueden agregar automáticamente rutas a la Base URL; si la solicitud falla, verifica primero si la solicitud final cae en el endpoint de Chat Completions.
- No se garantiza que todos los modos de edición, completado o llamadas a herramientas estén disponibles antes de completar la versión fija E2E.
