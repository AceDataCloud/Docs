FreeAIr es una extensión de código abierto para Visual Studio 2022/2026, que según la declaración oficial, puede conectarse a cualquier API compatible con OpenAI. El comportamiento de las solicitudes puede variar entre diferentes versiones de la extensión; para la primera conexión, se recomienda fijar la versión y completar la verificación mínima a continuación.

## Configuración

1. Instala FreeAIr desde Visual Studio Marketplace o el repositorio oficial.
2. Abre la configuración de FreeAIr y añade una conexión compatible con OpenAI.
3. En Endpoint, escribe `https://api.acedata.cloud/v1`.
4. En Token, introduce tu Token de API de Ace Data Cloud.
5. En Model, escribe el ID del modelo exacto que soporte Chat Completions en el directorio de modelos.
6. Después de guardar, envía `Reply only OK`, y prueba nuevamente una solicitud con el contexto del proyecto.

## Límites actuales

- Esta guía cubre solo FreeAIr y no representa que el Copilot integrado en Visual Studio soporte URL base arbitrarias.
- La versión de la extensión puede cambiar la forma de concatenar el endpoint; al verificar, se debe comprobar la URL de solicitud final.
- Las capacidades de MCP dentro de la extensión y las llamadas a herramientas necesitan verificación independiente, no se puede sustituir el éxito de un chat normal.
