La extensión oficial de IDE de OpenCode es compatible con editores como VS Code, Cursor, Windsurf, VSCodium, y reutiliza la configuración de runtime y Provider local de OpenCode. La extensión de IDE reutiliza el Provider CLI local, pero la cadena de solicitudes puede variar entre diferentes versiones de editores; al integrarse por primera vez, se recomienda fijar la versión y completar la validación mínima.

## Configuración del Provider

Primero, configure el Provider de Ace Data Cloud en `opencode.json` o `opencode.jsonc` según la [configuración de OpenCode Terminal](https://platform.acedata.cloud/documents/opencode-terminal-integration):

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## Instalación de la Extensión IDE

1. Ejecute `opencode` en la terminal integrada del editor para instalar automáticamente la extensión según el proceso oficial; también puede instalarla manualmente desde el Marketplace correspondiente.
2. Recargue el editor.
3. Inicie `Reply only OK` desde la extensión de OpenCode.
4. Ejecute nuevamente la solicitud que necesita leer archivos o modificar código, para confirmar que la extensión IDE utiliza el mismo Provider y modelo.

## Límites actuales

- Las capacidades del Provider provienen del runtime de OpenCode, no representan el soporte nativo de Ace Data Cloud en el editor anfitrión.
- Las versiones de la extensión de VS Code y sus forks pueden ser diferentes, y se deben registrar por separado.
- Un chat exitoso no puede reemplazar la validación de lectura de archivos, edición y llamadas a herramientas.
