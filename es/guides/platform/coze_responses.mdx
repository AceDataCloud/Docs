La documentación oficial del modelo personalizado de Coze admite la API de OpenAI Responses y proporciona la URL base de la API, la clave de API y los campos del modelo. Las diferentes versiones de inquilinos de Coze pueden manejar la concatenación de rutas, la salida en streaming y las llamadas a herramientas de manera diferente; si es la primera vez que te conectas, verifica cada elemento a continuación.

## Configuración

1. Accede a la gestión de modelos de Coze y añade un modelo personalizado.
2. Selecciona el protocolo API de OpenAI Responses.
3. Rellena la URL base de la API con `https://api.acedata.cloud/v1`.
4. Rellena la clave de API con tu token de API de Ace Data Cloud.
5. Rellena el modelo con el ID de modelo exacto que admite la API de Responses en el directorio de modelos.
6. Guarda y completa la prueba de conexión de Coze.
7. En Bot/Agente, envía `Reply only OK`, y prueba nuevamente la llamada a la herramienta.

## Límites Actuales

- Diferentes regiones, versiones o paquetes de Coze pueden mostrar diferentes formularios.
- La URL base de la API debe usar base, no añadas `/responses` de nuevo; si la UI actual requiere claramente la URL completa de la API, sigue las indicaciones del formulario.
- Chat Completions, Responses y Anthropic Messages son tres rutas independientes y no pueden sustituirse entre sí para la verificación.
