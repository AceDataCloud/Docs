---
title: "Obtener la lista de modelos de la plataforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Devuelve el catálogo público de modelos de la plataforma; la respuesta utiliza una estructura de estilo OpenAI `{ "object": "list", "data": [...] }`. Este catálogo se utiliza para la selección de modelos y el descubrimiento de capacidades, y no representa que la cuenta actual haya solicitado necesariamente los servicios correspondientes.

## Resumen de la interfaz

| Elemento   | Contenido                                              |
| --- | ----------------------------------------------- |
| Método  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| Autenticación  | Pública, no se requiere token de cuenta                                       |
| Paginación  | Sin paginación, todos los elementos coincidentes se encuentran en `data`                              |

## Parámetros de consulta

| Parámetro             | Tipo      | Obligatorio  | Descripción                                      |
| -------------- | ------- | --- | --------------------------------------- |
| `owned_by`     | string  | No   | Filtra con precisión por el identificador del proveedor del modelo en el catálogo                        |
| `type`         | string  | No   | Filtra con precisión por tipo de modelo, por ejemplo `chat`                     |
| `capability`   | string  | No   | Devuelve únicamente modelos cuyos `capabilities` contienen esta capacidad, por ejemplo `vision` |
| `with_pricing` | boolean | No   | Adjunta información pública de precios cuando es `1`, `true` o `yes`            |

`service_id`, `tag`, `limit`, `offset` y `ordering` no son compatibles actualmente; tras pasarlos no producirán los efectos correspondientes de filtrado o paginación.

## Ejemplos de solicitudes

```shell
# Todos los modelos públicos
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# Modelos chat compatibles con visión, con precios incluidos
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## Estructura de respuesta real

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

`pricing` y el `credit_usd_rate` de nivel superior solo aparecen cuando `with_pricing=true`; no todos los modelos tienen un `pricing` calculable. Los objetos de modelo se basan en los campos públicos de `config/models.json`, y los clientes deben ignorar los campos nuevos.

> Los campos de precios son datos de visualización del catálogo. Las llamadas comerciales reales siguen sujetas a las reglas de facturación de la API/Service correspondiente y a los registros finales de uso.
