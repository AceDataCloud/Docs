Productor nos permite generar letras a través de palabras clave, este documento explica cómo integrar la API relacionada.

Esta API solo tiene un parámetro de entrada, que es `prompt`, que es la palabra clave para generar la letra.

Aquí, el `prompt` que ingresamos es `Una canción sobre el invierno`, que es la palabra clave para generar la letra.

```bash
curl -X POST 'https://api.acedata.cloud/producer/lyrics' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Una canción sobre el invierno"
}'
```

El resultado es el siguiente:

```
{
    "success": true,
    "task_id": "d354b519-43c0-4888-a3da-83adbf845fd6",
    "data": {
        "title": "Misericordia en los Árboles",
        "lyrics": "[Verso 1]\nSalí más allá del patio de trenes\nDonde los pinos crecen densos con escarcha\nLa nieve no se preocupa por lo que he hecho\nCubre todo de la misma manera\n\n[Verso 2]\nHay una capilla hecha de troncos de abedul\nY el altar es el suelo\nMe arrodillo allí como un traidor\nEsperando que el silencio perdone\n\n[Estribillo]\nEl invierno es un abrigo pesado\nEl invierno es un abrigo pesado\n\n[Verso 3]\nTe fuiste antes de la primera tormenta\nMe quedé a ver el mundo volverse blanco\nAhora cada rama es un hueso\nY solo estoy contando lo que queda\n\n[Verso 4]\nDicen que el frío te matará\nPero creo que solo te hace honesto\nAquí afuera con la tierra congelada\nNo hay ningún lugar para esconder tus manos\n\n[Estribillo]\nEl invierno es un abrigo pesado\nEl invierno es un abrigo pesado\n\n[Verso 5]\nEncontré tu carta en mi bolsillo\nLa tinta se había corrido por todo el deshielo\nPero aún podía leer misericordia\nEscrita en el espacio vacío entre\n\n[Final]\nLos árboles no piden absolución\nSolo están allí, desnudos y verdaderos\nEstoy aprendiendo a hacer lo mismo\nDejando que la nieve entierre lo que necesita enterrar"
    }
}
```

Se puede ver que el campo `lyrics` de `data` es el contenido de la letra generada.
