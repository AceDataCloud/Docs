---
title: "Instrucciones de integración de la API de carga de audio de referencia de Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer nos permite cargar audio de referencia para realizar una creación secundaria; este documento explica el método de integración de la API relacionada.

Esta API solo tiene un parámetro de entrada, que es `audio_url`; es una dirección CDN de acceso público y admite el sufijo mp3.

Aquí, el `audio_url` que introducimos es `https://cdn.acedata.cloud/suno_demo.mp3`, que es una dirección CDN de acceso público.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

El resultado es el siguiente:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Soft female vocals, bright and cheerful]\n\n[Verse 1]\n阳光洒在海边\n浪花笑得灿烂\n你和我在沙滩\n钟表停止转\n冰淇淋在融化\n手牵手去散步\n风儿轻轻吹过\n心跳不停跳\n\n[Chorus]\n夏天夏天\n时间停在这一天\n笑声回荡\n蔚蓝天空在身旁",
    "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
  }
}
```

Se puede ver que el campo `audio_id` de `data` es el ID de la canción después de la carga.

Después de tener el ID de la canción, podemos usar la [API de generación de audios de Producer](https://platform.acedata.cloud/documents/producer-audios-integration) para generar canciones personalizadas; por ejemplo, si se pasa `upload_extend` en `action` y, al mismo tiempo, se pasa el ID de canción devuelto en `audio_id`, se puede generar una nueva canción basándose en el audio de referencia.
