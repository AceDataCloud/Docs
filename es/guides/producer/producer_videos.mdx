title: "Productor descarga de video API integración"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Productor nos permite descargar videos relacionados con canciones, este documento explica el método de integración de la API correspondiente.

Esta API solo tiene un parámetro de entrada, que es `audio_id`, que es el ID único de la canción.

Aquí el `audio_id` que ingresamos es `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, que es un ID de canción generado por Productor.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

El resultado es el siguiente:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4?example=video-001"
  }
}
```

Se puede ver que el campo `video_url` de `data` es el enlace para descargar el video.
