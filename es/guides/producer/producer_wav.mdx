---
title: "Instrucciones de integración de la API de descarga de WAV de Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer nos permite descargar archivos WAV relacionados con canciones; este documento explica el método de integración de la API correspondiente.

Esta API solo tiene un parámetro de entrada, que es `audio_id`, el cual es el ID único de la canción.

Aquí el `audio_id` que ingresamos es `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, que es un ID de canción generado por Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/wav' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

El resultado es el siguiente:

```
{
  "success": true,
  "task_id": "44963173-b6c5-463c-915f-96730d14ec63",
  "trace_id": "f75d6a27-54bc-49fd-a40e-6d4cd0427764",
  "data": [
    {
      "title": "Woke up with the sun in my eyes",
      "file_url": "https://cdn.acedata.cloud/assets/examples/fish/64adc04b-c196-4a0f-9070-222ba101ce6c-fc50de38c165.wav"
    }
  ]
}
```

Se puede ver que el campo `file_url` de `data` es el enlace de descarga del WAV.
