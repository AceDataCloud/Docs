SUNO nos permite cargar audio de referencia para creación secundaria; este documento explica el método de integración de la API relacionada.

La carga normal solo requiere `audio_url`, que es una dirección de CDN de audio accesible públicamente. `mode` tiene como valor predeterminado `standard`, por lo tanto, no es necesario modificar las llamadas existentes. Una carga normal exitosa consume **0.06 Credits**; las cargas fallidas no tienen costo.

El `audio_url` que ingresamos aquí es `https://cdn.acedata.cloud/suno_demo.mp3`, que es una dirección de CDN accesible públicamente.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Una vez que tenga el ID de la canción, puede usar la [API de generación de audios de Suno](https://platform.acedata.cloud/documents/suno-audios) para llamar a operaciones que requieren `audio_id`, como `upload_extend`, `upload_cover` o muestreo de intervalos. Si desea crear música nueva a partir de 1 a 4 segmentos completos de audio de referencia mediante la función de creación por inspiración Inspo, llame directamente a `action=inspo` y pase la lista de URL públicas de audio originales; el servicio completará automáticamente la carga y el análisis, sin necesidad de que el cliente ensamble los metadatos de audio.

## Cargar la canción original para una versión con una voz privada

Al crear una versión con una voz privada creada con `/suno/voices`, pase el `persona_id` de esa voz en la solicitud de carga normal para asociar la canción original con la voz:

```json
{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "mode": "standard",
  "persona_id": "<声音创建接口返回的 persona_id>"
}
```

Después de una carga exitosa, use el `data.audio_id` devuelto para llamar a `/suno/audios`, establezca `action: "upload_cover"` y pase el mismo `persona_id`. No continúe utilizando el ID de audio anterior que no estaba asociado con esa voz.

`persona_id` solo admite cargas normales y no puede utilizarse simultáneamente con `mode: "enhanced"`. No es necesario especificar adicionalmente `vocal_gender`; la preferencia de género no puede sustituir al ID de voz. La creación de la voz, la carga de la canción original y la versión deben usar el mismo canal de servicio.

## Modo de carga mejorada

> `audio_url` es la dirección de entrada y se entregará directamente al flujo de procesamiento de audio; no será transferida previamente por el servicio de persistencia de medios del estado final. Asegúrese de que pueda accederse públicamente a ella durante el procesamiento de la tarea.

Cuando la carga normal no pueda procesar el audio que posee o para cuyo uso ha obtenido autorización, puede establecer `mode` como `enhanced`. Este modo también debe proporcionar un `name` de 1 a 100 caracteres y utilizar una `audio_url` HTTPS accesible públicamente.

La carga mejorada utiliza obligatoriamente procesamiento asíncrono y normalmente requiere 2 minutos o más. El procesamiento exitoso consume **1.87 Credits**; los fallos de procesamiento no tienen costo.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

La interfaz devolverá inmediatamente `task_id` y `trace_id`. Use la [API de tareas de Suno](https://platform.acedata.cloud/documents/suno-tasks) para consultar la tarea y, tras completarse correctamente, lea el ID del audio cargado desde `response.data.audio_id`. También puede proporcionar una `callback_url` HTTPS para recibir el estado final.
El `audio_id` obtenido al mejorar la carga puede usarse para Cover, Samples y Mashup. La extracción de acompañamiento y MIDI, la separación de todas las pistas y la separación de voz/acomañamiento aún pueden estar sujetas a restricciones de la cuenta a la que pertenece el audio; no se garantiza que las operaciones no enumeradas admitan el uso entre cuentas. Cuanto más corto sea el audio, mayor suele ser la tasa de éxito del procesamiento.
