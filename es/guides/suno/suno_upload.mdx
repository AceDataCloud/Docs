SUNO nos permite subir audio de referencia para la creación secundaria, este documento explica cómo integrar las API relacionadas.

La carga normal solo requiere `audio_url`, que es una dirección CDN de audio accesible públicamente. `mode` es `standard` por defecto, por lo que las llamadas existentes no necesitan modificaciones.

Aquí, la `audio_url` que ingresamos es `https://cdn.acedata.cloud/suno_demo.mp3`, que es una dirección CDN accesible públicamente.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

## Modo de carga mejorada

Cuando la carga normal no puede manejar el audio que posee o tiene autorización para usar, se puede establecer `mode` como `enhanced`. Este modo también debe proporcionar un `name` de 1 a 100 caracteres y usar un `audio_url` HTTPS accesible públicamente.

La carga mejorada utiliza procesamiento asíncrono fijo, que generalmente requiere 2 minutos o más. El procesamiento exitoso consume **1.87 Créditos**, lo que equivale a aproximadamente **¥1.20/vez**; el procesamiento fallido no incurre en costos.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

La interfaz devolverá inmediatamente `task_id` y `trace_id`. Utilice la [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) para consultar la tarea, y una vez que sea exitosa, lea el ID de audio subido desde `response.data.audio_id`. También se puede proporcionar un `callback_url` HTTPS para recibir el estado final.

El `audio_id` obtenido de la carga mejorada se puede utilizar para Cover, Samples y Mashup. La extracción de acompañamiento y MIDI, separación de pistas completas y separación de voz/acompañamiento aún pueden estar sujetas a restricciones de la cuenta a la que pertenece el audio; las operaciones no listadas no garantizan soporte para uso entre cuentas. Cuanto más corto sea el audio, mayor será la tasa de éxito del procesamiento.
