SUNO nos permite cargar audio de referencia para la creación secundaria; este documento explica el método de integración de la API relacionada.

La carga normal solo requiere `audio_url`, que es una dirección CDN de audio accesible públicamente. `mode` es `standard` por defecto, por lo tanto no es necesario modificar las llamadas existentes. Una carga normal exitosa consume **0.06 Credits**; las cargas fallidas no tienen costo.

Aquí, el `audio_url` que ingresamos es `https://cdn.acedata.cloud/suno_demo.mp3`, una dirección CDN accesible públicamente.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Se puede ver que `data` siempre es un objeto y `audio_id` es el ID de la canción después de la carga. Los resultados de análisis, como `lyric`, `style`, `duration`, el título y las URL de medios, son campos opcionales; los detalles dependen del contenido devuelto.

Después de obtener el ID de la canción, puede llamar a operaciones que requieren `audio_id`, como `upload_extend`, `upload_cover` o muestreo por intervalo, a través de la [API de generación de audios de Suno](https://platform.acedata.cloud/documents/suno-audios). Si desea utilizar la función de creación por inspiración Inspo para crear música nueva basándose en 1 a 4 segmentos completos de audio de referencia, llame directamente a `action=inspo` y pase la lista original de URL de audio públicas; el servicio completará automáticamente la carga y el análisis, sin necesidad de que el cliente ensamble los metadatos del audio.

## Modo de carga mejorada

> `audio_url` es la dirección de entrada y se entregará directamente al flujo de procesamiento de audio; el servicio de persistencia de medios en estado final no realizará una transferencia previa. Asegúrese de que sea accesible públicamente durante el procesamiento de la tarea.

Cuando la carga normal no pueda procesar audio que usted posee o está autorizado a utilizar, puede establecer `mode` en `enhanced`. Este modo también debe proporcionar un `name` de 1 a 100 caracteres y utilizar una `audio_url` HTTPS accesible públicamente.

La carga mejorada utiliza procesamiento asíncrono de forma fija y normalmente requiere 2 minutos o más. Un procesamiento exitoso consume **1.87 Credits**; los procesamientos fallidos no tienen costo.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

La interfaz devolverá inmediatamente `task_id` y `trace_id`. Use la [API de tareas de Suno](https://platform.acedata.cloud/documents/suno-tasks) para consultar la tarea y, tras el éxito, lea el ID del audio cargado desde `response.data.audio_id`. También puede proporcionar una `callback_url` HTTPS para recibir el estado final.

El `audio_id` obtenido mediante la carga mejorada puede utilizarse para Cover, Samples y Mashup. La extracción de acompañamiento y MIDI, la separación de todas las pistas y la separación de voz/acompañamiento aún pueden estar sujetas a restricciones de la cuenta propietaria del audio; no se garantiza la compatibilidad de uso entre cuentas para las operaciones no enumeradas. Cuanto más corto sea el audio, mayor suele ser la tasa de éxito del procesamiento.
