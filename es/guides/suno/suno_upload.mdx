SUNO nos permite cargar audio de referencia para creación secundaria, este documento explica el método de integración de las API relacionadas.

La carga normal solo requiere `audio_url`, que es una dirección de CDN de audio accesible públicamente. `mode` tiene como valor predeterminado `standard`, por lo tanto, las llamadas existentes no necesitan modificarse. Una carga normal exitosa consume **0.06 Credits**; las cargas fallidas no generan cargos.

Aquí, el `audio_url` que ingresamos es `https://cdn.acedata.cloud/suno_demo.mp3`, que es una dirección de CDN accesible públicamente.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Se puede ver que `data` siempre es un objeto, y `audio_id` es el ID de la canción después de la carga. Los resultados de análisis, como `lyric`, `style`, `duration`, el título y las URL de medios, son campos opcionales; los detalles dependen del contenido devuelto.

Después de obtener el ID de la canción, puede usar [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) para invocar operaciones como `upload_extend`, `upload_cover` o muestreo por intervalos que requieren `audio_id`. Si desea crear música nueva basándose en 1 a 4 segmentos completos de audio de referencia mediante la función de creación de inspiración Inspo, invoque directamente `action=inspo` y proporcione la lista original de URL de audio públicas; el servicio completará automáticamente la carga y el análisis, sin necesidad de que el cliente ensamble los metadatos de audio.

## Modo de carga mejorada

> `audio_url` es la dirección de entrada y se entregará directamente al flujo de procesamiento de audio; no será transferida previamente por el servicio de persistencia de medios en estado final. Asegúrese de que pueda accederse públicamente a ella durante el procesamiento de la tarea.

Cuando la carga normal no puede procesar audio que usted posee o para el cual ha obtenido autorización de uso, puede establecer `mode` en `enhanced`. Este modo también debe proporcionar un `name` de 1 a 100 caracteres y utilizar un HTTPS `audio_url` accesible públicamente.

La carga mejorada adopta obligatoriamente el procesamiento asíncrono y normalmente requiere 2 minutos o más. El procesamiento exitoso consume **1.87 Credits**; los procesamientos fallidos no generan cargos.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

La interfaz devolverá inmediatamente `task_id` y `trace_id`. Use [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) para consultar la tarea y, tras el éxito, lea el ID de audio cargado desde `response.data.audio_id`. También puede proporcionar un HTTPS `callback_url` para recibir el estado final.

El `audio_id` obtenido mediante la carga mejorada puede usarse para Cover, Samples y Mashup. La extracción de acompañamiento y MIDI, la separación de todas las pistas y la separación de voz/acomañamiento aún pueden estar sujetas a restricciones de la cuenta a la que pertenece el audio; no se garantiza que las operaciones no enumeradas sean compatibles para uso entre cuentas. Cuanto más corto sea el audio, normalmente mayor será la tasa de éxito del procesamiento.
