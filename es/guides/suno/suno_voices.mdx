---
title: "Guía de integración de la API de clonación de voz de Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO nos permite crear personajes de voz personalizados mediante cualquier archivo de audio, implementando la clonación de voz para la generación de música. A diferencia de la API Persona existente (que utiliza el `audio_id` generado por Suno), esta API acepta un `audio_url` públicamente accesible, es decir, tu propia grabación de voz. Este documento explica el método de integración de la API de clonación de voz.

## Paso 1: Crear un personaje de voz

Esta API tiene tres parámetros de entrada: `audio_url` (obligatorio), una URL de archivo de audio en formato MP3 o WAV públicamente accesible que contiene una voz humana clara de una sola persona; `name` y `description` (opcionales), el nombre y la descripción del personaje de voz.

> **Requisitos del archivo de audio**
> - El formato de audio debe ser `WAV` o `MP3`
> - La duración del audio debe estar entre `10~240 segundos`; se recomienda utilizar material de voz seca limpio de una sola persona de `30~60 segundos`
> - El audio debe contener una **voz clara y reconocible de una sola persona hablando o cantando**
> - Asegúrate de evitar **ruido de fondo, acompañamiento, eco, reverberación**; las canciones completas con acompañamiento normalmente no pueden superar la validación de huella vocal
> - No incluyas **varios hablantes** o **múltiples voces**
> - El material con volumen demasiado bajo, voz poco clara o ruido excesivo puede provocar **fallos de clonación** o **resultados de generación deficientes**
> **Descripción de las restricciones de uso**
> - Los personajes de voz creados mediante la carga de audio son **recursos privados**
> - Este personaje de voz **no admite reutilización entre cuentas**
> - Se recomienda utilizarlo lo antes posible después de crearlo correctamente; si no se utiliza durante mucho tiempo, puede **caducar o dejar de estar disponible**
> - El `name` devuelto es generado automáticamente por el sistema; toma como referencia el `persona_id` devuelto

> **Vuelve a intentarlo primero cuando falle la llamada**
> La clonación de voz es una tarea intensiva en computación; incluso si el material cumple completamente con las normas, existe cierta probabilidad de fallos ocasionales, con respuestas comunes como
> `voices_sound_different` (la validación de huella vocal no se superó), etc. **Este tipo de fallo no está relacionado con la calidad del audio; volver a intentarlo con el mismo material normalmente puede tener éxito**,
> se recomienda implementar 1~2 reintentos automáticos para los resultados fallidos durante la integración. Las solicitudes fallidas no se cobran.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> El anterior `https://cdn.acedata.cloud/suno_demo.mp3` es material de ejemplo que puede invocarse directamente (MP3, 41 segundos, voz seca de una sola persona).
> Si necesitas un ejemplo en formato `WAV`, puedes utilizar
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 segundos, mono 44.1kHz).

El resultado es el siguiente:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Se puede ver que el campo `persona_id` de `data` es el ID del personaje de voz creado. El campo `is_public` siempre es `false`, porque los personajes de voz creados mediante la carga de audio son privados. Ten en cuenta que el `name` devuelto es generado automáticamente por el sistema; posteriormente utiliza `persona_id` para referenciar este personaje de voz.

## Paso 2: Usar el personaje de voz para generar música

Después de tener el ID del personaje de voz, podemos utilizar la [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) para generar música. Establece `action` como `generate` y establece `persona_id` como el ID del personaje de voz devuelto anteriormente; las canciones generadas utilizarán la voz clonada para cantar.

> **Nota:** La clonación de voz solo admite modelos `chirp-v4-5` y superiores (como `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), y no admite `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

El resultado es el siguiente:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

Se puede ver que la canción generada utiliza la voz clonada para cantar. `persona_id` también se puede utilizar junto con la acción `cover` para versionar canciones existentes con la voz clonada.
