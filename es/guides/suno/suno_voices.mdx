---
title: "Instrucciones de integración de la API de clonación de voz de Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO nos permite crear personajes de voz personalizados a través de cualquier archivo de audio, implementando la clonación de voz para la generación de música. A diferencia de la API Persona existente (que utiliza el `audio_id` generado por Suno), esta API acepta un `audio_url` de acceso público, es decir, tu propia grabación vocal. Este documento explica cómo integrar la API de clonación de voz.

## Paso 1: Crear un personaje de voz

Esta API tiene tres parámetros de entrada: `audio_url` (obligatorio), que es la URL de un archivo de audio MP3 o WAV de acceso público que contiene una voz humana clara de una sola persona; `name` y `description` (opcionales), que son el nombre y la descripción del personaje de voz.

> **Requisitos del archivo de audio**
> - El formato de audio debe ser `WAV` o `MP3`
> - La duración del audio debe estar entre `10~240 segundos`; se recomienda utilizar material vocal limpio y seco de una sola persona de `30~60 segundos`
> - El audio debe contener una **voz clara e identificable de una sola persona hablando o cantando**
> - Asegúrate de evitar **ruido de fondo, acompañamiento, eco y reverberación**; las canciones completas con acompañamiento normalmente no pueden pasar la verificación de huella vocal
> - No debe incluir **varios hablantes** ni **múltiples voces**
> - El material con volumen demasiado bajo, voz poco clara o ruido excesivo puede causar un **fallo de clonación** o **resultados de generación deficientes**
> **Descripción de las restricciones de uso**
> - Los personajes de voz creados mediante la carga de audio son **recursos privados**
> - Este personaje de voz **no admite reutilización entre cuentas**
> - Se recomienda utilizarlo lo antes posible después de crearlo correctamente; si no se utiliza durante mucho tiempo, podría **caducar o quedar no disponible**
> - El `name` devuelto es generado automáticamente por el sistema; utiliza el `persona_id` devuelto como referencia

> **Vuelve a intentarlo primero cuando falle la llamada**
> La clonación de voz es una tarea intensiva en capacidad de cómputo; incluso si el material cumple completamente los requisitos, existe cierta probabilidad de fallos ocasionales, con respuestas comunes como
> `voices_sound_different` (la verificación de huella vocal no se superó), entre otras. **Este tipo de fallo no está relacionado con la calidad del audio; volver a intentarlo con el mismo material normalmente permite completar la operación correctamente**,
> se recomienda implementar 1~2 reintentos automáticos para los resultados fallidos durante la integración. Las solicitudes fallidas no se cobran.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> El `https://cdn.acedata.cloud/suno_demo.mp3` anterior es material de ejemplo que se puede invocar directamente (MP3, 41 segundos, voz seca de una sola persona).
> Si necesitas un ejemplo en formato `WAV`, puedes utilizar
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 segundos, mono 44.1kHz).

El resultado es el siguiente:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Como se puede ver, el campo `persona_id` de `data` es el ID del personaje de voz creado. El campo `is_public` siempre es `false`, porque los personajes de voz creados mediante la carga de audio son privados. Ten en cuenta que el `name` devuelto es generado automáticamente por el sistema; utiliza posteriormente `persona_id` para hacer referencia a este personaje de voz.

## Paso 2: Usar el personaje de voz para generar música

Después de tener el ID del personaje de voz, podemos utilizar la [API de generación de audios de Suno](https://platform.acedata.cloud/documents/suno-audios) para generar música. Establece `action` en `generate` y `persona_id` en el ID del personaje de voz devuelto anteriormente; las canciones generadas utilizarán la voz clonada para cantar.

> **Nota:** La clonación de voz solo admite los modelos `chirp-v4-5` y superiores (como `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`); no admite `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

El resultado es el siguiente:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` puede utilizarse para la generación mediante `generate`, y también para versiones mediante `cover` / `upload_cover`. No es necesario completar `vocal_gender` al especificar una voz; la similitud de voz seguirá dependiendo del material de referencia y del resultado generado.

Las voces creadas mediante esta interfaz son recursos privados. Antes de versionar una canción existente, llama primero a `/suno/upload`, pasando el `audio_url` de la canción original y el `persona_id` de esta voz; después de que la carga se realice correctamente, llama a `/suno/audios` con el `data.audio_id` devuelto y el mismo `persona_id`:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

La creación de voz, la carga de la canción original y la versión deben utilizar el mismo canal de servicio. No reutilices directamente IDs de canciones que no se hayan asociado previamente con esta voz privada; consulta los detalles en [Suno: cargar audio de referencia](https://platform.acedata.cloud/documents/suno-upload).
