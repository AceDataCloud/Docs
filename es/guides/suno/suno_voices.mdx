SUNO nos permite crear personajes de voz personalizados a partir de cualquier archivo de audio, logrando la clonación de voz para la generación musical. A diferencia de la API Persona existente (que utiliza `audio_id` generado por Suno), esta API acepta un `audio_url` accesible públicamente, es decir, una grabación de voz propia. Este documento explica cómo integrar la API de clonación de voz.

## Paso 1: Crear un personaje de voz

Esta API tiene tres parámetros de entrada: `audio_url` (obligatorio), que es una URL accesible públicamente a un archivo de audio en formato MP3 o WAV que contenga voz clara de una sola persona; `name` y `description` (opcionales), que son el nombre y la descripción del personaje de voz.

**Requisitos del archivo de audio:**
- Formato: MP3 o WAV
- Duración: al menos 10 segundos
- Contenido: voz clara de una sola persona, con el menor ruido de fondo o música posible

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

El resultado es el siguiente:

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

Como se puede ver, el campo `persona_id` dentro de `data` es el ID del personaje de voz creado. El campo `is_public` siempre es `false`, porque los personajes de voz creados mediante la carga de audio son privados.

## Paso 2: Generar música usando el personaje de voz

Con el ID del personaje de voz, podemos usar la [API de generación de audios de Suno](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) para generar música. Establece `action` en `generate` y asigna `persona_id` al ID del personaje de voz obtenido anteriormente; la canción generada usará la voz clonada para la interpretación.

> **Nota:** La clonación de voz solo es compatible con modelos `chirp-v4-5` y superiores (como `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), no es compatible con `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

El resultado es el siguiente:

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

Como se observa, la canción generada utiliza la voz clonada para la interpretación. El `persona_id` también puede usarse junto con la acción `cover` para hacer covers de canciones existentes con la voz clonada.
