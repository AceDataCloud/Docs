title: "Suno API de clonación de voz - Instrucciones de integración"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

SUNO nos permite crear personajes de voz personalizados a partir de cualquier archivo de audio, logrando la clonación de voz para la generación musical. A diferencia de la API Persona existente (que utiliza el `audio_id` generado por Suno), esta API acepta una `audio_url` de acceso público, es decir, tu propia grabación de voz. Este documento explica cómo integrar la API de clonación de voz.

La API tiene tres parámetros de entrada: `audio_url` (obligatorio), que es una URL de un archivo de audio en formato MP3 o WAV accesible públicamente, que contenga una voz humana clara de una sola persona; `name` y `description` (opcionales), que son el nombre y la descripción del personaje de voz.

**Requisitos del archivo de audio:**

- Formato: MP3 o WAV
- Duración: al menos 10 segundos
- Contenido: voz humana clara de una sola persona, minimizando el ruido de fondo o la música

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://example.com/my-vocal-recording.mp3",
  "name": "My Voice",
  "description": "A warm male voice"
}'
```

El resultado es el siguiente:

```json
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dde0be60-5280-4bd2-89a0-4020ddd3db52",
    "name": "My Voice",
    "is_public": false
  }
}
```

Como se puede ver, el campo `persona_id` de `data` es el ID del personaje de voz creado. El campo `is_public` siempre es `false`, ya que los personajes de voz creados mediante la carga de audio son privados.

Una vez que tengamos el ID del personaje de voz, podemos utilizar la [API de Generación de Audios de Suno](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) para la generación musical. Establecer `action` como `vox` y `persona_id` con el valor devuelto anteriormente, la canción generada será interpretada con la voz clonada.
