Si deseas personalizar la generación de canciones, pero no quieres escribir las letras tú mismo, puedes utilizar la API de generación de letras proporcionada por AceDataCloud para generar letras a través de un prompt. La API es [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

El principal parámetro de entrada de esta API es `prompt`, y el `model` es opcional (por defecto chirp-v3), un ejemplo de cómo llenarlo es el siguiente:

![](https://cdn.acedata.cloud/p53wtj.png)

Aquí, el `prompt` que ingresamos es `A song about winter`, generando una canción relacionada con el invierno.

Haz clic en ejecutar, y el resultado es el siguiente:

```
{
  "success": true,
  "task_id": "57e8ce3a-39cb-41a2-802f-e70a324f4d0a",
  "data": {
    "text": "[Verse]\nCae nieve del cielo\nEl frío toque del invierno\nOh, cómo me eleva\nMe envuelvo en capas\nOh, tan acogedor\nSaliendo y sintiendo la escarcha en mi nariz\nVer\n\n[Verse 2]\nEl mundo está cubierto con una manta blanca\nCarámbanos colgando\nBrillando tan intensamente\nEl aire frío llena mis pulmones con cada respiración\nCaminando en la nieve\nDejando huellas que no se borrarán\n\n[Chorus]\nOh\nEl frío toque del invierno\nEs una temporada que amo tanto\nLa nevada trae una sensación tan divina\nEl frío toque del invierno\nEs un tiempo mágico",
    "title": "El Frío Toque del Invierno",
    "status": "complete"
  }
}
```

Se puede ver que el campo `text` de `data` es la información de la letra.

Una vez que tenemos la letra, podemos utilizar la [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) para generar canciones personalizadas.
