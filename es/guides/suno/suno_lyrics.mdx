---

Si deseas personalizar la generación de canciones, pero no quieres escribir las letras tú mismo, puedes utilizar la API de generación de letras proporcionada por AceDataCloud para generar letras a través de un prompt. La API es [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

El principal parámetro de entrada de esta API es `prompt`, y `model` (opcional, con valores posibles `default`, `remi-v1`, siendo `default` el valor por defecto). Un ejemplo de cómo llenarlo es el siguiente:

![](https://cdn.acedata.cloud/p53wtj.png)

Aquí, el `prompt` que ingresamos es `A song about winter`, generando una canción relacionada con el invierno.

Haz clic en ejecutar, y el resultado es el siguiente:

```json

  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nCae nieve del cielo\nEl frío toque del invierno\nOh, cómo me eleva\nMe envuelvo en capas\nOh, tan acogedor\nSaliendo y sintiendo la escarcha en mi nariz\n\n[Chorus]\nOh\nEl frío toque del invierno\nEs una temporada que amo tanto\nLa nevada trae una sensación tan divina\nEl frío toque del invierno\nEs un tiempo mágico",
      "title": "El Frío Toque del Invierno",
      "status": "complete",
      "tags": ["soñador, suave, balada"]
    },
    {
      "text": "[Verse]\nEl mundo está cubierto con una manta blanca\nCarámbanos colgando\nBrillando tan intensamente\nEl aire frío llena mis pulmones con cada respiración\nCaminando en la nieve\nDejando huellas atrás\n\n[Chorus]\nPaís de maravillas invernales\nTodo es tan brillante\nPaís de maravillas invernales\nAbrázame durante la noche",

  "started_at": 1780684179.15,

```

Como se puede ver, `data` es un array que devuelve múltiples candidatos de letras cada vez, donde el campo `text` de cada elemento es el contenido de la letra, `title` es el título, y `tags` son las etiquetas de estilo recomendadas.

Una vez que tengamos las letras, podemos utilizar la [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) para generar canciones personalizadas.
