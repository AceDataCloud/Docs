La principal función de la API de Suno Tasks es consultar el estado de ejecución de las tareas generadas mediante la API de Suno Audios Generation o la API de Suno Lyrics Generation a través de la ID de tarea ingresada.

Este documento detallará las instrucciones de integración de la API de Suno Tasks, ayudándole a integrar fácilmente y aprovechar al máximo las potentes funciones de esta API. A través de la API de Suno Tasks, puede consultar fácilmente el estado de ejecución de las tareas de la API de Suno Lyrics Generation o de la API de Suno Audios Generation.

## Proceso de solicitud

Para utilizar la API de Suno Tasks, primero debe ir a la página de solicitud [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) para solicitar el servicio correspondiente, y luego copiar la ID de tarea de la API de Suno Audios Generation, como se muestra en la imagen:

<p><img src="https://cdn.acedata.cloud/bc6754.png" width="500" class="m-auto"></p>

Finalmente, acceda a la página de la API de Tasks [Suno Tasks API](https://platform.acedata.cloud/documents/b0dd9823-0e01-4c75-af83-5a6e2e05bfed) para solicitar el servicio correspondiente. Una vez en la página, haga clic en el botón "Acquire", como se muestra en la imagen:

![Página de solicitud](https://cdn.acedata.cloud/rci31i.png)

Si aún no ha iniciado sesión o registrado, será redirigido automáticamente a la [página de inicio de sesión](https://platform.acedata.cloud) que le invita a registrarse e iniciar sesión. Después de iniciar sesión o registrarse, será redirigido automáticamente a la página actual.

En la primera solicitud, se otorgará un crédito gratuito que le permitirá utilizar esta API de forma gratuita.

## Ejemplo de solicitud

La API de Suno Tasks se puede utilizar para consultar los resultados de las API de Suno Audios Generation y Suno Lyrics Generation. Para saber cómo utilizar la API de Suno Audios Generation, consulte el documento [Suno Audios Generation API](https://platform.acedata.cloud/documents/d016ee3f-421b-4b6e-989a-8beba8701701). Para saber cómo utilizar la API de Suno Lyrics Generation, consulte [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/f1c66741-a488-43ca-91fc-e53fbbda639a).

Tomaremos como ejemplo una ID de tarea devuelta por el servicio de la API de Suno Audios Generation, para demostrar cómo utilizar esta API. Supongamos que tenemos una ID de tarea: eae26f89-b64b-404d-a80c-761996660b1c, a continuación, demostraremos cómo pasar una ID de tarea.

### Configuración de encabezados de solicitud y cuerpo de solicitud

**Request Headers** incluye:

- `accept`: especifica que se aceptan respuestas en formato JSON, aquí se debe ingresar `application/json`.
- `authorization`: la clave para llamar a la API, que se puede seleccionar directamente después de la solicitud.

**Request Body** incluye:

- `id`: la ID de tarea cargada.
- `action`: el método de operación sobre la tarea.

Algunos ejemplos de código son los siguientes:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/suno/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "eae26f89-b64b-404d-a80c-761996660b1c",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "eae26f89-b64b-404d-a80c-761996660b1c",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
```

## Manejo de errores

Al llamar a la API, si se encuentra con un error, la API devolverá el código de error correspondiente y la información. Por ejemplo:

- `400 token_mismatched`: Solicitud incorrecta, posiblemente debido a parámetros faltantes o inválidos.
- `400 api_not_implemented`: Solicitud incorrecta, posiblemente debido a parámetros faltantes o inválidos.
- `401 invalid_token`: No autorizado, token de autorización inválido o faltante.
- `429 too_many_requests`: Demasiadas solicitudes, has superado el límite de tasa.
- `500 api_error`: Error interno del servidor, algo salió mal en el servidor.
