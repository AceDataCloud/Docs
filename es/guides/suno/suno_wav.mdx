SUNO nos permite obtener archivos de música en formato wav. Este documento explica cómo integrar la API relacionada.

El parámetro de entrada principal de esta API es `audio_id`, que es el ID de la canción generado oficialmente; opcionalmente también se admite `callback_url` como dirección de callback asíncrono.

Aquí, el `audio_id` que ingresamos es `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer YOUR_API_KEY",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

El resultado es el siguiente:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://cdn.acedata.cloud/e724d7f13d.png?example=image-001"
    }
  ]
}
```

Como se puede ver, el campo `file_url` de `data` es el archivo de música en formato wav que se ha obtenido, es una dirección CDN accesible públicamente.

> **Sobre la persistencia del enlace WAV**
> La plataforma priorizará la persistencia del archivo WAV en su estado final en el CDN de Ace Data Cloud antes de devolver la respuesta. La URL anterior solo muestra el formato de respuesta y no representa un objeto real que exista a largo plazo. Solo si la persistencia en el CDN no se ha completado y la dirección del medio original se puede descargar a un archivo WAV válido tras una verificación inmediata, `file_url` podría mantener esa dirección; si la dirección ha caducado o la verificación del archivo ha fallado, la solicitud devolverá un error o un tiempo de espera, y no se considerará una dirección no descargable como un resultado exitoso. Por favor, descargue y guarde adecuadamente después de que la tarea se complete, el período de retención específico dependerá de la política de almacenamiento actual de la plataforma.
