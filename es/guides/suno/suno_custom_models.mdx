---
title: "Guía de integración de modelos de música personalizados de Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Los modelos de música personalizados pueden aprender características musicales consistentes a partir de 6 a 24 audios autorizados, y utilizarse para la creación posterior de canciones. La creación es una operación asíncrona; se recomienda utilizar 24 audios con un estilo consistente y una calidad de sonido clara para obtener resultados más estables.

> Solo puede enviar audios sobre los que posea derechos legítimos de uso, o para los que haya obtenido autorización para la creación del modelo y la generación posterior. No cargue música ni materiales de sonido sin autorización.

## Crear un modelo

Llame a `POST /suno/custom-models` y establezca `action=create`:

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

La interfaz devuelve inmediatamente el ID del modelo de la plataforma y el ID de la tarea. Una vez completada la creación, el `status` en la devolución de llamada o en el resultado de la consulta cambiará a `ready`. Solo se cobrarán **10 Credits** si el modelo se crea correctamente; si la creación falla, no se realizará ningún cargo.

## Consultar modelos

Consultar un único modelo:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Consultar de forma paginada los modelos de la aplicación actual:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Todos los modelos pertenecen a la aplicación de Suno que los creó. La rotación de credenciales de la API no cambia la pertenencia del modelo, y otras aplicaciones no pueden consultar ni utilizar el modelo.

## Usar el modelo para generar canciones

Cuando el estado del modelo sea `ready`, continúe llamando a `POST /suno/custom-models` y establezca `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

El `id` debe ser un modelo de música personalizado con estado `ready` dentro de la aplicación actual. La solicitud fallará si el modelo no está disponible y no se cambiará automáticamente a otro modelo. `persona_id` es mutuamente excluyente con los modelos de música personalizados; si se envían simultáneamente, la interfaz devolverá HTTP 400 antes de que la solicitud se envíe al servicio de generación, y no se realizará ningún cargo. Si necesita utilizar Persona, use en su lugar las operaciones `artist_consistency` o `artist_consistency_vox` de `/suno/audios`.

La generación exitosa de una canción consume **0.90 Credits**; si la generación falla, no se realizará ningún cargo. Consultar y archivar modelos es gratuito.

## Archivar modelos

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

La versión Beta actual archivará el modelo e impedirá que continúe utilizándose; `capacity_released=false` en la respuesta indica que el archivado no garantiza la liberación de la capacidad del modelo. La operación de archivado puede llamarse repetidamente y no se cobrará más de una vez.
