---
title: "Guía de acceso al modelo de música exclusivo de Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

El modelo de música exclusivo puede aprender características musicales consistentes a partir de 6 a 24 audios autorizados y ser utilizado para la creación de canciones posteriores. La creación es una operación asíncrona; se recomienda utilizar 24 audios de estilo consistente y calidad de sonido clara para obtener un efecto más estable.

> Solo se pueden enviar audios de los que tenga derechos de uso legal, o que haya obtenido autorización para la creación del modelo y la generación posterior. No suba música o material de sonido sin licencia.

## Crear modelo

Llamar a `POST /suno/custom-models` y establecer `action=create`:

```json
{
  "action": "create",
  "name": "Mi Modelo Indie",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

La interfaz devuelve inmediatamente el ID del modelo de la plataforma y el ID de la tarea. Una vez completada la creación, el `status` en la respuesta o consulta cambiará a `ready`. Solo se cobrará **10 Créditos** si la creación del modelo es exitosa; si falla, no se cobrará.

## Consultar modelo

Consultar un modelo individual:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Consulta paginada de los modelos actuales de la aplicación:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Todos los modelos pertenecen a la aplicación Suno que los creó. La rotación de credenciales de API no cambiará la pertenencia del modelo, y otras aplicaciones no pueden consultar o usar ese modelo.

## Usar modelo para generar canciones

Una vez que el estado del modelo sea `ready`, continúe llamando a `POST /suno/custom-models` y establezca `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Lluvia Neón",
  "lyric": "[Verso]\nLas luces de la ciudad caen a través de la lluvia",
  "style": "indie rock, sintetizador analógico cálido"
}
```

El `id` debe ser el modelo de música exclusivo con estado `ready` bajo la aplicación actual. Si el modelo no está disponible, la solicitud fallará y no se cambiará automáticamente a otro modelo. La generación de la canción exitosa consume **0.90 Créditos**; si la generación falla, no se cobrará. Consultar y archivar modelos es gratuito.

## Archivar modelo

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

La versión Beta actual archivará el modelo y prohibirá su uso posterior, la respuesta con `capacity_released=false` indica que el archivo no garantiza la liberación de la capacidad del modelo. La operación de archivo se puede llamar repetidamente y no se cobrará de nuevo.
