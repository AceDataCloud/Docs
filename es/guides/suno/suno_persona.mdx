---
title: "Instrucciones de integración de la API de estilo de cantante personalizado de Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO nos permite establecer un estilo de cantante para canciones ya generadas y luego realizar una creación secundaria basada en él. Este documento explica el método de integración de las API relacionadas.

La consulta de lista con `GET /suno/persona` y la eliminación de registros con `DELETE /suno/persona` no tienen costo, y no requieren encabezados adicionales de solicitud sin costo. La operación de creación con `POST /suno/persona` sigue cobrando según las reglas de precios de la API.

En las rutas de creación que admiten consulta de timbre de voz, se puede usar la aplicación original y la identidad del llamador para pasar el `persona_id` de los resultados de creación a `POST /suno/availability`. Cuando se confirma que está disponible, devuelve `data.available=true`. [Guía de consulta de disponibilidad de timbre de voz](https://platform.acedata.cloud/documents/suno-availability-integration)

Esta API solo tiene tres parámetros de entrada: primero, `audio_id`, que es un ID de canción ya generada correctamente en la plataforma oficial; luego, `name` y `description`, que son un nombre y una descripción de un estilo de cantante.

El `audio_id` que introducimos aquí es `https://cdn.acedata.cloud/2qhzs3.png`; esto puede consultarse en [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) para realizar una generación de canción personalizada, y finalmente se puede obtener `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

El resultado es el siguiente:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Se puede ver que el campo `persona_id` de `data` es el ID del estilo de cantante generado.

Después de tener el ID del estilo de cantante, podemos usar [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) para realizar una generación de canción personalizada; por ejemplo, pasar `artist_consistency` en `action`, al mismo tiempo pasar el ID de la canción subida en `audio_id`, y también es necesario subir el parámetro `persona_id`; este valor es el ID del estilo de cantante devuelto anteriormente, y así se pueden generar nuevas canciones según el estilo de cantante de referencia.
