---
title: "Instrucciones de integración de la API de URL MP3 de Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

La API de URL MP3 de Suno genera una ruta para una música existente que termina en `.mp3`, adecuada para escenarios donde los enlaces de descarga antiguos han fallado, la reproducción en dispositivos móviles es necesaria o se requiere volver a obtener una URL de audio pública.

El parámetro obligatorio `audio_id` es el ID de audio devuelto por la interfaz de generación de audio de Suno. Cada llamada creará una tarea de URL MP3 independiente, no modificará la tarea de generación de música original ni cambiará el ID de audio original.

## Llamada sincrónica

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={
        "accept": "application/json",
        "authorization": "Bearer <YOUR_API_TOKEN>",
        "content-type": "application/json"
    },
    json={"audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f"},
    timeout=240
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["file_url"])
```

En caso de éxito, `data[0].file_url` es la dirección de audio reproducible. La interfaz priorizará el almacenamiento en `https://cdn.acedata.cloud/suno/{audio_id}.mp3`; si la persistencia falla, devolverá la dirección del medio original actualmente disponible.

## Llamada asincrónica

Cuando el tiempo de procesamiento es largo, se puede pasar `async: true`:

```python
submission = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={"authorization": "Bearer <YOUR_API_TOKEN>"},
    json={
        "audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f",
        "async": True
    }
).json()

export_task_id = submission["task_id"]
```

Luego, se puede consultar `export_task_id` a través de `/suno/tasks`. También se puede proporcionar `callback_url` para recibir el resultado final una vez que la tarea esté completa. La respuesta sincrónica, la consulta de tareas y la devolución de llamada utilizan la misma estructura de datos de estado final.

## Consideraciones

- `audio_id` debe provenir de un audio de Suno reconocible.
- Las tareas de URL MP3 son independientes de las tareas de generación de música original.
- La falla en la persistencia no bloqueará el resultado, retrocederá a la dirección del medio original; por favor, descárguelo a tiempo.
- Se recomienda que el lado del negocio descargue los resultados a tiempo y los guarde según su propia política de retención de datos.
