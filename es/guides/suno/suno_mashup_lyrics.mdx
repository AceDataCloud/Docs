title: "Instrucciones para la integración de la API de generación de letras de mezcla de Suno"

---

Si deseas utilizar las letras de dos canciones para generar una canción mezclada, puedes usar esta API para generar las letras correspondientes. La API es [Suno MashupLyrics Generation API](https://platform.acedata.cloud/documents/suno-mashup-lyrics).

Los principales parámetros de entrada de esta API son `lyrics_a` y `lyrics_b`, un ejemplo de cómo llenarlos se muestra a continuación:

![](https://cdn.acedata.cloud/g9n3t6.png)

Haz clic en ejecutar, el resultado es el siguiente:

```
{
  "success": true,
  "task_id": "80aa3cd3-ca87-4ca3-82d2-1830e3d8f53a",
  "data": {
    "text": "Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nSambuy come, Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \nSambuy come back",
    "title": "Letras de Mezcla",
    "tags": [],
    "status": "complete"
  }
}
```

Como se puede ver, el campo `text` de `data` es la información de la letra.

Una vez que tengamos la letra, podemos usar la [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) para generar canciones personalizadas.
