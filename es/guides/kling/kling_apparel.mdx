---
title: "Guía de integración para la recreación de videos de indumentaria"

---

Envía tareas mediante `POST /kling/apparel` y utiliza el existente `POST /kling/tasks` para consultar el estado de las tareas de la plataforma.

## Entrada

Proporciona una descripción del producto de hasta 2500 caracteres, un video de referencia de 5–180 segundos y 1–5 imágenes del producto. También se pueden proporcionar 1–5 imágenes de modelos, un archivo de música de fondo y especificar una voz de doblaje; si no se especifica una voz, se utiliza la locución original.

A continuación se muestra un ejemplo de la estructura de la solicitud; reemplaza las URL de los recursos antes de llamar.

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "你的商品或口播内容"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## Resultados y facturación

El modo síncrono devuelve el resultado generado; el modo asíncrono primero devuelve `task_id`, y el resultado completado incluye los enlaces de video o imagen en `data` y el `usage` calculado por el servidor. `callback_url` se utiliza para las notificaciones de finalización; las solicitudes con `watermark=true` devuelven simultáneamente una versión con marca de agua.

Locución original: 720p cuesta 1.82 Credits/segundo y 1080p cuesta 2.38 Credits/segundo; doblaje especificado: 720p cuesta 2.38 Credits/segundo y 1080p cuesta 2.8 Credits/segundo. Los videos se facturan según la duración real generada; el precio base por segundo antes de la generación no representa el precio total de toda la tarea. Las tareas fallidas no generan cargos de generación.
