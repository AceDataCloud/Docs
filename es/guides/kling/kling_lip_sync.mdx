---
title: "API de sincronización labial de Kling (Kling Lip Sync)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Permite que un **video existente de Kling** (5 segundos o 10 segundos) "hable" según un audio o texto, es decir, sincronización labial (Lip Sync). Combinado con `/kling/videos` y `image2video` (hacer que las fotos cobren vida), se puede formar un proceso completo de "**fotos que hablan / narración digital**".

> Esta interfaz es un envoltorio conveniente de un solo paso proporcionado por AceDataCloud, orientado a escenarios comunes impulsados por audio/texto; no es un espejo de campo de la interfaz de múltiples pasos oficial de Kling "reconocimiento facial → Sincronización labial avanzada". Por favor, consulte la tabla de parámetros de esta página.

- **Dirección de la interfaz**: `POST https://api.acedata.cloud/kling/lip-sync`
- **Formato de solicitud**: `application/json`
- **Formato de respuesta**: `application/json`
- **Facturación**: **2.45 Créditos** (fijo) por cada llamada exitosa

## Encabezados de solicitud (Request Headers)

| Campo              | Valor                   | Descripción                                           |
| ----------------- | --------------------- | -------------------------------------------------- |
| `authorization`   | `Bearer ${API_KEY}`   | Tu clave API, [dirección para obtenerla](https://platform.acedata.cloud) |
| `content-type`    | `application/json`    | Formato del cuerpo de la solicitud                      |
| `accept`          | `application/json`    | Formato de respuesta                                   |

## Parámetros de solicitud (Request Body)

| Parámetro         | Tipo      | Requerido | Predeterminado | Descripción                                                                                                               |
| ----------------- | ------- | -------- | ------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `mode`            | string  | Sí       | —             | Modo de generación. Enumeración: `audio2video` (impulsado por audio), `text2video` (impulsado por texto)             |
| `video_id`        | string  | Opcional | —             | ID del video generado por Kling (por ejemplo, el `video_id` devuelto por `image2video` de `/kling/videos`). **Solo se admiten videos de 5s/10s generados en los últimos 30 días**. `video_id` y `video_url` son opcionales, no se pueden enviar ambos al mismo tiempo |
| `video_url`       | string  | Opcional | —             | Enlace de video accesible públicamente. Restricciones: `.mp4`/`.mov`, ≤100MB, duración de 2–10s, solo 720p/1080p, dimensiones de 720–1920px. Opcional con `video_id`                                  |
| `audio_url`       | string  | Condicional | —             | URL de descarga del audio que impulsa, obligatorio cuando `audio2video` + `audio_type=url`. Formato `.mp3`/`.wav`/`.m4a`/`.aac`, ≤5MB                                     |
| `audio_type`      | string  | No       | `url`         | Método de transmisión de audio. Enumeración: `url`, `file` (efectivo cuando `audio2video`)                             |
| `audio_file`      | string  | Condicional | —             | Base64 del archivo de audio, obligatorio cuando `audio_type=file`. Formato como arriba, ≤5MB                           |
| `text`            | string  | Condicional | —             | Texto a leer, obligatorio cuando `text2video`, **máximo 120 caracteres**                                               |
| `voice_id`        | string  | Condicional | —             | ID de la voz, obligatorio cuando `text2video`                                                                          |
| `voice_language`  | string  | No       | `zh`          | Idioma de la voz. Enumeración: `zh`, `en` (efectivo cuando `text2video`)                                             |
| `voice_speed`     | float   | No       | `1.0`         | Velocidad del habla, rango `0.8`–`2.0`, con una decimal (efectivo cuando `text2video`)                                 |
| `callback_url`    | string  | No       | —             | Dirección de callback. Si se incluye este campo o `async=true`, se activa el **modo asíncrono**: devuelve inmediatamente `task_id`, y se llama de vuelta una vez que se genera el resultado |
| `async`           | boolean | No       | `false`       | Si es asíncrono. Si es `true`, devuelve inmediatamente `task_id`, junto con `/kling/tasks` para sondear o `callback_url` para callback |

## Ejemplo de solicitud

### 1) Impulsado por audio (audio2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2) Impulsado por texto (text2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "Hermano, ¡cuánto tiempo sin verte! Estoy bien, cuídate.",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## Ejemplo de respuesta (éxito sincrónico)

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| Campo          | Tipo      | Descripción                                   |
| -------------- | ------- | -------------------------------------------- |
| `success`      | boolean | Si fue exitoso                                 |
| `task_id`      | string  | ID de la tarea actual (puede usarse para consultar `/kling/tasks`) |
| `video_id`     | string  | ID de Kling del video generado (puede usarse como entrada para la próxima `extend`/`lip-sync`) |
| `video_url`    | string  | URL del video hablado generado (almacenado en el CDN de esta plataforma, válido a largo plazo) |
| `duration`     | string  | Duración del video (segundos)                  |
| `state`        | string  | Estado de la tarea: `succeed` / `failed`      |

## Modo asíncrono y consulta

Al pasar `callback_url` o `async: true`, la interfaz **devuelve inmediatamente** `task_id`; luego se puede:

- **Sondear**: `POST /kling/tasks`, cuerpo `{ "action": "retrieve", "id": "<task_id>" }` (gratis)
- **Callback**: Después de completar la generación, el resultado se envía a tu `callback_url`

## Proceso completo: fotos que hablan (image2video → lip-sync)
```bash
# Paso 1: Hacer que la foto cobre vida, obtener video_id
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"mirar a la cámara, natural","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# Paso 2: Sincronizar labios con audio
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"}'
# → { "video_url": "https://platform2.cdn.acedata.cloud/kling/....mp4", ... }
```

## Respuesta de error

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "se requiere uno de video_id o video_url" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | código                  | significado                                           |
| ---- | ----------------------- | --------------------------------------------------- |
| 400  | `bad_request`           | Parámetros faltantes o inválidos (como no enviar mode, conflicto entre video y audio, texto excede 120 caracteres) |
| 401  | `authorization_missing` | Falta o es inválida la clave API                     |
| 403  | `forbidden`             | Contenido bloqueado por control de riesgo            |
| 429  | `too_many_requests`     | Límite de concurrencia en el upstream, por favor intente más tarde |
| 500  | `api_error`             | Error en el upstream o interno                       |

## Consideraciones

- `video_id` debe ser un video de Kling generado en **los últimos 30 días**, y debe ser de **5s o 10s**; de lo contrario, use `video_url` para enviar un video que cumpla con las restricciones.
- Se recomienda que el video de entrada sea **claro, de frente, y de una sola persona**, para obtener el mejor efecto de sincronización de labios.
- La duración del audio/texto debe coincidir con la duración del video (el audio no debe exceder la longitud del video).
- La facturación ocurre en el momento de **éxito** (2.45 créditos por intento); la falla en la validación de parámetros (4xx) no incurre en costos.
