title: "Guía de integración de locución para comercio electrónico"

---

Envía una tarea mediante `POST /kling/video-commerce` y utiliza el `POST /kling/tasks` existente para consultar el estado de la tarea en la plataforma.

## Entrada

Sube una imagen de una persona y especifica `voice_id`, o utiliza un `avatar_id` preestablecido (ambos son mutuamente excluyentes; para las personas preestablecidas no se puede especificar adicionalmente `voice_id`). Debes proporcionar un `speech_script` de hasta 2000 caracteres. Al proporcionar información del producto, se requiere al menos una `ref_image` y un `goods_title`; la locución de productos no admite `speech_rate`. La locución de personas normales admite una velocidad de habla de 0.8, 1.0 o 1.2 veces.

A continuación se muestra un ejemplo de la estructura de la solicitud; reemplaza las URL de los recursos antes de realizar la llamada.

```json
{
  "contents": [
    {
      "type": "avatar_image",
      "url": "https://your-cdn.example/person.jpg"
    },
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    },
    {
      "type": "speech_script",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "voice_id": "male_calm_informative"
  },
  "async": true
}
```

## Resultados y facturación

El modo síncrono devuelve el resultado de la generación; el modo asíncrono primero devuelve `task_id`, y el resultado completado incluye en `data` los enlaces del video o imagen y el `usage` calculado por el servidor. `callback_url` se utiliza para las notificaciones de finalización; las solicitudes con `watermark=true` devuelven al mismo tiempo la versión con marca de agua.

Locución de personas normales: 720p cuesta 1.4 Credits/segundo y 1080p cuesta 1.68 Credits/segundo; locución de productos: 720p cuesta 1.96 Credits/segundo y 1080p cuesta 2.24 Credits/segundo. Los videos se facturan según la duración real generada; el precio base por segundo antes de la generación no representa el precio total de toda la tarea. Las tareas fallidas no generan cargos de generación.
