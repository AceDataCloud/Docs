---
title: "API de fotos parlantes de Kling (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Convierte con un solo clic **una foto + un audio** en un «video parlante». El servicio completa automáticamente dos pasos internamente: primero usa image2video para animar la foto y luego usa lip-sync para sincronizar los labios con el audio. Solo necesitas llamar **una vez**.

- **Dirección de la API**: `POST https://api.acedata.cloud/kling/talking-photo`
- **Facturación**: por duración, 5 segundos **16.45 Credits**, 10 segundos **30.45 Credits** (= precio combinado de image2video + lip-sync)

## Encabezados de solicitud

| Campo              | Valor               |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## Parámetros de solicitud

| Parámetro             | Tipo      | Obligatorio  | Predeterminado                  | Descripción                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | Sí   | —                   | URL pública de la foto de la persona, se recomienda un rostro frontal claro                    |
| `audio_url`    | string  | Sí   | —                   | URL pública del audio de conducción (.mp3/.wav/.m4a/.aac, ≤5MB) |
| `prompt`       | string  | No   | —                   | Palabras de indicación de acción/expresión para la etapa de animación de la foto                      |
| `model`        | string  | No   | `kling-v2-1-master` | Modelo Kling utilizado para la animación de la foto                     |
| `duration`     | integer | No   | `5`                 | Duración del video (5 o 10 segundos)                        |
| `mode`         | string  | No   | `pro`               | Calidad de animación (std/pro)                        |
| `callback_url` | string  | No   | —                   | Si se proporciona o `async=true`, devuelve `task_id` de forma asíncrona        |
| `async`        | boolean | No   | `false`             | Modo asíncrono, úsalo con sondeo o callback de `/kling/tasks`          |

## Ejemplo de solicitud

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Ejemplo de respuesta

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Campo                 | Descripción                        |
| ------------------ | ------------------------- |
| `video_url`        | Video parlante final (ya almacenado en la CDN de esta plataforma)      |
| `source_video_url` | Video de animación de foto intermedio (resultado de image2video) |
| `video_id`         | ID de video de Kling                   |

## Consideraciones

- Se recomienda que la foto tenga un rostro frontal claro y una sola persona.
- Se recomienda que la duración del audio no exceda la duración del video (5 s/10 s).
- La facturación se realiza al completarse correctamente; los errores de validación de parámetros (4xx) no se facturan.
- La generación tarda aproximadamente 4–6 minutos (dos pasos); se recomienda usar `async=true` + sondeo de `/kling/tasks`.
