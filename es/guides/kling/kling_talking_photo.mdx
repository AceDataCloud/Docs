---
title: "API de Foto Hablante de Kling (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Convierte **una foto + un audio** en un "video que habla" con un solo clic. El servicio completa automáticamente dos pasos: primero usa image2video para animar la foto, y luego usa lip-sync para sincronizar los labios con el audio. Solo necesitas hacer la llamada **una vez**.

- **URL de la API**: `POST https://api.acedata.cloud/kling/talking-photo`
- **Facturación**: por duración, 5 segundos **16.45 Créditos**, 10 segundos **30.45 Créditos** (= precio combinado de image2video + lip-sync)

## Encabezados de la Solicitud

| Campo              | Valor                 |
| ----------------- | --------------------- |
| `authorization`   | `Bearer ${API_KEY}`   |
| `content-type`    | `application/json`    |

## Parámetros de la Solicitud

| Parámetro        | Tipo      | Requerido | Predeterminado          | Descripción                                   |
| ---------------- | --------- | --------- | ----------------------- | --------------------------------------------- |
| `image_url`      | string    | Sí        | —                       | URL pública de la foto de la persona, se recomienda que sea clara y de frente |
| `audio_url`      | string    | Sí        | —                       | URL pública del audio ( .mp3/.wav/.m4a/.aac, ≤5MB) |
| `prompt`         | string    | No        | —                       | Palabras clave para la animación de la foto (acciones/expresiones) |
| `model`          | string    | No        | `kling-v2-1-master`    | Modelo Kling utilizado para la animación de la foto |
| `duration`       | integer   | No        | `5`                     | Duración del video (5 o 10 segundos)        |
| `mode`           | string    | No        | `pro`                   | Calidad de la animación (std/pro)           |
| `callback_url`   | string    | No        | —                       | Si se proporciona o `async=true`, devuelve task_id de forma asíncrona |
| `async`          | boolean   | No        | `false`                 | Modo asíncrono, para hacer polling o callback con `/kling/tasks` |

## Ejemplo de Solicitud

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Ejemplo de Respuesta

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "source_video_url": "https://platform2.cdn.acedata.cloud/kling/163ac822-1a15-4f5e-a2eb-465154df15af.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Campo                | Descripción                                   |
| ------------------- | --------------------------------------------- |
| `video_url`         | El video final que habla (almacenado en el CDN de esta plataforma) |
| `source_video_url`  | Video intermedio de la animación de la foto (resultado de image2video) |
| `video_id`          | ID del video de Kling                         |

## Notas

- Se recomienda que la foto sea clara, de frente y de una sola persona.
- La duración del audio no debe exceder la duración del video (5s/10s).
- La facturación ocurre al tener éxito; la validación de parámetros fallida (4xx) no se factura.
- El tiempo de generación es de aproximadamente 4–6 minutos (dos pasos), se recomienda usar `async=true` + `/kling/tasks` para hacer polling.
