---
title: "Guía de integración de videos de productos"
description: "Kling video generation API guide - Ace Data Cloud"
---

Envía una tarea mediante `POST /kling/goods-studio` y utiliza el existente `POST /kling/tasks` para consultar el estado de la tarea en la plataforma.

## Entrada

Proporciona entre 1 y 5 imágenes de productos y un título de producto de hasta 200 caracteres; la descripción del producto es opcional, hasta 2000 caracteres. La duración puede ser opcionalmente de 15, 30 o 60 segundos.

El siguiente es un ejemplo de estructura de solicitud; reemplaza la URL del material antes de realizar la llamada.

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## Resultados y facturación

El modo síncrono devuelve el resultado generado; el modo asíncrono primero devuelve `task_id`, y el resultado completado incluye los enlaces de video o imagen en `data` y el `usage` calculado por el servidor. `callback_url` se utiliza para la notificación de finalización; la solicitud con `watermark=true` devuelve simultáneamente la versión con marca de agua.

720p: 2,38 Credits/segundo; 1080p: 2,8 Credits/segundo. Los videos se facturan según la duración real generada; el precio base por segundo antes de la generación no representa el precio total de toda la tarea. Las tareas fallidas no cobran tarifas de generación.
