Google SERP (Página de Resultados del Motor de Búsqueda) es la página de resultados que los usuarios ven después de ingresar una consulta en el motor de búsqueda de Google. Muestra resultados de búsqueda orgánicos, anuncios, fragmentos destacados, gráficos de conocimiento, así como imágenes, videos y otros tipos de contenido, con el objetivo de proporcionar a los usuarios la información más relevante.

Este artículo presentará en detalle la Google SERP API, que puede proporcionar resultados al ingresar consultas en el motor de búsqueda de Google, y el contenido de los resultados también incluye muchos tipos, como fragmentos destacados, gráficos de conocimiento y diversas imágenes.

Este documento describirá las instrucciones de integración de la Google SERP API.

## Proceso de solicitud

Para utilizar la Google SERP API, primero dirígete a [la consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obtener tu API Token, que debes guardar para uso futuro.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión que te invitará a registrarte e iniciar sesión; una vez completado, regresarás automáticamente a la página actual.

**Un API Token es suficiente para acceder a todos los servicios de la plataforma, no es necesario solicitar uno por cada servicio.** La primera solicitud incluirá un crédito gratuito para que puedas probarlo; si el crédito es insuficiente, puedes recargar el saldo general en [la consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [Google SERP API →](https://platform.acedata.cloud/documents/serp-google)

## Uso básico

Primero, debes entender la forma básica de uso, que consiste en ingresar el tipo de recurso de búsqueda y la palabra clave para obtener los resultados de búsqueda; solo necesitas pasar el campo `query` y especificar el modelo correspondiente.

Por ejemplo, para buscar información sobre "apple inc", podemos llenar el contenido correspondiente en la interfaz, como se muestra en la imagen:

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

Aquí podemos ver que hemos configurado los Request Headers, que incluyen:

- `accept`: el formato de respuesta que deseas recibir, aquí se establece como `application/json`, es decir, en formato JSON.
- `authorization`: la clave para llamar a la API, que puedes seleccionar directamente después de solicitarla.

Además, se ha configurado el Request Body, que incluye:

- `type`: el tipo de recurso de búsqueda, actualmente solo se admiten seis tipos, siendo el predeterminado `search`.
- `query`: la palabra clave de búsqueda.
- `country`: el país donde se personalizan los resultados de búsqueda, siendo el predeterminado Estados Unidos (US).
- `language`: el idioma de los resultados de búsqueda, siendo el predeterminado inglés (en).
- `range`: el rango de tiempo de los resultados de búsqueda, sin restricciones por defecto.
- `number`: el tamaño de la página de resultados de búsqueda, siendo el predeterminado 10.
- `page`: el número de página de los resultados de búsqueda, siendo el predeterminado 1.

另外如果想生成对应的对接代码，可以直接复制生成，例如 CURL 的代码如下：

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc"
}'
```

Python 的对接代码如下：

```python
import requests

url = "https://api.acedata.cloud/serp/google"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "query": "apple inc"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Si desea personalizar el tipo de recurso de búsqueda, podemos modificar el parámetro `type`, que incluye recursos normales `search`, recursos de imágenes `images`, recursos de noticias `news`, recursos de mapas `maps`, recursos de áreas `places`, recursos de videos `videos`, en este artículo haremos una demostración con recursos de video `videos`.

## 自定义搜索结果时间范围
本文还可以 personalizar el rango de tiempo de los resultados de búsqueda, que incluye cinco tipos: `qdr:h` (última hora), `qdr:d` (último día), `qdr:w` (última semana), `qdr:m` (último mes), y por defecto sin restricciones. Podemos pasar el rango de tiempo correspondiente a través de `range`, por ejemplo, aquí se establece como `qdr:d`, lo que indica que se buscan resultados del último día, así que la entrada es la siguiente:

<p><img src="https://cdn.acedata.cloud/qccfib.png" width="500" class="m-auto"></p>

El código correspondiente es el siguiente:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "range": "qdr:d",
  "query": "apple inc"
}'
```
