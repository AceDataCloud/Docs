`POST https://api.acedata.cloud/webextrator/extract`

La API de extracción inteligente WebExtrator convierte una URL en **resultados estructurados tipados**: artículos, productos,
recetas, vídeos, discusiones, ofertas de empleo y más, junto con Markdown limpio y texto sin formato. Usa esta API cuando quieras "datos estructurados limpios" en lugar de HTML sin procesar.

## Proceso de Solicitud

Para usar la página de servicios de WebExtrator, primero ve a [la consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obtener tu Token de API, guárdalo para uso futuro.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión que te invita a registrarte e iniciar sesión, y una vez completado, regresarás automáticamente a la página actual.

**Un Token de API es suficiente para acceder a todos los servicios de la plataforma, no es necesario solicitar uno por cada servicio.** La primera solicitud te otorgará un crédito gratuito para que lo pruebes; si el crédito es insuficiente, puedes recargar el saldo general en [la consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [Página de servicios de WebExtrator →](https://platform.acedata.cloud/service/webextrator)

## Autenticación

```
Authorization: Bearer YOUR_API_KEY
Content-Type:  application/json
```

## Parámetros de la solicitud

Extract acepta **todos** los parámetros de [Render API](/es/guides/webextrator/webextrator_render)
（`url`、`user_agent`、`timeout`、`wait_until`、`delay`、`wait_for_selector`、
`block_resources`、`headers`、`cookies`、`callback_url`、`bypass_cache`、
`cache_ttl_seconds`、`async`）, además de dos campos exclusivos de Extract:

| Campo | Tipo | Obligatorio | Predeterminado | Descripción |
|------|------|:----:|------|------|
| `expected_type` | enum | ❌ | Detección automática | Sugerencia de tipo de página: `product` / `article` / `general`. Especifica el tipo de resultado esperado. |
| `enable_llm` | boolean | ❌ | `false` | Permite invocar la extracción con LLM cuando schema.org no encuentra coincidencias. En páginas sin JSON-LD como Amazon / HN / Greenhouse, debe activarse para obtener resultados tipados. |

### Campos de nivel superior

| Campo | Tipo | Descripción |
|------|------|------|
| `kind` | string | Siempre `"extract"`. |
| `url` | string | La URL que enviaste. |
| `finalUrl` | string | La URL final después de las redirecciones. |
| `contentType` | enum | Tipo de página: `product` / `article` / `general`. |
| `title` | string | Título de la página. |
| `description` | string? | Descripción o resumen de la página. |
| `byline` | string? | Autor, canal o empresa. |
| `language` | string? | `<html lang>`.  |
| `siteName` | string? | `og:site_name`.  |
| `publishedAt` | string? | Hora de publicación, en formato ISO 8601. |
| `images` | string[] | Hasta 50 `<img src />`, resueltos como URL absolutas, sin duplicados y descartando URI `data:`. |
| `links` | string[] | Hasta 100 enlaces externos, con fragmentos / `javascript:` / `mailto:` / `tel:` filtrados. |
| `markdown` | string | Contenido Markdown de la página. |
| `text` | string | Texto sin formato de la página. |
| `structured` | object | Resultado estructurado completo; véase a continuación. |
| `rawSignals` | object | Información de diagnóstico para depuración. |
| `cached` | boolean? | `true` cuando se encuentra en caché. |
| `cacheStoredAt` | number? | Marca de tiempo Unix en milisegundos de la primera escritura de la entrada de caché. |

### Subcampos de `data.structured`

| Subcampo | Cuándo aparece | Descripción |
|--------|---------|------|
| `schemaOrg` | Siempre | `{ primary, breadcrumbs, all }`. `primary` es la entidad tipada de mayor prioridad; si no se encuentra, es `null`. |
| `openGraph` | Siempre | `{ title, description, image, type }`, procedente de `<meta property="og:*" />`. |
| `jsonLd` | Siempre | Matriz JSON sin procesar de todos los bloques `<script type="application/ld+json">`. |
| `llm` | Cuando el LLM se ejecuta correctamente | `{ kind, data, model, promptCharCount }`, resultado tipado. |
| `llmError` | Cuando el LLM se ejecuta, pero falla | `{ kind, error, model }`, la solicitud aún puede devolver otros campos extraídos. |
| `amazon` | Cuando la URL es `amazon.*` | Resultados de la extensión heredada de Amazon; para nuevas integraciones, use resultados tipados. |

## Tipos de resultados de schema.org

`structured.schemaOrg.primary` admite los siguientes tipos de resultados:

| Tipo de schema.org | kind | Campos de salida |
|----------------|----------|----------|
| `Product` | product | `name, sku, gtin, model, color, brand, url, images, offer.{price,currency,availability,condition,seller}, rating.{value,count}, reviews[], properties[]` |
| `Recipe` | recipe | `name, description, image, datePublished, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords, recipeCategory, recipeCuisine` |
| `VideoObject` | video | `name, description, thumbnailUrl, uploadDate, duration, embedUrl, contentUrl, channel, interactionCount` |
| `JobPosting` | job | `title, description, datePosted, validThrough, hiringOrganization, jobLocation, baseSalary, employmentType` |
| `Event` (incluido `*Event`) | event | `name, description, startDate, endDate, location.{name,address}, organizer, offer.{url,price,currency}` |
| `Article` / `NewsArticle` / `BlogPosting` / `ScholarlyArticle` / `TechArticle` / `Report` / `*NewsArticle` | article | `subtype, headline, description, datePublished, dateModified, author, publisher, image[], url, sameAs[]` |
| `FAQPage` | faq | `questions[{question, answer}]` |
| `BreadcrumbList` | (adjunto a sibling) | Siempre se genera en `structured.schemaOrg.breadcrumbs[]`; no será primary. |

## Tipos de resultados de LLM

Cuando `enable_llm: true` y la página no tiene datos estructurados de schema.org utilizables, se pueden devolver los siguientes tipos de resultados de extracción:

| Kind | Campos obligatorios | Campos opcionales |
|------|---------|---------|
| `article` | `headline` | `description, byline, publishedAt, language, topics[], sections[{heading,summary}]` |
| `product` | `name` | `description, brand, sku, price, currency, availability, rating.{value,count}, bullets[], specifications[{name,value}]` |
| `discussion` | `title` | `author, postedAt, points, commentCount, body, url` |
| `recipe` | `name` | `description, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords[]` |
| `video` | `name` | `description, channel, uploadDate, duration, viewCount, likeCount, thumbnailUrl, transcript` |
| `job` | `title` | `description, company, location, remote, employmentType, datePosted, validThrough, salaryMin, salaryMax, salaryCurrency, salaryPeriod, responsibilities[], qualifications[]` |

## Caché

La misma URL, los parámetros de solicitud, `cookies` y `headers` pueden reutilizar resultados almacenados en caché; `async`, `bypass_cache` y `cache_ttl_seconds` se utilizan para controlar el modo de ejecución y el comportamiento de la caché.

| Campo | Comportamiento |
|------|------|
| `bypass_cache: true` | Omite la lectura; el resultado de esta vez se seguirá escribiendo en la caché y las solicitudes idénticas posteriores podrán acertar en la caché. |
| `cache_ttl_seconds: 0` | Esta respuesta **no se almacena en caché**. |
| `cache_ttl_seconds: N` | Personaliza el TTL de esta entrada (predeterminado: 3600 segundos). |

Las respuestas obtenidas de la caché incluirán `data.cached: true` y `data.cacheStoredAt: <unix-ms>`.

## Modo asíncrono y callbacks

Configurar `async: true` para entrar en modo asíncrono (proporcionar `callback_url` también hará que se active automáticamente). La plataforma devuelve inmediatamente (HTTP 200):

```json
{
  "success": true,
  "task_id": "550e8400-...",
  "trace_id": "6ba7b810-...",
  "started_at": 1777717800.123
}
```

Cuando la tarea se complete, se enviará el sobre completo `POST` a tu `callback_url` (si se configuró). También puedes consultar
proactivamente a través de [`/webextrator/tasks`](/es/guides/webextrator/webextrator_tasks).

```bash

  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://en.wikipedia.org/wiki/Diffbot",
    "expected_type": "article"
  }'
```

### Python (requests)

```python
import os, requests

API_KEY = os.environ["ACEDATA_API_KEY"]

resp = requests.post(
    "https://api.acedata.cloud/webextrator/extract",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "url": "https://en.wikipedia.org/wiki/Diffbot",
        "expected_type": "article",
    },
    timeout=120,
)
resp.raise_for_status()
data = resp.json()["data"]

primary = (data.get("structured") or {}).get("schemaOrg", {}).get("primary")
print("contentType:", data["contentType"])
print("title:      ", data["title"])
print("byline:     ", data.get("byline"))
print("publishedAt:", data.get("publishedAt"))
if primary and primary["kind"] == "article":
    print("headline:    ", primary["headline"])
    print("dateModified:", primary.get("dateModified"))
```

### Node.js (fetch)

```js
const apiKey = process.env.ACEDATA_API_KEY;

const res = await fetch('https://api.acedata.cloud/webextrator/extract', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${apiKey}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://www.allrecipes.com/recipe/16354/easy-meatloaf/',
  }),
});
const { data } = await res.json();
const recipe = data?.structured?.schemaOrg?.primary;
console.log(recipe.name, recipe.cookTime, recipe.ingredients.length, 'tipos de ingredientes');
```

## Consejos y consideraciones

- **Pasa `expected_type` cuando necesites especificar el tipo de página.** Por ejemplo, usa `article` para páginas de artículos y `product` para páginas de productos.
- **`enable_llm: true` es gratuito en las páginas que coinciden con schema.org.** El LLM solo se invoca cuando schema.org
  no tiene un elemento principal, por lo que es seguro dejarlo activado de forma predeterminada.
- **Durante la depuración, revisa primero `rawSignals.hasJsonLd`.** Si es `true` pero `structured.schemaOrg.primary`
  es `null`, significa que `@type` de la página aún no es compatible; puedes informarnos.
- **`structured.llmError` es informativo.** La solicitud aún puede devolver correctamente otros campos extraídos. Consulta
  `llmError.error` para identificar la causa (tiempo de espera agotado, error de análisis de JSON o error de validación de estructura).
- **`links[]` para páginas que no son artículos no aplica ordenación por relevancia.** Solo realiza una limpieza básica según "máximo de 100 elementos + filtrado de protocolos no válidos".
  en la medida de lo posible.
- **Los aciertos de caché también se facturan.**
