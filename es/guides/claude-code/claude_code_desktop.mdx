Claude Code es una herramienta de **Agentic Coding** lanzada por Anthropic, también conocida como uno de los agentes de programación más poderosos del mundo. La aplicación de escritorio Claude Code ofrece una interfaz gráfica independiente, soporta revisión Diff, sesiones paralelas (aisladas a través de Git Worktree), sesiones remotas y más, sin necesidad de depender de ningún IDE.

Este documento describe principalmente cómo configurar y usar la aplicación de escritorio Claude Code a través del servicio proxy de AceData Cloud.

> **Nota**: La aplicación de escritorio Claude Code se encuentra actualmente en fase de vista previa (Preview), y solo es compatible con macOS y Windows.

## Proceso de solicitud

Para usar Claude Code, primero puedes ir a la [página del servicio Claude Messages](https://platform.acedata.cloud/documents/claude-messages) y hacer clic en el botón "Acquire" para obtener las credenciales necesarias para la solicitud:

![](https://cdn.acedata.cloud/nyq0xz.png)

Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión que te invita a registrarte e iniciar sesión; después de iniciar sesión o registrarte, serás devuelto automáticamente a la página actual.

En la primera solicitud, se te otorgará un crédito gratuito para que puedas experimentar el servicio Claude Code sin costo.

## Instalación de la aplicación de escritorio

### Requisitos del sistema

- macOS (Intel y Apple Silicon) o Windows (x64 / ARM64)
- Linux no es compatible con la aplicación de escritorio

### Descarga e instalación

Dirígete a la [página de descarga oficial de Claude](https://claude.ai) para descargar el paquete de instalación correspondiente a tu plataforma:

- **macOS**: descarga el archivo `.dmg` y arrástralo a la carpeta Applications
- **Windows x64**: descarga el paquete de instalación `.exe` y sigue las instrucciones para instalar
- **Windows ARM64**: descarga la versión ARM64 (nota: ARM64 no soporta sesiones locales, se debe usar sesiones remotas)

![Página de descarga de la aplicación de escritorio Claude](https://cdn.acedata.cloud/c3c8c57264.png)

Una vez completada la instalación, inicia Claude desde la carpeta Applications (macOS) o el menú de inicio (Windows).

## Configuración de la API de AceData Cloud

Después de iniciar la aplicación de escritorio, necesitarás iniciar sesión en tu cuenta de Anthropic. Podemos usar variables de entorno para utilizar la API proxy de AceData Cloud, **sin necesidad de suscripción oficial**.

La aplicación de escritorio lee las variables de entorno de tu entorno Shell, por lo que necesitas configurarlas en el archivo de configuración de Shell.

### Configuración de variables de entorno

**Usuarios de macOS**

Agrega el siguiente contenido a `~/.zshrc` (o `~/.bashrc`), reemplazando `{token}` con tu token de API:

```bash
# AceData Cloud - Configuración del proxy de Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Guarda y ejecuta:

```bash
source ~/.zshrc
```

**Usuarios de Windows**

Agrega las siguientes variables de entorno del sistema a través de "Propiedades del sistema → Avanzado → Variables de entorno":

| Nombre de variable          | Valor                           |
| ---------------------- | ----------------------------- |
| `ANTHROPIC_AUTH_TOKEN` | `{token}` (reemplaza con tu token de API) |
| `ANTHROPIC_BASE_URL`   | `https://api.acedata.cloud`   |

O usa PowerShell:

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**También se puede configurar a través de settings.json**

Edita `~/.claude/settings.json` (crea el archivo si no existe):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Consejo**: El token de API se puede ver en la [consola de AceData Cloud](https://platform.acedata.cloud/console). Después de completar la configuración, es necesario **reiniciar la aplicación de escritorio** para que las variables de entorno surtan efecto.

## Uso básico

### Abrir un proyecto

1. Inicia la aplicación de escritorio Claude
2. Haz clic en la pestaña **Code** en la parte superior
3. Selecciona el modo de ejecución **Local**
4. Haz clic en **Select folder** para elegir tu directorio de proyecto

### Comenzar una conversación

Ingresa en el cuadro de texto una descripción en lenguaje natural de tus necesidades:

- "Encuentra los comentarios TODO y corrígelos"
- "Agrega pruebas a la función principal"
- "Explica la arquitectura de este proyecto"

Claude analizará tu repositorio de código, propondrá modificaciones y mostrará los cambios en vista Diff.

### Modo de permisos

Cambia a través del selector de modo junto al botón de enviar:

| Modo       | Descripción                       |
| -------- | ------------------------------- |
| **Ask**  | Pregunta confirmación antes de cada modificación (recomendado para principiantes) |
| **Code** | Acepta automáticamente la edición de archivos, pero los comandos de terminal aún requieren confirmación |
| **Plan** | Primero elabora un plan detallado y espera aprobación, solo se ejecuta después de la confirmación |

### Sesiones paralelas

Haz clic en **+ New session** en la barra lateral para iniciar múltiples sesiones paralelas. Para repositorios de Git, cada sesión obtendrá una copia independiente del proyecto a través de Worktree, sin interferencias.

Worktree se almacena por defecto en el directorio `~/.claude-worktrees/`.

### Revisión Diff

Cuando Claude modifica archivos, mostrará estadísticas de cambios (como `+12 -1`), haciendo clic se abrirá el visor Diff para revisar los cambios archivo por archivo. También puedes hacer clic en líneas de código específicas para agregar comentarios, Claude ajustará según tus comentarios.

## Conexión a herramientas externas

Antes de comenzar una sesión, haz clic en el botón **⋯**, selecciona **Connectors** para agregar integraciones externas:

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- Más...

Después de conectar, Claude podrá leer directamente el calendario, enviar mensajes, crear Issues, etc.

## Relación con CLI

La aplicación de escritorio y CLI utilizan el mismo motor subyacente, compartiendo la siguiente configuración:

- Archivos de memoria del proyecto `CLAUDE.md` / `CLAUDE.local.md`
- Configuración del servidor MCP en `~/.claude.json` / `.mcp.json`
- Configuración en `~/.claude/settings.json`
- Configuración de Hooks y Skills

Ambos pueden ejecutarse simultáneamente en el mismo proyecto, manteniendo cada uno su historial de sesiones independiente.

## Preguntas frecuentes

### ¿Qué hacer si la conexión falla?

1. Verifica si el archivo `~/.claude/config.json` se ha creado correctamente
2. Asegúrate de que las variables de entorno estén configuradas correctamente (reinicia la aplicación de escritorio para que surtan efecto)
3. Confirma que el token de API sea válido (puedes verlo en la [consola](https://platform.acedata.cloud/console))
4. Si usas `settings.json` para configurar las variables de entorno, asegúrate de que el formato del archivo sea correcto

### ¿No se pueden encontrar las herramientas instaladas?

Si Claude no puede encontrar comandos como `npm`, `node`, etc.:

1. Asegúrate de que estas herramientas funcionen correctamente en una terminal normal
2. Verifica si tu archivo de configuración de Shell (`~/.zshrc`, `~/.bashrc`) tiene configurado correctamente el PATH
3. Reinicia la aplicación de escritorio para recargar las variables de entorno

### ¿Cómo ver el saldo restante?

Inicia sesión en la [consola de AceData Cloud](https://platform.acedata.cloud/console) para ver el saldo restante y el uso actual de tu cuenta.
