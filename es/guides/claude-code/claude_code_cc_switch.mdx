## 1. Obtener API Key

Abre la [lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), accede a las aplicaciones disponibles y copia el API Key.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar CC Switch

Descarga desde [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), también se puede ejecutar en macOS:

```bash
brew install --cask cc-switch
```

## 3. Añadir Provider

Abre CC Switch, selecciona **Claude Code → Add Provider → Custom**, completa:

| Campo       | Valor                        |
| ----------- | ---------------------------- |
| Nombre      | `Ace Data Cloud`            |
| URL Base    | `https://api.acedata.cloud` |
| API Key     | El API Key que copiaste recién  |
| Formato API | `Anthropic Messages`        |

Si necesitas usar el editor JSON, configúralo como:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

CC Switch escribirá la configuración en la configuración del usuario de Claude Code. No guardes el Key real en el repositorio del equipo, ni mantengas el viejo `ANTHROPIC_API_KEY` al mismo tiempo.

## 4. Habilitar y verificar

Después de guardar, habilita **Ace Data Cloud**, y vuelve a abrir Claude Code. Envía una tarea simple de solo lectura y verifica la llamada en [Historial de uso](https://platform.acedata.cloud/console/usages). Si después de cambiar aún usas la configuración antigua, cierra completamente Claude Code y CC Switch y vuelve a intentarlo.
