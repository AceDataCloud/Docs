Claude Code es una herramienta de programación lanzada por Anthropic, también conocida como uno de los agentes de programación más poderosos del mundo. La extensión de Claude Code para VS Code ofrece una interfaz gráfica nativa, siendo la forma recomendada de usar Claude Code en VS Code.

Este documento describe principalmente cómo configurar y usar la extensión de Claude Code en VS Code a través del servicio proxy de Ace Data Cloud.

## Proceso de solicitud

Para usar Claude Code, primero puede ir a [la consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) y obtener su API Token, para tenerlo como respaldo.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no ha iniciado sesión o registrado, será redirigido automáticamente a la página de inicio de sesión que le invita a registrarse e iniciar sesión; después de registrarse e iniciar sesión, volverá automáticamente a la página actual.

En la primera solicitud, se otorgará un crédito gratuito para que pueda experimentar el servicio de Claude Code de forma gratuita.

## Instalación del complemento Claude Code

Busque **Claude Code** en el mercado de extensiones de VS Code, confirme que el editor sea **Anthropic** y luego instálelo. Una vez completada la instalación, aparecerá la entrada de Claude Code en la barra de actividades.

## Configuración de la API de Ace Data Cloud

La primera vez que abra el complemento, se le pedirá que inicie sesión en la cuenta oficial de Anthropic. Podemos omitir el inicio de sesión oficial y usar la API proxy de Ace Data Cloud, sin necesidad de suscripción oficial.

La extensión y la CLI del terminal leen el mismo conjunto de configuraciones de Claude Code. Para obtener información completa sobre la autenticación, el manejo de conflictos de credenciales y la configuración global, consulte [la guía de configuración del terminal de Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration). Si solo desea que funcione en el proyecto actual, cree un archivo `.claude/settings.local.json` en el directorio raíz del proyecto que esté incluido en `.gitignore`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Donde `{token}` es la API Key que copió anteriormente. Si en el entorno donde se inicia VS Code ya existe un `ANTHROPIC_API_KEY` antiguo, primero debe ejecutar `unset ANTHROPIC_API_KEY` en ese entorno; no trate de limpiar con una cadena vacía y no coloque la clave real en el archivo compartido del equipo `.claude/settings.json`.

A continuación se muestra la configuración completada en la máquina local utilizando VS Code 1.136.1 y la extensión Claude Code 2.1.251. La captura de pantalla utiliza una clave de marcador de posición para evitar la divulgación de credenciales reales:

![Configuración de Ace Data Cloud Claude Code en VS Code](https://cdn.acedata.cloud/f925e9e9597b.png)

Una vez configurado, reinicie VS Code.

> Nota: La configuración anterior solo afecta al proyecto actual, y se recomienda agregar la ruta del archivo de configuración `.claude/settings.local.json` al archivo `.gitignore` para evitar que se suba al repositorio remoto.

Si desea que funcione en todos los proyectos, puede configurar directamente en el directorio del usuario. La ruta correspondiente es `~/.claude/settings.json`,

> Nota: Después de completar la configuración, reinicie o recargue VS Code para que la configuración tenga efecto.

## Uso básico

Una vez configurado, envíe una tarea simple de solo lectura en el panel de Claude Code, como "lee README.md y resume en una frase". Después de que la tarea se complete con éxito, puede verificar esta llamada en [el historial de uso](https://platform.acedata.cloud/console/usages).

## Cómo ver el saldo restante

A través de [la consola de Ace Data Cloud - Lista de aplicaciones](https://platform.acedata.cloud/console/applications), puede ver el saldo restante de su cuenta.

A través de [la consola de Ace Data Cloud - Historial de uso](https://platform.acedata.cloud/console/usages) puede ver todo el historial de uso y los detalles de facturación.
