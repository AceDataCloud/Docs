## 1. Obtener API Key

Abre [la lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), accede a la aplicación disponible y copia la API Key.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

En el **Settings → Secrets and variables → Actions** del repositorio de GitHub objetivo, crea un nuevo Secret:

```text
ACEDATACLOUD_API_KEY
```

## 2. Instalar la aplicación de GitHub

Instala [Claude GitHub App](https://github.com/apps/claude) y autoriza el repositorio objetivo. Esta aplicación oficial solicitará un conjunto de permisos completos; entre ellos, Claude Code Action utiliza realmente los permisos de Contents, Issues y Pull requests, la página de instalación de GitHub no puede seleccionar solo estos tres. Si la organización requiere permisos mínimos, crea una aplicación de GitHub personalizada según la documentación oficial.

## 3. Agregar Workflow

Crea `.github/workflows/claude.yml`:

```yaml
name: Claude Code

on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  claude:
    if: contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      actions: read
      id-token: write
    env:
      ANTHROPIC_BASE_URL: https://api.acedata.cloud
      ANTHROPIC_CUSTOM_HEADERS: "Authorization: Bearer ${{ secrets.ACEDATACLOUD_API_KEY }}"
    steps:
      - uses: actions/checkout@v6
        with:
          fetch-depth: 1
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: dummy-not-used
```

`claude-code-action` requiere una entrada no vacía para `anthropic_api_key`; el valor de marcador de posición aquí no se utilizará para la autenticación en la plataforma. `ANTHROPIC_CUSTOM_HEADERS` se sobrescribirá para el Bearer Header requerido por Ace Data Cloud, la clave real solo proviene del Secret de GitHub.

## 4. Verificación

Después de enviar el Workflow, envía en un comentario de Issue o PR:

```text
@claude Responde solo OK
```

Si tiene éxito, el workflow de Actions se completará y actualizará el resultado en el Issue/PR correspondiente. Si Action indica que faltan credenciales, confirma que `dummy-not-used` aún existe; si aparece 401, verifica el Secret `ACEDATACLOUD_API_KEY`. No imprimas el Secret en los registros. Puedes usar `claude_args` para configurar `--max-turns` según sea necesario o elegir el modelo disponible actual, pero la plantilla de integración no fija el modelo.
