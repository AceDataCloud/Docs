Claude Code es una herramienta de **programación agentiva** lanzada por Anthropic, también conocida como uno de los agentes de programación más poderosos del mundo. Claude Code ofrece un plugin específico para JetBrains IDE, que es compatible con IntelliJ IDEA, PyCharm, WebStorm, GoLand, PhpStorm, Android Studio y toda la serie de JetBrains IDE.

Este documento describe principalmente cómo configurar y usar Claude Code en JetBrains IDE a través del servicio proxy de AceData Cloud.

## Proceso de solicitud

Para usar Claude Code, primero puedes ir a la [página del servicio Claude Messages](https://platform.acedata.cloud/documents/claude-messages) y hacer clic en el botón "Acquire" para obtener las credenciales necesarias para la solicitud:

![](https://cdn.acedata.cloud/nyq0xz.png)

Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión que te invita a registrarte e iniciar sesión. Después de registrarte e iniciar sesión, serás redirigido automáticamente a la página actual.

En la primera solicitud, se te otorgará un crédito gratuito para que puedas experimentar el servicio de Claude Code de forma gratuita.

## Instalación

### Requisitos previos

El plugin de Claude Code para JetBrains depende de Claude Code CLI, asegúrate de haber instalado CLI primero:

```bash
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# O usando Homebrew
brew install claude-code
```

Después de la instalación, puedes verificar:

```bash
claude --version
```

### Instalación del plugin

![Plugin Claude Code en JetBrains Marketplace](https://cdn.acedata.cloud/de78fd305b.png)

1. Abre JetBrains IDE
2. Ve a **Settings** → **Plugins** → **Marketplace**
3. Busca **Claude Code**
4. Haz clic en **Install** para instalar el plugin
5. Reinicia el IDE

O visita directamente [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/27310-claude-code-beta-) para instalar en línea.

> **Importante**: Después de instalar el plugin, es necesario **reiniciar completamente el IDE** (puede que necesites reiniciar varias veces) para que surta efecto.

## Configuración de AceData Cloud API

El plugin de Claude Code para JetBrains ejecuta el comando `claude` a través de la terminal integrada, por lo que la configuración de las variables de entorno es la misma que para CLI.

### Paso uno: Crear config.json

Crea el archivo de configuración para Claude Code:

| Sistema            | Ruta                                   |
| ----------------- | ------------------------------------ |
| **macOS / Linux** | `~/.claude/config.json`              |
| **Windows**       | `C:\Users\{nombre de usuario}\.claude\config.json` |

Escribe el siguiente contenido en este archivo y guárdalo:

```json
{
  "primaryApiKey": "self"
}
```

Comando rápido para crear en macOS / Linux:

```bash
mkdir -p ~/.claude && echo '{"primaryApiKey": "self"}' > ~/.claude/config.json
```

### Paso dos: Configurar variables de entorno

**Método uno: Configurar en el archivo de configuración de Shell (recomendado)**

Agrega el siguiente contenido a tu `~/.zshrc` o `~/.bashrc`, reemplazando `{token}` con tu token de API:

```bash
# AceData Cloud - Configuración del proxy de Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Después de modificar, ejecuta `source ~/.zshrc` para que la configuración surta efecto, y luego **reinicia JetBrains IDE**.

**Método dos: Configurar en settings.json de Claude Code**

Edita `~/.claude/settings.json` (crea si no existe):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Consejo**: El token de API se puede ver en el [panel de control de AceData Cloud](https://platform.acedata.cloud/console).

## Uso básico

### Iniciar desde la terminal integrada del IDE

Abre la terminal integrada de JetBrains IDE y ejecuta:

```bash
claude
```

Al ejecutarlo en la terminal integrada del IDE, todas las funciones integradas (vista Diff, selección de contexto, etc.) se activarán automáticamente.

### Conectar desde una terminal externa

Si ejecutas Claude Code en una terminal externa, puedes usar el comando `/ide` para conectarte a JetBrains IDE:

```bash
claude
> /ide
```

Asegúrate de iniciar Claude Code desde la misma ruta del directorio raíz del proyecto del IDE, para que Claude pueda acceder al mismo conjunto de archivos.

### Atajos de teclado

| Atajo de teclado                                      | Función                      |
| -------------------------------------------------- | ----------------------- |
| `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux)        | Abrir rápidamente Claude Code        |
| `Cmd+Option+K` (Mac) / `Alt+Ctrl+K` (Windows/Linux) | Insertar referencia de archivo (ej. `@File#L1-99`) |

### Funciones integradas

El plugin de Claude Code para JetBrains ofrece las siguientes funciones integradas:

- **Vista Diff**: Los cambios de código se muestran directamente en el visor Diff del IDE.
- **Selección de contexto**: El código y las pestañas seleccionadas actualmente se comparten automáticamente con Claude.
- **Referencia de archivo**: Usa atajos de teclado para referenciar rápidamente archivos y números de línea.
- **Compartición de diagnósticos**: La información de diagnóstico como Lint, errores de sintaxis, etc., se comparte automáticamente con Claude.

## Configuración del plugin

En **Settings** → **Tools** → **Claude Code [Beta]** puedes configurar:

| Configuración                      | Descripción                                         |
| -------------------------------- | ------------------------------------------ |
| **Comando de Claude**            | Ruta personalizada del comando de Claude (ej. `/usr/local/bin/claude`) |
| **Habilitar actualizaciones automáticas**  | Comprobar e instalar actualizaciones del plugin automáticamente                                |
| **Habilitar uso de Option+Enter** | Usar Option+Enter en macOS para hacer un salto de línea en el cuadro de diálogo             |

### Configuración para usuarios de WSL

Si usas en un entorno WSL, debes establecer el comando de Claude como:

```
wsl -d Ubuntu -- bash -lic "claude"
```

(reemplaza `Ubuntu` con el nombre de tu distribución de WSL)

## Preguntas frecuentes

### ¿Qué hacer si la conexión falla?

1. Verifica si el archivo `~/.claude/config.json` se creó correctamente.
2. Asegúrate de que las variables de entorno estén configuradas correctamente.
3. Confirma que el token de API sea válido (puedes verlo en el [panel de control](https://platform.acedata.cloud/console)).
4. Reinicia JetBrains IDE y vuelve a intentarlo.

### ¿El plugin no funciona?

1. Asegúrate de ejecutar Claude Code desde el directorio raíz del proyecto.
2. Verifica si el plugin está habilitado en la configuración del IDE.
3. Reinicia completamente el IDE (puede que necesites reiniciar varias veces).
4. Si usas el modo de desarrollo remoto, asegúrate de que el plugin esté instalado en el host remoto (Settings → Plugin (Host)).

### ¿El IDE no es detectado?

1. Asegúrate de que el plugin esté instalado y habilitado.
2. Reinicia el IDE.
3. Asegúrate de ejecutar Claude Code en la terminal integrada.
4. Los usuarios de WSL deben consultar la [guía de solución de problemas de WSL](https://code.claude.com/docs/en/troubleshooting#jetbrains-ide-not-detected-on-wsl2).

### command not found

Si al hacer clic en el ícono de Claude aparece "command not found":

1. Verifica si CLI está instalado: `which claude`.
2. Configura la ruta completa del comando de Claude en la configuración del plugin.
3. Los usuarios de WSL deben usar el formato de comando WSL mencionado anteriormente.
### ¿Cómo ver el saldo restante?

Inicie sesión en [la consola de AceData Cloud](https://platform.acedata.cloud/console) para ver el saldo restante y el uso actual de su cuenta.
