## 1. Obtener API Key

Abre la [lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), accede a las aplicaciones disponibles y copia la API Key.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar CLI y plugin

Primero, instala Claude Code CLI.

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

Luego, instala el plugin **Claude Code** desde JetBrains Marketplace y reinicia el IDE. El plugin llama al comando `claude` de la máquina; si aparece un mensaje de que no se encuentra el comando, completa su ruta completa en **Settings → Tools → Claude Code**.

## 3. Configurar Ace Data Cloud

Configura en el entorno que inicia el backend de JetBrains.

macOS / Linux / WSL：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="tu API Key"
unset ANTHROPIC_API_KEY
```

Windows PowerShell：

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "tu API Key"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

También puedes usar el archivo `.claude/settings.local.json` que se ha ignorado en el proyecto:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "tu API Key"
  }
}
```

El desarrollo remoto debe configurarse e instalarse en el host remoto; los usuarios de WSL pueden establecer el comando Claude como `wsl -d Ubuntu -- bash -lic "claude"`.

## 4. Verificación

Ejecuta `claude` desde la terminal integrada del IDE, o inicia una terminal externa y escribe `/ide`. Una vez conectado, haz que Claude responda `OK`, luego lee un archivo de prueba y verifica esa solicitud en el [historial de uso de Ace Data Cloud](https://platform.acedata.cloud/console/usages).

Si el plugin no se inicia, primero ejecuta `claude --version` en la misma terminal; si obtienes un 401, verifica las variables de entorno que realmente hereda el backend y el antiguo `ANTHROPIC_API_KEY`.
