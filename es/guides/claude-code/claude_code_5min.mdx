El objetivo de este documento es uno solo: que **en 5 minutos** puedas ejecutar tu primer comando Claude Code usando el proxy de AceData Cloud. El tutorial completo está en los documentos específicos para cada IDE ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); aquí solo seguiremos la ruta más rápida con "**CLI en terminal** + **extensión VS Code**".

> **¿Por qué usar el proxy de AceData Cloud para Claude Code?**  
> - Conexión directa en China, sin necesidad de VPN propia  
> - Precios más bajos que el oficial (facturación por tokens de plataforma)  
> - La misma clave soporta simultáneamente Claude Messages API + protocolo Claude Code Token

## Minuto 1: Solicitar credenciales

Abre la [página del servicio Claude Messages](https://platform.acedata.cloud/documents/claude-messages) y haz clic en el botón "**Acquire**":

![](https://cdn.acedata.cloud/nyq0xz.png)

La plataforma creará automáticamente una Aplicación y te dará un crédito gratuito. Anota los valores de **Base URL** y **API Token** que aparecen en la página de detalles — los necesitarás en los siguientes 5 pasos.

| Campo | Valor | Uso |
|-------|-------|-----|
| `BASE_URL` | `https://api.acedata.cloud` | Entrada compatible con Claude Messages |
| `API_TOKEN` | `sk-...` (copiable en la página de detalles) | Encabezado de autenticación compatible con Anthropic |

## Minuto 2: Instalar Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell nativo):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Al terminar la instalación, abre una nueva terminal y verifica que funcione:

```bash
claude --version
```

> Deberías ver el número de versión. Claude Code incluye su propio runtime de Node.js, no depende de la versión de Node instalada en tu máquina.

## Minuto 3: Configurar variables de entorno para usar AceData Cloud

No uses el proceso oficial `claude login`, en su lugar sobrescribe con variables de entorno. Puedes elegir una de estas dos formas:

**Opción A: Temporal (solo para la sesión actual del shell)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-tu-Token"
```

**Opción B: Persistente (recomendado)**

Agrega las dos líneas anteriores al final de `~/.zshrc` o `~/.bashrc`, y luego ejecuta `source` para recargar.

> **Error común**: la variable debe llamarse `ANTHROPIC_AUTH_TOKEN`, no `ANTHROPIC_API_KEY`; si usas el nombre incorrecto, Claude Code volverá al endpoint oficial y dará error 401.

## Minuto 4: Ejecutar el primer comando

Entra en cualquier repositorio Git y ejecuta:

```bash
claude
```

Si al iniciar te pide iniciar sesión, presiona `Esc` para saltar. Luego escribe:

```
Lista las dependencias del proyecto actual y explica brevemente para qué sirve cada una.
```

Normalmente verás que Claude usa herramientas como `read_file` / `glob` / `grep` para explorar el repositorio y luego te da la lista. Si el modelo responde correctamente y no hay error 401, el proxy está funcionando.

## Minuto 5: Conectar también la extensión de VS Code

1. Abre VS Code → panel de extensiones → busca `Claude Code` e instala la oficial de Anthropic;  
2. Reinicia VS Code o ejecuta en la paleta de comandos `Developer: Reload Window` para que la extensión cargue el `~/.claude/settings.json` configurado en el minuto 3;  
3. Haz clic en el icono ✦ Spark en la esquina superior derecha del editor, o en la barra de estado en “✱ Claude Code” para abrir el panel;  
4. La primera vez pedirá iniciar sesión en la cuenta oficial, presiona `Esc` para saltar — la extensión usará automáticamente `ANTHROPIC_BASE_URL` y `ANTHROPIC_AUTH_TOKEN` configurados.

> **Consejo**: La extensión de VS Code y la CLI comparten el mismo archivo `~/.claude/settings.json`, así que no necesitas configurar nada adicional en VS Code. Si quieres usar configuración a nivel proyecto, crea `.claude/settings.local.json` en la raíz del repositorio (ya está en gitignore).

Cuando funcione, podrás arrastrar archivos al panel para hacer preguntas o usar `@-mention` para referenciar archivos y proponer modificaciones. Todo el consumo se factura vía AceData Cloud.

## Verifica que realmente estás usando el proxy

Ejecuta con modo `--debug` para confirmar que las peticiones van a AceData Cloud:

```bash
claude --debug -p "say hi" 2>&1 | grep -iE 'base.?url|api\.acedata|anthropic\.com' | head
```

Si ves `https://api.acedata.cloud` significa que el proxy está activo; si aparece `api.anthropic.com` o error 401, revisa las variables de entorno (deben ser `ANTHROPIC_AUTH_TOKEN` y no `ANTHROPIC_API_KEY`) y asegúrate de que `~/.claude/.credentials.json` no contenga el token oficial (bórralo si existe).

## 5 preguntas frecuentes

**P: Después de hacer `claude login` y cambiar las variables a AceData, ¿por qué no funciona?**  
R: `claude login` guarda el token oficial en `~/.claude/.credentials.json`, que tiene prioridad sobre las variables de entorno. Borra ese archivo y vuelve a hacer `source ~/.zshrc`.

**P: ¿Puedo usar modelos como `--model claude-opus-4-7`?**  
R: Sí. El proxy de AceData Cloud pasa el campo model tal cual, soportando todos los modelos públicos de Anthropic más nuestras extensiones `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5`.

**P: ¿Puedo configurar varios perfiles (personal + trabajo)?**  
R: Sí. Claude Code soporta múltiples perfiles en `~/.claude/settings.json`; o simplemente crea dos funciones shell `claude_personal` y `claude_work` que exporten diferentes `ANTHROPIC_AUTH_TOKEN` y luego llamen a `claude $@`.

**P: ¿Se puede usar en GitHub Actions?**  
R: Sí. Consulta el [tutorial de integración con GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**P: ¿Qué pasa cuando se acaba el crédito gratuito?**  
R: Ve a [Gestión de aplicaciones](https://platform.acedata.cloud/applications) → selecciona la aplicación Claude → recarga saldo (pago por tokens consumidos) o cambia a suscripción por puntos.
