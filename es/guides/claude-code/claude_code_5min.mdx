Este documento tiene un único objetivo: que puedas**en 5 minutos**, ejecutar tu primer comando de Claude Code usando el proxy de AceData Cloud. El tutorial completo está en los subdocumentos de cada IDE ( [VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); aquí solo seguimos el camino más rápido con 「**CLI de terminal** + **Extensión de VS Code**」.

> **¿Por qué usar el proxy de AceData Cloud para Claude Code?**：
> - Conexión directa en China, sin necesidad de VPN
> - Precio más bajo comparado con la versión oficial (facturación por tokens en la plataforma)
> - Una misma clave permite usar tanto Claude Messages API como el protocolo de tokens de Claude Code

## Primer minuto: solicitar credenciales

Abre la página de servicio [Claude Messages](https://platform.acedata.cloud/documents/claude-messages) y haz clic en 「**Acquire**」:

![](https://cdn.acedata.cloud/nyq0xz.png)

La plataforma creará automáticamente una aplicación y te dará una cuota gratuita. Toma nota de las dos entradas del panel de detalles: **Base URL** + **API Token** — las necesitarás en los próximos 5 pasos.

| Campo | Valor | Uso |
|------|------|------|
| `BASE_URL` | `https://api.acedata.cloud` | Punto de entrada compatible con Claude Messages |
| `API_TOKEN` | `sk-...` (se puede copiar desde la página de detalles) | Encabezado de autorización compatible con Anthropic |

## Segundo minuto: instalar Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell nativo):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Al terminar la instalación, abre una terminal nueva y confirma que funcione:

```bash
claude --version
```

> Debe mostrarte la versión. Claude Code incluye un runtime de Node.js, no depende de la versión instalada en tu máquina.

## Tercer minuto: configurar las variables de entorno para que apunten a AceData Cloud

No uses el proceso oficial `claude login`, sino sobrescribe las variables de entorno. Puedes hacer cualquiera de estas opciones:

**Opción A: Temporal (solo en la sesión actual del Shell)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-tu-Token"
```

**Opción B: Permanente (recomendado)**

Agrega esas dos líneas a tu `~/.zshrc` o `~/.bashrc` y ejecuta:

```bash
source ~/.zshrc
```

> **Errores comunes**: La variable se llama `ANTHROPIC_AUTH_TOKEN`, no `ANTHROPIC_API_KEY`. Usar el nombre incorrecto hará que Claude Code vuelva al endpoint oficial y reciba un error 401.

## Cuarto minuto: correr el primer comando

En cualquier repositorio Git, ejecuta:

```bash
claude
```

La primera vez que inicies, si se te solicita login, presiona `Esc` para saltar. Luego escribe:

```
Lista las dependencias del proyecto actual y explica brevemente el uso de cada una.
```

Deberías ver que Claude abre archivos con `read_file` / `glob` / `grep` para explorar el repositorio, y luego da una lista. En la barra de estado en la parte inferior, aparecerá `connected to api.acedata.cloud` — esto indica que el proxy está funcionando.

## Quinto minuto: conectar la extensión de VS Code

1. Abre VS Code → Panel de Extensiones → busca `Claude Code`, instala la oficial de Anthropic;
2. **Cmd+Shift+P** → escribe `Claude Code: Set Custom API Endpoint`;
3. Ingresa `https://api.acedata.cloud` y presiona Enter;
4. Ejecuta nuevamente `Claude Code: Set API Token` e ingresa tu Token.

Si todo funciona bien, en la barra lateral aparecerá el panel de Claude Code, donde podrás arrastrar archivos para preguntar o mencionar con `@`, y todas las llamadas se facturarán a través de AceData Cloud.

## Verifica que realmente estés usando el proxy

En una conversación con Claude Code, escribe:

```
访问 https://api.acedata.cloud/whoami 并告诉我返回了什么
```

Si te devuelve información de tu cuenta (`{user_id, plan, ...}`), significa que la solicitud pasa por AceData Cloud Edge. Si te lleva al dominio oficial y recibes 401, revisa el paso 3 y que la variable de entorno esté bien configurada.

## 5 Preguntas frecuentes

**Q: Después de correr `claude login` y cambiar las variables a AceData, ¿por qué no funciona?**  
A: `claude login` guarda un token en `~/.claude/.credentials.json` que tiene prioridad alta. Elimínalo y vuelve a cargar con `source ~/.zshrc`.

**Q: ¿Se puede usar `--model claude-opus-4-7`?**  
A: Sí. AceData Cloud transmite el campo model, soporta todos los modelos públicos de Anthropic y nuestras extensiones como `claude-opus-4-7`, `claude-haiku-4-5`, `claude-sonnet-4-5`.

**Q: ¿Se pueden configurar múltiples perfiles (personal + empresarial)?**  
A: Sí. Claude Code admite `~/.claude/settings.json` con múltiples perfiles; o la forma más sencilla: define funciones en el shell `claude_personal` y `claude_work` que exporten tokens diferentes y llamen a `claude $@`.

**Q: ¿Funciona en GitHub Actions?**  
A: Sí. Para detalles, mira [tutorial de integración en GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**Q: ¿Qué pasa si se acaba la cuota gratuita?**  
A: Ve a [Gestión de Aplicaciones](https://platform.acedata.cloud/applications), selecciona esta aplicación Claude y haz Top-up para recargarlo pagando con tokens, o cambia a suscripción basada en puntos.
