## 1. Obtener API Key

Abre [la lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), accede a las aplicaciones disponibles y copia el API Key.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar Claude Code

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
```

Verifica después de la instalación:

```bash
claude --version
```

## 3. Configurar Ace Data Cloud

Para uso global, añade las siguientes variables a `~/.zshrc` o `~/.bashrc`：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="tu API Key"
unset ANTHROPIC_API_KEY
```

Reabre la terminal o `source` el archivo de configuración correspondiente.

Para que solo tenga efecto en el proyecto actual, puedes crear un `.claude/settings.local.json` que esté incluido en `.gitignore`：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "tu API Key"
  }
}
```

Elige una de las dos opciones. No escribas la clave real en el `.claude/settings.json` compartido por el equipo; si ya existe `ANTHROPIC_API_KEY` en el entorno, debe ser realmente eliminado, no solo establecido como una cadena vacía.

## 4. Iniciar y verificar

```bash
cd /path/to/your/project
claude
```

Una vez dentro, envía una tarea de solo lectura, como "lee README.md y resume en una frase". Los registros de llamadas y el saldo se pueden ver en [historial de uso](https://platform.acedata.cloud/console/usages) y [lista de aplicaciones](https://platform.acedata.cloud/console/applications).

Si devuelve 401, verifica si la clave está completa, si el antiguo `ANTHROPIC_API_KEY` ha sido eliminado y reinicia completamente Claude Code. El modelo no necesita estar fijado en la configuración de acceso, se puede seleccionar el modelo disponible actualmente en Claude Code.
