Claude Code es una herramienta de **Agentic Coding** lanzada por Anthropic, también conocida como uno de los agentes de programación más poderosos del mundo. La terminal CLI es la experiencia central de Claude Code, puedes ejecutar el comando `claude` en cualquier terminal y colaborar en programación con la IA a través del lenguaje natural.

Este documento describe principalmente cómo instalar, configurar y usar Claude Code CLI a través del servicio proxy de AceData Cloud en la terminal.

## Proceso de solicitud

Para usar Claude Code, primero puedes ir a la [página de servicio de Claude Messages](https://platform.acedata.cloud/documents/claude-messages) y hacer clic en el botón "Acquire" para obtener las credenciales necesarias para la solicitud:

![](https://cdn.acedata.cloud/nyq0xz.png)

Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión que te invita a registrarte e iniciar sesión, después de iniciar sesión o registrarte, serás devuelto automáticamente a la página actual.

En la primera solicitud, se te otorgará un crédito gratuito para que puedas experimentar el servicio de Claude Code de forma gratuita.

## Instalación de Claude Code

### Requisitos del sistema

- macOS, Linux o Windows (incluido WSL)
- Node.js no es necesario, el método de instalación nativa manejará automáticamente las dependencias

### Métodos de instalación

Claude Code admite varios métodos de instalación:

**Método 1: Instalación nativa (recomendado)**

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows CMD:

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**Método 2: Homebrew (macOS / Linux)**

```bash
brew install claude-code
```

**Método 3: WinGet (Windows)**

```cmd
winget install Claude.ClaudeCode
```

La instalación nativa se actualizará automáticamente en segundo plano, manteniéndose siempre en la última versión.

## Configuración de la API de AceData Cloud

Una vez completada la instalación, se te pedirá que inicies sesión en la cuenta oficial de Anthropic. Podemos usar la API proxy de AceData Cloud configurando variables de entorno, **sin necesidad de suscripción oficial**.

### Configuración de variables de entorno

Hay dos formas de configurar las variables de entorno, puedes elegir cualquiera de ellas.

**Método 1: Configurar en el archivo de configuración del Shell (recomendado)**

Agrega el siguiente contenido a tu archivo de configuración del Shell (`~/.zshrc`, `~/.bashrc` o `~/.bash_profile`), reemplazando `{token}` con el token de API que obtuviste en el panel de control de AceData Cloud:

```bash
# AceData Cloud - Configuración del proxy de Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Después de modificar, ejecuta el siguiente comando para que la configuración surta efecto:

```bash
source ~/.zshrc  # o source ~/.bashrc
```

**Método 2: Configurar en settings.json de Claude Code**

Edita `~/.claude/settings.json` (crea el archivo si no existe) y agrega la configuración `env`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

La ventaja de este método es que las variables de entorno solo afectan a Claude Code y no a otros programas.

> **Consejo**: El token de API se puede ver en el [panel de control de AceData Cloud](https://platform.acedata.cloud/console). El valor de `ANTHROPIC_AUTH_TOKEN` se enviará automáticamente al servidor con el prefijo `Bearer`.

## Comenzar a usar

### Iniciar modo interactivo

Abre la terminal, navega a tu directorio de proyecto y luego ejecuta:

```bash
cd /path/to/your/project
claude
```

Verás la pantalla de bienvenida de Claude Code, simplemente ingresa el lenguaje natural para comenzar la interacción.

### Comandos comunes

| Comando            | Descripción          | Ejemplo                   |
| ------------------ | ------------------- | ------------------------- |
| `claude`           | Iniciar modo interactivo | `claude`                 |
| `claude "tarea"`   | Ejecutar tarea única | `claude "arreglar error de construcción"` |
| `claude -p "consulta"` | Ejecutar consulta y salir | `claude -p "explicar esta función"` |
| `claude -c`       | Continuar la conversación más reciente en el directorio actual | `claude -c`              |
| `claude -r`       | Recuperar conversación anterior | `claude -r`              |
| `claude commit`    | Crear un commit de Git | `claude commit`          |

### Comandos en modo interactivo

En modo interactivo, puedes usar los siguientes comandos integrados:

| Comando            | Función            |
| ------------------ | ------------------ |
| `/help`            | Mostrar información de ayuda |
| `/clear`           | Limpiar el historial de conversación |
| `/config`          | Abrir el panel de configuración |
| `/model`           | Cambiar de modelo  |
| `/mcp`             | Administrar el servicio MCP |
| `/compact`         | Comprimir contexto  |
| `/memory`          | Administrar memoria |
| `/login`           | Cambiar de cuenta  |
| `exit` o `Ctrl+C` | Salir              |

### Ejemplos de interacción en conversación

```bash
# Analizar proyecto
> ¿qué hace este proyecto?

# Arreglar Bug
> hay un bug donde los usuarios pueden enviar formularios vacíos - arréglalo

# Escribir pruebas
> escribe pruebas unitarias para las funciones de la calculadora

# Refactorizar código
> refactoriza el módulo de autenticación para usar async/await

# Operaciones de Git
> confirma mis cambios con un mensaje descriptivo
> crea un pr para esta función
```

## Uso avanzado

### Canalización y scripting

Claude Code sigue la filosofía de Unix, soportando operaciones de canalización y scripting:

```bash
# Monitorear logs y alertar automáticamente
tail -f app.log | claude -p "si se detecta una anomalía, notifícame"

# Traducir automáticamente texto nuevo
claude -p "si hay nuevas cadenas de texto, tradúcelas al francés y crea un PR"

# Revisión de código
git diff main | claude -p "revisa estos cambios"
```

### Referencia de variables de entorno

A continuación se presentan las variables de entorno comunes que Claude Code admite:

| Variable                       | Descripción                                      |
| ------------------------------ | ------------------------------------------------ |
| `ANTHROPIC_AUTH_TOKEN`        | Valor del encabezado de autorización personalizado (se agrega automáticamente el prefijo Bearer) |
| `ANTHROPIC_API_KEY`           | Clave de API (enviada como encabezado X-Api-Key) |
| `ANTHROPIC_BASE_URL`          | URL base de la API                              |
| `ANTHROPIC_MODEL`             | Sobrescribir el modelo predeterminado           |
| `ANTHROPIC_SMALL_FAST_MODEL`  | Modelo de nivel Haiku (para tareas en segundo plano) |
| `MAX_THINKING_TOKENS`         | Establecer el presupuesto de tokens de pensamiento (establecer en 0 desactiva el modo de pensamiento) |
| `DISABLE_COST_WARNINGS`       | Establecer en 1 desactiva las advertencias de costos |

### Memoria del proyecto CLAUDE.md

Crea un archivo `CLAUDE.md` en el directorio raíz del proyecto para proporcionar instrucciones y contexto específicos del proyecto a Claude Code. Claude cargará automáticamente este archivo al iniciarse.

```markdown
# Descripción del proyecto
Este es un proyecto full-stack de Django + Vue.js.

## Normas de codificación
- Usar Python 3.12
- Seguir el estilo de código PEP 8
- Todas las API deben tener pruebas unitarias
```

## Preguntas frecuentes

### ¿Qué hacer si la conexión falla?
1. Verifica si el archivo `~/.claude/config.json` se ha creado correctamente, con el contenido `{"primaryApiKey": "self"}`
2. Confirma que las variables de entorno están configuradas correctamente:
   ```bash
   echo $ANTHROPIC_AUTH_TOKEN
   echo $ANTHROPIC_BASE_URL
   ```
3. Asegúrate de que el token de API sea válido (puedes verlo en [la consola](https://platform.acedata.cloud/console))
4. Intenta reiniciar la terminal

### command not found: claude

Si después de la instalación aparece `command not found`, intenta:

1. Cerrar y volver a abrir la terminal
2. Verificar el PATH: `echo $PATH`
3. Reinstalar: `curl -fsSL https://claude.ai/install.sh | bash`

### ¿Cómo ver el saldo restante?

Inicia sesión en [la consola de AceData Cloud](https://platform.acedata.cloud/console) para ver el saldo restante y el uso actual de tu cuenta.
