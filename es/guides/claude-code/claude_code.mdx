Claude Code se conecta al Coding Plan a través del protocolo Anthropic Messages, actualmente ofrece dos entradas de configuración: terminal y VS Code.

| Entrada de uso     | Guía de configuración                                                                                       |
| ------------------ | ---------------------------------------------------------------------------------------------------------- |
| Terminal / CLI     | [Configuración de Claude Code en terminal](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code            | [Configuración de Claude Code para VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## Configuración común

- URL base: `https://api.acedata.cloud`
- Token de API: obtener de la Aplicación de Coding y configurar a través de `ANTHROPIC_AUTH_TOKEN` en la guía
- ID del modelo: seleccionar del directorio de modelos en tiempo real
- Después de modificar la configuración: reiniciar Claude Code; los usuarios de VS Code necesitan recargar la ventana

No mantenga al mismo tiempo la antigua `ANTHROPIC_API_KEY`, ni escriba el Token real en archivos compartidos del equipo.

Regresar al [Centro de configuración de Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
