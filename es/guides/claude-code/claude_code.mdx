Claude Code es un agente inteligente de programación lanzado por Anthropic, que se puede utilizar en diversas entornos como terminal, IDE, aplicaciones de escritorio, etc. A través del proxy de AceData Cloud, puedes utilizar Claude Code a un precio más bajo.

Por favor, elige el tutorial de configuración correspondiente a tu escenario de uso:

| Plataforma          | Descripción                                 | Enlace del tutorial                                                                                          |
| ------------------ | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Terminal (CLI)** | Experiencia principal, simplemente ejecuta `claude` en cualquier terminal para comenzar | [Tutorial de configuración de terminal](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code**        | Extensión nativa, soporta Diff en línea, @-menciones, revisión programada | [Tutorial de configuración de VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **JetBrains IDE**  | Soporta toda la gama de IDEs como IntelliJ IDEA, PyCharm, WebStorm | [Tutorial de configuración de JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automatiza la revisión de código y el manejo de Issues con `@claude` | [Tutorial de configuración de GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Consejo**: Si es tu primera solicitud, puedes ir a la [página de servicios de Claude Messages](https://platform.acedata.cloud/documents/claude-messages) y hacer clic en "Acquire" para obtener un certificado, lo que te otorgará un crédito gratuito.
