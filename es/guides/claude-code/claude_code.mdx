Claude Code es un agente inteligente de programación desarrollado por Anthropic, que puede usarse en entornos como terminales, IDEs y pipelines de CI/CD. A través del proxy de AceData Cloud, puedes usar Claude Code a un costo menor.

Selecciona la guía de configuración completa correspondiente a tu escenario de uso:

| Plataforma | Descripción | Enlace a la guía |
|--------------|--------------|------------------|
| **VS Code** | Extensión nativa, soporta Diff en línea, @-menciones, revisión de planificación | [Guía de configuración de VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | Editor compatible con VS Code, soporte completo para la extensión Claude Code | [Guía de configuración de Cursor](https://platform.acedata.cloud/documents/development_cursor_coding) |
| **Terminal (CLI)** | Experiencia principal, simplemente ejecuta `claude` en cualquier terminal para comenzar | [Guía de configuración de Terminal](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **GitHub Actions** | Usa `@claude` para revisión automática de código y gestión de Issues | [Guía de configuración de GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Consejo**: Para la primera solicitud, puedes ir a la [página del servicio Claude Messages](https://platform.acedata.cloud/documents/claude-messages) y hacer clic en «Acquire» para obtener las credenciales, lo que te dará crédito gratuito.
