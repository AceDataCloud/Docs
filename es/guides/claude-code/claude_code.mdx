Claude Code es un agente inteligente de programación lanzado por Anthropic, que se puede utilizar en terminales, IDE, aplicaciones de escritorio y otros entornos. A través del proxy de AceData Cloud, puedes usar Claude Code a un costo más bajo.

> **¿Primera vez conectándote?** Se recomienda primero leer [Claude Code 5 minutos para empezar rápido](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) — desde obtener las credenciales hasta ejecutar el primer comando con éxito, en cinco pasos.

Elige el tutorial de configuración completo correspondiente a la plataforma según el escenario de uso:

| Plataforma | Descripción | Enlace al tutorial |
|------------|-------------|--------------------|
| **⚡ Inicio rápido en 5 minutos** | Desde obtener credenciales hasta el primer comando `claude`, completado en cinco pasos | [Tutorial de 5 minutos](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) |
| **Terminal (CLI)** | Experiencia principal, ejecuta `claude` en cualquier terminal para comenzar | [Tutorial de configuración para terminal](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code** | Extensión nativa, soporta Diff en línea, menciones @, revisión de planes | [Tutorial de configuración para VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | Editor compatible con VS Code, extensión Claude Code totalmente soportada | [Tutorial de configuración para Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **JetBrains IDE** | Soporta IntelliJ IDEA, PyCharm, WebStorm y toda la serie de IDEs | [Tutorial de configuración para JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automatiza revisión de código y gestión de Issues con `@claude` | [Tutorial de configuración para GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |
| **Aplicación de escritorio (Preview)** | Cliente gráfico independiente, soporta sesiones paralelas y conexión con herramientas externas | [Tutorial de configuración para aplicación de escritorio](https://platform.acedata.cloud/documents/claude-code-desktop-integration) |

> **Consejo**: Para la primera solicitud, visita la [página del servicio Claude Messages](https://platform.acedata.cloud/documents/claude-messages) y haz clic en "Acquire" para obtener credenciales, lo que incluye un crédito gratuito.
