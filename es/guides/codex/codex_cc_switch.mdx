---
title: "Guía de configuración de Codex CC Switch"
description: "Codex API guide - Ace Data Cloud"
---

CC Switch se puede gestionar a través de una interfaz gráfica para los proveedores y la clave API de Codex.

## 1. Obtener la clave API

Abre [la lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), accede a las aplicaciones disponibles y copia la clave API.

![Obtener la clave API de Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar CC Switch

Descarga e instala desde [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), o ejecuta en macOS:

```bash
brew install --cask cc-switch
```

## 3. Añadir proveedor

1. Abre CC Switch y cambia a **Codex**.
2. Haz clic en **Add Provider** y selecciona **Custom**.
3. Completa:

| Campo     | Contenido                        |
| --------- | ------------------------------- |
| Nombre    | `acedatacloud`                 |
| URL Base  | `https://api.acedata.cloud/v1` |
| Clave API | La clave API de Ace Data Cloud que copiaste anteriormente |

Si CC Switch proporciona un editor de configuración personalizada, la configuración debe mantenerse como:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"
requires_openai_auth = true
```

CC Switch guardará la clave API en `~/.codex/auth.json`:

```json
{
  "OPENAI_API_KEY": "{token}"
}
```

No añadas `env_key` o `[model_providers.acedatacloud.auth]` en el proveedor anterior; la configuración manual y la configuración de CC Switch son mutuamente excluyentes. No es necesario fijar `model`, simplemente selecciónalo directamente en Codex.

## 4. Habilitar y verificar

Habilita el proveedor `acedatacloud`, cierra completamente y reinicia Codex o VS Code. Ejecuta `/model`, confirma que el proveedor sea `acedatacloud`, luego selecciona un modelo y envía un mensaje simple.

Si devuelve 401, confirma que el proveedor habilitado sea `acedatacloud` y verifica si `OPENAI_API_KEY` en `~/.codex/auth.json` es la clave API de Ace Data Cloud que copiaste. Los registros de llamadas se pueden ver en [Historial de uso](https://platform.acedata.cloud/console/usages).
