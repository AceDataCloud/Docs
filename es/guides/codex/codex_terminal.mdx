## 1. Obtener API Key

Abre [la lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), accede a las aplicaciones disponibles y copia el API Key.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar Codex

```bash
npm install -g @openai/codex
```

## 3. Configurar API Key

macOS / Linux：

```bash
export ACEDATACLOUD_API_KEY="tu API Key"
```

Para que sea permanente, añade esta línea a `~/.zshrc` o `~/.bashrc`. Windows PowerShell usa:

```powershell
setx ACEDATACLOUD_API_KEY "tu API Key"
```

Después de configurarlo, reinicia la terminal.

## 4. Configurar AceDataCloud

Edita `~/.codex/config.toml` (en Windows es `%USERPROFILE%\.codex\config.toml`), añade:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

En Windows, cambia las dos últimas líneas a:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

No es necesario rellenar `model`; después de iniciar, puedes seleccionar el modelo en Codex. Las configuraciones existentes se pueden mantener, no crees un provider con el mismo nombre.

## 5. Iniciar

```bash
cd /path/to/your/project
codex
```

Una vez dentro de Codex, ejecuta `/model`, confirma que el Provider sea `acedatacloud`, y luego selecciona el modelo necesario. Los registros de llamadas y el saldo se pueden ver en [Historial de uso](https://platform.acedata.cloud/console/usages) y [Lista de aplicaciones](https://platform.acedata.cloud/console/applications).

Si aparece un mensaje de falta de Key o devuelve 401, confirma que la variable de entorno esté configurada, y cierra completamente antes de volver a abrir la terminal y Codex.
