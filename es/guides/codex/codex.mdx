description: "Codex 集成指南 - Ace Data Cloud"
---

Codex CLI es un agente de programación local de código abierto lanzado por OpenAI, que puede leer código, modificar archivos, ejecutar comandos y asistir en tareas de desarrollo directamente desde la terminal. A través del proxy de Ace Data Cloud, puedes usar Codex CLI a un costo menor, sin necesidad de suscribirte por separado a una cuenta oficial de OpenAI.

Elige el tutorial completo correspondiente según el escenario de uso:

| Plataforma | Descripción | Enlace al tutorial |
|------------|-------------|--------------------|
| **VS Code** | Extensión oficial, chat en la barra lateral del editor, referencia de archivos, vista previa de diff | [Tutorial de configuración para VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| **Terminal (CLI)** | Experiencia principal, ejecuta `codex` en cualquier terminal para comenzar | [Tutorial de configuración para terminal](https://platform.acedata.cloud/documents/codex-terminal-integration) |

> **Consejo**: Para la primera solicitud, puedes obtener un API Token en la [Consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications), lo que incluye un crédito gratuito. Codex CLI funciona a través de la interfaz compatible con OpenAI Responses de Ace Data Cloud (`/v1/responses`); para más información sobre modelos y facturación, consulta la [página de servicios OpenAI](https://platform.acedata.cloud/documents/openai).
