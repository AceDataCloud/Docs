Codex CLI, Desktop y la extensión de VS Code comparten `~/.codex/config.toml`. Configura una vez el proveedor `acedatacloud`, y podrás usar Codex a través de Ace Data Cloud.

| Modo de Uso      | Guía de Configuración                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------- |
| Terminal / CLI   | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)          |
| Desktop          | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)       |
| VS Code          | [Codex para VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)  |
| Cambio Gráfico   | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration)   |

La configuración común solo tiene tres elementos:

- Proveedor: `acedatacloud`
- URL Base: `https://api.acedata.cloud/v1`
- Clave API: obtenida de [lista de aplicaciones](https://platform.acedata.cloud/console/applications) y guardada en `ACEDATACLOUD_API_KEY`

No es necesario fijar el modelo en la configuración de acceso; después de iniciar Codex, puedes seleccionar el modelo directamente.

Regresar al [Centro de Configuración de Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
