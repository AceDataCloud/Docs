title: "Guía de configuración de Codex para VS Code"
description: "Codex API guide - Ace Data Cloud"
---

La extensión Codex para VS Code comparte `~/.codex/config.toml` con Codex CLI.

## 1. Obtener la clave API

Abre la [lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), accede a la aplicación disponible y copia la clave API.

![Obtener la clave API de Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar la extensión

Instala **Codex – OpenAI's coding agent** publicado por OpenAI en el mercado de extensiones de VS Code, o ejecuta:

```bash
code --install-extension openai.chatgpt
```

## 3. Configurar la clave API

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="tu clave API"
```

Para que sea permanente, añade esta línea a `~/.zshrc` o `~/.bashrc`. En Windows PowerShell usa:

```powershell
setx ACEDATACLOUD_API_KEY "tu clave API"
```

## 4. Configurar AceDataCloud

Edita `~/.codex/config.toml` (en Windows es `%USERPROFILE%\.codex\config.toml`), añade:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

En Windows, cambia las dos últimas líneas a:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

No es necesario rellenar `model`; puedes seleccionar el modelo en el panel de Codex.

## 5. Reiniciar y verificar

Cierra completamente y vuelve a abrir VS Code, luego abre el panel de Codex. Ejecuta `/model`, confirma que el Provider sea `acedatacloud`, y luego envía un mensaje simple; los registros de llamadas se pueden ver en [Historial de uso](https://platform.acedata.cloud/console/usages).

Si la extensión no puede leer la clave, inicia VS Code desde una terminal donde se haya configurado la variable de entorno, o configura la variable de entorno a nivel del sistema y reinicia VS Code. Remote SSH, WSL y Dev Container necesitan ser configurados en el entorno donde se ejecuta realmente la extensión.
