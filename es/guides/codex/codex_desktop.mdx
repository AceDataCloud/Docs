title: "Guía de configuración de Codex Desktop"
description: "Codex API guide - Ace Data Cloud"
---

Codex Desktop comparte `~/.codex/config.toml` con Codex CLI.

## 1. Obtener API Key

Abre la [lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), accede a la aplicación disponible y copia la API Key.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configurar API Key

macOS：

```bash
launchctl setenv ACEDATACLOUD_API_KEY "tu API Key"
```

Windows PowerShell：

```powershell
setx ACEDATACLOUD_API_KEY "tu API Key"
```

## 3. Configurar AceDataCloud

Edita `~/.codex/config.toml` (en Windows es `%USERPROFILE%\.codex\config.toml`), añade:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

En Windows, cambia las dos últimas líneas a:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

No es necesario llenar `model`; abre Codex y selecciona el modelo directamente.

## 4. Reiniciar y verificar

Cierra completamente y vuelve a abrir Codex Desktop, crea una tarea local y envía un mensaje simple. El proveedor debería mostrarse como `acedatacloud`; las llamadas reales se pueden ver en [historial de uso](https://platform.acedata.cloud/console/usages).

Si la configuración no tiene efecto, asegúrate de que has modificado el `~/.codex/config.toml` del usuario actual, que la variable de entorno está configurada y luego reinicia completamente la aplicación. Las tareas en la nube o la automatización que se ejecutan en diferentes entornos necesitan configurar la Key por separado en el entorno correspondiente.
