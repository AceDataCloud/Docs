La API Claude Messages Count Tokens puede calcular la cantidad de Tokens de entrada de un Message sin crear realmente un mensaje, incluyendo el conteo de Tokens de herramientas, imágenes y documentos, entre otros contenidos. Esto es muy útil cuando se necesita estimar costos o verificar si la entrada excede el límite de contexto del modelo.

Este documento presenta principalmente el proceso de uso de la API Claude Messages Count Tokens.

## Proceso de solicitud

Para usar la API Claude Messages Count Tokens, primero obtenga su API Token en la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) y guárdelo para usarlo posteriormente.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no ha iniciado sesión o no se ha registrado, será redirigido automáticamente a la página de inicio de sesión, donde se le invitará a registrarse e iniciar sesión; al completarlo, volverá automáticamente a la página actual.

**Un solo API Token permite invocar todos los servicios de la plataforma, sin necesidad de solicitar uno por separado para cada servicio.** La primera solicitud incluye créditos gratuitos para experimentar sin costo; cuando los créditos sean insuficientes, puede recargar saldo general en la [consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Uso básico

La ruta de solicitud de la API Claude Messages Count Tokens es `/v1/messages/count_tokens`, y se mantiene consistente con la API oficial de Anthropic. Como mínimo, necesitamos proporcionar dos parámetros obligatorios:

- `model`: seleccionar el modelo Claude que se utilizará, como el más reciente modelo insignia `claude-fable-5-1`; el anterior `claude-fable-5` sigue siendo compatible y se conserva.
- `messages`: el arreglo de mensajes de entrada; cada mensaje contiene `role` (rol) y `content` (contenido).

Parámetros opcionales comunes:

- `system`: prompt del sistema, que se incluirá en la cantidad de Tokens.
- `tools`: definición de herramientas, que se incluirá en la cantidad de Tokens.
- `thinking`: configuración de pensamiento extendido.
- `tool_choice`: configuración de selección de herramientas.
- `cache_control`: configuración de control de caché de nivel superior o de bloque de contenido.

`messages`, `system`, la reproducción de llamadas de herramientas, las imágenes URL y los bloques de contenido document/PDF utilizan la misma estructura de solicitud estable que la API Messages.

### Ejemplo de cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Ejemplo de Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Ejemplo de resultado devuelto:

```json
{
  "input_tokens": 11
}
```

### Uso del SDK de Anthropic

La API Claude Messages Count Tokens acepta la estructura de solicitud estable del SDK de Anthropic y puede invocarse mediante la biblioteca `anthropic`. La interfaz utiliza la capacidad nativa Count Tokens correspondiente al modelo seleccionado para contar la entrada, y puede utilizarse para verificar el tamaño de la entrada antes de enviar una solicitud de Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Conteo de Tokens que incluye herramientas

Si su solicitud incluye definiciones de herramientas, estas también se incluirán en la cantidad de Tokens:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Conteo de Tokens que incluye prompts del sistema

Los prompts del sistema también se incluirán en la cantidad de Tokens:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Consideraciones

- Esta API solo calcula la cantidad de Tokens de entrada y no generará ninguna salida del modelo.
- El resultado del conteo de Tokens puede utilizarse para estimar el tamaño de la entrada y verificar la ventana de contexto; la facturación final se basa en el `usage` de la respuesta real de Messages.
- Las imágenes, PDF, definiciones de herramientas, prompts del sistema y la configuración de thinking se incluirán en el resultado según las reglas de entrada del modelo seleccionado.
- Esta API es completamente gratuita y no consume ningún crédito.
