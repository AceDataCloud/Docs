La API Claude Messages Count Tokens puede calcular la cantidad de Tokens de entrada de un Message sin crear realmente un mensaje, incluyendo el conteo de Tokens de contenidos como herramientas, imágenes y documentos. Esto es muy útil cuando se necesita estimar costos o verificar si la entrada excede el límite de contexto del modelo.

Este documento presenta principalmente el proceso de uso de la API Claude Messages Count Tokens.

`claude-fable-5-2` actualmente no proporciona una interfaz Count Tokens. El uso final de las solicitudes generadas puede consultarse en `usage` de la respuesta de Messages; no utilice los resultados de conteo de otros modelos como sustituto del uso preciso de este modelo.

## Proceso de solicitud

Para usar la API Claude Messages Count Tokens, primero obtenga su API Token en la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) y guárdelo como respaldo.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no ha iniciado sesión o no se ha registrado, será redirigido automáticamente a la página de inicio de sesión para invitarlo a registrarse e iniciar sesión; al finalizar, regresará automáticamente a la página actual.

**Un solo API Token puede llamar a todos los servicios de la plataforma, sin necesidad de solicitar uno por separado para cada servicio.** La primera solicitud incluye crédito gratuito, que permite una experiencia gratuita; cuando el crédito sea insuficiente, puede recargar el saldo general en la [consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Uso básico

La ruta de solicitud de la API Claude Messages Count Tokens es `/v1/messages/count_tokens`, y se mantiene coherente con la API oficial de Anthropic. Necesitamos proporcionar al menos dos parámetros obligatorios:

- `model`: complete el ID completo del modelo en la lista de modelos de esta interfaz, y utilice el mismo modelo para las solicitudes posteriores de Messages.
- `messages`: el arreglo de mensajes de entrada, donde cada mensaje incluye `role` (rol) y `content` (contenido).

Parámetros opcionales comunes:

- `system`: prompt del sistema, se incluirá en la cantidad de Tokens.
- `tools`: definición de herramientas, se incluirá en la cantidad de Tokens.
- `thinking`: configuración de pensamiento extendido.
- `tool_choice`: configuración de selección de herramientas.
- `cache_control`: configuración de control de caché de nivel superior o de bloque de contenido.

Los bloques de contenido de `messages`, `system`, reproducción de llamadas de herramientas, imágenes URL y documentos/PDF utilizan la misma estructura de solicitud estable que la API Messages.

### Ejemplo de cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Ejemplo de Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Ejemplo de resultado devuelto:

```json
{
  "input_tokens": 11
}
```

### Uso del SDK de Anthropic

La API Claude Messages Count Tokens acepta la estructura de solicitud estable del SDK de Anthropic y se puede llamar mediante la biblioteca `anthropic`. La interfaz cuenta los Tokens de entrada según el modelo seleccionado, y puede usarse para verificar el tamaño de la entrada antes de enviar una solicitud de Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Conteo de Tokens que incluye herramientas

Si su solicitud incluye definiciones de herramientas, estas herramientas también se incluirán en la cantidad de Tokens:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Conteo de Tokens que incluye prompts del sistema

Los prompts del sistema también se incluirán en la cantidad de Tokens:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Consideraciones

- Esta API solo calcula la cantidad de Tokens de entrada y no generará ninguna salida del modelo.
- Los resultados del conteo de Tokens pueden usarse para estimar la escala de entrada y verificar la ventana de contexto; la facturación final se basará en `usage` de la respuesta real de Messages.
- Las imágenes, los PDF, las definiciones de herramientas, los prompts del sistema y la configuración de thinking se incluirán en el resultado según las reglas de entrada del modelo seleccionado.
- Esta API es completamente gratuita y no consume ningún crédito.
