Este documento presentará las instrucciones de integración de la API de Veo Upsample. Esta interfaz se utiliza para realizar un upsampling de un video de Veo ya generado o para generar una vista previa en formato GIF.

## Proceso de Solicitud

Para utilizar la API, primero debes solicitarla en la página correspondiente del servicio Veo. Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión.

## Uso Básico

Para llamar a esta interfaz, se deben pasar dos parámetros:

- `video_id`: ID de tarea del video de origen. Puede ser un ID de video generado por cualquiera de las interfaces `/veo/videos`, `/veo/extend`, `/veo/reshoot`, `/veo/objects`.
- `action`: acción de upsampling, soporta las siguientes tres opciones:
  - `1080p`: eleva la resolución del video a 1080p.
  - `4k`: eleva la resolución del video a 4K.
  - `gif`: convierte el video en una vista previa en formato GIF.

Ejemplo de solicitud:

```shell
curl -X POST 'https://api.acedata.cloud/veo/upsample' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "4k"
  }'
```

El resultado devuelto es el mismo que el de `/veo/videos`, sigue siendo una estructura de tarea asíncrona, y se puede consultar el estado de la tarea a través de `task_id` en la interfaz `/veo/tasks`:

```json
{
  "success": true,
  "task_id": "8f5a90ae-3f86-4c4f-86f7-7126f5e92c76",
  "trace_id": "0f3e09c2-4c2e-46ea-9cdc-a31ec48b7c12",
  "data": [
    {
      "id": "253eedc47f1c4eb2a370ed2312168f4b",
      "video_url": "https://platform.cdn.acedata.cloud/veo/8f5a90ae.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

Descripción de los campos devueltos:

- `success`: indica si la tarea de upsampling se ha enviado con éxito.
- `task_id`: ID de la tarea de upsampling actual.
- `data`: resultados del video después del upsampling.
  - `video_url`: dirección del video después del upsampling.

## Descripción de Facturación

- `action=1080p`: 0.16 Crédito / vez
- `action=4k`: 0.50 Crédito / vez
- `action=gif`: 0.13 Crédito / vez

Si el `action` proporcionado no está en las enumeraciones anteriores, se cobrará por defecto como 0.50 Crédito. Se recomienda pasar explícitamente los valores soportados.

## Callback Asíncrono

La interfaz también soporta modo asíncrono, pasando `callback_url` se puede recibir el resultado a través de una solicitud POST una vez que la tarea se complete. Si no hay una dirección de callback pública, también se puede establecer `async` como `true`, la interfaz devolverá inmediatamente `task_id`, y luego se puede obtener el resultado mediante la interfaz de consulta de tareas correspondiente.
