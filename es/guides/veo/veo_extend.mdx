Este documento presentará las instrucciones para la integración de la API de Veo Extend. Esta interfaz se utiliza para **extender la duración** de un video de Veo ya generado, la IA automáticamente continuará escribiendo las escenas posteriores.

## Proceso de Solicitud

Para utilizar la API, primero debes solicitar en la página correspondiente del servicio Veo. Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión.

## Uso Básico

Para llamar a esta interfaz, se deben pasar los siguientes parámetros:

- `video_id` (obligatorio): ID de tarea del video de origen (proveniente de `/veo/videos` o de esta misma interfaz).
- `model` (obligatorio): modelo utilizado para la extensión, **solo se admiten los modelos `veo31-fast` y `veo31`**, otros modelos no son compatibles.
- `prompt` (opcional): texto de indicación para guiar las escenas de la extensión.
- `aspect_ratio` (opcional): `16:9` o `9:16`, por defecto `16:9`.
- `resolution` (opcional): `720p` o `1080p`.

Ejemplo de solicitud:

```shell
curl -X POST 'https://api.acedata.cloud/veo/extend' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "model": "veo31-fast",
    "prompt": "la cámara se aleja lentamente para revelar más del paisaje"
  }'
```

El resultado devuelto es el mismo que el de `/veo/videos`:

```json
{
  "success": true,
  "task_id": "5fa2d9a6-7e54-481b-a4b0-3dc6f25dd2ab",
  "data": [
    {
      "id": "9b6f3b6b9c45419fbf2e3fe2f10b2b3a",
      "video_url": "https://platform.cdn.acedata.cloud/veo/5fa2d9a6.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

## Restricciones Importantes

El `video_id` debe provenir de la generación de la línea actual de `/veo/videos` o del `data[].id` después de completar la extensión. Los ID de video generados en líneas históricas anteriores no se pueden utilizar con esta interfaz, al llamar se devolverá `400 bad_request`; por favor, vuelve a generar a través de `/veo/videos` antes de extender.

Los videos de resultados de extensión provenientes de `/veo/extend` pueden **ser extendidos nuevamente con `/veo/extend`**, pero **no pueden** ser procesados por las siguientes interfaces:

- `/veo/reshoot` —— no se puede cambiar el movimiento de la cámara
- `/veo/objects` —— no se pueden agregar o eliminar objetos

Si el `video_id` proporcionado es un resultado de extensión, las interfaces relacionadas devolverán un error 400, por favor utiliza el video original como fuente.

## Información de Facturación

- `model=veo31-fast`: 1.68 Crédito / vez
- `model=veo31`: 12.00 Crédito / vez

## Callback Asíncrono

La interfaz admite modo asíncrono, al pasar `callback_url` se puede recibir el resultado a través de una solicitud POST una vez que la tarea se complete. Si no hay una dirección de callback pública, también se puede establecer `async` como `true`, la interfaz devolverá inmediatamente `task_id`, y luego se puede consultar el resultado mediante la interfaz de consulta de tareas correspondiente.
