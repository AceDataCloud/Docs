Este documento presentará la integración de la API de Veo Reshoot. Esta interfaz se utiliza para **regenerar un video de Veo ya generado** de acuerdo con **un nuevo tipo de movimiento de cámara**, manteniendo el contenido visual consistente, pero la posición y el movimiento de la cámara se reinterpretarán según `motion_type`.

## Proceso de Solicitud

Para utilizar la API, primero debes solicitar en la página correspondiente del servicio de Veo. Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión.

## Uso Básico

Para llamar a esta interfaz, se deben pasar los siguientes parámetros:

- `video_id` (obligatorio): ID de tarea del video de origen. **No puede** ser un video de salida de `/veo/extend`.
- `motion_type` (obligatorio): nuevo tipo de movimiento de cámara, utilizando un alias conciso en estilo de subrayado en mayúsculas.

### Valores soportados para `motion_type`

| Alias                             | Significado           |
| ------------------------------ | -------------------- |
| `STATIONARY`                   | Cámara fija           |
| `STATIONARY_UP`                | Cámara fija, inclinación hacia arriba |
| `STATIONARY_DOWN`              | Cámara fija, inclinación hacia abajo |
| `STATIONARY_LEFT`              | Cámara fija, paneo a la izquierda |
| `STATIONARY_RIGHT`             | Cámara fija, paneo a la derecha |
| `STATIONARY_DOLLY_IN_ZOOM_OUT` | Cámara fija, empuje hacia adelante + zoom out |
| `STATIONARY_DOLLY_OUT_ZOOM_IN` | Cámara fija, retroceso + zoom in |
| `UP`                           | Cámara ascendiendo    |
| `DOWN`                         | Cámara descendiendo    |
| `LEFT_TO_RIGHT`                | Cámara desplazándose de izquierda a derecha |
| `RIGHT_TO_LEFT`                | Cámara desplazándose de derecha a izquierda |
| `FORWARD`                      | Cámara avanzando      |
| `BACKWARD`                     | Cámara retrocediendo   |
| `DOLLY_IN_ZOOM_OUT`            | Empuje hacia adelante + zoom out en movimiento |
| `DOLLY_OUT_ZOOM_IN`            | Retroceso + zoom in en movimiento |

Ejemplo de solicitud:

```shell
curl -X POST 'https://api.acedata.cloud/veo/reshoot' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "motion_type": "LEFT_TO_RIGHT"
  }'
```

La estructura del resultado devuelto es la misma que la de `/veo/videos`.

## Información de Facturación

- Regrabación única: 1.20 Crédito.

## Callback Asíncrono

La interfaz soporta modo asíncrono, pasando `callback_url` se puede recibir el resultado a través de una solicitud POST una vez que la tarea esté completada. Si no hay una dirección de callback pública, también se puede establecer `async` como `true`, la interfaz devolverá inmediatamente `task_id`, y luego se puede obtener el resultado mediante la interfaz de consulta de tareas correspondiente.
