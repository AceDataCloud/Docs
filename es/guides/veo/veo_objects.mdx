Este documento presentará las instrucciones de integración de la API de Veo Objects. Esta interfaz se utiliza para realizar operaciones de **adición o eliminación de objetos** en un video de Veo ya generado (repaint local basado en máscara).

## Proceso de solicitud

Para utilizar la API, primero debe solicitar en la página correspondiente del servicio Veo. Si aún no ha iniciado sesión o registrado, será redirigido automáticamente a la página de inicio de sesión.

## Uso básico

Para llamar a esta interfaz, se deben pasar los siguientes parámetros:

- `video_id` (obligatorio): ID de tarea del video de origen. **No puede** ser el video de salida de `/veo/extend`.
- `action` (obligatorio): tipo de operación, `insert` o `remove`.
- `prompt`:
  - `action=insert`: **obligatorio**, descripción del objeto a añadir.
  - `action=remove`: opcional, descripción del contenido a eliminar (principalmente para registro, el área real de borrado está determinada por `image_mask`).
- `image_mask`:
  - `action=insert`: opcional. Si no se pasa, la IA decidirá automáticamente la ubicación de inserción; si se pasa, se insertará en el área de píxeles blancos.
  - `action=remove`: **obligatorio**, el área de píxeles blancos es el objeto a borrar.

`image_mask` acepta dos formatos:

1. Una **dirección de imagen HTTP(S) accesible públicamente** (recomendado).
2. **Cadena JPEG codificada en base64**, que puede llevar el prefijo `data:image/jpeg;base64,` o ser base64 puro.

Ejemplo de solicitud (insertar objeto, no pasar máscara, dejar que la IA localice automáticamente):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "insert",
    "prompt": "add a flying pig with black wings"
  }'
```

Ejemplo de solicitud (eliminar objeto según máscara):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "remove",
    "image_mask": "https://example.com/mask.jpg",
    "prompt": "remove the white cloud"
  }'
```

La estructura de los resultados devueltos es la misma que la de `/veo/videos`.

## Instrucciones de facturación

- `action=insert` o `remove`: 1.50 Crédito / vez.

## Callback asíncrono

La interfaz admite modo asíncrono, pasando `callback_url` se puede recibir el resultado a través de una solicitud POST una vez que la tarea se complete. Si no hay una dirección de callback pública, también se puede establecer `async` en `true`, la interfaz devolverá inmediatamente `task_id`, y luego se puede consultar el resultado mediante la interfaz de consulta de tareas correspondiente.
