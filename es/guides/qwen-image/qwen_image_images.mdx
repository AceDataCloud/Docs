---
title: "API de generación y edición de imágenes Qwen"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` permite completar la generación de imágenes a partir de texto y la edición de 1 a 3 imágenes de referencia a través de la misma interfaz, soportando `qwen-image-3.0` y `qwen-image-3.0-pro`.

## Selección de modelo

| Modelo                  | Escenario adecuado       | Precio estándar oficial                   |
| ---------------------- | --------------------- | ------------------------------------- |
| `qwen-image-3.0`      | Creación en lote, iteración rápida  | Salida $0.030/imágen             |
| `qwen-image-3.0-pro`  | Composición compleja, alta precisión | 1K $0.040/imágen; 2K $0.075/imágen |

Las imágenes de referencia se cobran según la cantidad de entradas reales, precio estándar oficial $0.003/imágen.

## Generación sincrónica

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "Un simple círculo rojo centrado en un fondo blanco limpio.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

La respuesta exitosa incluye la dirección de la imagen en CDN permanente, uso real y costo de esta vez:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Edición de imágenes de referencia

Agregue `image_urls`, soportando de 1 a 3 imágenes accesibles públicamente:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "Conservar el sujeto, cambiar el fondo a un estilo de cartel cálido **###**",
  "image_urls": ["https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` se utiliza solo para la generación de imágenes a partir de texto. El rango de `n` es de 1 a 6; la relación de aspecto debe estar entre 1:8 y 8:1.

## Tareas asíncronas

Al establecer `async: true`, la interfaz devuelve inmediatamente `task_id`. Utilice `/qwen-image/tasks` para consultar el estado final, o pase `callback_url` para recibir notificaciones de finalización. La generación solo se cobra una vez, la consulta de tareas no incurre en cargos repetidos.
