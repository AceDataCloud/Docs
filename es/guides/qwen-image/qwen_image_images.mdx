---
title: "Guía de integración de la API de imágenes Qwen"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` soporta la generación de imágenes a partir de texto y la edición de 1 a 3 imágenes de referencia para `qwen-image-3.0` y `qwen-image-3.0-pro`.

## Generación de imágenes a partir de texto

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen-image-3.0","prompt":"un cartel tecnológico minimalista","size":"1024*1024","n":1}'
```

## Edición de imágenes

Agregue `image_urls` en la misma solicitud, soportando de 1 a 3 imágenes públicas:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "mantener el sujeto, cambiar a un estilo de cartel cálido**###**",
  "image_urls": ["https://cdn.acedata.cloud/r9vsv9.png"],
  "size": "2048*2048",
  "prompt_extend": true,
  "prompt_extend_mode": "direct",
  "enable_thinking": true,
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` solo soporta la generación de imágenes a partir de texto. El rango de `n` es de 1 a 6. El tamaño total de salida debe estar entre 512×512 y 2048×2048, con una relación de aspecto de 1:8 a 8:1.

## Llamadas asíncronas

Configurar `async: true` permite obtener inmediatamente `task_id`; también se puede pasar `callback_url` para recibir el resultado final. Después de completar, consulte a través de `/qwen-image/tasks`.

La respuesta exitosa incluye `data[].image_url`, `usage`, `task_id` y `trace_id`. Los enlaces de las imágenes se almacenarán en la medida de lo posible en el CDN de Ace Data Cloud. Un ejemplo de respuesta real se añadirá después de la validación E2E en producción.
