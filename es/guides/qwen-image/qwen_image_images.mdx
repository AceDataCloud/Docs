---
title: "API de generación y edición de imágenes de Qwen"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` completa la generación de texto a imagen y la edición con 1–3 imágenes de referencia mediante la misma interfaz, compatible con `qwen-image-3.0` y `qwen-image-3.0-pro`.

## Selección de modelo

| Modelo               | Escenarios adecuados                 | Precio estándar oficial          |
| -------------------- | ------------------------------------ | ------------------------------- |
| `qwen-image-3.0`     | Creación por lotes, iteración rápida | Salida $0.030/imagen            |
| `qwen-image-3.0-pro` | Maquetación compleja, resultado final de alta precisión | 1K $0.040/imagen; 2K $0.075/imagen |

Las imágenes de referencia se cobran según la cantidad real de entradas, con un precio estándar oficial de $0.003/imagen.

## Generación síncrona

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "A simple red circle centered on a clean white background.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

La respuesta exitosa incluye una dirección de imagen CDN permanente, el uso real y el coste de esta solicitud:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Edición con imágenes de referencia

Añada `image_urls`, compatible con 1–3 imágenes públicamente accesibles:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "保留主体，将背景改成暖色电影海报风格",
  "image_urls": ["https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` se utiliza únicamente para la generación de texto a imagen. El rango de `n` es de 1–6; la relación de aspecto debe estar entre 1:8 y 8:1.

## Tareas asíncronas

Después de establecer `async: true`, la interfaz devuelve inmediatamente `task_id`. Utilice `/qwen-image/tasks` para consultar el estado final, o proporcione `callback_url` para recibir una notificación de finalización. La generación se liquida solo una vez y las consultas de tareas no se cobran repetidamente.
