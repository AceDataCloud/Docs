---
title: "Guía de integración de la API de tareas de Qwen Image"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

Utilice `POST https://api.acedata.cloud/qwen-image/tasks` para consultar tareas de generación de imágenes asíncronas. Esta interfaz de consulta es gratuita.

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Para consultas por lotes, utilice `action=retrieve_batch` y el array `ids`. Una vez que la tarea se complete con éxito, `response.data` contendrá la dirección permanente de la imagen generada y el uso real.
