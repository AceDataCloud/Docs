---
title: "API de consulta de tareas de Qwen Image"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/tasks` se utiliza para consultar, consultar en lotes o eliminar tareas asíncronas de Qwen Image. Esta interfaz no genera consumo adicional de API.

## Consulta de una sola tarea

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Una vez que la tarea se complete, `response.data` contendrá la dirección de la imagen CDN permanente, `response.usage` incluirá la cantidad real de entradas/salidas, y `response.cost` será la información de liquidación de la tarea generada.

## Consulta en lote

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Devuelve `{ "items": [...], "count": 2 }`. La consulta de lista también admite filtrado por usuario, aplicación y rango de tiempo de creación.

## Eliminar registros de tareas

```json
{"action":"delete","id":"TASK_ID"}
```

La eliminación solo afecta el historial de tareas y no eliminará los archivos CDN ya generados.
