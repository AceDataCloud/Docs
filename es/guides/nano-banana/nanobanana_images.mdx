Este documento presenta la integración y el uso de la API de Nano Banana Images. Esta interfaz admite dos funcionalidades: **generación de imágenes (generate)** y **edición de imágenes (edit)**.

## Proceso de solicitud

Para utilizar la API de Nano Banana Images, primero acceda a la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obtener su API Token y guardarlo para utilizarlo posteriormente.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no ha iniciado sesión o no se ha registrado, el sistema le redirigirá automáticamente a la página de inicio de sesión para invitarle a registrarse e iniciar sesión. Una vez completado el proceso, regresará automáticamente a la página actual.

**Un solo API Token permite acceder a todos los servicios de la plataforma, sin necesidad de solicitar uno por separado para cada servicio.** Al realizar la primera solicitud, recibirá una cuota gratuita para probar el servicio sin coste. Cuando el saldo sea insuficiente, podrá recargar el saldo general en la [consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [API de Nano Banana Images →](https://platform.acedata.cloud/documents/nano-banana-images)

## Descripción general de la interfaz

- **URL base**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **Método de autenticación**：Incluir `authorization: Bearer {token}` en el encabezado HTTP.
- **Encabezados de la solicitud**：
  - `accept: application/json`
  - `content-type: application/json`
- **Acción (action)**：
  - `generate`：Generar imágenes a partir de indicaciones de texto.
  - `edit`：Editar imágenes basándose en las imágenes proporcionadas.
- **Modelo (model)** (opcional)：
  - `nano-banana` (predeterminado)：Basado en Gemini 2.5 Flash Image, ofrece una velocidad rápida y un coste bajo.
  - `nano-banana-2-lite`：Basado en Gemini 3.1 Flash Lite Image, solo admite 1K y ofrece una velocidad de generación rápida.
  - `nano-banana-2`：Basado en Gemini 3.1 Flash Image Preview, ofrece calidad de nivel Pro y velocidad Flash.
  - `nano-banana-2.1`：Modelo de imágenes eficiente de nueva generación, compatible con generación y edición de imágenes en 1K, 2K y 4K.
  - `nano-banana-pro`：Basado en Gemini 3 Pro Image Preview, ofrece la máxima calidad.
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`：Versiones del canal oficial de los modelos correspondientes, con mejor calidad de imagen y estabilidad, y tarifas diferentes.
- **Callback asíncrono**：Opcional. Reciba notificaciones de finalización de tareas y resultados mediante `callback_url`.
- **Cantidad de imágenes**：Opcional. Utilice `count` para especificar entre 1 y 4 imágenes; el valor predeterminado es 1. Cada imagen se genera mediante una llamada independiente. Los fallos técnicos normales o los rechazos de seguridad del proveedor solo afectan a la llamada correspondiente; las demás imágenes generadas correctamente se devuelven con normalidad y se cobra según la cantidad real de imágenes generadas correctamente.

## Inicio rápido: Generar imágenes (`action=generate`)

**Parámetros mínimos obligatorios**：`action`、`prompt`

Cuando solo desee generar directamente una imagen a partir de una indicación, basta con establecer `action` en `generate` y proporcionar un `prompt` claro.

### Ejemplo de solicitud (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Ejemplo de solicitud (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

```json
{
  "success": true,
  "task_id": "70e6931b-6e34-43db-9e36-8765e2809d04",
  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {
      "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
      "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }
  ]

```

### Descripción de los campos

- `success`：Indica si la solicitud actual se ha realizado correctamente.
- `task_id`：ID de la tarea.
- `trace_id`：ID de seguimiento de la cadena de ejecución, que facilita la investigación de problemas.
- `count`：Cantidad de imágenes solicitadas para generar o editar. Admite de 1 a 4 imágenes y el valor predeterminado es 1. `data` solo contiene las imágenes generadas correctamente y la facturación se realiza según la cantidad real de imágenes devueltas. Cada llamada de generación aplica obligatoriamente las políticas de seguridad nativas del proveedor; si una llamada es rechazada, esto no afecta a las demás llamadas que se completen correctamente. Si todas las llamadas son rechazadas, se devuelve un error 403.
- `data[]`：Lista de resultados.
  - `prompt`：Indicación utilizada para la generación (devuelta en la respuesta).
  - `image_url`：URL directa de la imagen generada.

> Nota: `/nano-banana/images` solo requiere `action` y `prompt` para generar imágenes.

## Editar imágenes (`action=edit`)

Cuando desee editar una imagen existente, establezca `action` en `edit` y proporcione la lista de enlaces de las imágenes que desea editar mediante `image_urls` (una o varias imágenes), junto con un `prompt` que describa el objetivo de la edición.

Por ejemplo, aquí proporcionamos una fotografía de una persona y una fotografía de una prenda de vestir. Para que la persona lleve esa prenda, podemos introducir simultáneamente los enlaces de ambas imágenes y especificar `action` como `edit`. La URL puede ser una URL HTTP, es decir, un enlace público accesible mediante el protocolo `https` o `http`, o también puede ser una imagen codificada en Base64, como `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Ejemplo de solicitud (cURL)
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Ejemplo de solicitud (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Ejemplo de respuesta exitosa

```json

  "task_id": "93f11baf-347b-4bb4-9520-8653cb46d6a3",
  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",
  "data": [
    {
      "prompt": "let this man wear on this T-shirt",

    }

```

### Descripción de los campos

- `image_urls[]`: Lista de URL de las imágenes que se van a editar (deben ser accesibles públicamente). Se pueden proporcionar varias imágenes y el servicio combinará estos materiales con `prompt` para completar la edición.
- Los demás campos son iguales a los de la respuesta de «Generar imagen».

## Devolución de llamada asíncrona (opcional, recomendada)

La generación o edición puede requerir cierto tiempo. Para evitar que las conexiones prolongadas ocupen recursos, se recomienda utilizar **devoluciones de llamada Webhook** mediante `callback_url`:

1. Añade `callback_url` al cuerpo de la solicitud, por ejemplo, la dirección Webhook de tu servidor (debe ser accesible públicamente y admitir POST JSON).
2. La API **devuelve inmediatamente** una respuesta que contiene `task_id` (o que incluye resultados básicos).
3. Cuando la tarea se complete, la plataforma enviará el JSON completo a `callback_url` mediante el método `POST`. Puedes utilizar `task_id` para asociar la solicitud con el resultado.

**Ejemplo de carga útil de devolución de llamada** (la estructura de los campos es igual a la de la respuesta exitosa síncrona):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Gestión de errores

Cuando una llamada falla, se devuelve un formato de error estándar junto con un ID de seguimiento. Los errores más comunes son los siguientes:

- **400 `token_mismatched`**: la solicitud no es válida o hay un error en los parámetros.
- **400 `api_not_implemented`**: la interfaz no está implementada (contacta con el servicio de soporte).
- **401 `invalid_token`**: error de autenticación o falta el Token.
- **403 `forbidden`**: la política de seguridad nativa del proveedor ha rechazado la solicitud o el resultado generado. Esta llamada no devolverá ninguna imagen ni generará cargos; las solicitudes con varias imágenes aún pueden devolver resultados y cobrar por otras llamadas exitosas.
- **429 `too_many_requests`**: se ha superado el límite de frecuencia de solicitudes.
- **500 `api_error`**: error del servidor.

### Ejemplo de respuesta de error

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Comparación de parámetros y observaciones

- **Obligatorios**: `action`, `prompt`
- **Exclusivo de la edición**: `image_urls` (matriz, al menos 1 elemento)
- **Opcionales**: `model` (por defecto `nano-banana`; también se puede elegir `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-2.1`, `nano-banana-pro`; excepto `nano-banana-2.1`, también existen versiones oficiales del canal correspondientes con el sufijo `:official`), `aspect_ratio` (`auto` o una relación de aspecto específica, como `1:1`, `16:9`), `resolution` (resolución, como `1K`, `2K`, `4K`; `nano-banana-2-lite` solo admite `1K`), `callback_url` (para devoluciones de llamada asíncronas)
- **Headers**: se debe proporcionar `authorization: Bearer {token}`; se recomienda establecer `accept` en `application/json`
- **Accesibilidad de las imágenes**: `image_urls` debe contener enlaces directos accesibles públicamente (HTTP/HTTPS); se recomienda utilizar HTTPS
- **Idempotencia y seguimiento**: conserva `task_id` y `trace_id` para facilitar la resolución de problemas y la asociación de resultados

Al pasar explícitamente `"aspect_ratio": "auto"`, se seleccionará el ajuste preestablecido más cercano según la proporción, orientación o composición indicada en el prompt. Esto es aplicable tanto a la generación como a la edición. Por ejemplo, si el prompt dice «miniatura de YouTube», se puede seleccionar `16:9`. Si el prompt no especifica requisitos de tamaño o el reconocimiento automático no está disponible, la generación de texto a imagen utilizará la relación de aspecto predeterminada, mientras que la edición de imágenes seguirá la primera imagen de referencia y utilizará la proporción compatible más cercana. Si se omite este campo, se utilizará la relación de aspecto predeterminada o la de la imagen de referencia. Si ya existe un requisito explícito de relación de aspecto, introduce directamente la proporción específica.
