Flux Videos API utiliza `POST /flux/videos` para completar la generación de videos, la generación de video a partir de imágenes de fotogramas clave, la continuación de videos y la mejora de borradores. `action` distingue entre generación, edición y superresolución, y `mode` selecciona el modo de generación; para consultar resultados se utiliza de forma unificada el ya existente `POST /flux/tasks`.

> Actualmente está en Beta. Ya están disponibles texto a video, imagen a video, continuación de video y mejora de borradores. En pruebas reales del 2026-10-02, la edición de video y la superresolución devolvieron `service_unavailable`; estas dos funciones no están disponibles temporalmente, y las tareas fallidas no descuentan costos de generación. HTTP 200 y el ID de tarea solo indican que la tarea fue aceptada; se debe continuar consultando el resultado final.

## 1. Obtener API Token

1. Regístrate o inicia sesión en la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications), crea una aplicación y obtén el API Token. Un API Token general puede llamar a los servicios de la plataforma; confirma que la aplicación tenga permisos para llamar al servicio Flux y saldo disponible.
2. Consulta los planes y precios de cada operación en la [página del servicio Flux](https://platform.acedata.cloud/services/flux?tab=pricing). Cuando el saldo sea insuficiente, recarga en la [página de saldo de la consola](https://platform.acedata.cloud/console/coin).
3. Las solicitudes utilizan `Authorization: Bearer <tu Token>`. El Token debe guardarse en las variables de entorno del servidor; no lo escribas en páginas frontend, repositorios públicos, capturas de pantalla ni URL de callback.

![Solicitar API Token en la consola](https://cdn.acedata.cloud/dvc3cg.jpg)

El código de este artículo lee de forma unificada las variables de entorno:

```bash
export ACEDATACLOUD_API_TOKEN='替换为你自己的 API Token'
```

| Elemento      | Valor                                           |
| ------- | ----------------------------------------------- |
| Dirección raíz de API | `https://api.acedata.cloud`                     |
| Enviar tarea de video  | `POST /flux/videos`                             |
| Consultar tarea existente  | `POST /flux/tasks`                              |
| Autenticación      | `Authorization: Bearer $ACEDATACLOUD_API_TOKEN` |
| Formato de solicitud    | `Content-Type: application/json`                |

Consulta los campos completos y la depuración en línea en [Flux Videos API](https://platform.acedata.cloud/documents/flux-videos), y la consulta de tareas en [Flux Tasks API](https://platform.acedata.cloud/documents/flux-tasks).

## 2. Elegir operación e entrada

| action                      | mode            | Entrada                       | Resultado            |
| --------------------------- | --------------- | ------------------------ | ------------- |
| `generate`（valor predeterminado al omitir action） | `t2v`           | `prompt`                 | Generar video a partir de texto       |
| `generate`                  | `i2v`           | `prompt`、`keyframes`     | Generar video a partir de uno o varios fotogramas clave |
| `generate`                  | `v2v`           | `prompt`、`start_video`   | Continuar basado en el video de entrada      |
| `generate`                  | `draft_enhance` | `draft_task_id` de un borrador que ya hayas completado | Mejorar ese borrador         |
| `edit`                      | No enviar              | `video`、`prompt`         | Edición de video（temporalmente no disponible）    |
| `upscale`                   | No enviar              | `input_video`            | Superresolución de video（temporalmente no disponible）    |

El modelo de generación es `flux-3`. La edición y la superresolución utilizan sus respectivos campos; no envíes parámetros de generación como `model`, `mode`, `duration`, `draft`, etc. `action=upsale` es un error ortográfico; debe ser `upscale`.

### Parámetros generales de generación

| Parámetro                 | Descripción                                                           |
| ------------------ | ------------------------------------------------------------ |
| `mode`             | Obligatorio; `t2v`, `i2v`, `v2v` o `draft_enhance`                       |
| `prompt`           | Obligatorio para generación normal; la mejora de borradores no permite sobrescribir el prompt original                                        |
| `duration`         | Para t2v/i2v es un entero de 5–20 segundos, para v2v es un entero de 5–15 segundos, o `auto`; la duración final de salida puede diferir ligeramente del valor solicitado |
| `resolution`       | `hd`, `fhd`, `qhd`, `uhd`; el valor predeterminado para generación normal es `hd`, y para mejora de borradores es `fhd`              |
| `aspect_ratio`     | `auto`, `21:9`, `2:1`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `9:21`   |
| `draft`            | Si se genera primero un borrador; los borradores solo admiten `hd`                                           |
| `generate_audio`   | Si se genera audio sincronizado; `false` es un valor válido, conserva el valor booleano explícito                               |
| `safety_tolerance` | Opcional; entero de 0–4                                                   |
| `async`            | Se recomienda establecerlo en `true`, devuelve inmediatamente el ID de tarea de la plataforma y luego consulta los resultados                                |
| `callback_url`     | Opcional; dirección HTTP(S) que recibe el resultado JSON final; tras configurarlo también se aceptará de forma asíncrona                        |

La URL del material debe poder ser leída por el servicio. Si utilizas una URL firmada temporal, reserva suficiente tiempo de validez para la descarga y el procesamiento. No uses una dirección de página web como dirección de archivo de imagen o video.

## 3. Texto a video: solicitud completa y resultado probados

La siguiente solicitud se ejecutó correctamente en la interfaz de producción antes del ajuste de precio del 2026-10-02. Omitir `action` verificó el comportamiento de generación predeterminado; `async=true` evita esperar durante mucho tiempo la conexión HTTP.

```bash
curl -X POST 'https://api.acedata.cloud/flux/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light, steady camera, no text.",
    "duration": 5,
    "resolution": "hd",
    "draft": true,
    "async": true
  }'
```

Respuesta de aceptación（ID de tarea real）：

```json
{
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607"
}
```

Guarda el `task_id` de tu propia respuesta y continúa consultando; no uses el ID de tarea de ejemplo de la documentación para consultar resultados de otras cuentas.

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"替换为本次返回的 task_id"}'
```

El campo `response` devuelto por la consulta de tarea contiene el resultado final de negocio. | Campo de respuesta                              | Uso                                       |
| --------------------------------- | ---------------------------------------- |
| `success`                         | Si la tarea final fue exitosa; que la fase de aceptación devuelva task_id no equivale a success=true |
| `task_id`                         | ID de tarea de la plataforma, utilizado para sondeo y procesamiento de idempotencia de negocio                      |
| `trace_id`                        | Proporcionarlo al personal de soporte durante la resolución de problemas                             |
| `data[].video_url`                | Dirección del resultado de video que se puede leer                               |
| `data[].seconds/width/height/fps` | Duración, dimensiones y velocidad de fotogramas reales de la salida medidas por el servidor                       |
| `data[].draft_task_id`            | ID de entrada para mejora de borrador; solo aparece al devolver un borrador reutilizable                  |
| `usage`                           | Uso final facturado; no use la duration de la solicitud para sobrescribir los seconds reales      |
| `cost.amount`                     | Credits finales deducidos esta vez; `currency=credit` no son dólares estadounidenses   |
| `cost.list_amount`                | Credits antes del descuento de consumo del usuario de la aplicación; se devuelve cuando corresponde                 |

Esta es una prueba histórica anterior al ajuste de precios: `list_amount=2.9871876975` Credits, la cuenta tenía entonces un 10% de descuento de consumo, y el `amount=2.68846892775` Credits real. El nuevo precio del 2026-10-02 ya se ha reducido aproximadamente un 6.33%; el mismo borrador de 5.041667 segundos cuesta 2.798125185 Credits al precio actual (antes del descuento de consumo), y sería 2.5183126665 Credits si aún se disfruta de un 10% de descuento de consumo. Las facturas de tareas históricas no se recalculan. Los planes y descuentos de otras cuentas pueden ser diferentes; este no es un precio fijo en dólares estadounidenses para todos los usuarios.

## 4. Imagen a video: normal y con fotogramas clave temporizados

Los siguientes son ejemplos de parámetros; es necesario reemplazar las URL de los materiales, y no son una declaración de que este ejemplo ya se haya ejecutado correctamente. Después de completar la generación, consulte siguiendo el proceso anterior; la estructura del resultado es la misma.

Una o dos imágenes usan un arreglo normal:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "The camera slowly moves around the product in soft studio light.",
  "keyframes": [
    "https://example.com/first-frame.jpg"
  ],
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "async": true
}
```

Al especificar momentos de fotogramas clave, use pares de `[segundos, URL de imagen]`:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "A smooth transition from morning light to a warm sunset.",
  "keyframes": [[0, "https://example.com/start.jpg"], [5, "https://example.com/end.jpg"]],
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

Se permiten de 1 a 10 fotogramas clave. Los arreglos con tiempo deben estar en orden temporal ascendente, el tiempo debe ser de 0 a 20 segundos, y no se pueden mezclar URL normales y elementos con tiempo. Tres o más fotogramas clave normales deben especificar explícitamente duration, y no pueden usar auto.

## 6. Primero borrador, luego mejora

1. Genera un borrador con `draft=true`、`resolution=hd` y espera a que tenga éxito.
2. Obtén el ID de borrador de la plataforma desde el `data[0].draft_task_id` final.
3. Envía una solicitud de mejora con las credenciales de la aplicación de la misma propiedad:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "draft_enhance",
  "draft_task_id": "替换为自己的已完成草稿 ID",
  "resolution": "fhd",
  "async": true
}
```

La mejora de borrador no puede recibir `prompt`、`duration`、`aspect_ratio`、`version`、`generate_audio`、`draft`、`keyframes`、`start_video` para sobrescribir el contenido original. La caché de borradores es un recurso temporal; mejórala a tiempo; no se garantiza la conservación permanente ni una cantidad fija de días de retención. Los borradores que no sean propios/no pertenezcan a la aplicación actual, los borradores no completados y las cachés expiradas no pueden reutilizarse. El borrador y la mejora son dos tareas y se cobran por separado después de tener éxito.

## 7. Llamada integral de Python

Instala `requests`, configura tu propio Token y ejecuta el siguiente script para completar «enviar una vez → sondear → mostrar la URL del video». Tanto las consultas como los reintentos de red deben usar el task_id original, para evitar el reenvío repetido de tareas de pago.
```python
import os
import time
import requests

base_url = "https://api.acedata.cloud"
headers = {
    "Authorization": "Bearer " + os.environ["ACEDATACLOUD_API_TOKEN"],
    "Accept": "application/json",
}
payload = {
    "action": "generate",
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light.",
    "duration": 5,
    "resolution": "hd",
    "draft": True,
    "async": True,
}
submitted = requests.post(base_url + "/flux/videos", json=payload, headers=headers, timeout=120)
submitted.raise_for_status()
accepted = submitted.json()
if accepted.get("error"):
    raise RuntimeError(accepted["error"])
task_id = accepted["task_id"]
print("Task ID:", task_id)  # 持久化保存，用于恢复轮询

# 30 分钟是本示例的客户端等待上限，不是服务的完成时限承诺。
deadline = time.monotonic() + 30 * 60
while time.monotonic() < deadline:
    polled = requests.post(
        base_url + "/flux/tasks",
        json={"action": "retrieve", "id": task_id},
        headers=headers,
        timeout=30,
    )
    polled.raise_for_status()
    task = polled.json()
    if task.get("error"):
        raise RuntimeError(task["error"])
    result = task.get("response") or task.get("result")
    if isinstance(result, dict) and result.get("success") is True:
        print("Video:", result["data"][0]["video_url"])
        print("Usage:", result.get("usage"))
        print("Cost:", result.get("cost"))
        break
    if isinstance(result, dict) and result.get("error"):
        raise RuntimeError(result["error"])
    time.sleep(10)
else:
    raise TimeoutError("Still processing; resume polling with task_id=" + task_id)
```

Después de un tiempo de espera de red, no trate un estado desconocido como un error y vuelva a enviar inmediatamente. Si ya se obtuvo `task_id`, continúe consultando esa tarea; registre `task_id` y `trace_id` para facilitar la investigación. La propia interfaz de sondeo no cobra tarifas de generación.

## 8. Uso de callbacks

Añada `callback_url` al enviar; después de que la tarea se complete, se enviará el resultado JSON final mediante POST a esa dirección. La estructura en caso de éxito es coherente con la response anterior, y en caso de fallo incluye error.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "t2v",
  "prompt": "A small sailboat on calm water.",
  "duration": 5,
  "resolution": "hd",
  "draft": true,
  "callback_url": "https://your-server.example/flux-callback"
}
```

La dirección de callback debe ser accesible desde la red pública. Después de recibir la notificación, procese de forma idempotente según task_id y devuelva 2xx lo antes posible; el procesamiento de negocio puede ponerse en cola. Este documento no declara que el callback tenga autenticación de firma: antes de operaciones sensibles, como otorgar beneficios de negocio, use su propio Token para consultar la misma tarea y verificar el resultado. Si no se recibe el callback, también puede continuar con el sondeo; no vuelva a generar.

## 9. Edición de vídeo y superresolución (temporalmente no disponibles)

Estas dos operaciones siguen seleccionándose mediante la action de `/flux/videos`; a continuación solo se muestra el contrato de parámetros, y actualmente no se debe depender de su entrega exitosa.

Edición:

```json
{
  "action": "edit",
  "video": "https://example.com/source.mp4",
  "prompt": "Change the scene to warm sunset lighting.",
  "async": true
}
```

Superresolución:

```json
{
  "action": "upscale",
  "input_video": "https://example.com/source.mp4",
  "upscale_factor": 1.5,
  "creativity": 0,
  "async": true
}
```

`upscale_factor` es 1.5–3, `creativity=0` es superresolución precisa, y `1` es superresolución creativa. No es una cadena, y tampoco omita el 0 explícito. La longitud del prompt de edición es de 1–4096 caracteres. No mezcle campos de generación.

## 11. Preguntas frecuentes y resolución de problemas
| Situación                       | Recomendación                                           |
| ------------------------ | -------------------------------------------- |
| Error de parámetros (400)                | Compruebe la ortografía de action, mode, duration y el formato de los fotogramas clave; no mezcle campos de operaciones diferentes |
| Error de autenticación (401)                | Compruebe si el Bearer Token, los permisos de la aplicación y las credenciales son válidos                  |
| Rechazo de moderación de contenido (403)              | Ajuste los materiales y las indicaciones, no envíe repetidamente el mismo contenido                            |
| Límite de tasa (429)                  | Reduzca la concurrencia, reintente con espera progresiva                                    |
| service_unavailable (503) | La operación actual no está disponible; las tareas asíncronas aceptadas pueden informar este error en la response final        |
| task_id ya devuelto pero aún no hay vídeo        | Continúe consultando la response, no considere HTTP 200 como generación completada             |
| Los borradores no se pueden reutilizar                   | Confirme el usuario/la aplicación actual, que la tarea ha finalizado, que la solicitud original tenía draft=true, y compruebe si la caché temporal sigue siendo válida  |

Al enviar comentarios, proporcione task_id, trace_id, la hora de la solicitud y los parámetros anonimizados; no envíe el API Token. Para más métodos, consulte la [Guía de integración de Flux MCP](https://platform.acedata.cloud/documents/flux-mcp).
