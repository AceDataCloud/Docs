MiMo 2.6 Pro y MiMo 2.6 Flash son modelos de la serie MiMo de Xiaomi. Esta interfaz utiliza el formato OpenAI Chat Completions y cobra según los tokens de entrada, salida y aciertos de caché.

## Modelos e interfaz

| Modelo                | Posicionamiento           |
| ----------------- | ------------ |
| `mimo-v2.6-pro`   | Análisis complejo, razonamiento y llamadas a herramientas |
| `mimo-v2.6-flash` | Conversación cotidiana y tareas ligeras    |

Active MiMo y obtenga las credenciales de API correspondientes, envíe solicitudes a `https://api.acedata.cloud/mimo/chat/completions`. El `base_url` del SDK de OpenAI puede configurarse como `https://api.acedata.cloud/mimo`. La entrada unificada `/v1/chat/completions` también requiere los permisos de servicio correspondientes.

El alcance inicial de la interfaz es Chat Completions de texto; imágenes, audio, vídeo, búsqueda en Internet, Responses, Messages, Batch y UltraSpeed no están incluidos en esta versión.

## Ejemplo de Python

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ACEDATACLOUD_API_KEY"],
    base_url="https://api.acedata.cloud/mimo",
)
response = client.chat.completions.create(
    model="mimo-v2.6-pro",
    messages=[{"role": "user", "content": "解释彩虹形成的原因。"}],
    max_completion_tokens=256,
    extra_body={"thinking": {"type": "disabled"}},
)
print(response.choices[0].message.content)
print(response.usage)
```

El ejemplo muestra la forma de escribir la solicitud; los ejemplos de respuestas reales se añadirán después de la validación del servicio.

## Transmisión, razonamiento y llamadas a herramientas

Configure `stream=true` para recibir SSE; si necesita el uso final, pase `stream_options={"include_usage": true}`. El cliente debe procesar los incrementos de contenido, contenido de razonamiento y llamadas a herramientas, así como el evento final de usage.

Utilice `thinking.type=enabled` para activar el razonamiento y `disabled` para desactivarlo. `reasoning_content` y el `content` final se devuelven por separado; al continuar llamadas a herramientas, conserve el contenido de razonamiento en el mensaje del asistente, los `tool_calls` completos y el `tool_call_id` correspondiente.

Envíe únicamente declaraciones de herramientas con `type=function`; `tool_choice` solo admite `auto`. La aplicación es responsable de ejecutar las herramientas y devolver los resultados; que el modelo devuelva una llamada a herramienta no significa que la herramienta ya se haya ejecutado. La búsqueda en Internet integrada del servicio aún no está disponible.

## Facturación

`prompt_tokens` incluye las entradas con aciertos de caché; `prompt_tokens_details.cached_tokens` se calcula al precio de caché, y el resto de las entradas se calcula al precio normal de entrada. `completion_tokens` incluye la salida de razonamiento; no acumule repetidamente los tokens de razonamiento. Las llamadas de transmisión también se liquidan según el uso real final.

Los precios están sujetos a la consola, y el coste en dólares estadounidenses de Credit depende del plan adquirido. Las solicitudes fallidas no deben considerarse completadas correctamente; si necesita verificar los cargos, proporcione el identificador de seguimiento de la respuesta.

## Manejo de errores

Para errores de parámetros, compruebe el formato de la solicitud; para errores de autenticación o permisos, compruebe las credenciales y la activación del servicio; ante un 429, realice reintentos con espera exponencial. Cuando no haya capacidad de modelo saludable, puede devolverse un 503. Si se produce una interrupción después de que haya comenzado la respuesta de transmisión, primero compruebe los resultados y el uso ya recibidos para evitar repetir solicitudes a ciegas.
