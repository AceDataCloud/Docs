---
title: "Generación 3D con Tripo"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Llama a `POST /tripo/generations` para crear un modelo nuevo, proporcionando texto, una sola imagen o varias vistas del mismo objeto. Usa un token de AceDataCloud; de forma predeterminada, el resultado se devuelve de forma síncrona. Al enviar `async: true` o `callback_url`, primero se devuelven HTTP 200 y `task_id`. La devolución de llamada al finalizar tiene la misma estructura JSON que el resultado síncrono.

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

`action` es `generate` de forma predeterminada. Elige una de las tres entradas: `prompt` (1–1024 caracteres), `image_url` o `image_urls`. Las imágenes deben ser PNG/JPEG públicas mediante HTTPS, de un máximo de 20 MiB. Las vistas múltiples se ordenan como frontal, izquierda, posterior y derecha; deben proporcionarse la frontal y al menos otra, y se puede usar null para omitir vistas intermedias.

`model` es `v3.1-20260211` de forma predeterminada; también se puede elegir explícitamente `v3.0-20250812`, `v2.5-20250123`, `P1-20260311` o `P2-20260801`. `texture` es `standard` de forma predeterminada; usa `none` para geometría pura. Los distintos modelos y niveles de textura consumen diferentes cantidades de cuota.

Descarga el GLB desde `data[0].model_url`; `image_url` es una vista previa opcional. Conserva `data[0].id` para posteriores operaciones de texturizado, conversión o esqueleto. Al reintentar el mismo envío, conserva el mismo `Idempotency-Key` y cuerpo de la solicitud.
