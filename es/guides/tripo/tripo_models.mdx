---
title: "Procesamiento de modelos de Tripo"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Utilice `POST /tripo/models` para procesar un modelo existente, pasando la `action` necesaria. Los modos síncrono y asíncrono, las devoluciones de llamada, la pertenencia a la cuenta y la consulta de tareas son iguales que para la generación 3D.

| action  | Entrada                                                                | Resultado                                                                   |
| ------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| import  | `model_url`, archivo GLB, GLTF, FBX, OBJ o STL público por HTTPS, de 150 MiB como máximo | ID de modelo que se puede seguir referenciando y GLB; devuelve `normalize_scale` y `normalize_translation` cuando hay datos |
| texture | `model_id` o `model_url`; opcionalmente, uno de `prompt`, `image_url` o `image_urls` | Nuevo modelo, textura y vista previa opcional |
| convert | `model_id` o `model_url`, y el `format` de destino                     | Archivo de modelo convertido                                                |

```json
{"action":"texture","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","prompt":"蓝色哑光表面","texture_quality":"standard","async":true}
```

La calidad de textura admite `fast`, `standard`, `detailed` y `extreme`. Al utilizar un texto de indicación, se puede añadir `style_image_url`; las referencias de imagen y de múltiples vistas siguen el formato de la interfaz de generación. Consulte OpenAPI para ver más parámetros de textura.

La conversión admite `GLTF`, `FBX`, `USDZ`, `OBJ`, `STL` y `3MF`. El `format` del elemento devuelto indica el formato de entrega real; por ejemplo, al solicitar GLTF se puede entregar un GLB binario. OBJ empaqueta los materiales y mapas de textura en un ZIP. Al solicitar FBX, establezca `texture_packaging: "zip"` para obtener los mapas de textura por separado; el resultado empaquetado indica `container: "ZIP"`. Activar ajustes de malla o textura distintos de los predeterminados puede facturarse como conversión avanzada; consulte los precios del servicio para más detalles.

Utilice `data[0].id` para referenciar un modelo de esta cuenta; la transformación de normalización del modelo importado cumple `normalized = original × normalize_scale + normalize_translation`. La dirección de descarga del modelo está en `data[0].model_url`.
