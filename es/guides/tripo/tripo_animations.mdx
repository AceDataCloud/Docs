---
title: "Animación de personajes de Tripo"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Llama a `POST /tripo/animations` y usa `action` para seleccionar la comprobación del esqueleto, la vinculación automática o la retargetización de animaciones. Envía `async: true` para consultar periódicamente `/tripo/tasks`, o envía `callback_url` para recibir el resultado final.

1. **Comprobación**. Envía `{"action":"rig_check","model_id":"5db97adc-a877-4587-af16-bbf443aa55de"}`. El elemento del resultado contiene el valor booleano `riggable` y el campo opcional `rig_type`. Una comprobación correcta con `riggable: false` indica que el modelo no es apto para la vinculación. Esta operación es gratuita.
2. **Vinculación**. Envía `{"action":"rig","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","model":"v3.0-20260909","rig_type":"biped","format":"GLB"}`. El resultado es un nuevo modelo con esqueleto; conserva su `data[0].id`. La comprobación y la vinculación también pueden leer un archivo existente mediante `model_url`.
3. **Retargetización**. Usa el ID del resultado de la vinculación como `model_id`. Por ejemplo, `{"action":"retarget","model_id":"96a66a1d-69d2-48f0-846b-bdf02ed9bcc4","animations":["preset:walk","preset:idle"],"format":"GLB","async":true}`. Selecciona preajustes compatibles con la versión y el tipo de esqueleto; para uno solo, envía `animation`; para varios, envía `animations`, con un máximo de cinco, y se cobra según el número de movimientos. Una solicitud por lotes puede entregar un archivo con varias pistas de animación.

Tanto la vinculación como la retargetización admiten GLB y FBX. Usa `export_with_geometry` para controlar si el resultado de la retargetización incluye geometría, y `animate_in_place` para controlar si se conserva el desplazamiento. La dirección de descarga del archivo del modelo se encuentra en `data[0].model_url`.
