La API de HappyHorse Tasks se utiliza para consultar las tareas de generación o edición de videos creadas por la API de HappyHorse Videos.

## Proceso de solicitud

Para utilizar la API de HappyHorse Videos, primero dirígete a [la consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obtener tu token de API, guárdalo para uso futuro.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión que te invitará a registrarte e iniciar sesión; una vez completado, serás redirigido automáticamente a la página actual.

**Un token de API es suficiente para acceder a todos los servicios de la plataforma, no es necesario solicitar uno por cada servicio.** La primera solicitud incluirá un crédito gratuito para que puedas probarlo; si el crédito es insuficiente, puedes recargar el saldo general en [la consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Ejemplo de solicitud

La API de HappyHorse Tasks se puede utilizar para consultar los resultados de la API de HappyHorse Videos.

### Configuración de encabezados de solicitud y cuerpo de solicitud

**Encabezados de solicitud** incluyen:

- `accept`: especifica que se aceptan respuestas en formato JSON, aquí se debe escribir `application/json`.
- `authorization`: la clave para llamar a la API, que se puede seleccionar directamente después de la solicitud.

**Cuerpo de solicitud** incluye:

- `id`: el ID de la tarea a consultar.
- `action`: el método de operación sobre la tarea, para una consulta individual se debe escribir `retrieve`.

### Ejemplo de código CURL

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Ejemplo de respuesta

Después de una solicitud exitosa, la API devolverá los detalles de la tarea. El campo `request` es el cuerpo de la solicitud al crear la tarea, el campo `response` es el cuerpo de respuesta devuelto después de completar la tarea, por ejemplo:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "Una toma cinematográfica de un caballo blanco corriendo por una playa iluminada por la luna",
    "resolution": "720P",
    "duration": 5
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "1469cfc3-3004-4d9e-ab10-xxxxxx",
        "video_url": "https://cdn.acedata.cloud/happyhorse/c8cbf53aa0.mp4",
        "state": "succeeded",
        "duration": 5,
        "resolution": "720P",
        "ratio": "16:9"
      }
    ]
  }
}
```

La descripción de los campos es la siguiente:

- `id`: el ID de la tarea generada, utilizado para identificar de manera única esta tarea de generación.
- `request`: la información de la solicitud al crear la tarea.
- `response`: la información de retorno actual o final de la tarea.
- `created_at`: la hora de creación de la tarea, marca de tiempo Unix (segundos, punto flotante).
- `started_at`: la hora de inicio de ejecución de la tarea, cadena de tiempo UTC ISO-8601.
- `finished_at`: la hora de finalización de la tarea, marca de tiempo Unix (segundos, punto flotante). Este campo no se devuelve si la tarea no ha finalizado.
- `elapsed`: el tiempo de ejecución de la tarea, en segundos (punto flotante, con 3 decimales). Este campo no se devuelve si la tarea no ha finalizado.

## Operación de consulta por lotes

Para consultar los detalles de varias tareas por ID, establece `action` como `retrieve_batch` y pasa un array de IDs de tareas a través de `ids`:

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```

El resultado devuelto incluirá los campos `items` y `count`, donde `items` es un array de detalles de las tareas y `count` es la cantidad de tareas coincidentes en esta consulta.
