Este documento describe la forma de integración de la API de HappyHorse Videos. Esta interfaz admite videos generados a partir de texto, videos generados a partir de la primera imagen, videos generados a partir de imágenes de referencia y edición de videos a través de un único punto de entrada `/happyhorse/videos` y el parámetro `action`.

## Proceso de solicitud

Para utilizar la API de HappyHorse Videos, primero dirígete a la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obtener tu token de API y guardarlo para uso futuro.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión que te invitará a registrarte e iniciar sesión; una vez completado, serás redirigido automáticamente a la página actual.

**Un token de API es suficiente para acceder a todos los servicios de la plataforma, no es necesario solicitar uno por cada servicio.** La primera solicitud te otorgará un crédito gratuito para que puedas probarlo; si el crédito es insuficiente, puedes recargar el saldo general en la [consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Tipos de operación

`action` determina el modo de generación de esta solicitud:

- `generate`: video generado a partir de texto, acción predeterminada, admite `happyhorse-1.0-t2v` y `happyhorse-1.1-t2v`, debe incluir `prompt`.
- `image_to_video`: video generado a partir de la primera imagen, admite `happyhorse-1.0-i2v` y `happyhorse-1.1-i2v`, debe incluir `image_url`.
- `reference_to_video`: video generado a partir de imágenes de referencia, admite `happyhorse-1.0-r2v` y `happyhorse-1.1-r2v`, debe incluir `prompt` y de 1 a 9 `image_urls`.
- `video_edit`: edición de video, admite `happyhorse-1.0-video-edit`, debe incluir `prompt` y `video_url`, se pueden incluir de 0 a 5 imágenes de referencia `image_urls`.

Cada acción utiliza por defecto el modelo 1.1; `video_edit` actualmente solo tiene `happyhorse-1.0-video-edit`.

## Uso básico

Para generar un video a partir de texto, solo necesitas proporcionar `prompt`, también puedes especificar parámetros como `resolution`, `ratio`, `duration`, etc.:

```json
{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "Un caballo blanco cinematográfico levanta la cabeza, la crin se mueve suavemente en el viento del amanecer, acercamiento lento de la cámara, iluminación cálida de película",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

Un ejemplo de resultado devuelto es el siguiente:

```json
{
  "success": true,
  "task_id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
  "trace_id": "6071ab5e-2f37-46f0-9e07-f1e378112e69",
  "data": [
    {
      "id": "9650580f-6d9e-4bc1-823a-29011790c5cb",
      "video_url": "https://platform2.cdn.acedata.cloud/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1.mp4",
      "state": "succeeded",
      "duration": 5,
      "resolution": "720P",
      "ratio": null
    }
  ]
}
```

Descripción de los campos:

- `success`: indica si la solicitud fue exitosa.
- `task_id`: ID de tarea del lado de Ace Data Cloud, se puede usar para consultar el estado de la tarea.
- `trace_id`: ID de seguimiento de esta solicitud, utilizado para resolver problemas.
- `data`: lista de resultados de video.
  - `id`: ID de tarea del lado de HappyHorse.
  - `video_url`: dirección del enlace CDN del video generado.
  - `state`: estado de la tarea, puede ser `pending` / `succeeded` / `error`.
  - `duration`: duración del video facturable, en segundos; `video_edit` es la suma de la duración del video de entrada y salida.
  - `resolution`: resolución de salida.
  - `ratio`: relación de aspecto de salida.

El código CURL correspondiente es el siguiente:

```shell
curl -X POST 'https://api.acedata.cloud/happyhorse/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "Un caballo blanco cinematográfico levanta la cabeza, la crin se mueve suavemente en el viento del amanecer, acercamiento lento de la cámara, iluminación cálida de película",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}'
```

El código Python correspondiente es el siguiente:

```python
import requests

url = "https://api.acedata.cloud/happyhorse/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "Un caballo blanco cinematográfico levanta la cabeza, la crin se mueve suavemente en el viento del amanecer, acercamiento lento de la cámara, iluminación cálida de película",
    "resolution": "720P",
    "ratio": "16:9",
    "duration": 5,
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Video generado a partir de la primera imagen

Al usar `image_to_video`, `image_url` se utilizará como el primer fotograma del video. La relación de aspecto de salida seguirá lo más posible la imagen del primer fotograma, por lo que esta acción no necesita que se pase `ratio`.

```json
{
  "action": "image_to_video",
  "model": "happyhorse-1.1-i2v",
  "image_url": "https://cdn.acedata.cloud/b1c82e4937.png",
  "prompt": "Un caballo blanco cinematográfico levanta la cabeza, la crin se mueve suavemente en el viento del amanecer, acercamiento lento de la cámara, iluminación cálida de película",
  "resolution": "1080P",
  "duration": 5
}
```

## Video generado a partir de imágenes de referencia

Al usar `reference_to_video`, se pueden pasar de 1 a 9 imágenes de referencia en `image_urls`. En el prompt, se pueden referenciar las imágenes en el orden correspondiente usando `character1`, `character2`, etc.

```json
{
  "action": "reference_to_video",
  "model": "happyhorse-1.1-r2v",
  "prompt": "character1 avanza a través de un prado al amanecer con el estilo de cuero cálido y detalles dorados de character2",
  "image_urls": [
    "https://cdn.acedata.cloud/b1c82e4937.png",
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

## Edición de video

Al usar `video_edit`, es necesario proporcionar el `video_url` del video a editar y la intención de edición en `prompt`. Las `image_urls` opcionales se utilizarán como imágenes de referencia, por ejemplo, para cambiar de vestuario, transferencia de estilo o reemplazo parcial. `audio_setting` puede ser `auto` u `origin`, donde `origin` indica que se conserva el audio original del video.

```json
{
  "action": "video_edit",
  "model": "happyhorse-1.0-video-edit",
  "prompt": "Aplica el estilo de cuero cálido y detalles dorados de la imagen de referencia mientras se preserva el movimiento de cámara original",
  "video_url": "https://platform2.cdn.acedata.cloud/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1.mp4",
  "image_urls": [
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "audio_setting": "auto"
}
```

## Callback asíncrono
La generación de video requiere un tiempo de procesamiento. Si no desea mantener una conexión larga esperando, puede pasar `callback_url`, en este caso, la API devolverá inmediatamente `task_id`, y una vez que la tarea esté completada, enviará el resultado final a esa dirección mediante un POST:

```json
{
  "action": "generate",
  "prompt": "Un caballo corriendo a través de un bosque nevado",
  "duration": 5,
  "callback_url": "https://your-domain.com/callback/happyhorse"
}
```

El resultado devuelto inmediatamente es el siguiente:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

Si solo desea hacer polling y no necesita un callback, también puede pasar `"async": true`, y luego consultar el resultado de la tarea a través de [HappyHorse Tasks API](https://platform.acedata.cloud/documents/happyhorse-tasks).

## Descripción de facturación

HappyHorse cobra según los segundos de video de salida y la resolución:

- `720P`: tan bajo como $0.105 / segundo.
- `1080P`: tan bajo como $0.18 / segundo.
- `video_edit`: se cobra según la duración total del video de entrada y salida, la duración de facturación real se basa en las estadísticas después de completar la tarea.

Las tareas fallidas no se cobran y no ocupan el límite gratuito.

## Manejo de errores

Cuando hay un problema con la solicitud, la API devolverá el código de error correspondiente y la descripción, los más comunes son:

- `400`: Parámetros de solicitud incorrectos, por ejemplo, acción y modelo no coinciden, falta `prompt` / `image_url` / `video_url`, o `duration` excede el rango de 3–15 segundos.
- `401`: Fallo de autenticación, token inválido o no coincide con la API.
- `403`: Saldo insuficiente, o la palabra clave ha sido rechazada por la revisión de contenido.
- `429`: Solicitudes demasiado frecuentes, se ha activado la limitación, por favor intente de nuevo más tarde.
- `500`: Error interno del servidor o fallo en la generación.
