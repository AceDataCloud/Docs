## 1. Obtener API Key

Abre la [lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), entra en una aplicación disponible y copia la API Key.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Editar usando URL de imagen

Imagen original:

![Imagen original para edición de GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

Respuesta exitosa:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Este es el resultado de edición realmente completado a través de Ace Data Cloud el 8 de septiembre de 2026: la taza se volvió naranja, el fondo se volvió azul marino oscuro, y se mantuvieron la composición original y el tamaño de 1024×1536:

![Resultado de edición de taza naranja de GPT Image 2](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Subir imagen local

Usa `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

Se puede enviar repetidamente `image`; la serie GPT Image admite hasta 16 imágenes de referencia. `image` en las solicitudes JSON puede ser una única URL o una matriz de URL; los archivos locales se suben mediante multipart.

## 4. Parámetros comunes

| Campo                | Descripción                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (más rápido) o `gpt-image-2.5-sunburst` (mayor fidelidad y control); los tres pueden seleccionar la variante correspondiente `:official`, y `gpt-image-2` también admite `:reverse` |
| `image`           | JSON usa una única URL o una matriz de hasta 16 URL; multipart usa uno o más campos de archivo `image`                                                                    |
| `prompt`          | Instrucción de edición                                                                                                                             |
| `size`            | `auto` o `WIDTHxHEIGHT` que cumpla las restricciones                                                                                                     |
| `n`               | 1–10; cuando `response_format=b64_json`, solo se admite 1                                                                                           |
| `response_format` | `url` o `b64_json`                                                                                                               |
| `callback_url`    | Dirección de callback asíncrono opcional                                                                                                                         |

Las reglas de tamaño son las mismas que las de la interfaz de generación: el ancho y el alto deben ser múltiplos de 16, el lado largo no debe superar 3840, los píxeles totales deben ser 655,360–8,294,400, y la relación de aspecto no debe superar 3:1. Cuando se omite `size` o se usa `auto`, el modelo elegirá el formato basándose en el prompt y la primera imagen de referencia.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` y `gpt-image-2:reverse` se cobran según el número de imágenes exitosas; `gpt-image-2:official`, `gpt-image-2.5-flare:official` y `gpt-image-2.5-sunburst:official` se liquidan según los Tokens reales de entrada de texto, entrada de imágenes y salida de imágenes, y el registro de uso final prevalece.

## 5. Callback asíncrono y resolución de problemas

Para tareas largas, se puede añadir en la solicitud:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

La respuesta asíncrona 200 es `{"task_id": "..."}`; al completarse, se devuelve el resultado final mediante callback. Las solicitudes síncronas devuelven `created` y `data`.

| Estado  | Verificar                      |
| --- | ----------------------- |
| 400 | Formato/cantidad de imágenes, combinación de parámetros y formato de tamaño       |
| 401 | API Key y Bearer Header |
| 429 | Frecuencia de solicitudes                    |
| 504 | Cambiar a callback asíncrono                  |

Las respuestas de error incluirán `trace_id`. Proporciona este ID al informar de un problema, no proporciones la API Key.

Los campos completos y las enumeraciones en tiempo real están sujetos a la página de [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Para la generación de imágenes a partir de texto puro, consulta [Generación de imágenes GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
