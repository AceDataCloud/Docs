## 1. Obtener la clave API

Abre [la lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), accede a las aplicaciones disponibles y copia la clave API.

![Obtener la clave API de Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Editar usando la URL de la imagen

Imagen original:

![Imagen original editada por GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer tu clave API" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Mantén la taza, la mesa, el ángulo de la cámara, el diseño vertical y la sombra suave sin cambios. Cambia solo el color de la taza de blanco a naranja vívido y el fondo crema pálido a un azul marino oscuro sólido. Sin texto ni logotipo.",
    "size": "1024x1536"
  }'
```

Respuesta exitosa:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Este es el resultado de la edición completada el 8 de septiembre de 2026 a través de Ace Data Cloud, la taza se volvió naranja, el fondo se volvió azul marino oscuro, y se mantuvo la composición original y el tamaño de 1024×1536:

![Resultado de la edición de la taza naranja de GPT Image 2](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Subir imágenes locales

Usando `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer tu clave API" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Reemplaza el fondo con un estudio moderno brillante"
```

Se puede enviar `image` varias veces, la serie GPT Image admite hasta 16 imágenes de referencia. En la solicitud JSON, `image` puede ser una única URL o un array de URLs; los archivos locales se suben usando multipart.

## 4. Parámetros comunes

| Campo              | Descripción                                                      |
| ----------------- | ------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2:official` o `gpt-image-2:reverse`  |
| `image`           | JSON usa una única URL o un array de hasta 16 URLs; multipart usa uno o más campos de archivo `image` |
| `prompt`          | Instrucciones de edición                                        |
| `size`            | `auto` o `WIDTHxHEIGHT` que cumpla con las restricciones         |
| `n`               | 1–10; solo se admite 1 cuando `response_format=b64_json`       |
| `response_format` | `url` o `b64_json`                                            |
| `callback_url`    | Dirección de callback asíncrono opcional                        |

Las reglas de tamaño son las mismas que las de la interfaz de generación: el ancho y la altura deben ser múltiplos de 16, el lado más largo no debe exceder 3840, y el total de píxeles no debe superar 8,294,400. Si se omite `size` o se usa `auto`, el modelo elegirá el formato basado en las palabras clave y la primera imagen de referencia.

El `gpt-image-2` por defecto y `:reverse` se cobran según la cantidad de imágenes exitosas; `gpt-image-2:official` se factura según los tokens reales de entrada de texto, entrada de imágenes y salida de imágenes, con base en el registro de uso.

## 5. Callback asíncrono y depuración

Para tareas largas, se puede agregar en la solicitud:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

La respuesta asíncrona 200 es `{"task_id": "..."}`; después de completar, se llama al resultado final. Las solicitudes sincrónicas devuelven `created` y `data`.

| Estado | Verificación                  |
| ------ | ----------------------------- |
| 400    | Formato/cantidad de imagen, combinación de parámetros y formato de tamaño |
| 401    | Clave API y encabezado Bearer |
| 429    | Frecuencia de solicitudes      |
| 504    | Cambiar a callback asíncrono  |

Las respuestas de error incluirán `trace_id`. Al informar problemas, proporciona este ID, no la clave API.

Los campos completos y la enumeración en tiempo real se basan en la página de [API de Ediciones de Imágenes de OpenAI](https://platform.acedata.cloud/documents/openai-images-edits). Para generar imágenes en texto plano, consulta [GPT Image 2 Generación de Imágenes](https://platform.acedata.cloud/documents/openai-images-generations).
