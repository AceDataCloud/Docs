## 1. Obtener API Key

Abre la [lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), entra en una aplicación disponible y copia la API Key.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Enviar la primera solicitud

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

La imagen de la respuesta exitosa se encuentra en `data[].url`. A continuación se muestra el resultado de 1024×1536 obtenido mediante una solicitud real a través de Ace Data Cloud el 8 de septiembre de 2026 (tarea `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Taza blanca generada por GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Parámetros comunes

| Campo                | Descripción                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (recomendado por defecto), `gpt-image-2.5-flare` (más rápido) o `gpt-image-2.5-sunburst` (mayor fidelidad y control); los tres pueden seleccionar la variante `:official` correspondiente, y `gpt-image-2` también admite `:reverse` |
| `prompt`          | Descripción de la imagen, con un máximo de 32.000 caracteres                                                                                                                     |
| `size`            | `auto` o `WIDTHxHEIGHT`; el ancho y alto deben ser múltiplos de 16, el lado largo no debe superar 3840, los píxeles totales deben ser 655.360–8.294.400, y la relación de aspecto no debe superar 3:1                                                       |
| `n`               | 1–10; solo admite 1 cuando `response_format=b64_json`                                                                                                 |
| `quality`         | `low`, `medium`, `high` o `auto`; la compatibilidad y el método de facturación varían según la ruta                                                                                          |
| `response_format` | `url` o `b64_json`                                                                                                                     |
| `callback_url`    | Opcional; envía el resultado a esta dirección tras completarse una tarea larga                                                                                                                      |

Tamaños comunes:

| Proporción   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` seleccionará el formato según la proporción, los píxeles y la intención de composición en el prompt; cuando se necesiten píxeles exactos, escribe directamente el tamaño.

## 4. Generación de varias imágenes

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` y `gpt-image-2:reverse` se facturan según el número de imágenes generadas correctamente; `gpt-image-2:official`, `gpt-image-2.5-flare:official` y `gpt-image-2.5-sunburst:official` se liquidan según los Tokens reales de entrada de texto y salida de imagen en la respuesta. El precio de la página es una estimación antes de la solicitud; el registro de uso final prevalece.

## 5. Devolución de llamada asíncrona

Después de añadir `callback_url` al cuerpo de la solicitud, la interfaz primero devolverá `{"task_id": "..."}` y, al completarse, enviará el resultado final mediante POST a dicha URL; las solicitudes síncronas seguirán devolviendo `created` y `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

El receptor de la devolución de llamada debe usar `task_id` para eliminar duplicados, y verificar el origen de la solicitud y el formato de los datos.

## 6. Solución de errores

| Estado  | Comprobar                                                  |
| --- | --------------------------------------------------- |
| 400 | La combinación de `model`, `prompt`, formato de tamaño, `n` y `response_format`    |
| 401 | Si la API Key está completa y si el Header es `Authorization: Bearer ...` |
| 429 | La solicitud es demasiado frecuente; vuelve a intentarlo más tarde                                         |
| 504 | Tiempo de espera agotado en la generación síncrona; usa `callback_url`                            |

La respuesta de error incluirá `error.code`, `error.message` y `trace_id`. Al informar de un problema, proporciona `trace_id`, no proporciones la API Key.

Los campos completos y las enumeraciones en tiempo real se rigen por la página de [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Para la edición de imágenes, consulta [edición de imágenes GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-edits).
