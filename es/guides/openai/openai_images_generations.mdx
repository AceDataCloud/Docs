## 1. Obtener la API Key

Abre la [lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), accede a una aplicación disponible y copia la API Key.

![Obtener la API Key de Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Enviar la primera solicitud

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

La imagen de una respuesta exitosa se encuentra en `data[].url`. A continuación se muestra el resultado de 1024×1536 obtenido mediante una solicitud real a través de Ace Data Cloud el 8 de septiembre de 2026 (tarea `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

## 3. Parámetros comunes

| Campo                | Descripción                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (recomendado por defecto), `gpt-image-2.5-flare` (más rápido) o `gpt-image-2.5-sunburst` (mayor fidelidad y control); los tres pueden elegir la variante `:official` correspondiente, y `gpt-image-2` también admite `:reverse` |
| `prompt`          | Descripción de la imagen, con un máximo de 32.000 caracteres                                                                                                                     |
| `size`            | `auto` o `WIDTHxHEIGHT`; el ancho y alto deben ser múltiplos de 16, el lado más largo no debe superar 3840, los píxeles totales deben ser 655.360–8.294.400 y la relación de aspecto no debe superar 3:1                                                       |
| `n`               | 1–10; cuando `response_format=b64_json`, solo se admite 1                                                                                                 |
| `quality`         | `low`, `medium`, `high` o `auto`; la compatibilidad y el método de facturación varían según la ruta                                                                                          |
| `response_format` | `url` o `b64_json`                                                                                                                     |
| `callback_url`    | Opcional; envía el resultado a esta dirección tras completarse una tarea larga                                                                                                                      |

Tamaños comunes:

| Proporción   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` seleccionará el formato según la proporción, los píxeles y la intención de composición en el prompt; cuando se necesiten píxeles precisos, introduce directamente las dimensiones.

### Modelos y métodos de facturación

| Modelo                                | Escenarios aplicables y método de facturación                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Canal inverso predeterminado, facturación fija por número de imágenes exitosas                        |
| `gpt-image-2:reverse`             | Selección explícita del canal inverso, facturación fija por número de imágenes exitosas                      |
| `gpt-image-2:official`            | Canal de la API oficial, mayor estabilidad, facturación según el uso real de Tokens            |
| `gpt-image-2.5-flare`             | Enfocado en la velocidad de generación, facturación fija por número de imágenes exitosas                        |
| `gpt-image-2.5-flare:official`    | Canal de la API oficial, mayor estabilidad y enfocado en la velocidad de generación, facturación según el uso real de Tokens     |
| `gpt-image-2.5-sunburst`          | Enfocado en alta fidelidad y control detallado, facturación fija por número de imágenes exitosas                    |
| `gpt-image-2.5-sunburst:official` | Canal de la API oficial, mayor estabilidad y enfocado en alta fidelidad y control detallado, facturación según el uso real de Tokens |

El precio mostrado para el canal de la API oficial es una estimación previa a la solicitud; el resultado final se basa en el uso real de Tokens y los registros de uso de la respuesta.

## 4. Generación múltiple

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` y `gpt-image-2:reverse` se facturan según el número de imágenes exitosas; `gpt-image-2:official`, `gpt-image-2.5-flare:official` y `gpt-image-2.5-sunburst:official` se liquidan según los Tokens reales de entrada de texto y salida de imagen en la respuesta. El precio mostrado es una estimación previa a la solicitud; el resultado final se basa en los registros de uso.

## 5. Devolución de llamada asíncrona

Después de añadir `callback_url` al cuerpo de la solicitud, la interfaz primero devolverá `{"task_id": "..."}` y enviará el resultado final mediante POST a dicha URL al completarse; las solicitudes síncronas seguirán devolviendo `created` y `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

El receptor de la devolución de llamada debe usar `task_id` para eliminar duplicados y verificar el origen de la solicitud y el formato de los datos.

## 6. Solución de problemas

| Estado  | Comprobar                                                  |
| --- | --------------------------------------------------- |
| 400 | La combinación de `model`, `prompt`, formato de dimensiones, `n` y `response_format`    |
| 401 | Si la API Key está completa y si el Header es `Authorization: Bearer ...` |
| 429 | La solicitud es demasiado frecuente; vuelve a intentarlo más tarde                                         |
| 504 | Tiempo de espera agotado en la generación síncrona; usa `callback_url`                            |

Las respuestas de error incluirán `error.code`, `error.message` y `trace_id`. Al informar de un problema, proporciona `trace_id`, no proporciones la API Key.

Los campos completos y las enumeraciones en tiempo real se rigen por la página [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Para la edición de imágenes, consulta [Edición de imágenes GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-edits).
