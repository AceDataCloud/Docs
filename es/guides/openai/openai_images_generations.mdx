## 1. Obtener la API Key

Abre la [lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), entra en una aplicación disponible y copia la API Key.

![Obtener la API Key de Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Enviar la primera solicitud

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

La imagen de la respuesta exitosa se encuentra en `data[].url`. A continuación se muestra el resultado de 1024×1536 obtenido mediante una solicitud real a través de Ace Data Cloud el 8 de septiembre de 2026 (tarea `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Taza blanca generada por GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Parámetros comunes

| Campo                | Descripción                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (recomendado por defecto), `gpt-image-2.5-flare` (más rápido) o `gpt-image-2.5-sunburst` (mayor fidelidad y control); los tres pueden seleccionar la variante `:official` correspondiente, y `gpt-image-2` también admite `:reverse` |
| `prompt`          | Descripción de la imagen, hasta 32.000 caracteres                                                                                                                     |
| `size`            | `auto` o `WIDTHxHEIGHT`; el ancho y la altura deben ser múltiplos de 16, el lado largo no puede superar 3840, los píxeles totales deben ser 655.360–8.294.400 y la relación de aspecto no puede superar 3:1                                                       |
| `n`               | 1–10; solo admite 1 cuando `response_format=b64_json`                                                                                                 |
| `quality`         | Los modelos GPT Image admiten `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare / Sunburst (incluido `:official`) admiten adicionalmente `xhigh`, `max`. El canal oficial se factura según el uso real de Token             |
| `response_format` | `url` o `b64_json`                                                                                                                     |
| `callback_url`    | Opcional; envía el resultado a esta dirección después de completar tareas largas                                                                                                                      |

Tamaños comunes:

| Proporción   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` seleccionará el formato según la proporción, los píxeles y la intención de composición en el prompt; cuando se necesiten píxeles precisos, rellena directamente el tamaño.

### Modelos y métodos de facturación

| Modelo                                | Escenarios aplicables y método de facturación                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | Canal inverso predeterminado, facturación fija por número de imágenes exitosas                               |
| `gpt-image-2:reverse`             | Selección explícita del canal inverso, facturación fija por número de imágenes exitosas                             |
| `gpt-image-2:official`            | Canal oficial de API, mayor estabilidad, facturación según el uso real de Token                   |
| `gpt-image-2.5-flare`             | Enfocado en la velocidad de generación, facturación fija por número de imágenes exitosas                               |
| `gpt-image-2.6-flare`             | Enfocado en la velocidad de generación, facturación fija por número de imágenes exitosas                               |
| `gpt-image-2.5-flare:reverse`     | Alias inverso explícito, equivalente a `gpt-image-2.5-flare`, facturación fija por número de imágenes exitosas    |
| `gpt-image-2.6-flare:reverse`     | Alias inverso explícito, equivalente a `gpt-image-2.6-flare`, facturación fija por número de imágenes exitosas    |
| `gpt-image-2.5-flare:official`    | Canal oficial de API, mayor estabilidad y enfocado en la velocidad de generación, facturación según el uso real de Token            |
| `gpt-image-2.6-flare:official`    | Canal oficial de API, mayor estabilidad y enfocado en la velocidad de generación, facturación según el uso real de Token            |
| `gpt-image-2.5-sunburst`          | Enfocado en alta fidelidad y control preciso, facturación fija por número de imágenes exitosas                           |
| `gpt-image-2.6-sunburst`          | Enfocado en alta fidelidad y control preciso, facturación fija por número de imágenes exitosas                           |
| `gpt-image-2.5-sunburst:reverse`  | Alias inverso explícito, equivalente a `gpt-image-2.5-sunburst`, facturación fija por número de imágenes exitosas |
| `gpt-image-2.6-sunburst:reverse`  | Alias inverso explícito, equivalente a `gpt-image-2.6-sunburst`, facturación fija por número de imágenes exitosas |
| `gpt-image-2.5-sunburst:official` | Canal oficial de API, mayor estabilidad y enfocado en alta fidelidad y control preciso, facturación según el uso real de Token        |
| `gpt-image-2.6-sunburst:official` | Canal oficial de API, mayor estabilidad y enfocado en alta fidelidad y control preciso, facturación según el uso real de Token        |

Los modelos inversos 2.0 / 2.5 (incluidos los alias `:reverse`) pueden usar GPT Image 2.5 Flare para completar la solicitud durante la recuperación automática; el modelo solicitado y el método de facturación por número de imágenes exitosas permanecen sin cambios.

El precio mostrado en la página del canal oficial de API es una estimación previa a la solicitud; el importe final se basa en el uso real de Token y el registro de uso en la respuesta.

## 4. Generación de múltiples imágenes

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` y sus alias `:reverse` se cobran por número de imágenes generadas correctamente; `gpt-image-2:official`, `gpt-image-2.5-flare:official` y `gpt-image-2.5-sunburst:official` se liquidan según los Tokens reales de entrada de texto y salida de imagen en la respuesta. El precio de la página es una estimación previa a la solicitud; el resultado final se basa en los registros de uso.

## 5. Devolución de llamada asíncrona

Después de añadir `callback_url` al cuerpo de la solicitud, la interfaz primero devolverá `{"task_id": "..."}` y, al completarse, enviará el resultado final mediante POST a esa URL; las solicitudes síncronas seguirán devolviendo `created` y `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

El receptor de la devolución de llamada debe usar `task_id` para eliminar duplicados y verificar el origen de la solicitud y el formato de los datos.

## 6. Solución de problemas

| Estado  | Verificar                                                  |
| --- | --------------------------------------------------- |
| 400 | La combinación de `model`, `prompt`, formato de tamaño, `n` y `response_format`    |
| 401 | Si la API Key está completa y si el Header es `Authorization: Bearer ...` |
| 429 | La solicitud es demasiado frecuente; vuelva a intentarlo más tarde                                         |
| 504 | Tiempo de espera agotado en la generación síncrona; use `callback_url`                            |

Las respuestas de error incluirán `error.code`, `error.message` y `trace_id`. Al informar un problema, proporcione `trace_id`, no proporcione la API Key.

Los campos completos y las enumeraciones en tiempo real se rigen por la página de [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Para la edición de imágenes, consulte [Edición de imágenes GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-edits).

## GPT Image 2.6

GPT Image 2.6 mantiene las interfaces de generación, edición, tareas asíncronas y facturación de 2.5:

| Modelo                                                          | Facturación                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/imagen                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/imagen                   |
| `gpt-image-2.6-flare:official`                              | Igual que 2.5 official, se cobra según el uso real de Tokens |
| `gpt-image-2.6-sunburst:official`                           | Igual que 2.5 official, se cobra según el uso real de Tokens |

La calidad puede ser `auto`, `low`, `medium`, `high`, `xhigh`, `max`; el tamaño usa `auto` o `WIDTHxHEIGHT` que cumpla con las restricciones anteriores. Esta interfaz admite `png`, `jpeg`, `webp` y por el momento no admite SVG/GIF. La edición admite URL de imagen JSON y carga de archivos multipart. `:reverse` es el alias explícito de la versión normal del mismo nombre. Use el modelo completo, no pase `gpt-image-2.6`.
