## 1. Obtener la clave API

Abre [la lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), accede a las aplicaciones disponibles y copia la clave API.

![Obtener la clave API de Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Enviar la primera solicitud

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer tu clave API" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Ilustración de producto editorial minimalista: una taza de café de cerámica blanca centrada en una mesa de cobalt azul sólido, fondo crema pálido, sombra suave, formas geométricas limpias, sin texto, sin logo, composición vertical",
    "size": "1024x1536"
  }'
```

La imagen de respuesta exitosa se encuentra en `data[].url`. A continuación se muestra el resultado de 1024×1536 obtenido mediante una solicitud real a Ace Data Cloud el 8 de septiembre de 2026 (tarea `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, traza `eb938601-8192-407f-b539-1e0554b697ec`):

![Taza blanca generada por GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Parámetros comunes

| Campo              | Descripción                                                               |
| ----------------- | ---------------------------------------------------------------------- |
| `model`           | Usar `gpt-image-2`; también se puede elegir explícitamente `gpt-image-2:official` o `gpt-image-2:reverse` |
| `prompt`          | Descripción de la imagen, máximo 32,000 caracteres                             |
| `size`            | `auto` o `WIDTHxHEIGHT`; las dimensiones deben ser múltiplos de 16, el lado más largo no debe exceder 3840, el total de píxeles no debe exceder 8,294,400 |
| `n`               | 1–10; solo se admite 1 cuando `response_format=b64_json`                  |
| `quality`         | `low`, `medium`, `high` o `auto`; el soporte y la facturación varían según la línea |
| `response_format` | `url` o `b64_json`                                                     |
| `callback_url`    | Opcional; enviar resultados a esta dirección después de completar tareas largas |

Tamaños comunes:

| Proporción | 1K          | 2K          | 4K          |
| --------- | ----------- | ----------- | ----------- |
| 1:1      | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3      | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4      | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9     | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16     | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` seleccionará el formato según la proporción, píxeles e intención de diseño en el prompt; si se necesitan píxeles exactos, se debe ingresar el tamaño directamente.

## 4. Generación múltiple

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer tu clave API" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Un pequeño zorro leyendo bajo un hongo brillante, ilustración en acuarela",
    "size": "1536x1024",
    "n": 2
  }'
```

El `gpt-image-2` por defecto y `:reverse` se facturan según la cantidad de imágenes exitosas; `gpt-image-2:official` se liquida según los tokens reales utilizados en la entrada de texto y salida de imagen. Los precios en la página son estimaciones previas a la solicitud, el registro de uso es el que cuenta.

## 5. Callback asíncrono

Al agregar `callback_url` al cuerpo de la solicitud, la interfaz devolverá primero `{"task_id": "..."}`, y al completarse, enviará el resultado final a esa URL mediante POST; las solicitudes sincrónicas aún devolverán `created` y `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "Un cartel de producto con tipografía clara",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

El receptor del callback debe usar `task_id` para evitar duplicados y verificar la fuente de la solicitud y el formato de los datos.

## 6. Solución de problemas

| Estado | Verificación                                           |
| ------ | ----------------------------------------------------- |
| 400    | Combinación de `model`, `prompt`, formato de tamaño, `n` y `response_format` |
| 401    | Verificar si la clave API está completa, el encabezado debe ser `Authorization: Bearer ...` |
| 429    | Solicitudes demasiado frecuentes, intenta de nuevo más tarde |
| 504    | Tiempo de espera en la generación sincrónica; usa `callback_url` |

Las respuestas de error incluirán `error.code`, `error.message` y `trace_id`. Al informar problemas, proporciona `trace_id`, no la clave API.

Los campos completos y la enumeración en tiempo real se basan en la página de [API de Generaciones de Imágenes de OpenAI](https://platform.acedata.cloud/documents/openai-images-generations). Para la edición de imágenes, consulta [Edición de Imágenes GPT 2](https://platform.acedata.cloud/documents/openai-images-edits).
