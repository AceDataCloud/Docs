OpenAI ChatGPT es un sistema de conversación de IA muy potente; basta con introducir un prompt para generar respuestas fluidas y naturales en tan solo unos segundos. ChatGPT destaca en la industria por sus excelentes capacidades de comprensión y generación de lenguaje. Hoy en día, ChatGPT ya se utiliza ampliamente en diversas industrias y ámbitos, y su influencia es cada vez más notable. Ya sea para conversaciones cotidianas, escritura creativa, consultas profesionales o programación de código, ChatGPT puede proporcionar una asistencia inteligente sorprendente, mejorando enormemente la eficiencia laboral y la creatividad humanas.

Este documento presenta principalmente el flujo de uso de las operaciones de la API OpenAI Chat Completion; con ella podemos utilizar fácilmente las funciones de conversación del ChatGPT oficial de OpenAI.

Las solicitudes de modelos compatibles aceptadas por la plataforma se facturan según el uso de entrada, salida y caché del modelo. Los `prompt_tokens` de Chat Completions incluyen tokens de caché, y la parte de caché reportada se liquida según el precio de caché correspondiente; cambiar el formato de la interfaz no se convertirá en una facturación por cantidad fija de veces. Los cargos se basan en el precio actual del modelo en la consola y en `usage.cost` de la respuesta.

## GPT-6.1 Terra

Utilice `model: "gpt-6.1-terra"` para seleccionar este modelo. Admite entrada de texto, imágenes y salida en streaming; para herramientas de funciones y salidas estructuradas, llame según el formato de parámetros de esta interfaz. Los niveles de razonamiento admiten `low`, `medium`, `high`, `xhigh` y `max`; se recomienda comenzar con `reasoning_effort: "low"`; no se admiten `none` ni `minimal`. Cuando la entrada supera los 272,000 tokens, se aplica el precio de contexto largo; el coste real se basa en el precio actual de la consola y el uso en la respuesta.

## GPT-6.1 Sol

Utilice `model: "gpt-6.1-sol"` para seleccionar este modelo. Admite salida en streaming, llamadas a funciones, salida estructurada y entrada de imágenes. Durante la primera semana de disponibilidad, solo estará disponible para titulares verificados de ACE T1+ (al menos 100,000 ACE) o usuarios autorizados; el horario específico de disponibilidad se basará en el aviso de acceso de la consola.

Los niveles de razonamiento admiten `low`, `medium`, `high`, `xhigh` y `max`; por el momento no se admiten `none` ni `minimal`. Se recomienda comenzar con `reasoning_effort: "low"`. Cuando la entrada supera los 272,000 tokens, toda la solicitud se factura con el precio de contexto largo, y el coste se basa en el precio actual de la consola.

## Proceso de solicitud

Para utilizar la API OpenAI Chat Completion, primero vaya a la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obtener su API Token y guárdelo como respaldo.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no ha iniciado sesión ni se ha registrado, se le redirigirá automáticamente a la página de inicio de sesión para invitarle a registrarse e iniciar sesión; al completarlo, regresará automáticamente a la página actual.

**Un solo API Token puede llamar a todos los servicios de la plataforma, sin necesidad de solicitar uno por separado para cada servicio.** La primera solicitud incluye crédito gratuito, que puede utilizarse para una experiencia gratuita; cuando el crédito sea insuficiente, puede recargar saldo universal en la [consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [OpenAI Chat Completion API →](https://platform.acedata.cloud/documents/openai-chat-completions)

## Uso básico

A continuación, puede completar el contenido correspondiente en la interfaz, como se muestra en la imagen:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

Al utilizar esta interfaz por primera vez, necesitamos completar al menos tres elementos. Uno es `authorization`, que se puede seleccionar directamente en la lista desplegable. Otro parámetro es `model`; `model` es la categoría de modelo oficial de OpenAI ChatGPT que elegimos utilizar. Aquí disponemos principalmente de 20 modelos; para más detalles puede consultar los modelos que proporcionamos. El último parámetro es `messages`; `messages` es el arreglo de prompts que introducimos. Es un arreglo que indica que se pueden cargar varios prompts simultáneamente. Cada prompt incluye `role` y `content`, donde `role` representa el rol del solicitante. Proporcionamos tres identidades: `user`, `assistant` y `system`. El otro, `content`, es el contenido específico de nuestra consulta.

Al mismo tiempo, puede observar que a la derecha se genera el código de llamada correspondiente. Puede copiar el código y ejecutarlo directamente, o hacer clic directamente en el botón «Try» para realizar pruebas.

Parámetros opcionales comunes:

- `max_tokens`: limita el número máximo de tokens en una sola respuesta.
- `temperature`: aleatoriedad de la generación, entre 0 y 2; cuanto mayor sea el valor, más disperso será el resultado.
- `n`: cuántas respuestas candidatas se generan de una vez.
- `response_format`: configuración del formato de respuesta.

## Respuesta en streaming

Esta interfaz también admite respuestas en streaming, lo cual es muy útil para la integración con páginas web y permite lograr un efecto de visualización carácter por carácter.

Si desea devolver respuestas en streaming, puede cambiar el parámetro `stream ` en los encabezados de la solicitud a `true`.

La modificación se muestra en la imagen; sin embargo, el código de llamada debe tener los cambios correspondientes para admitir respuestas en streaming.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

Después de cambiar `stream` a `true`, la API devolverá los datos JSON correspondientes línea por línea; a nivel de código, debemos realizar las modificaciones correspondientes para obtener los resultados línea por línea.

Código de llamada de ejemplo en Python:
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Integración con OpenAI-Python

La API de OpenAI Chat Completion mantiene compatibilidad con la interfaz oficial de OpenAI, y puede integrarse directamente mediante el SDK oficial [OpenAI-Python](https://github.com/openai/openai-python). Este artículo presentará brevemente cómo utilizarlo.

1. Primero debe configurar un entorno local de `Python`; puede buscar este proceso en Google.
2. Descargue e instale un entorno de desarrollo, por ejemplo, instale el editor VSCode.
3. Configure las variables de entorno de `OpenAI`.

- En la carpeta del proyecto, cree un archivo llamado `.env` y guárdelo.
- Contenido del archivo `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # 再次提醒：如果你使用官网OpenAI的key，不要用这个地址。
```

Reemplace `sk-xxx` con su propia key. `OPENAI_BASE_URL` es la interfaz proxy para acceder a OpenAI.

4. Instale los paquetes de los que depende el proyecto

```shell
pip install openai
```

En Mac OS, el comando es:

```shell
pip3 install openai
```

5. Cree un archivo de código fuente de ejemplo

Supongamos que hemos creado un código de ejemplo `index.py`; el contenido específico es el siguiente:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Modelo visual

gpt-4o es un modelo de lenguaje grande multimodal desarrollado por OpenAI; añade capacidades de comprensión visual sobre la base de GPT-4. Este modelo puede procesar simultáneamente entradas de texto e imágenes, logrando comprensión y generación multimodal.

El procesamiento de texto utilizando el modelo gpt-4o es coherente con el contenido de uso básico anterior. A continuación, se presentará brevemente cómo utilizar la capacidad de procesamiento de imágenes del modelo.

La capacidad de procesamiento de imágenes del modelo gpt-4o se utiliza principalmente agregando un campo `type` sobre la base del contenido original de `content`. Mediante este campo se puede saber si se ha cargado texto o una imagen, para así utilizar la capacidad de procesamiento de imágenes del modelo gpt-4o. A continuación se describe principalmente cómo llamar a esta función mediante Curl y Python.

```

-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",

            }

    ]
  }'
```

## Manejo de errores

Al llamar a la API, si se produce un error, la API devolverá el código de error y la información correspondientes. Por ejemplo:

- `400 token_mismatched`: Solicitud incorrecta, posiblemente debido a parámetros faltantes o no válidos.
- `400 api_not_implemented`: Solicitud incorrecta, posiblemente debido a parámetros faltantes o no válidos.
- `401 invalid_token`: No autorizado, token de autorización no válido o faltante.
- `429 too_many_requests`: Demasiadas solicitudes, ha excedido el límite de tasa.
- `500 api_error`: Error interno del servidor, algo salió mal en el servidor.

### Ejemplo de respuesta de error

```
{
  "success": false,
  "error": {

  },

}
```
