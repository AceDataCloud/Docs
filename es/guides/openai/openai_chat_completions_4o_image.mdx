OpenAI ChatGPT es un sistema de diálogo de IA muy potente que, con solo ingresar una indicación, puede generar respuestas fluidas y naturales en cuestión de segundos. ChatGPT se destaca en la industria por su excelente capacidad de comprensión y generación de lenguaje. Hoy en día, ChatGPT se ha aplicado ampliamente en diversos sectores y campos, y su influencia es cada vez más significativa. Ya sea para conversaciones cotidianas, escritura creativa, consultas profesionales o programación de código, ChatGPT puede ofrecer una asistencia inteligente sorprendente, mejorando enormemente la eficiencia laboral y la creatividad humana.

Este documento describe principalmente el proceso de uso de la API OpenAI Chat Completion 4o Image, con la cual podemos utilizar fácilmente la función multimodal de diálogo oficial de OpenAI ChatGPT.

## Proceso de Solicitud

Para usar la API OpenAI Chat Completion 4o Image, primero puede ir a la página [OpenAI Chat Completion 4o Image API](https://platform.acedata.cloud/documents/openai-chat-completions) y hacer clic en el botón "Acquire" para obtener las credenciales necesarias para las solicitudes:

![](https://cdn.acedata.cloud/nyq0xz.png)

Si aún no ha iniciado sesión o registrado, será redirigido automáticamente a la página de inicio de sesión para registrarse e iniciar sesión, y después de hacerlo, volverá automáticamente a esta página.

Al solicitar por primera vez, se otorgará un crédito gratuito para usar esta API sin costo.

## Modelo de Dibujo GPT-4o

### Generación de imagen basada en imagen de referencia

A continuación se muestra un ejemplo de generación de una imagen con estilo personalizado basada en una imagen de entrada. Primero, veamos la imagen que ingresamos, como se muestra a continuación:

![](https://cdn.acedata.cloud/qzx2z1.png)

Se puede observar que la imagen de referencia es una foto real de una persona. Podemos cambiar su estilo, por ejemplo, convertirla en una imagen con estilo anime. El ejemplo específico de la solicitud es:

```json
{
  "model": "gpt-4o-image",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "生成动漫风格的图片，并且带上个帽子"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

## Manejo de Errores

Al llamar a la API, si se encuentra un error, la API devolverá un código y mensaje de error correspondiente. Por ejemplo:

- `400 token_mismatched`: Solicitud incorrecta, posiblemente por parámetros faltantes o inválidos.
- `400 api_not_implemented`: Solicitud incorrecta, posiblemente por parámetros faltantes o inválidos.
- `401 invalid_token`: No autorizado, token de autorización inválido o faltante.
- `429 too_many_requests`: Demasiadas solicitudes, ha excedido el límite de tasa.
- `500 api_error`: Error interno del servidor, algo salió mal en el servidor.

### Ejemplo de respuesta de error
