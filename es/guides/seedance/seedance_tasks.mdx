La principal función de la API de Tareas de SeeDance es consultar el estado de ejecución de una tarea mediante el ID de tarea generado por la API de Generación de Video de SeeDance.

Este documento detallará las instrucciones de integración de la API de Tareas de SeeDance, ayudándole a integrar y aprovechar al máximo las potentes funciones de esta API. A través de la API de Tareas de SeeDance, puede consultar fácilmente el estado de ejecución de las tareas de la API de Generación de Video de SeeDance.

## Proceso de Solicitud

Para utilizar la API de Tareas de SeeDance, primero debe ir a la página de solicitud [API de Generación de Video de SeeDance](https://platform.acedata.cloud/documents/seedance-videos) para solicitar el servicio correspondiente, y luego copiar el ID de tarea de la API de Generación de Video de SeeDance, como se muestra en la imagen:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Finalmente, acceda a la página de la API de Tareas [API de Tareas de SeeDance](https://platform.acedata.cloud/documents/seedance-tasks) para solicitar el servicio correspondiente. Una vez en la página, haga clic en el botón "Acquire", como se muestra en la imagen:

![Página de Solicitud](https://cdn.acedata.cloud/rci31i.png)

Si aún no ha iniciado sesión o registrado, será redirigido automáticamente a la [página de inicio de sesión](https://platform.acedata.cloud) que le invita a registrarse e iniciar sesión. Después de registrarse e iniciar sesión, será redirigido automáticamente a la página actual.

Al solicitar por primera vez, se le otorgará un crédito gratuito que le permitirá utilizar esta API de forma gratuita.

## Ejemplo de Solicitud

La API de Tareas de SeeDance se puede utilizar para consultar los resultados de la API de Generación de Video de SeeDance. Para saber cómo utilizar la API de Generación de Video de SeeDance, consulte el documento [API de Generación de Video de SeeDance](https://platform.acedata.cloud/documents/seedance-videos-integration).

### Configuración de Encabezados de Solicitud y Cuerpo de Solicitud

**Encabezados de Solicitud** incluyen:

- `accept`: especifica que se aceptan respuestas en formato JSON, aquí se debe llenar como `application/json`.
- `authorization`: la clave para llamar a la API, que puede seleccionarse directamente después de la solicitud.

**Cuerpo de Solicitud** incluye:

- `id`: el ID de tarea cargado.
- `action`: el método de operación sobre la tarea.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/seedance/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "a6e0d456-189b-4c78-9232-2fe72166ab39",
  "action": "retrieve"
}'
```

## 错误处理

En la llamada a la API, si se encuentra un error, la API devolverá el código de error correspondiente y la información. Por ejemplo:

- `400 token_mismatched`：Solicitud incorrecta, posiblemente debido a parámetros faltantes o inválidos.
- `400 api_not_implemented`：Solicitud incorrecta, posiblemente debido a parámetros faltantes o inválidos.
- `401 invalid_token`：No autorizado, token de autorización inválido o faltante.
- `429 too_many_requests`：Demasiadas solicitudes, ha superado el límite de tasa.
- `500 api_error`：Error interno del servidor, algo salió mal en el servidor.

### 错误响应示例

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
