Continue soporta la API compatible con OpenAI. Para asegurarse de utilizar Chat Completions, es necesario establecer explícitamente `useResponsesApi: false`.

## Configuración

Agrega en la configuración local YAML de Continue:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Guarda `ACEDATACLOUD_API_KEY` en la gestión de secretos de Continue, no envíes el Token real a la configuración del proyecto. La configuración JSON de Continue ha sido descontinuada, la nueva configuración utiliza YAML.

## Verificación

Recarga VS Code, abre la barra lateral de Continue, selecciona el modelo en Configuración Local y envía `Reply only OK`; luego ejecuta nuevamente la tarea de archivo de solo lectura. Si la solicitud se envía incorrectamente a `/responses`, verifica si `useResponsesApi: false` está dentro de la entrada de ese modelo.
