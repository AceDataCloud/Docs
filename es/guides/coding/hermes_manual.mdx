## 1. Obtener la API Key

Abre la [lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), entra en una aplicación disponible y copia la API Key.

![Obtener la API Key de Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Guardar la Key

Escribe en `~/.hermes/.env`:

```dotenv
ACEDATACLOUD_API_KEY=tu API Key
```

## 3. Configurar el Provider

Añade en `~/.hermes/config.yaml`:

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

Ve al [catálogo de modelos](https://platform.acedata.cloud/models) para consultar los nombres de los modelos (por ejemplo, `claude-opus-5`, `gpt-6-sol`), y reemplaza todos los `MODEL_ID` por el mismo nombre; para una validación precisa, toma como referencia el valor de `id` en la respuesta de `/v1/models`. Este valor es el nombre del modelo utilizado por el parámetro `model` de la API, no el UUID del servicio o de la API. No escribas la Key real en YAML ni confirmes `.env`.

## 4. Verificar

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

Si devuelve 401, revisa `~/.hermes/.env`; si la configuración no surte efecto, cierra completamente y reinicia Hermes.
