## 1. Obtener API Key

Abre la [lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), entra en una aplicación disponible y copia la API Key.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar OpenCode

```bash
curl -fsSL https://opencode.ai/install | bash
```

También puedes usar npm:

```bash
npm install -g opencode-ai
```

## 3. Configurar API Key

```bash
export ACEDATACLOUD_API_KEY="你的 API Key"
```

Si necesitas que sea efectivo a largo plazo, añade esta línea a `~/.zshrc` o `~/.bashrc` y luego vuelve a abrir la terminal.

## 4. Configurar Provider

Edita `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ace Data Cloud",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  }
}
```

Ve al [catálogo de modelos](https://platform.acedata.cloud/models) para ver los nombres de los modelos (por ejemplo, `claude-opus-5`, `gpt-6-sol`), y reemplaza todos los `MODEL_ID` por el mismo nombre; para una verificación precisa, toma como referencia el valor `id` en la respuesta de `/v1/models`. Este valor es el nombre de modelo utilizado por el parámetro `model` de la API, no el UUID del servicio o de la API. Ace Data Cloud utiliza Chat Completions aquí, por lo que el adaptador es `@ai-sdk/openai-compatible`.

## 5. Verificar e iniciar

```bash
opencode auth list
opencode models acedatacloud
opencode run --model acedatacloud/MODEL_ID "Reply only OK"
```

Luego ejecuta `opencode` en el directorio del proyecto. Si el modelo no aparece, verifica la ruta del archivo de configuración, la sintaxis JSON y las variables de entorno; 401 indica que la Key no es válida o no se ha exportado.

La extensión de IDE reutiliza la misma configuración de runtime de OpenCode, consulta [OpenCode IDE Extension](https://platform.acedata.cloud/documents/opencode-ide-integration).
