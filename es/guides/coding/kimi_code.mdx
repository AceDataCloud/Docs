## 1. Obtener API Key

Abre la [lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), entra en una aplicación disponible y copia la API Key.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar Kimi Code

macOS / Linux：

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

También se puede instalar mediante npm：

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. Configurar AceDataCloud

Edita `~/.kimi/config.toml` y añade la siguiente configuración：

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "你的 API Key"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

Ve al [catálogo de modelos](https://platform.acedata.cloud/models) para consultar los nombres de los modelos (por ejemplo, `claude-opus-5`, `gpt-6-sol`) y reemplaza todos los `MODEL_ID` por el mismo nombre; para una verificación precisa, toma como referencia el valor de `id` en la respuesta de `/v1/models`. Este valor es el nombre del modelo utilizado por el parámetro `model` de la API, no el UUID del servicio o de la API. `type = "openai"` utiliza el protocolo OpenAI Chat Completions.

El archivo de configuración contiene la Key; en macOS / Linux se recomienda limitar los permisos：

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. Verificar e iniciar

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

Después de entrar en el proyecto, ejecuta `kimi` para empezar a usarlo. Si devuelve 401, revisa la API Key; si muestra model not found, confirma que `default_model`, el nombre de la tabla de modelos y el campo `model` utilicen el mismo ID.
