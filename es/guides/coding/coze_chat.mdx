La documentación oficial del modelo personalizado de Coze admite la API de Chat de OpenAI. Las diferentes versiones de inquilinos de Coze pueden manejar la concatenación de rutas, la salida en streaming y las llamadas a herramientas de manera diferente, por lo que se recomienda revisar cada punto a continuación al realizar la integración por primera vez.

## Configuración

1. Accede a la gestión de modelos de Coze y añade un modelo personalizado.
2. Selecciona el Protocolo OpenAI Chat API.
3. Completa la URL base de la API con `https://api.acedata.cloud/v1`.
4. Completa la clave de API con tu token de API de Ace Data Cloud.
5. Completa el modelo con el ID de modelo exacto que soporte Chat Completions en el directorio de modelos.
6. Guarda y completa la prueba de conexión de Coze.
7. En Bot/Agente, envía `Reply only OK`, y prueba nuevamente la llamada a la herramienta.

## Límites Actuales

- Diferentes regiones, versiones o paquetes de Coze pueden mostrar formularios diferentes.
- La URL base de la API debe usar base, no se debe añadir `/chat/completions` de nuevo; si la UI actual requiere explícitamente la URL completa de la API, sigue las indicaciones del formulario.
- Chat Completions, Responses y Anthropic Messages son tres rutas independientes y no pueden sustituirse entre sí para la verificación.
