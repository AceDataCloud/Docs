## 1. Obtener la API Key

Abre la [lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), entra en una aplicación disponible y copia la API Key.

![Obtener la API Key de Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configuración

Roo Code proporciona oficialmente un Provider compatible con OpenAI y requiere que el modelo admita tools/function calling nativos de OpenAI.

1. Abre la configuración de Roo Code en VS Code.
2. Establece **API Provider** como **OpenAI Compatible**.
3. Completa:

| Campo       | Valor                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | La API Key que acabas de copiar                  |
| Model ID | El ID del modelo seleccionado en el asistente de configuración de Coding         |

![Interfaz de configuración OpenAI Compatible de Roo Code](https://cdn.acedata.cloud/b6a0e7156438.png)

A continuación, configura las opciones de context, max output, imágenes y computer-use según las capacidades reales del modelo. Por último, guarda la configuración y vuelve a cargar VS Code.

## 3. Verificación

Primero envía `Reply only OK`, luego pide a Roo Code que lea un archivo de prueba. Si el chat normal funciona pero las herramientas de Agent fallan, cambia a un modelo que admita tool calling nativo y confirma que el endpoint compatible pueda devolver correctamente en streaming los parámetros y resultados de las herramientas.
