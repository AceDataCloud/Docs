## 1. Obtener API Key

Abre [la lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), accede a las aplicaciones disponibles y copia el API Key.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configurar Provider

El plugin de JetBrains de Kilo Code utiliza el formato de Provider `kilo.jsonc`. La configuración debe estar en el entorno del usuario donde se ejecuta realmente el plugin; en el desarrollo remoto, generalmente es el host backend remoto.

Escribe en `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

En el entorno donde se inicia el backend de JetBrains, exporta `ACEDATACLOUD_API_KEY`, luego reinicia el IDE o el backend remoto.

## 3. Verificación

Selecciona `acedatacloud/MODEL_ID`, envía `Reply only OK`, y luego haz que el Agente lea un archivo de prueba. Si funciona localmente pero falla de forma remota, verifica primero si el archivo de configuración y las variables de entorno están escritas en el host remoto.
