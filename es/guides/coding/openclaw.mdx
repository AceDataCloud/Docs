## 1. Obtener API Key

Abre [la lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), accede a las aplicaciones disponibles y copia el API Key.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar OpenClaw y el plugin

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

El plugin requiere OpenClaw `2026.4.2` o superior, actualmente proporciona capacidades nativas de Chat y Búsqueda Web.

## 3. Configurar Key

Se recomienda usar onboarding:

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "tu API Key"
```

También se puede usar una variable de entorno:

```bash
export ACEDATACLOUD_API_KEY="tu API Key"
```

## 4. Opcional: Configuración manual

Si no se usa onboarding, habilita el plugin y establece el modelo predeterminado en `~/.openclaw/openclaw.json`:

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

No escribas el API Key en este archivo; continúa usando variables de entorno.

## 5. Elegir modelo y verificar

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "Responde solo OK"
```

Reemplaza `MODEL_ID` con el modelo actualmente proporcionado por Coding Plan. Si necesitas establecerlo como modelo predeterminado, ejecuta:

```bash
openclaw models set acedatacloud/MODEL_ID
```

Los registros de llamadas se pueden ver en [Historial de uso](https://platform.acedata.cloud/console/usages). Un 401 indica que el Key es inválido; si el modelo no existe, primero verifica el ID exacto y la versión del plugin. `cost: 0` en el directorio del plugin solo indica que no es estimado nuevamente por OpenClaw, el costo real sigue siendo registrado por Ace Data Cloud.

## Búsqueda Web

```bash
openclaw infer web search \
  --provider acedatacloud --query "últimos marcos de agentes de IA" --limit 5
```

Actualmente, no consideres las capacidades de imágenes, videos o música mencionadas en la introducción del plugin como capacidades nativas del Provider de OpenClaw.
