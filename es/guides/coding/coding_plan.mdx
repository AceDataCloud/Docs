Coding Plan proporciona interfaces de Claude Messages, OpenAI Responses y OpenAI-compatible Chat Completions. Los cuatro planes tienen el mismo alcance de acceso a los modelos; los precios y los créditos de las promociones se rigen por la [página de precios de Coding Plan](https://platform.acedata.cloud/services/coding?tab=pricing). Coding Application no recurre al saldo general.

## Catálogo dinámico de modelos

Primero puede abrir el [catálogo de modelos](https://platform.acedata.cloud/models) para consultar los nombres actuales de los modelos, por ejemplo, `claude-opus-5`, `gpt-6-sol`. Cuando necesite confirmar si las credenciales de Coding y el protocolo de la API coinciden, use credenciales válidas de Coding Application para realizar la solicitud:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

El catálogo de modelos cambiará continuamente; este documento no mantiene una cantidad fija ni una lista estática de modelos. El `id` de cada entrada en la respuesta es el **nombre del modelo** que puede pasarse directamente al parámetro `model` de la API; por ejemplo, `{"id":"deepseek-v4-pro"}` corresponde a introducir `deepseek-v4-pro`; no es el UUID de un servicio, API o Application. `/v1/models` devuelve el catálogo global de modelos y no se filtra automáticamente según las credenciales de Coding; antes de configurar, todavía debe confirmarse de forma cruzada con el API scope de las credenciales, el protocolo seleccionado y el alcance de compatibilidad del cliente.

## Solución de problemas comunes

- **Saldo insuficiente**: acceda a la [consola de Applications](https://platform.acedata.cloud/console/applications), busque Coding Application y renueve activamente la compra.
- **El cliente todavía solicita la dirección original**: confirme que la configuración pertenece al mismo usuario y espacio de trabajo que inicia el cliente, y salga completamente antes de reiniciar el cliente.
- **El nombre del modelo no está disponible**: vuelva a solicitar `/v1/models` y compruebe si el nombre del modelo introducido coincide exactamente con el `id` del catálogo, el API scope de las credenciales y el protocolo compatible con el cliente.
- **El Token no puede llamar a la interfaz**: confirme que las credenciales pertenecen a Coding Application y compruebe `allowed_api_ids` y los permisos de la API de la aplicación.
