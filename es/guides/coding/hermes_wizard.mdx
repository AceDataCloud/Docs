## 1. Obtener la API Key

Abra la [lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), entre en una aplicación disponible y copie la API Key.

![Obtener la API Key de Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Ejecutar el asistente

```bash
hermes model
```

Seleccione **Custom endpoint** y complete en orden:

| Campo             | Valor                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | La API Key que acaba de copiar                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | Vaya al [catálogo de modelos](https://platform.acedata.cloud/models) para consultar y complete el nombre del modelo objetivo tal cual, por ejemplo `claude-opus-5`, `gpt-6-sol` |
| Context length | Déjelo vacío para la detección automática, o complételo según el catálogo de modelos                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model` es el nombre del modelo utilizado por el parámetro `model` en las solicitudes de API, no el UUID del servicio o de la API. Puede consultarlo primero en el [catálogo de modelos](https://platform.acedata.cloud/models); si necesita una validación precisa, use la API Key actual para solicitar `GET https://api.acedata.cloud/v1/models` y copie el valor de `id` del modelo objetivo desde el arreglo `data` de la respuesta.

El asistente escribirá en `~/.hermes/config.yaml` y en el archivo de credenciales local.

## 3. Verificar

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

Si el asistente no guardó la configuración, puede ejecutar `hermes model --reset` y volver a intentarlo; 401 indica que la API Key no es válida o que no ha sido leída por la configuración del usuario actual.
