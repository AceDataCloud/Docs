Qwen Code utiliza la configuración `modelProviders` de `~/.qwen/settings.json` para personalizar el Provider. Aquí se utiliza un protocolo compatible con OpenAI.

## Configuración

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud` debe ser un arreglo. Los elementos del Provider se configuran de manera independiente y no heredan automáticamente otros parámetros de contexto, Header o body de nivel superior.

## Verificación

```bash
export ACEDATACLOUD_API_KEY="PEGA_TU_TOKEN_DE_ACEDATACLOUD_AQUÍ"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Responde solo OK"
```

Entra y envía `Responde solo OK`, luego ejecuta nuevamente la herramienta de solo lectura de archivos. Si el punto final compatible rechaza el formato de resultados de la herramienta, verifica la versión actual de Qwen Code y la documentación oficial de compatibilidad.
