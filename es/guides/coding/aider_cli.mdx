Aider se conecta a la API compatible con OpenAI a través del prefijo de modelo `openai/` de LiteLLM.

## Configuración

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

Reemplace `MODEL_ID` con el modelo seleccionado en el asistente de configuración de Coding. También puede escribir las opciones correspondientes en el archivo local `.env` o `.aider.conf.yml`, pero no envíe el Token real.

## Verificación

```bash
aider --model openai/MODEL_ID --message "Reply only OK"
```

Al usar un modelo desconocido por primera vez, Aider puede indicar que falta metadatos del modelo; esto no es lo mismo que un fallo de autenticación. 401 verifica el Token, 404 verifica el ID del modelo y la URL base `/v1`.
