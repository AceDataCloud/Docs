La documentación oficial del modelo personalizado de Coze admite la API de Anthropic Messages. Las diferentes versiones de inquilinos de Coze pueden manejar los encabezados, la concatenación de rutas, el streaming y las llamadas a herramientas de manera diferente; si es la primera vez que se conecta, verifique cada punto a continuación.

## Configuración

1. Ingrese a la gestión de modelos de Coze y agregue un modelo personalizado.
2. Seleccione el Protocolo de la API de Anthropic Messages.
3. Complete la URL base de la API con `https://api.acedata.cloud`.
4. Complete la clave de la API con su token de API de Ace Data Cloud.
5. Complete el modelo con el ID de modelo exacto que admite Anthropic Messages en el directorio de modelos.
6. Guarde y complete la prueba de conexión de Coze.
7. En Bot/Agente, envíe `Reply only OK`, y pruebe nuevamente la llamada a la herramienta.

## Límites Actuales

- Diferentes regiones, versiones o paquetes de Coze pueden mostrar diferentes formularios.
- La URL base de la API no debe tener `/v1/messages` añadido nuevamente; si la interfaz de usuario actual requiere explícitamente la URL completa de la API, siga las indicaciones del formulario.
- Messages, Chat Completions y Responses son tres rutas independientes y no pueden sustituirse entre sí para la verificación.
