## 1. Obtener API Key

Abre [la lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), accede a la aplicación disponible y copia el API Key.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configuración

Kilo CLI lee `kilo.jsonc` y obtiene el API Key del shell desde el que se inicia el CLI.

Escribe en `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Luego, en el shell actual, exporta el Token:

```bash
export ACEDATACLOUD_API_KEY="PEGA_TU_TOKEN_DE_ACEDATACLOUD_AQUÍ"
```

## 3. Verificación

```bash
kilo run -m acedatacloud/MODEL_ID "Responde solo OK"
```

Si el CLI no puede leer el Token, asegúrate de que la variable ya esté `exportada`, y no solo escrita en un archivo `.env` no cargado.
