## 1. Obtener API Key

Abre la [lista de aplicaciones de Ace Data Cloud](https://platform.acedata.cloud/console/applications), entra en una aplicación disponible y copia la API Key.

![Obtener Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Añadir un modelo

En WorkBuddy, entra en **Configuración → Modelos → Modelos personalizados → Añadir modelo**, y luego completa:

| Campo       | Valor                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------ |
| Provider | `Custom`                                                                                         |
| Dirección de la interfaz     | `https://api.acedata.cloud/v1`                                                                   |
| API Key  | La API Key que acabas de copiar                                                                                    |
| Nombre del modelo     | Ve al [catálogo de modelos](https://platform.acedata.cloud/models) para consultar, y completa sin modificar el nombre del modelo que deseas invocar, por ejemplo `claude-opus-5`, `gpt-6-sol` |
| Protocolo personalizado    | Desactivado                                                                                               |

![Interfaz de configuración de WorkBuddy Custom Provider](https://cdn.acedata.cloud/189027b68722.png)

> El `id` aquí es el nombre del modelo utilizado por el parámetro `model` en las solicitudes API; no es el UUID del servicio, API o Application, ni tampoco un nombre de visualización personalizado. Solo puedes completar `ds-4.0` cuando el catálogo en tiempo real devuelva `{"id":"ds-4.0"}`; si no está en el catálogo, significa que no está disponible actualmente, no adivines ni abrevies.

Primero puedes consultar los modelos disponibles en el [catálogo de modelos](https://platform.acedata.cloud/models); si necesitas confirmar el nombre exacto que pueden invocar las credenciales Coding actuales, usa la API Key que acabas de copiar para consultar el catálogo de API:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Encuentra el modelo objetivo en el arreglo `data` de la respuesta y copia sin modificar su valor de `id`. Configura los interruptores de capacidades según el soporte real de ese modelo.

Al mantener desactivado el «protocolo personalizado», WorkBuddy completará la ruta según las reglas de OpenAI Chat Completions. Los interruptores de capacidades avanzadas (herramientas, imágenes, razonamiento) solo deben activarse según las capacidades reales del modelo seleccionado; si no estás seguro, primero mantén los valores predeterminados.

## 3. Verificación

Después de guardar, selecciona el modelo que acabas de añadir en el selector de modelos de chat y envía `Reply only OK`. Luego ejecuta una tarea de archivo o herramienta de solo lectura para confirmar que las capacidades necesarias están disponibles; los registros de llamadas pueden consultarse en el [historial de uso](https://platform.acedata.cloud/console/usages).

Si el modelo no aparece, confirma que la configuración se haya guardado y habilitado; para 401, revisa la Key; para 404, revisa si el nombre del modelo ingresado coincide completamente con el `id` del catálogo, y si la dirección de la interfaz es correcta. La documentación oficial de WorkBuddy indica que la Key se guarda en la configuración local, pero el contenido de las solicitudes seguirá enviándose al servicio de modelos configurado.
