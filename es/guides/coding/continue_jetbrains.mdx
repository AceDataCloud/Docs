El plugin de Continuar utiliza el mismo formato de modelo YAML que VS Code; la configuración y el secreto deben pertenecer al usuario que ejecuta el plugin de JetBrains.

## Configuración

Añadir en la configuración YAML local de Continuar:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Guardar `ACEDATACLOUD_API_KEY` en los secretos de Continuar. En el escenario de Desarrollo Remoto, se debe configurar en el host donde se ejecuta realmente el plugin.

## Verificación

Reiniciar el IDE de JetBrains, abrir la ventana de herramientas de Continuar, seleccionar el modelo de Configuración Local y enviar `Reply only OK`; luego ejecutar nuevamente la tarea de archivo de solo lectura. Si aún se utiliza el modelo antiguo, reiniciar el backend remoto y verificar la indentación del YAML.
