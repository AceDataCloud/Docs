Esta interfaz se basa en la [API Model de Fish Audio](https://docs.fish.audio/resources/api-reference/model) y se utiliza para **crear un modelo de voz clonada reutilizable a largo plazo basado en una muestra de audio**. La dirección es `POST https://api.acedata.cloud/fish/model`.

> Si solo necesita usar una voz de referencia temporalmente, no es necesario crear un modelo, puede usar directamente el `references` de la [API Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para clonar instantáneamente. Para buscar voces existentes, consulte la [API Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query); para consultar los detalles de una sola voz por `_id`, consulte la [API Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get).

## Proceso de Solicitud

Para usar la API Fish Model, primero obtenga su API Token en la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) y guárdelo para uso futuro.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no ha iniciado sesión o registrado, será redirigido automáticamente a la página de inicio de sesión que lo invitará a registrarse e iniciar sesión, y después volverá automáticamente a la página actual.

**Un API Token es suficiente para acceder a todos los servicios de la plataforma, no es necesario solicitar uno por cada servicio.** La primera solicitud incluirá un crédito gratuito para que pueda probarlo; si se queda sin créditos, puede recargar el saldo general en la [consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [API Fish Model →](https://platform.acedata.cloud/services/fish)

## Campos del Cuerpo de Solicitud

| Campo                    | Tipo       | Requerido | Descripción                                                                        |
| ----------------------- | -------- | -------- | --------------------------------------------------------------------------------- |
| `title`                 | string   | Sí       | Nombre de la voz, utilizado para identificar en la lista de la consola.          |
| `voices`                | string   | Sí       | URL HTTP(S) de la muestra de audio (**una sola cadena**, no un array). Esta interfaz no admite carga multipart/binaria, coloque el audio en cualquier almacenamiento de objetos accesible públicamente. |
| `description`           | string   | No       | Descripción de la voz.                                                            |
| `cover_image`           | string   | No       | URL HTTP(S) de la imagen de portada.                                             |
| `tags`                  | string[] | No       | Etiquetas de búsqueda de la biblioteca pública, por ejemplo, `["male","narration","zh"]`. |
| `texts`                 | string[] | No       | Texto de referencia correspondiente a la muestra (para corregir la pronunciación). |
| `enhance_audio_quality` | boolean  | No       | Si se debe mejorar la calidad del audio de la muestra antes del entrenamiento.    |
| `generate_sample`       | boolean  | No       | Si se debe generar automáticamente un audio de muestra después de completar el entrenamiento. |

> Los campos son idénticos a los de la interfaz superior, consulte también la [documentación oficial de Fish](https://docs.fish.audio/resources/api-reference/model).

## Ejemplo: Crear una voz clonada privada

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "Mi voz clonada",
    "description": "Voz en chino clonada de una grabación de podcast",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Nota: `voices` debe ser **una cadena** (una sola URL de audio), no un array. Si se envía como `["..."]`, la interfaz superior lo rechazará.

`_id` se puede usar como el valor del campo `reference_id` en la posterior [API Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para realizar la síntesis de voz con esta voz clonada:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hola, esta es una voz sintetizada usando mi voz clonada recién creada.",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Requisitos de la Muestra

Valores de experiencia (coinciden con la interfaz superior, consulte la [documentación oficial de Fish](https://docs.fish.audio/resources/api-reference/model)):

- Se recomienda una duración de más de 30 segundos y menos de 5 minutos; más de 10 minutos no ofrece grandes beneficios.
- Tasa de muestreo de 16 kHz o más, se acepta mono o estéreo.
- El contenido debe ser lo más limpio posible: sin música de fondo, ecos, ruidos ambientales evidentes; un solo hablante.
- Formato recomendado `mp3` / `wav`.

Si no está seguro de la calidad de la muestra, puede enviar `enhance_audio_quality: true` para que la interfaz superior mejore la calidad del audio primero.

## Descripción de la Facturación

Crear un modelo de voz clonada (`POST /fish/model`) es gratuito, no se cobran tarifas; las interfaces de consulta de voz ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query), [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) también son gratuitas. Los costos solo se generan al llamar a [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para sintetizar voz según el uso.

## Manejo de Errores
- `400 token_mismatched`：Faltan o son inválidos los parámetros de la solicitud (lo más común es que `voices` no sea una URL, o se haya pasado como un array).
- `401 invalid_token`：El token de autenticación no existe o es inválido.
- `429 too_many_requests`：Se ha activado el límite de velocidad de la cuenta.
- `500 api_error`：Error interno del servidor.

Ejemplo de respuesta de error:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices es requerido y debe ser una URL HTTP(S) que apunte a un archivo de audio"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusión

Para llamar a esta interfaz, solo necesitas preparar una URL de audio de muestra que sea accesible públicamente, ponerla en el campo `voices` y podrás obtener el `_id`, luego alimentarlo al `reference_id` de `/fish/tts` para completar el proceso de "clonación → síntesis". Un punto común de confusión es que `voices` debe ser una cadena, no puede ser un array.
