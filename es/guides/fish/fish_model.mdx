Este interfaz se basa en [Fish Audio 官方 Model API](https://docs.fish.audio/resources/api-reference/model) y se utiliza para **crear un nuevo clon de voz basado en una muestra de audio**. La dirección es `POST https://api.acedata.cloud/fish/model`.

> Para la búsqueda paginada de voces existentes, consulte [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query); para consultar los detalles de una sola voz por `_id`, consulte [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Proceso de Solicitud

Para usar la Fish Model API, primero dirígete a [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) para obtener tu API Token y guardarlo para uso futuro.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión que te invitará a registrarte e iniciar sesión; una vez completado, serás devuelto automáticamente a la página actual.

**Un API Token es suficiente para acceder a todos los servicios de la plataforma, no es necesario solicitar uno por cada servicio.** La primera solicitud incluye un crédito gratuito para que puedas probarlo; si el crédito se agota, puedes recargar el saldo general en [控制台](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Campos del Cuerpo de Solicitud

| Campo                    | Tipo       | Requerido | Descripción                                                                      |
| ----------------------- | -------- | -------- | ----------------------------------------------------------------------------- |
| `title`                 | string   | Sí       | Nombre de la voz, utilizado para identificar en la lista del panel de control. |
| `voices`                | string   | Sí       | URL HTTP(S) de la muestra de audio (**una sola cadena**, no un array). Este interfaz no soporta la carga multipart/binaria, coloca el audio en cualquier almacenamiento de objetos accesible públicamente. |
| `description`           | string   | No       | Descripción de la voz.                                                          |
| `cover_image`           | string   | No       | URL HTTP(S) de la imagen de portada.                                          |
| `visibility`            | string   | No       | `private` o `public`, por defecto `private`. `public` indica que se publica en la biblioteca pública de voces de Fish para que otros lo usen. |
| `tags`                  | string[] | No       | Etiquetas de búsqueda en la biblioteca pública, por ejemplo `["male","narration","zh"]`. |
| `texts`                 | string[] | No       | Texto de referencia correspondiente a la muestra (para corregir la pronunciación). |
| `enhance_audio_quality` | boolean  | No       | Si se debe mejorar la calidad del audio de la muestra antes del entrenamiento. |
| `generate_sample`       | boolean  | No       | Si se debe generar automáticamente un audio de muestra después de completar el entrenamiento. |

> Los campos son idénticos a los de upstream, consulte también [Fish 官方文档](https://docs.fish.audio/resources/api-reference/model).

## Ejemplo: Crear un clon de voz privado

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的中文音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png",
    "visibility": "private"
  }'
```

> Nota: `voices` debe ser **una cadena** (una sola URL de audio), no un array. Si se envía como `["..."]`, upstream lo rechazará.

La respuesta exitosa devuelve directamente el objeto ModelEntity de la plataforma Fish (el siguiente ejemplo es la voz mínima utilizable que hemos probado, se han eliminado algunos campos largos para facilitar la lectura):

`_id` se puede usar como el valor del campo `reference_id` en la posterior [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) para realizar la síntesis de voz con este clon de voz:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，这是一段使用我刚创建的克隆音色合成的语音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Requisitos de la Muestra

Valores de experiencia (coinciden con upstream, consulte [Fish 官方文档](https://docs.fish.audio/resources/api-reference/model)):

- La duración recomendada es de más de 30 segundos y menos de 5 minutos; más de 10 minutos tiene un rendimiento marginal.
- La tasa de muestreo debe ser de 16 kHz o más, se acepta mono o estéreo.
- El contenido debe ser lo más limpio posible: sin música de fondo, ecos, ruidos ambientales evidentes; un solo hablante.
- Se recomienda el formato `mp3` / `wav`.

Si no estás seguro de la calidad de la muestra, puedes enviar `enhance_audio_quality: true` para que upstream realice primero la mejora de calidad.

## Descripción de la Facturación

La creación de un modelo de clon de voz (`POST /fish/model`) es gratuita, no se cobra ninguna tarifa; las interfaces de consulta de voz ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query), [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) también son gratuitas. Los costos solo se generan al llamar a [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para sintetizar voz según el uso.

## Manejo de Errores
- `400 token_mismatched`：Parámetros de solicitud faltantes o no válidos (lo más común es que `voices` no sea una URL, o se haya pasado como un array).
- `401 invalid_token`：El token de autenticación no existe o es inválido.
- `429 too_many_requests`：Se ha activado el límite de velocidad de la cuenta.
- `500 api_error`：Error interno del servidor.

Ejemplo de respuesta de error:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices es requerido y debe ser una URL HTTP(S) que apunte a un archivo de audio"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusión

Para llamar a esta interfaz, solo necesitas preparar una URL de audio de muestra que sea accesible públicamente, ponerla en el campo `voices` y podrás obtener el `_id`, luego alimentarlo al `reference_id` de `/fish/tts` para completar el proceso de "clonación → síntesis". Un punto común de confusión es que `voices` debe ser una cadena, no un array.
