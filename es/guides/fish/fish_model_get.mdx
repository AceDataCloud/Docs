Esta interfaz se basa en la [API Model oficial de Fish Audio](https://docs.fish.audio/resources/api-reference/model) y se utiliza para **consultar los detalles completos de un solo tono de clonación por `_id`**. La dirección es `GET https://api.acedata.cloud/fish/model/{id}`.

> Para crear un tono, consulte la [API Fish Model Create](https://platform.acedata.cloud/documents/fish-model); para la búsqueda paginada, consulte la [API Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query).

## Proceso de solicitud

Para utilizar la API Fish Model, primero dirígete a la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obtener tu token de API, que debes guardar como respaldo.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión que te invita a registrarte e iniciar sesión; una vez completado, volverás automáticamente a la página actual.

**Un token de API es suficiente para acceder a todos los servicios de la plataforma, no es necesario solicitar uno por cada servicio.** La primera solicitud te otorgará un crédito gratuito para que puedas probarlo; si el crédito es insuficiente, puedes recargar el saldo general en la [consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [API Fish Model →](https://platform.acedata.cloud/services/fish)

## Parámetros de ruta

| Parámetro | Requerido | Descripción                                                                                                                                                                                                |
| --------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`      | Sí        | El `_id` del tono (cadena hexadecimal de 32 bits). Se puede obtener al crear a través de [Fish Model Create](https://platform.acedata.cloud/documents/fish-model) o mediante la búsqueda en [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query). |

Sin cuerpo de solicitud, sin parámetros de consulta.

## Ejemplo: Obtener los detalles completos de un tono público en español

```shell
curl 'https://api.acedata.cloud/fish/model/8d2c17a9b26d4d83888ea67a1ee565b2' \
  -H 'authorization: Bearer {token}'
```

El `_id` obtenido se puede usar directamente como `reference_id` en [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para sintetizar voz con el mismo tono:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

## Diferencias con la interfaz de lista

| Campo                                               | `GET /fish/model` (lista) | `GET /fish/model/{id}` (detalles) |
| -------------------------------------------------- | -------------------------- | ---------------------------------- |
| `samples[].audio`                                  | URL de caché R2 a corto plazo | Enlace directo R2 firmado (incluye firma de consulta) |
| `unliked` / `liked` / `marked` / `dmca_taken_down` | También existen            | También existen                    |
| `default_text` / `lock_visibility`                 | También existen            | También existen                    |

Si solo deseas escuchar, el `samples[].audio` de la interfaz de lista es suficiente; para enlaces de descarga más estables, se recomienda usar esta interfaz.

## Campos de respuesta (extracto)

| Campo            | Tipo     | Descripción                                      |
| ---------------- | -------- | ------------------------------------------------ |
| `_id`            | string   | ID del tono (utilizado como `reference_id` en `/fish/tts`). |
| `type`           | string   | Tipo de modelo, generalmente `tts`.              |
| `title`          | string   | Nombre del tono.                                 |
| `description`    | string   | Descripción larga.                               |
| `state`          | string   | Estado de entrenamiento: `trained` significa disponible, `training` significa que aún está en entrenamiento. |
| `tags`           | string[] | Etiquetas de la biblioteca pública.              |
| `samples`        | object[] | Muestras predefinidas, que incluyen `title`, `text`, `task_id`, `audio` enlace directo. |
| `languages`      | string[] | Códigos de idiomas en los que el tono es competente. |
| `visibility`     | string   | `public` o `private`.                            |
| `like_count`     | integer  | Número de "me gusta" en la biblioteca pública.   |
| `task_count`     | integer  | Número de síntesis históricas (puede usarse para referencia de popularidad). |
| `author`         | object   | Información del autor: `_id` / `nickname` / `avatar`. |
| `created_at`     | string   | Fecha de creación en formato ISO 8601.          |
| `updated_at`     | string   | Última fecha de actualización en formato ISO 8601. |

## Instrucciones de facturación

Esta interfaz no tiene costo: consultar los detalles de un tono por ID es una operación gratuita. Crear un tono ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) también es gratuito, los costos solo se generan al llamar a [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para sintetizar voz según el uso.

## Manejo de errores
- `400 token_mismatched`: El `id` en la ruta no tiene un formato válido, o el upstream reporta "Modelo no encontrado".
- `401 invalid_token`: El token de autenticación no existe o es inválido.
- `404 not_found`: El `_id` especificado no es visible en el upstream de Fish (el tono ha sido eliminado, es privado, o pertenece a otra cuenta).
- `429 too_many_requests`: Se ha activado el límite de velocidad de la cuenta.
- `500 api_error`: Error interno del servidor.

Al solicitar un ID que no existe, el upstream devolverá directamente `400 Model not found` (comprobado):

```shell
curl 'https://api.acedata.cloud/fish/model/test123' \
  -H 'authorization: Bearer {token}'
```

Devuelve:

```json
{ "status": 400, "message": "Model not found" }
```

Ejemplo de respuesta de error:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusión

Al conocer el `_id` del tono, se puede usar directamente esta interfaz para obtener el ModelEntity completo. El uso más común es: (1) escuchar `samples[].audio`, (2) proporcionar el `_id` a `reference_id` de `/fish/tts` para completar la síntesis. Si solo se tiene el título o las etiquetas, primero se debe usar [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) para realizar la búsqueda.
