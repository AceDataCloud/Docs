Esta API se basa en la [Model API oficial de Fish Audio](https://docs.fish.audio/resources/api-reference/model) y se utiliza para **consultar de forma paginada la biblioteca pública de voces de Fish o las voces clonadas de la cuenta actual**. La dirección es `GET https://api.acedata.cloud/fish/model`.

> Para crear una voz, consulte [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); para consultar los detalles de una sola voz por `_id`, consulte [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Proceso de solicitud

Para usar Fish Model API, primero vaya a la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obtener su API Token y guárdelo como respaldo.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no ha iniciado sesión o no se ha registrado, será redirigido automáticamente a la página de inicio de sesión para invitarle a registrarse e iniciar sesión; al completarlo, volverá automáticamente a la página actual.

**Un solo API Token puede invocar todos los servicios de la plataforma, sin necesidad de solicitarlo por separado para cada servicio.** La primera solicitud incluirá crédito gratuito, permitiendo una experiencia gratuita; cuando el crédito sea insuficiente, puede recargar saldo general en la [consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Parámetros de consulta

| Parámetro             | Tipo    | Predeterminado | Descripción                                                                                  |
| ---------------- | ------- | ---- | ------------------------------------------------------------------------------------- |
| `page_size`      | integer | 10   | Número de elementos por página.                                                                            |
| `page_number`    | integer | 1    | Número de página, a partir de 1.                                                                          |
| `title`          | string  | —    | Búsqueda aproximada por título.                                                                      |
| `tag`            | string  | —    | Filtrar por una sola etiqueta.                                                                      |
| `self`           | boolean | —    | Cuando `true`, solo se devuelven las voces creadas y guardadas mediante esta plataforma por la cuenta que realiza la llamada actual.                                |
| `author_id`      | string  | —    | Filtrar por ID del autor de la voz.                                                                  |
| `language`       | string  | —    | Filtrar por idioma de la voz, por ejemplo, `en`, `zh`, `es`.                                                  |
| `title_language` | string  | —    | Filtrar por idioma del título en la biblioteca pública de voces.                                                        |
| `sort_by`        | string  | —    | Campo de ordenación; cuando `self=true`, se admiten `created_at` y `task_count`.                              |

## Ejemplo 2: búsqueda difusa por título (`title`)

```shell

  -H 'authorization: Bearer {token}' \
```

## Ejemplo 3: listar solo las voces creadas por uno mismo (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Ejemplo de respuesta:

```json
{
  "total": 1,
  "items": [
    {
      "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
      "type": "tts",
      "title": "copilot-smoke-test",
      "description": "smoke test from api.acedata.cloud",
      "state": "trained",
      "languages": ["zh"],
      "visibility": "public",
      "samples": [
        {
          "title": "Default Sample",
          "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
          "task_id": "6a1bf398dfae49dca0e23159214342a0",
          "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
        }
      ],
      "created_at": "2026-05-10T03:52:55.601000Z",
      "author": {
        "_id": "780f2b2f862d41a08c0507bbbda77eb6",
        "nickname": "Penny Conrad"
      }
    }
  ],
  "has_more": false

```
`self=true` enumera, según la cuenta de llamada real, las voces creadas y guardadas a través de esta plataforma; las voces creadas por la misma cuenta usando diferentes API Token también se enumerarán juntas. Los resultados se paginan en orden descendente por hora de creación, y `author_id` puede filtrar adicionalmente el ID del autor de estas voces. Este parámetro solo filtra la lista; las voces siguen estando disponibles públicamente.

`self=true` no admite `title_language`; si necesita buscar por idioma del título, consulte la biblioteca pública de voces.

## Ejemplo 4: filtrar por idioma + etiqueta

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> La coincidencia de `tag` es más flexible; si el número de resultados es 0, se recomienda usar la coincidencia aproximada de `title`.

## Campos de respuesta

Cada elemento en `items[]` es un objeto ModelEntity completo, campos comunes:

| Campo            | Tipo       | Descripción                                        |
| ------------- | -------- | ----------------------------------------- |
| `_id`         | string   | ID de voz, como valor de `reference_id` en `/fish/tts`. |
| `type`        | string   | Tipo de modelo, normalmente `tts`.                           |
| `title`       | string   | Nombre de la voz.                                     |
| `description` | string   | Descripción de la voz.                                     |
| `state`       | string   | Estado de entrenamiento: `trained` indica que está disponible.                      |
| `tags`        | string[] | Etiquetas de la biblioteca pública.                                    |
| `languages`   | string[] | Idiomas en los que la voz destaca.                                  |
| `visibility`  | string   | `public` o `private`.                     |
| `samples`     | object[] | Muestras preestablecidas (incluyen enlace directo de `audio`).                       |
| `like_count`  | integer  | Número de «me gusta» en la biblioteca pública.                                   |
| `task_count`  | integer  | Número de síntesis históricas.                                   |
| `author`      | object   | Información del autor de la voz: `_id` / `nickname` / `avatar`.     |
| `total`（nivel superior）   | integer  | Número total de elementos que cumplen las condiciones.                                 |
| `has_more`    | boolean? | Es un valor booleano cuando `self=true`; las consultas de la biblioteca pública de voces pueden ser `null`.      |

## Descripción de facturación

Esta interfaz no tiene costo: la consulta paginada de la lista de voces es una operación gratuita. Crear voces ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) también es gratuito; los cargos solo se generan según el uso al llamar a [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para sintetizar voz.

## Manejo de errores

- `400 token_mismatched`: faltan parámetros de la solicitud o no son válidos.
- `401 invalid_token`: el token de autenticación no existe o no es válido.
- `429 too_many_requests`: se activó el límite de velocidad de la cuenta.
- `500 api_error`: error interno del servidor.

Ejemplo de respuesta de error:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusión

Para seleccionar una voz de la biblioteca pública de Fish y proporcionarla como `reference_id` de `/fish/tts`, primero use esta interfaz junto con `title` / `tag` / `language` para buscar, ubique el `_id` objetivo y luego use [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) para obtener muestras y escucharlas. Para enumerar las voces que creó usted mismo, simplemente pase `self=true`.
