Esta interfaz se basa en la [API Model de Fish Audio](https://docs.fish.audio/resources/api-reference/model) y se utiliza para **buscar de forma paginada en la biblioteca de voces públicas de Fish o en las voces clonadas de la cuenta actual**. La dirección es `GET https://api.acedata.cloud/fish/model`.

> Para crear voces, consulte la [API Fish Model Create](https://platform.acedata.cloud/documents/fish-model); para consultar los detalles de una sola voz por `_id`, consulte la [API Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get).

## Proceso de Solicitud

Para usar la API Fish Model, primero dirígete a la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obtener tu API Token, que debes guardar como respaldo.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión que te invitará a registrarte e iniciar sesión; una vez completado, volverás automáticamente a la página actual.

**Un API Token es suficiente para acceder a todos los servicios de la plataforma, no es necesario solicitar uno por cada servicio.** La primera solicitud incluirá un crédito gratuito para que puedas probarlo; si el crédito es insuficiente, puedes recargar el saldo general en la [consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [API Fish Model →](https://platform.acedata.cloud/services/fish)

## Parámetros de Consulta

| Parámetro         | Tipo      | Predeterminado | Descripción                                 |
| ----------------- | --------- | -------------- | ------------------------------------------- |
| `page_size`       | integer   | 10             | Número de elementos por página.             |
| `page_number`     | integer   | 1              | Número de página comenzando desde 1.       |
| `title`           | string    | —              | Búsqueda difusa por título.                 |
| `tag`             | string    | —              | Filtrar por una sola etiqueta.              |
| `self`            | boolean   | —              | Si es `true`, solo devuelve las voces creadas por la cuenta actual, sin condiciones adicionales. |
| `author_id`       | string    | —              | Filtrar por el `_id` del usuario superior.  |
| `language`        | string    | —              | Filtrar por el idioma de la voz, como `en`, `zh`, `es`. |
| `title_language`  | string    | —              | Filtrar por el idioma del título.           |
| `sort_by`         | string    | —              | Campo de ordenación, igual que en el superior, como `created_at`, `task_count`. |

> La nomenclatura de los parámetros es idéntica a la de `GET https://api.fish.audio/model`, consulte la [documentación oficial de Fish](https://docs.fish.audio/resources/api-reference/model).

## Ejemplo 2: Búsqueda difusa por título (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Respuesta (prueba real):

## Ejemplo 3: Listar solo las voces creadas por uno mismo (`self=true`)

```shell

  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

## Ejemplo 4: Filtrar por idioma + etiqueta
```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> El upstream también devolverá resultados para `tag` que no están en el diccionario de etiquetas, pero la coincidencia es relativamente laxa; si el número de coincidencias es 0, se sugiere usar coincidencias difusas con `title`.

## Campos de respuesta

Cada elemento en `items[]` es un objeto completo ModelEntity, campos comunes:

| Campo          | Tipo      | Descripción                                          |
| ------------- | -------- | ------------------------------------------------- |
| `_id`         | string   | ID de tono, como valor de `reference_id` en `/fish/tts`.         |
| `type`        | string   | Tipo de modelo, generalmente `tts`.                           |
| `title`       | string   | Nombre del tono.                                       |
| `description` | string   | Descripción del tono.                                   |
| `state`       | string   | Estado de entrenamiento: `trained` indica que está disponible.      |
| `tags`        | string[] | Etiquetas de la biblioteca pública.                     |
| `languages`   | string[] | Idiomas en los que el tono es experto.                  |
| `visibility`  | string   | `public` o `private`.                             |
| `samples`     | object[] | Muestras preestablecidas (incluye enlaces directos de `audio`).     |
| `like_count`  | integer  | Número de "me gusta" en la biblioteca pública.           |
| `task_count`  | integer  | Número de síntesis históricas.                          |
| `author`      | object   | Información del autor upstream: `_id` / `nickname` / `avatar`.     |
| `total` (nivel superior) | integer  | Número total de elementos que cumplen con los criterios.       |
| `has_more`    | boolean? | Indicador de paginación upstream, puede ser `null`. Se sugiere calcular el número total de páginas usando `total / page_size`. |

## Descripción de facturación

Esta interfaz no tiene costo: la consulta paginada de la lista de tonos es una operación gratuita. La creación de tonos ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) también es gratuita, los costos solo se generan al llamar a [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para sintetizar voz según el uso.

## Manejo de errores

- `400 token_mismatched`: Falta o es inválido un parámetro de solicitud.
- `401 invalid_token`: El token de autenticación no existe o es inválido.
- `429 too_many_requests`: Se ha activado el límite de velocidad de la cuenta.
- `500 api_error`: Error interno del servidor.

Ejemplo de respuesta de error:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusión

Para seleccionar un tono de la biblioteca pública de Fish para alimentar el `reference_id` de `/fish/tts`, primero use esta interfaz junto con `title` / `tag` / `language` para buscar, localizar el `_id` objetivo, y luego use [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) para obtener muestras de audio. Para listar los tonos que ha creado, simplemente pase `self=true`.
