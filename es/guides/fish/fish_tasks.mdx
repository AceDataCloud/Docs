La principal función de la API de Fish Tasks es consultar el estado de ejecución de una tarea mediante el ID de tarea generado por la API de Fish Audios Generation.

Este documento detallará las instrucciones de integración de la API de Fish Tasks, ayudándole a integrar y aprovechar al máximo las potentes funciones de esta API. A través de la API de Fish Tasks, puede consultar fácilmente el estado de ejecución de las tareas de la API de Fish Audios Generation.

## Proceso de solicitud

Para utilizar la API de Fish Tasks, primero debe ir a la página de solicitud [Fish Audios Generation API](https://platform.acedata.cloud/documents/fish-tts) para solicitar el servicio correspondiente, y luego copiar el ID de tarea de la API de Fish Audios Generation, como se muestra en la imagen:

<p><img src="https://cdn.acedata.cloud/jxvue8.png" width="500" className="m-auto" /></p>

Finalmente, acceda a la página de Tasks API [Fish Tasks API](https://platform.acedata.cloud/documents/fish-tasks) para solicitar el servicio correspondiente. Una vez en la página, haga clic en el botón "Acquire", como se muestra en la imagen:

![Página de solicitud](https://cdn.acedata.cloud/rci31i.png)

Si aún no ha iniciado sesión o registrado, será redirigido automáticamente a la [página de inicio de sesión](https://platform.acedata.cloud) para invitarle a registrarse e iniciar sesión. Después de registrarse e iniciar sesión, será redirigido automáticamente a la página actual.

En la primera solicitud, se le otorgará un crédito gratuito, que le permitirá utilizar esta API de forma gratuita.

## Ejemplo de solicitud

La API de Fish Tasks se puede utilizar para consultar los resultados de la API de Fish Audios Generation. Para obtener información sobre cómo utilizar la API de Fish Audios Generation, consulte el documento [Fish Videos Generation API](https://platform.acedata.cloud/documents/fish-tts-integration).

Tomaremos como ejemplo un ID de tarea devuelto por el servicio de la API de Fish Audios Generation. Supongamos que tenemos un ID de tarea: 2725a2d3-f87e-4905-9c53-9988d5a7b2f5, a continuación, se demostrará cómo utilizar esta API pasando un ID de tarea.

### Configuración de encabezados de solicitud y cuerpo de solicitud

**Request Headers** incluye:

- `accept`: especifica que se aceptan respuestas en formato JSON, aquí se debe completar como `application/json`.
- `authorization`: la clave para llamar a la API, que puede seleccionarse directamente después de la solicitud.

**Request Body** incluye:

- `id`: el ID de tarea cargado.
- `action`: el método de operación sobre la tarea.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/fish/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5",
  "action": "retrieve"
}'
```

## 错误处理

在调用 API 时，如果遇到错误，API 会返回相应的错误代码和信息。例如：

- `400 token_mismatched`：Solicitud incorrecta, posiblemente debido a parámetros faltantes o inválidos.
- `400 api_not_implemented`：Solicitud incorrecta, posiblemente debido a parámetros faltantes o inválidos.
- `401 invalid_token`：No autorizado, token de autorización inválido o faltante.
- `429 too_many_requests`：Demasiadas solicitudes, ha superado el límite de tasa.
- `500 api_error`：Error interno del servidor, algo salió mal en el servidor.

### 错误响应示例

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "la recuperación falló"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
