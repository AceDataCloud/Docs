Este documento presenta las instrucciones para integrar la API Gemini Videos Generation, que permite generar videos de Google Gemini (omni-flash) a partir de indicaciones de texto (y opcionalmente imágenes de referencia).

## Proceso de solicitud

Para usar la API, primero debe solicitar el servicio correspondiente en la página de [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos). Al ingresar, haga clic en el botón «Acquire», como se muestra en la imagen:

![](https://cdn.acedata.cloud/q6ytrc.png)

Si aún no ha iniciado sesión o registrado, será redirigido automáticamente a la página de inicio de sesión para registrarse e ingresar. Después de iniciar sesión, volverá automáticamente a esta página.

Al solicitar por primera vez, se otorgará un crédito gratuito para usar la API sin costo.

## Uso básico

Primero, conozca la forma básica de uso: ingresando la indicación `prompt`, el modelo `model` y la relación de aspecto `aspect_ratio`, podrá generar el video correspondiente.

Aquí configuramos los encabezados de la solicitud (Request Headers), que incluyen:

- `accept`: el formato de respuesta deseado, aquí se establece como `application/json` (formato JSON).
- `authorization`: la clave para llamar a la API, que puede seleccionar directamente tras la solicitud.

Además, configuramos el cuerpo de la solicitud (Request Body), que incluye:

- `prompt`: texto que describe el contenido del video a generar, **obligatorio**.
- `model`: modelo para generar el video, actualmente solo soporta `omni-flash`, que es el valor predeterminado.
- `aspect_ratio`: relación de aspecto del video generado, puede ser `16:9` (horizontal) o `9:16` (vertical), por defecto `16:9`.
- `image_urls`: arreglo opcional de enlaces a imágenes (o videos) de referencia para guiar la generación, los elementos vacíos serán ignorados.
- `callback_url`: URL para callback asíncrono; si se establece, la API devolverá inmediatamente un `task_id` y enviará el resultado final a esta dirección mediante POST cuando la tarea termine.

Haga clic en el botón «Try» para probar, y el resultado será similar al siguiente:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Los campos del resultado son:

- `success`: indica si la solicitud de generación de video fue exitosa.
- `task_id`: ID de la tarea de generación de video.
- `trace_id`: ID de rastreo para depuración.
- `data`: lista con los resultados de los videos generados.
  - `id`: identificador único del video generado.
  - `video_url`: enlace al video generado.
  - `state`: estado de la tarea de generación, puede ser `pending` / `succeeded` / `failed`.

Solo necesita obtener el video generado mediante el enlace `video_url` en `data`.

El código CURL correspondiente es:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

El código Python correspondiente es:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Generación de video a partir de imágenes

Si desea generar un video basado en imágenes de referencia, puede pasar uno o varios enlaces en `image_urls` para guiar la generación:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## Callback asíncrono

La generación de video requiere cierto tiempo de procesamiento. Si no desea mantener una conexión larga esperando, puede proporcionar `callback_url`. En este caso, la API devolverá inmediatamente un `task_id` y enviará el resultado final mediante POST a esa URL cuando la tarea termine:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

La respuesta inmediata será:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Consulta del resultado de la tarea

Si usa callback asíncrono o desea consultar el estado de la tarea activamente, puede usar la [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) para consultar el estado y resultado más reciente mediante el `task_id`.

## Manejo de errores

Cuando ocurre un problema en la solicitud, la API devuelve un código de error y descripción. Los más comunes son:

- `400`: error en los parámetros de la solicitud, por ejemplo falta `prompt` o valor inválido en `aspect_ratio`.
- `401`: fallo de autenticación, token inválido o no coincide con la API.
- `403`: saldo insuficiente o la indicación fue rechazada por revisión de contenido.
- `500`: error interno del servidor o fallo en la generación upstream.
