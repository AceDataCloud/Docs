Este documento presentará las instrucciones de integración de la API de generación de videos de Gemini, que puede generar videos de Google Gemini (omni-flash) a través de la entrada de texto de indicación (y una imagen de referencia opcional).

## Proceso de solicitud

Para utilizar la API de generación de videos de Gemini, primero dirígete a [la consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obtener tu token de API, que debes guardar como respaldo.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión que te invitará a registrarte e iniciar sesión; una vez completado, regresarás automáticamente a la página actual.

**Un token de API es suficiente para acceder a todos los servicios de la plataforma, no es necesario solicitar uno por cada servicio.** La primera solicitud te otorgará un crédito gratuito para que lo pruebes; si el crédito es insuficiente, puedes recargar el saldo general en [la consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [API de generación de videos de Gemini →](https://platform.acedata.cloud/documents/gemini-videos)

## Uso básico

Primero, comprende la forma básica de uso, ingresando la palabra clave `prompt`, el modelo `model` y la relación de aspecto `aspect_ratio`, lo que generará el video correspondiente.

Aquí podemos ver que hemos configurado los encabezados de la solicitud, que incluyen:

- `accept`: el formato de respuesta que deseas recibir, aquí se establece como `application/json`, es decir, formato JSON.
- `authorization`: la clave para llamar a la API, que puedes seleccionar directamente después de solicitarla.

Además, se ha configurado el cuerpo de la solicitud, que incluye:

- `prompt`: la palabra clave de texto que describe el contenido del video que deseas generar, **obligatorio**.
- `model`: el modelo para generar el video, actualmente solo se admite `omni-flash`, que es el valor predeterminado.
- `aspect_ratio`: la relación de aspecto del video generado, puede ser `16:9` (horizontal) o `9:16` (vertical), el valor predeterminado es `16:9`.
- `resolution`: la resolución de salida opcional, puede ser `720p` o `1080p`, el valor predeterminado es `720p`.
- `image_urls`: un array de enlaces de imágenes de referencia opcionales, que se utilizan para guiar la generación del video; los campos vacíos se ignorarán. Cuando se utiliza `video_urls` para la edición de video, este parámetro es obligatorio (al menos una imagen).
- `video_urls`: un array de enlaces de videos de referencia opcionales (máximo 1), utilizado para **edición de video / referencia de video**; si se proporciona, se debe proporcionar al menos una `image_urls`.
- `callback_url`: dirección de callback asíncrona, al configurarla, la API devolverá inmediatamente `task_id`, y cuando la tarea esté completa, enviará el resultado a esa dirección.
- `async`: opcional, si se establece en `true`, la interfaz devolverá inmediatamente `task_id`, sin necesidad de proporcionar `callback_url`, y luego se puede consultar el resultado a través de la interfaz de consulta de tareas correspondiente.

Haz clic en el botón "Try" para realizar una prueba, y el resultado obtenido será similar al siguiente:

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://platform2.cdn.acedata.cloud/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "Una toma cinematográfica de un gatito persiguiendo una mariposa en un jardín iluminado por el sol"
    }
  ],
  "started_at": "2026-07-15T10:55:53.856Z",
  "finished_at": "2026-07-15T10:57:01.328Z",
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

El resultado devuelto tiene varios campos, que se describen a continuación:

- `success`: si la solicitud de generación de video fue exitosa.
- `task_id`: el ID de la tarea de generación de video.
- `trace_id`: el ID de seguimiento de la solicitud, utilizado para resolver problemas.
- `data`: lista de resultados del video generado.
  - `id`: identificador único del video generado.
  - `video_url`: enlace al video generado (si `state` es `pending`, será `null`).
  - `state`: estado de la tarea de generación de video, puede ser `pending` / `succeeded` / `failed`.
  - `aspect_ratio`: la relación de aspecto del video, que coincide con el parámetro de solicitud.
  - `prompt`: la palabra clave utilizada para generar el video.

Cuando se devuelve de forma sincrónica, también se incluirán los campos `started_at`, `finished_at`, `elapsed` (tiempo transcurrido, en segundos) y `cost` (costo de esta transacción, en créditos).

Solo necesitamos obtener el video generado a través de la dirección del enlace `video_url` en `data`.

El código CURL correspondiente es el siguiente:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Una toma cinematográfica de un gatito persiguiendo una mariposa en un jardín iluminado por el sol",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

El código Python correspondiente es el siguiente:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "Una toma cinematográfica de un gatito persiguiendo una mariposa en un jardín iluminado por el sol",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Generación de video a partir de imágenes

Si deseas generar un video basado en imágenes de referencia, puedes pasar uno o más enlaces de imágenes en `image_urls`, que se utilizarán para guiar la generación del video:

```json
{
  "prompt": "La mujer se da la vuelta lentamente y sonríe a la cámara, suave brisa",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3.png"
  ]
}
```

## Edición de video / Video de referencia (video de entrada, video generado)

Se admite "ingresar un video y generar un nuevo video": pasa un enlace de video de referencia en `video_urls` (máximo 1), y **simultáneamente** proporciona al menos una imagen de referencia en `image_urls` (requisito estricto de upstream), luego usa `prompt` para describir el efecto de edición deseado (cambiar estilo, cambiar escena, agregar o eliminar elementos, etc.).

A continuación se muestra un ejemplo completo y real: transformar un video de una playa soleada en una escena invernal con nieve, manteniendo la disposición de la playa, las palmeras y el bote. La edición de video toma más tiempo (en este caso, aproximadamente 6.5 minutos), por lo que se envía de forma asíncrona con `async: true`:
```json
{
  "prompt": "Convierte esta playa tropical soleada en una escena invernal nevada con nieve cayendo intensamente y cielo nublado; mantén la misma playa, palmeras y disposición de botes.",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://platform2.cdn.acedata.cloud/seedance/dd3dc063-3383-4f29-bedc-e771a096758c.mp4"
  ],
  "async": true
}
```

Después de enviar, la interfaz devuelve inmediatamente `task_id`:

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

Luego, usa ese `task_id` como `id` para consultar la [API de Tareas de Gemini](https://platform.acedata.cloud/documents/gemini-tasks), una vez que la tarea esté completa, podrás obtener el nuevo video generado (este es el resultado real de este ejemplo):

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://platform2.cdn.acedata.cloud/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "Convierte esta playa tropical soleada en una escena invernal nevada con nieve cayendo intensamente y cielo nublado; mantén la misma playa, palmeras y disposición de botes."
    }
  ],
  "started_at": "2026-07-15T03:01:22.914Z",
  "finished_at": "2026-07-15T03:07:57.090Z",
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Si deseas un resultado de mayor calidad, puedes establecer `resolution` en `1080p` (los demás parámetros permanecen igual).

> Sugerencia: Los enlaces de medios de entrada/salida en el ejemplo son resultados generados reales. **Los enlaces de videos e imágenes generados por la plataforma tienen un período de validez, después de lo cual caducarán**, asegúrate de descargar y guardar los resultados en tu almacenamiento a tiempo.

> Nota: Se permite un máximo de 1 video de referencia; y al proporcionar `video_urls` se debe incluir al menos una `image_urls`, de lo contrario, se devolverá el siguiente error de parámetros:

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (al menos una imagen de referencia) es requerida cuando se proporciona video_urls."
  }
}
```

## Callback Asíncrono

La generación de videos requiere un tiempo de procesamiento. Si no deseas mantener una conexión larga esperando, puedes enviar `callback_url`, en este caso, la API devolverá inmediatamente `task_id`, y una vez que la tarea esté completa, enviará el resultado final a esa dirección:

```json
{
  "prompt": "Una toma cinematográfica de un gatito persiguiendo una mariposa en un jardín iluminado por el sol",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

El resultado devuelto inmediatamente es el siguiente:

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## Consultar Resultados de Tareas

Si utilizaste un callback asíncrono o deseas consultar el estado de la tarea de forma proactiva, puedes hacerlo a través de la [API de Tareas de Gemini](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) utilizando el `task_id` devuelto al crear el video como `id`:

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

El resultado devuelto una vez que la tarea esté completa es similar al siguiente, la estructura de `response.data` es la misma que cuando se genera de forma sincrónica (mientras se genera, `state` es `pending`, `video_url` es `null`):

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
  "type": "videos",
  "request": {
    "model": "omni-flash",
    "prompt": "Un time-lapse de nubes sobre montañas nevadas al amanecer",
    "aspect_ratio": "16:9",
    "async": true
  },
  "response": {
    "success": true,
    "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
    "data": [
      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
        "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4",
        "state": "succeeded",
        "aspect_ratio": "16:9",
        "prompt": "Un time-lapse de nubes sobre montañas nevadas al amanecer"
      }
    ],
    "elapsed": 96.716,
    "cost": {
      "amount": 1.932,
      "currency": "credit",
      "list_amount": 2.1
    }
  }
}
```

## Manejo de Errores

Cuando hay un problema con la solicitud, la API devolverá el código de error correspondiente y la descripción, los más comunes son:

- `400`: Parámetros de solicitud incorrectos, como falta de `prompt` o valor ilegal de `aspect_ratio`.
- `401`: Fallo de autenticación, token inválido o no coincide con la API.
- `403`: Saldo insuficiente, o el mensaje de advertencia ha sido rechazado por la revisión de contenido.
- `500`: Error interno del servidor o fallo en la generación upstream.
