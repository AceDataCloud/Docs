La función principal de la API Gemini Tasks es consultar el estado de ejecución de una tarea mediante el ID de tarea generado por la API Gemini Videos Generation.

Este documento describe detalladamente cómo integrar la API Gemini Tasks para facilitar la consulta del estado de las tareas de la API Gemini Videos Generation.

## Proceso de solicitud

Para usar la API Gemini Tasks, primero debe solicitar el servicio correspondiente en la página [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos) y copiar el ID de tarea que devuelve la API Gemini Videos Generation.

Luego, acceda a la página [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) para solicitar el servicio correspondiente. Una vez en la página, haga clic en el botón «Acquire».

Si aún no ha iniciado sesión o registrado, será redirigido automáticamente a la [página de inicio de sesión](https://platform.acedata.cloud) para que se registre o inicie sesión. Tras hacerlo, volverá automáticamente a la página actual.

La primera solicitud incluye un crédito gratuito para usar esta API sin costo.

## Ejemplo de solicitud

La API Gemini Tasks se utiliza para consultar los resultados de la API Gemini Videos Generation.

### Configuración de encabezados y cuerpo de la solicitud

**Encabezados de la solicitud** incluyen:

- `accept`: especifica que se espera una respuesta en formato JSON, se debe establecer en `application/json`.
- `authorization`: la clave para llamar a la API, que puede seleccionarse directamente tras la solicitud.

**Cuerpo de la solicitud** incluye:

- `id`: el ID de la tarea que se desea consultar.
- `action`: la acción a realizar sobre la tarea, para una consulta individual se usa `retrieve`.

### Ejemplo de código CURL

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Ejemplo de respuesta

Si la solicitud es exitosa, la API devolverá los detalles de la tarea. El campo `request` contiene el cuerpo de la solicitud original, y el campo `response` contiene el cuerpo de la respuesta tras completar la tarea, por ejemplo:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
        "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Descripción de los campos:

- `id`: ID de la tarea generada, que identifica de forma única esta tarea.
- `request`: información de la solicitud dentro de la tarea consultada.
- `response`: información de la respuesta dentro de la tarea consultada.

## Consulta por lotes

Para consultar detalles de múltiples tareas, establezca `action` en `retrieve_batch` y pase un arreglo de IDs mediante `ids`:

**Cuerpo de la solicitud** incluye:

- `ids`: arreglo de IDs de tareas que se desean consultar.
- `action`: la acción a realizar sobre las tareas, para consulta por lotes se usa `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
