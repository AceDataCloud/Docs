La principal función de la API de Gemini Tasks es consultar el estado de ejecución de una tarea mediante el ID de tarea generado por la API de Gemini Videos Generation.

Este documento detallará las instrucciones de integración de la API de Gemini Tasks, ayudándole a integrar y consultar fácilmente el estado de ejecución de las tareas de la API de Gemini Videos Generation.

## Proceso de solicitud

Para utilizar la API de Gemini Videos Generation, primero dirígete a [la consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obtener tu token de API, que debes guardar para uso futuro.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Si aún no has iniciado sesión o registrado, serás redirigido automáticamente a la página de inicio de sesión que te invitará a registrarte e iniciar sesión; una vez completado, serás redirigido automáticamente a la página actual.

**Un token de API es suficiente para acceder a todos los servicios de la plataforma, no es necesario solicitar uno por cada servicio.** La primera solicitud incluirá un crédito gratuito para que puedas probarlo; si el crédito es insuficiente, puedes recargar el saldo general en [la consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [API de Gemini Videos Generation →](https://platform.acedata.cloud/documents/gemini-videos)

## Ejemplo de solicitud

La API de Gemini Tasks se puede utilizar para consultar los resultados de la API de Gemini Videos Generation.

### Configuración de encabezados de solicitud y cuerpo de solicitud

**Encabezados de solicitud** incluyen:

- `accept`: especifica que se aceptan respuestas en formato JSON, aquí se debe escribir `application/json`.
- `authorization`: la clave para llamar a la API, que puedes seleccionar directamente después de solicitarla.

**Cuerpo de solicitud** incluye:

- `id`: el ID de la tarea que deseas consultar.
- `action`: el método de operación sobre la tarea, para una consulta individual se debe escribir `retrieve`.

### Ejemplo de código CURL

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Ejemplo de respuesta

Después de una solicitud exitosa, la API devolverá la información detallada de la tarea aquí. El campo `request` es el cuerpo de la solicitud al iniciar la tarea, y el campo `response` es el cuerpo de la respuesta devuelto después de completar la tarea, por ejemplo:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "Una toma cinematográfica de un gatito persiguiendo una mariposa en un jardín iluminado por el sol",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
        "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

La descripción de los campos es la siguiente:

- `id`: el ID de la tarea generada, utilizado para identificar de manera única esta tarea de generación.
- `request`: información de la solicitud en la tarea consultada.
- `response`: información de la respuesta en la tarea consultada.
- `created_at`: hora de creación de la tarea, marca de tiempo Unix (segundos, punto flotante).
- `started_at`: hora de inicio de ejecución de la tarea, cadena de tiempo UTC ISO-8601.
- `finished_at`: hora de finalización de la tarea, marca de tiempo Unix (segundos, punto flotante). Este campo no se devuelve si la tarea no se ha completado.
- `elapsed`: tiempo de ejecución de la tarea, en segundos (punto flotante, con 3 decimales). Este campo no se devuelve si la tarea no se ha completado.

## Operación de consulta por lotes

Para consultar los detalles de varias tareas ID, establece `action` como `retrieve_batch` y pasa un array de IDs de tarea a través de `ids`:

**Cuerpo de solicitud** incluye:

- `ids`: array de IDs de tarea que deseas consultar.
- `action`: el método de operación sobre la tarea, para consultas por lotes se debe escribir `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
