Maestro es una interfaz de producción de video **nativa para Agent**: usas una frase de lenguaje natural `prompt` para describir el video que deseas (opcionalmente adjuntas imágenes / videos / audios de referencia con `file_urls`), y un «director de IA» sin interfaz completará automáticamente la selección del tema, la escritura del guion, la generación de imágenes, la locución, la música, la composición y el renderizado, produciendo finalmente un video terminado con subtítulos y cargándolo en el CDN.

Este documento presentará en detalle la guía de integración de la API de generación de videos Maestro, para ayudarte a integrarla rápidamente y aprovechar plenamente las capacidades de esta API.

Esta es una interfaz de **tareas asíncronas**: después de enviarla, devolverá inmediatamente `task_id`, y luego podrás obtener el resultado mediante sondeo a través de la [API de consulta de tareas Maestro](/es/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (el sondeo es gratuito y no se factura). Para continuar iterando sobre un video existente, puedes usar `action: remix` / `edit` / `extend` junto con `ref_task_id`.

## Proceso de solicitud

Para usar la API de generación de videos Maestro, primero ve a la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obtener tu API Token y guárdalo para su uso posterior.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no has iniciado sesión o te has registrado, serás redirigido automáticamente a la página de inicio de sesión para invitarte a registrarte e iniciar sesión; al completarlo, regresarás automáticamente a la página actual.

**Un único API Token permite llamar a todos los servicios de la plataforma; no es necesario solicitar uno por separado para cada servicio.** La primera solicitud otorgará crédito gratuito para que puedas probarlo sin costo; cuando el crédito sea insuficiente, puedes recargar saldo general en la [consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [API de generación de videos Maestro →](https://platform.acedata.cloud/documents/maestro-videos)

## Uso básico

`POST https://api.acedata.cloud/maestro/videos`

El uso más básico solo requiere proporcionar un `prompt` en lenguaje natural; el director de IA decidirá automáticamente el guion, las imágenes, la locución y la edición. Aquí primero conoceremos los encabezados y el cuerpo de la solicitud que se deben configurar.

Los **Request Headers** incluyen:

- `accept`: el formato en el que deseas recibir el resultado de la respuesta; aquí se completa como `application/json`, es decir, formato JSON.
- `authorization`: la clave para llamar a la API, que se puede seleccionar directamente en el menú desplegable después de solicitarla.
- `content-type`: el formato del cuerpo de la solicitud; aquí se completa como `application/json`.

El **Request Body** incluye principalmente:

- `prompt`: describe en lenguaje natural el video que deseas crear (tema, qué mostrar, estilo, audiencia).
- `langs`: matriz de idiomas del video terminado; solo se transmite uno cada vez, como `["zh-cn"]`; el valor predeterminado es `["zh-cn"]`.
- `aspect`: proporción de la imagen, `9:16` (predeterminado) / `16:9` / `1:1`.
- `duration`: duración objetivo (segundos), el valor predeterminado es 30.

Todos los campos del cuerpo de la solicitud se muestran en la siguiente tabla:

| Campo            | Tipo       | Obligatorio  | Descripción                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Sí   | Describe en lenguaje natural el video que deseas crear (tema, qué mostrar, estilo, audiencia). El guion, las imágenes, la locución y la edición son decididos por la IA                                                                                                                                                                             |
| `action`      | string   | No   | `generate` (predeterminado, genera un video nuevo) / `remix` / `edit` / `extend` (itera sobre un video existente; se debe usar junto con `ref_task_id`)                                                                                                                                                |
| `ref_task_id` | string   | No   | Obligatorio cuando `action` es remix / edit / extend: el `task_id` de la tarea histórica que sirve como punto de partida                                                                                                                                                                   |
| `file_urls`   | string[] | No   | Medios de referencia (URL de imagen / video / audio), como la imagen del producto o el logo que debe aparecer en pantalla, o un fragmento de material al que se deben añadir subtítulos                                                                                                                                                                             |
| `langs`       | string[] | No   | Idioma del video terminado; solo se puede transmitir uno cada vez, como `["zh-cn"]`; el valor predeterminado es `["zh-cn"]`                                                                                                                                                                                    |
| `aspect`      | string   | No   | `9:16` (predeterminado) / `16:9` / `1:1`, salida unificada en 1080p/30fps                                                                                                                                                                                  |
| `duration`    | int      | No   | Duración objetivo (segundos), el valor predeterminado es 30; admite **5–300 segundos**. Se factura según la duración real del video terminado, pero no superará la duración solicitada                                                                                                                                                                             |
| `scenario`    | string   | No   | Tipo de video: `auto` / `narrated` / `captions` / `avatar` / `drama`. `captions` requiere transmitir el video de origen, y `avatar` requiere transmitir un retrato                                                                                                                                    |
| `style`       | string   | No   | Preajuste de estilo visual: `auto` (predeterminado) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`; también acepta texto libre como sugerencia suave. Es ortogonal a `scenario` y no cambia el enrutamiento |
| `voice`       | string   | No   | Voz de narración (independiente del idioma y de uso común entre idiomas): `auto` (predeterminado) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`                                    |

A continuación se muestra un ejemplo concreto. Supongamos que queremos generar un video corto de divulgación científica en chino, vertical y de 20 segundos; el código CURL correspondiente es el siguiente:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

El código Python correspondiente es el siguiente:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Haz clic en ejecutar y podrás ver que se obtiene inmediatamente un resultado, como el siguiente:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

La introducción de los campos del resultado devuelto es la siguiente:
- `success`: si esta tarea se ha enviado correctamente.
- `task_id`: el ID de esta tarea de generación de video; úselo posteriormente para consultar los resultados mediante la [API de consulta de tareas de Maestro](/es/guides/maestro/maestro_tasks).
- `trace_id`: el ID de seguimiento de esta solicitud; puede proporcionarlo al soporte técnico para la localización cuando encuentre problemas.

Dado que la producción de video tarda bastante, la interfaz **devuelve `task_id` inmediatamente** aquí, y no esperará a que finalice el renderizado del video. A continuación, debe usar `task_id` para consultar los resultados; consulte la sección «Obtener resultados» para más detalles.

## Especificar tipo y estilo de video (scenario / style)

Cuando no se pasa `scenario`, la IA lo determina automáticamente (equivale a `auto`); si desea fijar el video a un tipo concreto, páselo explícitamente. Por ejemplo, para crear un **drama corto vertical**, puede especificar lo siguiente:

- `scenario`: tipo de video, aquí se establece como `drama` (drama corto con personajes + diálogos).
- `style`: estilo visual, aquí se establece como `cinematic` (calidad cinematográfica).

El código CURL de ejemplo de relleno es el siguiente:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Formas habituales de combinación:

- Cortometraje narrado: `scenario: "narrated"`.
- Subtítulos automáticos: `scenario: "captions"`, se debe usar `file_urls` para pasar el video de origen.
- Avatar digital / presentación oral: `scenario: "avatar"`, se debe usar `file_urls` para pasar una imagen de retrato.
- Drama corto: `scenario: "drama"` (personajes + diálogos).
- `style` es un preajuste de estilo visual (como `modern` / `neon` / `luxury`), no cambia el tipo, solo afecta a la apariencia.
- `voice` se utiliza para especificar el timbre de la narración (como `warm-female` / `deep-male`), no está relacionado con el idioma y es universal entre idiomas.

El resultado devuelto es coherente con «Uso básico», e igualmente devuelve `task_id` inmediatamente.

## Idioma del video final

Una tarea solo entrega un video final en un único idioma. `langs` solo puede contener un código de idioma, como `["zh-cn"]` o `["en"]`; pasar varios idiomas devolverá 400. Si necesita videos en distintos idiomas, cree las tareas por separado. La selección de idioma no cambia el precio por segundo.

## Iterar sobre un video existente (remix / edit / extend)

Pase `action` y el `ref_task_id` de la tarea anterior para realizar modificaciones diferenciales sobre la base del proyecto original (como «cambiar el título de la escena 2», «cambiar la locución», «oscurecer el conjunto»). Los cambios pequeños son rápidos; los grandes se volverán a realizar:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: reinterpretar sobre la estructura original del video (mantiene el tema y ajusta la presentación).
- `edit`: realizar un refinamiento de partes especificadas (como cambiar el título, la locución o la corrección de color).
- `extend`: ampliar el contenido sobre la base del video original.

El resultado devuelto también devuelve inmediatamente un nuevo `task_id`; úselo para consultar y podrá obtener el video final iterado.

## Obtener resultados

Dado que la producción de video tarda bastante, esta interfaz devuelve `task_id` inmediatamente después del envío; debe usarlo para consultar los resultados mediante la [API de consulta de tareas de Maestro](/es/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Cuando la tarea se complete, devolverá información de un video final (ubicada en el array `variants`). `status` pasará por `pending → planning → producing → succeeded` (o `failed`), **la consulta es gratuita y no consume créditos**. Consulte las [instrucciones de integración de la API de consulta de tareas de Maestro](/es/guides/maestro/maestro_tasks) para conocer el formato de respuesta completo y la consulta de listas históricas.

## Facturación

**Tras el éxito de la tarea, se cobra según la duración real del video final entregado; los fallos no generan cargos.** La duración facturable se calcula en segundos enteros y no supera la duración solicitada; cuando no se puede leer la duración del video final, se recurre a la duración solicitada. El envío de la tarea no se factura por separado, y las consultas a `/maestro/tasks` son gratuitas.

```
Créditos = segundos facturables reales × 0.7
```

Todos los escenarios, acciones e idiomas utilizan el mismo precio, sin multiplicadores por escenario ni recargos por idioma. Cada tarea solo entrega un video final en un único idioma. La duración objetivo solicitada admite entre 5 y 300 segundos, con salida unificada de 1080p / 30fps.

| Duración facturable real              | Créditos |
| ------------------- | --: |
| 30 segundos                |  21 |
| 60 segundos                |  42 |
| 120 segundos               |  84 |
| 300 segundos               | 210 |
| Consulta de `/maestro/tasks` | Gratis |

## Manejo de errores

Al llamar a la API, si se produce un error, la API devolverá el código y la información de error correspondientes. Por ejemplo:

- `400 invalid_request`: Solicitud incorrecta, posiblemente debido a la falta de un `prompt` o a parámetros no válidos.
- `401 invalid_token`: No autorizado, token de autorización no válido o ausente.
- `403 forbidden`: Prohibido, saldo o acceso insuficiente.
- `429 too_many_requests`: Demasiadas solicitudes, ha superado el límite de tasa.
- `500 api_error`: Error interno del servidor, algo salió mal en el servidor.

### Ejemplo de respuesta de error

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
