Maestro es una interfaz de producción de video **nativa de Agent**: usas un `prompt` en lenguaje natural para describir el video que deseas (opcionalmente adjuntas imágenes / videos / audios de referencia con `file_urls`), y un «director de IA» sin interfaz completa automáticamente la selección de tema, escritura de guion, generación de imágenes, locución, música, composición y renderizado, para finalmente producir un video terminado con subtítulos y subirlo al CDN.

Este documento presentará en detalle la guía de integración de la API de generación de video Maestro, para ayudarte a integrarla rápidamente y aprovechar plenamente las capacidades de esta API.

Esta es una interfaz de **tareas asíncronas**: tras el envío devolverá inmediatamente un `task_id`, y posteriormente se obtendrán los resultados mediante sondeo a través de la [API de consulta de tareas Maestro](/es/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (el sondeo es gratuito y no se factura). Para continuar iterando sobre un video existente, puedes usar `action: remix` / `edit` / `extend` junto con `ref_task_id`.

## Proceso de solicitud

Para utilizar la API de generación de video Maestro, primero obtén tu API Token en la [consola de Ace Data Cloud](https://platform.acedata.cloud/console/applications) y guárdalo para su uso posterior.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si aún no has iniciado sesión o te has registrado, serás redirigido automáticamente a la página de inicio de sesión para invitarte a registrarte e iniciar sesión; al completarlo, volverás automáticamente a la página actual.

**Un solo API Token permite llamar a todos los servicios de la plataforma, sin necesidad de solicitar uno por separado para cada servicio.** La primera solicitud incluirá créditos gratuitos, permitiendo una experiencia gratuita; cuando los créditos sean insuficientes, puedes recargar saldo general en la [consola](https://platform.acedata.cloud/console/coin).

> 📘 Documentación completa: [API de generación de video Maestro →](https://platform.acedata.cloud/documents/maestro-videos)

## Uso básico

`POST https://api.acedata.cloud/maestro/videos`

El uso más básico solo requiere introducir un `prompt` en lenguaje natural; el director de IA decidirá automáticamente el guion, las imágenes, la locución y la edición. Aquí primero veremos los encabezados y el cuerpo de la solicitud que deben configurarse.

**Request Headers** incluyen:

- `accept`: qué formato de resultado de respuesta se desea recibir; aquí se completa con `application/json`, es decir, formato JSON.
- `authorization`: la clave para llamar a la API, que puede seleccionarse directamente en el menú desplegable después de solicitarla.
- `content-type`: el formato del cuerpo de la solicitud; aquí se completa con `application/json`.

**Request Body** incluye principalmente:

- `prompt`: describe en lenguaje natural el video que se desea crear (tema, qué mostrar, estilo, audiencia).
- `langs`: matriz de idiomas del video terminado; se transmite solo uno cada vez, como `["zh-cn"]`; el valor predeterminado es `["zh-cn"]`.
- `aspect`: proporción de imagen, `9:16` (predeterminado) / `16:9` / `1:1`.
- `duration`: duración objetivo (segundos), el valor predeterminado es 30.

Todos los campos del cuerpo de la solicitud se muestran en la siguiente tabla:

| Campo            | Tipo       | Obligatorio  | Descripción                                                                                                                                                                                                                                    |
| ------------- | -------- | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Sí   | Describe en lenguaje natural el video que se desea crear (tema, qué mostrar, estilo, audiencia). El guion, las imágenes, la locución y la edición son decididos por la IA                                                                                                                                                                                      |
| `action`      | string   | No   | `generate` (predeterminado, genera un video nuevo) / `remix` / `edit` / `extend` (itera sobre un video existente; debe usarse junto con `ref_task_id`)                                                                                                                                                         |
| `ref_task_id` | string   | No   | Obligatorio cuando `action` es remix / edit / extend: el `task_id` de la tarea histórica que sirve como punto de partida                                                                                                                                                                            |
| `file_urls`   | string[] | No   | Medios de referencia (URL de imagen / video / audio), como una imagen de producto, logo que debe aparecer en pantalla, o un fragmento de material al que se deben añadir subtítulos                                                                                                                                                                                      |
| `langs`       | string[] | No   | Idioma del video terminado; solo se puede transmitir uno cada vez, como `["zh-cn"]`; el valor predeterminado es `["zh-cn"]`                                                                                                                                                                                             |
| `aspect`      | string   | No   | `9:16` (predeterminado) / `16:9` / `1:1`, salida unificada en 1080p/30fps                                                                                                                                                                                           |
| `duration`    | int      | No   | Duración objetivo (segundos), el valor predeterminado es 30; admite **5–300 segundos**. Se factura según la duración real del video terminado, pero no superará la duración solicitada                                                                                                                                                                                      |
| `scenario`    | string   | No   | Tipo de video: `auto` / `narrated` / `captions` / `avatar` / `drama`. `captions` requiere transmitir el video fuente, y `avatar` requiere transmitir un retrato                                                                                                                                             |
| `style`       | string   | No   | Preajuste de estilo visual: `auto` (predeterminado) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`; también acepta texto libre como sugerencia flexible. Es ortogonal a `scenario` y no cambia el enrutamiento          |
| `voice`       | string   | No   | Timbre de voz de narración (independiente del idioma, universal entre idiomas): `auto` (predeterminado) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`; también admite `reference_id` de timbre de voz hexadecimal de 32 bits; otros textos libres no son ID de timbre de voz válidos |

A continuación se muestra una demostración mediante un ejemplo concreto. Supongamos que deseamos generar un video corto de divulgación científica en chino, vertical y de 20 segundos; el código CURL correspondiente es el siguiente:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

El código Python correspondiente es el siguiente:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Haz clic en ejecutar y verás que se obtiene inmediatamente un resultado, como se muestra a continuación:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

La introducción de los campos del resultado devuelto es la siguiente:
- `success`: si esta tarea se envió correctamente.
- `task_id`: el ID de esta tarea de generación de video, úsalo posteriormente para consultar el resultado mediante la [API de consulta de tareas de Maestro](/es/guides/maestro/maestro_tasks).
- `trace_id`: el ID de seguimiento de esta solicitud, que puede proporcionarse al soporte técnico para la localización en caso de problemas.

Dado que la producción de video tarda bastante tiempo, la interfaz **devuelve `task_id` inmediatamente** aquí y no espera a que finalice el renderizado del video. A continuación, debes usar `task_id` para consultar el resultado; consulta la sección «Obtener resultados» para más detalles.

## Especificar tipo y estilo de video (scenario / style)

Cuando no se pasa `scenario`, la IA lo determina automáticamente (equivale a `auto`); si deseas fijar el video a cierto tipo, pásalo explícitamente. Por ejemplo, para crear un **drama corto en formato vertical**, puedes especificar lo siguiente:

- `scenario`: tipo de video, aquí se establece como `drama` (drama corto con personajes + diálogos).
- `style`: estilo visual, aquí se establece como `cinematic` (textura cinematográfica).

El código CURL de ejemplo es el siguiente:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Formas comunes de combinación:

- Cortometraje narrado: `scenario: "narrated"`.
- Subtítulos automáticos: `scenario: "captions"`, se debe usar `file_urls` para pasar el video fuente.
- Avatar digital / locución a cámara: `scenario: "avatar"`, se debe usar `file_urls` para pasar una imagen de retrato.
- Drama corto: `scenario: "drama"` (personajes + diálogos).
- `style` es un preajuste de estilo visual (como `modern` / `neon` / `luxury`), no cambia el tipo, solo afecta a la apariencia.
- `voice` se utiliza para especificar el timbre de la narración (como `warm-female` / `deep-male`), no está relacionado con el idioma y es universal entre idiomas.

El resultado devuelto es consistente con «Uso básico»: también devuelve `task_id` inmediatamente.

## Idioma del video final

Una tarea solo entrega un video final en un idioma. `langs` solo puede contener un código de idioma, como `["zh-cn"]` o `["en"]`; pasar varios idiomas devolverá 400. Si necesitas videos en distintos idiomas, crea tareas por separado. La selección de idioma no cambia el precio por segundo.

## Iterar sobre un video existente (remix / edit / extend)

Pasa `action` y el `ref_task_id` de la tarea anterior para realizar modificaciones incrementales sobre el proyecto original (como «cambiar el título de la escena 2», «cambiar la locución», «oscurecer todo»). Los cambios pequeños son rápidos; los cambios grandes se volverán a realizar:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: reinterpretar sobre la estructura del video original (conserva el tema, ajusta la presentación).
- `edit`: realizar un refinamiento detallado en una parte especificada (como cambiar el título, cambiar la locución o ajustar el color).
- `extend`: extender el contenido sobre la base del video original.

El resultado devuelto también es un nuevo `task_id` inmediatamente; úsalo para consultar y obtener el video final iterado.

## Obtener resultados

Dado que la producción de video tarda bastante tiempo, esta interfaz devuelve `task_id` inmediatamente después del envío; debes usarlo para consultar el resultado mediante la [API de consulta de tareas de Maestro](/es/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Cuando la tarea se complete, devolverá información de un video final (ubicada en el array `variants`). `status` pasará por `pending → planning → producing → succeeded` (o `failed`), **la consulta es gratuita y no consume créditos**. Para el formato completo de respuesta y la consulta de listas históricas, consulta las [instrucciones de integración de la API de consulta de tareas de Maestro](/es/guides/maestro/maestro_tasks).

## Facturación

**Después de que la tarea se complete correctamente, se factura según la duración real del video final entregado; los fallos no se cobran.** La duración facturada se calcula en segundos enteros y no supera la duración solicitada; cuando no se puede leer la duración del video final, se recurre a la duración solicitada. El envío de tareas no se factura por separado, y la consulta de `/maestro/tasks` es gratuita.

```
Créditos = segundos reales facturables × 0.7
```

Todos los escenarios, acciones e idiomas utilizan el mismo precio, sin multiplicadores por escenario ni recargos por idioma. Cada tarea solo entrega un video final en un idioma. La duración objetivo solicitada admite de 5 a 300 segundos, con salida uniforme de 1080p / 30fps.

| Duración real facturable              | Créditos |
| ------------------- | --: |
| 30 segundos         |  21 |
| 60 segundos         |  42 |
| 120 segundos        |  84 |
| 300 segundos        | 210 |
| Consulta de `/maestro/tasks` | Gratis |

## Manejo de errores

Al llamar a la API, si se produce un error, la API devolverá el código de error y la información correspondientes. Por ejemplo:

- `400 invalid_request`: Solicitud incorrecta, posiblemente debido a un `prompt` faltante o parámetros no válidos.
- `401 invalid_token`: No autorizado, token de autorización no válido o faltante.
- `403 forbidden`: Prohibido, saldo o acceso insuficiente.
- `429 too_many_requests`: Demasiadas solicitudes, has excedido el límite de frecuencia.
- `500 api_error`: Error interno del servidor, algo salió mal en el servidor.

### Ejemplo de respuesta de error

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
