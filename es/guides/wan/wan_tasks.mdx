title: "Wan 任务查询 API"
description: "Wan API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/wan/tasks` se utiliza para consultar, consultar en lote o eliminar tareas de video Wan. La consulta de tareas no incurre en costos de generación duplicados.

## 查询单个任务

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

La `response.data.video_url` de la tarea completada es la dirección CDN permanente; `response.usage` incluye la resolución, los segundos de video de entrada/salida, la tasa de cuadros y la proporción; `response.cost` es la liquidación de la tarea generada.

## 批量查询

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Devuelve `{ "items": [...], "count": 2 }`. Puede que no haya `finished_at` y `response` final cuando la tarea está en progreso.

## 删除任务记录

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

La eliminación solo afecta el historial de tareas, no eliminará los videos CDN ya generados.
