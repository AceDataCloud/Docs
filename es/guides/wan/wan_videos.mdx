title: "Wan API de generación de videos"
description: "Wan API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/wan/videos` soporta simultáneamente el modelo existente Wan 2.6 y `wan3.0-video`. Wan 3 identifica automáticamente el texto, el primer y último fotograma o el modo de material de referencia según `media`.

## Wan 3 Video a partir de texto

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "Un barco de papel flotando a través de una ciudad de neón por la noche",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 soporta duraciones enteras de 2 a 30 segundos o `-1` para duración inteligente, con resoluciones de `480P`, `720P`, `1080P`.

## Referencia multimedia

```json
{
  "model": "wan3.0-video",
  "prompt": "Crear una revelación de producto cinematográfica",
  "media": [
    {"type":"first_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"},
    {"type":"last_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` soporta:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

Los modos de primer y último fotograma y el modo de material de referencia no se pueden mezclar. El video de referencia se contabiliza según la duración real del video de entrada más la duración del video de salida; la entrada de texto, imágenes y audio no aumenta la duración del video.

## Compatibilidad con Wan 2.6

Los modelos existentes `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` y las variantes de flash continúan utilizando parámetros como `action`, `image_url`, `reference_video_urls`, sin cambios en la ruta de llamada.

## Asincronía y resultados

Al establecer `async: true`, se obtiene inmediatamente un `task_id`, y se puede obtener el estado final a través de `/wan/tasks`. Los videos exitosos se almacenarán en el CDN de AceDataCloud y se devolverán en la respuesta el uso real y el costo.
