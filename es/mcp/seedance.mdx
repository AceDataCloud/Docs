[MCP (Model Context Protocol)](https://modelcontextprotocol.io) es un protocolo de contexto de modelos lanzado por Anthropic, que permite a los modelos de IA (como Claude, GPT, etc.) llamar a herramientas externas mediante interfaces estandarizadas. A través del Seedance MCP Server proporcionado por AceData Cloud, puedes usar directamente ByteDance Seedance para generar videos con IA en clientes de IA como Claude Desktop, VS Code, Cursor, etc.

## Resumen de funcionalidades

Seedance MCP Server proporciona las siguientes funcionalidades principales:

- **Generación de video a partir de texto** — Genera videos de alta calidad mediante indicaciones de texto
- **Generación de video a partir de imágenes** — Genera videos tomando imágenes como referencia (modos como primer fotograma, último fotograma, imagen de referencia, etc.)
- **Compatibilidad con múltiples modelos** — Compatible con Seedance 1.x, 1.5, 2.0 y 2.5
- **Múltiples resoluciones** — Compatible con 480p, 720p, 1080p; algunos modelos admiten 4k
- **Múltiples relaciones de aspecto** — Compatible con 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 y adaptive
- **Duración flexible** — Según el modelo, admite 2–30 segundos o duración automática
- **Video multimodal** — Compatible con generación de audio, audio/video de referencia, así como edición y extensión de video en 2.5
- **Consulta de tareas** — Supervisa el progreso de generación y obtiene resultados

## Recomendado: usar la autorización OAuth de MCP alojado

Agrega la dirección del servidor en clientes compatibles con OAuth de MCP remoto:

```text
https://seedance.mcp.acedata.cloud/mcp
```

Selecciona conectar o iniciar sesión, inicia sesión en Ace Data Cloud, revisa los permisos y autoriza, luego habilita las herramientas. Esta ruta no requiere crear ni copiar primero un API Token. El servicio ya admite OAuth discovery, registro dinámico de clientes (DCR) y S256 PKCE; DCR registra clientes, los usuarios aún deben iniciar sesión y autorizar, y el uso de la API se factura normalmente.

| Cliente                            | Método y condiciones de integración                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Versión web de Claude o versión Desktop que proporciona conectores remotos | Agrega la dirección anterior en la interfaz de conectores y autoriza; el acceso depende de la versión y el plan. No escribas la configuración HTTP remota en el archivo de configuración local de stdio.                      |
| VS Code compatible con OAuth de MCP remoto nativo     | Ejecuta **MCP: Add Server**, selecciona HTTP, introduce la dirección e inicia sesión según las indicaciones; la extensión dedicada AceDataCloud usa una configuración de API Key independiente. |
| Otros clientes                          | Confirma que la versión actual admite HTTP remoto, OAuth/DCR, y usa las instrucciones de configuración de ese cliente. Los formatos de archivos de configuración no son reutilizables entre distintos clientes.                     |

## Ruta alternativa con API Token

Para stdio local, autoalojamiento o clientes que no admiten OAuth remoto, usa un API Token. Inicia sesión en la [plataforma Ace Data Cloud](https://platform.acedata.cloud), selecciona el servicio y crea credenciales de API con los permisos necesarios. Guarda el Token en la configuración de credenciales del cliente o en variables de entorno locales, no lo incluyas en URL, contenido de chat ni repositorios. La configuración de HTTP Header para distintos clientes debe completarse según las instrucciones de su versión.

Instalar MCP de código abierto o completar la autorización no significa obtener cuotas gratuitas, ni garantiza el tiempo de generación o los derechos de uso comercial. Antes de generar, revisa los precios actuales del servicio, el saldo y los términos aplicables.

## Método dos: ejecución local (instalación mediante pip / uvx)

Si necesitas stdio local, código personalizado o autoalojamiento, puedes iniciar MCP Server localmente. La generación aún requiere conectarse a Internet para llamar a la API, no es inferencia sin conexión.

### Instalación

Instalación con pip (recomendada):

```bash
pip install mcp-seedance
```

O instalación desde el código fuente:

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Después de completar la instalación, puedes usar el comando `mcp-seedance` para iniciar el servicio.

### Uso en Claude Desktop (local)

Edita el archivo de configuración de Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Agrega la siguiente configuración:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tu API Token"
      }
    }
  }
}
```

Si usas `uvx` (sin necesidad de instalar el paquete previamente):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tu API Token"
      }
    }
  }
}
```

Guarda la configuración y reinicia Claude Desktop para que surta efecto.

### Uso en VS Code (local)

Crea `.vscode/mcp.json` en el directorio raíz del proyecto:

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tu API Token"
      }
    }
  }
}
```

O usa `uvx`:

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tu API Token"
      }
    }
  }
}
```

Para otros clientes locales, completa command, args y env según las instrucciones de configuración de stdio de su versión actual; no uses directamente la configuración de VS Code como formato universal.

## Verificación de resultados y fallos comunes

Pide al cliente que genere una obra de video sencilla, conserva el número de tarea y consulta la misma tarea hasta que alcance el estado final de éxito, luego abre o reproduce el enlace final. La conexión exitosa, la carga de la lista de herramientas, HTTP 200, el número de tarea y la vista previa durante el procesamiento no representan el producto final.

Si encuentras un 401, vuelve a iniciar sesión o revisa el Token y los permisos; si el saldo es insuficiente, revisa la facturación; mientras la tarea se procesa, continúa consultando; si falla finalmente, lee el error antes de decidir si reintentar, ya que una nueva generación podría volver a facturarse.

## Lista de herramientas disponibles

| Nombre de la herramienta                                  | Descripción             |
| ------------------------------------ | -------------- |
| `seedance_generate_video`            | Genera video mediante indicaciones de texto    |
| `seedance_generate_video_from_image` | Genera video tomando una imagen como referencia     |
| `seedance_get_task`                  | Consulta el estado de una tarea individual       |
| `seedance_get_tasks_batch`           | Consulta en lote el estado de las tareas       |
| `seedance_list_models`               | Enumera todos los modelos disponibles y sus capacidades   |
| `seedance_list_resolutions`          | Enumera las resoluciones y relaciones de aspecto disponibles   |
| `seedance_list_actions`              | Enumera todas las herramientas disponibles y ejemplos de flujos de trabajo |

## Ejemplos de uso

Una vez completada la configuración, puedes llamar directamente a estas funciones mediante lenguaje natural en el cliente de IA, por ejemplo:

- «Ayúdame a usar Seedance para generar un video de time-lapse de calles urbanas»
- «Usa esta foto como el primer fotograma para generar un video de 8 segundos»
- «Genera un video corto vertical de 1080p y 9:16»
- «Usa el modelo Seedance 1.5 Pro para generar un video con audio»
