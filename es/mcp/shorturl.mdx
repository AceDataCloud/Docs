[MCP (Model Context Protocol)](https://modelcontextprotocol.io) es un protocolo de contexto de modelo lanzado por Anthropic, que permite a modelos de IA (como Claude, GPT, etc.) llamar a herramientas externas a través de una interfaz estandarizada. Mediante el ShortURL MCP Server proporcionado por AceData Cloud, puedes generar enlaces cortos directamente en clientes de IA como Claude Desktop, VS Code, Cursor, entre otros.

## Resumen de Funcionalidades

El ShortURL MCP Server ofrece las siguientes funciones principales:

- **Acortamiento de un solo enlace** — Convierte URLs largas en enlaces cortos fáciles de compartir
- **Acortamiento masivo de enlaces** — Acorta múltiples URLs a la vez (hasta 10)
- **Guía de uso** — Obtén instrucciones completas y mejores prácticas
- **Información de API** — Consulta detalles del servicio API y códigos de error

## Requisitos Previos

Antes de usar, necesitas obtener el Token API de AceData Cloud:

1. Regístrate o inicia sesión en la [plataforma AceData Cloud](https://platform.acedata.cloud)
2. Ve a la página de la [API ShortURL](https://platform.acedata.cloud/documents/short-url)
3. Haz clic en «Acquire» para obtener el Token API (la primera solicitud incluye crédito gratuito)

## Instalación y Configuración

### Método 1: Instalación con pip (recomendado)

```bash
pip install mcp-shorturl
```

### Método 2: Instalación desde código fuente

```bash
git clone https://github.com/AceDataCloud/ShortURLMCP.git
cd ShortURLMCP
pip install -e .
```

Una vez instalado, puedes iniciar el servicio con el comando `mcp-shorturl`.

## Uso en Claude Desktop

Edita el archivo de configuración de Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Agrega la siguiente configuración:

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Tu Token API"
      }
    }
  }
}
```

Si usas `uvx` (sin necesidad de instalar paquetes previamente):

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "uvx",
      "args": ["mcp-shorturl"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Tu Token API"
      }
    }
  }
}
```

Guarda la configuración y reinicia Claude Desktop para usar las herramientas ShortURL en las conversaciones.

## Lista de Herramientas Disponibles

| Nombre de la herramienta     | Descripción                              |
|------------------------------|----------------------------------------|
| `shorturl_create`             | Acorta una sola URL                     |
| `shorturl_batch_create`       | Acorta múltiples URLs (hasta 10)       |
| `shorturl_get_usage_guide`    | Obtiene la guía completa de uso         |
| `shorturl_get_api_info`       | Obtiene detalles del servicio API       |

## Ejemplos de Uso

Después de configurar, puedes llamar a estas funciones directamente en el cliente de IA usando lenguaje natural, por ejemplo:

- «Ayúdame a acortar este enlace»
- «Acorta estos 5 URLs en lote»
- «Genera un enlace corto para compartir»
