[MCP (Model Context Protocol)](https://modelcontextprotocol.io) es un protocolo de contexto de modelos lanzado por Anthropic, que permite a los modelos de IA (como Claude, GPT, etc.) llamar herramientas externas a través de interfaces estandarizadas. Mediante Flux MCP Server proporcionado por AceData Cloud, puedes generar y editar imágenes de IA directamente en clientes de IA como Claude Desktop, VS Code, Cursor, entre otros.

## Resumen de funciones

Flux MCP Server ofrece las siguientes funciones principales:

- **Generación de imágenes a partir de texto** — Genera imágenes de alta calidad mediante indicaciones de texto
- **Edición de imágenes** — Edita imágenes existentes basándose en instrucciones de texto
- **Compatibilidad con múltiples modelos** — Compatible con diversos modelos como Flux Pro, Flux Dev, Flux 2, Flux Kontext, entre otros
- **Consulta de modelos** — Consulta todos los modelos disponibles y sus capacidades
- **Consulta de tareas** — Supervisa el progreso de generación y obtiene los resultados

## Preparativos previos

Antes de usarlo, necesitas obtener un API Token de AceData Cloud:

1. Regístrate o inicia sesión en la [plataforma AceData Cloud](https://platform.acedata.cloud)
2. Ve a la página de [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Haz clic en «Acquire» para obtener el API Token (la primera solicitud incluye crédito gratuito)

## Método uno: usar MCP Server alojado (recomendado, sin instalación)

AceData Cloud ya ha alojado **Flux MCP Server** en la nube, **sin necesidad de instalar ninguna dependencia localmente**; solo tienes que introducir la siguiente URL directamente en el cliente de IA para usarlo:

```
https://flux.mcp.acedata.cloud/mcp
```

Método de autenticación: añade `Authorization: Bearer 你的API Token` en el encabezado de la solicitud (Claude.ai lo completa automáticamente mediante OAuth, sin necesidad de introducir el Token manualmente).

### Claude.ai (versión web, inicio de sesión OAuth, la más sencilla)

1. Abre [Claude.ai](https://claude.ai) → **Customize** en la esquina inferior izquierda → **Connectors** → **Add More**
2. Introduce en URL: `https://flux.mcp.acedata.cloud/mcp`
3. Completa el inicio de sesión de autorización OAuth (redirige automáticamente a la página de inicio de sesión de AceData Cloud)
4. Vuelve a la interfaz de conversación y podrás usar las herramientas

### Claude Desktop

Edita el archivo de configuración:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Guarda y reinicia Claude Desktop para que los cambios surtan efecto.

### Claude Code (línea de comandos de terminal)

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Otros clientes compatibles con MCP

Cualquier cliente compatible con el protocolo MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant, etc.) puede conectarse completando los siguientes dos elementos:

- **URL**: `https://flux.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer 你的API Token`

## Método dos: ejecución local (instalación mediante pip / uvx)

Si necesitas ejecutarlo sin conexión, personalizar el código o implementarlo en una red interna, puedes instalar MCP Server localmente e iniciarlo mediante stdio.

### Instalación

Instalación mediante pip (recomendada):

```bash
pip install mcp-flux-pro
```

O instalación desde el código fuente:

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Una vez completada la instalación, puedes usar el comando `mcp-flux-pro` para iniciar el servicio.

### Uso en Claude Desktop (local)

Edita el archivo de configuración de Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Añade la siguiente configuración:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Si usas `uvx` (sin necesidad de instalar el paquete previamente):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Guarda la configuración y reinicia Claude Desktop para que los cambios surtan efecto.

## Lista de herramientas disponibles

| Nombre de herramienta   | Descripción |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | Genera imágenes mediante indicaciones de texto |
| `flux_edit_image`      | Edita imágenes existentes basándose en instrucciones de texto |
| `flux_generate_video`  | Generación de texto a video/imagen a video/video de FLUX 3 y mejora de borradores existentes |
| `flux_get_task`        | Consulta el estado de una sola tarea |
| `flux_get_tasks_batch` | Consulta por lotes el estado de las tareas |
| `flux_list_models`     | Enumera todos los modelos disponibles y sus capacidades |
| `flux_list_actions`    | Enumera todas las herramientas disponibles y ejemplos de flujos de trabajo |

## Ejemplos de uso

Una vez completada la configuración, puedes llamar directamente a estas funciones en el cliente de IA usando lenguaje natural, por ejemplo:

- «Ayúdame a generar con Flux una imagen de una escena nocturna urbana de estilo ciberpunk»
- «Cambia el fondo de esta foto por una playa»

## Restricciones de modelos y tamaños
`flux-2-flex`, `flux-2-pro`, `flux-2-max` y los modelos Kontext deben usar
proporciones para `size`, por ejemplo `1:1` o `16:9`, y no pueden usar dimensiones de píxeles como `1024x1024`.
`flux-2-klein` solo admite generación y no está entre los modelos opcionales de `flux_edit_image`.

`flux_generate_video` distingue `t2v`, `i2v`, `v2v` y
`draft_enhance` mediante `request.mode`, y las entradas se muestran según el modo. La mejora de borrador debe hacer referencia a su propio `draft_task_id` temporal.
El envío es asíncrono por defecto; conserva el ID de tarea devuelto y usa `flux_get_task` para leer el resultado.
