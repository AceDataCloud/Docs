[MCP (Model Context Protocol)](https://modelcontextprotocol.io) es un protocolo de contexto de modelo desarrollado por Anthropic, que permite a los modelos de IA (como Claude, GPT, etc.) llamar a herramientas externas a través de una interfaz estandarizada. Mediante el Flux MCP Server proporcionado por AceData Cloud, puedes generar y editar imágenes de IA directamente en clientes de IA como Claude Desktop, VS Code, Cursor, entre otros.

## Resumen de Funcionalidades

Flux MCP Server ofrece las siguientes funcionalidades principales:

- **Generación de imágenes a partir de texto** — Genera imágenes de alta calidad a partir de indicaciones textuales
- **Edición de imágenes** — Edita imágenes existentes basándose en instrucciones de texto
- **Soporte para múltiples modelos** — Compatible con modelos como Flux Pro, Flux Dev, Flux Schnell, Flux Kontext, entre otros
- **Consulta de modelos** — Visualiza todos los modelos disponibles y sus capacidades
- **Consulta de tareas** — Supervisa el progreso de generación y obtiene resultados

## Requisitos Previos

Antes de usar, necesitas obtener un Token API de AceData Cloud:

1. Regístrate o inicia sesión en la [plataforma AceData Cloud](https://platform.acedata.cloud)
2. Dirígete a la página de la [API Flux Images](https://platform.acedata.cloud/documents/flux-images)
3. Haz clic en "Acquire" para obtener el Token API (la primera solicitud incluye un crédito gratuito)

## Instalación y Configuración

### Método 1: Instalación con pip (recomendado)

```bash
pip install mcp-flux-pro
```

### Método 2: Instalación desde código fuente

```bash
git clone https://github.com/AceDataCloud/MCPFlux.git
cd MCPFlux
pip install -e .
```

Una vez instalado, puedes iniciar el servicio con el comando `mcp-flux-pro`.

## Uso en Claude Desktop

Edita el archivo de configuración de Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Agrega la siguiente configuración:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tu Token API"
      }
    }
  }
}
```

Si usas `uvx` (sin necesidad de preinstalar paquetes):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tu Token API"
      }
    }
  }
}
```

Guarda la configuración y reinicia Claude Desktop para usar las herramientas relacionadas con Flux en las conversaciones.

## Lista de Herramientas Disponibles

| Nombre de la herramienta | Descripción |
|--------------------------|-------------|
| `flux_generate_image`    | Genera imágenes a partir de indicaciones textuales |
| `flux_edit_image`        | Edita imágenes existentes basándose en instrucciones textuales |
| `flux_get_task`          | Consulta el estado de una tarea individual |
| `flux_get_tasks_batch`   | Consulta el estado de tareas en lote |
| `flux_list_models`       | Lista todos los modelos disponibles y sus capacidades |
| `flux_list_actions`      | Lista todas las herramientas disponibles y ejemplos de flujos de trabajo |

## Ejemplos de Uso

Después de la configuración, puedes invocar estas funciones directamente con lenguaje natural en el cliente de IA, por ejemplo:

- "Ayúdame a generar con Flux una imagen de una ciudad nocturna estilo cyberpunk"
- "Cambia el fondo de esta foto a una playa"
- "Edita esta imagen con el modelo Flux Kontext Pro para cambiar el color de la ropa a rojo"
- "Lista todos los modelos Flux disponibles"
