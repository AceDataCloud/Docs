[MCP (Model Context Protocol)](https://modelcontextprotocol.io) es un protocolo de contexto de modelos lanzado por Anthropic, que permite a los modelos de IA (como Claude, GPT, etc.) llamar herramientas externas mediante interfaces estandarizadas. A través de Suno MCP Server proporcionado por AceData Cloud, puedes generar directamente música, letras y gestionar proyectos de audio en clientes de IA como Claude Desktop, VS Code, Cursor, entre otros.

## Resumen de funcionalidades

Suno MCP Server proporciona las siguientes funcionalidades principales:

- **Generación de música** — Genera música de IA mediante indicaciones de texto
- **Creación personalizada** — Controla completamente las letras, el título y el estilo musical
- **Continuación de canciones** — Continúa extendiendo canciones existentes desde cualquier punto de tiempo
- **Versiones/remezclas** — Crea versiones con diferentes estilos
- **Generación de letras** — Genera letras estructuradas según una descripción
- **Personajes vocales** — Guarda y reutiliza estilos de voz
- **Conversión de medios** — Obtén MP4, WAV, MIDI, separación vocal, entre otros
- **Optimización de estilo** — Optimiza las etiquetas de estilo musical
- **Consulta de tareas** — Supervisa el progreso de generación y obtén resultados

## Preparativos previos

Antes de usarlo, necesitas obtener un API Token de AceData Cloud:

1. Regístrate o inicia sesión en la [plataforma AceData Cloud](https://platform.acedata.cloud)
2. Ve a la página de [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Haz clic en «Acquire» para obtener el API Token (la primera solicitud incluye crédito gratuito)

## Método uno: usar el MCP Server alojado (recomendado, sin instalación)

AceData Cloud ya ha alojado **Suno MCP Server** en la nube, **sin necesidad de instalar ninguna dependencia localmente**; solo tienes que introducir la siguiente URL directamente en el cliente de IA para usarlo:

```
https://suno.mcp.acedata.cloud/mcp
```

Método de autenticación: añade `Authorization: Bearer tu API Token` en el encabezado de la solicitud (Claude.ai lo completa automáticamente mediante OAuth, sin necesidad de introducir el Token manualmente).

### Claude.ai (versión web, inicio de sesión OAuth, el más sencillo)

1. Abre [Claude.ai](https://claude.ai) → abajo a la izquierda **Customize** → **Connectors** → **Add More**
2. Introduce en la URL: `https://suno.mcp.acedata.cloud/mcp`
3. Completa el inicio de sesión de autorización OAuth (redirige automáticamente a la página de inicio de sesión de AceData Cloud)
4. Vuelve a la interfaz de conversación y la herramienta estará disponible

### Claude Desktop

Edita el archivo de configuración:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Reinicia Claude Desktop después de guardar para que surta efecto.

### Claude Code (línea de comandos de terminal)

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Otros clientes compatibles con MCP

Cualquier cliente compatible con el protocolo MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant, etc.) puede conectarse completando los siguientes dos elementos:

- **URL**: `https://suno.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer tu API Token`

## Método dos: ejecución local (instalación mediante pip / uvx)

Si necesitas ejecutarlo sin conexión, personalizar el código o implementarlo en una red interna, puedes instalar el MCP Server localmente e iniciarlo mediante stdio.

### Instalación

Instalación mediante pip (recomendada):

```bash
pip install mcp-suno
```

O instalación desde el código fuente:

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

Después de completar la instalación, puedes usar el comando `mcp-suno` para iniciar el servicio.

### Uso en Claude Desktop (local)

Edita el archivo de configuración de Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Añade la siguiente configuración:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Si usas `uvx` (sin necesidad de instalar el paquete previamente):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Reinicia Claude Desktop después de guardar la configuración para que surta efecto.

### Uso en VS Code / Cursor (local)

## Ejemplos de uso

Después de completar la configuración, puedes llamar directamente a estas funciones en el cliente de IA usando lenguaje natural, por ejemplo:

- «Ayúdame a generar una canción pop sobre el verano»
- «Haz una versión de esta canción con estilo jazz»
- «Continúa esta canción a partir del segundo 30»
- «Genera una letra en chino con el tema de los viajes»
- «Separa las voces de esta canción»
- «Ayúdame a convertir esta canción al formato MIDI»

## Control avanzado y proyectos de Studio

`suno_generate_music` admite `variety`; `suno_generate_custom_music` también admite
`max_mode` y `audio_weight`. `max_mode` utiliza un nivel de facturación de API más alto, no está habilitado
por defecto y debe configurarse después de que el usuario elija explícitamente el modo mejorado. Los precios actuales se rigen por la página de servicio de la plataforma.

`suno_generate_with_custom_model` puede usar `instrumental=true` para generar música instrumental, o usar
`lyric_prompt` para generar letras automáticamente; de lo contrario, proporciona `lyric`. El título y el estilo pueden omitirse, y también se pueden pasar
`negative_tags`, `vocal_gender`, `weirdness`, `style_influence`, `duration` y
`callback_url`. Los valores de control explícitos de `0` se conservarán.

La `request.action` de `suno_manage_project` puede ser `create`, `retrieve`, `save`,
`upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`,
`remove_track`, `render`. La entrada se distingue según la acción; las modificaciones del proyecto deben usar el `version_id` de la lectura más reciente;
al guardar, pasa el `state` completo y conserva las pistas y los campos existentes.

Excepto `retrieve`, cada llamada debe proporcionar un `idempotency_key`. Las nuevas operaciones de escritura usan una nueva clave;
cuando se agota el tiempo de espera o el resultado de aceptación es incierto, conserva la clave original y vuelve a intentar con una solicitud exactamente idéntica, o consulta la tarea original; no
cambies automáticamente la clave para reenviar una generación de pago. Los intervalos de audio de origen usan segundos, y los intervalos de la línea de tiempo del proyecto usan compases. La generación solo crea candidatos;
es necesario seleccionar un candidato y llamar a `commit_candidate` para que se escriba en la pista.

El `task_id` aceptado de forma asíncrona se consulta con `suno_get_task`. Cuando `finished_at` está vacío, continúa esperando;
después de un estado terminal, comprueba `response.success` y los errores; no consideres que una aceptación exitosa equivale a una generación, confirmación o exportación exitosa.
`suno_get_tasks_batch` devuelve registros completos de tareas JSON, conservando objetos de modelos personalizados, estados de proyectos,
candidatos y diversos resultados como MIDI. El flujo de trabajo completo se encuentra en la [Guía de proyectos de Studio](https://platform.acedata.cloud/documents/suno-projects-integration).
