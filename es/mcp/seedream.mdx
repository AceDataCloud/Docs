[MCP (Model Context Protocol)](https://modelcontextprotocol.io) es un protocolo de contexto de modelo lanzado por Anthropic que permite a los modelos de IA (como Claude, GPT, etc.) llamar a herramientas externas a través de una interfaz estandarizada. Con el Seedream MCP Server proporcionado por AceData Cloud, puedes usar directamente la generación y edición de imágenes AI de Seedream de ByteDance en clientes de IA como Claude Desktop, VS Code, Cursor, entre otros.

## Resumen de Funcionalidades

Seedream MCP Server ofrece las siguientes funciones principales:

- **Generación de imágenes a partir de texto** — Genera imágenes de alta calidad mediante indicaciones textuales (soporta indicaciones en chino e inglés)
- **Edición de imágenes** — Modifica el estilo, fondo, atributos y más de imágenes existentes
- **Prueba virtual de ropa** — Aplica prendas a fotos de personas
- **Soporte multi-modelo** — Compatible con Seedream v4.5, v4.0, v3.0 T2I, SeedEdit v3.0 I2I, entre otros modelos
- **Múltiples resoluciones** — Soporta 1K, 2K, 4K y resoluciones adaptativas
- **Control de semilla** — Permite resultados reproducibles mediante el parámetro seed
- **Consulta de tareas** — Monitorea el progreso de generación y obtiene resultados

## Requisitos Previos

Antes de usar, necesitas obtener un API Token de AceData Cloud:

1. Regístrate o inicia sesión en la [plataforma AceData Cloud](https://platform.acedata.cloud)
2. Accede a la página de [Seedream Images API](https://platform.acedata.cloud/documents/seedream-images)
3. Haz clic en “Acquire” para obtener el API Token (la primera solicitud incluye crédito gratuito)

## Instalación y Configuración

### Método 1: Instalación con pip (recomendado)

```bash
pip install mcp-seedream-pro
```

### Método 2: Instalación desde código fuente

```bash
git clone https://github.com/AceDataCloud/SeedreamMCP.git
cd SeedreamMCP
pip install -e .
```

Después de la instalación, puedes iniciar el servicio con el comando `mcp-seedream-pro`.

## Uso en Claude Desktop

Edita el archivo de configuración de Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Agrega la siguiente configuración:

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tu API Token"
      }
    }
  }
}
```

Si usas `uvx` (sin necesidad de instalar paquetes previamente):

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tu API Token"
      }
    }
  }
}
```

Guarda la configuración y reinicia Claude Desktop para usar las herramientas Seedream en las conversaciones.

## Lista de Herramientas Disponibles

| Herramienta               | Descripción                          |
|--------------------------|------------------------------------|
| `seedream_generate_image` | Genera imágenes a partir de texto  |
| `seedream_edit_image`     | Edita o modifica imágenes existentes |
| `seedream_get_task`       | Consulta el estado de una tarea individual |
| `seedream_get_tasks_batch`| Consulta el estado de tareas por lotes |
| `seedream_list_models`    | Lista todos los modelos disponibles y sus capacidades |
| `seedream_list_sizes`     | Lista tamaños y resoluciones de imagen disponibles |

## Ejemplos de Uso

Después de la configuración, puedes llamar a estas funciones directamente en clientes de IA con lenguaje natural, por ejemplo:

- “Ayúdame a generar con Seedream una pintura de paisaje estilo tinta china”
- “Cambia el fondo de esta foto a un cielo estrellado”
- “Genera un retrato 4K en alta definición con Seedream v4.5”
- “Prueba virtualmente esta prenda en esta foto”
