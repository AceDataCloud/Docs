[MCP (Model Context Protocol)](https://modelcontextprotocol.io) es un protocolo de contexto de modelo lanzado por Anthropic, que permite a los modelos de IA (como Claude, GPT, etc.) llamar a herramientas externas mediante una interfaz estandarizada. A través del Veo MCP Server proporcionado por AceData Cloud, puedes usar Google Veo para generar videos de IA directamente en clientes de IA como Claude Desktop, VS Code, Cursor, entre otros.

## Resumen de Funcionalidades

Veo MCP Server ofrece las siguientes funciones principales:

- **Generación de video a partir de texto** — Genera videos de alta calidad a partir de indicaciones textuales
- **Generación de video a partir de imágenes** — Genera videos basados en imágenes
- **Soporte para múltiples modelos** — Compatible con modelos como veo3, veo2, veo31-fast-ingredients, etc.
- **Varias resoluciones** — Soporta formatos de salida como 4K, 1080p, GIF, entre otros
- **Diversas proporciones de pantalla** — Soporta relaciones de aspecto 16:9, 9:16, etc.
- **Actualización a 1080p** — Mejora videos ya generados a resolución 1080p
- **Consulta de tareas** — Monitorea el progreso de generación y obtiene resultados

## Requisitos Previos

Antes de usar, necesitas obtener un API Token de AceData Cloud:

1. Regístrate o inicia sesión en la [plataforma AceData Cloud](https://platform.acedata.cloud)
2. Ve a la página de [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos)
3. Haz clic en "Acquire" para obtener el API Token (la primera solicitud incluye un crédito gratuito)

## Instalación y Configuración

### Método 1: Instalación con pip (recomendado)

```bash
pip install mcp-veo
```

### Método 2: Instalación desde código fuente

```bash
git clone https://github.com/AceDataCloud/VeoMCP.git
cd VeoMCP
pip install -e .
```

Después de la instalación, puedes iniciar el servicio con el comando `mcp-veo`.

## Uso en Claude Desktop

Edita el archivo de configuración de Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Agrega la siguiente configuración:

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tu API Token"
      }
    }
  }
}
```

Si usas `uvx` (sin necesidad de instalar paquetes previamente):

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tu API Token"
      }
    }
  }
}
```

Guarda la configuración y reinicia Claude Desktop para usar las herramientas Veo en las conversaciones.

## Uso en VS Code / Cursor

Crea un archivo `.vscode/mcp.json` en la raíz del proyecto:

```json
{

      "env": {
```

O usa `uvx`:


## Lista de Herramientas Disponibles

| Nombre de la herramienta | Descripción                          |
|--------------------------|------------------------------------|
| `veo_text_to_video`       | Genera video a partir de texto     |
| `veo_image_to_video`      | Genera video basado en imágenes    |
| `veo_get_1080p`           | Actualiza video a resolución 1080p |
| `veo_get_task`            | Consulta el estado de una tarea    |
| `veo_get_tasks_batch`     | Consulta el estado de tareas en lote |

## Ejemplos de Uso

Después de configurar, puedes llamar a estas funciones directamente en el cliente de IA con lenguaje natural, por ejemplo:

- "Ayúdame a generar un video time-lapse del cielo estrellado con Veo"
- "Genera un video 4K a partir de esta foto de paisaje"
- "Genera un video corto en formato vertical 9:16"
- "Actualiza este video a 1080p"
