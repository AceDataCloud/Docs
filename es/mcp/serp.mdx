[MCP (Model Context Protocol)](https://modelcontextprotocol.io) es un protocolo de contexto de modelo lanzado por Anthropic, que permite a los modelos de IA (como Claude, GPT, etc.) llamar a herramientas externas a través de interfaces estandarizadas. A través del SERP MCP Server proporcionado por AceData Cloud, puedes realizar búsquedas en Google directamente en clientes de IA como Claude Desktop, VS Code, Cursor, etc., obteniendo resultados de búsqueda de páginas web, imágenes, noticias, videos, lugares, entre otros.

## Resumen de funciones

El SERP MCP Server ofrece las siguientes funciones clave:

- **Búsqueda de páginas web** — Buscar resultados de páginas web de Google
- **Búsqueda de imágenes** — Buscar imágenes de Google
- **Búsqueda de noticias** — Buscar noticias de Google
- **Búsqueda de videos** — Buscar videos de Google
- **Búsqueda de lugares** — Buscar información de lugares de Google
- **Búsqueda de mapas** — Buscar mapas de Google
- **Multilenguaje y multirregión** — Soporta parámetros de país y lenguaje personalizados
- **Filtrado por rango de tiempo** — Filtrar resultados por día, semana, mes, año

## Preparativos previos

Antes de usar, necesitas obtener el Token de API de AceData Cloud:

1. Regístrate o inicia sesión en la [plataforma AceData Cloud](https://platform.acedata.cloud)
2. Ve a la página de [Google SERP API](https://platform.acedata.cloud/documents/serp-google)
3. Haz clic en "Acquire" para obtener el Token de API (se ofrece un crédito gratuito en la primera solicitud)

## Instalación y configuración

### Método 1: Instalación con pip (recomendado)

```bash
pip install mcp-serp
```

### Método 2: Instalación desde el código fuente

```bash
git clone https://github.com/AceDataCloud/MCPSerp.git
cd MCPSerp
pip install -e .
```

Una vez completada la instalación, puedes usar el comando `mcp-serp` para iniciar el servicio.

## Uso en Claude Desktop

Edita el archivo de configuración de Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Agrega la siguiente configuración:

```json
{
  "mcpServers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tu Token de API"
      }
    }
  }
}
```

Si usas `uvx` (sin necesidad de instalar paquetes previamente):

```json
{
  "mcpServers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tu Token de API"
      }
    }
  }
}
```

Guarda la configuración y reinicia Claude Desktop, podrás usar herramientas relacionadas con la búsqueda de Google en la conversación.

| `serp_google_news`           | Búsqueda de noticias de Google |
| `serp_google_videos`         | Búsqueda de videos de Google |
| `serp_google_places`         | Búsqueda de lugares de Google |
| `serp_google_maps`           | Búsqueda de mapas de Google |

Una vez configurado, puedes llamar a estas funciones directamente en el cliente de IA usando lenguaje natural, por ejemplo:

- "Busca restaurantes de hot pot deliciosos en Beijing"
- "Encuentra imágenes sobre programación asíncrona en Python"
