---
title: "Servidor MCP"
description: "Servidor del Protocolo de Contexto del Modelo para integración de herramientas de IA"
---

Ace Data Cloud ofrece un servidor MCP (Model Context Protocol), que permite a asistentes de IA como Claude, Cursor, Windsurf, entre otros, llamar directamente a nuestra API.

<Note title="Consejo">
  Este artículo presenta el servidor MCP proporcionado por Ace Data Cloud, que soporta la interacción de información e integración de múltiples asistentes de inteligencia artificial.
</Note>
