## ¿Qué es MCP?

Model Context Protocol (MCP) es un protocolo abierto que permite a asistentes de IA (como Claude, Cursor) llamar directamente a herramientas y API externas. A través de MCP, la IA no solo puede responder preguntas, sino también realizar operaciones prácticas.

## MCP Server proporcionados por Ace Data Cloud

| MCP Server      | Nombre del paquete PyPI | Función           |
|-----------------|------------------------|-------------------|
| MCPSuno         | mcp-suno               | Generación de música AI |
| MCPSerp         | mcp-serp               | Búsqueda en Google |
| MCPMidjourney   | mcp-midjourney         | Generación de imágenes AI |
| MCPLuma         | mcp-luma               | Generación de video AI |
| MCPSora         | mcp-sora               | Generación de video AI |
| MCPVeo          | mcp-veo                | Generación de video AI |
| MCPNanoBanana   | mcp-nano-banana        | Generación de imágenes AI |

## Instalación y uso

### Instalación

```bash
pip install mcp-suno  # o cualquier otro MCP Server
```

### Configurar variables de entorno

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### Configuración en Cursor

Agregar en la configuración MCP de Cursor:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### Configuración en Claude Desktop

Editar el archivo de configuración de Claude Desktop para agregar la configuración del MCP Server.

## Casos de uso

1. **Generar música en Cursor**: Indicar a la IA "Genera una canción alegre con Suno", la IA llamará directamente a la API.
2. **Buscar información en tiempo real**: La IA puede buscar información actualizada mediante el MCP Server SERP.
3. **Generar materiales para proyectos**: La IA puede usar Midjourney para crear imágenes necesarias para el proyecto.

## MCP vs llamada directa a API

- **MCP**: adecuado para usar dentro de herramientas de programación AI, llamado automático por la IA.
- **API**: adecuado para integrar en tus propias aplicaciones con control programático.

Ambos usan el mismo Ace Data Cloud API Token y llaman a los mismos endpoints de API subyacentes.

## Resumen

MCP permite que los asistentes AI llamen directamente a diversas API de Ace Data Cloud. Todos los MCP Server están publicados en PyPI, la instalación y configuración es sencilla, haciendo tus herramientas AI más potentes.

Visita [platform.acedata.cloud](https://platform.acedata.cloud) para obtener tu API Token.
