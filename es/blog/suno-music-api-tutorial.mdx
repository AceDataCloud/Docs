## Introducción a Suno

Suno es una de las plataformas de generación de música por IA más potentes actualmente. A través de la API Suno de Ace Data Cloud, puedes generar música de alta calidad mediante simples llamadas a la API.

## Endpoints de la API

| Endpoint | Función |
|----------|---------|
| `POST /suno/audios` | Generar música (endpoint principal) |
| `POST /suno/lyrics` | Generar letras |
| `POST /suno/persona` | Gestionar estilos de cantante |
| `POST /suno/wav` | Obtener formato WAV |
| `POST /suno/mp4` | Obtener formato MP4 |
| `POST /suno/tasks` | Consultar estado de tareas |

## Generación básica

### Generación mediante descripción de texto

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### Generación personalizada de letras

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\n夏日的阳光洒满了海岸\n微风中传来浪花的声音\n\n[Chorus]\n让我们一起去远方\n追逐那自由的梦想",
        "style": "pop upbeat",
        "title": "夏日冒险",
    },
)
```

## Funciones avanzadas

### Continuación de canción

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### Generar letras

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "写一首关于冬天的歌",
    },
)
```
