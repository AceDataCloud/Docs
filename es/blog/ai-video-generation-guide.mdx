## Resumen

La generación de video AI está evolucionando rápidamente. Ace Data Cloud ofrece 7 tipos de API de generación de video, cubriendo diversos escenarios desde texto a video hasta imagen a video.

## Servicios de generación de video disponibles

| Servicio | Endpoint | Modelo | Características |
|----------|----------|--------|-----------------|
| Sora     | `POST /sora/videos` | sora-2, sora-2-pro | Producido por OpenAI, calidad cinematográfica |
| Veo      | `POST /veo/videos` | veo3, veo3-fast | Producido por Google, soporte 4K |
| Kling    | `POST /kling/videos` | kling-v2-5-turbo | Producido por Kuaishou, alta velocidad |
| Luma     | `POST /luma/videos` | — | Control de cuadro inicial y final |
| Hailuo   | `POST /hailuo/videos` | minimax-t2v | Producido por MiniMax |
| Seedance | `POST /seedance/videos` | doubao-seedance-1-0-pro-250528 | Producido por ByteDance |
| Wan      | `POST /wan/videos` | wan2.6-t2v | Producido por Alibaba |

## Inicio rápido

### Generación de video con Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A cat playing in a sunny garden",
        "model": "sora-2",
        "duration": 10,
        "orientation": "landscape",
    },
)
print(response.json())
```

### Generación de video con Kling

```python
response = requests.post(
    "https://api.acedata.cloud/kling/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A white cat walking in the snow",
        "model": "kling-v2-5-turbo",
        "duration": 5,
        "aspect_ratio": "16:9",
    },
)
print(response.json())
```

### Generación de video con Veo

```python
response = requests.post(
    "https://api.acedata.cloud/veo/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },

        "action": "text2video",
        "prompt": "A coffee mug rotating on a marble counter",
        "model": "veo3",

```

## Manejo de tareas asíncronas

La generación de video suele tomar tiempo. Todas las APIs de video soportan:

1. **Notificación por callback**: configurar `callback_url` en la solicitud para recibir automáticamente el resultado cuando se complete la generación
2. **Consulta por polling**: consultar el progreso de la tarea mediante el endpoint `/tasks`

```python
# Usando URL de callback
data = {
    "prompt": "A sunrise over mountains",
    "model": "sora-2",
    "callback_url": "https://your-server.com/webhook",
}

# O consultando el estado de la tarea
task_response = requests.post("https://api.acedata.cloud/sora/tasks",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json={"task_id": "your-task-id"})
```

## Recomendaciones de selección

- **Mejor calidad de imagen**: Sora (sora-2-pro)
- **Mayor velocidad**: Kling (kling-v2-5-turbo)
- **Mayor resolución**: Veo (soporte 4K)
- **Control de cuadro inicial y final**: Luma
- **Mejor relación calidad-precio**: Wan
