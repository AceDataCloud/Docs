## Introducción

Midjourney es un servicio de imágenes AI proporcionado por Ace Data Cloud, que genera imágenes con Midjourney AI. A través de la API unificada de Ace Data Cloud, puedes usar cURL para llamar rápidamente a Midjourney y realizar funciones como generación de imágenes a partir de texto, edición de imágenes, descripción de imágenes, generación de video a partir de imágenes, control de Seed, callback asíncrono, entre otras.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Tener un entorno de terminal con cURL instalado

## Uso básico

El endpoint principal para llamar a la API de Midjourney es:

```
POST https://api.acedata.cloud/midjourney/imagine
```

Ejemplo completo del comando cURL:

```bash
curl -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}'
```

Por favor reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Ejemplo de respuesta

Después de una llamada exitosa, se devuelve un dato en formato JSON, por ejemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Uso de jq para procesar la respuesta

Se recomienda usar la herramienta jq para formatear la salida:

```bash
curl -s -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}' | jq .
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción                      |
|------------------|--------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o sin permiso de acceso |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor      |
