## Introducción

Seedream es un servicio de imágenes AI proporcionado por Ace Data Cloud, basado en el modelo de generación de imágenes Seedream de ByteDance. A través de la API unificada de Ace Data Cloud, puedes integrar rápidamente Seedream usando JavaScript para realizar generación de imágenes a partir de texto, edición de imágenes, múltiples resoluciones, control de marcas de agua y más.

## Requisitos Previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Node.js 18+ o un entorno de navegador moderno

## Uso Básico

El endpoint principal para llamar a la API de Seedream es:

```
POST https://api.acedata.cloud/seedream/images
```

Este ejemplo utiliza el modelo `doubao-seedream-4-0-250828`.  
Modelos disponibles incluyen: `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`, `doubao-seedream-3-0-t2i-250415`, `doubao-seededit-3-0-i2i-250628`.

Ejemplo completo de código JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/seedream/images", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "一只白色的暹罗猫坐在窗台上",
  "model": "doubao-seedream-4-0-250828",
  "size": "1K"
}),
});

const result = await response.json();
console.log(result);
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Manejo de Respuestas

Se recomienda verificar el código de estado de la respuesta y manejar errores:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Llamada exitosa:", result);
} else {
  console.error(`Llamada fallida, código de estado: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Encapsulación en Node.js

Se recomienda encapsular en una función reutilizable:

```javascript
async function callSeedream(data) {
  const response = await fetch("https://api.acedata.cloud/seedream/images", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Manejo de Errores

Códigos de error comunes:

| Código de Estado | Descripción                          |
|------------------|------------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o acceso denegado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor         |
