## Introducción

Seedream es un servicio de imágenes AI proporcionado por Ace Data Cloud, basado en el modelo de generación de imágenes Seedream de ByteDance. A través de la API unificada de Ace Data Cloud, puedes usar cURL para llamar rápidamente a Seedream y realizar funciones como generación de imágenes a partir de texto, edición de imágenes, múltiples resoluciones, control de marcas de agua, entre otras.

## Requisitos Previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Tener un entorno de terminal con cURL instalado

## Uso Básico

El endpoint principal para llamar a la API de Seedream es:

```
POST https://api.acedata.cloud/seedream/images
```

Este ejemplo usa el modelo `doubao-seedream-4-0-250828`.
Modelos disponibles incluyen: `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`, `doubao-seedream-3-0-t2i-250415`, `doubao-seededit-3-0-i2i-250628`.

Ejemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}'
```

Por favor reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Ejemplo de Respuesta

Después de una llamada exitosa, se devuelve un JSON, por ejemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Uso de jq para Procesar la Respuesta

Se recomienda usar la herramienta jq para formatear la salida:

```bash
curl -s -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}' | jq .
```

## Manejo de Errores

Códigos de error comunes:

| Código de Estado | Descripción                         |
|------------------|-----------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o acceso denegado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor        |
