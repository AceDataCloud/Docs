## Introducción

Seedream es un servicio de imágenes AI proporcionado por Ace Data Cloud, basado en el modelo de generación de imágenes Seedream de ByteDance. A través de la API unificada de Ace Data Cloud, puedes integrar rápidamente Seedream con Python para realizar generación de imágenes a partir de texto, edición de imágenes, múltiples resoluciones, control de marcas de agua y más.

## Requisitos Previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Entorno Python 3.7 o superior
- Instalar la librería requests: `pip install requests`

## Uso Básico

El endpoint principal para llamar a la API de Seedream es:

```
POST https://api.acedata.cloud/seedream/images
```

Este ejemplo utiliza el modelo `doubao-seedream-4-0-250828`.
Modelos disponibles incluyen: `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`, `doubao-seedream-3-0-t2i-250415`, `doubao-seededit-3-0-i2i-250628`.

Ejemplo completo de código Python:

```python
import requests

url = "https://api.acedata.cloud/seedream/images"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "Un gato siamés blanco sentado en el alféizar de una ventana",
    "model": "doubao-seedream-4-0-250828",
    "size": "1K"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Manejo de Respuestas

Tras una llamada exitosa, la API devuelve datos en formato JSON. Se recomienda verificar el código de estado HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Llamada exitosa:", result)
else:
    print(f"Llamada fallida, código de estado: {response.status_code}")
    print(response.text)
```

## Uso Avanzado

Para APIs que soportan tareas asíncronas, puedes obtener resultados mediante una URL de callback:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Los resultados serán enviados a tu servidor a través de la URL de callback
```

## Manejo de Errores

Códigos de error comunes:

| Código | Descripción |
|--------|-------------|
| 401 | Autenticación fallida, verifica el API Token |
| 403 | Saldo insuficiente o acceso denegado |
| 429 | Límite de frecuencia de solicitudes excedido |
| 500 | Error interno del servidor |
