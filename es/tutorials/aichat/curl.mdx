## Introducción

AI Chat es un servicio de chat AI proporcionado por Ace Data Cloud, un servicio de diálogo AI con múltiples modelos. A través de la API unificada de Ace Data Cloud, puedes usar cURL para llamar rápidamente a AI Chat, logrando soporte para múltiples modelos, conversaciones con estado, roles predefinidos y más.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Tener un entorno de terminal con cURL instalado

## Uso básico

El endpoint principal para llamar a la API AI Chat es:

```
POST https://api.acedata.cloud/aichat/conversations
```

Este ejemplo usa el modelo `gpt-4o`.  
Modelos disponibles incluyen: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Ejemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}'
```

Por favor reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Ejemplo de respuesta

Después de una llamada exitosa, se devuelve un dato en formato JSON, por ejemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Uso de jq para procesar la respuesta

Se recomienda usar la herramienta jq para formatear la salida:

```bash
curl -s -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}' | jq .
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción                          |
|------------------|------------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o acceso denegado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor          |
