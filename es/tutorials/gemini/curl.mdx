## Introducción

Gemini es un servicio de chat de IA proporcionado por Ace Data Cloud, basado en la serie de grandes modelos de lenguaje Google Gemini. A través de la API unificada de Ace Data Cloud, puedes usar cURL para llamar rápidamente a Gemini y aprovechar funciones como conversaciones multi-turno, indicaciones del sistema, salida en streaming, modo de salida JSON, entre otras.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Tener un entorno de terminal con cURL instalado

## Uso básico

El endpoint principal para llamar a la API de Gemini es:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

Este ejemplo usa el modelo `gemini-2.5-flash`.  
Modelos disponibles incluyen: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Ejemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/gemini/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gemini-2.5-flash", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Ejemplo de respuesta

Al llamar con éxito, se devuelve un dato en formato JSON, por ejemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Uso de jq para procesar la respuesta

Se recomienda usar la herramienta jq para formatear la salida:

```bash
curl -s -X POST https://api.acedata.cloud/gemini/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gemini-2.5-flash", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción                      |
|------------------|--------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o acceso denegado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor      |
