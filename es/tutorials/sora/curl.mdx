## Introducción

Sora es un servicio de video AI proporcionado por Ace Data Cloud, basado en el modelo de generación de video OpenAI Sora. A través de la API unificada de Ace Data Cloud, puedes usar cURL para llamar rápidamente a Sora y lograr funciones como generación de video a partir de texto, múltiples duraciones, orientación horizontal o vertical, control de personajes, imágenes de referencia, entre otras.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener el API Token
- Tener instalado cURL en el entorno de terminal

## Uso básico

El endpoint principal para llamar a la API de Sora es:

```
POST https://api.acedata.cloud/sora/videos
```

Este ejemplo usa el modelo `sora-2`.  
Modelos disponibles incluyen: `sora-2`, `sora-2-pro`.

Ejemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}'
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Ejemplo de respuesta

Después de una llamada exitosa, se devuelve un dato en formato JSON, por ejemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Uso de jq para procesar la respuesta

Se recomienda usar la herramienta jq para formatear la salida:

```bash
curl -s -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}' | jq .
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción                      |
|------------------|---------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o acceso denegado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor       |
