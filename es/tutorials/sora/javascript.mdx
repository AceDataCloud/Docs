## Introducción

Sora es un servicio de video AI proporcionado por Ace Data Cloud, basado en el modelo de generación de video OpenAI Sora. A través de la API unificada de Ace Data Cloud, puedes integrar rápidamente Sora con JavaScript para generar videos a partir de texto, con opciones de diversas duraciones, orientación horizontal o vertical, control de personajes, imágenes de referencia, entre otras funcionalidades.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Node.js 18+ o un entorno de navegador moderno

## Uso básico

El endpoint principal para llamar a la API de Sora es:

```
POST https://api.acedata.cloud/sora/videos
```

Este ejemplo utiliza el modelo `sora-2`.  
Modelos disponibles: `sora-2`, `sora-2-pro`.

Ejemplo completo de código JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/sora/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "A cat running across a sunny meadow",
  "model": "sora-2",
  "duration": 10,
  "orientation": "landscape"
}),
});

const result = await response.json();
console.log(result);
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Manejo de la respuesta

Se recomienda verificar el código de estado de la respuesta y manejar errores:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Llamada exitosa:", result);
} else {
  console.error(`Llamada fallida, código de estado: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Encapsulación en Node.js

Se recomienda encapsular en una función reutilizable:

```javascript
async function callSora(data) {
  const response = await fetch("https://api.acedata.cloud/sora/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`Error de API: ${response.status}`);
  return response.json();
}
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción |
|------------------|-------------|
| 401 | Autenticación fallida, por favor verifica el API Token |
| 403 | Saldo insuficiente o acceso no autorizado |
| 429 | Límite de frecuencia de solicitudes excedido |
| 500 | Error interno del servidor |
