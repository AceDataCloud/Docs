## Introducción

Sora es un servicio de video AI proporcionado por Ace Data Cloud, basado en el modelo de generación de video OpenAI Sora. A través de la API unificada de Ace Data Cloud, puedes integrar rápidamente Sora con Python para crear videos a partir de texto, con diversas duraciones, orientación horizontal o vertical, control de personajes, imágenes de referencia y más.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Entorno Python 3.7 o superior
- Instalar la librería requests: `pip install requests`

## Uso básico

El endpoint principal para llamar a la API de Sora es:

```
POST https://api.acedata.cloud/sora/videos
```

Este ejemplo utiliza el modelo `sora-2`.  
Modelos disponibles: `sora-2`, `sora-2-pro`.

Ejemplo completo de código Python:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Manejo de la respuesta

Tras una llamada exitosa, la API devuelve datos en formato JSON. Se recomienda verificar el código de estado HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Llamada exitosa:", result)
else:
    print(f"Llamada fallida, código de estado: {response.status_code}")
    print(response.text)
```

## Uso avanzado

Para APIs que soportan tareas asíncronas, puedes obtener el resultado mediante una URL de callback:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# El resultado será enviado a tu servidor vía la URL de callback
```

## Manejo de errores

Códigos de error comunes:

| Código | Descripción                          |
|--------|------------------------------------|
| 401    | Autenticación fallida, verifica el API Token |
| 403    | Saldo insuficiente o acceso denegado |
| 429    | Límite de frecuencia de solicitudes excedido |
| 500    | Error interno del servidor         |
