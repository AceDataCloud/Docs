## Introducción

Google Search es un servicio de búsqueda proporcionado por Ace Data Cloud, la API de búsqueda de Google. A través de la API unificada de Ace Data Cloud, puedes integrar rápidamente Google Search con JavaScript para realizar búsquedas en páginas web, imágenes, noticias, mapas, videos y más.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Node.js 18+ o un entorno de navegador moderno

## Uso básico

El endpoint principal para llamar a la API de Google Search es:

```
POST https://api.acedata.cloud/serp/google
```

Ejemplo completo de código JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/serp/google", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "query": "artificial intelligence latest news",
  "type": "search",
  "number": 10,
  "language": "en",
  "country": "US"
}),
});

const result = await response.json();
console.log(result);
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Manejo de la respuesta

Se recomienda verificar el código de estado de la respuesta y manejar errores:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Llamada exitosa:", result);
} else {
  console.error(`Llamada fallida, código de estado: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Envoltorio para Node.js

Se recomienda encapsular en una función reutilizable:

```javascript
async function callGoogleSearch(data) {
  const response = await fetch("https://api.acedata.cloud/serp/google", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`Error de API: ${response.status}`);
  return response.json();
}
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción |
|------------------|-------------|
| 401              | Autenticación fallida, por favor verifica el API Token |
| 403              | Saldo insuficiente o acceso no autorizado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor |
