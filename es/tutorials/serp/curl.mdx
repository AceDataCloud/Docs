## Introducción

Google Search es un servicio de búsqueda proporcionado por Ace Data Cloud, la API de búsqueda de Google. A través de la API unificada de Ace Data Cloud, puedes usar cURL para llamar rápidamente a Google Search y realizar búsquedas en páginas web, imágenes, noticias, mapas, videos, entre otras funciones.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Tener un entorno de terminal con cURL instalado

## Uso básico

El endpoint principal para llamar a la API de Google Search es:

```
POST https://api.acedata.cloud/serp/google
```

Ejemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}'
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Ejemplo de respuesta

Después de una llamada exitosa, se devuelve un dato en formato JSON, por ejemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Uso de jq para procesar la respuesta

Se recomienda usar la herramienta jq para formatear la salida:

```bash
curl -s -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}' | jq .
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción                         |
|------------------|-----------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o acceso denegado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor        |
