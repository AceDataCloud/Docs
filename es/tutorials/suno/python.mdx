## Introducción

Suno es un servicio de audio AI proporcionado por Ace Data Cloud para la generación de música AI. A través de la API unificada de Ace Data Cloud, puedes integrar rápidamente Suno con Python para generar música a partir de texto, personalizar letras, continuar canciones, hacer covers, separar voces, generar letras y más.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Entorno Python 3.7 o superior
- Instalar la librería requests: `pip install requests`

## Uso básico

El endpoint principal para llamar a la API de Suno es:

```
POST https://api.acedata.cloud/suno/audios
```

Este ejemplo usa el modelo `chirp-v5`.  
Modelos disponibles: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`.

Ejemplo completo en Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A cheerful pop song about summer vacation",
    "model": "chirp-v5",
    "custom": false
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Manejo de respuestas

Después de una llamada exitosa, la API devuelve datos en formato JSON. Se recomienda verificar el código de estado HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Llamada exitosa:", result)
else:
    print(f"Llamada fallida, código de estado: {response.status_code}")
    print(response.text)
```

## Uso avanzado

Para APIs que soportan tareas asíncronas, puedes obtener resultados mediante una URL de callback:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Los resultados serán enviados a tu servidor vía la URL de callback
```

## Manejo de errores

Códigos de error comunes:

| Código | Descripción |
|--------|-------------|
| 401    | Autenticación fallida, verifica el API Token |
| 403    | Saldo insuficiente o acceso denegado |
| 429    | Límite de frecuencia de solicitudes excedido |
| 500    | Error interno del servidor |
