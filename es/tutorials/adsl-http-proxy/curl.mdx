---

## Introducción

ADSL HTTP Proxy es un servicio de proxy de red proporcionado por Ace Data Cloud, que extrae IPs dinámicas ADSL. A través de la API unificada de Ace Data Cloud, puedes usar cURL para llamar rápidamente a ADSL HTTP Proxy y realizar funciones como proxy HTTP/SOCKS, múltiples operadores, múltiples provincias, duración personalizada, lista blanca de IP, entre otras.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener el API Token
- Tener un entorno de terminal con cURL instalado

## Uso básico

El endpoint principal para llamar a la API de ADSL HTTP Proxy es:

```
POST https://api.acedata.cloud/adsl/extract
```

Ejemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}'
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Ejemplo de respuesta

Después de una llamada exitosa, se devuelve un dato en formato JSON, por ejemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Uso de jq para procesar la respuesta

Se recomienda usar la herramienta jq para formatear la salida:

```bash
curl -s -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}' | jq .
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción                      |
|------------------|---------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o sin permiso de acceso |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor      |
