## Introducción

ADSL HTTP Proxy es un servicio de proxy de red proporcionado por Ace Data Cloud para la extracción de IPs dinámicas ADSL. A través de la API unificada de Ace Data Cloud, puedes integrar rápidamente ADSL HTTP Proxy con Python, logrando funcionalidades como proxy HTTP/SOCKS, múltiples operadores, múltiples provincias, duración personalizada, lista blanca de IPs, entre otras.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Entorno Python 3.7 o superior
- Instalar la librería requests: `pip install requests`

## Uso básico

El endpoint principal para llamar a la API de ADSL HTTP Proxy es:

```
POST https://api.acedata.cloud/adsl/extract
```

Ejemplo completo de código en Python:

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "number": 5,
    "type": "http",
    "duration": 300,
    "province": "广东",
    "isp": "电信"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Por favor reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Manejo de la respuesta

Tras una llamada exitosa, la API devuelve datos en formato JSON. Se recomienda verificar el código de estado HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Llamada exitosa:", result)
else:
    print(f"Llamada fallida, código de estado: {response.status_code}")
    print(response.text)
```

## Uso avanzado

Para APIs que soportan tareas asíncronas, puedes obtener resultados mediante una URL de callback:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Los resultados serán enviados a tu servidor vía la URL de callback
```

## Manejo de errores

Códigos de error comunes:

| Código | Descripción                           |
|--------|-------------------------------------|
| 401    | Autenticación fallida, verifica el API Token |
| 403    | Saldo insuficiente o acceso denegado |
| 429    | Límite de frecuencia de solicitudes excedido |
| 500    | Error interno del servidor           |
