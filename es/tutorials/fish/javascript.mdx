## Introducción

Fish TTS es un servicio de audio AI proporcionado por Ace Data Cloud, un servicio de síntesis de voz Fish. A través de la API unificada de Ace Data Cloud, puedes integrar rápidamente Fish TTS con JavaScript para convertir texto a voz, utilizar múltiples tonos de voz, personalizar voces, entre otras funciones.

## Requisitos Previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Node.js 18+ o un entorno de navegador moderno

## Uso Básico

El endpoint principal para llamar a la API Fish TTS es:

```
POST https://api.acedata.cloud/fish/audios
```

Este ejemplo usa el modelo `fish-tts`.  
Modelos disponibles incluyen: `fish-tts`.

Ejemplo completo de código JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/fish/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "speech",
  "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务",
  "voice_id": "d7900c21663f485ab63ebdb7e5905036",
  "model": "fish-tts"
}),
});

const result = await response.json();
console.log(result);
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Manejo de Respuestas

Se recomienda verificar el código de estado de la respuesta y manejar errores:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Llamada exitosa:", result);
} else {
  console.error(`Llamada fallida, código de estado: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Encapsulación en Node.js

Se recomienda encapsular en una función reutilizable:

```javascript
async function callFishTTS(data) {
  const response = await fetch("https://api.acedata.cloud/fish/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`Error de API: ${response.status}`);
  return response.json();
}
```

## Manejo de Errores

Códigos de error comunes:

| Código de Estado | Descripción                          |
|------------------|------------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o acceso denegado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor         |
