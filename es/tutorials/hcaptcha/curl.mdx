## Introducción

hCaptcha es un servicio de captcha proporcionado por Ace Data Cloud. La solución hCaptcha permite, a través de la API unificada de Ace Data Cloud, utilizar cURL para llamar rápidamente a hCaptcha, logrando obtener tokens de hCaptcha, reconocimiento de imágenes hCaptcha y otras funciones.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Tener instalado cURL en el entorno de terminal

## Uso básico

El endpoint principal para llamar a la API de hCaptcha es:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Ejemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}'
```

Por favor, reemplaza `YOUR_API_TOKEN` con el token real que obtuviste en la plataforma Ace Data Cloud.

## Ejemplo de respuesta

Después de una llamada exitosa, se devuelve un dato en formato JSON, por ejemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Uso de jq para procesar la respuesta

Se recomienda usar la herramienta jq para formatear la salida:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}' | jq .
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción                          |
|------------------|------------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o sin permiso de acceso |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor          |
