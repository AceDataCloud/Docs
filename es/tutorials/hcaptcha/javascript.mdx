## Introducción

hCaptcha es un servicio de captcha proporcionado por Ace Data Cloud. Con la solución hCaptcha y la API unificada de Ace Data Cloud, puedes integrar rápidamente hCaptcha usando JavaScript para obtener tokens hCaptcha, reconocimiento de imágenes hCaptcha y otras funciones.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Node.js 18+ o un entorno de navegador moderno

## Uso básico

El endpoint principal para llamar a la API de hCaptcha es:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Ejemplo completo de código JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/captcha/token/hcaptcha", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2",
  "website_url": "https://accounts.hcaptcha.com/demo"
}),
});

const result = await response.json();
console.log(result);
```

Por favor, reemplaza `YOUR_API_TOKEN` con el token real que obtuviste en la plataforma Ace Data Cloud.

## Manejo de la respuesta

Se recomienda verificar el código de estado de la respuesta y manejar errores:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Llamada exitosa:", result);
} else {
  console.error(`Llamada fallida, código de estado: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Envoltorio para Node.js

Se recomienda encapsular en una función reutilizable:

```javascript
async function callhCaptcha(data) {
  const response = await fetch("https://api.acedata.cloud/captcha/token/hcaptcha", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`Error de API: ${response.status}`);
  return response.json();
}
```

## Manejo de errores

Códigos de error comunes:

| Código | Descripción |
|--------|-------------|
| 401 | Autenticación fallida, por favor verifica el API Token |
| 403 | Saldo insuficiente o acceso denegado |
| 429 | Límite de frecuencia de solicitudes excedido |
| 500 | Error interno del servidor |
