## Introducción

reCAPTCHA es un servicio de captcha proporcionado por Ace Data Cloud, una solución de Google reCAPTCHA. A través de la API unificada de Ace Data Cloud, puedes integrar rápidamente reCAPTCHA con Python, implementando funciones como Token reCAPTCHA v2, reconocimiento reCAPTCHA v2, Token reCAPTCHA v3, entre otras.

## Requisitos Previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Entorno Python 3.7 o superior
- Instalar la librería requests: `pip install requests`

## Uso Básico

El endpoint principal para llamar a la API de reCAPTCHA es:

```
POST https://api.acedata.cloud/captcha/token/recaptcha2
```

Ejemplo completo de código en Python:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/recaptcha2"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-",
    "website_url": "https://www.google.com/recaptcha/api2/demo"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Manejo de Respuestas

Después de una llamada exitosa, la API devuelve datos en formato JSON. Se recomienda verificar el código de estado HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Llamada exitosa:", result)
else:
    print(f"Llamada fallida, código de estado: {response.status_code}")
    print(response.text)
```

## Uso Avanzado

Para APIs que soportan tareas asíncronas, puedes obtener resultados mediante una URL de callback:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Los resultados serán enviados a tu servidor a través de la URL de callback
```

## Manejo de Errores

Códigos de error comunes:

| Código de Estado | Descripción                      |
|------------------|--------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o acceso denegado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor      |

## Otros Endpoints
