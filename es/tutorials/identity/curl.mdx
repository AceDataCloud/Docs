---

## Introducción

Identity es un servicio de autenticación proporcionado por Ace Data Cloud para la verificación de identidad con DNI/tarjeta bancaria/número de teléfono. A través de la API unificada de Ace Data Cloud, puedes usar cURL para llamar rápidamente a Identity y realizar funciones como OCR de DNI, verificación de DNI, verificación de tarjeta bancaria y verificación de número de teléfono.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Tener un entorno de terminal con cURL instalado

## Uso básico

El endpoint principal para llamar a la API de Identity es:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Ejemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}'
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Ejemplo de respuesta

Después de una llamada exitosa, se devuelve un dato en formato JSON, por ejemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Uso de jq para procesar la respuesta

Se recomienda usar la herramienta jq para formatear la salida:

```bash
curl -s -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}' | jq .
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción                          |
|------------------|------------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o sin permiso de acceso |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor          |
