## Introducción

Hailuo es un servicio de video AI proporcionado por Ace Data Cloud, basado en el modelo de generación de video MiniMax Hailuo. A través de la API unificada de Ace Data Cloud, puedes integrar rápidamente Hailuo con JavaScript para lograr funciones como generación de video a partir de texto, generación de video a partir de imágenes y modo director.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Node.js 18+ o un entorno de navegador moderno

## Uso básico

El endpoint principal para llamar a la API de Hailuo es:

```
POST https://api.acedata.cloud/hailuo/videos
```

Este ejemplo usa el modelo `minimax-t2v`.  
Modelos disponibles incluyen: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Ejemplo completo de código JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/hailuo/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "model": "minimax-t2v",
  "prompt": "A golden sunset over the ocean waves"
}),
});

const result = await response.json();
console.log(result);
```

Por favor reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Manejo de la respuesta

Se recomienda verificar el código de estado de la respuesta y manejar errores:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Llamada exitosa:", result);
} else {
  console.error(`Llamada fallida, código de estado: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Encapsulación en Node.js

Se recomienda encapsular en una función reutilizable:

```javascript
async function callHailuo(data) {
  const response = await fetch("https://api.acedata.cloud/hailuo/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción                          |
|------------------|------------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o acceso denegado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor         |
