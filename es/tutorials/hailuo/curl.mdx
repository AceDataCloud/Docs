## Introducción

Hailuo es un servicio de video AI proporcionado por Ace Data Cloud, basado en el modelo de generación de video MiniMax Hailuo. A través de la API unificada de Ace Data Cloud, puedes usar cURL para llamar rápidamente a Hailuo y realizar funciones como generación de video a partir de texto, generación de video a partir de imágenes, modo director, entre otras.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Tener un entorno de terminal con cURL instalado

## Uso básico

El endpoint principal para llamar a la API de Hailuo es:

```
POST https://api.acedata.cloud/hailuo/videos
```

Este ejemplo usa el modelo `minimax-t2v`.
Los modelos disponibles incluyen: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Ejemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}'
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Ejemplo de respuesta

Después de una llamada exitosa, se devuelve un dato en formato JSON, por ejemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Uso de jq para procesar la respuesta

Se recomienda usar la herramienta jq para formatear la salida:

```bash
curl -s -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}' | jq .
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción                      |
|------------------|---------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o acceso denegado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor       |
