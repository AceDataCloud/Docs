## Introducción

Claude es un servicio de chat AI proporcionado por Ace Data Cloud, basado en la serie de modelos de lenguaje grande Anthropic Claude. A través de la API unificada de Ace Data Cloud, puedes integrar rápidamente Claude con JavaScript para implementar funciones como diálogo multi-turno, mensajes de sistema, salida en streaming, modo de salida JSON, entre otras.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un Token API
- Node.js 18+ o un entorno de navegador moderno

## Uso básico

El endpoint principal para llamar a la API de Claude es:

```
POST https://api.acedata.cloud/v1/chat/completions
```

Este ejemplo usa el modelo `claude-sonnet-4-6`.  
Modelos disponibles incluyen: `claude-sonnet-4-6`, `claude-opus-4-5-20251101`, `claude-3-5-sonnet`.

Ejemplo completo de código JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "claude-sonnet-4-6",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Por favor, reemplaza `YOUR_API_TOKEN` con el token real que obtuviste en la plataforma Ace Data Cloud.

## Manejo de la respuesta

Se recomienda verificar el código de estado de la respuesta y manejar errores:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Llamada exitosa:", result);
} else {
  console.error(`Llamada fallida, código de estado: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Envoltorio para Node.js

Se recomienda encapsular en una función reutilizable:

```javascript
async function callClaude(data) {
  const response = await fetch("https://api.acedata.cloud/v1/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`Error en API: ${response.status}`);
  return response.json();
}
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción                         |
|------------------|-----------------------------------|
| 401              | Autenticación fallida, verifica el Token API |
| 403              | Saldo insuficiente o acceso denegado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor        |
