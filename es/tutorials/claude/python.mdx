## Introducción

Claude es un servicio de chat AI proporcionado por Ace Data Cloud, basado en la serie de grandes modelos de lenguaje Anthropic Claude. A través de la API unificada de Ace Data Cloud, puedes integrar rápidamente Claude con Python para lograr funcionalidades como diálogo multi-turno, indicaciones del sistema, salida en streaming, modo de salida JSON, entre otras.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un token API
- Entorno Python 3.7 o superior
- Instalar la librería requests: `pip install requests`

## Uso básico

El endpoint principal para llamar a la API de Claude es:

```
POST https://api.acedata.cloud/v1/chat/completions
```

Este ejemplo usa el modelo `claude-sonnet-4-6`.  
Modelos disponibles incluyen: `claude-sonnet-4-6`, `claude-opus-4-5-20251101`, `claude-3-5-sonnet`.

Ejemplo completo en Python:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "claude-sonnet-4-6",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Reemplaza `YOUR_API_TOKEN` con el token real que obtuviste en la plataforma Ace Data Cloud.

## Manejo de respuestas

Tras una llamada exitosa, la API devuelve datos en formato JSON. Se recomienda verificar el código de estado HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Llamada exitosa:", result)
else:
    print(f"Llamada fallida, código de estado: {response.status_code}")
    print(response.text)
```

## Uso avanzado

Para APIs de chat, se soporta salida en streaming para obtener respuestas en tiempo real:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción                         |
|------------------|-----------------------------------|
| 401              | Autenticación fallida, verifica el token API |
| 403              | Saldo insuficiente o acceso denegado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor        |
