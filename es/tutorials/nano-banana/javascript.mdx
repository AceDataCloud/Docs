## Introducción

Nano Banana es un servicio de imágenes AI proporcionado por Ace Data Cloud, basado en el servicio de generación de imágenes Gemini. A través de la API unificada de Ace Data Cloud, puedes integrar rápidamente Nano Banana con JavaScript para realizar generación de imágenes a partir de texto, edición de imágenes, múltiples proporciones, alta resolución y otras funciones.

## Requisitos Previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Node.js 18+ o un entorno de navegador moderno

## Uso Básico

El endpoint principal para llamar a la API de Nano Banana es:

```
POST https://api.acedata.cloud/nano-banana/images
```

Este ejemplo utiliza el modelo `nano-banana-2`.  
Modelos disponibles: `nano-banana`, `nano-banana-2`, `nano-banana-pro`.

Ejemplo completo de código JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/nano-banana/images", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A white siamese cat",
  "model": "nano-banana-2",
  "aspect_ratio": "1:1"
}),
});

const result = await response.json();
console.log(result);
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Manejo de Respuestas

Se recomienda verificar el código de estado de la respuesta y manejar errores:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Llamada exitosa:", result);
} else {
  console.error(`Llamada fallida, código de estado: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Envoltorio para Node.js

Se recomienda encapsular en una función reutilizable:

```javascript
async function callNanoBanana(data) {
  const response = await fetch("https://api.acedata.cloud/nano-banana/images", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Manejo de Errores

Códigos de error comunes:

| Código de Estado | Descripción |
|------------------|-------------|
| 401 | Autenticación fallida, por favor verifica el API Token |
| 403 | Saldo insuficiente o acceso no autorizado |
| 429 | Límite de frecuencia de solicitudes excedido |
| 500 | Error interno del servidor |
