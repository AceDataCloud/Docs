---

## Introducción

Nano Banana es un servicio de imágenes AI proporcionado por Ace Data Cloud, basado en el servicio de generación de imágenes Gemini. A través de la API unificada de Ace Data Cloud, puedes usar cURL para llamar rápidamente a Nano Banana y realizar funciones como generación de imágenes a partir de texto, edición de imágenes, múltiples proporciones y alta resolución.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un API Token
- Tener un entorno de terminal con cURL instalado

## Uso básico

El endpoint principal para llamar a la API de Nano Banana es:

```
POST https://api.acedata.cloud/nano-banana/images
```

Este ejemplo usa el modelo `nano-banana-2`.  
Modelos disponibles: `nano-banana`, `nano-banana-2`, `nano-banana-pro`.

Ejemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat", "model": "nano-banana-2", "aspect_ratio": "1:1"}'
```

Por favor, reemplaza `YOUR_API_TOKEN` con el Token real que obtuviste en la plataforma Ace Data Cloud.

## Ejemplo de respuesta

Después de una llamada exitosa, se devuelve un dato en formato JSON, por ejemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Uso de jq para procesar la respuesta

Se recomienda usar la herramienta jq para formatear la salida:

```bash
curl -s -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat", "model": "nano-banana-2", "aspect_ratio": "1:1"}' | jq .
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción                          |
|------------------|------------------------------------|
| 401              | Autenticación fallida, verifica el API Token |
| 403              | Saldo insuficiente o acceso denegado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor          |
