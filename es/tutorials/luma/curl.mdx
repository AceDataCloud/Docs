## Introducción

Luma es un servicio de video AI proporcionado por Ace Data Cloud, que genera videos con Luma Dream Machine. A través de la API unificada de Ace Data Cloud, puedes usar cURL para llamar rápidamente a Luma y realizar funciones como generación de video a partir de texto, generación de video a partir de imágenes, continuación de video, control de cuadros inicial y final, videos en bucle, entre otros.

## Requisitos previos

- Tener una cuenta en [Ace Data Cloud](https://platform.acedata.cloud) y obtener un Token API
- Tener un entorno de terminal con cURL instalado

## Uso básico

El endpoint principal para llamar a la API de Luma es:

```
POST https://api.acedata.cloud/luma/videos
```

Ejemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}'
```

Por favor, reemplaza `YOUR_API_TOKEN` con el token real que obtuviste en la plataforma Ace Data Cloud.

## Ejemplo de respuesta

Después de una llamada exitosa, se devuelve un dato en formato JSON, por ejemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Uso de jq para procesar la respuesta

Se recomienda usar la herramienta jq para formatear la salida:

```bash
curl -s -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}' | jq .
```

## Manejo de errores

Códigos de error comunes:

| Código de estado | Descripción                         |
|------------------|-----------------------------------|
| 401              | Autenticación fallida, verifica el Token API |
| 403              | Saldo insuficiente o acceso denegado |
| 429              | Límite de frecuencia de solicitudes excedido |
| 500              | Error interno del servidor        |
