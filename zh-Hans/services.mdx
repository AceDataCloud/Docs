选择下方服务。先阅读[快速开始](https://platform.acedata.cloud/documents/api-quickstart?lang=zh-cn)获取 API Key 并发起请求，各指南说明对应服务的输入、模型与输出格式。

**GPT Image 2.6** 可以选择 [Flare](https://platform.acedata.cloud/models/gpt-image-2.6-flare?m=image&lang=zh-cn) 或 [Sunburst](https://platform.acedata.cloud/models/gpt-image-2.6-sunburst?m=image&lang=zh-cn)，再阅读[图像生成](https://platform.acedata.cloud/documents/openai-images-generations-integration?lang=zh-cn)或[图像编辑](https://platform.acedata.cloud/documents/openai-images-edits-integration?lang=zh-cn)指南。
