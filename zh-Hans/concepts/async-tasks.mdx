---
title: "异步任务"
description: "提交一次生成，查询原任务 ID 并取得最终结果。"
---

支持 `async: true` 的端点可以先返回任务 ID，生成会继续执行。立即保存该 ID，按对应端点的终态规则持续查询，再读取结果或错误。

## 提交生成请求

从[应用管理](https://platform.acedata.cloud/console/applications?lang=zh-cn&utm_source=docs&utm_medium=referral&utm_campaign=evergreen)复制 API Key。要[使用 ACE Music 生成歌曲](https://platform.acedata.cloud/documents/acemusic-audios-integration?lang=zh-cn)，先在终端设置 Key，再提交一次生成请求。下方 JSON 示例展示已发布的响应结构，请使用自己请求返回的任务 ID、音轨 ID 和媒体地址替换占位值。

```bash
export ACEDATACLOUD_API_KEY="YOUR_API_KEY"

curl --fail-with-body https://api.acedata.cloud/acemusic/audios \
  --header "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "action": "generate",
    "model": "acemusic-v1.1",
    "custom": false,
    "prompt": "An uplifting acoustic folk song about coming home",
    "async": true
  }'
```

### 提交响应 JSON

ACE Music 受理异步请求后返回 HTTP `202`。保存 `task_id`，后续持续查询这个任务。

```json
{
  "task_id": "YOUR_TASK_ID",
  "trace_id": "YOUR_TRACE_ID",
  "status": "created"
}
```

## 查询原任务

把已保存的 `task_id` 放入查询请求的 `id` 字段。

```bash
curl --fail-with-body https://api.acedata.cloud/acemusic/tasks \
  --header "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"action":"retrieve","id":"YOUR_TASK_ID"}'
```

### 处理中响应 JSON

任务查询返回 HTTP `200` 时，生成可能仍在处理中。

```json
{
  "id": "YOUR_TASK_ID",
  "type": "audios",
  "state": "processing",
  "trace_id": "YOUR_TRACE_ID",
  "finished_at": null,
  "response": {
    "success": false,
    "task_id": "YOUR_TASK_ID",
    "status": "processing",
    "data": []
  }
}
```

`state` 为 `created`、`submitting`、`processing`、`storing` 或 `submission_unknown` 时继续查询。处理中嵌套的 `response.success` 可能为 `false`，先检查任务状态再判断生成是否失败。

### 完成响应 JSON

完整歌曲生成组的 `state` 为 `succeeded`，结果包含两首音轨。

```json
{
  "id": "YOUR_TASK_ID",
  "type": "audios",
  "state": "succeeded",
  "trace_id": "YOUR_TRACE_ID",
  "response": {
    "success": true,
    "task_id": "YOUR_TASK_ID",
    "status": "succeeded",
    "data": [
      {
        "id": "FIRST_TRACK_ID",
        "model": "acemusic-v1.1",
        "state": "succeeded",
        "audio_url": "https://media.example.com/first-song.mp3"
      },
      {
        "id": "SECOND_TRACK_ID",
        "model": "acemusic-v1.1",
        "state": "succeeded",
        "audio_url": "https://media.example.com/second-song.mp3"
      }
    ]
  }
}
```

使用每首音轨的 `response.data[].audio_url` 播放或下载结果。音轨 `id` 用于后续翻唱或融合，原 `task_id` 用于查询这次生成。`failed` 和 `partial_failed` 都是终态，读取错误及已交付的音轨。完整字段见 [ACE Music 任务指南](https://platform.acedata.cloud/documents/acemusic-tasks-integration?lang=zh-cn)。

## 用 Python 执行同一流程

Python 与上方 cURL 步骤二选一使用。先运行 `pip install requests`。下面的代码提交一次，打印任务 ID，并查询到终态。

```python
import os
import time
import requests

headers = {"Authorization": f"Bearer {os.environ['ACEDATACLOUD_API_KEY']}"}
submitted = requests.post(
    "https://api.acedata.cloud/acemusic/audios",
    headers=headers,
    json={
        "action": "generate",
        "model": "acemusic-v1.1",
        "custom": False,
        "prompt": "An uplifting acoustic folk song about coming home",
        "async": True,
    },
    timeout=30,
)
submitted.raise_for_status()
task_id = submitted.json()["task_id"]
print("Save this task ID to resume later:", task_id, flush=True)

# Keep this ID when resuming. Submit the generation only once.
for attempt in range(180):
    response = requests.post(
        "https://api.acedata.cloud/acemusic/tasks",
        headers=headers,
        json={"action": "retrieve", "id": task_id},
        timeout=30,
    )
    response.raise_for_status()
    task = response.json()
    state = task.get("state") or task.get("status")
    if state in {"succeeded", "failed", "partial_failed"}:
        result = task.get("response") or {}
        if state != "succeeded":
            raise RuntimeError({"task_id": task_id, "state": state, "error": result.get("error")})
        for track in result.get("data", []):
            print(track["audio_url"])
        break
    time.sleep(5)
else:
    print("Still pending. Resume querying this task ID:", task_id)

```

## 按端点的任务规则处理

各服务分别定义查询路径、请求字段与终态。调用 Suno、Veo、Seedance 等 API 时，按对应[服务指南](https://platform.acedata.cloud/services?lang=zh-cn)编写查询。任务查询返回成功 HTTP 状态时，生成仍可能处于处理中。部分操作会直接返回完整结果或流式输出。

查询失败或达到轮询次数后，保留原任务 ID，稍后继续查询。提交时的连接超时可能导致受理结果待确认，重新提交相同生成前，先检查任务历史，或带 `trace_id` 联系支持。

## Webhook 回调

端点支持时，在原生成请求中传入 `callback_url` 接收最终结果。ACE Music 接受 HTTPS 回调地址，并以异步方式执行该请求。

```json
{
  "action": "generate",
  "model": "acemusic-v1.1",
  "custom": false,
  "prompt": "An uplifting acoustic folk song about coming home",
  "async": true,
  "callback_url": "https://your-app.example/callbacks/acemusic"
}
```

在应用中保存提交返回的任务 ID，按该 ID 幂等处理回调，并及时返回 `2xx`。将回调作为通知，更新应用状态前查询已记录的原任务确认结果。轮询也可以恢复缺失的回调。具体回调内容以所选端点指南为准。
