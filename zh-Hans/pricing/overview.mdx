Ace Data Cloud 上的按量 AI API 服务采用**按量计费**（Pay-as-you-go），不收取月度订阅费。下文的 Credits 换算与按调用扣费规则适用于这类 API 套餐。

Discord、Telegram 账号代理等部署服务需要先开通**按时长订阅**再部署。可选订阅时长和当前价格以控制台为准。

## 计费币种

- 控制台展示使用 **USD** 作为参考币种
- 实际扣减以**积分（Credits）**为单位
- 套餐购买时按当时套餐的「Credits ↔ USD」比例折算

USD 估算：

$$
\text{USD} = \text{Credits} \times \frac{\text{package.price}}{\text{package.amount}}
$$

每个套餐的换算比例可能不同，请使用当前套餐的价格与 Credits 数量计算，并在购买前查看控制台中的实时套餐。

## 计费时机

| 调用类型 | 何时扣费 |
|---|---|
| 同步 API（如 Chat） | 响应返回时按 token / 字符 / 次数扣 |
| 异步任务（图像 / 视频 / 音频） | 任务最终 success 时扣费 |
| 任务最终 failed | 一般不扣费（以服务详情页约定为准） |
| 上游 5xx / 网关超时 | 不扣费 |

## 查看实时价格

价格随服务、模型、参数（分辨率、时长、token 数）变化，**最权威的当前价格在控制台**：

<Steps>
  <Step title="登录控制台">
    打开 [platform.acedata.cloud](https://platform.acedata.cloud)
  </Step>
  <Step title="进入服务详情页">
    在「Services」中选择目标服务（Midjourney、Suno、Claude 等）
  </Step>
  <Step title="查看定价">
    打开「定价」/「Pricing」标签，按场景查 USD 单价
  </Step>
</Steps>

<Note>
  历史上本文档区曾尝试维护分品类的价格表，但 AI 模型更新极快——为避免误导，目前**只把控制台作为唯一定价来源**。
</Note>

## 实例余额与通用余额

- **实例余额**（Instance / Dedicated）：在某个服务下创建的应用所分配的额度，只能用于该服务
- **通用余额**（General Balance）：所有服务通用
- 默认从实例余额扣减；按量（`Usage`）应用的 `allow_overdraft=true` 时，即使余额变成负数，也继续从自身余额扣费，不会因余额不足切换到通用余额
- 未开启透支时，实例余额耗尽后是否切换由「允许使用通用余额」（`allow_consume_global`）决定；切换后以通用 Application 的透支设置为准
- `allow_overdraft` 是只读字段，默认为 `false`，须由管理员授权。调用仍正常计费，负余额表示待结算额度；应用禁用、到期和 API 凭证限额仍然生效
- 适用余额不足且未获准透支时，API 返回 `403 used_up`（不是 402）——见 [响应格式](/zh-Hans/concepts/responses)

## 折扣

质押 $ACE 代币可叠加折扣，相关入口与规则以控制台为准。
