title: "ACE Music MCP 接入"
description: "acemusic MCP server integration"
---

ACE Music MCP 为支持 Model Context Protocol 的客户端提供歌曲创作、参考音频上传、翻唱、双参考融合、歌词生成和任务查询工具。使用已获 ACE Music 服务权限的 AceDataCloud API 凭据。

## 配置

服务器包名为 `mcp-acemusic`，支持标准输入输出与托管 HTTP 接入。包和托管端的发布状态以 [MCP 仓库](https://github.com/AceDataCloud/MCPs/tree/main/acemusic) 的发行说明为准。

发布后，可在支持 MCP 的客户端配置 stdio 服务：

```json
{
  "mcpServers": {
    "acemusic": {
      "command": "uvx",
      "args": ["mcp-acemusic"],
      "env": {"ACEDATACLOUD_API_TOKEN": "YOUR_API_KEY"}
    }
  }
}
```

环境变量为 `ACEDATACLOUD_API_TOKEN`。工具包括灵感生歌、自定义生歌、参考上传、翻唱、融合、歌词生成与任务查询；具体启动参数与版本以该包 README 为准。

## 创作流程

1. 告诉助手歌曲主题、风格，或提供自定义标题和歌词。
2. 助手提交一次生成并保存返回的任务 ID。
3. 使用任务工具等待和查询原任务，不因等待而重复提交。
4. 结果包含两首候选的播放与下载地址；歌词助手可以先生成可编辑草稿。

生成、上传与歌词工具分别收费，任务查询免费。生成、翻唱与融合的完整两首按一组收一次费用；最终失败或部分失败不收生成费。参考上传成功导入一首后收一次费用，失败不收费。基础生成可选 `acemusic-v1.1` 与 `acemusic-v1`；翻唱和融合使用 `acemusic-v1.1`。翻唱选一首自己的平台音轨，融合选恰好两首不同且兼容的音轨。仅在用户明确选择上传操作时导入新参考，不要为翻唱隐式另发付费上传。当前不提供纯音乐、风格强度、续写、分轨或音色工具。

API 的参数和错误约定见 [歌曲指南](https://platform.acedata.cloud/documents/acemusic-audios-integration) 与 [任务指南](https://platform.acedata.cloud/documents/acemusic-tasks-integration)。
