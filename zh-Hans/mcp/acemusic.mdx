ACE Music MCP 让支持 [Model Context Protocol](https://modelcontextprotocol.io) 的 AI 客户端调用歌曲创作、参考音频上传、翻唱、双参考融合、歌词生成和任务查询工具。你可以先让助手写歌词，确认后再生成歌曲，或使用自己的参考音轨继续创作。

## 申请和使用

接入前，先获取 AceDataCloud API Token：

1. 注册或登录 [AceDataCloud 控制台](https://platform.acedata.cloud/console/applications)。
2. 打开**通用应用**，点击**创建 API Key**；如果已有可用的 API Key，直接复制即可。这里的 API Key 就是本指南使用的 API Token。
3. 确认该凭据允许访问 ACE Music 的相关 API，且应用余额、有效期和凭据限额满足调用要求。已有 ACE Music 应用的凭据也可以使用。
4. 需要管理、更新或撤销凭据时，前往 [API 凭据管理](https://platform.acedata.cloud/console/credentials)。价格与额度见 [ACE Music 服务页面](https://platform.acedata.cloud/services/acemusic)。

将下面示例中的 `YOUR_API_TOKEN` 替换为复制出的 API Key。不要使用账号管理 Token 代替 API 调用凭据，也不要把真实密钥写入对话、公开代码或版本库。

## 方式一：本地运行 MCP Server

本地接入使用已发布的 Python 包 [`mcp-acemusic`](https://pypi.org/project/mcp-acemusic/)。先安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)，确保客户端能够运行 `uvx`，再添加以下 stdio 配置：

```json
{
  "mcpServers": {
    "acemusic": {
      "command": "uvx",
      "args": ["mcp-acemusic"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

例如，Claude Desktop 的配置文件位置为：

- macOS：`~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows：`%APPDATA%\Claude\claude_desktop_config.json`

将配置合并到已有的 `mcpServers` 中，保存后重启或重新连接客户端。其他支持 stdio 的客户端按其配置入口填写相同的命令、参数和环境变量即可。

## 方式二：连接托管 MCP Server

支持 Streamable HTTP 的客户端可以配置以下连接信息：

| 配置项 | 内容 |
| --- | --- |
| Server URL | `https://acemusic.mcp.acedata.cloud/mcp` |
| 请求头 | `Authorization: Bearer YOUR_API_TOKEN` |

例如，在 VS Code 的 `.vscode/mcp.json` 中配置：

```json
{
  "servers": {
    "acemusic": {
      "type": "http",
      "url": "https://acemusic.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_TOKEN"
      }
    }
  }
}
```

保存后在客户端连接该服务器并加载工具。不同客户端的 HTTP 配置格式可能不同，请使用该客户端的 MCP 设置入口。未携带有效凭据时，服务器会拒绝连接；如果客户端只支持 OAuth，请按其授权流程连接，具体兼容性以客户端和服务端当前支持情况为准。

## 可用工具

| 工具 | 用途 |
| --- | --- |
| `acemusic_generate_music` | 根据主题和风格描述生成歌曲 |
| `acemusic_generate_custom_music` | 根据标题、歌词和音乐风格生成歌曲 |
| `acemusic_upload_audio` | 从公开 HTTPS MP3 地址导入一首参考音轨，单独收费 |
| `acemusic_cover_audio` | 使用一首自己的平台音轨翻唱 |
| `acemusic_mashup_audio` | 融合恰好两首不同且兼容的平台音轨 |
| `acemusic_generate_lyrics` | 生成可编辑的标题与歌词，单独收费 |
| `acemusic_get_task` | 查询一个原任务的状态与结果 |
| `acemusic_get_tasks_batch` | 批量查询原任务，每次 1–50 个 |
| `acemusic_list_tasks` | 分页查询自己的历史，每页最多 50 条 |
| `acemusic_list_models` | 查看可用模型与默认模型 |
| `acemusic_get_capabilities` | 查看支持的操作与任务恢复说明 |

基础歌曲生成可选 `acemusic-v1.1`（默认）和 `acemusic-v1`。翻唱和融合使用 `acemusic-v1.1`，需提供歌词与风格，标题可选；`audio_influence` 范围为 1–100，默认 60。参考音轨的 `audio_id` 来自已完成任务中的音轨 `id`，与 `task_id` 不同。

当前不提供纯音乐控制、风格强度、续写、分轨、音色、WAV、MIDI 或视频导出工具。请以工具实际参数为准，不要套用其他音乐服务的字段。

## 从歌词到歌曲

连接成功后，可以对助手说：

> 先帮我写一首关于故乡的中文民谣歌词，给出标题。先让我确认歌词，再生成歌曲。

确认后再说：

> 用刚才确认的标题和歌词生成歌曲，风格是温暖民谣、木吉他。提交一次后保存任务 ID，查询同一个任务，完成后给我两首候选的播放和下载链接。

助手应按以下步骤执行：

1. 调用歌词工具生成草稿，让你确认或修改。
2. 使用自定义歌曲工具提交一次创作，保存 `task_id`。
3. 约每 10 秒查询原任务，根据等待情况逐步延长间隔。
4. 检查任务和各音轨状态，返回已完成音轨的 `audio_url`。完整歌曲任务包含两首候选；参考上传任务包含一首音轨。

如需翻唱已有作品，直接使用已完成音轨的 `audio_id`。只有你明确选择导入新参考时才调用上传工具，避免额外产生参考上传费用。

## 任务状态与费用

`created`、`submitting`、`processing`、`storing` 表示任务尚在处理。`succeeded` 为完整成功，`partial_failed` 和 `failed` 为终态；部分失败时仍可能保留一首可播放的候选。歌曲结果位于任务记录的 `response.data` 中。

如果状态为 `submission_unknown`，表示提交结果需要进一步核查。保留原任务 ID、Trace ID 和请求信息，不要自动重新生成。客户端超时、断线或重启后同样应先查询原任务。

生成、翻唱和融合按完整双曲组收费，每组只收一次；最终失败或部分失败不收生成费。参考上传和歌词助手分别按成功操作收费，任务查询免费且仍需有效凭据和访问权限。具体价格以 [ACE Music 服务页面](https://platform.acedata.cloud/services/acemusic) 和实际应用套餐为准。

## 常见问题

- **找不到 `uvx` 命令**：先安装 uv，并确认 AI 客户端的运行环境能够找到该命令，然后重新连接 MCP。
- **连接返回 401/403**：检查 API Token 是否正确、是否已撤销，以及凭据是否允许访问 ACE Music 的相关 API。
- **提示余额或限额不足**：在控制台检查应用余额与 API Key 限额。免费查询仍需要任务 API 权限。
- **提交后没有立即收到音频**：生成是异步任务，使用原 `task_id` 查询；受理成功不代表音频已交付。
- **需要查看底层 API 参数**：参阅 [歌曲与参考音频集成指南](https://platform.acedata.cloud/documents/acemusic-audios-integration)、[歌词生成集成指南](https://platform.acedata.cloud/documents/acemusic-lyrics-integration) 和 [任务查询集成指南](https://platform.acedata.cloud/documents/acemusic-tasks-integration)。MCP 安装与版本说明见 [项目仓库](https://github.com/AceDataCloud/MCPs/tree/main/acemusic)。
