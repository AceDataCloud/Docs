[MCP（Model Context Protocol）](https://modelcontextprotocol.io) 是由 Anthropic 推出的模型上下文协议，允许 AI 模型（如 Claude、GPT 等）通过标准化接口调用外部工具。通过 AceData Cloud 提供的 Seedance MCP Server，你可以在 Claude Desktop、VS Code、Cursor 等 AI 客户端中直接使用字节跳动 Seedance 生成 AI 视频。

## 功能概览

Seedance MCP Server 提供以下核心功能：

- **文本生成视频** — 通过文本提示词生成高质量视频
- **图片生成视频** — 以图片为参考生成视频（首帧、末帧、参考图等模式）
- **多模型支持** — 支持 Seedance 1.5 Pro、1.0 Pro、1.0 Lite 等多种模型
- **多种分辨率** — 支持 480p、720p、1080p 多种分辨率
- **多种画面比例** — 支持 16:9、9:16、1:1、4:3、3:4、21:9 等比例
- **灵活时长** — 支持 2-12 秒的视频时长
- **音频生成** — 部分模型支持同时生成音频
- **任务查询** — 监控生成进度并获取结果

## 前置准备

使用前，你需要获取 AceData Cloud API Token：

1. 注册或登录 [AceData Cloud 平台](https://platform.acedata.cloud)
2. 前往 [Seedance Videos API](https://platform.acedata.cloud/documents/seedance-videos) 页面
3. 点击「Acquire」获取 API Token（首次申请赠送免费额度）

## 方式一：使用托管 MCP Server（推荐，零安装）

AceData Cloud 已经把 **Seedance MCP Server** 托管在云端，**无需本地安装任何依赖**，直接在 AI 客户端里填写下面这个 URL 就能用：

```
https://seedance.mcp.acedata.cloud/mcp
```

认证方式：在请求头中加上 `Authorization: Bearer 你的API Token` 即可（Claude.ai 通过 OAuth 自动完成，无需手动填 Token）。

### Claude.ai（网页版，OAuth 登录，最简单）

1. 打开 [Claude.ai](https://claude.ai) → 左下角 **Customize** → **Connectors** → **Add More**
2. 在 URL 处填入：`https://seedance.mcp.acedata.cloud/mcp`
3. 完成 OAuth 授权登录（自动跳转 AceData Cloud 登录页）
4. 回到对话界面，工具即可使用

### Claude Desktop

编辑配置文件：

- macOS：`~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows：`%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "seedance": {
      "type": "http",
      "url": "https://seedance.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

保存后重启 Claude Desktop 即可生效。

### Claude Code（终端命令行）

```bash
claude mcp add seedance --transport http https://seedance.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### 其他支持 MCP 的客户端

任何支持 MCP Streamable HTTP 协议的客户端（Windsurf、Cline、ChatGPT Connectors、Gemini CLI、JetBrains AI Assistant 等）都可以通过填写以下两项接入：

- **URL**：`https://seedance.mcp.acedata.cloud/mcp`
- **Header**：`Authorization: Bearer 你的API Token`

## 方式二：本地运行（pip / uvx 安装）

如果你需要离线运行、自定义代码或部署到内网，可以把 MCP Server 安装在本地通过 stdio 启动。

### 安装

pip 安装（推荐）：

```bash
pip install mcp-seedance
```

或源码安装：

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

安装完成后，即可使用 `mcp-seedance` 命令启动服务。

### 在 Claude Desktop 中使用（本地）

编辑 Claude Desktop 配置文件：

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

添加以下配置：

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

如果使用 `uvx`（无需提前安装包）：

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

保存配置后重启 Claude Desktop 即可生效。

### 在 VS Code / Cursor 中使用（本地）

在项目根目录创建 `.vscode/mcp.json`：

```json
{
```

## 可用工具列表

| 工具名 | 说明 |
|--------|------|
| `seedance_generate_video` | 通过文本提示词生成视频 |
| `seedance_generate_video_from_image` | 以图片为参考生成视频 |
| `seedance_get_task` | 查询单个任务状态 |
| `seedance_get_tasks_batch` | 批量查询任务状态 |
| `seedance_list_models` | 列出所有可用模型及其能力 |
| `seedance_list_resolutions` | 列出可用分辨率和画面比例 |
| `seedance_list_actions` | 列出所有可用工具和工作流示例 |
