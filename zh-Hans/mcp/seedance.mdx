[MCP（Model Context Protocol）](https://modelcontextprotocol.io) 是由 Anthropic 推出的模型上下文协议，允许 AI 模型（如 Claude、GPT 等）通过标准化接口调用外部工具。通过 AceData Cloud 提供的 Seedance MCP Server，你可以在 Claude Desktop、VS Code、Cursor 等 AI 客户端中直接使用字节跳动 Seedance 生成 AI 视频。

## 功能概览

Seedance MCP Server 提供以下核心功能：

- **文本生成视频** — 通过文本提示词生成高质量视频
- **图片生成视频** — 以图片为参考生成视频（首帧、末帧、参考图等模式）
- **多模型支持** — 支持 Seedance 1.x、1.5、2.0 与 2.5
- **多种分辨率** — 支持 480p、720p、1080p，部分模型支持 4k
- **多种画面比例** — 支持 16:9、9:16、1:1、4:3、3:4、21:9 与 adaptive
- **灵活时长** — 按模型支持 2–30 秒或自动时长
- **多模态视频** — 支持音频生成、参考音频/视频，以及 2.5 的视频编辑与延长
- **任务查询** — 监控生成进度并获取结果

## 推荐：使用托管 MCP 的 OAuth 授权

在支持远程 MCP OAuth 的客户端中添加服务器地址：

```text
https://seedance.mcp.acedata.cloud/mcp
```

选择连接或登录，登录 Ace Data Cloud，查看权限并授权，然后启用工具。此路径不需要先创建或复制 API Token。服务已支持 OAuth discovery、动态客户端注册（DCR）及 S256 PKCE；DCR 注册客户端，用户仍需登录和授权，API 使用照常计费。

| 客户端 | 接入方式与条件 |
| --- | --- |
| Claude 网页版或提供远程连接器的 Desktop 版本 | 在连接器界面添加上述地址并授权；入口受版本与套餐影响。不要将远程 HTTP 配置写入本地 stdio 配置文件。 |
| 支持原生远程 MCP OAuth 的 VS Code | 执行 **MCP: Add Server**，选择 HTTP，填入地址并按提示登录；专用 AceDataCloud 扩展使用独立的 API Key 设置。 |
| 其他客户端 | 确认当前版本支持远程 HTTP、OAuth/DCR，并使用该客户端的配置说明。配置文件格式不能在不同客户端间通用。 |

## API Token 备选路径

本地 stdio、自托管或不支持远程 OAuth 的客户端使用 API Token。登录 [Ace Data Cloud 平台](https://platform.acedata.cloud)，选择服务并创建所需权限的 API 凭据。将 Token 存入客户端的凭据设置或本地环境变量，不要放进 URL、聊天内容或版本库。不同客户端的 HTTP Header 配置应按其版本说明填写。

安装开源 MCP 或完成授权不代表获得免费额度，也不承诺生成时间或商业使用权。生成前查看当前服务价格、余额与适用条款。

## 方式二：本地运行（pip / uvx 安装）

如果你需要本地 stdio、自定义代码或自托管，可以在本地启动 MCP Server。生成仍需联网调用 API，不是离线推理。

### 安装

pip 安装（推荐）：

```bash
pip install mcp-seedance
```

或源码安装：

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

安装完成后，即可使用 `mcp-seedance` 命令启动服务。

### 在 Claude Desktop 中使用（本地）

编辑 Claude Desktop 配置文件：

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

添加以下配置：

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

如果使用 `uvx`（无需提前安装包）：

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

保存配置后重启 Claude Desktop 即可生效。

### 在 VS Code 中使用（本地）

在项目根目录创建 `.vscode/mcp.json`：

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

或者使用 `uvx`：

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

其他本地客户端请按其当前版本的 stdio 配置说明填写 command、args 和 env，不要将 VS Code 的配置直接当成通用格式。

## 验证结果与常见失败

请客户端生成一项简单的视频作品，保留任务编号并查询同一个任务，直到终态成功，再打开或播放最终链接。连接成功、工具列表加载、HTTP 200、任务编号与处理中预览均不代表最终产物。

遇到 401，重新登录或检查 Token 与权限；余额不足时查看账单；任务处理中继续查询；最终失败时阅读错误后决定是否重试，新生成可能再次计费。

## 可用工具列表

| 工具名 | 说明 |
|--------|------|
| `seedance_generate_video` | 通过文本提示词生成视频 |
| `seedance_generate_video_from_image` | 以图片为参考生成视频 |
| `seedance_get_task` | 查询单个任务状态 |
| `seedance_get_tasks_batch` | 批量查询任务状态 |
| `seedance_list_models` | 列出所有可用模型及其能力 |
| `seedance_list_resolutions` | 列出可用分辨率和画面比例 |
| `seedance_list_actions` | 列出所有可用工具和工作流示例 |

## 使用示例

配置完成后，你可以在 AI 客户端中直接用自然语言调用这些功能，例如：

- 「用这张照片作为第一帧，生成一段 8 秒的视频」
- 「生成一段 1080p 竖屏 9:16 的短视频」
- 「用 Seedance 1.5 Pro 模型生成带音频的视频」
