## 准备工作

1. 准备一个 API Token（见 [网关与认证](/authentication)）
2. 安装 Python 3.10+（或用 `pipx` / `uvx`）
3. 选择目标 AI 工具的 MCP 配置文件

## Claude Desktop 配置

编辑 `~/Library/Application Support/Claude/claude_desktop_config.json`（Mac）或 `%APPDATA%\Claude\claude_desktop_config.json`（Windows）：

```json
{
  "mcpServers": {
    "midjourney": {
      "command": "uvx",
      "args": ["mcp-midjourney"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    },
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    },
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

重启 Claude Desktop，输入框右下角会出现 🔌 图标——可用工具列表已加载完毕。

## Cursor / Windsurf 配置

在 Cursor `Settings` → `Tools & Integrations` → `Add new MCP server`，或编辑 `~/.cursor/mcp.json`：

```json
{
  "mcpServers": {
    "midjourney": {
      "command": "uvx",
      "args": ["mcp-midjourney"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

Windsurf 同样支持 `mcp.json` 配置。

## HTTP 传输模式

每个 MCP 服务器都支持 `stdio` 和 `streamable-http` 两种传输：

```bash
# stdio（默认，给桌面工具用）
uvx mcp-midjourney

# HTTP（给远程 / 多客户端）
uvx mcp-midjourney --transport streamable-http --host 0.0.0.0 --port 8000
```

HTTP 模式下 AI 客户端连接 `http://your-host:8000/mcp`。

## pip 安装

如果你不想用 `uvx`，可以用 pip：

```bash
pip install mcp-midjourney mcp-suno mcp-serp
# 然后命令变成
{
  "command": "mcp-midjourney",
  "args": [],
  "env": { "ACEDATACLOUD_API_TOKEN": "..." }
}
```

## 常见问题

- **AI 助手看不到工具**：检查 MCP 服务器日志（Claude Desktop 在 `~/Library/Logs/Claude/`），确认 Token 没拼错
- **`uvx` 命令找不到**：用 `pip install uv` 安装 `uv`，或直接换 `pip install`
- **HTTP 模式被拒**：检查防火墙、监听地址是 `0.0.0.0`（不是 `127.0.0.1`）
- **想用代理**：设置 `HTTPS_PROXY` 环境变量
