## 动态模型目录

使用有效的 Coding Application 凭证请求：

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

模型目录会持续变化，不在本文维护固定数量或静态模型清单。`/v1/models` 返回全局模型目录，不会按 Coding 凭证自动裁剪；配置前仍需与凭证 API scope、所选协议和客户端兼容范围交叉确认。

## 常见排查

- **余额不足**：进入 [Applications 控制台](https://platform.acedata.cloud/console/applications)，找到 Coding Application 并主动续购。
- **客户端仍请求原地址**：确认配置属于启动客户端的同一用户和工作区，并完全退出后重新启动客户端。
- **模型名称不可用**：重新请求 `/v1/models`，核对 exact model ID、凭证 API scope 和客户端支持的协议。
- **Token 无法调用接口**：确认凭证属于 Coding Application，并检查 `allowed_api_ids` 和应用 API 权限。
