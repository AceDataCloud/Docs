Coding Plan 配置向导固定为三步：选择开发产品、选择接入方案、选择该方案已验证的 exact model。

> Plus、Standard、Pro、Max 的模型权限相同，只区分 Credits 数量。Coding Application 不使用通用余额回退。

## 状态

| 状态 | 含义 |
|---|---|
| 待复验 | 旧路径存在，但还没绑定最终选择器字节和当前客户端证据 |
| 待 evidence | 官方配置机制明确，仍缺工具调用、ApiUsage与扣费核对 |
| 待能力确认 | 尚未观察当前产品真实 outbound 合同，不生成配置 |
| 受限 | 官方合同不支持或未证明任意自定义 Endpoint |
| 已验证 | 最终配置、客户端请求、用量与 Coding 余额均已核对 |

只有“已验证”方案进入模型选择并显示复制按钮。指南存在、MCP可用或旧版本曾成功，都不等于最终profile已验证。

## WorkBuddy 与 Cursor 兼容性

WorkBuddy 的自定义模型使用 OpenAI Chat Completions。保持“自定义协议”关闭并填写 Base URL，客户端会校验地址并补上标准 `/chat/completions` 路径：

```text
Base URL: https://api.acedata.cloud/v1
API Key: YOUR_API_TOKEN
```

- [WorkBuddy 配置](https://platform.acedata.cloud/documents/development_workbuddy)（已验证的自定义模型配置）
- [Cursor 兼容性说明](https://platform.acedata.cloud/documents/development_cursor_coding)（Cursor 当前官方 BYOK 文档未保证任意自定义 Base URL，选择器不生成 Cursor 配置）

模型 ID 以实时目录与具体profile allowlist的交集为准；模型家族不决定协议，不在本文维护静态清单。

## 如何选择计费方式

- 只用 Claude、每天重度交互并能接受 5 小时窗口与周额度：Claude Max 可能更划算。社区重度个案显示 Max 可产生远高于月费的官方 API 等值，但这不是固定额度或一般用户承诺。
- 主要使用 Kimi Code 与 Kimi 消费产品，并能接受共享月额度和 5 小时/周频控：Kimi 会员可能更合适。
- 需要 Claude、GPT/Codex、GLM、Kimi、DeepSeek 自由切换，或需要 API、自动化与逐次账单：Coding Plan 更合适。

消费会员、官方 API 与 Ace Credits 是不同计费模型，不能把 Max 5x/20x 或 Kimi 会员额度换算成固定 Ace Credits，也不能承诺 Coding Plan 一定更便宜。Coding Plan 不采用消费会员式的 5 小时/周额度重置，但 API 仍有正常并发与速率限制。

### 怎么看“便宜多少”

截至 2026-08-14，Claude Pro 月付 $20，Claude Max 5x 月付 $100，Max 20x 月付 $200。Claude 与 Claude Code 共享动态订阅额度，会话额度每 5 小时重置，另有每周及其他限制；官方没有公布可换算成固定 Ace Credits 的 Token 数。

- Coding Plus ¥99 的购买门槛比 Claude Pro 月付约低 27%。
- Coding Standard ¥299 的购买门槛比 Claude Max 5x 月付约低 56%。
- 这两项只比较公开月付价格，不是同额度、同权益或同等可用量比较。

Ace Coding 的区别是按实际 Credits 扣减，没有消费会员式的 5 小时或每周额度重置；一次购买会增加对应 Credits，并将应用有效期顺延 30 天，不自动续费。四档模型权限完全相同。个人偶尔使用选 Plus，每天开发选 Standard，高强度持续 Agent 选 Pro；只有多 Agent、团队共享或无人值守负载才建议 Max。

## 如何选择模型

- 大型重构、跨文件分析、长Agent任务：优先 Claude Opus / Sonnet。
- Codex CLI、Responses工具链、OpenAI SDK：选择GPT系列。
- 中文项目和高性价比日常编码：尝试GLM。
- 超长上下文、需求文档和仓库规划：尝试Kimi。
- 算法推理、高频任务和成本敏感工作：尝试DeepSeek。

## 常见排查

### 返回余额不足

进入 [Applications 控制台](https://platform.acedata.cloud/console/applications)，找到 Coding Application 并续购。Coding余额不会自动回退到通用余额。

### 客户端仍请求原地址

确认环境变量在启动客户端的同一个终端会话中生效，并完全退出后重新启动客户端。

### 模型名称不可用

先请求 `GET https://api.acedata.cloud/v1/models` 获取实时模型目录。不要把 Codex 当成模型名称；Codex是客户端，配置后选择GPT系列模型。

### Token 无法调用某个接口

确认凭证属于 Coding Application，并查看该应用的API权限范围。Coding Plan支持Claude Messages、Count Tokens、OpenAI Chat Completions和OpenAI Responses。
