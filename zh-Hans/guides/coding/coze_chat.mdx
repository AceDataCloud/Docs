当前 **coze.com 托管版**公开文档没有证明可以把任意 OpenAI-compatible Base URL 配置为模型 Provider，因此本页面不生成配置。

开源 **Coze Studio** 的模型管理后台支持 `openai` 协议和 API Root。它与托管版 Coze 不是同一能力合同。

## 如果你使用 Coze Studio

1. 打开 `http://localhost:8888/admin/#model-management`。
2. 新增 Provider 并选择 `openai` 协议。
3. API Root 填 `https://api.acedata.cloud/v1`，不要填写完整 `/chat/completions` 路径。
4. 填写 Coding 专属 API Token 和模型 ID。
5. 使用 Studio 自带连接测试；修改生产模型前先停止相关 Agent/Workflow 流量。

如果你使用托管版 Coze，请不要照搬 Studio 配置。可改用 Cline、Roo Code、Kilo Code、Continue、Aider 等已公开支持兼容端点的客户端。
