## 1. 获取 API Key

打开 [Ace Data Cloud 应用列表](https://platform.acedata.cloud/console/applications)，进入可用的应用并复制 API Key。

![获取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 安装 OpenCode

```bash
curl -fsSL https://opencode.ai/install | bash
```

也可以使用 npm：

```bash
npm install -g opencode-ai
```

## 3. 设置 API Key

```bash
export ACEDATACLOUD_API_KEY="你的 API Key"
```

如需长期生效，把这一行加入 `~/.zshrc` 或 `~/.bashrc` 后重新打开终端。

## 4. 配置 Provider

编辑 `~/.config/opencode/opencode.json`：

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ace Data Cloud",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  }
}
```

将两处 `MODEL_ID` 替换为 Coding Plan 当前提供的同一个模型 ID。Ace Data Cloud 这里使用 Chat Completions，所以 adapter 是 `@ai-sdk/openai-compatible`。

## 5. 验证并启动

```bash
opencode auth list
opencode models acedatacloud
opencode run --model acedatacloud/MODEL_ID "Reply only OK"
```

然后在项目目录运行 `opencode`。如果模型未出现，检查配置文件路径、JSON 语法和环境变量；401 表示 Key 无效或未导出。

IDE 扩展复用同一份 OpenCode runtime 配置，参见 [OpenCode IDE Extension](https://platform.acedata.cloud/documents/opencode-ide-integration)。
