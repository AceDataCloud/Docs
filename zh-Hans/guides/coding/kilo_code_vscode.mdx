## 1. 获取 API Key

打开 [Ace Data Cloud 应用列表](https://platform.acedata.cloud/console/applications)，进入可用的应用并复制 API Key。

![获取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 添加 Custom provider

在 Kilo Code 中打开 **Settings → Providers**，点击 **Custom provider**，然后填写：

| 字段 | 值 |
| --- | --- |
| Provider ID | `acedatacloud` |
| Display name | `AceDataCloud` |
| Provider API | `OpenAI Compatible` |
| Base URL | `https://api.acedata.cloud/v1` |
| API key | 刚刚复制的 API Key |
| Models | 添加要使用的模型 ID |

![Kilo Code Custom provider 配置界面示意图](https://cdn.acedata.cloud/94eb5abd7a6f.png)

> 界面示意图（非实时截图）：基于 Kilo Code MIT 仓库的官方界面图，通过 GPT Image 2 仅替换 Provider ID、显示名、Base URL 和合成 Key 占位符；不作为连接成功证明。

点击 **Submit**，模型会出现在选择器中。需要团队共享或更细配置时，也可按官方文档编辑用户级 `~/.config/kilo/kilo.jsonc` 或项目级 `./kilo.jsonc`。

## 3. 验证

选择 `acedatacloud/MODEL_ID` 并发送 `Reply only OK`，再执行一次只读文件操作。若模型没有出现，检查 Provider 是否已提交、模型 ID 和 Base URL 是否正确。
