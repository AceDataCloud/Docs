Kilo Code 支持自定义 Provider。以下配置固定使用 OpenAI Chat Completions，并由 VS Code 插件读取。

## 配置

在用户级 `~/.config/kilo/kilo.jsonc` 或项目级 `./kilo.jsonc` 写入：

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

在启动 VS Code 的环境中导出 `ACEDATACLOUD_API_KEY`，把两处 `MODEL_ID` 替换为配置向导中选择的模型。

## 验证

重新加载 VS Code，选择 `acedatacloud/MODEL_ID`，发送 `Reply only OK`，再执行一次只读文件操作。如果 Provider 列表没有刷新，检查 JSONC 语法、环境变量和配置文件所在用户。
