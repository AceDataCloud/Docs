Coze 官方自定义模型文档支持 Anthropic Messages API。当前路线为**实验性**：官方能力明确，但 Coze 租户版本、Header、路径拼接、streaming 和工具调用仍需逐项验证。

## 配置

1. 进入 Coze 模型管理并新增自定义模型。
2. Protocol 选择 Anthropic Messages API。
3. Base API URL 填写 `https://api.acedata.cloud`。
4. API Key 填写你的 Ace Data Cloud API Token。
5. Model 填写模型目录中支持 Anthropic Messages 的精确模型 ID。
6. 保存并完成 Coze 的连接测试。
7. 在 Bot/Agent 中发送 `Reply only OK`，再测试一次工具调用。

## 当前边界

- 不同 Coze 区域、版本或套餐可能显示不同表单。
- Base API URL 不应重复追加 `/v1/messages`；若当前 UI 明确要求完整 API URL，以表单提示为准。
- Messages、Chat Completions 和 Responses 是三条独立路线，不能互相替代验证。
