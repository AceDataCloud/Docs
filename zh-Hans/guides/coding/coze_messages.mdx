当前 **coze.com 托管版**公开文档没有说明可将任意 Anthropic Messages Base URL 配置为模型 Provider，因此本页面不提供猜测性 URL、Header 或模型配置。

Coze 的开源 **Coze Studio** 是不同产品。其官方 Model configuration 文档支持在管理后台增加模型 Provider，但能否选择原生 `claude` 协议、如何填写 API Root，取决于你部署的 Studio 版本和 Provider 插件。

## 如果你使用 Coze Studio

1. 打开 `http://localhost:8888/admin/#model-management`。
2. 新增模型 Provider，先确认当前版本存在原生 Claude/Anthropic 协议选项。
3. 仅在表单明确支持 API Root 时使用 `https://api.acedata.cloud`；不要把 `/v1/messages` 当作 Base URL 重复拼接。
4. 保存后用 Studio 自带连接测试验证。

如果你使用托管版 Coze，请等待官方开放自定义模型端点，或选择本配置中心中已明确支持自定义 Provider 的客户端。
