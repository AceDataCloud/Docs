如果你熟悉 YAML，可以直接维护 Hermes 的 named provider 配置。主配置位于 `~/.hermes/config.yaml`，Token 放在 `~/.hermes/.env`。

## 1. 保存 Token

```dotenv
ACEDATACLOUD_API_KEY=PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE
```

## 2. 配置 Provider

```yaml
providers:
  acedatacloud:
    type: openai
    base_url: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    default_model: MODEL_ID

model:
  provider: acedatacloud
  default: MODEL_ID
```

把两个 `MODEL_ID` 替换为 Coding 配置向导中选择的同一个模型 ID。不要把真实 Token 直接写进 YAML 或提交 `.env`。

## 3. 验证

```bash
hermes --version
hermes chat --model MODEL_ID "Reply only OK"
```

如果 Hermes 仍使用旧配置，请确认文件属于启动 Hermes 的同一用户，并完全退出后重启。自定义 `base_url` 会直接使用该兼容端点，不会继承其它 Provider 的配置。
