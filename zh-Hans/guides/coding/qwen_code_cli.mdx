Qwen Code 使用 `~/.qwen/settings.json` 的 `modelProviders` 配置自定义 Provider。这里固定使用 OpenAI-compatible 协议。

## 配置

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud` 必须是数组。Provider 条目是独立配置，不会自动继承其它顶层 context、Header 或 body 参数。

## 验证

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Reply only OK"
```

进入后发送 `Reply only OK`，再运行一次只读文件工具。严格兼容端点若拒绝工具结果格式，请检查当前 Qwen Code 版本和官方 compatibility 说明。
