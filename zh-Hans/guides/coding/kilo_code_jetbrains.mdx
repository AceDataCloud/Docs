Kilo Code 的 JetBrains 插件使用同一套 `kilo.jsonc` Provider 格式。配置必须位于实际运行插件的用户环境；Remote Development 时通常是远程 backend 主机。

## Provider 配置

在 `~/.config/kilo/kilo.jsonc` 写入：

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

在启动 JetBrains backend 的环境中导出 `ACEDATACLOUD_API_KEY`，再重启 IDE 或远程 backend。

## 验证

选择 `acedatacloud/MODEL_ID`，发送 `Reply only OK`，再让 Agent 读取一个测试文件。若本地正常而远程失败，优先检查配置文件和环境变量是否写在远程主机。
