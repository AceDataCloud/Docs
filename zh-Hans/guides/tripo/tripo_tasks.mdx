---
title: "查询 Tripo 模型任务"
description: "Tripo 3D 集成指南 - Ace Data Cloud"
---

凭 AceDataCloud Token 调用 `POST /tripo/tasks`。查询免费，使用与生成相同的账号。单笔用 `id` 或 `trace_id`，`action` 默认为 `retrieve`。

```bash
curl -X POST https://api.acedata.cloud/tripo/tasks \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H "Content-Type: application/json" \
  -d "{\"action\":\"retrieve\",\"id\":\"${TASK_ID}\"}"
```

单笔结果是任务记录，包含 `id`、`type`、`trace_id`、原请求 `request`、`started_at` 和 `progress`。处理中可以间隔几秒继续查询。完成后查看 `response.success`，成功时 `response.data[0].model_url` 是下载地址，失败时 `response.error` 包含错误码和消息。时间戳、`finished_at` 和耗时 `elapsed` 位于任务记录顶层，单位为秒。遇到 `submission_unknown` 时保留原任务 ID 核对。

批量查询使用 `{"action":"retrieve_batch","ids":["&lt;任务 ID 1>","&lt;任务 ID 2>"]}`，也可使用 `trace_ids`；每次最多 100 条。响应为 `{"items":[...],"count":2}`，保留输入顺序和重复项。查不到或无权读取的任务，单查返回 `{}`，批查对应位置为 `null`。

任务记录的 `type` 为 `generations`、`models` 或 `animations`。骨骼检查读取 `response.data[0].riggable`，文件类操作读取 `response.data[0].model_url`。
