---
title: "Tripo 模型处理"
description: "Tripo 3D 集成指南 - Ace Data Cloud"
---

使用 `POST /tripo/models` 处理已有模型，传入所需的 `action`。同步、异步、回调、账号归属及任务查询与 3D 生成相同。

| action | 输入 | 结果 |
| --- | --- | --- |
| import | `model_url`，公开 HTTPS 的 GLB、GLTF、FBX、OBJ 或 STL 文件，最大 150 MiB | 可继续引用的模型 ID 和 GLB；有数据时返回 `normalize_scale` 和 `normalize_translation` |
| texture | `model_id` 或 `model_url`；可选 `prompt`、`image_url`、`image_urls` 三选一 | 新模型、纹理和可选预览 |
| convert | `model_id` 或 `model_url`，以及目标 `format` | 转换后的模型文件 |

```json
{"action":"texture","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","prompt":"蓝色哑光表面","texture_quality":"standard","async":true}
```

纹理质量支持 `fast`、`standard`、`detailed`、`extreme`。使用文本提示时可附加 `style_image_url`；图片和多视图参考遵循生成接口的格式。更多纹理参数见 OpenAPI。

转换支持 `GLTF`、`FBX`、`USDZ`、`OBJ`、`STL` 和 `3MF`。返回项的 `format` 表示实际交付格式；例如请求 GLTF 可交付二进制 GLB。OBJ 以 ZIP 打包材质和贴图。请求 FBX 时设 `texture_packaging: "zip"` 可获得分离贴图，打包结果注明 `container: "ZIP"`。开启非默认网格或纹理设置可能按高级转换计费，详见服务价格。

使用 `data[0].id` 引用本账户模型，导入的归一化变换满足 `normalized = original × normalize_scale + normalize_translation`。模型下载地址在 `data[0].model_url`。
