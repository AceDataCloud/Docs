---
title: "Tripo 3D 生成"
description: "Tripo 3D 集成指南 - Ace Data Cloud"
---

调用 `POST /tripo/generations` 创建新模型，传入文字、单图或同一物体的多个视角。使用 AceDataCloud Token，默认同步返回结果。传 `async: true` 或 `callback_url` 时先返回 HTTP 200 和 `task_id`。完成回调与同步结果具有相同的 JSON 结构。

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

`action` 默认为 `generate`。输入三选一：`prompt`（1–1024 个字符）、`image_url`、`image_urls`。图片为最大 20 MiB 的公开 HTTPS PNG/JPEG。多视图按正、左、背、右排列，必须提供正面和至少另一面，可用 null 跳过中间视角。

`model` 默认 `v3.1-20260211`，也可显式选用 `v3.0-20250812`、`v2.5-20250123`、`P1-20260311` 或 `P2-20260801`。`texture` 默认为 `standard`，纯几何用 `none`。不同模型和纹理档位使用不同额度。

从 `data[0].model_url` 下载 GLB，`image_url` 为可选预览。保留 `data[0].id` 供后续纹理、转换或骨骼操作使用。重试同一提交时保留同一个 `Idempotency-Key` 和请求体。
