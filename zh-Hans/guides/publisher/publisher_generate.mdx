## 介绍

Publisher Generate API 是 Ace Data Cloud 提供的 AI 内容改写接口。它可以将原始内容根据目标平台的特点和风格进行智能改写，生成适合该平台的优质内容。

## 功能特点

- **平台适配**：根据不同平台的内容风格自动调整
- **AI 驱动**：使用先进的 AI 模型进行内容改写
- **保留原意**：在改写的同时保持原文的核心观点和信息

## 基本用法

```bash
curl -X POST 'https://api.acedata.cloud/publisher/generate' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "title": "AI API 入门指南",
    "content": "# AI API 入门\n\n本文将介绍如何使用 AI API...",
    "channel": "xiaohongshu"
  }'
```

### 响应示例

```json
{
  "success": true,
  "data": {
    "title": "小红书教程：AI API 入门指南 ✨",
    "content": "✨ 最近发现了一个超好用的 AI API...\n\n💡 入门超简单...\n\n📌 实测效果超赞..."
  }
}
```

## 支持的平台

| 平台 | channel 值 | 改写风格说明 |
|------|-----------|------------|
| 小红书 | xiaohongshu | 年轻化、表情丰富、种草风格 |
| Medium | medium | 专业博客、英文长文 |
| Dev.to | dev | 技术社区、开发者友好 |
| X | x | 简短精炼、社交媒体风格 |

## 注意事项

- 每次生成请求消耗 1.0 积分
- 目前支持 4 个平台的内容生成
- 生成的内容可以直接用于 Publish API 的 content 字段
