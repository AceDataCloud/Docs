## 1. 获取 API Key

打开 [Ace Data Cloud 应用列表](https://platform.acedata.cloud/console/applications)，进入可用的应用并复制 API Key。

![获取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 发送第一个请求

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

成功响应的图片位于 `data[].url`。下面是 2026 年 9 月 8 日通过 Ace Data Cloud 实际请求得到的 1024×1536 结果（任务 `d56455e2-e7f7-4bcd-b935-475b0a1e0948`，trace `eb938601-8192-407f-b539-1e0554b697ec`）：

![GPT Image 2 生成的白色马克杯](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. 常用参数

| 字段 | 说明 |
| --- | --- |
| `model` | `gpt-image-2`（默认推荐）、`gpt-image-2.5-flare`（更快）或 `gpt-image-2.5-sunburst`（更高保真与控制）；三者均可选择对应的 `:official` 变体，`gpt-image-2` 还支持 `:reverse` |
| `prompt` | 图片描述，最长 32,000 个字符 |
| `size` | `auto` 或 `WIDTHxHEIGHT`；宽高须为 16 的倍数，长边不超过 3840，总像素为 655,360–8,294,400，宽高比不超过 3:1 |
| `n` | 1–10；`response_format=b64_json` 时仅支持 1 |
| `quality` | GPT Image 模型支持 `auto`、`low`、`medium`、`high`；2.5 / 2.6 Flare / Sunburst（含 `:official`）额外支持 `xhigh`、`max`。官方通道按实际 Token 用量计费 |
| `response_format` | `url` 或 `b64_json` |
| `callback_url` | 可选；长任务完成后向该地址发送结果 |

常用尺寸：

| 比例 | 1K | 2K | 4K |
| --- | --- | --- | --- |
| 1:1 | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3 | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4 | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` 会根据提示词中的比例、像素和版式意图选择画幅；需要精确像素时直接填写尺寸。

2.0 / 2.5 逆向型号（含 `:reverse` 别名）在自动恢复时可能使用 GPT Image 2.5 Flare 完成请求；请求型号和按成功图片张数计费的方式保持不变。

官方 API 通道的页面价格是请求前估算，最终以响应中的实际 Token 用量和使用记录为准。

## 4. 多张生成

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` 及其 `:reverse` 别名按成功张数计费；`gpt-image-2:official`、`gpt-image-2.5-flare:official` 和 `gpt-image-2.5-sunburst:official` 根据响应中的文字输入和图片输出实际 Token 结算。页面价格是请求前估算，最终以使用记录为准。

## 5. 异步回调

请求体加入 `callback_url` 后，接口会先返回 `{"task_id": "..."}`，完成时向该 URL POST 最终结果；同步请求仍返回 `created` 和 `data`：

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

回调接收方应使用 `task_id` 去重，并验证请求来源与数据格式。

## 6. 排错

| 状态 | 检查 |
| --- | --- |
| 400 | `model`、`prompt`、尺寸格式、`n` 与 `response_format` 组合 |
| 401 | API Key 是否完整，Header 是否为 `Authorization: Bearer ...` |
| 429 | 请求过于频繁，稍后重试 |
| 504 | 同步生成超时；改用 `callback_url` |

错误响应会包含 `error.code`、`error.message` 和 `trace_id`。反馈问题时提供 `trace_id`，不要提供 API Key。

完整字段和实时枚举以 [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations) 页面为准。图像编辑请查看 [GPT Image 2 / 2.5 / 2.6 图像编辑](https://platform.acedata.cloud/documents/openai-images-edits)。

## GPT Image 2.6

GPT Image 2.6 沿用 2.5 的生成、编辑、异步任务和计费接口：

| 模型 | 计费 |
| --- | --- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse` | 0.22 Credits/张 |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/张 |
| `gpt-image-2.6-flare:official` | 与 2.5 official 相同，按实际 Token 用量计费 |
| `gpt-image-2.6-sunburst:official` | 与 2.5 official 相同，按实际 Token 用量计费 |

质量可选 `auto`、`low`、`medium`、`high`、`xhigh`、`max`；尺寸使用 `auto` 或符合上述约束的 `WIDTHxHEIGHT`。本接口支持 `png`、`jpeg`、`webp`；GPT Image 2.6 还支持原生 `gif` 动图，暂不支持 SVG。编辑支持 JSON 图片 URL 和 multipart 文件上传。`:reverse` 是同名普通版的显式别名。请使用完整型号，不要传 `gpt-image-2.6`。

### GPT Image 2.6 GIF 动图

GPT Image 2.6 Flare、Sunburst 的普通版、`:reverse`、`:official` 均可使用 `output_format: "gif"`。动画帧、循环信息和播放时长会保留；`frame_count` 表示帧数，`frame_duration_ms` 表示每帧毫秒数，帧数必须为 2–16 的整数，每帧时长必须为 20–655350 毫秒的整数，且仅用于 GIF；编码按最接近的 10ms 取整。未指定时默认为 9 帧、每帧 200 毫秒；GIF 的 size 省略或为 auto 时使用 512x512 预设。

推荐先使用 `size: "512x512"`、`frame_count: 9`、`frame_duration_ms: 200`。GIF 有独立的尺寸和帧数限制，不能直接套用静态 4K 规格；部分模型会调整实际输出尺寸。`n` 表示返回的 GIF 文件数量，不是动画帧数。普通版和 `:reverse` 仍按成功文件数量计费，官方版按实际 Token 用量计费。

```json
{
  "model": "gpt-image-2.6-flare",
  "prompt": "A small red ball moves left and right on a white background, seamless looping animation, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### GPT Image 2.6 4K 静态图

Flare、Sunburst 及其 `:reverse`、`:official` 变体都可使用前述 4K 像素预设，例如 `3840x2160` 和 `2160x3840`。生成和编辑均通过 `size` 传入具体像素；`4K` 不是有效的 `size` 值，`4096x4096` 也超出当前像素上限。上述 4K 规格适用于静态 PNG/JPEG/WebP，GIF 请使用其专用参数。


### GPT Image 2.6 构图复杂度

`complexity` 可选 `low`、`medium`、`high`，省略时使用模型默认 `high`。它控制规划复杂度，与 `quality` 渲染质量独立；不会额外按次收费，官方版仍按实际 Token 结算。其他型号不支持此参数。

GIF 不支持 mask、标注图、自定义压缩、提示词重写或部分图像流式输出；不兼容的组合会在生成前拒绝。尺寸、帧数和数量共同受模型像素预算限制；普通 Flare 的 `1024x1024`、2 帧已验证可用，不能把这个结论扩展到所有 1K 组合或 4K GIF。
