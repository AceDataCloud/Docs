title: "ACE Music 歌曲生成 API"

ACE Music 支持从一句创作灵感或自定义歌词生成一组歌曲候选。可选模型为 `acemusic-v1.1`（默认）和 `acemusic-v1`。一次完整生成包含两首候选，分别试听并下载 MP3。

## 获取凭据

在 [控制台](https://platform.acedata.cloud/console/applications) 开通 ACE Music，或使用已获该服务权限的通用应用凭据。请求携带 `Authorization: Bearer YOUR_API_KEY`。应用余额、凭据限额和服务权限均会检查。

## 灵感模式

```bash
curl --request POST 'https://api.acedata.cloud/acemusic/audios' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'Idempotency-Key: music-draft-001' \
  --data '{
    "action": "generate",
    "model": "acemusic-v1.1",
    "custom": false,
    "prompt": "一首关于故乡的中文歌曲，温暖的民谣风格",
    "async": true
  }'
```

## 自定义模式

将 `custom` 设为 `true`，提供 `title`、`lyric` 和 `style`。歌词可包含 `[Verse]`、`[Chorus]` 等段落标签，也可先通过 [歌词生成 API](https://platform.acedata.cloud/documents/acemusic-lyrics-integration) 创作，再编辑后提交。

```json
{
  "action": "generate",
  "model": "acemusic-v1.1",
  "custom": true,
  "title": "回家的路",
  "lyric": "[Verse]\n晚风吹过熟悉的街道\n[Chorus]\n灯火等我回到家",
  "style": "中文民谣，木吉他，温暖人声",
  "async": true
}
```

| 字段 | 说明 |
| --- | --- |
| `action` | 当前仅支持 `generate`，可省略 |
| `model` | `acemusic-v1.1` 或 `acemusic-v1` |
| `custom` | `false` 使用灵感模式；`true` 使用自定义歌词 |
| `prompt` | 灵感模式必填的创作描述 |
| `lyric` / `style` / `title` | 自定义模式的歌词、音乐风格和标题 |
| `async` | 默认 `true`；返回任务 ID 后查询结果 |
| `callback_url` | 可选的 HTTPS 完成回调地址；传入后采用异步执行 |

当前生成接口不接受音频上传、翻唱、续写、分轨或音色参数。风格描述会影响创作方向，成品的演绎和实际时长以结果为准。

## 任务与交付

保存提交返回的 `task_id`，通过 [任务 API](https://platform.acedata.cloud/documents/acemusic-tasks-integration) 查询。提交受理仅表示任务已建立。完整结果的 `data` 是音轨列表，每首包含平台音轨 `id`、`model`、`state`、`title`、`lyric`、`style`、实际 `duration`（秒）、`audio_url` 和可选 `image_url`。

两首音频均可交付后，整个组才标记为成功。部分失败保留已完成的音轨，任务标记为 `partial_failed`；封面缺失不影响已有音频播放。浏览器刷新、网络中断后应查询原任务，不要再次提交生成。

同一 `Idempotency-Key` 与同一请求内容返回原任务；使用同键发送不同内容会冲突。超时且受理状态不明确时保留该键和原任务身份，等待查询或联系支持，不要换键自动补发。

## 费用

按生成任务收费，完整两首只收一次。最终失败或部分失败的任务不收生成费；任务查询免费。歌词助手是独立的付费 API，歌曲生成不会自动另收歌词助手费用。

价格以控制台对应套餐为准。2026-11-17 的最大套餐与汇率基准下，一次完整生成折合人民币 ¥0.20，约 US$0.02995；不同套餐、优惠、站点加价和后续汇率变化会影响折算金额。

## 回调与错误

完成后向 `callback_url` 推送最终任务结果。接收方应按 `task_id` 去重并返回成功状态；回调可能重投。回调接收失败不会重新生成歌曲或额外扣费，仍可使用任务 API 获取结果。

参数无效返回 400；认证或权限问题返回 401/403；余额不足返回 402；限流返回 429；服务失败返回 500。异步执行错误通过任务终态和 `error` 表达。排查时提供 `task_id` 与 `trace_id`。
