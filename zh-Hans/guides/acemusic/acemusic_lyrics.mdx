ACE Music 歌词生成 API 可以根据主题和音乐风格生成标题与歌词。你可以先编辑歌词，再通过 [歌曲生成 API](https://platform.acedata.cloud/documents/acemusic-audios-integration) 的自定义模式创作歌曲。本文介绍获取 API Token、提交歌词请求、读取结果，以及将歌词用于歌曲创作的完整流程。

## 申请流程

1. 打开 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications)。如果尚未登录，请先注册或登录。
2. 在**通用应用**的 **API Key** 区域选择并复制密钥；如果尚无密钥，点击**创建 API Key**。文中的 API Token 与 API Key 指同一类调用凭据。
3. 你也可以在 [凭据管理](https://platform.acedata.cloud/console/credentials) 中管理密钥。使用 ACE Music 专属应用或设有 API 限制的密钥时，请确认允许访问歌词 API；后续查询和生歌还需要相应的任务、歌曲 API 权限。
4. 付费创作前请确认应用余额和密钥用量限额，余额不足时可前往 [充值页面](https://platform.acedata.cloud/console/coin)。

将示例中的 `YOUR_API_TOKEN` 替换为复制的 Token，并通过 `Authorization: Bearer YOUR_API_TOKEN` 请求头发送。请在服务端保存 Token，不要将其放入公开网页或代码仓库。

> 完整接口参数与在线调试：[ACE Music Lyrics API](https://platform.acedata.cloud/documents/acemusic-lyrics)。

## 基本使用

请求地址为 `POST https://api.acedata.cloud/acemusic/lyrics`。例如，想写一首关于夜晚坐火车回家的中文民谣，可以将主题写入 `prompt`，将音乐氛围写入 `style`。

```bash
curl --request POST 'https://api.acedata.cloud/acemusic/lyrics' \
  --header 'Accept: application/json' \
  --header 'Authorization: Bearer YOUR_API_TOKEN' \
  --header 'Content-Type: application/json' \
  --data '{
    "prompt": "写一段关于夜晚坐火车回家的原创中文民谣歌词，包含一段主歌和一段副歌。",
    "style": "温暖、木吉他、希望"
  }'
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `prompt` | string | 是 | 歌词主题、语言、故事或段落要求，最多 20,000 字符。 |
| `style` | string | 否 | 希望的风格和氛围，最多 20,000 字符。 |

本接口同步等待歌词结果，不接受 `async` 或 `callback_url` 参数。如果等待超过处理预算，会返回 HTTP 202 和 `task_id`；此时保存该 ID，改用任务 API 查询原任务。

### 响应示例

以下为一次真实成功响应。生成内容会随请求而变化。

```json
{
  "success": true,
  "task_id": "893deb8e-d6b5-4872-8d3a-07bdcae189e5",
  "trace_id": "a06d171c-ad78-4aeb-aa8e-1cd0834fe19b",
  "status": "succeeded",
  "data": [
    {
      "title": "归途夜车",
      "text": "[verse]\n车窗倒映着疲惫的脸庞\n铁轨在夜色里轻轻摇晃\n路过的站台落满了微霜\n背包里装着一年的行囊\n\n[chorus]\n呜——列车穿过了漫长黑夜\n每一步都在把距离缩短\n车轮声数着心底的期盼\n天亮时就能看见家门前的炊烟"
    }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `success` | 本次歌词生成是否成功。 |
| `task_id` | 平台任务 ID，用于后续查询和排查问题。 |
| `trace_id` | 请求跟踪 ID，联系支持时一并提供。 |
| `status` | 任务状态；`succeeded` 表示生成完成。HTTP 202 的受理结果仍需继续查询。 |
| `data` | 歌词结果列表。 |
| `data[*].title` | 生成的歌曲标题，可编辑。 |
| `data[*].text` | 歌词正文，包含换行和段落标签，可编辑；此字段不是音频地址。 |

## 将歌词用于歌曲创作

1. 从成功响应中取出 `data[0].title` 和 `data[0].text`，按需要编辑。
2. 调用歌曲生成 API，设置 `action=generate`、`custom=true`，将标题填入 `title`，将歌词正文填入 `lyric`，并填写 `style`。
3. 保存歌曲请求返回的新 `task_id`，通过 [任务查询指南](https://platform.acedata.cloud/documents/acemusic-tasks-integration) 获取歌曲结果。

注意两个接口的字段名称不同：歌词接口返回 **`text`**，歌曲接口接收 **`lyric`**。歌词任务与歌曲任务也各有自己的 `task_id`。

下列为歌曲接口的请求体示例；请将占位内容替换为你确认后的标题、完整歌词与风格，再按 [歌曲指南](https://platform.acedata.cloud/documents/acemusic-audios-integration) 发送请求。

```json
{
  "action": "generate",
  "model": "acemusic-v1.1",
  "custom": true,
  "title": "YOUR_SONG_TITLE",
  "lyric": "YOUR_LYRICS_TEXT",
  "style": "温暖的中文民谣，木吉他伴奏",
  "async": true
}
```

歌词生成与歌曲生成是两次独立的付费操作。仅调用歌词接口不会生成音频；直接调用歌曲接口也不会隐式另收歌词助手费用。

## 查询与异常处理

如果返回 HTTP 202，请将响应中的 `task_id` 填入下列请求的 `id`：

```bash
curl --request POST 'https://api.acedata.cloud/acemusic/tasks' \
  --header 'Accept: application/json' \
  --header 'Authorization: Bearer YOUR_API_TOKEN' \
  --header 'Content-Type: application/json' \
  --data '{
    "action": "retrieve",
    "id": "YOUR_LYRICS_TASK_ID"
  }'
```

任务查询返回任务记录，完成后的歌词位于 **`response.data`**，与直接调用歌词 API 成功时的 `data` 层级不同。建议每隔数秒查询并逐步延长间隔，达到终态后停止。

| HTTP 状态码 | 处理建议 |
| --- | --- |
| `400` | 检查 `prompt`、`style` 和参数类型，不要传入歌曲 API 的专用参数。 |
| `401` / `403` | 检查 Token 是否有效，以及应用和密钥是否有对应 API 权限。 |
| `402` | 检查余额和密钥用量限额。 |
| `404` | 查询时检查任务 ID 和当前调用账号。 |
| `429` | 降低调用频率，延迟后重试查询。 |
| `500` / `503` | 保留已有 `task_id`、`trace_id`，先查询原任务或联系支持。 |

网络中断或等待超时后，不要自动重发歌词生成请求。已拿到任务 ID 时继续查询原任务；未取得任务 ID 且受理状态不明确时，保留请求信息联系支持，避免重复生成和计费。

## 费用说明

每次成功生成歌词收取 **0.0157408497024 Credits**，最终失败不收费；查询自己的任务免费。实际货币金额受所用套餐、优惠、站点定价和汇率影响，请以控制台展示为准。
