---
title: "ACE Music 歌词生成 API"
description: "ACE Music 集成指南 - Ace Data Cloud"
---

根据主题与风格生成标题和歌词，编辑后可用于 [ACE Music 自定义歌曲生成](https://platform.acedata.cloud/documents/acemusic-audios-integration)。歌词生成独立收费，调用歌曲生成 API 不会隐式调用本接口。

```bash
curl --request POST 'https://api.acedata.cloud/acemusic/lyrics' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{"prompt":"关于故乡和回家的一首中文歌","style":"温暖的中国风民谣"}'
```

`prompt` 必填；`style` 可选。本接口等待同步结果，超过等待预算时返回 HTTP 202 和任务 ID，此时继续查询原任务。完成后结果沿用 `success`、`task_id`、`trace_id` 包络，`data` 为包含 `title` 和 `text` 的歌词列表。`text` 是可编辑歌词，不是音频地址。

成功生成收一次歌词费用。以 2026-11-17 的最大套餐与汇率基准折合人民币 ¥0.01，约 US$0.001497；实际折算按所用套餐、优惠、站点加价和汇率而异。生成失败不收费。查询已完成的个人任务免费。

网络中断时保留已取得的任务 ID。不要自动重发同步收费请求；优先使用 [任务 API](https://platform.acedata.cloud/documents/acemusic-tasks-integration) 查询原任务。权限、余额、参数和限流错误的处理与歌曲 API 一致。
