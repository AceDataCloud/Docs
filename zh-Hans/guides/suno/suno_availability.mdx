---
title: "Suno 音频和音色可用性检查 API"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

`POST /suno/availability` 接受一个资源 ID。查歌曲传 `audio_id`，查音色传 `persona_id`，两者必填其一。检查同步完成，需要 API Token，目前不扣 Credits。

## 请求

`audio_id` 来自已完成的歌曲任务，可用于续写或翻唱前的检查。

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

`persona_id` 来自音色创建结果。使用原应用和调用者身份，在支持音色查询的创建线路上发送以下请求体。

```json
{
  "persona_id": "33333333-3333-4333-8333-333333333333"
}
```

## 响应

两种请求使用同一份成功响应。`data.id` 是本次查询的资源 ID。

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

`available: true` 表示本次检查获得了正向证据。对音色，检查会核实创建归属，并确认关联账号当前被报告在线。实际生成结果仍以生成任务为准。

通过 `/suno/voices` 创建的私有克隆音色依赖创建账号。确认该账号当前离线时，接口返回 HTTP 200，`data` 示例如下。

```json
{
  "id": "33333333-3333-4333-8333-333333333333",
  "available": false
}
```

客户端可以把该音色标记为当前不可用，稍后再查。

无法确认时返回 HTTP 503 和 `availability_unknown`，例如查不到资源、旧记录缺少创建线路或查询超时。公开歌手风格可以跨账号使用，创建账号离线时同样返回 503。歌曲查询仍只在确认可用时返回 `available: true`。

每次请求只发送一个有效 UUID。所有线路收到双 ID 或两个 ID 都缺失的请求时，都会返回 HTTP 400。仅支持歌曲查询的线路收到只含 `persona_id` 的请求时返回 HTTP 400。遇到 HTTP 429 请降低查询频率。
