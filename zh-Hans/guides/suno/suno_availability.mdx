---
title: "Suno 音频可用性检查 API"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

`POST /suno/availability` 根据 `audio_id` 寻找音频在当前线路可继续处理的正向证据。可在续写、翻唱等操作前调用；结果只反映检查时的状态，不保证某个具体操作一定成功。该接口同步返回、需要 API Token，目前不扣 Credits。

`audio_id` 是已完成的 Suno 任务返回的歌曲 ID，不是 `task_id`。

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

成功响应示意：

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

检查成功时，`data.available` 为 `true`；无法确认时返回 `503 availability_unknown`，不返回 `false`。`audio_id` 格式错误返回 400，限流或服务异常也会返回错误响应。检查完成后到实际操作之间状态仍可能变化。
