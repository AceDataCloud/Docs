专属音乐模型可以从 6 至 24 首授权音频中学习一致的音乐特征，并用于后续歌曲创作。创建是异步操作；建议使用 24 首风格一致、音质清晰的音频获得更稳定的效果。

> 仅可提交您拥有合法使用权，或已取得模型创建及后续生成授权的音频。请勿上传未经许可的音乐或声音素材。

## 创建模型

调用 `POST /suno/custom-models`，并设置 `action=create`。建议同时发送唯一的 `Idempotency-Key` 请求头；网络重试时复用相同键，避免重复创建：

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

接口立即返回平台模型 ID 和任务 ID。创建完成后，回调或查询结果中的 `status` 会变为 `ready`。只有模型创建成功才会计费 **10 Credits**，按最大套餐折算约 **¥6.75/个**；创建失败不会扣费。

## 查询模型

查询单个模型：

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

分页查询当前应用的模型：

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

所有模型均归属于创建它的 Suno 应用。API 凭据轮换不会改变模型归属，其他应用不能查询或使用该模型。

## 使用模型生成歌曲

模型状态为 `ready` 后，继续调用 `POST /suno/custom-models`，并设置 `action=generate`：

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id` 必须是当前应用下状态为 `ready` 的专属音乐模型。模型不可用时请求会失败，不会自动改用其他模型。歌曲生成成功消耗 **0.90 Credits**，按最大套餐折算约 **¥0.61/次**；生成失败不扣费。查询和归档模型免费。

## 归档模型

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

当前 Beta 版本会将模型归档并禁止继续使用，响应中的 `capacity_released=false` 表示归档不承诺释放模型容量。归档操作可重复调用，不会重复计费。
