## Kickart 一键成片 API

`POST https://api.acedata.cloud/kickart/videos`

火山引擎 Kickart（即创）电商营销视频生成。输入商品链接或素材图片/视频，一键生成「商品介绍视频」或「商品主图视频」。

### 请求头

| 头 | 值 |
|---|---|
| `Authorization` | `Bearer &lt;你的 API Key>` |
| `Content-Type` | `application/json` |

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `mode` | string | 否 | 生成模式：`fast`（快速）/ `pro`（专业），默认 `fast`。与 `type` 一起决定套用的模板 |
| `type` | string | 否 | 视频类型：`intro`（商品介绍）/ `main`（商品主图），默认 `intro` |
| `template_id` | string | 否 | 直接指定官方模板 ID（高级用法）。传入后覆盖 `mode`/`type` |
| `product_url` | string | 否 | 抖店商品链接（`product_url`/`product_id`/`user_images`/`user_videos` 至少一个） |
| `product_id` | string | 否 | 抖店商品 ID |
| `user_images` | string[] | 否 | 用户提供的图片 URL 列表 |
| `user_videos` | string[] | 否 | 用户提供的视频 URL 列表 |
| `duration` | integer | 是 | 期望视频时长（秒）。商品介绍：15/30/45/60；商品主图：15/30 |
| `aspect_ratio` | string | 否 | 画面比例：`9:16`/`16:9`/`3:4`/`4:3`/`1:1`，默认 `9:16` |
| `language` | string | 否 | 视频语言（影响口播/字幕），如 `zh`/`en`/`pt-br`，默认 `zh` |
| `purpose` | string | 否 | 商品介绍视频的细分类型（好物推荐、品牌广告、剧情演绎、测评对比、日常Vlog 等） |
| `prompt` | string | 否 | 创意指令，描述视频核心内容、风格与卖点 |
| `nle_subtitle_enabled` | boolean | 否 | 是否添加硬字幕，默认 `true` |
| `use_subtitle_erasure` | boolean | 否 | 是否在分镜渲染阶段擦除底部字幕，默认 `false` |
| `watermark` | boolean | 否 | 是否添加「AI生成」明水印，默认 `false` |
| `callback_url` | string | 否 | 传入则立即返回 `task_id`，结果生成后回调该地址 |
| `async` | boolean | 否 | 设为 `true` 时立即返回 `task_id`，通过 `/kickart/tasks` 轮询结果 |

> **计费按档位**：价格由 `mode`+`type`（或 `template_id`）与 `duration` 决定，与官方一致。生成时间较长（专业档可能数分钟到数十分钟），建议使用 `async: true` 或 `callback_url` 异步获取结果。

### 请求示例

```bash
curl -X POST https://api.acedata.cloud/kickart/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "fast",
    "type": "intro",
    "product_url": "https://www.tiktok.com/view/product/172839182",
    "duration": 15,
    "language": "zh",
    "aspect_ratio": "9:16"
  }'
```

### 响应参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `success` | boolean | 是否成功 |
| `task_id` | string | 任务 ID |
| `trace_id` | string | 追踪 ID |
| `data.video_url` | string | 生成视频的 URL（已转存到 Ace Data Cloud CDN，永久可达） |
| `data.produce_id` | string | 上游作品 ID |
| `data.usage` | number | 上游消耗的创点数（用于对账） |
| `data.duration` | integer | 视频时长（秒） |

### 异步与轮询

设置 `async: true` 时，接口立即返回 `task_id`；随后通过任务查询接口获取结果：

```bash
curl -X POST https://api.acedata.cloud/kickart/tasks \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"action": "retrieve", "id": "<task_id>"}'
```

轮询接口免费（不计费）。也可通过 `callback_url` 在完成时接收结果推送。
