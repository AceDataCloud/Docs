title: "MiniMax H3 视频生成 API"

---

`POST https://api.acedata.cloud/minimax/videos` 使用 MiniMax H3 官方 V2 多模态请求结构创建异步视频任务。请求成功立即返回 `task_id`，再通过 [MiniMax H3 任务查询 API](/documents/minimax-tasks-integration) 获取状态和成片。

## 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 固定为官方模型名 `MiniMax-H3` |
| `content` | object[] | 是 | 多模态内容数组，必须包含一个非空 `text` 项 |
| `resolution` | string | 是 | `768P` 或 `2K` |
| `duration` | integer | 是 | 4–15 秒整数 |
| `ratio` | string | 条件必填 | `adaptive`、`21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16` |
| `callback_url` | string | 否 | 任务状态变化回调 URL |
| `aigc_watermark` | boolean | 否 | 是否添加 AIGC 标识水印，默认 `false` |

接口不接受 `prompt`、`image_urls`、`audio_urls`、`messages`、`first_frame_image` 或 `async` 等兼容字段。

## content 内容项

每个内容项通过 `type` 区分：

- `text`：使用 `text` 提供提示词，所有场景必填，最多 7000 字符。
- `image_url`：使用 `image_url.url` 提供图片，并通过 `role` 标记 `first_frame`、`last_frame` 或 `reference_image`。
- `video_url`：使用 `video_url.url` 提供参考视频，`role` 必须为 `reference_video`。
- `audio_url`：使用 `audio_url.url` 提供参考音频，`role` 必须为 `reference_audio`。

媒体 URL 支持公网 URL、`mm_file://{file_id}` 和对应媒体类型的 Base64 data URI。首尾帧场景与多模态参考场景不可混用。

## 文生视频

文生视频只包含文本项，`ratio` 必填且不能为 `adaptive`。

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "史诗级太空歌剧院线预告：女舰长站在巨大观景窗前，舰队跃迁离去，镜头缓慢推进。"
    }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "16:9"
}
```

## 首帧图生视频

图生视频把图片标记为 `first_frame`；宽高比跟随输入图片，`ratio` 可省略或设为 `adaptive`。

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "让画面中的人物自然移动，镜头缓慢推进"
    },
    {
      "type": "image_url",
      "image_url": {
        "url": "https://cdn.acedata.cloud/b1c82e4937.png"
      },
      "role": "first_frame"
    }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "adaptive"
}
```

首尾帧生成可再加入一项 `role: "last_frame"` 的图片。

## 多模态参考生视频

参考图片、视频、音频可组合使用。最多支持 9 张参考图、3 段参考视频和 3 段参考音频。

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "人物按照参考动作跳舞，剪辑节奏跟随参考音频"
    },
    {
      "type": "image_url",
      "image_url": { "url": "https://cdn.acedata.cloud/reference.png" },
      "role": "reference_image"
    },
    {
      "type": "video_url",
      "video_url": { "url": "https://cdn.acedata.cloud/motion.mp4" },
      "role": "reference_video"
    },
    {
      "type": "audio_url",
      "audio_url": { "url": "https://cdn.acedata.cloud/beat.mp3" },
      "role": "reference_audio"
    }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "adaptive"
}
```

## 创建响应

```json
{
  "task_id": "c0f63a98-a7dc-4a09-a1fb-46d32b312a28"
}
```

创建接口始终异步。成功和失败结果均通过任务查询接口获取；只有成功任务计费。
