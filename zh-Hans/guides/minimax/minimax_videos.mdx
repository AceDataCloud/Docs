`POST https://api.acedata.cloud/minimax/videos` 统一支持文生视频、单图图生视频、多图参考和音频引导视频。接口根据素材自动选择模式，无需传 `action`。

## 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `model` | string | 否 | `minimax-h3` | 当前仅支持 `minimax-h3` |
| `prompt` | string | 是 | — | 视频内容、动作、镜头与风格描述，最多 7000 字符 |
| `image_urls` | string[] | 否 | — | 1–9 个公网图片 URL；单图作为首帧，多图作为参考图 |
| `audio_urls` | string[] | 否 | — | 1–3 个公网 WAV/MP3 URL；传入时必须同时提供图片 |
| `resolution` | string | 否 | `2K` | `768P` 或 `2K` |
| `ratio` | string | 否 | `16:9` | `16:9` 或 `9:16`；单图模式跟随图片比例 |
| `duration` | integer | 否 | `4` | 4–15 秒整数 |
| `aigc_watermark` | boolean | 否 | `false` | 是否添加 AIGC 标识水印 |
| `async` | boolean | 否 | `false` | `true` 时立即返回任务 ID |
| `callback_url` | string | 否 | — | 公网 HTTP(S) 完成回调地址 |

模式规则：没有素材时为文生视频；一张图片且没有音频时为首帧图生视频；多张图片或存在音频时为多模态参考视频。

## 分辨率价格

| 分辨率 | 最大套餐价格 | 4 秒示例 |
| --- | --- | --- |
| 768P | **$0.057143/秒** | $0.228572 |
| 2K | **$0.091429/秒** | $0.365716 |

只对成功任务计费，失败任务不扣费。

## 文生视频

```json
{
  "model": "minimax-h3",
  "prompt": "A red fox running through a snowy forest at dawn, cinematic tracking shot",
  "resolution": "768P",
  "ratio": "16:9",
  "duration": 4,
  "async": true
}
```

## 单图图生视频

```json
{
  "model": "minimax-h3",
  "prompt": "Gentle camera push-in, natural motion, soft morning light",
  "image_urls": ["https://cdn.acedata.cloud/b1c82e4937.png"],
  "resolution": "768P",
  "duration": 4,
  "async": true
}
```

## 音频引导视频

```json
{
  "model": "minimax-h3",
  "prompt": "A dancer moves naturally to the rhythm, cuts follow the beat",
  "image_urls": ["https://cdn.acedata.cloud/b1c82e4937.png"],
  "audio_urls": ["https://cdn.acedata.cloud/6f7d62b18b.wav"],
  "resolution": "768P",
  "ratio": "9:16",
  "duration": 4,
  "async": true
}
```

## 异步执行

推荐传 `async: true`，立即获得 `task_id`，再通过 [MiniMax H3 任务查询 API](/documents/minimax-tasks-integration) 轮询。也可传 `callback_url` 接收最终结果。

成功结果的 `data[]` 包含 `model`、`mode`、`video_url`、`state`、`duration`、`ratio` 和 `resolution`；视频 URL 均为 AceDataCloud CDN 地址。

## 常见错误

| HTTP | 错误码 | 说明 |
| --- | --- | --- |
| 400 | `bad_request` | prompt 缺失、分辨率/比例/时长无效或素材超限 |
| 403 | `forbidden` | 内容安全检查未通过 |
| 429 | `busy` | 服务繁忙，请稍后重试 |
| 500 | `api_error` | 服务暂时不可用 |
| 504 | `timeout` | 本次等待超时；系统不会重复创建任务 |
