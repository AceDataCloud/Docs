`POST https://api.acedata.cloud/minimax/videos` 通过一个统一入口支持文生视频、图生视频和音频引导视频。接口根据输入素材自动判断模式，不需要传入 `action`。

## 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `model` | string | 否 | `minimax-h3` | 当前仅支持 `minimax-h3` |
| `prompt` | string | 条件 | — | 视频内容、动作、镜头和风格描述；纯文生视频时必填 |
| `image_urls` | string[] | 否 | — | 1–9 个公网 HTTP(S) 图片 URL |
| `audio_urls` | string[] | 否 | — | 1–3 个公网 HTTP(S) 音频 URL |
| `ratio` | string | 否 | `16:9` | `16:9` 或 `9:16` |
| `duration` | integer | 否 | `4` | 4–15 秒，必须为整数 |
| `async` | boolean | 否 | `false` | 设为 `true` 时立即返回任务 ID |
| `callback_url` | string | 否 | — | 公网 HTTP(S) 回调地址；设置后自动异步执行 |

至少需要提供 `prompt`、`image_urls`、`audio_urls` 中的一项。模式按以下顺序自动判断：存在 `audio_urls` 时为音频引导视频；否则存在 `image_urls` 时为图生视频；否则为文生视频。

价格为 **$0.25/秒**，失败任务不扣费。

## 文生视频

```bash
curl -X POST 'https://api.acedata.cloud/minimax/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "minimax-h3",
    "prompt": "A red fox running through a snowy forest at dawn, cinematic tracking shot",
    "ratio": "16:9",
    "duration": 6,
    "async": true
  }'
```

## 图生视频

```json
{
  "model": "minimax-h3",
  "prompt": "Gentle camera push-in, soft morning light",
  "image_urls": ["https://cdn.acedata.cloud/b1c82e4937.png"],
  "ratio": "9:16",
  "duration": 8,
  "async": true
}
```

最多可以提供 9 张参考图。传入多张图片时，应在提示词中说明需要保持的主体、风格或场景关系。

## 音频引导视频

```json
{
  "model": "minimax-h3",
  "prompt": "A dancer moving naturally to the rhythm",
  "image_urls": ["https://cdn.acedata.cloud/b1c82e4937.png"],
  "audio_urls": ["https://cdn.acedata.cloud/6f7d62b18b.wav"],
  "ratio": "9:16",
  "duration": 8,
  "async": true
}
```

最多支持 3 条参考音频。图片和提示词均为可选项，但至少需要提供一条音频。

## 异步执行

视频生成通常需要数分钟，推荐设置 `async: true`。接口会立即返回 `task_id`，随后使用 [MiniMax H3 任务查询 API](/documents/minimax-tasks-integration) 获取结果。

也可以提供 `callback_url`。任务完成后，AceDataCloud 会把与同步响应相同的最终结果 POST 到该地址。

## 成功结果字段

| 字段 | 说明 |
| --- | --- |
| `success` | 请求是否成功 |
| `task_id` | AceDataCloud 任务 ID |
| `trace_id` | 请求追踪 ID |
| `data[].id` | 与顶层一致的任务 ID |
| `data[].model` | 实际使用的公开模型名称 |
| `data[].mode` | `text_to_video`、`image_to_video` 或 `audio_guided` |
| `data[].video_url` | AceDataCloud CDN 视频地址 |
| `data[].state` | 成功时为 `succeeded` |
| `data[].duration` | 最终计费时长，单位秒 |
| `data[].ratio` | 输出宽高比 |

## 常见错误

| HTTP | 错误码 | 说明 |
| --- | --- | --- |
| 400 | `bad_request` | 参数缺失、素材数量超限、比例或时长无效 |
| 403 | `forbidden` | 内容安全检查未通过 |
| 413 | `request_too_large` | 请求体过大 |
| 429 | `too_many_requests` | 同时执行的任务过多 |
| 500 | `api_error` | 服务暂时不可用 |
| 504 | `timeout` | 本次等待超时；系统不会重复创建任务 |
