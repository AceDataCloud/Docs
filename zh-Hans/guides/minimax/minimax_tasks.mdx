通过 `POST https://api.acedata.cloud/minimax/tasks` 查询 `/minimax/videos` 创建的任务。字段遵循 MiniMax H3 官方任务对象；AceDataCloud 仅保留现有 POST 路由和 `action` 查询方式。

## 查询单个任务

```bash
curl -X POST 'https://api.acedata.cloud/minimax/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"YOUR_TASK_ID"}'
```

响应：

```json
{
  "task": {
    "id": "c0f63a98-a7dc-4a09-a1fb-46d32b312a28",
    "model": "MiniMax-H3",
    "status": "succeeded",
    "created_at": 1785125529,
    "updated_at": 1785125946,
    "content": {
      "url": "https://cdn.acedata.cloud/minimax/c0f63a98-a7dc-4a09-a1fb-46d32b312a28.mp4"
    },
    "resolution": "2K",
    "duration": 5,
    "usage": {
      "total_seconds": 5,
      "input_seconds": 0,
      "output_seconds": 5,
      "input_image_count": 1
    },
    "ratio": "adaptive",
    "task_type": "generation",
    "modality": "video"
  }
}
```

`status` 可能为 `queued`、`running`、`succeeded`、`failed` 或 `cancelled`。成功时视频地址位于 `task.content.url`；失败时返回 `task.error.code` 和 `task.error.message`。

## 批量查询

```json
{
  "action": "retrieve_batch",
  "ids": ["TASK_ID_1", "TASK_ID_2"]
}
```

批量响应：

```json
{
  "items": [
    {
      "id": "TASK_ID_1",
      "model": "MiniMax-H3",
      "status": "running",
      "task_type": "generation",
      "modality": "video"
    }
  ],
  "total": 1
}
```

还可使用 `created_at_min`、`created_at_max`、`offset` 与 `limit` 分页筛选任务。任务查询免费，不会重复扣费。
