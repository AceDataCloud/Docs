通过 `POST https://api.acedata.cloud/minimax/tasks` 查询、批量查询或删除由 `/minimax/videos` 创建的任务记录。任务查询免费，不会重复扣费。

## 查询单个任务

```bash
curl -X POST 'https://api.acedata.cloud/minimax/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"YOUR_TASK_ID"}'
```

`action` 默认值为 `retrieve`，因此也可以只传 `id`。

## 批量查询

```json
{
  "action": "retrieve_batch",
  "ids": ["TASK_ID_1", "TASK_ID_2"]
}
```

批量结果包含 `items` 和 `count`。也可以使用 `trace_ids`、`application_id`、`created_at_min`、`created_at_max`、`offset` 与 `limit` 筛选自己的任务。

## 删除任务记录

```json
{
  "action": "delete",
  "id": "YOUR_TASK_ID"
}
```

删除只影响 AceDataCloud 保存的任务记录，不会撤回已经执行的生成任务或删除已下载的视频。
