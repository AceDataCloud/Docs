Claude Code 是 Anthropic 推出的编程智能体，可以在终端、IDE 以及 CI/CD 流水线等多种环境中使用。通过 AceData Cloud 代理，你可以以更低的价格使用 Claude Code。

按使用场景选择对应平台的完整配置教程：

| 平台 | 说明 | 教程链接 |
|------|------|---------|
| **VS Code** | 原生扩展，支持内联 Diff、@-mentions、计划审查 | [VS Code 配置教程](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | VS Code 兼容编辑器，Claude Code 扩展完全支持 | [Cursor 配置教程](https://platform.acedata.cloud/documents/development_cursor_coding) |
| **终端 (CLI)** | 核心体验，在任意终端运行 `claude` 即可开始 | [终端配置教程](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **JetBrains IDE** | 支持 IntelliJ IDEA、PyCharm、WebStorm 等全系 IDE | [JetBrains 配置教程](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | 用 `@claude` 自动化代码审查和 Issue 处理 | [GitHub Actions 配置教程](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **提示**：首次申请可前往 [Claude Messages 服务页面](https://platform.acedata.cloud/documents/claude-messages) 点击「Acquire」获取凭证，即赠免费额度。
