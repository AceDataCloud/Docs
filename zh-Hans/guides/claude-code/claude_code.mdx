Claude Code 可通过五条独立路线接入 Coding Plan。每条路线固定使用 Anthropic Messages，并独立维护配置与 evidence。

| 接入方案 | 指南 | 状态 |
|---|---|---|
| Terminal / CLI | [配置](https://platform.acedata.cloud/documents/claude-code-terminal-integration) | 待最终复验 |
| VS Code | [配置](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) | 待最终复验 |
| JetBrains | [配置](https://platform.acedata.cloud/documents/claude-code-jetbrains-integration) | 待最终复验 |
| CC Switch | [配置](https://platform.acedata.cloud/documents/claude-code-cc-switch-integration) | 待最终复验 |
| GitHub Actions | [配置](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) | 历史实测，待最终字节复验 |

Claude Code Native App是独立产品形态，当前没有足够证据证明它与CLI/IDE读取相同配置，因此选择器只展示限制说明，不复用上述profile。

## 共通边界

- Base URL：`https://api.acedata.cloud`
- 认证由每条指南定义，不能混用`ANTHROPIC_API_KEY`与`ANTHROPIC_AUTH_TOKEN`路径。
- Model ID必须来自具体profile和实时模型目录的交集。
- 配置修改后按指南重启CLI、IDE或workflow。

指南存在不代表最终profile已验证。只有当前客户端版本、最终渲染字节、工具调用、ApiUsage与Coding余额都核对后，选择器才提供模型和复制按钮。
