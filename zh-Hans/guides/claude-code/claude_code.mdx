Claude Code 通过 Anthropic Messages 协议接入 Coding Plan，当前提供终端与 VS Code 两种配置入口。

| 使用入口 | 配置指南 |
|---|---|
| Terminal / CLI | [Claude Code 终端配置](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| VS Code | [Claude Code for VS Code 配置](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## 共通配置

- Base URL：`https://api.acedata.cloud`
- API Token：从 Coding Application 获取，并通过指南中的 `ANTHROPIC_AUTH_TOKEN` 配置
- Model ID：从实时模型目录选择
- 修改配置后：重新启动 Claude Code；VS Code 用户需要重载窗口

不要同时保留旧的 `ANTHROPIC_API_KEY`，也不要把真实 Token 写入团队共享文件。

返回 [Coding Plan 配置中心](https://platform.acedata.cloud/documents/coding-plan-integration)。
