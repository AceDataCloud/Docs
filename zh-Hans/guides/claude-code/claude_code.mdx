Claude Code 是 Anthropic 推出的编程智能体（Agentic Coding 工具），可以在终端、各类 IDE 以及 GitHub Actions 等 CI/CD 流水线中使用。通过 AceData Cloud 代理，你可以用更低的价格、无需 Anthropic 官方订阅来使用 Claude Code，而且一把 API Token 即可调用平台上的所有服务。

## 按平台选择配置教程

根据你的使用场景，选择对应平台的完整配置教程：

| 平台 | 说明 | 教程链接 |
|------|------|---------|
| **终端 (CLI)** | 核心体验，在任意终端运行 `claude` 即可开始 | [终端配置教程](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code** | 原生扩展，支持内联 Diff、@-mentions、计划审查 | [VS Code 配置教程](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | VS Code 兼容编辑器，Claude Code 扩展完全支持 | [Cursor 配置教程](https://platform.acedata.cloud/documents/development_cursor_coding) |
| **GitHub Actions** | 在 Issue / PR 中 `@claude` 自动化代码审查与处理 | [GitHub Actions 配置教程](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

## 通用配置

无论使用哪个平台，核心都是把 Claude Code 的两个环境变量指向 AceData Cloud：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="{token}"
```

其中 `{token}` 为你在 [控制台](https://platform.acedata.cloud/console/applications) 获取的 API Token；各平台的具体写法（环境变量或 `.claude/settings.local.json` 等）详见上方对应教程。

> **提示**：首次申请可前往 [Claude Messages 服务页面](https://platform.acedata.cloud/documents/claude-messages) 点击「Acquire」获取凭证，即赠免费额度；额度不足时可在 [控制台](https://platform.acedata.cloud/console/coin) 充值通用余额。
