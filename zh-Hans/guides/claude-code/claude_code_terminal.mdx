Claude Code 是 Anthropic 推出的编程 Agent。除了 VS Code 扩展，它也提供了终端 CLI，你可以在任意项目目录中运行 `claude`，让它阅读代码、修改文件、运行命令、解释错误并协助完成开发任务。

本文介绍如何通过 Ace Data Cloud 的 Claude Code 代理服务，在本地终端中安装、配置和使用 Claude Code CLI。配置完成后，Claude Code 会把请求发送到 `https://api.acedata.cloud`，无需单独订阅 Anthropic 官方账号。

## 申请流程

要使用 Claude Code，首先可以到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications)，获取您的 API Token，留作备用。

![](https://cdn.acedata.cloud/5hmkdg.jpg)

如果你尚未登录或注册，会自动跳转到登录页面邀请您来注册和登录，登录注册之后会自动返回当前页面。

在首次申请时会有免费额度赠送，可以免费体验 Claude Code 服务。

## 安装 Claude Code

Claude Code 支持 macOS、Linux、Windows 和 WSL。你可以使用官方原生安装方式，也可以通过 npm 安装。

### 原生安装（推荐）

官方原生安装方式会安装 `claude` 命令，并自动处理后续更新。

macOS、Linux、WSL 可以运行：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell 可以运行：

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows CMD 可以运行：

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

### npm 安装

如果你已经安装了 Node.js，也可以通过 npm 安装 Claude Code。该方式要求 Node.js 18 或更高版本。

```bash
npm install -g @anthropic-ai/claude-code
```

### 检查安装

安装完成后，重新打开终端，然后检查命令是否可用：

```bash
claude --version
```

如果提示 `command not found`，通常是当前终端还没有加载新的 PATH。请关闭并重新打开终端，或检查安装脚本输出中提示的 PATH 配置。

## 配置

安装完成后，Claude Code 默认会尝试连接 Anthropic 官方服务。要改用 Ace Data Cloud，需要配置 Claude Code 使用我们的代理地址和您刚才获取的 API Token。

### 方式一：Shell 配置文件

推荐把配置写入 Shell 配置文件，例如 `~/.zshrc`、`~/.bashrc` 或 `~/.bash_profile`：

```bash
export ACEDATACLOUD_API_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="$ACEDATACLOUD_API_TOKEN"
```

其中 `{token}` 替换为您在 Ace Data Cloud 控制台复制的 API Token。

配置后重新打开终端，或执行对应的 `source` 命令让配置立即生效：

```bash
source ~/.zshrc
```

这种方式适合希望所有项目都默认使用 Ace Data Cloud 的场景。

### 方式二：项目 Settings 文件

如果你只想让某一个项目使用 Ace Data Cloud，也可以在项目根目录创建 `.claude/settings.local.json`：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

如果当前 Shell 或系统环境里已经设置了旧的 `ANTHROPIC_API_KEY`，请先在启动 Claude Code / VS Code 的同一个环境中取消它：

```bash
unset ANTHROPIC_API_KEY
```

不要把真实 Token 放进团队共享的 `.claude/settings.json`；个人凭据只放在已忽略的 `.claude/settings.local.json` 或本机环境变量中。

这种方式只对当前项目生效。它同时适用于终端 CLI 和 Claude Code 的 VS Code 扩展：你在 VS Code 中打开同一个项目后，扩展也会读取这份项目级配置。

建议把 `.claude/settings.local.json` 加入 `.gitignore`，避免把个人 Token 提交到远程仓库。配置完成后，请重新打开终端；如果是在 VS Code 中使用，也请重启或重新加载 VS Code。

> 注意：如果存在旧的 `ANTHROPIC_API_KEY`，应真正 `unset`，而不是把空字符串写入配置。清理后需要重新启动 Claude Code；VS Code 扩展还要完全重载窗口。

### 清理已缓存的 Anthropic 登录

如果你之前已经用 Anthropic 官方账号登录过 Claude Code，本地可能缓存了官方登录状态。切换到 Ace Data Cloud 代理前，建议先清理一次旧登录。

启动 Claude Code：

```bash
claude
```

在 Claude Code 交互界面中输入：

```text
/logout
```

退出 Claude Code 后重新打开终端，再次运行 `claude`。如果你从未登录过 Anthropic 官方账号，可以跳过这一步。

### 启动会话

进入你的项目目录，然后启动 Claude Code：

```bash
cd /path/to/your/project
claude
```

看到 Claude Code 的交互界面后，就可以直接输入需求，例如：

```text
解释这个项目的目录结构
```

也可以用一次性命令让 Claude Code 完成单个任务：

```bash
claude "帮我检查最近的 git diff，找出可能的 bug"
```

如果希望 Claude Code 输出结果后直接退出，可以使用 `-p`：

```bash
claude -p "总结 README.md 的作用"
```

### 验证配置

进入 Claude Code 后，可以输入 `/status` 检查当前连接配置：

```text
/status
```

你应该能看到类似信息：

```text
Auth token: ANTHROPIC_AUTH_TOKEN
Anthropic base URL: https://api.acedata.cloud
```

如图所示：

![](https://cdn.acedata.cloud/zwv76c.jpg)

如果 `Anthropic base URL` 不是 `https://api.acedata.cloud`，说明当前终端没有读取到正确配置。请检查 Shell 配置文件是否保存成功，并重新打开终端。

你也可以通过 [Ace Data Cloud 控制台 - 使用历史](https://platform.acedata.cloud/console/usages) 查看请求记录和扣费详情，通过 [Ace Data Cloud 控制台 - 应用列表](https://platform.acedata.cloud/console/applications) 查看剩余额度。

## 工作原理

Claude Code 原生使用 Anthropic Messages API 协议。Ace Data Cloud 在 `https://api.acedata.cloud` 提供兼容 Anthropic API 的代理服务，因此 Claude Code 不需要本地代理程序，也不需要额外插件。

工作流程如下：

1. Claude Code 从环境变量或 `.claude/settings.local.json` 读取 `ANTHROPIC_BASE_URL` 和 `ANTHROPIC_AUTH_TOKEN`。
2. 当 `ANTHROPIC_BASE_URL` 指向 `https://api.acedata.cloud` 时，请求会直接发送到 Ace Data Cloud。
3. Ace Data Cloud 使用您的 API Token 验证身份、检查额度，并把请求转发到可用的 Claude Code 服务通道。
4. 请求完成后，平台根据实际使用量记录用量并扣减额度。

这意味着你仍然使用原版 `claude` 命令和 Claude Code 的原生交互体验，只是把底层 API 服务切换为 Ace Data Cloud。

## 配置模型

Claude Code 会根据任务类型选择不同级别的模型。你也可以通过环境变量指定默认模型。

例如，可以在 Shell 配置文件中加入：

```bash
export ANTHROPIC_DEFAULT_OPUS_MODEL="claude-opus-4-8"
export ANTHROPIC_DEFAULT_SONNET_MODEL="claude-sonnet-4-6"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="claude-haiku-4-5-20251001"
export CLAUDE_CODE_SUBAGENT_MODEL="claude-sonnet-4-6"
```

常用变量说明如下：

| 变量 | 作用 |
| --- | --- |
| `ANTHROPIC_DEFAULT_OPUS_MODEL` | 用于复杂推理、规划和高难度编码任务的模型 |
| `ANTHROPIC_DEFAULT_SONNET_MODEL` | 用于日常编码、阅读代码和常规修改任务的模型 |
| `ANTHROPIC_DEFAULT_HAIKU_MODEL` | 用于较快、较轻量任务的模型 |
| `CLAUDE_CODE_SUBAGENT_MODEL` | Claude Code 创建子 Agent 时使用的模型 |

如果不确定该怎么选，可以先不配置这些模型变量，直接使用 Claude Code 默认选择。后续如果你希望固定使用某个模型，再根据 [Ace Data Cloud Claude 服务文档](https://platform.acedata.cloud/documents/claude-messages) 中支持的模型名称进行配置。

> 注意：Claude Code 对 Claude 系列模型兼容性最好。建议优先使用 Ace Data Cloud 提供的 Claude 模型，不建议随意切换到非 Claude 模型。
