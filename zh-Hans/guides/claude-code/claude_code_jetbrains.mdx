Claude Code 通过官方 JetBrains 插件与 IntelliJ IDEA、PyCharm、Android Studio、WebStorm、PhpStorm、GoLand 等 IDE 集成。插件本身不包含 Claude Code CLI；它会在 IDE 集成终端中运行本机的 `claude` 命令，因此必须先安装 CLI。

> 本文的插件安装、快捷键、`/ide`、Claude command、Remote Development 与 WSL 行为均按 [Claude Code 官方 JetBrains 文档](https://code.claude.com/docs/en/jetbrains) 核对。Ace Data Cloud 相关内容仅说明 API 地址和凭据配置。

## 1. 获取 Ace Data Cloud Token

在 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 打开 Coding Application，创建或复制该应用的 API Token。不要把 Token 放进截图、聊天记录或 Git 仓库。

## 2. 安装 Claude Code CLI

macOS、Linux 或 WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
```

重新打开终端并验证：

```bash
claude --version
```

## 3. 安装官方 JetBrains 插件

可任选一种官方方式：

### 方法 A：Marketplace

1. 打开 **Settings / Preferences → Plugins → Marketplace**。
2. 搜索并安装 **Claude Code** 插件。
3. 完全重启 IDE。

![Claude Code Plugin in JetBrains Marketplace](https://cdn.acedata.cloud/de78fd305b.png)

### 方法 B：从 Claude Code 自动安装

在 IDE 项目目录的终端中运行：

```bash
claude
```

进入 Claude Code 后执行：

```text
/ide
```

如果 Claude Code 检测到正在运行但尚未安装插件的 JetBrains IDE，`/ide` 会安装插件并提示重启 IDE。

插件找不到 `claude` 时，在插件设置的 **Claude command** 中填写可执行文件的完整路径。可先运行以下命令定位：

```bash
which claude
```

## 4. 配置 Ace Data Cloud

Claude Code 官方 Settings 的 `env` 字段接受环境变量的**具体字符串值**；官方文档没有说明它会展开 `${NAME}`。因此不要把 `${ACEDATACLOUD_API_KEY}` 写进 `settings.json` 并假设会自动替换。

推荐把凭据设在启动 IDE 的本机环境中。

macOS / Linux / WSL：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="你的 Ace Data Cloud API Token"
```

Windows PowerShell：

```powershell
$env:ANTHROPIC_BASE_URL="https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN="你的 Ace Data Cloud API Token"
```

必须从同一个已配置环境启动 JetBrains IDE，或把变量加入你实际用于启动 IDE 的本机用户环境。配置后完全退出并重新打开 IDE。

如果你选择把值写入 Claude Code Settings，只能写入本机私有的 `~/.claude/settings.json` 或已被 Git 忽略的 `.claude/settings.local.json`，并在本机把占位符替换为真实 Token：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "在本机替换为真实 Token"
  }
}
```

不要把真实 Token 写进团队共享并提交到 Git 的 `.claude/settings.json`。

如果同一启动环境中存在旧 `ANTHROPIC_API_KEY`，请先取消它：

```bash
unset ANTHROPIC_API_KEY
```

## 5. 使用与验证

从 IDE 集成终端运行 `claude` 时，插件会自动启用 IDE 集成功能。也可以从项目根目录的外部终端启动 Claude Code，再执行 `/ide` 连接当前 IDE：

```bash
cd /path/to/project
claude
```

```text
/ide
```

连接成功后 Claude Code 会显示类似 `Connected to IntelliJ IDEA` 的提示。

先做最小连接验证：

```bash
claude -p "Reply only OK"
```

再从 IDE 中发起一个只读任务，例如：

```text
解释当前项目的目录结构，不要修改文件。
```

官方插件支持的主要能力包括 IDE diff viewer、当前选择/标签页上下文、文件行号引用和诊断信息共享。常用快捷键：

- macOS：`Cmd+Esc` 快速打开；`Cmd+Option+K` 插入文件引用。
- Windows/Linux：`Ctrl+Esc` 快速打开；`Alt+Ctrl+K` 插入文件引用。

## 6. Remote Development 与 WSL

- JetBrains Remote Development 必须在**远程主机**安装插件：**Settings → Plugin (Host)**。
- 远程环境中的 Claude Code CLI、API 环境变量和项目路径也必须配置在远程主机，而不是本地 UI 机器。
- WSL2 下 IDE 与 Claude Code 的发现依赖 Windows/WSL 网络连通；若 `/ide` 无法检测 IDE，请按 [Claude Code 官方 JetBrains WSL 排错](https://code.claude.com/docs/en/jetbrains#wsl-configuration) 检查防火墙或 mirrored networking。
- 不要把浏览器或本机 Windows 的 OS 自动当成远程项目的执行环境。

## 常见问题

### Cannot launch Claude Code / command not found

插件不附带 CLI。先确认 `claude --version` 成功；若 IDE 的 PATH 不同，在 **Claude command** 中填写 `which claude` 返回的完整路径，然后重启 IDE。

### IDE not detected

确认官方插件已启用，Claude Code 从同一个项目根目录启动，并在会话中重新执行 `/ide`。Remote Development 时确认插件安装在 Host 侧。

### 返回 401

确认 Token 属于可用的 Coding Application，IDE 进程确实继承了 `ANTHROPIC_AUTH_TOKEN`，且没有残留旧的 `ANTHROPIC_API_KEY`。

### 模型不可用

模型目录会持续更新。以 Coding 配置选择器和实时模型目录中的 exact model ID 与验证状态为准，不依赖教程中的静态模型清单。
