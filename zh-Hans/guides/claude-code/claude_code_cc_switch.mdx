[Claude Code](https://platform.acedata.cloud/documents/claude-code-integration) 原生通过 `ANTHROPIC_BASE_URL` 与 `ANTHROPIC_AUTH_TOKEN` 两个环境变量决定请求发往哪里，把它们指向 Ace Data Cloud 即可用更低的价格、无需 Anthropic 官方订阅来使用 Claude Code。手动编辑 `.claude/settings.json` 对新手并不友好，而 [CC Switch](https://github.com/farion1231/cc-switch) 提供了一个图形界面，帮你把这两个变量一键写好、并在多套供应商之间即时切换。

本文介绍如何用 CC Switch 把 Claude Code 接入 Ace Data Cloud。

## 什么是 CC Switch

CC Switch（官网 [ccswitch.io](https://ccswitch.io/)）是一个开源、跨平台的桌面端配置管理器，用于统一管理 Claude Code、Claude Desktop、Codex、Gemini CLI、OpenCode、OpenClaw、Hermes 等多个 AI 编程工具的供应商配置。它基于 [Tauri 2](https://tauri.app/) 构建，采用 MIT 协议开源，在 GitHub 上已获得超过 11 万 Star（参见 [farion1231/cc-switch](https://github.com/farion1231/cc-switch)）。

它的核心价值在于（详见官方 [User Manual](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/en/README.md)）：

- **免手动改配置**：不用再手写 `settings.json` / `config.toml` / `.env`，图形界面填一次即可。
- **一键切换**：预存多套供应商，从主界面或系统托盘即时切换。
- **原子写入**：所有数据存于本地 SQLite 数据库（`~/.cc-switch/cc-switch.db`），采用「临时文件 + 重命名」的原子写入，避免配置损坏。

> CC Switch 的工作原理是在底层动态覆盖 Claude Code 的 `ANTHROPIC_BASE_URL` 和 `ANTHROPIC_AUTH_TOKEN`，把原本发往 Anthropic 官方的请求重定向到你配置的第三方接口（本例即 Ace Data Cloud）。这一机制在社区的[图文教程](https://github.com/Golden-Promise/vscode-cc-switch)中也有详细说明。

## 申请 API Token

要使用 Claude Code，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications)，获取你的 API Token，留作备用。

![](https://cdn.acedata.cloud/5hmkdg.jpg)

如果你尚未登录或注册，会自动跳转到登录页面邀请你注册和登录，登录注册之后会自动返回当前页面。首次申请时会有免费额度赠送，可以免费体验 Claude Code 服务。

> **提示**：也可以前往 [Claude Messages 服务页面](https://platform.acedata.cloud/documents/claude-messages) 点击「Acquire」获取凭证，即赠免费额度；额度不足时可在 [控制台 - 通用余额](https://platform.acedata.cloud/console/coin) 充值。

## 下载与安装 CC Switch

前往 CC Switch 的 [Releases 页面](https://github.com/farion1231/cc-switch/releases)（或直接下载[最新版本](https://github.com/farion1231/cc-switch/releases/latest)），按操作系统选择对应安装包。以下安装方式均来自官方 [README](https://github.com/farion1231/cc-switch#download--installation)：

| 操作系统 | 系统要求 | 安装方式 |
|------|------|------|
| **Windows** | Windows 10 及以上 | 下载 `CC-Switch-v{version}-Windows.msi` 安装版，或 `-Windows-Portable.zip` 便携版 |
| **macOS** | macOS 12 (Monterey) 及以上 | 推荐 `brew install --cask cc-switch`，或下载 `.dmg`（已由 Apple 签名与公证，可直接打开） |
| **Linux** | Ubuntu 22.04+ / Debian 11+ / Fedora 34+ | 下载 `.deb` / `.rpm` / `.AppImage`；Arch 用户可 `paru -S cc-switch-bin` |

安装完成后启动 CC Switch，准备添加供应商。

> 首次启动时，CC Switch 可以把你已有的 CLI 配置导入为默认供应商（参见官方 [Quick Start](https://github.com/farion1231/cc-switch#quick-start)），避免覆盖原有配置。

## 添加 Ace Data Cloud 供应商

CC Switch 内置了 50+ 供应商预设，但目前不含 Ace Data Cloud，因此我们使用「Custom（自定义）」方式添加。以下步骤对应官方文档 [2.1 Add Provider](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/en/2-providers/2.1-add.md)。

1. 在 CC Switch 顶部切换到 **Claude Code** 应用。
2. 点击右上角的 **+**（Add Provider）按钮打开添加面板，在 **App-specific Provider** 标签下操作。
3. 在预设下拉框中选择 **Custom**，然后填写配置。

CC Switch 官方「添加供应商」面板如下（截图来自 [CC Switch 官方仓库](https://github.com/farion1231/cc-switch#screenshots)）：

![CC Switch 添加供应商面板](https://raw.githubusercontent.com/farion1231/cc-switch/main/assets/screenshots/add-en.png)

按如下信息填写：

| 字段 | 填写内容 |
|------|------|
| 名称（Name） | `Ace Data Cloud`（可自定义） |
| 接口地址（Base URL） | `https://api.acedata.cloud` |
| 密钥（API Key / Token） | 你在控制台复制的 API Token |

选择 Custom 后，也可以直接在 JSON 编辑框中填入 Claude 配置。Ace Data Cloud 提供原生兼容 Anthropic Messages API 的代理，因此使用默认的 `ANTHROPIC_*` 环境变量即可（配置格式参见官方 [Claude Configuration Format](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/en/2-providers/2.1-add.md#custom-configuration)）：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "CLAUDE_CODE_AUTO_COMPACT_WINDOW": "850000"
  }
}
```

其中 `{token}` 替换为你在 Ace Data Cloud 控制台复制的 API Token。`CLAUDE_CODE_AUTO_COMPACT_WINDOW` 将自动压缩的触发窗口设为约 85 万 token，为工具结果和最终回答预留空间，并不会修改模型的上下文上限。核对无误后点击 **Add** 完成添加。

> **API 格式（Advanced Options）**：Ace Data Cloud 使用原生 Anthropic Messages 协议，因此高级选项中的 **API Format** 保持默认的 **Anthropic Messages** 即可，无需开启本地路由或格式转换。

## 启用并切换供应商

添加完成后，在 Claude Code 供应商列表中找到 **Ace Data Cloud** 卡片，点击 **Enable（启用）** 即可（参见官方 [2.2 Switch Provider](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/en/2-providers/2.2-switch.md)）。你也可以从系统托盘菜单直接点击供应商名称进行即时切换，无需打开完整界面。

> **是否需要重启？** 根据官方 [FAQ](https://github.com/farion1231/cc-switch#faq)，Claude Code 支持「热切换」——切换供应商后无需重启即可生效；其余大多数工具（如 Codex、Gemini CLI）则需要重启对应 CLI 或终端。

CC Switch 启用供应商时，会把上面的配置写入 Claude Code 的配置文件（用户级 `~/.claude/settings.json`）。因此，无论你在终端里运行 `claude`，还是使用 VS Code 的 Claude Code 扩展，都会读取到同一份配置。配置文件的位置与格式参见官方 [5.1 配置文件说明](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/en/5-faq/5.1-config-files.md)。

## 在终端与 VS Code 中使用

CC Switch 只负责写入配置，Claude Code 本体仍需单独安装。启用供应商后：

- **终端 CLI**：安装并运行 `claude` 即可，完整步骤见 [Claude Code 终端配置教程](https://platform.acedata.cloud/documents/claude-code-terminal-integration)。进入交互界面后输入 `/status`，应能看到 `Anthropic base URL: https://api.acedata.cloud`。

  ![](https://cdn.acedata.cloud/zwv76c.jpg)

- **VS Code 扩展**：在扩展市场安装 Claude Code 扩展，完整步骤见 [Claude Code VS Code 配置教程](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)。由于扩展和 CLI 共享同一份配置，CC Switch 写好后 VS Code 扩展会直接复用，无需再手动填写。
- **GitHub Actions**：如果你想在 CI/CD 中使用，参见 [Claude Code GitHub Actions 配置教程](https://platform.acedata.cloud/documents/claude-code-github-actions-integration)（该场景通过 Secrets 注入变量，通常不使用 CC Switch）。

## 远程开发（Remote - SSH）

如果你通过 VS Code Remote - SSH 在远程服务器上开发，远程端读不到你本机的环境变量。此时可以借助 CC Switch 的**本地代理（Local Proxy）**功能：在 CC Switch 中开启本地代理后，它会在本机监听一个端口并转发请求；再通过 SSH 的 `RemoteForward` 把该端口转发到远程主机，远程的 Claude Code 即可复用本地供应商。本地代理的配置说明见官方 [4.1 Proxy Service](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/en/4-proxy/4.1-service.md)，Remote - SSH 的完整图文步骤可参考社区教程 [Golden-Promise/vscode-cc-switch](https://github.com/Golden-Promise/vscode-cc-switch#%EF%B8%8F-%E5%9B%9B%E9%80%9A%E8%BF%87-cc-switch-%E8%B0%83%E7%94%A8%E7%AC%AC%E4%B8%89%E6%96%B9%E6%A8%A1%E5%9E%8B)。

## 常见问题

- **为什么无法删除当前正在使用的供应商？** CC Switch 遵循「最小侵入」原则，始终保留一个已启用配置，避免删除全部配置后 CLI 工具无法使用。详见官方 [FAQ](https://github.com/farion1231/cc-switch#faq)。
- **如何切回官方登录？** 从预设列表添加一个官方登录（Official Login）供应商，切换后按照官方登录 / OAuth 流程操作即可（参见官方 [Quick Start](https://github.com/farion1231/cc-switch#quick-start)）。
- **配置数据存在哪里？** 供应商、MCP、Prompts、Skills 等数据存于 `~/.cc-switch/cc-switch.db`（SQLite），设备级 UI 偏好存于 `~/.cc-switch/settings.json`，自动备份位于 `~/.cc-switch/backups/`（参见官方 [FAQ](https://github.com/farion1231/cc-switch#faq)）。
