MiMo 2.6 Pro 和 MiMo 2.6 Flash 是小米 MiMo 系列模型。本接口使用 OpenAI Chat Completions 格式，按输入、输出和缓存命中 token 计费。

## 模型与接口

| 模型 | 定位 |
| --- | --- |
| `mimo-v2.6-pro` | 复杂分析、推理与工具调用 |
| `mimo-v2.6-flash` | 日常对话与轻量任务 |

开通 MiMo 并获取对应的 API 凭据，向 `https://api.acedata.cloud/mimo/chat/completions` 发送请求。OpenAI SDK 的 `base_url` 可设为 `https://api.acedata.cloud/mimo`。统一 `/v1/chat/completions` 入口同样需要相应的服务权限。

首批接口范围为文本 Chat Completions；图像、音频、视频、联网搜索、Responses、Messages、Batch 与 UltraSpeed 不在本次发布范围内。

## Python 示例

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ACEDATACLOUD_API_KEY"],
    base_url="https://api.acedata.cloud/mimo",
)
response = client.chat.completions.create(
    model="mimo-v2.6-pro",
    messages=[{"role": "user", "content": "解释彩虹形成的原因。"}],
    max_completion_tokens=256,
    extra_body={"thinking": {"type": "disabled"}},
)
print(response.choices[0].message.content)
print(response.usage)
```

示例展示请求写法；真实响应示例将在服务验证后补充。

## 流式、推理与工具调用

设置 `stream=true` 接收 SSE；如需最终用量，传入 `stream_options={"include_usage": true}`。客户端应处理内容、推理内容和工具调用增量，以及最终 usage 事件。

使用 `thinking.type=enabled` 开启推理，`disabled` 关闭。`reasoning_content` 与最终 `content` 分开返回；续接工具调用时保留助手消息中的推理内容、完整 `tool_calls` 和对应的 `tool_call_id`。

仅提交 `type=function` 的工具声明，`tool_choice` 仅支持 `auto`。应用负责执行工具并回传结果；模型返回工具调用本身不代表工具已执行。服务内置联网搜索尚未开放。

## 计费

`prompt_tokens` 包含缓存命中的输入；`prompt_tokens_details.cached_tokens` 按缓存价格计算，其余输入按普通输入价格计算。`completion_tokens` 包含推理输出，请勿重复累加推理 token。流式调用也按最终实际用量结算。

价格以控制台为准，Credit 的美元成本取决于购买套餐。失败请求不应被视为成功完成；如需核对扣费，请提供响应中的追踪标识。

## 错误处理

参数错误请检查请求格式；鉴权或权限错误请检查凭据与服务开通情况；遇到 429 请退避重试。无健康模型容量时可能返回 503。流式响应开始后发生中断时，先检查已接收结果与用量，避免盲目重复请求。
