title: "OpenCode IDE Extension 接入 Ace Data Cloud"
description: "Platform 集成指南 - Ace Data Cloud"
---

OpenCode 官方 IDE Extension 支持 VS Code、Cursor、Windsurf、VSCodium 等编辑器，并复用 OpenCode 本地 runtime 与 Provider 配置。IDE 扩展复用本地 CLI Provider，但不同编辑器版本的请求链可能变化；首次接入请固定版本并完成最小验证。

## 配置 Provider

先按 [OpenCode Terminal 配置](https://platform.acedata.cloud/documents/opencode-terminal-integration) 在 `opencode.json` 或 `opencode.jsonc` 中配置 Ace Data Cloud Provider：

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## 安装 IDE Extension

1. 在编辑器的集成终端中运行 `opencode`，按官方流程自动安装 Extension；也可以从对应 Marketplace 手动安装。
2. Reload 编辑器。
3. 从 OpenCode Extension 发起 `Reply only OK`。
4. 再执行一次需要读取文件或修改代码的请求，确认 IDE Extension 使用同一 Provider 与模型。

## 当前边界

- Provider 能力来自 OpenCode runtime，不代表宿主编辑器原生支持 Ace Data Cloud。
- VS Code 与各 fork 的扩展版本可能不同，应分别记录版本。
- 普通聊天成功不能替代文件读取、编辑和工具调用验证。
