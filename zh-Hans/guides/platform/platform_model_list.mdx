返回平台公开的模型目录，响应采用 OpenAI 风格的 `{ "object": "list", "data": [...] }` 结构。该目录用于模型选择和能力发现，不代表当前账户一定已经申请了对应服务。

## 接口概览

| 项 | 内容 |
| --- | --- |
| 方法 | `GET` |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| 鉴权 | 公开，无需账户令牌 |
| 分页 | 不分页，全部匹配项位于 `data` |

## 查询参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `owned_by` | string | 否 | 按目录中的模型提供方标识精确筛选 |
| `type` | string | 否 | 按模型类型精确筛选，例如 `chat` |
| `capability` | string | 否 | 仅返回 `capabilities` 包含该能力的模型，例如 `vision` |
| `with_pricing` | boolean | 否 | `1`、`true` 或 `yes` 时附加公开价格信息 |

`service_id`、`tag`、`limit`、`offset` 和 `ordering` 当前不受支持；传入后不会产生相应筛选或分页效果。

## 请求示例

```shell
# 全部公开模型
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# 支持视觉的 chat 模型，并附价格
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## 真实响应结构

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

`pricing` 和顶层 `credit_usd_rate` 仅在 `with_pricing=true` 时出现；并非每个模型都有可计算的 `pricing`。模型对象以 `config/models.json` 的公开字段为准，客户端应忽略新增字段。

> 价格字段是目录展示数据。实际业务调用仍以对应 API/Service 的计费规则和最终用量记录为准。
