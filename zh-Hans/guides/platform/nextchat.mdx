[NextChat](https://github.com/ChatGPTNextWeb/NextChat)（前身 ChatGPT-Next-Web）是开源 AI 客户端，可在 Vercel、Cloudflare 或 Docker 上部署。它支持自定义 OpenAI 兼容端点，因此可以接入 Ace Data Cloud。本文介绍配置流程。

## 申请流程

要在 NextChat 中接入 Ace Data Cloud，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications)，获取您的 API Token，留作备用。

![获取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

如果你尚未登录或注册，会自动跳转到登录页面邀请您来注册和登录，登录注册之后会自动返回当前页面。

在首次申请时会有免费额度赠送，可以免费体验 Ace Data Cloud 的模型服务。

## 下载 NextChat

可以使用桌面版（[Releases 页](https://github.com/ChatGPTNextWeb/NextChat/releases) 下载 `.exe` / `.dmg` / AppImage）、[Web 在线版](https://app.nextchat.club/)，或自行部署到 Vercel / Cloudflare / Docker（见下文进阶章节）。

## 配置 Ace Data Cloud

启动 NextChat，进入 **设置 → 模型服务**：

| 字段 | 值 | 说明 |
| --- | --- | --- |
| 模型服务商 | `OpenAI` | 使用 OpenAI 兼容协议 |
| OpenAI 接口地址 | `https://api.acedata.cloud` | 只填根域名，**不带 `/openai`、不带 `/v1`** |
| API Key | 你的 Ace Data Cloud Token | 控制台复制的 Token |

![NextChat Ace Data Cloud 配置界面](https://cdn.acedata.cloud/47e0aed34570.png)


NextChat 会自动在接口地址后拼接 `/v1/chat/completions`，因此只填根域名即可：

| 接口地址 | 实际请求 | 结果 |
| --- | --- | --- |
| `https://api.acedata.cloud` | `https://api.acedata.cloud/v1/chat/completions` | 正确 |
| `https://api.acedata.cloud/openai` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404（`/openai` 下没有 `/v1`） |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404 |

在「自定义模型名」框里用英文逗号分隔填写模型。NextChat 支持特殊语法：`+模型名` 添加、`-模型名` 隐藏、`模型名=显示名` 自定义显示名、`-all` 先全部隐藏。推荐最干净的写法：

```text
-all,+MODEL_ID=显示名称
```

## 选择模型

模型目录会持续更新。优先使用客户端自动加载的模型列表；需要手动填写时，先请求 `GET https://api.acedata.cloud/v1/models` 获取当前模型 ID，再按客户端支持的上下文、图片和工具调用能力选择。

## 验证对接

如果不确定问题出在 NextChat 还是网络，可以先用 curl 直接验证端点（把 `{token}` 替换为你的 Token）：

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

返回 OpenAI 兼容的 `chat.completion` 对象即说明 Token 与端点都已就绪；若返回 `HTTP 403 used_up` 则表示 Token 有效但余额不足，到 [控制台](https://platform.acedata.cloud/console/applications) 充值即可。

## 进阶：一键部署到自己的域名

NextChat 支持部署一个属于自己的 AI 网站。以 Docker 为例（把 `{token}` 替换为你的 Token）：

```bash
docker run -d \
  --name nextchat \
  -p 3000:3000 \
  -e OPENAI_API_KEY={token} \
  -e BASE_URL=https://api.acedata.cloud \
  -e CODE=your-password \
  -e CUSTOM_MODELS="-all,+MODEL_ID=显示名称" \
  yidadaa/chatgpt-next-web
```

Vercel / Cloudflare 部署时在项目的环境变量里配置相同的 `OPENAI_API_KEY`、`BASE_URL`、`CODE`、`CUSTOM_MODELS` 即可。`CODE` 支持英文逗号分隔多个访问密码，便于按人统计用量。以上环境变量的完整说明（`BASE_URL` 默认 `https://api.openai.com`、`CUSTOM_MODELS` 的 `+/-/=/-all/+all` 语法）请以 [NextChat 官方 README](https://github.com/ChatGPTNextWeb/NextChat#environment-variables) 为准。

## 常见问题

### 提示 404 Not Found

通常是接口地址写成了 `.../openai` 或 `.../openai/v1`。改成 `https://api.acedata.cloud`，让 NextChat 自己拼接 `/v1/chat/completions`。

### 模型下拉里没有添加的模型

检查 `CUSTOM_MODELS` 格式，每个模型前必须有 `+`；如果用了 `-all`，要确保后面用 `+` 重新加回需要的模型。

### 提示 401 Unauthorized

请确认 API Key 中粘贴的是 Ace Data Cloud 的 Token（不含 `Bearer` 前缀、无多余空格），且所属应用的余额充足。
