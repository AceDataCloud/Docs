Ace Data Cloud 提供 Hermes Agent 私有部署入口。该入口为受控服务，是否可用及可选资源以控制台当前显示为准。

## 使用步骤

1. 在平台找到 **Hermes Agent 私有部署**。
2. 按页面提示选择可用配置并创建服务。
3. 等待平台显示就绪状态。
4. 使用页面提供的入口和凭据访问实例。
5. 先发送 `Reply only OK`，再开始真实任务。

模型、凭据、存储和删除行为以创建页面及确认弹窗为准；不要把本地 Hermes 教程中的 YAML 直接当作平台部署合同。删除前先导出需要保留的数据。

如果控制台未显示创建入口，说明当前账户暂未开放该服务，可改用 [Hermes 交互向导](https://platform.acedata.cloud/documents/hermes-wizard-integration) 或 [手动配置](https://platform.acedata.cloud/documents/hermes-manual-integration)。
