为每个 Application 创建独立 Hermes 容器实例。默认使用固定发行版本的基础镜像，保留原生功能；平台提供购买、续费、持久化存储与部署管理。

## 创建与购买

1. 打开 [Hermes 部署](https://platform.acedata.cloud/services/hermes) 并创建 Application。
2. 在购买页选择时长套餐，完成付款。
3. 返回配置页，可从下拉列表选择平台聊天模型，并查看当前模型价格。平台会为这个实例创建独立 API 凭据；也可关闭平台接入，在原生控制台自行配置。
4. 选择自动生成访问凭据，或设置自己的强密码/Token，确认后开始部署。访问凭据与模型 API 凭据互相独立。
5. 实例就绪后，从管理页取得访问地址与登录凭据。
6. 登录原生控制台，配置自己的模型提供商、密钥和渠道。

部署费按套餐时长计费，具体美元价格、时长以购买页为准。模型调用费用另计；购买部署时长不会赠送模型额度。启用平台接入时，专用 API 凭据仅开放所选模型对应的聊天接口，调用从你的平台余额另外计费。每个 Application 分别购买、续费和管理。

## 密码、凭据与后续配置

访问凭据会在首次启动前设置。自动生成方式使用随机凭据，自定义密码至少 16 个字符，OpenClaw Token 至少 32 个字符。草稿不保存密码；切换页面后可能需要重新输入。部署后，只有 Application 所有者和管理员能查看访问凭据。

每个实例的模型 API 凭据互不复用，随部署续费延长有效期，删除实例时撤销。部署初始化后，请在原生控制台修改模型和渠道；如果改选其他服务的模型，请先在平台凭据管理中调整对应接口授权，或使用相应凭据。普通重新部署不会覆盖原生设置。未经发布验证的部署环境会暂时拒绝新部署，请联系支持。

## 版本与数据

配置页显示当前发布的镜像版本。新建实例使用服务当前发布版本；现有实例不会随目录更新自动替换。重新部署会应用当前服务版本，请先备份，确认所用版本的升级要求。

每个实例默认提供 1 CPU、2 GiB 内存上限和 10 GiB 持久化存储。重启保留实例数据。主动删除部署或到期回收会删除存储，请提前导出需要保留的数据。

## 续费与到期

在当前 Application 的购买页续费，有效期按平台现有时长规则延长。到期后访问入口暂停，宽限期内续费恢复访问；超过宽限期会回收实例与数据。以管理页的到期时间、计费状态及删除提示为准。

## 登录管理界面

在部署管理页复制 Dashboard 地址、用户名 `admin` 和密码，打开后登录。登录信息仅向该 Application 的所有者和平台管理员提供。模型、技能与渠道在 Hermes 原生界面中配置。

## 常见问题

- **为什么新实例还不能回答？** 部署完成表示容器就绪；需要在原生界面配置模型和凭据才能开始使用。
- **是否预装额外插件或模型 fallback？** 默认不添加，按需要在原生界面配置。
- **已有实例怎么更新？** 原有 Application 和订单保留，重新部署时使用当前服务版本；升级前先备份数据并检查版本兼容性。
- **启动失败怎么办？** 先查看部署日志与事件，确认实例就绪后再配置模型。不要在公开评论或截图中暴露实例密码和密钥。
