[LobeChat](https://lobehub.com/) 是支持插件、知识库和自部署的开源 AI 客户端，可使用在线版或 Docker 部署。它支持自定义 OpenAI 兼容端点，因此可以接入 Ace Data Cloud。本文介绍配置流程。

## 申请流程

要在 LobeChat 中接入 Ace Data Cloud，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications)，获取您的 API Token，留作备用。

![获取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

如果你尚未登录或注册，会自动跳转到登录页面邀请您来注册和登录，登录注册之后会自动返回当前页面。

在首次申请时会有免费额度赠送，可以免费体验 Ace Data Cloud 的模型服务。

## 配置 Ace Data Cloud

进入 LobeChat 的 **应用设置 → 语言模型**，找到 **OpenAI** 卡片并启用，填入：

| 字段 | 值 | 说明 |
| --- | --- | --- |
| API Key | 你的 Ace Data Cloud Token | 控制台复制的 Token |
| API 代理地址 | `https://api.acedata.cloud/v1` | **必须以 `/v1` 结尾** |
| 客户端请求模式 | 开启 | 浏览器直连，Key 不经过 LobeChat 服务器 |

![LobeChat OpenAI Provider 配置界面](https://cdn.acedata.cloud/629ef9d3084a.png)

> 使用 Chat Completions 接口时，请保持 Responses API Specification 关闭。

LobeChat 不会自动给 Base URL 拼接 `/v1`，请求路径直接是 `{API 代理地址}/chat/completions`：

| API 代理地址 | 实际请求 | 结果 |
| --- | --- | --- |
| `https://api.acedata.cloud/v1` | `https://api.acedata.cloud/v1/chat/completions` | 正确 |
| `https://api.acedata.cloud/openai` | `https://api.acedata.cloud/openai/chat/completions` | 也可用 |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404（`/openai` 下没有 `/v1`） |
| `https://api.acedata.cloud` | `https://api.acedata.cloud/chat/completions` | 404（缺 `/v1`） |

LobeChat 默认会调用 `/v1/models` 自动拉取模型，Ace Data Cloud 返回的模型较多时界面会很长，建议在「模型列表 → 自定义模型名称」中手动填写一个 allow list，用英文逗号分隔。如需自定义显示名，可以用 `=`，格式为 `MODEL_ID=显示名称`。

## 选择模型

模型目录会持续更新。优先使用客户端自动加载的模型列表；需要手动填写时，先请求 `GET https://api.acedata.cloud/v1/models` 获取当前模型 ID，再按客户端支持的上下文、图片和工具调用能力选择。

## 验证对接

如果不确定问题出在 LobeChat 还是网络，可以先用 curl 直接验证端点（把 `{token}` 替换为你的 Token）：

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

返回 OpenAI 兼容的 `chat.completion` 对象即说明 Token 与端点都已就绪；若返回 `HTTP 403 used_up` 则表示 Token 有效但余额不足，到 [控制台](https://platform.acedata.cloud/console/applications) 充值即可。

## 进阶：Docker 自部署

如果希望部署一份私有版给团队使用，可用 Docker 一行命令启动（把 `{token}` 替换为你的 Token）：

```bash
docker run -d \
  --name lobe-chat \
  -p 3210:3210 \
  -e OPENAI_API_KEY={token} \
  -e OPENAI_PROXY_URL=https://api.acedata.cloud/v1 \
  -e ACCESS_CODE=your-secret-password \
  -e OPENAI_MODEL_LIST="MODEL_ID" \
  lobehub/lobe-chat:latest
```

打开 `http://你的服务器IP:3210`，输入 `ACCESS_CODE` 即可使用，团队成员无需各自填写 Key。上面用到的 `OPENAI_API_KEY`、`OPENAI_PROXY_URL`、`OPENAI_MODEL_LIST` 等环境变量的完整说明见 [LobeChat 模型服务商环境变量文档](https://lobehub.com/docs/self-hosting/environment-variables/model-provider)。若用 nginx 反向代理加 HTTPS，请务必加上 `proxy_buffering off;`，否则流式响应会被缓冲。更多部署形态请参考 [LobeChat 自部署入门](https://lobehub.com/docs/self-hosting/start) 与 [Docker Compose 部署](https://lobehub.com/docs/self-hosting/platform/docker-compose)。

## 常见问题

### 提示 404 Not Found

通常是 API 代理地址写成了 `.../openai/v1` 或漏了 `/v1`。改成 `https://api.acedata.cloud/v1`。

### 模型列表为空

打开「客户端请求模式」开关；或在「自定义模型名称」中手动填写模型 allow list。

### 提示 401 Unauthorized

请确认 API Key 中粘贴的是 Ace Data Cloud 的 Token（不含 `Bearer` 前缀、无多余空格），且所属应用的余额充足。
