通过 Service UUID 分页返回该服务挂载的 Proxy 端点。只有 alias 时，先调用[服务详情](https://platform.acedata.cloud/documents/platform-service-detail)取得 `id`。

## 接口概览

| 项 | 内容 |
| --- | --- |
| 方法 | `GET` |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| 鉴权 | 公开，无需账户令牌 |
| 分页 | `count` + `items` |

## 参数

| 参数 | 位置 | 必填 | 说明 |
| --- | --- | --- | --- |
| `service_id` | path | 是 | Service UUID，不支持 alias |
| `limit` / `offset` | query | 否 | 分页 |
| `ordering` | query | 否 | Django 排序表达式；推荐 `rank` 或 `-rank` |

```shell
export SERVICE_ID='你的 Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## 响应说明

列表项由 Proxy 模型序列化，线上已验证的字段包括 `id`、`service_id`、`title`、`endpoint`、`price`、`stage`、`rank`、`tags`、`metadata`、`document_id`、`service` 和时间字段。

- 业务入口字段是 `endpoint`，不是 `path`。
- 定价字段是 `price`，不是 `cost`。
- Service 类型不是 Proxy 或未挂载 Proxy 时返回空 `items`。

公开集成只依赖 `endpoint` 和已发布能力，不应依赖未公开的实现细节。
