---
title: "创建 AceDataCloud 平台充值订单"
description: "Platform 集成指南 - Ace Data Cloud"
---

为一个或多个 Application 创建待支付订单。创建会写入订单，但不会自动完成付款；付款前应核对响应中的 `price`、套餐和 Application。

## 准备工作

- 创建 [Account Token](https://platform.acedata.cloud/documents/platform-token)。
- 从[Application 列表](https://platform.acedata.cloud/documents/platform-application-list)取得 `application_id`。
- 从[服务详情](https://platform.acedata.cloud/documents/platform-service-detail)的 `packages` 中选择与 Application 类型匹配且可购买的 `package_id`。

```shell
export PLATFORM_TOKEN='你的账户令牌'
export APPLICATION_ID='你的 Application ID'
export PACKAGE_ID='你的 Package ID'
```

## 接口概览

| 项 | 内容 |
| --- | --- |
| 方法 | `POST` |
| URL | `https://platform.acedata.cloud/api/v1/orders/` |
| 鉴权 | Account Token，OAuth token 需 `orders:write` |
| Body | JSON |

## 请求体

单 Application 订单使用 `application_id` + `package_id`；批量订单使用长度对应的 `application_ids` + `package_ids`。普通订单在后续 `/pay/` 请求中选择支付方式。iOS 内购订单创建时传入 `pay_way: "AppleIAP"`，且只能选择一个带 `metadata.apple_product_id` 和 `metadata.apple_price` 的 Usage 套餐。Apple 内购使用独立的美元预设价格，不叠加会员折扣、支付方式折扣或站点加价；其他地区的本币扣款金额以 Apple 付款确认页为准。

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/orders/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d "{\"application_id\":\"${APPLICATION_ID}\",\"package_id\":\"${PACKAGE_ID}\"}"
```

## 响应说明

成功返回 `201` 和新建的 Order 对象。关键字段包括 `id`、`price`、`discount`、`state`、`application_id/application_ids`、`package_id/package_ids`、`expired_at` 与时间字段。新订单通常是 `Pending`，接着调用[支付订单](https://platform.acedata.cloud/documents/platform-order-pay)。

- `price` 是服务端根据套餐、站点加价和折扣计算后的应付金额；不要由客户端自行计算。
- Package 与 Application 服务或类型不匹配时返回 `400`。
- 免费且系统管理的 Package 不能通过公开订单接口自行领取。
- 为不属于当前账户的 Application 创建订单会被拒绝。
