你大概也遇到过这种情况：手里用着 Claude Code、Cursor 或者 Codex，写代码写得正顺，突然需要一张配图、一段背景音乐、一个短视频，或者想让它顺手查一下最新资料。结果发现——agent 本身并不会这些。你得自己去找 API、读文档、配 key、写调用代码、处理异步轮询，一套折腾下来，灵感早就凉了。

[AceKit](https://github.com/AceDataCloud/AceKit) 就是来省掉这一整套折腾的。一行命令，它把 AceData Cloud 上的生图、生视频、生音乐、网页搜索、LLM 对话等能力，整套装进你的编码 agent。装完之后你直接说人话，agent 会自己加载对应技能、自己鉴权、自己轮询，把活干完。

## 30 秒看懂它在干嘛

装之前 vs 装之后：

| 你说的话 | 装之前 | 装之后（agent 自己做）|
|---|---|---|
| "给这篇 README 配张封面图" | agent 不会，让你自己去找生图 API | 调 NanoBanana / Flux / Midjourney 出图 |
| "把这段脚本做成 30 秒短视频" | 不会 | 调 Sora / Veo / Kling / Seedance 出片 |
| "给这个 demo 配段背景音乐" | 不会 | 调 Suno 出歌 |
| "搜一下最新的 X 再总结" | 不会联网 | 调 Google SERP 拿实时结果 |
| "把这个长链接缩短" | 不会 | 调短链服务返回 surl.id 链接 |

一句话：**你的编码 agent 从"只会写代码"，变成"还会生图、生视频、生音乐、联网搜索"。**

## 三步上手

整个过程几分钟跑通，需要 Node.js 18+。

**第一步 · 拿一个 API Token。** 到 [控制台](https://platform.acedata.cloud/console/applications) 复制 Token——所有能力共用这一个，首次申请送免费额度，可以先免费试。

![在控制台复制 API Token](https://cdn.acedata.cloud/dvc3cg.jpg)

**第二步 · 装。** 一行命令：

```bash
npx acekit
```

它会自动检测机器上的编码 agent 并装好整套技能。真实运行长这样（这台机器只装了 Claude Code）：

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> 没设 Token 时，首次运行会交互式提示你粘贴；也可以提前 `export ACEDATACLOUD_API_TOKEN=你的token` 做到完全无人值守地装。技能数量会随平台能力增加而变化，以 `npx acekit list` 显示的当前清单为准。

**第三步 · 说人话。** 重载一下 agent，然后直接下指令，比如：

```text
用 short-url 技能把 https://platform.acedata.cloud/services 缩短一下
```

agent 会自己加载技能、自己发起调用，给你真实可跳转的结果。

## 真实跑一遍（带输出）

下面四个例子全部是**真实调用、当场返回的结果**，不是示意。命令里的 `$KEY` 就是你的 API Token。

**① 缩短网址（同步，秒回）**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

返回 `https://surl.id/r/1uKp2kilXQ`——点开会 302 跳转回原始的 services 页面。

**② 联网搜索（同步）**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

拿到实时的 Google 结果（节选）：

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ LLM 对话（同步，一个接口接 50+ 模型）**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP是用于统一管理和交换模型上下文信息的协议。
（39 tokens，本次约 0.00007 credit）
```

**④ 生图（异步，约 20 秒，agent 自动轮询到出图）**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

约 22 秒后返回一张真实图片（HTTP 200 · image/png · 317 KB · 本次约 0.13 credit）：

![AceKit 真实生成的图片](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

这些接口你其实不用记——装好技能后，agent 会按各自的 `SKILL.md` 自己拼出正确的请求、处理鉴权和轮询。上面只是把"它在背后干的事"摊开给你看。

## 它到底装了什么

AceKit 是 AceData 整个开发者工具面的"前门"，目前一次安装装的是**技能工具集（Skills）**：

- **一套 Agent 技能**：每个技能是一份写好的 `SKILL.md` 操作手册——鉴权、异步轮询、错误重试、参数怎么填都写清楚了，agent 照着做就行。运行 `npx acekit list` 看当前清单（写这篇时是 19 个，且持续增加）：

```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **统一一个 Token**：一个 `ACEDATACLOUD_API_TOKEN` 解锁全部能力，按真实用量计费。

按能力归类（以 `npx acekit list` 为准）：

| 类型 | 提供方 |
|---|---|
| 🖼️ 生图 | Midjourney · Flux · Seedream · NanoBanana |
| 🎬 生视频 | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan |
| 🎵 生音乐 / 音频 | Suno · Producer · Fish Audio（TTS）|
| 💬 LLM 对话 | 50+ 模型统一接口（GPT · Claude · Gemini · DeepSeek · Grok…）|
| 🔎 搜索 | Google SERP（网页 · 图片 · 新闻 · 地图 · 视频）|
| 🔗 工具 | 短链 · 人脸处理 |

> 同样这些能力，AceData 也提供独立的 **MCP 服务器**（Suno、Midjourney、Sora、SERP… 已发布到 PyPI / VS Code / Smithery / Docker）、**命令行 CLI** 和 **Python / TypeScript SDK**，可按需单独使用。AceKit v0.2 计划支持 `acekit add <name>` 单能力安装，以及自动写入各 agent 的 MCP 配置。

## 支持哪些 Agent

| Agent | 技能安装位置 |
|---|---|
| Claude Code | `~/.claude/skills` |
| Codex CLI | `~/.agents/skills` |
| Cursor / Gemini / OpenCode 等 | `~/.agents/skills`（让你的 agent 指向这里）|

安装时 AceKit 自动检测机器上已装的 agent，只往检测到的那几个里装。

## 彩蛋：用同一个 Token 驱动 Claude Code 本身

AceData 的接口同时兼容 Anthropic 的 `/v1/messages` 格式，所以你**不需要 Anthropic 官方订阅**，用同一个 AceData Token 就能驱动 Claude Code。在项目根目录建 `.claude/settings.local.json`：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

重启 Claude Code 即可——它既用上了 Claude 全系模型，又通过 AceKit 有了生图生视频生音乐的"手"。更多细节见 [Claude Code 集成指南](https://platform.acedata.cloud/documents/claude-code-integration)。
