持有 $ACE 并验证您的 Solana 钱包后，可在 Ace Data Cloud **支持该权益的 Credits API 服务**中获得调用折扣。$ACE 始终保留在您的钱包中；平台只读取链上余额，不会托管、锁定、转移或消耗代币。

> $ACE 不是平台充值余额，也不是支付授权或质押产品。折扣仅适用于页面列出的 Credits API 服务，不适用于充值订单、x402 USDC 支付或其他非 Credits 消费路径。

## $ACE 是什么

$ACE 是部署在 Solana 主网上的 Ace Data Cloud 生态代币。当前已经上线的用途是持有权益：钱包中的 $ACE 余额达到对应门槛后，平台会为支持的 API 服务自动应用折扣。

## 第一步：购买 $ACE

购买 $ACE **不需要先在平台绑定钱包**。您只需要准备：

- 一个 Solana 主网钱包，例如 Phantom 或 Solflare；
- 可用于兑换的 SOL、USDC 或页面实际支持的其他资产；
- 少量 SOL，用于支付 Solana 网络费。

平台不会要求您提供助记词或私钥。任何要求您提交助记词、私钥或远程控制钱包的页面都不是正常流程。

### 1. 从平台提供的准确入口进入

打开 [$ACE 持有权益页面](https://platform.acedata.cloud/console/coin)，在第一步卡片中核对完整 Mint 并点击“购买 $ACE”；也可以直接打开：

[在 Jupiter 查看并兑换 $ACE](https://jup.ag/tokens/GnHpRsrcyfHSMZNzmpjAzTFQA26vnbRMzbKQ11ZKpump)

该链接已经包含当前官方 Mint。不要只通过搜索代币简称选择结果。

### 2. 连接您的 Solana 钱包

在兑换页面连接准备好的钱包，并确认当前网络是 Solana 主网。首次使用钱包时，请先了解钱包自己的安全提示和交易确认界面。

### 3. 选择用于兑换的资产和数量

选择 SOL、USDC 或页面实际支持的其他资产作为支付资产，输入希望兑换的数量。确认页面显示的目标代币 Mint 与下列地址完全一致：

```text
GnHpRsrcyfHSMZNzmpjAzTFQA26vnbRMzbKQ11ZKpump
```

### 4. 核对兑换信息

提交前检查：

- 预计获得的 $ACE 数量；
- 汇率、价格影响和最小收到数量；
- 网络费和其他页面列出的费用；
- 钱包弹窗中的实际交易内容。

链上兑换价格和流动性会变化。平台不承诺成交价格、可成交数量或代币价值；请只在理解交易内容并能承担风险时自行确认。

### 5. 在钱包中确认

确认后等待 Solana 网络完成交易，再回到钱包查看 $ACE 余额。不要关闭或刷新仍在等待钱包确认的弹窗，除非钱包明确提示交易失败或已取消。

## 第二步：购买后连接并验证钱包

购买完成后，再回到平台连接和验证钱包。购买前不需要绑定；购买本身也不会自动绑定账户。请使用**持有 $ACE 的同一个钱包**完成以下操作：

1. 返回 [$ACE 持有权益页面](https://platform.acedata.cloud/console/coin)；
2. 点击“连接钱包”，选择刚才使用的钱包；
3. 点击“验证并绑定”；
4. 在钱包中签署平台展示的所有权验证消息；
5. 等待平台同步 finalized 链上余额。

所有权验证签名只证明您控制该钱包，**不会授权支付或转移代币**。正常流程签署的是可读消息，不会要求您向未知地址转账。

验证成功后，页面会显示钱包缩略地址、$ACE 余额、最后同步时间和当前适用折扣。链上交易完成与平台余额同步之间可能存在延迟，因此购买完成后折扣不一定立即显示。

折扣按服务配置。请以持有权益页面中的“支持 ACE 权益的服务”列表及各服务当前显示的折扣为准，不应理解为覆盖平台上的全部服务。

余额由后台任务读取 Solana finalized 状态。Coin 类型折扣带有效期：

- 成功同步后，符合门槛的折扣会自动应用；
- 临时同步失败时，页面会提示余额状态异常；
- 超过有效期仍无法刷新时，计费链路会暂停陈旧折扣；
- 钱包余额降低或卖出 $ACE 后，下一次成功同步会按新的余额重新计算权益。

## 常见问题

### 为什么买完以后平台余额仍为 0？

先确认交易已在 Solana 主网完成，并确认绑定的是持有 $ACE 的同一个钱包。平台读取 finalized 链上状态，交易确认与后台同步都可能带来短暂延迟。如果页面持续提示同步异常，请稍后重试或联系支持团队。

### 为什么无法签署验证消息？

当前首选流程要求钱包支持 `signMessage`。请更新钱包版本，或改用支持消息签名的 Solana 钱包。不要通过转账或提交私钥来绕过验证。

### 连接了错误的钱包怎么办？

浏览器中的“断开钱包连接”只会断开当前浏览器连接，不会修改平台绑定。若要更换权益钱包，请在持有权益页面点击“解除钱包绑定”，确认撤销当前 ACE 折扣后，再连接并验证新钱包。

### 钱包签名会转走我的资产吗？

不会。绑定流程签署的是所有权验证消息，不是代币转账或支付授权。签名前仍应核对钱包显示的消息内容；如出现交易、转账或陌生授权请求，请拒绝。

### 购买多少 $ACE 才有折扣？

当前第一档门槛是 100,000 $ACE，对支持的 Credits API 服务提供 1% 折扣。各档位见上表，实际适用服务和当前折扣以持有权益页面为准。

### 哪些服务支持 $ACE 权益？

请查看持有权益页面的“支持 ACE 权益的服务”区域。充值订单、x402 USDC 支付和非 Credits 消费路径不使用该折扣。

### 卖出或转出 $ACE 后会怎样？

权益按链上余额计算。余额下降后，下一次成功同步会降低或撤销相应折扣；陈旧折扣也有有效期，不会无限保留。

### 无法访问旧钱包怎么办？

登录您的平台账户，在持有权益页面点击“解除钱包绑定”并确认即可。解除绑定只会撤销平台中的钱包关联和 ACE 折扣，不会转移、销毁或操作钱包内的任何资产；完成后可以连接并验证新钱包。
