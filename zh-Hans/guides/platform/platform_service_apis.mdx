通过 Service UUID 分页返回该服务当前启用且未弃用的 API。只有 alias 时，先调用[服务详情](https://platform.acedata.cloud/documents/platform-service-detail)取得 `id`。

## 接口概览

| 项 | 内容 |
| --- | --- |
| 方法 | `GET` |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| 鉴权 | 公开，无需账户令牌 |
| 分页 | `count` + `items` |

## 参数

| 参数 | 位置 | 必填 | 说明 |
| --- | --- | --- | --- |
| `service_id` | path | 是 | Service UUID，不支持 alias |
| `limit` | query | 否 | 每页条数，最大 100 |
| `offset` | query | 否 | 分页偏移量 |
| `ordering` | query | 否 | Django 排序表达式；推荐 `rank` 或 `-rank` |

当前接口不支持 `stage` 筛选；它已经排除 `Deprecated` API。

```shell
export SERVICE_ID='你的 Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

列表项使用与[平台 API 列表](https://platform.acedata.cloud/documents/platform-api-list)相同的索引结构，当前包含 `definition`。需要单个 API 的稳定入口时，继续调用 `/api/v1/apis/{api_id}`。

## 错误处理

- 服务不存在或当前站点不可见：`404`。
- `service_id` 必须是 UUID；alias 不会在该 action 中解析。
