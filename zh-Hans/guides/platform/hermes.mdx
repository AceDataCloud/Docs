Hermes Agent 通过 OpenAI Chat Completions 协议接入 Ace Data Cloud。任选一种配置方式：

| 配置方式 | 指南 |
| --- | --- |
| `hermes model` 交互向导 | [向导配置](https://platform.acedata.cloud/documents/hermes-wizard-integration) |
| `config.yaml` 手动配置 | [手动配置](https://platform.acedata.cloud/documents/hermes-manual-integration) |
| 平台私有部署 | [托管部署](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

本地接入的共通参数：

- Base URL：`https://api.acedata.cloud/v1`
- Transport：`chat_completions`
- Provider：`custom:acedatacloud`
- API Key：从 [应用列表](https://platform.acedata.cloud/console/applications) 获取

两种本地方式最终都写入 `~/.hermes/config.yaml`，不要重复配置。

返回 [Coding Plan 配置中心](https://platform.acedata.cloud/documents/coding-plan-integration)。
