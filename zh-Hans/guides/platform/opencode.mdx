OpenCode 的 Coding Plan 模型 Provider、IDE Extension 与 MCP 是三项独立能力。IDE Extension 连接本地 OpenCode runtime，并复用同一份 Provider 配置；它不代表宿主编辑器原生支持 Ace Data Cloud。

| 路线 | 说明 | 链接 | 状态 |
|---|---|---|---|
| Terminal / CLI / TUI Provider | 使用 `opencode.json[c]` 和 Chat Completions | [Provider 配置](https://platform.acedata.cloud/documents/opencode-terminal-integration) | 已验证配置合同 |
| IDE Extension | VS Code、Cursor、Windsurf、VSCodium 等宿主连接 OpenCode runtime | [IDE 配置](https://platform.acedata.cloud/documents/opencode-ide-integration) | 实验性 |
| MCP | 在 OpenCode 内调用远程工具 | [MCP 总览](https://platform.acedata.cloud/documents/opencode-mcp-all) | 独立能力 |

Provider 配置成功后，IDE Extension 应使用相同的 Provider 与模型。仍需分别验证 IDE 内聊天、文件读取、编辑与工具调用，不应把 CLI 的一次普通请求自动外推为全部 IDE 能力。

模型 ID 以 [实时目录](https://platform.acedata.cloud/models) 为准。
