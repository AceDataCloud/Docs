分页返回当前站点可见的 API 端点。适合按业务路径、服务或发布阶段查找 API；若只需要一个 API 的完整定义，请直接调用[API 详情](https://platform.acedata.cloud/documents/platform-api-detail)。

## 接口概览

| 项 | 内容 |
| --- | --- |
| 方法 | `GET` |
| URL | `https://platform.acedata.cloud/api/v1/apis/` |
| 鉴权 | 公开，无需账户令牌 |
| 分页 | `count` + `items` |

## 查询参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `path` | string | 否 | 精确匹配 `path` 或 `path2` |
| `service` | string | 否 | 服务 alias 或 UUID |
| `stage` | string | 否 | 按发布阶段筛选；可重复传入多个值 |
| `limit` | integer | 否 | 每页条数，最大 100 |
| `offset` | integer | 否 | 分页偏移量 |

`id`、`service_id`、`tag` 当前不是列表筛选参数；传入后不会产生对应筛选效果。

```shell
curl --get 'https://platform.acedata.cloud/api/v1/apis/' \
  --data-urlencode 'service=midjourney' \
  --data-urlencode 'stage=Production' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/apis/",
    params={"service": "midjourney", "limit": 20},
    timeout=30,
)
response.raise_for_status()
for api in response.json()["items"]:
    print(api["id"], api["method"], api["path"])
```

## 响应说明

线上响应使用 `{count, items}`。每个列表项当前包含 API 模型字段，以及：

- `document_id`：关联开发者文档 ID，可能为空；
- `service_id` / `service`：主服务 ID 与摘要，可能为空；
- `definition`：OpenAPI 定义，可能较大；
- `method`、`path`、`path2`、`stage`、`cost`、`tags`、`metadata` 等。

列表 serializer 当前包含 `definition`，拉取全量目录时应分页并设置超时。字段可能向后兼容地增加，客户端只读取所需字段。
