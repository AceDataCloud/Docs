Coze 官方支持接入自定义模型，并提供 OpenAI Chat API、OpenAI Responses API 和 Anthropic Messages API 三种协议。三条路线的 Base URL、路径拼接、Header、streaming 和工具调用合同不同，因此必须分别配置和验证。

| 路线 | 状态 | 指南 |
|---|---|---|
| OpenAI Chat Completions | 实验性 | [Chat 配置](https://platform.acedata.cloud/documents/coze-chat-integration) |
| OpenAI Responses | 实验性 | [Responses 配置](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages | 实验性 | [Messages 配置](https://platform.acedata.cloud/documents/coze-messages-integration) |

“实验性”表示官方能力和配置入口已确认，但不同 Coze 区域、版本或套餐可能显示不同表单，Ace Data Cloud 仍需按协议完成固定版本验证。不要把某一条协议成功外推到另外两条。

## 配置原则

- Base API URL 优先填写文档给出的 base；不要重复追加客户端会自动补齐的 endpoint path。
- API Key 使用你的 Ace Data Cloud API Token。
- Model 使用模型目录中与所选协议兼容的精确模型 ID。
- 普通文本成功后，还应验证 streaming 和工具调用。
