FreeAIr 是面向 Visual Studio 2022/2026 的开源扩展，官方声明可连接任意 OpenAI-compatible API。不同扩展版本的请求行为可能变化；首次接入请固定版本并完成下文的最小验证。

## 配置

1. 从 Visual Studio Marketplace 或官方仓库安装 FreeAIr。
2. 打开 FreeAIr 设置并新增 OpenAI-compatible 连接。
3. Endpoint 填写 `https://api.acedata.cloud/v1`。
4. Token 填写你的 Ace Data Cloud API Token。
5. Model 填写模型目录中支持 Chat Completions 的精确模型 ID。
6. 保存后发送 `Reply only OK`，再测试一次带项目上下文的请求。

## 当前边界

- 本指南只覆盖 FreeAIr，不代表 Visual Studio 内置 Copilot 支持 arbitrary Base URL。
- 扩展版本可能改变 endpoint 拼接方式；验证时应核对最终请求 URL。
- 工具调用和扩展内 MCP 能力需要独立验证，不能用普通聊天成功代替。
