GitHub Copilot 官方 BYOK 文档将 VS Code 列为支持的本地客户端，并支持 OpenAI-compatible Provider。VS Code 版本、企业策略和模型可见性会影响最终 endpoint；首次接入请按下文检查实际请求。

## 配置范围

1. 确认你的 GitHub Copilot 账户或组织已启用 BYOK/Custom Models 功能。
2. 在 VS Code 的 Copilot 模型管理中新增 OpenAI-compatible Provider。
3. Base URL 填写 `https://api.acedata.cloud/v1`。
4. API Key 填写你的 Ace Data Cloud API Token。
5. Model 填写模型目录中与所选协议兼容的精确模型 ID。
6. 在 Copilot Chat 中发送 `Reply only OK`，再测试一次带工作区上下文的请求。

## 当前边界

- Copilot App、CLI、GitHub Desktop、Enterprise BYOK 与 VS Code 的配置合同不同，本指南不把其他客户端步骤直接套用到 VS Code。
- 组织策略可能禁止个人添加 Provider 或模型。
- Tab completion、Chat、Agent 与后台任务可能使用不同模型路径，应分别验证。
