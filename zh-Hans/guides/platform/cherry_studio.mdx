## 1. 获取 API Key

打开 [Ace Data Cloud 应用列表](https://platform.acedata.cloud/console/applications)，进入可用的应用并复制 API Key。

![获取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 添加 Provider

打开 Cherry Studio，进入 **设置 → 模型服务 → 添加提供商**，填写：

| 字段 | 值 |
| --- | --- |
| 提供商名称 | `Ace Data Cloud` |
| 提供商类型 | `OpenAI` |
| API Key | 刚刚复制的 API Key |
| API 地址 | `https://api.acedata.cloud` |

![Cherry Studio 添加 Ace Data Cloud Provider 配置界面](https://cdn.acedata.cloud/b67a927eae62.png)


Cherry Studio 会为 OpenAI 类型自动补全 `/v1/chat/completions`。使用通用入口时不要在地址末尾加 `#`，也无需按模型家族创建多份 Provider。

## 3. 添加并启用模型

1. 点击 **获取模型列表**；如果当前版本不支持自动获取，则前往 [模型目录](https://platform.acedata.cloud/models) 查看，再手动添加目标模型名称，例如 `claude-opus-5`、`gpt-6-sol`。
2. 点击 API Key 旁的检查按钮验证连接。
3. 打开 Provider 的 **启用** 开关。
4. 在对话模型选择器中选择刚添加的模型。

![Cherry Studio Provider 与模型列表](https://cdn.acedata.cloud/149de1d088bf.png)

> 完成模型获取或手动添加后，请打开右上角的 Provider 开关。

发送 `Reply only OK`，并在 [使用历史](https://platform.acedata.cloud/console/usages) 核对调用。401 检查 Key；模型未显示时检查 Provider 是否启用；404 检查手动填写的模型名称是否与目录中的 `id` 完全一致。

## 关于 GPT Image 2

Cherry Studio 的普通自定义聊天 Provider 不能直接调用 Images API。`gpt-image-2` 生成与编辑应使用 Ace Data Cloud 专用接口：

- [GPT Image 2 图像生成](https://platform.acedata.cloud/documents/openai-images-generations)
- [GPT Image 2 图像编辑](https://platform.acedata.cloud/documents/openai-images-edits)

不要把 `/openai/images/generations` 填进聊天 Provider。
