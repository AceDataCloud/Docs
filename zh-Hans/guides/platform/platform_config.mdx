读取当前请求上下文下的公开功能开关与国家/地区判断。适合前端启动时决定功能是否显示；它不是站点品牌、联系方式或公告目录。

## 接口概览

| 项 | 内容 |
| --- | --- |
| 方法 | `GET` |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| 鉴权 | 公开；携带登录态时部分功能开关可能按用户计算 |

## 查询参数与请求头

| 名称 | 位置 | 说明 |
| --- | --- | --- |
| `country` | query | 两位 ASCII 国家代码；用于覆盖响应中的展示国家，不改变服务端安全判断 |
| `features` | query | 功能开关覆盖表达式；只对允许客户端覆盖的开关或超级管理员生效 |
| `X-Feature-Overrides` | header | 与 `features` 相同的覆盖来源 |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## 真实响应结构

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `features` | object | 当前请求可见的功能开关；键会随平台配置变化，客户端应按需读取并为缺失键设置安全默认值 |
| `country` | string / null | 小写国家代码；无法识别时可能为 `null` |

不要从本接口读取站点名称、CDN、货币、语言、客服联系方式或公告；这些字段不属于当前响应契约。

## 使用建议

- 功能开关会按用户、指纹和站点上下文计算，不要跨用户长期共享缓存。
- 客户端传入的 `country` 只影响返回值，不会绕过服务端地区或安全策略。
- 未识别的 query 参数会被忽略；只使用本页列出的参数。
