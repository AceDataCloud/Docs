---
title: "获取 AceDataCloud 平台 API 近期调用样本"
description: "Platform 集成指南 - Ace Data Cloud"
---

公开返回某个 API 最近 15 分钟内的调用记录样本，用于快速观察近期状态。它不是按状态码聚合的计数接口，也不能用于个人账单、SLA 或完整用量统计。

## 接口概览

| 项 | 内容 |
| --- | --- |
| 方法 | `GET` |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| 鉴权 | 公开，无需账户令牌 |
| 上限 | 合并最近创建/完成的记录后最多返回 5,000 条 |

`api_id` 从[API 列表](https://platform.acedata.cloud/documents/platform-api-list)获取。

```shell
export API_ID='你的 API ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## 真实响应结构

响应直接是数组，不使用分页 envelope：

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| 字段 | 说明 |
| --- | --- |
| `api_id` | API ID |
| `created_at` | 记录创建时间 |
| `trace_id` | 请求追踪标识 |
| `status_code` | HTTP 状态码 |
| `elapsed` | 调用耗时，单位为秒 |

API 不存在时当前也可能返回空数组，因为该 action 直接按 ID 查询近期 usage，并不先验证 API 对象。要计算成功率需由客户端对返回样本自行分组；要查个人扣费请使用账户级接口。
