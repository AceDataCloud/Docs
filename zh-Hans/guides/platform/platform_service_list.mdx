title: "获取 AceDataCloud 平台服务列表"

分页返回当前站点可见的 Service 目录，包括服务类型、展示信息、免费额度、套餐和关联 API/Proxy ID。适合构建服务市场或选择待申请服务。

## 接口概览

| 项 | 内容 |
| --- | --- |
| 方法 | `GET` |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| 鉴权 | 公开；带登录态时 `applied` 才反映当前账户 |
| 分页 | `count` + `items` |

## 查询参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | UUID | 否 | 按服务 ID 筛选；支持重复参数 |
| `private` | boolean | 否 | 按公开状态筛选；站点可见性规则仍然生效 |
| `type` | string | 否 | 服务类型；支持重复参数 |
| `tag` | string | 否 | 按标签筛选 |
| `include_facets` | boolean | 否 | `true` 时附加当前站点可用的类型/标签统计 |
| `limit` | integer | 否 | 每页条数，最大 100 |
| `offset` | integer | 否 | 分页偏移量 |
| `ordering` | string | 否 | 仅支持 `rank` 或 `-rank` |

列表不支持 `alias` 筛选；已有 alias 时直接请求 `/api/v1/services/{alias}`。`applied_count`、`updated_at` 不是允许的排序字段。

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## 响应说明

响应为 `{count, items}`；仅在 `include_facets=true` 时增加 `facets`。服务项包含 `id`、`alias`、`title`、`description`、`type`、`applied_count`、`free_amount`、`unit`、`private`、`need_verify`、`rank`、`tags`、`thumbnail`、`doc_url`、`demo_url`、`api_ids`、`proxy_ids`、`cost`、`packages` 等当前公开字段。

`applied` 在匿名列表中不代表某个账户的申请状态。需要账户相关状态时应带有效登录态，并以[服务申请列表](https://platform.acedata.cloud/documents/platform-application-list)为最终依据。
