Codex CLI、Desktop 和 VS Code 扩展共用 `~/.codex/config.toml`。配置一次 `acedatacloud` provider，即可通过 Ace Data Cloud 使用 Codex。

| 使用方式 | 配置指南 |
| --- | --- |
| Terminal / CLI | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration) |
| Desktop | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration) |
| VS Code | [Codex for VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| 图形化切换 | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration) |

共通配置只有三项：

- Provider：`acedatacloud`
- Base URL：`https://api.acedata.cloud/v1`
- API Key：从 [应用列表](https://platform.acedata.cloud/console/applications) 获取，并保存到 `ACEDATACLOUD_API_KEY`

无需在接入配置中固定模型；启动 Codex 后可直接选择模型。

返回 [Coding Plan 配置中心](https://platform.acedata.cloud/documents/coding-plan-integration)。
