Codex CLI 是 OpenAI 推出的开源本地编程 Agent，可以在终端中阅读代码、修改文件、运行命令并协助完成开发任务。通过 Ace Data Cloud 代理，你可以以更低的价格使用 Codex CLI，无需单独订阅 OpenAI 官方账号。

按使用场景选择对应的完整配置教程：

| 平台 | 说明 | 教程链接 |
|------|------|---------|
| **VS Code** | 官方扩展，在编辑器侧边栏聊天、引用文件、预览 diff | [VS Code 配置教程](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| **终端 (CLI)** | 核心体验，在任意终端运行 `codex` 即可开始 | [终端配置教程](https://platform.acedata.cloud/documents/codex-terminal-integration) |
| **CC Switch（图形界面）** | 桌面端 GUI，一键切换供应商、免手写 config.toml | [CC Switch 配置教程](https://platform.acedata.cloud/documents/codex-cc-switch-integration) |

> **提示**：首次申请可前往 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 获取 API Token，即赠免费额度。Codex CLI 通过 Ace Data Cloud 的 OpenAI Responses 兼容接口（`/v1/responses`）工作，更多模型与计费信息可参考 [OpenAI 服务页面](https://platform.acedata.cloud/documents/openai)。
