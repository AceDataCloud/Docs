Codex CLI 通过 OpenAI Responses 协议接入 Coding Plan。

| 使用入口 | 配置指南 |
|---|---|
| Terminal / CLI | [Codex CLI 终端配置](https://platform.acedata.cloud/documents/codex-terminal-integration) |

## 共通配置

- Base URL：`https://api.acedata.cloud/v1`
- Wire API：`responses`
- API Token：从 Coding Application 获取，并存入 `ACEDATACLOUD_API_KEY`
- Model ID：从实时模型目录选择，不要把 `Codex` 当作模型 ID

Codex 从 `~/.codex/config.toml` 读取 provider 设置；配置中的 `model_provider` 必须与 `[model_providers.acedatacloud]` 完全一致。

返回 [Coding Plan 配置中心](https://platform.acedata.cloud/documents/coding-plan-integration)。
