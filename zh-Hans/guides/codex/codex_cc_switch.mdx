title: "Codex CC Switch 配置指南"
description: "Codex 集成指南 - Ace Data Cloud"
---

CC Switch 可以用图形界面管理 Codex 的 provider 和 API Key。

## 1. 获取 API Key

打开 [Ace Data Cloud 应用列表](https://platform.acedata.cloud/console/applications)，进入可用的应用并复制 API Key。

![获取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 安装 CC Switch

从 [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest) 下载并安装，或在 macOS 上运行：

```bash
brew install --cask cc-switch
```

## 3. 添加 provider

1. 打开 CC Switch，切换到 **Codex**。
2. 点击 **Add Provider**，选择 **Custom**。
3. 填写：

| 字段 | 内容 |
| --- | --- |
| Name | `acedatacloud` |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key | 刚刚复制的 Ace Data Cloud API Key |

如果 CC Switch 提供自定义配置编辑器，配置应保持为：

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"
requires_openai_auth = true
```

CC Switch 会把 API Key 保存到 `~/.codex/auth.json`：

```json
{
  "OPENAI_API_KEY": "{token}"
}
```

不要在上述 provider 中再添加 `env_key` 或 `[model_providers.acedatacloud.auth]`；手动配置与 CC Switch 配置二选一。无需固定 `model`，在 Codex 中直接选择即可。

## 4. 启用并验证

启用 `acedatacloud` provider，完全退出并重启 Codex 或 VS Code。运行 `/model`，确认 Provider 为 `acedatacloud`，再选择模型并发送一条简单消息。

如果返回 401，确认当前启用的是 `acedatacloud`，并检查 `~/.codex/auth.json` 中的 `OPENAI_API_KEY` 是否为刚复制的 Ace Data Cloud API Key。调用记录可在 [使用历史](https://platform.acedata.cloud/console/usages) 查看。
