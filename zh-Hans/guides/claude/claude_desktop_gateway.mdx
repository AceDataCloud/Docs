本指南配置 Claude Desktop 的 **Third-Party Inference Gateway**，不是 Claude Code，也不是 Claude Desktop 的 MCP Connector。

## 1. 获取 API Key

打开 [Ace Data Cloud 应用列表](https://platform.acedata.cloud/console/applications)，进入可用的应用并复制 API Key。

![获取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 打开第三方推理配置

在 Claude Desktop 登录页依次打开 **Help → Troubleshooting → Enable Developer Mode**，再选择 **Developer → Configure Third-Party Inference…**。

![Claude Desktop 打开 Third-Party Inference](https://cdn.acedata.cloud/713ffd7104a3.png)

> 图片来自 Bifrost Apache-2.0 仓库，仅用于定位 Claude Desktop 菜单；不同版本的界面可能略有差异。

## 3. 配置 Gateway

选择 **Gateway**，然后填写：

| 字段 | 值 |
| --- | --- |
| Gateway base URL | `https://api.acedata.cloud` |
| Gateway API key | 刚刚复制的 API Key |
| Gateway auth scheme | `bearer` |
| Credential kind | `Static API key` |

点击 **Apply Changes**，再点击 **Save & Restart**。

## 4. 验证

重启后选择可用模型，新建对话并发送 `Reply only OK`，再执行一个简单工具任务。调用记录可在 [使用历史](https://platform.acedata.cloud/console/usages) 查看。

Ace Data Cloud Gateway 支持 Claude Desktop 使用的 `/v1/models`、Bearer 认证流式 `/v1/messages`、工具调用和 `tool_result` 续写。提示缓存字段会保留；缓存写入与读取值均为 0 时不代表发生了缓存命中。

401 通常表示 Key 不正确；找不到模型时重新检查配置并完整重启 Claude Desktop。反馈问题时提供调用记录中的 trace ID，不要提供 API Key。
