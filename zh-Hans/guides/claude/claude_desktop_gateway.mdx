本指南配置的是 Claude Desktop 的 **Third-Party Inference Gateway**，不是 Claude Code，也不是 Claude Desktop 的 MCP Connector。

## 1. 获取 API Key

打开 [Ace Data Cloud 应用列表](https://platform.acedata.cloud/console/applications)，进入可用的应用并复制 API Key。

![获取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 启用 Developer Mode

在 Claude Desktop 菜单中打开 **Help → Troubleshooting → Enable Developer Mode**。

![Claude Desktop 启用 Developer Mode](https://cdn.acedata.cloud/bab31c0961b5.png)

> 公开教程截图，仅用于定位菜单；不同版本的界面可能略有差异。

## 3. 打开第三方推理配置

启用后，打开 **Developer → Configure Third-Party Inference…**。

![Claude Desktop 打开 Third-Party Inference](https://cdn.acedata.cloud/9e0b95372e2f.png)

> 公开教程截图，仅用于定位菜单；不同版本的界面可能略有差异。

## 4. 配置 Gateway

选择 **Gateway**，然后填写：

| 字段 | 值 |
| --- | --- |
| Gateway base URL | `https://api.acedata.cloud` |
| Gateway API key | 刚刚复制的 API Key |
| Gateway auth scheme | `bearer` |
| Credential kind | `Static API key` |

![Claude Desktop Gateway 配置界面示意图](https://cdn.acedata.cloud/dbf2298940a0.png)

> 界面示意图（非实时截图）：基于公开教程图片通过 GPT Image 2 仅替换网关地址，Key 保持遮罩。它用于说明字段位置，不作为连接成功证明。

点击 **Test connection**；测试通过后点击 **Apply Changes**。如应用提示重启，请按提示重启，再从可用模型中选择需要的 Claude 模型。

## 5. 验证

新建对话并发送 `Reply only OK`。随后执行一个简单工具任务；调用记录可在 [使用历史](https://platform.acedata.cloud/console/usages) 查看。

2026 年 9 月 8 日对 Ace Data Cloud Anthropic 接口的实际检查覆盖了 `/v1/models`、Bearer 认证的流式 `/v1/messages`、工具调用和 `tool_result` 续写。响应也保留提示缓存用量字段；本次检查中的缓存写入与读取值均为 0，因此不代表发生了缓存命中。

401 通常表示 Key 不正确；找不到模型时先重新测试连接并重启 Claude Desktop。反馈问题时提供调用记录中的 trace ID，不要提供 API Key。
