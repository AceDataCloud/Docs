通过 `POST /kling/apparel` 提交任务，使用已有 `POST /kling/tasks` 查询平台任务状态。

## 输入

提供一个最多 2500 字的商品说明、一个 5–180 秒的参考视频和 1–5 张商品图。可另提供 1–5 张模特图、一个背景音乐文件，以及指定配音音色；不指定音色时使用原生口播。

以下是请求结构示例，请替换素材 URL 后调用。

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "你的商品或口播内容"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## 结果与计费

同步模式返回生成结果；异步模式先返回 `task_id`，完成结果包含 `data` 中的视频或图片链接及服务端计算的 `usage`。`callback_url` 用于完成通知；`watermark=true` 请求同时返回水印版本。

原生口播：720p 为 1.82 Credits/秒、1080p 为 2.38 Credits/秒；指定配音：720p 为 2.38 Credits/秒、1080p 为 2.8 Credits/秒。 视频按实际生成时长结算，生成前的每秒基础价不代表整项任务总价。失败任务不收取生成费用。
