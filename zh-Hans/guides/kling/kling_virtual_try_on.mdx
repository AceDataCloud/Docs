通过 `POST /kling/virtual-try-on` 提交任务，使用已有 `POST /kling/tasks` 查询平台任务状态。

## 输入

必须恰好提供一张 product_image 和一张 person_image。keep_face、keep_pose、keep_background 默认均为 true，可独立关闭。输入图片最长边不超过 2048px、最短边大于 300px，文件不超过 10MB。

以下是请求结构示例，请替换素材 URL 后调用。

```json
{
  "contents": [
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "person_image",
      "url": "https://your-cdn.example/person.jpg"
    }
  ],
  "async": true
}
```

## 结果与计费

同步模式返回生成结果；异步模式先返回 `task_id`，完成结果包含 `data` 中的视频或图片链接及服务端计算的 `usage`。`callback_url` 用于完成通知；`watermark=true` 请求同时返回水印版本。

1.12 Credits/张，按实际输出图片数计费。 视频按实际生成时长结算，生成前的每秒基础价不代表整项任务总价。失败任务不收取生成费用。
