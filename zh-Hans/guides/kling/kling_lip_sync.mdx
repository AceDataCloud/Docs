## 可灵对口型 API

`POST https://api.acedata.cloud/kling/lip-sync`

让一个已有的可灵视频（5s 或 10s）按音频或文本"开口说话"（对口型）。配合 `/kling/videos` 的 image2video，可串成完整的"会说话的照片"流程。

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `mode` | string | 是 | `audio2video`（音频驱动）或 `text2video`（文本驱动） |
| `video_id` | string | 二选一 | 可灵生成视频的 ID（如 image2video 返回的，30 天内） |
| `video_url` | string | 二选一 | 公网可访问的 5s/10s 视频 URL |
| `audio_url` | string | audio2video 必填 | 驱动音频的公网 URL |
| `text` | string | text2video 必填 | 要说的文本（≤120 字） |
| `voice_id` | string | text2video 必填 | 音色 ID |
| `callback_url` | string | 否 | 传入或 `async=true` 则立即返回 task_id，异步回调 |

### 计费

每次调用 **2.45 Credits**（固定）。
