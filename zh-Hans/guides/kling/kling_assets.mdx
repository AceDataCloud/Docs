`POST /kling/elements` 和 `POST /kling/voices` 通过 `action` 管理平台资产：`list` 列出自己的资产，`presets` 获取预置资产，`retrieve` 查询 `id`，`delete` 删除自己的 `id`。预置资产不可删除。所有引用都使用接口返回的平台 ID；资产按用户和应用隔离。管理操作不计费。

`list` 和 `presets` 支持 `page_num`（1–1000，默认 1）和 `page_size`（1–500，默认 30）。预置资产首次读取后可用于生成。删除后资产不能再用于新任务。

## 创建音色

向 `/kling/voices` 提交 `action="create"`、最多 20 字的 `voice_name` 和 `voice_url`。音频应为 5–30 秒的清晰单人声音，支持 mp3、wav、mp4、mov。创建一次收费 0.07 Credits；失败任务遵循平台失败计费规则。`async=true` 或提供 `callback_url` 时先返回 `task_id`，通过 `/kling/tasks` 查询最终结果。

```json
{
  "action": "create",
  "voice_name": "Narrator",
  "voice_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
  "async": true
}
```

创建成功后，在 `/kling/videos` 使用 `voice_list=[{"voice_id":"平台音色 ID"}]`。支持 1–2 个音色，限 `model="kling-v2-6"`、`mode="pro"`、`generate_audio=true`。在 `prompt` 中用 `&lt;&lt;<voice_1>>>` 或 `&lt;&lt;<voice_2>>>` 指定已选音色。指定音色的视频按实际输出时长、1.68 Credits/秒计费，支持小数秒；结果中的 `usage.duration` 是实际计量时长。例如输出 5.04 秒对应 8.4672 Credits。不能与 `element_list` 混用。服务未提供有效输出时长时返回 502。

生成前的预估总价按请求时长计算：5 秒为 8.4 Credits，10 秒为 16.8 Credits；最终账单按实际输出时长结算。

## 主体引用

在 `/kling/videos` 使用 `element_list=[{"element_id":"平台主体 ID"}]` 引用已获取的预置主体。支持 1–3 个主体，限 V3、V3 Omni 和 O1。Omni/O1 的主体加图片总数最多 7；有参考视频时最多 4。其他生成限制仍适用。

自定义主体创建暂未开放，`action="create"` 返回 503；价格确认前不会提交创建任务。准备中的请求契约包含 `element_name`（最多 20 字）、`element_description`（最多 100 字）和 `reference_type`。`image_refer` 使用正面图片与 1–3 张参考图片；`video_refer` 使用一个 3–8 秒、1080p、最多 200 MB 的参考视频。两种素材形式不可混用。此准备契约不表示创建能力已上线。
