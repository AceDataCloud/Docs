Ace Data Cloud 提供文本回复、图像、歌曲、视频、语音、搜索与数据工具 API。从[应用管理](https://platform.acedata.cloud/console/applications?lang=zh-cn&utm_source=docs&utm_medium=referral&utm_campaign=evergreen)复制 API Key，即可调用当前账号已开放的服务。各服务指南说明支持的操作、请求字段和输出格式。

要获取文本回复，可以试试[对话 API](https://platform.acedata.cloud/documents/openai-chat-completions-integration?lang=zh-cn)。要生成图片或音乐，可以从 [GPT Image 2.6](https://platform.acedata.cloud/models/gpt-image-2.6-flare?m=image&lang=zh-cn)、[ACE Music](https://platform.acedata.cloud/documents/acemusic-audios-integration?lang=zh-cn) 或 [Suno](https://platform.acedata.cloud/documents/suno-audios-integration?lang=zh-cn) 开始。长任务返回任务 ID，使用它查询最终结果。完整示例见[异步任务](https://platform.acedata.cloud/documents/acemusic-tasks-integration?lang=zh-cn)。

在业务代码中接入可以阅读 [SDK 指南](https://platform.acedata.cloud/documents/acedatacloud-sdk?lang=zh-cn)，连接助手或工作流可以查看 [MCP 接入指南](https://platform.acedata.cloud/documents/mcp-tutorials-claude-desktop?lang=zh-cn)。
