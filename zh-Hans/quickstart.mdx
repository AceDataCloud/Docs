先获取一条文本回复，也可以从下方选择图像、音乐、视频或搜索 API。

## 获取 API Key

1. 打开[应用管理](https://platform.acedata.cloud/console/applications?lang=zh-cn&utm_source=docs&utm_medium=referral&utm_campaign=evergreen)，登录或注册账号。
2. 找到**通用应用**。如尚未创建，点击**初始化通用应用**，然后复制 **API Key**。通用 Key 可访问当前账号已开放的服务。
3. 查看所选模型的[价格](https://platform.acedata.cloud/models?lang=zh-cn)和应用余额。独立 Key 与可选限制见 [API Key 指南](https://platform.acedata.cloud/documents/api-key-guide?lang=zh-cn)。

点击图中 **1** 复制 Key。需要为本次接入创建独立 Key 时，点击 **2** 打开 **Manage Keys / 管理密钥**。

![在通用应用中复制 API Key，或打开管理密钥](https://raw.githubusercontent.com/AceDataCloud/NanoBananaDify/2522b2f57210597af2db866445319334a1677a23/_assets/tutorial/get-api-key-en.png)

在终端环境变量中保存原始 Key。

```bash
export ACEDATACLOUD_API_KEY="YOUR_API_KEY"
```

## 发送请求

在终端或自己的后端运行以下命令，获取一条简短回复。

```bash
curl --fail-with-body https://api.acedata.cloud/v1/chat/completions \
  --header "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-6-luna",
    "messages": [{"role": "user", "content": "用一句话打个招呼。"}]
  }'
```

## 读取结果

回复位于 `choices[0].message.content`。下面是响应结构示意。

```json
{
  "choices": [
    {"message": {"role": "assistant", "content": "你好，很高兴帮助你！"}}
  ]
}
```

如果响应包含 `error`，根据其中的 `code` 和 `message` 处理问题。联系支持时保留 `trace_id`。响应字段说明见[对话 API 指南](https://platform.acedata.cloud/documents/openai-chat-completions-integration?lang=zh-cn)。
