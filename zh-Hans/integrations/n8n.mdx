---
title: "在 n8n 中使用 AceDataCloud"
description: "导入聊天工作流，用 AceDataCloud API Token 运行。"
---

使用 n8n 自带的 HTTP Request 节点调用 AceDataCloud。[示例工作流](https://raw.githubusercontent.com/AceDataCloud/Docs/main/examples/n8n/acedatacloud-chat.json)向 Chat Completions API 发送提示词，并返回回复和 Token 用量，无需安装社区节点。

## 导入工作流

1. [创建 AceDataCloud API Token](https://platform.acedata.cloud/console/applications)。
2. 在 n8n 中新建工作流，选择 **Import from URL**，填入[示例工作流地址](https://raw.githubusercontent.com/AceDataCloud/Docs/main/examples/n8n/acedatacloud-chat.json)。也可以下载 JSON 文件后选择 **Import from File**。
3. 打开 **AceDataCloud chat** 节点，在 **Authentication → Generic Credential Type** 中选择 **Bearer Auth**，创建凭据并填入 AceDataCloud Token。只需填 Token 本身，n8n 会自动添加 `Bearer ` 前缀。保存后在节点中选中这个凭据。
4. 在 **Set prompt and model** 节点修改示例提示词，并选择[受支持的聊天模型](https://platform.acedata.cloud/documents/openai-chat-completions)。
5. 点击 **Execute workflow**。HTTP Request 的输出包含 `choices[0].message.content` 和 `usage`。

请把 Token 只存放在 n8n 凭据中，不要写入工作流 JSON 或 Set 节点。每次运行都会产生 API 用量；启用定时或 Webhook 触发前，请先查看模型当前价格。

## 扩展工作流

可将手动触发器换成自己的触发器，再把输入文本映射到 **Set prompt and model** 中的 `prompt`。HTTP Request 节点向 `https://api.acedata.cloud/v1/chat/completions` 发送非流式 `POST` 请求，后续节点可以直接使用返回结果。请求和响应结构见 [Chat Completions](/zh-Hans/guides/openai/openai_chat_completions)。

请求失败时，检查节点选择的凭据、Token 是否误带 `Bearer ` 前缀、模型名称和可用余额。遇到鉴权或余额错误，先排除原因再重试。
