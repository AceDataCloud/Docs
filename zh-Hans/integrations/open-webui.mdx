Open WebUI 内置的 OpenAI 兼容 **Chat Completions** 连接可以直接使用 Ace Data Cloud，无需自定义 Pipe。本文面向已有实例；部署、持久化和详细排错见[完整配置指南](/zh-Hans/guides/platform/open_webui)。连接步骤曾在 v0.11.4 核对；v0.12.0 的模型发现和普通用户读取权限也已分别验证。

## 准备工作

- 在 [Ace Data Cloud 应用控制台](https://platform.acedata.cloud/console/applications?utm_source=opensource&utm_medium=referral&utm_campaign=evergreen&utm_content=openwebui_docs_api_key)获取应用 API Key，确认模型权限、当前价格和余额。受限 Key 须同时允许 `/v1/models` 和 `/v1/chat/completions`。
- 用 Open WebUI 管理员账户添加服务端连接并授权模型。获准用户共享该连接的 Key，可以消耗它的 Credits。不要把 Key 填在聊天正文或截图中。

## 添加连接

1. 在 Open WebUI 用户菜单中打开 **Admin Panel → Settings → Connections**。
2. 在 **OpenAI API → Manage OpenAI API Connections** 下点击 **Add Connection**（`+`）。
3. **Connection Type** 保持 **External**；**URL** 填 `https://api.acedata.cloud/v1`（末尾不要加 `/`）；**Auth** 选择 **Bearer**；**API Key** 填应用 Key；**API Type** 保持 **Chat Completions**。
4. 点击 **Verify Connection** 检查 `/v1/models`；保存连接时也可以跳过这一步。点击连接弹窗中的 **Save**，如页面仍提示，再点击 Connections 主设置页的 **Save**。
5. 在 **Admin Panel → Settings → Models** 给目标用户或组授予各模型的 **Read** 权限。随后以获准用户新建聊天，选择当前支持 Chat Completions 的模型，发送 `Reply with the single word OK.`，核对完整回复和对应的[使用记录](https://platform.acedata.cloud/console/usages)。

模型 ID 与可用性会变化，请结合返回列表和[当前聊天模型目录](https://platform.acedata.cloud/documents/openai-chat-completions)选择。只需少量模型时，在 **Advanced → Model IDs** 中逐个输入准确 ID、点击 **Add**（`+`）并保存。该允许列表控制模型发现，不能代替各模型的 Read 权限。出现模型 ID 不证明它支持图片、工具或其他协议。

## 核对请求与排错

URL 已包含 `/v1`，Open WebUI 会追加 `/models` 或 `/chat/completions`。不要填写完整聊天地址或 `/openai/v1`。**Verify Connection** 只验证模型发现，完整聊天回复才证明聊天路由可用。普通用户看不到模型时，须独立检查 Read 授权，不能只检查应用权限、Key 和余额。

停用不需要的默认连接，避免误选或探测。Ace Key 存放在服务端连接设置中，应限制服务器和模型的访问权限。个人模型 Key 的 Pipe 或服务 Tool 各有自己的用户设置与权限，共享连接不会自动填入这些 Key。

每次模型请求都可能消耗 Credits。生成标题、标签和后续提问可能发起额外请求；需要控制首次验证次数时，先关闭这些功能。在[使用历史](https://platform.acedata.cloud/console/usages)按 Key 和时间窗口核对扣费。媒体任务被接受不代表已经完成；本文文字聊天流程不验证媒体、文件、Community 工具发布或所有模型。

连接规则见 Open WebUI [官方兼容指南](https://docs.openwebui.com/getting-started/quick-start/connect-a-provider/starting-with-openai-compatible/)。后续可阅读[完整配置指南](/zh-Hans/guides/platform/open_webui)或 [Chat Completions 请求格式](/zh-Hans/guides/openai/openai_chat_completions)。

## 独立安装服务工具

Suno、Seedance、Happy Horse、GPT Image 和 Nano Banana 各有单独可下载的 Tool，见 [Ace Data Cloud v0.1.1 版本](https://github.com/AceDataCloud/OpenWebUIPlugins/releases/tag/v0.1.1)及[中英文分服务教程](https://github.com/AceDataCloud/OpenWebUIPlugins/tree/v0.1.1/readme/services)。这是 Ace 的 GitHub 分发；Open WebUI Community 正式帖子/Get 链接仍待核实，不能把仓库下载当成官方目录收录或默认内置。

只选择所需服务的 JSON 或 ZIP，核校验值并审阅 Python，再由管理员导入 **Workspace → Tools** 并授予 **Read**。用户在该 Tool 自己的 **User Valves → Api Key** 填个人 Key，除明确要执行收费提交外，保持 **Allow Billable Calls** 关闭。模型和工具权限互相独立。异步生成先返回任务号，随后只查询同 ID，直到终态成功并打开返回媒体，不为轮询重复生成。具体 Key 权限、当前价检查、动作和结果限制见相应服务教程。
