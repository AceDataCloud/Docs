title: "在 Open WebUI 中使用 AceDataCloud"
description: "通过 Open WebUI 的 OpenAI 兼容供应商连接 AceDataCloud 聊天模型。"
---

Open WebUI 支持 OpenAI 兼容的 Chat Completions 接口，可以直接连接 AceDataCloud，无需编写自定义 Pipe 或供应商模块。

## 添加连接

1. [创建 AceDataCloud API Token](https://platform.acedata.cloud/console/applications)。
2. 在 Open WebUI 中打开 **Settings → Admin → Connections**，在 **Manage OpenAI API Connections** 下选择 **Add Connection**。
3. URL 填 `https://api.acedata.cloud/v1`，API Key 填 AceDataCloud Token。
4. 如果没有自动发现模型，在 **Model IDs** 中手动加入 `gpt-5.5`。保存连接，在新对话中选中该模型并发送简短提示词。

Open WebUI 的 **Verify Connection** 会请求 `/models`；模型发现失败不等于 Chat Completions 调用失败。此时可手动添加模型 ID，再用真实聊天请求验证。AceDataCloud 的 `/v1/models` 和 `/v1/chat/completions` 路由均使用 Bearer Token。请以[当前模型目录](https://platform.acedata.cloud/documents/openai-chat-completions)为准。

Token 只存放在 Open WebUI 的连接设置中。测试提示词可能产生 API 用量，请先查看模型当前价格。协议细节见 [Chat Completions](/zh-Hans/guides/openai/openai_chat_completions)和 [Open WebUI 官方指南](https://docs.openwebui.com/getting-started/quick-start/connect-a-provider/starting-with-openai-compatible/)。
