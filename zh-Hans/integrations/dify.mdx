---
title: "在 Dify 中使用 AceDataCloud 模型"
description: "用 Dify 的 OpenAI API 兼容模型供应商接入 AceDataCloud。"
---

Dify 的 OpenAI API 兼容模型供应商可以调用 AceDataCloud 聊天模型。配置模型时无需安装 AceDataCloud 专属插件。

## 配置模型

1. [创建 AceDataCloud API Token](https://platform.acedata.cloud/console/applications)。
2. 在 Dify 中打开 **设置 → 模型供应商**。如果尚未安装，从 Marketplace 安装 [OpenAI-API-compatible](https://marketplace.dify.ai/plugin/langgenius/openai_api_compatible)。
3. 添加聊天模型，填写：

| 字段 | 值 |
| --- | --- |
| API Base URL | `https://api.acedata.cloud/v1` |
| API Key | 你的 AceDataCloud Token |
| 模型名称 | `gpt-5.5`，或其他[受支持的聊天模型](https://platform.acedata.cloud/documents/openai-chat-completions) |
| 模型类型 | LLM |
| 对话类型 | Chat（对话） |
| API 类型 | Chat Completions API |

4. 保存并测试模型，然后在 Dify 的 **LLM** 节点中选择它。

Base URL 以 `/v1` 结尾，不要再加 `/chat/completions`；Dify 会自行拼接操作路径。旧的 `/openai/v1` 地址不提供此接口。

每次测试或运行工作流都会产生 AceDataCloud 用量。发布工作流前，检查模型当前价格及 Dify 的重试设置。API Key 只存放在 Dify 的供应商凭据设置中，不要写进提示词或工作流导出文件。

请求和响应结构见 [Chat Completions](/zh-Hans/guides/openai/openai_chat_completions)。
