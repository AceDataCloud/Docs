## مقدمة عن Suno

Suno هو واحد من أقوى منصات توليد الموسيقى باستخدام الذكاء الاصطناعي حالياً. من خلال Suno API التابعة لـ Ace Data Cloud، يمكنك توليد موسيقى عالية الجودة عبر استدعاءات API بسيطة.

## نقاط نهاية API

| نقطة النهاية | الوظيفة |
|--------------|---------|
| `POST /suno/audios` | توليد الموسيقى (النقطة الرئيسية) |
| `POST /suno/lyrics` | توليد كلمات الأغاني |
| `POST /suno/persona` | إدارة أساليب المغني |
| `POST /suno/wav` | الحصول على صيغة WAV |
| `POST /suno/mp4` | الحصول على صيغة MP4 |
| `POST /suno/tasks` | الاستعلام عن حالة المهام |

## التوليد الأساسي

### توليد بناءً على وصف نصي

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### توليد كلمات أغاني مخصصة

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\n夏日的阳光洒满了海岸\n微风中传来浪花的声音\n\n[Chorus]\n让我们一起去远方\n追逐那自由的梦想",
        "style": "pop upbeat",
        "title": "夏日冒险",
    },
)
```

## الميزات المتقدمة

### استكمال الأغاني

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### توليد كلمات الأغاني

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "写一首关于冬天的歌",
    },
)
```

## النماذج المتاحة

| النموذج | الميزة |
|---------|---------|
| chirp-v5 | أحدث إصدار، أفضل جودة صوت |
| v4-5-plus | نسخة محسنة |
| v4-5 | نسخة مستقرة |
| v4 | النسخة الكلاسيكية |

## الخلاصة

يوفر Suno API عبر منصة Ace Data Cloud قدرة كاملة على توليد الموسيقى. سواء كان التوليد النصي البسيط أو إنشاء كلمات أغاني مخصصة، يمكن تحقيق ذلك ببضع أسطر من الكود.

قم بالتسجيل والتجربة عبر [platform.acedata.cloud](https://platform.acedata.cloud).
