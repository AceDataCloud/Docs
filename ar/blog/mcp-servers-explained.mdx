## ما هو MCP

بروتوكول سياق النموذج (Model Context Protocol - MCP) هو بروتوكول مفتوح يسمح لمساعدي الذكاء الاصطناعي (مثل Claude و Cursor) بالاتصال المباشر بالأدوات الخارجية وواجهات برمجة التطبيقات (API). من خلال MCP، لا يقتصر الذكاء الاصطناعي على الإجابة على الأسئلة فقط، بل يمكنه أيضًا تنفيذ العمليات الفعلية.

## MCP Server الذي تقدمه Ace Data Cloud

| MCP Server       | اسم حزمة PyPI    | الوظيفة          |
|------------------|------------------|------------------|
| MCPSuno          | mcp-suno         | توليد الموسيقى بالذكاء الاصطناعي |
| MCPSerp          | mcp-serp         | بحث Google       |
| MCPMidjourney    | mcp-midjourney   | توليد الصور بالذكاء الاصطناعي |
| MCPLuma          | mcp-luma         | توليد الفيديو بالذكاء الاصطناعي |
| MCPSora          | mcp-sora         | توليد الفيديو بالذكاء الاصطناعي |
| MCPVeo           | mcp-veo          | توليد الفيديو بالذكاء الاصطناعي |
| MCPNanoBanana    | mcp-nano-banana  | توليد الصور بالذكاء الاصطناعي |

## التثبيت والاستخدام

### التثبيت

```bash
pip install mcp-suno  # أو أي MCP Server آخر
```

### إعداد متغيرات البيئة

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### التكوين في Cursor

أضف في إعدادات MCP الخاصة بـ Cursor:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### التكوين في Claude Desktop

قم بتحرير ملف إعدادات Claude Desktop وأضف تكوين MCP Server.

## سيناريوهات الاستخدام

1. **توليد الموسيقى في Cursor**: أخبر الذكاء الاصطناعي "أنشئ أغنية مبهجة باستخدام Suno"، وسيقوم الذكاء الاصطناعي بالاتصال المباشر بـ API
2. **البحث عن المعلومات الحية**: يمكن للذكاء الاصطناعي استخدام MCP Server الخاص بـ SERP للبحث عن أحدث المعلومات
3. **توليد مواد المشروع**: يمكن للذكاء الاصطناعي استدعاء Midjourney لتوليد الصور المطلوبة للمشروع

## MCP مقابل الاتصال المباشر بـ API

- **MCP**: مناسب للاستخدام داخل أدوات برمجة الذكاء الاصطناعي، حيث يتم الاستدعاء تلقائيًا بواسطة الذكاء الاصطناعي
- **API**: مناسب للتكامل في تطبيقاتك الخاصة مع التحكم البرمجي

كلاهما يستخدم نفس رمز API الخاص بـ Ace Data Cloud، والنداءات الأساسية تتم إلى نفس نقاط نهاية API.

## الخلاصة

يتيح MCP لمساعدي الذكاء الاصطناعي الاتصال المباشر بمختلف واجهات برمجة التطبيقات الخاصة بـ Ace Data Cloud. جميع MCP Server متاحة على PyPI، والتثبيت والتكوين بسيط، مما يجعل أدوات الذكاء الاصطناعي الخاصة بك أكثر قوة.

توجه إلى [platform.acedata.cloud](https://platform.acedata.cloud) للحصول على رمز API الخاص بك.
