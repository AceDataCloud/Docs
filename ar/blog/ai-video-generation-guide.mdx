## نظرة عامة

توليد الفيديو بالذكاء الاصطناعي يتطور بسرعة. تقدم Ace Data Cloud سبع واجهات برمجة تطبيقات لتوليد الفيديو، تغطي مختلف السيناريوهات من تحويل النص إلى فيديو إلى تحويل الصور إلى فيديو.

## خدمات توليد الفيديو المتاحة

| الخدمة | نقطة النهاية | النموذج | الميزات |
|--------|--------------|---------|---------|
| Sora   | `POST /sora/videos` | sora-2, sora-2-pro | من إنتاج OpenAI، جودة سينمائية |
| Veo    | `POST /veo/videos` | veo3, veo3-fast | من إنتاج Google، يدعم 4K |
| Kling  | `POST /kling/videos` | kling-v2-5-turbo | من إنتاج Kuaishou، سرعة عالية |
| Luma   | `POST /luma/videos` | — | تحكم في الإطار الأول والأخير |
| Hailuo | `POST /hailuo/videos` | minimax-t2v | من إنتاج MiniMax |
| Seedance | `POST /seedance/videos` | doubao-seedance-1-0-pro-250528 | من إنتاج ByteDance |
| Wan    | `POST /wan/videos` | wan2.6-t2v | من إنتاج Alibaba |

## البدء السريع

### توليد فيديو Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A cat playing in a sunny garden",
        "model": "sora-2",
        "duration": 10,
        "orientation": "landscape",
    },
)
print(response.json())
```

### توليد فيديو Kling

```python
response = requests.post(
    "https://api.acedata.cloud/kling/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A white cat walking in the snow",
        "model": "kling-v2-5-turbo",
        "duration": 5,
        "aspect_ratio": "16:9",
    },
)
print(response.json())
```

### توليد فيديو Veo

```python
response = requests.post(
    "https://api.acedata.cloud/veo/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A coffee mug rotating on a marble counter",
        "model": "veo3",
    },
)
print(response.json())
```

## معالجة المهام غير المتزامنة

عادةً ما يستغرق توليد الفيديو وقتًا طويلاً. جميع واجهات برمجة تطبيقات الفيديو تدعم:

1. **إشعارات رد الاتصال**: تعيين `callback_url` في الطلب، ليتم إرسال النتيجة تلقائيًا عند الانتهاء
2. **الاستعلام الدوري**: الاستعلام عن تقدم المهمة عبر نقطة النهاية `/tasks`

```python
# استخدام عنوان URL للرد الاتصال
data = {
    "prompt": "A sunrise over mountains",
    "model": "sora-2",
    "callback_url": "https://your-server.com/webhook",
}

# أو الاستعلام الدوري عن حالة المهمة
task_response = requests.post("https://api.acedata.cloud/sora/tasks",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json={"task_id": "your-task-id"})
```

## توصيات الاختيار

- **أفضل جودة صورة**: Sora (sora-2-pro)
- **أسرع سرعة**: Kling (kling-v2-5-turbo)
- **أعلى دقة**: Veo (يدعم 4K)
- **تحكم في الإطار الأول والأخير**: Luma
- **أفضل قيمة مقابل السعر**: Wan

تفضل بزيارة [platform.acedata.cloud](https://platform.acedata.cloud) لتجربة مجانية.
