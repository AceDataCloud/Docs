تشارك إضافة Codex لـ VS Code و Codex CLI ملف `~/.codex/config.toml`.

## 1. الحصول على مفتاح API

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، انتقل إلى التطبيقات المتاحة وانسخ مفتاح API.

![الحصول على مفتاح API من Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. تثبيت الإضافة

قم بتثبيت **Codex – وكيل البرمجة من OpenAI** من سوق إضافات VS Code، أو قم بتشغيل:

```bash
code --install-extension openai.chatgpt
```

## 3. إعداد مفتاح API

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="مفتاح API الخاص بك"
```

لجعل هذا التغيير دائمًا، أضف هذا السطر إلى `~/.zshrc` أو `~/.bashrc`. استخدم Windows PowerShell:

```powershell
setx ACEDATACLOUD_API_KEY "مفتاح API الخاص بك"
```

## 4. تكوين AceDataCloud

قم بتحرير `~/.codex/config.toml` (بالنسبة لـ Windows، يكون `%USERPROFILE%\.codex\config.toml`)، وأضف:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

قم بتغيير السطرين الأخيرين في Windows إلى:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

لا حاجة لملء `model`؛ يمكنك اختيار النموذج من لوحة Codex.

## 5. إعادة التشغيل والتحقق

قم بالخروج تمامًا وأعد فتح VS Code، ثم افتح لوحة Codex. قم بتشغيل `/model`، تأكد من أن المزود هو `acedatacloud`، ثم أرسل رسالة بسيطة؛ يمكنك عرض سجلات الاستدعاء في [سجل الاستخدام](https://platform.acedata.cloud/console/usages).

إذا لم تتمكن الإضافة من قراءة المفتاح، يرجى بدء VS Code من الطرفية التي تم إعداد متغير البيئة فيها، أو إعداد متغير بيئة على مستوى النظام ثم إعادة تشغيل VS Code. يحتاج Remote SSH و WSL و Dev Container إلى تكوين في البيئة التي يتم فيها تشغيل الإضافة فعليًا.
