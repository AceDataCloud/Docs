يتشارك Codex Desktop و Codex CLI في `~/.codex/config.toml`.

## 1. الحصول على مفتاح API

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، انتقل إلى التطبيقات المتاحة ونسخ مفتاح API.

![الحصول على مفتاح API من Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. إعداد مفتاح API

macOS:

```bash
launchctl setenv ACEDATACLOUD_API_KEY "مفتاح API الخاص بك"
```

Windows PowerShell:

```powershell
setx ACEDATACLOUD_API_KEY "مفتاح API الخاص بك"
```

## 3. تكوين AceDataCloud

قم بتحرير `~/.codex/config.toml` (بالنسبة لـ Windows يكون `%USERPROFILE%\.codex\config.toml`)، وأضف:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

بالنسبة لـ Windows، قم بتغيير السطرين الأخيرين إلى:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

لا حاجة لملء `model`؛ بعد فتح Codex، اختر النموذج مباشرة.

## 4. إعادة التشغيل والتحقق

قم بالخروج تمامًا وأعد فتح Codex Desktop، أنشئ مهمة محلية وأرسل رسالة بسيطة. يجب أن يظهر المزود كـ `acedatacloud`؛ يمكن رؤية الاستدعاءات الحقيقية في [سجل الاستخدام](https://platform.acedata.cloud/console/usages).

إذا لم تنجح الإعدادات، تأكد من أنك قمت بتعديل `~/.codex/config.toml` الخاص بالمستخدم الحالي، وأن متغير البيئة قد تم تعيينه، ثم أعد تشغيل التطبيق بالكامل مرة أخرى. تحتاج المهام السحابية أو التشغيل التلقائي في بيئات مختلفة إلى تكوين المفتاح بشكل منفصل في كل بيئة.
