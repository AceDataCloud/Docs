## 1. الحصول على مفتاح API

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، انتقل إلى التطبيقات المتاحة وانسخ مفتاح API.

![الحصول على مفتاح API من Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. تثبيت Codex

```bash
npm install -g @openai/codex
```

## 3. إعداد مفتاح API

macOS / Linux：

```bash
export ACEDATACLOUD_API_KEY="مفتاح API الخاص بك"
```

لجعلها دائمة، أضف هذا السطر إلى `~/.zshrc` أو `~/.bashrc`. استخدم Windows PowerShell:

```powershell
setx ACEDATACLOUD_API_KEY "مفتاح API الخاص بك"
```

بعد الإعداد، أعد فتح الطرفية.

## 4. تكوين AceDataCloud

قم بتحرير `~/.codex/config.toml` (بالنسبة لـ Windows، يكون `%USERPROFILE%\.codex\config.toml`)، وأضف:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

بالنسبة لـ Windows، قم بتغيير السطرين الأخيرين إلى:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

لا حاجة لملء `model`؛ بعد التشغيل، يمكنك اختيار النموذج في Codex. يمكن الاحتفاظ بالإعدادات الأخرى، ولا تقم بإنشاء مزود بنفس الاسم مرة أخرى.

## 5. بدء التشغيل

```bash
cd /path/to/your/project
codex
```

بعد الدخول إلى Codex، قم بتشغيل `/model`، تأكد من أن المزود هو `acedatacloud`، ثم اختر النموذج المطلوب. يمكنك عرض سجلات الاستدعاء والرصيد في [سجل الاستخدام](https://platform.acedata.cloud/console/usages) و [قائمة التطبيقات](https://platform.acedata.cloud/console/applications).

إذا ظهرت رسالة تفيد بفقدان المفتاح أو عادت 401، تأكد من إعداد متغير البيئة، ثم اغلق الطرفية تمامًا وأعد فتحها و Codex.
