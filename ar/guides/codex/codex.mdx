title: "دليل إعداد Codex"
description: "Codex 集成指南 - Ace Data Cloud"
---

Codex CLI هو وكيل برمجة محلي مفتوح المصدر أطلقته OpenAI، يمكنه قراءة الكود، تعديل الملفات، تشغيل الأوامر، والمساعدة في إكمال مهام التطوير من خلال الطرفية. عبر وكيل Ace Data Cloud، يمكنك استخدام Codex CLI بتكلفة أقل دون الحاجة للاشتراك في حساب OpenAI الرسمي بشكل منفصل.

اختر الدليل الكامل المناسب حسب سيناريو الاستخدام:

| المنصة | الوصف | رابط الدليل |
|--------|--------|-------------|
| **VS Code** | امتداد رسمي، للدردشة في الشريط الجانبي للمحرر، استدعاء الملفات، ومعاينة الفروقات | [دليل إعداد VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| **الطرفية (CLI)** | التجربة الأساسية، شغّل `codex` في أي طرفية للبدء | [دليل إعداد الطرفية](https://platform.acedata.cloud/documents/codex-terminal-integration) |

> **ملاحظة**: للحصول على رمز API لأول مرة، يمكنك زيارة [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على رمز API مع رصيد مجاني. يعمل Codex CLI عبر واجهة متوافقة مع OpenAI Responses الخاصة بـ Ace Data Cloud (`/v1/responses`)، ولمزيد من المعلومات حول النماذج والتسعير، يرجى مراجعة [صفحة خدمات OpenAI](https://platform.acedata.cloud/documents/openai).
