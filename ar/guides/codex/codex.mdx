title: "دليل تكوين Codex"
description: "Codex API guide - Ace Data Cloud"
---

تشارك Codex CLI وDesktop وVS Code الإعدادات في `~/.codex/config.toml`. قم بتكوين مزود `acedatacloud` مرة واحدة، ويمكنك استخدام Codex عبر Ace Data Cloud.

| طريقة الاستخدام     | دليل التكوين                                                                                   |
| -------------- | --------------------------------------------------------------------------------------- |
| Terminal / CLI | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)        |
| Desktop        | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)     |
| VS Code        | [Codex for VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)  |
| التبديل الرسومي     | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration) |

تتكون الإعدادات المشتركة من ثلاث نقاط فقط:

- المزود: `acedatacloud`
- عنوان URL الأساسي: `https://api.acedata.cloud/v1`
- مفتاح API: احصل عليه من [قائمة التطبيقات](https://platform.acedata.cloud/console/applications) واحفظه في `ACEDATACLOUD_API_KEY`

لا حاجة لتثبيت النموذج في إعدادات الاتصال؛ يمكنك اختيار النموذج مباشرة بعد تشغيل Codex.

عد إلى [مركز تكوين خطة البرمجة](https://platform.acedata.cloud/documents/coding-plan-integration).
