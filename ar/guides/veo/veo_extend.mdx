ستتناول هذه الوثيقة توضيحات دمج واجهة Veo Extend API. تُستخدم هذه الواجهة لتمديد **مدة** فيديو Veo تم إنشاؤه مسبقًا، حيث ستقوم الذكاء الاصطناعي تلقائيًا بكتابة المشاهد اللاحقة.

## عملية التقديم

لاستخدام واجهة API، يجب أولاً التوجه إلى صفحة خدمة Veo المعنية لتقديم الطلب. إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول.

## الاستخدام الأساسي

يتطلب استدعاء هذه الواجهة تمرير المعلمات التالية:

- `video_id` (مطلوب): معرف مهمة الفيديو المصدر (من `/veo/videos` أو من هذه الواجهة نفسها).
- `model` (مطلوب): النموذج المستخدم للتمديد، **يدعم فقط `veo31-fast` و `veo31`**، النماذج الأخرى غير مدعومة.
- `prompt` (اختياري): نص إرشادي لتمديد مشهد الفيديو.
- `aspect_ratio` (اختياري): `16:9` أو `9:16`، الافتراضي هو `16:9`.
- `resolution` (اختياري): `720p` أو `1080p`.

مثال على الطلب:

```shell
curl -X POST 'https://api.acedata.cloud/veo/extend' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "model": "veo31-fast",
    "prompt": "the camera slowly zooms out to reveal more of the landscape"
  }'
```

نتيجة الاستجابة مشابهة لـ `/veo/videos`:

```json
{
  "success": true,
  "task_id": "5fa2d9a6-7e54-481b-a4b0-3dc6f25dd2ab",
  "data": [
    {
      "id": "9b6f3b6b9c45419fbf2e3fe2f10b2b3a",
      "video_url": "https://platform.cdn.acedata.cloud/veo/5fa2d9a6.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

## القيود المهمة

يجب أن يكون `video_id` من توليد خط TTAPI أو من `data[].id` بعد الانتهاء من التمديد. معرفات الفيديو التاريخية التي تم إنشاؤها بواسطة الخط القديم قبل التبديل إلى TTAPI لا يمكن استخدامها مع هذه الواجهة، وسيتم إرجاع `400 bad_request` عند الاستدعاء؛ يرجى إعادة التوليد عبر `/veo/videos` ثم التمديد.

يمكن أن يتم تمديد الفيديو الناتج من `/veo/extend` **مرة أخرى بواسطة `/veo/extend`**، ولكن **لا يمكن** معالجته بواسطة الواجهات التالية:

- `/veo/reshoot` —— لا يمكن تغيير حركة الكاميرا
- `/veo/objects` —— لا يمكن إضافة أو حذف الأجسام

إذا كان `video_id` المدخل هو نتيجة التمديد، ستعيد الواجهات ذات الصلة خطأ 400، يرجى استخدام الفيديو الأصلي كمصدر.

## توضيحات الفوترة

- `model=veo31-fast`: 1.68 ائتمان / مرة
- `model=veo31`: 12.00 ائتمان / مرة

## الاستدعاء غير المتزامن

تدعم الواجهة الوضع غير المتزامن، يمكن تمرير `callback_url` لاستدعاء النتيجة عبر طلب POST بعد إكمال المهمة. إذا لم يكن لديك عنوان استدعاء عام، يمكنك أيضًا تعيين `async` إلى `true`، وستعيد الواجهة على الفور `task_id`، ثم يمكنك الاستعلام عن النتائج عبر واجهة استعلام المهمة المعنية.
