ستتناول هذه الوثيقة توضيح تكامل واجهة برمجة تطبيقات Veo Reshoot. تُستخدم هذه الواجهة لإعادة توليد فيديو Veo تم إنشاؤه مسبقًا وفقًا لـ **طريقة حركة جديدة للكاميرا**، مع الحفاظ على محتوى الصورة كما هو، ولكن سيتم إعادة تفسير موضع الكاميرا وحركتها وفقًا لـ `motion_type`.

## عملية التقديم

لاستخدام واجهة برمجة التطبيقات، يجب أولاً التوجه إلى الصفحة المقابلة لخدمات Veo لتقديم الطلب. إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول.

## الاستخدام الأساسي

يتطلب استدعاء هذه الواجهة تمرير المعلمات التالية:

- `video_id` (مطلوب): معرف مهمة الفيديو المصدر. **لا يمكن** أن يكون الفيديو الناتج من `/veo/extend`.
- `motion_type` (مطلوب): طريقة حركة الكاميرا الجديدة، باستخدام اختصار بسيط بأسلوب الحروف الكبيرة والفواصل السفلية.

### القيم المدعومة لـ `motion_type`

| الاختصار                          | المعنى           |
| ------------------------------ | ------------ |
| `STATIONARY`                   | الكاميرا ثابتة       |
| `STATIONARY_UP`                | الكاميرا ثابتة، مائلة لأعلى    |
| `STATIONARY_DOWN`              | الكاميرا ثابتة، مائلة لأسفل    |
| `STATIONARY_LEFT`              | الكاميرا ثابتة، مائلة لليسار      |
| `STATIONARY_RIGHT`             | الكاميرا ثابتة، مائلة لليمين      |
| `STATIONARY_DOLLY_IN_ZOOM_OUT` | الكاميرا ثابتة، دفع للأمام + زوم للخارج |
| `STATIONARY_DOLLY_OUT_ZOOM_IN` | الكاميرا ثابتة، تراجع للخلف + زوم للداخل |
| `UP`                           | الكاميرا ترتفع         |
| `DOWN`                         | الكاميرا تنخفض         |
| `LEFT_TO_RIGHT`                | الكاميرا تتحرك من اليسار إلى اليمين     |
| `RIGHT_TO_LEFT`                | الكاميرا تتحرك من اليمين إلى اليسار     |
| `FORWARD`                      | الكاميرا تتحرك للأمام       |
| `BACKWARD`                     | الكاميرا تتحرك للخلف        |
| `DOLLY_IN_ZOOM_OUT`            | أثناء الحركة دفع للأمام + زوم للخارج   |
| `DOLLY_OUT_ZOOM_IN`            | أثناء الحركة تراجع للخلف + زوم للداخل   |

مثال على الطلب:

```shell
curl -X POST 'https://api.acedata.cloud/veo/reshoot' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "motion_type": "LEFT_TO_RIGHT"
  }'
```

هيكل نتيجة العودة مشابه لـ `/veo/videos`.

## توضيح الفوترة

- إعادة التصوير لمرة واحدة: 1.20 رصيد.

## الاستدعاء غير المتزامن

تدعم الواجهة وضع غير متزامن، حيث يمكنك تمرير `callback_url` لاستدعاء النتيجة عبر طلب POST بعد اكتمال المهمة. إذا لم يكن لديك عنوان استدعاء عام، يمكنك أيضًا تعيين `async` إلى `true`، وستقوم الواجهة بإرجاع `task_id` على الفور، ثم يمكنك الاستعلام عن النتائج من خلال واجهة استعلام المهمة المقابلة.
