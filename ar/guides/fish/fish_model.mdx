هذا الواجهة تعتمد على [واجهة Model API الرسمية من Fish Audio](https://docs.fish.audio/resources/api-reference/model)، لإنشاء **نموذج صوتي قابل للاستخدام طويل الأمد بناءً على عينة صوتية**. العنوان هو `POST https://api.acedata.cloud/fish/model`.

> إذا كنت بحاجة لاستخدام صوت مرجعي بشكل مؤقت، فلا حاجة لإنشاء نموذج، يمكنك استخدام [واجهة Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) لـ `references` لنسخ فوري لمرة واحدة. لاسترجاع الأصوات الموجودة، يرجى الرجوع إلى [واجهة Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query)؛ للاستعلام عن تفاصيل صوت واحد حسب `_id`، يرجى الرجوع إلى [واجهة Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## عملية التقديم

لاستخدام Fish Model API، يجب أولاً الذهاب إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، احتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، سيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد الانتهاء، سيتم إرجاعك تلقائيًا إلى الصفحة الحالية.

**رمز API واحد يكفي لاستدعاء جميع خدمات المنصة، ولا حاجة لتقديم طلب منفصل لكل خدمة.** عند التقديم لأول مرة، ستحصل على رصيد مجاني لتجربته؛ إذا كان الرصيد غير كافٍ، يمكنك إعادة شحن الرصيد العام في [لوحة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## حقول جسم الطلب

| الحقل                      | النوع       | مطلوب  | الشرح                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | نعم   | اسم الصوت، يستخدم للتعرف عليه في قائمة لوحة التحكم.                                                             |
| `voices`                | string   | نعم   | عنوان URL لعينة الصوت HTTP(S) (**سلسلة واحدة**، ليست مصفوفة). هذه الواجهة لا تدعم تحميل multipart/ثنائي، يرجى وضع الصوت في أي تخزين كائن يمكن الوصول إليه علنًا. |
| `description`           | string   | لا    | وصف الصوت.                                                                         |
| `cover_image`           | string   | لا    | عنوان URL لصورة الغلاف HTTP(S).                                                              |
| `tags`                  | string[] | لا    | علامات البحث في المكتبة العامة، مثل `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | لا    | نصوص مرجعية تتوافق مع العينة (لإصلاح النطق).                                                           |
| `enhance_audio_quality` | boolean  | لا    | هل يجب تحسين جودة العينة قبل التدريب.                                                                |
| `generate_sample`       | boolean  | لا    | هل يجب إنشاء عينة صوتية تلقائيًا بعد الانتهاء من التدريب.                                                            |

> الحقول متطابقة تمامًا مع المصدر، يرجى الرجوع أيضًا إلى [الوثائق الرسمية من Fish](https://docs.fish.audio/resources/api-reference/model).

## مثال: إنشاء صوت مستنسخ خاص

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "صوتي المستنسخ",
    "description": "صوت صيني مستنسخ من تسجيل بودكاست",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> ملاحظة: يجب أن يكون `voices` **سلسلة** (عنوان URL صوتي واحد)، وليس مصفوفة. إذا تم تمريرها كـ `["..."]`، سيتم رفضها من المصدر.

الاستجابة الناجحة تعيد مباشرة كائن ModelEntity من منصة Fish (فيما يلي مثال على أقل صوت قابل للاستخدام تم اختباره، مع حذف بعض الحقول الطويلة لتسهيل القراءة):

  "description": "smoke test from api.acedata.cloud",

`_id` يمكن استخدامه كقيمة لحقل `reference_id` في [واجهة Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) لاستخدام هذا الصوت المستنسخ في توليد الصوت:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "مرحبًا، هذه عبارة تم توليدها باستخدام صوتي المستنسخ الذي أنشأته للتو.",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## متطلبات العينة

قيم الخبرة (مطابقة للمصدر، يمكن الرجوع إلى [الوثائق الرسمية من Fish](https://docs.fish.audio/resources/api-reference/model)):

- يُفضل أن تكون المدة أكثر من 30 ثانية وأقل من 5 دقائق؛ أكثر من 10 دقائق لا تعطي فائدة كبيرة.
- معدل العينة 16 كيلوهرتز أو أعلى، يمكن أن تكون أحادية أو استريو.
- يجب أن تكون المحتويات نظيفة: بدون موسيقى خلفية، صدى، ضوضاء بيئية واضحة؛ نفس المتحدث.
- يُفضل أن تكون الصيغة `mp3` / `wav`.

إذا لم تكن متأكدًا من جودة العينة، يمكنك تمرير `enhance_audio_quality: true` للسماح للمصدر بتحسين الجودة أولاً.

## توضيح الفوترة

إنشاء نموذج صوت مستنسخ (`POST /fish/model`) مجاني، ولا يتم فرض أي رسوم؛ واجهات استعلام الصوت (`[Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)، [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)`) أيضًا لا تتطلب رسوم. الرسوم تُفرض فقط عند استدعاء [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) لتوليد الصوت بناءً على الاستخدام.

## معالجة الأخطاء
- `400 token_mismatched`：طلب المعلمات مفقود أو غير صالح (الأكثر شيوعًا هو أن `voices` ليست URL، أو تم تمريرها كمصفوفة).
- `401 invalid_token`：رمز المصادقة غير موجود أو غير صالح.
- `429 too_many_requests`：تم تفعيل حد معدل الحساب.
- `500 api_error`：خطأ داخلي في الخادم.

مثال على استجابة الخطأ:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## الاستنتاج

استدعاء هذه الواجهة يتطلب فقط إعداد عنوان URL لعينة صوتية يمكن الوصول إليها علنًا، وضعه في حقل `voices` للحصول على `_id`، ثم تقديمه إلى `reference_id` في `/fish/tts` لإكمال عملية "استنساخ → تركيب" من النهاية إلى النهاية. النقطة الشائعة هي أن `voices` يجب أن تكون سلسلة نصية، ولا يمكن أن تكون مصفوفة.
