تعتمد هذه الواجهة على [واجهة Model API الرسمية لـ Fish Audio](https://docs.fish.audio/resources/api-reference/model)، وتُستخدم **لإنشاء نموذج صوت مستنسخ قابل لإعادة الاستخدام على المدى الطويل استنادًا إلى عينة صوتية**. العنوان هو `POST https://api.acedata.cloud/fish/model`.

> عند الحاجة إلى استخدام صوت مرجعي مؤقتًا فقط، لا حاجة إلى إنشاء نموذج، ويمكن استخدام الاستنساخ الفوري لمرة واحدة عبر `references` في [واجهة Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) مباشرةً. لاسترجاع الأصوات الموجودة عبر صفحات، يرجى الرجوع إلى [واجهة Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query)؛ وللاستعلام عن تفاصيل صوت واحد حسب `_id`، يرجى الرجوع إلى [واجهة Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## عملية التقديم

لاستخدام Fish Model API، انتقل أولًا إلى [وحدة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على API Token الخاص بك، واحتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تقم بتسجيل الدخول أو التسجيل بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وبعد الإكمال ستعود تلقائيًا إلى الصفحة الحالية.

**يمكن لـ API Token واحد استدعاء جميع خدمات المنصة، ولا حاجة إلى تقديم طلب منفصل لكل خدمة.** سيُمنح رصيد مجاني عند التقديم لأول مرة، ويمكنك التجربة مجانًا؛ وعندما يكون الرصيد غير كافٍ، يمكنك شحن الرصيد العام من [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## حقول نص الطلب

| الحقل                      | النوع       | مطلوب  | الوصف                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | نعم   | اسم الصوت، يُستخدم للتعرّف عليه في قائمة وحدة التحكم.                                                             |
| `voices`                | string   | نعم   | عنوان URL عبر HTTP(S) لعينة الصوت (**سلسلة نصية واحدة**، وليست مصفوفة). لا تدعم هذه الواجهة رفع multipart/ثنائي، يرجى وضع الصوت أولًا في أي تخزين كائنات قابل للوصول العام. |
| `description`           | string   | لا   | وصف الصوت.                                                                         |
| `cover_image`           | string   | لا   | عنوان URL عبر HTTP(S) لصورة الغلاف.                                                              |
| `tags`                  | string[] | لا   | علامات البحث في المكتبة العامة، مثل `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | لا   | النصوص المرجعية المقابلة للعينات (تُستخدم لتصحيح النطق).                                                           |
| `enhance_audio_quality` | boolean  | لا   | ما إذا كان سيتم تحسين جودة صوت العينة قبل التدريب.                                                                |
| `generate_sample`       | boolean  | لا   | ما إذا كان سيتم إنشاء مقطع صوتي نموذجي تلقائيًا بعد اكتمال التدريب.                                                            |

> لمزيد من المعلومات حول نماذج الأصوات، يمكن الرجوع إلى [وثائق Fish الرسمية](https://docs.fish.audio/resources/api-reference/model).

> سيتم حفظ الصوت الذي تم إنشاؤه علنًا على المدى الطويل، وقد يبحث عنه مستخدمون آخرون ويستخدمونه. لا حاجة إلى تمرير `visibility`؛ حتى عند تمرير `private` أو `unlist`، لن تغيّر الواجهة الحالية نطاق النشر بناءً على ذلك.

## مثال: إنشاء صوت مستنسخ عام

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的中文音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> ملاحظة: يجب أن يكون `voices` **سلسلة نصية** (رابط URL صوتي واحد)، وليس مصفوفة. لا يُدعم تمرير `["..."]`. يُنصح باستخدام روابط مباشرة قابلة للتنزيل بشكل عام وتنتهي باللاحقة `.mp3` أو `.wav`.

تُرجع الاستجابة الناجحة مباشرةً كائن ModelEntity الخاص بمنصة Fish (المثال التالي هو الحد الأدنى من الصوت القابل للاستخدام الذي اختبرناه؛ وقد حُذفت بعض الحقول الطويلة لتسهيل القراءة):

```json
{
  "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
  "type": "tts",
  "title": "copilot-smoke-test",
  "description": "smoke test from api.acedata.cloud",
  "cover_image": "coverimage/e5c6db52c3ed417f9cb2e5a33fb04667",
  "train_mode": "fast",

    }
  ],
  "created_at": "2026-05-10T03:52:55.601000Z",
```

يمكن استخدام `_id` كقيمة للحقل `reference_id` في [واجهة Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) اللاحقة، لاستخدام هذا الصوت المستنسخ في تركيب الكلام:

يتم حفظ الصوت الذي تم إنشاؤه بنجاح بشكل عام. يمكنك استخدام `self=true` في [واجهة Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query) للاستعلام عن الأصوات التي أنشأها المستخدم الحالي عبر هذه المنصة. يعمل `self=true` على تصفية القائمة فقط، ولا يمنع المستخدمين الآخرين من استخدام هذا الصوت.

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，这是一段使用我刚创建的克隆音色合成的语音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## متطلبات العينة

التوصيات المرجعية (للتفاصيل، راجع [وثائق Fish الرسمية](https://docs.fish.audio/resources/api-reference/model)):

- يُنصح بأن تكون المدة 30 ثانية أو أكثر، وتكون النتائج أفضل ضمن 5 دقائق؛ أما ما يتجاوز 10 دقائق فالفائدة الإضافية محدودة.
- معدل أخذ عينات يبلغ 16 كيلوهرتز أو أعلى، مع إمكانية استخدام الصوت الأحادي أو الاستريو.
- اجعل المحتوى نظيفًا قدر الإمكان: دون موسيقى خلفية أو صدى أو ضوضاء بيئية واضحة؛ ولمتحدث واحد.
- التنسيقات الموصى بها: `mp3` / `wav`.

إذا لم تكن متأكدًا من جودة العينة، يمكنك أيضًا تمرير `enhance_audio_quality: true` لتفعيل تحسين جودة الصوت.

## تعليمات الفوترة
إنشاء نموذج استنساخ صوتي (`POST /fish/model`) مجاني ولا يترتب عليه أي رسوم؛ كما أن واجهات الاستعلام عن الأصوات ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)، [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) لا تُحتسب عليها رسوم أيضًا. لا تنشأ التكلفة إلا عند استدعاء [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) لاحقًا لتركيب الصوت حسب الاستخدام.

## معالجة الأخطاء

- `400 token_mismatched`: معلمات الطلب مفقودة أو غير صالحة (الأكثر شيوعًا أن `voices` ليس عنوان URL، أو تم تمريره كمصفوفة).
- `400`: عند تعذر تنزيل الصوت المرجعي، أو كان قصيرًا جدًا، أو تعذر التعرف على تنسيقه، يرجى التحقق من عنوان URL للصوت وتنسيق الملف.
- `401 invalid_token`: رمز المصادقة token غير موجود أو غير صالح.
- `429 too_many_requests`: تم تفعيل حد معدل الطلبات للحساب.
- `500 api_error`: خطأ داخلي في الخادم.

مثال على استجابة خطأ:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## الخلاصة

لاستدعاء هذه الواجهة، تحتاج فقط إلى إعداد عنوان URL لعينة صوتية يمكن الوصول إليها علنًا، ووضعه في حقل `voices` للحصول على `_id`، ثم تمريره إلى `reference_id` الخاص بـ `/fish/tts` لإكمال عملية «الاستنساخ ← التركيب» من البداية إلى النهاية. من الأخطاء الشائعة أن `voices` يجب أن يكون سلسلة نصية، ولا يمكن أن يكون مصفوفة.

## إنشاء الأصوات وإعادة استخدامها عبر MCP

استدعِ في Fish MCP:
`fish_create_model(title="صوتي", voices="https://example.com/authorized-voice.wav")`。
`voices` هو عنوان URL صوتي واحد عبر HTTP(S)؛ ويمكن أيضًا تمرير `description` و`cover_image` و`tags` و
`texts` و`enhance_audio_quality` و`generate_sample`.

ستحفظ هذه الأداة الأصوات العامة لفترة طويلة، وقد يكتشفها مستخدمون آخرون ويستخدمونها؛ لذا يُرجى استخدام
المواد الصوتية المصرح بمعالجتها ونشرها فقط. لا تحتوي الأداة على خيار خاص أو غير معلن. يُستخدم `_id` الذي يتم إرجاعه عند نجاح الإنشاء في
`reference_id` الخاص بـ `fish_generate_audio`، ويمكن لـ `fish_list_models(self=true)` الاستعلام عن الأصوات التي
حفظتها بنفسك. عند الحاجة إلى صوت مرجعي لمرة واحدة فقط، استخدم `references` الخاص بـ `fish_generate_audio`،
ولا حاجة لإنشاء صوت طويل الأمد.
