تعتمد هذه الواجهة على [Fish Audio الرسمية Model API](https://docs.fish.audio/resources/api-reference/model)، وتُستخدم من أجل **استرجاع مكتبة أصوات Fish العامة أو الأصوات المستنسخة ضمن الحساب الحالي على صفحات**. العنوان هو `GET https://api.acedata.cloud/fish/model`。

> لإنشاء صوت، يُرجى الرجوع إلى [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model)؛ وللاستعلام عن تفاصيل صوت واحد حسب `_id`، يُرجى الرجوع إلى [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get)。

## إجراءات التقديم

لاستخدام Fish Model API، انتقل أولاً إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على API Token الخاص بك، واحتفظ به للاستخدام لاحقاً.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد سجلت الدخول أو أنشأت حساباً بعد، فسيتم تحويلك تلقائياً إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وبعد الإكمال ستعود تلقائياً إلى الصفحة الحالية.

**يمكن لـ API Token واحد استدعاء جميع خدمات المنصة، ولا حاجة للتقديم بشكل منفصل لكل خدمة.** سيمنحك أول تقديم رصيداً مجانياً لتجربة الخدمة مجاناً؛ وعندما لا يكون الرصيد كافياً، يمكنك شحن الرصيد العام من [لوحة التحكم](https://platform.acedata.cloud/console/coin)。

> 📘 الوثائق الكاملة: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## معلمات الاستعلام

| المعلمة             | النوع    | الافتراضي | الوصف                                                                                  |
| ---------------- | ------- | ---- | ------------------------------------------------------------------------------------- |
| `page_size`      | integer | 10   | عدد العناصر في كل صفحة.                                                                            |
| `page_number`    | integer | 1    | رقم الصفحة، يبدأ من 1.                                                                          |
| `title`          | string  | —    | بحث تقريبي حسب العنوان.                                                                      |
| `tag`            | string  | —    | التصفية حسب علامة واحدة.                                                                      |
| `self`           | boolean | —    | عند `true`، تُرجع فقط الأصوات التي أنشأها وحفظها حساب الاستدعاء الحالي عبر هذه المنصة.                                |
| `author_id`      | string  | —    | التصفية حسب معرّف مؤلف الصوت.                                                                  |
| `language`       | string  | —    | التصفية حسب لغة الصوت، مثل `en` و`zh` و`es`.                                                  |
| `title_language` | string  | —    | التصفية حسب لغة العنوان في مكتبة الأصوات العامة.                                                        |
| `sort_by`        | string  | —    | حقل الفرز؛ عند `self=true`، يدعم `created_at` و`task_count`.                              |

## المثال 1: التنقل الافتراضي بين الصفحات (حسب `page_size`)

```shell

  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=2'
```

## المثال 2: البحث التقريبي حسب العنوان (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

الإرجاع (تم اختباره فعلياً):

  "items": [

## المثال 3: عرض الأصوات التي أنشأتها بنفسك فقط (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

مثال على الإرجاع:

```json
{
  "total": 1,
  "items": [
    {
      "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
      "type": "tts",
      "title": "copilot-smoke-test",
      "description": "smoke test from api.acedata.cloud",
      "state": "trained",
      "languages": ["zh"],
      "visibility": "public",
      "samples": [
        {
          "title": "Default Sample",
          "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
          "task_id": "6a1bf398dfae49dca0e23159214342a0",
          "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
        }
      ],
      "created_at": "2026-05-10T03:52:55.601000Z",
      "author": {
        "_id": "780f2b2f862d41a08c0507bbbda77eb6",
        "nickname": "Penny Conrad"
      }
    }

```
`self=true` يسرد، وفقًا لحساب الاستدعاء الفعلي، الأصوات التي تم إنشاؤها وحفظها عبر هذه المنصة؛ كما ستُسرد معًا الأصوات التي أنشأها الحساب نفسه باستخدام API Token مختلف. تُرتَّب النتائج بترتيب زمني تنازلي حسب وقت الإنشاء مع تقسيمها إلى صفحات، ويمكن لـ `author_id` تصفية معرّف مؤلف هذه الأصوات بشكل إضافي. هذه المعلمة تصفي القائمة فقط، وتبقى الأصوات متاحة للعامة.

`self=true` لا يدعم `title_language`؛ إذا كنت بحاجة إلى البحث حسب لغة العنوان، فيُرجى الاستعلام من مكتبة الأصوات العامة.

## المثال 4: التصفية حسب اللغة + العلامة

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> تكون المطابقة باستخدام `tag` أكثر تساهلًا؛ إذا كان عدد النتائج المطابقة 0، يُنصح باستخدام المطابقة التقريبية `title`.

## حقول الاستجابة

كل عنصر في `items[]` هو كائن ModelEntity كامل، والحقول الشائعة هي:

| الحقل            | النوع       | الوصف                                        |
| ------------- | -------- | ----------------------------------------- |
| `_id`         | string   | معرّف الصوت، ويُستخدم كقيمة `reference_id` في `/fish/tts`۔ |
| `type`        | string   | نوع النموذج، وعادةً ما يكون `tts`۔                           |
| `title`       | string   | اسم الصوت۔                                     |
| `description` | string   | وصف الصوت۔                                     |
| `state`       | string   | حالة التدريب: `trained` تعني أنه متاح للاستخدام۔                      |
| `tags`        | string[] | علامات المكتبة العامة۔                                    |
| `languages`   | string[] | اللغات التي يجيدها الصوت۔                                  |
| `visibility`  | string   | `public` أو `private`۔                     |
| `samples`     | object[] | عينات مُعدّة مسبقًا (تتضمن رابط `audio` مباشرًا)۔                       |
| `like_count`  | integer  | عدد الإعجابات في المكتبة العامة۔                                   |
| `task_count`  | integer  | عدد مرات التركيب السابقة۔                                   |
| `author`      | object   | معلومات مؤلف الصوت: `_id` / `nickname` / `avatar`۔     |
| `total`（المستوى الأعلى）   | integer  | العدد الإجمالي الذي يستوفي الشروط۔                                 |
| `has_more`    | boolean? | تكون قيمة منطقية عند `self=true`؛ وقد تكون استعلامات مكتبة الأصوات العامة `null`۔      |

## توضيح الفوترة

لا تُفرض رسوم على هذه الواجهة—استعلام قائمة الأصوات عبر الصفحات عملية مجانية. إنشاء صوت ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) مجاني أيضًا، ولا تنشأ الرسوم إلا عند استدعاء [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) لتركيب الصوت حسب الاستخدام.

## معالجة الأخطاء

- `400 token_mismatched`: معلمات الطلب مفقودة أو غير صالحة.
- `401 invalid_token`: رمز token للمصادقة غير موجود أو غير صالح.
- `429 too_many_requests`: تم تفعيل حد معدل الطلبات للحساب.
- `500 api_error`: خطأ داخلي في الخادم.

مثال على استجابة خطأ:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## الخلاصة

لاختيار صوت من مكتبة Fish العامة وتمريره إلى `reference_id` الخاص بـ `/fish/tts`، استخدم هذه الواجهة أولًا مع `title` / `tag` / `language` للبحث، وحدد `_id` الهدف، ثم استخدم [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) للحصول على عينة للاستماع التجريبي. ولسرد الأصوات التي أنشأتها بنفسك، يكفي تمرير `self=true`.
