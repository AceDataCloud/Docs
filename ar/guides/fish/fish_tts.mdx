هذا الواجهة تعتمد على [Fish Audio الرسمية TTS API](https://docs.fish.audio/text-to-speech/text-to-speech)، فقط في طريقة التوثيق (باستخدام توكن هذه المنصة) والرد غير المتزامن (توسيع `callback_url`) هناك اختلاف، هيكل جسم الطلب متطابق مع المصدر. العنوان هو `POST https://api.acedata.cloud/fish/tts`.

## عملية التقديم

لاستخدام Fish TTS API، يجب أولاً الذهاب إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على توكن API الخاص بك، احتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، سيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد الانتهاء سيتم العودة تلقائيًا إلى الصفحة الحالية.

**توكن API واحد يكفي لاستدعاء جميع خدمات المنصة، ولا حاجة لتقديم طلب منفصل لكل خدمة.** عند التقديم لأول مرة، ستحصل على رصيد مجاني لتجربته؛ عند نفاد الرصيد، يمكنك إعادة شحن الرصيد العام في [لوحة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [Fish TTS API →](https://platform.acedata.cloud/services/fish)

## رأس الطلب

| Header          | مطلوب  | الشرح                                                                                                     |
| --------------- | --- | ------------------------------------------------------------------------------------------------------ |
| `authorization` | نعم   | `Bearer {token}`، `{token}` هو المفتاح الذي تم الحصول عليه من هذه المنصة.                                                                 |
| `content-type`  | نعم   | `application/json`。                                                                                    |
| `accept`        | لا    | `application/json`。                                                                                    |
| `model`         | لا    | نموذج TTS، يمكن اختيار `s1`، `s2-pro` أو `s2.1-pro`، الافتراضي هو `s2-pro`。`s2.1-pro` هو الجيل الأحدث، و`s2-pro` ذو تعبير قوي؛ `s1` أكثر استقرارًا، والنصوص الطويلة لا تخرج عن المسار بسهولة. الثلاثة بنفس السعر. |

## حقول جسم الطلب

| الحقل             | النوع                 | مطلوب  | الشرح                                                                                                                                                                         |
| -------------- | ------------------ | --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `text`         | string             | نعم   | النص المراد تركيبه، يجب أن يكون سلسلة غير فارغة.                                                                                                                                                              |
| `format`       | string             | لا    | تنسيق الصوت الناتج، يمكن اختيار `mp3` (افتراضي)، `wav`، `pcm`。`wav` و `pcm` كلاهما يعودان في حاوية WAV. `opus` غير مدعوم، إذا تم تمريره سيتم إرجاع `400` مباشرة.                                                                                      |
| `reference_id` | string \| string[] | لا    | معرف صوت مستنسخ (يمكن إنشاؤه بواسطة [Fish Model API](https://platform.acedata.cloud/documents/fish-model) أو استرجاعه في [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)). |
| `references`   | object[]           | لا    | عينات مرجعية مضمنة، الهيكل مطابق للمصدر، كل عنصر يحتوي على `audio` و `text`。مع `reference_id` أحدهما فقط.                                                                                                                  |
| `sample_rate`  | integer            | لا    | معدل العينة، الشائع هو `16000`、`22050`、`44100`。`format=mp3` الافتراضي هو 44100。                                                                                                                      |
| `mp3_bitrate`  | integer            | لا    | معدل بت MP3، يمكن اختيار `64`、`128`、`192`。يعمل فقط مع `format=mp3`。                                                                                                                              |
| `prosody`      | object             | لا    | تغطية الإيقاع، تدعم `speed` (سرعة الكلام، 1.0 هي السرعة الأصلية) و `volume` (زيادة الصوت dB). على سبيل المثال `{"speed":1.2,"volume":0}`。                                                                                              |
| `chunk_length` | integer            | لا    | طول الشظايا من المصدر، الافتراضي يحدده المصدر.                                                                                                                                                             |
| `temperature`  | number             | لا    | درجة حرارة العينة، تتراوح تقريبًا من 0.0 إلى 1.0.                                                                                                                                                          |
| `top_p`        | number             | لا    | معلمة عينة top-p.                                                                                                                                                                |
| `latency`      | string             | لا    | `normal` أو `balanced`، الافتراضي يتم ملؤه تلقائيًا بواسطة هذه الواجهة `normal` (إذا تم تمرير سلسلة فارغة، سيرفض المصدر).                                                                                                                    |
| `normalize`    | boolean            | لا    | هل يجب تطبيع النص.                                                                                                                                                                 |
| `callback_url` | string             | لا    | عنوان رد غير متزامن، انظر أدناه "الرد غير المتزامن". **هذا هو توسيع بالنسبة للواجهة الرسمية**.                                                                                                                                         |

> أسماء الحقول متطابقة تمامًا مع المصدر. باستثناء `callback_url`، المعاني والقيم الأخرى راجع [وثائق TTS الرسمية لـ Fish](https://docs.fish.audio/text-to-speech/text-to-speech).

## مثال 1: الحد الأدنى من الطلب (`text` + `format=mp3`)

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hello world.",
    "format": "mp3"
  }'
```

الرد (تم الاختبار):

```json
{
  "audio_url": "https://platform2.cdn.acedata.cloud/fish/e2ffcc06-18da-4a8c-b9aa-9337d0f9ec1d.mp3"
}
```

`audio_url` تشير إلى CDN الخاص بهذه المنصة، يمكن تنزيلها مباشرة باستخدام GET أو تشغيلها في `<audio>`。الرابط متاح لفترة طويلة، ولكن لا يزال يُنصح بالاحتفاظ بنسخة في تخزينك الخاص.

## مثال 2: استخدام صوت مستنسخ `reference_id`

فيما يلي استخدام صوت إسباني عام على منصة Fish (`_id` يمكن استرجاعه من [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)):

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

الرد (تم الاختبار):

```json
{
  "audio_url": "https://platform2.cdn.acedata.cloud/fish/b6f161f2-a100-4818-add2-47694f234659.mp3"
}
```

## مثال 3: ضبط سرعة الكلام / الصوت (`prosody`)

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Faster speech with prosody overrides.",
    "prosody": { "speed": 1.2, "volume": 0 },
    "format": "mp3"
  }'
```

الرد (تم الاختبار):

```json
{
  "audio_url": "https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"
}
```

`speed` أكبر من 1 يسرع، أقل من 1 يبطئ؛ `volume` وحدة dB، 0 تعني عدم التغيير، الأعداد الموجبة زيادة، والأعداد السالبة تقليل.

## مثال 4: تبديل النموذج + التحكم في معدل البت

من خلال رأس HTTP `model: s1` يتم التبديل إلى النموذج المستقر، أضف في جسم الطلب `mp3_bitrate: 128` للتحكم في معدل بت MP3:
```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s1' \
  -d '{
    "text": "معدل بت عالي mp3",
    "format": "mp3",
    "mp3_bitrate": 128
  }'
```

返回（实测）：

```json
{
  "audio_url": "https://platform2.cdn.acedata.cloud/fish/7e7abf3d-3d72-4c9f-8eb6-8af932d7c96e.mp3"
}
```

## مثال 5: شكل موجة PCM الأصلية

في السيناريوهات التي تحتاج إلى تجميع في الوقت الحقيقي في المتصفح، أو معالجة لاحقة على العميل (خلط، تغيير السرعة)، يُوصى باستخدام `pcm`:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "مرحبا",
    "format": "pcm",
    "sample_rate": 16000
  }'
```

返回（实测）：

```json
{
  "audio_url": "https://platform2.cdn.acedata.cloud/fish/64adc04b-c196-4a0f-9070-222ba101ce6c.wav"
}
```

> امتداد الرابط يتبع `format` في الطلب: `mp3` يحصل على `.mp3`، `wav` و `pcm` يحصلان على `.wav` (حاوية WAV، 16 بت PCM).

## ردود غير متزامنة (`callback_url`)

قد تحتاج عملية التوليد لنص طويل إلى عشرات الثواني، وإذا انقطع الاتصال يجب إعادة المحاولة. بعد إرسال `callback_url` في جسم الطلب، ستعيد الواجهة على الفور `{task_id, started_at}`، وعند الانتهاء الحقيقي من المعالجة، سيتم إرسال النتيجة الكاملة إلى هذا الرابط بصيغة POST JSON، مع تضمين نفس `task_id` في جسم الطلب.

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "الجو اليوم جميل، دعنا نخرج للتنزه.",
    "format": "mp3",
    "callback_url": "https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34"
  }'
```

立即返回（实测）：

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "started_at": "2026-05-11T01:23:04.742Z"
}
```

稍后 `callback_url` 会收到形如：

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "audio_url": "https://platform2.cdn.acedata.cloud/fish/bd66b8c5-7543-4557-b684-baa72407e336.mp3"
}
```

يمكنك أيضًا استخدام [Fish Tasks API](https://platform.acedata.cloud/documents/fish-tasks) لسحب النتائج حسب `task_id`، راجع الوثيقة لذلك.

## معالجة الأخطاء

- `400 token_mismatched`: معلمات الطلب مفقودة أو غير صالحة (الأكثر شيوعًا هو أن `text` فارغ، أو تم تمرير قيمة غير `mp3`/`wav`/`pcm` لـ `format`).
- `401 invalid_token`: رمز المصادقة غير موجود أو غير صالح.
- `429 too_many_requests`: تم تفعيل حد معدل الحساب.
- `500 api_error`: خطأ داخلي في الخادم.

مثال على استجابة الخطأ:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "فشل في الاسترجاع"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

أخطاء التحقق من المعلمات ستضع نص الخطأ الأصلي من pydantic في حقل `message`، لتسهيل تحديد أي حقل غير صالح، مثل:

```json
{
  "status": 400,
  "message": "[{\"type\":\"literal_error\",\"loc\":[\"format\"],\"msg\":\"الإدخال يجب أن يكون 'pcm' أو 'mp3'\",\"input\":\"wav\"}]"
}
```

## الاستنتاج

أقل تكلفة لدمج Fish TTS هي: في الشيفرة الموجودة التي تستدعي `api.fish.audio/v1/tts`، استبدل المصادقة برمز المنصة، وأضف في جسم الطلب **بوضوح** `format: "mp3"` . في سيناريو النصوص الطويلة، يُوصى باستخدام `callback_url` للرد غير المتزامن؛ لاكتشاف صوت النسخ `reference_id`، يُرجى استخدام [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) و [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get).
