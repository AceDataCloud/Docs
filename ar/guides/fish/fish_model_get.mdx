هذه الواجهة تعتمد على [واجهة Model API الرسمية من Fish Audio](https://docs.fish.audio/resources/api-reference/model) ، وتستخدم **للاستعلام عن تفاصيل كاملة لنغمة استنساخ واحدة حسب `_id`**. العنوان هو `GET https://api.acedata.cloud/fish/model/{id}`.

> لإنشاء نغمة، يرجى الرجوع إلى [واجهة Fish Model Create API](https://platform.acedata.cloud/documents/fish-model)؛ وللاستعلام عن الصفحات، يرجى الرجوع إلى [واجهة Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query).

## عملية التقديم

لاستخدام واجهة Fish Model API، يجب أولاً الذهاب إلى [وحدة التحكم في Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، احتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، سيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد الانتهاء، سيتم العودة تلقائيًا إلى الصفحة الحالية.

**يمكن استخدام رمز API واحد لاستدعاء جميع خدمات المنصة، ولا حاجة لتقديم طلب منفصل لكل خدمة.** عند التقديم لأول مرة، ستحصل على رصيد مجاني لتجربته؛ وعند نفاد الرصيد، يمكنك إعادة شحن الرصيد العام في [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## معلمات المسار

| المعلمة | إلزامية | الشرح                                                                                                                                                                                                |
| ---- | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id` | نعم  | `_id` للنغمة (سلسلة سداسية عشرية مكونة من 32 حرفًا). يمكن الحصول عليه عند إنشاء [Fish Model Create](https://platform.acedata.cloud/documents/fish-model) أو من خلال [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query). |

لا يوجد جسم طلب، ولا معلمات استعلام.

## مثال: سحب تفاصيل كاملة لنغمة إسبانية عامة

```shell
curl 'https://api.acedata.cloud/fish/model/8d2c17a9b26d4d83888ea67a1ee565b2' \
  -H 'authorization: Bearer {token}'
```

يمكنك استخدام `_id` الذي حصلت عليه مباشرة في `reference_id` لـ [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) لتوليد صوت بنفس النغمة:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "إخواني، اليوم هو يوم جيد.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

## الاختلافات مع واجهة القائمة

| الحقل                                               | `GET /fish/model` (قائمة) | `GET /fish/model/{id}` (تفاصيل) |
| -------------------------------------------------- | --------------------- | -------------------------- |
| `samples[].audio`                                  | رابط R2 مؤقت            | رابط مباشر موقّع من R2 (بما في ذلك توقيع الاستعلام)      |
| `unliked` / `liked` / `marked` / `dmca_taken_down` | موجودة أيضًا            | موجودة أيضًا                       |
| `default_text` / `lock_visibility`                 | موجودة أيضًا            | موجودة أيضًا                       |

إذا كنت ترغب فقط في الاستماع، فإن `samples[].audio` في واجهة القائمة كافية؛ للحصول على رابط تنزيل أكثر استقرارًا، يُنصح باستخدام هذه الواجهة.

## حقول الاستجابة (مقتطفات)

| الحقل            | النوع       | الشرح                                          |
| ------------- | -------- | ------------------------------------------- |
| `_id`         | string   | معرف النغمة (يستخدم في `reference_id` لـ `/fish/tts`).     |
| `type`        | string   | نوع النموذج، عادةً ما يكون `tts`.                             |
| `title`       | string   | اسم النغمة.                                       |
| `description` | string   | وصف طويل.                                        |
| `state`       | string   | حالة التدريب: `trained` تعني متاحة، `training` تعني لا تزال قيد التدريب.      |
| `tags`        | string[] | علامات المكتبة العامة.                                      |
| `samples`     | object[] | عينات مسبقة، تحتوي على `title`، `text`، `task_id`، `audio` رابط مباشر. |
| `languages`   | string[] | رموز اللغات التي تتقنها النغمة.                                  |
| `visibility`  | string   | `public` أو `private`.                       |
| `like_count`  | integer  | عدد الإعجابات في المكتبة العامة.                                     |
| `task_count`  | integer  | عدد مرات التوليد التاريخية (يمكن استخدامها كمرجع لترتيب الشعبية).                          |
| `author`      | object   | معلومات المؤلف: `_id` / `nickname` / `avatar`.       |
| `created_at`  | string   | وقت الإنشاء بصيغة ISO 8601.                              |
| `updated_at`  | string   | آخر وقت تحديث بصيغة ISO 8601.                            |

## توضيح الفوترة

هذه الواجهة لا تتطلب رسوم - الاستعلام عن تفاصيل نغمة واحدة حسب ID هو عملية مجانية. إنشاء نغمة ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) أيضًا مجاني، وتُفرض الرسوم فقط عند استدعاء [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) لتوليد الصوت حسب الاستخدام.

## معالجة الأخطاء
- `400 token_mismatched`：المعرف في المسار ليس بتنسيق قانوني، أو تم الإبلاغ من قبل المصدر "النموذج غير موجود".
- `401 invalid_token`：رمز المصادقة غير موجود أو غير صالح.
- `404 not_found`：المعرف المحدد `_id` غير مرئي في Fish (تم حذف الصوت، أو خاص، أو ينتمي إلى حساب آخر).
- `429 too_many_requests`：تم تفعيل حد معدل الحساب.
- `500 api_error`：خطأ داخلي في الخادم.

عند الطلب فعليًا لمعرف غير موجود، سيقوم المصدر بإرجاع `400 Model not found` مباشرةً (تم الاختبار):

```shell
curl 'https://api.acedata.cloud/fish/model/test123' \
  -H 'authorization: Bearer {token}'
```

الإرجاع:

```json
{ "status": 400, "message": "Model not found" }
```

مثال على استجابة الخطأ:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## الاستنتاج

عند معرفة الصوت `_id`، استخدم هذا الواجهة للحصول على ModelEntity كاملة، وأشهر الاستخدامات هي: (1) الاستماع إلى `samples[].audio`، (2) إطعام `_id` إلى `reference_id` في `/fish/tts` لإكمال التركيب. إذا كان لديك فقط عنوان أو علامات، يرجى استخدام [استعلام نموذج Fish](https://platform.acedata.cloud/documents/fish-model-query) للبحث.
