استخدم `POST /tripo/models` لمعالجة نموذج موجود، مع تمرير `action` المطلوب. المزامنة، وعدم المزامنة، وعمليات رد النداء، وملكية الحساب، والاستعلام عن المهام مماثلة لتوليد النماذج ثلاثية الأبعاد.

| action | الإدخال | النتيجة |
| ------- | ----------------------------------------------------------------- | -------------------------------------------------------------------- |
| import | `model_url`، ملف GLB أو GLTF أو FBX أو OBJ أو STL متاح عبر HTTPS العام، بحد أقصى 150 MiB | معرّف نموذج وملف GLB يمكن الرجوع إليهما لاحقًا؛ وتُعاد `normalize_scale` و`normalize_translation` عند توفر البيانات |
| texture | `model_id` أو `model_url`؛ واختياريًا أحد `prompt` أو `image_url` أو `image_urls` | نموذج جديد وخامة ومعاينة اختيارية |
| convert | `model_id` أو `model_url`، بالإضافة إلى `format` المستهدف | ملف النموذج بعد التحويل |

```json
{"action":"texture","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","prompt":"蓝色哑光表面","texture_quality":"standard","async":true}
```

تدعم جودة الخامة القيم `fast` و`standard` و`detailed` و`extreme`. عند استخدام توجيه نصي، يمكن إضافة `style_image_url`؛ وتتبع الصور والمراجع متعددة المناظير تنسيق واجهة التوليد. راجع OpenAPI لمزيد من معلمات الخامة.

يدعم التحويل `GLTF` و`FBX` و`USDZ` و`OBJ` و`STL` و`3MF`. يشير `format` في العنصر المُعاد إلى صيغة التسليم الفعلية؛ فعلى سبيل المثال، قد يؤدي طلب GLTF إلى تسليم GLB ثنائي. تُحزم مواد OBJ وخرائطه في ملف ZIP. عند طلب FBX، اضبط `texture_packaging: "zip"` للحصول على خرائط منفصلة، ويُشار إلى النتيجة المعبأة بـ `container: "ZIP"`. قد يؤدي تفعيل إعدادات غير افتراضية للشبكة أو الخامة إلى احتساب رسوم التحويل المتقدم، راجع أسعار الخدمة للتفاصيل.

استخدم `data[0].id` للإشارة إلى نموذج في هذا الحساب، ويحقق تحويل التطبيع المستورد العلاقة `normalized = original × normalize_scale + normalize_translation`. يوجد رابط تنزيل النموذج في `data[0].model_url`.
