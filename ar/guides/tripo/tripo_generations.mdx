---
title: "إنشاء نماذج Tripo 3D"
description: "Tripo 3D API guide - Ace Data Cloud"
---

استدعِ `POST /tripo/generations` لإنشاء نموذج جديد، مع تمرير نص أو صورة واحدة أو عدة زوايا للعنصر نفسه. استخدم رمز AceDataCloud، وتُعاد النتيجة افتراضيًا بشكل متزامن. عند تمرير `async: true` أو `callback_url`، يُعاد أولًا HTTP 200 و`task_id`. تحمل نتيجة ردّ الاتصال عند الاكتمال بنية JSON نفسها التي تحملها النتيجة المتزامنة.

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

القيمة الافتراضية لـ `action` هي `generate`. اختر أحد المدخلات الثلاثة: `prompt` ‏(من 1 إلى 1024 حرفًا)، أو `image_url`، أو `image_urls`. يجب أن تكون الصور عامة، بصيغة PNG/JPEG ومتاحة عبر HTTPS، وألا يتجاوز حجمها 20 MiB. تُرتّب طرق العرض المتعددة حسب الأمام واليسار والخلف واليمين، ويجب توفير الواجهة الأمامية وواجهة أخرى واحدة على الأقل، ويمكن استخدام null لتجاوز زوايا العرض الوسطى.

القيمة الافتراضية لـ `model` هي `v3.1-20260211`، ويمكن أيضًا اختيار `v3.0-20250812` أو `v2.5-20250123` أو `P1-20260311` أو `P2-20260801` صراحةً. القيمة الافتراضية لـ `texture` هي `standard`، واستخدم `none` للهندسة فقط. تستهلك النماذج ومستويات النسيج المختلفة حصصًا مختلفة.

نزّل ملف GLB من `data[0].model_url`، ويمثل `image_url` معاينة اختيارية. احتفظ بـ `data[0].id` لاستخدامه لاحقًا في عمليات النسيج أو التحويل أو الهيكل العظمي. عند إعادة محاولة الإرسال نفسه، احتفظ بقيمة `Idempotency-Key` نفسها ونص الطلب نفسه.
