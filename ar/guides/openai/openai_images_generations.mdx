## 1. الحصول على مفتاح API

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، انتقل إلى التطبيقات المتاحة وانسخ مفتاح API.

![الحصول على مفتاح API من Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. إرسال الطلب الأول

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer مفتاح API الخاص بك" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "توضيح منتج تحريري بسيط: كوب قهوة سيراميك أبيض عادي في وسط طاولة زرقاء كوبالت صلبة، خلفية كريمية فاتحة، ظل ناعم، أشكال هندسية نظيفة، بدون نص، بدون شعار، تكوين عمودي",
    "size": "1024x1536"
  }'
```

الصورة المستجيبة الناجحة موجودة في `data[].url`. فيما يلي نتيجة 1024×1536 التي تم الحصول عليها من طلب فعلي عبر Ace Data Cloud في 8 سبتمبر 2026 (المهمة `d56455e2-e7f7-4bcd-b935-475b0a1e0948`، تتبع `eb938601-8192-407f-b539-1e0554b697ec`):

![كوب القهوة الأبيض الذي تم إنشاؤه بواسطة GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. المعلمات الشائعة

| الحقل                | الوصف                                                                     |
| ----------------- | ---------------------------------------------------------------------- |
| `model`           | استخدم `gpt-image-2`؛ يمكن أيضًا اختيار `gpt-image-2:official` أو `gpt-image-2:reverse` بشكل صريح |
| `prompt`          | وصف الصورة، بحد أقصى 32,000 حرف                                                     |
| `size`            | `auto` أو `WIDTHxHEIGHT`؛ يجب أن تكون الأبعاد مضاعفات 16، وألا يتجاوز الطول 3840، وإجمالي البكسلات 8,294,400        |
| `n`               | 1–10؛ يدعم فقط 1 عند استخدام `response_format=b64_json`                                 |
| `quality`         | `low`، `medium`، `high` أو `auto`؛ تختلف طرق الدعم والفوترة حسب الخطوط المختلفة                          |
| `response_format` | `url` أو `b64_json`                                                     |
| `callback_url`    | اختياري؛ إرسال النتائج إلى هذا العنوان بعد الانتهاء من المهام الطويلة                                                      |

الأحجام الشائعة:

| النسبة   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` سيختار الأبعاد بناءً على النسبة، البكسلات، ونية التنسيق في النص؛ عند الحاجة إلى بكسلات دقيقة، اكتب الأبعاد مباشرة.

## 4. توليد عدة صور

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer مفتاح API الخاص بك" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "ثعلب صغير يقرأ تحت فطر متوهج، توضيح بالألوان المائية",
    "size": "1536x1024",
    "n": 2
  }'
```

يتم احتساب `gpt-image-2` الافتراضي و`:reverse` بناءً على عدد الصور الناجحة؛ بينما يتم تسوية `gpt-image-2:official` بناءً على المدخلات النصية والصور الناتجة في الاستجابة. الأسعار المعروضة هي تقديرات قبل الطلب، والنهائية تعتمد على سجلات الاستخدام.

## 5. ردود غير متزامنة

بعد إضافة `callback_url` إلى جسم الطلب، ستعيد الواجهة أولاً `{"task_id": "..."}`، وعند الانتهاء، سترسل النتيجة النهائية إلى هذا URL عبر POST؛ لا يزال الطلب المتزامن يعيد `created` و`data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "ملصق منتج مع طباعة واضحة",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

يجب على جهة استقبال الردود استخدام `task_id` لإزالة التكرار، والتحقق من مصدر الطلب وتنسيق البيانات.

## 6. استكشاف الأخطاء

| الحالة  | الفحص                                                  |
| --- | --------------------------------------------------- |
| 400 | مجموعة `model`، `prompt`، تنسيق الحجم، `n` و`response_format`    |
| 401 | هل مفتاح API كامل، هل الرأس هو `Authorization: Bearer ...` |
| 429 | الطلبات متكررة للغاية، يرجى المحاولة لاحقًا                                         |
| 504 | تجاوز الوقت المخصص للتوليد المتزامن؛ استخدم `callback_url`                            |

ستحتوي الاستجابة الخطأ على `error.code`، `error.message` و`trace_id`. عند الإبلاغ عن مشكلة، قدم `trace_id`، ولا تقدم مفتاح API.

تكون الحقول الكاملة والتعدادات الحية وفقًا لصفحة [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). لمزيد من المعلومات حول تحرير الصور، يرجى مراجعة [تحرير الصور باستخدام GPT Image 2](https://platform.acedata.cloud/documents/openai-images-edits).
