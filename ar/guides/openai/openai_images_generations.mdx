## 1. الحصول على API Key

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، وادخل إلى التطبيق المتاح وانسخ API Key.

![الحصول على Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. إرسال أول طلب

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

توجد الصورة في الاستجابة الناجحة ضمن `data[].url`۔ فيما يلي نتيجة 1024×1536 التي تم الحصول عليها من خلال طلب فعلي عبر Ace Data Cloud بتاريخ 8 سبتمبر 2026 (المهمة `d56455e2-e7f7-4bcd-b935-475b0a1e0948`، والتتبّع `eb938601-8192-407f-b539-1e0554b697ec`):

![كوب أبيض تم إنشاؤه بواسطة GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. المعلمات الشائعة

| الحقل                | الوصف                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (موصى به افتراضيًا)، أو `gpt-image-2.5-flare` (أسرع)، أو `gpt-image-2.5-sunburst` (دقة وتحكم أعلى)؛ يمكن للثلاثة جميعًا اختيار متغير `:official` المقابل، كما يدعم `gpt-image-2` أيضًا `:reverse` |
| `prompt`          | وصف الصورة، بحد أقصى 32,000 حرف                                                                                                                     |
| `size`            | `auto` أو `WIDTHxHEIGHT`؛ يجب أن يكون العرض والارتفاع من مضاعفات 16، وألا يتجاوز الضلع الأطول 3840، وإجمالي البكسلات هو 655,360–8,294,400، وألا تتجاوز نسبة العرض إلى الارتفاع 3:1                                                       |
| `n`               | 1–10؛ عند `response_format=b64_json` يتم دعم 1 فقط                                                                                                 |
| `quality`         | تدعم نماذج GPT Image القيم `auto` و`low` و`medium` و`high`؛ وتدعم Flare / Sunburst 2.5 / 2.6 (بما في ذلك `:official`) أيضًا `xhigh` و`max`. يتم احتساب رسوم القناة الرسمية وفقًا لاستهلاك Token الفعلي             |
| `response_format` | `url` أو `b64_json`                                                                                                                     |
| `callback_url`    | اختياري؛ إرسال النتيجة إلى هذا العنوان بعد اكتمال المهمة الطويلة                                                                                                                      |

الأحجام الشائعة:

| النسبة   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

سيختار `size: "auto"` أبعاد الصورة بناءً على النسبة والبكسلات ونية التخطيط في نص المطالبة؛ عند الحاجة إلى بكسلات دقيقة، اكتب الأبعاد مباشرةً.

| `gpt-image-2.6-sunburst:reverse`  | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.6-sunburst`، بفوترة ثابتة حسب عدد الصور الناجحة |
| `gpt-image-2.5-sunburst:official` | قناة API رسمية، باستقرار أعلى وتركيز على الدقة العالية والتحكم التفصيلي، وفوترة حسب استهلاك Token الفعلي        |
| `gpt-image-2.6-sunburst:official` | قناة API رسمية، باستقرار أعلى وتركيز على الدقة العالية والتحكم التفصيلي، وفوترة حسب استهلاك Token الفعلي        |

قد تستخدم الطرازات العكسية 2.0 / 2.5 (بما في ذلك الأسماء المستعارة `:reverse`) GPT Image 2.5 Flare لإكمال الطلب عند الاستعادة التلقائية؛ ويبقى طراز الطلب وطريقة الفوترة حسب عدد الصور الناجحة دون تغيير.

سعر الصفحة لقناة API الرسمية هو تقدير قبل الطلب، وتكون الأولوية النهائية لاستهلاك Token الفعلي وسجل الاستخدام في الاستجابة.

## 4. توليد صور متعددة

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
تتم محاسبة `gpt-image-2` و`gpt-image-2.5-flare` و`gpt-image-2.5-sunburst` وأسماءها المستعارة `:reverse` حسب عدد الصور الناجحة؛ بينما تتم تسوية `gpt-image-2:official` و`gpt-image-2.5-flare:official` و`gpt-image-2.5-sunburst:official` بناءً على وحدات Token الفعلية لمدخلات النص ومخرجات الصور في الاستجابة. أسعار الصفحة هي تقديرات قبل الطلب، ويُعتمد سجل الاستخدام النهائي.

## 5. رد الاتصال غير المتزامن

بعد إضافة `callback_url` إلى نص الطلب، ستُرجع الواجهة أولاً `{"task_id": "..."}`، وعند الاكتمال سترسل النتيجة النهائية عبر POST إلى ذلك العنوان URL؛ بينما تظل الطلبات المتزامنة تُرجع `created` و`data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

ينبغي على مستلِم رد الاتصال استخدام `task_id` لإزالة التكرار، والتحقق من مصدر الطلب وتنسيق البيانات.

## 6. استكشاف الأخطاء وإصلاحها

| الحالة  | التحقق                                                  |
| --- | --------------------------------------------------- |
| 400 | تركيبة `model` و`prompt` وتنسيق الحجم و`n` و`response_format`    |
| 401 | ما إذا كان مفتاح API كاملاً، وما إذا كان Header هو `Authorization: Bearer ...` |
| 429 | الطلبات متكررة جداً، أعد المحاولة لاحقاً                                         |
| 504 | انتهت مهلة التوليد المتزامن؛ استخدم `callback_url`                            |

ستتضمن استجابة الخطأ `error.code` و`error.message` و`trace_id`۔ عند الإبلاغ عن مشكلة، قدّم `trace_id`، ولا تقدّم مفتاح API.

تعتمد الحقول الكاملة والقيم المعدودة في الوقت الفعلي على صفحة [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). لتحرير الصور، راجع [تحرير الصور GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-edits).

## GPT Image 2.6

يستخدم GPT Image 2.6 واجهات التوليد والتحرير والمهام غير المتزامنة والفوترة الخاصة بـ 2.5:

| النموذج                                                          | الفوترة                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/صورة                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/صورة                   |
| `gpt-image-2.6-flare:official`                              | مثل 2.5 official، تُحتسب حسب استخدام Token الفعلي |
| `gpt-image-2.6-sunburst:official`                           | مثل 2.5 official، تُحتسب حسب استخدام Token الفعلي |

خيارات الجودة هي `auto` و`low` و`medium` و`high` و`xhigh` و`max`؛ يستخدم الحجم `auto` أو `WIDTHxHEIGHT` المتوافق مع القيود المذكورة أعلاه. تدعم هذه الواجهة `png` و`jpeg` و`webp`؛ كما يدعم GPT Image 2.6 أيضاً صور `gif` المتحركة الأصلية، ولا يدعم SVG حالياً. يدعم التحرير عناوين URL للصور بصيغة JSON ورفع الملفات عبر multipart. يمثّل `:reverse` اسماً مستعاراً صريحاً للإصدار العادي الذي يحمل الاسم نفسه. استخدم الطراز الكامل، ولا تمرّر `gpt-image-2.6`.

### صور GIF المتحركة في GPT Image 2.6

يمكن للإصدار العادي من Flare و`:reverse` و`:official`، وكذلك `gpt-image-2.6-sunburst:official`، استخدام `output_format: "gif"`۔ لم يُتح GIF بعد للإصدار العادي من Sunburst و`:reverse`، وما زالا يدعمان توليد الصور الثابتة وتحريرها. سيتم الاحتفاظ بإطارات الرسوم المتحركة ومعلومات التكرار ومدة التشغيل؛ يشير `frame_count` إلى عدد الإطارات، ويشير `frame_duration_ms` إلى عدد المللي ثانية لكل إطار، ويجب أن يكون كلاهما عدداً صحيحاً موجباً، وهما مخصصان لـ GIF فقط. عند عدم التحديد، يكون الافتراضي 9 إطارات و200 مللي ثانية لكل إطار؛ وعندما يُحذف حجم GIF أو يكون auto، يُستخدم الإعداد المسبق 512x512.

يوصى بالبدء باستخدام `size: "512x512"` و`frame_count: 9` و`frame_duration_ms: 200`۔ لدى GIF قيود مستقلة للحجم وعدد الإطارات، ولا يمكن تطبيق مواصفات 4K الثابتة مباشرة؛ ستقوم بعض النماذج بتعديل حجم الإخراج الفعلي. يشير `n` إلى عدد ملفات GIF المُعادة، وليس عدد إطارات الرسوم المتحركة. تظل الإصدارات العادية و`:reverse` تُحاسب حسب عدد الملفات الناجحة، بينما تُحاسب الإصدارات الرسمية حسب استخدام Token الفعلي.

```json
{
  "model": "gpt-image-2.6-flare",
  "prompt": "A small red ball moves left and right on a white background, seamless looping animation, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### صور 4K الثابتة في GPT Image 2.6

يمكن لـ Flare وSunburst ومتغيراتها `:reverse` و`:official` جميعاً استخدام الإعدادات المسبقة لبكسلات 4K المذكورة سابقاً، مثل `3840x2160` و`2160x3840`۔ يُمرَّر عدد البكسلات المحدد عبر `size` لكل من التوليد والتحرير؛ `4K` ليست قيمة `size` صالحة، و`4096x4096` يتجاوز أيضاً حد البكسلات الحالي. تنطبق مواصفات 4K المذكورة أعلاه على صور PNG/JPEG/WebP الثابتة، أما GIF فاستخدم معلماته المخصصة.
