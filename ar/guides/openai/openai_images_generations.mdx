## 1. الحصول على مفتاح API

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، وادخل إلى التطبيق المتاح وانسخ مفتاح API.

![الحصول على مفتاح API لـ Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. إرسال أول طلب

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

توجد الصورة في الاستجابة الناجحة ضمن `data[].url`۔ فيما يلي نتيجة 1024×1536 تم الحصول عليها عبر طلب فعلي من Ace Data Cloud في 8 سبتمبر 2026 (المهمة `d56455e2-e7f7-4bcd-b935-475b0a1e0948`، والتتبع `eb938601-8192-407f-b539-1e0554b697ec`):

![كوب أبيض تم إنشاؤه بواسطة GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. المعلمات الشائعة

| الحقل                | الوصف                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (الموصى به افتراضياً)، أو `gpt-image-2.5-flare` (أسرع)، أو `gpt-image-2.5-sunburst` (دقة وتحكم أعلى)؛ يمكن للثلاثة جميعاً اختيار متغير `:official` المقابل، كما يدعم `gpt-image-2` أيضاً `:reverse` |
| `prompt`          | وصف الصورة، بحد أقصى 32,000 حرف                                                                                                                     |
| `size`            | `auto` أو `WIDTHxHEIGHT`؛ يجب أن يكون العرض والارتفاع من مضاعفات 16، وألا يتجاوز الضلع الأطول 3840، وأن يكون إجمالي البكسلات بين 655,360–8,294,400، وألا تتجاوز نسبة العرض إلى الارتفاع 3:1                                                       |
| `n`               | 1–10؛ يدعم `response_format=b64_json` القيمة 1 فقط                                                                                                 |
| `quality`         | `low` أو `medium` أو `high` أو `auto`؛ يختلف الدعم وطريقة الفوترة بين المسارات                                                                                          |
| `response_format` | `url` أو `b64_json`                                                                                                                     |
| `callback_url`    | اختياري؛ يرسل النتيجة إلى هذا العنوان بعد اكتمال المهمة الطويلة                                                                                                                      |

الأحجام الشائعة:

| النسبة   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

يختار `size: "auto"` أبعاد الصورة وفقاً للنسبة والبكسلات وقصد التخطيط في نص التوجيه؛ املأ الحجم مباشرة عند الحاجة إلى بكسلات دقيقة.

### النماذج وطرق الفوترة

| النموذج                                | حالات الاستخدام وطرق الفوترة                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | قناة عكسية افتراضية، تُفوّت بسعر ثابت لكل صورة ناجحة                        |
| `gpt-image-2:reverse`             | اختيار صريح للقناة العكسية، تُفوّت بسعر ثابت لكل صورة ناجحة                      |
| `gpt-image-2:official`            | قناة واجهة برمجة التطبيقات الرسمية، ذات استقرار أعلى، وتُفوّت وفقاً لاستخدام Token الفعلي            |
| `gpt-image-2.5-flare`             | تركز على سرعة التوليد، وتُفوّت بسعر ثابت لكل صورة ناجحة                        |
| `gpt-image-2.5-flare:official`    | قناة واجهة برمجة التطبيقات الرسمية، ذات استقرار أعلى وتركز على سرعة التوليد، وتُفوّت وفقاً لاستخدام Token الفعلي     |
| `gpt-image-2.5-sunburst`          | تركز على الدقة العالية والتحكم التفصيلي، وتُفوّت بسعر ثابت لكل صورة ناجحة                    |
| `gpt-image-2.5-sunburst:official` | قناة واجهة برمجة التطبيقات الرسمية، ذات استقرار أعلى وتركز على الدقة العالية والتحكم التفصيلي، وتُفوّت وفقاً لاستخدام Token الفعلي |

أسعار الصفحة لقنوات واجهة برمجة التطبيقات الرسمية هي تقديرات قبل الطلب، وتخضع القيمة النهائية لاستخدام Token الفعلي وسجل الاستخدام في الاستجابة.

## 4. التوليد المتعدد

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

تُفوّت `gpt-image-2` و`gpt-image-2.5-flare` و`gpt-image-2.5-sunburst` و`gpt-image-2:reverse` بحسب عدد الصور الناجحة؛ بينما تُسوّى `gpt-image-2:official` و`gpt-image-2.5-flare:official` و`gpt-image-2.5-sunburst:official` وفقاً لإدخال النص وإخراج الصور واستخدام Token الفعلي في الاستجابة. أسعار الصفحة هي تقديرات قبل الطلب، وتخضع القيمة النهائية لسجل الاستخدام.

## 5. الاستدعاء غير المتزامن

بعد إضافة `callback_url` إلى نص الطلب، ستعيد الواجهة أولاً `{"task_id": "..."}`، ثم سترسل النتيجة النهائية عبر POST إلى عنوان URL هذا عند الاكتمال؛ بينما تعيد الطلبات المتزامنة `created` و`data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

ينبغي على مستلِم الاستدعاء استخدام `task_id` لإزالة التكرار، والتحقق من مصدر الطلب وتنسيق البيانات.

## 6. استكشاف الأخطاء وإصلاحها

| الحالة  | التحقق                                                  |
| --- | --------------------------------------------------- |
| 400 | تركيبة `model` و`prompt` وتنسيق الحجم و`n` و`response_format`    |
| 401 | ما إذا كان مفتاح API كاملاً، وما إذا كان Header هو `Authorization: Bearer ...` |
| 429 | الطلبات متكررة جداً، أعد المحاولة لاحقاً                                         |
| 504 | انتهت مهلة التوليد المتزامن؛ استخدم `callback_url`                            |

ستتضمن استجابة الخطأ `error.code` و`error.message` و`trace_id`۔ عند الإبلاغ عن مشكلة، قدّم `trace_id`، ولا تقدّم مفتاح API.

للاطلاع على الحقول الكاملة والتعدادات الفورية، راجع صفحة [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). ولتحرير الصور، راجع [تحرير صور GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-edits).
