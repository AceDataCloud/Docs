## 1. الحصول على API Key

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، وادخل إلى التطبيق المتاح وانسخ API Key.

![الحصول على Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. إرسال أول طلب

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

توجد الصورة في الاستجابة الناجحة ضمن `data[].url`۔ فيما يلي نتيجة 1024×1536 التي تم الحصول عليها من طلب فعلي عبر Ace Data Cloud في 8 سبتمبر 2026 (المهمة `d56455e2-e7f7-4bcd-b935-475b0a1e0948`، والتتبع `eb938601-8192-407f-b539-1e0554b697ec`)：

![كوب أبيض تم إنشاؤه بواسطة GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. المعلمات الشائعة

| الحقل                | الوصف                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (موصى به افتراضيًا)، أو `gpt-image-2.5-flare` (أسرع)، أو `gpt-image-2.5-sunburst` (دقة وتحكم أعلى)؛ يمكن للثلاثة اختيار متغير `:official` المقابل، كما يدعم `gpt-image-2` أيضًا `:reverse` |
| `prompt`          | وصف الصورة، بحد أقصى 32,000 حرف                                                                                                                     |
| `size`            | `auto` أو `WIDTHxHEIGHT`؛ يجب أن يكون العرض والارتفاع من مضاعفات 16، وألا يتجاوز الضلع الأطول 3840، وأن يكون إجمالي البكسلات بين 655,360–8,294,400، وألا تتجاوز نسبة العرض إلى الارتفاع 3:1                                                       |
| `n`               | 1–10؛ يدعم `response_format=b64_json` القيمة 1 فقط                                                                                                 |
| `quality`         | تدعم نماذج GPT Image القيم `auto` و`low` و`medium` و`high`؛ فقط 2.5 Flare / Sunburst (بما في ذلك `:official`) تدعم أيضًا `xhigh` و`max`۔ تُحتسب القناة الرسمية حسب استخدام Token الفعلي                 |
| `response_format` | `url` أو `b64_json`                                                                                                                     |
| `callback_url`    | اختياري؛ يرسل النتائج إلى هذا العنوان بعد اكتمال المهام الطويلة                                                                                                                      |

الأحجام الشائعة:

| النسبة   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

سيختار `size: "auto"` أبعاد الصورة بناءً على النسبة والبكسلات ونية التخطيط في المطالبة؛ عند الحاجة إلى بكسلات دقيقة، اكتب الأبعاد مباشرةً.

### النماذج وطريقة الفوترة

| النموذج                                | سيناريوهات الاستخدام وطريقة الفوترة                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | قناة عكسية افتراضية، بفوترة ثابتة حسب عدد الصور الناجحة                        |
| `gpt-image-2:reverse`             | اختيار صريح للقناة العكسية، بفوترة ثابتة حسب عدد الصور الناجحة                      |
| `gpt-image-2:official`            | قناة API رسمية، باستقرار أعلى، وتُحتسب حسب استخدام Token الفعلي            |
| `gpt-image-2.5-flare`             | تركز على سرعة التوليد، بفوترة ثابتة حسب عدد الصور الناجحة                        |
| `gpt-image-2.5-flare:official`    | قناة API رسمية، باستقرار أعلى مع التركيز على سرعة التوليد، وتُحتسب حسب استخدام Token الفعلي     |
| `gpt-image-2.5-sunburst`          | تركز على الدقة العالية والتحكم التفصيلي، بفوترة ثابتة حسب عدد الصور الناجحة                    |
| `gpt-image-2.5-sunburst:official` | قناة API رسمية، باستقرار أعلى مع التركيز على الدقة العالية والتحكم التفصيلي، وتُحتسب حسب استخدام Token الفعلي |

سعر الصفحة لقناة API الرسمية هو تقدير قبل الطلب، ويعتمد النهائي على استخدام Token الفعلي وسجل الاستخدام في الاستجابة.

## 4. توليد صور متعددة

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

تتم فوترة `gpt-image-2` و`gpt-image-2.5-flare` و`gpt-image-2.5-sunburst` و`gpt-image-2:reverse` حسب عدد الصور الناجحة؛ بينما تتم تسوية `gpt-image-2:official` و`gpt-image-2.5-flare:official` و`gpt-image-2.5-sunburst:official` بناءً على Token الفعلي لإدخال النص وإخراج الصورة في الاستجابة. سعر الصفحة هو تقدير قبل الطلب، والنهائي يعتمد على سجل الاستخدام.

## 5. الاستدعاء غير المتزامن

بعد إضافة `callback_url` إلى نص الطلب، ستعيد الواجهة أولًا `{"task_id": "..."}`، ثم ترسل النتيجة النهائية عبر POST إلى ذلك الرابط عند الاكتمال؛ بينما ما زالت الطلبات المتزامنة تعيد `created` و`data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

ينبغي لمستلم الاستدعاء استخدام `task_id` لإزالة التكرار، والتحقق من مصدر الطلب وتنسيق البيانات.

## 6. استكشاف الأخطاء وإصلاحها

| الحالة  | تحقق من                                                  |
| --- | --------------------------------------------------- |
| 400 | تركيبة `model` و`prompt` وتنسيق الأبعاد و`n` و`response_format`    |
| 401 | ما إذا كان API Key كاملًا، وما إذا كان Header هو `Authorization: Bearer ...` |
| 429 | الطلبات متكررة جدًا، أعد المحاولة لاحقًا                                         |
| 504 | انتهت مهلة التوليد المتزامن؛ استخدم `callback_url`                            |

ستتضمن استجابة الخطأ `error.code` و`error.message` و`trace_id`۔ عند الإبلاغ عن مشكلة، قدم `trace_id`، ولا تقدم API Key.

تُعتمد الحقول الكاملة والقيم المعدودة الفورية على صفحة [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). لتحرير الصور، راجع [تحرير الصور GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-edits).
