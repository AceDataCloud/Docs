## 3. رفع صورة محلية

استخدم `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

يمكن تمرير `image` بصورة متكررة، وتدعم سلسلة GPT Image ما يصل إلى 16 صورة مرجعية. يمكن أن يكون `image` في طلب JSON رابط URL واحدًا أو مصفوفة من روابط URL؛ وتُرفع الملفات المحلية باستخدام multipart.

## 4. التحرير الموضعي باستخدام القناع

تحدد واجهة Images Edit الرسمية المنطقة المسموح بتعديلها عبر `mask`. وتتبع نماذج `:official` من Ace Data Cloud عقد multipart نفسه:

- يجب أن يكون `mask` ملف PNG يحتوي على قناة Alpha، وألا يتجاوز حجمه 4MB؛
- يجب أن يكون حجم القناع مطابقًا تمامًا للصورة الأولى `image`؛
- تشير البكسلات الشفافة ذات Alpha بقيمة `0` إلى السماح بالتحرير، بينما تشير البكسلات غير الشفافة إلى وجوب الاحتفاظ بها؛
- لا يمكن استخدام صور RGB التي تكون ألوانها أبيض وأسود فقط، ولكنها لا تحتوي على قناة شفافية، كأقنعة صالحة؛
- يجب أن يصف الموجّه الصورة الكاملة المطلوبة، مع توضيح التعديل الموضعي والمحتوى الذي يجب أن يبقى دون تغيير.

أنشئ أولًا قناعًا من الصورة الأصلية أدناه. يضبط المثال المستطيل المركزي ليكون شفافًا، بحيث يسمح للنموذج بتعديل هذه المنطقة فقط:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

ثم ارفع الصورة الأصلية والقناع معًا:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

يمكنك أيضًا اتباع طريقة استدعاء `images.edit` الخاصة بـ Python SDK الرسمي من OpenAI، ما عليك سوى توجيه `base_url` إلى Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

عند استخدام `mask`، يجب رفع الصورة الأصلية والقناع بشكل منفصل ضمن طلب multipart نفسه عبر `image=@input.png` و`mask=@mask.png`. لا تخلط بين صورة أصلية برابط URL وملف قناع محلي عند الإرسال؛ إذ لا تدعم طلبات التحرير التي تستخدم روابط URL فقط إضافة ملف `mask` محلي. يقيّد القناع منطقة التحرير، لكن نموذج التوليد قد يستمر في دمج الحواف بصورة طبيعية؛ وعندما تكون هناك حاجة إلى حدود صارمة، ينبغي استخدام حواف Alpha واضحة وتكرار توضيح المحتوى الذي يجب أن يبقى دون تغيير في الموجّه.

تتوافق طريقة الاستدعاء أعلاه مع أمثلة الأقنعة في [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) و[GPT Image Official Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. المعلمات الشائعة

| الحقل                | الوصف                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` أو `gpt-image-2.5-flare` (أسرع) أو `gpt-image-2.5-sunburst` (دقة وتحكم أعلى)؛ ويمكن للثلاثة جميعًا اختيار متغير `:official` المقابل، كما يدعم `gpt-image-2` أيضًا `:reverse` |
| `image`           | يستخدم JSON رابط URL واحدًا أو مصفوفة تضم ما يصل إلى 16 رابط URL؛ بينما يستخدم multipart حقل ملف `image` واحدًا أو أكثر. يجب رفع ملفات صور محلية عند استخدام `mask`                                              |
| `mask`            | قناع PNG اختياري، يقتصر على رفع الملفات عبر multipart؛ يجب أن يحتوي على قناة Alpha، وأن يطابق حجم أول `image`، وألا يتجاوز 4MB                                                                 |
| `prompt`          | تعليمات التحرير                                                                                                                             |
| `size`            | `auto` أو `WIDTHxHEIGHT` الذي يطابق القيود                                                                                                     |
| `n`               | 1–10؛ عند استخدام `response_format=b64_json` لا يُدعم سوى 1                                                                                           |
| `response_format` | `url` أو `b64_json`                                                                                                               |
| `callback_url`    | عنوان اختياري لاستدعاء غير متزامن                                                                                                                         |
尺寸规则与生成接口一致：宽高须为 16 的倍数，长边不超过 3840，总像素为 655,360–8,294,400，宽高比不超过 3:1。省略 `size` 或使用 `auto` 时，模型会结合提示词和第一张参考图选择画幅。

`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` 与 `gpt-image-2:reverse` 按成功张数计费；`gpt-image-2:official`、`gpt-image-2.5-flare:official` 和 `gpt-image-2.5-sunburst:official` 根据文字输入、参考图输入和图片输出的实际 Token 结算，最终以使用记录为准。

## 6. الاستدعاءات غير المتزامنة واستكشاف الأخطاء وإصلاحها

يمكن للمهام الطويلة إضافة ما يلي إلى الطلب:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

استجابة 200 غير المتزامنة هي `{"task_id": "..."}`؛ وبعد الاكتمال، يتم استدعاء النتيجة النهائية. أما الطلبات المتزامنة فتعيد `created` و`data`.

| الحالة | الفحص |
| --- | --- |
| 400 | تنسيق/عدد الصور، ومجموعة المعلمات وتنسيق الحجم؛ عند استخدام `mask`، تحقّق من قناة PNG Alpha، وحد 4MB، وما إذا كانت أبعادها مطابقة للصورة الأصلية الأولى |
| 401 | API Key وBearer Header |
| 429 | معدل تكرار الطلبات |
| 504 | استخدم الاستدعاء غير المتزامن بدلًا من ذلك |

ستتضمن استجابة الخطأ `trace_id`. عند الإبلاغ عن مشكلة، قدّم هذا المعرّف، ولا تقدّم API Key.

للاطلاع على الحقول الكاملة والتعدادات في الوقت الفعلي، راجع صفحة [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). لإنشاء الصور من نص فقط، راجع [GPT Image 2 / 2.5 图像生成](https://platform.acedata.cloud/documents/openai-images-generations).
