## 2. التحرير باستخدام رابط الصورة URL

  -H "Content-Type: application/json" \
  -d '{

## 3. رفع صورة محلية

استخدم `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

يمكن تمرير `image` بشكل متكرر، وتدعم سلسلة GPT Image ما يصل إلى 16 صورة مرجعية. يمكن أن تكون `image` في طلب JSON رابط URL واحدًا أو مصفوفة من روابط URL؛ وتُرفع الملفات المحلية باستخدام multipart.

### النماذج وطريقة الفوترة

| النموذج                                | سيناريوهات الاستخدام وطريقة الفوترة                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | قناة عكسية افتراضية، بفوترة ثابتة حسب عدد الصور الناجحة                               |
| `gpt-image-2:reverse`             | اختيار صريح للقناة العكسية، بفوترة ثابتة حسب عدد الصور الناجحة                             |
| `gpt-image-2:official`            | قناة API الرسمية، باستقرار أعلى، وبفوترة حسب الاستخدام الفعلي للرموز                   |
| `gpt-image-2.5-flare`             | يركز على سرعة التوليد، بفوترة ثابتة حسب عدد الصور الناجحة                               |
| `gpt-image-2.6-flare`             | يركز على سرعة التوليد، بفوترة ثابتة حسب عدد الصور الناجحة                               |
| `gpt-image-2.5-flare:reverse`     | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.5-flare`، وبفوترة ثابتة حسب عدد الصور الناجحة    |
| `gpt-image-2.6-flare:reverse`     | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.6-flare`، وبفوترة ثابتة حسب عدد الصور الناجحة    |
| `gpt-image-2.5-flare:official`    | قناة API الرسمية، باستقرار أعلى وتركز على سرعة التوليد، وبفوترة حسب الاستخدام الفعلي للرموز            |
| `gpt-image-2.6-flare:official`    | قناة API الرسمية، باستقرار أعلى وتركز على سرعة التوليد، وبفوترة حسب الاستخدام الفعلي للرموز            |
| `gpt-image-2.5-sunburst`          | يركز على الدقة العالية والتحكم التفصيلي، بفوترة ثابتة حسب عدد الصور الناجحة                           |
| `gpt-image-2.6-sunburst`          | يركز على الدقة العالية والتحكم التفصيلي، بفوترة ثابتة حسب عدد الصور الناجحة                           |
| `gpt-image-2.5-sunburst:reverse`  | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.5-sunburst`، وبفوترة ثابتة حسب عدد الصور الناجحة |
| `gpt-image-2.6-sunburst:reverse`  | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.6-sunburst`، وبفوترة ثابتة حسب عدد الصور الناجحة |
| `gpt-image-2.5-sunburst:official` | قناة API الرسمية، باستقرار أعلى وتركز على الدقة العالية والتحكم التفصيلي، وبفوترة حسب الاستخدام الفعلي للرموز        |
| `gpt-image-2.6-sunburst:official` | قناة API الرسمية، باستقرار أعلى وتركز على الدقة العالية والتحكم التفصيلي، وبفوترة حسب الاستخدام الفعلي للرموز        |

قد تستخدم الطرازات العكسية 2.0 / 2.5 (بما في ذلك الأسماء المستعارة `:reverse`) GPT Image 2.5 Flare لإكمال الطلب عند الاسترداد التلقائي؛ ويظل طراز الطلب وطريقة الفوترة حسب عدد الصور الناجحة دون تغيير.

سعر الصفحة لقناة API الرسمية هو تقدير قبل الطلب، ويُعتمد في النهاية على الاستخدام الفعلي للرموز وسجل الاستخدام في الاستجابة.

يدعم `quality` القيم `auto` و`low` و`medium` و`high`؛ وتدعم Flare وSunburst للإصدارين 2.5 / 2.6 (بما في ذلك متغيرات `:reverse` و`:official`) أيضًا `xhigh` و`max`. يمكن تمرير هذا الحقل في كلٍّ من تحرير روابط الصور URL عبر JSON وتحرير الملفات عبر multipart؛ وتُفوّتَر القناة الرسمية حسب الاستخدام الفعلي للرموز.

## 4. استخدام القناع للتحرير الجزئي

تحدد واجهة Images Edit الرسمية المنطقة المسموح بتعديلها عبر `mask`. تتبع نماذج `:official` الخاصة بـ Ace Data Cloud عقد multipart نفسه:

- يجب أن يكون `mask` بصيغة PNG مع قناة Alpha، وألا يتجاوز حجمه 4MB؛
- يجب أن تتطابق أبعاد القناع تمامًا مع الصورة الأولى `image`؛
- تمثل البكسلات الشفافة التي تكون قيمة Alpha فيها `0` المناطق المسموح بتحريرها، وتمثل البكسلات غير الشفافة المناطق التي ينبغي الاحتفاظ بها؛
- لا يمكن استخدام صور RGB التي تحتوي فقط على اللونين الأسود والأبيض، لكنها لا تحتوي على قناة شفافية، كقناع صالح؛
- ينبغي أن يصف الموجّه المشهد الكامل المتوقع الحصول عليه، مع توضيح التعديلات الجزئية والمحتوى المطلوب إبقاؤه دون تغيير.

فيما يلي، يُنشأ قناع من الصورة الأصلية أولًا. يضبط المثال المستطيل المركزي ليكون شفافًا، بحيث يُسمح للنموذج بتعديل هذه المنطقة فقط:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

ثم ارفع الصورة الأصلية والقناع معًا:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

يمكنك أيضًا الاستمرار باستخدام أسلوب استدعاء `images.edit` الخاص بـ Python SDK الرسمي من OpenAI، ما عليك سوى توجيه `base_url` إلى Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

عند استخدام `mask`، يجب رفع الصورة الأصلية والقناع ضمن طلب multipart نفسه عبر `image=@input.png` و`mask=@mask.png` على التوالي. لا تمرّر صورة أصلية عبر URL وملف قناع محلي معًا؛ فطلبات التحرير التي تستخدم URL فقط لا تدعم إرفاق ملف `mask` محلي إضافي. يقيّد القناع منطقة التحرير، لكن نموذج التوليد قد لا يزال يجري دمجًا طبيعيًا عند الحواف؛ وعند الحاجة إلى حدود صارمة، يجب استخدام حواف Alpha واضحة وتكرار توضيح المحتوى الذي يجب أن يبقى دون تغيير في الموجّه.

طريقة الاستدعاء المذكورة أعلاه متوافقة مع أمثلة الأقنعة في [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) و[GPT Image Official Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. المعلمات الشائعة

| الحقل                | الوصف                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` أو `gpt-image-2.5-flare` (أسرع) أو `gpt-image-2.5-sunburst` (دقة وتحكم أعلى)؛ يمكن للثلاثة جميعًا اختيار متغير `:official` المقابل، كما يدعم `gpt-image-2` أيضًا `:reverse` |
| `image`           | يستخدم JSON عنوان URL واحدًا أو مصفوفة تضم حتى 16 عنوان URL؛ ويستخدم multipart حقل ملف `image` واحدًا أو أكثر. عند استخدام `mask` يجب رفع ملف صورة محلي                                              |
| `mask`            | قناع PNG اختياري، يقتصر على رفع ملفات multipart؛ يجب أن يحتوي على قناة Alpha، وأن يكون بنفس أبعاد أول `image` وألا يتجاوز 4MB                                                                 |
| `prompt`          | تعليمات التحرير                                                                                                                             |
| `size`            | `auto` أو `WIDTHxHEIGHT` متوافق مع القيود                                                                                                     |
| `n`               | 1–10؛ عند `response_format=b64_json` لا يُدعم سوى 1                                                                                           |
| `response_format` | `url` أو `b64_json`                                                                                                               |
| `callback_url`    | عنوان رد اتصال غير متزامن اختياري                                                                                                                         |

تتوافق قواعد الأبعاد مع واجهة التوليد: يجب أن يكون العرض والارتفاع من مضاعفات 16، وألا يتجاوز الضلع الطويل 3840، وأن يكون إجمالي البكسلات بين 655,360 و8,294,400، وألا تتجاوز نسبة العرض إلى الارتفاع 3:1. عند حذف `size` أو استخدام `auto`، سيختار النموذج أبعاد اللوحة بناءً على الموجّه والصورة المرجعية الأولى.

تُحتسب رسوم `gpt-image-2` و`gpt-image-2.5-flare` و`gpt-image-2.5-sunburst` وأسماءها المستعارة `:reverse` وفقًا لعدد الصور الناجحة؛ بينما تتم تسوية `gpt-image-2:official` و`gpt-image-2.5-flare:official` و`gpt-image-2.5-sunburst:official` استنادًا إلى Tokens الفعلية للمدخلات النصية ومدخلات الصور ومخرجات الصور، ويكون السجل الفعلي للاستخدام هو المرجع النهائي.

## 6. رد الاتصال غير المتزامن واستكشاف الأخطاء وإصلاحها

يمكن للمهام الطويلة إضافة ما يلي إلى الطلب:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

تكون استجابة 200 غير المتزامنة هي `{"task_id": "..."}`؛ وبعد الاكتمال يتم إرسال النتيجة النهائية عبر رد الاتصال. أما الطلبات المتزامنة فتعيد `created` و`data`.

| الحالة  | التحقق                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | تنسيق/عدد الصور، ومجموعة المعلمات وتنسيق الأبعاد؛ وعند استخدام `mask` تحقق من قناة PNG Alpha، وحد 4MB، وما إذا كانت أبعادها مطابقة للصورة الأصلية الأولى |
| 401 | API Key وBearer Header                                           |
| 429 | معدل الطلبات                                                              |
| 504 | استخدم رد الاتصال غير المتزامن                                                            |

ستتضمن استجابة الخطأ `trace_id`. عند الإبلاغ عن مشكلة، قدّم هذا المعرّف، ولا تقدّم API Key.

للحصول على الحقول الكاملة والقيم المعدّدة في الوقت الفعلي، راجع صفحة [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). لتوليد الصور من النص فقط، راجع [توليد الصور GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

يواصل GPT Image 2.6 استخدام واجهات 2.5 للتوليد والتحرير والمهام غير المتزامنة والفوترة:

| النموذج                                                          | الفوترة                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/صورة                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/صورة                   |
| `gpt-image-2.6-flare:official`                              | مثل 2.5 official، تُحتسب وفقًا لاستخدام Tokens الفعلي |
| `gpt-image-2.6-sunburst:official`                           | مثل 2.5 official، تُحتسب وفقًا لاستخدام Tokens الفعلي |

يمكن أن تكون الجودة `auto` أو `low` أو `medium` أو `high` أو `xhigh` أو `max`؛ ويستخدم الحجم `auto` أو `WIDTHxHEIGHT` المتوافق مع القيود المذكورة أعلاه. تدعم هذه الواجهة `png` و`jpeg` و`webp`، ولا تدعم SVG/GIF حاليًا. يدعم التحرير عناوين URL للصور عبر JSON ورفع الملفات عبر multipart. يُعد `:reverse` اسمًا مستعارًا صريحًا للإصدار العادي الذي يحمل الاسم نفسه. يرجى استخدام اسم الطراز الكامل، ولا تمرّر `gpt-image-2.6`.
