## 2. التحرير باستخدام URL للصورة

  -H "Authorization: Bearer 你的 API Key" \

## 3. رفع صورة محلية

استخدم `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

يمكن تمرير `image` بشكل متكرر، وتدعم سلسلة GPT Image حتى 16 صورة مرجعية. يمكن أن تكون `image` في طلب JSON عنوان URL واحدًا أو مصفوفة من عناوين URL؛ وتُرفع الملفات المحلية باستخدام multipart.

### النماذج وطريقة الفوترة

| النموذج                                | سيناريوهات الاستخدام وطريقة الفوترة                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | قناة عكسية افتراضية، بفوترة ثابتة حسب عدد الصور الناجحة                        |
| `gpt-image-2:reverse`             | اختيار صريح للقناة العكسية، بفوترة ثابتة حسب عدد الصور الناجحة                      |
| `gpt-image-2:official`            | قناة API الرسمية، باستقرار أعلى، وبفوترة حسب الاستخدام الفعلي للـ Token            |
| `gpt-image-2.5-flare`             | يركز على سرعة التوليد، بفوترة ثابتة حسب عدد الصور الناجحة                        |
| `gpt-image-2.5-flare:official`    | قناة API الرسمية، باستقرار أعلى وتركيز على سرعة التوليد، وبفوترة حسب الاستخدام الفعلي للـ Token     |
| `gpt-image-2.5-sunburst`          | يركز على الدقة العالية والتحكم التفصيلي، بفوترة ثابتة حسب عدد الصور الناجحة                    |
| `gpt-image-2.5-sunburst:official` | قناة API الرسمية، باستقرار أعلى وتركيز على الدقة العالية والتحكم التفصيلي، وبفوترة حسب الاستخدام الفعلي للـ Token |

سعر صفحة قناة API الرسمية هو تقدير قبل الطلب، ويُعتمد في النهاية على الاستخدام الفعلي للـ Token وسجل الاستخدام في الاستجابة.

يدعم `quality` القيم `auto` و`low` و`medium` و`high`؛ ويدعم فقط `gpt-image-2.5-flare` و`gpt-image-2.5-sunburst` (بما في ذلك متغيرات `:official`) أيضًا `xhigh` و`max`. يمكن تمرير هذا الحقل في كل من تحرير URL للصور عبر JSON وتحرير الملفات عبر multipart؛ وتُحتسب رسوم القناة الرسمية حسب الاستخدام الفعلي للـ Token.

## 4. استخدام قناع للتحرير الجزئي

تحدد واجهة Images Edit الرسمية المنطقة المسموح بتعديلها عبر `mask`. تتبع نماذج `:official` الخاصة بـ Ace Data Cloud عقد multipart نفسه:

- يجب أن يكون `mask` ملف PNG مزودًا بقناة Alpha، وألا يتجاوز حجمه 4MB؛
- يجب أن يتطابق حجم القناع تمامًا مع أول `image`؛
- تشير البكسلات الشفافة ذات Alpha بقيمة `0` إلى السماح بالتحرير، وتشير البكسلات غير الشفافة إلى وجوب الاحتفاظ بها؛
- لا يمكن استخدام صور RGB التي تكون ألوانها أبيض وأسود فقط ولكنها لا تحتوي على قناة شفافية كقناع صالح؛
- يجب أن يصف الموجّه المشهد الكامل المتوقع، مع توضيح التعديل الجزئي والمحتوى المطلوب إبقاؤه دون تغيير.

يُنشأ أولًا قناع من الصورة الأصلية أدناه. يضبط المثال المستطيل المركزي ليكون شفافًا، بحيث يُسمح للنموذج بتعديل هذه المنطقة فقط:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

ثم ارفع الصورة الأصلية والقناع معًا:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

يمكنك أيضًا الاستمرار في استخدام أسلوب استدعاء `images.edit` الخاص بـ Python SDK الرسمي من OpenAI، ما عليك سوى توجيه `base_url` إلى Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```
عند استخدام `mask`، يجب رفع الصورة الأصلية والقناع بشكل منفصل ضمن طلب multipart نفسه عبر `image=@input.png` و`mask=@mask.png`. لا تمرّر صورة أصلية عبر URL وملف قناع محلي معًا؛ طلبات التحرير التي تستخدم URL فقط لا تدعم إرفاق ملف `mask` محلي إضافي. سيقيّد القناع منطقة التحرير، لكن نموذج التوليد قد يظل يجري دمجًا طبيعيًا عند الحواف؛ عند الحاجة إلى حدود صارمة، يجب استخدام حواف Alpha واضحة وتكرار توضيح المحتوى الذي يجب أن يبقى دون تغيير في المطالبة.

تتوافق طريقة الاستدعاء أعلاه مع أمثلة الأقنعة في [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) و[GPT Image Official Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. المعلمات الشائعة

| الحقل                | الوصف                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` أو `gpt-image-2.5-flare` (أسرع) أو `gpt-image-2.5-sunburst` (دقة وتحكم أعلى)؛ يمكن للثلاثة جميعًا اختيار متغير `:official` المقابل، كما يدعم `gpt-image-2` أيضًا `:reverse` |
| `image`           | يستخدم JSON عنوان URL واحدًا أو مصفوفة تضم ما يصل إلى 16 عنوان URL؛ ويستخدم multipart حقل ملف `image` واحدًا أو أكثر. عند استخدام `mask` يجب رفع ملف صورة محلي                                              |
| `mask`            | قناع PNG اختياري، يقتصر على رفع ملفات multipart؛ يجب أن يحتوي على قناة Alpha، وأن يكون بالحجم نفسه للصورة الأولى في `image` وألا يتجاوز 4MB                                                                 |
| `prompt`          | تعليمات التحرير                                                                                                                             |
| `size`            | `auto` أو `WIDTHxHEIGHT` المتوافق مع القيود                                                                                                     |
| `n`               | 1–10؛ عند `response_format=b64_json` لا يُدعم سوى 1                                                                                           |
| `response_format` | `url` أو `b64_json`                                                                                                               |
| `callback_url`    | عنوان رد اتصال غير متزامن اختياري                                                                                                                         |

تتوافق قواعد الأبعاد مع واجهة التوليد: يجب أن يكون العرض والارتفاع من مضاعفات 16، وألا يتجاوز الضلع الأطول 3840، وأن يكون إجمالي البكسلات بين 655,360–8,294,400، وألا تتجاوز نسبة العرض إلى الارتفاع 3:1. عند حذف `size` أو استخدام `auto`، سيختار النموذج أبعاد اللوحة بالاستناد إلى المطالبة والصورة المرجعية الأولى.

تُحتسب رسوم `gpt-image-2` و`gpt-image-2.5-flare` و`gpt-image-2.5-sunburst` و`gpt-image-2:reverse` بحسب عدد الصور الناجحة؛ أما `gpt-image-2:official` و`gpt-image-2.5-flare:official` و`gpt-image-2.5-sunburst:official` فتُسوّى وفق Token الفعلية للمدخلات النصية ومدخلات الصور ومخرجات الصور، ويكون السجلّ الفعلي للاستخدام هو المرجع النهائي.

## 6. رد الاتصال غير المتزامن واستكشاف الأخطاء وإصلاحها

يمكن للمهام الطويلة إضافة ما يلي إلى الطلب:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

تكون استجابة 200 غير المتزامنة هي `{"task_id": "..."}`؛ وبعد الاكتمال يُعيد رد الاتصال النتيجة النهائية. أما الطلبات المتزامنة فتعيد `created` و`data`.

| الحالة  | التحقق                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | تنسيق/عدد الصور، وتركيبات المعلمات وتنسيق الأبعاد؛ عند استخدام `mask` تحقّق من قناة Alpha في PNG، وحد 4MB، وما إذا كانت أبعاده مطابقة للصورة الأصلية الأولى |
| 401 | API Key وBearer Header                                           |
| 429 | معدل تكرار الطلبات                                                              |
| 504 | التحويل إلى رد اتصال غير متزامن                                                            |

ستتضمن استجابة الخطأ `trace_id`. عند الإبلاغ عن مشكلة، قدّم هذا المعرّف، ولا تقدّم API Key.

تخضع الحقول الكاملة والقيم المعدودة الفورية لصفحة [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). لتوليد الصور من نص فقط، يُرجى الاطلاع على [GPT Image 2 / 2.5 توليد الصور](https://platform.acedata.cloud/documents/openai-images-generations).
