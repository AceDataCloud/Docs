## 1. الحصول على API Key

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، وادخل إلى التطبيق المتاح وانسخ API Key.

![الحصول على Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. التحرير باستخدام URL للصورة

الصورة الأصلية:

![الصورة الأصلية لتحرير GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

استجابة ناجحة:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

هذه هي نتيجة التحرير التي أُنجزت فعليًا عبر Ace Data Cloud في 8 سبتمبر 2026، حيث أصبح الكوب برتقاليًا، والخلفية زرقاء كحلية داكنة، مع الحفاظ على التكوين الأصلي وأبعاد 1024×1536:

![نتيجة تحرير كوب برتقالي في GPT Image 2](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. رفع صورة محلية

استخدم `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

يمكن تمرير `image` بشكل متكرر، وتدعم سلسلة GPT Image ما يصل إلى 16 صورة مرجعية. يمكن أن يكون `image` في طلب JSON عنوان URL واحدًا أو مصفوفة من عناوين URL؛ وتُرفع الملفات المحلية باستخدام multipart.

## 4. المعلمات الشائعة

| الحقل                | الوصف                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`، أو `gpt-image-2.5-flare` (أسرع)، أو `gpt-image-2.5-sunburst` (دقة وتحكم أعلى)؛ ويمكن للثلاثة جميعًا اختيار متغير `:official` المقابل، كما يدعم `gpt-image-2` أيضًا `:reverse` |
| `image`           | يستخدم JSON عنوان URL واحدًا أو مصفوفة تضم ما يصل إلى 16 عنوان URL؛ ويستخدم multipart حقل ملف `image` واحدًا أو أكثر                                                                    |
| `prompt`          | تعليمات التحرير                                                                                                                             |
| `size`            | `auto` أو `WIDTHxHEIGHT` المطابق للقيود                                                                                                     |
| `n`               | 1–10؛ عند `response_format=b64_json` لا يُدعم سوى 1                                                                                           |
| `response_format` | `url` أو `b64_json`                                                                                                               |
| `callback_url`    | عنوان رد اتصال غير متزامن اختياري                                                                                                                         |

تتطابق قواعد الأبعاد مع واجهة التوليد: يجب أن يكون العرض والارتفاع من مضاعفات 16، وألا يتجاوز الضلع الطويل 3840، وأن يكون إجمالي البكسلات بين 655,360 و8,294,400، وألا تتجاوز نسبة العرض إلى الارتفاع 3:1. عند حذف `size` أو استخدام `auto`، سيختار النموذج أبعاد الصورة بناءً على نص الطلب والصورة المرجعية الأولى.

تُحاسب `gpt-image-2` و`gpt-image-2.5-flare` و`gpt-image-2.5-sunburst` و`gpt-image-2:reverse` حسب عدد الصور الناجحة؛ بينما تُسوّى `gpt-image-2:official` و`gpt-image-2.5-flare:official` و`gpt-image-2.5-sunburst:official` وفقًا للـ Token الفعلية لإدخال النصوص وإدخال الصور وإخراج الصور، ويُعتد بسجل الاستخدام النهائي.

## 5. رد الاتصال غير المتزامن واستكشاف الأخطاء وإصلاحها

يمكن إضافة ما يلي إلى الطلبات الطويلة:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

تكون استجابة 200 غير المتزامنة هي `{"task_id": "..."}`؛ وبعد الاكتمال يُرسل رد الاتصال النتيجة النهائية. أما الطلبات المتزامنة فتُرجع `created` و`data`.

| الحالة  | التحقق                      |
| --- | ----------------------- |
| 400 | تنسيق/عدد الصور، ومجموعة المعلمات، وتنسيق الأبعاد       |
| 401 | API Key وBearer Header |
| 429 | معدل الطلبات                    |
| 504 | استخدم رد الاتصال غير المتزامن                  |

ستتضمن استجابة الخطأ `trace_id`. عند الإبلاغ عن مشكلة، قدم هذا المعرّف ولا تقدم API Key.

للحصول على الحقول الكاملة والقيم المعدودة في الوقت الفعلي، راجع صفحة [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). لإنشاء الصور من النص فقط، راجع [توليد الصور GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
