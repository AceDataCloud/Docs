## 3. رفع صور محلية

استخدم `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

يمكن تمرير `image` بشكل متكرر، وتدعم سلسلة GPT Image حتى 16 صورة مرجعية. يمكن أن تكون `image` في طلب JSON رابط URL واحدًا أو مصفوفة من روابط URL؛ وتُرفع الملفات المحلية باستخدام multipart.

### النماذج وطريقة الفوترة

| النموذج                                | سيناريوهات الاستخدام وطريقة الفوترة                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | قناة عكسية افتراضية، بفوترة ثابتة حسب عدد الصور الناجحة                               |
| `gpt-image-2:reverse`             | اختيار صريح للقناة العكسية، بفوترة ثابتة حسب عدد الصور الناجحة                             |
| `gpt-image-2:official`            | قناة API رسمية، باستقرار أعلى، وبفوترة حسب الاستخدام الفعلي للـ Token                   |
| `gpt-image-2.5-flare`             | يركز على سرعة التوليد، بفوترة ثابتة حسب عدد الصور الناجحة                               |
| `gpt-image-2.6-flare`             | يركز على سرعة التوليد، بفوترة ثابتة حسب عدد الصور الناجحة                               |
| `gpt-image-2.5-flare:reverse`     | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.5-flare`، بفوترة ثابتة حسب عدد الصور الناجحة    |
| `gpt-image-2.6-flare:reverse`     | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.6-flare`، بفوترة ثابتة حسب عدد الصور الناجحة    |
| `gpt-image-2.5-flare:official`    | قناة API رسمية، باستقرار أعلى مع التركيز على سرعة التوليد، وبفوترة حسب الاستخدام الفعلي للـ Token            |
| `gpt-image-2.6-flare:official`    | قناة API رسمية، باستقرار أعلى مع التركيز على سرعة التوليد، وبفوترة حسب الاستخدام الفعلي للـ Token            |

| `gpt-image-2.6-sunburst`          | يركز على الدقة العالية والتحكم التفصيلي، بفوترة ثابتة حسب عدد الصور الناجحة                           |
| `gpt-image-2.5-sunburst:reverse`  | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.5-sunburst`، بفوترة ثابتة حسب عدد الصور الناجحة |
| `gpt-image-2.6-sunburst:reverse`  | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.6-sunburst`، بفوترة ثابتة حسب عدد الصور الناجحة |
| `gpt-image-2.5-sunburst:official` | قناة API رسمية، باستقرار أعلى مع التركيز على الدقة العالية والتحكم التفصيلي، وبفوترة حسب الاستخدام الفعلي للـ Token        |
| `gpt-image-2.6-sunburst:official` | قناة API رسمية، باستقرار أعلى مع التركيز على الدقة العالية والتحكم التفصيلي، وبفوترة حسب الاستخدام الفعلي للـ Token        |

قد تستخدم نماذج 2.0 / 2.5 العكسية (بما في ذلك الأسماء المستعارة `:reverse`) GPT Image 2.5 Flare لإكمال الطلب عند الاسترداد التلقائي؛ ويظل نموذج الطلب وطريقة الفوترة حسب عدد الصور الناجحة دون تغيير.

سعر الصفحة لقناة API الرسمية هو تقدير قبل الطلب، ويُعتمد في النهاية على الاستخدام الفعلي للـ Token وسجل الاستخدام في الاستجابة.

يدعم `quality` القيم `auto` و`low` و`medium` و`high`؛ ويدعم Flare وSunburst للإصدارين 2.5 / 2.6 (بما في ذلك متغيرات `:reverse` و`:official`) أيضًا `xhigh` و`max`. يمكن تمرير هذا الحقل في كل من تحرير روابط URL للصور عبر JSON وتحرير الملفات عبر multipart؛ وتُفرض رسوم القناة الرسمية حسب الاستخدام الفعلي للـ Token.

## 4. استخدام قناع للتحرير الجزئي

تحدد واجهة Images Edit الرسمية المنطقة المسموح بتعديلها عبر `mask`. تتبع نماذج `:official` في Ace Data Cloud عقد multipart نفسه:

- يجب أن يكون `mask` بصيغة PNG مع قناة Alpha، وألا يتجاوز حجمه 4MB؛
- يجب أن يطابق حجم القناع الصورة الأولى `image` تمامًا؛
- تمثل البكسلات الشفافة التي قيمة Alpha لها `0` المناطق المسموح بتحريرها، وتمثل البكسلات غير الشفافة المناطق التي يجب الاحتفاظ بها؛
- لا يمكن استخدام صور RGB التي تكون ألوانها بالأبيض والأسود فقط ولكنها لا تحتوي على قناة شفافية كأقنعة صالحة؛
- يجب أن يصف الموجّه المشهد الكامل المتوقع الحصول عليه، مع توضيح التعديل الجزئي والمحتوى الذي يجب أن يبقى دون تغيير.

أولًا، أنشئ قناعًا من الصورة الأصلية. يضبط المثال المستطيل المركزي ليكون شفافًا، مما يسمح للنموذج بتعديل هذه المنطقة فقط:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

ثم ارفع الصورة الأصلية والقناع معًا:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

يمكنك أيضًا الاستمرار باستخدام أسلوب استدعاء `images.edit` الخاص بـ Python SDK الرسمي لـ OpenAI، ما عليك سوى توجيه `base_url` إلى Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

عند استخدام `mask`، يجب رفع الصورة الأصلية والقناع بشكل منفصل في طلب multipart نفسه عبر `image=@input.png` و`mask=@mask.png`. لا تمرّر صورة أصلية عبر URL وملف قناع محلي معًا؛ فطلبات التحرير التي تستخدم URL فقط لا تدعم إرفاق ملف `mask` محلي إضافي. سيقيّد القناع منطقة التحرير، لكن نموذج التوليد قد لا يزال يجري دمجًا طبيعيًا عند الحواف؛ وعند الحاجة إلى حدود صارمة، يجب استخدام حواف Alpha واضحة والتأكيد في نص المطالبة على المحتوى الذي يجب أن يبقى دون تغيير.

تتوافق طريقة الاستدعاء أعلاه مع أمثلة القناع في [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) و[GPT Image Official Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. المعلمات الشائعة

| الحقل                | الوصف                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` و`gpt-image-2.5-flare` (أسرع) أو `gpt-image-2.5-sunburst` (دقة وتحكم أعلى)؛ يمكن للثلاثة اختيار متغير `:official` المقابل، كما يدعم `gpt-image-2` أيضًا `:reverse` |
| `image`           | يستخدم JSON عنوان URL واحدًا أو مصفوفة تضم حتى 16 عنوان URL؛ ويستخدم multipart حقل ملف `image` واحدًا أو أكثر. عند استخدام `mask` يجب رفع ملف صورة محلي                                              |
| `mask`            | قناع PNG اختياري، يقتصر على رفع ملفات multipart؛ يجب أن يحتوي على قناة Alpha، وأن يكون بنفس أبعاد أول `image` وألا يتجاوز 4MB                                                                 |
| `prompt`          | تعليمات التحرير                                                                                                                             |
| `size`            | `auto` أو `WIDTHxHEIGHT` المتوافق مع القيود                                                                                                     |
| `n`               | 1–10؛ يدعم `response_format=b64_json` القيمة 1 فقط                                                                                           |
| `response_format` | `url` أو `b64_json`                                                                                                               |
| `callback_url`    | عنوان اختياري لاستدعاء غير متزامن                                                                                                                         |

تتوافق قواعد الأبعاد مع واجهة التوليد: يجب أن يكون العرض والارتفاع من مضاعفات 16، وألا يتجاوز الضلع الأطول 3840، وأن يكون إجمالي البكسلات بين 655,360 و8,294,400، وألا تتجاوز نسبة العرض إلى الارتفاع 3:1. عند حذف `size` أو استخدام `auto`، سيختار النموذج أبعاد الصورة بالاستناد إلى نص المطالبة وأول صورة مرجعية.

تُحتسب رسوم `gpt-image-2` و`gpt-image-2.5-flare` و`gpt-image-2.5-sunburst` وأسماءها المستعارة `:reverse` بحسب عدد الصور الناجحة؛ أما `gpt-image-2:official` و`gpt-image-2.5-flare:official` و`gpt-image-2.5-sunburst:official` فتتم تسويتها بناءً على Tokens الفعلية للمدخلات النصية ومدخلات الصور ومخرجات الصور، ويكون السجل النهائي للاستخدام هو المرجع.

## 6. الاستدعاءات غير المتزامنة واستكشاف الأخطاء وإصلاحها

يمكن إضافة ما يلي إلى الطلبات الطويلة:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

تكون استجابة 200 غير المتزامنة بالشكل `{"task_id": "..."}`؛ وبعد الاكتمال يتم استدعاء النتيجة النهائية. أما الطلبات المتزامنة فتعيد `created` و`data`.

| الحالة  | التحقق                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | تنسيق/عدد الصور، وتركيبات المعلمات وتنسيق الأبعاد؛ عند استخدام `mask` تحقق من قناة PNG Alpha وحد 4MB وما إذا كانت أبعادها مطابقة للصورة الأصلية الأولى |
| 401 | API Key وترويسة Bearer                                           |
| 429 | معدل الطلبات                                                              |
| 504 | استخدم استدعاءً غير متزامن                                                            |

ستتضمن استجابة الخطأ `trace_id`. عند الإبلاغ عن مشكلة، قدّم هذا المعرّف، ولا تقدّم API Key.

ارجع إلى صفحة [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) للحصول على الحقول الكاملة والقيم المعدودة في الوقت الفعلي. لتوليد الصور من النص فقط، راجع [توليد الصور GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

يواصل GPT Image 2.6 استخدام واجهات 2.5 للتوليد والتحرير والمهام غير المتزامنة والفوترة:

| النموذج                                                          | الفوترة                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/صورة                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/صورة                   |
| `gpt-image-2.6-flare:official`                              | مثل 2.5 official، تُحتسب وفق الاستخدام الفعلي لـ Token |
| `gpt-image-2.6-sunburst:official`                           | مثل 2.5 official، تُحتسب وفق الاستخدام الفعلي لـ Token |

تتوفر خيارات الجودة `auto` و`low` و`medium` و`high` و`xhigh` و`max`؛ استخدم للأبعاد `auto` أو `WIDTHxHEIGHT` المتوافق مع القيود المذكورة أعلاه. تدعم هذه الواجهة `png` و`jpeg` و`webp`؛ كما يدعم GPT Image 2.6 أيضًا صور `gif` المتحركة الأصلية، ولا يدعم SVG حاليًا. يدعم التحرير عناوين URL للصور عبر JSON ورفع الملفات عبر multipart. يمثّل `:reverse` اسمًا مستعارًا صريحًا للإصدار العادي الذي يحمل الاسم نفسه. استخدم اسم الطراز الكامل، ولا تمرّر `gpt-image-2.6`.

### تحويل صور GPT Image 2.6 إلى صور GIF متحركة
يدعم كلٌّ من الإصدار العادي لـ GPT Image 2.6 Flare وSunburst و`:reverse` و`:official` استخدام `output_format: "gif"`۔ سيتم الاحتفاظ بإطارات الرسوم المتحركة ومعلومات التكرار ومدة التشغيل؛ يشير `frame_count` إلى عدد الإطارات، ويشير `frame_duration_ms` إلى عدد الملي ثانية لكل إطار، ويجب أن يكون عدد الإطارات عددًا صحيحًا من 2 إلى 16، ويجب أن تكون مدة كل إطار عددًا صحيحًا من 20 إلى 655350 ملي ثانية، وذلك لـ GIF فقط؛ يتم تقريب الترميز إلى أقرب 10ms. عند عدم التحديد، يكون الافتراضي 9 إطارات و200 ملي ثانية لكل إطار؛ عندما يكون `size` في GIF محذوفًا أو auto، يتم استخدام الإعداد المسبق 512x512.

يوصى باستخدام `size: "512x512"` و`frame_count: 9` و`frame_duration_ms: 200` أولًا. لدى GIF قيود مستقلة للحجم وعدد الإطارات، ولا يمكن تطبيق مواصفات 4K الثابتة مباشرةً؛ ستقوم بعض النماذج بتعديل حجم الإخراج الفعلي. يشير `n` إلى عدد ملفات GIF المُعادة، وليس عدد إطارات الرسوم المتحركة. لا يزال الإصدار العادي و`:reverse` يُحاسبان وفقًا لعدد الملفات الناجحة، بينما يُحاسب الإصدار الرسمي وفقًا لاستخدام Token الفعلي.

```json
{
  "model": "gpt-image-2.6-flare",
  "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
  "prompt": "Animate the mug gently moving left and right. Keep its appearance and the background, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### صور GPT Image 2.6 الثابتة بدقة 4K

يمكن لـ Flare وSunburst ومتغيراتهما `:reverse` و`:official` جميعًا استخدام إعدادات بكسل 4K المسبقة المذكورة أعلاه، مثل `3840x2160` و`2160x3840`. يتم تمرير البكسلات المحددة عبر `size` لكلٍّ من الإنشاء والتحرير؛ `4K` ليست قيمة `size` صالحة، و`4096x4096` يتجاوز أيضًا الحد الحالي للبكسلات. تنطبق مواصفات 4K المذكورة أعلاه على PNG/JPEG/WebP الثابتة، ويُرجى استخدام المعلمات المخصصة لـ GIF.

### تعقيد تكوين GPT Image 2.6

يمكن أن يكون `complexity` اختياريًا بين `low` و`medium` و`high`، ويُستخدم الإعداد الافتراضي للنموذج `high` عند حذفه. يتحكم في تعقيد التخطيط، وهو مستقل عن جودة العرض `quality`؛ ولا يتم فرض رسوم إضافية لكل مرة، بينما يستمر الإصدار الرسمي في التسوية وفقًا لـ Token الفعلي. لا تدعم النماذج الأخرى هذه المعلمة.

لا يدعم GIF القناع أو صور التعليم أو الضغط المخصص أو إعادة كتابة المطالبة أو الإخراج الجزئي لتدفق الصور؛ سيتم رفض التركيبات غير المتوافقة قبل الإنشاء. يخضع الحجم وعدد الإطارات والكمية معًا لحد ميزانية البكسلات للنموذج؛ تم التحقق من أن `1024x1024` وإطارين في Flare العادي قابلان للاستخدام، ولا يمكن توسيع هذا الاستنتاج ليشمل جميع تركيبات 1K أو GIF بدقة 4K.

### التحرير الموجَّه بالعلامات

يدعم تحرير GPT Image 2.6 الثابت `markup`. ارفع PNG شفافًا بالحجم نفسه للصورة المرجعية الأولى، وحدد في طبقة مستقلة الموضع المراد تعديله، واشرح متطلبات التعديل في `prompt`. يجب أن تحتوي طبقة التعليم على بكسلات شفافة؛ ويجب ألا تتجاوز كل صورة 16777216 بكسلًا، وألا تتجاوز صورة التعليم 40MB. يمكن لـ JSON تمرير عنوان HTTPS أو عنوان بيانات PNG base64 أو `{ "image_url": "https://..." }`؛ ويتم رفع الملف عبر `markup` في multipart. ستقوم المنصة بتمرير طبقة التعليم كملف. لا يمكن استخدام `markup` مع `mask` أو GIF أو `prompt_rewriter`، ولا يدعم `file_id`.
