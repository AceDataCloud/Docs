## 1. الحصول على مفتاح API

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، انتقل إلى التطبيقات المتاحة وانسخ مفتاح API.

![الحصول على مفتاح API من Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. استخدام URL الصورة للتحرير

الصورة الأصلية:

![تحرير الصورة الأصلية لـ GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer مفتاح API الخاص بك" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "احتفظ بالكوب، وطاولة العرض، وزاوية الكاميرا، وتخطيط الصورة، والظل الناعم دون تغيير. غير فقط لون الكوب من الأبيض إلى البرتقالي الزاهي والخلفية الكريمية الفاتحة إلى الأزرق الداكن الصلب. لا نص ولا شعار.",
    "size": "1024x1536"
  }'
```

استجابة ناجحة:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

هذه هي نتيجة التحرير التي تم إكمالها فعليًا في 8 سبتمبر 2026 عبر Ace Data Cloud، حيث أصبح الكوب برتقاليًا، والخلفية زرقاء داكنة، مع الحفاظ على التكوين الأصلي وحجم 1024×1536:

![نتيجة تحرير كوب برتقالي لـ GPT Image 2](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. رفع صورة محلية

استخدم `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer مفتاح API الخاص بك" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=استبدل الخلفية باستوديو حديث مشرق"
```

يمكن تكرار إدخال `image`، حيث تدعم سلسلة GPT Image ما يصل إلى 16 صورة مرجعية. يمكن أن يكون `image` في طلب JSON عنوان URL واحد أو مصفوفة من عناوين URL؛ يتم استخدام رفع الملفات المحلية عبر multipart.

## 4. المعلمات الشائعة

| الحقل              | الوصف                                                        |
| ----------------- | ----------------------------------------------------------- |
| `model`           | `gpt-image-2`، `gpt-image-2:official` أو `gpt-image-2:reverse` |
| `image`           | يستخدم JSON عنوان URL واحد أو مصفوفة تصل إلى 16 عنوان URL؛ يستخدم multipart حقل ملف `image` واحد أو أكثر |
| `prompt`          | تعليمات التحرير                                              |
| `size`            | `auto` أو `WIDTHxHEIGHT` متوافق مع القيود                     |
| `n`               | 1–10؛ يدعم فقط 1 عند استخدام `response_format=b64_json`     |
| `response_format` | `url` أو `b64_json`                                        |
| `callback_url`    | عنوان رد غير متزامن اختياري                                   |

قواعد الحجم متوافقة مع واجهة التوليد: يجب أن تكون الأبعاد مضاعفات 16، وألا يتجاوز الطول 3840، وإجمالي البكسلات لا يتجاوز 8,294,400. عند حذف `size` أو استخدام `auto`، سيختار النموذج نسبة العرض إلى الارتفاع بناءً على التعليمات والصورة المرجعية الأولى.

يتم احتساب `gpt-image-2` و `:reverse` بناءً على عدد الصور الناجحة؛ بينما يتم تسوية `gpt-image-2:official` بناءً على عدد الرموز الفعلية المدخلة، وصور المرجع، وصور الإخراج، مع اعتبار السجلات المستخدمة كمرجع نهائي.

## 5. ردود غير متزامنة واستكشاف الأخطاء

يمكن إضافة المهام الطويلة في الطلب:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

استجابة غير متزامنة 200 هي `{"task_id": "..."}`؛ بعد الانتهاء، يتم استدعاء النتيجة النهائية. بينما تعيد الطلبات المتزامنة `created` و `data`.

| الحالة  | الفحص                      |
| --- | ----------------------- |
| 400 | تنسيق الصورة/العدد، تركيبة المعلمات وتنسيق الحجم       |
| 401 | مفتاح API ورأس Bearer |
| 429 | معدل الطلب                    |
| 504 | استخدم رد غير متزامن                  |

ستحتوي استجابة الخطأ على `trace_id`. عند الإبلاغ عن مشكلة، يرجى تقديم هذا المعرف، وعدم تقديم مفتاح API.

تكون الحقول الكاملة والتعداد في الوقت الحقيقي وفقًا لصفحة [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). يرجى مراجعة [توليد الصور باستخدام GPT Image 2](https://platform.acedata.cloud/documents/openai-images-generations) للحصول على توليد الصور بنص عادي.
