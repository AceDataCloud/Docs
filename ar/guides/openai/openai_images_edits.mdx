## 3. رفع صورة محلية

استخدم `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

يمكن تمرير `image` بشكل متكرر، وتدعم سلسلة GPT Image حتى 16 صورة مرجعية كحد أقصى. يمكن أن تكون `image` في طلب JSON رابط URL واحدًا أو مصفوفة من عناوين URL؛ وتُرفع الملفات المحلية باستخدام multipart.

### النماذج وطريقة الفوترة

| النموذج                                | سيناريوهات الاستخدام وطريقة الفوترة                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | قناة عكسية افتراضية، بفوترة ثابتة حسب عدد الصور الناجحة                               |
| `gpt-image-2:reverse`             | اختيار صريح للقناة العكسية، بفوترة ثابتة حسب عدد الصور الناجحة                             |
| `gpt-image-2:official`            | قناة API الرسمية، باستقرار أعلى، وفوترة حسب الاستخدام الفعلي للرموز المميزة                   |
| `gpt-image-2.5-flare`             | يركز على سرعة التوليد، بفوترة ثابتة حسب عدد الصور الناجحة                               |
| `gpt-image-2.5-flare:reverse`     | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.5-flare`، بفوترة ثابتة حسب عدد الصور الناجحة    |
| `gpt-image-2.5-flare:official`    | قناة API الرسمية، باستقرار أعلى مع التركيز على سرعة التوليد، وفوترة حسب الاستخدام الفعلي للرموز المميزة            |
| `gpt-image-2.5-sunburst`          | يركز على الدقة العالية والتحكم التفصيلي، بفوترة ثابتة حسب عدد الصور الناجحة                           |
| `gpt-image-2.5-sunburst:reverse`  | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.5-sunburst`، بفوترة ثابتة حسب عدد الصور الناجحة |
| `gpt-image-2.5-sunburst:official` | قناة API الرسمية، باستقرار أعلى مع التركيز على الدقة العالية والتحكم التفصيلي، وفوترة حسب الاستخدام الفعلي للرموز المميزة        |

قد تستخدم النماذج العكسية (بما في ذلك الاسم المستعار `:reverse`) GPT Image 2.5 Flare لإكمال الطلبات أثناء الاستعادة التلقائية؛ ويبقى نموذج الطلب وطريقة الفوترة حسب عدد الصور الناجحة دون تغيير.

سعر صفحة قناة API الرسمية هو تقدير قبل الطلب، ويُعتمد في النهاية على الاستخدام الفعلي للرموز المميزة في الاستجابة وسجل الاستخدام.

يدعم `quality` القيم `auto` و`low` و`medium` و`high`؛ ويدعم فقط `gpt-image-2.5-flare` و`gpt-image-2.5-sunburst` (بما في ذلك متغيرات `:reverse` و`:official`) بشكل إضافي `xhigh` و`max`. يمكن تمرير هذا الحقل في كل من تحرير رابط صورة JSON وتحرير ملفات multipart؛ وتُفوتر القناة الرسمية حسب الاستخدام الفعلي للرموز المميزة.

## 4. استخدام قناع للتحرير الجزئي

تحدد واجهة Images Edit الرسمية المنطقة المسموح بتعديلها عبر `mask`. تتبع نماذج `:official` الخاصة بـ Ace Data Cloud عقد multipart نفسه:

- يجب أن يكون `mask` بصيغة PNG مع قناة Alpha، وألا يتجاوز حجمه 4MB؛
- يجب أن تتطابق أبعاد القناع تمامًا مع أول `image`؛
- تشير البكسلات الشفافة التي قيمة Alpha فيها `0` إلى السماح بالتحرير، بينما تشير البكسلات غير الشفافة إلى وجوب الاحتفاظ بها؛
- لا يمكن استخدام صور RGB التي تكون ألوانها بالأبيض والأسود فقط ولكن من دون قناة شفافية كأقنعة صالحة؛
- يجب أن يصف الموجّه المشهد الكامل المطلوب الحصول عليه، مع توضيح التعديلات الجزئية والمحتوى الذي يجب أن يبقى دون تغيير.

يُنشأ أدناه قناع من الصورة الأصلية أولًا. يضبط المثال المستطيل المركزي على الشفافية، ولا يسمح للنموذج بتعديل سوى هذه المنطقة:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

ثم ارفع الصورة الأصلية والقناع معًا:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

يمكن أيضًا اتباع طريقة استدعاء `images.edit` الخاصة بـ Python SDK الرسمي لـ OpenAI، مع توجيه `base_url` إلى Ace Data Cloud فقط:
```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

عند استخدام `mask`، يجب رفع الصورة الأصلية والقناع ضمن طلب multipart نفسه بشكل منفصل عبر `image=@input.png` و`mask=@mask.png`. لا تمرّر صورة أصلية عبر URL وملف قناع محلي معًا؛ فطلبات التحرير عبر URL فقط لا تدعم إرفاق ملف `mask` محلي إضافي. يقيّد القناع منطقة التحرير، لكن نموذج التوليد قد يظل يجري دمجًا طبيعيًا عند الحواف؛ وعند الحاجة إلى حدود صارمة، يجب استخدام حواف Alpha واضحة والتأكيد في نص المطالبة على المحتوى الذي يجب أن يبقى دون تغيير.

تتوافق طريقة الاستدعاء أعلاه مع أمثلة الأقنعة في [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) و[GPT Image Official Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. المعلمات الشائعة

| الحقل                | الوصف                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` أو `gpt-image-2.5-flare` (أسرع) أو `gpt-image-2.5-sunburst` (دقة وتحكم أعلى)؛ ويمكن للثلاثة اختيار متغير `:official` المقابل، كما يدعم `gpt-image-2` أيضًا `:reverse` |
| `image`           | يستخدم JSON عنوان URL واحدًا أو مصفوفة تضم حتى 16 عنوان URL؛ ويستخدم multipart حقل ملف `image` واحدًا أو أكثر. عند استخدام `mask`، يجب رفع ملف صورة محلي                                              |
| `mask`            | قناع PNG اختياري، يقتصر على رفع ملفات multipart؛ يجب أن يحتوي على قناة Alpha، وأن يكون بالحجم نفسه للصورة الأولى في `image` وألا يتجاوز 4MB                                                                 |
| `prompt`          | تعليمات التحرير                                                                                                                             |
| `size`            | `auto` أو `WIDTHxHEIGHT` مطابق للقيود                                                                                                     |
| `n`               | 1–10؛ يدعم `response_format=b64_json` القيمة 1 فقط                                                                                           |
| `response_format` | `url` أو `b64_json`                                                                                                               |
| `callback_url`    | عنوان اختياري لاستدعاء غير متزامن                                                                                                                         |

تتوافق قواعد الأبعاد مع واجهة التوليد: يجب أن يكون العرض والارتفاع من مضاعفات 16، وألا يتجاوز الضلع الأطول 3840، وأن يكون إجمالي البكسلات بين 655,360 و8,294,400، وألا تتجاوز نسبة العرض إلى الارتفاع 3:1. عند حذف `size` أو استخدام `auto`، سيختار النموذج أبعاد الصورة بالاستناد إلى نص المطالبة وأول صورة مرجعية.

يتم احتساب تكلفة `gpt-image-2` و`gpt-image-2.5-flare` و`gpt-image-2.5-sunburst` وأسماءها المستعارة `:reverse` بحسب عدد الصور الناجحة؛ بينما تتم تسوية `gpt-image-2:official` و`gpt-image-2.5-flare:official` و`gpt-image-2.5-sunburst:official` وفقًا للـ Token الفعلية للمدخلات النصية ومدخلات الصور ومخرجات الصور، ويُعتمد سجل الاستخدام النهائي.

## 6. الاستدعاءات غير المتزامنة واستكشاف الأخطاء وإصلاحها

يمكن إضافة ما يلي إلى الطلبات الطويلة:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

تكون استجابة 200 غير المتزامنة بالشكل `{"task_id": "..."}`؛ وبعد الاكتمال، يعيد الاستدعاء النتيجة النهائية. أما الطلبات المتزامنة فتعيد `created` و`data`.

| الحالة  | التحقق                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | تنسيق/عدد الصور، وتركيبات المعلمات وتنسيق الأبعاد؛ وعند استخدام `mask`، تحقّق من قناة PNG Alpha، وحد 4MB، وما إذا كانت أبعادها مطابقة للصورة الأصلية الأولى |
| 401 | API Key وBearer Header                                           |
| 429 | معدل تكرار الطلبات                                                              |
| 504 | التحويل إلى استدعاء غير متزامن                                                            |

ستتضمن استجابة الخطأ `trace_id`. عند الإبلاغ عن مشكلة، قدّم هذا المعرّف، ولا تقدّم API Key.

تُعتمد الحقول الكاملة والقيم المعدودة الفورية من صفحة [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). لتوليد الصور من نص فقط، راجع [توليد صور GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
