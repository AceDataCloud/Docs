## 3. رفع صورة محلية

استخدم `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

يمكن تمرير `image` بشكل متكرر، وتدعم سلسلة GPT Image حتى 16 صورة مرجعية. يمكن أن تكون `image` في طلب JSON رابط URL واحدًا أو مصفوفة من روابط URL؛ وتُرفع الملفات المحلية عبر multipart.

### النموذج وطريقة الفوترة

| النموذج                                | سيناريوهات الاستخدام وطريقة الفوترة                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | قناة عكسية افتراضية، بفوترة ثابتة حسب عدد الصور الناجحة                        |
| `gpt-image-2:reverse`             | اختيار صريح للقناة العكسية، بفوترة ثابتة حسب عدد الصور الناجحة                      |
| `gpt-image-2:official`            | قناة API رسمية، باستقرار أعلى، وفوترة حسب استخدام Token الفعلي            |
| `gpt-image-2.5-flare`             | يركز على سرعة التوليد، بفوترة ثابتة حسب عدد الصور الناجحة                        |
| `gpt-image-2.5-flare:official`    | قناة API رسمية، باستقرار أعلى وتركيز على سرعة التوليد، وفوترة حسب استخدام Token الفعلي     |
| `gpt-image-2.5-sunburst`          | يركز على الدقة العالية والتحكم التفصيلي، بفوترة ثابتة حسب عدد الصور الناجحة                    |
| `gpt-image-2.5-sunburst:official` | قناة API رسمية، باستقرار أعلى وتركيز على الدقة العالية والتحكم التفصيلي، وفوترة حسب استخدام Token الفعلي |

سعر صفحة قناة API الرسمية هو تقدير قبل الطلب، ويُعتمد نهائيًا على استخدام Token الفعلي وسجل الاستخدام في الاستجابة.

## 4. استخدام قناع للتحرير الموضعي

تحدد واجهة Images Edit الرسمية المنطقة المسموح بتعديلها عبر `mask`. تتبع نماذج `:official` الخاصة بـ Ace Data Cloud عقد multipart نفسه:

- يجب أن يكون `mask` ملف PNG يحتوي على قناة Alpha، وألا يتجاوز حجمه 4MB؛
- يجب أن يتطابق حجم القناع تمامًا مع الصورة الأولى `image`؛
- تشير البكسلات الشفافة ذات Alpha بقيمة `0` إلى السماح بالتحرير، بينما تشير البكسلات غير الشفافة إلى ما يجب الاحتفاظ به؛
- لا يمكن استخدام صور RGB التي تكون ألوانها بالأبيض والأسود فقط ولكن لا تحتوي على قناة شفافية كأقنعة صالحة؛
- يجب أن يصف النص التوجيهي المشهد الكامل المتوقع، مع توضيح التعديلات الموضعية والمحتوى الذي يجب أن يبقى دون تغيير.

يُنشئ ما يلي أولًا قناعًا من الصورة الأصلية. يضبط المثال المستطيل المركزي على الشفافية، مما يسمح للنموذج بتعديل هذه المنطقة فقط:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

ثم ارفع الصورة الأصلية والقناع معًا:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

يمكنك أيضًا متابعة أسلوب استدعاء `images.edit` الخاص بـ Python SDK الرسمي من OpenAI، ما عليك سوى توجيه `base_url` إلى Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

عند استخدام `mask`، يجب رفع الصورة الأصلية والقناع ضمن طلب multipart نفسه عبر `image=@input.png` و`mask=@mask.png` على التوالي. لا تخلط بين صورة أصلية عبر URL وملف قناع محلي عند تمريرهما؛ إذ لا تدعم طلبات التحرير التي تعتمد على URL فقط إرفاق ملف `mask` محلي إضافي. يقيّد القناع منطقة التحرير، لكن نموذج التوليد قد لا يزال يجري دمجًا طبيعيًا عند الحواف؛ وعند الحاجة إلى حدود صارمة، يجب استخدام حواف Alpha واضحة والتأكيد في النص التوجيهي على المحتوى الذي يجب أن يبقى دون تغيير.

تتوافق طريقة الاستدعاء المذكورة أعلاه مع أمثلة الأقنعة في [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) و[GPT Image Official Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. المعلمات الشائعة
| الحقل                | الوصف                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` أو `gpt-image-2.5-flare` (أسرع) أو `gpt-image-2.5-sunburst` (دقة وتحكم أعلى)؛ يمكن للثلاثة جميعًا اختيار متغير `:official` المقابل، كما يدعم `gpt-image-2` أيضًا `:reverse` |
| `image`           | يستخدم JSON عنوان URL واحدًا أو مصفوفة تضم حتى 16 عنوان URL؛ ويستخدم multipart حقل ملف `image` واحدًا أو أكثر. يجب رفع ملف صورة محلي عند استخدام `mask`                                              |
| `mask`            | قناع PNG اختياري، يقتصر على رفع الملفات عبر multipart؛ يجب أن يحتوي على قناة Alpha، وأن يكون بنفس أبعاد أول `image` وألا يتجاوز 4MB                                                                 |
| `prompt`          | تعليمات التحرير                                                                                                                             |
| `size`            | `auto` أو `WIDTHxHEIGHT` المتوافق مع القيود                                                                                                     |
| `n`               | 1–10؛ يدعم 1 فقط عند `response_format=b64_json`                                                                                           |
| `response_format` | `url` أو `b64_json`                                                                                                               |
| `callback_url`    | عنوان رد نداء غير متزامن اختياري                                                                                                                         |

تتطابق قواعد الأبعاد مع واجهة التوليد: يجب أن يكون العرض والارتفاع من مضاعفات 16، وألا يتجاوز الضلع الأطول 3840، وأن يكون إجمالي البكسلات 655,360–8,294,400، وألا تتجاوز نسبة العرض إلى الارتفاع 3:1. عند حذف `size` أو استخدام `auto`، سيختار النموذج أبعاد اللوحة بالاستناد إلى نص الطلب وأول صورة مرجعية.

تتم محاسبة `gpt-image-2` و`gpt-image-2.5-flare` و`gpt-image-2.5-sunburst` و`gpt-image-2:reverse` حسب عدد الصور الناجحة؛ بينما تتم تسوية `gpt-image-2:official` و`gpt-image-2.5-flare:official` و`gpt-image-2.5-sunburst:official` وفقًا للـ Token الفعلي لمدخلات النص ومدخلات الصور ومخرجات الصور، ويُعتد بسجل الاستخدام النهائي.

## 6. رد النداء غير المتزامن واستكشاف الأخطاء وإصلاحها

يمكن للمهام الطويلة إضافة ما يلي في الطلب:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

تكون استجابة 200 غير المتزامنة هي `{"task_id": "..."}`؛ وبعد الإكمال، يتم رد نداء النتيجة النهائية. أما الطلبات المتزامنة فتعيد `created` و`data`.

| الحالة  | الفحص                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | تنسيق/عدد الصور، وتركيبات المعلمات وتنسيق الأبعاد؛ عند استخدام `mask`، تحقق من قناة Alpha في PNG، وحد 4MB، وما إذا كانت أبعاده متطابقة مع أول صورة أصلية |
| 401 | API Key وBearer Header                                           |
| 429 | معدل تكرار الطلبات                                                              |
| 504 | استخدم رد النداء غير المتزامن                                                            |

ستتضمن استجابة الخطأ `trace_id`. عند الإبلاغ عن مشكلة، قدم هذا المعرّف، ولا تقدم API Key.

للحصول على الحقول الكاملة والقيم المعدودة في الوقت الفعلي، راجع صفحة [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). لإنشاء الصور من النص فقط، راجع [توليد صور GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
