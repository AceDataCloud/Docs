## 2. التحرير باستخدام رابط الصورة URL

الصورة الأصلية:

![الصورة الأصلية لتحرير GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
```

## 3. رفع صورة محلية

استخدم `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

يمكن تمرير `image` بشكل متكرر، وتدعم سلسلة GPT Image حتى 16 صورة مرجعية. يمكن أن تكون `image` في طلب JSON رابط URL واحدًا أو مصفوفة من روابط URL؛ وتُرفع الملفات المحلية باستخدام multipart.

### النماذج وطريقة الفوترة

| النموذج                                | سيناريوهات الاستخدام وطريقة الفوترة                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | قناة عكسية افتراضية، بفوترة ثابتة حسب عدد الصور الناجحة                        |
| `gpt-image-2:reverse`             | اختيار صريح للقناة العكسية، بفوترة ثابتة حسب عدد الصور الناجحة                      |
| `gpt-image-2:official`            | قناة API رسمية، باستقرار أعلى، وبفوترة حسب استخدام Token الفعلي            |
| `gpt-image-2.5-flare`             | تركيز على سرعة التوليد، بفوترة ثابتة حسب عدد الصور الناجحة                        |
| `gpt-image-2.5-flare:official`    | قناة API رسمية، باستقرار أعلى وتركيز على سرعة التوليد، وبفوترة حسب استخدام Token الفعلي     |
| `gpt-image-2.5-sunburst`          | تركيز على الدقة العالية والتحكم التفصيلي، بفوترة ثابتة حسب عدد الصور الناجحة                    |
| `gpt-image-2.5-sunburst:official` | قناة API رسمية، باستقرار أعلى وتركيز على الدقة العالية والتحكم التفصيلي، وبفوترة حسب استخدام Token الفعلي |

سعر صفحة قناة API الرسمية هو تقدير قبل الطلب، ويعتمد السعر النهائي على استخدام Token الفعلي وسجل الاستخدام في الاستجابة.

## 4. استخدام القناع للتحرير الموضعي

تحدد واجهة Images Edit الرسمية المنطقة المسموح بتعديلها عبر `mask`. وتتبع نماذج `:official` في Ace Data Cloud نفس عقد multipart:

- يجب أن يكون `mask` ملف PNG مع قناة Alpha، وألا يتجاوز حجمه 4MB؛
- يجب أن تتطابق أبعاد القناع تمامًا مع أول `image`؛
- تشير البكسلات الشفافة ذات Alpha بقيمة `0` إلى السماح بالتحرير، بينما تشير البكسلات غير الشفافة إلى وجوب الاحتفاظ بها؛
- لا يمكن استخدام صور RGB التي تكون ألوانها بالأبيض والأسود فقط، ولكنها لا تحتوي على قناة شفافية، كقناع صالح؛
- يجب أن يصف النص التوجيهي الصورة الكاملة المتوقعة، مع توضيح التعديل الموضعي والمحتوى الذي يجب أن يبقى دون تغيير.

فيما يلي، يتم أولًا إنشاء قناع من الصورة الأصلية. يضبط المثال المستطيل المركزي ليكون شفافًا، بحيث يُسمح للنموذج بتعديل تلك المنطقة فقط:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

ثم ارفع الصورة الأصلية والقناع معًا:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

يمكن أيضًا الاستمرار باستخدام طريقة استدعاء `images.edit` الخاصة بـ Python SDK الرسمي من OpenAI، ما عليك سوى توجيه `base_url` إلى Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

عند استخدام `mask`، يجب رفع الصورة الأصلية والقناع في طلب multipart نفسه بشكل منفصل عبر `image=@input.png` و`mask=@mask.png`. لا تخلط بين الصورة الأصلية عبر URL وملف القناع المحلي عند الإرسال؛ إذ لا تدعم طلبات التحرير التي تعتمد على URL فقط إرفاق ملف `mask` محلي إضافي. سيقيّد القناع منطقة التحرير، لكن نموذج التوليد قد يظل يجري دمجًا طبيعيًا عند الحواف؛ وعند الحاجة إلى حدود صارمة، يجب استخدام حواف Alpha واضحة وتكرار توضيح المحتوى الذي يجب أن يبقى دون تغيير في النص التوجيهي.

تتوافق طريقة الاستدعاء أعلاه مع مثال القناع في [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) و[GPT Image Cookbook الرسمي](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).
## 5. المعلمات الشائعة

| الحقل                | الوصف                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`، أو `gpt-image-2.5-flare` (أسرع)، أو `gpt-image-2.5-sunburst` (دقة وتحكم أعلى)؛ يمكن للثلاثة جميعًا اختيار نسخة `:official` المقابلة، كما يدعم `gpt-image-2` أيضًا `:reverse` |
| `image`           | يستخدم JSON عنوان URL واحدًا أو مصفوفة تضم ما يصل إلى 16 عنوان URL؛ ويستخدم multipart حقل ملف `image` واحدًا أو أكثر. عند استخدام `mask` يجب رفع ملف صورة محلي                                              |
| `mask`            | قناع PNG اختياري، يقتصر على رفع ملفات multipart؛ يجب أن يحتوي على قناة Alpha، وأن يكون بنفس أبعاد أول `image` وألا يتجاوز 4MB                                                                 |
| `prompt`          | تعليمات التحرير                                                                                                                             |
| `size`            | `auto` أو `WIDTHxHEIGHT` المتوافق مع القيود                                                                                                     |
| `n`               | 1–10؛ عند `response_format=b64_json` يدعم 1 فقط                                                                                           |
| `response_format` | `url` أو `b64_json`                                                                                                               |
| `callback_url`    | عنوان رد اتصال غير متزامن اختياري                                                                                                                         |

تتوافق قواعد الأبعاد مع واجهة التوليد: يجب أن يكون العرض والارتفاع من مضاعفات 16، وألا يتجاوز الضلع الأطول 3840، وأن يكون إجمالي البكسلات بين 655,360–8,294,400، وألا تتجاوز نسبة العرض إلى الارتفاع 3:1. عند حذف `size` أو استخدام `auto`، سيختار النموذج أبعاد اللوحة بالاستناد إلى نص المطالبة وأول صورة مرجعية.

يتم احتساب `gpt-image-2` و`gpt-image-2.5-flare` و`gpt-image-2.5-sunburst` و`gpt-image-2:reverse` حسب عدد الصور الناجحة؛ بينما تتم تسوية `gpt-image-2:official` و`gpt-image-2.5-flare:official` و`gpt-image-2.5-sunburst:official` وفقًا لرموز Token الفعلية لإدخال النصوص وإدخال الصور المرجعية وإخراج الصور، ويُعتد بسجل الاستخدام النهائي.

## 6. رد الاتصال غير المتزامن واستكشاف الأخطاء وإصلاحها

يمكن للمهام الطويلة إضافة ما يلي في الطلب:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

تكون استجابة 200 غير المتزامنة هي `{"task_id": "..."}`؛ وبعد الإكمال يتم رد الاتصال بالنتيجة النهائية. أما الطلبات المتزامنة فتُرجع `created` و`data`.

| الحالة  | التحقق                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | تنسيق/عدد الصور، ومجموعات المعلمات وتنسيق الأبعاد؛ عند استخدام `mask` تحقق من قناة PNG Alpha، وحد 4MB، وما إذا كانت أبعاده متطابقة مع أول صورة أصلية |
| 401 | مفتاح API وترويسة Bearer                                           |
| 429 | معدل تكرار الطلبات                                                              |
| 504 | التحويل إلى رد اتصال غير متزامن                                                            |

ستتضمن استجابة الخطأ `trace_id`. عند الإبلاغ عن مشكلة، قدم هذا المعرّف، ولا تقدم مفتاح API.

للحصول على الحقول الكاملة والتعدادات الفورية، يُرجى الرجوع إلى صفحة [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). لإنشاء الصور من النص فقط، يُرجى الاطلاع على [توليد صور GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
