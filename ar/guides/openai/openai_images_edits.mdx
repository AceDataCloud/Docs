## 3. رفع صور محلية

استخدم `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

يمكن تمرير `image` بشكل متكرر، وتدعم سلسلة GPT Image حتى 16 صورة مرجعية. يمكن أن تكون `image` في طلب JSON عنوان URL واحدًا أو مصفوفة من عناوين URL؛ وتُرفع الملفات المحلية باستخدام multipart.

### النماذج وطريقة الفوترة

| النموذج                                | سيناريوهات الاستخدام وطريقة الفوترة                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | قناة عكسية افتراضية، بفوترة ثابتة حسب عدد الصور الناجحة                               |
| `gpt-image-2:reverse`             | اختيار صريح للقناة العكسية، بفوترة ثابتة حسب عدد الصور الناجحة                             |
| `gpt-image-2:official`            | قناة API رسمية، باستقرار أعلى، وبفوترة حسب الاستخدام الفعلي للرموز                   |
| `gpt-image-2.5-flare`             | يركز على سرعة التوليد، بفوترة ثابتة حسب عدد الصور الناجحة                               |
| `gpt-image-2.6-flare`             | يركز على سرعة التوليد، بفوترة ثابتة حسب عدد الصور الناجحة                               |
| `gpt-image-2.5-flare:reverse`     | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.5-flare`، بفوترة ثابتة حسب عدد الصور الناجحة    |
| `gpt-image-2.6-flare:reverse`     | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.6-flare`، بفوترة ثابتة حسب عدد الصور الناجحة    |
| `gpt-image-2.5-flare:official`    | قناة API رسمية، باستقرار أعلى مع التركيز على سرعة التوليد، وبفوترة حسب الاستخدام الفعلي للرموز            |
| `gpt-image-2.6-flare:official`    | قناة API رسمية، باستقرار أعلى مع التركيز على سرعة التوليد، وبفوترة حسب الاستخدام الفعلي للرموز            |
| `gpt-image-2.5-sunburst`          | يركز على الدقة العالية والتحكم التفصيلي، بفوترة ثابتة حسب عدد الصور الناجحة                           |
| `gpt-image-2.6-sunburst`          | يركز على الدقة العالية والتحكم التفصيلي، بفوترة ثابتة حسب عدد الصور الناجحة                           |
| `gpt-image-2.5-sunburst:reverse`  | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.5-sunburst`، بفوترة ثابتة حسب عدد الصور الناجحة |
| `gpt-image-2.6-sunburst:reverse`  | اسم مستعار عكسي صريح، مكافئ لـ `gpt-image-2.6-sunburst`، بفوترة ثابتة حسب عدد الصور الناجحة |
| `gpt-image-2.5-sunburst:official` | قناة API رسمية، باستقرار أعلى مع التركيز على الدقة العالية والتحكم التفصيلي، وبفوترة حسب الاستخدام الفعلي للرموز        |
| `gpt-image-2.6-sunburst:official` | قناة API رسمية، باستقرار أعلى مع التركيز على الدقة العالية والتحكم التفصيلي، وبفوترة حسب الاستخدام الفعلي للرموز        |

قد تستخدم نماذج 2.0 / 2.5 العكسية (بما في ذلك الاسم المستعار `:reverse`) GPT Image 2.5 Flare لإكمال الطلب عند الاسترداد التلقائي؛ ويظل نموذج الطلب وطريقة الفوترة حسب عدد الصور الناجحة دون تغيير.

سعر الصفحة لقناة API الرسمية هو تقدير قبل الطلب، ويُعتمد نهائيًا على الاستخدام الفعلي للرموز في الاستجابة وسجل الاستخدام.

يدعم `quality` القيم `auto` و`low` و`medium` و`high`؛ وتدعم Flare وSunburst 2.5 / 2.6 (بما في ذلك متغيرات `:reverse` و`:official`) أيضًا `xhigh` و`max`. يمكن تمرير هذا الحقل في كل من تحرير عناوين URL للصور عبر JSON وتحرير الملفات عبر multipart؛ وتُحتسب رسوم القناة الرسمية حسب الاستخدام الفعلي للرموز.

## 4. استخدام قناع للتحرير الموضعي

تحدد واجهة Images Edit الرسمية المنطقة المسموح بتعديلها عبر `mask`. تتبع نماذج `:official` من Ace Data Cloud عقد multipart نفسه:

- يجب أن يكون `mask` بصيغة PNG مع قناة Alpha، وألا يتجاوز حجمه 4MB؛
- يجب أن يتطابق حجم القناع تمامًا مع أول `image`؛
- تشير البكسلات الشفافة التي تكون قيمة Alpha فيها `0` إلى السماح بالتحرير، وتشير البكسلات غير الشفافة إلى وجوب الاحتفاظ بها؛
- لا يمكن استخدام صور RGB التي تكون ألوانها أبيض وأسود فقط، ولكن دون قناة شفافية، كقناع صالح؛
- يجب أن يصف الموجّه المشهد الكامل المتوقع، مع توضيح التعديل الموضعي والمحتوى الذي يجب أن يبقى دون تغيير.

فيما يلي، يُنشأ قناع أولًا من الصورة الأصلية. يضبط المثال المستطيل المركزي على أنه شفاف، بحيث يسمح للنموذج بتعديل هذه المنطقة فقط:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

ثم ارفع الصورة الأصلية والقناع معًا:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

يمكنك أيضًا الاستمرار في استخدام أسلوب استدعاء `images.edit` الخاص بـ Python SDK الرسمي من OpenAI، ما عليك سوى توجيه `base_url` إلى Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

عند استخدام `mask`، يجب رفع الصورة الأصلية والقناع بشكل منفصل ضمن طلب multipart نفسه عبر `image=@input.png` و`mask=@mask.png`. لا تمرر صورة أصلية عبر URL وملف قناع محلي معًا؛ فطلبات التحرير التي تستخدم URL فقط لا تدعم إرفاق ملف `mask` محلي إضافي. سيقيّد القناع منطقة التحرير، لكن نموذج التوليد قد يظل يدمج الحواف بصورة طبيعية؛ وعند الحاجة إلى حدود صارمة، يجب استخدام حواف Alpha واضحة وتكرار توضيح المحتوى الذي يجب أن يبقى دون تغيير في الموجّه.

يتوافق أسلوب الاستدعاء أعلاه مع أمثلة الأقنعة في [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) و[GPT Image Official Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. المعلمات الشائعة

| الحقل                | الوصف                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` أو `gpt-image-2.5-flare` (أسرع) أو `gpt-image-2.5-sunburst` (دقة وتحكم أعلى)؛ يمكن للثلاثة اختيار متغير `:official` المقابل، كما يدعم `gpt-image-2` أيضًا `:reverse` |
| `image`           | يستخدم JSON عنوان URL واحدًا أو مصفوفة تضم حتى 16 عنوان URL؛ ويستخدم multipart حقل ملف `image` واحدًا أو أكثر. عند استخدام `mask` يجب رفع ملف صورة محلي                                              |
| `mask`            | قناع PNG اختياري، يقتصر على رفع ملفات multipart؛ يجب أن يحتوي على قناة Alpha، وأن يكون بالحجم نفسه للصورة الأولى في `image` وألا يتجاوز 4MB                                                                 |
| `prompt`          | تعليمات التحرير                                                                                                                             |
| `size`            | `auto` أو `WIDTHxHEIGHT` المتوافق مع القيود                                                                                                     |
| `n`               | 1–10؛ عند استخدام `response_format=b64_json`، لا يُدعم إلا 1                                                                                           |
| `response_format` | `url` أو `b64_json`                                                                                                               |
| `callback_url`    | عنوان رد اتصال اختياري غير متزامن                                                                                                                         |

تتوافق قواعد الحجم مع واجهة التوليد: يجب أن يكون العرض والارتفاع من مضاعفات 16، وألا يتجاوز الضلع الطويل 3840، وأن يكون إجمالي البكسلات بين 655,360–8,294,400، وألا تتجاوز نسبة العرض إلى الارتفاع 3:1. عند حذف `size` أو استخدام `auto`، سيختار النموذج أبعاد اللوحة استنادًا إلى الموجّه وأول صورة مرجعية.

تُحتسب رسوم `gpt-image-2` و`gpt-image-2.5-flare` و`gpt-image-2.5-sunburst` وأسماءها المستعارة `:reverse` بحسب عدد الصور الناجحة؛ أما `gpt-image-2:official` و`gpt-image-2.5-flare:official` و`gpt-image-2.5-sunburst:official` فتتم تسويتها وفقًا لـ Token الفعلية للمدخلات النصية ومدخلات الصور ومخرجات الصور، ويكون سجل الاستخدام هو المرجع النهائي.

## 6. رد الاتصال غير المتزامن واستكشاف الأخطاء وإصلاحها

يمكن إضافة ما يلي إلى الطلبات الطويلة:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

تكون استجابة 200 غير المتزامنة هي `{"task_id": "..."}`؛ وبعد الاكتمال، يعيد رد الاتصال النتيجة النهائية. أما الطلبات المتزامنة فتعيد `created` و`data`.

| الحالة  | التحقق                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | تنسيق/عدد الصور، وتركيبات المعلمات وتنسيق الحجم؛ عند استخدام `mask`، تحقق من قناة PNG Alpha، وحد 4MB، وما إذا كان حجمها يطابق الصورة الأصلية الأولى |
| 401 | API Key وBearer Header                                           |
| 429 | معدل الطلبات                                                              |
| 504 | التحويل إلى رد اتصال غير متزامن                                                            |

ستحتوي استجابة الخطأ على `trace_id`. عند الإبلاغ عن مشكلة، قدم هذا المعرّف، ولا تقدم API Key.

للاطلاع على الحقول الكاملة والتعدادات الفورية، راجع صفحة [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). لتوليد الصور من نص فقط، راجع [توليد صور GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

يواصل GPT Image 2.6 استخدام واجهات 2.5 للتوليد والتحرير والمهام غير المتزامنة والفوترة:

| النموذج                                                          | الفوترة                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/صورة                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/صورة                   |
| `gpt-image-2.6-flare:official`                              | مماثلة لـ 2.5 official، وتُحتسب وفقًا لاستخدام Token الفعلي |
| `gpt-image-2.6-sunburst:official`                           | مماثلة لـ 2.5 official، وتُحتسب وفقًا لاستخدام Token الفعلي |

يمكن اختيار الجودة من `auto` و`low` و`medium` و`high` و`xhigh` و`max`؛ ويستخدم الحجم `auto` أو `WIDTHxHEIGHT` المتوافق مع القيود المذكورة أعلاه. تدعم هذه الواجهة `png` و`jpeg` و`webp`؛ كما يدعم GPT Image 2.6 أيضًا صور `gif` المتحركة الأصلية، ولا يدعم SVG حاليًا. يدعم التحرير عناوين URL للصور بصيغة JSON ورفع ملفات multipart. يُعد `:reverse` اسمًا مستعارًا صريحًا للإصدار العادي الذي يحمل الاسم نفسه. يرجى استخدام اسم الطراز الكامل، ولا تمرر `gpt-image-2.6`.

### تحويل صور GPT Image 2.6 إلى صور GIF متحركة
يمكن للإصدار العادي من Flare، و`:reverse`، و`:official`، وكذلك `gpt-image-2.6-sunburst:official` استخدام `output_format: "gif"`۔ لا يتوفر GIF مؤقتًا للإصدار العادي من Sunburst و`:reverse`، مع استمرار دعم إنشاء الصور الثابتة وتحريرها. سيتم الاحتفاظ بإطارات الرسوم المتحركة ومعلومات التكرار ومدة التشغيل؛ يشير `frame_count` إلى عدد الإطارات، ويشير `frame_duration_ms` إلى عدد المللي ثانية لكل إطار، ويجب أن يكون كلاهما عددًا صحيحًا موجبًا، ويُستخدمان لـ GIF فقط. عند عدم التحديد، يكون الافتراضي 9 إطارات و200 مللي ثانية لكل إطار؛ عند حذف حجم GIF أو كونه auto، يتم استخدام الإعداد المسبق 512x512.

يُوصى بالبدء باستخدام `size: "512x512"`، و`frame_count: 9`، و`frame_duration_ms: 200`۔ لدى GIF قيود مستقلة للحجم وعدد الإطارات، ولا يمكن تطبيق مواصفات 4K الثابتة مباشرةً؛ قد تعدّل بعض النماذج حجم الإخراج الفعلي. يشير `n` إلى عدد ملفات GIF المُعادة، وليس عدد إطارات الرسوم المتحركة. يظل الإصدار العادي و`:reverse` محاسبين حسب عدد الملفات الناجحة، بينما تُحاسَب الإصدارات الرسمية حسب استخدام Token الفعلي.

```json
{
  "model": "gpt-image-2.6-flare",
  "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
  "prompt": "Animate the mug gently moving left and right. Keep its appearance and the background, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### صور GPT Image 2.6 الثابتة بدقة 4K

يمكن لـ Flare وSunburst ومتغيراتهما `:reverse` و`:official` جميعًا استخدام إعدادات بكسل 4K المسبقة المذكورة أعلاه، مثل `3840x2160` و`2160x3840`۔ يتم تمرير البكسلات المحددة عبر `size` لكل من الإنشاء والتحرير؛ `4K` ليست قيمة `size` صالحة، و`4096x4096` يتجاوز أيضًا الحد الحالي للبكسلات. تنطبق مواصفات 4K المذكورة أعلاه على PNG/JPEG/WebP الثابتة، ويُرجى استخدام المعلمات المخصصة لـ GIF.
