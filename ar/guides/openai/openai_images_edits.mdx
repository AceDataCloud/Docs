## 3. رفع صورة محلية

استخدم `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

يمكن تمرير `image` بشكل متكرر، وتدعم سلسلة GPT Image حتى 16 صورة مرجعية كحد أقصى. يمكن أن يكون `image` في طلبات JSON رابط URL واحدًا أو مصفوفة من روابط URL؛ وتُرفع الملفات المحلية باستخدام multipart.

## 4. استخدام قناع للتحرير الجزئي

تستخدم واجهة Images Edit الرسمية `mask` لتحديد المنطقة المسموح بتعديلها. وتتبع نماذج `:official` من Ace Data Cloud عقد multipart نفسه:

- يجب أن يكون `mask` بصيغة PNG مع قناة Alpha، وألا يتجاوز حجمه 4MB؛
- يجب أن تتطابق أبعاد القناع تمامًا مع أول `image`؛
- تشير البكسلات الشفافة التي تكون قيمة Alpha فيها `0` إلى السماح بالتحرير، بينما تشير البكسلات غير الشفافة إلى وجوب الاحتفاظ بها؛
- لا يمكن لصورة RGB التي تكون ألوانها بالأبيض والأسود فقط ولكنها لا تحتوي على قناة شفافية أن تكون قناعًا صالحًا؛
- يجب أن يصف الطلب النصي المشهد الكامل المتوقع الحصول عليه، مع توضيح التعديل الجزئي والمحتوى الذي يجب أن يبقى دون تغيير.

أنشئ أولًا قناعًا من الصورة الأصلية. يضبط المثال المستطيل المركزي ليكون شفافًا، ولا يسمح للنموذج بتعديل سوى تلك المنطقة:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

ثم ارفع الصورة الأصلية والقناع معًا:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

يمكنك أيضًا اتباع أسلوب استدعاء `images.edit` الخاص بـ Python SDK الرسمي لـ OpenAI، ما عليك سوى توجيه `base_url` إلى Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

يُقدَّم `mask` حاليًا كحقل ملف multipart. عند الحاجة إلى تمرير الصورة الأصلية عبر URL، يُرجى أيضًا تغيير الطلب إلى multipart: يمكن أن يبقى `image` كحقل نصي لـ URL، ويُرفع `mask` باستخدام `@mask.png`. سيقيّد القناع منطقة التحرير، لكن نموذج التوليد قد يستمر في دمج الحواف بصورة طبيعية؛ وعند الحاجة إلى حدود صارمة، ينبغي استخدام حواف Alpha واضحة والتأكيد مرارًا في الطلب النصي على المحتوى الذي يجب أن يبقى دون تغيير.

يتوافق أسلوب الاستدعاء أعلاه مع أمثلة الأقنعة في [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) و[GPT Image Official Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. المعلمات الشائعة

| الحقل                | الوصف                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` أو `gpt-image-2.5-flare` (أسرع) أو `gpt-image-2.5-sunburst` (دقة وتحكم أعلى)؛ ويمكن للثلاثة جميعًا اختيار متغير `:official` المقابل، كما يدعم `gpt-image-2` أيضًا `:reverse` |
| `image`           | يستخدم JSON رابط URL واحدًا أو مصفوفة تضم حتى 16 رابط URL؛ ويستخدم multipart حقل ملف `image` واحدًا أو أكثر                                                                    |
| `prompt`          | تعليمات التحرير                                                                                                                             |
| `size`            | `auto` أو `WIDTHxHEIGHT` متوافق مع القيود                                                                                                     |
| `n`               | 1–10؛ وعند `response_format=b64_json` لا يُدعم سوى 1                                                                                           |
| `response_format` | `url` أو `b64_json`                                                                                                               |
| `callback_url`    | عنوان رد اتصال غير متزامن اختياري                                                                                                                         |

تتوافق قواعد المقاس مع واجهة التوليد: يجب أن يكون العرض والارتفاع من مضاعفات 16، وألا يتجاوز الضلع الأطول 3840، وأن يكون إجمالي البكسلات بين 655,360 و8,294,400، وألا تتجاوز نسبة العرض إلى الارتفاع 3:1. عند حذف `size` أو استخدام `auto`، سيختار النموذج أبعاد الصورة بناءً على الطلب النصي وأول صورة مرجعية.
`gpt-image-2` و`gpt-image-2.5-flare` و`gpt-image-2.5-sunburst` و`gpt-image-2:reverse` تُحتسب حسب عدد الصور الناجحة؛ أما `gpt-image-2:official` و`gpt-image-2.5-flare:official` و`gpt-image-2.5-sunburst:official` فتُسوّى بناءً على الـ Token الفعلية لإدخال النصوص وإدخال الصور المرجعية وإخراج الصور، ويُعتمد سجل الاستخدام النهائي.

## 6. الاستدعاءات غير المتزامنة واستكشاف الأخطاء وإصلاحها

يمكن للمهام الطويلة إضافة ما يلي في الطلب:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

تكون استجابة 200 غير المتزامنة هي `{"task_id": "..."}`؛ وبعد الإكمال، يُستدعى الناتج النهائي. أما الطلبات المتزامنة فتعيد `created` و`data`.

| الحالة  | التحقق                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | تنسيق/عدد الصور، وتوليفات المعلمات وتنسيق الأبعاد؛ عند استخدام `mask`، تحقّق من قناة PNG Alpha وحد 4MB وما إذا كانت أبعادها متطابقة مع الصورة الأصلية الأولى |
| 401 | API Key وBearer Header                                           |
| 429 | معدل تكرار الطلبات                                                              |
| 504 | استخدم الاستدعاء غير المتزامن                                                            |

ستتضمن استجابة الخطأ `trace_id`. عند الإبلاغ عن مشكلة، قدّم هذا المعرّف، ولا تقدّم API Key.

تعتمد الحقول الكاملة والتعدادات الفورية على صفحة [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). لإنشاء الصور من النصوص فقط، يرجى الاطلاع على [إنشاء الصور باستخدام GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
