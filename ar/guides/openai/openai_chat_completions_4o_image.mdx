يُعد OpenAI ChatGPT نظام حوار ذكي قوي للغاية، حيث يمكنه توليد ردود طبيعية وسلسة في غضون ثوانٍ فقط بمجرد إدخال الكلمات المفتاحية. يتميز ChatGPT بقدراته الممتازة في فهم اللغة وتوليدها، مما يجعله فريدًا في المجال. اليوم، يُستخدم ChatGPT على نطاق واسع في مختلف الصناعات والمجالات، وتأثيره أصبح أكثر وضوحًا. سواء في المحادثات اليومية، أو الكتابة الإبداعية، أو الاستشارات المهنية، أو برمجة الأكواد، يمكن لـ ChatGPT تقديم مساعدة ذكية مذهلة، مما يعزز بشكل كبير كفاءة الإنسان وإبداعه.

تتناول هذه الوثيقة بشكل رئيسي خطوات استخدام واجهة برمجة تطبيقات OpenAI Chat Completion 4o Image، والتي تتيح لنا بسهولة استخدام وظيفة الحوار متعددة الوسائط الرسمية لـ OpenAI ChatGPT.

## خطوات الطلب

لاستخدام واجهة برمجة تطبيقات OpenAI Chat Completion 4o Image، يمكنك أولاً الذهاب إلى صفحة [OpenAI Chat Completion 4o Image API](https://platform.acedata.cloud/documents/1bcf3bba-102b-495d-9bba-47cd96717e45) والنقر على زر "Acquire" للحصول على بيانات الاعتماد المطلوبة للطلب:

![](https://cdn.acedata.cloud/nyq0xz.png)

إذا لم تكن قد سجلت الدخول أو أنشأت حسابًا بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لتسجيل حساب جديد أو تسجيل الدخول، وبعد ذلك ستعود تلقائيًا إلى الصفحة الحالية.

عند الطلب لأول مرة، ستحصل على حصة مجانية لاستخدام هذه الواجهة مجانًا.

## نموذج الرسم GPT-4o

### توليد صورة بناءً على صورة مرجعية

فيما يلي مثال على توليد صورة بأسلوب مخصص بناءً على صورة واحدة، دعونا أولاً نلقي نظرة على الصورة التي أدخلناها كما هو موضح أدناه:

![](https://cdn.acedata.cloud/qzx2z1.png)

يمكننا أن نرى أن الصورة المرجعية هي صورة شخص حقيقي، ويمكننا تغييرها إلى نمط معين، مثل تحويلها إلى صورة بأسلوب الأنمي. فيما يلي نموذج الطلب:

```json
{
  "model": "gpt-4o-image",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "生成动漫风格的图片，并且带上个帽子"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

## معالجة الأخطاء

عند استدعاء API، إذا حدث خطأ، ستعيد الواجهة رمز الخطأ والمعلومات ذات الصلة. على سبيل المثال:

- `400 token_mismatched`: طلب غير صالح، ربما بسبب معلمات مفقودة أو غير صحيحة.
- `400 api_not_implemented`: طلب غير صالح، ربما بسبب معلمات مفقودة أو غير صحيحة.
- `401 invalid_token`: غير مصرح، رمز التفويض غير صالح أو مفقود.
- `429 too_many_requests`: عدد الطلبات كبير جدًا، لقد تجاوزت الحد المسموح به.
- `500 api_error`: خطأ داخلي في الخادم، حدث خطأ ما في الخادم.

### مثال على استجابة الخطأ

```
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
