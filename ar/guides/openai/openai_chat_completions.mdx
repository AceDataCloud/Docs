OpenAI ChatGPT هو نظام محادثة بالذكاء الاصطناعي قوي للغاية، فما عليك سوى إدخال كلمات توجيهية ليتمكن من إنشاء ردود سلسة وطبيعية في غضون ثوانٍ قليلة. يتميز ChatGPT في المجال بقدراته الممتازة على فهم اللغة وتوليدها، واليوم، أصبح ChatGPT مستخدمًا على نطاق واسع في مختلف الصناعات والمجالات، وأصبح تأثيره أكثر وضوحًا. سواء في المحادثات اليومية أو الكتابة الإبداعية أو الاستشارات المهنية أو برمجة الأكواد، يمكن لـ ChatGPT تقديم مساعدة ذكية مدهشة، مما يحسن بشكل كبير كفاءة العمل والإبداع لدى البشر.

تقدم هذه الوثيقة بشكل أساسي سير عمل استخدام عملية OpenAI Chat Completion API، وباستخدامها يمكننا بسهولة استخدام ميزة المحادثة الخاصة بـ OpenAI ChatGPT الرسمي.

## GPT-6.1 Sol

استخدم `model: "gpt-6.1-sol"` لاختيار هذا النموذج. يدعم الإخراج المتدفق، واستدعاء الدوال، والإخراج المنظم، وإدخال الصور. خلال الأسبوع الأول من فتحه، سيكون متاحًا فقط لحاملي ACE T1+ الذين تم التحقق منهم (100,000 ACE على الأقل) أو للمستخدمين المصرح لهم؛ ويُعتمد وقت الإتاحة المحدد على تنبيه الوصول في وحدة التحكم.

تدعم مستويات الاستدلال `low` و`medium` و`high` و`xhigh` و`max`، ولا تدعم حاليًا `none` أو `minimal`. يوصى بالبدء من `reasoning_effort: "low"`. عند تجاوز الإدخال 272,000 tokens، ينطبق تسعير السياق الطويل على الطلب بالكامل، وتخضع الرسوم للسعر الحالي في وحدة التحكم.

لاستخدام OpenAI Chat Completion API، انتقل أولًا إلى [وحدة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على API Token الخاص بك، واحتفظ به كنسخة احتياطية.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد سجلت الدخول أو أنشأت حسابًا بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وبعد الإكمال ستعود تلقائيًا إلى الصفحة الحالية.

**يمكن لـ API Token واحد استدعاء جميع خدمات المنصة، ولا حاجة للتقديم بشكل منفصل لكل خدمة.** سيمنحك أول تقديم رصيدًا مجانيًا لتجربة الخدمة مجانًا؛ وعند عدم كفاية الرصيد، يمكنك شحن الرصيد العام من [وحدة التحكم](https://platform.acedata.cloud/console/coin).

## الاستخدام الأساسي

بعد ذلك، يمكنك ملء المحتوى المقابل في الواجهة، كما هو موضح في الصورة:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

عند استخدام هذه الواجهة لأول مرة، نحتاج إلى ملء ثلاثة عناصر على الأقل، أحدها هو `authorization`، ويمكن اختياره مباشرة من القائمة المنسدلة. المعلمة الأخرى هي `model`، و`model` هي فئة النموذج التي نختار استخدامها من موقع OpenAI ChatGPT الرسمي، وهنا لدينا بشكل أساسي 20 نموذجًا، ويمكنك الاطلاع على النماذج التي نوفرها لمزيد من التفاصيل. المعلمة الأخيرة هي `messages`، و`messages` هي مصفوفة كلمات الاستفسار التي ندخلها، وهي مصفوفة، مما يعني إمكانية رفع عدة كلمات استفسار في الوقت نفسه، وكل كلمة استفسار تتضمن `role` و`content`، حيث يشير `role` إلى دور السائل، ونحن نوفر ثلاث هويات، وهي `user` و`assistant` و`system`. أما `content` الآخر فهو المحتوى المحدد لاستفسارنا.

في الوقت نفسه، يمكنك ملاحظة وجود إنشاء لكود الاستدعاء المقابل على الجانب الأيمن، ويمكنك نسخ الكود وتشغيله مباشرة، أو النقر مباشرة على زر «Try» للاختبار.

المعلمات الاختيارية الشائعة:

- `max_tokens`: يحد من الحد الأقصى لعدد tokens في الرد الواحد.
- `temperature`: عشوائية التوليد، بين 0 و2، وكلما زادت القيمة زاد التشتت.
- `n`: عدد الردود المرشحة التي يتم توليدها في المرة الواحدة.
- `response_format`: إعداد تنسيق الإرجاع.

## الاستجابة المتدفقة

تدعم هذه الواجهة أيضًا الاستجابة المتدفقة، وهذا مفيد جدًا لربط صفحات الويب، ويمكن أن يتيح للصفحة تحقيق تأثير العرض حرفًا بحرف.

إذا كنت تريد إرجاع الاستجابة بشكل متدفق، يمكنك تغيير معلمة `stream ` في رأس الطلب إلى `true`.

يتم التعديل كما هو موضح في الصورة، ولكن يجب أن يتضمن كود الاستدعاء تغييرات مقابلة لدعم الاستجابة المتدفقة.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

بعد تعديل `stream` إلى `true`، ستُرجع API بيانات JSON المقابلة سطرًا بسطر، وعلى مستوى الكود نحتاج إلى إجراء تعديلات مناسبة للحصول على النتائج سطرًا بسطر.

كود استدعاء Python نموذجي:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

يدعم JavaScript أيضًا ذلك، فعلى سبيل المثال يكون كود الاستدعاء المتدفق لـ Node.js كما يلي:

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4",
    messages: [{ role: "user", content: "hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

كود عينة Java:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "gpt-4");
jsonObject.put("messages", [{"role":"user","content":"hello"}]);
jsonObject.put("stream", true);
MediaType mediaType = "application/json; charset=utf-8".toMediaType();
RequestBody body = jsonObject.toString().toRequestBody(mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/openai/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.print(response.body!!.string())
```

يمكن إعادة كتابة اللغات الأخرى بشكل مستقل، والمبدأ واحد في جميع الحالات.

## التكامل مع OpenAI-Python

تتوافق واجهة برمجة تطبيقات OpenAI Chat Completion مع واجهة OpenAI الرسمية، ويمكن استخدام حزمة SDK الرسمية [OpenAI-Python](https://github.com/openai/openai-python) مباشرةً للتكامل، وستقدم هذه المقالة بإيجاز طريقة الاستخدام.

1. تحتاج أولًا إلى إعداد بيئة `Python` محلية، ويمكن البحث عن هذه العملية في Google.
2. نزّل وثبّت بيئة التطوير، مثل تثبيت محرر VSCode.
3. اضبط متغيرات بيئة `OpenAI`.

- في مجلد المشروع، أنشئ ملفًا باسم `.env` واحفظه.
- محتوى ملف `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # تذكير مرة أخرى: إذا كنت تستخدم مفتاح OpenAI الرسمي، فلا تستخدم هذا العنوان.
```

استبدل `sk-xxx` بمفتاحك الخاص. إن `OPENAI_BASE_URL` هي واجهة الوكيل للوصول إلى OpenAI.

4. ثبّت الحزم التي يعتمد عليها المشروع

```shell
pip install openai
```

في نظام Mac OS، يكون الأمر:

```shell
pip3 install openai
```

5. أنشئ ملف الشفرة المصدرية للمثال

افترض أننا أنشأنا شفرة مثال باسم `index.py`، ويكون محتواها المحدد كما يلي:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

```json
    "completion_tokens": 82,

```

يمكن ملاحظة أن معلومات الرد داخل `choices` يتم الحصول عليها بعد الاستعلام عبر الإنترنت، كما أنها تعرض الروابط ذات الصلة. يجب عرض معلومات الرد داخل `choices` باستخدام صياغة `markdown`، وبهذه الطريقة فقط يمكن الحصول على أفضل تجربة، وفي النهاية يعكس هذا أيضًا الميزة القوية لوظيفة الاتصال بالإنترنت في نموذجنا.

## النموذج المرئي

gpt-4o هو نموذج لغوي كبير متعدد الوسائط طورته OpenAI، وقد أضاف قدرة الفهم البصري على أساس GPT-4. يمكن لهذا النموذج معالجة مدخلات النصوص والصور في الوقت نفسه، محققًا الفهم والتوليد عبر الوسائط.

تتوافق معالجة النصوص باستخدام نموذج gpt-4o مع محتوى الاستخدام الأساسي المذكور أعلاه، وفيما يلي مقدمة موجزة حول كيفية استخدام قدرة النموذج على معالجة الصور.

تُستخدم قدرة معالجة الصور في نموذج gpt-4o بشكل رئيسي من خلال إضافة حقل `type` إلى محتوى `content` الأصلي، ومن خلال هذا الحقل يمكن معرفة ما إذا كان المرفوع نصًا أم صورة، وبالتالي استخدام قدرة معالجة الصور في نموذج gpt-4o. وفيما يلي شرح رئيسي لطريقتين لاستدعاء هذه الوظيفة باستخدام Curl وPython.

- طريقة نص Curl البرمجي

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

- طريقة نص Python البرمجي
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
                    }
                },
            ],
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## معالجة الأخطاء

عند استدعاء API، إذا واجهت خطأً، فسيُرجع API رمز الخطأ والمعلومات المقابلة. على سبيل المثال:

- `400 token_mismatched`: طلب غير صالح، قد يكون بسبب معلمات مفقودة أو غير صالحة.
- `400 api_not_implemented`: طلب غير صالح، قد يكون بسبب معلمات مفقودة أو غير صالحة.
- `401 invalid_token`: غير مصرح به، رمز التفويض غير صالح أو مفقود.
- `429 too_many_requests`: طلبات كثيرة جدًا، لقد تجاوزت حد المعدل.
- `500 api_error`: خطأ داخلي في الخادم، حدث خطأ ما على الخادم.

### مثال على استجابة الخطأ

```
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
