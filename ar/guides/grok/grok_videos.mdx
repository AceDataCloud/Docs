ستقدم هذه المقالة تعليمات دمج Grok Videos Generation API، الذي يمكنه إنشاء فيديوهات Grok Imagine (xAI) من خلال إدخال نصوص توجيهية، صور إدخال، وصور مرجعية اختيارية.

## عملية التقديم

لاستخدام API، يجب أولاً التقديم للحصول على الخدمة المناسبة من صفحة [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos). بعد الدخول إلى الصفحة، اضغط على زر "Acquire" كما هو موضح في الصورة:

![](https://cdn.acedata.cloud/q6ytrc.png)

إذا لم تكن مسجلاً أو مسجلاً الدخول، سيتم توجيهك تلقائيًا إلى صفحة تسجيل الدخول لتسجيل حسابك أو الدخول. بعد التسجيل أو الدخول، ستعود تلقائيًا إلى الصفحة الحالية.

عند التقديم لأول مرة، ستحصل على رصيد مجاني لاستخدام API مجانًا.

## شرح النماذج

يدعم هذا API نموذجين:

- `grok-imagine-video` (الافتراضي): يدعم إنشاء فيديو من النص فقط (`prompt` فقط) أو من صورة (`image_url`)، بسعر أقل.
- `grok-imagine-video-1.5-preview`: يدعم فقط إنشاء فيديو من صورة، **يجب** تمرير `image_url`.

## الاستخدام الأساسي

أولاً، تعرف على طريقة الاستخدام الأساسية، حيث تدخل نص التوجيه `prompt`، النموذج `model`، وغيرها من المعلمات لإنشاء الفيديو المطلوب.

نلاحظ هنا أننا قمنا بتعيين رؤوس الطلب (Request Headers) والتي تشمل:

- `accept`: نوع تنسيق الاستجابة المرغوب، هنا نستخدم `application/json` أي تنسيق JSON.
- `authorization`: مفتاح استدعاء API، يمكن اختياره من القائمة بعد التقديم.

كما تم تعيين جسم الطلب (Request Body) والذي يشمل:

- `prompt`: نص يصف محتوى الفيديو المراد إنشاؤه. مطلوب عند استخدام `grok-imagine-video` لإنشاء فيديو من النص فقط؛ اختياري عند تمرير `image_url`.
- `model`: نموذج إنشاء الفيديو، يمكن اختيار `grok-imagine-video` (الافتراضي) أو `grok-imagine-video-1.5-preview`.
- `image_url`: رابط صورة الإدخال لإنشاء فيديو من الصورة. مطلوب عند استخدام `grok-imagine-video-1.5-preview`.
- `reference_image_urls`: مصفوفة روابط الصور المرجعية الاختيارية لتوجيه نمط أو محتوى الفيديو.
- `aspect_ratio`: نسبة العرض إلى الارتفاع للفيديو الناتج، يمكن اختيار `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`.
- `resolution`: دقة الإخراج، يمكن اختيار `480p` (الافتراضية) أو `720p`، كلما زادت الدقة زاد استهلاك الرصيد.
- `duration`: مدة الفيديو بالثواني، ضمن النطاق 1–15، الافتراضي 8. يتم احتساب التكلفة بناءً على مدة الفيديو.
- `callback_url`: عنوان استدعاء رجعي غير متزامن، عند تعيينه يعيد API فورًا `task_id`، وعند انتهاء المهمة يتم إرسال النتيجة عبر POST إلى هذا العنوان.

اضغط على زر "Try" للاختبار، وستحصل على نتيجة مشابهة لما يلي:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
      "state": "succeeded"
    }
  ]
}
```

تتضمن النتيجة عدة حقول، وهي كما يلي:

- `success`: هل نجح طلب إنشاء الفيديو.
- `task_id`: معرف مهمة إنشاء الفيديو.
- `trace_id`: معرف تتبع الطلب لاستخدامه في استكشاف الأخطاء.
- `data`: قائمة نتائج الفيديوهات المُنشأة.
  - `id`: المعرف الفريد للفيديو المُنشأ.
  - `video_url`: رابط الفيديو المُنشأ.
  - `state`: حالة مهمة إنشاء الفيديو، يمكن أن تكون `pending` / `succeeded` / `failed`.

كل ما علينا هو الحصول على الفيديو من خلال رابط `video_url` في حقل `data`.

كود CURL المقابل هو:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "resolution": "480p",
  "duration": 8
}'
```

وكود Python المقابل هو:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## إنشاء فيديو من صورة

إذا أردت إنشاء فيديو بناءً على صورة إدخال، يمكنك تمرير `image_url`. عند استخدام `grok-imagine-video-1.5-preview` يجب توفير هذا الحقل:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5-preview",
  "image_url": "https://cdn.acedata.cloud/5hmkdg.jpg",
  "resolution": "720p",
  "duration": 8
}
```

## توجيه بواسطة صور مرجعية

إذا أردت توجيه نمط أو محتوى الفيديو باستخدام صورة أو أكثر كمرجع، يمكنك تمرير مصفوفة روابط الصور في `reference_image_urls`:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/vunnjf.png"
  ]
}
```

## الاستدعاء الرجعي غير المتزامن

يتطلب إنشاء الفيديو بعض الوقت للمعالجة. إذا لم ترغب في الانتظار مع بقاء الاتصال مفتوحًا، يمكنك تمرير `callback_url`، عندها يعيد API فورًا `task_id`، وعند انتهاء المهمة يتم إرسال النتيجة النهائية عبر POST إلى هذا العنوان:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "duration": 8,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

النتيجة التي تعود فورًا تكون كما يلي:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## استعلام نتائج المهمة

إذا استخدمت الاستدعاء الرجعي غير المتزامن أو أردت الاستعلام عن حالة المهمة بنشاط، يمكنك استخدام [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) للاستعلام عن أحدث حالة ونتيجة المهمة عبر `task_id`.

## شرح التسعير

تُحسب تكلفة الخدمة بناءً على "مدة الفيديو الناتج" بالثواني، ويحدد السعر الوحدة كل من `model` و `resolution`. السعر الإجمالي = السعر للوحدة × `duration` (الافتراضي 8 ثوانٍ). دقة `720p` أغلى من `480p`، و`grok-imagine-video-1.5-preview` أغلى من `grok-imagine-video`. السعر التفصيلي متوفر في صفحة التسعير.

## معالجة الأخطاء

عند وجود مشكلة في الطلب، يعيد API رمز الخطأ مع شرح، والأخطاء الشائعة هي:

- `400`: خطأ في معلمات الطلب، مثل نقص `prompt` لإنشاء فيديو من النص، أو نقص `image_url` في `grok-imagine-video-1.5-preview`، أو تجاوز `duration` للنطاق 1–15.
- `401`: فشل التوثيق، رمز التوكن غير صالح أو لا يتطابق مع API.
- `403`: رصيد غير كافٍ، أو رفض المحتوى بسبب مراجعة المحتوى.
- `429`: طلبات متكررة جدًا، تم تفعيل الحد الأعلى من المصدر، يرجى المحاولة لاحقًا.
- `500`: خطأ داخلي في الخادم أو فشل في الإنشاء من المصدر.
