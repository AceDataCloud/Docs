ستتناول هذه الوثيقة توضيح تكامل واجهة برمجة تطبيقات توليد فيديوهات Grok، والتي يمكنها من خلال إدخال نصوص، صور، وصور مرجعية اختيارية توليد فيديوهات Grok Imagine (xAI).

## عملية التقديم

لاستخدام واجهة برمجة تطبيقات توليد فيديوهات Grok، يجب أولاً الذهاب إلى [وحدة التحكم في Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، للاحتفاظ به كنسخة احتياطية.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، سيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد الانتهاء سيتم العودة تلقائيًا إلى الصفحة الحالية.

**يمكن استخدام رمز API واحد لاستدعاء جميع خدمات المنصة، دون الحاجة لتقديم طلب منفصل لكل خدمة.** عند التقديم لأول مرة، ستحصل على رصيد مجاني لتجربته؛ وعند نفاد الرصيد، يمكنك إعادة شحن الرصيد العام في [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [واجهة برمجة تطبيقات توليد فيديوهات Grok →](https://platform.acedata.cloud/documents/grok-videos)

## توضيح النموذج

تدعم هذه الواجهة نوعين من النماذج:

- `grok-imagine-video-1.5-fast` (افتراضي): يدعم توليد الفيديو من النص (فقط تمرير `prompt`) وتوليد الفيديو من الصورة (تمرير `image_url`)، بحد أقصى 30 ثانية، وسعر أقل.
- `grok-imagine-video-1.5`: يدعم فقط توليد الفيديو من الصورة، **يجب** تمرير `image_url`، بحد أقصى 15 ثانية.

## الاستخدام الأساسي

أولاً، تعرف على طريقة الاستخدام الأساسية، حيث يمكنك إدخال نص `prompt`، النموذج `model`، وغيرها من المعلمات، لتوليد الفيديو المقابل.

يمكنك رؤية أننا قمنا بتعيين رؤوس الطلب، بما في ذلك:

- `accept`: نوع الاستجابة التي ترغب في تلقيها، هنا يتم ملؤها بـ `application/json`، أي بتنسيق JSON.
- `authorization`: مفتاح استدعاء API، يمكنك اختياره مباشرة بعد التقديم.

كما تم تعيين جسم الطلب، بما في ذلك:

- `prompt`: نص يصف محتوى الفيديو الذي ترغب في توليده. عند استخدام `grok-imagine-video-1.5-fast` لتوليد الفيديو من النص **يجب ملؤه**؛ وعند تمرير `image_url` يكون اختياريًا.
- `model`: نموذج توليد الفيديو، يمكن اختيار `grok-imagine-video-1.5-fast` (افتراضي) أو `grok-imagine-video-1.5`.
- `image_url`: رابط الصورة المدخلة لتوليد الفيديو. عندما يكون `model` هو `grok-imagine-video-1.5` **يجب ملؤه**.
- `reference_image_urls`: مصفوفة روابط الصور المرجعية الاختيارية، تستخدم لتوجيه أسلوب أو محتوى الفيديو.
- `aspect_ratio`: نسبة العرض إلى الارتفاع للفيديو الناتج، يمكن اختيار `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`.
- `resolution`: دقة الإخراج، يمكن اختيار `480p` (افتراضي)، `720p` أو `1080p`.
- `duration`: مدة الفيديو الناتج (بالثواني). نطاق `grok-imagine-video-1.5-fast` هو 1–30، ونطاق `grok-imagine-video-1.5` هو 1–15، الافتراضي هو 6. يُوصى باستخدام 6 ثوانٍ أو 10 ثوانٍ، حيث أن هذين الطولين القياسيين أكثر استقرارًا.
- `callback_url`: عنوان رد الاتصال غير المتزامن، بعد تعيينه ستعيد الواجهة مباشرة `task_id`، وعند الانتهاء من المهمة سيتم إرسال النتيجة إلى هذا العنوان.
- `async`: اختياري، عند تعيينه إلى `true` ستعيد الواجهة مباشرة `task_id`، دون الحاجة لتوفير `callback_url`، ثم يمكنك الاستعلام عن النتائج من خلال واجهة استعلام المهام المقابلة.

انقر على زر "Try" لإجراء اختبار، وستكون النتائج مشابهة لما يلي:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video-1.5-fast:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
      "state": "succeeded"
    }
  ]
}
```

تتضمن النتيجة العائدة عدة حقول، كما يلي:

- `success`: هل كانت طلب توليد الفيديو ناجحة.
- `task_id`: معرف مهمة توليد الفيديو هذه.
- `trace_id`: معرف تتبع الطلب، يستخدم لتحديد المشكلات.
- `data`: قائمة نتائج الفيديو الناتج.
  - `id`: المعرف الفريد للفيديو الناتج.
  - `video_url`: عنوان رابط الفيديو الناتج.
  - `state`: حالة مهمة توليد الفيديو، يمكن أن تكون `pending` / `succeeded` / `failed`.

نحتاج فقط إلى الحصول على الفيديو الناتج من رابط `video_url` في `data`.

الكود المقابل لـ CURL كما يلي:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "resolution": "480p",
  "duration": 6
}'
```

الكود المقابل لـ Python كما يلي:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video-1.5-fast",
    "resolution": "480p",
    "duration": 6
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## توليد الفيديو من الصورة

إذا كنت ترغب في توليد فيديو بناءً على صورة مدخلة، يمكنك تمرير `image_url`. عند استخدام `grok-imagine-video-1.5` يجب توفير هذا الحقل:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5",
  "image_url": "https://cdn.acedata.cloud/5hmkdg.jpg",
  "resolution": "720p",
  "duration": 6
}
```

## توجيه الصور المرجعية

إذا كنت ترغب في استخدام صورة واحدة أو أكثر لتوجيه أسلوب أو محتوى الفيديو الناتج، يمكنك تمرير مصفوفة روابط الصور في `reference_image_urls`:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video-1.5-fast",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/vunnjf.png"
  ]
}
```

## رد الاتصال غير المتزامن

تتطلب عملية توليد الفيديو بعض الوقت للمعالجة. إذا كنت لا ترغب في الحفاظ على اتصال طويل في الانتظار، يمكنك تمرير `callback_url`، في هذه الحالة ستعيد الواجهة مباشرة `task_id`، وعند الانتهاء من المهمة ستقوم بإرسال النتيجة النهائية إلى هذا العنوان:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "duration": 6,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

النتيجة التي ستعود على الفور كما يلي:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## استعلام نتائج المهام
إذا تم استخدام استدعاء غير متزامن أو إذا كنت ترغب في الاستعلام عن حالة المهمة بشكل نشط، يمكنك من خلال [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) الاستعلام عن الحالة والنتائج الأخيرة للمهمة بناءً على `task_id`.

## شرح الفوترة

تحدد طريقة الفوترة لهذه الخدمة بواسطة `model`:

- `grok-imagine-video-1.5-fast`: يتم الفوترة حسب المدة الزمنية، بغض النظر عن الدقة - `1–10` ثوانٍ، `11–20` ثانية، `21–30` ثانية تتوافق مع أسعار مختلفة.
- `grok-imagine-video-1.5`: يتم الفوترة حسب "عدد الثواني الناتجة"، السعر الإجمالي = السعر الفردي × `duration`، `1080p` أغلى من `480p`/`720p`.

تكون الأسعار الفردية وفقًا لصفحة التسعير. الطلبات الفاشلة لا يتم احتسابها في الفوترة، ولا تستهلك من الحصة المجانية.

## معالجة الأخطاء

عند حدوث مشكلة في الطلب، ستقوم واجهة برمجة التطبيقات بإرجاع رمز الخطأ المقابل مع الشرح، والأخطاء الشائعة هي كما يلي:

- `400`: هناك خطأ في معلمات الطلب، مثل عدم وجود `prompt` في فيديو النص، أو عدم وجود `image_url` في `grok-imagine-video-1.5`، أو تجاوز `duration` النطاق (لـ `grok-imagine-video-1.5-fast` هو 1–30، ولـ `grok-imagine-video-1.5` هو 1–15).
- `401`: فشل في التحقق من الهوية، الرمز المميز غير صالح أو لا يتطابق مع واجهة برمجة التطبيقات.
- `403`: رصيد غير كافٍ، أو تم رفض المحتوى بسبب مراجعة المحتوى.
- `429`: الطلبات متكررة جدًا، يرجى المحاولة لاحقًا.
- `500`: فشل في إنشاء الفيديو أو حدوث خطأ في الخدمة.
