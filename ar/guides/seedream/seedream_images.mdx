ستقدم هذه المقالة دليلاً لتكامل واجهة برمجة تطبيقات توليد صور SeeDream، والتي تتيح إنشاء صور SeeDream الرسمية من خلال إدخال معلمات مخصصة.

## عملية التقديم

لاستخدام واجهة برمجة تطبيقات توليد صور SeeDream، انتقل أولاً إلى [وحدة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على API Token الخاص بك، واحتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تقم بتسجيل الدخول أو التسجيل بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وبعد الإكمال ستعود تلقائيًا إلى الصفحة الحالية.

**يمكن لـ API Token واحد استدعاء جميع خدمات المنصة، ولا حاجة للتقديم بشكل منفصل لكل خدمة.** سيُمنح طلبك الأول رصيدًا مجانيًا لتجربة الخدمة مجانًا؛ وعندما لا يكون الرصيد كافيًا، يمكنك شحن الرصيد العام في [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [SeeDream Images Generation API →](https://platform.acedata.cloud/documents/seedream-images)

## الاستخدام الأساسي

لنتعرف أولاً على طريقة الاستخدام الأساسية، وهي أنه بإدخال كلمة التوجيه `prompt`، وإجراء التوليد `action`، وحجم الصورة `size`، يمكنك الحصول على النتيجة المعالجة. تحتاج أولاً إلى تمرير حقل `action` بشكل بسيط، وتكون قيمته `generate`، ثم نحتاج أيضًا إلى إدخال كلمة التوجيه، والمحتوى المحدد كما يلي:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

يمكنك رؤية أننا قمنا هنا بتعيين Request Headers، بما في ذلك:

- `accept`: نوع تنسيق نتيجة الاستجابة التي ترغب في تلقيها، ويُملأ هنا بـ `application/json`، أي تنسيق JSON.
- `authorization`: مفتاح استدعاء API، ويمكن اختياره مباشرةً من القائمة المنسدلة بعد التقديم.

كما تم تعيين Request Body، بما في ذلك:

- `prompt`: كلمة التوجيه.
- `model`: نموذج التوليد، الافتراضي هو `doubao-seedream-5-0-lite-260128` (SeeDream 5.0 Lite، الأحدث). يدعم `doubao-seedream-5-0-pro-260628` و`doubao-seedream-5-0-lite-260128` و`doubao-seedream-4-5-251128` و`doubao-seedream-4-0-250828`. من بينها، `doubao-seedream-5-0-pro-260628` (SeeDream 5.0 Pro) هو نموذج رئيسي للصور المفردة، ويولّد صورة واحدة فقط، **ولا يدعم مجموعات الصور (`sequential_image_generation`) أو البث (`stream`) أو البحث عبر الإنترنت (`tools`)**. **يجب تمرير سلسلة النموذج الكاملة إلى `model` (مثل `doubao-seedream-5-0-lite-260128`)، إذ إن تمرير اختصار مثل `doubao-seedream-5.0-lite` سيعيد 400.**
- `image`: معلومات الصورة المُدخلة، ويدعم URL أو ترميز Base64. يدعم `doubao-seedream-5-0-pro-260628` إدخال صورة واحدة أو عدة صور (بحد أقصى 10 صور)، كما يدعم `doubao-seedream-5-0-lite-260128` و`doubao-seedream-4-5-251128` و`doubao-seedream-4-0-250828` إدخال صورة واحدة أو عدة صور.
- `size`: يحدد معلومات حجم الصورة المُولَّدة، ويدعم الطريقتين التاليتين، ولا يمكن استخدامهما معًا. الطريقة 1 | تحديد دقة الصورة المُولَّدة، ووصف نسبة عرض الصورة إلى ارتفاعها بلغة طبيعية في prompt. **تختلف الإعدادات المسبقة المدعومة بين النماذج**: يدعم `doubao-seedream-5-0-pro-260628` `1K`/`1.5K`/`2K`؛ ويدعم `doubao-seedream-5-0-lite-260128` `2K`/`3K`/`4K`؛ ويدعم `doubao-seedream-4-5-251128` فقط `2K`/`4K`؛ ويدعم `doubao-seedream-4-0-250828` `1K`/`2K`/`4K`. الطريقة 2 | تحديد قيم بكسلات عرض وارتفاع الصورة المُولَّدة: الافتراضي `2048x2048`، ويختلف نطاق إجمالي البكسلات ونسبة العرض إلى الارتفاع حسب النموذج (على سبيل المثال، نطاق إجمالي البكسلات في 5.0 Pro هو [921600, 4624220]، والحد الأدنى لإجمالي البكسلات في 5.0 Lite / 4.5 هو 3,686,400، وفي 4.0 هو 921,600).
- `sequential_image_generation`: مجموعة صور: مجموعة من الصور المرتبطة بالمحتوى يتم توليدها بناءً على المحتوى الذي أدخلته. يدعم `doubao-seedream-5-0-lite-260128` و`doubao-seedream-4-5-251128` و`doubao-seedream-4-0-250828` هذه المعلمة، والقيمة الافتراضية هي `disabled`.
- `stream`: يتحكم في ما إذا كان سيتم تفعيل وضع الإخراج المتدفق. يدعم `doubao-seedream-5-0-lite-260128` و`doubao-seedream-4-5-251128` و`doubao-seedream-4-0-250828` هذه المعلمة، والقيمة الافتراضية هي `false`.
- `response_format`: يحدد تنسيق الإرجاع للصور المُولَّدة. الافتراضي هو `url`، كما يدعم `b64_json`.
- `watermark`: ما إذا كان سيتم إضافة علامة مائية إلى الصور المُولَّدة. الافتراضي هو `true`.
- `output_format`: يحدد تنسيق ملف الصور المُولَّدة، ويدعم `jpeg` (الافتراضي) و`png`. يدعمه فقط `doubao-seedream-5-0-pro-260628` و`doubao-seedream-5-0-lite-260128`.
- `tools`: يهيئ الأدوات التي سيستدعيها النموذج، ويدعم حاليًا `web_search` (البحث عبر الإنترنت). يدعمه فقط Seedream 5.0 Lite.
- `optimize_prompt_options`: إعدادات تحسين كلمة التوجيه. يدعم 5.0 Pro `standard`/`fast`؛ ويدعم 5.0 Lite و4.5 فقط `standard`؛ ويدعم 4.0 `standard`/`fast`.
- `background`: يدعمه فقط تحرير الصورة المفردة في 5.0 Pro. يتطلب `transparent` إدخال صورة PNG بقناة شفافية، ويجب أن يكون `output_format` هو `png`؛ أما `opaque` فهو خلفية عادية غير شفافة.
- `layer_decomposition`: يدعمه فقط 5.0 Pro. عند تعيينه إلى `true`، يجب إدخال PNG/JPEG، ويمكن عدم تمرير `prompt` للتقسيم التلقائي، أو استخدام لغة طبيعية/`<bbox>` لتحديد العناصر؛ ويدعم `size` `auto`/`1K`/`1.5K`/`2K`. لا يمكن استخدام هذا الوضع مع مجموعة الصور أو البث أو البحث عبر الإنترنت أو `background`.
- `callback_url`: عنوان URL الذي يحتاج إلى نتيجة استدعاء عكسي.
- `async`: ما إذا كانت المعالجة ستتم في الوضع غير المتزامن. عند تعيينه إلى `true`، تعيد الواجهة فورًا `task_id`، ولا حاجة لتوفير `callback_url`، ثم يتم الاستعلام عن النتيجة عبر `/seedream/tasks`.

بعد الاختيار، يمكنك ملاحظة أنه تم أيضًا إنشاء الكود المقابل على الجانب الأيمن، كما هو موضح في الصورة:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

انقر على زر «Try» لإجراء الاختبار، كما هو موضح في الصورة أعلاه، وهنا نحصل على النتيجة التالية:
```json
{
  "success": true,
  "task_id": "80ceeed1-17d4-4eb7-82e0-18b34290f36e",
  "trace_id": "96b7fdc8-0fc8-4e2e-82a9-83c0a82f0a08",
  "data": [
    {
      "prompt": "A single matte blue cube centered on a clean white studio background, neutral lighting",
      "size": "2048x2048",
      "image_url": "https://platform2.cdn.acedata.cloud/seedream/db93b46e-c302-4676-8a11-63f0ba638a27.jpg"
    }
  ]
}
```

تتضمن النتيجة المُعادة عدة حقول، ويُعرَّف كل منها كما يلي:

- `success`، حالة مهمة إنشاء الفيديو في هذه اللحظة.
- `task_id`، معرّف مهمة إنشاء الفيديو في هذه اللحظة.
- `trace_id`، معرّف تتبع إنشاء الفيديو في هذه اللحظة.
- `data`، قائمة نتائج مهمة إنشاء الصور في هذه اللحظة.
  - `image_url`، رابط مهمة إنشاء الصورة في هذه اللحظة.
  - `prompt`، كلمة المطالبة.
  - `size`: بكسلات الصورة المُنشأة

يمكن ملاحظة أننا حصلنا على معلومات صورة مرضية، ونحتاج فقط إلى الحصول على صورة SeeDream المُنشأة بناءً على عنوان رابط الصورة في `data` ضمن النتيجة.

بالإضافة إلى ذلك، إذا كنت تريد إنشاء كود التكامل المقابل، يمكنك نسخه مباشرةً، على سبيل المثال، كود CURL كما يلي:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-5-0-lite-260128",
  "prompt": "A single matte blue cube centered on a clean white studio background, neutral lighting"
}'
```

## مهمة تحرير الصور

إذا كنت تريد تحرير صورة معينة، فيجب أولاً تمرير رابط الصورة المراد تحريرها إلى المعلمة `image`

- model: النموذج المستخدم في مهمة تحرير الصور هذه، وتدعم النماذج `doubao-seedream-5-0-pro-260628` و`doubao-seedream-5-0-lite-260128` و`doubao-seedream-4-5-251128` و`doubao-seedream-4-0-250828` جميعها إدخال الصور.
- image: رفع الصورة المراد تحريرها، صورة واحدة أو عدة صور

مثال على التعبئة كما يلي:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

الكود المقابل:

```python
import requests

url = "https://api.acedata.cloud/seedream/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

يمكن ملاحظة أن التأثير المُنشأ هو تأثير تحرير الصورة الأصلية، والنتيجة مشابهة لما سبق.

## فصل الطبقات (Seedream 5.0 Pro)

سيؤدي فصل الطبقات إلى تقسيم صورة إدخال واحدة إلى صورة خلفية واحدة وما يصل إلى 16 طبقة PNG شفافة قابلة للتحرير بشكل مستقل. يجعل الطلب التالي النموذج يتعرف تلقائياً على العناصر الرئيسية؛ وإذا كنت بحاجة إلى تحديد عناصر، يمكنك إضافة `prompt`، ويمكنك أيضاً استخدام إحداثيات `<bbox>` المعيارية في كلمات المطالبة.

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "model": "doubao-seedream-5-0-pro-260628",
  "image": "https://example.com/poster.png",
  "layer_decomposition": true,
  "size": "2K",
  "watermark": false
}'
```

يتم ترتيب `data` المُعادة من الأسفل إلى الأعلى حسب `z_index`. تكون قيمة `z_index` لصورة الخلفية هي 0؛ وتشمل الطبقات أيضاً `name` و`description` و`bounding_box.absolute`/`normalized`. عند إعادة التجميع باستخدام الإحداثيات المطلقة، قم بتحجيم الطبقة إلى `[right-left, bottom-top]`، وضعها في `[left, top]`، ثم قم بتكديسها بترتيب تصاعدي حسب `z_index`. عند فشل إنشاء أي طبقة، تفشل عملية الفصل بأكملها.

## الإخراج المتدفق

عند تعيين `stream: true` في Lite/4.x، استخدم `accept: application/x-ndjson` في رأس الطلب. تُرجع الواجهة سطراً بسطر `image_generation.partial_succeeded` أو `image_generation.partial_failed`، وفي النهاية تُرجع حدث `image_generation.completed` الوحيد و`usage` النهائي؛ ولا يتم فرض الرسوم إلا مرة واحدة عند تفعيل حدث الإكمال. لا يمكن استخدام الوضع المتدفق مع `async` أو `callback_url` في الوقت نفسه.

## الاستدعاء غير المتزامن

نظراً لأن الوقت الذي يستغرقه SeeDream Images Generation API في الإنشاء طويل نسبياً، ويحتاج تقريباً من 1 إلى 2 دقيقة، فإذا لم تستجب واجهة API لفترة طويلة، سيبقى طلب HTTP متصلاً باستمرار، مما يؤدي إلى استهلاك إضافي لموارد النظام، لذلك توفر واجهة API هذه أيضاً دعماً للاستدعاء غير المتزامن.

العملية العامة هي: عند بدء العميل للطلب، يحدد بشكل إضافي حقل `callback_url`، وبعد أن يبدأ العميل طلب API، ستُرجع API فوراً نتيجة تتضمن معلومات الحقل `task_id`، والذي يمثل معرّف المهمة الحالية. بعد اكتمال المهمة، سيتم إرسال نتيجة إنشاء الصورة إلى `callback_url` الذي حدده العميل على هيئة POST JSON، وتتضمن أيضاً حقل `task_id`، وبهذه الطريقة يمكن ربط نتيجة المهمة بواسطة المعرّف.

إذا لم يكن لديك عنوان عام متاح للاستدعاء، يمكنك أيضاً عدم تحديد `callback_url`، وتعيين الحقل `async` إلى `true` في الطلب بدلاً من ذلك. في هذه الحالة، ستُرجع الواجهة أيضاً `task_id` فوراً، لكنها لن تدفع النتيجة، ويتعين عليك استخدام `task_id` هذا لاستدعاء واجهة `/seedream/tasks` لاستطلاع حالة المهمة والحصول على النتيجة النهائية.

فيما يلي سنتعرف من خلال مثال على كيفية التشغيل بالتحديد.

انقر على التشغيل، ويمكن ملاحظة أنك ستحصل فوراً على نتيجة كما يلي:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

المحتوى كما يلي:
```json
{

    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"

    ]

```

يمكن ملاحظة وجود حقل `task_id` في النتيجة، وتكون الحقول الأخرى مشابهة لما سبق، ويمكن تحقيق ربط المهام من خلال هذا الحقل.

## معالجة الأخطاء

عند استدعاء API، إذا واجهت خطأً، فسيُرجع API رمز الخطأ والمعلومات المقابلة. على سبيل المثال:

- `400 token_mismatched`：طلب غير صالح، وربما يكون ذلك بسبب معلمات مفقودة أو غير صالحة.
- `400 api_not_implemented`：طلب غير صالح، وربما يكون ذلك بسبب معلمات مفقودة أو غير صالحة.
- `401 invalid_token`：غير مصرح به، رمز التفويض غير صالح أو مفقود.
- `429 too_many_requests`：طلبات كثيرة جدًا، لقد تجاوزت حد المعدل.
- `500 api_error`：خطأ داخلي في الخادم، حدث خطأ ما على الخادم.

### مثال على استجابة خطأ

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## الخلاصة

من خلال هذا المستند، أصبحت تعرف كيفية استخدام SeeDream Images Generation API لإنشاء الصور عبر إدخال نصوص المطالبة. نأمل أن يساعدك هذا المستند على التكامل مع API واستخدامه بشكل أفضل. إذا كانت لديك أي أسئلة، فيُرجى التواصل مع فريق الدعم الفني لدينا في أي وقت.
