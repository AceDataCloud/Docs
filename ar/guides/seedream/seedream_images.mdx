تقدم هذه الوثيقة شرحًا لكيفية تكامل واجهة برمجة تطبيقات توليد الصور SeeDream، والتي تتيح إنشاء صور رسمية من SeeDream عبر إدخال معلمات مخصصة.

## عملية التقديم

لاستخدام API، يجب أولاً التقديم للحصول على الخدمة المناسبة من خلال صفحة [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images). بعد الدخول إلى الصفحة، اضغط على زر "Acquire" كما هو موضح في الصورة:

![](https://cdn.acedata.cloud/q6ytrc.png)

إذا لم تكن مسجلاً أو مسجلاً الدخول، سيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لتسجيل حساب أو تسجيل الدخول، وبعدها ستعود تلقائيًا إلى الصفحة الحالية.

عند التقديم لأول مرة، سيتم منحك حصة مجانية لاستخدام API مجانًا.

## الاستخدام الأساسي

أولاً، تعرف على طريقة الاستخدام الأساسية، وهي إدخال كلمة التوجيه `prompt`، وسلوك التوليد `action`، وأبعاد الصورة `size`، لتحصل على النتيجة المعالجة. يجب تمرير حقل `action` بقيمة `generate`، ثم إدخال كلمة التوجيه، كما هو موضح أدناه:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

يمكن ملاحظة أننا قمنا بإعداد رؤوس الطلب (Request Headers) والتي تشمل:

- `accept`: نوع التنسيق المطلوب للاستجابة، هنا يتم تعيينه إلى `application/json` أي تنسيق JSON.
- `authorization`: مفتاح استدعاء API، يمكن اختياره مباشرة بعد التقديم.

كما تم إعداد جسم الطلب (Request Body) والذي يشمل:

- `prompt`: كلمة التوجيه.
- `model`: نموذج التوليد، الافتراضي `doubao-seedream-5.0-lite`. يدعم `doubao-seedream-5.0-lite` (الأحدث)، `doubao-seedream-4.5`، `doubao-seedream-4.0`، `doubao-seedream-3.0-t2i`، `doubao-seededit-3.0-i2i`.
- `image`: معلومات الصورة المدخلة، تدعم URL أو ترميز Base64. تدعم `doubao-seedream-5.0-lite`، `doubao-seedream-4.5`، `doubao-seedream-4.0` إدخال صورة واحدة أو متعددة، بينما يدعم `doubao-seededit-3.0-i2i` صورة واحدة فقط، ولا يدعم `doubao-seedream-3.0-t2i` هذا المعامل.
- `size`: تحديد أبعاد الصورة الناتجة، يدعم طريقتين لا يمكن دمجهما:
  - الطريقة 1 | تحديد دقة الصورة (مثل `2K`، `3K`، `4K`) مع وصف نسبة العرض إلى الارتفاع في كلمة التوجيه.
  - الطريقة 2 | تحديد أبعاد العرض والارتفاع بالبكسل: القيمة الافتراضية `2048x2048`، ونطاق القيم يختلف حسب النموذج.
- `seed`: بذرة عشوائية للتحكم في عشوائية المحتوى الناتج. النطاق [-1, 2147483647]. يدعم فقط `doubao-seedream-3.0-t2i` و `doubao-seededit-3.0-i2i`.
- `sequential_image_generation`: توليد مجموعة صور مرتبطة بناءً على المحتوى المدخل. يدعم `doubao-seedream-5.0-lite`، `doubao-seedream-4.5`، `doubao-seedream-4.0`، القيمة الافتراضية `disabled`.
- `stream`: التحكم في تفعيل وضع الإخراج المتدفق. يدعم `doubao-seedream-5.0-lite`، `doubao-seedream-4.5`، `doubao-seedream-4.0`، القيمة الافتراضية `false`.
- `guidance_scale`: درجة التوافق بين ناتج النموذج وكلمة التوجيه، كلما زادت القيمة زادت الصلة. النطاق [1, 10]. القيمة الافتراضية لـ `doubao-seedream-3.0-t2i` هي 2.5، ولـ `doubao-seededit-3.0-i2i` هي 5.5، ولا يدعمها النماذج الأخرى.
- `response_format`: تنسيق استرجاع الصورة الناتجة. الافتراضي `url`، ويدعم أيضًا `b64_json`.
- `watermark`: هل تضيف علامة مائية على الصورة الناتجة. الافتراضي `true`.
- `output_format`: تنسيق ملف الصورة الناتجة، يدعم `jpeg` (افتراضي) و `png`. يدعم فقط `doubao-seedream-5.0-lite`.
- `tools`: تكوين الأدوات التي يستدعيها النموذج، حاليًا يدعم `web_search` (البحث عبر الإنترنت). يدعم فقط `doubao-seedream-5.0-lite`.
- `callback_url`: عنوان URL لاستقبال نتائج الاستدعاء العكسي.

بعد الاختيار، ستلاحظ أن الكود المقابل تم إنشاؤه على الجانب الأيمن، كما هو موضح:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

اضغط على زر "Try" للاختبار، كما في الصورة أعلاه، وستحصل على النتيجة التالية:

```json
{
  "success": true,
  "task_id": "25027ba3-0430-4a1b-91c8-d2297f19ba73",
  "trace_id": "8043a9e9-692f-43b0-82f7-5890f798be38",
  "data": [
    {
      "prompt": "a white siamese cat",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/3c060029-69b1-406f-a957-fcd55ddc9386.jpg"
    }
  ]
}
```

تحتوي النتيجة على عدة حقول، وهي:

- `success`: حالة مهمة توليد الصورة.
- `task_id`: معرف مهمة توليد الصورة.
- `trace_id`: معرف تتبع المهمة.
- `data`: قائمة نتائج مهمة توليد الصورة.
  - `image_url`: رابط الصورة الناتجة.
  - `prompt`: كلمة التوجيه.
  - `size`: أبعاد الصورة الناتجة بالبكسل.

يمكنك الحصول على صورة SeeDream الناتجة من خلال رابط الصورة في `data`.

لإنشاء كود التكامل، يمكنك نسخه مباشرة، على سبيل المثال كود CURL كما يلي:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-4-0-250828",
  "prompt": "a white siamese cat"
}'
```

## مهمة تحرير الصور

إذا أردت تحرير صورة معينة، يجب تمرير رابط الصورة التي تريد تحريرها في المعامل `image`.

- model: النموذج المستخدم لمهمة تحرير الصورة، يدعم `doubao-seedream-5.0-lite`، `doubao-seedream-4.5`، `doubao-seedream-4.0` إدخال صورة واحدة أو متعددة، ويدعم `doubao-seededit-3.0-i2i` صورة واحدة فقط.
- image: تحميل الصورة أو الصور التي تريد تحريرها.

مثال تعبئة النموذج:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

الكود المقابل:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

بعد التشغيل، ستحصل على النتيجة فورًا كما يلي:

```json

    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

يمكن ملاحظة أن النتيجة تمثل تأثير تحرير الصورة الأصلية، والنتيجة مشابهة لما سبق.

## الاستدعاء العكسي غير المتزامن

نظرًا لأن توليد الصور عبر SeeDream Images Generation API يستغرق وقتًا نسبيًا طويلًا يتراوح بين 1-2 دقيقة، وإذا لم يستجب API لفترة طويلة، سيظل طلب HTTP مفتوحًا مما يستهلك موارد النظام. لذلك، توفر هذه الواجهة دعم الاستدعاء العكسي غير المتزامن.

العملية هي: عند إرسال الطلب من العميل، يتم تحديد حقل إضافي `callback_url`. بعد إرسال طلب API، يعيد API فورًا نتيجة تحتوي على حقل `task_id` الذي يمثل معرف المهمة الحالية. عند الانتهاء من المهمة، يتم إرسال نتيجة توليد الصورة عبر POST بصيغة JSON إلى عنوان `callback_url` المحدد من العميل، متضمنًا أيضًا حقل `task_id` لربط النتائج بالمهمة.

فيما يلي مثال على العملية.

بعد التشغيل، ستحصل على النتيجة فورًا كما يلي:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

المحتوى:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

يمكن ملاحظة وجود حقل `task_id` في النتيجة، وباقي الحقول مشابهة لما سبق، ويمكن ربط النتائج بالمهمة عبر هذا المعرف.

## معالجة الأخطاء

عند استدعاء API، إذا حدث خطأ، سيرجع API رمز الخطأ والمعلومات المناسبة، مثل:

- `400 token_mismatched`: طلب غير صحيح، ربما بسبب معلمات مفقودة أو غير صحيحة.
- `400 api_not_implemented`: طلب غير صحيح، ربما بسبب معلمات مفقودة أو غير صحيحة.
- `401 invalid_token`: غير مصرح، رمز التفويض مفقود أو غير صالح.
- `429 too_many_requests`: عدد الطلبات كبير جدًا، تم تجاوز الحد المسموح.
- `500 api_error`: خطأ داخلي في الخادم.

### مثال على استجابة الخطأ

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
