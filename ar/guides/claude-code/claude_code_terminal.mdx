## 1. الحصول على مفتاح API

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، انتقل إلى التطبيقات المتاحة وانسخ مفتاح API.

![الحصول على مفتاح API لـ Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. تثبيت Claude Code

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
```

بعد التثبيت، تحقق من:

```bash
claude --version
```

## 3. تكوين Ace Data Cloud

عند الاستخدام العالمي، أضف المتغيرات التالية إلى `~/.zshrc` أو `~/.bashrc`：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="مفتاح API الخاص بك"
unset ANTHROPIC_API_KEY
```

أعد فتح الطرفية، أو استخدم `source` للملف التكويني المعني.

إذا كان التأثير فقط على المشروع الحالي، يمكنك إنشاء ملف `.claude/settings.local.json` الذي تم إضافته إلى `.gitignore`：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "مفتاح API الخاص بك"
  }
}
```

اختر واحدة من الطريقتين. لا تكتب المفتاح الحقيقي في `.claude/settings.json` المشتركة مع الفريق؛ إذا كان هناك بالفعل `ANTHROPIC_API_KEY` في البيئة، يجب إلغاؤه فعليًا، وليس تعيينه إلى سلسلة فارغة.

## 4. بدء التشغيل والتحقق

```bash
cd /path/to/your/project
claude
```

بعد الدخول، أرسل مهمة للقراءة فقط، مثل "قراءة README.md وتلخيصه في جملة واحدة". يمكن الاطلاع على سجلات الاستدعاء والرصيد في [سجل الاستخدام](https://platform.acedata.cloud/console/usages) و [قائمة التطبيقات](https://platform.acedata.cloud/console/applications).

إذا تم إرجاع 401، تحقق مما إذا كان المفتاح كاملاً، وما إذا كان `ANTHROPIC_API_KEY` القديم قد تم إلغاؤه، وأعد تشغيل Claude Code بالكامل. لا يحتاج النموذج إلى أن يكون ثابتًا في تكوين الاتصال، يمكنك اختيار النموذج المتاح حاليًا في Claude Code.
