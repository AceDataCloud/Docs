## 1. الحصول على مفتاح API

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، انتقل إلى التطبيقات المتاحة وانسخ مفتاح API.

![الحصول على مفتاح API من Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. تثبيت CC Switch

قم بتنزيله من [إصدارات CC Switch](https://github.com/farion1231/cc-switch/releases/latest)، يمكن تشغيله أيضًا على macOS:

```bash
brew install --cask cc-switch
```

## 3. إضافة مزود

افتح CC Switch، اختر **Claude Code → إضافة مزود → مخصص**، املأ:

| الحقل       | القيمة                          |
| ---------- | ------------------------------ |
| الاسم      | `Ace Data Cloud`               |
| عنوان URL الأساسي | `https://api.acedata.cloud` |
| مفتاح API  | مفتاح API الذي تم نسخه للتو         |
| تنسيق API  | `رسائل أنثروبيك`              |

إذا كنت بحاجة لاستخدام محرر JSON، قم بتكوينه كالتالي:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

سيقوم CC Switch بكتابة التكوين في إعدادات مستخدم Claude Code. لا تحتفظ بمفتاح حقيقي في مستودع الفريق، ولا تحتفظ أيضًا بمفتاح `ANTHROPIC_API_KEY` القديم.

## 4. التفعيل والتحقق

بعد الحفظ، قم بتمكين **Ace Data Cloud**، وأعد فتح Claude Code. أرسل مهمة بسيطة للقراءة فقط، وتحقق من الاستدعاء في [سجل الاستخدام](https://platform.acedata.cloud/console/usages). إذا استمرت في استخدام التكوين القديم بعد التبديل، قم بالخروج تمامًا من Claude Code و CC Switch ثم حاول مرة أخرى.
