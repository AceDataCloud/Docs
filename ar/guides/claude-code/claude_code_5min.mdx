الهدف من هذه الوثيقة هو واحد فقط: أن تجري أول أمر Claude Code باستخدام وكيل AceData Cloud **في غضون 5 دقائق**. للحصول على الدليل الكامل، راجع وثائق IDE الفرعية ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations))؛ هذه المقالة تتبع أسرع مسار "**سطر الأوامر CLI** + **امتداد VS Code**".

> **لماذا تستخدم وكيل AceData Cloud لـ Claude Code**:
> - اتصال مباشر داخل الصين بدون الحاجة إلى VPN خاص
> - أسعار أقل مقارنة بالرسوم الرسمية (حسب توكنات المنصة)
> - نفس المفتاح يدعم في نفس الوقت بروتوكول Claude Messages API + Claude Code Token

## الدقيقة 1: طلب بيانات الاعتماد

افتح صفحة خدمة [Claude Messages](https://platform.acedata.cloud/documents/claude-messages) واضغط على زر "**Acquire**":

![](https://cdn.acedata.cloud/nyq0xz.png)

سيقوم النظام تلقائيًا بإنشاء تطبيق لك ومنحك رصيدًا مجانيًا. احتفظ بـ **Base URL** و **API Token** من صفحة التفاصيل — ستحتاجهما في الخطوات الخمس التالية.

| الحقل | القيمة | الاستخدام |
|------|------|------|
| `BASE_URL` | `https://api.acedata.cloud/claude` | نقطة دخول متوافقة مع Claude Messages |
| `API_TOKEN` | `sk-...` (يمكن نسخه من صفحة التفاصيل) | رأس المصادقة متوافق مع Anthropic |

## الدقيقة 2: تثبيت Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell الأصلي):

```powershell
irm https://claude.ai/install.ps1 | iex
```

بعد التثبيت، افتح نافذة طرفية جديدة وتحقق من التشغيل:

```bash
claude --version
```

> يجب أن ترى رقم الإصدار. يأتي Claude Code مع بيئة تشغيل Node.js مدمجة، ولا يعتمد على نسخة Node المثبتة على جهازك.

## الدقيقة 3: تعيين متغيرات البيئة إلى AceData Cloud

لا تستخدم عملية `claude login` الرسمية، بل قم بالكتابة فوقها باستخدام متغيرات البيئة. اختر أحد الطريقتين:

**الطريقة أ: مؤقتة (لجلسة Shell الحالية فقط)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud/claude"
export ANTHROPIC_AUTH_TOKEN="sk-توكن-خاصتك"
```

**الطريقة ب: دائمة (موصى بها)**

أضف السطرين أعلاه إلى `~/.zshrc` أو `~/.bashrc` ثم نفذ `source` للملف.

> **مشكلة شائعة**: اسم متغير البيئة هو `ANTHROPIC_AUTH_TOKEN` وليس `ANTHROPIC_API_KEY`؛ استخدام الاسم الخطأ يجعل Claude Code يعود إلى نقطة النهاية الرسمية ويعطي خطأ 401.

## الدقيقة 4: تشغيل أول أمر

انتقل إلى أي مستودع Git وشغّل:

```bash
claude
```

إذا طلب تسجيل الدخول في المرة الأولى، اضغط `Esc` لتخطي. ثم أدخل:

```
اعرض تبعيات المشروع الحالي وشرح مختصر لكل منها.
```

عادة سترى Claude يستخدم أدوات مثل `read_file` / `glob` / `grep` لتصفح المستودع ثم يعرض القائمة. شريط الحالة في أسفل الشاشة سيظهر `connected to api.acedata.cloud` — هذه علامة مهمة تدل على أن الوكيل يعمل.

## الدقيقة 5: ربط امتداد VS Code

1. افتح VS Code → لوحة الإضافات → ابحث عن `Claude Code` وقم بتثبيت الإضافة الرسمية من Anthropic؛
2. اضغط **Cmd+Shift+P** → اكتب `Claude Code: Set Custom API Endpoint`؛
3. أدخل `https://api.acedata.cloud/claude` واضغط Enter؛
4. نفذ مرة أخرى `Claude Code: Set API Token` وأدخل توكنك.

بعد النجاح، سيظهر لوحة Claude Code في الشريط الجانبي، يمكنك سحب الملفات إليها للسؤال أو استخدام `@-mention` لاقتراح تعديلات على ملف. جميع الفواتير تتم عبر AceData Cloud.

## تحقق من أنك تستخدم الوكيل فعلاً

في محادثة Claude Code، اكتب:

```
قم بزيارة https://api.acedata.cloud/whoami وأخبرني بما تم إرجاعه
```

إذا تلقيت معلومات حسابك (`{user_id, plan, ...}`)، فهذا يعني أن الطلب يمر عبر حافة AceData Cloud. إذا تم التحويل إلى النطاق الرسمي وظهرت 401، ارجع إلى الدقيقة 3 وتحقق من اسم متغير البيئة.

## أكثر 5 أسئلة شيوعًا

**س: بعد تشغيل `claude login` وتغيير متغيرات البيئة إلى AceData، لماذا لا يعمل؟**  
ج: `claude login` يكتب التوكن الرسمي في `~/.claude/.credentials.json`، وهذا له أولوية أعلى من متغيرات البيئة. احذف هذا الملف ثم نفذ `source ~/.zshrc`.

**س: هل يمكن استخدام أسماء نماذج مثل `--model claude-opus-4-7`؟**  
ج: نعم. وكيل AceData Cloud يمرر حقل النموذج مباشرة، جميع نماذج Anthropic العامة بالإضافة إلى نماذجنا الموسعة `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5` مدعومة.

**س: هل يمكن إعداد عدة ملفات تعريف (شخصي + عمل)؟**  
ج: نعم. Claude Code يدعم `~/.claude/settings.json` لعدة ملفات تعريف؛ أو ببساطة اكتب دالتين shell `claude_personal` و `claude_work` تقومان بتصدير `ANTHROPIC_AUTH_TOKEN` مختلفة ثم تستدعيان `claude $@`.

**س: هل يمكن تشغيله في GitHub Actions؟**  
ج: نعم. راجع [دليل تكامل Claude Code مع GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**س: ماذا بعد نفاد الرصيد المجاني؟**  
ج: اذهب إلى [إدارة التطبيقات](https://platform.acedata.cloud/applications) → اختر تطبيق Claude → اشحن رصيدك (حسب استهلاك التوكنات) أو قم بالتبديل إلى الاشتراك بالنقاط.
