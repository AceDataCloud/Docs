الهدف من هذه الوثيقة هو فقط: أن تتمكن **في غضون 5 دقائق** من تشغيل أول أمر لـ Claude Code عبر وكيل AceData Cloud. الدليل الكامل موجود في وثائق IDE الفرعية ( [VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) )؛ هذه الوثيقة تركز فقط على أسرع مسار باستخدام «**واجهة الأوامر الطرفية CLI** + **ملحق VS Code**».

> **لماذا نستخدم AceData Cloud كوكيل لـ Claude Code**:
> - اتصال مباشر من داخل البلاد، بدون الحاجة لإعداد VPN خاص
> - سعر أقل مقارنة بالمصدر الرسمي (حسب منصة Token)
> - نفس المفتاح يدعم في الوقت ذاته كل من Claude Messages API وClaude Code Token Protocol

## الدقيقة 1: طلب الاعتماد

افتح [صفحة خدمة Claude Messages](https://platform.acedata.cloud/documents/claude-messages) وانقر على زر «**Acquire**»:

![](https://cdn.acedata.cloud/nyq0xz.png)

سيقوم المنصة تلقائيًا بإنشاء تطبيق لك وتوفير رصيد مجاني. احفظ **Base URL** و **API Token** من صفحة التفاصيل — ستحتاج إليهما في الخطوات الخمسة التالية.

| الحقل | القيمة | الاستخدام |
|--------|---------|------------|
| `BASE_URL` | `https://api.acedata.cloud` | مدخل متوافق مع Claude Messages |
| `API_TOKEN` | `sk-...` (يمكن نسخه من صفحة التفاصيل) | رأس المصادقة المتوافق مع Anthropic |

## الدقيقة 2: تثبيت Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell الأصلي):

```powershell
irm https://claude.ai/install.ps1 | iex
```

بعد الانتهاء من التثبيت، افتح طرفية جديدة وتأكد من أن الأمر يعمل:

```bash
claude --version
```

> إذا ظهرت لك رقم الإصدار، فهذا يعني أن التثبيت ناجح. Claude Code يأتي مع Node.js runtime مدمج، ولا يعتمد على نسخة Node المثبتة على جهازك.

## الدقيقة 3: توجيه متغيرات البيئة إلى AceData Cloud

لا تستخدم عملية `claude login` الرسمية، بل استبدلها بواسطة متغيرات البيئة. اختر أحد الطريقتين:

**الطريقة أ: مؤقتًا (لجلسة الشل الحالية فقط)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-مفتاح-الخاص-بك"
```

**الطريقة ب: دائمًا (موصى بها)**

أضف السطرين أعلاه إلى ملف `~/.zshrc` أو `~/.bashrc`، ثم نفذ الأمر:

```bash
source ~/.zshrc
```
أو
```bash
source ~/.bashrc
```

> **ملاحظة مهمة**: اسم متغير البيئة هو `ANTHROPIC_AUTH_TOKEN` وليس `ANTHROPIC_API_KEY`؛ استخدام الاسم الخاطئ يؤدي إلى رجوع Claude Code إلى نقطة النهاية الرسمية مع خطأ 401.

## الدقيقة 4: تشغيل الأمر الأول

انتقل إلى أي مستودع Git، ثم نفذ:

```bash
claude
```

إذا ظهرت رسالة تطلب تسجيل الدخول عند التشغيل لأول مرة، اضغط على `Esc` لتخطيها. ثم أدخل الأمر التالي:

```
عرض dependencies الحالية للمشروع وشرح مختصر لكل منها.
```

عادة سترى Claude يستخدم أدوات مثل `read_file` / `glob` / `grep` لتصفح المستودع، ثم يعرض قائمة. إذا استجاب النموذج بشكل صحيح ولم يظهر خطأ 401، فهذا يعني أن الوكيل يعمل بشكل صحيح.

## الدقيقة 5: ربط ملحق VS Code

1. افتح VS Code → لوحة الملحقات → ابحث عن `Claude Code`، وثبّت الملحق الرسمي من Anthropic؛
2. أعد تشغيل VS Code أو نفذ الأمر `Developer: Reload Window` من لوحة الأوامر، ليتم تحميل إعدادات `~/.claude/settings.json` التي أعددتها في الدقيقة 3؛
3. اضغط على أيقونة ✦ Spark في أعلى يمين المحرر، أو على شريط الحالة السفلي على «✱ Claude Code» لفتح اللوحة؛
4. في المرة الأولى، سيطلب منك تسجيل الدخول إلى حساب Anthropic، اضغط على `Esc` لتخطي، وسيستخدم الملحق تلقائيًا إعدادات `ANTHROPIC_BASE_URL` و `ANTHROPIC_AUTH_TOKEN` التي أعددتها في الدقيقة 3.

> **ملاحظة**: ملحق VS Code وCLI يستخدمان نفس ملف الإعدادات `~/.claude/settings.json`، لذلك لا حاجة لإعدادها بشكل منفصل في VS Code. إذا أردت تجاوز الإعدادات على مستوى المشروع، يمكنك إنشاء ملف `~/.claude/settings.local.json` في جذر المستودع (مخفي في git).

عند النجاح، يمكنك سحب ملفات من اللوحة لطرح أسئلة، أو استخدام `@-mention` للإشارة إلى ملفات لاقتراح التعديلات. جميع عمليات الدفع تتم عبر AceData Cloud.

## التحقق من أن الوكيل يعمل فعلاً

قم بتشغيل الأمر التالي مع وضع `--debug`، للتحقق من أن الطلبات تصل فعلاً إلى AceData Cloud:

```bash
claude --debug -p "say hi" 2>&1 | grep -iE 'base.?url|api\.acedata|anthropic\.com' | head
```

إذا رأيت `https://api.acedata.cloud`، فهذا يدل على أن الوكيل يعمل. وإذا ظهرت `api.anthropic.com` أو حصلت على خطأ 401، عد إلى الدقيقة 3 للتحقق من اسم متغير البيئة (`ANTHROPIC_AUTH_TOKEN` وليس `ANTHROPIC_API_KEY`) وتأكد من أن ملف `~/.claude/.credentials.json` لا يحتوي على مفتاح رسمي، واحذف الملف إن وجد.

## أكثر 5 أسئلة تكرارًا

**س: بعد تشغيل `claude login` غيرت متغيرات البيئة إلى AceData، ولم تعمل؟**  
ج: `claude login` يكتب المفتاح الرسمي في `~/.claude/.credentials.json`، وله أولوية أعلى من متغيرات البيئة. احذف هذا الملف ثم نفذ `source ~/.zshrc` أو `source ~/.bashrc`.

**س: هل يمكن استخدام `--model claude-opus-4-7` مثلاً؟**  
ج: نعم. وكيل AceData Cloud ينقل حقل النموذج بشكل مباشر، ويدعم جميع نماذج Anthropic العامة بالإضافة إلى نماذجنا الموسعة مثل `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5`.

**س: هل يمكن إعداد ملفات تعريف متعددة (شخصية + شركة)؟**  
ج: نعم. يدعم Claude Code ملفات `~/.claude/settings.json` متعددة، أو أبسط حل هو كتابة دالتين شل `claude_personal` / `claude_work`، وتصدير `ANTHROPIC_AUTH_TOKEN` مختلف لكلٍ منهما، ثم استدعاء `claude $@`.

**س: هل يمكن تشغيله في GitHub Actions؟**  
ج: نعم. راجع [دليل تكامل Claude Code مع GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**س: ماذا لو استُهلك الرصيد المجاني؟**  
ج: انتقل إلى [إدارة التطبيقات](https://platform.acedata.cloud/applications) → اختر تطبيق Claude الخاص بك → اشحن الرصيد (سيتم خصم التكلفة حسب استهلاك Token)، أو قم بالتحويل إلى اشتراك يعتمد على النقاط.
