## 1. الحصول على مفتاح API

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، انتقل إلى التطبيقات المتاحة ونسخ مفتاح API.

![الحصول على مفتاح API من Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. تثبيت CLI والإضافات

أولاً، قم بتثبيت Claude Code CLI.

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

ثم قم بتثبيت إضافة **Claude Code** من JetBrains Marketplace وأعد تشغيل IDE. تستدعي الإضافة الأمر `claude` المحلي؛ إذا تم الإشارة إلى عدم العثور على الأمر، قم بملء المسار الكامل له في **Settings → Tools → Claude Code**.

## 3. إعداد Ace Data Cloud

قم بالإعداد في بيئة تشغيل JetBrains backend.

macOS / Linux / WSL:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="مفتاح API الخاص بك"
unset ANTHROPIC_API_KEY
```

Windows PowerShell:

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "مفتاح API الخاص بك"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

يمكنك أيضًا استخدام ملف `.claude/settings.local.json` الذي تم تجاهله في المشروع:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "مفتاح API الخاص بك"
  }
}
```

يجب تكوين وتثبيت الإضافة في Host البعيد لتطوير Remote؛ يمكن لمستخدمي WSL تعيين أمر Claude ليكون `wsl -d Ubuntu -- bash -lic "claude"`.

## 4. التحقق

قم بتشغيل `claude` من الطرفية المدمجة في IDE، أو ابدأ في الطرفية الخارجية ثم أدخل `/ide`. بعد الاتصال بنجاح، اجعل Claude يرد بـ `OK`، ثم اقرأ ملف اختبار، وتحقق من هذا الطلب في [سجل الاستخدامات](https://platform.acedata.cloud/console/usages) في Ace Data Cloud.

إذا لم تتمكن الإضافة من البدء، قم بتشغيل `claude --version` في نفس الطرفية أولاً؛ إذا كان 401، تحقق من المتغيرات البيئية الفعلية الموروثة من backend و `ANTHROPIC_API_KEY` القديم.
