---
title: "دليل تكوين Claude Code"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code هو وكيل برمجي ذكي أطلقته Anthropic، يمكن استخدامه في بيئات متعددة مثل الطرفية، IDE، وخطوط أنابيب CI/CD. من خلال وكيل AceData Cloud، يمكنك استخدام Claude Code بأسعار أقل.

اختر الدليل الكامل لتكوين المنصة المناسبة حسب سيناريو الاستخدام:

| المنصة | الوصف | رابط الدليل |
|---------|--------|--------------|
| **VS Code** | امتداد أصلي، يدعم Diff المدمج، @-mentions، مراجعة الجدول الزمني | [دليل تكوين VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | محرر متوافق مع VS Code، يدعم امتداد Claude Code بشكل كامل | [دليل تكوين Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **الطرفية (CLI)** | التجربة الأساسية، يمكنك البدء بتشغيل `claude` في أي طرفية | [دليل تكوين الطرفية](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **IDE من JetBrains** | يدعم جميع بيئات IDE مثل IntelliJ IDEA، PyCharm، WebStorm | [دليل تكوين JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | استخدم `@claude` لأتمتة مراجعة الكود ومعالجة Issues | [دليل تكوين GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **ملاحظة**: يمكن للتقديم الأولي أن يتم عبر زيارة [صفحة خدمة رسائل Claude](https://platform.acedata.cloud/documents/claude-messages) والنقر على «Acquire» للحصول على الاعتماد، مما يمنحك رصيدًا مجانيًا.
