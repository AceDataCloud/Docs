يتصل Claude Code بخطة الترميز من خلال بروتوكول رسائل Anthropic، ويوفر حاليًا مدخلين للتكوين: الطرفية و VS Code.

| مدخل الاستخدام      | دليل التكوين                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| الطرفية / CLI  | [تكوين Claude Code للطرفية](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code        | [تكوين Claude Code لـ VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## التكوين المشترك

- عنوان URL الأساسي: `https://api.acedata.cloud`
- رمز API: احصل عليه من تطبيق الترميز، وقم بتكوينه من خلال `ANTHROPIC_AUTH_TOKEN` في الدليل
- معرف النموذج: اختر من دليل النماذج الحية
- بعد تعديل التكوين: أعد تشغيل Claude Code؛ يحتاج مستخدمو VS Code إلى إعادة تحميل النافذة

لا تحتفظ برمز `ANTHROPIC_API_KEY` القديم في نفس الوقت، ولا تكتب الرمز الحقيقي في ملفات المشاركة الجماعية.

عد إلى [مركز تكوين خطة الترميز](https://platform.acedata.cloud/documents/coding-plan-integration).
