---
title: "دليل إعداد Claude Code"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code هو وكيل برمجي تم إطلاقه من قبل Anthropic، يمكن استخدامه في بيئات متعددة مثل الطرفية، IDE، وتطبيقات سطح المكتب. من خلال وكيل AceData Cloud، يمكنك استخدام Claude Code بأسعار أقل.

يرجى اختيار دليل الإعداد المناسب بناءً على سيناريو الاستخدام الخاص بك:

| المنصة               | الوصف                                        | رابط الدليل                                                                                                   |
| ------------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **الطرفية (CLI)**    | تجربة أساسية، يمكنك البدء بتشغيل `claude` في أي طرفية                | [دليل إعداد الطرفية](https://platform.acedata.cloud/documents/claude-code-terminal-integration)                    |
| **VS Code**        | إضافة أصلية، تدعم Diff المضمن، @-mentions، مراجعة المخطط            | [دليل إعداد VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)               |
| **JetBrains IDE**  | تدعم IntelliJ IDEA، PyCharm، WebStorm وغيرها من IDEs الكاملة | [دليل إعداد JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)          |
| **GitHub Actions** | استخدم `@claude` لأتمتة مراجعة الكود ومعالجة القضايا             | [دليل إعداد GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **نصيحة**: يمكن للمستخدمين الجدد زيارة [صفحة خدمة Claude Messages](https://platform.acedata.cloud/documents/claude-messages) والنقر على "Acquire" للحصول على الشهادة، مما يمنحك رصيدًا مجانيًا.
