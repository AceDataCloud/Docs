---
title: "دليل إعداد Claude Code"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code هو وكيل برمجي ذكي أطلقته شركة Anthropic، يمكن استخدامه في بيئات متعددة مثل الطرفية، وIDE، وتطبيقات سطح المكتب. من خلال وكيل AceData Cloud، يمكنك استخدام Claude Code بتكلفة أقل.

> **هل هذه هي المرة الأولى التي تستخدم فيها؟** يُنصح بمراجعة [Claude Code 5 دقائق للبدء السريع](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) — من الحصول على الاعتماد إلى تشغيل أول أمر بنجاح، خمس خطوات فقط.

اختر الدليل الكامل للإعداد حسب منصة الاستخدام:

| المنصة | الوصف | رابط الدليل |
|------|------|---------|
| **⚡ بدء سريع خلال 5 دقائق** | من الحصول على الاعتماد إلى أول أمر `claude`، خمس خطوات فقط | [دليل 5 دقائق](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) |
| **الطرفية (CLI)** | التجربة الأساسية، شغّل `claude` في أي طرفية للبدء | [دليل إعداد الطرفية](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code** | امتداد أصلي يدعم مقارنة التغييرات داخل السطر، و@-mentions، ومراجعة الخطط | [دليل إعداد VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | محرر متوافق مع VS Code، يدعم امتداد Claude Code بالكامل | [دليل إعداد Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **JetBrains IDE** | يدعم IntelliJ IDEA، PyCharm، WebStorm وجميع IDEs من JetBrains | [دليل إعداد JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | استخدم `@claude` لأتمتة مراجعة الكود ومعالجة القضايا | [دليل إعداد GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |
| **تطبيق سطح المكتب (معاينة)** | عميل رسومي مستقل يدعم الجلسات المتوازية وربط الأدوات الخارجية | [دليل إعداد تطبيق سطح المكتب](https://platform.acedata.cloud/documents/claude-code-desktop-integration) |

> **تلميح**: عند التقديم لأول مرة، يمكنك زيارة [صفحة خدمة Claude Messages](https://platform.acedata.cloud/documents/claude-messages) والنقر على "Acquire" للحصول على الاعتماد، وستحصل على رصيد مجاني.
