Claude Code هو أداة **Agentic Coding** أطلقتها شركة Anthropic، ويعتبر واحدًا من أقوى وكلاء البرمجة في العالم. يوفر تطبيق Claude Code لسطح المكتب واجهة رسومية مستقلة، ويدعم مراجعة Diff، والجلسات المتوازية (من خلال عزل Git Worktree)، والجلسات عن بُعد، دون الحاجة للاعتماد على أي IDE.

تتناول هذه الوثيقة كيفية تكوين واستخدام تطبيق Claude Code من خلال خدمة الوكيل الخاصة بـ AceData Cloud.

> **ملاحظة**: تطبيق Claude Code لسطح المكتب حاليًا في مرحلة المعاينة (Preview)، ويدعم فقط macOS و Windows.

## عملية التقديم

لاستخدام Claude Code، يمكنك أولاً زيارة [صفحة خدمة Claude Messages](https://platform.acedata.cloud/documents/claude-messages) والنقر على زر "Acquire" للحصول على الشهادات المطلوبة:

![](https://cdn.acedata.cloud/nyq0xz.png)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل، سيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد تسجيل الدخول، سيتم العودة تلقائيًا إلى الصفحة الحالية.

عند التقديم لأول مرة، ستحصل على رصيد مجاني لتجربة خدمة Claude Code مجانًا.

## تثبيت تطبيق سطح المكتب

### متطلبات النظام

- macOS (Intel و Apple Silicon) أو Windows (x64 / ARM64)
- لا يدعم Linux تطبيق سطح المكتب حاليًا

### تنزيل وتثبيت

انتقل إلى [صفحة التنزيل الرسمية لـ Claude](https://claude.ai) لتنزيل حزمة التثبيت المناسبة للمنصة:

- **macOS**: قم بتنزيل ملف `.dmg`، واسحبه إلى مجلد Applications
- **Windows x64**: قم بتنزيل حزمة التثبيت `.exe`، واتبع التعليمات للتثبيت
- **Windows ARM64**: قم بتنزيل إصدار ARM64 (ملاحظة: لا يدعم ARM64 الجلسات المحلية، يجب استخدام الجلسات عن بُعد)

![صفحة تنزيل تطبيق Claude لسطح المكتب](https://cdn.acedata.cloud/c3c8c57264.png)

بعد الانتهاء من التثبيت، قم بتشغيل Claude من مجلد Applications (macOS) أو قائمة ابدأ (Windows).

## تكوين واجهة برمجة التطبيقات لـ AceData Cloud

بعد تشغيل تطبيق سطح المكتب، تحتاج إلى تسجيل الدخول إلى حساب Anthropic. يمكننا استخدام واجهة برمجة التطبيقات الخاصة بـ AceData Cloud من خلال تكوين متغيرات البيئة، **دون الحاجة للاشتراك الرسمي**.

يقرأ تطبيق سطح المكتب متغيرات البيئة من بيئة Shell الخاصة بك، لذا يجب إعدادها في ملف تكوين Shell.

### تكوين متغيرات البيئة

**لمستخدمي macOS**

أضف المحتوى التالي إلى `~/.zshrc` (أو `~/.bashrc`)، واستبدل `{token}` برمز API الخاص بك:

```bash
# تكوين وكيل AceData Cloud - Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

بعد الحفظ، نفذ:

```bash
source ~/.zshrc
```

**لمستخدمي Windows**

قم بإضافة متغيرات البيئة النظامية التالية من خلال "خصائص النظام → متقدم → متغيرات البيئة":

| اسم المتغير                | القيمة                           |
| ---------------------- | ----------------------------- |
| `ANTHROPIC_AUTH_TOKEN` | `{token}` (استبدل برمز API الخاص بك)     |
| `ANTHROPIC_BASE_URL`   | `https://api.acedata.cloud` |

أو استخدم PowerShell:

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**يمكن أيضًا تكوينها من خلال settings.json**

قم بتحرير `~/.claude/settings.json` (إذا لم يكن موجودًا، قم بإنشائه):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **تلميح**: يمكنك عرض رمز API في [وحدة التحكم الخاصة بـ AceData Cloud](https://platform.acedata.cloud/console). بعد الانتهاء من التكوين، تحتاج إلى **إعادة تشغيل تطبيق سطح المكتب** لتفعيل متغيرات البيئة.

## الاستخدام الأساسي

### فتح المشروع

1. قم بتشغيل تطبيق Claude لسطح المكتب
2. انقر على علامة التبويب **Code** في الأعلى
3. اختر وضع التشغيل **Local**
4. انقر على **Select folder** لاختيار دليل مشروعك

### بدء المحادثة

في مربع الإدخال، أدخل وصفًا بلغة طبيعية لاحتياجاتك:

- "ابحث عن تعليقات TODO وقم بإصلاحها"
- "أضف اختبارًا للدالة الرئيسية"
- "اشرح هيكل هذا المشروع"

سيقوم Claude بتحليل مستودع الشيفرة الخاص بك، واقتراح تعديلات، وعرض التغييرات في عرض Diff.

### وضع الأذونات

يمكنك التبديل بين الأوضاع باستخدام محدد الوضع بجانب زر الإرسال:

| الوضع       | الوصف                 |
| -------- | ------------------ |
| **Ask**  | استفسار قبل كل تعديل (موصى به للمبتدئين)  |
| **Code** | قبول تحرير الملفات تلقائيًا، لكن أوامر الطرفية تحتاج إلى تأكيد |
| **Plan** | وضع خطة مفصلة أولاً في انتظار الموافقة، ثم التنفيذ بعد التأكيد |

### الجلسات المتوازية

يمكنك بدء جلسات متعددة متوازية من خلال النقر على **+ New session** في الشريط الجانبي. بالنسبة لمستودعات Git، ستحصل كل جلسة على نسخة مستقلة من المشروع من خلال Worktree، دون تداخل.

يتم تخزين Worktree بشكل افتراضي في دليل `~/.claude-worktrees/`.

### مراجعة Diff

عندما يقوم Claude بتعديل الملفات، سيظهر إحصاء التغييرات (مثل `+12 -1`)، يمكنك النقر لفتح عارض Diff لمراجعة التعديلات ملفًا بملف. يمكنك أيضًا النقر على سطور الشيفرة المحددة لإضافة تعليقات، وسيقوم Claude بتعديل بناءً على ملاحظاتك.

## الاتصال بالأدوات الخارجية

قبل بدء الجلسة، انقر على زر **⋯**، واختر **Connectors** لإضافة تكاملات خارجية:

- تقويم Google
- Slack
- GitHub
- Linear
- Notion
- المزيد...

بعد الاتصال، يمكن لـ Claude قراءة التقويم مباشرة، وإرسال الرسائل، وإنشاء القضايا، وغيرها.

## العلاقة مع CLI

يستخدم تطبيق سطح المكتب و CLI نفس المحرك الأساسي، ويتشاركان في التكوينات التالية:

- ملفات ذاكرة المشروع `CLAUDE.md` / `CLAUDE.local.md`
- تكوين خادم MCP في `~/.claude.json` / `.mcp.json`
- الإعدادات في `~/.claude/settings.json`
- تكوينات Hooks و Skills

يمكن تشغيل كلاهما في نفس المشروع، مع الحفاظ على تاريخ جلسات مستقل.

## الأسئلة الشائعة

### ماذا أفعل إذا فشلت الاتصال؟

1. تحقق مما إذا تم إنشاء ملف `~/.claude/config.json` بشكل صحيح
2. تأكد من أن متغيرات البيئة تم إعدادها بشكل صحيح (أعد تشغيل تطبيق سطح المكتب لتفعيلها)
3. تأكد من أن رمز API صالح (يمكنك التحقق في [وحدة التحكم](https://platform.acedata.cloud/console))
4. إذا كنت تستخدم `settings.json` لتكوين متغيرات البيئة، تأكد من أن تنسيق الملف صحيح

### ماذا أفعل إذا لم أتمكن من العثور على الأدوات المثبتة؟

إذا لم يتمكن Claude من العثور على أوامر مثل `npm`، `node`:

1. تأكد من أن هذه الأدوات تعمل بشكل صحيح في الطرفية العادية
2. تحقق من ملف تكوين Shell الخاص بك (`~/.zshrc`، `~/.bashrc`) للتأكد من إعداد PATH بشكل صحيح
3. أعد تشغيل تطبيق سطح المكتب لإعادة تحميل متغيرات البيئة

### كيف يمكنني عرض الرصيد المتبقي؟

قم بتسجيل الدخول إلى [وحدة التحكم الخاصة بـ AceData Cloud](https://platform.acedata.cloud/console) لعرض الرصيد المتبقي وحالة الاستخدام الحالية.
