## 1. الحصول على مفتاح API

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، انتقل إلى التطبيقات المتاحة وانسخ مفتاح API.

![الحصول على مفتاح API من Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

في مستودع GitHub المستهدف، انتقل إلى **الإعدادات → الأسرار والمتغيرات → الإجراءات** وأنشئ سرًا جديدًا:

```text
ACEDATACLOUD_API_KEY
```

## 2. تثبيت تطبيق GitHub

قم بتثبيت [تطبيق Claude GitHub](https://github.com/apps/claude) ومنح الإذن للمستودع المستهدف. سيطلب هذا التطبيق الرسمي مجموعة كاملة من الأذونات الثابتة؛ حيث يستخدم إجراء Claude Code فعليًا أذونات المحتويات، والمشكلات، وطلبات السحب، ولا يمكن تحديد هذه الثلاثة فقط في صفحة تثبيت GitHub. إذا كانت المنظمة تتطلب الحد الأدنى من الأذونات، يرجى إنشاء تطبيق GitHub مخصص وفقًا للوثائق الرسمية.

## 3. إضافة Workflow

قم بإنشاء `.github/workflows/claude.yml`:

```yaml
name: Claude Code

on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  claude:
    if: contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      actions: read
      id-token: write
    env:
      ANTHROPIC_BASE_URL: https://api.acedata.cloud
      ANTHROPIC_CUSTOM_HEADERS: "Authorization: Bearer ${{ secrets.ACEDATACLOUD_API_KEY }}"
    steps:
      - uses: actions/checkout@v6
        with:
          fetch-depth: 1
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: dummy-not-used
```

يتطلب `claude-code-action` إدخال `anthropic_api_key` غير الفارغ؛ لن يتم استخدام قيمة الحجز هنا في مصادقة المنصة. ستقوم `ANTHROPIC_CUSTOM_HEADERS` بتجاوز رأس Bearer المطلوب من Ace Data Cloud، والمفتاح الحقيقي يأتي فقط من سر GitHub.

## 4. التحقق

بعد تقديم Workflow، أرسل في تعليق Issue أو PR:

```text
@claude Reply only OK
```

عند النجاح، ستكتمل إجراءات Workflow، وسيتم تحديث النتائج في Issue/PR المقابل. إذا أشار الإجراء إلى نقص في بيانات الاعتماد، تأكد من أن `dummy-not-used` لا يزال موجودًا؛ إذا كان هناك خطأ 401، تحقق من سر `ACEDATACLOUD_API_KEY`. لا تقم بطباعة السر في السجلات. يمكن استخدام `claude_args` لضبط `--max-turns` حسب الحاجة أو اختيار النموذج المتاح حاليًا، لكن الاتصال بالنموذج ليس ثابتًا.
