Claude Code هو أداة برمجة أطلقتها شركة Anthropic، ويُعتبر واحدًا من أقوى وكلاء البرمجة في العالم. يوفر ملحق Claude Code لـ VS Code واجهة رسومية أصلية، وهو الطريقة الموصى بها لاستخدام Claude Code في VS Code.

تتناول هذه الوثيقة كيفية تكوين واستخدام ملحق Claude Code في VS Code من خلال خدمة الوكيل الخاصة بـ Ace Data Cloud.

## عملية التقديم

لاستخدام Claude Code، يمكنك أولاً الذهاب إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، احتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تقم بتسجيل الدخول أو التسجيل بعد، سيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد تسجيل الدخول سيتم العودة تلقائيًا إلى الصفحة الحالية.

عند التقديم لأول مرة، ستحصل على حصة مجانية لتجربة خدمة Claude Code مجانًا.

## تثبيت ملحق Claude Code

ابحث عن **Claude Code** في سوق ملحقات VS Code، وتأكد من أن الناشر هو **Anthropic** ثم قم بالتثبيت. بعد الانتهاء من التثبيت، ستظهر مدخل Claude Code في شريط النشاط.

## تكوين واجهة برمجة تطبيقات Ace Data Cloud

عند فتح الملحق لأول مرة، سيُطلب منك تسجيل الدخول إلى حساب Anthropic الرسمي. يمكننا تخطي تسجيل الدخول الرسمي، من خلال تكوين واجهة برمجة تطبيقات الوكيل الخاصة بـ Ace Data Cloud للاستخدام، دون الحاجة إلى اشتراك رسمي.

تقرأ الإضافات وسطر الأوامر CLI نفس مجموعة إعدادات Claude Code. لمزيد من التفاصيل حول المصادقة الكاملة، ومعالجة تعارضات الاعتماديات، وطريقة التكوين العالمية، راجع [دليل تكوين سطر أوامر Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration). إذا كنت ترغب في أن تكون الإعدادات فعالة فقط في المشروع الحالي، قم بإنشاء ملف `.claude/settings.local.json` في جذر المشروع وتم تضمينه في `.gitignore`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

حيث أن `{token}` هو رمز API الذي قمت بنسخه سابقًا. إذا كان هناك `ANTHROPIC_API_KEY` قديم في بيئة تشغيل VS Code، يرجى أولاً استخدام الأمر `unset ANTHROPIC_API_KEY` في تلك البيئة؛ لا تعتبر السلسلة الفارغة كتنظيف، ولا تضع المفتاح الحقيقي في ملف `.claude/settings.json` المشترك مع الفريق.

فيما يلي تكوين تم إكماله على الجهاز المحلي باستخدام VS Code 1.136.1 وملحق Claude Code 2.1.251. تم استخدام مفاتيح مكانية في اللقطات لتجنب تسريب الاعتماديات الحقيقية:

![تكوين Ace Data Cloud Claude Code في VS Code](https://cdn.acedata.cloud/f925e9e9597b.png)

بعد الانتهاء من التكوين، أعد تشغيل VS Code.

> ملاحظة: التكوين أعلاه ساري فقط على المشروع الحالي، ومن المستحسن تضمين مسار ملف التكوين `.claude/settings.local.json` في ملف `.gitignore` لمنع رفعه إلى المستودع البعيد.

إذا كنت ترغب في أن يكون التكوين ساريًا على جميع المشاريع، يمكنك ببساطة وضع هذا التكوين في دليل المستخدم. المسار المقابل هو `~/.claude/settings.json`،

> ملاحظة: بعد الانتهاء من التكوين، يرجى إعادة تشغيل أو إعادة تحميل VS Code لتفعيل التكوين المذكور.

## الاستخدام الأساسي

بعد التكوين، أرسل مهمة بسيطة للقراءة فقط في لوحة Claude Code، مثل "اقرأ README.md وقدم ملخصًا بجملة واحدة". بعد نجاح المهمة، يمكنك التحقق من هذه المكالمة في [سجل الاستخدام](https://platform.acedata.cloud/console/usages).

## كيفية التحقق من الرصيد المتبقي

يمكنك التحقق من الرصيد المتبقي لحسابك من خلال [لوحة تحكم Ace Data Cloud - قائمة التطبيقات](https://platform.acedata.cloud/console/applications).

يمكنك أيضًا الاطلاع على جميع سجلات الاستخدام وتفاصيل الخصم من خلال [لوحة تحكم Ace Data Cloud - سجل الاستخدام](https://platform.acedata.cloud/console/usages).
