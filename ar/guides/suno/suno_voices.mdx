تتيح لنا SUNO إنشاء شخصية صوت مخصصة من خلال أي ملف صوتي، لتحقيق استنساخ الصوت لاستخدامه في توليد الموسيقى. على عكس واجهة برمجة التطبيقات Persona API الموجودة (التي تستخدم `audio_id` المُولد بواسطة Suno)، تقبل هذه الواجهة رابطًا عامًا متاحًا `audio_url`، وهو تسجيل صوتك الخاص. توضح هذه الوثيقة طريقة دمج واجهة برمجة تطبيقات استنساخ الصوت.

## الخطوة الأولى: إنشاء شخصية صوت

تحتوي هذه الواجهة على ثلاثة معلمات إدخال: `audio_url` (إلزامي)، وهو رابط ملف صوتي بصيغة MP3 أو WAV متاح للعامة، يحتوي على صوت واضح لشخص واحد؛ و`name` و`description` (اختياريان)، وهما اسم ووصف شخصية الصوت.

**متطلبات ملف الصوت:**
- الصيغة: MP3 أو WAV
- الطول: لا يقل عن 10 ثوانٍ
- المحتوى: صوت واضح لشخص واحد، مع تقليل الضوضاء الخلفية أو الموسيقى قدر الإمكان

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

النتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

يمكن ملاحظة أن حقل `persona_id` في `data` هو معرف شخصية الصوت التي تم إنشاؤها. وحقل `is_public` يكون دائمًا `false` لأن شخصية الصوت التي تم إنشاؤها عبر رفع ملف صوتي هي خاصة.

## الخطوة الثانية: استخدام شخصية الصوت لتوليد الموسيقى

بعد الحصول على معرف شخصية الصوت، يمكننا استخدام [واجهة برمجة تطبيقات توليد الأصوات Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) لتوليد الموسيقى. قم بتعيين `action` إلى `generate`، و`persona_id` إلى معرف شخصية الصوت الذي تم إرجاعه أعلاه، وسيتم أداء الأغنية باستخدام الصوت المستنسخ.

> **ملاحظة:** استنساخ الصوت مدعوم فقط للنماذج `chirp-v4-5` وما فوق (مثل `chirp-v4-5`، `chirp-v5`، `chirp-v5-5`)، ولا يدعم `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

النتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

يمكن ملاحظة أن الأغنية المولدة تم أداؤها باستخدام الصوت المستنسخ. يمكن أيضًا استخدام `persona_id` مع إجراء `cover` لإعادة غناء أغاني موجودة باستخدام الصوت المستنسخ.
