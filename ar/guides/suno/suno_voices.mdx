---

تسمح SUNO لنا بإنشاء شخصية صوت مخصصة عبر أي ملف صوتي، وتحقيق استنساخ الصوت لاستخدامه في توليد الموسيقى. بخلاف Persona API الحالية (التي تستخدم `audio_id` المُنشأ بواسطة Suno)، تقبل هذه الواجهة `audio_url` متاحًا للعامة، أي تسجيلك الصوتي الخاص. يشرح هذا المستند طريقة تكامل واجهة API لاستنساخ الصوت.

## الخطوة الأولى: إنشاء شخصية صوت

تحتوي واجهة API هذه على ثلاث معاملات إدخال: `audio_url` (إلزامي)، وهو عنوان URL لملف صوتي بصيغة MP3 أو WAV متاح للعامة ويحتوي على صوت بشري واضح لشخص واحد؛ و`name` و`description` (اختياريان)، وهما اسم ووصف شخصية الصوت.

> **متطلبات الملف الصوتي**
> - يجب أن تكون صيغة الصوت `WAV` أو `MP3`
> - يجب أن تتراوح مدة الصوت بين `10~240 ثانية`، ويُوصى باستخدام مادة صوتية نظيفة وجافة لشخص واحد لمدة `30~60 ثانية`
> - يجب أن يحتوي الصوت على **كلام أو غناء بشري واضح وقابل للتمييز لشخص واحد**
> - يُرجى التأكد من تجنب **ضوضاء الخلفية، والمصاحبة الموسيقية، والصدى، والارتداد الصوتي**؛ فعادةً لا يمكن للأغاني الكاملة المصحوبة بموسيقى اجتياز التحقق من بصمة الصوت
> - لا تُضمّن **عدة متحدثين** أو **أصواتًا بشرية متعددة**
> - قد تؤدي المواد ذات مستوى الصوت المنخفض جدًا، أو الكلام غير الواضح، أو الضوضاء المفرطة إلى **فشل الاستنساخ** أو **نتائج توليد ضعيفة**
> **توضيح قيود الاستخدام**
> - شخصيات الصوت التي تُنشأ عبر رفع الصوت هي **موارد خاصة**
> - شخصية الصوت هذه **لا تدعم إعادة الاستخدام عبر الحسابات**
> - يُوصى باستخدامها في أقرب وقت ممكن بعد إنشائها بنجاح؛ فقد تصبح **غير صالحة أو غير متاحة** إذا لم تُستخدم لفترة طويلة
> - يتم إنشاء `name` المُعاد تلقائيًا بواسطة النظام، لذا يُرجى الاعتماد على `persona_id` المُعاد

> **يُرجى إعادة المحاولة أولًا عند فشل الاستدعاء**
> استنساخ الصوت مهمة كثيفة الحوسبة، وحتى لو كانت المادة متوافقة تمامًا، توجد احتمالية معينة لفشل عرضي، ومن النتائج الشائعة
> `voices_sound_different` (لم يجتز التحقق من بصمة الصوت) وغيرها. **هذا النوع من الفشل لا علاقة له بجودة الصوت، وعادةً ما تنجح إعادة المحاولة باستخدام المادة نفسها**،
> ويُوصى بتنفيذ 1~2 من عمليات إعادة المحاولة التلقائية للنتائج الفاشلة عند التكامل. لن يتم احتساب رسوم للطلبات الفاشلة.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> ما سبق `https://cdn.acedata.cloud/suno_demo.mp3` هو مادة مثال يمكن استدعاؤها مباشرةً (MP3، 41 ثانية، صوت جاف لشخص واحد).
> إذا كنت تحتاج إلى مثال بصيغة `WAV`، يمكنك استخدام
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV، 41 ثانية، أحادي القناة 44.1kHz).

النتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

يمكن ملاحظة أن حقل `persona_id` في `data` هو معرّف شخصية الصوت التي تم إنشاؤها. يكون حقل `is_public` دائمًا `false`، لأن شخصية الصوت التي تم إنشاؤها عبر رفع ملف صوتي خاصة. لاحظ أن `name` المُعاد يتم إنشاؤه تلقائيًا بواسطة النظام، لذا استخدم `persona_id` للإشارة إلى شخصية الصوت هذه لاحقًا.

## الخطوة الثانية: استخدام شخصية الصوت لتوليد الموسيقى

بعد الحصول على معرّف شخصية الصوت، يمكننا استخدام [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) لتوليد الموسيقى. اضبط `action` على `generate`، واضبط `persona_id` على معرّف شخصية الصوت المُعاد أعلاه، وستستخدم الأغاني المُنشأة الصوت المستنسخ للغناء.

> **ملاحظة:** يدعم استنساخ الصوت فقط نماذج `chirp-v4-5` وما فوق (مثل `chirp-v4-5` و`chirp-v5` و`chirp-v5-5`)، ولا يدعم `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

النتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

يمكن ملاحظة أن الأغنية المُنشأة استخدمت الصوت المستنسخ للغناء. يمكن أيضًا استخدام `persona_id` مع إجراء `cover` لإعادة غناء الأغاني الموجودة باستخدام الصوت المستنسخ.
