---

---

تتيح لنا SUNO إنشاء شخصيات صوتية مخصصة عبر أي ملف صوتي، وتحقيق استنساخ الصوت لاستخدامه في توليد الموسيقى. وعلى خلاف واجهة Persona API الحالية (التي تستخدم `audio_id` المُنشأ بواسطة Suno)، تقبل واجهة برمجة التطبيقات هذه `audio_url` متاحًا للعامة، أي تسجيلك الصوتي الخاص. يشرح هذا المستند طريقة تكامل واجهة برمجة تطبيقات استنساخ الصوت.

## الخطوة الأولى: إنشاء شخصية صوتية

الفوترة: بعد إنشاء الشخصية الصوتية بنجاح، تبلغ التكلفة القياسية لكل طلب **0.15 Credits**. تخضع العروض الاستهلاكية المطبقة للفوترة الفعلية، ولا تُفرض رسوم على الطلبات الفاشلة.

تحتوي واجهة برمجة التطبيقات هذه على ثلاث معاملات إدخال: `audio_url` (إلزامي)، وهو عنوان URL لملف صوتي بصيغة MP3 أو WAV متاح للعامة ويحتوي على صوت بشري واضح لشخص واحد؛ و`name` و`description` (اختياريان)، وهما اسم ووصف الشخصية الصوتية.

> **متطلبات الملف الصوتي**
> - يجب أن تكون صيغة الصوت `WAV` أو `MP3`
> - يجب أن تتراوح مدة الصوت بين `10~240 ثانية`، ويُوصى باستخدام مادة صوتية نظيفة وجافة لشخص واحد لمدة `30~60 ثانية`
> - يجب أن يحتوي الصوت على **صوت واضح وقابل للتمييز لشخص واحد يتحدث أو يغني**
> - يُرجى التأكد من تجنب **ضوضاء الخلفية، والمرافقة الموسيقية، والصدى، والارتداد الصوتي**؛ إذ إن الأغاني الكاملة المصحوبة بمرافقة موسيقية لا تجتاز عادةً التحقق من البصمة الصوتية
> - لا تضمّن **عدة متحدثين** أو**أصواتًا بشرية متعددة**
> - قد تؤدي المواد ذات الصوت المنخفض جدًا أو الكلام غير الواضح أو الضوضاء الشديدة إلى **فشل الاستنساخ** أو**نتائج توليد ضعيفة**
> **شرح قيود الاستخدام**
> - الشخصيات الصوتية المُنشأة عبر رفع الصوت هي **موارد خاصة**
> - هذه الشخصية الصوتية **لا تدعم إعادة الاستخدام عبر الحسابات**
> - يُوصى باستخدامها في أقرب وقت ممكن بعد إنشائها بنجاح؛ فقد تصبح **غير صالحة أو غير متاحة** عند عدم استخدامها لفترة طويلة
> - يتم إنشاء `name` المُعاد تلقائيًا بواسطة النظام، ويُرجى الاعتماد على `persona_id` المُعاد

> **يُرجى إعادة المحاولة أولًا عند فشل الاستدعاء**
> استنساخ الصوت مهمة كثيفة الحوسبة، وحتى إذا كانت المادة متوافقة تمامًا، فهناك احتمال معين لحدوث فشل عرضي، ومن الردود الشائعة
> `voices_sound_different` (لم يجتز التحقق من البصمة الصوتية) وغيرها. **هذا النوع من الفشل لا يتعلق بجودة الصوت، وعادةً ما تنجح إعادة المحاولة باستخدام المادة نفسها**،
> ويُوصى بتنفيذ إعادة محاولة تلقائية من 1 إلى مرتين للنتائج الفاشلة عند التكامل. لن تُفرض رسوم على الطلبات الفاشلة.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> إن `https://cdn.acedata.cloud/suno_demo.mp3` أعلاه هو مادة مثال يمكن استدعاؤها مباشرةً (MP3، 41 ثانية، صوت جاف لشخص واحد).
> إذا كنت بحاجة إلى مثال بصيغة `WAV`، يمكنك استخدام
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV، 41 ثانية، أحادي القناة 44.1kHz).

تكون النتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

يمكن ملاحظة أن حقل `persona_id` ضمن `data` هو معرّف الشخصية الصوتية التي تم إنشاؤها. يكون حقل `is_public` دائمًا `false`، لأن الشخصيات الصوتية المُنشأة عبر رفع الصوت خاصة. لاحظ أن `name` المُعاد يتم إنشاؤه تلقائيًا بواسطة النظام، ويُرجى استخدام `persona_id` لاحقًا للإشارة إلى هذه الشخصية الصوتية.

## الخطوة الثانية: استخدام الشخصية الصوتية لتوليد الموسيقى

بعد الحصول على معرّف الشخصية الصوتية، يمكننا استخدام [واجهة برمجة تطبيقات توليد أصوات Suno](https://platform.acedata.cloud/documents/suno-audios) لتوليد الموسيقى. اضبط `action` على `generate`، واضبط `persona_id` على معرّف الشخصية الصوتية المُعاد أعلاه، وستستخدم الأغنية المُولدة الصوت المستنسخ للغناء.

> **ملاحظة:** يدعم استنساخ الصوت فقط نماذج `chirp-v4-5` والإصدارات الأحدث (مثل `chirp-v4-5` و`chirp-v5` و`chirp-v5-5`)، ولا يدعم `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

تكون النتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

يمكن استخدام `persona_id` للتوليد عبر `generate`، كما يمكن استخدامه للغناء المعاد عبر `cover` / `upload_cover`. لا حاجة إلى تعبئة `vocal_gender` في الوقت نفسه عند تحديد الصوت؛ وتظل درجة تشابه الصوت معتمدة على المادة المرجعية ونتيجة التوليد.

الصوت الذي يُنشأ عبر هذه الواجهة هو مورد خاص. قبل إعادة غناء أغنية موجودة، استدعِ أولًا `/suno/upload`، ومرّر `audio_url` للأغنية الأصلية و`persona_id` الخاص بهذا الصوت؛ وبعد نجاح الرفع، استخدم `data.audio_id` المُعاد و`persona_id` نفسه لاستدعاء `/suno/audios`:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

يجب استخدام قناة الخدمة نفسها لإنشاء الصوت ورفع الأغنية الأصلية وإعادة الغناء. لا تُعد استخدام معرّفات الأغاني التي لم تُربط مسبقًا بهذا الصوت الخاص مباشرةً؛ للتفاصيل، راجع [رفع صوت مرجعي في Suno](https://platform.acedata.cloud/documents/suno-upload).
