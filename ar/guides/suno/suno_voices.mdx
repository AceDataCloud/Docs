تتيح لنا SUNO إنشاء شخصية صوتية مخصصة عبر أي ملف صوتي، لتحقيق استنساخ الصوت لاستخدامه في توليد الموسيقى. بخلاف واجهة Persona API الحالية (التي تستخدم `audio_id` المُنشأ بواسطة Suno)، تقبل هذه الواجهة `audio_url` متاحًا للعامة، أي تسجيلك الصوتي الخاص. يشرح هذا المستند طريقة تكامل واجهة برمجة تطبيقات استنساخ الصوت.

## الخطوة الأولى: إنشاء شخصية صوتية

تحتوي واجهة برمجة التطبيقات هذه على ثلاث معاملات إدخال: `audio_url` (إلزامي)، وهو رابط لملف صوتي بتنسيق MP3 أو WAV يمكن الوصول إليه علنًا ويحتوي على صوت بشري واضح لشخص واحد؛ و`name` و`description` (اختياريان)، وهما اسم ووصف الشخصية الصوتية.

> **متطلبات الملف الصوتي**
> - يجب أن يكون تنسيق الصوت `WAV` أو `MP3`
> - يجب أن تتراوح مدة الصوت بين `10~240 ثانية`، ويوصى باستخدام مادة صوتية نظيفة وجافة لشخص واحد لمدة `30~60 ثانية`
> - يجب أن يحتوي الصوت على **صوت بشري واضح وقابل للتعرّف لشخص واحد يتحدث أو يغني**
> - يُرجى التأكد من تجنب **ضوضاء الخلفية، والمرافقة الموسيقية، والصدى، والارتداد الصوتي**؛ إذ إن الأغاني الكاملة المصحوبة بمرافقة موسيقية لا تجتاز عادةً التحقق من البصمة الصوتية
> - لا تضمّن **عدة متحدثين** أو**أصواتًا بشرية متعددة**
> - قد تؤدي المواد ذات مستوى الصوت المنخفض جدًا أو الكلام غير الواضح أو الضوضاء الشديدة إلى **فشل الاستنساخ** أو**ضعف نتيجة التوليد**
> **توضيح قيود الاستخدام**
> - الشخصيات الصوتية التي يتم إنشاؤها عبر رفع الصوت هي **موارد خاصة**
> - هذه الشخصية الصوتية **لا تدعم إعادة الاستخدام عبر الحسابات**
> - يُنصح باستخدامها في أقرب وقت ممكن بعد نجاح الإنشاء، فقد تصبح **غير صالحة أو غير متاحة** إذا لم تُستخدم لفترة طويلة
> - يتم إنشاء `name` المُعاد تلقائيًا بواسطة النظام، ويُرجى الاعتماد على `persona_id` المُعاد

> **يُرجى إعادة المحاولة أولًا عند فشل الاستدعاء**
> استنساخ الصوت مهمة كثيفة الحوسبة، وحتى إذا كانت المادة متوافقة تمامًا، فهناك احتمال معين لحدوث فشل عرضي، ومن الردود الشائعة مثل
> `voices_sound_different` (لم يجتز التحقق من البصمة الصوتية) وغيرها. **هذا النوع من الفشل لا علاقة له بجودة الصوت، وعادةً ما تنجح إعادة المحاولة باستخدام المادة نفسها**،
> ويُنصح بتنفيذ 1~2 من عمليات إعادة المحاولة التلقائية للنتائج الفاشلة عند التكامل. لن يتم احتساب رسوم على الطلبات الفاشلة.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> يُعد `https://cdn.acedata.cloud/suno_demo.mp3` أعلاه مادة نموذجية يمكن استدعاؤها مباشرةً (MP3، 41 ثانية، صوت جاف لشخص واحد).
> إذا كنت بحاجة إلى مثال بتنسيق `WAV`، فيمكنك استخدام
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV، 41 ثانية، أحادي القناة 44.1kHz).

تكون النتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

كما يمكن ملاحظة، فإن حقل `persona_id` في `data` هو معرّف الشخصية الصوتية التي تم إنشاؤها. يكون حقل `is_public` دائمًا `false`، لأن الشخصيات الصوتية التي يتم إنشاؤها عبر رفع الصوت هي خاصة. لاحظ أن `name` المُعاد يتم إنشاؤه تلقائيًا بواسطة النظام، ويُرجى استخدام `persona_id` للإشارة إلى هذه الشخصية الصوتية لاحقًا.

## الخطوة الثانية: استخدام الشخصية الصوتية لتوليد الموسيقى

بعد الحصول على معرّف الشخصية الصوتية، يمكننا استخدام [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) لتوليد الموسيقى. اضبط `action` على `generate`، واضبط `persona_id` على معرّف الشخصية الصوتية المُعاد أعلاه، وستستخدم الأغنية المُولدة الصوت المستنسخ للغناء.

> **ملاحظة:** يدعم استنساخ الصوت نماذج `chirp-v4-5` والإصدارات الأعلى فقط (مثل `chirp-v4-5` و`chirp-v5` و`chirp-v5-5`)، ولا يدعم `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

تكون النتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

يمكن استخدام `persona_id` لتوليد `generate`، ويمكن استخدامه أيضًا للغناء المعاد `cover` / `upload_cover`. لا يلزم تعبئة `vocal_gender` في الوقت نفسه عند تحديد الصوت؛ ولا تزال درجة تشابه الصوت تعتمد على المادة المرجعية ونتيجة التوليد.

الصوت الذي يتم إنشاؤه عبر هذه الواجهة هو مورد خاص. قبل إعادة غناء أغنية موجودة، استدعِ أولًا `/suno/upload`، ومرّر `audio_url` للأغنية الأصلية و`persona_id` لهذا الصوت؛ وبعد نجاح الرفع، استخدم `data.audio_id` المُعاد و`persona_id` نفسه لاستدعاء `/suno/audios`:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

يجب استخدام قناة الخدمة نفسها لإنشاء الصوت ورفع الأغنية الأصلية وإعادة الغناء. يُرجى عدم إعادة استخدام معرّفات الأغاني التي لم تُربط مسبقًا بهذا الصوت الخاص مباشرةً؛ لمزيد من التفاصيل، راجع [رفع الصوت المرجعي في Suno](https://platform.acedata.cloud/documents/suno-upload).
