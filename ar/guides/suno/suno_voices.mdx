---
title: "سنو واجهة برمجة التطبيقات لاستنساخ الصوت"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

تسمح لنا SUNO بإنشاء شخصيات صوتية مخصصة من خلال أي ملف صوتي، مما يتيح استنساخ الصوت لأغراض توليد الموسيقى. على عكس واجهة برمجة التطبيقات Persona الحالية (التي تستخدم `audio_id` الذي تم إنشاؤه بواسطة Suno)، تقبل هذه الواجهة عنوان URL صوتي عام يمكن الوصول إليه، وهو تسجيل صوتك الخاص. توضح هذه الوثيقة كيفية دمج واجهة برمجة التطبيقات لاستنساخ الصوت.

تحتوي هذه الواجهة على ثلاثة معلمات إدخال: `audio_url` (إلزامي)، وهو عنوان URL لملف صوتي بتنسيق MP3 أو WAV يمكن الوصول إليه بشكل عام، يحتوي على صوت إنسان واضح لشخص واحد؛ و`name` و`description` (اختياريان)، وهما اسم ووصف شخصية الصوت.

**متطلبات ملف الصوت:**

- التنسيق: MP3 أو WAV
- المدة: لا تقل عن 10 ثوانٍ
- المحتوى: صوت إنسان واضح لشخص واحد، مع تقليل الضوضاء الخلفية أو الموسيقى قدر الإمكان

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://example.com/my-vocal-recording.mp3",
  "name": "My Voice",
  "description": "A warm male voice"
}'
```

النتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dde0be60-5280-4bd2-89a0-4020ddd3db52",
    "name": "My Voice",
    "is_public": false
  }
}
```

يمكنك أن ترى أن حقل `persona_id` في `data` هو معرف شخصية الصوت التي تم إنشاؤها. حقل `is_public` دائمًا يكون `false`، لأن شخصية الصوت التي تم إنشاؤها من خلال تحميل الصوت خاصة.

بعد الحصول على معرف شخصية الصوت، يمكننا استخدام [واجهة برمجة تطبيقات توليد الصوتيات من سنو](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) لتوليد الموسيقى. قم بتعيين `action` إلى `vox`، وقم بتعيين `persona_id` إلى القيمة التي تم إرجاعها أعلاه، وستستخدم الأغاني الناتجة الصوت المستنسخ في الغناء.
