يسمح SUNO لنا بإنشاء شخصيات صوتية مخصصة عبر أي ملف صوتي، لتحقيق استنساخ الصوت لتوليد الموسيقى. بخلاف Persona API الحالي (الذي يستخدم `audio_id` الذي تم إنشاؤه بواسطة Suno)، يقبل هذا الـ API رابط `audio_url` يمكن الوصول إليه علنًا، أي تسجيلك الصوتي الخاص. يشرح هذا المستند طريقة تكامل API لاستنساخ الصوت.

في مسار الإنشاء الذي يدعم الاستعلام عن توفر الصوت، يمكن استخدام التطبيق الأصلي وهوية المستدعي، وتمرير `persona_id` في نتيجة الإنشاء إلى `POST /suno/availability`. عند اتصال الحساب المرتبط، يتم إرجاع `data.available=true`، وعند تأكيد عدم اتصاله يتم إرجاع `data.available=false`.[دليل الاستعلام عن توفر الصوت](https://platform.acedata.cloud/documents/suno-availability-integration)

## الخطوة الأولى: إنشاء شخصية صوتية

الفوترة: بعد إنشاء الشخصية الصوتية بنجاح، تكون التكلفة القياسية لكل طلب هي **0.15 Credits**. تخضع عروض الاستهلاك المطبقة للفوترة الفعلية، ولا يتم احتساب رسوم للطلبات الفاشلة.

يحتوي هذا الـ API على ثلاث معاملات إدخال: `audio_url` (إلزامي)، وهو رابط ملف صوتي بتنسيق MP3 أو WAV يمكن الوصول إليه علنًا، ويحتوي على صوت بشري واضح لشخص واحد؛ و`name` و`description` (اختياريان)، وهما اسم ووصف الشخصية الصوتية.

> **متطلبات الملف الصوتي**
> - يجب أن يكون تنسيق الصوت `WAV` أو `MP3`
> - يجب أن تتراوح مدة الصوت بين `10~240 ثانية`، ويوصى باستخدام مادة صوتية نظيفة وجافة لشخص واحد لمدة `30~60 ثانية`
> - يجب أن يحتوي الصوت على **صوت واضح ويمكن تمييزه لشخص واحد يتحدث أو يغني**
> - يرجى الحرص على تجنب **ضوضاء الخلفية، والمرافقة الموسيقية، والصدى، والارتداد الصوتي**؛ فالأغاني الكاملة المصحوبة بمرافقة موسيقية عادةً لا تجتاز التحقق من البصمة الصوتية
> - لا تقم بتضمين **متحدثين متعددين** أو**أصوات بشرية متعددة**
> - قد تؤدي المواد ذات مستوى الصوت المنخفض جدًا، أو الكلام غير الواضح، أو الضوضاء الشديدة إلى **فشل الاستنساخ** أو**ضعف نتائج التوليد**
> **توضيح قيود الاستخدام**
> - الشخصيات الصوتية التي يتم إنشاؤها عبر رفع الصوت هي **موارد خاصة**
> - هذه الشخصية الصوتية **لا تدعم إعادة الاستخدام عبر الحسابات**
> - يوصى باستخدامها في أقرب وقت بعد الإنشاء الناجح، وقد تصبح **غير صالحة أو غير متاحة** إذا لم تُستخدم لفترة طويلة
> - يتم إنشاء `name` المُعاد تلقائيًا بواسطة النظام، ويُرجى الاعتماد على `persona_id` المُعاد

> **التعامل مع الفشل وفقًا لعلامة إعادة المحاولة الصريحة**
> إن `retryable` في كائن الخطأ هو حقل منطقي اختياري. عندما تكون `error.retryable` بقيمة `true`، فهذا يعني أن هذا الفشل يسمح بإعادة الطلب لاحقًا باستخدام نفس المادة ونفس المعلمات. قد تحمل حالات انشغال الخدمة التي لم يتم قبولها صراحةً أو بعض حالات فشل التحقق المؤقت من البصمة الصوتية هذه العلامة، ويوصى باستخدام فواصل تراجع والحد من عدد مرات إعادة المحاولة.
> عندما تكون `retryable` بقيمة `false` أو يكون الحقل مفقودًا، لا تُعِد الإرسال تلقائيًا استنادًا فقط إلى HTTP 500 أو `busy` أو نص الخطأ. يجب تصحيح مشكلات التنسيق والمدة والوضوح والتسجيلات المكررة ومراجعة المحتوى أولًا؛ وعند انتهاء مهلة الإرسال، أو انقطاع الاتصال، أو عدم وضوح نتيجة الإنشاء، يجب إعطاء الأولوية للاستعلام عن المهمة باستخدام `task_id` الأصلي، لتجنب إنشاء صوت مكرر. لا يتم احتساب رسوم للطلبات الفاشلة، وتُحتسب رسوم الطلبات التي تنجح بعد إعادة المحاولة وفقًا للقواعد العادية.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> إن `https://cdn.acedata.cloud/suno_demo.mp3` المذكور أعلاه هو مادة نموذجية يمكن استدعاؤها مباشرةً (MP3، 41 ثانية، صوت جاف لشخص واحد).
> إذا كنت بحاجة إلى مثال بتنسيق `WAV`، فيمكنك استخدام
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV، 41 ثانية، أحادي القناة 44.1kHz).

النتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

يمكن ملاحظة أن حقل `persona_id` في `data` هو معرّف الشخصية الصوتية التي تم إنشاؤها. يكون حقل `is_public` دائمًا `false`، لأن الشخصيات الصوتية التي يتم إنشاؤها عبر رفع الصوت خاصة. لاحظ أن `name` المُعاد يتم إنشاؤه تلقائيًا بواسطة النظام، ويرجى استخدام `persona_id` للإشارة إلى هذه الشخصية الصوتية لاحقًا.

## الخطوة الثانية: استخدام الشخصية الصوتية لتوليد الموسيقى

بعد الحصول على معرّف الشخصية الصوتية، يمكننا استخدام [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) لتوليد الموسيقى. اضبط `action` على `generate`، واضبط `persona_id` على معرّف الشخصية الصوتية المُعاد أعلاه، وستستخدم الأغنية المُولدة الصوت المستنسخ للغناء.

> **ملاحظة:** يدعم استنساخ الصوت نماذج `chirp-v4-5` وما فوق فقط (مثل `chirp-v4-5` و`chirp-v5` و`chirp-v5-5`)، ولا يدعم `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

النتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

يمكن استخدام `persona_id` للتوليد عبر `generate`، ويمكن أيضًا استخدامه للغناء المعاد عبر `cover` / `upload_cover`. لا يلزم ملء `vocal_gender` في الوقت نفسه عند تحديد الصوت؛ ولا يزال تشابه الصوت يعتمد على المادة المرجعية ونتيجة التوليد.

الأصوات التي يتم إنشاؤها عبر هذه الواجهة هي موارد خاصة. قبل إعادة غناء أغنية موجودة، استدعِ `/suno/upload` أولًا، ومرّر `audio_url` للأغنية الأصلية و`persona_id` لهذا الصوت؛ وبعد نجاح الرفع، استخدم `data.audio_id` المُعاد و`persona_id` نفسه لاستدعاء `/suno/audios`:
```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

يجب استخدام نفس قناة الخدمة لإنشاء الصوت، ورفع الأغنية الأصلية، وإعادة الغناء. يُرجى عدم إعادة استخدام معرّف أغنية سابق غير مرتبط بهذا الصوت الخاص مباشرةً؛ راجع التفاصيل في [Suno رفع الصوت المرجعي](https://platform.acedata.cloud/documents/suno-upload).
