يسمح لنا SUNO بإنشاء شخصيات صوتية مخصصة من خلال أي ملف صوتي، مما يحقق استنساخ الصوت لتوليد الموسيقى. على عكس API Persona الموجود (الذي يستخدم `audio_id` الذي تم إنشاؤه بواسطة Suno)، يقبل هذا API عنوان URL صوتي عام يمكن الوصول إليه، أي تسجيل صوتك الخاص. تشرح هذه الوثيقة كيفية توصيل API استنساخ الصوت.

## الخطوة الأولى: إنشاء شخصية صوتية

يحتوي هذا API على ثلاثة معلمات إدخال: `audio_url` (إلزامي)، وهو عنوان URL لملف صوتي بتنسيق MP3 أو WAV يمكن الوصول إليه بشكل عام، ويحتوي على صوت شخص واحد واضح؛ و`name` و`description` (اختياري)، وهما اسم ووصف الشخصية الصوتية.

> **متطلبات ملف الصوت**
> - يجب أن يكون تنسيق الصوت `WAV` أو `MP3`
> - يجب أن تكون مدة الصوت لا تقل عن `10 ثوانٍ`، يُوصى باستخدام مواد صوتية نظيفة تتراوح بين `30~60 ثانية`
> - يجب أن يحتوي الصوت على **حديث أو غناء واضح وقابل للتعرف عليه من شخص واحد**
> - يُرجى تجنب **الضوضاء الخلفية، والموسيقى المصاحبة، والصدى، والارتداد**
> - لا يجب أن يحتوي على **أكثر من متحدث واحد** أو **أصوات متعددة**
> - قد تؤدي المواد ذات الصوت المنخفض جدًا، أو الكلام غير الواضح، أو الضوضاء الزائدة إلى **فشل الاستنساخ** أو **نتائج ضعيفة**
> **ملاحظات حول قيود الاستخدام**
> - الشخصية الصوتية التي تم إنشاؤها عن طريق تحميل الصوت هي **موارد خاصة**
> - هذه الشخصية الصوتية **لا تدعم إعادة الاستخدام عبر الحسابات**
> - يُنصح باستخدامها في أقرب وقت ممكن بعد إنشائها، حيث قد يحدث **انتهاء صلاحية أو عدم توفر** بعد فترة طويلة من عدم الاستخدام

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "http://cos.aitutu.cc/mp4/ru-user-voice.mp3",
  "name": "RU User Voice Test",
  "description": "مثال على تسجيل صوت المستخدم"
}'
```

النتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "b9150e51-d87c-4556-a55e-100947a63bdf",
  "data": {
    "persona_id": "e95013f8-eaee-4741-a42f-1d559a9d0b2b",
    "name": "RU User Voice Test",
    "is_public": false
  }
}
```

يمكنك أن ترى أن حقل `persona_id` في `data` هو معرف الشخصية الصوتية التي تم إنشاؤها. يظل حقل `is_public` دائمًا `false`، لأن الشخصية الصوتية التي تم إنشاؤها عن طريق تحميل الصوت هي خاصة.

## الخطوة الثانية: استخدام الشخصية الصوتية لتوليد الموسيقى

بعد الحصول على معرف الشخصية الصوتية، يمكننا استخدام [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) لتوليد الموسيقى. قم بتعيين `action` إلى `generate`، وقم بتعيين `persona_id` إلى معرف الشخصية الصوتية الذي تم إرجاعه أعلاه، وستستخدم الأغاني المولدة الصوت المستنسخ في الغناء.

> **ملاحظة:** يدعم استنساخ الصوت فقط النماذج `chirp-v4-5` وما فوق (مثل `chirp-v4-5`، `chirp-v5`، `chirp-v5-5`)، ولا يدعم `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "أغنية دافئة من نوع الساينث-بوب عن ليالي المدينة",
  "persona_id": "e95013f8-eaee-4741-a42f-1d559a9d0b2b"
}'
```

النتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn1.suno.ai/16463960-077c-4700-bbb3-3c7897b943d3.mp3",
      "image_url": "https://cdn2.suno.ai/image_16463960-077c-4700-bbb3-3c7897b943d3.jpeg",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "أغنية دافئة من نوع الساينث-بوب عن ليالي المدينة",
      "duration": 156.28
    }
  ]
}
```

يمكنك أن ترى أن الأغنية المولدة استخدمت الصوت المستنسخ في الغناء. يمكن أيضًا استخدام `persona_id` مع إجراء `cover` لعمل إعادة غناء للأغاني الموجودة باستخدام الصوت المستنسخ.
