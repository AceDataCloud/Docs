`POST https://api.acedata.cloud/suno/projects` هي واجهة Beta لإدارة المشاريع متعددة المسارات. يتم التمييز بين الإنشاء والحفظ وتوليد المرشحات وتقديم المرشحات والتصدير عبر `action`.

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Idempotency-Key: <每次写操作的新 UUID>
```

باستثناء `retrieve`، **كل عملية تتطلب** `Idempotency-Key`. المفتاح نفسه مع الطلب نفسه يعيد فقط النتيجة الأصلية؛ والمفتاح نفسه مع طلب مختلف يعيد 409. عند مواجهة مهلة شبكة أو عدم تأكد من نتيجة الإرسال أثناء التوليد المدفوع، استعلم أولًا باستخدام معرّف المهمة الأصلي أو مفتاح عدم التكرار نفسه، ولا تغيّر المفتاح وتعيد الإرسال مباشرة.

## المعرّفات ووحدات الوقت

| الاسم                             | من أين يتم الحصول عليه                                                                                      | أين يُستخدم                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| `id`                           | استجابة `create` ضمن `data.id`                                                                      | جميع الطلبات اللاحقة للمشروع الحالي                                      |
| `version_id`                   | `data.version_id` من أحدث عملية `retrieve` أو `save` أو `add_track` أو `commit_candidate` أو `remove_track` | التعديل وتوليد المرشحات والتصدير؛ يجب استخدام أحدث إصدار                              |
| `audio_id` / `source_audio_id` | `response.data.candidate.audio_id` في الحالة النهائية لـ `upload`، أو معرّف صوت مكتمل موجود مسبقًا                                | الإشارة إلى الصوت الأصلي عند `add_track` أو التوليد أو الاستبدال                          |
| `render_audio_id`              | `response.data.audio_id` في الحالة النهائية لـ `render`                                                       | مرجع مزيج المشروع لـ `generate_track`                         |
| `operation_id`                 | `response.data.operation_id` في الحالة النهائية لـ `generate_track` أو `replace_section`                       | `commit_candidate`؛ يكون عادةً مماثلًا لـ `task_id` لمهمة التوليد، لكن يجب قراءة القيمة المُعادة |
| `candidate_id`                 | `response.data.candidates[].id` في الحالة النهائية للتوليد                                                       | اختيار مرشح لتقديمه                                         |
| `track_id`                     | `data.state.tracks[].id` للمشروع                                                                | تقديم مرشح أو حذف مسار                                        |
| `task_id`                      | استجابة إرسال العملية غير المتزامنة                                                                                   | استخدام `/suno/tasks` للاستعلام عن الحالة النهائية؛ وهو ليس معرّف المشروع                   |

`start_seconds` / `end_seconds` هي **ثوانٍ ضمن الصوت المصدر**؛ و`start_beats` / `end_beats` هي **عدد النبضات على المخطط الزمني للمشروع**. `state.timing.bps` هو عدد النبضات في الثانية، والقيمة الافتراضية هي 2. على سبيل المثال، مقطع مدته 41 ثانية يبدأ من النبضة 0، تكون نقطة نهايته الافتراضية النبضة 82. يُستخدم نطاق الثواني في `generate_track` لتحديد مرجع التوليد، ولا يضمن أن يكون طول المرشح هو هذا النطاق فقط.

## سير العمليات

| الترتيب  | `action`                             | الوظيفة                         | طريقة الإرجاع         |
| --- | ------------------------------------ | -------------------------- | ------------ |
| 1   | `create`                             | إنشاء مشروع فارغ                      | بيانات مشروع متزامنة       |
| 2   | `retrieve`                           | قراءة أحدث إصدار و`state` الكامل          | بيانات مشروع متزامنة       |
| 3   | `save`                               | الحفظ الأول أو حفظ `state` المعدّل بالكامل      | بيانات مشروع متزامنة       |
| 4   | `upload`                             | إنشاء مادة من عنوان صوت HTTPS           | مهمة غير متزامنة         |
| 5   | `add_track`                          | وضع صوت المادة في المشروع                  | مهمة غير متزامنة، وتحديث الإصدار    |
| 6   | `save`                               | إذا كان يلزم استقبال مرشحات لمسار جديد، احفظ أولًا مسارًا مستهدفًا فارغًا        | بيانات مشروع متزامنة، وتحديث الإصدار  |
| 7   | `render`                             | تصدير المسارات القابلة للاستماع حاليًا، والحصول على مرجع المزيج `audio_id` | مهمة غير متزامنة         |
| 8   | `generate_track` أو `replace_section` | توليد مرشح لمسار جديد أو مرشح استبدال جزئي على التوالي            | مهمة غير متزامنة، لا تعدّل المشروع مؤقتًا  |
| 9   | `commit_candidate`                   | اختيار مرشح وتقديمه                  | مهمة غير متزامنة، وتحديث الإصدار بعد النجاح |
| اختياري  | `remove_track`                       | حذف المسار المحدد                     | بيانات مشروع متزامنة، وتحديث الإصدار  |

إذا كان المطلوب استبدالًا جزئيًا فقط، فيكفي وجود صوت مصدر قابل للاستخدام، ولا حاجة إلى `render` أولًا؛ وإذا كان صوت المصدر موجودًا بالفعل في المشروع، يمكن أيضًا تجاوز `upload` و`add_track`. إن `render_audio_id` هو مرجع إلزامي فقط لـ `generate_track`.

عند إرسال عملية غير متزامنة، يتم إرجاع `{ "task_id": "...", "trace_id": "..." }` أولًا، وهذا **لا يعني نجاح التوليد**. الاستعلام الدوري:

```http
POST /suno/tasks
Content-Type: application/json

{"action":"retrieve","id":"上一步返回的 task_id"}
```

لا تُعد العملية ناجحة إلا إذا كان لسجل المهمة `finished_at`، وكانت قيمة `response.success` فيه `true`؛ وعندما تكون `response.success=false`، اقرأ `response.error`. رغم أن `save` قد يحتوي على `task_id`، فإنه يكتمل بشكل متزامن ضمن هذه الواجهة. لا تعدّل `upload` و`render` و`generate_track` و`replace_section` إصدار المشروع؛ وبعد نجاح `save` و`add_track` و`commit_candidate` و`remove_track` يجب أخذ `version_id` الجديد.

## اتفاقيات الطلبات

| المعامل                | النوع والنطاق                                                                                   | الوصف                                                              |
| ----------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `action`          | سلسلة نصية مطلوبة                                                                                     | ثابت على أحد أسماء العمليات المذكورة في هذه الصفحة؛ ينفّذ طلب واحد عملية واحدة فقط.                                      |
| `id`              | سلسلة نصية مطلوبة باستثناء `create`                                                                         | معرّف المشروع، من `create.data.id`.                                      |
| `version_id`      | سلسلة نصية مطلوبة عند التعديل أو توليد المرشحات أو التصدير؛ يمكن إهمالها عند أول `save` لمشروع فارغ                                                         | استخدم أحدث إصدار، وسيتم رفض الإصدار القديم. لا تحتاج `retrieve` إليه.                                 |
| `Idempotency-Key` | ترويسة طلب مطلوبة باستثناء `retrieve`، من 1 إلى 128 حرفًا                                                              | استخدم مفتاحًا جديدًا لكل عملية جديدة؛ المفتاح نفسه مع الطلب نفسه يعيد النتيجة الأصلية دون توليد أو احتساب رسوم مجددًا.                                   |
| `async`           | قيمة منطقية اختيارية لـ `upload` و`add_track` و`generate_track` و`replace_section` و`commit_candidate` و`render` | هذه العمليات غير متزامنة دائمًا؛ ولن يحوّل `false` التوليد إلى عملية متزامنة.                                    |
| `callback_url`    | عنوان URL اختياري للعمليات غير المتزامنة                                                                                | يستقبل إشعارات الحالة النهائية؛ عند حذفه، استعلم عن `/suno/tasks` باستخدام `task_id`. ولا يزال يجب التحقق من `response.success`. |

توضح الأمثلة التالية بصورة مترابطة تمرير المعرّفات والإصدارات بين العمليات. لا تسرد الاستجابات سوى الحقول المرتبطة بالخطوة الحالية؛ عند التكامل، استبدل معرّفات الأمثلة بقيم الاستجابة من تطبيقك الحالي.

## حفظ حالة المشروع

| المعلمة | النوع والوصف |
|---|---|
| `state` | كائن مطلوب. أرسل **حالة المشروع الكاملة**، وليس تصحيحًا جزئيًا؛ استند إلى `data.state` الذي أعادته أحدث عملية قراءة أو تعديل، واحتفظ بالحقول غير المعروفة. |
| `title` | سلسلة اختيارية؛ عند الحذف، يتم استخدام `state.title`، وإذا لم يوجد أيضًا فتُستخدم العنوان الافتراضي. |
| `version_id` | يمكن حذفه عند الحفظ الأول لمشروع فارغ جديد؛ بعد ذلك يجب استخدام أحدث إصدار. |

يجب أن يكون `state.timing.bps` رقمًا موجبًا، والقيمة الافتراضية هي 2. `state.tracks` هي مصفوفة المسارات؛ يشير `clipId` في مقاطع الصوت الموجودة إلى معرّف الصوت، ويستخدم `startBeats` و`endBeats` و`readStartBeats` وحدة نبضات المشروع. أكثر طرق التحرير أمانًا هي قراءة `state` الكامل، وتعديل المسار أو المقطع المستهدف فقط، ثم إجراء `save` بشكل كامل. يجب أن يحتوي المسار الهدف الفارغ الجديد على الأقل على `id` فريد و`type:"audio"` و`clips:[]`؛ راجع المثال في «إنشاء مسار صوتي جديد» لبنية المسار الفارغ الكاملة. لا تستخدم نقاط الإيقاع في نتائج تحليل الصوت مباشرةً كإحداثيات للخط الزمني للمشروع.

## رفع الصوت وإضافة مسار

| العملية | المعلمة | النوع والوصف |
|---|---|---|
| `upload` | `audio_url` | عنوان URL إلزامي عبر HTTPS، يشير إلى صوت متاح للعامة ولديك الحق في استخدامه. يمكن استخدام `candidate.audio_id` في الحالة النهائية لإضافة مسار. |
| `add_track` | `audio_id` | سلسلة إلزامية؛ معرّف الصوت للمادة المكتملة، وليس عنوان URL. |
| `add_track` | `name`، `color` | سلسلتان اختياريتان؛ يأخذ اسم المسار افتراضيًا عنوان الصوت، ويُوصى بأن يكون اللون `#RRGGBB`، والقيمة الافتراضية هي `#7251F7`. |
| `add_track` | `title` | سلسلة اختيارية؛ تعدّل عنوان المشروع في الوقت نفسه، وعادةً تُحذف. |
| `add_track` | `start_beats`، `end_beats` | أرقام غير سالبة اختيارية، ويجب أن تكون النهاية أكبر من البداية؛ يبدأ افتراضيًا من النبضة 0، وتُحسب النهاية وفقًا لمدة الصوت و`timing.bps`. |
| `add_track` | `gain` | رقم غير سالب اختياري، والقيمة الافتراضية هي 1؛ معامل مستوى الصوت للمقطع والمسار. |

## إنشاء مسار صوتي جديد

ترتبط المرشحات وإصدار المشروع وقت الإنشاء. احفظ أولًا مسارًا فارغًا لتلقي المرشحات، ثم صدّر المزيج الحالي كمرجع للإنشاء؛ بعد اكتمال الإنشاء، اختر مرشحًا واحدًا لإرساله إلى ذلك المسار الفارغ.

### حجز المسار الهدف: `save`

ترتبط مرشحات `generate_track` بإصدار المشروع الحالي. أضف المسار الفارغ التالي إلى `state.tracks` في `state` **الكامل** الذي أعادته الحالة النهائية السابقة لـ `add_track`، ثم احفظه باستخدام `save`؛ واحتفظ بالحقول الموجودة الأخرى كما هي:
```
&#123;
"id": "bdec15b5-ce96-43fa-b681-26298e013b06",
"type": "audio",
"name": "بيانو مُولَّد",
"clips": [],
"takeLanes": [],
"mute": false,
"solo": false,
"amplitude": 1,
"instrument": &#123;
"type": "song"
&#125;,
"color": "#7251F7"
&#125;

```

### تصدير مزيج مرجعي: `render`

| المعلمة | النوع والوصف |
|---|---|
| `title` | سلسلة نصية مطلوبة؛ عنوان الصوت المُصدَّر. |
| `lyrics`، `tags` | سلاسل نصية اختيارية؛ كلمات الأغنية الافتراضية هي `[Instrumental]`، و`tags` هي وصف للنمط. |
| `start_beats`، `end_beats` | أرقام غير سالبة اختيارية، ويجب أن تكون النهاية أكبر من البداية؛ عند الحذف تغطي جميع المقاطع المسموعة. لا تشارك المقاطع المكتومة؛ وعند وجود مسارات `solo`، يتم اختيار مسارات `solo` فقط. |

| `project_version_conflict` / `project_candidate_stale`(409) | تغير إصدار المشروع، أو أن المرشح لا ينتمي إلى الإصدار الحالي. | `retrieve` أحدث المشروع وأعد تخطيط التعديلات؛ لا تُعِد تشغيل المرشحين القدامى. |
| `bad_request` / `studio_state_invalid` / `studio_model_unsupported` (عادةً 400) | المعلمات أو حالة المقطع أو مدة المرشح أو النموذج لا تتوافق مع العملية. | راجع خطأ الحالة النهائية للمهمة وصحح الإدخال؛ احتفظ بالمشروع الأصلي عندما لا يمكن دمج المرشحين بأمان. |
| `studio_audio_unavailable` / `studio_access_denied` / `content_rejected`(403) | الصوت المرجعي غير متاح لعملية المشروع هذه، أو لا تملك صلاحية الوصول إليه، أو تم رفضه بسبب فحص المحتوى. | تحقق من مصدر الصوت والمهمة `trace_id`؛ لا تساوِ بين المرشحين الذين تم إنشاؤهم وإمكانية تصدير الأغنية كاملة. |
| `too_many_requests`(429) | الطلب مقيّد بمعدل الطلبات. | استعلم عن المهمة الأصلية أولاً، ثم قرر ما إذا كنت ستبدأ عملية جديدة بمفتاح عدم تكرار جديد. |
| `studio_unavailable` / `studio_model_unavailable`(503) | معالجة المشروع أو النموذج المحدد غير متاح مؤقتًا. | احتفظ بنتيجة المهمة الأصلية؛ أعد المحاولة صراحةً لاحقًا، ولا تبدّل النموذج تلقائيًا. |
| `studio_processing_failed` / انتهاء المهلة (500/504) | فشلت المعالجة أو أن الحالة النهائية غير مؤكدة. | استعلم باستخدام `task_id` أو مفتاح عدم التكرار الأصلي لتجنب إنشاءات مكررة تُحتسب رسومها. |

يرتبط المشروع والمرشحون بالتطبيق الذي أنشأهم؛ يُرجى استخدام التطبيق الأصلي للوصول إليهم. احفظ بشكل دائم عنوان URL النهائي للصوت الذي تم تصديره بنجاح، واحتفظ بـ `trace_id` لتسهيل استكشاف الأخطاء وإصلاحها.
