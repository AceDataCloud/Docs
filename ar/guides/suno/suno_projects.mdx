`POST https://api.acedata.cloud/suno/projects` هي واجهة Beta لإدارة المشاريع متعددة المسارات. يميز طرف واحد بين الإنشاء والحفظ وتوليد المرشحين وتقديم المرشحين والتصدير عبر `action`. يحتاج المستدعي فقط إلى استخدام الحقول العامة أدناه، ولا يحتاج إلى تعبئة بنية الطلب الداخلية لخدمة التوليد الأساسية.

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Idempotency-Key: استخدم UUID جديدًا لكل عملية تعديل
```

باستثناء `retrieve`، **تتطلب كل عملية** `Idempotency-Key`. يعيد المفتاح نفسه والطلب نفسه قراءة النتيجة الأصلية فقط؛ ويؤدي المفتاح نفسه مع طلب مختلف إلى إرجاع 409. عند مواجهة انتهاء مهلة الشبكة أو عدم التأكد من نتيجة الإرسال في عمليات التوليد المدفوعة، استعلم أولًا باستخدام معرّف المهمة الأصلي أو مفتاح عدم التكرار نفسه، ولا تغيّر المفتاح وترسل الطلب مجددًا مباشرةً.

## ميّز أولًا بين هذه المعرّفات ووحدات الوقت

| الاسم                             | من أين يُحصل عليه                                                                                      | أين يُستخدم                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| `id`                           | استجابة `create` ‏`data.id`                                                                      | جميع الطلبات اللاحقة للمشروع الحالي                                      |
| `version_id`                   | `data.version_id` من أحدث `retrieve` أو `save` أو `add_track` أو `commit_candidate` أو `remove_track` | التعديل وتوليد المرشحين والتصدير؛ يجب استخدام أحدث إصدار                              |
| `audio_id` / `source_audio_id` | `response.data.candidate.audio_id` في الحالة النهائية لـ `upload`، أو معرّف صوت مكتمل موجود مسبقًا                                | الإشارة إلى الصوت الأصلي عند `add_track` أو التوليد أو الاستبدال                          |
| `render_audio_id`              | `response.data.audio_id` في الحالة النهائية لـ `render`                                                       | مرجع مزيج المشروع لـ `generate_track`                         |
| `operation_id`                 | `response.data.operation_id` في الحالة النهائية لـ `generate_track` أو `replace_section`                       | `commit_candidate`؛ يكون عادةً مطابقًا لـ `task_id` لمهمة التوليد، لكن يجب قراءة القيمة المُعادة |
| `candidate_id`                 | `response.data.candidates[].id` في الحالة النهائية للتوليد                                                       | اختيار مرشح لتقديمه                                         |
| `track_id`                     | `data.state.tracks[].id` للمشروع                                                                | تقديم مرشح أو حذف مسار                                        |
| `task_id`                      | استجابة إرسال العملية غير المتزامنة                                                                                   | استخدام `/suno/tasks` للاستعلام عن الحالة النهائية؛ وهو ليس معرّف المشروع                   |

`start_seconds` / `end_seconds` هي **الثواني داخل الصوت المصدر**؛ و`start_beats` / `end_beats` هي **عدد النبضات على الخط الزمني للمشروع**. `state.timing.bps` هو عدد النبضات في الثانية، والقيمة الافتراضية هي 2. على سبيل المثال، مقطع مدته 41 ثانية يبدأ من النبضة 0، تكون نهايته الافتراضية عند النبضة 82. يُستخدم نطاق الثواني في `generate_track` لتحديد مرجع التوليد، ولا يضمن أن يكون طول المرشح ضمن ذلك النطاق فقط.

## ترتيب العمليات وتحديد النتائج

| الترتيب  | `action`                             | الوظيفة                         | طريقة الإرجاع         |
| --- | ------------------------------------ | -------------------------- | ------------ |
| 1   | `create`                             | إنشاء مشروع فارغ                      | بيانات مشروع متزامنة       |
| 2   | `retrieve`                           | قراءة أحدث إصدار و`state` الكامل          | بيانات مشروع متزامنة       |
| 3   | `save`                               | الحفظ الأول أو الحفظ الكلي لـ `state` المعدّل      | بيانات مشروع متزامنة       |
| 4   | `upload`                             | إنشاء مادة من عنوان صوت HTTPS           | مهمة غير متزامنة         |
| 5   | `add_track`                          | وضع صوت المادة في المشروع                  | مهمة غير متزامنة، وتحديث الإصدار    |
| 6   | `save`                               | إذا كان يلزم استقبال مرشح لمسار جديد، فاحفظ أولًا مسار هدف فارغًا        | بيانات مشروع متزامنة، وتحديث الإصدار  |
| 7   | `render`                             | تصدير المسارات القابلة للاستماع حاليًا، والحصول على مرجع المزيج `audio_id` | مهمة غير متزامنة         |
| 8   | `generate_track` أو `replace_section` | توليد مرشح لمسار جديد أو مرشح استبدال جزئي على التوالي            | مهمة غير متزامنة، لا تعدّل المشروع مؤقتًا  |
| 9   | `commit_candidate`                   | اختيار مرشح وتقديمه                  | مهمة غير متزامنة، وتحديث الإصدار بعد النجاح |
| اختياري  | `remove_track`                       | حذف المسار المحدد                     | بيانات مشروع متزامنة، وتحديث الإصدار  |

إذا كان المطلوب استبدالًا جزئيًا فقط، فيكفي وجود صوت مصدر متاح، ولا حاجة إلى `render` أولًا؛ وإذا كان الصوت المصدر موجودًا بالفعل في المشروع، فيمكن أيضًا تجاوز `upload` و`add_track`. إن `render_audio_id` هو مرجع إلزامي لـ `generate_track` فقط.

عند إرسال عملية غير متزامنة، يتم إرجاع `{ "task_id": "...", "trace_id": "..." }` أولًا، وهذا **لا يعني نجاح التوليد**. الاستعلام الدوري:

```http
POST /suno/tasks
Content-Type: application/json

{"action":"retrieve","id":"معرّف task_id المُعاد في الخطوة السابقة"}
```

لا تُعد المهمة ناجحة إلا عند وجود `finished_at` في سجل المهمة، وكون `response.success` فيها يساوي `true`؛ وعندما يكون `response.success=false`، اقرأ `response.error`. رغم أن `save` قد يتضمن `task_id`، فإنه يكتمل بشكل متزامن ضمن هذه الواجهة. لا تعدّل `upload` و`render` و`generate_track` و`replace_section` إصدار المشروع؛ وبعد نجاح `save` و`add_track` و`commit_candidate` و`remove_track` يجب أخذ `version_id` الجديد.

## معلمات الطلب

### الحقول العامة ورؤوس الطلب

| المعلمة                | النوع والنطاق المنطبق                                                                                   | الوصف                                                              |
| ----------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `action`          | سلسلة نصية مطلوبة                                                                                     | ثابتة كأحد أسماء العمليات المذكورة في هذه الصفحة؛ ينفّذ كل طلب عملية واحدة فقط.                                      |
| `id`              | سلسلة نصية مطلوبة باستثناء `create`                                                                         | معرّف المشروع، من `create.data.id`.                                      |
| `version_id`      | سلسلة نصية مطلوبة عند التعديل أو توليد المرشحين أو التصدير؛ ويمكن إهمالها في أول `save` لمشروع فارغ                                                         | استخدم أحدث إصدار، وسيُرفض الإصدار القديم. لا يحتاجها `retrieve`.                                 |
| `Idempotency-Key` | رأس طلب مطلوب باستثناء `retrieve`، من 1 إلى 128 حرفًا                                                              | استخدم مفتاحًا جديدًا لكل عملية جديدة؛ يعيد المفتاح نفسه والطلب نفسه قراءة النتيجة الأصلية، دون إعادة توليد أو خصم رسوم.                                   |
| `async`           | قيمة منطقية اختيارية لـ `upload` و`add_track` و`generate_track` و`replace_section` و`commit_candidate` و`render` | هذه العمليات تكون دائمًا غير متزامنة؛ حتى `false` لن يحوّل التوليد إلى متزامن.                                    |
| `callback_url`    | عنوان URL اختياري للعمليات التي تتضمن حقلًا غير متزامن اختياريًا أعلاه                                                                       | يستقبل إشعار الحالة النهائية؛ وعند إهماله، استعلم عن `/suno/tasks` باستخدام `task_id`. لا يزال يجب التحقق من `response.success`. |

### المشروع والمواد
| `action`       | المعلمات الخاصة                 | النوع والشروط                           | الوصف                                                               |
| -------------- | --------------------------- | -------------------------------- | ------------------------------------------------------------------ |
| `create`       | `title`                     | سلسلة نصية مطلوبة، من 1 إلى 200 حرف         | عنوان المشروع الجديد.                                                    |
| `retrieve`     | لا يوجد                       | —                                | لا يتطلب سوى `action` و`id` المشروع؛ ويُرجع `state` كاملاً قابلاً للتحرير.          |
| `save`         | `state`                     | كائن مطلوب                             | **استبدال كامل** لحالة المشروع، وليس تصحيحاً جزئياً. عدّل استناداً إلى أحدث `retrieve.data.state` وقدّمه كاملاً، مع الاحتفاظ بالحقول غير المعروفة. |
| `save`         | `title`                     | سلسلة نصية اختيارية                       | عنوان المشروع؛ عند حذفه يُستخدم `state.title`، وإن لم يوجد أيضاً فيُستخدم العنوان الافتراضي.         |
| `upload`       | `audio_url`                 | رابط HTTPS مطلوب                      | عنوان مادة صوتية يمكن الوصول إليها علناً؛ بعد النجاح اقرأ الحالة النهائية `candidate.audio_id`. يجب أن يمتلك المستدعي حق استخدام المادة. |
| `add_track`    | `audio_id`                  | سلسلة نصية مطلوبة                           | معرّف صوت لمادة مكتملة، وليس رابط URL.                                        |
| `add_track`    | `name` / `color`            | سلسلة نصية اختيارية                           | اسم ولون المسار الجديد؛ يأخذ الاسم افتراضياً عنوان الصوت، ويُقترح للون `#RRGGBB`، والقيمة الافتراضية هي `#7251F7`. |
| `add_track`    | `title`                     | سلسلة نصية اختيارية                           | تعديل عنوان المشروع في الوقت نفسه؛ يُحذف عادةً.                                     |
| `add_track`    | `start_beats` / `end_beats` | أرقام اختيارية غير سالبة، `end_beats > start_beats` | موضع المقطع في الخط الزمني للمشروع. نقطة البداية الافتراضية 0؛ ونقطة النهاية الافتراضية `نقطة البداية + مدة الصوت × timing.bps`. |
| `add_track`    | `gain`                      | رقم اختياري غير سالب، الافتراضي 1                    | معامل مستوى الصوت للمقطع والمسار الجديد.                                           |
| `remove_track` | `track_id`                  | سلسلة نصية مطلوبة                            | معرّف المسار الحالي المراد حذفه. استخدم الإصدار الجديد المُعاد بعد النجاح.                         |

يجب أن يكون `state.timing.bps` رقماً موجباً، والقيمة الافتراضية هي 2. `state.tracks` هي مصفوفة المسارات؛ يشير `clipId` للمقاطع الصوتية الموجودة إلى معرّف الصوت، وتستخدم `startBeats` و`endBeats` و`readStartBeats` وحدة النبضات الخاصة بالمشروع. إن أكثر طرق التحرير أماناً هي قراءة `state` كاملاً، وتعديل المسار أو المقطع المستهدف فقط، ثم إجراء `save` كامل. يجب أن يحتوي المسار الهدف الفارغ الجديد على الأقل على `id` فريد و`type:"audio"` و`clips:[]`؛ راجع الشكل الكامل القابل للاستخدام فعلياً في الخطوة 5 أدناه. لا تستخدم نقاط النبض من نتائج تحليل الصوت مباشرةً كإحداثيات للخط الزمني للمشروع.

### الإنشاء، والإرسال، والتصدير
| `action`                             | المعلمات الخاصة                               | النوع والشروط                                  | الوصف                                                                                                                                                        |
| ------------------------------------ | ---------------------------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `generate_track` / `replace_section` | `source_audio_id`                  | سلسلة نصية مطلوبة                                  | معرّف الصوت المصدر المكتمل. أضف الصوت المصدر إلى المشروع أولاً، حتى تتمكن الخيارات اللاحقة من العثور على الموضع المقابل.                                                                                                                        |

| `generate_track` / `replace_section` | `start_seconds` / `end_seconds`    | أرقام مطلوبة، `0 ≤ start_seconds &lt; end_seconds` | ثواني البداية والنهاية داخل الصوت المصدر؛ عند الاستبدال، يجب أيضاً ألا تتجاوز نقطة النهاية المدة الفعلية للصوت المصدر. ليست هذه نبضات المشروع، ولا تضمن مدة إخراج الخيار.                                                                                                         |
| `generate_track`                     | `render_audio_id`                  | سلسلة نصية مطلوبة                                  | قيمة `response.data.audio_id` بعد نجاح `render` للمشروع الحالي، وتُستخدم كمرجع للمزج عند التوليد.                                                                                                   |
| `generate_track`                     | `stem_control_tags`                | سلسلة نصية مطلوبة                                  | وصف للمسار الصوتي الجديد، مثل `add Piano` أو `add Drums` أو `add Bass`؛ وليست تعداداً ثابتاً.                                                                                                      |
| `generate_track`                     | `batch_size`                       | عدد صحيح اختياري 1–4، الافتراضي 2                          | عدد الخيارات المطلوب توليدها.                                                                                                                                                |
| `generate_track`                     | `instrumental` / `vocal_gender`    | قيمة منطقية اختيارية／سلسلة نصية تعداد                            | القيمة الافتراضية لـ `instrumental` هي `true`؛ ويمكن ملء تفضيل الصوت الغنائي بـ `f` أو `m` أو `unspecified`، والقيمة الافتراضية هي `unspecified`. يعتمد الالتزام بالتفضيل على الصوت الفعلي.                                                                     |
| `generate_track` / `replace_section` | `title` / `tags` / `negative_tags` | سلسلة نصية اختيارية                                  | عنوان الخيار، ووصف النمط المطلوب، وعلامات النمط المراد تجنبها. عند حذف `tags` و`negative_tags`، مرّر سلسلتين فارغتين.                                                                                                  |
| `generate_track`                     | `prompt`                           | سلسلة نصية اختيارية                                  | تلميح نصي أو كلمات غنائية للمسار الصوتي الجديد؛ يمكن حذفه للموسيقى الآلية الخالصة.                                                                                                                                       |
| `replace_section`                    | `prompt` / `replacement_lyrics`    | سلسلة نصية اختيارية                                  | الأول هو كلمات الأغنية الأصلية أو النص السياقي، والثاني هو الكلمات الجديدة لمنطقة الاستبدال؛ عند الحذف مرّر سلسلتين فارغتين.                                                                                                                      |
| `replace_section`                    | `fixed`                            | قيمة منطقية اختيارية، الافتراضي `false`                       | طلب استبدال بطول ثابت؛ عندما تكون `true` يجب أن تكون المنطقة أقصر من 26 ثانية، وقد لا يدعمها النموذج المحدد. يستخدم المثال الحقيقي هذه المرة الوضع الافتراضي، ولم يتم التحقق من `fixed=true` بعد.                                                                                    |
| `commit_candidate`                   | `operation_id` / `candidate_id`    | سلسلة نصية مطلوبة                                  | تُؤخذ على التوالي من `data.operation_id` في الحالة النهائية للتوليد و`data.candidates[].id` المحدد؛ يجب أن ينتمي الخيار إلى إصدار المشروع الحالي.                                                                                    |
| `commit_candidate`                   | `track_id`                         | سلسلة نصية مطلوبة                                  | يجب إرسال خيار المسار الجديد إلى **مسار فارغ محفوظ قبل التوليد**؛ ويُرسل خيار الاستبدال الجزئي إلى المسار الأصلي الذي يحتوي على المقطع المصدر الوحيد.                                                                                                              |
| `commit_candidate`                   | `start_beats` / `end_beats`        | أرقام غير سالبة اختيارية لخيار المسار الجديد فقط                           | تحدد موضع المقطع الجديد في المخطط الزمني للمشروع؛ عند الحذف، تُستخدم نقطة بداية المقطع المصدر، وتُحسب نقطة النهاية وفقاً للمدة الفعلية للخيار. يجب ألا تتداخل مع المقاطع الموجودة في المسار الهدف. **يجب حذفها لخيار الاستبدال الجزئي**.                                                                                      |
| `commit_candidate`                   | `name` / `gain`                    | سلسلة نصية／رقم غير سالب اختياريان لخيار المسار الجديد فقط                       | اسم المقطع المُولَّد ومعامل مستوى الصوت، والقيمة الافتراضية لـ `gain` هي 1.                                                                                                                                  |
| `render`                             | `title`                            | سلسلة نصية مطلوبة                                  | عنوان الصوت المُصدَّر.                                                                                                                                                   |
| `render`                             | `lyrics` / `tags`                  | سلسلة نصية اختيارية                                  | نص الكلمات الغنائية ووصف النمط عند التصدير؛ القيمة الافتراضية للكلمات هي `[Instrumental]`.                                                                                                                      |
| `render`                             | `start_beats` / `end_beats`        | أرقام غير سالبة اختيارية، ويجب أن تكون النهاية أكبر من البداية                         | نطاق نبضات المشروع للتصدير؛ عند الحذف، يُؤخذ أبكر موضع بداية وآخر موضع نهاية لجميع المقاطع المسموعة. لا تشارك المقاطع الصامتة، وعند وجود مسارات solo يتم اختيار مسارات solo فقط.                                                                                             |

ينتج التوليد خيارات فقط، **ولا يضعها تلقائياً في المشروع**. يتحقق `commit_candidate` من أن الخيار ما زال ينتمي إلى الإصدار الحالي. لا يمكن إرسال خيار الاستبدال الجزئي تلقائياً إلا عندما يمكن مطابقة مدته الفعلية بشكل موثوق مع الصوت المصدر الكامل أو المنطقة المحددة؛ وعند عدم التطابق، يُحتفظ بالمشروع الأصلي ويُرجع خطأ، ولا يمكن فرض تجميعه عبر التخمين اليدوي للنبضات.

## 2026-10-09 الطلبات والاستجابات الفعلية

تُؤخذ نصوص الطلبات وحقول الاستجابات التالية من استدعاءات فعلية للمشروع نفسه. كل مجموعة من JSON هي بالترتيب: الطلب، واستجابة القبول (إذا كانت غير متزامنة)، واستجابة الحالة النهائية للمهمة. لتسهيل القراءة، لا تستخرج الاستجابات إلا الحقول اللازمة لإكمال هذا التدفق؛ ولا يتم عرض حقول الحساب والاستخدام والمدة. تنتمي معرّفات المثال إلى تطبيق الاختبار هذا، ويجب عند التكامل استخدام المعرّفات التي تُرجعها طلباتك أنت و`Idempotency-Key` جديد.

### 1. إنشاء مشروع فارغ وقراءته: `create`، `retrieve`

طلب `create`:

```json
{
  "action": "create",
  "title": "Suno Projects Documentation Verification 2026-10-09"
}
```

```json
{
  "success": true,
  "trace_id": "42408a82-988b-4127-ba68-9b89348a7c56",
  "data": {
    "id": "af0e104a-2a4c-40e0-9c70-7614566824a6",
    "title": "Suno Projects Documentation Verification 2026-10-09",
    "state": {
      "tracks": [],
      "timing": {
        "bps": 2
      }
    }
  }
}
```

ثم استدعاء `retrieve` مباشرة:

```json
{
  "action": "retrieve",
  "id": "af0e104a-2a4c-40e0-9c70-7614566824a6"
}
```

## الأخطاء والاسترداد

| النتيجة                                                                            | المعنى                          | الخطوة التالية                                    |
| ----------------------------------------------------------------------------- | --------------------------- | -------------------------------------- |
| `project_version_conflict` / `project_candidate_stale`（409）                   | تغيّر إصدار المشروع، أو أن المرشح لا ينتمي إلى الإصدار الحالي.         | نفّذ `retrieve` لأحدث مشروع وأعِد تخطيط التعديلات؛ لا تُعِد تشغيل مرشح قديم.        |
| `bad_request` / `studio_state_invalid` / `studio_model_unsupported`（عادةً 400）   | لا تتطابق المعلمات أو حالة المسار أو مدة المرشح أو النموذج مع العملية.      | اعرض خطأ الحالة النهائية للمهمة، وصحّح الإدخال؛ احتفظ بالمشروع الأصلي عندما لا يمكن دمج المرشح بأمان.          |
| `studio_audio_unavailable` / `studio_access_denied` / `content_rejected`（403） | الصوت المُشار إليه غير متاح لعملية المشروع هذه، أو لا توجد صلاحية وصول، أو تم رفض فحص المحتوى. | تحقّق من مصدر الصوت و`trace_id` للمهمة؛ لا تعتبر المرشحين المُنشأين بالفعل مساويين لإمكانية تصدير الأغنية كاملة. |
| `too_many_requests`（429）                                                      | الطلب مقيّد بمعدل الطلبات.                   | استعلم عن المهمة الأصلية أولًا، ثم قرر ما إذا كنت ستبدأ عملية جديدة بمفتاح idempotency جديد.                |
| `studio_unavailable` / `studio_model_unavailable`（503）                        | معالجة المشروع أو النموذج المحدد غير متاح مؤقتًا.             | احتفظ بنتيجة المهمة الأصلية؛ أعد المحاولة صراحةً لاحقًا، ولا تبدّل النموذج تلقائيًا.                |
| `studio_processing_failed` / مهلة（500/504）                                      | فشلت المعالجة أو أن الحالة النهائية غير مؤكدة.                 | استعلم باستخدام `task_id` أو مفتاح idempotency الأصلي، لتجنب إنشاء مكرر برسوم إضافية.          |

ترتبط المشاريع والمرشحون بالتطبيق وبيئة التنفيذ اللذين أنشآهما، ولا يمكن افتراض إعادة استخدامها عبر التطبيقات أو التبديل التلقائي عند الفشل. يُرجى حفظ عنوان URL النهائي للصوت المُصدَّر بنجاح بشكل دائم، والاحتفاظ بـ`trace_id` لتسهيل استكشاف الأخطاء وإصلاحها.
