تدير واجهة API لمشروع Suno Studio مشاريع الموسيقى متعددة المسارات عبر نقطة دخول واحدة:

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

يحدد `action` في الطلب نوع العملية. يستخدم المفتاح الأساسي للمشروع `id` بشكل موحّد؛ ويمثل `version_id` إصدار المشروع الحالي، ويجب أن ترسل جميع عمليات التعديل والتصدير أحدث إصدار لتجنب الكتابة فوق التغييرات المتزامنة.

## نظرة عامة على العمليات

| action             | النمط  | الاستخدام                      |
| ------------------ | --- | ----------------------- |
| `create`           | متزامن  | إنشاء مشروع فارغ                   |
| `retrieve`         | متزامن  | قراءة المشروع وحالة `state` الكاملة القابلة للتحرير      |
| `save`             | متزامن  | حفظ حالة المشروع الكاملة                |
| `upload`           | غير متزامن  | تهيئة مادة يمكن إضافتها إلى المشروع من عنوان صوت HTTPS |
| `add_track`        | غير متزامن  | إضافة صوت موجود إلى المشروع               |
| `generate_track`   | غير متزامن  | إنشاء مرشحين لمسار صوتي جديد لنطاق محدد            |
| `replace_section`  | غير متزامن  | إنشاء مرشحين للاستبدال الجزئي                |
| `commit_candidate` | غير متزامن  | إرسال المرشح المحدد إلى المشروع             |
| `remove_track`     | متزامن  | حذف المسار المحدد                  |
| `render`           | غير متزامن  | تصدير الإصدار المحفوظ كأغنية كاملة           |

تعيد العمليات غير المتزامنة `task_id` فورًا. استخدم واجهة `/suno/tasks` المجانية للاستعلام الدوري، أو مرر `callback_url` لتلقي نتيجة الحالة النهائية.

## الإنشاء والقراءة

```json
{"action":"create","title":"My Studio Project"}
```

يجب أن ترسل جميع عمليات التعديل ترويسة `Idempotency-Key` فريدة. بعد نجاح الإنشاء، يكون `data.id` في الاستجابة هو معرّف المشروع. قد لا يحتوي المشروع الفارغ الجديد على `version_id` قبل الحفظ الأول.

```json
{"action":"retrieve","id":"PROJECT_ID"}
```

تتضمن استجابة القراءة `state` كاملة. يُوصى بالقراءة أولًا، ثم التعديل والحفظ استنادًا إلى القيمة المعادة؛ لا تُنشئ بنية الإيقاع والمسارات الداخلية يدويًا من الصفر.

## حفظ الحالة الكاملة

```json
{
  "action":"save",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Edited Project",
  "state":{"tracks":[],"timing":{}}
}
```

يمكن حذف `version_id` عند الحفظ الأول لمشروع فارغ جديد؛ بعد أن ينشئ الحفظ الأول إصدارًا، يجب أن ترسل أحدث قيمة في عمليات الحفظ اللاحقة. إذا كان الإصدار قد تغيّر، تعيد الواجهة HTTP 409. عندئذٍ أعد `retrieve`، وادمج التعديلات ثم أرسلها باستخدام مفتاح عدم تكرار جديد؛ لا تعِد محاولة الطلب القديم بشكل أعمى.

## رفع المسارات وإضافتها

```json
{
  "action":"upload",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "audio_url":"https://cdn.example.com/reference.mp3",
  "async":true
}
```

بعد اكتمال الرفع، تعيد نتيجة المهمة `audio_id` للمرشح. ثم أضِفه إلى المشروع:

```json
{
  "action":"add_track",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "audio_id":"AUDIO_ID",
  "name":"Backing Vocals"
}
```

## التوليد والاستبدال

ينشئ `generate_track` مرشحين لمسار صوتي لنطاق من المشروع؛ ويعيد `replace_section` مرشحين للاستبدال الجزئي. لا تختار أي من العمليتين النتيجة الفنية تلقائيًا.

```json
{
  "action":"replace_section",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "source_audio_id":"AUDIO_ID",
  "start_seconds":35.12,
  "end_seconds":48.76,
  "model":"chirp-v6",
  "replacement_lyrics":"新的歌词片段",
  "async":true
}
```

بعد اختيار المرشح، أرسله:

```json
{
  "action":"commit_candidate",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "operation_id":"OPERATION_ID",
  "candidate_id":"CANDIDATE_ID",
  "track_id":"TRACK_ID"
}
```

يرتبط المرشح بإصدار المشروع وقت التوليد. عندما يكون المشروع قد تغيّر، لا يمكن إرسال المرشح القديم مباشرةً.

## تصدير الأغنية الكاملة

```json
{
  "action":"render",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Final Mix",
  "lyrics":"[Instrumental]",
  "async":true,
  "callback_url":"https://example.com/webhooks/suno"
}
```

يقرأ الخادم حالة المشروع الموثوقة للإصدار المحدد ويجمع معلمات التصدير. تتضمن نتيجة الحالة النهائية `render_id` و`audio_id` و`audio_url` والمدة. يرتبط المشروع ببيئة التنفيذ عند إنشائه، ولا يمكن نقله بين البيئات أو إجراء تجاوز تلقائي للأعطال.

> لا يجوز رفع أو معالجة سوى الصوتيات التي تمتلك حقًا قانونيًا لاستخدامها. واجهة API للمشاريع حاليًا في مرحلة Beta؛ يُرجى حفظ عناوين URL النهائية للصوت في النتائج المهمة بشكل دائم.
