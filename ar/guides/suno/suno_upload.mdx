تسمح SUNO لنا برفع مرجع الصوت لإعادة الإبداع، توضح هذه الوثيقة طرق توصيل API ذات الصلة.

الرفع العادي يحتاج فقط إلى `audio_url`، وهو عنوان CDN صوتي يمكن الوصول إليه علنًا. `mode` افتراضيًا هو `standard`، لذا لا حاجة لتعديل الاستدعاءات الحالية.

هنا ندخل `audio_url` وهو `https://cdn.acedata.cloud/suno_demo.mp3`، وهو عنوان CDN يمكن الوصول إليه علنًا.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

بعد الحصول على معرف الأغنية، يمكننا استخدام [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) لإنشاء أغاني مخصصة، على سبيل المثال، تمرير `action` كـ `upload_extend`، بينما يتم تمرير `audio_id` كمعرف الأغنية الذي تم إرجاعه، يمكننا إنشاء أغنية جديدة بناءً على مرجع الصوت.

## وضع الرفع المعزز

عندما لا يمكن للرفع العادي معالجة الصوت الذي تملكه أو حصلت على إذن لاستخدامه، يمكنك تعيين `mode` كـ `enhanced`. يجب أيضًا تقديم `name` يتكون من 1 إلى 100 حرف، واستخدام `audio_url` يمكن الوصول إليه علنًا عبر HTTPS.

يتم معالجة الرفع المعزز بشكل ثابت بشكل غير متزامن، وعادة ما يستغرق 2 دقيقة أو أكثر. المعالجة الناجحة تستهلك **1.87 Credits**، وفقًا لأعلى حزمة تعادل حوالي **¥1.20/مرة**؛ الفشل في المعالجة لا يخصم أي رسوم.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

ستعيد الواجهة على الفور `task_id` و `trace_id`. استخدم [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) للاستعلام عن المهمة، بعد النجاح، اقرأ معرف الصوت المرفوع من `response.data.audio_id`. يمكنك أيضًا تقديم `callback_url` عبر HTTPS لاستقبال الحالة النهائية.

يمكن استخدام `audio_id` الذي تم الحصول عليه من الرفع المعزز لـ Cover و Samples و Mashup. قد تظل عمليات استخراج المرافقة و MIDI، وفصل المسارات الكاملة، وفصل الصوت/المرافقة تخضع لقيود حساب الصوت؛ العمليات غير المدرجة لا تضمن دعم الاستخدام عبر الحسابات. كلما كانت مدة الصوت أقصر، كانت نسبة نجاح المعالجة عادةً أعلى.
