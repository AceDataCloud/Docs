يمكن لنموذج الموسيقى المخصص التعلم من 6 إلى 24 مقطع صوتي مرخص لاستخراج ميزات موسيقية متسقة، واستخدامها في إنشاء الأغاني لاحقًا. الإنشاء هو عملية غير متزامنة؛ يُنصح باستخدام 24 مقطع صوتي متسق في الأسلوب وذو جودة صوت واضحة للحصول على نتائج أكثر استقرارًا.

> يمكن تقديم الصوتيات التي تمتلك حقوق استخدامها القانونية، أو التي تم الحصول على إذن لإنشاء النموذج وتوليد المحتوى لاحقًا. يُرجى عدم رفع الموسيقى أو المواد الصوتية غير المرخصة.

## إنشاء النموذج

استدعاء `POST /suno/custom-models`، وتعيين `action=create`. يُنصح أيضًا بإرسال رأس طلب فريد `Idempotency-Key`؛ لإعادة استخدام نفس المفتاح عند إعادة المحاولة عبر الشبكة، لتجنب الإنشاء المكرر:

```json
{
  "action": "create",
  "name": "نموذجي المستقل",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

ترجع الواجهة على الفور معرف نموذج المنصة ومعرف المهمة. بعد الانتهاء من الإنشاء، سيتغير `status` في الاستجابة أو نتيجة الاستعلام إلى `ready`. سيتم احتساب **10 Credits** فقط عند نجاح إنشاء النموذج، وفقًا لأعلى حزمة بحوالي **¥6.75/كل**؛ لن يتم خصم أي رسوم عند فشل الإنشاء.

## استعلام النموذج

استعلام عن نموذج واحد:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

استعلام مجمع عن نماذج التطبيق الحالي:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

جميع النماذج تعود إلى تطبيق Suno الذي أنشأها. لن تؤثر تدوير بيانات اعتماد API على ملكية النموذج، ولا يمكن للتطبيقات الأخرى استعلام أو استخدام هذا النموذج.

## استخدام النموذج لإنشاء الأغاني

بعد أن يكون حالة النموذج `ready`، تابع استدعاء `POST /suno/custom-models`، وتعيين `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "مطر نيون",
  "lyric": "[المقطع]\nأضواء المدينة تتساقط عبر المطر",
  "style": "روك مستقل، سينث دافئ"
}
```

يجب أن يكون `id` هو النموذج الموسيقي المخصص الذي حالته `ready` ضمن التطبيق الحالي. ستفشل الطلبات عند عدم توفر النموذج، ولن يتم التبديل تلقائيًا إلى نماذج أخرى. استهلاك **0.90 Credits** عند نجاح إنشاء الأغنية، وفقًا لأعلى حزمة بحوالي **¥0.61/مرة**؛ لن يتم خصم أي رسوم عند فشل الإنشاء. الاستعلام وأرشفة النماذج مجانية.

## أرشفة النموذج

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

ستقوم النسخة التجريبية الحالية بأرشفة النموذج ومنع استخدامه لاحقًا، حيث تشير `capacity_released=false` في الاستجابة إلى أن الأرشفة لا تضمن تحرير سعة النموذج. يمكن استدعاء عملية الأرشفة بشكل متكرر، ولن يتم احتساب رسوم إضافية.
