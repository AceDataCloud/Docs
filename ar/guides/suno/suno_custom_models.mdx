يمكن لنموذج الموسيقى المخصص تعلم خصائص موسيقية متسقة من 6 إلى 24 مقطعًا صوتيًا مُصرحًا به، واستخدامها في إنشاء الأغاني لاحقًا. الإنشاء عملية غير متزامنة؛ يُنصح باستخدام 24 مقطعًا صوتيًا متسق الأسلوب وواضح الجودة للحصول على نتائج أكثر استقرارًا.

> لا يجوز إرسال سوى المقاطع الصوتية التي تمتلك حق استخدامها قانونيًا، أو التي حصلت على تفويض لإنشاء النموذج والتوليد اللاحق باستخدامها. يُرجى عدم رفع مواد موسيقية أو صوتية غير مصرح بها.

## إنشاء نموذج

استدعِ `POST /suno/custom-models`، واضبط `action=create`:

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

تعيد الواجهة فورًا معرّف نموذج المنصة ومعرّف المهمة. بعد اكتمال الإنشاء، ستصبح قيمة `status` في نتيجة رد النداء أو الاستعلام `ready`. لا يتم احتساب **10 Credits** إلا عند نجاح إنشاء النموذج؛ ولا تُخصم رسوم عند فشل الإنشاء.

## الاستعلام عن نموذج

الاستعلام عن نموذج واحد:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

استعلام مُجزّأ عن نماذج التطبيق الحالي:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

تنتمي جميع النماذج إلى تطبيق Suno الذي أنشأها. لا يؤثر تدوير بيانات اعتماد API على ملكية النموذج، ولا يمكن للتطبيقات الأخرى الاستعلام عن النموذج أو استخدامه.

## استخدام النموذج لإنشاء أغنية

بعد أن تصبح حالة النموذج `ready`، تابع استدعاء `POST /suno/custom-models`، واضبط `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

يجب أن يكون `id` لنموذج موسيقى مخصص بحالة `ready` ضمن التطبيق الحالي. يفشل الطلب عندما لا يكون النموذج متاحًا، ولن يتم التحويل تلقائيًا إلى نموذج آخر. يتعارض `persona_id` مع نموذج الموسيقى المخصص؛ وعند إرسالهما معًا، تعيد الواجهة HTTP 400 قبل إرسال الطلب إلى خدمة التوليد، ولا تُخصم رسوم. إذا كنت بحاجة إلى استخدام Persona، فاستخدم بدلًا من ذلك عمليتَي `artist_consistency` أو `artist_consistency_vox` في `/suno/audios`.

يستهلك نجاح إنشاء الأغنية **0.90 Credits**؛ ولا تُخصم رسوم عند فشل التوليد. الاستعلام عن النماذج وأرشفتها مجانيان.

## أرشفة نموذج

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

سيقوم إصدار Beta الحالي بأرشفة النموذج ومنع استمرار استخدامه، وتشير `capacity_released=false` في الاستجابة إلى أن الأرشفة لا تضمن تحرير سعة النموذج. يمكن استدعاء عملية الأرشفة بشكل متكرر، ولن يتم احتساب رسوم بشكل متكرر.
