---
title: "شرح تكامل API لنمط مغني Suno المخصص"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

يسمح لنا SUNO بتعيين نمط مغنٍ للأغاني التي تم إنشاؤها بالفعل، ثم إجراء إنشاء ثانوي بناءً عليه، يشرح هذا المستند طريقة تكامل API ذات الصلة.

لا يتم احتساب رسوم لعملية الاستعلام عن القائمة عبر `GET /suno/persona` وحذف السجلات عبر `DELETE /suno/persona`، ولا تتطلب ترويسة طلب إضافية للإعفاء من الرسوم. تظل عملية الإنشاء عبر `POST /suno/persona` خاضعة للرسوم وفقًا لقواعد تسعير الواجهة.

يحتوي API هذا على ثلاثة معاملات إدخال فقط، أولًا `audio_id`، وهو معرّف أغنية تم إنشاؤها بنجاح مسبقًا على المنصة الرسمية، ثم `name` و`description`، وهما اسم ووصف لنمط المغني.

`audio_id` الذي ندخله هنا هو `https://cdn.acedata.cloud/2qhzs3.png`، ويمكن الرجوع إلى [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) لإجراء إنشاء أغنية مخصصة، ويمكن في النهاية الحصول على `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

النتيجة كما يلي:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

يمكن ملاحظة أن حقل `persona_id` ضمن `data` هو معرّف نمط المغني بعد إنشائه.

بعد الحصول على معرّف نمط المغني، يمكننا استخدام [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) لإجراء إنشاء أغنية مخصصة، على سبيل المثال تمرير `artist_consistency` إلى `action`، وتمرير معرّف الأغنية المرفوعة إلى `audio_id`، كما يلزم رفع المعامل `persona_id`، وقيمته هي معرّف نمط المغني الذي تم إرجاعه أعلاه، وبذلك يمكن إنشاء أغنية جديدة وفقًا لنمط المغني المرجعي.
