---
title: "شرح تكامل API لأسلوب المغني المخصص في Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

يتيح لنا SUNO تعيين أسلوب مغنٍ للأغاني التي تم إنشاؤها بالفعل، ثم إجراء إنشاء ثانوي بناءً عليه، ويشرح هذا المستند طريقة تكامل واجهة API ذات الصلة.

لا تُحتسب رسوم على استعلام القائمة عبر `GET /suno/persona` وحذف السجلات عبر `DELETE /suno/persona`، ولا حاجة إلى ترويسة إضافية لطلب الإعفاء من الرسوم. تظل عملية الإنشاء عبر `POST /suno/persona` خاضعة للرسوم وفقًا لقواعد تسعير الواجهة.

في مسار الإنشاء الذي يدعم الاستعلام عن الصوت، يمكن استخدام التطبيق الأصلي وهوية المستدعي لتمرير `persona_id` من نتائج الإنشاء إلى `POST /suno/availability`. عند تأكيد التوفر، يتم إرجاع `data.available=true`. [دليل الاستعلام عن توفر الصوت](https://platform.acedata.cloud/documents/suno-availability-integration)

تحتوي واجهة API هذه على ثلاثة معاملات إدخال فقط، أولها `audio_id`، وهو معرّف أغنية تم إنشاؤها بنجاح مسبقًا على المنصة الرسمية، والثاني `name` و`description`، وهما اسم ووصف لنوع من أساليب المغني.

إن `audio_id` الذي ندخله هنا هو `https://cdn.acedata.cloud/2qhzs3.png`، ويمكن الرجوع إلى [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) لإجراء إنشاء أغنية مخصصة، وفي النهاية يمكن الحصول على `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

النتيجة كما يلي:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

يمكن ملاحظة أن حقل `persona_id` في `data` هو معرّف أسلوب المغني بعد الإنشاء.

بعد الحصول على معرّف أسلوب المغني، يمكننا استخدام [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) لإجراء إنشاء أغنية مخصصة، فعلى سبيل المثال، يتم تمرير `artist_consistency` إلى `action`، وفي الوقت نفسه يتم تمرير معرّف الأغنية المرفوعة إلى `audio_id`، كما يلزم رفع المعامل `persona_id`، وقيمته هي معرّف أسلوب المغني المُعاد أعلاه، وبذلك يمكن إنشاء أغنية جديدة وفقًا لأسلوب المغني المرجعي.
