---

إذا كنت ترغب في تخصيص توليد الأغاني، ولكنك لا تريد كثيرًا كتابة كلمات الأغاني بنفسك، فيمكنك استخدام واجهة API لتوليد كلمات الأغاني التي توفرها AceDataCloud لتوليد كلمات الأغاني عبر prompt، وواجهة API هي [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

الفوترة: بعد نجاح التوليد، تبلغ التكلفة القياسية لكل طلب **0.08 Credits**. عند إرجاع عدة مرشحين لكلمات الأغاني في طلب واحد، لا تزال الفوترة تُحسب كطلب واحد فقط؛ وتخضع خصومات الاستهلاك المطبقة للفواتير الفعلية، ولا تُفرض رسوم على الطلبات الفاشلة.

معلمة الإدخال الرئيسية لهذه الواجهة API هي `prompt`، و`model` اختيارية (القيم الاختيارية هي `default` و`remi-v1`، والقيمة الافتراضية هي `default`)، ومثال التعبئة كما يلي:

![](https://cdn.acedata.cloud/p53wtj.png)

هنا، قيمة `prompt` التي أدخلناها هي `A song about winter`، لتوليد أغنية مرتبطة بالشتاء.

انقر على التشغيل، وستكون النتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nSnowflakes falling from the sky\nWinter's cold touch\nOh how it gets me high\nI bundle up in layers\nOh so cozy\nStepping out and feeling the frost on my nose\n\n[Chorus]\nOh\nWinter's cold touch\nIt's a season that I love so much\nSnowfall brings a feeling so divine\nWinter's cold touch\nIt's a magical time",
      "title": "Winter's Cold Touch",
      "status": "complete",
      "tags": ["dreamy, mellow, ballad"]
    },
    {
      "text": "[Verse]\nThe world is covered in a blanket of white\nIcicles hanging\nShimmering so bright\nThe chilly air fills my lungs with every breath\nWalking in the snow\nLeaving footprints behind\n\n[Chorus]\nWinter wonderland\nEverything is so bright\nWinter wonderland\nHold me through the night",
      "title": "Winter Wonderland",
      "status": "complete",
      "tags": ["dream pop, mellow, shoegaze"]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,
  "elapsed": 7.433
}
```

يمكن ملاحظة أن `data` هي مصفوفة، وستُرجع عدة مرشحين لكلمات الأغاني في كل مرة، حيث إن حقل `text` لكل عنصر هو محتوى كلمات الأغاني، و`title` هو العنوان، و`tags` هي علامات أنماط الموسيقى الموصى بها.

بعد الحصول على كلمات الأغاني، يمكننا استخدام [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) لإجراء توليد أغاني مخصصة.
