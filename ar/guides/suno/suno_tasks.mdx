الوظيفة الرئيسية لواجهة برمجة تطبيقات مهام Suno هي استعلام حالة تنفيذ المهمة من خلال إدخال معرف المهمة الذي تم إنشاؤه بواسطة واجهة برمجة تطبيقات توليد الصوتيات Suno أو واجهة برمجة تطبيقات توليد كلمات الأغاني Suno.

ستتناول هذه الوثيقة تفاصيل تكامل واجهة برمجة تطبيقات مهام Suno، لمساعدتك على دمجها بسهولة والاستفادة الكاملة من القوة الكبيرة لهذه الواجهة. من خلال واجهة برمجة تطبيقات مهام Suno، يمكنك بسهولة استعلام حالة تنفيذ المهام من واجهة برمجة تطبيقات توليد كلمات الأغاني Suno أو واجهة برمجة تطبيقات توليد الصوتيات Suno.

## عملية التقديم

لاستخدام واجهة برمجة تطبيقات توليد الصوتيات Suno، يجب أولاً الذهاب إلى [وحدة التحكم في بيانات Ace](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، احتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد الانتهاء، سيتم إرجاعك تلقائيًا إلى الصفحة الحالية.

**يمكن استخدام رمز API واحد لاستدعاء جميع خدمات المنصة، دون الحاجة لتقديم طلب منفصل لكل خدمة.** عند التقديم لأول مرة، ستحصل على رصيد مجاني لتجربته مجانًا؛ وعند نفاد الرصيد، يمكنك إعادة شحن الرصيد العام في [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [واجهة برمجة تطبيقات توليد الصوتيات Suno →](https://platform.acedata.cloud/documents/suno-audios)

## مثال على الطلب

يمكن استخدام واجهة برمجة تطبيقات مهام Suno لاستعلام نتائج واجهتي برمجة تطبيقات توليد الصوتيات Suno وتوليد كلمات الأغاني Suno. حول كيفية استخدام واجهة برمجة تطبيقات توليد الصوتيات Suno، يرجى الرجوع إلى الوثيقة [واجهة برمجة تطبيقات توليد الصوتيات Suno](https://platform.acedata.cloud/documents/suno-audios-integration). حول كيفية استخدام واجهة برمجة تطبيقات توليد كلمات الأغاني Suno، يرجى الرجوع إلى [واجهة برمجة تطبيقات توليد كلمات الأغاني Suno](https://platform.acedata.cloud/documents/suno-lyrics-generation-integration).

سنأخذ مثالاً على معرف المهمة الذي تم إرجاعه من خدمة واجهة برمجة تطبيقات توليد الصوتيات Suno، ونوضح كيفية استخدام هذه الواجهة. لنفترض أن لدينا معرف مهمة: eae26f89-b64b-404d-a80c-761996660b1c، وسنوضح بعد ذلك كيفية تمرير معرف المهمة.

### إعداد رأس الطلب وجسم الطلب

**رؤوس الطلب** تشمل:

- `accept`: يحدد استلام استجابة بتنسيق JSON، هنا يتم ملؤه بـ `application/json`.
- `authorization`: مفتاح استدعاء الواجهة، يمكن اختياره مباشرة بعد التقديم.

**جسم الطلب** يشمل:

- `id`: معرف المهمة المرفوع.
- `action`: طريقة تنفيذ العملية على المهمة.

بعض أمثلة الكود كما يلي:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/suno/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "eae26f89-b64b-404d-a80c-761996660b1c",
  "action": "retrieve"
}'
```

#### بايثون

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "eae26f89-b64b-404d-a80c-761996660b1c",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## معالجة الأخطاء

عند استدعاء واجهة برمجة التطبيقات، إذا واجهت خطأ، ستقوم واجهة برمجة التطبيقات بإرجاع رمز الخطأ والمعلومات ذات الصلة. على سبيل المثال:

- `400 token_mismatched` : طلب غير صحيح، ربما بسبب معلمات مفقودة أو غير صالحة.
- `400 api_not_implemented` : طلب غير صحيح، ربما بسبب معلمات مفقودة أو غير صالحة.
- `401 invalid_token` : غير مصرح، رمز تفويض غير صالح أو مفقود.
- `429 too_many_requests` : عدد كبير جدًا من الطلبات، لقد تجاوزت الحد الأقصى لمعدل الطلبات.
- `500 api_error` : خطأ داخلي في الخادم، حدث خطأ ما على الخادم.

### مثال على استجابة الخطأ

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "فشل في الاسترجاع"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## الخاتمة

من خلال هذه الوثيقة، لقد فهمت كيفية استخدام واجهة برمجة تطبيقات مهام Suno لاسترجاع تفاصيل مهمة أغاني فردية أو دفعات. نأمل أن تساعدك هذه الوثيقة في التوصيل واستخدام واجهة برمجة التطبيقات بشكل أفضل. إذا كان لديك أي استفسارات، فلا تتردد في الاتصال بفريق الدعم الفني لدينا.
