تتمثل الوظيفة الرئيسية لـ Suno Tasks API في الاستعلام عن حالة تنفيذ المهمة من خلال إدخال معرّف المهمة الذي تم إنشاؤه بواسطة Suno Audios Generation API أو Suno Lyrics Generation API.

سيقدم هذا المستند بالتفصيل إرشادات تكامل Suno Tasks API، لمساعدتك على دمج هذه الواجهة والاستفادة الكاملة من وظائفها القوية بسهولة. من خلال Suno Tasks API، يمكنك بسهولة الاستعلام عن حالة تنفيذ مهام Suno Lyrics Generation API أو Suno Audios Generation API.

## عملية التقديم

لاستخدام Suno Audios Generation API، انتقل أولاً إلى [وحدة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على API Token الخاص بك، واحتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تقم بتسجيل الدخول أو التسجيل بعد، فسيتم إعادة توجيهك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وبعد الإكمال ستعود تلقائيًا إلى الصفحة الحالية.

**يمكن لـ API Token واحد استدعاء جميع خدمات المنصة، ولا حاجة للتقديم بشكل منفصل لكل خدمة.** سيُمنحك رصيد مجاني عند التقديم لأول مرة لتجربة الخدمة مجانًا؛ وعندما لا يكون الرصيد كافيًا، يمكنك شحن الرصيد العام من [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## مثال على الطلب

يمكن استخدام Suno Tasks API للاستعلام عن نتائج كل من Suno Audios Generation API وSuno Lyrics Generation API. لمعرفة كيفية استخدام Suno Audios Generation API، يُرجى الرجوع إلى وثائق [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios-integration). ولمعرفة كيفية استخدام Suno Lyrics Generation API، يُرجى الرجوع إلى [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics-generation-integration).

سنأخذ معرّف مهمة تم إرجاعه من خدمة Suno Audios Generation API كمثال لعرض كيفية استخدام هذه الواجهة. افترض أن لدينا معرّف مهمة: eae26f89-b64b-404d-a80c-761996660b1c، وسنعرض بعد ذلك كيفية تمرير معرّف مهمة من خلال.

### إعداد رؤوس الطلب وجسم الطلب

تتضمن **Request Headers** ما يلي:

- `accept`: يحدد استلام نتيجة الاستجابة بتنسيق JSON، ويُملأ هنا بـ `application/json`.
- `authorization`: مفتاح استدعاء API، ويمكن اختياره مباشرةً من القائمة المنسدلة بعد التقديم.

يتضمن **Request Body** ما يلي:

- `id`: معرّف المهمة المرفوع.
- `action`: طريقة تنفيذ العملية على المهمة.

يمكن ملاحظة أنه تم إنشاء أكواد بلغات مختلفة تلقائيًا بالفعل على الجانب الأيمن من الصفحة، كما هو موضح في الصورة:

بعض أمثلة الأكواد كما يلي:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/suno/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "eae26f89-b64b-404d-a80c-761996660b1c",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "eae26f89-b64b-404d-a80c-761996660b1c",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

تتضمن نتيجة الإرجاع عدة حقول، وحقل `request` هو `request body` عند بدء المهمة، بينما حقل `response` هو `response body` الذي يُرجع بعد اكتمال المهمة. وفيما يلي تعريف الحقول.

- `id`، معرّف مهمة إنشاء هذه الأغنية، ويُستخدم لتمييز مهمة إنشاء الأغنية هذه بشكل فريد.
- `request`، معلومات الطلب في استعلام مهمة الأغنية.
- `response`، معلومات الإرجاع في استعلام مهمة الأغنية.
- `created_at`، وقت إنشاء المهمة، طابع زمني Unix (بالثواني، رقم عشري).
- `started_at`، وقت بدء تنفيذ المهمة، طابع زمني Unix (بالثواني، رقم عشري).
- `finished_at`، وقت اكتمال المهمة، طابع زمني Unix (بالثواني، رقم عشري). لا يُرجع هذا الحقل عندما لا تكون المهمة مكتملة.
- `elapsed`، الوقت المستغرق في تنفيذ المهمة، بوحدة الثواني (رقم عشري، مع الاحتفاظ بـ 3 منازل عشرية). لا يُرجع هذا الحقل عندما لا تكون المهمة مكتملة.

```json {
          }
        ]
      }
    }
  ],
  "count": 2
}
```
 

تتضمن نتيجة الإرجاع عدة حقول إجمالًا، حيث يحتوي `items` على معلومات التفاصيل المحددة لمهام الأغاني المجمّعة، وتكون المعلومات المحددة لكل مهمة أغنية مماثلة للحقول المذكورة أعلاه، ومعلومات الحقول كما يلي.

- `items`، جميع معلومات التفاصيل المحددة لمهام الأغاني المجمّعة. وهي مصفوفة، ويكون تنسيق كل عنصر في المصفوفة مطابقًا لتنسيق نتيجة الإرجاع للاستعلام عن مهمة واحدة المذكورة أعلاه.
- `count`، عدد مهام الأغاني التي تم الاستعلام عنها دفعةً واحدة هنا.

#### Python

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "ids": ["eae26f89-b64b-404d-a80c-761996660b1c","0d3ed03b-912b-4f7d-941b-8441323cb77b"],
    "action": "retrieve_batch"
```

## معالجة الأخطاء

عند استدعاء واجهة API، إذا واجهت خطأً، فستُرجع واجهة API رمز الخطأ والمعلومات المقابلة. على سبيل المثال:

- `400 token_mismatched`：طلب غير صالح، ربما بسبب معلمات مفقودة أو غير صالحة.
- `400 api_not_implemented`：طلب غير صالح، ربما بسبب معلمات مفقودة أو غير صالحة.
- `401 invalid_token`：غير مُصرّح به، رمز التفويض غير صالح أو مفقود.
- `429 too_many_requests`：طلبات كثيرة جدًا، لقد تجاوزت حد المعدل.
- `500 api_error`：خطأ داخلي في الخادم، حدث خطأ ما على الخادم.

### مثال على استجابة الخطأ

```json
  },

}
```
