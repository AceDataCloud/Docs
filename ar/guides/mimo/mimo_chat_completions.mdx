MiMo 2.6 Pro وMiMo 2.6 Flash هما من نماذج سلسلة Xiaomi MiMo. تستخدم هذه الواجهة تنسيق OpenAI Chat Completions، وتُحتسب الرسوم حسب token الإدخال والإخراج وإصابة التخزين المؤقت.

## النماذج والواجهة

| النموذج                | التموضع           |
| ----------------- | ------------ |
| `mimo-v2.6-pro`   | التحليل المعقد والاستدلال واستدعاء الأدوات |
| `mimo-v2.6-flash` | المحادثات اليومية والمهام الخفيفة    |

فعّل MiMo واحصل على بيانات اعتماد API المقابلة، ثم أرسل الطلبات إلى `https://api.acedata.cloud/mimo/chat/completions`. يمكن ضبط `base_url` في OpenAI SDK على `https://api.acedata.cloud/mimo`. يتطلب مدخل `/v1/chat/completions` الموحد أيضًا أذونات الخدمة المقابلة.

يشمل نطاق الواجهة الأولي Text Chat Completions؛ ولا تدخل الصور والصوت والفيديو والبحث عبر الإنترنت وResponses وMessages وBatch وUltraSpeed ضمن نطاق هذا الإصدار.

## مثال Python

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ACEDATACLOUD_API_KEY"],
    base_url="https://api.acedata.cloud/mimo",
)
response = client.chat.completions.create(
    model="mimo-v2.6-pro",
    messages=[{"role": "user", "content": "解释彩虹形成的原因。"}],
    max_completion_tokens=256,
    extra_body={"thinking": {"type": "disabled"}},
)
print(response.choices[0].message.content)
print(response.usage)
```

يعرض المثال صيغة كتابة الطلب؛ وسيُستكمل مثال الاستجابة الفعلية بعد التحقق من الخدمة.

## البث والاستدلال واستدعاء الأدوات

اضبط `stream=true` لتلقي SSE؛ وإذا كنت تحتاج إلى الاستخدام النهائي، فمرّر `stream_options={"include_usage": true}`. يجب على العميل معالجة المحتوى ومحتوى الاستدلال والزيادات الخاصة باستدعاء الأدوات، بالإضافة إلى حدث usage النهائي.

استخدم `thinking.type=enabled` لتفعيل الاستدلال، و`disabled` لتعطيله. يُعاد `reasoning_content` و`content` النهائي بشكل منفصل؛ وعند استئناف استدعاء الأدوات، احتفظ بمحتوى الاستدلال في رسالة المساعد، وبـ `tool_calls` الكامل و`tool_call_id` المقابل.

قدّم فقط تعريفات الأدوات من `type=function`، ويدعم `tool_choice` فقط `auto`. يكون التطبيق مسؤولًا عن تنفيذ الأدوات وإعادة النتائج؛ ولا يعني إرجاع النموذج لاستدعاء الأداة نفسه أن الأداة قد نُفذت. لم تُفتح بعد خدمة البحث عبر الإنترنت المضمنة.

## الفوترة

يتضمن `prompt_tokens` الإدخال الذي أصاب التخزين المؤقت؛ ويُحتسب `prompt_tokens_details.cached_tokens` بسعر التخزين المؤقت، بينما يُحتسب باقي الإدخال بسعر الإدخال العادي. يتضمن `completion_tokens` مخرجات الاستدلال، لذا لا تجمع token الاستدلال بشكل متكرر. تُسوّى الاستدعاءات المتدفقة أيضًا وفق الاستخدام الفعلي النهائي.

تكون الأسعار وفقًا للوحة التحكم، وتعتمد التكلفة بالدولار لـ Credit على باقة الشراء. لا ينبغي اعتبار الطلبات الفاشلة مكتملة بنجاح؛ وإذا احتجت إلى التحقق من الرسوم المخصومة، فيرجى تقديم معرّف التتبع في الاستجابة.

## معالجة الأخطاء

بالنسبة إلى أخطاء المعلمات، يرجى التحقق من تنسيق الطلب؛ وبالنسبة إلى أخطاء المصادقة أو الأذونات، يرجى التحقق من بيانات الاعتماد وتفعيل الخدمة؛ وعند مواجهة 429، يرجى إعادة المحاولة بتراجع تدريجي. قد يتم إرجاع 503 عند عدم توفر سعة نموذج سليمة. عند حدوث انقطاع بعد بدء الاستجابة المتدفقة، تحقّق أولًا من النتائج والاستخدام المستلمين لتجنب تكرار الطلبات بشكل أعمى.
