Google Gemini هو نظام محادثة بالذكاء الاصطناعي قوي للغاية، فما عليك سوى إدخال كلمة توجيهية ليتمكن من إنشاء ردود سلسة وطبيعية خلال بضع ثوانٍ. يمكن لـ Gemini تقديم مساعدة ذكية مذهلة، مما يحسن كفاءة العمل والإبداع البشريين بشكل كبير.

يقدم هذا المستند بشكل أساسي عملية استخدام عمليات Gemini Chat Completion API، وباستخدامه يمكننا بسهولة استخدام وظيفة المحادثة الرسمية لـ Gemini.

## عملية التقديم

لاستخدام Gemini Chat Completion API، انتقل أولاً إلى [وحدة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على API Token الخاص بك، واحتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد سجلت الدخول أو أنشأت حسابًا بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وبعد الإكمال ستعود تلقائيًا إلى الصفحة الحالية.

**يمكن لـ API Token واحد استدعاء جميع خدمات المنصة، ولا حاجة للتقديم بشكل منفصل لكل خدمة.** سيُمنحك رصيد مجاني عند التقديم لأول مرة لتجربة الخدمة مجانًا؛ وعندما لا يكون الرصيد كافيًا، يمكنك شحن الرصيد العام من [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [Gemini Chat Completion API →](https://platform.acedata.cloud/documents/gemini-chat-completions)

## الاستخدام الأساسي

بعد ذلك، يمكنك ملء المحتوى المقابل في الواجهة، كما هو موضح في الصورة:

<p><img src="https://cdn.acedata.cloud/f6ksts.png" width="400" className="m-auto" /></p>

عند استخدام هذه الواجهة لأول مرة، نحتاج على الأقل إلى ملء ثلاثة عناصر. أحدها هو `authorization`، ويمكنك اختياره مباشرة من القائمة المنسدلة. المعلمة الأخرى هي `model`، و`model` هي فئة نموذج Gemini الرسمي التي نختار استخدامها، وتخضع النماذج المتاحة لتعداد `model` في وثائق الواجهة. المعلمة الأخيرة هي `messages`، و`messages` هي مصفوفة كلمات الاستفسار التي ندخلها، وهي مصفوفة تشير إلى إمكانية رفع عدة كلمات استفسار في الوقت نفسه، ويتضمن كل استفسار `role` و`content`، حيث يشير `role` إلى دور السائل، وقد وفرنا ثلاث هويات، وهي `user` و`assistant` و`system`. أما `content` الآخر فهو المحتوى المحدد لسؤالنا.

في الوقت نفسه، يمكنك ملاحظة وجود توليد لرمز الاستدعاء المقابل على اليمين، ويمكنك نسخ الرمز وتشغيله مباشرة، أو النقر مباشرة على زر «Try» للاختبار.

<p><img src="https://cdn.acedata.cloud/a3mdgy.png" width="400" className="m-auto" /></p>

تتضمن النتيجة المرجعة عدة حقول، وفيما يلي تعريفها:

## فهم الصور (إدخال متعدد الوسائط)

Gemini هو نموذج متعدد الوسائط أصلي، ويمكنه «رؤية الصور» مباشرة. لتمرير صورة، غيّر `content` لإحدى الرسائل من سلسلة نصية إلى **مصفوفة كتل محتوى**، وضع فيها كتلة `text` وكتلة `image_url` معًا — وهذا يتطابق تمامًا مع تنسيق OpenAI، وكذلك تنسيق Gemini الرسمي المتوافق مع OpenAI.

يدعم `image_url.url` طريقتين للكتابة:

- **base64 `data:` URI (موصى به، الأكثر استقرارًا)**: التنسيق هو `data:&lt;媒体类型>;base64,&lt;数据>`، على سبيل المثال `data:image/jpeg;base64,/9j/4AAQ...`. **نوع الوسائط (MIME) مكتوب بالفعل في بادئة `data:`**، لذلك لا حاجة إلى حقل `media_type` منفصل، وهو غير موجود أيضًا.
- **رابط URL لصورة يمكن الوصول إليها علنًا**: على سبيل المثال `https://cdn.acedata.cloud/4hfydw.jpg`.

أنواع الصور المدعومة: `png` و`jpeg` و`webp` و`heic` و`heif`.

رمز استدعاء نموذجي لـ Python (base64 data URI):
```python
import base64
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

# 把本地图片读成 base64 data URI
with open("image.jpg", "rb") as f:
    base64_image = base64.b64encode(f.read()).decode("utf-8")
data_uri = f"data:image/jpeg;base64,{base64_image}"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-3.1-pro-preview",
    "messages": [
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "请用一句话描述这张图片。"},
                {"type": "image_url", "image_url": {"url": data_uri}}
            ]
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

يمكنك أيضًا تمرير رابط URL لصورة متاحة للعامة مباشرةً:

> 💡 لا يقبل `image_url` إلا الحقل `url` (يمكن أن تكون قيمته رابط URL للصورة أو `data:` URI بتنسيق base64)، بالإضافة إلى الحقل الاختياري `detail`. **لا تمرر `media_type`** — فهذا حقل صور خاص بـ Anthropic Claude، ولا ينتمي إلى تنسيق `image_url` الخاص بـ OpenAI / Gemini.

## الاستجابة المتدفقة

تدعم هذه الواجهة أيضًا الاستجابة المتدفقة، وهذا مفيد جدًا لتكامل صفحات الويب، إذ يتيح للصفحة تنفيذ تأثير العرض حرفًا بحرف.

إذا أردت إرجاع الاستجابة بشكل متدفق، يمكنك تغيير المعلمة `stream ` في ترويسة الطلب إلى `true`.

التعديل كما هو موضح في الصورة، ولكن يجب أن يحتوي كود الاستدعاء على التعديلات المناسبة لدعم الاستجابة المتدفقة.

<p><img src="https://cdn.acedata.cloud/o2blmi.png" width="400" className="m-auto" /></p>

بعد تعديل `stream` إلى `true`، ستُرجع واجهة API بيانات JSON المقابلة سطرًا بسطر، وعلى مستوى الكود نحتاج إلى إجراء التعديلات المناسبة للحصول على النتائج سطرًا بسطر.

مثال على كود الاستدعاء في Python:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-2.5-pro",
    "messages": [{"role":"user","content":"Hello,What model are you?"}],
    "stream": True,
    "stream_options": {"include_usage": True}
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

- `choices`، معلومات الإجابة التي يقدمها Gemini على كلمات الاستعلام.

يدعم JavaScript أيضًا، على سبيل المثال، يكون كود الاستدعاء المتدفق في Node.js كما يلي:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "gemini-2.5-pro",
    messages: [{ role: "user", content: "Hello, what model are you?" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/gemini/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

## نموذج Gemini-3.1 متعدد الوسائط

`gemini-3.1-pro-preview` هو معرّف النموذج الرسمي الحالي لـ Gemini 3.1 Pro، ويدعم المدخلات متعددة الوسائط مثل النصوص والصور ومقاطع الفيديو، وهو مناسب لمهام الاستدلال والترميز والفهم المعقدة.

مثال للطلب:

```json
{
  "model": "gemini-3.1-pro-preview",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "图片的内容是什么？"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

## معالجة الأخطاء

عند استدعاء API، إذا واجهت خطأً، فسيُرجع API رمز الخطأ والمعلومات المقابلة. على سبيل المثال:

- `400 token_mismatched`: طلب غير صالح، ربما بسبب معلمات مفقودة أو غير صالحة.
- `400 api_not_implemented`: طلب غير صالح، ربما بسبب معلمات مفقودة أو غير صالحة.
- `401 invalid_token`: غير مصرح به، رمز المصادقة غير صالح أو مفقود.
- `429 too_many_requests`: طلبات كثيرة جدًا، لقد تجاوزت حد المعدل.
- `500 api_error`: خطأ داخلي في الخادم، حدث خطأ ما على الخادم.

### مثال على استجابة خطأ
```
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## الخلاصة

من خلال هذا المستند، تعرفت بالفعل على كيفية استخدام Gemini Chat Completion API لتنفيذ وظيفة المحادثة الرسمية لـ Gemini بسهولة. نأمل أن يساعدك هذا المستند على التكامل مع واجهة API هذه واستخدامها بشكل أفضل. إذا كانت لديك أي أسئلة، فيرجى التواصل مع فريق الدعم الفني لدينا في أي وقت.
