Google Gemini هو نظام محادثة بالذكاء الاصطناعي قوي جدًا، ويمكنه إنشاء ردود سلسة وطبيعية خلال ثوانٍ بمجرد إدخال مطالبة. يصف هذا المستند بشكل أساسي طريقة استخدام واجهة Gemini Generate Content API، وهي تنسيق واجهة برمجة التطبيقات الأصلي الرسمي من Google، وتدعم نقطتي النهاية `generateContent` و`streamGenerateContent`.

## الفرق عن Chat Completions API

تستخدم Gemini Generate Content API تنسيق الطلب الأصلي الرسمي من Google (حقل `contents`) بدلًا من التنسيق المتوافق مع OpenAI (حقل `messages`). إذا كنت تستخدم بالفعل Google Gemini SDK أو كنت على دراية بتنسيق واجهة برمجة التطبيقات الرسمي، فيمكنك استخدام هذه الواجهة مباشرةً دون تعديل تنسيق الطلب.

## نطاق الدعم الحالي

تقبل الواجهة إدخالات النصوص والصور والفيديو والصوت (عبر `inlineData` أو `fileData`)، وإعدادات التفكير وإعلانات الدوال المخصصة. لا تتوفر حتى الآن ضمانات موحدة لإتاحة الحقول الأصلية مثل مخرجات الصوت والأدوات المضمنة والتخزين المؤقت الصريح للسياق؛ يُرجى الرجوع إلى الاستجابة الفعلية للنموذج المحدد.

عند إرسال ملفات مثل الصوت باستخدام `fileData.fileUri`، يُرجى التأكد من إمكانية الوصول إلى الملف مباشرةً عبر HTTPS، وألا يعتمد على حالة تسجيل الدخول، وأن تغطي صلاحية الرابط الموقّع كامل وقت معالجة الطلب. لا تُرجع تحليلات الصوت غير المتدفقة النتائج إلا بعد انتهاء النموذج من المعالجة، وقد تتجاوز 90 ثانية؛ ينبغي للعميل تعيين مهلة إجمالية طويلة بما يكفي وفقًا لحجم الملف وسيناريو العمل، لتجنب قطع الاتصال بينما لا يزال الخادم يعالج الطلب.

## عملية التقديم

قبل استخدام Gemini Generate Content API، يُرجى أولًا زيارة صفحة [Gemini Generate Content API](https://platform.acedata.cloud/documents/gemini-generate-content-api)، والنقر على زر "الحصول" للحصول على بيانات الاعتماد المطلوبة للطلب.

إذا لم تقم بتسجيل الدخول أو التسجيل بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول. يتوفر رصيد مجاني عند أول طلب.

## الاستخدام الأساسي

### Non-Streaming（غير متدفق）

أرسل طلب POST إلى `/v1beta/models/{model}:generateContent`:

> **ملاحظة**: سلسلة `gemini-3.x` من flash هي نماذج تفكير، وستستهلك reasoning tokens أولًا؛ يُرجى تعيين `generationConfig.maxOutputTokens` إلى 512 أو أكثر، وإلا فقد تُرجع محتوى فارغًا فقط.

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "你好，请介绍一下你自己"
          }
        ]
      }
    ]
  }'
```

مثال على النتيجة المعادة:

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [{"text": "你好！很高兴与你交流。"}]
      },
      "finishReason": "MAX_TOKENS"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 6,
    "candidatesTokenCount": 19,
    "thoughtsTokenCount": 489,
    "totalTokenCount": 514
  },
  "usage": {
    "prompt_tokens": 6,
    "completion_tokens": 19,
    "total_tokens": 514,
    "thoughts_tokens": 489,
    "cost": {
      "amount": 0.008860916380159999,
      "currency": "credit",
      "list_amount": 0.009631430847999998
    }
  },
  "modelVersion": "gemini-3.5-flash",
  "model": "gemini-3.5-flash"
}
```

تُحتسب حقول token في `usageMetadata` وفقًا لدلالات Gemini الأصلية:

- يتضمن `promptTokenCount` قيمة `cachedContentTokenCount`، ويُحتسب الجزء المطابق للتخزين المؤقت بسعر قراءة التخزين المؤقت، ولن يُحتسب مجددًا كإدخال عادي.
- ستتم تسوية `promptTokensDetails` و`cacheTokensDetails` إلى `text_tokens` و`image_tokens` و`video_tokens` و`audio_tokens` وتفاصيل `cached_*` المقابلة ضمن `usage.prompt_tokens_details`. تُضمَّن هذه القيم على التوالي في `prompt_tokens` و`cached_tokens`؛ وتُعاد حساب الوسائط المختلفة وفق أسعارها الخاصة فقط، دون احتساب مكرر.
- يُحتسب كل من `candidatesTokenCount` و`thoughtsTokenCount` وفقًا لسعر output token.
- يُعد `toolUsePromptTokenCount` رمز إدخال مستقلًا للأداة، ويُحتسب وفقًا لسعر input token.

تعيد Ace Data Cloud بالإضافة إلى ذلك كائن `usage` موحّدًا، وتُقرأ تكلفة هذه المكالمة بشكل موحّد عبر بروتوكولات النماذج من `usage.cost`. إن `cost` هي معاينة تكلفة اختيارية؛ وعندما تكون معاينة السعر غير متاحة مؤقتًا، ستظل استجابة النموذج تُرجع بشكل طبيعي، لكنها قد لا تتضمن هذا الحقل. تخضع الفاتورة النهائية لسجل الاستخدام.

### Streaming（متدفق）

أرسل طلب POST إلى `/v1beta/models/{model}:streamGenerateContent?alt=sse`:

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "写一首关于春天的诗"
          }
        ]
      }
    ]
  }'
```

ستُرجع الاستجابة المتدفقة المحتوى تدريجيًا بتنسيق SSE（Server-Sent Events）. تحتوي الأحداث الوسيطة عادةً على محتوى تزايدي فقط؛ بينما سيتضمن الحدث النهائي الذي يحتوي على استخدام موثوق `usageMetadata` و`usage` الموحّد، وتظل التكلفة ضمن `usage.cost`:

```text
data: {"candidates":[{"content":{"parts":[{"text":"Hello!"}],"role":"model"},"index":0}],"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

data: {"candidates":[{"content":{"parts":[],"role":"model"},"finishReason":"STOP","index":0}],"usageMetadata":{"promptTokenCount":7,"candidatesTokenCount":89,"totalTokenCount":96},"usage":{"prompt_tokens":7,"completion_tokens":89,"total_tokens":96,"cost":{"amount":0.00026161075472,"currency":"credit","list_amount":0.000284359516}},"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

```

إغلاق الاتصال يعني انتهاء التدفق؛ ولا يرسل تدفق Gemini الأصلي `data: [DONE]`. إذا كانت معاينة السعر النهائي غير متاحة مؤقتًا، فسيظل `usage` يعيد استخدام token، لكنه سيحذف `cost`.

## الميزات المتقدمة

### تعليمات النظام

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "你好"}]
    }
  ],
  "systemInstruction": {
    "parts": [{"text": "你是一个专业的诗人，所有回复都用诗歌形式。"}]
  }
}
```

### إعدادات التوليد

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "讲一个故事"}]
    }
  ],
  "generationConfig": {
    "temperature": 0.7,
    "maxOutputTokens": 1024,
    "topP": 0.9,
    "topK": 40
  }
}
```

### وضع JSON

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {
          "text": "列出三个中国城市及其人口"
        }
      ]
    }
  ],
  "generationConfig": {
    "responseMimeType": "application/json",
    "responseSchema": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "city": {
            "type": "string"
          },
          "population": {
            "type": "integer"
          }
        }
      }
    }
  }
}
```

### وضع التفكير (Thinking)

يمكن للنماذج التي تدعم ميزة التفكير (مثل gemini-2.5-flash وgemini-2.5-pro) تفعيل وضع التفكير:

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "解释量子纠缠"}]
    }
  ],
  "generationConfig": {
    "thinkingConfig": {
      "includeThoughts": true,
      "thinkingBudget": 2048
    }
  }
}
```

### استدعاء الدوال

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "北京现在的天气怎么样？"}]
    }
  ],
  "tools": [
    {
      "functionDeclarations": [
        {
          "name": "get_weather",
          "description": "获取指定城市的天气信息",

            "type": "object",
            "properties": {
              "city": {
                "type": "string",
                "description": "城市名称"
              }
            },
            "required": ["city"]

      ]
    }
  ]
}
```

## إعدادات الأمان

يمكن التحكم في تصفية المحتوى عبر `safetySettings`:

```json
{
  "contents": [...],
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_ONLY_HIGH"
    }
  ]
}
```

## معالجة الأخطاء

| رمز حالة HTTP | المعنى             |
| -------- | -------------- |
| 400      | معلمات الطلب غير صالحة         |
| 401      | فشلت المصادقة، يرجى التحقق من Token |
| 403      | تم اعتراض المحتوى بواسطة عامل تصفية الأمان     |
| 429      | الطلبات متكررة للغاية         |
| 500      | خطأ داخلي في الخادم        |
