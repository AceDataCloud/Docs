ستتناول هذه المقالة واجهة برمجة تطبيقات توليد فيديوهات جمنيس، والتي يمكنها توليد فيديوهات Google Gemini (omni-flash) من خلال إدخال نصوص توجيهية (وصور مرجعية اختيارية).

## عملية التقديم

لاستخدام واجهة برمجة تطبيقات توليد فيديوهات جمنيس، يجب أولاً الذهاب إلى [وحدة التحكم في Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، والاحتفاظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد الانتهاء، سيتم إرجاعك تلقائيًا إلى الصفحة الحالية.

**يمكن استخدام رمز API واحد لاستدعاء جميع خدمات المنصة، دون الحاجة لتقديم طلب منفصل لكل خدمة.** سيتم منحك رصيد مجاني عند التقديم لأول مرة، يمكنك تجربته مجانًا؛ وعند نفاد الرصيد، يمكنك إعادة شحن الرصيد العام في [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [واجهة برمجة تطبيقات توليد فيديوهات جمنيس →](https://platform.acedata.cloud/documents/gemini-videos)

## الاستخدام الأساسي

أولاً، تعرف على طريقة الاستخدام الأساسية، حيث يمكنك إدخال نص التوجيه `prompt`، النموذج `model`، ونسبة العرض إلى الارتفاع `aspect_ratio`، لتوليد الفيديو المقابل.

يمكنك أن ترى هنا أننا قمنا بتعيين رؤوس الطلب، بما في ذلك:

- `accept`: نوع الاستجابة التي ترغب في تلقيها، هنا يتم ملؤها بـ `application/json`، أي بتنسيق JSON.
- `authorization`: مفتاح استدعاء API، يمكنك اختياره مباشرة بعد التقديم.

كما تم تعيين جسم الطلب، بما في ذلك:

- `prompt`: نص توجيهي يصف محتوى الفيديو المراد توليده، **مطلوب**.
- `model`: نموذج توليد الفيديو، حاليًا يدعم فقط `omni-flash`، وهو الافتراضي.
- `aspect_ratio`: نسبة العرض إلى الارتفاع للفيديو المولد، يمكن أن تكون `16:9` (أفقي) أو `9:16` (عمودي)، الافتراضي هو `16:9`.
- `resolution`: دقة الإخراج الاختيارية، يمكن أن تكون `720p` أو `1080p`، الافتراضي هو `720p`.
- `image_urls`: مصفوفة روابط الصور المرجعية الاختيارية، تستخدم لتوجيه توليد الفيديو، سيتم تجاهل العناصر الفارغة. عند استخدام `video_urls` لتحرير الفيديو، يجب أن تكون هذه المعلمة مطلوبة (على الأقل صورة واحدة).
- `video_urls`: مصفوفة روابط الفيديو المرجعية الاختيارية (بحد أقصى 1)، تستخدم **لتحرير الفيديو / مرجع الفيديو**؛ عند تقديمها، يجب تقديم على الأقل صورة واحدة من `image_urls`.
- `callback_url`: عنوان رد الاتصال غير المتزامن، بعد تعيينه، ستعيد واجهة برمجة التطبيقات على الفور `task_id`، وعند الانتهاء من المهمة، سيتم نشر النتائج إلى هذا العنوان.
- `async`: اختياري، إذا تم تعيينه إلى `true`، ستعيد الواجهة على الفور `task_id`، دون الحاجة لتقديم `callback_url`، ثم يمكنك الاستعلام عن النتائج من خلال واجهة استعلام المهام المقابلة.

انقر على زر "Try" لإجراء اختبار، وستكون النتائج مشابهة لما يلي:

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://platform2.cdn.acedata.cloud/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "لقطة سينمائية لقط صغير يطارد فراشة في حديقة مضاءة بأشعة الشمس"
    }
  ],
  "started_at": 1784112953.856,
  "finished_at": 1784113021.328,
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

تتضمن نتيجة العودة عدة حقول، كما هو موضح أدناه:

- `success`: هل كانت طلب توليد الفيديو ناجحة.
- `task_id`: معرف مهمة توليد الفيديو هذه.
- `trace_id`: معرف تتبع الطلب، يستخدم لتحديد المشكلات.
- `data`: قائمة نتائج الفيديو المولد.
  - `id`: المعرف الفريد للفيديو المولد.
  - `video_url`: عنوان رابط الفيديو المولد (`state` يكون `pending` في هذه الحالة `null`).
  - `state`: حالة مهمة توليد الفيديو، يمكن أن تكون `pending` / `succeeded` / `failed`.
  - `aspect_ratio`: نسبة العرض إلى الارتفاع لهذا الفيديو، تتطابق مع معلمات الطلب.
  - `prompt`: النص التوجيهي المستخدم لتوليد هذا الفيديو.

عند العودة المتزامنة، ستتضمن الطبقة العليا أيضًا `started_at`، `finished_at`، `elapsed` (الوقت المستغرق، بالثواني) و `cost` (المبلغ المخصوم، بوحدة الائتمان) وغيرها من الحقول.

نحتاج فقط إلى الحصول على الفيديو المولد من خلال رابط `video_url` في `data`.

الكود المقابل لـ CURL كما يلي:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "لقطة سينمائية لقط صغير يطارد فراشة في حديقة مضاءة بأشعة الشمس",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

الكود المقابل لـ Python كما يلي:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "لقطة سينمائية لقط صغير يطارد فراشة في حديقة مضاءة بأشعة الشمس",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## توليد الفيديو من الصور

إذا كنت ترغب في توليد فيديو بناءً على صور مرجعية، يمكنك تمرير رابط صورة واحدة أو أكثر في `image_urls`، لتوجيه توليد الفيديو:

```json
{
  "prompt": "المرأة تدور ببطء وتبتسم للكاميرا، نسيم لطيف",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3.png"
  ]
}
```

## تحرير الفيديو / فيديو مرجعي (إدخال فيديو، توليد فيديو)

يدعم مباشرة "إدخال مقطع فيديو، توليد مقطع فيديو جديد": في `video_urls`، يمكنك تمرير رابط فيديو مرجعي (بحد أقصى 1)، و**في نفس الوقت**، يجب تقديم على الأقل صورة واحدة في `image_urls` (متطلبات صارمة من المصدر)، ثم استخدم `prompt` لوصف تأثير التحرير المطلوب (تغيير الأسلوب، تغيير المشهد، إضافة أو حذف عناصر، إلخ).

إليك مثال كامل حقيقي - تحويل مقطع فيديو لشاطئ مشمس إلى مشهد شتوي مع تساقط الثلوج، مع الاحتفاظ بتخطيط الشاطئ، وأشجار النخيل، والقارب. يستغرق تحرير الفيديو وقتًا طويلاً (في هذا المثال حوالي 6.5 دقيقة)، لذلك تم تقديمه بشكل غير متزامن باستخدام `async: true`:
```json
{
  "prompt": "حوّل هذه الشاطئ الاستوائي المشمس إلى مشهد شتوي ثلجي مع تساقط كثيف للثلوج وسماء غائمة؛ احتفظ بنفس الشاطئ وأشجار النخيل وتخطيط القارب.",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://platform2.cdn.acedata.cloud/seedance/dd3dc063-3383-4f29-bedc-e771a096758c.mp4"
  ],
  "async": true
}
```

بعد الإرسال، ستعيد الواجهة على الفور `task_id`:

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

بعد ذلك، استخدم `task_id` كـ `id` لاستعلام [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks)، وعند الانتهاء من المهمة يمكنك الحصول على الفيديو الجديد الذي تم إنشاؤه (هذا هو النتيجة الحقيقية لهذا المثال):

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://platform2.cdn.acedata.cloud/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "حوّل هذه الشاطئ الاستوائي المشمس إلى مشهد شتوي ثلجي مع تساقط كثيف للثلوج وسماء غائمة؛ احتفظ بنفس الشاطئ وأشجار النخيل وتخطيط القارب."
    }
  ],
  "started_at": 1784084482.914,
  "finished_at": 1784084877.09,
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

إذا كنت بحاجة إلى نتائج بدقة أعلى، يمكنك تعيين `resolution` إلى `1080p` (مع الحفاظ على بقية المعلمات كما هي).

> ملاحظة: الروابط المستخدمة في المثال هي نتائج حقيقية تم إنشاؤها. **روابط الفيديو والصور التي تم إنشاؤها على المنصة لها فترة صلاحية، وستنتهي صلاحيتها بعد انتهاء المدة المحددة**، يرجى تنزيلها وحفظها في تخزينك الخاص بعد الحصول على النتائج.

> ملاحظة: يجب أن يكون هناك فيديو مرجعي واحد كحد أقصى؛ وعند تقديم `video_urls` يجب تقديم صورة واحدة على الأقل في `image_urls`، وإلا ستظهر لك رسالة خطأ كما يلي:

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (at least one reference image) is required when video_urls is provided."
  }
}
```

## ردود غير متزامنة

تتطلب عملية إنشاء الفيديو بعض الوقت للمعالجة. إذا كنت لا ترغب في الانتظار مع اتصال طويل، يمكنك تمرير `callback_url`، في هذه الحالة ستعيد الواجهة على الفور `task_id`، وعند الانتهاء من المهمة ستقوم بإرسال النتيجة النهائية عبر POST إلى هذا العنوان:

```json
{
  "prompt": "لقطة سينمائية لقط يطارد فراشة في حديقة مضاءة بأشعة الشمس",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

ستكون النتيجة التي تم إرجاعها على الفور كما يلي:

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## استعلام عن نتائج المهمة

إذا كنت قد استخدمت ردود غير متزامنة أو ترغب في استعلام حالة المهمة بشكل نشط، يمكنك استخدام [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) لاستعلام الحالة والنتائج الأخيرة للمهمة بناءً على `task_id`:

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

ستكون النتيجة التي تم إرجاعها عند الانتهاء من المهمة مشابهة لما يلي، هيكل `response.data` متطابق مع الهيكل عند الإنشاء المتزامن (عند الإنشاء، تكون `state` هي `pending`، و`video_url` هي `null`):

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
  "type": "videos",
  "request": {
    "model": "omni-flash",
    "prompt": "تسارع الزمن للغيوم فوق جبال الثلج عند شروق الشمس",
    "aspect_ratio": "16:9",
    "async": true
  },
  "response": {
    "success": true,
    "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
    "data": [
      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
        "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4",
        "state": "succeeded",
        "aspect_ratio": "16:9",
        "prompt": "تسارع الزمن للغيوم فوق جبال الثلج عند شروق الشمس"
      }
    ],
    "elapsed": 96.716,
    "cost": {
      "amount": 1.932,
      "currency": "credit",
      "list_amount": 2.1
    }
  }
}
```

## معالجة الأخطاء

عند حدوث مشكلة في الطلب، ستعيد الواجهة رمز الخطأ المقابل مع الشرح، ومن الأخطاء الشائعة ما يلي:

- `400`: هناك خطأ في معلمات الطلب، مثل عدم وجود `prompt` أو أن قيمة `aspect_ratio` غير صالحة.
- `401`: فشل في التوثيق، الرمز غير صالح أو لا يتطابق مع الواجهة البرمجية.
- `403`: رصيد غير كافٍ، أو تم رفض المحتوى بسبب انتهاك شروط الاستخدام.
- `500`: خطأ داخلي في الخادم أو فشل في التوليد من المصدر.
