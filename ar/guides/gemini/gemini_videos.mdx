تقدم هذه الوثيقة تعليمات دمج واجهة برمجة تطبيقات Gemini Videos Generation، والتي تتيح إنشاء فيديوهات Google Gemini (omni-flash) من خلال إدخال نصوص وصفية (وكذلك صور مرجعية اختيارية).

## عملية التقديم

لاستخدام الواجهة البرمجية، يجب أولاً التقديم للحصول على الخدمة المناسبة من صفحة [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos). بعد الدخول إلى الصفحة، انقر على زر "Acquire" كما هو موضح في الصورة:

![](https://cdn.acedata.cloud/q6ytrc.png)

إذا لم تكن مسجلاً أو مسجلاً دخولك، سيتم توجيهك تلقائيًا إلى صفحة تسجيل الدخول للتسجيل أو تسجيل الدخول، وبعد ذلك ستعود تلقائيًا إلى الصفحة الحالية.

عند التقديم لأول مرة، ستحصل على رصيد مجاني لاستخدام الواجهة البرمجية مجانًا.

## الاستخدام الأساسي

أولاً، تعرف على طريقة الاستخدام الأساسية، حيث يتم إدخال النص الوصفي `prompt`، والنموذج `model`، ونسبة العرض إلى الارتفاع `aspect_ratio` لإنشاء الفيديو المطلوب.

نلاحظ هنا أننا قمنا بإعداد رؤوس الطلب (Request Headers)، والتي تشمل:

- `accept`: نوع تنسيق الاستجابة المرغوب، هنا يتم تعيينه إلى `application/json`، أي تنسيق JSON.
- `authorization`: مفتاح استدعاء الواجهة البرمجية، يمكن اختياره مباشرة بعد التقديم.

كما تم إعداد جسم الطلب (Request Body)، والذي يتضمن:

- `prompt`: نص وصفي لمحتوى الفيديو المراد إنشاؤه، **مطلوب**.
- `model`: نموذج إنشاء الفيديو، حاليًا يدعم فقط `omni-flash`، وهو الافتراضي.
- `aspect_ratio`: نسبة العرض إلى الارتفاع للفيديو، يمكن اختيار `16:9` (أفقي) أو `9:16` (عمودي)، الافتراضي `16:9`.
- `image_urls`: مصفوفة روابط صور (أو فيديوهات) مرجعية اختيارية لتوجيه إنشاء الفيديو، يتم تجاهل العناصر الفارغة.
- `callback_url`: عنوان استدعاء رجعي غير متزامن، عند تعيينه ستُعيد الواجهة البرمجية فورًا `task_id`، وعند الانتهاء من المهمة سيتم إرسال النتيجة عبر POST إلى هذا العنوان.

انقر على زر "Try" لاختبار الطلب، وستحصل على نتيجة مشابهة للتالي:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

تتضمن النتيجة عدة حقول، وهي كما يلي:

- `success`: هل نجح طلب إنشاء الفيديو.
- `task_id`: معرف مهمة إنشاء الفيديو.
- `trace_id`: معرف تتبع الطلب، يستخدم لتشخيص المشكلات.
- `data`: قائمة نتائج الفيديوهات المُنشأة.
  - `id`: المعرف الفريد للفيديو المُنشأ.
  - `video_url`: رابط الفيديو المُنشأ.
  - `state`: حالة مهمة إنشاء الفيديو، يمكن أن تكون `pending` / `succeeded` / `failed`.

كل ما نحتاجه هو الحصول على الفيديو من خلال رابط `video_url` في `data`.

كود CURL المقابل هو:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

كود Python المقابل هو:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## إنشاء فيديو من صورة

إذا كنت ترغب في إنشاء فيديو بناءً على صور مرجعية، يمكنك تمرير رابط أو أكثر في `image_urls` لتوجيه إنشاء الفيديو:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## الاستدعاء الرجعي غير المتزامن

يتطلب إنشاء الفيديو وقت معالجة معين. إذا لم ترغب في الانتظار على اتصال طويل، يمكنك تمرير `callback_url`، عندها ستُعيد الواجهة البرمجية فورًا `task_id`، وعند الانتهاء من المهمة سيتم إرسال النتيجة النهائية عبر POST إلى هذا العنوان:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

النتيجة التي تُعاد فورًا تكون كالتالي:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## استعلام نتائج المهمة

إذا استخدمت الاستدعاء الرجعي غير المتزامن أو أردت الاستعلام عن حالة المهمة بنشاط، يمكنك استخدام [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) للاستعلام عن أحدث حالة ونتيجة المهمة باستخدام `task_id`.

## معالجة الأخطاء

عند حدوث مشكلة في الطلب، ستُعيد الواجهة البرمجية رمز الخطأ مع وصف، والأخطاء الشائعة هي:

- `400`: خطأ في معلمات الطلب، مثل فقدان `prompt` أو قيمة غير صالحة لـ `aspect_ratio`.
- `401`: فشل التوثيق، رمز التوكن غير صالح أو لا يتطابق مع الواجهة البرمجية.
- `403`: رصيد غير كافٍ، أو تم رفض النص الوصفي بسبب مراجعة المحتوى.
- `500`: خطأ داخلي في الخادم أو فشل في التوليد من المصدر الأعلى.
