ستتناول هذه الوثيقة واجهة برمجة تطبيقات توليد فيديوهات جمنيس، والتي يمكنها توليد فيديوهات Google Gemini (omni-flash) من خلال إدخال نصوص توجيهية (وصور مرجعية اختيارية).

## عملية التقديم

لاستخدام واجهة برمجة تطبيقات توليد فيديوهات جمنيس، يجب أولاً الذهاب إلى [وحدة التحكم في Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، والاحتفاظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد الانتهاء، سيتم إرجاعك تلقائيًا إلى الصفحة الحالية.

**يمكن استخدام رمز API واحد لاستدعاء جميع خدمات المنصة، دون الحاجة لتقديم طلب منفصل لكل خدمة.** عند التقديم لأول مرة، ستحصل على رصيد مجاني لتجربته؛ وعند نفاد الرصيد، يمكنك إعادة شحن الرصيد العام في [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [واجهة برمجة تطبيقات توليد فيديوهات جمنيس →](https://platform.acedata.cloud/documents/gemini-videos)

## الاستخدام الأساسي

أولاً، تعرف على طريقة الاستخدام الأساسية، حيث يمكنك إدخال نص التوجيه `prompt`، النموذج `model`، ونسبة العرض إلى الارتفاع `aspect_ratio`، لتوليد الفيديو المقابل.

يمكنك أن ترى هنا أننا قمنا بتعيين رؤوس الطلب، بما في ذلك:

- `accept`: نوع الاستجابة التي ترغب في تلقيها، هنا يتم ملؤها بـ `application/json`، أي بتنسيق JSON.
- `authorization`: مفتاح استدعاء API، يمكنك اختياره مباشرة بعد التقديم.

كما تم تعيين جسم الطلب، بما في ذلك:

- `prompt`: نص توجيهي يصف محتوى الفيديو المراد توليده، **مطلوب**.
- `model`: نموذج توليد الفيديو، حاليًا يدعم فقط `omni-flash`، وهو الافتراضي.
- `aspect_ratio`: نسبة العرض إلى الارتفاع للفيديو المولد، يمكن أن تكون `16:9` (أفقي) أو `9:16` (عمودي)، الافتراضي هو `16:9`.
- `resolution`: دقة الإخراج الاختيارية، يمكن أن تكون `720p` أو `1080p`، الافتراضي هو `720p`.
- `image_urls`: مصفوفة روابط الصور المرجعية الاختيارية، تستخدم لتوجيه توليد الفيديو، سيتم تجاهل العناصر الفارغة. عند استخدام `video_urls` لتحرير الفيديو، يجب أن تكون هذه المعلمة مطلوبة (على الأقل صورة واحدة).
- `video_urls`: مصفوفة روابط الفيديو المرجعية الاختيارية (بحد أقصى 1)، تستخدم **لتحرير الفيديو / مرجع الفيديو**؛ عند تقديمها، يجب تقديم على الأقل صورة واحدة من `image_urls`.
- `callback_url`: عنوان رد الاتصال غير المتزامن، بعد تعيينه، ستعيد API على الفور `task_id`، وعند الانتهاء من المهمة، سيتم إرسال النتائج إلى هذا العنوان.
- `async`: اختياري، إذا تم تعيينه إلى `true`، ستعيد الواجهة على الفور `task_id`، دون الحاجة لتقديم `callback_url`، ثم يمكنك الاستعلام عن النتائج من خلال واجهة استعلام المهام المقابلة.

انقر على زر "Try" لإجراء اختبار، وستكون النتائج مشابهة لما يلي:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

تتضمن النتيجة العائدة عدة حقول، كما يلي:

- `success`: هل كانت طلب توليد الفيديو ناجحة.
- `task_id`: معرف مهمة توليد الفيديو هذه.
- `trace_id`: معرف تتبع الطلب، يستخدم لتحديد المشكلات.
- `data`: قائمة نتائج الفيديو المولد.
  - `id`: المعرف الفريد للفيديو المولد.
  - `video_url`: عنوان رابط الفيديو المولد.
  - `state`: حالة مهمة توليد الفيديو، يمكن أن تكون `pending` / `succeeded` / `failed`.

نحتاج فقط إلى الحصول على الفيديو المولد من عنوان رابط `video_url` في النتيجة.

الكود المقابل لـ CURL كما يلي:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "لقطة سينمائية لقط صغير يطارد فراشة في حديقة مضاءة بأشعة الشمس",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

الكود المقابل لـ Python كما يلي:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "لقطة سينمائية لقط صغير يطارد فراشة في حديقة مضاءة بأشعة الشمس",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## توليد الفيديو من الصور

إذا كنت ترغب في توليد فيديو بناءً على صور مرجعية، يمكنك تمرير رابط صورة واحدة أو أكثر في `image_urls`، لتوجيه توليد الفيديو:

```json
{
  "prompt": "الشخصية تدور ببطء وتبتسم للكاميرا",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## تحرير الفيديو / فيديو مرجعي

يدعم تحرير الفيديوهات الموجودة أو الإشارة إليها مباشرة: يمكنك تمرير رابط فيديو مرجعي في `video_urls` (بحد أقصى 1)، و**في نفس الوقت** تقديم على الأقل صورة مرجعية واحدة في `image_urls` (متطلبات صارمة من المصدر). يمكنك استخدام `prompt` لوصف التأثيرات التحريرية المرغوبة (تغيير النمط، تغيير المشهد، إضافة أو حذف عناصر، إلخ):

```json
{
  "prompt": "إعادة تصميم الفيديو إلى نمط سينمائي أنمي، مع الحفاظ على الحركة",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ],
  "video_urls": [
    "https://cdn.acedata.cloud/example-source.mp4"
  ]
}
```

> ملاحظة: بحد أقصى فيديو مرجعي واحد؛ وعند تقديم `video_urls`، يجب تقديم على الأقل صورة واحدة من `image_urls` (وإلا ستظهر رسالة خطأ في المعلمات).

## رد الاتصال غير المتزامن

تتطلب عملية توليد الفيديو بعض الوقت للمعالجة. إذا كنت لا ترغب في الحفاظ على اتصال طويل في الانتظار، يمكنك تمرير `callback_url`، في هذه الحالة ستعيد API على الفور `task_id`، وعند الانتهاء من المهمة، سيتم إرسال النتائج النهائية إلى هذا العنوان:

```json
{
  "prompt": "لقطة سينمائية لقط صغير يطارد فراشة في حديقة مضاءة بأشعة الشمس",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

ستكون النتيجة المعادة على الفور كما يلي:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## استعلام عن نتائج المهام

إذا كنت قد استخدمت رد الاتصال غير المتزامن أو ترغب في الاستعلام عن حالة المهمة، يمكنك استخدام [واجهة برمجة تطبيقات مهام جمنيس](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) للاستعلام عن الحالة والنتائج الأخيرة للمهمة بناءً على `task_id`.

## معالجة الأخطاء

عند حدوث مشكلة في الطلب، ستعيد API رمز الخطأ المقابل مع الشرح، ومن الأخطاء الشائعة ما يلي:
- `400`：طلب المعلمات غير صحيح، مثل عدم وجود `prompt` أو أن قيمة `aspect_ratio` غير صالحة.
- `401`：فشل في التحقق من الهوية، الرمز المميز غير صالح أو لا يتطابق مع واجهة برمجة التطبيقات.
- `403`：الرصيد غير كاف، أو تم رفض المحتوى بسبب انتهاك سياسة المراجعة.
- `500`：خطأ داخلي في الخادم أو فشل في التوليد من المصدر.
