قدّم مهمة عبر `POST /kling/virtual-try-on`، واستخدم `POST /kling/tasks` الحالي للاستعلام عن حالة مهمة المنصة.

## الإدخال

يجب تقديم صورة product_image واحدة وصورة person_image واحدة بالضبط. تكون keep_face وkeep_pose وkeep_background جميعها true افتراضيًا، ويمكن إيقافها بشكل مستقل. يجب ألا يتجاوز أطول ضلع لصورة الإدخال 2048px، وأن يكون أقصر ضلع أكبر من 300px، وألا يتجاوز حجم الملف 10MB.

فيما يلي مثال على بنية الطلب، يُرجى استبدال عناوين URL للمواد ثم الاستدعاء.

```json
{
  "contents": [
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "person_image",
      "url": "https://your-cdn.example/person.jpg"
    }
  ],
  "async": true
}
```

## النتائج والفوترة

يعيد الوضع المتزامن نتيجة الإنشاء؛ ويعيد الوضع غير المتزامن أولًا `task_id`، وتتضمن نتيجة الإكمال روابط الفيديو أو الصورة في `data` و`usage` المحسوب من جانب الخادم. يُستخدم `callback_url` لإشعار الإكمال؛ ويعيد طلب `watermark=true` إصدارًا بعلامة مائية في الوقت نفسه.

1.12 Credits/صورة، وتُحتسب الرسوم وفقًا للعدد الفعلي للصور الناتجة. تتم تسوية الفيديوهات وفقًا لمدة الإنشاء الفعلية، ولا يمثل السعر الأساسي لكل ثانية قبل الإنشاء السعر الإجمالي للمهمة بالكامل. لا تُفرض رسوم إنشاء على المهام الفاشلة.
