أرسل مهمة عبر `POST /kling/apparel`، واستخدم `POST /kling/tasks` الموجود للاستعلام عن حالة مهمة المنصة.

## الإدخال

قدّم وصفًا للمنتج بحد أقصى 2500 حرف، وفيديو مرجعيًا مدته 5–180 ثانية، و1–5 صور للمنتج. يمكن أيضًا تقديم 1–5 صور لعارض الأزياء، وملف موسيقى خلفية، وتحديد صوت التعليق؛ عند عدم تحديد صوت، يُستخدم التعليق الصوتي الأصلي.

فيما يلي مثال على بنية الطلب، يُرجى استبدال عناوين URL للمواد ثم الاستدعاء.

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "你的商品或口播内容"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## النتائج والفوترة

يعيد الوضع المتزامن نتيجة التوليد؛ أما الوضع غير المتزامن فيعيد `task_id` أولًا، وتتضمن النتيجة المكتملة روابط الفيديو أو الصور في `data` و`usage` المحسوب من الخادم. يُستخدم `callback_url` لإشعار الإكمال؛ ويعيد طلب `watermark=true` إصدارًا بعلامة مائية في الوقت نفسه.

التعليق الصوتي الأصلي: 1.82 Credits/ثانية لدقة 720p، و2.38 Credits/ثانية لدقة 1080p؛ التعليق الصوتي المحدد: 2.38 Credits/ثانية لدقة 720p، و2.8 Credits/ثانية لدقة 1080p. تتم تسوية تكلفة الفيديو وفقًا لمدة التوليد الفعلية، ولا يمثل السعر الأساسي لكل ثانية قبل التوليد السعر الإجمالي للمهمة بأكملها. لا تُفرض رسوم توليد على المهام الفاشلة.
