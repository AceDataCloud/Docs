أرسل مهمة عبر `POST /kling/video-commerce`، واستخدم `POST /kling/tasks` الموجود للاستعلام عن حالة مهمة المنصة.

## الإدخال

ارفع صورة لشخص وحدد voice_id، أو استخدم avatar_id مُعدًا مسبقًا (وهما متنافيان، ولا يمكن تحديد voice_id بشكل منفصل للشخصية المُعدة مسبقًا). يجب توفير speech_script لا يتجاوز 2000 حرف. عند توفير معلومات المنتج، يلزم وجود ref_image واحدة على الأقل وgoods_title واحد؛ لا يدعم التعليق الصوتي للمنتجات speech_rate. يدعم التعليق الصوتي العادي للشخصيات سرعة كلام بمقدار 0.8 أو 1.0 أو 1.2 مرة.

فيما يلي مثال على بنية الطلب، يُرجى استبدال عناوين URL للمواد قبل الاستدعاء.

```json
{
  "contents": [
    {
      "type": "avatar_image",
      "url": "https://your-cdn.example/person.jpg"
    },
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "منتجك أو محتوى التعليق الصوتي"
    },
    {
      "type": "speech_script",
      "text": "منتجك أو محتوى التعليق الصوتي"
    }
  ],
  "settings": {
    "resolution": "720p",
    "voice_id": "male_calm_informative"
  },
  "async": true
}
```

## النتائج والفوترة

يعيد الوضع المتزامن نتيجة التوليد؛ ويعيد الوضع غير المتزامن `task_id` أولًا، وتتضمن النتيجة المكتملة روابط الفيديو أو الصور في `data` و`usage` المحسوب من الخادم. يُستخدم `callback_url` لإشعار الإكمال؛ ويعيد طلب `watermark=true` إصدارًا بعلامة مائية في الوقت نفسه.

التعليق الصوتي العادي للشخصيات: تبلغ التكلفة في 720p مقدار 1.4 Credits/ثانية، وفي 1080p مقدار 1.68 Credits/ثانية؛ تعليق المنتجات الصوتي: تبلغ التكلفة في 720p مقدار 1.96 Credits/ثانية، وفي 1080p مقدار 2.24 Credits/ثانية. تتم تسوية تكلفة الفيديو وفقًا للمدة الفعلية المُولدة، ولا يمثل السعر الأساسي لكل ثانية قبل التوليد السعر الإجمالي للمهمة بأكملها. لا تُفرض رسوم توليد على المهام الفاشلة.
