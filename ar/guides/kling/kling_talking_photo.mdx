بضغطة زر واحدة يمكنك تحويل **صورة + مقطع صوتي** إلى "فيديو يتحدث". يتم تنفيذ خطوتين تلقائيًا داخل الخدمة: أولاً، باستخدام image2video لجعل الصورة تتحرك، ثم باستخدام lip-sync لمزامنة الشفاه مع الصوت. كل ما عليك هو استدعاء **مرة واحدة**.

- **عنوان الواجهة**: `POST https://api.acedata.cloud/kling/talking-photo`
- **التسعير**: حسب المدة، 5 ثواني **16.45 Credits**، 10 ثواني **30.45 Credits** (= سعر دمج image2video + lip-sync)

## رأس الطلب

| الحقل              | القيمة                   |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## معلمات الطلب

| المعلمة          | النوع      | إلزامي  | الافتراضي              | الشرح                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | نعم   | —                   | URL عام لصورة الشخص، يُفضل أن تكون واضحة ووجهها أمامي                    |
| `audio_url`    | string  | نعم   | —                   | URL عام للصوت (بصيغة .mp3/.wav/.m4a/.aac، ≤5MB) |
| `prompt`       | string  | لا    | —                   | كلمات توجيه للحركة/التعبيرات في مرحلة تحريك الصورة                      |
| `model`        | string  | لا    | `kling-v2-1-master` | نموذج Kling المستخدم في تحريك الصورة                     |
| `duration`     | integer | لا    | `5`                 | مدة الفيديو (5 أو 10 ثواني)                        |
| `mode`         | string  | لا    | `pro`               | جودة التحريك (std/pro)                        |
| `callback_url` | string  | لا    | —                   | إذا تم تمريره أو `async=true` سيتم إرجاع task_id بشكل غير متزامن        |
| `async`        | boolean | لا    | `false`             | وضع غير متزامن، بالتعاون مع `/kling/tasks` للاستعلام أو الاستجابة          |

## مثال على الطلب

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## مثال على الاستجابة

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "source_video_url": "https://platform2.cdn.acedata.cloud/kling/163ac822-1a15-4f5e-a2eb-465154df15af.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| الحقل                 | الشرح                        |
| ------------------ | ------------------------- |
| `video_url`        | الفيديو النهائي المتحدث (تم حفظه على منصة CDN)      |
| `source_video_url` | الفيديو المتحرك الوسيط (نتيجة image2video) |
| `video_id`         | معرف فيديو القابلة للتحدث                   |

## ملاحظات

- يُفضل أن تكون الصورة واضحة ووجهها أمامي، لشخص واحد.
- يُفضل ألا تتجاوز مدة الصوت مدة الفيديو (5s/10s).
- يتم احتساب الرسوم عند النجاح؛ فشل التحقق من المعلمات (4xx) لا يتم احتسابه.
- يستغرق التوليد حوالي 4–6 دقائق (خطوتين)، يُفضل استخدام `async=true` + `/kling/tasks` للاستعلام.
