title: "واجهة برمجة تطبيقات مزامنة الشفاه لكيلينغ (Kling Lip Sync)"
description: "Kling video generation API guide - Ace Data Cloud"
---

اجعل مقطع فيديو **كيلينغ موجود مسبقًا** (5 ثوانٍ أو 10 ثوانٍ) "يتحدث" بناءً على الصوت أو النص — أي مزامنة الشفاه (Lip Sync). بالتعاون مع `/kling/videos` الخاص بـ `image2video` (لجعل الصور تتحرك)، يمكن ربطها لتكوين عملية كاملة لـ "**الصور الناطقة / التقديم الرقمي**".

> هذه الواجهة هي تغليف بسيط خطوة واحدة مقدم من AceDataCloud، موجهة لسيناريوهات شائعة تعتمد على الصوت/النص؛ وليست نسخة طبق الأصل من واجهة كيلينغ الرسمية متعددة الخطوات "التعرف على الوجه → مزامنة الشفاه المتقدمة". يرجى الاعتماد على جدول المعلمات في هذه الصفحة.

- **عنوان الواجهة**: `POST https://api.acedata.cloud/kling/lip-sync`
- **صيغة الطلب**: `application/json`
- **صيغة الاستجابة**: `application/json`
- **التكلفة**: 2.45 رصيد لكل استدعاء ناجح (ثابت)

## رؤوس الطلب (Request Headers)

| الحقل             | القيمة                 | الشرح                                               |
| --------------- | ------------------- | ------------------------------------------------ |
| `authorization` | `Bearer ${API_KEY}` | مفتاح API الخاص بك، [رابط الحصول عليه](https://platform.acedata.cloud) |
| `content-type`  | `application/json`  | صيغة جسم الطلب                                        |
| `accept`        | `application/json`  | صيغة الاستجابة                                       |

## معلمات الطلب (Request Body)

| المعامل            | النوع     | إلزامي | الافتراضي | الشرح                                                                                                                       |
| ---------------- | ------- | --- | ------- | ------------------------------------------------------------------------------------------------------------------------ |
| `mode`           | string  | نعم  | —       | وضع التوليد. القيم: `audio2video` (مدفوع بالصوت)، `text2video` (مدفوع بالنص)                                                                           |
| `video_id`       | string  | اختياري (واحد من اثنين) | —       | معرف فيديو كيلينغ المُنتج (مثل `video_id` الناتج من `/kling/videos` الخاص بـ image2video). **يدعم فقط فيديوهات 5 ث أو 10 ث التي تم إنشاؤها خلال 30 يومًا**. لا يمكن إرسال `video_id` و `video_url` معًا |
| `video_url`      | string  | اختياري (واحد من اثنين) | —       | رابط فيديو متاح على الإنترنت. القيود: `.mp4`/`.mov`، ≤100 ميجابايت، مدة 2–10 ثوانٍ، دقة 720p/1080p فقط، أبعاد 720–1920 بكسل. لا يمكن إرسال `video_url` و `video_id` معًا                                  |
| `audio_url`      | string  | مشروط | —       | رابط تحميل الصوت المحرك، مطلوب عند `audio2video` مع `audio_type=url`. الصيغ: `.mp3`/`.wav`/`.m4a`/`.aac`، ≤5 ميجابايت                                     |
| `audio_type`     | string  | غير إلزامي | `url`   | طريقة نقل الصوت. القيم: `url`، `file` (تعمل عند `audio2video`)                                                                                |
| `audio_file`     | string  | مشروط | —       | ملف الصوت بصيغة Base64، مطلوب عند `audio_type=file`. نفس الصيغ والقيود أعلاه، ≤5 ميجابايت                                                                             |
| `text`           | string  | مشروط | —       | النص المراد قراءته، مطلوب عند `text2video`، **بحد أقصى 120 حرفًا**                                                                                     |
| `voice_id`       | string  | مشروط | —       | معرف الصوت، مطلوب عند `text2video`                                                                                                   |
| `voice_language` | string  | غير إلزامي | `zh`    | لغة الصوت. القيم: `zh`، `en` (تعمل عند `text2video`)                                                                                      |
| `voice_speed`    | float   | غير إلزامي | `1.0`   | سرعة الكلام، النطاق من `0.8` إلى `2.0` بدقة عشرية واحدة (تعمل عند `text2video`)                                                                              |
| `callback_url`   | string  | غير إلزامي | —       | عنوان رد الاتصال. عند تمرير هذا أو `async=true` يكون الوضع **غير متزامن**: يعيد فورًا `task_id`، ويتم رد الاتصال عند الانتهاء                                                                 |
| `async`          | boolean | غير إلزامي | `false` | هل الوضع غير متزامن. عند `true` يعيد فورًا `task_id`، ويستخدم مع `/kling/tasks` للاستعلام أو رد الاتصال عبر `callback_url`                                                      |

## أمثلة على الطلب

### 1) مدفوع بالصوت (audio2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2) مدفوع بالنص (text2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "أخي، لم نلتق منذ زمن طويل، أنا بخير، اعتنِ بنفسك جيدًا.",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## مثال على الاستجابة (نجاح متزامن)

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| الحقل         | النوع      | الشرح                                         |
| ----------- | ------- | ------------------------------------------ |
| `success`   | boolean | هل كانت العملية ناجحة                           |
| `task_id`   | string  | معرف المهمة الحالي (يمكن استخدامه للاستعلام عبر `/kling/tasks`)             |
| `video_id`  | string  | معرف فيديو كيلينغ الناتج (يمكن استخدامه كمدخل في `extend`/`lip-sync` لاحقًا) |
| `video_url` | string  | رابط فيديو التحدث الناتج (مخزن على CDN الخاص بالمنصة، صالح لفترة طويلة)              |
| `duration`  | string  | مدة الفيديو (بالثواني)                                    |
| `state`     | string  | حالة المهمة: `succeed` / `failed`                  |

## الوضع غير المتزامن والاستعلام

عند تمرير `callback_url` أو `async: true`، تعيد الواجهة **فورًا** `task_id`؛ بعدها يمكن:

- **الاستعلام الدوري**: `POST /kling/tasks`، الجسم `{ "action": "retrieve", "id": "<task_id>" }` (مجاني)
- **رد الاتصال**: عند الانتهاء، يتم إرسال النتيجة عبر POST إلى `callback_url` الخاص بك

## العملية الكاملة: الصور الناطقة (image2video → lip-sync)
```bash
# الخطوة 1: جعل الصورة تتحرك، والحصول على video_id
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"look at camera, natural","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# الخطوة 2: مزامنة الشفاه مع الصوت
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"}'
# → { "video_url": "https://platform2.cdn.acedata.cloud/kling/....mp4", ... }
```

## استجابة الخطأ

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "one of video_id or video_url is required" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | code                    | المعنى                                               |
| ---- | ----------------------- | -------------------------------------------------- |
| 400  | `bad_request`           | نقص أو خطأ في المعلمات (مثل عدم تمرير mode، تعارض video و audio، النص يتجاوز 120 حرف) |
| 401  | `authorization_missing` | مفتاح API مفقود أو غير صالح                               |
| 403  | `forbidden`             | تم حظر المحتوى بواسطة نظام التحكم في المخاطر               |
| 429  | `too_many_requests`     | قيود تزامن من المصدر، يرجى المحاولة لاحقًا                  |
| 500  | `api_error`             | خطأ من المصدر أو داخلي                                   |

## ملاحظات

- يجب أن يكون `video_id` فيديو قابل للحركة تم إنشاؤه خلال **30 يومًا**، ومدة **5 ثوانٍ أو 10 ثوانٍ**؛ وإلا يرجى استخدام `video_url` لتمرير فيديو يتوافق مع القيود.
- يُنصح بأن يكون الفيديو المدخل **واضحًا، وجه واحد**، حيث تكون تأثيرات الشفاه أفضل.
- يجب أن تتطابق مدة الصوت/النص مع مدة الفيديو (لا يتجاوز الصوت طول الفيديو).
- يتم احتساب الرسوم عند **النجاح** (2.45 Credits/مرة)؛ فشل التحقق من المعلمات (4xx) لا يتم احتسابه.
