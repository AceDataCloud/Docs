قم بإرسال المهمة عبر `POST /kling/goods-studio`، واستخدم `POST /kling/tasks` الموجود للاستعلام عن حالة مهام المنصة.

## الإدخال

وفّر 1–5 صور للمنتج وعنوان منتج بحد أقصى 200 حرف؛ وصف المنتج اختياري، وبحد أقصى 2000 حرف. يمكن أن تكون المدة 15 أو 30 أو 60 ثانية.

فيما يلي مثال على بنية الطلب، يرجى استبدال عنوان URL للمادة ثم الاستدعاء.

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "عنوان منتجك أو محتوى التعليق الصوتي"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## النتائج والفوترة

يعيد الوضع المتزامن نتيجة التوليد؛ ويعيد الوضع غير المتزامن `task_id` أولًا، وتتضمن النتيجة المكتملة روابط الفيديو أو الصور في `data` و`usage` المحسوب من جانب الخادم. يُستخدم `callback_url` لإشعار الإكمال؛ ويعيد طلب `watermark=true` إصدارًا بعلامة مائية في الوقت نفسه.

720p: ‏2.38 Credits/ثانية؛ 1080p: ‏2.8 Credits/ثانية. تتم تسوية تكلفة الفيديو حسب مدة التوليد الفعلية، ولا يمثّل السعر الأساسي لكل ثانية قبل التوليد السعر الإجمالي للمهمة بالكامل. لا تُفرض رسوم توليد على المهام الفاشلة.
