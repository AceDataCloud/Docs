يدعم `POST https://api.acedata.cloud/wan/videos` في الوقت نفسه نماذج Wan 2.6 الحالية و`wan3.0-video`. يتعرّف Wan 3 تلقائيًا على وضع النص أو الإطارين الأول والأخير أو المواد المرجعية وفقًا لـ `media`.

## تحويل النص إلى فيديو في Wan 3

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "A paper boat drifting through a neon city at night",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

يدعم Wan 3 أعدادًا صحيحة من 2 إلى 30 ثانية أو مدة ذكية `-1`، ودرجات الدقة هي `480P` و`720P` و`1080P`.

## مرجع متعدد الوسائط

```json
{
  "model": "wan3.0-video",
  "prompt": "Create a cinematic product reveal",
  "media": [
    {"type":"first_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"},
    {"type":"last_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460-a2a2c1afbf39.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

يدعم `media.type`:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

لا يمكن استخدام وضع الإطارين الأول والأخير ووضع المواد المرجعية معًا. تتم تسوية الفيديوهات المرجعية في النهاية وفقًا لإجمالي ثواني فيديو الإدخال الفعلية وثواني فيديو الإخراج الناجح؛ ولا تزيد مدخلات النصوص والصور والصوت من ثواني الفيديو.

## السعر الرسمي القياسي

| 720P  | $0.10/ثانية |
| 1080P | $0.20/ثانية |

## التوافق مع Wan 2.6

تستمر متغيرات `wan2.6-t2v` و`wan2.6-i2v` و`wan2.6-r2v` وflash الحالية في استخدام معلمات مثل `action` و`image_url` و`reference_video_urls`، دون تغيير مسار الاستدعاء.

## عدم التزامن والنتائج

بعد تعيين `async: true`، يتم الحصول على `task_id` فورًا، ويتم الحصول على الحالة النهائية عبر `/wan/tasks`. سيتم نقل الفيديوهات الناجحة إلى AceDataCloud CDN، وستُعاد قيمة usage وcost الفعلية في الاستجابة.
