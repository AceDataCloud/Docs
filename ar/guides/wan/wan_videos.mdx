`POST https://api.acedata.cloud/wan/videos` تدعم كل من نموذج Wan 2.6 الحالي و `wan3.0-video`. يقوم Wan 3 بالتعرف التلقائي على النصوص، والإطارات الأولى والأخيرة أو نمط المواد المرجعية بناءً على `media`.

## Wan 3 توليد الفيديو من النص

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "قارب ورقي ينجرف عبر مدينة نيون في الليل",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

يدعم Wan 3 مدة تتراوح بين 2–30 ثانية كأعداد صحيحة أو `-1` كمدة ذكية، والدقة هي `480P`، `720P`، `1080P`.

## المواد المرجعية المتعددة

```json
{
  "model": "wan3.0-video",
  "prompt": "إنشاء عرض سينمائي للمنتج",
  "media": [
    {"type":"first_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"},
    {"type":"last_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

يدعم `media.type`:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

لا يمكن استخدام نمط الإطارات الأولى والأخيرة مع نمط المواد المرجعية معًا. يتم احتساب الفيديو المرجعي بناءً على عدد ثواني الفيديو المدخل الفعلي بالإضافة إلى عدد ثواني الفيديو الناتج؛ المدخلات النصية والصورية والصوتية لا تزيد من عدد ثواني الفيديو.

## الأسعار الرسمية القياسية

| الدقة   |      السعر |
| ----- | ------: |
| 480P  | $0.05/ثانية |
| 720P  | $0.10/ثانية |
| 1080P | $0.20/ثانية |

## التوافق مع Wan 2.6

تستمر النماذج الحالية `wan2.6-t2v`، `wan2.6-i2v`، `wan2.6-r2v` مع متغيرات الفلاش في استخدام معلمات مثل `action`، `image_url`، `reference_video_urls`، ولا يتغير مسار الاستدعاء.

## غير متزامن والنتائج

بعد تعيين `async: true`، ستحصل على `task_id` على الفور، ويمكنك الحصول على الحالة النهائية من خلال `/wan/tasks`. سيتم تخزين الفيديو الناجح في CDN الخاص بـ AceDataCloud، وسيتم إرجاع الاستخدام الحقيقي والتكلفة في الاستجابة.
