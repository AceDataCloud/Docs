مايسترو هو واجهة إنتاج فيديو **مستندة إلى الوكيل**: يمكنك استخدام جملة طبيعية `prompt` لوصف الفيديو الذي تريده (يمكنك اختيار إرفاق صور / فيديوهات / صوتيات مرجعية باستخدام `file_urls`)، وسيقوم "مخرج الذكاء الاصطناعي" تلقائيًا بإكمال اختيار الموضوع، كتابة السيناريو، توليد الصور، التعليق الصوتي، الموسيقى، التركيب والتصيير، وفي النهاية إنتاج الفيديو مع الترجمة وتحميله على CDN.

ستتناول هذه المقالة بالتفصيل تعليمات دمج واجهة برمجة تطبيقات توليد الفيديو من مايسترو، لمساعدتك على دمجها بسرعة واستغلال قدراتها بشكل كامل.

هذه واجهة **مهام غير متزامنة**: بعد الإرسال، سيتم إرجاع `task_id` على الفور، ثم يمكنك الاستعلام عن النتائج من خلال [واجهة برمجة تطبيقات استعلام مهام مايسترو](development_maestro_tasks.md) (`POST /maestro/tasks`) (الاستعلام مجاني ولا يتم احتساب رسوم). للاستمرار في التكرار على فيديو موجود، يمكنك استخدام `action: remix` / `edit` / `extend` مع `ref_task_id`.

## عملية التقديم

لاستخدام واجهة برمجة تطبيقات توليد الفيديو من مايسترو، يجب أولاً الذهاب إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، احتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد الانتهاء، سيتم إرجاعك تلقائيًا إلى الصفحة الحالية.

**يمكن استخدام رمز API واحد لاستدعاء جميع خدمات المنصة، دون الحاجة لتقديم طلب لكل خدمة على حدة.** عند التقديم لأول مرة، ستحصل على رصيد مجاني لتجربته؛ وعند نفاد الرصيد، يمكنك إعادة شحن الرصيد العام في [لوحة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [واجهة برمجة تطبيقات توليد الفيديو من مايسترو →](https://platform.acedata.cloud/documents/maestro-videos)

## الاستخدام الأساسي

`POST https://api.acedata.cloud/maestro/videos`

أبسط طريقة للاستخدام تتطلب فقط إدخال جملة طبيعية `prompt`، وسيقوم مخرج الذكاء الاصطناعي بتحديد السيناريو، الصور، التعليق الصوتي والمونتاج تلقائيًا. هنا سنتعرف على رؤوس الطلب وجسم الطلب الذي يجب إعداده.

**رؤوس الطلب** تشمل:

- `accept`: نوع الاستجابة التي ترغب في تلقيها، هنا يتم إدخال `application/json`، أي بتنسيق JSON.
- `authorization`: مفتاح استدعاء API، يمكنك اختياره مباشرة بعد التقديم.
- `content-type`: تنسيق جسم الطلب، هنا يتم إدخال `application/json`.

**جسم الطلب** يتضمن بشكل رئيسي:

- `prompt`: وصف الفيديو الذي تريد إنشاؤه بلغة طبيعية (الموضوع، ما يجب عرضه، الأسلوب، الجمهور).
- `langs`: مصفوفة اللغات الناتجة، مثل `["zh-cn", "en"]`، الافتراضي هو `["zh-cn"]`.
- `aspect`: نسبة العرض إلى الارتفاع، `9:16` (افتراضي) / `16:9` / `1:1`.
- `duration`: الطول المستهدف (بالثواني)، الافتراضي 30.

جميع حقول جسم الطلب موضحة في الجدول أدناه:

| الحقل            | النوع       | إلزامي  | الشرح                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | نعم   | وصف الفيديو الذي تريد إنشاؤه بلغة طبيعية (الموضوع، ما يجب عرضه، الأسلوب، الجمهور). السيناريو، الصور، التعليق الصوتي، والمونتاج يتم تحديدها بواسطة الذكاء الاصطناعي.                                                                                                                                                                             |
| `action`      | string   | لا    | `generate` (افتراضي، لإنشاء فيديو جديد) / `remix` / `edit` / `extend` (للتكرار على فيديو موجود، يجب استخدام `ref_task_id`).                                                                                                                                                |
| `ref_task_id` | string   | لا    | يجب ملؤه عند كون `action` هو remix / edit / extend: `task_id` للتاريخ الذي يتم استخدامه كنقطة انطلاق.                                                                                                                                                                   |
| `file_urls`   | string[] | لا    | وسائل الإعلام المرجعية (صور / فيديوهات / صوتيات URL)، مثل صور المنتجات، الشعار، أو مقاطع المواد التي تحتاج إلى إضافة ترجمات.                                                                                                                                                                             |
| `langs`       | string[] | لا    | اللغات الناتجة، مثل `["zh-cn", "en"]`، الافتراضي هو `["zh-cn"]`. الأولى هي اللغة الرئيسية؛ لكل لغة إضافية، يتم إعادة استخدام الصور، مع إضافة التعليق الصوتي + التصيير، **كل لغة إضافية +6 نقاط**.                                                                                                                                          |
| `aspect`      | string   | لا    | `9:16` (افتراضي) / `16:9` / `1:1` (نسبة العرض إلى الارتفاع، قد يقوم الذكاء الاصطناعي بتعديلها بناءً على `prompt`).                                                                                                                                                                         |
| `duration`    | int      | لا    | الطول المستهدف (بالثواني، **1–600**، أي بحد أقصى 10 دقائق)، الافتراضي 30. **يتم احتساب الرسوم بناءً على الطول الفعلي للفيديو**، كلما زاد الطول زادت التكلفة (انظر الرسوم أدناه).                                                                                                                                                                  |
| `quality`     | string   | لا    | مستوى الإنتاج (مضاعف يؤثر على سعر الطول): `draft` (معاينة سريعة، حوالي **0.5×** من المستوى القياسي) / `standard` (افتراضي، متوازن، **1×**) / `premium` (أكثر دقة، وأكثر تميزًا، يستغرق وقتًا أطول، حوالي **2×** من المستوى القياسي).                                                                                                             |
| `scenario`    | string   | لا    | تلميح نوع الفيديو (مجرد تلميح، لا يزال مخرج الذكاء الاصطناعي يحدد الهيكل النهائي): `auto` (افتراضي) / `narrated` (صور حقيقية متعددة المشاهد + تعليق + بطاقة بيانات) / `drama` (شخصيات + حوار قصير) / `avatar` (شخصية رقمية / تعليق، يجب استخدام `file_urls` لإرسال الصورة) / `motion` (نصوص متحركة / بيانات / تأثيرات الشعار) / `slideshow` (عرض تقديمي / عرض).                               |
| `style`       | string   | لا    | إعدادات الأسلوب البصري: `auto` (افتراضي) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`، كما يقبل نصوص حرة كإشارات ناعمة. لا يغير التوجيه. |
| `voice`       | string   | لا    | نغمة التعليق الصوتي (غير مرتبطة باللغة، تعمل عبر اللغات): `auto` (افتراضي) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`.                                    |

دعونا نوضح ذلك من خلال مثال محدد. لنفترض أننا نريد إنشاء فيديو قصير علمي ثنائي اللغة (الصينية والإنجليزية)، عمودي، مدته 20 ثانية، سيكون كود CURL المقابل كما يلي:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn", "en"],
  "aspect": "9:16",
  "duration": 20
}'
```

الكود المقابل بلغة بايثون كما يلي:
```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "استخدم 20 ثانية لشرح ما هو قاعدة بيانات المتجهات، مناسب للجمهور بدون خلفية، وأنهى بجملة للتذكر",
    "langs": ["zh-cn", "en"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

عند النقر على التشغيل، يمكنك أن تجد أنك ستحصل على نتيجة على الفور، كما يلي:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

تقديم حقول نتيجة العودة كما يلي:

- `success`: هل تم تقديم المهمة بنجاح.
- `task_id`: معرف مهمة إنشاء الفيديو، استخدمه لاحقًا للاستعلام عن النتائج عبر [API استعلام مهام Maestro](development_maestro_tasks.md).
- `trace_id`: معرف تتبع الطلب، يمكن تقديمه للدعم الفني لتحديد موقع المشكلة.

نظرًا لأن إنتاج الفيديو يستغرق وقتًا طويلاً، فإن الواجهة هنا **ترجع `task_id` على الفور**، ولن تنتظر حتى يكتمل عرض الفيديو. بعد ذلك، تحتاج إلى استخدام `task_id` للاستعلام عن النتائج، انظر قسم "الحصول على النتائج".

## تحديد نوع الفيديو والأسلوب (scenario / style)

عند عدم تمرير `scenario`، يتم تحديده تلقائيًا بواسطة الذكاء الاصطناعي (يعادل `auto`)؛ إذا كنت ترغب في تثبيت الفيديو على نوع معين، يمكنك تمرير ذلك بشكل صريح. على سبيل المثال، لإنشاء **دراما قصيرة عمودية**، يمكنك تحديد المحتوى كما يلي:

- `scenario`: نوع الفيديو، هنا يتم تعيينه إلى `drama` (دراما قصيرة مع شخصيات + حوار).
- `style`: الأسلوب البصري، هنا يتم تعيينه إلى `cinematic` (جودة سينمائية).

كود CURL الخاص بمثال التعبئة كما يلي:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "شخصان يتشاركان السكن يتشاجران بسبب قطة ثم يتصالحان، مع ثلاثة مشاهد من التحولات، النهاية دافئة",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

طرق التوافق الشائعة:

- دراما قصيرة: `scenario: "drama"` (شخصيات + حوار).
- إنسان رقمي / تعليق صوتي: `scenario: "avatar"`، واستخدم `file_urls` لتمرير صورة شخصية.
- نصوص ديناميكية / رسوم متحركة للبيانات: `scenario: "motion"`؛ عرض تقديمي / عرض: `scenario: "slideshow"`.
- `style` هو إعداد الأسلوب البصري (مثل `modern` / `neon` / `luxury`)، لا يغير النوع، بل يؤثر فقط على التجربة البصرية.
- `voice` يستخدم لتحديد نغمة التعليق الصوتي (مثل `warm-female` / `deep-male`)، غير مرتبط باللغة، ويعمل عبر اللغات.

نتيجة العودة تتوافق مع "الاستخدام الأساسي"، حيث يتم أيضًا إرجاع `task_id` على الفور.

## إخراج متعدد اللغات

قم بتمرير عدة لغات في `langs` للحصول على إصدارات متعددة اللغات مرة واحدة. الأولى هي اللغة الرئيسية، وبعد ذلك، ستقوم **إعادة استخدام نفس مجموعة المشاهد**، مع إضافة التعليق الصوتي + العرض، لذلك **كل لغة إضافية تضيف فقط +6 نقاط**. مثال:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "قدم منتج خدمة العملاء الذكي لدينا، مع تسليط الضوء على 3 نقاط رئيسية",
  "langs": ["zh-cn", "en", "ja"],
  "aspect": "16:9",
  "duration": 30
}'
```

عند الانتهاء من المهمة، ستتوافق كل لغة مع `variant` في النتيجة (انظر [API استعلام مهام Maestro](development_maestro_tasks.md)).

## التكرار على فيديو موجود (remix / edit / extend)

قم بتمرير `action` ومعرف المهمة السابقة `ref_task_id`، يمكنك إجراء تعديلات طفيفة على المشروع الأصلي (مثل "تغيير عنوان المشهد الثاني" أو "تغيير التعليق الصوتي" أو "تعتيم الصورة بشكل عام"). التعديلات الصغيرة سريعة، والتعديلات الكبيرة ستحتاج إلى إعادة العمل:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "استبدل عنوان البداية بجملة أكثر تأثيرًا، واجعل الألوان أكثر ظلمة"
}'
```

- `remix`: إعادة تقديم الفيديو الأصلي (مع الحفاظ على الموضوع، وتعديل العرض).
- `edit`: إجراء تعديلات دقيقة على جزء محدد (مثل تغيير العنوان، تغيير التعليق الصوتي، تعديل الألوان).
- `extend`: توسيع المحتوى بناءً على الفيديو الأصلي.

نتيجة العودة هي أيضًا إرجاع `task_id` جديد على الفور، استخدمه للاستعلام للحصول على النسخة المعدلة.

## الحصول على النتائج

نظرًا لأن إنتاج الفيديو يستغرق وقتًا طويلاً، فإن هذه الواجهة تعيد `task_id` على الفور بعد التقديم، تحتاج إلى استخدامه للاستعلام عبر [API استعلام مهام Maestro](development_maestro_tasks.md):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

عند الانتهاء من المهمة، ستعيد معلومات الفيديو (كل لغة تتوافق مع `variant`). ستشهد `status` مراحل `pending → planning → producing → succeeded` (أو `failed`)، **الاستعلام مجاني، ولا يستهلك النقاط**. يرجى الرجوع إلى [إرشادات تكامل API استعلام مهام Maestro](development_maestro_tasks.md) للحصول على تنسيق الاستجابة الكامل واستعلام القائمة التاريخية.

## الفوترة

**يتم الفوترة بعد إكمال المهمة بناءً على الفيديو الناتج الفعلي، ولا يتم خصم الرسوم عن المهام الفاشلة.** يتم الفوترة بناءً على طول الفيديو الناتج الفعلي وعدد اللغات الناتجة الفعلي - على سبيل المثال، إذا طلبت 600 ثانية ولكن الفيديو الناتج كان 50 ثانية، فسيتم الفوترة فقط على حوالي 50 ثانية؛ إذا لم يتم إنتاج لغة معينة في النهاية، فلن يتم فرض رسوم إضافية على تلك اللغة. تقديم المهمة نفسها لا يتم فوترة بشكل منفصل (النتائج يمكن الاستعلام عنها مجانًا عبر `/maestro/tasks`).

تقدير النقاط لفيديو واحد يمكن أن يكون تقريبيًا وفقًا للصيغة التالية:

```
النقاط ≈ 0.85 × طول الفيديو بالثواني × مضاعف الجودة × مضاعف المشهد + 6 × max(عدد اللغات - 1, 0)
```

- مضاعف الجودة: `draft` 0.5× / `standard` 1× (افتراضي) / `premium` 2×.
- مضاعف المشهد: `drama` 1.35× / `avatar` 1.15× / غير ذلك 1×.

كمثال على الجودة القياسية، غير دراما قصيرة / إنسان رقمي، ولغة واحدة، فإن النقاط التقريبية لطول الفيديو الناتج ستكون كما يلي:
| مدة الفيديو                     | نقاط المعيار |
| --------------------------- | ----- |
| 30 ثانية                     | 25.5  |
| 60 ثانية                     | 51    |
| 120 ثانية (دقيقتان)            | 102   |
| 300 ثانية (5 دقائق)            | 255   |
| 600 ثانية (10 دقائق، الحد الأقصى) | 510   |
| لكل لغة إضافية (`langs` أكثر من 1) | +6    |
| الاستطلاع على `/maestro/tasks` | مجاني    |

## معالجة الأخطاء

عند استدعاء واجهة برمجة التطبيقات، إذا واجهت خطأ، ستقوم واجهة برمجة التطبيقات بإرجاع رمز الخطأ والمعلومات المناسبة. على سبيل المثال:

- `400 invalid_request` : طلب غير صالح، ربما بسبب فقدان `prompt` أو معلمات غير صالحة.
- `401 invalid_token` : غير مصرح، رمز تفويض غير صالح أو مفقود.
- `403 forbidden` : محظور، رصيد غير كافٍ أو وصول غير مصرح به.
- `429 too_many_requests` : عدد كبير جدًا من الطلبات، لقد تجاوزت الحد الأقصى لمعدل الطلبات.
- `500 api_error` : خطأ في الخادم الداخلي، حدث خطأ ما على الخادم.

### مثال على استجابة الخطأ

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## الخاتمة

من خلال هذه الوثيقة، لقد تعرفت على كيفية استخدام واجهة برمجة تطبيقات توليد الفيديو Maestro: فقط جملة واحدة من اللغة الطبيعية `prompt`، يمكنك إكمال النص، المواد، التعليق الصوتي، الموسيقى، التحرير، الترجمة والتصيير التلقائي، ويدعم تحديد نوع الفيديو، الأسلوب، نغمة الصوت، الإخراج متعدد اللغات وكذلك التكرار على الفيديوهات الموجودة. نأمل أن تساعدك هذه الوثيقة في التفاعل بشكل أفضل واستخدام هذه الواجهة. إذا كان لديك أي استفسارات، لا تتردد في الاتصال بفريق الدعم الفني لدينا.
