Maestro هي واجهة إنتاج فيديو **أصلية للوكلاء (Agent)**: تستخدم `prompt` بلغة طبيعية لوصف الفيديو الذي تريده بجملة واحدة (ويمكنك اختياريًا إرفاق صور / فيديوهات / ملفات صوتية مرجعية عبر `file_urls`)، وسيتولى «مخرج AI» بلا واجهة تلقائيًا إكمال اختيار الموضوع، وكتابة السيناريو، وتوليد المشاهد، والتعليق الصوتي، والموسيقى التصويرية، والتركيب والعرض، لينتج في النهاية فيديو مكتملًا مع ترجمة ويرفعه إلى CDN.

ستعرض هذه المقالة بالتفصيل دليل تكامل واجهة API لتوليد فيديو Maestro، لمساعدتك على الدمج بسرعة والاستفادة الكاملة من قدرات واجهة API هذه.

هذه واجهة **مهام غير متزامنة**: بعد الإرسال، سيُعاد `task_id` فورًا، ثم يُستعلم عن النتيجة عبر [واجهة API للاستعلام عن مهام Maestro](/ar/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) من خلال الاستطلاع (الاستطلاع مجاني ولا يُحتسب ضمن الرسوم). لمواصلة التكرار على فيديو موجود، يمكنك استخدام `action: remix` / `edit` / `extend` مع `ref_task_id`.

## عملية التقديم

لاستخدام واجهة API لتوليد فيديو Maestro، انتقل أولًا إلى [وحدة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على API Token الخاص بك، واحتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد سجلت الدخول أو أنشأت حسابًا بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وستعود تلقائيًا إلى الصفحة الحالية بعد الإكمال.

**يمكن لـ API Token واحد استدعاء جميع خدمات المنصة، ولا حاجة للتقديم بشكل منفصل لكل خدمة.** سيُمنح رصيد مجاني عند التقديم لأول مرة، ويمكنك التجربة مجانًا؛ وعندما يكون الرصيد غير كافٍ، يمكنك شحن الرصيد العام من [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [واجهة API لتوليد فيديو Maestro →](https://platform.acedata.cloud/documents/maestro-videos)

## الاستخدام الأساسي

`POST https://api.acedata.cloud/maestro/videos`

يتطلب الاستخدام الأساسي فقط تمرير `prompt` واحد بلغة طبيعية، وسيقرر مخرج AI تلقائيًا السيناريو والمشاهد والتعليق الصوتي والمونتاج. هنا سنتعرف أولًا على ترويسات الطلب ونص الطلب المطلوب ضبطهما.

تشمل **Request Headers** ما يلي:

- `accept`: صيغة نتيجة الاستجابة التي تريد تلقيها، املأ هنا `application/json`، أي صيغة JSON.
- `authorization`: مفتاح استدعاء API، ويمكن اختياره مباشرة من القائمة المنسدلة بعد التقديم.
- `content-type`: صيغة نص الطلب، املأ هنا `application/json`.

يشمل **Request Body** بشكل أساسي:

- `prompt`: صف الفيديو المراد إنشاؤه بلغة طبيعية (الموضوع، وما يجب عرضه، والأسلوب، والجمهور).
- `langs`: مصفوفة لغات الفيديو النهائي، مرر لغة واحدة فقط كل مرة، مثل `["zh-cn"]`، والقيمة الافتراضية هي `["zh-cn"]`.
- `aspect`: نسبة أبعاد المشهد، `9:16` (افتراضي) / `16:9` / `1:1`.
- `duration`: المدة المستهدفة (بالثواني)، والافتراضي 30.

جميع حقول نص الطلب موضحة في الجدول التالي:

| الحقل            | النوع       | مطلوب  | الوصف                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | نعم   | صف الفيديو المراد إنشاؤه بلغة طبيعية (الموضوع، وما يجب عرضه، والأسلوب، والجمهور). يحدد AI السيناريو والمشاهد والتعليق الصوتي والمونتاج                                                                                                                                                                             |
| `action`      | string   | لا   | `generate` (افتراضي، لإنشاء فيديو جديد) / `remix` / `edit` / `extend` (للتكرار على فيديو موجود، ويتطلب استخدامه مع `ref_task_id`)                                                                                                                                                |
| `ref_task_id` | string   | لا   | مطلوب عندما تكون `action` هي remix / edit / extend: `task_id` للمهمة السابقة المستخدمة كنقطة بداية                                                                                                                                                                   |
| `file_urls`   | string[] | لا   | وسائط مرجعية (صور / فيديو / صوت URL)، مثل صورة المنتج أو الشعار المراد ظهوره، أو مقطع المواد المراد إضافة ترجمة إليه                                                                                                                                                                             |
| `langs`       | string[] | لا   | لغة الفيديو النهائي، يمكن تمرير لغة واحدة فقط كل مرة، مثل `["zh-cn"]`، والقيمة الافتراضية هي `["zh-cn"]`                                                                                                                                                                                    |
| `aspect`      | string   | لا   | `9:16` (افتراضي) / `16:9` / `1:1`، إخراج موحد بدقة 1080p/30fps                                                                                                                                                                                  |
| `duration`    | int      | لا   | المدة المستهدفة (بالثواني)، والافتراضي 30، ويدعم **5–300 ثانية**. تُحتسب الرسوم حسب مدة الفيديو الفعلية، لكنها لن تتجاوز مدة الطلب                                                                                                                                                                             |
| `scenario`    | string   | لا   | نوع الفيديو: `auto` / `narrated` / `captions` / `avatar` / `drama`. يتطلب `captions` تمرير فيديو المصدر، ويتطلب `avatar` تمرير صورة شخصية                                                                                                                                    |
| `style`       | string   | لا   | إعداد مسبق للأسلوب البصري: `auto` (افتراضي) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`، ويقبل أيضًا نصًا حرًا كتلميح مرن. وهو متعامد مع `scenario` ولا يغير التوجيه |
| `voice`       | string   | لا   | نبرة صوت التعليق (مستقلة عن اللغة وعامة عبر اللغات): `auto` (افتراضي) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`                                    |

سنوضح ذلك الآن عبر مثال محدد. افترض أننا نريد إنشاء فيديو قصير علمي باللغة الصينية، عمودي، ومدته 20 ثانية، ويكون كود CURL المقابل كما يلي:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

كود Python المقابل كما يلي:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

انقر للتشغيل، وستلاحظ أنه يمكنك الحصول فورًا على نتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

فيما يلي تعريف حقول النتيجة المُعادة:
- `success`: ما إذا تم إرسال هذه المهمة بنجاح.
- `task_id`: معرّف مهمة إنشاء الفيديو هذه، يُستخدم لاحقًا لاستطلاع النتيجة عبر [واجهة API للاستعلام عن مهام Maestro](/ar/guides/maestro/maestro_tasks).
- `trace_id`: معرّف التتبع لهذا الطلب، ويمكن تقديمه للدعم الفني لتحديد المشكلة عند حدوثها.

نظرًا لأن إنتاج الفيديو يستغرق وقتًا طويلًا، تُرجع الواجهة هنا **`task_id` فورًا**، ولن تنتظر حتى يكتمل تصيير الفيديو. بعد ذلك، تحتاج إلى استخدام `task_id` لاستطلاع النتيجة، راجع قسم «الحصول على النتيجة» للتفاصيل.

## تحديد نوع الفيديو والنمط (scenario / style)

عند عدم تمرير `scenario`، يحدده الذكاء الاصطناعي تلقائيًا (يساوي `auto`)؛ وإذا أردت تثبيت الفيديو على نوع معيّن، فمرّره صراحةً. على سبيل المثال، لإنشاء **دراما قصيرة عمودية**، يمكن تحديد المحتوى التالي:

- `scenario`: نوع الفيديو، اضبطه هنا على `drama` (دراما قصيرة بشخصيات + حوار).
- `style`: النمط البصري، اضبطه هنا على `cinematic` (طابع سينمائي).

كود CURL النموذجي المكتمل كما يلي:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

طرق الدمج الشائعة:

- مقطع قصير سردي: `scenario: "narrated"`.
- ترجمة تلقائية: `scenario: "captions"`، يلزم تمرير الفيديو المصدر عبر `file_urls`.
- إنسان رقمي / إلقاء مباشر: `scenario: "avatar"`، يلزم تمرير صورة شخصية عبر `file_urls`.
- دراما قصيرة: `scenario: "drama"` (شخصيات + حوار).
- `style` هو إعداد مسبق للنمط البصري (مثل `modern` / `neon` / `luxury`)، ولا يغيّر النوع، بل يؤثر على المظهر فقط.
- يُستخدم `voice` لتحديد نبرة صوت الراوي (مثل `warm-female` / `deep-male`)، وهو غير مرتبط باللغة ومتوافق عبر اللغات.

تتطابق النتيجة المعادة مع «الاستخدام الأساسي»، حيث يتم أيضًا إرجاع `task_id` فورًا.

## لغة الفيديو النهائي

تُسلّم كل مهمة فيديو نهائيًا واحدًا بلغة واحدة فقط. لا يمكن أن يحتوي `langs` إلا على رمز لغة واحد، مثل `["zh-cn"]` أو `["en"]`؛ وسيؤدي تمرير لغات متعددة إلى إرجاع 400. إذا كنت تحتاج إلى فيديوهات بلغات مختلفة، فيرجى إنشاء مهام منفصلة. لا يؤثر اختيار اللغة على السعر لكل ثانية.

## التكرار على فيديو موجود (remix / edit / extend)

مرّر `action` و`ref_task_id` للمهمة السابقة لإجراء تعديلات تفاضلية على أساس المشروع الأصلي (مثل «تغيير عنوان المشهد الثاني»، «تغيير التعليق الصوتي»، «تغميق المظهر العام»). تكون التعديلات الصغيرة سريعة، بينما تؤدي التعديلات الكبيرة إلى إعادة الإنشاء:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: إعادة تقديم على بنية الفيديو الأصلية (الحفاظ على الموضوع، مع تعديل التعبير).
- `edit`: تحسين دقيق لأجزاء محددة (مثل تغيير العنوان، أو التعليق الصوتي، أو تدرج الألوان).
- `extend`: توسيع المحتوى على أساس الفيديو الأصلي.

تُرجع النتيجة أيضًا `task_id` جديدًا فورًا، ويمكن استخدامه للاستطلاع والحصول على الفيديو النهائي بعد التكرار.

## الحصول على النتيجة

نظرًا لأن إنتاج الفيديو يستغرق وقتًا طويلًا، تُرجع هذه الواجهة `task_id` فورًا بعد الإرسال، وتحتاج إلى استخدامه لاستطلاع النتيجة عبر [واجهة API للاستعلام عن مهام Maestro](/ar/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

عند اكتمال المهمة، سيتم إرجاع معلومات فيديو نهائي واحد (ضمن مصفوفة `variants`). سيمر `status` عبر `pending → planning → producing → succeeded` (أو `failed`)، **والاستطلاع مجاني ولا يستهلك رصيدًا**. للحصول على تنسيق الاستجابة الكامل والاستعلام عن القائمة التاريخية، راجع [تعليمات تكامل واجهة API للاستعلام عن مهام Maestro](/ar/guides/maestro/maestro_tasks).

## الفوترة

**تتم الفوترة بعد نجاح المهمة بناءً على المدة الفعلية للفيديو النهائي المُسلَّم، ولا يتم الخصم عند الفشل.** تُحتسب مدة الفوترة بالثواني الصحيحة، ولا تتجاوز المدة المطلوبة؛ وعند تعذر قراءة مدة الفيديو النهائي، يتم الرجوع إلى المدة المطلوبة. لا تتم فوترة إرسال المهمة نفسه بشكل منفصل، واستطلاع `/maestro/tasks` مجاني.

```
الرصيد = ثواني الفوترة الفعلية × 0.7
```

تستخدم جميع السيناريوهات والإجراءات واللغات السعر نفسه، دون مضاعفات للسيناريو أو رسوم إضافية للغة. تُسلّم كل مهمة فيديو نهائيًا واحدًا بلغة واحدة فقط. تدعم مدة الهدف المطلوبة من 5 إلى 300 ثانية، مع إخراج موحّد بدقة 1080p / 30fps.

| مدة الفوترة الفعلية              |  الرصيد |
| ------------------- | --: |
| 30 ثانية                |  21 |
| 60 ثانية                |  42 |
| 120 ثانية               |  84 |
| 300 ثانية               | 210 |
| استطلاع `/maestro/tasks` |  مجاني |

## معالجة الأخطاء

عند استدعاء API، إذا واجهت خطأً، فستُرجع API رمز الخطأ والمعلومات المقابلة. على سبيل المثال:

- `400 invalid_request`: طلب غير صالح، قد يكون بسبب فقدان `prompt` أو معلمات غير صالحة.
- `401 invalid_token`: غير مصرح، رمز التفويض غير صالح أو مفقود.
- `403 forbidden`: ممنوع، الرصيد أو صلاحية الوصول غير كافيين.
- `429 too_many_requests`: طلبات كثيرة جدًا، لقد تجاوزت حد المعدل.
- `500 api_error`: خطأ داخلي في الخادم، حدث خطأ ما على الخادم.

### مثال على استجابة خطأ

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## الخلاصة

من خلال هذا المستند، تعرفت بالفعل على كيفية استخدام API لإنشاء فيديوهات Maestro: فبمجرد جملة واحدة بلغة طبيعية ضمن `prompt`، يمكن إكمال النص والمواد والتعليق الصوتي والموسيقى والمونتاج والترجمة وتصييّر الفيديو النهائي تلقائيًا، مع دعم تحديد نوع الفيديو والنمط ونبرة الصوت ولغة الفيديو النهائي، وكذلك التكرار على الفيديوهات الموجودة. نأمل أن يساعدك هذا المستند على تكامل هذه API واستخدامها بشكل أفضل. إذا كانت لديك أي أسئلة، فيرجى التواصل مع فريق الدعم الفني لدينا في أي وقت.
