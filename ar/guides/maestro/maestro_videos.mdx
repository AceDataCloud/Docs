مايسترو هو واجهة إنتاج الفيديو **المعتمدة على الوكيل**: يمكنك استخدام جملة طبيعية `prompt` لوصف الفيديو الذي تريده (يمكنك اختيار إرفاق صور / فيديوهات / صوتيات مرجعية باستخدام `file_urls`)، وسيقوم "مخرج الذكاء الاصطناعي" تلقائيًا بإكمال اختيار الموضوع، كتابة السيناريو، توليد المشاهد، التعليق الصوتي، الموسيقى، الدمج والتصيير، وفي النهاية إنتاج الفيديو مع الترجمة وتحميله على CDN.

ستتناول هذه المقالة بالتفصيل تعليمات دمج واجهة برمجة تطبيقات توليد الفيديو من مايسترو، لمساعدتك على دمجها بسرعة واستغلال قدراتها بشكل كامل.

هذه واجهة **مهام غير متزامنة**: بعد الإرسال، سيتم إرجاع `task_id` على الفور، ثم يمكنك الاستعلام عن النتائج من خلال [واجهة برمجة تطبيقات استعلام مهام مايسترو](development_maestro_tasks.md) (`POST /maestro/tasks`) (الاستعلام مجاني ولا يتم احتساب رسوم). للاستمرار في التكرار على فيديو موجود، يمكنك استخدام `action: remix` / `edit` / `extend` مع `ref_task_id`.

## عملية التقديم

لاستخدام واجهة برمجة تطبيقات توليد الفيديو من مايسترو، يجب أولاً الذهاب إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، احتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد الانتهاء، سيتم إرجاعك تلقائيًا إلى الصفحة الحالية.

**يمكن استخدام رمز API واحد لاستدعاء جميع خدمات المنصة، دون الحاجة لتقديم طلب منفصل لكل خدمة.** عند التقديم لأول مرة، ستحصل على رصيد مجاني لتجربته؛ وعند نفاد الرصيد، يمكنك إعادة شحن الرصيد العام في [لوحة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [واجهة برمجة تطبيقات توليد الفيديو من مايسترو →](https://platform.acedata.cloud/documents/maestro-videos)

## الاستخدام الأساسي

`POST https://api.acedata.cloud/maestro/videos`

أبسط طريقة للاستخدام تتطلب فقط إدخال جملة طبيعية `prompt`، وسيقوم مخرج الذكاء الاصطناعي بتحديد السيناريو، المشاهد، التعليق الصوتي والمونتاج تلقائيًا. هنا سنتعرف على رؤوس الطلب وجسم الطلب المطلوبين.

**رؤوس الطلب** تشمل:

- `accept`: نوع الاستجابة التي ترغب في تلقيها، هنا يتم إدخال `application/json`، أي بتنسيق JSON.
- `authorization`: مفتاح استدعاء API، يمكنك اختياره مباشرة بعد التقديم.
- `content-type`: تنسيق جسم الطلب، هنا يتم إدخال `application/json`.

**جسم الطلب** يتضمن بشكل رئيسي:

- `prompt`: وصف الفيديو الذي تريد إنشاؤه بلغة طبيعية (الموضوع، ما يجب عرضه، الأسلوب، الجمهور).
- `langs`: مصفوفة اللغات الناتجة، مثل `["zh-cn", "en"]`، الافتراضي هو `["zh-cn"]`.
- `aspect`: نسبة العرض إلى الارتفاع، `9:16` (افتراضي) / `16:9` / `1:1`.
- `duration`: الطول المستهدف (بالثواني)، الافتراضي 30.

جميع حقول جسم الطلب موضحة في الجدول أدناه:

| الحقل            | النوع       | إلزامي  | الشرح                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | نعم   | وصف الفيديو الذي تريد إنشاؤه بلغة طبيعية (الموضوع، ما يجب عرضه، الأسلوب، الجمهور). السيناريو، المشاهد، التعليق الصوتي، والمونتاج يتم تحديدها بواسطة الذكاء الاصطناعي                                                                                                                                                                             |
| `action`      | string   | لا    | `generate` (افتراضي، إنشاء فيديو جديد) / `remix` / `edit` / `extend` (التكرار على فيديو موجود، يجب استخدام `ref_task_id` مع ذلك)                                                                                                                                                |
| `ref_task_id` | string   | لا    | يجب ملؤه عند كون `action` هو remix / edit / extend: كمعرف المهمة التاريخية `task_id` كنقطة انطلاق                                                                                                                                                                   |
| `file_urls`   | string[] | لا    | وسائل الإعلام المرجعية (صور / فيديوهات / صوتيات URL)، مثل صور المنتجات، الشعار، أو مقاطع المواد التي تحتاج إلى إضافة ترجمات                                                                                                                                                                             |
| `langs`       | string[] | لا    | اللغات الناتجة، مثل `["zh-cn", "en"]`، الافتراضي هو `["zh-cn"]`. الأولى هي اللغة الرئيسية؛ كل لغة إضافية تعيد استخدام المشاهد، مع إضافة التعليق الصوتي + التصيير، **كل لغة إضافية +6 نقاط**                                                                                                                                          |
| `aspect`      | string   | لا    | `9:16` (افتراضي) / `16:9` / `1:1`. Lite ينتج 720p/24fps، Standard و Pro ينتجان 1080p/30fps                                                                                                                                                  |
| `duration`    | int      | لا    | الطول المستهدف (بالثواني)، الافتراضي 30. Lite يتراوح بين **5–30 ثانية**، Standard بين **5–120 ثانية**، Pro بين **5–300 ثانية**. يتم احتساب الرسوم بناءً على الطول الفعلي للفيديو، ولكن لا يتجاوز الطول المطلوب                                                                                                                                 |
| `quality`     | string   | لا    | مستوى الإنتاج: `lite` (فيديو قصير سريع، 0.20 نقطة/ثانية) / `standard` (افتراضي، إنتاج متوازن، 0.60 نقطة/ثانية) / `pro` (إنتاج متقدم، 1.20 نقطة/ثانية)                                                                                                                                           |
| `scenario`    | string   | لا    | نوع الفيديو: Lite يدعم `auto` / `narrated` / `captions`؛ Standard يضيف `avatar`؛ Pro يضيف `drama`. `captions` يتطلب تقديم الفيديو المصدر، `avatar` يتطلب تقديم صورة شخصية                                                                                                             |
| `style`       | string   | لا    | إعدادات الأسلوب البصري: `auto` (افتراضي) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`، كما يقبل نصوص حرة كإشارات ناعمة. لا تتداخل مع `scenario` ولا تغير المسار |
| `voice`       | string   | لا    | نغمة التعليق الصوتي (غير مرتبطة باللغة، تستخدم عبر اللغات): `auto` (افتراضي) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`                                    |

دعونا نوضح ذلك من خلال مثال محدد. لنفترض أننا نريد إنشاء فيديو قصير علمي ثنائي اللغة (الصينية والإنجليزية)، عمودي، مدته 20 ثانية، كود CURL المقابل هو كما يلي:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn", "en"],
  "aspect": "9:16",
  "duration": 20
}'
```

الكود المقابل بلغة بايثون هو كما يلي:
```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn", "en"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

عند النقر على التشغيل، يمكنك أن تجد أنك ستحصل على نتيجة على الفور، كما يلي:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

تقديم حقول نتيجة العودة كما يلي:

- `success`: هل تم تقديم المهمة بنجاح.
- `task_id`: معرف مهمة إنشاء الفيديو هذه، استخدمه لاحقًا لاستعلام نتائج [API استعلام مهام Maestro](development_maestro_tasks.md).
- `trace_id`: معرف تتبع الطلب الحالي، يمكن تقديمه للدعم الفني لتحديد موقع المشكلة.

نظرًا لأن إنتاج الفيديو يستغرق وقتًا طويلاً، فإن الواجهة هنا **ترجع `task_id` على الفور**، ولن تنتظر حتى يكتمل عرض الفيديو. بعد ذلك، تحتاج إلى استخدام `task_id` لاستعلام النتائج، انظر قسم "الحصول على النتائج".

## تحديد نوع الفيديو والأسلوب (scenario / style)

عند عدم تمرير `scenario`، يتم تحديده تلقائيًا بواسطة الذكاء الاصطناعي (يعادل `auto`)؛ إذا كنت ترغب في تثبيت الفيديو على نوع معين، يمكنك تمرير ذلك بشكل صريح. على سبيل المثال، لإنشاء **دراما قصيرة عمودية**، يمكنك تحديد المحتوى كما يلي:

- `scenario`: نوع الفيديو، هنا يتم تعيينه إلى `drama` (دراما قصيرة مع شخصيات + حوار).
- `style`: الأسلوب البصري، هنا يتم تعيينه إلى `cinematic` (جودة سينمائية).

كود CURL لملء النموذج كما يلي:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

طرق التوافق الشائعة:

- مقاطع الفيديو المروية: `scenario: "narrated"`، تدعمها Lite / Standard / Pro.
- الترجمة التلقائية: `scenario: "captions"`، تحتاج إلى استخدام `file_urls` لتمرير الفيديو المصدر، تدعمها Lite / Standard / Pro.
- الشخصيات الرقمية / التعليق الصوتي: `scenario: "avatar"`، تحتاج إلى استخدام `file_urls` لتمرير صورة شخصية، تدعمها Standard / Pro.
- الدراما: `scenario: "drama"` (شخصيات + حوار)، تدعمها فقط Pro.
- `style` هو إعداد الأسلوب البصري (مثل `modern` / `neon` / `luxury`)، لا يغير النوع، يؤثر فقط على التجربة البصرية.
- `voice` تستخدم لتحديد نغمة التعليق الصوتي (مثل `warm-female` / `deep-male`)، غير مرتبطة باللغة، وتعمل عبر اللغات.

نتيجة العودة متطابقة مع "الاستخدام الأساسي"، أيضًا ترجع `task_id` على الفور.

## الإخراج متعدد اللغات

قم بتمرير عدة لغات في `langs` للحصول على إصدارات متعددة اللغات مرة واحدة. الأولى هي اللغة الرئيسية، وبعد ذلك ستعيد كل لغة إضافية **نفس مجموعة المشاهد**، مع إضافة الصوت + العرض فقط، لذلك **كل لغة إضافية تضيف فقط +6 نقاط**. مثال:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "介绍我们的智能客服产品，突出 3 个核心卖点",
  "langs": ["zh-cn", "en", "ja"],
  "aspect": "16:9",
  "duration": 30
}'
```

عند الانتهاء من المهمة، ستتوافق كل لغة مع `variant` في النتيجة (انظر [API استعلام مهام Maestro](development_maestro_tasks.md)).

## التكرار على الفيديو الموجود (remix / edit / extend)

قم بتمرير `action` مع `ref_task_id` من المهمة السابقة، يمكنك إجراء تعديلات طفيفة على أساس المشروع الأصلي (مثل "تغيير عنوان الفصل الثاني" أو "تغيير التعليق الصوتي" أو "تعتيم الصورة بشكل عام"). التعديلات الصغيرة سريعة، والتعديلات الكبيرة ستحتاج إلى إعادة العمل:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: إعادة تقديم الفيديو على هيكل الفيديو الأصلي (الحفاظ على الموضوع، تعديل العرض).
- `edit`: إجراء تعديلات دقيقة على جزء محدد (مثل تغيير العنوان، تغيير التعليق الصوتي، تعديل الألوان).
- `extend`: توسيع المحتوى على أساس الفيديو الأصلي.

نتيجة العودة أيضًا ترجع `task_id` جديدة، استخدمها للاستعلام للحصول على النسخة المعدلة.

## الحصول على النتائج

نظرًا لأن إنتاج الفيديو يستغرق وقتًا طويلاً، فإن هذه الواجهة ترجع `task_id` على الفور بعد التقديم، تحتاج إلى استخدامه لاستعلام [API استعلام مهام Maestro](development_maestro_tasks.md) للحصول على النتائج:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

عند الانتهاء من المهمة، ستعيد معلومات النسخة النهائية (كل لغة تتوافق مع `variant`). ستشهد `status` تطورًا من `pending → planning → producing → succeeded` (أو `failed`)، **الاستعلام مجاني، ولا يستهلك النقاط**. يرجى الرجوع إلى [إرشادات تكامل API استعلام مهام Maestro](development_maestro_tasks.md) للحصول على تنسيق الاستجابة الكامل واستعلام القائمة التاريخية.

## الفوترة

**يتم الفوترة بعد إتمام المهمة بناءً على النسخة النهائية، ولا يتم خصم أي رسوم عن المهام الفاشلة.** يتم الفوترة بناءً على طول النسخة النهائية الفعلي وعدد اللغات، ولن تتجاوز مدة الفوترة المدة المطلوبة. إذا لم يتم إنتاج لغة معينة في النهاية، فلن يتم فرض رسوم إضافية قدرها +6 لهذه اللغة. تقديم المهمة نفسها لا يتم فوترة بشكل منفصل، واستعلام `/maestro/tasks` مجاني.

يتم حساب النقاط للنسخة النهائية الواحدة وفقًا للصيغة التالية:

```
النقاط = طول النسخة النهائية بالثواني × سعر SKU لكل ثانية × معامل السيناريو + 6 × max(عدد اللغات - 1, 0)
```
| SKU        |    سعر لكل ثانية |  أطول مدة | إخراج                | المشهد والإجراء                                |
| ---------- | ------: | ----: | ----------------- | ------------------------------------ |
| `lite`     | 0.20 نقاط |  30 ثانية | 720p / 24fps      | auto، narrated، captions؛ generate، edit |
| `standard` | 0.60 نقاط | 120 ثانية | 1080p / 30fps     | إضافة avatar؛ إضافة remix                   |
| `pro`      | 1.20 نقاط | 300 ثانية | 1080p / 30fps عالي البت | إضافة drama؛ إضافة extend                   |

معدل المشهد: `drama` 1.35× / `avatar` 1.15× / أخرى 1×.

| مثال                  |  نقاط |
| ------------------- | --: |
| Lite 30 ثانية           |   6 |
| Standard 30 ثانية       |  18 |
| Standard 60 ثانية       |  36 |
| Standard 120 ثانية      |  72 |
| Pro 30 ثانية            |  36 |
| Pro 300 ثانية           | 360 |
| لكل لغة تسليم فعلية إضافية          |  +6 |
| `/maestro/tasks` استعلام |  مجاني |

## معالجة الأخطاء

عند استدعاء API، إذا واجهت خطأ، سيقوم API بإرجاع رمز الخطأ والمعلومات المناسبة. على سبيل المثال:

- `400 invalid_request`：طلب غير صالح، ربما بسبب نقص في `prompt` أو معلمات غير صالحة.
- `401 invalid_token`：غير مصرح، رمز تفويض غير صالح أو مفقود.
- `403 forbidden`：ممنوع، رصيد غير كافٍ أو وصول.
- `429 too_many_requests`：طلبات كثيرة جداً، لقد تجاوزت حد المعدل.
- `500 api_error`：خطأ في الخادم الداخلي، حدث خطأ ما في الخادم.

### مثال على استجابة الخطأ

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## الخاتمة

من خلال هذه الوثيقة، لقد تعرفت على كيفية استخدام API لتوليد الفيديو Maestro: فقط جملة طبيعية `prompt`، يمكنك إكمال النص، المواد، التعليق الصوتي، الموسيقى، التحرير، الترجمة والتصميم النهائي تلقائيًا، ويدعم تحديد نوع الفيديو، الأسلوب، نغمة الصوت، الإخراج متعدد اللغات وكذلك التكرار على الفيديوهات الموجودة. نأمل أن تساعدك هذه الوثيقة في التواصل واستخدام هذا API بشكل أفضل. إذا كان لديك أي استفسارات، لا تتردد في الاتصال بفريق الدعم الفني لدينا.
