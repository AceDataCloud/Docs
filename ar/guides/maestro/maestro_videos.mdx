Maestro هو واجهة إنتاج فيديو **أصلية للـ Agent**: تستخدم `prompt` بلغة طبيعية من جملة واحدة لوصف الفيديو الذي تريده (ويمكنك اختياريًا إرفاق صور / فيديوهات / صوتيات مرجعية باستخدام `file_urls`)، وسيتولى «مخرج AI» بلا واجهة تلقائيًا إتمام اختيار الموضوع، وكتابة النص، وإنشاء المشاهد، والتعليق الصوتي، والموسيقى التصويرية، والتركيب والعرض، لينتج في النهاية فيديو مكتملًا مع ترجمة ويرفعه إلى CDN.

ستعرض هذه المقالة بالتفصيل تعليمات تكامل API لإنشاء فيديو Maestro، لمساعدتك على التكامل بسرعة والاستفادة الكاملة من قدرات API.

هذه واجهة **مهام غير متزامنة**: بعد الإرسال ستعيد فورًا `task_id`، ثم يمكنك استطلاع النتيجة عبر [Maestro Task Query API](/ar/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (الاستطلاع مجاني ولا يُحتسب ضمن الفوترة). لمتابعة التكرار على فيديو موجود، يمكنك استخدام `action: remix` / `edit` / `extend` مع `ref_task_id`.

## عملية التقديم

لاستخدام API لإنشاء فيديو Maestro، انتقل أولًا إلى [وحدة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على API Token الخاص بك، واحتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تقم بتسجيل الدخول أو التسجيل بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وبعد الإكمال ستعود تلقائيًا إلى الصفحة الحالية.

**يمكن لـ API Token واحد استدعاء جميع خدمات المنصة، ولا حاجة إلى التقديم بشكل منفصل لكل خدمة.** سيُمنحك رصيد مجاني عند أول تقديم، ويمكنك التجربة مجانًا؛ وعندما يكون الرصيد غير كافٍ، يمكنك إعادة شحن الرصيد العام من [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [Maestro Video Generation API →](https://platform.acedata.cloud/documents/maestro-videos)

## الاستخدام الأساسي

`POST https://api.acedata.cloud/maestro/videos`

لا يتطلب الاستخدام الأساسي سوى تمرير `prompt` واحد بلغة طبيعية، وسيقرر مخرج AI تلقائيًا النص والمشاهد والتعليق الصوتي والتحرير. سنتعرف هنا أولًا على رؤوس الطلب ونص الطلب اللذين يجب ضبطهما.

تشمل **Request Headers** ما يلي:

- `accept`: صيغة نتيجة الاستجابة التي تريد تلقيها، املأ هنا `application/json`، أي صيغة JSON.
- `authorization`: مفتاح استدعاء API، ويمكنك اختياره مباشرة من القائمة المنسدلة بعد التقديم.
- `content-type`: صيغة نص الطلب، املأ هنا `application/json`.

يشمل **Request Body** بشكل أساسي ما يلي:

- `prompt`: صف الفيديو المراد إنشاؤه بلغة طبيعية (الموضوع، ما الذي تريد عرضه، الأسلوب، الجمهور).
- `langs`: مصفوفة لغات الفيديو المكتمل، مرّر لغة واحدة فقط في كل مرة، مثل `["zh-cn"]`، والقيمة الافتراضية هي `["zh-cn"]`.
- `aspect`: نسبة أبعاد المشهد، `9:16` (الافتراضية) / `16:9` / `1:1`.
- `duration`: المدة المستهدفة (بالثواني)، والقيمة الافتراضية هي 30.

جميع حقول نص الطلب موضحة في الجدول التالي:

| الحقل            | النوع       | مطلوب  | الوصف                                                                                                                                                                                                                                    |
| ------------- | -------- | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | نعم   | صف الفيديو المراد إنشاؤه بلغة طبيعية (الموضوع، ما الذي تريد عرضه، الأسلوب، الجمهور). يقرر AI النص والمشاهد والتعليق الصوتي والتحرير                                                                                                                                                                                      |
| `action`      | string   | لا   | `generate` (افتراضي، لإنشاء فيديو جديد) / `remix` / `edit` / `extend` (للتكرار على فيديو موجود، ويجب استخدامه مع `ref_task_id`)                                                                                                                                                         |
| `ref_task_id` | string   | لا   | مطلوب عندما تكون `action` هي remix / edit / extend: `task_id` للمهمة السابقة التي تُستخدم كنقطة انطلاق                                                                                                                                                                            |
| `file_urls`   | string[] | لا   | وسائط مرجعية (URL للصور / الفيديو / الصوت)، مثل صورة المنتج أو الشعار الذي سيظهر، أو مقطع المواد الذي ستُضاف إليه ترجمة                                                                                                                                                                                      |
| `langs`       | string[] | لا   | لغة الفيديو المكتمل، يمكن تمرير لغة واحدة فقط في كل مرة، مثل `["zh-cn"]`، والقيمة الافتراضية هي `["zh-cn"]`                                                                                                                                                                                             |
| `aspect`      | string   | لا   | `9:16` (افتراضي) / `16:9` / `1:1`، مخرجات موحدة بدقة 1080p/30fps                                                                                                                                                                                           |
| `duration`    | int      | لا   | المدة المستهدفة (بالثواني)، الافتراضية 30، وتدعم **5–300 ثانية**. تُحتسب التكلفة وفق مدة الفيديو المكتمل الفعلية، لكنها لن تتجاوز مدة الطلب                                                                                                                                                                                      |
| `scenario`    | string   | لا   | نوع الفيديو: `auto` / `narrated` / `captions` / `avatar` / `drama`. يتطلب `captions` تمرير الفيديو المصدر، ويتطلب `avatar` تمرير صورة شخصية                                                                                                                                             |
| `style`       | string   | لا   | إعداد مسبق للأسلوب البصري: `auto` (افتراضي) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`، ويقبل أيضًا نصًا حرًا كتلميح غير ملزم. وهو متعامد مع `scenario` ولا يغير التوجيه          |
| `voice`       | string   | لا   | صوت التعليق الصوتي (غير مرتبط باللغة، وعام عبر اللغات): `auto` (افتراضي) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`؛ كما يدعم `reference_id` لصوت سداسي عشري من 32 بت، أما النصوص الحرة الأخرى فليست معرّفات صوت صالحة |

فيما يلي عرض توضيحي من خلال مثال محدد. لنفترض أننا نريد إنشاء فيديو علمي قصير باللغة الصينية، عمودي، ومدته 20 ثانية، فإن كود CURL المقابل هو كما يلي:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

كود Python المقابل هو كما يلي:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

انقر للتشغيل، وستجد أنه يمكنك الحصول فورًا على نتيجة كما يلي:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

تعريف حقول نتيجة الإرجاع كما يلي:
- `success`: ما إذا تم إرسال هذه المهمة بنجاح.
- `task_id`: معرّف مهمة إنشاء الفيديو هذه، ويُستخدم لاحقًا لاستطلاع النتائج عبر [واجهة برمجة تطبيقات الاستعلام عن مهام Maestro](/ar/guides/maestro/maestro_tasks).
- `trace_id`: معرّف التتبع لهذا الطلب، ويمكن تقديمه للدعم الفني لتحديد المشكلة عند مواجهتها.

نظرًا لأن إنتاج الفيديو يستغرق وقتًا طويلًا، تُرجع الواجهة هنا **`task_id` فورًا**، ولن تنتظر حتى يكتمل تصيير الفيديو. بعد ذلك، تحتاج إلى استخدام `task_id` لاستطلاع النتائج، راجع قسم «الحصول على النتائج» للتفاصيل.

## تحديد نوع الفيديو ونمطه (scenario / style)

عند عدم تمرير `scenario`، يحدد الذكاء الاصطناعي ذلك تلقائيًا (يساوي `auto`)؛ إذا أردت تثبيت الفيديو على نوع معين، فمرّره صراحةً. على سبيل المثال، لإنشاء **دراما قصيرة عمودية**، يمكن تحديد المحتوى التالي:

- `scenario`: نوع الفيديو، ويُضبط هنا على `drama` (دراما قصيرة بشخصيات + حوار).
- `style`: النمط البصري، ويُضبط هنا على `cinematic` (إحساس سينمائي).

فيما يلي مثال على كود CURL المكتمل:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

طرق الاقتران الشائعة:

- مقطع شرح قصير: `scenario: "narrated"`.
- ترجمة تلقائية: `scenario: "captions"`، يجب تمرير فيديو المصدر باستخدام `file_urls`.
- إنسان رقمي / حديث مباشر: `scenario: "avatar"`، يجب تمرير صورة شخصية باستخدام `file_urls`.
- دراما قصيرة: `scenario: "drama"` (شخصيات + حوار).
- `style` هو إعداد مسبق للنمط البصري (مثل `modern` / `neon` / `luxury`)، ولا يغير النوع، بل يؤثر فقط على المظهر.
- يُستخدم `voice` لتحديد نبرة صوت التعليق الصوتي (مثل `warm-female` / `deep-male`)، وهو غير مرتبط باللغة وعام بين اللغات.

تتوافق النتيجة المعادة مع «الاستخدام الأساسي»، إذ تُرجع أيضًا `task_id` فورًا.

## لغة الفيديو النهائي

تُسلَّم لكل مهمة نسخة فيديو نهائية واحدة بلغة واحدة فقط. يمكن أن يحتوي `langs` على رمز لغة واحد فقط، مثل `["zh-cn"]` أو `["en"]`؛ سيؤدي تمرير لغات متعددة إلى إرجاع 400. إذا كنت بحاجة إلى فيديوهات بلغات مختلفة، فيرجى إنشاء مهام منفصلة. لا يؤثر اختيار اللغة على السعر لكل ثانية.

## التكرار على فيديو موجود (remix / edit / extend)

مرّر `action` و`ref_task_id` للمهمة السابقة، ويمكنك إجراء تعديلات تدريجية على أساس المشروع الأصلي (مثل «تغيير عنوان المشهد الثاني»، «تبديل التعليق الصوتي»، «تعتيم الفيديو بالكامل»). التعديلات الصغيرة سريعة، أما التعديلات الكبيرة فستُعاد معالجتها:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: إعادة تقديم على بنية الفيديو الأصلية (مع الحفاظ على الفكرة وتعديل العرض).
- `edit`: إجراء تنقيح دقيق على جزء محدد (مثل تغيير العنوان أو التعليق الصوتي أو تدرج الألوان).
- `extend`: توسيع المحتوى على أساس الفيديو الأصلي.

تُرجع النتيجة أيضًا `task_id` جديدًا فورًا، ويمكنك استخدامه للاستطلاع والحصول على الفيديو النهائي بعد التكرار.

## الحصول على النتائج

نظرًا لأن إنتاج الفيديو يستغرق وقتًا طويلًا، تُرجع هذه الواجهة `task_id` فورًا بعد الإرسال، وتحتاج إلى استخدامه لاستطلاع النتائج عبر [واجهة برمجة تطبيقات الاستعلام عن مهام Maestro](/ar/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

عند اكتمال المهمة، ستُرجع معلومات فيديو نهائي واحدة (توجد في مصفوفة `variants`). سيمر `status` بالمراحل `pending → planning → producing → succeeded` (أو `failed`)، و**الاستطلاع مجاني ولا يستهلك نقاطًا**. راجع [تعليمات تكامل واجهة برمجة تطبيقات الاستعلام عن مهام Maestro](/ar/guides/maestro/maestro_tasks) للحصول على تنسيق الاستجابة الكامل والاستعلام عن القائمة التاريخية.

## الفوترة

**بعد نجاح المهمة، تُحتسب الرسوم بناءً على المدة الفعلية للفيديو النهائي المُسلَّم، ولا تُفرض رسوم عند الفشل.** تُحتسب مدة الفوترة بالثواني الصحيحة، ولا تتجاوز المدة المطلوبة؛ وعند تعذر قراءة مدة الفيديو النهائي، يتم الرجوع إلى المدة المطلوبة. لا يتم احتساب رسوم منفصلة على إرسال المهمة نفسه، واستطلاع `/maestro/tasks` مجاني.

```
النقاط = الثواني الفعلية القابلة للفوترة × 0.7
```

تستخدم جميع السيناريوهات والإجراءات واللغات السعر نفسه، دون معاملات مضاعفة للسيناريو أو رسوم إضافية للغة. تُسلَّم لكل مهمة نسخة فيديو نهائية واحدة بلغة واحدة فقط. تدعم مدة الهدف المطلوبة من 5 إلى 300 ثانية، ويكون الإخراج الموحد بدقة 1080p / 30fps.

| مدة الفوترة الفعلية              |  النقاط |
| ------------------- | --: |
| 30 ثانية                |  21 |
| 60 ثانية                |  42 |
| 120 ثانية               |  84 |
| 300 ثانية               | 210 |
| استطلاع `/maestro/tasks` |  مجاني |

## معالجة الأخطاء

عند استدعاء API، إذا واجهت خطأً، فستُرجع API رمز الخطأ والمعلومات المقابلة. على سبيل المثال:

- `400 invalid_request`: طلب غير صالح، ربما بسبب فقدان `prompt` أو معلمات غير صالحة.
- `401 invalid_token`: غير مصرح به، رمز تفويض غير صالح أو مفقود.
- `403 forbidden`: محظور، رصيد أو صلاحية وصول غير كافيين.
- `429 too_many_requests`: طلبات كثيرة جدًا، لقد تجاوزت حد المعدل.
- `500 api_error`: خطأ داخلي في الخادم، حدث خطأ ما على الخادم.

### مثال على استجابة خطأ

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## الخلاصة

من خلال هذا المستند، أصبحت تعرف بالفعل كيفية استخدام Maestro Video Generation API: كل ما تحتاجه هو `prompt` واحد بلغة طبيعية لإكمال النص والمواد والتعليق الصوتي والموسيقى والمونتاج والترجمة وتصييّر الفيديو النهائي تلقائيًا، كما يدعم تحديد نوع الفيديو ونمطه ونبرة الصوت ولغة الفيديو النهائي والتكرار على الفيديوهات الموجودة. نأمل أن يساعدك هذا المستند على التكامل مع API واستخدامها بشكل أفضل. إذا كانت لديك أي أسئلة، فيرجى الاتصال بفريق الدعم الفني لدينا في أي وقت.
