`POST https://api.acedata.cloud/webextrator/extract`

تحوّل واجهة برمجة تطبيقات الاستخراج الذكي WebExtrator عنوان URL إلى **نتائج منظمة ومُصنّفة حسب النوع** — مقالات ومنتجات ووصفات
وفيديوهات ومناقشات ووظائف وغيرها، مع Markdown منظّف ونص عادي. استخدم هذه الواجهة عندما تريد «بيانات منظّمة
ونظيفة» بدلًا من HTML الخام.

## عملية التقديم

لاستخدام صفحة خدمة WebExtrator، يجب أولاً الذهاب إلى [وحدة التحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، احتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل، سيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد الانتهاء سيتم إرجاعك تلقائيًا إلى الصفحة الحالية.

**رمز API واحد يكفي لاستدعاء جميع خدمات المنصة، دون الحاجة لتقديم طلب منفصل لكل خدمة.** عند التقديم لأول مرة، ستحصل على رصيد مجاني لتجربته؛ عند نفاد الرصيد، يمكنك إعادة شحن الرصيد العام في [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [صفحة خدمة WebExtrator →](https://platform.acedata.cloud/service/webextrator)

## المصادقة

```
Authorization: Bearer YOUR_API_KEY
Content-Type:  application/json
```

## معلمات الطلب

يقبل Extract **جميع** معلمات [واجهة Render API](/ar/guides/webextrator/webextrator_render)
(`url`، `user_agent`، `timeout`، `wait_until`، `delay`، `wait_for_selector`،
`block_resources`، `headers`، `cookies`، `callback_url`، `bypass_cache`،
`cache_ttl_seconds`، `async`)، بالإضافة إلى حقلين خاصين بـ Extract:

| الحقل | النوع | مطلوب | الافتراضي | الوصف |
|------|------|:----:|------|------|
| `expected_type` | enum | ❌ | تحديد تلقائي | تلميح نوع الصفحة: `product` / `article` / `general`. حدّد نوع النتيجة المتوقع. |
| `enable_llm` | boolean | ❌ | `false` | يسمح باستدعاء نموذج لغوي كبير (LLM) للاستخراج عند عدم العثور على schema.org. في الصفحات التي لا تحتوي على JSON-LD، مثل Amazon / HN / Greenhouse، يجب تفعيله للحصول على نتائج ذات نوع محدد. |

### الحقول ذات المستوى الأعلى

| الحقل | النوع | الوصف |
|------|------|------|
| `kind` | string | `"extract"` ثابت. |
| `url` | string | عنوان URL الذي أرسلته. |
| `finalUrl` | string | عنوان URL النهائي بعد إعادة التوجيه. |
| `contentType` | enum | نوع الصفحة: `product` / `article` / `general`. |
| `title` | string | عنوان الصفحة. |
| `description` | string? | وصف الصفحة أو ملخصها. |
| `byline` | string? | المؤلف أو القناة أو الشركة. |
| `language` | string? | `<html lang>`.  |
| `siteName` | string? | `og:site_name`.  |
| `publishedAt` | string? | وقت النشر، بتنسيق ISO 8601. |
| `images` | string[] | بحد أقصى 50 من `<img src />`، تم تحليلها إلى عناوين URL مطلقة، وإزالة التكرارات، واستبعاد عناوين URI الخاصة بـ `data:`. |
| `links` | string[] | بحد أقصى 100 رابط خارجي، مع تصفية الأجزاء / `javascript:` / `mailto:` / `tel:`. |
| `markdown` | string | محتوى Markdown للصفحة. |
| `text` | string | النص العادي للصفحة. |
| `structured` | object | النتيجة المنظمة الكاملة، انظر أدناه. |
| `rawSignals` | object | معلومات تشخيصية لأغراض التصحيح. |
| `cached` | boolean? | تكون `true` عند العثور على نتيجة في ذاكرة التخزين المؤقت. |
| `cacheStoredAt` | number? | الطابع الزمني بـ Unix بالمللي ثانية عند كتابة إدخال ذاكرة التخزين المؤقت لأول مرة. |

### الحقول الفرعية لـ `data.structured`

| الحقل الفرعي | متى يظهر | الوصف |
|--------|---------|------|
| `schemaOrg` | دائمًا | `{ primary, breadcrumbs, all }`. ‏`primary` هو الكيان المصنّف ذو الأولوية الأعلى؛ وعند عدم العثور عليه تكون القيمة `null`. |
| `openGraph` | دائمًا | `{ title, description, image, type }`، مستمد من `<meta property="og:*" />`. |
| `jsonLd` | دائمًا | مصفوفة JSON الخام لجميع كتل `<script type="application/ld+json">`. |
| `llm` | عند تشغيل LLM ونجاحه | `{ kind, data, model, promptCharCount }`، نتيجة مصنّفة. |
| `llmError` | عند تشغيل LLM وفشله | `{ kind, error, model }`، لا يزال بإمكان الطلب إرجاع حقول أخرى تم استخراجها. |
| `amazon` | عندما يكون عنوان URL هو `amazon.*` | نتائج امتداد Amazon القديمة؛ استخدم النتائج المُحددة الأنواع للتكاملات الجديدة. |

## أنواع نتائج schema.org

يدعم `structured.schemaOrg.primary` أنواع النتائج التالية:

| نوع schema.org | kind | حقول الإخراج |
|----------------|----------|----------|
| `Product` | product | `name, sku, gtin, model, color, brand, url, images, offer.{price,currency,availability,condition,seller}, rating.{value,count}, reviews[], properties[]` |
| `Recipe` | recipe | `name, description, image, datePublished, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords, recipeCategory, recipeCuisine` |
| `VideoObject` | video | `name, description, thumbnailUrl, uploadDate, duration, embedUrl, contentUrl, channel, interactionCount` |
| `JobPosting` | job | `title, description, datePosted, validThrough, hiringOrganization, jobLocation, baseSalary, employmentType` |
| `Event` (بما في ذلك `*Event`) | event | `name, description, startDate, endDate, location.{name,address}, organizer, offer.{url,price,currency}` |
| `Article` / `NewsArticle` / `BlogPosting` / `ScholarlyArticle` / `TechArticle` / `Report` / `*NewsArticle` | article | `subtype, headline, description, datePublished, dateModified, author, publisher, image[], url, sameAs[]` |
| `FAQPage` | faq | `questions[{question, answer}]` |
| `BreadcrumbList` | (مُرفق بـ sibling) | يتم الإخراج دائمًا إلى `structured.schemaOrg.breadcrumbs[]`، ولن يكون primary. |

## أنواع نتائج LLM

عندما يكون `enable_llm: true` ولا تحتوي الصفحة على بيانات منظمة متاحة من schema.org، يمكن إرجاع نتائج استخراج من الأنواع التالية:

| Kind | الحقول المطلوبة | الحقول الاختيارية |
|------|---------|---------|
| `article` | `headline` | `description, byline, publishedAt, language, topics[], sections[{heading,summary}]` |
| `product` | `name` | `description, brand, sku, price, currency, availability, rating.{value,count}, bullets[], specifications[{name,value}]` |
| `discussion` | `title` | `author, postedAt, points, commentCount, body, url` |
| `recipe` | `name` | `description, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords[]` |
| `video` | `name` | `description, channel, uploadDate, duration, viewCount, likeCount, thumbnailUrl, transcript` |
| `job` | `title` | `description, company, location, remote, employmentType, datePosted, validThrough, salaryMin, salaryMax, salaryCurrency, salaryPeriod, responsibilities[], qualifications[]` |

## التخزين المؤقت

يمكن إعادة استخدام النتائج المخزنة مؤقتًا لعنوان URL نفسه ومعلمات الطلب و`cookies` و`headers`؛ وتُستخدم `async` و`bypass_cache` و`cache_ttl_seconds` للتحكم في طريقة التنفيذ وسلوك التخزين المؤقت.

| الحقل | 效果 |
|------|------|
| `bypass_cache: true` | تخطي القراءة؛ ستظل نتيجة هذه المرة تُكتب إلى ذاكرة التخزين المؤقت، ويمكن للطلب نفسه في المرة القادمة أن يصيبها. |
| `cache_ttl_seconds: 0` | لن يتم **تخزين** هذه الاستجابة مؤقتًا. |
| `cache_ttl_seconds: N` | تخصيص TTL لهذا العنصر (الافتراضي 3600 ثانية). |

ستتضمن الاستجابة التي تصيب ذاكرة التخزين المؤقت `data.cached: true` و`data.cacheStoredAt: <unix-ms>`.

## 异步模式与回调

设置 `async: true` 进入异步模式（提供 `callback_url` 也会自动进入）。平台立即返回（HTTP 200）：

```json
{
  "success": true,
  "task_id": "550e8400-...",
  "trace_id": "6ba7b810-...",
  "started_at": 1777717800.123
}
```

任务完成时把完整 envelope `POST` 到你的 `callback_url`（如果配置了）。也可以事
后通过 [`/webextrator/tasks`](/ar/guides/webextrator/webextrator_tasks) 主动查询。

### بايثون (requests)

```python
import os, requests

API_KEY = os.environ["ACEDATA_API_KEY"]

resp = requests.post(
    "https://api.acedata.cloud/webextrator/extract",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "url": "https://en.wikipedia.org/wiki/Diffbot",
        "expected_type": "article",
    },
    timeout=120,
)
resp.raise_for_status()
data = resp.json()["data"]

primary = (data.get("structured") or {}).get("schemaOrg", {}).get("primary")
print("contentType:", data["contentType"])
print("title:      ", data["title"])
print("byline:     ", data.get("byline"))
print("publishedAt:", data.get("publishedAt"))
if primary and primary["kind"] == "article":
    print("headline:    ", primary["headline"])
    print("dateModified:", primary.get("dateModified"))
```

### Node.js (fetch)

```js
const apiKey = process.env.ACEDATA_API_KEY;

const res = await fetch('https://api.acedata.cloud/webextrator/extract', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${apiKey}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://www.allrecipes.com/recipe/16354/easy-meatloaf/',
  }),
});
const { data } = await res.json();
const recipe = data?.structured?.schemaOrg?.primary;
console.log(recipe.name, recipe.cookTime, recipe.ingredients.length, 'نوع من المكونات');
```

## نصائح ومطبات

- **مرّر `expected_type` عند الحاجة إلى تحديد نوع الصفحة.** على سبيل المثال، تستخدم صفحة المقال `article`، وتستخدم صفحة المنتج `product`.
- **`enable_llm: true` مجاني للصفحات التي تحتوي على تطابق في schema.org.** لا يتم استدعاء LLM إلا عندما لا يكون لدى schema.org
  primary، لذا من الآمن تفعيله افتراضيًا.
- **عند التصحيح، تحقّق أولًا من `rawSignals.hasJsonLd`.** إذا كان `true` لكن `structured.schemaOrg.primary`
  هو `null`، فهذا يعني أن `@type` للصفحة غير مدعوم حاليًا، ويمكنك إبلاغنا بذلك.
- **`structured.llmError` ذو طابع معلوماتي.** قد ينجح الطلب مع ذلك في إرجاع حقول مستخرجة أخرى. راجع
  `llmError.error` لتحديد السبب (انتهاء المهلة، فشل تحليل JSON، فشل التحقق من البنية).
- **`links[]` للصفحات غير المقالات لا يجري ترتيبًا بحسب الصلة.** يتم فقط التنظيف بأفضل جهد وفقًا لـ"حد أقصى 100 عنصر + تصفية البروتوكولات غير الصالحة".
  تنظيف بأفضل جهد.
- **تُفرض رسوم أيضًا على إصابات ذاكرة التخزين المؤقت.**
