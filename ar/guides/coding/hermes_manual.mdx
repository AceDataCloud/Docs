## 1. الحصول على API Key

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، وادخل إلى التطبيق المتاح وانسخ API Key.

![الحصول على Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. حفظ Key

اكتب في `~/.hermes/.env`:

```dotenv
ACEDATACLOUD_API_KEY=API Key الخاص بك
```

## 3. تهيئة Provider

أضف إلى `~/.hermes/config.yaml`:

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

انتقل إلى [دليل النماذج](https://platform.acedata.cloud/models) لعرض أسماء النماذج (مثل `claude-opus-5` و`gpt-6-sol`)، واستبدل جميع قيم `MODEL_ID` بالاسم نفسه؛ عند التحقق الدقيق، اعتمد على قيمة `id` في استجابة `/v1/models`. هذه القيمة هي اسم النموذج الذي تستخدمه معلمة API `model`، وليست UUID للخدمة أو API. لا تكتب Key الحقيقي داخل YAML ولا تُرسل ملف `.env`.

## 4. التحقق

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

إذا أعاد 401، فتحقق من `~/.hermes/.env`؛ وإذا لم تدخل التهيئة حيز التنفيذ، فاخرج من Hermes بالكامل ثم أعد تشغيله.
