## 1. الحصول على مفتاح API

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، انتقل إلى التطبيقات المتاحة ونسخ مفتاح API.

![الحصول على مفتاح API من Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. الإعداد

يقرأ Kilo CLI ملف `kilo.jsonc`، ويستخرج مفتاح API من الصدفة التي تم تشغيل CLI منها.

اكتب في `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

ثم في الصدفة الحالية قم بتصدير الرمز:

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
```

## 3. التحقق

```bash
kilo run -m acedatacloud/MODEL_ID "Reply only OK"
```

إذا لم يتمكن CLI من قراءة الرمز، تأكد من أن المتغير قد تم `export`، وليس فقط مكتوبًا في ملف `.env` غير المحمّل.
