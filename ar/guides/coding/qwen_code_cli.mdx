يستخدم Qwen Code تكوين `modelProviders` في `~/.qwen/settings.json` لمزود مخصص. هنا يتم استخدام بروتوكول متوافق مع OpenAI بشكل ثابت.

## التكوين

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

يجب أن يكون `modelProviders.acedatacloud` مصفوفة. إدخالات المزود هي تكوينات مستقلة، ولن ترث تلقائيًا أي معلمات من السياق العلوي أو الرأس أو الجسم.

## التحقق

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Reply only OK"
```

ادخل ثم أرسل `Reply only OK`، ثم قم بتشغيل أداة قراءة الملفات مرة أخرى. إذا كانت نقطة النهاية متوافقة بشكل صارم ترفض تنسيق نتائج الأداة، يرجى التحقق من إصدار Qwen Code الحالي وبيان التوافق الرسمي.
