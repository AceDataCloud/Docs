## 1. الحصول على مفتاح API

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، انتقل إلى التطبيقات المتاحة وانسخ مفتاح API.

![الحصول على مفتاح API من Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. تثبيت OpenClaw والملحق

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

يتطلب الملحق OpenClaw `2026.4.2` أو إصدار أعلى، ويوفر حاليًا قدرات الدردشة والبحث على الويب بشكل أصلي.

## 3. تكوين المفتاح

يوصى باستخدام onboarding:

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "مفتاح API الخاص بك"
```

يمكنك أيضًا استخدام متغيرات البيئة:

```bash
export ACEDATACLOUD_API_KEY="مفتاح API الخاص بك"
```

## 4. اختياري: التكوين اليدوي

عند عدم استخدام onboarding، قم بتمكين الملحق وتعيين النموذج الافتراضي في `~/.openclaw/openclaw.json`:

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

لا تكتب مفتاح API في هذا الملف؛ استمر في استخدام متغيرات البيئة.

## 5. اختيار النموذج والتحقق

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "رد فقط OK"
```

استبدل `MODEL_ID` بالنموذج الذي يوفره Coding Plan حاليًا. إذا كنت بحاجة إلى تعيينه كنموذج افتراضي، قم بتشغيل:

```bash
openclaw models set acedatacloud/MODEL_ID
```

يمكنك عرض سجلات الاستدعاءات في [سجل الاستخدام](https://platform.acedata.cloud/console/usages). 401 تعني أن المفتاح غير صالح؛ إذا كان النموذج غير موجود، تحقق أولاً من ID الدقيق وإصدار الملحق. يشير `cost: 0` في دليل الملحقات فقط إلى أنه لا يتم إعادة تقدير التكلفة بواسطة OpenClaw، بينما يتم تسجيل التكلفة الفعلية بواسطة Ace Data Cloud.

## البحث على الويب

```bash
openclaw infer web search \
  --provider acedatacloud --query "أحدث أطر عمل الوكلاء الذكيين" --limit 5
```

لا تعتبر حاليًا القدرات المتعلقة بالصور أو الفيديو أو الموسيقى المذكورة في مقدمة الملحق كقدرات أصلية لمزود OpenClaw.
