## 1. الحصول على API Key

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، وادخل إلى التطبيق المتاح وانسخ API Key.

![الحصول على Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. التكوين

يوفر Roo Code رسميًا OpenAI-compatible Provider، ويتطلب أن يدعم النموذج استدعاء OpenAI tools/function calling الأصلي.

1. افتح إعدادات Roo Code في VS Code.
2. اضبط **API Provider** على **OpenAI Compatible**.
3. املأ:

| الحقل       | القيمة                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | API Key الذي نسخته للتو                  |
| Model ID | معرّف النموذج الذي تم اختياره في معالج إعداد Coding         |

![واجهة تكوين Roo Code OpenAI Compatible](https://cdn.acedata.cloud/b6a0e7156438.png)

بعد ذلك، اضبط خيارات context وmax output والصور وcomputer-use وفقًا للقدرات الفعلية للنموذج. أخيرًا، احفظ التكوين وأعد تحميل VS Code.

## 3. التحقق

أرسل أولًا `Reply only OK`، ثم اطلب من Roo Code قراءة ملف اختبار. إذا نجحت المحادثة العادية ولكن فشلت أداة Agent، فاستبدل النموذج بآخر يدعم tool calling الأصلي، وتأكد من أن نقطة النهاية المتوافقة يمكنها إعادة معاملات الأداة ونتائجها بشكل متدفق صحيح.
