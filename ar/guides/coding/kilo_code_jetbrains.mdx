## 1. الحصول على مفتاح API

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، انتقل إلى التطبيقات المتاحة وانسخ مفتاح API.

![الحصول على مفتاح API من Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. تكوين المزود

تستخدم إضافة كود كيلومتر لجيهت برينز تنسيق مزود `kilo.jsonc`. يجب أن يكون التكوين موجودًا في بيئة المستخدم التي تعمل فيها الإضافة؛ عادةً ما يكون ذلك في المضيف الخلفي البعيد أثناء التطوير عن بُعد.

اكتب في `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

قم بتصدير `ACEDATACLOUD_API_KEY` في بيئة تشغيل جيهت برينز الخلفية، ثم أعد تشغيل IDE أو المضيف الخلفي البعيد.

## 3. التحقق

اختر `acedatacloud/MODEL_ID`، أرسل `Reply only OK`، ثم اجعل الوكيل يقرأ ملف اختبار. إذا كان يعمل محليًا ولكنه فشل عن بُعد، تحقق أولاً من أن ملف التكوين ومتغيرات البيئة مكتوبة في المضيف البعيد.
