يدعم Continue واجهة برمجة التطبيقات المتوافقة مع OpenAI. لتثبيت استخدام Chat Completions، يجب تعيين `useResponsesApi: false` بشكل صريح.

## الإعداد

أضف إلى ملف YAML المحلي الخاص بـ Continue:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

احفظ `ACEDATACLOUD_API_KEY` في إدارة الأسرار الخاصة بـ Continue، ولا تقم بتقديم الرمز الحقيقي إلى إعدادات المشروع. تم إلغاء إعداد JSON الخاص بـ Continue، ويستخدم الإعداد الجديد YAML.

## التحقق

أعد تحميل VS Code، افتح الشريط الجانبي لـ Continue، اختر النموذج في Local Config وأرسل `Reply only OK`؛ ثم نفذ مرة أخرى مهمة قراءة الملفات فقط. إذا تم إرسال الطلب بشكل خاطئ إلى `/responses`، تحقق مما إذا كانت `useResponsesApi: false` موجودة ضمن إدخال النموذج.
