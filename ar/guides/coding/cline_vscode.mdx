## 1. الحصول على API Key

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، وادخل إلى التطبيق المتاح وانسخ API Key.

![الحصول على Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. إعداد Cline

ثبّت وافتح Cline في VS Code، ثم ادخل إلى إعدادات Provider عبر زر الإعدادات في لوحة Cline، واملأ:

| الحقل                                | القيمة                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| API Provider                      | `OpenAI Compatible`                                                                            |
| Base URL                          | `https://api.acedata.cloud/v1`                                                                 |
| API Key                           | API Key الذي نسخته للتو                                                                                  |
| Model ID                          | انتقل إلى [دليل النماذج](https://platform.acedata.cloud/models) للاطلاع، واملأ اسم النموذج المستهدف كما هو، مثل `claude-opus-5` و`gpt-6-sol` |
| Custom Headers                    | اتركه فارغًا                                                                                             |
| Set Azure API version             | اتركه فارغًا                                                                                             |
| Use Azure Identity Authentication | إيقاف                                                                                             |

![واجهة إعداد Cline OpenAI Compatible](https://cdn.acedata.cloud/8f356c2f1378.png)

`Model ID` هو اسم النموذج المستخدم بواسطة معامل `model` في طلب API، وليس UUID للخدمة أو API، ولا يمكن اختصاره ذاتيًا. يمكنك الاطلاع عليه أولًا في [دليل النماذج](https://platform.acedata.cloud/models)؛ وإذا احتجت إلى تحقق دقيق، فاستخدم API Key الحالي لطلب `GET https://api.acedata.cloud/v1/models`، وانسخ قيمة `id` للنموذج المستهدف من مصفوفة `data` في الاستجابة.

أبقِ إعدادات قدرات النموذج الأخرى على الوضع الافتراضي مؤقتًا؛ وعند الحاجة إلى الصور أو سياق أكبر، اضبطها لاحقًا وفقًا للقدرات الفعلية للنموذج المحدد.

## 3. التحقق

بعد الحفظ، أنشئ مهمة جديدة وأرسل `Reply only OK`。ثم اطلب من Cline قراءة ملف اختبار، للتأكد من أن النموذج يدعم استدعاء الأدوات؛ ويمكن الاطلاع على سجلات الاستدعاء في [سجل الاستخدام](https://platform.acedata.cloud/console/usages).

يشير 401 عادةً إلى أن Key غير صحيح؛ ويشير 404 عادةً إلى أن Base URL غير صحيح، أو أن Model ID المُدخل لا يتطابق تمامًا مع `id` في الدليل. إذا كان النموذج يستطيع الدردشة لكنه لا يستطيع التعامل مع الملفات، فتحقق من قدرة النموذج على استدعاء الأدوات.
