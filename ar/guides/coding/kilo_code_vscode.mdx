## 1. الحصول على API Key

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، وادخل إلى التطبيق المتاح وانسخ API Key.

![الحصول على Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. إضافة Custom provider

افتح **Settings → Providers** في Kilo Code، وانقر على **Custom provider**، ثم املأ:

| الحقل           | القيمة                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------- |
| Provider ID  | `acedatacloud`                                                                                 |
| Display name | `AceDataCloud`                                                                                 |
| Provider API | `OpenAI Compatible`                                                                            |
| Base URL     | `https://api.acedata.cloud/v1`                                                                 |
| API key      | API Key الذي نسخته للتو                                                                            |
| Models       | انتقل إلى [دليل النماذج](https://platform.acedata.cloud/models) للاطلاع، وأضف اسم النموذج الذي تريد استخدامه، مثل `claude-opus-5` و`gpt-6-sol` |

![واجهة إعداد Kilo Code Custom provider](https://cdn.acedata.cloud/94eb5abd7a6f.png)

إن `id` الخاص بالنموذج هنا هو اسم النموذج الذي يستخدمه المعامل `model` في طلب API، وليس UUID للخدمة أو API. يمكنك الاطلاع عليه أولًا في [دليل النماذج](https://platform.acedata.cloud/models)؛ وعند التحقق الدقيق، يرجى نسخه كما هو من مصفوفة `data` في استجابة `/v1/models`، ولا تخمّنه أو تختصره بنفسك.

انقر على **Submit**، وسيظهر النموذج في المحدد. عند الحاجة إلى مشاركة الفريق أو إعدادات أكثر تفصيلًا، يمكنك أيضًا تحرير `~/.config/kilo/kilo.jsonc` على مستوى المستخدم أو `./kilo.jsonc` على مستوى المشروع وفقًا للوثائق الرسمية.

## 3. التحقق

اختر `acedatacloud/MODEL_ID` وأرسل `أجب بـ OK فقط`، ثم نفّذ عملية ملف للقراءة فقط مرة أخرى. إذا لم يظهر النموذج، فتحقق مما إذا كان Provider قد تم إرساله، وما إذا كان اسم النموذج مطابقًا تمامًا لـ `id` في الدليل، وما إذا كان Base URL صحيحًا.
