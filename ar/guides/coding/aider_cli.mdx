يتصل Aider بواجهة برمجة التطبيقات المتوافقة مع OpenAI من خلال نموذج LiteLLM باستخدام بادئة `openai/`.

## الإعدادات

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

استبدل `MODEL_ID` بالنموذج الذي اخترته في معالج إعدادات البرمجة. يمكنك أيضًا كتابة الخيارات المقابلة في ملف `.env` المحلي أو `.aider.conf.yml`، لكن لا تقم بتقديم رمز التوكن الحقيقي.

## التحقق

```bash
aider --model openai/MODEL_ID --message "Reply only OK"
```

عند استخدام نموذج غير معروف للمرة الأولى، قد يُظهر Aider رسالة تفيد بعدم وجود بيانات وصفية للنموذج؛ وهذا لا يعادل فشل التحقق. تحقق من رمز التوكن في 401، وتحقق من معرف النموذج وBase URL `/v1` في 404.
