توفر وثائق نموذج Coze الرسمية دعمًا لواجهة برمجة تطبيقات OpenAI Chat. قد تختلف معالجة تجميع المسارات، والإخراج المتدفق، واستدعاءات الأدوات بين إصدارات Coze المختلفة، لذا يرجى التحقق من كل نقطة أدناه عند الاتصال لأول مرة.

## التكوين

1. انتقل إلى إدارة نماذج Coze وأضف نموذجًا مخصصًا جديدًا.
2. اختر بروتوكول OpenAI Chat API.
3. املأ عنوان API الأساسي بـ `https://api.acedata.cloud/v1`.
4. املأ مفتاح API برمز Ace Data Cloud API الخاص بك.
5. املأ النموذج بمعرف النموذج الدقيق المدعوم في دليل النماذج لتجميع المحادثات.
6. احفظ وأكمل اختبار الاتصال بـ Coze.
7. في Bot/Agent، أرسل `Reply only OK`، ثم اختبر استدعاء الأداة مرة أخرى.

## الحدود الحالية

- قد تعرض مناطق أو إصدارات أو باقات Coze المختلفة نماذج مختلفة.
- يجب استخدام عنوان API الأساسي كقاعدة، ولا تضف `/chat/completions` مرة أخرى؛ إذا كانت واجهة المستخدم الحالية تطلب عنوان API كامل، فاستند إلى إشعار النموذج.
- تجميع المحادثات، والاستجابات، ورسائل Anthropic هي ثلاث مسارات مستقلة، ولا يمكن استبدالها للتحقق.
