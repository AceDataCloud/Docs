## 1. الحصول على مفتاح API

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، وادخل إلى التطبيق المتاح وانسخ مفتاح API.

![الحصول على مفتاح Ace Data Cloud API](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. تثبيت Kimi Code

macOS / Linux:

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

يمكن أيضًا التثبيت عبر npm:

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. إعداد AceDataCloud

حرّر `~/.kimi/config.toml`، وأضف الإعدادات التالية:

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "مفتاح API الخاص بك"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

انتقل إلى [دليل النماذج](https://platform.acedata.cloud/models) لعرض أسماء النماذج (مثل `claude-opus-5` و`gpt-6-sol`)، واستبدل جميع `MODEL_ID` بالاسم نفسه؛ عند التحقق الدقيق، اعتمد على قيمة `id` في استجابة `/v1/models`. هذه القيمة هي اسم النموذج المستخدم في معامل API `model`، وليست UUID للخدمة أو API. يستخدم `type = "openai"` بروتوكول OpenAI Chat Completions.

يحتوي ملف الإعدادات على المفتاح، ويُنصح في macOS / Linux بتقييد الصلاحيات:

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. التحقق والبدء

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

بعد الدخول إلى المشروع، شغّل `kimi` لبدء الاستخدام. إذا ظهرت 401، فتحقق من مفتاح API؛ وإذا ظهرت رسالة model not found، فتأكد من أن `default_model` واسم جدول النموذج وحقل `model` تستخدم المعرّف نفسه.
