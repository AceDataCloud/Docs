## 1. الحصول على API Key

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، وادخل إلى التطبيق المتاح وانسخ API Key.

![الحصول على Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. تشغيل المعالج

```bash
hermes model
```

اختر **Custom endpoint**، واملأ القيم التالية بالترتيب:

| الحقل             | القيمة                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | API Key الذي نسخته للتو                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | انتقل إلى [دليل النماذج](https://platform.acedata.cloud/models) للاطلاع عليه، واملأ اسم النموذج المستهدف كما هو، مثل `claude-opus-5` و`gpt-6-sol` |
| Context length | اتركه فارغًا للاكتشاف التلقائي، أو املأه وفقًا لدليل النماذج                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model` هو اسم النموذج المستخدم في معلمة `model` ضمن طلب API، وليس UUID الخاص بالخدمة أو API. يمكنك الاطلاع عليه أولًا في [دليل النماذج](https://platform.acedata.cloud/models)؛ وإذا احتجت إلى تحقق دقيق، فاستخدم API Key الحالي لطلب `GET https://api.acedata.cloud/v1/models`، وانسخ قيمة `id` للنموذج المستهدف من مصفوفة `data` في الاستجابة.

سيكتب المعالج إلى `~/.hermes/config.yaml` وملف بيانات الاعتماد المحلي.

## 3. التحقق

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

إذا لم يحفظ المعالج الإعدادات، يمكنك تشغيل `hermes model --reset` ثم المحاولة مجددًا؛ يشير 401 إلى أن API Key غير صالح أو لم تتم قراءته من إعدادات المستخدم الحالي.
