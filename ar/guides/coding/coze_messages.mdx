توفر وثائق نموذج Coze الرسمية دعمًا لواجهة برمجة تطبيقات Anthropic Messages. قد تختلف معالجة الإصدارات المختلفة من مستأجري Coze لـ Header، وتجميع المسارات، والبث، واستدعاءات الأدوات، لذا يرجى التحقق من كل عنصر أدناه عند الاتصال لأول مرة.

## التكوين

1. الدخول إلى إدارة نماذج Coze وإضافة نموذج مخصص جديد.
2. اختيار Protocol كواجهة برمجة تطبيقات Anthropic Messages.
3. ملء Base API URL بـ `https://api.acedata.cloud`.
4. ملء API Key برمز Ace Data Cloud API الخاص بك.
5. ملء Model بمعرف النموذج الدقيق المدعوم من Anthropic Messages في دليل النماذج.
6. حفظ وإكمال اختبار الاتصال بـ Coze.
7. إرسال `Reply only OK` في Bot/Agent، ثم اختبار استدعاء الأداة مرة أخرى.

## الحدود الحالية

- قد تعرض مناطق أو إصدارات أو باقات Coze المختلفة نماذج مختلفة.
- يجب ألا يتم تكرار إضافة `/v1/messages` إلى Base API URL؛ إذا كانت واجهة المستخدم الحالية تطلب صراحةً عنوان API الكامل، يجب اتباع إشعار النموذج.
- Messages وChat Completions وResponses هي ثلاث مسارات مستقلة، ولا يمكن استبدالها للتحقق.
