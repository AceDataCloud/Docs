[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) هو وكيل برمجي يعمل محليًا. يقوم بقراءة مساحة العمل، واستدعاء الأدوات وتنفيذ الأوامر، ثم يستدعي النموذج من خلال واجهة Chat Completions المتوافقة مع OpenAI.

> هذه الوثيقة مناسبة لـ `deepseek-harness-sdk==0.1.0rc6` و `deepseek-harness-runtime-bin==0.1.0rc6`. بعد ترقية العميل، يرجى إعادة إكمال اختبار الملفات للقراءة فقط أدناه.

## نطاق الدعم

| المشروع         | التكوين                                   |
| -------------- | ---------------------------------------- |
| عنوان API الأساسي | `https://api.acedata.cloud/v1`           |
| النموذج         | `deepseek-v4-pro`                        |
| البروتوكول      | Chat Completions المتوافقة مع OpenAI (تدفق) |
| القدرات         | نص، عملية استدلال، استدعاء أدوات الدوال، حلقة أدوات Bash المحلية، إحصائيات الاستخدام |

ستتغير قائمة النماذج. قبل التشغيل، استخدم مفتاح خاص بخطة البرمجة للاستعلام عن القائمة الحية:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY"
```

تأكد من أن الاستجابة تحتوي على `deepseek-v4-pro`. لا تعتبر `deepseek-v4-flash` بديلاً مكافئًا لوضع الأدوات في هذه الوثيقة؛ في اختبار الإصدار الثابت هذا، لم تنجح تاريخ الاستدلال المتعدد والدعوة للأدوات.

## 1. إعداد مفتاح خاص

افتح [تطبيق خطة البرمجة](https://platform.acedata.cloud/console/applications)، انتقل إلى تطبيق البرمجة الذي تم شراؤه، أنشئ أو انسخ مفتاح API الخاص بهذا التطبيق. لا تستخدم خطة البرمجة رصيدًا عامًا، ولا يمكن لمفاتيح التطبيقات الأخرى تمثيل صلاحيات الحزمة.

ضع المفتاح فقط في shell الحالي:

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_CODING_KEY_HERE"
export DEEPSEEK_BASE_URL="https://api.acedata.cloud/v1"
export DEEPSEEK_API_KEY="$ACEDATACLOUD_API_KEY"
```

لا تكتب المفتاح الحقيقي في السكربتات، مستودعات التكوين، لقطات الشاشة أو سجلات الجلسة.

## 2. إنشاء مساحة عمل معزولة

تحتوي حزمة التشغيل المدمجة لـ Harness على أدوات Bash محلية. في أول تحقق، لا توجه إلى مشروع حقيقي أو الدليل الرئيسي؛ أنشئ دليلًا لمرة واحدة بدون أسرار:

```bash
mkdir -p /tmp/deepseek-harness-demo/workspace
mkdir -p /tmp/deepseek-harness-demo/sessions
printf 'compatibility fixture\n' > /tmp/deepseek-harness-demo/workspace/fixture.txt
python3 -m venv /tmp/deepseek-harness-demo/venv
/tmp/deepseek-harness-demo/venv/bin/pip install \
  "deepseek-harness-sdk==0.1.0rc6"
```

إذا كانت شبكة الشركة تستخدم صورة PyPI خاصة، يرجى التأكد من وجود نفس إصدار `deepseek-harness-runtime-bin` في الصورة. لا تستخدم `danger-full-access` لتوسيع نطاق الوصول إلى الملفات؛ مثال هذه الوثيقة يمرر فقط الدليل لمرة واحدة إلى `cwd`.

## 3. تشغيل SDK Python الرسمي

احفظ المحتوى أدناه كـ `/tmp/deepseek-harness-demo/run.py`:

```python
import os

from deepseek_harness import DeepSeekHarness

with DeepSeekHarness(
    provider="deepseek-official",
    model="deepseek-v4-pro",
    max_tokens=160,
    cwd="/tmp/deepseek-harness-demo/workspace",
    session_root="/tmp/deepseek-harness-demo/sessions",
    base_url=os.environ["DEEPSEEK_BASE_URL"],
    api_key=os.environ["DEEPSEEK_API_KEY"],
    request_timeout_seconds=180,
) as harness:
    result = harness.run(
        "Read fixture.txt once, then reply with exactly: sdk-harness-ok",
        session_id="acedatacloud-compat",
    )

print(result.final_response)
print(result.finish_reason)
```

التشغيل:

```bash
/tmp/deepseek-harness-demo/venv/bin/python \
  /tmp/deepseek-harness-demo/run.py
```

النتيجة المتوقعة:

```text
sdk-harness-ok
completed
```

تتحقق هذه الخطوة من مصادقة Bearer، `/v1/chat/completions`، SSE، محتوى الاستدلال، استدعاء الأدوات وإرجاع نتائج الأدوات. بعد الانتهاء، يمكنك حذف `/tmp/deepseek-harness-demo`؛ إذا كانت مجلدات الجلسة تحتوي على سياق المشروع، يجب أيضًا الاحتفاظ بها بمستوى حساسية مماثل لمستودع الشيفرة.

## الأسئلة الشائعة

- **401**: تحقق مما إذا كان `ACEDATACLOUD_API_KEY` قد تم تصديره إلى نفس shell الذي يتم فيه تشغيل Python.
- **403 أو إشعار الحصة**: تأكد من أن المفتاح ينتمي إلى تطبيق البرمجة الحالي، وأن الحزمة لا تزال سارية ولديها رصيد متبقي.
- **النموذج غير متاح**: أعد الاستعلام عن `/v1/models`، ولا تخمن اسم النموذج بناءً على لقطات قديمة.
- **خطأ في `reasoning_content` / استرجاع الأدوات**: تأكد من أن SDK / runtime هما الإصدار الثابت في هذه الوثيقة، واستخدم `deepseek-v4-pro`.
- **عدد تنفيذ الأدوات غير طبيعي**: أوقف تشغيل المهام التي قد تسبب آثارًا جانبية، واستخدم أولاً fixture للقراءة فقط للتحقق من إصدار الخدمة الحالي.
- **فشل التثبيت**: تأكد من أن Python 3.10+، وهندسة نظام التشغيل مدعومة من قبل العجلة الحالية، وتحقق من توافق إصدار SDK / runtime.

## حدود القدرات

تتحقق هذه الوثيقة فقط من نص SDK Python المحلي إلى Chat Completions ودورة الأدوات. الصور، واجهة API للملفات، `/v1/responses`، `/v1/messages`، مساحة العمل البعيدة وsandbox المستضاف ليست ضمن نطاق هذا الدليل؛ صلاحيات مساحة العمل ومخاطر الأوامر المحلية تقع على عاتق الجهاز والتكوين الذي يقوم بتشغيل Harness.
