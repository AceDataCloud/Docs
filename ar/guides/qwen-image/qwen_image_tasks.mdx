description: "Qwen Image 3 API guide - Ace Data Cloud"
---

استخدم `POST https://api.acedata.cloud/qwen-image/tasks` لاستعلام عن مهام توليد الصور غير المتزامنة. هذه الواجهة مجانية.

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

للاستعلام الجماعي، استخدم `action=retrieve_batch` ومصفوفة `ids`. بعد نجاح المهمة، تحتوي `response.data` على العنوان الدائم للصور المولدة والاستخدام الفعلي.
