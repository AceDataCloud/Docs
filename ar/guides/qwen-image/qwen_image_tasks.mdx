---

`POST https://api.acedata.cloud/qwen-image/tasks` تُستخدم لاستعلام، استعلام جماعي أو حذف مهام Qwen Image غير المتزامنة. هذه الواجهة لا تنتج استهلاك إضافي للواجهة البرمجية.

## استعلام مهمة واحدة

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

بعد إكمال المهمة، يحتوي `response.data` على عنوان الصورة الدائم على CDN، و`response.usage` يحتوي على العدد الحقيقي للإدخال/الإخراج، و`response.cost` هو معلومات تسوية المهمة المُنشأة.

## استعلام جماعي

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

يرجع `{ "items": [...], "count": 2 }`. يدعم استعلام القائمة أيضًا التصفية حسب المستخدم، التطبيق ونطاق وقت الإنشاء.

## حذف سجل المهام

```json
{"action":"delete","id":"TASK_ID"}
```

الحذف يؤثر فقط على سجل المهام، ولن يحذف ملفات CDN التي تم إنشاؤها.
