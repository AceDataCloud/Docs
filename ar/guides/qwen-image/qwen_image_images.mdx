`POST https://api.acedata.cloud/qwen-image/images` من خلال نفس الواجهة لإكمال إنشاء الصور والنماذج المرجعية من 1 إلى 3 صور، تدعم `qwen-image-3.0` و `qwen-image-3.0-pro`.

## اختيار النموذج

| النموذج                   | السيناريو المناسب       | السعر الرسمي القياسي                   |
| -------------------- | ---------- | ----------------------- |
| `qwen-image-3.0`     | الإبداع الجماعي، التكرار السريع  | الإخراج $0.030/صورة             |
| `qwen-image-3.0-pro` | تخطيط معقد، دقة عالية | 1K $0.040/صورة؛ 2K $0.075/صورة |

تُحتسب رسوم الصور المرجعية بناءً على العدد الفعلي المدخل، السعر الرسمي القياسي $0.003/صورة.

## إنشاء متزامن

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "دائرة حمراء بسيطة في وسط خلفية بيضاء نظيفة.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

تتضمن الاستجابة الناجحة عنوان صورة CDN دائم، الاستخدام الفعلي وتكلفة هذه العملية:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## تحرير الصور المرجعية

زيادة `image_urls`، تدعم 1–3 صور يمكن الوصول إليها علنًا:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "احتفظ بالموضوع، غير الخلفية إلى نمط ملصق دافئ**###**",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"
  ],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` يُستخدم فقط لإنشاء الصور. نطاق `n` هو 1–6؛ يجب أن يكون نسبة العرض إلى الارتفاع بين 1:8 و 8:1.

## المهام غير المتزامنة

بعد تعيين `async: true`، تعيد الواجهة على الفور `task_id`. استخدم `/qwen-image/tasks` للاستعلام عن الحالة النهائية، أو مرر `callback_url` لتلقي إشعار الانتهاء. يتم احتساب التكلفة مرة واحدة فقط، ولا يتم فرض رسوم على استعلامات المهام المتكررة.
