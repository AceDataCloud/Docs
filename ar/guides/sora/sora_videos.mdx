تقدم هذه الوثيقة شرحًا لكيفية دمج واجهة برمجة تطبيقات توليد فيديوهات Sora، والتي تسمح بإدخال معلمات مخصصة لتوليد فيديوهات رسمية من Sora. تدعم هذه الواجهة نمطين من الإصدارات:

- **الإصدار 1 (النمط الكلاسيكي)**: يدعم معلمات مثل `duration` (10/15/25 ثانية)، `orientation` (أفقي/عمودي)، `size` (وضوح صغير/كبير)، صور مرجعية `image_urls`، ورابط الشخصية `character_url` وغيرها.
- **الإصدار 2 (نمط الشركاء)**: يدعم معلمات مثل `seconds` (4/8/12 ثانية)، دقة بكسلية `size` (مثل 1280x720)، وصور مرجعية `input_reference` وغيرها.

## عملية التقديم

لاستخدام الواجهة، يجب أولاً التقديم للحصول على الخدمة من خلال صفحة [Sora Videos Generation API](https://platform.acedata.cloud/documents/99a24421-2e22-4028-8201-e19cb834b67e). بعد الدخول إلى الصفحة، اضغط على زر "Acquire" كما هو موضح في الصورة:

![](https://cdn.acedata.cloud/q6ytrc.png)

إذا لم تكن مسجلاً أو مسجلاً دخولًا، سيتم توجيهك تلقائيًا إلى صفحة تسجيل الدخول أو التسجيل، وبعدها ستعود تلقائيًا إلى الصفحة الحالية.

عند التقديم لأول مرة، ستحصل على رصيد مجاني لاستخدام الواجهة مجانًا.

## الاستخدام الأساسي (الإصدار 1)

أولاً، لفهم طريقة الاستخدام الأساسية للإصدار 1، يتم إدخال عبارة التوجيه `prompt`، ومصفوفة روابط الصور المرجعية `image_urls`، والنموذج `model` للحصول على النتيجة المعالجة، كما يلي:

<p><img src="https://cdn.acedata.cloud/h8dyz3.png" width="500" className="m-auto" /></p>

يمكن ملاحظة أننا قمنا بتعيين رؤوس الطلب (Request Headers) كالتالي:

- `accept`: نوع الاستجابة المطلوبة، هنا `application/json` أي بصيغة JSON.
- `authorization`: مفتاح استدعاء الواجهة، يمكن اختياره من القائمة المنسدلة بعد التقديم.

كما قمنا بتعيين جسم الطلب (Request Body) كالتالي:

- `model`: نموذج توليد الفيديو، يدعم `sora-2` (النمط القياسي) و `sora-2-pro` (النمط عالي الدقة). يدعم `sora-2-pro` مدة فيديو تصل إلى 25 ثانية، بينما يدعم `sora-2` 10 أو 15 ثانية فقط.
- `size`: وضوح الفيديو، `small` للوضوح القياسي، و `large` للوضوح العالي (خاص بالإصدار 1 فقط).
- `duration`: مدة الفيديو، يدعم 10، 15، 25 ثانية، حيث 25 ثانية مدعومة فقط في `sora-2-pro` (خاص بالإصدار 1).
- `orientation`: اتجاه الفيديو، يدعم `landscape` (أفقي) و `portrait` (عمودي) (خاص بالإصدار 1).
- `image_urls`: مصفوفة روابط الصور المرجعية لتوليد الفيديو من الصور (خاص بالإصدار 1).
- `character_url`: رابط الشخصية، لا يمكن أن يحتوي الفيديو على أشخاص حقيقيين (خاص بالإصدار 1).
- `character_start`/`character_end`: وقت ظهور الشخصية بالثواني، نطاق الفرق 1-3 ثواني (خاص بالإصدار 1).
- `prompt`: عبارة التوجيه (مطلوبة).
- `callback_url`: رابط استدعاء رد الاتصال غير المتزامن.
- `version`: إصدار الواجهة، `1` (افتراضي) أو `2`.

## مهمة توليد فيديو من الصور (الإصدار 1)

إذا رغبت في توليد فيديو من الصور، يجب تمرير معلمة `image_urls` التي تحتوي على روابط الصور المرجعية، ويمكن تحديد المحتويات كما يلي:

- `image_urls`: مصفوفة روابط الصور المرجعية المستخدمة في توليد الفيديو. يجب عدم تمرير صور لأشخاص حقيقيين لتجنب فشل المهمة.

مثال تعبئة:

<p><img src="https://cdn.acedata.cloud/ch7x3t.png" width="500" className="m-auto" /></p>

بعد التعبئة، يتم توليد الكود تلقائيًا كما يلي:

<p><img src="https://cdn.acedata.cloud/z1ud8l.png" width="500" className="m-auto" /></p>

الكود المقابل:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "large",
    "duration": 15,
    "orientation": "landscape",
    "prompt": "cat running on the river",
    "model": "sora-2",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## مهمة توليد فيديو من شخصية (الإصدار 1)

- `character_url`: رابط فيديو لإنشاء الشخصية، لا يجب أن يحتوي الفيديو على أشخاص حقيقيين.

## نمط الإصدار 2

بالإضافة إلى نمط الإصدار 1، تدعم الواجهة نمط الإصدار 2 من خلال تعيين معلمة `version` إلى `2`. يدعم الإصدار 2 مدة فيديو أقصر وتحكمًا دقيقًا في دقة البكسل.

### شرح معلمات الإصدار 2

| المعلمة       | النوع    | إلزامية | الوصف                              |
|---------------|----------|---------|-----------------------------------|
| `version`     | عدد صحيح | نعم     | تعيين القيمة إلى `2`              |
| `prompt`      | نص      | نعم     | عبارة التوجيه لتوليد الفيديو       |
| `model`       | نص      | لا      | `sora-2` (افتراضي) أو `sora-2-pro` |
| `duration`    | عدد صحيح | لا      | مدة الفيديو: `4` (افتراضي)، `8`، `12` ثانية |
| `size`        | نص      | لا      | الدقة: `720x1280` (افتراضي)، `1280x720`، `1024x1792`، `1792x1024` |
| `image_urls`  | مصفوفة  | لا      | مصفوفة روابط الصور المرجعية، تستخدم الصورة الأولى فقط، ويجب أن تتطابق أبعاد الصورة مع معلمة `size` |
| `callback_url`| نص      | لا      | رابط استدعاء رد الاتصال غير المتزامن |

### مثال أساسي

```shell
curl -X POST 'https://api.acedata.cloud/sora/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "version": 2,
  "prompt": "cat running on the river",
  "model": "sora-2",
  "duration": 8,
  "size": "1280x720"
}'
```

الكود المقابل بلغة Python:


### استخدام الصور المرجعية (الإصدار 2)

في نمط الإصدار 2، يمكن تمرير معلمة `image_urls` لتمرير صورة مرجعية لتوجيه توليد الفيديو (تستخدم الصورة الأولى فقط):

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "version": 2,
    "prompt": "a person walking through a beautiful garden",
    "model": "sora-2",
    "duration": 4,
    "size": "1280x720",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

> **ملاحظة**: يجب أن تتطابق أبعاد الصورة المرجعية مع معلمة `size`، على سبيل المثال إذا كانت `size` هي `1280x720`، يجب أن تكون أبعاد الصورة 1280×720.

### مقارنة معلمات الإصدار 1 و 2

| المعلمة        | الإصدار 1             | الإصدار 2                              |
|----------------|-----------------------|---------------------------------------|
| `version`      | 1 (افتراضي)           | 2                                     |
| `prompt`       | ✅                    | ✅                                    |
| `model`        | ✅ sora-2 / sora-2-pro | ✅ sora-2 / sora-2-pro                 |
| `duration`     | ✅ 10/15/25 ثانية      | ✅ 4/8/12 ثانية                        |
| `orientation`  | ✅ landscape/portrait  | ❌                                    |
| `size`         | ✅ small/large         | ✅ 720x1280/1280x720/1024x1792/1792x1024 |
| `image_urls`   | ✅ عدة صور مرجعية     | ✅ تستخدم الصورة الأولى فقط           |
| `character_url`| ✅                     | ❌                                    |
| `callback_url` | ✅                     | ✅                                    |

## رد الاتصال غير المتزامن

نظرًا لأن توليد فيديوهات Sora يستغرق وقتًا نسبيًا طويلًا (حوالي 1-2 دقيقة)، وإذا لم يستجب API لفترة طويلة، ستظل طلبات HTTP متصلة مما يستهلك موارد النظام. لذلك توفر الواجهة دعمًا لرد الاتصال غير المتزامن.

العملية كالتالي: عند إرسال الطلب، يتم تمرير معلمة `callback_url` التي تحدد عنوان URL لاستقبال رد الاتصال. بعد إرسال الطلب، تعيد الواجهة فورًا نتيجة تحتوي على `task_id` لتمثيل معرف المهمة. عند إتمام المهمة، ترسل الواجهة نتيجة توليد الفيديو عبر طلب POST بصيغة JSON إلى عنوان `callback_url` المحدد، مع تضمين `task_id` لربط النتائج بالمهمة.

فيما يلي مثال توضيحي.

أولًا، رد الاتصال Webhook هو خدمة تستقبل طلبات HTTP، ويجب على المطور استبدالها بعنوان URL لخادم HTTP الخاص به. لأغراض العرض، نستخدم موقع Webhook عام https://webhook.site/، حيث يمكنك الحصول على عنوان URL لرد الاتصال كما في الصورة:

![](https://cdn.acedata.cloud/cjjfly.png)

## معالجة الأخطاء

عند استدعاء الواجهة، إذا حدث خطأ، ستعيد الواجهة رمز الخطأ والمعلومات المناسبة، مثل:

- `400 token_mismatched`: طلب غير صحيح، ربما بسبب معلمات مفقودة أو غير صحيحة.
- `400 api_not_implemented`: طلب غير صحيح، ربما بسبب معلمات مفقودة أو غير صحيحة.
- `401 invalid_token`: غير مصرح، رمز التفويض مفقود أو غير صالح.
- `429 too_many_requests`: عدد الطلبات كبير جدًا، تجاوزت الحد المسموح.
- `500 api_error`: خطأ داخلي في الخادم.

### مثال على استجابة الخطأ

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## الخلاصة

من خلال هذه الوثيقة، تعرفت على كيفية استخدام واجهة برمجة تطبيقات توليد فيديوهات Sora لتوليد فيديوهات عبر إدخال عبارة توجيه وصور مرجعية. نأمل أن تساعدك هذه الوثيقة في دمج واستخدام الواجهة بشكل أفضل. إذا كان لديك أي استفسار، لا تتردد في التواصل مع فريق الدعم الفني لدينا.
