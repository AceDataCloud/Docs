يمكن لـ Claude Messages Count Tokens API حساب عدد رموز الإدخال لرسالة Message دون إنشاء الرسالة فعليًا، بما في ذلك حساب رموز محتويات مثل الأدوات والصور والمستندات. وهذا مفيد جدًا عند الحاجة إلى تقدير التكلفة أو التحقق مما إذا كان الإدخال يتجاوز حد سياق النموذج.

تقدم هذه الوثيقة بشكل رئيسي عملية استخدام Claude Messages Count Tokens API.

لا يوفر `claude-fable-5-2` حاليًا واجهة Count Tokens. يمكن الاطلاع على الاستخدام النهائي للطلبات المُنشأة من `usage` في استجابة Messages؛ لا تستخدم نتائج العد الخاصة بالنماذج الأخرى بدلًا من الاستخدام الدقيق لهذا النموذج.

## عملية التقديم

لاستخدام Claude Messages Count Tokens API، انتقل أولًا إلى [وحدة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على API Token الخاص بك، واحتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد سجلت الدخول أو أنشأت حسابًا بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وبعد الإكمال ستعود تلقائيًا إلى الصفحة الحالية.

**يمكن لـ API Token واحد استدعاء جميع خدمات المنصة، ولا حاجة إلى التقديم بشكل منفصل لكل خدمة.** سيُمنح رصيد مجاني عند التقديم لأول مرة، ويمكنك التجربة مجانًا؛ وعندما يكون الرصيد غير كافٍ، يمكنك إعادة شحن الرصيد العام في [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## الاستخدام الأساسي

مسار طلب Claude Messages Count Tokens API هو `/v1/messages/count_tokens`، وهو متوافق مع Anthropic Official API. نحتاج على الأقل إلى توفير معاملين إلزاميين:

- `model`: املأ معرّف النموذج الكامل في قائمة نماذج هذه الواجهة، واستخدم النموذج نفسه في طلب Messages اللاحق.
- `messages`: مصفوفة الرسائل المُدخلة، وتحتوي كل رسالة على `role` (الدور) و`content` (المحتوى).

المعاملات الاختيارية الشائعة:

- `system`: موجه النظام، وسيُحتسب ضمن عدد الرموز.
- `tools`: تعريفات الأدوات، وستُحتسب ضمن عدد الرموز.
- `thinking`: إعدادات التفكير الموسع.
- `tool_choice`: إعدادات اختيار الأداة.
- `cache_control`: إعدادات التحكم بالتخزين المؤقت على المستوى الأعلى أو على مستوى كتلة المحتوى.

تستخدم `messages` و`system` وإعادة تشغيل استدعاءات الأدوات وصور URL وكتل محتوى document/PDF نفس بنية الطلب المستقرة الخاصة بـ Messages API.

### مثال cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### مثال Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

مثال على النتيجة المعادة:

```json
{
  "input_tokens": 11
}
```

### استخدام Anthropic SDK

يقبل Claude Messages Count Tokens API بنية الطلب المستقرة الخاصة بـ Anthropic SDK، ويمكن استدعاؤه عبر مكتبة `anthropic`. تحسب الواجهة رموز الإدخال وفقًا للنموذج المحدد، ويمكن استخدامها للتحقق من حجم الإدخال قبل إرسال طلب Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## حساب الرموز التي تتضمن أدوات

إذا كان طلبك يحتوي على تعريفات أدوات، فسيتم احتساب هذه الأدوات أيضًا ضمن عدد الرموز:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## حساب الرموز التي تتضمن موجهات النظام

تُحتسب موجهات النظام أيضًا ضمن عدد الرموز:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## ملاحظات

- تحسب هذه الواجهة عدد رموز الإدخال فقط، ولن تنتج أي مخرجات من النموذج.
- يمكن استخدام نتيجة حساب الرموز لتقدير حجم الإدخال والتحقق من نافذة السياق؛ وتكون الفوترة النهائية وفقًا لـ `usage` في استجابة Messages الفعلية.
- ستُحتسب الصور وملفات PDF وتعريفات الأدوات وموجهات النظام وإعدادات thinking ضمن النتيجة وفقًا لقواعد الإدخال الخاصة بالنموذج المحدد.
- هذه الواجهة مجانية بالكامل ولا تستهلك أي رصيد.
