يمكن لـ Claude Messages Count Tokens API حساب عدد رموز الإدخال لرسالة Message دون إنشاء رسالة فعليًا، بما في ذلك عدّ رموز محتويات مثل الأدوات والصور والمستندات. يكون هذا مفيدًا جدًا عند الحاجة إلى تقدير التكلفة أو التحقق مما إذا كان الإدخال يتجاوز حد سياق النموذج.

تعرّف هذه الوثيقة بشكل أساسي على عملية استخدام Claude Messages Count Tokens API.

## عملية التقديم

لاستخدام Claude Messages Count Tokens API، انتقل أولًا إلى [وحدة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على API Token الخاص بك، واحتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد سجلت الدخول أو أنشأت حسابًا بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وبعد الإكمال ستعود تلقائيًا إلى الصفحة الحالية.

**يمكن لـ API Token واحد استدعاء جميع خدمات المنصة، ولا حاجة للتقديم بشكل منفصل لكل خدمة.** سيمنحك أول طلب حصة مجانية لتجربة الخدمة مجانًا؛ وعندما تكون الحصة غير كافية، يمكنك إعادة شحن الرصيد العام من [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## الاستخدام الأساسي

مسار طلب Claude Messages Count Tokens API هو `/v1/messages/count_tokens`، وهو متوافق مع Anthropic API الرسمي. نحتاج إلى توفير معلمتين مطلوبتين على الأقل:

- `model`: اختر نموذج Claude المراد استخدامه؛ يمكن استخدام `claude-opus-5-5` لـ Messages Token Count، مثل النموذج الرائد الأحدث `claude-fable-5-1`؛ ولا يزال `claude-fable-5` السابق محفوظًا ومتوافقًا.
- `messages`: مصفوفة الرسائل المدخلة، تحتوي كل رسالة على `role` (الدور) و`content` (المحتوى).

المعلمات الاختيارية الشائعة:

- `system`: مطالبة النظام، وتُحتسب ضمن عدد الرموز.
- `tools`: تعريفات الأدوات، وتُحتسب ضمن عدد الرموز.
- `thinking`: إعدادات التفكير الموسع.
- `tool_choice`: إعدادات اختيار الأداة.
- `cache_control`: إعدادات التحكم في التخزين المؤقت على المستوى الأعلى أو مستوى كتلة المحتوى.

تستخدم كتل محتوى `messages` و`system` وإعادة تشغيل استدعاءات الأدوات وصور URL والمستندات/PDF نفس بنية الطلب المستقرة المستخدمة في Messages API.

### مثال cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### مثال Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

مثال على نتيجة الإرجاع:

```json
{
  "input_tokens": 11
}
```

### استخدام Anthropic SDK

يقبل Claude Messages Count Tokens API بنية الطلب المستقرة الخاصة بـ Anthropic SDK، ويمكن استدعاؤه عبر مكتبة `anthropic`. تستخدم الواجهة قدرة Count Tokens الأصلية المقابلة للنموذج المحدد لإحصاء الإدخال، ويمكن استخدامها للتحقق من حجم الإدخال قبل إرسال طلب Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## عدّ الرموز مع تضمين الأدوات

إذا كان طلبك يتضمن تعريفات أدوات، فستُحتسب هذه الأدوات أيضًا ضمن عدد الرموز:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## عدّ الرموز مع تضمين مطالبة النظام

تُحتسب مطالبة النظام أيضًا ضمن عدد الرموز:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## ملاحظات

- تحسب واجهة API هذه عدد رموز الإدخال فقط، ولن تُنتج أي مخرجات من النموذج.
- يمكن استخدام نتيجة عدّ الرموز لتقدير حجم الإدخال والتحقق من نافذة السياق؛ وتكون الفوترة النهائية وفقًا لـ `usage` في استجابة Messages الفعلية.
- تُحتسب الصور وملفات PDF وتعريفات الأدوات ومطالبات النظام وإعدادات thinking ضمن النتيجة وفقًا لقواعد إدخال النموذج المحدد.
- واجهة API هذه مجانية بالكامل ولا تستهلك أي حصة.
