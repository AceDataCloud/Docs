يُعد Anthropic Claude نظام محادثة بالذكاء الاصطناعي قويًا للغاية، فما عليك سوى إدخال نص توجيهي ليُنشئ ردودًا سلسة وطبيعية في غضون ثوانٍ قليلة. يتميز Claude في المجال بفضل قدراته الممتازة على فهم اللغة وتوليدها، واليوم، أصبح Claude مستخدمًا على نطاق واسع في مختلف الصناعات والمجالات، وأصبح تأثيره أكثر وضوحًا. سواء في المحادثات اليومية أو الكتابة الإبداعية أو الاستشارات المتخصصة أو برمجة الأكواد، يمكن لـ Claude تقديم مساعدة ذكية مذهلة، مما يعزز بشكل كبير كفاءة العمل والإبداع البشري.

تقدم هذه الوثيقة بشكل رئيسي عملية استخدام عمليات Claude Chat Completion API، وباستخدامها يمكننا بسهولة استخدام وظيفة المحادثة الرسمية لـ Claude.

## Claude Fable 5.2

استخدم اسم الطراز الكامل `claude-fable-5-2`. هذا الطراز مناسب للاستدلال المعقد والمهام طويلة المدى؛ وعند الحاجة إلى كتل محتوى التفكير الأصلية والتفاعل مع الأدوات، أعطِ الأولوية لاستخدام Messages. يكون التفكير التكيفي مفعّلًا باستمرار، احذف `temperature` و`top_p` و`top_k`، واستخدم `auto` لاختيار الأدوات، ولا تفرض تحديد أداة بعينها. يغطي `max_tokens` كلاً من التفكير والنص النهائي. لا تتوفر حاليًا واجهات Responses وCount Tokens لهذا الطراز.

وفقًا لحساب أكبر باقة حالية (142,800 Credits／$13,584)، تبلغ تكلفة الإدخال العادي لـ Fable 5.2 مقدار $3.20، والإخراج $16／لكل مليون token؛ وتبلغ قراءة التخزين المؤقت $0.08، بينما تبلغ كتابة التخزين المؤقت لمدة 5 دقائق／ساعة واحدة $4／$6.40／لكل مليون token على التوالي. الأسعار المذكورة أعلاه تساوي 40% من سعر واجهة API القياسي الرسمي (أرخص بنسبة 60%)؛ بالنسبة إلى الباقات الأخرى والخصومات الإضافية للحساب، يُرجى الرجوع إلى صفحة تسعير الطراز والفاتورة.

لاستخدام Claude Chat Completion API، انتقل أولًا إلى [وحدة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على API Token الخاص بك، واحتفظ به للاستخدام لاحقًا.

## الاستخدام الأساسي

بعد ذلك، يمكنك ملء المحتوى المقابل في الواجهة، كما هو موضح في الشكل:

<p><img src="https://cdn.acedata.cloud/ejeq57.png" width="400" className="m-auto" /></p>

عند استخدام هذه الواجهة لأول مرة، نحتاج إلى ملء ثلاثة عناصر على الأقل، أحدها هو `authorization`، ويمكنك اختياره مباشرة من القائمة المنسدلة. المعلمة الأخرى هي `model`، ويمكن اختيار الطرازات العامة مثل `claude-opus-5-5` و`claude-fable-5-1`؛ ولا يزال بالإمكان الاستمرار في استدعاء `claude-fable-5` الأصلي. المعلمة الأخيرة هي `messages`، وهي مصفوفة من نصوص الأسئلة، ويحتوي كل عنصر على `role` و`content`؛ يدعم `role` كلاً من `user` و`assistant` و`system`، و`content` هو المحتوى المحدد. عند الحاجة إلى كتل محتوى التفكير الكاملة لـ Claude، والتوقيعات، ودلالات الأدوات الأصلية، يُرجى الاستمرار في استخدام Messages API.

في الوقت نفسه، يمكنك ملاحظة وجود إنشاء لكود الاستدعاء المقابل على الجانب الأيمن، ويمكنك نسخ الكود وتشغيله مباشرة، أو النقر مباشرة على زر «Try» للاختبار.

المعلمات الاختيارية الشائعة:

- `max_tokens`: يحد من العدد الأقصى لـ token في الرد الواحد.
- `temperature`: عشوائية التوليد، بين 0-2، وكلما زادت القيمة زاد التباعد.
- `n`: عدد الردود المرشحة التي يتم توليدها دفعة واحدة.
- `response_format`: إعداد تنسيق الإرجاع.

يدعم `claude-opus-5-5` Chat Completions العادية والمتدفقة؛ ولا يسمح هذا الطراز إلا بـ `n=1`. لا تضبط له `temperature` أقل من 1 أو `top_p` غير افتراضي، ولاستدعاء الأدوات استخدم `tool_choice: "auto"`، ولا تفرض تحديد أداة بعينها. لا تُرجع واجهة Chat المتوافقة كتل محتوى التفكير الأصلية.

<p><img src="https://cdn.acedata.cloud/v6lbjo.png" width="400" className="m-auto" /></p>

بعد الاستدعاء، نجد أن النتيجة المعادة كما يلي:

```json
{
  "id": "msg_bdrk_01Q6WN27v95ypCa1kbanAQ6K",
  "model": "claude-opus-4-8",
  "object": "chat.completion",
  "created": 1768619365,
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 8,
    "completion_tokens": 12,
    "total_tokens": 20,
    "prompt_tokens_details": {
      "cached_tokens": 0,
      "cache_write_tokens": 0
    },
    "completion_tokens_details": {
      "reasoning_tokens": 0
    }
  }
}
```

تحتوي النتيجة المعادة على عدة حقول، ويكون تعريفها كما يلي:

- `id`، معرّف مهمة المحادثة هذه التي تم إنشاؤها، ويُستخدم لتعريف مهمة المحادثة هذه بشكل فريد.
- `model `، طراز Claude الرسمي المحدد.
- `choices`، معلومات الإجابة التي يقدمها Claude على نص السؤال.
- `usage `: معلومات إحصائية حول token لعملية السؤال والجواب هذه.

في تنسيق Chat Completions، يمثل `usage.prompt_tokens` إجمالي الإدخال؛ ويسجل `prompt_tokens_details.cached_tokens` و`prompt_tokens_details.cache_write_tokens` تفاصيل قراءة وكتابة التخزين المؤقت على التوالي. إن `completion_tokens_details.reasoning_tokens` مجموعة فرعية من `completion_tokens`، ولا تضفه مرة أخرى عند حساب الإجمالي أو التكلفة. قد تعرض الاستجابة غير المتدفقة أيضًا كائن `usage.cost`، حيث يكون `amount` هو استهلاك الرصيد الفعلي، و`currency` هي وحدة القياس، و`list_amount` هو المبلغ قبل الخصم (إن وُجد).

اسم الحقل في Chat-compatible هو `reasoning_tokens`؛ وتستخدم Messages API الأصلية `output_tokens_details.thinking_tokens`. يختلف مخطط wire للبروتوكولين، ويجب ألا يخلط العميل بين أسماء الحقول.

من بينها، `choices` تحتوي على معلومات إجابة Claude، و`choices` بداخلها هي المعلومات المحددة لإجابة Claude، ويمكن ملاحظتها كما هو موضح في الشكل.

<p><img src="https://cdn.acedata.cloud/2ulyhw.png" width="400" className="m-auto" /></p>

يمكن ملاحظة أن حقل `content` داخل `choices` يحتوي على المحتوى المحدد لرد Claude.

## الاستجابة المتدفقة

تدعم هذه الواجهة أيضًا الاستجابة المتدفقة، وهذا مفيد جدًا لربط صفحات الويب، إذ يمكن أن يتيح للصفحة تحقيق تأثير العرض حرفًا بحرف.

إذا أردت إرجاع الاستجابة بشكل متدفق، فيمكنك تغيير معلمة `stream ` في رأس الطلب إلى `true`.

يكون التعديل كما هو موضح في الشكل، لكن يجب أن يحتوي كود الاستدعاء على التعديلات المقابلة لدعم الاستجابة المتدفقة.

<p><img src="https://cdn.acedata.cloud/ueugot.png" width="400" className="m-auto" /></p>
بعد تعديل `stream` إلى `true`، ستُرجع واجهة API بيانات JSON المقابلة سطرًا بسطر، وعلى مستوى الكود نحتاج إلى إجراء التعديلات المقابلة للحصول على النتائج سطرًا بسطر.

كود استدعاء نموذجي لـ Python:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "claude-opus-4-20250514",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## التفكير العميق

قد تستدل نماذج Claude من الجيل الجديد وفقًا للاستراتيجية الافتراضية للنموذج، دون الحاجة إلى التفعيل عبر لاحقة النموذج `-thinking`. تستخدم استجابات Chat-compatible حقل usage المتوافق مع OpenAI وهو `completion_tokens_details.reasoning_tokens`. إن `reasoning_tokens` مضمنة بالفعل في `completion_tokens`، لذا لا تجمعها مرة أخرى. تشترك الاستدلالات والنص المرئي في الحد الأقصى لرموز الإخراج، لذلك قد يظهر النص فارغًا أو مقتطعًا عندما تكون قيمة `max_tokens` صغيرة؛ عند مواجهة هذه الحالة، يرجى زيادة ميزانية الإخراج، أو اختيار مستوى جهد استدلال أقل عندما يدعم النموذج المستخدم ذلك.

إذا كنت بحاجة إلى `thinking` الأصلي، و`output_config.effort`، وكتل محتوى thinking وإرجاع التوقيع، فيرجى استخدام `/v1/messages`. حقل usage المقابل لـ Messages هو `output_tokens_details.thinking_tokens`، ولا تخلطه مع `completion_tokens_details.reasoning_tokens` الخاص بـ Chat-compatible.

## النموذج المرئي

claude-sonnet-4-20250514 هو نموذج لغة كبير متعدد الوسائط طورته Claude، ويضيف قدرات الفهم البصري على أساس claude-4. يمكن لهذا النموذج معالجة مدخلات النص والصور في الوقت نفسه، ويحقق الفهم والتوليد عبر الوسائط.

تتوافق معالجة النصوص باستخدام نموذج claude-sonnet-4-20250514 مع محتوى الاستخدام الأساسي المذكور أعلاه، وفيما يلي مقدمة موجزة عن كيفية استخدام قدرات معالجة الصور في النموذج.

تُستخدم قدرات معالجة الصور لنموذج claude-sonnet-4-20250514 بشكل رئيسي عبر إضافة حقل `type` إلى محتوى `content` الأصلي، ومن خلال هذا الحقل يمكن معرفة ما إذا كان المرفوع نصًا أم صورة، وبالتالي استخدام قدرات معالجة الصور لنموذج claude-sonnet-4-20250514. وفيما يلي شرح رئيسي لطريقتين لاستدعاء هذه الوظيفة باستخدام Curl وPython.

- طريقة سكربت Curl

```
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "claude-sonnet-4-20250514",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://cdn.acedata.cloud/ueugot.png"
            }
          }
        ]
      }
    ]
  }'
```

- طريقة سكربت Python

    "authorization": "Bearer {token}",
    "content-type": "application/json"

payload = {
    "model": "claude-sonnet-4-20250514",
    "messages": [
        {
            "role": "user",

## معالجة الأخطاء

عند استدعاء API، إذا واجهت خطأً، فسيعيد API رمز الخطأ والمعلومات المقابلة. على سبيل المثال:

- `400 token_mismatched`：طلب غير صالح، ربما بسبب معلمات مفقودة أو غير صالحة.
- `400 api_not_implemented`：طلب غير صالح، ربما بسبب معلمات مفقودة أو غير صالحة.
- `401 invalid_token`：غير مصرح به، رمز التفويض غير صالح أو مفقود.
- `429 too_many_requests`：طلبات كثيرة جدًا، لقد تجاوزت حد المعدل.
- `500 api_error`：خطأ داخلي في الخادم، حدث خطأ ما على الخادم.
