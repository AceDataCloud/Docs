---
title: "شرح تكامل واجهة برمجة التطبيقات لتنزيل WAV من Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

يتيح لنا Producer تنزيل ملفات WAV المتعلقة بالأغاني، ويشرح هذا المستند طريقة تكامل واجهة برمجة التطبيقات ذات الصلة.

تحتوي واجهة برمجة التطبيقات هذه على مُعامل إدخال واحد فقط، وهو `audio_id`، وهو المعرّف الفريد للأغنية.

قيمة `audio_id` التي ندخلها هنا هي `a54609c6-13e2-4176-be0f-4d7eebc68e1f`، وهي معرّف أغنية تم إنشاؤها بواسطة Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/wav' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

النتيجة كما يلي:

```
{
  "success": true,
  "task_id": "44963173-b6c5-463c-915f-96730d14ec63",
  "trace_id": "f75d6a27-54bc-49fd-a40e-6d4cd0427764",
  "data": [
    {
      "title": "Woke up with the sun in my eyes",
      "file_url": "https://cdn.acedata.cloud/assets/examples/fish/64adc04b-c196-4a0f-9070-222ba101ce6c-fc50de38c165.wav"
    }
  ]
}
```

كما يمكن ملاحظة، فإن حقل `file_url` ضمن `data` هو رابط تنزيل ملف WAV.
