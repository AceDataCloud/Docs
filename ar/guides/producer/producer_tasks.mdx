تتمثل الوظيفة الرئيسية لـ Producer Tasks API في الاستعلام عن حالة تنفيذ المهمة عبر إدخال معرّف المهمة الذي تم إنشاؤه بواسطة Producer Audios Generation API.

سيقدّم هذا المستند بالتفصيل شرح تكامل Producer Tasks API، لمساعدتك على دمج واستخدام الوظائف القوية لهذه API بسهولة وبشكل كامل. من خلال Producer Tasks API، يمكنك بسهولة الاستعلام عن حالة تنفيذ مهام Producer Audios Generation API.

## عملية التقديم

لاستخدام Producer Audios Generation API، انتقل أولاً إلى [وحدة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على API Token الخاص بك، واحتفظ به لاستخدامه لاحقاً.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد سجلت الدخول أو أنشأت حساباً بعد، فسيتم تحويلك تلقائياً إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، ثم ستعود تلقائياً إلى الصفحة الحالية بعد الإكمال.

**يمكن استخدام API Token واحد لاستدعاء جميع خدمات المنصة، ولا حاجة للتقديم بشكل منفصل لكل خدمة.** ستحصل على رصيد مجاني عند التقديم لأول مرة، ويمكنك التجربة مجاناً؛ وعندما لا يكون الرصيد كافياً، يمكنك شحن الرصيد العام في [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [Producer Audios Generation API →](https://platform.acedata.cloud/documents/producer-audios)

## مثال على الطلب

يمكن استخدام Producer Tasks API للاستعلام عن نتائج Producer Audios Generation API. لمعرفة كيفية استخدام Producer Audios Generation API، يرجى الرجوع إلى وثائق [Producer Audios Generation API ](https://platform.acedata.cloud/documents/producer-audios-integration).

سنأخذ معرّف مهمة واحداً تم إرجاعه من خدمة Producer Audios Generation API كمثال، لعرض كيفية استخدام هذه API. لنفترض أن لدينا معرّف مهمة: 1a6ac2ad-10f2-4e2b-b500-66ec27fe82ad، وسنوضّح بعد ذلك كيفية تمرير معرّف مهمة واحد من خلاله.

### إعداد رؤوس الطلب ونص الطلب

يتضمن **Request Headers**:

- `accept`: يحدد تلقي نتيجة استجابة بتنسيق JSON، وهنا يُملأ بـ `application/json`.
- `authorization`: مفتاح استدعاء API، ويمكن اختياره مباشرةً من القائمة المنسدلة بعد التقديم.

يتضمن **Request Body**:

- `id`: معرّف المهمة المرفوعة.
- `action`: طريقة العملية على المهمة.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/producer/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "1a6ac2ad-10f2-4e2b-b500-66ec27fe82ad",
  "action": "retrieve"
}'
```

## معالجة الأخطاء

عند استدعاء API، إذا واجهت خطأً، فسيعيد API رمز الخطأ والمعلومات المقابلة. على سبيل المثال:

- `400 token_mismatched`：طلب غير صالح، ربما بسبب معلمات مفقودة أو غير صالحة.
- `400 api_not_implemented`：طلب غير صالح، ربما بسبب معلمات مفقودة أو غير صالحة.
- `401 invalid_token`：غير مصرح، رمز التفويض غير صالح أو مفقود.
- `429 too_many_requests`：طلبات كثيرة جدًا، لقد تجاوزت حد المعدل.
- `500 api_error`：خطأ داخلي في الخادم، حدث خطأ ما على الخادم.

### مثال على استجابة الخطأ

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## الخلاصة

من خلال هذا المستند، أصبحت تعرف كيفية استخدام Producer Tasks API للاستعلام عن جميع معلومات التفاصيل المحددة لمهمة واحدة أو لمهام مجمعة. نأمل أن يساعدك هذا المستند في التكامل مع API واستخدامه بشكل أفضل. إذا كانت لديك أي أسئلة، فلا تتردد في الاتصال بفريق الدعم الفني لدينا.
