الوظيفة الرئيسية لواجهة برمجة تطبيقات مهام المنتج هي استعلام حالة تنفيذ المهمة من خلال إدخال معرف المهمة الذي تم إنشاؤه بواسطة واجهة برمجة تطبيقات إنتاج الصوتيات للمنتج (Producer Audios Generation API).

ستتناول هذه الوثيقة تفاصيل تكامل واجهة برمجة تطبيقات مهام المنتج، لمساعدتك على دمجها بسهولة والاستفادة الكاملة من القوة الكبيرة لهذه الواجهة. من خلال واجهة برمجة تطبيقات مهام المنتج، يمكنك بسهولة استعلام حالة تنفيذ المهام من واجهة برمجة تطبيقات إنتاج الصوتيات للمنتج.

## عملية التقديم

لاستخدام واجهة برمجة تطبيقات إنتاج الصوتيات للمنتج، يجب أولاً الذهاب إلى [وحدة التحكم في سحابة Ace Data](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، للاحتفاظ به كنسخة احتياطية.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد الانتهاء، سيتم إرجاعك تلقائيًا إلى الصفحة الحالية.

**يمكن استخدام رمز API واحد لاستدعاء جميع خدمات المنصة، دون الحاجة لتقديم طلب منفصل لكل خدمة.** عند التقديم لأول مرة، ستحصل على رصيد مجاني لتجربته؛ وعند نفاد الرصيد، يمكنك إعادة شحن الرصيد العام في [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [واجهة برمجة تطبيقات إنتاج الصوتيات للمنتج →](https://platform.acedata.cloud/documents/producer-audios)

## مثال على الطلب

يمكن استخدام واجهة برمجة تطبيقات مهام المنتج لاستعلام نتائج واجهة برمجة تطبيقات إنتاج الصوتيات للمنتج. لمزيد من المعلومات حول كيفية استخدام واجهة برمجة تطبيقات إنتاج الصوتيات للمنتج، يرجى الرجوع إلى الوثيقة [واجهة برمجة تطبيقات إنتاج الصوتيات للمنتج](https://platform.acedata.cloud/documents/producer-audios-integration).

سنأخذ مثالاً على معرف المهمة الذي تم إرجاعه من خدمة واجهة برمجة تطبيقات إنتاج الصوتيات للمنتج، لنوضح كيفية استخدام هذه الواجهة. لنفترض أن لدينا معرف مهمة: 1a6ac2ad-10f2-4e2b-b500-66ec27fe82ad، وسنوضح بعد ذلك كيفية تمرير معرف المهمة.

### إعداد رأس الطلب وجسم الطلب

**رؤوس الطلب** تشمل:

- `accept`: تحديد استلام استجابة بتنسيق JSON، هنا يتم ملؤه بـ `application/json`.
- `authorization`: مفتاح استدعاء الواجهة، يمكن اختياره مباشرة بعد التقديم.

**جسم الطلب** يشمل:

- `id`: معرف المهمة المرفوعة.
- `action`: طريقة تنفيذ العملية على المهمة.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/producer/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "1a6ac2ad-10f2-4e2b-b500-66ec27fe82ad",
  "action": "retrieve"
}'
```

## معالجة الأخطاء

عند استدعاء API، إذا واجهت خطأ، ستقوم API بإرجاع رمز الخطأ والمعلومات المناسبة. على سبيل المثال:

- `400 token_mismatched`：طلب غير صحيح، ربما بسبب معلمات مفقودة أو غير صالحة.
- `400 api_not_implemented`：طلب غير صحيح، ربما بسبب معلمات مفقودة أو غير صالحة.
- `401 invalid_token`：غير مصرح، رمز التفويض غير صالح أو مفقود.
- `429 too_many_requests`：طلبات كثيرة جداً، لقد تجاوزت الحد الأقصى لمعدل الطلبات.
- `500 api_error`：خطأ داخلي في الخادم، حدث خطأ ما في الخادم.

### مثال على استجابة الخطأ

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "فشل في جلب البيانات"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

من خلال هذه الوثيقة، لقد فهمت كيفية استخدام واجهة برمجة التطبيقات Producer Tasks لاستعلام تفاصيل مهمة واحدة أو جماعية. نأمل أن تساعدك هذه الوثيقة في التوصيل واستخدام هذه الواجهة بشكل أفضل. إذا كان لديك أي أسئلة، فلا تتردد في الاتصال بفريق الدعم الفني لدينا.
