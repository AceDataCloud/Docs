يسمح لنا Producer بتحميل مقاطع الفيديو المتعلقة بالأغاني، توضح هذه الوثيقة طريقة الاتصال بالـ API ذات الصلة.

هذا الـ API يحتوي على معلمة إدخال واحدة فقط، وهي `audio_id`، وهي المعرف الفريد للأغنية.

هنا، المعرف `audio_id` المدخل هو `a54609c6-13e2-4176-be0f-4d7eebc68e1f`، وهو معرف أغنية تم إنشاؤه بواسطة Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

النتيجة كما يلي:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://storage.googleapis.com/corpusant-app-public/song-videos/a54609c6-13e2-4176-be0f-4d7eebc68e1f:5178f294b214798f7d38b810ac289be75306659be24af88900a633efce334012.mp4"
  }
}
```

يمكننا أن نرى أن حقل `video_url` في `data` هو رابط الفيديو الذي يمكن تحميله.
