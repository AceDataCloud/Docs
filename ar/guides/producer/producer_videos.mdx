---
title: "شرح تكامل واجهة برمجة التطبيقات لتنزيل فيديوهات Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

يتيح لنا Producer تنزيل مقاطع الفيديو المرتبطة بالأغاني، ويشرح هذا المستند طريقة تكامل واجهة برمجة التطبيقات ذات الصلة.

تحتوي واجهة برمجة التطبيقات هذه على معلمة إدخال واحدة فقط، وهي `audio_id`، وهو المعرّف الفريد للأغنية.

هنا، قيمة `audio_id` التي ندخلها هي `a54609c6-13e2-4176-be0f-4d7eebc68e1f`، وهي معرّف أغنية تم إنشاؤها بواسطة Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

النتيجة كما يلي:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4"
  }
}
```

كما يمكن ملاحظة، فإن حقل `video_url` في `data` هو رابط الفيديو الذي يتم تنزيله.
