---

يتيح لنا Producer رفع صوت مرجعي لإجراء إبداع ثانوي، ويشرح هذا المستند طريقة تكامل واجهة API ذات الصلة.

تحتوي واجهة API هذه على معلمة إدخال واحدة فقط، وهي `audio_url`، وهي عنوان CDN يمكن الوصول إليه بشكل عام، وتدعم لاحقة mp3.

هنا، قيمة `audio_url` التي ندخلها هي `https://cdn.acedata.cloud/suno_demo.mp3`، وهي عنوان CDN يمكن الوصول إليه بشكل عام.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

النتيجة كما يلي:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Soft female vocals, bright and cheerful]\n\n[Verse 1]\n阳光洒在海边\n浪花笑得灿烂\n你和我在沙滩\n钟表停止转\n冰淇淋在融化\n手牵手去散步\n风儿轻轻吹过\n心跳不停跳\n\n[Chorus]\n夏天夏天\n时间停在这一天\n笑声回荡\n蔚蓝天空在身旁",
    "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
  }
}
```

كما يمكن ملاحظة، فإن حقل `audio_id` في `data` هو معرّف الأغنية بعد الرفع.

بعد الحصول على معرّف الأغنية، يمكننا استخدام [واجهة API لإنشاء أصوات Producer](https://platform.acedata.cloud/documents/producer-audios-integration) لإجراء إنشاء أغنيات مخصصة، فعلى سبيل المثال، عند تمرير `upload_extend` إلى `action`، وتمرير معرّف الأغنية المُعاد إلى `audio_id` في الوقت نفسه، يمكن إنشاء أغنية جديدة بناءً على الصوت المرجعي.
