تستخدم واجهة برمجة تطبيقات HappyHorse Tasks لاستعلام عن مهام إنشاء أو تحرير الفيديوهات التي تم إنشاؤها بواسطة واجهة برمجة تطبيقات HappyHorse Videos.

## عملية التقديم

لاستخدام واجهة برمجة تطبيقات HappyHorse Videos، يجب أولاً الذهاب إلى [وحدة التحكم في Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، احتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد الانتهاء سيتم العودة تلقائيًا إلى الصفحة الحالية.

**يمكن استخدام رمز API واحد لاستدعاء جميع خدمات المنصة، دون الحاجة لتقديم طلب منفصل لكل خدمة.** عند التقديم لأول مرة، ستحصل على رصيد مجاني لتجربته مجانًا؛ وعند نفاد الرصيد، يمكنك إعادة شحن الرصيد العام في [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## مثال على الطلب

يمكن استخدام واجهة برمجة تطبيقات HappyHorse Tasks لاستعلام نتائج واجهة برمجة تطبيقات HappyHorse Videos.

### إعداد رأس الطلب وجسم الطلب

**رؤوس الطلب** تشمل:

- `accept`: تحديد استلام نتائج الاستجابة بتنسيق JSON، هنا يتم ملؤه بـ `application/json`.
- `authorization`: مفتاح استدعاء واجهة برمجة التطبيقات، يمكن اختياره مباشرة بعد التقديم.

**جسم الطلب** يشمل:

- `id`: معرف المهمة التي تريد الاستعلام عنها.
- `action`: طريقة إجراء العملية على المهمة، يتم ملء `retrieve` للاستعلام الفردي.

### مثال على كود CURL

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### مثال على الاستجابة

بعد نجاح الطلب، ستقوم واجهة برمجة التطبيقات بإرجاع تفاصيل تلك المهمة. حيث أن حقل `request` هو جسم الطلب عند إنشاء المهمة، وحقل `response` هو جسم الاستجابة الذي يتم إرجاعه بعد إكمال المهمة، على سبيل المثال:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "لقطة سينمائية لحصان أبيض يجري عبر شاطئ مضاء بالقمر",
    "resolution": "720P",
    "duration": 5
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "1469cfc3-3004-4d9e-ab10-xxxxxx",
        "video_url": "https://cdn.acedata.cloud/happyhorse/c8cbf53aa0.mp4",
        "state": "succeeded",
        "duration": 5,
        "resolution": "720P",
        "ratio": "16:9"
      }
    ]
  }
}
```

تقديم الحقول كما يلي:

- `id`: معرف المهمة التي تم إنشاؤها، يستخدم لتحديد هذه المهمة بشكل فريد.
- `request`: معلومات الطلب عند إنشاء المهمة.
- `response`: المعلومات الحالية أو النهائية التي تم إرجاعها عن المهمة.
- `created_at`: وقت إنشاء المهمة، طابع زمني Unix (ثوانٍ، نقطة عائمة).
- `started_at`: وقت بدء تنفيذ المهمة، سلسلة زمنية UTC ISO-8601.
- `finished_at`: وقت إكمال المهمة، طابع زمني Unix (ثوانٍ، نقطة عائمة). لا يتم إرجاع هذا الحقل إذا لم تكتمل المهمة.
- `elapsed`: الوقت المستغرق لتنفيذ المهمة، بوحدة الثواني (نقطة عائمة، مع الاحتفاظ بـ 3 أرقام عشرية). لا يتم إرجاع هذا الحقل إذا لم تكتمل المهمة.

## عمليات الاستعلام الجماعي

عند استعلام تفاصيل المهام لعدة معرفات مهام، يتم تعيين `action` إلى `retrieve_batch`، ويتم تمرير مصفوفة معرفات المهام عبر `ids`:

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```

ستتضمن النتيجة حقلي `items` و `count`، حيث أن `items` هو مصفوفة تفاصيل المهام، و `count` هو عدد المهام المطابقة في هذه المرة.
