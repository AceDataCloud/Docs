تتناول هذه الوثيقة طريقة الربط مع HappyHorse Videos API. يدعم هذا الواجهة من خلال نقطة دخول موحدة `/happyhorse/videos` ومعامل `action` إنشاء الفيديوهات من النصوص، وإنشاء الفيديوهات من الصورة الأولى، وإنشاء الفيديوهات من الصور المرجعية، وتحرير الفيديو.

## عملية التقديم

لاستخدام HappyHorse Videos API، يجب أولاً الذهاب إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، احتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، سيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد الانتهاء سيتم العودة تلقائيًا إلى الصفحة الحالية.

**يمكن استخدام رمز API واحد لاستدعاء جميع خدمات المنصة، دون الحاجة لتقديم طلب منفصل لكل خدمة.** ستمنحك أول عملية تقديم رصيد مجاني لتجربته مجانًا؛ عند نفاد الرصيد، يمكنك إعادة شحن الرصيد العام في [لوحة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## أنواع العمليات

يحدد `action` نمط الإنشاء لهذه الطلب:

- `generate`: فيديو من النص، الإجراء الافتراضي، يدعم `happyhorse-1.0-t2v` و `happyhorse-1.1-t2v`، يجب تمرير `prompt`.
- `image_to_video`: فيديو من الصورة الأولى، يدعم `happyhorse-1.0-i2v` و `happyhorse-1.1-i2v`، يجب تمرير `image_url`.
- `reference_to_video`: فيديو من الصورة المرجعية، يدعم `happyhorse-1.0-r2v` و `happyhorse-1.1-r2v`، يجب تمرير `prompt` و 1–9 صورة `image_urls`.
- `video_edit`: تحرير الفيديو، يدعم `happyhorse-1.0-video-edit`، يجب تمرير `prompt` و `video_url`، ويمكن تمرير 0–5 صورة مرجعية `image_urls` بشكل إضافي.

تستخدم جميع الإجراءات النموذج 1.1 بشكل افتراضي؛ حاليًا، `video_edit` يدعم فقط `happyhorse-1.0-video-edit`.

## الاستخدام الأساسي

فيديو من النص يتطلب فقط تقديم `prompt`، ويمكن أيضًا تحديد معلمات مثل `resolution`، `ratio`، `duration`:

```json
{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "حصان أبيض سينمائي يرفع رأسه، ويداعب ذيله بلطف في نسيم شروق الشمس، كاميرا بطيئة تقترب، إضاءة دافئة",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

مثال على نتيجة العودة:

```json
{
  "success": true,
  "task_id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
  "trace_id": "6071ab5e-2f37-46f0-9e07-f1e378112e69",
  "data": [
    {
      "id": "9650580f-6d9e-4bc1-823a-29011790c5cb",
      "video_url": "https://platform2.cdn.acedata.cloud/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1.mp4",
      "state": "succeeded",
      "duration": 5,
      "resolution": "720P",
      "ratio": null
    }
  ]
}
```

تفسير الحقول:

- `success`: هل كانت هذه الطلبية ناجحة.
- `task_id`: معرف المهمة من جانب Ace Data Cloud، يمكن استخدامه للاستعلام عن حالة المهمة.
- `trace_id`: معرف التتبع لهذه الطلبية، يستخدم لتحديد المشكلات.
- `data`: قائمة نتائج الفيديو.
  - `id`: معرف المهمة من جانب HappyHorse.
  - `video_url`: عنوان رابط CDN للفيديو الناتج.
  - `state`: حالة المهمة، يمكن أن تكون `pending` / `succeeded` / `error`.
  - `duration`: مدة الفيديو المحسوبة، بوحدة الثواني؛ `video_edit` هو مجموع مدة الفيديو المدخل والمخرج.
  - `resolution`: دقة الإخراج.
  - `ratio`: نسبة العرض إلى الارتفاع للإخراج.

الكود المقابل لـ CURL كما يلي:

```shell
curl -X POST 'https://api.acedata.cloud/happyhorse/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "حصان أبيض سينمائي يرفع رأسه، ويداعب ذيله بلطف في نسيم شروق الشمس، كاميرا بطيئة تقترب، إضاءة دافئة",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}'
```

الكود المقابل لـ Python كما يلي:

```python
import requests

url = "https://api.acedata.cloud/happyhorse/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "حصان أبيض سينمائي يرفع رأسه، ويداعب ذيله بلطف في نسيم شروق الشمس، كاميرا بطيئة تقترب، إضاءة دافئة",
    "resolution": "720P",
    "ratio": "16:9",
    "duration": 5,
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## فيديو من الصورة الأولى

عند استخدام `image_to_video`، ستعتبر `image_url` كصورة أولى للفيديو. ستتبع نسبة العرض إلى الارتفاع الناتجة الصورة الأولى قدر الإمكان، لذا لا تحتاج هذه العملية إلى تمرير `ratio`.

```json
{
  "action": "image_to_video",
  "model": "happyhorse-1.1-i2v",
  "image_url": "https://cdn.acedata.cloud/b1c82e4937.png",
  "prompt": "حصان أبيض سينمائي يرفع رأسه، ويداعب ذيله بلطف في نسيم شروق الشمس، كاميرا بطيئة تقترب، إضاءة دافئة",
  "resolution": "1080P",
  "duration": 5
}
```

## فيديو من الصورة المرجعية

عند استخدام `reference_to_video`، يمكن تمرير 1–9 صورة مرجعية عبر `image_urls`. يمكن استخدام `character1`، `character2`، وما إلى ذلك في النص للإشارة إلى الصور بالترتيب المناسب.

```json
{
  "action": "reference_to_video",
  "model": "happyhorse-1.1-r2v",
  "prompt": "character1 يمشي للأمام عبر مرج في شروق الشمس بأسلوب الجلد الدافئ والتفاصيل الذهبية من character2",
  "image_urls": [
    "https://cdn.acedata.cloud/b1c82e4937.png",
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

## تحرير الفيديو

عند استخدام `video_edit`، يجب تمرير فيديو `video_url` المراد تحريره ونية التحرير `prompt`. يمكن أن تكون `image_urls` اختيارية كصور مرجعية، مثل تغيير الملابس، أو نقل الأسلوب، أو الاستبدال الجزئي. يمكن أن تكون `audio_setting` إما `auto` أو `origin`، حيث تعني `origin` الاحتفاظ بالصوت الأصلي للفيديو.

```json
{
  "action": "video_edit",
  "model": "happyhorse-1.0-video-edit",
  "prompt": "تطبيق أسلوب الجلد الدافئ والتفاصيل الذهبية من الصورة المرجعية مع الحفاظ على حركة الكاميرا الأصلية",
  "video_url": "https://platform2.cdn.acedata.cloud/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1.mp4",
  "image_urls": [
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "audio_setting": "auto"
}
```

## ردود الفعل غير المتزامنة
生成 الفيديو يحتاج إلى وقت معالجة معين. إذا كنت لا ترغب في الانتظار مع اتصال طويل، يمكنك تمرير `callback_url`، في هذه الحالة ستقوم API بإرجاع `task_id` على الفور، وبعد الانتهاء من المهمة ستقوم بإرسال النتيجة النهائية عبر POST إلى هذا العنوان:

```json
{
  "action": "generate",
  "prompt": "حصان يجري عبر غابة ثلجية",
  "duration": 5,
  "callback_url": "https://your-domain.com/callback/happyhorse"
}
```

النتيجة التي تم إرجاعها على الفور هي كما يلي:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

إذا كنت ترغب فقط في الاستعلام، ولا تحتاج إلى رد، يمكنك أيضًا تمرير `"async": true`، ثم يمكنك الاستعلام عن نتائج المهمة من خلال [HappyHorse Tasks API](https://platform.acedata.cloud/documents/happyhorse-tasks).

## شرح الفوترة

تقوم HappyHorse بفرض رسوم بناءً على عدد ثواني الفيديو الناتج والدقة:

- `720P`: يبدأ من حوالي $0.105 / ثانية.
- `1080P`: يبدأ من حوالي $0.18 / ثانية.
- `video_edit`: يتم فرض رسوم بناءً على مجموع طول الفيديو المدخل والمخرج، وتكون مدة الفوترة الفعلية وفقًا للإحصائيات بعد إكمال المهمة.

المهام الفاشلة لا يتم فرض رسوم عليها، ولا تحتسب من الحصة المجانية.

## معالجة الأخطاء

عند حدوث مشكلة في الطلب، ستقوم API بإرجاع رمز الخطأ المقابل مع الشرح، والأخطاء الشائعة هي كما يلي:

- `400`: هناك خطأ في معلمات الطلب، مثل عدم تطابق action مع model، أو نقص `prompt` / `image_url` / `video_url`، أو أن `duration` تتجاوز نطاق 3–15 ثانية.
- `401`: فشل في التوثيق، الرمز غير صالح أو لا يتطابق مع API.
- `403`: رصيد غير كاف، أو تم رفض المحتوى بسبب انتهاك سياسة المراجعة.
- `429`: الطلبات متكررة جدًا، مما أدى إلى تفعيل الحد، يرجى المحاولة لاحقًا.
- `500`: خطأ داخلي في الخادم أو فشل في التوليد.
