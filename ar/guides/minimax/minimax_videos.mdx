تتناول هذه المقالة تكامل واستخدام واجهة برمجة تطبيقات MiniMax H3 لإنشاء الفيديو. تدعم هذه الواجهة إنشاء الفيديو من النصوص، والتحكم في الإطارات الأولى والأخيرة، والفيديو المرجعي متعدد الوسائط، باستخدام هيكل `content` الموحد من V2 لإنشاء المهام.

## عملية التقديم

لاستخدام واجهة برمجة تطبيقات MiniMax H3 لإنشاء الفيديو، يجب أولاً الذهاب إلى [وحدة التحكم في Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، والاحتفاظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد الانتهاء، سيتم إرجاعك تلقائيًا إلى الصفحة الحالية.

**يمكن استخدام رمز API واحد لاستدعاء جميع خدمات المنصة، دون الحاجة لتقديم طلبات منفصلة لكل خدمة.** عند التقديم لأول مرة، ستحصل على رصيد مجاني لتجربته؛ وعند نفاد الرصيد، يمكنك إعادة شحن الرصيد العام في [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [واجهة برمجة تطبيقات MiniMax H3 لإنشاء الفيديو →](https://platform.acedata.cloud/documents/minimax-videos-integration)

يوصى بحفظ الرمز كمتغير بيئي، وعدم كتابته في الشيفرة المصدرية أو رفعه إلى مستودع النسخ:

```bash
export ACEDATACLOUD_API_KEY="YOUR_API_KEY"
```

## نظرة عامة على الواجهة

- **Base URL**: `https://api.acedata.cloud`
- **Endpoint**: `POST /minimax/videos`
- **طريقة المصادقة**: يتم تضمين `authorization: Bearer {token}` في رأس HTTP
- **رؤوس الطلب**:
  - `accept: application/json`
  - `content-type: application/json`
- **النموذج (model)**: `MiniMax-H3`
- **هيكل الإدخال**: يتم تمرير النصوص والصور والفيديوهات والصوتيات عبر `content`
- **وضع الإخراج**: بشكل افتراضي، يتم الانتظار حتى تكتمل عملية الإنشاء وإرجاع `task` كاملة؛ عند تمرير `async: true` أو `callback_url`، يتم إرجاع `task_id` و `trace_id` على الفور
- **استعلام النتائج**: يتم الحصول على الحالة والفيديو النهائي من خلال [واجهة برمجة تطبيقات استعلام مهام MiniMax H3](/documents/minimax-tasks-integration)
- **الاستدعاء غير المتزامن**: اختياري، يتم استلام نتائج المهام النهائية عبر `callback_url`

لا تحتاج إلى تمرير `action` لاختيار وضع الإنشاء، حيث ستقوم الواجهة بتحديد الاستخدام تلقائيًا بناءً على نوع المواد في `content` و `role`.

## السيناريوهات المناسبة

| السيناريو         | تركيبة الإدخال                  | الاستخدامات الشائعة                      |
| ---------- | --------------------- | ------------------------- |
| فيديو من النص       | نص                    | أفكار إعلانات، تجارب مشهد، فيديوهات قصيرة، لقطات جوية        |
| فيديو من الصورة الأولى     | نص + صورة أولى             | جعل صور المنتجات، الملصقات، صور الأشخاص أو الرسوم المتحركة تتحرك بشكل طبيعي      |
| فيديو من الإطار الأخير / الإطارين | نص + إطار أخير، أو نص + إطار أول + إطار أخير | التحكم في مقدمة ونهاية الفيديو، الانتقالات، التغيرات والنمو والمقارنات      |
| فيديو مرجعي متعدد الوسائط   | نص + صورة / فيديو / صوت مرجعي   | الحفاظ على تناسق الشخصيات والمنتجات، تقليد الحركات، زوايا الكاميرا، نغمة الصوت أو إيقاع التحرير |

## عملية الاستدعاء

بشكل افتراضي، عند عدم تمرير `async`، ستنتظر `/minimax/videos` حتى تكتمل عملية الإنشاء وتعيد `task` كاملة. إذا كنت بحاجة إلى تحرير الاتصال على الفور، قم بتمرير `async: true` أو `callback_url`:

1. احفظ `task_id` و `trace_id` في الاستجابة الفورية.
2. عند عدم تكوين ردود الاستدعاء، قم باستدعاء `/minimax/tasks` كل 10 ثوانٍ تقريبًا للاستعلام.
3. عندما يتغير `task.status` إلى `succeeded`، احصل على الفيديو من `task.content.url`.
4. عندما تكون الحالة `failed` أو `cancelled`، توقف عن الاستعلام، واقرأ `task.error`.

## معلمات الطلب العليا

| المعلمة             | النوع       | إلزامي   | القيمة الافتراضية        | الوصف                                                |
| -------------- | -------- | ---- | ---------- | ------------------------------------------------- |
| `model`        | string   | نعم    | -          | ثابت كـ `MiniMax-H3`                                  |
| `content`      | object[] | نعم    | -          | مصفوفة المحتوى متعدد الوسائط، يجب أن تحتوي على عنصر نصي غير فارغ                         |
| `resolution`   | string   | نعم    | -          | `768P` أو `2K`                                     |
| `duration`     | integer  | نعم    | -          | مدة الإنشاء، عدد صحيح بين 4-15 ثانية                                     |
| `ratio`        | string   | مطلوب شرطي | `adaptive` | `adaptive`، `21:9`، `16:9`، `4:3`، `1:1`، `3:4`، `9:16` |
| `async`        | boolean  | لا    | `false`    | عند `true`، يتم إرجاع معرف المهمة على الفور، ويتم الحصول على النتائج عبر واجهة المهام                       |
| `callback_url` | string   | لا    | -          | عنوان URL للرد العام لاستلام نتائج المهام النهائية؛ عند تقديمه، يتم تفعيل الوضع غير المتزامن تلقائيًا                     |

تعتمد قواعد `ratio` على سير العمل:

- **فيديو من النص**: إلزامي، ولا يمكن أن يكون `adaptive`.
- **فيديو من الإطار الأول، الإطار الأخير أو الإطارين**: يتم تحديد نسبة العرض من الصورة المدخلة، يوصى بتجاهلها أو تمرير `adaptive`.
- **فيديو مرجعي متعدد الوسائط**: يمكن تجاهله، القيمة الافتراضية هي `adaptive`؛ يمكن أيضًا تحديد نسبة ثابتة.

لا تقبل الواجهة الحقول القديمة أو المتوافقة، مثل `prompt`، `image_urls`، `audio_urls`، `messages` و `first_frame_image`. عند تلقي هذه المعلمات بشكل خاطئ، يرجى حذف الحقول القديمة والانتقال إلى `content`؛ على سبيل المثال، تحويل `"prompt": "قطة تلوح"` إلى `"content": [{"type": "text", "text": "قطة تلوح"}]`. لا ترسل كلا التنسيقين الجديد والقديم في نفس الوقت.

## معلمات عناصر محتوى content

يجب أن تحتوي كل عنصر محتوى على `type`، وتحدد الحقول الأخرى بناءً على النوع:

| `type`      | بيانات الحقل            | `role`            | الوصف                                     |
| ----------- | --------------- | ----------------- | -------------------------------------- |
| `text`      | `text`          | لا ترسل                | يجب أن يحتوي كل طلب على عنصر نصي غير فارغ، بحد أقصى 7000 حرف             |
| `image_url` | `image_url.url` | `first_frame`     | صورة الإطار الأول؛ إذا كانت هناك صورة واحدة فقط وتم تجاهل `role`، يتم اعتبارها أيضًا كإطار أول         |
| `image_url` | `image_url.url` | `last_frame`      | صورة الإطار الأخير؛ يمكن استخدامها بمفردها، أو مع `first_frame` للتحكم في البداية والنهاية |
| `image_url` | `image_url.url` | `reference_image` | صورة مرجعية، شخصية، منتج، ملابس، مشهد أو نمط                    |
| `video_url` | `video_url.url` | `reference_video` | فيديو مرجعي للحركة، زوايا الكاميرا، الأداء أو هيكل التحرير                        |
| `audio_url` | `audio_url.url` | `reference_audio` | صوت مرجعي، حوار، موسيقى أو إيقاع                          |

تدعم عناوين الوسائط ثلاثة أشكال:

- عنوان URL HTTPS يمكن الوصول إليه عبر الإنترنت، يوصى به للملفات الكبيرة.
- `mm_file://{file_id}`، للإشارة إلى الملفات التي تم تحميلها بالفعل أو النتائج الموجودة.
- URI بيانات Base64 من النوع المقابل للوسائط. سيؤدي Base64 إلى زيادة الحجم بحوالي الثلث، يرجى التأكد من أن حجم جسم الطلب بالكامل لا يتجاوز 64 ميجابايت.

## عرض القدرات الإنتاجية

ما يلي ليس رسومات مفاهيمية أو مواد مؤقتة، بل هو مدخلات حقيقية لمعاينة القدرات الإنتاجية الرسمية لـ MiniMax H3 ومخرجات الفيديو الفعلية. تغطي ثلاث مجموعات من الحالات مقاطع الفيديو القصيرة للعلامات التجارية، السرد البشري، والتجارة الإلكترونية للأزياء، مما يجعلها مناسبة لتقييم القدرات الأكثر أهمية للنموذج في الإنتاج التجاري.

| القدرة       | الملاحظات الرئيسية                        |
| -------- | --------------------------- |
| اتساق الشخصيات والوجوه | استقرار ملامح الوجه، تسريحات الشعر، المكياج، وسمات الشخصية بعد تبديل الزوايا     |
| أداء الوجه     | تعبيرات العين، التعبيرات الدقيقة، توتر المشاعر، وحركة الرأس الطبيعية في اللقطات القريبة      |
| الحفاظ على هيكل المنتج   | ملامح النظارات، الحقائب، وغيرها من المنتجات، المواد، علاقات الارتداء، والانعكاسات    |
| تنفيذ الرؤية العلامية   | هل تتوافق أجواء المشهد، حبيبات الفيلم، الألوان، الشعار، وإيقاع التحرير |
| السرد السينمائي    | هل يمكن أن تتشكل تغييرات الزوايا، تنظيم الشخصيات، حركة الكاميرا، الإيقاع، والصوت في مقاطع كاملة  |

هنا، تشير "قدرة الوجه" إلى اتساق مظهر الشخصيات، تفاصيل الوجه، والتحكم في الأداء في توليد الفيديو، وليس التعرف على الهوية، مقارنة الوجوه، أو واجهات تغيير الوجه.

## فيديو نصي

عندما يكون هناك عنصر نصي واحد فقط، يكون ذلك فيديو نصيًا. مناسب لإنشاء مشهد مباشرة من الإبداع، أو السيناريو، أو وصف اللقطة. يمكن تنظيم الكلمات المفتاحية حسب ترتيب "الموضوع + الحركة + المشهد + اللقطة + الإضاءة + الصوت".

```bash
curl -X POST 'https://api.acedata.cloud/minimax/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MiniMax-H3",
    "content": [
      {
        "type": "text",
        "text": "15 ثانية إعلان عطر بمستوى سينمائي: على الصخور السوداء على الساحل في الصباح، زجاجة عطر شفافة محاطة بالضباب وأمواج البحر. عرض مقرب يظهر قطرات الماء على الزجاج وانكسار الضوء، الكاميرا ترفع ببطء من التركيز على المنتج إلى سطح البحر الواسع؛ نغمات فضية وزرقاء، ضوء طبيعي حقيقي، ضبط راقٍ، النهاية تثبت المنتج."
      }
    ],
    "resolution": "2K",
    "duration": 15,
    "ratio": "16:9"
  }'
```

الوضع الافتراضي المتزامن سيعيد المهمة الكاملة بعد الانتهاء من التوليد:

```json
{
  "task": {
    "id": "f5977217-ed2c-40da-adbe-93d08235618f",
    "model": "MiniMax-H3",
    "status": "succeeded",
    "content": { "url": "https://cdn.acedata.cloud/minimax/f5977217.mp4" },
    "resolution": "2K",
    "duration": 15,
    "ratio": "16:9"
  }
}
```

إذا تم إضافة `"async": true` إلى الطلب، ستعيد الواجهة على الفور:

```json
{
  "task_id": "f5977217-ed2c-40da-adbe-93d08235618f",
  "trace_id": "trace_7f8c2b1a"
}
```

## فيديو من الصورة الأولى

قم بتحديد الصورة على أنها `first_frame`، سيبدأ النموذج من هذه الصورة. مناسب لجعل الملصقات، وصور المنتجات، وصور الشخصيات، والأعمال الفوتوغرافية تتحرك بشكل طبيعي.

```json
{
  "model": "MiniMax-H3",
  "content": [
    {

      "role": "first_frame"

  "resolution": "2K",
  "duration": 5,
  "ratio": "adaptive"

```

## فيديو من الإطار الأخير والإطارين الأول والأخير
只提供 `last_frame` 可以让模型自然生成到指定画面；同时提供 `first_frame` 与 `last_frame`，可以明确控制起点和终点。适合转场、形态变化、成长过程或产品前后对比。

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "الفتاة تنمو بشكل طبيعي من الطفولة إلى الشباب، مرور الوقت سلس، والشخصية دائمًا في وسط الصورة"
    },
    {
      "type": "image_url",
      "image_url": { "url": "YOUR_FIRST_FRAME_URL" },
      "role": "first_frame"
    },
    {
      "type": "image_url",
      "image_url": { "url": "YOUR_LAST_FRAME_URL" },
      "role": "last_frame"
    }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "adaptive"
}
```

首帧与尾帧的尺寸和宽高比应尽量一致，主体位置、构图和光线差异不要过大，这样更容易得到自然过渡。

## 多模态参考生视频

参考素材可以组合使用：参考图片控制角色或产品外观，参考视频控制动作和运镜，参考音频控制对白音色、音乐或剪辑节奏。提示词中应明确说明每类素材要控制什么，避免只上传素材却不给出关联关系。

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "الحفاظ على ملامح الشخصية، تسريحة الشعر والملابس متطابقة مع الصورة المرجعية، إكمال الفيديو القصير العصري وفقًا لأداء الفيديو المرجعي؛ إيقاع الكاميرا يتبع الصوت المرجعي، اللقطات القريبة تبرز تعبيرات الوجه الطبيعية"
    },
    {
      "type": "image_url",
      "image_url": { "url": "YOUR_CHARACTER_IMAGE_URL" },
      "role": "reference_image"
    },
    {
      "type": "video_url",
      "video_url": { "url": "YOUR_PERFORMANCE_VIDEO_URL" },
      "role": "reference_video"
    },
    {
      "type": "audio_url",
      "audio_url": { "url": "YOUR_AUDIO_URL" },
      "role": "reference_audio"
    }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "adaptive"
}
```

## 回调通知

传入 `callback_url` 会自动启用异步模式：创建接口立即返回 `task_id` 和 `trace_id`，并在任务完成后向该地址 POST 最终结果，结构与任务查询响应一致。

回调中的最终状态为 `succeeded`、`failed` 或 `cancelled`。即使使用回调，也建议保存 `task_id`，以便主动查询或补偿漏掉的通知。

## 常见错误

| HTTP 状态码 | 含义           | 处理建议                           |
| -------- | ------------ | ------------------------------ |
| `400`    | خطأ في المعلمات أو تركيبة المواد غير صالحة | تحقق من الحقول المطلوبة، `role`، عدد المواد والتنسيق          |
| `401`    | مفقود أو غير صالح  | تحقق من `Authorization: Bearer ...` |
| `402`    | رصيد أو حد غير كاف      | أضف رصيد عام في وحدة التحكم                     |
| `422`    | فحص أمان المحتوى لم ينجح    | قم بتعديل الكلمات الدالة أو المواد ثم أعد الإرسال                  |
| `429`    | الطلبات متكررة جدًا       | حاول مرة أخرى بعد فترة تراجع؛ يُنصح بفترة استعلام عن المهام حوالي 10 ثوانٍ         |
| `500`    | الخدمة غير متاحة مؤقتًا      | احتفظ بمعلومات الطلب، وحاول مرة أخرى لاحقًا                    |

استجابة المتزامنة التي تحتوي على `task.status: succeeded` تعني أن الفيديو قد تم إنشاؤه؛ التأكيد غير المتزامن يمثل فقط أن المهمة قد دخلت في قائمة الانتظار. سيتم تحصيل الرسوم فقط عند نجاح المهمة النهائية، واستعلام المهمة نفسها مجاني، ولن يتم خصم الرسوم مرة أخرى.
