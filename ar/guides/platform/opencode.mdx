نموذج خطة البرمجة OpenCode Provider و IDE Extension و MCP هي ثلاث قدرات مستقلة. يربط IDE Extension وقت تشغيل OpenCode المحلي، ويعيد استخدام نفس تكوين Provider؛ لا يمثل دعم المحرر الأصلي لـ Ace Data Cloud.

| المسار                          | الوصف                                                      | الرابط                                                                                  | الحالة      |
| ----------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------- |
| مزود Terminal / CLI / TUI     | استخدام `opencode.json[c]` و Chat Completions                | [تكوين المزود](https://platform.acedata.cloud/documents/opencode-terminal-integration) | تم التحقق من عقد التكوين |
| IDE Extension                 | VS Code و Cursor و Windsurf و VSCodium وغيرها من المضيفين المتصلين بوقت تشغيل OpenCode | [تكوين IDE](https://platform.acedata.cloud/documents/opencode-ide-integration)           | تجريبي     |
| MCP                           | استدعاء أدوات بعيدة داخل OpenCode                                      | [نظرة عامة على MCP](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | قدرة مستقلة    |

بعد نجاح تكوين المزود، يجب على IDE Extension استخدام نفس المزود والنموذج. لا يزال يتعين التحقق من الدردشة داخل IDE وقراءة الملفات والتحرير واستدعاء الأدوات بشكل منفصل، ولا ينبغي افتراض أن طلب CLI العادي يمكن تعميمه على جميع قدرات IDE.

معرف النموذج يعتمد على [الدليل المباشر](https://platform.acedata.cloud/models).
