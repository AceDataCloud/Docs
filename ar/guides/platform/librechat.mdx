[LibreChat](https://www.librechat.ai/) هو عميل AI مفتوح المصدر قابل للتكوين بدرجة عالية، يمكن استخدام `librechat.yaml` لوصف مقدمي الخدمة، والنماذج، وقواعد التوجيه. يدعم نقاط النهاية المتوافقة مع OpenAI المخصصة، مما يسمح بالاتصال بـ Ace Data Cloud. يوضح هذا المقال عملية التكوين.

## عملية التقديم

للاتصال بـ Ace Data Cloud في LibreChat، يجب أولاً الذهاب إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على رمز API الخاص بك، احتفظ به للاستخدام لاحقًا.

![الحصول على مفتاح API لـ Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد قمت بتسجيل الدخول أو التسجيل بعد، سيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك للتسجيل وتسجيل الدخول، وبعد تسجيل الدخول، سيتم العودة تلقائيًا إلى الصفحة الحالية.

عند التقديم لأول مرة، سيكون هناك حد مجاني متاح، يمكنك من تجربة خدمات نموذج Ace Data Cloud مجانًا.

## نشر LibreChat

يتم نشر LibreChat عبر Docker Compose، أولاً قم بإعداد الدليل وتنزيل التكوين الرسمي:

```bash
mkdir -p ~/librechat && cd ~/librechat
curl -O https://raw.githubusercontent.com/danny-avila/LibreChat/main/docker-compose.yml
curl -O https://raw.githubusercontent.com/danny-avila/LibreChat/main/.env.example
mv .env.example .env
```

في `.env`، استخدم `openssl rand -hex 32` لإنشاء `JWT_SECRET`، `JWT_REFRESH_SECRET`، `CREDS_KEY`، `CREDS_IV` وغيرها من المفاتيح الأمنية، وقم بتعيين `ALLOW_REGISTRATION` حسب الحاجة.

## تكوين Ace Data Cloud

قم بإنشاء `librechat.yaml`، واجعل Ace Data Cloud كنقطة نهاية مخصصة متوافقة مع OpenAI (لشرح الحقول بالكامل، انظر [وثائق النقاط المخصصة](https://www.librechat.ai/docs/quick_start/custom_endpoints)، واستبدل `{token}` برمزك):

```yaml
version: 1.0.5
cache: true

endpoints:
  custom:
    - name: "Ace Data Cloud"
      apiKey: "{token}"
      baseURL: "https://api.acedata.cloud/v1"
      models:
        default:
          - "MODEL_ID"
        fetch: true
      titleConvo: true
      titleModel: "MODEL_ID"
      modelDisplayLabel: "Ace Data Cloud"
```

في `docker-compose.yml` تحت خدمة `api`، قم بربط هذا الملف بالحاوية، ثم قم بتشغيل `docker compose up -d`:

```yaml
    volumes:
      - type: bind
        source: ./librechat.yaml
        target: /app/librechat.yaml
```

لاحظ قواعد مسار `baseURL`:

| baseURL                               | الطلب الفعلي                                           | النتيجة                   |
| ------------------------------------- | ---------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`    | صحيح                     |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`| يمكن استخدامه أيضًا      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (`/openai` لا يحتوي على `/v1`) |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`       | 404 (يفتقر إلى `/v1`)    |

## اختيار النموذج

ستستمر قائمة النماذج في التحديث. استخدم أولاً قائمة النماذج التي يتم تحميلها تلقائيًا من العميل؛ إذا كنت بحاجة إلى إدخال يدوي، اطلب أولاً `GET https://api.acedata.cloud/v1/models` للحصول على معرف النموذج الحالي، ثم اختر وفقًا لقدرات السياق والصورة وأدوات الاستدعاء المدعومة من العميل.

## التحقق من الاتصال

إذا لم تكن متأكدًا مما إذا كانت المشكلة في LibreChat أو الشبكة، يمكنك التحقق من النقطة مباشرة باستخدام curl (استبدل `{token}` برمزك):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

إذا تم إرجاع كائن `chat.completion` المتوافق مع OpenAI، فهذا يعني أن الرمز والنقطة جاهزان؛ إذا تم إرجاع `HTTP 403 used_up`، فهذا يعني أن الرمز صالح ولكن الرصيد غير كافٍ، يمكنك إعادة شحنه من [لوحة التحكم](https://platform.acedata.cloud/console/applications).

## متقدم: نصائح تكوين yaml

يدعم `librechat.yaml` مجموعات متعددة من النقاط، يمكنك استخدام `apiKey: "user_provided"` ليقوم كل مستخدم بإدخال مفتاحه الخاص؛ `titleModel` يحدد النموذج المستخدم لإنشاء عنوان المحادثة؛ `dropParams` يمكن أن يحذف بشكل موحد المعلمات التي لا تدعمها واجهة برمجة التطبيقات المستهدفة. لمزيد من التفاصيل، انظر [شرح تكوين librechat.yaml](https://www.librechat.ai/docs/configuration/librechat_yaml).

## الأسئلة الشائعة

### لا أرى نقطة نهاية Ace Data Cloud بعد التشغيل

عادةً ما يكون السبب هو عدم ربط yaml بالحاوية أو وجود خطأ في المسافة البادئة. تحقق من `docker-compose.yml` الخاص بـ volumes، وتحقق من المسافة البادئة في yaml.

### تظهر رسالة 404

تم كتابة `baseURL` كـ `.../openai/v1` أو تم حذف `/v1`. قم بتغييره إلى `https://api.acedata.cloud/v1`.

### قائمة النماذج فارغة

`fetch: true` ولكن `/v1/models` فشل، قم بتغييره إلى `fetch: false` وأدرج `default` يدويًا.

### لا تنجح التغييرات في yaml

يجب إعادة تشغيل الحاوية: `docker compose restart api`.
