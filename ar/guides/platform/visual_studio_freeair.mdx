FreeAIr هو امتداد مفتوح المصدر موجه لـ Visual Studio 2022/2026، وقد صرحت الجهة الرسمية بأنه يمكن الاتصال بأي واجهة برمجة تطبيقات متوافقة مع OpenAI. قد تتغير سلوكيات الطلبات في إصدارات الامتداد المختلفة؛ يرجى تثبيت إصدار ثابت وإكمال الحد الأدنى من التحقق المذكور أدناه عند الاتصال لأول مرة.

## التكوين

1. قم بتثبيت FreeAIr من Visual Studio Marketplace أو المستودع الرسمي.
2. افتح إعدادات FreeAIr وأضف اتصالاً متوافقًا مع OpenAI.
3. املأ Endpoint بـ `https://api.acedata.cloud/v1`.
4. املأ Token برمز API الخاص بك من Ace Data Cloud.
5. املأ Model بمعرف النموذج الدقيق المدعوم لـ Chat Completions في دليل النماذج.
6. بعد الحفظ، أرسل `Reply only OK`، ثم اختبر مرة أخرى طلبًا مع سياق المشروع.

## الحدود الحالية

- تغطي هذه الإرشادات FreeAIr فقط، ولا تمثل دعم Visual Studio المدمج لـ Copilot لعنوان URL أساسي عشوائي.
- قد يتغير إصدار الامتداد طريقة تجميع endpoint؛ يجب التحقق من عنوان URL النهائي عند التحقق.
- يتطلب استدعاء الأدوات وقدرات MCP داخل الامتداد تحققًا مستقلًا، ولا يمكن استبدال النجاح في الدردشة العادية بذلك.
