أنشئ مثيل حاوية Hermes مستقلًا لكل Application. يُستخدم افتراضيًا صورة أساسية بإصدار ثابت منشور، مع الاحتفاظ بالوظائف الأصلية؛ وتوفر المنصة الشراء والتجديد والتخزين الدائم وإدارة النشر.

## الإنشاء والشراء

1. افتح [نشر Hermes](https://platform.acedata.cloud/services/hermes) وأنشئ Application.
2. اختر باقة المدة في صفحة الشراء وأكمل الدفع.
3. عُد إلى صفحة الإعدادات، ويمكنك اختيار نموذج دردشة المنصة من القائمة المنسدلة وعرض سعر النموذج الحالي. ستنشئ المنصة بيانات اعتماد API مستقلة لهذا المثيل؛ ويمكنك أيضًا إغلاق اتصال المنصة وإعداده بنفسك في وحدة التحكم الأصلية.
4. اختر إنشاء بيانات اعتماد الوصول تلقائيًا، أو عيّن كلمة مرور/Token قويًا خاصًا بك؛ وحدد A2A وEnvarPay حسب الحاجة، ثم ابدأ النشر بعد التأكيد. بيانات اعتماد الوصول وبيانات اعتماد API للنموذج مستقلة عن بعضها البعض.
5. بعد أن يصبح المثيل جاهزًا، احصل على عنوان الوصول وبيانات تسجيل الدخول من صفحة الإدارة.
6. سجّل الدخول إلى وحدة التحكم الأصلية لإعداد القنوات. إذا أغلقت اتصال نموذج المنصة عند النشر، فيجب عليك أيضًا إعداد موفر النموذج وبيانات الاعتماد بنفسك حتى يمكن استخدام الدردشة.

تُحتسب رسوم النشر وفقًا لمدة الباقة، وتكون الأسعار المحددة بالدولار الأمريكي والمدد وفقًا لصفحة الشراء. تُحتسب رسوم استدعاء النموذج بشكل منفصل؛ ولا يمنح شراء مدة النشر رصيدًا للنموذج. عند تفعيل اتصال المنصة، تفتح بيانات اعتماد API المخصصة فقط واجهة الدردشة المقابلة للنموذج المحدد، وتُحتسب الاستدعاءات بشكل منفصل من رصيد منصتك. يتم شراء وتجديد وإدارة كل Application بشكل منفصل.

## كلمات المرور وبيانات الاعتماد والإعدادات اللاحقة

تُضبط بيانات اعتماد الوصول قبل أول تشغيل. تستخدم طريقة الإنشاء التلقائي بيانات اعتماد عشوائية، ويجب ألا تقل كلمة المرور المخصصة عن 16 حرفًا، وألا يقل OpenClaw Token عن 32 حرفًا. لا تحفظ المسودات كلمات المرور؛ وقد تحتاج إلى إعادة إدخالها بعد تبديل الصفحة. بعد النشر، لا يمكن إلا لمالك Application والمسؤولين عرض بيانات اعتماد الوصول.

لا تُعاد استخدام بيانات اعتماد API للنموذج لكل مثيل، وتمتد صلاحيتها مع تجديد النشر، وتُلغى عند حذف المثيل. إذا لم يتم توصيل نموذج المنصة عند النشر الأول، يمكنك اختيار نموذج المنصة في صفحة إعدادات Application وإعادة النشر؛ ستحدّث المنصة النموذج الافتراضي، مع الاحتفاظ بالمحادثات والإعدادات الأصلية الأخرى. بعد ذلك، يُرجى تعديل النموذج والقنوات في وحدة التحكم الأصلية؛ وإذا اخترت نموذجًا لخدمة أخرى، فعدّل أولًا تفويض الواجهة المقابلة في إدارة بيانات اعتماد المنصة، أو استخدم بيانات الاعتماد المناسبة. لا تؤدي إعادة النشر العادية إلى الكتابة فوق الإعدادات الأصلية. سترفض بيئات النشر غير المتحقق من إصدارها عمليات النشر الجديدة مؤقتًا، يُرجى الاتصال بالدعم.

## مكونات النشر الاختيارية

بعد تحديد A2A، سيشغّل قالب النشر بوابة Hermes A2A الأصلية، ويوفر رمز المالك في صفحة الإدارة. سيؤدي تحديد EnvarPay إلى تثبيت حاوية خدمة مستقلة ودفتر أستاذ دائم إضافيين، ويتطلب تفعيل A2A أولًا. لا يحتوي EnvarPay في البداية إلا على بيانات اعتماد وصول المالك، ولا يحتوي على خدمة أو هوية تحصيل، ولن يفرض رسومًا أو يشتري بالنيابة تلقائيًا. لا يؤدي أي من الخيارين إلى تسجيل المثيل تلقائيًا في Envar؛ ويمكن للمثيلات الحالية الدخول إلى الإعدادات من صفحة الإدارة، ثم إعادة النشر بعد التفعيل. لا يمكن حاليًا إيقاف تشغيل المكونات المفعّلة في هذا المعالج.

## الإصدار والبيانات

تعرض صفحة الإعدادات إصدار الصورة المنشور حاليًا. تستخدم المثيلات الجديدة الإصدار المنشور الحالي للخدمة؛ ولا تُستبدل المثيلات الحالية تلقائيًا مع تحديثات الكتالوج. ستطبق إعادة النشر إصدار الخدمة الحالي، يُرجى إجراء النسخ الاحتياطي أولًا والتأكد من متطلبات الترقية للإصدار المستخدم.

يوفر كل مثيل افتراضيًا 1 CPU، وحدًا أقصى للذاكرة يبلغ 2 GiB، وتخزينًا دائمًا بسعة 10 GiB. يحتفظ إعادة التشغيل ببيانات المثيل. سيؤدي حذف النشر يدويًا أو الاسترداد عند انتهاء الصلاحية إلى حذف التخزين، يُرجى تصدير البيانات التي تحتاج إلى الاحتفاظ بها مسبقًا.

## التجديد وانتهاء الصلاحية

جدّد في صفحة الشراء الخاصة بـ Application الحالي، وستمتد فترة الصلاحية وفقًا لقواعد المدة الحالية للمنصة. بعد انتهاء الصلاحية، يتم إيقاف مدخل الوصول مؤقتًا، ويؤدي التجديد خلال فترة السماح إلى استعادة الوصول؛ وبعد تجاوز فترة السماح، سيتم استرداد المثيل والبيانات. يُعتد بوقت انتهاء الصلاحية وحالة الفوترة وتنبيهات الحذف في صفحة الإدارة.

## تسجيل الدخول إلى واجهة الإدارة

انسخ عنوان Dashboard واسم المستخدم `admin` وكلمة المرور من صفحة إدارة النشر، ثم افتحها وسجّل الدخول. تُوفر معلومات تسجيل الدخول فقط لمالك Application ومسؤولي المنصة. يتم إعداد النماذج والمهارات والقنوات في واجهة Hermes الأصلية.

## الأسئلة الشائعة

- **لماذا لا يزال المثيل الجديد غير قادر على الإجابة؟** يعني اكتمال النشر فقط أن الحاوية جاهزة. إذا أُغلق اتصال نموذج المنصة عند النشر، فيجب اختيار نموذج المنصة في صفحة الإعدادات وإعادة النشر، أو إعداد النموذج وبيانات الاعتماد بنفسك في الواجهة الأصلية.
- **هل تُثبّت إضافات أو نموذج fallback إضافي مسبقًا؟** لا تُضاف افتراضيًا، ويمكن إعدادها حسب الحاجة في الواجهة الأصلية.
- **كيف يتم تحديث مثيل موجود؟** يتم الاحتفاظ بـ Application والطلب الأصليين، ويُستخدم إصدار الخدمة الحالي عند إعادة النشر؛ قم أولًا بنسخ البيانات احتياطيًا وتحقق من توافق الإصدار قبل الترقية.
- **ماذا أفعل إذا فشل التشغيل؟** تحقّق أولًا من سجلات وأحداث النشر، ثم أعد إعداد النموذج بعد التأكد من أن المثيل جاهز. لا تكشف كلمة مرور المثيل والمفاتيح في التعليقات العامة أو لقطات الشاشة.
