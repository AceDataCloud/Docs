إنشاء مثيل حاوية Hermes مستقل لكل Application. يُستخدم افتراضيًا صورة أساسية بإصدار إصدار ثابت، مع الاحتفاظ بالوظائف الأصلية؛ وتوفّر المنصة الشراء والتجديد والتخزين الدائم وإدارة النشر.

## الإنشاء والشراء

1. افتح [نشر Hermes](https://platform.acedata.cloud/services/hermes) وأنشئ Application.
2. اختر باقة المدة في صفحة الشراء، وأكمل الدفع.
3. ارجع إلى صفحة الإعدادات، ويمكنك اختيار نموذج الدردشة الخاص بالمنصة من القائمة المنسدلة، وعرض سعر النموذج الحالي. ستنشئ المنصة بيانات اعتماد API مستقلة لهذا المثيل؛ ويمكنك أيضًا إيقاف اتصال المنصة وإعداده بنفسك في لوحة التحكم الأصلية.
4. اختر إنشاء بيانات اعتماد الوصول تلقائيًا، أو عيّن كلمة مرور/Token قوية خاصة بك، ثم ابدأ النشر بعد التأكيد. بيانات اعتماد الوصول وبيانات اعتماد API للنموذج مستقلة عن بعضها.
5. بعد أن يصبح المثيل جاهزًا، احصل على عنوان الوصول وبيانات اعتماد تسجيل الدخول من صفحة الإدارة.
6. سجّل الدخول إلى لوحة التحكم الأصلية لإعداد القنوات. إذا أوقفت اتصال نموذج المنصة عند النشر، فيجب عليك أيضًا إعداد موفّر النموذج وبيانات الاعتماد بنفسك حتى يمكن استخدام الدردشة.

تُحتسب رسوم النشر حسب مدة الباقة، وتخضع أسعار الدولار الأمريكي والمدة المحددة لصفحة الشراء. تُحتسب رسوم استدعاء النموذج بشكل منفصل؛ وشراء مدة النشر لا يمنح رصيدًا للنموذج. عند تفعيل اتصال المنصة، تفتح بيانات اعتماد API المخصصة فقط واجهة الدردشة المقابلة للنموذج المحدد، وتُحتسب الاستدعاءات بشكل منفصل من رصيد منصتك. يتم شراء كل Application وتجديده وإدارته بشكل منفصل.

## كلمات المرور وبيانات الاعتماد والإعدادات اللاحقة

يتم تعيين بيانات اعتماد الوصول قبل أول تشغيل. تستخدم طريقة الإنشاء التلقائي بيانات اعتماد عشوائية، ويجب أن تتكون كلمة المرور المخصصة من 16 حرفًا على الأقل، وأن يتكون OpenClaw Token من 32 حرفًا على الأقل. لا تحفظ المسودات كلمات المرور؛ وقد تحتاج إلى إعادة إدخالها بعد تبديل الصفحة. بعد النشر، لا يمكن إلا لمالك Application والمسؤولين عرض بيانات اعتماد الوصول.

لا يعاد استخدام بيانات اعتماد API للنموذج الخاصة بكل مثيل، وتمتد صلاحيتها مع تجديد النشر، وتُلغى عند حذف المثيل. إذا لم يتم ربط نموذج المنصة عند النشر الأول، فيمكنك اختيار نموذج المنصة في صفحة إعدادات ذلك Application وإعادة النشر؛ ستحدّث المنصة النموذج الافتراضي، مع الاحتفاظ بالجلسات والإعدادات الأصلية الأخرى. بعد ذلك، يُرجى تعديل النموذج والقنوات في لوحة التحكم الأصلية؛ وإذا اخترت نموذجًا من خدمة أخرى، فاضبط أولًا تفويض الواجهة المقابلة في إدارة بيانات اعتماد المنصة، أو استخدم بيانات الاعتماد المقابلة. لا تؤدي إعادة النشر العادية إلى الكتابة فوق الإعدادات الأصلية. ستُرفض عمليات النشر الجديدة مؤقتًا في بيئات النشر التي لم تجتز التحقق من الإصدار، يُرجى الاتصال بالدعم.

## الإصدار والبيانات

تعرض صفحة الإعدادات إصدار الصورة المنشور حاليًا. تستخدم المثيلات الجديدة الإصدار المنشور حاليًا للخدمة؛ ولن تُستبدل المثيلات الحالية تلقائيًا مع تحديثات الكتالوج. ستطبق إعادة النشر إصدار الخدمة الحالي، يُرجى إجراء نسخة احتياطية أولًا والتأكد من متطلبات الترقية للإصدار المستخدم.

يوفّر كل مثيل افتراضيًا حدًا قدره 1 CPU و2 GiB من الذاكرة و10 GiB من التخزين الدائم. تحتفظ إعادة التشغيل ببيانات المثيل. سيؤدي حذف النشر يدويًا أو الاسترداد عند انتهاء الصلاحية إلى حذف التخزين، يُرجى تصدير البيانات التي تحتاج إلى الاحتفاظ بها مسبقًا.

## التجديد وانتهاء الصلاحية

جدّد الاشتراك في صفحة الشراء الخاصة بـ Application الحالي، وستمتد فترة الصلاحية وفق قواعد المدة الحالية للمنصة. بعد انتهاء الصلاحية، يتم إيقاف مدخل الوصول مؤقتًا، ويؤدي التجديد خلال فترة السماح إلى استعادة الوصول؛ وسيتم استرداد المثيل والبيانات بعد تجاوز فترة السماح. يُرجى الرجوع إلى وقت انتهاء الصلاحية وحالة الفوترة وإشعارات الحذف في صفحة الإدارة.

## تسجيل الدخول إلى واجهة الإدارة

انسخ عنوان Dashboard واسم المستخدم `admin` وكلمة المرور من صفحة إدارة النشر، ثم افتحها وسجّل الدخول. لا تُقدَّم معلومات تسجيل الدخول إلا لمالك ذلك Application ومسؤولي المنصة. يتم إعداد النماذج والمهارات والقنوات في واجهة Hermes الأصلية.

## الأسئلة الشائعة

- **لماذا لا يستطيع المثيل الجديد الإجابة بعد؟** اكتمال النشر يعني فقط أن الحاوية جاهزة. إذا أوقفت اتصال نموذج المنصة عند النشر، فيجب اختيار نموذج المنصة في صفحة الإعدادات وإعادة النشر، أو إعداد النموذج وبيانات الاعتماد بنفسك في الواجهة الأصلية.
- **هل توجد إضافات إضافية أو نموذج fallback مثبت مسبقًا؟** لا تتم إضافتها افتراضيًا، قم بالإعداد حسب الحاجة في الواجهة الأصلية.
- **كيف يتم تحديث مثيل موجود؟** يتم الاحتفاظ بـ Application والطلب الأصليين، ويُستخدم إصدار الخدمة الحالي عند إعادة النشر؛ قم بعمل نسخة احتياطية للبيانات وتحقق من توافق الإصدار قبل الترقية.
- **ماذا أفعل عند فشل التشغيل؟** تحقق أولًا من سجلات النشر والأحداث، وأعد إعداد النموذج بعد التأكد من أن المثيل جاهز. لا تكشف كلمة مرور المثيل والمفاتيح في التعليقات العامة أو لقطات الشاشة.
