إنشاء مثيل حاوية Hermes مستقل لكل Application. يُستخدم افتراضيًا صورة أساسية بإصدار ثابت، مع الاحتفاظ بالوظائف الأصلية؛ وتوفر المنصة الشراء والتجديد والتخزين الدائم وإدارة النشر.

## الإنشاء والشراء

1. افتح [نشر Hermes](https://platform.acedata.cloud/services/hermes) وأنشئ Application.
2. اختر باقة المدة في صفحة الشراء، وأكمل الدفع.
3. ارجع إلى صفحة الإعداد، ويمكنك اختيار نموذج الدردشة الخاص بالمنصة من القائمة المنسدلة، وعرض سعر النموذج الحالي. ستنشئ المنصة بيانات اعتماد API مستقلة لهذا المثيل؛ ويمكنك أيضًا إيقاف تكامل المنصة وإعداده بنفسك في وحدة التحكم الأصلية.
4. اختر إنشاء بيانات اعتماد الوصول تلقائيًا، أو عيّن كلمة مرور/Token قويًا خاصًا بك، ثم ابدأ النشر بعد التأكيد. بيانات اعتماد الوصول وبيانات اعتماد API للنموذج مستقلة عن بعضها.
5. بعد أن يصبح المثيل جاهزًا، احصل على عنوان الوصول وبيانات تسجيل الدخول من صفحة الإدارة.
6. سجّل الدخول إلى وحدة التحكم الأصلية، واضبط موفر النموذج والمفاتيح والقنوات الخاصة بك.

تُحتسب رسوم النشر وفق مدة الباقة، وتكون الأسعار المحددة بالدولار الأمريكي والمدة وفقًا لصفحة الشراء. تُحتسب رسوم استدعاء النموذج بشكل منفصل؛ ولا يمنح شراء مدة النشر رصيدًا للنموذج. عند تمكين تكامل المنصة، تفتح بيانات اعتماد API المخصصة فقط واجهة الدردشة المقابلة للنموذج المحدد، وتُحتسب الاستدعاءات بشكل منفصل من رصيدك على المنصة. يتم شراء كل Application وتجديده وإدارته بشكل منفصل.

## كلمات المرور وبيانات الاعتماد والإعدادات اللاحقة

تُضبط بيانات اعتماد الوصول قبل بدء التشغيل الأول. تستخدم طريقة الإنشاء التلقائي بيانات اعتماد عشوائية، ويجب أن تتكون كلمة المرور المخصصة من 16 حرفًا على الأقل، وOpenClaw Token من 32 حرفًا على الأقل. لا تحفظ المسودات كلمات المرور؛ وقد تحتاج إلى إدخالها مجددًا بعد تبديل الصفحة. بعد النشر، لا يمكن إلا لمالك Application والمسؤولين عرض بيانات اعتماد الوصول.

لا يُعاد استخدام بيانات اعتماد API للنموذج بين المثيلات، وتمتد صلاحيتها مع تجديد النشر، وتُلغى عند حذف المثيل. بعد تهيئة النشر، يُرجى تعديل النماذج والقنوات في وحدة التحكم الأصلية؛ وإذا غيّرت اختيارك إلى نموذج من خدمة أخرى، فاضبط أولًا تفويض الواجهة المقابلة في إدارة بيانات اعتماد المنصة، أو استخدم بيانات الاعتماد المناسبة. لن تؤدي إعادة النشر العادية إلى الكتابة فوق الإعدادات الأصلية. ستُرفض عمليات النشر الجديدة مؤقتًا في بيئات النشر التي لم تجتز التحقق من الإصدار، يُرجى الاتصال بالدعم.

## الإصدار والبيانات

تعرض صفحة الإعداد إصدار الصورة المنشور حاليًا. تستخدم المثيلات الجديدة الإصدار المنشور حاليًا للخدمة؛ ولن تُستبدل المثيلات الموجودة تلقائيًا مع تحديثات الدليل. ستطبق إعادة النشر إصدار الخدمة الحالي، يُرجى النسخ الاحتياطي أولًا والتأكد من متطلبات الترقية للإصدار المستخدم.

يوفر كل مثيل افتراضيًا حدًا أقصى قدره 1 CPU و2 GiB من الذاكرة و10 GiB من التخزين الدائم. يحتفظ إعادة التشغيل ببيانات المثيل. سيؤدي حذف النشر يدويًا أو الاسترداد عند انتهاء الصلاحية إلى حذف التخزين، يُرجى تصدير البيانات التي تحتاج إلى الاحتفاظ بها مسبقًا.

## التجديد وانتهاء الصلاحية

جدّد في صفحة الشراء الخاصة بـ Application الحالي، وستمتد فترة الصلاحية وفقًا لقواعد المدة الحالية للمنصة. بعد انتهاء الصلاحية، يتم تعليق نقطة الوصول، ويؤدي التجديد خلال فترة السماح إلى استعادة الوصول؛ وسيتم استرداد المثيل والبيانات بعد تجاوز فترة السماح. يُرجى الرجوع إلى وقت انتهاء الصلاحية وحالة الفوترة وتنبيهات الحذف في صفحة الإدارة.

## تسجيل الدخول إلى واجهة الإدارة

انسخ عنوان Dashboard واسم المستخدم `admin` وكلمة المرور من صفحة إدارة النشر، ثم افتحها وسجّل الدخول. تُتاح معلومات تسجيل الدخول فقط لمالك Application ومسؤولي المنصة. يتم إعداد النماذج والمهارات والقنوات في واجهة Hermes الأصلية.

## الأسئلة الشائعة

- **لماذا لا يزال المثيل الجديد غير قادر على الرد؟** يعني اكتمال النشر أن الحاوية جاهزة؛ تحتاج إلى إعداد النموذج وبيانات الاعتماد في الواجهة الأصلية قبل بدء الاستخدام.
- **هل توجد إضافات إضافية أو نموذج fallback مثبت مسبقًا؟** لا تُضاف افتراضيًا، اضبطها حسب الحاجة في الواجهة الأصلية.
- **كيف يتم تحديث المثيل الموجود؟** يتم الاحتفاظ بـ Application والطلب الأصليين، ويُستخدم إصدار الخدمة الحالي عند إعادة النشر؛ انسخ البيانات احتياطيًا أولًا وتحقق من توافق الإصدار قبل الترقية.
- **ماذا أفعل عند فشل بدء التشغيل؟** تحقق أولًا من سجلات النشر والأحداث، واضبط النموذج بعد التأكد من أن المثيل جاهز. لا تكشف كلمة مرور المثيل ومفاتيحه في التعليقات العامة أو لقطات الشاشة.
