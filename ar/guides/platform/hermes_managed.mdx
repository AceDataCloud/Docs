أنشئ مثيل حاوية Hermes مستقلاً لكل Application. يُستخدم افتراضياً صورة أساسية بإصدار ثابت، مع الاحتفاظ بالوظائف الأصلية؛ توفر المنصة الشراء والتجديد والتخزين الدائم وإدارة النشر.

## الإنشاء والشراء

1. افتح [نشر Hermes](https://platform.acedata.cloud/services/hermes) وأنشئ Application.
2. اختر باقة المدة في صفحة الشراء، وأكمل الدفع.
3. ارجع إلى صفحة التكوين، حيث يمكنك اختيار نموذج الدردشة الخاص بالمنصة من القائمة المنسدلة، وعرض سعر النموذج الحالي. ستنشئ المنصة بيانات اعتماد API مستقلة لهذا المثيل؛ ويمكنك أيضاً إيقاف تكامل المنصة وإجراء التكوين بنفسك في وحدة التحكم الأصلية.
4. اختر إنشاء بيانات اعتماد الوصول تلقائياً، أو عيّن كلمة مرور/Token قوية خاصة بك؛ حدّد A2A وEnvarPay حسب الحاجة، وابدأ النشر بعد التأكيد. بيانات اعتماد الوصول وبيانات اعتماد API للنموذج مستقلة عن بعضها البعض.
5. بعد أن يصبح المثيل جاهزاً، احصل على عنوان الوصول وبيانات تسجيل الدخول من صفحة الإدارة.
6. سجّل الدخول إلى وحدة التحكم الأصلية لتكوين القنوات. إذا أوقفت تكامل نموذج المنصة عند النشر، فيجب أيضاً تكوين موفر النموذج وبيانات الاعتماد بنفسك قبل أن تتمكن الدردشة من الاستخدام.

تُحتسب رسوم النشر وفق مدة الباقة، وتخضع الأسعار المحددة بالدولار الأمريكي والمدة لصفحة الشراء. تُحتسب رسوم استدعاء النماذج بشكل منفصل؛ شراء مدة النشر لا يمنح رصيداً للنموذج. عند تمكين تكامل المنصة، تتيح بيانات اعتماد API المخصصة فقط واجهة الدردشة المقابلة للنموذج المحدد، وتُحتسب الاستدعاءات بشكل منفصل من رصيد منصتك. يتم شراء وتجديد وإدارة كل Application بشكل منفصل.

## كلمات المرور وبيانات الاعتماد والتكوين اللاحق

سيتم تعيين بيانات اعتماد الوصول قبل بدء التشغيل الأول. تستخدم طريقة الإنشاء التلقائي بيانات اعتماد عشوائية، ويجب ألا تقل كلمة المرور المخصصة عن 16 حرفاً، وألا يقل OpenClaw Token عن 32 حرفاً. لا تحفظ المسودات كلمات المرور؛ وقد تحتاج إلى إدخالها مجدداً بعد تبديل الصفحة. بعد النشر، لا يمكن سوى لمالك Application والمسؤولين عرض بيانات اعتماد الوصول.

لا يُعاد استخدام بيانات اعتماد API للنموذج الخاصة بكل مثيل، وتمتد صلاحيتها مع تجديد النشر، وتُلغى عند حذف المثيل. إذا لم يتم ربط نموذج المنصة عند النشر الأول، فيمكنك اختيار نموذج المنصة في صفحة تكوين Application وإعادة النشر؛ ستحدّث المنصة النموذج الافتراضي مع الاحتفاظ بالجلسات والإعدادات الأصلية الأخرى. بعد ذلك، يرجى تعديل النموذج والقنوات في وحدة التحكم الأصلية؛ إذا اخترت نموذجاً من خدمة أخرى، فاضبط أولاً تفويض الواجهة المقابلة في إدارة بيانات اعتماد المنصة، أو استخدم بيانات الاعتماد المناسبة. لا تؤدي إعادة النشر العادية إلى الكتابة فوق الإعدادات الأصلية. ستُرفض عمليات النشر الجديدة مؤقتاً في بيئات النشر التي لم تجتز التحقق من الإصدار، يرجى الاتصال بالدعم.

## مكونات النشر الاختيارية

بعد تحديد A2A، سيبدأ قالب النشر بوابة Hermes A2A الأصلية، ويوفر رمز المالك في صفحة الإدارة. يؤدي تحديد EnvarPay إلى تثبيت حاوية خدمة مستقلة ودفتر أستاذ دائم إضافيين، ويتطلب تمكين A2A أولاً. لا يحتوي EnvarPay في البداية إلا على بيانات اعتماد وصول المالك، ولا يملك هوية خدمة أو هوية تحصيل، ولن يفرض رسوماً أو يشتري بالنيابة تلقائياً. لا يسجل أي من الخيارين المثيل تلقائياً في Envar؛ يمكن للمثيلات الموجودة الدخول إلى التكوين من صفحة الإدارة وتمكينها ثم إعادة النشر. لا يمكن حالياً إيقاف المكونات الممكّنة في هذا المعالج.

بعد تمكين A2A وجاهزية المثيل، ستعرض بطاقة عنوان الوصول في صفحة الإدارة عنوان Agent Card قابلاً للنسخ. يستخدم Hermes A2A الأصلي عنواناً عاماً مستقلاً؛ لا يمكن استخدام عنوان تسجيل دخول Dashboard كعنوان Agent Card. إذا تم تمكين EnvarPay في الوقت نفسه، فستعرض صفحة الإدارة أيضاً «عنوان الوصول إلى Envar» المقابل؛ عند الوصول إلى خدمة Envar، انسخ عنوان URL هذا بالأولوية.

## الإصدار والبيانات

تعرض صفحة التكوين إصدار الصورة المنشور حالياً. تستخدم المثيلات الجديدة الإصدار المنشور حالياً للخدمة؛ ولا يتم استبدال المثيلات الموجودة تلقائياً مع تحديثات الدليل. ستؤدي إعادة النشر إلى تطبيق إصدار الخدمة الحالي، يرجى النسخ الاحتياطي أولاً والتأكد من متطلبات الترقية للإصدار المستخدم.

يوفر كل مثيل افتراضياً وحدة CPU واحدة، وحداً أقصى للذاكرة قدره 2 GiB، و10 GiB من التخزين الدائم. يحتفظ إعادة التشغيل ببيانات المثيل. سيؤدي حذف النشر بشكل استباقي أو الاسترداد عند انتهاء الصلاحية إلى حذف التخزين، يرجى تصدير البيانات التي تحتاج إلى الاحتفاظ بها مسبقاً.

## التجديد وانتهاء الصلاحية

جدّد الاشتراك في صفحة الشراء الخاصة بـ Application الحالي، وستُمدد فترة الصلاحية وفق قواعد المدة الحالية للمنصة. بعد انتهاء الصلاحية، يتم تعليق مدخل الوصول، ويستعيد التجديد خلال فترة السماح الوصول؛ وبعد تجاوز فترة السماح، سيتم استرداد المثيل والبيانات. يُعتد بوقت انتهاء الصلاحية وحالة الفوترة وتنبيهات الحذف في صفحة الإدارة.

## تسجيل الدخول إلى واجهة الإدارة

انسخ عنوان Dashboard واسم المستخدم `admin` وكلمة المرور في صفحة إدارة النشر، ثم افتحها وسجّل الدخول. لا تُقدَّم معلومات تسجيل الدخول إلا لمالك Application والمسؤولين في المنصة. يتم تكوين النماذج والمهارات والقنوات في واجهة Hermes الأصلية.

## الأسئلة الشائعة

- **لماذا لا يستطيع المثيل الجديد الإجابة بعد؟** اكتمال النشر يعني فقط أن الحاوية جاهزة. إذا أوقفت تكامل نموذج المنصة عند النشر، فيجب اختيار نموذج المنصة لاحقاً في صفحة التكوين وإعادة النشر، أو تكوين النموذج وبيانات الاعتماد بنفسك في الواجهة الأصلية.
- **هل توجد إضافات إضافية أو fallback للنموذج مثبتة مسبقاً؟** لا تتم إضافتها افتراضياً، قم بالتكوين حسب الحاجة في الواجهة الأصلية.
- **كيف يتم تحديث المثيلات الموجودة؟** يتم الاحتفاظ بـ Application والطلب الأصليين، ويُستخدم إصدار الخدمة الحالي عند إعادة النشر؛ انسخ البيانات احتياطياً أولاً وتحقق من توافق الإصدار قبل الترقية.
- **ماذا أفعل عند فشل بدء التشغيل؟** اعرض أولاً سجلات النشر والأحداث، وقم بتكوين النموذج بعد التأكد من جاهزية المثيل. لا تكشف كلمة مرور المثيل والمفاتيح في التعليقات العامة أو لقطات الشاشة.
