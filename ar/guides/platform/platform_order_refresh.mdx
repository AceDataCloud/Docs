استعلم بشكل استباقي عن أحدث حالة لطريقة الدفع المقابلة للطلب وقم بمزامنتها مع المنصة. قد يصل هذا الطلب إلى خدمة الدفع ويغير حالة الطلب، لذا استخدمه فقط عند تأخر رد الاتصال أو الحاجة إلى تأكيد فوري.

## الأعمال التحضيرية

- استخدم [رمز الحساب](https://platform.acedata.cloud/documents/platform-token).
- احصل على معرّف طلبك من [قائمة الطلبات](https://platform.acedata.cloud/documents/platform-order-list).

```shell
export PLATFORM_TOKEN='你的账户令牌'
export ORDER_ID='你的订单 ID'
```

## نظرة عامة على الواجهة

| البند    | المحتوى                                                                 |
| ---- | ------------------------------------------------------------------ |
| الطريقة   | `POST`                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/orders/{order_id}/refresh/` |
| المصادقة   | مالك الطلب أو المشرف الفائق                                                        |
| Body | يكون فارغًا عادةً؛ وقد تتطلب سيناريوهات رد اتصال PayPal `payer_id` / `PayerID`                         |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/orders/${ORDER_ID}/refresh/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

يعيد النجاح كائن Order الكامل بعد التحديث. استخدم `state` لتحديد النتيجة، واستخدم `finished_at` كوقت الإكمال؛ لا يحتوي النموذج الحالي على حقل `paid_at`. تتضمن قيم الحالة `Pending` و`Paid` و`Finished` و`Expired` و`Failed` و`Refunded`.

سيؤدي الموعد النهائي للدفع فقط إلى تغيير الطلبات التي لا تزال في حالة `Pending` إلى `Expired`. تظل طلبات `Refunded` التي تم رد أموالها بالفعل في حالة رد الأموال حتى بعد التحديث أو تلقي رد اتصال دفع متأخر.

## توصيات إعادة المحاولة

- اعتمد على رد اتصال المنصة للدفع العادي بشكل أساسي؛ ولا تقم بالتحديث الاستباقي إلا عندما لا تتحدث الحالة لفترة طويلة.
- لا تستخدم استعلامًا ثابتًا عالي التردد. يُنصح بالتراجع الأسي، والتوقف بعد الوصول إلى حالة نهائية واضحة.
- يشير `401` إلى أن الرمز غير صالح؛ ويشير `403` إلى أنك لست مالك الطلب؛ ويشير `404` إلى أن الطلب غير موجود.
- عند فشل استعلام خدمة الدفع، احتفظ بمعرّف الطلب ومعرّف التتبع، وأعد المحاولة لاحقًا؛ لا تنشئ طلبات مكررة بدلًا من تأكيد الحالة.
