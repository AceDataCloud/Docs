استعلم عن تفاصيل استدعاءات واجهة برمجة التطبيقات التجارية خلال آخر 60 يومًا للحساب الحالي، وهي مناسبة للتحقق من الرسوم، وتحديد الطلبات الفاشلة، واستكشاف المشكلات حسب الخدمة أو Application أو API أو بيانات الاعتماد.

> ما يتم الاستعلام عنه في هذه الصفحة هو تدفق الاستدعاءات الخاص بالحساب نفسه. إذا كنت تريد فقط عرض إحصاءات الاستدعاءات العامة لواجهة API معينة على المنصة بالكامل، فيرجى استخدام [إحصاءات استدعاءات API](https://platform.acedata.cloud/documents/platform-api-usage).

## نطاق الاحتفاظ بالبيانات

يتم الاحتفاظ بسجلات الاستدعاء وملخصات الفوترة لآخر 60 يومًا؛ ويتم الاحتفاظ بنصوص الطلبات والاستجابات لمدة آخر 30 يومًا. لا يزال بالإمكان الاستعلام في السجلات التي عمرها 30–60 يومًا عن الملخصات مثل trace والحالة والوقت والنموذج والاستخدام والرسوم الفعلية، ولكن `metadata.request` و`metadata.response` في التفاصيل لن تعود. يتم الاحتفاظ بالملخصات المطلوبة لتجميع النموذج وإحصاءات النتائج الفعالة حتى انتهاء صلاحية النصوص. إذا كنت تحتاج إلى الاحتفاظ بالنصوص على المدى الطويل، فيرجى حفظها بنفسك عند الاستدعاء.

## الأعمال التحضيرية

### 1. إنشاء رمز الحساب

تنتمي هذه الواجهة إلى واجهة API لإدارة المنصة، ويجب استخدام **Account Token (رمز الحساب)**:

1. سجّل الدخول إلى [منصة AceDataCloud](https://platform.acedata.cloud).
2. افتح [وحدة تحكم Account Token](https://platform.acedata.cloud/console/platform-tokens).
3. انقر على «إنشاء»، واحفظ الرمز فورًا في مدير كلمات المرور أو Secret Manager.

للاطلاع على التعليمات الكاملة، راجع [إدارة رموز حساب منصة AceDataCloud](https://platform.acedata.cloud/documents/platform-token). يُستخدم رمز الحساب مع `platform.acedata.cloud/api/v1/**`؛ أما استدعاء الواجهات التجارية `api.acedata.cloud/**` فيستخدم بيانات اعتماد API (Credential)، ولا يمكن خلط الاثنين.

```shell
export PLATFORM_TOKEN='رمز حسابك'
```

لا تكتب الرمز في كود الواجهة الأمامية أو السجلات أو المستودعات العامة؛ إذا تم تسريبه، فاحذفه وأعد إنشاؤه فورًا من وحدة التحكم.

### 2. إعداد معرّفات التصفية (اختياري)

يمكنك عرض السجلات التي يحق للحساب الحالي عرضها دون تمرير شروط تصفية. عند الحاجة إلى تضييق النطاق:

- `application_id`: احصل عليه من [قائمة طلبات الخدمة](https://platform.acedata.cloud/documents/platform-application-list)؛
- `credential_id`: احصل عليه من [قائمة بيانات اعتماد API](https://platform.acedata.cloud/documents/platform-credential-list)؛
- `api_id`: احصل عليه من [قائمة API](https://platform.acedata.cloud/documents/platform-api-list)؛
- `service_id`: احصل عليه من [قائمة الخدمات](https://platform.acedata.cloud/documents/platform-service-list).

لا يحتاج المستخدمون العاديون إلى تمرير `user_id`؛ وإذا تم تمريره صراحةً، فيجب أن يتطابق مع الحساب الحالي، وإلا فسيتم إرجاع `403`. يمكن للمسؤولين استخدام هذه المعلمة للتصفية عبر الحسابات.

## نظرة عامة على الواجهة

| العنصر           | المحتوى                                                  |
| --------------- | ------------------------------------------------------- |
| الطريقة          | `GET`                                                   |
| URL             | `https://platform.acedata.cloud/api/v1/usage/apis/`     |
| المصادقة         | `Authorization: Bearer ${PLATFORM_TOKEN}`               |
| OAuth Scope     | `usage:read` (يمكن لـ `platform:read` / `platform` التوسّع ليشمله) |
| الترقيم الصفحي   | `count` + `items`، 10 عناصر لكل صفحة افتراضيًا          |

## نطاق الاستعلام

| `perspective` | المعنى                                            |
| ------------- | ------------------------------------------------- |
| `both`        | القيمة الافتراضية؛ يعيد السجلات التي دفع الحساب الحالي مقابلها أو استدعاها فعليًا |
| `billing`     | يعيد فقط السجلات التي دفع الحساب الحالي مقابلها    |
| `actor`       | يعيد فقط السجلات التي استدعاها الحساب الحالي فعليًا |

## معلمات الاستعلام

| المعلمة             | النوع       | مطلوب | الافتراضي      | الوصف                                      |
| ------------------ | ---------- | ----- | -------------- | ------------------------------------------ |
| `perspective`      | string     | لا    | `both`         | `billing` أو `actor` أو `both`             |
| `user_id`          | UUID       | لا    | —              | تصفية حسب المستخدم للمسؤولين فقط؛ تدعم تكرار المعلمة |
| `service_id`       | UUID       | لا    | —              | تصفية حسب الخدمة؛ تدعم تكرار المعلمة        |
| `application_id`   | UUID       | لا    | —              | تصفية حسب Application؛ تدعم تكرار المعلمة   |
| `api_id`           | UUID       | لا    | —              | تصفية حسب API؛ تدعم تكرار المعلمة           |
| `credential_id`    | UUID       | لا    | —              | تصفية حسب بيانات اعتماد API؛ تدعم تكرار المعلمة |
| `status_code`      | integer    | لا    | —              | تصفية حسب رمز حالة HTTP؛ تدعم التكرار أو القيم المفصولة بفواصل |
| `created_at_from`  | datetime   | لا    | —              | الحد الأدنى لوقت الإنشاء، ISO 8601          |
| `created_at_to`    | datetime   | لا    | —              | الحد الأعلى لوقت الإنشاء، ISO 8601          |
| `limit`            | integer    | لا    | 10             | عدد العناصر في كل صفحة، الحد الأقصى 100     |
| `offset`           | integer    | لا    | 0              | إزاحة الترقيم الصفحي                        |
| `ordering`         | string     | لا    | `-created_at`  | ترتيب تنازلي حسب وقت الإنشاء                |

عندما يكون وقت الطلب أقدم من آخر 60 يومًا، تعيد الواجهة خطأ تحقق من الحقل `400`، موضحةً أن تفاصيل الاستدعاءات الكاملة يتم الاحتفاظ بها لمدة 60 يومًا فقط.

## أمثلة الطلبات

استعلم عن أحدث 100 سجل:

```shell
curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/' \
  --data-urlencode 'perspective=both' \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=-created_at' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

التصفية حسب الوقت وApplication وحالة الفشل:

```shell
export APPLICATION_ID='معرّف Application الخاص بك'

curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'created_at_from=2026-09-01T00:00:00Z' \
  --data-urlencode 'created_at_to=2026-09-02T00:00:00Z' \
  --data-urlencode 'status_code=500' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

مثال على الترقيم الصفحي في Python:

```python
import os
import requests

url = "https://platform.acedata.cloud/api/v1/usage/apis/"
headers = {"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"}
params = {"perspective": "both", "limit": 100, "offset": 0}

response = requests.get(url, headers=headers, params=params, timeout=30)
response.raise_for_status()
data = response.json()

for usage in data["items"]:
    print(usage["created_at"], usage["status_code"], usage["deducted_amount"], usage["trace_id"])

if params["offset"] + len(data["items"]) < data["count"]:
    params["offset"] += len(data["items"])
```

## الحقول الرئيسية

| الحقل                               | الوصف                                  |
| -------------------------------- | ----------------------------------- |
| `user_id`                        | الحساب الذي يتحمل الخصم لهذه المرة                           |
| `actor_user_id`                  | الحساب الذي بدأ الاستدعاء فعليًا؛ قد يختلف عن `user_id` عند تفويض الآخرين لاستخدام بيانات الاعتماد |
| `used_amount`                    | الاستخدام المحسوب لهذه الدعوة وفقًا للقواعد الأصلية                       |
| `original_amount`                | الاستخدام الأصلي قبل تطبيق خصم التطبيق                          |
| `deducted_amount`                | الحصة التي تم خصمها فعليًا بشكل نهائي                           |
| `remaining_amount`               | الحصة المتبقية في Application بعد إتمام الخصم لهذه المرة           |
| `elapsed`                        | مدة الاستدعاء المسجلة من جانب الخادم، بوحدة الثواني                     |
| `trace_id`                       | معرّف التتبع المستخدم عند التحقيق في طلب واحد                      |
| `metadata`                       | بيانات وصفية عامة؛ لا تعرض القائمة محتوى الطلب أو الاستجابة كاملًا               |
| `api` / `service` / `credential` | ملخصات الكائنات المرتبطة لتسهيل العرض؛ قد تكون فارغة إذا لم يعد الكائن المرتبط موجودًا           |

تُحدد وحدة الحصة بواسطة `service.unit` الخاص بـ Application المقابل، ولا ينبغي افتراض أنها دولارات.

## الأخطاء وإعادة المحاولة

| HTTP | `error`                   | المعنى             | طريقة المعالجة                               |
| ---- | ------------------------- | -------------- | ---------------------------------- |
| 400  | خطأ في التحقق من الحقل                    | نطاق الاستعلام أقدم من فترة الاحتفاظ البالغة 60 يومًا | اضبط وقت البدء ليكون ضمن آخر 60 يومًا                  |
| 401  | `not_authenticated`       | رمز الحساب مفقود أو غير صالح      | تحقق من Account Token، ولا تستخدم Credential الخاص بالعمل بالخطأ |
| 403  | `permission_denied`       | يتضمن الطلب سجلات لا تملك صلاحية عرضها    | أزل شروط تصفية المستخدم غير المصرح بها                       |
| 429  | `usage_query_in_progress` | لا يزال الاستعلام المطابق تمامًا قيد التنفيذ    | انتظر `Retry-After` ثم أعد المحاولة بتراجع             |
| 503  | `usage_query_timeout`     | تجاوز الاستعلام المهلة الآمنة من جانب الخادم    | قلّص النطاق الزمني أو أضف شروط تصفية ثم أعد المحاولة                   |

يُحتفظ بطلب واحد قيد التنفيذ كحد أقصى لمجموعة معلمات الاستعلام نفسها. بالنسبة للاستعلامات واسعة النطاق، استخدم أولًا نافذة يوم واحد أو أصغر، ولا تكدّس طلبات متطابقة بفاصل زمني ثابت.
