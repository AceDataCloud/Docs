Python SDK مناسب لخدمات الواجهة الخلفية، ومهام البيانات، ووكيل الأتمتة، ونصوص المعالجة الدفعية. يتولى `acedatacloud` استدعاءات API، بينما يتولى `acedatacloud-x402` إصدار ترويسة الطلب `PAYMENT-SIGNATURE`.

عناوين المصدر والحزم:

- مستودع SDK: [https://github.com/AceDataCloud/SDK](https://github.com/AceDataCloud/SDK)
- مستودع X402 Client: [https://github.com/AceDataCloud/X402Client](https://github.com/AceDataCloud/X402Client)
- PyPI SDK: [https://pypi.org/project/acedatacloud/](https://pypi.org/project/acedatacloud/)
- PyPI X402 Client: [https://pypi.org/project/acedatacloud-x402/](https://pypi.org/project/acedatacloud-x402/)

## تثبيت التبعيات

```bash
pip install acedatacloud acedatacloud-x402
```

إذا كنت تريد استخدام `upto`، تحتاج أيضًا إلى استدعاء Permit2 approve CLI لمرة واحدة، ويعتمد هذا CLI على `web3`:

```bash
pip install 'acedatacloud-x402[cli]'
```

مخرجات فحص التثبيت والاستيراد في Python venv نظيف:

```text
acedatacloud 2026.4.26.1
acedatacloud-x402 2026.5.31.3
imports_ok True True True True True True
usage: acedatacloud-x402 [-h] {approve-permit2} ...
approve-permit2  One-time ERC-20 approve(Permit2, amount) needed before signing upto payments.
```

توضيح النتائج:

- يمكن تثبيت واستيراد كل من `acedatacloud` و`acedatacloud-x402` من PyPI.
- سيضيف `pip install 'acedatacloud-x402[cli]'` واجهة CLI لـ `approve-permit2`، المستخدمة للتفويض المسبق لـ `upto`.

## مثال Base

لا يتطلب المثال التالي API Token. يُستخدم المفتاح الخاص للمحفظة للتوقيع محليًا فقط، ولن يُرسل إلى Ace Data Cloud.

```python
import os

from acedatacloud import AceDataCloud
from acedatacloud_x402 import EVMAccountSigner, create_x402_payment_handler

signer = EVMAccountSigner.from_private_key(os.environ["EVM_PRIVATE_KEY"])

client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
    )
)

res = client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)

print(res["choices"][0]["message"]["content"])
```

يُرجع Python SDK حاليًا `dict`، لذلك يستخدم المثال `res["choices"][0]["message"]["content"]`۔ لا تفترض مباشرةً أنه يمتلك دائمًا الخاصية `.choices`.

## مثال Solana

يستخدم Solana secret key مرمّزًا بـ base58:

```python
import os

from acedatacloud import AceDataCloud
from acedatacloud_x402 import SolanaKeypairSigner, create_x402_payment_handler

client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="solana",
        solana_signer=SolanaKeypairSigner.from_base58(os.environ["SOLANA_SECRET_KEY"]),
    )
)

res = client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)
```

يقوم مسار Solana ببناء وإرسال معاملة SPL USDC `TransferChecked`، ثم يضع توقيع المعاملة داخل envelope لـ `PAYMENT-SIGNATURE`.

أعاد Solana paid retry على Production API بالفعل HTTP 200 و`ADC_SOLANA_E2E_OK`. واجه استعلام RPC العام هذه المرة تحديدًا للمعدل، ولم يتم تأكيد signature على السلسلة بشكل مستقر؛ عند الحاجة إلى المطابقة، يُرجى استخدام Solana RPC الخاص بك للاستعلام عن هذه المعاملة.

## عميل Async

يمكن استخدام payment handler نفسه مع `AsyncAceDataCloud`:

```python
import os

from acedatacloud import AsyncAceDataCloud
from acedatacloud_x402 import EVMAccountSigner, create_x402_payment_handler

signer = EVMAccountSigner.from_private_key(os.environ["EVM_PRIVATE_KEY"])

client = AsyncAceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
    )
)

res = await client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)
```

## استخدام القياس اللاحق `upto`

قد لا تُعرف التكلفة الفعلية لواجهات API مثل إكمالات الدردشة واستدعاءات النماذج إلا بعد انتهاء الاستجابة. في هذه الحالة، قد تُرجع API كلاً من `exact` و`upto`. إذا كنت تريد إعطاء الأولوية لاستخدام `upto`:

```python
client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
        prefer_scheme="upto",
    )
)
```

نتيجة تشغيل برنامج Base `upto`:

```text
payer 0x5d4f08D5c2bb60703284bc06671Eb680fA41B105
elapsed_ms 5104
content ADC_BASE_UPTO_OK
id chatcmpl-DlcbyS4IT8kUAMo4Ri97HiIHc9T8V
settlement tx 0x4b0b836ce1cd1171cdbc37df1637150b024214ec28e7f6f2d09122f15cbfc036
settled value 3 atomic USDC
```

تأكيد على السلسلة:

```text
explorer https://basescan.org/tx/0x4b0b836ce1cd1171cdbc37df1637150b024214ec28e7f6f2d09122f15cbfc036
block 46726437
transfer value 3 atomic USDC
```

توضيح النتائج:

- يشير `content ADC_BASE_UPTO_OK` إلى أن الطلب دخل بالفعل إلى Model API.
- يشير `settled value 3 atomic USDC` إلى أن `upto` يُسوّى وفقًا للاستخدام الفعلي، بدلًا من خصم الحد الكامل.
- يمكن فتح `settlement tx` في BaseScan، واحفظ tx hash وpayer وcompletion id وملخص الطلب عند المطابقة.

يستخدم `upto` تفويض Permit2 لحد أعلى، ولا يمكن أن يتجاوز مبلغ التسوية الفعلي هذا الحد. قبل الاستخدام الأول، يلزم إجراء `approve(Permit2, amount)` واحد لـ USDC على السلسلة المستهدفة.

طريقة CLI:

```bash
X402_PRIVATE_KEY=0x... acedatacloud-x402 approve-permit2 --network base
```

طريقة برمجية:

```python
from acedatacloud_x402 import EVMAccountSigner, approve_permit2

approve_permit2(
    rpc_url="https://mainnet.base.org",
    signer=EVMAccountSigner.from_private_key("0x..."),
    token_address="0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
)
```

هذا الـ helper متكرر بأمان. إذا كان allowance كافيًا بالفعل، فسيُرجع `{"skipped": true}`، ولن يرسل معاملة أخرى على السلسلة.

## التوقيع منخفض المستوى

إذا لم تستخدم SDK، يمكنك أيضًا استدعاء دالة التوقيع منخفضة المستوى مباشرةً:

```python
import base64
import json

from acedatacloud_x402 import EVMAccountSigner, sign_evm_payment

envelope = sign_evm_payment(requirement, EVMAccountSigner.from_private_key("0x..."))
x_payment = base64.b64encode(json.dumps(envelope, separators=(",", ":")).encode()).decode()
```

الدالة منخفضة المستوى مناسبة للاختبارات، وطبقات الوكيل، وتكامل البوابات، أو SDK غير الرسمية. أعطِ الأولوية لاستخدام `create_x402_payment_handler` في كود الأعمال العادي.
