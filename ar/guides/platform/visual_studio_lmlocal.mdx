LMLocal هو امتداد موجه لـ Visual Studio 2022/2026، يدعم رسميًا واجهة برمجة التطبيقات المتوافقة مع OpenAI وURL أساسي مخصص. قد يتغير مدخل التكوين مع إصدار الامتداد؛ عند الاتصال لأول مرة، يرجى تثبيت إصدار ثابت والتحقق من تحرير حقيقي، واستدعاءات الأدوات، وسجلات الاستخدام.

## التكوين

1. قم بتثبيت LMLocal من سوق فيجوال ستوديو أو المستودع الرسمي.
2. أضف مزود Custom/OpenAI-compatible في Providers.
3. املأ Base URL بـ `https://api.acedata.cloud/v1`.
4. املأ Auth Key برمز API الخاص بـ Ace Data Cloud.
5. املأ Model بمعرف النموذج الدقيق المدعوم من Chat Completions في دليل النماذج.
6. بعد الحفظ، أرسل `Reply only OK`، ثم اختبر مرة أخرى عملية تحرير المشروع.

## الحدود الحالية

- تغطي هذه الإرشادات LMLocal فقط، ولا تمثل تكوينات مشتركة مع امتدادات فيجوال ستوديو الأخرى.
- قد تتعامل الإصدارات المختلفة مع طلبات الدردشة، والتحرير، والبناء، والاختبار بشكل منفصل؛ يجب التحقق من كل وضع بشكل مستقل.
- إذا أضاف العميل تلقائيًا `/v1` أو مسار نقطة النهاية، يرجى تجنب تكرار المسار.
