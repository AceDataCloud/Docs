ربما مررت بهذا الموقف أيضًا: تستخدم Claude Code أو Cursor أو Codex، وتكون منسجمًا في كتابة الكود، ثم تحتاج فجأة إلى صورة مرافقة، أو مقطع موسيقي في الخلفية، أو فيديو قصير، أو تريد منه البحث سريعًا عن أحدث المعلومات. ثم تكتشف أن — الوكيل نفسه لا يعرف فعل هذه الأشياء. يتعين عليك أن تبحث بنفسك عن API، وتقرأ الوثائق، وتضبط المفتاح، وتكتب كود الاستدعاء، وتتعامل مع الاستعلام غير المتزامن، وبعد كل هذه المعاناة، يكون الإلهام قد برد منذ زمن.

يأتي [AceKit](https://github.com/AceDataCloud/AceKit) ليوفر عليك هذه المجموعة الكاملة من المعاناة. بأمر واحد، يضع قدرات إنشاء الصور، وإنشاء الفيديوهات، وإنشاء الموسيقى، والبحث على الويب، ومحادثات LLM وغيرها الموجودة على AceData Cloud، كلها داخل وكيل البرمجة الخاص بك. بعد التثبيت، تتحدث مباشرة بلغة طبيعية، وسيقوم الوكيل بنفسه بتحميل المهارة المناسبة، والمصادقة بنفسه، والاستعلام بنفسه، وإنهاء العمل.

## افهم ما الذي يفعله خلال 30 ثانية

قبل التثبيت مقابل بعد التثبيت:

| ما تقوله               | قبل التثبيت                   | بعد التثبيت (الوكيل يفعله بنفسه)                      |
| ------------------ | --------------------- | ----------------------------------- |
| "أضف صورة غلاف إلى README هذا" | الوكيل لا يعرف، ويطلب منك أن تبحث بنفسك عن API لإنشاء الصور | يستدعي NanoBanana / Flux / Midjourney لإنشاء الصورة |
| "حوّل هذا السكربت إلى فيديو قصير مدته 30 ثانية"  | لا يعرف                    | يستدعي Sora / Veo / Kling / Seedance لإنتاج الفيديو  |
| "أضف مقطع موسيقى خلفية لهذا الـ demo"  | لا يعرف                    | يستدعي Suno لإنشاء الموسيقى                           |
| "ابحث عن أحدث X ثم لخّصه"     | لا يمكنه الاتصال بالإنترنت                  | يستدعي Google SERP للحصول على نتائج فورية                 |
| "اختصر هذا الرابط الطويل"         | لا يعرف                    | يستدعي خدمة الروابط القصيرة ويعيد رابط surl.id                  |

باختصار: **يتحول وكيل البرمجة الخاص بك من "لا يعرف سوى كتابة الكود" إلى "يعرف أيضًا إنشاء الصور، وإنشاء الفيديوهات، وإنشاء الموسيقى، والبحث عبر الإنترنت".**

## ابدأ في ثلاث خطوات

يمكن إتمام العملية بالكامل خلال دقائق، وتتطلب Node.js 18+.

**الخطوة الأولى · احصل على API Token.** انسخ Token من [لوحة التحكم](https://platform.acedata.cloud/console/applications) — تستخدم جميع القدرات هذا الرمز الواحد، وتحصل على رصيد مجاني عند أول طلب، ويمكنك التجربة مجانًا أولًا.

![انسخ API Token من لوحة التحكم](https://cdn.acedata.cloud/dvc3cg.jpg)

**الخطوة الثانية · ثبّت.** أمر واحد:

```bash
npx acekit
```

سيكتشف تلقائيًا وكلاء البرمجة على جهازك ويثبت مجموعة المهارات كاملة. هذا ما يبدو عليه التشغيل الفعلي (هذا الجهاز مثبت عليه Claude Code فقط):

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> عند عدم ضبط Token، سيطلب منك التشغيل الأول لصقه بشكل تفاعلي؛ ويمكنك أيضًا تنفيذ `export ACEDATACLOUD_API_TOKEN=你的token` مسبقًا لتحقيق تثبيت كامل دون تدخل. سيتغير عدد المهارات مع زيادة قدرات المنصة، ويُعتد بالقائمة الحالية التي يعرضها `npx acekit list`.

**الخطوة الثالثة · تحدث بلغة طبيعية.** أعد تحميل الوكيل، ثم أعطه تعليمات مباشرة، مثل:

```text
استخدم مهارة short-url لاختصار https://platform.acedata.cloud/services
```

سيقوم الوكيل بنفسه بتحميل المهارة، وبدء الاستدعاء، ومنحك نتيجة حقيقية قابلة للفتح.

## شغّله فعليًا مرة واحدة (مع المخرجات)

الأمثلة الأربعة التالية كلها **استدعاءات حقيقية ونتائج أعيدت في الحال**، وليست توضيحية. يشير `$KEY` في الأوامر إلى API Token الخاص بك.

**① اختصار رابط (متزامن، رد خلال ثوانٍ)**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

يعيد `https://surl.id/r/1uKp2kilXQ` — سيؤدي فتحه إلى إعادة توجيه 302 نحو صفحة services الأصلية.

**② البحث عبر الإنترنت (متزامن)**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

تحصل على نتائج Google فورية (مقتطف):

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ محادثة LLM (متزامنة، واجهة واحدة تتصل بأكثر من 50 نموذجًا)**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP是用于统一管理和交换模型上下文信息的协议。
（39 tokens，本次约 0.00007 credit）
```

**④ إنشاء الصور (غير متزامن، نحو 20 ثانية، يستعلم الوكيل تلقائيًا حتى ظهور الصورة)**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

بعد نحو 22 ثانية، يعيد صورة حقيقية (HTTP 200 · image/png · 317 KB · نحو 0.13 credit لهذه المرة):

![صورة تم إنشاؤها فعليًا بواسطة AceKit](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

في الواقع، لا تحتاج إلى تذكر هذه الواجهات — بعد تثبيت المهارات، سيقوم الوكيل بنفسه، وفقًا لملف `SKILL.md` الخاص بكل منها، بتجميع الطلبات الصحيحة ومعالجة المصادقة والاستعلام. ما سبق مجرد عرض لـ "ما يفعله في الخلفية" أمامك.

## ماذا يثبّت بالضبط

AceKit هو "البوابة الأمامية" لكامل واجهة أدوات المطورين في AceData، ويثبت حاليًا **مجموعة أدوات المهارات (Skills)** دفعة واحدة:

- **مجموعة مهارات Agent**: كل مهارة هي دليل تشغيل مكتوب بصيغة `SKILL.md` — المصادقة، والاستعلام غير المتزامن، وإعادة محاولة الأخطاء، وكيفية تعبئة المعلمات، كلها موضحة بوضوح، ويكفي أن يتبعها الوكيل. شغّل `npx acekit list` لرؤية القائمة الحالية (كانت 19 عند كتابة هذا، وما زالت تزداد باستمرار):
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **Token موحّد واحد**: يفتح `ACEDATACLOUD_API_TOKEN` واحد جميع الإمكانات، مع احتساب الرسوم حسب الاستخدام الفعلي.

مصنّف حسب الإمكانات (وفقًا لـ `npx acekit list`):

| النوع         | المزوّد                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ توليد الصور      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 توليد الفيديو      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 توليد الموسيقى / الصوت | Suno · Producer · Fish Audio（TTS）                    |
| 💬 محادثة LLM   | واجهة موحّدة لأكثر من 50 نموذجًا（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 البحث       | Google SERP（الويب · الصور · الأخبار · الخرائط · الفيديو）                  |
| 🔗 الأدوات       | روابط قصيرة · معالجة الوجوه                                            |

> توفر AceData أيضًا هذه الإمكانات نفسها عبر **خوادم MCP** مستقلة (تم نشر Suno وMidjourney وSora وSERP… على PyPI / VS Code / Smithery / Docker)، و**واجهة سطر أوامر CLI** و**SDK لـ Python / TypeScript**، ويمكن استخدامها بشكل منفصل حسب الحاجة. يخطط AceKit v0.2 لدعم تثبيت إمكانات منفردة عبر `acekit add <name>`، بالإضافة إلى الكتابة التلقائية لإعدادات MCP الخاصة بكل agent.

## ما هي الـ Agents المدعومة

| Agent                        | موقع تثبيت المهارات                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode وغيرها | `~/.agents/skills`（اجعل الـ agent الخاص بك يشير إلى هنا） |

أثناء التثبيت، يكتشف AceKit تلقائيًا الـ agents المثبتة على الجهاز، ويثبّت فقط في تلك التي تم اكتشافها.

## مفاجأة: تشغيل Claude Code نفسه باستخدام الـ Token نفسه

تتوافق واجهة AceData أيضًا مع صيغة Anthropic `/v1/messages`، لذلك **لا تحتاج إلى اشتراك Anthropic رسمي**؛ يمكنك تشغيل Claude Code باستخدام AceData Token نفسه. أنشئ `.claude/settings.local.json` في جذر المشروع:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

أعد تشغيل Claude Code فحسب — سيستخدم بذلك جميع نماذج Claude، وسيحصل أيضًا عبر AceKit على "أيدٍ" لتوليد الصور والفيديو والموسيقى. لمزيد من التفاصيل، راجع [دليل تكامل Claude Code](https://platform.acedata.cloud/documents/claude-code-integration).
