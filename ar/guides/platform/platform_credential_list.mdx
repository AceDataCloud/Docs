اعرض بيانات اعتماد واجهة برمجة تطبيقات الأعمال على صفحات. تتضمن هذه الاستجابة حاليًا حقولًا حساسة لبيانات اعتماد Token أو Identity، ويجب معالجتها على الخادم فقط، ويُمنع كتابتها في السجلات أو منصات التحليلات أو التخزين الدائم للواجهة الأمامية أو المستودعات العامة.

## الأعمال التحضيرية

أنشئ [Account Token](https://platform.acedata.cloud/documents/platform-token)، واحصل على UUID للحساب الحالي عبر `GET /api/v1/platform-tokens/me/`.

```shell
export PLATFORM_TOKEN='رمز حسابك'
export USER_ID='UUID حسابك'
```

## نظرة عامة على الواجهة

| البند   | المحتوى                                                   |
| --- | ---------------------------------------------------- |
| الطريقة  | `GET`                                                |
| URL | `https://platform.acedata.cloud/api/v1/credentials/` |
| المصادقة  | Account Token، ويتطلب OAuth token صلاحية `credentials:read`       |
| التصفح على صفحات  | `count` + `items`                                    |

ينبغي للمستخدمين العاديين تمرير `user_id` الخاص بهم أو `application_id` مصرح به، وإلا فقد يتم إرجاع `403` عند مواجهة كائنات غير مصرح بها أثناء التصفح على صفحات.

## معلمات الاستعلام

| المعلمة                 | النوع      | مطلوبة  | الوصف                             |
| ------------------ | ------- | --- | ------------------------------ |
| `user_id`          | string  | حسب السيناريو | حامل بيانات الاعتماد؛ يدعم المعلمات المكررة                   |
| `application_id`   | UUID    | لا   | التصفية حسب Application؛ يدعم المعلمات المكررة        |
| `host`             | string  | لا   | التصفية الدقيقة حسب host؛ يدعم المعلمات المكررة             |
| `name`             | string  | لا   | التصفية الدقيقة حسب الاسم؛ يدعم المعلمات المكررة                 |
| `granted`          | boolean | لا   | `true` لبيانات الاعتماد الممنوحة للآخرين، و`false` لبيانات الاعتماد للاستخدام الشخصي |
| `limit` / `offset` | integer | لا   | التصفح على صفحات                             |
| `ordering`         | string  | لا   | `created_at` أو `-created_at`   |

لا تُعد `service_id` و`disabled` و`expired` حاليًا معلمات تصفية.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/credentials/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## وصف الاستجابة

الاستجابة التي تم التحقق منها على الإنترنت هي `{count, items}`. تتضمن كل خانة `id` و`application_id` و`application` و`user_id` و`creator_id` و`name` و`type` و`limited_amount` و`used_amount` و`expired_at` و`allowed_api_ids` و`host` و`granted` و`granted_to_user_id` و`tags` و`metadata` وحقول الوقت، وتُرجع `token` أو `username/password` حسب النوع.

> تُرجع استجابة القائمة الحالية القيم الحساسة الكاملة. لا تعرضها في وحدة تحكم المتصفح أو أنظمة التجميع، ولا تعتمد على استعادة النص الصريح عبر القائمة؛ يجب أن يكون العميل متوافقًا مع سياسة الإخفاء المستقبلية.
