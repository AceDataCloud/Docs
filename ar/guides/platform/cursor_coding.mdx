تقدم Cursor حاليًا مفتاح API من OpenAI وإعداد **Override OpenAI Base URL**، مما يتيح الاتصال بخدمات متوافقة مع OpenAI. هذه القدرة موجودة، لكن المعالجة بين الإصدارات المختلفة لـ `/chat/completions` و`/responses`، وقائمة النماذج، وأنماط Agent/Composer ليست متسقة تمامًا.

قد يختلف نطاق التوافق بين إصدارات Cursor المختلفة، وأنظمة التشغيل، وأنماط الطلبات. يرجى اتباع تكوين هذه الصفحة لإكمال فحص الأنماط الفعلي، ولا تستنتج أن جميع الميزات متاحة بناءً على نجاح محادثة واحدة.

## ما الذي تضمنه Cursor رسميًا BYOK حاليًا

وفقًا لوثيقة [Cursor الرسمية حول إحضار مفتاح API الخاص بك](https://cursor.com/help/models-and-usage/api-keys):

- دعم بيانات اعتماد OpenAI وAnthropic وGoogle وAzure OpenAI وAWS Bedrock؛
- مفتاح API مخصص يُستخدم فقط لنماذج الدردشة، بينما تستمر إكمالات التبويب في استخدام نماذج Cursor المدمجة؛
- لا يتم تخزين مفتاح API بشكل دائم على خوادم Cursor، ولكن يتم إرسال المفتاح إلى خلفية Cursor مع كل طلب، لاستخدامه في بناء prompt النهائي؛
- عند استخدام مفتاح خاص، لا تنطبق سياسة الاحتفاظ بالبيانات صفرية على Cursor، وتخضع معالجة البيانات لسياسة المزود المختار.

## التكوين

1. افتح إعدادات Cursor → النماذج.
2. في مفتاح API من OpenAI، أدخل رمز API الخاص بـ Ace Data Cloud.
3. قم بتمكين **Override OpenAI Base URL**، وأدخل `https://api.acedata.cloud/v1`.
4. اختر أو أضف معرف النموذج الدقيق المتوافق مع بروتوكول Cursor الحالي.
5. أرسل أولاً `Reply only OK`، ثم اختبر أنماط Ask/Edit/Agent التي تستخدمها فعليًا.

## الحدود الحالية

- مفتاح API مخصص يُستخدم فقط لنماذج الدردشة، بينما تستمر إكمالات التبويب في استخدام نماذج Cursor المدمجة.
- قد تكمل Cursor أيضًا بناء prompt النهائي على الخادم؛ يرجى تقييم مسار البيانات بناءً على بيان الخصوصية الرسمي.
- قد يغطي Override Base URL بعض الطلبات فقط، أو يتغير بسبب تغييرات الإصدار بين Chat Completions/Responses.
- لا ينبغي أن يُعلن عن اتصال Agent أو Auto أو Composer أو المهام الخلفية بناءً على نجاح طلب محادثة واحدة فقط.

## الخيارات المتاحة حاليًا

عند استخدام خطة الترميز، اختر أولاً العملاء الذين لديهم عقود تكوين واضحة وبوابات تحقق:

- [نظرة عامة على تكوين Claude Code](https://platform.acedata.cloud/documents/claude-code-integration)
- [نظرة عامة على تكوين Codex](https://platform.acedata.cloud/documents/codex-integration)
- [تكوين WorkBuddy](https://platform.acedata.cloud/documents/development_workbuddy)

## فحص التوافق الكامل

إذا كنت ترغب في الاستخدام طويل الأمد في سير العمل الإنتاجي، يرجى إكمال الفحوصات التالية:

1. تثبيت إصدار Cursor ونظام التشغيل؛
2. إكمال اختبار smoke للعميل الحقيقي لهذا الإصدار، وتوثيق بروتوكول الطلب النهائي والمسار؛
3. نجاح طلب Chat Completions للنموذج الدقيق؛
4. التأكد من أن استدعاءات الأدوات وطلبات Agent تمر عبر نقطة النهاية المستهدفة؛
5. يمكن التحقق من الاستخدام والتكاليف؛
6. توثيق واضح ما إذا كانت الطلبات قد مرت عبر خادم Cursor والقيود المتعلقة بالخصوصية.

يجب إعادة تنفيذ هذه الفحوصات بعد ترقية العميل، للتأكد من عدم تغيير بروتوكول الطلب، واستدعاءات الأدوات، ومسار البيانات.
