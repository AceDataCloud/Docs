نزّل تفاصيل استدعاءات API للحساب الحالي مباشرةً بصيغة CSV، وهي مناسبة للمطابقة المالية أو التحليل دون اتصال أو حفظ كميات كبيرة من السجلات. إذا كنت تحتاج فقط إلى عرض عدد قليل من التفاصيل في الصفحة، فاستخدم أولاً [قائمة سجلات الاستدعاء](https://platform.acedata.cloud/documents/platform-usage-list).

نطاق الاستعلام لسجلات الاستدعاء وملخصات الفوترة هو آخر 60 يومًا؛ بينما يُحتفظ بنصوص الطلبات والاستجابات بشكل منفصل لآخر 30 يومًا. انتهاء صلاحية النصوص لا يغيّر الخصم الفعلي أو الاستخدام أو الإحصاءات المجمّعة لهذا السجل.

## التحضيرات

1. سجّل الدخول إلى [منصة AceDataCloud](https://platform.acedata.cloud).
2. أنشئ رمز حساب في [وحدة تحكم Account Token](https://platform.acedata.cloud/console/platform-tokens)، واحفظه فورًا في مدير كلمات المرور أو Secret Manager.
3. احصل عند الحاجة على معرّفات التصفية من [قائمة طلبات الخدمة](https://platform.acedata.cloud/documents/platform-application-list)، أو [قائمة بيانات اعتماد API](https://platform.acedata.cloud/documents/platform-credential-list)، أو [قائمة API](https://platform.acedata.cloud/documents/platform-api-list).

راجع [إدارة رموز الحساب](https://platform.acedata.cloud/documents/platform-token) للحصول على شرح كامل للرموز. لا يمكن استخدام رمز الحساب وCredential الخاص باستدعاء API للأعمال بالتبادل.

```shell
export PLATFORM_TOKEN='رمز حسابك'
```

## نظرة عامة على الواجهة

| البند           | المحتوى                                                   |
| -------------- | --------------------------------------------------------- |
| الطريقة         | `GET`                                                     |
| URL            | `https://platform.acedata.cloud/api/v1/usage/apis/export/` |
| المصادقة        | `Authorization: Bearer ${PLATFORM_TOKEN}`                 |
| OAuth Scope    | `usage:read` (يتضمنه `platform:read` / `platform` توسيعيًا) |
| الاستجابة       | `200 text/csv; charset=utf-8`                             |
| اسم الملف       | `usages.csv`                                              |

تُرجع هذه الواجهة CSV بشكل متدفق ومتزامن، ولا تنشئ مهمة تصدير، ولا تُرجع JSON أو رابط تنزيل. فقط عندما لا يتم توفير وقت البداية والنهاية معًا، يتم افتراضيًا تصدير السجلات من بداية الشهر التقويمي الحالي حتى الوقت الحالي؛ وعند توفير حد واحد فقط، لن يُستكمل الحد الآخر تلقائيًا بحدود هذا الشهر.

## معاملات الاستعلام

| المعامل              | النوع     | مطلوب | الافتراضي | الوصف                                      |
| ------------------- | -------- | ----- | --------- | ------------------------------------------ |
| `perspective`       | string   | لا    | `both`    | `billing` أو `actor` أو `both`             |
| `service_id`        | UUID     | لا    | —         | التصفية حسب الخدمة؛ يدعم المعاملات المتكررة |
| `application_id`   | UUID     | لا    | —         | التصفية حسب Application؛ يدعم المعاملات المتكررة |
| `api_id`            | UUID     | لا    | —         | التصفية حسب API؛ يدعم المعاملات المتكررة    |
| `credential_id`    | UUID     | لا    | —         | التصفية حسب بيانات اعتماد API؛ يدعم المعاملات المتكررة |
| `status_code`       | integer  | لا    | —         | يدعم القيم المتكررة أو المفصولة بفواصل      |
| `created_at_from`  | datetime | لا    | —         | وقت البداية بصيغة ISO 8601                 |
| `created_at_to`    | datetime | لا    | —         | وقت النهاية بصيغة ISO 8601                 |

يقتصر نطاق التصدير دائمًا على السجلات المرئية للحساب الحالي باعتباره جهة الدفع و/أو المستدعي الفعلي، ولا يدعم التصدير عبر الحسابات.

## أمثلة الطلبات

احفظ CSV للشهر الحالي مباشرةً:

```shell
curl --fail-with-body --location \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

التصدير حسب Application والوقت ورمز الحالة:

```shell
export APPLICATION_ID='معرّف Application الخاص بك'

curl --fail-with-body --get \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'status_code=200,500' \
  --data-urlencode 'created_at_from=2026-09-01T00:00:00Z' \
  --data-urlencode 'created_at_to=2026-09-08T00:00:00Z' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

الحفظ المتدفق في Python والتحقق من الاكتمال:

```python
import os
from pathlib import Path

import requests

url = "https://platform.acedata.cloud/api/v1/usage/apis/export/"
headers = {"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"}
params = {
    "created_at_from": "2026-09-01T00:00:00Z",
    "created_at_to": "2026-09-08T00:00:00Z",
    "perspective": "both",
}
output = Path("usages.csv")

with requests.get(url, headers=headers, params=params, stream=True, timeout=120) as response:
    response.raise_for_status()
    if not response.headers.get("content-type", "").startswith("text/csv"):
        raise RuntimeError("لم يُرجع الخادم CSV")
    with output.open("wb") as file:
        for chunk in response.iter_content(chunk_size=64 * 1024):
            file.write(chunk)

last_line = output.read_text(encoding="utf-8").splitlines()[-1]
if last_line.startswith("# truncated:") or last_line.startswith("# error:"):
    raise RuntimeError(f"التصدير غير مكتمل: {last_line}")
```

## أعمدة CSV

ترتيب رأس CSV ثابت كما يلي:

```text
Usage ID,API,Status Code,Deducted Amount,Original Amount,Trace ID,Created At
```

| العمود              | الوصف                                            |
| ------------------ | ----------------------------------------------- |
| `Usage ID`         | معرّف سجل الاستدعاء                              |
| `API`              | عنوان API؛ وقد يكون معرّف API أو قيمة فارغة عند تعذر المطابقة |
| `Status Code`      | رمز حالة HTTP                                   |
| `Deducted Amount`  | الرصيد المخصوم فعليًا بشكل نهائي                 |
| `Original Amount`  | الرصيد الأصلي قبل خصم التطبيق                    |
| `Trace ID`         | معرّف تتبع الطلب                                 |
| `Created At`       | وقت إنشاء السجل، بصيغة ISO 8601                 |

تُحدَّد وحدة الرصيد بواسطة `service.unit` الخاص بـ Application المقابل.

## تحديد ما إذا كان التصدير مكتملًا

يتم إخراج ما يصل إلى 1,000,000 سجل في المرة الواحدة. بعد أن يبدأ الخادم في إرجاع CSV، لا يمكنه تغيير الخطأ أثناء العملية إلى حالة HTTP أخرى، لذا يجب على العميل التحقق من السطر الأخير:

- `# truncated:`: تم الوصول إلى حد عدد الصفوف؛ صدّر على دفعات باستخدام نوافذ زمنية أصغر.
- `# error:`: انقطعت القراءة المتدفقة؛ أعد التصدير بعد تقليص النطاق.

يجب على برنامج المطابقة اعتبار الملف غير مكتمل عند رؤية أي marker، ولا يجوز تسجيله بصمت.

## الأخطاء وإعادة المحاولة

| الحالة                         | طريقة المعالجة                                              |
| ----------------------------- | ----------------------------------------------------------- |
| `400 usage_history_expired`   | استخدم `available_from` في الاستجابة للضبط ضمن نطاق آخر 60 يومًا |
| `401 not_authenticated`       | تحقق من وجود Account Token وصحته وعدم حذفه                  |
| استجابة ليست CSV               | لا تحفظها كملف ناجح؛ اقرأ استجابة الخطأ أولًا وصحح الطلب    |
| انقطاع التنزيل أو marker       | قلّص النافذة الزمنية، واستخدم استراتيجية تراجع لإعادة التصدير |
