الحصول على المعلومات الكاملة لخدمة واحدة عبر معرّف الخدمة (UUID) أو الاسم المستعار (alias) — الحقول المعادة أشمل من [الحصول على قائمة خدمات منصة AceDataCloud](https://platform.acedata.cloud/documents/platform-service-list)، وسيتم توسيع الكائنات المرتبطة مثل `apis` و`proxies` و`datasets` و`packages` إضافيًا. مناسب لسيناريوهات مثل صفحة تفاصيل الخدمة، وصفحة مقارنة الأسعار، ووصف أدوات Agent.

> ℹ️ تنتمي هذه الواجهة إلى **واجهة برمجة تطبيقات إدارة منصة AceDataCloud**، والبادئة الموحدة هي `https://platform.acedata.cloud/api/v1/`۔ للاطلاع على فهرس الواجهات الكامل، راجع [الحصول على قائمة وثائق منصة AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list).

## نظرة عامة على الواجهة

| العنصر   | المحتوى                                                            |
| --- | ------------------------------------------------------------- |
| الطريقة  | `GET`                                                         |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}` |
| المصادقة  | ❌ عامة                                                          |

كل من `/services/{id}` و`/services/{id}/` متاحان حاليًا؛ تستخدم الأمثلة بشكل موحد الصيغة دون الشرطة المائلة الختامية.

## توضيح المصادقة

هذه الواجهة عامة بالكامل. **لكن بعد إرفاق رمز الحساب، سيعكس الحقل `applied` في الاستجابة حالة التقديم الفعلية للحساب الحالي**، وإلا فسيكون دائمًا `false`.

للحصول على رمز الحساب، راجع [إدارة رموز حساب منصة AceDataCloud](https://platform.acedata.cloud/documents/platform-token).

## معاملات المسار

| المعامل           | النوع            | مطلوب  | الوصف                                                    |
| ------------ | ------------- | --- | ----------------------------------------------------- |
| `service_id` | UUID / string | ✅   | معرّف الخدمة (UUID) أو الاسم المستعار (`midjourney` أو `openai` أو `webextrator` وغيرها) |

## أمثلة الطلبات

### cURL

```shell
# 按 UUID 查询
curl 'https://platform.acedata.cloud/api/v1/services/8efa1d83-9b75-4562-b44a-af95ce563d05' \
  -H 'accept: application/json'

# 按 alias 查询
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json'

# 带账户令牌看 applied 状态
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

resp = requests.get(
    "https://platform.acedata.cloud/api/v1/services/midjourney",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
svc = resp.json()
print(f"服务: {svc['title']} ({svc['alias']})")
print(f"已申请: {svc['applied']}, 免费额度: {svc['free_amount']} {svc['unit']}")
print(f"API 数: {len(svc['apis'])}, 套餐数: {len(svc['packages'])}")
for pkg in svc["packages"]:
    print(f"  ¥{pkg['price']:>7.2f}  ->  {pkg['amount']} {svc['unit']}")
```

### Node.js

```javascript
const r = await fetch('https://platform.acedata.cloud/api/v1/services/midjourney', {
  headers: { accept: 'application/json' },
})
const svc = await r.json()
console.log(`${svc.title} - 套餐 ${svc.packages.length} 个 - API ${svc.apis.length} 个`)
```

## توضيح حقول الاستجابة

تقوم واجهة التفاصيل، بالإضافة إلى جميع حقول [واجهة القائمة](https://platform.acedata.cloud/documents/platform-service-list)، بتوسيع ما يلي إضافيًا:

| الحقل         | النوع    | الوصف                                                            |
| ---------- | ----- | ------------------------------------------------------------- |
| `apis`     | array | القائمة الكاملة لكائنات API المرتبطة (تحتوي كل منها على `id` و`name` و`title` و`path` و`stage` و`cost`) |
| `proxies`  | array | القائمة الكاملة لكائنات Proxy المرتبطة                                              |
| `datasets` | array | مجموعات البيانات المرتبطة (إذا كان `type=Dataset`)                                      |
| `packages` | array | قائمة الباقات، تتضمن `type` (`Usage`/`Period`) و`price` و`amount` و`duration`   |

للاطلاع على تعريفات الحقول الأخرى، راجع [الحصول على قائمة خدمات منصة AceDataCloud → توضيح حقول الاستجابة](https://platform.acedata.cloud/documents/platform-service-list).

## معالجة الأخطاء

| HTTP | code        | المعنى                            |
| ---- | ----------- | ----------------------------- |
| 404  | `not_found` | `service_id` (UUID أو alias) غير موجود |
| 500  | —           | يكون السبب عادةً إضافة شرطة مائلة بالخطأ في نهاية URL؛ أزلها ثم أعد المحاولة          |

## نصائح عملية

- **`alias` > `UUID`**: يكون تضمين `alias` (مثل `midjourney`) بشكل ثابت في الكود أكثر استقرارًا؛ إذ قد يتغير UUID عند ترحيل البيئة.
- **لا يتضمن الحقل `apis` تعريف OpenAPI**: يوجد مخطط OpenAPI 3.0 الكامل في واجهة [الحصول على تفاصيل API لمنصة AceDataCloud](https://platform.acedata.cloud/documents/platform-api-detail).
- **جلب "القدرات الكاملة" لخدمة**: استخدم هذه الواجهة للحصول على `api_ids`، ثم استدعِ `/apis/{api_id}` واحدًا تلو الآخر لجلب التفاصيل.
- **إذا كان `applied=true`**، يمكنك مباشرةً [إنشاء بيانات اعتماد API](https://platform.acedata.cloud/documents/platform-credential-create) للحصول على رمز Token المكوّن من 32 خانة المطلوب لاستدعاء واجهات الأعمال، دون الحاجة إلى تقديم طلب مرة أخرى.
