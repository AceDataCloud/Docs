---
title: "OpenCode IDE Extension 接入 Ace Data Cloud"
description: "Platform API guide - Ace Data Cloud"

يدعم OpenCode IDE Extension الرسمي محررات مثل VS Code وCursor وWindsurf وVSCodium، ويعيد استخدام وقت التشغيل المحلي لـ OpenCode وتكوين Provider. يعيد IDE Extension استخدام CLI Provider المحلي، لكن سلسلة الطلبات قد تختلف بين إصدارات المحرر المختلفة؛ عند الاتصال لأول مرة، يرجى تثبيت إصدار ثابت وإكمال الحد الأدنى من التحقق.

## تكوين Provider

أولاً، اتبع [تكوين OpenCode Terminal](https://platform.acedata.cloud/documents/opencode-terminal-integration) لتكوين Ace Data Cloud Provider في `opencode.json` أو `opencode.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## تثبيت IDE Extension

1. قم بتشغيل `opencode` في الطرفية المدمجة بالمحرر، واتبع العملية الرسمية لتثبيت Extension تلقائيًا؛ يمكنك أيضًا تثبيته يدويًا من Marketplace المعني.
2. أعد تحميل المحرر.
3. ابدأ `Reply only OK` من OpenCode Extension.
4. نفذ مرة أخرى الطلب الذي يحتاج إلى قراءة ملف أو تعديل كود، تأكد من أن IDE Extension يستخدم نفس Provider والنموذج.

## الحدود الحالية

- تأتي قدرات Provider من وقت تشغيل OpenCode، ولا تمثل دعم المحرر الأصلي لـ Ace Data Cloud.
- قد تختلف إصدارات VS Code والإصدارات المشتقة، يجب تسجيل الإصدارات بشكل منفصل.
- نجاح الدردشة العادية لا يمكن أن يحل محل التحقق من قراءة الملفات وتحريرها واستدعاء الأدوات.
