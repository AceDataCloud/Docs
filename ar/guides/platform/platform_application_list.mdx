إرجاع Application التي يملكها الحساب أو المصرح له باستخدامها على شكل صفحات، بما في ذلك الرصيد والحالة وملخص الخدمة وبيانات الاعتماد المرتبطة. مناسب لمراقبة الأرصدة بالجملة، والعثور على Application ID، والدخول إلى إدارة بيانات الاعتماد.

## الأعمال التحضيرية

1. سجّل الدخول إلى [منصة AceDataCloud](https://platform.acedata.cloud).
2. أنشئ رمز حساب في [وحدة تحكم Account Token](https://platform.acedata.cloud/console/platform-tokens).
3. يستخدم المستخدمون العاديون `user_id=me`؛ ويمكن أيضًا الحصول على UUID الخاص بهم من `GET /api/v1/platform-tokens/me/`.

```shell
export PLATFORM_TOKEN='رمز حسابك'
```

## نظرة عامة على الواجهة

| البند   | المحتوى                                                    |
| --- | ----------------------------------------------------- |
| الطريقة  | `GET`                                                 |
| URL | `https://platform.acedata.cloud/api/v1/applications/` |
| المصادقة  | Account Token، يتطلب OAuth token صلاحية `applications:read`       |
| الترقيم  | `count` + `items`                                     |

يجب على المستخدمين العاديين تمرير `user_id=me`. عند عدم تمريره، لا يتم تضييق الاستعلام حسب الحساب أولًا، وقد تُرجع الصفحات `403` عند مواجهة كائنات غير مصرح بها؛ وعند عدم تمريره من قبل المسؤولين يمكنهم عرض الجدول بالكامل.

## معلمات الاستعلام

| المعلمة            | النوع          | مطلوبة     | الوصف                                                  |
| ------------- | ----------- | ------ | --------------------------------------------------- |
| `user_id`     | UUID / `me` | مطلوبة للمستخدمين العاديين | موضوع الاستعلام؛ يدعم المعلمات المتكررة                                         |
| `affiliation` | string      | لا      | `owner` (افتراضي) أو `granted`؛ يمكن تمرير كليهما بشكل متكرر لأخذ الاتحاد، ولا يسري إلا عند وجود `user_id` |
| `service_id`  | UUID        | لا      | التصفية حسب الخدمة؛ يدعم المعلمات المتكررة                                        |
| `scope`       | string      | لا      | `Individual` أو `Global`؛ يدعم المعلمات المتكررة                      |
| `type`        | string      | لا      | `Usage` أو `Period`؛ يدعم المعلمات المتكررة                           |
| `limit`       | integer     | لا      | عدد العناصر في كل صفحة، بحد أقصى 100                                         |
| `offset`      | integer     | لا      | إزاحة الترقيم                                               |
| `ordering`    | string      | لا      | يدعم فقط `created_at` أو `-created_at`                    |

لا تُعد `paid` و`disabled` و`expired` و`low_balance` و`tag` حاليًا معلمات تصفية من جانب الخادم. ينبغي جلب القائمة أولًا لتنبيهات الرصيد، ثم الحكم من جانب العميل وفقًا لـ `remaining_amount` و`service.unit` والحدود التجارية لكل Application.

## مثال على الطلب

```shell
curl --get 'https://platform.acedata.cloud/api/v1/applications/' \
  --data-urlencode 'user_id=me' \
  --data-urlencode 'affiliation=owner' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

عرض Application التي تملكها وتلك التي منحها الآخرون لك في الوقت نفسه:

```shell
curl --get 'https://platform.acedata.cloud/api/v1/applications/' \
  --data-urlencode 'user_id=me' \
  --data-urlencode 'affiliation=owner' \
  --data-urlencode 'affiliation=granted' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## وصف الاستجابة

الاستجابة هي `{count, items}`. تحتوي كل خانة على حقول نموذج Application، بالإضافة إلى:

- `service`: `id` و`alias` و`title` و`type` و`unit` و`icon_url`؛
- `credentials`: ملخص بيانات الاعتماد التي يحق للمتصل الحالي رؤيتها؛
- `paid` و`remaining_amount` و`used_amount` و`disabled` و`allow_consume_global` و`allow_overdraft`؛
- القيمة الفعلية لـ `scope` هي `Individual` أو `Global`؛
- القيمة الفعلية لـ `type` هي `Usage` أو `Period`.

`allow_overdraft` هو حقل منطقي للقراءة فقط يتحكم فيه المسؤول، وقيمته الافتراضية `false`. بالنسبة للتطبيقات حسب الاستخدام (`Usage`) التي تم تمكين السحب على المكشوف لها، فإن الرصيد غير الكافي لا يمنع الاستدعاء، ولا يزال يتم الخصم وفقًا للاستخدام الفعلي؛ ويشير الرصيد السلبي إلى حصة بانتظار التسوية. يظل التعطيل والانتهاء وحدود بيانات اعتماد API سارية.

قد تكون `remaining_amount` فارغة؛ يجب على العميل التحقق من أنها ليست فارغة أولًا قبل إجراء المقارنات الرقمية. تحدد `service.unit` وحدة الحصة.
