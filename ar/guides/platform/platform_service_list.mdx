إرجاع دليل `Service` المرئي للموقع الحالي على شكل صفحات، بما في ذلك نوع الخدمة، ومعلومات العرض، والحصة المجانية، والباقات، ومعرّفات API/Proxy المرتبطة. مناسب لبناء سوق خدمات أو اختيار الخدمات المطلوب التقدم بطلب للحصول عليها.

## نظرة عامة على الواجهة

| البند   | المحتوى                                                |
| --- | ------------------------------------------------- |
| الطريقة  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| المصادقة  | عام؛ عند وجود حالة تسجيل دخول فقط يعكس `applied` الحساب الحالي                        |
| الترقيم  | `count` + `items`                                 |

## معلمات الاستعلام

| المعلمة               | النوع      | مطلوب  | الوصف                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | لا   | التصفية حسب معرّف الخدمة؛ تدعم المعلمات المتكررة         |
| `private`        | boolean | لا   | التصفية حسب حالة الإتاحة العامة؛ تظل قواعد رؤية الموقع سارية      |
| `type`           | string  | لا   | نوع الخدمة؛ تدعم المعلمات المتكررة              |
| `tag`            | string  | لا   | التصفية حسب الوسم                    |
| `include_facets` | boolean | لا   | عند `true` تُضاف إحصاءات النوع/الوسم المتاحة للموقع الحالي |
| `limit`          | integer | لا   | عدد العناصر في كل صفحة، بحد أقصى 100              |
| `offset`         | integer | لا   | إزاحة الترقيم                    |
| `ordering`       | string  | لا   | يدعم فقط `rank` أو `-rank`     |

لا تدعم القائمة التصفية بـ `alias`؛ عند وجود alias، اطلب مباشرةً `/api/v1/services/{alias}`. الحقلان `applied_count` و`updated_at` ليسا حقلي ترتيب مسموحًا بهما.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## وصف الاستجابة

تكون الاستجابة بالشكل `{count, items}`؛ ولا تتم إضافة `facets` إلا عند `include_facets=true`. تتضمن عناصر الخدمة الحقول العامة الحالية مثل `id` و`alias` و`title` و`description` و`type` و`applied_count` و`free_amount` و`unit` و`private` و`need_verify` و`rank` و`tags` و`thumbnail` و`doc_url` و`demo_url` و`api_ids` و`proxy_ids` و`cost` و`packages` وغيرها.

لا تمثل `applied` في القائمة المجهولة حالة طلب حساب معيّن. عند الحاجة إلى حالة مرتبطة بالحساب، يجب إرفاق حالة تسجيل دخول صالحة، واعتماد [قائمة طلبات الخدمة](https://platform.acedata.cloud/documents/platform-application-list) كمرجع نهائي.
