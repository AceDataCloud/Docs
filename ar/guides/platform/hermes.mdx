title: "دليل تكامل وكيل هيرميس"
description: "Platform API guide - Ace Data Cloud"
---

يتكامل وكيل هيرميس مع سحابة بيانات آيس من خلال بروتوكول إكمالات دردشة OpenAI. اختر أي طريقة تكوين:

| طريقة التكوين                | الدليل                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| دليل التفاعل `hermes model` | [تكوين الدليل](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| التكوين اليدوي `config.yaml`  | [التكوين اليدوي](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| النشر الخاص بالمنصة              | [النشر المدارة](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

المعلمات المشتركة للتكامل المحلي:

- عنوان URL الأساسي: `https://api.acedata.cloud/v1`
- النقل: `chat_completions`
- المزود: `custom:acedatacloud`
- مفتاح API: احصل عليه من [قائمة التطبيقات](https://platform.acedata.cloud/console/applications)

تكتب الطريقتان المحليتان في النهاية في `~/.hermes/config.yaml`، لا تقم بتكرار التكوين.

ارجع إلى [مركز تكوين خطة البرمجة](https://platform.acedata.cloud/documents/coding-plan-integration).
