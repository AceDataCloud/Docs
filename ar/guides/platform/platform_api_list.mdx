يعيد بشكل مقسم إلى صفحات نقاط نهاية API المرئية في الموقع الحالي. مناسب للعثور على واجهات API حسب مسار العمل أو الخدمة أو مرحلة الإصدار؛ إذا كنت تحتاج فقط إلى التعريف الكامل لواجهة API واحدة، فيرجى استدعاء [تفاصيل API](https://platform.acedata.cloud/documents/platform-api-detail) مباشرةً.

## نظرة عامة على الواجهة

| العنصر   | المحتوى                                            |
| --- | --------------------------------------------- |
| الطريقة  | `GET`                                         |
| URL | `https://platform.acedata.cloud/api/v1/apis/` |
| المصادقة  | عامة، لا تتطلب رمز حساب                                     |
| التقسيم إلى صفحات  | `count` + `items`                             |

## معلمات الاستعلام

| المعلمة        | النوع      | مطلوبة  | الوصف                    |
| --------- | ------- | --- | --------------------- |
| `path`    | string  | لا   | مطابقة تامة لـ `path` أو `path2` |
| `service` | string  | لا   | الاسم المستعار للخدمة أو UUID       |
| `stage`   | string  | لا   | التصفية حسب مرحلة الإصدار؛ يمكن تمرير قيم متعددة بشكل متكرر      |
| `limit`   | integer | لا   | عدد العناصر في كل صفحة، الحد الأقصى 100           |
| `offset`  | integer | لا   | إزاحة التقسيم إلى صفحات                 |

لا تُعد `id` و`service_id` و`tag` حاليًا معلمات تصفية للقائمة؛ ولن يؤدي تمريرها إلى تأثير التصفية المقابل.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/apis/' \
  --data-urlencode 'service=midjourney' \
  --data-urlencode 'stage=Production' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/apis/",
    params={"service": "midjourney", "limit": 20},
    timeout=30,
)
response.raise_for_status()
for api in response.json()["items"]:
    print(api["id"], api["method"], api["path"])
```

## وصف الاستجابة

تستخدم الاستجابة الفعلية `{count, items}`. يتضمن كل عنصر في القائمة حاليًا حقول نموذج API، بالإضافة إلى:

- `document_id`: معرّف وثيقة المطور المرتبطة، وقد يكون فارغًا؛
- `service_id` / `service`: معرّف الخدمة الرئيسية وملخصها، وقد يكونان فارغين؛
- `definition`: تعريف OpenAPI، وقد يكون كبيرًا؛
- `method` و`path` و`path2` و`stage` و`cost` و`tags` و`metadata` وغيرها.

يتضمن serializer الخاص بالقائمة حاليًا `definition`، ويجب استخدام التقسيم إلى صفحات وتعيين مهلة عند جلب الكتالوج الكامل. قد تتم إضافة الحقول بتوافق مع الإصدارات السابقة، وعلى العميل قراءة الحقول المطلوبة فقط.
