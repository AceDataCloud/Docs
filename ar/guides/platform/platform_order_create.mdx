---
title: "إنشاء طلب شحن لمنصة AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

أنشئ طلبًا معلّق الدفع لتطبيق واحد أو أكثر. سيؤدي الإنشاء إلى تسجيل الطلب، لكنه لن يُكمل الدفع تلقائيًا؛ يجب التحقق من `price` والباقـة وApplication في الاستجابة قبل الدفع.

## الأعمال التحضيرية

- أنشئ [Account Token](https://platform.acedata.cloud/documents/platform-token).
- احصل على `application_id` من [قائمة Application](https://platform.acedata.cloud/documents/platform-application-list).
- اختر `package_id` القابل للشراء والمتوافق مع نوع Application من `packages` في [تفاصيل الخدمة](https://platform.acedata.cloud/documents/platform-service-detail).

```shell
export PLATFORM_TOKEN='رمز حسابك'
export APPLICATION_ID='معرّف Application الخاص بك'
export PACKAGE_ID='معرّف Package الخاص بك'
```

## نظرة عامة على الواجهة

| البند    | المحتوى                                              |
| ---- | ----------------------------------------------- |
| الطريقة   | `POST`                                          |
| URL  | `https://platform.acedata.cloud/api/v1/orders/` |
| المصادقة   | Account Token، يتطلب OAuth token صلاحية `orders:write`      |
| Body | JSON                                            |

## جسم الطلب

يستخدم طلب Application واحد `application_id` + `package_id`؛ ويستخدم الطلب المجمع `application_ids` + `package_ids` ذات الأطوال المتطابقة. تختار الطلبات العادية طريقة الدفع في طلب `/pay/` اللاحق. عند إنشاء طلب شراء iOS داخل التطبيق، مرّر `pay_way: "AppleIAP"`، ولا يمكن اختيار سوى باقة Usage واحدة تحتوي على `metadata.apple_product_id` و`metadata.apple_price`. يستخدم شراء Apple داخل التطبيق أسعارًا مستقلة محددة مسبقًا بالدولار الأمريكي، ولا تُضاف إليه خصومات العضوية أو خصومات طريقة الدفع أو الزيادات السعرية للموقع؛ ويعتمد مبلغ الخصم بالعملة المحلية في المناطق الأخرى على صفحة تأكيد الدفع من Apple.

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/orders/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d "{\"application_id\":\"${APPLICATION_ID}\",\"package_id\":\"${PACKAGE_ID}\"}"
```

## شرح الاستجابة

تعيد العملية الناجحة `201` وكائن Order الذي تم إنشاؤه حديثًا. تشمل الحقول الرئيسية `id` و`price` و`discount` و`state` و`application_id/application_ids` و`package_id/package_ids` و`expired_at` وحقول الوقت. يكون الطلب الجديد عادةً `Pending`، ثم استدعِ [دفع الطلب](https://platform.acedata.cloud/documents/platform-order-pay).

- `price` هو المبلغ المستحق الذي يحسبه الخادم بناءً على الباقة والزيادة السعرية للموقع والخصومات؛ لا تحسبه من جهة العميل بنفسك.
- يتم إرجاع `400` عندما لا تتطابق Package مع خدمة أو نوع Application.
- لا يمكن المطالبة بـ Package المجانية والمدارة من النظام ذاتيًا عبر واجهة الطلبات العامة.
- سيتم رفض إنشاء طلب لـ Application لا تنتمي إلى الحساب الحالي.
