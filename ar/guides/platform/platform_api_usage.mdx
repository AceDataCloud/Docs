يعيد بشكل علني عينة من سجلات الاستدعاءات خلال آخر 15 دقيقة لواجهة API معينة، لاستخدامها في المراقبة السريعة للحالة الأخيرة. وهو ليس واجهة عدّ مجمّعة حسب رموز الحالة، ولا يمكن استخدامه للفوترة الشخصية أو SLA أو إحصاءات الاستخدام الكاملة.

## نظرة عامة على الواجهة

| البند   | المحتوى                                                           |
| --- | ------------------------------------------------------------ |
| الطريقة  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| المصادقة  | علنية، لا تحتاج إلى رمز حساب                                                    |
| الحد الأقصى  | بعد دمج السجلات التي تم إنشاؤها/إكمالها مؤخراً، يتم إرجاع ما يصل إلى 5,000 سجل                                    |

يتم الحصول على `api_id` من [قائمة API](https://platform.acedata.cloud/documents/platform-api-list).

```shell
export API_ID='你的 API ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## بنية الاستجابة الفعلية

الاستجابة عبارة عن مصفوفة مباشرة، ولا تستخدم envelope للترقيم الصفحي:

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| الحقل            | الوصف        |
| ------------- | --------- |
| `api_id`      | معرّف API    |
| `created_at`  | وقت إنشاء السجل    |
| `trace_id`    | معرّف تتبع الطلب    |
| `status_code` | رمز حالة HTTP  |
| `elapsed`     | مدة الاستدعاء، بوحدة الثواني |

حتى عند عدم وجود API، قد تُرجع الواجهة حالياً مصفوفة فارغة، لأن هذا الإجراء يستعلم مباشرة عن usage الأخيرة حسب المعرّف، ولا يتحقق أولاً من كائن API. لحساب معدل النجاح، يجب على العميل تجميع العينات المُعادة بنفسه؛ وللاستعلام عن الخصومات الشخصية، يُرجى استخدام الواجهة على مستوى الحساب.
