---
title: "إعداد مشاركة الرصيد العالمي لـ AceDataCloud Application"
description: "Platform API guide - Ace Data Cloud"
---

قم بإعداد `allow_consume_global`. بعد التفعيل، يمكن لتطبيقات Application حسب الاستخدام التي تستوفي الشروط الاستمرار في استخدام الرصيد العالمي للحساب عند عدم كفاية رصيدها الخاص.

## التحضيرات

- أنشئ واحفظ بأمان [Account Token](https://platform.acedata.cloud/documents/platform-token).
- احصل على `application_id` الذي تملكه من [قائمة طلبات الخدمة](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='رمز حسابك'
export APPLICATION_ID='معرّف Application الخاص بك'
```

## نظرة عامة على الواجهة

| العنصر    | المحتوى                                                                                             |
| ---- | -------------------------------------------------------------------------------------------------- |
| الطريقة   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| المصادقة   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

عند النجاح، يتم إرجاع كائن Application المحدّث. يُرجى الاعتماد على `allow_consume_global` في الاستجابة، بدلًا من افتراض أن قيمة الطلب قد تم حفظها بالضرورة.

> لا يُسمح لتطبيقات Application من نوع `Period` باستهلاك الرصيد العالمي. حتى عند طلب `true`، سيُبقي الخادم هذا الحقل على `false`.

## معالجة الأخطاء

- `401`: Account Token غير صالح أو مفقود.
- `403`: الحساب الحالي ليس مالك Application هذا.
- `404`: معرّف Application غير موجود.

يُرجى الاعتماد على منصة التحكم وعلى الباقات الفعلية التي تُرجعها [عملية إنشاء الطلب](https://platform.acedata.cloud/documents/platform-order-create) فيما يتعلق بمدخل شحن الرصيد العالمي والباقات المتاحة؛ لا تفترض وجود باقات من نوع `Wallet`.
