استعلم عن طلب باستخدام معرّف الطلب. تدعم نقطة النهاية هذه وضعَي قراءة: يعيد الوصول المجهول الحد الأدنى من الحقول المطلوبة لصفحة الدفع فقط؛ بينما يعيد مالك الطلب الذي يحمل Account Token التفاصيل الكاملة.

## نظرة عامة على الواجهة

| العنصر   | المحتوى                                                        |
| --- | --------------------------------------------------------- |
| الطريقة  | `GET`                                                     |
| URL | `https://platform.acedata.cloud/api/v1/orders/{order_id}` |
| المصادقة  | اختيارية؛ المجهول يحصل على إسقاط أدنى، والمالك المصادق عليه يحصل على إسقاط كامل                                    |

يتوفر حاليًا كل من `/orders/{id}` و`/orders/{id}/`. يُعد معرّف الطلب جزءًا من رابط الدفع، وينبغي اعتباره معرّفًا حساسًا ومعتمًا، ولا تنشره علنًا.

## الاستعلام المجهول

يمكن لصفحة الدفع القراءة مباشرة عند فقدان حالة تسجيل الدخول:

```shell
export ORDER_ID='你的订单 ID'
curl "https://platform.acedata.cloud/api/v1/orders/${ORDER_ID}" \
  -H 'Accept: application/json'
```

لا تتضمن الاستجابة المجهولة سوى `id` و`description` و`price` و`state` و`pay_way` و`pay_url` و`expired_at` و`created_at`. ولن تعيد الحساب أو Application أو Package أو المعرّفات الداخلية للدفع أو metadata.

## الاستعلام المصادق عليه

```shell
export PLATFORM_TOKEN='你的账户令牌'
curl "https://platform.acedata.cloud/api/v1/orders/${ORDER_ID}" \
  -H 'Accept: application/json' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

سيتلقى مالك الطلب تفاصيل Order الكاملة، بما في ذلك `application` / `applications` و`package` / `packages` و`bank_details` و`invoice_automation` وحقول النموذج. إذا كان المستخدم مصادقًا عليه لكنه ليس مالك الطلب، فسيتم إرجاع `403`؛ باستثناء المسؤولين المتميزين.

## الحقول الرئيسية

| الحقل            | الوصف                                                          |
| ------------- | ----------------------------------------------------------- |
| `state`       | `Pending` أو `Paid` أو `Finished` أو `Expired` أو `Failed` أو `Refunded` |
| `pay_way`     | طريقة الدفع الحالية للطلب؛ اسم الحقل ليس `payment_method`                             |
| `pay_url`     | عنوان صفحة الدفع المستضافة أو رمز QR، وقد يكون فارغًا                                           |
| `price`       | المبلغ النهائي المستحق للطلب، ولا يوفر نموذج الطلب الحالي حقل `final_price`                         |
| `amount`      | كمية رصيد الباقة؛ يظهر فقط في الاستجابة الكاملة المصادق عليها                                            |
| `finished_at` | وقت اكتمال الطلب؛ اسم الحقل ليس `paid_at`                                      |

قد تضيف الاستجابة الكاملة حقولًا وفقًا لطريقة الدفع، وينبغي للعملاء قراءتها حسب الحاجة، وتجنب دائمًا تسجيل metadata الحساسة في الاستجابة الكاملة.

## معالجة الأخطاء

- `404`: معرّف الطلب غير موجود.
- `403`: تم تسجيل الدخول لكن المستخدم ليس مالك الطلب.
- لا تعيد الطلبات المجهولة `401`؛ بل تحصل فقط على الإسقاط العام الأدنى.
