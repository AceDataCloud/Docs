إنفيربال هو امتداد موجه لفيجوال ستوديو 2022/2026، يدعم رسميًا الاتصال بخدمات متوافقة مع OpenAI. قد تؤثر إصدارات الامتداد على التحرير، واستدعاءات الأدوات، وتسجيل الاستخدام؛ يرجى تثبيت الإصدار الثابت وإكمال الحد الأدنى من التحقق المذكور أدناه عند الاتصال لأول مرة.

## التكوين

1. قم بتثبيت إنفيربال من سوق فيجوال ستوديو أو المستودع الرسمي.
2. افتح **الإعدادات → الاتصال** لإنفيربال.
3. اختر مزود OpenAI-compatible.
4. املأ عنوان URL الأساسي بـ `https://api.acedata.cloud/v1`.
5. املأ مفتاح API برمز Ace Data Cloud API الخاص بك.
6. املأ النموذج بمعرف النموذج الدقيق المدعوم من Chat Completions في دليل النماذج.
7. بعد الحفظ، أرسل `Reply only OK`، ثم نفذ مرة أخرى طلبًا يتضمن سياق الكود.

## الحدود الحالية

- تغطي هذه الإرشادات إنفيربال فقط، ولا تمثل دعم فيجوال ستوديو المدمج أو أي امتدادات أخرى لنفس الحقول.
- قد تضيف الإصدارات المختلفة مسارًا تلقائيًا إلى عنوان URL الأساسي؛ إذا فشل الطلب، يرجى التحقق أولاً مما إذا كان الطلب النهائي يقع ضمن نقطة نهاية Chat Completions.
- لا يتم الالتزام بتوفر جميع أوضاع التحرير، والتكملة، أو استدعاءات الأدوات قبل إكمال الإصدار الثابت E2E.
