title: "حذف بيانات اعتماد API لمنصة AceDataCloud"

احذف بشكل دائم بيانات اعتماد API واحدة. بعد الحذف **لا يمكن استعادتها فورًا**، وستتلقى جميع واجهات الأعمال التي تستخدم هذا الـ Token حاليًا `401` على الفور.

> ℹ️ تنتمي هذه الواجهة إلى **API إدارة منصة AceDataCloud**، والبادئة الموحدة هي `https://platform.acedata.cloud/api/v1/`۔

## نظرة عامة على الواجهة

| البند   | المحتوى                                                                  |
| --- | ------------------------------------------------------------------- |
| الطريقة  | `DELETE`                                                            |
| URL | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}` |
| المصادقة  | ✅ يتطلب رمز حساب                                                            |

كلا المسارين `/credentials/{id}` و`/credentials/{id}/` متاحان حاليًا؛ وتستخدم الأمثلة بشكل موحد صيغة دون شرطة مائلة لاحقة.

## توضيح المصادقة (كيفية الحصول على رمز الحساب)

رأس الطلب:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

راجع [إدارة رموز حساب منصة AceDataCloud](https://platform.acedata.cloud/documents/platform-token) لمعرفة طريقة الحصول عليه.

## معلمات المسار

| المعلمة              | النوع   | مطلوب  | التوضيح        |
| --------------- | ---- | --- | --------- |
| `credential_id` | UUID | ✅   | معرّف بيانات الاعتماد المراد حذفها |

## أمثلة الطلبات

### cURL

```shell
curl -X DELETE 'https://platform.acedata.cloud/api/v1/credentials/df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

cred_id = "df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6"
resp = requests.delete(
    f"https://platform.acedata.cloud/api/v1/credentials/{cred_id}",
    headers={"authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"},
    timeout=10,
)
assert resp.status_code == 204, resp.text
print("✅ 已删除")
```

### Node.js

```javascript
const credId = 'df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6'
const r = await fetch(`https://platform.acedata.cloud/api/v1/credentials/${credId}`, {
  method: 'DELETE',
  headers: { authorization: `Bearer ${process.env.PLATFORM_TOKEN}` },
})
console.log('status:', r.status) // 204
```

## الاستجابة

- **النجاح**: `HTTP 204 No Content`، **لا يوجد جسم استجابة**.
- **الفشل**: يعيد JSON للخطأ، راجع الجدول أدناه.

## معالجة الأخطاء

| HTTP | code                | المعنى         |
| ---- | ------------------- | ---------- |
| 401  | `not_authenticated` | رمز الحساب مفقود     |
| 403  | `permission_denied` | بيانات الاعتماد هذه لا تنتمي إليك    |
| 404  | `not_found`         | بيانات الاعتماد غير موجودة أو تم حذفها |

## نصائح عملية

- **الحذف غير قابل للعكس**——لا تحتفظ المنصة بنسخة من الـ Token. إذا كنت تشك فقط في حدوث تسريب وما زلت ترغب في الاحتفاظ ببيانات المراقبة، فيجب استخدام [تدوير بيانات اعتماد API لمنصة AceDataCloud](https://platform.acedata.cloud/documents/platform-credential-rotate) بدلًا من الحذف.
- **لن يعيد الحذف الحصة التي استهلكتها بيانات الاعتماد هذه**. يتم خصم رصيد Application فورًا حسب الاستهلاك، ولا يؤثر حذف بيانات الاعتماد في سجل الرصيد.
- بعد الحذف، يمكنك إعادة تأكيد بيانات الاعتماد المتبقية حسب `application_id` عبر [قائمة بيانات اعتماد API](https://platform.acedata.cloud/documents/platform-credential-list).
- **تحقق من المستدعين قبل التنظيف الجماعي**: لا تحتوي القائمة حاليًا على حقل وقت آخر استخدام؛ يجب تأكيد أن بيانات الاعتماد لم تعد مستخدمة بالاقتران مع إعدادات النشر وسجلات الاستدعاء، ثم حذفها واحدة تلو الأخرى.
