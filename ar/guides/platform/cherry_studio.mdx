## 1. الحصول على API Key

افتح [قائمة تطبيقات Ace Data Cloud](https://platform.acedata.cloud/console/applications)، وادخل إلى التطبيق المتاح وانسخ API Key.

![الحصول على Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. إضافة Provider

افتح Cherry Studio، وانتقل إلى **الإعدادات → خدمات النماذج → إضافة مزود**، واملأ:

| الحقل      | القيمة                           |
| ------- | --------------------------- |
| اسم المزود   | `Ace Data Cloud`            |
| نوع المزود   | `OpenAI`                    |
| API Key | API Key الذي نسخته للتو               |
| عنوان API  | `https://api.acedata.cloud` |

![واجهة إعداد إضافة Ace Data Cloud Provider في Cherry Studio](https://cdn.acedata.cloud/b67a927eae62.png)

سيكمل Cherry Studio تلقائيًا `/v1/chat/completions` لنوع OpenAI. عند استخدام نقطة الدخول العامة، لا تضف `#` في نهاية العنوان، ولا حاجة أيضًا لإنشاء عدة Providers حسب عائلة النموذج.

## 3. إضافة النموذج وتمكينه

1. انقر على **الحصول على قائمة النماذج**؛ إذا كان الإصدار الحالي لا يدعم الحصول التلقائي، فانتقل إلى [دليل النماذج](https://platform.acedata.cloud/models) للاطلاع، ثم أضف اسم النموذج المستهدف يدويًا، مثل `claude-opus-5` و`gpt-6-sol`.
2. انقر على زر الفحص بجانب API Key للتحقق من الاتصال.
3. فعّل مفتاح **تمكين** الخاص بـ Provider.
4. اختر النموذج الذي أضفته للتو في محدد نموذج المحادثة.

![قائمة Provider والنماذج في Cherry Studio](https://cdn.acedata.cloud/149de1d088bf.png)

> بعد إتمام الحصول على النموذج أو إضافته يدويًا، يرجى تفعيل مفتاح Provider في الزاوية العلوية اليمنى.

أرسل `Reply only OK`، وتحقق من الاستدعاء في [سجل الاستخدام](https://platform.acedata.cloud/console/usages). عند ظهور 401 تحقق من Key؛ وعندما لا يظهر النموذج، تحقق مما إذا كان Provider مفعّلًا؛ وعند ظهور 404 تحقق مما إذا كان اسم النموذج المُدخل يدويًا مطابقًا تمامًا لـ `id` في الدليل.

## حول GPT Image 2

لا يستطيع Provider الدردشة المخصص العادي في Cherry Studio استدعاء Images API مباشرةً. يجب استخدام واجهة Ace Data Cloud المخصصة لإنشاء وتحرير `gpt-image-2`:

- [إنشاء صور GPT Image 2](https://platform.acedata.cloud/documents/openai-images-generations)
- [تحرير صور GPT Image 2](https://platform.acedata.cloud/documents/openai-images-edits)

لا تضع `/openai/images/generations` في Provider الدردشة.
