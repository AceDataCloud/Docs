احصل على المعلومات الكاملة لنقطة نهاية API واحدة عبر معرّف API — إضافةً إلى حقول `definition` ‏(مخطط OpenAPI 3.0)، و`service` ‏(تفاصيل الخدمة التابعة)، و`products` ‏(المنتجات المرتبطة) مقارنةً بـ[واجهة القائمة](https://platform.acedata.cloud/documents/platform-api-list).

مناسب لسيناريوهات مثل إنشاء SDK تلقائيًا، وتغذية LLM Agent بوصف الأدوات، والعرض الديناميكي لمواقع الوثائق.

> ℹ️ تنتمي هذه الواجهة إلى **واجهة API لإدارة منصة AceDataCloud**، وبادئة موحّدة هي `https://platform.acedata.cloud/api/v1/`. راجع [الحصول على قائمة وثائق منصة AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list) لفهرس الواجهات الكامل.

## نظرة عامة على الواجهة

| البند   | المحتوى                                                    |
| --- | ----------------------------------------------------- |
| الطريقة  | `GET`                                                 |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}` |
| المصادقة  | ❌ عامة                                                  |

كلٌّ من `/apis/{id}` و`/apis/{id}/` متاحان حاليًا؛ تستخدم الأمثلة بشكل موحّد صيغة بدون شرطة مائلة لاحقة.

## شرح المصادقة

هذه الواجهة **عامة بالكامل، ولا تتطلب رمز حساب أو حالة تسجيل دخول**.

## معاملات المسار

| المعامل       | النوع   | مطلوب  | الوصف                    |
| -------- | ---- | --- | --------------------- |
| `api_id` | UUID | ✅   | معرّف API (بتنسيق UUID، ولا يدعم الأسماء المستعارة) |

## أمثلة الطلبات

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/apis/afc7917f-d89f-4dc9-95c2-863936b02cad' \
  -H 'accept: application/json'
```

### Python

```python
import requests

api_id = "afc7917f-d89f-4dc9-95c2-863936b02cad"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/apis/{api_id}",
    headers={"accept": "application/json"},
    timeout=10,
)
api = resp.json()
print(f"API: {api['title']}")
print(f"المسار: {api['path']}")
print(f"الخدمة التابعة: {api['service']['title']} ({api['service']['alias']})")
print(f"عدد مسارات OpenAPI: {len(api.get('definition', {}).get('paths', {}))}")
```

### Node.js

```javascript
const apiId = 'afc7917f-d89f-4dc9-95c2-863936b02cad'
const r = await fetch(`https://platform.acedata.cloud/api/v1/apis/${apiId}`)
const api = await r.json()
console.log(api.title, api.path, api.service.title)
```

## شرح حقول الاستجابة

تتضمن واجهة التفاصيل، بالإضافة إلى [حقول واجهة القائمة](https://platform.acedata.cloud/documents/platform-api-list)، ما يلي:

| الحقل           | النوع     | الوصف                                                                                          |
| ------------ | ------ | ------------------------------------------------------------------------------------------- |
| `service`    | object | المعلومات الأساسية للخدمة التابعة: `id`، `title`، `type`، `alias`                                                       |
| `products`   | array  | قائمة المنتجات المرتبطة (تكون فارغة عادةً، للاستخدام من جانب العمليات)                                                                         |
| `definition` | object | **تعريف مواصفات OpenAPI 3.0 الكامل**، يتضمن `paths` و`components` و`info` وغيرها، ويمكن تغذيته مباشرةً إلى `openapi-generator` لإنشاء كود العميل |

## معالجة الأخطاء

| HTTP | code        | المعنى                 |
| ---- | ----------- | ------------------ |
| 400  | `invalid`   | `api_id` ليس UUID صالحًا |
| 404  | `not_found` | واجهة API غير موجودة أو تم إيقافها        |

## نصائح عملية

- حقل **`definition` كبير جدًا**: قد يحتوي مخطط OpenAPI الخاص بواجهة API واحدة على مئات أسطر JSON. إذا كنت تحتاج فقط إلى فهرس الخدمات ولا تحتاج إلى المخطط، فيجب استخدام [واجهة القائمة](https://platform.acedata.cloud/documents/platform-api-list) بدلًا من ذلك.
- **الاستخدام الشائع لإنشاء SDK**:
  ```shell
  # الحصول على ملف OpenAPI
  curl -s 'https://platform.acedata.cloud/api/v1/apis/<api_id>' | jq '.definition' > openapi.json

  # استخدام openapi-generator-cli لإنشاء عميل Python
  openapi-generator-cli generate -i openapi.json -g python -o ./client
  ```
- **تتبع تغييرات API**: حقل `updated_at` هو وقت آخر تغيير للمخطط. يتيح الاشتراك في هذا الحقل إعادة إنشاء SDK تلقائيًا عند تغيّر OpenAPI.
