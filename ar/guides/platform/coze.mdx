تدعم Coze رسميًا دمج النماذج المخصصة، وتوفر ثلاث بروتوكولات: OpenAI Chat API وOpenAI Responses API وAnthropic Messages API. تختلف عناوين URL الأساسية، وتجميع المسارات، والرؤوس، والبث، وعقود استدعاء الأدوات بين هذه الطرق، لذا يجب تكوينها والتحقق منها بشكل منفصل.

| الطريق                      | الحالة  | الدليل                                                                                  |
| ----------------------- | --- | ----------------------------------------------------------------------------------- |
| OpenAI Chat Completions | تجريبي | [تكوين الدردشة](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | تجريبي | [تكوين الاستجابات](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | تجريبي | [تكوين الرسائل](https://platform.acedata.cloud/documents/coze-messages-integration)   |

تشير "تجريبي" إلى أن القدرات الرسمية ونقاط الدخول للتكوين قد تم تأكيدها، ولكن قد تظهر نماذج مختلفة في مناطق Coze أو الإصدارات أو الباقات المختلفة، ولا يزال يتعين على Ace Data Cloud إكمال التحقق من الإصدار الثابت وفقًا للبروتوكول. لا تقم بتعميم نجاح بروتوكول معين على البروتوكولات الأخرى.

## مبادئ التكوين

- يجب ملء عنوان API الأساسي وفقًا لما تقدمه الوثائق؛ لا تضف مسار نقطة النهاية الذي سيكمله العميل تلقائيًا.
- استخدم مفتاح API الخاص بك من Ace Data Cloud API Token.
- استخدم معرف النموذج الدقيق المتوافق مع البروتوكول المختار من دليل النماذج.
- بعد النجاح في النص العادي، يجب أيضًا التحقق من البث واستدعاء الأدوات.
