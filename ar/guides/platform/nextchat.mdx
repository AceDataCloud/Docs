[NextChat](https://github.com/ChatGPTNextWeb/NextChat) (المعروف سابقًا باسم ChatGPT-Next-Web) هو عميل ذكاء اصطناعي مفتوح المصدر يمكن نشره على Vercel أو Cloudflare أو Docker. وهو يدعم نقاط نهاية متوافقة مع OpenAI مخصصة، لذلك يمكن دمجه مع Ace Data Cloud. يشرح هذا المقال عملية الإعداد.

## عملية التقديم

لدمج Ace Data Cloud في NextChat، انتقل أولًا إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications)، واحصل على API Token الخاص بك، واحتفظ به للاستخدام لاحقًا.

![الحصول على مفتاح API لـ Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد سجلت الدخول أو أنشأت حسابًا بعد، فسيتم إعادة توجيهك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وبعد التسجيل وتسجيل الدخول ستعود تلقائيًا إلى الصفحة الحالية.

عند التقديم لأول مرة، سيتم منحك رصيد مجاني، ويمكنك تجربة خدمات نماذج Ace Data Cloud مجانًا.

## تنزيل NextChat

يمكنك استخدام إصدار سطح المكتب (تنزيل `.exe` / `.dmg` / AppImage من [صفحة Releases](https://github.com/ChatGPTNextWeb/NextChat/releases))، أو [الإصدار عبر الويب](https://app.nextchat.club/)، أو النشر بنفسك على Vercel / Cloudflare / Docker (انظر القسم المتقدم أدناه).

## إعداد Ace Data Cloud

شغّل NextChat، وانتقل إلى **الإعدادات → خدمة النماذج**:

| الحقل          | القيمة                           | الوصف                              |
| ----------- | --------------------------- | ------------------------------- |
| مزود خدمة النماذج       | `OpenAI`                    | استخدام بروتوكول متوافق مع OpenAI                  |
| عنوان واجهة OpenAI | `https://api.acedata.cloud` | املأ اسم النطاق الجذر فقط، **من دون `/openai` ومن دون `/v1`** |
| API Key     | Ace Data Cloud Token الخاص بك     | Token المنسوخ من لوحة التحكم                    |

![واجهة إعداد Ace Data Cloud في NextChat](https://cdn.acedata.cloud/47e0aed34570.png)

سيقوم NextChat تلقائيًا بإلحاق `/v1/chat/completions` بعد عنوان الواجهة، لذلك يكفي ملء اسم النطاق الجذر فقط:

| عنوان الواجهة                                  | الطلب الفعلي                                                      | النتيجة                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | صحيح                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (لا يوجد `/v1` ضمن `/openai`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

في مربع «اسم النموذج المخصص»، املأ النماذج مفصولة بفواصل إنجليزية. يدعم NextChat صياغة خاصة: `+اسم النموذج` للإضافة، و`-اسم النموذج` للإخفاء، و`اسم النموذج=اسم العرض` لتخصيص اسم العرض، و`-all` لإخفاء الكل أولًا. الصياغة الأنظف الموصى بها:

```text
-all,+MODEL_ID=اسم العرض
```

## اختيار النموذج

سيتم تحديث دليل النماذج باستمرار. استخدم قائمة النماذج التي يحمّلها العميل تلقائيًا بشكل أساسي؛ وعند الحاجة إلى الإدخال يدويًا، اطلب أولًا `GET https://api.acedata.cloud/v1/models` للحصول على معرّفات النماذج الحالية، ثم اختر وفقًا لسياق العميل المدعوم والصور وقدرات استدعاء الأدوات.

## التحقق من التكامل

إذا لم تكن متأكدًا مما إذا كانت المشكلة في NextChat أو في الشبكة، يمكنك أولًا استخدام curl للتحقق مباشرة من نقطة النهاية (استبدل `{token}` بـ Token الخاص بك):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

إن إرجاع كائن `chat.completion` متوافق مع OpenAI يعني أن Token ونقطة النهاية جاهزان؛ وإذا تم إرجاع `HTTP 403 used_up` فهذا يعني أن Token صالح لكن الرصيد غير كافٍ، ويمكنك إعادة الشحن من [لوحة التحكم](https://platform.acedata.cloud/console/applications).

## متقدم: النشر بنقرة واحدة على نطاقك الخاص

يدعم NextChat نشر موقع ذكاء اصطناعي خاص بك. باستخدام Docker كمثال (استبدل `{token}` بـ Token الخاص بك):

```bash
docker run -d \
  --name nextchat \
  -p 3000:3000 \
  -e OPENAI_API_KEY={token} \
  -e BASE_URL=https://api.acedata.cloud \
  -e CODE=your-password \
  -e CUSTOM_MODELS="-all,+MODEL_ID=اسم العرض" \
  yidadaa/chatgpt-next-web
```

عند النشر على Vercel / Cloudflare، ما عليك سوى إعداد متغيرات البيئة نفسها `OPENAI_API_KEY` و`BASE_URL` و`CODE` و`CUSTOM_MODELS` في المشروع. يدعم `CODE` عدة كلمات مرور وصول مفصولة بفواصل إنجليزية، لتسهيل إحصاء الاستخدام حسب الأشخاص. بالنسبة إلى الشرح الكامل لمتغيرات البيئة أعلاه (القيمة الافتراضية لـ `BASE_URL` هي `https://api.openai.com`، وصياغة `+/-/=/-all/+all` لـ `CUSTOM_MODELS`)، يُرجى الرجوع إلى [README الرسمي لـ NextChat](https://github.com/ChatGPTNextWeb/NextChat#environment-variables).

## الأسئلة الشائعة

### ظهور 404 Not Found

عادةً ما يكون عنوان الواجهة مكتوبًا على شكل `.../openai` أو `.../openai/v1`. غيّره إلى `https://api.acedata.cloud`، ودع NextChat يضيف بنفسه `/v1/chat/completions`.

### النموذج المضاف غير موجود في القائمة المنسدلة للنماذج

تحقق من تنسيق `CUSTOM_MODELS`، إذ يجب أن يسبق كل نموذج `+`؛ وإذا استخدمت `-all`، فتأكد من إعادة إضافة النموذج المطلوب باستخدام `+` لاحقًا.

### ظهور 401 Unauthorized

يرجى التأكد من أن ما تم لصقه في API Key هو Token الخاص بـ Ace Data Cloud (من دون بادئة `Bearer` ومن دون مسافات زائدة)، وأن رصيد التطبيق التابع له كافٍ.
