---
title: "الحصول على قائمة نماذج منصة AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

يعيد دليل النماذج العامة للمنصة، ويستخدم الرد بنية `{ "object": "list", "data": [...] }` بأسلوب OpenAI. يُستخدم هذا الدليل لاختيار النماذج واكتشاف القدرات، ولا يعني أن الحساب الحالي قد تقدّم بالضرورة بطلب للحصول على الخدمة المقابلة.

## نظرة عامة على الواجهة

| البند   | المحتوى                                              |
| --- | ----------------------------------------------- |
| الطريقة  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| المصادقة  | عامة، لا تتطلب رمز حساب                                       |
| الترقيم  | بدون ترقيم، جميع العناصر المطابقة موجودة في `data`                              |

## معاملات الاستعلام

| المعامل             | النوع      | مطلوب  | الوصف                                      |
| -------------- | ------- | --- | --------------------------------------- |
| `owned_by`     | string  | لا   | تصفية دقيقة حسب معرّف مزود النموذج في الدليل                        |
| `type`         | string  | لا   | تصفية دقيقة حسب نوع النموذج، مثل `chat`                     |
| `capability`   | string  | لا   | يعيد فقط النماذج التي تتضمن `capabilities` لديها هذه القدرة، مثل `vision` |
| `with_pricing` | boolean | لا   | يضيف معلومات الأسعار العامة عند استخدام `1` أو `true` أو `yes`            |

`service_id` و`tag` و`limit` و`offset` و`ordering` غير مدعومة حاليًا؛ ولن يؤدي تمريرها إلى تأثيرات التصفية أو الترقيم المقابلة.

## أمثلة الطلبات

```shell
# جميع النماذج العامة
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# نماذج chat التي تدعم الرؤية، مع الأسعار
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## بنية الاستجابة الفعلية

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

تظهر `pricing` و`credit_usd_rate` على المستوى الأعلى فقط عند استخدام `with_pricing=true`؛ ولا يملك كل نموذج بالضرورة `pricing` قابلة للحساب. تستند كائنات النماذج إلى الحقول العامة في `config/models.json`، ويجب على العميل تجاهل الحقول المضافة.

> حقول الأسعار هي بيانات عرض للدليل. تظل استدعاءات الأعمال الفعلية خاضعة لقواعد الفوترة وسجلات الاستخدام النهائية الخاصة بـ API/Service المقابلة.
