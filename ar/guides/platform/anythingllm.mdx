[AnythingLLM](https://anythingllm.com/) هو عميل مفتوح المصدر يتمحور حول مفهوم «المستندات → ChatGPT خاص»، ومفهومه الأساسي هو **Workspace**—كل Workspace عبارة عن مجموعة من المستندات، ومجموعة من المستخدمين، ومجموعة من أدوات Agent، معزولة بشكل مستقل. وهو مصمم خصيصًا للمحادثة مع المستندات، ويوفر شكلين: تطبيق سطح المكتب وDocker. ضمن **LLM Provider**، يتضمن خيار [OpenAI (Generic)](https://docs.anythingllm.com/setup/llm-configuration/cloud/openai-generic)، حيث يمكن تعبئة Base URL مخصص، وبالتالي يمكن توجيه نموذج المحادثة مباشرة إلى Ace Data Cloud. يشرح هذا المقال عملية الإعداد.

## عملية التقديم

لربط Ace Data Cloud في AnythingLLM، انتقل أولًا إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications)، واحصل على API Token الخاص بك، واحتفظ به للاستخدام لاحقًا.

![الحصول على Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد سجلت الدخول أو أنشأت حسابًا بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وبعد التسجيل وتسجيل الدخول ستعود تلقائيًا إلى الصفحة الحالية.

عند التقديم لأول مرة، سيتم منحك رصيد مجاني، ويمكنك تجربة خدمات نماذج Ace Data Cloud مجانًا.

## تنزيل AnythingLLM

للاستخدام الشخصي، يمكنك تنزيل [نسخة سطح المكتب](https://anythingllm.com/download)، حيث تعمل قاعدة المتجهات (LanceDB) محليًا، ويكون البحث في المستندات دون اتصال بالكامل، ولا يتطلب الاتصال بالإنترنت إلا عند استدعاء النموذج؛ ولحالات الفرق متعددة المستخدمين، استخدم [نشر Docker](https://docs.anythingllm.com/installation-docker/overview).

## إعداد نموذج المحادثة

شغّل AnythingLLM، وانتقل إلى **Settings → LLM Preference**، واختر **OpenAI (Generic)** كمزوّد Provider (لا تختر OpenAI العادي، لأنه يشير بشكل ثابت إلى `api.openai.com` ولا يتيح Base URL مخصصًا). راجع الوثائق الرسمية في [OpenAI (Generic) LLM Provider](https://docs.anythingllm.com/setup/llm-configuration/cloud/openai-generic).

| الحقل                   | القيمة                              | الوصف                                       |
| -------------------- | ------------------------------ | ---------------------------------------- |
| Base URL             | `https://api.acedata.cloud/v1` | **يجب أن ينتهي بـ `/v1`**                         |
| API Key              | Ace Data Cloud Token الخاص بك        | Token المنسوخ من لوحة التحكم                             |
| Selected Model       | معرّف النموذج الحالي                        | أعطِ الأولوية للقائمة التي يتم تحميلها تلقائيًا من `/models`؛ وعند عدم إرجاعها، استعلم وفق الطريقة أعلاه ثم املأها يدويًا |
| Model context window | املأه وفقًا للنموذج المحدد                        | اقرأ الحد الأقصى للسياق من دليل النموذج الحالي، ولا تنسخ قيم النماذج الأخرى               |

![واجهة إعداد AnythingLLM Generic OpenAI](https://cdn.acedata.cloud/a155f5476de7.png)

> تعتمد قدرات النموذج والحد الأقصى للسياق على دليل النموذج الحالي.

انتبه إلى قواعد مسار Base URL:

| Base URL                              | الطلب الفعلي                                                   | النتيجة                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | صحيح                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | يمكن استخدامه أيضًا                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404（لا يوجد `/v1` تحت `/openai`） |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404（`/v1` مفقود）             |

## إعداد نموذج Embedding

جوهر AnythingLLM هو RAG، ويحتاج إلى نموذج تضمين لتحويل المستندات إلى متجهات. إن **Embedding Preference** وLLM Preference فيه مجموعتا إعدادات مستقلتان عن بعضهما—راجع [نظرة عامة على إعدادات Embedder](https://docs.anythingllm.com/setup/embedder-configuration/overview). يعمل **AnythingLLM Embedder（Built-in / Native）** المدمج مباشرةً محليًا، وهو جاهز للاستخدام دون إعدادات، وهو الخيار الافتراضي والموصى به:

انتقل إلى **Settings → Embedding Preference**، واترك Provider على **AnythingLLM Embedder** الافتراضي، ولا حاجة لملء أي مفاتيح. سيُكمل تحويل المستندات إلى متجهات محليًا، ويتم تخزين كل من النص الأصلي والمتجهات في LanceDB محليًا، دون رفعها إلى السحابة.

> يتم ربط خيارات Embedder في AnythingLLM (السحابية: OpenAI / Azure OpenAI / Cohere؛ المحلية: Built-in وLM Studio و[LocalAI](https://docs.anythingllm.com/setup/embedder-configuration/local/localai) وOllama) وفقًا للصيغة الثابتة الخاصة بكل منها. من بينها، يشير تضمين OpenAI السحابي بشكل ثابت إلى `api.openai.com` ولا يدعم Base URL مخصصًا؛ وإذا كنت ترغب في استخدام نقطة نهاية مخصصة، فيمكنك استخدام Embedder **Generic OpenAI** (والذي يحتوي أيضًا على حقل Base URL ويمكن توجيهه إلى `text-embedding-3-large` الخاص بـ Ace Data Cloud) أو Embedder **LocalAI** المحلي. يستخدم نموذج المحادثة في هذا المقال Ace Data Cloud، بينما يستخدم التضمين Embedder المحلي المدمج في AnythingLLM، ولا يؤثر أي منهما في الآخر.

## اختيار النموذج

سيستمر تحديث دليل النماذج. أعطِ الأولوية لقائمة النماذج التي يحملها العميل تلقائيًا؛ وعند الحاجة إلى الإدخال اليدوي، اطلب أولًا `GET https://api.acedata.cloud/v1/models` للحصول على معرّف النموذج الحالي، ثم اختر وفقًا لقدرات السياق والصور واستدعاء الأدوات التي يدعمها العميل.

## التحقق من الربط

إذا لم تكن متأكدًا مما إذا كانت المشكلة في AnythingLLM أو في الشبكة، فيمكنك أولًا استخدام curl للتحقق من نقطة النهاية مباشرةً (استبدل `{token}` بـ Token الخاص بك):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

إن إرجاع كائن `chat.completion` متوافق مع OpenAI يعني أن Token ونقطة النهاية جاهزان؛ وإذا أُعيد `HTTP 403 used_up` فهذا يعني أن Token صالح لكن الرصيد غير كافٍ، ويمكنك إعادة الشحن من [لوحة التحكم](https://platform.acedata.cloud/console/applications).

## متقدم: Workspace والمحادثة مع المستندات

بعد إنشاء Workspace جديد، ارفع مستندات مثل PDF / Word / Markdown، وسيقوم AnythingLLM بتقسيمها حسب الفقرات، واستخدام Embedder المحلي لإنشاء المتجهات وتخزينها في LanceDB المحلي. أثناء المحادثة، سيسترجع أولًا المقاطع ذات الصلة، ثم يرسل المقاطع وسؤالك معًا إلى نموذج المحادثة (أي Ace Data Cloud) للإجابة، ويشير إلى مصادر الاقتباسات أسفل الإجابة. يمكن التبديل بين وضعي **Query** (الإجابة بناءً على المستندات فقط) و**Chat** (دمج المعرفة العامة) في أعلى كل Workspace، ويوصى باستخدام وضع Query في السيناريوهات الجادة لتجنب الهلوسة. عند النشر باستخدام Docker، يمكن استخدام متغيرات البيئة مثل `GENERIC_OPEN_AI_BASE_PATH` و`GENERIC_OPEN_AI_API_KEY` و`GENERIC_OPEN_AI_MODEL_PREF` لإعداد نفس ربط نموذج المحادثة مسبقًا، وتمكين وضع تعدد المستخدمين.

## الأسئلة الشائعة

### ظهور 404 / connection fail

عادةً ما يكون Base URL مكتوبًا على شكل `.../openai/v1` أو أن `/v1` مفقود. غيّره إلى `https://api.acedata.cloud/v1`.

### تعذّر إجراء محادثة بعد رفع المستند

يرجى التأكد من اختيار Embedder قابل للاستخدام في **Settings → Embedding Preference** (يمكن تشغيل AnythingLLM Embedder الافتراضي محليًا، ولا يحتاج إلى إعدادات إضافية)، ثم أعد رفع المستند لإنشاء المتجهات.

### ظهور 401 Unauthorized
يرجى التأكد من أن ما تم لصقه في API Key هو Token الخاص بـ Ace Data Cloud (دون بادئة `Bearer` ودون مسافات إضافية)، وأن رصيد التطبيق التابع له كافٍ.

### هل سيتم رفع المستندات المحلية إلى السحابة؟

لا. يتم تخزين النص الأصلي للمستندات محليًا في LanceDB، ولن يتم إرسال سوى المقاطع المطابقة في الاسترجاع وسؤالك إلى النموذج.
