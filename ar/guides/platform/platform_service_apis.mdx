إرجاع واجهات API المفعّلة حاليًا وغير المهجورة لهذه الخدمة على صفحات عبر Service UUID. عند وجود alias فقط، استدعِ أولًا [تفاصيل الخدمة](https://platform.acedata.cloud/documents/platform-service-detail) للحصول على `id`.

## نظرة عامة على الواجهة

| البند   | المحتوى                                                                  |
| --- | ------------------------------------------------------------------- |
| الطريقة  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| المصادقة  | عامة، لا يلزم رمز حساب                                                           |
| الترقيم  | `count` + `items`                                                   |

## المعلمات

| المعلمة           | الموقع    | مطلوب  | الوصف                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | نعم   | Service UUID، لا يدعم alias           |
| `limit`      | query | لا   | عدد العناصر في كل صفحة، الحد الأقصى 100                      |
| `offset`     | query | لا   | إزاحة الترقيم                            |
| `ordering`   | query | لا   | تعبير ترتيب Django؛ يُوصى بـ `rank` أو `-rank` |

لا تدعم الواجهة الحالية التصفية حسب `stage`؛ وقد استبعدت بالفعل واجهات API ذات الحالة `Deprecated`.

```shell
export SERVICE_ID='你的 Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

تستخدم عناصر القائمة بنية الفهرس نفسها الخاصة بـ [قائمة Platform API](https://platform.acedata.cloud/documents/platform-api-list)، وتتضمن حاليًا `definition`. عند الحاجة إلى مدخل ثابت لواجهة API واحدة، تابع باستدعاء `/api/v1/apis/{api_id}`.

## معالجة الأخطاء

- الخدمة غير موجودة أو غير مرئية في الموقع الحالي: `404`.
- يجب أن يكون `service_id` بصيغة UUID؛ لن يتم تحليل alias في هذا الإجراء.
