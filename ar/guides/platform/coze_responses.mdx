توفر وثائق نموذج Coze الرسمي المخصص دعمًا لواجهة برمجة تطبيقات OpenAI Responses، وتقدم عنوان API الأساسي، ومفتاح API، وحقول النموذج. قد تختلف معالجة مسارات الدمج، والإخراج المتدفق، واستدعاءات الأدوات في إصدارات Coze المختلفة، لذا يرجى التحقق من كل نقطة أدناه عند الاتصال لأول مرة.

## التكوين

1. انتقل إلى إدارة نماذج Coze وأضف نموذجًا مخصصًا جديدًا.
2. اختر بروتوكول OpenAI Responses API.
3. املأ عنوان API الأساسي بـ `https://api.acedata.cloud/v1`.
4. املأ مفتاح API برمز Ace Data Cloud API الخاص بك.
5. املأ النموذج بمعرف النموذج الدقيق المدعوم من Responses API في دليل النماذج.
6. احفظ وأكمل اختبار الاتصال بـ Coze.
7. في Bot/Agent، أرسل `Reply only OK`، ثم اختبر استدعاء الأداة مرة أخرى.

## الحدود الحالية

- قد تظهر نماذج مختلفة في مناطق أو إصدارات أو باقات Coze المختلفة.
- يجب استخدام عنوان API الأساسي كما هو، ولا تضف `/responses` مرة أخرى؛ إذا كانت واجهة المستخدم الحالية تطلب عنوان API الكامل بوضوح، فاستند إلى إشعار النموذج.
- Chat Completions وResponses وAnthropic Messages هي ثلاث مسارات مستقلة، ولا يمكن استبدالها للتحقق.
