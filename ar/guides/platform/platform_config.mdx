اقرأ مفاتيح الميزات العامة وأحكام الدولة/المنطقة ضمن سياق الطلب الحالي. مناسب لاتخاذ قرار عرض الميزات عند بدء تشغيل الواجهة الأمامية؛ وهو ليس علامة الموقع التجارية أو معلومات الاتصال أو فهرس الإعلانات.

## نظرة عامة على الواجهة

| البند   | المحتوى                                              |
| --- | ----------------------------------------------- |
| الطريقة  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| المصادقة  | عامة؛ عند حمل حالة تسجيل الدخول، قد تُحسب بعض مفاتيح الميزات حسب المستخدم                          |

## معلمات الاستعلام ورؤوس الطلب

| الاسم                    | الموقع     | الوصف                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | تعبير تجاوز مفتاح الميزات؛ لا يسري إلا على المفاتيح التي يُسمح للعميل بتجاوزها أو للمسؤولين الفائقين |
| `X-Feature-Overrides` | header | مصدر تجاوز مماثل لـ `features`           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## بنية الاستجابة الفعلية

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| الحقل         | النوع            | الوصف                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | مفاتيح الميزات المرئية للطلب الحالي؛ قد تتغير المفاتيح وفقًا لتكوين المنصة، ويجب على العميل قراءتها عند الحاجة وتعيين قيم افتراضية آمنة للمفاتيح المفقودة |
| `region`   | string / null | رمز الدولة أو المنطقة المكتشف بناءً على IP الطلب، بأحرف صغيرة؛ يكون `null` عند تعذر التعرّف عليه        |

لا تقرأ اسم الموقع أو CDN أو العملة أو اللغة أو معلومات اتصال خدمة العملاء أو الإعلانات من هذه الواجهة؛ فهذه الحقول ليست ضمن عقد الاستجابة الحالي.

## توصيات الاستخدام

- تُحسب مفاتيح الميزات حسب المستخدم والبصمة وسياق الموقع، فلا تشارك التخزين المؤقت طويل الأمد بين المستخدمين.
- يُحفظ اختيار محدد المنطقة في الواجهة الأمامية فقط، وعند العرض استخدم المنطقة المختارة أولاً، وإلا فاستخدم `region` من هذه الواجهة. لا تقبل هذه الواجهة معلمات تجاوز المنطقة.
- تُتجاهل معلمات query غير المعروفة؛ استخدم فقط المعلمات المذكورة في هذه الصفحة.
