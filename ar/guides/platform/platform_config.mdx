---
title: "الحصول على إعدادات تشغيل منصة AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

قراءة مفاتيح تبديل الميزات العامة وحكم الدولة/المنطقة ضمن سياق الطلب الحالي. مناسب لتحديد ما إذا كان ينبغي عرض الميزات عند بدء تشغيل الواجهة الأمامية؛ وهو ليس العلامة التجارية للموقع أو معلومات الاتصال أو دليل الإعلانات.

## نظرة عامة على الواجهة

| البند   | المحتوى                                              |
| --- | ----------------------------------------------- |
| الطريقة  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| المصادقة  | عامة؛ عند حمل حالة تسجيل الدخول قد يتم حساب بعض مفاتيح تبديل الميزات حسب المستخدم                          |

## معلمات الاستعلام ورؤوس الطلب

| الاسم                    | الموقع     | الوصف                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | رمز دولة ASCII من حرفين؛ يُستخدم لتجاوز دولة العرض في الاستجابة، ولا يغيّر حكم الأمان على الخادم |
| `features`            | query  | تعبير تجاوز مفتاح تبديل الميزات؛ لا يسري إلا على المفاتيح المسموح للعميل بتجاوزها أو على المسؤولين الفائقين        |
| `X-Feature-Overrides` | header | مصدر تجاوز مماثل لـ `features`                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## بنية الاستجابة الفعلية

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| الحقل         | النوع            | الوصف                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | مفاتيح تبديل الميزات المرئية للطلب الحالي؛ تتغير المفاتيح وفقًا لإعدادات المنصة، ويجب على العميل قراءتها حسب الحاجة وتعيين قيم افتراضية آمنة للمفاتيح المفقودة |
| `country`  | string / null | رمز دولة بأحرف صغيرة؛ قد يكون `null` عند تعذر التعرف عليه                     |

لا تقرأ اسم الموقع أو CDN أو العملة أو اللغة أو معلومات اتصال خدمة العملاء أو الإعلانات من هذه الواجهة؛ فهذه الحقول لا تنتمي إلى عقد الاستجابة الحالي.

## توصيات الاستخدام

- تُحسب مفاتيح تبديل الميزات حسب المستخدم والبصمة وسياق الموقع، فلا تشارك ذاكرة التخزين المؤقت طويلة الأمد عبر المستخدمين.
- يؤثر `country` الذي يمرره العميل على القيمة المعادة فقط، ولن يتجاوز سياسات المنطقة أو الأمان على الخادم.
- يتم تجاهل معلمات query غير المعروفة؛ استخدم فقط المعلمات المدرجة في هذه الصفحة.
