[ChatBox](https://chatboxai.app/) هو عميل ذكاء اصطناعي مفتوح المصدر يدعم Windows وmacOS وLinux وiOS وAndroid والويب. وهو يدعم مزودي الخدمة المخصصين من نوع «OpenAI API»، لذلك يمكنه الاتصال مباشرة بـ Ace Data Cloud. يوضح هذا المقال عملية الإعداد.

## عملية التقديم

للاتصال بـ Ace Data Cloud في ChatBox، انتقل أولاً إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications)، واحصل على API Token الخاص بك، واحتفظ به للاستخدام لاحقًا.

![الحصول على Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد سجلت الدخول أو أنشأت حسابًا بعد، فسيتم تحويلك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وبعد التسجيل وتسجيل الدخول ستعود تلقائيًا إلى الصفحة الحالية.

عند التقديم لأول مرة، سيتم منحك رصيد مجاني، ويمكنك تجربة خدمات نماذج Ace Data Cloud مجانًا.

## تنزيل ChatBox

انتقل إلى [الموقع الرسمي لـ ChatBox](https://chatboxai.app/) لتنزيله حسب المنصة، أو استخدم مباشرة [إصدار الويب](https://web.chatboxai.app/) الذي لا يتطلب تثبيتًا:

- سطح المكتب: Windows `.exe`، وmacOS `.dmg` (مع التمييز بين Intel / Apple Silicon)، وLinux AppImage
- الأجهزة المحمولة: App Store، وGoogle Play، ورابط Android مباشر من الموقع الرسمي

## إعداد Ace Data Cloud

شغّل ChatBox، وانتقل إلى **الإعدادات → النموذج → إضافة Provider مخصص**، واضبط **API Mode** على **OpenAI API Compatible**، ثم املأ:

| الحقل       | القيمة                           | الوصف                                      |
| -------- | --------------------------- | --------------------------------------- |
| مفتاح API   | Token الخاص بك في Ace Data Cloud     | الـ Token المنسوخ من لوحة التحكم                            |
| API Host | `https://api.acedata.cloud` | املأ اسم النطاق الجذر فقط، **ولا تضف `/openai` أو `/v1`**         |
| API Path | `/v1/chat/completions`      | القيمة الافتراضية في ChatBox هي `/chat/completions`، ويجب تعديلها يدويًا إلى هذه القيمة |

![واجهة إعداد ChatBox Ace Data Cloud Provider](https://cdn.acedata.cloud/3789c8e3dd4d.png)

مسار طلب ChatBox هو `{API Host} + {API Path}`، لذلك يكفي ملء اسم النطاق الجذر في Host:

| API Host                              | الطلب النهائي                                                      | النتيجة                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | صحيح                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (لا يوجد `/v1` ضمن `/openai`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

لا يستدعي ChatBox تلقائيًا `/v1/models`، لذا يجب إدخال معرّفات النماذج يدويًا في مربع إدخال «النماذج المخصصة» أسفل صفحة إعدادات النموذج (واحد في كل سطر)، وبعد الحفظ يمكن اختيارها من القائمة المنسدلة للنماذج في واجهة المحادثة. يجب تعبئة مفاتيح القدرات ونافذة السياق والحد الأقصى للإخراج وفقًا للعقد الحالي للنموذج المحدد، ولا تنسخ قيم نماذج أخرى.

## اختيار النموذج

سيستمر تحديث دليل النماذج. استخدم قائمة النماذج التي يحمّلها العميل تلقائيًا أولاً؛ وعند الحاجة إلى الإدخال اليدوي، اطلب أولاً `GET https://api.acedata.cloud/v1/models` للحصول على معرّفات النماذج الحالية، ثم اختر وفقًا لقدرات السياق والصور واستدعاء الأدوات التي يدعمها العميل.

## التحقق من الاتصال

إذا لم تكن متأكدًا مما إذا كانت المشكلة في ChatBox أو في الشبكة، فيمكنك التحقق من نقطة النهاية مباشرةً باستخدام curl أولاً (استبدل `{token}` بـ Token الخاص بك):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

إن إرجاع كائن `chat.completion` متوافق مع OpenAI يعني أن كلًا من Token ونقطة النهاية جاهزان؛ وإذا أُرجع `HTTP 403 used_up` فهذا يعني أن Token صالح لكن الرصيد غير كافٍ، ويمكنك إعادة الشحن من [لوحة التحكم](https://platform.acedata.cloud/console/applications).

## الأسئلة الشائعة

### ظهور 404 Not Found

عادةً ما يكون السبب هو إضافة `/openai` أو `/v1` بشكل زائد إلى API Host. املأ فقط `https://api.acedata.cloud` في Host، واترك المسار الافتراضي `/v1/chat/completions`.

### ظهور 401 / token_mismatched

يرجى التأكد من أن ما تم لصقه في «مفتاح API» هو Token الخاص بـ Ace Data Cloud (من دون بادئة `Bearer` ومن دون مسافات زائدة)، وأن رصيد التطبيق التابع له كافٍ.

### لا تظهر النماذج في القائمة المنسدلة للنماذج

لا يجلب ChatBox قائمة النماذج تلقائيًا، ويجب إدخال معرّفات النماذج يدويًا وحفظها في مربع «النماذج المخصصة».

### تريد إنشاء صور في ChatBox

إن إنشاء الصور في Ace Data Cloud هو Images API مستقل (`/openai/images/generations`) بمسار مختلف عن واجهة المحادثة، ولا يمكن لمدخل الصور في ChatBox الاتصال به مباشرةً. إذا كنت بحاجة إلى إنشاء صور، فيرجى الرجوع إلى [وثائق API لإنشاء الصور](https://platform.acedata.cloud/documents/openai-images-generations) لاستدعائها باستخدام curl / SDK.
