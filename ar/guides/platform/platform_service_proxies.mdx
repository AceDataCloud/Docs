إرجاع نقاط نهاية Proxy المرتبطة بهذه الخدمة على صفحات عبر Service UUID. عند توفر alias فقط، استدعِ أولاً [تفاصيل الخدمة](https://platform.acedata.cloud/documents/platform-service-detail) للحصول على `id`.

## نظرة عامة على الواجهة

| البند   | المحتوى                                                                     |
| --- | ---------------------------------------------------------------------- |
| الطريقة  | `GET`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| المصادقة  | عامة، لا يلزم رمز حساب                                                              |
| الترقيم  | `count` + `items`                                                      |

## المعلمات

| المعلمة                 | الموقع    | مطلوب  | الوصف                               |
| ------------------ | ----- | --- | -------------------------------- |
| `service_id`       | path  | نعم   | Service UUID، لا يدعم alias           |
| `limit` / `offset` | query | لا   | الترقيم                               |
| `ordering`         | query | لا   | تعبير ترتيب Django؛ يُوصى بـ `rank` أو `-rank` |

```shell
export SERVICE_ID='معرّف Service الخاص بك'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## وصف الاستجابة

تُسلسل عناصر القائمة بواسطة نموذج Proxy، وتشمل الحقول التي تم التحقق منها عبر الإنترنت `id` و`service_id` و`title` و`endpoint` و`price` و`stage` و`rank` و`tags` و`metadata` و`document_id` و`service` وحقول الوقت.

- حقل مدخل الأعمال هو `endpoint`، وليس `path`.
- حقل التسعير هو `price`، وليس `cost`.
- إذا لم يكن نوع Service هو Proxy أو لم يتم ربط أي Proxy، فسيتم إرجاع `items` فارغاً.

تعتمد عمليات التكامل العامة فقط على `endpoint` والقدرات المنشورة، ويجب ألا تعتمد على تفاصيل التنفيذ غير العامة.
