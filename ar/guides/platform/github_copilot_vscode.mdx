تعتبر وثائق GitHub Copilot الرسمية الخاصة بـ BYOK أن VS Code هو عميل محلي مدعوم، ويدعم مزود متوافق مع OpenAI. ستؤثر إصدارات VS Code، والسياسات المؤسسية، ورؤية النموذج على نقطة النهاية النهائية؛ يرجى التحقق من الطلب الفعلي عند الاتصال لأول مرة كما هو موضح أدناه.

## نطاق التكوين

1. تأكد من أن حساب GitHub Copilot الخاص بك أو المنظمة قد قامت بتمكين ميزة BYOK/النماذج المخصصة.
2. أضف مزود متوافق مع OpenAI في إدارة نماذج Copilot في VS Code.
3. املأ عنوان URL الأساسي بـ `https://api.acedata.cloud/v1`.
4. املأ مفتاح API برمز Ace Data Cloud API الخاص بك.
5. املأ النموذج بمعرف النموذج الدقيق المتوافق مع البروتوكول المختار في دليل النماذج.
6. أرسل في دردشة Copilot `Reply only OK`، ثم اختبر مرة أخرى الطلب مع سياق مساحة العمل.

## الحدود الحالية

- تختلف عقود تكوين Copilot App وCLI وGitHub Desktop وEnterprise BYOK عن VS Code، ولا يتم تطبيق خطوات العملاء الآخرين مباشرة على VS Code في هذا الدليل.
- قد تمنع السياسات التنظيمية الأفراد من إضافة مزود أو نموذج.
- قد تستخدم إكمال التبويب والدردشة والوكيل والمهام الخلفية مسارات نماذج مختلفة، ويجب التحقق منها بشكل منفصل.
