احصل على الحالة الكاملة لطلب خدمة واحد عبر Application ID — يتضمن حقولًا إضافية مقارنةً بواجهة القائمة مثل كائن `service` الكامل (بما في ذلك باقات `packages`) وغيرها، وهو مناسب لصفحة التفاصيل.

> ℹ️ تنتمي هذه الواجهة إلى **واجهة API لإدارة منصة AceDataCloud**، وبادئتها الموحدة هي `https://platform.acedata.cloud/api/v1/`. راجع الفهرس الكامل للواجهات في [الحصول على قائمة وثائق منصة AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list).

## نظرة عامة على الواجهة

| البند   | المحتوى                                                                    |
| --- | --------------------------------------------------------------------- |
| الطريقة  | `GET`                                                                 |
| URL | `https://platform.acedata.cloud/api/v1/applications/{application_id}` |
| المصادقة  | ✅ يتطلب رمز حساب                                                              |

كلٌّ من `/applications/{id}` و`/applications/{id}/` متاح حاليًا؛ تستخدم الأمثلة بشكل موحّد الصيغة دون شرطة مائلة لاحقة.

## توضيح المصادقة (كيفية الحصول على رمز الحساب)

ترويسة الطلب:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

راجع طريقة الحصول التفصيلية في [إدارة رمز حساب منصة AceDataCloud](https://platform.acedata.cloud/documents/platform-token).

> ℹ️ بخلاف واجهة القائمة، **يتم التحقق من صلاحيات واجهة التفاصيل مباشرةً على الكائن الواحد**، ولا حاجة إلى تمرير `?user_id=`. ولكن إذا وصلت إلى طلب شخص آخر فستحصل على `403 permission_denied`.

## معلمات المسار

| المعلمة               | النوع   | مطلوب  | الوصف             |
| ---------------- | ---- | --- | -------------- |
| `application_id` | UUID | ✅   | Application ID |

## أمثلة الطلب

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/applications/82f57141-2323-4453-8730-60f7d833a2da' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

app_id = "82f57141-2323-4453-8730-60f7d833a2da"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/applications/{app_id}",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
app = resp.json()
print(f"服务：{app['service']['title']}")
print(f"剩余 {app['remaining_amount']} {app['service']['unit']} / 已用 {app['used_amount']}")
```

### Node.js

```javascript
const appId = '82f57141-2323-4453-8730-60f7d833a2da'
const r = await fetch(`https://platform.acedata.cloud/api/v1/applications/${appId}`, {
  headers: { authorization: `Bearer ${process.env.PLATFORM_TOKEN}` },
})
console.log(await r.json())
```

## توضيح حقول الاستجابة

معاني الحقول هي نفسها في [واجهة القائمة](https://platform.acedata.cloud/documents/platform-application-list)، مع احتوائها بالإضافة إلى ذلك على:

| الحقل        | النوع     | الوصف                                                        |
| --------- | ------ | --------------------------------------------------------- |
| `service` | object | كائن الخدمة الكامل (بما في ذلك باقات `packages` و`unit` و`free_amount`)؛ يمكنه عرض لوحة تفاصيل الخدمة مباشرةً |

## معالجة الأخطاء

| HTTP | code                | المعنى                  |
| ---- | ------------------- | ------------------- |
| 401  | `not_authenticated` | رمز الحساب مفقود              |
| 403  | `permission_denied` | هذا الـ Application لا يخصك  |
| 404  | `not_found`         | الـ Application غير موجود أو تم حذفه |

## نصائح عملية

- **استخدم القائمة أولًا للمراقبة المجمعة**: بعد جلب قائمة Application دفعة واحدة، احكم وفقًا لوحدات وعتبات كل خدمة، لتجنب طلب التفاصيل واحدًا تلو الآخر.
- **عند الحاجة إلى عرض عدد بيانات الاعتماد**: استخدم [قائمة بيانات اعتماد API](https://platform.acedata.cloud/documents/platform-credential-list) للتصفية حسب `application_id`.
- **نهج استكشاف `disabled=true` وإصلاحه**: تحقق من التذاكر / إشعارات البريد الإلكتروني لمعرفة ما إذا تم الإيقاف بسبب التحكم بالمخاطر أو المتأخرات أو الاستدعاءات المخالفة؛ لا يمكن رفعه عبر API، ويجب الاتصال بخدمة العملاء.
