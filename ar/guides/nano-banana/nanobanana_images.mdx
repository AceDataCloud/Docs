تقدم هذه المقالة تكامل واستخدام Nano Banana Images API. تدعم هذه الواجهة قدرتين: **توليد الصور (generate)** و**تحرير الصور (edit)**.

## عملية التقديم

لاستخدام Nano Banana Images API، انتقل أولاً إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications) للحصول على API Token الخاص بك، واحتفظ به للاستخدام لاحقاً.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد سجلت الدخول أو أنشأت حساباً بعد، فسيتم تحويلك تلقائياً إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وبعد الإكمال ستعود تلقائياً إلى الصفحة الحالية.

**يمكن استخدام API Token واحد لاستدعاء جميع خدمات المنصة، ولا حاجة للتقديم بشكل منفصل لكل خدمة.** سيمنحك أول طلب حصة مجانية لتجربة الخدمة مجاناً؛ وعندما لا تكفي الحصة، يمكنك شحن الرصيد العام في [لوحة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## نظرة عامة على الواجهة

- **Base URL**: `https://api.acedata.cloud`
- **Endpoint**: `POST /nano-banana/images`
- **طريقة المصادقة**: تضمين `authorization: Bearer {token}` في HTTP Header
- **رؤوس الطلب**:
  - `accept: application/json`
  - `content-type: application/json`
- **الإجراء (action)**:
  - `generate`: إنشاء صورة استناداً إلى وصف نصي
  - `edit`: إجراء تحرير استناداً إلى صورة محددة
- **النموذج (model)** (اختياري):
  - `nano-banana` (افتراضي): يستند إلى Gemini 2.5 Flash Image، سريع ومنخفض التكلفة
  - `nano-banana-2-lite`: يستند إلى Gemini 3.1 Flash Lite Image، يدعم 1K فقط، وسريع في التوليد
  - `nano-banana-2`: يستند إلى Gemini 3.1 Flash Image Preview، جودة بمستوى Pro + سرعة Flash
  - `nano-banana-2.1`: نموذج صور فعّال من الجيل الجديد، يدعم توليد الصور وتحريرها بدقة 1K و2K و4K
  - `nano-banana-pro`: يستند إلى Gemini 3 Pro Image Preview، بأعلى جودة
  - `nano-banana:official`، `nano-banana-2-lite:official`، `nano-banana-2:official`، `nano-banana-pro:official`: إصدارات القنوات الرسمية للنماذج المقابلة، بجودة صور واستقرار أفضل، وبآلية تسعير مختلفة
- **رد الاتصال غير المتزامن**: اختياري، استقبل إشعار اكتمال المهمة والنتيجة عبر `callback_url`
- **عدد الصور**: اختياري، حدد من 1 إلى 4 صور عبر `count`، والافتراضي صورة واحدة؛ تُنجز كل صورة عبر استدعاء توليد مستقل؛ لا يؤثر الفشل التقني العادي أو رفض الأمان من المزوّد إلا على الاستدعاء المقابل، وتُعاد الصور الناجحة الأخرى كالمعتاد، ويتم احتساب الرسوم وفقاً لعدد الصور الناجحة فعلياً

## البدء السريع: توليد الصور (`action=generate`)

**الحد الأدنى من المعلمات المطلوبة**: `action`، `prompt`
عندما تريد إنشاء صورة مباشرةً استناداً إلى الوصف فقط، اضبط `action` على `generate` وقدم `prompt` واضحاً.

### مثال طلب (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### مثال طلب (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### شرح الحقول

- `success`: ما إذا كان هذا الطلب ناجحاً.
- `task_id`: معرّف المهمة.
- `trace_id`: معرّف تتبع المسار، لتسهيل استكشاف المشكلات وإصلاحها.
- `count`: عدد الصور المطلوب توليدها أو تحريرها، يدعم من 1 إلى 4، والافتراضي 1. لا يحتوي `data` إلا على الصور التي تم توليدها بنجاح، وتُحتسب الرسوم وفقاً لعدد الصور المعادة فعلياً. يفرض كل استدعاء توليد سياسة الأمان الأصلية الخاصة بالمزوّد؛ رفض استدعاء معين لا يؤثر على الاستدعاءات الناجحة الأخرى، وعند رفض جميع الاستدعاءات تُعاد استجابة 403.
- `data[]`: قائمة النتائج.
  - `prompt`: الوصف المستخدم للتوليد (يُعاد عرضه).
  - `image_url`: رابط URL مباشر للصورة المُولدة.

> ملاحظة: يحتاج `/nano-banana/images` فقط إلى `action` و`prompt` لتوليد صورة

## تحرير الصور (`action=edit`)

عندما ترغب في التحرير استناداً إلى صورة موجودة، اضبط `action` على `edit`، ومرر قائمة روابط الصور المطلوب تحريرها (صورة واحدة أو أكثر) عبر `image_urls`، مع تقديم `prompt` يصف هدف التحرير.

على سبيل المثال، هنا نقدم صورة لشخص وصورة لملابس، ونريد أن يرتدي الشخص هذه الملابس، فيمكن تمرير روابط الصور في الوقت نفسه، وتحديد action على أنه `edit`، ويمكن أن يكون URL رابط HTTP، أو رابطاً متاحاً للعامة يبدأ ببروتوكول `https` أو `http`، أو صورة مشفرة بـ Base64، مثل `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### مثال طلب (cURL)
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### مثال الطلب (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

- `image_urls[]`: قائمة عناوين URL للصور المراد تحريرها (يجب أن تكون قابلة للوصول عبر الإنترنت العام). يمكن تمرير عدة صور، وستجمع الخدمة بين هذه المواد و`prompt` لإكمال التحرير.
- الحقول الأخرى هي نفسها الموجودة في إرجاع «توليد الصور».

## الاستدعاء غير المتزامن (اختياري، موصى به)

قد يستغرق التوليد أو التحرير بعض الوقت. لتجنب استهلاك الموارد بسبب الاتصالات الطويلة، يوصى باستخدام **استدعاء Webhook** عبر `callback_url`:

1. أضف `callback_url` إلى نص الطلب، مثل عنوان Webhook لخادمك (يجب أن يكون قابلاً للوصول عبر الإنترنت العام ويدعم POST JSON).
2. ستقوم واجهة API **بالإرجاع فورًا** باستجابة تتضمن `task_id` (أو تتضمن نتائج أساسية).
3. عند اكتمال المهمة، سترسل المنصة JSON الكامل إلى `callback_url` باستخدام `POST`. يمكنك ربط الطلب بالنتيجة من خلال `task_id`.

**مثال على حمولة الاستدعاء** (بنية الحقول متسقة مع الإرجاع الناجح المتزامن):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## معالجة الأخطاء

عند فشل الاستدعاء، سيتم إرجاع تنسيق خطأ قياسي ومعرّف تتبع. الأخطاء الشائعة كما يلي:

- **400 `token_mismatched`**: الطلب غير صالح أو توجد أخطاء في المعلمات.
- **400 `api_not_implemented`**: الواجهة غير مُنفذة (يرجى الاتصال بالدعم).
- **401 `invalid_token`**: فشلت المصادقة أو الرمز المميز مفقود.
- **403 `forbidden`**: رفضت سياسة الأمان الأصلية للمزوّد الطلب أو نتيجة التوليد. لن يُرجع هذا الاستدعاء صورة ولن يتم احتساب رسوم؛ وقد تظل طلبات الصور المتعددة تُرجع وتُحتسب رسوم للاستدعاءات الناجحة الأخرى.
- **429 `too_many_requests`**: تجاوز معدل الطلبات الحد المسموح.
- **500 `api_error`**: استثناء في جانب الخادم.

### مثال على استجابة الخطأ

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## مقارنة المعلمات والملاحظات

- **مطلوب**: `action`، `prompt`
- **خاص بالتحرير**: `image_urls` (مصفوفة، عنصر واحد على الأقل)
- **اختياري**: `model` (الافتراضي `nano-banana`، والخيارات هي `nano-banana-2-lite` و`nano-banana-2` و`nano-banana-2.1` و`nano-banana-pro`؛ باستثناء `nano-banana-2.1`، توجد أيضًا إصدارات قنوات رسمية مقابلة بـ `:official`)، `aspect_ratio` (نسبة العرض إلى الارتفاع، مثل `1:1` و`16:9`)، `resolution` (الدقة، مثل `1K` و`2K` و`4K`؛ يدعم `nano-banana-2-lite` `1K` فقط)، `callback_url` (للاستدعاءات غير المتزامنة)
- **Headers**: يجب توفير `authorization: Bearer {token}`؛ ويوصى بتعيين `accept` إلى `application/json`
- **إمكانية الوصول إلى الصور**: يجب أن تكون `image_urls` روابط مباشرة قابلة للوصول عبر الإنترنت العام (HTTP/HTTPS)، ويوصى باستخدام HTTPS
- **التكرار والتتبع**: احتفظ بـ `task_id` و`trace_id` لتسهيل استكشاف الأخطاء وإصلاحها وربط النتائج
