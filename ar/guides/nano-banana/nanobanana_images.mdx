يقدّم هذا المقال تكامل واستخدام Nano Banana Images API. تدعم هذه الواجهة قدرتين: **توليد الصور (generate)** و**تحرير الصور (edit)**.

## عملية التقديم

لاستخدام Nano Banana Images API، احصل أولاً على API Token الخاص بك من [وحدة تحكم Ace Data Cloud](https://platform.acedata.cloud/console/applications)، واحتفظ به للاستخدام لاحقًا.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

إذا لم تكن قد سجلت الدخول أو أنشأت حسابًا بعد، فسيتم توجيهك تلقائيًا إلى صفحة تسجيل الدخول لدعوتك إلى التسجيل وتسجيل الدخول، وبعد الإكمال ستعود تلقائيًا إلى الصفحة الحالية.

**يمكن لـ API Token واحد استدعاء جميع خدمات المنصة، ولا حاجة للتقديم بشكل منفصل لكل خدمة.** ستحصل على رصيد مجاني عند التقديم لأول مرة لتجربة الخدمة مجانًا؛ وعندما لا يكون الرصيد كافيًا، يمكنك شحن الرصيد العام من [وحدة التحكم](https://platform.acedata.cloud/console/coin).

> 📘 الوثائق الكاملة: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## نظرة عامة على الواجهة

- **Base URL**: `https://api.acedata.cloud`
- **Endpoint**: `POST /nano-banana/images`
- **طريقة المصادقة**: تضمين `authorization: Bearer {token}` في HTTP Header
- **رؤوس الطلب**:
  - `accept: application/json`
  - `content-type: application/json`
- **الإجراء (action)**:
  - `generate`: توليد صورة بناءً على نص التوجيه
  - `edit`: التحرير بناءً على صورة معطاة
- **النموذج (model)** (اختياري):
  - `nano-banana` (افتراضي): يستند إلى Gemini 2.5 Flash Image، سريع ومنخفض التكلفة
  - `nano-banana-2-lite`: يستند إلى Gemini 3.1 Flash Lite Image، يدعم 1K فقط وسريع في التوليد
  - `nano-banana-2`: يستند إلى Gemini 3.1 Flash Image Preview، جودة بمستوى Pro + سرعة Flash
  - `nano-banana-pro`: يستند إلى Gemini 3 Pro Image Preview، أعلى جودة
  - `nano-banana:official`، `nano-banana-2-lite:official`، `nano-banana-2:official`، `nano-banana-pro:official`: إصدارات القنوات الرسمية للنماذج المقابلة، بجودة صورة واستقرار أفضل، وفوترة مختلفة
- **رد الاتصال غير المتزامن**: اختياري، استقبل إشعارات اكتمال المهمة والنتائج عبر `callback_url`
- **عدد الصور**: اختياري، حدّد 1–4 صور عبر `count`، والافتراضي صورة واحدة؛ يتم إكمال كل صورة عبر استدعاء توليد مستقل؛ تؤثر حالات الفشل التقنية العادية أو الرفض الأمني من المزوّد في الاستدعاء المقابل فقط، بينما تُعاد الصور الناجحة الأخرى كالمعتاد، وتتم الفوترة وفقًا للعدد الفعلي للصور الناجحة

## البدء السريع: توليد الصور (`action=generate`)

**أقل المعلمات المطلوبة**: `action`، `prompt`  
عندما تريد فقط إنشاء صورة مباشرةً بناءً على نص التوجيه، عيّن `action` إلى `generate` وقدّم `prompt` واضحًا.

### مثال طلب (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### مثال طلب (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### وصف الحقول

- `success`: ما إذا كان هذا الطلب ناجحًا.
- `task_id`: معرّف المهمة.
- `trace_id`: معرّف تتبع السلسلة، لتسهيل استكشاف المشكلات وإصلاحها.
- `count`: عدد الصور المطلوب توليدها أو تحريرها، يدعم 1–4، والافتراضي 1. يحتوي `data` فقط على الصور التي تم توليدها بنجاح، وتتم الفوترة وفقًا للعدد الفعلي للصور المُعادة. يفرض كل استدعاء توليد استخدام سياسات الأمان الأصلية للمزوّد؛ ولا يؤثر رفض استدعاء معين في الاستدعاءات الناجحة الأخرى، وعند رفض جميع الاستدعاءات يتم إرجاع 403.
- `data[]`: قائمة النتائج.
  - `prompt`: نص التوجيه المستخدم للتوليد (إعادة عرض).
  - `image_url`: رابط URL مباشر للصورة المُولّدة.

> ملاحظة: يتطلب `/nano-banana/images` فقط `action` و`prompt` لتوليد صورة

## تحرير الصور (`action=edit`)

عندما تريد التحرير بناءً على صورة موجودة، عيّن `action` إلى `edit`، ومرّر قائمة روابط الصور المراد تحريرها (صورة واحدة أو عدة صور) عبر `image_urls`، مع تقديم `prompt` يصف هدف التحرير.

على سبيل المثال، هنا نوفر صورة لشخص وصورة لملابس، ولجعل الشخص يرتدي هذه الملابس، يمكن تمرير روابط الصور في الوقت نفسه وتحديد action على أنه `edit`. يمكن أن يكون URL هو HTTP URL، أي رابط يمكن الوصول إليه علنًا ببروتوكول `https` أو `http`، كما يمكن أن يكون صورة بترميز Base64، مثل `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### مثال طلب (cURL)
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### مثال طلب (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

- الحقول الأخرى مماثلة لإرجاع «إنشاء الصور».

## رد الاتصال غير المتزامن (اختياري، موصى به)

قد يستغرق الإنشاء أو التحرير بعض الوقت. لتجنب استهلاك الموارد بسبب الاتصالات الطويلة، يُوصى باستخدام **رد اتصال Webhook** عبر `callback_url`:

1. أضف `callback_url` إلى نص الطلب، مثل عنوان Webhook لخادمك (يجب أن يكون قابلاً للوصول من الإنترنت العام ويدعم POST JSON).
2. ستُرجع API **فورًا** استجابة تتضمن `task_id` (أو تتضمن نتيجة أساسية).
3. عند اكتمال المهمة، سترسل المنصة JSON الكامل إلى `callback_url` بطريقة `POST`. يمكنك ربط الطلب بالنتيجة عبر `task_id`.

**مثال على حمولة رد الاتصال** (بنية الحقول مماثلة للإرجاع الناجح المتزامن):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## معالجة الأخطاء

عند فشل الاستدعاء، سيتم إرجاع تنسيق خطأ قياسي ومعرّف تتبع. الأخطاء الشائعة كالتالي:

- **400 `token_mismatched`**: الطلب غير صالح أو توجد أخطاء في المعلمات.
- **400 `api_not_implemented`**: الواجهة غير مُنفذة (يرجى الاتصال بالدعم).
- **401 `invalid_token`**: فشلت المصادقة أو Token مفقود.
- **403 `forbidden`**: رفضت سياسة الأمان الأصلية للمزوّد الطلب أو نتيجة الإنشاء. لن يُرجع هذا الاستدعاء صورة ولن يتم احتساب رسوم؛ وقد تستمر الطلبات متعددة الصور في إرجاع واحتساب رسوم الاستدعاءات الناجحة الأخرى.
- **429 `too_many_requests`**: تجاوز معدل الطلبات الحد المسموح.
- **500 `api_error`**: استثناء في الخادم.

### مثال على استجابة الخطأ

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## مطابقة المعلمات والملاحظات

- **مطلوب**: `action`، `prompt`
- **خاص بالتحرير**: `image_urls` (مصفوفة، عنصر واحد على الأقل)
- **اختياري**: `model` (الافتراضي `nano-banana`، والخيارات هي `nano-banana-2-lite` و`nano-banana-2` و`nano-banana-pro`، أو إصدارات القنوات الرسمية المقابلة ذات `:official`)، `aspect_ratio` (نسبة العرض إلى الارتفاع، مثل `1:1` و`16:9`)، `resolution` (الدقة، مثل `1K` و`2K` و`4K`؛ يدعم `nano-banana-2-lite` `1K` فقط)، `callback_url` (لرد الاتصال غير المتزامن)
- **Headers**: يجب توفير `authorization: Bearer {token}`؛ ويُوصى بتعيين `accept` إلى `application/json`
- **إمكانية الوصول إلى الصور**: يجب أن تكون `image_urls` روابط مباشرة قابلة للوصول من الإنترنت العام (HTTP/HTTPS)، ويُوصى باستخدام HTTPS
- **التكرارية والتتبع**: احتفظ بـ `task_id` و`trace_id` لتسهيل استكشاف الأخطاء وربط النتائج
