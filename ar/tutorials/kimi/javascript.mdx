---
title: "كيمي جافا سكريبت بداية سريعة"
---

## مقدمة

كيمي هي خدمة دردشة ذكاء اصطناعي مقدمة من Ace Data Cloud، نموذج اللغة الكبير من سلسلة كيمي لوجه القمر المظلم. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام جافا سكريبت للاندماج السريع مع كيمي، وتحقيق وظائف مثل المحادثات متعددة الجولات، تعليمات النظام، الإخراج المتدفق، وضع إخراج JSON، وغيرها.

## المتطلبات المسبقة

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API
- بيئة Node.js 18+ أو متصفح حديث

## الاستخدام الأساسي

النقطة النهائية الرئيسية لاستدعاء API كيمي هي:

```
POST https://api.acedata.cloud/kimi/chat/completions
```

يستخدم هذا المثال نموذج `kimi-k2.5`.
النماذج المتاحة تشمل: `kimi-k2.5`، `kimi-k2-thinking-turbo`، `kimi-k2-thinking`، `kimi-k2-instruct-0905`.

مثال كامل على كود جافا سكريبت:

```javascript
const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "kimi-k2.5",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## معالجة الاستجابة

يوصى بفحص رمز حالة الاستجابة ومعالجة الأخطاء:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("تم الاتصال بنجاح:", result);
} else {
  console.error(`فشل الاتصال، رمز الحالة: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## تغليف Node.js

يوصى بتغليفه كدالة قابلة لإعادة الاستخدام:

```javascript
async function callKimi(data) {
  const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## معالجة الأخطاء

رموز الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|-------|
| 401 | فشل التوثيق، يرجى التحقق من رمز API |
| 403 | رصيد غير كافٍ أو لا توجد صلاحية للوصول |
| 429 | تجاوز معدل الطلبات |
| 500 | خطأ داخلي في الخادم |

## الخطوة التالية

- انتقل إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على رمز API
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعلمات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
