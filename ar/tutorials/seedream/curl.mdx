## مقدمة

Seedream هي خدمة صور AI مقدمة من Ace Data Cloud، نموذج توليد الصور Seedream من ByteDance. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام cURL لاستدعاء Seedream بسرعة لتحقيق وظائف مثل توليد الصور من النصوص، تحرير الصور، دقة متعددة، والتحكم في العلامة المائية.

## المتطلبات المسبقة

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على API Token
- بيئة طرفية مثبت عليها cURL

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء واجهة برمجة تطبيقات Seedream هي:

```
POST https://api.acedata.cloud/seedream/images
```

في هذا المثال يتم استخدام نموذج `doubao-seedream-4-0-250828`.
النماذج المتاحة تشمل: `doubao-seedream-4-5-251128`، `doubao-seedream-4-0-250828`، `doubao-seedream-3-0-t2i-250415`، `doubao-seededit-3-0-i2i-250628`.

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "قطة سيامية بيضاء تجلس على النافذة", "model": "doubao-seedream-4-0-250828", "size": "1K"}'
```

يرجى استبدال `YOUR_API_TOKEN` بالتوكن الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد الاستدعاء الناجح يتم إرجاع بيانات بصيغة JSON، على سبيل المثال:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "قطة سيامية بيضاء تجلس على النافذة", "model": "doubao-seedream-4-0-250828", "size": "1K"}' | jq .
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف                      |
|------------|----------------------------|
| 401        | فشل التوثيق، يرجى التحقق من API Token |
| 403        | رصيد غير كافٍ أو لا تملك صلاحية الوصول |
| 429        | تجاوز معدل الطلبات          |
| 500        | خطأ داخلي في الخادم         |

## الخطوة التالية

- توجه إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على API Token
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعلمات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
