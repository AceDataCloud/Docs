## مقدمة

Gemini هي خدمة دردشة AI مقدمة من Ace Data Cloud، نموذج اللغة الكبير من سلسلة Google Gemini. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام cURL لاستدعاء Gemini بسرعة، وتحقيق وظائف مثل المحادثات متعددة الجولات، تعليمات النظام، الإخراج المتدفق، وضع الإخراج JSON، وغيرها.

## المتطلبات المسبقة

- امتلاك حساب في [Ace Data Cloud](https://platform.acedata.cloud) والحصول على API Token
- وجود بيئة طرفية مثبت عليها cURL

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء Gemini API هي:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

في هذا المثال نستخدم نموذج `gemini-2.5-flash`.
النماذج المتاحة تشمل: `gemini-2.5-flash`، `gemini-2.5-pro`، `gemini-2.0-flash`، `gemini-3.0-pro`.

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/gemini/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gemini-2.5-flash", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد الاستدعاء الناجح، يتم إرجاع بيانات بصيغة JSON، مثل:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/gemini/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gemini-2.5-flash", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف                          |
|------------|-------------------------------|
| 401        | فشل التوثيق، يرجى التحقق من API Token |
| 403        | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429        | تجاوز معدل الطلبات             |
| 500        | خطأ داخلي في الخادم           |

## الخطوة التالية

- انتقل إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على API Token
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعلمات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكلفة
