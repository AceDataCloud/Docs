## مقدمة

Hailuo هي خدمة فيديو AI تقدمها Ace Data Cloud، نموذج توليد الفيديو MiniMax Hailuo. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام cURL لاستدعاء Hailuo بسرعة، وتحقيق وظائف مثل إنشاء الفيديو من النص، إنشاء الفيديو من الصور، ووضع المخرج.

## المتطلبات الأساسية

- امتلاك حساب في [Ace Data Cloud](https://platform.acedata.cloud) والحصول على API Token
- بيئة طرفية مثبت فيها cURL

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء Hailuo API هي:

```
POST https://api.acedata.cloud/hailuo/videos
```

في هذا المثال نستخدم نموذج `minimax-t2v`.
النماذج المتاحة تشمل: `minimax-i2v`، `minimax-t2v`، `minimax-i2v-director`.

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}'
```

يرجى استبدال `YOUR_API_TOKEN` بالتوكن الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد الاستدعاء الناجح يتم إرجاع بيانات بصيغة JSON، مثل:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}' | jq .
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|--------|
| 401 | فشل التوثيق، يرجى التحقق من API Token |
| 403 | الرصيد غير كافٍ أو لا توجد صلاحية للوصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |

## الخطوة التالية

- انتقل إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على API Token
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعلمات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
