---

## مقدمة

Midjourney هي خدمة صور ذكاء اصطناعي مقدمة من Ace Data Cloud، تولد صورًا باستخدام Midjourney AI. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام cURL لاستدعاء Midjourney بسرعة لتحقيق وظائف مثل تحويل النص إلى صورة، تحرير الصور، وصف الصور، تحويل الصور إلى فيديو، التحكم في Seed، والاستدعاء غير المتزامن.

## المتطلبات المسبقة

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API
- بيئة طرفية مثبت عليها cURL

## الاستخدام الأساسي

النقطة النهائية الرئيسية لاستدعاء Midjourney API هي:

```
POST https://api.acedata.cloud/midjourney/imagine
```

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}'
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد استدعاء ناجح، يتم إرجاع بيانات بصيغة JSON، مثل:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}' | jq .
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف                          |
|------------|-------------------------------|
| 401        | فشل التوثيق، يرجى التحقق من رمز API |
| 403        | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429        | تجاوز حد معدل الطلبات          |
| 500        | خطأ داخلي في الخادم            |

## الخطوة التالية

- توجه إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على رمز API
- اطلع على [وثائق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعلمات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
