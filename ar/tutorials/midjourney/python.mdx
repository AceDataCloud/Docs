## مقدمة

Midjourney هي خدمة صور AI مقدمة من Ace Data Cloud، توليد صور Midjourney AI. من خلال API موحد من Ace Data Cloud، يمكنك استخدام Python لدمج Midjourney بسرعة، وتحقيق وظائف مثل توليد الصور من النص، تحرير الصور، وصف الصور، توليد الفيديو من الصور، التحكم في Seed، والاستدعاء غير المتزامن.

## المتطلبات الأساسية

- امتلاك حساب [Ace Data Cloud](https://platform.acedata.cloud) والحصول على API Token
- بيئة Python 3.7 أو أعلى
- تثبيت مكتبة requests: `pip install requests`

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء Midjourney API هي:

```
POST https://api.acedata.cloud/midjourney/imagine
```

مثال كامل على كود Python:

```python
import requests

url = "https://api.acedata.cloud/midjourney/imagine"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "A serene Japanese garden with cherry blossoms",
    "action": "generate",
    "mode": "fast",
    "translation": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## معالجة الاستجابة

بعد الاستدعاء الناجح، تعيد API بيانات بصيغة JSON. يُنصح بفحص رمز حالة HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("تم الاستدعاء بنجاح:", result)
else:
    print(f"فشل الاستدعاء، رمز الحالة: {response.status_code}")
    print(response.text)
```

## الاستخدام المتقدم

لـ API التي تدعم المهام غير المتزامنة، يمكن الحصول على النتائج عبر عنوان URL للاستدعاء العكسي (callback):

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# سيتم دفع النتائج إلى خادمك عبر عنوان URL للاستدعاء العكسي
```

## معالجة الأخطاء

رموز الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|--------|
| 401 | فشل التوثيق، يرجى التحقق من API Token |
| 403 | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |

## نقاط نهاية أخرى

تقدم خدمة Midjourney أيضًا نقاط نهاية أخرى:

- `POST https://api.acedata.cloud/midjourney/seed`
- `POST https://api.acedata.cloud/midjourney/edits`
- `POST https://api.acedata.cloud/midjourney/videos`
- `POST https://api.acedata.cloud/midjourney/describe`
