---

## مقدمة

AI Chat هو خدمة دردشة ذكية تقدمها Ace Data Cloud، وهي خدمة حوار متعددة النماذج تعتمد على الذكاء الاصطناعي. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام cURL لاستدعاء AI Chat بسرعة، مما يتيح دعم نماذج متعددة، حوارات ذات حالة، وأدوار محددة مسبقًا.

## المتطلبات الأساسية

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على API Token
- وجود بيئة طرفية مثبت عليها cURL

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء API الخاص بـ AI Chat هي:

```
POST https://api.acedata.cloud/aichat/conversations
```

في هذا المثال نستخدم نموذج `gpt-4o`.
النماذج المتاحة تشمل: `gpt-4o`، `gpt-4`، `deepseek-r1`، `grok-3`.

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}'
```

يرجى استبدال `YOUR_API_TOKEN` بالتوكن الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد استدعاء ناجح، يتم إرجاع بيانات بصيغة JSON، على سبيل المثال:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق المخرجات:

```bash
curl -s -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}' | jq .
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف                      |
|------------|----------------------------|
| 401        | فشل التوثيق، يرجى التحقق من API Token |
| 403        | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429        | تجاوز معدل الطلبات المسموح به |
| 500        | خطأ داخلي في الخادم         |

## الخطوة التالية

- انتقل إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على API Token
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل للمعاملات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
