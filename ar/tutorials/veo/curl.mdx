title: "مقدمة سريعة لاستخدام Veo مع cURL"
---

## مقدمة

Veo هي خدمة فيديو AI تقدمها Ace Data Cloud، نموذج توليد الفيديو من Google Veo. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام cURL لاستدعاء Veo بسرعة لتحقيق وظائف مثل تحويل النص إلى فيديو، تحويل الصورة إلى فيديو، دقة 4K، ونسب متعددة.

## المتطلبات المسبقة

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API Token
- بيئة طرفية مثبت عليها cURL

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء واجهة برمجة تطبيقات Veo هي:

```
POST https://api.acedata.cloud/veo/videos
```

في هذا المثال نستخدم نموذج `veo3`.
النماذج المتاحة تشمل: `veo2`، `veo2-fast`، `veo3`، `veo3-fast`، `veo31`، `veo31-fast`.

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/veo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A coffee mug rotating slowly on a marble counter", "model": "veo3"}'
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد استدعاء ناجح، يتم إرجاع بيانات بصيغة JSON، مثل:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/veo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A coffee mug rotating slowly on a marble counter", "model": "veo3"}' | jq .
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|--------|
| 401 | فشل التوثيق، يرجى التحقق من API Token |
| 403 | رصيد غير كافٍ أو لا توجد صلاحية وصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |

## الخطوة التالية

- انتقل إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على API Token
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعلمات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
