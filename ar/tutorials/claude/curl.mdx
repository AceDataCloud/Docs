## مقدمة

Claude هو خدمة دردشة ذكاء اصطناعي مقدمة من Ace Data Cloud، وهو جزء من سلسلة نماذج اللغة الكبيرة Anthropic Claude. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام cURL لاستدعاء Claude بسرعة، وتحقيق محادثات متعددة الأدوار، وإعداد تعليمات النظام، والإخراج التدريجي، ووضع إخراج JSON وغيرها من الميزات.

## المتطلبات المسبقة

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API Token
- وجود بيئة طرفية مثبت عليها cURL

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء واجهة Claude API هي:

```
POST https://api.acedata.cloud/v1/chat/completions
```

في هذا المثال نستخدم نموذج `claude-sonnet-4-6`.
النماذج المتاحة تشمل: `claude-sonnet-4-6`، `claude-opus-4-5-20251101`، `claude-3-5-sonnet`.

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-6", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد استدعاء ناجح، يتم إرجاع بيانات بصيغة JSON، مثل:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-6", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|--------|
| 401        | فشل التوثيق، يرجى التحقق من API Token |
| 403        | رصيد غير كافٍ أو لا تملك صلاحية الوصول |
| 429        | تجاوز معدل الطلبات المسموح به |
| 500        | خطأ داخلي في الخادم |

## الخطوة التالية

- توجه إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على API Token
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لمعرفة شرح كامل للمعاملات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
