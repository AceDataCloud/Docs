## مقدمة

Grok هو خدمة دردشة AI مقدمة من Ace Data Cloud، وهو جزء من سلسلة نماذج اللغة الكبيرة xAI Grok. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام Python لدمج Grok بسرعة، وتحقيق محادثات متعددة الأدوار، وإعدادات نظام التوجيه، والإخراج التدريجي، ووضع إخراج JSON، والفهم البصري، وغيرها من الوظائف.

## المتطلبات المسبقة

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API
- بيئة Python 3.7 أو أعلى
- تثبيت مكتبة requests: `pip install requests`

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء Grok API هي:

```
POST https://api.acedata.cloud/grok/chat/completions
```

في هذا المثال نستخدم نموذج `grok-3`.
النماذج المتاحة تشمل: `grok-4`، `grok-4-1-fast`، `grok-3`، `grok-3-mini`، `grok-2-vision`.

مثال كامل على كود Python:

```python
import requests

url = "https://api.acedata.cloud/grok/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "grok-3",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## معالجة الاستجابة

بعد استدعاء ناجح، تعيد API بيانات بصيغة JSON. يُنصح بالتحقق من رمز حالة HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("تم الاستدعاء بنجاح:", result)
else:
    print(f"فشل الاستدعاء، رمز الحالة: {response.status_code}")
    print(response.text)
```

## الاستخدام المتقدم

بالنسبة لواجهات API الخاصة بالدردشة، يتم دعم الإخراج التدريجي للحصول على استجابة في الوقت الحقيقي:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## معالجة الأخطاء

رموز الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|--------|
| 401 | فشل التوثيق، يرجى التحقق من رمز API |
| 403 | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429 | تجاوز معدل الطلبات |
| 500 | خطأ داخلي في الخادم |
