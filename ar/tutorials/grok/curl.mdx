---

## مقدمة

Grok هو خدمة دردشة ذكاء اصطناعي تقدمها Ace Data Cloud، وهو جزء من سلسلة نماذج اللغة الكبيرة xAI Grok. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام cURL لاستدعاء Grok بسرعة، وتحقيق محادثات متعددة الجولات، وإعدادات توجيه النظام، والإخراج التدريجي، ووضع إخراج JSON، وفهم بصري، وغيرها من الميزات.

## المتطلبات المسبقة

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API Token
- وجود بيئة طرفية مثبت عليها cURL

## الاستخدام الأساسي

النقطة النهائية الرئيسية لاستدعاء Grok API هي:

```
POST https://api.acedata.cloud/grok/chat/completions
```

في هذا المثال نستخدم نموذج `grok-3`.
النماذج المتاحة تشمل: `grok-4`، `grok-4-1-fast`، `grok-3`، `grok-3-mini`، `grok-2-vision`.

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/grok/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "grok-3", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد استدعاء ناجح، يتم إرجاع بيانات بصيغة JSON، مثل:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/grok/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "grok-3", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## معالجة الأخطاء

رموز الأخطاء الشائعة:

| رمز الحالة | الوصف                         |
|------------|------------------------------|
| 401        | فشل التوثيق، يرجى التحقق من API Token |
| 403        | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429        | تجاوز معدل الطلبات المسموح به |
| 500        | خطأ داخلي في الخادم          |

## الخطوة التالية

- انتقل إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على API Token
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعلمات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
