## مقدمة

Grok هو خدمة دردشة AI مقدمة من Ace Data Cloud، وهو جزء من سلسلة نماذج اللغة الكبيرة xAI Grok. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام JavaScript لدمج Grok بسرعة، وتحقيق وظائف مثل المحادثات متعددة الجولات، وإرشادات النظام، والإخراج المتدفق، ووضع إخراج JSON، والفهم البصري.

## المتطلبات الأساسية

- امتلاك حساب في [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API
- بيئة Node.js 18+ أو متصفح حديث

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء واجهة برمجة تطبيقات Grok هي:

```
POST https://api.acedata.cloud/grok/chat/completions
```

يستخدم هذا المثال نموذج `grok-3`.
النماذج المتاحة تشمل: `grok-4`، `grok-4-1-fast`، `grok-3`، `grok-3-mini`، `grok-2-vision`.

مثال كامل على كود JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/grok/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "grok-3",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## معالجة الاستجابة

يوصى بفحص رمز حالة الاستجابة ومعالجة الأخطاء:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("تم الاتصال بنجاح:", result);
} else {
  console.error(`فشل الاتصال، رمز الحالة: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## تغليف Node.js

يوصى بتغليفه كدالة قابلة لإعادة الاستخدام:

```javascript
async function callGrok(data) {
  const response = await fetch("https://api.acedata.cloud/grok/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|--------|
| 401 | فشل التوثيق، يرجى التحقق من رمز API |
| 403 | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |

## الخطوة التالية
