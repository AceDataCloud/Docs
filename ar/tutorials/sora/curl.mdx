## مقدمة

Sora هي خدمة فيديو AI مقدمة من Ace Data Cloud، نموذج توليد الفيديو OpenAI Sora. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام cURL لاستدعاء Sora بسرعة، وتحقيق وظائف مثل إنشاء الفيديو من النص، وأطوال متعددة، ووضعيات أفقية وعمودية، والتحكم في الشخصيات، وصور مرجعية وغيرها.

## المتطلبات المسبقة

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API
- بيئة طرفية مثبت عليها cURL

## الاستخدام الأساسي

النقطة النهائية الرئيسية لاستدعاء واجهة برمجة تطبيقات Sora هي:

```
POST https://api.acedata.cloud/sora/videos
```

في هذا المثال نستخدم نموذج `sora-2`.
النماذج المتاحة تشمل: `sora-2`، `sora-2-pro`.

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}'
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد الاستدعاء الناجح يتم إرجاع بيانات بصيغة JSON، مثل:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}' | jq .
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|-------|
| 401 | فشل التوثيق، يرجى التحقق من رمز API |
| 403 | الرصيد غير كافٍ أو لا يوجد صلاحية للوصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |

## الخطوة التالية

- انتقل إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على رمز API
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعاملات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
