## مقدمة

Kling هو خدمة فيديو AI مقدمة من Ace Data Cloud، وهو نموذج توليد فيديو سريع. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام cURL لاستدعاء Kling بسرعة لتحقيق وظائف مثل تحويل النص إلى فيديو، تحويل الصورة إلى فيديو، استكمال الفيديو، بأطوال ونسب متعددة.

## المتطلبات المسبقة

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API
- وجود بيئة طرفية مثبت عليها cURL

## الاستخدام الأساسي

النقطة النهائية الرئيسية لاستدعاء API الخاصة بـ Kling هي:

```
POST https://api.acedata.cloud/kling/videos
```

في هذا المثال نستخدم نموذج `kling-v2-5-turbo`.
النماذج المتاحة تشمل: `kling-v1`، `kling-v1-6`، `kling-v2-master`، `kling-v2-1-master`، `kling-v2-5-turbo`، `kling-video-o1`.

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/kling/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A white cat walking in the snow", "model": "kling-v2-5-turbo", "duration": 5, "aspect_ratio": "16:9"}'
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد الاستدعاء الناجح، يتم إرجاع بيانات بصيغة JSON، مثل:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/kling/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A white cat walking in the snow", "model": "kling-v2-5-turbo", "duration": 5, "aspect_ratio": "16:9"}' | jq .
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|--------|
| 401 | فشل التوثيق، يرجى التحقق من رمز API |
| 403 | الرصيد غير كافٍ أو لا يوجد صلاحية وصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |

## الخطوة التالية

- انتقل إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على رمز API
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم المعلمات الكاملة
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
