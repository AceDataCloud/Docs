title: "مقدمة سريعة لـ OpenAI جافا سكريبت"
---

## مقدمة

OpenAI هي خدمة دردشة AI مقدمة من Ace Data Cloud، تعتمد على سلسلة نماذج اللغة الكبيرة GPT من OpenAI. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك دمج OpenAI بسرعة باستخدام جافا سكريبت لتحقيق وظائف مثل المحادثات متعددة الجولات، تعليمات النظام، الإخراج المتدفق، وضع الإخراج JSON، تضمين النصوص، توليد الصور، وغيرها.

## المتطلبات المسبقة

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API
- Node.js 18+ أو بيئة متصفح حديثة

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء OpenAI API هي:

```
POST https://api.acedata.cloud/openai/chat/completions
```

في هذا المثال نستخدم نموذج `gpt-4o`.
النماذج المتاحة تشمل: `gpt-4o`، `gpt-4o-mini`، `o1`، `o3-mini`.

مثال كامل على كود جافا سكريبت:

```javascript
const response = await fetch("https://api.acedata.cloud/openai/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "gpt-4o",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## معالجة الاستجابة

يوصى بفحص رمز حالة الاستجابة ومعالجة الأخطاء:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("تم الاتصال بنجاح:", result);
} else {
  console.error(`فشل الاتصال، رمز الحالة: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## تغليف Node.js

يوصى بتغليفه كدالة قابلة لإعادة الاستخدام:

```javascript
async function callOpenAI(data) {
  const response = await fetch("https://api.acedata.cloud/openai/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|--------|
| 401 | فشل التوثيق، يرجى التحقق من رمز API |
| 403 | الرصيد غير كافٍ أو لا يوجد إذن بالوصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |

## الخطوة التالية

- انتقل إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على رمز API
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعاملات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
