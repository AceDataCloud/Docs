---

## مقدمة

OpenAI هو خدمة دردشة ذكاء اصطناعي مقدمة من Ace Data Cloud، تعتمد على سلسلة نماذج اللغة الكبيرة GPT من OpenAI. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام cURL لاستدعاء OpenAI بسرعة، وتحقيق محادثات متعددة الجولات، وإعدادات تعليمات النظام، والإخراج التدريجي، ووضع إخراج JSON، وتضمين النصوص، وتوليد الصور، وغيرها من الوظائف.

## المتطلبات المسبقة

- امتلاك حساب في [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API Token
- وجود بيئة طرفية مثبت عليها cURL

## الاستخدام الأساسي

النقطة النهائية الرئيسية لاستدعاء API الخاص بـ OpenAI هي:

```
POST https://api.acedata.cloud/openai/chat/completions
```

في هذا المثال، نستخدم نموذج `gpt-4o`.
النماذج المتاحة تشمل: `gpt-4o`، `gpt-4o-mini`، `o1`، `o3-mini`.

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد الاستدعاء الناجح، يتم إرجاع بيانات بصيغة JSON، مثل:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|-------|
| 401 | فشل التوثيق، يرجى التحقق من API Token |
| 403 | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |

## الخطوة التالية

- توجه إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على API Token
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعلمات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
