---

## مقدمة

بحث Google هو خدمة بحث تقدمها Ace Data Cloud، وهي واجهة برمجة التطبيقات الخاصة ببحث Google. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك دمج بحث Google بسرعة باستخدام جافا سكريبت لتحقيق وظائف مثل البحث في الويب، البحث عن الصور، البحث في الأخبار، البحث في الخرائط، البحث عن الفيديوهات، وغيرها.

## المتطلبات المسبقة

- امتلاك حساب في [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API
- بيئة Node.js 18+ أو متصفح حديث

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء واجهة برمجة تطبيقات بحث Google هي:

```
POST https://api.acedata.cloud/serp/google
```

مثال كامل على كود جافا سكريبت:

```javascript
const response = await fetch("https://api.acedata.cloud/serp/google", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "query": "artificial intelligence latest news",
  "type": "search",
  "number": 10,
  "language": "en",
  "country": "US"
}),
});

const result = await response.json();
console.log(result);
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## معالجة الاستجابة

يوصى بفحص رمز حالة الاستجابة ومعالجة الأخطاء:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("تم الاستدعاء بنجاح:", result);
} else {
  console.error(`فشل الاستدعاء، رمز الحالة: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## تغليف Node.js

يوصى بتغليفه كدالة قابلة لإعادة الاستخدام:

```javascript
async function callGoogleSearch(data) {
  const response = await fetch("https://api.acedata.cloud/serp/google", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## معالجة الأخطاء

رموز الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|-------|
| 401 | فشل التوثيق، يرجى التحقق من رمز API |
| 403 | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |

## الخطوة التالية

- توجه إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على رمز API
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعلمات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
