---
title: "مقدمة سريعة لاستخدام Google Search مع cURL"
---

## مقدمة

Google Search هي خدمة بحث تقدمها Ace Data Cloud، وهي واجهة برمجة تطبيقات Google Search. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام cURL لاستدعاء Google Search بسرعة، وتنفيذ وظائف مثل البحث في الويب، البحث عن الصور، البحث في الأخبار، البحث في الخرائط، والبحث عن الفيديوهات.

## المتطلبات المسبقة

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API Token
- وجود بيئة طرفية مثبت عليها cURL

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء Google Search API هي:

```
POST https://api.acedata.cloud/serp/google
```

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}'
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد الاستدعاء الناجح، يتم إرجاع بيانات بصيغة JSON، مثل:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}' | jq .
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|--------|
| 401 | فشل التوثيق، يرجى التحقق من API Token |
| 403 | الرصيد غير كافٍ أو لا يوجد إذن بالوصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |

## الخطوة التالية

- انتقل إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على API Token
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعاملات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
