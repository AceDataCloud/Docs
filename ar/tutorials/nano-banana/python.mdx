## مقدمة

نانو بانانا هو خدمة صور AI مقدمة من Ace Data Cloud، تعتمد على خدمة توليد الصور Gemini. من خلال واجهة API الموحدة لـ Ace Data Cloud، يمكنك استخدام بايثون لدمج نانو بانانا بسرعة، وتحقيق وظائف مثل إنشاء الصور من النصوص، تحرير الصور، نسب متعددة، ودقة عالية.

## المتطلبات المسبقة

- امتلاك حساب في [Ace Data Cloud](https://platform.acedata.cloud) والحصول على API Token
- بيئة بايثون 3.7 أو أعلى
- تثبيت مكتبة requests: `pip install requests`

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء Nano Banana API هي:

```
POST https://api.acedata.cloud/nano-banana/images
```

في هذا المثال نستخدم نموذج `nano-banana-2`.
النماذج المتاحة تشمل: `nano-banana`، `nano-banana-2`، `nano-banana-pro`.

مثال كامل على كود بايثون:

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A white siamese cat",
    "model": "nano-banana-2",
    "aspect_ratio": "1:1"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

يرجى استبدال `YOUR_API_TOKEN` بالتوكن الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## معالجة الاستجابة

عند نجاح الاستدعاء، تعيد API بيانات بصيغة JSON. يُنصح بفحص رمز الحالة HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("تم الاستدعاء بنجاح:", result)
else:
    print(f"فشل الاستدعاء، رمز الحالة: {response.status_code}")
    print(response.text)
```

## الاستخدام المتقدم

بالنسبة للـ API التي تدعم المهام غير المتزامنة، يمكن الحصول على النتائج عبر عنوان URL للنداء العكسي (callback):

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# سيتم إرسال النتائج إلى خادمك عبر عنوان URL للنداء العكسي
```

## معالجة الأخطاء

رموز الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|--------|
| 401 | فشل التوثيق، يرجى التحقق من API Token |
| 403 | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |

## نقاط نهاية أخرى

توفر خدمة Nano Banana أيضًا نقاط نهاية أخرى:

- `POST https://api.acedata.cloud/nano-banana/tasks`
