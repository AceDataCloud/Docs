## مقدمة

Fish TTS هي خدمة صوتية بالذكاء الاصطناعي تقدمها Ace Data Cloud، وهي خدمة تحويل النص إلى كلام Fish. من خلال API موحد من Ace Data Cloud، يمكنك دمج Fish TTS بسرعة باستخدام بايثون لتحقيق تحويل النص إلى كلام، أصوات متعددة، تخصيص الصوت، وغيرها من الميزات.

## المتطلبات المسبقة

- امتلاك حساب في [Ace Data Cloud](https://platform.acedata.cloud) والحصول على API Token
- بيئة بايثون 3.7 أو أعلى
- تثبيت مكتبة requests: `pip install requests`

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء Fish TTS API هي:

```
POST https://api.acedata.cloud/fish/audios
```

في هذا المثال نستخدم نموذج `fish-tts`.
النماذج المتاحة تشمل: `fish-tts`.

مثال كامل على كود بايثون:

```python
import requests

url = "https://api.acedata.cloud/fish/audios"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "speech",
    "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务",
    "voice_id": "d7900c21663f485ab63ebdb7e5905036",
    "model": "fish-tts"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

يرجى استبدال `YOUR_API_TOKEN` بالتوكن الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## معالجة الاستجابة

بعد استدعاء ناجح، تعيد الـ API بيانات بصيغة JSON. يُنصح بالتحقق من رمز حالة HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("تم الاستدعاء بنجاح:", result)
else:
    print(f"فشل الاستدعاء، رمز الحالة: {response.status_code}")
    print(response.text)
```

## الاستخدام المتقدم

لـ API التي تدعم المهام غير المتزامنة، يمكن الحصول على النتائج عبر عنوان URL للنداء العكسي (callback):

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# سيتم دفع النتائج إلى خادمك عبر عنوان URL للنداء العكسي
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|-------|
| 401 | فشل التوثيق، يرجى التحقق من API Token |
| 403 | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |

## نقاط نهاية أخرى

تقدم خدمة Fish TTS أيضًا نقاط نهاية أخرى:

- `POST https://api.acedata.cloud/fish/voices`
- `POST https://api.acedata.cloud/fish/tasks`
