title: "بدء سريع مع Identity cURL"
---

## مقدمة

Identity هي خدمة التحقق من الهوية التي تقدمها Ace Data Cloud، للتحقق من الهوية باستخدام بطاقة الهوية/بطاقة البنك/رقم الهاتف المحمول. من خلال API موحد من Ace Data Cloud، يمكنك استخدام cURL لاستدعاء Identity بسرعة، لتحقيق وظائف مثل OCR لبطاقة الهوية، التحقق من بطاقة الهوية، التحقق من بطاقة البنك، والتحقق من رقم الهاتف المحمول.

## المتطلبات المسبقة

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على API Token
- وجود بيئة طرفية مثبت فيها cURL

## الاستخدام الأساسي

النقطة النهائية الرئيسية لاستدعاء Identity API هي:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}'
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد الاستدعاء الناجح، يتم إرجاع بيانات بصيغة JSON، مثل:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}' | jq .
```

## معالجة الأخطاء

رموز الأخطاء الشائعة:

| رمز الحالة | الوصف                     |
|------------|---------------------------|
| 401        | فشل التوثيق، يرجى التحقق من API Token |
| 403        | رصيد غير كافٍ أو لا توجد صلاحية للوصول |
| 429        | تجاوز معدل الطلبات المسموح به |
| 500        | خطأ داخلي في الخادم       |

## الخطوة التالية

- توجه إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على API Token
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعلمات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
