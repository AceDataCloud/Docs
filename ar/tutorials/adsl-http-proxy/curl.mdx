---

## مقدمة

وكيل HTTP ADSL هو خدمة وكيل شبكة مقدمة من Ace Data Cloud لاستخراج عناوين IP الديناميكية عبر ADSL. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام cURL لاستدعاء وكيل HTTP ADSL بسرعة، وتحقيق وظائف مثل وكيل HTTP/SOCKS، متعدد مزودي الخدمة، متعدد المحافظات، مدة مخصصة، وقائمة بيضاء لعناوين IP.

## المتطلبات المسبقة

- امتلاك حساب في [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API Token
- بيئة طرفية مثبت عليها cURL

## الاستخدام الأساسي

النقطة النهائية الرئيسية لاستدعاء API لوكيل HTTP ADSL هي:

```
POST https://api.acedata.cloud/adsl/extract
```

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}'
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد استدعاء ناجح، يتم إرجاع بيانات بصيغة JSON، مثل:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}' | jq .
```

## معالجة الأخطاء

رموز الأخطاء الشائعة:

| رمز الحالة | الوصف                   |
|------------|-------------------------|
| 401        | فشل التوثيق، يرجى التحقق من API Token |
| 403        | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429        | تجاوز معدل الطلبات المسموح به |
| 500        | خطأ داخلي في الخادم    |

## الخطوة التالية

- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
