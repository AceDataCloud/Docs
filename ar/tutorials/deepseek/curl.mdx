---

## مقدمة

DeepSeek هو خدمة دردشة ذكاء اصطناعي تقدمها Ace Data Cloud، وهو جزء من سلسلة نماذج اللغة الكبيرة DeepSeek. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام cURL لاستدعاء DeepSeek بسرعة، وتحقيق محادثات متعددة الجولات، وإعداد تعليمات النظام، والإخراج التدريجي، ووضع الإخراج بصيغة JSON، والاستدلال العميق، وغيرها من الميزات.

## المتطلبات الأساسية

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API Token
- وجود بيئة طرفية مثبت بها cURL

## الاستخدام الأساسي

النقطة النهائية الرئيسية لاستدعاء DeepSeek API هي:

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

في هذا المثال، نستخدم نموذج `deepseek-r1`.
النماذج المتاحة تشمل: `deepseek-r1`، `deepseek-r1-0528`، `deepseek-v3`، `deepseek-v3-250324`.

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/deepseek/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-r1", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

عند الاستدعاء الناجح، يتم إرجاع بيانات بصيغة JSON، مثل:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/deepseek/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-r1", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|--------|
| 401 | فشل التوثيق، يرجى التحقق من API Token |
| 403 | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |

## الخطوة التالية

- انتقل إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على API Token
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعلمات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
