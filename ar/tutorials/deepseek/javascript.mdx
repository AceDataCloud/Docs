## مقدمة

DeepSeek هي خدمة دردشة AI تقدمها Ace Data Cloud، وهي جزء من سلسلة نماذج اللغة الكبيرة DeepSeek. من خلال واجهة برمجة التطبيقات الموحدة لـ Ace Data Cloud، يمكنك استخدام JavaScript لدمج DeepSeek بسرعة، وتحقيق وظائف مثل المحادثات متعددة الجولات، وإرشادات النظام، والإخراج التدريجي، ووضع إخراج JSON، والاستدلال العميق.

## المتطلبات المسبقة

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API Token
- بيئة Node.js 18+ أو متصفح حديث

## الاستخدام الأساسي

النقطة النهائية الرئيسية لاستدعاء واجهة برمجة تطبيقات DeepSeek هي:

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

في هذا المثال، نستخدم نموذج `deepseek-r1`.
النماذج المتاحة تشمل: `deepseek-r1`، `deepseek-r1-0528`، `deepseek-v3`، `deepseek-v3-250324`.

مثال كامل على كود JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/deepseek/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "deepseek-r1",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## معالجة الاستجابة

يوصى بفحص رمز حالة الاستجابة ومعالجة الأخطاء:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("تم الاستدعاء بنجاح:", result);
} else {
  console.error(`فشل الاستدعاء، رمز الحالة: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## تغليف Node.js

يوصى بتغليفه كدالة قابلة لإعادة الاستخدام:

```javascript
async function callDeepSeek(data) {
  const response = await fetch("https://api.acedata.cloud/deepseek/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`خطأ في API: ${response.status}`);
  return response.json();
}
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|-------|
| 401        | فشل التوثيق، يرجى التحقق من API Token |
| 403        | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429        | تجاوز معدل الطلبات المسموح به |
| 500        | خطأ داخلي في الخادم |

## الخطوة التالية

- توجه إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على API Token
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعلمات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
