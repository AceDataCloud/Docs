## مقدمة

Flux هو خدمة صور AI تقدمها Ace Data Cloud، وهو نموذج توليد الصور من Black Forest Labs Flux. من خلال API موحد من Ace Data Cloud، يمكنك استخدام Python لدمج Flux بسرعة، وتحقيق وظائف مثل توليد الصور من النصوص، تحرير الصور، نماذج متعددة، وأحجام مخصصة.

## المتطلبات المسبقة

- امتلاك حساب في [Ace Data Cloud](https://platform.acedata.cloud) والحصول على رمز API Token
- بيئة Python 3.7 أو أعلى
- تثبيت مكتبة requests: `pip install requests`

## الاستخدام الأساسي

النقطة النهائية الرئيسية لاستدعاء Flux API هي:

```
POST https://api.acedata.cloud/flux/images
```

في هذا المثال نستخدم نموذج `flux-pro-1.1`.
النماذج المتاحة تشمل: `flux-dev`، `flux-pro`، `flux-pro-1.1`، `flux-pro-1.1-ultra`، `flux-kontext-pro`، `flux-kontext-max`.

مثال كامل على كود Python:

```python
import requests

url = "https://api.acedata.cloud/flux/images"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A white siamese cat sitting on a windowsill",
    "model": "flux-pro-1.1",
    "size": "1024x1024"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## معالجة الاستجابة

بعد استدعاء ناجح، تعيد API بيانات بصيغة JSON. يُنصح بالتحقق من رمز حالة HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("تم الاستدعاء بنجاح:", result)
else:
    print(f"فشل الاستدعاء، رمز الحالة: {response.status_code}")
    print(response.text)
```

## الاستخدام المتقدم

بالنسبة للـ API التي تدعم المهام غير المتزامنة، يمكن الحصول على النتائج عبر URL رد الاتصال (callback):

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# سيتم دفع النتائج إلى خادمك عبر URL رد الاتصال
```

## معالجة الأخطاء

رموز الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|-------|
| 401 | فشل التوثيق، يرجى التحقق من API Token |
| 403 | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |
