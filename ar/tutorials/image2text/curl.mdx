## مقدمة

Image2Text هي خدمة التحقق من الرموز المرئية (Captcha) التي تقدمها Ace Data Cloud، والتي تقوم بالتعرف على رموز التحقق في الصور. من خلال API موحد من Ace Data Cloud، يمكنك استخدام cURL لاستدعاء Image2Text بسرعة، وتحقيق التعرف على رموز التحقق في الصور، وإدخال Base64، وإدخال URL وغيرها من الوظائف.

## المتطلبات الأساسية

- امتلاك حساب على [Ace Data Cloud](https://platform.acedata.cloud) والحصول على API Token
- وجود بيئة طرفية مثبت عليها cURL

## الاستخدام الأساسي

نقطة النهاية الرئيسية لاستدعاء Image2Text API هي:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

مثال كامل لأمر cURL:

```bash
curl -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}'
```

يرجى استبدال `YOUR_API_TOKEN` بالرمز الفعلي الذي حصلت عليه من منصة Ace Data Cloud.

## مثال على الاستجابة

بعد الاستدعاء الناجح يتم إرجاع بيانات بصيغة JSON، مثل:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## استخدام jq لمعالجة الاستجابة

يوصى باستخدام أداة jq لتنسيق الإخراج:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}' | jq .
```

## معالجة الأخطاء

أكواد الأخطاء الشائعة:

| رمز الحالة | الوصف |
|------------|--------|
| 401 | فشل التوثيق، يرجى التحقق من API Token |
| 403 | رصيد غير كافٍ أو عدم وجود صلاحية الوصول |
| 429 | تجاوز معدل الطلبات المسموح به |
| 500 | خطأ داخلي في الخادم |

## الخطوة التالية

- توجه إلى [لوحة تحكم Ace Data Cloud](https://platform.acedata.cloud) للحصول على API Token
- اطلع على [توثيق API](https://docs.acedata.cloud/zh-CN/api-reference) لفهم كامل المعلمات
- اطلع على [خطط التسعير](https://platform.acedata.cloud/services) لمعرفة التكاليف
