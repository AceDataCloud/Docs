جميع واجهات برمجة تطبيقات Ace Data Cloud تستخدم مصادقة **Bearer Token**.

## الحصول على التوكن

سجّل الدخول إلى [قائمة التطبيقات](https://platform.acedata.cloud/console/applications?lang=ar&utm_source=docs&utm_medium=referral&utm_campaign=evergreen) وافتح **General Application**. انقر على زر النسخ بجوار **API KEY**.

![مفتاح API للتطبيق العام](https://cdn.acedata.cloud/dvc3cg.jpg)

احتفظ بالمفتاح على الخادم واستخدم قيمته بدلًا من `YOUR_API_TOKEN` في المثال.

## استخدام التوكن

قم بتضمين التوكن في رأس `Authorization` لكل طلب:

```bash
Authorization: Bearer YOUR_API_TOKEN
```


## تحديد معدل الطلبات

يختلف تحديد معدل الطلبات حسب الخدمة ومستوى الاشتراك. عند تجاوز الحد، تعيد الواجهة `429 Too Many Requests`.

## أفضل ممارسات الأمان

- لا تكشف عن توكن API في كود العميل
- استخدم متغيرات البيئة لتخزين التوكن
- قم بتدوير التوكن بانتظام
- استخدم توكنات مختلفة لبيئات التطوير والإنتاج
