جميع واجهات برمجة تطبيقات Ace Data Cloud تستخدم مصادقة **Bearer Token**.

## الحصول على التوكن

1. سجل حسابًا في [platform.acedata.cloud](https://platform.acedata.cloud)
2. اشترك في الخدمات المطلوبة
3. أنشئ بيانات اعتماد (API Token) لكل خدمة

## استخدام التوكن

قم بتضمين التوكن في رأس `Authorization` لكل طلب:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="تنبيه">
  كل توكن مرتبط باشتراك خدمة محددة. استخدم توكن مختلف لكل خدمة، أو أنشئ بيانات اعتماد **عالمية** للاستخدام عبر الخدمات.
</Note>

## حدود المعدل

تختلف حدود المعدل حسب الخدمة ومستوى الاشتراك. عند تجاوز الحد، تعيد الواجهة `429 Too Many Requests`.

## أفضل ممارسات الأمان

- لا تكشف عن توكن API في كود العميل
- استخدم متغيرات البيئة لتخزين التوكن
- قم بتدوير التوكن بانتظام
- استخدم توكنات مختلفة لبيئات التطوير والإنتاج
