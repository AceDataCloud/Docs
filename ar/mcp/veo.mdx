[MCP (بروتوكول سياق النموذج)](https://modelcontextprotocol.io) هو بروتوكول سياق النموذج الذي أطلقته شركة Anthropic، والذي يسمح لنماذج الذكاء الاصطناعي (مثل Claude وGPT وغيرها) باستدعاء أدوات خارجية من خلال واجهات موحدة. من خلال خادم Veo MCP المقدم من AceData Cloud، يمكنك استخدام Google Veo لإنشاء مقاطع فيديو AI مباشرة في عملاء الذكاء الاصطناعي مثل Claude Desktop وVS Code وCursor.

## نظرة عامة على الوظائف

يوفر خادم Veo MCP الوظائف الأساسية التالية:

- **توليد الفيديو من النص** — إنشاء مقاطع فيديو عالية الجودة من خلال نصوص ترويجية
- **توليد الفيديو من الصور** — إنشاء مقاطع فيديو بناءً على الصور
- **دعم نماذج متعددة** — دعم نماذج مثل veo3 وveo2 وveo31-fast-ingredient
- **دعم دقات متعددة** — دعم تنسيقات الإخراج مثل 4K و1080p وGIF
- **نسب عرض متعددة** — دعم نسب مثل 16:9 و9:16
- **ترقية 1080p** — ترقية مقاطع الفيديو التي تم إنشاؤها إلى 1080p
- **استعلام المهام** — مراقبة تقدم الإنشاء والحصول على النتائج

## التحضيرات المسبقة

قبل الاستخدام، تحتاج إلى الحصول على رمز API من AceData Cloud:

1. سجل أو قم بتسجيل الدخول إلى [منصة AceData Cloud](https://platform.acedata.cloud)
2. انتقل إلى صفحة [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos)
3. انقر على "Acquire" للحصول على رمز API (تقدم أول طلب هدية مجانية)

## التثبيت والتكوين

### الطريقة الأولى: تثبيت pip (موصى به)

```bash
pip install mcp-veo
```

### الطريقة الثانية: تثبيت من المصدر

```bash
git clone https://github.com/AceDataCloud/MCPVeo.git
cd MCPVeo
pip install -e .
```

بعد الانتهاء من التثبيت، يمكنك استخدام الأمر `mcp-veo` لبدء الخدمة.

## الاستخدام في Claude Desktop

قم بتحرير ملف تكوين Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

أضف التكوين التالي:

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

إذا كنت تستخدم `uvx` (لا حاجة لتثبيت الحزمة مسبقًا):

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

بعد حفظ التكوين، أعد تشغيل Claude Desktop، وستتمكن من استخدام أدوات Veo ذات الصلة في المحادثة.

## الاستخدام في VS Code / Cursor

قم بإنشاء ملف `.vscode/mcp.json` في دليل المشروع الجذر:

```json
{
  "servers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

أو استخدم `uvx`:

```json
{
  "servers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"

```

## قائمة الأدوات المتاحة

| اسم الأداة               | الوصف           |
| --------------------- | ------------ |
| `veo_text_to_video`   | إنشاء فيديو من نصوص ترويجية  |
| `veo_image_to_video`  | إنشاء فيديو بناءً على الصور   |
| `veo_get_1080p`       | ترقية الفيديو إلى 1080p |
| `veo_get_task`        | استعلام عن حالة مهمة واحدة     |
| `veo_get_tasks_batch` | استعلام جماعي عن حالة المهام     |

## أمثلة على الاستخدام

بعد الانتهاء من التكوين، يمكنك استدعاء هذه الوظائف مباشرة بلغة طبيعية في عملاء الذكاء الاصطناعي، مثل:

- "ساعدني في إنشاء فيديو بتقنية timelapse للسماء المرصعة بالنجوم باستخدام Veo"
- "استخدم هذه الصورة للمناظر الطبيعية لإنشاء فيديو بدقة 4K"
- "أنشئ فيديو قصير عمودي بنسبة 9:16"
- "قم بترقية هذا الفيديو إلى 1080p"
