[بروتوكول MCP (Model Context Protocol)](https://modelcontextprotocol.io) هو بروتوكول سياق النماذج الذي أطلقته Anthropic، ويتيح لنماذج الذكاء الاصطناعي (مثل Claude وGPT وغيرها) استدعاء الأدوات الخارجية عبر واجهات موحّدة. من خلال Suno MCP Server الذي توفره AceData Cloud، يمكنك إنشاء الموسيقى وكلمات الأغاني مباشرةً وإدارة مشاريع الصوت في عملاء الذكاء الاصطناعي مثل Claude Desktop وVS Code وCursor وغيرها.

## نظرة عامة على الميزات

يوفر Suno MCP Server الميزات الأساسية التالية:

- **إنشاء الموسيقى** — إنشاء موسيقى بالذكاء الاصطناعي عبر مطالبات نصية
- **الإبداع المخصص** — تحكم كامل في كلمات الأغاني والعنوان والنمط الموسيقي
- **متابعة كتابة الأغاني** — متابعة تمديد الأغاني الموجودة من أي نقطة زمنية
- **إعادة الغناء/المزج** — إنشاء نسخ إعادة غناء بأنماط مختلفة
- **إنشاء كلمات الأغاني** — إنشاء كلمات أغاني منظمة بناءً على الوصف
- **شخصيات صوتية** — حفظ أنماط الأصوات وإعادة استخدامها
- **تحويل الوسائط** — الحصول على MP4 وWAV وMIDI وفصل الأصوات البشرية وغيرها
- **تحسين النمط** — تحسين علامات النمط الموسيقي
- **استعلام المهام** — مراقبة تقدم الإنشاء والحصول على النتائج

## التحضير المسبق

قبل الاستخدام، تحتاج إلى الحصول على AceData Cloud API Token:

1. سجّل أو سجّل الدخول إلى [منصة AceData Cloud](https://platform.acedata.cloud)
2. انتقل إلى صفحة [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. انقر على «Acquire» للحصول على API Token (يتم منح رصيد مجاني عند أول طلب)

## الطريقة الأولى: استخدام MCP Server المستضاف (موصى به، بدون تثبيت)

استضافت AceData Cloud بالفعل **Suno MCP Server** في السحابة، و**لا حاجة إلى تثبيت أي تبعيات محليًا**، ما عليك سوى إدخال عنوان URL التالي مباشرةً في عميل الذكاء الاصطناعي لاستخدامه:

```
https://suno.mcp.acedata.cloud/mcp
```

طريقة المصادقة: أضف `Authorization: Bearer API Token الخاص بك` إلى رأس الطلب (يتم إكمال ذلك تلقائيًا عبر OAuth في Claude.ai، ولا حاجة إلى إدخال Token يدويًا).

### Claude.ai (نسخة الويب، تسجيل دخول OAuth، الأسهل)

1. افتح [Claude.ai](https://claude.ai) → **Customize** في أسفل اليسار → **Connectors** → **Add More**
2. أدخل في خانة URL: `https://suno.mcp.acedata.cloud/mcp`
3. أكمل تسجيل الدخول بتفويض OAuth (سيتم التحويل تلقائيًا إلى صفحة تسجيل دخول AceData Cloud)
4. عد إلى واجهة المحادثة، وستصبح الأداة متاحة للاستخدام

### Claude Desktop

حرّر ملف الإعدادات:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

بعد الحفظ، أعد تشغيل Claude Desktop ليصبح ساري المفعول.

### Claude Code (سطر أوامر الطرفية)

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### عملاء آخرون يدعمون MCP

يمكن لأي عميل يدعم بروتوكول MCP Streamable HTTP (مثل Windsurf وCline وChatGPT Connectors وGemini CLI وJetBrains AI Assistant وغيرها) الاتصال عبر إدخال العنصرين التاليين:

- **URL**: `https://suno.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer API Token الخاص بك`

## الطريقة الثانية: التشغيل محليًا (تثبيت pip / uvx)

إذا كنت بحاجة إلى التشغيل دون اتصال بالإنترنت، أو تخصيص الكود، أو النشر داخل الشبكة الداخلية، فيمكنك تثبيت MCP Server محليًا وتشغيله عبر stdio.

### التثبيت

التثبيت عبر pip (موصى به):

```bash
pip install mcp-suno
```

أو التثبيت من المصدر:

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

بعد اكتمال التثبيت، يمكنك استخدام أمر `mcp-suno` لبدء الخدمة.

### الاستخدام في Claude Desktop (محليًا)

حرّر ملف إعدادات Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

أضف الإعدادات التالية:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

إذا كنت تستخدم `uvx` (لا حاجة إلى تثبيت الحزمة مسبقًا):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

بعد حفظ الإعدادات، أعد تشغيل Claude Desktop ليصبح ساري المفعول.

## قائمة الأدوات المتاحة
| اسم الأداة                               | الوصف                          |
| --------------------------------- | --------------------------- |
| `suno_generate_music`             | إنشاء موسيقى عبر موجّهات نصية                 |
| `suno_generate_custom_music`      | إنشاء موسيقى بكلمات ونمط مخصصين                |
| `suno_extend_music`               | متابعة كتابة الأغنية من نقطة زمنية محددة                  |
| `suno_cover_music`                | إنشاء نسخة غنائية معاد أداؤها                      |
| `suno_concat_music`               | دمج مقاطع الأغاني                      |
| `suno_generate_with_persona`      | إنشاء موسيقى باستخدام شخصية صوتية محددة                |
| `suno_remaster_music`             | إعادة المعالجة الرئيسية                      |
| `suno_stems_music`                | فصل المسارات الصوتية (الصوت البشري/المرافقة الموسيقية)                 |
| `suno_replace_section`            | استبدال مقطع محدد في الأغنية                  |
| `suno_upload_extend`              | رفع الصوت ومتابعة كتابته                     |
| `suno_upload_cover`               | رفع الصوت وإعادة أدائه غنائيًا                     |
| `suno_mashup_music`               | مزج عدة أغانٍ                      |
| `suno_generate_lyrics`            | إنشاء كلمات الأغاني بناءً على الوصف                    |
| `suno_create_persona`             | إنشاء شخصية صوتية                      |
| `suno_get_mp4`                    | الحصول على فيديو MP4 للأغنية                 |
| `suno_get_timing`                 | الحصول على الخط الزمني لكلمات الأغنية                     |
| `suno_extract_vocals`             | استخراج الصوت البشري                        |
| `suno_get_wav`                    | الحصول على WAV عالي الجودة                   |
| `suno_get_midi`                   | الحصول على ملف MIDI                  |
| `suno_optimize_style`             | تحسين علامات نمط الموسيقى                    |
| `suno_mashup_lyrics`              | مزج كلمات الأغاني                        |
| `suno_upload_audio`               | رفع صوت مخصص                     |
| `suno_add_stem`                   | إنشاء مسار لآلة محددة أو صوت بشري لصوت موجود            |
| `suno_extract_stem`               | استخراج مسار صوتي محدد وإرجاع النسخة المكملة               |
| `suno_generate_sound`             | إنشاء مؤثر صوتي لمرة واحدة أو متكرر، مع إمكانية تحديد BPM والمقام       |
| `suno_adjust_speed`               | ضبط السرعة، مع إمكانية اختيار الحفاظ على حدة الصوت                |
| `suno_generate_with_custom_model` | الإبداع باستخدام نموذج مخصص جاهز، مع دعم الموسيقى الخالصة وكلمات الأغاني التلقائية    |
| `suno_manage_project`             | إدارة مشروع Studio متعدد المسارات ذي الإصدارات حسب action |
| `suno_get_task`                   | الاستعلام عن حالة مهمة واحدة                    |
| `suno_get_tasks_batch`            | الاستعلام الجماعي عن حالات المهام                    |

## أمثلة الاستخدام

بعد إكمال الإعداد، يمكنك استدعاء هذه الوظائف مباشرة باللغة الطبيعية في عميل AI، على سبيل المثال:

- «ساعدني في إنشاء موسيقى بوب عن الصيف»
- «أعد أداء هذه الأغنية بأسلوب الجاز»
- «تابع كتابة هذه الأغنية، بدءًا من الثانية 30»
- «أنشئ كلمات أغنية باللغة الصينية، موضوعها السفر»
- «افصل الصوت البشري من هذه الأغنية»
- «ساعدني في تحويل هذه الأغنية إلى تنسيق MIDI»

## التحكم المتقدم ومشاريع Studio

يدعم `suno_generate_music` الخيار `variety`؛ كما يدعم `suno_generate_custom_music`
الخيارين `max_mode` و`audio_weight`. يستخدم `max_mode` مستوى فوترة أعلى لواجهة API، وهو غير مفعّل
افتراضيًا، ويجب ضبطه بعد أن يختار المستخدم وضع التحسين صراحةً. الأسعار الحالية تخضع لصفحة خدمة المنصة.

يمكن لـ `suno_generate_with_custom_model` استخدام `instrumental=true` لإنشاء موسيقى خالصة، أو استخدام
`lyric_prompt` لإنشاء كلمات الأغاني تلقائيًا؛ وإلا فوفّر `lyric`. يمكن حذف العنوان والنمط، كما يمكن تمرير
`negative_tags` و`vocal_gender` و`weirdness` و`style_influence` و`duration` و
`callback_url`. ستُحتفظ بقيم التحكم الصريحة `0`.

يمكن أن يكون `request.action` في `suno_manage_project` أحد الخيارات `create` أو `retrieve` أو `save` أو
`upload` أو `add_track` أو `generate_track` أو `replace_section` أو `commit_candidate` أو
`remove_track` أو `render`. تختلف المدخلات حسب الإجراء، ويجب أن تستخدم تعديلات المشروع `version_id` المقروء مؤخرًا؛
عند الحفظ، مرّر `state` الكامل، واحتفظ بالمسارات والحقول الموجودة.

باستثناء `retrieve`، يجب أن يقدّم كل استدعاء `idempotency_key`. استخدم مفتاحًا جديدًا لعمليات الكتابة الجديدة؛
عند انتهاء المهلة أو عدم التأكد من نتيجة القبول، احتفظ بالمفتاح الأصلي وأعِد المحاولة بالطلب المطابق تمامًا، أو استعلم عن المهمة الأصلية، ولا
تغيّر المفتاح تلقائيًا لإعادة إرسال عملية إنشاء مدفوعة. تستخدم فترات الصوت المصدر الثواني، بينما تستخدم فترات الخط الزمني للمشروع عدد النبضات. ينشئ التوليد المرشحين فقط،
وتحتاج إلى تحديد مرشح واستدعاء `commit_candidate` لكي يُكتب في المسار.

يُستعلم عن `task_id` المقبول بشكل غير متزامن باستخدام `suno_get_task`. عند كون `finished_at` فارغًا، استمر في الانتظار،
وبعد الحالة النهائية افحص `response.success` والأخطاء؛ لا تعتبر نجاح القبول نجاحًا في الإنشاء أو الالتزام أو التصدير.
يعيد `suno_get_tasks_batch` سجلات مهام JSON كاملة، ويحتفظ بكائنات النموذج المخصص وحالة المشروع،
والمرشحين وMIDI ومختلف أنواع النتائج الأخرى. راجع سير العمل الكامل في [دليل مشروع Studio](https://platform.acedata.cloud/documents/suno-projects-integration).
