[MCP (نموذج بروتوكول السياق)](https://modelcontextprotocol.io) هو بروتوكول سياق النموذج الذي أطلقته شركة Anthropic، والذي يسمح لنماذج الذكاء الاصطناعي (مثل Claude وGPT وغيرها) باستدعاء أدوات خارجية من خلال واجهات موحدة. من خلال خادم Suno MCP المقدم من AceData Cloud، يمكنك مباشرةً إنشاء موسيقى وكلمات وإدارة مشاريع صوتية في عملاء الذكاء الاصطناعي مثل Claude Desktop وVS Code وCursor.

## نظرة عامة على الوظائف

يوفر خادم Suno MCP الوظائف الأساسية التالية:

- **توليد الموسيقى** — توليد موسيقى AI من خلال نصوص ترويجية
- **الإبداع المخصص** — التحكم الكامل في الكلمات والعناوين وأسلوب الموسيقى
- **استكمال الأغاني** — مواصلة تمديد الأغاني الموجودة من أي نقطة زمنية
- **إعادة الغناء/المزج** — إنشاء نسخ مغطاة بأساليب مختلفة
- **توليد الكلمات** — توليد كلمات منظمة بناءً على الوصف
- **أدوار الصوت البشري** — حفظ وإعادة استخدام أنماط الصوت
- **تحويل الوسائط** — الحصول على MP4 وWAV وMIDI وفصل الصوت البشري وغيرها
- **تحسين الأسلوب** — تحسين علامات أسلوب الموسيقى
- **استعلام المهام** — مراقبة تقدم التوليد والحصول على النتائج

## التحضيرات المسبقة

قبل الاستخدام، تحتاج إلى الحصول على رمز API من AceData Cloud:

1. سجل أو قم بتسجيل الدخول إلى [منصة AceData Cloud](https://platform.acedata.cloud)
2. انتقل إلى صفحة [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. انقر على "Acquire" للحصول على رمز API (تقدم أول طلب هدية مجانية)

## التثبيت والتكوين

### الطريقة الأولى: تثبيت pip (موصى به)

```bash
pip install mcp-suno
```

### الطريقة الثانية: تثبيت من المصدر

```bash
git clone https://github.com/AceDataCloud/MCPSuno.git
cd MCPSuno
pip install -e .
```

بعد الانتهاء من التثبيت، يمكنك استخدام الأمر `mcp-suno` لبدء الخدمة.

## الاستخدام في Claude Desktop

قم بتحرير ملف تكوين Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

أضف التكوين التالي:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

إذا كنت تستخدم `uvx` (لا حاجة لتثبيت الحزمة مسبقًا):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

بعد حفظ التكوين، أعد تشغيل Claude Desktop، وستتمكن من استخدام أدوات Suno ذات الصلة في المحادثة.

## الاستخدام في VS Code / Cursor

في دليل المشروع الجذري، أنشئ ملف `.vscode/mcp.json`:

```json

    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }

```

أو استخدم `uvx`:

## قائمة الأدوات المتاحة

| اسم الأداة                       | الوصف           |
| ---------------------------- | ------------ |
| `suno_generate_music`        | توليد موسيقى من خلال نصوص ترويجية  |
| `suno_generate_custom_music` | توليد موسيقى مع كلمات وأسلوب مخصص |
| `suno_extend_music`          | استكمال الأغاني من نقطة زمنية محددة   |
| `suno_cover_music`           | إنشاء نسخ مغطاة       |
| `suno_concat_music`          | دمج مقاطع الأغاني       |
| `suno_generate_with_persona` | توليد موسيقى باستخدام أدوار صوت محددة |
| `suno_remaster_music`        | إعادة معالجة الصوت       |
| `suno_stems_music`           | فصل المسارات (صوت بشري/موسيقى)  |
| `suno_replace_section`       | استبدال مقاطع محددة في الأغاني   |
| `suno_upload_extend`         | رفع الصوت واستكماله      |
| `suno_upload_cover`          | رفع الصوت وإعادة غنائه      |
| `suno_mashup_music`          | مزج عدة أغاني       |
| `suno_generate_lyrics`       | توليد كلمات بناءً على الوصف     |
| `suno_create_persona`        | إنشاء أدوار صوت       |
| `suno_get_mp4`               | الحصول على فيديو MP4 للأغاني  |
| `suno_get_timing`            | الحصول على توقيت الكلمات      |
| `suno_extract_vocals`        | استخراج الصوت البشري         |
| `suno_get_wav`               | الحصول على WAV عالي الجودة    |
| `suno_get_midi`              | الحصول على ملفات MIDI   |
| `suno_optimize_style`        | تحسين علامات أسلوب الموسيقى     |
| `suno_mashup_lyrics`         | مزج الكلمات         |
| `suno_upload_audio`          | رفع صوت مخصص      |
| `suno_get_task`              | استعلام عن حالة مهمة واحدة     |
| `suno_get_tasks_batch`       | استعلام عن حالة المهام بشكل جماعي     |

## أمثلة على الاستخدام

بعد الانتهاء من التكوين، يمكنك مباشرةً استدعاء هذه الوظائف باستخدام لغة طبيعية في عملاء الذكاء الاصطناعي، مثل:

- "ساعدني في توليد أغنية عن الصيف"
- "أعد غناء هذه الأغنية بأسلوب الجاز"
- "استكمل هذه الأغنية بدءًا من 30 ثانية"
- "توليد كلمات باللغة الصينية، موضوعها السفر"
- "افصل الصوت البشري عن هذه الأغنية"
- "ساعدني في تحويل هذه الأغنية إلى تنسيق MIDI"
