[MCP (نموذج بروتوكول السياق)](https://modelcontextprotocol.io) هو بروتوكول سياق النموذج الذي أطلقته Anthropic، والذي يسمح لنماذج الذكاء الاصطناعي (مثل Claude و GPT وغيرها) باستدعاء أدوات خارجية من خلال واجهات موحدة. من خلال خادم SERP MCP المقدم من AceData Cloud، يمكنك إجراء بحث على Google مباشرة في عملاء الذكاء الاصطناعي مثل Claude Desktop و VS Code و Cursor، والحصول على نتائج بحث تشمل صفحات الويب والصور والأخبار ومقاطع الفيديو والأماكن.

## نظرة عامة على الوظائف

يوفر خادم SERP MCP الوظائف الأساسية التالية:

- **بحث الويب** — البحث عن نتائج صفحات Google
- **بحث الصور** — البحث عن صور Google
- **بحث الأخبار** — البحث عن أخبار Google
- **بحث الفيديو** — البحث عن مقاطع فيديو Google
- **بحث الأماكن** — البحث عن معلومات الأماكن في Google
- **بحث الخرائط** — البحث عن خرائط Google
- **دعم متعدد اللغات والمناطق** — دعم معلمات الدولة واللغة المخصصة
- **تصفية نطاق الوقت** — تصفية النتائج حسب اليوم والأسبوع والشهر والسنة

## التحضيرات المسبقة

قبل الاستخدام، تحتاج إلى الحصول على رمز API من AceData Cloud:

1. سجل أو قم بتسجيل الدخول إلى [منصة AceData Cloud](https://platform.acedata.cloud)
2. انتقل إلى صفحة [Google SERP API](https://platform.acedata.cloud/documents/serp-google)
3. انقر على "Acquire" للحصول على رمز API (تقدم أول طلب هدية مجانية)

## التثبيت والتكوين

### الطريقة الأولى: تثبيت pip (موصى به)

```bash
pip install mcp-serp
```

### الطريقة الثانية: تثبيت من المصدر

```bash
git clone https://github.com/AceDataCloud/MCPSerp.git
cd MCPSerp
pip install -e .
```

بعد الانتهاء من التثبيت، يمكنك استخدام الأمر `mcp-serp` لبدء الخدمة.

## الاستخدام في Claude Desktop

قم بتحرير ملف تكوين Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

أضف التكوين التالي:

```json
{
  "mcpServers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

إذا كنت تستخدم `uvx` (لا حاجة لتثبيت الحزمة مسبقًا):

```json
{
  "mcpServers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

بعد حفظ التكوين، أعد تشغيل Claude Desktop، وستتمكن من استخدام أدوات البحث ذات الصلة بـ Google في المحادثة.

## الاستخدام في VS Code / Cursor

قم بإنشاء `.vscode/mcp.json` في دليل المشروع الجذر:

```json

      "env": {
```

## قائمة الأدوات المتاحة

| اسم الأداة                | الوصف          |
| -------------------- | ----------- |
| `serp_google_search` | بحث صفحات Google |
| `serp_google_images` | بحث صور Google |
| `serp_google_news`   | بحث أخبار Google |
| `serp_google_videos` | بحث مقاطع فيديو Google |
| `serp_google_places` | بحث أماكن Google |
| `serp_google_maps`   | بحث خرائط Google |

## أمثلة على الاستخدام

بعد الانتهاء من التكوين، يمكنك استدعاء هذه الوظائف مباشرة بلغة طبيعية في عملاء الذكاء الاصطناعي، مثل:

- "ساعدني في البحث عن أحدث الأوراق البحثية في الذكاء الاصطناعي"
- "ابحث عن مطاعم الحساء الساخن الجيدة في بكين"
- "ابحث عن صور حول برمجة Python غير المتزامنة"
- "ابحث عن أخبار التكنولوجيا اليوم"
- "ابحث عن المقاهي القريبة على الخريطة"
