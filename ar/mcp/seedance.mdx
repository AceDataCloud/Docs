[MCP (Model Context Protocol)](https://modelcontextprotocol.io) هو بروتوكول سياق النماذج الذي أطلقته Anthropic، ويسمح لنماذج الذكاء الاصطناعي (مثل Claude وGPT وغيرها) باستدعاء الأدوات الخارجية عبر واجهات موحّدة. من خلال Seedance MCP Server الذي توفره AceData Cloud، يمكنك استخدام ByteDance Seedance مباشرةً في عملاء الذكاء الاصطناعي مثل Claude Desktop وVS Code وCursor وغيرها لإنشاء مقاطع فيديو بالذكاء الاصطناعي.

## نظرة عامة على الوظائف

يوفر Seedance MCP Server الوظائف الأساسية التالية:

- **إنشاء فيديو من النص** — إنشاء مقاطع فيديو عالية الجودة عبر مطالبات نصية
- **إنشاء فيديو من الصور** — إنشاء فيديو بالاستناد إلى الصور (مثل الإطار الأول، والإطار الأخير، والصورة المرجعية وغيرها من الأوضاع)
- **دعم نماذج متعددة** — يدعم Seedance 1.x و1.5 و2.0 و2.5
- **دقات متعددة** — يدعم 480p و720p و1080p، وتدعم بعض النماذج 4k
- **نسب أبعاد متعددة** — يدعم 16:9 و9:16 و1:1 و4:3 و3:4 و21:9 وadaptive
- **مدة مرنة** — من 2 إلى 30 ثانية حسب دعم النموذج أو مدة تلقائية
- **فيديو متعدد الوسائط** — يدعم إنشاء الصوت، والصوت/الفيديو المرجعي، بالإضافة إلى تحرير الفيديو وتمديده في 2.5
- **استعلام عن المهام** — مراقبة تقدم الإنشاء والحصول على النتائج

## موصى به: استخدام تفويض OAuth لـ MCP المستضاف

أضف عنوان الخادم في العملاء الذين يدعمون OAuth لـ MCP عن بُعد:

```text
https://seedance.mcp.acedata.cloud/mcp
```

اختر الاتصال أو تسجيل الدخول، وسجّل الدخول إلى Ace Data Cloud، وراجع الأذونات وامنح التفويض، ثم فعّل الأدوات. لا يتطلب هذا المسار إنشاء أو نسخ API Token مسبقًا. تدعم الخدمة OAuth discovery، وتسجيل العميل الديناميكي (DCR)، وS256 PKCE؛ يقوم DCR بتسجيل العميل، ولا يزال المستخدم بحاجة إلى تسجيل الدخول والتفويض، ويتم احتساب رسوم استخدام API كالمعتاد.

| العميل                            | طريقة التكامل والشروط                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| إصدار Claude على الويب أو إصدار Desktop الذي يوفر موصلات عن بُعد | أضف العنوان المذكور أعلاه في واجهة الموصلات وامنح التفويض؛ يعتمد توفر المدخل على الإصدار والخطة. لا تكتب إعدادات HTTP عن بُعد في ملف إعدادات stdio المحلي.                      |
| VS Code الذي يدعم OAuth لـ MCP عن بُعد بشكل أصلي     | نفّذ **MCP: Add Server**، واختر HTTP، وأدخل العنوان وسجّل الدخول وفقًا للمطالبات؛ تستخدم إضافة AceDataCloud المخصصة إعداد API Key مستقلًا. |
| عملاء آخرون                          | تأكد من أن الإصدار الحالي يدعم HTTP عن بُعد وOAuth/DCR، واستخدم إرشادات إعدادات ذلك العميل. لا يمكن استخدام تنسيق ملف الإعدادات بشكل عام بين العملاء المختلفين.                     |

## مسار بديل باستخدام API Token

تستخدم بيئات stdio المحلية أو الاستضافة الذاتية أو العملاء الذين لا يدعمون OAuth عن بُعد API Token. سجّل الدخول إلى [منصة Ace Data Cloud](https://platform.acedata.cloud)، واختر الخدمة وأنشئ بيانات اعتماد API بالأذونات المطلوبة. خزّن Token في إعدادات بيانات اعتماد العميل أو متغيرات البيئة المحلية، ولا تضعه في URL أو محتوى المحادثة أو مستودع الأكواد. يجب تعبئة إعدادات HTTP Header للعملاء المختلفين وفقًا لتعليمات إصدارهم.

لا يعني تثبيت MCP مفتوح المصدر أو إكمال التفويض الحصول على رصيد مجاني، ولا يضمن وقت الإنشاء أو حقوق الاستخدام التجاري. راجع أسعار الخدمة الحالية والرصيد والشروط المطبقة قبل الإنشاء.

## الطريقة الثانية: التشغيل محليًا (تثبيت pip / uvx)

إذا كنت تحتاج إلى stdio محلي أو كود مخصص أو استضافة ذاتية، فيمكنك تشغيل MCP Server محليًا. لا يزال الإنشاء يتطلب الاتصال بالإنترنت لاستدعاء API، وليس استدلالًا دون اتصال.

### التثبيت

التثبيت عبر pip (موصى به):

```bash
pip install mcp-seedance
```

أو التثبيت من المصدر:

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

بعد اكتمال التثبيت، يمكنك استخدام الأمر `mcp-seedance` لبدء الخدمة.

### الاستخدام في Claude Desktop (محليًا)

حرّر ملف إعدادات Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

أضف الإعدادات التالية:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

إذا كنت تستخدم `uvx` (لا حاجة لتثبيت الحزمة مسبقًا):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

أعد تشغيل Claude Desktop بعد حفظ الإعدادات لتصبح سارية المفعول.

### الاستخدام في VS Code (محليًا)

أنشئ `.vscode/mcp.json` في الدليل الجذر للمشروع:

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

أو استخدم `uvx`:

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

بالنسبة إلى العملاء المحليين الآخرين، املأ command وargs وenv وفقًا لتعليمات إعدادات stdio للإصدار الحالي الخاص بهم، ولا تتعامل مع إعدادات VS Code مباشرةً باعتبارها تنسيقًا عامًا.

## التحقق من النتائج والإخفاقات الشائعة

اطلب من العميل إنشاء عمل فيديو بسيط، واحتفظ برقم المهمة واستعلم عن المهمة نفسها حتى تصل إلى الحالة النهائية الناجحة، ثم افتح الرابط النهائي أو شغّله. لا يعني نجاح الاتصال أو تحميل قائمة الأدوات أو HTTP 200 أو رقم المهمة أو معاينة المعالجة أن المنتج النهائي جاهز.

عند مواجهة 401، سجّل الدخول مجددًا أو تحقّق من Token والأذونات؛ عند عدم كفاية الرصيد، راجع الفوترة؛ أثناء معالجة المهمة، استمر في الاستعلام؛ وعند الفشل النهائي، اقرأ الخطأ ثم قرر ما إذا كنت ستعيد المحاولة، إذ قد يتم احتساب رسوم على عملية إنشاء جديدة مرة أخرى.

## قائمة الأدوات المتاحة

| اسم الأداة                                  | الوصف             |
| ------------------------------------ | -------------- |
| `seedance_generate_video`            | إنشاء فيديو عبر مطالبة نصية    |
| `seedance_generate_video_from_image` | إنشاء فيديو بالاستناد إلى صورة     |
| `seedance_get_task`                  | الاستعلام عن حالة مهمة واحدة       |
| `seedance_get_tasks_batch`           | الاستعلام عن حالات المهام على دفعات       |
| `seedance_list_models`               | سرد جميع النماذج المتاحة وقدراتها   |
| `seedance_list_resolutions`          | سرد الدقات المتاحة ونسب الأبعاد   |
| `seedance_list_actions`              | سرد جميع الأدوات المتاحة وأمثلة سير العمل |
