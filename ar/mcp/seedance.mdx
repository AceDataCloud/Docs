[MCP (Model Context Protocol)](https://modelcontextprotocol.io) هو بروتوكول سياق النموذج الذي أطلقته Anthropic، يسمح لنماذج الذكاء الاصطناعي مثل Claude و GPT وغيرها باستدعاء أدوات خارجية عبر واجهة موحدة. من خلال خادم Seedance MCP المقدم من AceData Cloud، يمكنك استخدام فيديوهات الذكاء الاصطناعي التي تنتجها ByteDance Seedance مباشرة في عملاء الذكاء الاصطناعي مثل Claude Desktop و VS Code و Cursor.

## نظرة عامة على الوظائف

يقدم خادم Seedance MCP الوظائف الأساسية التالية:

- **توليد الفيديو من النص** — إنشاء فيديو عالي الجودة بناءً على نصوص وصفية
- **توليد الفيديو من الصور** — إنشاء فيديو باستخدام صورة كمرجع (إطارات أولى، أخيرة، أو نماذج مرجعية)
- **دعم نماذج متعددة** — يدعم نماذج Seedance 1.5 Pro، 1.0 Pro، 1.0 Lite وغيرها
- **دقة متعددة** — يدعم دقة 480p، 720p، 1080p وغيرها
- **نسب أبعاد متعددة** — يدعم نسب 16:9، 9:16، 1:1، 4:3، 3:4، 21:9 وغيرها
- **مدة مرنة** — يدعم مدة فيديو من 2 إلى 12 ثانية
- **توليد الصوت** — بعض النماذج تدعم توليد الصوت مع الفيديو
- **استعلام المهام** — مراقبة تقدم التوليد والحصول على النتائج

## المتطلبات المسبقة

قبل الاستخدام، تحتاج إلى الحصول على رمز API من AceData Cloud:

1. قم بالتسجيل أو تسجيل الدخول إلى [منصة AceData Cloud](https://platform.acedata.cloud)
2. انتقل إلى صفحة [Seedance Videos API](https://platform.acedata.cloud/documents/seedance-videos)
3. اضغط على "Acquire" للحصول على رمز API (تحصل على حصة مجانية عند الطلب الأول)

## التثبيت والإعداد

### الطريقة الأولى: التثبيت عبر pip (موصى به)

```bash
pip install mcp-seedance
```

### الطريقة الثانية: التثبيت من المصدر

```bash
git clone https://github.com/AceDataCloud/MCPSeedance.git
cd MCPSeedance
pip install -e .
```

بعد التثبيت، يمكنك بدء الخدمة باستخدام الأمر `mcp-seedance`.

## الاستخدام في Claude Desktop

قم بتحرير ملف إعدادات Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

أضف الإعداد التالي:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

إذا كنت تستخدم `uvx` (لا حاجة لتثبيت الحزم مسبقًا):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

بعد حفظ الإعدادات، أعد تشغيل Claude Desktop لتتمكن من استخدام أدوات Seedance في المحادثات.

## قائمة الأدوات المتاحة

| اسم الأداة                      | الوصف                      |
|-------------------------------|----------------------------|
| `seedance_generate_video`       | توليد فيديو من نصوص وصفية   |
| `seedance_generate_video_from_image` | توليد فيديو باستخدام صورة كمرجع |
| `seedance_get_task`             | استعلام حالة مهمة واحدة     |
| `seedance_get_tasks_batch`      | استعلام حالة مهام متعددة    |
| `seedance_list_models`          | عرض جميع النماذج المتاحة وقدراتها |
| `seedance_list_resolutions`     | عرض الدقات ونسب الأبعاد المتاحة |
| `seedance_list_actions`         | عرض جميع الأدوات وأمثلة سير العمل |

## أمثلة على الاستخدام

بعد الإعداد، يمكنك استدعاء هذه الوظائف مباشرة باستخدام اللغة الطبيعية في عملاء الذكاء الاصطناعي، مثل:

- "ساعدني في توليد فيديو تصوير تسريع لشارع في المدينة باستخدام Seedance"
- "استخدم هذه الصورة كإطار أول، واصنع فيديو مدته 8 ثوانٍ"
- "أنشئ فيديو قصير بدقة 1080p ونسبة عرض إلى ارتفاع 9:16"
- "استخدم نموذج Seedance 1.5 Pro لتوليد فيديو مع صوت"
