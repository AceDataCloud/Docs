[MCP (بروتوكول سياق النموذج)](https://modelcontextprotocol.io) هو بروتوكول سياق النموذج الذي أطلقته شركة Anthropic، والذي يسمح لنماذج الذكاء الاصطناعي (مثل Claude وGPT وغيرها) باستدعاء أدوات خارجية من خلال واجهات موحدة. من خلال خادم Luma MCP المقدم من AceData Cloud، يمكنك مباشرةً إنشاء فيديوهات AI في عملاء الذكاء الاصطناعي مثل Claude Desktop وVS Code وCursor.

## نظرة عامة على الوظائف

يوفر خادم Luma MCP الوظائف الأساسية التالية:

- **توليد الفيديو من النص** — إنشاء فيديو عالي الجودة من خلال نصوص ترويجية
- **توليد الفيديو من الصورة** — إنشاء فيديو بدءًا من صورة أو انتهاءً بها
- **استكمال الفيديو** — متابعة إنشاء الفيديو من آخر إطار موجود
- **نسب عرض متعددة** — دعم نسب 16:9 و9:16 و1:1 وغيرها
- **تحسين الصورة** — وظيفة اختيارية لتحسين الجودة البصرية
- **استعلام المهام** — مراقبة تقدم الإنشاء والحصول على النتائج

## التحضيرات المسبقة

قبل الاستخدام، تحتاج إلى الحصول على رمز API من AceData Cloud:

1. سجل أو قم بتسجيل الدخول إلى [منصة AceData Cloud](https://platform.acedata.cloud)
2. انتقل إلى صفحة [API فيديوهات Luma](https://platform.acedata.cloud/documents/luma-videos)
3. انقر على "Acquire" للحصول على رمز API (تُمنح حصة مجانية عند الطلب لأول مرة)

## التثبيت والتكوين

### الطريقة الأولى: تثبيت باستخدام pip (موصى به)

```bash
pip install mcp-luma
```

### الطريقة الثانية: تثبيت من المصدر

```bash
git clone https://github.com/AceDataCloud/LumaMCP.git
cd LumaMCP
pip install -e .
```

بعد الانتهاء من التثبيت، يمكنك استخدام الأمر `mcp-luma` لبدء الخدمة.

## الاستخدام في Claude Desktop

قم بتحرير ملف تكوين Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

أضف التكوين التالي:

```json
{
  "mcpServers": {
    "luma": {
      "command": "mcp-luma",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

إذا كنت تستخدم `uvx` (لا حاجة لتثبيت الحزمة مسبقًا):

```json
{
  "mcpServers": {
    "luma": {
      "command": "uvx",
      "args": ["mcp-luma"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

بعد حفظ التكوين، أعد تشغيل Claude Desktop، وستتمكن من استخدام أدوات Luma ذات الصلة في المحادثة.

## الاستخدام في VS Code / Cursor

قم بإنشاء ملف `.vscode/mcp.json` في دليل المشروع الجذري:

```json
{
  "servers": {
    "luma": {
      "command": "mcp-luma",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

أو استخدم `uvx`:

```json
{
  "servers": {
    "luma": {
      "command": "uvx",
      "args": ["mcp-luma"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

## قائمة الأدوات المتاحة

| اسم الأداة                          | الوصف             |
| -------------------------------- | -------------- |
| `luma_generate_video`            | توليد فيديو من نصوص ترويجية    |
| `luma_generate_video_from_image` | توليد فيديو من صورة        |
| `luma_extend_video`              | استكمال فيديو موجود         |
| `luma_extend_video_from_url`     | استكمال فيديو محدد من URL |
| `luma_get_task`                  | استعلام عن حالة مهمة واحدة       |
| `luma_get_tasks_batch`           | استعلام جماعي عن حالات المهام       |

## أمثلة على الاستخدام

بعد الانتهاء من التكوين، يمكنك مباشرةً استدعاء هذه الوظائف بلغة طبيعية في عملاء الذكاء الاصطناعي، مثل:

- "ساعدني في إنشاء فيديو لشروق الشمس على الشاطئ"
- "استخدم هذه الصورة كالإطار الأول، وأنشئ فيديو مدته 5 ثوانٍ"
- "استكمل هذا الفيديو، وامتد لفترة إضافية"
- "أنشئ فيديو عموديًا، بنسبة 9:16"
