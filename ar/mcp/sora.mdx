[MCP (بروتوكول سياق النموذج)](https://modelcontextprotocol.io) هو بروتوكول سياق النموذج الذي أطلقته شركة Anthropic، والذي يسمح لنماذج الذكاء الاصطناعي (مثل Claude وGPT وغيرها) باستدعاء أدوات خارجية من خلال واجهات موحدة. من خلال خادم Sora MCP المقدم من AceData Cloud، يمكنك استخدام OpenAI Sora لإنشاء مقاطع فيديو AI مباشرة في عملاء الذكاء الاصطناعي مثل Claude Desktop وVS Code وCursor.

## نظرة عامة على الوظائف

يوفر خادم Sora MCP الوظائف الأساسية التالية:

- **إنشاء فيديو من نص** — إنشاء فيديو عالي الجودة من خلال نصوص ترويجية
- **إنشاء فيديو من صورة** — إنشاء فيديو بناءً على صورة
- **فيديو بتناسق الشخصيات** — الحفاظ على تناسق الشخصيات باستخدام صور مرجعية
- **إنشاء غير متزامن** — دعم تقديم المهام غير المتزامنة واستعلام النتائج
- **اتجاهات عرض متعددة** — دعم العرض الأفقي (landscape) والعمودي (portrait)
- **استعلام المهام** — مراقبة تقدم الإنشاء والحصول على النتائج

## التحضيرات المسبقة

قبل الاستخدام، تحتاج إلى الحصول على رمز API من AceData Cloud:

1. سجل أو قم بتسجيل الدخول إلى [منصة AceData Cloud](https://platform.acedata.cloud)
2. انتقل إلى صفحة [API فيديوهات Sora](https://platform.acedata.cloud/documents/sora-videos)
3. انقر على "Acquire" للحصول على رمز API (تقدم أول طلب هدية رصيد مجاني)

## التثبيت والتكوين

### الطريقة الأولى: تثبيت باستخدام pip (موصى به)

```bash
pip install mcp-sora
```

### الطريقة الثانية: تثبيت من المصدر

```bash
git clone https://github.com/AceDataCloud/SoraMCP.git
cd SoraMCP
pip install -e .
```

بعد الانتهاء من التثبيت، يمكنك استخدام الأمر `mcp-sora` لبدء الخدمة.

## الاستخدام في Claude Desktop

قم بتحرير ملف تكوين Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

أضف التكوين التالي:

```json
{
  "mcpServers": {
    "sora": {
      "command": "mcp-sora",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

إذا كنت تستخدم `uvx` (لا حاجة لتثبيت الحزمة مسبقًا):

```json
{
  "mcpServers": {
    "sora": {
      "command": "uvx",
      "args": ["mcp-sora"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

بعد حفظ التكوين، أعد تشغيل Claude Desktop، وستتمكن من استخدام أدوات Sora في المحادثة.

## قائمة الأدوات المتاحة

| اسم الأداة                              | الوصف             |
| ------------------------------------ | -------------- |
| `sora_generate_video`                | إنشاء فيديو من نصوص ترويجية    |
| `sora_generate_video_from_image`     | إنشاء فيديو بناءً على صورة     |
| `sora_generate_video_with_character` | إنشاء فيديو بتناسق الشخصيات باستخدام صورة مرجعية |
| `sora_generate_video_async`          | تقديم مهام إنشاء الفيديو بشكل غير متزامن     |
| `sora_get_task`                      | استعلام عن حالة مهمة واحدة       |
| `sora_get_tasks_batch`               | استعلام عن حالة المهام بشكل جماعي       |

## أمثلة على الاستخدام

بعد الانتهاء من التكوين، يمكنك استدعاء هذه الوظائف مباشرة بلغة طبيعية في عميل الذكاء الاصطناعي، مثل:

- "ساعدني في إنشاء فيديو لقطط تجري على العشب باستخدام Sora"
- "استخدم هذه الصورة لشخصية لإنشاء فيديو، مع الحفاظ على تناسق الشخصية"
- "أنشئ فيديو عمودي، محتواه هو شروق الشمس في المدينة"
- "أنشئ فيديو بشكل غير متزامن واستعلم عن النتائج لاحقًا"
