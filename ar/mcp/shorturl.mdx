[MCP (Model Context Protocol)](https://modelcontextprotocol.io) هو بروتوكول سياق النموذج الذي أطلقته Anthropic، والذي يسمح لنماذج الذكاء الاصطناعي (مثل Claude و GPT وغيرها) باستدعاء الأدوات الخارجية عبر واجهة موحدة. من خلال خادم ShortURL MCP الذي توفره AceData Cloud، يمكنك إنشاء روابط قصيرة مباشرة في عملاء الذكاء الاصطناعي مثل Claude Desktop و VS Code و Cursor.

## نظرة عامة على الوظائف

يقدم خادم ShortURL MCP الوظائف الأساسية التالية:

- **اختصار رابط واحد** — تحويل URL طويل إلى رابط قصير سهل المشاركة
- **اختصار روابط متعددة دفعة واحدة** — اختصار عدة روابط (حتى 10 روابط)
- **دليل الاستخدام** — الحصول على تعليمات الاستخدام الكاملة وأفضل الممارسات
- **معلومات API** — عرض تفاصيل خدمة API وتعريف رموز الأخطاء

## المتطلبات المسبقة

قبل الاستخدام، تحتاج إلى الحصول على رمز API من AceData Cloud:

1. قم بالتسجيل أو تسجيل الدخول إلى [منصة AceData Cloud](https://platform.acedata.cloud)
2. انتقل إلى صفحة [ShortURL API](https://platform.acedata.cloud/documents/short-url)
3. اضغط على "Acquire" للحصول على رمز API (تمنحك المنصة حصة مجانية عند الطلب الأول)

## التثبيت والإعداد

### الطريقة الأولى: التثبيت عبر pip (موصى به)

```bash
pip install mcp-shorturl
```

### الطريقة الثانية: التثبيت من المصدر

```bash
git clone https://github.com/AceDataCloud/ShortURLMCP.git
cd ShortURLMCP
pip install -e .
```

بعد التثبيت، يمكنك تشغيل الخدمة باستخدام الأمر `mcp-shorturl`.

## الاستخدام في Claude Desktop

قم بتحرير ملف إعدادات Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

أضف الإعداد التالي:

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

إذا كنت تستخدم `uvx` (لا حاجة لتثبيت الحزم مسبقًا):

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "uvx",
      "args": ["mcp-shorturl"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

بعد حفظ الإعدادات، أعد تشغيل Claude Desktop لتتمكن من استخدام أدوات ShortURL ضمن المحادثات.

## الاستخدام في VS Code / Cursor

## قائمة الأدوات المتاحة

| اسم الأداة               | الوصف                          |
|-------------------------|-------------------------------|
| `shorturl_create`       | اختصار رابط واحد              |
| `shorturl_batch_create` | اختصار عدة روابط دفعة واحدة (حتى 10 روابط) |
| `shorturl_get_usage_guide` | الحصول على دليل الاستخدام الكامل |
| `shorturl_get_api_info` | الحصول على تفاصيل خدمة API   |

## أمثلة على الاستخدام

بعد الإعداد، يمكنك استدعاء هذه الوظائف مباشرة باستخدام اللغة الطبيعية في عملاء الذكاء الاصطناعي، مثل:

- "ساعدني في اختصار هذا الرابط"
- "اختصر لي هذه الروابط الخمسة دفعة واحدة"
- "أنشئ رابطًا قصيرًا للمشاركة"
