[MCP (Model Context Protocol)](https://modelcontextprotocol.io) هو بروتوكول سياق النموذج الذي أطلقته Anthropic، والذي يسمح لنماذج الذكاء الاصطناعي مثل Claude و GPT وغيرها باستدعاء أدوات خارجية عبر واجهة موحدة. من خلال خادم Seedream MCP الذي توفره AceData Cloud، يمكنك استخدام Seedream من ByteDance لتوليد وتحرير صور الذكاء الاصطناعي مباشرة في عملاء الذكاء الاصطناعي مثل Claude Desktop و VS Code و Cursor.

## نظرة عامة على الوظائف

يقدم خادم Seedream MCP الوظائف الأساسية التالية:

- **توليد الصور من النصوص** — توليد صور عالية الجودة عبر أوامر نصية (يدعم اللغتين الصينية والإنجليزية)
- **تحرير الصور** — تعديل أسلوب الصورة، الخلفية، الخصائص، وغيرها
- **التجريب الافتراضي للملابس** — وضع الملابس على صور الأشخاص
- **دعم نماذج متعددة** — يدعم نماذج Seedream v4.5، v4.0، v3.0 T2I، SeedEdit v3.0 I2I وغيرها
- **دقة متعددة** — يدعم 1K، 2K، 4K ودقة متكيفة
- **التحكم بالبذرة (seed)** — تحقيق نتائج قابلة للتكرار عبر معلمة seed
- **استعلام المهام** — مراقبة تقدم التوليد والحصول على النتائج

## المتطلبات المسبقة

قبل الاستخدام، تحتاج إلى الحصول على رمز API من AceData Cloud:

1. قم بالتسجيل أو تسجيل الدخول إلى [منصة AceData Cloud](https://platform.acedata.cloud)
2. انتقل إلى صفحة [Seedream Images API](https://platform.acedata.cloud/documents/seedream-images)
3. اضغط على "Acquire" للحصول على رمز API (يتم منح حصة مجانية عند الطلب الأول)

## التثبيت والإعداد

### الطريقة الأولى: التثبيت عبر pip (موصى به)

```bash
pip install mcp-seedream-pro
```

### الطريقة الثانية: التثبيت من المصدر

```bash
git clone https://github.com/AceDataCloud/MCPSeedream.git
cd MCPSeedream
pip install -e .
```

بعد الانتهاء من التثبيت، يمكنك تشغيل الخدمة باستخدام الأمر `mcp-seedream-pro`.

## الاستخدام في Claude Desktop

قم بتحرير ملف إعدادات Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

أضف الإعداد التالي:

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

إذا كنت تستخدم `uvx` (لا يتطلب تثبيت الحزم مسبقاً):

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

بعد حفظ الإعدادات، أعد تشغيل Claude Desktop لتتمكن من استخدام أدوات Seedream ضمن المحادثات.

## قائمة الأدوات المتاحة

| اسم الأداة                | الوصف                     |
|---------------------------|---------------------------|
| `seedream_generate_image` | توليد صورة من نص          |
| `seedream_edit_image`     | تحرير أو تعديل صورة موجودة |
| `seedream_get_task`       | استعلام حالة مهمة واحدة   |
| `seedream_get_tasks_batch`| استعلام حالة مهام متعددة  |
| `seedream_list_models`    | عرض جميع النماذج المتاحة وقدراتها |
| `seedream_list_sizes`     | عرض أحجام ودقات الصور المتاحة |

## أمثلة على الاستخدام

بعد الإعداد، يمكنك استدعاء هذه الوظائف باللغة الطبيعية في عملاء الذكاء الاصطناعي، مثل:

- "ساعدني في توليد صورة بأسلوب الرسم بالحبر الصيني باستخدام Seedream"
- "غيّر خلفية هذه الصورة إلى سماء مرصعة بالنجوم"
- "استخدم Seedream v4.5 لتوليد صورة شخصية بدقة 4K عالية"
- "جرب هذه الملابس افتراضياً على هذه الصورة"
