[MCP（Model Context Protocol）](https://modelcontextprotocol.io) هو بروتوكول سياق النماذج الذي أطلقته Anthropic، ويتيح لنماذج الذكاء الاصطناعي (مثل Claude وGPT وغيرها) استدعاء الأدوات الخارجية عبر واجهات موحّدة. من خلال Flux MCP Server الذي توفره AceData Cloud، يمكنك إنشاء صور الذكاء الاصطناعي وتحريرها مباشرةً في عملاء الذكاء الاصطناعي مثل Claude Desktop وVS Code وCursor وغيرها.

## نظرة عامة على الميزات

يوفر Flux MCP Server الميزات الأساسية التالية:

- **توليد الصور من النص** — إنشاء صور عالية الجودة عبر مطالبات نصية
- **تحرير الصور** — تحرير الصور الموجودة بناءً على تعليمات نصية
- **دعم نماذج متعددة** — يدعم عدة نماذج مثل Flux Pro وFlux Dev وFlux 2 وFlux Kontext وغيرها
- **استعلام النماذج** — عرض جميع النماذج المتاحة وقدراتها
- **استعلام المهام** — مراقبة تقدم التوليد والحصول على النتائج

## التحضير المسبق

قبل الاستخدام، تحتاج إلى الحصول على AceData Cloud API Token:

1. سجّل أو سجّل الدخول إلى [منصة AceData Cloud](https://platform.acedata.cloud)
2. انتقل إلى صفحة [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. انقر على «Acquire» للحصول على API Token (يتم منح رصيد مجاني عند التقديم لأول مرة)

## الطريقة الأولى: استخدام MCP Server المستضاف (موصى بها، بدون تثبيت)

لقد استضافت AceData Cloud **Flux MCP Server** على السحابة، **ولا تحتاج إلى تثبيت أي تبعيات محليًا**، ما عليك سوى إدخال عنوان URL التالي مباشرةً في عميل الذكاء الاصطناعي لاستخدامه:

```
https://flux.mcp.acedata.cloud/mcp
```

طريقة المصادقة: أضف `Authorization: Bearer API Token الخاص بك` إلى رأس الطلب (يكمل Claude.ai ذلك تلقائيًا عبر OAuth، ولا حاجة لإدخال Token يدويًا).

### Claude.ai (نسخة الويب، تسجيل دخول OAuth، الأسهل)

1. افتح [Claude.ai](https://claude.ai) → **Customize** في الزاوية السفلية اليسرى → **Connectors** → **Add More**
2. أدخل في خانة URL: `https://flux.mcp.acedata.cloud/mcp`
3. أكمل تسجيل الدخول بتفويض OAuth (سيتم الانتقال تلقائيًا إلى صفحة تسجيل دخول AceData Cloud)
4. عد إلى واجهة المحادثة، وستكون الأدوات جاهزة للاستخدام

### Claude Desktop

حرّر ملف الإعدادات:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

أعد تشغيل Claude Desktop بعد الحفظ لتفعيل الإعدادات.

### Claude Code (سطر أوامر الطرفية)

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### عملاء آخرون يدعمون MCP

يمكن لأي عميل يدعم بروتوكول MCP Streamable HTTP (مثل Windsurf وCline وChatGPT Connectors وGemini CLI وJetBrains AI Assistant وغيرها) الاتصال عبر إدخال العنصرين التاليين:

- **URL**: `https://flux.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer API Token الخاص بك`

## الطريقة الثانية: التشغيل محليًا (تثبيت pip / uvx)

إذا كنت تحتاج إلى التشغيل دون اتصال بالإنترنت، أو تخصيص الشيفرة، أو النشر داخل الشبكة الداخلية، فيمكنك تثبيت MCP Server محليًا وتشغيله عبر stdio.

### التثبيت

التثبيت عبر pip (موصى به):

```bash
pip install mcp-flux-pro
```

أو التثبيت من المصدر:

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

بعد اكتمال التثبيت، يمكنك استخدام الأمر `mcp-flux-pro` لبدء الخدمة.

### الاستخدام في Claude Desktop (محليًا)

حرّر ملف إعدادات Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

أضف الإعدادات التالية:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

في حال استخدام `uvx` (لا حاجة لتثبيت الحزمة مسبقًا):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

أعد تشغيل Claude Desktop بعد حفظ الإعدادات لتفعيلها.

## قائمة الأدوات المتاحة

| اسم الأداة                    | الوصف                       |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | توليد صورة عبر مطالبة نصية              |
| `flux_edit_image`      | تحرير صورة موجودة بناءً على تعليمات نصية             |
| `flux_generate_video`  | توليد FLUX 3 من النص/الصورة/الفيديو وتعزيز المسودات الموجودة |
| `flux_get_task`        | استعلام حالة مهمة واحدة                 |
| `flux_get_tasks_batch` | استعلام حالات المهام بشكل جماعي                 |
| `flux_list_models`     | عرض جميع النماذج المتاحة وقدراتها             |
| `flux_list_actions`    | عرض جميع الأدوات المتاحة وأمثلة سير العمل           |

## أمثلة الاستخدام

بعد إكمال الإعداد، يمكنك استدعاء هذه الميزات مباشرةً باللغة الطبيعية في عميل الذكاء الاصطناعي، على سبيل المثال:

- «ساعدني في استخدام Flux لإنشاء صورة لمنظر مدينة ليلي بأسلوب السايبربانك»
- «غيّر خلفية هذه الصورة إلى شاطئ»
- «استخدم نموذج Flux Kontext Pro لتحرير هذه الصورة وتغيير لون الملابس إلى الأحمر»
- «اعرض جميع نماذج Flux المتاحة»

## قيود النماذج والأبعاد
يجب أن يستخدم `size` لنماذج `flux-2-flex` و`flux-2-pro` و`flux-2-max` وKontext
النِّسب، مثل `1:1` أو `16:9`، ولا يمكن استخدام أبعاد البكسل مثل `1024x1024`.
يدعم `flux-2-klein` التوليد فقط، وليس ضمن النماذج الاختيارية في `flux_edit_image`.

يميز `flux_generate_video` بين `t2v` و`i2v` و`v2v` و
`draft_enhance` عبر `request.mode`، وتُعرض المدخلات حسب الوضع. يجب أن يشير تحسين المسودة إلى `draft_task_id` المؤقت الخاص به.
يكون الإرسال غير متزامن افتراضيًا، ويجب الاحتفاظ بمعرّف المهمة المُعاد واستخدام `flux_get_task` لقراءة النتيجة.
