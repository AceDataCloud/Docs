[MCP (Model Context Protocol)](https://modelcontextprotocol.io) هو بروتوكول سياق النموذج الذي أطلقته Anthropic، والذي يسمح لنماذج الذكاء الاصطناعي مثل Claude و GPT وغيرها باستدعاء الأدوات الخارجية عبر واجهة موحدة. من خلال خادم Flux MCP الذي توفره AceData Cloud، يمكنك إنشاء وتحرير صور الذكاء الاصطناعي مباشرة في عملاء AI مثل Claude Desktop و VS Code و Cursor.

## نظرة عامة على الوظائف

يقدم خادم Flux MCP الوظائف الأساسية التالية:

- **توليد الصور من النص** — إنشاء صور عالية الجودة بناءً على تعليمات نصية
- **تحرير الصور** — تعديل الصور الموجودة بناءً على أوامر نصية
- **دعم نماذج متعددة** — يدعم نماذج Flux Pro و Flux Dev و Flux Schnell و Flux Kontext وغيرها
- **استعلام النماذج** — عرض جميع النماذج المتاحة وقدراتها
- **استعلام المهام** — مراقبة تقدم التوليد والحصول على النتائج

## المتطلبات المسبقة

قبل الاستخدام، تحتاج إلى الحصول على رمز API من AceData Cloud:

1. سجل أو قم بتسجيل الدخول إلى [منصة AceData Cloud](https://platform.acedata.cloud)
2. انتقل إلى صفحة [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. اضغط على "Acquire" للحصول على رمز API (يتم منح حصة مجانية عند الطلب لأول مرة)

## التثبيت والإعداد

### الطريقة الأولى: التثبيت عبر pip (موصى به)

```bash
pip install mcp-flux-pro
```

### الطريقة الثانية: التثبيت من المصدر

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

بعد التثبيت، يمكنك تشغيل الخدمة باستخدام الأمر `mcp-flux-pro`.

## الاستخدام في Claude Desktop

قم بتحرير ملف إعدادات Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

أضف الإعداد التالي:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

إذا كنت تستخدم `uvx` (لا حاجة لتثبيت الحزم مسبقًا):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "رمز API الخاص بك"
      }
    }
  }
}
```

بعد حفظ الإعدادات، أعد تشغيل Claude Desktop لتتمكن من استخدام أدوات Flux في المحادثات.

## قائمة الأدوات المتاحة

| اسم الأداة             | الوصف                          |
|-----------------------|-------------------------------|
| `flux_generate_image`  | توليد صورة من تعليمات نصية     |
| `flux_edit_image`      | تحرير صورة موجودة بناءً على نص |
| `flux_get_task`        | استعلام حالة مهمة واحدة        |
| `flux_get_tasks_batch` | استعلام حالة مهام متعددة       |
| `flux_list_models`     | عرض جميع النماذج المتاحة وقدراتها |
| `flux_list_actions`    | عرض جميع الأدوات وأمثلة سير العمل |

## أمثلة على الاستخدام

بعد الإعداد، يمكنك استدعاء هذه الوظائف مباشرة باستخدام اللغة الطبيعية في عملاء AI، مثل:

- "ساعدني في توليد صورة لمدينة بأسلوب سايبربانك باستخدام Flux"
- "غيّر خلفية هذه الصورة إلى شاطئ"
- "استخدم نموذج Flux Kontext Pro لتحرير هذه الصورة وتغيير لون الملابس إلى الأحمر"
- "اعرض جميع نماذج Flux المتاحة"
