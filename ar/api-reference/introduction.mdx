## عنوان الأساس

العنوان الأساسي لجميع نقاط نهاية API:

```
https://api.acedata.cloud
```

## المصادقة

جميع النقاط النهائية تتطلب مصادقة Bearer Token:

```
Authorization: Bearer YOUR_API_TOKEN
```

## الاختبار عبر الإنترنت

كل نقطة نهاية في هذا المرجع تحتوي على صندوق رمل تفاعلي. أدخل رمز API لاختبار الطلبات مباشرة في المتصفح.

<Note title="نصيحة">
  احصل على رمز API من [platform.acedata.cloud](https://platform.acedata.cloud).
</Note>
