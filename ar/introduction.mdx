## ما هو Ace Data Cloud؟

Ace Data Cloud هو منصة API موحدة للذكاء الاصطناعي، تتيح الوصول إلى خدمات الذكاء الاصطناعي الرائدة عالميًا من خلال مفتاح API واحد وواجهة موحدة.

## المزايا الأساسية

- **API موحد** — وصول إلى أكثر من 50 خدمة ذكاء اصطناعي بمفتاح API واحد
- **متوافق مع OpenAI** — يمكن استدعاء Claude، Gemini، DeepSeek وغيرها مباشرة عبر واجهة OpenAI
- **صندوق رمل تفاعلي** — اختبار كل API مباشرة ضمن الوثائق
- **الدفع حسب الاستخدام** — لا توجد رسوم اشتراك، الدفع بناءً على الاستخدام الفعلي
- **خوادم MCP** — دعم أصلي لأدوات برمجة الذكاء الاصطناعي مثل Cursor، Claude وغيرها
