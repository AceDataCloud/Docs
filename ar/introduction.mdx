## ما هو Ace Data Cloud؟

Ace Data Cloud هو منصة API موحدة للذكاء الاصطناعي، تتيح الوصول إلى خدمات الذكاء الاصطناعي الرائدة عالميًا من خلال مفتاح API واحد وواجهة موحدة.

## المزايا الأساسية

- **API موحدة** — مفتاح API واحد للوصول إلى أكثر من 50 خدمة ذكاء اصطناعي
- **متوافق مع OpenAI** — يمكن استدعاء نماذج مثل Claude وGemini وDeepSeek مباشرة عبر واجهة OpenAI
- **صندوق رمل تفاعلي** — اختبار كل API مباشرة داخل الوثائق
- **الدفع حسب الاستخدام** — بدون رسوم اشتراك، الدفع حسب الاستخدام الفعلي
- **خوادم MCP** — دعم أصلي لأدوات البرمجة بالذكاء الاصطناعي مثل Cursor وClaude
