Claude Code é um agente inteligente de programação lançado pela Anthropic, que pode ser usado em diversos ambientes, como terminais, IDEs e aplicativos de desktop. Através do proxy AceData Cloud, você pode usar o Claude Code a um custo mais baixo.

Por favor, escolha o tutorial de configuração correspondente à sua situação de uso:

| Plataforma           | Descrição                                   | Link do Tutorial                                                                                           |
| ------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **Terminal (CLI)**  | Experiência principal, execute `claude` em qualquer terminal para começar | [Tutorial de Configuração do Terminal](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code**         | Extensão nativa, suporta Diff inline, @-menções, revisão planejada | [Tutorial de Configuração do VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **JetBrains IDE**   | Suporta toda a linha de IDEs como IntelliJ IDEA, PyCharm, WebStorm | [Tutorial de Configuração do JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions**  | Automatize revisões de código e tratamento de Issues com `@claude` | [Tutorial de Configuração do GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Dica**: Para solicitações iniciais, você pode visitar a [página de serviços do Claude Messages](https://platform.acedata.cloud/documents/claude-messages) e clicar em "Acquire" para obter um token, que inclui um crédito gratuito.
