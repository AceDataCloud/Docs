Claude Code se conecta ao Coding Plan através do protocolo Anthropic Messages, atualmente oferecendo duas entradas de configuração: Terminal e VS Code.

| Entrada de Uso      | Guia de Configuração                                                                                       |
| ------------------ | --------------------------------------------------------------------------------------------------------- |
| Terminal / CLI     | [Configuração do Claude Code no Terminal](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code            | [Configuração do Claude Code para VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## Configuração Comum

- URL Base: `https://api.acedata.cloud`
- Token da API: obtido a partir da Aplicação de Codificação e configurado através de `ANTHROPIC_AUTH_TOKEN` no guia
- ID do Modelo: selecionado a partir do diretório de modelos em tempo real
- Após modificar a configuração: reinicie o Claude Code; usuários do VS Code precisam recarregar a janela

Não mantenha ao mesmo tempo a antiga `ANTHROPIC_API_KEY`, nem escreva o Token real em arquivos compartilhados pela equipe.

Volte para o [Centro de Configuração do Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
