Claude Code é um agente inteligente de programação lançado pela Anthropic, que pode ser usado em diversos ambientes como terminal, IDE e pipelines CI/CD. Através do proxy AceData Cloud, você pode usar o Claude Code a um custo mais baixo.

Escolha o tutorial completo de configuração para a plataforma correspondente ao seu cenário de uso:

| Plataforma | Descrição | Link do Tutorial |
|------------|-----------|------------------|
| **VS Code** | Extensão nativa, suporta Diff inline, @-mentions, revisão planejada | [Tutorial de Configuração do VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | Editor compatível com VS Code, extensão Claude Code totalmente suportada | [Tutorial de Configuração do Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **Terminal (CLI)** | Experiência principal, basta rodar `claude` em qualquer terminal para começar | [Tutorial de Configuração do Terminal](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **JetBrains IDE** | Suporta IntelliJ IDEA, PyCharm, WebStorm e toda a linha de IDEs | [Tutorial de Configuração do JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Use `@claude` para automatizar revisão de código e tratamento de Issues | [Tutorial de Configuração do GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Dica**: Para a primeira solicitação, acesse a [página do serviço Claude Messages](https://platform.acedata.cloud/documents/claude-messages) e clique em "Acquire" para obter as credenciais, ganhando uma cota gratuita.
