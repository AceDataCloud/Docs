Claude Code é uma ferramenta de **Codificação Agente** lançada pela Anthropic, também conhecida como um dos agentes de programação mais poderosos do mundo. O terminal CLI é a experiência central do Claude Code, onde você pode executar o comando `claude` em qualquer terminal e colaborar em programação com a IA usando linguagem natural.

Este documento apresenta como instalar, configurar e usar o Claude Code CLI através do serviço de proxy da AceData Cloud no terminal.

## Processo de Solicitação

Para usar o Claude Code, primeiro você pode acessar a [página de serviços Claude Messages](https://platform.acedata.cloud/documents/claude-messages) e clicar no botão "Acquire" para obter as credenciais necessárias para a solicitação:

![](https://cdn.acedata.cloud/nyq0xz.png)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, convidando-o a se registrar e logar. Após o registro e login, você será redirecionado de volta para a página atual.

Na primeira solicitação, haverá um crédito gratuito disponível para que você possa experimentar o serviço Claude Code sem custo.

## Instalação do Claude Code

### Requisitos do Sistema

- macOS, Linux ou Windows (incluindo WSL)
- Node.js não é obrigatório, o método de instalação nativo gerenciará automaticamente as dependências

### Métodos de Instalação

Claude Code suporta vários métodos de instalação:

**Método 1: Instalação Nativa (Recomendado)**

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows CMD:

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**Método 2: Homebrew (macOS / Linux)**

```bash
brew install claude-code
```

**Método 3: WinGet (Windows)**

```cmd
winget install Claude.ClaudeCode
```

A instalação nativa atualizará automaticamente em segundo plano, mantendo sempre a versão mais recente.

## Configuração da API da AceData Cloud

Após a instalação, você será solicitado a fazer login na conta oficial da Anthropic. Podemos usar variáveis de ambiente para configurar a API de proxy da AceData Cloud, **sem necessidade de assinatura oficial**.

### Configuração de Variáveis de Ambiente

Existem duas maneiras de configurar variáveis de ambiente, escolha uma delas.

**Método 1: Configurar no arquivo de configuração do Shell (Recomendado)**

Adicione o seguinte conteúdo ao seu arquivo de configuração do Shell (`~/.zshrc`, `~/.bashrc` ou `~/.bash_profile`), substituindo `{token}` pelo token da API que você obteve no console da AceData Cloud:

```bash
# AceData Cloud - Configuração do Proxy do Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Após a modificação, execute o seguinte comando para aplicar a configuração:

```bash
source ~/.zshrc  # ou source ~/.bashrc
```

**Método 2: Configurar no settings.json do Claude Code**

Edite `~/.claude/settings.json` (crie se não existir) e adicione a configuração `env`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

A vantagem desse método é que as variáveis de ambiente só afetam o Claude Code, sem impactar outros programas.

> **Dica**: O token da API pode ser visualizado no [console da AceData Cloud](https://platform.acedata.cloud/console). O valor de `ANTHROPIC_AUTH_TOKEN` será automaticamente precedido pelo prefixo `Bearer` ao ser enviado ao servidor.

## Começando a Usar

### Iniciar Modo Interativo

Abra o terminal, navegue até o diretório do seu projeto e execute:

```bash
cd /path/to/your/project
claude
```

Você verá a tela de boas-vindas do Claude Code, onde pode começar a interagir digitando em linguagem natural.

### Comandos Comuns

| Comando            | Descrição                | Exemplo                   |
| ------------------ | ----------------------- | ------------------------- |
| `claude`           | Iniciar modo interativo  | `claude`                 |
| `claude "tarefa"`  | Executar tarefa única    | `claude "corrigir erro de construção"` |
| `claude -p "consulta"` | Executar consulta e sair | `claude -p "explique esta função"` |
| `claude -c`       | Continuar a conversa mais recente no diretório atual | `claude -c`              |
| `claude -r`       | Recuperar conversa anterior | `claude -r`              |
| `claude commit`    | Criar commit no Git      | `claude commit`          |

### Comandos do Modo Interativo

No modo interativo, você pode usar os seguintes comandos internos:

| Comando            | Função                  |
| ------------------ | ---------------------- |
| `/help`            | Exibir informações de ajuda |
| `/clear`           | Limpar histórico de conversa |
| `/config`          | Abrir painel de configurações |
| `/model`           | Alternar modelo        |
| `/mcp`             | Gerenciar serviço MCP   |
| `/compact`         | Compactar contexto      |
| `/memory`          | Gerenciar memória       |
| `/login`           | Alternar conta         |
| `exit` ou `Ctrl+C` | Sair                   |

### Exemplos de Interação

```bash
# Analisando o projeto
> o que este projeto faz?

# Corrigindo Bug
> há um bug onde os usuários podem enviar formulários vazios - conserte isso

# Escrevendo testes
> escreva testes unitários para as funções do calculador

# Refatorando código
> refatore o módulo de autenticação para usar async/await

# Operações Git
> faça commit das minhas alterações com uma mensagem descritiva
> crie um PR para este recurso
```

## Uso Avançado

### Encadeamento e Scriptização

Claude Code segue a filosofia Unix, suportando encadeamento e operações scriptadas:

```bash
# Monitorar logs e alertar automaticamente
tail -f app.log | claude -p "se encontrar anomalias, me avise"

# Traduzir automaticamente novos textos
claude -p "se houver novas strings de texto, traduza para francês e crie um PR"

# Revisão de código
git diff main | claude -p "revise essas alterações"
```

### Referência de Variáveis de Ambiente

Aqui estão algumas variáveis de ambiente comuns suportadas pelo Claude Code:

| Variável                       | Descrição                                      |
| ------------------------------ | ---------------------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`        | Valor do cabeçalho Authorization personalizado (prefixo Bearer adicionado automaticamente) |
| `ANTHROPIC_API_KEY`           | Chave da API (enviada como cabeçalho X-Api-Key) |
| `ANTHROPIC_BASE_URL`          | URL base da API                               |
| `ANTHROPIC_MODEL`             | Sobrescrever modelo padrão                     |
| `ANTHROPIC_SMALL_FAST_MODEL`  | Modelo de nível Haiku (para tarefas em segundo plano) |
| `MAX_THINKING_TOKENS`         | Definir orçamento de tokens de pensamento (defina como 0 para desativar o modo de pensamento) |
| `DISABLE_COST_WARNINGS`       | Defina como 1 para desativar avisos de custo  |

### Memória do Projeto CLAUDE.md

Crie um arquivo `CLAUDE.md` no diretório raiz do projeto para fornecer instruções e contexto específicos do projeto ao Claude Code. Claude carregará automaticamente este arquivo ao iniciar.

```markdown
# Descrição do Projeto
Este é um projeto full-stack Django + Vue.js.

## Padrões de Codificação
- Usar Python 3.12
- Seguir o estilo de código PEP 8
- Todos os APIs precisam ter testes unitários
```

## Perguntas Frequentes

### O que fazer se a conexão falhar?
1. Verifique se o arquivo `~/.claude/config.json` foi criado corretamente, com o conteúdo `{"primaryApiKey": "self"}`
2. Confirme se as variáveis de ambiente estão configuradas corretamente:
   ```bash
   echo $ANTHROPIC_AUTH_TOKEN
   echo $ANTHROPIC_BASE_URL
   ```
3. Confirme se o token da API é válido (pode ser verificado no [console](https://platform.acedata.cloud/console))
4. Tente reiniciar o terminal

### comando não encontrado: claude

Se, após a instalação, aparecer a mensagem `command not found`, tente:

1. Fechar e reabrir o terminal
2. Verificar o PATH: `echo $PATH`
3. Reinstalar: `curl -fsSL https://claude.ai/install.sh | bash`

### Como verificar o saldo restante?

Faça login no [console da AceData Cloud](https://platform.acedata.cloud/console) para ver o saldo restante e o uso atual da conta.
