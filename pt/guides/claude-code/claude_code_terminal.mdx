## 1. Obter API Key

Abra a [lista de aplicativos do Ace Data Cloud](https://platform.acedata.cloud/console/applications), acesse os aplicativos disponíveis e copie a API Key.

![Obter Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar Claude Code

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
```

Verifique após a instalação:

```bash
claude --version
```

## 3. Configurar Ace Data Cloud

Para uso global, adicione as seguintes variáveis em `~/.zshrc` ou `~/.bashrc`：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sua API Key"
unset ANTHROPIC_API_KEY
```

Reabra o terminal ou `source` o arquivo de configuração correspondente.

Para efeito apenas no projeto atual, você pode criar um `.claude/settings.local.json` que já esteja incluído no `.gitignore`：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "sua API Key"
  }
}
```

Escolha uma das duas opções. Não escreva a chave real no `.claude/settings.json` compartilhado pela equipe; se a variável `ANTHROPIC_API_KEY` já existir no ambiente, deve ser realmente removida, e não apenas definida como uma string vazia.

## 4. Iniciar e Verificar

```bash
cd /caminho/para/seu/projeto
claude
```

Após entrar, envie uma tarefa somente leitura, como "ler README.md e resumir em uma frase". Os registros de chamadas e saldo podem ser visualizados em [Histórico de Uso](https://platform.acedata.cloud/console/usages) e [Lista de Aplicativos](https://platform.acedata.cloud/console/applications).

Se retornar 401, verifique se a chave está completa, se a antiga `ANTHROPIC_API_KEY` foi removida e reinicie completamente o Claude Code. O modelo não precisa estar fixo na configuração de acesso, pode ser escolhido um modelo disponível no Claude Code.
