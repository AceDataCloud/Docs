Claude Code é uma ferramenta de **Agentic Coding** lançada pela Anthropic, também conhecida como um dos agentes de programação mais poderosos do mundo. Claude Code oferece um plugin específico para JetBrains IDE, suportando IntelliJ IDEA, PyCharm, WebStorm, GoLand, PhpStorm, Android Studio e toda a linha de IDEs da JetBrains.

Este documento apresenta como configurar e usar o Claude Code no JetBrains IDE através do serviço de proxy da AceData Cloud.

## Processo de Solicitação

Para usar o Claude Code, primeiro você pode acessar a [página de serviços Claude Messages](https://platform.acedata.cloud/documents/claude-messages) e clicar no botão "Acquire" para obter as credenciais necessárias para a solicitação:

![](https://cdn.acedata.cloud/nyq0xz.png)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, convidando-o a se registrar e logar. Após o login ou registro, você será redirecionado de volta para a página atual.

Na primeira solicitação, haverá um crédito gratuito disponível para que você possa experimentar o serviço Claude Code sem custo.

## Instalação

### Pré-requisitos

O plugin Claude Code para JetBrains depende do Claude Code CLI, portanto, certifique-se de que o CLI esteja instalado:

```bash
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# Ou use o Homebrew
brew install claude-code
```

Após a instalação, você pode verificar:

```bash
claude --version
```

### Instalação do Plugin

![Plugin Claude Code no JetBrains Marketplace](https://cdn.acedata.cloud/de78fd305b.png)

1. Abra o JetBrains IDE
2. Vá para **Settings** → **Plugins** → **Marketplace**
3. Pesquise por **Claude Code**
4. Clique em **Install** para instalar o plugin
5. Reinicie o IDE

Ou acesse diretamente o [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/27310-claude-code-beta-) para instalação online.

> **Importante**: Após instalar o plugin, é necessário **reiniciar completamente o IDE** (pode ser necessário reiniciar várias vezes) para que funcione.

## Configuração da API AceData Cloud

O plugin Claude Code para JetBrains executa o comando `claude` através do terminal integrado, portanto, a configuração das variáveis de ambiente é a mesma do CLI.

### Passo 1: Criar config.json

Crie o arquivo de configuração do Claude Code:

| Sistema            | Caminho                                   |
| ----------------- | ------------------------------------ |
| **macOS / Linux** | `~/.claude/config.json`              |
| **Windows**       | `C:\Users\{nome de usuário}\.claude\config.json` |

Escreva o seguinte conteúdo neste arquivo e salve:

```json
{
  "primaryApiKey": "self"
}
```

Comando rápido para criar no macOS / Linux:

```bash
mkdir -p ~/.claude && echo '{"primaryApiKey": "self"}' > ~/.claude/config.json
```

### Passo 2: Configurar Variáveis de Ambiente

**Método 1: Configurar no arquivo de configuração do Shell (recomendado)**

Adicione o seguinte conteúdo ao seu `~/.zshrc` ou `~/.bashrc`, substituindo `{token}` pelo seu token de API:

```bash
# AceData Cloud - Configuração do proxy Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Após modificar, execute `source ~/.zshrc` para que a configuração tenha efeito, e então **reinicie o JetBrains IDE**.

**Método 2: Configurar no settings.json do Claude Code**

Edite `~/.claude/settings.json` (crie se não existir):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Dica**: O token de API pode ser visualizado no [console da AceData Cloud](https://platform.acedata.cloud/console).

## Uso Básico

### Iniciar a partir do Terminal Integrado do IDE

Abra o terminal integrado do JetBrains IDE e execute:

```bash
claude
```

Ao executar no terminal integrado do IDE, todas as funcionalidades integradas (visualização de Diff, seleção de contexto, etc.) serão ativadas automaticamente.

### Conectar a partir do Terminal Externo

Se você estiver executando o Claude Code em um terminal externo, pode usar o comando `/ide` para se conectar ao JetBrains IDE:

```bash
claude
> /ide
```

Certifique-se de iniciar o Claude Code a partir do mesmo diretório raiz do projeto do IDE, para que o Claude possa acessar o mesmo conjunto de arquivos.

### Atalhos

| Atalho                                              | Função                      |
| ------------------------------------------------ | ----------------------- |
| `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux)        | Abrir rapidamente o Claude Code        |
| `Cmd+Option+K` (Mac) / `Alt+Ctrl+K` (Windows/Linux) | Inserir referência de arquivo (ex: `@File#L1-99`) |

### Funcionalidades Integradas

O plugin Claude Code para JetBrains oferece as seguintes funcionalidades integradas:

- **Visualização de Diff**: Mudanças de código são exibidas diretamente no visualizador de Diff do IDE
- **Seleção de Contexto**: O código e a aba selecionados atualmente são compartilhados automaticamente com o Claude
- **Referência de Arquivo**: Use atalhos para referenciar rapidamente arquivos e números de linha
- **Compartilhamento de Diagnósticos**: Informações de diagnóstico como Lint e erros de sintaxe no IDE são compartilhadas automaticamente com o Claude

## Configurações do Plugin

Você pode configurar em **Settings** → **Tools** → **Claude Code [Beta]**:

| Configuração                        | Descrição                                         |
| --------------------------------- | ------------------------------------------ |
| **Comando Claude**                | Caminho do comando Claude personalizado (ex: `/usr/local/bin/claude`) |
| **Habilitar atualizações automáticas**  | Verificar e instalar atualizações do plugin automaticamente                                |
| **Habilitar uso de Option+Enter** | Usar Option+Enter no macOS para quebrar linha na caixa de diálogo             |

### Configuração para Usuários WSL

Se você estiver usando em um ambiente WSL, deve definir o comando Claude como:

```
wsl -d Ubuntu -- bash -lic "claude"
```

(Substitua `Ubuntu` pelo nome da sua distribuição WSL)

## Perguntas Frequentes

### O que fazer se a conexão falhar?

1. Verifique se o arquivo `~/.claude/config.json` foi criado corretamente
2. Confirme se as variáveis de ambiente estão configuradas corretamente
3. Verifique se o token de API é válido (pode ser visualizado no [console](https://platform.acedata.cloud/console))
4. Reinicie o JetBrains IDE e tente novamente

### O plugin não está funcionando?

1. Certifique-se de que o Claude Code está sendo executado a partir do diretório raiz do projeto
2. Verifique se o plugin está habilitado nas configurações do IDE
3. Reinicie completamente o IDE (pode ser necessário reiniciar várias vezes)
4. Se estiver usando o modo de desenvolvimento remoto, certifique-se de que o plugin está instalado na máquina remota (Settings → Plugin (Host))

### IDE não detectada?

1. Confirme se o plugin está instalado e habilitado
2. Reinicie o IDE
3. Certifique-se de que o Claude Code está sendo executado no terminal integrado
4. Usuários WSL devem consultar o [Guia de Solução de Problemas do WSL](https://code.claude.com/docs/en/troubleshooting#jetbrains-ide-not-detected-on-wsl2)

### comando não encontrado

Se ao clicar no ícone do Claude aparecer "comando não encontrado":

1. Verifique se o CLI está instalado: `which claude`
2. Configure o caminho completo do comando Claude nas configurações do plugin
3. Usuários WSL devem usar o formato de comando WSL mencionado acima
### Como verificar o saldo restante?

Faça login no [Console da AceData Cloud](https://platform.acedata.cloud/console) para visualizar o saldo restante e o uso atual da sua conta.
