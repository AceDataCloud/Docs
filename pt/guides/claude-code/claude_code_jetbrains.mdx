## 1. Obter API Key

Abra a [lista de aplicativos do Ace Data Cloud](https://platform.acedata.cloud/console/applications), acesse os aplicativos disponíveis e copie a API Key.

![Obter Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar CLI e Plugin

Primeiro, instale o Claude Code CLI.

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

Em seguida, instale o plugin **Claude Code** a partir do JetBrains Marketplace e reinicie o IDE. O plugin chama o comando `claude` local; se aparecer uma mensagem de comando não encontrado, preencha o caminho completo em **Settings → Tools → Claude Code**.

## 3. Configurar Ace Data Cloud

Configure no ambiente que inicia o backend do JetBrains.

macOS / Linux / WSL:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sua API Key"
unset ANTHROPIC_API_KEY
```

Windows PowerShell:

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "sua API Key"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

Você também pode usar o arquivo `.claude/settings.local.json` que foi ignorado no projeto:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "sua API Key"
  }
}
```

O Desenvolvimento Remoto deve ser configurado e o plugin instalado no Host remoto; usuários do WSL podem definir o comando Claude como `wsl -d Ubuntu -- bash -lic "claude"`.

## 4. Verificação

Execute `claude` no terminal integrado do IDE ou inicie um terminal externo e digite `/ide`. Após a conexão bem-sucedida, faça com que Claude responda `OK`, em seguida, leia um arquivo de teste e verifique essa solicitação no [histórico de uso](https://platform.acedata.cloud/console/usages) do Ace Data Cloud.

Se o plugin não iniciar, execute `claude --version` no mesmo terminal; se retornar 401, verifique as variáveis de ambiente que o backend realmente herda e a antiga `ANTHROPIC_API_KEY`.
