## 1. Obter API Key

Abra a [lista de aplicativos do Ace Data Cloud](https://platform.acedata.cloud/console/applications), acesse os aplicativos disponíveis e copie a API Key.

![Obter Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar o CC Switch

Baixe a partir do [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), o macOS também pode ser executado:

```bash
brew install --cask cc-switch
```

## 3. Adicionar Provider

Abra o CC Switch, selecione **Claude Code → Add Provider → Custom**, preencha:

| Campo       | Valor                        |
| ----------- | ---------------------------- |
| Nome        | `Ace Data Cloud`             |
| URL Base    | `https://api.acedata.cloud`  |
| API Key     | A API Key copiada anteriormente  |
| Formato API | `Anthropic Messages`         |

Se precisar usar o editor JSON, configure como:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

O CC Switch escreverá a configuração nas configurações do usuário do Claude Code. Não salve a chave real no repositório da equipe e não mantenha ao mesmo tempo a antiga `ANTHROPIC_API_KEY`.

## 4. Ativar e Verificar

Após salvar, ative **Ace Data Cloud**, reinicie o Claude Code. Envie uma tarefa simples de leitura e verifique a chamada em [Histórico de Uso](https://platform.acedata.cloud/console/usages). Se após a troca ainda estiver usando a configuração antiga, saia completamente do Claude Code e do CC Switch e tente novamente.
