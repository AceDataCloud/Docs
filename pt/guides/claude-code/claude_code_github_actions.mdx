## 1. Obter API Key

Abra a [lista de aplicativos do Ace Data Cloud](https://platform.acedata.cloud/console/applications), acesse o aplicativo disponível e copie a API Key.

![Obter Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

No repositório GitHub de destino, vá em **Settings → Secrets and variables → Actions** e crie um novo Secret:

```text
ACEDATACLOUD_API_KEY
```

## 2. Instalar o GitHub App

Instale o [Claude GitHub App](https://github.com/apps/claude) e autorize o repositório de destino. Este App oficial solicitará um conjunto fixo de permissões completas; entre elas, a Claude Code Action realmente utiliza as permissões de Contents, Issues e Pull requests, a página de instalação do GitHub não pode selecionar apenas essas três opções. Se a organização exigir permissões mínimas, siga a documentação oficial para criar um GitHub App personalizado.

## 3. Adicionar Workflow

Crie o arquivo `.github/workflows/claude.yml`:

```yaml
name: Claude Code

on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  claude:
    if: contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      actions: read
      id-token: write
    env:
      ANTHROPIC_BASE_URL: https://api.acedata.cloud
      ANTHROPIC_CUSTOM_HEADERS: "Authorization: Bearer ${{ secrets.ACEDATACLOUD_API_KEY }}"
    steps:
      - uses: actions/checkout@v6
        with:
          fetch-depth: 1
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: dummy-not-used
```

`claude-code-action` requer uma entrada `anthropic_api_key` não vazia; o valor de espaço reservado aqui não será utilizado para autenticação na plataforma. `ANTHROPIC_CUSTOM_HEADERS` irá sobrescrever o Bearer Header necessário para o Ace Data Cloud, a chave real vem apenas do GitHub Secret.

## 4. Verificação

Após submeter o Workflow, envie um comentário em um Issue ou PR:

```text
@claude Responda apenas OK
```

Se for bem-sucedido, o workflow do Actions será concluído e o resultado será atualizado no respectivo Issue/PR. Se a Action indicar falta de credenciais, confirme se `dummy-not-used` ainda está presente; se retornar 401, verifique o Secret `ACEDATACLOUD_API_KEY`. Não imprima Secrets nos logs. Você pode usar `claude_args` para definir `--max-turns` conforme necessário ou escolher o modelo atualmente disponível, mas a integração do template não fixa o modelo.
