Claude Code é uma ferramenta de **Codificação Agentic** lançada pela Anthropic, também conhecida como um dos agentes de programação mais poderosos do mundo. O aplicativo de desktop Claude Code oferece uma interface gráfica independente, suportando funcionalidades como revisão Diff, sessões paralelas (isoladas por meio do Git Worktree), sessões remotas, entre outras, sem depender de nenhum IDE.

Este documento descreve principalmente como configurar e usar o aplicativo de desktop Claude Code através do serviço de proxy da AceData Cloud.

> **Nota**: O aplicativo de desktop Claude Code está atualmente em fase de pré-visualização (Preview), suportando apenas macOS e Windows.

## Processo de Solicitação

Para usar o Claude Code, primeiro você pode acessar a [página de serviços Claude Messages](https://platform.acedata.cloud/documents/claude-messages) e clicar no botão "Acquire" para obter as credenciais necessárias para a solicitação:

![](https://cdn.acedata.cloud/nyq0xz.png)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, convidando-o a se registrar e fazer login. Após o login ou registro, você será redirecionado de volta para a página atual.

Na primeira solicitação, haverá um crédito gratuito disponível para que você possa experimentar o serviço Claude Code sem custo.

## Instalação do Aplicativo de Desktop

### Requisitos do Sistema

- macOS (Intel e Apple Silicon) ou Windows (x64 / ARM64)
- Linux não suporta o aplicativo de desktop no momento

### Download e Instalação

Acesse a [página de download oficial do Claude](https://claude.ai) para baixar o pacote de instalação correspondente à sua plataforma:

- **macOS**: baixe o arquivo `.dmg` e arraste para a pasta Applications
- **Windows x64**: baixe o pacote de instalação `.exe` e siga as instruções para instalar
- **Windows ARM64**: baixe a versão ARM64 (observação: ARM64 não suporta sessões locais, deve-se usar sessões remotas)

![Página de download do aplicativo de desktop Claude](https://cdn.acedata.cloud/c3c8c57264.png)

Após a instalação, inicie o Claude a partir da pasta Applications (macOS) ou do menu Iniciar (Windows).

## Configuração da API AceData Cloud

Após iniciar o aplicativo de desktop, você precisará fazer login na conta da Anthropic. Podemos usar variáveis de ambiente para configurar a API de proxy da AceData Cloud, **sem necessidade de assinatura oficial**.

O aplicativo de desktop lê as variáveis de ambiente do seu ambiente Shell, portanto, é necessário configurá-las no arquivo de configuração do Shell.

### Configuração de Variáveis de Ambiente

**Usuários de macOS**

Adicione o seguinte conteúdo ao `~/.zshrc` (ou `~/.bashrc`), substituindo `{token}` pelo seu token de API:

```bash
# AceData Cloud - Configuração de Proxy Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Após salvar, execute:

```bash
source ~/.zshrc
```

**Usuários de Windows**

Adicione as seguintes variáveis de ambiente do sistema através de "Propriedades do Sistema → Avançado → Variáveis de Ambiente":

| Nome da Variável          | Valor                           |
| ------------------------- | ------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`   | `{token}` (substitua pelo seu token de API) |
| `ANTHROPIC_BASE_URL`     | `https://api.acedata.cloud`   |

Ou use o PowerShell:

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**Também é possível configurar através do settings.json**

Edite `~/.claude/settings.json` (crie se não existir):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Dica**: O token de API pode ser visualizado no [console da AceData Cloud](https://platform.acedata.cloud/console). Após a configuração, é necessário **reiniciar o aplicativo de desktop** para que as variáveis de ambiente tenham efeito.

## Uso Básico

### Abrir Projeto

1. Inicie o aplicativo de desktop Claude
2. Clique na aba **Code** na parte superior
3. Selecione o modo de execução **Local**
4. Clique em **Select folder** para escolher o diretório do seu projeto

### Iniciar Diálogo

Digite na caixa de entrada uma descrição em linguagem natural da sua necessidade:

- "Encontre comentários TODO e corrija-os"
- "Adicione testes à função principal"
- "Explique a arquitetura deste projeto"

Claude analisará seu repositório de código, sugerirá alterações e exibirá as mudanças em uma visualização Diff.

### Modo de Permissão

Alterne através do seletor de modo ao lado do botão de envio:

| Modo       | Descrição                          |
| ---------- | ---------------------------------- |
| **Ask**    | Pergunta confirmação antes de cada modificação (recomendado para iniciantes) |
| **Code**   | Aceita automaticamente edições de arquivos, mas comandos de terminal ainda precisam de confirmação |
| **Plan**   | Primeiro elabora um plano detalhado aguardando aprovação, só executa após confirmação |

### Sessões Paralelas

Clique em **+ New session** na barra lateral para iniciar várias sessões paralelas. Para repositórios Git, cada sessão obterá uma cópia independente do projeto através do Worktree, sem interferência.

O Worktree é armazenado por padrão no diretório `~/.claude-worktrees/`.

### Revisão Diff

Quando Claude modifica arquivos, exibirá estatísticas de mudanças (como `+12 -1`), clicando você pode abrir o visualizador Diff para revisar as alterações arquivo por arquivo. Você também pode clicar em linhas de código específicas para adicionar comentários, e Claude ajustará com base no seu feedback.

## Conexão com Ferramentas Externas

Antes de iniciar uma sessão, clique no botão **⋯**, selecione **Connectors** para adicionar integrações externas:

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- Mais...

Após a conexão, Claude pode acessar diretamente o calendário, enviar mensagens, criar Issues, etc.

## Relação com CLI

O aplicativo de desktop e a CLI usam o mesmo motor subjacente, compartilhando as seguintes configurações:

- Arquivos de memória do projeto `CLAUDE.md` / `CLAUDE.local.md`
- Configurações do servidor MCP em `~/.claude.json` / `.mcp.json`
- Configurações em `~/.claude/settings.json`
- Configurações de Hooks e Skills

Ambos podem ser executados simultaneamente no mesmo projeto, mantendo cada um seu histórico de sessão independente.

## Perguntas Frequentes

### O que fazer se a conexão falhar?

1. Verifique se o arquivo `~/.claude/config.json` foi criado corretamente
2. Confirme se as variáveis de ambiente estão configuradas corretamente (reinicie o aplicativo de desktop para que tenham efeito)
3. Verifique se o token de API é válido (pode ser visualizado no [console](https://platform.acedata.cloud/console))
4. Se estiver usando `settings.json` para configurar variáveis de ambiente, verifique se o formato do arquivo está correto

### Não consigo encontrar as ferramentas instaladas?

Se Claude não conseguir encontrar comandos como `npm`, `node`, etc.:

1. Confirme se essas ferramentas funcionam normalmente no terminal comum
2. Verifique se seu arquivo de configuração do Shell (`~/.zshrc`, `~/.bashrc`) está configurado corretamente para o PATH
3. Reinicie o aplicativo de desktop para recarregar as variáveis de ambiente

### Como verificar o saldo restante?

Faça login no [console da AceData Cloud](https://platform.acedata.cloud/console) para visualizar o saldo restante e o uso atual da sua conta.
