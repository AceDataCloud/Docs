Claude Code é uma ferramenta de programação lançada pela Anthropic, também conhecida como um dos agentes de programação mais poderosos do mundo. A extensão do Claude Code para o VS Code oferece uma interface gráfica nativa, sendo a forma recomendada de usar o Claude Code no VS Code.

Este documento descreve principalmente como configurar e usar a extensão do Claude Code no VS Code através do serviço de proxy da Ace Data Cloud.

## Processo de Solicitação

Para usar o Claude Code, primeiro você pode acessar o [Console da Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter seu Token de API, que deve ser guardado para uso futuro.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, convidando-o a se registrar e fazer login. Após o registro e login, você será redirecionado de volta para a página atual.

Na primeira solicitação, haverá um crédito gratuito disponível, permitindo que você experimente o serviço Claude Code sem custo.

## Instalação do Plugin Claude Code

Pesquise por **Claude Code** no mercado de extensões do VS Code e instale-o, confirmando que o publicador é **Anthropic**. Após a instalação, um ícone do Claude Code aparecerá na barra de atividades.

## Configuração da API da Ace Data Cloud

Ao abrir o plugin pela primeira vez, será solicitado que você faça login na conta oficial da Anthropic. Podemos pular o login oficial e usar a API de proxy da Ace Data Cloud, sem necessidade de assinatura oficial.

A extensão e o CLI do terminal leem o mesmo conjunto de Configurações do Claude Code. Para informações completas sobre autenticação, tratamento de conflitos de credenciais e configuração global, consulte o [Tutorial de Configuração do Terminal Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration). Se você deseja que a configuração seja válida apenas para o projeto atual, crie um arquivo `.claude/settings.local.json` na raiz do projeto, que deve ser incluído no `.gitignore`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Onde `{token}` é a chave da API que você copiou anteriormente. Se no ambiente em que você iniciou o VS Code já existir um `ANTHROPIC_API_KEY` antigo, primeiro execute `unset ANTHROPIC_API_KEY` nesse ambiente; não trate uma string vazia como limpeza e não coloque a chave real no arquivo compartilhado da equipe `.claude/settings.json`.

Abaixo está a configuração concluída em uma máquina local usando VS Code 1.136.1 e a extensão Claude Code 2.1.251. A captura de tela usa uma chave de espaço reservado para evitar a divulgação de credenciais reais:

![Configuração do Ace Data Cloud Claude Code no VS Code](https://cdn.acedata.cloud/f925e9e9597b.png)

Após a configuração, reinicie o VS Code.

> Nota: A configuração acima é válida apenas para o projeto atual e é recomendável que o caminho do arquivo de configuração `.claude/settings.local.json` seja adicionado ao arquivo `.gitignore` para evitar que seja enviado para o repositório remoto.

Se você deseja que a configuração seja válida para todos os projetos, pode configurá-la diretamente no diretório do usuário. O caminho correspondente é `~/.claude/settings.json`,

> Nota: Após a configuração, reinicie ou recarregue o VS Code para que as configurações entrem em vigor.

## Uso Básico

Após a configuração, envie uma tarefa simples de leitura no painel do Claude Code, como "Leia o README.md e resuma em uma frase". Após a conclusão da tarefa, você pode verificar esta chamada no [Histórico de Uso](https://platform.acedata.cloud/console/usages).

## Como Verificar o Saldo Restante

Através do [Console da Ace Data Cloud - Lista de Aplicativos](https://platform.acedata.cloud/console/applications), você pode verificar o saldo restante da sua conta.

Através do [Console da Ace Data Cloud - Histórico de Uso](https://platform.acedata.cloud/console/usages), você pode ver todo o histórico de uso e detalhes de cobrança.
