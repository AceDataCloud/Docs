Este documento tem um único objetivo: permitir que você **execute seu primeiro comando Claude Code usando o proxy AceData Cloud em 5 minutos**. Para um tutorial completo, consulte os documentos específicos para cada IDE ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); aqui, seguimos o caminho mais rápido com "**CLI no Terminal** + **Extensão VS Code**".

> **Por que usar o proxy AceData Cloud para Claude Code**:
> - Conexão direta dentro da China, sem necessidade de VPN
> - Preços mais baixos que o oficial (cobrança por token na plataforma)
> - A mesma chave suporta simultaneamente Claude Messages API + protocolo Claude Code Token

## Minuto 1: Solicitar Credenciais

Abra a [página do serviço Claude Messages](https://platform.acedata.cloud/documents/claude-messages) e clique no botão "**Acquire**":

![](https://cdn.acedata.cloud/nyq0xz.png)

A plataforma criará automaticamente uma Application para você e concederá um crédito gratuito. Anote o **Base URL** e o **API Token** da página de detalhes — você precisará deles nos próximos 5 passos.

| Campo | Valor | Uso |
|------|------|------|
| `BASE_URL` | `https://api.acedata.cloud` | Endpoint compatível com Claude Messages |
| `API_TOKEN` | `sk-...` (copiável na página de detalhes) | Cabeçalho de autenticação compatível com Anthropic |

## Minuto 2: Instalar Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell nativo):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Após a instalação, abra um novo terminal e verifique a instalação:

```bash
claude --version
```

> Se aparecer a versão, está tudo certo. Claude Code vem com runtime Node.js embutido, não depende da versão Node instalada na sua máquina.

## Minuto 3: Configurar Variáveis de Ambiente para o AceData Cloud

Não use o fluxo oficial `claude login`. Em vez disso, sobrescreva com variáveis de ambiente. Escolha uma das duas formas:

**Opção A: Temporário (só para a sessão atual do shell)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-seu-Token"
```

**Opção B: Persistente (recomendado)**

Acrescente as duas linhas acima no `~/.zshrc` ou `~/.bashrc` e depois rode `source` no arquivo.

> **Erro comum**: o nome correto da variável é `ANTHROPIC_AUTH_TOKEN`, não `ANTHROPIC_API_KEY`; usar o nome errado fará o Claude Code voltar ao endpoint oficial e gerar erro 401.

## Minuto 4: Execute o Primeiro Comando

Entre em qualquer repositório Git e rode:

```bash
claude
```

Se for a primeira vez e pedir login, pressione `Esc` para pular. Depois digite:

```
Liste as dependências do projeto atual e explique brevemente a função de cada uma.
```

Você verá Claude usar ferramentas como `read_file` / `glob` / `grep` para examinar o repositório e depois apresentar a lista. A barra de status na parte inferior mostrará `connected to api.acedata.cloud` — este é o sinal chave de que o proxy está ativo.

## Minuto 5: Conecte a Extensão do VS Code

1. Abra o VS Code → painel de extensões → busque por `Claude Code` e instale a oficial da Anthropic;
2. Pressione **Cmd+Shift+P** → digite `Claude Code: Set Custom API Endpoint`;
3. Insira `https://api.acedata.cloud` e pressione Enter;
4. Execute novamente `Claude Code: Set API Token` e insira seu Token.

Se tudo der certo, o painel Claude Code aparecerá na barra lateral. Você pode arrastar arquivos para perguntar ou usar `@-mention` para sugerir modificações em um arquivo. Toda cobrança será feita via AceData Cloud.

## Verifique se Está Usando o Proxy

No chat do Claude Code, digite:

```
Acesse https://api.acedata.cloud/whoami e me informe o que retornou
```

Se retornar suas informações de conta (`{user_id, plan, ...}`), significa que a requisição passou pelo edge do AceData Cloud. Se redirecionar para o domínio oficial e der erro 401, volte ao Minuto 3 e confira o nome das variáveis de ambiente.

## 5 Perguntas Frequentes

**Q: Depois de rodar `claude login` e mudar as variáveis para AceData, por que não funciona?**  
A: `claude login` grava o token oficial em `~/.claude/.credentials.json`, que tem prioridade sobre variáveis de ambiente. Apague esse arquivo e rode `source ~/.zshrc` para corrigir.

**Q: Posso usar modelos como `--model claude-opus-4-7`?**  
A: Sim. O proxy AceData Cloud passa o campo model diretamente, suportando todos os modelos públicos da Anthropic e nossos modelos estendidos `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5`.

**Q: Posso configurar múltiplos perfis (pessoal + trabalho)?**  
A: Sim. Claude Code suporta múltiplos perfis em `~/.claude/settings.json`; ou o mais simples: crie duas funções shell `claude_personal` / `claude_work` que exportem diferentes `ANTHROPIC_AUTH_TOKEN` e chamem `claude $@`.

**Q: Dá para rodar no GitHub Actions?**  
A: Sim. Veja o tutorial em [Claude Code GitHub Actions Integration](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**Q: E quando acabar o crédito gratuito?**  
A: Vá para [Gerenciamento de Aplicações](https://platform.acedata.cloud/applications) → selecione sua Application Claude → Topup para recarregar (cobrança por token consumido), ou mude para assinatura com pontos.
