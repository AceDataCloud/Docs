Este documento tem um único objetivo: permitir que você **em 5 minutos** execute seu primeiro comando Claude Code usando o proxy AceData Cloud. O tutorial completo está disponível nas subdocumentações para cada IDE ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); aqui, seguimos o caminho mais rápido com **CLI no terminal + extensão VS Code**.

> **Por que usar o proxy AceData Cloud para Claude Code**:
> - Conexão direta na China, sem necessidade de VPN
> - Preço mais baixo que o oficial (cobrança por token da plataforma)
> - A mesma chave suporta simultaneamente Claude Messages API + protocolo Claude Code Token

## Minuto 1: Solicitar Credenciais

Abra a [página do serviço Claude Messages](https://platform.acedata.cloud/documents/claude-messages) e clique no botão "**Acquire**":

![](https://cdn.acedata.cloud/nyq0xz.png)

A plataforma criará automaticamente uma Application para você e concederá créditos gratuitos. Anote os valores de **Base URL** e **API Token** na página de detalhes — você precisará deles nos próximos 5 passos.

| Campo | Valor | Uso |
|-------|-------|-----|
| `BASE_URL` | `https://api.acedata.cloud` | Endpoint compatível com Claude Messages |
| `API_TOKEN` | `sk-...` (copiado da página de detalhes) | Cabeçalho de autenticação compatível com Anthropic |

## Minuto 2: Instalar Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell nativo):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Após a instalação, abra um novo terminal e verifique a instalação:

```bash
claude --version
```

> Se aparecer a versão, está tudo certo. Claude Code já inclui o runtime Node.js, não depende da versão instalada na sua máquina.

## Minuto 3: Configurar Variáveis de Ambiente para o AceData Cloud

Não use o fluxo oficial `claude login`. Em vez disso, sobrescreva com variáveis de ambiente. Escolha uma das duas opções:

**Opção A: Temporário (apenas para a sessão atual do shell)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-seu-Token"
```

**Opção B: Persistente (recomendado)**

Adicione as duas linhas acima ao seu `~/.zshrc` ou `~/.bashrc` e depois rode `source` no arquivo.

> **Erro comum**: o nome correto da variável é `ANTHROPIC_AUTH_TOKEN`, não `ANTHROPIC_API_KEY`. Se usar o nome errado, Claude Code tentará o endpoint oficial e retornará erro 401.

## Minuto 4: Executar o Primeiro Comando

Entre em qualquer repositório Git e execute:

```bash
claude
```

Se na primeira execução pedir login, pressione `Esc` para pular. Depois digite:

```
Liste as dependências do projeto atual e explique brevemente a função de cada uma.
```

Você deverá ver Claude usando ferramentas como `read_file` / `glob` / `grep` para explorar o repositório e depois apresentando a lista. Se o modelo responder corretamente e não der erro 401, o proxy está funcionando.

## Minuto 5: Conectar a Extensão VS Code

1. Abra o VS Code → painel de extensões → pesquise por `Claude Code` e instale a oficial da Anthropic;
2. Reinicie o VS Code ou execute no painel de comandos `Developer: Reload Window` para carregar o `~/.claude/settings.json` configurado no Minuto 3;
3. Clique no ícone ✦ Spark no canto superior direito do editor, ou no status bar em "✱ Claude Code" para abrir o painel;
4. Na primeira vez, se pedir login oficial, pressione `Esc` para pular — a extensão usará automaticamente as variáveis `ANTHROPIC_BASE_URL` e `ANTHROPIC_AUTH_TOKEN` configuradas no Minuto 3.

> **Dica**: A extensão VS Code e o CLI compartilham o mesmo `~/.claude/settings.json`, então não é necessário configurar duas vezes. Se quiser usar configuração por projeto, crie `.claude/settings.local.json` na raiz do repositório (já ignorado pelo git).

Quando estiver funcionando, você poderá arrastar arquivos para o painel para fazer perguntas, usar `@-mention` para referenciar arquivos e propor modificações. A cobrança será feita via AceData Cloud.

## Verifique se Está Usando o Proxy

Execute uma vez com modo `--debug` para confirmar que as requisições vão para o AceData Cloud:

```bash
claude --debug -p "say hi" 2>&1 | grep -iE 'base.?url|api\.acedata|anthropic\.com' | head
```

Se aparecer `https://api.acedata.cloud`, o proxy está ativo; se aparecer `api.anthropic.com` ou erro 401, volte ao Minuto 3 para conferir o nome da variável (deve ser `ANTHROPIC_AUTH_TOKEN`, não `ANTHROPIC_API_KEY`) e verifique se o arquivo `~/.claude/.credentials.json` não contém token oficial (apague este arquivo se existir).

## 5 Perguntas Frequentes

**Q: Depois de rodar `claude login` e mudar as variáveis para AceData, por que não funciona?**  
A: `claude login` grava o token oficial em `~/.claude/.credentials.json`, que tem prioridade sobre variáveis de ambiente. Apague esse arquivo e rode `source ~/.zshrc` novamente.

**Q: Posso usar modelos como `--model claude-opus-4-7`?**  
A: Sim. O proxy AceData Cloud passa o campo model diretamente, suportando todos os modelos públicos da Anthropic e extensões como `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5`.

**Q: Posso configurar múltiplos perfis (pessoal + trabalho)?**  
A: Sim. Claude Code suporta múltiplos perfis em `~/.claude/settings.json`; ou simplesmente crie duas funções shell `claude_personal` e `claude_work` que exportem tokens diferentes e chamem `claude $@`.

**Q: Posso usar no GitHub Actions?**  
A: Sim. Veja o tutorial em [Claude Code GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**Q: E quando acabar o crédito gratuito?**  
A: Vá para [Gerenciamento de Aplicações](https://platform.acedata.cloud/applications) → selecione a Application Claude → Topup para recarregar créditos (cobrança por token consumido), ou mude para assinatura por pontos.
