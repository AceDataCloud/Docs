Google SERP (Search Engine Results Page) é a página de resultados que os usuários veem após inserir uma consulta no mecanismo de busca Google. Ela exibe resultados de pesquisa orgânica, anúncios, resumos em destaque, painel de conhecimento, bem como diversos conteúdos como imagens e vídeos, visando fornecer aos usuários as informações mais relevantes.

Este artigo apresentará detalhadamente a API Google SERP, que pode fornecer resultados ao inserir uma consulta no mecanismo de busca Google, e o conteúdo dos resultados também inclui muitos tipos, como resumos em destaque, painel de conhecimento e imagens, entre vários outros resultados.

Este documento apresentará as instruções de integração da API Google SERP.

## Processo de solicitação

Para usar a API Google SERP, primeiro obtenha seu API Token no [Console Ace Data Cloud](https://platform.acedata.cloud/console/applications) e guarde-o para uso posterior.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não fez login ou se registrou, será automaticamente redirecionado para a página de login para convidá-lo a se registrar e fazer login, e após a conclusão retornará automaticamente à página atual.

**Um API Token pode chamar todos os serviços da plataforma, não sendo necessário solicitar separadamente para cada serviço.** A primeira solicitação oferecerá créditos gratuitos, permitindo uma experiência gratuita; quando os créditos forem insuficientes, você poderá recarregar o saldo geral no [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentação completa: [Google SERP API →](https://platform.acedata.cloud/documents/serp-google)

## Uso básico

Insira palavras-chave e o tipo de recurso de pesquisa para obter resultados: use `query` para transmitir as palavras-chave e `type` para selecionar tipos de pesquisa como páginas da web, imagens e notícias; esta interface não requer a transmissão de `model`.

Por exemplo, para buscar: informações sobre “apple inc”, em seguida podemos preencher o conteúdo correspondente na interface, conforme mostrado na imagem:

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

Pode-se ver que aqui configuramos os Request Headers, incluindo:

- `accept`: o formato de resultado de resposta que se deseja receber, aqui preenchido como `application/json`, ou seja, o formato JSON.
- `authorization`: a chave para chamar a API, que pode ser selecionada diretamente na lista suspensa após a solicitação.

Além disso, configuramos o Request Body, incluindo:

- `type`: o tipo do recurso de pesquisa, atualmente apenas seis tipos são suportados, e o padrão é `search`.
- `query`: as palavras-chave da pesquisa.
- `country`: o país onde os resultados da pesquisa são personalizados, o padrão é Estados Unidos (US).
- `language`: o idioma dos resultados da pesquisa personalizados, o padrão é inglês (en).
- `range`: o intervalo de tempo dos resultados da pesquisa personalizados, o padrão é sem restrições.
- `number`: o tamanho da página da paginação dos resultados da pesquisa personalizados, o padrão é 10.
- `page`: o número da página da paginação dos resultados da pesquisa personalizados, o padrão é 1.

Além disso, se quiser gerar o código de integração correspondente, você pode copiá-lo e gerá-lo diretamente; por exemplo, o código CURL é o seguinte:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc"
}'
```

O código de integração em Python é o seguinte:

```python
import requests

url = "https://api.acedata.cloud/serp/google"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "query": "apple inc"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Tipo de pesquisa personalizado

Se você personalizar o tipo de recursos de pesquisa, podemos modificar o parâmetro `type`, que inclui recursos comuns `search`, recursos de imagens `images`, recursos de notícias `news`, recursos de mapas `maps`, recursos de regiões `places` e recursos de vídeos `videos`; este artigo usará os recursos de vídeos `videos` como demonstração.

A seguir, vamos demonstrar as operações específicas.

Primeiro, defina o parâmetro `type` como `videos` e transmita normalmente o parâmetro `query`, conforme mostrado na imagem:
<p><img src="https://cdn.acedata.cloud/czlt12.png" width="500" className="m-auto" /></p>

O código correspondente é o seguinte:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "videos",
  "query": "apple inc"
}'
```

## Personalizar o intervalo de tempo dos resultados de pesquisa
Este artigo também pode personalizar o intervalo de tempo dos resultados de pesquisa, incluindo cinco tipos, que são `qdr:h` (última hora), `qdr:d` (último dia), `qdr:w` (última semana), `qdr:m` (último mês), e sem limite por padrão, podemos passar o intervalo de tempo correspondente por meio de `range`, por exemplo, aqui definido como `qdr:d`, isso representa a pesquisa de resultados do último dia, portanto a entrada é a seguinte:

<p><img src="https://cdn.acedata.cloud/qccfib.png" width="500" className="m-auto" /></p>

O código correspondente é o seguinte:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "range": "qdr:d",
  "query": "apple inc"
}'
```

## Personalizar a paginação dos resultados de pesquisa

Esta API também oferece suporte à exibição paginada personalizada dos resultados de pesquisa, `number` e `page` representam o tamanho da página e o número da página da paginação, este artigo configurará a paginação com 20 resultados de pesquisa em uma página, as informações específicas são mostradas na imagem:

<p><img src="https://cdn.acedata.cloud/dqla1e.png" width="500" className="m-auto" /></p>

> Observação: quando os resultados por página excedem 10, os créditos deduzidos serão duplicados.

O código é o seguinte:
```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc",
```
