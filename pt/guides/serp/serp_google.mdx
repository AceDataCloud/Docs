Google SERP (Search Engine Results Page) é a página de resultados que os usuários veem após inserir uma consulta no mecanismo de busca do Google. Ela exibe resultados de busca orgânica, anúncios, resumos em destaque, gráficos de conhecimento, além de imagens, vídeos e outros conteúdos, com o objetivo de fornecer as informações mais relevantes aos usuários.

Este artigo irá detalhar a API Google SERP, que pode fornecer resultados ao inserir consultas no mecanismo de busca do Google, e o conteúdo dos resultados também inclui muitos tipos, como resumos em destaque, gráficos de conhecimento e imagens, entre outros.

Este documento apresentará as instruções de integração da API Google SERP.

## Processo de Solicitação

Para usar a API Google SERP, primeiro acesse o [Painel de Controle da Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter seu Token de API, que deve ser guardado para uso futuro.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, convidando-o a se registrar e fazer login; após concluir, você será retornado automaticamente à página atual.

**Um Token de API é suficiente para acessar todos os serviços da plataforma, não sendo necessário solicitar individualmente para cada serviço.** A primeira solicitação oferece um crédito gratuito, permitindo uma experiência sem custo; quando o crédito estiver baixo, você pode recarregar o saldo geral no [painel de controle](https://platform.acedata.cloud/console/coin).

> 📘 Documentação Completa: [API Google SERP →](https://platform.acedata.cloud/documents/serp-google)

## Uso Básico

Primeiro, entenda a forma básica de uso, que é inserir o tipo de recurso de busca e a palavra-chave para obter os resultados da busca, bastando passar o campo `query` e especificar o modelo correspondente.

Por exemplo, para buscar informações sobre "apple inc", podemos preencher o conteúdo correspondente na interface, como mostrado na imagem:

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

Podemos ver que aqui configuramos os Headers da Requisição, incluindo:

- `accept`: o formato de resposta desejado, aqui preenchido como `application/json`, ou seja, formato JSON.
- `authorization`: a chave para chamar a API, que pode ser selecionada diretamente após a solicitação.

Além disso, configuramos o Corpo da Requisição, incluindo:

- `type`: o tipo de recurso de busca, atualmente suportando apenas seis tipos, sendo o padrão `search`.
- `query`: a palavra-chave da busca.
- `country`: o país onde os resultados da busca devem ser personalizados, sendo o padrão os Estados Unidos (US).
- `language`: o idioma dos resultados da busca, sendo o padrão o inglês (en).
- `range`: o intervalo de tempo dos resultados da busca, sendo o padrão sem restrições.
- `number`: o tamanho da página de resultados da busca, sendo o padrão 10.
- `page`: o número da página de resultados da busca, sendo o padrão 1.

## Tipo de pesquisa personalizada

Se você personalizar o tipo de recurso de pesquisa, podemos modificar o parâmetro `type`, que inclui recursos normais `search`, recursos de imagem `images`, recursos de notícias `news`, recursos de mapa `maps`, recursos de área `places`, recursos de vídeo `videos`, este artigo fará uma demonstração com o recurso de vídeo `videos`.

Agora vamos demonstrar a operação específica.

Primeiro, defina o parâmetro `type` como `videos` e passe normalmente o parâmetro `query`, como mostrado na imagem:
<p><img src="https://cdn.acedata.cloud/czlt12.png" width="500" className="m-auto" /></p>

O código correspondente é o seguinte:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "videos",
  "query": "apple inc"
}'
```

## 自定义搜索结果时间范围
本文还可以自定义 resultados de busca do tempo, incluindo cinco tipos, que são `qdr:h` (última hora), `qdr:d` (último dia), `qdr:w` (última semana), `qdr:m` (último mês), e o padrão sem restrições. Podemos passar o intervalo de tempo correspondente através de `range`, por exemplo, aqui definido como `qdr:d`, o que significa buscar resultados do último dia, então a entrada é a seguinte:

<p><img src="https://cdn.acedata.cloud/qccfib.png" width="500" className="m-auto" /></p>

O código correspondente é o seguinte:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "range": "qdr:d",
  "query": "apple inc"
}'
```

## Paginação de Resultados de Busca Personalizados

Esta API também suporta a exibição de resultados de busca personalizados em páginas, `number` e `page` representam o tamanho da página e o número da página, este artigo definirá que uma página contém 20 resultados de busca para exibição em páginas, as informações específicas são mostradas na imagem:

<p><img src="https://cdn.acedata.cloud/dqla1e.png" width="500" className="m-auto" /></p>

> Nota: Quando o número de resultados por página excede 10, os pontos descontados serão dobrados.

O código é o seguinte:
```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc",
  "number": 20,
  "page": 1
}'
```
