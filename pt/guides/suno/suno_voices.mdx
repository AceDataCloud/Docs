---
title: "Instruções de integração da API de clonagem de voz do Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

O SUNO permite criar personagens de voz personalizados por meio de qualquer arquivo de áudio, realizando clonagem de voz para geração de música. Diferente da API Persona já existente (que utiliza o `audio_id` gerado pelo Suno), esta API aceita um `audio_url` publicamente acessível, ou seja, sua própria gravação de voz. Este documento explica o método de integração da API de clonagem de voz.

## Primeiro passo: criar um personagem de voz

Esta API possui três parâmetros de entrada: `audio_url` (obrigatório), que é uma URL de arquivo de áudio em formato MP3 ou WAV publicamente acessível, contendo uma voz humana clara de uma única pessoa; `name` e `description` (opcionais), que são o nome e a descrição do personagem de voz.

> **Requisitos do arquivo de áudio**
> - O formato de áudio deve ser `WAV` ou `MP3`
> - A duração do áudio deve estar entre `10~240 segundos`; recomenda-se utilizar material limpo de voz seca de uma única pessoa, com `30~60 segundos`
> - O áudio deve conter **fala ou canto claro e identificável de uma única pessoa**
> - Certifique-se de evitar **ruído de fundo, acompanhamento, eco, reverberação**; músicas completas com acompanhamento geralmente não passam na verificação de impressão vocal
> - Não inclua **vários falantes** ou **múltiplas vozes**
> - Materiais com volume muito baixo, voz pouco clara ou ruído excessivo podem causar **falha na clonagem** ou **qualidade de geração inferior**
> **Descrição das restrições de uso**
> - Os personagens de voz criados pelo envio de áudio são **recursos privados**
> - Este personagem de voz **não oferece suporte à reutilização entre contas**
> - Recomenda-se utilizá-lo assim que possível após a criação bem-sucedida; caso não seja utilizado por muito tempo, pode ocorrer **expiração ou indisponibilidade**
> - O `name` retornado é gerado automaticamente pelo sistema; considere o `persona_id` retornado como referência

> **Em caso de falha na chamada, tente novamente primeiro**
> A clonagem de voz é uma tarefa intensiva em capacidade computacional; mesmo que o material esteja totalmente em conformidade, há uma certa probabilidade de falhas ocasionais, com retornos comuns como
> `voices_sound_different` (falha na verificação de impressão vocal) etc. **Esse tipo de falha não está relacionado à qualidade do áudio; tentar novamente com o mesmo material geralmente será bem-sucedido**,
> recomenda-se implementar 1~2 tentativas automáticas para resultados com falha durante a integração. Solicitações com falha não serão cobradas.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> O `https://cdn.acedata.cloud/suno_demo.mp3` acima é um material de exemplo que pode ser chamado diretamente (MP3, 41 segundos, voz seca de uma única pessoa).
> Se precisar de um exemplo em formato `WAV`, pode utilizar
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 segundos, mono 44,1 kHz).

O resultado é o seguinte:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Pode-se ver que o campo `persona_id` de `data` é o ID do personagem de voz criado. O campo `is_public` é sempre `false`, porque os personagens de voz criados pelo envio de áudio são privados. Observe que o `name` retornado é gerado automaticamente pelo sistema; posteriormente, utilize `persona_id` para referenciar este personagem de voz.

## Segundo passo: usar o personagem de voz para gerar música

Após obter o ID do personagem de voz, podemos utilizar a [API de geração de áudios do Suno](https://platform.acedata.cloud/documents/suno-audios) para realizar a geração de música. Defina `action` como `generate` e `persona_id` como o ID do personagem de voz retornado acima; a música gerada usará a voz clonada para cantar.

> **Observação:** a clonagem de voz oferece suporte apenas aos modelos `chirp-v4-5` e superiores (como `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), e não oferece suporte ao `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

O resultado é o seguinte:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

Pode-se ver que a música gerada utilizou a voz clonada para cantar. O `persona_id` também pode ser usado em conjunto com a ação `cover`, para fazer uma versão de músicas existentes com a voz clonada.
