---
title: "Instruções de integração da API de clonagem de voz do Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

O SUNO nos permite criar personagens de voz personalizados por meio de qualquer arquivo de áudio, realizando clonagem de voz para geração de música. Diferente da API Persona existente (que usa o `audio_id` gerado pelo Suno), esta API aceita um `audio_url` publicamente acessível, ou seja, sua própria gravação de voz. Este documento explica como integrar a API de clonagem de voz.

## Etapa 1: criar um personagem de voz

Esta API possui três parâmetros de entrada: `audio_url` (obrigatório), que é uma URL de arquivo de áudio MP3 ou WAV publicamente acessível contendo uma voz humana clara de uma única pessoa; `name` e `description` (opcionais), que são o nome e a descrição do personagem de voz.

> **Requisitos do arquivo de áudio**
> - O formato de áudio deve ser `WAV` ou `MP3`
> - A duração do áudio deve estar entre `10~240 segundos`; recomenda-se usar material de voz seca, limpa e de uma única pessoa, de `30~60 segundos`
> - O áudio deve conter **fala ou canto claro e identificável de uma única pessoa**
> - Certifique-se de evitar **ruído de fundo, acompanhamento, eco e reverberação**; músicas completas com acompanhamento geralmente não passam na validação de impressão vocal
> - Não inclua **vários locutores** ou **múltiplas vozes**
> - Materiais com volume muito baixo, fala pouco clara ou ruído excessivo podem resultar em **falha na clonagem** ou **qualidade de geração inferior**
> **Explicação das restrições de uso**
> - Os personagens de voz criados por meio do envio de áudio são **recursos privados**
> - Este personagem de voz **não oferece suporte à reutilização entre contas**
> - Recomenda-se usá-lo o mais rápido possível após a criação bem-sucedida; a falta de uso por muito tempo pode resultar em **expiração ou indisponibilidade**
> - O `name` retornado é gerado automaticamente pelo sistema; use o `persona_id` retornado como referência

> **Em caso de falha na chamada, tente novamente primeiro**
> A clonagem de voz é uma tarefa intensiva em recursos computacionais; mesmo que o material esteja totalmente em conformidade, há uma certa probabilidade de falhas ocasionais, com retornos comuns como
> `voices_sound_different` (a validação de impressão vocal não foi aprovada), entre outros. **Esse tipo de falha não está relacionado à qualidade do áudio; normalmente, tentar novamente usando o mesmo material é suficiente para obter sucesso**,
> recomenda-se implementar de 1 a 2 tentativas automáticas para resultados com falha durante a integração. Solicitações com falha não serão cobradas.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> O `https://cdn.acedata.cloud/suno_demo.mp3` acima é um material de exemplo que pode ser chamado diretamente (MP3, 41 segundos, voz seca de uma única pessoa).
> Se precisar de um exemplo no formato `WAV`, você pode usar
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 segundos, mono 44,1 kHz).

O resultado é o seguinte:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Como pode ser visto, o campo `persona_id` de `data` é o ID do personagem de voz criado. O campo `is_public` é sempre `false`, pois os personagens de voz criados por meio do envio de áudio são privados. Observe que o `name` retornado é gerado automaticamente pelo sistema; posteriormente, use o `persona_id` para referenciar esse personagem de voz.

## Etapa 2: usar o personagem de voz para gerar música

Após obter o ID do personagem de voz, podemos usar a [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) para gerar música. Defina `action` como `generate` e `persona_id` como o ID do personagem de voz retornado acima; a música gerada será cantada com a voz clonada.

> **Observação:** a clonagem de voz é compatível apenas com modelos `chirp-v4-5` e superiores (como `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`) e não é compatível com `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

O resultado é o seguinte:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` pode ser usado para a geração com `generate` e também para covers com `cover` / `upload_cover`. Não é necessário preencher simultaneamente `vocal_gender` ao especificar a voz; a similaridade da voz ainda depende do material de referência e do resultado gerado.

As vozes criadas por meio desta interface são recursos privados. Antes de fazer cover de uma música existente, chame primeiro `/suno/upload`, passando o `audio_url` da música original e o `persona_id` dessa voz; após o envio bem-sucedido, chame `/suno/audios` usando o `data.audio_id` retornado e o mesmo `persona_id`:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

A criação da voz, o envio da música original e o cover devem usar o mesmo canal de serviço. Não reutilize diretamente IDs de músicas anteriores que não estejam associados a essa voz privada; consulte os detalhes em [Suno enviar áudio de referência](https://platform.acedata.cloud/documents/suno-upload).
