A SUNO permite criar personagens de voz personalizados por meio de qualquer arquivo de áudio, realizando clonagem de voz para geração de música. Diferentemente da API Persona existente (que usa o `audio_id` gerado pelo Suno), esta API aceita um `audio_url` publicamente acessível, ou seja, sua própria gravação de voz. Este documento explica como integrar a API de clonagem de voz.

Na rota de criação compatível com consulta de timbre, é possível usar a aplicação original e a identidade do chamador para passar o `persona_id` nos resultados da criação para `POST /suno/availability`. Quando a conta associada estiver online, retorna `data.available=true`; quando estiver confirmadamente offline, retorna `data.available=false`. [Guia de consulta de disponibilidade de timbre](https://platform.acedata.cloud/documents/suno-availability-integration)

## Primeiro passo: criar um personagem de voz

Cobrança: após a criação bem-sucedida do personagem de voz, o custo padrão de cada solicitação é de **0.15 Credits**. Os descontos de consumo aplicáveis estão sujeitos à fatura real, e solicitações com falha não são cobradas.

Esta API possui três parâmetros de entrada: `audio_url` (obrigatório), uma URL de arquivo de áudio MP3 ou WAV publicamente acessível que contenha uma voz humana clara de uma única pessoa; `name` e `description` (opcionais), que são o nome e a descrição do personagem de voz.

> **Requisitos do arquivo de áudio**
> - O formato de áudio deve ser `WAV` ou `MP3`
> - A duração do áudio deve estar entre `10~240 segundos`; recomenda-se usar material de voz seca e limpa de uma única pessoa com `30~60 segundos`
> - O áudio deve conter **voz de fala ou canto clara e identificável de uma única pessoa**
> - Certifique-se de evitar **ruído de fundo, acompanhamento, eco, reverberação**; músicas completas com acompanhamento geralmente não passam pela verificação de impressão vocal
> - Não inclua **vários falantes** ou **múltiplas vozes**
> - Materiais com volume muito baixo, fala pouco clara ou excesso de ruído podem resultar em **falha na clonagem** ou **qualidade de geração inferior**
> **Descrição das restrições de uso**
> - Personagens de voz criados por meio de áudio enviado são **recursos privados**
> - Este personagem de voz **não oferece suporte à reutilização entre contas**
> - Recomenda-se utilizá-lo o quanto antes após a criação bem-sucedida; longos períodos sem uso podem resultar em **expiração ou indisponibilidade**
> - O `name` retornado é gerado automaticamente pelo sistema; use o `persona_id` retornado como referência

> **Trate falhas de acordo com a sinalização explícita de repetição**
> O `retryable` no objeto de erro é um campo booleano opcional. Quando `error.retryable` for `true`, isso indica que esta falha permite solicitar novamente mais tarde usando o mesmo material e os mesmos parâmetros. Serviços explicitamente não aceitos por estarem ocupados ou algumas falhas temporárias de verificação de impressão vocal podem ter esta sinalização; recomenda-se usar intervalos de espera progressiva e limitar o número de tentativas.
> Quando `retryable` for `false` ou o campo estiver ausente, não reenvie automaticamente apenas com base em HTTP 500, `busy` ou no texto do erro. Problemas de formato, duração, clareza, gravações duplicadas e revisão de conteúdo devem ser corrigidos primeiro; em caso de tempo limite de envio, interrupção de conexão ou resultado de criação incerto, priorize consultar a tarefa usando o `task_id` original para evitar criar timbres duplicados. Solicitações com falha não serão cobradas, e solicitações repetidas bem-sucedidas serão cobradas de acordo com as regras normais.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> O `https://cdn.acedata.cloud/suno_demo.mp3` acima é um material de exemplo que pode ser chamado diretamente (MP3, 41 segundos, voz seca de uma única pessoa).
> Se precisar de um exemplo no formato `WAV`, você pode usar
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 segundos, mono 44.1kHz).

O resultado é o seguinte:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Como pode ser visto, o campo `persona_id` de `data` é o ID do personagem de voz criado. O campo `is_public` é sempre `false`, pois personagens de voz criados por meio de áudio enviado são privados. Observe que o `name` retornado é gerado automaticamente pelo sistema; posteriormente, use `persona_id` para referenciar esse personagem de voz.

## Segundo passo: usar o personagem de voz para gerar música

Após ter o ID do personagem de voz, podemos usar a [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) para gerar música. Defina `action` como `generate` e `persona_id` como o ID do personagem de voz retornado acima; as músicas geradas usarão a voz clonada para cantar.

> **Observação:** a clonagem de voz é compatível apenas com modelos `chirp-v4-5` e superiores (como `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), não sendo compatível com `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

O resultado é o seguinte:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` pode ser usado para geração com `generate` e também para covers com `cover` / `upload_cover`. Ao especificar uma voz, não é necessário preencher `vocal_gender` simultaneamente; a similaridade de voz ainda depende do material de referência e do resultado gerado.

As vozes criadas por esta interface são recursos privados. Antes de fazer cover de uma música existente, primeiro chame `/suno/upload`, passando o `audio_url` da música original e o `persona_id` dessa voz; após o upload bem-sucedido, use o `data.audio_id` retornado e o mesmo `persona_id` para chamar `/suno/audios`:
```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<audio_id retornado após o upload associado a esta voz>",
  "persona_id": "<persona_id retornado pela interface de criação de voz>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\nPreencha a letra a ser cantada",
  "async": true
}
```

A criação de voz, o upload da música original e o cover devem usar o mesmo canal de serviço. Não reutilize diretamente o ID de uma música que não tenha sido previamente associada a esta voz privada; para mais detalhes, consulte [Suno carregar áudio de referência](https://platform.acedata.cloud/documents/suno-upload).
