A SUNO permite criar personagens de voz personalizados a partir de qualquer arquivo de áudio, possibilitando a clonagem de voz para geração musical. Diferente da Persona API existente (que utiliza o `audio_id` gerado pela Suno), esta API aceita um `audio_url` publicamente acessível, ou seja, sua própria gravação vocal. Este documento explica como integrar a API de clonagem de voz.

## Passo 1: Criar um Personagem de Voz

Esta API possui três parâmetros de entrada: `audio_url` (obrigatório), que deve ser uma URL publicamente acessível de um arquivo de áudio em formato MP3 ou WAV contendo voz clara de uma única pessoa; `name` e `description` (opcionais), que são o nome e a descrição do personagem de voz.

**Requisitos do arquivo de áudio:**
- Formato: MP3 ou WAV
- Duração: pelo menos 10 segundos
- Conteúdo: voz clara de uma única pessoa, com o mínimo possível de ruído de fundo ou música

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

O resultado será:

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

Como pode ser visto, o campo `persona_id` dentro de `data` é o ID do personagem de voz criado. O campo `is_public` estará sempre como `false`, pois personagens de voz criados via upload de áudio são privados.

## Passo 2: Gerar Música Usando o Personagem de Voz

Com o ID do personagem de voz, podemos usar a [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) para gerar música. Defina `action` como `generate` e `persona_id` como o ID do personagem retornado acima; a música gerada será cantada com a voz clonada.

> **Atenção:** A clonagem de voz suporta apenas modelos `chirp-v4-5` ou superiores (como `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), não suportando `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

O resultado será:

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

Como pode ser observado, a música gerada utiliza a voz clonada para a interpretação. O `persona_id` também pode ser usado em conjunto com a ação `cover` para regravar músicas existentes com a voz clonada.
