---
title: "Suno Geração de Letras API Integração"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

Se você deseja personalizar a geração de músicas, mas não quer escrever as letras por conta própria, pode usar a API de geração de letras fornecida pela AceDataCloud para gerar letras através de um prompt. A API é a [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/514d82dc-f7ab-4638-9f21-8b9275916b08).

O principal parâmetro de entrada dessa API é o `prompt`, com um parâmetro opcional `model` (padrão chirp-v3), um exemplo de preenchimento é o seguinte:

![](https://cdn.acedata.cloud/p53wtj.png)

Aqui, o `prompt` que inserimos é `Uma canção sobre o inverno`, gerando uma música relacionada ao inverno.

Clique em executar, o resultado é o seguinte:

```
{
  "success": true,
  "task_id": "57e8ce3a-39cb-41a2-802f-e70a324f4d0a",
  "data": {
    "text": "[Verso]\nFlocos de neve caindo do céu\nO toque frio do inverno\nOh como isso me deixa nas nuvens\nEu me agasalho em camadas\nOh tão aconchegante\nSaindo e sentindo o frio no meu nariz\nVeja\n\n[Verso 2]\nO mundo está coberto por um manto branco\nCiclistas pendurados\nBrilhando tão intensamente\nO ar gelado enche meus pulmões a cada respiração\nCaminhando na neve\nDeixando pegadas que não serão apagadas\n\n[Refrão]\nOh\nO toque frio do inverno\nÉ uma estação que eu amo tanto\nA queda de neve traz uma sensação tão divina\nO toque frio do inverno\nÉ um tempo mágico",
    "title": "O Toque Frio do Inverno",
    "status": "complete"
  }
}
```

Pode-se ver que o campo `text` de `data` é a informação da letra.

Com a letra em mãos, podemos usar a [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) para gerar músicas personalizadas.
