title: "Suno Lyrics Generation API Integration Instructions"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Se você deseja personalizar a geração de músicas, mas não quer escrever as letras por conta própria, pode usar a API de geração de letras fornecida pela AceDataCloud para gerar letras através de um prompt. A API é a [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

O principal parâmetro de entrada dessa API é o `prompt`, e o `model` (opcional, com valores `default` e `remi-v1`, sendo `default` o padrão). Um exemplo de preenchimento é o seguinte:

![](https://cdn.acedata.cloud/p53wtj.png)

Aqui, o `prompt` que inserimos é `A song about winter`, gerando uma música relacionada ao inverno.

Clique em executar, e o resultado é o seguinte:

Pode-se ver que o `data` é um array, e a cada vez retorna várias opções de letras, onde o campo `text` de cada elemento é o conteúdo da letra, `title` é o título, e `tags` são as etiquetas de estilo recomendadas.

Com as letras em mãos, podemos usar a [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) para gerar músicas personalizadas.
