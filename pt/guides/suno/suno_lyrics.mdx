---
title: "Instruções de integração da API de geração de letras do Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Se você quiser personalizar a geração de músicas, mas não quiser escrever as letras por conta própria, pode usar a API de geração de letras fornecida pela AceDataCloud para gerar letras por meio de prompt. A API é a [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Cobrança: após a geração bem-sucedida, o custo padrão de cada solicitação é de **0.08 Credits**. Quando uma solicitação retorna vários candidatos de letras, ainda será cobrada apenas uma vez; os descontos de consumo aplicáveis estão sujeitos à fatura real, e solicitações com falha não são cobradas.

O principal parâmetro de entrada dessa API é `prompt`, com `model` opcional (valores opcionais: `default`, `remi-v1`; o padrão é `default`), conforme o exemplo de preenchimento abaixo:

![](https://cdn.acedata.cloud/p53wtj.png)

Aqui, o `prompt` que inserimos é `A song about winter`, gerando uma música relacionada ao inverno.

Clique em executar, e o resultado será o seguinte:

Pode-se ver que `data` é um array, e vários candidatos de letras são retornados a cada vez, sendo que o campo `text` de cada elemento é o conteúdo da letra, `title` é o título e `tags` são as tags de estilo musical recomendadas.

Depois de obter as letras, podemos usar a [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) para realizar a geração personalizada de músicas.
