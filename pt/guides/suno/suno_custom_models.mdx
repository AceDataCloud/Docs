---
title: "Guia de integração de modelos de música personalizados do Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Modelos de música personalizados podem aprender características musicais consistentes a partir de 6 a 24 áudios autorizados e ser usados para criações de músicas subsequentes. A criação é uma operação assíncrona; recomenda-se usar 24 áudios com estilo consistente e qualidade de som nítida para obter resultados mais estáveis.

> Você só pode enviar áudios para os quais possui direito legal de uso ou autorização para criação do modelo e gerações subsequentes. Não envie materiais de música ou som sem permissão.

## Criar um modelo

Chame `POST /suno/custom-models` e defina `action=create`:

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

A interface retorna imediatamente o ID do modelo da plataforma e o ID da tarefa. Após a criação ser concluída, o `status` no callback ou no resultado da consulta mudará para `ready`. Apenas a criação bem-sucedida do modelo será cobrada em **10 Credits**; falhas na criação não serão cobradas.

## Consultar modelos

Consultar um único modelo:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Consultar os modelos do aplicativo atual com paginação:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Todos os modelos pertencem ao aplicativo Suno que os criou. A rotação de credenciais da API não altera a propriedade do modelo, e outros aplicativos não podem consultar ou usar o modelo.

## Usar um modelo para gerar músicas

Após o status do modelo ser `ready`, continue chamando `POST /suno/custom-models` e defina `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

O `id` deve ser um modelo de música personalizado com status `ready` no aplicativo atual. A solicitação falhará quando o modelo não estiver disponível e não mudará automaticamente para outro modelo. `persona_id` é mutuamente exclusivo com modelos de música personalizados; quando enviados simultaneamente, a interface retornará HTTP 400 antes que a solicitação seja enviada ao serviço de geração, e não haverá cobrança. Se precisar usar Persona, utilize as operações `artist_consistency` ou `artist_consistency_vox` de `/suno/audios`.

A geração bem-sucedida de músicas consome **0.90 Credits**; falhas na geração não são cobradas. Consultar e arquivar modelos é gratuito.

## Arquivar modelos

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

A versão Beta atual arquivará o modelo e proibirá seu uso contínuo; `capacity_released=false` na resposta indica que o arquivamento não garante a liberação da capacidade do modelo. A operação de arquivamento pode ser chamada repetidamente e não será cobrada novamente.
