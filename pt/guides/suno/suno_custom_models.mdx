title: "Guia de Acesso ao Modelo de Música Exclusivo Suno"

O modelo de música exclusivo pode aprender características musicais consistentes a partir de 6 a 24 áudios autorizados e ser utilizado para a criação de músicas subsequentes. A criação é uma operação assíncrona; recomenda-se usar 24 áudios com estilo consistente e qualidade de som clara para obter resultados mais estáveis.

> Apenas envie áudios dos quais você possui direitos de uso legal ou que tenha obtido autorização para a criação do modelo e geração subsequente. Não faça upload de músicas ou materiais sonoros sem permissão.

## Criar Modelo

Chame `POST /suno/custom-models` e defina `action=create`. Recomenda-se enviar ao mesmo tempo um cabeçalho de solicitação `Idempotency-Key` exclusivo; reutilize a mesma chave em tentativas de rede para evitar a criação duplicada:

```json
{
  "action": "create",
  "name": "Meu Modelo Indie",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

A interface retorna imediatamente o ID do modelo da plataforma e o ID da tarefa. Após a conclusão da criação, o `status` no callback ou na consulta de resultados mudará para `ready`. Apenas modelos criados com sucesso serão cobrados; falhas na criação não resultarão em cobrança.

## Consultar Modelo

Consultar um único modelo:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Consulta paginada dos modelos atuais da aplicação:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Todos os modelos pertencem à aplicação Suno que os criou. A rotação das credenciais da API não altera a propriedade do modelo, e outras aplicações não podem consultar ou usar esse modelo.

## Usar Modelo para Gerar Músicas

Após o estado do modelo ser `ready`, continue chamando `POST /suno/custom-models` e defina `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Chuva Neon",
  "lyric": "[Verso]\nAs luzes da cidade estão caindo pela chuva",
  "style": "indie rock, sintetizador analógico quente"
}
```

`id` deve ser o modelo de música exclusivo com estado `ready` sob a aplicação atual. Se o modelo não estiver disponível, a solicitação falhará e não usará automaticamente outro modelo.

## Arquivar Modelo

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

A versão Beta atual arquivará o modelo e proibirá seu uso contínuo, a resposta com `capacity_released=false` indica que o arquivamento não garante a liberação da capacidade do modelo. A operação de arquivamento pode ser chamada repetidamente e não resultará em cobrança duplicada.
