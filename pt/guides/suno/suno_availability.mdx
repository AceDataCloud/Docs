---
title: "API de verificação de disponibilidade de áudio do Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

`POST /suno/availability` procura, com base em `audio_id`, evidências positivas de que o áudio pode continuar sendo processado na rota atual. Pode ser chamada antes de operações como continuação e cover; o resultado reflete apenas o estado no momento da verificação e não garante o sucesso de uma operação específica. Esta interface retorna de forma síncrona, requer um token de API e atualmente não consome Credits.

`audio_id` é o ID da música retornado por uma tarefa Suno concluída, não `task_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

Exemplo de resposta bem-sucedida:

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

Quando a verificação é bem-sucedida, `data.available` é `true`; quando não é possível confirmar, retorna `503 availability_unknown` e não retorna `false`. Um formato inválido de `audio_id` retorna 400, e limitação de taxa ou anomalias do serviço também retornam uma resposta de erro. O estado ainda pode mudar entre a conclusão da verificação e a operação real.
