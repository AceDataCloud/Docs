A SUNO nos permite obter arquivos de música no formato wav. Este documento explica como integrar a API relacionada.

O parâmetro de entrada principal da API é `audio_id`, que é o ID da música gerado oficialmente; opcionalmente, também suporta o endereço de callback assíncrono `callback_url`.

Aqui, o `audio_id` que inserimos é `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer YOUR_API_KEY",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

O resultado é o seguinte:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://cdn.acedata.cloud/suno/41572926-1a7a-41bc-adb8-9431e494c144.wav"
    }
  ]
}
```

Pode-se ver que o campo `file_url` de `data` é o arquivo de música no formato wav obtido, que é um endereço CDN acessível publicamente.

> **Sobre a Persistência do Link WAV**
> A plataforma priorizará a persistência do arquivo WAV em seu estado final no CDN da Ace Data Cloud antes de retornar. O URL acima apenas demonstra o formato da resposta, não representando um objeto real de longa duração. Somente quando a persistência no CDN não estiver concluída e o endereço do mídia original, após verificação imediata, ainda puder ser baixado como um arquivo WAV válido, o `file_url` poderá manter esse endereço; se o endereço estiver inválido ou a verificação do arquivo falhar, a solicitação retornará falha ou timeout, não considerando endereços não baixáveis como resultado de sucesso. Por favor, baixe e armazene adequadamente após a conclusão da tarefa, o período de retenção específico está sujeito à política de armazenamento atual da plataforma.
