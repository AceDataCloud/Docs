---
title: "Instruções de integração da API de estilo de cantor personalizado do Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

O SUNO nos permite definir um estilo de cantor para músicas já geradas e, em seguida, realizar uma criação secundária com base nele. Este documento explica o método de integração da API relacionada.

A consulta de lista `GET /suno/persona` e a exclusão de registros `DELETE /suno/persona` não são cobradas, não sendo necessário um cabeçalho adicional de solicitação isenta de cobrança. A operação de criação `POST /suno/persona` continua sendo cobrada de acordo com as regras de precificação da interface.

Esta API possui apenas três parâmetros de entrada: primeiro, `audio_id`, que é o ID de uma música já gerada com sucesso na plataforma oficial; em seguida, `name` e `description`, que são um nome e uma descrição para o estilo de cantor.

Aqui, o `audio_id` que inserimos é `https://cdn.acedata.cloud/2qhzs3.png`. Você pode consultar a [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) para realizar a geração personalizada de músicas e, ao final, obter o `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

O resultado é o seguinte:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Pode-se ver que o campo `persona_id` de `data` é o ID do estilo de cantor gerado.

Depois de obter o ID do estilo de cantor, podemos usar a [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) para realizar a geração personalizada de músicas. Por exemplo, passando `artist_consistency` em `action`, passando simultaneamente o ID da música enviada em `audio_id`, e também enviando o parâmetro `persona_id`, cujo valor é o ID do estilo de cantor retornado acima, será possível gerar novas músicas com base no estilo de cantor de referência.
