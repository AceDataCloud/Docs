---
title: "Suno API de Integração de Estilo de Cantor Personalizado"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

O SUNO nos permite definir o estilo de cantor para músicas que já foram geradas e, em seguida, realizar uma nova criação com base nisso. Este documento explica como integrar a API relacionada.

Esta API possui apenas três parâmetros de entrada: primeiro, `audio_id`, que é um ID de uma música que já foi gerada com sucesso pelo oficial; em segundo lugar, `name` e `description`, que são um nome e uma descrição do estilo do cantor.

Aqui, o `audio_id` que inserimos é `https://cdn.acedata.cloud/2qhzs3.png`, que pode ser referenciado na [API de Geração de Áudios do Suno](https://platform.acedata.cloud/documents/suno-audios) para gerar músicas personalizadas, e por fim, podemos obter o `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

O resultado é o seguinte:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Podemos ver que o campo `persona_id` em `data` é o ID do estilo de cantor gerado.

Com o ID do estilo de cantor em mãos, podemos usar a [API de Geração de Áudios do Suno](https://platform.acedata.cloud/documents/suno-audios) para gerar músicas personalizadas. Por exemplo, passando `action` como `artist_consistency`, enquanto `audio_id` é o ID da música carregada, e também precisamos enviar o parâmetro `persona_id`, que é o valor do ID do estilo de cantor retornado acima, assim podemos gerar novas músicas com base no estilo de cantor de referência.
