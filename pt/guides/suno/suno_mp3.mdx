title: "Instruções de Integração da API Suno MP3 URL"

A API Suno MP3 URL gera um caminho para um endereço reproduzível que termina em `.mp3` para músicas já existentes, adequada para cenários em que links de download antigos estão inativos, reprodução em dispositivos móveis ou necessidade de recuperar novamente URLs de áudio públicos.

O parâmetro obrigatório `audio_id` é o ID de áudio retornado pela interface de geração de áudio Suno. Cada chamada cria uma tarefa de URL MP3 independente, não modificando a tarefa de geração de música original e não alterando o ID de áudio original.

## Chamada Sincrona

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={
        "accept": "application/json",
        "authorization": "Bearer <YOUR_API_TOKEN>",
        "content-type": "application/json"
    },
    json={"audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f"},
    timeout=240
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["file_url"])
```

Em caso de sucesso, `data[0].file_url` é o endereço de áudio reproduzível. A interface prioriza a transferência para `https://platform2.cdn.acedata.cloud/suno/{audio_id}.mp3`; se a transferência demorar mais de 30 segundos ou falhar, retornará o endereço de áudio fonte atualmente disponível.

## Chamada Assíncrona

Quando o tempo de processamento é mais longo, pode-se passar `async: true`:

```python
submission = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={"authorization": "Bearer <YOUR_API_TOKEN>"},
    json={
        "audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f",
        "async": True
    }
).json()

export_task_id = submission["task_id"]
```

Em seguida, consulte `export_task_id` através de `/suno/tasks`. Também é possível fornecer `callback_url`, para receber o resultado final após a conclusão da tarefa. A resposta síncrona, consulta de tarefa e callback utilizam a mesma estrutura de dados final.

## Observações

- `audio_id` deve ser proveniente de um áudio Suno reconhecível.
- As tarefas de URL MP3 são independentes das tarefas de geração de música original.
- A transferência pode esperar no máximo 30 segundos; o tempo limite ou falha na transferência não bloqueará o resultado, retornando ao endereço de áudio fonte.
- Recomenda-se que o lado do negócio baixe os resultados prontamente e os salve de acordo com sua estratégia de retenção de dados.
