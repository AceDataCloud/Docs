A API de projeto do Suno Studio gerencia projetos de música multifaixa por meio de um único endpoint:

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

O `action` na solicitação determina o tipo de operação. A chave primária do Project usa uniformemente `id`; `version_id` representa a versão atual do projeto, e todas as operações de modificação e exportação devem enviar a versão mais recente para evitar sobrescritas simultâneas.

## Visão geral das operações

| action             | Modo  | Finalidade                      |
| ------------------ | --- | ----------------------- |
| `create`           | Síncrono  | Criar um projeto vazio                   |
| `retrieve`         | Síncrono  | Ler o projeto e o `state` editável completo      |
| `save`             | Síncrono  | Salvar o estado completo do projeto                |
| `upload`           | Assíncrono  | Inicializar material que pode ser adicionado ao projeto a partir de um endereço de áudio HTTPS |
| `add_track`        | Assíncrono  | Adicionar áudio existente ao projeto               |
| `generate_track`   | Assíncrono  | Gerar novos candidatos de faixa de áudio para um intervalo especificado            |
| `replace_section`  | Assíncrono  | Gerar candidatos de substituição local                |
| `commit_candidate` | Assíncrono  | Enviar o candidato selecionado ao projeto             |
| `remove_track`     | Síncrono  | Excluir a faixa especificada                  |
| `render`           | Assíncrono  | Exportar a versão salva como uma música completa           |

As operações assíncronas retornam imediatamente um `task_id`. Use a interface gratuita `/suno/tasks` para consultar, ou forneça `callback_url` para receber o resultado no estado final.

## Criar e ler

```json
{
  "action": "create",
  "title": "My Studio Project"
}
```

Todas as operações de modificação devem enviar um Header `Idempotency-Key` exclusivo. Após a criação bem-sucedida, o `data.id` na resposta é o ID do Project. Um novo projeto vazio pode não ter `version_id` antes do primeiro salvamento.

```json
{"action":"retrieve","id":"PROJECT_ID"}
```

A resposta da leitura contém o `state` completo. Recomenda-se ler primeiro, depois modificar e salvar com base no valor retornado; não construa manualmente do zero as estruturas internas de batidas e faixas.

## Salvar o estado completo

```json
{
  "action":"save",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Edited Project",
  "state":{"tracks":[],"timing":{}}
}
```

O primeiro salvamento de um novo projeto vazio pode omitir `version_id`; depois que o primeiro salvamento gerar uma versão, os salvamentos subsequentes devem enviar o valor mais recente. Se a versão já tiver mudado, a interface retorna HTTP 409. Nesse caso, faça `retrieve` novamente, mescle as modificações e envie com uma nova chave de idempotência; não tente novamente cegamente a solicitação antiga.

## Fazer upload e adicionar faixas

```json
{
  "action":"upload",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "audio_url":"https://cdn.example.com/reference.mp3",
  "async":true
}
```

Após a conclusão do upload, o resultado da tarefa retorna o `audio_id` candidato. Em seguida, adicione-o ao projeto:

```json
{
  "action": "add_track",
  "id": "PROJECT_ID",
  "version_id": "CURRENT_VERSION_ID",
  "audio_id": "AUDIO_ID",
  "name": "Backing Vocals"
}
```

## Gerar e substituir

`generate_track` gera candidatos de faixa de áudio para um intervalo do projeto; `replace_section` retorna dois candidatos de substituição local. Nenhuma das duas operações seleciona automaticamente o resultado artístico.

```json
{
  "action": "replace_section",
  "id": "PROJECT_ID",
  "version_id": "CURRENT_VERSION_ID",
  "source_audio_id": "AUDIO_ID",
  "start_seconds": 35.12,
  "end_seconds": 48.76,
  "model": "chirp-v6",
  "replacement_lyrics": "novo trecho de letra",
  "async": true
}
```

Após selecionar um candidato, envie-o:

```json
{
  "action":"commit_candidate",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "operation_id":"OPERATION_ID",
  "candidate_id":"CANDIDATE_ID",
  "track_id":"TRACK_ID"
}
```

Os candidatos são vinculados à versão do projeto no momento da geração. Quando o projeto já tiver mudado, candidatos antigos não poderão ser enviados diretamente.

## Exportar a música completa

```json
{
  "action":"render",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Final Mix",
  "lyrics":"[Instrumental]",
  "async":true,
  "callback_url":"https://example.com/webhooks/suno"
}
```

O servidor lê o estado autoritativo do projeto da versão especificada e monta os parâmetros de exportação. O resultado no estado final contém `render_id`, `audio_id`, `audio_url` e a duração. O projeto é vinculado ao ambiente de execução no momento da criação e não pode ser migrado entre ambientes nem alternado automaticamente em caso de falha.

> Você só pode fazer upload ou processar áudios para os quais possui direitos legais de uso. A API de projeto está atualmente em Beta; persista as URLs finais de áudio nos resultados importantes.
