Se você deseja usar as letras de duas músicas para gerar uma música misturada, pode primeiro usar esta API para gerar as letras correspondentes. A API é [Suno MashupLyrics Generation API](https://platform.acedata.cloud/documents/suno-mashup-lyrics).

Os principais parâmetros de entrada da API são `lyrics_a` e `lyrics_b`, um exemplo de preenchimento é mostrado abaixo:

![](https://cdn.acedata.cloud/g9n3t6.png)

Clique em executar, o resultado será o seguinte:

```
{
  "success": true,
  "task_id": "80aa3cd3-ca87-4ca3-82d2-1830e3d8f53a",
  "data": {
    "text": "Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nSambuy come, Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \nSambuy come back",
    "title": "Lyrics Mashup",
    "tags": [],
    "status": "complete"
  }
}
```

Pode-se ver que o campo `text` de `data` contém as informações da letra.

Com as letras em mãos, podemos usar a [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) para gerar músicas personalizadas.
