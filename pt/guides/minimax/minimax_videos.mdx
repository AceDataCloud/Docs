Este artigo apresenta a integração e o uso da API de Geração de Vídeo MiniMax H3. Esta interface suporta a geração de vídeo a partir de texto, controle de quadros iniciais e finais, e geração de vídeo de referência multimodal, utilizando uma estrutura unificada de `content` multimodal V2 para criar tarefas.

## Processo de Solicitação

Para usar a API de Geração de Vídeo MiniMax H3, primeiro acesse o [Painel de Controle da Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter seu Token de API, que deve ser guardado para referência futura.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, onde será convidado a se registrar e logar; após a conclusão, você será redirecionado de volta para a página atual.

**Um Token de API é suficiente para acessar todos os serviços da plataforma, não sendo necessário solicitar um para cada serviço.** A primeira solicitação oferece um crédito gratuito para que você possa experimentar; quando o crédito estiver baixo, você pode recarregar o saldo geral no [painel de controle](https://platform.acedata.cloud/console/coin).

> 📘 Documentação Completa: [API de Geração de Vídeo MiniMax H3 →](https://platform.acedata.cloud/documents/minimax-videos-integration)

Recomenda-se salvar o Token como uma variável de ambiente, não escrevê-lo no código-fonte ou enviá-lo para o repositório:

```bash
export ACEDATACLOUD_API_KEY="YOUR_API_KEY"
```

## Visão Geral da Interface

- **Base URL**: `https://api.acedata.cloud`
- **Endpoint**: `POST /minimax/videos`
- **Método de Autenticação**: Enviar `authorization: Bearer {token}` no cabeçalho HTTP
- **Cabeçalhos de Requisição**:
  - `accept: application/json`
  - `content-type: application/json`
- **Modelo (model)**: `MiniMax-H3`
- **Estrutura de Entrada**: Transmitir texto, imagem, vídeo e áudio através de `content`
- **Modo de Saída**: Por padrão, aguarda a conclusão da geração e retorna a `task` completa; ao passar `async: true` ou `callback_url`, retorna imediatamente `task_id` e `trace_id`
- **Consulta de Resultados**: Obter status e vídeo final através da [API de Consulta de Tarefas MiniMax H3](/documents/minimax-tasks-integration)
- **Callback Assíncrono**: Opcional, receber o resultado final da tarefa através de `callback_url`

Você não precisa passar `action` para escolher o modo de geração, a interface determinará automaticamente o uso com base no tipo de material e `role` em `content`.

## Cenários Adequados

| Cenário         | Combinação de Entrada        | Usos Comuns                      |
| -------------- | --------------------- | ------------------------- |
| Geração de Vídeo a partir de Texto | Texto                    | Criatividade publicitária, ensaio de cenas, vídeos curtos, cenas atmosféricas        |
| Geração de Vídeo a partir de Imagem Inicial | Texto + Imagem Inicial             | Fazer com que imagens de produtos, pôsteres, fotos de pessoas ou ilustrações ganhem vida      |
| Vídeo com Quadro Final / Quadro Inicial e Final | Texto + Quadro Final, ou Texto + Quadro Inicial + Quadro Final | Controlar a abertura e o fechamento do vídeo, transições, mudanças de crescimento e comparações |
| Geração de Vídeo de Referência Multimodal | Texto + Imagem / Vídeo / Áudio de Referência   | Manter a consistência de personagens e produtos, replicar ações, movimentos de câmera, timbre ou ritmo de edição |

## Fluxo de Chamada

Por padrão, ao não passar `async`, `/minimax/videos` aguardará a conclusão da geração e retornará diretamente a `task` completa. Se precisar liberar a conexão imediatamente, passe `async: true` ou `callback_url`:

1. Salve `task_id` e `trace_id` da resposta imediata.
2. Se não houver configuração de callback, consulte `/minimax/tasks` a cada 10 segundos.
3. Quando `task.status` mudar para `succeeded`, obtenha o vídeo de `task.content.url`.
4. Quando o status for `failed` ou `cancelled`, pare a consulta e leia `task.error`.

## Parâmetros de Solicitação de Nível Superior

| Parâmetro         | Tipo       | Obrigatório | Valor Padrão  | Descrição                                                |
| ---------------- | -------- | --------- | ------------ | ------------------------------------------------- |
| `model`          | string   | Sim       | -            | Fixo como `MiniMax-H3`                                  |
| `content`        | object[] | Sim       | -            | Array de conteúdo multimodal, deve conter um item `text` não vazio                         |
| `resolution`     | string   | Sim       | -            | `768P` ou `2K`                                     |
| `duration`       | integer  | Sim       | -            | Duração da geração, inteiro de 4 a 15 segundos                                     |
| `ratio`          | string   | Condicional | `adaptive`   | `adaptive`, `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16` |
| `async`          | boolean  | Não       | `false`      | Se `true`, retorna imediatamente a identificação da tarefa, resultados obtidos através da interface de tarefas                       |
| `callback_url`   | string   | Não       | -            | URL pública de callback para receber o resultado final da tarefa; se fornecida, ativa automaticamente o modo assíncrono                     |

As regras para `ratio` dependem do fluxo de trabalho:

- **Geração de Vídeo a partir de Texto**: Obrigatório e não pode ser `adaptive`.
- **Vídeo com Quadro Inicial, Quadro Final ou Quadro Inicial e Final**: A proporção é determinada pela imagem de entrada, recomenda-se omitir ou passar `adaptive`.
- **Geração de Vídeo de Referência Multimodal**: Pode ser omitido, padrão é `adaptive`; também pode ser especificada uma proporção fixa.

A interface não aceita campos antigos ou compatíveis, como `prompt`, `image_urls`, `audio_urls`, `messages` e `first_frame_image`. Ao receber parâmetros desse tipo, remova os campos antigos e migre para `content`; por exemplo, mude `"prompt": "um gato acenando"` para `"content": [{"type": "text", "text": "um gato acenando"}]`. Não envie simultaneamente os dois formatos.

## Parâmetros de Itens de Conteúdo

Cada item de conteúdo deve ter `type`, os demais campos são determinados pelo tipo:

| `type`        | Campo de Dados        | `role`            | Descrição                                     |
| ------------- | --------------------- | ----------------- | -------------------------------------- |
| `text`        | `text`                | Não enviar         | Cada solicitação deve conter um item de texto não vazio, máximo de 7000 caracteres             |
| `image_url`   | `image_url.url`       | `first_frame`     | Imagem do quadro inicial; se houver apenas uma imagem e `role` for omitido, também será tratada como quadro inicial         |
| `image_url`   | `image_url.url`       | `last_frame`      | Imagem do quadro final; pode ser usada sozinha ou combinada com `first_frame` para controlar o início e o fim |
| `image_url`   | `image_url.url`       | `reference_image` | Imagem de referência de sujeito, personagem, produto, vestuário, cena ou estilo                    |
| `video_url`   | `video_url.url`       | `reference_video` | Vídeo de referência de ação, movimento de câmera, performance ou estrutura de edição                        |
| `audio_url`   | `audio_url.url`       | `reference_audio` | Áudio de referência de timbre, diálogo, música ou ritmo                          |

Os endereços de mídia suportam três formas:

- URL HTTPS acessível publicamente, recomendada para arquivos grandes.
- `mm_file://{file_id}`, referenciando arquivos já carregados ou resultados existentes.
- URI de dados Base64 correspondente ao tipo de mídia. Base64 aumentará o tamanho em cerca de um terço, certifique-se de que o corpo da solicitação total não exceda 64 MB.

## Especificações e Limitações de Material
| Material | Formato                                      | Limite de arquivo | Tamanho / Duração                                                   | Limite de quantidade                  |
| --- | ------------------------------------------- | --------- | --------------------------------------------------------------- | --------------------------- |
| Imagem  | JPG, JPEG, PNG, WEBP, HEIC, HEIF                 | Não exceder 30 MB | Largura e altura entre 256-5760 px; proporção de 0.4-2.5                | Máximo de 1 imagem de primeiro quadro, máximo de 1 imagem de último quadro, máximo de 9 imagens de referência |
| Vídeo   | MP4, MOV; H.264/AVC ou H.265/HEVC; trilha de áudio AAC ou MP3 | Não exceder 50 MB | Cada segmento de 2-15 segundos, totalizando não mais que 15 segundos; largura e altura entre 256-5760 px; proporção de 0.4-2.5; 23.976-60 fps | Máximo de 3 segmentos de vídeo de referência                  |
| Áudio   | WAV, MP3                                     | Não exceder 15 MB | Cada segmento de 2-15 segundos, totalizando não mais que 15 segundos        | Máximo de 3 segmentos de áudio de referência                  |

No cenário de referência multimodal, o total de imagens, vídeos e áudios não pode exceder 12 arquivos. Os cenários de primeiro e último quadro e os cenários de material de referência são mutuamente exclusivos: uma vez que `reference_image`, `reference_video` ou `reference_audio` é utilizado, não é possível usar `first_frame` ou `last_frame`, e vice-versa.

## Demonstração de capacidade em nível de produção

O que se segue não são imagens conceituais ou materiais de placeholder, mas sim entradas reais de referência e saídas de vídeo do MiniMax H3 em nível de produção oficial. Três grupos de casos cobrem curtas-metragens de marca, narrativas com pessoas reais e e-commerce de moda, adequados para avaliar as capacidades mais críticas do modelo em produções comerciais.

| Capacidade       | Observações principais                  |
| -------- | --------------------------- |
| Consistência de personagens e rostos | Estabilidade das características faciais, penteado, maquiagem e temperamento do personagem após cortes de múltiplas câmeras     |
| Performance facial     | Expressões faciais, micro-expressões, tensão emocional e movimento natural da cabeça em close-ups      |
| Manutenção da estrutura do produto   | Contornos, materiais, relações de uso e reflexos de produtos como óculos e bolsas    |
| Execução visual da marca   | Atmosfera da cena, granulação cinematográfica, cores, logo e ritmo de edição estão unificados |
| Narrativa cinematográfica    | Mudanças de plano, disposição de personagens, movimento de câmera, ritmo e som podem formar parágrafos completos  |

Aqui, a "capacidade facial" refere-se à consistência da aparência dos personagens, detalhes faciais e controle de performance na geração de vídeo, não à identificação de identidade, comparação de rostos ou interfaces de troca de rosto.

## Vídeo Gerado a Partir de Texto

Quando há apenas um item de texto, é um vídeo gerado a partir de texto. É adequado para gerar imagens diretamente a partir de ideias, roteiros ou descrições de cenas. As palavras-chave podem ser organizadas na ordem "sujeito + ação + cena + câmera + luz + som".

```bash
curl -X POST 'https://api.acedata.cloud/minimax/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MiniMax-H3",
    "content": [
      {
        "type": "text",
        "text": "15 segundos de anúncio de perfume cinematográfico: nas rochas negras da costa ao amanhecer, uma garrafa de perfume transparente é cercada por névoa e ondas do mar. Close-up mostra gotas de água e refração do vidro, a câmera se afasta lentamente do close do produto para o vasto mar; tons prateados e azuis, luz natural realista, sofisticado e contido, finalizando com a imagem do produto."
      }
    ],
    "resolution": "2K",
    "duration": 15,
    "ratio": "16:9"
  }'
```

O modo padrão de sincronização retornará a tarefa completa após a conclusão da geração:

```json
{
  "task": {
    "id": "f5977217-ed2c-40da-adbe-93d08235618f",
    "model": "MiniMax-H3",
    "status": "succeeded",
    "content": { "url": "https://cdn.acedata.cloud/minimax/f5977217.mp4" },
    "resolution": "2K",
    "duration": 15,
    "ratio": "16:9"
  }
}
```

Se a solicitação incluir `"async": true`, a interface retornará imediatamente:

```json
{
  "task_id": "f5977217-ed2c-40da-adbe-93d08235618f",
  "trace_id": "trace_7f8c2b1a"
}
```

## Vídeo Gerado a Partir da Primeira Imagem

Marque a imagem como `first_frame`, e o modelo começará a gerar a partir dessa cena. É adequado para dar vida a pôsteres, imagens de produtos, ilustrações de personagens e obras fotográficas.

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "A personagem respira naturalmente e olha pela janela, a ponta de sua roupa é movida pela brisa, a câmera avança lentamente."
    },
    {
      "type": "image_url",
      "image_url": {
        "url": "https://cdn.acedata.cloud/b1c82e4937.png"
      },
      "role": "first_frame"
    }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "adaptive"
}
```

## Vídeo de Quadro Final e Quadro Inicial
只提供 `last_frame` 可以让模型自然生成到指定画面；同时提供 `first_frame` 与 `last_frame`，可以明确控制起点和终点。适合转场、形态变化、成长过程或产品前后对比。

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "A menina cresce naturalmente da infância para a juventude, o tempo passa suavemente, e a personagem permanece sempre no centro da tela."
    },
    {
      "type": "image_url",
      "image_url": { "url": "YOUR_FIRST_FRAME_URL" },
      "role": "first_frame"
    },
    {
      "type": "image_url",
      "image_url": { "url": "YOUR_LAST_FRAME_URL" },
      "role": "last_frame"
    }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "adaptive"
}
```

As dimensões e a proporção da primeira e da última imagem devem ser o mais consistentes possível, e as diferenças na posição do sujeito, composição e iluminação não devem ser muito grandes, para que a transição natural seja mais fácil de obter.

## Referência de Vídeo Multimodal

Materiais de referência podem ser usados em combinação: imagens de referência controlam a aparência de personagens ou produtos, vídeos de referência controlam ações e movimentos de câmera, e áudios de referência controlam o tom de voz, música ou ritmo de edição. As instruções devem deixar claro o que cada tipo de material deve controlar, evitando o envio de materiais sem estabelecer relações.

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "Mantenha as características faciais, o penteado e a roupa do personagem de referência consistentes, completando o curta-metragem de moda de acordo com as ações de performance do vídeo de referência; o ritmo da câmera deve seguir o áudio de referência, com close-ups que destacam expressões faciais naturais."
    },
    {
      "type": "image_url",
      "image_url": { "url": "YOUR_CHARACTER_IMAGE_URL" },
      "role": "reference_image"
    },
    {
      "type": "video_url",
      "video_url": { "url": "YOUR_PERFORMANCE_VIDEO_URL" },
      "role": "reference_video"
    },
    {
      "type": "audio_url",
      "audio_url": { "url": "YOUR_AUDIO_URL" },
      "role": "reference_audio"
    }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "adaptive"
}
```

## Notificação de Callback

A inclusão de `callback_url` ativará automaticamente o modo assíncrono: a interface de criação retornará imediatamente `task_id` e `trace_id`, e após a conclusão da tarefa, enviará um POST para esse endereço com o resultado final, cuja estrutura é a mesma da resposta de consulta de tarefa.

O estado final no callback será `succeeded`, `failed` ou `cancelled`. Mesmo ao usar callback, é recomendável salvar o `task_id`, para que você possa consultar ativamente ou compensar notificações perdidas.

## Erros Comuns

| Código de Status HTTP | Significado                     | Sugestão de Tratamento                     |
| --------------------- | ------------------------------- | ------------------------------------------ |
| `400`                 | Erro de parâmetro ou combinação de materiais inválida | Verifique os campos obrigatórios, `role`, quantidade e formato dos materiais |
| `401`                 | Token ausente ou inválido       | Verifique `Authorization: Bearer ...`    |
| `402`                 | Saldo ou limite insuficiente    | Complete o saldo geral no console         |
| `422`                 | Verificação de segurança de conteúdo não aprovada | Ajuste as instruções ou materiais e reenvie |
| `429`                 | Solicitações muito frequentes   | Tente novamente após um retrocesso exponencial; recomenda-se um intervalo de cerca de 10 segundos para a consulta de tarefas |
| `500`                 | Serviço temporariamente indisponível | Guarde as informações da solicitação e tente novamente mais tarde |

O `task.status: succeeded` na resposta síncrona indica que o vídeo foi gerado; a confirmação assíncrona apenas representa que a tarefa entrou na fila. Apenas quando a tarefa for finalmente bem-sucedida haverá cobrança, a consulta da tarefa em si é gratuita e não resultará em cobranças duplicadas.
