Este documento apresenta as instruções para integrar a API Grok Videos Generation, que pode gerar vídeos Grok Imagine (xAI) a partir de texto, imagens de entrada e imagens de referência opcionais.

## Processo de Solicitação

Para usar a API, é necessário solicitar o serviço correspondente na página [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos). Após acessar a página, clique no botão "Acquire", conforme mostrado na imagem:

![](https://cdn.acedata.cloud/q6ytrc.png)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, onde poderá se registrar e fazer login. Após o login, você será redirecionado de volta para a página atual.

Na primeira solicitação, será concedida uma cota gratuita para uso da API.

## Descrição dos Modelos

Esta API suporta dois modelos:

- `grok-imagine-video` (padrão): suporta geração de vídeo a partir de texto (apenas com `prompt`) e a partir de imagem (com `image_url`), com custo menor.
- `grok-imagine-video-1.5-preview`: suporta somente geração de vídeo a partir de imagem, **é obrigatório** fornecer `image_url`.

## Uso Básico

Primeiro, entenda a forma básica de uso: forneça o texto `prompt`, o modelo `model` e outros parâmetros para gerar o vídeo correspondente.

Aqui configuramos os cabeçalhos da requisição (Request Headers), incluindo:

- `accept`: formato desejado para a resposta, aqui definido como `application/json` (formato JSON).
- `authorization`: chave de acesso para chamar a API, selecionável após a solicitação.

Também configuramos o corpo da requisição (Request Body), incluindo:

- `prompt`: texto que descreve o conteúdo do vídeo a ser gerado. Obrigatório para geração de vídeo a partir de texto com `grok-imagine-video`; opcional se `image_url` for fornecido.
- `model`: modelo para geração do vídeo, pode ser `grok-imagine-video` (padrão) ou `grok-imagine-video-1.5-preview`.
- `image_url`: link da imagem de entrada para geração de vídeo a partir de imagem. Obrigatório se `model` for `grok-imagine-video-1.5-preview`.
- `reference_image_urls`: array opcional de links de imagens de referência para guiar o estilo ou conteúdo do vídeo.
- `aspect_ratio`: proporção largura:altura do vídeo gerado, opções: `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`.
- `resolution`: resolução de saída, opções: `480p` (padrão) ou `720p`. Resoluções maiores consomem mais cota.
- `duration`: duração do vídeo em segundos, intervalo de 1 a 15, padrão 8. A cobrança é feita por segundo de saída.
- `callback_url`: URL para callback assíncrono. Se configurado, a API retorna imediatamente o `task_id` e envia o resultado final para este endereço via POST quando a tarefa for concluída.

Clique no botão "Try" para testar. O resultado será similar ao seguinte:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/grok/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Os campos retornados são:

- `success`: indica se a solicitação de geração de vídeo foi bem-sucedida.
- `task_id`: ID da tarefa de geração de vídeo.
- `trace_id`: ID de rastreamento da solicitação para diagnóstico.
- `data`: lista dos resultados dos vídeos gerados.
  - `id`: identificador único do vídeo gerado.
  - `video_url`: URL do vídeo gerado.
  - `state`: estado da tarefa de geração, pode ser `pending` / `succeeded` / `failed`.

Basta acessar o link `video_url` em `data` para obter o vídeo gerado.

Exemplo de código CURL:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "resolution": "480p",
  "duration": 8
}'
```

Exemplo de código Python:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Geração de Vídeo a partir de Imagem

Para gerar vídeo baseado em uma imagem de entrada, forneça `image_url`. Ao usar `grok-imagine-video-1.5-preview`, este campo é obrigatório:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5-preview",
  "image_url": "https://cdn.acedata.cloud/grok/example-input.png",
  "resolution": "720p",
  "duration": 8
}
```

## Guia por Imagens de Referência

Para guiar o estilo ou conteúdo do vídeo com uma ou mais imagens de referência, envie um array de URLs em `reference_image_urls`:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/grok/example-reference.png"
  ]
}
```

## Callback Assíncrono

A geração de vídeo pode levar algum tempo. Para evitar manter a conexão aberta, configure `callback_url`. A API retornará imediatamente o `task_id` e enviará o resultado final via POST para o endereço configurado quando a tarefa for concluída:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "duration": 8,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

Resposta imediata:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Consulta de Resultado da Tarefa

Se usar callback assíncrono ou desejar consultar o status da tarefa, utilize a [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) com o `task_id` para obter o status e resultado atualizados.

## Informações de Cobrança

O serviço cobra pela "duração de saída" do vídeo gerado, com preço determinado pelo `model` e `resolution`. O custo total = preço unitário × `duration` (padrão 8 segundos). `720p` é mais caro que `480p`, e `grok-imagine-video-1.5-preview` é mais caro que `grok-imagine-video`. Consulte a página de preços para detalhes.

## Tratamento de Erros

Em caso de problemas, a API retorna códigos de erro e mensagens, comuns são:

- `400`: parâmetros inválidos, como falta de `prompt` para vídeo a partir de texto, ausência de `image_url` para `grok-imagine-video-1.5-preview`, ou `duration` fora do intervalo 1–15.
- `401`: falha na autenticação, token inválido ou incompatível com a API.
- `403`: saldo insuficiente ou rejeição por violação de política de conteúdo.
- `429`: requisições muito frequentes, limite de taxa acionado, tente novamente mais tarde.
- `500`: erro interno do servidor ou falha na geração upstream.
