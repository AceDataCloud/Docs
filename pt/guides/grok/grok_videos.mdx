Este documento apresentará as instruções de integração da Grok Videos Generation API, que pode gerar vídeos Grok Imagine (xAI) através da entrada de texto, imagens e imagens de referência opcionais.

## Processo de Solicitação

Para usar a Grok Videos Generation API, primeiro acesse o [Painel de Controle da Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter seu Token de API, que deve ser guardado.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, onde será convidado a se registrar e logar; após a conclusão, você será retornado automaticamente à página atual.

**Um Token de API é suficiente para acessar todos os serviços da plataforma, não sendo necessário solicitar um para cada serviço.** A primeira solicitação oferece um crédito gratuito para experimentar; quando o crédito acabar, você pode recarregar o saldo geral no [painel de controle](https://platform.acedata.cloud/console/coin).

> 📘 Documentação Completa: [Grok Videos Generation API →](https://platform.acedata.cloud/documents/grok-videos)

## Descrição do Modelo

Esta API suporta dois modelos:

- `grok-imagine-video-1.5-fast` (padrão): suporta vídeos gerados a partir de texto (apenas passando `prompt`) e vídeos gerados a partir de imagens (passando `image_url`), com duração máxima de 30 segundos e preço mais baixo.
- `grok-imagine-video-1.5`: suporta apenas vídeos gerados a partir de imagens, **é obrigatório** passar `image_url`, com duração máxima de 15 segundos.

## Uso Básico

Primeiro, entenda a forma básica de uso, passando os parâmetros de texto `prompt`, modelo `model`, entre outros, para gerar o vídeo correspondente.

Aqui, configuramos os Cabeçalhos da Solicitação, incluindo:

- `accept`: o formato de resposta desejado, aqui preenchido como `application/json`, ou seja, formato JSON.
- `authorization`: a chave para chamar a API, que pode ser selecionada diretamente após a solicitação.

Além disso, configuramos o Corpo da Solicitação, incluindo:

- `prompt`: texto que descreve o conteúdo do vídeo que você deseja gerar. É **obrigatório** ao usar `grok-imagine-video-1.5-fast` para vídeos gerados a partir de texto; opcional ao passar `image_url`.
- `model`: o modelo para gerar o vídeo, podendo ser `grok-imagine-video-1.5-fast` (padrão) ou `grok-imagine-video-1.5`.
- `image_url`: link da imagem de entrada para vídeos gerados a partir de imagens. É **obrigatório** quando `model` é `grok-imagine-video-1.5`.
- `reference_image_urls`: array de links de imagens de referência opcionais, usadas para guiar o estilo ou conteúdo do vídeo.
- `aspect_ratio`: a proporção largura-altura do vídeo gerado, podendo ser `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`.
- `resolution`: resolução de saída, podendo ser `480p` (padrão), `720p` ou `1080p`.
- `duration`: duração do vídeo gerado (segundos). O intervalo para `grok-imagine-video-1.5-fast` é de 1 a 30, e para `grok-imagine-video-1.5` é de 1 a 15, padrão 6. Recomenda-se usar 6 segundos ou 10 segundos, que são durações padrão relativamente estáveis.
- `callback_url`: endereço de callback assíncrono; ao configurá-lo, a API retornará imediatamente `task_id`, e quando a tarefa for concluída, o resultado será enviado para esse endereço.
- `async`: opcional, se definido como `true`, a interface retornará imediatamente `task_id`, sem necessidade de fornecer `callback_url`, e você poderá consultar o resultado através da interface de consulta de tarefas correspondente.

Clique no botão "Try" para realizar o teste, e o resultado obtido será semelhante ao seguinte:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video-1.5-fast:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
      "state": "succeeded"
    }
  ]
}
```

O resultado retornado contém vários campos, descritos a seguir:

- `success`: se a solicitação de geração de vídeo foi bem-sucedida.
- `task_id`: o ID da tarefa de geração de vídeo.
- `trace_id`: o ID de rastreamento da solicitação, usado para solucionar problemas.
- `data`: lista de resultados do vídeo gerado.
  - `id`: identificador único do vídeo gerado.
  - `video_url`: endereço do link do vídeo gerado.
  - `state`: estado da tarefa de geração de vídeo, podendo ser `pending` / `succeeded` / `failed`.

Precisamos apenas obter o vídeo gerado através do link `video_url` no resultado `data`.

O código CURL correspondente é o seguinte:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "resolution": "480p",
  "duration": 6
}'
```

O código Python correspondente é o seguinte:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video-1.5-fast",
    "resolution": "480p",
    "duration": 6
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Vídeos Gerados a partir de Imagens

Se você deseja gerar um vídeo com base em uma imagem de entrada, pode passar `image_url`. Ao usar `grok-imagine-video-1.5`, este campo deve ser fornecido:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5",
  "image_url": "https://cdn.acedata.cloud/5hmkdg.jpg",
  "resolution": "720p",
  "duration": 6
}
```

## Direcionamento com Imagens de Referência

Se você deseja usar uma ou mais imagens de referência para guiar o estilo ou conteúdo do vídeo gerado, pode passar um array de links de imagens em `reference_image_urls`:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video-1.5-fast",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/vunnjf.png"
  ]
}
```

## Callback Assíncrono

A geração de vídeo requer um certo tempo de processamento. Se você não deseja manter uma conexão longa esperando, pode passar `callback_url`; nesse caso, a API retornará imediatamente `task_id`, e após a conclusão da tarefa, enviará o resultado final para esse endereço:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "duration": 6,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

O resultado retornado imediatamente será o seguinte:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Consultar Resultados da Tarefa
Se você usou callbacks assíncronos ou deseja consultar ativamente o status da tarefa, pode consultar o status e os resultados mais recentes da tarefa pelo [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) com base no `task_id`.

## Descrição da Cobrança

O método de cobrança deste serviço é determinado pelo `model`:

- `grok-imagine-video-1.5-fast`: cobrança por duração em faixas, independente da resolução — `1–10` segundos, `11–20` segundos, `21–30` segundos correspondem a diferentes faixas de preço.
- `grok-imagine-video-1.5`: cobrança por "segundos de saída", preço total = preço unitário × `duration`, `1080p` é mais caro que `480p`/`720p`.

Os preços unitários são conforme a página de preços. Solicitações falhadas não são cobradas e não consomem a cota gratuita.

## Tratamento de Erros

Quando há um problema com a solicitação, a API retornará o código de erro correspondente e a descrição, os mais comuns são:

- `400`: parâmetros da solicitação estão incorretos, por exemplo, vídeo gerado por texto sem `prompt`, ou `grok-imagine-video-1.5` sem `image_url`, ou `duration` fora do intervalo (`grok-imagine-video-1.5-fast` é 1–30, `grok-imagine-video-1.5` é 1–15).
- `401`: falha na autenticação, token inválido ou não correspondente à API.
- `403`: saldo insuficiente, ou a palavra-chave atingiu a revisão de conteúdo e foi rejeitada.
- `429`: solicitações muito frequentes, por favor, tente novamente mais tarde.
- `500`: falha na geração do vídeo ou anomalia no serviço.
