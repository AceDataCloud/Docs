A principal função da API Grok Tasks é consultar o status de execução de tarefas através do ID da tarefa gerado pela API Grok Videos Generation.

Este documento irá detalhar as instruções de integração da API Grok Tasks, ajudando você a integrar e consultar facilmente o status de execução das tarefas da API Grok Videos Generation.

## Processo de Solicitação

Para usar a API Grok Videos Generation, primeiro acesse o [Painel de Controle da Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter seu Token de API, que deve ser guardado para uso futuro.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, onde será convidado a se registrar e logar. Após a conclusão, você será redirecionado de volta para a página atual.

**Um Token de API é suficiente para acessar todos os serviços da plataforma, não sendo necessário solicitar um para cada serviço individualmente.** A primeira solicitação oferece um crédito gratuito para que você possa experimentar; quando o crédito acabar, você pode recarregar o saldo geral no [painel de controle](https://platform.acedata.cloud/console/coin).

> 📘 Documentação Completa: [Grok Videos Generation API →](https://platform.acedata.cloud/documents/grok-videos)

## Exemplo de Solicitação

A API Grok Tasks pode ser usada para consultar os resultados da API Grok Videos Generation.

### Configurando Cabeçalhos e Corpo da Solicitação

**Cabeçalhos da Solicitação** incluem:

- `accept`: especifica que a resposta deve ser no formato JSON, preenchido como `application/json`.
- `authorization`: a chave para chamar a API, que pode ser selecionada diretamente após a solicitação.

**Corpo da Solicitação** inclui:

- `id`: o ID da tarefa a ser consultada.
- `action`: a forma de operação na tarefa, para consulta única, preencha como `retrieve`.

### Exemplo de Código CURL

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Exemplo de Resposta

Após uma solicitação bem-sucedida, a API retornará as informações detalhadas da tarefa. O campo `request` é o corpo da solicitação quando a tarefa foi iniciada, e o campo `response` é o corpo da resposta retornado após a conclusão da tarefa, por exemplo:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262729.623,
  "elapsed": 7.8,
  "request": {
    "prompt": "Uma cena cinematográfica de um gatinho perseguindo uma borboleta em um jardim ensolarado",
    "model": "grok-imagine-video-1.5-fast:reverse",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video-1.5-fast:reverse:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

A descrição dos campos é a seguinte:

- `id`: ID da tarefa gerada, usado para identificar exclusivamente esta tarefa de geração.
- `request`: informações da solicitação na tarefa consultada.
- `response`: informações da resposta na tarefa consultada.
- `created_at`: data e hora de criação da tarefa, timestamp Unix (segundos, ponto flutuante).
- `started_at`: data e hora em que a tarefa começou a ser executada, timestamp Unix (segundos, ponto flutuante).
- `finished_at`: data e hora em que a tarefa foi concluída, timestamp Unix (segundos, ponto flutuante). Este campo não é retornado se a tarefa não estiver concluída.
- `elapsed`: tempo gasto na execução da tarefa, em segundos (ponto flutuante, com 3 casas decimais). Este campo não é retornado se a tarefa não estiver concluída.

## Operação de Consulta em Lote

Para consultar detalhes de várias tarefas ID, defina `action` como `retrieve_batch` e passe um array de IDs de tarefas através de `ids`:

**Corpo da Solicitação** inclui:

- `ids`: array de IDs de tarefas a serem consultadas.
- `action`: a forma de operação na tarefa, para consulta em lote, preencha como `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
