A principal função da API Grok Tasks é consultar o status de execução de uma tarefa a partir do ID da tarefa gerado pela API Grok Videos Generation.

Este documento detalha as instruções para integração da API Grok Tasks, ajudando você a integrar facilmente e consultar o status das tarefas da API Grok Videos Generation.

## Processo de Solicitação

Para usar a API Grok Tasks, primeiro é necessário solicitar o serviço correspondente na página [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos) e copiar o ID da tarefa retornado pela API Grok Videos Generation.

Em seguida, acesse a página [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) para solicitar o serviço correspondente. Após entrar na página, clique no botão "Acquire".

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a [página de login](https://platform.acedata.cloud), onde poderá se registrar e fazer login. Após o login, você será redirecionado automaticamente para a página atual.

Na primeira solicitação, há uma cota gratuita concedida, permitindo o uso gratuito da API.

## Exemplo de Requisição

A API Grok Tasks pode ser usada para consultar os resultados da API Grok Videos Generation.

### Configuração dos Cabeçalhos e Corpo da Requisição

**Cabeçalhos da Requisição** incluem:

- `accept`: especifica que a resposta deve estar no formato JSON, aqui definido como `application/json`.
- `authorization`: chave de autenticação para chamar a API, que pode ser selecionada diretamente após a solicitação.

**Corpo da Requisição** inclui:

- `id`: o ID da tarefa a ser consultada.
- `action`: a ação a ser realizada na tarefa, para consulta única use `retrieve`.

### Exemplo de Código CURL

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Exemplo de Resposta

Após o sucesso da requisição, a API retornará os detalhes da tarefa. O campo `request` contém o corpo da requisição enviada para iniciar a tarefa, e o campo `response` contém o corpo da resposta após a conclusão da tarefa, por exemplo:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video-1.5-fast",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video-1.5-fast:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Descrição dos campos:

- `id`: ID da tarefa gerada, usado para identificar unicamente esta tarefa.
- `request`: informações da requisição da tarefa consultada.
- `response`: informações da resposta da tarefa consultada.

## Consulta em Lote

Para consultar detalhes de múltiplos IDs de tarefas, defina o `action` como `retrieve_batch` e passe um array de IDs através do campo `ids`:

**Corpo da Requisição** inclui:

- `ids`: array dos IDs das tarefas a serem consultadas.
- `action`: ação a ser realizada, para consulta em lote use `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
