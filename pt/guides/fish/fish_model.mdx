Esta interface é baseada na [API oficial de Model da Fish Audio](https://docs.fish.audio/resources/api-reference/model) e é usada para **criar um modelo de voz clonada reutilizável a longo prazo com base em uma amostra de áudio**. O endereço é `POST https://api.acedata.cloud/fish/model`.

> Quando precisar usar temporariamente uma voz de referência, não é necessário criar um modelo; você pode usar diretamente a clonagem instantânea única `references` da [API Fish TTS](https://platform.acedata.cloud/documents/fish-tts). Para pesquisar vozes existentes com paginação, consulte a [API Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query); para consultar os detalhes de uma única voz por `_id`, consulte a [API Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get).

## Processo de solicitação

Para usar a API Fish Model, primeiro obtenha seu API Token no [console do Ace Data Cloud](https://platform.acedata.cloud/console/applications) e guarde-o como reserva.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não estiver conectado ou registrado, será automaticamente redirecionado para a página de login, convidando você a se registrar e entrar; após concluir, você retornará automaticamente à página atual.

**Um único API Token pode chamar todos os serviços da plataforma, sem necessidade de solicitar um separadamente para cada serviço.** A primeira solicitação concede créditos gratuitos, permitindo uma experiência gratuita; quando os créditos forem insuficientes, você pode recarregar o saldo geral no [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentação completa: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Campos do corpo da solicitação

| Campo                      | Tipo       | Obrigatório  | Descrição                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | Sim   | Nome da voz, usado para identificação na lista do console.                                                             |
| `voices`                | string   | Sim   | URL HTTP(S) da amostra de áudio (**uma única string**, não um array). Esta interface não suporta upload multipart/binário; primeiro coloque o áudio em qualquer armazenamento de objetos publicamente acessível. |
| `description`           | string   | Não   | Descrição da voz.                                                                         |
| `cover_image`           | string   | Não   | URL HTTP(S) da imagem de capa.                                                              |
| `tags`                  | string[] | Não   | Tags de pesquisa da biblioteca pública, por exemplo, `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | Não   | Textos de referência correspondentes às amostras (usados para corrigir a pronúncia).                                                           |
| `enhance_audio_quality` | boolean  | Não   | Se deve realizar melhoria da qualidade de áudio na amostra antes do treinamento.                                                                |
| `generate_sample`       | boolean  | Não   | Se deve gerar automaticamente um áudio de exemplo após a conclusão do treinamento.                                                            |

> Para mais informações sobre o modelo de voz, consulte a [documentação oficial da Fish](https://docs.fish.audio/resources/api-reference/model).

> As vozes criadas serão salvas publicamente a longo prazo, e outros usuários poderão pesquisá-las e utilizá-las. Não é necessário passar `visibility`; mesmo que seja passado `private` ou `unlist`, a interface atual não alterará o escopo público com base nisso.

## Exemplo: criar uma voz clonada pública

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的中文音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Observação: `voices` deve ser uma **string** (uma única URL de áudio), não um array. Se for passado como `["..."]`, o upstream recusará. Recomenda-se usar um link direto publicamente baixável com sufixo `.mp3` ou `.wav`.

A resposta bem-sucedida retorna diretamente o objeto ModelEntity da plataforma Fish (o exemplo abaixo é a voz mínima utilizável que testamos; alguns campos longos foram removidos para facilitar a leitura):


## Requisitos da amostra

Valores de experiência (consistentes com o upstream; consulte a [documentação oficial da Fish](https://docs.fish.audio/resources/api-reference/model)):

- Recomenda-se duração de mais de 30 segundos, com melhor efeito em até 5 minutos; acima de 10 minutos, o ganho marginal não é grande.
- Taxa de amostragem de 16 kHz ou superior; mono ou estéreo são ambos aceitos.
- O conteúdo deve estar o mais limpo possível: sem música de fundo, eco ou ruído ambiental evidente; o mesmo falante.
- Formatos recomendados: `mp3` / `wav`.

Se não tiver certeza sobre a qualidade da amostra, você também pode passar `enhance_audio_quality: true` para que o upstream realize primeiro a melhoria da qualidade de áudio.

## Explicação de cobrança
A criação de modelos de clonagem de voz (`POST /fish/model`) é gratuita, sem qualquer cobrança; as interfaces de consulta de vozes ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)、[Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) também não são cobradas. Os custos são gerados apenas conforme o uso ao chamar posteriormente o [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para sintetizar voz.

## Tratamento de erros

- `400 token_mismatched`: parâmetros da solicitação ausentes ou inválidos (o mais comum é `voices` não ser uma URL, ou ter sido enviado como um array).
- `400`: quando o áudio de referência não puder ser baixado, tiver duração muito curta ou o formato não puder ser reconhecido, verifique a URL do áudio e o formato do arquivo.
- `401 invalid_token`: o token de autenticação não existe ou é inválido.
- `429 too_many_requests`: o limite de taxa da conta foi acionado.
- `500 api_error`: erro interno do servidor.

Exemplo de resposta de erro:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusão

Para chamar esta interface, basta preparar uma URL de áudio de amostra publicamente acessível, colocá-la no campo `voices` para obter o `_id` e, em seguida, passá-lo para o `reference_id` de `/fish/tts`, concluindo assim o processo completo de «clonagem → síntese». Um erro comum é que `voices` deve ser uma string, não podendo ser um array.

## Criar e reutilizar vozes por meio do MCP

No Fish MCP, chame
`fish_create_model(title="Minha voz", voices="https://example.com/authorized-voice.wav")`.
`voices` é uma única URL de áudio HTTP(S); também é possível passar `description`, `cover_image`, `tags`,
`texts`, `enhance_audio_quality`, `generate_sample`.

Esta ferramenta salvará vozes públicas permanentemente, e outros usuários poderão descobri-las e utilizá-las; use apenas
materiais de áudio autorizados para processamento e divulgação. A ferramenta não possui opções privadas ou não públicas. O `_id` retornado após a criação bem-sucedida é usado para o
`reference_id` de `fish_generate_audio`, e `fish_list_models(self=true)` pode consultar as vozes
salvas por você. Quando for necessário apenas uma voz de referência única, use `references` de `fish_generate_audio`,
sem precisar criar uma voz permanente.
