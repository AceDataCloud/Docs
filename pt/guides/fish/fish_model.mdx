Esta interface é baseada na [API Model do Fish Audio](https://docs.fish.audio/resources/api-reference/model) e é utilizada para **criar um novo timbre de voz baseado em uma amostra de áudio**. O endereço é `POST https://api.acedata.cloud/fish/model`.

> Para pesquisa paginada de timbres existentes, consulte a [API Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query); para consultar detalhes de um único timbre por `_id`, consulte a [API Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get).

## Processo de Solicitação

Para usar a API Fish Model, primeiro acesse o [Painel de Controle da Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter seu Token de API, que deve ser guardado para uso futuro.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, onde será convidado a se registrar e logar. Após a conclusão, você será redirecionado de volta para a página atual.

**Um Token de API é suficiente para acessar todos os serviços da plataforma, não sendo necessário solicitar um para cada serviço individualmente.** A primeira solicitação vem com um crédito gratuito, permitindo uma experiência sem custo; quando o crédito acabar, você pode recarregar o saldo geral no [painel](https://platform.acedata.cloud/console/coin).

> 📘 Documentação completa: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Campos do Corpo da Solicitação

| Campo                    | Tipo       | Obrigatório | Descrição                                                                         |
| ----------------------- | -------- | --------- | ------------------------------------------------------------------------------- |
| `title`                 | string   | Sim       | Nome do timbre, usado para identificação na lista do painel.                             |
| `voices`                | string   | Sim       | URL HTTP(S) da amostra de áudio (**uma única string**, não um array). Esta interface não suporta upload multipart/binário, coloque o áudio em qualquer armazenamento de objetos acessível publicamente. |
| `description`           | string   | Não       | Descrição do timbre.                                                              |
| `cover_image`           | string   | Não       | URL HTTP(S) da imagem de capa.                                                   |
| `tags`                  | string[] | Não       | Tags de pesquisa da biblioteca pública, por exemplo, `["male","narration","zh"]`.       |
| `texts`                 | string[] | Não       | Texto de referência correspondente à amostra (para correção de pronúncia).               |
| `enhance_audio_quality` | boolean  | Não       | Se deve ou não melhorar a qualidade do áudio da amostra antes do treinamento.         |
| `generate_sample`       | boolean  | Não       | Se deve ou não gerar automaticamente uma amostra de áudio após a conclusão do treinamento. |

> Os campos são idênticos aos da interface anterior, consulte também a [documentação oficial do Fish](https://docs.fish.audio/resources/api-reference/model).

## Exemplo: Criar um timbre de voz clonado privado

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "Meu timbre clonado",
    "description": "Timbre em chinês clonado a partir de uma gravação de podcast",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Atenção: `voices` deve ser uma **string** (uma única URL de áudio), não um array. Se for passado como `["..."]`, a interface anterior irá rejeitar.

`_id` pode ser usado como o valor do campo `reference_id` na [API Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para realizar a síntese de voz com o timbre clonado:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Olá, esta é uma voz sintetizada usando o timbre clonado que acabei de criar.",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Requisitos da Amostra

Valores de experiência (consistentes com a interface anterior, consulte a [documentação oficial do Fish](https://docs.fish.audio/resources/api-reference/model)):

- A duração recomendada é de mais de 30 segundos e até 5 minutos para o melhor efeito; mais de 10 minutos traz benefícios marginais.
- Taxa de amostragem de 16 kHz ou mais, mono ou estéreo é aceitável.
- O conteúdo deve ser o mais limpo possível: sem música de fundo, eco ou ruído ambiental evidente; com o mesmo falante.
- Formatos recomendados: `mp3` / `wav`.

Se você não tiver certeza da qualidade da amostra, pode passar `enhance_audio_quality: true` para que a interface anterior faça a melhoria da qualidade do áudio primeiro.

## Instruções de Cobrança

Criar um modelo de timbre clonado (`POST /fish/model`) é gratuito e não gera custos; as interfaces de consulta de timbre ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query), [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) também não geram custos. Os custos são gerados apenas ao chamar a [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para sintetizar a voz.

## Tratamento de Erros

- `400 token_mismatched`: Parâmetros de solicitação ausentes ou inválidos (o mais comum é que `voices` não seja uma URL ou tenha sido passado como um array).
- `401 invalid_token`: Token de autenticação inexistente ou inválido.
- `429 too_many_requests`: Limite de taxa da conta atingido.
- `500 api_error`: Erro interno do servidor.

Exemplo de resposta de erro:
```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "vozes é obrigatório e deve ser uma URL HTTP(S) apontando para um arquivo de áudio"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusão

Chamar esta interface só precisa preparar uma URL de áudio de amostra acessível publicamente, colocá-la no campo `vozes` e você obterá o `_id`, depois forneça ao `reference_id` de `/fish/tts` e a "clonagem → síntese" estará completa. Um ponto comum de erro é que `vozes` deve ser uma string, não pode ser um array.
