Esta API é baseada na [API oficial de Modelos Fish Audio](https://docs.fish.audio/resources/api-reference/model) e é usada para **recuperar de forma paginada a biblioteca pública de vozes Fish ou as vozes clonadas na conta atual**. O endereço é `GET https://api.acedata.cloud/fish/model`.

> Para criar uma voz, consulte a [API Fish Model Create](https://platform.acedata.cloud/documents/fish-model); para consultar os detalhes de uma única voz por `_id`, consulte a [API Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get).

## Processo de solicitação

Para usar a API Fish Model, primeiro obtenha seu API Token no [Console Ace Data Cloud](https://platform.acedata.cloud/console/applications) e guarde-o para uso posterior.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não tiver feito login ou se registrado, será redirecionado automaticamente para a página de login para se registrar e fazer login; após a conclusão, você retornará automaticamente à página atual.

**Um único API Token pode chamar todos os serviços da plataforma, sem necessidade de solicitar um separadamente para cada serviço.** A primeira solicitação concederá créditos gratuitos, permitindo uma experiência gratuita; quando os créditos forem insuficientes, você poderá recarregar o saldo geral no [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentação completa: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Parâmetros de consulta

| Parâmetro               | Tipo      | Padrão  | Descrição                                              |
| ---------------- | ------- | --- | ----------------------------------------------- |
| `page_size`      | integer | 10  | Número de itens por página.                                           |
| `page_number`    | integer | 1   | Número da página, começando em 1.                                         |
| `title`          | string  | —   | Pesquisa aproximada por título.                                        |
| `tag`            | string  | —   | Filtra por uma única tag.                                        |
| `self`           | boolean | —   | Quando `true`, retorna apenas as vozes criadas e salvas pela conta de chamada atual através desta plataforma.                 |
| `author_id`      | string  | —   | Filtra pelo ID do autor da voz.                                    |
| `language`       | string  | —   | Filtra pelo idioma da voz, como `en`, `zh`, `es`.                       |
| `title_language` | string  | —   | Filtra pelo idioma do título na biblioteca pública de vozes.                                 |
| `sort_by`        | string  | —   | Campo de ordenação; quando `self=true`, suporta `created_at`, `task_count`. |

> A nomenclatura dos parâmetros é totalmente consistente com o upstream `GET https://api.fish.audio/model`; consulte a [documentação oficial do Fish](https://docs.fish.audio/resources/api-reference/model) para detalhes.

## Exemplo 1: Paginação padrão (por `page_size`)

```shell
  --data-urlencode 'page_size=2'
```

## Exemplo 2: Pesquisa aproximada por título (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Retorno (testado):

## Exemplo 3: Listar apenas as vozes criadas por você (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Exemplo de retorno:

```json

      "state": "trained",

          "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
        }
      ],
      "created_at": "2026-05-10T03:52:55.601000Z",
```

`self=true` lista as vozes criadas e salvas através desta plataforma pela conta efetivamente utilizada na chamada; vozes criadas pela mesma conta usando diferentes API Tokens também serão listadas juntas. Os resultados são paginados em ordem decrescente de tempo de criação, e `author_id` pode filtrar ainda mais o ID do autor dessas vozes. Este parâmetro filtra apenas a lista; as vozes continuam publicamente disponíveis.

`self=true` não oferece suporte a `title_language`; se precisar pesquisar por idioma do título, consulte a biblioteca pública de vozes.

## Exemplo 4: Filtrar por idioma + tag

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> A origem também retorna resultados para `tag` que não estejam no dicionário de tags, mas a correspondência é relativamente ampla; se o número de correspondências for 0, recomenda-se usar correspondência aproximada por `title`.

## Campos de resposta

Cada item em `items[]` é um objeto ModelEntity completo, campos comuns:

| Campo            | Tipo       | Descrição                                        |
| ------------- | -------- | ----------------------------------------- |
| `_id`         | string   | ID da voz, usado como valor de `reference_id` em `/fish/tts`. |
| `type`        | string   | Tipo de modelo, geralmente `tts`.                           |
| `title`       | string   | Nome da voz.                                     |
| `description` | string   | Descrição da voz.                                     |
| `state`       | string   | Status de treinamento: `trained` indica que está disponível.                      |
| `tags`        | string[] | Tags da biblioteca pública.                                    |
| `languages`   | string[] | Idiomas em que a voz se destaca.                                  |
| `visibility`  | string   | `public` ou `private`.                     |
| `samples`     | object[] | Amostras predefinidas (inclui link direto para `audio`).                       |
| `like_count`  | integer  | Número de curtidas na biblioteca pública.                                   |
| `task_count`  | integer  | Número de sínteses históricas.                                   |
| `author`      | object   | Informações do autor da voz: `_id` / `nickname` / `avatar`.     |
| `total`（nível superior）   | integer  | Número total de itens que atendem às condições.                                 |
| `has_more`    | boolean? | É um valor booleano quando `self=true`; a consulta à biblioteca pública de vozes pode ser `null`.      |

## Descrição de cobrança

Esta interface não é cobrada — consultar paginadamente a lista de vozes é uma operação gratuita. Criar vozes ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) também é gratuito; os custos são gerados apenas conforme o uso ao chamar [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para sintetizar fala.

## Tratamento de erros

- `400 token_mismatched`: parâmetros da solicitação ausentes ou inválidos.
- `401 invalid_token`: o token de autenticação não existe ou é inválido.
- `429 too_many_requests`: o limite de taxa da conta foi acionado.
- `500 api_error`: erro interno do servidor.

Exemplo de resposta de erro:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusão

Para selecionar vozes da biblioteca pública do Fish e fornecê-las ao `reference_id` de `/fish/tts`, primeiro use esta interface em conjunto com `title` / `tag` / `language` para pesquisar, localize o `_id` desejado e, em seguida, use [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) para obter amostras e ouvi-las. Para listar as vozes que você criou, basta passar `self=true`.
