Esta interface é baseada na [API Model do Fish Audio](https://docs.fish.audio/resources/api-reference/model) e é utilizada para **pesquisar em páginas a biblioteca pública de timbres do Fish ou os timbres clonados da conta atual**. O endereço é `GET https://api.acedata.cloud/fish/model`.

> Para criar timbres, consulte a [API Fish Model Create](https://platform.acedata.cloud/documents/fish-model); para consultar os detalhes de um único timbre por `_id`, consulte a [API Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get).

## Processo de Solicitação

Para usar a API Fish Model, primeiro acesse o [console da Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter seu Token API, que deve ser guardado para uso futuro.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, onde será convidado a se registrar e logar; após a conclusão, você será redirecionado de volta para a página atual.

**Um Token API é suficiente para acessar todos os serviços da plataforma, não sendo necessário solicitar um para cada serviço individualmente.** A primeira solicitação oferece um crédito gratuito, permitindo uma experiência sem custo; quando o crédito estiver baixo, você pode recarregar o saldo geral no [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentação completa: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Parâmetros de Consulta

| Parâmetro         | Tipo      | Padrão | Descrição                                   |
| ---------------- | -------- | ------ | ------------------------------------------- |
| `page_size`      | integer   | 10     | Número de itens por página.                 |
| `page_number`    | integer   | 1      | Número da página começando de 1.           |
| `title`          | string    | —      | Pesquisa difusa por título.                 |
| `tag`            | string    | —      | Filtra por um único tag.                    |
| `self`           | boolean   | —      | Quando `true`, retorna apenas os timbres criados pela conta atual, sem necessidade de condições adicionais. |
| `author_id`      | string    | —      | Filtra por `_id` do usuário upstream.       |
| `language`       | string    | —      | Filtra por idioma do timbre, como `en`, `zh`, `es`. |
| `title_language` | string    | —      | Filtra por idioma do título.                |
| `sort_by`        | string    | —      | Campo de ordenação, igual ao upstream, como `created_at`, `task_count`. |

> A nomenclatura dos parâmetros é idêntica à do `GET https://api.fish.audio/model`, consulte a [documentação oficial do Fish](https://docs.fish.audio/resources/api-reference/model).

## Exemplo 1: Paginação padrão (por `page_size`)

```shell

  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=2'
```

## Exemplo 2: Pesquisa difusa por título (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Retorno (testado):

## Exemplo 3: Listar apenas os timbres que você criou (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Retorno (testado, a conta atual possui apenas 1 timbre):

## Exemplo 4: Filtrar por idioma + tag
```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> O upstream também retornará resultados para `tag` que não estão no dicionário de tags, mas a correspondência é relativamente flexível; se o número de correspondências for 0, recomenda-se usar a correspondência difusa de `title`.

## Campos de Resposta

Cada item em `items[]` é um objeto ModelEntity completo, campos comuns:

| Campo          | Tipo     | Descrição                                           |
| ------------- | -------- | ------------------------------------------------- |
| `_id`         | string   | ID da voz, usado como valor de `reference_id` em `/fish/tts`.         |
| `type`        | string   | Tipo de modelo, geralmente `tts`.                                   |
| `title`       | string   | Nome da voz.                                             |
| `description` | string   | Descrição da voz.                                             |
| `state`       | string   | Estado de treinamento: `trained` significa disponível.                              |
| `tags`        | string[] | Tags da biblioteca pública.                                            |
| `languages`   | string[] | Idiomas em que a voz é especializada.                                          |
| `visibility`  | string   | `public` ou `private`.                             |
| `samples`     | object[] | Amostras pré-definidas (inclui link direto de `audio`).                               |
| `like_count`  | integer  | Número de curtidas na biblioteca pública.                                           |
| `task_count`  | integer  | Número de sínteses históricas.                                           |
| `author`      | object   | Informações do autor upstream: `_id` / `nickname` / `avatar`.             |
| `total` (nível superior)   | integer  | Número total de itens que atendem aos critérios.                                         |
| `has_more`    | boolean? | Indicação de paginação upstream, pode ser `null`. Recomenda-se calcular o total de páginas usando `total / page_size`. |

## Instruções de Cobrança

Esta interface não gera cobrança — a consulta de lista de vozes paginada é uma operação gratuita. A criação de vozes ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) também é gratuita, a cobrança ocorre apenas ao chamar [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para sintetizar voz com base no uso.

## Tratamento de Erros

- `400 token_mismatched`: Parâmetros de solicitação ausentes ou inválidos.
- `401 invalid_token`: Token de autenticação inexistente ou inválido.
- `429 too_many_requests`: Limite de taxa da conta acionado.
- `500 api_error`: Erro interno do servidor.

Exemplo de resposta de erro:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusão

Para selecionar uma voz da biblioteca pública Fish para alimentar o `reference_id` de `/fish/tts`, primeiro use esta interface em conjunto com `title` / `tag` / `language` para pesquisar, localize o `_id` alvo e, em seguida, use [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) para obter amostras para audição. Para listar as vozes que você criou, basta passar `self=true`.
