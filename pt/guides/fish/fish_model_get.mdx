Esta interface é baseada na [API Model oficial da Fish Audio](https://docs.fish.audio/resources/api-reference/model) e é utilizada para **consultar os detalhes completos de um único clone de voz pelo `_id`**. O endereço é `GET https://api.acedata.cloud/fish/model/{id}`.

> Para criar uma voz, consulte a [API Fish Model Create](https://platform.acedata.cloud/documents/fish-model); para pesquisa paginada, consulte a [API Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query).

## Processo de Solicitação

Para usar a API Fish Model, primeiro acesse o [console da Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter seu Token de API, que deve ser guardado para uso futuro.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, onde será convidado a se registrar e logar; após a conclusão, você será redirecionado de volta para a página atual.

**Um Token de API é suficiente para acessar todos os serviços da plataforma, não sendo necessário solicitar um para cada serviço individualmente.** A primeira solicitação oferece um crédito gratuito para que você possa experimentar; quando o crédito acabar, você pode recarregar o saldo geral no [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentação completa: [API Fish Model →](https://platform.acedata.cloud/services/fish)

## Parâmetros de Caminho

| Parâmetro | Obrigatório | Descrição                                                                                                                                                                                                |
| --------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`      | Sim         | O `_id` da voz (string hexadecimal de 32 bits). Pode ser retornado ao criar através do [Fish Model Create](https://platform.acedata.cloud/documents/fish-model) ou obtido através da [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query). |

Sem corpo de solicitação, sem parâmetros de consulta.

## Exemplo: Obter detalhes completos de uma voz pública em espanhol

  -H 'authorization: Bearer {token}'

O `_id` obtido pode ser diretamente fornecido ao `reference_id` da [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para sintetizar a voz correspondente:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

## Diferenças em relação à interface de lista

| Campo                                               | `GET /fish/model` (lista) | `GET /fish/model/{id}` (detalhes) |
| -------------------------------------------------- | -------------------------- | --------------------------------- |
| `samples[].audio`                                  | URL de cache R2 de curto prazo | Link direto R2 assinado (inclui assinatura de consulta) |
| `unliked` / `liked` / `marked` / `dmca_taken_down` | Também existem             | Também existem                    |
| `default_text` / `lock_visibility`                 | Também existem             | Também existem                    |

Se você só deseja ouvir, o `samples[].audio` na interface de lista já é suficiente; para links de download mais estáveis, recomenda-se usar esta interface.

## Campos de Resposta (trecho)

| Campo            | Tipo     | Descrição                                      |
| ---------------- | -------- | ---------------------------------------------- |
| `_id`            | string   | ID da voz (usado como `reference_id` em `/fish/tts`). |
| `type`           | string   | Tipo de modelo, geralmente `tts`.             |
| `title`          | string   | Nome da voz.                                  |
| `description`    | string   | Descrição longa.                              |
| `state`          | string   | Estado de treinamento: `trained` significa disponível, `training` significa que ainda está em treinamento. |
| `tags`           | string[] | Tags da biblioteca pública.                   |
| `samples`        | object[] | Amostras pré-definidas, contendo `title`, `text`, `task_id`, `audio` link direto. |
| `languages`      | string[] | Códigos de idiomas em que a voz é proficiente. |
| `visibility`     | string   | `public` ou `private`.                        |
| `like_count`     | integer  | Número de curtidas na biblioteca pública.     |
| `task_count`     | integer  | Número de sínteses históricas (pode ser usado como referência para popularidade). |
| `author`         | object   | Informações do autor: `_id` / `nickname` / `avatar`. |
| `created_at`     | string   | Data de criação em ISO 8601.                 |
| `updated_at`     | string   | Última data de atualização em ISO 8601.      |

## Informações de Cobrança

Esta interface não gera cobrança — consultar os detalhes de uma única voz pelo ID é uma operação gratuita. Criar uma voz ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) também é gratuito, e a cobrança ocorre apenas ao chamar a [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) para sintetizar a voz, com base no uso.

## Tratamento de Erros
- `400 token_mismatched`: O `id` no caminho não está em um formato válido, ou o upstream retorna "Model not found".
- `401 invalid_token`: O token de autenticação não existe ou é inválido.
- `404 not_found`: O `_id` especificado não é visível no upstream do Fish (o timbre foi excluído, é privado ou pertence a outra conta).
- `429 too_many_requests`: Limite de taxa da conta acionado.
- `500 api_error`: Erro interno do servidor.

Quando uma solicitação é feita para um ID inexistente, o upstream retorna diretamente `400 Model not found` (testado na prática):

```shell
curl 'https://api.acedata.cloud/fish/model/test123' \
  -H 'authorization: Bearer {token}'
```

Retorno:

```json
{ "status": 400, "message": "Model not found" }
```

Exemplo de resposta de erro:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusão

Ao saber o `_id` do timbre, use diretamente esta interface para obter o ModelEntity completo. Os usos mais comuns são: (1) ouvir `samples[].audio`, (2) fornecer o `_id` para o `reference_id` de `/fish/tts` para completar a síntese. Se você tiver apenas o título ou as tags, primeiro use [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) para pesquisar.
