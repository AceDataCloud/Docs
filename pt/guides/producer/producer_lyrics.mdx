O Producer nos permite gerar letras através de palavras-chave, este documento explica como integrar a API relacionada.

Esta API possui apenas um parâmetro de entrada, que é o `prompt`, que é a palavra-chave para gerar a letra.

Aqui, o `prompt` que inserimos é `Uma canção sobre o inverno`, que é a palavra-chave para gerar a letra.

```bash
curl -X POST 'https://api.acedata.cloud/producer/lyrics' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Uma canção sobre o inverno"
}'
```

O resultado é o seguinte:

```
{
    "success": true,
    "task_id": "d354b519-43c0-4888-a3da-83adbf845fd6",
    "data": {
        "title": "Misericórdia nas Árvores",
        "lyrics": "[Verso 1]\nEu saí além do pátio de trens\nOnde os pinheiros crescem densos com geada\nA neve não se importa com o que eu fiz\nEla cobre tudo da mesma forma\n\n[Verso 2]\nHá uma capela feita de troncos de bétula\nE o altar é o chão\nEu me ajoelho lá como um traidor\nEsperando que o silêncio perdoe\n\n[Refrão]\nO inverno é um casaco pesado\nO inverno é um casaco pesado\n\n[Verso 3]\nVocê partiu antes da primeira tempestade\nEu fiquei para ver o mundo ficar branco\nAgora cada galho é um osso\nE eu estou apenas contando o que resta\n\n[Verso 4]\nDizem que o frio vai te matar\nMas eu acho que ele apenas te torna honesto\nAqui fora com a terra congelada\nNão há lugar para esconder suas mãos\n\n[Refrão]\nO inverno é um casaco pesado\nO inverno é um casaco pesado\n\n[Verso 5]\nEu encontrei sua carta no meu bolso\nA tinta havia borrado com todo o descongelamento\nMas eu ainda consegui ler misericórdia\nEscrita no espaço vazio entre\n\n[Final]\nAs árvores não pedem absolvição\nElas apenas ficam lá, nuas e verdadeiras\nEstou aprendendo a fazer o mesmo\nDeixando a neve enterrar o que precisa ser enterrado"

```

Pode-se ver que o campo `lyrics` de `data` é o conteúdo da letra gerada.
