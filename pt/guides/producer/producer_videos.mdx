---
title: "Instruções de integração da API de download de vídeo do Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

O Producer nos permite baixar vídeos relacionados a músicas. Este documento explica como integrar a API relacionada.

Esta API possui apenas um parâmetro de entrada, que é o `audio_id`, que é o ID único da música.

Aqui, o `audio_id` que inserimos é `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, que é um ID de música gerado pelo Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

O resultado é o seguinte:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://storage.googleapis.com/corpusant-app-public/song-videos/a54609c6-13e2-4176-be0f-4d7eebc68e1f:5178f294b214798f7d38b810ac289be75306659be24af88900a633efce334012.mp4"
  }
}
```

Pode-se ver que o campo `video_url` em `data` é o link para o vídeo a ser baixado.
