---
title: "Instruções de integração da API de upload de áudio de referência do Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

O Producer nos permite fazer upload de áudio de referência para criação secundária, este documento explica o método de integração da API relacionada.

Esta API possui apenas um parâmetro de entrada, que é `audio_url`, ele é um endereço CDN publicamente acessível e suporta o sufixo mp3.

Aqui, o `audio_url` que inserimos é `https://cdn.acedata.cloud/suno_demo.mp3`, que é um endereço CDN publicamente acessível.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

O resultado é o seguinte:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Soft female vocals, bright and cheerful]\n\n[Verse 1]\n阳光洒在海边\n浪花笑得灿烂\n你和我在沙滩\n钟表停止转\n冰淇淋在融化\n手牵手去散步\n风儿轻轻吹过\n心跳不停跳\n\n[Chorus]\n夏天夏天\n时间停在这一天\n笑声回荡\n蔚蓝天空在身旁",
    "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
  }
}
```

Como pode ser visto, o campo `audio_id` de `data` é o ID da música após o upload.

Depois de obter o ID da música, podemos usar a [API de Geração de Áudios do Producer](https://platform.acedata.cloud/documents/producer-audios-integration) para realizar a geração personalizada de músicas. Por exemplo, ao passar `upload_extend` em `action` e, ao mesmo tempo, passar o ID da música retornado em `audio_id`, é possível gerar uma nova música com base no áudio de referência.
