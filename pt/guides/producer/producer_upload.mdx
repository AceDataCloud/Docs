---
title: "Instruções de Integração da API de Upload de Áudio de Referência do Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

O Producer nos permite fazer upload de áudio de referência para recriação. Este documento explica como integrar a API relacionada.

Esta API possui apenas um parâmetro de entrada, que é `audio_url`, que é um endereço CDN acessível publicamente, suportando a extensão mp3.

Aqui, o `audio_url` que inserimos é `https://cdn.acedata.cloud/suno_demo.mp3`, que é um endereço CDN acessível publicamente.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

O resultado é o seguinte:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Vocais femininos suaves, brilhantes e alegres]\n\n[Verso 1]\nO sol brilha na praia\nAs ondas sorriem radiante\nVocê e eu na areia\nO relógio para de girar\nO sorvete está derretendo\nDe mãos dadas vamos passear\nO vento sopra suavemente\nO coração bate sem parar\n\n[Refrão]\nVerão, verão\nO tempo para neste dia\nRisos ecoam\nO céu azul ao nosso lado",
    "audio_url": "https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"
  }
}
```

Pode-se ver que o campo `audio_id` de `data` é o ID da música após o upload.

Com o ID da música, podemos usar a [API de Geração de Áudios do Producer](https://platform.acedata.cloud/documents/producer-audios-integration) para gerar músicas personalizadas, por exemplo, passando `action` como `upload_extend` e `audio_id` como o ID da música retornado, podemos gerar uma nova música com base no áudio de referência.
