A principal função da API de Tarefas do Produtor é consultar o status de execução de uma tarefa através do ID da tarefa gerado pela API de Geração de Áudios do Produtor.

Este documento irá detalhar as instruções de integração da API de Tarefas do Produtor, ajudando você a integrar facilmente e aproveitar ao máximo o poderoso recurso dessa API. Com a API de Tarefas do Produtor, você pode consultar facilmente o status de execução das tarefas da API de Geração de Áudios do Produtor.

## Processo de Solicitação

Para usar a API de Tarefas do Produtor, você precisa primeiro acessar a página de solicitação [API de Geração de Áudios do Produtor](https://platform.acedata.cloud/documents/producer-audios) para solicitar o serviço correspondente e, em seguida, copiar o ID da tarefa da API de Geração de Áudios do Produtor, como mostrado na imagem:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" class="m-auto"></p>

Por fim, acesse a página da API de Tarefas [API de Tarefas do Produtor](https://platform.acedata.cloud/documents/622626b1-30a7-4799-a772-4946e1df3ac0) para solicitar o serviço correspondente. Após acessar a página, clique no botão "Adquirir", como mostrado na imagem:

![Página de Solicitação](https://cdn.acedata.cloud/rci31i.png)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a [página de login](https://platform.acedata.cloud), convidando-o a se registrar e fazer login. Após o registro e login, você será redirecionado automaticamente de volta para a página atual.

Na primeira solicitação, haverá um crédito gratuito disponível, permitindo que você use a API gratuitamente.

## Exemplo de Solicitação

A API de Tarefas do Produtor pode ser usada para consultar os resultados da API de Geração de Áudios do Produtor. Para saber como usar a API de Geração de Áudios do Produtor, consulte o documento [API de Geração de Áudios do Produtor](https://platform.acedata.cloud/documents/producer-audios-integration).

Usaremos um exemplo de ID de tarefa retornado pelo serviço da API de Geração de Áudios do Produtor para demonstrar como usar essa API. Suponha que temos um ID de tarefa: 1a6ac2ad-10f2-4e2b-b500-66ec27fe82ad, a seguir, demonstraremos como passar um ID de tarefa.

### Configurando Cabeçalhos e Corpo da Solicitação

**Cabeçalhos da Solicitação** incluem:

- `accept`: especifica que a resposta deve ser no formato JSON, preenchido como `application/json`.
- `authorization`: chave para chamar a API, que pode ser selecionada diretamente após a solicitação.

**Corpo da Solicitação** inclui:

- `id`: ID da tarefa enviada.
- `action`: forma de operação na tarefa.

Configurar conforme mostrado na imagem abaixo:

<p><img src="https://cdn.acedata.cloud/bfe4ww.png" width="500" class="m-auto"></p>

### Exemplo de Código

Pode-se notar que, no lado direito da página, já foram gerados automaticamente códigos em várias linguagens, como mostrado na imagem:

Alguns exemplos de código são os seguintes:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/producer/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "1a6ac2ad-10f2-4e2b-b500-66ec27fe82ad",
  "action": "retrieve"
}'
```

## Tratamento de Erros

Ao chamar a API, se encontrar um erro, a API retornará o código de erro e a mensagem correspondente. Por exemplo:

- `400 token_mismatched`: Solicitação inválida, possivelmente devido a parâmetros ausentes ou inválidos.
- `400 api_not_implemented`: Solicitação inválida, possivelmente devido a parâmetros ausentes ou inválidos.
- `401 invalid_token`: Não autorizado, token de autorização inválido ou ausente.
- `429 too_many_requests`: Muitas solicitações, você excedeu o limite de taxa.
- `500 api_error`: Erro interno do servidor, algo deu errado no servidor.

### Exemplo de Resposta de Erro

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
