---
title: "Instruções de integração da API de download de WAV do Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

O Producer nos permite baixar arquivos WAV relacionados a músicas; este documento explica o método de integração da API relacionada.

Esta API possui apenas um parâmetro de entrada, que é `audio_id`, o ID exclusivo da música.

Aqui, o `audio_id` que inserimos é `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, que é um ID de música gerada pelo Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/wav' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

O resultado é o seguinte:

```
{
  "success": true,
  "task_id": "44963173-b6c5-463c-915f-96730d14ec63",
  "trace_id": "f75d6a27-54bc-49fd-a40e-6d4cd0427764",
  "data": [
    {
      "title": "Woke up with the sun in my eyes",
      "file_url": "https://cdn.acedata.cloud/assets/examples/fish/64adc04b-c196-4a0f-9070-222ba101ce6c-fc50de38c165.wav"
    }
  ]
}
```

Como pode ser visto, o campo `file_url` de `data` é o link para download do WAV.
