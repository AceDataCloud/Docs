---
title: "Instruções de Integração da API de Download de WAV do Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

O Producer nos permite baixar arquivos WAV relacionados a músicas. Este documento explica como integrar a API relacionada.

Esta API possui apenas um parâmetro de entrada, que é o `audio_id`, que é o ID único da música.

Aqui, o `audio_id` que inserimos é `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, que é um ID de música gerado pelo Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/wav' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

O resultado é o seguinte:

```
{
  "success": true,
  "task_id": "44963173-b6c5-463c-915f-96730d14ec63",
  "trace_id": "f75d6a27-54bc-49fd-a40e-6d4cd0427764",
  "data": [
    {
      "title": "Acordei com o sol nos meus olhos",
      "file_url": "https://cdn.ttapi.io/other/2025-12-30/a1508051-a6b8-4867-8cbb-32273a99c2ae.wav"
    }
  ]
}
```

Pode-se ver que o campo `file_url` de `data` é o link para download do WAV.
