Maestro é uma interface de produção de vídeos **nativa para Agent**: você usa uma frase em linguagem natural no `prompt` para descrever o vídeo desejado (opcionalmente, anexa imagens / vídeos / áudios de referência com `file_urls`), e um «diretor de IA» sem interface gráfica concluirá automaticamente a seleção do tema, a escrita do roteiro, a geração de imagens, dublagem, trilha sonora, composição e renderização, produzindo por fim um vídeo final com legendas e enviando-o para a CDN.

Este documento apresentará detalhadamente o guia de integração da API de geração de vídeos Maestro, ajudando você a integrar rapidamente e aproveitar plenamente os recursos desta API.

Esta é uma interface de **tarefas assíncronas**: após o envio, ela retornará imediatamente o `task_id`; em seguida, obtenha o resultado por sondagem através da [API de consulta de tarefas Maestro](/pt/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (a sondagem é gratuita e não será cobrada). Para continuar iterando sobre um vídeo existente, você pode usar `action: remix` / `edit` / `extend` em conjunto com `ref_task_id`.

## Processo de solicitação

Para usar a API de geração de vídeos Maestro, primeiro acesse o [Console Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter seu API Token e guarde-o para uso posterior.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não tiver feito login ou se registrado, será automaticamente redirecionado para a página de login, onde será convidado a se registrar e fazer login; após a conclusão, retornará automaticamente à página atual.

**Um único API Token permite chamar todos os serviços da plataforma, sem necessidade de solicitar um separadamente para cada serviço.** A primeira solicitação concede créditos gratuitos para experimentar gratuitamente; quando os créditos forem insuficientes, você poderá recarregar o saldo geral no [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentação completa: [API de geração de vídeos Maestro →](https://platform.acedata.cloud/documents/maestro-videos)

## Uso básico

`POST https://api.acedata.cloud/maestro/videos`

O uso mais básico exige apenas fornecer um `prompt` em linguagem natural, e o diretor de IA decidirá automaticamente o roteiro, as imagens, a dublagem e a edição. Aqui, vamos primeiro conhecer os cabeçalhos e o corpo da solicitação que precisam ser configurados.

Os **Request Headers** incluem:

- `accept`: qual formato de resposta você deseja receber; aqui, preencha com `application/json`, ou seja, o formato JSON.
- `authorization`: a chave para chamar a API, que pode ser diretamente selecionada no menu suspenso após a solicitação.
- `content-type`: o formato do corpo da solicitação; aqui, preencha com `application/json`.

O **Request Body** inclui principalmente:

- `prompt`: descreva em linguagem natural o vídeo a ser criado (tema, o que mostrar, estilo, público).
- `langs`: matriz de idiomas do vídeo final; transmita apenas um por vez, como `["zh-cn"]`; o padrão é `["zh-cn"]`.
- `aspect`: proporção da imagem, `9:16` (padrão) / `16:9` / `1:1`.
- `duration`: duração desejada (segundos), o padrão é 30.

Todos os campos do corpo da solicitação são mostrados na tabela abaixo:

| Campo            | Tipo       | Obrigatório  | Descrição                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Sim   | Descreva em linguagem natural o vídeo a ser criado (tema, o que mostrar, estilo, público). O roteiro, as imagens, a dublagem e a edição são todos decididos pela IA                                                                                                                                                                             |
| `action`      | string   | Não   | `generate` (padrão, gera um novo vídeo) / `remix` / `edit` / `extend` (itera sobre um vídeo existente, requer uso com `ref_task_id`)                                                                                                                                                |
| `ref_task_id` | string   | Não   | Obrigatório quando `action` for remix / edit / extend: o `task_id` da tarefa histórica usada como ponto de partida                                                                                                                                                                   |
| `file_urls`   | string[] | Não   | Mídias de referência (URLs de imagem / vídeo / áudio), por exemplo, a imagem do produto, o logo que aparecerão no vídeo, ou o clipe de material ao qual adicionar legendas                                                                                                                                                                             |
| `langs`       | string[] | Não   | Idioma do vídeo final; só é possível transmitir um por vez, como `["zh-cn"]`; o padrão é `["zh-cn"]`                                                                                                                                                                                    |
| `aspect`      | string   | Não   | `9:16` (padrão) / `16:9` / `1:1`, saída unificada em 1080p/30fps                                                                                                                                                                                  |
| `duration`    | int      | Não   | Duração desejada (segundos), o padrão é 30, suporta **5–300 segundos**. A cobrança é feita conforme a duração real do vídeo final, mas não excederá a duração solicitada                                                                                                                                                                             |
| `scenario`    | string   | Não   | Tipo de vídeo: `auto` / `narrated` / `captions` / `avatar` / `drama`. `captions` requer o vídeo de origem, e `avatar` requer um retrato                                                                                                                                    |
| `style`       | string   | Não   | Predefinições de estilo visual: `auto` (padrão) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`; também aceita texto livre como sugestão suave. É ortogonal a `scenario` e não altera o roteamento |
| `voice`       | string   | Não   | Timbre da narração (independente do idioma, universal entre idiomas): `auto` (padrão) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`                                    |

A seguir, demonstraremos com um exemplo específico. Suponha que desejamos gerar um vídeo curto em chinês, vertical, de 20 segundos, de divulgação científica; o código CURL correspondente é o seguinte:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

O código Python correspondente é o seguinte:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Clique para executar e você verá que obterá imediatamente um resultado, como segue:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

A introdução dos campos do resultado retornado é a seguinte:
- `success`: se esta tarefa foi enviada com sucesso.
- `task_id`: o ID desta tarefa de geração de vídeo, use-o posteriormente para consultar os resultados na [API de consulta de tarefas Maestro](/pt/guides/maestro/maestro_tasks).
- `trace_id`: o ID de rastreamento desta solicitação, que pode ser fornecido ao suporte técnico para localização em caso de problemas.

Como a produção de vídeos leva bastante tempo, a interface **retorna imediatamente o `task_id`** aqui e não espera a conclusão da renderização do vídeo. Em seguida, é necessário usar o `task_id` para consultar os resultados; consulte a seção «Obter resultados» para mais detalhes.

## Especificar tipo e estilo de vídeo (scenario / style)

Quando `scenario` não é enviado, a IA determina automaticamente (equivalente a `auto`); se quiser fixar o vídeo em determinado tipo, envie-o explicitamente. Por exemplo, para criar um **drama curto em formato vertical**, é possível especificar o seguinte:

- `scenario`: tipo de vídeo, definido aqui como `drama` (drama curto com personagens + diálogos).
- `style`: estilo visual, definido aqui como `cinematic` (qualidade cinematográfica).

O código CURL de exemplo preenchido é o seguinte:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Combinações comuns:

- Curta narrado: `scenario: "narrated"`.
- Legendas automáticas: `scenario: "captions"`, é necessário usar `file_urls` para enviar o vídeo de origem.
- Avatar digital / apresentação falada: `scenario: "avatar"`, é necessário usar `file_urls` para enviar uma imagem de retrato.
- Drama curto: `scenario: "drama"` (personagens + diálogos).
- `style` é uma predefinição de estilo visual (como `modern` / `neon` / `luxury`), não altera o tipo, apenas afeta a aparência.
- `voice` é usado para especificar o timbre da narração (como `warm-female` / `deep-male`), independentemente do idioma e aplicável entre idiomas.

O resultado retornado é consistente com o «Uso básico», e também retorna imediatamente o `task_id`.

## Idioma do vídeo final

Uma tarefa entrega apenas um vídeo final em um único idioma. `langs` pode conter apenas um código de idioma, como `["zh-cn"]` ou `["en"]`; enviar vários idiomas retornará 400. Se precisar de vídeos em idiomas diferentes, crie tarefas separadamente. A seleção de idioma não altera o preço por segundo.

## Iterar sobre um vídeo existente (remix / edit / extend)

Envie `action` e o `ref_task_id` da tarefa anterior para fazer modificações incrementais com base no projeto original (como «alterar o título da cena 2», «trocar a narração» ou «escurecer o conjunto»). Pequenas alterações são rápidas, enquanto grandes alterações refazem o vídeo:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: recria com base na estrutura do vídeo original (mantém o tema e ajusta a apresentação).
- `edit`: faz refinamentos em partes especificadas (como trocar o título, a narração ou ajustar as cores).
- `extend`: estende o conteúdo com base no vídeo original.

O resultado retornado também retorna imediatamente um novo `task_id`; use-o para consultar e obter o vídeo final após a iteração.

## Obter resultados

Como a produção de vídeos leva bastante tempo, esta interface retorna imediatamente o `task_id` após o envio; é necessário usá-lo para consultar os resultados na [API de consulta de tarefas Maestro](/pt/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Quando a tarefa for concluída, será retornada uma informação de vídeo final (localizada no array `variants`). O `status` passará por `pending → planning → producing → succeeded` (ou `failed`), e **as consultas são gratuitas e não consomem créditos**. Para o formato completo da resposta e a consulta da lista de histórico, consulte as [instruções de integração da API de consulta de tarefas Maestro](/pt/guides/maestro/maestro_tasks).

## Cobrança

**Após o sucesso da tarefa, a cobrança é feita com base na duração real do vídeo final entregue; em caso de falha, não há cobrança.** A duração cobrada é calculada em segundos inteiros e não excede a duração solicitada; quando não for possível ler a duração do vídeo final, é usada como alternativa a duração solicitada. O envio da tarefa em si não é cobrado separadamente, e as consultas em `/maestro/tasks` são gratuitas.

```
Créditos = segundos efetivamente cobrados × 0.7
```

Todos os cenários, ações e idiomas usam o mesmo preço, sem multiplicadores por cenário ou cobranças adicionais por idioma. Cada tarefa entrega apenas um vídeo final em um único idioma. A duração-alvo solicitada suporta de 5 a 300 segundos, com saída unificada em 1080p / 30fps.

| Duração efetivamente cobrada | Créditos |
| ------------------- | --: |
| 30 segundos         |  21 |
| 60 segundos         |  42 |
| 120 segundos        |  84 |
| 300 segundos        | 210 |
| Consulta em `/maestro/tasks` | Grátis |

## Tratamento de erros

Ao chamar a API, se ocorrer um erro, a API retornará o código e a mensagem de erro correspondentes. Por exemplo:

- `400 invalid_request`: Solicitação inválida, possivelmente devido a um `prompt` ausente ou parâmetros inválidos.
- `401 invalid_token`: Não autorizado, token de autorização inválido ou ausente.
- `403 forbidden`: Proibido, saldo ou acesso insuficiente.
- `429 too_many_requests`: Solicitações em excesso, você excedeu o limite de taxa.
- `500 api_error`: Erro interno do servidor, algo deu errado no servidor.

### Exemplo de resposta de erro

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
