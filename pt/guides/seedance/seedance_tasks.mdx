A principal função da API SeeDance Tasks é consultar o status de execução de uma tarefa através do ID da tarefa gerado pela API SeeDance Video Generation.

Este documento irá detalhar as instruções de integração da API SeeDance Tasks, ajudando você a integrar facilmente e aproveitar ao máximo as poderosas funcionalidades dessa API. Com a API SeeDance Tasks, você pode consultar facilmente o status de execução das tarefas da API SeeDance Video Generation.

## Processo de Solicitação

Para usar a API SeeDance Tasks, você precisa primeiro ir à página de solicitação [SeeDance Video Generation API](https://platform.acedata.cloud/documents/seedance-videos) para solicitar o serviço correspondente e, em seguida, copiar o ID da tarefa da API SeeDance Video Generation, como mostrado na imagem:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Por fim, acesse a página da API Tasks [SeeDance Tasks API](https://platform.acedata.cloud/documents/seedance-tasks) para solicitar o serviço correspondente. Após entrar na página, clique no botão "Acquire", como mostrado na imagem:

![Página de Solicitação](https://cdn.acedata.cloud/rci31i.png)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a [página de login](https://platform.acedata.cloud), convidando você a se registrar e fazer login. Após o registro e login, você será redirecionado automaticamente de volta para a página atual.

Na primeira solicitação, haverá um crédito gratuito disponível, permitindo que você use essa API gratuitamente.

## Exemplo de Solicitação

A API SeeDance Tasks pode ser usada para consultar os resultados da API SeeDance Video Generation. Para saber como usar a API SeeDance Video Generation, consulte a documentação [SeeDance Video Generation API](https://platform.acedata.cloud/documents/seedance-videos-integration).

### Configurando Cabeçalhos e Corpo da Solicitação

**Request Headers** incluem:

- `accept`: especifica que a resposta deve ser no formato JSON, preenchido como `application/json`.
- `authorization`: a chave para chamar a API, que pode ser selecionada diretamente após a solicitação.

**Request Body** inclui:

- `id`: o ID da tarefa enviada.
- `action`: a forma de operação na tarefa.

Configuração conforme mostrado na imagem abaixo:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/seedance/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "a6e0d456-189b-4c78-9232-2fe72166ab39",
  "action": "retrieve"
}'
```

## Tratamento de Erros

Ao chamar a API, se ocorrer um erro, a API retornará o código de erro e a mensagem correspondente. Por exemplo:

- `400 token_mismatched`: Solicitação inválida, possivelmente devido a parâmetros ausentes ou inválidos.
- `400 api_not_implemented`: Solicitação inválida, possivelmente devido a parâmetros ausentes ou inválidos.
- `401 invalid_token`: Não autorizado, token de autorização inválido ou ausente.
- `429 too_many_requests`: Muitas solicitações, você excedeu o limite de taxa.
- `500 api_error`: Erro interno do servidor, algo deu errado no servidor.

### Exemplo de Resposta de Erro

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
