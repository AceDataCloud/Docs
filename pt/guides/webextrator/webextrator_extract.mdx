`POST https://api.acedata.cloud/webextrator/extract`

Realiza extração de conteúdo com base em `/webextrator/render`. Além de todos os parâmetros da interface render, suporta adicionalmente:

| Campo | Tipo | Obrigatório | Padrão | Descrição |
|-------|------|:-----------:|--------|-----------|
| `expected_type` | string | ❌ | `markdown` | Produto esperado da extração: `markdown` / `article` / `text` / `links` / `structured` |
| `enable_llm` | boolean | ❌ | false | Ativa pós-processamento LLM (adequado para `article` / `structured`) |
| `instruction` | string | ❌ | - | Instrução de extração para LLM, por exemplo, "extrair título do produto, preço, especificações" |

## Resposta síncrona

```json
{
  "success": true,
  "task_id": "550e8400-...",
  "trace_id": "550e8400-...",
  "started_at": "2026-05-02T10:30:00.123Z",
  "finished_at": "2026-05-02T10:30:08.789Z",
  "elapsed": 8.666,
  "data": {
    "kind": "extract",
    "expected_type": "article",
    "url": "https://example.com/post/1",
    "title": "Exemplo de Artigo",
    "author": "Zhang San",
    "published_at": "2026-05-01",
    "content": "# Exemplo de Artigo\n\nCorpo do texto ...",
    "summary": "Este artigo apresenta ..."
  }
}
```

O modo assíncrono, códigos de erro e regras de cobrança são idênticos a `/webextrator/render`.

## Exemplo: Extração do corpo do artigo (com LLM ativado)

```bash
curl -X POST https://api.acedata.cloud/webextrator/extract \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/news/1",
    "expected_type": "article",
    "enable_llm": true
  }'
```

## Exemplo: Assíncrono + extração estruturada personalizada

```bash
curl -X POST https://api.acedata.cloud/webextrator/extract \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://shop.example.com/item/123",
    "expected_type": "structured",
    "enable_llm": true,
    "instruction": "extrair título do produto, preço, estoque, URLs de 3 imagens principais",
    "callback_url": "https://your-domain.com/wbx-callback"
  }'
```
