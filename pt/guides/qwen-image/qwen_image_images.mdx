---
title: "API de Geração e Edição de Imagens Qwen"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` conclui a geração de imagens a partir de texto e a edição com 1–3 imagens de referência por meio da mesma interface, com suporte a `qwen-image-3.0` e `qwen-image-3.0-pro`.

## Seleção de modelo

| Modelo                   | Cenários adequados       | Preço padrão oficial                   |
| -------------------- | ---------- | ----------------------- |
| `qwen-image-3.0`     | Criação em lote, iteração rápida  | Saída $0.030/imagem             |
| `qwen-image-3.0-pro` | Layout complexo, resultado final de alta precisão | 1K $0.040/imagem; 2K $0.075/imagem |

As imagens de referência são cobradas de acordo com a quantidade real de entradas, ao preço padrão oficial de $0.003/imagem.

## Geração síncrona

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "A simple red circle centered on a clean white background.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

A resposta bem-sucedida inclui o endereço permanente da imagem no CDN, o usage real e o custo desta vez:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Edição com imagens de referência

Adicione `image_urls`, com suporte para 1–3 imagens publicamente acessíveis:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "保留主体，将背景改成暖色电影海报风格",
  "image_urls": ["https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` é usado apenas para geração de imagens a partir de texto. O intervalo de `n` é de 1–6; a proporção entre largura e altura deve estar entre 1:8 e 8:1.

## Tarefas assíncronas

Após definir `async: true`, a interface retorna imediatamente `task_id`. Use `/qwen-image/tasks` para consultar o estado final, ou forneça `callback_url` para receber a notificação de conclusão. A geração é cobrada apenas uma vez, e a consulta de tarefas não gera cobranças repetidas.
