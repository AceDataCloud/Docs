---
title: "Guia de Integração da API de Imagens Qwen"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` suporta `qwen-image-3.0` e `qwen-image-3.0-pro` para geração de imagens a partir de texto e edição de 1 a 3 imagens de referência.

## Geração de Imagens a partir de Texto

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer SUA_CHAVE_API' \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen-image-3.0","prompt":"Um pôster tecnológico minimalista","size":"1024*1024","n":1}'
```

## Edição de Imagens

Adicione `image_urls` na mesma solicitação, suportando 1 a 3 imagens públicas:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "Manter o sujeito, mudar para um estilo de pôster quente**###**",
  "image_urls": ["https://cdn.acedata.cloud/r9vsv9.png"],
  "size": "2048*2048",
  "prompt_extend": true,
  "prompt_extend_mode": "direct",
  "enable_thinking": true,
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` suporta apenas geração de imagens a partir de texto. O valor de `n` varia de 1 a 6. O tamanho total da saída deve estar entre 512×512 e 2048×2048, com uma proporção de aspecto de 1:8 a 8:1.

## Chamada Assíncrona

Defina `async: true` para obter imediatamente `task_id`; também é possível passar `callback_url` para receber o resultado final. Após a conclusão, consulte através de `/qwen-image/tasks`.

A resposta de sucesso inclui `data[].image_url`, `usage`, `task_id` e `trace_id`. Os links das imagens serão armazenados no CDN da Ace Data Cloud sempre que possível. Exemplos de resposta real serão adicionados após a validação E2E em produção.
