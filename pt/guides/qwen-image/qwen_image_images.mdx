---
title: "API de Geração e Edição de Imagens Qwen"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` permite a criação de imagens a partir de texto e a edição de 1 a 3 imagens de referência através da mesma interface, suportando `qwen-image-3.0` e `qwen-image-3.0-pro`.

## Selecionar Modelo

| Modelo                   | Cenário Adequado       | Preço Padrão Oficial                   |
| -------------------- | ------------------ | ----------------------- |
| `qwen-image-3.0`     | Criação em massa, iteração rápida  | Saída $0.030/imagem             |
| `qwen-image-3.0-pro` | Layouts complexos, alta precisão | 1K $0.040/imagem; 2K $0.075/imagem |

As imagens de referência são cobradas com base na quantidade real de entradas, preço padrão oficial $0.003/imagem.

## Geração Sincronizada

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "Um círculo vermelho simples centrado em um fundo branco limpo.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

A resposta de sucesso inclui o endereço da imagem CDN permanente, uso real e custo desta vez:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Edição de Imagens de Referência

Adicione `image_urls`, suportando 1 a 3 imagens acessíveis publicamente:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "Manter o sujeito, mudar o fundo para um estilo de pôster quente**###**",
  "image_urls": ["https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` é usado apenas para geração de imagens a partir de texto. O valor de `n` varia de 1 a 6; a proporção largura-altura deve estar entre 1:8 e 8:1.

## Tarefas Assíncronas

Após definir `async: true`, a interface retorna imediatamente `task_id`. Use `/qwen-image/tasks` para consultar o estado final, ou forneça `callback_url` para receber notificações de conclusão. A geração é cobrada apenas uma vez, e a consulta de tarefas não gera cobranças duplicadas.
