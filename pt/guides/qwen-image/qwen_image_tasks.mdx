---
title: "Qwen Image Task Query API"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/tasks` é usado para consultar, consultar em massa ou excluir tarefas assíncronas do Qwen Image. Esta interface não gera consumo adicional de API.

## Consultar uma única tarefa

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Após a conclusão da tarefa, `response.data` contém o endereço da imagem CDN permanente, `response.usage` contém a quantidade real de entrada/saída, e `response.cost` é a informação de liquidação da tarefa gerada.

## Consulta em massa

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Retorna `{ "items": [...], "count": 2 }`. A consulta em lista também suporta filtragem por usuário, aplicativo e intervalo de tempo de criação.

## Excluir registros de tarefas

```json
{"action":"delete","id":"TASK_ID"}
```

A exclusão afeta apenas o histórico da tarefa, não excluirá os arquivos CDN já gerados.
