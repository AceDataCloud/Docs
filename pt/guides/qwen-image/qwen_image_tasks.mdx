---
title: "Guia de Integração da API de Tarefas de Imagem Qwen"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

Use `POST https://api.acedata.cloud/qwen-image/tasks` para consultar tarefas de geração de imagens assíncronas. Esta interface de consulta é gratuita.

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

A consulta em lote usa `action=retrieve_batch` e um array `ids`. Após a conclusão da tarefa, `response.data` contém o endereço permanente da imagem gerada e o uso real.
