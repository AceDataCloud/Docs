---
title: "Processamento de modelos Tripo"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Use `POST /tripo/models` para processar um modelo existente, informando a `action` desejada. Sincronização, processamento assíncrono, callback, associação à conta e consulta de tarefas seguem as mesmas regras da geração 3D.

| action  | Entrada                                                                | Resultado                                                                   |
| ------- | ----------------------------------------------------------------- | -------------------------------------------------------------------- |
| import  | `model_url`, arquivo GLB, GLTF, FBX, OBJ ou STL acessível publicamente via HTTPS, com tamanho máximo de 150 MiB | ID do modelo reutilizável e GLB; retorna `normalize_scale` e `normalize_translation` quando houver dados |
| texture | `model_id` ou `model_url`; opcionalmente, uma das três opções: `prompt`, `image_url` ou `image_urls` | Novo modelo, textura e pré-visualização opcional |
| convert | `model_id` ou `model_url`, e o `format` de destino | Arquivo do modelo convertido |

```json
{"action":"texture","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","prompt":"蓝色哑光表面","texture_quality":"standard","async":true}
```

A qualidade da textura aceita `fast`, `standard`, `detailed` e `extreme`. Ao usar um prompt de texto, é possível adicionar `style_image_url`; referências de imagem e de múltiplas vistas seguem o formato da interface de geração. Para mais parâmetros de textura, consulte o OpenAPI.

A conversão aceita `GLTF`, `FBX`, `USDZ`, `OBJ`, `STL` e `3MF`. O `format` do item retornado indica o formato efetivamente entregue; por exemplo, uma solicitação de GLTF pode entregar um GLB binário. OBJ é empacotado em ZIP com materiais e mapas de textura. Ao solicitar FBX, defina `texture_packaging: "zip"` para obter mapas de textura separados; o resultado empacotado indica `container: "ZIP"`. A ativação de configurações de malha ou textura diferentes das padrão pode ser cobrada como conversão avançada; consulte os preços do serviço para mais detalhes.

Use `data[0].id` para referenciar um modelo desta conta; a transformação de normalização do modelo importado satisfaz `normalized = original × normalize_scale + normalize_translation`. O endereço de download do modelo está em `data[0].model_url`.
