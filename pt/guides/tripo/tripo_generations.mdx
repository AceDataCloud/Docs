---
title: "Geração 3D com Tripo"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Chame `POST /tripo/generations` para criar um novo modelo, fornecendo texto, uma única imagem ou vários ângulos do mesmo objeto. Use o Token da AceDataCloud; por padrão, o resultado é retornado de forma síncrona. Ao fornecer `async: true` ou `callback_url`, primeiro são retornados HTTP 200 e `task_id`. O callback de conclusão tem a mesma estrutura JSON que o resultado síncrono.

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

`action` é `generate` por padrão. Escolha uma das três entradas: `prompt` (1–1024 caracteres), `image_url` ou `image_urls`. As imagens devem ser PNG/JPEG públicas via HTTPS, com no máximo 20 MiB. As múltiplas vistas são ordenadas como frontal, esquerda, traseira e direita; é obrigatório fornecer a vista frontal e pelo menos mais uma, e é possível usar null para pular vistas intermediárias.

`model` é `v3.1-20260211` por padrão, mas também é possível selecionar explicitamente `v3.0-20250812`, `v2.5-20250123`, `P1-20260311` ou `P2-20260801`. `texture` é `standard` por padrão; use `none` para geometria pura. Modelos e níveis de textura diferentes consomem cotas diferentes.

Baixe o GLB de `data[0].model_url`; `image_url` é uma prévia opcional. Guarde `data[0].id` para operações posteriores de textura, conversão ou esqueleto. Ao tentar novamente o mesmo envio, mantenha o mesmo `Idempotency-Key` e corpo da requisição.
