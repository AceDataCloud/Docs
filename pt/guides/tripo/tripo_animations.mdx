---
title: "Animação de personagens Tripo"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Chame `POST /tripo/animations` e use `action` para selecionar a verificação do esqueleto, a vinculação automática ou o redirecionamento de animação. Envie `async: true` para consultar `/tripo/tasks` periodicamente ou envie `callback_url` para receber o resultado final.

1. **Verificação**. Envie `{"action":"rig_check","model_id":"5db97adc-a877-4587-af16-bbf443aa55de"}`. O item de resultado contém o valor booleano `riggable` e o campo opcional `rig_type`. Uma verificação bem-sucedida com `riggable: false` indica que o modelo não é adequado para vinculação. Esta operação é gratuita.
2. **Vinculação**. Envie `{"action":"rig","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","model":"v3.0-20260909","rig_type":"biped","format":"GLB"}`. O resultado é um novo modelo com esqueleto; preserve seu `data[0].id`. A verificação e a vinculação também podem ler arquivos existentes por meio de `model_url`.
3. **Redirecionamento**. Use o ID do resultado da vinculação como `model_id`. Por exemplo, `{"action":"retarget","model_id":"96a66a1d-69d2-48f0-846b-bdf02ed9bcc4","animations":["preset:walk","preset:idle"],"format":"GLB","async":true}`. Selecione predefinições compatíveis com a versão e o tipo do esqueleto; envie `animation` para uma única animação ou `animations` para um lote de até cinco, com cobrança por número de ações. Uma solicitação em lote pode entregar um arquivo com várias faixas de animação.

Tanto a vinculação quanto o redirecionamento são compatíveis com GLB e FBX. Use `export_with_geometry` para controlar se o resultado do redirecionamento inclui geometria e `animate_in_place` para controlar se o deslocamento é mantido. O endereço de download do arquivo do modelo está em `data[0].model_url`.
