Aider conecta-se à API compatível com OpenAI através do prefixo de modelo `openai/` do LiteLLM.

## Configuração

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

Substitua `MODEL_ID` pelo modelo escolhido no assistente de configuração do Coding. Você também pode escrever as opções correspondentes em um arquivo local `.env` ou `.aider.conf.yml`, mas não envie o Token real.

## Verificação

```bash
aider --model openai/MODEL_ID --message "Responda apenas OK"
```

Na primeira vez que usar um modelo desconhecido, o Aider pode indicar que falta metadados do modelo; isso não é o mesmo que falha de autenticação. O erro 401 verifica o Token, o erro 404 verifica o ID do modelo e a URL base `/v1`.
