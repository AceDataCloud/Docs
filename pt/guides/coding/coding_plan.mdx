Os quatro níveis de planos possuem o mesmo escopo de acesso a modelos; os preços e os créditos promocionais prevalecem conforme a [página de preços do Coding Plan](https://platform.acedata.cloud/services/coding?tab=pricing). A Coding Application não recorre ao saldo geral.

## Catálogo dinâmico de modelos

Primeiro, você pode abrir o [catálogo de modelos](https://platform.acedata.cloud/models) para visualizar os nomes atuais dos modelos, por exemplo, `claude-opus-5`, `gpt-6-sol`. Quando precisar confirmar se as credenciais do Coding e o protocolo da API correspondem, use credenciais válidas do Coding Application para solicitar:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

O catálogo de modelos mudará continuamente; este documento não mantém uma quantidade fixa nem uma lista estática de modelos. O `id` de cada entrada na resposta é o **nome do modelo** que pode ser passado diretamente ao parâmetro `model` da API; por exemplo, `{"id":"deepseek-v4-pro"}` corresponde ao preenchimento de `deepseek-v4-pro`; ele não é o UUID de um serviço, API ou Application. `/v1/models` retorna o catálogo global de modelos e não será filtrado automaticamente pelas credenciais do Coding; antes da configuração, ainda é necessário confirmar de forma cruzada com o escopo da API das credenciais, o protocolo selecionado e o intervalo de compatibilidade do cliente.

## Solução de problemas comuns

- **Saldo insuficiente**: acesse o [console de Applications](https://platform.acedata.cloud/console/applications), encontre o Coding Application e renove ativamente.
- **O cliente ainda solicita o endereço original**: confirme que a configuração pertence ao mesmo usuário e espaço de trabalho que iniciou o cliente e reinicie o cliente após encerrá-lo completamente.
- **Nome do modelo indisponível**: solicite novamente `/v1/models` e verifique se o nome do modelo preenchido corresponde exatamente ao `id` no catálogo, ao escopo da API das credenciais e ao protocolo compatível com o cliente.
- **O Token não consegue chamar a interface**: confirme que as credenciais pertencem ao Coding Application e verifique `allowed_api_ids` e as permissões da API do aplicativo.
