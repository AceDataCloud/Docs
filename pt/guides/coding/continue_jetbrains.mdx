O plugin Continue do JetBrains utiliza o mesmo formato de modelo YAML que o VS Code; a configuração e o Secret devem pertencer ao usuário que executa o plugin do JetBrains.

## Configuração

Adicione ao arquivo de configuração YAML local do Continue:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Salve `ACEDATACLOUD_API_KEY` nos segredos do Continue. O cenário de Desenvolvimento Remoto deve ser configurado na máquina onde o plugin está realmente em execução.

## Verificação

Reinicie o IDE do JetBrains, abra a janela de ferramentas do Continue, selecione o modelo de Configuração Local e envie `Reply only OK`; em seguida, execute novamente a tarefa de arquivo somente leitura. Se ainda estiver usando o modelo antigo, reinicie o backend remoto e verifique a indentação do YAML.
