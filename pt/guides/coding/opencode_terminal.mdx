## 1. Obter a API Key

Abra a [lista de aplicações do Ace Data Cloud](https://platform.acedata.cloud/console/applications), entre em uma aplicação disponível e copie a API Key.

![Obter a API Key do Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar o OpenCode

```bash
curl -fsSL https://opencode.ai/install | bash
```

Também é possível usar npm:

```bash
npm install -g opencode-ai
```

## 3. Definir a API Key

```bash
export ACEDATACLOUD_API_KEY="你的 API Key"
```

Para que tenha efeito permanente, adicione esta linha a `~/.zshrc` ou `~/.bashrc` e reabra o terminal.

## 4. Configurar o Provider

Edite `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ace Data Cloud",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  }
}
```

Acesse o [catálogo de modelos](https://platform.acedata.cloud/models) para ver os nomes dos modelos (por exemplo, `claude-opus-5`, `gpt-6-sol`) e substitua todos os `MODEL_ID` pelo mesmo nome; para validação precisa, use o valor de `id` na resposta de `/v1/models` como referência. Esse valor é o nome do modelo usado pelo parâmetro `model` da API, não o UUID do serviço ou da API. O Ace Data Cloud usa Chat Completions aqui, portanto o adapter é `@ai-sdk/openai-compatible`.

## 5. Verificar e iniciar

```bash
opencode auth list
opencode models acedatacloud
opencode run --model acedatacloud/MODEL_ID "Reply only OK"
```

Em seguida, execute `opencode` no diretório do projeto. Se o modelo não aparecer, verifique o caminho do arquivo de configuração, a sintaxe JSON e as variáveis de ambiente; 401 indica que a Key é inválida ou não foi exportada.

A extensão da IDE reutiliza a mesma configuração de runtime do OpenCode; consulte [OpenCode IDE Extension](https://platform.acedata.cloud/documents/opencode-ide-integration).
