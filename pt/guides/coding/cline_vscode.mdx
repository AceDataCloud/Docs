## 1. Obter a API Key

Abra a [lista de aplicativos do Ace Data Cloud](https://platform.acedata.cloud/console/applications), entre em um aplicativo disponível e copie a API Key.

![Obter a API Key do Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configurar o Cline

Instale e abra o Cline no VS Code e, em seguida, acesse a configuração do Provider pelo botão de configurações no painel do Cline, preenchendo:

| Campo                                | Valor                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| API Provider                      | `OpenAI Compatible`                                                                            |
| Base URL                          | `https://api.acedata.cloud/v1`                                                                 |
| API Key                           | A API Key que acabou de ser copiada                                                                                  |
| Model ID                          | Acesse o [catálogo de modelos](https://platform.acedata.cloud/models) para consultar e preencha o nome do modelo de destino exatamente como está, por exemplo `claude-opus-5`、`gpt-6-sol` |
| Custom Headers                    | Deixe em branco                                                                                             |
| Set Azure API version             | Deixe em branco                                                                                             |
| Use Azure Identity Authentication | Desative                                                                                             |

![Tela de configuração do Cline OpenAI Compatible](https://cdn.acedata.cloud/8f356c2f1378.png)

`Model ID` é o nome do modelo usado pelo parâmetro `model` nas solicitações de API, não é o UUID do serviço ou da API, nem pode ser abreviado livremente. Você pode primeiro consultar o [catálogo de modelos](https://platform.acedata.cloud/models); se precisar de uma validação precisa, use a API Key atual para solicitar `GET https://api.acedata.cloud/v1/models` e copie o valor de `id` do modelo de destino do array `data` na resposta.

Mantenha as demais configurações de capacidade do modelo nos valores padrão por enquanto; quando precisar de imagens ou de um contexto maior, ajuste-as de acordo com as capacidades reais do modelo selecionado.

## 3. Verificar

Após salvar, crie uma nova tarefa e envie `Reply only OK`. Em seguida, peça ao Cline para ler um arquivo de teste para confirmar que o modelo oferece suporte a chamadas de ferramentas; os registros de chamadas podem ser consultados no [histórico de uso](https://platform.acedata.cloud/console/usages).

O erro 401 geralmente indica que a Key está incorreta; o erro 404 geralmente indica que a Base URL está incorreta ou que o Model ID preenchido não corresponde exatamente ao `id` no catálogo. Se o modelo consegue conversar, mas não consegue operar arquivos, verifique a capacidade de chamadas de ferramentas desse modelo.
