## 1. Obter API Key

Abra a [lista de aplicativos do Ace Data Cloud](https://platform.acedata.cloud/console/applications), acesse os aplicativos disponíveis e copie a API Key.

![Obter Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configuração

Kilo CLI lê `kilo.jsonc` e obtém a API Key do shell que iniciou o CLI.

Escreva em `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Em seguida, exporte o Token no shell atual:

```bash
export ACEDATACLOUD_API_KEY="COLE_SEU_TOKEN_ACEDATACLOUD_AQUI"
```

## 3. Verificação

```bash
kilo run -m acedatacloud/MODEL_ID "Responda apenas OK"
```

Se o CLI não conseguir ler o Token, verifique se a variável foi `export` e não apenas escrita em um arquivo `.env` não carregado.
