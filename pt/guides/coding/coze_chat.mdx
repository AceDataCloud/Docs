A documentação oficial do modelo personalizado Coze suporta a API de Chat da OpenAI. Diferentes versões do inquilino Coze podem tratar a concatenação de caminhos, saída em fluxo e chamadas de ferramentas de maneira diferente; ao se conectar pela primeira vez, verifique cada item abaixo.

## Configuração

1. Acesse a gestão de modelos Coze e adicione um modelo personalizado.
2. Selecione o Protocolo como OpenAI Chat API.
3. Preencha a URL Base da API como `https://api.acedata.cloud/v1`.
4. Preencha a Chave da API com seu Token da Ace Data Cloud API.
5. Preencha o Modelo com o ID exato do modelo que suporta Chat Completions no diretório de modelos.
6. Salve e complete o teste de conexão do Coze.
7. No Bot/Agente, envie `Reply only OK`, e teste novamente a chamada da ferramenta.

## Limites Atuais

- Diferentes regiões, versões ou pacotes do Coze podem exibir formulários diferentes.
- A URL Base da API deve usar base, não adicione repetidamente `/chat/completions`; se a UI atual exigir uma URL API completa, siga as instruções do formulário.
- Chat Completions, Responses e Anthropic Messages são três rotas independentes e não podem se substituir na validação.
