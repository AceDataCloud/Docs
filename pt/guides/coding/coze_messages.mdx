A documentação oficial do modelo personalizado Coze suporta a API Anthropic Messages. Diferentes versões do inquilino Coze podem tratar Header, concatenação de caminhos, streaming e chamadas de ferramentas de maneira diferente; ao se conectar pela primeira vez, verifique cada item abaixo.

## Configuração

1. Acesse a gestão de modelos Coze e adicione um modelo personalizado.
2. Selecione Protocol como API Anthropic Messages.
3. Preencha a Base API URL com `https://api.acedata.cloud`.
4. Preencha a API Key com seu Token da Ace Data Cloud API.
5. Preencha o Model com o ID exato do modelo que suporta Anthropic Messages no diretório de modelos.
6. Salve e complete o teste de conexão do Coze.
7. No Bot/Agente, envie `Reply only OK`, e teste novamente a chamada da ferramenta.

## Limites Atuais

- Diferentes regiões, versões ou pacotes do Coze podem exibir formulários diferentes.
- A Base API URL não deve ter `/v1/messages` adicionada novamente; se a UI atual exigir um URL API completo, siga o que o formulário indicar.
- Messages, Chat Completions e Responses são três rotas independentes e não podem se substituir na validação.
