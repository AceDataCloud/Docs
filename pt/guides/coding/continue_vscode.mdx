Continue suporta API compatível com OpenAI. Para garantir que utilize Chat Completions, é necessário definir explicitamente `useResponsesApi: false`.

## Configuração

Adicione ao arquivo YAML local de configuração do Continue:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Salve `ACEDATACLOUD_API_KEY` na gestão de segredos do Continue, não envie o Token real para a configuração do projeto. A configuração JSON do Continue foi descontinuada, a nova configuração utiliza YAML.

## Verificação

Recarregue o VS Code, abra a barra lateral do Continue, selecione o modelo na Configuração Local e envie `Reply only OK`; em seguida, execute novamente a tarefa de arquivo somente leitura. Se a solicitação for enviada incorretamente para `/responses`, verifique se `useResponsesApi: false` está presente na entrada do modelo.
