## 1. Obter a API Key

Abra a [lista de aplicativos do Ace Data Cloud](https://platform.acedata.cloud/console/applications), entre em um aplicativo disponível e copie a API Key.

![Obter a API Key do Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Executar o assistente

```bash
hermes model
```

Selecione **Custom endpoint** e preencha em sequência:

| Campo             | Valor                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | A API Key copiada agora                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | Acesse o [catálogo de modelos](https://platform.acedata.cloud/models) para verificar e preencha o nome do modelo de destino exatamente como está, por exemplo, `claude-opus-5`、`gpt-6-sol` |
| Context length | Deixe em branco para detecção automática ou preencha conforme o catálogo de modelos                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model` é o nome do modelo usado pelo parâmetro `model` na solicitação da API, não o UUID do serviço ou da API. Você pode primeiro verificar no [catálogo de modelos](https://platform.acedata.cloud/models); se precisar de validação precisa, use a API Key atual para solicitar `GET https://api.acedata.cloud/v1/models` e copie o valor de `id` do modelo de destino no array `data` da resposta.

O assistente gravará em `~/.hermes/config.yaml` e no arquivo de credenciais local.

## 3. Verificação

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

Se o assistente não salvar a configuração, você pode executar `hermes model --reset` e tentar novamente; 401 indica que a API Key é inválida ou não foi lida pela configuração do usuário atual.
