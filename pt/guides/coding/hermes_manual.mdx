## 1. Obter a API Key

Abra a [lista de aplicações do Ace Data Cloud](https://platform.acedata.cloud/console/applications), entre na aplicação disponível e copie a API Key.

![Obter a API Key do Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Salvar a Key

Escreva em `~/.hermes/.env`:

```dotenv
ACEDATACLOUD_API_KEY=sua API Key
```

## 3. Configurar o Provider

Adicione em `~/.hermes/config.yaml`:

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

Acesse o [catálogo de modelos](https://platform.acedata.cloud/models) para ver os nomes dos modelos (por exemplo, `claude-opus-5`, `gpt-6-sol`) e substitua todos os `MODEL_ID` pelo mesmo nome; para validação precisa, use o valor de `id` na resposta de `/v1/models` como referência. Esse valor é o nome do modelo usado pelo parâmetro `model` da API, não o UUID do serviço ou da API. Não escreva a Key real no YAML nem envie o `.env` para o repositório.

## 4. Verificar

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

Se retornar 401, verifique `~/.hermes/.env`; se a configuração não entrar em vigor, saia completamente e reinicie o Hermes.
