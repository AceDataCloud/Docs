## 1. Obter a API Key

Abra a [lista de aplicações do Ace Data Cloud](https://platform.acedata.cloud/console/applications), entre em uma aplicação disponível e copie a API Key.

![Obter a API Key do Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configuração

O Roo Code oferece oficialmente o Provider compatível com OpenAI e exige que o modelo suporte OpenAI tools/function calling nativo.

1. Abra as configurações do Roo Code no VS Code.
2. Defina **API Provider** como **OpenAI Compatible**.
3. Preencha:

| Campo       | Valor                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | A API Key copiada agora                  |
| Model ID | O ID do modelo selecionado no assistente de configuração do Coding         |

![Interface de configuração do Roo Code OpenAI Compatible](https://cdn.acedata.cloud/b6a0e7156438.png)

Em seguida, configure as opções de context, max output, imagens e computer-use de acordo com as capacidades reais do modelo. Por fim, salve a configuração e recarregue o VS Code.

## 3. Verificação

Primeiro envie `Reply only OK` e depois peça ao Roo Code para ler um arquivo de teste. Se o chat comum funcionar, mas as ferramentas do Agent falharem, troque por um modelo que suporte tool calling nativo e confirme que o endpoint compatível pode retornar corretamente, por streaming, os parâmetros e resultados das ferramentas.
