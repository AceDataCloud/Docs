## 1. Obter API Key

Abra a [lista de aplicativos do Ace Data Cloud](https://platform.acedata.cloud/console/applications), acesse os aplicativos disponíveis e copie a API Key.

![Obter Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configurar Provider

O plugin JetBrains do Kilo Code utiliza o formato de Provider `kilo.jsonc`. A configuração deve estar no ambiente do usuário onde o plugin está realmente em execução; durante o Desenvolvimento Remoto, geralmente é o host backend remoto.

Escreva em `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

No ambiente que inicia o backend do JetBrains, exporte `ACEDATACLOUD_API_KEY`, e reinicie o IDE ou o backend remoto.

## 3. Verificação

Selecione `acedatacloud/MODEL_ID`, envie `Reply only OK`, e então faça o Agent ler um arquivo de teste. Se funcionar localmente, mas falhar remotamente, verifique primeiro se o arquivo de configuração e as variáveis de ambiente estão escritas no host remoto.
