O Qwen Code usa a configuração `modelProviders` em `~/.qwen/settings.json` para personalizar o Provider. Aqui, utilizamos o protocolo compatível com OpenAI.

## Configuração

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud` deve ser um array. Os itens do Provider são configurados de forma independente e não herdarão automaticamente outros parâmetros de contexto, Header ou body de nível superior.

## Verificação

```bash
export ACEDATACLOUD_API_KEY="COLE_SEU_TOKEN_ACEDATACLOUD_AQUI"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Responda apenas OK"
```

Após entrar, envie `Responda apenas OK`, e execute novamente a ferramenta de leitura de arquivos. Se o endpoint estritamente compatível recusar o formato de resultado da ferramenta, verifique a versão atual do Qwen Code e as instruções de compatibilidade oficiais.
