## 1. Obter a API Key

Abra a [lista de aplicações do Ace Data Cloud](https://platform.acedata.cloud/console/applications), entre em uma aplicação disponível e copie a API Key.

![Obter a API Key do Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar o Kimi Code

macOS / Linux:

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

Também pode ser instalado via npm:

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. Configurar o AceDataCloud

Edite `~/.kimi/config.toml` e adicione a seguinte configuração:

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "sua API Key"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

Acesse o [catálogo de modelos](https://platform.acedata.cloud/models) para verificar os nomes dos modelos (por exemplo, `claude-opus-5`, `gpt-6-sol`) e substitua todos os `MODEL_ID` pelo mesmo nome; para validação precisa, use o valor de `id` na resposta de `/v1/models`. Esse valor é o nome do modelo usado pelo parâmetro `model` da API, não o UUID do serviço ou da API. `type = "openai"` usa o protocolo OpenAI Chat Completions.

O arquivo de configuração contém a Key; no macOS / Linux, recomenda-se restringir as permissões:

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. Verificar e iniciar

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

Após entrar no projeto, execute `kimi` para começar a usar. Se retornar 401, verifique a API Key; se for exibido model not found, confirme que `default_model`, o nome do modelo na tabela e o campo `model` usam o mesmo ID.
