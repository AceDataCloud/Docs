## 1. Obter API Key

Abra a [lista de aplicativos do Ace Data Cloud](https://platform.acedata.cloud/console/applications), acesse os aplicativos disponíveis e copie a API Key.

![Obter Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar OpenClaw e o plugin

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

O plugin requer OpenClaw `2026.4.2` ou versão superior, atualmente oferece suporte nativo para Chat e Web Search.

## 3. Configurar Key

Recomenda-se usar onboarding:

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "sua API Key"
```

Você também pode usar variáveis de ambiente:

```bash
export ACEDATACLOUD_API_KEY="sua API Key"
```

## 4. Opcional: Configuração Manual

Ao não usar onboarding, habilite o plugin e defina o modelo padrão em `~/.openclaw/openclaw.json`:

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

Não escreva a API Key neste arquivo; continue usando variáveis de ambiente.

## 5. Escolher Modelo e Verificar

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "Responda apenas OK"
```

Substitua `MODEL_ID` pelo modelo atualmente fornecido pelo Coding Plan. Para definir como modelo padrão, execute:

```bash
openclaw models set acedatacloud/MODEL_ID
```

Os registros de chamadas podem ser visualizados em [Histórico de Uso](https://platform.acedata.cloud/console/usages). 401 indica que a Key é inválida; se o modelo não existir, verifique primeiro o ID exato e a versão do plugin. O `cost: 0` no diretório do plugin apenas indica que não é estimado novamente pelo OpenClaw, o custo real ainda é registrado pelo Ace Data Cloud.

## Pesquisa na Web

```bash
openclaw infer web search \
  --provider acedatacloud --query "últimos frameworks de agentes de IA" --limit 5
```

Atualmente, não considere as capacidades de imagem, vídeo ou música mencionadas na introdução do plugin como capacidades nativas do Provider OpenClaw.
