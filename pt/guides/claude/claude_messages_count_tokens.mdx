A API Claude Messages Count Tokens pode calcular a quantidade de Tokens de entrada de uma Message sem realmente criar uma mensagem, incluindo a contagem de Tokens de conteúdos como ferramentas, imagens e documentos. Isso é muito útil quando é necessário estimar custos ou verificar se a entrada excede o limite de contexto do modelo.

Este documento apresenta principalmente o processo de uso da API Claude Messages Count Tokens.

## Processo de solicitação

Para usar a API Claude Messages Count Tokens, primeiro obtenha seu API Token no [Console Ace Data Cloud](https://platform.acedata.cloud/console/applications) e mantenha-o como reserva.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não tiver feito login ou se registrado, será automaticamente redirecionado para a página de login, onde será convidado a se registrar e fazer login; após a conclusão, você retornará automaticamente à página atual.

**Um único API Token pode chamar todos os serviços da plataforma, sem necessidade de solicitar separadamente para cada serviço.** A primeira solicitação oferece créditos gratuitos, permitindo uma experiência gratuita; quando os créditos forem insuficientes, é possível recarregar o saldo geral no [Console](https://platform.acedata.cloud/console/coin).

> 📘 Documentação completa: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Uso básico

O caminho de solicitação da API Claude Messages Count Tokens é `/v1/messages/count_tokens`, mantendo-se consistente com a API oficial da Anthropic. Precisamos fornecer pelo menos dois parâmetros obrigatórios:

- `model`: selecione o modelo Claude a ser usado, como o mais recente carro-chefe `claude-fable-5-1`; o anterior `claude-fable-5` ainda permanece compatível.
- `messages`: o array de mensagens de entrada, em que cada mensagem contém `role` (função) e `content` (conteúdo).

Parâmetros opcionais comuns:

- `system`: prompt do sistema, que será incluído na quantidade de Tokens.
- `tools`: definições de ferramentas, que serão incluídas na quantidade de Tokens.
- `thinking`: configuração de pensamento estendido.
- `tool_choice`: configuração de seleção de ferramentas.
- `cache_control`: configuração de controle de cache de nível superior ou de bloco de conteúdo.

`messages`, `system`, reprodução de chamadas de ferramentas, imagens por URL e blocos de conteúdo document/PDF usam a mesma estrutura estável de solicitação da API Messages.

### Exemplo cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Exemplo Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Exemplo de resultado retornado:

```json
{
  "input_tokens": 11
}
```

### Uso do SDK Anthropic

A API Claude Messages Count Tokens aceita a estrutura estável de solicitação do SDK Anthropic e pode ser chamada por meio da biblioteca `anthropic`. A interface usa a capacidade nativa de Count Tokens correspondente ao modelo selecionado para contar a entrada, podendo ser usada para verificar o tamanho da entrada antes de enviar uma solicitação Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Contagem de Tokens incluindo ferramentas

Se sua solicitação incluir definições de ferramentas, essas ferramentas também serão incluídas na quantidade de Tokens:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Contagem de Tokens incluindo prompt do sistema

O prompt do sistema também será incluído na quantidade de Tokens:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Observações

- Esta API calcula apenas a quantidade de Tokens de entrada e não produzirá nenhuma saída do modelo.
- O resultado da contagem de Tokens pode ser usado para estimar o tamanho da entrada e verificar a janela de contexto; a cobrança final prevalece conforme o `usage` na resposta real de Messages.
- Imagens, PDFs, definições de ferramentas, prompts do sistema e configurações de thinking serão incluídos no resultado de acordo com as regras de entrada do modelo selecionado.
- Esta API é totalmente gratuita e não consome nenhum crédito.
