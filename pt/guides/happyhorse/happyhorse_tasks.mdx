A API HappyHorse Tasks é utilizada para consultar as tarefas de geração ou edição de vídeos criadas pela API HappyHorse Videos.

## Processo de Solicitação

Para usar a API HappyHorse Videos, primeiro acesse o [Painel de Controle Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter seu Token de API, que deve ser guardado para referência futura.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, onde será convidado a se registrar e logar. Após a conclusão, você será redirecionado de volta para a página atual.

**Um Token de API é suficiente para acessar todos os serviços da plataforma, não sendo necessário solicitar um para cada serviço individualmente.** A primeira solicitação vem com um crédito gratuito, permitindo uma experiência sem custo; quando o crédito estiver baixo, você pode recarregar o saldo geral no [painel de controle](https://platform.acedata.cloud/console/coin).

> 📘 Documentação Completa: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Exemplo de Solicitação

A API HappyHorse Tasks pode ser utilizada para consultar os resultados da API HappyHorse Videos.

### Configurando Cabeçalhos e Corpo da Solicitação

**Cabeçalhos da Solicitação** incluem:

- `accept`: especifica que a resposta deve ser no formato JSON, preenchido como `application/json`.
- `authorization`: a chave para chamar a API, que pode ser selecionada diretamente após a solicitação.

**Corpo da Solicitação** inclui:

- `id`: o ID da tarefa a ser consultada.
- `action`: a forma de operação na tarefa, preenchido como `retrieve` para uma consulta única.

### Exemplo de Código CURL

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Exemplo de Resposta

Após uma solicitação bem-sucedida, a API retornará os detalhes da tarefa. O campo `request` é o corpo da solicitação ao criar a tarefa, e o campo `response` é o corpo da resposta retornada após a conclusão da tarefa, por exemplo:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "Uma cena cinematográfica de um cavalo branco correndo por uma praia iluminada pela lua",
    "resolution": "720P",
    "duration": 5
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "1469cfc3-3004-4d9e-ab10-xxxxxx",
        "video_url": "https://cdn.acedata.cloud/happyhorse/c8cbf53aa0.mp4",
        "state": "succeeded",
        "duration": 5,
        "resolution": "720P",
        "ratio": "16:9"
      }
    ]
  }
}
```

A descrição dos campos é a seguinte:

- `id`: ID da tarefa gerada, usado para identificar exclusivamente esta tarefa de geração.
- `request`: informações da solicitação ao criar a tarefa.
- `response`: informações de retorno atuais ou finais da tarefa.
- `created_at`: data e hora de criação da tarefa, timestamp Unix (segundos, ponto flutuante).
- `started_at`: data e hora de início da execução da tarefa, timestamp Unix (segundos, ponto flutuante).
- `finished_at`: data e hora de conclusão da tarefa, timestamp Unix (segundos, ponto flutuante). Este campo não é retornado se a tarefa não estiver concluída.
- `elapsed`: tempo gasto na execução da tarefa, em segundos (ponto flutuante, com 3 casas decimais). Este campo não é retornado se a tarefa não estiver concluída.

## Operação de Consulta em Lote

Para consultar detalhes de várias tarefas ID, defina `action` como `retrieve_batch` e passe um array de IDs de tarefas através de `ids`:

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```

O resultado retornado incluirá os campos `items` e `count`, onde `items` é um array de detalhes da tarefa e `count` é o número de tarefas correspondentes encontradas nesta consulta.
