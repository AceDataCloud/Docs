---
title: "API de Foto Falante Kling (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Transforme **uma foto + um áudio** em um "vídeo falante" com um clique. O serviço realiza automaticamente duas etapas: primeiro, usa image2video para animar a foto, e depois usa lip-sync para sincronizar os lábios com o áudio. Você só precisa chamar **uma vez**.

- **URL da API**: `POST https://api.acedata.cloud/kling/talking-photo`
- **Cobrança**: por duração, 5 segundos **16,45 Créditos**, 10 segundos **30,45 Créditos** (= preço combinado de image2video + lip-sync)

## Cabeçalhos da Requisição

| Campo              | Valor                 |
| ----------------- | ------------------- |
| `authorization`   | `Bearer ${API_KEY}` |
| `content-type`    | `application/json`  |

## Parâmetros da Requisição

| Parâmetro        | Tipo      | Obrigatório | Padrão                  | Descrição                                    |
| ---------------- | --------- | ----------- | ---------------------- | ------------------------------------------- |
| `image_url`      | string    | Sim         | —                      | URL pública da foto da pessoa, recomenda-se que seja clara e de frente                    |
| `audio_url`      | string    | Sim         | —                      | URL pública do áudio (mp3/wav/m4a/aac, ≤5MB) |
| `prompt`         | string    | Não         | —                      | Palavras-chave de ação/expressão para a fase de animação da foto                      |
| `model`          | string    | Não         | `kling-v2-1-master`   | Modelo Kling usado para a animação da foto                     |
| `duration`       | integer   | Não         | `5`                    | Duração do vídeo (5 ou 10 segundos)                        |
| `mode`           | string    | Não         | `pro`                  | Qualidade da animação (std/pro)                        |
| `callback_url`   | string    | Não         | —                      | Se fornecido ou `async=true`, retornará task_id de forma assíncrona        |
| `async`          | boolean   | Não         | `false`                | Modo assíncrono, usado com `/kling/tasks` para polling ou callback          |

## Exemplo de Requisição

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Exemplo de Resposta

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "source_video_url": "https://platform2.cdn.acedata.cloud/kling/163ac822-1a15-4f5e-a2eb-465154df15af.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Campo                | Descrição                        |
| ------------------- | ------------------------------- |
| `video_url`         | O vídeo final que fala (armazenado na CDN da plataforma)      |
| `source_video_url`  | O vídeo de animação da foto intermediária (resultado do image2video) |
| `video_id`          | ID do vídeo Kling                   |

## Observações

- Recomenda-se que a foto seja clara, de frente e de uma única pessoa.
- A duração do áudio não deve exceder a duração do vídeo (5s/10s).
- A cobrança ocorre no sucesso; falhas de validação de parâmetros (4xx) não geram cobrança.
- O tempo de geração é de aproximadamente 4–6 minutos (duas etapas), recomenda-se usar `async=true` + `/kling/tasks` para polling.
