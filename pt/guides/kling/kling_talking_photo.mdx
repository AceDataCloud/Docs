---
title: "API de Foto Falante Kling (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Com um clique, transforme **uma foto + um áudio** em um «vídeo falante». O serviço conclui automaticamente duas etapas internamente: primeiro usa image2video para animar a foto e, em seguida, usa lip-sync para sincronizar os lábios com o áudio. Você só precisa chamar **uma vez**.

- **Endereço da interface**: `POST https://api.acedata.cloud/kling/talking-photo`
- **Cobrança**: por duração, 5 segundos **16.45 Credits**, 10 segundos **30.45 Credits** (= preço combinado de image2video + lip-sync)

## Cabeçalhos da solicitação

| Campo              | Valor               |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## Parâmetros da solicitação

| Parâmetro             | Tipo      | Obrigatório  | Padrão                  | Descrição                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | Sim   | —                   | URL pública da foto da pessoa, recomenda-se um rosto frontal nítido                    |
| `audio_url`    | string  | Sim   | —                   | URL pública do áudio de condução（.mp3/.wav/.m4a/.aac,≤5MB） |
| `prompt`       | string  | Não   | —                   | Palavra-chave de ação/expressão para a etapa de animação da foto                      |
| `model`        | string  | Não   | `kling-v2-1-master` | Modelo Kling usado para a animação da foto                     |
| `duration`     | integer | Não   | `5`                 | Duração do vídeo（5 ou 10 segundos）                        |
| `mode`         | string  | Não   | `pro`               | Qualidade da animação（std/pro）                        |
| `callback_url` | string  | Não   | —                   | Retorna `task_id` de forma assíncrona se fornecido ou se `async=true`        |
| `async`        | boolean | Não   | `false`             | Modo assíncrono, use com consulta ou callback de `/kling/tasks`          |

## Exemplo de solicitação

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Exemplo de resposta

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Campo                 | Descrição                        |
| ------------------ | ------------------------- |
| `video_url`        | Vídeo falante final（já armazenado no CDN desta plataforma）      |
| `source_video_url` | Vídeo intermediário de animação da foto（resultado de image2video） |
| `video_id`         | ID do vídeo Kling                   |

## Observações

- Recomenda-se que a foto tenha um rosto frontal nítido e uma única pessoa.
- Recomenda-se que a duração do áudio não exceda a duração do vídeo（5s/10s）。
- A cobrança ocorre após o sucesso; falhas na validação dos parâmetros（4xx）não são cobradas。
- A geração leva cerca de 4–6 minutos（duas etapas）, recomenda-se usar `async=true` + consulta de `/kling/tasks`.
