Envie uma tarefa através de `POST /kling/video-commerce` e use o `POST /kling/tasks` existente para consultar o status da tarefa na plataforma.

## Entrada

Envie uma imagem de pessoa e especifique o voice_id, ou use um avatar_id predefinido (os dois são mutuamente exclusivos; personagens predefinidos não podem especificar voice_id adicionalmente). É obrigatório fornecer um speech_script de no máximo 2000 caracteres. Ao fornecer informações do produto, é necessária pelo menos uma ref_image e um goods_title; a locução de produto não oferece suporte a speech_rate. A locução de pessoa comum oferece suporte a velocidades de fala de 0.8, 1.0 ou 1.2 vezes.

A seguir está um exemplo de estrutura da solicitação; substitua as URLs dos materiais antes de chamar.

```json
{
  "contents": [
    {
      "type": "avatar_image",
      "url": "https://your-cdn.example/person.jpg"
    },
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    },
    {
      "type": "speech_script",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "voice_id": "male_calm_informative"
  },
  "async": true
}
```

## Resultados e Cobrança

O modo síncrono retorna o resultado gerado; o modo assíncrono primeiro retorna o `task_id`, e o resultado concluído contém os links de vídeo ou imagem em `data` e o `usage` calculado pelo servidor. `callback_url` é usado para notificação de conclusão; solicitações com `watermark=true` também retornam a versão com marca d'água.

Locução de pessoa comum: 1.4 Credits/segundo para 720p e 1.68 Credits/segundo para 1080p; locução de produto: 1.96 Credits/segundo para 720p e 2.24 Credits/segundo para 1080p. Os vídeos são cobrados conforme a duração real gerada; o preço-base por segundo antes da geração não representa o preço total de toda a tarefa. Tarefas com falha não incorrem em custos de geração.
