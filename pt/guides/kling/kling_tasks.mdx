A principal função da API Kling Tasks é consultar o status de execução de uma tarefa através do ID da tarefa gerado pela API Kling Videos Generation.

Este documento irá detalhar as instruções de integração da API Kling Tasks, ajudando você a integrar facilmente e aproveitar ao máximo o poderoso recurso dessa API. Com a API Kling Tasks, você pode consultar facilmente o status de execução das tarefas da API Kling Videos Generation.

## Processo de Solicitação

Para usar a API Kling Tasks, você precisa primeiro ir à página de solicitação [Kling Videos Generation API](https://platform.acedata.cloud/documents/3b921a16-a411-4557-8335-53f21d3f9e46) para solicitar o serviço correspondente e, em seguida, copiar o ID da tarefa da API Kling Videos Generation, como mostrado na imagem:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Por fim, acesse a página da API Tasks [Pika Tasks API](https://platform.acedata.cloud/documents/6b43ff7b-8298-49c8-a390-83df85c2c5e5) para solicitar o serviço correspondente. Após entrar na página, clique no botão "Acquire", como mostrado na imagem:

![Página de Solicitação](https://cdn.acedata.cloud/rci31i.png)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a [página de login](https://platform.acedata.cloud) que o convidará a se registrar e fazer login. Após o login ou registro, você será redirecionado automaticamente de volta para a página atual.

Na primeira solicitação, haverá um crédito gratuito disponível, permitindo que você use a API gratuitamente.

## Exemplo de Solicitação

A API Kling Tasks pode ser usada para consultar os resultados da API Kling Videos Generation. Para saber como usar a API Kling Videos Generation, consulte o documento [Kling Videos Generation API](https://platform.acedata.cloud/documents/3b921a16-a411-4557-8335-53f21d3f9e46).

Usaremos um exemplo de ID de tarefa retornado pelo serviço da API Kling Videos Generation. Suponha que temos um ID de tarefa: 20068983-0cc9-4c6a-aeb6-9c6a3c668be0, a seguir, demonstraremos como passar um ID de tarefa.

### Configurando Cabeçalhos e Corpo da Solicitação

**Request Headers** incluem:

- `accept`: especifica que a resposta deve estar no formato JSON, preenchido como `application/json`.
- `authorization`: chave para chamar a API, que pode ser selecionada diretamente após a solicitação.

**Request Body** inclui:

- `id`: ID da tarefa enviada.
- `action`: modo de operação da tarefa.

Configuração conforme mostrado na imagem abaixo:

<p><img src="https://cdn.acedata.cloud/xztiqi.png" width="500" className="m-auto" /></p>

### Exemplo de Código

Pode-se notar que, no lado direito da página, já foram gerados automaticamente códigos em várias linguagens, como mostrado na imagem:

<p><img src="https://cdn.acedata.cloud/bsqh3i.png" width="500" className="m-auto" /></p>

Alguns exemplos de código são os seguintes:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/kling/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/kling/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Erro de tratamento

Ao chamar a API, se encontrar um erro, a API retornará o respectivo código de erro e informações. Por exemplo:

- `400 token_mismatched`：Solicitação inválida, possivelmente devido a parâmetros ausentes ou inválidos.
- `400 api_not_implemented`：Solicitação inválida, possivelmente devido a parâmetros ausentes ou inválidos.
- `401 invalid_token`：Não autorizado, token de autorização inválido ou ausente.
- `429 too_many_requests`：Muitas solicitações, você excedeu o limite de taxa.
- `500 api_error`：Erro interno do servidor, algo deu errado no servidor.

### Exemplo de resposta de erro

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
