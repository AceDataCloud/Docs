Envie uma tarefa por meio de `POST /kling/apparel` e use o `POST /kling/tasks` existente para consultar o status da tarefa na plataforma.

## Entrada

Forneça uma descrição do produto de até 2500 caracteres, um vídeo de referência de 5–180 segundos e 1–5 imagens do produto. Opcionalmente, podem ser fornecidas 1–5 imagens de modelo, um arquivo de música de fundo e uma voz de dublagem especificada; caso nenhuma voz seja especificada, será usada a fala original.

A seguir está um exemplo de estrutura de solicitação. Substitua as URLs dos materiais antes de chamar.

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "Seu produto ou conteúdo de fala"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## Resultados e cobrança

O modo síncrono retorna o resultado gerado; o modo assíncrono primeiro retorna `task_id`, e o resultado concluído inclui os links de vídeo ou imagem em `data` e o `usage` calculado pelo servidor. `callback_url` é usado para notificações de conclusão; a solicitação com `watermark=true` também retorna uma versão com marca d'água.

Fala original: 720p custa 1,82 Credits/segundo e 1080p custa 2,38 Credits/segundo; dublagem especificada: 720p custa 2,38 Credits/segundo e 1080p custa 2,8 Credits/segundo. O vídeo é cobrado com base na duração real gerada; o preço-base por segundo antes da geração não representa o preço total de toda a tarefa. Tarefas com falha não são cobradas pela geração.
