title: "API de Sincronização Labial Kling (Kling Lip Sync)"

Permite que um **vídeo Kling existente** (5 segundos ou 10 segundos) "fale" de acordo com um áudio ou texto — ou seja, sincronização labial (Lip Sync). Combinado com `/kling/videos` e `image2video` (fazer fotos se moverem), pode formar um fluxo completo de "**fotos falantes / avatares digitais**".

> Esta interface é uma embalagem conveniente de um único passo fornecida pela AceDataCloud, voltada para cenários comuns de áudio/texto. Não é um espelho de campo da interface de múltiplos passos oficial da Kling "Reconhecimento Facial → Sincronização Labial Avançada". Por favor, consulte a tabela de parâmetros nesta página.

- **Endereço da API**: `POST https://api.acedata.cloud/kling/lip-sync`
- **Formato da solicitação**: `application/json`
- **Formato da resposta**: `application/json`
- **Cobrança**: **2,45 Créditos** por chamada bem-sucedida (fixo)

## Cabeçalhos da Solicitação (Request Headers)

| Campo              | Valor                   | Descrição                                           |
| ----------------- | --------------------- | ------------------------------------------------ |
| `authorization`   | `Bearer ${API_KEY}`   | Sua chave API, [endereço para obter](https://platform.acedata.cloud) |
| `content-type`    | `application/json`    | Formato do corpo da solicitação                      |
| `accept`          | `application/json`    | Formato da resposta                                   |

## Parâmetros da Solicitação (Request Body)

| Parâmetro         | Tipo     | Obrigatório | Padrão   | Descrição                                                                                                                   |
| ----------------- | -------- | ----------- | -------- | -------------------------------------------------------------------------------------------------------------------------- |
| `mode`            | string   | Sim         | —        | Modo de geração. Enumeração: `audio2video` (dirigido por áudio), `text2video` (dirigido por texto)                       |
| `video_id`       | string   | Um dos dois | —        | ID do vídeo gerado pelo Kling (como o `video_id` retornado por `image2video` de `/kling/videos`). **Apenas suporta vídeos de 5s/10s gerados nos últimos 30 dias**. `video_id` e `video_url` são mutuamente exclusivos, não podem ser enviados ao mesmo tempo |
| `video_url`      | string   | Um dos dois | —        | Link de vídeo acessível publicamente. Restrições: `.mp4`/`.mov`, ≤100MB, duração de 2–10s, apenas 720p/1080p, comprimento de lado de 720–1920px. Mutuamente exclusivo com `video_id` |
| `audio_url`      | string   | Condicional | —        | URL de download do áudio que irá dirigir, obrigatório quando `audio2video` + `audio_type=url`. Formato `.mp3`/`.wav`/`.m4a`/`.aac`, ≤5MB |
| `audio_type`     | string   | Não         | `url`    | Método de transmissão de áudio. Enumeração: `url`, `file` (aplica-se quando `audio2video`)                                 |
| `audio_file`     | string   | Condicional | —        | Arquivo de áudio em Base64, obrigatório quando `audio_type=file`. Formato como acima, ≤5MB                                 |
| `text`           | string   | Condicional | —        | Texto a ser lido, obrigatório quando `text2video`, **máximo de 120 caracteres**                                           |
| `voice_id`       | string   | Condicional | —        | ID da voz, obrigatório quando `text2video`                                                                                 |
| `voice_language` | string   | Não         | `zh`     | Idioma da voz. Enumeração: `zh`, `en` (aplica-se quando `text2video`)                                                     |
| `voice_speed`    | float    | Não         | `1.0`    | Velocidade da fala, intervalo `0.8`–`2.0`, precisão até uma casa decimal (aplica-se quando `text2video`)                  |
| `callback_url`   | string   | Não         | —        | Endereço de callback. Se este item ou `async=true` for fornecido, então **modo assíncrono**: retorna imediatamente `task_id`, e o resultado é retornado após a geração |
| `async`          | boolean  | Não         | `false`  | Se é assíncrono. Se `true`, retorna imediatamente `task_id`, em conjunto com `/kling/tasks` para polling ou callback em `callback_url` |

## Exemplo de Solicitação

### 1) Dirigido por Áudio (audio2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2) Dirigido por Texto (text2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "Irmão, há quanto tempo, estou bem, você precisa cuidar de si mesmo.",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## Exemplo de Resposta (sucesso síncrono)

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| Campo         | Tipo     | Descrição                                       |
| ------------- | -------- | ----------------------------------------------- |
| `success`     | boolean  | Se foi bem-sucedido                             |
| `task_id`     | string   | ID da tarefa atual (pode ser usado para consultar `/kling/tasks`) |
| `video_id`    | string   | ID do vídeo gerado pelo Kling (pode ser usado como entrada para a próxima `extend`/`lip-sync`) |
| `video_url`   | string   | URL do vídeo falante gerado (armazenado na CDN da plataforma, válido a longo prazo) |
| `duration`    | string   | Duração do vídeo (segundos)                     |
| `state`       | string   | Estado da tarefa: `succeed` / `failed`         |

## Modo Assíncrono e Consulta

Ao fornecer `callback_url` ou `async: true`, a interface **retorna imediatamente** `task_id`; depois pode:

- **Polling**: `POST /kling/tasks`, corpo `{ "action": "retrieve", "id": "<task_id>" }` (grátis)
- **Callback**: Após a geração, o resultado é enviado para o seu `callback_url`

## Fluxo Completo: Fotos Falantes (image2video → lip-sync)
```bash
# Passo 1: Faça a foto se mover, obtenha o video_id
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"olhe para a câmera, natural","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# Passo 2: Sincronize os lábios com o áudio
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"}'
# → { "video_url": "https://platform2.cdn.acedata.cloud/kling/....mp4", ... }
```

## Resposta de erro

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "um dos video_id ou video_url é necessário" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | código                  | significado                                           |
| ---- | ----------------------- | --------------------------------------------------- |
| 400  | `bad_request`           | Parâmetro ausente ou inválido (como não passar mode, conflito entre video e audio, texto acima de 120 caracteres) |
| 401  | `authorization_missing` | Chave API ausente ou inválida                        |
| 403  | `forbidden`             | Conteúdo bloqueado por controle de risco             |
| 429  | `too_many_requests`     | Limite de concorrência superior, por favor tente novamente mais tarde |
| 500  | `api_error`             | Erro interno ou de upstream                          |

## Observações

- `video_id` deve ser um vídeo Kling gerado **nos últimos 30 dias** e ter **5s ou 10s**; caso contrário, use `video_url` para passar um vídeo que atenda às restrições.
- O vídeo de entrada deve ser **claro, de frente, e de uma única pessoa**, o efeito de sincronização labial será melhor.
- A duração do áudio/texto deve corresponder à duração do vídeo (áudio não deve exceder o comprimento do vídeo).
- A cobrança ocorre em caso de **sucesso** (2,45 Créditos/vez); falhas na validação de parâmetros (4xx) não geram cobrança.
