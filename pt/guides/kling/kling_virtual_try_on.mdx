Envie uma tarefa por meio de `POST /kling/virtual-try-on`, use o `POST /kling/tasks` existente para consultar o status da tarefa na plataforma.

## Entrada

Deve ser fornecida exatamente uma product_image e uma person_image. keep_face, keep_pose, keep_background são todos true por padrão e podem ser desativados independentemente. O lado mais longo da imagem de entrada não deve exceder 2048px, o lado mais curto deve ser maior que 300px e o arquivo não deve exceder 10MB.

A seguir está um exemplo da estrutura da solicitação, substitua a URL do material antes de chamar.

```json
{
  "contents": [
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "person_image",
      "url": "https://your-cdn.example/person.jpg"
    }
  ],
  "async": true
}
```

## Resultados e cobrança

O modo síncrono retorna o resultado gerado; o modo assíncrono primeiro retorna `task_id`, e o resultado concluído inclui os links de vídeo ou imagem em `data` e o `usage` calculado pelo servidor. `callback_url` é usado para notificação de conclusão; a solicitação com `watermark=true` retorna simultaneamente a versão com marca d'água.

1.12 Credits/imagem, cobrado conforme o número real de imagens de saída. Os vídeos são cobrados conforme a duração real gerada, e o preço base por segundo antes da geração não representa o preço total de toda a tarefa. Tarefas com falha não cobram taxas de geração.
