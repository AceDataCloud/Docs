title: "Guia de Configuração do Codex para VS Code"

---

A extensão Codex do VS Code compartilha `~/.codex/config.toml` com o Codex CLI.

## 1. Obter a Chave da API

Abra a [lista de aplicativos do Ace Data Cloud](https://platform.acedata.cloud/console/applications), acesse o aplicativo disponível e copie a Chave da API.

![Obter a Chave da API do Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar a Extensão

Instale o **Codex – agente de codificação da OpenAI** no mercado de extensões do VS Code, ou execute:

```bash
code --install-extension openai.chatgpt
```

## 3. Configurar a Chave da API

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="sua Chave da API"
```

Para que tenha efeito a longo prazo, adicione esta linha ao `~/.zshrc` ou `~/.bashrc`. No Windows PowerShell, use:

```powershell
setx ACEDATACLOUD_API_KEY "sua Chave da API"
```

## 4. Configurar o AceDataCloud

Edite `~/.codex/config.toml` (no Windows, `%USERPROFILE%\.codex\config.toml`), adicione:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

No Windows, altere as duas últimas linhas para:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Não é necessário preencher `model`; você pode escolher o modelo no painel do Codex.

## 5. Reiniciar e Verificar

Saia completamente e reabra o VS Code, em seguida, abra o painel do Codex. Execute `/model`, confirme que o Provider é `acedatacloud`, e então envie uma mensagem simples; os registros de chamadas podem ser visualizados em [Histórico de Uso](https://platform.acedata.cloud/console/usages).

Se a extensão não conseguir ler a Chave, inicie o VS Code a partir de um terminal onde a variável de ambiente foi configurada, ou configure a variável de ambiente a nível de sistema e reinicie o VS Code. Remote SSH, WSL e Dev Container precisam ser configurados no ambiente onde a extensão está realmente sendo executada.
