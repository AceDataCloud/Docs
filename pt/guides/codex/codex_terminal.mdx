## 1. Obter API Key

Abra a [lista de aplicativos do Ace Data Cloud](https://platform.acedata.cloud/console/applications), acesse os aplicativos disponíveis e copie a API Key.

![Obter Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar Codex

```bash
npm install -g @openai/codex
```

## 3. Configurar API Key

macOS / Linux：

```bash
export ACEDATACLOUD_API_KEY="sua API Key"
```

Para que tenha efeito a longo prazo, adicione esta linha ao `~/.zshrc` ou `~/.bashrc`. Windows PowerShell usa:

```powershell
setx ACEDATACLOUD_API_KEY "sua API Key"
```

Após a configuração, reinicie o terminal.

## 4. Configurar AceDataCloud

Edite `~/.codex/config.toml` (para Windows é `%USERPROFILE%\.codex\config.toml`), adicione:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Para Windows, altere as duas últimas linhas para:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Não é necessário preencher `model`; após iniciar, você pode escolher o modelo no Codex. Outras configurações existentes podem ser mantidas, não crie providers com o mesmo nome.

## 5. Iniciar

```bash
cd /caminho/para/seu/projeto
codex
```

Após entrar no Codex, execute `/model`, confirme que o Provider é `acedatacloud`, e então escolha o modelo desejado. Os registros de chamadas e saldo podem ser visualizados em [Histórico de Uso](https://platform.acedata.cloud/console/usages) e [Lista de Aplicativos](https://platform.acedata.cloud/console/applications).

Se aparecer a mensagem de falta de Key ou retornar 401, confirme que a variável de ambiente foi configurada e saia completamente antes de reiniciar o terminal e o Codex.
