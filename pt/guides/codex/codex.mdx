O Codex CLI é um agente de programação local de código aberto lançado pela OpenAI, que pode ler código, modificar arquivos, executar comandos e auxiliar na conclusão de tarefas de desenvolvimento diretamente no terminal. Através do proxy Ace Data Cloud, você pode usar o Codex CLI a um custo menor, sem a necessidade de assinar uma conta oficial da OpenAI separadamente.

Escolha o tutorial de configuração completo correspondente ao seu cenário de uso:

| Plataforma | Descrição | Link do Tutorial |
|------------|-----------|------------------|
| **VS Code** | Extensão oficial, chat na barra lateral do editor, referência de arquivos, visualização de diff | [Tutorial de Configuração do VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| **Terminal (CLI)** | Experiência principal, execute `codex` em qualquer terminal para começar | [Tutorial de Configuração do Terminal](https://platform.acedata.cloud/documents/codex-terminal-integration) |

> **Dica**: Para a primeira solicitação, acesse o [Console do Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter o API Token, que inclui créditos gratuitos. O Codex CLI funciona através da interface compatível OpenAI Responses do Ace Data Cloud (`/v1/responses`). Para mais informações sobre modelos e cobrança, consulte a [Página de Serviços OpenAI](https://platform.acedata.cloud/documents/openai).
