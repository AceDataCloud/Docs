O Codex CLI, Desktop e a extensão do VS Code compartilham `~/.codex/config.toml`. Configure uma vez o provedor `acedatacloud` e você poderá usar o Codex através do Ace Data Cloud.

| Modo de Uso      | Guia de Configuração                                                                          |
| ---------------- | ------------------------------------------------------------------------------------------- |
| Terminal / CLI   | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)          |
| Desktop          | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)       |
| VS Code          | [Codex para VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)  |
| Alternância Gráfica | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration) |

As configurações comuns são apenas três:

- Provedor: `acedatacloud`
- URL Base: `https://api.acedata.cloud/v1`
- Chave da API: obtenha da [lista de aplicativos](https://platform.acedata.cloud/console/applications) e salve em `ACEDATACLOUD_API_KEY`

Não é necessário fixar o modelo na configuração de integração; após iniciar o Codex, você pode escolher o modelo diretamente.

Volte para o [Centro de Configuração do Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
