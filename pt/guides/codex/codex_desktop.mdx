Codex Desktop compartilha `~/.codex/config.toml` com Codex CLI.

## 1. Obter API Key

Abra a [lista de aplicativos do Ace Data Cloud](https://platform.acedata.cloud/console/applications), acesse o aplicativo disponível e copie a API Key.

![Obter Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configurar API Key

macOS：

```bash
launchctl setenv ACEDATACLOUD_API_KEY "sua API Key"
```

Windows PowerShell：

```powershell
setx ACEDATACLOUD_API_KEY "sua API Key"
```

## 3. Configurar AceDataCloud

Edite `~/.codex/config.toml` (no Windows é `%USERPROFILE%\.codex\config.toml`), adicione:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

No Windows, altere as duas últimas linhas para:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Não é necessário preencher `model`; após abrir o Codex, selecione diretamente o modelo.

## 4. Reiniciar e Verificar

Saia completamente e reabra o Codex Desktop, crie uma nova tarefa local e envie uma mensagem simples. O Provider deve ser exibido como `acedatacloud`; chamadas reais podem ser vistas em [Histórico de Uso](https://platform.acedata.cloud/console/usages).

Se a configuração não tiver efeito, confirme se você modificou o `~/.codex/config.toml` do usuário atual, se a variável de ambiente foi configurada e reinicie completamente o aplicativo novamente. Tarefas em nuvem ou automações que rodam em ambientes diferentes precisam ter a Key configurada separadamente em cada ambiente.
