---
title: "Guia de Configuração do Codex CC Switch"
description: "Codex API guide - Ace Data Cloud"
---

CC Switch pode gerenciar o provider e a API Key do Codex através de uma interface gráfica.

## 1. Obter API Key

Abra a [lista de aplicativos do Ace Data Cloud](https://platform.acedata.cloud/console/applications), acesse os aplicativos disponíveis e copie a API Key.

![Obter Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalar CC Switch

Baixe e instale a partir do [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), ou execute no macOS:

```bash
brew install --cask cc-switch
```

## 3. Adicionar provider

1. Abra o CC Switch e mude para **Codex**.
2. Clique em **Add Provider** e selecione **Custom**.
3. Preencha:

| Campo       | Conteúdo                             |
| ----------- | ------------------------------------ |
| Nome        | `acedatacloud`                      |
| URL Base    | `https://api.acedata.cloud/v1`     |
| API Key     | A API Key do Ace Data Cloud que você acabou de copiar |

Se o CC Switch oferecer um editor de configuração personalizada, a configuração deve permanecer como:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"
requires_openai_auth = true
```

O CC Switch salvará a API Key em `~/.codex/auth.json`:

```json
{
  "OPENAI_API_KEY": "{token}"
}
```

Não adicione `env_key` ou `[model_providers.acedatacloud.auth]` no provider acima; a configuração manual e a configuração do CC Switch são alternativas. Não é necessário fixar `model`, você pode escolher diretamente no Codex.

## 4. Ativar e Verificar

Ative o provider `acedatacloud`, saia completamente e reinicie o Codex ou o VS Code. Execute `/model`, confirme se o Provider é `acedatacloud`, em seguida, escolha um modelo e envie uma mensagem simples.

Se retornar 401, confirme se o `acedatacloud` está ativado e verifique se a `OPENAI_API_KEY` em `~/.codex/auth.json` é a API Key do Ace Data Cloud que você acabou de copiar. Os registros de chamadas podem ser visualizados em [Histórico de Uso](https://platform.acedata.cloud/console/usages).
