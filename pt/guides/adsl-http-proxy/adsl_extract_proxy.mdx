Este documento apresenta principalmente o fluxo de uso da operação da ADSL Proxy API, com a qual podemos facilmente extrair o IP da ADSL e adicionar IPs à lista branca da ADSL Proxy.

## Fluxo de Solicitação

Para usar a extração do IP da ADSL e adicionar IPs à lista branca da ADSL Proxy, primeiro você pode acessar a página da [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/adsl-extract) e da [ADSL Proxy Whitelist API](https://platform.acedata.cloud/documents/adsl-whitelist) e clicar no botão "Adquirir" para obter as credenciais necessárias para a solicitação:

![](https://cdn.acedata.cloud/nyq0xz.png)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, convidando-o a se registrar e fazer login. Após o registro e login, você será redirecionado de volta para a página atual.

Na primeira solicitação, haverá um crédito gratuito disponível, permitindo o uso gratuito dessa API.

## Extração do IP da ADSL

Em seguida, você pode preencher o conteúdo correspondente na interface da [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/adsl-extract), e a seguir, demonstraremos como extrair o IP da ADSL.

### Configurando o Cabeçalho e o Corpo da Solicitação

**Cabeçalhos da Solicitação** incluem:

- `accept`: especifica que a resposta deve ser no formato JSON, preenchido como `application/json`.
- `authorization`: a chave para chamar a API, que pode ser selecionada diretamente após a solicitação.

**Corpo da Solicitação** inclui:

- `number`: a quantidade de IPs da ADSL a serem extraídos, padrão é 1.
- `type`: o tipo de IP da ADSL a ser extraído, dividido principalmente em `http` e `socks`, padrão é `http`.
- `province`: a província onde o IP será extraído, padrão é aleatório.
- `city`: a cidade onde o IP será extraído, padrão é aleatório.

Para os parâmetros `province` e `city`, há requisitos específicos, eles devem corresponder, por exemplo, `city`: Nanchang deve corresponder a `province`: Jiangxi, e precisam estar alinhados com a província, as regras específicas são as seguintes:

### 使用代理

> 注意：使用提取到的代理 IP 之前，请务必添加 IP 白名单，否则无法使用，关于添加白名单的说明请参考下文内容。

Curl 示例代码：

```shell
curl -x 115.219.4.171:23456 myip.vpsnb.net # http proxy
curl --socks5 115.219.3.54:23457 myip.vpsnb.net # socks proxy
```

Python 示例代理：

```python
import requests
import socks
import socket
import time

def test_http_proxy(proxy):
    try:
        start_time = time.time()
        response = requests.get(
            'http://httpbin.org/ip', proxies={'http': proxy, 'https': proxy}, timeout=100)
        elapsed_time = time.time() - start_time
        print(response)
        if response.status_code == 200:
            print(f"HTTP Proxy {proxy} success. time: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"HTTP Proxy {proxy} failed. code: {response.status_code}")
    except Exception as e:
        print(f"HTTP Proxy {proxy} failed: {str(e)}")

def test_socks_proxy(proxy):
    proxy_parts = proxy.split(':')
    if len(proxy_parts) != 2:
        print(f"SOCKS failed: {proxy}")
        return

    host, port = proxy_parts
    port = int(port)

    try:
        start_time = time.time()
        socks.set_default_proxy(socks.SOCKS5, host, port)
        socket.socket = socks.socksocket
        response = requests.get('http://httpbin.org/ip', timeout=10)
        elapsed_time = time.time() - start_time

        if response.status_code == 200:
            print(f"SOCKS Proxy {proxy} success. time: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"SOCKS Proxy {proxy} failed. code: {response.status_code}")
    except Exception as e:
        print(f"SOCKS Proxy {proxy} failed: {str(e)}")
    finally:
        socks.set_default_proxy()
        socket.socket = socket.socket

if __name__ == "__main__":
    # HTTP Proxy
    http_proxy = "http://115.219.4.171:23456"
    test_http_proxy(http_proxy)

    # SOCKS Proxy
    socks_proxy = "115.219.3.54:23457"
    test_socks_proxy(socks_proxy)

```

在第一次使用该接口时，我们至少需要填写三个内容，一个是 `authorization`，直接在下拉列表里面选择即可。另一个参数是 `ip`， `ip` 就是我们需要使用上文提取到的 IP 代理的本机网络地址。最后一个参数是`action`，`action` 是我们对白名单进行的操作，这里是对白名单进行添加的操作。

同时您可以注意到右侧有对应的调用代码生成，您可以复制代码直接运行，也可以直接点击「Try」按钮进行测试。

<p><img src="https://cdn.acedata.cloud/cs5ib2.png" width="500" class="m-auto"></p>

Código de exemplo em Python:

```python
import requests

url = "https://api.acedata.cloud/adsl/whitelist"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "ip": "113.112.122.132",
    "action": "add"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

调用之后，我们发现返回结果如下：

```json
{
  "success": true
}
```

返回结果一共有一个字段，介绍如下：

- `success `，此处操作结果的状态。

其中 `success` 是包含了操作结果的状态，我们可以看到将 IP `113.112.122.132` 已经成功添加到白名单内。

## Tratamento de Erros

在调用 API 时，如果遇到错误，API 会返回相应的错误代码和信息。例如：

- `400 token_mismatched`：Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`：Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`：Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`：Too many requests, you have exceeded the rate limit.
- `500 api_error`：Internal server error, something went wrong on the server.
