Este documento apresenta a integração e a utilização da API Nano Banana Images. Essa interface oferece dois recursos: **geração de imagens (generate)** e **edição de imagens (edit)**.

## Processo de Solicitação

Para utilizar a API Nano Banana Images, primeiro acesse o [painel de controle do Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter seu API Token e deixá-lo disponível para uso posterior.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não estiver conectado ou registrado, será redirecionado automaticamente para a página de login, onde será convidado a se registrar e fazer login. Após a conclusão, você retornará automaticamente à página atual.

**Um único API Token é suficiente para acessar todos os serviços da plataforma, sem a necessidade de solicitar um token separadamente para cada serviço.** Na primeira solicitação, você receberá uma cota gratuita para experimentar o serviço sem custos; quando a cota for insuficiente, você poderá adicionar saldo geral no [painel de controle](https://platform.acedata.cloud/console/coin).

> 📘 Documentação completa: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## Visão Geral da Interface

- **URL Base**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **Método de autenticação**：incluir `authorization: Bearer {token}` no HTTP Header
- **Cabeçalhos da solicitação**：
  - `accept: application/json`
  - `content-type: application/json`
- **Ação (action)**：
  - `generate`：gerar imagens com base em prompts de texto
  - `edit`：editar imagens com base em imagens fornecidas
- **Modelo (model)** (opcional)：
  - `nano-banana` (padrão): baseado no Gemini 2.5 Flash Image, com alta velocidade e baixo custo
  - `nano-banana-2-lite`: baseado no Gemini 3.1 Flash Lite Image, suporta apenas 1K e oferece alta velocidade de geração
  - `nano-banana-2`: baseado no Gemini 3.1 Flash Image Preview, qualidade de nível Pro + velocidade Flash
  - `nano-banana-2.1`: modelo de imagem eficiente de nova geração, compatível com geração e edição de imagens em 1K, 2K e 4K
  - `nano-banana-pro`: baseado no Gemini 3 Pro Image Preview, com qualidade máxima
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`: versões dos canais oficiais dos modelos correspondentes, com melhor qualidade de imagem e estabilidade, mas com cobrança diferente
- **Retorno de chamada assíncrono**：opcional, permite receber notificações de conclusão da tarefa e resultados por meio de `callback_url`
- **Quantidade de imagens**：opcional, permite especificar de 1 a 4 imagens por meio de `count`, sendo 1 imagem por padrão; cada imagem é concluída por uma chamada de geração independente; falhas técnicas comuns ou recusas de segurança do provedor afetam apenas a chamada correspondente, enquanto as demais imagens geradas com sucesso são retornadas normalmente, e a cobrança é calculada de acordo com a quantidade real de imagens geradas com sucesso

## Início Rápido: Gerar Imagens (`action=generate`)

**Parâmetros mínimos obrigatórios**: `action`, `prompt`

Quando você quiser gerar imagens diretamente com base em um prompt, basta definir `action` como `generate` e fornecer um `prompt` claro.

### Exemplo de solicitação (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Exemplo de solicitação (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Exemplo de resposta bem-sucedida

```json
{
  "success": true,
  "task_id": "70e6931b-6e34-43db-9e36-8765e2809d04",
  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {
      "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
      "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }
  ]
}
```

### Descrição dos campos

- `success`：indica se a solicitação foi bem-sucedida.
- `task_id`：ID da tarefa.
- `trace_id`：ID de rastreamento da cadeia, utilizado para facilitar a investigação de problemas.
- `count`：quantidade de imagens solicitadas para geração ou edição, com suporte de 1 a 4, sendo 1 por padrão. `data` contém apenas as imagens geradas com sucesso, e a cobrança é calculada com base na quantidade efetivamente retornada. Cada chamada de geração utiliza obrigatoriamente as políticas de segurança nativas do provedor; a recusa de uma chamada não afeta as demais chamadas bem-sucedidas. Se todas as chamadas forem recusadas, será retornado o código 403.
- `data[]`：lista de resultados.
  - `prompt`：prompt utilizado para a geração (retornado na resposta).
  - `image_url`：URL direta da imagem gerada.

> Observação: `/nano-banana/images` precisa apenas de `action` e `prompt` para gerar imagens.

## Editar Imagens (`action=edit`)

Quando você quiser editar uma imagem existente, defina `action` como `edit` e transmita a lista de links das imagens que deseja editar (uma ou várias imagens) por meio de `image_urls`, fornecendo também um `prompt` que descreva o objetivo da edição.

Por exemplo, aqui fornecemos uma foto de uma pessoa e uma foto de uma roupa. Para fazer com que a pessoa vista essa roupa, podemos transmitir simultaneamente os links das imagens e definir a ação como `edit`. A URL pode ser uma URL HTTP, ou seja, um link público e acessível por meio dos protocolos `https` ou `http`, ou também pode ser uma imagem codificada em Base64, como `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Exemplo de solicitação (cURL)
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Exemplo de solicitação (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Exemplo de resposta bem-sucedida

```json
{
  "success": true,
  "task_id": "93f11baf-347b-4bb4-9520-8653cb46d6a3",
  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",
  "data": [
    {
      "prompt": "let this man wear on this T-shirt",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/8e9e0253-26f4-45b9-b3f8-ac1aed1c284b.png"
    }
  ]
}
```

### Descrição dos campos

- `image_urls[]`: lista de URLs das imagens a serem editadas (devem estar acessíveis publicamente). É possível enviar várias imagens; o serviço combinará esses materiais com o `prompt` para concluir a edição.
- Os demais campos são iguais aos retornados em «Gerar imagem».

## Callback assíncrono (opcional, recomendado)

A geração ou edição pode levar algum tempo. Para evitar manter conexões longas ocupando recursos, recomenda-se utilizar **callbacks Webhook** por meio de `callback_url`:

1. Adicione `callback_url` ao corpo da solicitação, por exemplo, o endereço do Webhook do seu servidor (deve estar acessível publicamente e aceitar POST JSON).
2. A API retornará **imediatamente** uma resposta contendo `task_id` (ou um resultado básico).
3. Quando a tarefa for concluída, a plataforma enviará o JSON completo para `callback_url` por meio de uma solicitação `POST`. Você poderá associar a solicitação ao resultado usando `task_id`.

**Exemplo de carga útil do callback** (a estrutura dos campos é igual à da resposta síncrona bem-sucedida):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Tratamento de erros

Quando uma chamada falha, é retornado um formato de erro padrão com um ID de rastreamento. Os erros mais comuns são:

- **400 `token_mismatched`**: solicitação inválida ou erro nos parâmetros.
- **400 `api_not_implemented`**: interface não implementada (entre em contato com o suporte).
- **401 `invalid_token`**: falha na autenticação ou ausência do Token.
- **403 `forbidden`**: a política de segurança nativa do provedor recusou a solicitação ou o resultado gerado. Essa chamada não retornará uma imagem nem será cobrada; solicitações com várias imagens ainda poderão retornar resultados e cobrar por outras chamadas bem-sucedidas.
- **429 `too_many_requests`**: limite de frequência de solicitações excedido.
- **500 `api_error`**: erro no servidor.

### Exemplo de resposta de erro

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Comparação de parâmetros e observações

- **Obrigatórios**: `action`, `prompt`
- **Específico para edição**: `image_urls` (array, com pelo menos 1 item)
- **Opcionais**: `model` (padrão `nano-banana`, opções `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-2.1`, `nano-banana-pro`; exceto `nano-banana-2.1`, também existem versões oficiais correspondentes do canal oficial com o sufixo `:official`), `aspect_ratio` (`auto` ou uma proporção específica, como `1:1`, `16:9`), `resolution` (resolução, como `1K`, `2K`, `4K`; `nano-banana-2-lite` suporta apenas `1K`), `callback_url` (usado para callbacks assíncronos)
- **Headers**: é obrigatório fornecer `authorization: Bearer {token}`; recomenda-se definir `accept` como `application/json`
- **Acessibilidade das imagens**: `image_urls` deve conter links diretos acessíveis publicamente (HTTP/HTTPS); recomenda-se utilizar HTTPS
- **Idempotência e rastreamento**: mantenha `task_id` e `trace_id` para facilitar a investigação de falhas e a associação dos resultados

Ao transmitir explicitamente `"aspect_ratio": "auto"`, o sistema selecionará a predefinição mais próxima com base na proporção, orientação ou layout indicado no prompt. Isso se aplica tanto à geração quanto à edição. Por exemplo, se o prompt mencionar «miniatura do YouTube», poderá ser selecionada a proporção `16:9`. Se o prompt não especificar dimensões ou a seleção automática não estiver disponível, a geração de texto para imagem utilizará o formato padrão, enquanto a edição de imagens seguirá a primeira imagem de referência, utilizando a proporção suportada mais próxima. Se esse campo for omitido, será utilizado o formato padrão ou a proporção da imagem de referência. Quando já houver uma exigência explícita de formato, transmita diretamente a proporção específica.
