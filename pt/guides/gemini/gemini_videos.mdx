Este documento apresentará as instruções de integração da API de Geração de Vídeos Gemini, que pode gerar vídeos do Google Gemini (omni-flash) através da entrada de palavras-chave de texto (e imagens de referência opcionais).

## Processo de Solicitação

Para usar a API de Geração de Vídeos Gemini, primeiro acesse o [Painel de Controle da Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter seu Token de API, que deve ser mantido em segurança.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, onde será convidado a se registrar e fazer login. Após a conclusão, você será redirecionado de volta para a página atual.

**Um Token de API é suficiente para acessar todos os serviços da plataforma, não sendo necessário solicitar um para cada serviço individualmente.** A primeira solicitação oferece um crédito gratuito para que você possa experimentar; quando o crédito estiver baixo, você pode recarregar o saldo geral no [painel de controle](https://platform.acedata.cloud/console/coin).

> 📘 Documentação Completa: [API de Geração de Vídeos Gemini →](https://platform.acedata.cloud/documents/gemini-videos)

## Uso Básico

Primeiro, entenda a forma básica de uso, inserindo a palavra-chave `prompt`, o modelo `model` e a proporção `aspect_ratio`, e você poderá gerar o vídeo correspondente.

Aqui, configuramos os Cabeçalhos da Solicitação, incluindo:

- `accept`: o formato de resposta desejado, que deve ser preenchido como `application/json`, ou seja, formato JSON.
- `authorization`: a chave para chamar a API, que pode ser selecionada diretamente após a solicitação.

Além disso, configuramos o Corpo da Solicitação, incluindo:

- `prompt`: a descrição do conteúdo do vídeo que você deseja gerar, **obrigatório**.
- `model`: o modelo para gerar o vídeo, atualmente apenas `omni-flash` é suportado, sendo o padrão `omni-flash`.
- `aspect_ratio`: a proporção do vídeo gerado, podendo ser `16:9` (paisagem) ou `9:16` (retrato), sendo o padrão `16:9`.
- `resolution`: a resolução de saída opcional, podendo ser `720p` ou `1080p`, sendo o padrão `720p`.
- `image_urls`: um array de links de imagens de referência opcionais, usados para guiar a geração do vídeo; campos vazios serão ignorados. Quando usar `video_urls` para edição de vídeo, este parâmetro é obrigatório (pelo menos uma imagem).
- `video_urls`: um array de links de vídeos de referência opcionais (máximo de 1), usados para **edição de vídeo / referência de vídeo**; se fornecido, deve ser acompanhado de pelo menos uma `image_urls`.
- `callback_url`: endereço de callback assíncrono; ao ser configurado, a API retornará imediatamente um `task_id`, e quando a tarefa for concluída, o resultado será enviado para esse endereço.
- `async`: opcional, se definido como `true`, a interface retornará imediatamente um `task_id`, sem necessidade de fornecer `callback_url`, e você poderá consultar o resultado através da interface de consulta de tarefas correspondente.

Clique no botão "Try" para realizar o teste, e o resultado obtido será semelhante ao seguinte:

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://platform2.cdn.acedata.cloud/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "Uma cena cinematográfica de um gatinho perseguindo uma borboleta em um jardim ensolarado"
    }
  ],
  "started_at": 1784112953.856,
  "finished_at": 1784113021.328,
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

O resultado retornado contém vários campos, descritos a seguir:

- `success`: se a solicitação de geração de vídeo foi bem-sucedida.
- `task_id`: o ID da tarefa de geração de vídeo.
- `trace_id`: o ID de rastreamento da solicitação, usado para solucionar problemas.
- `data`: lista de resultados do vídeo gerado.
  - `id`: identificador único do vídeo gerado.
  - `video_url`: link para o vídeo gerado (sendo `state` `pending`, será `null`).
  - `state`: o estado da tarefa de geração de vídeo, podendo ser `pending` / `succeeded` / `failed`.
  - `aspect_ratio`: a proporção do vídeo, consistente com os parâmetros da solicitação.
  - `prompt`: a palavra-chave usada para gerar o vídeo.

Na resposta síncrona, o nível superior também incluirá `started_at`, `finished_at`, `elapsed` (tempo gasto, em segundos) e `cost` (custo desta operação, em Créditos).

Precisamos apenas obter o vídeo gerado através do link `video_url` no resultado `data`.

O código correspondente em CURL é o seguinte:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Uma cena cinematográfica de um gatinho perseguindo uma borboleta em um jardim ensolarado",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

O código correspondente em Python é o seguinte:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "Uma cena cinematográfica de um gatinho perseguindo uma borboleta em um jardim ensolarado",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Vídeo Gerado a partir de Imagens

Se você deseja gerar um vídeo com base em imagens de referência, pode passar um ou mais links de imagens em `image_urls`, que serão usados para guiar a geração do vídeo:

```json
{
  "prompt": "A mulher lentamente se vira e sorri para a câmera, brisa suave",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3.png"
  ]
}
```

## Edição de Vídeo / Vídeo de Referência (Entrada de vídeo, Geração de vídeo)

Suporta diretamente "inserir um vídeo e gerar um novo vídeo": passe um link de vídeo de referência em `video_urls` (máximo de 1) e **simultaneamente** forneça pelo menos uma imagem de referência em `image_urls` (exigência rigorosa), e então use `prompt` para descrever o efeito de edição desejado (alterar estilo, mudar cena, adicionar ou remover elementos, etc.).

Aqui está um exemplo completo e real — transformar um vídeo de praia ensolarada em uma cena de inverno com neve caindo, mantendo a disposição da praia, coqueiros e pequenos barcos. A edição de vídeo leva mais tempo (neste exemplo, cerca de 6,5 minutos), portanto, usamos `async: true` para enviar a solicitação de forma assíncrona:
```json
{
  "prompt": "Transforme esta praia tropical ensolarada em uma cena de inverno nevado com neve caindo pesadamente e céu nublado; mantenha a mesma praia, palmeiras e disposição dos barcos.",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://platform2.cdn.acedata.cloud/seedance/dd3dc063-3383-4f29-bedc-e771a096758c.mp4"
  ],
  "async": true
}
```

Após o envio, a interface retorna imediatamente `task_id`:

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

Depois, use esse `task_id` como `id` para consultar a [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks), após a conclusão da tarefa, você poderá obter o novo vídeo gerado (este é o resultado real deste exemplo):

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://platform2.cdn.acedata.cloud/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "Transforme esta praia tropical ensolarada em uma cena de inverno nevado com neve caindo pesadamente e céu nublado; mantenha a mesma praia, palmeiras e disposição dos barcos."
    }
  ],
  "started_at": 1784084482.914,
  "finished_at": 1784084877.09,
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Se precisar de um resultado em maior definição, você pode definir `resolution` como `1080p` (os outros parâmetros permanecem os mesmos).

> Dica: Os links de mídia de entrada / saída no exemplo são resultados gerados reais. **Os links de vídeos e imagens gerados pela plataforma têm um prazo de validade, após o qual expiram**, por favor, baixe e salve em seu armazenamento assim que obtiver os resultados.

> Atenção: O vídeo de referência pode ser no máximo 1; e ao fornecer `video_urls`, deve-se fornecer pelo menos uma `image_urls`, caso contrário, retornará o seguinte erro de parâmetro:

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (pelo menos uma imagem de referência) é necessária quando video_urls é fornecido."
  }
}
```

## Callback Assíncrono

A geração de vídeo requer um certo tempo de processamento. Se você não quiser manter uma conexão longa esperando, pode passar um `callback_url`, nesse caso, a API retornará imediatamente `task_id`, e após a conclusão da tarefa, enviará o resultado final para esse endereço via POST:

```json
{
  "prompt": "Uma cena cinematográfica de um gatinho perseguindo uma borboleta em um jardim ensolarado",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

O resultado retornado imediatamente é o seguinte:

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## Consultar Resultados da Tarefa

Se você usou callback assíncrono ou deseja consultar o status da tarefa ativamente, pode usar a [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) para consultar o status e resultados mais recentes da tarefa com base no `task_id`:

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

O resultado retornado após a conclusão da tarefa é semelhante ao seguinte, a estrutura de `response.data` é a mesma que durante a geração síncrona (durante a geração, `state` é `pending`, `video_url` é `null`):

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
  "type": "videos",
  "request": {
    "model": "omni-flash",
    "prompt": "Um time-lapse de nuvens sobre montanhas nevadas ao amanhecer",
    "aspect_ratio": "16:9",
    "async": true
  },
  "response": {
    "success": true,
    "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
    "data": [
      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
        "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4",
        "state": "succeeded",
        "aspect_ratio": "16:9",
        "prompt": "Um time-lapse de nuvens sobre montanhas nevadas ao amanhecer"

}
```

## Tratamento de Erros

Quando a solicitação apresenta problemas, a API retornará o código de erro correspondente e a descrição, os mais comuns são:

- `400`: Parâmetros da solicitação estão incorretos, como falta de `prompt` ou valor de `aspect_ratio` inválido.
- `401`: Falha na autenticação, token inválido ou incompatível com a API.
- `403`: Saldo insuficiente, ou a frase de solicitação foi rejeitada pela revisão de conteúdo.
- `500`: Erro interno do servidor ou falha na geração upstream.
