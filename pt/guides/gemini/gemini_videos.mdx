Este documento apresentará as instruções de integração da API de Geração de Vídeos Gemini, que pode gerar vídeos do Google Gemini (omni-flash) através da entrada de palavras-chave de texto (e imagens de referência opcionais).

## Processo de Solicitação

Para usar a API de Geração de Vídeos Gemini, primeiro acesse o [Painel de Controle da Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter seu Token de API, que deve ser guardado para uso futuro.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login, onde será convidado a se registrar e fazer login. Após a conclusão, você será redirecionado de volta para a página atual.

**Um Token de API é suficiente para acessar todos os serviços da plataforma, não sendo necessário solicitar um para cada serviço.** A primeira solicitação oferece um crédito gratuito para que você possa experimentar; quando o crédito estiver baixo, você pode recarregar o saldo geral no [painel de controle](https://platform.acedata.cloud/console/coin).

> 📘 Documentação Completa: [API de Geração de Vídeos Gemini →](https://platform.acedata.cloud/documents/gemini-videos)

## Uso Básico

Primeiro, entenda a forma básica de uso, inserindo a palavra-chave `prompt`, o modelo `model` e a proporção `aspect_ratio`, e você poderá gerar o vídeo correspondente.

Aqui, configuramos os Cabeçalhos da Solicitação, incluindo:

- `accept`: o formato de resposta desejado, que deve ser preenchido como `application/json`, ou seja, formato JSON.
- `authorization`: a chave para chamar a API, que pode ser selecionada diretamente após a solicitação.

Além disso, configuramos o Corpo da Solicitação, incluindo:

- `prompt`: a descrição do conteúdo do vídeo que você deseja gerar, **obrigatório**.
- `model`: o modelo para gerar o vídeo, atualmente apenas `omni-flash` é suportado, sendo o padrão `omni-flash`.
- `aspect_ratio`: a proporção do vídeo gerado, podendo ser `16:9` (paisagem) ou `9:16` (retrato), sendo o padrão `16:9`.
- `resolution`: a resolução de saída opcional, podendo ser `720p` ou `1080p`, sendo o padrão `720p`.
- `image_urls`: um array de links de imagens de referência opcionais, usados para guiar a geração do vídeo; campos vazios serão ignorados. Quando usar `video_urls` para edição de vídeo, este parâmetro é obrigatório (pelo menos uma imagem).
- `video_urls`: um array de links de vídeos de referência opcionais (máximo de 1), usados para **edição de vídeo / referência de vídeo**; se fornecido, deve haver pelo menos uma `image_urls`.
- `callback_url`: endereço de callback assíncrono; ao configurá-lo, a API retornará imediatamente `task_id`, e quando a tarefa for concluída, o resultado será enviado para esse endereço.
- `async`: opcional, se definido como `true`, a interface retornará imediatamente `task_id`, sem necessidade de fornecer `callback_url`, e você poderá consultar o resultado através da interface de consulta de tarefas correspondente.

Clique no botão "Try" para realizar o teste, e o resultado obtido será semelhante ao seguinte:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

O resultado retornado contém vários campos, descritos a seguir:

- `success`: se a solicitação de geração de vídeo foi bem-sucedida.
- `task_id`: o ID da tarefa de geração de vídeo.
- `trace_id`: o ID de rastreamento da solicitação, usado para solucionar problemas.
- `data`: lista de resultados do vídeo gerado.
  - `id`: identificador único do vídeo gerado.
  - `video_url`: endereço do link do vídeo gerado.
  - `state`: estado da tarefa de geração de vídeo, podendo ser `pending` / `succeeded` / `failed`.

Precisamos apenas obter o vídeo gerado através do link `video_url` no resultado `data`.

O código correspondente em CURL é o seguinte:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

O código correspondente em Python é o seguinte:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Vídeo a partir de Imagem

Se você deseja gerar um vídeo com base em imagens de referência, pode passar um ou mais links de imagens em `image_urls`, que serão usados para guiar a geração do vídeo:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## Edição de Vídeo / Vídeo de Referência

Suporta edição direta de vídeos existentes ou referência: passe um link de vídeo de referência em `video_urls` (máximo de 1) e **simultaneamente** forneça pelo menos uma imagem de referência em `image_urls` (exigência rígida). Você pode descrever o efeito de edição desejado através de `prompt` (alterar estilo, mudar cena, adicionar ou remover elementos, etc.):

```json
{
  "prompt": "Restyle the video into cinematic anime, keep the motion",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ],
  "video_urls": [
    "https://cdn.acedata.cloud/example-source.mp4"
  ]
}
```

> Nota: máximo de 1 vídeo de referência; e ao fornecer `video_urls`, deve haver pelo menos uma `image_urls` (caso contrário, retornará erro de parâmetro).

## Callback Assíncrono

A geração de vídeo requer um certo tempo de processamento. Se você não deseja manter uma conexão longa esperando, pode passar `callback_url`, nesse caso a API retornará imediatamente `task_id`, e quando a tarefa for concluída, enviará o resultado final para esse endereço:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

O resultado retornado imediatamente será:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Consultar Resultados da Tarefa

Se você usou callback assíncrono ou deseja consultar o status da tarefa ativamente, pode usar a [API de Tarefas Gemini](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) para consultar o status e os resultados mais recentes da tarefa com base no `task_id`.

## Tratamento de Erros

Quando ocorre um problema na solicitação, a API retornará o código de erro correspondente e a descrição, sendo os mais comuns os seguintes:
- `400`: Parâmetros da solicitação estão incorretos, como falta de `prompt` ou valor de `aspect_ratio` inválido.
- `401`: Falha na autenticação, token inválido ou não corresponde à API.
- `403`: Saldo insuficiente ou a palavra-chave atingiu a revisão de conteúdo e foi rejeitada.
- `500`: Erro interno do servidor ou falha na geração upstream.
