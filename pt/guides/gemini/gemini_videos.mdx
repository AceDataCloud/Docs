Este documento apresenta as instruções para integração com a Gemini Videos Generation API, que permite gerar vídeos Google Gemini (omni-flash) a partir de prompts de texto (e opcionalmente, imagens de referência).

## Processo de Solicitação

Para usar a API, é necessário solicitar o serviço na página correspondente do [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos). Após acessar a página, clique no botão 「Acquire」, conforme ilustrado:

![](https://cdn.acedata.cloud/q6ytrc.png)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login/registro. Após o login ou registro, será retornado à página atual.

Na primeira solicitação, há uma cota gratuita disponível, permitindo uso gratuito da API.

## Uso Básico

Primeiramente, entenda a forma básica de uso: envie um prompt `prompt`, o modelo `model` e a proporção de aspecto `aspect_ratio` para gerar o vídeo correspondente.

Aqui, configuramos os cabeçalhos da requisição (`Request Headers`), incluindo:

- `accept`: define o formato de resposta desejado, aqui como `application/json` (JSON).
- `authorization`: sua chave de API, que pode ser selecionada na lista suspensa após a solicitação.

Além disso, configuramos o corpo da requisição (`Request Body`), incluindo:

- `prompt`: descrição do conteúdo do vídeo a ser gerado, **obrigatório**.
- `model`: modelo de geração de vídeo, atualmente apenas `omni-flash`, que é o padrão.
- `aspect_ratio`: proporção de aspecto do vídeo, opcional `16:9` (paisagem) ou `9:16` (retrato), padrão `16:9`.
- `image_urls`: array opcional de links de imagens (ou vídeos) de referência, usados para orientar a geração. Caso vazio, será ignorado.
- `callback_url`: URL de callback assíncrono. Ao configurar, a API retornará imediatamente um `task_id`, e ao concluir o processamento, enviará o resultado via POST para esse endereço.

Clique em 「Try」 para testar, obtendo um resultado semelhante a este:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

A resposta contém vários campos, explicados a seguir:

- `success`: indica se a solicitação de geração do vídeo foi bem-sucedida.
- `task_id`: ID da tarefa de geração de vídeo.
- `trace_id`: ID de rastreamento da requisição, útil para diagnóstico.
- `data`: lista de resultados de vídeos gerados.
  - `id`: identificador único do vídeo gerado.
  - `video_url`: link para o vídeo gerado.
  - `state`: status da tarefa, podendo ser `pending`, `succeeded` ou `failed`.

Basta acessar o `video_url` na resposta para obter o vídeo gerado.

Código CURL correspondente:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Código Python equivalente:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Geração de Vídeo a partir de Imagens

Para gerar vídeos com base em imagens de referência, envie um ou mais links de imagens em `image_urls`:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## Callback Assíncrono

A geração de vídeo pode levar algum tempo. Para evitar manter conexão aberta, utilize `callback_url`. Assim, a API retornará imediatamente um `task_id`, e ao concluir, enviará o resultado ao endereço especificado:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Resposta imediata:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Consultar Resultado da Tarefa

Se usar callback ou desejar consultar o status manualmente, utilize a [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) com o `task_id` para obter o status mais recente e resultados.

## Tratamento de Erros

Em caso de problemas, a API retornará códigos de erro e mensagens correspondentes, como:

- `400`: parâmetros inválidos, como ausência de `prompt` ou `aspect_ratio` com valor inválido.
- `401`: falha na autenticação, token inválido ou incompatível.
- `403`: saldo insuficiente ou conteúdo do prompt rejeitado pela revisão.
- `500`: erro interno do servidor ou falha na geração upstream.
