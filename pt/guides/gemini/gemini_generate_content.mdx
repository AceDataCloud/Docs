O Google Gemini é um sistema de diálogo de IA muito poderoso, capaz de gerar respostas fluentes e naturais em segundos por meio de prompts de entrada. Este documento descreve principalmente como usar a API Gemini Generate Content, que é o formato de API nativo oficial do Google e oferece suporte aos dois endpoints `generateContent` e `streamGenerateContent`.

## Diferenças em relação à API Chat Completions

A API Gemini Generate Content usa o formato de solicitação nativo oficial do Google (campo `contents`), em vez do formato compatível com OpenAI (campo `messages`). Se você já usa o SDK do Google Gemini ou está familiarizado com o formato oficial da API, pode usar esta API diretamente sem modificar o formato da solicitação.

## Escopo de suporte atual

A interface aceita entradas de texto, imagem, vídeo e áudio (`inlineData` ou `fileData`), configurações de raciocínio e declarações de funções personalizadas. Campos nativos como saída de áudio, ferramentas integradas e cache explícito de contexto ainda não têm garantia de disponibilidade unificada; consulte o retorno real de cada modelo específico.

Ao enviar arquivos como áudio usando `fileData.fileUri`, certifique-se de que o arquivo possa ser acessado diretamente via HTTPS, sem depender de estado de login, e de que o período de validade do link assinado cubra todo o tempo de processamento da solicitação. A análise de áudio não fluida só retorna resultados após o modelo concluir o processamento, podendo exceder 90 segundos; o cliente deve definir um tempo limite total suficientemente longo de acordo com o tamanho do arquivo e o cenário de negócio, evitando desconectar enquanto o servidor ainda está processando.

## Processo de solicitação

Antes de usar a API Gemini Generate Content, acesse a página [Gemini Generate Content API](https://platform.acedata.cloud/documents/gemini-generate-content-api) e clique no botão "Obter" para receber as credenciais necessárias para a solicitação.

Se você ainda não estiver conectado ou registrado, será redirecionado automaticamente para a página de login. A primeira solicitação terá uma cota gratuita.

## Uso básico

### Non-Streaming (não fluido)

Envie uma solicitação POST para `/v1beta/models/{model}:generateContent`:

> **Dica**: a série `gemini-3.x` flash consiste em modelos de raciocínio, que primeiro consomem reasoning tokens; defina `generationConfig.maxOutputTokens` como 512 ou mais, caso contrário poderá retornar apenas conteúdo vazio.

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "你好，请介绍一下你自己"
          }
        ]
      }
    ]
  }'
```

Exemplo de resultado retornado:

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [
          {
            "text": "你好！很高兴与你交流。"
          }
        ]
      },
      "finishReason": "MAX_TOKENS"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 6,
    "candidatesTokenCount": 19,
    "thoughtsTokenCount": 489,
    "totalTokenCount": 514
  },
  "usage": {
    "prompt_tokens": 6,
    "completion_tokens": 19,
    "total_tokens": 514,
    "thoughts_tokens": 489,
    "cost": {
      "amount": 0.008860916380159999,
      "currency": "credit",
      "list_amount": 0.009631430847999998
    }
  },
  "modelVersion": "gemini-3.5-flash",
  "model": "gemini-3.5-flash"
}
```

Os campos de token em `usageMetadata` são cobrados de acordo com a semântica nativa do Gemini:

- `promptTokenCount` inclui `cachedContentTokenCount`; a parte com acerto de cache é calculada pelo preço de leitura de cache e não é contabilizada novamente como entrada comum.
- `promptTokensDetails` e `cacheTokensDetails` serão normalizados como `text_tokens`, `image_tokens`, `video_tokens`, `audio_tokens` e os respectivos detalhes `cached_*` em `usage.prompt_tokens_details`. Esses valores estão incluídos respectivamente em `prompt_tokens` e `cached_tokens`; diferentes modalidades são recalculadas apenas de acordo com seus próprios preços, sem cobrança duplicada.
- Tanto `candidatesTokenCount` quanto `thoughtsTokenCount` são calculados pelo preço de tokens de saída.
- `toolUsePromptTokenCount` consiste em tokens independentes de entrada de ferramentas, calculados pelo preço de tokens de entrada.

A Ace Data Cloud retorna adicionalmente o objeto `usage` normalizado, que lê de forma unificada o custo desta chamada em `usage.cost` entre protocolos de modelos. `cost` é uma prévia opcional de custo; quando a prévia de preço estiver temporariamente indisponível, a resposta do modelo ainda será retornada normalmente, mas poderá não incluir esse campo. A fatura final prevalece de acordo com os registros de uso.

### Streaming (fluido)

Envie uma solicitação POST para `/v1beta/models/{model}:streamGenerateContent?alt=sse`:

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "写一首关于春天的诗"
          }
        ]
      }
    ]
  }'
```

O retorno fluido retornará o conteúdo gradualmente no formato SSE (Server-Sent Events). Os eventos intermediários normalmente contêm apenas conteúdo incremental; o evento final com uso autoritativo incluirá `usageMetadata` e o `usage` normalizado, e o custo continuará localizado em `usage.cost`:

```text
data: {"candidates":[{"content":{"parts":[{"text":"Hello!"}],"role":"model"},"index":0}],"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

data: {"candidates":[{"content":{"parts":[],"role":"model"},"finishReason":"STOP","index":0}],"usageMetadata":{"promptTokenCount":7,"candidatesTokenCount":89,"totalTokenCount":96},"usage":{"prompt_tokens":7,"completion_tokens":89,"total_tokens":96,"cost":{"amount":0.00026161075472,"currency":"credit","list_amount":0.000284359516}},"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

```

O fechamento da conexão indica o fim do fluxo; o fluxo nativo do Gemini não enviará `data: [DONE]`. Se a prévia de preço final estiver temporariamente indisponível, `usage` ainda retornará o uso de tokens, mas omitirá `cost`.

## Funcionalidades avançadas

### Instruções do sistema

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "你好"}]
    }
  ],
  "systemInstruction": {
    "parts": [{"text": "你是一个专业的诗人，所有回复都用诗歌形式。"}]
  }
}
```

### Configuração de geração

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "讲一个故事"}]
    }
  ],
  "generationConfig": {
    "temperature": 0.7,
    "maxOutputTokens": 1024,
    "topP": 0.9,
    "topK": 40
  }
}
```

### Modo JSON

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {
          "text": "列出三个中国城市及其人口"
        }
      ]
    }
  ],
  "generationConfig": {
    "responseMimeType": "application/json",
    "responseSchema": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "city": {
            "type": "string"
          },
          "population": {
            "type": "integer"
          }
        }
      }
    }
  }
}
```

### Modo de pensamento (Thinking)

Os modelos que suportam a funcionalidade de pensamento (como gemini-2.5-flash e gemini-2.5-pro) podem ativar o modo de pensamento:

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "解释量子纠缠"}]
    }
  ],
  "generationConfig": {
    "thinkingConfig": {
      "includeThoughts": true,
      "thinkingBudget": 2048
    }
  }
}
```

### Chamada de função

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "北京现在的天气怎么样？"}]
    }
  ],
  "tools": [
    {
      "functionDeclarations": [
        {
          "name": "get_weather",
          "description": "获取指定城市的天气信息",
          "parameters": {
            "type": "object",
            "properties": {
              "city": {
                "type": "string",
                "description": "城市名称"
              }
            },
            "required": ["city"]
          }
        }
      ]
    }
  ]
}
```

### Conversa com múltiplos turnos

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "你好，我叫小明"}]
    },
    {
      "role": "model",
      "parts": [{"text": "你好小明！很高兴认识你。"}]
    },
    {
      "role": "user",
      "parts": [{"text": "我叫什么名字？"}]
    }
  ]
}
```

### Compreensão de imagens

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {"text": "描述这张图片"},
        {
          "inlineData": {
            "mimeType": "image/jpeg",
            "data": "base64_encoded_image_data..."
          }
        }
      ]
    }
  ]
}
```

## Configurações de segurança

O filtro de conteúdo pode ser controlado por meio de `safetySettings`:

```json
{
  "contents": [...],
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_ONLY_HIGH"
    }
  ]
}
```

## Tratamento de erros

| Código de status HTTP | Significado             |
| -------- | -------------- |
| 400      | Parâmetros da solicitação inválidos         |
| 401      | Falha na autenticação, verifique o Token |
| 403      | Conteúdo bloqueado pelo filtro de segurança     |
| 429      | Solicitações muito frequentes         |
| 500      | Erro interno do servidor        |
