A principal função da API de Tarefas QR Artístico é consultar o status de execução de uma tarefa através do ID da tarefa gerado pela API de Geração QR Artístico.

Este documento irá detalhar as instruções de integração da API de Tarefas QR Artístico, ajudando você a integrar facilmente e aproveitar ao máximo as poderosas funcionalidades dessa API. Com a API de Tarefas QR Artístico, você pode consultar facilmente o status de execução das tarefas da API de Geração QR Artístico.

## Processo de Solicitação

Para usar a API de Tarefas QR Artístico, você precisa primeiro ir à página de solicitação [API de Geração QR Artístico](https://platform.acedata.cloud/documents/qrart-generate) para solicitar o serviço correspondente e, em seguida, copiar o ID da tarefa da API de Geração QR Artístico, como mostrado na imagem:

<p><img src="https://cdn.acedata.cloud/2wicjy.png" width="500" className="m-auto" /></p>

Por fim, acesse a página da API de Tarefas QR Artístico [API de Tarefas QR Artístico](https://platform.acedata.cloud/documents/qrart-tasks) para solicitar o serviço correspondente. Após acessar a página, clique no botão "Adquirir", como mostrado na imagem:

![Página de Solicitação](https://cdn.acedata.cloud/rci31i.png)

Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a [página de login](https://platform.acedata.cloud), convidando-o a se registrar e fazer login. Após o registro e login, você será redirecionado automaticamente de volta para a página atual.

Na primeira solicitação, haverá um crédito gratuito disponível, permitindo que você use essa API gratuitamente.

## Exemplo de Solicitação

A API de Tarefas QR Artístico pode ser usada para consultar o resultado de uma API da API de Geração QR Artístico. Para saber como usar a API de Geração QR Artístico, consulte o documento [API de Geração QR Artístico](https://platform.acedata.cloud/documents/qrart-generate).

Usaremos um exemplo de ID de tarefa retornado pelo serviço da API de Geração QR Artístico. Suponha que temos um ID de tarefa: e2c65b20-a970-431e-99c1-76721e799df8, a seguir, demonstraremos como passar um ID de tarefa.

### Configurando Cabeçalhos e Corpo da Solicitação

**Cabeçalhos da Solicitação** incluem:

- `accept`: especifica que a resposta deve ser no formato JSON, preenchido como `application/json`.
- `authorization`: chave para chamar a API, que pode ser selecionada diretamente após a solicitação.

**Corpo da Solicitação** inclui:

- `id`: ID da tarefa enviada.
- `action`: modo de operação da tarefa.

Configuração conforme mostrado na imagem abaixo:

<p><img src="https://cdn.acedata.cloud/use825.png" width="500" className="m-auto" /></p>

### Exemplo de Código

Pode-se notar que, no lado direito da página, já foram gerados automaticamente códigos em várias linguagens, como mostrado na imagem:

<p><img src="https://cdn.acedata.cloud/jejwy6.png" width="500" className="m-auto" /></p>

Alguns exemplos de código são os seguintes:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/qrart/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "e2c65b20-a970-431e-99c1-76721e799df8",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/qrart/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "e2c65b20-a970-431e-99c1-76721e799df8",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Erro de tratamento

Ao chamar a API, se encontrar um erro, a API retornará o respectivo código de erro e informações. Por exemplo:

- `400 token_mismatched`：Solicitação inválida, possivelmente devido a parâmetros ausentes ou inválidos.
- `400 api_not_implemented`：Solicitação inválida, possivelmente devido a parâmetros ausentes ou inválidos.
- `401 invalid_token`：Não autorizado, token de autorização inválido ou ausente.
- `429 too_many_requests`：Muitas solicitações, você excedeu o limite de taxa.
- `500 api_error`：Erro interno do servidor, algo deu errado no servidor.

### Exemplo de resposta de erro

