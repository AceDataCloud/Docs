`POST https://api.acedata.cloud/wan/tasks` é usado para consultar, consultar em lote ou excluir tarefas de vídeo Wan. A consulta de tarefas não cobra taxas de geração repetidas.

## Consulta de uma única tarefa

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

A `response.data.video_url` da tarefa concluída é o endereço CDN permanente; `response.usage` contém a resolução, segundos de vídeo de entrada/saída, taxa de quadros e proporção; `response.cost` é a liquidação da tarefa gerada.

## Consulta em lote

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Retorna `{ "items": [...], "count": 2 }`. Quando a tarefa está em andamento, pode não haver `finished_at` e `response` final.

## Excluir registro de tarefa

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

A exclusão afeta apenas o histórico da tarefa, não excluirá o vídeo CDN já gerado.
