O OpenAI ChatGPT é um sistema de diálogo de IA muito poderoso; basta inserir um prompt para gerar respostas fluentes e naturais em apenas alguns segundos. O ChatGPT se destaca no setor por sua excelente capacidade de compreensão e geração de linguagem. Hoje, o ChatGPT já é amplamente utilizado em diversos setores e áreas, e sua influência está se tornando cada vez mais significativa. Seja em conversas cotidianas, escrita criativa, consultas profissionais ou programação de código, o ChatGPT pode fornecer uma assistência inteligente surpreendente, melhorando enormemente a eficiência de trabalho e a criatividade humanas.

Este documento apresenta principalmente o processo de uso das operações da API OpenAI Chat Completion; com ela, podemos usar facilmente a funcionalidade de diálogo do OpenAI ChatGPT oficial.

## GPT-6.1 Sol

Use `model: "gpt-6.1-sol"` para selecionar este modelo. Suporta saída em streaming, chamada de funções, saída estruturada e entrada de imagens. Durante a primeira semana de abertura, estará disponível apenas para detentores verificados de ACE T1+ (pelo menos 100.000 ACE) ou usuários autorizados; o horário específico de abertura está sujeito ao aviso de acesso no console.

Os níveis de raciocínio suportam `low`, `medium`, `high`, `xhigh` e `max`; `none` ou `minimal` ainda não são suportados. Recomenda-se começar com `reasoning_effort: "low"`. Quando a entrada exceder 272.000 tokens, o preço de contexto longo será aplicado à solicitação inteira; as taxas estão sujeitas ao preço atual no console.

## Processo de solicitação

Para usar a API OpenAI Chat Completion, primeiro acesse o [Console Ace Data Cloud](https://platform.acedata.cloud/console/applications) para obter seu API Token e guarde-o para uso posterior.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não estiver conectado ou registrado, será automaticamente redirecionado para a página de login, onde será convidado a se registrar e entrar; após concluir, retornará automaticamente à página atual.

**Um único API Token pode chamar todos os serviços da plataforma, sem necessidade de solicitar separadamente para cada serviço.** Na primeira solicitação, será concedida uma cota gratuita para experimentação; quando a cota for insuficiente, você poderá recarregar o saldo universal no [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentação completa: [OpenAI Chat Completion API →](https://platform.acedata.cloud/documents/openai-chat-completions)

## Uso básico

Em seguida, você pode preencher o conteúdo correspondente na interface, como mostrado na imagem:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

Ao usar esta interface pela primeira vez, precisamos preencher pelo menos três conteúdos. Um deles é `authorization`, que pode ser selecionado diretamente na lista suspensa. Outro parâmetro é `model`; `model` é a categoria de modelo do site oficial OpenAI ChatGPT que escolhemos usar. Aqui, temos principalmente 20 modelos, e você pode consultar os modelos que fornecemos para mais detalhes. O último parâmetro é `messages`; `messages` é o array de prompts que inserimos. Ele é um array, indicando que vários prompts podem ser enviados ao mesmo tempo. Cada prompt contém `role` e `content`, onde `role` representa o papel do solicitante. Fornecemos três identidades: `user`, `assistant` e `system`. O outro, `content`, é o conteúdo específico da nossa pergunta.

Ao mesmo tempo, você pode observar que há a geração do código de chamada correspondente no lado direito. Você pode copiar o código e executá-lo diretamente, ou clicar diretamente no botão 「Try」 para testar.

Parâmetros opcionais comuns:

- `max_tokens`: limita o número máximo de tokens em uma única resposta.
- `temperature`: aleatoriedade da geração, entre 0 e 2; quanto maior o valor, mais divergente.
- `n`: quantas respostas candidatas gerar de uma vez.
- `response_format`: configuração do formato de retorno.

## Resposta em streaming

Esta interface também oferece suporte a respostas em streaming, o que é muito útil para integração com páginas web, permitindo que a página web implemente um efeito de exibição palavra por palavra.

Se desejar retornar respostas em streaming, você pode alterar o parâmetro `stream ` no cabeçalho da solicitação para `true`.

A modificação é mostrada na imagem; no entanto, o código de chamada precisa ter as alterações correspondentes para oferecer suporte a respostas em streaming.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

Após modificar `stream` para `true`, a API retornará os dados JSON correspondentes linha por linha. No nível do código, precisamos fazer as modificações correspondentes para obter os resultados linha por linha.

Código de chamada de exemplo em Python:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Se você quiser integrar a funcionalidade de conversa com múltiplas rodadas, será necessário enviar várias perguntas no campo `messages`; um exemplo específico de várias perguntas é mostrado na imagem abaixo:

Código de chamada de exemplo em Python:
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
```

## Integração com OpenAI-Python

A API OpenAI Chat Completion mantém compatibilidade com a interface oficial da OpenAI, sendo possível integrar diretamente usando o SDK oficial [OpenAI-Python](https://github.com/openai/openai-python). Este artigo apresentará brevemente a forma de uso.

1. Primeiro, é necessário configurar um ambiente local de `Python`; esse processo pode ser pesquisado no Google.
2. Baixe e instale o ambiente de desenvolvimento, por exemplo, o editor VSCode.
3. Configure as variáveis de ambiente da `OpenAI`.

- Na pasta do projeto, crie e salve um arquivo chamado `.env`
- Conteúdo do arquivo `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # Novamente: se você usar a chave da OpenAI oficial, não use este endereço.
```

Substitua `sk-xxx` pela sua própria chave. `OPENAI_BASE_URL` é a interface de proxy para acessar a OpenAI.

4. Instale os pacotes de dependência do projeto

```shell
pip install openai
```

No Mac OS, o comando é:

```shell
pip3 install openai
```

5. Crie um arquivo de código-fonte de exemplo

Suponha que criamos um código de exemplo `index.py`, cujo conteúdo específico é o seguinte:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Modelo visual

gpt-4o é um grande modelo de linguagem multimodal desenvolvido pela OpenAI, que adiciona capacidade de compreensão visual com base no GPT-4. Este modelo pode processar simultaneamente entradas de texto e imagem, realizando compreensão e geração multimodais.

O processamento de texto usando o modelo gpt-4o é consistente com o conteúdo de uso básico acima. A seguir, será apresentado brevemente como usar a capacidade de processamento de imagens do modelo.

A capacidade de processamento de imagens do modelo gpt-4o é usada principalmente adicionando um campo `type` com base no conteúdo original de `content`. Por meio desse campo, é possível saber se o que foi enviado é texto ou imagem, utilizando assim a capacidade de processamento de imagens do modelo gpt-4o. A seguir, será explicado principalmente como chamar essa funcionalidade por meio de Curl e Python.

- Método de script Curl

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

- Método de script Python
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"

payload = {

        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
```

## Tratamento de erros

Ao chamar a API, caso ocorra um erro, a API retornará o código de erro e as informações correspondentes. Por exemplo:

- `400 token_mismatched`: Bad request, possivelmente devido a parâmetros ausentes ou inválidos.
- `400 api_not_implemented`: Bad request, possivelmente devido a parâmetros ausentes ou inválidos.
- `401 invalid_token`: Não autorizado, token de autorização inválido ou ausente.
- `429 too_many_requests`: Solicitações em excesso, você excedeu o limite de taxa.
- `500 api_error`: Erro interno do servidor, algo deu errado no servidor.

### Exemplo de resposta de erro

```
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
