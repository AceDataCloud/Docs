Serviço de vetores de palavras da OpenAI, usado para gerar resultados de vetores de palavras que representam o texto de entrada.

Este documento apresenta principalmente o processo de uso das operações da API de Embeddings da OpenAI. Com ela, podemos criar vetores de embedding que representam o texto de entrada.

## Processo de solicitação

Para usar a API de Embeddings da OpenAI, primeiro obtenha seu API Token no [Console do Ace Data Cloud](https://platform.acedata.cloud/console/applications) e guarde-o para uso posterior.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não tiver feito login ou se registrado, será automaticamente redirecionado para a página de login, onde será convidado a se registrar e fazer login. Após a conclusão, você retornará automaticamente à página atual.

**Um único API Token permite chamar todos os serviços da plataforma, sem necessidade de solicitar separadamente para cada serviço.** A primeira solicitação inclui créditos gratuitos para uma experiência sem custo; quando os créditos forem insuficientes, você poderá recarregar o saldo universal no [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentação completa: [OpenAI Embeddings API →](https://platform.acedata.cloud/documents/openai-embeddings)

## Uso básico

Em seguida, você pode preencher o conteúdo correspondente na interface, conforme mostrado na imagem:

<p><img src="https://cdn.acedata.cloud/4qtbvr.png" width="500" className="m-auto" /></p>

Ao usar esta interface pela primeira vez, precisamos preencher pelo menos três conteúdos. Um deles é `authorization`, que pode ser selecionado diretamente na lista suspensa. Outro parâmetro é `model`; `model` é a categoria de modelo oficial da OpenAI que escolhemos usar. Os modelos atualmente disponíveis são `text-embedding-3-small` e `text-embedding-3-large`. O `text-embedding-ada-002` deixou de ser fornecido; se índices vetoriais existentes usam esse modelo antigo, os vetores dos novos modelos não podem ser misturados diretamente e é necessário recriar o índice. O último parâmetro é `input`; `input` é o texto que precisamos converter em vetores de palavras.

Ao mesmo tempo, você pode observar que há uma geração de código de chamada correspondente no lado direito. Você pode copiar o código e executá-lo diretamente, ou clicar diretamente no botão «Try» para testar.

Parâmetros opcionais:

- `dimensions`: reduz a dimensão do vetor; por padrão, retorna a dimensão completa.
- `encoding_format`: formato de retorno, podendo ser `float` ou `base64`.

<p><img src="https://cdn.acedata.cloud/gqulm9.png" width="500" className="m-auto" /></p>

Código de chamada de exemplo em Python:

```python
import requests

url = "https://api.acedata.cloud/openai/embeddings"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "The food was delicious and the waiter...",
    "model": "text-embedding-3-small",
    "encoding_format": "float"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

O resultado retornado possui vários campos, apresentados a seguir:

- `model`, o modelo usado nesta conversão de texto em vetor de palavras.
- `usage`, as informações de token usadas nesta conversão de texto em vetor de palavras.
- `data`, o resultado do vetor de palavras após a conversão do texto.

Entre eles, `data` contém as informações específicas dos vetores de palavras correspondentes ao texto, e seu `embedding` é o resultado específico do vetor de palavras gerado.

## Tratamento de erros

Ao chamar a API, se ocorrer um erro, a API retornará o código e as informações de erro correspondentes. Por exemplo:

- `400 token_mismatched`: Solicitação incorreta, possivelmente devido a parâmetros ausentes ou inválidos.
- `400 api_not_implemented`: Solicitação incorreta, possivelmente devido a parâmetros ausentes ou inválidos.
- `401 invalid_token`: Não autorizado, token de autorização inválido ou ausente.
- `429 too_many_requests`: Muitas solicitações, você excedeu o limite de taxa.
- `500 api_error`: Erro interno do servidor, algo deu errado no servidor.

### Exemplo de resposta de erro

```json
{

  "error": {

    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
