## 1. Obter a API Key

Abra a [lista de aplicativos Ace Data Cloud](https://platform.acedata.cloud/console/applications), entre em um aplicativo disponível e copie a API Key.

## 2. Editar usando URL de imagem

Imagem original:

![Imagem original para edição com GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

## 3. Carregar imagem local

Use `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

É possível enviar repetidamente `image`; a série GPT Image oferece suporte a até 16 imagens de referência. O `image` em solicitações JSON pode ser uma única URL ou um array de URLs; arquivos locais são carregados usando multipart.

## 4. Usar máscara para edição local

A interface oficial Images Edit especifica as áreas permitidas para modificação por meio de `mask`. Os modelos `:official` da Ace Data Cloud seguem o mesmo contrato multipart:

- `mask` deve ser um PNG com canal Alpha, com tamanho máximo de 4MB;
- o tamanho da máscara deve ser exatamente igual ao da primeira `image`;
- pixels transparentes com Alpha igual a `0` indicam que a edição é permitida, e pixels não transparentes indicam que devem ser preservados;
- imagens RGB que possuem apenas cores preto e branco, mas não possuem canal de transparência, não podem ser usadas como máscaras válidas;
- o prompt deve descrever a imagem completa esperada e, ao mesmo tempo, deixar claras as modificações locais e o conteúdo que deve permanecer inalterado.

A seguir, primeiro gere uma máscara a partir da imagem original. O exemplo define o retângulo central como transparente, permitindo que o modelo modifique apenas essa área:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Em seguida, carregue a imagem original e a máscara juntas:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Também é possível continuar usando a forma de chamada `images.edit` do SDK Python oficial da OpenAI; basta apontar `base_url` para a Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Atualmente, `mask` é fornecida como um campo de arquivo multipart. Quando for necessário enviar a imagem original por URL, também altere a solicitação para multipart: `image` pode continuar como um campo de texto de URL, e `mask` é carregada usando `@mask.png`. A máscara restringirá a área de edição, mas o modelo de geração ainda poderá fazer uma fusão natural nas bordas; quando limites rigorosos forem necessários, use bordas Alpha nítidas e repita no prompt quais conteúdos devem permanecer inalterados.

As formas de chamada acima são consistentes com os exemplos de máscara da [API OpenAI Image Edit](https://developers.openai.com/api/reference/python/resources/images/methods/edit) e do [Cookbook oficial do GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Parâmetros comuns

| Campo                | Descrição                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (mais rápido) ou `gpt-image-2.5-sunburst` (maior fidelidade e controle); todos os três podem selecionar a variante `:official` correspondente, e `gpt-image-2` também oferece suporte a `:reverse` |
| `image`           | JSON usa uma única URL ou um array de até 16 URLs; multipart usa um ou mais campos de arquivo `image`                                                                    |
| `prompt`          | Instrução de edição                                                                                                                             |
| `size`            | `auto` ou `WIDTHxHEIGHT` que esteja em conformidade com as limitações                                                                                                     |
| `n`               | 1–10; quando `response_format=b64_json`, apenas 1 é suportado                                                                                           |
| `response_format` | `url` ou `b64_json`                                                                                                               |
| `callback_url`    | Endereço opcional de callback assíncrono                                                                                                                         |

As regras de tamanho são consistentes com a interface de geração: a largura e a altura devem ser múltiplos de 16, o lado maior não pode exceder 3840, o total de pixels deve ser 655.360–8.294.400, e a proporção entre largura e altura não pode exceder 3:1. Quando `size` é omitido ou `auto` é usado, o modelo seleciona o formato com base no prompt e na primeira imagem de referência.
`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` e `gpt-image-2:reverse` são cobrados pelo número de imagens bem-sucedidas; `gpt-image-2:official`, `gpt-image-2.5-flare:official` e `gpt-image-2.5-sunburst:official` são liquidados com base nos Tokens reais da entrada de texto, da entrada de imagem de referência e da saída de imagem, prevalecendo os registros de uso finais.

## 6. Callback assíncrono e depuração

Tarefas longas podem adicionar à solicitação:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

A resposta assíncrona 200 é `{"task_id": "..."}`; após a conclusão, o resultado final é retornado por callback. Solicitações síncronas retornam `created` e `data`.

| Status  | Verificação                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Formato/quantidade de imagens, combinação de parâmetros e formato de dimensões; ao usar `mask`, verifique o canal Alpha do PNG, o limite de 4 MB e se suas dimensões são iguais às da primeira imagem original |
| 401 | API Key e Bearer Header                                           |
| 429 | Frequência de solicitações                                                              |
| 504 | Use callback assíncrono                                                            |

As respostas de erro incluirão `trace_id`. Ao relatar problemas, forneça esse ID, não forneça a API Key.

Os campos completos e as enumerações em tempo real estão sujeitos à página [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Para gerar imagens apenas a partir de texto, consulte [Geração de imagens GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
