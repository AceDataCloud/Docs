## 1. Obter API Key

Abra a [lista de aplicativos da Ace Data Cloud](https://platform.acedata.cloud/console/applications), acesse os aplicativos disponíveis e copie a API Key.

![Obter Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Editar usando URL da imagem

Imagem original:

![GPT Image 2 Editar Imagem Original](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer sua API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Mantenha a caneca, a mesa, o ângulo da câmera, o layout retrato e a sombra suave inalterados. Mude apenas a cor da caneca de branca para laranja vívido e o fundo creme pálido para um azul marinho escuro sólido. Sem texto e sem logotipo.",
    "size": "1024x1536"
  }'
```

Resposta de sucesso:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Este é o resultado da edição realizada em 8 de setembro de 2026 através da Ace Data Cloud, a caneca se tornou laranja, o fundo se tornou azul marinho escuro, mantendo a composição original e o tamanho de 1024×1536:

## 3. Fazer upload de imagem local

Usando `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer sua API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Substitua o fundo por um estúdio moderno brilhante"
```

É possível enviar múltiplas imagens, a série GPT Image suporta até 16 imagens de referência. O campo `image` no pedido JSON pode ser uma única URL ou um array de URLs; arquivos locais devem ser enviados via multipart.

## 4. Parâmetros Comuns

| Campo              | Descrição                                                                                                                   |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (mais rápido), `gpt-image-2.5-sunburst` (maior fidelidade e controle), `gpt-image-2:official` ou `gpt-image-2:reverse` |
| `image`           | JSON usa uma única URL ou um array de até 16 URLs; multipart usa um ou mais campos de arquivo `image`                      |
| `prompt`          | Instruções de edição                                                                                                       |
| `size`            | `auto` ou `LARGURAxALTURA` que atenda às restrições                                                                        |
| `n`               | 1–10; apenas 1 é suportado quando `response_format=b64_json`                                                               |
| `response_format` | `url` ou `b64_json`                                                                                                       |
| `callback_url`    | Endereço de callback assíncrono opcional                                                                                   |

As regras de tamanho são as mesmas da interface de geração: largura e altura devem ser múltiplos de 16, a maior dimensão não pode exceder 3840, o total de pixels deve estar entre 655.360 e 8.294.400, e a proporção largura-altura não pode exceder 3:1. Se `size` for omitido ou `auto` for usado, o modelo escolherá a proporção com base nas instruções e na primeira imagem de referência.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` e `:reverse` são cobrados com base no número de imagens geradas; `gpt-image-2:official` é cobrado com base nos tokens de entrada, imagens de referência e saída, sendo o registro de uso o que conta.

## 5. Callback Assíncrono e Depuração

Tarefas longas podem incluir no pedido:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

A resposta assíncrona 200 será `{"task_id": "..."}`; após a conclusão, o resultado final será retornado. Pedidos síncronos retornarão `created` e `data`.

| Status | Verificação                     |
| ------ | ------------------------------- |
| 400    | Formato/número de imagem, combinação de parâmetros e formato de tamanho |
| 401    | API Key e Bearer Header        |
| 429    | Frequência de pedidos           |
| 504    | Use callback assíncrono        |

Respostas de erro incluirão `trace_id`. Ao relatar problemas, forneça esse ID, não forneça a API Key.

Os campos completos e a enumeração em tempo real podem ser consultados na página [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Para geração de imagens em texto puro, consulte [GPT Image 2 / 2.5 Geração de Imagens](https://platform.acedata.cloud/documents/openai-images-generations).
