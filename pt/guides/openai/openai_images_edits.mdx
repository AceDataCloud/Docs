## 1. Obter a API Key

Abra a [lista de aplicações do Ace Data Cloud](https://platform.acedata.cloud/console/applications), entre em uma aplicação disponível e copie a API Key.

![Obter a API Key do Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Editar usando URL da imagem

Imagem original:

![Imagem original para edição do GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

Resposta bem-sucedida:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Este é o resultado da edição efetivamente concluída através do Ace Data Cloud em 8 de setembro de 2026: a caneca tornou-se laranja, o fundo tornou-se azul-marinho escuro, e a composição original e o tamanho 1024×1536 foram mantidos:

![Resultado da edição da caneca laranja do GPT Image 2](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Carregar uma imagem local

Use `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

É possível enviar `image` repetidamente; a série GPT Image suporta no máximo 16 imagens de referência. O `image` em solicitações JSON pode ser uma única URL ou um array de URLs; arquivos locais são carregados usando multipart.

## 4. Parâmetros comuns

| Campo                | Descrição                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (mais rápido) ou `gpt-image-2.5-sunburst` (maior fidelidade e controle); todos os três podem selecionar a variante correspondente `:official`, e `gpt-image-2` também oferece suporte a `:reverse` |
| `image`           | JSON usa uma única URL ou um array de até 16 URLs; multipart usa um ou mais campos de arquivo `image`                                                                    |
| `prompt`          | Instrução de edição                                                                                                                             |
| `size`            | `auto` ou `WIDTHxHEIGHT` que atenda às restrições                                                                                                     |
| `n`               | 1–10; apenas 1 é suportado quando `response_format=b64_json`                                                                                           |
| `response_format` | `url` ou `b64_json`                                                                                                               |
| `callback_url`    | Endereço opcional de callback assíncrono                                                                                                                         |

As regras de tamanho são iguais às da interface de geração: largura e altura devem ser múltiplos de 16, o lado maior não pode exceder 3840, o total de pixels deve ser de 655.360–8.294.400, e a proporção entre largura e altura não pode exceder 3:1. Quando `size` é omitido ou `auto` é usado, o modelo selecionará o formato com base no prompt e na primeira imagem de referência.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` e `gpt-image-2:reverse` são cobrados pelo número de imagens bem-sucedidas; `gpt-image-2:official`, `gpt-image-2.5-flare:official` e `gpt-image-2.5-sunburst:official` são cobrados com base nos Tokens reais de entrada de texto, entrada de imagens de referência e saída de imagens, prevalecendo os registros de uso finais.

## 5. Callback assíncrono e solução de problemas

Tarefas longas podem adicionar o seguinte à solicitação:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

A resposta assíncrona 200 é `{"task_id": "..."}`; após a conclusão, o resultado final será enviado por callback. Solicitações síncronas retornam `created` e `data`.

| Status  | Verificar                      |
| --- | ----------------------- |
| 400 | Formato/quantidade de imagens, combinação de parâmetros e formato de tamanho       |
| 401 | API Key e Header Bearer |
| 429 | Frequência de solicitações                    |
| 504 | Mudar para callback assíncrono                  |

As respostas de erro incluirão `trace_id`. Ao relatar problemas, forneça esse ID, não forneça a API Key.

Para os campos completos e enumerações em tempo real, consulte a página [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Para gerar imagens somente com texto, consulte [Geração de imagens GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
