## 1. Obter API Key

Abra a [lista de aplicações do Ace Data Cloud](https://platform.acedata.cloud/console/applications), entre em uma aplicação disponível e copie a API Key.

![Obter a API Key do Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Enviar a primeira solicitação

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

A imagem da resposta bem-sucedida está em `data[].url`. Abaixo está o resultado de 1024×1536 obtido por meio de uma solicitação real do Ace Data Cloud em 8 de setembro de 2026 (tarefa `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Caneca branca gerada pelo GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Parâmetros comuns

| Campo                | Descrição                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (recomendado por padrão), `gpt-image-2.5-flare` (mais rápido) ou `gpt-image-2.5-sunburst` (maior fidelidade e controle); os três podem selecionar a variante `:official` correspondente, e `gpt-image-2` também oferece suporte a `:reverse` |
| `prompt`          | Descrição da imagem, com no máximo 32.000 caracteres                                                                                                                     |
| `size`            | `auto` ou `WIDTHxHEIGHT`; a largura e a altura devem ser múltiplos de 16, o lado maior não pode exceder 3840, o total de pixels é de 655.360–8.294.400, e a proporção não pode exceder 3:1                                                       |
| `n`               | 1–10; quando `response_format=b64_json`, apenas 1 é suportado                                                                                                 |
| `quality`         | Os modelos GPT Image oferecem suporte a `auto`, `low`, `medium`, `high`; Flare / Sunburst 2.5 / 2.6 (incluindo `:official`) oferecem adicionalmente suporte a `xhigh`, `max`. O canal oficial é cobrado com base no uso real de Tokens             |
| `response_format` | `url` ou `b64_json`                                                                                                                     |
| `callback_url`    | Opcional; envia o resultado para esse endereço após a conclusão de uma tarefa longa                                                                                                                      |

Tamanhos comuns:

| Proporção   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` selecionará o formato com base na proporção, nos pixels e na intenção de layout no prompt; quando forem necessários pixels exatos, preencha diretamente o tamanho.

Os preços exibidos na página do canal oficial da API são estimativas anteriores à solicitação; o valor final é baseado no uso real de tokens e nos registros de uso presentes na resposta.

## 4. Geração de múltiplas imagens

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` e seus aliases `:reverse` são cobrados pelo número de imagens bem-sucedidas; `gpt-image-2:official`, `gpt-image-2.5-flare:official` e `gpt-image-2.5-sunburst:official` são cobrados de acordo com os Tokens reais de entrada de texto e saída de imagem na resposta. O preço na página é uma estimativa antes da solicitação; o valor final é baseado no registro de uso.

## 5. Retorno de chamada assíncrono

Após adicionar `callback_url` ao corpo da solicitação, a interface primeiro retornará `{"task_id": "..."}` e, quando concluída, enviará o resultado final via POST para essa URL; as solicitações síncronas ainda retornam `created` e `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

O receptor do retorno de chamada deve usar `task_id` para deduplicação e verificar a origem da solicitação e o formato dos dados.

## 6. Solução de problemas

| Status  | Verificar                                                  |
| --- | --------------------------------------------------- |
| 400 | Combinação de `model`, `prompt`, formato de tamanho, `n` e `response_format`    |
| 401 | Se a API Key está completa e se o Header é `Authorization: Bearer ...` |
| 429 | Solicitações muito frequentes; tente novamente mais tarde                                         |
| 504 | Tempo esgotado na geração síncrona; use `callback_url`                            |

As respostas de erro incluirão `error.code`, `error.message` e `trace_id`. Ao reportar problemas, forneça `trace_id`, não forneça a API Key.

Os campos completos e as enumerações em tempo real estão sujeitos à página [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Para edição de imagens, consulte [Edição de imagens GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-edits).

## GPT Image 2.6

O GPT Image 2.6 mantém as interfaces de geração, edição, tarefas assíncronas e cobrança da versão 2.5:

| Modelo                                                          | Cobrança                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/imagem                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/imagem                   |
| `gpt-image-2.6-flare:official`                              | Igual ao official 2.5, cobrado pelo uso real de Tokens |
| `gpt-image-2.6-sunburst:official`                           | Igual ao official 2.5, cobrado pelo uso real de Tokens |

A qualidade pode ser `auto`, `low`, `medium`, `high`, `xhigh`, `max`; para o tamanho, use `auto` ou `WIDTHxHEIGHT` que esteja em conformidade com as restrições acima. Esta interface suporta `png`, `jpeg`, `webp`; o GPT Image 2.6 também suporta animações `gif` nativas, mas SVG ainda não é suportado. A edição suporta URLs de imagens JSON e upload de arquivos multipart. `:reverse` é um alias explícito da versão regular de mesmo nome. Use o modelo completo, não envie `gpt-image-2.6`.

### Animações GIF do GPT Image 2.6

As versões regulares, `:reverse` e `:official` do GPT Image 2.6 Flare e Sunburst podem usar `output_format: "gif"`. Os quadros de animação, informações de loop e duração de reprodução serão preservados; `frame_count` representa o número de quadros, `frame_duration_ms` representa os milissegundos por quadro, o número de quadros deve ser um inteiro de 2–16, a duração de cada quadro deve ser um inteiro de 20–655350 milissegundos e ambos são usados apenas para GIF; a codificação é arredondada para os 10 ms mais próximos. Quando não especificado, o padrão é 9 quadros, 200 milissegundos por quadro; quando o `size` do GIF é omitido ou é auto, é usada a predefinição 512x512.

Recomenda-se usar primeiro `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. Os GIFs têm limites independentes de tamanho e número de quadros, e não podem aplicar diretamente as especificações estáticas de 4K; alguns modelos ajustarão o tamanho real da saída. `n` representa o número de arquivos GIF retornados, não o número de quadros de animação. As versões regulares e `:reverse` continuam sendo cobradas pelo número de arquivos bem-sucedidos, enquanto as versões oficiais são cobradas pelo uso real de Tokens.

```json
{
  "model": "gpt-image-2.6-flare",
  "prompt": "A small red ball moves left and right on a white background, seamless looping animation, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### Imagens estáticas 4K do GPT Image 2.6

Flare, Sunburst e suas variantes `:reverse`, `:official` podem usar as predefinições de pixels 4K mencionadas acima, como `3840x2160` e `2160x3840`. Tanto a geração quanto a edição recebem pixels específicos por meio de `size`; `4K` não é um valor `size` válido, e `4096x4096` também excede o limite atual de pixels. As especificações 4K acima se aplicam a PNG/JPEG/WebP estáticos; para GIF, use seus parâmetros específicos.

### Complexidade de composição do GPT Image 2.6

`complexity` pode ser `low`, `medium`, `high`; quando omitido, é usado o padrão `high` do modelo. Ele controla a complexidade do planejamento e é independente da qualidade de renderização de `quality`; não há cobrança adicional por solicitação, e as versões oficiais continuam sendo cobradas pelos Tokens reais. Outros modelos não suportam este parâmetro.

GIF não suporta mask, imagens de anotação, compactação personalizada, reescrita de prompt ou saída parcial de imagem em streaming; combinações incompatíveis serão rejeitadas antes da geração. Tamanho, número de quadros e quantidade estão conjuntamente sujeitos ao limite de orçamento de pixels do modelo; `1024x1024` e 2 quadros do Flare regular foram verificados como utilizáveis, mas essa conclusão não pode ser estendida a todas as combinações 1K ou GIFs 4K.
