## 1. Obter a API Key

Abra a [lista de aplicações do Ace Data Cloud](https://platform.acedata.cloud/console/applications), entre em uma aplicação disponível e copie a API Key.

![Obter a API Key do Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Enviar a primeira solicitação

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

A imagem da resposta bem-sucedida está em `data[].url`. Abaixo está o resultado de 1024×1536 obtido por meio de uma solicitação real via Ace Data Cloud em 8 de setembro de 2026 (tarefa `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Caneca branca gerada pelo GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Parâmetros comuns

| Campo                | Descrição                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (recomendado por padrão), `gpt-image-2.5-flare` (mais rápido) ou `gpt-image-2.5-sunburst` (maior fidelidade e controle); os três podem selecionar a variante `:official` correspondente, e `gpt-image-2` também oferece suporte a `:reverse` |
| `prompt`          | Descrição da imagem, com até 32.000 caracteres                                                                                                                     |
| `size`            | `auto` ou `WIDTHxHEIGHT`; a largura e a altura devem ser múltiplos de 16, o lado maior não pode exceder 3840, o total de pixels deve ser 655.360–8.294.400, e a proporção não pode exceder 3:1                                                       |
| `n`               | 1–10; apenas 1 é compatível quando `response_format=b64_json`                                                                                                 |
| `quality`         | `low`, `medium`, `high` ou `auto`; o suporte e a forma de cobrança variam entre as diferentes rotas                                                                                          |
| `response_format` | `url` ou `b64_json`                                                                                                                     |
| `callback_url`    | Opcional; envia o resultado para esse endereço após a conclusão de tarefas longas                                                                                                                      |

Tamanhos comuns:

| Proporção   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` selecionará o formato com base na proporção, nos pixels e na intenção de layout no prompt; quando forem necessários pixels precisos, preencha diretamente o tamanho.

### Modelos e formas de cobrança

| Modelo                                | Cenários aplicáveis e forma de cobrança                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Canal reverso padrão, cobrança fixa por número de imagens bem-sucedidas                        |
| `gpt-image-2:reverse`             | Seleciona explicitamente o canal reverso, cobrança fixa por número de imagens bem-sucedidas                      |
| `gpt-image-2:official`            | Canal oficial da API, maior estabilidade, cobrado pelo uso real de Tokens            |
| `gpt-image-2.5-flare`             | Foco na velocidade de geração, cobrança fixa por número de imagens bem-sucedidas                        |
| `gpt-image-2.5-flare:official`    | Canal oficial da API, maior estabilidade e foco na velocidade de geração, cobrado pelo uso real de Tokens     |
| `gpt-image-2.5-sunburst`          | Foco em alta fidelidade e controle detalhado, cobrança fixa por número de imagens bem-sucedidas                    |
| `gpt-image-2.5-sunburst:official` | Canal oficial da API, maior estabilidade e foco em alta fidelidade e controle detalhado, cobrado pelo uso real de Tokens |

O preço exibido na página para o canal oficial da API é uma estimativa antes da solicitação; o valor final se baseia no uso real de Tokens na resposta e nos registros de uso.

## 4. Geração de múltiplas imagens

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` e `gpt-image-2:reverse` são cobrados pelo número de imagens bem-sucedidas; `gpt-image-2:official`, `gpt-image-2.5-flare:official` e `gpt-image-2.5-sunburst:official` são cobrados de acordo com os Tokens reais de entrada de texto e saída de imagem na resposta. O preço exibido na página é uma estimativa antes da solicitação, e o valor final se baseia nos registros de uso.

## 5. Callback assíncrono

Após adicionar `callback_url` ao corpo da solicitação, a interface primeiro retornará `{"task_id": "..."}` e, quando concluída, enviará o resultado final via POST para essa URL; solicitações síncronas ainda retornam `created` e `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

O receptor do callback deve usar `task_id` para eliminar duplicatas e verificar a origem da solicitação e o formato dos dados.

## 6. Solução de problemas

| Status  | Verificar                                                  |
| --- | --------------------------------------------------- |
| 400 | Combinação de `model`, `prompt`, formato de tamanho, `n` e `response_format`    |
| 401 | Se a API Key está completa e se o Header é `Authorization: Bearer ...` |
| 429 | Solicitações muito frequentes; tente novamente mais tarde                                         |
| 504 | Tempo limite da geração síncrona; use `callback_url`                            |

A resposta de erro incluirá `error.code`, `error.message` e `trace_id`. Ao relatar problemas, forneça `trace_id`, não forneça a API Key.

Consulte a página [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations) para campos completos e enumerações em tempo real. Para edição de imagens, consulte [Edição de imagens GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-edits).
