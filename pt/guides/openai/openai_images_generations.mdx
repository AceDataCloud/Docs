## 1. Obter API Key

Abra a [lista de aplicativos da Ace Data Cloud](https://platform.acedata.cloud/console/applications), acesse os aplicativos disponíveis e copie a API Key.

![Obter Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Enviar a primeira solicitação

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer sua API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Ilustração editorial mínima de produto: uma caneca de cerâmica branca simples centrada em uma mesa de cobalt blue sólida, fundo creme pálido, sombra suave, formas geométricas limpas, sem texto, sem logotipo, composição retrato",
    "size": "1024x1536"
  }'
```

A imagem da resposta bem-sucedida está localizada em `data[].url`. Abaixo está o resultado de 1024×1536 obtido através de uma solicitação real na Ace Data Cloud em 8 de setembro de 2026 (tarefa `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Caneca branca gerada pelo GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Parâmetros Comuns

| Campo              | Descrição                                                                                                                                    |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (recomendado por padrão), `gpt-image-2.5-flare` (mais rápido) ou `gpt-image-2.5-sunburst` (maior fidelidade e controle); também pode-se escolher explicitamente `gpt-image-2:official` ou `gpt-image-2:reverse` |
| `prompt`          | Descrição da imagem, máximo de 32.000 caracteres                                                                                             |
| `size`            | `auto` ou `LARGURAxALTURA`; largura e altura devem ser múltiplos de 16, lado longo não deve exceder 3840, total de pixels de 655.360–8.294.400, proporção não deve exceder 3:1                             |
| `n`               | 1–10; `response_format=b64_json` suporta apenas 1                                                                                           |
| `quality`         | `low`, `medium`, `high` ou `auto`; diferentes linhas têm suporte e formas de cobrança diferentes                                               |
| `response_format` | `url` ou `b64_json`                                                                                                                        |
| `callback_url`    | Opcional; envia o resultado para este endereço após a conclusão de tarefas longas                                                               |

Tamanhos comuns:

| Proporção | 1K          | 2K          | 4K          |
| --------- | ----------- | ----------- | ----------- |
| 1:1      | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3      | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4      | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9     | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16     | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` escolherá a proporção, pixels e intenção de layout com base no prompt; se precisar de pixels exatos, preencha diretamente o tamanho.

## 4. Geração de Múltiplas Imagens

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer sua API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Uma pequena raposa lendo sob um cogumelo brilhante, ilustração em aquarela",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` e `:reverse` cobram com base no número de imagens geradas; `gpt-image-2:official` é cobrado com base nos tokens reais de entrada de texto e saída de imagem. Os preços na página são estimativas antes da solicitação, o valor final é baseado no registro de uso.

## 5. Callback Assíncrono

Após adicionar `callback_url` ao corpo da solicitação, a interface retornará primeiro `{"task_id": "..."}`, e ao concluir, enviará o resultado final para essa URL via POST; solicitações síncronas ainda retornam `created` e `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "Um cartaz de produto com tipografia clara",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

O receptor do callback deve usar `task_id` para evitar duplicatas e verificar a origem da solicitação e o formato dos dados.

## 6. Solução de Problemas

| Status | Verificação                                               |
| ------ | ------------------------------------------------------- |
| 400    | Combinação de `model`, `prompt`, formato de tamanho, `n` e `response_format` |
| 401    | A API Key está completa? O Header é `Authorization: Bearer ...`? |
| 429    | Solicitações muito frequentes, tente novamente mais tarde |
| 504    | Geração síncrona excedeu o tempo limite; use `callback_url` |

Respostas de erro incluirão `error.code`, `error.message` e `trace_id`. Ao relatar problemas, forneça `trace_id`, não forneça a API Key.

Os campos completos e enumerações em tempo real estão disponíveis na página [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Para edição de imagens, consulte [GPT Image 2 / 2.5 Edição de Imagens](https://platform.acedata.cloud/documents/openai-images-edits).
