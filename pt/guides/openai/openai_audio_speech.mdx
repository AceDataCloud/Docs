---
title: "OpenAI API de Síntese de Voz (/v1/audio/speech)"
description: "OpenAI generation API guide - Ace Data Cloud"
---

Converta texto em voz natural, **totalmente compatível com o `/v1/audio/speech` da OpenAI**. Qualquer SDK da OpenAI pode simplesmente apontar o `base_url` para `https://api.acedata.cloud` e trocar a chave pelo seu Token AceData para uso direto. A interface retorna um fluxo de bytes de áudio de forma síncrona.

- **URL de Requisição**: `POST https://api.acedata.cloud/v1/audio/speech` (também conhecido como `POST /openai/audio/speech`)
- **Autenticação**: Cabeçalho da requisição `Authorization: Bearer {token}`
- **Cobrança**: Cobrança baseada no número de bytes do texto da requisição, cerca de 85% do preço oficial da OpenAI (veja a tabela abaixo).

## Parâmetros da Requisição

| Campo              | Tipo     | Obrigatório | Descrição                                                       |
| ----------------- | ------ | --------- | ------------------------------------------------------------- |
| `input`           | string | Sim       | O texto a ser sintetizado.                                     |
| `model`           | string | Não       | `tts-1` (mais rápido) ou `tts-1-hd` (maior qualidade de áudio, padrão). |
| `voice`           | string | Não       | Um dos seguintes: `alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`, padrão `alloy`. |
| `response_format` | string | Não       | `mp3` (padrão), `opus`, `aac`, `flac`, `wav`, `pcm`.         |
| `speed`           | number | Não       | Velocidade de fala 0.25–4.0, padrão 1.0.                     |

## Exemplo

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/speech' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -o speech.mp3 \
  -d '{
    "model": "tts-1-hd",
    "input": "E se uma API lhe desse todos os modelos de vídeo de IA?",
    "voice": "nova",
    "response_format": "mp3"
  }'
```

O retorno é o próprio arquivo de áudio (`Content-Type: audio/mpeg`), que pode ser escrito diretamente em `speech.mp3` para reprodução.

Usando o SDK Python oficial da OpenAI:

```python
from openai import OpenAI
client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
client.audio.speech.create(model="tts-1-hd", voice="nova", input="Olá da AceData.").stream_to_file("speech.mp3")
```

## Preços

| Modelo        | Preço Oficial da OpenAI | Preço nesta Plataforma (cerca de 85% de desconto) |
| ------------ | ----------------------- | ----------------------------------------------- |
| `tts-1`     | $15 / 1 milhão de caracteres | cerca de $12.75 / 1 milhão de caracteres      |
| `tts-1-hd`  | $30 / 1 milhão de caracteres | cerca de $25.5 / 1 milhão de caracteres       |

> Cobrança baseada no número de bytes do texto da requisição; o campo `official_price` exibe o preço oficial da OpenAI para comparação.

## Códigos de Erro

| Código | code                    | Descrição               |
| ----- | ----------------------- | ---------------------- |
| 400   | `bad_request`           | `input` está vazio ou parâmetros inválidos. |
| 401   | `authentication_failed` | token inválido.        |
| 403   | `used_up`               | Saldo insuficiente.    |
| 429   | `too_many_requests`     | Requisições muito frequentes. |
| 500   | `api_error`             | Erro interno/externo.  |
