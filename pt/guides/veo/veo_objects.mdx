Este documento irá apresentar as instruções de integração da API Veo Objects. Esta interface é utilizada para realizar operações de **adição ou remoção de objetos** em um vídeo Veo já gerado (repaint local baseado em máscara).

## Processo de Solicitação

Para usar a API, é necessário primeiro solicitar na página correspondente do serviço Veo. Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login.

## Uso Básico

Para chamar esta interface, é necessário passar os seguintes parâmetros:

- `video_id` (obrigatório): ID da tarefa do vídeo de origem. **Não pode** ser o vídeo de saída de `/veo/extend`.
- `action` (obrigatório): tipo de operação, `insert` ou `remove`.
- `prompt`:
  - `action=insert`: **obrigatório**, descreve o objeto a ser adicionado.
  - `action=remove`: opcional, descreve o conteúdo a ser removido (principalmente para registro de logs, a área real a ser apagada é determinada por `image_mask`).
- `image_mask`:
  - `action=insert`: opcional. Se não for passado, a IA decidirá automaticamente a posição de inserção; se for passado, será inserido na área de pixels brancos.
  - `action=remove`: **obrigatório**, a área de pixels brancos é o objeto a ser apagado.

`image_mask` aceita dois formatos:

1. Um **endereço de imagem HTTP(S) acessível publicamente** (recomendado).
2. Uma **string JPEG codificada em base64**, que pode ter o prefixo `data:image/jpeg;base64,` ou ser base64 puro.

Exemplo de solicitação (inserir objeto, não passar máscara, deixar a IA localizar automaticamente):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "insert",
    "prompt": "adicionar um porco voador com asas pretas"
  }'
```

Exemplo de solicitação (remover objeto com base na máscara):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "remove",
    "image_mask": "https://example.com/mask.jpg",
    "prompt": "remover a nuvem branca"
  }'
```

A estrutura do resultado retornado é a mesma de `/veo/videos`.

## Instruções de Cobrança

- `action=insert` ou `remove`: 1,50 Crédito / vez.

## Callback Assíncrono

A interface suporta modo assíncrono, passando `callback_url` você pode receber o resultado através de uma solicitação POST após a conclusão da tarefa. Se não houver um endereço de callback público, você também pode definir `async` como `true`, a interface retornará imediatamente `task_id`, e em seguida, você poderá consultar o resultado através da interface de consulta de tarefas correspondente.
