Este documento irá apresentar as instruções de integração da API Veo Extend. Esta interface é utilizada para **extensão de duração** de um vídeo Veo já gerado, onde a IA irá automaticamente continuar a escrever as cenas subsequentes.

## Processo de Solicitação

Para usar a API, é necessário primeiro solicitar na página correspondente do serviço Veo. Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login.

## Uso Básico

Para chamar esta interface, é necessário passar os seguintes parâmetros:

- `video_id` (obrigatório): ID da tarefa do vídeo de origem (proveniente de `/veo/videos` ou da própria interface).
- `model` (obrigatório): modelo utilizado para a extensão, **apenas suporta os modelos `veo31-fast` e `veo31`**, outros modelos não são suportados.
- `prompt` (opcional): texto de sugestão para guiar as cenas da extensão.
- `aspect_ratio` (opcional): `16:9` ou `9:16`, padrão `16:9`.
- `resolution` (opcional): `720p` ou `1080p`.

Exemplo de solicitação:

```shell
curl -X POST 'https://api.acedata.cloud/veo/extend' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "model": "veo31-fast",
    "prompt": "a câmera lentamente se afasta para revelar mais da paisagem"
  }'
```

O resultado retornado é o mesmo que o de `/veo/videos`:

```json
{
  "success": true,
  "task_id": "5fa2d9a6-7e54-481b-a4b0-3dc6f25dd2ab",
  "data": [
    {
      "id": "9b6f3b6b9c45419fbf2e3fe2f10b2b3a",
      "video_url": "https://platform.cdn.acedata.cloud/veo/5fa2d9a6.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

## Limitações Importantes

`video_id` deve ser proveniente da geração da linha TTAPI ou do `data[].id` após a extensão. IDs de vídeos históricos gerados por linhas antigas antes da mudança para TTAPI não podem ser usados nesta interface, e a chamada retornará `400 bad_request`; por favor, gere novamente através de `/veo/videos` antes de estender.

Os vídeos resultantes da extensão de `/veo/extend` podem **continuar a ser estendidos novamente por `/veo/extend`**, mas **não podem** ser processados pelas seguintes interfaces:

- `/veo/reshoot` — não pode mudar o movimento da câmera
- `/veo/objects` — não pode adicionar ou remover objetos

Se o `video_id` fornecido for um resultado de extensão, as interfaces relacionadas retornarão erro 400, por favor, utilize o vídeo original como fonte.

## Instruções de Cobrança

- `model=veo31-fast`: 1.68 Crédito / vez
- `model=veo31`: 12.00 Crédito / vez

## Callback Assíncrono

A interface suporta modo assíncrono, passando `callback_url` você poderá receber o resultado através de uma solicitação POST após a conclusão da tarefa. Se não houver um endereço de callback público, você também pode definir `async` como `true`, a interface retornará imediatamente `task_id`, e você poderá consultar o resultado através da interface de consulta de tarefas correspondente.
