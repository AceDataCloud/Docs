Este documento irá apresentar as instruções de integração da API Veo Upsample. Esta interface é utilizada para realizar upsampling de um vídeo Veo já gerado ou para gerar uma prévia em GIF.

## Processo de Solicitação

Para usar a API, é necessário primeiro solicitar na página correspondente do serviço Veo. Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login.

## Uso Básico

Para chamar esta interface, é necessário passar dois parâmetros:

- `video_id`: ID da tarefa do vídeo de origem. Pode ser o ID de vídeo gerado por qualquer uma das interfaces `/veo/videos`, `/veo/extend`, `/veo/reshoot`, `/veo/objects`.
- `action`: Ação de upsampling, suportando as seguintes três opções:
  - `1080p`: Realiza upsampling do vídeo para resolução 1080p.
  - `4k`: Realiza upsampling do vídeo para resolução 4K.
  - `gif`: Converte o vídeo em uma prévia em GIF.

Exemplo de solicitação:

```shell
curl -X POST 'https://api.acedata.cloud/veo/upsample' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "4k"
  }'
```

O resultado retornado é o mesmo que o de `/veo/videos`, ainda é uma estrutura de tarefa assíncrona, podendo ser consultado o status da tarefa através do `task_id` na interface `/veo/tasks`:

```json
{
  "success": true,
  "task_id": "8f5a90ae-3f86-4c4f-86f7-7126f5e92c76",
  "trace_id": "0f3e09c2-4c2e-46ea-9cdc-a31ec48b7c12",
  "data": [
    {
      "id": "253eedc47f1c4eb2a370ed2312168f4b",
      "video_url": "https://platform.cdn.acedata.cloud/veo/8f5a90ae.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

Descrição dos campos retornados:

- `success`: Indica se a tarefa de upsampling foi submetida com sucesso.
- `task_id`: ID da tarefa de upsampling atual.
- `data`: Resultados do vídeo após o upsampling.
  - `video_url`: Endereço do vídeo após o upsampling.

## Descrição de Cobrança

- `action=1080p`: 0.16 Crédito / vez
- `action=4k`: 0.50 Crédito / vez
- `action=gif`: 0.13 Crédito / vez

Se o `action` passado não estiver entre os enumerados acima, será cobrado como 0.50 Crédito por padrão. Recomenda-se passar explicitamente os valores suportados.

## Callback Assíncrono

A interface também suporta modo assíncrono, passando `callback_url` para receber o resultado através de uma solicitação POST após a conclusão da tarefa. Se não houver um endereço de callback público, também é possível definir `async` como `true`, e a interface retornará imediatamente o `task_id`, permitindo que o resultado seja obtido através da interface de consulta de tarefas correspondente.
