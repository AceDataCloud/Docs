Este documento apresentará as instruções de integração da API Veo Reshoot. Esta interface é utilizada para **regenerar um vídeo Veo já gerado** de acordo com **um novo tipo de movimento de câmera**, mantendo o conteúdo visual consistente, mas a posição e o movimento da câmera serão reinterpretados de acordo com `motion_type`.

## Processo de Solicitação

Para usar a API, é necessário primeiro solicitar na página correspondente do serviço Veo. Se você ainda não estiver logado ou registrado, será redirecionado automaticamente para a página de login.

## Uso Básico

Para chamar esta interface, é necessário passar os seguintes parâmetros:

- `video_id` (obrigatório): ID da tarefa do vídeo de origem. **Não pode** ser um vídeo de saída de `/veo/extend`.
- `motion_type` (obrigatório): novo tipo de movimento de câmera, usando um alias conciso em estilo de sublinhado maiúsculo.

### Valores suportados para `motion_type`

| Alias                             | Significado           |
| ------------------------------ | ------------------- |
| `STATIONARY`                   | Câmera fixa           |
| `STATIONARY_UP`                | Câmera fixa, inclinação para cima |
| `STATIONARY_DOWN`              | Câmera fixa, inclinação para baixo |
| `STATIONARY_LEFT`              | Câmera fixa, movimento para a esquerda |
| `STATIONARY_RIGHT`             | Câmera fixa, movimento para a direita |
| `STATIONARY_DOLLY_IN_ZOOM_OUT` | Câmera fixa, avanço + zoom para fora |
| `STATIONARY_DOLLY_OUT_ZOOM_IN` | Câmera fixa, recuo + zoom para dentro |
| `UP`                           | Câmera subindo        |
| `DOWN`                         | Câmera descendo       |
| `LEFT_TO_RIGHT`                | Câmera se movendo da esquerda para a direita |
| `RIGHT_TO_LEFT`                | Câmera se movendo da direita para a esquerda |
| `FORWARD`                      | Câmera avançando      |
| `BACKWARD`                     | Câmera recuando      |
| `DOLLY_IN_ZOOM_OUT`            | Movimento com avanço + zoom para fora |
| `DOLLY_OUT_ZOOM_IN`            | Movimento com recuo + zoom para dentro |

Exemplo de solicitação:

```shell
curl -X POST 'https://api.acedata.cloud/veo/reshoot' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "motion_type": "LEFT_TO_RIGHT"
  }'
```

A estrutura do resultado retornado é a mesma de `/veo/videos`.

## Instruções de Cobrança

- Refilmagem única: 1,20 Crédito.

## Callback Assíncrono

A interface suporta modo assíncrono, passando `callback_url` você poderá receber o resultado através de uma solicitação POST após a conclusão da tarefa. Se não houver um endereço de callback público, você também pode definir `async` como `true`, a interface retornará imediatamente `task_id`, e você poderá consultar o resultado através da interface de consulta de tarefas correspondente.
