MiMo 2.6 Pro e MiMo 2.6 Flash são modelos da série MiMo da Xiaomi. Esta API usa o formato OpenAI Chat Completions e cobra por tokens de entrada, saída e acertos de cache.

## Modelos e Interface

| Modelo                | Posicionamento           |
| ----------------- | ------------ |
| `mimo-v2.6-pro`   | Análise complexa, raciocínio e chamada de ferramentas |
| `mimo-v2.6-flash` | Conversação diária e tarefas leves    |

Ative o MiMo e obtenha as credenciais de API correspondentes, envie solicitações para `https://api.acedata.cloud/mimo/chat/completions`. O `base_url` do SDK OpenAI pode ser definido como `https://api.acedata.cloud/mimo`. A entrada unificada `/v1/chat/completions` também requer as permissões de serviço correspondentes.

O escopo inicial da interface é Chat Completions de texto; imagens, áudio, vídeo, pesquisa na web, Responses, Messages, Batch e UltraSpeed não estão no escopo desta versão.

## Exemplo em Python

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ACEDATACLOUD_API_KEY"],
    base_url="https://api.acedata.cloud/mimo",
)
response = client.chat.completions.create(
    model="mimo-v2.6-pro",
    messages=[{"role": "user", "content": "解释彩虹形成的原因。"}],
    max_completion_tokens=256,
    extra_body={"thinking": {"type": "disabled"}},
)
print(response.choices[0].message.content)
print(response.usage)
```

O exemplo demonstra a forma de escrever a solicitação; exemplos de respostas reais serão adicionados após a validação do serviço.

## Streaming, Raciocínio e Chamada de Ferramentas

Defina `stream=true` para receber SSE; se precisar do uso final, passe `stream_options={"include_usage": true}`. O cliente deve processar incrementos de conteúdo, conteúdo de raciocínio e chamadas de ferramentas, bem como o evento final de usage.

Use `thinking.type=enabled` para ativar o raciocínio e `disabled` para desativá-lo. `reasoning_content` e o `content` final são retornados separadamente; ao continuar chamadas de ferramentas, preserve o conteúdo de raciocínio na mensagem do assistente, os `tool_calls` completos e o `tool_call_id` correspondente.

Envie apenas declarações de ferramentas com `type=function`, e `tool_choice` suporta apenas `auto`. A aplicação é responsável por executar as ferramentas e retornar os resultados; o retorno de uma chamada de ferramenta pelo modelo não significa que a ferramenta já foi executada. A pesquisa na web integrada ao serviço ainda não está disponível.

## Cobrança

`prompt_tokens` inclui entradas com acerto de cache; `prompt_tokens_details.cached_tokens` é calculado pelo preço de cache, e as demais entradas são calculadas pelo preço normal de entrada. `completion_tokens` inclui a saída de raciocínio; não some tokens de raciocínio novamente. Chamadas de streaming também são liquidadas de acordo com o uso real final.

Os preços estão sujeitos ao console, e o custo em dólares do Credit depende do plano adquirido. Solicitações com falha não devem ser consideradas como concluídas com sucesso; se precisar verificar a cobrança, forneça o identificador de rastreamento na resposta.

## Tratamento de Erros

Para erros de parâmetros, verifique o formato da solicitação; para erros de autenticação ou permissão, verifique as credenciais e o status de ativação do serviço; ao encontrar 429, faça novas tentativas com recuo. Quando não houver capacidade de modelo saudável, poderá ser retornado 503. Se ocorrer uma interrupção após o início da resposta de streaming, primeiro verifique os resultados e o uso já recebidos, para evitar repetir solicitações cegamente.
