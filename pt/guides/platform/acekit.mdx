Você provavelmente também já passou por isso: está usando Claude Code, Cursor ou Codex, programando a todo vapor, e de repente precisa de uma imagem, uma música de fundo, um vídeo curto ou quer que ele pesquise as informações mais recentes. Aí você descobre — o próprio agent não sabe fazer essas coisas. Você precisa procurar APIs, ler documentação, configurar keys, escrever código de chamada e lidar com polling assíncrono por conta própria. Depois de toda essa complicação, a inspiração já esfriou há muito tempo.

[AceKit](https://github.com/AceDataCloud/AceKit) veio justamente para eliminar toda essa complicação. Com uma linha de comando, ele coloca no seu agent de codificação todos os recursos de geração de imagens, geração de vídeos, geração de música, busca na web, conversas com LLM e mais do AceData Cloud. Depois de instalar, você só precisa falar normalmente, e o agent carrega sozinho a habilidade correspondente, se autentica sozinho, faz o polling sozinho e conclui o trabalho.

## Entenda o que ele faz em 30 segundos

Antes de instalar vs. depois de instalar:

| O que você diz               | Antes de instalar                   | Depois de instalar (o agent faz sozinho)                      |
| ------------------ | --------------------- | ----------------------------------- |
| "Dê uma imagem de capa para este README" | o agent não sabe, pede para você procurar uma API de geração de imagens | Chama NanoBanana / Flux / Midjourney para gerar a imagem |
| "Transforme este script em um vídeo curto de 30 segundos"  | não sabe                    | Chama Sora / Veo / Kling / Seedance para gerar o vídeo  |
| "Adicione uma música de fundo a este demo"  | não sabe                    | Chama Suno para gerar a música                           |
| "Pesquise o X mais recente e depois resuma"     | não consegue se conectar à internet                  | Chama Google SERP para obter resultados em tempo real                 |
| "Encurte este link longo"         | não sabe                    | Chama o serviço de links curtos e retorna um link surl.id                  |

Em uma frase: **seu agent de codificação deixa de "só saber escrever código" e passa a "também saber gerar imagens, vídeos, música e pesquisar na internet".**

## Comece em três passos

Todo o processo pode ser concluído em poucos minutos e requer Node.js 18+.

**Primeiro passo · Obtenha um API Token.** Vá ao [console](https://platform.acedata.cloud/console/applications) e copie o Token — todas as capacidades compartilham este único token; a primeira solicitação oferece créditos gratuitos, então você pode testar gratuitamente primeiro.

![Copie o API Token no console](https://cdn.acedata.cloud/dvc3cg.jpg)

**Segundo passo · Instale.** Uma linha de comando:

```bash
npx acekit
```

Ele detectará automaticamente os agents de codificação na máquina e instalará todo o conjunto de habilidades. A execução real é assim (esta máquina só tem o Claude Code instalado):

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> Quando o Token não está configurado, a primeira execução solicitará interativamente que você o cole; você também pode executar antecipadamente `export ACEDATACLOUD_API_TOKEN=seu_token` para instalar de forma totalmente não assistida. A quantidade de habilidades pode mudar conforme as capacidades da plataforma aumentam; use a lista atual exibida por `npx acekit list` como referência.

**Terceiro passo · Fale normalmente.** Recarregue o agent e dê instruções diretamente, por exemplo:

```text
Use a habilidade short-url para encurtar https://platform.acedata.cloud/services
```

O agent carregará a habilidade sozinho, fará a chamada sozinho e fornecerá um resultado real que pode ser acessado.

## Execute de verdade uma vez (com saída)

Os quatro exemplos abaixo são todos **chamadas reais, com resultados retornados na hora**, não demonstrações. O `$KEY` nos comandos é o seu API Token.

**① Encurtar URL (síncrono, resposta em segundos)**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

Retorna `https://surl.id/r/1uKp2kilXQ` — ao abrir, ele faz um redirecionamento 302 de volta para a página original de services.

**② Busca na internet (síncrono)**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

Obtém resultados do Google em tempo real (trecho):

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ Conversa com LLM (síncrono, uma interface conecta mais de 50 modelos)**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP是用于统一管理和交换模型上下文信息的协议。
（39 tokens，本次约 0.00007 credit）
```

**④ Geração de imagem (assíncrono, cerca de 20 segundos, o agent faz polling automaticamente até gerar a imagem)**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

Após cerca de 22 segundos, retorna uma imagem real (HTTP 200 · image/png · 317 KB · cerca de 0.13 credit nesta chamada):

![Imagem realmente gerada pelo AceKit](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

Você, na verdade, não precisa memorizar essas interfaces — depois de instalar as habilidades, o agent montará sozinho as solicitações corretas conforme cada `SKILL.md`, lidará com a autenticação e com o polling. O objetivo acima é apenas mostrar o que "ele faz nos bastidores".

## O que exatamente ele instala

AceKit é a "porta de entrada" de toda a área de ferramentas para desenvolvedores do AceData; atualmente, uma única instalação inclui o **conjunto de ferramentas de habilidades (Skills)**:

- **Um conjunto de habilidades para Agent**: cada habilidade é um manual de operação `SKILL.md` já escrito — autenticação, polling assíncrono, repetição em caso de erros e como preencher os parâmetros estão todos explicados, basta o agent seguir as instruções. Execute `npx acekit list` para ver a lista atual (no momento em que este texto foi escrito, eram 19 e o número continua crescendo):
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **Um Token unificado**: um `ACEDATACLOUD_API_TOKEN` desbloqueia todas as capacidades, com cobrança baseada no uso real.

Classificado por capacidade (conforme `npx acekit list`):

| Tipo         | Provedores                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ Geração de imagens      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 Geração de vídeos      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 Geração de música / áudio | Suno · Producer · Fish Audio（TTS）                    |
| 💬 Conversa com LLM   | Interface unificada para mais de 50 modelos（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 Pesquisa       | Google SERP（web · imagens · notícias · mapas · vídeos）                  |
| 🔗 Ferramentas       | Links curtos · processamento facial                                            |

> Para essas mesmas capacidades, a AceData também oferece **servidores MCP** independentes（Suno、Midjourney、Sora、SERP… publicados no PyPI / VS Code / Smithery / Docker）、**CLI de linha de comando** e **SDKs Python / TypeScript**, que podem ser usados separadamente conforme necessário. A AceKit v0.2 planeja oferecer suporte à instalação de uma única capacidade com `acekit add <name>`, bem como à gravação automática da configuração MCP de cada agent.

## Quais Agents são suportados

| Agent                        | Local de instalação das habilidades                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode etc. | `~/.agents/skills`（faça seu agent apontar para cá） |

Durante a instalação, a AceKit detecta automaticamente os agents já instalados na máquina e instala apenas nos que forem detectados.

## Extra: use o mesmo Token para executar o próprio Claude Code

A interface da AceData também é compatível com o formato `/v1/messages` da Anthropic, portanto você **não precisa de uma assinatura oficial da Anthropic**: pode usar o mesmo Token da AceData para executar o Claude Code. Crie `.claude/settings.local.json` na raiz do projeto:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "seu token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Basta reiniciar o Claude Code — ele passa a usar toda a linha de modelos Claude e, por meio da AceKit, ganha as “mãos” para gerar imagens, vídeos e músicas. Veja mais detalhes no [guia de integração do Claude Code](https://platform.acedata.cloud/documents/claude-code-integration).
