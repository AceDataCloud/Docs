O Provider de modelo Coding Plan, a IDE Extension e o MCP do OpenCode são três capacidades independentes. A IDE Extension conecta-se ao runtime local do OpenCode e reutiliza a mesma configuração de Provider; ela não representa suporte nativo do editor hospedeiro ao Ace Data Cloud.

| Rota                            | Descrição                                                      | Link                                                                                    | Status      |
| ----------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------- |
| Terminal / CLI / TUI Provider | Usa `opencode.json[c]` e Chat Completions                | [Configuração do Provider](https://platform.acedata.cloud/documents/opencode-terminal-integration) | Contrato de configuração verificado |
| IDE Extension                 | Hosts como VS Code, Cursor, Windsurf, VSCodium etc. conectam-se ao runtime do OpenCode | [Configuração da IDE](https://platform.acedata.cloud/documents/opencode-ide-integration)           | Experimental     |
| MCP                           | Chama ferramentas remotas dentro do OpenCode                                      | [Visão geral do MCP](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | Capacidade independente    |

Após a configuração do Provider ser bem-sucedida, a IDE Extension deve usar o mesmo Provider e modelo. Ainda é necessário verificar separadamente o chat na IDE, a leitura de arquivos, a edição e a chamada de ferramentas; uma solicitação comum única do CLI não deve ser automaticamente extrapolada para todas as capacidades da IDE.

O ID do modelo deve seguir o [catálogo em tempo real](https://platform.acedata.cloud/models).
