---
title: "Configurar o compartilhamento global de saldo do AceDataCloud Application"
description: "Platform API guide - Ace Data Cloud"
---

Configure `allow_consume_global`. Após ativado, Applications por uso que atendam às condições podem continuar usando o saldo global da conta quando o seu próprio saldo for insuficiente.

## Preparação

- Crie e armazene com segurança o [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Obtenha o `application_id` que você possui na [lista de solicitações de serviço](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='seu token de conta'
export APPLICATION_ID='seu Application ID'
```

## Visão geral da interface

| Item    | Conteúdo                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------- |
| Método   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Autenticação   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

Em caso de sucesso, retorna o objeto Application atualizado. Use como referência o `allow_consume_global` na resposta, em vez de presumir que o valor solicitado foi necessariamente salvo.

> Applications do tipo `Period` não podem consumir o saldo global. Mesmo que seja solicitado `true`, o servidor manterá esse campo como `false`.

## Tratamento de erros

- `401`: Account Token inválido ou ausente.
- `403`: A conta atual não é a proprietária deste Application.
- `404`: O Application ID não existe.

A entrada de recarga do saldo global e os planos disponíveis devem seguir o console da plataforma e os planos reais retornados pela [criação de pedido](https://platform.acedata.cloud/documents/platform-order-create); não presuma a existência de planos do tipo `Wallet`.
