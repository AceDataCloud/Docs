O Coze oferece suporte oficial à integração de modelos personalizados e fornece três protocolos: OpenAI Chat API, OpenAI Responses API e Anthropic Messages API. As três rotas diferem em Base URL, composição de caminhos, Header, streaming e contrato de chamadas de ferramentas, portanto devem ser configuradas e verificadas separadamente.

| Rota                      | Status  | Guia                                                                                  |
| ----------------------- | --- | ----------------------------------------------------------------------------------- |
| OpenAI Chat Completions | Experimental | [Configuração do Chat](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | Experimental | [Configuração do Responses](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | Experimental | [Configuração do Messages](https://platform.acedata.cloud/documents/coze-messages-integration)   |

“Experimental” significa que os recursos oficiais e as entradas de configuração foram confirmados, mas diferentes regiões, versões ou planos do Coze podem exibir formulários diferentes; a Ace Data Cloud ainda precisa concluir a validação da versão fixa de acordo com o protocolo. Não extrapole o sucesso de um protocolo para os outros dois.

## Princípios de configuração

- Para a Base API URL, preencha preferencialmente a base fornecida pela documentação; não adicione repetidamente o endpoint path que o cliente preencherá automaticamente.
- Para a API Key, use seu Ace Data Cloud API Token.
- Para o Model, use o ID exato do modelo no catálogo de modelos que seja compatível com o protocolo selecionado.
- Após o sucesso do texto comum, streaming e chamadas de ferramentas também devem ser verificados.
