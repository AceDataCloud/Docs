A documentação oficial do modelo personalizado Coze suporta a API OpenAI Responses e fornece a URL da API Base, a chave da API e os campos do modelo. Diferentes versões do inquilino Coze podem tratar a concatenação de caminhos, a saída em fluxo e a chamada de ferramentas de maneira diferente; ao se conectar pela primeira vez, verifique cada item abaixo.

## Configuração

1. Acesse a gestão de modelos Coze e adicione um modelo personalizado.
2. Selecione o Protocolo como API OpenAI Responses.
3. Preencha a URL da API Base como `https://api.acedata.cloud/v1`.
4. Preencha a chave da API com seu Token da API Ace Data Cloud.
5. Preencha o modelo com o ID exato do modelo que suporta a API Responses no diretório de modelos.
6. Salve e complete o teste de conexão do Coze.
7. No Bot/Agente, envie `Reply only OK` e teste novamente a chamada da ferramenta.

## Limites Atuais

- Diferentes regiões, versões ou pacotes do Coze podem exibir formulários diferentes.
- A URL da API Base deve usar base, não adicione `/responses` novamente; se a UI atual exigir uma URL da API completa, siga as instruções do formulário.
- Chat Completions, Responses e Anthropic Messages são três rotas independentes e não podem se substituir na validação.
