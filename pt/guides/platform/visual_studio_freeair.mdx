FreeAIr é uma extensão de código aberto para Visual Studio 2022/2026, que, segundo a declaração oficial, pode se conectar a qualquer API compatível com OpenAI. O comportamento das solicitações pode variar entre diferentes versões da extensão; ao se conectar pela primeira vez, fixe a versão e complete a validação mínima abaixo.

## Configuração

1. Instale o FreeAIr a partir do Visual Studio Marketplace ou do repositório oficial.
2. Abra as configurações do FreeAIr e adicione uma conexão compatível com OpenAI.
3. Preencha o Endpoint com `https://api.acedata.cloud/v1`.
4. Preencha o Token com seu Token da API do Ace Data Cloud.
5. Preencha o Model com o ID do modelo exato que suporta Chat Completions no diretório de modelos.
6. Após salvar, envie `Reply only OK` e teste novamente uma solicitação com o contexto do projeto.

## Limites atuais

- Este guia cobre apenas o FreeAIr e não representa que o Copilot embutido no Visual Studio suporte URLs base arbitrárias.
- A versão da extensão pode alterar a forma de concatenação do endpoint; ao validar, deve-se verificar a URL da solicitação final.
- A capacidade de chamada de ferramentas e MCP dentro da extensão precisa ser validada de forma independente, não podendo ser substituída pelo sucesso de um chat comum.
