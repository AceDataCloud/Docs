Lê os switches de funcionalidades públicas e a determinação de país/região no contexto da solicitação atual. Adequado para decidir se as funcionalidades são exibidas na inicialização do frontend; não se trata da marca do site, informações de contato ou catálogo de anúncios.

## Visão geral da interface

| Item   | Conteúdo                                              |
| --- | ----------------------------------------------- |
| Método  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Autenticação  | Pública; ao transportar estado de login, alguns switches de funcionalidades podem ser calculados por usuário                          |

## Parâmetros de consulta e cabeçalhos de solicitação

| Nome                    | Localização     | Descrição                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | Código de país ASCII de duas letras; usado para substituir o país de exibição na resposta, sem alterar a determinação de segurança do servidor |
| `features`            | query  | Expressão de substituição de switches de funcionalidades; válida apenas para switches que permitem substituição pelo cliente ou para superadministradores        |
| `X-Feature-Overrides` | header | Fonte de substituição igual a `features`                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## Estrutura real da resposta

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| Campo         | Tipo            | Descrição                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Switches de funcionalidades visíveis para a solicitação atual; as chaves mudam conforme a configuração da plataforma, e o cliente deve ler conforme necessário e definir valores padrão seguros para chaves ausentes |
| `country`  | string / null | Código de país em minúsculas; pode ser `null` quando não for possível identificar                     |

Não leia desta interface o nome do site, CDN, moeda, idioma, informações de contato do atendimento ao cliente ou anúncios; esses campos não pertencem ao contrato de resposta atual.

## Recomendações de uso

- Os switches de funcionalidades são calculados por usuário, impressão digital e contexto do site; não compartilhe cache de longo prazo entre usuários.
- O `country` enviado pelo cliente afeta apenas o valor retornado e não contorna as políticas de região ou segurança do servidor.
- Parâmetros query não reconhecidos serão ignorados; use apenas os parâmetros listados nesta página.
