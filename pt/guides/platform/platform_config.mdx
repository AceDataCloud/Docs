Lê os switches de funcionalidades públicas e a determinação de país/região no contexto da solicitação atual. Adequado para decidir se as funcionalidades são exibidas durante a inicialização do frontend; não se trata da marca do site, informações de contato ou catálogo de anúncios.

## Visão geral da interface

| Item   | Conteúdo                                              |
| --- | ----------------------------------------------- |
| Método  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Autenticação  | Público; ao portar um estado de login, alguns switches de funcionalidades podem ser calculados por usuário                          |

## Parâmetros de consulta e cabeçalhos de solicitação

| Nome                    | Localização     | Descrição                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | Expressão de substituição de switch de funcionalidade; só tem efeito para switches que permitem substituição pelo cliente ou para superadministradores |
| `X-Feature-Overrides` | header | Fonte de substituição igual a `features`           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## Estrutura real da resposta

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| Campo         | Tipo            | Descrição                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Switches de funcionalidades visíveis na solicitação atual; as chaves variam conforme a configuração da plataforma, e o cliente deve lê-las conforme necessário e definir valores padrão seguros para chaves ausentes |
| `region`   | string / null | Código de país ou região detectado com base no IP da solicitação, em letras minúsculas; é `null` quando não puder ser identificado        |

Não leia desta interface o nome do site, CDN, moeda, idioma, informações de contato do suporte ao cliente ou anúncios; esses campos não pertencem ao contrato de resposta atual.

## Recomendações de uso

- Os switches de funcionalidades são calculados por usuário, impressão digital e contexto do site; não compartilhe o cache entre usuários por longos períodos.
- A seleção do seletor de região é salva apenas no frontend; ao exibir, priorize a região já selecionada; caso contrário, use o `region` desta interface. Esta interface não aceita parâmetros de substituição de região.
- Parâmetros de query não reconhecidos serão ignorados; use apenas os parâmetros listados nesta página.
