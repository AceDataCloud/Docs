LMLocal é uma extensão para Visual Studio 2022/2026, com suporte oficial para API compatível com OpenAI e URL Base personalizada. O ponto de configuração pode mudar com a versão da extensão; para a primeira integração, fixe a versão e verifique a edição real, chamadas de ferramentas e registros de uso.

## Configuração

1. Instale o LMLocal a partir do Visual Studio Marketplace ou do repositório oficial.
2. Adicione um Provider Custom/OpenAI-compatible em Providers.
3. Preencha a Base URL com `https://api.acedata.cloud/v1`.
4. Preencha o Auth Key com seu Token da API do Ace Data Cloud.
5. Preencha o Model com o ID exato do modelo que suporta Chat Completions no diretório de modelos.
6. Após salvar, envie `Reply only OK`, e teste novamente o fluxo de edição do projeto.

## Limites atuais

- Este guia cobre apenas o LMLocal e não representa a configuração compartilhada por outras extensões do Visual Studio.
- Versões diferentes podem tratar separadamente solicitações de chat, edição, construção e teste; cada modo deve ser validado de forma independente.
- Se o cliente adicionar automaticamente `/v1` ou o caminho do endpoint, evite caminhos duplicados.
