---
title: "Rotacionar credenciais de API da plataforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Gere um novo Token ou senha para uma Credential existente. O ID da credencial, a associação da Application, os limites e outros campos permanecem inalterados, e o segredo antigo é invalidado imediatamente.

> A rotação interromperá os clientes que ainda usam o segredo antigo. Primeiro prepare planos de distribuição segura e reversão, depois execute a operação de escrita.

## Visão geral da interface

| Item | Conteúdo                                                                  |
| ---- | ------------------------------------------------------------------------- |
| Método | `POST`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}/rotate/` |
| Autenticação | Account Token                                                   |
| Body | Nenhum ou `{}`                                                          |

Obtenha `credential_id` na [lista de credenciais](https://platform.acedata.cloud/documents/platform-credential-list):

```shell
export PLATFORM_TOKEN='seu token de conta'
export CREDENTIAL_ID='ID da Credential a ser rotacionada'

curl -X POST \
  "https://platform.acedata.cloud/api/v1/credentials/${CREDENTIAL_ID}/rotate/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Em caso de sucesso, retorna a Credential atualizada. Quando `type=Token`, leia o novo `token`; quando `type=Identity`, leia a nova `password`. Trate a resposta completa como segredo e atualize imediatamente os chamadores.

## Tratamento de erros

- `401`: Account Token inválido.
- `403`: Sem permissão para gerenciar esta credencial.
- `404`: O ID da Credential não existe.
