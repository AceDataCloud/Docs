---
title: "Obter a lista de serviços da plataforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Retorna de forma paginada o catálogo de Service visível no site atual, incluindo tipo de serviço, informações de exibição, cota gratuita, pacotes e IDs de API/Proxy associados. Adequado para construir um marketplace de serviços ou selecionar serviços a serem solicitados.

## Visão geral da interface

| Item   | Conteúdo                                                |
| --- | ------------------------------------------------- |
| Método  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| Autenticação  | Público; com estado de login, `applied` reflete a conta atual                        |
| Paginação  | `count` + `items`                                 |

## Parâmetros de consulta

| Parâmetro               | Tipo      | Obrigatório  | Descrição                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | Não   | Filtrar por ID do serviço; suporta parâmetros repetidos         |
| `private`        | boolean | Não   | Filtrar por status público; as regras de visibilidade do site continuam em vigor      |
| `type`           | string  | Não   | Tipo de serviço; suporta parâmetros repetidos              |
| `tag`            | string  | Não   | Filtrar por tag                    |
| `include_facets` | boolean | Não   | Quando `true`, adiciona estatísticas de tipo/tag disponíveis no site atual |
| `limit`          | integer | Não   | Número de itens por página, máximo 100              |
| `offset`         | integer | Não   | Deslocamento de paginação                    |
| `ordering`       | string  | Não   | Suporta apenas `rank` ou `-rank`     |

A lista não suporta filtragem por `alias`; quando já houver um alias, solicite diretamente `/api/v1/services/{alias}`. `applied_count` e `updated_at` não são campos de ordenação permitidos.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## Descrição da resposta

A resposta é `{count, items}`; `facets` é adicionado apenas quando `include_facets=true`. Os itens de serviço incluem os campos públicos atuais como `id`, `alias`, `title`, `description`, `type`, `applied_count`, `free_amount`, `unit`, `private`, `need_verify`, `rank`, `tags`, `thumbnail`, `doc_url`, `demo_url`, `api_ids`, `proxy_ids`, `cost`, `packages` e outros.

`applied` em uma lista anônima não representa o status de solicitação de uma determinada conta. Quando for necessário um status relacionado à conta, deve-se usar um estado de login válido e tomar a [lista de solicitações de serviço](https://platform.acedata.cloud/documents/platform-application-list) como referência final.
