A extensão oficial do OpenCode IDE suporta editores como VS Code, Cursor, Windsurf, VSCodium, entre outros, e reutiliza o runtime local do OpenCode e a configuração do Provider. A extensão do IDE reutiliza o Provider CLI local, mas a cadeia de requisições pode variar entre diferentes versões de editores; ao integrar pela primeira vez, fixe a versão e complete a validação mínima.

## Configuração do Provider

Primeiro, siga a [configuração do Terminal OpenCode](https://platform.acedata.cloud/documents/opencode-terminal-integration) para configurar o Provider do Ace Data Cloud em `opencode.json` ou `opencode.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## Instalação da Extensão IDE

1. Execute `opencode` no terminal integrado do editor para instalar automaticamente a extensão seguindo o processo oficial; você também pode instalá-la manualmente a partir do Marketplace correspondente.
2. Recarregue o editor.
3. Inicie um `Reply only OK` a partir da Extensão OpenCode.
4. Execute novamente a requisição que precisa ler arquivos ou modificar código, confirmando que a Extensão IDE utiliza o mesmo Provider e modelo.

## Limitações atuais

- A capacidade do Provider vem do runtime do OpenCode, não representando suporte nativo do editor anfitrião ao Ace Data Cloud.
- As versões das extensões do VS Code e seus forks podem ser diferentes, devendo ser registradas separadamente.
- O sucesso de um chat comum não substitui a validação de leitura de arquivos, edição e chamadas de ferramentas.
