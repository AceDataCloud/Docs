Obtenha as informações completas de um único serviço por ID de serviço (UUID) ou alias (alias) — os campos retornados são mais completos do que em [Obter lista de serviços da plataforma AceDataCloud](https://platform.acedata.cloud/documents/platform-service-list), e expandem adicionalmente objetos associados como `apis`, `proxies`, `datasets`, `packages` etc. Adequado para cenários como páginas de detalhes de serviço, páginas de comparação de preços e descrições de ferramentas de Agent.

> ℹ️ Esta interface pertence à **API de gerenciamento da plataforma AceDataCloud**, com o prefixo unificado `https://platform.acedata.cloud/api/v1/`. Para o índice completo de interfaces, consulte [Obter lista de documentos da plataforma AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list).

## Visão geral da interface

| Item   | Conteúdo                                                            |
| --- | ------------------------------------------------------------- |
| Método  | `GET`                                                         |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}` |
| Autenticação  | ❌ Pública                                                          |

`/services/{id}` e `/services/{id}/` estão atualmente disponíveis; os exemplos usam uniformemente o formato sem barra final.

## Explicação sobre autenticação

Esta interface é totalmente pública. **No entanto, após incluir o token da conta, o campo `applied` na resposta refletirá o status real de solicitação da conta atual**; caso contrário, será sempre `false`.

Para saber como obter o token da conta, consulte [Gerenciar tokens de conta da plataforma AceDataCloud](https://platform.acedata.cloud/documents/platform-token).

## Parâmetros de caminho

| Parâmetro           | Tipo            | Obrigatório  | Descrição                                                    |
| ------------ | ------------- | --- | ----------------------------------------------------- |
| `service_id` | UUID / string | ✅   | ID do serviço (UUID) ou alias (`midjourney`, `openai`, `webextrator` etc.) |

## Exemplos de solicitação

### cURL

```shell
# 按 UUID 查询
curl 'https://platform.acedata.cloud/api/v1/services/8efa1d83-9b75-4562-b44a-af95ce563d05' \
  -H 'accept: application/json'

# 按 alias 查询
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json'

# 带账户令牌看 applied 状态
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

resp = requests.get(
    "https://platform.acedata.cloud/api/v1/services/midjourney",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
svc = resp.json()
print(f"服务: {svc['title']} ({svc['alias']})")
print(f"已申请: {svc['applied']}, 免费额度: {svc['free_amount']} {svc['unit']}")
print(f"API 数: {len(svc['apis'])}, 套餐数: {len(svc['packages'])}")
for pkg in svc["packages"]:
    print(f"  ¥{pkg['price']:>7.2f}  ->  {pkg['amount']} {svc['unit']}")
```

### Node.js

```javascript
const r = await fetch('https://platform.acedata.cloud/api/v1/services/midjourney', {
  headers: { accept: 'application/json' },
})
const svc = await r.json()
console.log(`${svc.title} - 套餐 ${svc.packages.length} 个 - API ${svc.apis.length} 个`)
```

## Explicação dos campos de resposta

Além de todos os campos da [interface de lista](https://platform.acedata.cloud/documents/platform-service-list), a interface de detalhes expande adicionalmente:

| Campo         | Tipo    | Descrição                                                            |
| ---------- | ----- | ------------------------------------------------------------- |
| `apis`     | array | Lista completa de objetos API associados (cada item inclui `id`, `name`, `title`, `path`, `stage`, `cost`) |
| `proxies`  | array | Lista completa de objetos Proxy associados                                              |
| `datasets` | array | Conjuntos de dados associados (se `type=Dataset`)                                      |
| `packages` | array | Lista de pacotes, incluindo `type` (`Usage`/`Period`), `price`, `amount`, `duration`   |

Para as definições dos demais campos, consulte [Obter lista de serviços da plataforma AceDataCloud → Explicação dos campos de resposta](https://platform.acedata.cloud/documents/platform-service-list).

## Tratamento de erros

| HTTP | code        | Significado                            |
| ---- | ----------- | ----------------------------- |
| 404  | `not_found` | `service_id` (UUID ou alias) não existe |
| 500  | —           | Geralmente é causado pela adição incorreta de uma barra no final da URL; remova-a e tente novamente          |

## Dicas práticas

- **`alias` > `UUID`**: codificar `alias` (como `midjourney`) diretamente no código é mais estável; o UUID muda ao migrar ambientes.
- **O campo `apis` não inclui a definição OpenAPI**: o Schema OpenAPI 3.0 completo está na interface [Obter detalhes da API da plataforma AceDataCloud](https://platform.acedata.cloud/documents/platform-api-detail).
- **Obter as "capacidades completas" de um serviço**: use esta interface para obter `api_ids` e, em seguida, chame `/apis/{api_id}` um por um para obter os detalhes.
- **Se `applied=true`**, você pode diretamente [criar uma credencial de API](https://platform.acedata.cloud/documents/platform-credential-create) para obter o Token de 32 caracteres necessário para chamar a interface de negócio, sem precisar solicitar novamente.
