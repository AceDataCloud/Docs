description: "Platform API guide - Ace Data Cloud"

O Hermes Agent se conecta ao Ace Data Cloud através do protocolo OpenAI Chat Completions. Escolha uma das opções de configuração:

| Opção de Configuração         | Guia                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| Assistente de Interação `hermes model` | [Configuração do Assistente](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| Configuração Manual `config.yaml`  | [Configuração Manual](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| Implantação Privada na Plataforma              | [Implantação Gerenciada](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

Parâmetros comuns para acesso local:

- URL Base: `https://api.acedata.cloud/v1`
- Transporte: `chat_completions`
- Provedor: `custom:acedatacloud`
- Chave da API: obtenha da [lista de aplicativos](https://platform.acedata.cloud/console/applications)

Ambas as opções locais devem ser escritas em `~/.hermes/config.yaml`, não configure repetidamente.

Retorne ao [Centro de Configuração do Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
