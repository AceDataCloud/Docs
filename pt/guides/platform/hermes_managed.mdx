Ace Data Cloud oferece a entrada para a implantação privada do Hermes Agent. Esta entrada é um serviço controlado, e a disponibilidade e os recursos opcionais estão sujeitos ao que é exibido atualmente no console.

## Passos para Uso

1. Encontre **Hermes Agent Private Deployment** na plataforma.
2. Siga as instruções na página para selecionar a configuração disponível e criar o serviço.
3. Aguarde o status de prontidão exibido pela plataforma.
4. Use a entrada e as credenciais fornecidas na página para acessar a instância.
5. Primeiro envie `Reply only OK`, e então comece a tarefa real.

Modelos, credenciais, armazenamento e comportamentos de exclusão estão sujeitos à página de criação e à janela de confirmação; não trate o YAML do tutorial local do Hermes como um contrato de implantação da plataforma. Exporte os dados que precisam ser mantidos antes de excluir.

Se o console não exibir a entrada de criação, isso significa que a conta atual ainda não tem esse serviço disponível, podendo-se usar o [Assistente Interativo do Hermes](https://platform.acedata.cloud/documents/hermes-wizard-integration) ou [Configuração Manual](https://platform.acedata.cloud/documents/hermes-manual-integration).
