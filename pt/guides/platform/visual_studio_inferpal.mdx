Inferpal é uma extensão para Visual Studio 2022/2026, que oferece suporte oficial para conectar-se a serviços compatíveis com OpenAI. A versão da extensão pode afetar a edição, chamadas de ferramentas e registro de uso; ao se conectar pela primeira vez, fixe a versão e complete a validação mínima abaixo.

## Configuração

1. Instale o Inferpal a partir do Visual Studio Marketplace ou do repositório oficial.
2. Abra as **Configurações do Inferpal → Conexão**.
3. Selecione Provider como OpenAI-compatible.
4. Preencha a Base URL com `https://api.acedata.cloud/v1`.
5. Preencha a API Key com seu Token de API do Ace Data Cloud.
6. Preencha o Model com o ID exato do modelo que suporta Chat Completions no diretório de modelos.
7. Após salvar, envie `Reply only OK`, e execute novamente uma solicitação que inclua o contexto do código.

## Limites Atuais

- Este guia cobre apenas o Inferpal e não representa que o Copilot embutido no Visual Studio ou outras extensões suportem os mesmos campos.
- Diferentes versões podem adicionar automaticamente caminhos à Base URL; se a solicitação falhar, verifique se a solicitação final está no endpoint de Chat Completions.
- Antes de completar a versão fixa E2E, não garantimos que todos os modos de edição, complementação ou chamadas de ferramentas estejam disponíveis.
