## 1. Obter a API Key

Abra a [lista de aplicativos do Ace Data Cloud](https://platform.acedata.cloud/console/applications), entre em um aplicativo disponível e copie a API Key.

![Obter a API Key do Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Adicionar Provider

Abra o Cherry Studio, acesse **Configurações → Serviços de modelo → Adicionar provedor**, e preencha:

| Campo      | Valor                           |
| ------- | --------------------------- |
| Nome do provedor   | `Ace Data Cloud`            |
| Tipo de provedor   | `OpenAI`                    |
| API Key | A API Key que acabou de copiar               |
| Endereço da API  | `https://api.acedata.cloud` |

![Tela de configuração para adicionar o Provider do Ace Data Cloud no Cherry Studio](https://cdn.acedata.cloud/b67a927eae62.png)

O Cherry Studio completará automaticamente `/v1/chat/completions` para o tipo OpenAI. Ao usar a entrada genérica, não adicione `#` ao final do endereço, nem é necessário criar vários Providers por família de modelos.

## 3. Adicionar e ativar modelos

1. Clique em **Obter lista de modelos**; se a versão atual não oferecer suporte à obtenção automática, acesse o [catálogo de modelos](https://platform.acedata.cloud/models) para consultar e, em seguida, adicione manualmente o nome do modelo desejado, por exemplo, `claude-opus-5`, `gpt-6-sol`.
2. Clique no botão de verificação ao lado da API Key para validar a conexão.
3. Ative o interruptor **Habilitar** do Provider.
4. Selecione o modelo recém-adicionado no seletor de modelos de conversa.

![Lista de Providers e modelos do Cherry Studio](https://cdn.acedata.cloud/149de1d088bf.png)

> Após concluir a obtenção ou adição manual de modelos, ative o interruptor do Provider no canto superior direito.

Envie `Responda apenas OK` e verifique a chamada no [histórico de uso](https://platform.acedata.cloud/console/usages). Para 401, verifique a Key; se o modelo não for exibido, verifique se o Provider está habilitado; para 404, verifique se o nome do modelo preenchido manualmente corresponde exatamente ao `id` no catálogo.

## Sobre o GPT Image 2

O Provider comum de chat personalizado do Cherry Studio não pode chamar diretamente a Images API. A geração e edição do `gpt-image-2` devem usar a interface dedicada do Ace Data Cloud:

- [Geração de imagens do GPT Image 2](https://platform.acedata.cloud/documents/openai-images-generations)
- [Edição de imagens do GPT Image 2](https://platform.acedata.cloud/documents/openai-images-edits)

Não preencha `/openai/images/generations` no Provider de chat.
