---
title: "Obter a lista de Proxies sob o serviço da plataforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Retorna paginadamente os endpoints Proxy montados neste serviço por meio do UUID do Service. Quando houver apenas alias, primeiro chame os [detalhes do serviço](https://platform.acedata.cloud/documents/platform-service-detail) para obter `id`.

## Visão geral da interface

| Item   | Conteúdo                                                                     |
| --- | ---------------------------------------------------------------------- |
| Método  | `GET`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| Autenticação  | Pública, não requer token de conta                                                              |
| Paginação  | `count` + `items`                                                      |

## Parâmetros

| Parâmetro                 | Localização    | Obrigatório  | Descrição                               |
| ------------------ | ----- | --- | -------------------------------- |
| `service_id`       | path  | Sim   | UUID do Service, alias não é suportado           |
| `limit` / `offset` | query | Não   | Paginação                               |
| `ordering`         | query | Não   | Expressão de ordenação Django; recomenda-se `rank` ou `-rank` |

```shell
export SERVICE_ID='Seu Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## Descrição da resposta

Os itens da lista são serializados pelo modelo Proxy, e os campos verificados online incluem `id`, `service_id`, `title`, `endpoint`, `price`, `stage`, `rank`, `tags`, `metadata`, `document_id`, `service` e campos de tempo.

- O campo de entrada de negócio é `endpoint`, não `path`.
- O campo de precificação é `price`, não `cost`.
- Quando o tipo de Service não for Proxy ou não houver Proxy montado, serão retornados `items` vazios.

Integrações públicas dependem apenas de `endpoint` e das capacidades publicadas, e não devem depender de detalhes de implementação não divulgados.
