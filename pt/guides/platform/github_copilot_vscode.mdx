A documentação oficial do GitHub Copilot BYOK lista o VS Code como um cliente local suportado e compatível com o Provider OpenAI. A versão do VS Code, a política empresarial e a visibilidade do modelo podem afetar o endpoint final; para a primeira integração, verifique os pedidos reais conforme descrito abaixo.

## Escopo de Configuração

1. Confirme se sua conta ou organização do GitHub Copilot tem a funcionalidade BYOK/Modelos Personalizados ativada.
2. Adicione um Provider compatível com OpenAI no gerenciamento de modelos do Copilot no VS Code.
3. Preencha a URL base como `https://api.acedata.cloud/v1`.
4. Preencha a chave da API com seu Token da Ace Data Cloud.
5. Preencha o modelo com o ID exato do modelo compatível com o protocolo selecionado no diretório de modelos.
6. Envie `Reply only OK` no Copilot Chat e teste novamente um pedido com o contexto do espaço de trabalho.

## Limites Atuais

- O contrato de configuração do Copilot App, CLI, GitHub Desktop e Enterprise BYOK é diferente do do VS Code; este guia não aplica diretamente os passos de outros clientes ao VS Code.
- A política da organização pode proibir a adição de Providers ou modelos por indivíduos.
- A conclusão de Tab, Chat, Agent e tarefas em segundo plano podem usar caminhos de modelos diferentes, devendo ser verificados separadamente.
