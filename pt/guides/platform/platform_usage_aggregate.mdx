Resume o número de solicitações e a cota efetivamente deduzida da conta atual por data e API, adequado para criar relatórios mensais, gráficos de tendências e análises de custo. Para depurar cada registro, use a [lista de registros de chamadas](https://platform.acedata.cloud/documents/platform-usage-list); para obter detalhes completos off-line, use a [exportação de volume de chamadas](https://platform.acedata.cloud/documents/platform-usage-export).

O intervalo de consulta de registros de chamadas e resumos de cobrança é dos últimos 60 dias; os corpos de solicitação e resposta são mantidos separadamente pelos últimos 30 dias. A expiração dos corpos não altera a cobrança real, o uso ou as estatísticas agregadas desse registro.

## Preparação

1. Faça login na [plataforma AceDataCloud](https://platform.acedata.cloud).
2. Crie um token de conta no [console de Account Token](https://platform.acedata.cloud/console/platform-tokens) e salve-o imediatamente.
3. Caso seja necessário restringir o escopo, obtenha o ID correspondente na [lista de solicitações de serviço](https://platform.acedata.cloud/documents/platform-application-list), na [lista de credenciais de API](https://platform.acedata.cloud/documents/platform-credential-list) ou na [lista de APIs](https://platform.acedata.cloud/documents/platform-api-list).

Para a descrição completa dos tokens, consulte [gerenciar tokens de conta](https://platform.acedata.cloud/documents/platform-token). Esta API usa Account Token, não credenciais de negócio.

```shell
export PLATFORM_TOKEN='你的账户令牌'
```

## Visão geral da API

| Item           | Conteúdo                                                      |
| -------------- | ------------------------------------------------------------- |
| Método         | `GET`                                                         |
| URL            | `https://platform.acedata.cloud/api/v1/usage/apis/aggregate/` |
| Autenticação   | `Authorization: Bearer ${PLATFORM_TOKEN}`                     |
| OAuth Scope    | `usage:read` (incluído de forma expansível por `platform:read` / `platform`) |
| Escopo de permissão | Para usuários comuns, fixado ao próprio uso pago; administradores podem passar `user_id` |

## Parâmetros de consulta

| Parâmetro         | Tipo            | Obrigatório | Padrão                                           | Descrição                                                    |
| ----------------- | --------------- | ----------- | ------------------------------------------------ | ------------------------------------------------------------ |
| `created_at_from` | date / datetime | Não         | Primeiro dia do mês atual no fuso horário selecionado | Hora de início, nome de parâmetro recomendado                |
| `created_at_to`   | date / datetime | Não         | Hora atual                                       | Hora de término, nome de parâmetro recomendado               |
| `timezone`        | string          | Não         | `UTC`                                            | Fuso horário IANA, por exemplo, `Asia/Shanghai`; valores inválidos retornam para UTC |
| `service_id`      | UUID            | Não         | —                                                | Filtra por serviço; suporta parâmetros repetidos             |
| `application_id`  | UUID            | Não         | —                                                | Filtra por Application; suporta parâmetros repetidos         |
| `api_id`          | UUID            | Não         | —                                                | Filtra por API; suporta parâmetros repetidos                 |
| `credential_id`   | UUID            | Não         | —                                                | Filtra por credencial de API; suporta parâmetros repetidos   |
| `include_models`  | boolean         | Não         | `false`                                          | Se calcula adicionalmente o resumo por dimensão de modelo; aumenta o custo da consulta |
| `user_id`         | UUID            | Não         | Para usuários comuns, fixado a si mesmo; para administradores, todos os usuários quando não informado | Somente administradores podem especificar qualquer conta |

`start_time` / `end_time` ainda podem ser usados como aliases de compatibilidade para clientes antigos; novas integrações devem usar uniformemente `created_at_from` / `created_at_to`. A forma de data de `created_at_to` incluirá esse dia natural, isto é, usa a meia-noite do dia seguinte como limite.

## Exemplos de solicitação

Consulte o resumo diário/API do mês atual no horário de Pequim, incluindo a dimensão de modelo:

```shell
curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/aggregate/' \
  --data-urlencode 'timezone=Asia/Shanghai' \
  --data-urlencode 'include_models=true' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Consulte o uso de uma semana de uma Application especificada:

```shell
export APPLICATION_ID='你的 Application ID'

curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/aggregate/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'created_at_from=2026-09-01' \
  --data-urlencode 'created_at_to=2026-09-07' \
  --data-urlencode 'timezone=Asia/Shanghai' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Exemplo em Python:

```python
import os
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/usage/apis/aggregate/",
    headers={"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"},
    params={
        "created_at_from": "2026-09-01",
        "created_at_to": "2026-09-07",
        "timezone": "Asia/Shanghai",
        "include_models": "true",
    },
    timeout=30,
)
response.raise_for_status()
data = response.json()
print("requests:", data["requests"], "deducted:", data["total"])
for row in data["items"]:
    print(row["date"], row["api_id"], row["amount"])
```

## Exemplo de resposta

```json
{
  "items": [
    {
      "date": "2026-09-01",
      "api_id": "00000000-0000-4000-8000-000000000001",
      "amount": 12.5
    }
  ],
  "total": 12.5,
  "apis": {
    "00000000-0000-4000-8000-000000000001": {
      "title": "Example API"
    }
  },
  "requests": 42,
  "models": [
    {
      "model": "example-model",
      "amount": 12.5,
      "requests": 42
    }
  ]
}
```

## Campos da resposta

| Campo      | Descrição                                                    |
| ---------- | ------------------------------------------------------------ |
| `items`    | Agrupado por data no fuso horário selecionado e `api_id`; cada linha inclui `date`, `api_id`, `amount` |
| `total`    | Soma de `deducted_amount` dentro do intervalo de consulta    |
| `apis`     | Mapeamento de ID de API para resumo de título, facilitando a exibição de `items` |
| `requests` | Número total de solicitações dentro do intervalo de consulta |
| `models`   | Calculado apenas quando `include_models=true`; cada item inclui `model`, `amount`, `requests` |

A unidade de cota depende de `service.unit` da Application relacionada. Se a consulta incluir serviços com unidades diferentes, primeiro faça as estatísticas separadamente por `service_id` ou `application_id`, evitando compará-las ou somá-las diretamente.

Quando a hora de término não for maior que a hora de início, a API retorna uma estrutura vazia completa: `items=[]`, `total=0`, `apis={}`, `requests=0`, `models=[]`.

## Recomendações de erros e desempenho

| HTTP | `error`                 | Forma de tratamento                                      |
| ---- | ----------------------- | -------------------------------------------------------- |
| 400  | `usage_history_expired` | Ajuste o intervalo de tempo para após `available_from` da resposta |
| 401  | `not_authenticated`     | Verifique o Account Token; não use por engano uma Credential de negócio |
| 403  | `permission_denied`     | Usuários comuns não podem consultar outras contas        |

- Por padrão, não ative `include_models`; habilite-o somente quando o relatório realmente precisar de divisão por modelo.
- Para consultas de grande alcance, priorize a separação por `service_id` ou `application_id`, evitando unidades mistas e reduzindo o custo da consulta.
- Datas sem chamadas não recebem zeros automaticamente; complete o eixo de datas no cliente antes de desenhar gráficos.
