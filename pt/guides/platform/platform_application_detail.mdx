Obtenha o status completo de uma única solicitação de serviço por meio do Application ID — em comparação com a interface de lista, inclui campos adicionais como o objeto completo `service` (incluindo os pacotes `packages`), sendo adequado para páginas de detalhes.

> ℹ️ Esta interface pertence à **API de gerenciamento da plataforma AceDataCloud**, com o prefixo unificado `https://platform.acedata.cloud/api/v1/`. Para o índice completo de interfaces, consulte [Obter lista de documentação da plataforma AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list).

## Visão geral da interface

| Item   | Conteúdo                                                                    |
| --- | --------------------------------------------------------------------- |
| Método  | `GET`                                                                 |
| URL | `https://platform.acedata.cloud/api/v1/applications/{application_id}` |
| Autenticação  | ✅ Requer token de conta                                                              |

`/applications/{id}` e `/applications/{id}/` estão ambos disponíveis atualmente; os exemplos usam de forma consistente o formato sem barra final.

## Instruções de autenticação (como obter o token de conta)

Cabeçalho da solicitação:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

Para o método detalhado de obtenção, consulte [Gerenciar token de conta da plataforma AceDataCloud](https://platform.acedata.cloud/documents/platform-token).

> ℹ️ Diferentemente da interface de lista, a **verificação de permissão da interface de detalhes é realizada diretamente sobre um único objeto**, sem a necessidade de passar `?user_id=`. Porém, se você acessar a solicitação de outra pessoa, receberá `403 permission_denied`.

## Parâmetros de caminho

| Parâmetro               | Tipo   | Obrigatório  | Descrição             |
| ---------------- | ---- | --- | -------------- |
| `application_id` | UUID | ✅   | Application ID |

## Exemplos de solicitação

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/applications/82f57141-2323-4453-8730-60f7d833a2da' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

app_id = "82f57141-2323-4453-8730-60f7d833a2da"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/applications/{app_id}",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
app = resp.json()
print(f"服务：{app['service']['title']}")
print(f"剩余 {app['remaining_amount']} {app['service']['unit']} / 已用 {app['used_amount']}")
```

### Node.js

```javascript
const appId = '82f57141-2323-4453-8730-60f7d833a2da'
const r = await fetch(`https://platform.acedata.cloud/api/v1/applications/${appId}`, {
  headers: { authorization: `Bearer ${process.env.PLATFORM_TOKEN}` },
})
console.log(await r.json())
```

## Descrição dos campos de resposta

Os significados dos campos são os mesmos da [interface de lista](https://platform.acedata.cloud/documents/platform-application-list), com a inclusão de:

| Campo        | Tipo     | Descrição                                                        |
| --------- | ------ | --------------------------------------------------------- |
| `service` | object | Objeto completo do serviço (incluindo os pacotes `packages`, `unit`, `free_amount`), que pode renderizar diretamente o painel de detalhes do serviço |

## Tratamento de erros

| HTTP | code                | Significado                  |
| ---- | ------------------- | ------------------- |
| 401  | `not_authenticated` | Token de conta ausente              |
| 403  | `permission_denied` | Esta Application não pertence a você  |
| 404  | `not_found`         | A Application não existe ou foi excluída |

## Dicas práticas

- **Para monitoramento em lote, priorize a lista**: após obter a lista de Applications de uma vez, determine com base na unidade e nos limites de cada serviço, evitando solicitar detalhes individualmente.
- **Quando precisar verificar a quantidade de credenciais**: use a [lista de credenciais de API](https://platform.acedata.cloud/documents/platform-credential-list) para filtrar por `application_id`.
- **Abordagem para investigar `disabled=true`**: verifique chamados / notificações por e-mail para ver se o serviço foi desativado por controle de risco, inadimplência ou chamadas em violação; não é possível reativá-lo pela API, sendo necessário entrar em contato com o atendimento ao cliente.
