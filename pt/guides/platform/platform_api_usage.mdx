---
title: "Obter amostras recentes de chamadas da API da plataforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Retorna publicamente amostras de registros de chamadas de uma determinada API nos últimos 15 minutos, para observar rapidamente o estado recente. Não é uma interface de contagem agregada por código de status e também não pode ser usada para faturamento pessoal, SLA ou estatísticas completas de uso.

## Visão geral da interface

| Item   | Conteúdo                                                           |
| --- | ------------------------------------------------------------ |
| Método  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| Autenticação  | Pública, não requer token de conta                                                    |
| Limite  | Após combinar os registros criados/concluídos mais recentemente, retorna no máximo 5.000 itens                                    |

Obtenha o `api_id` na [lista de APIs](https://platform.acedata.cloud/documents/platform-api-list).

```shell
export API_ID='你的 API ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## Estrutura real da resposta

A resposta é diretamente um array, sem usar envelope de paginação:

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| Campo            | Descrição        |
| ------------- | --------- |
| `api_id`      | ID da API    |
| `created_at`  | Hora de criação do registro    |
| `trace_id`    | Identificador de rastreamento da solicitação    |
| `status_code` | Código de status HTTP  |
| `elapsed`     | Duração da chamada, em segundos |

Quando a API não existe, atualmente também pode retornar um array vazio, pois esta action consulta diretamente o usage recente pelo ID, sem primeiro validar o objeto da API. Para calcular a taxa de sucesso, o cliente deve agrupar por conta própria as amostras retornadas; para consultar cobranças pessoais, use a interface de nível de conta.
