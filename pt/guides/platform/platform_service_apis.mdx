---
title: "Obter a lista de APIs sob o serviço da plataforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Retorna de forma paginada as APIs atualmente habilitadas e não descontinuadas deste serviço por meio do Service UUID. Quando houver apenas alias, primeiro chame [detalhes do serviço](https://platform.acedata.cloud/documents/platform-service-detail) para obter `id`.

## Visão geral da interface

| Item   | Conteúdo                                                                  |
| --- | ------------------------------------------------------------------- |
| Método  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| Autenticação  | Pública, não requer token de conta                                                           |
| Paginação  | `count` + `items`                                                   |

## Parâmetros

| Parâmetro           | Localização    | Obrigatório  | Descrição                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | Sim   | Service UUID, não oferece suporte a alias           |
| `limit`      | query | Não   | Número de itens por página, máximo de 100                      |
| `offset`     | query | Não   | Deslocamento da paginação                            |
| `ordering`   | query | Não   | Expressão de ordenação Django; recomenda-se `rank` ou `-rank` |

A interface atual não oferece suporte à filtragem por `stage`; ela já exclui APIs `Deprecated`.

```shell
export SERVICE_ID='Seu Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

Os itens da lista usam a mesma estrutura de índice da [lista de APIs da plataforma](https://platform.acedata.cloud/documents/platform-api-list) e atualmente incluem `definition`. Quando precisar de uma entrada estável para uma única API, continue chamando `/api/v1/apis/{api_id}`.

## Tratamento de erros

- O serviço não existe ou não está visível no site atual: `404`.
- `service_id` deve ser um UUID; alias não será resolvido nesta action.
