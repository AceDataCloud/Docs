Cursor atualmente oferece a chave da API OpenAI e a configuração de **Override OpenAI Base URL**, podendo conectar-se a serviços compatíveis com OpenAI. Essa capacidade existe, mas diferentes versões tratam `/chat/completions`, `/responses`, listas de modelos e modos como Agent/Composer de maneira não totalmente consistente.

A compatibilidade entre diferentes versões do Cursor, sistemas operacionais e modos de solicitação pode variar. Por favor, siga a configuração nesta página para concluir a verificação do modo real, não inferindo que todas as funcionalidades estão disponíveis com base em um único chat bem-sucedido.

## O que o Cursor oficial BYOK garante atualmente

De acordo com a [documentação oficial do Cursor Bring your own API key](https://cursor.com/help/models-and-usage/api-keys):

- Suporte a credenciais do OpenAI, Anthropic, Google, Azure OpenAI e AWS Bedrock;
- A chave da API personalizada é usada apenas para modelos de chat, a conclusão de Tab continua usando o modelo embutido do Cursor;
- A chave da API não é persistida nos servidores do Cursor, mas a cada solicitação a chave é enviada ao backend do Cursor, para a construção final do prompt;
- Ao usar sua própria chave, a política de Zero Data Retention do Cursor não se aplica, o processamento de dados segue a política do provedor escolhido.

## Configuração

1. Abra Configurações do Cursor → Modelos.
2. Preencha seu Token da API Ace Data Cloud em OpenAI API Key.
3. Ative **Override OpenAI Base URL**, preenchendo `https://api.acedata.cloud/v1`.
4. Selecione ou adicione um ID de modelo exato compatível com o protocolo atual do Cursor.
5. Primeiro envie `Reply only OK`, depois teste separadamente os modos Ask/Edit/Agent que você realmente utiliza.

## Limites atuais

- A chave da API personalizada é usada apenas para modelos de chat, a conclusão de Tab continua usando o modelo embutido do Cursor.
- O Cursor ainda pode completar a construção final do prompt no servidor; por favor, avalie o caminho dos dados em conjunto com a declaração de privacidade oficial.
- O Override da URL base pode cobrir apenas algumas solicitações, ou pode alternar entre Chat Completions/Responses devido a mudanças de versão.
- Não se deve afirmar que Agent, Auto, Composer ou tarefas em segundo plano estão conectados apenas com base no sucesso de uma solicitação de chat.

## Verificação completa de compatibilidade

Para uso a longo prazo em fluxos de trabalho de produção, conclua as seguintes verificações:

1. Versão fixa do Cursor e sistema operacional;
2. Realize um teste de smoke com um cliente real para essa versão e registre o protocolo e o caminho da solicitação final;
3. Solicitações de Chat Completions do modelo exato bem-sucedidas;
4. Chamadas de ferramentas e solicitações de Agent realmente passam pelo endpoint alvo;
5. O uso e a cobrança podem ser verificados;
6. Registre claramente se a solicitação passou pelos servidores do Cursor e as restrições de privacidade correspondentes.

Após a atualização do cliente, essas verificações devem ser repetidas para confirmar que o protocolo de solicitação, chamadas de ferramentas e caminhos de dados não mudaram.
