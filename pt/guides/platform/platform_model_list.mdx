title: "Obter a lista de modelos da plataforma AceDataCloud"

Retorna o catálogo público de modelos da plataforma, com a resposta adotando a estrutura no estilo OpenAI `{ "object": "list", "data": [...] }`. Este catálogo é usado para seleção de modelos e descoberta de capacidades, e não representa que a conta atual necessariamente já tenha solicitado os serviços correspondentes.

## Visão geral da interface

| Item   | Conteúdo                                              |
| --- | ----------------------------------------------- |
| Método  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| Autenticação  | Público, não requer token de conta                                       |
| Paginação  | Sem paginação, todos os itens correspondentes estão em `data`                              |

## Parâmetros de consulta

| Parâmetro             | Tipo      | Obrigatório  | Descrição                                      |
| -------------- | ------- | --- | --------------------------------------- |
| `owned_by`     | string  | Não   | Filtra precisamente pelo identificador do provedor de modelos no catálogo                        |
| `type`         | string  | Não   | Filtra precisamente pelo tipo de modelo, por exemplo, `chat`                     |
| `capability`   | string  | Não   | Retorna apenas modelos cujas `capabilities` incluem esta capacidade, por exemplo, `vision` |
| `with_pricing` | boolean | Não   | Adiciona informações públicas de preço quando for `1`, `true` ou `yes`            |

`service_id`, `tag`, `limit`, `offset` e `ordering` não são suportados atualmente; passá-los não produzirá os efeitos correspondentes de filtragem ou paginação.

## Exemplos de requisição

```shell
# Todos os modelos públicos
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# Modelos chat que suportam visão, com preços incluídos
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## Estrutura de resposta real

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

`pricing` e o `credit_usd_rate` de nível superior aparecem apenas quando `with_pricing=true`; nem todo modelo possui `pricing` calculável. Os objetos de modelo são baseados nos campos públicos de `config/models.json`, e os clientes devem ignorar novos campos.

> Os campos de preço são dados de exibição do catálogo. As chamadas de negócio reais ainda estão sujeitas às regras de cobrança da API/Service correspondente e aos registros finais de uso.
