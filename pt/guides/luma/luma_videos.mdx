Com a ampla aplicação da IA, vários tipos de programas de IA têm se popularizado gradualmente. A IA tem se aprofundado gradualmente em todos os aspectos do trabalho e da vida das pessoas. E os setores envolvidos pela IA também estão se tornando cada vez mais numerosos, desde a escrita inicial, passando pela educação médica, até os vídeos atuais.

Luma é uma plataforma profissional de geração de vídeos de alta qualidade. Os usuários só precisam enviar materiais para gerar automaticamente vídeos de alta qualidade com base em diferentes estilos e efeitos. Este gerador de vídeos por IA foi desenvolvido por membros de equipes de empresas de tecnologia renomadas, com o objetivo de permitir que todos criem vídeos excelentes facilmente, sem ferramentas de edição complexas.

No entanto, a Luma oficialmente não fornece uma API. A AceDataCloud fornece um conjunto de APIs da Luma, simulando a integração oficial da Suno, permitindo gerar de forma conveniente e rápida os vídeos desejados.

## Solicitação e uso

Para usar a API de Geração de Vídeos Luma, primeiro obtenha seu Token de API no [console do Ace Data Cloud](https://platform.acedata.cloud/console/applications) e guarde-o para uso posterior.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se você ainda não estiver conectado ou registrado, será redirecionado automaticamente para a página de login para se registrar e entrar. Após concluir, você retornará automaticamente a esta página.

**Um único Token de API pode chamar todos os serviços da plataforma, sem necessidade de solicitar separadamente para cada serviço.** A primeira solicitação oferece créditos gratuitos para uma experiência gratuita; quando os créditos forem insuficientes, é possível recarregar o saldo universal no [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentação completa: [API de Geração de Vídeos Luma →](https://platform.acedata.cloud/documents/luma-videos)

## Uso básico

Para gerar qualquer vídeo desejado, você pode inserir livremente um trecho de texto. Por exemplo, se eu quiser gerar um vídeo sobre astronautas viajando entre o espaço e vulcões, posso inserir `Astronauts shuttle from space to volcano`, conforme mostrado na imagem:

O código gerado é o seguinte:

<p><img src="https://cdn.acedata.cloud/ieq7yn.png" width="500" className="m-auto" /></p>

Principais parâmetros de solicitação:

- `prompt`: Texto de instrução para gerar o vídeo.
- `aspect_ratio`: Proporção de aspecto do vídeo, o padrão é 16:9.
- `end_image_url`: Opcional, especifica o quadro final.
- `enhancement`: Opcional, interruptor de aprimoramento de nitidez.
- `loop`: Se deve gerar um vídeo em loop, o padrão é false.
- `timeout`: Opcional, número de segundos de tempo limite.
- `callback_url`: Endereço de callback assíncrono.
- `async`: Opcional, quando definido como `true`, a interface retorna imediatamente o `task_id`, sem necessidade de fornecer `callback_url`; em seguida, obtenha o resultado por polling através da interface de consulta de tarefa correspondente.

Pode-se ver que, neste momento, obtivemos as informações relacionadas a este vídeo, incluindo ID do vídeo, link do vídeo, capa do vídeo e outros conteúdos.

A descrição dos campos é a seguinte:

- success: Se a geração foi bem-sucedida; se foi bem-sucedida, será `true`, caso contrário será `false`
- task_id: O ID único da tarefa de geração de vídeo aqui
- video_id: O ID único do vídeo gerado pela tarefa de geração de vídeo aqui
- prompt: As palavras-chave da tarefa de geração de vídeo aqui
- video_url: O link do vídeo resultante da tarefa de geração de vídeo aqui
- video_height: A altura da imagem de capa do vídeo gerada
- video_width: A largura da imagem de capa do vídeo gerada
- state: O status da tarefa de geração de vídeo aqui; se a tarefa for concluída, será `completed`.
- thumbnail_url: O link da imagem de capa do vídeo gerada
- thumbnail_width: A largura da imagem de capa do vídeo gerada
- thumbnail_height: A altura da imagem de capa do vídeo gerada

## Geração personalizada com quadros inicial e final

Se desejar gerar um vídeo personalizando os quadros inicial e final do vídeo, você pode inserir os links das imagens dos quadros inicial e final:

Neste momento, o campo `start_image_url` do quadro inicial do vídeo pode receber a seguinte imagem como quadro inicial do vídeo:

![Quadro inicial](https://cdn.acedata.cloud/r9vsv9.png)

Em seguida, para gerar um vídeo personalizado com base nos quadros inicial e final e nas palavras-chave, é possível especificar o seguinte conteúdo:

- action: A ação da tarefa de geração de vídeo, geralmente geração normal `generate` e geração de extensão `extend`, o padrão é `generate`.
- start_image_url: Especifica o quadro inicial do vídeo a ser gerado.
- end_image_url: Especifica o quadro final do vídeo a ser gerado.
- prompt: O conteúdo de palavras-chave para gerar o vídeo.

O exemplo de preenchimento é o seguinte:

<p><img src="https://cdn.acedata.cloud/zvzydx.png" width="500" className="m-auto" /></p>

Após o preenchimento, o seguinte código é gerado automaticamente:

<p><img src="https://cdn.acedata.cloud/tx80pu.png" width="500" className="m-auto" /></p>

O código correspondente:

```python
import requests

url = "https://api.acedata.cloud/luma/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "start_image_url": "https://cdn.acedata.cloud/r9vsv9.png",
    "action": "generate",
    "prompt": "Astronauts shuttle from space to volcano"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Funcionalidade de extensão de vídeo

Se quiser continuar gerando o vídeo gerado, você pode definir o parâmetro `action` como `extend` e inserir o ID ou o link do vídeo que precisa continuar sendo gerado. A obtenção do ID e do link do vídeo é feita com base no uso básico, conforme mostrado na imagem abaixo:


> Observe que `video_id` e `video_url` no vídeo aqui são o ID e o link do vídeo gerado. Se você não souber como gerar um vídeo, pode consultar o uso básico acima para gerar um vídeo.

Para continuar gerando o vídeo, é necessário enviar o link ou o ID do vídeo. Abaixo é demonstrado o uso do ID do vídeo para extensão. Em seguida, devemos preencher palavras-chave para personalizar a geração do vídeo, podendo especificar o seguinte conteúdo:

- action: o comportamento de extensão do vídeo neste momento, que aqui deve ser `extend`.
- prompt: as palavras-chave do vídeo que precisa ser estendido.
- video_url: o link do vídeo que precisa ser gerado por extensão.
- video_id: o ID único do vídeo que precisa ser gerado por extensão.
- end_image_url: o link da imagem que pode especificar o quadro final do vídeo gerado por extensão, parâmetro opcional.

```python
import requests
```

## Callback assíncrono

Como o tempo para o Luma gerar vídeos é relativamente longo, levando cerca de 1 a 2 minutos, se a API não responder por muito tempo, a solicitação HTTP permanecerá conectada, resultando em consumo adicional de recursos do sistema. Portanto, esta API também oferece suporte a callbacks assíncronos.
O fluxo geral é: quando o cliente inicia uma solicitação, ele especifica adicionalmente um campo `callback_url`. Após o cliente iniciar uma solicitação de API, a API retornará imediatamente um resultado, contendo um campo `task_id`, que representa o ID da tarefa atual. Quando a tarefa for concluída, o resultado da geração de música será enviado em formato POST JSON para o `callback_url` especificado pelo cliente, incluindo também o campo `task_id`, para que o resultado da tarefa possa ser associado por meio do ID.

A seguir, vamos entender como operar especificamente por meio de um exemplo.

Primeiramente, o callback Webhook é um serviço que pode receber solicitações HTTP, e o desenvolvedor deve substituí-lo pela URL de um servidor HTTP criado por ele mesmo. Aqui, para facilitar a demonstração, usamos um site público de exemplo de Webhook https://webhook.site/. Ao abrir esse site, é possível obter uma URL de Webhook, conforme mostrado na imagem:

<p><img src="https://cdn.acedata.cloud/q78okf.png" width="500" className="m-auto" /></p>

Copie esta URL para usá-la como Webhook; o exemplo aqui é https://webhook.site/0c87ca0e-cd74-4577-8d68-f2b80fbf8a13.
