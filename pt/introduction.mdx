## O que é Ace Data Cloud?

Ace Data Cloud é uma plataforma unificada de API de IA que permite acessar serviços líderes globais de IA com uma única chave API e uma interface consistente.

## Vantagens principais

- **API unificada** — Uma única chave API para acessar mais de 50 serviços de IA
- **Compatível com OpenAI** — Claude, Gemini, DeepSeek e outros podem ser chamados diretamente via interface OpenAI
- **Sandbox interativo** — Teste cada API diretamente na documentação
- **Pagamento conforme uso** — Sem taxa de assinatura, pague pelo uso real
- **Servidor MCP** — Suporte nativo para ferramentas de programação de IA como Cursor, Claude e outras
