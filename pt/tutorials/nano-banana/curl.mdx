## Introdução

Nano Banana é um serviço de IA para imagens fornecido pela Ace Data Cloud, baseado no serviço de geração de imagens Gemini. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o Nano Banana e realizar funções como geração de imagens a partir de texto, edição de imagens, múltiplas proporções e alta resolução.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API Nano Banana é:

```
POST https://api.acedata.cloud/nano-banana/images
```

Este exemplo usa o modelo `nano-banana-2`.  
Modelos disponíveis incluem: `nano-banana`, `nano-banana-2`, `nano-banana-pro`.

Exemplo completo do comando cURL:

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat", "model": "nano-banana-2", "aspect_ratio": "1:1"}'
```

Substitua `YOUR_API_TOKEN` pelo token real obtido na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após uma chamada bem-sucedida, será retornado um dado em formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat", "model": "nano-banana-2", "aspect_ratio": "1:1"}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                       |
|--------|--------------------------------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor       |
