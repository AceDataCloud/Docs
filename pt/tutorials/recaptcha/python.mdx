## Introdução

reCAPTCHA é um serviço de captcha fornecido pela Ace Data Cloud, uma solução do Google reCAPTCHA. Através da API unificada da Ace Data Cloud, você pode integrar rapidamente o reCAPTCHA usando Python, implementando funcionalidades como Token reCAPTCHA v2, reconhecimento reCAPTCHA v2, Token reCAPTCHA v3, entre outras.

## Pré-requisitos

- Possuir uma conta [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente Python 3.7 ou superior
- Instalar a biblioteca requests: `pip install requests`

## Uso Básico

O endpoint principal para chamar a API reCAPTCHA é:

```
POST https://api.acedata.cloud/captcha/token/recaptcha2
```

Exemplo completo de código Python:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/recaptcha2"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-",
    "website_url": "https://www.google.com/recaptcha/api2/demo"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Por favor, substitua `YOUR_API_TOKEN` pelo Token real que você obteve na plataforma Ace Data Cloud.

## Tratamento de Resposta

Após uma chamada bem-sucedida, a API retorna dados em formato JSON. Recomenda-se verificar o código de status HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Chamada bem-sucedida:", result)
else:
    print(f"Chamada falhou, código de status: {response.status_code}")
    print(response.text)
```

## Uso Avançado

Para APIs que suportam tarefas assíncronas, você pode obter resultados via URL de callback:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# O resultado será enviado para seu servidor através da URL de callback
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                           |
|--------|-----------------------------------|
| 401    | Falha de autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de requisições excedido    |
| 500    | Erro interno do servidor          |

## Outros Endpoints

O serviço reCAPTCHA também oferece os seguintes endpoints:

- `POST https://api.acedata.cloud/captcha/recognition/recaptcha2`
- `POST https://api.acedata.cloud/captcha/token/recaptcha3`
