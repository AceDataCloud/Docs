## Introdução

Producer é um serviço de áudio AI fornecido pela Ace Data Cloud, FUZZ Producer AI para geração de música. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o Producer e realizar funções como geração de música a partir de texto, letras personalizadas, continuação de canções, covers, separação de voz e geração de MV.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o Token da API
- Ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API do Producer é:

```
POST https://api.acedata.cloud/producer/audios
```

Este exemplo utiliza o modelo `FUZZ-2.0 Pro`.  
Modelos disponíveis incluem: `FUZZ-2.0 Pro`, `FUZZ-2.0`, `FUZZ-1.1 Pro`, `FUZZ-1.0 Pro`.

Exemplo completo do comando cURL:

```bash
curl -X POST https://api.acedata.cloud/producer/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A relaxing jazz piece for a coffee shop", "model": "FUZZ-2.0 Pro", "lyric": "[Verse]\nSoft piano keys in the morning light", "custom": true}'
```

Substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após a chamada bem-sucedida, retorna dados no formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/producer/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A relaxing jazz piece for a coffee shop", "model": "FUZZ-2.0 Pro", "lyric": "[Verse]\nSoft piano keys in the morning light", "custom": true}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                           |
|--------|-----------------------------------|
| 401    | Falha de autenticação, verifique o Token da API |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor          |
