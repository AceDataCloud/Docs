## Introdução

Hailuo é um serviço de vídeo AI fornecido pela Ace Data Cloud, modelo de geração de vídeo MiniMax Hailuo. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o Hailuo e realizar funções como geração de vídeo a partir de texto, geração de vídeo a partir de imagem, modo diretor, entre outras.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API Hailuo é:

```
POST https://api.acedata.cloud/hailuo/videos
```

Este exemplo usa o modelo `minimax-t2v`.  
Modelos disponíveis incluem: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Exemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}'
```

Substitua `YOUR_API_TOKEN` pelo token real obtido na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após a chamada bem-sucedida, retorna dados no formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código de Status | Descrição                        |
|------------------|---------------------------------|
| 401              | Falha na autenticação, verifique o API Token |
| 403              | Saldo insuficiente ou acesso negado |
| 429              | Limite de frequência de requisições excedido |
| 500              | Erro interno do servidor        |
