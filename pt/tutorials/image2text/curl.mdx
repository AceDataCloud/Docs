## Introdução

Image2Text é um serviço de reconhecimento de captcha de imagem oferecido pela Ace Data Cloud. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o Image2Text, realizando reconhecimento de captcha de imagem, entrada em Base64, entrada via URL, entre outras funcionalidades.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API Image2Text é:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Exemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}'
```

Substitua `YOUR_API_TOKEN` pelo token real que você obteve na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após uma chamada bem-sucedida, será retornado um dado em formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código de Status | Descrição                         |
|------------------|----------------------------------|
| 401              | Falha na autenticação, verifique o API Token |
| 403              | Saldo insuficiente ou acesso negado |
| 429              | Limite de frequência de requisições excedido |
| 500              | Erro interno do servidor          |
