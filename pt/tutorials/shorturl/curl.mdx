## Introdução

Short URL é um serviço de ferramenta fornecido pela Ace Data Cloud para geração de links curtos. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o Short URL e realizar funções como encurtamento de URL e domínio personalizado.

## Pré-requisitos

- Possuir uma conta [Ace Data Cloud](https://platform.acedata.cloud) e obter o Token da API
- Ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API Short URL é:

```
POST https://api.acedata.cloud/shorturl
```

Exemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}'
```

Por favor, substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após a chamada bem-sucedida, será retornado um dado em formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                          |
|--------|----------------------------------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor         |
