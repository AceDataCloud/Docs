## Introdução

Fish TTS é um serviço de áudio AI fornecido pela Ace Data Cloud, serviço de síntese de voz Fish. Através da API unificada da Ace Data Cloud, você pode integrar rapidamente o Fish TTS com Python para realizar conversão de texto em fala, múltiplas vozes, personalização de voz e outras funcionalidades.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente Python 3.7 ou superior
- Instalar a biblioteca requests: `pip install requests`

## Uso Básico

O endpoint principal para chamar a API Fish TTS é:

```
POST https://api.acedata.cloud/fish/audios
```

Este exemplo usa o modelo `fish-tts`.  
Modelos disponíveis incluem: `fish-tts`.

Exemplo completo de código Python:

```python
import requests

url = "https://api.acedata.cloud/fish/audios"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "speech",
    "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务",
    "voice_id": "d7900c21663f485ab63ebdb7e5905036",
    "model": "fish-tts"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Tratamento de Resposta

Após a chamada bem-sucedida, a API retorna dados em formato JSON. Recomenda-se verificar o código de status HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Chamada bem-sucedida:", result)
else:
    print(f"Falha na chamada, código de status: {response.status_code}")
    print(response.text)
```

## Uso Avançado

Para APIs que suportam tarefas assíncronas, é possível obter resultados através de uma URL de callback:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# O resultado será enviado para seu servidor via URL de callback
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                         |
|--------|----------------------------------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de requisições excedido   |
| 500    | Erro interno do servidor         |
