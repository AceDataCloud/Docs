## Introdução

Suno é um serviço de áudio AI fornecido pela Ace Data Cloud, para geração de música AI Suno. Através da API unificada da Ace Data Cloud, você pode integrar rapidamente o Suno usando JavaScript para realizar geração de música a partir de texto, letras personalizadas, continuação de músicas, covers, separação de voz, geração de letras, entre outras funcionalidades.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Node.js 18+ ou ambiente de navegador moderno

## Uso Básico

O endpoint principal para chamar a API do Suno é:

```
POST https://api.acedata.cloud/suno/audios
```

Este exemplo usa o modelo `chirp-v5`.  
Modelos disponíveis incluem: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`.

Exemplo completo de código JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/suno/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A cheerful pop song about summer vacation",
  "model": "chirp-v5",
  "custom": false
}),
});

const result = await response.json();
console.log(result);
```

Substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Tratamento da Resposta

Recomenda-se verificar o código de status da resposta e tratar erros:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Chamada bem-sucedida:", result);
} else {
  console.error(`Falha na chamada, código de status: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Encapsulamento para Node.js

Recomenda-se encapsular em uma função reutilizável:

```javascript
async function callSuno(data) {
  const response = await fetch("https://api.acedata.cloud/suno/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`Erro na API: ${response.status}`);
  return response.json();
}
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição |
|--------|-----------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor |
