## Introdução

AI Chat é um serviço de chat AI fornecido pela Ace Data Cloud, oferecendo serviço de diálogo AI com múltiplos modelos. Através da API unificada da Ace Data Cloud, você pode integrar rapidamente o AI Chat usando Python, suportando múltiplos modelos, diálogos com estado e personagens predefinidos.

## Pré-requisitos

- Ter uma conta [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente Python 3.7 ou superior
- Instalar a biblioteca requests: `pip install requests`

## Uso Básico

O endpoint principal para chamar a API AI Chat é:

```
POST https://api.acedata.cloud/aichat/conversations
```

Este exemplo usa o modelo `gpt-4o`.  
Modelos disponíveis incluem: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Exemplo completo de código Python:

```python
import requests

url = "https://api.acedata.cloud/aichat/conversations"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gpt-4o",
    "question": "O que é inteligência artificial?",
    "stateful": True
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Tratamento de Resposta

Após a chamada bem-sucedida, a API retorna dados em formato JSON. Recomenda-se verificar o código de status HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Chamada bem-sucedida:", result)
else:
    print(f"Falha na chamada, código de status: {response.status_code}")
    print(response.text)
```

## Uso Avançado

Para APIs que suportam tarefas assíncronas, é possível obter resultados via URL de callback:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# O resultado será enviado para seu servidor via callback URL
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                         |
|--------|----------------------------------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor         |
