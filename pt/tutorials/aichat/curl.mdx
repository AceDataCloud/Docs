## Introdução

AI Chat é um serviço de chat AI fornecido pela Ace Data Cloud, oferecendo serviço de diálogo AI com múltiplos modelos. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o AI Chat, implementando suporte a múltiplos modelos, diálogo com estado, papéis predefinidos e outras funcionalidades.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API AI Chat é:

```
POST https://api.acedata.cloud/aichat/conversations
```

Este exemplo usa o modelo `gpt-4o`.  
Modelos disponíveis incluem: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Exemplo completo do comando cURL:

```bash
curl -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}'
```

Substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após uma chamada bem-sucedida, será retornado um dado em formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                          |
|--------|----------------------------------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor          |
