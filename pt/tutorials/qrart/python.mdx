## Introdução

QR Art é um serviço de imagem AI fornecido pela Ace Data Cloud, que gera QR codes artísticos com AI. Através da API unificada da Ace Data Cloud, você pode integrar rapidamente o QR Art usando Python, implementando funcionalidades como QR code de link, QR code de texto, estilos predefinidos, parâmetros personalizados, entre outros.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente Python 3.7 ou superior
- Instalar a biblioteca requests: `pip install requests`

## Uso Básico

O endpoint principal para chamar a API do QR Art é:

```
POST https://api.acedata.cloud/qrart/generate
```

Exemplo completo de código Python:

```python
import requests

url = "https://api.acedata.cloud/qrart/generate"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "type": "link",
    "content": "https://platform.acedata.cloud",
    "prompt": "sunset ocean waves",
    "preset": "neon-mech"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Substitua `YOUR_API_TOKEN` pelo Token real que você obteve na plataforma Ace Data Cloud.

## Tratamento da Resposta

Após uma chamada bem-sucedida, a API retorna dados no formato JSON. Recomenda-se verificar o código de status HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Chamada bem-sucedida:", result)
else:
    print(f"Falha na chamada, código de status: {response.status_code}")
    print(response.text)
```

## Uso Avançado

Para APIs que suportam tarefas assíncronas, você pode obter o resultado via URL de callback:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# O resultado será enviado para seu servidor através da URL de callback
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição |
|--------|-----------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de requisições excedido |
| 500    | Erro interno do servidor |
