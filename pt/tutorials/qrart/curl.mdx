## Introdução

QR Art é um serviço de imagem AI fornecido pela Ace Data Cloud, que gera códigos QR artísticos com inteligência artificial. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o QR Art, realizando funções como códigos QR para links, códigos QR para texto, estilos predefinidos e parâmetros personalizados.

## Pré-requisitos

- Possuir uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ter um ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API QR Art é:

```
POST https://api.acedata.cloud/qrart/generate
```

Exemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}'
```

Por favor, substitua `YOUR_API_TOKEN` pelo token real que você obteve na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após uma chamada bem-sucedida, retorna dados no formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                         |
|--------|----------------------------------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor         |
