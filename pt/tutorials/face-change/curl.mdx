## Introdução

Face Change é um serviço de IA para imagens oferecido pela Ace Data Cloud, focado em processamento facial. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o Face Change e realizar substituição facial, embelezamento facial, transformação de idade, mudança de gênero, estilização em anime, análise facial e outras funcionalidades.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API Face Change é:

```
POST https://api.acedata.cloud/face/swap
```

Exemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}'
```

Substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após uma chamada bem-sucedida, será retornado um dado em formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição |
|--------|-----------|
| 401 | Falha na autenticação, verifique o API Token |
| 403 | Saldo insuficiente ou acesso negado |
| 429 | Limite de frequência de requisições excedido |
| 500 | Erro interno do servidor |
