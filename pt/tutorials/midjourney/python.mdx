## Introdução

Midjourney é um serviço de imagem AI fornecido pela Ace Data Cloud, gerando imagens com Midjourney AI. Através da API unificada da Ace Data Cloud, você pode integrar rapidamente o Midjourney usando Python para realizar geração de imagens a partir de texto, edição de imagens, descrição de imagens, geração de vídeos a partir de imagens, controle de Seed, callback assíncrono, entre outras funcionalidades.

## Pré-requisitos

- Possuir uma conta [Ace Data Cloud](https://platform.acedata.cloud) e obter o Token da API
- Ambiente Python 3.7 ou superior
- Instalar a biblioteca requests: `pip install requests`

## Uso Básico

O endpoint principal para chamar a API Midjourney é:

```
POST https://api.acedata.cloud/midjourney/imagine
```

Exemplo completo de código Python:

```python
import requests

url = "https://api.acedata.cloud/midjourney/imagine"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "A serene Japanese garden with cherry blossoms",
    "action": "generate",
    "mode": "fast",
    "translation": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Tratamento de Resposta

Após a chamada bem-sucedida, a API retorna dados no formato JSON. Recomenda-se verificar o código de status HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Chamada bem-sucedida:", result)
else:
    print(f"Falha na chamada, código de status: {response.status_code}")
    print(response.text)
```

## Uso Avançado

Para APIs que suportam tarefas assíncronas, é possível obter resultados via callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# O resultado será enviado para seu servidor através do callback URL
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição |
|--------|-----------|
| 401    | Falha na autenticação, verifique o Token da API |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor |

## Outros Endpoints

O serviço Midjourney também oferece os seguintes endpoints:

- `POST https://api.acedata.cloud/midjourney/seed`
- `POST https://api.acedata.cloud/midjourney/edits`
- `POST https://api.acedata.cloud/midjourney/videos`
- `POST https://api.acedata.cloud/midjourney/describe`
