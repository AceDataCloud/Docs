## Introdução

Midjourney é um serviço de imagens AI fornecido pela Ace Data Cloud, que gera imagens com inteligência artificial. Através da API unificada da Ace Data Cloud, você pode integrar rapidamente o Midjourney usando JavaScript para realizar geração de imagens a partir de texto, edição de imagens, descrição de imagens, criação de vídeos a partir de imagens, controle de Seed, callbacks assíncronos, entre outras funcionalidades.

## Pré-requisitos

- Possuir uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Node.js 18+ ou ambiente de navegador moderno

## Uso Básico

O endpoint principal para chamar a API do Midjourney é:

```
POST https://api.acedata.cloud/midjourney/imagine
```

Exemplo completo de código JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/midjourney/imagine", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "A serene Japanese garden with cherry blossoms",
  "action": "generate",
  "mode": "fast",
  "translation": true
}),
});

const result = await response.json();
console.log(result);
```

Substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Tratamento da Resposta

Recomenda-se verificar o código de status da resposta e tratar erros:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Chamada bem-sucedida:", result);
} else {
  console.error(`Chamada falhou, código de status: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Encapsulamento para Node.js

Recomenda-se encapsular em uma função reutilizável:

```javascript
async function callMidjourney(data) {
  const response = await fetch("https://api.acedata.cloud/midjourney/imagine", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`Erro na API: ${response.status}`);
  return response.json();
}
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição |
|--------|-----------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de requisições excedido |
| 500    | Erro interno do servidor |
