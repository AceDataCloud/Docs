## Introdução

Midjourney é um serviço de imagem AI fornecido pela Ace Data Cloud, que gera imagens com Midjourney AI. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o Midjourney e realizar funcionalidades como geração de imagem a partir de texto, edição de imagem, descrição de imagem, geração de vídeo a partir de imagem, controle de Seed, callback assíncrono, entre outras.

## Pré-requisitos

- Ter uma conta [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API Midjourney é:

```
POST https://api.acedata.cloud/midjourney/imagine
```

Exemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}'
```

Substitua `YOUR_API_TOKEN` pelo Token real que você obteve na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após uma chamada bem-sucedida, será retornado um dado em formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                         |
|--------|----------------------------------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor          |
