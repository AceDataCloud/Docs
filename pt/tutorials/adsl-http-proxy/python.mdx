## Introdução

ADSL HTTP Proxy é um serviço de proxy de rede fornecido pela Ace Data Cloud, que extrai IPs dinâmicos de proxy ADSL. Através da API unificada da Ace Data Cloud, você pode integrar rapidamente o ADSL HTTP Proxy usando Python, implementando funcionalidades como proxy HTTP/SOCKS, múltiplos provedores, múltiplas províncias, duração personalizada, whitelist de IPs, entre outras.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente Python 3.7 ou superior
- Instalar a biblioteca requests: `pip install requests`

## Uso Básico

O endpoint principal para chamar a API do ADSL HTTP Proxy é:

```
POST https://api.acedata.cloud/adsl/extract
```

Exemplo completo de código Python:

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "number": 5,
    "type": "http",
    "duration": 300,
    "province": "广东",
    "isp": "电信"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Tratamento de Resposta

Após a chamada bem-sucedida, a API retorna dados em formato JSON. Recomenda-se verificar o código de status HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Chamada bem-sucedida:", result)
else:
    print(f"Falha na chamada, código de status: {response.status_code}")
    print(response.text)
```

## Uso Avançado

Para APIs que suportam tarefas assíncronas, é possível obter resultados via URL de callback:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# O resultado será enviado para seu servidor através da URL de callback
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                          |
|--------|----------------------------------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de requisições excedido    |
| 500    | Erro interno do servidor          |
