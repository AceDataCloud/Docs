## Introdução

Google Search é um serviço de busca fornecido pela Ace Data Cloud, através da API Google Search. Com a API unificada da Ace Data Cloud, você pode integrar rapidamente o Google Search usando JavaScript para realizar buscas na web, imagens, notícias, mapas, vídeos, entre outras funcionalidades.

## Pré-requisitos

- Possuir uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente Node.js 18+ ou navegador moderno

## Uso Básico

O endpoint principal para chamar a API Google Search é:

```
POST https://api.acedata.cloud/serp/google
```

Exemplo completo de código JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/serp/google", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "query": "artificial intelligence latest news",
  "type": "search",
  "number": 10,
  "language": "en",
  "country": "US"
}),
});

const result = await response.json();
console.log(result);
```

Substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Tratamento da Resposta

Recomenda-se verificar o código de status da resposta e tratar erros:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Chamada bem-sucedida:", result);
} else {
  console.error(`Falha na chamada, código de status: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Encapsulamento em Node.js

Recomenda-se encapsular em uma função reutilizável:

```javascript
async function callGoogleSearch(data) {
  const response = await fetch("https://api.acedata.cloud/serp/google", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`Erro na API: ${response.status}`);
  return response.json();
}
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição |
|--------|-----------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de requisições excedido |
| 500    | Erro interno do servidor |
