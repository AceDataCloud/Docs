---

## Introdução

Identity é um serviço de autenticação fornecido pela Ace Data Cloud, que realiza verificação de identidade com cartão de identidade, cartão bancário e número de telefone. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o Identity e realizar funções como OCR de cartão de identidade, verificação de cartão de identidade, verificação de cartão bancário e verificação de número de telefone.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API Identity é:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Exemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}'
```

Por favor, substitua `YOUR_API_TOKEN` pelo token real obtido na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após uma chamada bem-sucedida, será retornado um dado no formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                          |
|--------|----------------------------------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor          |
