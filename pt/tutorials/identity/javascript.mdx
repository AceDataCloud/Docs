## Introdução

Identity é um serviço de autenticação fornecido pela Ace Data Cloud para verificação de identidade com cartão de identidade, cartão bancário e número de telefone. Através da API unificada da Ace Data Cloud, você pode integrar rapidamente o Identity usando JavaScript para realizar OCR de cartão de identidade, verificação de cartão de identidade, verificação de cartão bancário, verificação de número de telefone, entre outras funcionalidades.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Node.js 18+ ou ambiente de navegador moderno

## Uso Básico

O endpoint principal da API Identity é:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Exemplo completo de código JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/identity/idcard/ocr", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "image_url": "https://example.com/idcard-front.jpg"
}),
});

const result = await response.json();
console.log(result);
```

Substitua `YOUR_API_TOKEN` pelo Token real que você obteve na plataforma Ace Data Cloud.

## Tratamento da Resposta

Recomenda-se verificar o código de status da resposta e tratar erros:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Chamada bem-sucedida:", result);
} else {
  console.error(`Chamada falhou, código de status: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Encapsulamento para Node.js

Recomenda-se encapsular em uma função reutilizável:

```javascript
async function callIdentity(data) {
  const response = await fetch("https://api.acedata.cloud/identity/idcard/ocr", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`Erro na API: ${response.status}`);
  return response.json();
}
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                          |
|--------|----------------------------------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor         |
