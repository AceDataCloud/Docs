## Introdução

OpenAI é o serviço de chat AI fornecido pela Ace Data Cloud, baseado na série de grandes modelos de linguagem OpenAI GPT. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o OpenAI, realizando diálogos multi-turnos, prompts de sistema, saída em streaming, modo de saída JSON, incorporação de texto, geração de imagens e outras funcionalidades.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o Token da API
- Ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API OpenAI é:

```
POST https://api.acedata.cloud/openai/chat/completions
```

Este exemplo usa o modelo `gpt-4o`.  
Modelos disponíveis incluem: `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`.

Exemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Por favor, substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após uma chamada bem-sucedida, retorna dados no formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código de Status | Descrição                      |
|------------------|-------------------------------|
| 401              | Falha na autenticação, verifique o API Token |
| 403              | Saldo insuficiente ou acesso negado |
| 429              | Limite de frequência de requisições excedido |
| 500              | Erro interno do servidor       |
