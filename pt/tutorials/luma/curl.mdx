## Introdução

Luma é um serviço de vídeo AI fornecido pela Ace Data Cloud, com geração de vídeo Luma Dream Machine. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o Luma, realizando funcionalidades como vídeo a partir de texto, vídeo a partir de imagem, continuação de vídeo, controle de quadros inicial e final, vídeo em loop, entre outras.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API do Luma é:

```
POST https://api.acedata.cloud/luma/videos
```

Exemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}'
```

Por favor, substitua `YOUR_API_TOKEN` pelo token real obtido na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após a chamada bem-sucedida, retorna dados no formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                        |
|--------|--------------------------------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor       |
