## Introdução

Seedream é um serviço de imagem AI fornecido pela Ace Data Cloud, utilizando o modelo de geração de imagens Seedream da ByteDance. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o Seedream e realizar funções como geração de imagens a partir de texto, edição de imagens, múltiplas resoluções, controle de marca d'água, entre outras.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ter um ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API Seedream é:

```
POST https://api.acedata.cloud/seedream/images
```

Este exemplo utiliza o modelo `doubao-seedream-4-0-250828`.  
Modelos disponíveis incluem: `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`, `doubao-seedream-3-0-t2i-250415`, `doubao-seededit-3-0-i2i-250628`.

Exemplo completo de comando cURL:

```bash
curl -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}'
```

Substitua `YOUR_API_TOKEN` pelo token real que você obteve na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após uma chamada bem-sucedida, será retornado um dado em formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                          |
|--------|----------------------------------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor         |
