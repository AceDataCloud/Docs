## Introdução

Flux é um serviço de imagem AI fornecido pela Ace Data Cloud, baseado no modelo de geração de imagens Black Forest Labs Flux. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o Flux, realizando geração de imagens a partir de texto, edição de imagens, múltiplos modelos, tamanhos personalizados, entre outras funcionalidades.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o Token de API
- Ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API Flux é:

```
POST https://api.acedata.cloud/flux/images
```

Este exemplo usa o modelo `flux-pro-1.1`.  
Modelos disponíveis incluem: `flux-dev`, `flux-pro`, `flux-pro-1.1`, `flux-pro-1.1-ultra`, `flux-kontext-pro`, `flux-kontext-max`.

Exemplo completo do comando cURL:

```bash
curl -X POST https://api.acedata.cloud/flux/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat sitting on a windowsill", "model": "flux-pro-1.1", "size": "1024x1024"}'
```

Substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após uma chamada bem-sucedida, retorna dados no formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/flux/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat sitting on a windowsill", "model": "flux-pro-1.1", "size": "1024x1024"}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código de Status | Descrição                          |
|------------------|----------------------------------|
| 401              | Falha de autenticação, verifique o Token de API |
| 403              | Saldo insuficiente ou acesso negado |
| 429              | Limite de frequência de requisições excedido |
| 500              | Erro interno do servidor          |
