## Introdução

Localization é um serviço de ferramenta fornecido pela Ace Data Cloud, um serviço de tradução AI para localização. Através da API unificada da Ace Data Cloud, você pode usar cURL para chamar rapidamente o Localization, realizando tradução de Markdown, tradução de JSON, suporte a 18 idiomas, preservação de formato, entre outras funcionalidades.

## Pré-requisitos

- Ter uma conta [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente de terminal com cURL instalado

## Uso Básico

O endpoint principal para chamar a API Localization é:

```
POST https://api.acedata.cloud/localization/translate
```

Este exemplo utiliza o modelo `gpt-4`.  
Modelos disponíveis incluem: `gpt-3.5`, `gpt-4`.

Exemplo completo do comando cURL:

```bash
curl -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}'
```

Substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Exemplo de Resposta

Após uma chamada bem-sucedida, será retornado um dado em formato JSON, por exemplo:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Usando jq para Processar a Resposta

Recomenda-se usar a ferramenta jq para formatar a saída:

```bash
curl -s -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}' | jq .
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                          |
|--------|----------------------------------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor          |
