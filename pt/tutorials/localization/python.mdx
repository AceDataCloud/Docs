## Introdução

Localization é um serviço de ferramenta fornecido pela Ace Data Cloud, um serviço de tradução e localização por IA. Através da API unificada da Ace Data Cloud, você pode integrar rapidamente o Localization usando Python para realizar tradução de Markdown, tradução de JSON, suporte a 18 idiomas, preservação de formato, entre outras funcionalidades.

## Pré-requisitos

- Ter uma conta na [Ace Data Cloud](https://platform.acedata.cloud) e obter o API Token
- Ambiente Python 3.7 ou superior
- Instalar a biblioteca requests: `pip install requests`

## Uso Básico

O endpoint principal para chamar a API Localization é:

```
POST https://api.acedata.cloud/localization/translate
```

Este exemplo utiliza o modelo `gpt-4`.  
Modelos disponíveis incluem: `gpt-3.5`, `gpt-4`.

Exemplo completo de código Python:

```python
import requests

url = "https://api.acedata.cloud/localization/translate"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "input": "# 欢迎使用\n\n这是一段示例文本。",
    "locale": "en",
    "extension": "md",
    "model": "gpt-4"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Por favor, substitua `YOUR_API_TOKEN` pelo Token real obtido na plataforma Ace Data Cloud.

## Tratamento de Resposta

Após uma chamada bem-sucedida, a API retorna dados em formato JSON. Recomenda-se verificar o código de status HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Chamada bem-sucedida:", result)
else:
    print(f"Falha na chamada, código de status: {response.status_code}")
    print(response.text)
```

## Uso Avançado

Para APIs que suportam tarefas assíncronas, é possível obter o resultado via URL de callback:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# O resultado será enviado para seu servidor através da URL de callback
```

## Tratamento de Erros

Códigos de erro comuns:

| Código | Descrição                          |
|--------|----------------------------------|
| 401    | Falha na autenticação, verifique o API Token |
| 403    | Saldo insuficiente ou acesso negado |
| 429    | Limite de frequência de requisições excedido |
| 500    | Erro interno do servidor         |
