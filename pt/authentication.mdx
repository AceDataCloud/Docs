Todas as APIs do Ace Data Cloud utilizam autenticação **Bearer Token**.

## Obter Token

Entre em [Applications](https://platform.acedata.cloud/console/applications?lang=pt&utm_source=docs&utm_medium=referral&utm_campaign=evergreen) e abra **General Application**. Se o aplicativo ainda não aparecer, selecione **Initialize General Application**. Ao lado de **API KEY**, clique no botão de copiar indicado pelo número **1** na imagem.

![Botão para copiar a chave do aplicativo, indicado pelo número 1](https://raw.githubusercontent.com/AceDataCloud/NanoBananaDify/2522b2f57210597af2db866445319334a1677a23/_assets/tutorial/get-api-key-en.png)

Guarde a chave no servidor e use o valor copiado no lugar de `YOUR_API_TOKEN` no exemplo.

## Usar Token

Inclua o Token no cabeçalho `Authorization` de cada requisição:

```bash
Authorization: Bearer YOUR_API_TOKEN
```


## Limite de taxa

O limite de taxa varia conforme o serviço e o nível da assinatura. Se ultrapassado, a API retorna `429 Too Many Requests`.

## Melhores práticas de segurança

- Não exponha o API Token no código cliente
- Armazene o Token em variáveis de ambiente
- Faça a rotação periódica dos Tokens
- Use Tokens diferentes para ambientes de desenvolvimento e produção
