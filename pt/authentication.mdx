title: "Autenticação"
description: "Como autenticar usando a API do Ace Data Cloud"
---

Todas as APIs do Ace Data Cloud utilizam autenticação **Bearer Token**.

## Obter Token

1. Registre uma conta em [platform.acedata.cloud](https://platform.acedata.cloud)
2. Assine os serviços necessários
3. Crie credenciais (API Token) para cada serviço

## Usar Token

Inclua o Token no cabeçalho `Authorization` de cada requisição:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Dica">
  Cada Token está vinculado a uma assinatura de serviço específica. Use Tokens diferentes para serviços distintos ou crie credenciais **globais** para uso entre serviços.
</Note>

## Limite de taxa

O limite de taxa varia conforme o serviço e o nível da assinatura. Se ultrapassado, a API retorna `429 Too Many Requests`.

## Melhores práticas de segurança

- Não exponha o API Token no código cliente
- Armazene o Token em variáveis de ambiente
- Faça a rotação periódica dos Tokens
- Use Tokens diferentes para ambientes de desenvolvimento e produção
