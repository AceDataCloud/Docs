O [MCP (Model Context Protocol)](https://modelcontextprotocol.io) é um protocolo de contexto de modelo lançado pela Anthropic, que permite que modelos de IA (como Claude, GPT etc.) chamem ferramentas externas por meio de interfaces padronizadas. Por meio do Flux MCP Server fornecido pelo AceData Cloud, você pode gerar e editar imagens de IA diretamente em clientes de IA como Claude Desktop, VS Code, Cursor etc.

## Visão Geral dos Recursos

O Flux MCP Server fornece os seguintes recursos principais:

- **Geração de imagem a partir de texto** — Gera imagens de alta qualidade por meio de prompts de texto
- **Edição de imagem** — Edita imagens existentes com base em instruções de texto
- **Suporte a múltiplos modelos** — Suporta diversos modelos, como Flux Pro, Flux Dev, Flux 2, Flux Kontext etc.
- **Consulta de modelos** — Visualize todos os modelos disponíveis e suas capacidades
- **Consulta de tarefas** — Monitore o progresso da geração e obtenha os resultados

## Preparação

Antes de usar, você precisa obter um API Token do AceData Cloud:

1. Registre-se ou faça login na [plataforma AceData Cloud](https://platform.acedata.cloud)
2. Acesse a página [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Clique em «Acquire» para obter o API Token (a primeira solicitação inclui créditos gratuitos)

## Método 1: Usar o MCP Server hospedado (recomendado, sem instalação)

O AceData Cloud já hospedou o **Flux MCP Server** na nuvem, **sem necessidade de instalar nenhuma dependência localmente**; basta preencher a seguinte URL no cliente de IA para usá-lo:

```
https://flux.mcp.acedata.cloud/mcp
```

Método de autenticação: basta adicionar `Authorization: Bearer seu API Token` ao cabeçalho da solicitação (o Claude.ai conclui automaticamente por OAuth, sem necessidade de preencher o Token manualmente).

### Claude.ai (versão web, login OAuth, o mais simples)

1. Abra [Claude.ai](https://claude.ai) → **Customize** no canto inferior esquerdo → **Connectors** → **Add More**
2. Preencha a URL: `https://flux.mcp.acedata.cloud/mcp`
3. Conclua o login de autorização OAuth (redirecionamento automático para a página de login do AceData Cloud)
4. Volte à interface de conversa, e as ferramentas estarão disponíveis

### Claude Desktop

Edite o arquivo de configuração:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Salve e reinicie o Claude Desktop para que tenha efeito.

### Claude Code (linha de comando do terminal)

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Outros clientes que suportam MCP

Qualquer cliente que suporte o protocolo MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant etc.) pode se integrar preenchendo os dois itens a seguir:

- **URL**: `https://flux.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer seu API Token`

## Método 2: Execução local (instalação via pip / uvx)

Se você precisar executar offline, personalizar o código ou implantar em uma rede interna, poderá instalar o MCP Server localmente e iniciá-lo por meio de stdio.

### Instalação

Instalação via pip (recomendado):

```bash
pip install mcp-flux-pro
```

Ou instalação a partir do código-fonte:

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Após a instalação, você poderá usar o comando `mcp-flux-pro` para iniciar o serviço.

### Uso no Claude Desktop (local)

Edite o arquivo de configuração do Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Adicione a seguinte configuração:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Se usar `uvx` (não é necessário instalar o pacote antecipadamente):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Salve a configuração e reinicie o Claude Desktop para que tenha efeito.

### Uso no VS Code / Cursor (local)

Crie `.vscode/mcp.json` no diretório raiz do projeto:

## Lista de Ferramentas Disponíveis

| Nome da ferramenta                    | Descrição                       |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | Gera imagens por meio de prompts de texto              |
| `flux_edit_image`      | Edita imagens existentes com base em instruções de texto             |
| `flux_generate_video`  | Geração de texto para vídeo/imagem para vídeo do FLUX 3 e aprimoramento de rascunhos existentes |
| `flux_get_task`        | Consulta o status de uma única tarefa                 |
| `flux_get_tasks_batch` | Consulta em lote o status das tarefas                 |
| `flux_list_models`     | Lista todos os modelos disponíveis e suas capacidades             |
| `flux_list_actions`    | Lista todas as ferramentas disponíveis e exemplos de fluxos de trabalho           |

## Exemplos de Uso

Após concluir a configuração, você poderá chamar diretamente esses recursos em linguagem natural no cliente de IA, por exemplo:

- «Ajude-me a usar o Flux para gerar uma imagem de uma paisagem urbana noturna em estilo cyberpunk»
- «Altere o plano de fundo desta foto para uma praia»
- «Use o modelo Flux Kontext Pro para editar esta imagem e alterar a cor da roupa para vermelho»
- «Liste todos os modelos Flux disponíveis»

## Restrições de Modelos e Dimensões
`flux-2-flex`, `flux-2-pro`, `flux-2-max` e os modelos Kontext devem usar
proporções para `size`, por exemplo `1:1` ou `16:9`, e não podem usar dimensões em pixels como `1024x1024`.
`flux-2-klein` suporta apenas geração e não está entre os modelos opcionais de `flux_edit_image`.

`flux_generate_video` distingue `t2v`, `i2v`, `v2v` e
`draft_enhance` por meio de `request.mode`, e as entradas são exibidas de acordo com o modo. O aprimoramento de rascunho deve referenciar seu próprio `draft_task_id` temporário.
O envio é assíncrono por padrão; mantenha o ID da tarefa retornado e use `flux_get_task` para ler o resultado.
