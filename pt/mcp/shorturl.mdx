[MCP (Model Context Protocol)](https://modelcontextprotocol.io) é um protocolo de contexto de modelo lançado pela Anthropic, que permite que modelos de IA (como Claude, GPT, etc.) chamem ferramentas externas por meio de uma interface padronizada. Com o ShortURL MCP Server fornecido pela AceData Cloud, você pode gerar links curtos diretamente em clientes de IA como Claude Desktop, VS Code, Cursor, entre outros.

## Visão Geral das Funcionalidades

O ShortURL MCP Server oferece as seguintes funcionalidades principais:

- **Encurtamento de link único** — Converte URLs longas em links curtos fáceis de compartilhar  
- **Encurtamento em lote** — Encurta múltiplos URLs de uma vez (até 10)  
- **Guia de uso** — Obtenha instruções completas e melhores práticas  
- **Informações da API** — Consulte detalhes do serviço API e códigos de erro  

## Preparação

Antes de usar, você precisa obter o Token da API da AceData Cloud:

1. Registre-se ou faça login na [plataforma AceData Cloud](https://platform.acedata.cloud)  
2. Acesse a página da [API ShortURL](https://platform.acedata.cloud/documents/short-url)  
3. Clique em "Acquire" para obter o Token da API (a primeira solicitação concede uma cota gratuita)  

## Instalação e Configuração

### Método 1: Instalação via pip (recomendado)

```bash
pip install mcp-shorturl
```

### Método 2: Instalação via código-fonte

```bash
git clone https://github.com/AceDataCloud/ShortURLMCP.git
cd ShortURLMCP
pip install -e .
```

Após a instalação, você pode iniciar o serviço com o comando `mcp-shorturl`.

## Uso no Claude Desktop

Edite o arquivo de configuração do Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`  
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`  

Adicione a seguinte configuração:

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "seu API Token"
      }
    }
  }
}
```

Se usar `uvx` (sem necessidade de instalar pacotes antecipadamente):

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "uvx",
      "args": ["mcp-shorturl"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "seu API Token"
      }
    }
  }
}
```

Salve a configuração e reinicie o Claude Desktop para usar as ferramentas ShortURL nas conversas.

## Lista de Ferramentas Disponíveis

| Nome da Ferramenta       | Descrição                          |
|-------------------------|----------------------------------|
| `shorturl_create`       | Encurta um único URL              |
| `shorturl_batch_create` | Encurta múltiplos URLs (até 10)  |
| `shorturl_get_usage_guide` | Obtém o guia completo de uso    |
| `shorturl_get_api_info` | Obtém detalhes do serviço API    |

## Exemplos de Uso

Após configurar, você pode chamar essas funcionalidades diretamente em linguagem natural nos clientes de IA, por exemplo:

- "Me ajude a encurtar este link"  
- "Encurte estes 5 URLs em lote"  
- "Gere um link curto para compartilhar"
