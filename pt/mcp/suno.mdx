[MCP (Model Context Protocol)](https://modelcontextprotocol.io) é um protocolo de contexto de modelo lançado pela Anthropic, que permite que modelos de IA (como Claude, GPT etc.) chamem ferramentas externas por meio de interfaces padronizadas. Por meio do Suno MCP Server fornecido pela AceData Cloud, você pode gerar diretamente músicas, letras e gerenciar projetos de áudio em clientes de IA como Claude Desktop, VS Code, Cursor etc.

## Visão geral dos recursos

O Suno MCP Server fornece os seguintes recursos principais:

- **Geração de música** — Gera música de IA por meio de prompts de texto
- **Criação personalizada** — Controle completo sobre letras, título e estilo musical
- **Continuação de músicas** — Continua estendendo músicas existentes a partir de qualquer ponto no tempo
- **Cover/remix** — Cria versões cover em estilos diferentes
- **Geração de letras** — Gera letras estruturadas com base em descrições
- **Personagens vocais** — Salva e reutiliza estilos de voz
- **Conversão de mídia** — Obtém MP4, WAV, MIDI, separação vocal etc.
- **Otimização de estilo** — Otimiza tags de estilo musical
- **Consulta de tarefas** — Monitora o progresso de geração e obtém resultados

## Preparação

Antes de usar, você precisa obter o AceData Cloud API Token:

1. Registre-se ou faça login na [plataforma AceData Cloud](https://platform.acedata.cloud)
2. Acesse a página [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Clique em «Acquire» para obter o API Token (a primeira solicitação inclui créditos gratuitos)

## Método um: usar o MCP Server hospedado (recomendado, sem instalação)

A AceData Cloud já hospedou o **Suno MCP Server** na nuvem, **sem necessidade de instalar nenhuma dependência localmente**; basta preencher o URL abaixo diretamente no cliente de IA para usá-lo:

```
https://suno.mcp.acedata.cloud/mcp
```

Método de autenticação: basta adicionar `Authorization: Bearer seu API Token` ao cabeçalho da solicitação (o Claude.ai conclui automaticamente por OAuth, sem necessidade de preencher o Token manualmente).

### Claude.ai (versão web, login OAuth, o mais simples)

1. Abra [Claude.ai](https://claude.ai) → **Customize** no canto inferior esquerdo → **Connectors** → **Add More**
2. Preencha o URL: `https://suno.mcp.acedata.cloud/mcp`
3. Conclua o login de autorização OAuth (redirecionamento automático para a página de login da AceData Cloud)
4. Volte à interface de conversa para usar as ferramentas

### Claude Desktop

Edite o arquivo de configuração:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Salve e reinicie o Claude Desktop para que tenha efeito.

### Claude Code (linha de comando do terminal)

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Outros clientes que oferecem suporte a MCP

Qualquer cliente que ofereça suporte ao protocolo MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant etc.) pode se integrar preenchendo os dois itens abaixo:

- **URL**: `https://suno.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer seu API Token`

## Método dois: executar localmente (instalação por pip / uvx)

Se você precisar executar offline, personalizar o código ou implantar em uma rede interna, poderá instalar o MCP Server localmente e iniciá-lo por meio de stdio.

### Instalação

Instalação por pip (recomendada):

```bash
pip install mcp-suno
```

Ou instalação a partir do código-fonte:

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

Após a instalação, você poderá usar o comando `mcp-suno` para iniciar o serviço.

### Usar no Claude Desktop (local)

Edite o arquivo de configuração do Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Adicione a seguinte configuração:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Se usar `uvx` (não é necessário instalar o pacote antecipadamente):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Salve a configuração e reinicie o Claude Desktop para que tenha efeito.

### Usar no VS Code / Cursor (local)

## Exemplos de uso

Após a configuração, você pode chamar diretamente esses recursos no cliente de IA usando linguagem natural, por exemplo:

- 「Ajude-me a gerar uma música pop sobre o verão」
- 「Faça um cover desta música em estilo jazz」
- 「Continue esta música, começando no segundo 30」
- 「Gere uma letra em chinês, com o tema de viagem」
- 「Separe os vocais desta música」
- 「Ajude-me a converter esta música para o formato MIDI」

## Controle avançado e projetos Studio

`suno_generate_music` suporta `variety`; `suno_generate_custom_music` também suporta
`max_mode` e `audio_weight`. `max_mode` utiliza um nível de cobrança de API mais alto e não é ativado por padrão,
devendo ser definido após o usuário escolher explicitamente o modo aprimorado. Os preços atuais prevalecem conforme a página de serviço da plataforma.

`suno_generate_with_custom_model` pode usar `instrumental=true` para gerar música instrumental, ou usar
`lyric_prompt` para gerar letras automaticamente; caso contrário, forneça `lyric`. Título e estilo podem ser omitidos, e também podem ser passados
`negative_tags`, `vocal_gender`, `weirdness`, `style_influence`, `duration` e
`callback_url`. Valores de controle explícitos de `0` serão preservados.

`request.action` de `suno_manage_project` pode ser `create`, `retrieve`, `save`,
`upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`,
`remove_track`, `render`. As entradas variam conforme a ação, e modificações no projeto devem usar o `version_id` da leitura mais recente;
ao salvar, passe o `state` completo, preservando as faixas e os campos existentes.

Exceto `retrieve`, cada chamada deve fornecer um `idempotency_key`. Use uma nova chave para novas operações de escrita;
quando houver timeout ou o resultado de aceitação for incerto, mantenha a chave original e repita exatamente a mesma solicitação, ou consulte a tarefa original, não
troque automaticamente a chave para reenviar uma geração cobrada. Os intervalos de áudio de origem usam segundos, e os intervalos da linha do tempo do projeto usam batidas. A geração apenas cria candidatos,
sendo necessário selecionar um candidato e chamar `commit_candidate` para gravá-lo na faixa.

Consulte o `task_id` aceito de forma assíncrona usando `suno_get_task`. Quando `finished_at` estiver vazio, continue aguardando,
e, após o estado final, verifique `response.success` e os erros; não considere uma aceitação bem-sucedida como geração, envio ou exportação bem-sucedida.
`suno_get_tasks_batch` retorna registros completos de tarefas em JSON, preservando objetos de modelos personalizados, estado do projeto,
candidatos e vários tipos de resultados, como MIDI. Para o fluxo de trabalho completo, consulte o [Guia de projetos Studio](https://platform.acedata.cloud/documents/suno-projects-integration).
