[MCP (Model Context Protocol)](https://modelcontextprotocol.io) é um protocolo de contexto de modelo lançado pela Anthropic, que permite que modelos de IA (como Claude, GPT, etc.) chamem ferramentas externas por meio de uma interface padronizada. Com o Seedream MCP Server fornecido pela AceData Cloud, você pode usar diretamente a geração e edição de imagens de IA da ByteDance Seedream em clientes de IA como Claude Desktop, VS Code, Cursor, entre outros.

## Visão Geral das Funcionalidades

O Seedream MCP Server oferece as seguintes funcionalidades principais:

- **Geração de imagem a partir de texto** — gera imagens de alta qualidade a partir de prompts em texto (suporta prompts em chinês e inglês)
- **Edição de imagem** — modifica o estilo, fundo, atributos e outros aspectos de imagens existentes
- **Prova virtual de roupas** — aplica roupas em fotos de pessoas
- **Suporte a múltiplos modelos** — suporta Seedream v4.5, v4.0, v3.0 T2I, SeedEdit v3.0 I2I e outros modelos
- **Diversas resoluções** — suporta 1K, 2K, 4K e resoluções adaptativas
- **Controle de seed** — permite resultados reproduzíveis por meio do parâmetro seed
- **Consulta de tarefas** — monitora o progresso da geração e obtém resultados

## Preparação

Antes de usar, você precisa obter o Token da API da AceData Cloud:

1. Registre-se ou faça login na [plataforma AceData Cloud](https://platform.acedata.cloud)
2. Acesse a página da [Seedream Images API](https://platform.acedata.cloud/documents/seedream-images)
3. Clique em "Acquire" para obter o Token da API (a primeira solicitação oferece crédito gratuito)

## Instalação e Configuração

### Método 1: Instalação via pip (recomendado)

```bash
pip install mcp-seedream-pro
```

### Método 2: Instalação via código-fonte

```bash
git clone https://github.com/AceDataCloud/SeedreamMCP.git
cd SeedreamMCP
pip install -e .
```

Após a instalação, você pode iniciar o serviço com o comando `mcp-seedream-pro`.

## Uso no Claude Desktop

Edite o arquivo de configuração do Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Adicione a seguinte configuração:

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Seu API Token"
      }
    }
  }
}
```

Se usar `uvx` (não requer instalação prévia de pacotes):

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Seu API Token"
      }
    }
  }
}
```

Salve a configuração e reinicie o Claude Desktop para usar as ferramentas Seedream nas conversas.

## Lista de Ferramentas Disponíveis

| Nome da Ferramenta           | Descrição                         |
|-----------------------------|----------------------------------|
| `seedream_generate_image`   | Gera imagens a partir de texto   |
| `seedream_edit_image`       | Edita ou modifica imagens existentes |
| `seedream_get_task`         | Consulta o status de uma tarefa  |
| `seedream_get_tasks_batch`  | Consulta em lote o status de tarefas |
| `seedream_list_models`      | Lista todos os modelos disponíveis e suas capacidades |
| `seedream_list_sizes`       | Lista tamanhos e resoluções de imagem disponíveis |

## Exemplos de Uso

Após a configuração, você pode chamar essas funcionalidades diretamente em clientes de IA usando linguagem natural, por exemplo:

- "Me ajude a gerar uma pintura de paisagem em estilo tinta chinesa com Seedream"
- "Mude o fundo desta foto para um céu estrelado"
- "Gere um retrato em 4K com Seedream v4.5"
- "Faça uma prova virtual desta roupa nesta foto"
