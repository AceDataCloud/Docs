[MCP (Model Context Protocol)](https://modelcontextprotocol.io) é um protocolo de contexto de modelo lançado pela Anthropic, que permite que modelos de IA (como Claude, GPT etc.) chamem ferramentas externas por meio de interfaces padronizadas. Por meio do Seedance MCP Server fornecido pela AceData Cloud, você pode usar diretamente o Seedance da ByteDance para gerar vídeos de IA em clientes de IA como Claude Desktop, VS Code, Cursor etc.

## Visão geral das funcionalidades

O Seedance MCP Server fornece as seguintes funcionalidades principais:

- **Geração de vídeo por texto** — Gere vídeos de alta qualidade por meio de prompts de texto
- **Geração de vídeo por imagem** — Gere vídeos usando imagens como referência (modos como primeiro quadro, último quadro, imagem de referência etc.)
- **Suporte a múltiplos modelos** — Suporta Seedance 1.x, 1.5, 2.0 e 2.5
- **Múltiplas resoluções** — Suporta 480p, 720p, 1080p, e alguns modelos suportam 4k
- **Múltiplas proporções de tela** — Suporta 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 e adaptive
- **Duração flexível** — Conforme o modelo, suporta 2–30 segundos ou duração automática
- **Vídeo multimodal** — Suporta geração de áudio, áudio/vídeo de referência, além de edição e extensão de vídeo no 2.5
- **Consulta de tarefas** — Monitore o progresso da geração e obtenha os resultados

## Recomendado: usar a autorização OAuth do MCP hospedado

Adicione o endereço do servidor em clientes que suportem OAuth de MCP remoto:

```text
https://seedance.mcp.acedata.cloud/mcp
```

Selecione conectar ou fazer login, faça login no Ace Data Cloud, visualize as permissões e autorize, depois habilite as ferramentas. Este caminho não exige criar ou copiar previamente um API Token. O serviço já suporta OAuth discovery, registro dinâmico de cliente (DCR) e S256 PKCE; o DCR registra o cliente, e o usuário ainda precisa fazer login e autorizar; o uso da API é cobrado normalmente.

| Cliente                            | Método e condições de integração                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Versão web do Claude ou versão Desktop que oferece conectores remotos | Adicione o endereço acima e autorize na interface de conectores; o acesso depende da versão e do plano. Não escreva a configuração HTTP remota no arquivo de configuração local do stdio.                      |
| VS Code com suporte nativo a OAuth de MCP remoto     | Execute **MCP: Add Server**, selecione HTTP, preencha o endereço e faça login conforme solicitado; a extensão dedicada AceDataCloud usa uma configuração de API Key independente. |
| Outros clientes                          | Confirme se a versão atual suporta HTTP remoto, OAuth/DCR, e use as instruções de configuração desse cliente. O formato do arquivo de configuração não pode ser usado universalmente entre clientes diferentes.                     |

## Caminho alternativo com API Token

Clientes locais com stdio, auto-hospedados ou que não suportam OAuth remoto usam API Token. Faça login na [plataforma Ace Data Cloud](https://platform.acedata.cloud), selecione o serviço e crie credenciais de API com as permissões necessárias. Armazene o Token nas configurações de credenciais do cliente ou em variáveis de ambiente locais; não o coloque em URLs, conteúdo de chats ou repositórios. A configuração de HTTP Header de diferentes clientes deve ser preenchida conforme as instruções de suas versões.

Instalar o MCP de código aberto ou concluir a autorização não significa obter créditos gratuitos, nem garante tempo de geração ou direitos de uso comercial. Antes de gerar, verifique os preços atuais do serviço, o saldo e os termos aplicáveis.

## Método dois: executar localmente (instalação via pip / uvx)

Se você precisa de stdio local, código personalizado ou auto-hospedagem, pode iniciar o MCP Server localmente. A geração ainda exige conexão à internet para chamar a API, não é inferência offline.

### Instalação

Instalação via pip (recomendado):

```bash
pip install mcp-seedance
```

Ou instalação a partir do código-fonte:

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Após a instalação, você pode usar o comando `mcp-seedance` para iniciar o serviço.

### Uso no Claude Desktop (local)

Edite o arquivo de configuração do Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Adicione a seguinte configuração:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "seu API Token"
      }
    }
  }
}
```

Se usar `uvx` (não é necessário instalar o pacote antecipadamente):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "seu API Token"
      }
    }
  }
}
```

Após salvar a configuração, reinicie o Claude Desktop para que entre em vigor.

### Uso no VS Code (local)

Crie `.vscode/mcp.json` no diretório raiz do projeto:

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "seu API Token"
      }
    }
  }
}
```

Ou use `uvx`:

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "seu API Token"
      }
    }
  }
}
```

Para outros clientes locais, preencha command, args e env conforme as instruções de configuração do stdio da versão atual; não use diretamente a configuração do VS Code como formato universal.

## Verificação de resultados e falhas comuns

Peça ao cliente para gerar uma obra de vídeo simples, mantenha o número da tarefa e consulte a mesma tarefa até que o estado final seja bem-sucedido, depois abra ou reproduza o link final. Conexão bem-sucedida, carregamento da lista de ferramentas, HTTP 200, número da tarefa e pré-visualização em processamento não representam o produto final.

Ao encontrar 401, faça login novamente ou verifique o Token e as permissões; quando o saldo for insuficiente, verifique o faturamento; enquanto a tarefa estiver sendo processada, continue consultando; em caso de falha final, leia o erro e decida se deve tentar novamente, pois uma nova geração poderá ser cobrada novamente.

## Lista de ferramentas disponíveis

| Nome da ferramenta                                  | Descrição             |
| ------------------------------------ | -------------- |
| `seedance_generate_video`            | Gera vídeo por meio de prompts de texto    |
| `seedance_generate_video_from_image` | Gera vídeo usando uma imagem como referência     |
| `seedance_get_task`                  | Consulta o status de uma única tarefa       |
| `seedance_get_tasks_batch`           | Consulta em lote o status das tarefas       |
| `seedance_list_models`               | Lista todos os modelos disponíveis e suas capacidades   |
| `seedance_list_resolutions`          | Lista as resoluções e proporções de tela disponíveis   |
| `seedance_list_actions`              | Lista todas as ferramentas disponíveis e exemplos de fluxos de trabalho |

## Exemplos de uso

Após concluir a configuração, você pode chamar diretamente essas funcionalidades em linguagem natural no cliente de IA, por exemplo:

- 「Ajude-me a usar o Seedance para gerar um vídeo de time-lapse de uma rua da cidade」
- 「Use esta foto como o primeiro quadro e gere um vídeo de 8 segundos」
- 「Gere um vídeo curto vertical em 1080p e 9:16」
- 「Use o modelo Seedance 1.5 Pro para gerar um vídeo com áudio」
