[MCP (Model Context Protocol)](https://modelcontextprotocol.io) é um protocolo de contexto de modelo lançado pela Anthropic, que permite que modelos de IA (como Claude, GPT, etc.) chamem ferramentas externas através de interfaces padronizadas. Através do SERP MCP Server fornecido pela AceData Cloud, você pode realizar buscas no Google diretamente em clientes de IA como Claude Desktop, VS Code, Cursor, etc., obtendo resultados de busca de páginas da web, imagens, notícias, vídeos, locais, entre outros.

## Visão Geral das Funcionalidades

O SERP MCP Server oferece as seguintes funcionalidades principais:

- **Busca na Web** — Pesquisar resultados de páginas do Google
- **Busca de Imagens** — Pesquisar imagens do Google
- **Busca de Notícias** — Pesquisar notícias do Google
- **Busca de Vídeos** — Pesquisar vídeos do Google
- **Busca de Locais** — Pesquisar informações de locais do Google
- **Busca de Mapas** — Pesquisar mapas do Google
- **Multilíngue e Multirregional** — Suporte a parâmetros de país e idioma personalizados
- **Filtragem por Intervalo de Tempo** — Filtrar resultados por dia, semana, mês, ano

## Preparativos

Antes de usar, você precisa obter o Token da API da AceData Cloud:

1. Registre-se ou faça login na [plataforma AceData Cloud](https://platform.acedata.cloud)
2. Vá para a página [Google SERP API](https://platform.acedata.cloud/documents/serp-google)
3. Clique em "Acquire" para obter o Token da API (primeira solicitação oferece crédito gratuito)

## Instalação e Configuração

### Método 1: Instalação via pip (recomendado)

```bash
pip install mcp-serp
```

### Método 2: Instalação a partir do código-fonte

```bash
git clone https://github.com/AceDataCloud/MCPSerp.git
cd MCPSerp
pip install -e .
```

Após a instalação, você pode usar o comando `mcp-serp` para iniciar o serviço.

## Usando no Claude Desktop

Edite o arquivo de configuração do Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Adicione a seguinte configuração:

```json
{
  "mcpServers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "seu Token da API"
      }
    }
  }
}
```

Se usar `uvx` (sem necessidade de instalar pacotes previamente):

```json
{
  "mcpServers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "seu Token da API"
      }
    }
  }
}
```

Após salvar a configuração, reinicie o Claude Desktop para usar as ferramentas de busca do Google nas conversas.

## Usando no VS Code / Cursor

Crie um arquivo `.vscode/mcp.json` no diretório raiz do projeto:

```json
{
  "servers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "seu Token da API"
      }
    }
  }
}
```

Ou use `uvx`:

```json
{
  "servers": {
```

| Nome da Ferramenta      | Descrição          |
| ----------------------- | ------------------ |
| `serp_google_search`    | Busca na web do Google |
| `serp_google_images`    | Busca de imagens do Google |
| `serp_google_news`      | Busca de notícias do Google |
| `serp_google_videos`    | Busca de vídeos do Google |
| `serp_google_places`    | Busca de locais do Google |
| `serp_google_maps`      | Busca de mapas do Google |

## Exemplos de Uso

Após a configuração, você pode chamar essas funcionalidades diretamente em linguagem natural nos clientes de IA, por exemplo:

- "Ajude-me a pesquisar os artigos mais recentes sobre IA"
- "Pesquise restaurantes de hot pot deliciosos em Pequim"
- "Encontre imagens sobre programação assíncrona em Python"
- "Pesquise as notícias de tecnologia de hoje"
