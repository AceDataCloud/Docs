## Introdução ao Suno

Suno é uma das plataformas de geração de música por IA mais poderosas atualmente. Através da API Suno da Ace Data Cloud, você pode gerar músicas de alta qualidade com chamadas simples de API.

## Endpoints da API

| Endpoint | Função |
|----------|--------|
| `POST /suno/audios` | Gerar música (endpoint principal) |
| `POST /suno/lyrics` | Gerar letras |
| `POST /suno/persona` | Gerenciar estilos de cantor |
| `POST /suno/wav` | Obter formato WAV |
| `POST /suno/mp4` | Obter formato MP4 |
| `POST /suno/tasks` | Consultar status de tarefas |

## Geração Básica

### Geração por descrição de texto

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### Geração personalizada de letras

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\n夏日的阳光洒满了海岸\n微风中传来浪花的声音\n\n[Chorus]\n让我们一起去远方\n追逐那自由的梦想",
        "style": "pop upbeat",
        "title": "夏日冒险",
    },
)
```

## Funcionalidades Avançadas

### Continuação de música

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### Geração de letras

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "写一首关于冬天的歌",
    },
)
```
