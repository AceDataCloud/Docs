## Visão Geral

A geração de vídeo por IA está se desenvolvendo rapidamente. A Ace Data Cloud oferece 7 tipos de APIs de geração de vídeo, cobrindo diversos cenários desde texto para vídeo até imagem para vídeo.

## Serviços de Geração de Vídeo Disponíveis

| Serviço | Endpoint | Modelo | Características |
|---------|----------|--------|-----------------|
| Sora    | `POST /sora/videos` | sora-2, sora-2-pro | Desenvolvido pela OpenAI, qualidade cinematográfica |
| Veo     | `POST /veo/videos` | veo3, veo3-fast | Desenvolvido pelo Google, suporta 4K |
| Kling   | `POST /kling/videos` | kling-v2-5-turbo | Desenvolvido pela Kuaishou, alta velocidade |
| Luma    | `POST /luma/videos` | — | Controle de quadro inicial e final |
| Hailuo  | `POST /hailuo/videos` | minimax-t2v | Desenvolvido pela MiniMax |
| Seedance| `POST /seedance/videos` | doubao-seedance-1-0-pro-250528 | Desenvolvido pela ByteDance |
| Wan     | `POST /wan/videos` | wan2.6-t2v | Desenvolvido pela Alibaba |

## Início Rápido

### Geração de Vídeo com Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A cat playing in a sunny garden",
        "model": "sora-2",
        "duration": 10,
        "orientation": "landscape",
    },
)
print(response.json())
```

### Geração de Vídeo com Kling

```python
response = requests.post(
    "https://api.acedata.cloud/kling/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A white cat walking in the snow",
        "model": "kling-v2-5-turbo",
        "duration": 5,
        "aspect_ratio": "16:9",
    },
)
print(response.json())
```

### Geração de Vídeo com Veo

```python
response = requests.post(
    "https://api.acedata.cloud/veo/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A coffee mug rotating on a marble counter",
        "model": "veo3",
    },
)
print(response.json())
```

## Processamento de Tarefas Assíncronas

A geração de vídeo geralmente leva um tempo considerável. Todas as APIs de vídeo suportam:

1. **Notificação por callback**: Defina `callback_url` na requisição para receber automaticamente o resultado após a conclusão
2. **Consulta por polling**: Verifique o progresso da tarefa pelo endpoint `/tasks`

```python
# Usando callback URL
data = {
    "prompt": "A sunrise over mountains",
    "model": "sora-2",
    "callback_url": "https://your-server.com/webhook",
}

# Ou consultando o status da tarefa
task_response = requests.post("https://api.acedata.cloud/sora/tasks",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json={"task_id": "your-task-id"})
```

## Recomendações de Escolha

- **Melhor qualidade de imagem**: Sora (sora-2-pro)
- **Maior velocidade**: Kling (kling-v2-5-turbo)
- **Maior resolução**: Veo (suporta 4K)
- **Controle de quadro inicial e final**: Luma
- **Custo-benefício**: Wan
