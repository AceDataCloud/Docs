## O que é MCP

Model Context Protocol (MCP) é um protocolo aberto que permite que assistentes de IA (como Claude, Cursor) chamem diretamente ferramentas externas e APIs. Com o MCP, a IA não só responde perguntas, mas também executa operações reais.

## MCP Server fornecido pela Ace Data Cloud

| MCP Server       | Nome do pacote PyPI | Função            |
|------------------|---------------------|-------------------|
| MCPSuno          | mcp-suno            | Geração de música por IA |
| MCPSerp          | mcp-serp            | Pesquisa no Google |
| MCPMidjourney    | mcp-midjourney      | Geração de imagens por IA |
| MCPLuma          | mcp-luma            | Geração de vídeo por IA |
| MCPSora          | mcp-sora            | Geração de vídeo por IA |
| MCPVeo           | mcp-veo             | Geração de vídeo por IA |
| MCPNanoBanana    | mcp-nano-banana     | Geração de imagens por IA |

## Instalação e uso

### Instalação

```bash
pip install mcp-suno  # ou outro MCP Server
```

### Configurar variável de ambiente

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### Configuração no Cursor

Adicione nas configurações MCP do Cursor:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### Configuração no Claude Desktop

Edite o arquivo de configuração do Claude Desktop para adicionar a configuração do MCP Server.

## Cenários de uso

1. **Gerar música no Cursor**: diga para a IA "gere uma música alegre com Suno", a IA chamará diretamente a API  
2. **Pesquisar informações em tempo real**: a IA pode usar o MCP Server SERP para buscar informações atualizadas  
3. **Gerar materiais para projetos**: a IA pode chamar Midjourney para gerar imagens necessárias para o projeto

## MCP vs chamada direta de API

- **MCP**: adequado para uso em ferramentas de programação de IA, chamado automático pela IA  
- **API**: adequado para integração em suas próprias aplicações, controle programático

Ambos usam o mesmo Ace Data Cloud API Token e acessam os mesmos endpoints de API subjacentes.

## Resumo

O MCP permite que assistentes de IA chamem diretamente várias APIs da Ace Data Cloud. Todos os MCP Servers já estão publicados no PyPI, com instalação e configuração simples, tornando suas ferramentas de IA mais poderosas.

Acesse [platform.acedata.cloud](https://platform.acedata.cloud) para obter seu API Token.
