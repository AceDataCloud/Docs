## URL Base

Endereço base para todos os endpoints da API:

```
https://api.acedata.cloud
```

## Autenticação

Todos os endpoints requerem autenticação Bearer Token:

```
Authorization: Bearer YOUR_API_TOKEN
```

## Teste Online

Cada endpoint nesta referência inclui um sandbox interativo. Insira o API Token para testar as requisições diretamente no navegador.

<Note title="Dica">
  Obtenha seu API Token em [platform.acedata.cloud](https://platform.acedata.cloud).
</Note>
