## 什么是 MCP

Model Context Protocol（MCP）是一种开放协议，允许 AI 助手（如 Claude、Cursor）直接调用外部工具和 API。通过 MCP，AI 不仅能回答问题，还能执行实际操作。

## Ace Data Cloud 提供的 MCP Server

| MCP Server | PyPI 包名 | 功能 |
|------------|-----------|------|
| MCPSuno | mcp-suno | AI 音乐生成 |
| MCPSerp | mcp-serp | Google 搜索 |
| MCPMidjourney | mcp-midjourney | AI 图像生成 |
| MCPLuma | mcp-luma | AI 视频生成 |
| MCPSora | mcp-sora | AI 视频生成 |
| MCPVeo | mcp-veo | AI 视频生成 |
| MCPNanoBanana | mcp-nano-banana | AI 图像生成 |

## 安装与使用

### 安装

```bash
pip install mcp-suno  # 或其他 MCP Server
```

### 配置环境变量

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### 在 Cursor 中配置

在 Cursor 的 MCP 设置中添加：

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### 在 Claude Desktop 中配置

编辑 Claude Desktop 配置文件，添加 MCP Server 配置。

## 使用场景

1. **在 Cursor 中生成音乐**：告诉 AI "用 Suno 生成一首欢快的歌曲"，AI 将直接调用 API
2. **搜索实时信息**：AI 可以通过 SERP MCP Server 搜索最新信息
3. **生成项目素材**：AI 可以调用 Midjourney 生成项目需要的图片素材

## MCP vs 直接 API 调用

- **MCP**：适合在 AI 编程工具中使用，由 AI 自动调用
- **API**：适合在自己的应用中集成，编程控制

两者使用相同的 Ace Data Cloud API Token，底层调用的也是相同的 API 端点。

## 总结

MCP 让 AI 助手能够直接调用 Ace Data Cloud 的各种 API。所有 MCP Server 都已发布到 PyPI，安装配置简单，让你的 AI 工具更加强大。

前往 [platform.acedata.cloud](https://platform.acedata.cloud) 获取 API Token。
