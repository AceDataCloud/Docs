Suno 是领先的 AI 音乐生成平台，通过 Ace Data Cloud 提供 API。以下是完整指南。

## Suno 的功能

- **根据文本提示生成歌曲**（最长可达 9 分钟）
- **自定义歌词**，完全控制标题、风格和结构
- **从任意点扩展**现有歌曲
- **不同风格翻唱**歌曲
- **分离音轨**（人声、鼓声、贝斯等）
- **混搭**多首歌曲
- **重新母带处理**，提升音质

## 快速开始

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={
        "prompt": "A chill lo-fi hip hop beat for studying",
        "model": "chirp-v4",
        "action": "generate",
    },
)

for song in response.json()["data"]:
    print(f"{song['title']}: {song['audio_url']}")
```

## 模型

| 模型 | 最长时长 | 质量 |
|-------|---------|-------|
| chirp-v3 | 4 分钟 | 良好 |
| chirp-v3.5 | 4 分钟 | 更好 |
| chirp-v4 | 6 分钟 | 优秀 |
| chirp-v5 | 9 分钟 | 最佳 |
