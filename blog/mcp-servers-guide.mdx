---

MCP（Model Context Protocol，模型上下文协议）是 Anthropic 推出的一个开放协议，允许 AI 助手调用外部工具。可以把它看作是“AI 插件”——但它是标准化且开源的。

## MCP 的工作原理

```
AI 助手（Claude、GPT 等）
    │
    ├── MCP 客户端（内置于 Claude Desktop、VS Code、Cursor）
    │
    └── MCP 服务器（你的工具）
        ├── list_tools()     → 告诉 AI 你能做什么
        ├── call_tool()      → AI 请求时执行操作
        └── get_prompt()     → 提供上下文/指令
```

## 可用的 MCP 服务器

Ace Data Cloud 发布了以下开源 MCP 服务器：

| 服务器 | 安装 | 使用场景 |
|--------|---------|----------|
| [mcp-suno](https://pypi.org/project/mcp-suno/) | `pip install mcp-suno` | AI 音乐生成 |
| [mcp-serp](https://pypi.org/project/mcp-serp/) | `pip install mcp-serp` | 谷歌搜索 |
| mcp-midjourney | GitHub | AI 图像生成 |
| mcp-luma | GitHub | AI 视频（Dream Machine） |
| mcp-sora | GitHub | AI 视频（OpenAI Sora） |
| mcp-veo | GitHub | AI 视频（Google Veo） |
| mcp-nanobanana | GitHub | AI 图像编辑（Gemini） |

## 快速设置

```bash
# 安装
pip install mcp-suno mcp-serp

# 设置你的 API 密钥
export ACEDATACLOUD_API_TOKEN="your_key_here"

# 运行（Claude Desktop 的 stdio 模式）
mcp-suno
```
