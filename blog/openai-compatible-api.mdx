OpenAI SDK（Python 版的 `openai`，Node.js 版的 `openai`）是全球使用最广泛的 AI SDK。通过 Ace Data Cloud，您可以使用同一套 SDK 访问 **Claude、Gemini、DeepSeek、Grok** 及其他 50 多个模型。

## 工作原理

只需更改 `base_url`：

```python
from openai import OpenAI

# 不再指向 api.openai.com...
client = OpenAI(
    api_key="YOUR_ACEDATA_KEY",
    base_url="https://api.acedata.cloud/v1",  # ← 唯一的改动
)

# 现在可以使用任意模型
response = client.chat.completions.create(
    model="claude-sonnet-4-20250514",  # Anthropic Claude
    messages=[{"role": "user", "content": "你好！"}],
)
```

## JavaScript 示例

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "YOUR_ACEDATA_KEY",
  baseURL: "https://api.acedata.cloud/v1",
});

const response = await client.chat.completions.create({
  model: "gemini-2.5-flash",
  messages: [{ role: "user", content: "你好！" }],
});
```

## cURL 示例

```bash
curl https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer YOUR_ACEDATA_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-chat", "messages": [{"role": "user", "content": "你好！"}]}'
```
