## Suno 简介

Suno 是目前最强大的 AI 音乐生成平台之一。通过 Ace Data Cloud 的 Suno API，你可以通过简单的 API 调用生成高质量音乐。

## API 端点

| 端点 | 功能 |
|------|------|
| `POST /suno/audios` | 生成音乐（主端点） |
| `POST /suno/lyrics` | 生成歌词 |
| `POST /suno/persona` | 管理歌手风格 |
| `POST /suno/wav` | 获取 WAV 格式 |
| `POST /suno/mp4` | 获取 MP4 格式 |
| `POST /suno/tasks` | 查询任务状态 |

## 基础生成

### 文本描述生成

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### 自定义歌词生成

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\n夏日的阳光洒满了海岸\n微风中传来浪花的声音\n\n[Chorus]\n让我们一起去远方\n追逐那自由的梦想",
        "style": "pop upbeat",
        "title": "夏日冒险",
    },
)
```

## 进阶功能

### 歌曲续写

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### 生成歌词

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "写一首关于冬天的歌",
    },
)
```
