---
title: "如何使用 AI 构建文本转语音应用"
---

使用 Fish Audio API 构建支持语音克隆的文本转语音应用。

## 快速开始

```python
import requests

API_KEY = "YOUR_API_KEY"

response = requests.post(
    "https://api.acedata.cloud/fish/audios",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "text": "Welcome to Ace Data Cloud, your unified AI API platform.",
        "reference_id": "default",
    },
)

result = response.json()
print("音频链接:", result.get("audio_url"))
```

## 自定义语音

克隆语音或使用预设语音：

```python
# 列出可用语音
voices = requests.get(
    "https://api.acedata.cloud/fish/voices",
    headers={"Authorization": f"Bearer {API_KEY}"},
).json()

# 使用指定语音
response = requests.post(
    "https://api.acedata.cloud/fish/audios",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "text": "这里填写您的自定义文本。",
        "reference_id": voices["data"][0]["id"],
    },
)
```
