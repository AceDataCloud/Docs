---
title: "如何使用 Suno API 生成 AI 音乐"
---

通过 Ace Data Cloud 使用 Suno API 生成 AI 音乐曲目。

## 快速开始

```python
import requests

API_KEY = "YOUR_API_KEY"

# 根据文本提示生成歌曲
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "prompt": "一首关于夏日冒险的欢快流行歌曲",
        "model": "chirp-v4",
        "action": "generate",
    },
)

songs = response.json()["data"]
for song in songs:
    print(f"标题: {song['title']}")
    print(f"音频链接: {song['audio_url']}")
    print(f"时长: {song['duration']}秒")
```

## 自定义歌词和风格

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "model": "chirp-v4",
        "custom": True,
        "action": "generate",
        "title": "夏日梦想",
        "style": "流行，欢快，充满活力",
        "lyric": "[Verse]\n阳光洒在脸上\n奔跑在海浪中\n\n[Chorus]\n夏日梦想在召唤我",
    },
)
```

## 续写歌曲

从指定时间点继续现有歌曲：

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "model": "chirp-v4",
        "action": "extend",
        "audio_id": "SONG_ID_HERE",
        "continue_at": 120,  # 从2分钟处继续
    },
)
```

## 可用操作

| 操作       | 描述               |
|------------|--------------------|
| `generate` | 根据提示创建新歌曲 |
| `extend`   | 续写现有歌曲       |
| `cover`    | 以不同风格制作翻唱 |
| `stems`    | 分离人声和乐器     |
| `mashup`   | 混合多首歌曲       |
| `remaster` | 提升音频质量       |
