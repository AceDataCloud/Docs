使用 Ace Data Cloud 作为 AI 后端构建 AI SaaS 应用的架构指南。

## 为什么使用统一 API

无需为每个 AI 提供商管理单独的 API 密钥和 SDK，Ace Data Cloud 为您提供：

- **一个 API 密钥**，支持 50+ AI 模型和服务
- **兼容 OpenAI 格式** — 可使用现有 SDK
- **按需付费** — 无最低消费限制
- **内置限流和错误处理**

## 推荐架构

```
您的 SaaS 应用
    │
    ├── 前端 (React/Vue/Next.js)
    │
    ├── 后端 (Node.js/Python/Go)
    │   ├── 用户认证与计费
    │   ├── AI 请求路由
    │   └── 响应缓存
    │
    └── Ace Data Cloud API
        ├── 聊天 (Claude/GPT/Gemini)
        ├── 图像 (Midjourney/Flux)
        ├── 视频 (Sora/Veo/Luma)
        ├── 音频 (Suno/Fish)
        └── 搜索 (Google SERP)
```

## 关键集成模式

### 1. 模型路由

让用户选择他们偏好的模型：

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_KEY",
    base_url="https://api.acedata.cloud/v1",
)

def generate_response(user_model_preference, messages):
    return client.chat.completions.create(
        model=user_model_preference,  # 用户选择的模型
        messages=messages,
        stream=True,
    )
```

### 2. 备用链路

如果一个模型失败，尝试另一个：

```python
FALLBACK_MODELS = ["claude-sonnet-4-20250514", "gpt-4o", "gemini-2.5-flash"]

def generate_with_fallback(messages):
    for model in FALLBACK_MODELS:
        try:
            return client.chat.completions.create(
                model=model,
                messages=messages,
            )
        except Exception:
            continue
    raise Exception("所有模型均失败")
```

### 3. 成本优化

针对简单任务路由到更便宜的模型：

```python
def smart_route(messages, task_complexity="simple"):
    if task_complexity == "simple":
        model = "deepseek-chat"       # 最具性价比
    elif task_complexity == "medium":
        model = "gpt-4o-mini"         # 良好平衡
    else:
        model = "claude-sonnet-4-20250514"  # 最高质量

    return client.chat.completions.create(model=model, messages=messages)
```
