为营销、品牌推广和创意项目打造惊艳的 AI 增强二维码。

## 快速开始

```python
import requests

API_KEY = "YOUR_API_KEY"

response = requests.post(
    "https://api.acedata.cloud/qrart/generate",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "content": "https://acedata.cloud",
        "prompt": "一座美丽的花园，带有水彩画风格的花朵",
    },
)

result = response.json()
print("二维码艺术图 URL:", result.get("image_url"))
```

## 使用场景

- **营销活动** — 传单和广告上的品牌二维码
- **名片** — 突出个性的艺术二维码
- **产品包装** — 美观且可扫描的二维码
- **活动邀请** — 定制主题二维码
