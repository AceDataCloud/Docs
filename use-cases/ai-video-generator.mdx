---
title: "如何使用 Sora API 生成 AI 视频"
---

通过 Ace Data Cloud 使用 OpenAI 的 Sora API 生成 AI 视频。

## 快速开始

```python
import requests

API_KEY = "YOUR_API_KEY"

# 生成视频
response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "model": "sora-2",
        "prompt": "一只猫在爵士俱乐部弹钢琴，电影感灯光",
        "duration": 10,
    },
)

result = response.json()
if result.get("task_id"):
    print("任务已提交:", result["task_id"])
    # 视频生成需要1-5分钟
```

## 查询任务状态

```python
task_id = result["task_id"]

status = requests.get(
    f"https://api.acedata.cloud/sora/tasks/{task_id}",
    headers={"Authorization": f"Bearer {API_KEY}"},
)

task = status.json()
if task["state"] == "succeeded":
    print("视频链接:", task["video_url"])
else:
    print("状态:", task["state"])
```

## 使用 Webhook 进行异步处理

```python
response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "model": "sora-2",
        "prompt": "日落时的海浪",
        "callback_url": "https://your-server.com/webhook",
    },
)
# 结果将通过 POST 方式发送到你的 callback_url
```

## 其他视频 API 选项

| API   | 适用场景       | 速度       |
|-------|----------------|------------|
| Sora  | 电影级画质     | 2-5 分钟   |
| Veo   | 音频 + 视频    | 1-3 分钟   |
| Luma  | 快速创意视频   | 30秒-2分钟 |
| Kling | 动作控制       | 1-3 分钟   |
