---
title: "如何使用 Python 构建 AI 聊天机器人"
---

使用 Ace Data Cloud 的统一 API，在 Python 中构建一个功能齐全的 AI 聊天机器人。本教程适用于 **Claude、GPT-4o、Gemini、DeepSeek** 以及任何其他支持的模型。

## 你将构建的内容

一个命令行聊天机器人，具备以下功能：
- 维护对话历史（多轮对话）
- 支持流式响应
- 通过一个 API 支持任何 AI 模型

## 前提条件

```bash
pip install openai
```

## 完整代码

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.acedata.cloud/v1",
)

def chat(model="claude-sonnet-4-20250514"):
    messages = []
    print(f"聊天机器人已准备好（{model}）。输入 'quit' 退出。\n")

    while True:
        user_input = input("你: ")
        if user_input.lower() in ("quit", "exit"):
            break

        messages.append({"role": "user", "content": user_input})

        stream = client.chat.completions.create(
            model=model,
            messages=messages,
            stream=True,
        )

        print("AI: ", end="", flush=True)
        full_response = ""
        for chunk in stream:
            if chunk.choices[0].delta.content:
                content = chunk.choices[0].delta.content
                print(content, end="", flush=True)
                full_response += content
        print()

        messages.append({"role": "assistant", "content": full_response})

if __name__ == "__main__":
    chat()
```

## 即刻切换模型

更改 `model` 参数即可使用任何提供商：

```python
chat("claude-sonnet-4-20250514")  # Anthropic Claude
chat("gpt-4o")                    # OpenAI GPT-4o
chat("gemini-2.5-flash")          # Google Gemini
chat("deepseek-chat")             # DeepSeek
chat("grok-3")                    # xAI Grok
```

所有模型均使用相同的 OpenAI 兼容 API 格式 —— 无需更改代码。

## 添加系统提示

自定义你的聊天机器人个性：

```python
messages = [
    {
        "role": "system",
        "content": "你是一个乐于助人的编码助手。请简洁回答并附带代码示例。",
    }
]
```
