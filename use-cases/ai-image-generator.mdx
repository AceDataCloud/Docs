---
title: "如何构建 AI 图像生成器应用"
---

通过 Ace Data Cloud 使用 Midjourney API 构建 AI 图像生成器。

## 你将构建的内容

一个 Python 应用，能够：
- 根据文本提示生成图像
- 将图像放大至高分辨率
- 创建生成图像的变体
- 使用 webhook 处理异步生成

## 快速开始

```python
import requests
import time

API_KEY = "YOUR_API_KEY"
BASE_URL = "https://api.acedata.cloud"

# 生成图像
response = requests.post(
    f"{BASE_URL}/midjourney/imagine",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "prompt": "夕阳下的未来城市，赛博朋克风格 --ar 16:9",
        "mode": "fast",
    },
)

result = response.json()
print("图像 URL:", result["image_url"])
print("可用操作:", result["actions"])
```

## 放大图像

生成后，可以放大以获得更高分辨率：

```python
# 从生成响应中获取 image_id
image_id = result["image_id"]

upscale = requests.post(
    f"{BASE_URL}/midjourney/imagine",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "image_id": image_id,
        "action": "upscale",
        "index": 1,  # 放大第一张图（1-4）
    },
)

upscaled = upscale.json()
print("放大后 URL:", upscaled["image_url"])
```

## 另一选择：使用 Flux 实现更快生成

对于快速原型开发，Flux 可在几秒内生成图像：

```python
response = requests.post(
    f"{BASE_URL}/flux/images",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "model": "flux-schnell",
        "prompt": "宁静的山间风景",
    },
)
```
