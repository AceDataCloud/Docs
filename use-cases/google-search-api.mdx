---
title: "如何在 Python 中使用 Google 搜索 API"
---

使用 SERP API 以编程方式访问 Google 搜索结果。

## 快速开始

```python
import requests

API_KEY = "YOUR_API_KEY"

response = requests.post(
    "https://api.acedata.cloud/serp/google",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "type": "search",
        "query": "best AI APIs 2026",
        "number": 10,
    },
)

results = response.json()
for item in results.get("organic_results", []):
    print(f"{item['title']} - {item['link']}")
```

## 搜索类型

| 类型 | 描述 |
|------|-------------|
| `search` | 标准网页搜索结果 |
| `images` | 图片搜索结果 |
| `news` | 新闻文章 |
| `shopping` | 商品列表 |
| `videos` | 视频结果 |
| `maps` | 位置结果 |

## 按位置和语言过滤

```python
response = requests.post(
    "https://api.acedata.cloud/serp/google",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "type": "search",
        "query": "AI startups",
        "country": "US",
        "language": "en",
        "range": "month",  # 过去一个月的结果
    },
)
```
