---
title: "如何在 Claude Desktop 中使用 MCP 服务器"
---

设置 MCP（模型上下文协议）服务器，使 Claude Desktop 能访问 AI 音乐、视频、图像和搜索工具。

## 什么是 MCP 服务器？

MCP 服务器允许像 Claude 这样的 AI 助手调用外部工具。借助 Ace Data Cloud 的 MCP 服务器，Claude 可以：

- 使用 **Suno** 生成音乐
- 使用 **Sora**、**Veo**、**Luma** 创建视频
- 使用 **Midjourney**、**Nano Banana** 生成图像
- 使用 **Google SERP** 进行网页搜索

## 设置步骤

### 1. 安装 MCP 服务器

```bash
pip install mcp-suno mcp-serp mcp-midjourney mcp-luma mcp-sora mcp-veo
```

### 2. 获取 API 密钥

在 [platform.acedata.cloud](https://platform.acedata.cloud) 注册并获取您的 Bearer 令牌。

### 3. 配置 Claude Desktop

编辑 `~/Library/Application Support/Claude/claude_desktop_config.json` 文件：

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_KEY"
      }
    },
    "search": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_KEY"
      }
    },
    "midjourney": {
      "command": "mcp-midjourney",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_KEY"
      }
    },
    "sora": {
      "command": "mcp-sora",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_KEY"
      }
    }
  }
}
```

### 4. 重启 Claude Desktop

保存配置后，重启 Claude Desktop。您将在聊天输入框看到工具图标 (🔨)。

## 示例提示

- “生成一首关于雨天的爵士乐”
- “制作一段猫咪弹钢琴的视频”
- “搜索最新的 AI 新闻”
- “生成一幅未来城市的图像”

## 可用的 MCP 服务器

| 服务器 | PyPI | 功能 |
|--------|------|------|
| mcp-suno | [PyPI](https://pypi.org/project/mcp-suno/) | 音乐生成、歌词、封面、伴奏 |
| mcp-serp | [PyPI](https://pypi.org/project/mcp-serp/) | Google 搜索（网页、图片、新闻） |
| mcp-midjourney | GitHub | 图像生成、放大、变体 |
| mcp-luma | GitHub | 视频生成（Dream Machine） |
| mcp-sora | GitHub | 视频生成（OpenAI Sora） |
| mcp-veo | GitHub | 视频生成（Google Veo） |
