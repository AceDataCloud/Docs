Tutte le Ace Data Cloud API utilizzano l'autenticazione **Bearer Token**.

## Ottenere il Token

Accedi a [Applications](https://platform.acedata.cloud/console/applications?lang=it&utm_source=docs&utm_medium=referral&utm_campaign=evergreen) e apri **General Application**. Se al primo accesso l’applicazione non è presente, seleziona **Initialize General Application**. Accanto ad **API KEY**, premi il pulsante di copia contrassegnato con **1**.

![Pulsante di copia della chiave contrassegnato con il numero 1](https://raw.githubusercontent.com/AceDataCloud/NanoBananaDify/2522b2f57210597af2db866445319334a1677a23/_assets/tutorial/get-api-key-en.png)

Conserva la chiave sul server e usala al posto di `YOUR_API_TOKEN` nell’esempio.

## Utilizzo del Token

Includi il Token nell'intestazione `Authorization` di ogni richiesta:

```bash
Authorization: Bearer YOUR_API_TOKEN
```


## Limiti di velocità

I limiti di velocità variano in base al servizio e al livello di abbonamento. Se superati, l'API restituisce `429 Too Many Requests`.

## Best practice di sicurezza

- Non esporre il Token API nel codice client
- Usa variabili d'ambiente per memorizzare il Token
- Ruota regolarmente i Token
- Usa Token diversi per ambienti di sviluppo e produzione
