title: "Autenticazione"
description: "Come autenticarsi utilizzando l'Ace Data Cloud API"
---

Tutte le Ace Data Cloud API utilizzano l'autenticazione **Bearer Token**.

## Ottenere il Token

1. Registrarsi su [platform.acedata.cloud](https://platform.acedata.cloud)
2. Abbonarsi ai servizi necessari
3. Creare credenziali (API Token) per ogni servizio

## Utilizzare il Token

Includere il Token nell'intestazione `Authorization` di ogni richiesta:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Suggerimento">
  Ogni Token è associato a un abbonamento di servizio specifico. Servizi diversi utilizzano Token differenti, oppure è possibile creare credenziali **globali** per l'uso trasversale ai servizi.
</Note>

## Limiti di velocità

I limiti di velocità variano in base al servizio e al livello di abbonamento. Se si supera il limite, l'API restituisce `429 Too Many Requests`.

## Best practice di sicurezza

- Non esporre il Token API nel codice client
- Utilizzare variabili d'ambiente per memorizzare il Token
- Ruotare periodicamente i Token
- Usare Token differenti per ambienti di sviluppo e produzione
