title: "Autenticazione"
description: "Come autenticarsi utilizzando l'Ace Data Cloud API"
---

Tutte le Ace Data Cloud API utilizzano l'autenticazione **Bearer Token**.

## Ottenere il Token

1. Registrati su [platform.acedata.cloud](https://platform.acedata.cloud)
2. Abbonati ai servizi necessari
3. Crea credenziali (API Token) per ogni servizio

## Utilizzo del Token

Includi il Token nell'intestazione `Authorization` di ogni richiesta:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Tip">
  Ogni Token è associato a un abbonamento di servizio specifico. Servizi diversi utilizzano Token differenti, oppure crea credenziali **globali** per l'uso trasversale ai servizi.
</Note>

## Limiti di velocità

I limiti di velocità variano in base al servizio e al livello di abbonamento. Se superati, l'API restituisce `429 Too Many Requests`.

## Best practice di sicurezza

- Non esporre il Token API nel codice client
- Usa variabili d'ambiente per memorizzare il Token
- Ruota regolarmente i Token
- Usa Token diversi per ambienti di sviluppo e produzione
