## Cos'è MCP

Model Context Protocol (MCP) è un protocollo aperto che permette agli assistenti AI (come Claude, Cursor) di chiamare direttamente strumenti esterni e API. Grazie a MCP, l'AI non solo può rispondere alle domande, ma anche eseguire operazioni pratiche.

## MCP Server forniti da Ace Data Cloud

| MCP Server       | Nome pacchetto PyPI | Funzionalità        |
|------------------|---------------------|---------------------|
| MCPSuno          | mcp-suno            | Generazione musicale AI |
| MCPSerp          | mcp-serp            | Ricerca Google      |
| MCPMidjourney    | mcp-midjourney      | Generazione immagini AI |
| MCPLuma          | mcp-luma            | Generazione video AI |
| MCPSora          | mcp-sora            | Generazione video AI |
| MCPVeo           | mcp-veo             | Generazione video AI |
| MCPNanoBanana    | mcp-nano-banana     | Generazione immagini AI |

## Installazione e utilizzo

### Installazione

```bash
pip install mcp-suno  # o altri MCP Server
```

### Configurazione delle variabili d'ambiente

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### Configurazione in Cursor

Aggiungere nelle impostazioni MCP di Cursor:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### Configurazione in Claude Desktop

Modificare il file di configurazione di Claude Desktop aggiungendo la configurazione del MCP Server.

## Scenari d'uso

1. **Generare musica in Cursor**: dire all'AI "Genera una canzone allegra con Suno", l'AI chiamerà direttamente l'API  
2. **Ricerca di informazioni in tempo reale**: l'AI può usare MCP Server SERP per cercare informazioni aggiornate  
3. **Generare materiali per progetti**: l'AI può chiamare Midjourney per generare immagini necessarie al progetto

## MCP vs chiamata API diretta

- **MCP**: adatto all'uso in strumenti di programmazione AI, chiamato automaticamente dall'AI  
- **API**: adatto all'integrazione nelle proprie applicazioni, controllo programmato

Entrambi utilizzano lo stesso Ace Data Cloud API Token e chiamano gli stessi endpoint API sottostanti.

## Riepilogo

MCP permette agli assistenti AI di chiamare direttamente le varie API di Ace Data Cloud. Tutti i MCP Server sono pubblicati su PyPI, l'installazione e la configurazione sono semplici, rendendo i tuoi strumenti AI più potenti.

Visita [platform.acedata.cloud](https://platform.acedata.cloud) per ottenere il tuo API Token.
