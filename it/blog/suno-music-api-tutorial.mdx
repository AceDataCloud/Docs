## Introduzione a Suno

Suno è attualmente una delle piattaforme di generazione musicale AI più potenti. Attraverso l'API Suno di Ace Data Cloud, puoi generare musica di alta qualità con semplici chiamate API.

## Endpoint API

| Endpoint | Funzione |
|----------|----------|
| `POST /suno/audios` | Generazione musicale (endpoint principale) |
| `POST /suno/lyrics` | Generazione di testi |
| `POST /suno/persona` | Gestione dello stile del cantante |
| `POST /suno/wav` | Ottenere formato WAV |
| `POST /suno/mp4` | Ottenere formato MP4 |
| `POST /suno/tasks` | Verifica stato dei task |

## Generazione Base

### Generazione da descrizione testuale

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### Generazione personalizzata di testi

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\n夏日的阳光洒满了海岸\n微风中传来浪花的声音\n\n[Chorus]\n让我们一起去远方\n追逐那自由的梦想",
        "style": "pop upbeat",
        "title": "夏日冒险",
    },
)
```

## Funzionalità Avanzate

### Continuazione di una canzone

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### Generazione di testi

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "写一首关于冬天的歌",
    },
)
```
