## Panoramica

La generazione video AI sta evolvendo rapidamente. Ace Data Cloud offre 7 tipi di API per la generazione video, coprendo vari scenari dalla generazione video da testo a quella da immagini.

## Servizi di generazione video disponibili

| Servizio | Endpoint | Modello | Caratteristiche |
|----------|----------|---------|-----------------|
| Sora     | `POST /sora/videos` | sora-2, sora-2-pro | Prodotto da OpenAI, qualità cinematografica |
| Veo      | `POST /veo/videos` | veo3, veo3-fast | Prodotto da Google, supporta 4K |
| Kling    | `POST /kling/videos` | kling-v2-5-turbo | Prodotto da Kuaishou, alta velocità |
| Luma     | `POST /luma/videos` | — | Controllo dei fotogrammi iniziali e finali |
| Hailuo   | `POST /hailuo/videos` | minimax-t2v | Prodotto da MiniMax |
| Seedance | `POST /seedance/videos` | doubao-seedance-1-0-pro-250528 | Prodotto da ByteDance |
| Wan      | `POST /wan/videos` | wan2.6-t2v | Prodotto da Alibaba |

## Guida rapida

### Generazione video con Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A cat playing in a sunny garden",
        "model": "sora-2",
        "duration": 10,
        "orientation": "landscape",
    },
)
print(response.json())
```

### Generazione video con Kling

```python
response = requests.post(
    "https://api.acedata.cloud/kling/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A white cat walking in the snow",
        "model": "kling-v2-5-turbo",
        "duration": 5,
        "aspect_ratio": "16:9",
    },
)
print(response.json())
```

### Generazione video con Veo

```python
response = requests.post(
```

## Gestione asincrona delle attività

La generazione video richiede generalmente tempi lunghi. Tutte le API video supportano:

1. **Notifiche callback**: impostando `callback_url` nella richiesta, il risultato viene inviato automaticamente al completamento
2. **Polling dello stato**: tramite l'endpoint `/tasks` è possibile interrogare lo stato dell'attività

```python
# Uso di callback URL
data = {
    "prompt": "A sunrise over mountains",
    "model": "sora-2",
    "callback_url": "https://your-server.com/webhook",
}

# Oppure polling dello stato dell'attività
task_response = requests.post("https://api.acedata.cloud/sora/tasks",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json={"task_id": "your-task-id"})
```
