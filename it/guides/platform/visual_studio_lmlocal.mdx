LMLocal è un'estensione per Visual Studio 2022/2026, che supporta ufficialmente API compatibili con OpenAI e URL di base personalizzati. L'ingresso di configurazione potrebbe variare con le versioni dell'estensione; per la prima integrazione, si prega di fissare la versione e controllare l'editing reale, le chiamate agli strumenti e la registrazione dell'uso.

## Configurazione

1. Installa LMLocal dal Visual Studio Marketplace o dal repository ufficiale.
2. Aggiungi un Provider Custom/OpenAI-compatible in Providers.
3. Compila l'URL di base con `https://api.acedata.cloud/v1`.
4. Compila l'Auth Key con il tuo Token API di Ace Data Cloud.
5. Compila il Model con l'ID del modello esatto che supporta le Chat Completions nella directory dei modelli.
6. Dopo aver salvato, invia `Reply only OK`, quindi testa di nuovo il flusso di editing del progetto.

## Attuali limiti

- Questa guida copre solo LMLocal e non rappresenta la configurazione condivisa di altre estensioni di Visual Studio.
- Versioni diverse potrebbero gestire separatamente le richieste di chat, editing, costruzione e test; ciascun modo deve essere verificato indipendentemente.
- Se il client aggiunge automaticamente `/v1` o il percorso dell'endpoint, si prega di evitare percorsi duplicati.
