Il modello Provider, l'estensione IDE e il MCP di OpenCode sono tre capacità indipendenti. L'estensione IDE si connette al runtime locale di OpenCode e riutilizza la stessa configurazione del Provider; non rappresenta il supporto nativo dell'editor host per Ace Data Cloud.

| Percorso                        | Descrizione                                               | Link                                                                                     | Stato      |
| ----------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------- |
| Provider Terminal / CLI / TUI | Utilizza `opencode.json[c]` e Chat Completions          | [Configurazione del Provider](https://platform.acedata.cloud/documents/opencode-terminal-integration) | Contratto di configurazione verificato |
| Estensione IDE                | VS Code, Cursor, Windsurf, VSCodium e altri host collegati al runtime di OpenCode | [Configurazione IDE](https://platform.acedata.cloud/documents/opencode-ide-integration)           | Sperimentale     |
| MCP                           | Chiamata a strumenti remoti all'interno di OpenCode     | [Panoramica MCP](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | Capacità indipendente    |

Dopo una configurazione riuscita del Provider, l'estensione IDE dovrebbe utilizzare lo stesso Provider e modello. È necessario verificare separatamente la chat all'interno dell'IDE, la lettura dei file, la modifica e la chiamata degli strumenti; non si dovrebbe automaticamente estendere una richiesta normale del CLI a tutte le capacità dell'IDE.

L'ID del modello è basato sul [catalogo in tempo reale](https://platform.acedata.cloud/models).
