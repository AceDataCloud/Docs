---
title: "Recuperare l'elenco degli ordini della piattaforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Restituisce in modo paginato gli ordini di ricarica dell'account, adatto per trovare l'ID dell'ordine, visualizzare lo stato del pagamento e la riconciliazione.

## Preparazione

Crea un [Account Token](https://platform.acedata.cloud/documents/platform-token) e ottieni l'UUID dell'account corrente da `GET /api/v1/platform-tokens/me/`.

```shell
export PLATFORM_TOKEN='il tuo token dell'account'
export USER_ID='l'UUID del tuo account'
```

## Panoramica dell'interfaccia

| Voce   | Contenuto                                       |
| --- | ----------------------------------------------- |
| Metodo  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/orders/` |
| Autorizzazione  | Account Token, il token OAuth richiede `orders:read`       |
| Paginazione  | `count` + `items`                               |

Gli utenti normali devono passare il proprio `user_id`; altrimenti, quando la paginazione incontra oggetti non autorizzati, potrebbe restituire `403`.

## Parametri di query

| Parametro                    | Tipo       | Obbligatorio     | Descrizione                                                        |
| --------------------- | -------- | ------ | --------------------------------------------------------- |
| `user_id`             | UUID     | Obbligatorio per gli utenti normali | Account a cui appartiene l'ordine; supporta parametri ripetuti                                             |
| `pay_way`             | string   | No      | Filtra per metodo di pagamento; supporta valori ripetuti o separati da virgole                                        |
| `state`               | string   | No      | Filtra per stato; supporta valori ripetuti o separati da virgole                                          |
| `created_at_from/to`  | datetime | No      | Intervallo dell'ora di creazione                                                    |
| `finished_at_from/to` | datetime | No      | Intervallo dell'ora di completamento                                                    |
| `limit` / `offset`    | integer  | No      | Paginazione                                                        |
| `ordering`            | string   | No      | `created_at`, `-created_at`, `finished_at` o `-finished_at` |

L'elenco corrente non supporta il filtraggio tramite `application_id`, `service_id`, `package_id`, `payment_method` o `tag`; il nome del campo per il metodo di pagamento è `pay_way`.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/orders/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode 'state=Paid,Finished' \
  --data-urlencode 'pay_way=Stripe' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## Descrizione della risposta

La risposta è `{count, items}`. Gli elementi dell'elenco online includono `id`, `user_id`, `application_id/application_ids`, `package_id/package_ids`, `price`, `amount`, `discount`, `remaining_amount`, `state`, `pay_way`, `pay_id`, `pay_url`, `finished_at`, `expired_at`, `invoice`, `metadata` e campi temporali.

- Gli stati effettivi sono `Pending`, `Paid`, `Finished`, `Expired`, `Failed`, `Refunded`, non esiste `Cancelled`.
- I nomi dei campi sono `pay_way`, `finished_at`, `discount` e `price`, non `payment_method`, `paid_at`, `discount_rate` o `final_price`.
- `price` è il prezzo finale registrato dell'ordine; la valuta e i dettagli di regolamento potrebbero trovarsi in metadata controllati e non possono essere dedotti autonomamente solo dal metodo di pagamento.
