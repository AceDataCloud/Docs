---
title: "Ottenere l'elenco dei Proxy sotto un servizio della piattaforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Restituisce in modo paginato gli endpoint Proxy montati su questo servizio tramite Service UUID. Se è presente solo alias, chiamare prima i [dettagli del servizio](https://platform.acedata.cloud/documents/platform-service-detail) per ottenere `id`.

## Panoramica dell'interfaccia

| Voce   | Contenuto                                                              |
| --- | ---------------------------------------------------------------------- |
| Metodo  | `GET`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| Autenticazione  | Pubblica, non richiede token dell'account                                                              |
| Paginazione  | `count` + `items`                                                      |

## Parametri

| Parametro                 | Posizione    | Obbligatorio  | Descrizione                               |
| ------------------ | ----- | --- | -------------------------------- |
| `service_id`       | path  | Sì   | Service UUID, alias non supportato           |
| `limit` / `offset` | query | No   | Paginazione                               |
| `ordering`         | query | No   | Espressione di ordinamento Django; consigliato `rank` o `-rank` |

```shell
export SERVICE_ID='Il tuo Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## Descrizione della risposta

Gli elementi dell'elenco sono serializzati dal modello Proxy; i campi verificati online includono `id`, `service_id`, `title`, `endpoint`, `price`, `stage`, `rank`, `tags`, `metadata`, `document_id`, `service` e i campi temporali.

- Il campo di ingresso business è `endpoint`, non `path`.
- Il campo di prezzo è `price`, non `cost`.
- Se il tipo di Service non è Proxy o non è montato alcun Proxy, viene restituito `items` vuoto.

Le integrazioni pubbliche dipendono solo da `endpoint` e dalle capacità pubblicate, e non dovrebbero dipendere da dettagli di implementazione non pubblici.
