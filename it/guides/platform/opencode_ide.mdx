---
title: "Integrazione dell'estensione OpenCode IDE con Ace Data Cloud"
description: "Platform API guide - Ace Data Cloud"
---

L'estensione ufficiale di OpenCode IDE supporta editor come VS Code, Cursor, Windsurf, VSCodium e riutilizza il runtime locale di OpenCode e la configurazione del Provider. L'estensione IDE riutilizza il Provider CLI locale, ma la catena di richieste potrebbe variare tra le diverse versioni degli editor; per la prima integrazione, si prega di fissare la versione e completare la verifica minima.

## Configurazione del Provider

Prima di tutto, seguire la [configurazione del terminale OpenCode](https://platform.acedata.cloud/documents/opencode-terminal-integration) per configurare il Provider di Ace Data Cloud in `opencode.json` o `opencode.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## Installazione dell'estensione IDE

1. Eseguire `opencode` nel terminale integrato dell'editor, seguendo il processo ufficiale per installare automaticamente l'estensione; è anche possibile installarla manualmente dal Marketplace corrispondente.
2. Ricaricare l'editor.
3. Iniziare `Reply only OK` dall'estensione OpenCode.
4. Eseguire nuovamente la richiesta che richiede la lettura di file o la modifica di codice, per confermare che l'estensione IDE utilizzi lo stesso Provider e modello.

## Limiti attuali

- Le capacità del Provider derivano dal runtime di OpenCode e non rappresentano il supporto nativo del editor host per Ace Data Cloud.
- Le versioni delle estensioni di VS Code e dei vari fork potrebbero differire, e dovrebbero essere registrate separatamente.
- Una chat normale di successo non può sostituire la verifica della lettura di file, modifica e chiamata di strumenti.
