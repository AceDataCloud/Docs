Coze supporta ufficialmente l'integrazione di modelli personalizzati e fornisce tre protocolli: OpenAI Chat API, OpenAI Responses API e Anthropic Messages API. Gli URL di base, la concatenazione dei percorsi, gli header, lo streaming e i contratti di chiamata degli strumenti sono diversi per ciascuna delle tre rotte, quindi devono essere configurati e verificati separatamente.

| Rotta                      | Stato  | Guida                                                                                  |
| ----------------------- | --- | ----------------------------------------------------------------------------------- |
| OpenAI Chat Completions | Sperimentale | [Configurazione Chat](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | Sperimentale | [Configurazione Responses](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | Sperimentale | [Configurazione Messages](https://platform.acedata.cloud/documents/coze-messages-integration)   |

"Sperimentale" indica che le capacità ufficiali e i punti di accesso alla configurazione sono stati confermati, ma diverse aree, versioni o pacchetti di Coze potrebbero mostrare moduli diversi; Ace Data Cloud deve comunque completare la verifica della versione fissa secondo il protocollo. Non si deve estendere il successo di un protocollo agli altri due.

## Principi di configurazione

- L'URL API di base deve essere compilato prioritariamente con quello fornito nella documentazione; non aggiungere nuovamente il percorso dell'endpoint che il client completerà automaticamente.
- La chiave API deve utilizzare il tuo token API di Ace Data Cloud.
- Il modello deve utilizzare l'ID modello esatto compatibile con il protocollo scelto presente nel catalogo dei modelli.
- Dopo il successo del testo normale, è necessario verificare anche lo streaming e le chiamate agli strumenti.
