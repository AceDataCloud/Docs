---
title: "Ottenere l'elenco delle API sotto un servizio della piattaforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Restituisce in modo paginato le API attualmente abilitate e non deprecate del servizio tramite Service UUID. Se è disponibile solo l'alias, chiamare prima i [dettagli del servizio](https://platform.acedata.cloud/documents/platform-service-detail) per ottenere `id`.

## Panoramica dell'interfaccia

| Voce   | Contenuto                                                                  |
| --- | ------------------------------------------------------------------- |
| Metodo  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| Autenticazione  | Pubblica, nessun token dell'account richiesto                                                           |
| Paginazione  | `count` + `items`                                                   |

## Parametri

| Parametro           | Posizione    | Obbligatorio  | Descrizione                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | Sì   | Service UUID, alias non supportato           |
| `limit`      | query | No   | Numero di elementi per pagina, massimo 100                      |
| `offset`     | query | No   | Offset della paginazione                            |
| `ordering`   | query | No   | Espressione di ordinamento Django; consigliato `rank` o `-rank` |

L'interfaccia corrente non supporta il filtro `stage`; ha già escluso le API `Deprecated`.

```shell
export SERVICE_ID='Il tuo Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

Gli elementi dell'elenco utilizzano la stessa struttura di indice dell'[elenco API della piattaforma](https://platform.acedata.cloud/documents/platform-api-list) e attualmente includono `definition`. Quando è necessario un punto di accesso stabile per una singola API, continuare a chiamare `/api/v1/apis/{api_id}`.

## Gestione degli errori

- Il servizio non esiste o non è visibile nel sito corrente: `404`.
- `service_id` deve essere un UUID; l'alias non verrà risolto in questa action.
