La documentazione ufficiale del modello personalizzato Coze supporta l'API OpenAI Responses e fornisce l'URL di base dell'API, la chiave API e i campi del modello. Le diverse versioni dei tenant Coze possono gestire la concatenazione dei percorsi, l'output in streaming e le chiamate agli strumenti in modo diverso; per il primo accesso, controlla ogni punto di seguito.

## Configurazione

1. Accedi alla gestione dei modelli Coze e aggiungi un modello personalizzato.
2. Seleziona Protocollo OpenAI Responses API.
3. Compila l'URL di base dell'API con `https://api.acedata.cloud/v1`.
4. Compila la chiave API con il tuo token API di Ace Data Cloud.
5. Compila il modello con l'ID del modello esatto che supporta l'API Responses nella directory dei modelli.
6. Salva e completa il test di connessione di Coze.
7. Invia `Reply only OK` nel Bot/Agent e testa di nuovo la chiamata allo strumento.

## Attuali Limiti

- Diverse aree, versioni o pacchetti Coze potrebbero mostrare moduli diversi.
- L'URL di base dell'API deve utilizzare base, non aggiungere nuovamente `/responses`; se l'attuale interfaccia utente richiede esplicitamente l'URL completo dell'API, attenersi alle indicazioni del modulo.
- Chat Completions, Responses e Anthropic Messages sono tre percorsi indipendenti e non possono sostituirsi a vicenda per la verifica.
