Inferpal è un'estensione per Visual Studio 2022/2026, ufficialmente supporta la connessione a servizi compatibili con OpenAI. La versione dell'estensione può influenzare l'editing, le chiamate agli strumenti e la registrazione dell'uso; per la prima integrazione, si prega di fissare la versione e completare la minima verifica di seguito.

## Configurazione

1. Installa Inferpal dal Visual Studio Marketplace o dal repository ufficiale.
2. Apri **Impostazioni di Inferpal → Connessione**.
3. Seleziona Provider OpenAI-compatible.
4. Compila l'URL di base con `https://api.acedata.cloud/v1`.
5. Compila la chiave API con il tuo token API di Ace Data Cloud.
6. Compila il modello con l'ID del modello esatto che supporta le Chat Completions nella directory dei modelli.
7. Dopo aver salvato, invia `Rispondi solo OK`, quindi esegui nuovamente una richiesta che includa il contesto del codice.

## Limiti attuali

- Questa guida copre solo Inferpal e non rappresenta il supporto per i campi simili da parte di Copilot integrato in Visual Studio o altre estensioni.
- Diverse versioni potrebbero aggiungere automaticamente percorsi all'URL di base; se la richiesta fallisce, verifica prima che la richiesta finale rientri nell'endpoint delle Chat Completions.
- Prima di completare la versione fissa E2E, non si garantisce che tutti i modelli di editing, completamento o chiamate agli strumenti siano disponibili.
