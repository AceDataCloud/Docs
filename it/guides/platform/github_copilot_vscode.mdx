La documentazione ufficiale BYOK di GitHub Copilot elenca VS Code come client locale supportato e supporta Provider compatibili con OpenAI. La versione di VS Code, le politiche aziendali e la visibilità del modello influenzeranno l'endpoint finale; per la prima integrazione, controlla le richieste effettive di seguito.

## Ambito di configurazione

1. Conferma che il tuo account o organizzazione GitHub Copilot abbia abilitato la funzionalità BYOK/Modelli personalizzati.
2. Aggiungi un Provider compatibile con OpenAI nella gestione dei modelli di Copilot in VS Code.
3. Compila l'URL di base con `https://api.acedata.cloud/v1`.
4. Compila la chiave API con il tuo Token API di Ace Data Cloud.
5. Compila il modello con l'ID del modello esatto compatibile con il protocollo selezionato nella directory dei modelli.
6. Invia `Reply only OK` in Copilot Chat, quindi testa nuovamente una richiesta con il contesto del workspace.

## Limiti attuali

- L'app Copilot, CLI, GitHub Desktop, Enterprise BYOK e la configurazione di VS Code hanno contratti diversi; questa guida non applica direttamente i passaggi di altri client a VS Code.
- Le politiche organizzative potrebbero vietare agli individui di aggiungere Provider o modelli.
- Il completamento automatico, Chat, Agent e i task in background potrebbero utilizzare percorsi di modelli diversi, e dovrebbero essere verificati separatamente.
