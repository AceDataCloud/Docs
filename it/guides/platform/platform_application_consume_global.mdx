---
title: "Configurare la condivisione globale del saldo di AceDataCloud Application"
description: "Platform API guide - Ace Data Cloud"
---

Configura `allow_consume_global`. Dopo l'attivazione, le Application a consumo che soddisfano le condizioni possono continuare a utilizzare il saldo globale dell'account quando il proprio saldo è insufficiente.

## Preparazione

- Crea e conserva in modo sicuro un [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Ottieni l'`application_id` delle Application di tua proprietà dall'[elenco delle richieste di servizio](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='il tuo token dell'account'
export APPLICATION_ID='il tuo Application ID'
```

## Panoramica dell'interfaccia

| Voce    | Contenuto                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------- |
| Metodo   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Autenticazione   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

In caso di successo viene restituito l'oggetto Application aggiornato. Fai riferimento a `allow_consume_global` nella risposta, anziché presumere che il valore richiesto sia stato necessariamente salvato.

> Le Application di tipo `Period` non possono consumare il saldo globale. Anche se viene richiesto `true`, il server manterrà questo campo su `false`.

## Gestione degli errori

- `401`: Account Token non valido o mancante.
- `403`: l'account corrente non è il proprietario di questa Application.
- `404`: Application ID inesistente.

Per il punto di ricarica del saldo globale e i pacchetti disponibili, fai riferimento alla console della piattaforma e ai pacchetti effettivamente restituiti dalla [creazione dell'ordine](https://platform.acedata.cloud/documents/platform-order-create); non presumere l'esistenza di pacchetti di tipo `Wallet`.

## Applicazioni autorizzate allo scoperto

Quando il campo di sola lettura `allow_overdraft=true` di un'applicazione a consumo è impostato, l'applicazione può continuare ad addebitare dal proprio saldo, anche se il saldo diventa negativo, e non passerà all'account globale a causa di un saldo insufficiente. Le applicazioni senza scoperto attivato seguono comunque `allow_consume_global`; dopo il passaggio, l'eventuale autorizzazione allo scoperto dipende dalla configurazione dell'Application globale effettivamente addebitata.
