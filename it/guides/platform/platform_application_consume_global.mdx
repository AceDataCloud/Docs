---
title: "Configurare la condivisione del saldo globale di AceDataCloud Application"
description: "Platform API guide - Ace Data Cloud"
---

Configura `allow_consume_global`. Dopo l'attivazione, le Application a consumo che soddisfano le condizioni possono continuare a utilizzare il saldo globale dell'account quando il proprio saldo è insufficiente.

## Preparazione

- Crea e conserva in modo sicuro l'[Account Token](https://platform.acedata.cloud/documents/platform-token).
- Ottieni l'`application_id` di tua proprietà dall'[elenco delle richieste di servizio](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='il tuo token dell’account'
export APPLICATION_ID='il tuo Application ID'
```

## Panoramica dell'interfaccia

| Voce    | Contenuto                                                                                          |
| ---- | -------------------------------------------------------------------------------------------------- |
| Metodo   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Autenticazione   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

In caso di successo, viene restituito l'oggetto Application aggiornato. Fai riferimento a `allow_consume_global` nella risposta, anziché presumere che il valore della richiesta venga sicuramente salvato.

> Le Application di tipo `Period` non sono autorizzate a consumare il saldo globale. Anche se viene richiesto `true`, il server manterrà questo campo come `false`.

## Gestione degli errori

- `401`: Account Token non valido o mancante.
- `403`: l'account corrente non è il proprietario di questa Application.
- `404`: Application ID non esistente.

Per il punto di ricarica del saldo globale e i pacchetti disponibili, fai riferimento alla console della piattaforma e ai pacchetti effettivi restituiti dalla [creazione dell'ordine](https://platform.acedata.cloud/documents/platform-order-create); non presumere l'esistenza di pacchetti di tipo `Wallet`.
