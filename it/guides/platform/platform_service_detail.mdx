Ottieni le informazioni complete di un singolo servizio tramite l'ID del servizio (UUID) o l'alias (alias): rispetto a [Ottenere l'elenco dei servizi della piattaforma AceDataCloud](https://platform.acedata.cloud/documents/platform-service-list), i campi restituiti sono più completi e verranno espansi ulteriormente oggetti associati come `apis`, `proxies`, `datasets`, `packages` e altri. Adatto a scenari come pagine di dettagli del servizio, pagine di confronto prezzi, descrizioni di strumenti Agent e altri.

> ℹ️ Questa interfaccia appartiene all'**API di gestione della piattaforma AceDataCloud**, con prefisso unificato `https://platform.acedata.cloud/api/v1/`. Per l'indice completo delle interfacce, vedere [Ottenere l'elenco dei documenti della piattaforma AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list).

## Panoramica dell'interfaccia

| Voce   | Contenuto                                                    |
| --- | ------------------------------------------------------------- |
| Metodo  | `GET`                                                         |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}` |
| Autenticazione  | ❌ Pubblica                                                          |

`/services/{id}` e `/services/{id}/` sono attualmente entrambi disponibili; gli esempi utilizzano uniformemente il formato senza barra finale.

## Istruzioni sull'autenticazione

Questa interfaccia è completamente pubblica. **Tuttavia, dopo aver aggiunto il token dell'account, il campo `applied` nella risposta rifletterà lo stato effettivo della richiesta dell'account corrente**, altrimenti sarà sempre `false`.

Per il metodo di ottenimento del token dell'account, vedere [Gestire i token dell'account della piattaforma AceDataCloud](https://platform.acedata.cloud/documents/platform-token).

## Parametri del percorso

| Parametro           | Tipo            | Obbligatorio  | Descrizione                                                    |
| ------------ | ------------- | --- | ----------------------------------------------------- |
| `service_id` | UUID / string | ✅   | ID del servizio (UUID) o alias (`midjourney`, `openai`, `webextrator` e altri) |

## Esempi di richiesta

### cURL

```shell
# 按 UUID 查询
curl 'https://platform.acedata.cloud/api/v1/services/8efa1d83-9b75-4562-b44a-af95ce563d05' \
  -H 'accept: application/json'

# 按 alias 查询
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json'

# 带账户令牌看 applied 状态
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

resp = requests.get(
    "https://platform.acedata.cloud/api/v1/services/midjourney",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
svc = resp.json()
print(f"服务: {svc['title']} ({svc['alias']})")
print(f"已申请: {svc['applied']}, 免费额度: {svc['free_amount']} {svc['unit']}")
print(f"API 数: {len(svc['apis'])}, 套餐数: {len(svc['packages'])}")
for pkg in svc["packages"]:
    print(f"  ¥{pkg['price']:>7.2f}  ->  {pkg['amount']} {svc['unit']}")
```

### Node.js

```javascript
const r = await fetch('https://platform.acedata.cloud/api/v1/services/midjourney', {
  headers: { accept: 'application/json' },
})
const svc = await r.json()
console.log(`${svc.title} - 套餐 ${svc.packages.length} 个 - API ${svc.apis.length} 个`)
```

## Descrizione dei campi di risposta

L'interfaccia dei dettagli, oltre a tutti i campi dell'[interfaccia elenco](https://platform.acedata.cloud/documents/platform-service-list), espande ulteriormente:

| Campo         | Tipo    | Descrizione                                                            |
| ---------- | ----- | ------------------------------------------------------------- |
| `apis`     | array | Elenco completo degli oggetti API associati (ogni voce contiene `id`, `name`, `title`, `path`, `stage`, `cost`) |
| `proxies`  | array | Elenco completo degli oggetti Proxy associati                                              |
| `datasets` | array | Dataset associati (se `type=Dataset`)                                      |
| `packages` | array | Elenco dei pacchetti, contenente `type` (`Usage`/`Period`), `price`, `amount`, `duration`   |

Per le definizioni degli altri campi, vedere [Ottenere l'elenco dei servizi della piattaforma AceDataCloud → Descrizione dei campi di risposta](https://platform.acedata.cloud/documents/platform-service-list).

## Gestione degli errori

| HTTP | code        | Significato                            |
| ---- | ----------- | ----------------------------- |
| 404  | `not_found` | `service_id` (UUID o alias) non esiste |
| 500  | —           | Generalmente viene aggiunta erroneamente una barra finale all'URL; rimuoverla e riprovare          |

## Suggerimenti pratici

- **`alias` > `UUID`**: codificare rigidamente l'`alias` (come `midjourney`) nel codice è più stabile; l'UUID cambia durante la migrazione dell'ambiente.
- **Il campo `apis` non contiene la definizione OpenAPI**: lo Schema OpenAPI 3.0 completo si trova nell'interfaccia [Ottenere i dettagli API della piattaforma AceDataCloud](https://platform.acedata.cloud/documents/platform-api-detail).
- **Recuperare le "capacità complete" di un servizio**: utilizzare questa interfaccia per ottenere `api_ids`, quindi chiamare uno per uno `/apis/{api_id}` per recuperare i dettagli.
- **Se `applied=true`**, è possibile [creare direttamente le credenziali API](https://platform.acedata.cloud/documents/platform-credential-create) per ottenere il Token di 32 caratteri necessario per chiamare le interfacce aziendali, senza dover richiedere nuovamente.
