---
title: "Ottenere l'elenco dei servizi della piattaforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Restituisce in modo paginato il catalogo dei Service visibili nel sito corrente, inclusi tipo di servizio, informazioni di visualizzazione, quota gratuita, piani e ID API/Proxy associati. Adatto per creare un marketplace di servizi o selezionare i servizi da richiedere.

## Panoramica dell'interfaccia

| Voce   | Contenuto                                                |
| --- | ------------------------------------------------- |
| Metodo  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| Autenticazione  | Pubblica; con stato di accesso `applied` riflette l'account corrente                        |
| Paginazione  | `count` + `items`                                 |

## Parametri di query

| Parametro               | Tipo      | Obbligatorio  | Descrizione                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | No   | Filtra per ID del servizio; supporta parametri ripetuti         |
| `private`        | boolean | No   | Filtra per stato pubblico; le regole di visibilità del sito restano valide      |
| `type`           | string  | No   | Tipo di servizio; supporta parametri ripetuti              |
| `tag`            | string  | No   | Filtra per tag                    |
| `include_facets` | boolean | No   | Quando è `true`, aggiunge le statistiche dei tipi/tag disponibili nel sito corrente |
| `limit`          | integer | No   | Numero di elementi per pagina, massimo 100              |
| `offset`         | integer | No   | Offset di paginazione                    |
| `ordering`       | string  | No   | Supporta solo `rank` o `-rank`     |

L'elenco non supporta il filtro `alias`; quando esiste già un alias, richiedere direttamente `/api/v1/services/{alias}`. `applied_count` e `updated_at` non sono campi di ordinamento consentiti.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## Descrizione della risposta

La risposta è `{count, items}`; aggiunge `facets` solo quando `include_facets=true`. Gli elementi del servizio includono i campi pubblici correnti quali `id`, `alias`, `title`, `description`, `type`, `applied_count`, `free_amount`, `unit`, `private`, `need_verify`, `rank`, `tags`, `thumbnail`, `doc_url`, `demo_url`, `api_ids`, `proxy_ids`, `cost`, `packages` e altri.

`applied` nell'elenco anonimo non rappresenta lo stato della richiesta di un determinato account. Quando è necessario uno stato relativo all'account, utilizzare uno stato di accesso valido e fare riferimento all'[elenco delle richieste di servizio](https://platform.acedata.cloud/documents/platform-application-list) come fonte definitiva.
