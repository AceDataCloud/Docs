[NextChat](https://github.com/ChatGPTNextWeb/NextChat) (precedentemente ChatGPT-Next-Web) è un client AI open source, distribuibile su Vercel, Cloudflare o Docker. Supporta endpoint compatibili con OpenAI personalizzati, pertanto può essere collegato ad Ace Data Cloud. Questo articolo illustra il processo di configurazione.

## Procedura di richiesta

Per collegare Ace Data Cloud in NextChat, innanzitutto vai alla [console di Ace Data Cloud](https://platform.acedata.cloud/console/applications), ottieni il tuo API Token e conservalo come riserva.

![Ottenere Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Se non hai ancora effettuato l'accesso o la registrazione, verrai automaticamente reindirizzato alla pagina di accesso per invitarti a registrarti e ad accedere; dopo l'accesso e la registrazione tornerai automaticamente alla pagina corrente.

Alla prima richiesta verrà offerta una quota gratuita, con cui potrai provare gratuitamente i servizi modello di Ace Data Cloud.

## Scaricare NextChat

Puoi utilizzare la versione desktop (scarica `.exe` / `.dmg` / AppImage dalla [pagina Releases](https://github.com/ChatGPTNextWeb/NextChat/releases)), la [versione Web online](https://app.nextchat.club/), oppure distribuirlo autonomamente su Vercel / Cloudflare / Docker (vedi la sezione avanzata qui sotto).

## Configurare Ace Data Cloud

Avvia NextChat e vai su **Impostazioni → Servizi modello**:

| Campo          | Valore                           | Descrizione                              |
| ----------- | --------------------------- | ------------------------------- |
| Provider del servizio modello       | `OpenAI`                    | Utilizza il protocollo compatibile con OpenAI                  |
| Indirizzo API OpenAI | `https://api.acedata.cloud` | Inserisci solo il dominio radice, **senza `/openai`, senza `/v1`** |
| API Key     | Il tuo Token Ace Data Cloud     | Il Token copiato dalla console                    |

![Interfaccia di configurazione Ace Data Cloud di NextChat](https://cdn.acedata.cloud/47e0aed34570.png)

NextChat aggiungerà automaticamente `/v1/chat/completions` dopo l'indirizzo API, pertanto è sufficiente inserire il dominio radice:

| Indirizzo API                                  | Richiesta effettiva                                                      | Risultato                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | Corretto                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (non esiste `/v1` sotto `/openai`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

Nel campo «Nome modello personalizzato», inserisci i modelli separandoli con virgole inglesi. NextChat supporta una sintassi speciale: `+nome_modello` per aggiungere, `-nome_modello` per nascondere, `nome_modello=nome_visualizzato` per personalizzare il nome visualizzato, `-all` per nascondere prima tutti. La sintassi più pulita consigliata è:

```text
-all,+MODEL_ID=nome visualizzato
```

## Selezionare un modello

Il catalogo dei modelli verrà aggiornato continuamente. Dai priorità all'elenco dei modelli caricato automaticamente dal client; quando è necessario compilare manualmente, richiedi prima `GET https://api.acedata.cloud/v1/models` per ottenere l'ID del modello corrente, quindi scegli in base alle capacità di contesto, immagini e chiamate strumenti supportate dal client.

## Verificare l'integrazione

Se non sei sicuro che il problema sia in NextChat o nella rete, puoi prima usare curl per verificare direttamente l'endpoint (sostituisci `{token}` con il tuo Token):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

La restituzione di un oggetto `chat.completion` compatibile con OpenAI indica che sia il Token sia l'endpoint sono pronti; se viene restituito `HTTP 403 used_up`, significa che il Token è valido ma il saldo è insufficiente: basta effettuare una ricarica nella [console](https://platform.acedata.cloud/console/applications).

## Avanzato: distribuzione con un clic sul proprio dominio

NextChat supporta la distribuzione di un sito AI personale. Prendendo Docker come esempio (sostituisci `{token}` con il tuo Token):

```bash
docker run -d \
  --name nextchat \
  -p 3000:3000 \
  -e OPENAI_API_KEY={token} \
  -e BASE_URL=https://api.acedata.cloud \
  -e CODE=your-password \
  -e CUSTOM_MODELS="-all,+MODEL_ID=显示名称" \
  yidadaa/chatgpt-next-web
```

Durante la distribuzione su Vercel / Cloudflare, configura nelle variabili d'ambiente del progetto gli stessi `OPENAI_API_KEY`, `BASE_URL`, `CODE`, `CUSTOM_MODELS`. `CODE` supporta più password di accesso separate da virgole inglesi, facilitando la statistica dell'utilizzo per persona. Per la descrizione completa delle variabili d'ambiente sopra indicate (`BASE_URL` predefinito `https://api.openai.com`, sintassi `+/-/=/-all/+all` di `CUSTOM_MODELS`), fai riferimento al [README ufficiale di NextChat](https://github.com/ChatGPTNextWeb/NextChat#environment-variables).

## Domande frequenti

### Viene visualizzato 404 Not Found

Di solito l'indirizzo API è stato scritto come `.../openai` o `.../openai/v1`. Modificalo in `https://api.acedata.cloud` e lascia che NextChat aggiunga autonomamente `/v1/chat/completions`.

### Il modello aggiunto non appare nel menu a discesa dei modelli

Controlla il formato di `CUSTOM_MODELS`: ogni modello deve avere `+` davanti; se hai usato `-all`, assicurati di aggiungere nuovamente con `+` i modelli necessari in seguito.

### Viene visualizzato 401 Unauthorized

Assicurati che nell'API Key sia incollato il Token di Ace Data Cloud (senza prefisso `Bearer`, senza spazi aggiuntivi) e che il saldo dell'applicazione a cui appartiene sia sufficiente.
