Legge gli interruttori di funzionalità pubblici e la determinazione del paese/regione nel contesto della richiesta corrente. È adatto per decidere se mostrare le funzionalità all'avvio del frontend; non riguarda il brand del sito, i contatti o il catalogo degli annunci.

## Panoramica dell'interfaccia

| Voce   | Contenuto                                      |
| --- | ----------------------------------------------- |
| Metodo  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Autenticazione  | Pubblica; quando viene trasportato uno stato di accesso, alcuni interruttori di funzionalità potrebbero essere calcolati in base all'utente                          |

## Parametri di query e intestazioni della richiesta

| Nome                    | Posizione     | Descrizione                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | Espressione di override degli interruttori di funzionalità; valida solo per gli interruttori che consentono l'override dal client o per i super amministratori |
| `X-Feature-Overrides` | header | Fonte di override identica a `features`           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## Struttura della risposta reale

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| Campo         | Tipo            | Descrizione                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Interruttori di funzionalità visibili alla richiesta corrente; le chiavi variano in base alla configurazione della piattaforma, il client deve leggerle secondo necessità e impostare valori predefiniti sicuri per le chiavi mancanti |
| `region`   | string / null | Codice del paese o della regione rilevato in base all'IP della richiesta, in minuscolo; è `null` quando non può essere identificato        |

Non leggere da questa interfaccia il nome del sito, il CDN, la valuta, la lingua, i contatti dell'assistenza clienti o gli annunci; questi campi non fanno parte del contratto di risposta corrente.

## Suggerimenti per l'uso

- Gli interruttori di funzionalità vengono calcolati in base all'utente, all'impronta digitale e al contesto del sito; non condividere cache a lungo termine tra utenti diversi.
- La selezione del selettore di regione viene salvata solo nel frontend; durante la visualizzazione, utilizzare prioritariamente la regione già selezionata, altrimenti usare `region` di questa interfaccia. Questa interfaccia non accetta parametri di override della regione.
- I parametri di query non riconosciuti vengono ignorati; utilizzare solo i parametri elencati in questa pagina.
