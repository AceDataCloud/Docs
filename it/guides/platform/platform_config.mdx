Legge gli interruttori di funzionalità pubblici e la determinazione del paese/regione nel contesto della richiesta corrente. È adatto per decidere se visualizzare le funzionalità all'avvio del frontend; non riguarda il brand del sito, i contatti o il catalogo degli annunci.

## Panoramica dell'interfaccia

| Voce   | Contenuto                                              |
| --- | ----------------------------------------------- |
| Metodo  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Autenticazione  | Pubblica; quando viene trasmesso lo stato di accesso, alcuni interruttori di funzionalità potrebbero essere calcolati in base all'utente                          |

## Parametri di query e intestazioni della richiesta

| Nome                    | Posizione     | Descrizione                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | Codice paese ASCII di due lettere; utilizzato per sovrascrivere il paese visualizzato nella risposta, senza modificare la valutazione di sicurezza lato server |
| `features`            | query  | Espressione di sovrascrittura degli interruttori di funzionalità; valida solo per gli interruttori autorizzati alla sovrascrittura client o per i super amministratori        |
| `X-Feature-Overrides` | header | Fonte di sovrascrittura identica a `features`                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## Struttura della risposta effettiva

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| Campo         | Tipo            | Descrizione                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Interruttori di funzionalità visibili nella richiesta corrente; le chiavi cambiano in base alla configurazione della piattaforma, il client deve leggerle secondo necessità e impostare valori predefiniti sicuri per le chiavi mancanti |
| `country`  | string / null | Codice paese in minuscolo; potrebbe essere `null` quando non è possibile identificarlo                     |

Non leggere da questa interfaccia il nome del sito, il CDN, la valuta, la lingua, i contatti dell'assistenza clienti o gli annunci; questi campi non appartengono al contratto di risposta corrente.

## Suggerimenti per l'utilizzo

- Gli interruttori di funzionalità vengono calcolati in base all'utente, all'impronta digitale e al contesto del sito; non condividere cache a lungo termine tra utenti diversi.
- Il `country` trasmesso dal client influisce solo sul valore restituito e non aggira le politiche regionali o di sicurezza lato server.
- I parametri di query non riconosciuti verranno ignorati; utilizzare solo i parametri elencati in questa pagina.
