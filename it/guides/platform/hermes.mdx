description: "Platform API guide - Ace Data Cloud"
---

Hermes Agent si integra con Ace Data Cloud tramite il protocollo OpenAI Chat Completions. Scegli uno dei seguenti metodi di configurazione:

| Metodo di configurazione       | Guida                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| Guida interattiva `hermes model` | [Configurazione della guida](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| Configurazione manuale `config.yaml`  | [Configurazione manuale](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| Distribuzione privata della piattaforma              | [Distribuzione gestita](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

Parametri comuni per l'integrazione locale:

- Base URL: `https://api.acedata.cloud/v1`
- Transport: `chat_completions`
- Provider: `custom:acedatacloud`
- API Key: da ottenere dalla [lista delle applicazioni](https://platform.acedata.cloud/console/applications)

Entrambi i metodi locali scrivono infine in `~/.hermes/config.yaml`, non configurare due volte.

Torna al [Centro di configurazione del Piano di Codifica](https://platform.acedata.cloud/documents/coding-plan-integration).
