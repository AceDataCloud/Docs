---
title: "Rotazione delle credenziali API della piattaforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Genera un nuovo Token o password per una Credential esistente. L'ID della credenziale, l'associazione Application, i limiti e gli altri campi rimangono invariati, e il vecchio segreto diventa immediatamente non valido.

> La rotazione interromperà i client che utilizzano ancora il vecchio segreto. Prepara prima un piano di distribuzione sicura e rollback, quindi esegui l'operazione di scrittura.

## Panoramica dell'interfaccia

| Voce    | Contenuto                                                                  |
| ---- | --------------------------------------------------------------------------- |
| Metodo   | `POST`                                                                      |
| URL  | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}/rotate/` |
| Autenticazione   | Account Token                                                               |
| Body | Nessuno o `{}`                                                                     |

Ottieni `credential_id` dall'[elenco delle credenziali](https://platform.acedata.cloud/documents/platform-credential-list):

```shell
export PLATFORM_TOKEN='你的账户令牌'
export CREDENTIAL_ID='要轮换的 Credential ID'

curl -X POST \
  "https://platform.acedata.cloud/api/v1/credentials/${CREDENTIAL_ID}/rotate/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

In caso di successo viene restituita la Credential aggiornata. Quando `type=Token`, leggi il nuovo `token`; quando `type=Identity`, leggi la nuova `password`. Tratta la risposta completa come un segreto e aggiorna immediatamente i chiamanti.

## Gestione degli errori

- `401`: Account Token non valido.
- `403`: Non autorizzato a gestire questa credenziale.
- `404`: L'ID della Credential non esiste.
