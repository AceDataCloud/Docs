---
title: "Ottenere campioni di chiamate recenti dell'API della piattaforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Restituisce pubblicamente campioni di record di chiamata di un'API negli ultimi 15 minuti, per osservare rapidamente lo stato recente. Non è un'interfaccia di conteggio aggregata per codice di stato, né può essere utilizzata per la fatturazione personale, gli SLA o statistiche complete di utilizzo.

## Panoramica dell'interfaccia

| Voce   | Contenuto                                                           |
| --- | ------------------------------------------------------------ |
| Metodo  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| Autenticazione  | Pubblica, nessun token dell'account richiesto                                                    |
| Limite  | Dopo aver unito i record creati/completati più di recente, vengono restituiti al massimo 5.000 record                                    |

`api_id` si ottiene dall'[elenco delle API](https://platform.acedata.cloud/documents/platform-api-list).

```shell
export API_ID='你的 API ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## Struttura della risposta reale

La risposta è direttamente un array, senza utilizzare un envelope di paginazione:

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| Campo            | Descrizione        |
| ------------- | --------- |
| `api_id`      | ID API    |
| `created_at`  | Ora di creazione del record    |
| `trace_id`    | Identificatore di tracciamento della richiesta    |
| `status_code` | Codice di stato HTTP  |
| `elapsed`     | Durata della chiamata, in secondi |

Quando l'API non esiste, attualmente potrebbe essere restituito anche un array vuoto, perché questa action interroga direttamente l'usage recente per ID, senza prima verificare l'oggetto API. Per calcolare il tasso di successo, il client deve raggruppare autonomamente i campioni restituiti; per consultare gli addebiti personali, utilizzare l'interfaccia a livello di account.
