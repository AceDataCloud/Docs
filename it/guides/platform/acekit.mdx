Probabilmente ti è già capitato: stai usando Claude Code, Cursor o Codex, stai scrivendo codice e tutto procede bene, quando all'improvviso ti serve un'immagine di accompagnamento, una musica di sottofondo, un breve video, oppure vuoi che cerchi rapidamente le informazioni più recenti. E scopri che l'agent stesso non sa fare queste cose. Devi trovare da solo le API, leggere la documentazione, configurare le chiavi, scrivere il codice di chiamata, gestire il polling asincrono; dopo tutta questa trafila, l'ispirazione si è già raffreddata.

[AceKit](https://github.com/AceDataCloud/AceKit) serve proprio a risparmiarti tutta questa trafila. Con una riga di comando, inserisce nell'agent di programmazione l'intero set di capacità di AceData Cloud per generazione di immagini, generazione di video, generazione musicale, ricerca web, conversazioni LLM e altro ancora. Dopo l'installazione, parli direttamente in linguaggio naturale e l'agent caricherà da solo le skill corrispondenti, si autenticherà da solo, eseguirà il polling da solo e completerà il lavoro.

## Capisci in 30 secondi cosa fa

Prima dell'installazione vs dopo l'installazione:

| Quello che dici               | Prima dell'installazione                   | Dopo l'installazione (l'agent fa da solo)                      |
| ------------------ | --------------------- | ----------------------------------- |
| "Metti un'immagine di copertina a questo README" | l'agent non sa farlo, ti chiede di cercare da solo un'API di generazione immagini | chiama NanoBanana / Flux / Midjourney per generare l'immagine |
| "Trasforma questo script in un breve video di 30 secondi"  | non sa farlo                    | chiama Sora / Veo / Kling / Seedance per generare il video  |
| "Aggiungi una musica di sottofondo a questa demo"  | non sa farlo                    | chiama Suno per generare la canzone                           |
| "Cerca l'ultimo X e poi riassumilo"     | non può connettersi a Internet                  | chiama Google SERP per ottenere risultati in tempo reale                 |
| "Accorcia questo lungo link"         | non sa farlo                    | chiama il servizio di link brevi e restituisce un link surl.id                  |

In una frase: **il tuo agent di programmazione passa da "sa solo scrivere codice" a "sa anche generare immagini, video, musica e fare ricerche online".**

## Inizia in tre passaggi

L'intero processo si completa in pochi minuti e richiede Node.js 18+.

**Primo passaggio · Ottieni un API Token.** Vai alla [console](https://platform.acedata.cloud/console/applications) e copia il Token: tutte le capacità condividono questo unico Token; alla prima richiesta ricevi credito gratuito, quindi puoi prima provarlo gratuitamente.

![Copia l'API Token nella console](https://cdn.acedata.cloud/dvc3cg.jpg)

**Secondo passaggio · Installa.** Una riga di comando:

```bash
npx acekit
```

Rileverà automaticamente gli agent di programmazione presenti sul computer e installerà l'intero set di skill. L'esecuzione reale appare così (su questa macchina è installato solo Claude Code):

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> Quando il Token non è impostato, alla prima esecuzione ti verrà richiesto in modo interattivo di incollarlo; puoi anche eseguire prima `export ACEDATACLOUD_API_TOKEN=tuotoken` per un'installazione completamente non supervisionata. Il numero di skill varia con l'aumento delle capacità della piattaforma; fai riferimento all'elenco corrente mostrato da `npx acekit list`.

**Terzo passaggio · Parla in linguaggio naturale.** Ricarica l'agent, poi impartisci direttamente istruzioni, ad esempio:

```text
Usa la skill short-url per accorciare https://platform.acedata.cloud/services
```

L'agent caricherà da solo la skill, avvierà da solo la chiamata e ti fornirà un risultato reale navigabile.

## Esecuzione reale (con output)

I quattro esempi qui sotto sono tutti **chiamate reali, con risultati restituiti sul momento**, non dimostrazioni. Il `$KEY` nei comandi è il tuo API Token.

**① Accorciare un URL (sincrono, risposta in pochi secondi)**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

Restituisce `https://surl.id/r/1uKp2kilXQ`—aprendolo, reindirizza con 302 alla pagina services originale.

**② Ricerca online (sincrona)**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

Ottieni risultati Google in tempo reale (estratto):

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ Conversazione LLM (sincrona, un'interfaccia per oltre 50 modelli)**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP è un protocollo utilizzato per gestire e scambiare in modo unificato le informazioni di contesto dei modelli.
（39 token, circa 0.00007 credit per questa volta）
```

**④ Generazione di immagini (asincrona, circa 20 secondi, l'agent esegue automaticamente il polling fino alla generazione dell'immagine)**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

Dopo circa 22 secondi restituisce un'immagine reale (HTTP 200 · image/png · 317 KB · circa 0.13 credit per questa volta):

![Immagine realmente generata da AceKit](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

In realtà non devi ricordare queste interfacce: dopo aver installato le skill, l'agent comporrà da solo le richieste corrette seguendo i rispettivi `SKILL.md`, gestendo autenticazione e polling. Quanto sopra serve solo a mostrarti apertamente "cosa fa dietro le quinte".

## Che cosa installa esattamente

AceKit è la "porta d'ingresso" dell'intero ecosistema di strumenti per sviluppatori di AceData; al momento, una singola installazione aggiunge il **set di strumenti delle skill (Skills)**:

- **Un set di skill per Agent**: ogni skill è un manuale operativo `SKILL.md` già scritto—autenticazione, polling asincrono, nuovi tentativi in caso di errore e compilazione dei parametri sono tutti spiegati chiaramente; l'agent deve solo seguirlo. Esegui `npx acekit list` per vedere l'elenco corrente (al momento della scrittura sono 19, e sono in continuo aumento):
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **Un unico Token**: un `ACEDATACLOUD_API_TOKEN` sblocca tutte le funzionalità, con addebito in base all'utilizzo effettivo.

Classificati per funzionalità (fare riferimento a `npx acekit list`):

| Tipo         | Fornitori                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ Generazione immagini      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 Generazione video      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 Generazione musica / audio | Suno · Producer · Fish Audio（TTS）                    |
| 💬 Chat LLM   | Interfaccia unificata per oltre 50 modelli（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 Ricerca       | Google SERP（web · immagini · notizie · mappe · video）                  |
| 🔗 Strumenti       | Link brevi · elaborazione del volto                                            |

> Per queste stesse funzionalità, AceData fornisce anche **server MCP** indipendenti（Suno、Midjourney、Sora、SERP… pubblicati su PyPI / VS Code / Smithery / Docker）、**CLI da riga di comando** e **SDK Python / TypeScript**, utilizzabili separatamente secondo necessità. AceKit v0.2 prevede di supportare l'installazione di singole funzionalità con `acekit add <name>`, nonché la scrittura automatica della configurazione MCP dei vari agent.

## Quali Agent sono supportati

| Agent                        | Posizione di installazione delle skill                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode ecc. | `~/.agents/skills`（fai puntare qui il tuo agent） |

Durante l'installazione, AceKit rileva automaticamente gli agent già installati sulla macchina e installa solo in quelli rilevati.

## Easter egg: usa lo stesso Token per alimentare Claude Code stesso

L'interfaccia di AceData è compatibile anche con il formato `/v1/messages` di Anthropic, quindi **non hai bisogno di un abbonamento ufficiale Anthropic**: puoi alimentare Claude Code con lo stesso AceData Token. Crea `.claude/settings.local.json` nella directory radice del progetto:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Riavvia Claude Code: utilizzerà sia l'intera famiglia di modelli Claude, sia, tramite AceKit, avrà le "mani" per generare immagini, video e musica. Per maggiori dettagli, consulta la [guida all'integrazione di Claude Code](https://platform.acedata.cloud/documents/claude-code-integration).
