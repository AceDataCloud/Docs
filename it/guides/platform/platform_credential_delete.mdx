---
title: "Eliminare le credenziali API della piattaforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Elimina definitivamente una credenziale API. Dopo l'eliminazione, è **immediatamente irreversibile** e tutte le interfacce aziendali che utilizzano questo Token riceveranno subito `401`.

> ℹ️ Questa interfaccia appartiene alla **API di gestione della piattaforma AceDataCloud**, con prefisso unificato `https://platform.acedata.cloud/api/v1/`.

## Panoramica dell'interfaccia

| Voce   | Contenuto                                                           |
| --- | ------------------------------------------------------------------- |
| Metodo  | `DELETE`                                                            |
| URL | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}` |
| Autenticazione  | ✅ Richiede un token dell'account                                                            |

`/credentials/{id}` e `/credentials/{id}/` sono attualmente entrambi disponibili; gli esempi utilizzano uniformemente il formato senza barra finale.

## Istruzioni per l'autenticazione (come ottenere il token dell'account)

Intestazione della richiesta:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

Per il metodo di ottenimento, consultare [Gestire il token dell'account della piattaforma AceDataCloud](https://platform.acedata.cloud/documents/platform-token).

## Parametri del percorso

| Parametro              | Tipo   | Obbligatorio  | Descrizione        |
| --------------- | ---- | --- | --------- |
| `credential_id` | UUID | ✅   | ID della credenziale da eliminare |

## Esempi di richiesta

### cURL

```shell
curl -X DELETE 'https://platform.acedata.cloud/api/v1/credentials/df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

cred_id = "df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6"
resp = requests.delete(
    f"https://platform.acedata.cloud/api/v1/credentials/{cred_id}",
    headers={"authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"},
    timeout=10,
)
assert resp.status_code == 204, resp.text
print("✅ 已删除")
```

### Node.js

```javascript
const credId = 'df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6'
const r = await fetch(`https://platform.acedata.cloud/api/v1/credentials/${credId}`, {
  method: 'DELETE',
  headers: { authorization: `Bearer ${process.env.PLATFORM_TOKEN}` },
})
console.log('status:', r.status) // 204
```

## Risposta

- **Successo**: `HTTP 204 No Content`, **nessun corpo della risposta**.
- **Errore**: restituisce JSON di errore, vedere la tabella seguente.

## Gestione degli errori

| HTTP | code                | Significato         |
| ---- | ------------------- | ---------- |
| 401  | `not_authenticated` | Token dell'account mancante     |
| 403  | `permission_denied` | Questa credenziale non ti appartiene    |
| 404  | `not_found`         | La credenziale non esiste o è già stata eliminata |

## Suggerimenti pratici

- **L'eliminazione è irreversibile**—la piattaforma non conserva copie del Token. Se sospetti solo una fuga di dati ma vuoi mantenere i dati di monitoraggio, dovresti utilizzare [Ruotare le credenziali API della piattaforma AceDataCloud](https://platform.acedata.cloud/documents/platform-credential-rotate) anziché eliminarle.
- **L'eliminazione non restituisce la quota già consumata dalla credenziale**. Il saldo dell'Application viene detratto in tempo reale in base al consumo; l'eliminazione della credenziale non influisce sul saldo contabile.
- Dopo l'eliminazione, puoi riconfermare le credenziali rimanenti tramite l'[elenco delle credenziali API](https://platform.acedata.cloud/documents/platform-credential-list) in base a `application_id`.
- **Verifica prima i chiamanti prima della pulizia in batch**: l'elenco attualmente non dispone di un campo relativo all'ultimo utilizzo; dovresti verificare, in combinazione con la configurazione di distribuzione e i record delle chiamate, che la credenziale non sia più utilizzata, quindi eliminarle una alla volta.
