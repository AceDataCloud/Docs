---
title: "Creare un ordine di ricarica sulla piattaforma AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Crea un ordine in attesa di pagamento per una o più Application. La creazione scriverà l'ordine, ma non completerà automaticamente il pagamento; prima del pagamento è necessario verificare `price`, il pacchetto e l'Application nella risposta.

## Preparazione

- Crea un [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Ottieni `application_id` dall'[elenco delle Application](https://platform.acedata.cloud/documents/platform-application-list).
- Seleziona dai `packages` dei [dettagli del servizio](https://platform.acedata.cloud/documents/platform-service-detail) un `package_id` che corrisponda al tipo di Application e che sia acquistabile.

```shell
export PLATFORM_TOKEN='il tuo token dell'account'
export APPLICATION_ID='il tuo ID Application'
export PACKAGE_ID='il tuo ID Package'
```

## Panoramica dell'interfaccia

| Voce    | Contenuto                                       |
| ---- | ----------------------------------------------- |
| Metodo   | `POST`                                          |
| URL  | `https://platform.acedata.cloud/api/v1/orders/` |
| Autenticazione   | Account Token, il token OAuth richiede `orders:write`      |
| Body | JSON                                            |

## Corpo della richiesta

Un ordine per una singola Application utilizza `application_id` + `package_id`; un ordine in batch utilizza `application_ids` + `package_ids` di lunghezza corrispondente. Gli ordini normali scelgono il metodo di pagamento nella successiva richiesta `/pay/`. Gli ordini di acquisto in-app iOS passano `pay_way: "AppleIAP"` al momento della creazione e possono selezionare solo un pacchetto Usage con `metadata.apple_product_id` e `metadata.apple_price`. Gli acquisti in-app Apple utilizzano prezzi preimpostati indipendenti in dollari statunitensi e non applicano cumulativamente sconti per membri, sconti sul metodo di pagamento o sovrapprezzi del sito; l'importo addebitato nella valuta locale in altre regioni è soggetto alla pagina di conferma del pagamento Apple.

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/orders/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d "{\"application_id\":\"${APPLICATION_ID}\",\"package_id\":\"${PACKAGE_ID}\"}"
```

## Descrizione della risposta

In caso di successo restituisce `201` e il nuovo oggetto Order. I campi chiave includono `id`, `price`, `discount`, `state`, `application_id/application_ids`, `package_id/package_ids`, `expired_at` e i campi temporali. I nuovi ordini sono generalmente `Pending`, quindi chiama [Paga ordine](https://platform.acedata.cloud/documents/platform-order-pay).

- `price` è l'importo pagabile calcolato dal server in base al pacchetto, al sovrapprezzo del sito e agli sconti; non deve essere calcolato autonomamente dal client.
- Se il Package non corrisponde al servizio o al tipo dell'Application, viene restituito `400`.
- I Package gratuiti e gestiti dal sistema non possono essere riscattati autonomamente tramite l'interfaccia pubblica degli ordini.
- La creazione di un ordine per un'Application che non appartiene all'account corrente verrà rifiutata.
