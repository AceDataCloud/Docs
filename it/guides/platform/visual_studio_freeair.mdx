FreeAIr è un'estensione open source per Visual Studio 2022/2026, che secondo l'annuncio ufficiale può connettersi a qualsiasi API compatibile con OpenAI. Il comportamento delle richieste può variare tra le diverse versioni dell'estensione; per la prima integrazione, si prega di fissare la versione e completare la seguente verifica minima.

## Configurazione

1. Installa FreeAIr dal Visual Studio Marketplace o dal repository ufficiale.
2. Apri le impostazioni di FreeAIr e aggiungi una connessione compatibile con OpenAI.
3. Compila l'Endpoint con `https://api.acedata.cloud/v1`.
4. Compila il Token con il tuo Ace Data Cloud API Token.
5. Compila il Model con l'ID del modello esatto che supporta le Chat Completions nella directory dei modelli.
6. Dopo aver salvato, invia `Reply only OK`, quindi testa nuovamente una richiesta con il contesto del progetto.

## Attuali limiti

- Questa guida copre solo FreeAIr e non rappresenta il supporto per URL Base arbitrari da parte del Copilot integrato in Visual Studio.
- Le versioni dell'estensione possono modificare il modo in cui viene concatenato l'endpoint; durante la verifica, è necessario controllare l'URL finale della richiesta.
- Le capacità di chiamata degli strumenti e di MCP all'interno dell'estensione devono essere verificate separatamente e non possono essere sostituite dal successo di una normale chat.
