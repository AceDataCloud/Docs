Restituisce il catalogo pubblico dei modelli della piattaforma, con una risposta che adotta la struttura in stile OpenAI `{ "object": "list", "data": [...] }`. Questo catalogo viene utilizzato per la selezione dei modelli e la scoperta delle capacità, e non rappresenta necessariamente i servizi corrispondenti già richiesti dall'account corrente.

## Panoramica dell'interfaccia

| Voce   | Contenuto                                              |
| --- | ----------------------------------------------- |
| Metodo  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| Autenticazione  | Pubblica, non richiede un token dell'account                                       |
| Paginazione  | Nessuna paginazione, tutti gli elementi corrispondenti si trovano in `data`                              |

## Parametri di query

| Parametro             | Tipo      | Obbligatorio  | Descrizione                                      |
| -------------- | ------- | --- | --------------------------------------- |
| `owned_by`     | string  | No   | Filtra esattamente in base all'identificatore del fornitore del modello nel catalogo                        |
| `type`         | string  | No   | Filtra esattamente in base al tipo di modello, ad esempio `chat`                     |
| `capability`   | string  | No   | Restituisce solo i modelli in cui `capabilities` include questa capacità, ad esempio `vision` |
| `with_pricing` | boolean | No   | Aggiunge informazioni sui prezzi pubblici quando è `1`, `true` o `yes`            |

`service_id`, `tag`, `limit`, `offset` e `ordering` non sono attualmente supportati; il loro passaggio non produrrà il corrispondente effetto di filtro o paginazione.

## Esempi di richiesta

```shell
# Tutti i modelli pubblici
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# Modelli chat che supportano la visione, con prezzi inclusi
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## Struttura della risposta effettiva

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

`pricing` e `credit_usd_rate` al livello superiore compaiono solo quando `with_pricing=true`; non tutti i modelli dispongono di un `pricing` calcolabile. Gli oggetti modello fanno riferimento ai campi pubblici di `config/models.json`; i client devono ignorare i nuovi campi.

> I campi relativi ai prezzi sono dati di visualizzazione del catalogo. Le effettive chiamate aziendali restano soggette alle regole di fatturazione dell'API/Service corrispondente e ai registri di utilizzo finali.
