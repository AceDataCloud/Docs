Maestro è un'interfaccia di produzione video **nativa per Agent**: descrivi il video desiderato con un `prompt` in linguaggio naturale (facoltativamente allegando immagini / video / audio di riferimento tramite `file_urls`), e un "regista AI" senza interfaccia completerà automaticamente la scelta dell'argomento, la scrittura della sceneggiatura, la generazione delle immagini, il doppiaggio, la musica di sottofondo, il compositing e il rendering, producendo infine un video completo con sottotitoli e caricandolo sulla CDN.

Questo articolo introdurrà nel dettaglio la guida all'integrazione dell'API di generazione video Maestro, aiutandovi a integrarla rapidamente e a sfruttarne appieno le funzionalità.

Questa è un'interfaccia di **attività asincrona**: dopo l'invio, restituirà immediatamente `task_id`; successivamente, utilizza la [API di query delle attività Maestro](/it/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) per effettuare il polling e ottenere il risultato (il polling è gratuito e non viene addebitato). Per continuare a iterare su un video esistente, puoi utilizzare `action: remix` / `edit` / `extend` insieme a `ref_task_id`.

## Processo di richiesta

Per utilizzare l'API di generazione video Maestro, ottieni innanzitutto il tuo API Token dalla [console Ace Data Cloud](https://platform.acedata.cloud/console/applications) e conservalo come riserva.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se non hai ancora effettuato l'accesso o non ti sei registrato, verrai automaticamente reindirizzato alla pagina di accesso per registrarti e accedere; al termine tornerai automaticamente alla pagina corrente.

**Un solo API Token può chiamare tutti i servizi della piattaforma, senza bisogno di richiederne uno separatamente per ogni servizio.** La prima richiesta include crediti gratuiti, consentendo una prova gratuita; quando i crediti non sono sufficienti, puoi ricaricare il saldo universale nella [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentazione completa: [API di generazione video Maestro →](https://platform.acedata.cloud/documents/maestro-videos)

## Utilizzo di base

`POST https://api.acedata.cloud/maestro/videos`

Per l'utilizzo più semplice, basta passare una descrizione in linguaggio naturale a `prompt`: il regista AI deciderà automaticamente sceneggiatura, immagini, doppiaggio e montaggio. Vediamo innanzitutto le intestazioni e il corpo della richiesta da impostare.

**Intestazioni della richiesta** includono:

- `accept`: il formato in cui si desidera ricevere la risposta; inserire qui `application/json`, ovvero il formato JSON.
- `authorization`: la chiave per chiamare l'API, selezionabile direttamente dal menu a discesa dopo averla richiesta.
- `content-type`: il formato del corpo della richiesta; inserire qui `application/json`.

**Corpo della richiesta** include principalmente:

- `prompt`: descrizione in linguaggio naturale del video da realizzare (tema, cosa mostrare, stile e pubblico).
- `langs`: array delle lingue del video finale; trasmettere una sola lingua alla volta, ad esempio `["zh-cn"]`. Il valore predefinito è `["zh-cn"]`.
- `aspect`: proporzioni dell'immagine, `9:16` (predefinito) / `16:9` / `1:1`.
- `duration`: durata desiderata (secondi); il valore predefinito è 30.

Tutti i campi del corpo della richiesta sono mostrati nella tabella seguente:

| Campo | Tipo | Obbligatorio | Descrizione |
|---|---|---|---|
| `prompt` | string | Sì | Descrivi in linguaggio naturale il video da realizzare (tema, cosa mostrare, stile e pubblico). La sceneggiatura, le immagini, il doppiaggio e il montaggio sono tutti decisi dall'AI. |
| `action` | string | No | `generate` (predefinito, genera un nuovo video) / `remix` / `edit` / `extend` (itera su un video esistente; richiede `ref_task_id`) |
| `ref_task_id` | string | No | Obbligatorio quando `action` è remix / edit / extend: `task_id` dell'attività precedente da usare come punto di partenza. |
| `file_urls` | string[] | No | Media di riferimento (URL di immagini / video / audio), ad esempio immagini del prodotto o logo da mostrare, oppure clip di materiale a cui aggiungere sottotitoli. |
| `langs` | string[] | No | Lingua del video finale: è possibile specificarne solo una alla volta, ad esempio `["zh-cn"]`; il valore predefinito è `["zh-cn"]` |
| `aspect` | string | No | `9:16` (predefinito) / `16:9` / `1:1`; output uniforme a 1080p/30 fps |
| `duration` | int | No | Durata desiderata (secondi), predefinita 30, supporta **5–300 secondi**. La fatturazione avviene in base alla durata effettiva del video finale, senza superare la durata richiesta |
| `scenario` | string | No | Tipo di video: `auto` / `narrated` / `captions` / `avatar` / `drama`. Per `captions` è necessario fornire un video sorgente, mentre per `avatar` è necessario fornire un ritratto |
| `style` | string | No | Preimpostazione dello stile visivo: `auto` (predefinito) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`; accetta anche testo libero come suggerimento soft. Può essere impostata indipendentemente da `scenario` |
| `voice` | string | No | Voce della narrazione (indipendente dalla lingua e utilizzabile tra lingue diverse): `auto` (predefinito) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`; supporta anche un reference_id della voce esadecimale a 32 bit. Altro testo libero non costituisce un ID voce valido |

Di seguito viene illustrato un esempio concreto. Supponiamo di voler generare un breve video divulgativo in cinese, verticale e della durata di 20 secondi. Il codice CURL corrispondente è il seguente:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

Il codice Python corrispondente è il seguente:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Facendo clic su Esegui, è possibile notare che si ottiene immediatamente un risultato, come segue:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Di seguito è riportata la descrizione dei campi del risultato restituito:

- `success`: indica se questa attività è stata inviata correttamente.
- `task_id`: ID di questa attività di generazione video; utilizzalo successivamente per interrogare periodicamente il risultato tramite l'[API di query delle attività Maestro](/it/guides/maestro/maestro_tasks).
- `trace_id`: ID di tracciamento di questa richiesta; in caso di problemi, può essere fornito al supporto tecnico per facilitarne l'identificazione.

Poiché la produzione del video richiede molto tempo, l'interfaccia restituisce **immediatamente `task_id`** e non attende il completamento del rendering del video. Successivamente, è necessario usare `task_id` per effettuare il polling del risultato; per i dettagli, vedere la sezione «Ottenere il risultato».

## Specificare il tipo e lo stile del video (scenario / style)

Quando `scenario` non viene passato, viene determinato automaticamente dall'AI (equivale a `auto`); se si desidera fissare il video a un determinato tipo, passarlo esplicitamente. Ad esempio, per creare un **cortometraggio verticale**, è possibile specificare quanto segue:

- `scenario`: tipo di video, qui impostato su `drama` (cortometraggio con personaggi + dialoghi).
- `style`: stile visivo, qui impostato su `cinematic` (qualità cinematografica).

Il codice CURL dell'esempio di compilazione è il seguente:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Modalità di abbinamento comuni:

- Cortometraggio narrato: `scenario: "narrated"`.
- Sottotitoli automatici: `scenario: "captions"`, è necessario usare `file_urls` per passare il video sorgente.
- Avatar digitale / presentazione parlata: `scenario: "avatar"`, è necessario usare `file_urls` per passare un'immagine ritratto.
- Cortometraggio: `scenario: "drama"` (personaggi + dialoghi).
- `style` è una preimpostazione dello stile visivo (come `modern` / `neon` / `luxury`), non modifica il tipo e influenza solo l'aspetto.
- `voice` viene utilizzato per specificare il timbro della voce narrante (come `warm-female` / `deep-male`), non è legato alla lingua ed è universale tra le lingue.

Il risultato restituito è coerente con «Utilizzo di base», e restituisce immediatamente anch'esso `task_id`.

## Lingua del video finale

Un'attività consegna solo un video finale in una sola lingua. `langs` può contenere solo un codice lingua, come `["zh-cn"]` o `["en"]`; il passaggio di più lingue restituirà 400. Se sono necessari video in lingue diverse, creare attività separate. La selezione della lingua non modifica il prezzo al secondo.

## Iterare su un video esistente (remix / edit / extend)

Passando `action` e il `ref_task_id` dell'attività precedente, è possibile apportare modifiche incrementali sulla base del progetto originale (come «modificare il titolo della scena 2», «cambiare il doppiaggio», «scurire l'insieme»). Le piccole modifiche sono rapide, mentre le grandi modifiche verranno rifatte:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: reinterpretare sulla struttura del video originale (mantenere il tema, modificare la presentazione).
- `edit`: rifinire una parte specificata (come cambiare il titolo, il doppiaggio o la gradazione colore).
- `extend`: estendere il contenuto sulla base del video originale.

Il risultato restituito restituisce immediatamente anch'esso un nuovo `task_id`, che può essere usato per l'interrogazione per ottenere il video finale dopo l'iterazione.

## Ottenere i risultati

Poiché la produzione video richiede molto tempo, questa interfaccia restituisce immediatamente `task_id` dopo l'invio; è necessario usarlo per interrogare i risultati tramite l'[API di query delle attività Maestro](/it/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Al completamento dell'attività verranno restituite le informazioni di un video finale (nell'array `variants`). `status` passerà attraverso `pending → planning → producing → succeeded` (oppure `failed`), **l'interrogazione è gratuita e non consuma crediti**. Per il formato di risposta completo e la query dell'elenco cronologico, fare riferimento alle [istruzioni di integrazione dell'API di query delle attività Maestro](/it/guides/maestro/maestro_tasks).

## Fatturazione

**Dopo il successo dell'attività, la fatturazione avviene in base alla durata effettiva del video finale consegnato; in caso di errore non viene addebitato alcun costo.** La durata fatturabile viene calcolata in secondi interi e non supera la durata richiesta; quando non è possibile leggere la durata del video finale, viene usata come fallback la durata richiesta. L'invio dell'attività stesso non viene fatturato separatamente, l'interrogazione di `/maestro/tasks` è gratuita.

```
Crediti = secondi effettivamente fatturabili × 0.7
```

Tutti gli scenari, le azioni e le lingue adottano lo stesso prezzo, senza moltiplicatori per scenario o supplementi per lingua. Ogni attività consegna solo un video finale in una sola lingua. La durata obiettivo richiesta supporta 5–300 secondi, con output uniforme a 1080p / 30fps.

| Durata effettivamente fatturabile | Crediti |
| ------------------- | --: |
| 30 secondi          |  21 |
| 60 secondi          |  42 |
| 120 secondi         |  84 |
| 300 secondi         | 210 |
| Interrogazione `/maestro/tasks` | gratuito |

## Gestione degli errori

Quando si chiama l'API, se si verifica un errore, l'API restituirà il codice e il messaggio di errore corrispondenti. Ad esempio:

- `400 invalid_request`: Richiesta non valida, probabilmente a causa di un `prompt` mancante o di parametri non validi.
- `401 invalid_token`: Non autorizzato, token di autorizzazione non valido o mancante.
- `403 forbidden`: Vietato, saldo o accesso insufficiente.
- `429 too_many_requests`: Troppe richieste, è stato superato il limite di frequenza.
- `500 api_error`: Errore interno del server, qualcosa è andato storto sul server.

### Esempio di risposta di errore

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
