---
title: "Elaborazione dei modelli Tripo"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Usa `POST /tripo/models` per elaborare un modello esistente, passando l'`action` desiderata. Le modalità sincrona e asincrona, i callback, l'appartenenza all'account e la consultazione delle attività sono uguali a quelli della generazione 3D.

| action  | Input                                                                | Risultato                                                                   |
| ------- | ----------------------------------------------------------------- | -------------------------------------------------------------------- |
| import  | `model_url`, file GLB, GLTF, FBX, OBJ o STL accessibile pubblicamente tramite HTTPS, massimo 150 MiB | ID del modello e GLB utilizzabili per riferimenti successivi; restituisce `normalize_scale` e `normalize_translation` quando i dati sono disponibili |
| texture | `model_id` o `model_url`; facoltativamente, uno tra `prompt`, `image_url` e `image_urls` | Nuovo modello, texture e anteprima facoltativa |
| convert | `model_id` o `model_url` e `format` di destinazione | File del modello convertito |

```json
{"action":"texture","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","prompt":"蓝色哑光表面","texture_quality":"standard","async":true}
```

La qualità delle texture supporta `fast`, `standard`, `detailed` ed `extreme`. Quando si usa un prompt testuale, è possibile aggiungere `style_image_url`; i riferimenti tramite immagini e viste multiple seguono il formato dell'interfaccia di generazione. Per altri parametri delle texture, consulta OpenAPI.

La conversione supporta `GLTF`, `FBX`, `USDZ`, `OBJ`, `STL` e `3MF`. Il campo `format` dell'elemento restituito indica il formato effettivamente fornito; ad esempio, una richiesta GLTF può essere soddisfatta con un file GLB binario. Per OBJ, i materiali e le mappe sono racchiusi in un file ZIP. Quando si richiede FBX, imposta `texture_packaging: "zip"` per ottenere mappe separate; il risultato confezionato riporta `container: "ZIP"`. L'attivazione di impostazioni non predefinite per la mesh o le texture potrebbe essere addebitata come conversione avanzata; per i dettagli, consulta i prezzi del servizio.

Usa `data[0].id` per fare riferimento a un modello di questo account; la trasformazione di normalizzazione del modello importato soddisfa `normalized = original × normalize_scale + normalize_translation`. L'indirizzo di download del modello si trova in `data[0].model_url`.
