Questo documento presenterà le istruzioni per l'integrazione dell'API Veo Upsample. Questa interfaccia è utilizzata per l'upscaling di un video Veo già generato o per l'output di un'anteprima GIF.

## Processo di richiesta

Per utilizzare l'API, è necessario prima richiederla nella pagina corrispondente ai servizi Veo. Se non sei ancora loggato o registrato, verrai reindirizzato automaticamente alla pagina di accesso.

## Utilizzo di base

Per chiamare questa interfaccia è necessario fornire due parametri:

- `video_id`: ID del task del video sorgente. Può essere un ID video generato da qualsiasi interfaccia tra `/veo/videos`, `/veo/extend`, `/veo/reshoot`, `/veo/objects`.
- `action`: azione di upscaling, supporta le seguenti tre opzioni:
  - `1080p`: esegue l'upscaling del video a risoluzione 1080p.
  - `4k`: esegue l'upscaling del video a risoluzione 4K.
  - `gif`: converte il video in un'anteprima GIF.

Esempio di richiesta:

```shell
curl -X POST 'https://api.acedata.cloud/veo/upsample' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "4k"
  }'
```

Il risultato restituito è lo stesso di `/veo/videos`, ed è ancora una struttura di task asincrona, che può essere consultata tramite `task_id` nell'interfaccia `/veo/tasks` per verificare lo stato del task:

```json
{
  "success": true,
  "task_id": "8f5a90ae-3f86-4c4f-86f7-7126f5e92c76",
  "trace_id": "0f3e09c2-4c2e-46ea-9cdc-a31ec48b7c12",
  "data": [
    {
      "id": "253eedc47f1c4eb2a370ed2312168f4b",
      "video_url": "https://platform.cdn.acedata.cloud/veo/8f5a90ae.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

Descrizione dei campi restituiti:

- `success`: indica se il task di upscaling è stato inviato con successo.
- `task_id`: ID del task di upscaling attuale.
- `data`: risultati del video dopo l'upscaling.
  - `video_url`: indirizzo del video dopo l'upscaling.

## Informazioni di fatturazione

- `action=1080p`: 0.16 Credito / volta
- `action=4k`: 0.50 Credito / volta
- `action=gif`: 0.13 Credito / volta

Se l'`action` fornita non è tra quelle elencate, verrà addebitata per default come 0.50 Credito. Si consiglia di fornire esplicitamente i valori supportati.

## Callback asincrona

L'interfaccia supporta anche la modalità asincrona, basta fornire `callback_url` per ricevere il risultato tramite una richiesta POST al termine del task. Se non è disponibile un indirizzo di callback pubblico, è possibile impostare `async` su `true`, l'interfaccia restituirà immediatamente `task_id`, e successivamente sarà possibile ottenere i risultati tramite l'interfaccia di query del task corrispondente.
