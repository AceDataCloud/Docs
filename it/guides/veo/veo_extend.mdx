Questo documento presenterà le istruzioni per l'integrazione dell'API Veo Extend. Questa interfaccia è utilizzata per **estendere la durata** di un video Veo già generato, l'AI scriverà automaticamente le scene successive.

## Processo di richiesta

Per utilizzare l'API, è necessario prima richiederla nella pagina corrispondente ai servizi Veo. Se non sei ancora loggato o registrato, verrai reindirizzato automaticamente alla pagina di accesso.

## Utilizzo di base

Per chiamare questa interfaccia è necessario fornire i seguenti parametri:

- `video_id` (obbligatorio): ID del task del video sorgente (proveniente da `/veo/videos` o dalla stessa interfaccia).
- `model` (obbligatorio): modello utilizzato per l'estensione, **supporta solo i modelli `veo31-fast` e `veo31`**, altri modelli non sono supportati.
- `prompt` (facoltativo): suggerimento testuale per guidare le scene di estensione.
- `aspect_ratio` (facoltativo): `16:9` o `9:16`, predefinito `16:9`.
- `resolution` (facoltativo): `720p` o `1080p`.

Esempio di richiesta:

```shell
curl -X POST 'https://api.acedata.cloud/veo/extend' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "model": "veo31-fast",
    "prompt": "la telecamera si allontana lentamente per rivelare di più del paesaggio"
  }'
```

Il risultato di ritorno è lo stesso di `/veo/videos`:

```json
{
  "success": true,
  "task_id": "5fa2d9a6-7e54-481b-a4b0-3dc6f25dd2ab",
  "data": [
    {
      "id": "9b6f3b6b9c45419fbf2e3fe2f10b2b3a",
      "video_url": "https://platform.cdn.acedata.cloud/veo/5fa2d9a6.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

## Limitazioni importanti

`video_id` deve provenire da un video generato o esteso completato dalla linea TTAPI. Gli ID video storici generati da vecchie linee prima del passaggio a TTAPI non possono essere utilizzati con questa interfaccia, la chiamata restituirà `400 bad_request`; si prega di rigenerare tramite `/veo/videos` prima di estendere.

I video di estensione provenienti da `/veo/extend` possono **essere ulteriormente estesi tramite `/veo/extend`**, ma **non possono** essere elaborati dalle seguenti interfacce:

- `/veo/reshoot` —— non è possibile cambiare il movimento della telecamera
- `/veo/objects` —— non è possibile aggiungere o rimuovere oggetti

Se il `video_id` fornito è un risultato di estensione, le interfacce correlate restituiranno un errore 400, si prega di utilizzare il video originale come sorgente.

## Informazioni di fatturazione

- `model=veo31-fast`: 1.68 Credito / volta
- `model=veo31`: 12.00 Credito / volta

## Callback asincrono

L'interfaccia supporta la modalità asincrona, fornendo `callback_url` è possibile ricevere il risultato tramite una richiesta POST al termine del task. Se non è disponibile un indirizzo di callback pubblico, è possibile impostare `async` su `true`, l'interfaccia restituirà immediatamente `task_id`, quindi è possibile ottenere i risultati tramite l'interfaccia di query del task corrispondente.
