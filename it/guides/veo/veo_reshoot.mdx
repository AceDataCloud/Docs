Questo documento presenterà le istruzioni per l'integrazione dell'API Veo Reshoot. Questa interfaccia è utilizzata per **rigenerare** un video Veo già creato secondo **un nuovo modo di movimento della telecamera**, mantenendo il contenuto visivo invariato, ma la posizione e il movimento della telecamera saranno reinterpretati secondo `motion_type`.

## Processo di richiesta

Per utilizzare l'API, è necessario prima richiederla nella pagina corrispondente ai servizi Veo. Se non sei ancora loggato o registrato, verrai reindirizzato automaticamente alla pagina di accesso.

## Utilizzo di base

Per chiamare questa interfaccia è necessario fornire i seguenti parametri:

- `video_id` (obbligatorio): ID del task del video sorgente. **Non può** essere un video di output di `/veo/extend`.
- `motion_type` (obbligatorio): nuovo modo di movimento della telecamera, utilizzando un alias conciso in stile maiuscolo con underscore.

### Valori supportati per `motion_type`

| Alias                             | Significato           |
| ------------------------------ | ------------------- |
| `STATIONARY`                   | Telecamera fissa       |
| `STATIONARY_UP`                | Telecamera fissa, inclinata verso l'alto    |
| `STATIONARY_DOWN`              | Telecamera fissa, inclinata verso il basso    |
| `STATIONARY_LEFT`              | Telecamera fissa, inclinata a sinistra      |
| `STATIONARY_RIGHT`             | Telecamera fissa, inclinata a destra      |
| `STATIONARY_DOLLY_IN_ZOOM_OUT` | Telecamera fissa, spinta in avanti + zoom out |
| `STATIONARY_DOLLY_OUT_ZOOM_IN` | Telecamera fissa, spinta indietro + zoom in |
| `UP`                           | Telecamera in salita         |
| `DOWN`                         | Telecamera in discesa         |
| `LEFT_TO_RIGHT`                | Telecamera che si sposta da sinistra a destra     |
| `RIGHT_TO_LEFT`                | Telecamera che si sposta da destra a sinistra     |
| `FORWARD`                      | Telecamera che avanza       |
| `BACKWARD`                     | Telecamera che retrocede        |
| `DOLLY_IN_ZOOM_OUT`            | Movimento in avanti + zoom out   |
| `DOLLY_OUT_ZOOM_IN`            | Movimento indietro + zoom in   |

Esempio di richiesta:

```shell
curl -X POST 'https://api.acedata.cloud/veo/reshoot' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "motion_type": "LEFT_TO_RIGHT"
  }'
```

La struttura del risultato restituito è la stessa di `/veo/videos`.

## Informazioni di fatturazione

- Ripresa singola: 1.20 Credito.

## Callback asincrona

L'interfaccia supporta la modalità asincrona, passando `callback_url` è possibile ricevere il risultato tramite una richiesta POST al termine del task. Se non hai un indirizzo di callback pubblico, puoi impostare `async` su `true`, l'interfaccia restituirà immediatamente `task_id`, quindi puoi ottenere i risultati tramite l'interfaccia di query del task corrispondente.
