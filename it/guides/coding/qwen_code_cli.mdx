Qwen Code utilizza la configurazione `modelProviders` di `~/.qwen/settings.json` per personalizzare il Provider. Qui si utilizza un protocollo compatibile con OpenAI.

## Configurazione

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud` deve essere un array. Gli elementi del Provider sono configurazioni indipendenti e non erediteranno automaticamente altri parametri di contesto, Header o body di livello superiore.

## Verifica

```bash
export ACEDATACLOUD_API_KEY="INSERISCI_IL_TUO_TOKEN_API_ACEDATACLOUD_QUI"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Rispondi solo OK"
```

Dopo essere entrati, inviare `Rispondi solo OK`, quindi eseguire di nuovo lo strumento di lettura file. Se l'endpoint compatibile rifiuta il formato dei risultati dello strumento, controllare la versione attuale di Qwen Code e le istruzioni di compatibilità ufficiali.
