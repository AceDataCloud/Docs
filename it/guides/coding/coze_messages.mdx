La documentazione ufficiale del modello personalizzato Coze supporta l'API Anthropic Messages. Le diverse versioni dei tenant Coze possono gestire in modo diverso Header, concatenazione dei percorsi, streaming e chiamate agli strumenti; per il primo accesso, controlla ogni punto di seguito.

## Configurazione

1. Accedi alla gestione dei modelli Coze e aggiungi un modello personalizzato.
2. Seleziona Protocollo come Anthropic Messages API.
3. Compila l'URL Base API con `https://api.acedata.cloud`.
4. Compila la chiave API con il tuo token API di Ace Data Cloud.
5. Compila il modello con l'ID del modello esatto supportato da Anthropic Messages nella directory dei modelli.
6. Salva e completa il test di connessione di Coze.
7. Invia `Reply only OK` nel Bot/Agent, poi testa di nuovo la chiamata allo strumento.

## Attuali Limiti

- Diverse aree, versioni o pacchetti di Coze possono mostrare moduli diversi.
- L'URL Base API non deve avere `/v1/messages` aggiunto nuovamente; se l'attuale interfaccia utente richiede esplicitamente l'URL API completo, segui le indicazioni del modulo.
- Messages, Chat Completions e Responses sono tre percorsi indipendenti e non possono sostituirsi a vicenda per la verifica.
