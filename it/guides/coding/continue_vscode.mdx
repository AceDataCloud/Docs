Continue supporta l'API compatibile con OpenAI. Per utilizzare esclusivamente Chat Completions, è necessario impostare esplicitamente `useResponsesApi: false`.

## Configurazione

Aggiungere al file YAML locale di configurazione di Continue:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Salvare `ACEDATACLOUD_API_KEY` nella gestione dei segreti di Continue, non inviare il Token reale nella configurazione del progetto. La configurazione JSON di Continue è stata deprecata, la nuova configurazione utilizza YAML.

## Verifica

Ricaricare VS Code, aprire la barra laterale di Continue, selezionare il modello nella Configurazione Locale e inviare `Reply only OK`; eseguire nuovamente il compito di file in sola lettura. Se la richiesta viene erroneamente inviata a `/responses`, controllare se `useResponsesApi: false` è presente all'interno di quella voce del modello.
