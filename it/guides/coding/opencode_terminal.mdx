## 1. Ottenere la API Key

Apri l'[elenco delle applicazioni Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedi a un'applicazione disponibile e copia la API Key.

![Ottenere la API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installare OpenCode

```bash
curl -fsSL https://opencode.ai/install | bash
```

Puoi anche usare npm:

```bash
npm install -g opencode-ai
```

## 3. Impostare la API Key

```bash
export ACEDATACLOUD_API_KEY="la tua API Key"
```

Per renderla effettiva a lungo termine, aggiungi questa riga a `~/.zshrc` o `~/.bashrc`, quindi riapri il terminale.

## 4. Configurare il Provider

Modifica `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ace Data Cloud",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  }
}
```

Vai al [catalogo dei modelli](https://platform.acedata.cloud/models) per visualizzare i nomi dei modelli (ad esempio `claude-opus-5`, `gpt-6-sol`) e sostituisci tutti i `MODEL_ID` con lo stesso nome; per una verifica precisa, fai riferimento al valore `id` nella risposta di `/v1/models`. Questo valore è il nome del modello utilizzato dal parametro API `model`, non l'UUID del servizio o dell'API. Ace Data Cloud utilizza qui Chat Completions, quindi l'adapter è `@ai-sdk/openai-compatible`.

## 5. Verificare e avviare

```bash
opencode auth list
opencode models acedatacloud
opencode run --model acedatacloud/MODEL_ID "Reply only OK"
```

Quindi esegui `opencode` nella directory del progetto. Se il modello non appare, controlla il percorso del file di configurazione, la sintassi JSON e le variabili d'ambiente; 401 indica che la Key non è valida o non è stata esportata.

L'estensione IDE riutilizza la stessa configurazione runtime di OpenCode, vedi [OpenCode IDE Extension](https://platform.acedata.cloud/documents/opencode-ide-integration).
