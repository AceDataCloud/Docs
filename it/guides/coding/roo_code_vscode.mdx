## 1. Ottenere la API Key

Apri l'[elenco delle applicazioni Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedi a un'applicazione disponibile e copia la API Key.

![Ottenere la API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configurazione

Roo Code fornisce ufficialmente il Provider compatibile con OpenAI e richiede che il modello supporti OpenAI tools/function calling nativi.

1. Apri le impostazioni di Roo Code in VS Code.
2. Imposta **API Provider** su **OpenAI Compatible**.
3. Compila:

| Campo       | Valore                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | La API Key appena copiata                  |
| Model ID | L'ID del modello selezionato nella procedura guidata di configurazione Coding         |

![Interfaccia di configurazione OpenAI Compatible di Roo Code](https://cdn.acedata.cloud/b6a0e7156438.png)

Successivamente, imposta le opzioni context, max output, immagini e computer-use in base alle effettive capacità del modello. Infine salva la configurazione e ricarica VS Code.

## 3. Verifica

Invia prima `Reply only OK`, quindi chiedi a Roo Code di leggere un file di test. Se la chat normale riesce ma lo strumento Agent fallisce, sostituisci il modello con uno che supporti tool calling nativo e conferma che l'endpoint compatibile possa restituire correttamente in streaming i parametri e i risultati dello strumento.
