## 1. Ottenere la API Key

Apri l'[elenco delle applicazioni Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedi a un'applicazione disponibile e copia la API Key.

![Ottenere la API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installare Kimi Code

macOS / Linux:

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

Puoi anche installarlo tramite npm:

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. Configurare AceDataCloud

Modifica `~/.kimi/config.toml`, aggiungendo la seguente configurazione:

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "你的 API Key"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

Vai al [catalogo dei modelli](https://platform.acedata.cloud/models) per visualizzare i nomi dei modelli (ad esempio `claude-opus-5`, `gpt-6-sol`) e sostituisci tutti gli `MODEL_ID` con lo stesso nome; per una verifica precisa, fai riferimento al valore `id` nella risposta di `/v1/models`. Questo valore è il nome del modello utilizzato dal parametro API `model`, non l'UUID del servizio o dell'API. `type = "openai"` utilizza il protocollo OpenAI Chat Completions.

Il file di configurazione contiene la Key; su macOS / Linux è consigliato limitare i permessi:

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. Verificare e avviare

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

Dopo essere entrato nel progetto, esegui `kimi` per iniziare a utilizzarlo. Se restituisce 401, controlla la API Key; se viene visualizzato model not found, verifica che `default_model`, il nome nella tabella dei modelli e il campo `model` utilizzino lo stesso ID.
