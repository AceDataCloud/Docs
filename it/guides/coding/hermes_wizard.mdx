## 1. Ottenere la API Key

Apri l'[elenco delle applicazioni Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedi a un'applicazione disponibile e copia la API Key.

![Ottenere la API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Eseguire la procedura guidata

```bash
hermes model
```

Seleziona **Custom endpoint** e compila nell'ordine:

| Campo             | Valore                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | La API Key appena copiata                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | Vai al [catalogo dei modelli](https://platform.acedata.cloud/models) per verificarlo e inserisci esattamente il nome del modello di destinazione, ad esempio `claude-opus-5`, `gpt-6-sol` |
| Context length | Lascia vuoto per il rilevamento automatico oppure compila in base al catalogo dei modelli                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model` è il nome del modello utilizzato dal parametro `model` nelle richieste API, non l'UUID del servizio o dell'API. Puoi prima verificarlo nel [catalogo dei modelli](https://platform.acedata.cloud/models); se è necessaria una convalida precisa, usa quindi l'attuale API Key per richiedere `GET https://api.acedata.cloud/v1/models`, e copia il valore `id` del modello di destinazione dall'array `data` nella risposta.

La procedura guidata scriverà in `~/.hermes/config.yaml` e nel file delle credenziali locale.

## 3. Verifica

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

Se la procedura guidata non ha salvato la configurazione, puoi eseguire `hermes model --reset` e riprovare; 401 indica che la API Key non è valida oppure non viene letta dalla configurazione dell'utente corrente.
