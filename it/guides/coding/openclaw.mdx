## 1. Ottenere la API Key

Aprire [l'elenco delle applicazioni di Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedere alle applicazioni disponibili e copiare la API Key.

![Ottenere la API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installare OpenClaw e il plugin

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

Il plugin richiede OpenClaw `2026.4.2` o superiore, attualmente offre capacità native di Chat e Web Search.

## 3. Configurare la Key

Si consiglia di utilizzare l'onboarding:

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "la tua API Key"
```

È possibile anche utilizzare le variabili d'ambiente:

```bash
export ACEDATACLOUD_API_KEY="la tua API Key"
```

## 4. Opzionale: configurazione manuale

Se non si utilizza l'onboarding, abilitare il plugin e impostare il modello predefinito in `~/.openclaw/openclaw.json`:

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

Non scrivere la API Key in questo file; continuare a utilizzare le variabili d'ambiente.

## 5. Scegliere il modello e verificare

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "Rispondi solo OK"
```

Sostituire `MODEL_ID` con il modello attualmente fornito da Coding Plan. Se necessario impostarlo come modello predefinito, eseguire:

```bash
openclaw models set acedatacloud/MODEL_ID
```

I registri delle chiamate possono essere visualizzati in [Cronologia utilizzo](https://platform.acedata.cloud/console/usages). 401 indica che la Key non è valida; se il modello non esiste, controllare prima l'ID esatto e la versione del plugin. `cost: 0` nella directory del plugin indica solo che non è stata stimata nuovamente da OpenClaw, i costi effettivi sono comunque registrati da Ace Data Cloud.

## Ricerca Web

```bash
openclaw infer web search \
  --provider acedatacloud --query "ultimi framework di agenti AI" --limit 5
```

Attualmente non considerare le capacità di immagini, video o musica menzionate nell'introduzione al plugin come capacità native del Provider OpenClaw.
