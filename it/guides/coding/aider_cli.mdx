Aider si connette all'API compatibile con OpenAI tramite il prefisso del modello `openai/` di LiteLLM.

## Configurazione

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

Sostituisci `MODEL_ID` con il modello selezionato nella guida alla configurazione di Coding. Puoi anche scrivere le opzioni corrispondenti nel tuo file locale `.env` o `.aider.conf.yml`, ma non inviare Token reali.

## Verifica

```bash
aider --model openai/MODEL_ID --message "Rispondi solo OK"
```

Al primo utilizzo di un modello sconosciuto, Aider potrebbe segnalare la mancanza di metadati del modello; questo non equivale a un fallimento di autenticazione. Controlla il Token per il codice 401, controlla l'ID del modello e l'URL di base `/v1` per il codice 404.
