## 1. Ottenere la API Key

Aprire [l'elenco delle applicazioni di Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedere alle applicazioni disponibili e copiare la API Key.

![Ottenere la API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configurazione

Kilo CLI legge `kilo.jsonc` e ottiene la API Key dalla shell da cui viene avviato il CLI.

Scrivere in `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Poi esportare il Token nella shell corrente:

```bash
export ACEDATACLOUD_API_KEY="INSERISCI_IL_TUO_TOKEN_ACEDATACLOUD_QUI"
```

## 3. Verifica

```bash
kilo run -m acedatacloud/MODEL_ID "Rispondi solo OK"
```

Se il CLI non riesce a leggere il Token, assicurarsi che la variabile sia stata `export` e non solo scritta in un file `.env` non caricato.
