## 1. Ottenere la API Key

Aprire l' [elenco delle applicazioni di Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedere alle applicazioni disponibili e copiare la API Key.

![Ottenere la API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configurare il Provider

Il plugin JetBrains di Kilo Code utilizza il formato Provider `kilo.jsonc`. La configurazione deve trovarsi nell'ambiente utente in cui il plugin viene eseguito; durante lo Sviluppo Remoto, di solito è l'host backend remoto.

Scrivere in `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Esportare `ACEDATACLOUD_API_KEY` nell'ambiente in cui si avvia il backend di JetBrains, quindi riavviare l'IDE o il backend remoto.

## 3. Verifica

Selezionare `acedatacloud/MODEL_ID`, inviare `Reply only OK`, quindi far leggere un file di test all'Agent. Se funziona localmente ma fallisce in remoto, controllare prima se il file di configurazione e le variabili d'ambiente sono scritte sull'host remoto.
