## 1. Ottenere la API Key

Apri l'[elenco delle applicazioni Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedi a un'applicazione disponibile e copia la API Key.

![Ottenere la API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Salvare la Key

Scrivi in `~/.hermes/.env`:

```dotenv
ACEDATACLOUD_API_KEY=la tua API Key
```

## 3. Configurare il Provider

Aggiungi in `~/.hermes/config.yaml`:

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

Vai al [catalogo dei modelli](https://platform.acedata.cloud/models) per visualizzare i nomi dei modelli (ad esempio `claude-opus-5`, `gpt-6-sol`) e sostituisci tutti i `MODEL_ID` con lo stesso nome; per una verifica precisa, fai riferimento al valore `id` nella risposta di `/v1/models`. Questo valore è il nome del modello utilizzato dal parametro API `model`, non l'UUID del servizio o dell'API. Non scrivere la Key reale nel YAML né inviare `.env`.

## 4. Verifica

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

Se viene restituito 401, controlla `~/.hermes/.env`; se la configurazione non ha effetto, esci completamente e riavvia Hermes.
