La documentazione ufficiale del modello personalizzato Coze supporta l'API Chat di OpenAI. Le diverse versioni dei tenant Coze possono gestire in modo diverso la concatenazione dei percorsi, l'output in streaming e le chiamate agli strumenti; per la prima integrazione, controlla ogni punto di seguito.

## Configurazione

1. Accedi alla gestione dei modelli Coze e aggiungi un modello personalizzato.
2. Seleziona Protocollo OpenAI Chat API.
3. Compila l'URL API di base con `https://api.acedata.cloud/v1`.
4. Compila la chiave API con il tuo token API di Ace Data Cloud.
5. Compila il modello con l'ID del modello esatto supportato nelle Chat Completions.
6. Salva e completa il test di connessione di Coze.
7. Invia `Reply only OK` nel Bot/Agente, poi testa di nuovo la chiamata allo strumento.

## Attuali Limiti

- Diverse aree, versioni o pacchetti Coze possono mostrare moduli diversi.
- L'URL API di base deve utilizzare base, non aggiungere nuovamente `/chat/completions`; se l'attuale interfaccia utente richiede esplicitamente l'URL API completo, segui le indicazioni del modulo.
- Chat Completions, Responses e Anthropic Messages sono tre percorsi indipendenti e non possono sostituirsi a vicenda per la verifica.
