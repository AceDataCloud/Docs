## 1. Ottenere l'API Key

Apri l'[elenco delle applicazioni Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedi a un'applicazione disponibile e copia l'API Key.

![Ottenere l'API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configurare Cline

Installa e apri Cline in VS Code, quindi accedi alla configurazione del Provider tramite il pulsante delle impostazioni nel pannello Cline e compila:

| Campo                                | Valore                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| API Provider                      | `OpenAI Compatible`                                                                            |
| Base URL                          | `https://api.acedata.cloud/v1`                                                                 |
| API Key                           | L'API Key appena copiata                                                                                  |
| Model ID                          | Vai al [catalogo dei modelli](https://platform.acedata.cloud/models) per visualizzare e inserire esattamente il nome del modello di destinazione, ad esempio `claude-opus-5`、`gpt-6-sol` |
| Custom Headers                    | Lascia vuoto                                                                                             |
| Set Azure API version             | Lascia vuoto                                                                                             |
| Use Azure Identity Authentication | Disattiva                                                                                             |

![Interfaccia di configurazione Cline OpenAI Compatible](https://cdn.acedata.cloud/8f356c2f1378.png)

`Model ID` è il nome del modello utilizzato dal parametro `model` nella richiesta API, non è l'UUID del servizio o dell'API, né può essere abbreviato autonomamente. Puoi prima verificarlo nel [catalogo dei modelli](https://platform.acedata.cloud/models); se è necessaria una convalida precisa, usa l'API Key corrente per richiedere `GET https://api.acedata.cloud/v1/models` e copia il valore `id` del modello di destinazione dall'array `data` della risposta.

Mantieni inizialmente predefinite le altre configurazioni delle capacità del modello; quando sono necessarie immagini o un contesto più ampio, regolale in base alle capacità effettive del modello selezionato.

## 3. Verifica

Dopo il salvataggio, crea una nuova attività e invia `Reply only OK`. Poi chiedi a Cline di leggere un file di test, per confermare che il modello supporti le chiamate agli strumenti; i record delle chiamate possono essere visualizzati nella [cronologia di utilizzo](https://platform.acedata.cloud/console/usages).

Un errore 401 indica generalmente una Key errata; un errore 404 indica generalmente che il Base URL non è corretto, oppure che il Model ID inserito non coincide completamente con l'`id` nel catalogo. Se il modello può conversare ma non può operare sui file, verifica la capacità di chiamata degli strumenti del modello.
