L'API HappyHorse Tasks è utilizzata per interrogare i compiti di generazione o modifica video creati dall'API HappyHorse Videos.

## Processo di richiesta

Per utilizzare l'API HappyHorse Videos, prima vai al [Pannello di controllo Ace Data Cloud](https://platform.acedata.cloud/console/applications) per ottenere il tuo API Token, da conservare per uso futuro.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se non hai ancora effettuato il login o la registrazione, verrai automaticamente reindirizzato alla pagina di login che ti invita a registrarti e accedere; una volta completato, verrai riportato automaticamente alla pagina corrente.

**Un API Token è sufficiente per accedere a tutti i servizi della piattaforma, senza dover richiedere separatamente per ogni servizio.** La prima richiesta ti darà un credito gratuito, per provare senza costi; quando il credito è insufficiente, puoi ricaricare il saldo generale nel [pannello di controllo](https://platform.acedata.cloud/console/coin).

> 📘 Documentazione completa: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Esempio di richiesta

L'API HappyHorse Tasks può essere utilizzata per interrogare i risultati dell'API HappyHorse Videos.

### Impostazione dell'intestazione della richiesta e del corpo della richiesta

**Request Headers** include:

- `accept`: specifica di ricevere la risposta in formato JSON, qui inserito come `application/json`.
- `authorization`: la chiave per chiamare l'API, che può essere selezionata direttamente dopo la richiesta.

**Request Body** include:

- `id`: l'ID del compito da interrogare.
- `action`: il modo di operare sul compito, per una singola interrogazione inserire `retrieve`.

### Esempio di codice CURL

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Esempio di risposta

Dopo una richiesta riuscita, l'API restituirà i dettagli di quel compito. Il campo `request` è il corpo della richiesta al momento della creazione del compito, il campo `response` è il corpo della risposta restituito al termine del compito, ad esempio:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262774.423,
  "elapsed": 52.6,
  "request": {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "Una ripresa cinematografica di un cavallo bianco che corre su una spiaggia illuminata dalla luna",
    "resolution": "720P",
    "duration": 5
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "1469cfc3-3004-4d9e-ab10-xxxxxx",
        "video_url": "https://cdn.acedata.cloud/happyhorse/c8cbf53aa0.mp4",
        "state": "succeeded",
        "duration": 5,
        "resolution": "720P",
        "ratio": "16:9"
      }
    ]
  }
}
```

La descrizione dei campi è la seguente:

- `id`: l'ID del compito di generazione, utilizzato per identificare univocamente questo compito di generazione.
- `request`: le informazioni della richiesta al momento della creazione del compito.
- `response`: le informazioni di ritorno attuali o finali del compito.
- `created_at`: data e ora di creazione del compito, timestamp Unix (secondi, float).
- `started_at`: data e ora di inizio esecuzione del compito, timestamp Unix (secondi, float).
- `finished_at`: data e ora di completamento del compito, timestamp Unix (secondi, float). Questo campo non viene restituito se il compito non è completato.
- `elapsed`: tempo impiegato per l'esecuzione del compito, in secondi (float, con 3 cifre decimali). Questo campo non viene restituito se il compito non è completato.

## Operazione di interrogazione in batch

Per interrogare i dettagli di più ID di compiti, impostare `action` su `retrieve_batch` e passare l'array degli ID dei compiti tramite `ids`:

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```

Il risultato restituito conterrà i campi `items` e `count`, dove `items` è l'array dei dettagli dei compiti e `count` è il numero di compiti corrispondenti trovati in questa richiesta.
