Servizio di vettori di parole OpenAI, utilizzato per generare risultati di vettori di parole che rappresentano il testo di input.

Questo documento presenta principalmente il processo di utilizzo delle operazioni dell'API OpenAI Embeddings, attraverso la quale possiamo creare vettori di embedding che rappresentano il testo di input。。

## Procedura di richiesta

Per utilizzare l'API OpenAI Embeddings, per prima cosa vai alla [console di Ace Data Cloud](https://platform.acedata.cloud/console/applications) per ottenere il tuo API Token, da conservare come riserva.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se non hai ancora effettuato l'accesso o la registrazione, verrai automaticamente reindirizzato alla pagina di accesso per invitarti a registrarti e ad accedere; al termine, tornerai automaticamente alla pagina corrente.

**Un solo API Token può richiamare tutti i servizi della piattaforma, senza la necessità di richiederne uno separatamente per ogni servizio.** Alla prima richiesta verrà fornito un credito gratuito, che può essere utilizzato per una prova gratuita; quando il credito è insufficiente, puoi ricaricare il saldo universale dalla [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentazione completa: [OpenAI Embeddings API →](https://platform.acedata.cloud/documents/openai-embeddings)

## Utilizzo di base

Successivamente puoi compilare i contenuti corrispondenti nell'interfaccia, come mostrato nell'immagine:

<p><img src="https://cdn.acedata.cloud/4qtbvr.png" width="500" className="m-auto" /></p>

Quando utilizzi questa interfaccia per la prima volta, dobbiamo compilare almeno tre contenuti: uno è `authorization`, che può essere selezionato direttamente nell'elenco a discesa. Un altro parametro è `model`, `model` è la categoria di modello del sito ufficiale OpenAI che scegliamo di utilizzare; i modelli attualmente disponibili sono `text-embedding-3-small` e `text-embedding-3-large`. `text-embedding-ada-002` non viene più fornito; se un indice vettoriale esistente utilizza questo vecchio modello, non può mescolare direttamente i vettori dei nuovi modelli e deve essere ricreato. L'ultimo parametro è `input`, `input` è il testo del vettore di parole che dobbiamo convertire.

Allo stesso tempo, puoi notare che sulla destra viene generato il codice di chiamata corrispondente; puoi copiare il codice ed eseguirlo direttamente, oppure fare clic direttamente sul pulsante «Try» per effettuare un test.

Parametri opzionali:

- `dimensions`: riduce le dimensioni del vettore, per impostazione predefinita restituisce le dimensioni complete.
- `encoding_format`: formato di restituzione, può essere `float` o `base64`.

<p><img src="https://cdn.acedata.cloud/gqulm9.png" width="500" className="m-auto" /></p>

Codice di chiamata di esempio Python:

```python
import requests

url = "https://api.acedata.cloud/openai/embeddings"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "The food was delicious and the waiter...",
    "model": "text-embedding-3-small",
    "encoding_format": "float"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Il risultato restituito contiene diversi campi, presentati di seguito:

- `model`, il modello utilizzato per questa conversione del testo in vettori di parole.

Tra questi, `data` contiene le informazioni specifiche relative ai vettori di parole corrispondenti al testo, e il suo `embedding` è il risultato specifico del vettore di parole generato.

## Gestione degli errori

Quando si richiama l'API, se si verifica un errore, l'API restituisce il codice e le informazioni di errore corrispondenti. Ad esempio:

- `400 token_mismatched`: Richiesta non valida, probabilmente a causa di parametri mancanti o non validi.
- `400 api_not_implemented`: Richiesta non valida, probabilmente a causa di parametri mancanti o non validi.
- `401 invalid_token`: Non autorizzato, token di autorizzazione non valido o mancante.
- `429 too_many_requests`: Troppe richieste, hai superato il limite di velocità.
- `500 api_error`: Errore interno del server, qualcosa è andato storto sul server.

### Esempio di risposta di errore

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
