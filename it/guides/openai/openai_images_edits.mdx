## 1. Ottenere l'API Key

Apri l'[elenco delle applicazioni Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedi a un'applicazione disponibile e copia l'API Key.

![Ottenere l'API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Modificare usando l'URL dell'immagine

Immagine originale:

![Immagine originale per la modifica GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

Risposta riuscita:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Questo è il risultato della modifica effettivamente completata tramite Ace Data Cloud l'8 settembre 2026: la tazza è diventata arancione, lo sfondo è diventato blu navy scuro, mantenendo la composizione originale e le dimensioni 1024×1536:

![Risultato della modifica della tazza arancione GPT Image 2](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Caricare immagini locali

Usa `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

Puoi passare ripetutamente `image`; la serie GPT Image supporta fino a 16 immagini di riferimento. `image` nelle richieste JSON può essere un singolo URL o un array di URL; i file locali vengono caricati tramite multipart.

## 4. Parametri comuni

| Campo                | Descrizione                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (più veloce) o `gpt-image-2.5-sunburst` (maggiore fedeltà e controllo); tutti e tre possono selezionare la corrispondente variante `:official`, mentre `gpt-image-2` supporta anche `:reverse` |
| `image`           | JSON usa un singolo URL o un array di fino a 16 URL; multipart usa uno o più campi file `image`                                                                    |
| `prompt`          | Istruzione di modifica                                                                                                                             |
| `size`            | `auto` o `WIDTHxHEIGHT` conforme alle limitazioni                                                                                                     |
| `n`               | 1–10; quando `response_format=b64_json`, è supportato solo 1                                                                                           |
| `response_format` | `url` o `b64_json`                                                                                                               |
| `callback_url`    | Indirizzo opzionale per callback asincrono                                                                                                                         |

Le regole sulle dimensioni sono coerenti con l'interfaccia di generazione: larghezza e altezza devono essere multipli di 16, il lato lungo non deve superare 3840, i pixel totali devono essere 655.360–8.294.400 e il rapporto larghezza-altezza non deve superare 3:1. Quando `size` viene omesso o si usa `auto`, il modello sceglie il formato combinando il prompt e la prima immagine di riferimento.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` e `gpt-image-2:reverse` vengono fatturati in base al numero di immagini riuscite; `gpt-image-2:official`, `gpt-image-2.5-flare:official` e `gpt-image-2.5-sunburst:official` vengono regolati in base ai Token effettivi dell'input testuale, dell'input delle immagini di riferimento e dell'output delle immagini; fa fede il registro di utilizzo finale.

## 5. Callback asincrono e risoluzione dei problemi

Per attività lunghe, puoi aggiungere alla richiesta:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

La risposta asincrona 200 è `{"task_id": "..."}`; al completamento verrà richiamato il risultato finale. Le richieste sincrone restituiscono invece `created` e `data`.

| Stato  | Controllo                      |
| --- | ----------------------- |
| 400 | Formato/numero delle immagini, combinazione dei parametri e formato delle dimensioni       |
| 401 | API Key e Bearer Header |
| 429 | Frequenza delle richieste                    |
| 504 | Passare al callback asincrono                  |

Le risposte di errore includono `trace_id`. Quando segnali un problema, fornisci questo ID e non fornire l'API Key.

Per i campi completi e le enumerazioni in tempo reale, fai riferimento alla pagina [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Per generare immagini da solo testo, consulta [Generazione immagini GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
