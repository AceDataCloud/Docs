## 1. Ottenere la chiave API

Aprire [l'elenco delle applicazioni di Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedere alle applicazioni disponibili e copiare la chiave API.

![Ottenere la chiave API di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Modificare utilizzando l'URL dell'immagine

Immagine originale:

![Immagine originale di GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer la tua chiave API" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Mantieni la tazza, il tavolo, l'angolo della fotocamera, il layout verticale e l'ombra morbida invariati. Cambia solo il colore della tazza da bianco a arancione vivace e lo sfondo crema pallido in un blu navy scuro solido. Nessun testo e nessun logo.",
    "size": "1024x1536"
  }'
```

Risposta di successo:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Questo è il risultato della modifica completata il 8 settembre 2026 tramite Ace Data Cloud, la tazza è diventata arancione, lo sfondo è diventato blu navy scuro e mantiene la composizione originale e le dimensioni di 1024×1536:

![Risultato della modifica della tazza arancione di GPT Image 2](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Caricare immagini locali

Utilizzare `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer la tua chiave API" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Sostituisci lo sfondo con uno studio moderno luminoso"
```

È possibile inviare più volte `image`, la serie GPT Image supporta fino a 16 immagini di riferimento. L'`image` nella richiesta JSON può essere un singolo URL o un array di URL; i file locali vengono caricati utilizzando multipart.

## 4. Parametri comuni

| Campo              | Descrizione                                                    |
| ----------------- | ----------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2:official` o `gpt-image-2:reverse` |
| `image`           | JSON utilizza un singolo URL o un array di massimo 16 URL; multipart utilizza uno o più campi file `image` |
| `prompt`          | Istruzioni di modifica                                        |
| `size`            | `auto` o `WIDTHxHEIGHT` conforme ai limiti                     |
| `n`               | 1–10; supporta solo 1 quando `response_format=b64_json`      |
| `response_format` | `url` o `b64_json`                                          |
| `callback_url`    | Indirizzo di callback asincrono opzionale                      |

Le regole delle dimensioni sono le stesse dell'interfaccia di generazione: larghezza e altezza devono essere multipli di 16, il lato lungo non deve superare 3840, e il numero totale di pixel non deve superare 8.294.400. Se si omette `size` o si utilizza `auto`, il modello sceglierà il formato in base al prompt e alla prima immagine di riferimento.

Il `gpt-image-2` predefinito e `:reverse` vengono addebitati in base al numero di successi; `gpt-image-2:official` viene calcolato in base ai token effettivi di input di testo, input di immagini e output di immagini, con la registrazione finale basata sull'uso.

## 5. Callback asincroni e risoluzione dei problemi

Per compiti lunghi, è possibile aggiungere alla richiesta:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

La risposta asincrona 200 è `{"task_id": "..."}`; dopo il completamento, verrà richiamato il risultato finale. Le richieste sincrone restituiscono `created` e `data`.

| Stato  | Controllo                  |
| --- | ----------------------- |
| 400 | Formato/numero dell'immagine, combinazione dei parametri e formato delle dimensioni |
| 401 | Chiave API e intestazione Bearer |
| 429 | Frequenza delle richieste        |
| 504 | Utilizzare il callback asincrono  |

Le risposte di errore conterranno `trace_id`. Quando si segnalano problemi, fornire questo ID, non fornire la chiave API.

I campi completi e l'elenco in tempo reale sono disponibili nella pagina [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Per la generazione di immagini in testo semplice, consultare [GPT Image 2 Generazione di immagini](https://platform.acedata.cloud/documents/openai-images-generations).
