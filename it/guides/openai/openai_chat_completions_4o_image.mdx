## Processo di Richiesta

Per utilizzare l'OpenAI Chat Completion 4o Image API, è possibile visitare la pagina [OpenAI Chat Completion 4o Image API](https://platform.acedata.cloud/documents/1bcf3bba-102b-495d-9bba-47cd96717e45) e cliccare sul pulsante "Acquire" per ottenere le credenziali necessarie per le richieste:

Se non sei ancora loggato o registrato, verrai automaticamente reindirizzato alla pagina di login per registrarti e accedere; dopo il login, tornerai automaticamente alla pagina corrente.

Al primo accesso viene offerto un credito gratuito per utilizzare l'API senza costi.

## Modello di Disegno GPT-4o

### Generazione di Immagini da Immagine di Riferimento

Di seguito un esempio di generazione di un’immagine con stile personalizzato partendo da una foto. Prima di tutto, diamo un’occhiata all’immagine di input:

![](https://cdn.acedata.cloud/qzx2z1.png)

Come si vede, l’immagine di riferimento è una foto di una persona reale. Possiamo farla trasformare in uno stile diverso, ad esempio in stile anime. Ecco un esempio di richiesta:

```json
{
  "model": "gpt-4o-image",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "生成动漫风格的图片，并且带上个帽子"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

Esempio di risposta:


## Gestione degli Errori

Quando si chiama l’API, in caso di errore verranno restituiti codici e messaggi di errore specifici, ad esempio:

- `400 token_mismatched`: Richiesta errata, probabilmente per parametri mancanti o non validi.
- `400 api_not_implemented`: Richiesta errata, probabilmente per parametri mancanti o non validi.
- `401 invalid_token`: Non autorizzato, token di autorizzazione mancante o non valido.
- `429 too_many_requests`: Troppe richieste, superato il limite di velocità.
- `500 api_error`: Errore interno del server, si è verificato un problema sul server.

### Esempio di Risposta di Errore
