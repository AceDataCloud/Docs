## 1. Ottenere la chiave API

Aprire [l'elenco delle applicazioni di Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedere alle applicazioni disponibili e copiare la chiave API.

![Ottenere la chiave API di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Inviare la prima richiesta

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer la tua chiave API" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Illustrazione di prodotto editoriale minimale: una semplice tazza da caffè in ceramica bianca centrata su un tavolo solido blu cobalto, sfondo crema pallido, ombra morbida, forme geometriche pulite, nessun testo, nessun logo, composizione verticale",
    "size": "1024x1536"
  }'
```

L'immagine della risposta di successo si trova in `data[].url`. Di seguito è riportato il risultato 1024×1536 ottenuto tramite richiesta reale su Ace Data Cloud il 8 settembre 2026 (compito `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, traccia `eb938601-8192-407f-b539-1e0554b697ec`):

![Tazza bianca generata da GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Parametri comuni

| Campo              | Descrizione                                                               |
| ----------------- | ---------------------------------------------------------------------- |
| `model`           | Utilizzare `gpt-image-2`; è possibile scegliere esplicitamente `gpt-image-2:official` o `gpt-image-2:reverse` |
| `prompt`          | Descrizione dell'immagine, massimo 32.000 caratteri                             |
| `size`            | `auto` o `LARGHEZZAxALTEZZA`; le dimensioni devono essere multipli di 16, il lato lungo non deve superare 3840, il numero totale di pixel non deve superare 8.294.400        |
| `n`               | 1–10; supporta solo 1 quando `response_format=b64_json`                     |
| `quality`         | `basso`, `medio`, `alto` o `auto`; il supporto e le modalità di fatturazione variano a seconda delle linee |
| `response_format` | `url` o `b64_json`                                                     |
| `callback_url`    | Facoltativo; invia i risultati a questo indirizzo dopo il completamento di compiti lunghi |

Dimensioni comuni:

| Rapporto  | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` selezionerà il formato in base al rapporto, ai pixel e all'intento di layout nel prompt; se sono necessari pixel precisi, inserire direttamente le dimensioni.

## 4. Generazione multipla

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer la tua chiave API" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Una piccola volpe che legge sotto un fungo luminoso, illustrazione ad acquerello",
    "size": "1536x1024",
    "n": 2
  }'
```

Il `gpt-image-2` predefinito e `:reverse` addebitano in base al numero di immagini generate; `gpt-image-2:official` calcola i Token effettivi in base all'input di testo e all'output dell'immagine nella risposta. I prezzi sulla pagina sono stime prima della richiesta, il risultato finale è basato sui registri di utilizzo.

## 5. Callback asincrona

Dopo aver aggiunto `callback_url` al corpo della richiesta, l'API restituirà prima `{"task_id": "..."}`, e al completamento invierà il risultato finale a quell'URL tramite POST; le richieste sincrone restituiscono comunque `created` e `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "Un poster di prodotto con tipografia chiara",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Il ricevente del callback dovrebbe utilizzare `task_id` per evitare duplicati e verificare la provenienza della richiesta e il formato dei dati.

## 6. Risoluzione dei problemi

| Stato  | Controllo                                              |
| --- | --------------------------------------------------- |
| 400 | Combinazione di `model`, `prompt`, formato delle dimensioni, `n` e `response_format`    |
| 401 | La chiave API è completa? L'intestazione è `Authorization: Bearer ...` |
| 429 | Richiesta troppo frequente, riprovare più tardi                                   |
| 504 | Timeout nella generazione sincrona; utilizzare `callback_url`                    |

Le risposte di errore conterranno `error.code`, `error.message` e `trace_id`. Quando si segnalano problemi, fornire `trace_id`, non fornire la chiave API.

I campi completi e l'elenco in tempo reale sono disponibili sulla pagina [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Per la modifica delle immagini, consultare [GPT Image 2 modifica delle immagini](https://platform.acedata.cloud/documents/openai-images-edits).
