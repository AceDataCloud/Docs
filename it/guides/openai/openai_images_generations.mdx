## 1. Ottenere l'API Key

Apri [l'elenco delle applicazioni Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedi a un'applicazione disponibile e copia l'API Key.

![Ottenere l'API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Inviare la prima richiesta

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

L'immagine della risposta riuscita si trova in `data[].url`. Di seguito è riportato il risultato 1024×1536 ottenuto tramite una richiesta effettiva attraverso Ace Data Cloud l'8 settembre 2026 (attività `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Tazza bianca generata da GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Parametri comuni

| Campo                | Descrizione                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (consigliato per impostazione predefinita), `gpt-image-2.5-flare` (più veloce) o `gpt-image-2.5-sunburst` (maggiore fedeltà e controllo); tutti e tre possono selezionare la variante `:official` corrispondente, mentre `gpt-image-2` supporta anche `:reverse` |
| `prompt`          | Descrizione dell'immagine, fino a 32.000 caratteri                                                                                                                     |
| `size`            | `auto` o `WIDTHxHEIGHT`; larghezza e altezza devono essere multipli di 16, il lato lungo non deve superare 3840, i pixel totali devono essere 655.360–8.294.400 e il rapporto d'aspetto non deve superare 3:1                                                       |
| `n`               | 1–10; quando `response_format=b64_json`, è supportato solo 1                                                                                                 |
| `quality`         | I modelli GPT Image supportano `auto`, `low`, `medium`, `high`; solo 2.5 Flare / Sunburst (incluso `:official`) supportano inoltre `xhigh`, `max`. Il canale ufficiale viene fatturato in base all'effettivo utilizzo di Token                 |
| `response_format` | `url` o `b64_json`                                                                                                                     |
| `callback_url`    | Opzionale; invia il risultato a questo indirizzo dopo il completamento di attività lunghe                                                                                                                      |

Dimensioni comuni:

| Rapporto   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` selezionerà il formato in base al rapporto, ai pixel e all'intento di impaginazione nel prompt; quando sono necessari pixel precisi, inserisci direttamente le dimensioni.

### Modelli e modalità di fatturazione

| Modello                                | Scenari applicabili e modalità di fatturazione                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | Canale inverso predefinito, fatturazione fissa in base al numero di immagini riuscite                               |
| `gpt-image-2:reverse`             | Seleziona esplicitamente il canale inverso, fatturazione fissa in base al numero di immagini riuscite                             |
| `gpt-image-2:official`            | Canale API ufficiale, maggiore stabilità, fatturazione in base all'effettivo utilizzo di Token                   |
| `gpt-image-2.5-flare`             | Incentrato sulla velocità di generazione, fatturazione fissa in base al numero di immagini riuscite                               |
| `gpt-image-2.5-flare:reverse`     | Alias inverso esplicito, equivalente a `gpt-image-2.5-flare`, fatturazione fissa in base al numero di immagini riuscite    |
| `gpt-image-2.5-flare:official`    | Canale API ufficiale, maggiore stabilità e incentrato sulla velocità di generazione, fatturazione in base all'effettivo utilizzo di Token            |
| `gpt-image-2.5-sunburst`          | Incentrato su alta fedeltà e controllo dettagliato, fatturazione fissa in base al numero di immagini riuscite                           |
| `gpt-image-2.5-sunburst:reverse`  | Alias inverso esplicito, equivalente a `gpt-image-2.5-sunburst`, fatturazione fissa in base al numero di immagini riuscite |
| `gpt-image-2.5-sunburst:official` | Canale API ufficiale, maggiore stabilità e incentrato su alta fedeltà e controllo dettagliato, fatturazione in base all'effettivo utilizzo di Token        |

I modelli inversi (inclusi gli alias `:reverse`) possono utilizzare GPT Image 2.5 Flare per completare la richiesta durante il ripristino automatico; il modello richiesto e la modalità di fatturazione in base al numero di immagini riuscite rimangono invariati.

Il prezzo mostrato sulla pagina per il canale API ufficiale è una stima prima della richiesta; il risultato finale si basa sull'effettivo utilizzo di Token nella risposta e sui registri di utilizzo.

## 4. Generazione multipla

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` e i relativi alias `:reverse` vengono fatturati in base al numero di immagini riuscite; `gpt-image-2:official`, `gpt-image-2.5-flare:official` e `gpt-image-2.5-sunburst:official` vengono regolati in base ai Token effettivi di input testuale e output immagine nella risposta. Il prezzo mostrato sulla pagina è una stima prima della richiesta; il risultato finale si basa sui registri di utilizzo.

## 5. Callback asincrono

Dopo aver aggiunto `callback_url` al corpo della richiesta, l'interfaccia restituirà prima `{"task_id": "..."}` e invierà il risultato finale tramite POST a quell'URL al completamento; le richieste sincrone restituiscono ancora `created` e `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Il destinatario del callback deve usare `task_id` per la deduplicazione e verificare l'origine della richiesta e il formato dei dati.

## 6. Risoluzione dei problemi

| Stato  | Verificare                                                  |
| --- | --------------------------------------------------- |
| 400 | Combinazione di `model`, `prompt`, formato delle dimensioni, `n` e `response_format`    |
| 401 | Se l'API Key è completa e se l'Header è `Authorization: Bearer ...` |
| 429 | Richieste troppo frequenti, riprovare più tardi                                         |
| 504 | Timeout della generazione sincrona; usare invece `callback_url`                            |

La risposta di errore includerà `error.code`, `error.message` e `trace_id`. Quando segnali un problema, fornisci `trace_id`, non fornire l'API Key.
I campi completi e gli enum in tempo reale fanno riferimento alla pagina [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Per la modifica delle immagini, consulta [GPT Image 2 / 2.5 Modifica delle immagini](https://platform.acedata.cloud/documents/openai-images-edits).
