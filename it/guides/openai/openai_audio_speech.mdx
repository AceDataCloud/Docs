---
title: "OpenAI API di sintesi vocale (/v1/audio/speech)"
description: "OpenAI generation API guide - Ace Data Cloud"
---

Sintetizza il testo in voce naturale, **completamente compatibile con OpenAI `/v1/audio/speech`**. Qualsiasi SDK OpenAI deve semplicemente puntare `base_url` a `https://api.acedata.cloud` e sostituire la chiave con il tuo AceData Token per poter essere utilizzato direttamente. L'interfaccia restituisce in modo sincrono un flusso di byte audio.

- **Indirizzo della richiesta**: `POST https://api.acedata.cloud/v1/audio/speech` (alias `POST /openai/audio/speech`)
- **Autenticazione**: intestazione della richiesta `Authorization: Bearer {token}`
- **Fatturazione**: fatturato in base al numero di byte del testo richiesto, circa l'85% del prezzo ufficiale di OpenAI (vedi tabella sottostante).

## Parametri della richiesta

| Campo              | Tipo     | Obbligatorio | Descrizione                                                      |
| ----------------- | ------ | ------------ | ------------------------------------------------------------- |
| `input`           | string | Sì          | Il testo da sintetizzare.                                       |
| `model`           | string | No          | `tts-1` (più veloce) o `tts-1-hd` (qualità audio superiore, predefinito). |
| `voice`           | string | No          | Uno tra `alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`, predefinito `alloy`. |
| `response_format` | string | No          | `mp3` (predefinito), `opus`, `aac`, `flac`, `wav`, `pcm`.    |
| `speed`           | number | No          | Velocità di lettura 0.25–4.0, predefinita 1.0.                |

## Esempio

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/speech' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -o speech.mp3 \
  -d '{
    "model": "tts-1-hd",
    "input": "Cosa succederebbe se un'API ti desse ogni modello video AI?",
    "voice": "nova",
    "response_format": "mp3"
  }'
```

La risposta è il file audio stesso (`Content-Type: audio/mpeg`), che può essere scritto direttamente in `speech.mp3` per essere riprodotto.

Utilizzando l'SDK Python ufficiale di OpenAI:

```python
from openai import OpenAI
client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
client.audio.speech.create(model="tts-1-hd", voice="nova", input="Ciao da AceData.").stream_to_file("speech.mp3")
```

## Prezzi

| Modello       | Prezzo ufficiale OpenAI | Prezzo su questa piattaforma (circa 85% di sconto) |
| ------------ | ----------------------- | ------------------------------------------------- |
| `tts-1`      | $15 / 1 milione di caratteri | circa $12.75 / 1 milione di caratteri             |
| `tts-1-hd`   | $30 / 1 milione di caratteri | circa $25.5 / 1 milione di caratteri              |

> Fatturato in base al numero di byte del testo richiesto; il campo `official_price` mostra il prezzo ufficiale di OpenAI per confronto.

## Codici di errore

| Codice | code                    | Descrizione           |
| ------ | ----------------------- | --------------------- |
| 400    | `bad_request`           | `input` è vuoto o i parametri sono non validi. |
| 401    | `authentication_failed` | token non valido.     |
| 403    | `used_up`               | Saldo insufficiente.  |
| 429    | `too_many_requests`     | Richieste troppo frequenti. |
| 500    | `api_error`             | Errore upstream/interno. |
