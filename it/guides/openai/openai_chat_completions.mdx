OpenAI ChatGPT è un sistema di conversazione AI molto potente: basta inserire un prompt per generare risposte fluide e naturali in pochi secondi. ChatGPT si distingue nel settore per le sue eccellenti capacità di comprensione e generazione del linguaggio. Oggi, ChatGPT è già ampiamente utilizzato in vari settori e ambiti, e la sua influenza è sempre più significativa. Che si tratti di conversazioni quotidiane, scrittura creativa, consulenza professionale o programmazione di codice, ChatGPT può fornire un'assistenza intelligente sorprendente, migliorando notevolmente l'efficienza lavorativa e la creatività umana.

Questo documento presenta principalmente il processo di utilizzo delle operazioni dell'API OpenAI Chat Completion, che ci consente di utilizzare facilmente la funzionalità di conversazione dell'OpenAI ChatGPT ufficiale.

## GPT-6.1 Sol

Utilizzare `model: "gpt-6.1-sol"` per selezionare questo modello. Supporta output in streaming, chiamate di funzione, output strutturato e input di immagini. Nella prima settimana dall'apertura, è disponibile solo per i possessori verificati di ACE T1+ (almeno 100.000 ACE) o per gli utenti autorizzati; l'orario specifico di apertura è soggetto all'avviso di accesso nella console.

I livelli di ragionamento supportano `low`, `medium`, `high`, `xhigh` e `max`; `none` o `minimal` non sono temporaneamente supportati. Si consiglia di iniziare con `reasoning_effort: "low"`. Quando l'input supera 272.000 token, all'intera richiesta si applica il prezzo del contesto lungo; il costo è soggetto al prezzo corrente della console.

## Procedura di richiesta

Per utilizzare l'API OpenAI Chat Completion, per prima cosa vai alla [console Ace Data Cloud](https://platform.acedata.cloud/console/applications) per ottenere il tuo API Token, da conservare come riserva.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se non hai ancora effettuato l'accesso o non ti sei registrato, verrai automaticamente reindirizzato alla pagina di accesso per registrarti e accedere; al termine, tornerai automaticamente alla pagina corrente.

**Un solo API Token può chiamare tutti i servizi della piattaforma, senza necessità di richiederne uno separatamente per ogni servizio.** Alla prima richiesta verrà fornito un credito gratuito, che potrà essere utilizzato per un'esperienza gratuita; quando il credito è insufficiente, puoi ricaricare il saldo universale nella [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentazione completa: [OpenAI Chat Completion API →](https://platform.acedata.cloud/documents/openai-chat-completions)

## Utilizzo di base

Successivamente puoi compilare i contenuti corrispondenti nell'interfaccia, come mostrato nell'immagine:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

Quando utilizziamo questa interfaccia per la prima volta, dobbiamo compilare almeno tre contenuti. Uno è `authorization`, che può essere selezionato direttamente nell'elenco a discesa. Un altro parametro è `model`; `model` è la categoria di modello del sito ufficiale OpenAI ChatGPT che scegliamo di utilizzare. Qui abbiamo principalmente 20 modelli, per i dettagli puoi consultare i modelli che forniamo. L'ultimo parametro è `messages`; `messages` è l'array delle domande che inseriamo. È un array, il che indica che è possibile caricare contemporaneamente più domande. Ogni domanda contiene `role` e `content`, dove `role` indica il ruolo di chi pone la domanda. Forniamo tre identità, ovvero `user`, `assistant`, `system`. L'altro, `content`, è il contenuto specifico della nostra domanda.

Allo stesso tempo, puoi notare che sulla destra viene generato il codice di chiamata corrispondente: puoi copiare il codice ed eseguirlo direttamente, oppure fare clic direttamente sul pulsante «Try» per effettuare un test.

Parametri opzionali comuni:

- `max_tokens`: limita il numero massimo di token per una singola risposta.
- `temperature`: casualità della generazione, compresa tra 0 e 2; maggiore è il valore, più divergente sarà.
- `n`: quante risposte candidate generare in una sola volta.
- `response_format`: impostazione del formato di risposta.

## Risposta in streaming

Questa interfaccia supporta anche le risposte in streaming, il che è molto utile per l'integrazione con pagine web e consente alla pagina web di ottenere un effetto di visualizzazione carattere per carattere.

Se desideri restituire la risposta in streaming, puoi modificare il parametro `stream ` nell'intestazione della richiesta, impostandolo su `true`.

La modifica è mostrata nell'immagine, ma il codice di chiamata deve essere modificato di conseguenza per supportare la risposta in streaming.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

Dopo aver modificato `stream` in `true`, l'API restituirà riga per riga i dati JSON corrispondenti; a livello di codice dobbiamo apportare le modifiche corrispondenti per ottenere i risultati riga per riga.

Codice di chiamata di esempio Python:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Anche JavaScript è supportato; ad esempio, il codice di chiamata in streaming per Node.js è il seguente:

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4",
    messages: [{ role: "user", content: "hello" }],
    stream: true,
  }),

fetch("https://api.acedata.cloud/openai/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

## Integrazione con OpenAI-Python

OpenAI Chat Completion API rimane compatibile con l'interfaccia ufficiale OpenAI e può essere integrata direttamente utilizzando l'SDK ufficiale [OpenAI-Python](https://github.com/openai/openai-python); questo articolo introdurrà brevemente il metodo di utilizzo.

1. Per prima cosa è necessario configurare l'ambiente locale `Python`; per questo processo è possibile effettuare una ricerca su Google.
2. Scaricare e installare l'ambiente di sviluppo, ad esempio l'editor VSCode.
3. Configurare le variabili d'ambiente di `OpenAI`.

- Nella cartella del progetto, creare un file denominato `.env` e salvarlo
- Contenuto del file `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # 再次提醒：如果你使用官网OpenAI的key，不要用这个地址。
```

Sostituire `sk-xxx` con la propria key. `OPENAI_BASE_URL` è l'interfaccia proxy per accedere a OpenAI.

4. Installare i pacchetti dalle cui dipendenze dipende il progetto

```shell
pip install openai
```

In Mac OS il comando è:

```shell
pip3 install openai
```

5. Creare il file del codice sorgente di esempio

Supponiamo di aver creato un codice di esempio `index.py`, il cui contenuto specifico è il seguente:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Modello visivo

gpt-4o è un grande modello linguistico multimodale sviluppato da OpenAI, che aggiunge capacità di comprensione visiva sulla base di GPT-4. Questo modello può elaborare contemporaneamente input di testo e immagini, realizzando comprensione e generazione intermodali.

L'elaborazione del testo con il modello gpt-4o è coerente con il contenuto dell'utilizzo di base sopra descritto; di seguito verrà brevemente illustrato come utilizzare la capacità di elaborazione delle immagini del modello.

La capacità di elaborazione delle immagini del modello gpt-4o viene utilizzata principalmente aggiungendo un campo `type` sulla base del contenuto `content` originale; tramite questo campo è possibile sapere se ciò che viene caricato è testo o immagine, utilizzando così la capacità di elaborazione delle immagini del modello gpt-4o. Di seguito viene illustrato principalmente come chiamare questa funzione utilizzando i due metodi Curl e Python.

- Metodo tramite script Curl

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

- Metodo tramite script Python
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
                    }
                },
            ],
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Gestione degli errori

Durante la chiamata dell'API, se si verifica un errore, l'API restituirà il codice e il messaggio di errore corrispondenti. Ad esempio:

- `400 token_mismatched`: Richiesta non valida, probabilmente a causa di parametri mancanti o non validi.
- `400 api_not_implemented`: Richiesta non valida, probabilmente a causa di parametri mancanti o non validi.
- `401 invalid_token`: Non autorizzato, token di autorizzazione non valido o mancante.
- `429 too_many_requests`: Troppe richieste, hai superato il limite di frequenza.
- `500 api_error`: Errore interno del server, qualcosa è andato storto sul server.

### Esempio di risposta di errore

```
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
