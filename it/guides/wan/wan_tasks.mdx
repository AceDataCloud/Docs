title: "Wan 任务查询 API"
description: "Wan API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/wan/tasks` è utilizzato per cercare, cercare in batch o eliminare i compiti video Wan. La ricerca dei compiti non comporta costi di generazione ripetuti.

## 查询单个任务

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Il `response.data.video_url` del compito completato è l'indirizzo CDN permanente; `response.usage` include risoluzione, secondi video in ingresso/uscita, frame rate e proporzione; `response.cost` è il costo di regolazione del compito.

## 批量查询

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Restituisce `{ "items": [...], "count": 2 }`. Durante l'esecuzione del compito, potrebbero non esserci ancora `finished_at` e `response` finale.

## 删除任务记录

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

L'eliminazione influisce solo sulla cronologia dei compiti, non eliminerà i video CDN già generati.
