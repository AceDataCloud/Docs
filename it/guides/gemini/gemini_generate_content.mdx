Google Gemini è un sistema di conversazione AI molto potente, in grado di generare risposte fluide e naturali in pochi secondi tramite l'inserimento di prompt. Questo documento descrive principalmente come utilizzare la Gemini Generate Content API, che è il formato API nativo ufficiale di Google e supporta i due endpoint `generateContent` e `streamGenerateContent`.

## Differenze rispetto alla Chat Completions API

La Gemini Generate Content API utilizza il formato di richiesta nativo ufficiale di Google (campo `contents`), anziché il formato compatibile con OpenAI (campo `messages`). Se utilizzi già Google Gemini SDK o conosci il formato API ufficiale, puoi usare direttamente questa API senza modificare il formato della richiesta.

## Ambito di supporto attuale

L'interfaccia accetta input di testo, immagini, video e audio (`inlineData` o `fileData`), configurazioni di ragionamento e dichiarazioni di funzioni personalizzate. Campi nativi quali output audio, strumenti integrati e caching esplicito del contesto non hanno ancora una garanzia di disponibilità uniforme; fai riferimento al comportamento effettivo restituito dal modello specifico.

Quando invii file quali audio usando `fileData.fileUri`, assicurati che il file sia direttamente accessibile tramite HTTPS, che non dipenda dallo stato di accesso e che il periodo di validità del link firmato copra l'intero tempo di elaborazione della richiesta. L'analisi audio non in streaming restituisce il risultato solo dopo che il modello ha completato l'elaborazione e potrebbe superare i 90 secondi; il client deve impostare un timeout totale sufficientemente lungo in base alle dimensioni del file e allo scenario aziendale, evitando di interrompere la connessione mentre il server sta ancora elaborando.

## Procedura di richiesta

Prima di utilizzare la Gemini Generate Content API, visita la pagina [Gemini Generate Content API](https://platform.acedata.cloud/documents/gemini-generate-content-api) e fai clic sul pulsante "Ottieni" per ottenere le credenziali necessarie per la richiesta.

Se non hai ancora effettuato l'accesso o non ti sei registrato, verrai automaticamente reindirizzato alla pagina di accesso. La prima richiesta include una quota gratuita.

## Utilizzo di base

### Non-Streaming (non in streaming)

Invia una richiesta POST a `/v1beta/models/{model}:generateContent`:

> **Suggerimento**: la serie flash `gemini-3.x` è costituita da modelli di ragionamento e consumerà prima reasoning tokens; imposta `generationConfig.maxOutputTokens` a un valore superiore a 512, altrimenti potrebbe restituire solo contenuto vuoto.

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "你好，请介绍一下你自己"
          }
        ]
      }
    ]
  }'
```

Esempio di risultato restituito:

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [{"text": "你好！很高兴与你交流。"}]
      },
      "finishReason": "MAX_TOKENS"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 6,
    "candidatesTokenCount": 19,
    "thoughtsTokenCount": 489,
    "totalTokenCount": 514
  },
  "usage": {
    "prompt_tokens": 6,
    "completion_tokens": 19,
    "total_tokens": 514,
    "thoughts_tokens": 489,
    "cost": {
      "amount": 0.008860916380159999,
      "currency": "credit",
      "list_amount": 0.009631430847999998
    }
  },
  "modelVersion": "gemini-3.5-flash",
  "model": "gemini-3.5-flash"
}
```

I campi token in `usageMetadata` vengono fatturati secondo la semantica nativa di Gemini:

- `promptTokenCount` include `cachedContentTokenCount`; la parte che colpisce la cache viene calcolata al prezzo di lettura della cache e non viene conteggiata nuovamente come input ordinario.
- `promptTokensDetails` e `cacheTokensDetails` vengono normalizzati in `text_tokens`, `image_tokens`, `video_tokens`, `audio_tokens` e nei corrispondenti dettagli `cached_*` sotto `usage.prompt_tokens_details`. Questi valori sono inclusi rispettivamente in `prompt_tokens` e `cached_tokens`; le diverse modalità vengono ricalcolate solo in base ai rispettivi prezzi, senza doppia fatturazione.
- `candidatesTokenCount` e `thoughtsTokenCount` vengono entrambi calcolati al prezzo dei token di output.
- `toolUsePromptTokenCount` è un token di input per strumenti indipendente, calcolato al prezzo dei token di input.

Ace Data Cloud restituisce inoltre un oggetto `usage` normalizzato; tra i protocolli dei modelli, il costo di questa chiamata viene letto in modo uniforme da `usage.cost`. `cost` è un'anteprima facoltativa del costo; quando l'anteprima del prezzo non è temporaneamente disponibile, la risposta del modello verrà comunque restituita normalmente, ma potrebbe non includere questo campo. La fattura finale fa fede ai registri di utilizzo.

### Streaming (in streaming)

Invia una richiesta POST a `/v1beta/models/{model}:streamGenerateContent?alt=sse`:

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "写一首关于春天的诗"
          }
        ]
      }
    ]
  }'
```

La risposta in streaming restituirà gradualmente il contenuto in formato SSE (Server-Sent Events). Gli eventi intermedi di solito contengono solo contenuti incrementali; l'evento terminale con utilizzo autorevole includerà `usageMetadata` e `usage` normalizzato, mentre il costo rimane in `usage.cost`:

```text
data: {"candidates":[{"content":{"parts":[{"text":"Hello!"}],"role":"model"},"index":0}],"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

data: {"candidates":[{"content":{"parts":[],"role":"model"},"finishReason":"STOP","index":0}],"usageMetadata":{"promptTokenCount":7,"candidatesTokenCount":89,"totalTokenCount":96},"usage":{"prompt_tokens":7,"completion_tokens":89,"total_tokens":96,"cost":{"amount":0.00026161075472,"currency":"credit","list_amount":0.000284359516}},"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

```

La chiusura della connessione indica la fine del flusso; il flusso Gemini nativo non invia `data: [DONE]`. Se l'anteprima del prezzo terminale non è temporaneamente disponibile, `usage` restituirà comunque l'utilizzo dei token, ma ometterà `cost`.

## Funzionalità avanzate

### Istruzioni di sistema

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "你好"}]
    }
  ],
  "systemInstruction": {
    "parts": [{"text": "你是一个专业的诗人，所有回复都用诗歌形式。"}]
  }
}
```

### Configurazione della generazione

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "讲一个故事"}]
    }
  ],
  "generationConfig": {
    "temperature": 0.7,
    "maxOutputTokens": 1024,
    "topP": 0.9,
    "topK": 40
  }
}
```

### Modalità JSON

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {
          "text": "列出三个中国城市及其人口"
        }
      ]
    }
  ],
  "generationConfig": {
    "responseMimeType": "application/json",
    "responseSchema": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "city": {
            "type": "string"
          },
          "population": {
            "type": "integer"
          }
        }
      }
    }
  }
}
```

### Modalità di pensiero (Thinking)

I modelli che supportano la funzione di pensiero (come gemini-2.5-flash, gemini-2.5-pro) possono abilitare la modalità di pensiero:

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "解释量子纠缠"}]
    }
  ],
  "generationConfig": {
    "thinkingConfig": {
      "includeThoughts": true,
      "thinkingBudget": 2048
    }
  }
}
```

### Chiamata di funzione

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "北京现在的天气怎么样？"}]
    }
  ],
  "tools": [
    {
      "functionDeclarations": [
        {
          "name": "get_weather",
          "description": "获取指定城市的天气信息",
          "parameters": {
            "type": "object",
            "properties": {
              "city": {
                "type": "string",
                "description": "城市名称"
              }
            },
            "required": ["city"]
          }
        }
      ]
    }
  ]
}
```

### Conversazione multi-turno

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "你好，我叫小明"}]
    },
    {
      "role": "model",
      "parts": [{"text": "你好小明！很高兴认识你。"}]
    },
    {
      "role": "user",
      "parts": [{"text": "我叫什么名字？"}]
    }
  ]
}
```

### Comprensione delle immagini

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {"text": "描述这张图片"},
        {
          "inlineData": {
            "mimeType": "image/jpeg",
            "data": "base64_encoded_image_data..."
          }
        }
      ]
    }
  ]
}
```

## Impostazioni di sicurezza

È possibile controllare il filtraggio dei contenuti tramite `safetySettings`:

```json
{
  "contents": [...],
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_ONLY_HIGH"
    }
  ]
}
```

## Gestione degli errori

| Codice di stato HTTP | Significato             |
| -------- | -------------- |
| 400      | Parametri della richiesta non validi         |
| 401      | Autenticazione non riuscita, controllare il Token |
| 403      | Contenuto intercettato dal filtro di sicurezza     |
| 429      | Richieste troppo frequenti         |
| 500      | Errore interno del server        |
