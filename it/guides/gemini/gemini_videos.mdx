Questo documento introduce l'integrazione dell'API Gemini Videos Generation, che può generare video Google Gemini (omni-flash) tramite l'input di parole chiave testuali (e immagini di riferimento opzionali).

## Processo di richiesta

Per utilizzare l'API Gemini Videos Generation, prima vai al [Pannello di controllo di Ace Data Cloud](https://platform.acedata.cloud/console/applications) per ottenere il tuo API Token, da conservare per uso futuro.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Se non hai ancora effettuato il login o la registrazione, verrai automaticamente reindirizzato alla pagina di login che ti invita a registrarti e accedere; una volta completato, verrai riportato automaticamente alla pagina corrente.

**Un API Token è sufficiente per accedere a tutti i servizi della piattaforma, senza necessità di richiederne uno per ogni servizio.** La prima richiesta riceverà un credito gratuito, per un'esperienza senza costi; quando il credito è insufficiente, puoi ricaricare il saldo generale nel [pannello di controllo](https://platform.acedata.cloud/console/coin).

> 📘 Documentazione completa: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Utilizzo di base

Iniziamo a comprendere le modalità di utilizzo di base, inserendo le parole chiave `prompt`, il modello `model` e il rapporto d'aspetto `aspect_ratio`, per generare il video corrispondente.

Possiamo vedere che qui abbiamo impostato le intestazioni della richiesta, tra cui:

- `accept`: il formato della risposta desiderata, qui impostato su `application/json`, ovvero formato JSON.
- `authorization`: la chiave per chiamare l'API, che può essere selezionata direttamente dopo la richiesta.

Inoltre, abbiamo impostato il corpo della richiesta, che include:

- `prompt`: le parole chiave testuali che descrivono il contenuto del video da generare, **obbligatorio**.
- `model`: il modello per generare il video, attualmente supporta solo `omni-flash`, che è il valore predefinito.
- `aspect_ratio`: il rapporto d'aspetto del video generato, può essere `16:9` (orizzontale) o `9:16` (verticale), predefinito `16:9`.
- `resolution`: risoluzione di output opzionale, può essere `720p` o `1080p`, predefinito `720p`.
- `image_urls`: array di link a immagini di riferimento opzionali, utilizzati per guidare la generazione del video; i campi vuoti verranno ignorati. Quando si utilizza `video_urls` per l'editing video, questo parametro è obbligatorio (almeno un'immagine).
- `video_urls`: array di link a video di riferimento opzionali (massimo 1), utilizzati per **editing video / video di riferimento**; se fornito, deve essere fornita anche almeno un'immagine in `image_urls`.
- `callback_url`: indirizzo di callback asincrono; una volta impostato, l'API restituirà immediatamente `task_id`, e al termine del compito, il risultato verrà inviato a questo indirizzo tramite POST.
- `async`: opzionale, se impostato su `true`, l'interfaccia restituirà immediatamente `task_id`, senza necessità di fornire `callback_url`, e successivamente si potrà ottenere il risultato tramite l'interfaccia di query del compito corrispondente.

Cliccando sul pulsante "Try" è possibile effettuare un test, e il risultato ottenuto sarà simile al seguente:

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://platform2.cdn.acedata.cloud/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden"
    }
  ],
  "started_at": 1784112953.856,
  "finished_at": 1784113021.328,
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Il risultato restituito contiene diversi campi, descritti come segue:

- `success`: se la richiesta di generazione video è stata completata con successo.
- `task_id`: l'ID del compito di generazione video.
- `trace_id`: l'ID di tracciamento della richiesta, utilizzato per la risoluzione dei problemi.
- `data`: lista dei risultati video generati.
  - `id`: identificatore unico del video generato.
  - `video_url`: link al video generato (è `null` quando `state` è `pending`).
  - `state`: stato del compito di generazione video, può essere `pending` / `succeeded` / `failed`.
  - `aspect_ratio`: il rapporto d'aspetto del video, coerente con i parametri della richiesta.
  - `prompt`: le parole chiave utilizzate per generare il video.

Quando la risposta è sincrona, il livello superiore includerà anche i campi `started_at`, `finished_at`, `elapsed` (tempo impiegato, in secondi) e `cost` (costo di questa operazione, in Crediti).

Dobbiamo solo ottenere il video generato dal link `video_url` presente in `data`.

Il codice CURL corrispondente è il seguente:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Il codice Python corrispondente è il seguente:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Video generati da immagini

Se desideri generare un video basato su immagini di riferimento, puoi fornire uno o più link a immagini in `image_urls`, utilizzati per guidare la generazione del video:

```json
{
  "prompt": "The woman slowly turns around and smiles at the camera, gentle breeze",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3.png"
  ]
}
```

## Editing video / Video di riferimento (video in input, video in output)

Supporta direttamente "inserire un video e generare un nuovo video": in `video_urls` puoi fornire un link a un video di riferimento (massimo 1), e **contemporaneamente** in `image_urls` fornire almeno un'immagine di riferimento (richiesta obbligatoria), quindi utilizzare `prompt` per descrivere l'effetto di editing desiderato (cambiare stile, cambiare scena, aggiungere o rimuovere elementi, ecc.).

Ecco un esempio completo e reale: trasformare un video di una spiaggia soleggiata in una scena invernale con neve, mantenendo la disposizione della spiaggia, delle palme e della barca. L'editing video richiede più tempo (in questo esempio circa 6,5 minuti), quindi utilizziamo `async: true` per inviare la richiesta in modo asincrono:
```json
{
  "prompt": "Trasforma questa spiaggia tropicale soleggiata in una scena invernale nevosa con forte neve che cade e cielo nuvoloso; mantieni la stessa spiaggia, palme e disposizione delle barche.",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://platform2.cdn.acedata.cloud/seedance/dd3dc063-3383-4f29-bedc-e771a096758c.mp4"
  ],
  "async": true
}
```

Dopo l'invio, l'interfaccia restituisce immediatamente `task_id`:

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

Successivamente, utilizza il `task_id` come `id` per interrogare [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks), una volta completato il compito, puoi ottenere il nuovo video generato (questo è il risultato reale di questo esempio):

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://platform2.cdn.acedata.cloud/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "Trasforma questa spiaggia tropicale soleggiata in una scena invernale nevosa con forte neve che cade e cielo nuvoloso; mantieni la stessa spiaggia, palme e disposizione delle barche."
    }
  ],
  "started_at": 1784084482.914,
  "finished_at": 1784084877.09,
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Se desideri risultati di qualità superiore, puoi impostare `resolution` su `1080p` (gli altri parametri rimangono invariati).

> Suggerimento: i link ai media di input / output nell'esempio sono risultati generati reali. **I video e i link delle immagini generati dalla piattaforma hanno un termine di scadenza, dopo il quale scadranno**, assicurati di scaricarli e salvarli nel tuo spazio di archiviazione non appena ottieni i risultati.

> Nota: è consentito un massimo di 1 video di riferimento; e quando fornisci `video_urls` devi fornire almeno un'immagine in `image_urls`, altrimenti verrà restituito il seguente errore di parametro:

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (almeno un'immagine di riferimento) è richiesta quando è fornito video_urls."
  }
}
```

## Callback asincrona

La generazione del video richiede un certo tempo di elaborazione. Se non desideri mantenere una connessione lunga in attesa, puoi fornire `callback_url`, in questo caso l'API restituirà immediatamente `task_id`, e una volta completato il compito, invierà il risultato finale a quell'indirizzo:

```json
{
  "prompt": "Una ripresa cinematografica di un gattino che insegue una farfalla in un giardino illuminato dal sole",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Il risultato restituito immediatamente è il seguente:

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## Verifica dei risultati del compito

Se hai utilizzato un callback asincrono o desideri controllare attivamente lo stato del compito, puoi utilizzare [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) per controllare lo stato e i risultati più recenti del compito in base al `task_id`. Nel corpo della richiesta, inserisci il `task_id` restituito al momento della creazione del video come `id`:

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

Il risultato restituito al termine del compito è simile al seguente, la struttura di `response.data` è la stessa di quando viene generato in modo sincrono (quando è in fase di generazione, `state` è `pending`, `video_url` è `null`):

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
  "type": "videos",
  "request": {
    "model": "omni-flash",
    "prompt": "Un time-lapse di nuvole sopra montagne innevate all'alba",
    "aspect_ratio": "16:9",
    "async": true
  },
  "response": {
    "success": true,
    "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
    "data": [
      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
        "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4",
        "state": "succeeded",
        "aspect_ratio": "16:9",
        "prompt": "Un time-lapse di nuvole sopra montagne innevate all'alba"

  }
}
```

## Gestione degli errori

Quando si verifica un problema con la richiesta, l'API restituirà il codice di errore corrispondente e la spiegazione, i più comuni sono:

- `400`: i parametri della richiesta sono errati, ad esempio manca `prompt` o il valore di `aspect_ratio` è illegale.
- `401`: autenticazione fallita, token non valido o non corrispondente all'API.
- `403`: saldo insufficiente, o il messaggio di richiesta ha colpito la revisione dei contenuti ed è stato rifiutato.
- `500`: errore interno del server o fallimento della generazione upstream.
