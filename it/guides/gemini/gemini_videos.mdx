Questo documento illustra le istruzioni per l'integrazione con Gemini Videos Generation API, che consente di generare video Google Gemini (omni-flash) tramite input di prompt testuali (e opzionalmente immagini di riferimento).

## Procedura di richiesta

Per utilizzare l'API, è necessario prima richiedere il servizio corrispondente sulla pagina [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos). Una volta entrati nella pagina, cliccare sul pulsante "Acquire", come mostrato nell'immagine:

![](https://cdn.acedata.cloud/q6ytrc.png)

Se non si è ancora effettuato l'accesso o la registrazione, si verrà automaticamente reindirizzati alla pagina di login per registrarsi e accedere. Dopo il login, si tornerà automaticamente alla pagina corrente.

Alla prima richiesta si riceverà un credito gratuito per utilizzare l'API senza costi.

## Utilizzo base

Innanzitutto, vediamo il modo base di utilizzo: inserendo il prompt `prompt`, il modello `model` e il rapporto d'aspetto `aspect_ratio`, è possibile generare il video corrispondente.

Qui impostiamo gli header della richiesta, tra cui:

- `accept`: il formato di risposta desiderato, qui impostato su `application/json` (formato JSON).
- `authorization`: la chiave per chiamare l'API, selezionabile dopo la richiesta.

Inoltre, impostiamo il corpo della richiesta (Request Body), che include:

- `prompt`: testo descrittivo del contenuto video da generare, **obbligatorio**.
- `model`: modello per generare il video, attualmente supporta solo `omni-flash`, che è anche il valore predefinito.
- `aspect_ratio`: rapporto d'aspetto del video, opzionale tra `16:9` (orizzontale) o `9:16` (verticale), predefinito `16:9`.
- `image_urls`: array opzionale di link a immagini (o video) di riferimento per guidare la generazione video; voci vuote verranno ignorate.
- `callback_url`: URL per callback asincrono; se impostato, l'API restituisce immediatamente `task_id` e al completamento del task invia il risultato tramite POST a questo URL.

Cliccando su "Try" si può testare la chiamata, ottenendo un risultato simile al seguente:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Il risultato restituito contiene diversi campi, descritti come segue:

- `success`: indica se la richiesta di generazione video è andata a buon fine.
- `task_id`: ID del task di generazione video.
- `trace_id`: ID di tracciamento della richiesta, utile per debug.
- `data`: lista dei risultati video generati.
  - `id`: identificativo univoco del video generato.
  - `video_url`: URL del video generato.
  - `state`: stato del task di generazione video, può essere `pending` / `succeeded` / `failed`.

Basterà utilizzare il link `video_url` presente in `data` per ottenere il video generato.

Il codice CURL corrispondente è il seguente:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Il codice Python corrispondente è il seguente:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Generazione video da immagini

Se si desidera generare un video basato su immagini di riferimento, è possibile passare uno o più URL di immagini in `image_urls` per guidare la generazione video:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## Callback asincrono

La generazione video richiede un certo tempo di elaborazione. Se non si desidera mantenere una connessione aperta in attesa, si può passare `callback_url`; in questo caso l'API restituirà immediatamente `task_id` e, al completamento del task, invierà il risultato finale tramite POST a tale URL:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Il risultato restituito immediatamente sarà:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Consultazione dello stato del task

Se si utilizza il callback asincrono o si desidera interrogare attivamente lo stato del task, è possibile utilizzare la [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) per ottenere lo stato e il risultato aggiornato tramite `task_id`.

## Gestione degli errori

In caso di problemi nella richiesta, l'API restituisce un codice di errore e una descrizione. I più comuni sono:

- `400`: parametri della richiesta errati, ad esempio mancanza di `prompt` o valore non valido per `aspect_ratio`.
- `401`: autenticazione fallita, token non valido o non corrispondente all'API.
- `403`: saldo insufficiente o prompt rifiutato per violazione delle policy di contenuto.
- `500`: errore interno del server o fallimento nella generazione upstream.
