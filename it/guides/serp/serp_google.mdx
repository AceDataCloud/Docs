Google SERP (Search Engine Results Page) è la pagina dei risultati che gli utenti vedono dopo aver inserito una query nel motore di ricerca Google. Mostra risultati di ricerca organici, annunci, snippet in evidenza, knowledge graph e vari contenuti come immagini e video, con l'obiettivo di fornire agli utenti le informazioni più pertinenti.

Questo articolo presenterà nel dettaglio l'API Google SERP, che può fornire i risultati ottenuti inserendo una query nel motore di ricerca Google; anche il contenuto dei risultati include molti tipi, come snippet in evidenza, knowledge graph e immagini, tra gli altri risultati.

Questo documento presenterà la guida all'integrazione dell'API Google SERP.

## Procedura di richiesta

Per utilizzare l'API Google SERP, per prima cosa vai alla [console di Ace Data Cloud](https://platform.acedata.cloud/console/applications) per ottenere il tuo API Token, da conservare come riserva.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se non hai ancora effettuato l'accesso o la registrazione, verrai automaticamente reindirizzato alla pagina di accesso per invitarti a registrarti e ad accedere; una volta completato, tornerai automaticamente alla pagina corrente.

**Un solo API Token può chiamare tutti i servizi della piattaforma, senza necessità di richiederne uno separatamente per ogni servizio.** Alla prima richiesta verrà assegnato un credito gratuito, che consente una prova gratuita; quando il credito è insufficiente, puoi ricaricare il saldo universale nella [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentazione completa: [Google SERP API →](https://platform.acedata.cloud/documents/serp-google)

## Utilizzo di base

Inserisci una parola chiave e il tipo di risorsa di ricerca per ottenere i risultati: usa `query` per passare la parola chiave e `type` per selezionare tipi di ricerca come pagine web, immagini e notizie; questa interfaccia non richiede di passare `model`.

Ad esempio, per cercare: informazioni su “apple inc”, possiamo quindi compilare il contenuto corrispondente nell'interfaccia, come mostrato nell'immagine:

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

Qui possiamo vedere che abbiamo impostato i Request Headers, inclusi:

- `accept`: il formato della risposta che si desidera ricevere; qui viene compilato come `application/json`, ovvero il formato JSON.
- `authorization`: la chiave per chiamare l'API, che dopo la richiesta può essere selezionata direttamente dal menu a discesa.

Sono inoltre stati impostati i Request Body, inclusi:

- `type`: il tipo di risorsa di ricerca; attualmente sono supportati solo sei tipi e il valore predefinito è `search`.
- `query`: la parola chiave della ricerca.
- `country`: il paese in cui si trovano i risultati di ricerca personalizzati; il valore predefinito sono gli Stati Uniti (US).
- `language`: la lingua dei risultati di ricerca personalizzati; il valore predefinito è l'inglese (en).
- `range`: l'intervallo di tempo dei risultati di ricerca personalizzati; il valore predefinito è senza limitazioni.
- `number`: la dimensione della pagina di paginazione dei risultati di ricerca personalizzati; il valore predefinito è 10.
- `page`: il numero di pagina della paginazione dei risultati di ricerca personalizzati; il valore predefinito è 1.

Inoltre, se si desidera generare il codice di integrazione corrispondente, è possibile copiarlo e generarlo direttamente; ad esempio, il codice CURL è il seguente:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc"
}'
```

Il codice di integrazione Python è il seguente:

```python
import requests

url = "https://api.acedata.cloud/serp/google"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "query": "apple inc"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Tipo di ricerca personalizzato

Se si personalizza il tipo di risorse di ricerca, possiamo modificare il parametro `type`, che include rispettivamente risorse normali `search`, risorse di immagini `images`, risorse di notizie `news`, risorse di mappe `maps`, risorse locali `places` e risorse video `videos`; in questo articolo verrà fornito un esempio con le risorse video `videos`.

Di seguito, mostreremo le operazioni specifiche.

Innanzitutto, impostare il parametro `type` su `videos` e passare normalmente il parametro `query`, come mostrato nell'immagine:
<p><img src="https://cdn.acedata.cloud/czlt12.png" width="500" className="m-auto" /></p>

Il codice corrispondente è il seguente:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "videos",
  "query": "apple inc"
}'
```

## Lingua personalizzata dei risultati di ricerca
Possiamo anche personalizzare la lingua dei risultati di ricerca. <p><img src="https://cdn.acedata.cloud/yyrssp.png" width="500" className="m-auto" /></p>

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "news",
  "query": "apple inc",
  "language": "zh-cn"
```

## Intervallo temporale personalizzato dei risultati di ricerca
Questo articolo consente inoltre di personalizzare l'intervallo di tempo dei risultati di ricerca, includendo cinque tipi, ovvero `qdr:h` (l'ultima ora), `qdr:d` (l'ultimo giorno), `qdr:w` (l'ultima settimana), `qdr:m` (l'ultimo mese), e nessuna limitazione per impostazione predefinita. Possiamo trasmettere l'intervallo di tempo corrispondente tramite `range`; ad esempio, qui è impostato su `qdr:d`, che indica la ricerca dei risultati dell'ultimo giorno, quindi l'input è il seguente:

<p><img src="https://cdn.acedata.cloud/qccfib.png" width="500" className="m-auto" /></p>

Il codice corrispondente è il seguente:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "range": "qdr:d",
  "query": "apple inc"
}'
```
