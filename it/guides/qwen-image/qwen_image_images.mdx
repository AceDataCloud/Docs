---
title: "API per la generazione e modifica di immagini Qwen"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` consente di completare la generazione di immagini e la modifica di 1–3 immagini di riferimento tramite lo stesso endpoint, supportando `qwen-image-3.0` e `qwen-image-3.0-pro`.

## Seleziona modello

| Modello                | Scenari adatti       | Prezzo standard ufficiale       |
| --------------------- | ------------------ | -------------------------- |
| `qwen-image-3.0`      | Creazione in massa, iterazione rapida | Output $0.030/imagine       |
| `qwen-image-3.0-pro`  | Impaginazione complessa, alta precisione | 1K $0.040/imagine; 2K $0.075/imagine |

Le immagini di riferimento vengono addebitate in base al numero reale di input, prezzo standard ufficiale $0.003/imagine.

## Generazione sincronizzata

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "Un semplice cerchio rosso centrato su uno sfondo bianco pulito.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

La risposta di successo include l'indirizzo dell'immagine CDN permanente, l'uso reale e il costo di questa operazione:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Modifica delle immagini di riferimento

Aggiungere `image_urls`, supporta 1–3 immagini accessibili pubblicamente:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "Mantieni il soggetto, cambia lo sfondo in uno stile poster caldo**###**",
  "image_urls": ["https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` è utilizzato solo per la generazione di immagini. L'intervallo di `n` è da 1 a 6; il rapporto di aspetto deve essere compreso tra 1:8 e 8:1.

## Compiti asincroni

Impostando `async: true`, l'endpoint restituisce immediatamente `task_id`. Utilizzare `/qwen-image/tasks` per interrogare lo stato finale, o fornire `callback_url` per ricevere notifiche di completamento. La generazione viene addebitata una sola volta, la query del compito non comporta costi ripetuti.
