---
title: "API di generazione e modifica Qwen Image"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` completa tramite la stessa interfaccia sia la generazione da testo a immagine sia la modifica con 1–3 immagini di riferimento, supportando `qwen-image-3.0` e `qwen-image-3.0-pro`.

## Selezione del modello

| Modello                   | Scenari adatti       | Prezzo standard ufficiale                   |
| -------------------- | ---------- | ----------------------- |
| `qwen-image-3.0`     | Creazione in batch, iterazione rapida  | Output $0.030/immagine             |
| `qwen-image-3.0-pro` | Impaginazione complessa, risultati finali ad alta precisione | 1K $0.040/immagine; 2K $0.075/immagine |

Le immagini di riferimento vengono fatturate in base alla quantità effettivamente inserita, al prezzo standard ufficiale di $0.003/immagine.

## Generazione sincrona

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "A simple red circle centered on a clean white background.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

La risposta riuscita include l'indirizzo permanente dell'immagine CDN, l'usage effettivo e il costo di questa richiesta:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Modifica con immagini di riferimento

Aggiungere `image_urls`, supporta 1–3 immagini pubblicamente accessibili:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "保留主体，将背景改成暖色电影海报风格",
  "image_urls": ["https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` è utilizzato solo per la generazione da testo a immagine. L'intervallo di `n` è 1–6; il rapporto larghezza-altezza deve essere compreso tra 1:8 e 8:1.

## Attività asincrone

Dopo aver impostato `async: true`, l'interfaccia restituisce immediatamente `task_id`. Utilizzare `/qwen-image/tasks` per interrogare lo stato finale, oppure passare `callback_url` per ricevere la notifica di completamento. La generazione viene addebitata una sola volta e le interrogazioni dell'attività non vengono fatturate ripetutamente.
