---
title: "Guida all'integrazione dell'API Qwen Image"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` supporta `qwen-image-3.0` e `qwen-image-3.0-pro` per la generazione di immagini e l'editing di 1–3 immagini di riferimento.

## Generazione di immagini

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen-image-3.0","prompt":"Un poster tecnologico minimalista","size":"1024*1024","n":1}'
```

## Editing delle immagini

Aggiungere `image_urls` nella stessa richiesta, supporta 1–3 immagini pubbliche:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "Mantieni il soggetto, cambia in uno stile poster caldo**###**",
  "image_urls": ["https://cdn.acedata.cloud/r9vsv9.png"],
  "size": "2048*2048",
  "prompt_extend": true,
  "prompt_extend_mode": "direct",
  "enable_thinking": true,
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` supporta solo la generazione di immagini. `n` varia da 1 a 6. La dimensione totale in pixel dell'output deve essere compresa tra 512×512 e 2048×2048, con un rapporto d'aspetto da 1:8 a 8:1.

## Chiamata asincrona

Impostare `async: true` per ottenere immediatamente `task_id`; è possibile anche fornire `callback_url` per ricevere il risultato finale. Una volta completato, è possibile consultare tramite `/qwen-image/tasks`.

La risposta di successo include `data[].image_url`, `usage`, `task_id` e `trace_id`. I link delle immagini verranno trasferiti al CDN di Ace Data Cloud quando possibile. Esempi di risposta reale saranno forniti dopo la verifica E2E in produzione.
