---
title: "Guida all'integrazione dell'API per il compito Qwen Image"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

Utilizzare `POST https://api.acedata.cloud/qwen-image/tasks` per interrogare i compiti di generazione di immagini asincroni. Questa interfaccia di query è gratuita.

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Per la query in batch, utilizzare `action=retrieve_batch` e l'array `ids`. Dopo il successo del compito, `response.data` contiene l'indirizzo permanente delle immagini generate e l'uso effettivo.
