---
title: "Qwen Image Task Query API"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/tasks` è utilizzato per interrogare, interrogare in batch o eliminare i compiti asincroni di Qwen Image. Questa interfaccia non genera un consumo API aggiuntivo.

## Interrogare un singolo compito

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Dopo il completamento del compito, `response.data` contiene l'indirizzo dell'immagine CDN permanente, `response.usage` contiene il numero reale di input/output, e `response.cost` è le informazioni di fatturazione per il compito generato.

## Interrogazione in batch

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Restituisce `{ "items": [...], "count": 2 }`. L'interrogazione della lista supporta anche il filtraggio per utente, applicazione e intervallo di tempo di creazione.

## Eliminare la registrazione del compito

```json
{"action":"delete","id":"TASK_ID"}
```

L'eliminazione influisce solo sulla cronologia dei compiti, non eliminerà i file CDN già generati.
