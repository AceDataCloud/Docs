Claude Code è uno strumento di **Agentic Coding** lanciato da Anthropic, ed è considerato uno dei più potenti agenti di programmazione al mondo. Claude Code offre un plugin specifico per JetBrains IDE, supportando l'intera gamma di JetBrains IDE come IntelliJ IDEA, PyCharm, WebStorm, GoLand, PhpStorm, Android Studio, ecc.

Questo documento descrive principalmente come configurare e utilizzare Claude Code in JetBrains IDE tramite il servizio proxy di AceData Cloud.

## Processo di richiesta

Per utilizzare Claude Code, puoi prima visitare la [pagina del servizio Claude Messages](https://platform.acedata.cloud/documents/claude-messages) e cliccare sul pulsante "Acquire" per ottenere le credenziali necessarie per la richiesta:

![](https://cdn.acedata.cloud/nyq0xz.png)

Se non hai ancora effettuato il login o la registrazione, verrai automaticamente reindirizzato alla pagina di login per registrarti e accedere. Dopo aver effettuato il login, verrai riportato automaticamente a questa pagina.

Al primo accesso, verrà offerto un credito gratuito per provare il servizio Claude Code.

## Installazione

### Requisiti

Il plugin Claude Code per JetBrains dipende da Claude Code CLI, assicurati prima di aver installato il CLI:

```bash
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# Oppure usa Homebrew
brew install claude-code
```

Dopo l'installazione, puoi verificare:

```bash
claude --version
```

### Installazione del plugin

![Plugin Claude Code nel JetBrains Marketplace](https://cdn.acedata.cloud/de78fd305b.png)

1. Apri JetBrains IDE
2. Vai su **Settings** → **Plugins** → **Marketplace**
3. Cerca **Claude Code**
4. Clicca su **Install** per installare il plugin
5. Riavvia l'IDE

Oppure visita direttamente il [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/27310-claude-code-beta-) per installarlo online.

> **Importante**: Dopo aver installato il plugin, è necessario **riavviare completamente l'IDE** (potrebbe essere necessario riavviare più volte) affinché abbia effetto.

## Configurazione dell'API AceData Cloud

Il plugin Claude Code per JetBrains esegue il comando `claude` tramite il terminale integrato, quindi la configurazione delle variabili d'ambiente è la stessa del CLI.

### Passo 1: Creare config.json

Crea il file di configurazione per Claude Code:

| Sistema            | Percorso                                   |
| ----------------- | ------------------------------------ |
| **macOS / Linux** | `~/.claude/config.json`              |
| **Windows**       | `C:\Users\{nome_utente}\.claude\config.json` |

Scrivi il seguente contenuto in questo file e salvalo:

```json
{
  "primaryApiKey": "self"
}
```

Comando rapido per creare su macOS / Linux:

```bash
mkdir -p ~/.claude && echo '{"primaryApiKey": "self"}' > ~/.claude/config.json
```

### Passo 2: Configurare le variabili d'ambiente

**Metodo 1: Impostare nel file di configurazione della Shell (consigliato)**

Aggiungi il seguente contenuto al tuo `~/.zshrc` o `~/.bashrc`, sostituendo `{token}` con il tuo token API:

```bash
# AceData Cloud - Configurazione proxy Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Dopo la modifica, esegui `source ~/.zshrc` per rendere effettive le configurazioni, quindi **riavvia JetBrains IDE**.

**Metodo 2: Impostare in settings.json di Claude Code**

Modifica `~/.claude/settings.json` (crea se non esiste):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Nota**: Il token API può essere visualizzato nel [pannello di controllo di AceData Cloud](https://platform.acedata.cloud/console).

## Uso di base

### Avvio dal terminale integrato dell'IDE

Apri il terminale integrato di JetBrains IDE e esegui:

```bash
claude
```

Quando esegui nel terminale integrato dell'IDE, tutte le funzionalità integrate (visualizzazione Diff, selezione del contesto, ecc.) si attiveranno automaticamente.

### Connessione da un terminale esterno

Se esegui Claude Code in un terminale esterno, puoi utilizzare il comando `/ide` per connetterti a JetBrains IDE:

```bash
claude
> /ide
```

Assicurati di avviare Claude Code dallo stesso percorso della radice del progetto IDE, in modo che Claude possa accedere allo stesso insieme di file.

### Scorciatoie da tastiera

| Scorciatoia                                         | Funzione                      |
| ------------------------------------------------ | ----------------------- |
| `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux)        | Apri rapidamente Claude Code        |
| `Cmd+Option+K` (Mac) / `Alt+Ctrl+K` (Windows/Linux) | Inserisci riferimento al file (es. `@File#L1-99`) |

### Funzionalità integrate

Il plugin Claude Code per JetBrains offre le seguenti funzionalità integrate:

- **Visualizzazione Diff**: le modifiche al codice vengono mostrate direttamente nel visualizzatore Diff dell'IDE
- **Selezione del contesto**: il codice e le schede attualmente selezionati vengono automaticamente condivisi con Claude
- **Riferimenti ai file**: utilizza le scorciatoie per citare rapidamente file e numeri di riga
- **Condivisione dei diagnostici**: le informazioni diagnostiche come Lint, errori di sintassi, ecc. nell'IDE vengono automaticamente condivise con Claude

## Impostazioni del plugin

Puoi configurare in **Settings** → **Tools** → **Claude Code [Beta]**:

| Impostazione                       | Descrizione                                         |
| ----------------------------- | ------------------------------------------ |
| **Claude command**            | Percorso del comando Claude personalizzato (es. `/usr/local/bin/claude`) |
| **Enable automatic updates**  | Controlla e installa automaticamente gli aggiornamenti del plugin                                |
| **Enable using Option+Enter** | Usa Option+Enter per andare a capo nella finestra di dialogo su macOS             |

### Configurazione per utenti WSL

Se utilizzi in un ambiente WSL, devi impostare il comando Claude come:

```
wsl -d Ubuntu -- bash -lic "claude"
```

(sostituisci `Ubuntu` con il nome della tua distribuzione WSL)

## Domande frequenti

### Cosa fare se la connessione fallisce?

1. Controlla se il file `~/.claude/config.json` è stato creato correttamente
2. Assicurati che le variabili d'ambiente siano impostate correttamente
3. Verifica che il token API sia valido (puoi controllarlo nel [pannello di controllo](https://platform.acedata.cloud/console))
4. Riavvia JetBrains IDE e riprova

### Cosa fare se il plugin non funziona?

1. Assicurati di eseguire Claude Code dalla radice del progetto
2. Controlla se il plugin è abilitato nelle impostazioni dell'IDE
3. Riavvia completamente l'IDE (potrebbe essere necessario riavviare più volte)
4. Se utilizzi la modalità di sviluppo remoto, assicurati che il plugin sia installato sull'host remoto (Settings → Plugin (Host))

### Cosa fare se l'IDE non viene rilevato?

1. Assicurati che il plugin sia installato e abilitato
2. Riavvia l'IDE
3. Assicurati di eseguire Claude Code nel terminale integrato
4. Gli utenti WSL possono consultare la [guida alla risoluzione dei problemi WSL](https://code.claude.com/docs/en/troubleshooting#jetbrains-ide-not-detected-on-wsl2)

### command not found

Se cliccando sull'icona di Claude ricevi il messaggio "command not found":

1. Verifica che il CLI sia installato: `which claude`
2. Configura il percorso completo del comando Claude nelle impostazioni del plugin
3. Gli utenti WSL devono utilizzare il formato di comando WSL sopra indicato
### Come controllare il saldo rimanente?

Accedi al [Pannello di controllo di AceData Cloud](https://platform.acedata.cloud/console) per visualizzare il saldo rimanente e l'utilizzo attuale del tuo account.
