## 1. Ottenere la chiave API

Aprire l'[elenco delle applicazioni di Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedere alle applicazioni disponibili e copiare la chiave API.

![Ottenere la chiave API di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installare CLI e plugin

Iniziare installando Claude Code CLI.

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

Poi installare il plugin **Claude Code** dal JetBrains Marketplace e riavviare l'IDE. Il plugin chiama il comando `claude` locale; se viene visualizzato un messaggio che indica che il comando non è stato trovato, compilare il percorso completo in **Settings → Tools → Claude Code**.

## 3. Configurare Ace Data Cloud

Impostare nell'ambiente di avvio del backend di JetBrains.

macOS / Linux / WSL:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="la tua chiave API"
unset ANTHROPIC_API_KEY
```

Windows PowerShell:

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "la tua chiave API"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

È possibile utilizzare anche il file `.claude/settings.local.json` ignorato nel progetto:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "la tua chiave API"
  }
}
```

Per lo sviluppo remoto, è necessario configurare e installare il plugin sull'host remoto; gli utenti WSL possono impostare il comando Claude come `wsl -d Ubuntu -- bash -lic "claude"`.

## 4. Verifica

Eseguire `claude` dal terminale integrato dell'IDE, oppure avviare un terminale esterno e digitare `/ide`. Dopo una connessione riuscita, far rispondere Claude con `OK`, quindi leggere un file di test e controllare la richiesta nella [cronologia utilizzi](https://platform.acedata.cloud/console/usages) di Ace Data Cloud.

Se il plugin non si avvia, eseguire prima `claude --version` nello stesso terminale; se si riceve un errore 401, controllare le variabili ambientali effettivamente ereditate dal backend e la vecchia `ANTHROPIC_API_KEY`.
