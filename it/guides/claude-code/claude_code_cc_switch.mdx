## 1. Ottenere la API Key

Apri [l'elenco delle applicazioni di Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedi alle applicazioni disponibili e copia la API Key.

![Ottenere la API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installare CC Switch

Scarica da [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), funziona anche su macOS:

```bash
brew install --cask cc-switch
```

## 3. Aggiungere Provider

Apri CC Switch, seleziona **Claude Code → Aggiungi Provider → Personalizzato**, compila:

| Campo       | Valore                        |
| ----------- | ----------------------------- |
| Nome        | `Ace Data Cloud`             |
| URL di base | `https://api.acedata.cloud`  |
| API Key     | La API Key appena copiata     |
| Formato API | `Messaggi Antropici`         |

Se desideri utilizzare l'editor JSON, configuralo come segue:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

CC Switch scriverà la configurazione nelle impostazioni utente di Claude Code. Non salvare la chiave reale nel repository di squadra e non mantenere contemporaneamente la vecchia `ANTHROPIC_API_KEY`.

## 4. Abilitare e verificare

Dopo aver salvato, abilita **Ace Data Cloud**, riapri Claude Code. Invia un semplice compito in sola lettura e controlla le chiamate in [Cronologia utilizzo](https://platform.acedata.cloud/console/usages). Se dopo il passaggio continui a utilizzare la vecchia configurazione, esci completamente da Claude Code e CC Switch e riprova.
