Claude Code è uno strumento di programmazione lanciato da Anthropic, ed è considerato uno dei più potenti agenti di programmazione al mondo. L'estensione di Claude Code per VS Code offre un'interfaccia grafica nativa ed è il modo consigliato per utilizzare Claude Code in VS Code.

Questo documento descrive principalmente come configurare e utilizzare l'estensione di Claude Code in VS Code tramite il servizio proxy di Ace Data Cloud.

## Processo di richiesta

Per utilizzare Claude Code, prima di tutto puoi andare al [pannello di controllo di Ace Data Cloud](https://platform.acedata.cloud/console/applications) per ottenere il tuo API Token, da tenere come riserva.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se non hai ancora effettuato il login o la registrazione, verrai automaticamente reindirizzato alla pagina di login che ti invita a registrarti e accedere; dopo aver effettuato il login o la registrazione, verrai riportato automaticamente a questa pagina.

Alla prima richiesta, verrà offerto un credito gratuito, permettendoti di provare il servizio di Claude Code senza costi.

## Installazione del plugin Claude Code

Cerca **Claude Code** nel marketplace delle estensioni di VS Code, e dopo aver confermato che il publisher è **Anthropic**, procedi con l'installazione. Una volta completata l'installazione, apparirà un'icona di accesso a Claude Code nella barra delle attività.

## Configurazione dell'API di Ace Data Cloud

La prima volta che apri il plugin, ti verrà chiesto di accedere all'account ufficiale di Anthropic. Possiamo saltare il login ufficiale e utilizzare l'API proxy di Ace Data Cloud, senza necessità di un abbonamento ufficiale.

L'estensione e il terminale CLI leggono la stessa serie di impostazioni di Claude Code. Per informazioni complete su autenticazione, gestione dei conflitti di credenziali e configurazione globale, consulta il [tutorial di configurazione del terminale di Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration). Se desideri che le impostazioni siano valide solo per il progetto attuale, crea un file `.claude/settings.local.json` nella directory principale del progetto, che sia incluso in `.gitignore`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Dove `{token}` è la chiave API che hai appena copiato. Se nell'ambiente in cui avvii VS Code esiste già un vecchio `ANTHROPIC_API_KEY`, assicurati di eseguire `unset ANTHROPIC_API_KEY` in quell'ambiente; non considerare una stringa vuota come pulizia e non inserire la chiave reale nel file `.claude/settings.json` condiviso con il team.

Di seguito è riportata la configurazione completata su un sistema locale utilizzando VS Code 1.136.1 e l'estensione Claude Code 2.1.251. Gli screenshot utilizzano una chiave segnaposto per evitare la divulgazione di credenziali reali:

![Configurazione di Ace Data Cloud Claude Code in VS Code](https://cdn.acedata.cloud/f925e9e9597b.png)

Dopo aver completato la configurazione, riavvia VS Code.

> Nota: la configurazione sopra è valida solo per il progetto attuale e si consiglia di aggiungere il percorso del file di configurazione `.claude/settings.local.json` a `.gitignore` per evitare che venga caricato nel repository remoto.

Se desideri che la configurazione sia valida per tutti i progetti, puoi direttamente inserire la configurazione nella directory utente. Il percorso corrispondente è `~/.claude/settings.json`,

> Nota: dopo aver completato la configurazione, riavvia o ricarica VS Code affinché le impostazioni abbiano effetto.

## Uso di base

Dopo aver configurato, invia un semplice compito di sola lettura nel pannello di Claude Code, ad esempio "leggi README.md e riassumi in una frase". Dopo il successo del compito, puoi controllare questa chiamata nella [cronologia utilizzi](https://platform.acedata.cloud/console/usages).

## Come controllare il credito residuo

Puoi controllare il credito residuo attuale accedendo alla [console di Ace Data Cloud - elenco applicazioni](https://platform.acedata.cloud/console/applications).

Puoi visualizzare tutta la cronologia degli utilizzi e i dettagli delle spese nella [console di Ace Data Cloud - cronologia utilizzi](https://platform.acedata.cloud/console/usages).
