Claude Code è uno strumento di **Agentic Coding** lanciato da Anthropic, ed è considerato uno dei più potenti agenti di programmazione al mondo. Il terminale CLI è l'esperienza centrale di Claude Code, puoi eseguire il comando `claude` in qualsiasi terminale e collaborare alla programmazione con l'AI attraverso il linguaggio naturale.

Questo documento descrive principalmente come installare, configurare e utilizzare Claude Code CLI tramite il servizio proxy di AceData Cloud.

## Processo di richiesta

Per utilizzare Claude Code, puoi prima andare alla [pagina del servizio Claude Messages](https://platform.acedata.cloud/documents/claude-messages) e cliccare sul pulsante "Acquire" per ottenere le credenziali necessarie per la richiesta:

![](https://cdn.acedata.cloud/nyq0xz.png)

Se non hai ancora effettuato il login o la registrazione, verrai automaticamente reindirizzato alla pagina di login che ti invita a registrarti e accedere; dopo aver effettuato il login, verrai riportato automaticamente a questa pagina.

Alla prima richiesta, verrà offerto un credito gratuito per provare il servizio Claude Code.

## Installazione di Claude Code

### Requisiti di sistema

- macOS, Linux o Windows (incluso WSL)
- Node.js non è necessario, il metodo di installazione nativo gestirà automaticamente le dipendenze

### Metodi di installazione

Claude Code supporta diversi metodi di installazione:

**Metodo 1: Installazione nativa (consigliata)**

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows CMD:

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**Metodo 2: Homebrew (macOS / Linux)**

```bash
brew install claude-code
```

**Metodo 3: WinGet (Windows)**

```cmd
winget install Claude.ClaudeCode
```

L'installazione nativa si aggiornerà automaticamente in background, mantenendo sempre l'ultima versione.

## Configurazione dell'API AceData Cloud

Dopo l'installazione, ti verrà chiesto di accedere al tuo account ufficiale Anthropic. Possiamo utilizzare le variabili d'ambiente per configurare l'API proxy di AceData Cloud, **senza necessità di abbonamento ufficiale**.

### Configurazione delle variabili d'ambiente

Ci sono due modi per configurare le variabili d'ambiente, puoi scegliere uno dei due.

**Metodo 1: Impostare nel file di configurazione della Shell (consigliato)**

Aggiungi il seguente contenuto al tuo file di configurazione della Shell (`~/.zshrc`, `~/.bashrc` o `~/.bash_profile`), sostituendo `{token}` con il token API ottenuto dalla console di AceData Cloud:

```bash
# AceData Cloud - Configurazione proxy di Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Dopo aver modificato, esegui il seguente comando per rendere effettive le configurazioni:

```bash
source ~/.zshrc  # o source ~/.bashrc
```

**Metodo 2: Impostare nel settings.json di Claude Code**

Modifica `~/.claude/settings.json` (crealo se non esiste) e aggiungi la configurazione `env`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Il vantaggio di questo metodo è che le variabili d'ambiente influenzano solo Claude Code e non altri programmi.

> **Suggerimento**: Il token API può essere visualizzato nella [console di AceData Cloud](https://platform.acedata.cloud/console). Il valore di `ANTHROPIC_AUTH_TOKEN` verrà automaticamente preceduto dal prefisso `Bearer` quando inviato al server.

## Iniziare a usare

### Avviare la modalità interattiva

Apri il terminale, vai nella directory del tuo progetto e poi esegui:

```bash
cd /path/to/your/project
claude
```

Vedrai la schermata di benvenuto di Claude Code, puoi iniziare a interagire semplicemente digitando in linguaggio naturale.

### Comandi comuni

| Comando            | Descrizione          | Esempio                   |
| ------------------ | ------------------- | ------------------------- |
| `claude`           | Avvia la modalità interattiva | `claude`                 |
| `claude "compito"` | Esegui un compito una tantum | `claude "correggi l'errore di build"` |
| `claude -p "query"` | Esegui una query e esci | `claude -p "spiega questa funzione"` |
| `claude -c`       | Continua l'ultima conversazione nella directory corrente | `claude -c`              |
| `claude -r`       | Ripristina la conversazione precedente | `claude -r`              |
| `claude commit`    | Crea un commit Git   | `claude commit`          |

### Comandi in modalità interattiva

In modalità interattiva, puoi utilizzare i seguenti comandi integrati:

| Comando            | Funzione            |
| ------------------ | ------------------- |
| `/help`            | Mostra informazioni di aiuto |
| `/clear`           | Pulisce la cronologia della conversazione |
| `/config`          | Apre il pannello delle impostazioni |
| `/model`           | Cambia modello      |
| `/mcp`             | Gestisci il servizio MCP |
| `/compact`         | Comprimi il contesto |
| `/memory`          | Gestisci la memoria  |
| `/login`           | Cambia account      |
| `exit` o `Ctrl+C` | Esci                |

### Esempi di interazione

```bash
# Analisi del progetto
> cosa fa questo progetto?

# Correzione di bug
> c'è un bug in cui gli utenti possono inviare moduli vuoti - correggilo

# Scrittura di test
> scrivi test unitari per le funzioni del calcolatore

# Rifattorizzazione del codice
> rifattorizza il modulo di autenticazione per utilizzare async/await

# Operazioni Git
> committa le mie modifiche con un messaggio descrittivo
> crea una pr per questa funzionalità
```

## Uso avanzato

### Pipe e scripting

Claude Code segue la filosofia Unix, supportando operazioni di pipe e scripting:

```bash
# Monitora i log e invia avvisi automatici
tail -f app.log | claude -p "se viene trovata un'anomalia, avvisami"

# Traduzione automatica di nuovi testi
claude -p "se ci sono nuove stringhe di testo, traducile in francese e crea una PR"

# Revisione del codice
git diff main | claude -p "revisione di queste modifiche"
```

### Riferimento delle variabili d'ambiente

Di seguito sono riportate alcune delle variabili d'ambiente comunemente supportate da Claude Code:

| Variabile                       | Descrizione                                    |
| ------------------------------- | ---------------------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`         | Valore personalizzato per l'intestazione Authorization (prefisso Bearer aggiunto automaticamente) |
| `ANTHROPIC_API_KEY`            | Chiave API (inviata come intestazione X-Api-Key) |
| `ANTHROPIC_BASE_URL`           | URL di base dell'API                          |
| `ANTHROPIC_MODEL`              | Sovrascrive il modello predefinito            |
| `ANTHROPIC_SMALL_FAST_MODEL`   | Modello di livello Haiku (per attività in background) |
| `MAX_THINKING_TOKENS`          | Imposta il budget per i token di pensiero (impostato a 0 disabilita la modalità di pensiero) |
| `DISABLE_COST_WARNINGS`        | Impostato a 1 per disabilitare gli avvisi sui costi |

### Memoria del progetto CLAUDE.md

Crea un file `CLAUDE.md` nella directory principale del progetto per fornire istruzioni e contesto specifici per il progetto a Claude Code. Claude caricherà automaticamente questo file all'avvio.

```markdown
# Descrizione del progetto
Questo è un progetto full-stack Django + Vue.js.

## Standard di codifica
- Utilizzare Python 3.12
- Seguire lo stile di codice PEP 8
- Tutti gli API devono avere test unitari
```

## Domande frequenti

### Cosa fare se la connessione fallisce?
1. Controlla se il file `~/.claude/config.json` è stato creato correttamente, il contenuto deve essere `{"primaryApiKey": "self"}`
2. Conferma che le variabili d'ambiente siano state impostate correttamente:
   ```bash
   echo $ANTHROPIC_AUTH_TOKEN
   echo $ANTHROPIC_BASE_URL
   ```
3. Verifica che il token API sia valido (puoi controllarlo nella [console](https://platform.acedata.cloud/console))
4. Prova a riavviare il terminale

### comando non trovato: claude

Se dopo l'installazione appare `command not found`, prova a:

1. Chiudere e riaprire il terminale
2. Controllare il PATH: `echo $PATH`
3. Reinstallare: `curl -fsSL https://claude.ai/install.sh | bash`

### Come vedere il saldo rimanente?

Accedi alla [console di AceData Cloud](https://platform.acedata.cloud/console) per visualizzare il saldo rimanente e l'utilizzo attuale del tuo account.
