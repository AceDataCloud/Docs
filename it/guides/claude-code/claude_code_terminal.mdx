## 1. Ottenere la API Key

Apri [l'elenco delle applicazioni di Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedi alle applicazioni disponibili e copia la API Key.

![Ottenere la API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installare Claude Code

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
```

Controlla dopo l'installazione:

```bash
claude --version
```

## 3. Configurare Ace Data Cloud

Per uso globale, aggiungi le seguenti variabili a `~/.zshrc` o `~/.bashrc`:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="la tua API Key"
unset ANTHROPIC_API_KEY
```

Riavvia il terminale o esegui `source` sul file di configurazione corrispondente.

Se deve essere valido solo per il progetto corrente, puoi creare un `.claude/settings.local.json` già incluso in `.gitignore`:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "la tua API Key"
  }
}
```

Scegli una delle due modalità. Non scrivere la chiave reale nel `.claude/settings.json` condiviso dal team; se nell'ambiente esiste già `ANTHROPIC_API_KEY`, deve essere realmente annullato, non impostato come stringa vuota.

## 4. Avviare e verificare

```bash
cd /path/to/your/project
claude
```

Una volta entrato, invia un compito in sola lettura, come "leggi README.md e riassumi in una frase". I registri delle chiamate e il saldo possono essere visualizzati in [Storia d'uso](https://platform.acedata.cloud/console/usages) e [Elenco delle applicazioni](https://platform.acedata.cloud/console/applications).

Se restituisce 401, controlla se la chiave è completa, se il vecchio `ANTHROPIC_API_KEY` è stato annullato e riavvia completamente Claude Code. Il modello non deve essere fissato nella configurazione di accesso, può essere selezionato il modello attualmente disponibile in Claude Code.
