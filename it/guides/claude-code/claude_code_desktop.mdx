Claude Code è uno strumento di **Agentic Coding** lanciato da Anthropic, ed è considerato uno dei più potenti agenti di programmazione al mondo. L'applicazione desktop di Claude Code offre un'interfaccia grafica indipendente, supporta funzionalità come la revisione Diff, sessioni parallele (isolamento tramite Git Worktree), sessioni remote e altro, senza dipendere da alcun IDE.

Questo documento descrive principalmente come configurare e utilizzare Claude Code attraverso il servizio proxy di AceData Cloud.

> **Nota**: L'applicazione desktop di Claude Code è attualmente in fase di anteprima (Preview) e supporta solo macOS e Windows.

## Procedura di richiesta

Per utilizzare Claude Code, puoi prima visitare la [pagina del servizio Claude Messages](https://platform.acedata.cloud/documents/claude-messages) e fare clic sul pulsante "Acquire" per ottenere le credenziali necessarie per la richiesta:

![](https://cdn.acedata.cloud/nyq0xz.png)

Se non hai ancora effettuato il login o registrato, verrai automaticamente reindirizzato alla pagina di login per registrarti e accedere. Dopo aver effettuato il login o la registrazione, verrai riportato automaticamente alla pagina corrente.

Alla prima richiesta, verrà offerto un credito gratuito per provare il servizio Claude Code.

## Installazione dell'applicazione desktop

### Requisiti di sistema

- macOS (Intel e Apple Silicon) o Windows (x64 / ARM64)
- Linux non supporta attualmente l'applicazione desktop

### Download e installazione

Visita la [pagina di download ufficiale di Claude](https://claude.ai) per scaricare il pacchetto di installazione per la tua piattaforma:

- **macOS**: scarica il file `.dmg` e trascinalo nella cartella Applicazioni
- **Windows x64**: scarica il pacchetto di installazione `.exe` e segui le istruzioni
- **Windows ARM64**: scarica la versione ARM64 (nota: ARM64 non supporta sessioni locali, è necessario utilizzare sessioni remote)

![Pagina di download dell'applicazione desktop Claude](https://cdn.acedata.cloud/c3c8c57264.png)

Una volta completata l'installazione, avvia Claude dalla cartella Applicazioni (macOS) o dal menu Start (Windows).

## Configurazione dell'API AceData Cloud

Dopo aver avviato l'applicazione desktop, è necessario accedere con un account Anthropic. Possiamo utilizzare le variabili d'ambiente per configurare l'API proxy di AceData Cloud, **senza necessità di un abbonamento ufficiale**.

L'applicazione desktop legge le variabili d'ambiente dal tuo ambiente Shell, quindi è necessario impostarle nel file di configurazione della Shell.

### Configurazione delle variabili d'ambiente

**Utenti macOS**

Aggiungi il seguente contenuto a `~/.zshrc` (o `~/.bashrc`), sostituendo `{token}` con il tuo token API:

```bash
# AceData Cloud - Configurazione proxy Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Dopo aver salvato, esegui:

```bash
source ~/.zshrc
```

**Utenti Windows**

Aggiungi le seguenti variabili d'ambiente di sistema tramite "Proprietà di sistema → Avanzate → Variabili d'ambiente":

| Nome variabile            | Valore                           |
| ---------------------- | ----------------------------- |
| `ANTHROPIC_AUTH_TOKEN` | `{token}` (sostituisci con il tuo token API)     |
| `ANTHROPIC_BASE_URL`   | `https://api.acedata.cloud` |

Oppure utilizza PowerShell:

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**Puoi anche configurare tramite settings.json**

Modifica `~/.claude/settings.json` (crealo se non esiste):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Suggerimento**: Il token API può essere visualizzato nel [pannello di controllo di AceData Cloud](https://platform.acedata.cloud/console). Dopo aver completato la configurazione, è necessario **riavviare l'applicazione desktop** affinché le variabili d'ambiente abbiano effetto.

## Uso di base

### Aprire un progetto

1. Avvia l'applicazione desktop di Claude
2. Fai clic sulla scheda **Code** in alto
3. Seleziona la modalità di esecuzione **Local**
4. Fai clic su **Select folder** per scegliere la tua directory di progetto

### Iniziare una conversazione

Inserisci nella casella di input una descrizione in linguaggio naturale delle tue esigenze:

- "Trova i commenti TODO e correggili"
- "Aggiungi test alla funzione principale"
- "Spiega l'architettura di questo progetto"

Claude analizzerà il tuo codice sorgente, proporrà modifiche e mostrerà le variazioni in vista Diff.

### Modalità di autorizzazione

Cambia modalità utilizzando il selettore accanto al pulsante di invio:

| Modalità       | Descrizione                 |
| ----------- | ------------------------ |
| **Ask**     | Chiede conferma prima di ogni modifica (consigliato per i principianti)  |
| **Code**    | Accetta automaticamente le modifiche ai file, ma i comandi del terminale richiedono conferma |
| **Plan**    | Prima elabora un piano dettagliato in attesa di approvazione, esegue solo dopo conferma |

### Sessioni parallele

Fai clic su **+ New session** nella barra laterale per avviare più sessioni parallele. Per i repository Git, ogni sessione avrà una copia indipendente del progetto tramite Worktree, senza interferenze.

Il Worktree viene memorizzato per impostazione predefinita nella directory `~/.claude-worktrees/`.

### Revisione Diff

Quando Claude modifica i file, verrà visualizzata una statistica delle modifiche (ad esempio `+12 -1`), facendo clic si aprirà il visualizzatore Diff per esaminare le modifiche file per file. Puoi anche fare clic su righe di codice specifiche per aggiungere commenti, e Claude si adatterà in base al tuo feedback.

## Collegamento a strumenti esterni

Prima di iniziare una sessione, fai clic sul pulsante **⋯**, seleziona **Connectors** per aggiungere integrazioni esterne:

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- E altro...

Dopo la connessione, Claude può leggere direttamente il calendario, inviare messaggi, creare issue, ecc.

## Relazione con CLI

L'applicazione desktop e la CLI utilizzano lo stesso motore sottostante, condividendo le seguenti configurazioni:

- File di memoria del progetto `CLAUDE.md` / `CLAUDE.local.md`
- Configurazione del server MCP in `~/.claude.json` / `.mcp.json`
- Impostazioni in `~/.claude/settings.json`
- Configurazione di Hooks e Skills

Entrambi possono essere eseguiti contemporaneamente sullo stesso progetto, mantenendo ciascuno una cronologia delle sessioni indipendente.

## Domande frequenti

### Cosa fare se la connessione fallisce?

1. Controlla se il file `~/.claude/config.json` è stato creato correttamente
2. Assicurati che le variabili d'ambiente siano impostate correttamente (riavvia l'applicazione desktop per applicare le modifiche)
3. Verifica che il token API sia valido (puoi controllarlo nel [pannello di controllo](https://platform.acedata.cloud/console))
4. Se utilizzi `settings.json` per configurare le variabili d'ambiente, assicurati che il formato del file sia corretto

### Non riesco a trovare gli strumenti installati?

Se Claude non riesce a trovare comandi come `npm`, `node`, ecc.:

1. Assicurati che questi strumenti funzionino correttamente nel terminale normale
2. Controlla se il tuo file di configurazione della Shell (`~/.zshrc`, `~/.bashrc`) ha impostato correttamente il PATH
3. Riavvia l'applicazione desktop per ricaricare le variabili d'ambiente

### Come posso controllare il credito rimanente?

Accedi al [pannello di controllo di AceData Cloud](https://platform.acedata.cloud/console) per visualizzare il credito rimanente e l'utilizzo attuale del tuo account.
