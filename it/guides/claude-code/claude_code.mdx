Claude Code è un agente di programmazione intelligente lanciato da Anthropic, utilizzabile in vari ambienti come terminale, IDE e pipeline CI/CD. Attraverso il proxy AceData Cloud, puoi utilizzare Claude Code a un costo inferiore.

Scegli la guida completa di configurazione in base allo scenario d'uso e alla piattaforma corrispondente:

| Piattaforma | Descrizione | Link alla Guida |
|-------------|-------------|-----------------|
| **VS Code** | Estensione nativa, supporta Diff inline, @-mentions, revisione pianificata | [Guida alla Configurazione VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | Editor compatibile con VS Code, estensione Claude Code completamente supportata | [Guida alla Configurazione Cursor](https://platform.acedata.cloud/documents/development_cursor_coding) |
| **Terminale (CLI)** | Esperienza core, esegui `claude` in qualsiasi terminale per iniziare | [Guida alla Configurazione Terminale](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **JetBrains IDE** | Supporta IntelliJ IDEA, PyCharm, WebStorm e tutta la famiglia di IDE | [Guida alla Configurazione JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automatizza revisione codice e gestione Issue con `@claude` | [Guida alla Configurazione GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Suggerimento**: Per la prima richiesta, visita la [pagina del servizio Claude Messages](https://platform.acedata.cloud/documents/claude-messages) e clicca su "Acquire" per ottenere le credenziali e ricevere un credito gratuito.
