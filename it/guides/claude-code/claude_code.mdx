Claude Code è un agente intelligente di programmazione lanciato da Anthropic, utilizzabile in vari ambienti come terminale, IDE, applicazioni desktop, ecc. Attraverso il proxy AceData Cloud, puoi utilizzare Claude Code a un prezzo inferiore.

Scegli la guida alla configurazione corrispondente alla tua situazione d'uso:

| Piattaforma          | Descrizione                                   | Link alla Guida                                                                                           |
| ------------------- | ------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **Terminale (CLI)**  | Esperienza principale, basta eseguire `claude` in qualsiasi terminale per iniziare | [Guida alla Configurazione del Terminale](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code**         | Estensione nativa, supporta Diff inline, @-menzioni, revisione pianificata | [Guida alla Configurazione di VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)  |
| **JetBrains IDE**   | Supporta tutti gli IDE della serie IntelliJ IDEA, PyCharm, WebStorm, ecc. | [Guida alla Configurazione di JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions**  | Automatizza la revisione del codice e la gestione delle Issue con `@claude` | [Guida alla Configurazione di GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Suggerimento**: Per la prima richiesta, puoi visitare la [pagina del servizio Claude Messages](https://platform.acedata.cloud/documents/claude-messages) e cliccare su "Acquire" per ottenere un certificato, ricevendo così un credito gratuito.
