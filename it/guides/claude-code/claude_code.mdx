Claude Code si integra con il Coding Plan tramite il protocollo Anthropic Messages, attualmente offre due ingressi di configurazione: Terminale e VS Code.

| Ingresso Utilizzato | Guida alla Configurazione                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------ |
| Terminale / CLI    | [Configurazione del Terminale di Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code            | [Configurazione di Claude Code per VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## Configurazione Comune

- Base URL: `https://api.acedata.cloud`
- API Token: ottenuto dall'Applicazione di Coding e configurato tramite `ANTHROPIC_AUTH_TOKEN` nella guida
- Model ID: selezionato dal catalogo dei modelli in tempo reale
- Dopo aver modificato la configurazione: riavviare Claude Code; gli utenti di VS Code devono ricaricare la finestra

Non mantenere contemporaneamente il vecchio `ANTHROPIC_API_KEY` e non scrivere il Token reale in documenti condivisi dal team.

Torna al [Centro di Configurazione del Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
