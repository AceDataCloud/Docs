Claude Code è un agente di programmazione intelligente lanciato da Anthropic, utilizzabile in vari ambienti come terminale, IDE, applicazioni desktop, ecc. Attraverso il proxy AceData Cloud, puoi utilizzare Claude Code a un costo inferiore.

> **Prima volta che ti connetti?** Ti consigliamo di leggere prima [Claude Code 5 minuti per iniziare rapidamente](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) — dalla ricezione delle credenziali al primo comando eseguito con successo, tutto in cinque passaggi.

Scegli la guida completa di configurazione corrispondente alla piattaforma in base allo scenario d’uso:

| Piattaforma | Descrizione | Link alla guida |
|-------------|-------------|-----------------|
| **⚡ Inizio rapido in 5 minuti** | Dalla ricezione delle credenziali al primo comando `claude`, tutto in cinque passaggi | [Guida 5 minuti](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) |
| **Terminale (CLI)** | Esperienza principale, esegui `claude` in qualsiasi terminale per iniziare | [Guida configurazione terminale](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code** | Estensione nativa, supporta Diff inline, @-mentions, revisione pianificata | [Guida configurazione VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | Editor compatibile con VS Code, estensione Claude Code completamente supportata | [Guida configurazione Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **JetBrains IDE** | Supporta IntelliJ IDEA, PyCharm, WebStorm e tutta la famiglia di IDE | [Guida configurazione JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automatizza la revisione del codice e la gestione degli Issue con `@claude` | [Guida configurazione GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |
| **Applicazione Desktop (Anteprima)** | Client grafico indipendente, supporta sessioni parallele e connessione a strumenti esterni | [Guida configurazione applicazione desktop](https://platform.acedata.cloud/documents/claude-code-desktop-integration) |

> **Suggerimento**: Per la prima richiesta, visita la [pagina del servizio Claude Messages](https://platform.acedata.cloud/documents/claude-messages) e clicca su «Acquire» per ottenere le credenziali, ricevendo così un credito gratuito.
