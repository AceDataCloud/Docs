Questo documento ha un solo obiettivo: farti **eseguire il primo comando Claude Code** tramite il proxy AceData Cloud **in meno di 5 minuti**. Il tutorial completo è disponibile nelle sottosezioni dedicate ai vari IDE ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); qui seguiamo solo il percorso più rapido con "**CLI da terminale** + **estensione VS Code**".

> **Perché usare AceData Cloud come proxy per Claude Code**:
> - Connessione diretta in Cina, senza bisogno di VPN
> - Prezzi più bassi rispetto all’ufficiale (tariffazione a token sulla piattaforma)
> - La stessa chiave supporta sia Claude Messages API che il protocollo Claude Code Token

## Minuto 1: Richiedere le credenziali

Apri la [pagina del servizio Claude Messages](https://platform.acedata.cloud/documents/claude-messages) e clicca sul pulsante "**Acquire**":

![](https://cdn.acedata.cloud/nyq0xz.png)

La piattaforma creerà automaticamente un’Application e ti regalerà un credito gratuito. Annota i valori di **Base URL** e **API Token** nella pagina dei dettagli — ti serviranno per i prossimi 5 passaggi.

| Campo | Valore | Uso |
|-------|--------|-----|
| `BASE_URL` | `https://api.acedata.cloud` | Endpoint compatibile Claude Messages |
| `API_TOKEN` | `sk-...` (copia dalla pagina dettagli) | Header di autenticazione compatibile Anthropic |

## Minuto 2: Installare Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell nativo):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Al termine dell’installazione, apri un nuovo terminale e verifica:

```bash
claude --version
```

> Se vedi il numero di versione, è tutto a posto. Claude Code include Node.js runtime integrato, non dipende dalla versione Node installata sulla tua macchina.

## Minuto 3: Impostare le variabili d’ambiente per puntare ad AceData Cloud

Non seguire il flusso ufficiale `claude login`, ma sovrascrivi con variabili d’ambiente. Scegli uno dei due metodi:

**Metodo A: temporaneo (solo per la sessione shell corrente)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-il-tuo-Token"
```

**Metodo B: persistente (consigliato)**

Aggiungi le due righe sopra a `~/.zshrc` o `~/.bashrc` e poi esegui `source` sul file.

> **Attenzione comune**: la variabile si chiama `ANTHROPIC_AUTH_TOKEN`, non `ANTHROPIC_API_KEY`; se usi il nome sbagliato, Claude Code ricadrà sull’endpoint ufficiale e restituirà errore 401.

## Minuto 4: Eseguire il primo comando

Entra in una qualsiasi cartella di un repository Git e digita:

```bash
claude
```

Se alla prima esecuzione ti chiede di fare il login, premi `Esc` per saltare. Poi inserisci:

```
Elenca le dipendenze del progetto corrente e spiega brevemente a cosa servono.
```

Dovresti vedere Claude usare strumenti come `read_file`, `glob`, `grep` per esplorare il repository e poi restituire la lista. Se il modello risponde correttamente senza errori 401, il proxy è attivo.

## Minuto 5: Collegare anche l’estensione VS Code

1. Apri VS Code → pannello Estensioni → cerca `Claude Code` e installa quella ufficiale di Anthropic;
2. Riavvia VS Code o esegui `Developer: Reload Window` dal Command Palette per caricare la configurazione `~/.claude/settings.json` impostata al minuto 3;
3. Clicca sull’icona ✦ Spark in alto a destra nell’editor o sulla barra di stato in basso su “✱ Claude Code” per aprire il pannello;
4. Alla prima apertura ti chiederà il login ufficiale, premi `Esc` per saltare — l’estensione userà automaticamente `ANTHROPIC_BASE_URL` e `ANTHROPIC_AUTH_TOKEN` configurati al minuto 3.

> **Suggerimento**: l’estensione VS Code e la CLI condividono lo stesso file `~/.claude/settings.json`, quindi non serve configurare due volte. Se vuoi sovrascrivere con configurazione a livello di progetto, crea un file `.claude/settings.local.json` nella root del repository (già ignorato da git).

Quando tutto funziona, puoi trascinare file nel pannello per fare domande o usare `@-mention` per citare file e proporre modifiche. Tutti i costi sono gestiti da AceData Cloud.

## Verifica che stai effettivamente usando il proxy

Avvia una volta in modalità debug per controllare che le richieste vadano ad AceData Cloud:

```bash
claude --debug -p "say hi" 2>&1 | grep -iE 'base.?url|api\.acedata|anthropic\.com' | head
```

Se vedi `https://api.acedata.cloud` significa che il proxy è attivo; se invece compare `api.anthropic.com` o ricevi errore 401, torna al minuto 3 e verifica che la variabile sia `ANTHROPIC_AUTH_TOKEN` (non `ANTHROPIC_API_KEY`) e che il file `~/.claude/.credentials.json` non contenga token ufficiali (eliminalo se presente).

## Le 5 domande più frequenti

**Q: Ho eseguito `claude login` e poi ho cambiato le variabili d’ambiente per AceData, perché non funziona?**  
A: `claude login` scrive il token ufficiale in `~/.claude/.credentials.json`, che ha priorità sulle variabili d’ambiente. Elimina quel file e ricarica la shell (`source ~/.zshrc`).

**Q: Posso usare modelli come `--model claude-opus-4-7`?**  
A: Sì. AceData Cloud proxy passa il campo model così com’è. Supporta tutti i modelli pubblici Anthropic più le nostre estensioni `claude-opus-4-7`, `claude-haiku-4-5`, `claude-sonnet-4-5`.

**Q: Posso configurare più profili (personale + lavoro)?**  
A: Sì. Claude Code supporta profili multipli in `~/.claude/settings.json`; oppure il modo più semplice è definire due funzioni shell `claude_personal` e `claude_work` che esportano token diversi e poi eseguono `claude $@`.

**Q: Posso eseguirlo in GitHub Actions?**  
A: Sì. Vedi il tutorial [Claude Code GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**Q: Cosa succede quando finisco il credito gratuito?**  
A: Vai su [Gestione Applicazioni](https://platform.acedata.cloud/applications) → seleziona l’Application Claude → Topup per ricaricare (paghi in base ai token consumati), oppure passa a un abbonamento a punti.
