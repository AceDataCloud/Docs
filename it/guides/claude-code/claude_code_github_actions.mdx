description: "Claude Code API guide - Ace Data Cloud"
---

## 1. Ottenere la chiave API

Aprire l'[elenco delle applicazioni di Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedere alle applicazioni disponibili e copiare la chiave API.

![Ottenere la chiave API di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

Nel **Settings → Secrets and variables → Actions** del repository GitHub di destinazione, creare un nuovo Secret:

```text
ACEDATACLOUD_API_KEY
```

## 2. Installare l'app GitHub

Installare l'[app GitHub Claude](https://github.com/apps/claude) e autorizzare il repository di destinazione. Questa app ufficiale richiederà un insieme fisso di permessi completi; tra cui l'azione Claude Code utilizza effettivamente i permessi di Contents, Issues e Pull requests, la pagina di installazione di GitHub non può selezionare solo questi tre elementi. Se l'organizzazione richiede permessi minimi, seguire la documentazione ufficiale per creare un'app GitHub personalizzata.

## 3. Aggiungere il Workflow

Creare `.github/workflows/claude.yml`:

```yaml
name: Claude Code

on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  claude:
    if: contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      actions: read
      id-token: write
    env:
      ANTHROPIC_BASE_URL: https://api.acedata.cloud
      ANTHROPIC_CUSTOM_HEADERS: "Authorization: Bearer ${{ secrets.ACEDATACLOUD_API_KEY }}"
    steps:
      - uses: actions/checkout@v6
        with:
          fetch-depth: 1
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: dummy-not-used
```

`claude-code-action` richiede un input `anthropic_api_key` non vuoto; il valore segnaposto qui non sarà utilizzato per l'autenticazione della piattaforma. `ANTHROPIC_CUSTOM_HEADERS` sovrascriverà l'intestazione Bearer richiesta da Ace Data Cloud, la chiave reale proviene solo dal Secret di GitHub.

## 4. Verifica

Dopo aver inviato il Workflow, inviare un commento in un Issue o PR:

```text
@claude Reply only OK
```

Se ha successo, il workflow delle azioni verrà completato e il risultato verrà aggiornato nel corrispondente Issue/PR. Se l'azione segnala la mancanza di credenziali, confermare che `dummy-not-used` sia ancora presente; se si riceve un errore 401, controllare il Secret `ACEDATACLOUD_API_KEY`. Non stampare il Secret nei log. È possibile utilizzare `claude_args` per impostare `--max-turns` o scegliere il modello attualmente disponibile, ma l'integrazione del modello non è fissa.
