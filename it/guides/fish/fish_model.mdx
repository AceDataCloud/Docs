Questa interfaccia si basa sulla [Model API ufficiale di Fish Audio](https://docs.fish.audio/resources/api-reference/model) e viene utilizzata per **creare un modello vocale clonato riutilizzabile a lungo termine basato su un campione audio**. L'indirizzo è `POST https://api.acedata.cloud/fish/model`.

> Quando è necessario utilizzare temporaneamente una voce di riferimento, non è necessario creare un modello: è possibile usare direttamente la clonazione istantanea una tantum tramite `references` della [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts). Per recuperare con paginazione i timbri vocali esistenti, consultare la [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query); per interrogare i dettagli di un singolo timbro vocale tramite `_id`, consultare la [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Processo di richiesta

Per utilizzare la Fish Model API, per prima cosa vai alla [console di Ace Data Cloud](https://platform.acedata.cloud/console/applications) per ottenere il tuo API Token e conservarlo per l'uso.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se non hai ancora effettuato l'accesso o non ti sei registrato, verrai automaticamente reindirizzato alla pagina di accesso per registrarti e accedere; al termine, tornerai automaticamente alla pagina corrente.

**Un solo API Token può chiamare tutti i servizi della piattaforma, senza necessità di richiederne uno separatamente per ogni servizio.** Alla prima richiesta verrà assegnato un credito gratuito, per consentire una prova gratuita; quando il credito è insufficiente, puoi ricaricare il saldo comune nella [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentazione completa: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Campi del corpo della richiesta

| Campo                      | Tipo       | Obbligatorio | Descrizione                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | Sì   | Nome del timbro vocale, utilizzato per identificarlo nell'elenco della console.                                                             |
| `voices`                | string   | Sì   | URL HTTP(S) del campione audio (**singola stringa**, non un array). Questa interfaccia non supporta il caricamento multipart/binario; carica prima l'audio in qualsiasi archivio di oggetti pubblicamente accessibile. |
| `description`           | string   | No   | Descrizione del timbro vocale.                                                                         |
| `cover_image`           | string   | No   | URL HTTP(S) dell'immagine di copertina.                                                              |
| `tags`                  | string[] | No   | Tag per la ricerca nella libreria pubblica, ad esempio `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | No   | Testi di riferimento corrispondenti ai campioni (utilizzati per correggere la pronuncia).                                                           |
| `enhance_audio_quality` | boolean  | No   | Se migliorare la qualità audio del campione prima dell'addestramento.                                                                |
| `generate_sample`       | boolean  | No   | Se generare automaticamente un audio di esempio dopo il completamento dell'addestramento.                                                            |

> Per ulteriori informazioni sui modelli vocali, puoi consultare la [documentazione ufficiale di Fish](https://docs.fish.audio/resources/api-reference/model).

> I timbri vocali creati verranno salvati pubblicamente a lungo termine e altri utenti potrebbero cercarli e utilizzarli. Non è necessario passare `visibility`; anche se viene passato `private` o `unlist`, l'interfaccia corrente non modificherà l'ambito pubblico in base a questo.

## Esempio: creare un timbro vocale clonato pubblico

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的中文音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Nota: `voices` deve essere una **stringa** (un singolo URL audio), non un array. Se viene passato come `["..."]`, l'upstream lo rifiuterà. Si consiglia di utilizzare un link diretto pubblicamente scaricabile con suffisso `.mp3` o `.wav`.

La risposta di successo restituisce direttamente l'oggetto ModelEntity della piattaforma Fish (l'esempio seguente è il timbro vocale minimo utilizzabile che abbiamo testato; alcuni campi lunghi sono stati rimossi per facilitarne la lettura):

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，这是一段使用我刚创建的克隆音色合成的语音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Requisiti del campione

Valori empirici (coerenti con l'upstream, puoi fare riferimento alla [documentazione ufficiale di Fish](https://docs.fish.audio/resources/api-reference/model)):

- Si consiglia una durata di almeno 30 secondi; entro 5 minuti si ottengono i risultati migliori; oltre 10 minuti il beneficio marginale non è significativo.
- Frequenza di campionamento di 16 kHz o superiore; sono supportati sia mono sia stereo.
- Il contenuto deve essere il più pulito possibile: senza musica di sottofondo, eco o rumore ambientale evidente; stesso parlante.
- Formati consigliati: `mp3` / `wav`.

Se non sei sicuro della qualità del campione, puoi anche passare `enhance_audio_quality: true` per consentire all'upstream di migliorare prima la qualità audio.

## Informazioni sulla fatturazione
La creazione di un modello di clonazione vocale (`POST /fish/model`) è gratuita e non comporta alcun costo; anche le API di consultazione della voce ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)、[Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) non sono a pagamento. I costi vengono generati solo in base all'utilizzo durante la successiva chiamata di [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) per sintetizzare la voce.

## Gestione degli errori

- `400 token_mismatched`: parametri della richiesta mancanti o non validi (il caso più comune è che `voices` non sia un URL oppure sia stato passato come array).
- `400`: quando l'audio di riferimento non può essere scaricato, la durata è troppo breve o il formato non può essere riconosciuto, controllare l'URL dell'audio e il formato del file.
- `401 invalid_token`: il token di autenticazione non esiste o non è valido.
- `429 too_many_requests`: è stato attivato il limite di frequenza dell'account.
- `500 api_error`: errore interno del server.

Esempio di risposta di errore:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusione

Per chiamare questa API è necessario preparare solo un URL di audio campione accessibile pubblicamente, inserirlo nel campo `voices` per ottenere `_id`, quindi fornirlo a `reference_id` di `/fish/tts` per completare il flusso end-to-end di «clonazione → sintesi». Un errore comune è che `voices` debba essere una stringa e non possa essere un array.

## Creare e riutilizzare voci tramite MCP

In Fish MCP, chiamare
`fish_create_model(title="La mia voce", voices="https://example.com/authorized-voice.wav")`.
`voices` è un singolo URL audio HTTP(S); è inoltre possibile passare `description`, `cover_image`, `tags`,
`texts`, `enhance_audio_quality`, `generate_sample`.

Questo strumento salva a lungo termine le voci pubbliche, che altri utenti potrebbero scoprire e utilizzare; usare solo
materiali audio autorizzati per l'elaborazione e la pubblicazione. Lo strumento non dispone di opzioni private o non pubbliche. L'`_id` restituito dopo la creazione riuscita viene utilizzato per
`reference_id` di `fish_generate_audio`, mentre `fish_list_models(self=true)` consente di consultare le voci
salvate dall'utente. Quando è necessaria solo una voce di riferimento una tantum, usare `references` di `fish_generate_audio`,
senza creare una voce a lungo termine.
