Questa interfaccia si basa sull'[API Model ufficiale di Fish Audio](https://docs.fish.audio/resources/api-reference/model) ed è utilizzata per **ricercare in modo paginato il database pubblico di timbri di Fish o i timbri clonati sotto l'account attuale**. L'indirizzo è `GET https://api.acedata.cloud/fish/model`.

> Per creare un timbro, si prega di fare riferimento all'[API Fish Model Create](https://platform.acedata.cloud/documents/fish-model); per cercare i dettagli di un singolo timbro per `_id`, si prega di fare riferimento all'[API Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get).

## Processo di Richiesta

Per utilizzare l'API Fish Model, prima di tutto vai al [Pannello di Controllo di Ace Data Cloud](https://platform.acedata.cloud/console/applications) per ottenere il tuo API Token, da tenere a disposizione.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se non hai ancora effettuato il login o registrato, verrai automaticamente reindirizzato alla pagina di login che ti invita a registrarti e accedere; una volta completato, verrai riportato automaticamente alla pagina corrente.

**Un API Token è sufficiente per accedere a tutti i servizi della piattaforma, non è necessario richiederne uno separato per ogni servizio.** La prima richiesta ti darà un credito gratuito, per un'esperienza senza costi; quando il credito è insufficiente, puoi ricaricare il saldo generale nel [pannello di controllo](https://platform.acedata.cloud/console/coin).

> 📘 Documentazione completa: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Parametri di Ricerca

| Parametro         | Tipo      | Predefinito | Descrizione                                 |
| ---------------- | ------- | --------- | --------------------------------------- |
| `page_size`      | intero   | 10        | Numero di elementi per pagina.                |
| `page_number`    | intero   | 1         | Numero di pagina a partire da 1.              |
| `title`          | stringa  | —         | Ricerca fuzzy per titolo.                     |
| `tag`            | stringa  | —         | Filtra per un singolo tag.                    |
| `self`           | booleano | —         | Se `true`, restituisce solo i timbri creati dall'account attuale, senza ulteriori condizioni. |
| `author_id`      | stringa  | —         | Filtra per `_id` dell'utente upstream.        |
| `language`       | stringa  | —         | Filtra per lingua del timbro, come `en`, `zh`, `es`. |
| `title_language` | stringa  | —         | Filtra per lingua del titolo.                  |
| `sort_by`        | stringa  | —         | Campo di ordinamento, coerente con l'upstream, come `created_at`, `task_count`. |

> La denominazione dei parametri è completamente coerente con l'upstream `GET https://api.fish.audio/model`, per maggiori dettagli vedere la [documentazione ufficiale di Fish](https://docs.fish.audio/resources/api-reference/model).

## Esempio 1: Paginazione predefinita (per `page_size`)

```shell

  -H 'authorization: Bearer {token}' \
```

## Esempio 2: Ricerca fuzzy per titolo (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Risposta (testato):

```json
{
  "total": 161,
  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",
      "type": "tts",
      "title": "Miles Morales ( Narration Paw )",
      "tags": ["male", "middle-aged", "entertainment", "storytelling", "Children's Content"],
      "languages": ["en"],
      "visibility": "public",
      "task_count": 770
    },
    {
      "_id": "76b55591c758444cb95253708696dfad",
      "type": "tts",
      "title": "Joe NARRATION",
```

Nota che `title` è una "corrispondenza fuzzy globale", colpirà tutti i timbri nel database pubblico di Fish (non solo i propri).

## Esempio 3: Elenca solo i timbri creati da te (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Risposta (testato, attualmente l'account ha solo 1 timbro):

## Esempio 4: Filtraggio per lingua + tag
```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> L'upstream restituirà risultati anche per `tag` non presenti nel dizionario dei tag, ma la corrispondenza sarà relativamente ampia; se il numero di corrispondenze è 0, si consiglia di utilizzare la corrispondenza fuzzy con `title`.

## Campi di risposta

Ogni elemento in `items[]` è un oggetto ModelEntity completo, campi comunemente usati:

| Campo          | Tipo      | Descrizione                                         |
| -------------- | --------- | -------------------------------------------------- |
| `_id`          | string    | ID del timbro, utilizzato come valore di `reference_id` in `/fish/tts`. |
| `type`         | string    | Tipo di modello, solitamente `tts`.                |
| `title`        | string    | Nome del timbro.                                   |
| `description`  | string    | Descrizione del timbro.                            |
| `state`        | string    | Stato di addestramento: `trained` indica che è disponibile. |
| `tags`         | string[]  | Tag della libreria pubblica.                       |
| `languages`    | string[]  | Lingue in cui il timbro è specializzato.          |
| `visibility`   | string    | `public` o `private`.                              |
| `samples`      | object[]  | Campioni preimpostati (inclusi i link diretti `audio`). |
| `like_count`   | integer   | Numero di "mi piace" nella libreria pubblica.     |
| `task_count`   | integer   | Numero di sintesi storiche.                        |
| `author`       | object    | Informazioni sull'autore upstream: `_id` / `nickname` / `avatar`. |
| `total` (livello superiore) | integer | Numero totale di elementi che soddisfano i criteri. |
| `has_more`     | boolean?  | Indicazione di paginazione upstream, potrebbe essere `null`. Si consiglia di calcolare il numero totale di pagine usando `total / page_size`. |

## Informazioni di fatturazione

Questa interfaccia non comporta costi - la query paginata della lista dei timbri è un'operazione gratuita. La creazione di timbri ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) è anch'essa gratuita, i costi si generano solo durante la chiamata a [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) per la sintesi vocale in base all'uso.

## Gestione degli errori

- `400 token_mismatched`: Parametri di richiesta mancanti o non validi.
- `401 invalid_token`: Il token di autorizzazione non esiste o è non valido.
- `429 too_many_requests`: Limite di velocità dell'account attivato.
- `500 api_error`: Errore interno del server.

Esempio di risposta di errore:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusione

Per selezionare un timbro dalla libreria pubblica di Fish da fornire a `/fish/tts` come `reference_id`, utilizzare prima questa interfaccia insieme a `title` / `tag` / `language` per cercare, localizzare l' `_id` target, quindi utilizzare [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) per ottenere campioni da ascoltare. Per elencare i timbri creati da sé, basta passare `self=true`.
