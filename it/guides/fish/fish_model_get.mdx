Questo API si basa su [Fish Audio Official Model API](https://docs.fish.audio/resources/api-reference/model) ed è utilizzato per **richiedere i dettagli completi di un singolo clone vocale in base a `_id`**. L'indirizzo è `GET https://api.acedata.cloud/fish/model/{id}`.

> Per creare un timbro vocale, si prega di fare riferimento a [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); per la ricerca paginata, si prega di fare riferimento a [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query).

## Processo di richiesta

Per utilizzare l'API Fish Model, prima di tutto vai al [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) per ottenere il tuo API Token, da conservare per uso futuro.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se non hai ancora effettuato il login o la registrazione, verrai automaticamente reindirizzato alla pagina di login che ti invita a registrarti e accedere; una volta completato, verrai riportato automaticamente alla pagina corrente.

**Un API Token è sufficiente per accedere a tutti i servizi della piattaforma, non è necessario richiederne uno separato per ogni servizio.** La prima richiesta ti darà un credito gratuito, che ti permetterà di provare gratuitamente; se il credito è insufficiente, puoi ricaricare il saldo generale nella [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentazione completa: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Parametri del percorso

| Parametro | Obbligatorio | Descrizione                                                                                                                                                                                                |
| --------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`      | Sì           | `_id` del timbro vocale (stringa esadecimale di 32 caratteri). Può essere restituito durante la creazione tramite [Fish Model Create](https://platform.acedata.cloud/documents/fish-model) o recuperato tramite [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query). |

Nessun corpo della richiesta, nessun parametro di query.

## Esempio: Recuperare i dettagli completi di un timbro vocale spagnolo pubblico

```shell
curl 'https://api.acedata.cloud/fish/model/8d2c17a9b26d4d83888ea67a1ee565b2' \
  -H 'authorization: Bearer {token}'
```

L' `_id` ottenuto può essere direttamente fornito a [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) come `reference_id` per sintetizzare la voce con lo stesso timbro:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

## Differenze con l'interfaccia di elenco

| Campo                                               | `GET /fish/model` (elenco) | `GET /fish/model/{id}` (dettagli) |
| -------------------------------------------------- | --------------------------- | ---------------------------------- |
| `samples[].audio`                                  | URL R2 cache a breve termine | Link diretto R2 firmato (incluso query di firma) |
| `unliked` / `liked` / `marked` / `dmca_taken_down` | Esistono entrambi            | Esistono entrambi                  |
| `default_text` / `lock_visibility`                 | Esistono entrambi            | Esistono entrambi                  |

Se desideri solo ascoltare, il `samples[].audio` nell'interfaccia di elenco è già sufficiente; per un link di download più stabile, si consiglia di utilizzare questa interfaccia.

## Campi di risposta (estratto)

| Campo            | Tipo     | Descrizione                                      |
| ---------------- | -------- | ------------------------------------------------ |
| `_id`            | string   | ID del timbro vocale (utilizzato per `reference_id` in `/fish/tts`). |
| `type`           | string   | Tipo di modello, solitamente `tts`.              |
| `title`          | string   | Nome del timbro vocale.                          |
| `description`    | string   | Descrizione lunga.                               |
| `state`          | string   | Stato di addestramento: `trained` indica disponibile, `training` indica in fase di addestramento. |
| `tags`           | string[] | Etichette della libreria pubblica.               |
| `samples`        | object[] | Campioni preimpostati, contenenti `title`, `text`, `task_id`, `audio` link diretto. |
| `languages`      | string[] | Codici delle lingue in cui il timbro vocale è esperto. |
| `visibility`     | string   | `public` o `private`.                            |
| `like_count`     | integer  | Numero di "mi piace" nella libreria pubblica.    |
| `task_count`     | integer  | Numero di sintesi storiche (può essere utilizzato come riferimento per la popolarità). |
| `author`         | object   | Informazioni sull'autore: `_id` / `nickname` / `avatar`. |
| `created_at`     | string   | Data di creazione in formato ISO 8601.          |
| `updated_at`     | string   | Data di ultimo aggiornamento in formato ISO 8601. |

## Informazioni di fatturazione

Questa interfaccia non comporta costi - la richiesta di dettagli di un singolo timbro vocale per ID è un'operazione gratuita. La creazione di un timbro vocale ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) è anch'essa gratuita, i costi si generano solo quando si utilizza [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) per sintetizzare la voce.

## Gestione degli errori
- `400 token_mismatched`: L'`id` nel percorso non è in un formato valido, oppure il sistema upstream riporta "Model not found".
- `401 invalid_token`: Il token di autorizzazione non esiste o è invalido.
- `404 not_found`: L'`_id` specificato non è visibile nell'upstream di Fish (il modello è stato eliminato, è privato o appartiene a un altro account).
- `429 too_many_requests`: È stato attivato il limite di velocità dell'account.
- `500 api_error`: Errore interno del server.

Quando si richiede un ID inesistente, l'upstream restituisce direttamente `400 Model not found` (testato):

```shell
curl 'https://api.acedata.cloud/fish/model/test123' \
  -H 'authorization: Bearer {token}'
```

Restituisce:

```json
{ "status": 400, "message": "Model not found" }
```

Esempio di risposta di errore:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusione

Quando si conosce l'`_id` del modello, utilizzare direttamente questa interfaccia per ottenere il ModelEntity completo. Gli usi più comuni sono: (1) ascoltare `samples[].audio`, (2) fornire l'`_id` a `reference_id` di `/fish/tts` per completare la sintesi. Se si dispone solo del titolo o delle etichette, utilizzare prima [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) per effettuare la ricerca.
