Questa API fornisce la conversione di testo in voce, la chiamata di voci salvate e la clonazione vocale istantanea una tantum, all'indirizzo `POST https://api.acedata.cloud/fish/tts`.

## Procedura di richiesta

Per utilizzare Fish TTS API, innanzitutto vai alla [console di Ace Data Cloud](https://platform.acedata.cloud/console/applications) per ottenere il tuo API Token, da conservare come riserva.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se non hai ancora effettuato l'accesso o la registrazione, verrai automaticamente reindirizzato alla pagina di accesso che ti inviterà a registrarti e ad accedere; una volta completato, tornerai automaticamente alla pagina corrente.

**Un solo API Token può chiamare tutti i servizi della piattaforma, non è necessario richiederne uno separatamente per ogni servizio.** Alla prima richiesta verrà assegnato un credito gratuito, utilizzabile per una prova gratuita; quando il credito è insufficiente, puoi ricaricare il saldo comune nella [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentazione completa: [Fish TTS API →](https://platform.acedata.cloud/services/fish)

## Intestazioni della richiesta

| Header          | Obbligatorio  | Descrizione                                                                                                     |
| --------------- | --- | ------------------------------------------------------------------------------------------------------ |
| `authorization` | Sì   | `Bearer {token}`, dove `{token}` è la chiave richiesta su questa piattaforma.                                                                 |
| `content-type`  | Sì   | `application/json`.                                                                                    |
| `accept`        | No   | `application/json`.                                                                                    |
| `model`         | No   | Modello TTS, opzionale tra `s1`, `s2-pro` o `s2.1-pro`, predefinito `s2-pro`. `s2.1-pro` è la generazione più recente, `s2-pro` ha una forte espressività; `s1` è più stabile e meno soggetto a deviazioni nei testi lunghi. Tutti e tre hanno lo stesso prezzo. |

## Campi del corpo della richiesta

| Campo             | Tipo                 | Obbligatorio  | Descrizione                                                                                                                                                                                                     |
| -------------- | ------------------ | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `text`         | string             | Sì   | Il testo da sintetizzare, stringa non vuota.                                                                                                                                                                                          |
| `format`       | string             | No   | Formato audio di output, opzionale tra `mp3` (predefinito), `wav`, `pcm`. Sia `wav` sia `pcm` restituiscono contenitori WAV. `opus` non è supportato e, se passato, restituisce direttamente `400`.                                                                                                                  |
| `reference_id` | string \| string[] | No   | ID del modello di una voce salvata o pubblica, creabile tramite [Fish Model API](https://platform.acedata.cloud/documents/fish-model), oppure ricercabile in [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query). Non può essere utilizzato contemporaneamente a `references`. |
| `references`   | object[]           | No   | Clonazione vocale istantanea una tantum, supporta un solo campione `{audio, text}`: `audio` è un URL HTTPS MP3/WAV pubblico, `text` è la trascrizione verbatim accurata dell'audio. Non può essere utilizzato contemporaneamente a `reference_id`.                                                                                             |
| `sample_rate`  | integer            | No   | Frequenza di campionamento, comunemente `16000`, `22050`, `44100`. `format=mp3` usa 44100 per impostazione predefinita.                                                                                                                                                  |
| `mp3_bitrate`  | integer            | No   | Bitrate MP3, opzionale tra `64`, `128`, `192`. Ha effetto solo con `format=mp3`.                                                                                                                                                          |
| `prosody`      | object             | No   | Sovrascrittura della prosodia, supporta `speed` (velocità del parlato, 1.0 è la velocità originale) e `volume` (guadagno del volume in dB). Ad esempio `{"speed":1.2,"volume":0}`.                                                                                                                          |
| `chunk_length` | integer            | No   | Lunghezza dei segmenti upstream, per impostazione predefinita determinata dall'upstream.                                                                                                                                                                                         |
| `temperature`  | number             | No   | Temperatura di campionamento, intervallo approssimativo 0.0–1.0.                                                                                                                                                                                      |
| `top_p`        | number             | No   | Parametro di campionamento top-p.                                                                                                                                                                                            |
| `latency`      | string             | No   | `normal` o `balanced`, se omesso questa API completa automaticamente con `normal` (passare direttamente una stringa vuota verrà rifiutato dall'upstream).                                                                                                                                                |
| `normalize`    | boolean            | No   | Se normalizzare il testo.                                                                                                                                                                                             |
| `callback_url` | string             | No   | Indirizzo di callback asincrono, vedi sotto «Callback asincrono». **Questa è un'estensione rispetto all'interfaccia ufficiale**.                                                                                                                                                                     |

> La clonazione una tantum accetta solo URL audio HTTPS, non accetta MessagePack, Base64, URI data o URL con credenziali. Per l'audio di riferimento si consigliano 10–270 secondi; Studio utilizza un intervallo più conservativo di 10–60 secondi.

## Esempio 1: richiesta minima (`text` + `format=mp3`)

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hello world.",
    "format": "mp3"
  }'
```

Restituisce (testato):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/e2ffcc06-18da-4a8c-b9aa-9337d0f9ec1d-230825dfc559.mp3"
}
```

`audio_url` punta al CDN di questa piattaforma e può essere scaricato direttamente con GET o riprodotto in `<audio>`. La risposta finale di successo restituisce inoltre `cost` al livello superiore, dove `amount` è il numero di Credits effettivamente detratto questa volta; in presenza di sconti sull'account, `list_amount` indica il credito prima dello sconto. Il collegamento è disponibile a lungo termine, ma si consiglia comunque di conservarne una copia nel proprio archivio.

## Esempio 2: utilizzare il timbro vocale clonato `reference_id`

Di seguito viene utilizzato un timbro vocale spagnolo pubblico sulla piattaforma Fish (`_id` può essere ottenuto tramite ricerca in [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)):

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

Restituisce (testato):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/b6f161f2-a100-4818-add2-47694f234659-6532864739de.mp3"
}
```

## Esempio 3: clonazione vocale istantanea una tantum (`references`)

Posiziona l'audio di riferimento a un indirizzo HTTPS pubblico e fornisci il testo originale accurato effettivamente pronunciato al suo interno. Questa voce verrà utilizzata solo per questa sintesi e non creerà un modello a lungo termine:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s2-pro' \
  -d '{
    "text": "新的旅程从这一刻开始，让我们一起向前。",
    "format": "mp3",
    "references": [{
      "audio": "https://cdn.acedata.cloud/assets/examples/fish/6220d605-39d0-4d43-9e58-0f12949dc9b9-570cfdf96ad9.mp3",
      "text": "春天的清晨，阳光穿过树叶，落在安静的小路上。"
    }]
  }'
```
Risposta di successo verificata:

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/995dfe37-b187-474d-8323-b08d6678ed8f-6359be9f8873.mp3",
  "cost": {"amount": 0.007609319999999999, "currency": "credit"}
}
```

| Metodo             | Ciclo di vita       | Scenari applicabili                          |
| -------------- | ---------- | ----------------------------- |
| `references`   | Solo per questa richiesta TTS | Utilizzo temporaneo o voce diversa ogni volta                   |
| `reference_id` | Riutilizzabile      | Voce pubblica o voce a lungo termine creata tramite `/fish/model` |

## Esempio 3: regolare velocità / volume (`prosody`)

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Faster speech with prosody overrides.",
    "prosody": { "speed": 1.2, "volume": 0 },
    "format": "mp3"
  }'
```

Restituisce (verificato):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
}
```

`speed` maggiore di 1 accelera, minore di 1 rallenta; l'unità di `volume` è dB, 0 indica nessuna modifica, i numeri positivi aumentano il guadagno, i numeri negativi lo attenuano.

## Esempio 5: cambiare modello + controllare il bitrate

Passare al modello stabile tramite l'header HTTP `model: s1`, aggiungere `mp3_bitrate: 128` nel corpo della richiesta per controllare il bitrate MP3:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s1' \
  -d '{
    "text": "high bitrate mp3",
    "format": "mp3",
    "mp3_bitrate": 128
  }'
```

Restituisce (verificato):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/7e7abf3d-3d72-4c9f-8eb6-8af932d7c96e-6f11bf2f30e9.mp3"
}
```

## Esempio 6: forma d'onda PCM grezza

Per gli scenari in cui è necessario effettuare la concatenazione in tempo reale nel browser, o eseguire elaborazioni successive sul client (mixaggio, variazione di velocità), si consiglia di utilizzare `pcm`:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "hi",
    "format": "pcm",
    "sample_rate": 16000
  }'
```

Restituisce (verificato):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/64adc04b-c196-4a0f-9070-222ba101ce6c-fc50de38c165.wav"
}
```

> L'estensione del link segue il `format` nella richiesta: `mp3` restituisce `.mp3`, `wav` e `pcm` restituiscono `.wav` (contenitore WAV, PCM a 16 bit).

## Callback asincrono (`callback_url`)

La sintesi di testi lunghi in una sola volta potrebbe richiedere da decine di secondi a diverse decine di secondi, e se la connessione viene interrotta è necessario riprovare. Dopo aver passato `callback_url` nel corpo della richiesta, l'interfaccia restituisce immediatamente `{task_id, started_at}`; quando l'elaborazione a monte è realmente completata, il risultato completo viene richiamato a quell'URL sotto forma di POST JSON, con lo stesso `task_id` e il `cost` di primo livello della fatturazione finale di questa volta nel corpo della richiesta. La conferma iniziale dell'attività non ha ancora completato la sintesi, pertanto non include `cost`.

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "今天天气真好，我们一起出去散散步吧。",
    "format": "mp3",
    "callback_url": "https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34"
  }'
```

Restituisce immediatamente (verificato):

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "started_at": 1778462584.742
}
```

Successivamente, `callback_url` riceverà qualcosa come:

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/bd66b8c5-7543-4557-b684-baa72407e336-52f2e79732f2.mp3"
}
```

È anche possibile utilizzare [Fish Tasks API](https://platform.acedata.cloud/documents/fish-tasks) per recuperare attivamente il risultato tramite `task_id`; il `response.cost` del record nello stato finale è coerente con il `cost` nel callback, vedere quel documento per i dettagli.

## Gestione degli errori

- `400 token_mismatched`: parametri della richiesta mancanti o non validi (i casi più comuni sono `text` vuoto, oppure `format` con un valore diverso da `mp3`/`wav`/`pcm`).
- `401 invalid_token`: il token di autenticazione non esiste o non è valido.
- `429 too_many_requests`: è stato attivato il limite di velocità dell'account.
- `500 api_error`: errore interno del server.

Esempio di risposta di errore:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

Gli errori di convalida dei parametri specificheranno il campo non valido nel campo `message`, ad esempio:

```json
{
  "status": 400,
  "message": "[{\"type\":\"literal_error\",\"loc\":[\"format\"],\"msg\":\"Input should be 'pcm' or 'mp3'\",\"input\":\"wav\"}]"
}
```

## Conclusione

Il costo minimo per integrare Fish TTS è: nel codice esistente che chiama `api.fish.audio/v1/tts`, sostituire l'autenticazione con il token di questa piattaforma e includere **esplicitamente** `format: "mp3"` nel corpo della richiesta. Per gli scenari di testo lungo si consiglia di utilizzare il callback asincrono `callback_url`; per l'individuazione di `reference_id` delle voci clonate, utilizzare insieme [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) e [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get).
