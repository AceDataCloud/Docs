Invia un'attività tramite `POST /kling/apparel`, usa l'esistente `POST /kling/tasks` per controllare lo stato dell'attività sulla piattaforma.

## Input

Fornisci una descrizione del prodotto di massimo 2500 caratteri, un video di riferimento di 5–180 secondi e 1–5 immagini del prodotto. Puoi inoltre fornire 1–5 immagini del modello, un file di musica di sottofondo e specificare una voce per il doppiaggio; se non viene specificata una voce, viene utilizzato il parlato nativo.

Di seguito è riportato un esempio di struttura della richiesta; sostituisci gli URL delle risorse prima di effettuare la chiamata.

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "Il contenuto del tuo prodotto o del parlato"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## Risultati e fatturazione

La modalità sincrona restituisce il risultato generato; la modalità asincrona restituisce prima `task_id`, mentre il risultato completato include nei link dei video o delle immagini in `data` e il valore `usage` calcolato dal server. `callback_url` viene utilizzato per la notifica di completamento; la richiesta `watermark=true` restituisce contemporaneamente la versione con filigrana.

Parlato nativo: 1,82 Credits/secondo per 720p, 2,38 Credits/secondo per 1080p; doppiaggio specificato: 2,38 Credits/secondo per 720p, 2,8 Credits/secondo per 1080p. I video vengono fatturati in base alla durata effettiva generata; il prezzo base al secondo prima della generazione non rappresenta il prezzo totale dell'intera attività. Le attività non riuscite non comportano costi di generazione.
