---
title: "Guida all'integrazione dei video di prodotto"
description: "Kling video generation API guide - Ace Data Cloud"
---

Invia un'attività tramite `POST /kling/goods-studio`, utilizza l'esistente `POST /kling/tasks` per verificare lo stato dell'attività della piattaforma.

## Input

Fornisci 1–5 immagini del prodotto e un titolo del prodotto di massimo 200 caratteri; la descrizione del prodotto è facoltativa, fino a 2000 caratteri. La durata può essere di 15, 30 o 60 secondi.

Di seguito è riportato un esempio di struttura della richiesta, sostituisci l'URL della risorsa prima di chiamare.

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "Il tuo prodotto o contenuto del parlato"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## Risultati e fatturazione

La modalità sincrona restituisce il risultato generato; la modalità asincrona restituisce prima `task_id`, il risultato completato include i collegamenti al video o alle immagini in `data` e l'`usage` calcolato dal server. `callback_url` viene utilizzato per la notifica di completamento; la richiesta `watermark=true` restituisce contemporaneamente la versione con filigrana.

720p: 2,38 Credits/secondo; 1080p: 2,8 Credits/secondo. I video vengono fatturati in base alla durata effettivamente generata, il prezzo base per secondo prima della generazione non rappresenta il prezzo totale dell'intera attività. Alle attività non riuscite non vengono addebitati costi di generazione.
