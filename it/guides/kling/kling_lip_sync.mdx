Fai "parlare" un **video Kling esistente** (5 secondi o 10 secondi) in base a un audio o a un testo — ovvero sincronizzazione labiale (Lip Sync). Combinato con `/kling/videos` e `image2video` (per animare le foto), può formare un flusso completo di "**foto parlanti / avatar digitali**".

> Questa interfaccia è una comoda e semplice incapsulazione fornita da AceDataCloud, rivolta a scenari comuni guidati da audio/testo; non è un campo speculare dell'interfaccia multi-passaggio ufficiale di Kling "riconoscimento facciale → Sincronizzazione labiale avanzata". Si prega di fare riferimento alla tabella dei parametri in questa pagina.

- **Indirizzo dell'interfaccia**: `POST https://api.acedata.cloud/kling/lip-sync`
- **Formato della richiesta**: `application/json`
- **Formato della risposta**: `application/json`
- **Fatturazione**: **2.45 Crediti** per ogni chiamata riuscita (fisso)

## Intestazioni della richiesta (Request Headers)

| Campo              | Valore                   | Descrizione                                               |
| ----------------- | ----------------------- | ------------------------------------------------------- |
| `authorization`   | `Bearer ${API_KEY}`     | La tua chiave API, [indirizzo per ottenerla](https://platform.acedata.cloud) |
| `content-type`    | `application/json`      | Formato del corpo della richiesta                           |
| `accept`          | `application/json`      | Formato della risposta                                     |

## Parametri della richiesta (Request Body)

| Parametro         | Tipo      | Obbligatorio | Predefinito | Descrizione                                                                                                                       |
| ----------------- | --------- | ------------ | ----------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `mode`            | string    | Sì           | —           | Modalità di generazione. Enum: `audio2video` (guidato da audio), `text2video` (guidato da testo)                               |
| `video_id`        | string    | Opzionale    | —           | ID del video generato da Kling (ad esempio, `video_id` restituito da `image2video` di `/kling/videos`). **Supporta solo video di 5s/10s generati negli ultimi 30 giorni**. `video_id` e `video_url` sono alternativi e non possono essere forniti contemporaneamente |
| `video_url`       | string    | Opzionale    | —           | Link video accessibile pubblicamente. Vincoli: `.mp4`/`.mov`, ≤100MB, durata 2–10s, solo 720p/1080p, dimensioni 720–1920px. Alternativo a `video_id`                                  |
| `audio_url`       | string    | Condizionale | —           | URL di download dell'audio di guida, obbligatorio quando `audio2video` + `audio_type=url`. Formato `.mp3`/`.wav`/`.m4a`/`.aac`, ≤5MB                                     |
| `audio_type`      | string    | No           | `url`       | Modalità di trasmissione audio. Enum: `url`, `file` (efficace quando `audio2video`)                                               |
| `audio_file`      | string    | Condizionale | —           | File audio in Base64, obbligatorio quando `audio_type=file`. Formato come sopra, ≤5MB                                             |
| `text`            | string    | Condizionale | —           | Testo da leggere, obbligatorio quando `text2video`, **massimo 120 caratteri**                                                     |
| `voice_id`        | string    | Condizionale | —           | ID della voce, obbligatorio quando `text2video`                                                                                 |
| `voice_language`  | string    | No           | `zh`        | Lingua della voce. Enum: `zh`, `en` (efficace quando `text2video`)                                                              |
| `voice_speed`     | float     | No           | `1.0`       | Velocità di parola, intervallo `0.8`–`2.0`, con una cifra decimale (efficace quando `text2video`)                               |
| `callback_url`    | string    | No           | —           | Indirizzo di callback. Se fornito o `async=true`, modalità **asincrona**: restituisce immediatamente `task_id`, callback dopo la generazione del risultato                             |
| `async`           | boolean   | No           | `false`     | Se asincrono. Se `true`, restituisce immediatamente `task_id`, da utilizzare con `/kling/tasks` per il polling o callback `callback_url` |

## Esempi di richiesta

### 1) Guidato da audio (audio2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2) Guidato da testo (text2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "Fratello, da quanto tempo, sto bene, devi prenderti cura di te.",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## Esempio di risposta (successo sincrono)

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| Campo          | Tipo      | Descrizione                                         |
| -------------- | --------- | -------------------------------------------------- |
| `success`      | boolean   | Se è riuscito                                       |
| `task_id`      | string    | ID del compito attuale (può essere utilizzato per la query di `/kling/tasks`)             |
| `video_id`     | string    | ID Kling del video generato (può essere utilizzato come input per il prossimo `extend`/`lip-sync`) |
| `video_url`    | string    | URL del video parlante generato (archiviato su CDN di questa piattaforma, valido a lungo termine)              |
| `duration`     | string    | Durata del video (secondi)                                    |
| `state`        | string    | Stato del compito: `succeed` / `failed`                  |

## Modalità asincrona e query

Fornendo `callback_url` o `async: true`, l'interfaccia **restituisce immediatamente** `task_id`; successivamente è possibile:

- **Polling**: `POST /kling/tasks`, body `{ "action": "retrieve", "id": "<task_id>" }` (gratuito)
- **Callback**: dopo il completamento della generazione, il risultato viene POSTato al tuo `callback_url`

## Flusso completo: foto parlanti (image2video → lip-sync)
```bash
# Passo 1: Fai muovere la foto, ottieni il video_id
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"guarda in camera, naturale","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# Passo 2: Sincronizza il labiale con l'audio
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"}'
# → { "video_url": "https://platform2.cdn.acedata.cloud/kling/....mp4", ... }
```

## Risposta di errore

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "uno tra video_id o video_url è richiesto" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | codice                  | significato                                           |
| ---- | ----------------------- | ---------------------------------------------------- |
| 400  | `bad_request`           | Parametri mancanti o non validi (ad esempio, mode non fornito, conflitto tra video e audio, testo oltre 120 caratteri) |
| 401  | `authorization_missing` | Chiave API mancante o non valida                      |
| 403  | `forbidden`             | Contenuto bloccato da controlli di sicurezza         |
| 429  | `too_many_requests`     | Limite di concorrenza superato, riprovare più tardi  |
| 500  | `api_error`             | Errore upstream o interno                             |

## Note

- `video_id` deve essere un video Kling generato **negli ultimi 30 giorni** e della durata di **5s o 10s**; in caso contrario, utilizzare `video_url` per fornire un video conforme ai requisiti.
- Si consiglia di utilizzare video **chiari, frontali e con una sola persona**, per i migliori risultati di sincronizzazione labiale.
- La durata dell'audio/testo deve corrispondere alla durata del video (l'audio non deve superare la lunghezza del video).
- La fatturazione avviene al momento del **successo** (2,45 Crediti/volta); i fallimenti di convalida dei parametri (4xx) non comportano costi.
