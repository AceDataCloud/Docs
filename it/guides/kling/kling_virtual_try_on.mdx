Invia un'attività tramite `POST /kling/virtual-try-on`, utilizza l'esistente `POST /kling/tasks` per verificare lo stato dell'attività sulla piattaforma.

## Input

Deve essere fornita esattamente un'immagine product_image e un'immagine person_image. keep_face, keep_pose, keep_background sono tutti true per impostazione predefinita e possono essere disattivati indipendentemente. Il lato più lungo dell'immagine di input non deve superare 2048px, il lato più corto deve essere maggiore di 300px e il file non deve superare 10MB.

Di seguito è riportato un esempio della struttura della richiesta; sostituisci gli URL delle risorse prima di effettuare la chiamata.

```json
{
  "contents": [
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "person_image",
      "url": "https://your-cdn.example/person.jpg"
    }
  ],
  "async": true
}
```

## Risultati e fatturazione

La modalità sincrona restituisce il risultato generato; la modalità asincrona restituisce prima `task_id`, mentre il risultato completato include i link a video o immagini in `data` e il `usage` calcolato dal server. `callback_url` viene utilizzato per la notifica di completamento; la richiesta con `watermark=true` restituisce contemporaneamente la versione con filigrana.

1.12 Credits/immagine, fatturati in base al numero effettivo di immagini di output. I video vengono fatturati in base alla durata effettiva generata; il prezzo base per secondo prima della generazione non rappresenta il prezzo totale dell'intera attività. Le attività non riuscite non comportano costi di generazione.
