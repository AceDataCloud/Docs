---
title: "API Foto Parlante Kling (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Trasforma con un clic **una foto + un audio** in un 「video parlante」。Il servizio completa automaticamente due passaggi interni: prima utilizza image2video per animare la foto, poi usa lip-sync per sincronizzare le labbra con l'audio. Devi effettuare **una sola** chiamata.

- **Endpoint**：`POST https://api.acedata.cloud/kling/talking-photo`
- **Fatturazione**：in base alla durata, 5 secondi **16.45 Credits**、10 secondi **30.45 Credits**(= prezzo combinato image2video + lip-sync)

## Intestazioni della richiesta

| Campo              | Valore                   |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## Parametri della richiesta

| Parametro             | Tipo      | Obbligatorio  | Predefinito                  | Descrizione                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | Sì   | —                   | URL pubblico della foto del personaggio, si consiglia un volto frontale nitido                    |
| `audio_url`    | string  | Sì   | —                   | URL pubblico dell'audio guida（.mp3/.wav/.m4a/.aac,≤5MB） |
| `prompt`       | string  | No   | —                   | Prompt per azioni/espressioni nella fase di animazione della foto                      |
| `model`        | string  | No   | `kling-v2-1-master` | Modello Kling utilizzato per l'animazione della foto                     |
| `duration`     | integer | No   | `5`                 | Durata del video（5 o 10 secondi）                        |
| `mode`         | string  | No   | `pro`               | Qualità dell'animazione（std/pro）                        |
| `callback_url` | string  | No   | —                   | Se passato o se `async=true`, restituisce task_id in modo asincrono        |
| `async`        | boolean | No   | `false`             | Modalità asincrona, utilizza il polling o il callback con `/kling/tasks`          |

## Esempio di richiesta

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Esempio di risposta

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Campo                 | Descrizione                        |
| ------------------ | ------------------------- |
| `video_url`        | Video parlante finale（già trasferito sul CDN di questa piattaforma）      |
| `source_video_url` | Video intermedio di animazione della foto（risultato image2video） |
| `video_id`         | ID del video Kling                   |

## Note

- Per la foto si consiglia un volto frontale nitido, di una sola persona.
- Si consiglia che la durata dell'audio non superi quella del video（5s/10s）。
- La fatturazione avviene al successo; gli errori di convalida dei parametri（4xx）non vengono fatturati。
- Il tempo di generazione è di circa 4–6 minuti（due passaggi), si consiglia di utilizzare `async=true` + il polling su `/kling/tasks`。
