---
title: "API di Foto Parlanti Kling (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Con un clic, trasforma **una foto + un audio** in un video "parlante". Il servizio completa automaticamente due passaggi: prima utilizza image2video per animare la foto, poi utilizza il lip-sync per sincronizzare il movimento delle labbra con l'audio. Devi solo chiamare **una volta**.

- **Indirizzo API**: `POST https://api.acedata.cloud/kling/talking-photo`
- **Fatturazione**: in base alla durata, 5 secondi **16,45 Crediti**, 10 secondi **30,45 Crediti** (= prezzo combinato di image2video + lip-sync)

## Intestazioni della Richiesta

| Campo              | Valore                 |
| ----------------- | --------------------- |
| `authorization`   | `Bearer ${API_KEY}`   |
| `content-type`    | `application/json`    |

## Parametri della Richiesta

| Parametro        | Tipo      | Obbligatorio | Predefinito           | Descrizione                                 |
| ---------------- | --------- | ------------ | --------------------- | ------------------------------------------- |
| `image_url`      | string    | Sì           | —                     | URL pubblico della foto del soggetto, si consiglia un'immagine chiara e frontale |
| `audio_url`      | string    | Sì           | —                     | URL pubblico dell'audio (formati .mp3/.wav/.m4a/.aac, ≤5MB) |
| `prompt`         | string    | No           | —                     | Parole chiave per suggerire azioni/espressioni durante l'animazione della foto |
| `model`          | string    | No           | `kling-v2-1-master`  | Modello Kling utilizzato per l'animazione della foto |
| `duration`       | integer   | No           | `5`                   | Durata del video (5 o 10 secondi)          |
| `mode`           | string    | No           | `pro`                 | Qualità dell'animazione (std/pro)          |
| `callback_url`   | string    | No           | —                     | Se fornito o `async=true`, restituisce task_id in modo asincrono |
| `async`          | boolean   | No           | `false`               | Modalità asincrona, da utilizzare con `/kling/tasks` per polling o callback |

## Esempio di Richiesta

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Esempio di Risposta

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "source_video_url": "https://platform2.cdn.acedata.cloud/kling/163ac822-1a15-4f5e-a2eb-465154df15af.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Campo                | Descrizione                               |
| ------------------- | ----------------------------------------- |
| `video_url`         | Il video finale parlante (archiviato su CDN della piattaforma) |
| `source_video_url`  | Il video animato intermedio (risultato di image2video) |
| `video_id`          | ID del video Kling                        |

## Note

- Si consiglia di utilizzare foto chiare, frontali e di una sola persona.
- La durata dell'audio non dovrebbe superare la durata del video (5s/10s).
- La fatturazione avviene al momento del successo; i fallimenti di convalida dei parametri (4xx) non vengono addebitati.
- Il tempo di generazione è di circa 4–6 minuti (due passaggi), si consiglia di utilizzare `async=true` + `/kling/tasks` per il polling.
