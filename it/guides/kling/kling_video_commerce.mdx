---
title: "Guida all'integrazione del parlato e-commerce"
description: "Kling video generation API guide - Ace Data Cloud"
---

Invia un'attività tramite `POST /kling/video-commerce` e utilizza il già disponibile `POST /kling/tasks` per verificare lo stato dell'attività sulla piattaforma.

## Input

Carica un'immagine di una persona e specifica voice_id, oppure utilizza un avatar_id preimpostato (i due sono mutuamente esclusivi e per i personaggi preimpostati non è possibile specificare ulteriormente voice_id). È obbligatorio fornire uno speech_script di massimo 2000 caratteri. Quando si forniscono informazioni sul prodotto, sono necessari almeno una ref_image e un goods_title; il parlato del prodotto non supporta speech_rate. Il normale parlato di una persona supporta una velocità di 0.8, 1.0 o 1.2 volte.

Di seguito è riportato un esempio della struttura della richiesta: sostituisci gli URL delle risorse prima di effettuare la chiamata.

```json
{
  "contents": [
    {
      "type": "avatar_image",
      "url": "https://your-cdn.example/person.jpg"
    },
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    },
    {
      "type": "speech_script",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "voice_id": "male_calm_informative"
  },
  "async": true
}
```

## Risultati e fatturazione

La modalità sincrona restituisce il risultato generato; la modalità asincrona restituisce prima `task_id`, e il risultato completato include i collegamenti al video o all'immagine in `data` e l'`usage` calcolato dal server. `callback_url` viene utilizzato per la notifica di completamento; una richiesta con `watermark=true` restituisce contemporaneamente la versione con filigrana.

Normale parlato di una persona: 1.4 Credits/secondo per 720p e 1.68 Credits/secondo per 1080p; parlato del prodotto: 1.96 Credits/secondo per 720p e 2.24 Credits/secondo per 1080p. I video vengono fatturati in base alla durata effettiva generata; il prezzo base al secondo prima della generazione non rappresenta il prezzo totale dell'intera attività. Le attività non riuscite non comportano costi di generazione.
