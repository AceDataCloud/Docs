---
title: "Suno API di generazione di testi misti"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Se desideri utilizzare i testi di due canzoni per generare una canzone mista, puoi prima utilizzare questa API per generare i testi corrispondenti. L'API è [Suno MashupLyrics Generation API](https://platform.acedata.cloud/documents/suno-mashup-lyrics).

I principali parametri di input per questa API sono `lyrics_a` e `lyrics_b`, un esempio di compilazione è il seguente:

![](https://cdn.acedata.cloud/g9n3t6.png)

Clicca su Esegui, il risultato sarà il seguente:

```
{
  "success": true,
  "task_id": "80aa3cd3-ca87-4ca3-82d2-1830e3d8f53a",
  "data": {
    "text": "Sambuy torna  \nBluespawn, greenspawn ti stanno facendo un spawn  \n\nSambuy torna  \nSambuy torna  \nBluespawn, greenspawn ti stanno facendo un spawn  \n\nSambuy torna  \nSambuy torna  \nBluespawn, greenspawn ti stanno facendo un spawn  \n\nSambuy torna  \nSambuy torna  \nSambuy, Sambuy torna  \nBluespawn, greenspawn ti stanno facendo un spawn  \n\nSambuy torna  \nSambuy torna  \nBluespawn, greenspawn ti stanno facendo un spawn  \nSambuy torna",
    "title": "Testi Misti",
    "tags": [],
    "status": "completo"
  }
}
```

Come puoi vedere, il campo `text` di `data` contiene le informazioni sui testi.

Una volta ottenuti i testi, possiamo utilizzare [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) per generare canzoni personalizzate.
