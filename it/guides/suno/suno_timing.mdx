SUNO ci permette di effettuare una seconda creazione sulla musica generata, ottenendo i testi delle canzoni e la timeline audio. Questo documento spiega il metodo di integrazione delle API correlate.

Questa API ha un solo parametro di input, ovvero `audio_id`, che è l'ID della canzone generata ufficialmente.

Qui inseriamo come `audio_id` il valore `ec13e502-d043-4eb2-92ee-e900c6da69d1`.

```python
import requests

url = "https://api.acedata.cloud/suno/timing"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "ec13e502-d043-4eb2-92ee-e900c6da69d1"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Descrizione del campo aligned_words

Come si può vedere, `data.aligned_words` è un array di oggetti, ciascuno rappresenta una parola o una frase con informazioni temporali.

- `word`: la parola o frase effettiva nel testo della canzone
- `success`: valore booleano che indica se l'allineamento di questa parola è riuscito
- `start_s`: tempo di inizio della parola
- `end_s`: tempo di fine della parola
- `p_align`: probabilità o punteggio di confidenza dell'allineamento, con valore compreso tra 0 e 1
