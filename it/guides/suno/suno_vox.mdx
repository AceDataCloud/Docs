SUNO ci consente di creare una nuova versione di Persona-v2-vox: stile cantante, a differenza della versione precedente, è necessario prima ottenere il valore del parametro `vox_audio_id`. Questo documento spiega il metodo di integrazione per creare la nuova versione di Persona-v2-vox.

Prima di tutto, è necessario utilizzare questa API per ottenere il valore del parametro `vox_audio_id`, questa API può accettare più parametri di input, come `audio_id`, `vocal_start`, `vocal_end`, che si riferiscono all'ID della canzone e all'intervallo di tempo selezionato.

Qui l'`audio_id` che inseriamo è `42599b24-fb14-4cd3-a444-e15ffde3661b`.

```python
import requests

url = "https://api.acedata.cloud/suno/vox"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Possiamo vedere che il campo `id` di `data` è il `vox_audio_id` che desideriamo, quindi andiamo a creare la nuova versione di Persona-v2-vox: stile cantante utilizzando l'[API Persona](https://platform.acedata.cloud/documents/suno-persona), i dettagli di input sono mostrati di seguito:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "test",
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20,
    "vox_audio_id": "24f0827e-5847-4011-b9b7-fc0b62032b65"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Dopo la chiamata otteniamo il seguente risultato:

```json
{
  "success": true,
  "task_id": "e04b06a1-ff61-48e2-9fcc-15284bd18481",
  "data": {
    "persona_id": "49bef16d-6a09-49d1-8c24-a81663698b98"
  }
}
```

Poi possiamo utilizzare il valore di `persona_id` sopra per creare la nuova versione di Persona-v2-vox: stile cantante, il metodo di creazione specifico è lo stesso delle [Istruzioni di integrazione dell'API di generazione di canzoni Suno](https://platform.acedata.cloud/documents/suno-audios-integration#%E8%87%AA%E5%AE%9A%E4%B9%89%E6%AD%8C%E6%89%8B%E9%A3%8E%E6%A0%BC%E7%94%9F%E6%88%90%E5%8A%9F%E8%83%BD), infine possiamo utilizzare l'API Suno Vox per realizzare canzoni con la nuova versione di Persona-v2-vox: stile cantante.
