Se desideri generare canzoni personalizzate, ma non vuoi scrivere i testi da solo, puoi utilizzare l'API di generazione testi fornita da AceDataCloud per generare testi tramite prompt. L'API è [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Il principale parametro di input di questa API è `prompt`, con `model` opzionale (predefinito chirp-v3), un esempio di compilazione è il seguente:

![](https://cdn.acedata.cloud/p53wtj.png)

Qui il `prompt` che abbiamo inserito è `A song about winter`, generando una canzone relativa all'inverno.

Clicca su Esegui, il risultato è il seguente:

```
{
  "success": true,
  "task_id": "57e8ce3a-39cb-41a2-802f-e70a324f4d0a",
  "data": {
    "text": "[Verse]\nFiocchi di neve che cadono dal cielo\nIl freddo tocco dell'inverno\nOh come mi fa sentire in alto\nMi avvolgo in strati\nOh così accogliente\nUscendo e sentendo il gelo sul mio naso\nVedi\n\n[Verse 2]\nIl mondo è coperto da una coperta bianca\nGhiaccioli appesi\nBrillando così luminosi\nL'aria fredda riempie i miei polmoni ad ogni respiro\nCamminando nella neve\nLasciando impronte che non verranno dimenticate\n\n[Chorus]\nOh\nIl freddo tocco dell'inverno\nÈ una stagione che amo così tanto\nLa neve porta una sensazione così divina\nIl freddo tocco dell'inverno\nÈ un momento magico",
    "title": "Il Freddo Tocco dell'Inverno",
    "status": "complete"
  }
}
```

Si può notare che il campo `text` di `data` contiene le informazioni sui testi.

Una volta ottenuti i testi, possiamo utilizzare [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) per generare canzoni personalizzate.
