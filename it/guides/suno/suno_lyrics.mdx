title: "Istruzioni per l'integrazione dell'API di generazione testi Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Se desideri generare canzoni personalizzate, ma non vuoi scrivere i testi da solo, puoi utilizzare l'API di generazione testi fornita da AceDataCloud per generare testi tramite prompt; l'API è [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Tariffazione: dopo una generazione riuscita, il costo standard per ogni richiesta è di **0.08 Crediti**. Quando una richiesta restituisce più candidati di testi, viene comunque addebitata una sola volta; gli sconti di consumo applicabili sono soggetti alla fattura effettiva, le richieste fallite non vengono addebitate.

Il principale parametro di input di questa API è `prompt`, con `model` opzionale (valori opzionali `default`, `remi-v1`, valore predefinito `default`); l'esempio di compilazione è il seguente:

![](https://cdn.acedata.cloud/p53wtj.png)

Qui il `prompt` che inseriamo è `A song about winter`, per generare una canzone relativa all'inverno.

Clicca su esegui, il risultato è il seguente:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nSnowflakes falling from the sky\nWinter's cold touch\nOh how it gets me high\nI bundle up in layers\nOh so cozy\nStepping out and feeling the frost on my nose\n\n[Chorus]\nOh\nWinter's cold touch\nIt's a season that I love so much\nSnowfall brings a feeling so divine\nWinter's cold touch\nIt's a magical time",
      "title": "Winter's Cold Touch",
      "status": "complete",
      "tags": ["dreamy, mellow, ballad"]
    },
    {
      "text": "[Verse]\nThe world is covered in a blanket of white\nIcicles hanging\nShimmering so bright\nThe chilly air fills my lungs with every breath\nWalking in the snow\nLeaving footprints behind\n\n[Chorus]\nWinter wonderland\nEverything is so bright\nWinter wonderland\nHold me through the night",
      "title": "Winter Wonderland",
      "status": "complete",
      "tags": ["dream pop, mellow, shoegaze"]
    }
  ],
  "started_at": 1780684179.15,

```

Si può vedere che `data` è un array, e ogni volta restituisce più candidati di testi, tra i quali il campo `text` di ciascun elemento è il contenuto del testo, `title` è il titolo e `tags` sono le etichette di stile musicale consigliate.

Dopo aver ottenuto i testi, possiamo utilizzare [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) per effettuare la generazione di canzoni personalizzate.
