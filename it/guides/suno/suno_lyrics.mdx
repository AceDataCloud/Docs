---
title: "Suno API di generazione testi"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Se desideri generare canzoni personalizzate, ma non vuoi scrivere i testi da solo, puoi utilizzare l'API di generazione testi fornita da AceDataCloud per generare testi tramite prompt. L'API è [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Il principale parametro di input per questa API è `prompt`, con `model` (valori opzionali `default`, `remi-v1`, predefinito `default`) come opzionale. Ecco un esempio di compilazione:

![](https://cdn.acedata.cloud/p53wtj.png)

Qui il `prompt` inserito è `A song about winter`, generando una canzone relativa all'inverno.

Cliccando su esegui, il risultato è il seguente:

```json

  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nFiocchi di neve che cadono dal cielo\nIl freddo tocco dell'inverno\nOh come mi fa sentire in alto\nMi avvolgo in strati\nOh così accogliente\nUscendo e sentendo il gelo sul mio naso\n\n[Chorus]\nOh\nIl freddo tocco dell'inverno\nÈ una stagione che amo così tanto\nLa neve porta una sensazione così divina\nIl freddo tocco dell'inverno\nÈ un momento magico",
      "title": "Il freddo tocco dell'inverno",
      "status": "complete",
      "tags": ["sognante, morbido, ballata"]
    },
    {
      "text": "[Verse]\nIl mondo è coperto da una coperta bianca\nGhiaccioli appesi\nBrillando così luminosi\nL'aria fredda riempie i miei polmoni ad ogni respiro\nCamminando nella neve\nLasciando impronte dietro di me\n\n[Chorus]\nPaesaggio invernale\nTutto è così luminoso\nPaesaggio invernale\nTienimi attraverso la notte",
      "title": "Paesaggio Invernale",

```

Si può notare che `data` è un array, e ogni volta restituisce più candidati per i testi, dove il campo `text` di ogni elemento è il contenuto del testo, `title` è il titolo, e `tags` sono i generi musicali consigliati.

Una volta ottenuti i testi, possiamo utilizzare [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) per generare canzoni personalizzate.
