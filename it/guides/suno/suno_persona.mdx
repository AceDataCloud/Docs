---
title: "Istruzioni per l'integrazione dell'API per lo stile cantante personalizzato di Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO ci consente di impostare uno stile cantante per le canzoni già generate e poi di effettuare una seconda creazione basata su di esso; questo documento spiega il metodo di integrazione delle API correlate.

Le operazioni di query dell'elenco `GET /suno/persona` e di eliminazione del record `DELETE /suno/persona` non sono a pagamento e non richiedono intestazioni aggiuntive per richieste esenti da addebito. L'operazione di creazione `POST /suno/persona` continua a essere addebitata secondo le regole di prezzo dell'interfaccia.

Questa API ha solo tre parametri di input: prima `audio_id`, che è l'ID di una canzone già generata con successo sulla piattaforma ufficiale; poi `name` e `description`, che sono rispettivamente un nome e una descrizione dello stile cantante.

Qui l'`audio_id` che inseriamo è `https://cdn.acedata.cloud/2qhzs3.png`; per questo è possibile fare riferimento a [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) per effettuare la generazione di canzoni personalizzate e ottenere infine `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Il risultato è il seguente:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Si può vedere che il campo `persona_id` di `data` è l'ID dello stile cantante generato.

Dopo aver ottenuto l'ID dello stile cantante, possiamo utilizzare [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) per effettuare la generazione di canzoni personalizzate; ad esempio, passando `artist_consistency` a `action`, passando contemporaneamente l'ID della canzone caricata a `audio_id` e caricando anche il parametro `persona_id`, il cui valore è l'ID dello stile cantante restituito sopra, sarà possibile generare nuove canzoni in base allo stile cantante di riferimento.
