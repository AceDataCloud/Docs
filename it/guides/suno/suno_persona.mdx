---
title: "Istruzioni per l'integrazione dell'API dello stile cantante personalizzato di Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO ci consente di impostare uno stile cantante per le canzoni già generate, per poi effettuare una creazione secondaria basata su di esso; questo documento illustra il metodo di integrazione delle relative API.

La query dell'elenco `GET /suno/persona` e l'eliminazione dei record `DELETE /suno/persona` non vengono addebitate e non richiedono intestazioni aggiuntive per richieste non a pagamento. L'operazione di creazione `POST /suno/persona` continua a essere addebitata secondo le regole di tariffazione dell'interfaccia.

Sulle linee di creazione che supportano la query del timbro vocale, è possibile utilizzare l'applicazione originale e l'identità del chiamante per passare il `persona_id` nei risultati della creazione a `POST /suno/availability`. Quando la disponibilità è confermata, viene restituito `data.available=true`. [Guida alla query di disponibilità del timbro vocale](https://platform.acedata.cloud/documents/suno-availability-integration)

Questa API ha solo tre parametri di input: innanzitutto `audio_id`, che è l'ID di una canzone già generata con successo ufficialmente; poi `name` e `description`, che sono un nome e una descrizione dello stile cantante.

Qui l'`audio_id` che inseriamo è `https://cdn.acedata.cloud/2qhzs3.png`; puoi fare riferimento a [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) per effettuare la generazione di canzoni personalizzate e infine ottenere l'`audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Il risultato è il seguente:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Come si può vedere, il campo `persona_id` di `data` è l'ID dello stile cantante dopo la generazione.

Dopo aver ottenuto l'ID dello stile cantante, possiamo utilizzare [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) per effettuare la generazione di canzoni personalizzate. Ad esempio, passando `artist_consistency` in `action`, passando contemporaneamente l'ID della canzone caricata in `audio_id`, e caricando inoltre il parametro `persona_id`, il cui valore è l'ID dello stile cantante restituito sopra, sarà possibile generare nuove canzoni in base allo stile cantante di riferimento.
