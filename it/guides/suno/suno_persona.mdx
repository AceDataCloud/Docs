---
title: "Suno API di integrazione per lo stile del cantante personalizzato"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO ci consente di impostare lo stile del cantante per le canzoni già generate e di effettuare una seconda creazione basata su di esso. Questo documento spiega come integrare le API correlate.

Questa API ha solo tre parametri di input: innanzitutto `audio_id`, che è un ID di una canzone già generata con successo dall'ufficiale, poi `name` e `description`, che sono un nome e una descrizione per lo stile del cantante.

Qui inseriamo `audio_id` come `https://cdn.acedata.cloud/2qhzs3.png`, questo può essere consultato nel [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) per generare canzoni personalizzate, infine si può ottenere `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Il risultato è il seguente:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Si può notare che il campo `persona_id` di `data` è l'ID dello stile del cantante generato.

Una volta ottenuto l'ID dello stile del cantante, possiamo utilizzare il [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) per generare canzoni personalizzate, ad esempio passando `action` come `artist_consistency`, mentre `audio_id` è l'ID della canzone caricata, è necessario anche caricare il parametro `persona_id`, il cui valore è l'ID dello stile del cantante restituito sopra, in modo da generare nuove canzoni basate sullo stile del cantante di riferimento.
