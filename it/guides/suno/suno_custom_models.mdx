---
title: "Guida all'integrazione del modello musicale personalizzato Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Il modello musicale personalizzato può apprendere caratteristiche musicali coerenti da 6 a 24 audio autorizzati ed essere utilizzato per la successiva creazione di canzoni. La creazione è un'operazione asincrona; si consiglia di utilizzare 24 audio con stile coerente e qualità sonora nitida per ottenere risultati più stabili.

> È possibile inviare solo audio per i quali si possiedono diritti di utilizzo legittimi o per i quali è stata ottenuta l'autorizzazione alla creazione del modello e alle generazioni successive. Non caricare musica o materiale sonoro non autorizzato.

## Creare un modello

Chiamare `POST /suno/custom-models` e impostare `action=create`:

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

L'interfaccia restituisce immediatamente l'ID del modello della piattaforma e l'ID dell'attività. Al completamento della creazione, lo `status` nel callback o nel risultato della query diventerà `ready`. Verranno addebitati **10 Credits** solo se la creazione del modello ha esito positivo; in caso di fallimento della creazione non verrà effettuato alcun addebito.

## Interrogare un modello

Interrogare un singolo modello:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Interrogare con paginazione i modelli dell'applicazione corrente:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Tutti i modelli appartengono all'applicazione Suno che li ha creati. La rotazione delle credenziali API non modifica l'appartenenza del modello e le altre applicazioni non possono interrogare o utilizzare il modello.

## Utilizzare il modello per generare canzoni

Dopo che lo stato del modello è `ready`, continuare a chiamare `POST /suno/custom-models` e impostare `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id` deve essere un modello musicale personalizzato con stato `ready` nell'applicazione corrente. La richiesta fallirà quando il modello non è disponibile e non verrà automaticamente utilizzato un altro modello. `persona_id` e il modello musicale personalizzato si escludono a vicenda; se inviati contemporaneamente, l'interfaccia restituirà HTTP 400 prima che la richiesta venga inviata al servizio di generazione e non verrà effettuato alcun addebito. Per utilizzare Persona, usare invece l'operazione `artist_consistency` o `artist_consistency_vox` di `/suno/audios`.

La generazione riuscita di una canzone consuma **0.90 Credits**; in caso di fallimento della generazione non viene effettuato alcun addebito. L'interrogazione e l'archiviazione dei modelli sono gratuite.

## Archiviare un modello

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

L'attuale versione Beta archivierà il modello e ne impedirà l'ulteriore utilizzo; `capacity_released=false` nella risposta indica che l'archiviazione non garantisce il rilascio della capacità del modello. L'operazione di archiviazione può essere chiamata ripetutamente e non verrà addebitata più volte.
