---
title: "Guida all'integrazione del modello musicale esclusivo Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Il modello musicale esclusivo può apprendere caratteristiche musicali coerenti da 6 a 24 audio autorizzati e utilizzato per la creazione di canzoni successive. La creazione è un'operazione asincrona; si consiglia di utilizzare 24 audio con uno stile coerente e una qualità audio chiara per ottenere risultati più stabili.

> È possibile inviare solo audio di cui si possiede il diritto legale di utilizzo o per cui si è ottenuta l'autorizzazione per la creazione del modello e la generazione successiva. Non caricare musica o materiali sonori non autorizzati.

## Creazione del modello

Chiamare `POST /suno/custom-models` e impostare `action=create`. Si consiglia di inviare anche un'intestazione di richiesta `Idempotency-Key` unica; riutilizzare la stessa chiave durante i tentativi di rete per evitare creazioni duplicate:

```json
{
  "action": "create",
  "name": "Il mio modello Indie",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

L'interfaccia restituisce immediatamente l'ID del modello della piattaforma e l'ID del compito. Una volta completata la creazione, il `status` nel callback o nei risultati cambierà in `ready`. Solo i modelli creati con successo saranno addebitati; i fallimenti nella creazione non comporteranno costi.

## Consultazione del modello

Consultare un singolo modello:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Consultazione paginata dei modelli attuali dell'app:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Tutti i modelli appartengono all'app Suno che li ha creati. La rotazione delle credenziali API non cambierà l'appartenenza del modello, altre app non possono consultare o utilizzare quel modello.

## Utilizzo del modello per generare canzoni

Dopo che lo stato del modello è `ready`, continuare a chiamare `POST /suno/custom-models` e impostare `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nLe luci della città cadono attraverso la pioggia",
  "style": "indie rock, synth analogico caldo"
}
```

`id` deve essere il modello musicale esclusivo con stato `ready` sotto l'app attuale. Se il modello non è disponibile, la richiesta fallirà e non verrà automaticamente utilizzato un altro modello.

## Archiviazione del modello

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

L'attuale versione Beta archivierà il modello e ne impedirà l'ulteriore utilizzo, la risposta con `capacity_released=false` indica che l'archiviazione non garantisce il rilascio della capacità del modello. L'operazione di archiviazione può essere chiamata ripetutamente senza costi aggiuntivi.
