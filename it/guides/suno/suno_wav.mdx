SUNO ci consente di ottenere file audio in formato wav. Questo documento spiega come integrare le relative API.

Il parametro di input principale di questa API è `audio_id`, che è l'ID della canzone generato ufficialmente; è facoltativo anche supportare `callback_url` come indirizzo di callback asincrono.

L'`audio_id` che inseriamo è `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer YOUR_API_KEY",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Il risultato è il seguente:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://cdn.acedata.cloud/e724d7f13d.png?example=image-001"
    }
  ]
}
```

Possiamo vedere che il campo `file_url` di `data` è il file audio in formato wav ottenuto, ed è un indirizzo CDN accessibile pubblicamente.

> **Riguardo alla persistenza del link WAV**
> La piattaforma priorizzerà la persistenza del file WAV finale nel CDN di Ace Data Cloud prima di restituire la risposta. L'URL sopra mostra solo il formato di risposta e non rappresenta un oggetto reale a lungo termine. Solo se la persistenza nel CDN non è completata e l'indirizzo del media originale, dopo una verifica immediata, consente ancora di scaricare un file WAV valido, `file_url` potrebbe mantenere tale indirizzo; se l'indirizzo è scaduto o la verifica del file fallisce, la richiesta restituirà un errore o un timeout, e non fornirà indirizzi non scaricabili come risultato di successo. Si prega di scaricare e conservare tempestivamente dopo il completamento del compito, il periodo di conservazione specifico è soggetto alla politica di archiviazione attuale della piattaforma.
