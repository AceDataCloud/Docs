description: "Suno Music Generation 集成指南 - Ace Data Cloud"

SUNO ci consente di creare personaggi vocali personalizzati tramite qualsiasi file audio, realizzando la clonazione vocale per la generazione musicale. A differenza della Persona API esistente (che utilizza `audio_id` generato da Suno), questa API accetta un `audio_url` accessibile pubblicamente, ovvero una registrazione vocale personale. Questo documento spiega come integrare l'API di clonazione vocale.

## Primo passo: creare un personaggio vocale

Questa API ha tre parametri di input: `audio_url` (obbligatorio), un URL pubblico di un file audio in formato MP3 o WAV contenente una voce chiara di una singola persona; `name` e `description` (opzionali), il nome e la descrizione del personaggio vocale.

**Requisiti del file audio:**
- Formato: MP3 o WAV
- Durata: almeno 10 secondi
- Contenuto: voce chiara di una singola persona, con rumori di fondo o musica ridotti al minimo

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

Il risultato sarà:

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

Come si vede, il campo `persona_id` in `data` è l'ID del personaggio vocale creato. Il campo `is_public` è sempre `false` perché i personaggi vocali creati tramite upload audio sono privati.

## Secondo passo: generare musica con il personaggio vocale

Con l'ID del personaggio vocale, possiamo utilizzare la [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) per generare musica. Impostando `action` su `generate` e `persona_id` sull'ID del personaggio vocale restituito, la canzone generata sarà cantata con la voce clonata.

> **Nota:** la clonazione vocale supporta solo modelli `chirp-v4-5` e superiori (ad esempio `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), non supporta `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

Il risultato sarà:

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

Come si vede, la canzone generata è cantata con la voce clonata. L’`persona_id` può anche essere usato con l’azione `cover` per reinterpretare canzoni esistenti con la voce clonata.
