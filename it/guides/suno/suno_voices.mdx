---
title: "Istruzioni per l'integrazione dell'API di clonazione vocale Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO ci consente di creare personaggi vocali personalizzati tramite qualsiasi file audio, realizzando la clonazione vocale per la generazione musicale. A differenza dell'API Persona esistente (che utilizza l'`audio_id` generato da Suno), questa API accetta un `audio_url` accessibile pubblicamente, ovvero la propria registrazione vocale. Questo documento illustra come integrare l'API di clonazione vocale.

## Passaggio 1: creare un personaggio vocale

Fatturazione: dopo la creazione riuscita del personaggio vocale, la tariffa standard per ogni richiesta è di **0.15 Credits**. Gli sconti di consumo applicabili sono soggetti alla fattura effettiva; le richieste non riuscite non vengono addebitate.

Questa API dispone di tre parametri di input: `audio_url` (obbligatorio), ovvero l'URL di un file audio MP3 o WAV accessibile pubblicamente contenente una voce chiara di una sola persona; `name` e `description` (facoltativi), ovvero il nome e la descrizione del personaggio vocale.

> **Requisiti del file audio**
> - Il formato audio deve essere `WAV` o `MP3`
> - La durata dell'audio deve essere compresa tra `10~240 secondi`; si consiglia di utilizzare materiale vocale pulito e senza accompagnamento di una sola persona della durata di `30~60 secondi`
> - L'audio deve contenere una **voce parlata o cantata chiara e riconoscibile di una sola persona**
> - Assicurarsi di evitare **rumore di fondo, accompagnamento, eco, riverbero**; le canzoni complete con accompagnamento solitamente non superano la verifica dell'impronta vocale
> - Non includere **più parlanti** o **voci multiple**
> - Materiale con volume troppo basso, voce poco chiara o rumore eccessivo può causare il **fallimento della clonazione** o **risultati di generazione scadenti**
> **Descrizione delle limitazioni d'uso**
> - I personaggi vocali creati caricando audio sono **risorse private**
> - Questo personaggio vocale **non supporta il riutilizzo tra account**
> - Si consiglia di utilizzarlo il prima possibile dopo la creazione riuscita; un mancato utilizzo prolungato potrebbe causarne la **scadenza o l'indisponibilità**
> - Il `name` restituito viene generato automaticamente dal sistema; fare riferimento al `persona_id` restituito

> **In caso di errore di chiamata, riprovare prima**
> La clonazione vocale è un'attività ad alta intensità di calcolo e, anche se il materiale è completamente conforme, esiste una certa probabilità di errori occasionali; restituzioni comuni includono
> `voices_sound_different` (verifica dell'impronta vocale non superata) e così via. **Questo tipo di errore non è correlato alla qualità dell'audio; riprovare con lo stesso materiale di solito consente di ottenere successo**,
> si consiglia di implementare 1~2 tentativi automatici per i risultati non riusciti durante l'integrazione. Le richieste non riuscite non vengono addebitate.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Il suddetto `https://cdn.acedata.cloud/suno_demo.mp3` è materiale di esempio richiamabile direttamente (MP3, 41 secondi, voce senza accompagnamento di una sola persona).
> Se è necessario un esempio in formato `WAV`, è possibile utilizzare
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 secondi, mono 44.1kHz).

Il risultato è il seguente:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Come si può vedere, il campo `persona_id` di `data` è l'ID del personaggio vocale creato. Il campo `is_public` è sempre `false`, perché i personaggi vocali creati caricando audio sono privati. Si noti che il `name` restituito viene generato automaticamente dal sistema; utilizzare successivamente `persona_id` per fare riferimento a questo personaggio vocale.

## Passaggio 2: utilizzare il personaggio vocale per generare musica

Una volta ottenuto l'ID del personaggio vocale, possiamo utilizzare la [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) per generare musica. Impostando `action` su `generate` e `persona_id` sull'ID del personaggio vocale restituito sopra, la canzone generata verrà cantata usando la voce clonata.

> **Nota:** la clonazione vocale supporta solo modelli `chirp-v4-5` e successivi (come `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), e non supporta `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Il risultato è il seguente:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` può essere utilizzato per la generazione `generate` e anche per le cover `cover` / `upload_cover`. Non è necessario compilare contemporaneamente `vocal_gender` quando si specifica una voce; la somiglianza vocale dipende comunque dal materiale di riferimento e dal risultato generato.

Le voci create tramite questa interfaccia sono risorse private. Prima di realizzare una cover di una canzone esistente, chiamare `/suno/upload`, passando l'`audio_url` della canzone originale e il `persona_id` di questa voce; dopo il caricamento riuscito, chiamare `/suno/audios` utilizzando il `data.audio_id` restituito e lo stesso `persona_id`:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

La creazione della voce, il caricamento della canzone originale e la cover devono utilizzare lo stesso canale di servizio. Non riutilizzare direttamente ID di canzoni precedenti che non sono stati associati a questa voce privata; per i dettagli, vedere [Suno carica audio di riferimento](https://platform.acedata.cloud/documents/suno-upload).
