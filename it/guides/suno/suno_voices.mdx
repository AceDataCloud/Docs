---

SUNO ci consente di creare personaggi vocali personalizzati tramite qualsiasi file audio, realizzando la clonazione vocale per la generazione musicale. A differenza dell'API Persona esistente (che utilizza l'`audio_id` generato da Suno), questa API accetta un `audio_url` accessibile pubblicamente, ovvero la propria registrazione vocale. Questo documento spiega come integrare l'API di clonazione vocale.

## Primo passo: creare un personaggio vocale

Questa API ha tre parametri di input: `audio_url` (obbligatorio), che è un URL di un file audio in formato MP3 o WAV accessibile pubblicamente, contenente una voce umana chiara di una sola persona; `name` e `description` (facoltativi), che sono il nome e la descrizione del personaggio vocale.

> **Requisiti del file audio**
> - Il formato audio deve essere `WAV` o `MP3`
> - La durata dell'audio deve essere compresa tra `10~240 secondi`; si consiglia di utilizzare materiale vocale pulito e senza accompagnamento di una sola persona di `30~60 secondi`
> - L'audio deve contenere una **voce parlata o cantata chiara e riconoscibile di una sola persona**
> - Assicurarsi di evitare **rumore di fondo, accompagnamento, eco, riverbero**; le canzoni complete con accompagnamento solitamente non superano la verifica dell'impronta vocale
> - Non includere **più parlanti** o **voci multiple**
> - Materiali con volume troppo basso, voce poco chiara o rumore eccessivo possono causare il **fallimento della clonazione** o una **qualità di generazione inferiore**
> **Descrizione delle limitazioni d'uso**
> - I personaggi vocali creati caricando audio sono **risorse private**
> - Questo personaggio vocale **non supporta il riutilizzo tra account**
> - Si consiglia di utilizzarlo il prima possibile dopo la creazione riuscita; se non viene utilizzato per lungo tempo potrebbe **scadere o diventare inutilizzabile**
> - Il `name` restituito viene generato automaticamente dal sistema; fare riferimento al `persona_id` restituito

> **In caso di fallimento della chiamata, riprovare prima**
> La clonazione vocale è un'attività ad alta intensità di calcolo; anche se il materiale è completamente conforme, esiste una certa probabilità di fallimenti occasionali, con risposte comuni come
> `voices_sound_different` (verifica dell'impronta vocale non superata), ecc. **Questo tipo di fallimento non è correlato alla qualità dell'audio; riprovare utilizzando lo stesso materiale solitamente consente di avere successo**,
> si consiglia di implementare 1~2 tentativi automatici per i risultati falliti durante l'integrazione. Le richieste fallite non vengono addebitate.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Il precedente `https://cdn.acedata.cloud/suno_demo.mp3` è un materiale di esempio utilizzabile direttamente (MP3, 41 secondi, voce singola senza accompagnamento).
> Se è necessario un esempio in formato `WAV`, è possibile utilizzare
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 secondi, mono 44,1 kHz).

Il risultato è il seguente:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Come si può vedere, il campo `persona_id` di `data` è l'ID del personaggio vocale creato. Il campo `is_public` è sempre `false`, poiché i personaggi vocali creati caricando audio sono privati. Si noti che il `name` restituito viene generato automaticamente dal sistema; utilizzare successivamente `persona_id` per fare riferimento a questo personaggio vocale.

## Secondo passo: utilizzare il personaggio vocale per generare musica

Dopo aver ottenuto l'ID del personaggio vocale, possiamo utilizzare la [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) per generare musica. Impostando `action` su `generate` e `persona_id` sull'ID del personaggio vocale restituito sopra, le canzoni generate utilizzeranno la voce clonata per il canto.

> **Nota:** La clonazione vocale supporta solo i modelli `chirp-v4-5` e superiori (come `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), e non supporta `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Il risultato è il seguente:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

Come si può vedere, la canzone generata utilizza la voce clonata per il canto. `persona_id` può anche essere utilizzato con l'azione `cover` per reinterpretare canzoni esistenti con la voce clonata.
