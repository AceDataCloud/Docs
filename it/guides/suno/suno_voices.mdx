SUNO ci consente di creare personaggi vocali personalizzati tramite qualsiasi file audio, realizzando il clonaggio vocale per la generazione musicale. A differenza dell'API Persona esistente (che utilizza l'`audio_id` generato da Suno), questa API accetta un `audio_url` pubblicamente accessibile, ovvero la tua registrazione vocale. Questo documento spiega come integrare l'API di clonaggio vocale.

## Primo passaggio: creare un personaggio vocale

Questa API ha tre parametri di input: `audio_url` (obbligatorio), un URL di file audio in formato MP3 o WAV pubblicamente accessibile, contenente una voce chiara di una singola persona; `name` e `description` (facoltativi), ovvero il nome e la descrizione del personaggio vocale.

> **Requisiti del file audio**
> - Il formato audio deve essere `WAV` o `MP3`
> - La durata dell'audio deve essere compresa tra `10~240 secondi`; si consiglia di utilizzare materiale vocale pulito e senza accompagnamento di una singola persona della durata di `30~60 secondi`
> - L'audio deve contenere **una voce parlata o cantata chiara e riconoscibile di una singola persona**
> - Assicurati di evitare **rumore di fondo, accompagnamento, eco, riverbero**; le canzoni complete con accompagnamento solitamente non superano la verifica dell'impronta vocale
> - Non includere **più parlanti** o **voci multiple**
> - Materiale con volume troppo basso, voce poco chiara o rumore eccessivo può causare **il fallimento del clonaggio** o **risultati generati di qualità inferiore**
> **Descrizione delle limitazioni d'uso**
> - I personaggi vocali creati caricando audio sono **risorse private**
> - Questo personaggio vocale **non supporta il riutilizzo tra account**
> - Si consiglia di utilizzarlo il prima possibile dopo la creazione riuscita; un mancato utilizzo prolungato potrebbe causarne **la scadenza o l'indisponibilità**
> - Il `name` restituito viene generato automaticamente dal sistema; fai riferimento al `persona_id` restituito

> **In caso di errore nella chiamata, riprova prima**
> Il clonaggio vocale è un'attività ad alta intensità di calcolo e, anche se il materiale è completamente conforme, esiste una certa probabilità di errori occasionali, con risposte comuni come
> `voices_sound_different` (verifica dell'impronta vocale non superata) e simili. **Questo tipo di errore non è correlato alla qualità dell'audio; solitamente è sufficiente riprovare con lo stesso materiale per ottenere successo**,
> si consiglia di implementare 1~2 tentativi automatici in caso di risultati falliti durante l'integrazione. Le richieste fallite non verranno addebitate.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Il suddetto `https://cdn.acedata.cloud/suno_demo.mp3` è un materiale di esempio utilizzabile direttamente (MP3, 41 secondi, voce senza accompagnamento di una singola persona).
> Per un esempio in formato `WAV`, puoi utilizzare
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 secondi, mono 44,1kHz).

Il risultato è il seguente:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Come si può vedere, il campo `persona_id` di `data` è l'ID del personaggio vocale creato. Il campo `is_public` è sempre `false`, perché i personaggi vocali creati caricando audio sono privati. Nota che il `name` restituito viene generato automaticamente dal sistema; utilizza successivamente `persona_id` per fare riferimento a questo personaggio vocale.

## Secondo passaggio: utilizzare il personaggio vocale per generare musica

Dopo aver ottenuto l'ID del personaggio vocale, possiamo utilizzare [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) per generare musica. Imposta `action` su `generate` e `persona_id` sull'ID del personaggio vocale restituito sopra; la canzone generata utilizzerà la voce clonata per il canto.

> **Nota:** il clonaggio vocale supporta solo modelli `chirp-v4-5` e superiori (come `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), e non supporta `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Il risultato è il seguente:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` può essere utilizzato per la generazione con `generate` e anche per cover con `cover` / `upload_cover`. Quando viene specificata una voce, non è necessario compilare contemporaneamente `vocal_gender`; la somiglianza vocale dipende comunque dal materiale di riferimento e dal risultato generato.

Le voci create tramite questa interfaccia sono risorse private. Prima di creare una cover di una canzone esistente, chiama `/suno/upload`, passando l'`audio_url` della canzone originale e il `persona_id` di questa voce; dopo il caricamento riuscito, utilizza il `data.audio_id` restituito e lo stesso `persona_id` per chiamare `/suno/audios`:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

La creazione della voce, il caricamento della canzone originale e la cover devono utilizzare lo stesso canale di servizio. Non riutilizzare direttamente ID di canzoni precedenti non associati a questa voce privata; per i dettagli, consulta [Suno carica audio di riferimento](https://platform.acedata.cloud/documents/suno-upload).
