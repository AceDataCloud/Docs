title: "Suno 声音克隆 API 对接说明"

---

SUNO ci consente di creare ruoli vocali personalizzati tramite qualsiasi file audio, realizzando il cloning della voce per la generazione musicale. A differenza dell'API Persona esistente (che utilizza `audio_id` generato da Suno), questa API accetta un `audio_url` accessibile pubblicamente, ovvero la tua registrazione vocale. Questo documento spiega come integrare l'API di cloning della voce.

Questa API ha tre parametri di input: `audio_url` (obbligatorio), che è un URL di un file audio in formato MP3 o WAV accessibile pubblicamente, contenente una voce umana chiara; `name` e `description` (opzionali), che sono il nome e la descrizione del ruolo vocale.

**Requisiti per il file audio:**

- Formato: MP3 o WAV
- Durata: almeno 10 secondi
- Contenuto: voce umana chiara, cercando di ridurre al minimo il rumore di fondo o la musica

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://example.com/my-vocal-recording.mp3",
  "name": "My Voice",
  "description": "A warm male voice"
}'
```

Il risultato è il seguente:

```json
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dde0be60-5280-4bd2-89a0-4020ddd3db52",
    "name": "My Voice",
    "is_public": false
  }
}
```

Come si può vedere, il campo `persona_id` di `data` è l'ID del ruolo vocale creato. Il campo `is_public` è sempre `false`, poiché i ruoli vocali creati tramite l'upload di audio sono privati.

Una volta ottenuto l'ID del ruolo vocale, possiamo utilizzare l'[API di Generazione Audio di Suno](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) per la generazione musicale. Impostiamo `action` su `vox` e `persona_id` sul valore restituito sopra, la canzone generata sarà cantata utilizzando la voce clonata.
