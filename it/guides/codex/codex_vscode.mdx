title: "Guida alla configurazione di Codex per VS Code"
description: "Codex API guide - Ace Data Cloud"
---

L'estensione Codex per VS Code condivide `~/.codex/config.toml` con Codex CLI.

## 1. Ottenere la chiave API

Apri l'[elenco delle applicazioni di Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedi alle applicazioni disponibili e copia la chiave API.

![Ottenere la chiave API di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installare l'estensione

Installa **Codex – OpenAI's coding agent** pubblicato da OpenAI nel marketplace delle estensioni di VS Code, oppure esegui:

```bash
code --install-extension openai.chatgpt
```

## 3. Impostare la chiave API

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="la tua chiave API"
```

Per renderla permanente, aggiungi questa riga a `~/.zshrc` o `~/.bashrc`. Windows PowerShell utilizza:

```powershell
setx ACEDATACLOUD_API_KEY "la tua chiave API"
```

## 4. Configurare AceDataCloud

Modifica `~/.codex/config.toml` (per Windows è `%USERPROFILE%\.codex\config.toml`), aggiungendo:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Per Windows, modifica le ultime due righe in:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Non è necessario specificare `model`; puoi selezionare il modello nel pannello Codex.

## 5. Riavviare e verificare

Esci completamente e riapri VS Code, quindi apri il pannello Codex. Esegui `/model`, conferma che il Provider sia `acedatacloud`, quindi invia un semplice messaggio; i registri delle chiamate possono essere visualizzati in [Cronologia utilizzo](https://platform.acedata.cloud/console/usages).

Se l'estensione non riesce a leggere la chiave, avvia VS Code da un terminale in cui hai impostato la variabile d'ambiente, oppure imposta una variabile d'ambiente a livello di sistema e riavvia VS Code. Remote SSH, WSL e Dev Container devono essere configurati separatamente nell'ambiente in cui l'estensione viene eseguita.
