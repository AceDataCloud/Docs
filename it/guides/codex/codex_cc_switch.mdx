---
title: "Guida alla configurazione di Codex CC Switch"
description: "Codex API guide - Ace Data Cloud"
---

CC Switch può gestire il provider e la chiave API di Codex tramite un'interfaccia grafica.

## 1. Ottenere la chiave API

Aprire l' [elenco delle applicazioni di Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedere alle applicazioni disponibili e copiare la chiave API.

![Ottenere la chiave API di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installare CC Switch

Scaricare e installare da [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), oppure eseguire su macOS:

```bash
brew install --cask cc-switch
```

## 3. Aggiungere il provider

1. Aprire CC Switch e passare a **Codex**.
2. Cliccare su **Add Provider**, selezionare **Custom**.
3. Compilare:

| Campo     | Contenuto                          |
| --------- | ---------------------------------- |
| Nome      | `acedatacloud`                    |
| Base URL  | `https://api.acedata.cloud/v1`   |
| Chiave API| La chiave API di Ace Data Cloud appena copiata |

Se CC Switch fornisce un editor di configurazione personalizzato, la configurazione dovrebbe rimanere come:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"
requires_openai_auth = true
```

CC Switch salverà la chiave API in `~/.codex/auth.json`:

```json
{
  "OPENAI_API_KEY": "{token}"
}
```

Non aggiungere `env_key` o `[model_providers.acedatacloud.auth]` nel provider sopra; la configurazione manuale è alternativa alla configurazione di CC Switch. Non è necessario fissare `model`, è possibile selezionarlo direttamente in Codex.

## 4. Abilitare e verificare

Abilitare il provider `acedatacloud`, uscire completamente e riavviare Codex o VS Code. Eseguire `/model`, confermare che il Provider sia `acedatacloud`, quindi selezionare un modello e inviare un semplice messaggio.

Se restituisce 401, confermare che il provider attivato sia `acedatacloud` e controllare se `OPENAI_API_KEY` in `~/.codex/auth.json` corrisponde alla chiave API di Ace Data Cloud appena copiata. I registri delle chiamate possono essere visualizzati in [Cronologia utilizzo](https://platform.acedata.cloud/console/usages).
