## 1. Ottenere la API Key

Apri [l'elenco delle applicazioni di Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedi alle applicazioni disponibili e copia la API Key.

![Ottenere la API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installare Codex

```bash
npm install -g @openai/codex
```

## 3. Impostare la API Key

macOS / Linux：

```bash
export ACEDATACLOUD_API_KEY="la tua API Key"
```

Per una validità a lungo termine, aggiungi questa riga a `~/.zshrc` o `~/.bashrc`. Windows PowerShell utilizza:

```powershell
setx ACEDATACLOUD_API_KEY "la tua API Key"
```

Dopo aver impostato, riapri il terminale.

## 4. Configurare AceDataCloud

Modifica `~/.codex/config.toml` (per Windows è `%USERPROFILE%\.codex\config.toml`), aggiungi:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Per Windows, modifica le ultime due righe in:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Non è necessario compilare `model`; dopo l'avvio, puoi selezionare il modello in Codex. Le altre configurazioni esistenti possono essere mantenute, non creare provider con lo stesso nome.

## 5. Avviare

```bash
cd /path/to/your/project
codex
```

Dopo essere entrato in Codex, esegui `/model`, conferma che il Provider sia `acedatacloud`, quindi seleziona il modello desiderato. I registri delle chiamate e il saldo possono essere visualizzati in [Storico utilizzo](https://platform.acedata.cloud/console/usages) e [Elenco applicazioni](https://platform.acedata.cloud/console/applications).

Se viene visualizzato un messaggio di chiave mancante o restituisce 401, verifica che la variabile d'ambiente sia stata impostata e chiudi completamente, quindi riapri il terminale e Codex.
