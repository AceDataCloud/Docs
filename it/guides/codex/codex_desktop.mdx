title: "Guida alla configurazione di Codex Desktop"
description: "Codex API guide - Ace Data Cloud"
---

Codex Desktop condivide `~/.codex/config.toml` con Codex CLI.

## 1. Ottenere la chiave API

Apri l'[elenco delle applicazioni di Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedi alle applicazioni disponibili e copia la chiave API.

![Ottenere la chiave API di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Impostare la chiave API

macOS：

```bash
launchctl setenv ACEDATACLOUD_API_KEY "la tua chiave API"
```

Windows PowerShell：

```powershell
setx ACEDATACLOUD_API_KEY "la tua chiave API"
```

## 3. Configurare AceDataCloud

Modifica `~/.codex/config.toml` (per Windows è `%USERPROFILE%\.codex\config.toml`), aggiungendo:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Per Windows, modifica le ultime due righe in:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Non è necessario compilare `model`; dopo aver aperto Codex, seleziona direttamente il modello.

## 4. Riavviare e verificare

Esci completamente e riapri Codex Desktop, crea un nuovo compito locale e invia un semplice messaggio. Il provider dovrebbe essere visualizzato come `acedatacloud`; le chiamate reali possono essere visualizzate nella [cronologia utilizzo](https://platform.acedata.cloud/console/usages).

Se la configurazione non ha effetto, assicurati di aver modificato il `~/.codex/config.toml` dell'utente corrente, che la variabile d'ambiente sia stata impostata e poi riavvia completamente l'app. I compiti cloud o le automazioni eseguite in ambienti diversi necessitano di una configurazione separata della chiave nell'ambiente corrispondente.
