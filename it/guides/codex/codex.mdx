Codex CLI è un agente di programmazione locale open source lanciato da OpenAI, che consente di leggere codice, modificare file, eseguire comandi e assistere nello sviluppo direttamente dal terminale. Attraverso il proxy Ace Data Cloud, puoi utilizzare Codex CLI a un costo inferiore, senza dover sottoscrivere un account ufficiale OpenAI separatamente.

Scegli la guida completa corrispondente in base allo scenario d'uso:

| Piattaforma | Descrizione | Link alla guida |
|-------------|-------------|-----------------|
| **VS Code** | Estensione ufficiale, chat nella barra laterale dell'editor, riferimento ai file, anteprima diff | [Guida alla configurazione VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| **Terminale (CLI)** | Esperienza principale, esegui `codex` in qualsiasi terminale per iniziare | [Guida alla configurazione terminale](https://platform.acedata.cloud/documents/codex-terminal-integration) |

> **Suggerimento**: Per la prima richiesta, visita la [console Ace Data Cloud](https://platform.acedata.cloud/console/applications) per ottenere un API Token, che include un credito gratuito. Codex CLI funziona tramite l’interfaccia compatibile OpenAI Responses di Ace Data Cloud (`/v1/responses`); per ulteriori informazioni su modelli e tariffe consulta la [pagina di servizio OpenAI](https://platform.acedata.cloud/documents/openai).
