Codex CLI, Desktop e l'estensione per VS Code condividono `~/.codex/config.toml`. Configura una volta il provider `acedatacloud` e potrai utilizzare Codex tramite Ace Data Cloud.

| Modalità d'uso     | Guida alla configurazione                                                                  |
| ------------------ | --------------------------------------------------------------------------------------- |
| Terminale / CLI    | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)        |
| Desktop            | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)     |
| VS Code            | [Codex per VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)  |
| Passaggio grafico  | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration) |

Le configurazioni comuni sono solo tre:

- Provider: `acedatacloud`
- Base URL: `https://api.acedata.cloud/v1`
- API Key: da ottenere dalla [lista delle applicazioni](https://platform.acedata.cloud/console/applications) e salvare in `ACEDATACLOUD_API_KEY`

Non è necessario fissare il modello nella configurazione di accesso; dopo aver avviato Codex, puoi selezionare direttamente il modello.

Torna al [Centro di configurazione del Piano di Codifica](https://platform.acedata.cloud/documents/coding-plan-integration).
