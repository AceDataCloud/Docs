title: "Producer Download WAV API Integration Instructions"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer ci consente di scaricare i file WAV relativi alle canzoni, questo documento spiega il metodo di integrazione dell'API correlata.

Questa API ha solo un parametro di input, che è `audio_id`, ed è l'ID unico della canzone.

Qui l'`audio_id` che inseriamo è `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, che è un ID canzone generato da Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/wav' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Il risultato è il seguente:

```
{
  "success": true,
  "task_id": "44963173-b6c5-463c-915f-96730d14ec63",
  "trace_id": "f75d6a27-54bc-49fd-a40e-6d4cd0427764",
  "data": [
    {
      "title": "Woke up with the sun in my eyes",
      "file_url": "https://platform2.cdn.acedata.cloud/fish/64adc04b-c196-4a0f-9070-222ba101ce6c.wav"
    }
  ]
}
```

Si può vedere che il campo `file_url` di `data` è il link per scaricare il WAV.
