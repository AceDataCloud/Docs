Producer ci consente di caricare audio di riferimento per la creazione secondaria, questo documento spiega il metodo di integrazione dell'API correlata.

Questa API ha solo un parametro di input, che è `audio_url`, ed è un indirizzo CDN accessibile pubblicamente, supporta l'estensione mp3.

Qui il nostro `audio_url` è `https://cdn.acedata.cloud/suno_demo.mp3`, che è un indirizzo CDN accessibile pubblicamente.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Il risultato è il seguente:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Soft female vocals, bright and cheerful]\n\n[Verse 1]\nIl sole splende sulla spiaggia\nLe onde ridono brillanti\nTu ed io sulla sabbia\nL'orologio si ferma\nIl gelato si sta sciogliendo\nMano nella mano per una passeggiata\nIl vento soffia leggero\nIl cuore batte incessantemente\n\n[Chorus]\nEstate estate\nIl tempo si ferma in questo giorno\nLe risate risuonano\nIl cielo blu accanto a noi",
    "audio_url": "https://storage.googleapis.com/corpusant-app-public/producer/raw/d906da31-87cb-42f5-98df-2fc4969923b1.mp3"
  }
}
```

Si può vedere che il campo `audio_id` di `data` è l'ID della canzone dopo il caricamento.

Con l'ID della canzone, possiamo utilizzare [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration) per generare canzoni personalizzate, ad esempio passando `action` come `upload_extend`, mentre `audio_id` è l'ID della canzone restituito, possiamo generare una nuova canzone basata sull'audio di riferimento.
