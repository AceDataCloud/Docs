title: "Producer Download Video API Integration Instructions"
description: "Producer Music Generation 集成指南 - Ace Data Cloud"
---

Producer ci consente di scaricare video correlati a canzoni, questo documento spiega il metodo di integrazione dell'API correlata.

Questa API ha solo un parametro di input, che è `audio_id`, ed è l'ID unico della canzone.

Qui l'`audio_id` che inseriamo è `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, che è un ID canzone generato da Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Il risultato è il seguente:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://storage.googleapis.com/corpusant-app-public/song-videos/a54609c6-13e2-4176-be0f-4d7eebc68e1f:5178f294b214798f7d38b810ac289be75306659be24af88900a633efce334012.mp4"
  }
}
```

Si può vedere che il campo `video_url` di `data` è il link per scaricare il video.
