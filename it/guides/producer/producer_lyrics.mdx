Producer ci consente di generare testi tramite parole chiave, questo documento spiega come integrare le API correlate.

Questa API ha solo un parametro di input, che è `prompt`, che è la parola chiave per generare il testo.

Qui il nostro `prompt` è `Una canzone sull'inverno`, è la parola chiave per generare il testo.

```bash
curl -X POST 'https://api.acedata.cloud/producer/lyrics' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Una canzone sull'inverno"
}'
```

Il risultato è il seguente:

{
    "success": true,
    "task_id": "d354b519-43c0-4888-a3da-83adbf845fd6",
    "data": {
        "title": "Misericordia negli Alberi",
        "lyrics": "[Verso 1]\nSono uscito oltre il deposito dei treni\nDove i pini crescono fitti di brina\nLa neve non si preoccupa di ciò che ho fatto\nCopre tutto allo stesso modo\n\n[Verso 2]\nC'è una cappella fatta di tronchi di betulla\nE l'altare è il terreno\nMi inginocchio lì come un traditore\nAspettando che il silenzio perdoni\n\n[ ritornello ]\nL'inverno è un pesante cappotto\nL'inverno è un pesante cappotto\n\n[Verso 3]\nSei andato via prima della prima tempesta\nSono rimasto a guardare il mondo diventare bianco\nOra ogni ramo è un osso\nE sto solo contando ciò che rimane\n\n[Verso 4]\nDicono che il freddo ti ucciderà\nMa penso che ti renda solo onesto\nQui fuori con la terra ghiacciata\nNon c'è più posto dove nascondere le mani\n\n[ ritornello ]\nL'inverno è un pesante cappotto\nL'inverno è un pesante cappotto\n\n[Verso 5]\nHo trovato la tua lettera nella mia tasca\nL'inchiostro si era sbiadito da tutto lo scioglimento\nMa potevo ancora leggere misericordia\nScritta nello spazio vuoto tra\n\n[Outro]\nGli alberi non chiedono assoluzione\nStanno solo lì, nudi e veri\nSto imparando a fare lo stesso\nLasciando che la neve seppellisca ciò che deve seppellire"
