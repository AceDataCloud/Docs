L'API Claude Messages Count Tokens può calcolare il numero di Token di input di un Message senza creare effettivamente un messaggio, inclusi i conteggi dei Token di strumenti, immagini e documenti e altri contenuti. Questo è molto utile quando è necessario stimare i costi o verificare se l'input supera il limite del contesto del modello.

Questo documento presenta principalmente il processo di utilizzo dell'API Claude Messages Count Tokens.

## Processo di richiesta

Per utilizzare l'API Claude Messages Count Tokens, accedi prima alla [console Ace Data Cloud](https://platform.acedata.cloud/console/applications) per ottenere il tuo API Token, da conservare come backup.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se non hai ancora effettuato l'accesso o non ti sei registrato, verrai automaticamente reindirizzato alla pagina di accesso per registrarti e accedere; al termine, tornerai automaticamente alla pagina corrente.

**Un solo API Token può chiamare tutti i servizi della piattaforma, senza doverne richiedere uno separatamente per ciascun servizio.** La prima richiesta include un credito gratuito, per consentire un'esperienza gratuita; quando il credito è insufficiente, puoi ricaricare il saldo universale nella [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentazione completa: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Utilizzo di base

Il percorso di richiesta dell'API Claude Messages Count Tokens è `/v1/messages/count_tokens`, coerente con l'API ufficiale Anthropic. Dobbiamo fornire almeno due parametri obbligatori:

- `model`: inserisci l'ID completo del modello nell'elenco dei modelli di questa interfaccia e utilizza lo stesso modello per le successive richieste Messages.
- `messages`: l'array dei messaggi di input, in cui ogni messaggio contiene `role` (ruolo) e `content` (contenuto).

Parametri opzionali comuni:

- `system`: prompt di sistema, incluso nel numero di Token.
- `tools`: definizioni degli strumenti, incluse nel numero di Token.
- `thinking`: configurazione del pensiero esteso.
- `tool_choice`: configurazione della selezione degli strumenti.
- `cache_control`: configurazione del controllo della cache a livello superiore o di blocco di contenuto.

`messages`, `system`, il replay delle chiamate degli strumenti, le immagini URL e i blocchi di contenuto document/documento PDF utilizzano la stessa struttura di richiesta stabile dell'API Messages.

### Esempio cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Esempio Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Esempio di risultato restituito:

```json
{
  "input_tokens": 11
}
```

### Utilizzo dell'SDK Anthropic

L'API Claude Messages Count Tokens accetta la struttura di richiesta stabile dell'SDK Anthropic e può essere chiamata tramite la libreria `anthropic`. L'interfaccia conteggia i Token di input in base al modello selezionato e può essere utilizzata per verificare la dimensione dell'input prima di inviare una richiesta Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Conteggio dei Token che includono strumenti

Se la tua richiesta include definizioni di strumenti, anche questi strumenti verranno inclusi nel numero di Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Conteggio dei Token che includono prompt di sistema

Anche i prompt di sistema verranno inclusi nel numero di Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Note

- Questa API calcola solo il numero di Token di input e non produce alcun output del modello.
- Il risultato del conteggio dei Token può essere utilizzato per stimare la dimensione dell'input e controllare la finestra di contesto; la fatturazione finale si basa su `usage` nella risposta Messages effettiva.
- Immagini, PDF, definizioni degli strumenti, prompt di sistema e configurazioni thinking verranno inclusi nel risultato secondo le regole di input del modello selezionato.
- Questa API è completamente gratuita e non consuma alcun credito.
