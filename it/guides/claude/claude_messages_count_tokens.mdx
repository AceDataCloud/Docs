Claude Messages Count Tokens API può calcolare il numero di Token di input di un messaggio senza effettivamente creare il messaggio, inclusi il conteggio dei Token per strumenti, immagini e documenti. Questo è molto utile quando è necessario stimare i costi o controllare se l'input supera i limiti di contesto del modello.

Questo documento descrive principalmente il processo di utilizzo di Claude Messages Count Tokens API.

## Processo di richiesta

Per utilizzare Claude Messages Count Tokens API, prima vai al [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) per ottenere il tuo API Token, da tenere come riserva.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Se non hai ancora effettuato il login o registrato, verrai automaticamente reindirizzato alla pagina di login che ti invita a registrarti e accedere; una volta completato, verrai automaticamente riportato alla pagina corrente.

**Un API Token è sufficiente per accedere a tutti i servizi della piattaforma, senza dover richiedere separatamente per ogni servizio.** La prima richiesta ti darà un credito gratuito, per un'esperienza gratuita; quando il credito è insufficiente, puoi ricaricare il saldo generale nella [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentazione completa: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Utilizzo di base

Il percorso di richiesta per Claude Messages Count Tokens API è `/v1/messages/count_tokens`, mantenendo la coerenza con l'API ufficiale di Anthropic. Dobbiamo fornire almeno due parametri obbligatori:

- `model`: scegli il modello Claude da utilizzare, come `claude-opus-4-8`, `claude-sonnet-4-6`, ecc.
- `messages`: array di messaggi di input, ogni messaggio contiene `role` (ruolo) e `content` (contenuto).

Parametri opzionali comunemente usati:

- `system`: messaggio di sistema, che verrà conteggiato nei Token.
- `tools`: definizione degli strumenti, che verrà conteggiata nei Token.
- `thinking`: configurazione di pensiero esteso.
- `tool_choice`: configurazione di scelta degli strumenti.
- `cache_control`: configurazione di controllo della cache a livello di blocco di contenuto o di livello superiore.

`messages`, `system`, riproduzione delle chiamate agli strumenti, immagini URL e blocchi di contenuto documenti/PDF utilizzano la stessa struttura di richiesta stabile dell'API Messages.

### Esempio cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-opus-4-8",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Esempio Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-opus-4-8",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Esempio di risultato restituito:

```json
{
  "input_tokens": 11
}
```

### Utilizzo dell'SDK di Anthropic

Claude Messages Count Tokens API accetta la struttura di richiesta stabile dell'SDK di Anthropic e può essere chiamata tramite la libreria `anthropic`. L'attuale valore restituito è calcolato da un estimatore locale di Ace Data Cloud e non è il risultato preciso del tokenizer ufficiale di Anthropic; il numero effettivo di token per modelli multimodali, strumenti e diversi modelli Claude potrebbe variare.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Conteggio dei Token con strumenti inclusi

Se la tua richiesta include definizioni di strumenti, questi strumenti verranno conteggiati nei Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Conteggio dei Token con messaggi di sistema inclusi

I messaggi di sistema verranno anch'essi conteggiati nei Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Note

- Questa API calcola solo il numero di Token di input e non genera alcun output dal modello.
- I risultati del conteggio dei Token possono essere utilizzati per una stima approssimativa della dimensione dell'input e non dovrebbero essere considerati come base per la fatturazione precisa, il controllo della finestra di contesto o il confronto con il tokenizer del modello.
- L'attuale estimatore non calcola con precisione i token visivi/documentali per immagini e PDF e non può riflettere le differenze del tokenizer ufficiale tra i diversi modelli Claude.
- Questa API è completamente gratuita e non consuma alcun credito.
