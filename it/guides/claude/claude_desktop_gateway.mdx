Questa guida configura il **Third-Party Inference Gateway** di Claude Desktop, non Claude Code, né il MCP Connector di Claude Desktop.

## 1. Ottenere l'API Key

Apri l'[elenco delle applicazioni di Ace Data Cloud](https://platform.acedata.cloud/console/applications), accedi a un'applicazione disponibile e copia l'API Key.

![Ottenere l'API Key di Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Aprire la configurazione dell'inferenza di terze parti

Nella pagina di accesso di Claude Desktop, apri in sequenza **Help → Troubleshooting → Enable Developer Mode**, quindi seleziona **Developer → Configure Third-Party Inference…**.

![Claude Desktop apre Third-Party Inference](https://cdn.acedata.cloud/713ffd7104a3.png)

> L'immagine proviene dal repository Bifrost Apache-2.0 ed è utilizzata solo per individuare il menu di Claude Desktop; l'interfaccia delle diverse versioni potrebbe presentare lievi differenze.

## 3. Configurare il Gateway

Seleziona **Gateway**, quindi compila:

| Campo                  | Valore                      |
| ------------------- | --------------------------- |
| Gateway base URL    | `https://api.acedata.cloud` |
| Gateway API key     | L'API Key appena copiata     |
| Gateway auth scheme | `bearer`                    |
| Credential kind     | `Static API key`            |

![Interfaccia di configurazione del Gateway di Claude Desktop](https://cdn.acedata.cloud/68d41fe682cb.png)

Fai clic su **Apply Changes**, quindi su **Save & Restart**.

## 4. Verifica

Dopo il riavvio, seleziona un modello disponibile, crea una nuova conversazione e invia `Reply only OK`, quindi esegui una semplice attività con strumenti. I record delle chiamate possono essere visualizzati nella [cronologia di utilizzo](https://platform.acedata.cloud/console/usages).

Ace Data Cloud Gateway supporta `/v1/models` utilizzato da Claude Desktop, `/v1/messages` in streaming con autenticazione Bearer, chiamate agli strumenti e continuazione di `tool_result`. I campi della cache dei prompt vengono mantenuti; quando i valori di scrittura e lettura della cache sono entrambi 0, non significa che si sia verificato un hit della cache.

Un errore 401 di solito indica che la Key non è corretta; se il modello non viene trovato, ricontrolla la configurazione e riavvia completamente Claude Desktop. Quando segnali un problema, fornisci il trace ID nei record delle chiamate, non fornire l'API Key.
