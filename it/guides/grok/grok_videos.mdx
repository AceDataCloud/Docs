Questo documento presenta le istruzioni per integrare l'API Grok Videos Generation, che consente di generare video Grok Imagine (xAI) inserendo prompt testuali, immagini e, opzionalmente, immagini di riferimento.

## Processo di richiesta

Per utilizzare l'API, è necessario prima richiedere il servizio sulla pagina corrispondente di [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos). Dopo aver aperto la pagina, cliccare sul pulsante «Acquire», come mostrato nell'immagine:

![](https://cdn.acedata.cloud/q6ytrc.png)

Se non si è ancora loggati o registrati, si verrà reindirizzati automaticamente alla pagina di login per registrarsi o effettuare l'accesso. Dopo aver effettuato login o registrazione, si ritornerà automaticamente alla pagina corrente.

Durante la prima richiesta, verrà assegnato un credito gratuito per l'uso dell'API senza costi.

## Descrizione del modello

L'API supporta due modelli:

- `grok-imagine-video` (predefinito): supporta video generati da testo (passando solo `prompt`) e da immagine (`image_url`), con un prezzo più basso.
- `grok-imagine-video-1.5-preview`: supporta esclusivamente video da immagine, **obbligatorio** passare `image_url`.

## Uso di base

Per iniziare, si forniscono i parametri di base: `prompt`, `model`, ecc., per generare il video desiderato.

Si può impostare la richiesta con le intestazioni (Request Headers), tra cui:

- `accept`: formato di risposta desiderato, qui impostato a `application/json` (JSON).
- `authorization`: chiave API, da ottenere in fase di richiesta.

Inoltre, si configura il corpo della richiesta (Request Body), che include:

- `prompt`: testo descrittivo del contenuto del video da generare. Obbligatorio se si usa `grok-imagine-video`; opzionale se si fornisce `image_url`.
- `model`: modello di generazione, opzionale tra `grok-imagine-video` (predefinito) e `grok-imagine-video-1.5-preview`.
- `image_url`: URL dell'immagine di input per il video da immagine. Obbligatorio se `model` è `grok-imagine-video-1.5-preview`.
- `reference_image_urls`: array opzionale di URL di immagini di riferimento, usate per guidare stile o contenuto.
- `aspect_ratio`: rapporto larghezza/altezza del video, opzionale, tra `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`.
- `resolution`: risoluzione di output, opzionale, tra `480p` (predefinito) e `720p`. Risoluzioni più alte consumano più crediti.
- `duration`: durata del video in secondi, tra 1 e 15, default 8. Si paga in base ai secondi di output.
- `callback_url`: URL di callback asincrono. Se impostato, l'API ritorna subito `task_id`, e al completamento POSTa i risultati a quell'indirizzo.

Cliccando su «Try» si può testare la richiesta, ottenendo un risultato simile al seguente:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/grok/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Le principali voci di risposta sono:

- `success`: indica se la richiesta di generazione è andata a buon fine.
- `task_id`: ID del task di generazione.
- `trace_id`: ID di tracciamento della richiesta, utile per debugging.
- `data`: lista dei risultati video generati.
  - `id`: identificativo univoco del video.
  - `video_url`: URL del video generato.
  - `state`: stato del task (`pending`, `succeeded`, `failed`).

Per ottenere il video generato, basta seguire il link in `video_url`.

Esempio di CURL:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "resolution": "480p",
  "duration": 8
}'
```

Esempio di Python:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Video da immagine

Per generare video partendo da un'immagine, bisogna fornire `image_url`. Quando si usa `grok-imagine-video-1.5-preview`, questo campo è **obbligatorio**:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5-preview",
  "image_url": "https://cdn.acedata.cloud/grok/example-input.png",
  "resolution": "720p",
  "duration": 8
}
```

## Guida con immagini di riferimento

Per guidare stile o contenuto con immagini di riferimento, inserire gli URL in `reference_image_urls`:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/grok/example-reference.png"
  ]
}
```

## Callback asincrono

La generazione video richiede tempo. Se non si vuole mantenere la connessione aperta, si può impostare `callback_url`. In tal caso, l'API ritorna subito `task_id`, e al completamento invia i risultati a quell'indirizzo:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "duration": 8,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

Risultato immediato:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Verifica dello stato del task

Se si usa `callback_url` o si desidera controllare lo stato, si può consultare lo stato più recente tramite [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) usando `task_id`.

## Costi

Il servizio si basa sul numero di secondi di output del video. Il prezzo dipende da `model` e `resolution`. La formula è:

**Prezzo totale = prezzo unitario × `duration`** (default 8 secondi). Risoluzioni più alte e modelli più avanzati sono più costosi, secondo le tariffe ufficiali.

## Gestione errori

In caso di problemi, l'API restituisce codici di errore e messaggi, tra cui:

- `400`: parametri errati (ad esempio, `prompt` mancante per generazione testo, `image_url` mancante per `grok-imagine-video-1.5-preview`, `duration` fuori intervallo 1–15).
- `401`: errore di autenticazione, token non valido.
- `403`: saldo insufficiente o contenuto vietato da filtri.
- `429`: troppo frequente, limite di rate superato.
- `500`: errore interno server o fallimento generazione upstream.
