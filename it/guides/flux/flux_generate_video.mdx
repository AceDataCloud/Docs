title: "Guida all'integrazione video FLUX"
description: "Flux API guide - Ace Data Cloud"
---

Invia un'attività tramite `POST /flux/videos`, usa `action` per selezionare generazione, modifica o upscaling. Omettere `action` equivale a `generate`. Usa l'attuale `POST /flux/tasks` per interrogare le attività della piattaforma. Sono supportati `async=true` e `callback_url`; il risultato completato include il link video della piattaforma e la durata, le dimensioni e il frame rate misurati dal server.

## Generazione: action=generate

Supporta `mode=t2v/i2v/v2v/draft_enhance`. La generazione normale supporta interi da 5–20 secondi o `auto`; la continuazione video supporta 5–15 secondi. i2v può fornire 1–10 fotogrammi chiave, supportando coppie ordinate `[secondi, immagine]`. Le risoluzioni di output sono hd/fhd/qhd/uhd ed è supportato l'audio sincronizzato. La bozza produce solo hd e restituisce il `draft_task_id` della piattaforma; il riutilizzo della bozza richiede la stessa appartenenza ed è soggetto al periodo di validità della cache di generazione. La riproduzione della bozza non può sovrascrivere il prompt e i materiali originali.

```json
{"action":"generate","model":"flux-3","mode":"t2v","prompt":"海边日落","duration":5,"resolution":"hd","async":true}
```

## Modifica: action=edit

Fornisci `video` e `prompt`. La modifica viene fatturata in base ai secondi effettivi dell'output e non accetta campi di generazione come `mode`, `duration` e altri.

```json
{
  "action": "edit",
  "video": "https://example.com/video.mp4",
  "prompt": "将场景改为蓝色调",
  "async": true
}
```

## Upscaling: action=upscale

Fornisci `input_video`, con `upscale_factor` opzionale (1.5–3) e `creativity` (0 per preciso, 1 per creativo). La fatturazione avviene in base agli MP·secondi effettivi dell'output: `durata × larghezza × altezza / 1048576 × frame rate / 24`, 1 MP = 1024×1024. Non accetta parametri di generazione.

```json
{
  "action": "upscale",
  "input_video": "https://example.com/video.mp4",
  "upscale_factor": 2,
  "creativity": 0,
  "async": true
}
```

Ogni operazione adotta gli attuali coefficienti di prezzo di riferimento FLUX e viene fatturata in base all'output effettivo. Le attività non riuscite non comportano costi di generazione; il costo finale delle attività con fatturazione dinamica dipende dal risultato completato. Le diverse operazioni accettano solo i propri parametri; un'action sconosciuta restituisce un errore di parametri.
