## Introduzione

Fish TTS è un servizio audio AI fornito da Ace Data Cloud, un servizio di sintesi vocale Fish. Attraverso l'API unificata di Ace Data Cloud, puoi integrare rapidamente Fish TTS con Python per realizzare funzionalità di sintesi da testo a voce, diverse tonalità vocali, voci personalizzate e altro.

## Prerequisiti

- Avere un account [Ace Data Cloud](https://platform.acedata.cloud) e ottenere un API Token
- Ambiente Python 3.7 o superiore
- Installare la libreria requests: `pip install requests`

## Uso Base

L'endpoint principale per chiamare l'API Fish TTS è:

```
POST https://api.acedata.cloud/fish/audios
```

In questo esempio si utilizza il modello `fish-tts`.
Modelli disponibili: `fish-tts`.

Esempio completo di codice Python:

```python
import requests

url = "https://api.acedata.cloud/fish/audios"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "speech",
    "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务",
    "voice_id": "d7900c21663f485ab63ebdb7e5905036",
    "model": "fish-tts"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Sostituisci `YOUR_API_TOKEN` con il Token reale ottenuto dalla piattaforma Ace Data Cloud.

## Gestione della Risposta

Dopo una chiamata riuscita, l'API restituisce dati in formato JSON. Si consiglia di verificare il codice di stato HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Chiamata riuscita:", result)
else:
    print(f"Chiamata fallita, codice stato: {response.status_code}")
    print(response.text)
```

## Uso Avanzato

Per le API che supportano attività asincrone, puoi ottenere i risultati tramite un URL di callback:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Il risultato sarà inviato al tuo server tramite l'URL di callback
```

## Gestione degli Errori

Codici di errore comuni:

| Codice Stato | Descrizione                         |
|--------------|-----------------------------------|
| 401          | Autenticazione fallita, controlla il API Token |
| 403          | Saldo insufficiente o accesso negato |
| 429          | Limite di frequenza richieste superato |
| 500          | Errore interno del server         |
