## Introduzione

Face Change è un servizio AI per immagini fornito da Ace Data Cloud, specializzato nell'elaborazione dei volti tramite intelligenza artificiale. Attraverso l'API unificata di Ace Data Cloud, puoi utilizzare cURL per chiamare rapidamente Face Change e realizzare funzionalità come sostituzione del volto, miglioramento del volto, cambiamento dell'età, cambiamento del genere, trasformazione in stile anime, analisi del volto, e altro.

## Prerequisiti

- Possedere un account su [Ace Data Cloud](https://platform.acedata.cloud) e ottenere un API Token
- Avere un ambiente terminale con cURL installato

## Uso Base

L'endpoint principale per chiamare l'API Face Change è:

```
POST https://api.acedata.cloud/face/swap
```

Esempio completo di comando cURL:

```bash
curl -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}'
```

Sostituisci `YOUR_API_TOKEN` con il Token reale ottenuto dalla piattaforma Ace Data Cloud.

## Esempio di Risposta

Dopo una chiamata riuscita, viene restituito un dato in formato JSON, ad esempio:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Utilizzo di jq per Gestire la Risposta

Si consiglia di usare lo strumento jq per formattare l'output:

```bash
curl -s -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}' | jq .
```

## Gestione degli Errori

Codici di errore comuni:

| Codice Stato | Descrizione                        |
|--------------|----------------------------------|
| 401          | Autenticazione fallita, verifica il API Token |
| 403          | Saldo insufficiente o accesso negato |
| 429          | Limite di frequenza richieste superato |
| 500          | Errore interno del server         |
