## Introduzione

Grok è un servizio di chat AI fornito da Ace Data Cloud, basato sulla serie di modelli di linguaggio di grandi dimensioni xAI Grok. Attraverso l'API unificata di Ace Data Cloud, puoi integrare rapidamente Grok con Python per realizzare conversazioni multi-turno, prompt di sistema, output in streaming, modalità di output JSON, comprensione visiva e altre funzionalità.

## Prerequisiti

- Avere un account su [Ace Data Cloud](https://platform.acedata.cloud) e ottenere un API Token
- Ambiente Python 3.7 o superiore
- Installare la libreria requests: `pip install requests`

## Uso base

L'endpoint principale per chiamare l'API Grok è:

```
POST https://api.acedata.cloud/grok/chat/completions
```

In questo esempio si utilizza il modello `grok-3`.  
I modelli disponibili includono: `grok-4`, `grok-4-1-fast`, `grok-3`, `grok-3-mini`, `grok-2-vision`.

Esempio completo di codice Python:

```python
import requests

url = "https://api.acedata.cloud/grok/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "grok-3",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Sostituisci `YOUR_API_TOKEN` con il Token reale ottenuto dalla piattaforma Ace Data Cloud.

## Gestione della risposta

Dopo una chiamata riuscita, l'API restituisce dati in formato JSON. Si consiglia di verificare il codice di stato HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Chiamata riuscita:", result)
else:
    print(f"Chiamata fallita, codice stato: {response.status_code}")
    print(response.text)
```

## Uso avanzato

Per le API di tipo chat, è supportato l’output in streaming per ricevere risposte in tempo reale:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Gestione degli errori

Codici di errore comuni:

| Codice | Descrizione                         |
|--------|-----------------------------------|
| 401    | Autenticazione fallita, controlla il API Token |
| 403    | Saldo insufficiente o accesso negato |
| 429    | Limite di frequenza richieste superato |
| 500    | Errore interno del server          |
