## Introduzione

Luma è un servizio video AI fornito da Ace Data Cloud, con generazione video tramite Luma Dream Machine. Attraverso l'API unificata di Ace Data Cloud, puoi utilizzare cURL per chiamare rapidamente Luma e realizzare funzionalità come video generati da testo, video generati da immagini, estensione video, controllo dei frame iniziali e finali, video in loop e altro.

## Prerequisiti

- Avere un account [Ace Data Cloud](https://platform.acedata.cloud) e ottenere un API Token
- Ambiente terminale con cURL installato

## Uso base

Il principale endpoint API di Luma è:

```
POST https://api.acedata.cloud/luma/videos
```

Esempio completo di comando cURL:

```bash
curl -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}'
```

Sostituisci `YOUR_API_TOKEN` con il Token reale ottenuto dalla piattaforma Ace Data Cloud.

## Esempio di risposta

Dopo una chiamata riuscita viene restituito un dato in formato JSON, ad esempio:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Utilizzo di jq per elaborare la risposta

Si consiglia di usare lo strumento jq per formattare l’output:

```bash
curl -s -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}' | jq .
```

## Gestione degli errori

Codici di errore comuni:

| Codice stato | Descrizione                         |
|--------------|-----------------------------------|
| 401          | Autenticazione fallita, controlla API Token |
| 403          | Saldo insufficiente o accesso negato |
| 429          | Limite di frequenza richieste superato |
| 500          | Errore interno del server          |
