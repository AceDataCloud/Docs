## Introduzione

Midjourney è un servizio di immagini AI fornito da Ace Data Cloud, che genera immagini AI con Midjourney. Attraverso l'API unificata di Ace Data Cloud, puoi utilizzare cURL per chiamare rapidamente Midjourney e realizzare funzionalità come generazione di immagini da testo, modifica immagini, descrizione immagini, generazione video da immagini, controllo Seed, callback asincroni e altro.

## Prerequisiti

- Avere un account su [Ace Data Cloud](https://platform.acedata.cloud) e ottenere un API Token
- Ambiente terminale con cURL installato

## Uso base

L'endpoint principale per chiamare l'API Midjourney è:

```
POST https://api.acedata.cloud/midjourney/imagine
```

Esempio completo di comando cURL:

```bash
curl -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}'
```

Sostituisci `YOUR_API_TOKEN` con il token reale ottenuto dalla piattaforma Ace Data Cloud.

## Esempio di risposta

Dopo una chiamata riuscita viene restituito un dato in formato JSON, ad esempio:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Utilizzo di jq per elaborare la risposta

Si consiglia di utilizzare lo strumento jq per formattare l'output:

```bash
curl -s -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}' | jq .
```

## Gestione degli errori

Codici di errore comuni:

| Codice stato | Descrizione                      |
|--------------|---------------------------------|
| 401          | Autenticazione fallita, controlla il API Token |
| 403          | Saldo insufficiente o accesso negato |
| 429          | Limite di frequenza richieste superato |
| 500          | Errore interno del server       |
