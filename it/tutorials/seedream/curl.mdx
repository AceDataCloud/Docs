## Introduzione

Seedream è un servizio di immagini AI fornito da Ace Data Cloud, basato sul modello di generazione di immagini Seedream di ByteDance. Attraverso l'API unificata di Ace Data Cloud, puoi utilizzare cURL per chiamare rapidamente Seedream e realizzare funzionalità come generazione di immagini da testo, modifica di immagini, diverse risoluzioni, controllo watermark e altro.

## Prerequisiti

- Avere un account su [Ace Data Cloud](https://platform.acedata.cloud) e ottenere un API Token
- Ambiente terminale con cURL installato

## Uso Base

L'endpoint principale per chiamare l'API Seedream è:

```
POST https://api.acedata.cloud/seedream/images
```

Questo esempio utilizza il modello `doubao-seedream-4-0-250828`.
I modelli disponibili includono: `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`, `doubao-seedream-3-0-t2i-250415`, `doubao-seededit-3-0-i2i-250628`.

Esempio completo di comando cURL:

```bash
curl -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}'
```

Sostituisci `YOUR_API_TOKEN` con il Token reale ottenuto dalla piattaforma Ace Data Cloud.

## Esempio di Risposta

Dopo una chiamata riuscita, viene restituito un dato in formato JSON, ad esempio:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Utilizzo di jq per Gestire la Risposta

Si consiglia di usare lo strumento jq per formattare l'output:

```bash
curl -s -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}' | jq .
```

## Gestione degli Errori

Codici di errore comuni:

| Codice Stato | Descrizione                         |
|--------------|-----------------------------------|
| 401          | Autenticazione fallita, controlla il API Token |
| 403          | Saldo insufficiente o accesso negato |
| 429          | Limite di frequenza richieste superato |
| 500          | Errore interno del server          |
