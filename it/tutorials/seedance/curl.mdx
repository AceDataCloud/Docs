## Introduzione

Seedance è un servizio video AI fornito da Ace Data Cloud, basato sul modello di generazione video Seedance di ByteDance. Attraverso l'API unificata di Ace Data Cloud, puoi utilizzare cURL per chiamare rapidamente Seedance e realizzare funzionalità come generazione video da testo, generazione video da immagini, generazione audio e supporto per varie risoluzioni.

## Prerequisiti

- Possedere un account [Ace Data Cloud](https://platform.acedata.cloud) e ottenere un API Token
- Avere un ambiente terminale con cURL installato

## Uso Base

L'endpoint principale per chiamare l'API Seedance è:

```
POST https://api.acedata.cloud/seedance/videos
```

In questo esempio si utilizza il modello `doubao-seedance-1-0-pro-250528`.
I modelli disponibili includono: `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`.

Esempio completo di comando cURL:

```bash
curl -X POST https://api.acedata.cloud/seedance/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "doubao-seedance-1-0-pro-250528", "content": [{"type": "text", "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"}]}'
```

Sostituisci `YOUR_API_TOKEN` con il token reale ottenuto dalla piattaforma Ace Data Cloud.

## Esempio di Risposta

Alla chiamata avvenuta con successo viene restituito un dato in formato JSON, ad esempio:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Uso di jq per Gestire la Risposta

Si consiglia di utilizzare lo strumento jq per formattare l'output:

```bash
curl -s -X POST https://api.acedata.cloud/seedance/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "doubao-seedance-1-0-pro-250528", "content": [{"type": "text", "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"}]}' | jq .
```

## Gestione degli Errori

Codici di errore comuni:

| Codice Stato | Descrizione                        |
|--------------|----------------------------------|
| 401          | Autenticazione fallita, controlla l'API Token |
| 403          | Saldo insufficiente o accesso negato |
| 429          | Limite di frequenza richieste superato |
| 500          | Errore interno del server         |
