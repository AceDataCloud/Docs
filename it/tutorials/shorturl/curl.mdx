## Introduzione

Short URL è un servizio offerto da Ace Data Cloud per la generazione di link brevi. Attraverso l'API unificata di Ace Data Cloud, puoi utilizzare cURL per chiamare rapidamente Short URL e realizzare funzionalità come l'accorciamento degli URL e l'uso di domini personalizzati.

## Prerequisiti

- Possedere un account [Ace Data Cloud](https://platform.acedata.cloud) e ottenere un API Token
- Avere un ambiente terminale con cURL installato

## Uso Base

L'endpoint principale per chiamare l'API Short URL è:

```
POST https://api.acedata.cloud/shorturl
```

Esempio completo di comando cURL:

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}'
```

Sostituisci `YOUR_API_TOKEN` con il token reale ottenuto dalla piattaforma Ace Data Cloud.

## Esempio di Risposta

Una chiamata riuscita restituisce dati in formato JSON, ad esempio:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Utilizzo di jq per Gestire la Risposta

Si consiglia di utilizzare lo strumento jq per formattare l'output:

```bash
curl -s -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}' | jq .
```

## Gestione degli Errori

Codici di errore comuni:

| Codice Stato | Descrizione                     |
|--------------|--------------------------------|
| 401          | Autenticazione fallita, verifica il API Token |
| 403          | Saldo insufficiente o accesso negato |
| 429          | Limite di frequenza richieste superato |
| 500          | Errore interno del server      |
