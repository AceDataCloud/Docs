## Introduzione

Suno è un servizio audio AI fornito da Ace Data Cloud, generazione musicale AI Suno. Tramite l'API unificata di Ace Data Cloud, puoi utilizzare cURL per chiamare rapidamente Suno e realizzare funzionalità come generazione musicale da testo, testi personalizzati, continuazione di canzoni, cover, separazione vocale, generazione di testi, ecc.

## Prerequisiti

- Possedere un account [Ace Data Cloud](https://platform.acedata.cloud) e ottenere un API Token
- Ambiente terminale con cURL installato

## Uso Base

Il principale endpoint per chiamare l'API Suno è:

```
POST https://api.acedata.cloud/suno/audios
```

In questo esempio si utilizza il modello `chirp-v5`.  
I modelli disponibili includono: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`.

Esempio completo di comando cURL:

```bash
curl -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}'
```

Sostituisci `YOUR_API_TOKEN` con il token reale ottenuto dalla piattaforma Ace Data Cloud.

## Esempio di Risposta

In caso di successo, viene restituito un dato in formato JSON, ad esempio:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Utilizzo di jq per Gestire la Risposta

Si consiglia di usare lo strumento jq per formattare l'output:

```bash
curl -s -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}' | jq .
```

## Gestione degli Errori

Codici di errore comuni:

| Codice Stato | Descrizione                          |
|--------------|------------------------------------|
| 401          | Autenticazione fallita, controlla il API Token |
| 403          | Saldo insufficiente o accesso negato |
| 429          | Limite di frequenza richieste superato |
| 500          | Errore interno del server          |
