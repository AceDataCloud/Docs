## Introduzione

ADSL HTTP Proxy è un servizio di proxy di rete fornito da Ace Data Cloud, che consente l’estrazione di IP dinamici ADSL. Attraverso l’API unificata di Ace Data Cloud, puoi integrare rapidamente ADSL HTTP Proxy in Python, realizzando funzionalità come proxy HTTP/SOCKS, multi-operatore, multi-provincia, durata personalizzata, whitelist IP e altro.

## Prerequisiti

- Possedere un account [Ace Data Cloud](https://platform.acedata.cloud) e ottenere un API Token
- Ambiente Python 3.7 o superiore
- Installare la libreria requests: `pip install requests`

## Uso Base

L’endpoint principale per chiamare l’API ADSL HTTP Proxy è:

```
POST https://api.acedata.cloud/adsl/extract
```

Esempio completo di codice Python:

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "number": 5,
    "type": "http",
    "duration": 300,
    "province": "广东",
    "isp": "电信"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Sostituisci `YOUR_API_TOKEN` con il Token reale ottenuto dalla piattaforma Ace Data Cloud.

## Gestione della Risposta

Dopo una chiamata riuscita, l’API restituisce dati in formato JSON. Si consiglia di verificare il codice di stato HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Chiamata riuscita:", result)
else:
    print(f"Chiamata fallita, codice stato: {response.status_code}")
    print(response.text)
```

## Uso Avanzato

Per le API che supportano attività asincrone, è possibile ottenere i risultati tramite un URL di callback:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Il risultato verrà inviato al tuo server tramite l’URL di callback
```

## Gestione degli Errori

Codici di errore comuni:

| Codice Stato | Descrizione                        |
|--------------|----------------------------------|
| 401          | Autenticazione fallita, verifica API Token |
| 403          | Saldo insufficiente o accesso negato |
| 429          | Limite di frequenza richieste superato |
| 500          | Errore interno del server         |
