## Introduzione

AI Chat è un servizio di chat AI fornito da Ace Data Cloud, un servizio di dialogo AI multi-modello. Attraverso l'API unificata di Ace Data Cloud, puoi utilizzare cURL per chiamare rapidamente AI Chat, supportando funzionalità come modelli multipli, conversazioni con stato e ruoli preimpostati.

## Prerequisiti

- Possedere un account [Ace Data Cloud](https://platform.acedata.cloud) e ottenere un API Token
- Avere un ambiente terminale con cURL installato

## Uso Base

L'endpoint principale per chiamare l'API AI Chat è:

```
POST https://api.acedata.cloud/aichat/conversations
```

Questo esempio utilizza il modello `gpt-4o`.
I modelli disponibili includono: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Esempio completo di comando cURL:

```bash
curl -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}'
```

Sostituisci `YOUR_API_TOKEN` con il token reale ottenuto dalla piattaforma Ace Data Cloud.

## Esempio di Risposta

In caso di chiamata riuscita, viene restituito un dato in formato JSON, ad esempio:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Utilizzo di jq per elaborare la risposta

Si consiglia di utilizzare lo strumento jq per formattare l'output:

```bash
curl -s -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}' | jq .
```

## Gestione degli Errori

Codici di errore comuni:

| Codice Stato | Descrizione                          |
|--------------|-----------------------------------|
| 401          | Autenticazione fallita, controlla il API Token |
| 403          | Saldo insufficiente o accesso negato |
| 429          | Limite di frequenza richieste superato |
| 500          | Errore interno del server         |
