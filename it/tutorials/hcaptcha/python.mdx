## Introduzione

hCaptcha è un servizio di captcha fornito da Ace Data Cloud, soluzione hCaptcha. Attraverso l'API unificata di Ace Data Cloud, puoi integrare rapidamente hCaptcha con Python, realizzando funzionalità come l'ottenimento del Token hCaptcha e il riconoscimento delle immagini hCaptcha.

## Prerequisiti

- Possedere un account [Ace Data Cloud](https://platform.acedata.cloud) e ottenere un API Token
- Ambiente Python 3.7 o superiore
- Installare la libreria requests: `pip install requests`

## Uso Base

L'endpoint principale per chiamare l'API hCaptcha è:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```



Esempio completo di codice Python:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/hcaptcha"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2",
    "website_url": "https://accounts.hcaptcha.com/demo"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Sostituisci `YOUR_API_TOKEN` con il Token reale ottenuto dalla piattaforma Ace Data Cloud.

## Gestione della Risposta

Dopo una chiamata riuscita, l'API restituisce dati in formato JSON. Si consiglia di verificare il codice di stato HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Chiamata riuscita:", result)
else:
    print(f"Chiamata fallita, codice stato: {response.status_code}")
    print(response.text)
```

## Uso Avanzato

Per le API che supportano attività asincrone, è possibile ottenere i risultati tramite un URL di callback:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Il risultato sarà inviato al tuo server tramite l'URL di callback
```

## Gestione degli Errori

Codici di errore comuni:

| Codice Stato | Descrizione |
|--------------|-------------|
| 401 | Autenticazione fallita, verifica il tuo API Token |
| 403 | Saldo insufficiente o accesso negato |
| 429 | Frequenza delle richieste superata |
| 500 | Errore interno del server |
