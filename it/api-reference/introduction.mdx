## URL base

L'indirizzo base per tutti gli endpoint API:

```
https://api.acedata.cloud
```

## Autenticazione

Tutti gli endpoint richiedono l'autenticazione con Bearer Token:

```
Authorization: Bearer YOUR_API_TOKEN
```

## Test online

Ogni endpoint in questo riferimento include una sandbox interattiva. Inserisci il token API per testare direttamente le richieste nel browser.

<Note title="Tip">
  Ottieni il token API su [platform.acedata.cloud](https://platform.acedata.cloud).
</Note>
