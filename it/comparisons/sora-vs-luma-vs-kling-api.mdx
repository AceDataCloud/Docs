## Esempi di codice

Gli esempi seguenti mostrano come chiamare rispettivamente Sora, Luma e Kling tramite l’API di Ace Data Cloud. Tutte le richieste utilizzano la stessa Base URL (`https://api.acedata.cloud`) e metodo di autenticazione.

### Chiamata a Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
},
)
print(response.json())
```
