## Analisi dettagliata

Claude e OpenAI sono entrambi accessibili tramite la chiamata API unificata di Ace Data Cloud, supportando interfacce REST standard e autenticazione Bearer Token.

**Claude** ha come endpoint principale `POST https://api.acedata.cloud/v1/chat/completions`, supportando conversazioni multi-turno, prompt di sistema, output in streaming, modalità output JSON e altre funzionalità. Offre inoltre endpoint come `/v1/messages`, `/v1/messages/count_tokens`.

## Esempi di codice

Gli esempi seguenti mostrano come chiamare Claude e OpenAI tramite l’API di Ace Data Cloud. Tutte le richieste utilizzano la stessa Base URL (`https://api.acedata.cloud`) e metodo di autenticazione.

### Chiamata a Claude

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/v1/chat/completions",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "model": "claude-sonnet-4-6",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
},
)
print(response.json())
```

response = requests.post(
