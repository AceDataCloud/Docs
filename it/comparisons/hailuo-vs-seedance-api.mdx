## Panoramica

Entrambi possono essere chiamati tramite la piattaforma API unificata di Ace Data Cloud, utilizzando lo stesso metodo di autenticazione e modalità di chiamata, senza la necessità di integrare separatamente le API dei diversi fornitori.

## Analisi dettagliata

### Funzionalità

Hailuo e Seedance sono entrambi accessibili tramite la chiamata API unificata di Ace Data Cloud, supportando interfacce REST standard e autenticazione Bearer Token.

**Hailuo** ha come endpoint principale `POST https://api.acedata.cloud/hailuo/videos`, supportando generazione video da testo, da immagine, modalità regista e altre funzionalità. Offre inoltre endpoint come `/hailuo/tasks`.

**Seedance** ha come endpoint principale `POST https://api.acedata.cloud/seedance/videos`, supportando generazione video da testo, da immagine, generazione audio e varie risoluzioni. Offre inoltre endpoint come `/seedance/tasks`.

## Esempi di codice

Gli esempi seguenti mostrano come chiamare rispettivamente Hailuo e Seedance tramite l’API di Ace Data Cloud. Tutte le richieste utilizzano lo stesso Base URL (`https://api.acedata.cloud`) e metodo di autenticazione.

### Chiamata a Hailuo

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/hailuo/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "action": "generate",
    "model": "minimax-t2v",
    "prompt": "A golden sunset over the ocean waves"
},
)
print(response.json())
```

### Chiamata a Seedance

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/seedance/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "model": "doubao-seedance-1-0-pro-250528",
    "content": [
        {
            "type": "text",
            "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"
        }
    ]
},
)
print(response.json())
```
