## Esempi di codice

Gli esempi seguenti mostrano come chiamare rispettivamente Gemini e DeepSeek tramite l’API di Ace Data Cloud. Tutte le richieste utilizzano lo stesso Base URL (`https://api.acedata.cloud`) e metodo di autenticazione.

### Chiamata a Gemini

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/gemini/chat/completions",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "model": "gemini-2.5-flash",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
},
)
print(response.json())
```
