[MCP (Model Context Protocol)](https://modelcontextprotocol.io) è un protocollo di contesto del modello lanciato da Anthropic, che consente ai modelli AI (come Claude, GPT, ecc.) di chiamare strumenti esterni tramite interfacce standardizzate. Attraverso il Veo MCP Server fornito da AceData Cloud, puoi utilizzare direttamente Google Veo per generare video AI in client AI come Claude Desktop, VS Code, Cursor, ecc.

## Panoramica delle funzionalità

Il Veo MCP Server offre le seguenti funzionalità principali:

- **Generazione video da testo** — Genera video di alta qualità tramite suggerimenti testuali
- **Generazione video da immagini** — Genera video basati su immagini
- **Supporto multi-modello** — Supporta modelli come veo3, veo2, veo31-fast-ingredient, ecc.
- **Varie risoluzioni** — Supporta formati di output come 4K, 1080p, GIF, ecc.
- **Vari rapporti d'aspetto** — Supporta proporzioni come 16:9, 9:16, ecc.
- **Aggiornamento a 1080p** — Aggiorna video già generati a 1080p
- **Query di stato** — Monitora il progresso della generazione e ottiene risultati

## Preparazione preliminare

Prima di utilizzare, è necessario ottenere il Token API di AceData Cloud:

1. Registrati o accedi alla [piattaforma AceData Cloud](https://platform.acedata.cloud)
2. Vai alla pagina [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos)
3. Clicca su "Acquire" per ottenere il Token API (il primo acquisto include un credito gratuito)

## Installazione e configurazione

### Metodo 1: installazione con pip (consigliato)

```bash
pip install mcp-veo
```

### Metodo 2: installazione da sorgente

```bash
git clone https://github.com/AceDataCloud/MCPVeo.git
cd MCPVeo
pip install -e .
```

Dopo l'installazione, puoi avviare il servizio utilizzando il comando `mcp-veo`.

## Utilizzo in Claude Desktop

Modifica il file di configurazione di Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Aggiungi la seguente configurazione:

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "il tuo Token API"
      }
    }
  }
}
```

Se utilizzi `uvx` (non è necessario installare pacchetti in anticipo):

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "il tuo Token API"
      }
    }
  }
}
```

Dopo aver salvato la configurazione, riavvia Claude Desktop per utilizzare gli strumenti relativi a Veo nella conversazione.

## Utilizzo in VS Code / Cursor

Crea `.vscode/mcp.json` nella directory principale del progetto:

```json
{
  "servers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "il tuo Token API"
      }
    }
  }
}
```

Oppure utilizza `uvx`:

```json
{

    "veo": {
```

## Elenco degli strumenti disponibili

| Nome dello strumento       | Descrizione                     |
| -------------------------- | ------------------------------- |
| `veo_text_to_video`       | Genera video tramite suggerimenti testuali  |
| `veo_image_to_video`      | Genera video basati su immagini   |
| `veo_get_1080p`           | Aggiorna video a 1080p          |
| `veo_get_task`            | Consulta lo stato di un singolo compito     |
| `veo_get_tasks_batch`     | Consulta lo stato di più compiti     |

## Esempi di utilizzo

Dopo aver completato la configurazione, puoi chiamare queste funzionalità direttamente in linguaggio naturale nei client AI, ad esempio:

- "Aiutami a generare un video di time-lapse del cielo stellato con Veo"
- "Genera un video 4K da questa foto di paesaggio"
- "Genera un breve video in verticale 9:16"
- "Aggiorna questo video a 1080p"
