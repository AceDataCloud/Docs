[MCP (Model Context Protocol)](https://modelcontextprotocol.io) è un protocollo di contesto modello sviluppato da Anthropic, che consente ai modelli AI (come Claude, GPT, ecc.) di chiamare strumenti esterni tramite un'interfaccia standardizzata. Attraverso il Flux MCP Server fornito da AceData Cloud, puoi generare e modificare immagini AI direttamente in client AI come Claude Desktop, VS Code, Cursor, ecc.

## Panoramica delle funzionalità

Flux MCP Server offre le seguenti funzionalità principali:

- **Generazione di immagini da testo** — genera immagini di alta qualità da prompt testuali
- **Modifica delle immagini** — modifica immagini esistenti basandosi su istruzioni testuali
- **Supporto multi-modello** — supporta vari modelli come Flux Pro, Flux Dev, Flux Schnell, Flux Kontext, ecc.
- **Query dei modelli** — visualizza tutti i modelli disponibili e le loro capacità
- **Query dei task** — monitora lo stato di generazione e ottieni i risultati

## Prerequisiti

Prima dell'uso, devi ottenere un API Token da AceData Cloud:

1. Registrati o accedi alla [piattaforma AceData Cloud](https://platform.acedata.cloud)
2. Vai alla pagina [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Clicca su "Acquire" per ottenere il token API (la prima richiesta include un credito gratuito)

## Installazione e configurazione

### Metodo 1: installazione con pip (consigliato)

```bash
pip install mcp-flux-pro
```

### Metodo 2: installazione dal sorgente

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Dopo l'installazione, puoi avviare il servizio con il comando `mcp-flux-pro`.

## Uso in Claude Desktop

Modifica il file di configurazione di Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Aggiungi la seguente configurazione:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tuo API Token"
      }
    }
  }
}
```

Se usi `uvx` (non richiede l'installazione preventiva del pacchetto):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tuo API Token"
      }
    }
  }
}
```

Salva la configurazione e riavvia Claude Desktop per usare gli strumenti Flux nelle conversazioni.

## Uso in VS Code / Cursor

Crea il file `.vscode/mcp.json` nella radice del progetto:

```json
{
  "servers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tuo API Token"
      }
    }
  }
}
```

Oppure usa `uvx`:

```json
{
  "servers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tuo API Token"

  }

```

## Elenco degli strumenti disponibili

| Nome strumento         | Descrizione                              |
|-----------------------|----------------------------------------|
| `flux_generate_image`  | Genera immagini da prompt testuali     |
| `flux_edit_image`      | Modifica immagini basandosi su testo   |
| `flux_get_task`        | Consulta lo stato di un singolo task   |
| `flux_get_tasks_batch` | Consulta lo stato di più task in batch |
| `flux_list_models`     | Elenca tutti i modelli disponibili e le loro capacità |
| `flux_list_actions`    | Elenca tutti gli strumenti e esempi di workflow disponibili |

## Esempi d'uso

Dopo la configurazione, puoi chiamare queste funzionalità direttamente in linguaggio naturale nei client AI, ad esempio:

- "Genera per me un'immagine in stile cyberpunk di una città notturna con Flux"
- "Cambia lo sfondo di questa foto in una spiaggia"
- "Modifica questa immagine con il modello Flux Kontext Pro, cambia il colore dei vestiti in rosso"
- "Elenca tutti i modelli Flux disponibili"
