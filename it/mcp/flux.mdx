[MCP（Model Context Protocol）](https://modelcontextprotocol.io) è un protocollo di contesto del modello lanciato da Anthropic, che consente ai modelli AI (come Claude, GPT ecc.) di chiamare strumenti esterni tramite interfacce standardizzate. Tramite Flux MCP Server fornito da AceData Cloud, puoi generare e modificare direttamente immagini AI in client AI come Claude Desktop, VS Code, Cursor e altri.

## Panoramica delle funzionalità

Flux MCP Server offre le seguenti funzionalità principali:

- **Generazione di immagini da testo** — Genera immagini di alta qualità tramite prompt testuali
- **Modifica di immagini** — Modifica immagini esistenti in base a istruzioni testuali
- **Supporto di più modelli** — Supporta vari modelli come Flux Pro, Flux Dev, Flux 2, Flux Kontext e altri
- **Query dei modelli** — Visualizza tutti i modelli disponibili e le loro capacità
- **Query delle attività** — Monitora il progresso della generazione e ottieni i risultati

## Preparazione preliminare

Prima dell'uso, devi ottenere un API Token di AceData Cloud:

1. Registrati o accedi alla [piattaforma AceData Cloud](https://platform.acedata.cloud)
2. Vai alla pagina [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Clicca su «Acquire» per ottenere l'API Token (la prima richiesta include crediti gratuiti)

## Metodo uno: utilizzo di MCP Server ospitato (consigliato, zero installazioni)

AceData Cloud ha già ospitato **Flux MCP Server** nel cloud, **senza necessità di installare alcuna dipendenza locale**: basta inserire il seguente URL direttamente nel client AI per utilizzarlo:

```
https://flux.mcp.acedata.cloud/mcp
```

Metodo di autenticazione: aggiungi `Authorization: Bearer il tuo API Token` nell'header della richiesta (Claude.ai completa automaticamente tramite OAuth, senza dover inserire manualmente il Token).

### Claude.ai (versione web, accesso OAuth, il più semplice)

1. Apri [Claude.ai](https://claude.ai) → in basso a sinistra **Customize** → **Connectors** → **Add More**
2. Inserisci nell'URL: `https://flux.mcp.acedata.cloud/mcp`
3. Completa l'accesso con autorizzazione OAuth (reindirizzamento automatico alla pagina di accesso AceData Cloud)
4. Torna all'interfaccia di conversazione e lo strumento sarà disponibile

### Claude Desktop

Modifica il file di configurazione:

- macOS：`~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows：`%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Dopo aver salvato, riavvia Claude Desktop per applicare le modifiche.

### Claude Code (terminale a riga di comando)

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Altri client che supportano MCP

Qualsiasi client che supporti il protocollo MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant ecc.) può integrarsi compilando i seguenti due elementi:

- **URL**：`https://flux.mcp.acedata.cloud/mcp`
- **Header**：`Authorization: Bearer il tuo API Token`

## Metodo due: esecuzione locale (installazione pip / uvx)

Se hai bisogno di eseguire offline, personalizzare il codice o distribuire nella rete interna, puoi installare MCP Server localmente e avviarlo tramite stdio.

### Installazione

Installazione pip (consigliata):

```bash
pip install mcp-flux-pro
```

Oppure installazione dal codice sorgente:

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Una volta completata l'installazione, puoi usare il comando `mcp-flux-pro` per avviare il servizio.

### Utilizzo in Claude Desktop (locale)

Modifica il file di configurazione di Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Aggiungi la seguente configurazione:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Se utilizzi `uvx` (senza necessità di installare il pacchetto in anticipo):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Dopo aver salvato la configurazione, riavvia Claude Desktop per applicare le modifiche.

## Elenco degli strumenti disponibili

| Nome dello strumento                    | Descrizione                       |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | Genera immagini tramite prompt testuali              |
| `flux_edit_image`      | Modifica immagini esistenti in base a istruzioni testuali             |
| `flux_generate_video`  | Generazione FLUX 3 da testo/immagine/video e miglioramento di bozze esistenti |
| `flux_get_task`        | Interroga lo stato di una singola attività                 |
| `flux_get_tasks_batch` | Interroga in batch lo stato delle attività                 |
| `flux_list_models`     | Elenca tutti i modelli disponibili e le loro capacità             |
| `flux_list_actions`    | Elenca tutti gli strumenti disponibili e gli esempi di workflow           |

Una volta completata la configurazione, puoi chiamare direttamente queste funzionalità nel client AI usando il linguaggio naturale, ad esempio:

## Vincoli dei modelli e delle dimensioni
`flux-2-flex`, `flux-2-pro`, `flux-2-max` e i modelli Kontext devono usare
proporzioni per `size`, ad esempio `1:1` o `16:9`, e non possono usare dimensioni in pixel come `1024x1024`.
`flux-2-klein` supporta solo la generazione e non è tra i modelli selezionabili di `flux_edit_image`.

`flux_generate_video` distingue `t2v`, `i2v`, `v2v` e
`draft_enhance` tramite `request.mode`, e l'input viene mostrato in base alla modalità. Il miglioramento della bozza deve fare riferimento al proprio `draft_task_id` temporaneo.
L'invio è asincrono per impostazione predefinita; conserva l'ID dell'attività restituito e usa `flux_get_task` per leggere il risultato.
