[MCP (Model Context Protocol)](https://modelcontextprotocol.io) è un protocollo di contesto modello sviluppato da Anthropic, che consente ai modelli AI (come Claude, GPT, ecc.) di chiamare strumenti esterni tramite un'interfaccia standardizzata. Attraverso il Seedance MCP Server fornito da AceData Cloud, puoi utilizzare direttamente Seedance di ByteDance per generare video AI in client AI come Claude Desktop, VS Code, Cursor, ecc.

## Panoramica delle funzionalità

Seedance MCP Server offre le seguenti funzionalità principali:

- **Generazione video da testo** — genera video di alta qualità da prompt testuali
- **Generazione video da immagine** — genera video con riferimento a immagini (modalità primo frame, ultimo frame, immagine di riferimento, ecc.)
- **Supporto multi-modello** — supporta vari modelli come Seedance 1.5 Pro, 1.0 Pro, 1.0 Lite, ecc.
- **Varie risoluzioni** — supporta risoluzioni 480p, 720p, 1080p
- **Diversi rapporti d'aspetto** — supporta 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 e altri rapporti
- **Durata flessibile** — supporta video da 2 a 12 secondi
- **Generazione audio** — alcuni modelli supportano la generazione audio simultanea
- **Query delle attività** — monitora il progresso della generazione e ottieni i risultati

## Prerequisiti

Prima di iniziare, devi ottenere un API Token da AceData Cloud:

1. Registrati o accedi alla [piattaforma AceData Cloud](https://platform.acedata.cloud)
2. Vai alla pagina [Seedance Videos API](https://platform.acedata.cloud/documents/seedance-videos)
3. Clicca su "Acquire" per ottenere l'API Token (la prima richiesta include un credito gratuito)

## Installazione e configurazione

### Metodo 1: installazione tramite pip (consigliato)

```bash
pip install mcp-seedance
```

### Metodo 2: installazione da sorgente

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Dopo l'installazione, puoi avviare il servizio con il comando `mcp-seedance`.

## Utilizzo in Claude Desktop

Modifica il file di configurazione di Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Aggiungi la seguente configurazione:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "il_tuo_API_Token"
      }
    }
  }
}
```

Se usi `uvx` (non è necessario installare pacchetti in anticipo):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "il_tuo_API_Token"
      }
    }
  }
}
```

Salva la configurazione e riavvia Claude Desktop per utilizzare gli strumenti Seedance nelle conversazioni.

## Utilizzo in VS Code / Cursor

Crea il file `.vscode/mcp.json` nella radice del progetto:

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "il_tuo_API_Token"
      }
    }
  }

```

Oppure usa `uvx`:

```json
{
```

## Elenco degli strumenti disponibili

| Nome strumento                  | Descrizione                          |
|--------------------------------|------------------------------------|
| `seedance_generate_video`       | Genera video da prompt testuale    |
| `seedance_generate_video_from_image` | Genera video con riferimento a immagine |
| `seedance_get_task`             | Consulta lo stato di un singolo task |
| `seedance_get_tasks_batch`      | Consulta lo stato di più task in batch |
| `seedance_list_models`          | Elenca tutti i modelli disponibili e le loro capacità |
| `seedance_list_resolutions`     | Elenca risoluzioni e rapporti d'aspetto disponibili |
| `seedance_list_actions`         | Elenca tutti gli strumenti e esempi di workflow disponibili |

## Esempi d'uso

Dopo la configurazione, puoi chiamare queste funzionalità direttamente con linguaggio naturale nei client AI, ad esempio:

- "Per favore genera un video time-lapse di una strada cittadina con Seedance"
- "Usa questa foto come primo frame per generare un video di 8 secondi"
- "Genera un breve video verticale 1080p con rapporto 9:16"
- "Genera un video con audio usando il modello Seedance 1.5 Pro"
