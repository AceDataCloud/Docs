[MCP (Model Context Protocol)](https://modelcontextprotocol.io) è un protocollo di contesto del modello lanciato da Anthropic, che consente ai modelli AI (come Claude, GPT e altri) di chiamare strumenti esterni tramite interfacce standardizzate. Tramite Seedance MCP Server fornito da AceData Cloud, puoi utilizzare direttamente ByteDance Seedance per generare video AI in client AI come Claude Desktop, VS Code e Cursor.

## Panoramica delle funzionalità

Seedance MCP Server offre le seguenti funzionalità principali:

- **Generazione video da testo** — Genera video di alta qualità tramite prompt testuali
- **Generazione video da immagini** — Genera video usando immagini come riferimento (modalità primo fotogramma, ultimo fotogramma, immagine di riferimento e altre)
- **Supporto multi-modello** — Supporta Seedance 1.x, 1.5, 2.0 e 2.5
- **Varie risoluzioni** — Supporta 480p, 720p, 1080p; alcuni modelli supportano 4k
- **Vari rapporti d'aspetto** — Supporta 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 e adaptive
- **Durata flessibile** — Da 2 a 30 secondi o durata automatica, a seconda del supporto del modello
- **Video multimodali** — Supporta la generazione audio, audio/video di riferimento, nonché l'editing e l'estensione video di 2.5
- **Query delle attività** — Monitora l'avanzamento della generazione e ottieni i risultati

## Consigliato: autorizzazione OAuth con MCP ospitato

Aggiungi l'indirizzo del server nei client che supportano OAuth MCP remoto:

```text
https://seedance.mcp.acedata.cloud/mcp
```

Scegli Connetti o Accedi, accedi ad Ace Data Cloud, visualizza le autorizzazioni e autorizza, quindi abilita gli strumenti. Questo percorso non richiede la creazione o la copia preventiva di un API Token. Il servizio supporta OAuth discovery, registrazione dinamica del client (DCR) e S256 PKCE; DCR registra il client, gli utenti devono comunque accedere e autorizzare e l'utilizzo dell'API viene fatturato normalmente.

| Client                            | Metodo e condizioni di integrazione                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Versione web di Claude o versione Desktop che offre connettori remoti | Aggiungi l'indirizzo sopra nell'interfaccia dei connettori e autorizza; l'accesso dipende dalla versione e dal piano. Non scrivere la configurazione HTTP remota nel file di configurazione stdio locale.                      |
| VS Code con supporto OAuth MCP remoto nativo     | Esegui **MCP: Add Server**, seleziona HTTP, inserisci l'indirizzo e accedi seguendo le istruzioni; l'estensione AceDataCloud dedicata utilizza una configurazione API Key separata. |
| Altri client                          | Verifica che la versione corrente supporti HTTP remoto, OAuth/DCR e utilizza le istruzioni di configurazione del client. Il formato del file di configurazione non può essere riutilizzato tra client diversi.                     |

## Percorso alternativo con API Token

I client stdio locali, self-hosted o che non supportano OAuth remoto utilizzano un API Token. Accedi alla [piattaforma Ace Data Cloud](https://platform.acedata.cloud), seleziona il servizio e crea credenziali API con le autorizzazioni richieste. Salva il Token nelle impostazioni delle credenziali del client o nelle variabili di ambiente locali; non inserirlo nell'URL, nel contenuto delle chat o nei repository. La configurazione degli HTTP Header dei diversi client deve essere compilata secondo le istruzioni della relativa versione.

L'installazione dell'MCP open source o il completamento dell'autorizzazione non implica l'ottenimento di crediti gratuiti, né garantisce tempi di generazione o diritti di utilizzo commerciale. Prima della generazione, consulta i prezzi correnti del servizio, il saldo e i termini applicabili.

## Metodo due: esecuzione locale (installazione pip / uvx)

Se hai bisogno di stdio locale, codice personalizzato o self-hosting, puoi avviare MCP Server localmente. La generazione richiede comunque una chiamata API tramite rete e non è inferenza offline.

### Installazione

Installazione con pip (consigliata):

```bash
pip install mcp-seedance
```

Oppure installazione dal codice sorgente:

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Dopo il completamento dell'installazione, puoi utilizzare il comando `mcp-seedance` per avviare il servizio.

### Utilizzo in Claude Desktop (locale)

Modifica il file di configurazione di Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Aggiungi la seguente configurazione:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Se utilizzi `uvx` (senza dover installare prima il pacchetto):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Dopo aver salvato la configurazione, riavvia Claude Desktop affinché abbia effetto.

### Utilizzo in VS Code (locale)

Crea `.vscode/mcp.json` nella directory radice del progetto:

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Oppure utilizza `uvx`:

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Per altri client locali, compila command, args ed env secondo le istruzioni di configurazione stdio della loro versione corrente; non considerare direttamente la configurazione di VS Code come formato universale.

## Verifica dei risultati e problemi comuni

Chiedi al client di generare un semplice video, conserva il numero dell'attività e interroga la stessa attività fino al successo dello stato finale, quindi apri o riproduci il link finale. Connessione riuscita, caricamento dell'elenco degli strumenti, HTTP 200, numero dell'attività e anteprima in elaborazione non rappresentano il prodotto finale.

In caso di 401, accedi nuovamente o controlla il Token e le autorizzazioni; se il saldo è insufficiente, consulta la fatturazione; durante l'elaborazione dell'attività, continua a interrogare; in caso di errore finale, leggi l'errore prima di decidere se riprovare: una nuova generazione potrebbe essere addebitata nuovamente.

## Elenco degli strumenti disponibili

| Nome strumento                                  | Descrizione             |
| ------------------------------------ | -------------- |
| `seedance_generate_video`            | Genera video tramite prompt testuali    |
| `seedance_generate_video_from_image` | Genera video usando immagini come riferimento     |
| `seedance_get_task`                  | Interroga lo stato di una singola attività       |
| `seedance_get_tasks_batch`           | Interroga in batch lo stato delle attività       |
| `seedance_list_models`               | Elenca tutti i modelli disponibili e le relative capacità   |
| `seedance_list_resolutions`          | Elenca le risoluzioni disponibili e i rapporti d'aspetto   |
| `seedance_list_actions`              | Elenca tutti gli strumenti disponibili e gli esempi di flusso di lavoro |

## Esempi di utilizzo

Dopo aver completato la configurazione, puoi chiamare direttamente queste funzionalità in linguaggio naturale nel client AI, ad esempio:

- «Aiutami a generare con Seedance un video time-lapse di una strada cittadina»
- «Usa questa foto come primo fotogramma e genera un video di 8 secondi»
- «Genera un breve video verticale 1080p in 9:16»
- «Usa il modello Seedance 1.5 Pro per generare un video con audio»
