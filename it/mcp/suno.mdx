[MCP (Model Context Protocol)](https://modelcontextprotocol.io) è un protocollo di contesto del modello lanciato da Anthropic, che consente ai modelli AI (come Claude, GPT, ecc.) di chiamare strumenti esterni tramite interfacce standardizzate. Tramite il Suno MCP Server fornito da AceData Cloud, puoi generare direttamente musica e testi, nonché gestire progetti audio in client AI come Claude Desktop, VS Code, Cursor e altri.

## Panoramica delle funzionalità

Suno MCP Server offre le seguenti funzionalità principali:

- **Generazione musicale** — Genera musica AI tramite prompt testuali
- **Creazione personalizzata** — Controllo completo su testi, titolo e stile musicale
- **Continuazione di brani** — Continua ad estendere brani esistenti da qualsiasi punto temporale
- **Cover/remix** — Crea versioni cover con stili diversi
- **Generazione di testi** — Genera testi strutturati in base a una descrizione
- **Personaggi vocali** — Salva e riutilizza stili vocali
- **Conversione multimediale** — Ottieni MP4, WAV, MIDI, separazione vocale e altro
- **Ottimizzazione dello stile** — Ottimizza i tag dello stile musicale
- **Query delle attività** — Monitora il progresso della generazione e ottieni i risultati

## Preparazione preliminare

Prima dell'uso, devi ottenere un API Token di AceData Cloud:

1. Registrati o accedi alla [piattaforma AceData Cloud](https://platform.acedata.cloud)
2. Vai alla pagina [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Clicca su «Acquire» per ottenere l'API Token (la prima richiesta include crediti gratuiti)

## Metodo uno: utilizzare il MCP Server ospitato (consigliato, zero installazione)

AceData Cloud ha già ospitato il **Suno MCP Server** nel cloud, **senza necessità di installare alcuna dipendenza in locale**: basta inserire il seguente URL direttamente nel client AI per utilizzarlo:

```
https://suno.mcp.acedata.cloud/mcp
```

Metodo di autenticazione: aggiungi `Authorization: Bearer il tuo API Token` nell'header della richiesta (Claude.ai completa automaticamente tramite OAuth, senza necessità di inserire manualmente il Token).

### Claude.ai (versione web, accesso OAuth, la più semplice)

1. Apri [Claude.ai](https://claude.ai) → in basso a sinistra **Customize** → **Connectors** → **Add More**
2. Inserisci nell'URL: `https://suno.mcp.acedata.cloud/mcp`
3. Completa l'accesso tramite autorizzazione OAuth (reindirizzamento automatico alla pagina di accesso AceData Cloud)
4. Torna all'interfaccia di conversazione e lo strumento sarà disponibile

### Claude Desktop

Modifica il file di configurazione:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Dopo aver salvato, riavvia Claude Desktop per rendere effettive le modifiche.

### Claude Code (terminale a riga di comando)

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Altri client che supportano MCP

Qualsiasi client che supporti il protocollo MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant, ecc.) può integrarsi compilando i seguenti due elementi:

## Metodo due: esecuzione locale (installazione pip / uvx)

Se hai bisogno di esecuzione offline, codice personalizzato o distribuzione in una rete interna, puoi installare il MCP Server in locale e avviarlo tramite stdio.

### Installazione

Installazione con pip (consigliata):

```bash
pip install mcp-suno
```

Oppure installazione dal codice sorgente:

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

Una volta completata l'installazione, puoi usare il comando `mcp-suno` per avviare il servizio.

### Utilizzo in Claude Desktop (locale)

Modifica il file di configurazione di Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Aggiungi la seguente configurazione:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Se utilizzi `uvx` (senza necessità di installare il pacchetto in anticipo):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Dopo aver salvato la configurazione, riavvia Claude Desktop per rendere effettive le modifiche.

## Esempi di utilizzo

Dopo aver completato la configurazione, puoi chiamare direttamente queste funzioni nel client AI usando il linguaggio naturale, ad esempio:

- «Aiutami a generare una canzone pop sull'estate»
- «Fai una cover di questa canzone in stile jazz»
- «Continua questa canzone, a partire dal 30° secondo»
- «Genera un testo in cinese, il tema è il viaggio»
- «Separa la voce di questa canzone»
- «Aiutami a convertire questa canzone in formato MIDI»

## Controlli avanzati e progetti Studio

`suno_generate_music` supporta `variety`; `suno_generate_custom_music` supporta inoltre
`max_mode` e `audio_weight`. `max_mode` utilizza una fascia di fatturazione API più elevata, non è abilitato per impostazione predefinita,
e deve essere impostato dopo che l'utente ha scelto esplicitamente la modalità avanzata. I prezzi attuali sono quelli indicati nella pagina del servizio della piattaforma.

`suno_generate_with_custom_model` può usare `instrumental=true` per generare musica strumentale, oppure usare
`lyric_prompt` per generare automaticamente i testi; altrimenti fornire `lyric`. Titolo e stile possono essere omessi, ed è anche possibile passare
`negative_tags`, `vocal_gender`, `weirdness`, `style_influence`, `duration` e
`callback_url`. I valori di controllo espliciti pari a `0` verranno mantenuti.

`request.action` di `suno_manage_project` può essere `create`, `retrieve`, `save`,
`upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`,
`remove_track`, `render`. L'input varia in base all'azione; le modifiche al progetto devono usare il `version_id` letto più di recente;
al salvataggio, passare lo `state` completo, mantenendo le tracce e i campi esistenti.

A eccezione di `retrieve`, ogni chiamata deve fornire `idempotency_key`. Le nuove operazioni di scrittura usano una nuova chiave;
in caso di timeout o risultato di accettazione incerto, mantenere la chiave originale e ritentare con una richiesta completamente identica, oppure interrogare l'attività originale, senza
cambiare automaticamente chiave e inviare nuovamente generazioni a pagamento. Gli intervalli dell'audio sorgente usano i secondi, gli intervalli della timeline del progetto usano i battiti. La generazione crea solo candidati,
è necessario selezionare un candidato e chiamare `commit_candidate` affinché venga scritto nella traccia.

Il `task_id` accettato in modo asincrono viene interrogato con `suno_get_task`. Quando `finished_at` è vuoto, continuare ad attendere,
dopo lo stato finale controllare `response.success` e gli errori; non considerare l'accettazione riuscita come generazione, invio o esportazione riusciti.
`suno_get_tasks_batch` restituisce record completi delle attività in JSON, mantenendo oggetti di modelli personalizzati, stati del progetto,
candidati e vari tipi di risultati come MIDI. Per il flusso di lavoro completo, consultare la [guida ai progetti Studio](https://platform.acedata.cloud/documents/suno-projects-integration).
