[MCP (Model Context Protocol)](https://modelcontextprotocol.io) è un protocollo di contesto modello sviluppato da Anthropic, che consente ai modelli AI (come Claude, GPT, ecc.) di chiamare strumenti esterni tramite un'interfaccia standardizzata. Attraverso il Seedream MCP Server fornito da AceData Cloud, puoi utilizzare direttamente la generazione e modifica di immagini AI di ByteDance Seedream in client AI come Claude Desktop, VS Code, Cursor, ecc.

## Panoramica delle funzionalità

Seedream MCP Server offre le seguenti funzionalità principali:

- **Generazione di immagini da testo** — genera immagini di alta qualità da prompt testuali (supporta prompt in cinese e inglese)
- **Modifica immagini** — modifica stile, sfondo, attributi e altro di immagini esistenti
- **Prova virtuale di abbigliamento** — applica capi di abbigliamento a foto di persone
- **Supporto multi-modello** — supporta modelli Seedream v4.5, v4.0, v3.0 T2I, SeedEdit v3.0 I2I, ecc.
- **Varie risoluzioni** — supporta risoluzioni 1K, 2K, 4K e risoluzioni adattive
- **Controllo del seed** — riproducibilità dei risultati tramite parametro seed
- **Query attività** — monitora lo stato di generazione e ottieni i risultati

## Prerequisiti

Prima dell'uso, devi ottenere un API Token AceData Cloud:

1. Registrati o accedi alla [piattaforma AceData Cloud](https://platform.acedata.cloud)
2. Vai alla pagina [Seedream Images API](https://platform.acedata.cloud/documents/seedream-images)
3. Clicca su "Acquire" per ottenere il token API (la prima richiesta include un credito gratuito)

## Installazione e configurazione

### Metodo 1: installazione pip (consigliato)

```bash
pip install mcp-seedream-pro
```

### Metodo 2: installazione da sorgente

```bash
git clone https://github.com/AceDataCloud/MCPSeedream.git
cd MCPSeedream
pip install -e .
```

Dopo l'installazione, puoi avviare il servizio con il comando `mcp-seedream-pro`.

## Uso in Claude Desktop

Modifica il file di configurazione di Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Aggiungi la seguente configurazione:

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tuo API Token"
      }
    }
  }
}
```

Se utilizzi `uvx` (non richiede l'installazione preventiva di pacchetti):

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tuo API Token"
      }
    }
  }
}
```

Salva la configurazione e riavvia Claude Desktop per utilizzare gli strumenti Seedream nelle conversazioni.

## Elenco degli strumenti disponibili

| Nome strumento           | Descrizione                      |
|-------------------------|---------------------------------|
| `seedream_generate_image` | Genera immagini da prompt testuali |
| `seedream_edit_image`      | Modifica o edita immagini esistenti |
| `seedream_get_task`        | Consulta lo stato di un singolo task |
| `seedream_get_tasks_batch` | Consulta in batch lo stato di più task |
| `seedream_list_models`     | Elenca tutti i modelli disponibili e le loro capacità |
| `seedream_list_sizes`      | Elenca le dimensioni e risoluzioni immagini disponibili |

## Esempi d'uso

Dopo la configurazione, puoi chiamare queste funzionalità direttamente in linguaggio naturale nei client AI, ad esempio:

- "Per favore genera un paesaggio in stile pittura a inchiostro con Seedream"
- "Cambia lo sfondo di questa foto in un cielo stellato"
- "Genera un ritratto 4K ad alta definizione con Seedream v4.5"
- "Applica virtualmente questo capo di abbigliamento a questa foto"
