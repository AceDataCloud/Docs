[MCP (Model Context Protocol)](https://modelcontextprotocol.io) è un protocollo di contesto modello sviluppato da Anthropic, che consente ai modelli AI (come Claude, GPT, ecc.) di chiamare strumenti esterni tramite un'interfaccia standardizzata. Attraverso il ShortURL MCP Server fornito da AceData Cloud, puoi generare link brevi direttamente in client AI come Claude Desktop, VS Code, Cursor, ecc.

## Panoramica delle funzionalità

Il ShortURL MCP Server offre le seguenti funzionalità principali:

- **Accorciamento singolo link** — Trasforma URL lunghi in link brevi e facilmente condivisibili
- **Accorciamento batch di link** — Accorcia più URL contemporaneamente (fino a 10)
- **Guida all'uso** — Ottieni istruzioni complete e best practice
- **Informazioni API** — Visualizza dettagli del servizio API e codici di errore

## Prerequisiti

Prima dell'uso, devi ottenere un API Token da AceData Cloud:

1. Registrati o accedi alla [piattaforma AceData Cloud](https://platform.acedata.cloud)
2. Vai alla pagina [ShortURL API](https://platform.acedata.cloud/documents/short-url)
3. Clicca su "Acquire" per ottenere l'API Token (la prima richiesta include un credito gratuito)

## Installazione e configurazione

### Metodo 1: installazione tramite pip (consigliato)

```bash
pip install mcp-shorturl
```

### Metodo 2: installazione da sorgente

```bash
git clone https://github.com/AceDataCloud/MCPShortURL.git
cd MCPShortURL
pip install -e .
```

Dopo l'installazione, puoi avviare il servizio con il comando `mcp-shorturl`.

## Uso in Claude Desktop

Modifica il file di configurazione di Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Aggiungi la seguente configurazione:

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tuo API Token"
      }
    }
  }
}
```

Se usi `uvx` (non richiede installazione preventiva di pacchetti):

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "uvx",
      "args": ["mcp-shorturl"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "tuo API Token"
      }
    }
  }
}
```

Salva la configurazione e riavvia Claude Desktop per utilizzare gli strumenti ShortURL nelle conversazioni.

## Elenco degli strumenti disponibili

| Nome strumento           | Descrizione                          |
|-------------------------|------------------------------------|
| `shorturl_create`       | Accorcia un singolo URL             |
| `shorturl_batch_create` | Accorcia più URL contemporaneamente (fino a 10) |
| `shorturl_get_usage_guide` | Ottieni la guida completa all'uso  |
| `shorturl_get_api_info` | Ottieni dettagli sul servizio API  |

## Esempi d'uso

Dopo la configurazione, puoi chiamare queste funzionalità direttamente nel client AI con linguaggio naturale, ad esempio:

- "Per favore accorcia questo link"
- "Accorcia questi 5 URL in batch"
- "Genera un link breve da condividere"
