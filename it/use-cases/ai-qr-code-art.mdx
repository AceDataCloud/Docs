## Panoramica

I codici QR tradizionali sono tutti uguali, mentre i codici QR artistici AI possono integrare elementi del brand nel design del codice QR, aumentando il tasso di scansione. L'API QR Art di Ace Data Cloud supporta diverse impostazioni di stile artistico.

## Servizi Coinvolti

- **QR Art**: `POST https://api.acedata.cloud/qrart/generate`

## Soluzione Tecnica

### Prerequisiti

1. Registrare un account su [Ace Data Cloud](https://platform.acedata.cloud)
2. Ottenere il Token API
3. Installare Python 3.7+ e la libreria requests

### Passaggi di Implementazione

### Passaggio 1: Impostare il contenuto del codice QR

Selezionare il tipo (link/text/email/phone) e impostare il contenuto.

### Passaggio 2: Scegliere lo stile artistico

Usare il parametro `preset` per selezionare uno stile predefinito, come sunset, floral, neon-mech.

### Passaggio 3: Generare e scaricare

Chiamare l’endpoint `/qrart/generate` per generare, e consultare `/qrart/tasks` per monitorare lo stato.

## Esempio di Codice

Di seguito un esempio completo in Python per utilizzare QR Art:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_qrart():
    response = requests.post(
        "https://api.acedata.cloud/qrart/generate",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "type": "link",
    "content": "https://platform.acedata.cloud",
    "prompt": "sunset ocean waves",
    "preset": "neon-mech"
},
    )
    return response.json()

result = call_qrart()
print(result)
```

## Best Practice

- **Ritenti in caso di errore**: applicare backoff esponenziale per errori 429 (rate limit) e 5xx
- **Elaborazione asincrona**: per attività più lunghe (generazione immagini/video), usare callback_url per ricevere i risultati in modo asincrono
- **Controllo dei costi**: monitorare utilizzo e spese tramite la console Ace Data Cloud
- **Sicurezza del Token**: conservare il Token API in variabili d’ambiente, evitare di inserirlo direttamente nel codice
