本页只记录**对开发者有可见影响**的变更（新接口、新模型、计费调整、行为变化）。Bug fix、内部重构、文档调整不纳入。

完整发布列表见各仓库的 GitHub Releases。

## 2025-12

<Update label="2025-12" tags={["docs"]}>
  **文档信息架构重写**

  - 新增 [统一响应格式](/concepts/responses)、[异步任务模式](/concepts/async-tasks) 概念页
  - 新增 [价格总览](/pricing/overview)（聊天 / 图像 / 视频 / 音乐 4 个细分页）
  - 新增 [FAQ](/faq/billing) 区（计费 / 并发 / 存储）
  - 拆分顶部导航：指南 / 价格 / API 参考 / MCP / FAQ / 关于
  - 文档站从 PlatformBackend 同步切换为独立维护
</Update>

## 2025-11

<Update label="2025-11" tags={["model"]}>
  **GPT Image 2**

  - 新增 `gpt-image-2` 模型，支持 14 种尺寸场景
  - 同时支持文生图与图编辑（inpaint）
</Update>

<Update label="2025-11" tags={["model"]}>
  **Veo 3.1**

  - 上线 Google `veo-3.1`，画质显著提升
  - 同时支持 `veo-3-fast` 廉价档
</Update>

## 2025-10

<Update label="2025-10" tags={["model"]}>
  **Seedream 5.0 / Seedance 2.0**

  - ByteDance 旗舰图像模型 `seedream-5.0`
  - ByteDance 视频 `seedance-2.0` 支持 1080p
</Update>

<Update label="2025-10" tags={["mcp"]}>
  **MCP 服务器：Producer / Wan / Hailuo / Kling**

  - 新增 4 个 MCP 服务器，目前 MCP 总数达到 15
  - 全部支持 `stdio` 和 `streamable-http` 两种传输
</Update>

## 2025-09

<Update label="2025-09" tags={["model"]}>
  **Claude 4.5 / Sonnet 4.5 / Haiku 4.5**

  - 上线 Anthropic 4.5 系列
  - 兼容 OpenAI Chat Completions 协议
</Update>

<Update label="2025-09" tags={["billing"]}>
  **任务失败统一不扣费**

  - 此前部分上游错误会半计费，现在全平台统一：**只有 `success` 才扣**
  - 内容审核拒绝（403）不扣费
</Update>

## 2025-08

<Update label="2025-08" tags={["model"]}>
  **Sora 2 上线**

  - 支持 720p / 1080p
  - 支持 image-to-video 与 character reference
</Update>

<Update label="2025-08" tags={["api"]}>
  **Webhook 签名校验**

  - 所有异步任务的 Webhook 现支持 `callback_secret`
  - 头部 `X-Callback-Signature: HMAC-SHA256(secret, body)`
  - 详见 [异步任务模式](/concepts/async-tasks)
</Update>

## 2025-07

<Update label="2025-07" tags={["model"]}>
  **GPT-5 系列**

  - OpenAI GPT-5 / GPT-5-mini 上线
  - 支持 reasoning effort 参数
</Update>

<Update label="2025-07" tags={["platform"]}>
  **X402 支付协议**

  - 支持用 Solana USDC / Base USDC 链上支付订单
  - 详见 [platform.acedata.cloud](https://platform.acedata.cloud) → 充值 → 加密货币
</Update>
