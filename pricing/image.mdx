图像生成按**单张出图**或**单次提交**计费，因服务和参数（尺寸、模型版本、是否带 video）不同。

## Midjourney

| 操作 | 单价 (USD) | 说明 |
|---|---|---|
| `/imagine` (1 次 4 宫格) | $0.025 | 文生图、图生图 |
| `/upscale` | $0.005 | 单张放大 |
| `/variation` | $0.025 | 变体（仍返回 4 宫格） |
| `/blend` | $0.025 | 多图融合 |
| `/describe` | $0.005 | 反向 prompt |
| `/inpaint` | $0.025 | 局部重绘 |
| `/animate` | $0.10 | 图转视频 |

支持版本：v5.2 / v6.0 / v6.1 / v7 / v8。计费与版本无关。

## 计费时机

- **任务 success 时扣费**
- 内容审核拒绝（403）不扣费
- 失败 / 超时不扣费
- 4 宫格按**整次 imagine** 扣费，不是每张

<Note>
  实际价格以 [platform.acedata.cloud](https://platform.acedata.cloud) 控制台为准。本表会定期同步但可能滞后。
</Note>
