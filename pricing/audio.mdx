音乐 / 音频生成按**单曲**或**单次合成**计费。

## Suno

| 操作 | 单价 (USD) | 说明 |
|---|---|---|
| 生成歌曲 (`/generate`) | $0.08 | 一次返回 2 首 |
| Custom 模式 | $0.08 | 自定义歌词、风格 |
| Extend | $0.05 | 延长已有歌曲 |
| Cover | $0.10 | 翻唱 / 改编 |
| Lyrics | $0.005 | 仅生成歌词，不出歌 |
| Persona (vocal) | $0.05 | 声纹替换 |
| Vocal / Instrumental 分离 | $0.02 | 从已有歌曲分离 |
| WAV / MIDI / MP4 导出 | $0.01 | 单一格式 |

## Producer (FUZZ)

|---|---|

| Instrumental Swap | $0.05 |

## Fish Audio (TTS)

| 操作 | 单价 |
|---|---|
| 文本转语音 | $0.015 / 1k 字符 |
| 语音克隆 (single shot) | $0.05 / 次 |
| 自定义音色 | 控制台询价 |

## 计费规则

- **任务 success 时扣费**
- `failed` / 上游超时不扣费
- 一次提交返回 2 首（Suno、Producer）算**一次**计费
- 同曲的多种格式导出（MP3 / WAV / MIDI / MP4）分开计费

<Note>
  实际价格以 [platform.acedata.cloud](https://platform.acedata.cloud) 控制台为准。本表会定期更新但可能延迟。
</Note>
