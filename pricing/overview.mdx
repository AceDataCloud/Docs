Ace Data Cloud 上的服务采用**按量计费**（Pay-as-you-go），不收取月度订阅费。计费在调用真实落地后扣减。

## 计费币种

- 控制台展示使用 **USD** 作为参考币种
- 实际扣减以**积分（Credits）**为单位，套餐购买时按当时汇率折算
- 详细折算关系见 [FAQ — 计费与额度](/faq/billing)

## 计费时机

| 类型 | 何时扣费 |
|---|---|
| 同步 API（如 Chat） | 响应返回时按 token / 字符数扣 |
| 异步任务（Image / Video / Audio） | **任务最终 success 时扣费**，`failed` 不扣费 |
| 内容审核拒绝（403） | **不扣费** |
| 上游超时 / 5xx | **不扣费** |

## 折扣

- **质押 $ACE 代币**可获得自动叠加的折扣，详见 [代币计划](https://platform.acedata.cloud/coin)
- **大客户**可申请阶梯返点，联系 `sales@acedata.cloud`

## 实时查价

最准确的当前价格在控制台：

1. 登录 [platform.acedata.cloud](https://platform.acedata.cloud)
2. 打开任一服务详情
3. 查看「定价」标签，按场景查看 USD 单价

<Note>
  本文档区的价格表会定期更新但**可能存在延迟**。出现差异时以控制台为准。
</Note>

## 余额与额度

- **服务额度**：订阅套餐附带的限额，只能用于该服务
- **全局余额**：可用于全部服务，不限品类
- 优先扣减顺序：服务额度 → 全局余额
- 用完后请求会返回 `402 insufficient_balance`

更多见 [FAQ — 计费与额度](/faq/billing)。
