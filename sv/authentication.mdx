---

Alla Ace Data Cloud API använder **Bearer Token** autentisering.

## Skaffa Token

1. Registrera ett konto på [platform.acedata.cloud](https://platform.acedata.cloud)
2. Prenumerera på önskade tjänster
3. Skapa autentiseringsuppgifter (API Token) för varje tjänst

## Använda Token

Inkludera Token i `Authorization`-huvudet för varje förfrågan:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Tip">
  Varje Token är kopplad till en specifik tjänsteprenumeration. Använd olika Token för olika tjänster, eller skapa **globala** autentiseringsuppgifter för att använda över flera tjänster.
</Note>

## Hastighetsbegränsningar

Hastighetsbegränsningar varierar beroende på tjänst och prenumerationsnivå. Vid överskridande av gränsen returnerar API:et `429 Too Many Requests`.

## Säkerhetsbästa praxis

- Exponera inte API Token i klientkod
- Använd miljövariabler för att lagra Token
- Rotera Token regelbundet
- Använd olika Token för utvecklings- och produktionsmiljöer
