Alla Ace Data Cloud API använder **Bearer Token** för autentisering.

## Hämta Token

Logga in på [Applications](https://platform.acedata.cloud/console/applications?lang=sv&utm_source=docs&utm_medium=referral&utm_campaign=evergreen) och öppna **General Application**. Om appen saknas första gången väljer du **Initialize General Application**. Klicka på kopieringsknappen bredvid **API KEY**, markerad med **1** i bilden.

![Kopieringsknappen bredvid API-nyckeln, markerad med 1](https://raw.githubusercontent.com/AceDataCloud/NanoBananaDify/2522b2f57210597af2db866445319334a1677a23/_assets/tutorial/get-api-key-en.png)

Förvara nyckeln på servern och ersätt `YOUR_API_TOKEN` i exemplet med det kopierade värdet.

## Använda Token

Inkludera Token i `Authorization`-huvudet för varje förfrågan:

```bash
Authorization: Bearer YOUR_API_TOKEN
```


## Hastighetsbegränsning

Hastighetsbegränsningar varierar beroende på tjänst och prenumerationsnivå. Vid överskridande av gränsen returnerar API:et `429 Too Many Requests`.

## Säkerhetsbästa praxis

- Exponera inte API Token i klientkod
- Använd miljövariabler för att lagra Token
- Rotera Token regelbundet
- Använd olika Token för utvecklings- och produktionsmiljöer
