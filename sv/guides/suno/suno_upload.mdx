SUNO låter oss ladda upp referensljud för vidare skapande, och detta dokument förklarar hur relaterade API:er integreras.

Vanliga uppladdningar behöver endast `audio_url`, som är en offentligt tillgänglig ljud-CDN-adress. `mode` är som standard `standard`, så befintliga anrop behöver inte ändras. En lyckad vanlig uppladdning förbrukar **0.06 Credits**; misslyckade uppladdningar kostar inget.

Här är `audio_url` som vi anger `https://cdn.acedata.cloud/suno_demo.mp3`, vilket är en offentligt tillgänglig CDN-adress.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Som du kan se är `data` alltid ett objekt, och `audio_id` är låt-ID:t efter uppladdningen. Analysresultat såsom `lyric`, `style`, `duration`, titel och medie-URL:er är valfria fält; detaljerna beror på det returnerade innehållet.

Efter att du har fått låt-ID:t kan du via [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) anropa åtgärder som `upload_extend`, `upload_cover` eller intervallsampling som kräver `audio_id`. Om du vill skapa ny musik baserat på 1 till 4 kompletta referensljud med Inspo-inspirationsskapandefunktionen, anropa direkt `action=inspo` och skicka in listan med ursprungliga offentliga ljud-URL:er; tjänsten slutför automatiskt uppladdning och analys, utan att klienten behöver sammanställa ljudmetadata.

## Ladda upp originalsång för cover med privat röst

När du använder en privat röst som skapats med `/suno/voices` för att göra en cover, skickar du `persona_id` för den rösten i den vanliga uppladdningsbegäran för att koppla originalsången till rösten:

```json
{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "mode": "standard",
  "persona_id": "<声音创建接口返回的 persona_id>"
}
```

Efter en lyckad uppladdning använder du det returnerade `data.audio_id` för att anropa `/suno/audios`, anger `action: "upload_cover"` och skickar in samma `persona_id`. Fortsätt inte att använda ett tidigare ljud-ID som inte har kopplats till denna röst.

`persona_id` stöder endast vanliga uppladdningar och kan inte användas tillsammans med `mode: "enhanced"`. Du behöver inte ange `vocal_gender` ytterligare; könspreferens kan inte ersätta röst-ID:t. Att skapa rösten, ladda upp originalsången och göra covern måste använda samma tjänstkanal.

## Förbättrat uppladdningsläge

> `audio_url` är indataadressen och skickas direkt till ljudbearbetningsflödet; den överförs inte i förväg av tjänsten för beständig lagring av slutligt media. Kontrollera att den är offentligt tillgänglig under uppgiftsbearbetningen.

När en vanlig uppladdning inte kan bearbeta ljud som du äger eller har fått tillstånd att använda, kan du ange `mode` som `enhanced`. Detta läge måste även tillhandahålla ett `name` på 1 till 100 tecken och använda en offentligt tillgänglig HTTPS-`audio_url`.

Förbättrad uppladdning använder alltid asynkron bearbetning och kräver vanligtvis 2 minuter eller mer. Lyckad bearbetning förbrukar **1.87 Credits**; misslyckad bearbetning kostar inget.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

API:et returnerar omedelbart `task_id` och `trace_id`. Använd [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) för att fråga uppgiften och läs, efter lyckat resultat, det uppladdade ljud-ID:t från `response.data.audio_id`. Du kan också tillhandahålla en HTTPS-`callback_url` för att ta emot slutstatus.
Det `audio_id` som erhålls vid förbättrad uppladdning kan användas för Cover, Samples och Mashup. Extrahering av ackompanjemang och MIDI, separation av alla spår samt separation av sång/ackompanjemang kan fortfarande vara begränsad av det konto som ljudet tillhör; åtgärder som inte listas garanteras inte stöd för användning mellan konton. Ju kortare ljudet är, desto högre är vanligtvis sannolikheten för lyckad bearbetning.
