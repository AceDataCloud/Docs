SUNO tillåter oss att ladda upp referensljud för sekundär skapande, detta dokument förklarar integrationsmetoden för relaterade API:er.

Vanlig uppladdning kräver endast `audio_url`, det är en offentligt tillgänglig ljud-CDN-adress. `mode` är som standard `standard`, därför behöver befintliga anrop inte ändras. En lyckad vanlig uppladdning förbrukar **0.06 Credits**; misslyckad uppladdning debiteras inte.

Här är den `audio_url` vi anger `https://cdn.acedata.cloud/suno_demo.mp3`, vilket är en offentligt tillgänglig CDN-adress.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Man kan se att `data` alltid är ett objekt, `audio_id` är låt-ID:t efter uppladdningen. Analysresultat såsom `lyric`, `style`, `duration`, titel och medie-URL:er är valfria fält, specifikt innehåll avgörs av returvärdet.

Efter att ha fått låt-ID:t kan man via [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) anropa `upload_extend`, `upload_cover` eller operationer såsom intervallsampling som kräver `audio_id`. Om du vill använda Inspo-funktionen för inspirationsskapande för att skapa ny musik baserat på 1 till 4 kompletta referensljud, anropa direkt `action=inspo` och skicka in listan över ursprungliga offentliga ljud-URL:er; tjänsten slutför automatiskt uppladdning och analys, utan att klienten behöver sätta ihop ljud-metadata.

## Förbättrat uppladdningsläge

> `audio_url` är inmatningsadressen, den överlämnas direkt till ljudbehandlingsflödet och överförs inte i förväg av tjänsten för persistent lagring av slutgiltiga medier. Se till att den är offentligt tillgänglig under uppgiftsbehandlingen.

När vanlig uppladdning inte kan behandla ljud som du äger eller har fått tillstånd att använda, kan du ange `mode` som `enhanced`. Detta läge måste också ange ett `name` på 1 till 100 tecken och använda en offentligt tillgänglig HTTPS-`audio_url`.

Förbättrad uppladdning använder alltid asynkron behandling och tar vanligtvis 2 minuter eller längre. Lyckad behandling förbrukar **1.87 Credits**; misslyckad behandling debiteras inte.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

Gränssnittet returnerar omedelbart `task_id` och `trace_id`. Använd [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) för att fråga efter uppgiften och läs, efter lyckad behandling, det uppladdade ljud-ID:t från `response.data.audio_id`. Du kan också ange HTTPS-`callback_url` för att ta emot slutstatusen.

`audio_id` som erhålls genom förbättrad uppladdning kan användas för Cover, Samples och Mashup. Extraktion av instrumentalt ljud och MIDI, separation av alla spår samt separation av sång/instrumentalt ljud kan fortfarande vara begränsade av det konto som ljudet tillhör; för operationer som inte listas garanteras inte stöd för användning över flera konton. Ju kortare ljudet är, desto högre är vanligtvis sannolikheten för lyckad behandling.
