SUNO tillåter oss att ladda upp referensljud för vidare skapande, detta dokument förklarar hur man integrerar relaterade API:er.

Vanlig uppladdning kräver endast `audio_url`, som är en offentligt tillgänglig ljud-CDN-adress. `mode` är som standard `standard`, så befintliga anrop behöver inte ändras.

Här är vår inmatade `audio_url`: `https://cdn.acedata.cloud/suno_demo.mp3`, som är en offentligt tillgänglig CDN-adress.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Man kan se att `data` fältet `audio_id` är ID:t för låten efter uppladdning.

Med låtens ID kan vi använda [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) för att generera anpassade låtar, till exempel genom att skicka `action` som `upload_extend` och `audio_id` som det returnerade låt-ID:t, så kan vi generera en ny låt baserat på referensljudet.

## Förbättrad uppladdningsläge

När vanlig uppladdning inte kan hantera ljud som du äger eller har rätt att använda, kan `mode` sättas till `enhanced`. Detta läge kräver också att man anger ett `name` med 1 till 100 tecken och använder en offentligt tillgänglig HTTPS `audio_url`.

Förbättrad uppladdning använder alltid asynkron behandling, vilket vanligtvis tar 2 minuter eller längre. En lyckad behandling kostar **1.87 Credits**, vilket motsvarar cirka **¥1.20/gång**; misslyckad behandling debiterar inte.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

API:et kommer omedelbart att returnera `task_id` och `trace_id`. Använd [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) för att kontrollera uppgiften, och vid framgång kan du läsa det uppladdade ljud-ID:t från `response.data.audio_id`. Du kan också ange en HTTPS `callback_url` för att ta emot slutstatus.

Det `audio_id` som erhålls från förbättrad uppladdning kan användas för Cover, Samples och Mashup. Ackompanjemang och MIDI-extraktion, full spårseparation samt sång/ackompanjemang-separation kan fortfarande vara begränsade av kontot som ljudet tillhör; icke-listade operationer garanterar inte stöd för användning över konton. Ju kortare ljudet är, desto högre är vanligtvis framgångsgraden för behandlingen.
