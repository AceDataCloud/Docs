SUNO tillåter oss att ladda upp referensljud för vidare skapande, detta dokument förklarar hur man integrerar relaterade API:er.

Detta API har endast en inparametrar, nämligen `audio_url`, som är en offentligt tillgänglig CDN-adress som stöder mp3-förlängning.

Här är vår inmatade `audio_url`: `https://cdn.acedata.cloud/suno_demo.mp3`, som är en offentligt tillgänglig CDN-adress.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Man kan se att `data` fältet `audio_id` är ID:t för låten efter uppladdningen.

Med låtens ID kan vi använda [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) för att generera anpassade låtar, till exempel genom att skicka `action` som `upload_extend`, samtidigt som `audio_id` skickas som det returnerade låt-ID:t, så kan vi generera en ny låt baserat på referensljudet.
