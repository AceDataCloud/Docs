---
title: "API för kontroll av Suno-ljudtillgänglighet"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

`POST /suno/availability` söker, baserat på `audio_id`, efter positiva bevis för att ljudet kan fortsätta bearbetas på den aktuella rutten. Kan anropas före åtgärder som fortsättning och coverversioner; resultatet återspeglar endast statusen vid kontrolltillfället och garanterar inte att en specifik åtgärd lyckas. Detta API returnerar synkront, kräver en API-token och drar för närvarande inga Credits.

`audio_id` är låt-ID:t som returneras av en slutförd Suno-uppgift, inte `task_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

Exempel på lyckat svar:

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

När kontrollen lyckas är `data.available` `true`; om det inte kan bekräftas returneras `503 availability_unknown` och `false` returneras inte. Felaktigt `audio_id`-format returnerar 400, och hastighetsbegränsning eller tjänstefel returnerar också ett felsvar. Statusen kan fortfarande ändras mellan kontrollens slutförande och den faktiska åtgärden.
