SUNO tillåter oss att hämta musik i wav-format, detta dokument förklarar hur man integrerar med relaterade API:er.

Den centrala inparametern för detta API är `audio_id`, som är det officiellt genererade låt-ID:t; valfritt stöder det även `callback_url` för asynkron återkoppling.

Här är det `audio_id` vi anger: `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer YOUR_API_KEY",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Resultatet ser ut som följer:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://cdn.acedata.cloud/e724d7f13d.png?example=image-001"
    }
  ]
}
```

Som vi kan se är `file_url`-fältet i `data` den wav-format musikfil vi har hämtat, det är en offentligt tillgänglig CDN-adress.

> **Om hållbarheten för WAV-länkar**
> Plattformen kommer först att persistenta WAV-filen i slutligt tillstånd till Ace Data Cloud CDN innan den returneras. Den ovanstående URL:en visar endast svarformatet och representerar inte ett långvarigt verkligt objekt. Endast om CDN-persistensen inte är slutförd och den ursprungliga medieadressen fortfarande kan laddas ner till en giltig WAV-fil vid omedelbar verifiering, kan `file_url` behålla den adressen; om adressen har upphört att gälla eller filverifieringen misslyckas, kommer begäran att returnera ett misslyckande eller timeout, och kommer inte att ge en odelbar adress som ett framgångsrikt resultat. Vänligen ladda ner och spara den i tid efter att uppgiften är slutförd, den specifika bevarandeperioden beror på plattformens aktuella lagringspolicy.
