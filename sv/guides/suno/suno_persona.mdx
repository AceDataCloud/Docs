---
title: "Suno API-integrationsanvisning för anpassad sångarstil"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO tillåter oss att ange en sångarstil för redan genererade låtar och sedan göra en sekundär skapelse baserat på den. Detta dokument förklarar integrationsmetoden för relaterade API:er.

`GET /suno/persona` för att hämta listan och `DELETE /suno/persona` för att ta bort poster är kostnadsfria och kräver inga extra förfrågningshuvuden för kostnadsfrihet. Skapandeåtgärden `POST /suno/persona` debiteras fortfarande enligt gränssnittets prissättningsregler.

På skapandelinjer som stödjer röstklangsfrågor kan du använda den ursprungliga applikationen och anroparidentiteten för att skicka `persona_id` från skapanderesultatet till `POST /suno/availability`. När den bekräftas vara tillgänglig returneras `data.available=true`. [Guide för kontroll av röstklangstillgänglighet](https://platform.acedata.cloud/documents/suno-availability-integration)

Detta API har endast tre inmatningsparametrar, först `audio_id`, vilket är ett låt-ID som redan har genererats framgångsrikt officiellt, därefter `name` och `description`, vilka är ett namn och en beskrivning av sångarstilen.

Här är `audio_id` som vi matar in `https://cdn.acedata.cloud/2qhzs3.png`, detta kan referera till [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) för att utföra anpassad låtgenerering, och slutligen kan `audio_id` erhållas.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Resultatet är följande:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Det går att se att fältet `persona_id` i `data` är det genererade ID:t för sångarstilen.

Efter att ha fått ID:t för sångarstilen kan vi använda [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) för att utföra anpassad låtgenerering, till exempel genom att skicka in `artist_consistency` för `action`, samtidigt skicka in ID:t för den uppladdade låten för `audio_id`, och även ladda upp parametern `persona_id`, där detta värde är ID:t för sångarstilen som returnerades ovan, så kan nya låtar genereras baserat på den refererade sångarstilen.
