---
title: "Instruktioner för API-integrering av Suno anpassad sångarstil"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO låter oss ange en sångarstil för redan genererade låtar och sedan utföra sekundär skapande baserat på den. Detta dokument förklarar hur relaterade API:er integreras.

Listfrågan `GET /suno/persona` och borttagning av poster med `DELETE /suno/persona` är kostnadsfria och kräver inga extra begärandehuvuden för kostnadsfrihet. Skapande med `POST /suno/persona` debiteras fortfarande enligt gränssnittets prissättningsregler.

Detta API har endast tre inmatningsparametrar: först `audio_id`, vilket är ID:t för en låt som redan har genererats framgångsrikt officiellt; sedan `name` och `description`, vilka är ett namn och en beskrivning av sångarstilen.

Här är `audio_id` som vi matar in `https://cdn.acedata.cloud/2qhzs3.png`. Du kan hänvisa till [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) för att generera en anpassad låt och slutligen få `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Resultatet är följande:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Som du kan se är fältet `persona_id` i `data` det genererade ID:t för sångarstilen.

Efter att ha fått ID:t för sångarstilen kan vi använda [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) för att generera en anpassad låt. Till exempel kan `action` skickas in som `artist_consistency`, samtidigt som `audio_id` skickas in som ID:t för den uppladdade låten. Parametern `persona_id` måste också laddas upp; detta värde är ID:t för sångarstilen som returnerades ovan. Då kan en ny låt genereras baserat på den refererade sångarstilen.
