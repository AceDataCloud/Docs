---
title: "Guide för integrering av Sunos exklusiva musikmodell"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Exklusiva musikmodeller kan lära sig konsekventa musikaliska egenskaper från 6 till 24 licensierade ljudfiler och användas för efterföljande låtskapande. Skapandet är en asynkron operation; det rekommenderas att använda 24 ljudfiler med konsekvent stil och tydlig ljudkvalitet för stabilare resultat.

> Du får endast skicka in ljudfiler som du har laglig rätt att använda, eller för vilka du har erhållit tillstånd för modellskapande och efterföljande generering. Ladda inte upp musik- eller ljudmaterial utan tillstånd.

## Skapa modell

Anropa `POST /suno/custom-models` och ange `action=create`:

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

Gränssnittet returnerar omedelbart plattformens modell-ID och uppgifts-ID. När skapandet är klart ändras `status` i callbacken eller frågeresultatet till `ready`. Endast lyckad modellskapande debiteras med **10 Credits**; misslyckat skapande debiteras inte.

## Fråga efter modeller

Fråga efter en enskild modell:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Fråga efter den aktuella applikationens modeller med sidindelning:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Alla modeller tillhör den Suno-applikation som skapade dem. Rotation av API-autentiseringsuppgifter ändrar inte modellens tillhörighet, och andra applikationer kan inte fråga efter eller använda modellen.

## Använd modellen för att generera låtar

När modellstatusen är `ready`, fortsätt att anropa `POST /suno/custom-models` och ange `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id` måste vara en exklusiv musikmodell med statusen `ready` under den aktuella applikationen. Begäran misslyckas när modellen inte är tillgänglig och växlar inte automatiskt till en annan modell. `persona_id` och exklusiva musikmodeller är ömsesidigt uteslutande; om de skickas in samtidigt returnerar gränssnittet HTTP 400 innan begäran skickas till genereringstjänsten, och ingen avgift debiteras. Om du behöver använda Persona ska du i stället använda operationen `artist_consistency` eller `artist_consistency_vox` för `/suno/audios`.

Lyckad låtgenerering förbrukar **0.90 Credits**; misslyckad generering debiteras inte. Det är kostnadsfritt att fråga efter och arkivera modeller.

## Arkivera modell

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Den aktuella Beta-versionen arkiverar modellen och förhindrar fortsatt användning; `capacity_released=false` i svaret innebär att arkivering inte garanterar att modellkapacitet frigörs. Arkiveringsoperationen kan anropas upprepade gånger utan att debiteras flera gånger.
