Det exklusiva musikmodellen kan lära sig konsekventa musikfunktioner från 6 till 24 auktoriserade ljudfiler och användas för efterföljande låtskrivande. Skapandet är en asynkron operation; det rekommenderas att använda 24 stycken med enhetlig stil och klar ljudkvalitet för att få ett mer stabilt resultat.

> Endast ljudfiler som du har laglig användarrätt till, eller som du har fått auktorisation för modellskapande och efterföljande generering, får skickas in. Ladda inte upp musik eller ljudmaterial utan tillstånd.

## Skapa modell

Anropa `POST /suno/custom-models` och ställ in `action=create`:

```json
{
  "action": "create",
  "name": "Min Indie Modell",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

Gränssnittet returnerar omedelbart plattformens modell-ID och uppgifts-ID. När skapandet är klart kommer `status` i callback eller resultatfrågan att ändras till `ready`. Endast om modellen skapats framgångsrikt debiteras **10 Credits**; om skapandet misslyckas debiteras inga avgifter.

## Fråga modell

Fråga enskild modell:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Sida-fråga aktuella applikationsmodeller:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Alla modeller tillhör den Suno-applikation som skapade dem. API-referensernas rotation påverkar inte modellens tillhörighet, andra applikationer kan inte fråga eller använda den modellen.

## Använd modell för att generera låtar

När modellens status är `ready`, fortsätt att anropa `POST /suno/custom-models` och ställ in `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Vers]\nStadens ljus faller genom regnet",
  "style": "indie rock, varm analog synt"
}
```

`id` måste vara den aktuella applikationens exklusiva musikmodell med status `ready`. Om modellen inte är tillgänglig kommer begäran att misslyckas och det kommer inte automatiskt att bytas till en annan modell. Låtens generering kostar **0.90 Credits**; om genereringen misslyckas debiteras inga avgifter. Fråga och arkivering av modeller är gratis.

## Arkivera modell

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Den nuvarande beta-versionen kommer att arkivera modellen och förbjuda fortsatt användning, svaret med `capacity_released=false` indikerar att arkiveringen inte garanterar frigöring av modellkapacitet. Arkiveringsoperationen kan anropas flera gånger utan att debiteras flera gånger.
