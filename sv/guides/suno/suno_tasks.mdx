Suno Tasks API:s huvudsakliga funktion är att genom ett uppgifts-ID genererat av Suno Audios Generation API eller Suno Lyrics Generation API kunna fråga om uppgiftens utförandestatus.

Detta dokument kommer att detaljerat beskriva integrationen av Suno Tasks API för att hjälpa dig att enkelt integrera och fullt ut utnyttja API:ets kraftfulla funktioner. Med Suno Tasks API kan du enkelt fråga om utförandestatus för uppgifter från Suno Lyrics Generation API eller Suno Audios Generation API.

## Ansökningsprocess

För att använda Suno Audios Generation API, gå först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API-token som du kan spara för framtida bruk.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Om du inte är inloggad eller registrerad kommer du automatiskt att omdirigeras till inloggningssidan där du uppmanas att registrera dig och logga in, och efter det återvänder du automatiskt till den aktuella sidan.

**En API-token räcker för att anropa alla plattformens tjänster, du behöver inte ansöka separat för varje tjänst.** Vid första ansökan får du en gratis kvot för att prova; när kvoten är slut kan du ladda på allmän balans i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## Exempel på förfrågan

Suno Tasks API kan användas för att fråga resultat från både Suno Audios Generation API och Suno Lyrics Generation API. För hur man använder Suno Audios Generation API, se dokumentationen [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios-integration). För hur man använder Suno Lyrics Generation API, se [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics-generation-integration).

Vi tar ett uppgifts-ID från Suno Audios Generation API som exempel för att visa hur man använder detta API. Antag att vi har ett uppgifts-ID: eae26f89-b64b-404d-a80c-761996660b1c, nedan visas hur man skickar in detta ID.

### Ställ in förfrågningshuvuden och förfrågningskropp

**Request Headers** inkluderar:

- `accept`: anger att svaret ska vara i JSON-format, här anges `application/json`.
- `authorization`: API-nyckeln för att anropa API:et, kan väljas direkt efter ansökan.

**Request Body** inkluderar:

- `id`: det uppladdade uppgifts-ID:t.
- `action`: hur uppgiften ska hanteras.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/suno/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "eae26f89-b64b-404d-a80c-761996660b1c",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "eae26f89-b64b-404d-a80c-761996660b1c",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Resultatet innehåller flera fält, där `items` är en lista med detaljerad information om batchlåtarna, varje låt har samma fält som ovanstående enskilda uppgift.

- `items`, alla specifika detaljer om batchlåtarna. Det är en array, där varje element i arrayen har samma format som resultatet av att fråga en enskild uppgift.
- `count`, antalet batchfrågor om låtar.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/suno/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["eae26f89-b64b-404d-a80c-761996660b1c","0d3ed03b-912b-4f7d-941b-8441323cb77b"],
  "action": "retrieve_batch"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "ids": ["eae26f89-b64b-404d-a80c-761996660b1c","0d3ed03b-912b-4f7d-941b-8441323cb77b"],
    "action": "retrieve_batch"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Felhantering

Vid anrop av API:et, om ett fel uppstår, kommer API:et att returnera motsvarande felkod och meddelande. Till exempel:

- `400 token_mismatched`: Felaktig begäran, möjligtvis på grund av saknade eller ogiltiga parametrar.
- `400 api_not_implemented`: Felaktig begäran, möjligtvis på grund av saknade eller ogiltiga parametrar.
- `401 invalid_token`: Obefogad, ogiltig eller saknad auktoriseringstoken.
- `429 too_many_requests`: För många begärningar, du har överskridit hastighetsgränsen.
- `500 api_error`: Intern serverfel, något gick fel på servern.
