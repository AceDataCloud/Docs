Suno Tasks API:s huvudfunktion är att genom att ange det uppgifts-ID som genererats av Suno Audios Generation API eller Suno Lyrics Generation API, kunna fråga om statusen för den uppgiften.

Detta dokument kommer att detaljerat beskriva Suno Tasks API:s integrationsanvisningar, för att hjälpa dig att enkelt integrera och fullt utnyttja denna APIs kraftfulla funktioner. Genom Suno Tasks API kan du enkelt fråga om statusen för uppgifter från Suno Lyrics Generation API eller Suno Audios Generation API.

## Ansökningsprocess

För att använda Suno Tasks API måste du först gå till ansökningssidan [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) för att ansöka om den aktuella tjänsten, och sedan kopiera uppgifts-ID:t från Suno Audios Generation API, som visas i bilden:

<p><img src="https://cdn.acedata.cloud/bc6754.png" width="500" className="m-auto" /></p>

Slutligen går du till Tasks API-sidan [Suno Tasks API](https://platform.acedata.cloud/documents/b0dd9823-0e01-4c75-af83-5a6e2e05bfed) för att ansöka om den aktuella tjänsten, och när du kommer till sidan klickar du på knappen "Acquire", som visas i bilden:

![Ansökningssidan](https://cdn.acedata.cloud/rci31i.png)

Om du inte har loggat in eller registrerat dig kommer du automatiskt att omdirigeras till [inloggningssidan](https://platform.acedata.cloud) där du uppmanas att registrera dig och logga in. Efter att ha loggat in eller registrerat dig kommer du automatiskt att återvända till den aktuella sidan.

Vid första ansökan kommer det att finnas en gratis kvot som ges, så att du kan använda denna API gratis.

## Begärningsexempel

Suno Tasks API kan användas för att fråga om resultaten från både Suno Audios Generation API och Suno Lyrics Generation API. För information om hur man använder Suno Audios Generation API, se dokumentet [Suno Audios Generation API](https://platform.acedata.cloud/documents/d016ee3f-421b-4b6e-989a-8beba8701701). För information om hur man använder Suno Lyrics Generation API, se [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/f1c66741-a488-43ca-91fc-e53fbbda639a).

Vi tar ett exempel med ett uppgifts-ID som returnerats av Suno Audios Generation API för att demonstrera hur man använder denna API. Anta att vi har ett uppgifts-ID: eae26f89-b64b-404d-a80c-761996660b1c, och vi visar hur man gör detta genom att ange ett uppgifts-ID.

### Ställa in begärningshuvuden och begärningskropp

**Begärningshuvuden** inkluderar:

- `accept`: specificera att du tar emot svar i JSON-format, här anges som `application/json`.
- `authorization`: nyckeln för att anropa API:t, som kan väljas direkt efter ansökan.

**Begärningskropp** inkluderar:

- `id`: det uppladdade uppgifts-ID:t.
- `action`: åtgärden för uppgiften.

Några kodexempel är som följer:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/suno/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "eae26f89-b64b-404d-a80c-761996660b1c",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "eae26f89-b64b-404d-a80c-761996660b1c",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Felhantering

Vid anrop av API:et, om ett fel uppstår, kommer API:et att returnera motsvarande felkod och meddelande. Till exempel:

- `400 token_mismatched`: Felaktig begäran, troligen på grund av saknade eller ogiltiga parametrar.
- `400 api_not_implemented`: Felaktig begäran, troligen på grund av saknade eller ogiltiga parametrar.
- `401 invalid_token`: Obefogad, ogiltig eller saknad auktoriseringstoken.
- `429 too_many_requests`: För många förfrågningar, du har överskridit hastighetsgränsen.
- `500 api_error`: Intern serverfel, något gick fel på servern.
