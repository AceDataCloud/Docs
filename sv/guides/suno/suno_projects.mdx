Suno Studio-projektets API hanterar musikprojekt med flera spår via en enda ingång:

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

`action` i begäran avgör åtgärdstypen. Project-primärnyckeln använder konsekvent `id`; `version_id` representerar den aktuella projektversionen, och alla ändrings- och exportåtgärder måste skicka in den senaste versionen för att undvika samtidiga överskrivningar.

## Översikt över åtgärder

| action             | Läge  | Användning                      |
| ------------------ | --- | ----------------------- |
| `create`           | Synkront  | Skapa ett tomt projekt                   |
| `retrieve`         | Synkront  | Läs projektet och dess fullständiga redigerbara `state`      |
| `save`             | Synkront  | Spara det fullständiga projekttillståndet                |
| `upload`           | Asynkront  | Initiera material som kan läggas till i projektet från en HTTPS-ljudadress |
| `add_track`        | Asynkront  | Lägg till befintligt ljud i projektet               |
| `generate_track`   | Asynkront  | Generera nya spårkandidater för ett angivet intervall            |
| `replace_section`  | Asynkront  | Generera kandidater för lokal ersättning                |
| `commit_candidate` | Asynkront  | Bekräfta den valda kandidaten till projektet             |
| `remove_track`     | Synkront  | Ta bort angivet spår                  |
| `render`           | Asynkront  | Exportera en komplett låt från den sparade versionen           |

Asynkrona åtgärder returnerar omedelbart `task_id`. Använd det kostnadsfria gränssnittet `/suno/tasks` för polling, eller skicka in `callback_url` för att ta emot slutresultatet.

## Skapa och läsa

```json
{
  "action": "create",
  "title": "My Studio Project"
}
```

Alla ändringsåtgärder bör skicka en unik `Idempotency-Key` Header. Efter att skapandet lyckats är `data.id` i svaret Project ID.

```json
{"action":"retrieve","id":"PROJECT_ID"}
```

Lässvaret innehåller fullständig `state`. Det rekommenderas att först läsa, sedan ändra och spara baserat på returvärdet; konstruera inte interna takt- och spårstrukturer manuellt från grunden.

## Spara fullständigt tillstånd

```json
{
  "action":"save",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Edited Project",
  "state":{"tracks":[],"timing":{}}
}
```

Om versionen har ändrats returnerar gränssnittet HTTP 409. Utför då `retrieve` igen, slå samman ändringarna och skicka sedan in med en ny idempotensnyckel; försök inte blint igen med den gamla begäran.

## Ladda upp och lägga till spår

```json
{
  "action":"upload",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "audio_url":"https://cdn.example.com/reference.mp3",
  "async":true
}
```

När uppladdningen är klar returnerar uppgiftsresultatet kandidatens `audio_id`. Lägg sedan till den i projektet:

```json
{
  "action": "add_track",
  "id": "PROJECT_ID",
  "version_id": "CURRENT_VERSION_ID",
  "audio_id": "AUDIO_ID",
  "name": "Backing Vocals"
}
```

## Generering och ersättning

`generate_track` genererar spårkandidater för ett projektintervall; `replace_section` returnerar två kandidater för lokal ersättning. Ingen av åtgärderna väljer automatiskt det konstnärliga resultatet.

```json
{
  "action": "replace_section",
  "id": "PROJECT_ID",
  "version_id": "CURRENT_VERSION_ID",
  "source_audio_id": "AUDIO_ID",
  "start_seconds": 35.12,
  "end_seconds": 48.76,
  "model": "chirp-v6",
  "replacement_lyrics": "nya låttextfragment",
  "async": true
}
```

Bekräfta efter att du har valt en kandidat:

```json
{
  "action":"commit_candidate",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "operation_id":"OPERATION_ID",
  "candidate_id":"CANDIDATE_ID",
  "track_id":"TRACK_ID"
}
```

Kandidater är bundna till projektversionen vid genereringstillfället. Om projektet redan har ändrats kan gamla kandidater inte bekräftas direkt.

## Exportera komplett låt

```json
{
  "action":"render",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Final Mix",
  "lyrics":"[Instrumental]",
  "async":true,
  "callback_url":"https://example.com/webhooks/suno"
}
```

Servern läser det auktoritativa projekttillståndet för den angivna versionen och sammanställer exportparametrarna. Slutresultatet innehåller `render_id`, `audio_id`, `audio_url` och varaktighet. Projektet är bundet till exekveringsmiljön vid skapandet och kan inte migreras mellan miljöer eller automatiskt växla vid fel.

> Du får endast ladda upp eller behandla ljud som du har laglig användningsrätt till. Projekt-API:t är för närvarande i Beta; spara de slutliga ljud-URL:erna i viktiga resultat permanent.
