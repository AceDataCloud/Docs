Suno Studio-projektets API hanterar flerspåriga musikprojekt via en enda ingång:

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

`action` i begäran avgör operationstypen. Project-primärnyckeln använder konsekvent `id`; `version_id` representerar den aktuella projektversionen, och alla ändrings- och exportoperationer måste skicka den senaste versionen för att undvika samtidiga överskrivningar.

## Översikt över operationer

| action             | Läge  | Användning                      |
| ------------------ | --- | ----------------------- |
| `create`           | Synkront  | Skapa ett tomt projekt                   |
| `retrieve`         | Synkront  | Läs projektet och det fullständiga redigerbara `state`      |
| `save`             | Synkront  | Spara projektets fullständiga tillstånd                |
| `upload`           | Asynkront  | Initiera material som kan läggas till i projektet från en HTTPS-ljudadress |
| `add_track`        | Asynkront  | Lägg till befintligt ljud i projektet               |
| `generate_track`   | Asynkront  | Generera nya spårkandidater för ett angivet intervall            |
| `replace_section`  | Asynkront  | Generera kandidater för lokal ersättning                |
| `commit_candidate` | Asynkront  | Bekräfta den valda kandidaten i projektet             |
| `remove_track`     | Synkront  | Ta bort det angivna spåret                  |
| `render`           | Asynkront  | Exportera den sparade versionen som en komplett låt           |

Asynkrona operationer returnerar omedelbart `task_id`. Använd det kostnadsfria `/suno/tasks`-gränssnittet för polling, eller skicka `callback_url` för att ta emot resultat i sluttillståndet.

## Skapa och läsa

```json
{
  "action": "create",
  "title": "My Studio Project"
}
```

Alla ändringsoperationer bör skicka en unik `Idempotency-Key` Header. Efter lyckad skapelse är `data.id` i svaret Project ID. Ett nytt tomt projekt kanske saknar `version_id` före den första sparningen.

```json
{"action":"retrieve","id":"PROJECT_ID"}
```

Lässvaret innehåller det fullständiga `state`. Det rekommenderas att först läsa, sedan ändra och spara baserat på returvärdet; konstruera inte interna takt- och spårstrukturer manuellt från grunden.

## Spara fullständigt tillstånd

```json
{
  "action":"save",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Edited Project",
  "state":{"tracks":[],"timing":{}}
}
```

Vid den första sparningen av ett nytt tomt projekt kan `version_id` utelämnas; efter att den första sparningen har skapat en version måste efterföljande sparningar skicka det senaste värdet. Om versionen redan har ändrats returnerar gränssnittet HTTP 409. Kör då `retrieve` igen, slå samman ändringarna och skicka sedan med en ny idempotensnyckel; försök inte blint igen med den gamla begäran.

## Ladda upp och lägga till spår

```json
{
  "action":"upload",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "audio_url":"https://cdn.example.com/reference.mp3",
  "async":true
}
```

När uppladdningen är klar returnerar aktivitetsresultatet kandidatens `audio_id`. Lägg sedan till den i projektet:

```json
{
  "action": "add_track",
  "id": "PROJECT_ID",
  "version_id": "CURRENT_VERSION_ID",
  "audio_id": "AUDIO_ID",
  "name": "Backing Vocals"
}
```

## Generering och ersättning

`generate_track` genererar spårkandidater för ett projektintervall; `replace_section` returnerar två kandidater för lokal ersättning. Ingen av de två operationerna väljer automatiskt det konstnärliga resultatet.

```json
{
  "action": "replace_section",
  "id": "PROJECT_ID",
  "version_id": "CURRENT_VERSION_ID",
  "source_audio_id": "AUDIO_ID",
  "start_seconds": 35.12,
  "end_seconds": 48.76,
  "model": "chirp-v6",
  "replacement_lyrics": "nya låttextfragment",
  "async": true
}
```

Bekräfta efter att kandidaten har valts:

```json
{
  "action":"commit_candidate",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "operation_id":"OPERATION_ID",
  "candidate_id":"CANDIDATE_ID",
  "track_id":"TRACK_ID"
}
```

Kandidaten är bunden till projektversionen vid genereringstillfället. När projektet redan har ändrats kan gamla kandidater inte bekräftas direkt.

## Exportera komplett låt

```json
{
  "action":"render",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Final Mix",
  "lyrics":"[Instrumental]",
  "async":true,
  "callback_url":"https://example.com/webhooks/suno"
}
```

Servern läser det auktoritativa projektstatuset för den angivna versionen och sammanställer exportparametrarna. Resultatet i sluttillståndet innehåller `render_id`, `audio_id`, `audio_url` och längd. Projektet är bundet till körmiljön vid skapandet och kan inte migreras mellan miljöer eller växla över automatiskt vid fel.

> Du får endast ladda upp eller behandla ljud som du har laglig användningsrätt till. Projekt-API:t är för närvarande i Beta; persistenta slutliga ljud-URL:er i viktiga resultat.
