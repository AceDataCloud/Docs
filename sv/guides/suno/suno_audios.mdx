I takt med att AI:s tillämpningar blir mer utbredda har olika AI-program gradvis blivit vanliga. AI har gradvis trängt in i alla aspekter av människors arbetsliv. Och branscherna som AI berör blir allt fler, från den ursprungliga skrivandet, till medicinsk utbildning, och nu till musik.

Suno är en professionell högkvalitativ AI låt- och musikskapande plattform där användare bara behöver ange enkla textpromptar för att generera låtar med sång baserat på genre och stil. Denna AI musikgenerator har utvecklats av teammedlemmar från kända teknikföretag som Meta, TikTok, Kensho med målet att ingen instrumentverktyg behövs, så att alla kan skapa underbar musik.

Här är uppdateringen av modellens framsteg:

| Version | model           | Lanseringsdatum | prompt begränsning | stil begränsning | Längsta låt längd |
| ------- | --------------- | --------------- | ------------------ | ---------------- | ----------------- |
| v5      | chirp-v5       | 2025.09.23      | 5000               | 1000             | 8 minuter         |
| v4.5+   | chirp-v4-5-plus| 2025.07.17      | 5000               | 1000             | 8 minuter         |
| v4.5    | chirp-v4-5     | 2025.05.03      | 5000               | 1000             | 4 minuter         |
| v4      | chirp-v4       | 2024.12.17      | 3000               | 200              | 150 sekunder      |
| v3.5    | chirp-v3-5     | ---             | 3000               | 200              | 120 sekunder      |

Suno har nyligen uppgraderat musikgenereringsmodellen till V5-versionen, för att använda den senaste V5 behöver du bara ändra model-parametern till `chirp-v5`, vilket kan generera låtar på 9 minuter.

Men Suno erbjuder inte officiellt en API, AceDataCloud har tillhandahållit en uppsättning av Suno:s API, som simulerar integrationen med Suno officiellt, vilket gör det enkelt och snabbt att generera önskad musik.

## Ansökan och användning

För att använda Suno Audios API kan du först gå till [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) sidan och klicka på "Acquire" knappen för att få de nödvändiga autentiseringsuppgifterna:

![](https://cdn.acedata.cloud/nyq0xz.png)

Om du inte har loggat in eller registrerat dig kommer du automatiskt att omdirigeras till inloggningssidan för att registrera och logga in, efter inloggning kommer du automatiskt att återvända till den aktuella sidan.

Vid första ansökan kommer det att finnas en gratis kvot som ges, så att du kan använda API:n gratis.

## Grundläggande användning

Tänk på vilken låt du vill ha, du kan ange en text, till exempel om jag vill generera en låt om jul, kan jag skriva `a song for Christmas`, som visas i bilden:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

Här kan vi se att vi har ställt in Request Headers, inklusive:

- `accept`: vilken format av svar du vill ta emot, här anges som `application/json`, det vill säga JSON-format.
- `authorization`: nyckeln för att anropa API:n, efter ansökan kan du direkt välja från rullgardinsmenyn.

Dessutom har vi ställt in Request Body, inklusive:

- `action`: åtgärden för denna musikgenereringsuppgift, standard är `generate`, som huvudsakligen inkluderar: `extend`, `upload_extend`, `cover`, `upload_cover`, `replace_section`, `replace_section`, `concat`, `stems`, `all_stems`, `remaster`.
- `prompt`: Suno officiella inspirationsmodellens prompt.
- `model`: modellen för denna musikgenereringsuppgift, standard är `chirp-v3-5`, som huvudsakligen inkluderar: `chirp-v3`, `chirp-v4`, `chirp-v3-5`, `chirp-v4-5`, `chirp-v4-5-plus`, `chirp-v5`.
- `lyric`: Suno officiella anpassade modellens låttextinnehåll.
- `custom`: om den anpassade modellen ska användas, standard är: `false`.
- `instrumental`: Suno officiella inspirationsmodellens ren musikval.
- `title`: Suno officiella anpassade modellens musiktitel.
- `style`: Suno officiella anpassade modellens musikstil.
- `style_negative`: Suno officiella anpassade modellens uteslutna stil.
- `audio_weight`: andelen av den uppladdade referensmusiken, intervall 0-1, ju större, desto mer beroende av referensmusiken.
- `audio_id`: ID för referensmusiken.
- `overpainting_start`/`overpainting_end`: start- och sluttid för att lägga till sång på befintlig ren musik, enhet sekunder.
- `underpainting_start`/`underpainting_end`: start- och sluttid för att lägga till ackompanjemang på ren sång, enhet sekunder.
- `persona_id`: artistens låt-ID.
- `continue_at`: tiden i sekunder för att fortsätta med befintlig ljud. Till exempel, 213.5 betyder att fortsätta till 3 minuter 33.5 sekunder.
- `style_influence`: avancerad parameter för `style_influence`.
- `replace_section_end`: den slutliga tiden för att ersätta segmentet.
- `replace_section_start`: den starttid för att ersätta segmentet.
- `vocal_gender`: kontrollerar könet på rösten, kvinnlig röst `f`, manlig röst `m`, giltig för modeller 4.5 och högre.
- `weirdness`: avancerad parameter för `weirdness`.
- `lyric_prompt`: prompt för att generera låttext, endast när `custom` är `true` och `lyric` inte har skickats.
- `callback_url`: URL för att få tillbaka resultatet.

  - style: stil

## Anpassad generering

Om du vill anpassa genereringen av text kan du ange texten:

I det här fallet kan `lyric`-fältet ta emot liknande innehåll:

```
[Vers]\nSnöflingor faller överallt\nGlittrande vitt\nTäcker marken\nBarn skrattar\nFulla av glädje\nI detta vinterunderland ikväll\nJultomten släde\nUppe i himlen\nRudolfs näsa lyser klart\nÅh min\nHör jingle bells\nRinga så klart\nGer glädje och julstämning\n[Vers 2]\nRostande kastanjer vid eldens glöd\nJulbelysning\nDe blinkar och visar\nFamiljer samlas med kärlek och glädje\nSprider värme till alla nära
```

> Observera att här i texten är `\n` radbrytningstecken, om du inte vet hur du ska generera text kan du använda AceDataClouds textgenererings-API för att generera text genom prompt, API är [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Nästa steg är att baserat på text, titel och stil anpassa genereringen av låten, så kan du ange följande innehåll:

- lyric: textinnehåll
- custom: ange som `true`, vilket representerar anpassad generering, denna parameter är som standard `false`, vilket representerar att använda `prompt` för att generera.
- title: låtens titel.
- style: låtens stil, valfritt.

## Anpassad sångarstil genereringsfunktion
Om du vill använda sångarens stil för att generera en låt, börja först med att generera en låt med grundläggande användning som nämnts ovan. Slutligen behöver du ställa in denna låt till sångarens stil och gå till [Suno Persona API](https://platform.acedata.cloud/documents/suno-persona) för att generera en sångarstilens id-parameter `persona_id` baserat på det officiellt genererade musik-ID:t `audio_id`. De specifika parametrarna visas i bilden nedan:

<p><img src="https://cdn.acedata.cloud/pmzo3l.png" width="500" className="m-auto" /></p>

När du har fyllt i allt genereras automatiskt koden nedan:

<p><img src="https://cdn.acedata.cloud/a5g0nj.png" width="500" className="m-auto" /></p>

Motsvarande Python-kod:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "name": "test"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Fortsätt generera funktion

Om du vill fortsätta generera en redan skapad Suno-låt kan du ställa in parametern `action` till `extend`, och ange ID:t för den låt som ska fortsätta genereras. Låt-ID:t kan hämtas från grundläggande användning, och enligt ovan kan du se att låtens ID är:

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> Observera att här är `id` i texten ID:t för den genererade låten. Om du inte vet hur man genererar en låt kan du referera till ovanstående grundläggande användning för att generera en låt.

Om du vill fortsätta generera en låt som du har laddat upp kan du ställa in parametern `action` till `upload_extend`, och ange ID:t för den anpassade uppladdade låten som ska fortsätta genereras. Låt-ID:t kan hämtas med [Suno Upload Generation API](https://platform.acedata.cloud/documents/suno-upload), som visas i bilden nedan:

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" className="m-auto" /></p>

Därefter måste vi fylla i texten, stil och anpassad generering av låten, så vi kan specificera följande innehåll:

- lyric: texten
- custom: sätts till `true`, vilket representerar anpassad generering, denna parameter är som standard `false`, vilket representerar användning av `prompt` för att generera.
- style: låtens stil, valfritt.
- continue_at: tiden i sekunder för att fortsätta den befintliga ljudfilen. Till exempel, 213.5 betyder att fortsätta till 3 minuter 33.5 sekunder.

## Ersätta avsnitt

När man har genererat en låt och behöver göra en separat operation för att ersätta ett avsnitt av låten, kan man specificera följande innehåll för att ersätta ett avsnitt av låten:

- action: Innehållet är `replace_section`.
- audio_id: ID för den tidigare genererade låten.
- model: Låtens genereringsmodell,
- lyric: Den kompletta texten efter ersättningen (det räcker att den överensstämmer med prompten, fullständig text behövs inte),
- prompt: Den del av texten som behöver ersättas.
- style: Låtens stil, valfritt.
- replace_section_start: Starttiden för texten som motsvarar `lyric` på tidslinjen.
- replace_section_end: Sluttiden för texten som motsvarar `lyric` på tidslinjen.

## Lägg till instrumentalfunktion

I augusti 2025 lanserade suno den nya funktionen Lägg till instrumentalt, först måste du ladda upp en a cappella-låt utan bakgrundsmusik, så att suno kan hjälpa dig med musiken. Först kan du gå till [Suno Upload API](https://platform.acedata.cloud/documents/suno-upload) för att ladda upp en a cappella-låt utan bakgrundsmusik, motsvarande följande operationer visas i bilden nedan:

<p><img src="https://cdn.acedata.cloud/fxl914.png" width="500" className="m-auto" /></p>

Därefter behöver du registrera det uppladdade `audio_id`, det specifika resultatet visas i bilden nedan:

<p><img src="https://cdn.acedata.cloud/47t6wj.png" width="500" className="m-auto" /></p>

Slutligen fick vi ett `audio_id`: 92254cab-3372-4d9e-bce9-cdcfdbc39070, och vi behöver också fylla i följande parametrar:

- action: Innehållet är `underpainting`.
- underpainting_start: Starttiden för att lägga till ackompanjemang till den uppladdade låten, standardvärdet är 0.
- underpainting_end: Sluttiden för att lägga till ackompanjemang till den uppladdade låten, måste vara mindre än låtens totala längd.
- audio_id: ID för den uppladdade a cappella-låten.
- style: Stilen för ackompanjemanget, det är bäst att inte använda texter eftersom det är bakgrundsmusik.

## Remaster-funktion

- model: Stöder endast v4.5+, v5.

- action: Innehållet är `mashup`.
- mashup_audio_ids: ID för de två referenslåtarna.

## Asynkron återkoppling

Eftersom Suno tar relativt lång tid att generera musik, cirka 1-2 minuter, om API:et inte svarar under en längre tid, kommer HTTP-förfrågan att hålla anslutningen öppen, vilket leder till extra systemresursförbrukning, så detta API erbjuder också stöd för asynkron återkoppling.

Den övergripande processen är: när klienten initierar en begäran, specificerar den ett extra `callback_url`-fält, efter att klienten har initierat API-begäran kommer API:et omedelbart att returnera ett resultat som innehåller ett `task_id`-fält, vilket representerar det aktuella uppdragets ID. När uppdraget är slutfört kommer resultatet av den genererade musiken att skickas till klientens angivna `callback_url` i POST JSON-format, vilket också inkluderar `task_id`-fältet, så att uppdragsresultatet kan kopplas ihop med ID.

Låt oss förstå hur man gör detta genom ett exempel.

Först är Webhook-återkoppling en tjänst som kan ta emot HTTP-förfrågningar, utvecklaren bör ersätta med URL:en till sin egen byggda HTTP-server. Här för att underlätta demonstration använder vi en offentlig Webhook-exempelsida https://webhook.site/, öppna denna webbplats för att få en Webhook-URL, som visas i bilden:

![](https://cdn.acedata.cloud/fwfqin.png)
