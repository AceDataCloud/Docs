Om du vill använda texterna från två låtar för att generera en blandad låt kan du först använda detta API för att generera motsvarande texter. API:et är [Suno MashupLyrics Generation API](https://platform.acedata.cloud/documents/suno-mashup-lyrics).

Detta API:s huvudsakliga indata parametrar är `lyrics_a`, `lyrics_b`, exempel på ifyllnad visas nedan:

![](https://cdn.acedata.cloud/g9n3t6.png)

Klicka på kör, resultatet blir följande:

```
{
  "success": true,
  "task_id": "80aa3cd3-ca87-4ca3-82d2-1830e3d8f53a",
  "data": {
    "text": "Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nSambuy come, Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \nSambuy come back",
    "title": "Lyrics Mashup",
    "tags": [],
    "status": "complete"
  }
}
```

Som du kan se är `data` fältet `text` själva textinformationen.

När vi har texterna kan vi använda [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) för att generera anpassade låtar.
