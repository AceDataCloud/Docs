title: "Suno MP3 URL API Integrationsbeskrivning"

---

Suno MP3 URL API skapar en väg till ett spelbart ljud med slutet `.mp3` för befintlig musik, lämplig för scenarier där gamla nedladdningslänkar har slutat fungera, mobiluppspelning eller behovet av att återfå offentliga ljud-URL:er.

Obligatorisk parameter `audio_id` är ljud-ID:t som returneras av Suno ljudgenereringsgränssnittet. Varje anrop skapar en oberoende MP3 URL-uppgift, ändrar inte den ursprungliga musikgenereringsuppgiften och påverkar inte det ursprungliga ljud-ID:t.

## Synkront anrop

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={
        "accept": "application/json",
        "authorization": "Bearer <YOUR_API_TOKEN>",
        "content-type": "application/json"
    },
    json={"audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f"},
    timeout=240
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["file_url"])
```

Vid framgång är `data[0].file_url` den spelbara ljudadressen. Gränssnittet kommer först att försöka lagra den på `https://platform2.cdn.acedata.cloud/suno/{audio_id}.mp3`; om lagringen tar mer än 30 sekunder eller misslyckas, returneras den aktuella tillgängliga källljudadressen.

## Asynkront anrop

Vid längre behandlingstid kan `async: true` anges:

```python
submission = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={"authorization": "Bearer <YOUR_API_TOKEN>"},
    json={
        "audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f",
        "async": True
    }
).json()

export_task_id = submission["task_id"]
```

Därefter kan du fråga `export_task_id` via `/suno/tasks`. Du kan också ange `callback_url` för att ta emot det slutliga resultatet när uppgiften är klar. Synkrona svar, uppgiftsfrågor och återkoppling använder samma slutliga databasstruktur.

## Viktiga punkter

- `audio_id` måste komma från ett identifierbart Suno-ljud.
- MP3 URL-uppgifter är oberoende av den ursprungliga musikgenereringsuppgiften.
- Lagring får vänta högst 30 sekunder; lagringstidsgräns eller misslyckande blockerar inte resultatet, utan återgår till källljudadressen.
- Det rekommenderas att affärssidan laddar ner resultatet i tid och sparar det enligt sin egen datalagringspolicy.
