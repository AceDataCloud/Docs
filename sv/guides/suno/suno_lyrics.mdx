Om du vill anpassa låtar men inte riktigt vill skriva låttexter själv, kan du använda AceDataClouds låttextgenererings-API för att generera låttexter via prompt. API:et är [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/514d82dc-f7ab-4638-9f21-8b9275916b08).

Den huvudsakliga inparametern för detta API är `prompt`, valfri `model` (standard chirp-v3), exempel på ifyllning nedan:

![](https://cdn.acedata.cloud/p53wtj.png)

Här är vår inmatade `prompt` `A song about winter`, vilket genererar en låt relaterad till vintern.

Klicka på kör, resultatet blir följande:

```
{
  "success": true,
  "task_id": "57e8ce3a-39cb-41a2-802f-e70a324f4d0a",
  "data": {
    "text": "[Vers]\nSnöflingor faller från himlen\nVinterns kalla beröring\nÅh hur det får mig att må bra\nJag klär mig i lager\nÅh så mysigt\nStegar ut och känner frosten på min näsa\nSe\n\n[Vers 2]\nVärlden är täckt av ett vitt täcke\nIstappar hänger\nGlittrar så klart\nDen kalla luften fyller mina lungor med varje andetag\nGår i snön\nLämnar fotspår som inte kommer att försvinna\n\n[Refräng]\nÅh\nVinterns kalla beröring\nDet är en säsong som jag älskar så mycket\nSnöfall ger en känsla så gudomlig\nVinterns kalla beröring\nDet är en magisk tid",
    "title": "Vinterns Kalla Beröring",
    "status": "complete"
  }
}
```

Som vi kan se, är `data` fältet `text` låttextinformationen.

Med låttexten kan vi sedan använda [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) för att generera anpassade låtar.
