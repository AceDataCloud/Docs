title: "Instruktioner för integrering av Suno API för textgenerering"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Om du vill anpassa genereringen av låtar, men inte riktigt vill skriva låttexter själv, kan du använda API:et för textgenerering som tillhandahålls av AceDataCloud för att generera låttexter via prompt. API:et är [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Prissättning: Efter en lyckad generering är standardavgiften för varje begäran **0.08 Credits**. När en begäran returnerar flera textkandidater debiteras den fortfarande endast som en begäran; tillämpliga förbrukningsrabatter baseras på den faktiska fakturan, misslyckade begäranden debiteras inte.

De huvudsakliga inmatningsparametrarna för detta API är `prompt`, med valfritt `model` (möjliga värden `default`, `remi-v1`, standardvärdet är `default`). Ett ifyllnadsexempel är följande:

![](https://cdn.acedata.cloud/p53wtj.png)

Här är den `prompt` vi matar in `A song about winter`, för att generera en låt relaterad till vintern.

Klicka på kör, resultatet är följande:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nSnowflakes falling from the sky\nWinter's cold touch\nOh how it gets me high\nI bundle up in layers\nOh so cozy\nStepping out and feeling the frost on my nose\n\n[Chorus]\nOh\nWinter's cold touch\nIt's a season that I love so much\nSnowfall brings a feeling so divine\nWinter's cold touch\nIt's a magical time",
      "title": "Winter's Cold Touch",
      "status": "complete",
      "tags": [
        "dreamy, mellow, ballad"
      ]
    },
    {
      "text": "[Verse]\nThe world is covered in a blanket of white\nIcicles hanging\nShimmering so bright\nThe chilly air fills my lungs with every breath\nWalking in the snow\nLeaving footprints behind\n\n[Chorus]\nWinter wonderland\nEverything is so bright\nWinter wonderland\nHold me through the night",
      "title": "Winter Wonderland",
      "status": "complete",
      "tags": [
        "dream pop, mellow, shoegaze"
      ]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,
  "elapsed": 7.433
}
```

Det går att se att `data` är en array, och flera textkandidater returneras varje gång. Fältet `text` i varje element är textinnehållet, `title` är titeln och `tags` är rekommenderade taggar för musikstil.

När vi har fått låttexten kan vi använda [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) för att generera anpassade låtar.
