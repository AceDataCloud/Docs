Om du vill anpassa genereringen av låtar, men inte riktigt vill skriva låttexter själv, kan du använda AceDataClouds låttextgenererings-API för att generera låttexter via prompt. API:et är [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Den huvudsakliga inparametern för API:et är `prompt`, valfri `model` (valfria värden `default`, `remi-v1`, standard `default`), exempel på ifyllning nedan:

![](https://cdn.acedata.cloud/p53wtj.png)

Här är vår inmatade `prompt` `A song about winter`, som genererar låtar relaterade till vintern.

Klicka på kör, resultatet blir följande:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Vers]\nSnöflingor faller från himlen\nVinterns kalla beröring\nÅh hur det får mig att må bra\nJag klär mig i lager\nÅh så mysigt\nStegar ut och känner frosten på min näsa\n\n[Refräng]\nÅh\nVinterns kalla beröring\nDet är en säsong som jag älskar så mycket\nSnöfall ger en känsla så gudomlig\nVinterns kalla beröring\nDet är en magisk tid",
      "title": "Vinterns Kalla Beröring",
      "status": "complete",
      "tags": [
        "drömmande, mjuk, ballad"
      ]
    },
    {
      "text": "[Vers]\nVärlden är täckt av ett vitt täcke\nIstappar hänger\nGlittrar så klart\nDen kalla luften fyller mina lungor med varje andetag\nGår i snön\nLämnar fotspår bakom mig\n\n[Refräng]\nVinterland\nAllt är så ljust\nVinterland\nHåll mig genom natten",
      "title": "Vinterland",
      "status": "complete",
      "tags": [
        "dröm pop, mjuk, shoegaze"
      ]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,
  "elapsed": 7.433
}
```

Som vi kan se är `data` en array, som varje gång returnerar flera låttextkandidater, där varje elements `text`-fält är låttextinnehållet, `title` är titeln, `tags` är rekommenderade musikstilar.

Med låttexterna kan vi sedan använda [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) för att generera anpassade låtar.
