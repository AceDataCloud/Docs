SUNO låter oss skapa anpassade röstkaraktärer från valfri ljudfil för att möjliggöra röstkloning vid musikgenerering. Till skillnad från den befintliga Persona API:n (som använder Suno-genererade `audio_id`), accepterar denna API en offentligt tillgänglig `audio_url`, det vill säga din egen röstinspelning. Denna dokumentation förklarar hur man integrerar röstkloning API:n.

## Steg 1: Skapa en röstkaraktär

API:n har tre inmatningsparametrar: `audio_url` (obligatorisk), som är en offentligt tillgänglig URL till en MP3- eller WAV-ljudfil med en tydlig enskild röst; `name` och `description` (valfria), som är namn och beskrivning för röstkaraktären.

**Krav på ljudfilen:**
- Format: MP3 eller WAV
- Längd: minst 10 sekunder
- Innehåll: en tydlig enskild röst, minimalt med bakgrundsljud eller musik

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

Resultatet blir:

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

Som du kan se är `persona_id` i `data` fältet ID:t för den skapade röstkaraktären. Fältet `is_public` är alltid `false` eftersom röstkaraktärer skapade via uppladdad ljudfil är privata.

## Steg 2: Använd röstkaraktären för musikgenerering

När du har röstkaraktärens ID kan du använda [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) för att generera musik. Sätt `action` till `generate` och `persona_id` till det röstkaraktärs-ID som returnerades ovan. Den genererade låten kommer att sjungas med den klonade rösten.

> **Observera:** Röstkloning stöds endast för modeller `chirp-v4-5` och senare (t.ex. `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), inte för `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

Resultatet blir:

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

Som du kan se sjungs den genererade låten med den klonade rösten. `persona_id` kan också användas tillsammans med `cover`-åtgärden för att göra covers av befintliga låtar med den klonade rösten.
