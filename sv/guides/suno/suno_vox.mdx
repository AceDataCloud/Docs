SUNO tillåter oss att skapa en ny version av Persona-v2-vox: sångarstilen, som skiljer sig från den gamla versionen och kräver att vi först får `vox_audio_id`. Detta dokument förklarar hur man integrerar den nya versionen av Persona-v2-vox.

Först behöver vi denna API för att hämta värdet för parametern `vox_audio_id`, denna API kan ta flera inmatningsparametrar, såsom `audio_id`, `vocal_start`, `vocal_end`, som refererar till låtens ID och det valda tidsintervallet.

Här är vårt inmatade `audio_id`: `42599b24-fb14-4cd3-a444-e15ffde3661b`.

```python
import requests

url = "https://api.acedata.cloud/suno/vox"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Vi kan se att `data` fältet `id` är det `vox_audio_id` vi vill ha, och sedan går vi till [Persona API](https://platform.acedata.cloud/documents/suno-persona) för att skapa den nya versionen av Persona-v2-vox: sångarstilen, med följande inmatning:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "test",
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20,
    "vox_audio_id": "24f0827e-5847-4011-b9b7-fc0b62032b65"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Efter anropet får vi följande resultat:

```json
{
  "success": true,
  "task_id": "e04b06a1-ff61-48e2-9fcc-15284bd18481",
  "data": {
    "persona_id": "49bef16d-6a09-49d1-8c24-a81663698b98"
  }
}
```

Sedan kan vi använda värdet av `persona_id` ovan för att skapa den nya versionen av Persona-v2-vox: sångarstilen, och metoden för skapande är densamma som i [Suno låtgenerering API integrationsbeskrivning](https://platform.acedata.cloud/documents/suno-audios-integration#%E8%87%AA%E5%AE%9A%E4%B9%89%E6%AD%8C%E6%89%8B%E9%A3%8E%E6%A0%BC%E7%94%9F%E6%88%90%E5%8A%9F%E8%83%BD), och slutligen kan vi använda Suno Vox API för att skapa låtar i den nya versionen av Persona-v2-vox: sångarstilen.
