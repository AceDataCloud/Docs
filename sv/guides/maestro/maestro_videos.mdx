Maestro är ett **Agent-nativt** videoproduktionsgränssnitt: du använder en naturlig språklig `prompt` för att beskriva videon du vill ha (och kan valfritt bifoga referensbilder / videor / ljud med `file_urls`), så kommer en huvudlös ”AI-regissör” automatiskt att slutföra ämnesval, manusförfattande, bildgenerering, röstpålägg, bakgrundsmusik, sammansättning och rendering, och slutligen producera en färdig video med undertexter och ladda upp den till CDN.

Detta dokument introducerar integrationsguiden för Maestro API för videogenerering i detalj, för att hjälpa dig att snabbt integrera och fullt ut använda API:ets möjligheter.

Detta är ett **asynkront uppgifts**-gränssnitt: efter inskickning returneras `task_id` omedelbart, och resultatet hämtas sedan genom polling via [Maestro API för uppgiftsfrågor](/sv/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (polling är gratis och debiteras inte). För att fortsätta iterera på en befintlig video kan du använda `action: remix` / `edit` / `extend` tillsammans med `ref_task_id`.

## Ansökningsprocess

För att använda Maestro API för videogenerering ska du först hämta din API-token i [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) och spara den för senare användning.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig omdirigeras du automatiskt till inloggningssidan där du uppmanas att registrera dig och logga in. När detta är klart återgår du automatiskt till den aktuella sidan.

**En API-token kan anropa alla plattformens tjänster, utan att du behöver ansöka separat för varje tjänst.** Vid första ansökan får du gratis kredit för att testa utan kostnad; om krediten inte räcker till kan du fylla på det gemensamma saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Maestro API för videogenerering →](https://platform.acedata.cloud/documents/maestro-videos)

## Grundläggande användning

`POST https://api.acedata.cloud/maestro/videos`

Den mest grundläggande användningen kräver endast att du skickar in en naturlig språklig `prompt`; AI-regissören avgör automatiskt manus, bild, röstpålägg och redigering. Här går vi först igenom de begärandehuvuden och den begärandetext som behöver anges.

**Request Headers** omfattar:

- `accept`: vilket format du vill ta emot svar i; fyll här i `application/json`, det vill säga JSON-format.
- `authorization`: nyckeln för att anropa API:et, som kan väljas direkt i rullgardinsmenyn efter ansökan.
- `content-type`: formatet för begärandetexten; fyll här i `application/json`.

**Request Body** omfattar huvudsakligen:

- `prompt`: beskriv videon som ska skapas med naturligt språk (tema, vad som ska visas, stil, målgrupp).
- `langs`: array med språk för den färdiga videon; skicka endast ett språk varje gång, exempelvis `["zh-cn"]`; standardvärdet är `["zh-cn"]`.
- `aspect`: bildförhållande, `9:16` (standard) / `16:9` / `1:1`.
- `duration`: mållängd (sekunder), standardvärdet är 30.

Alla fält i begärandetexten visas i tabellen nedan:

| Fält            | Typ       | Obligatoriskt  | Beskrivning                                                                                                                                                                                                                                    |
| ------------- | -------- | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Ja   | Beskriv videon som ska skapas med naturligt språk (tema, vad som ska visas, stil, målgrupp). Manus, bild, röstpålägg och redigering avgörs alla av AI                                                                                                                                                                                      |
| `action`      | string   | Nej   | `generate` (standard, generera ny video) / `remix` / `edit` / `extend` (iterera på en befintlig video, måste användas tillsammans med `ref_task_id`)                                                                                                                                                         |
| `ref_task_id` | string   | Nej   | Obligatoriskt när `action` är remix / edit / extend: den historiska uppgiftens `task_id` som används som utgångspunkt                                                                                                                                                                            |
| `file_urls`   | string[] | Nej   | Referensmedia (bild / video / ljud-URL), exempelvis produktbilden eller logotypen som ska visas, eller materialklippet som ska få undertexter                                                                                                                                                                                      |
| `langs`       | string[] | Nej   | Språk för den färdiga videon; endast ett språk kan skickas varje gång, exempelvis `["zh-cn"]`; standardvärdet är `["zh-cn"]`                                                                                                                                                                                             |
| `aspect`      | string   | Nej   | `9:16` (standard) / `16:9` / `1:1`, enhetlig utmatning i 1080p/30fps                                                                                                                                                                                           |
| `duration`    | int      | Nej   | Mållängd (sekunder), standardvärdet är 30, stöder **5–300 sekunder**. Debiteras enligt den faktiska längden på den färdiga videon, men överstiger inte den begärda längden                                                                                                                                                                                      |
| `scenario`    | string   | Nej   | Videotyp: `auto` / `narrated` / `captions` / `avatar` / `drama`. `captions` kräver en källvideo, och `avatar` kräver ett porträtt                                                                                                                                             |
| `style`       | string   | Nej   | Förinställning för visuell stil: `auto` (standard) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`; accepterar även fri text som mjuk instruktion. Är ortogonal mot `scenario` och ändrar inte routningen          |
| `voice`       | string   | Nej   | Röst för berättarröst (oberoende av språk, fungerar mellan språk): `auto` (standard) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`; stöder även 32-bitars hexadecimalt röst-`reference_id`; annan fri text är inte ett giltigt röst-ID |

Nedan demonstreras detta med ett konkret exempel. Anta att vi vill generera en kinesisk, vertikal, 20 sekunder lång populärvetenskaplig kortvideo. Motsvarande CURL-kod är följande:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

Motsvarande Python-kod är följande:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Klicka på kör för att se att du omedelbart får ett resultat enligt följande:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Fälten i returresultatet introduceras enligt följande:
- `success`：om denna uppgift har skickats in framgångsrikt.
- `task_id`：ID för denna videogenereringsuppgift, använd det senare för att polla resultaten via [Maestro API för uppgiftsfrågor](/sv/guides/maestro/maestro_tasks).
- `trace_id`：spårnings-ID för denna begäran, som kan tillhandahållas till teknisk support för felsökning om problem uppstår.

Eftersom videoproduktion tar relativt lång tid returnerar gränssnittet här **omedelbart `task_id`**, och väntar inte tills videorenderingen är klar. Därefter behöver du använda `task_id` för att polla resultaten, se avsnittet ”Hämta resultat”.

## Ange videotyp och stil (scenario / style)

När `scenario` inte skickas avgör AI automatiskt (motsvarar `auto`); om du vill låsa videon till en viss typ skickar du det explicit. Till exempel kan du ange följande innehåll för att skapa ett **vertikalt kortdrama**:

- `scenario`：videotyp, anges här som `drama` (kortdrama med karaktärer + dialog).
- `style`：visuell stil, anges här som `cinematic` (filmisk känsla).

Exempel på ifylld CURL-kod är följande:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Vanliga kombinationer:

- Berättande kortfilm：`scenario: "narrated"`。
- Automatiska undertexter：`scenario: "captions"`，källvideon måste skickas med `file_urls`。
- Digital människa / talvideo：`scenario: "avatar"`，ett porträttfoto måste skickas med `file_urls`。
- Kortdrama：`scenario: "drama"`（karaktärer + dialog）。
- `style` är en förinställning för visuell stil（t.ex. `modern` / `neon` / `luxury`），ändrar inte typen utan påverkar endast intrycket。
- `voice` används för att ange berättarröstens klangfärg（t.ex. `warm-female` / `deep-male`），är oberoende av språk och fungerar mellan språk。

Returresultatet är detsamma som i ”Grundläggande användning”, och `task_id` returneras också omedelbart.

## Språk för färdig video

En uppgift levererar endast en färdig video på ett språk. `langs` får endast innehålla en språkkod, till exempel `["zh-cn"]` eller `["en"]`; om flera språk skickas returneras 400. Om du behöver videor på olika språk ska du skapa separata uppgifter. Språkvalet ändrar inte priset per sekund.

## Iterera på befintlig video (remix / edit / extend)

Skicka in `action` och `ref_task_id` från den föregående uppgiften för att göra inkrementella ändringar baserat på originalprojektet (t.ex. ”ändra titeln i scen 2”, ”byt röst”, ”gör helheten mörkare”). Små ändringar går snabbt, medan stora ändringar görs om:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`：nytolkning baserad på originalvideons struktur（behåller temat och justerar uttrycket）。
- `edit`：finjustering av angivna delar（t.ex. byt titel, byt röst, färgkorrigering）。
- `extend`：utökar innehållet baserat på originalvideon。

Returresultatet är också att ett nytt `task_id` returneras omedelbart, använd det för polling för att hämta den itererade färdiga videon.

## Hämta resultat

Eftersom videoproduktion tar relativt lång tid returnerar detta gränssnitt `task_id` omedelbart efter inskickning, och du behöver använda det för att polla resultaten via [Maestro API för uppgiftsfrågor](/sv/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

När uppgiften är klar returneras information om en färdig video (i arrayen `variants`). `status` går igenom `pending → planning → producing → succeeded` (eller `failed`), **polling är gratis och förbrukar inga poäng**. Se [Integrationsguide för Maestro API för uppgiftsfrågor](/sv/guides/maestro/maestro_tasks) för det fullständiga svarsformatet och frågor om historiklistor.

## Fakturering

**Efter att uppgiften har lyckats debiteras den faktiska längden på den levererade färdiga videon, och misslyckanden debiteras inte.** Faktureringstiden beräknas i hela sekunder och överstiger inte den begärda längden; om längden på den färdiga videon inte kan läsas används den begärda längden som reserv. Att skicka in själva uppgiften debiteras inte separat, och polling via `/maestro/tasks` är gratis.

```
Poäng = faktiska debiterbara sekunder × 0.7
```

Alla scenarier, åtgärder och språk använder samma pris, utan scenariomultiplikator eller språkpåslag. Varje uppgift levererar endast en färdig video på ett språk. Begärd mållängd stöder 5–300 sekunder, med enhetlig utdata i 1080p / 30fps.

| Faktisk debiterbar längd              | Poäng |
| ------------------- | --: |
| 30 sekunder                |  21 |
| 60 sekunder                |  42 |
| 120 sekunder               |  84 |
| 300 sekunder               | 210 |
| Polling via `/maestro/tasks` | Gratis |

## Felhantering

Vid anrop av API:et returnerar API:et motsvarande felkod och information om ett fel uppstår. Till exempel:

- `400 invalid_request`：Felaktig begäran, eventuellt på grund av en saknad `prompt` eller ogiltiga parametrar.
- `401 invalid_token`：Obehörig, ogiltig eller saknad auktoriseringstoken.
- `403 forbidden`：Förbjuden, otillräckligt saldo eller otillräcklig åtkomst.
- `429 too_many_requests`：För många begäranden, du har överskridit hastighetsgränsen.
- `500 api_error`：Internt serverfel, något gick fel på servern.

### Exempel på felsvar

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
