Maestro är ett **Agent-nativt** videoproduktionsgränssnitt: du beskriver videon du vill ha med en naturlig språk-`prompt` (och bifogar valfritt referensbilder / videor / ljud med `file_urls`), så slutför en huvudlös ”AI-regissör” automatiskt ämnesval, manusskrivning, bildgenerering, röstpålägg, musik, sammansättning och rendering, och producerar slutligen en färdig video med undertexter samt laddar upp den till CDN.

Den här artikeln introducerar integrationsguiden för Maestro API för videogenerering i detalj, för att hjälpa dig att snabbt integrera och fullt ut använda API:ets funktioner.

Detta är ett **asynkront uppgifts**-gränssnitt: efter inskick returneras `task_id` omedelbart, och resultatet hämtas sedan genom polling via [Maestro API för uppgiftsfrågor](/sv/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (polling är gratis och debiteras inte). För att fortsätta iterera på en befintlig video kan du använda `action: remix` / `edit` / `extend` tillsammans med `ref_task_id`.

## Ansökningsprocess

För att använda Maestro API för videogenerering går du först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API Token och behåller den som reserv.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig omdirigeras du automatiskt till inloggningssidan där du uppmanas att registrera dig och logga in, och återvänder automatiskt till den aktuella sidan efter slutförandet.

**En API Token kan anropa alla plattformstjänster, och du behöver inte ansöka separat för varje tjänst.** Vid första ansökan får du kostnadsfri kvot och kan prova gratis; när kvoten är otillräcklig kan du fylla på det gemensamma saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Maestro API för videogenerering →](https://platform.acedata.cloud/documents/maestro-videos)

## Grundläggande användning

`POST https://api.acedata.cloud/maestro/videos`

Den mest grundläggande användningen kräver bara att du skickar in en naturlig språk-`prompt`, och AI-regissören avgör automatiskt manus, bilder, röstpålägg och klippning. Här går vi först igenom de request headers och request body som behöver ställas in.

**Request Headers** omfattar:

- `accept`: vilket format du vill ta emot svarsresultatet i, här anges `application/json`, alltså JSON-format.
- `authorization`: nyckeln för att anropa API:et, som kan väljas direkt från rullgardinsmenyn efter ansökan.
- `content-type`: formatet för request body, här anges `application/json`.

**Request Body** omfattar huvudsakligen:

- `prompt`: beskriv videon som ska skapas med naturligt språk (ämne, vad som ska visas, stil, målgrupp).
- `langs`: array med språk för den färdiga videon, endast ett språk skickas varje gång, till exempel `["zh-cn"]`, standard är `["zh-cn"]`.
- `aspect`: bildförhållande, `9:16` (standard) / `16:9` / `1:1`.
- `duration`: mållängd (sekunder), standard är 30.

Alla fält i request body visas i tabellen nedan:

| Fält            | Typ       | Obligatoriskt  | Beskrivning                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Ja   | Beskriv videon som ska skapas med naturligt språk (ämne, vad som ska visas, stil, målgrupp). Manus, bilder, röstpålägg och klippning avgörs alla av AI                                                                                                                                                                             |
| `action`      | string   | Nej   | `generate` (standard, generera ny video) / `remix` / `edit` / `extend` (iterera på en befintlig video, måste användas tillsammans med `ref_task_id`)                                                                                                                                                |
| `ref_task_id` | string   | Nej   | Obligatoriskt när `action` är remix / edit / extend: den historiska uppgiftens `task_id` som används som utgångspunkt                                                                                                                                                                   |
| `file_urls`   | string[] | Nej   | Referensmedia (bild / video / ljud-URL), till exempel produktbilden eller logotypen som ska synas, eller materialsegmentet som ska förses med undertexter                                                                                                                                                                             |
| `langs`       | string[] | Nej   | Språk för den färdiga videon, endast ett språk kan skickas varje gång, till exempel `["zh-cn"]`, standard är `["zh-cn"]`                                                                                                                                                                                    |
| `aspect`      | string   | Nej   | `9:16` (standard) / `16:9` / `1:1`, enhetlig utdata i 1080p/30fps                                                                                                                                                                                  |
| `duration`    | int      | Nej   | Mållängd (sekunder), standard är 30, stöder **5–300 sekunder**. Debiteras efter den faktiska längden på den färdiga videon, men överskrider inte den begärda längden                                                                                                                                                                             |
| `scenario`    | string   | Nej   | Videotyp: `auto` / `narrated` / `captions` / `avatar` / `drama`. `captions` kräver en källvideo, `avatar` kräver ett porträtt                                                                                                                                    |
| `style`       | string   | Nej   | Förinställning för visuell stil: `auto` (standard) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`, accepterar även fri text som mjuk prompt. Är ortogonal mot `scenario` och ändrar inte routning |
| `voice`       | string   | Nej   | Röst för berättarröst (oberoende av språk, fungerar mellan språk): `auto` (standard) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`                                    |

Nedan demonstreras detta med ett konkret exempel. Anta att vi vill generera en kinesisk, vertikal, 20 sekunder lång populärvetenskaplig kortvideo. Motsvarande CURL-kod är följande:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

Motsvarande Python-kod är följande:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Klicka på kör så ser du att ett resultat returneras omedelbart, enligt följande:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Fälten i svarsresultatet beskrivs enligt följande:
- `success`: om den här uppgiften har skickats in framgångsrikt.
- `task_id`: ID för den här videogenereringsuppgiften, använd det senare för att polla resultatet via [Maestro API för uppgiftsfrågor](/sv/guides/maestro/maestro_tasks).
- `trace_id`: spårnings-ID för denna begäran, som kan tillhandahållas till teknisk support för felsökning vid problem.

Eftersom videoproduktion tar lång tid returnerar gränssnittet **omedelbart `task_id`** här och väntar inte på att videorenderingen ska slutföras. Därefter behöver du använda `task_id` för att polla resultatet, se avsnittet ”Hämta resultat”.

## Ange videotyper och stilar (scenario / style)

När `scenario` inte skickas avgör AI automatiskt detta (motsvarar `auto`); om du vill låsa videon till en viss typ skickar du den uttryckligen. Om du till exempel skapar ett **kort drama i stående format**, kan du ange följande:

- `scenario`: videotyper, här anges `drama` (kort drama med roller + dialog).
- `style`: visuell stil, här anges `cinematic` (filmisk känsla).

CURL-koden för ifyllningsexemplet är följande:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Vanliga kombinationer:

- Berättande kortfilm: `scenario: "narrated"`.
- Automatiska undertexter: `scenario: "captions"`, använd `file_urls` för att skicka källvideon.
- Digital människa / muntlig presentation: `scenario: "avatar"`, använd `file_urls` för att skicka ett porträttfoto.
- Kort drama: `scenario: "drama"` (roller + dialog).
- `style` är en förinställning för visuell stil (som `modern` / `neon` / `luxury`), ändrar inte typen utan påverkar endast upplevelsen.
- `voice` används för att ange berättarröstens klangfärg (som `warm-female` / `deep-male`), oberoende av språk och allmänt användbar över språkgränser.

Returresultatet är detsamma som i ”Grundläggande användning”, och returnerar också `task_id` omedelbart.

## Språk för den färdiga videon

En uppgift levererar endast en färdig video på ett språk. `langs` får endast innehålla en språkkod, till exempel `["zh-cn"]` eller `["en"]`; om flera språk skickas returneras 400. Om du behöver videor på olika språk ska du skapa uppgifter separat. Språkvalet ändrar inte priset per sekund.

## Iterera på befintliga videor (remix / edit / extend)

Genom att skicka `action` och `ref_task_id` från den föregående uppgiften kan du göra inkrementella ändringar baserat på originalprojektet (till exempel ”ändra titeln i scen 2”, ”byt berättarröst”, ”gör helheten mörkare”). Små ändringar går snabbt, stora ändringar görs om:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: tolka om utifrån den ursprungliga videostrukturen (behåll temat, justera uttrycket).
- `edit`: finjustera angivna delar (som att byta titel, byta berättarröst eller färgkorrigera).
- `extend`: utöka innehållet baserat på den ursprungliga videon.

Returresultatet returnerar också omedelbart ett nytt `task_id`, använd det för polling för att hämta den itererade färdiga videon.

## Hämta resultat

Eftersom videoproduktion tar lång tid returnerar detta gränssnitt `task_id` omedelbart efter inskickning, och du behöver använda det för att polla resultatet via [Maestro API för uppgiftsfrågor](/sv/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

När uppgiften är slutförd returneras information om en färdig video (i arrayen `variants`). `status` genomgår `pending → planning → producing → succeeded` (eller `failed`), **polling är gratis och förbrukar inga poäng**. För fullständigt svarsformat och frågning av historiklistor, se [Integrationsbeskrivning för Maestro API för uppgiftsfrågor](/sv/guides/maestro/maestro_tasks).

## Debitering

**Efter att uppgiften har lyckats debiteras enligt den faktiskt levererade färdiga videons längd, och misslyckanden debiteras inte.** Debiteringslängden beräknas i hela sekunder och överstiger inte den begärda längden; när längden på den färdiga videon inte kan läsas används den begärda längden som reserv. Att skicka in en uppgift debiteras inte separat, och polling via `/maestro/tasks` är gratis.

```
Poäng = faktiskt debiterade sekunder × 0.7
```

Alla scenarier, åtgärder och språk använder samma pris, utan scenariomultiplikator eller språktillägg. Varje uppgift levererar endast en färdig video på ett språk. Begärd mållängd stöder 5–300 sekunder, med enhetlig utmatning i 1080p / 30fps.

| Faktisk debiteringslängd     | Poäng |
| ---------------------------- | ----: |
| 30 sekunder                  |    21 |
| 60 sekunder                  |    42 |
| 120 sekunder                 |    84 |
| 300 sekunder                 |   210 |
| `/maestro/tasks`-polling     | gratis |

## Felhantering

Vid anrop av API:t returnerar API:t motsvarande felkod och information om ett fel uppstår. Till exempel:

- `400 invalid_request`: Felaktig begäran, möjligen på grund av en saknad `prompt` eller ogiltiga parametrar.
- `401 invalid_token`: Obehörig, ogiltig eller saknad auktoriseringstoken.
- `403 forbidden`: Förbjuden, otillräckligt saldo eller åtkomst.
- `429 too_many_requests`: För många begäranden, du har överskridit hastighetsgränsen.
- `500 api_error`: Internt serverfel, något gick fel på servern.

### Exempel på felsvar

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
