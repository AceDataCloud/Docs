Maestro är ett **Agent-nativt** video produktionsgränssnitt: du beskriver det önskade videon med en naturlig språk `prompt` (valfritt kan du bifoga referensbilder / videor / ljud med `file_urls`), en huvudlös "AI-regissör" kommer automatiskt att slutföra ämnesval, skriva manus, generera bilder, röstinspelning, musik, sammansättning och rendering, och slutligen producera en färdig video med undertexter och ladda upp den till CDN.

Denna artikel kommer att ge en detaljerad beskrivning av Maestro video generation API:s integrationsanvisningar, för att hjälpa dig att snabbt integrera och fullt utnyttja API:ets kapabiliteter.

Detta är ett **asynkront uppgifts** gränssnitt: efter inlämning kommer det omedelbart att returnera `task_id`, och du kan sedan använda [Maestro uppgiftsfråge-API](development_maestro_tasks.md) (`POST /maestro/tasks`) för att pollera resultatet (polling är gratis och debiteras inte). För att fortsätta iterera på en befintlig video kan du använda `action: remix` / `edit` / `extend` tillsammans med `ref_task_id`.

## Ansökningsprocess

För att använda Maestro video generation API, börja med att gå till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att få din API-token, som du kan spara för framtida bruk.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du inte har loggat in eller registrerat dig kommer du automatiskt att omdirigeras till inloggningssidan för att registrera dig och logga in, och efter att ha slutfört detta kommer du automatiskt att återvända till den aktuella sidan.

**En API-token räcker för att anropa alla tjänster på plattformen, du behöver inte ansöka separat för varje tjänst.** Första ansökan ger en gratis kvot, så att du kan prova gratis; om kvoten tar slut kan du ladda på allmän balans i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Maestro video generation API →](https://platform.acedata.cloud/documents/maestro-videos)

## Grundläggande användning

`POST https://api.acedata.cloud/maestro/videos`

Den mest grundläggande användningen kräver bara att du skickar en naturlig språk `prompt`, AI-regissören kommer automatiskt att bestämma manus, bilder, röstinspelning och redigering. Här ska vi först förstå de begärningshuvuden och begärningskroppar som behöver ställas in.

**Request Headers** inkluderar:

- `accept`: vilken typ av format du vill ta emot som svar, här fylls i som `application/json`, det vill säga JSON-format.
- `authorization`: nyckeln för att anropa API:et, efter ansökan kan du direkt välja från rullgardinsmenyn.
- `content-type`: formatet på begärningskroppen, här fylls i som `application/json`.

**Request Body** inkluderar huvudsakligen:

- `prompt`: beskriv videon du vill göra med naturligt språk (ämne, vad som ska visas, stil, publik).
- `langs`: utmatningsspråk array, som `["zh-cn", "en"]`, standard `["zh-cn"]`.
- `aspect`: bildförhållande, `9:16` (standard) / `16:9` / `1:1`.
- `duration`: mållängd (sekunder), standard 30.

Alla fält i begärningskroppen visas i tabellen nedan:

| Fält            | Typ       | Obligatoriskt  | Beskrivning                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Ja   | Beskriv videon du vill göra med naturligt språk (ämne, vad som ska visas, stil, publik). Manus, bilder, röstinspelning och redigering bestäms av AI.                                                                                                                                                                             |
| `action`      | string   | Nej   | `generate` (standard, generera ny video) / `remix` / `edit` / `extend` (iterera på en befintlig video, kräver `ref_task_id`).                                                                                                                                                |
| `ref_task_id` | string   | Nej   | Obligatoriskt när `action` är remix / edit / extend: historisk uppgift `task_id` som utgångspunkt.                                                                                                                                                                   |
| `file_urls`   | string[] | Nej   | Referensmedia (bilder / videor / ljud-URL), till exempel produktbilder, logotyper eller materialklipp som ska ha undertexter.                                                                                                                                                                             |
| `langs`       | string[] | Nej   | Utmatningsspråk, som `["zh-cn", "en"]`, standard `["zh-cn"]`. Den första är huvudspråket; varje ytterligare språk återanvänder bilder, bara mer röstinspelning + rendering, **varje ytterligare +6 poäng**.                                                                                                                                          |
| `aspect`      | string   | Nej   | `9:16` (standard) / `16:9` / `1:1`. Lite ger ut 720p/24fps, Standard och Pro ger ut 1080p/30fps.                                                                                                                                                  |
| `duration`    | int      | Nej   | Mållängd (sekunder), standard 30. Lite är **5–30 sekunder**, Standard är **5–120 sekunder**, Pro är **5–300 sekunder**. Debitering baseras på den faktiska längden på den färdiga videon, men överstiger inte begärd längd.                                                                                                                                 |
| `quality`     | string   | Nej   | Produktionsnivå: `lite` (snabb kortvideo, 0.20 poäng/sekund) / `standard` (standard, balanserad produktion, 0.60 poäng/sekund) / `pro` (avancerad produktion, 1.20 poäng/sekund).                                                                                                                                           |
| `scenario`    | string   | Nej   | Videotyp: Lite stöder `auto` / `narrated` / `captions`; Standard lägger till `avatar`; Pro lägger till `drama`. `captions` kräver att källvideon skickas, `avatar` kräver att porträtt skickas.                                                                                                             |
| `style`       | string   | Nej   | Visuell stil förinställningar: `auto` (standard) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`, accepterar också fri text som mjuk prompt. Är ortogonal mot `scenario`, ändrar inte rutten. |
| `voice`       | string   | Nej   | Berättarröst (språkuavhängigt, fungerar över språk): `auto` (standard) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`.                                    |

Nedan visas ett konkret exempel. Anta att vi vill generera en tvåspråkig, vertikal, 20 sekunder lång populärvetenskaplig kortvideo, motsvarande CURL-koden ser ut som följer:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Förklara vad en vektordatabas är på 20 sekunder, lämplig för nybörjare, avsluta med en minnespunkt.",
  "langs": ["zh-cn", "en"],
  "aspect": "9:16",
  "duration": 20
}'
```

Motsvarande Python-kod ser ut som följer:
```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn", "en"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Klicka på körning, så kan du se att du omedelbart får ett resultat, som följer:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Beskrivningen av fälten i returresultatet är som följer:

- `success`: Om uppgiften har skickats framgångsrikt.
- `task_id`: ID för den här videoproduktionsuppgiften, som används för att [Maestro uppgiftsfråge-API](development_maestro_tasks.md) för att pollera resultatet.
- `trace_id`: Spårnings-ID för denna begäran, som kan ges till teknisk support för att lokalisera problem.

Eftersom videoproduktionen tar tid, returnerar API:et här **omedelbart `task_id`**, och väntar inte på att videon ska renderas klart. Nästa steg är att använda `task_id` för att pollera resultatet, se avsnittet "Hämta resultat".

## Specifika videotyp och stil (scenario / style)

Om `scenario` inte anges, bedömer AI automatiskt (lika med `auto`); om du vill fästa videon till en viss typ, ange det uttryckligen. Till exempel, för att göra en **stående kortfilm**, kan du specificera följande innehåll:

- `scenario`: Videotyp, här ställs den in på `drama` (karaktärer + dialog i kortfilm).
- `style`: Visuell stil, här ställs den in på `cinematic` (filmisk känsla).

Exempel på CURL-kod för att fylla i:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Vanliga kombinationer:

- Berättande kortfilm: `scenario: "narrated"`, stöds av Lite / Standard / Pro.
- Automatisk textning: `scenario: "captions"`, kräver att `file_urls` skickas med källvideon, stöds av Lite / Standard / Pro.
- Digital människa / röstuppläsning: `scenario: "avatar"`, kräver att `file_urls` skickas med en bild, stöds av Standard / Pro.
- Kortfilm: `scenario: "drama"` (karaktärer + dialog), stöds endast av Pro.
- `style` är en visuell stilpreset (som `modern` / `neon` / `luxury`), ändrar inte typ, påverkar bara upplevelsen.
- `voice` används för att specificera berättarröstens ton (som `warm-female` / `deep-male`), oberoende av språk, fungerar över språk.

Returresultatet är detsamma som "Grundläggande användning", det returnerar också omedelbart `task_id`.

## Flerspråkig utdata

Genom att ange flera språk i `langs` kan du producera flerspråkiga versioner på en gång. Den första är huvudspråket, och varje ytterligare språk kommer att **återanvända samma uppsättning bilder**, bara extra röst + rendering, så **varje ytterligare språk kostar endast +6 poäng**. Exempel:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "介绍我们的智能客服产品，突出 3 个核心卖点",
  "langs": ["zh-cn", "en", "ja"],
  "aspect": "16:9",
  "duration": 30
}'
```

När uppgiften är klar kommer varje språk att motsvara ett `variant` i resultatet (se [Maestro uppgiftsfråge-API](development_maestro_tasks.md)).

## Iterera på befintlig video (remix / edit / extend)

Genom att ange `action` och den senaste uppgiftens `ref_task_id`, kan du göra differensändringar på den ursprungliga projektbasen (som "ändra titeln på akt 2", "byta röst", "justera färgerna"). Små ändringar går snabbt, stora ändringar kommer att göras om:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: Återberätta på den ursprungliga videostrukturen (bevara temat, justera presentationen).
- `edit`: Gör finjusteringar på specifika delar (som att byta titel, byta röst, justera färger).
- `extend`: Utvidga innehållet på den ursprungliga videon.

Returresultatet är också omedelbart ett nytt `task_id`, som du kan använda för att pollera och få den itererade filmen.

## Hämta resultat

Eftersom videoproduktionen tar tid, returnerar detta API omedelbart `task_id` efter inlämning, du behöver använda det för att [Maestro uppgiftsfråge-API](development_maestro_tasks.md) för att pollera resultatet:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

När uppgiften är klar kommer den att returnera information om filmen (varje språk motsvarar en `variant`). `status` kommer att genomgå `pending → planning → producing → succeeded` (eller `failed`), **polling är gratis, kostar inga poäng**. Den fullständiga svarformatet och historiklistans frågor kan du se i [Maestro uppgiftsfråge-API integrationsbeskrivning](development_maestro_tasks.md).

## Avgifter

**Avgifter debiteras baserat på den faktiska filmen efter att uppgiften är klar, misslyckade uppgifter debiteras inte.** Avgifterna baseras på den faktiska levererade filmens längd och antal språk, och den debiterade längden kommer inte att överstiga begärningens längd. Om ett språk inte produceras slutligen, kommer det inte att debiteras +6 för det språket. Inlämning av uppgifter debiteras inte separat, `/maestro/tasks` polling är gratis.

Poängen för en enskild film beräknas enligt följande formel:

```
poäng = filmens längd i sekunder × SKU pris per sekund × scenariebaserad multiplikator + 6 × max(antal språk - 1, 0)
```
| SKU        |    Pris per sekund |  Längsta varaktighet | Utdata                | Scenarier och åtgärder                                |
| ---------- | ------: | ----: | ----------------- | ------------------------------------ |
| `lite`     | 0.20 poäng |  30 sek | 720p / 24fps      | auto, berättad, undertexter; generera, redigera |
| `standard` | 0.60 poäng | 120 sek | 1080p / 30fps     | Lägg till avatar; lägg till remix                   |
| `pro`      | 1.20 poäng | 300 sek | 1080p / 30fps hög bitrate | Lägg till drama; lägg till utöka                   |

Scenarbete: `drama` 1.35× / `avatar` 1.15× / annat 1×.

| Exempel                  |  Poäng |
| ------------------- | --: |
| Lite 30 sek           |   6 |
| Standard 30 sek       |  18 |
| Standard 60 sek       |  36 |
| Standard 120 sek      |  72 |
| Pro 30 sek            |  36 |
| Pro 300 sek           | 360 |
| För varje ytterligare leveransspråk          |  +6 |
| `/maestro/tasks` polling |  Gratis |

## Felhantering

Vid anrop av API:et, om ett fel uppstår, kommer API:et att returnera motsvarande felkod och information. Till exempel:

- `400 invalid_request`: Felaktig begäran, möjligtvis på grund av en saknad `prompt` eller ogiltiga parametrar.
- `401 invalid_token`: Obemyndigad, ogiltig eller saknad auktoriseringstoken.
- `403 forbidden`: Förbjuden, otillräcklig balans eller åtkomst.
- `429 too_many_requests`: För många begärningar, du har överskridit hastighetsgränsen.
- `500 api_error`: Intern serverfel, något gick fel på servern.

### Exempel på felrespons

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
