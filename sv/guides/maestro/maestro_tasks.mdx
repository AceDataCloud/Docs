Huvudfunktionen för Maestro API för uppgiftsfrågor är att, via det uppgifts-ID som returneras av [Maestro API för videogenerering](/sv/guides/maestro/maestro_videos) (`POST /maestro/videos`), fråga efter uppgiftens körstatus och slutresultat.

Detta dokument kommer att i detalj introducera integrationsanvisningarna för Maestro API för uppgiftsfrågor. Eftersom videogenerering är en asynkron uppgift behöver du efter inskickning använda detta gränssnitt för att hämta framsteg och färdig video genom polling, **polling är gratis och förbrukar inga poäng.**

`POST https://api.acedata.cloud/maestro/tasks`

## Ansökningsprocess

För att använda Maestro API för uppgiftsfrågor ska du först hämta din API Token från [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) och spara den för senare användning.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig omdirigeras du automatiskt till inloggningssidan för att registrera och logga in, och återvänder automatiskt till den aktuella sidan efter slutförandet.

**En API Token kan anropa alla plattformens tjänster, utan att behöva ansöka separat för varje tjänst.** Vid första ansökan får du en gratis kvot för kostnadsfri testning; när kvoten är otillräcklig kan du fylla på det gemensamma saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Maestro API för uppgiftsfrågor →](https://platform.acedata.cloud/documents/maestro-tasks)

## Fråga efter en enskild uppgift

För hur man skapar en videouppgift, se dokumentet [Maestro API för videogenerering](/sv/guides/maestro/maestro_videos). Vi använder ett av de uppgifts-ID:n som returneras av det som exempel: `f57e99c4f60f4373a15517742ce2357d`, för att demonstrera hur man frågar efter dess status och resultat.

### Ställ in begärandehuvuden och begärandetext

**Request Headers** inkluderar:

- `accept`: anger att JSON-formaterade svar ska tas emot, fyll i `application/json` här.
- `authorization`: nyckeln för att anropa API:t, kan väljas direkt från rullgardinsmenyn efter ansökan.
- `content-type`: formatet för begärandetexten, fyll i `application/json` här.

**Request Body** inkluderar:

| Fält       | Typ    | Obligatoriskt vid | Beskrivning                                                |
| -------- | ------ | --------- | ------------------------------------------------- |
| `id`     | string | Obligatoriskt vid fråga efter en enskild uppgift | `task_id` som returneras av `POST /maestro/videos`              |
| `action` | string | Nej         | `retrieve` (standard, fråga efter en enskild uppgift); vid fråga efter historiklista är det alltid `retrieve_batch` |

### Kodexempel

Motsvarande CURL-kod är följande:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d",
  "action": "retrieve"
}'
```

Motsvarande Python-kod är följande:

```python
import requests

url = "https://api.acedata.cloud/maestro/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "f57e99c4f60f4373a15517742ce2357d",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Svarsexempel

Efter att begäran har lyckats returnerar API:t status och resultat för denna videouppgift. Svarsexemplet när uppgiften är klar är följande (`variants`-arrayen innehåller en färdig video):

```json
{
  "id": "f57e99c4f60f4373a15517742ce2357d",
  "started_at": 1769262721.823,
  "finished_at": 1769264698.3,
  "elapsed": 1976.477,
  "status": "succeeded",
  "progress": {
    "percent": 100,
    "stage": "producing",
    "message": "rendering scene 2"
  },
  "request": {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": [
      "zh-cn"
    ],
    "aspect": "9:16",
    "duration": 20
  },
  "response": {
    "success": true,
    "data": {
      "variants": [
        {
          "lang": "zh-cn",
          "aspect": "9:16",
          "kind": "video",
          "title": "什么是向量数据库",
          "output_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4?example=video-001"
        }
      ],
      "project": {
        "tarball_url": null,
        "outputs": [
          "https://…/zh.mp4"
        ]
      },
      "percent": 100,
      "stage": "producing",
      "progress": [
        {
          "stage": "producing",
          "message": "rendering scene 2",
          "pct": 60,
          "t": 1750000000
        }
      ]
    }
  }
}
```

Introduktionen till fälten i returresultatet är följande:

- `id`: ID:t för denna videouppgift, används för att unikt identifiera denna videogenereringsuppgift.
- `status`: uppgiftsstatus, värdena är `pending → planning → producing → succeeded` (eller `failed`). Huruvida uppgiften har slutförts avgörs av denna översta `status`.
- `elapsed`: uppgiftens förbrukade tid (sekunder).
- `progress`: översta förloppsobjektet, `percent` (0–100) säkras till 100 efter att uppgiften lyckats; `stage` och `message` återspeglar AI-regissörens senaste förloppshändelse (därför kan `stage` efter lyckad körning fortfarande vara det sista körningssteget, till exempel `producing`), och kan direkt användas för att visa förloppsindikatorn.
- `request`: begärandetexten när uppgiften startades.
- `response`: uppgiftens returinformation.
  - `success`: huruvida uppgiften lyckades.
  - `data.variants`: innehåller ett färdigt videoobjekt på det valda språket, inklusive `lang`, `aspect`, `title`, `output_url` (nedladdningsadress för färdig video) med mera.
  - `data.project`: hela projektets resultat, inklusive `tarball_url` (projektpaket) och `outputs` (länkar till färdig video).
  - `data.progress`: en array med förloppshändelser som läggs till per steg (append-only-logg), kan användas för att visa detaljerade framsteg i realtid.
- `created_at`: uppgiftens skapandetid, Unix-tidsstämpel (sekunder).
- `started_at`: tid då uppgiften började köras, Unix-tidsstämpel (sekunder). Är null när uppgiften ännu inte har startat.
- `finished_at`: tid då uppgiften slutfördes, Unix-tidsstämpel (sekunder). Är null när uppgiften inte har slutförts.

## Fråga efter historiklista

Genom att skicka in `action: retrieve_batch` kan du hämta de senaste uppgifterna för den för närvarande inloggade utföraren (sorterade i fallande ordning efter skapandetid), vilket kan användas för listsidan ”Mina videor”. Historiklistan är isolerad efter inloggningsidentitet.

**Request Body** inkluderar:

| Fält               | Typ    | Obligatoriskt  | Beskrivning                              |
| ---------------- | ------ | --- | ------------------------------- |
| `action`         | string | Ja   | Alltid `retrieve_batch`            |
| `limit`          | int    | Nej   | Antal returnerade poster, standard är 20; giltigt intervall är 1–100          |
| `created_at_max` | int    | Nej   | Returnerar endast uppgifter som är strikt tidigare än denna Unix-tidsstämpel (exklusive gränsvärdet, används för sidindelning) |
| `created_at_min` | int    | Nej   | Returnerar endast uppgifter som är strikt senare än denna Unix-tidsstämpel (exklusive gränsvärdet)     |

### Kodexempel

Motsvarande CURL-kod är följande:
```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "retrieve_batch",
  "limit": 20
}'
```

När begäran har lyckats returnerar API:et den aktuella användarens historiska uppgiftslista:

```json

  "items": [
    {
      "id": "f57e99c4f60f4373a15517742ce2357d",
      "started_at": 1769262721.823,
      "finished_at": 1769264698.3,
      "elapsed": 1976.477,
      "status": "succeeded",
      "progress": {
        "percent": 100,
        "stage": "producing",
        "message": "rendering scene 2"
      },
      "request": {
        "prompt": "…",
        "langs": [
          "zh-cn"
        ],
        "aspect": "9:16",
        "duration": 20
      },
      "response": {
        "success": true,
        "data": {
          "variants": [
            {
              "lang": "zh-cn",

            }
```

Fälten i returresultatet beskrivs nedan:

- `count`: Det totala antalet uppgifter som är synliga för den aktuellt inloggade exekveraren, opåverkat av tidsvillkor eller `limit`.
- `items`: En uppgiftsarray filtrerad efter tidsvillkor och `limit`, sorterad i omvänd kronologisk ordning efter skapandetid; formatet för varje element är samma som returresultatet för ”Fråga efter en enskild uppgift”.

## Rekommendationer för polling

Eftersom videoproduktion tar lång tid kommer `status` att gå igenom `pending → planning → producing → succeeded` (eller `failed`). Det rekommenderas att polla en gång var 5–10:e sekund tills `status` ändras till `succeeded` eller `failed`. Den översta nivån `progress.percent` kan användas för att visa en förloppsindikator i realtid. **Polling av detta API är kostnadsfri och förbrukar inga poäng.**

## Felhantering

När API:et anropas returnerar API:et motsvarande felkod och information om ett fel uppstår. Till exempel:

- `401 invalid_token`: Obehörig, ogiltig eller saknad auktoriseringstoken.
- `404 not_found`: Uppgiften hittades inte, det angivna task_id finns inte.
- `429 too_many_requests`: För många begäranden, du har överskridit hastighetsgränsen.
- `500 api_error`: Internt serverfel, något gick fel på servern.

### Exempel på felsvar

```json
{
  "success": false,
  "error": {

    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
