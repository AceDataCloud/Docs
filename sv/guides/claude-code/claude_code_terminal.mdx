Claude Code är ett **Agentic Coding** verktyg som lanserats av Anthropic, och det kallas också för en av världens mest kraftfulla programmeringsagenter. Terminal CLI är den centrala upplevelsen av Claude Code, där du kan köra kommandot `claude` i valfri terminal och samarbeta med AI i programmering genom naturligt språk.

Detta dokument beskriver hur man installerar, konfigurerar och använder Claude Code CLI via AceData Clouds proxyservice i terminalen.

## Ansökningsprocess

För att använda Claude Code kan du först gå till [Claude Messages tjänstsida](https://platform.acedata.cloud/documents/claude-messages) och klicka på knappen "Acquire" för att få de nödvändiga autentiseringsuppgifterna:

![](https://cdn.acedata.cloud/nyq0xz.png)

Om du inte är inloggad eller registrerad kommer du automatiskt att omdirigeras till inloggningssidan där du blir inbjuden att registrera dig och logga in. Efter inloggning och registrering kommer du automatiskt att återvända till den aktuella sidan.

Vid första ansökan får du en gratis kvot som gör att du kan prova Claude Code-tjänsten kostnadsfritt.

## Installera Claude Code

### Systemkrav

- macOS, Linux eller Windows (inklusive WSL)
- Node.js är inte nödvändigt, den inbyggda installationsmetoden hanterar automatiskt beroenden

### Installationsmetoder

Claude Code stöder flera installationsmetoder:

**Metod ett: Inbyggd installation (rekommenderas)**

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows CMD:

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**Metod två: Homebrew (macOS / Linux)**

```bash
brew install claude-code
```

**Metod tre: WinGet (Windows)**

```cmd
winget install Claude.ClaudeCode
```

Den inbyggda installationen kommer automatiskt att uppdateras i bakgrunden för att alltid hålla den senaste versionen.

## Konfigurera AceData Cloud API

När installationen är klar kommer du som standard att bli ombedd att logga in på Anthropic officiella konto. Vi kan använda miljövariabler för att konfigurera AceData Clouds proxy-API, **utan officiell prenumeration**.

### Konfigurera miljövariabler

Det finns två sätt att konfigurera miljövariabler, välj vilket som helst.

**Metod ett: Ställ in i Shell-konfigurationsfilen (rekommenderas)**

Lägg till följande innehåll i din Shell-konfigurationsfil (`~/.zshrc`, `~/.bashrc` eller `~/.bash_profile`), och ersätt `{token}` med API-token som du fått från AceData Cloud-konsolen:

```bash
# AceData Cloud - Claude Code proxykonfiguration
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Kör följande kommando för att aktivera konfigurationen:

```bash
source ~/.zshrc  # eller source ~/.bashrc
```

**Metod två: Ställ in i Claude Code settings.json**

Redigera `~/.claude/settings.json` (om den inte finns, skapa den) och lägg till `env`-konfigurationen:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Fördelen med denna metod är att miljövariablerna endast påverkar Claude Code och inte andra program.

> **Tips**: API-token kan ses i [AceData Cloud-konsolen](https://platform.acedata.cloud/console). Värdet av `ANTHROPIC_AUTH_TOKEN` kommer automatiskt att få prefixet `Bearer` när det skickas till servern.

## Börja använda

### Starta interaktivt läge

Öppna terminalen, gå till din projektmapp och kör:

```bash
cd /path/to/your/project
claude
```

Du kommer att se Claude Codes välkomstskärm, skriv helt enkelt in naturligt språk för att börja interagera.

### Vanliga kommandon

| Kommando            | Beskrivning          | Exempel                   |
| ------------------ | ------------------- | ------------------------- |
| `claude`           | Starta interaktivt läge | `claude`                 |
| `claude "uppgift"` | Utför engångsuppgift | `claude "fixa byggfel"`  |
| `claude -p "fråga"` | Utför fråga och avsluta | `claude -p "förklara denna funktion"` |
| `claude -c`       | Fortsätt senaste konversationen i aktuell katalog | `claude -c`              |
| `claude -r`       | Återställ tidigare konversation | `claude -r`              |
| `claude commit`    | Skapa Git-commit    | `claude commit`          |

### Interaktiva lägekommandon

I interaktivt läge kan du använda följande inbyggda kommandon:

| Kommando            | Funktion            |
| ------------------ | ------------------ |
| `/help`            | Visa hjälpmeddelande |
| `/clear`           | Rensa konversationshistorik |
| `/config`          | Öppna inställningspanelen |
| `/model`           | Byt modell         |
| `/mcp`             | Hantera MCP-tjänst |
| `/compact`         | Komprimera kontext  |
| `/memory`          | Hantera minne      |
| `/login`           | Byt konto          |
| `exit` eller `Ctrl+C` | Avsluta         |

### Exempel på dialoginteraktion

```bash
# Analysera projekt
> vad gör detta projekt?

# Fixa buggar
> det finns en bugg där användare kan skicka tomma formulär - fixa det

# Skriva tester
> skriv enhetstester för kalkylatorfunktionerna

# Refaktorisera kod
> refaktorisera autentiseringsmodulen för att använda async/await

# Git-operationer
> committa mina ändringar med ett beskrivande meddelande
> skapa en pr för denna funktion
```

## Avancerad användning

### Pipelines och skriptning

Claude Code följer Unix-filosofin och stöder pipelining och skriptoperationer:

```bash
# Övervaka loggar och automatiskt larma
tail -f app.log | claude -p "om ett undantag upptäcks, meddela mig"

# Automatisk översättning av ny text
claude -p "om det finns nya textsträngar, översätt till franska och skapa PR"

# Kodgranskning
git diff main | claude -p "granska dessa ändringar"
```

### Referens för miljövariabler

Här är några vanliga miljövariabler som stöds av Claude Code:

| Variabel                       | Beskrivning                                   |
| ------------------------------ | --------------------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`        | Värdet för anpassad Authorization-header (automatiskt prefixat med Bearer) |
| `ANTHROPIC_API_KEY`           | API-nyckel (skickas som X-Api-Key-header)   |
| `ANTHROPIC_BASE_URL`          | API:s grund-URL                              |
| `ANTHROPIC_MODEL`             | Överskriv standardmodellen                    |
| `ANTHROPIC_SMALL_FAST_MODEL`  | Haiku-nivåmodell (för bakgrundsuppgifter)    |
| `MAX_THINKING_TOKENS`         | Ställ in budget för tänkande tokens (sätt till 0 för att inaktivera tänkande läge) |
| `DISABLE_COST_WARNINGS`       | Sätt till 1 för att inaktivera kostnadsvarningar |

### CLAUDE.md Projektminne

Skapa en `CLAUDE.md`-fil i projektets rotmapp för att ge Claude Code projektspecifika instruktioner och kontext. Claude kommer automatiskt att ladda denna fil vid start.

```markdown
# Projektbeskrivning
Detta är ett fullstack-projekt med Django + Vue.js.

## Kodstandard
- Använd Python 3.12
- Följ PEP 8 kodstil
- Alla API:er måste ha enhetstester
```

## Vanliga frågor

### Vad gör jag om anslutningen misslyckas?
1. Kontrollera att filen `~/.claude/config.json` har skapats korrekt, innehållet ska vara `{"primaryApiKey": "self"}`
2. Bekräfta att miljövariablerna har ställts in korrekt:
   ```bash
   echo $ANTHROPIC_AUTH_TOKEN
   echo $ANTHROPIC_BASE_URL
   ```
3. Bekräfta att API-token är giltig (kan ses i [kontrollpanelen](https://platform.acedata.cloud/console))
4. Försök att starta om terminalen

### kommando hittades inte: claude

Om det efter installationen visas `kommando hittades inte`, försök:

1. Stäng och öppna terminalen igen
2. Kontrollera PATH: `echo $PATH`
3. Installera om: `curl -fsSL https://claude.ai/install.sh | bash`

Logga in på [AceData Cloud kontrollpanelen](https://platform.acedata.cloud/console) för att se den aktuella kontots kvarvarande kvot och användning.
