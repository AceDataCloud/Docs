## 1. Hämta API-nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installera Claude Code

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
```

Kontrollera efter installation:

```bash
claude --version
```

## 3. Konfigurera Ace Data Cloud

För global användning, lägg till följande variabler i `~/.zshrc` eller `~/.bashrc`：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="din API-nyckel"
unset ANTHROPIC_API_KEY
```

Öppna terminalen på nytt, eller `source` motsvarande konfigurationsfil.

För att endast gälla för det aktuella projektet, kan du skapa en `.claude/settings.local.json` som är inkluderad i `.gitignore`：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "din API-nyckel"
  }
}
```

Välj en av de två metoderna. Skriv inte den verkliga nyckeln i teamets delade `.claude/settings.json`; om miljön redan har `ANTHROPIC_API_KEY`, bör den verkligen tas bort, inte sättas till en tom sträng.

## 4. Starta och verifiera

```bash
cd /path/to/your/project
claude
```

När du är inne, skicka en läsbar uppgift, till exempel "Läs README.md och sammanfatta med en mening". Anropshistorik och saldo kan ses i [användningshistorik](https://platform.acedata.cloud/console/usages) och [applikationslista](https://platform.acedata.cloud/console/applications).

Om du får tillbaka 401, kontrollera om nyckeln är komplett, om den gamla `ANTHROPIC_API_KEY` har tagits bort, och starta om Claude Code helt. Modellen behöver inte vara fastställd i anslutningskonfigurationen, utan kan väljas i Claude Code bland tillgängliga modeller.
