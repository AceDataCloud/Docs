## 1. Hämta API-nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installera CC Switch

Ladda ner från [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), macOS kan också köras:

```bash
brew install --cask cc-switch
```

## 3. Lägg till Provider

Öppna CC Switch, välj **Claude Code → Add Provider → Custom**, fyll i:

| Fält        | Värde                        |
| ----------- | ---------------------------- |
| Namn        | `Ace Data Cloud`            |
| Bas-URL     | `https://api.acedata.cloud` |
| API-nyckel  | Den just kopierade API-nyckeln |
| API-format  | `Anthropic Messages`        |

Om du vill använda JSON-redigeraren, konfigurera som:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

CC Switch kommer att skriva konfigurationen i Claude Codes användarinställningar. Spara inte den verkliga nyckeln i teamets repository och behåll inte den gamla `ANTHROPIC_API_KEY` samtidigt.

## 4. Aktivera och verifiera

Aktivera **Ace Data Cloud** efter att ha sparat, stäng sedan och öppna Claude Code igen. Skicka en enkel läs-uppgift och kontrollera anropet i [användningshistorik](https://platform.acedata.cloud/console/usages). Om den gamla konfigurationen fortfarande används efter bytet, stäng helt Claude Code och CC Switch och försök igen.
