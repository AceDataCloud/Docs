Claude Code är ett **Agentic Coding** verktyg som lanserats av Anthropic, och kallas också en av världens mest kraftfulla programmeringsagenter. Claude Code skrivbordsapplikation erbjuder ett fristående grafiskt gränssnitt, stöd för Diff-granskning, parallella sessioner (genom att isolera med Git Worktree), fjärrsessioner och mer, utan att behöva förlita sig på någon IDE.

Detta dokument beskriver huvudsakligen hur man konfigurerar och använder Claude Code skrivbordsapplikation via AceData Clouds proxyservice.

> **Observera**: Claude Code skrivbordsapplikation är för närvarande i förhandsgranskning (Preview) och stöder endast macOS och Windows.

## Ansökningsprocess

För att använda Claude Code kan du först gå till [Claude Messages tjänstsida](https://platform.acedata.cloud/documents/claude-messages) och klicka på "Acquire" knappen för att få de nödvändiga autentiseringsuppgifterna:

![](https://cdn.acedata.cloud/nyq0xz.png)

Om du inte är inloggad eller registrerad kommer du automatiskt att omdirigeras till inloggningssidan för att registrera dig och logga in, och efter inloggning kommer du automatiskt att återvända till den aktuella sidan.

Vid första ansökan får du en gratis kvot för att prova Claude Code-tjänsten.

## Installera skrivbordsapplikationen

### Systemkrav

- macOS (Intel och Apple Silicon) eller Windows (x64 / ARM64)
- Linux stöder för närvarande inte skrivbordsapplikationen

### Ladda ner och installera

Gå till [Claude officiella nedladdningssida](https://claude.ai) för att ladda ner installationspaketet för din plattform:

- **macOS**: Ladda ner `.dmg` filen och dra den till Applications mappen
- **Windows x64**: Ladda ner `.exe` installationspaketet och följ instruktionerna för installation
- **Windows ARM64**: Ladda ner ARM64-versionen (observera: ARM64 stöder inte lokala sessioner, fjärrsessioner måste användas)

![Claude skrivbordsapplikation nedladdningssida](https://cdn.acedata.cloud/c3c8c57264.png)

När installationen är klar, starta Claude från Applications mappen (macOS) eller startmenyn (Windows).

## Konfigurera AceData Cloud API

När skrivbordsapplikationen startas måste du logga in på ditt Anthropic-konto. Vi kan använda miljövariabler för att använda AceData Clouds proxy-API, **utan officiell prenumeration**.

Skrivbordsapplikationen läser miljövariabler från din Shell-miljö, så du behöver ställa in dem i din Shell-konfigurationsfil.

### Konfigurera miljövariabler

**macOS-användare**

Lägg till följande innehåll i `~/.zshrc` (eller `~/.bashrc`), ersätt `{token}` med din API-token:

```bash
# AceData Cloud - Claude Code proxykonfiguration
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Spara och kör:

```bash
source ~/.zshrc
```

**Windows-användare**

Lägg till följande systemmiljövariabler via "Systemegenskaper → Avancerat → Miljövariabler":

| Variabelnamn                    | Värde                           |
| ---------------------- | ----------------------------- |
| `ANTHROPIC_AUTH_TOKEN` | `{token}` (ersätt med din API-token)     |
| `ANTHROPIC_BASE_URL`   | `https://api.acedata.cloud` |

Eller använd PowerShell:

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**Kan också konfigureras via settings.json**

Redigera `~/.claude/settings.json` (om den inte finns, skapa den):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Tips**: API-token kan ses i [AceData Cloud-konsolen](https://platform.acedata.cloud/console). Efter konfigurationen behöver du **starta om skrivbordsapplikationen** för att miljövariablerna ska träda i kraft.

## Grundläggande användning

### Öppna projekt

1. Starta Claude skrivbordsapplikation
2. Klicka på **Code** fliken högst upp
3. Välj **Local** körläge
4. Klicka på **Select folder** för att välja din projektmapp

### Börja dialog

Skriv en naturlig språkbeskrivning av dina behov i inmatningsfältet:

- "Hitta TODO-kommentarer och åtgärda dem"
- "Lägg till tester för huvudfunktionen"
- "Förklara arkitekturen för detta projekt"

Claude kommer att analysera ditt kodbibliotek, föreslå ändringar och visa dem i Diff-vyn.

### Behörighetsläge

Byt läge med växlingsknappen bredvid sändknappen:

| Läge       | Beskrivning                 |
| -------- | -------------------------- |
| **Ask**  | Fråga om bekräftelse före varje ändring (rekommenderas för nybörjare)  |
| **Code** | Acceptera automatiskt filredigering, men terminalkommandon måste fortfarande bekräftas |
| **Plan** | Gör en detaljerad plan och vänta på godkännande innan den utförs |

### Parallella sessioner

Klicka på sidofältet **+ New session** för att starta flera parallella sessioner. För Git-repositorier får varje session en oberoende projektkopiering via Worktree, utan att störa varandra.

Worktree lagras som standard i `~/.claude-worktrees/` katalogen.

### Diff-granskning

När Claude har ändrat filer kommer ändringsstatistik att visas (t.ex. `+12 -1`), klicka för att öppna Diff-granskaren och granska ändringar fil för fil. Du kan också klicka på specifika kodrader för att lägga till kommentarer, och Claude kommer att justera sig baserat på din feedback.

## Ansluta externa verktyg

Innan du börjar en session, klicka på **⋯** knappen och välj **Connectors** för att lägga till externa integrationer:

- Google Kalender
- Slack
- GitHub
- Linear
- Notion
- Mer...

När du har anslutit kan Claude direkt läsa kalendern, skicka meddelanden, skapa ärenden osv.

## Förhållandet till CLI

Skrivbordsapplikationen och CLI använder samma underliggande motor och delar följande konfiguration:

- `CLAUDE.md` / `CLAUDE.local.md` projektminnesfiler
- `~/.claude.json` / `.mcp.json` MCP-serverkonfiguration
- `~/.claude/settings.json` inställningar
- Hooks och Skills konfiguration

Båda kan köras samtidigt på samma projekt och upprätthålla oberoende sessionhistorik.

## Vanliga frågor

### Vad ska jag göra om anslutningen misslyckas?

1. Kontrollera om `~/.claude/config.json` filen har skapats korrekt
2. Bekräfta att miljövariablerna har ställts in korrekt (starta om skrivbordsapplikationen för att de ska träda i kraft)
3. Bekräfta att API-token är giltig (kan ses i [konsolen](https://platform.acedata.cloud/console))
4. Om du använder `settings.json` för att konfigurera miljövariabler, kontrollera att filformatet är korrekt

### Vad ska jag göra om installerade verktyg inte hittas?

Om Claude inte kan hitta kommandon som `npm`, `node` osv.:

1. Bekräfta att dessa verktyg fungerar normalt i en vanlig terminal
2. Kontrollera att din Shell-konfigurationsfil (`~/.zshrc`, `~/.bashrc`) har ställt in PATH korrekt
3. Starta om skrivbordsapplikationen för att ladda miljövariablerna på nytt

### Hur kan jag se kvarvarande kvot?

Logga in på [AceData Cloud-konsolen](https://platform.acedata.cloud/console) för att se den aktuella kontots kvarvarande kvot och användning.
