Det här dokumentet har ett enda mål: att låta dig **på 5 minuter** använda AceData Cloud-proxy för att köra ditt första Claude Code-kommando. Komplett handledning finns i respektive IDE-underdokument ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); denna artikel går bara igenom den snabbaste vägen med "**Terminal CLI** + **VS Code-tillägg**".

> **Varför använda AceData Cloud-proxy för Claude Code**:
> - Direktanslutning inom Kina, inget behov av egen VPN
> - Lägre pris än officiellt (debitering baserat på plattforms-Token)
> - Samma nyckel stöder både Claude Messages API + Claude Code Token-protokoll

## Minut 1: Ansök om autentiseringsuppgifter

Öppna [Claude Messages tjänstesida](https://platform.acedata.cloud/documents/claude-messages) och klicka på knappen "**Acquire**":

![](https://cdn.acedata.cloud/nyq0xz.png)

Plattformen skapar automatiskt en Application åt dig och ger gratis kvot. Skriv ner **Base URL** + **API Token** från detaljsidan — de behövs i de följande 5 stegen.

| Fält | Värde | Användning |
|------|-------|------------|
| `BASE_URL` | `https://api.acedata.cloud/claude` | Claude Messages kompatibel ingång |
| `API_TOKEN` | `sk-...` (kan kopieras från detaljsidan) | Anthropic-kompatibel autentiseringstoken |

## Minut 2: Installera Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

När installationen är klar, öppna en ny terminal och verifiera:

```bash
claude --version
```

> Du ska se versionsnumret. Claude Code levereras med inbyggd Node.js runtime, så det är oberoende av Node-versionen på din maskin.

## Minut 3: Pekar miljövariabler till AceData Cloud

Hoppa över den officiella `claude login`-processen och skriv över med miljövariabler. Välj ett av följande två sätt:

**Metod A: Temporärt (endast aktuell shell-session)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud/claude"
export ANTHROPIC_AUTH_TOKEN="sk-din-Token"
```

**Metod B: Permanent (rekommenderas)**

Lägg till ovanstående två rader i `~/.zshrc` eller `~/.bashrc` och kör sedan `source` på filen.

> **Vanligt misstag**: miljövariabeln heter `ANTHROPIC_AUTH_TOKEN`, inte `ANTHROPIC_API_KEY`; fel namn gör att Claude Code faller tillbaka till officiell endpoint och ger 401.

## Minut 4: Kör ditt första kommando

Gå in i valfri Git-repo och kör:

```bash
claude
```

Om du uppmanas att logga in första gången, tryck `Esc` för att hoppa över. Skriv sedan:

```
Lista beroenden i det aktuella projektet och förklara kort syftet med varje.
```

Normalt kommer Claude att använda verktyg som `read_file` / `glob` / `grep` för att skanna repo och sedan ge en lista. Statusfältet längst ner visar `connected to api.acedata.cloud` — detta är en viktig indikator på att proxyn fungerar.

## Minut 5: Koppla även VS Code-tillägget

1. Öppna VS Code → Extensions-panel → sök efter `Claude Code` och installera det officiella Anthropic-tillägget;
2. Tryck **Cmd+Shift+P** → skriv `Claude Code: Set Custom API Endpoint`;
3. Ange `https://api.acedata.cloud/claude` och tryck Enter;
4. Kör sedan `Claude Code: Set API Token` och ange din token.

När det lyckas visas Claude Code-panelen i sidofältet, där du kan dra in filer för frågor eller `@-mention` en fil för ändringsförslag. All debitering går via AceData Cloud.

## Verifiera att du verkligen använder proxyn

Skriv i Claude Code-konversationen:

```
Besök https://api.acedata.cloud/whoami och berätta vad som returneras
```

Om du får tillbaka din kontoinformation (`{user_id, plan, ...}`) betyder det att förfrågan verkligen går via AceData Cloud edge. Om du får 401 från officiell domän, gå tillbaka till minut 3 och kontrollera miljövariabelnamnen.

## 5 Vanligaste frågor

**Q: Jag körde `claude login` och ändrade sedan miljövariabler till AceData, men det fungerar inte?**  
A: `claude login` skriver officiell token i `~/.claude/.credentials.json`, som har högre prioritet än miljövariabler. Ta bort den filen och kör `source ~/.zshrc` igen.

**Q: Kan jag använda modellnamn som `--model claude-opus-4-7`?**  
A: Ja. AceData Cloud-proxyn vidarebefordrar model-fältet, alla offentliga Anthropic-modeller plus våra utökningar `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5` stöds.

**Q: Kan jag konfigurera flera profiler (privat + jobb)?**  
A: Ja. Claude Code stödjer flera profiler i `~/.claude/settings.json`; enklast är att definiera två shell-funktioner `claude_personal` / `claude_work` som exporterar olika `ANTHROPIC_AUTH_TOKEN` och sedan anropar `claude $@`.

**Q: Kan jag köra detta i GitHub Actions?**  
A: Ja. Se [Claude Code GitHub Actions konfigurationsguide](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**Q: Vad händer när gratiskvoten är slut?**  
A: Gå till [Apphantering](https://platform.acedata.cloud/applications) → välj denna Claude Application → Topup för att fylla på (debitering baserad på faktisk tokenanvändning), eller byt till poängprenumeration.
