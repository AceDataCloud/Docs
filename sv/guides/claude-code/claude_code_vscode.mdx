Claude Code är ett programmeringsverktyg som lanserats av Anthropic, och kallas också för en av världens mest kraftfulla programmeringsagenter. Claude Codes VS Code-tillägg erbjuder ett inbyggt grafiskt gränssnitt och är det rekommenderade sättet att använda Claude Code i VS Code.

Detta dokument beskriver huvudsakligen hur man konfigurerar och använder Claude Code-tillägget i VS Code via Ace Data Clouds proxy-tjänst.

## Ansökningsprocess

För att använda Claude Code kan du först gå till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att få din API-token, som du bör spara för framtida bruk.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du inte har loggat in eller registrerat dig kommer du automatiskt att omdirigeras till inloggningssidan där du blir inbjuden att registrera dig och logga in. Efter att ha loggat in eller registrerat dig kommer du automatiskt att återvända till den aktuella sidan.

Vid första ansökan får du en gratis kvot som gör att du kan prova Claude Code-tjänsten kostnadsfritt.

## Installera Claude Code-tillägget

Sök efter **Claude Code** i VS Codes tilläggsmarknad och installera det efter att ha bekräftat att utgivaren är **Anthropic**. När installationen är klar kommer en ingång för Claude Code att visas i aktivitetsfältet.

## Konfigurera Ace Data Cloud API

När du öppnar tillägget för första gången kommer du att bli ombedd att logga in på Anthropics officiella konto. Vi kan hoppa över den officiella inloggningen och använda Ace Data Clouds proxy-API istället, utan att behöva en officiell prenumeration.

Tillägget och terminal CLI läser samma uppsättning Claude Code-inställningar. Fullständig autentisering, hantering av konflikt med referenser och globala konfigurationsmetoder finns i [Claude Code Terminal-konfigurationsguide](https://platform.acedata.cloud/documents/claude-code-terminal-integration). Om du bara vill att inställningarna ska gälla för det aktuella projektet, skapa en `.claude/settings.local.json` i projektets rotmapp som är inkluderad i `.gitignore`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Där `{token}` är den API-nyckel du just kopierade. Om det finns en gammal `ANTHROPIC_API_KEY` i miljön där VS Code startas, vänligen kör `unset ANTHROPIC_API_KEY` i den miljön; använd inte en tom sträng för att rensa, och placera inte den verkliga nyckeln i den teamdelade `.claude/settings.json`.

Nedan är konfigurationen som slutfördes på min maskin med VS Code 1.136.1 och Claude Code-tillägget 2.1.251. Skärmdumpen använder en platshållar-nyckel för att undvika läckage av verkliga referenser:

![Ace Data Cloud Claude Code-konfiguration i VS Code](https://cdn.acedata.cloud/f925e9e9597b.png)

När konfigurationen är klar, starta om VS Code.

> Observera: Denna konfiguration gäller endast för det aktuella projektet, och det rekommenderas att lägga till sökvägen till den ovanstående `.claude/settings.local.json`-konfigurationsfilen i `.gitignore`-filen för att förhindra att den laddas upp till det fjärrlagret.

Om du vill att alla projekt ska gälla, kan du direkt placera konfigurationen i användarkatalogen. Den motsvarande sökvägen är `~/.claude/settings.json`,

> Observera: Efter att ha slutfört konfigurationen, vänligen starta om eller ladda om VS Code för att konfigurationen ska träda i kraft.

## Grundläggande användning

När konfigurationen är klar, skicka en enkel läsbar uppgift i Claude Code-panelen, till exempel "Läs README.md och sammanfatta med en mening". När uppgiften är framgångsrik kan du kontrollera denna anrop i [Användningshistorik](https://platform.acedata.cloud/console/usages).

## Hur man ser kvarvarande kvot

Genom [Ace Data Cloud-konsolen - Applikationslista](https://platform.acedata.cloud/console/applications) kan du se den kvarvarande kvoten för ditt konto.

Genom [Ace Data Cloud-konsolen - Användningshistorik](https://platform.acedata.cloud/console/usages) kan du se all användningshistorik och avgiftsdetaljer.
