Claude Code är en programmeringsintelligent agent lanserad av Anthropic, som kan användas i terminaler, IDE:er och CI/CD-pipelines med flera miljöer. Genom AceData Cloud-proxy kan du använda Claude Code till ett lägre pris.

Välj komplett konfigurationsguide för respektive plattform baserat på användningsscenario:

| Plattform | Beskrivning | Guide-länk |
|------|------|---------|
| **VS Code** | Inbyggd extension, stöd för inline Diff, @-mentions, planerad granskning | [VS Code konfigurationsguide](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | VS Code-kompatibel editor, fullständigt stöd för Claude Code extension | [Cursor konfigurationsguide](https://platform.acedata.cloud/documents/development_cursor_coding) |
| **Terminal (CLI)** | Kärnupplevelse, kör `claude` i valfri terminal för att börja | [Terminal konfigurationsguide](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **JetBrains IDE** | Stöd för IntelliJ IDEA, PyCharm, WebStorm och andra JetBrains IDE:er | [JetBrains konfigurationsguide](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automatisera kodgranskning och Issue-hantering med `@claude` | [GitHub Actions konfigurationsguide](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Tips**: För första ansökan, gå till [Claude Messages tjänstesida](https://platform.acedata.cloud/documents/claude-messages) och klicka på "Acquire" för att få dina autentiseringsuppgifter och därmed gratis kvot.
