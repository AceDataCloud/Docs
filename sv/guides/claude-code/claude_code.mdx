Claude Code är en programmeringsagent som lanserats av Anthropic och kan användas i olika miljöer som terminal, IDE, skrivbordsapplikationer med mera. Genom AceData Cloud-agenten kan du använda Claude Code till ett lägre pris.

Vänligen välj den konfigurationsguide som motsvarar din användningssituation:

| Plattform            | Beskrivning                                   | Guide-länk                                                                                                   |
| ------------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **Terminal (CLI)**   | Kärnupplevelse, kör `claude` i valfri terminal för att börja                | [Terminal konfigurationsguide](https://platform.acedata.cloud/documents/claude-code-terminal-integration)                    |
| **VS Code**        | Inbyggd utvidgning, stöd för inline Diff, @-omnämnanden, planerade granskningar            | [VS Code konfigurationsguide](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)               |
| **JetBrains IDE**  | Stöd för IntelliJ IDEA, PyCharm, WebStorm och hela IDE-serien | [JetBrains konfigurationsguide](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)          |
| **GitHub Actions** | Använd `@claude` för att automatisera kodgranskningar och ärendehantering             | [GitHub Actions konfigurationsguide](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Tips**: För första gången kan du gå till [Claude Messages tjänstsida](https://platform.acedata.cloud/documents/claude-messages) och klicka på "Acquire" för att få ett certifikat, vilket ger dig gratis kredit.
