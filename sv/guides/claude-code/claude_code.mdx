Claude Code ansluter till Coding Plan via Anthropic Messages-protokollet, och erbjuder för närvarande två konfigurationsingångar: terminal och VS Code.

| Användningsingång   | Konfigurationsguide                                                                                          |
| ------------------ | ----------------------------------------------------------------------------------------------------------- |
| Terminal / CLI     | [Claude Code terminalkonfiguration](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code            | [Claude Code för VS Code-konfiguration](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## Gemensam konfiguration

- Bas-URL: `https://api.acedata.cloud`
- API-token: Hämta från Coding Application och konfigurera med `ANTHROPIC_AUTH_TOKEN` enligt guiden
- Modell-ID: Välj från den realtidsmodellkatalogen
- Efter att ha ändrat konfigurationen: Starta om Claude Code; VS Code-användare behöver ladda om fönstret

Behåll inte det gamla `ANTHROPIC_API_KEY` samtidigt, och skriv inte in den verkliga token i teamets delade filer.

Återvänd till [Coding Plan konfigurationscenter](https://platform.acedata.cloud/documents/coding-plan-integration).
