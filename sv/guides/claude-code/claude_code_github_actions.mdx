## 1. Hämta API-nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

I det mål-GitHub-förrådet, gå till **Inställningar → Hemligheter och variabler → Åtgärder** och skapa en ny hemlighet:

```text
ACEDATACLOUD_API_KEY
```

## 2. Installera GitHub App

Installera [Claude GitHub App](https://github.com/apps/claude) och ge behörighet till det mål-förrådet. Den officiella appen kommer att begära en fast uppsättning av fullständiga behörigheter; där Claude Code Action faktiskt använder behörigheterna för Innehåll, Problem och Pull-förfrågningar, GitHub installationssidan kan inte bara markera dessa tre. Om organisationen kräver minimi-behörigheter, vänligen skapa en anpassad GitHub App enligt den officiella dokumentationen.

## 3. Lägg till Workflow

Skapa `.github/workflows/claude.yml`:

```yaml
name: Claude Code

on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  claude:
    if: contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      actions: read
      id-token: write
    env:
      ANTHROPIC_BASE_URL: https://api.acedata.cloud
      ANTHROPIC_CUSTOM_HEADERS: "Authorization: Bearer ${{ secrets.ACEDATACLOUD_API_KEY }}"
    steps:
      - uses: actions/checkout@v6
        with:
          fetch-depth: 1
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: dummy-not-used
```

`claude-code-action` kräver en icke-tom `anthropic_api_key` inmatning; här är platshållarvärdet inte avsett för plattformsautentisering. `ANTHROPIC_CUSTOM_HEADERS` kommer att överskrida den Bearer-header som krävs av Ace Data Cloud, den verkliga nyckeln kommer endast från GitHub-hemligheten.

## 4. Verifiera

Efter att ha skickat Workflow, skicka i en Issue eller PR kommentar:

```text
@claude Reply only OK
```

Vid framgång kommer Actions workflow att slutföras och uppdatera resultatet i den motsvarande Issue/PR. Om Action indikerar att det saknas autentisering, bekräfta att `dummy-not-used` fortfarande finns; 401, kontrollera `ACEDATACLOUD_API_KEY` hemlighet. Skriv inte ut hemligheter i loggar. Du kan använda `claude_args` för att ställa in `--max-turns` eller välja den aktuellt tillgängliga modellen, men anslutningsmallen har inte en fast modell.
