## 1. Hämta API-nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installera CLI och plugin

Börja med att installera Claude Code CLI.

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

Installera sedan **Claude Code** plugin från JetBrains Marketplace och starta om IDE. Pluginet anropar det lokala `claude` kommandot; om det visas ett felmeddelande om att kommandot inte kan hittas, fyll i dess fullständiga sökväg i **Inställningar → Verktyg → Claude Code**.

## 3. Konfigurera Ace Data Cloud

Ställ in i miljön där JetBrains backend körs.

macOS / Linux / WSL:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="din API-nyckel"
unset ANTHROPIC_API_KEY
```

Windows PowerShell:

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "din API-nyckel"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

Du kan också använda den ignorerade `.claude/settings.local.json` i projektet:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "din API-nyckel"
  }
}
```

Remote Development måste konfigureras och installeras på den fjärranslutna värden; WSL-användare kan ställa in Claude-kommandot som `wsl -d Ubuntu -- bash -lic "claude"`.

## 4. Verifiera

Kör `claude` från IDE:s integrerade terminal, eller starta en extern terminal och skriv in `/ide`. När anslutningen är framgångsrik, låt Claude svara med `OK`, läs sedan en testfil och kontrollera begäran i Ace Data Cloud [användningshistorik](https://platform.acedata.cloud/console/usages).

Om pluginet inte kan starta, kör först `claude --version` i samma terminal; 401, kontrollera då de faktiska miljövariablerna som backend ärver och den gamla `ANTHROPIC_API_KEY`.
