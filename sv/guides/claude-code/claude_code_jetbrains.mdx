Claude Code är ett **Agentic Coding** verktyg som lanserats av Anthropic, och det kallas också en av världens mest kraftfulla programmeringsagenter. Claude Code erbjuder en plugin specifikt för JetBrains IDE, som stöder hela serien av JetBrains IDE inklusive IntelliJ IDEA, PyCharm, WebStorm, GoLand, PhpStorm, Android Studio med mera.

Detta dokument beskriver hur man konfigurerar och använder Claude Code i JetBrains IDE via AceData Clouds proxy-tjänst.

## Ansökningsprocess

För att använda Claude Code kan du först gå till [Claude Messages tjänstsidan](https://platform.acedata.cloud/documents/claude-messages) och klicka på "Acquire" knappen för att få de nödvändiga autentiseringsuppgifterna:

![](https://cdn.acedata.cloud/nyq0xz.png)

Om du inte är inloggad eller registrerad kommer du automatiskt att omdirigeras till inloggningssidan för att registrera dig och logga in, och efter inloggning kommer du automatiskt att återvända till den aktuella sidan.

Vid första ansökan får du en gratis kvot för att prova Claude Code-tjänsten.

## Installation

### Förutsättningar

Claude Code JetBrains-plugin är beroende av Claude Code CLI, så se till att CLI är installerat:

```bash
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# Eller använd Homebrew
brew install claude-code
```

Efter installationen kan du verifiera:

```bash
claude --version
```

### Installera plugin

![Claude Code-plugin i JetBrains Marketplace](https://cdn.acedata.cloud/de78fd305b.png)

1. Öppna JetBrains IDE
2. Gå till **Settings** → **Plugins** → **Marketplace**
3. Sök efter **Claude Code**
4. Klicka på **Install** för att installera plugin
5. Starta om IDE

Eller besök direkt [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/27310-claude-code-beta-) för att installera online.

> **Viktigt**: Efter installation av plugin måste du **starta om IDE helt** (kan kräva flera omstarter) för att det ska träda i kraft.

## Konfigurera AceData Cloud API

Claude Code JetBrains-plugin kör `claude` kommandot via den integrerade terminalen, så miljövariabelkonfigurationen är densamma som för CLI.

### Steg ett: Skapa config.json

Skapa konfigurationsfilen för Claude Code:

| System                | Sökväg                                   |
| ----------------- | ------------------------------------ |
| **macOS / Linux** | `~/.claude/config.json`              |
| **Windows**       | `C:\Users\{användarnamn}\.claude\config.json` |

Skriv följande innehåll i filen och spara:

```json
{
  "primaryApiKey": "self"
}
```

Snabbkommandon för att skapa på macOS / Linux:

```bash
mkdir -p ~/.claude && echo '{"primaryApiKey": "self"}' > ~/.claude/config.json
```

### Steg två: Konfigurera miljövariabler

**Metod ett: Ställ in i Shell-konfigurationsfil (rekommenderas)**

Lägg till följande innehåll i din `~/.zshrc` eller `~/.bashrc`, och ersätt `{token}` med din API-token:

```bash
# AceData Cloud - Claude Code proxykonfiguration
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Kör `source ~/.zshrc` efter ändringen för att aktivera konfigurationen, och **starta om JetBrains IDE**.

**Metod två: Ställ in i Claude Code settings.json**

Redigera `~/.claude/settings.json` (skapa om den inte finns):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Tips**: API-token kan ses i [AceData Cloud-konsolen](https://platform.acedata.cloud/console).

## Grundläggande användning

### Starta från IDE:s integrerade terminal

Öppna den integrerade terminalen i JetBrains IDE och kör:

```bash
claude
```

När du kör i IDE:s integrerade terminal aktiveras alla integrerade funktioner (Diff-vy, kontextval med mera) automatiskt.

### Anslut från extern terminal

Om du kör Claude Code från en extern terminal kan du använda kommandot `/ide` för att ansluta till JetBrains IDE:

```bash
claude
> /ide
```

Se till att starta Claude Code från samma sökväg som IDE:s projektrot, så att Claude kan få tillgång till samma uppsättning filer.

### Kortkommandon

| Kortkommando                                      | Funktion                      |
| ------------------------------------------------ | ----------------------- |
| `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux)        | Öppna Claude Code snabbt        |
| `Cmd+Option+K` (Mac) / `Alt+Ctrl+K` (Windows/Linux) | Infoga filreferens (t.ex. `@File#L1-99`) |

### Integrerade funktioner

Claude Code JetBrains-plugin erbjuder följande integrerade funktioner:

- **Diff-vy**: Kodändringar visas direkt i IDE:s Diff-visare
- **Välj kontext**: Den aktuellt valda koden och fliken delas automatiskt med Claude
- **Filreferens**: Använd kortkommandon för att snabbt referera till filer och radnummer
- **Diagnosdelning**: Diagnosinformation som Lint, syntaxfel med mera i IDE delas automatiskt med Claude

## Plugin-inställningar

I **Settings** → **Tools** → **Claude Code [Beta]** kan du konfigurera:

| Inställning                        | Beskrivning                                         |
| ----------------------------- | ------------------------------------------ |
| **Claude command**            | Anpassa sökvägen för Claude-kommandot (t.ex. `/usr/local/bin/claude`) |
| **Aktivera automatiska uppdateringar**  | Kontrollera och installera pluginuppdateringar automatiskt                                |
| **Aktivera användning av Option+Enter** | Använd Option+Enter för att bryta rad i dialogrutor på macOS             |

### WSL-användarkonfiguration

Om du använder WSL-miljö måste du ställa in Claude command till:

```
wsl -d Ubuntu -- bash -lic "claude"
```

(ersätt `Ubuntu` med namnet på din WSL-distribution)

## Vanliga frågor

### Vad gör jag om anslutningen misslyckas?

1. Kontrollera att `~/.claude/config.json`-filen har skapats korrekt
2. Bekräfta att miljövariablerna har ställts in korrekt
3. Bekräfta att API-token är giltig (kan ses i [konsolen](https://platform.acedata.cloud/console))
4. Starta om JetBrains IDE och försök igen

### Vad gör jag om plugin inte fungerar?

1. Se till att köra Claude Code från projektets rotmapp
2. Kontrollera att plugin är aktiverad i IDE:s inställningar
3. Starta om IDE helt (kan kräva flera omstarter)
4. Om du använder fjärrutvecklingsläge, se till att plugin är installerad på den fjärranslutna värden (Settings → Plugin (Host))

### IDE upptäcktes inte?

1. Bekräfta att plugin är installerad och aktiverad
2. Starta om IDE
3. Se till att köra Claude Code i den integrerade terminalen
4. WSL-användare bör se [WSL-felsökningsguiden](https://code.claude.com/docs/en/troubleshooting#jetbrains-ide-not-detected-on-wsl2)

### command not found

Om du får meddelandet "command not found" när du klickar på Claude-ikonen:

1. Bekräfta att CLI är installerad: `which claude`
2. Konfigurera den fullständiga sökvägen för Claude-kommandot i plugin-inställningarna
3. WSL-användare bör använda ovanstående WSL-kommandostruktur
### Hur man ser saldo kvar?

Logga in på [AceData Cloud-konsolen](https://platform.acedata.cloud/console) för att se det aktuella kontots saldo och användning.
