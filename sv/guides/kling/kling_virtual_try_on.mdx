Skicka in en uppgift via `POST /kling/virtual-try-on` och använd befintliga `POST /kling/tasks` för att fråga efter plattformsuppgiftens status.

## Indata

Exakt en product_image och en person_image måste tillhandahållas. keep_face, keep_pose och keep_background är alla true som standard och kan stängas av separat. Indatabildernas längsta sida får inte överstiga 2048px, den kortaste sidan måste vara större än 300px och filen får inte överstiga 10MB.

Nedan följer ett exempel på begäransstruktur. Ersätt materialets URL:er innan anropet görs.

```json
{
  "contents": [
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "person_image",
      "url": "https://your-cdn.example/person.jpg"
    }
  ],
  "async": true
}
```

## Resultat och debitering

Synkront läge returnerar det genererade resultatet; asynkront läge returnerar först `task_id`, och det slutförda resultatet innehåller video- eller bildlänkar i `data` samt serverberäknad `usage`. `callback_url` används för slutförandenotifieringar; en begäran med `watermark=true` returnerar samtidigt en version med vattenstämpel.

1,12 Credits/bild, debiteras utifrån det faktiska antalet producerade bilder. Videor debiteras utifrån den faktiskt genererade längden, och grundpriset per sekund före generering representerar inte den totala kostnaden för hela uppgiften. Misslyckade uppgifter debiteras inte för generering.
