Denna artikel introducerar en integrationsbeskrivning för Kling Videos Generation API, som kan generera officiella Kling-videor genom att mata in anpassade parametrar.

## Ansökningsprocess

För att använda API:et måste du först ansöka om motsvarande tjänst på [Kling Videos Generation API](https://platform.acedata.cloud/documents/3b921a16-a411-4557-8335-53f21d3f9e46). När du går in på sidan klickar du på knappen "Acquire", som visas nedan:

![](https://cdn.acedata.cloud/q6ytrc.png)

Om du inte är inloggad eller registrerad kommer du automatiskt att omdirigeras till inloggningssidan där du kan registrera dig och logga in. Efter inloggning eller registrering återvänder du automatiskt till den aktuella sidan.

Vid första ansökan får du en gratis kvot som gör att du kan använda API:et kostnadsfritt.

## Grundläggande användning

Först bör du förstå den grundläggande användningen, vilket innebär att du matar in prompten `prompt`, genereringsåtgärden `action`, startbildens referenslänk `start_image_url` samt modellen `model` för att få ett bearbetat resultat. Du behöver först skicka ett fält `action` med värdet `text2video`. Det finns huvudsakligen tre åtgärder: text-till-video (`text2video`), bild-till-video (`image2video`) och förlängningsvideo (`extend`). Sedan behöver vi ange modellen `model`. För närvarande finns följande modeller: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1`. Detaljer visas nedan:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" className="m-auto" /></p>

Här ser vi att vi har ställt in Request Headers, inklusive:

- `accept`: önskat format för svaret, här `application/json` (JSON-format).
- `authorization`: API-nyckeln för anrop, som kan väljas från en dropdown efter ansökan.

Dessutom har vi Request Body med följande fält:

- `model`: modellen för videoproduktion, huvudsakligen `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1`.
- `mode`: videoproduktionsläge, valbara värden är standardläge `std`, snabbläge `pro` och ursprungligt 4K-läge `4k`. `4k` stöds endast av `kling-v3` och `kling-v3-omni` och är inte kompatibelt med `camera_control` (kamerakontroll).
- `action`: åtgärden för videoproduktion, huvudsakligen tre typer: text-till-video (`text2video`), bild-till-video (`image2video`), förlängningsvideo (`extend`).
- `start_image_url`: när `image2video` väljs måste en startbildsreferenslänk anges.
- `end_image_url`: valfritt vid bild-till-video, för att specificera slutbild.
- `duration`: videons längd i sekunder. `kling-v3` och `kling-v3-omni` stödjer flexibel längd 3-15 sekunder (heltal), andra modeller stödjer 5 eller 10 sekunder.
- `generate_audio`: om ljud ska genereras samtidigt, valfritt booleanvärde. Stöds av `kling-v3`, `kling-v3-omni` och `kling-v2-6` (endast pro-läge). Standard är `false`.
- `aspect_ratio`: videons bildförhållande, valfritt, stöder `16:9`, `9:16`, `1:1`, standard är `16:9`.
- `cfg_scale`: korrelationsintensitet, intervall [0,1], högre värde ger bättre överensstämmelse med prompten.
- `camera_control`: valfritt, parametrar för kamerarörelse, stöder typ/simple presets samt konfigurationer som horizontal, vertical, pan, tilt, roll, zoom.
- `negative_prompt`: valfritt, negativa promptord som inte ska förekomma, max 200 tecken.
- `element_list`: huvudreferenslista, endast för modellen `kling-video-o1`. Användningsdetaljer finns i [officiell dokumentation](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `video_list`: referensvideor via URL, endast för modellen `kling-video-o1`. Användningsdetaljer finns i [officiell dokumentation](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `prompt`: prompttext.
- `callback_url`: URL för callback vid resultat.

När du valt detta genereras motsvarande kod till höger, som visas nedan:

<p><img src="https://cdn.acedata.cloud/3yjql0.png" width="500" className="m-auto" /></p>

Klicka på knappen "Try" för att testa. Som i bilden ovan får vi följande resultat:

```json
{
  "success": true,
  "video_id": "af9a1af0-9aa0-4638-81c1-d41d6143c508",
```

Resultatet innehåller flera fält, beskrivs nedan:

- `success`: status för videoproduktionsuppgiften.
- `task_id`: ID för videoproduktionsuppgiften.
- `video_id`: video-ID för den genererade videon.
- `video_url`: URL till den genererade videon.
- `duration`: videons längd.
- `state`: status för videoproduktionsuppgiften.

Vi har fått önskad videoinformation och kan hämta den genererade Kling-videon via videons URL i `data`.

Om du vill generera motsvarande integrationskod kan du kopiera den direkt, till exempel CURL-koden nedan:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v1",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## Förlängningsvideofunktion

Om du vill fortsätta generera en redan skapad Kling-video kan du sätta `action` till `extend` och ange video-ID:t för videon som ska förlängas. Video-ID hämtas enligt grundläggande användning, som visas nedan:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Här är video-ID:t:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

> Observera att `video_id` är ID:t för den genererade videon. Om du inte vet hur man genererar video, se grundläggande användning ovan.

Därefter måste du ange prompten för förlängningen för att anpassa videon, med följande parametrar:

- `model`: videomodell, huvudsakligen `kling-v1`, `kling-v1-5` och `kling-v1-6`.
- `mode`: videoläge, valbara är standard `std`, snabb `pro` och ursprungligt 4K `4k` (endast `kling-v3` och `kling-v3-omni`, ej kompatibelt med kamerakontroll).
- `duration`: videons längd, vanligtvis 5 eller 10 sekunder.
- `start_image_url`: vid `image2video` måste startbildsreferens anges.
- `prompt`: prompttext.

Exempel på ifyllnad:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" className="m-auto" /></p>

Efter ifyllnad genereras koden automatiskt:

<p><img src="https://cdn.acedata.cloud/52x4u5.png" width="500" className="m-auto" /></p>

Motsvarande Python-kod:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kör du koden får du ett resultat som nedan:

```json
{
  "success": true,
  "video_id": "bbc3b105-ac72-4de2-8390-0cb37dc7d41e",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/extendVideo/Cjil4mfBfs0AAAAAAKhr6A-0_raw_video_1.mp4",
  "duration": "9.6",
  "state": "succeed",
  "task_id": "3ece87e6-3ee3-4f5e-bd70-5ae5eca89a23"
}
```

Resultatet är i linje med tidigare exempel, vilket visar att förlängningsfunktionen fungerar.

## Asynkron callback

Eftersom generering av Kling Videos Generation API kan ta relativt lång tid, cirka 1-2 minuter, och om API:et inte svarar under lång tid kommer HTTP-förfrågan att hålla anslutningen öppen och orsaka extra systemresursförbrukning, erbjuder API:et även stöd för asynkron callback.

Processen är: klienten skickar en förfrågan och anger extra fältet `callback_url`. Efter att API:et mottagit förfrågan returnerar det omedelbart ett svar med ett `task_id` som identifierar uppgiften. När uppgiften är klar skickar API:et resultatet som en POST med JSON till den angivna `callback_url`, inklusive `task_id`, så att uppgiften kan kopplas ihop via ID.

Nedan följer ett exempel på hur man gör.

Först är webhook callback en tjänst som kan ta emot HTTP-förfrågningar. Utvecklare bör ersätta URL:en med sin egen HTTP-server. För demonstration används en offentlig webhook-webbplats https://webhook.site/, där du får en webhook-URL, som visas nedan:

![](https://cdn.acedata.cloud/tbcnai.png)

Kopiera denna URL och använd den som webhook, i exemplet är det `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`.

Därefter kan vi ange fältet `callback_url` till ovanstående webhook-URL och fylla i övriga parametrar, som visas nedan:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" className="m-auto" /></p>

Kör du detta får du omedelbart ett svar:

```
{
  "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Efter en stund kan du se resultatet av videoproduktionen på `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`, som visas nedan:

![](https://cdn.acedata.cloud/zv5u2q.png)

Innehållet är:

```json

    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/text2video/CjJzzGfBfqcAAAAAAKdVMQ-0_raw_video_1.mp4",
    "duration": "5.1",
    "state": "succeed",
    "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Resultatet innehåller ett `task_id` och övriga fält liknar tidigare exempel. Med detta fält kan du koppla ihop uppgifterna.

## Felhantering

Vid anrop av API:et, om fel uppstår, returnerar API:et motsvarande felkod och meddelande. Exempel:

- `400 token_mismatched`: Bad request, troligen saknade eller ogiltiga parametrar.
- `400 api_not_implemented`: Bad request, troligen saknade eller ogiltiga parametrar.
- `401 invalid_token`: Unauthorized, ogiltig eller saknad auktoriseringstoken.
- `429 too_many_requests`: För många förfrågningar, du har överskridit gränsen.
- `500 api_error`: Intern serverfel, något gick fel på servern.

### Exempel på felrespons

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
