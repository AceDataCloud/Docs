title: "Kling Lip Sync API（可灵对口型 API）"

Låt en **befintlig Kling-video** (5 sekunder eller 10 sekunder) "prata" enligt ljud eller text - det vill säga göra lip sync. Tillsammans med `/kling/videos` `image2video` (få bilder att röra sig), kan det bilda en komplett process för "**pratande bilder / digitala avatarer**".

> Detta gränssnitt är en enkel och bekväm förpackning som tillhandahålls av AceDataCloud, riktad mot vanliga ljud/text-drivna scenarier; det är inte en fältavbildning av Kling officiella "ansiktsigenkänning → Advanced Lip Sync" flerstegsgränssnitt. Vänligen använd parameterlistan på denna sida som referens.

- **API-adress**: `POST https://api.acedata.cloud/kling/lip-sync`
- **Begäran format**: `application/json`
- **Svar format**: `application/json`
- **Avgift**: **2.45 Credits** per lyckad anrop (fast)

## Begärningshuvud (Request Headers)

| Fält              | Värde                   | Beskrivning                                               |
| --------------- | ------------------- | ------------------------------------------------------ |
| `authorization` | `Bearer ${API_KEY}` | Din API-nyckel, [hämtningsadress](https://platform.acedata.cloud) |
| `content-type`  | `application/json`  | Format på begärningskroppen                                   |
| `accept`        | `application/json`  | Svarformat                                                |

## Begärningsparametrar (Request Body)

| Parameter          | Typ      | Obligatorisk  | Standard  | Beskrivning                                                                                                                       |
| ---------------- | ------- | --- | ------- | ------------------------------------------------------------------------------------------------------------------------ |
| `mode`           | string  | Ja   | —       | Genereringsläge. Enum: `audio2video` (ljuddriven), `text2video` (textdriven)                                                                           |
| `video_id`       | string  | Antingen | —       | Kling-genererat videos ID (t.ex. `video_id` som returneras av `/kling/videos` `image2video`). **Endast stöd för 5s/10s video som genererats inom 30 dagar**. `video_id` och `video_url` är ömsesidigt uteslutande |
| `video_url`      | string  | Antingen | —       | Offentligt tillgänglig videolänk. Begränsningar: `.mp4`/`.mov`, ≤100MB, längd 2–10s, endast 720p/1080p, sidlängd 720–1920px. Ömsesidigt uteslutande med `video_id`                                  |
| `audio_url`      | string  | Villkorlig  | —       | Ladda ner URL för ljuddrivning, obligatorisk när `audio2video` + `audio_type=url`. Format `.mp3`/`.wav`/`.m4a`/`.aac`, ≤5MB                                     |
| `audio_type`     | string  | Nej   | `url`   | Ljudöverföringsmetod. Enum: `url`, `file` (gäller för `audio2video`)                                                                                |
| `audio_file`     | string  | Villkorlig  | —       | Ljudfilens Base64, obligatorisk när `audio_type=file`. Format som ovan, ≤5MB                                                                             |
| `text`           | string  | Villkorlig  | —       | Texten som ska läsas, obligatorisk när `text2video`, **max 120 tecken**                                                                                     |
| `voice_id`       | string  | Villkorlig  | —       | Röst-ID, obligatorisk när `text2video`                                                                                                   |
| `voice_language` | string  | Nej   | `zh`    | Röstspråk. Enum: `zh`, `en` (gäller för `text2video`)                                                                                      |
| `voice_speed`    | float   | Nej   | `1.0`   | Talhastighet, intervall `0.8`–`2.0`, med en decimalprecision (gäller för `text2video`)                                                                              |
| `callback_url`   | string  | Nej   | —       | Callback-adress. Om detta anges eller `async=true` så är det **asynkront läge**: returnerar omedelbart `task_id`, callback när resultatet är genererat                                                                 |
| `async`          | boolean | Nej   | `false` | Om det är asynkront. `true` returnerar omedelbart `task_id`, i kombination med `/kling/tasks` för polling eller `callback_url` callback                                                      |

## Begärningsexempel

### 1）Ljuddriven (audio2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2）Textdriven (text2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "Bror, länge sen vi sågs, jag mår bra, ta hand om dig själv.",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## Svarsexempel (synchroniserad framgång)

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| Fält          | Typ      | Beskrivning                                         |
| ----------- | ------- | ------------------------------------------ |
| `success`   | boolean | Om det var framgångsrikt                                       |
| `task_id`   | string  | ID för denna uppgift (kan användas för att fråga `/kling/tasks`)             |
| `video_id`  | string  | Kling ID för den genererade videon (kan användas som input för nästa `extend`/`lip-sync`) |
| `video_url` | string  | URL för den genererade talande videon (har överförts till denna plattforms CDN, långvarig giltighet)              |
| `duration`  | string  | Videolängd (sekunder)                                    |
| `state`     | string  | Uppgiftsstatus: `succeed` / `failed`                  |

## Asynkront läge och förfrågan

När `callback_url` eller `async: true` anges, returnerar gränssnittet **omedelbart** `task_id`; därefter kan du:

- **Polling**: `POST /kling/tasks`, body `{ "action": "retrieve", "id": "<task_id>" }` (gratis)
- **Callback**: När genereringen är klar, POST-resultatet till din `callback_url`

## Fullständig process: Pratande bilder (image2video → lip-sync)
```bash
# Steg 1: Få fotot att röra sig, få video_id
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"look at camera, natural","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# Steg 2: Synka läppar med ljud
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"}'
# → { "video_url": "https://platform2.cdn.acedata.cloud/kling/....mp4", ... }
```

## Felrespons

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "en av video_id eller video_url krävs" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | kod                    | Betydelse                                             |
| ---- | --------------------- | --------------------------------------------------- |
| 400  | `bad_request`         | Parameter saknas eller är ogiltig (t.ex. om mode, video och audio är i konflikt, text över 120 tecken) |
| 401  | `authorization_missing` | Saknad eller ogiltig API-nyckel                             |
| 403  | `forbidden`           | Innehållet har blockerats av riskhantering                |
| 429  | `too_many_requests`   | Övergripande samtidighetsbegränsning, försök igen senare     |
| 500  | `api_error`           | Övergripande eller internt fel                            |

## Viktiga punkter

- `video_id` måste vara en **giltig video** som skapats inom **30 dagar** och vara **5s eller 10s**; annars använd `video_url` för att skicka en video som uppfyller kraven.
- Inmatad video rekommenderas att vara **klar, rakt framifrån, en person**, för bästa läppsynk.
- Längden på ljud/text bör matcha videons längd (ljud får inte överstiga videons längd).
- Avgifter debiteras vid **framgång** (2.45 Credits/gång); parameterkontrollfel (4xx) debiteras inte.
