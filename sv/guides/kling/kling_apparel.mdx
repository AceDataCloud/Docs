Skicka in uppgifter via `POST /kling/apparel` och använd befintliga `POST /kling/tasks` för att kontrollera plattformens uppgiftsstatus.

## Indata

Tillhandahåll en produktbeskrivning på högst 2500 tecken, en referensvideo på 5–180 sekunder och 1–5 produktbilder. Du kan dessutom tillhandahålla 1–5 modellbilder, en bakgrundsmusikfil samt ange en röst för voice-over; om ingen röst anges används originaltal.

Följande är ett exempel på begärans struktur. Ersätt material-URL:erna innan anropet görs.

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "Din produkt eller ditt talinnehåll"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## Resultat och debitering

Synkront läge returnerar det genererade resultatet; asynkront läge returnerar först `task_id`, och det slutförda resultatet innehåller video- eller bildlänkar i `data` samt serverberäknad `usage`. `callback_url` används för slutförandenotifieringar; begäran med `watermark=true` returnerar samtidigt en vattenmärkt version.

Originaltal: 720p kostar 1,82 Credits/sekund och 1080p kostar 2,38 Credits/sekund; angiven voice-over: 720p kostar 2,38 Credits/sekund och 1080p kostar 2,8 Credits/sekund. Videor debiteras efter den faktiska genererade längden, och grundpriset per sekund före generering representerar inte den totala kostnaden för hela uppgiften. Misslyckade uppgifter debiteras inte någon genereringsavgift.
