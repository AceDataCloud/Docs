---
title: "Kling Talande Foto API（Kling Talking Photo）"
description: "Kling video generation API guide - Ace Data Cloud"
---

En knapptryckning för att göra **ett foto + ett ljud** till en "talande video". Tjänsten utför automatiskt två steg: först använder den image2video för att få fotot att röra sig, och sedan använder den lip-sync för att synkronisera med ljudet. Du behöver bara anropa **en gång**.

- **API-adress**: `POST https://api.acedata.cloud/kling/talking-photo`
- **Avgift**: per längd, 5 sekunder **16.45 Credits**, 10 sekunder **30.45 Credits** (= image2video + lip-sync kombinationspris)

## Begärningshuvud

| Fält              | Värde                  |
| ---------------- | --------------------- |
| `authorization`  | `Bearer ${API_KEY}`   |
| `content-type`   | `application/json`    |

## Begärningsparametrar

| Parameter        | Typ      | Obligatorisk | Standard              | Beskrivning                                |
| ---------------- | ------- | ------------ | --------------------- | ------------------------------------------ |
| `image_url`      | string  | Ja           | —                     | Offentlig URL för personfoto, rekommenderas att vara tydlig och framifrån |
| `audio_url`      | string  | Ja           | —                     | Offentlig URL för ljud ( .mp3/.wav/.m4a/.aac, ≤5MB) |
| `prompt`         | string  | Nej          | —                     | Åtgärder/uttryck för fotots animeringsfas  |
| `model`          | string  | Nej          | `kling-v2-1-master`  | Kling-modell som används för fotots animering |
| `duration`       | integer | Nej          | `5`                   | Videolängd (5 eller 10 sekunder)          |
| `mode`           | string  | Nej          | `pro`                 | Animeringskvalitet (std/pro)              |
| `callback_url`   | string  | Nej          | —                     | Om angiven eller `async=true` returneras task_id asynkront |
| `async`          | boolean | Nej          | `false`               | Asynkront läge, används med `/kling/tasks` för polling eller callback |

## Begärningsexempel

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Svarsexempel

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "source_video_url": "https://platform2.cdn.acedata.cloud/kling/163ac822-1a15-4f5e-a2eb-465154df15af.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Fält                 | Beskrivning                              |
| ------------------- | ---------------------------------------- |
| `video_url`         | Den slutliga talande videon (har sparats på plattformens CDN) |
| `source_video_url`  | Det mellanliggande fotoanimationsvideon (image2video resultat) |
| `video_id`          | Kling video ID                           |

## Viktiga punkter

- Fotot rekommenderas att vara tydligt, framifrån och en person.
- Längden på ljudet rekommenderas att inte överstiga videolängden (5s/10s).
- Avgiften debiteras vid framgång; parameterkontrollfel (4xx) debiteras inte.
- Generering tar cirka 4–6 minuter (två steg), rekommenderas att använda `async=true` + `/kling/tasks` för polling.
