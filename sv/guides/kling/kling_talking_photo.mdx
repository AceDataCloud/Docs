---
title: "Kling pratande foto API (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Förvandla med ett klick **ett foto + ett ljudklipp** till en "pratande video". Tjänsten slutför automatiskt två steg internt: först används image2video för att få fotot att röra sig, sedan används lip-sync för att synkronisera läpparna med ljudet. Du behöver bara anropa **en gång**.

- **API-adress**：`POST https://api.acedata.cloud/kling/talking-photo`
- **Debitering**：efter längd, 5 sekunder **16.45 Credits**, 10 sekunder **30.45 Credits** (= kombinerat pris för image2video + lip-sync)

## Begärandehuvuden

| Fält              | Värde                   |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## Begärandeparametrar

| Parameter             | Typ      | Obligatorisk  | Standard                  | Beskrivning                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | Ja   | —                   | Offentlig URL till ett personfoto, ett tydligt ansikte framifrån rekommenderas                    |
| `audio_url`    | string  | Ja   | —                   | Offentlig URL till ljudet som ska användas (.mp3/.wav/.m4a/.aac, ≤5 MB) |
| `prompt`       | string  | Nej   | —                   | Prompt för rörelser/ansiktsuttryck under fotoanimeringssteget                      |
| `model`        | string  | Nej   | `kling-v2-1-master` | Kling-modellen som används för fotoanimering                     |
| `duration`     | integer | Nej   | `5`                 | Videolängd (5 eller 10 sekunder)                        |
| `mode`         | string  | Nej   | `pro`               | Animeringskvalitet (std/pro)                        |
| `callback_url` | string  | Nej   | —                   | Skicka in eller använd `async=true` för att asynkront returnera task_id        |
| `async`        | boolean | Nej   | `false`             | Asynkront läge, använd tillsammans med polling eller återanrop via `/kling/tasks`          |

## Exempel på begäran

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Exempel på svar

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Fält                 | Beskrivning                        |
| ------------------ | ------------------------- |
| `video_url`        | Den slutliga pratande videon (har sparats på denna plattforms CDN)      |
| `source_video_url` | Den mellanliggande fotoanimerade videon (image2video-resultat) |
| `video_id`         | Kling-video-ID                   |

## Anmärkningar

- För fotot rekommenderas ett tydligt ansikte framifrån och en enda person.
- Ljudlängden rekommenderas att inte överstiga videolängden (5 s/10 s).
- Debitering sker vid lyckad genomföring; misslyckad parametervalidering (4xx) debiteras inte.
- Genereringstiden är cirka 4–6 minuter (två steg); det rekommenderas att använda `async=true` + polling via `/kling/tasks`.
