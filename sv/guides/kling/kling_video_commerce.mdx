Skicka in en uppgift via `POST /kling/video-commerce` och använd befintliga `POST /kling/tasks` för att kontrollera statusen för plattformsuppgifter.

## Indata

Ladda upp en personbild och ange voice_id, eller använd ett förinställt avatar_id (de två utesluter varandra, och förinställda personer kan inte dessutom ange voice_id). Du måste ange ett speech_script på högst 2000 tecken. När produktinformation anges krävs minst en ref_image och en goods_title; produktmuntlig presentation stöder inte speech_rate. Vanlig muntlig presentation med person stöder 0,8, 1,0 eller 1,2 gånger talhastigheten.

Följande är ett exempel på begäransstruktur. Ersätt material-URL:erna innan anropet görs.

```json
{
  "contents": [
    {
      "type": "avatar_image",
      "url": "https://your-cdn.example/person.jpg"
    },
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    },
    {
      "type": "speech_script",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "voice_id": "male_calm_informative"
  },
  "async": true
}
```

## Resultat och debitering

Synkront läge returnerar genereringsresultatet; asynkront läge returnerar först `task_id`, och det färdiga resultatet innehåller video- eller bildlänkar i `data` samt serverberäknad `usage`. `callback_url` används för meddelande vid slutförande; begäran med `watermark=true` returnerar samtidigt en version med vattenstämpel.

Vanlig muntlig presentation med person: 720p kostar 1,4 Credits/sekund och 1080p kostar 1,68 Credits/sekund; produktmuntlig presentation: 720p kostar 1,96 Credits/sekund och 1080p kostar 2,24 Credits/sekund. Videor debiteras enligt den faktiska genererade längden, och grundpriset per sekund före generering representerar inte den totala kostnaden för hela uppgiften. Misslyckade uppgifter debiteras inte för generering.
