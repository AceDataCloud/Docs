Skicka in en uppgift via `POST /kling/goods-studio`, och använd den befintliga `POST /kling/tasks` för att kontrollera plattformsuppgiftens status.

## Indata

Tillhandahåll 1–5 produktbilder och en produkttitel på högst 200 tecken; produktbeskrivning är valfri, högst 2000 tecken. Längden kan vara 15, 30 eller 60 sekunder.

Följande är ett exempel på begärans struktur, ersätt materialets URL innan anropet.

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## Resultat och debitering

Synkront läge returnerar genereringsresultatet; asynkront läge returnerar först `task_id`, och det slutförda resultatet innehåller video- eller bildlänkar i `data` samt serverberäknad `usage`. `callback_url` används för slutförandenotifieringar; begäran med `watermark=true` returnerar även en version med vattenstämpel.

720p: 2,38 Credits/sekund; 1080p: 2,8 Credits/sekund. Videor debiteras utifrån den faktiska genererade längden, och grundpriset per sekund före generering representerar inte det totala priset för hela uppgiften. Misslyckade uppgifter debiteras inte för generering.
