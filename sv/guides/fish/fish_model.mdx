Detta gränssnitt baseras på [Fish Audio officiella Model API](https://docs.fish.audio/resources/api-reference/model) och används för att **skapa en klonad röstmodell som kan återanvändas långsiktigt baserat på ett ljudprov**. Adressen är `POST https://api.acedata.cloud/fish/model`.

> När referensrösten bara behöver användas tillfälligt finns det inget behov av att skapa en modell; du kan direkt använda [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) och `references` för omedelbar engångskloning. För sidindelad hämtning av befintliga röster, se [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query); för att fråga efter detaljer för en enskild röst med `_id`, se [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Ansökningsprocess

För att använda Fish Model API, gå först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API Token och spara den för senare användning.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig, omdirigeras du automatiskt till inloggningssidan där du uppmanas att registrera dig och logga in. När detta är klart återgår du automatiskt till den aktuella sidan.

**En API Token kan anropa alla plattformens tjänster, och du behöver inte ansöka separat för varje tjänst.** Vid första ansökan får du gratis kvot för att kunna prova tjänsten kostnadsfritt; när kvoten är otillräcklig kan du fylla på det gemensamma saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Fält i begärandetexten

| Fält                      | Typ       | Obligatoriskt  | Beskrivning                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | Ja   | Röstnamn, används för identifiering i konsollistan.                                                             |
| `voices`                | string   | Ja   | HTTP(S)-URL för ljudprovet (**en enskild sträng**, inte en array). Detta gränssnitt stöder inte multipart-/binär uppladdning; placera först ljudet i valfri offentligt åtkomlig objektlagring. |
| `description`           | string   | Nej   | Röstbeskrivning.                                                                         |
| `cover_image`           | string   | Nej   | HTTP(S)-URL för omslagsbilden.                                                              |
| `tags`                  | string[] | Nej   | Söketiketter för det offentliga biblioteket, till exempel `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | Nej   | Referenstext som motsvarar provet (används för att korrigera uttal).                                                           |
| `enhance_audio_quality` | boolean  | Nej   | Om ljudkvaliteten för provet ska förbättras före träning.                                                                |
| `generate_sample`       | boolean  | Nej   | Om ett exempelklipp automatiskt ska genereras efter att träningen har slutförts.                                                            |

> För mer information om röstmodeller, se [Fish officiella dokumentation](https://docs.fish.audio/resources/api-reference/model).

> De skapade rösterna sparas offentligt under lång tid, och andra användare kan söka efter och använda dem. Du behöver inte skicka `visibility`; även om `private` eller `unlist` skickas in kommer det aktuella gränssnittet inte att ändra offentlighetsomfånget baserat på detta.

## Exempel: Skapa en offentlig klonad röst

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的中文音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Obs: `voices` måste vara en **sträng** (en enskild ljud-URL), inte en array. Det går inte att skicka `["..."]`. Vi rekommenderar att använda en direktlänk som kan laddas ned offentligt och har suffixet `.mp3` eller `.wav`.

Ett lyckat svar returnerar direkt ett ModelEntity-objekt från Fish-plattformen (exemplet nedan är den minsta fungerande röst som vi har testat. Vissa långa fält har tagits bort för att underlätta läsningen):

`_id` kan sedan användas som värde för fältet `reference_id` i [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) för att generera tal med denna klonade röst:

Röster som skapats framgångsrikt sparas offentligt. Via `self=true` i [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query) kan du fråga efter röster som den aktuella anropande användaren har skapat via denna plattform. `self=true` filtrerar endast listan och begränsar inte andra användares användning av rösten.

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，这是一段使用我刚创建的克隆音色合成的语音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Krav på ljudprov

Rekommendationer (se [Fish officiella dokumentation](https://docs.fish.audio/resources/api-reference/model) för mer information):

- En längd på minst 30 sekunder rekommenderas, med bäst resultat inom 5 minuter; över 10 minuter ger begränsad extra nytta.
- Samplingsfrekvens på 16 kHz eller högre; mono eller stereo fungerar båda.
- Innehållet bör vara så rent som möjligt: ingen bakgrundsmusik, inget eko eller tydligt omgivningsljud; samma talare.
- Rekommenderade format: `mp3` / `wav`.

Om du är osäker på ljudprovets kvalitet kan du även skicka `enhance_audio_quality: true` för att aktivera förbättring av ljudkvaliteten.

## Prisbeskrivning
Att skapa en röstkloningsmodell (`POST /fish/model`) är gratis och medför inga avgifter; gränssnitten för att söka röstklanger ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query), [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) är också kostnadsfria. Avgifter uppstår endast baserat på användning när [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) senare anropas för att syntetisera tal.

## Felhantering

- `400 token_mismatched`: Begärandeparametrar saknas eller är ogiltiga (oftast är `voices` inte en URL eller har skickats som en array).
- `400`: När referensljudet inte kan laddas ned, är för kort eller formatet inte kan identifieras, kontrollera ljud-URL:en och filformatet.
- `401 invalid_token`: Autentiseringstoken saknas eller är ogiltig.
- `429 too_many_requests`: Kontots hastighetsgräns har utlösts.
- `500 api_error`: Internt serverfel.

Exempel på felsvar:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Slutsats

För att anropa detta gränssnitt behöver du endast förbereda en offentligt tillgänglig URL för ett exempelljud, placera den i fältet `voices` för att få `_id`, och sedan ange den till `reference_id` för `/fish/tts` för att slutföra hela flödet ”kloning → syntes”. En vanlig fallgrop är att `voices` måste vara en sträng och inte kan vara en array.

## Skapa och återanvänd röstklanger via MCP

Anropa följande i Fish MCP:
`fish_create_model(title="Min röstklang", voices="https://example.com/authorized-voice.wav")`.
`voices` är en enskild HTTP(S)-URL för ljud; du kan även skicka `description`, `cover_image`, `tags`,
`texts`, `enhance_audio_quality`, `generate_sample`.

Detta verktyg sparar offentliga röstklanger långsiktigt, och andra användare kan upptäcka och använda dem; använd endast
ljudmaterial som du har tillstånd att behandla och offentliggöra. Verktyget har inget privat eller icke-offentligt alternativ. Den `_id` som returneras efter lyckad skapelse används för
`reference_id` i `fish_generate_audio`, och `fish_list_models(self=true)` kan användas för att söka bland de röstklanger du själv
har sparat. När en referensröst endast behövs en enda gång, använd `references` i `fish_generate_audio`,
utan att skapa en långsiktig röstklang.
