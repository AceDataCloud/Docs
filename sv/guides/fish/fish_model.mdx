Detta gränssnitt är baserat på [Fish Audio officiella Model API](https://docs.fish.audio/resources/api-reference/model) och används för att **skapa en klon av ljudmodell som kan återanvändas långsiktigt baserat på ett ljudprov**. Adressen är `POST https://api.acedata.cloud/fish/model`.

> Om du bara tillfälligt behöver använda referensljud, behöver du inte skapa en modell, utan kan direkt använda [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) `references` för engångskloning. För att paginera och hämta befintliga ljudfärger, se [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query); för att söka detaljer om enskilda ljudfärger baserat på `_id`, se [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Ansökningsprocess

För att använda Fish Model API, börja med att gå till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att få din API-token, som du ska spara.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du inte har loggat in eller registrerat dig, kommer du automatiskt att omdirigeras till inloggningssidan för att registrera dig och logga in, och efter att du har slutfört detta kommer du automatiskt att återvända till den aktuella sidan.

**En API-token räcker för att anropa alla plattformens tjänster, du behöver inte ansöka separat för varje tjänst.** Första ansökan ger en gratis kvot för att prova; när kvoten är slut kan du ladda på allmän balans i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Begärningskroppsfält

| Fält                     | Typ      | Obligatoriskt | Beskrivning                                                                      |
| ----------------------- | -------- | ------------- | -------------------------------------------------------------------------------- |
| `title`                 | string   | Ja            | Ljudfärgens namn, används för att identifiera i konsolens lista.                |
| `voices`                | string   | Ja            | HTTP(S) URL för ljudprovet (**en enda sträng**, inte en array). Detta gränssnitt stöder inte multipart/binary uppladdning, vänligen lägg ljudet i en offentligt tillgänglig objektlagring först. |
| `description`           | string   | Nej           | Beskrivning av ljudfärgen.                                                       |
| `cover_image`           | string   | Nej           | HTTP(S) URL för omslagsbild.                                                    |
| `tags`                  | string[] | Nej           | Taggar för att söka i det offentliga biblioteket, till exempel `["male","narration","zh"]`. |
| `texts`                 | string[] | Nej           | Referenstexter som motsvarar provet (används för att korrigera uttal).          |
| `enhance_audio_quality` | boolean  | Nej           | Om ljudkvaliteten ska förbättras före träning.                                   |
| `generate_sample`       | boolean  | Nej           | Om en exempel ljudfil ska genereras automatiskt efter att träningen är klar.     |

> Fälten är helt identiska med upstream, vänligen se även [Fish officiella dokumentation](https://docs.fish.audio/resources/api-reference/model).

## Exempel: Skapa en privat klonljudfärg

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "Min klonljudfärg",
    "description": "Klonad kinesisk ljudfärg från en podcastinspelning",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Observera: `voices` måste vara en **sträng** (en enda ljud-URL), inte en array. Om det skickas som `["..."]` kommer upstream att avvisa det.

Ett framgångsrikt svar returnerar direkt Fish-plattformens ModelEntity-objekt (nedan är vårt testade minimi-användbara ljudfärg, vissa långa fält har tagits bort för läsbarhet):

`_id` kan användas som värdet för `reference_id`-fältet i efterföljande [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) för att använda den klonade ljudfärgen för talgenerering:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hej, detta är en röst som genererats med min nyss skapade klonljudfärg.",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Provkrav

Erfarenhetsvärden (enligt upstream, se [Fish officiella dokumentation](https://docs.fish.audio/resources/api-reference/model)):

- Längden bör vara över 30 sekunder och under 5 minuter för bästa resultat; över 10 minuter ger inte mycket mer värde.
- Samplingsfrekvens 16 kHz eller högre, mono eller stereo är okej.
- Innehållet bör vara så rent som möjligt: ingen bakgrundsmusik, ekon, uppenbart miljöljud; samma talare.
- Format rekommenderas `mp3` / `wav`.

Om du är osäker på provkvaliteten kan du samtidigt skicka `enhance_audio_quality: true` för att låta upstream först förbättra ljudkvaliteten.

## Avgiftsinformation

Att skapa en klonljudmodell (`POST /fish/model`) är gratis och kostar inget; ljudfärgens sökgränssnitt ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query), [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) debiteras inte heller. Avgifter uppstår endast vid efterföljande anrop av [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) för talgenerering.

## Felhantering
- `400 token_mismatched`：Begärningsparametrar saknas eller är ogiltiga (det vanligaste är att `voices` inte är en URL, eller att det har skickats som en array).
- `401 invalid_token`：Autentiseringstoken finns inte eller är ogiltig.
- `429 too_many_requests`：Uppnått konto hastighetsbegränsning.
- `500 api_error`：Intern serverfel.

Exempel på felrespons:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices är obligatoriskt och måste vara en HTTP(S) URL som pekar på en ljudfil"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Slutsats

För att anropa detta gränssnitt behöver du bara förbereda en offentligt tillgänglig provljud-URL, sätta den i `voices`-fältet för att få `_id`, och sedan ge den till `/fish/tts` som `reference_id` för att slutföra end-to-end "kloning → syntes". Vanliga fallgropar är att `voices` måste vara en sträng, inte en array.
