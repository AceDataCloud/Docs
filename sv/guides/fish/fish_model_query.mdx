Detta gränssnitt är baserat på [Fish Audio officiella Model API](https://docs.fish.audio/resources/api-reference/model) och används för **sidesökning av Fish offentliga ljudbibliotek eller klonade ljud från det aktuella kontot**. Adressen är `GET https://api.acedata.cloud/fish/model`.

> För att skapa ljud, vänligen se [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); för att söka efter detaljer om ett enskilt ljud baserat på `_id`, se [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Ansökningsprocess

För att använda Fish Model API, börja med att gå till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att få din API-token, som du kan spara för framtida bruk.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du inte har loggat in eller registrerat dig, kommer du automatiskt att omdirigeras till inloggningssidan för att registrera dig och logga in, och efter att ha slutfört detta kommer du automatiskt att återvända till den aktuella sidan.

**En API-token räcker för att anropa alla tjänster på plattformen, det behövs ingen separat ansökan för varje tjänst.** Första ansökan ger en gratis kvot för att prova; när kvoten är slut kan du ladda på allmänna medel i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Frågeparametrar

| Parameter         | Typ      | Standard | Beskrivning                                 |
| ----------------- | -------- | -------- | ------------------------------------------- |
| `page_size`      | integer  | 10       | Antal poster per sida.                     |
| `page_number`    | integer  | 1        | Sidnummer som börjar från 1.               |
| `title`          | string   | —        | Sök med fuzzy matchning på titeln.         |
| `tag`            | string   | —        | Filtrera med enskild tagg.                 |
| `self`           | boolean  | —        | När `true` returneras endast ljud skapade av det aktuella kontot, utan några ytterligare villkor. |
| `author_id`      | string   | —        | Filtrera med upstream-användarens `_id`.   |
| `language`       | string   | —        | Filtrera med ljudets språk, som `en`, `zh`, `es`. |
| `title_language` | string   | —        | Filtrera med titelspråk.                   |
| `sort_by`        | string   | —        | Sorteringsfält, samma som upstream, som `created_at`, `task_count`. |

> Parameternamnen är helt identiska med upstream `GET https://api.fish.audio/model`, se [Fish officiella dokumentation](https://docs.fish.audio/resources/api-reference/model).

## Exempel 1: Standard paginering (enligt `page_size`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=2'
```

## Exempel 2: Fuzzy sökning efter titel (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Svar (testat):

```json
{
  "total": 161,
  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",
      "type": "tts",
      "title": "Miles Morales ( Narration Paw )",
      "tags": ["male", "middle-aged", "entertainment", "storytelling", "Children's Content"],
      "languages": ["en"],
      "visibility": "public",
      "task_count": 770
    },
    {
      "_id": "76b55591c758444cb95253708696dfad",
      "type": "tts",
      "title": "Joe NARRATION",
      "tags": ["male", "middle-aged", "narration", "deep", "raspy"],
      "languages": ["en"],
      "visibility": "public"

```

Observera att `title` är en "global fuzzy match", som kommer att träffa alla ljud i Fish offentliga bibliotek (inte bara dina egna).

## Exempel 3: Lista endast ljud skapade av dig själv (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Svar (testat, det aktuella kontot har endast 1 ljud):

## Exempel 4: Filtrera efter språk + tagg
```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> Uppströms kommer att returnera resultat för `tag` som inte finns i taggordlistan, men matchningen är relativt lös; om antalet träffar är 0, rekommenderas att använda `title` för fuzzy matchning.

## Svarsfält

Varje post i `items[]` är ett komplett ModelEntity-objekt, vanliga fält:

| Fält            | Typ       | Beskrivning                                          |
| ------------- | -------- | ------------------------------------------------- |
| `_id`         | string   | Röst-ID, som värde för `reference_id` i `/fish/tts`.         |
| `type`        | string   | Modelltyp, vanligtvis `tts`.                                   |
| `title`       | string   | Röstnamn.                                             |
| `description` | string   | Röstbeskrivning.                                      |
| `state`       | string   | Träningsstatus: `trained` betyder tillgänglig.                |
| `tags`        | string[] | Offentliga bibliotekstaggar.                           |
| `languages`   | string[] | Språk som rösten är duktig på.                          |
| `visibility`  | string   | `public` eller `private`.                             |
| `samples`     | object[] | Förinställda prover (inklusive `audio` direktlänk).         |
| `like_count`  | integer  | Antal gillanden i det offentliga biblioteket.               |
| `task_count`  | integer  | Antal historiska synteser.                               |
| `author`      | object   | Uppströms författarinformation: `_id` / `nickname` / `avatar`. |
| `total`（toppnivå）   | integer  | Totalt antal som uppfyller villkoren.                     |
| `has_more`    | boolean? | Uppströms sidindikation, kan vara `null`. Rekommenderas att använda `total / page_size` för att beräkna totalt antal sidor. |

## Avgiftsbeskrivning

Detta gränssnitt debiterar inte - att göra en paginerad förfrågan om röstlistan är en gratis åtgärd. Att skapa röster ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) är också gratis, kostnader uppstår endast vid anrop av [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) för att syntetisera tal.

## Felhantering

- `400 token_mismatched`: Begärningsparametrar saknas eller är ogiltiga.
- `401 invalid_token`: Autentiseringstoken finns inte eller är ogiltig.
- `429 too_many_requests`: Utlöst konto hastighetsbegränsning.
- `500 api_error`: Intern serverfel.

Exempel på felrespons:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Slutsats

För att välja röster från Fish offentliga bibliotek för att mata in i `/fish/tts` med `reference_id`, använd först detta gränssnitt tillsammans med `title` / `tag` / `language` för att söka, lokalisera mål `_id`, och använd sedan [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) för att få prover att lyssna på. För att lista röster som skapats av dig, skicka `self=true`.
