Detta gränssnitt baseras på [Fish Audio officiella Model API](https://docs.fish.audio/resources/api-reference/model) och används för att **sidindelat söka i Fish offentliga röstbibliotek eller klonade röster under det aktuella kontot**. Adressen är `GET https://api.acedata.cloud/fish/model`.

> För att skapa en röst, se [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); för att söka information om en enskild röst efter `_id`, se [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Ansökningsprocess

För att använda Fish Model API, hämta först din API-token från [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) och spara den för senare användning.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig, omdirigeras du automatiskt till inloggningssidan där du uppmanas att registrera dig och logga in. När det är klart återvänder du automatiskt till den aktuella sidan.

**En API-token kan anropa alla plattformens tjänster, utan att behöva ansöka separat för varje tjänst.** Vid första ansökan får du gratis kvot för att kunna prova tjänsten kostnadsfritt; när kvoten är otillräcklig kan du fylla på det gemensamma saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Frågeparametrar

| Parameter               | Typ      | Standard  | Beskrivning                                              |
| ---------------- | ------- | --- | ----------------------------------------------- |
| `page_size`      | integer | 10  | Antal poster per sida.                                           |
| `page_number`    | integer | 1   | Sidnummer som börjar från 1.                                         |
| `title`          | string  | —   | Fuzzy-sökning efter titel.                                        |
| `tag`            | string  | —   | Filtrera efter en enskild tagg.                                        |
| `self`           | boolean | —   | När `true` returneras endast röster som det aktuella anropskontot har skapat och sparat via denna plattform.                 |
| `author_id`      | string  | —   | Filtrera efter röstförfattarens ID.                                    |
| `language`       | string  | —   | Filtrera efter röstens språk, till exempel `en`, `zh`, `es`.                       |
| `title_language` | string  | —   | Filtrera efter titelspråk i det offentliga röstbiblioteket.                                 |
| `sort_by`        | string  | —   | Sorteringsfält; när `self=true` stöds `created_at` och `task_count`. |

> Parameternamnen är helt identiska med uppströms `GET https://api.fish.audio/model`. Se [Fish officiella dokumentation](https://docs.fish.audio/resources/api-reference/model) för detaljer.

## Exempel 1: Standardbläddring (enligt `page_size`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=2'
```

## Exempel 2: Fuzzy-sökning efter titel (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Returnerar (testat i praktiken):

```json
{
  "total": 161,
  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",
      "type": "tts",
      "title": "Miles Morales ( Narration Paw )",
      "tags": ["male", "middle-aged", "entertainment", "storytelling", "Children's Content"],
      "languages": ["en"],
      "visibility": "public",
      "task_count": 770
    },
    {
      "_id": "76b55591c758444cb95253708696dfad",
      "type": "tts",
      "title": "Joe NARRATION",
```

Observera att `title` är en ”global fuzzy-matchning” och kommer samtidigt att träffa alla röster i Fish offentliga bibliotek (inte bara dina egna).

## Exempel 3: Lista endast röster som du själv har skapat (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Exempel på returnerat resultat:

```json
{
  "total": 1,
  "items": [
    {
      "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
      "type": "tts",
      "title": "copilot-smoke-test",
      "description": "smoke test from api.acedata.cloud",
      "state": "trained",
      "languages": [
        "zh"
      ],
      "visibility": "public",
      "samples": [
        {
          "title": "Default Sample",
          "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
          "task_id": "6a1bf398dfae49dca0e23159214342a0",
          "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
        }
      ],
      "created_at": "2026-05-10T03:52:55.601000Z",
      "author": {
        "_id": "780f2b2f862d41a08c0507bbbda77eb6",
        "nickname": "Penny Conrad"
      }
    }
  ],

```
`self=true` listar röster som skapats och sparats via denna plattform enligt det faktiskt anropande kontot; röster som skapats av samma konto med olika API-token listas också tillsammans. Resultaten pagineras i omvänd kronologisk ordning efter skapandetid, och `author_id` kan ytterligare filtrera författar-ID:t för dessa röster. Denna parameter filtrerar endast listan; rösterna är fortfarande offentligt tillgängliga.

`self=true` stöder inte `title_language`; om du behöver söka efter titelns språk, fråga det offentliga röstbiblioteket.

## Exempel 4: Filtrera efter språk + tagg

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> Uppströms returneras även resultat för `tag` som inte finns i taggordboken, men matchningen är relativt bred; om antalet träffar är 0 rekommenderas att använda ungefärlig matchning med `title`.

## Svarsfält

Varje post i `items[]` är ett komplett ModelEntity-objekt, med vanliga fält:

| Fält            | Typ       | Beskrivning                                        |
| ------------- | -------- | ----------------------------------------- |
| `_id`         | string   | Röst-ID, används som värdet för `reference_id` i `/fish/tts`. |
| `type`        | string   | Modelltyp, vanligtvis `tts`.                           |
| `title`       | string   | Röstnamn.                                     |
| `description` | string   | Röstbeskrivning.                                     |
| `state`       | string   | Träningsstatus: `trained` betyder tillgänglig.                      |
| `tags`        | string[] | Taggar i det offentliga biblioteket.                                    |
| `languages`   | string[] | Språk som rösten är bra på.                                  |
| `visibility`  | string   | `public` eller `private`.                     |
| `samples`     | object[] | Förinställda exempel (inklusive direktlänk till `audio`).                       |
| `like_count`  | integer  | Antal gilla-markeringar i det offentliga biblioteket.                                   |
| `task_count`  | integer  | Antal historiska syntestillfällen.                                   |
| `author`      | object   | Information om röstförfattaren: `_id` / `nickname` / `avatar`.     |
| `total`（toppnivå）   | integer  | Totalt antal poster som uppfyller villkoren.                                 |
| `has_more`    | boolean? | Är ett booleskt värde när `self=true`; frågor mot det offentliga röstbiblioteket kan vara `null`.      |

## Faktureringsinformation

Detta gränssnitt debiteras inte — paginerade frågor av röstlistan är kostnadsfria. Att skapa röster ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) är också kostnadsfritt; avgifter uppstår endast enligt användning när [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) anropas för att syntetisera tal.

## Felhantering

- `400 token_mismatched`: Begärandeparametrar saknas eller är ogiltiga.
- `401 invalid_token`: Auktoriseringstoken finns inte eller är ogiltig.
- `429 too_many_requests`: Kontots hastighetsbegränsning har utlösts.
- `500 api_error`: Internt serverfel.

Exempel på felsvar:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Slutsats

För att välja en röst från Fish offentliga bibliotek och använda den som `reference_id` för `/fish/tts`, använd först detta gränssnitt tillsammans med `title` / `tag` / `language` för sökning, identifiera mål-`_id` och använd sedan [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) för att hämta exempel för provlyssning. För att lista röster du själv har skapat räcker det att skicka `self=true`.
