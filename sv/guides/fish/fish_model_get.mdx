Detta gränssnitt är baserat på [Fish Audio officiella Model API](https://docs.fish.audio/resources/api-reference/model) och används för att **hämta fullständiga detaljer om en enskild klonröst baserat på `_id`**. Adressen är `GET https://api.acedata.cloud/fish/model/{id}`.

> För att skapa röster, vänligen se [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); för paginerad sökning, se [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query).

## Ansökningsprocess

För att använda Fish Model API, börja med att gå till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att få din API-token, som du kan spara för framtida bruk.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du inte är inloggad eller registrerad kommer du automatiskt att omdirigeras till inloggningssidan där du blir inbjuden att registrera dig och logga in. När detta är klart kommer du automatiskt att återvända till den aktuella sidan.

**En API-token räcker för att anropa alla tjänster på plattformen, det behövs ingen separat ansökan för varje tjänst.** Första ansökan ger en gratis kvot för att prova på; när kvoten är slut kan du ladda på allmän balans i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Sökvägsparametrar

| Parameter | Obligatorisk | Beskrivning                                                                                                                                                                                                |
| --------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`      | Ja           | Röstens `_id` (32-tecken hexadecimalt sträng). Kan erhållas vid skapande genom [Fish Model Create](https://platform.acedata.cloud/documents/fish-model) eller genom att hämta det via [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query). |

Ingen begäran kropp, inga sökparametrar.

Det erhållna `_id` kan direkt användas som `reference_id` i [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) för att syntetisera tal med samma röst:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

## Skillnader från listgränssnittet

| Fält                                               | `GET /fish/model` (lista) | `GET /fish/model/{id}` (detaljer) |
| -------------------------------------------------- | -------------------------- | ---------------------------------- |
| `samples[].audio`                                  | Kortvarig R2-cache URL     | Direktlänk med signatur (inklusive query-signatur) |
| `unliked` / `liked` / `marked` / `dmca_taken_down` | Finns också                | Finns också                        |
| `default_text` / `lock_visibility`                 | Finns också                | Finns också                        |

Om du bara vill lyssna på ett exempel är `samples[].audio` i listgränssnittet tillräckligt; för mer stabila nedladdningslänkar rekommenderas att använda detta gränssnitt.

## Svarsfält (utdrag)

| Fält            | Typ       | Beskrivning                                          |
| ------------- | -------- | --------------------------------------------------- |
| `_id`         | string   | Röst-ID (används för `/fish/tts` som `reference_id`). |
| `type`        | string   | Modelltyp, vanligtvis `tts`.                        |
| `title`       | string   | Röstnamn.                                          |
| `description` | string   | Lång beskrivning.                                   |
| `state`       | string   | Träningsstatus: `trained` betyder tillgänglig, `training` betyder att den fortfarande tränas. |
| `tags`        | string[] | Offentliga biblioteksetiketter.                     |
| `samples`     | object[] | Förinställda exempel, inklusive `title`, `text`, `task_id`, `audio` direktlänk. |
| `languages`   | string[] | Språk koden som rösten är bra på.                   |
| `visibility`  | string   | `public` eller `private`.                           |
| `like_count`  | integer  | Antal gillningar i det offentliga biblioteket.      |
| `task_count`  | integer  | Antal historiska synteser (kan användas för populäritetsranking). |
| `author`      | object   | Information om författaren: `_id` / `nickname` / `avatar`. |
| `created_at`  | string   | ISO 8601 skapelsedatum.                             |
| `updated_at`  | string   | ISO 8601 senaste uppdateringsdatum.                 |

## Avgiftsbeskrivning

Detta gränssnitt debiteras inte - att hämta detaljer om en röst baserat på ID är en gratis åtgärd. Att skapa röster ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) är också gratis, avgifter uppstår endast vid anrop av [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) för att syntetisera tal.

## Felhantering
- `400 token_mismatched`：`id` i sökvägen är inte i giltigt format, eller upstream rapporterar "Model not found".
- `401 invalid_token`：Autentiseringstoken saknas eller är ogiltig.
- `404 not_found`：Angivet `_id` är inte synligt i Fish upstream (rösten har tagits bort, är privat eller tillhör ett annat konto).
- `429 too_many_requests`：Kontots hastighetsbegränsning har utlösts.
- `500 api_error`：Internt serverfel.

När man faktiskt begär ett icke-existerande ID returnerar upstream direkt `400 Model not found` (testat):

```shell
curl 'https://api.acedata.cloud/fish/model/test123' \
  -H 'authorization: Bearer {token}'
```

Svar:

```json
{ "status": 400, "message": "Model not found" }
```

Exempel på felrespons:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Slutsats

När man känner till röstens `_id` används denna endpoint direkt för att hämta komplett ModelEntity, de vanligaste användningsfallen är: (1) lyssna på `samples[].audio`, (2) mata `_id` till `/fish/tts` som `reference_id` för att slutföra syntesen. Om man bara har titel eller taggar, använd först [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) för att söka.
