Detta gränssnitt tillhandahåller text-till-tal, anrop av sparade röster och engångskloning av röster i realtid, med adressen `POST https://api.acedata.cloud/fish/tts`.

## Ansökningsprocess

För att använda Fish TTS API, gå först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API-token och spara den för senare användning.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig omdirigeras du automatiskt till inloggningssidan, där du uppmanas att registrera dig och logga in. När detta är klart återgår du automatiskt till den aktuella sidan.

**En API-token kan användas för att anropa alla plattformens tjänster, utan att behöva ansöka separat för varje tjänst.** Vid första ansökan får du en kostnadsfri kvot för gratis testning; när kvoten inte räcker till kan du fylla på det gemensamma saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Fish TTS API →](https://platform.acedata.cloud/services/fish)

## Begärandehuvuden

| Header          | Obligatoriskt  | Beskrivning                                                                                                     |
| --------------- | --- | ------------------------------------------------------------------------------------------------------ |
| `authorization` | Ja   | `Bearer {token}`, där `{token}` är nyckeln som ansökts om på denna plattform.                                                                 |
| `content-type`  | Ja   | `application/json`.                                                                                    |
| `accept`        | Nej   | `application/json`.                                                                                    |
| `model`         | Nej   | TTS-modell, valbar mellan `s1`, `s2-pro` eller `s2.1-pro`, standard är `s2-pro`. `s2.1-pro` är den senaste generationen, `s2-pro` har stark uttrycksfullhet; `s1` är stabilare och avviker mindre vid långa texter. Alla tre har samma pris. |

## Fält i begärandetexten

| Fält             | Typ                 | Obligatoriskt  | Beskrivning                                                                                                                                                                                                     |
| -------------- | ------------------ | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `text`         | string             | Ja   | Texten som ska syntetiseras, en icke-tom sträng.                                                                                                                                                                                          |
| `format`       | string             | Nej   | Ljudformat för utdata, valbart mellan `mp3` (standard), `wav`, `pcm`. Både `wav` och `pcm` returnerar WAV-behållare. `opus` stöds inte, och om det skickas in returneras direkt `400`.                                                                                                                  |
| `reference_id` | string \| string[] | Nej   | Modell-ID för en sparad eller offentlig röst, som kan skapas via [Fish Model API](https://platform.acedata.cloud/documents/fish-model) eller hämtas via [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query). Kan inte användas samtidigt som `references`. |
| `references`   | object[]           | Nej   | Engångskloning av röst i realtid, stöder endast ett `{audio, text}`-prov: `audio` är en offentlig HTTPS MP3/WAV-URL och `text` är den exakta ordagranna transkriptionen av ljudet. Kan inte användas samtidigt som `reference_id`.                                                                                             |
| `sample_rate`  | integer            | Nej   | Samplingsfrekvens, vanliga värden är `16000`, `22050`, `44100`. `format=mp3` har som standard 44100.                                                                                                                                                  |
| `mp3_bitrate`  | integer            | Nej   | MP3-bithastighet, valbar mellan `64`, `128`, `192`. Gäller endast för `format=mp3`.                                                                                                                                                          |
| `prosody`      | object             | Nej   | Överskrivning av prosodi, stöder `speed` (talhastighet, 1.0 är ursprunglig hastighet) och `volume` (volymförstärkning i dB). Exempelvis `{"speed":1.2,"volume":0}`.                                                                                                                          |
| `chunk_length` | integer            | Nej   | Längd på uppströmssegment, avgörs som standard av uppströmssystemet.                                                                                                                                                                                         |
| `temperature`  | number             | Nej   | Samplingstemperatur, intervall ungefär 0.0–1.0.                                                                                                                                                                                      |
| `top_p`        | number             | Nej   | Samplingparameter för top-p.                                                                                                                                                                                            |
| `latency`      | string             | Nej   | `normal` eller `balanced`, om utelämnad fyller detta gränssnitt automatiskt i `normal` (om en tom sträng skickas direkt avvisar uppströmssystemet den).                                                                                                                                                |
| `normalize`    | boolean            | Nej   | Om texten ska normaliseras.                                                                                                                                                                                             |
| `callback_url` | string             | Nej   | Asynkron callback-adress, se avsnittet ”Asynkron callback” nedan. **Detta är en utökning jämfört med det officiella gränssnittet**.                                                                                                                                                                     |

> Engångskloning accepterar endast HTTPS-ljud-URL:er och accepterar inte MessagePack, Base64, data-URI:er eller URL:er med autentiseringsuppgifter. Referensljud rekommenderas vara 10–270 sekunder; Studio använder det mer konservativa intervallet 10–60 sekunder.

## Exempel 1: Minimal begäran (`text` + `format=mp3`)

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hello world.",
    "format": "mp3"
  }'
```

Returnerar (testat):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/e2ffcc06-18da-4a8c-b9aa-9337d0f9ec1d-230825dfc559.mp3"
}
```

`audio_url` pekar på denna plattforms CDN och kan laddas ned direkt med GET eller spelas upp i `<audio>`. Det slutliga lyckade svaret returnerar också `cost` på toppnivå, där `amount` är de Credits som faktiskt dras för denna gång; om det finns ett kontorabatt anger `list_amount` kvoten före rabatt. Länken fungerar långsiktigt, men det rekommenderas ändå att du sparar en kopia i din egen lagring.

## Exempel 2: Använd klonad röst `reference_id`

Nedan används en offentlig spansk röst på Fish-plattformen (`_id` kan hämtas via [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)):

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

Returnerar (testat):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/b6f161f2-a100-4818-add2-47694f234659-6532864739de.mp3"
}
```

## Exempel 3: Engångskloning av röst i realtid (`references`)

Placera referensljudet på en offentlig HTTPS-adress och ange den exakta originaltext som faktiskt sägs i det. Denna röst används endast för denna syntes och skapar ingen långsiktig modell:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s2-pro' \
  -d '{
    "text": "新的旅程从这一刻开始，让我们一起向前。",
    "format": "mp3",
    "references": [{
      "audio": "https://cdn.acedata.cloud/assets/examples/fish/6220d605-39d0-4d43-9e58-0f12949dc9b9-570cfdf96ad9.mp3",
      "text": "春天的清晨，阳光穿过树叶，落在安静的小路上。"
    }]
  }'
```
Uppmätt lyckat svar:

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/995dfe37-b187-474d-8323-b08d6678ed8f-6359be9f8873.mp3",
  "cost": {"amount": 0.007609319999999999, "currency": "credit"}
}
```

| Metod             | Livscykel       | Tillämpliga scenarier                          |
| -------------- | ---------- | ----------------------------- |
| `references`   | Endast denna TTS-begäran | Tillfällig användning eller olika röster varje gång                   |
| `reference_id` | Kan återanvändas      | Offentliga röster eller långvariga röster skapade via `/fish/model` |

## Exempel 3: Justera talhastighet / volym (`prosody`)

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Faster speech with prosody overrides.",
    "prosody": { "speed": 1.2, "volume": 0 },
    "format": "mp3"
  }'
```

Svar (uppmätt):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
}
```

`speed` större än 1 ökar hastigheten, mindre än 1 sänker den; enheten för `volume` är dB, 0 innebär ingen förändring, positiva värden ökar och negativa värden dämpar.

## Exempel 5: Byt modell + kontrollera bithastighet

Byt till den stabila modellen via HTTP-huvudet `model: s1`, och lägg till `mp3_bitrate: 128` i begärandetexten för att styra MP3-bithastigheten:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s1' \
  -d '{
    "text": "high bitrate mp3",
    "format": "mp3",
    "mp3_bitrate": 128
  }'
```

Svar (uppmätt):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/7e7abf3d-3d72-4c9f-8eb6-8af932d7c96e-6f11bf2f30e9.mp3"
}
```

## Exempel 6: PCM-råvågform

För scenarier där realtidssammanslagning behöver göras i webbläsaren, eller efterföljande bearbetning behöver göras på klienten (mixning, hastighetsändring), rekommenderas `pcm`:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "hi",
    "format": "pcm",
    "sample_rate": 16000
  }'
```

Svar (uppmätt):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/64adc04b-c196-4a0f-9070-222ba101ce6c-fc50de38c165.wav"
}
```

> Länkens filändelse följer `format` i begäran: `mp3` ger `.mp3`, medan `wav` och `pcm` ger `.wav` (WAV-behållare, 16-bitars PCM).

## Asynkront återanrop (`callback_url`)

Syntes av lång text kan ta från drygt tio sekunder till flera tiotals sekunder, och om anslutningen avbryts behöver den göras om. Efter att `callback_url` skickats i begärandetexten returnerar gränssnittet omedelbart `{task_id, started_at}`. När uppströmsprocessen verkligen är klar återanropas den URL:en med det fullständiga resultatet som POST JSON, med samma `task_id` och toppnivå-`cost` för den slutliga debiteringen för denna gång i begärandetexten. Den initiala uppgiftsbekräftelsen har ännu inte slutfört syntesen och innehåller därför inte `cost`.

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "今天天气真好，我们一起出去散散步吧。",
    "format": "mp3",
    "callback_url": "https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34"
  }'
```

Returneras omedelbart (uppmätt):

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "started_at": 1778462584.742
}
```

Senare kommer `callback_url` att ta emot något i stil med:

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/bd66b8c5-7543-4557-b684-baa72407e336-52f2e79732f2.mp3"
}
```

Du kan också använda [Fish Tasks API](https://platform.acedata.cloud/documents/fish-tasks) för att aktivt hämta resultatet via `task_id`; `response.cost` i slutstatusposten överensstämmer med `cost` i återanropet, se den dokumentationen för detaljer.

## Felhantering

- `400 token_mismatched`: Begärandeparametrar saknas eller är ogiltiga (vanligast är att `text` är tom, eller att `format` har ett annat värde än `mp3`/`wav`/`pcm`).
- `401 invalid_token`: Auktoriseringstoken finns inte eller är ogiltig.
- `429 too_many_requests`: Kontots hastighetsgräns har utlösts.
- `500 api_error`: Internt serverfel.

Exempel på felsvar:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

Parametervalideringsfel förklarar det ogiltiga fältet i fältet `message`, till exempel:

```json
{
  "status": 400,
  "message": "[{\"type\":\"literal_error\",\"loc\":[\"format\"],\"msg\":\"Input should be 'pcm' or 'mp3'\",\"input\":\"wav\"}]"
}
```

## Slutsats

Den minsta kostnaden för att integrera Fish TTS är att i befintlig kod som anropar `api.fish.audio/v1/tts` byta autentisering till denna plattforms token och **uttryckligen inkludera** `format: "mp3"` i begärandetexten. För scenarier med lång text rekommenderas asynkront återanrop med `callback_url`; för att hitta den klonade röstens `reference_id`, använd [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) tillsammans med [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get).
