HappyHorse Tasks API används för att fråga om videoproduktions- eller redigeringsuppgifter som skapats av HappyHorse Videos API.

## Ansökningsprocess

För att använda HappyHorse Videos API, börja med att gå till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att få din API-token, som du ska spara.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Om du inte har loggat in eller registrerat dig, kommer du automatiskt att omdirigeras till inloggningssidan som bjuder in dig att registrera dig och logga in, och efter att du har slutfört det kommer du automatiskt att återvända till den aktuella sidan.

**En API-token räcker för att anropa alla tjänster på plattformen, du behöver inte ansöka separat för varje tjänst.** Första ansökan ger en gratis kvot, så att du kan prova gratis; när kvoten är slut kan du ladda på allmän balans i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Begärningsexempel

HappyHorse Tasks API kan användas för att fråga om resultaten från HappyHorse Videos API.

### Ställ in begärningshuvuden och begärningskropp

**Begärningshuvuden** inkluderar:

- `accept`: anger att du tar emot svar i JSON-format, här fylls i som `application/json`.
- `authorization`: nyckeln för att anropa API:t, efter ansökan kan du direkt välja från en rullgardinsmeny.

**Begärningskropp** inkluderar:

- `id`: ID för den uppgift som ska frågas.
- `action`: åtgärden för uppgiften, för enskild fråga fylls i `retrieve`.

### CURL kodexempel

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Svarsexempel

Vid en lyckad begäran kommer API:t att returnera detaljer om uppgiften. Där `request`-fältet är begärningskroppen vid skapandet av uppgiften, och `response`-fältet är svaret som returneras efter att uppgiften har slutförts, till exempel:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic shot of a white horse running across a moonlit beach",
    "resolution": "720P",
    "duration": 5
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "1469cfc3-3004-4d9e-ab10-xxxxxx",
        "video_url": "https://cdn.acedata.cloud/happyhorse/c8cbf53aa0.mp4",
        "state": "succeeded",
        "duration": 5,
        "resolution": "720P",
        "ratio": "16:9"
      }
    ]
  }
}
```

Fälten beskrivs nedan:

- `id`: ID för den genererade uppgiften, används för att unikt identifiera denna genererade uppgift.
- `request`: begärningsinformation vid skapandet av uppgiften.
- `response`: aktuell eller slutlig återkoppling av uppgiften.
- `created_at`: tidpunkten då uppgiften skapades, Unix-tidsstämpel (sekunder, flyttal).
- `started_at`: tidpunkten då uppgiften började utföras, ISO-8601 UTC-tidssträng.
- `finished_at`: tidpunkten då uppgiften slutfördes, Unix-tidsstämpel (sekunder, flyttal). Fältet returneras inte om uppgiften inte är slutförd.
- `elapsed`: tid som uppgiften har tagit, enhet i sekunder (flyttal, med 3 decimaler). Fältet returneras inte om uppgiften inte är slutförd.

## Batchfrågeoperationer

För att fråga om uppgiftsdetaljer för flera uppgifts-ID:n, ställ in `action` till `retrieve_batch`, och skicka in en array av uppgifts-ID:n via `ids`:

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```

I det returnerade resultatet kommer `items` och `count` fälten att ingå, där `items` är en array av uppgiftsdetaljer och `count` är antalet uppgifter som matchades denna gång.
