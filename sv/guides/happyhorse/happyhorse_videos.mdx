Den här artikeln introducerar integrationsmetoden för HappyHorse Videos API. Detta API stöder text-till-video, första bildruta-bild-till-video, referensbild-till-video och videoredigering via den enhetliga ingången `/happyhorse/videos` och parametern `action`.

## Ansökningsprocess

För att använda HappyHorse Videos API, gå först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API-token och spara den för framtida bruk.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig omdirigeras du automatiskt till inloggningssidan där du blir inbjuden att registrera dig och logga in. När detta är klart återgår du automatiskt till den aktuella sidan.

**En API-token kan anropa alla plattformens tjänster, utan att behöva ansöka separat för varje tjänst.** Den första ansökan ger kostnadsfria krediter för gratis provanvändning; när krediterna inte räcker till kan du fylla på ditt allmänna saldo i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Åtgärdstyper

`action` avgör genereringsläget för denna begäran:

- `generate`: text-till-video, standardåtgärden, stöder `happyhorse-1.0-t2v` och `happyhorse-1.1-t2v`, och kräver att `prompt` skickas med.
- `image_to_video`: första bildruta-bild-till-video, stöder `happyhorse-1.0-i2v` och `happyhorse-1.1-i2v`, och kräver att `image_url` skickas med.
- `reference_to_video`: referensbild-till-video, stöder `happyhorse-1.0-r2v` och `happyhorse-1.1-r2v`, och kräver att `prompt` och 1–9 `image_urls` skickas med.
- `video_edit`: videoredigering, stöder `happyhorse-1.0-video-edit`, och kräver att `prompt` och `video_url` skickas med. Dessutom kan 0–5 referensbilder i `image_urls` skickas med.

Varje åtgärd använder som standard 1.1-modellen; `video_edit` har för närvarande endast `happyhorse-1.0-video-edit`.

## Grundläggande användning

Text-till-video kräver endast att `prompt` anges, och du kan även ange parametrar som `resolution`, `ratio` och `duration`:

```json
{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

Ett exempel på returresultatet är följande:

```json
{
  "success": true,
  "task_id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
  "trace_id": "6071ab5e-2f37-46f0-9e07-f1e378112e69",
  "data": [
    {
      "id": "9650580f-6d9e-4bc1-823a-29011790c5cb",
      "video_url": "https://cdn.acedata.cloud/assets/examples/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1-2c108ce23554.mp4",
      "state": "succeeded",
      "duration": 5,
      "resolution": "720P",
      "ratio": null
    }
  ]
}
```

Fältbeskrivning:

- `success`: om denna begäran lyckades.
- `task_id`: uppgifts-ID på Ace Data Cloud-sidan, som kan användas för att fråga efter uppgiftsstatus.
- `trace_id`: spårnings-ID för denna begäran, som används för felsökning.
- `data`: lista över videoresultat.
  - `id`: uppgifts-ID på HappyHorse-sidan.
  - `video_url`: CDN-länkadressen till den genererade videon.
  - `state`: uppgiftsstatus, möjliga värden är `pending` / `succeeded` / `error`.
  - `duration`: fakturerbar videolängd, i sekunder; för `video_edit` är detta den sammanlagda längden för in- och utdata-video.
  - `resolution`: utdataupplösning.
  - `ratio`: utdataformat.

Motsvarande CURL-kod är följande:

```shell
curl -X POST 'https://api.acedata.cloud/happyhorse/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}'
```

Motsvarande Python-kod är följande:

```python
import requests

url = "https://api.acedata.cloud/happyhorse/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
    "resolution": "720P",
    "ratio": "16:9",
    "duration": 5,
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Första bildruta-bild-till-video

När `image_to_video` används används `image_url` som videons första bildruta. Utdataformatet följer i möjligaste mån den första bildrutan, så denna åtgärd behöver inte skicka med `ratio`.

```json
{
  "action": "image_to_video",
  "model": "happyhorse-1.1-i2v",
  "image_url": "https://cdn.acedata.cloud/b1c82e4937.png",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "1080P",
  "duration": 5
}
```

## Referensbild-till-video

När `reference_to_video` används kan 1–9 referensbilder skickas i `image_urls`. I prompten kan bilderna i motsvarande ordning refereras till med exempelvis `character1`, `character2` och så vidare.

```json
{
  "action": "reference_to_video",
  "model": "happyhorse-1.1-r2v",
  "prompt": "character1 walks forward through a sunrise meadow with the warm leather and gold trim style from character2",
  "image_urls": [
    "https://cdn.acedata.cloud/b1c82e4937.png",
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

## Videoredigering

Utdataformatet och längden för `video_edit` ärvs från källvideon. Att skicka `duration` eller `ratio` ändrar dem inte; formatet för bild-till-video ärver också källbildens format. Redigeringsavgiften beräknas utifrån den sammanlagda längden för in- och utdata-video.

När `video_edit` används måste videon som ska redigeras, `video_url`, och redigeringsavsikten, `prompt`, skickas med. Valfria `image_urls` används som referensbilder, till exempel för klädbyte, stilöverföring eller lokal ersättning. `audio_setting` kan vara antingen `auto` eller `origin`, där `origin` innebär att den ursprungliga videons ljud behålls.
```json
{
  "action": "video_edit",
  "model": "happyhorse-1.0-video-edit",
  "prompt": "Tillämpa stilen med varmt läder och gulddetaljer från referensbilden samtidigt som den ursprungliga kamerarörelsen bevaras",
  "video_url": "https://cdn.acedata.cloud/assets/examples/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1-2c108ce23554.mp4",
  "image_urls": [
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "audio_setting": "auto"
}
```

## Asynkront återanrop

Videogenerering kräver en viss bearbetningstid. Om du inte vill behålla en lång anslutning och vänta kan du ange `callback_url`; då returnerar API:et omedelbart `task_id`, och när uppgiften är klar kommer slutresultatet att POST:as till denna adress:

```json
{
  "action": "generate",
  "prompt": "En häst som springer genom en snöig skog",
  "duration": 5,
  "callback_url": "https://your-domain.com/callback/happyhorse"
}
```

Det omedelbart returnerade resultatet är följande:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

Om du endast vill använda polling och inte behöver något återanrop kan du också ange `"async": true` och därefter använda [HappyHorse Tasks API](https://platform.acedata.cloud/documents/happyhorse-tasks) för att hämta uppgiftsresultatet.

## Prisinformation

HappyHorse debiterar baserat på antalet sekunder i utdatavideon och upplösningen:

- `720P`: från cirka 0,105 $ / sekund.
- `1080P`: från cirka 0,18 $ / sekund.
- `video_edit`: debiteras baserat på den sammanlagda längden av inmatningsvideon och utdatavideon; den faktiska debiterade längden baseras på statistiken efter att uppgiften har slutförts.

Misslyckade uppgifter debiteras inte och förbrukar inte heller den kostnadsfria kvoten.

## Felhantering

När ett problem uppstår med begäran returnerar API:et motsvarande felkod och beskrivning. Vanliga exempel är följande:

- `400`: Felaktiga begärandeparametrar, till exempel att action och model inte matchar, att `prompt` / `image_url` / `video_url` saknas eller att `duration` ligger utanför intervallet 3–15 sekunder.
- `401`: Autentisering misslyckades; token är ogiltig eller matchar inte API:et.
- `403`: Otillräckligt saldo, eller så avvisades prompten efter att ha träffat innehållsgranskningen.
- `429`: Begäranden görs för ofta, vilket har utlöst hastighetsbegränsning. Försök igen senare.
- `500`: Internt serverfel eller genereringen misslyckades.
