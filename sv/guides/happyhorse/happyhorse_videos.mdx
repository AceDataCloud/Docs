Denna artikel beskriver hur man integrerar med HappyHorse Videos API. Detta gränssnitt stöder text-till-video, bild-till-video, referensbild-till-video och videoredigering via den enhetliga ingången `/happyhorse/videos` och parametern `action`.

## Ansökningsprocess

För att använda HappyHorse Videos API, börja med att gå till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API-token, som du ska spara.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du inte har loggat in eller registrerat dig, kommer du automatiskt att omdirigeras till inloggningssidan för att registrera dig och logga in, och efter att du har slutfört detta kommer du automatiskt att återvända till den aktuella sidan.

**En API-token räcker för att anropa alla tjänster på plattformen, du behöver inte ansöka separat för varje tjänst.** Första ansökan ger en gratis kvot för att prova; om kvoten tar slut kan du ladda på allmän balans i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Operationstyper

`action` bestämmer genereringsläget för denna begäran:

- `generate`: text-till-video, standardåtgärd, stöder `happyhorse-1.0-t2v` och `happyhorse-1.1-t2v`, `prompt` måste anges.
- `image_to_video`: bild-till-video, stöder `happyhorse-1.0-i2v` och `happyhorse-1.1-i2v`, `image_url` måste anges.
- `reference_to_video`: referensbild-till-video, stöder `happyhorse-1.0-r2v` och `happyhorse-1.1-r2v`, `prompt` och 1–9 `image_urls` måste anges.
- `video_edit`: videoredigering, stöder `happyhorse-1.0-video-edit`, `prompt` och `video_url` måste anges, kan även ta emot 0–5 referensbilder `image_urls`.

Varje åtgärd använder som standard modell 1.1; `video_edit` har för närvarande endast `happyhorse-1.0-video-edit`.

## Grundläggande användning

För text-till-video behöver du bara ange `prompt`, du kan också specificera parametrar som `resolution`, `ratio`, `duration`:

```json
{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "En filmisk vit häst lyfter sitt huvud, manen rör sig försiktigt i soluppgångens vind, långsam kameraframdrivning, varm filmbelysning",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

Exempel på returresultat:

```json
{
  "success": true,
  "task_id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
  "trace_id": "6071ab5e-2f37-46f0-9e07-f1e378112e69",
  "data": [
    {
      "id": "9650580f-6d9e-4bc1-823a-29011790c5cb",
      "video_url": "https://platform2.cdn.acedata.cloud/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1.mp4",
      "state": "succeeded",
      "duration": 5,
      "resolution": "720P",
      "ratio": null
    }
  ]
}
```

Fältbeskrivning:

- `success`: om denna begäran var framgångsrik.
- `task_id`: Ace Data Cloud-sidans uppgifts-ID, kan användas för att kontrollera uppgiftens status.
- `trace_id`: spårnings-ID för denna begäran, används för att felsöka problem.
- `data`: lista över videoresultat.
  - `id`: uppgifts-ID på HappyHorse-sidan.
  - `video_url`: CDN-länk till den genererade videon.
  - `state`: uppgiftens status, kan vara `pending` / `succeeded` / `error`.
  - `duration`: debiterad videolängd, i sekunder; `video_edit` är summan av in- och utgångsvideolängd.
  - `resolution`: utdataupplösning.
  - `ratio`: utdataförhållande.

Motsvarande CURL-kod:

```shell
curl -X POST 'https://api.acedata.cloud/happyhorse/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "En filmisk vit häst lyfter sitt huvud, manen rör sig försiktigt i soluppgångens vind, långsam kameraframdrivning, varm filmbelysning",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}'
```

Motsvarande Python-kod:

```python
import requests

url = "https://api.acedata.cloud/happyhorse/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "En filmisk vit häst lyfter sitt huvud, manen rör sig försiktigt i soluppgångens vind, långsam kameraframdrivning, varm filmbelysning",
    "resolution": "720P",
    "ratio": "16:9",
    "duration": 5,
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Bild-till-video

När du använder `image_to_video`, kommer `image_url` att fungera som videons första bild. Utdataförhållandet kommer att försöka följa den första bildens bild, så denna åtgärd behöver inte ange `ratio`.

```json
{
  "action": "image_to_video",
  "model": "happyhorse-1.1-i2v",
  "image_url": "https://cdn.acedata.cloud/b1c82e4937.png",
  "prompt": "En filmisk vit häst lyfter sitt huvud, manen rör sig försiktigt i soluppgångens vind, långsam kameraframdrivning, varm filmbelysning",
  "resolution": "1080P",
  "duration": 5
}
```

## Referensbild-till-video

När du använder `reference_to_video`, kan `image_urls` ta emot 1–9 referensbilder. I prompten kan du referera till motsvarande bilder med `character1`, `character2` osv.

```json
{
  "action": "reference_to_video",
  "model": "happyhorse-1.1-r2v",
  "prompt": "character1 går framåt genom en soluppgångsäng med den varma läder- och guldtrimstilen från character2",
  "image_urls": [
    "https://cdn.acedata.cloud/b1c82e4937.png",
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

## Videoredigering

När du använder `video_edit` måste du ange den video som ska redigeras `video_url` och redigeringssyftet `prompt`. Valfria `image_urls` kommer att fungera som referensbilder, till exempel för klädbyte, stilöverföring eller partiell ersättning. `audio_setting` kan vara `auto` eller `origin`, där `origin` innebär att den ursprungliga videons ljud bevaras.

```json
{
  "action": "video_edit",
  "model": "happyhorse-1.0-video-edit",
  "prompt": "Tillämpa den varma läder- och guldtrimstilen från referensbilden samtidigt som den ursprungliga kamerarörelsen bevaras",
  "video_url": "https://platform2.cdn.acedata.cloud/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1.mp4",
  "image_urls": [
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "audio_setting": "auto"
}
```

## Asynkron återkoppling
Videogenerering kräver viss behandlingstid. Om du inte vill hålla en lång anslutning och vänta kan du ange `callback_url`, då kommer API:et omedelbart att returnera `task_id`, och när uppgiften är klar kommer det slutliga resultatet att POST:as till den adressen:

```json
{
  "action": "generate",
  "prompt": "En häst som springer genom en snöig skog",
  "duration": 5,
  "callback_url": "https://your-domain.com/callback/happyhorse"
}
```

Det omedelbart returnerade resultatet ser ut som följer:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

Om du bara vill använda polling och inte behöver en callback kan du också ange `"async": true`, och sedan kan du kontrollera uppgiftsresultatet via [HappyHorse Tasks API](https://platform.acedata.cloud/documents/happyhorse-tasks).

## Avgiftsbeskrivning

HappyHorse debiterar baserat på utgångsvideo sekunder och upplösning:

- `720P`: så lågt som cirka $0.105 / sekund.
- `1080P`: så lågt som cirka $0.18 / sekund.
- `video_edit`: debiteras baserat på den totala längden av in- och utgångsvideon, den faktiska debiterade längden baseras på statistiken efter att uppgiften är slutförd.

Misslyckade uppgifter debiteras inte och tar inte upp gratis kvot.

## Felhantering

När en begäran har problem kommer API:et att returnera motsvarande felkod och beskrivning, vanliga är följande:

- `400`: Begärningsparametrar är felaktiga, till exempel matchar inte action och model, saknas `prompt` / `image_url` / `video_url`, eller `duration` överskrider intervallet 3–15 sekunder.
- `401`: Autentisering misslyckades, token är ogiltig eller matchar inte API:et.
- `403`: Otillräcklig balans, eller prompten har avvisats av innehållsgranskning.
- `429`: Begäran är för frekvent, begränsning har utlösts, vänligen försök igen senare.
- `500`: Intern serverfel eller generering misslyckades.
