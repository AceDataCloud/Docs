---
title: "Qwen Image uppgiftssökning API"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/tasks` används för att söka, göra batchsökningar eller ta bort Qwen Image asynkrona uppgifter. Detta gränssnitt genererar ingen extra API-kostnad.

## Sök enskild uppgift

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

När uppgiften är slutförd, innehåller `response.data` den permanenta CDN-bildadressen, `response.usage` innehåller det verkliga antalet in- och utdata, och `response.cost` är avräkningsinformationen för den genererade uppgiften.

## Batchsökning

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Returnerar `{ "items": [...], "count": 2 }`. Listan för sökningar stöder också filtrering efter användare, applikation och tidsintervall för skapande.

## Ta bort uppgiftshistorik

```json
{"action":"delete","id":"TASK_ID"}
```

Borttagning påverkar endast uppgiftshistoriken och tar inte bort redan genererade CDN-filer.
