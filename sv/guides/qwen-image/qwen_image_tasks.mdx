---

Använd `POST https://api.acedata.cloud/qwen-image/tasks` för att fråga om asynkrona bildgenereringsuppgifter. Denna frågegränssnitt är gratis.

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Batchfrågor använder `action=retrieve_batch` och `ids`-arrayen. När uppgiften är framgångsrik innehåller `response.data` den permanenta adressen för de genererade bilderna samt faktisk användning.
