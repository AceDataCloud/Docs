title: "Qwen Image generering och redigerings API"

---

`POST https://api.acedata.cloud/qwen-image/images` genom samma gränssnitt för att slutföra text-till-bild och redigering av 1–3 referensbilder, stöder `qwen-image-3.0` och `qwen-image-3.0-pro`.

## Välj modell

| Modell                  | Lämpliga scenarier       | Officiellt standardpris                   |
| --------------------- | ------------------ | --------------------------------- |
| `qwen-image-3.0`      | Massproduktion, snabb iteration  | Utdata $0.030/bild             |
| `qwen-image-3.0-pro`  | Komplex layout, hög precision | 1K $0.040/bild; 2K $0.075/bild |

Referensbilder debiteras baserat på det verkliga antalet inmatningar, officiellt standardpris $0.003/bild.

## Synkron generering

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "En enkel röd cirkel centrerad på en ren vit bakgrund.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

Ett framgångsrikt svar innehåller en permanent CDN-bildadress, verklig användning och kostnaden för denna gång:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Referensbildredigering

Lägg till `image_urls`, stöder 1–3 offentligt tillgängliga bilder:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "Behåll subjektet, ändra bakgrunden till en varm**###**affischstil",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"
  ],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` används endast för text-till-bild. `n` kan vara mellan 1–6; bildförhållandet måste vara mellan 1:8 och 8:1.

## Asynkrona uppgifter

Genom att ställa in `async: true` returnerar gränssnittet omedelbart `task_id`. Använd `/qwen-image/tasks` för att fråga om slutstatus, eller ange `callback_url` för att ta emot slutförandeaviseringar. Generering debiteras endast en gång, uppgiftsfrågan debiteras inte flera gånger.
