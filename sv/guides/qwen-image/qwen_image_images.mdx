title: "Qwen Image Bild API Integrationsguide"

---

`POST https://api.acedata.cloud/qwen-image/images` stöder `qwen-image-3.0` och `qwen-image-3.0-pro` för text-till-bild och redigering av 1–3 referensbilder.

## Text-till-bild

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen-image-3.0","prompt":"en extremt minimalistisk teknologisk affisch","size":"1024*1024","n":1}'
```

## Bildredigering

Lägg till `image_urls` i samma begäran, stöder 1–3 offentliga bilder:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "bevara huvudämnet, ändra till varm**###** affischstil",
  "image_urls": ["https://cdn.acedata.cloud/r9vsv9.png"],
  "size": "2048*2048",
  "prompt_extend": true,
  "prompt_extend_mode": "direct",
  "enable_thinking": true,
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` stöder endast text-till-bild. `n` ligger i intervallet 1–6. Utdata storlekens totala pixlar måste vara mellan 512×512 och 2048×2048, med ett förhållande mellan bredd och höjd på 1:8 till 8:1.

## Asynkron anrop

Genom att ställa in `async: true` kan du omedelbart få `task_id`; du kan också ange `callback_url` för att ta emot det slutliga resultatet. Efter slutförande kan du fråga via `/qwen-image/tasks`.

Ett framgångsrikt svar innehåller `data[].image_url`, `usage`, `task_id` och `trace_id`. Bildlänkar kommer att lagras på Ace Data Cloud CDN så mycket som möjligt. Ett verkligt svarsexempel kommer att läggas till efter produktionens E2E-verifiering.
