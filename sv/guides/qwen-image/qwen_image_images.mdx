---
title: "Qwen Image-genererings- och redigerings-API"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` slutför text-till-bild och redigering med 1–3 referensbilder via samma gränssnitt, med stöd för `qwen-image-3.0` och `qwen-image-3.0-pro`.

## Välj modell

| Modell                   | Lämpliga scenarier       | Officiellt standardpris                   |
| -------------------- | ---------- | ----------------------- |
| `qwen-image-3.0`     | Batchskapande, snabb iteration  | Utdata $0.030/bild             |
| `qwen-image-3.0-pro` | Komplex layout, högprecisa färdiga bilder | 1K $0.040/bild; 2K $0.075/bild |

Referensbilder debiteras enligt det faktiska antalet indata, officiellt standardpris $0.003/bild.

## Synkron generering

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "A simple red circle centered on a clean white background.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

Ett lyckat svar innehåller en permanent CDN-bildadress, faktisk usage och kostnaden för denna gång:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Redigering med referensbilder

Lägg till `image_urls`, med stöd för 1–3 offentligt åtkomliga bilder:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "保留主体，将背景改成暖色电影海报风格",
  "image_urls": ["https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` används endast för text-till-bild. Intervallet för `n` är 1–6; bildförhållandet för bredd och höjd måste vara mellan 1:8 och 8:1.

## Asynkrona uppgifter

Efter att `async: true` har angetts returnerar gränssnittet omedelbart `task_id`. Använd `/qwen-image/tasks` för att fråga efter slutstatus, eller skicka in `callback_url` för att ta emot en slutförandenotifiering. Genereringen debiteras endast en gång, och uppgiftsfrågor debiteras inte upprepade gånger.
