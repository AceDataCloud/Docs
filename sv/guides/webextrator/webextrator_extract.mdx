`POST https://api.acedata.cloud/webextrator/extract`

WebExtrators intelligenta extraktions-API omvandlar en URL till **typade strukturerade resultat** — artiklar, produkter,
recept, videor, diskussioner, jobb med mera — och inkluderar samtidigt rensad Markdown och ren text. När du vill ha "rena strukturerade data" i stället för rå HTML är detta rätt API att använda.

## Ansökningsprocess

För att använda WebExtrator-tjänsten, gå först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API-token, som du kan spara för framtida bruk.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du inte har loggat in eller registrerat dig, kommer du automatiskt att omdirigeras till inloggningssidan som bjuder in dig att registrera dig och logga in, och efter att ha slutfört detta kommer du automatiskt att återvända till den aktuella sidan.

**En API-token räcker för att anropa alla tjänster på plattformen, du behöver inte ansöka separat för varje tjänst.** Första ansökan ger en gratis kvot, så att du kan prova gratis; när kvoten är slut kan du ladda på allmän balans i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [WebExtrator-tjänstsidan →](https://platform.acedata.cloud/service/webextrator)

## Auktorisering

```
Authorization: Bearer YOUR_API_KEY
Content-Type:  application/json
```

## Begärandeparametrar

Extract accepterar **alla** parametrar från [Render API](/sv/guides/webextrator/webextrator_render)
（`url`、`user_agent`、`timeout`、`wait_until`、`delay`、`wait_for_selector`、
`block_resources`、`headers`、`cookies`、`callback_url`、`bypass_cache`、
`cache_ttl_seconds`、`async`），samt ytterligare två Extract-specifika fält:

| Fält | Typ | Obligatoriskt | Standard | Beskrivning |
|------|------|:----:|------|------|
| `expected_type` | enum | ❌ | Identifiera automatiskt | Tips om sidtyp: `product` / `article` / `general`. Anger den förväntade resultattypen. |
| `enable_llm` | boolean | ❌ | `false` | Tillåt LLM-extrahering när schema.org inte ger någon träff. På sidor utan JSON-LD, såsom Amazon / HN / Greenhouse, måste detta aktiveras för att få typade resultat. |

### Fält på toppnivå

| Fält | Typ | Beskrivning |
|------|------|------|
| `kind` | string | Fast `"extract"`. |
| `url` | string | Den URL som du skickade in. |
| `finalUrl` | string | Den slutliga URL:en efter omdirigeringar. |
| `contentType` | enum | Sidtyp: `product` / `article` / `general`. |
| `title` | string | Sidtitel. |
| `description` | string? | Sidbeskrivning eller sammanfattning. |
| `byline` | string? | Författare, kanal eller företag. |
| `language` | string? | `<html lang>`.  |
| `siteName` | string? | `og:site_name`.  |
| `publishedAt` | string? | Publiceringstid i ISO 8601-format. |
| `images` | string[] | Högst 50 `<img src />`, tolkade som absoluta URL:er, avduplicerade och med `data:`-URI:er borttagna. |
| `links` | string[] | Högst 100 externa länkar, med fragment / `javascript:` / `mailto:` / `tel:` bortfiltrerade. |
| `markdown` | string | Sidans Markdown-innehåll. |
| `text` | string | Sidans rena text. |
| `structured` | object | Fullständigt strukturerat resultat, se nedan. |
| `rawSignals` | object | Diagnostisk information för felsökning. |
| `cached` | boolean? | Vid cacheträff är värdet `true`. |
| `cacheStoredAt` | number? | Unix-tidsstämpel i millisekunder för första skrivningen av cacheposten. |

### `data.structured`-delfält

| Delfält | När det visas | Beskrivning |
|--------|---------|------|
| `schemaOrg` | Alltid | `{ primary, breadcrumbs, all }`. `primary` är den typade entiteten med högst prioritet; `null` används om den inte hittas. |
| `openGraph` | Alltid | `{ title, description, image, type }`, från `<meta property="og:*" />`. |
| `jsonLd` | Alltid | Den ursprungliga JSON-matrisen med alla `<script type="application/ld+json">`-block. |
| `llm` | När LLM kördes och lyckades | `{ kind, data, model, promptCharCount }`, typat resultat. |
| `llmError` | När LLM kördes men misslyckades | `{ kind, error, model }`, begäran kan fortfarande returnera andra extraherade fält. |
| `amazon` | När URL:en är `amazon.*` | Äldre resultat från Amazon-tillägget; använd typade resultat för nya integrationer. |

## schema.org-resultattyper

`structured.schemaOrg.primary` stöder följande resultattyper:

| schema.org-typ | kind | Utdatafält |
|----------------|----------|----------|
| `Product` | product | `name, sku, gtin, model, color, brand, url, images, offer.{price,currency,availability,condition,seller}, rating.{value,count}, reviews[], properties[]` |
| `Recipe` | recipe | `name, description, image, datePublished, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords, recipeCategory, recipeCuisine` |
| `VideoObject` | video | `name, description, thumbnailUrl, uploadDate, duration, embedUrl, contentUrl, channel, interactionCount` |
| `JobPosting` | job | `title, description, datePosted, validThrough, hiringOrganization, jobLocation, baseSalary, employmentType` |
| `Event` (inklusive `*Event`) | event | `name, description, startDate, endDate, location.{name,address}, organizer, offer.{url,price,currency}` |
| `Article` / `NewsArticle` / `BlogPosting` / `ScholarlyArticle` / `TechArticle` / `Report` / `*NewsArticle` | article | `subtype, headline, description, datePublished, dateModified, author, publisher, image[], url, sameAs[]` |
| `FAQPage` | faq | `questions[{question, answer}]` |
| `BreadcrumbList` | (kopplad till sibling) | Matas alltid ut till `structured.schemaOrg.breadcrumbs[]` och används inte som primary. |

## LLM-resultattyper

När `enable_llm: true` och sidan saknar användbar strukturerad schema.org-data kan extraherade resultat av följande typer returneras:

| Kind | Obligatoriska fält | Valfria fält |
|------|---------|---------|
| `article` | `headline` | `description, byline, publishedAt, language, topics[], sections[{heading,summary}]` |
| `product` | `name` | `description, brand, sku, price, currency, availability, rating.{value,count}, bullets[], specifications[{name,value}]` |
| `discussion` | `title` | `author, postedAt, points, commentCount, body, url` |
| `recipe` | `name` | `description, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords[]` |
| `video` | `name` | `description, channel, uploadDate, duration, viewCount, likeCount, thumbnailUrl, transcript` |
| `job` | `title` | `description, company, location, remote, employmentType, datePosted, validThrough, salaryMin, salaryMax, salaryCurrency, salaryPeriod, responsibilities[], qualifications[]` |

## Cache

Cachelagrade resultat kan återanvändas för samma URL, begärandeparametrar, `cookies` och `headers`; `async`, `bypass_cache` och `cache_ttl_seconds` används för att styra exekveringssättet och cachebeteendet.

| Fält | Effekt |
|------|------|
| `bypass_cache: true` | Hoppa över läsning; resultatet skrivs fortfarande tillbaka till cachen, så att samma begäran kan träffa cachen nästa gång. |
| `cache_ttl_seconds: 0` | Det här svaret **cachelagras inte**. |
| `cache_ttl_seconds: N` | Anpassa TTL för den här posten (standard är 3600 sekunder). |

Svar som träffar cachen inkluderar `data.cached: true` och `data.cacheStoredAt: <unix-ms>`.

## Asynkront läge och callback

Ställ in `async: true` för att gå in i asynkront läge (att tillhandahålla `callback_url` kommer också automatiskt att gå in). Plattformen returnerar omedelbart (HTTP 200):

```json
{
  "success": true,
  "task_id": "550e8400-...",
  "trace_id": "6ba7b810-...",
  "started_at": 1777717800.123
}
```

När uppgiften är klar skickas hela kuvertet `POST` till din `callback_url` (om det har konfigurerats). Du kan också
aktivt fråga senare via [`/webextrator/tasks`](/sv/guides/webextrator/webextrator_tasks).

### Python (requests)

```python
import os, requests

API_KEY = os.environ["ACEDATA_API_KEY"]

resp = requests.post(
    "https://api.acedata.cloud/webextrator/extract",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "url": "https://en.wikipedia.org/wiki/Diffbot",
        "expected_type": "artikel",
    },
    timeout=120,
)
resp.raise_for_status()
data = resp.json()["data"]

primary = (data.get("structured") or {}).get("schemaOrg", {}).get("primary")
print("contentType:", data["contentType"])
print("title:      ", data["title"])
print("byline:     ", data.get("byline"))
print("publishedAt:", data.get("publishedAt"))
if primary and primary["kind"] == "artikel":
    print("headline:    ", primary["headline"])
    print("dateModified:", primary.get("dateModified"))
```

### Node.js (fetch)

```js
const apiKey = process.env.ACEDATA_API_KEY;

const res = await fetch('https://api.acedata.cloud/webextrator/extract', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${apiKey}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://www.allrecipes.com/recipe/16354/easy-meatloaf/',
  }),
});
const { data } = await res.json();
const recipe = data?.structured?.schemaOrg?.primary;
console.log(recipe.name, recipe.cookTime, recipe.ingredients.length, 'ingredienser');
```

## Tips och fallgropar

- **Ange `expected_type` när du behöver specificera sidtypen.** Använd till exempel `article` för artikelsidor och `product` för produktsidor.
- **`enable_llm: true` är kostnadsfritt på sidor som matchar schema.org.** LLM anropas endast när schema.org
  saknar primary, så det är säkert att ha det aktiverat som standard.
- **Kontrollera först `rawSignals.hasJsonLd` vid felsökning.** Om det är `true` men `structured.schemaOrg.primary`
  är `null` betyder det att sidans `@type` ännu inte stöds; du kan rapportera det till oss.
- **`structured.llmError` är endast informativt.** Begäran kan fortfarande lyckas och returnera andra extraherade fält. Se
  `llmError.error` för att identifiera orsaken (timeout, misslyckad JSON-tolkning, misslyckad strukturvalidering).
- **`links[]` för sidor som inte är artikelsidor relevanssorteras inte.** Endast "högst 100 poster + filtrering av ogiltiga protokoll"
  används för en bästa möjliga rensning.
- **Cacheträffar debiteras också.**
