---
title: "Tripo 3D-generering"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Anropa `POST /tripo/generations` för att skapa en ny modell och skicka in text, en enskild bild eller flera vyer av samma objekt. Använd en AceDataCloud-token; som standard returneras resultatet synkront. När `async: true` eller `callback_url` skickas returneras först HTTP 200 och `task_id`. Callbacken vid slutförande har samma JSON-struktur som det synkrona resultatet.

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

`action` är som standard `generate`. Välj ett av tre indataalternativ: `prompt` (1–1024 tecken), `image_url`, `image_urls`. Bilderna ska vara offentligt tillgängliga PNG/JPEG-filer via HTTPS och högst 20 MiB stora. Flera vyer ordnas som framifrån, vänster, bakifrån, höger. Framifrån och minst en annan vy måste anges; null kan användas för att hoppa över mellanliggande vyer.

`model` är som standard `v3.1-20260211`, men `v3.0-20250812`, `v2.5-20250123`, `P1-20260311` eller `P2-20260801` kan också väljas uttryckligen. `texture` är som standard `standard`; använd `none` för enbart geometri. Olika modeller och texturnivåer använder olika mycket av kvoten.

Ladda ned GLB-filen från `data[0].model_url`; `image_url` är en valfri förhandsvisning. Spara `data[0].id` för senare texturering, konvertering eller skelettoperationer. Behåll samma `Idempotency-Key` och förfrågningskropp när samma inskickning försöks igen.
