---
title: "Tripo-modellbearbetning"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Använd `POST /tripo/models` för att bearbeta en befintlig modell och ange önskad `action`. Synkron och asynkron bearbetning, återanrop, kontotillhörighet och uppgiftsförfrågningar fungerar på samma sätt som vid 3D-generering.

| action  | Indata                                                                | Resultat                                                                   |
| ------- | ----------------------------------------------------------------- | -------------------------------------------------------------------- |
| import  | `model_url`, en offentligt tillgänglig GLB-, GLTF-, FBX-, OBJ- eller STL-fil via HTTPS, högst 150 MiB | Ett modell-ID och en GLB-fil som kan refereras till senare; `normalize_scale` och `normalize_translation` returneras när data finns |
| texture | `model_id` eller `model_url`; valfritt ett av `prompt`, `image_url` eller `image_urls` | En ny modell, texturer och en valfri förhandsvisning |
| convert | `model_id` eller `model_url`, samt målformatet `format` | Den konverterade modellfilen |

```json
{"action":"texture","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","prompt":"蓝色哑光表面","texture_quality":"standard","async":true}
```

Texturkvaliteten stöder `fast`, `standard`, `detailed` och `extreme`. Vid användning av en textprompt kan `style_image_url` läggas till; bildreferenser och referenser med flera vyer följer genereringsgränssnittets format. Se OpenAPI för fler texturparametrar.

Konvertering stöder `GLTF`, `FBX`, `USDZ`, `OBJ`, `STL` och `3MF`. Det returnerade objektets `format` anger det faktiska leveransformatet; en begäran om GLTF kan till exempel levereras som binär GLB. För OBJ paketeras material och texturer i en ZIP-fil. Vid begäran om FBX kan `texture_packaging: "zip"` anges för att få separata texturer, och det paketerade resultatet märks med `container: "ZIP"`. Om andra nät- eller texturinställningar än standardinställningarna aktiveras kan debitering ske som avancerad konvertering, se tjänstens priser för mer information.

Använd `data[0].id` för att referera till en modell i det här kontot. Den importerade normaliseringstransformationen följer `normalized = original × normalize_scale + normalize_translation`. Modellens nedladdningsadress finns i `data[0].model_url`.
