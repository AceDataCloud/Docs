## Dreamina Digital Human Video Generation API

`POST https://api.acedata.cloud/dreamina/videos`

Ljuddriven digital människovideo generering (OmniHuman 1.5). Ge en bild av en person och en ljuddrivande ljudfil för att generera en video där personen pratar med synkroniserade läppar.

### Begärningshuvud

| Huvud            | Värde                     |
| ---------------- | ------------------------- |
| `Authorization`  | `Bearer <din API-nyckel>` |
| `Content-Type`   | `application/json`       |

### Begärningsparametrar

| Parameter        | Typ      | Obligatorisk | Beskrivning                                                              |
| ---------------- | -------- | ------------ | ----------------------------------------------------------------------- |
| `model`          | string   | Nej          | Modell, standard `omnihuman-1.5`                                       |
| `image_url`      | string   | Ja           | Offentlig URL till personens foto, rekommenderas att vara tydlig och framifrån |
| `audio_url`      | string   | Ja           | Offentlig URL till ljuddrivande ljudfil (mp3/wav), rekommenderas &lt; 60 sekunder |
| `prompt`         | string   | Nej          | Kontrollera uttryck, känslor, stabilitet och stil                       |
| `mask_url`       | string[] | Nej          | Huvudmask URL, används för att specificera drivande objekt i gruppbilder |
| `callback_url`   | string   | Nej          | Om angiven returneras omedelbart `task_id`, resultatet skickas till denna adress |
| `async`          | boolean  | Nej          | Sätt till `true` för att omedelbart returnera `task_id`, ingen `callback_url` behövs, resultatet kan hämtas via `/dreamina/tasks` |

### Inmatningsrekommendationer

- **Bild**: Tydlig, välbelyst framifrån bild av personen är bäst; ansiktet ska vara synligt och ta upp en rimlig del av bilden.
- **Ljud**: mp3/wav, måste vara offentligt tillgängligt. Rekommenderad längd är under 60 sekunder (1080p rekommenderas ≤30 sekunder, 720p ≤60 sekunder).
- `image_url` och `audio_url` måste båda vara offentligt tillgängliga.

### Svarsexempel

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",
  "data": {
    "task_id": "362b4fed67bd11f1ad1100163e57d510",
    "status": "done",
    "video_url": "https://cdn.acedata.cloud/634d760216.mp4",
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }
}
```

### Asynkron och förfrågan

API:et returnerar som standard den slutliga videon synkront. För längre uppgifter kan två asynkrona lägen användas:

- Ange `callback_url`: API:et returnerar omedelbart `task_id`, resultatet skickas till denna adress när det är klart.
- Ange `async: true`: API:et returnerar omedelbart `task_id`, och resultatet kan hämtas via `POST /dreamina/tasks` (gratis) med `task_id` eller `trace_id`.

För mer information om polling-kontrakt, se [Dreamina Tasks API](https://platform.acedata.cloud/documents/dreamina-tasks-integration).

### Felhantering

| Statuskod | kod                                      | Betydelse                               |
| --------- | ---------------------------------------- | --------------------------------------- |
| 400       | `bad_request`                            | Parameter saknas eller ogiltig (t.ex. `image_url` / `audio_url`) |
| 401       | `authorization_missing` / `invalid_token` | Auktoriseringstoken saknas eller ogiltig |
| 403       | `forbidden`                              | Otillräcklig balans/kvot, eller obehörig från uppströms |
| 429       | `too_many_requests`                      | För många förfrågningar, överskrider hastighetsbegränsningen |
| 500       | `api_error`                              | Intern serverfel                       |

```json
{
  "error": {
    "code": "bad_request",
    "message": "image_url is required (a public URL of a portrait image)"
  },
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

### Fakturering

Debitering baseras på den genererade videons längd, maxpaket cirka **¥1/sekund** (t.ex. 10 sekunders video cirka ¥10).
