Coze officiella dokumentation för anpassade modeller stöder Anthropic Messages API. Olika Coze hyresversioner kan hantera Header, sökvägssammanfogning, streaming och verktygsanrop på olika sätt, så kontrollera varje punkt nedan vid första anslutning.

## Konfiguration

1. Gå till Coze modellhantering och lägg till en anpassad modell.
2. Välj Protokoll Anthropic Messages API.
3. Fyll i Base API URL med `https://api.acedata.cloud`.
4. Fyll i API Nyckel med din Ace Data Cloud API Token.
5. Fyll i Modell med den exakta modell-ID som stöder Anthropic Messages i modellkatalogen.
6. Spara och slutför Coze:s anslutningstest.
7. Skicka `Reply only OK` i Bot/Agent, och testa verktygsanropet igen.

## Nuvarande gränser

- Olika Coze-regioner, versioner eller paket kan visa olika formulär.
- Base API URL bör inte upprepas med `/v1/messages`; om nuvarande UI tydligt kräver en fullständig API URL, följ formulärens anvisningar.
- Messages, Chat Completions och Responses är tre oberoende vägar och kan inte ersätta varandra för verifiering.
