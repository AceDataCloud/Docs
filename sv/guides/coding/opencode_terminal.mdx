## 1. Skaffa API Key

Öppna [listan över Ace Data Cloud-applikationer](https://platform.acedata.cloud/console/applications), gå in i den tillgängliga applikationen och kopiera API Key.

![Skaffa Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installera OpenCode

```bash
curl -fsSL https://opencode.ai/install | bash
```

Du kan även använda npm:

```bash
npm install -g opencode-ai
```

## 3. Ställ in API Key

```bash
export ACEDATACLOUD_API_KEY="din API Key"
```

För att göra detta permanent, lägg till denna rad i `~/.zshrc` eller `~/.bashrc` och öppna sedan terminalen igen.

## 4. Konfigurera Provider

Redigera `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ace Data Cloud",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  }
}
```

Gå till [modellkatalogen](https://platform.acedata.cloud/models) för att se modellnamn (till exempel `claude-opus-5`, `gpt-6-sol`) och ersätt alla `MODEL_ID` med samma namn; vid exakt kontroll används `id`-värdet i svaret från `/v1/models` som referens. Detta värde är modellnamnet som används av API-parametern `model`, inte tjänstens eller API:ets UUID. Ace Data Cloud använder här Chat Completions, så adaptern är `@ai-sdk/openai-compatible`.

## 5. Verifiera och starta

```bash
opencode auth list
opencode models acedatacloud
opencode run --model acedatacloud/MODEL_ID "Reply only OK"
```

Kör sedan `opencode` i projektkatalogen. Om modellen inte visas, kontrollera konfigurationsfilens sökväg, JSON-syntaxen och miljövariablerna; 401 betyder att Key är ogiltig eller inte exporterad.

IDE-tillägget återanvänder samma OpenCode runtime-konfiguration, se [OpenCode IDE Extension](https://platform.acedata.cloud/documents/opencode-ide-integration).
