## 1. Hämta API-nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Konfigurera Provider

Kilo Code:s JetBrains-plugin använder `kilo.jsonc` Provider-format. Konfigurationen måste befinna sig i den faktiska användarmiljön där pluginet körs; vid Remote Development är det vanligtvis den fjärranslutna backend-värden.

Skriv i `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Exportera `ACEDATACLOUD_API_KEY` i miljön där JetBrains backend startas, och starta om IDE eller den fjärranslutna backend-värden.

## 3. Verifiera

Välj `acedatacloud/MODEL_ID`, skicka `Reply only OK`, och låt Agent läsa en testfil. Om det fungerar lokalt men misslyckas på distans, kontrollera först att konfigurationsfilen och miljövariablerna är korrekt skrivna på den fjärranslutna värden.
