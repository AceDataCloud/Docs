## 1. Hämta API Key

Öppna [Ace Data Cloud-applistan](https://platform.acedata.cloud/console/applications), gå in i en tillgänglig applikation och kopiera API Key.

![Hämta Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Konfiguration

Roo Code erbjuder officiellt OpenAI-compatible Provider och kräver att modellen stöder native OpenAI tools/function calling.

1. Öppna Roo Code-inställningarna i VS Code.
2. Ställ in **API Provider** på **OpenAI Compatible**.
3. Fyll i:

| Fält       | Värde                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | API Key som just kopierades                  |
| Model ID | Modell-ID som valdes i Coding-konfigurationsguiden         |

![Roo Code OpenAI Compatible-konfigurationsgränssnitt](https://cdn.acedata.cloud/b6a0e7156438.png)

Ställ sedan in context, max output, bild- och computer-use-alternativ enligt modellens faktiska kapacitet. Spara slutligen konfigurationen och ladda om VS Code.

## 3. Verifiering

Skicka först `Reply only OK`, och låt sedan Roo Code läsa en testfil. Om vanlig chatt lyckas men Agent-verktyget misslyckas, byt till en modell som stöder native tool calling och bekräfta att den kompatibla ändpunkten kan returnera verktygsparametrar och resultat korrekt via streaming.
