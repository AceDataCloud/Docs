Qwen Code använder `~/.qwen/settings.json` för att konfigurera anpassade Provider med `modelProviders`. Här används en fast OpenAI-kompatibel protokoll.

## Konfiguration

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud` måste vara en array. Provider-poster är oberoende konfigurationer och kommer inte automatiskt att ärva andra överordnade kontext-, Header- eller body-parametrar.

## Verifiering

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Reply only OK"
```

Gå in och skicka `Reply only OK`, kör sedan en gång till med verktyget för att läsa filer. Om den strikta kompatibiliteten med slutpunkten vägrar verktygets resultatformat, kontrollera den aktuella Qwen Code-versionen och den officiella kompatibilitetsbeskrivningen.
