## 1. Hämta API-nyckel

Öppna [Ace Data Cloud-applikationslistan](https://platform.acedata.cloud/console/applications), gå in i den tillgängliga applikationen och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installera Kimi Code

macOS / Linux:

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

Kan även installeras via npm:

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. Konfigurera AceDataCloud

Redigera `~/.kimi/config.toml` och lägg till följande konfiguration:

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "din API-nyckel"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

Gå till [modellkatalogen](https://platform.acedata.cloud/models) för att se modellnamn (till exempel `claude-opus-5`, `gpt-6-sol`) och ersätt alla `MODEL_ID` med samma namn; vid exakt validering ska du utgå från `id`-värdet i svaret från `/v1/models`. Detta värde är modellnamnet som används av API-parametern `model`, inte tjänstens eller API:ets UUID. `type = "openai"` använder OpenAI Chat Completions-protokollet.

Konfigurationsfilen innehåller nyckeln, och i macOS / Linux rekommenderas det att begränsa behörigheterna:

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. Verifiera och starta

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

När du har gått in i projektet kan du köra `kimi` för att börja använda det. Om 401 returneras, kontrollera API-nyckeln; om meddelandet model not found visas, bekräfta att `default_model`, modelltabellens namn och fältet `model` använder samma ID.
