## 1. Hämta API Key

Öppna [Ace Data Cloud-applistan](https://platform.acedata.cloud/console/applications), gå in i en tillgänglig applikation och kopiera API Key.

![Hämta Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Kör guiden

```bash
hermes model
```

Välj **Custom endpoint** och fyll i följande i tur och ordning:

| Fält             | Värde                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | API Key som just kopierades                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | Gå till [modellkatalogen](https://platform.acedata.cloud/models) för att kontrollera och fyll i namnet på målmodellen exakt som det är, till exempel `claude-opus-5`, `gpt-6-sol` |
| Context length | Lämna tomt för automatisk identifiering, eller fyll i enligt modellkatalogen                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model` är modellnamnet som används av parametern `model` i API-begäran, inte tjänstens eller API:ets UUID. Du kan först kontrollera i [modellkatalogen](https://platform.acedata.cloud/models); om du behöver exakt validering använder du sedan den aktuella API Key för att begära `GET https://api.acedata.cloud/v1/models` och kopierar `id`-värdet för målmodellen från svarets `data`-array.

Guiden skriver till `~/.hermes/config.yaml` och den lokala autentiseringsfilen.

## 3. Verifiera

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

Om guiden inte sparar konfigurationen kan du köra `hermes model --reset` och sedan försöka igen; 401 betyder att API Key är ogiltig eller inte kan läsas av den aktuella användarkonfigurationen.
