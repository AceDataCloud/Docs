## 1. Hämta API Key

Öppna [Ace Data Cloud-applikationslistan](https://platform.acedata.cloud/console/applications), gå in i en tillgänglig applikation och kopiera API Key.

![Hämta Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Lägg till en modell

Gå i WorkBuddy till **Inställningar → Modeller → Anpassade modeller → Lägg till modell**, och fyll sedan i:

| Fält       | Värde                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------ |
| Leverantör | `Custom`                                                                                         |
| API-adress     | `https://api.acedata.cloud/v1`                                                                   |
| API Key  | API Key som just kopierades                                                                                    |
| Modellnamn     | Gå till [modellkatalogen](https://platform.acedata.cloud/models) för att se, och fyll i namnet på modellen som ska anropas exakt som det är, till exempel `claude-opus-5`, `gpt-6-sol` |
| Anpassat protokoll    | Av                                                                                               |

![Konfigurationsgränssnitt för WorkBuddy Custom Provider](https://cdn.acedata.cloud/189027b68722.png)

> `id` här är modellnamnet som används av parametern `model` i API-begäran, inte UUID för tjänsten, API:t eller Application, och inte heller ett anpassat visningsnamn. Endast när realtidskatalogen returnerar `{"id":"ds-4.0"}` kan `ds-4.0` fyllas i; om den inte finns i katalogen innebär det att den för närvarande inte är tillgänglig, gissa eller förkorta inte.

Du kan först se valbara modeller i [modellkatalogen](https://platform.acedata.cloud/models); om du behöver bekräfta det exakta namn som den aktuella Coding-autentiseringsuppgiften kan anropa, använd sedan den just kopierade API Key för att fråga API-katalogen:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Hitta målmodellen i svarets `data`-array och kopiera dess `id`-värde exakt som det är. Konfigurera funktionsväxlar enligt modellens faktiska stöd.

När ”Anpassat protokoll” hålls avstängt kompletterar WorkBuddy sökvägen enligt reglerna för OpenAI Chat Completions. Avancerade funktionsväxlar (verktyg, bilder, resonemang) ska endast aktiveras enligt den valda modellens faktiska kapacitet; om du är osäker, behåll först standardinställningarna.

## 3. Verifiering

Efter sparandet väljer du den nyligen tillagda modellen i chattmodellväljaren och skickar `Reply only OK`. Kör sedan ytterligare en skrivskyddad fil- eller verktygsuppgift för att bekräfta att de nödvändiga funktionerna är tillgängliga; anropsloggar kan ses i [användningshistoriken](https://platform.acedata.cloud/console/usages).

Om modellen inte visas, bekräfta att konfigurationen har sparats och aktiverats; kontrollera Key vid 401; kontrollera om det angivna modellnamnet exakt matchar `id` i katalogen, samt om API-adressen är korrekt, vid 404. WorkBuddy:s officiella dokumentation anger att Key lagras i den lokala konfigurationen, men att begäransinnehållet fortfarande skickas till den konfigurerade modelltjänsten.
