Aider ansluter till OpenAI-kompatibla API:er via LiteLLM:s `openai/` modellprefix.

## Konfiguration

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

Byt ut `MODEL_ID` mot modellen som valts i Coding konfigurationsguide. Du kan också skriva in motsvarande alternativ i den lokala `.env` eller `.aider.conf.yml`, men skicka inte in verkliga Token.

## Verifiering

```bash
aider --model openai/MODEL_ID --message "Svara endast OK"
```

Vid första användning av en okänd modell kan Aider påpeka att modellmetadata saknas; detta är inte detsamma som att autentisering misslyckas. 401 kontrollerar Token, 404 kontrollerar modell-ID och `/v1` bas-URL.
