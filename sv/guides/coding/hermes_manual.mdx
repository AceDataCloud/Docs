## 1. Hämta API Key

Öppna [Ace Data Cloud-applistan](https://platform.acedata.cloud/console/applications), gå in i den tillgängliga applikationen och kopiera API Key.

![Hämta Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Spara Key

Skriv följande i `~/.hermes/.env`:

```dotenv
ACEDATACLOUD_API_KEY=din API Key
```

## 3. Konfigurera Provider

Lägg till följande i `~/.hermes/config.yaml`:

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

Gå till [modellkatalogen](https://platform.acedata.cloud/models) för att se modellnamnen (till exempel `claude-opus-5`, `gpt-6-sol`), och ersätt alla `MODEL_ID` med samma namn; för exakt verifiering, använd värdet för `id` i svaret från `/v1/models` som referens. Detta värde är modellnamnet som används av API-parametern `model`, inte tjänstens eller API:ets UUID. Skriv inte den riktiga Key i YAML eller skicka in `.env`.

## 4. Verifiera

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

Om 401 returneras, kontrollera `~/.hermes/.env`; om konfigurationen inte börjar gälla, avsluta Hermes helt och starta om den.
