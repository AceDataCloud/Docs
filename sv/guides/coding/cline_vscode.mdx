## 1. Hämta API Key

Öppna [Ace Data Cloud-applistan](https://platform.acedata.cloud/console/applications), gå till en tillgänglig applikation och kopiera API Key.

![Hämta Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Konfigurera Cline

Installera och öppna Cline i VS Code, gå sedan till Provider-konfigurationen via inställningsknappen i Cline-panelen och fyll i:

| Fält                                | Värde                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| API Provider                      | `OpenAI Compatible`                                                                            |
| Base URL                          | `https://api.acedata.cloud/v1`                                                                 |
| API Key                           | API Key som just kopierades                                                                                  |
| Model ID                          | Gå till [modellkatalogen](https://platform.acedata.cloud/models) för att kontrollera och ange namnet på målmodellen exakt som det är, till exempel `claude-opus-5`, `gpt-6-sol` |
| Custom Headers                    | Lämna tomt                                                                                             |
| Set Azure API version             | Lämna tomt                                                                                             |
| Use Azure Identity Authentication | Stäng av                                                                                             |

![Cline OpenAI Compatible-konfigurationsgränssnitt](https://cdn.acedata.cloud/8f356c2f1378.png)

`Model ID` är modellnamnet som används av parametern `model` i API-begäran, inte UUID:t för tjänsten eller API:t, och det får inte förkortas på egen hand. Du kan först kontrollera det i [modellkatalogen](https://platform.acedata.cloud/models); om exakt validering behövs, använd sedan den aktuella API Key för att begära `GET https://api.acedata.cloud/v1/models` och kopiera `id`-värdet för målmodellen från svarets `data`-array.

Behåll övriga konfigurationer för modellfunktioner som standard tills vidare; när bilder eller större kontext behövs, justera dem enligt den valda modellens faktiska funktioner.

## 3. Verifiera

Efter sparandet, skapa en ny uppgift och skicka `Reply only OK`. Låt sedan Cline läsa en testfil för att bekräfta att modellen stöder verktygsanrop; anropshistoriken kan ses i [användningshistoriken](https://platform.acedata.cloud/console/usages).

401 betyder vanligtvis att Key är felaktig; 404 betyder vanligtvis att Base URL är felaktig eller att angivet Model ID inte exakt matchar `id` i katalogen. Om modellen kan chatta men inte kan hantera filer, kontrollera modellens kapacitet för verktygsanrop.
