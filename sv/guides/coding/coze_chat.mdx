Coze officiella dokumentation för anpassade modeller stöder OpenAI Chat API. Olika Coze-tenantversioner kan hantera sökvägssammanfogning, strömmande utdata och verktygsanrop på olika sätt, så kontrollera varje punkt nedan vid första anslutning.

## Konfiguration

1. Gå till Coze modellhantering och lägg till en anpassad modell.
2. Välj Protokoll OpenAI Chat API.
3. Fyll i Base API URL med `https://api.acedata.cloud/v1`.
4. Fyll i API Nyckel med din Ace Data Cloud API Token.
5. Fyll i Modell med den exakta modell-ID som stöder Chat Completions i modellkatalogen.
6. Spara och slutför Coze:s anslutningstest.
7. Skicka `Reply only OK` i Bot/Agent, och testa verktygsanropet igen.

## Nuvarande gränser

- Olika Coze-regioner, versioner eller paket kan visa olika formulär.
- Base API URL bör använda bas, och inte upprepade gånger lägga till `/chat/completions`; om nuvarande UI tydligt kräver fullständig API URL, följ formulärens anvisningar.
- Chat Completions, Responses och Anthropic Messages är tre oberoende vägar och kan inte ersätta varandra för verifiering.
