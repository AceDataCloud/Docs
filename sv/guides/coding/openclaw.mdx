## 1. Hämta API-nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installera OpenClaw och plugin

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

Plugin kräver OpenClaw `2026.4.2` eller högre version, för närvarande erbjuder den inbyggda Chat och Web Search-funktioner.

## 3. Konfigurera nyckel

Rekommenderas att använda onboarding:

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "din API-nyckel"
```

Det går också att använda miljövariabler:

```bash
export ACEDATACLOUD_API_KEY="din API-nyckel"
```

## 4. Valfritt: Manuell konfiguration

Om onboarding inte används, aktivera plugin i `~/.openclaw/openclaw.json` och ställ in standardmodell:

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

Skriv inte API-nyckeln i denna fil; fortsätt använda miljövariabler.

## 5. Välj modell och verifiera

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "Svara endast OK"
```

Ersätt `MODEL_ID` med den modell som Coding Plan för närvarande erbjuder. För att ställa in som standardmodell, kör:

```bash
openclaw models set acedatacloud/MODEL_ID
```

Anropshistorik kan ses i [användningshistorik](https://platform.acedata.cloud/console/usages). 401 indikerar att nyckeln är ogiltig; om modellen inte finns, kontrollera först exakt ID och pluginversion. `cost: 0` i plugin-katalogen indikerar endast att OpenClaw inte gör en dubbelberäkning, de faktiska kostnaderna registreras fortfarande av Ace Data Cloud.

## Web Search

```bash
openclaw infer web search \
  --provider acedatacloud --query "senaste AI-agentramverken" --limit 5
```

För närvarande, betrakta inte bild-, video- eller musikfunktioner i pluginintroduktionen som inbyggda funktioner i OpenClaw Provider.
