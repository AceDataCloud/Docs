Fortsätts JetBrains-plugin använder samma YAML-modellformat som VS Code; konfiguration och hemligheter måste tillhöra användaren som kör JetBrains-plugin.

## Konfiguration

Lägg till i Fortsätts lokala YAML-konfiguration:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Spara `ACEDATACLOUD_API_KEY` i Fortsätts hemligheter. Remote Development-scenarier måste konfigureras på den värd där pluginet faktiskt körs.

## Verifiering

Starta om JetBrains IDE, öppna Fortsätts verktygsfönster, välj Local Config-modellen och skicka `Reply only OK`; utför sedan en gång till en endast läsbar filuppgift. Om den fortfarande använder den gamla modellen, starta om den fjärranslutna backend och kontrollera YAML-indragningen.
