## 1. Hämta API-nyckel

Öppna [Ace Data Cloud-applistan](https://platform.acedata.cloud/console/applications), gå in i en tillgänglig app och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Lägg till Custom provider

Öppna **Settings → Providers** i Kilo Code, klicka på **Custom provider** och fyll sedan i:

| Fält           | Värde                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------- |
| Provider ID  | `acedatacloud`                                                                                 |
| Display name | `AceDataCloud`                                                                                 |
| Provider API | `OpenAI Compatible`                                                                            |
| Base URL     | `https://api.acedata.cloud/v1`                                                                 |
| API key      | API-nyckeln som just kopierades                                                                  |
| Models       | Gå till [modellkatalogen](https://platform.acedata.cloud/models) för att se och lägga till namnen på de modeller som ska användas, till exempel `claude-opus-5` och `gpt-6-sol` |

![Konfigurationsgränssnitt för Kilo Code Custom provider](https://cdn.acedata.cloud/94eb5abd7a6f.png)

Modellens `id` här är modellnamnet som används av parametern `model` i API-begäran, inte tjänstens eller API:ets UUID. Du kan först kontrollera det i [modellkatalogen](https://platform.acedata.cloud/models); vid exakt validering ska du kopiera det direkt från `data`-arrayen i svaret från `/v1/models`, utan att själv gissa eller förkorta det.

Klicka på **Submit** så visas modellen i väljaren. När delning inom teamet eller mer detaljerad konfiguration behövs kan du även, enligt den officiella dokumentationen, redigera användarnivåns `~/.config/kilo/kilo.jsonc` eller projektnivåns `./kilo.jsonc`.

## 3. Verifiering

Välj `acedatacloud/MODEL_ID` och skicka `Reply only OK`, och utför sedan en skrivskyddad filåtgärd. Om modellen inte visas, kontrollera om Provider har skickats in, om modellnamnet exakt matchar `id` i katalogen och om Base URL är korrekt.
