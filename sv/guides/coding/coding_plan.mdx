De fyra abonnemangsnivåerna har samma åtkomstomfång till modeller; priser och kampanjkvoter gäller enligt [Coding Plans prissida](https://platform.acedata.cloud/services/coding?tab=pricing). Coding Application återgår inte till det allmänna saldot.

## API-behörighetsomfattning

Coding Plan är för närvarande kopplad till:

1. Claude Messages
2. Claude Messages Count Tokens
3. Claude Chat Completions
4. OpenAI Chat Completions
5. OpenAI Responses
6. Gemini Chat Completions
7. GLM Chat Completions
8. Grok Chat Completions
9. Kimi Chat Completions
10. DeepSeek Chat Completions

De specifika autentiseringsuppgifterna kan också begränsas av `allowed_api_ids` och programmets behörighetsomfattning.

## Dynamisk modellkatalog

Du kan först öppna [modellkatalogen](https://platform.acedata.cloud/models) för att se aktuella modellnamn, till exempel `claude-opus-5` och `gpt-6-sol`. När du behöver bekräfta om Coding-autentiseringsuppgifterna och API-protokollet matchar, använd giltiga autentiseringsuppgifter för Coding Application för att skicka en begäran:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

Modellkatalogen kommer att fortsätta förändras, och ett fast antal eller en statisk modellista underhålls inte i detta dokument. `id` för varje post i svaret är det **modellnamn** som kan skickas direkt till API-parametern `model`, till exempel motsvarar `{"id":"deepseek-v4-pro"}` att ange `deepseek-v4-pro`; det är inte UUID:t för en tjänst, ett API eller en Application. `/v1/models` returnerar den globala modellkatalogen och filtreras inte automatiskt efter Coding-autentiseringsuppgifter; innan konfiguration behöver du fortfarande korsverifiera den mot autentiseringsuppgifternas API-scope, det valda protokollet och klientens kompatibilitetsomfattning.

## Vanlig felsökning

- **Otillräckligt saldo**: Gå till [Applications-konsolen](https://platform.acedata.cloud/console/applications), hitta Coding Application och förnya köpet aktivt.
- **Klienten begär fortfarande den ursprungliga adressen**: Bekräfta att konfigurationen tillhör samma användare och arbetsyta som startar klienten, och avsluta klienten helt innan du startar den igen.
- **Modellnamnet är inte tillgängligt**: Begär `/v1/models` igen och kontrollera att det angivna modellnamnet exakt matchar `id` i katalogen, autentiseringsuppgifternas API-scope och det protokoll som klienten stöder.
- **Token kan inte anropa gränssnittet**: Bekräfta att autentiseringsuppgifterna tillhör Coding Application och kontrollera `allowed_api_ids` och programmets API-behörigheter.
