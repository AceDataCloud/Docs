## 1. Hämta API-nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Konfiguration

Kilo CLI läser `kilo.jsonc` och hämtar API-nyckeln från shell där CLI startas.

Skriv in i `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Exportera sedan Token i nuvarande shell:

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
```

## 3. Verifiera

```bash
kilo run -m acedatacloud/MODEL_ID "Svara endast OK"
```

Om CLI inte kan läsa Token, kontrollera att variabeln har blivit `export` och inte bara skrivits in i en icke-laddad `.env`-fil.
