Google SERP (Search Engine Results Page) är den resultatsida som användare ser efter att ha angett en sökning i Google sökmotor. Den visar naturliga sökresultat, annonser, utvalda sammanfattningar, kunskapsgrafer samt olika typer av innehåll som bilder och videor, med syftet att ge användarna den mest relevanta informationen.

Denna artikel kommer att ge en detaljerad introduktion till Google SERP API, som kan tillhandahålla resultat från Google sökmotor baserat på inmatade sökfrågor, där resultaten också inkluderar många typer, såsom utvalda sammanfattningar, kunskapsgrafer och bilder.

Detta dokument kommer att beskriva integrationsanvisningarna för Google SERP API.

## Ansökningsprocess

För att använda Google SERP API måste du först gå till [Google SERP API](https://platform.acedata.cloud/documents/44c86226-8eaa-49bf-85f3-1fae8d2e23f1) motsvarande sida för att ansöka om den tjänst som behövs. När du kommer till sidan, klicka på "Acquire"-knappen, som visas i bilden:

![](https://cdn.acedata.cloud/q6ytrc.png)

Om du inte har loggat in eller registrerat dig kommer du automatiskt att omdirigeras till inloggningssidan där du uppmanas att registrera dig och logga in. Efter att ha loggat in eller registrerat dig kommer du automatiskt att återvända till den aktuella sidan.

Vid första ansökan kommer det att finnas en gratis kvot som ges, så att du kan använda API:et gratis.

## Grundläggande användning

Först och främst, förstå den grundläggande användningsmetoden, vilket innebär att du anger typ av sökresurs och nyckelord för att få sökresultat. Du behöver bara enkelt skicka `query`-fältet och ange motsvarande modell.

Till exempel, för att söka efter information om "apple inc", kan vi fylla i motsvarande innehåll på gränssnittet, som visas i bilden:

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

Här kan vi se att vi har ställt in Request Headers, inklusive:

- `accept`: vilken typ av svar du vill ta emot, här anges `application/json`, det vill säga JSON-format.
- `authorization`: nyckeln för att anropa API:et, som kan väljas direkt efter ansökan.

Dessutom har vi ställt in Request Body, inklusive:

- `type`: typ av sökresurs, för närvarande stöds endast sex typer, standard är `search`.
- `query`: söknyckelordet.
- `country`: anpassa sökresultatets land, standard är USA (US).
- `language`: anpassa sökresultatets språk, standard är engelska (en).
- `range`: anpassa tidsintervallet för sökresultaten, standard är utan begränsningar.
- `number`: anpassa storleken på sidnumret för sökresultaten, standard är 10.
- `page`: anpassa sidnumret för sökresultaten, standard är 1.

Dessutom, om du vill generera motsvarande kod för integration, kan du direkt kopiera den genererade, till exempel CURL-koden nedan:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc"
}'
```

Python-integrationskoden ser ut så här:

```python
import requests

url = "https://api.acedata.cloud/serp/google"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "query": "apple inc"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Anpassa tidsintervallet för sökresultat
Denna artikel kan också anpassa tidsintervallet för sökresultat, vilket inkluderar fem alternativ: `qdr:h` (den senaste timmen), `qdr:d` (den senaste dagen), `qdr:w` (den senaste veckan), `qdr:m` (den senaste månaden), och som standard ingen begränsning. Vi kan skicka det motsvarande tidsintervallet genom `range`, till exempel här ställt till `qdr:d`, vilket innebär att söka efter resultat från den senaste dagen, så inmatningen ser ut som följer:

curl -X POST 'https://api.acedata.cloud/serp/google' \

-H 'content-type: application/json' \
-d '{
  "range": "qdr:d",
  "query": "apple inc"
}'
