Codex CLI är en öppen källkod lokal programmeringsagent från OpenAI som kan läsa kod, ändra filer, köra kommandon och hjälpa till med utvecklingsuppgifter direkt i terminalen. Genom Ace Data Cloud-proxy kan du använda Codex CLI till en lägre kostnad utan att behöva prenumerera på ett separat OpenAI-konto.

Välj motsvarande fullständiga konfigurationsguide beroende på användningsscenario:

| Plattform | Beskrivning | Guide-länk |
|-----------|-------------|------------|
| **VS Code** | Officiellt tillägg, chatt i sidopanelen, referera filer, förhandsgranska diff | [VS Code konfigurationsguide](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| **Terminal (CLI)** | Kärnupplevelsen, kör `codex` i valfri terminal för att börja | [Terminal konfigurationsguide](https://platform.acedata.cloud/documents/codex-terminal-integration) |

> **Tips**: Första gången kan du gå till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att få en API-token och därmed gratis kvot. Codex CLI arbetar via Ace Data Clouds OpenAI Responses-kompatibla gränssnitt (`/v1/responses`). Mer information om modeller och prissättning finns på [OpenAI tjänstesida](https://platform.acedata.cloud/documents/openai).
