Codex CLI, Desktop och VS Code-tillägg delar `~/.codex/config.toml`. Konfigurera en gång `acedatacloud` provider, så kan du använda Codex via Ace Data Cloud.

| Användningssätt     | Konfigurationsguide                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| Terminal / CLI   | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)                 |
| Desktop          | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)              |
| VS Code          | [Codex för VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)          |
| Grafisk växling  | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration)         |

Gemensam konfiguration har endast tre punkter:

- Provider: `acedatacloud`
- Bas-URL: `https://api.acedata.cloud/v1`
- API-nyckel: fås från [applikationslistan](https://platform.acedata.cloud/console/applications) och spara till `ACEDATACLOUD_API_KEY`

Det är inte nödvändigt att fastställa modellen i anslutningskonfigurationen; efter att Codex har startats kan du direkt välja modell.

Återvänd till [Coding Plan konfigurationscenter](https://platform.acedata.cloud/documents/coding-plan-integration).
