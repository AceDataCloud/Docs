## 1. Hämta API-nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installera Codex

```bash
npm install -g @openai/codex
```

## 3. Ställ in API-nyckel

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="din API-nyckel"
```

För långvarig effekt, lägg till denna rad i `~/.zshrc` eller `~/.bashrc`. Windows PowerShell använder:

```powershell
setx ACEDATACLOUD_API_KEY "din API-nyckel"
```

Efter inställning, stäng och öppna terminalen igen.

## 4. Konfigurera AceDataCloud

Redigera `~/.codex/config.toml` (Windows är `%USERPROFILE%\.codex\config.toml`), lägg till:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Windows ändra de sista två raderna till:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Ingen behov av att fylla i `model`; efter start kan du välja modell i Codex. Eventuella andra konfigurationer kan behållas, skapa inte en ny provider med samma namn.

## 5. Starta

```bash
cd /path/to/your/project
codex
```

När du är inne i Codex, kör `/model`, bekräfta att Provider är `acedatacloud`, och välj sedan den modell du behöver. Anropshistorik och saldo kan ses i [användningshistorik](https://platform.acedata.cloud/console/usages) och [applikationslista](https://platform.acedata.cloud/console/applications).

Om det meddelas att nyckeln saknas eller returnerar 401, bekräfta att miljövariabeln har ställts in, och stäng helt av terminalen och Codex innan du öppnar dem igen.
