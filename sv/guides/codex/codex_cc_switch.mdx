CC Switch kan hantera Codex:s provider och API-nyckel via ett grafiskt gränssnitt.

## 1. Hämta API-nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installera CC Switch

Ladda ner och installera från [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), eller kör på macOS:

```bash
brew install --cask cc-switch
```

## 3. Lägg till provider

1. Öppna CC Switch, växla till **Codex**.
2. Klicka på **Add Provider**, välj **Custom**.
3. Fyll i:

| Fält       | Innehåll                             |
| -------- | ---------------------------------- |
| Namn     | `acedatacloud`                     |
| Bas-URL  | `https://api.acedata.cloud/v1`    |
| API-nyckel  | Den just kopierade Ace Data Cloud API-nyckeln   |

Om CC Switch erbjuder en anpassad konfigurationsredigerare, bör konfigurationen förbli som:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"
requires_openai_auth = true
```

CC Switch kommer att spara API-nyckeln i `~/.codex/auth.json`:

```json
{
  "OPENAI_API_KEY": "{token}"
}
```

Lägg inte till `env_key` eller `[model_providers.acedatacloud.auth]` i ovanstående provider; antingen manuell konfiguration eller CC Switch-konfiguration. Ingen fast `model` behövs, välj direkt i Codex.

## 4. Aktivera och verifiera

Aktivera `acedatacloud` provider, stäng helt av och starta om Codex eller VS Code. Kör `/model`, bekräfta att Provider är `acedatacloud`, välj sedan modell och skicka ett enkelt meddelande.

Om 401 returneras, bekräfta att `acedatacloud` är aktiverad och kontrollera att `OPENAI_API_KEY` i `~/.codex/auth.json` är den just kopierade Ace Data Cloud API-nyckeln. Anropshistorik kan ses i [användningshistorik](https://platform.acedata.cloud/console/usages).
