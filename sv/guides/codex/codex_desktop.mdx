Codex Desktop delar `~/.codex/config.toml` med Codex CLI.

## 1. Hämta API-nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Ställ in API-nyckel

macOS:

```bash
launchctl setenv ACEDATACLOUD_API_KEY "din API-nyckel"
```

Windows PowerShell:

```powershell
setx ACEDATACLOUD_API_KEY "din API-nyckel"
```

## 3. Konfigurera AceDataCloud

Redigera `~/.codex/config.toml` (för Windows `%USERPROFILE%\.codex\config.toml`), lägg till:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

För Windows ändra de sista två raderna till:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Ingen `model` behöver fyllas i; öppna Codex och välj modellen direkt.

## 4. Starta om och verifiera

Avsluta helt och starta om Codex Desktop, skapa en lokal uppgift och skicka ett enkelt meddelande. Leverantören bör visas som `acedatacloud`; verkliga anrop kan ses i [användningshistorik](https://platform.acedata.cloud/console/usages).

Om konfigurationen inte träder i kraft, kontrollera att du har ändrat den aktuella användarens `~/.codex/config.toml`, att miljövariabeln har ställts in och starta sedan om applikationen helt. Molnuppgifter eller automatiseringar som körs i olika miljöer behöver konfigurera nyckeln separat i respektive miljö.
