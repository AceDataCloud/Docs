Codex VS Code-tillägget delar `~/.codex/config.toml` med Codex CLI.

## 1. Hämta API-nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installera tillägg

Installera **Codex – OpenAI's coding agent** från VS Code-tilläggsmarknaden, eller kör:

```bash
code --install-extension openai.chatgpt
```

## 3. Ställ in API-nyckel

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="din API-nyckel"
```

För att göra det långvarigt, lägg till denna rad i `~/.zshrc` eller `~/.bashrc`. Windows PowerShell använder:

```powershell
setx ACEDATACLOUD_API_KEY "din API-nyckel"
```

## 4. Konfigurera AceDataCloud

Redigera `~/.codex/config.toml` (Windows är `%USERPROFILE%\.codex\config.toml`), lägg till:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

För Windows ändra de sista två raderna till:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Det är inte nödvändigt att fylla i `model`; du kan välja modell i Codex-panelen.

## 5. Starta om och verifiera

Stäng helt och öppna VS Code igen, öppna sedan Codex-panelen. Kör `/model`, bekräfta att Provider är `acedatacloud`, och skicka sedan ett enkelt meddelande; anropshistorik kan ses i [användningshistorik](https://platform.acedata.cloud/console/usages).

Om tillägget inte kan läsa nyckeln, starta VS Code från en terminal där miljövariabeln är inställd, eller ställ in systemomfattande miljövariabler och starta om VS Code. Remote SSH, WSL och Dev Container behöver konfigureras i den faktiska miljön där tillägget körs.
