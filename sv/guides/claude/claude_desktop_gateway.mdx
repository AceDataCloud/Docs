Denna guide konfigurerar Claude Desktops **Third-Party Inference Gateway**, inte Claude Code och inte heller Claude Desktops MCP Connector.

## 1. Hämta API-nyckeln

Öppna [Ace Data Cloud-applistan](https://platform.acedata.cloud/console/applications), gå in i en tillgänglig app och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Öppna tredjepartsinferenskonfigurationen

På Claude Desktops inloggningssida öppnar du i tur och ordning **Help → Troubleshooting → Enable Developer Mode**, och väljer sedan **Developer → Configure Third-Party Inference…**.

![Öppna Third-Party Inference i Claude Desktop](https://cdn.acedata.cloud/713ffd7104a3.png)

> Bilden kommer från Bifrost Apache-2.0-repositoriet och används endast för att hitta Claude Desktop-menyn; gränssnittet kan skilja sig något mellan olika versioner.

## 3. Konfigurera Gateway

Välj **Gateway** och fyll sedan i:

| Fält                  | Värde                           |
| ------------------- | --------------------------- |
| Gateway base URL    | `https://api.acedata.cloud` |
| Gateway API key     | API-nyckeln som just kopierades               |
| Gateway auth scheme | `bearer`                    |
| Credential kind     | `Static API key`            |

![Konfigurationsgränssnitt för Claude Desktop Gateway](https://cdn.acedata.cloud/68d41fe682cb.png)

Klicka på **Apply Changes** och sedan på **Save & Restart**.

## 4. Verifiera

Efter omstarten väljer du en tillgänglig modell, skapar en ny konversation och skickar `Reply only OK`, och utför sedan en enkel verktygsuppgift. Anropshistoriken kan ses i [användningshistoriken](https://platform.acedata.cloud/console/usages).

Ace Data Cloud Gateway stöder `/v1/models` som används av Claude Desktop, Bearer-autentiserad strömmande `/v1/messages`, verktygsanrop och fortsättning med `tool_result`. Fälten för promptcache bevaras; att både cache-skriv- och läsvärden är 0 innebär inte att en cacheträff har skett.

401 betyder vanligtvis att nyckeln är felaktig; om modellen inte hittas, kontrollera konfigurationen igen och starta om Claude Desktop helt. När du rapporterar problem ska du ange trace ID i anropshistoriken, men inte API-nyckeln.
