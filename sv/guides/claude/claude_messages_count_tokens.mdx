Claude Messages Count Tokens API kan beräkna antalet input-token för ett Message utan att faktiskt skapa ett meddelande, inklusive tokenräkning för innehåll såsom verktyg, bilder och dokument. Detta är mycket användbart när du behöver uppskatta kostnader eller kontrollera om indata överskrider modellens kontextgräns.

Detta dokument introducerar främst användningsprocessen för Claude Messages Count Tokens API.

## Ansökningsprocess

För att använda Claude Messages Count Tokens API går du först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API Token och behåller den som reserv.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig, omdirigeras du automatiskt till inloggningssidan där du uppmanas att registrera dig och logga in, och när detta är klart återgår du automatiskt till den aktuella sidan.

**En API Token kan anropa alla plattformens tjänster, utan att behöva ansöka separat för varje tjänst.** Vid första ansökan får du en kostnadsfri kvot för att kunna prova gratis; när kvoten är otillräcklig kan du fylla på det gemensamma saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Grundläggande användning

Claude Messages Count Tokens API:s begärandesökväg är `/v1/messages/count_tokens`, vilket är konsekvent med Anthropic:s officiella API. Vi behöver minst ange två obligatoriska parametrar:

- `model`: Välj Claude-modellen som ska användas; `claude-opus-5-5` kan användas för Messages Token Count, såsom den senaste flaggskeppsmodellen `claude-fable-5-1`; den tidigare `claude-fable-5` är fortfarande kompatibel och behålls. `claude-sonnet-5-5` har lagts till i det inbyggda Messages-seriegränssnittet och stöder bildindata och adaptivt tänkande; dess officiella referenspriser för indata, utdata och cacheläsning är 2, 10 respektive 0,20 USD per miljon Token.
- `messages`: Indatameddelandenas array, där varje meddelande innehåller `role` (roll) och `content` (innehåll).

Vanliga valfria parametrar:

- `system`: Systemprompt, räknas in i antalet Token.
- `tools`: Verktygsdefinitioner, räknas in i antalet Token.
- `thinking`: Konfiguration för utökat tänkande.
- `tool_choice`: Konfiguration för val av verktyg.
- `cache_control`: Cachekontrollkonfiguration på toppnivå eller innehållsblocknivå.

`messages`, `system`, återspelning av verktygsanrop, URL-bilder och innehållsblock för document/PDF använder samma stabila begärandestruktur som Messages API.

### cURL-exempel

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python-exempel

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Exempel på returnerat resultat:

```json
{
  "input_tokens": 11
}
```

### Användning av Anthropic SDK

Claude Messages Count Tokens API accepterar Anthropic SDK:s stabila begärandestruktur och kan anropas via biblioteket `anthropic`. Gränssnittet använder den valda modellens motsvarande inbyggda Count Tokens-funktion för att räkna indata och kan användas för att kontrollera indatans storlek innan en Messages-begäran skickas.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Tokenräkning som inkluderar verktyg

Om din begäran innehåller verktygsdefinitioner räknas även dessa verktyg in i antalet Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Tokenräkning som inkluderar systemprompt

Systemprompten räknas också in i antalet Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Anmärkningar

- Detta API beräknar endast antalet input-token och genererar ingen modellutdata.
- Tokenräkningsresultatet kan användas för att uppskatta indatans storlek och kontrollera kontextfönstret; slutlig debitering baseras på `usage` i det faktiska Messages-svaret.
- Bilder, PDF:er, verktygsdefinitioner, systemprompter och thinking-konfigurationer räknas in i resultatet enligt den valda modellens indateregler.
- Detta API är helt kostnadsfritt och förbrukar ingen kvot.
