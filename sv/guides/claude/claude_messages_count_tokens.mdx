Claude Messages Count Tokens API kan räkna antalet inmatningstokens för ett meddelande utan att faktiskt skapa meddelandet, inklusive verktyg, bilder och dokument. Detta är mycket användbart när man behöver uppskatta kostnader eller kontrollera om inmatningen överskrider modellens kontextgränser.

Detta dokument beskriver huvudsakligen användningsprocessen för Claude Messages Count Tokens API.

## Ansökningsprocess

För att använda Claude Messages Count Tokens API, börja med att gå till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API-token, som du kan spara för framtida bruk.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du inte har loggat in eller registrerat dig, kommer du automatiskt att omdirigeras till inloggningssidan för att registrera dig och logga in, och efter att ha slutfört detta kommer du automatiskt att återvända till den aktuella sidan.

**En API-token kan användas för att anropa alla tjänster på plattformen, utan att behöva ansöka separat för varje tjänst.** Första ansökan ger en gratis kvot för att prova; om kvoten är otillräcklig kan du ladda på allmän balans i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Grundläggande Användning

Begärningsvägen för Claude Messages Count Tokens API är `/v1/messages/count_tokens`, vilket är i linje med Anthropic officiella API. Vi behöver minst tillhandahålla två obligatoriska parametrar:

- `model`: Välj den Claude-modell som ska användas, som den senaste flaggskeppsmodellen `claude-fable-5-1`; den ursprungliga `claude-fable-5` är fortfarande kompatibel.
- `messages`: Inmatningsmeddelandearray, där varje meddelande innehåller `role` (roll) och `content` (innehåll).

Vanliga valfria parametrar:

- `system`: Systemprompt, som räknas med i tokenantalet.
- `tools`: Verktygsdefinition, som räknas med i tokenantalet.
- `thinking`: Utvidgad tänkande konfiguration.
- `tool_choice`: Verktygsvalkonfiguration.
- `cache_control`: Cachekontrollkonfiguration på toppnivå eller innehållsblocknivå.

`messages`, `system`, verktygsanrop, URL-bilder och dokument/PDF-innehållsblock använder samma stabila begärningsstruktur som Messages API.

### cURL Exempel

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python Exempel

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Exempel på returresultat:

```json
{
  "input_tokens": 11
}
```

### Användning av Anthropic SDK

Claude Messages Count Tokens API accepterar den stabila begärningsstrukturen från Anthropic SDK och kan anropas via `anthropic`-biblioteket. Det aktuella returvärdet beräknas av Ace Data Clouds lokala uppskattare och är inte det exakta resultatet från Anthropic officiella tokenizer; de faktiska tokenantalet för multimodala, verktyg och olika Claude-modeller kan variera.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Tokenräkning med Verktyg

Om din begäran innehåller verktygsdefinitioner, kommer dessa verktyg också att räknas med i tokenantalet:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Tokenräkning med Systemprompt

Systemprompten kommer också att räknas med i tokenantalet:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Viktiga Punkter

- Denna API räknar endast antalet inmatningstokens och genererar ingen modellutdata.
- Tokenräkningsresultatet kan användas för att grovt uppskatta inmatningsstorleken och bör inte användas som grund för exakt fakturering, kontextfönsterbegränsningar eller jämförelse med modellens tokenizer.
- Den aktuella uppskattaren beräknar inte exakt token för bilder och PDF-dokument och kan inte återspegla skillnader i den officiella tokenizern för olika Claude-modeller.
- Denna API är helt gratis och förbrukar ingen kvot.
