Claude Messages Count Tokens API kan beräkna antalet indata-Token för ett Message utan att faktiskt skapa meddelandet, inklusive Token-räkning för innehåll såsom verktyg, bilder och dokument. Detta är mycket användbart när du behöver uppskatta kostnader eller kontrollera om indata överskrider modellens kontextgräns.

Detta dokument introducerar främst användningsflödet för Claude Messages Count Tokens API.

`claude-fable-5-2` erbjuder för närvarande inte något Count Tokens-gränssnitt. Den slutliga användningen för genereringsbegäran kan ses i `usage` i Messages-svaret; använd inte räkningsresultat från andra modeller som ersättning för den exakta användningen för denna modell.

## Ansökningsprocess

För att använda Claude Messages Count Tokens API, gå först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API Token och spara den som reserv.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig omdirigeras du automatiskt till inloggningssidan där du uppmanas att registrera dig och logga in. När detta är klart återgår du automatiskt till den aktuella sidan.

**En API Token kan anropa alla plattformens tjänster, utan att du behöver ansöka separat för varje tjänst.** Vid första ansökan får du gratis kredit för att kunna prova kostnadsfritt; när krediten är otillräcklig kan du ladda på ett allmänt saldo i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Grundläggande användning

Begärandesökvägen för Claude Messages Count Tokens API är `/v1/messages/count_tokens`, vilket överensstämmer med Anthropic:s officiella API. Vi behöver minst ange två obligatoriska parametrar:

- `model`: Ange det fullständiga modell-ID:t i modellistan för detta gränssnitt, och använd samma modell i efterföljande Messages-begäranden.
- `messages`: Indatameddelandearrayen, där varje meddelande innehåller `role` (roll) och `content` (innehåll).

Vanliga valfria parametrar:

- `system`: Systemprompten, som räknas in i Token-antalet.
- `tools`: Verktygsdefinitioner, som räknas in i Token-antalet.
- `thinking`: Konfiguration för utökat tänkande.
- `tool_choice`: Konfiguration för verktygsval.
- `cache_control`: Cachningskontrollkonfiguration på toppnivå eller innehållsblocksnivå.

`messages`, `system`, återuppspelning av verktygsanrop, URL-bilder och innehållsblock för document/PDF använder samma stabila begärandestruktur som Messages API.

### cURL-exempel

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python-exempel

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Exempel på retursvar:

```json
{
  "input_tokens": 11
}
```

### Använda Anthropic SDK

Claude Messages Count Tokens API accepterar Anthropics SDK:s stabila begärandestruktur och kan anropas via biblioteket `anthropic`. Gränssnittet räknar indata-Token enligt den valda modellen och kan användas för att kontrollera indatastorleken innan en Messages-begäran skickas.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Token-räkning som inkluderar verktyg

Om din begäran innehåller verktygsdefinitioner räknas även dessa in i Token-antalet:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Token-räkning som inkluderar systemprompt

Systemprompten räknas också in i Token-antalet:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Observera

- Detta API beräknar endast antalet indata-Token och genererar ingen modellutdata.
- Token-räkningsresultatet kan användas för att uppskatta indatastorleken och kontrollera kontextfönstret; den slutliga debiteringen baseras på `usage` i det faktiska Messages-svaret.
- Bilder, PDF:er, verktygsdefinitioner, systemprompter och thinking-konfiguration räknas in i resultatet enligt indatereglerna för den valda modellen.
- Detta API är helt gratis och förbrukar ingen kredit.
