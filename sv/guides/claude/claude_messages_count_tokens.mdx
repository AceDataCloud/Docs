Claude Messages Count Tokens API kan beräkna antalet inmatnings-Token för ett Message utan att faktiskt skapa ett meddelande, inklusive Token-räkning för innehåll som verktyg, bilder och dokument. Detta är mycket användbart när du behöver uppskatta kostnader eller kontrollera om inmatningen överskrider modellens kontextgräns.

Detta dokument introducerar främst användningsflödet för Claude Messages Count Tokens API.

## Ansökningsprocess

För att använda Claude Messages Count Tokens API går du först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API Token och spara den för senare användning.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig omdirigeras du automatiskt till inloggningssidan där du uppmanas att registrera dig och logga in. När det är klart återvänder du automatiskt till den aktuella sidan.

**En API Token kan anropa alla plattformens tjänster, utan att du behöver ansöka separat för varje tjänst.** Vid första ansökan får du gratis kvot för kostnadsfri testning; när kvoten är otillräcklig kan du fylla på ditt allmänna saldo i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Grundläggande användning

Begärandesökvägen för Claude Messages Count Tokens API är `/v1/messages/count_tokens`, vilket överensstämmer med Anthropic:s officiella API. Vi behöver minst ange två obligatoriska parametrar:

- `model`: Välj vilken Claude-modell som ska användas, till exempel den senaste flaggskeppsmodellen `claude-fable-5-1`; den tidigare `claude-fable-5` är fortfarande kompatibel och behålls.
- `messages`: Indatamatrisen med meddelanden, där varje meddelande innehåller `role` (roll) och `content` (innehåll).

Vanliga valfria parametrar:

- `system`: Systemprompt, räknas in i antalet Token.
- `tools`: Verktygsdefinitioner, räknas in i antalet Token.
- `thinking`: Konfiguration för utökat tänkande.
- `tool_choice`: Konfiguration för verktygsval.
- `cache_control`: Cachekontrollkonfiguration på toppnivå eller innehållsblocknivå.

`messages`, `system`, uppspelning av verktygsanrop, URL-bilder och innehållsblock för document/PDF använder samma stabila begärandestruktur som Messages API.

### cURL-exempel

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python-exempel

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Exempel på returresultat:

```json
{
  "input_tokens": 11
}
```

### Använd Anthropic SDK

Claude Messages Count Tokens API accepterar Anthropic SDK:s stabila begärandestruktur och kan anropas via biblioteket `anthropic`. Gränssnittet använder den inbyggda Count Tokens-funktionen för den valda modellen för att räkna inmatningen och kan användas för att kontrollera inmatningsstorleken innan en Messages-begäran skickas.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Token-räkning med verktyg

Om din begäran innehåller verktygsdefinitioner räknas även dessa in i antalet Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Token-räkning med systemprompt

Systemprompten räknas också in i antalet Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Att tänka på

- Detta API räknar endast antalet inmatnings-Token och genererar ingen modellutmatning.
- Resultatet av Token-räkningen kan användas för att uppskatta inmatningsstorleken och kontrollera kontextfönstret; den slutliga debiteringen baseras på `usage` i det faktiska Messages-svaret.
- Bilder, PDF:er, verktygsdefinitioner, systemprompter och thinking-konfiguration räknas in i resultatet enligt inmatningsreglerna för den valda modellen.
- Detta API är helt gratis och förbrukar ingen kvot.
