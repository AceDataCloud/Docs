Claude Messages Count Tokens API kan beräkna antalet indata-Token för ett Message utan att faktiskt skapa meddelandet, inklusive Token-räkning för innehåll som verktyg, bilder och dokument. Detta är mycket användbart när du behöver uppskatta kostnader eller kontrollera om indata överskrider modellens kontextgräns.

Detta dokument introducerar främst användningsflödet för Claude Messages Count Tokens API.

## Ansökningsprocess

För att använda Claude Messages Count Tokens API, gå först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API Token och spara den för senare användning.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig kommer du automatiskt att omdirigeras till inloggningssidan för att registrera dig och logga in, och återvänder automatiskt till den aktuella sidan när du är klar.

**En API Token kan anropa alla plattformstjänster, utan att du behöver ansöka separat för varje tjänst.** Vid första ansökan får du gratis kredit för kostnadsfri testning; när krediten inte räcker till kan du fylla på det allmänna saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Grundläggande användning

Begärandesökvägen för Claude Messages Count Tokens API är `/v1/messages/count_tokens`, vilket är konsekvent med Anthropic:s officiella API. Vi behöver åtminstone ange två obligatoriska parametrar:

- `model`: Välj Claude-modellen som ska användas; `claude-opus-5-5` kan användas för Messages Token Count, såsom den senaste flaggskeppsmodellen `claude-fable-5-1`; den tidigare `claude-fable-5` är fortfarande kompatibel och behålls.
- `messages`: Arrayen med inmatade meddelanden, där varje meddelande innehåller `role` (roll) och `content` (innehåll).

Vanliga valfria parametrar:

- `system`: Systemprompt, som räknas in i Token-antalet.
- `tools`: Verktygsdefinitioner, som räknas in i Token-antalet.
- `thinking`: Konfiguration för utökat tänkande.
- `tool_choice`: Konfiguration för verktygsval.
- `cache_control`: Cachningskontroll på toppnivå eller innehållsblocksnivå.

`messages`, `system`, uppspelning av verktygsanrop, URL-bilder och innehållsblock för document/PDF använder samma stabila begärandestruktur som Messages API.

### cURL-exempel

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python-exempel

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Exempel på returnerat resultat:

```json
{
  "input_tokens": 11
}
```

### Använd Anthropic SDK

Claude Messages Count Tokens API accepterar den stabila begärandestrukturen från Anthropic SDK och kan anropas via biblioteket `anthropic`. Gränssnittet använder den valda modellens inbyggda Count Tokens-funktion för att räkna indata, och kan användas för att kontrollera indatastorleken innan en Messages-begäran skickas.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Token-räkning inklusive verktyg

Om din begäran innehåller verktygsdefinitioner räknas även dessa verktyg in i Token-antalet:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Token-räkning inklusive systemprompt

Systemprompten räknas också in i Token-antalet:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Anmärkningar

- Detta API räknar endast antalet indata-Token och genererar ingen modellutdata.
- Token-räkningsresultatet kan användas för att uppskatta indatastorleken och kontrollera kontextfönstret; den slutliga debiteringen baseras på `usage` i det faktiska Messages-svaret.
- Bilder, PDF-filer, verktygsdefinitioner, systemprompter och thinking-konfigurationer räknas in i resultatet enligt indatreglerna för den valda modellen.
- Detta API är helt kostnadsfritt och förbrukar ingen kredit.
