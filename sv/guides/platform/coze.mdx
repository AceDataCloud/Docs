Coze officiellt stödjer integration av anpassade modeller och erbjuder tre protokoll: OpenAI Chat API, OpenAI Responses API och Anthropic Messages API. De tre vägarna har olika Base URL, vägkomplettering, Header, streaming och verktygsanrop kontrakt, så de måste konfigureras och verifieras separat.

| Väg                      | Status  | Guide                                                                                  |
| ----------------------- | --- | ----------------------------------------------------------------------------------- |
| OpenAI Chat Completions | Experimentell | [Chat Konfiguration](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | Experimentell | [Responses Konfiguration](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | Experimentell | [Messages Konfiguration](https://platform.acedata.cloud/documents/coze-messages-integration)   |

"Experimentell" innebär att den officiella kapaciteten och konfigurationsingången har bekräftats, men olika Coze-regioner, versioner eller paket kan visa olika formulär, Ace Data Cloud måste fortfarande slutföra fast version verifiering enligt protokollet. Tänk inte att framgången för ett protokoll kan extrapoleras till de andra två.

## Konfigurationsprinciper

- Base API URL bör prioriteras att fyllas i med den bas som dokumentet ger; lägg inte till endpoint path som klienten automatiskt kommer att komplettera.
- API Nyckel använd din Ace Data Cloud API Token.
- Modell använd den exakta modell ID som är kompatibel med det valda protokollet i modellkatalogen.
- Efter framgång med vanlig text, bör även streaming och verktygsanrop verifieras.
