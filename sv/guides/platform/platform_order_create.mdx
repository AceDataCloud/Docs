title: "Skapa en påfyllningsorder på AceDataCloud-plattformen"

Skapa en obetald order för en eller flera Application. Skapandet registrerar ordern, men slutför inte betalningen automatiskt; kontrollera `price`, paketet och Application i svaret före betalning.

## Förberedelser

- Skapa en [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Hämta `application_id` från [Application-listan](https://platform.acedata.cloud/documents/platform-application-list).
- Välj ett köpbar `package_id` som matchar Application-typen bland `packages` i [tjänstedetaljerna](https://platform.acedata.cloud/documents/platform-service-detail).

```shell
export PLATFORM_TOKEN='你的账户令牌'
export APPLICATION_ID='你的 Application ID'
export PACKAGE_ID='你的 Package ID'
```

## API-översikt

| Objekt    | Innehåll                                        |
| ---- | ----------------------------------------------- |
| Metod   | `POST`                                          |
| URL  | `https://platform.acedata.cloud/api/v1/orders/` |
| Auktorisering   | Account Token, OAuth token kräver `orders:write`      |
| Body | JSON                                            |

## Begärandetext

En order för en enskild Application använder `application_id` + `package_id`; en batchorder använder `application_ids` + `package_ids` med motsvarande längd. Vanliga ordrar väljer betalningsmetod i det efterföljande anropet `/pay/`. iOS-köp i appen skickar `pay_way: "AppleIAP"` vid skapandet och kan endast välja ett Usage-paket med `metadata.apple_product_id` och `metadata.apple_price`. Apple-köp i appen använder separata förinställda priser i USD och kombineras inte med medlemsrabatter, rabatter för betalningsmetod eller webbplatsens prispåslag; debiteringsbeloppet i lokal valuta för andra regioner gäller enligt Apples betalningsbekräftelsesida.

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/orders/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d "{\"application_id\":\"${APPLICATION_ID}\",\"package_id\":\"${PACKAGE_ID}\"}"
```

## Svarsbeskrivning

Vid lyckat resultat returneras `201` och det nya Order-objektet. Viktiga fält omfattar `id`, `price`, `discount`, `state`, `application_id/application_ids`, `package_id/package_ids`, `expired_at` och tidsfält. Nya ordrar är vanligtvis `Pending`, följt av anrop till [betala order](https://platform.acedata.cloud/documents/platform-order-pay).

- `price` är det betalbara belopp som servern beräknar utifrån paketet, webbplatsens prispåslag och rabatter; låt inte klienten beräkna det själv.
- När Package och Application-tjänsten eller -typen inte matchar returneras `400`.
- Gratis Package som hanteras av systemet kan inte hämtas själv via det offentliga ordergränssnittet.
- Att skapa en order för en Application som inte tillhör det aktuella kontot nekas.
