Returnerar sidindelat den Service-katalog som är synlig på den aktuella webbplatsen, inklusive tjänstetyp, visningsinformation, gratis kvot, paket och associerade API-/Proxy-ID:n. Lämpligt för att bygga en tjänstemarknadsplats eller välja tjänster att ansöka om.

## API-översikt

| Post   | Innehåll                                                |
| --- | ------------------------------------------------- |
| Metod  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| Autentisering  | Offentlig; med inloggningsstatus återspeglar `applied` först det aktuella kontot                        |
| Sidindelning  | `count` + `items`                                 |

## Frågeparametrar

| Parameter               | Typ      | Obligatorisk  | Beskrivning                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | Nej   | Filtrera efter tjänste-ID; upprepade parametrar stöds         |
| `private`        | boolean | Nej   | Filtrera efter offentlig status; webbplatsens synlighetsregler gäller fortfarande      |
| `type`           | string  | Nej   | Tjänstetyp; upprepade parametrar stöds              |
| `tag`            | string  | Nej   | Filtrera efter tagg                    |
| `include_facets` | boolean | Nej   | Lägger till statistik över typer/taggar som är tillgängliga på den aktuella webbplatsen när `true` används |
| `limit`          | integer | Nej   | Antal poster per sida, högst 100              |
| `offset`         | integer | Nej   | Förskjutning för sidindelning                    |
| `ordering`       | string  | Nej   | Stöder endast `rank` eller `-rank`     |

Listan stöder inte filtrering med `alias`; när ett alias redan finns, begär direkt `/api/v1/services/{alias}`. `applied_count` och `updated_at` är inte tillåtna sorteringsfält.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## Svarsförklaring

Svaret är `{count, items}`; `facets` läggs endast till när `include_facets=true`. Tjänsteposter innehåller aktuella offentliga fält såsom `id`, `alias`, `title`, `description`, `type`, `applied_count`, `free_amount`, `unit`, `private`, `need_verify`, `rank`, `tags`, `thumbnail`, `doc_url`, `demo_url`, `api_ids`, `proxy_ids`, `cost`, `packages` med mera.

`applied` i den anonyma listan representerar inte ansökningsstatusen för ett visst konto. När kontorelaterad status krävs bör en giltig inloggningsstatus användas, och [tjänsteansökningslistan](https://platform.acedata.cloud/documents/platform-application-list) ska användas som slutlig grund.
