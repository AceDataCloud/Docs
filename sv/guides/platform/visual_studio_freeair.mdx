FreeAIr är en öppen källkodsutvidgning för Visual Studio 2022/2026, som officiellt kan ansluta till valfri OpenAI-kompatibel API. Begärningsbeteendet kan variera mellan olika versioner av utvidgningen; vid första anslutning, vänligen använd en fast version och slutför nedanstående minimala verifiering.

## Konfiguration

1. Installera FreeAIr från Visual Studio Marketplace eller den officiella lagringen.
2. Öppna FreeAIr-inställningarna och lägg till en OpenAI-kompatibel anslutning.
3. Fyll i Endpoint med `https://api.acedata.cloud/v1`.
4. Fyll i Token med din Ace Data Cloud API-token.
5. Fyll i Model med den exakta modell-ID:n som stöder Chat Completions i modellkatalogen.
6. Skicka `Reply only OK` efter att ha sparat, och testa sedan en gång till med en begäran som har projektkontext.

## Nuvarande gränser

- Denna guide täcker endast FreeAIr och representerar inte Visual Studios inbyggda Copilot som stödjer godtycklig bas-URL.
- Utvidgningsversioner kan ändra sättet att sammanfoga endpoint; vid verifiering bör den slutliga begärnings-URL:en kontrolleras.
- Verktygsanrop och MCP-funktioner inom utvidgningen behöver verifieras oberoende, och kan inte ersättas med framgångsrik vanlig chatt.
