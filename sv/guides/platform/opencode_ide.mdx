OpenCode officiella IDE Extension stöder VS Code, Cursor, Windsurf, VSCodium och andra redigerare, och återanvänder OpenCode lokala runtime och Provider-konfiguration. IDE-tillägget återanvänder den lokala CLI Provider, men begärningskedjan kan variera mellan olika redigerarversioner; vid första anslutning, vänligen använd en fast version och slutför minimi-verifiering.

## Konfigurera Provider

Börja med att följa [OpenCode Terminal-konfigurationen](https://platform.acedata.cloud/documents/opencode-terminal-integration) för att konfigurera Ace Data Cloud Provider i `opencode.json` eller `opencode.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## Installera IDE Extension

1. Kör `opencode` i den integrerade terminalen i redigeraren för att automatiskt installera Extension enligt den officiella processen; du kan också installera den manuellt från motsvarande Marketplace.
2. Ladda om redigeraren.
3. Initiera `Reply only OK` från OpenCode Extension.
4. Utför en gång till en begäran som behöver läsa filer eller ändra kod, bekräfta att IDE Extension använder samma Provider och modell.

## Nuvarande gränser

- Provider-funktionalitet kommer från OpenCode runtime, vilket inte innebär att värdredigeraren har inbyggt stöd för Ace Data Cloud.
- VS Code och olika fork-versioner av tillägg kan skilja sig åt, och versionerna bör dokumenteras separat.
- Vanlig chattframgång kan inte ersätta verifiering av filuppläsning, redigering och verktygsanrop.
