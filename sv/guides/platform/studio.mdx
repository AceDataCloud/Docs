[Ace Data Cloud Studio](https://studio.acedata.cloud) erbjuder enhetligt AI-chatt, bild, video, musik och verktyg för automatisk videoproduktion för kreatörer, drift-, design- och affärsteam. Användare väljer arbetsflöde utifrån sitt kreativa mål och behöver inte först registrera sig, fylla på saldo och växla mellan flera produkter upprepade gånger.

![Studio startsida：gå från kreativa mål till chatt, bild, video och musik](https://cdn.acedata.cloud/uploads/34c26779-82a4-4a9b-b81b-fb98ccd525be)

## Vilka scenarier passar det för

- **Innehållsskapande**：skrivande, research, affischer, omslag, korta videor och bakgrundsmusik；
- **Marknadsföring och drift**：produktbilder, material för sociala medier, aktivitetsvisualer och varumärkesinnehåll；
- **Designutforskning**：redigering av referensbilder, stilutforskning, komposition och lösningar i flera versioner；
- **Affärsteam**：slutför kreativa uppgifter över flera modeller och steg med naturligt språk；
- **Utvecklare och avancerade användare**：konfigurera API Key, Connector, Skill eller lokala verktyg i scenarier som stöds.

De specifika tillgängliga funktionerna kan variera beroende på webbplatskonfiguration, region, konto och produktversion. Det som faktiskt visas på den aktuella sidan gäller.

## Så kommer du igång

1. Besök [studio.acedata.cloud](https://studio.acedata.cloud)；
2. Välj den inloggningsmetod som för närvarande erbjuds på sidan；
3. Gå till verktyget via det kreativa målet på startsidan eller funktionsnavigeringen till vänster；
4. Läs priserna, parametrarna och innehållskraven för den aktuella tjänsten；
5. Verifiera först arbetsflödet med uppgifter till låg kostnad och fortsätt sedan med hög upplösning, långa videor eller batchgenerering.

Olika tjänster har olika faktureringsenheter, behandlingstider och parametrar. Kontrollera den aktuella sidan och användningshistoriken före inskickning och beräkna inte priser utifrån historiska skärmbilder.

## Kärnarbetsflöden

### AI-chatt

Används för skrivande, analys, lärande, programmering och multimodala diskussioner. Specifika modeller, kontextkapacitet och verktygsstöd avgörs av den aktuella modellväljaren.

### AI-bilder

Omfattar text-till-bild, redigering av referensbilder, utökning av bilder, stilöverföring och visuell design. Olika bildtjänster har olika fokus på storlek, textrendering, personkonsistens och redigeringsfunktioner.

### AI-video och automatisk videoproduktion

Stöder videoskapande drivet av text, bilder, referensmaterial eller manus. Arbetsflöden för automatisk videoproduktion kan kombinera manus, bildmaterial, röstpålägg, undertexter och musik; för långa uppgifter bör du uppmärksamma statusförfrågningar, orsaker till fel och den slutliga utmatningens fullständighet.

### AI-musik

Stöder generering av låtar utifrån stil eller låttext samt fortsatt redigering eller utökning enligt de funktioner som erbjuds på sidan. Före kommersiell användning bör du själv kontrollera innehållsrättigheter och reglerna för målplattformen.

### Connector, Skill och avancerade verktyg

Vissa konton eller webbplatser kan använda Connector, Skill och lokala verktyg. Dessa ingångar begränsas av den aktuella produkten, behörigheterna och körmiljön, och är inte öppna som standard för alla användare eller white-label-webbplatser.

## Webb, mobil och desktop

Studio Webbversion finns på `studio.acedata.cloud`. Funktioner och ingångar för webbplatshantering kan skilja sig mellan mobil- och desktopversioner:

- Hantering av white-label-webbplatser visas endast i webbversionen för den aktuella Site-administratören；
- Inbyggda mobil- och desktopappar visar inte alla inställningar för webbplatsdrift；
- Vid mobilbredd används funktionsnavigering längst ned, och komplexa kreativa formulär passar bättre i en desktopwebbläsare.

## Skapa din egen varumärkeswebbplats

Om du behöver driva Studio med eget namn, egen logotyp, sidans domännamn, funktionskatalog och kanalpriser kan du öppna den officiella Studio Webbversionen:

**Användaravatar → Inställningar → Mina webbplatser**

Efter skapandet klickar du på **Hantera** för målwebbplatsen från ”Mina webbplatser” och konfigurerar sedan varumärke, inloggning, funktioner, priser, banners, statistik och anpassat domännamn.

## Gränser för white-label och distribution

- White-label är en Site-konfiguration på en delad plattform, inte en separat distribution eller separat databas；
- Användarkonton, saldon, abonnemang och de flesta tillgångar tillhör det delade systemet；
- Att dölja påfyllning, funktioner eller tjänster styr endast sidvisningen och innebär inte behörighetsisolering；
- Site-påslag är kanalpriset i den vanliga köpprocessen för white-label, inte ett obligatoriskt tenant-pris för kontot i alla ingångar；
- Distributionsintäkter beror på giltiga beställningar, inbjudningsrelationer, nivåer, återbetalningar och riskkontroll, och garanterar inte fast andel, utbetalningshastighet eller inkomstbelopp.

## Rekommendationer för användning

- Viktiga fakta och genererat innehåll behöver granskas manuellt；
- Läck inte lösenord, API Key, identitetshandlingar eller betalningsinformation i promptar, skärmbilder, chattar eller supportärenden；
- Nödvändiga tillstånd ska erhållas för porträtt, röster, varumärken och upphovsrättsskyddat material；
- Gör först ett prov för uppgifter med hög kostnad och öka sedan omfattningen efter att parametrarna har bekräftats；
- Vid avvikelser, notera tid, tjänst, statuskod och offentlig begärandeidentifierare. Skicka inte in fullständiga token.

## OAuth-auktorisering för tredjepartswebbplatser på startsidan

Aktivera OAuth i inställningarna för webbplatskomponenten och fyll i tredjepartens applikations-ID och återanropsadress som registrerats hos ACE Data Cloud. Webbplatsen och återanropsadressen måste använda samma HTTPS-ursprung, som skiljer sig från Studio-ursprunget. Fyll inte i applikationshemligheten i inställningarna.

Tredjepartssidan måste integrera OAuth-meddelandeprotokollet. Inloggade besökare ser den officiella samtyckessidan i komponentområdet; efter samtycke kan tredje part läsa besökarens befintliga API Key via OAuth token. Ingen Key tillhandahålls om användaren inte är inloggad eller avvisar auktoriseringen.

Efter att läsning av Key har tillåtits kan tredje part spara och använda den. Att återkalla OAuth-auktoriseringen gör inte redan kopierade Key ogiltiga; återkalla eller rotera Key separat. Se komponentbeskrivningen för Studio i ”Integrera inloggning med Ace Data Cloud (OAuth 2.0)” för detaljer.
