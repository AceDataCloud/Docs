title: "Hämta orderinformation från AceDataCloud-plattformen"

Fråga efter en order via order-ID. Denna slutpunkt stöder två läslägen: anonym åtkomst returnerar endast de minimala fält som krävs för betalningssidan; när orderägaren använder en Account Token returneras fullständig information.

## API-översikt

| Objekt   | Innehåll                                                        |
| --- | --------------------------------------------------------- |
| Metod  | `GET`                                                     |
| URL | `https://platform.acedata.cloud/api/v1/orders/{order_id}` |
| Autentisering  | Valfri; anonym ger minimal projektion, autentiserad ägare ger fullständig projektion                                    |

`/orders/{id}` och `/orders/{id}/` är båda för närvarande tillgängliga. Order-ID:t är en del av betalningslänken och bör betraktas som en känslig, ogenomskinlig identifierare och får inte spridas offentligt.

## Anonym förfrågan

Betalningssidan kan läsa direkt när inloggningsstatusen har förlorats:

```shell
export ORDER_ID='ditt order-ID'
curl "https://platform.acedata.cloud/api/v1/orders/${ORDER_ID}" \
  -H 'Accept: application/json'
```

Det anonyma svaret innehåller endast `id`, `description`, `price`, `state`, `pay_way`, `pay_url`, `expired_at`, `created_at`. Det returnerar inte konto, Application, Package, interna betalningsidentifierare eller metadata.

## Autentiserad förfrågan

```shell
export PLATFORM_TOKEN='din kontotoken'
curl "https://platform.acedata.cloud/api/v1/orders/${ORDER_ID}" \
  -H 'Accept: application/json' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Orderägaren får fullständig Order-information, inklusive `application` / `applications`, `package` / `packages`, `bank_details`, `invoice_automation` och modellfält. Om användaren är autentiserad men inte är orderägaren returneras `403`; med undantag för superadministratörer.

## Nyckelfält

| Fält            | Beskrivning                                                          |
| ------------- | ----------------------------------------------------------- |
| `state`       | `Pending`, `Paid`, `Finished`, `Expired`, `Failed` eller `Refunded` |
| `pay_way`     | Orderns aktuella betalningsmetod; fältnamnet är inte `payment_method`                             |
| `pay_url`     | Adressen till den värdbaserade betalningssidan eller QR-koden, kan vara tom                                           |
| `price`       | Orderns slutliga betalningsbelopp, den nuvarande ordermodellen tillhandahåller inte fältet `final_price`                         |
| `amount`      | Antal paketkrediter; endast synligt i det fullständiga autentiserade svaret                                            |
| `finished_at` | Tidpunkt då ordern slutfördes; fältnamnet är inte `paid_at`                                      |

Det fullständiga svaret kan innehålla ytterligare fält beroende på betalningsmetod. Klienter bör läsa dem efter behov och alltid undvika att logga känslig metadata i det fullständiga svaret.

## Felhantering

- `404`: Order-ID:t finns inte.
- `403`: Inloggad men inte orderägaren.
- Anonyma förfrågningar returnerar inte `401`; de får endast den minimala offentliga projektionen.
