Ace Data Cloud erbjuder en privat distributionsingång för Hermes Agent. Denna ingång är en kontrollerad tjänst, och tillgänglighet samt valbara resurser baseras på vad som för närvarande visas i konsolen.

## Användningssteg

1. Hitta **Hermes Agent Privat Distribution** på plattformen.
2. Välj tillgänglig konfiguration och skapa tjänst enligt sidans anvisningar.
3. Vänta på att plattformen visar att den är redo.
4. Använd ingången och autentiseringsuppgifterna som tillhandahålls på sidan för att få åtkomst till instansen.
5. Skicka först `Reply only OK`, och börja sedan med den verkliga uppgiften.

Modell, autentiseringsuppgifter, lagring och raderingsbeteende baseras på skapelsens sida och bekräftelsepopup; använd inte YAML från den lokala Hermes-handboken som en direkt distributionskontrakt för plattformen. Exportera först de data som behöver bevaras innan du raderar.

Om konsolen inte visar skapelseingången, betyder det att det aktuella kontot för närvarande inte har öppnat denna tjänst, och du kan istället använda [Hermes Interaktiv Guide](https://platform.acedata.cloud/documents/hermes-wizard-integration) eller [Manuell Konfiguration](https://platform.acedata.cloud/documents/hermes-manual-integration).
