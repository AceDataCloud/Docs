Du har säkert också råkat ut för den här situationen: du använder Claude Code, Cursor eller Codex, kodar på bra, och plötsligt behöver du en bild, lite bakgrundsmusik, en kort video eller vill att den snabbt ska söka efter den senaste informationen. Resultatet är att du upptäcker att agenten själv inte kan göra sådant. Du måste själv leta upp API:er, läsa dokumentation, konfigurera nycklar, skriva anropskod och hantera asynkron polling. När allt är klart har inspirationen redan kallnat.

[AceKit](https://github.com/AceDataCloud/AceKit) finns för att slippa hela den processen. Med en enda rad kommando packar den in funktioner från AceData Cloud – bildgenerering, videogenerering, musikgenerering, webbsökning, LLM-konversationer med mera – direkt i din kodningsagent. Efter installationen behöver du bara uttrycka dig med vanligt språk; agenten laddar själv rätt färdighet, autentiserar själv, pollar själv och slutför arbetet.

## Förstå vad den gör på 30 sekunder

Före installation vs efter installation:

| Vad du säger               | Före installation                   | Efter installation (agenten gör det själv)                      |
| ------------------ | --------------------- | ----------------------------------- |
| "Ge den här README-filen en omslagsbild" | agenten kan inte, och ber dig själv hitta ett bildgenererings-API | Anropar NanoBanana / Flux / Midjourney för att skapa en bild |
| "Gör det här skriptet till en 30 sekunder lång kortvideo"  | Kan inte                    | Anropar Sora / Veo / Kling / Seedance för att skapa en video  |
| "Lägg till lite bakgrundsmusik till denna demo"  | Kan inte                    | Anropar Suno för att skapa en låt                           |
| "Sök efter den senaste informationen om X och sammanfatta den"     | Kan inte ansluta till internet                  | Anropar Google SERP för att hämta resultat i realtid                 |
| "Förkorta den här långa länken"         | Kan inte                    | Anropar en kortlänkstjänst och returnerar en surl.id-länk                  |

Kort sagt: **din kodningsagent går från att ”bara kunna skriva kod” till att ”även kunna skapa bilder, videor och musik samt söka på internet”.**

## Kom igång i tre steg

Hela processen är klar på några minuter och kräver Node.js 18+.

**Steg ett · Skaffa en API-token.** Gå till [konsolen](https://platform.acedata.cloud/console/applications) och kopiera Token – alla funktioner delar samma token. Första ansökan ger gratis kredit, så du kan prova gratis först.

![Kopiera API Token i konsolen](https://cdn.acedata.cloud/dvc3cg.jpg)

**Steg två · Installera.** En enda rad kommando:

```bash
npx acekit
```

Den identifierar automatiskt kodningsagenterna på din dator och installerar hela färdighetsuppsättningen. En verklig körning ser ut så här (den här datorn har endast Claude Code installerat):

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> Om Token inte är angiven uppmanas du interaktivt att klistra in den vid första körningen; du kan också i förväg köra `export ACEDATACLOUD_API_TOKEN=din_token` för en helt obemannad installation. Antalet färdigheter förändras när plattformens funktioner utökas; den aktuella listan som visas av `npx acekit list` gäller.

**Steg tre · Uttryck dig med vanligt språk.** Ladda om agenten och ge sedan instruktioner direkt, till exempel:

```text
Använd short-url-färdigheten för att förkorta https://platform.acedata.cloud/services
```

Agenten laddar själv färdigheten och initierar anropet, och ger dig ett verkligt resultat som går att öppna.

## Kör igenom det på riktigt (med output)

De fyra exemplen nedan är alla **verkliga anrop med resultat som returnerades direkt på plats**, inte illustrationer. `$KEY` i kommandona är din API-token.

**① Förkorta en webbadress (synkront, svar på sekunder)**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

Returnerar `https://surl.id/r/1uKp2kilXQ` – om du öppnar den omdirigeras du med 302 tillbaka till den ursprungliga services-sidan.

**② Webbsökning (synkront)**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

Hämtar Google-resultat i realtid (utdrag):

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ LLM-konversation (synkront, ett gränssnitt för 50+ modeller)**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP是用于统一管理和交换模型上下文信息的协议。
（39 tokens，本次约 0.00007 credit）
```

**④ Bildgenerering (asynkront, cirka 20 sekunder, agenten pollar automatiskt tills bilden är klar)**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

Efter cirka 22 sekunder returneras en verklig bild (HTTP 200 · image/png · 317 KB · cirka 0.13 credit för detta tillfälle):

![Bild som AceKit verkligen har genererat](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

Du behöver egentligen inte komma ihåg dessa gränssnitt – efter att färdigheterna har installerats bygger agenten själv korrekta begäranden enligt respektive `SKILL.md`, hanterar autentisering och polling. Ovanstående visar bara öppet ”vad den gör i bakgrunden”.

## Vad installerar den egentligen

AceKit är ”huvudentrén” till AceDatas hela verktygsyta för utvecklare. För närvarande installerar en enda installation **färdighetsverktygssamlingen (Skills)**:

- **En uppsättning agentfärdigheter**: varje färdighet är en färdigskriven `SKILL.md`-manual – autentisering, asynkron polling, felåterförsök och hur parametrar ska fyllas i är tydligt beskrivna, så agenten behöver bara följa den. Kör `npx acekit list` för att se den aktuella listan (när detta skrivs är det 19 stycken och antalet ökar kontinuerligt):
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **Ett enhetligt Token**: ett `ACEDATACLOUD_API_TOKEN` låser upp alla funktioner, med debitering efter faktisk användning.

Kategoriserat efter funktioner (enligt `npx acekit list`):

| Typ         | Leverantörer                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ Bildgenerering      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 Videogenerering      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 Musik- / ljudgenerering | Suno · Producer · Fish Audio（TTS）                    |
| 💬 LLM-chatt   | Enhetligt gränssnitt för 50+ modeller（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 Sökning       | Google SERP（webb · bilder · nyheter · kartor · videor）                  |
| 🔗 Verktyg       | Kortlänkar · ansiktshantering                                            |

> För samma funktioner erbjuder AceData också separata **MCP-servrar**（Suno、Midjourney、Sora、SERP… publicerade på PyPI / VS Code / Smithery / Docker）、**kommandorads-CLI** och **Python / TypeScript SDK**, som kan användas separat vid behov. AceKit v0.2 planerar att stödja installation av enskilda funktioner med `acekit add <name>`, samt automatisk skrivning av MCP-konfiguration för varje agent.

## Vilka agenter stöds

| Agent                        | Installationsplats för färdigheter                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode osv. | `~/.agents/skills`（låt din agent peka hit） |

Vid installationen upptäcker AceKit automatiskt de agenter som redan är installerade på datorn och installerar endast i de som upptäckts.

## Påskägg: driv själva Claude Code med samma Token

AceDatas gränssnitt är också kompatibelt med Anthropics `/v1/messages`-format, så du**behöver inte en officiell Anthropic-prenumeration**; du kan driva Claude Code med samma AceData Token. Skapa `.claude/settings.local.json` i projektets rotkatalog:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Starta om Claude Code så är det klart——den använder då hela Claude-modellserien och får samtidigt "händer" för bild-, video- och musikgenerering via AceKit. Se [integrationsguiden för Claude Code](https://platform.acedata.cloud/documents/claude-code-integration) för fler detaljer.
