---
title: "Hämta listan över API:er under en AceDataCloud-plattformstjänst"
description: "Platform API guide - Ace Data Cloud"
---

Returnerar via paginering de för närvarande aktiverade och ej utfasade API:erna för tjänsten genom Service UUID. Om endast alias finns, anropa först [tjänstdetaljer](https://platform.acedata.cloud/documents/platform-service-detail) för att hämta `id`.

## API-översikt

| Post   | Innehåll                                                                  |
| --- | ------------------------------------------------------------------- |
| Metod  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| Autentisering  | Offentlig, inget kontotoken krävs                                                           |
| Paginering  | `count` + `items`                                                   |

## Parametrar

| Parameter           | Plats    | Obligatorisk  | Beskrivning                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | Ja   | Service UUID, alias stöds inte           |
| `limit`      | query | Nej   | Antal poster per sida, högst 100                      |
| `offset`     | query | Nej   | Pagineringsoffset                            |
| `ordering`   | query | Nej   | Django-sorteringsuttryck; `rank` eller `-rank` rekommenderas |

Det aktuella API:et stöder inte filtrering med `stage`; det har redan exkluderat `Deprecated` API:er.

```shell
export SERVICE_ID='Ditt Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

Listobjekten använder samma indexstruktur som [plattformens API-lista](https://platform.acedata.cloud/documents/platform-api-list) och innehåller för närvarande `definition`. När en stabil ingång för ett enskilt API behövs, fortsätt att anropa `/api/v1/apis/{api_id}`.

## Felhantering

- Tjänsten finns inte eller är inte synlig på den aktuella webbplatsen: `404`.
- `service_id` måste vara en UUID; alias tolkas inte i denna action.
