Läs offentliga funktionsväxlar och lands-/regionsbedömningar i den aktuella begärandekontexten. Lämpligt för att avgöra om funktioner ska visas vid frontend-start; det är inte webbplatsens varumärke, kontaktuppgifter eller meddelandekatalog.

## API-översikt

| Post   | Innehåll                                              |
| --- | ----------------------------------------------- |
| Metod  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Autentisering  | Offentlig; när inloggningstillstånd medföljer kan vissa funktionsväxlar beräknas per användare                          |

## Frågeparametrar och begärandehuvuden

| Namn                    | Plats     | Beskrivning                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | Tvåsiffrig ASCII-landskod; används för att åsidosätta visningslandet i svaret, utan att ändra säkerhetsbedömningen på serversidan |
| `features`            | query  | Åsidosättningsuttryck för funktionsväxlar; gäller endast växlar som tillåter klientåsidosättning eller superadministratörer        |
| `X-Feature-Overrides` | header | Samma åsidosättningskälla som `features`                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## Verklig svarsstruktur

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| Fält         | Typ            | Beskrivning                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Funktionsväxlar som är synliga för den aktuella begäran; nycklar ändras med plattformskonfigurationen, klienten bör läsa dem efter behov och ange säkra standardvärden för saknade nycklar |
| `country`  | string / null | Landskod med små bokstäver; kan vara `null` när den inte kan identifieras                     |

Hämta inte webbplatsnamn, CDN, valuta, språk, kundtjänstkontaktuppgifter eller meddelanden från detta API; dessa fält ingår inte i det aktuella svarskontraktet.

## Användningsrekommendationer

- Funktionsväxlar beräknas utifrån användare, fingeravtryck och webbplatskontext, så dela inte cache långsiktigt mellan användare.
- `country` som skickas av klienten påverkar endast returvärdet och kringgår inte regionala eller säkerhetspolicyer på serversidan.
- Oigenkända query-parametrar ignoreras; använd endast parametrarna som listas på denna sida.
