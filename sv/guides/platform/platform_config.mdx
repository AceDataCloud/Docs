Läser offentliga funktionsväxlar och land-/regionsbedömningar i den aktuella begärandekontexten. Lämpligt för att avgöra om funktioner ska visas vid frontend-start; det är inte webbplatsens varumärke, kontaktuppgifter eller meddelandekatalog.

## API-översikt

| Objekt   | Innehåll                                              |
| --- | ----------------------------------------------- |
| Metod  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Autentisering  | Offentlig; när inloggningsstatus skickas med kan vissa funktionsväxlar beräknas per användare                          |

## Frågeparametrar och begärandehuvuden

| Namn                    | Plats     | Beskrivning                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | Åsidosättningsuttryck för funktionsväxlar; gäller endast växlar som tillåter klientåsidosättning eller superadministratörer |
| `X-Feature-Overrides` | header | Samma åsidosättningskälla som `features`           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## Verklig svarsstruktur

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| Fält         | Typ            | Beskrivning                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Funktionsväxlar som är synliga för den aktuella begäran; nycklarna ändras beroende på plattformskonfigurationen, klienten bör läsa efter behov och ange säkra standardvärden för saknade nycklar |
| `region`   | string / null | Lands- eller regionskod som upptäcks baserat på begärans IP, med små bokstäver; `null` när den inte kan identifieras        |

Hämta inte webbplatsnamn, CDN, valuta, språk, kundtjänstkontaktuppgifter eller meddelanden från detta API; dessa fält ingår inte i det aktuella svarskontraktet.

## Användningsrekommendationer

- Funktionsväxlar beräknas utifrån användare, fingeravtryck och webbplatskontext; dela inte cache långsiktigt mellan användare.
- Regionväljarens val sparas endast i frontend; använd den valda regionen i första hand vid visning, annars `region` från detta API. Detta API accepterar inte parametrar för regionåsidosättning.
- Okända query-parametrar ignoreras; använd endast parametrarna som anges på denna sida.
