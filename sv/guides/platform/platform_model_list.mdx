Returnerar plattformens offentliga modellkatalog, och svaret använder en struktur i OpenAI-stil med `{ "object": "list", "data": [...] }`. Denna katalog används för modellval och identifiering av funktioner, och innebär inte att det aktuella kontot nödvändigtvis har ansökt om motsvarande tjänst.

## API-översikt

| Post   | Innehåll                                              |
| --- | ----------------------------------------------- |
| Metod  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| Autentisering  | Offentlig, ingen kontotoken krävs                                       |
| Sidindelning  | Ingen sidindelning, alla matchande poster finns i `data`                              |

## Frågeparametrar

| Parameter             | Typ      | Obligatorisk  | Beskrivning                                      |
| -------------- | ------- | --- | --------------------------------------- |
| `owned_by`     | string  | Nej   | Filtrera exakt efter modellleverantörens identifierare i katalogen                        |
| `type`         | string  | Nej   | Filtrera exakt efter modelltyp, till exempel `chat`                     |
| `capability`   | string  | Nej   | Returnera endast modeller vars `capabilities` innehåller denna funktion, till exempel `vision` |
| `with_pricing` | boolean | Nej   | Lägg till offentlig prisinformation vid `1`, `true` eller `yes`            |

`service_id`, `tag`, `limit`, `offset` och `ordering` stöds för närvarande inte; att skicka dem ger ingen motsvarande filtrerings- eller sidindelningseffekt.

## Begäransexempel

```shell
# Alla offentliga modeller
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# Chat-modeller med stöd för vision, inklusive priser
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## Verklig svarsstruktur

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

`pricing` och `credit_usd_rate` på toppnivå visas endast när `with_pricing=true`; inte varje modell har en beräkningsbar `pricing`. Modellobjekten utgår från de offentliga fälten i `config/models.json`, och klienter bör ignorera nya fält.

> Prisfälten är data för katalogvisning. Faktiska affärsanrop omfattas fortfarande av faktureringsreglerna för motsvarande API/tjänst och den slutliga användningsregistreringen.
