LMLocal är en utvidgning för Visual Studio 2022/2026 som officiellt stöder OpenAI-kompatibla API:er och anpassad bas-URL. Konfigurationsingången kan variera med versionen av utvidgningen; vid första anslutning, vänligen använd en fast version och kontrollera verklig redigering, verktygsanrop och användningsregistrering.

## Konfiguration

1. Installera LMLocal från Visual Studio Marketplace eller den officiella lagringen.
2. Lägg till en Custom/OpenAI-kompatibel Provider i Providers.
3. Fyll i Base URL med `https://api.acedata.cloud/v1`.
4. Fyll i Auth Key med din Ace Data Cloud API-token.
5. Fyll i Model med den exakta modell-ID:n som stöder Chat Completions i modellkatalogen.
6. Skicka `Reply only OK` efter att ha sparat, och testa sedan en gång till projektredigeringsflödet.

## Nuvarande gränser

- Denna guide täcker endast LMLocal och representerar inte andra Visual Studio-utvidgningar som delar konfiguration.
- Olika versioner kan hantera chatt-, redigerings-, bygg- och testförfrågningar separat; varje läge måste verifieras oberoende.
- Om klienten automatiskt lägger till `/v1` eller endpoint-sökväg, undvik att duplicera sökvägar.
