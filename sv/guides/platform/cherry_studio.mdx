## 1. Hämta API Key

Öppna [Ace Data Cloud-applikationslistan](https://platform.acedata.cloud/console/applications), gå in i en tillgänglig applikation och kopiera API Key.

![Hämta Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Lägg till Provider

Öppna Cherry Studio, gå till **Inställningar → Modelltjänster → Lägg till leverantör**, och fyll i:

| Fält      | Värde                           |
| ------- | --------------------------- |
| Leverantörsnamn   | `Ace Data Cloud`            |
| Leverantörstyp   | `OpenAI`                    |
| API Key | API Key som just kopierades               |
| API-adress  | `https://api.acedata.cloud` |

![Konfigurationsgränssnitt för att lägga till Ace Data Cloud Provider i Cherry Studio](https://cdn.acedata.cloud/b67a927eae62.png)

Cherry Studio kompletterar automatiskt `/v1/chat/completions` för OpenAI-typen. När den gemensamma ingången används ska du inte lägga till `#` i slutet av adressen, och du behöver inte skapa flera Providers per modellfamilj.

## 3. Lägg till och aktivera modeller

1. Klicka på **Hämta modellista**; om den aktuella versionen inte stöder automatisk hämtning, gå till [modellkatalogen](https://platform.acedata.cloud/models) för att kontrollera och lägg sedan manuellt till namnet på målmodellen, till exempel `claude-opus-5`, `gpt-6-sol`.
2. Klicka på kontrollknappen bredvid API Key för att verifiera anslutningen.
3. Slå på Providerns **Aktivera**-reglage.
4. Välj den nyligen tillagda modellen i konversationsmodellväljaren.

![Cherry Studio Provider- och modellista](https://cdn.acedata.cloud/149de1d088bf.png)

> När modellhämtningen eller den manuella tilläggningen har slutförts, slå på Provider-reglaget uppe till höger.

Skicka `Reply only OK`, och kontrollera anropet i [användningshistoriken](https://platform.acedata.cloud/console/usages). Vid 401, kontrollera Key; om modellen inte visas, kontrollera om Providern är aktiverad; vid 404, kontrollera om det manuellt angivna modellnamnet exakt överensstämmer med `id` i katalogen.

## Om GPT Image 2

Cherry Studios vanliga anpassade chatt-Provider kan inte direkt anropa Images API. Generering och redigering med `gpt-image-2` ska använda Ace Data Clouds dedikerade gränssnitt:

- [GPT Image 2-bildgenerering](https://platform.acedata.cloud/documents/openai-images-generations)
- [GPT Image 2-bildredigering](https://platform.acedata.cloud/documents/openai-images-edits)

Fyll inte i `/openai/images/generations` i chatt-Providern.
