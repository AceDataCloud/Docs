[ChatBox](https://chatboxai.app/) är en AI-klient med öppen källkod som stöder Windows, macOS, Linux, iOS, Android och webben. Den stöder anpassade tjänsteleverantörer av typen ”OpenAI API”, och kan därför anslutas direkt till Ace Data Cloud. Den här artikeln beskriver konfigurationsprocessen.

## Ansökningsprocess

För att ansluta Ace Data Cloud i ChatBox, gå först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications), hämta din API-token och spara den som reserv.

![Hämta Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig, omdirigeras du automatiskt till inloggningssidan där du uppmanas att registrera dig och logga in. Efter inloggning och registrering återgår du automatiskt till den aktuella sidan.

Vid den första ansökan får du en gratis kvot, så att du kostnadsfritt kan prova Ace Data Clouds modelltjänster.

## Ladda ner ChatBox

Gå till [ChatBox officiella webbplats](https://chatboxai.app/) för att ladda ner enligt plattform, eller använd direkt den installationsfria [webbversionen](https://web.chatboxai.app/):

- Skrivbord: Windows `.exe`, macOS `.dmg` (Intel / Apple Silicon skiljs åt), Linux AppImage
- Mobil: App Store, Google Play, officiell Android-direktlänk

## Konfigurera Ace Data Cloud

Starta ChatBox, gå till **Inställningar → Modell → Lägg till anpassad Provider**, ställ in **API Mode** på **OpenAI API Compatible**, och fyll sedan i:

| Fält       | Värde                       | Beskrivning                                      |
| -------- | --------------------------- | --------------------------------------- |
| API-nyckel   | Din Ace Data Cloud-token     | Token som kopierats från konsolen                            |
| API Host | `https://api.acedata.cloud` | Fyll endast i rotdomänen, **lägg inte till `/openai` eller `/v1`**         |
| API Path | `/v1/chat/completions`      | ChatBox har som standard `/chat/completions`, vilket måste ändras manuellt till detta |

![ChatBox Ace Data Cloud Provider-konfigurationsgränssnitt](https://cdn.acedata.cloud/3789c8e3dd4d.png)

ChatBox begärandesökväg är `{API Host} + {API Path}`, så för Host räcker det att endast fylla i rotdomänen:

| API Host                              | Slutlig begäran                                                      | Resultat                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | Korrekt                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (det finns ingen `/v1` under `/openai`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

ChatBox anropar inte automatiskt `/v1/models`; du måste manuellt fylla i modell-ID:n (en per rad) i inmatningsfältet ”Anpassade modeller” längst ned på sidan för modellinställningar. Efter att du har sparat kan de väljas i modellrullgardinsmenyn i chattgränssnittet. Funktionsväxlar, kontextfönster och utmatningsgräns måste fyllas i enligt det aktuella kontraktet för den valda modellen; kopiera inte värden från andra modeller.

## Välj modell

Modellkatalogen uppdateras kontinuerligt. Prioritera modellistan som laddas automatiskt av klienten; om manuell inmatning krävs, begär först `GET https://api.acedata.cloud/v1/models` för att hämta aktuella modell-ID:n och välj sedan enligt de kontext-, bild- och verktygsanropsfunktioner som klienten stöder.

## Verifiera anslutningen

Om du är osäker på om problemet ligger i ChatBox eller nätverket kan du först använda curl för att direkt verifiera slutpunkten (ersätt `{token}` med din token):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Om ett OpenAI-kompatibelt `chat.completion`-objekt returneras betyder det att både token och slutpunkt är redo; om `HTTP 403 used_up` returneras betyder det att token är giltig men att saldot är otillräckligt. Ladda då på saldo i [konsolen](https://platform.acedata.cloud/console/applications).

## Vanliga frågor

### Meddelandet 404 Not Found

Vanligtvis har `/openai` eller `/v1` lagts till extra i API Host. Fyll endast i `https://api.acedata.cloud` för Host, och låt sökvägen använda standardvärdet `/v1/chat/completions`.

### Meddelandet 401 / token_mismatched

Bekräfta att det som klistrats in i ”API-nyckel” är Ace Data Clouds token (utan prefixet `Bearer` och utan extra mellanslag), och att saldot för den tillhörande applikationen är tillräckligt.

### Modeller visas inte i modellrullgardinsmenyn

ChatBox hämtar inte automatiskt modellistan; du måste manuellt fylla i modell-ID:n i rutan ”Anpassade modeller” och spara.

### Vill generera bilder i ChatBox

Ace Data Clouds bildgenerering är ett separat Images API (`/openai/images/generations`) och använder en annan sökväg än chattgränssnittet, så ChatBox bildfunktion kan inte anslutas direkt. Om du behöver skapa bilder, se [API-dokumentationen för bildgenerering](https://platform.acedata.cloud/documents/openai-images-generations) för anrop med curl / SDK.
