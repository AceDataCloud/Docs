[LobeChat](https://lobehub.com/) är en AI-klient med öppen källkod som stöder plugins, kunskapsbaser och självdistribution, och kan användas online eller distribueras med Docker. Den stöder anpassade OpenAI-kompatibla slutpunkter och kan därför anslutas till Ace Data Cloud. Den här artikeln beskriver konfigurationsprocessen.

## Ansökningsprocess

För att ansluta Ace Data Cloud i LobeChat går du först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications), hämtar din API-token och sparar den för senare användning.

![Hämta Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig omdirigeras du automatiskt till inloggningssidan för att registrera och logga in. Efter inloggning eller registrering återvänder du automatiskt till den aktuella sidan.

Vid den första ansökan får du en kostnadsfri kvot, så att du kan prova Ace Data Clouds modelltjänster gratis.

## Konfigurera Ace Data Cloud

Gå till **Appinställningar → Språkmodeller** i LobeChat, hitta kortet **OpenAI** och aktivera det, fyll sedan i:

| Fält       | Värde                              | Beskrivning                         |
| -------- | ------------------------------ | -------------------------- |
| API Key  | Din Ace Data Cloud-token        | Token som kopierats från konsolen               |
| API-proxyadress | `https://api.acedata.cloud/v1` | **Måste sluta med `/v1`**           |
| Klientbegäransläge  | Aktiverat                             | Direktanslutning från webbläsaren, Key passerar inte LobeChat-servern |

![LobeChat OpenAI Provider-konfigurationsgränssnitt](https://cdn.acedata.cloud/629ef9d3084a.png)

> När du använder Chat Completions-gränssnittet ska Responses API Specification förbli avstängt.

LobeChat lägger inte automatiskt till `/v1` till Base URL. Begärandesökvägen är direkt `{API-proxyadress}/chat/completions`:

| API-proxyadress                              | Faktisk begäran                                                   | Resultat                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | Korrekt                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | Fungerar också                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (det finns inget `/v1` under `/openai`) |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404 (`/v1` saknas)             |

LobeChat anropar som standard `/v1/models` för att automatiskt hämta modeller. När Ace Data Cloud returnerar många modeller kan gränssnittet bli mycket långt. Det rekommenderas att manuellt fylla i en allow list i ”Modellista → Anpassade modellnamn”, separerad med engelska kommatecken. Om du vill anpassa visningsnamnet kan du använda `=`, med formatet `MODEL_ID=visningsnamn`.

## Välj modell

Modellkatalogen uppdateras kontinuerligt. Prioritera modellistan som laddas automatiskt av klienten; om du behöver fylla i manuellt ska du först begära `GET https://api.acedata.cloud/v1/models` för att hämta aktuella modell-ID:n och sedan välja enligt de funktioner för kontext, bilder och verktygsanrop som klienten stöder.

## Verifiera anslutningen

Om du är osäker på om problemet ligger i LobeChat eller nätverket kan du först använda curl för att direkt verifiera slutpunkten (ersätt `{token}` med din Token):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Om ett OpenAI-kompatibelt `chat.completion`-objekt returneras betyder det att både Token och slutpunkt är redo; om `HTTP 403 used_up` returneras betyder det att Token är giltig men att saldot är otillräckligt. Ladda då på saldo i [konsolen](https://platform.acedata.cloud/console/applications).

## Avancerat: Docker-självdistribution

Om du vill distribuera en privat version för teamets användning kan du starta den med ett Docker-kommando (ersätt `{token}` med din Token):

```bash
docker run -d \
  --name lobe-chat \
  -p 3210:3210 \
  -e OPENAI_API_KEY={token} \
  -e OPENAI_PROXY_URL=https://api.acedata.cloud/v1 \
  -e ACCESS_CODE=your-secret-password \
  -e OPENAI_MODEL_LIST="MODEL_ID" \
  lobehub/lobe-chat:latest
```

Öppna `http://din-server-IP:3210` och ange `ACCESS_CODE` för att använda tjänsten. Teammedlemmar behöver inte fylla i sina egna Key. Fullständig information om miljövariablerna `OPENAI_API_KEY`, `OPENAI_PROXY_URL`, `OPENAI_MODEL_LIST` och andra som används ovan finns i [LobeChats dokumentation för miljövariabler för modellleverantörer](https://lobehub.com/docs/self-hosting/environment-variables/model-provider). Om du använder nginx som omvänd proxy med HTTPS måste du lägga till `proxy_buffering off;`, annars buffras strömmande svar. För fler distributionsformer, se [Introduktion till LobeChat-självdistribution](https://lobehub.com/docs/self-hosting/start) och [Docker Compose-distribution](https://lobehub.com/docs/self-hosting/platform/docker-compose).

## Vanliga frågor

### Meddelandet 404 Not Found

Vanligtvis beror det på att API-proxyadressen har skrivits som `.../openai/v1` eller att `/v1` saknas. Ändra den till `https://api.acedata.cloud/v1`.

### Modellistan är tom

Aktivera växeln ”Klientbegäransläge”; eller fyll manuellt i modellens allow list under ”Anpassade modellnamn”.

### Meddelandet 401 Unauthorized

Kontrollera att API Key innehåller Ace Data Clouds Token (utan prefixet `Bearer` och utan extra blanksteg), och att det tillhörande programmets saldo är tillräckligt.
