Returnerar synliga API-slutpunkter för den aktuella webbplatsen med sidindelning. Lämpligt för att söka efter API:er efter affärssökväg, tjänst eller publiceringsstadium; om du endast behöver den fullständiga definitionen av ett API, anropa direkt [API-detaljer](https://platform.acedata.cloud/documents/platform-api-detail).

## Gränssnittsöversikt

| Post   | Innehåll                                            |
| --- | --------------------------------------------- |
| Metod  | `GET`                                         |
| URL | `https://platform.acedata.cloud/api/v1/apis/` |
| Autentisering  | Offentlig, ingen kontotoken krävs                                     |
| Sidindelning  | `count` + `items`                             |

## Frågeparametrar

| Parameter        | Typ      | Obligatorisk  | Beskrivning                    |
| --------- | ------- | --- | --------------------- |
| `path`    | string  | Nej   | Exakt matchning av `path` eller `path2` |
| `service` | string  | Nej   | Tjänstealias eller UUID       |
| `stage`   | string  | Nej   | Filtrera efter publiceringsstadium; flera värden kan skickas upprepade gånger      |
| `limit`   | integer | Nej   | Antal poster per sida, maximalt 100           |
| `offset`  | integer | Nej   | Förskjutning för sidindelning                 |

`id`, `service_id` och `tag` är för närvarande inte filterparametrar för listan; att skicka dem ger ingen motsvarande filtreringseffekt.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/apis/' \
  --data-urlencode 'service=midjourney' \
  --data-urlencode 'stage=Production' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/apis/",
    params={"service": "midjourney", "limit": 20},
    timeout=30,
)
response.raise_for_status()
for api in response.json()["items"]:
    print(api["id"], api["method"], api["path"])
```

## Svarsbeskrivning

Produktionssvaret använder `{count, items}`. Varje listpost innehåller för närvarande API-modellfält, samt:

- `document_id`: ID för associerad utvecklardokumentation, kan vara tomt;
- `service_id` / `service`: ID och sammanfattning för huvudtjänsten, kan vara tomma;
- `definition`: OpenAPI-definition, kan vara stor;
- `method`, `path`, `path2`, `stage`, `cost`, `tags`, `metadata` osv.

Listserializeraren innehåller för närvarande `definition`; vid hämtning av hela katalogen bör sidindelning användas och timeout anges. Fält kan läggas till med bakåtkompatibilitet, klienter bör endast läsa de fält som behövs.
