Ladda upp lokala filer till AceDataCloud-plattformens CDN för att få en offentligt tillgänglig URL (i stilen `https://cdn.acedata.cloud/xxxxxx.png`), som omedelbart kan refereras i parametrar som `image_url`, `reference_url` i andra affärsgränssnitt (såsom Midjourney, Suno, Flux).

Tillämpliga scenarier:

- Ladda först upp referensbilden till CDN för att få en URL innan du anropar Midjourney `/midjourney/imagine`.
- Cacha videon som genererades i föregående steg för att använda den som indata i nästa steg.
- Tillfälligt lagra material som laddats upp av användare och undvika att bygga en egen S3.

> ℹ️ Detta gränssnitt tillhör **AceDataCloud-plattformens administrations-API**, med det gemensamma prefixet `https://platform.acedata.cloud/api/v1/`.

## Översikt över gränssnittet

| Objekt            | Innehåll                                       |
| ------------ | ---------------------------------------------- |
| Metod           | `POST`                                         |
| URL          | `https://platform.acedata.cloud/api/v1/files/` |
| Autentisering           | ✅ Kontotoken krävs                                       |
| Content-Type | `multipart/form-data` (**inte JSON**)             |

## Autentiseringsbeskrivning (hur man hämtar kontotoken)

Begärandehuvud:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

Hämtningsmetod: logga in på [AceDataCloud-plattformen](https://platform.acedata.cloud) → [Account Token-konsolen](https://platform.acedata.cloud/console/platform-tokens) → klicka på knappen ”Skapa”. Se [Hantera AceDataCloud-plattformens kontotoken](https://platform.acedata.cloud/documents/platform-token) för detaljer.

## Begärandetext (multipart/form-data)

| Fält     | Typ   | Krävs  | Beskrivning                        |
| ------ | ---- | --- | ------------------------- |
| `file` | file | ✅   | Binär filström. **Standardgränsen för en enskild fil är 100 MB** |

## Begärandeexempel

### cURL

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/files/' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}" \
  -F 'file=@./photo.jpg'
```

### Python

```python
import os
import requests

PLATFORM_TOKEN = os.environ["PLATFORM_TOKEN"]

with open("photo.jpg", "rb") as f:
    resp = requests.post(
        "https://platform.acedata.cloud/api/v1/files/",
        headers={
            "accept": "application/json",
            "authorization": f"Bearer {PLATFORM_TOKEN}",
        },
        files={"file": ("photo.jpg", f, "image/jpeg")},
        timeout=60,
    )

data = resp.json()
print(f"✅ Uppladdningen lyckades: {data['file_url']}")
# Använd direkt i andra affärsgränssnitt:
# requests.post("https://api.acedata.cloud/midjourney/imagine",
#     json={"prompt": "...", "image_urls": [data["file_url"]]}, ...)
```

### Node.js

```javascript
const fs = require('fs')
const FormData = require('form-data')

const form = new FormData()
form.append('file', fs.createReadStream('./photo.jpg'))

const r = await fetch('https://platform.acedata.cloud/api/v1/files/', {
  method: 'POST',
  headers: {
    authorization: `Bearer ${process.env.PLATFORM_TOKEN}`,
    ...form.getHeaders(),
  },
  body: form,
})
const data = await r.json()
console.log('CDN-URL:', data.file_url)
```

## Svarsexempel (HTTP 200)

```json
{
  "file_url": "https://cdn.acedata.cloud/qrd7gw.jpg"
}
```

Använd bara fältet `file_url` direkt i andra affärsgränssnitt—CDN-URL:en är för närvarande offentligt tillgänglig och kräver ingen autentisering; betrakta den inte som ett löfte om permanent arkivering.

## Beskrivning av svarsfält

| Fält         | Typ     | Beskrivning         |
| ---------- | ------ | ---------- |
| `file_url` | string | CDN-åtkomst-URL |

## Felhantering

| HTTP | Svarsexempel                                         | Betydelse                 |
| ---- | -------------------------------------------- | ------------------ |
| 400  | `{"error":"No file provided"}`               | Fältet `file` saknas eller har fel fältnamn |
| 401  | DRF-autentiseringsfelsvar                                   | Kontotoken saknas eller är ogiltig       |
| 413  | `{"error":"File too large","max_bytes":...}` | Filen överskrider 100 MB (standard)    |

## Praktiska tips

- **Ladda upp bilder som referensbilder**: Midjourney `image_urls`, Flux `image_url`, Veo `reference_url` accepterar alla CDN-URL:er, och accepterar **inte** base64. Att först hämta en URL via detta gränssnitt är standardförfarande.
- **Ladda inte upp känsliga data**: Den returnerade URL:en är offentligt tillgänglig; lagringsperioden följer plattformens aktuella lagringspolicy. Använd din egen objektlagring för långsiktig arkivering.
- **Stora mängder uppladdningar**: Kontrollera samtidigheten och ange en timeout för varje uppladdning; genomströmningen beror på filstorlek och nätverksmiljö.
