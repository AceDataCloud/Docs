Hämta fullständig information om en enskild API-slutpunkt via API-ID — jämfört med [listgränssnittet](https://platform.acedata.cloud/documents/platform-api-list) tillkommer fälten `definition` (OpenAPI 3.0 Schema), `service` (information om tillhörande tjänst) och `products` (relaterade produkter).

Lämpligt för scenarier som automatisk generering av SDK:er, matning av verktygsbeskrivningar till LLM Agent och dynamisk rendering av dokumentationswebbplatser.

> ℹ️ Detta gränssnitt tillhör **AceDataCloud-plattformens hanterings-API**, med det enhetliga prefixet `https://platform.acedata.cloud/api/v1/`. Se [Hämta dokumentlistan för AceDataCloud-plattformen](https://platform.acedata.cloud/documents/platform-document-list) för ett komplett gränssnittsindex.

## Gränssnittsöversikt

| Objekt   | Innehåll                                                    |
| --- | ----------------------------------------------------- |
| Metod  | `GET`                                                 |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}` |
| Autentisering  | ❌ Offentlig                                                  |

`/apis/{id}` och `/apis/{id}/` är båda för närvarande tillgängliga; exemplen använder konsekvent formen utan avslutande snedstreck.

## Autentiseringsbeskrivning

Detta gränssnitt är **helt offentligt och kräver varken kontotoken eller inloggningssession**.

## Sökvägsparametrar

| Parameter       | Typ   | Obligatorisk  | Beskrivning                    |
| -------- | ---- | --- | --------------------- |
| `api_id` | UUID | ✅   | API-ID (UUID-format, alias stöds inte) |

## Begäransexempel

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/apis/afc7917f-d89f-4dc9-95c2-863936b02cad' \
  -H 'accept: application/json'
```

### Python

```python
import requests

api_id = "afc7917f-d89f-4dc9-95c2-863936b02cad"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/apis/{api_id}",
    headers={"accept": "application/json"},
    timeout=10,
)
api = resp.json()
print(f"API: {api['title']}")
print(f"路径: {api['path']}")
print(f"所属服务: {api['service']['title']} ({api['service']['alias']})")
print(f"OpenAPI 路径数: {len(api.get('definition', {}).get('paths', {}))}")
```

### Node.js

```javascript
const apiId = 'afc7917f-d89f-4dc9-95c2-863936b02cad'
const r = await fetch(`https://platform.acedata.cloud/api/v1/apis/${apiId}`)
const api = await r.json()
console.log(api.title, api.path, api.service.title)
```

## Beskrivning av svarsfält

Detaljgränssnittet innehåller, utöver fälten i [listgränssnittet](https://platform.acedata.cloud/documents/platform-api-list), även:

| Fält           | Typ     | Beskrivning                                                                                          |
| ------------ | ------ | ------------------------------------------------------------------------------------------- |
| `service`    | object | Kärninformation om tillhörande tjänst: `id`, `title`, `type`, `alias`                                                       |
| `products`   | array  | Lista över relaterade produkter (vanligtvis tom, för användning på driftssidan)                                                                         |
| `definition` | object | **Fullständig OpenAPI 3.0-specifikationsdefinition**, innehåller `paths`, `components`, `info` osv. och kan direkt matas till `openapi-generator` för att generera klientkod |

## Felhantering

| HTTP | code        | Betydelse                 |
| ---- | ----------- | ------------------ |
| 400  | `invalid`   | `api_id` är inte en giltig UUID |
| 404  | `not_found` | API:t finns inte eller har tagits offline        |

## Praktiska tips

- **Fältet `definition` är mycket stort**: OpenAPI Schema för ett enskilt API kan omfatta hundratals rader JSON. Om du bara behöver skapa ett tjänsteindex och inte behöver Schema, bör du använda [listgränssnittet](https://platform.acedata.cloud/documents/platform-api-list) i stället.
- **Vanlig användning för att generera SDK**:
  ```shell
  # 拿到 OpenAPI 文件
  curl -s 'https://platform.acedata.cloud/api/v1/apis/<api_id>' | jq '.definition' > openapi.json

  # 用 openapi-generator-cli 生成 Python 客户端
  openapi-generator-cli generate -i openapi.json -g python -o ./client
  ```
- **Spåra API-ändringar**: Fältet `updated_at` är tidpunkten för den senaste ändringen av schemat. Genom att prenumerera på detta fält kan SDK:n automatiskt genereras på nytt när OpenAPI ändras.
