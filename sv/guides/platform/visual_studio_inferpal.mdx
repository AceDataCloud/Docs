Inferpal är en utvidgning för Visual Studio 2022/2026 som officiellt stöder anslutning till OpenAI-kompatibla tjänster. Utvidgningsversioner kan påverka redigering, verktygsanrop och användningsregistrering; vid första anslutning, vänligen lås versionen och slutför nedanstående minimala verifiering.

## Konfiguration

1. Installera Inferpal från Visual Studio Marketplace eller den officiella lagringen.
2. Öppna Inferpals **Inställningar → Anslutning**.
3. Välj Provider som OpenAI-kompatibel.
4. Fyll i Base URL med `https://api.acedata.cloud/v1`.
5. Fyll i API-nyckeln med din Ace Data Cloud API-token.
6. Fyll i Model med den exakta modell-ID:n som stöder Chat Completions i modellkatalogen.
7. Skicka `Reply only OK` efter att ha sparat, och gör sedan en gång till en begäran som innehåller kodkontext.

## Nuvarande gränser

- Denna guide täcker endast Inferpal och representerar inte Visual Studios inbyggda Copilot eller andra utvidgningar som stöder samma fält.
- Olika versioner kan automatiskt lägga till sökvägar till Base URL; om begäran misslyckas, kontrollera först om den slutliga begäran hamnar på Chat Completions-endpointen.
- Innan den fasta versionen E2E är slutförd, lovar vi inte att alla redigerings-, kompletterings- eller verktygsanropslägen är tillgängliga.
