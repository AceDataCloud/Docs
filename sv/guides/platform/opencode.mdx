OpenCode:s Coding Plan-modell Provider, IDE Extension och MCP är tre oberoende funktioner. IDE Extension kopplar till den lokala OpenCode-runtime och återanvänder samma Provider-konfiguration; det representerar inte värdredigerarens inbyggda stöd för Ace Data Cloud.

| Rutt                            | Beskrivning                                               | Länk                                                                                     | Status      |
| ----------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------- |
| Terminal / CLI / TUI Provider | Använder `opencode.json[c]` och Chat Completions       | [Provider-konfiguration](https://platform.acedata.cloud/documents/opencode-terminal-integration) | Verifierad konfiguration |
| IDE Extension                 | VS Code, Cursor, Windsurf, VSCodium m.fl. kopplar till OpenCode-runtime | [IDE-konfiguration](https://platform.acedata.cloud/documents/opencode-ide-integration)           | Experimentell     |
| MCP                           | Anropar fjärrverktyg inom OpenCode                       | [MCP Översikt](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | Oberoende funktion    |

När Provider-konfigurationen är framgångsrik bör IDE Extension använda samma Provider och modell. Det krävs fortfarande separat verifiering av chatt, filuppläsning, redigering och verktygsanrop inom IDE, och en vanlig begäran från CLI bör inte automatiskt extrapoleras till alla IDE-funktioner.

Modell-ID baseras på [real-tidskatalogen](https://platform.acedata.cloud/models).
