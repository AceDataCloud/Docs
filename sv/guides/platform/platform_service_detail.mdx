Hämta fullständig information för en enskild tjänst via tjänst-ID (UUID) eller alias (`alias`) — fler fält returneras än vid [Hämta lista över tjänster för AceDataCloud-plattformen](https://platform.acedata.cloud/documents/platform-service-list), och relaterade objekt som `apis`, `proxies`, `datasets` och `packages` expanderas dessutom. Lämpligt för scenarier som tjänsteinformationssidor, prisjämförelsesidor och Agent-verktygsbeskrivningar.

> ℹ️ Detta gränssnitt tillhör **AceDataCloud-plattformens administrations-API**, med det gemensamma prefixet `https://platform.acedata.cloud/api/v1/`. Se [Hämta lista över dokument för AceDataCloud-plattformen](https://platform.acedata.cloud/documents/platform-document-list) för ett fullständigt gränssnittsindex.

## Gränssnittsöversikt

| Objekt   | Innehåll                                                    |
| --- | ------------------------------------------------------------- |
| Metod  | `GET`                                                         |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}` |
| Autentisering  | ❌ Offentlig                                                          |

`/services/{id}` och `/services/{id}/` är båda för närvarande tillgängliga; exemplen använder konsekvent formatet utan avslutande snedstreck.

## Autentiseringsinformation

Detta gränssnitt är helt offentligt. **Men om en kontotoken skickas med kommer fältet `applied` i svaret att återspegla det aktuella kontots faktiska ansökningsstatus**, annars är det alltid `false`.

Information om hur du hämtar en kontotoken finns i [Hantera kontotoken för AceDataCloud-plattformen](https://platform.acedata.cloud/documents/platform-token).

## Sökvägsparametrar

| Parameter           | Typ            | Obligatorisk  | Beskrivning                                                    |
| ------------ | ------------- | --- | ----------------------------------------------------- |
| `service_id` | UUID / string | ✅   | Tjänst-ID (UUID) eller alias (t.ex. `midjourney`, `openai`, `webextrator`) |

## Begäransexempel

### cURL

```shell
# 按 UUID 查询
curl 'https://platform.acedata.cloud/api/v1/services/8efa1d83-9b75-4562-b44a-af95ce563d05' \
  -H 'accept: application/json'

# 按 alias 查询
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json'

# 带账户令牌看 applied 状态
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

resp = requests.get(
    "https://platform.acedata.cloud/api/v1/services/midjourney",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
svc = resp.json()
print(f"服务: {svc['title']} ({svc['alias']})")
print(f"已申请: {svc['applied']}, 免费额度: {svc['free_amount']} {svc['unit']}")
print(f"API 数: {len(svc['apis'])}, 套餐数: {len(svc['packages'])}")
for pkg in svc["packages"]:
    print(f"  ¥{pkg['price']:>7.2f}  ->  {pkg['amount']} {svc['unit']}")
```

### Node.js

```javascript
const r = await fetch('https://platform.acedata.cloud/api/v1/services/midjourney', {
  headers: { accept: 'application/json' },
})
const svc = await r.json()
console.log(`${svc.title} - 套餐 ${svc.packages.length} 个 - API ${svc.apis.length} 个`)
```

## Beskrivning av svarsfält

Informationsgränssnittet expanderar följande ytterligare utöver alla fält i [listgränssnittet](https://platform.acedata.cloud/documents/platform-service-list):

| Fält         | Typ    | Beskrivning                                                            |
| ---------- | ----- | ------------------------------------------------------------- |
| `apis`     | array | Fullständig lista över relaterade API-objekt (varje post innehåller `id`, `name`, `title`, `path`, `stage`, `cost`) |
| `proxies`  | array | Fullständig lista över relaterade Proxy-objekt                                              |
| `datasets` | array | Relaterade dataset (om `type=Dataset`)                                      |
| `packages` | array | Paketlista, inklusive `type` (`Usage`/`Period`), `price`, `amount`, `duration`   |

Se [Hämta lista över tjänster för AceDataCloud-plattformen → Beskrivning av svarsfält](https://platform.acedata.cloud/documents/platform-service-list) för definitioner av övriga fält.

## Felhantering

| HTTP | code        | Betydelse                            |
| ---- | ----------- | ----------------------------- |
| 404  | `not_found` | `service_id` (UUID eller alias) finns inte |
| 500  | —           | Vanligtvis beror det på ett felaktigt tillagt snedstreck i slutet av URL:en; ta bort det och försök igen          |

## Praktiska tips

- **`alias` > `UUID`**: Det är stabilare att hårdkoda `alias` (t.ex. `midjourney`) i koden; UUID ändras vid migrering av miljöer.
- **Fältet `apis` innehåller inte OpenAPI-definitioner**: Det fullständiga OpenAPI 3.0-schemat finns i gränssnittet [Hämta API-information för AceDataCloud-plattformen](https://platform.acedata.cloud/documents/platform-api-detail).
- **Hämta en tjänsts "fullständiga funktionalitet"**: Använd detta gränssnitt för att hämta `api_ids` och anropa sedan `/apis/{api_id}` en efter en för att hämta information.
- **Om `applied=true`** kan du direkt [skapa API-autentiseringsuppgifter](https://platform.acedata.cloud/documents/platform-credential-create) för att få den 32-siffriga Token som krävs för att anropa affärsgränssnittet, utan att behöva ansöka igen.
