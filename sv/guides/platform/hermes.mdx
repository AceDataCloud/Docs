Hermes Agent ansluter till Ace Data Cloud via OpenAI Chat Completions-protokollet. Välj en konfigurationsmetod:

| Konfigurationsmetod          | Guide                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| `hermes model` interaktiv guide | [Guide för konfiguration](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| `config.yaml` manuell konfiguration  | [Manuell konfiguration](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| Plattform privat distribution              | [Hanterad distribution](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

Gemensamma parametrar för lokal anslutning:

- Bas-URL: `https://api.acedata.cloud/v1`
- Transport: `chat_completions`
- Leverantör: `custom:acedatacloud`
- API-nyckel: Hämta från [applikationslistan](https://platform.acedata.cloud/console/applications)

Båda lokala metoder skrivs slutligen in i `~/.hermes/config.yaml`, konfigurera inte flera gånger.

Återvänd till [Coding Plan konfigurationscenter](https://platform.acedata.cloud/documents/coding-plan-integration).
