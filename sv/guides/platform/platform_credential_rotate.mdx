---
title: "Rotera AceDataCloud-plattformens API-autentiseringsuppgifter"
description: "Platform API guide - Ace Data Cloud"
---

Generera en ny Token eller ett nytt lösenord för en befintlig Credential. Credential-ID, Application-koppling, kvoter och andra fält förblir oförändrade, och den gamla hemligheten blir omedelbart ogiltig.

> Rotering avbryter klienter som fortfarande använder den gamla hemligheten. Förbered säker distribution och en återställningsplan innan du utför skrivåtgärden.

## API-översikt

| Objekt    | Innehåll                                                                    |
| --------- | --------------------------------------------------------------------------- |
| Metod     | `POST`                                                                      |
| URL       | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}/rotate/` |
| Autentisering | Account Token                                                           |
| Body      | Ingen eller `{}`                                                            |

Hämta `credential_id` från [Credential-listan](https://platform.acedata.cloud/documents/platform-credential-list):

```shell
export PLATFORM_TOKEN='din kontotoken'
export CREDENTIAL_ID='Credential-ID:t som ska roteras'

curl -X POST \
  "https://platform.acedata.cloud/api/v1/credentials/${CREDENTIAL_ID}/rotate/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Vid lyckat resultat returneras den uppdaterade Credential. När `type=Token` ska den nya `token` läsas; när `type=Identity` ska det nya `password` läsas. Behandla det fullständiga svaret som en hemlighet och uppdatera anroparna omedelbart.

## Felhantering

- `401`: Account Token är ogiltig.
- `403`: Saknar behörighet att hantera denna Credential.
- `404`: Credential-ID:t finns inte.
