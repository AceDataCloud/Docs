GitHub Copilot officiella BYOK-dokument listar VS Code som en stödd lokal klient och stöder OpenAI-kompatibla leverantörer. VS Code-version, företagspolicy och modellens synlighet kan påverka den slutliga endpointen; vid första anslutning, vänligen kontrollera de faktiska begärningarna enligt nedan.

## Konfigurationsområde

1. Bekräfta att ditt GitHub Copilot-konto eller organisation har aktiverat BYOK/Custom Models-funktionen.
2. Lägg till OpenAI-kompatibel leverantör i VS Code:s Copilot-modellhantering.
3. Fyll i Base URL med `https://api.acedata.cloud/v1`.
4. Fyll i API-nyckeln med din Ace Data Cloud API-token.
5. Fyll i Model med den exakta modell-ID:n som är kompatibel med det valda protokollet i modellkatalogen.
6. Skicka `Reply only OK` i Copilot Chat och testa sedan en gång till med arbetsytans kontext.

## Nuvarande gränser

- Copilot App, CLI, GitHub Desktop, Enterprise BYOK och VS Code:s konfigurationsavtal skiljer sig åt, denna guide tillämpar inte direkt steg för andra klienter på VS Code.
- Organisationspolicyer kan förbjuda individer att lägga till leverantörer eller modeller.
- Tab-completion, Chat, Agent och bakgrundsuppgifter kan använda olika modellvägar och bör verifieras separat.
