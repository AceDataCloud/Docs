Returnerar kontots påfyllningsordrar med paginering, lämpligt för att hitta order-ID, kontrollera betalningsstatus och stämma av.

## Förberedelser

Skapa en [Account Token](https://platform.acedata.cloud/documents/platform-token) och hämta aktuellt konto-UUID från `GET /api/v1/platform-tokens/me/`.

```shell
export PLATFORM_TOKEN='din kontotoken'
export USER_ID='ditt konto-UUID'
```

## API-översikt

| Objekt   | Innehåll                                              |
| --- | ----------------------------------------------- |
| Metod  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/orders/` |
| Autentisering  | Account Token, OAuth-token kräver `orders:read`       |
| Paginering  | `count` + `items`                               |

Vanliga användare måste ange sitt eget `user_id`; annars kan pagineringen returnera `403` när objekt utan behörighet påträffas.

## Frågeparametrar

| Parameter                    | Typ       | Obligatorisk     | Beskrivning                                                        |
| --------------------- | -------- | ------ | --------------------------------------------------------- |
| `user_id`             | UUID     | Obligatorisk för vanliga användare | Kontot som ordern tillhör; upprepade parametrar stöds                                             |
| `pay_way`             | string   | Nej      | Filtrera efter betalningsmetod; upprepade eller kommaseparerade värden stöds                                        |
| `state`               | string   | Nej      | Filtrera efter status; upprepade eller kommaseparerade värden stöds                                          |
| `created_at_from/to`  | datetime | Nej      | Intervall för skapandetid                                                    |
| `finished_at_from/to` | datetime | Nej      | Intervall för slutförandetid                                                    |
| `limit` / `offset`    | integer  | Nej      | Paginering                                                        |
| `ordering`            | string   | Nej      | `created_at`, `-created_at`, `finished_at` eller `-finished_at` |

Den aktuella listan stöder inte filtrering med `application_id`, `service_id`, `package_id`, `payment_method` eller `tag`; fältnamnet för betalningsmetod är `pay_way`.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/orders/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode 'state=Paid,Finished' \
  --data-urlencode 'pay_way=Stripe' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## Svarsbeskrivning

Svaret är `{count, items}`. Listobjekt i produktion innehåller `id`, `user_id`, `application_id/application_ids`, `package_id/package_ids`, `price`, `amount`, `discount`, `remaining_amount`, `state`, `pay_way`, `pay_id`, `pay_url`, `finished_at`, `expired_at`, `invoice`, `metadata` och tidsfält.

- Faktiska statusar är `Pending`, `Paid`, `Finished`, `Expired`, `Failed`, `Refunded`; `Cancelled` finns inte.
- Fältnamnen är `pay_way`, `finished_at`, `discount` och `price`, inte `payment_method`, `paid_at`, `discount_rate` eller `final_price`.
- `price` är orderpostens slutliga pris; valuta- och avräkningsdetaljer kan finnas i kontrollerad metadata och kan inte härledas enbart från betalningsmetoden.
