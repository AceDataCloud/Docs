---
title: "Konfigurera global saldodelning för AceDataCloud Application"
description: "Platform API guide - Ace Data Cloud"
---

Konfigurera `allow_consume_global`. När den är aktiverad kan kvalificerade förbrukningsbaserade Applications fortsätta använda kontots globala saldo när deras eget saldo är otillräckligt.

## Förberedelser

- Skapa och spara säkert en [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Hämta `application_id` för den Application som du äger från [listan över tjänsteansökningar](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='din kontotoken'
export APPLICATION_ID='ditt Application ID'
```

## API-översikt

| Objekt    | Innehåll                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------- |
| Metod   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Autentisering   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

Vid lyckat resultat returneras det uppdaterade Application-objektet. Utgå från `allow_consume_global` i svaret, i stället för att anta att det begärda värdet alltid sparas.

> Applications av typen `Period` får inte förbruka globalt saldo. Även om `true` begärs kommer servern att behålla detta fält som `false`.

## Felhantering

- `401`: Account Token är ogiltig eller saknas.
- `403`: Det aktuella kontot är inte ägaren av denna Application.
- `404`: Application ID finns inte.

Påfyllningsingången för det globala saldot och tillgängliga paket ska baseras på plattformskonsolen och de faktiska paket som returneras av [skapande av order](https://platform.acedata.cloud/documents/platform-order-create); anta inte att paket av typen `Wallet` finns.
