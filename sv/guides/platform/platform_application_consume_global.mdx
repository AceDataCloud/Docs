---
title: "Konfigurera delning av globalt saldo för AceDataCloud Application"
description: "Platform API guide - Ace Data Cloud"
---

Konfigurera `allow_consume_global`. När det är aktiverat kan kvalificerade förbrukningsbaserade Application fortsätta använda kontots globala saldo när deras egna saldo är otillräckligt.

## Förberedelser

- Skapa och spara säkert [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Hämta det `application_id` som du äger från [listan över tjänsteansökningar](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='din kontotoken'
export APPLICATION_ID='ditt Application ID'
```

## API-översikt

| Post    | Innehåll                                                                                           |
| ---- | -------------------------------------------------------------------------------------------------- |
| Metod   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Auktorisering   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

Vid lyckat resultat returneras det uppdaterade Application-objektet. Utgå från `allow_consume_global` i svaret, i stället för att anta att det begärda värdet alltid sparas.

> Application av typen `Period` får inte förbruka globalt saldo. Även om `true` begärs kommer servern att behålla detta fält som `false`.

## Felhantering

- `401`: Account Token är ogiltig eller saknas.
- `403`: Det aktuella kontot är inte ägare till denna Application.
- `404`: Application ID finns inte.

Påfyllningsingången för globalt saldo och tillgängliga paket ska baseras på plattformskonsolen och de faktiska paket som returneras av [orderskapande](https://platform.acedata.cloud/documents/platform-order-create); anta inte att det finns paket av typen `Wallet`.

## Applikationer med godkänd övertrassering

När det skrivskyddade fältet `allow_overdraft=true` för en förbrukningsbaserad applikation är satt kan applikationen fortsätta dra avgifter från sitt eget saldo, även om saldot blir negativt, och kommer inte att växla till det globala kontot på grund av otillräckligt saldo. Applikationer utan aktiverad övertrassering följer fortfarande `allow_consume_global`; om övertrassering tillåts efter växlingen beror på inställningen för den globala Application som den faktiska debiteringen sker från.
