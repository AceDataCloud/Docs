---
title: "Exportera API-anropsloggar från AceDataCloud-plattformen"
description: "Platform API guide - Ace Data Cloud"
---

Ladda ner API-anropsdetaljerna för det aktuella kontot direkt som CSV, lämpligt för ekonomisk avstämning, offlineanalys eller lagring av stora mängder poster. Om du bara behöver visa ett litet antal detaljer på sidan, använd först [listan över anropsloggar](https://platform.acedata.cloud/documents/platform-usage-list).

Sökintervallet för anropsloggar och faktureringssammanfattningar är de senaste 60 dagarna; förfrågnings- och svarstexter sparas separat under de senaste 30 dagarna. Att texten löper ut ändrar inte den faktiska debiteringen, användningen eller den sammanställda statistiken för posten.

## Förberedelser

1. Logga in på [AceDataCloud-plattformen](https://platform.acedata.cloud).
2. Skapa en kontotoken i [Account Token-konsolen](https://platform.acedata.cloud/console/platform-tokens), och spara den omedelbart i en lösenordshanterare eller Secret Manager.
3. Hämta efter behov filtrerings-ID från [listan över tjänsteansökningar](https://platform.acedata.cloud/documents/platform-application-list), [listan över API-autentiseringsuppgifter](https://platform.acedata.cloud/documents/platform-credential-list) eller [API-listan](https://platform.acedata.cloud/documents/platform-api-list).

Fullständig tokenbeskrivning finns i [Hantera kontotoken](https://platform.acedata.cloud/documents/platform-token). Kontotoken och Credential för att anropa verksamhets-API:er kan inte användas omväxlande.

```shell
export PLATFORM_TOKEN='din kontotoken'
```

## API-översikt

| Post           | Innehåll                                                   |
| -------------- | ---------------------------------------------------------- |
| Metod          | `GET`                                                      |
| URL            | `https://platform.acedata.cloud/api/v1/usage/apis/export/` |
| Autentisering  | `Authorization: Bearer ${PLATFORM_TOKEN}`                  |
| OAuth Scope    | `usage:read`（`platform:read` / `platform` kan utökas för att inkludera） |
| Svar           | `200 text/csv; charset=utf-8`                              |
| Filnamn        | `usages.csv`                                               |

Detta API returnerar CSV synkront som en ström, skapar ingen exportuppgift och returnerar inte heller JSON eller en nedladdningslänk. Endast när både start- och sluttid inte anges exporteras som standard poster från början av den aktuella kalendermånaden till den aktuella tidpunkten; om endast en gräns anges fylls den andra sidan inte automatiskt ut med månadens gräns.

## Frågeparametrar

| Parameter         | Typ      | Obligatorisk | Standard | Beskrivning                         |
| ----------------- | -------- | ------------ | -------- | ----------------------------------- |
| `perspective`     | string   | Nej          | `both`   | `billing`, `actor` eller `both`     |
| `service_id`      | UUID     | Nej          | —        | Filtrera efter tjänst; stöder upprepade parametrar |
| `application_id`  | UUID     | Nej          | —        | Filtrera efter Application; stöder upprepade parametrar |
| `api_id`          | UUID     | Nej          | —        | Filtrera efter API; stöder upprepade parametrar |
| `credential_id`   | UUID     | Nej          | —        | Filtrera efter API-autentiseringsuppgifter; stöder upprepade parametrar |
| `status_code`     | integer  | Nej          | —        | Stöder upprepade eller kommaseparerade värden |
| `created_at_from` | datetime | Nej          | —        | ISO 8601-starttid                  |
| `created_at_to`   | datetime | Nej          | —        | ISO 8601-sluttid                   |

Exportintervallet är alltid begränsat till poster som är synliga för det aktuella kontot som betalningspart och/eller faktisk anropare; export mellan konton stöds inte.

## Begäransexempel

Spara CSV för den aktuella månaden direkt:

```shell
curl --fail-with-body --location \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

Exportera efter Application, tid och statuskod:

```shell
export APPLICATION_ID='ditt Application-ID'

curl --fail-with-body --get \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'status_code=200,500' \
  --data-urlencode 'created_at_from=2026-09-01T00:00:00Z' \
  --data-urlencode 'created_at_to=2026-09-08T00:00:00Z' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

Python-strömspara och kontrollera integritet:

```python
import os
from pathlib import Path

import requests

url = "https://platform.acedata.cloud/api/v1/usage/apis/export/"
headers = {"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"}
params = {
    "created_at_from": "2026-09-01T00:00:00Z",
    "created_at_to": "2026-09-08T00:00:00Z",
    "perspective": "both",
}
output = Path("usages.csv")

with requests.get(url, headers=headers, params=params, stream=True, timeout=120) as response:
    response.raise_for_status()
    if not response.headers.get("content-type", "").startswith("text/csv"):
        raise RuntimeError("服务器没有返回 CSV")
    with output.open("wb") as file:
        for chunk in response.iter_content(chunk_size=64 * 1024):
            file.write(chunk)

last_line = output.read_text(encoding="utf-8").splitlines()[-1]
if last_line.startswith("# truncated:") or last_line.startswith("# error:"):
    raise RuntimeError(f"导出不完整：{last_line}")
```

## CSV-kolumner

Ordningen på CSV-rubrikerna är fast:

```text
Usage ID,API,Status Code,Deducted Amount,Original Amount,Trace ID,Created At
```

| Kolumn             | Beskrivning                                      |
| ------------------ | ------------------------------------------------ |
| `Usage ID`         | ID för anropslogg                                |
| `API`              | API-titel; kan vara API-ID eller tomt värde om ingen matchning kan göras |
| `Status Code`      | HTTP-statuskod                                   |
| `Deducted Amount`  | Slutligt faktiskt avdragen kvot                  |
| `Original Amount`  | Ursprunglig kvot före tillämpning av rabatt      |
| `Trace ID`         | Identifierare för begäransspårning               |
| `Created At`       | Postens skapandetid, ISO 8601                    |

Kvotenheten bestäms av `service.unit` för motsvarande Application.

## Avgör om exporten är fullständig

Högst 1 000 000 dataposter kan matas ut per gång. När servern redan har börjat returnera CSV går det inte att ändra ett fel som uppstår under tiden till en annan HTTP-status, därför måste klienten kontrollera den sista raden:

- `# truncated:`：radgränsen har nåtts; exportera segmentvis med mindre tidsfönster.
- `# error:`：strömavläsningen avbröts; minska intervallet och exportera igen.

När avstämningsprogrammet ser någon markerare måste det betrakta filen som ofullständig och får inte bokföra den tyst.

## Fel och återförsök

| Situation                    | Hantering                                  |
| --------------------------- | ------------------------------------------ |
| `400 usage_history_expired` | Justera till inom de senaste 60 dagarna med `available_from` i svaret |
| `401 not_authenticated`     | Kontrollera att Account Token finns, är korrekt och inte har raderats |
| Icke-CSV-svar                | Spara inte som en lyckad fil; läs först felsvaret och korrigera begäran |
| Nedladdningen avbryts eller markerare | Minska tidsfönstret och exportera igen med en backoff-strategi |
