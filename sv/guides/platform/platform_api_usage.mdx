Returnerar offentligt exempel på anropsposter för ett visst API under de senaste 15 minuterna, för att snabbt kunna observera aktuell status. Det är inte ett räknargränssnitt som aggregeras efter statuskod och kan inte användas för personlig fakturering, SLA eller fullständig användningsstatistik.

## Gränssnittsöversikt

| Post   | Innehåll                                                           |
| --- | ------------------------------------------------------------ |
| Metod  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| Auktorisering  | Offentlig, inget kontotoken krävs                                                    |
| Gräns  | Efter sammanslagning av de senast skapade/slutförda posterna returneras högst 5 000 poster                                    |

`api_id` hämtas från [API-listan](https://platform.acedata.cloud/documents/platform-api-list).

```shell
export API_ID='ditt API-ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## Verklig svarsstruktur

Svaret är direkt en array och använder inte ett paginerings-envelope:

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| Fält            | Beskrivning        |
| ------------- | --------- |
| `api_id`      | API-ID    |
| `created_at`  | Postens skapandetid    |
| `trace_id`    | Identifierare för begärandespårning    |
| `status_code` | HTTP-statuskod  |
| `elapsed`     | Anropstid, i sekunder |

När API:t inte finns kan det för närvarande också returnera en tom array, eftersom denna action direkt frågar efter nylig usage efter ID utan att först verifiera API-objektet. För att beräkna framgångsgrad måste klienten själv gruppera de returnerade exemplen; för att kontrollera personlig debitering ska du använda gränssnitt på kontonivå.
