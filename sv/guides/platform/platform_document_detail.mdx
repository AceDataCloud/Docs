title: "Retrieve AceDataCloud Platform Document Details"
description: "Platform API guide - Ace Data Cloud"
---

Retrieve the full content and navigation relationships of a single document through the document UUID or alias. When the alias is known, it can be requested directly without first filtering from the list.

## API Overview

| Item   | Content                                                              |
| --- | --------------------------------------------------------------- |
| Method  | `GET`                                                           |
| URL | `https://platform.acedata.cloud/api/v1/documents/{id_or_alias}` |
| Authentication  | Public; can be read directly as long as the UUID or alias is known                                       |

## Parameters

- `id_or_alias`: Document UUID, current alias, or old alias retained in `redirect_from`.
- `lang`: Optional language hint; `Accept-Language` can also be used. The final content language is determined by the response `content_locale`.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/documents/platform-token' \
  --data-urlencode 'lang=zh-CN' \
  -H 'Accept: application/json'
```

## Response Description

Details use a single object response, currently containing:

- `id`, `alias`, `redirect_from`, `name`, `title`, `type`, `rank`, `tags`;
- `content`, `content_mode`, `content_locale`, `content_hash`;
- `parent`, `sibling`, and public `children` summaries sorted by rank;
- `api` / `proxy` / `dataset` / `integration` associations, as well as `agent` (when present).

The response does not have a `breadcrumbs` field. When building breadcrumbs, you can continue retrieving the details of its `parent`, or use cached document directory relationships.

## Error Handling

- The ID/alias does not exist or does not meet the visibility of the current site: `404`. `private` only controls list visibility and does not prevent people who know the link from reading it directly; it cannot be used as a confidentiality boundary.
- The current route uses the no-trailing-slash form; do not rely on the proxy layer to automatically append a slash.
