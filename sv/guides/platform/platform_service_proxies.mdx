---
title: "Hämta Proxy-listan under AceDataCloud-plattformstjänsten"
description: "Platform API guide - Ace Data Cloud"
---

Returnera sidindelat de Proxy-slutpunkter som är monterade på tjänsten via Service UUID. Om endast alias finns, anropa först [tjänstedetaljer](https://platform.acedata.cloud/documents/platform-service-detail) för att hämta `id`.

## Gränssnittsöversikt

| Post   | Innehåll                                                                     |
| --- | ---------------------------------------------------------------------- |
| Metod  | `GET`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| Auktorisering  | Offentlig, ingen kontotoken krävs                                                              |
| Sidindelning  | `count` + `items`                                                      |

## Parametrar

| Parameter                 | Plats    | Obligatorisk  | Beskrivning                               |
| ------------------ | ----- | --- | -------------------------------- |
| `service_id`       | path  | Ja   | Service UUID, alias stöds inte           |
| `limit` / `offset` | query | Nej   | Sidindelning                               |
| `ordering`         | query | Nej   | Django-sorteringsuttryck; `rank` eller `-rank` rekommenderas |

```shell
export SERVICE_ID='Ditt Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## Svarsbeskrivning

Listobjekten serialiseras av Proxy-modellen, och fält som har verifierats online omfattar `id`, `service_id`, `title`, `endpoint`, `price`, `stage`, `rank`, `tags`, `metadata`, `document_id`, `service` och tidsfält.

- Affärsingångsfältet är `endpoint`, inte `path`.
- Prissättningsfältet är `price`, inte `cost`.
- När Service-typen inte är Proxy eller när ingen Proxy är monterad returneras tomma `items`.

Offentliga integrationer förlitar sig endast på `endpoint` och publicerade funktioner, och bör inte förlita sig på opublicerade implementeringsdetaljer.
