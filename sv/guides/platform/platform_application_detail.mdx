Hämta fullständig status för en enskild tjänstansökan via Application ID — jämfört med listgränssnittet tillkommer det fullständiga `service`-objektet (inklusive `packages`-paket) och andra fält, lämpligt för detaljsidor.

> ℹ️ Detta gränssnitt tillhör **AceDataCloud plattformshanterings-API**, med det gemensamma prefixet `https://platform.acedata.cloud/api/v1/`. För ett fullständigt gränssnittsindex, se [Hämta AceDataCloud-plattformens dokumentlista](https://platform.acedata.cloud/documents/platform-document-list).

## API-översikt

| Post   | Innehåll                                                              |
| --- | --------------------------------------------------------------------- |
| Metod  | `GET`                                                                 |
| URL | `https://platform.acedata.cloud/api/v1/applications/{application_id}` |
| Autentisering  | ✅ Kontotoken krävs                                                              |

`/applications/{id}` och `/applications/{id}/` fungerar båda för närvarande; exemplen använder konsekvent formen utan avslutande snedstreck.

## Autentiseringsanvisningar (hur man hämtar kontotoken)

Begärandehuvud:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

För detaljerade instruktioner om hur du hämtar den, se [Hantera AceDataCloud-plattformens kontotoken](https://platform.acedata.cloud/documents/platform-token).

> ℹ️ Till skillnad från listgränssnittet utförs **behörighetskontrollen för detaljgränssnittet direkt på det enskilda objektet**, och `?user_id=` behöver inte skickas. Men om du försöker komma åt någon annans ansökan får du `403 permission_denied`.

## Sökvägsparametrar

| Parameter               | Typ   | Obligatorisk  | Beskrivning             |
| ---------------- | ---- | --- | -------------- |
| `application_id` | UUID | ✅   | Application ID |

## Begäransexempel

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/applications/82f57141-2323-4453-8730-60f7d833a2da' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

app_id = "82f57141-2323-4453-8730-60f7d833a2da"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/applications/{app_id}",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
app = resp.json()
print(f"服务：{app['service']['title']}")
print(f"剩余 {app['remaining_amount']} {app['service']['unit']} / 已用 {app['used_amount']}")
```

### Node.js

```javascript
const appId = '82f57141-2323-4453-8730-60f7d833a2da'
const r = await fetch(`https://platform.acedata.cloud/api/v1/applications/${appId}`, {
  headers: { authorization: `Bearer ${process.env.PLATFORM_TOKEN}` },
})
console.log(await r.json())
```

## Beskrivning av svarsfält

Fältens betydelse är densamma som i [listgränssnittet](https://platform.acedata.cloud/documents/platform-application-list), med följande extra innehåll:

| Fält        | Typ     | Beskrivning                                                        |
| --------- | ------ | --------------------------------------------------------- |
| `service` | object | Fullständigt tjänsteobjekt (inklusive `packages`-paket, `unit`, `free_amount`), som kan användas för att direkt rendera panelen med tjänsteinformation |

## Felhantering

| HTTP | code                | Betydelse                  |
| ---- | ------------------- | ------------------- |
| 401  | `not_authenticated` | Kontotoken saknas              |
| 403  | `permission_denied` | Denna Application tillhör inte dig  |
| 404  | `not_found`         | Application finns inte eller har tagits bort |

## Praktiska tips

- **Använd listan först för batchövervakning**: Hämta Application-listan på en gång och bedöm utifrån varje tjänsts enhet och tröskelvärde, för att undvika att begära detaljer en i taget.
- **När du behöver se antalet autentiseringsuppgifter**: Använd [API-autentiseringsuppgiftslistan](https://platform.acedata.cloud/documents/platform-credential-list) och filtrera på `application_id`.
- **Felsökningsidéer för `disabled=true`**: Kontrollera supportärenden / e-postnotiser för att se om tjänsten har stängts av på grund av riskkontroll, obetalda avgifter eller otillåtna anrop; den kan inte återaktiveras via API utan du måste kontakta kundtjänst.
