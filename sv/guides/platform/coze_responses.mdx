Coze officiella dokumentation för anpassade modeller stöder OpenAI Responses API och tillhandahåller Base API URL, API-nyckel och modellfält. Olika Coze-uthyrningsversioner kan hantera sökvägssammanfogning, strömmande utdata och verktygsanrop på olika sätt, så kontrollera varje punkt nedan vid första anslutning.

## Konfiguration

1. Gå till Coze modellhantering och lägg till en anpassad modell.
2. Välj Protokoll OpenAI Responses API.
3. Fyll i Base API URL med `https://api.acedata.cloud/v1`.
4. Fyll i API-nyckel med din Ace Data Cloud API-token.
5. Fyll i Modell med den exakta modell-ID som stöder Responses API i modellkatalogen.
6. Spara och slutför Coze:s anslutningstest.
7. Skicka `Reply only OK` i Bot/Agent och testa verktygsanropet igen.

## Nuvarande gränser

- Olika Coze-regioner, versioner eller paket kan visa olika formulär.
- Base API URL bör använda bas, lägg inte till `/responses` igen; om nuvarande UI tydligt kräver fullständig API URL, följ formulärens anvisningar.
- Chat Completions, Responses och Anthropic Messages är tre oberoende vägar och kan inte ersätta varandra för verifiering.
