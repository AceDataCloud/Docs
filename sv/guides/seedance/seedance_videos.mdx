Den här artikeln introducerar en typ av integrationsinstruktioner för SeeDance Videos Generation API, som kan generera officiella videor från SeeDance genom att ange anpassade parametrar.

## Ansökningsprocess

För att använda SeeDance Videos Generation API, gå först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API Token och spara den för senare användning.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig kommer du automatiskt att omdirigeras till inloggningssidan där du uppmanas att registrera dig och logga in. När detta är klart återvänder du automatiskt till den aktuella sidan.

**En API Token kan anropa alla tjänster på plattformen, och behöver inte ansökas om separat för varje tjänst.** Vid första ansökan får du en gratis kvot för kostnadsfri testning; när kvoten är otillräcklig kan du fylla på det gemensamma saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [SeeDance Videos Generation API →](https://platform.acedata.cloud/documents/seedance-videos)

## Grundläggande användning

Börja med att förstå det grundläggande användningssättet: ange prompten `content.text`, typen `content.type=text` samt modellen `model`, så kan du få det bearbetade resultatet. Det specifika innehållet är följande:

<p><img src="https://cdn.acedata.cloud/seedance_parameters.png" width="500" className="m-auto" /></p>

Här kan vi se att vi har angett Request Headers, inklusive:

- `accept`: vilket format på svarsresultatet som ska tas emot, här anges `application/json`, det vill säga JSON-format.
- `authorization`: nyckeln för att anropa API:t, som kan väljas direkt i rullgardinsmenyn efter ansökan.

Dessutom har vi angett Request Body, inklusive:

- `model`: modellen för att generera videon.
  - **Seedance 1.x-serien**: `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`, `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-lite-t2v-250428`, `doubao-seedance-1-0-lite-i2v-250428`.
  - **Seedance 2.0-serien** (stöder multimodala referenser för karaktärer samt ljud och video): `doubao-seedance-2-0-260128` (standard), `doubao-seedance-2-0-fast-260128` (snabb), `doubao-seedance-2-0-mini-260615` (lättviktig).
  - **Seedance 2.5**: `doubao-seedance-2-5-260628`, stöder upp till 30 sekunder, rena ljudreferenser, fler material, videoredigering och förlängning.
- `content`: inmatningsinnehållsarray, `type` kan vara `text` (prompt), `image_url` (referensbild), `audio_url` (referensljud), `video_url` (referensvideo). Bilder kan ange användningsområde via `role`: `first_frame` (första bildrutan) / `last_frame` (sista bildrutan) / `reference_image` (referens för karaktär / motiv).
- `resolution`: utdataupplösning, valbart `480p` / `720p` / `1080p` / `4k`. 2.5 stöder 480p, 720p och 1080p; 2.0 Fast/Mini stöder 480p och 720p; 2.0 Standard stöder upp till 4k.
- `ratio`: bildförhållande, valbart `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive`.
- `duration`: videolängd (sekunder, heltal). 1.0-serien 2–12; 1.5 Pro 4–12; 2.0-serien 4–15; 2.5 4–30. 1.5/2.x stöder `-1` (automatisk längd).
- `seed`: slumpmässigt frö, heltal, -1 till 4294967295.
- `camerafixed`: om kameran ska vara fast, `true` / `false`.
- `watermark`: om vattenstämpel ska läggas till, `true` / `false`.
- `generate_audio`: om video med ljud ska genereras, `true` / `false`, stöds av Seedance 1.5 Pro och 2.x-serien.
- `return_last_frame`: om bild-URL:en för videons sista bildruta ska returneras i resultatet.
- `omni_reference_task_type`: endast 2.5; `auto` / `reference` / `edit` / `extend`.
- `output_format`: endast 2.5; `mp4` / `mov`, standard är `mp4`.
- `tools`: endast 2.5; stöder för närvarande online-sökverktyget `web_search`, som kan begränsa antalet resultat, antalet nyckelord och sökkällor.
- `priority`: valbar uppgiftsprioritet för 2.5, heltal 0–9, standard är 0.
- `safety_identifier`: stabil anonym identifierare för slutanvändare med högst 64 tecken; använd hash eller internt anonymt ID och skicka inte namn, e-postadress eller telefonnummer.
- `execution_expires_after`: tidsgräns för uppgiften (sekunder), intervall 3600–259200.
- `callback_url`: asynkron återanropsadress. När den har angetts returnerar API:t omedelbart `task_id`, och när uppgiften är klar POST:as resultatet till denna adress.
- `async`: valfritt. När den anges som `true` returnerar gränssnittet omedelbart `task_id`, utan att `callback_url` behöver anges. Hämta sedan resultatet genom att polla motsvarande gränssnitt för uppgiftsfråga.

## Beskrivning av inline-parametrar

I slutet av prompten `content[].text` kan genereringsparametrar skickas genom att lägga till `--parameter value` (gammal metod, svag validering, standardvärdet används automatiskt vid felaktig ifyllnad). Den fullständiga parameterlistan är följande:

| Inline-parameter       | Motsvarande fält              | Beskrivning      | Värdeintervall                                                          |
| ---------- | ----------------- | ------- | ------------------------------------------------------------- |
| `--rs`     | `resolution`      | Utdatupplösning   | `480p` / `720p` / `1080p`                                     |
| `--rt`     | `ratio`           | Bildförhållande     | `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` |
| `--dur`    | `duration`        | Videolängd (sekunder) | 2–12                                                          |
| `--frames` | `frames`          | Antal videobildrutor    | Heltal i [29, 289] som uppfyller 25+4n (**stöds endast av 1.0-serien**)                       |
| `--fps`    | `framespersecond` | Bildfrekvens      | Stöder endast `24`                                                      |
| `--seed`   | `seed`            | Slumpmässigt frö    | -1 till 4294967295                                               |
| `--cf`     | `camerafixed`     | Om kameran är fast | `true` / `false`                                              |
| `--wm`     | `watermark`       | Om vattenstämpel ska läggas till  | `true` / `false`                                              |

> **Rekommenderad metod**: Använd motsvarande fält på toppnivå direkt i Request Body (såsom `resolution`, `ratio` osv.). Detta är ett läge med stark validering och ger tydliga felmeddelanden om parametrarna är felaktigt ifyllda, vilket gör det enklare att felsöka problem.

## Generera videor med ljud

Seedance 1.5 Pro- och 2.x-serierna stöder generering av videor med ljud via parametern `generate_audio`:

```json
{
  "model": "doubao-seedance-1-5-pro-251215",
  "content": [
    {
      "type": "text",
      "text": "A girl holds a fox, the wind blows her hair, you can hear the sound of the wind"
    }
  ],
  "generate_audio": true,
  "ratio": "16:9",
  "duration": 5
}
```

1.0-serien stöder inte denna parameter.

## Seedance 2.5 multimodal generering, redigering och förlängning

`doubao-seedance-2-5-260628` stöder 480p / 720p / 1080p, 4–30 sekunder eller automatisk längd, och höjer materialgränsen till 30 referensbilder, 10 referensvideor och 10 referensljudklipp (högst 50 totalt). 2.5 stöder även att endast skicka referensljud, utan att längre kräva att bilder eller videor tillhandahålls samtidigt.

Vid vanlig multimodal generering kan `omni_reference_task_type` utelämnas, anges som `auto` eller uttryckligen anges som `reference`. Videoredigering och förlängning måste skicka in `reference_video`:

```json
{
  "model": "doubao-seedance-2-5-260628",
  "content": [
    {"type": "text", "text": "Replace the sky with a warm sunset while preserving the subject and camera motion."},
    {"type": "video_url", "role": "reference_video", "video_url": {"url": "https://cdn.acedata.cloud/input.mp4"}}
  ],
  "resolution": "720p",
  "ratio": "adaptive",
  "duration": -1,
  "omni_reference_task_type": "edit",
  "output_format": "mov"
}
```

- `reference`: Skicka in minst en `reference_image`, `reference_video` eller `reference_audio`; 2.5 stöder att endast skicka referensljud.
- `edit`: Måste använda `ratio: adaptive` och `duration: -1`; utdatalängden debiteras enligt det faktiska resultatet.
- `extend`: Måste använda `ratio: adaptive`; `duration` kan vara 4–30 eller `-1`.
- `auto`: Modellen väljer automatiskt generering, redigering eller förlängning baserat på prompten och materialet.
- Om uppgiftstypen inte matchar materialet eller prompten misslyckas uppgiften och returnerar ett lokaliserbart parameterfel; justera enligt ovanstående begränsningar och skicka in igen.

## Första bildrutan för bild-till-video

Om du vill ha en bild-till-video-uppgift måste parametern `content` först innehålla ett objekt med `type` som `image_url`, och fältet `image_url` måste vara i objektformat: `{"url": "https://..."}` eller Base64-format `{"url": "data:image/png;base64,..."}`.

> **Obs**: `image_url` stöder inte att en sträng skickas direkt (t.ex. `"image_url": "https://cdn.acedata.cloud/e724d7f13d.png"`). Objektformatet `"image_url": {"url": "https://..."}` måste användas, annars returneras fel 400.

Motsvarande kod:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": [
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/i2v_foxrgirl.png"
            }
        },
        {
            "type": "text",
            "text": "A girl holds a fox in her arms. She opens her eyes and gazes tenderly at the camera, while the fox affectionately holds her back. As the camera slowly pulls away, her hair is gently blown by the wind. --ratio adaptive  --dur 5"
        }
    ],
    "model": "doubao-seedance-1-0-pro-250528"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

- role: Anger första bildrutan eller sista bildrutan.
- image_url
  - url Bildlänk
    Samtidigt måste `content` även mata in typen `text` som prompt

## Karaktärs- och ljud-/videomultimodala referenser (Seedance 2.0)

**Seedance 2.0-serien** (`doubao-seedance-2-0-260128`, `doubao-seedance-2-0-fast-260128`, `doubao-seedance-2-0-mini-260615`) stöder `reference_image`, `reference_audio` och `reference_video`. Eget eller auktoriserat material kan användas för att bibehålla konsekvens i karaktärer, motiv, rörelser, kamerarörelser, ljud och rytm.

> Ladda endast upp eget eller auktoriserat material med riktiga personer och karaktärer. Olika modeller stöder material med riktiga personer på olika sätt; begärans format förblir oförändrat, och ett tydligt fel returneras om materialet inte uppfyller kraven.

Viktiga punkter:

- Endast modeller i **Seedance 2.0-serien** stöder `reference_image`; för 1.x-modeller ska `first_frame` / `last_frame` användas (första och sista bildrutan för bild-till-video).
- Första bildrutan i bild-till-video, första och sista bildrutan i bild-till-video och referens för alla modaliteter är tre ömsesidigt uteslutande scenarier: `first_frame` / `last_frame` kan inte användas tillsammans med `reference_image` / `reference_video` / `reference_audio`.
- Om du vill ange första och sista bildrutan i en referens för alla modaliteter, märk bilderna som `reference_image` och skriv i prompten ”bild 1 som första bildruta” eller ”bild 2 som sista bildruta”; om första och sista bildrutan måste låsas strikt, använd endast `first_frame` / `last_frame`.
- Övre gräns för antalet multimodala referenser: högst **9** `image_url`; 2.0 stöder även `audio_url` (`role` är `reference_audio`, högst 3 objekt) och `video_url` (`role` är `reference_video`, högst 3 objekt).
- **Krav för referensljud (`audio_url`)**: format `wav` / `mp3`; **varje enskilt klipp ska vara 2–15 sekunder**, högst 3 klipp och **den totala längden får inte överstiga 15 sekunder**; varje enskilt klipp får inte överstiga 15 MB. Ljud utanför längdintervallet misslyckas under materialbearbetningen.
- **Krav för referensvideo (`video_url`)**: format `mp4` / `mov`; **varje enskild video ska vara 2–15 sekunder**, högst 3 videor och **den totala längden får inte överstiga 15 sekunder**.
- För referensbilder rekommenderas foton med **en person, ansiktet framåt, tydliga och utan skymmande objekt**; ju tydligare ansiktet är, desto högre blir likheten.

## Asynkron återuppringning

Eftersom SeeDance Videos Generation API har en relativt lång genereringstid (cirka 1–2 minuter), kan du använda asynkront läge via fältet `callback_url` för att undvika att HTTP-anslutningen är upptagen under en lång tid.

Övergripande flöde: klienten anger `callback_url` när begäran initieras, och API:et returnerar omedelbart ett svar som innehåller `task_id`; efter att uppgiften har slutförts skickar plattformen genereringsresultatet till `callback_url` i form av POST JSON, och resultatet innehåller också `task_id` för att möjliggöra koppling.

```json
{
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd"
}
```

När uppgiften är slutförd är innehållet som plattformen skickar till `callback_url` följande:

```json
{
```

## Felhantering

Vid anrop av API:et returnerar API:et motsvarande felkod och information om ett fel uppstår. Till exempel:

- `400 token_mismatched`：Felaktig begäran, möjligen på grund av saknade eller ogiltiga parametrar.
- `400 api_not_implemented`：Felaktig begäran, möjligen på grund av saknade eller ogiltiga parametrar.
- `401 invalid_token`：Obehörig, ogiltig eller saknad auktoriseringstoken.
- `429 too_many_requests`：För många begäranden, du har överskridit hastighetsgränsen.
- `500 api_error`：Internt serverfel, något gick fel på servern.
