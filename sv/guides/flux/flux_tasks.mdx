Huvudfunktionen för Flux Tasks API är att fråga om exekveringsstatusen för en uppgift genom att ange det uppgifts-ID som returneras av Flux Images Generation API eller Flux Videos API.

Detta dokument kommer att introducera integrationsanvisningarna för Flux Tasks API i detalj, för att hjälpa dig att enkelt integrera och fullt ut nyttja detta API:s kraftfulla funktioner. Genom Flux Tasks API kan du enkelt fråga om uppgiftsexekveringsstatusen för Flux Images Generation API.

Se [Integreringsguide för Flux Videos API](https://platform.acedata.cloud/documents/flux-videos-integration) för ett komplett exempel på videoinlämning och polling. Ingen ytterligare genereringsavgift tas ut för att fråga om befintliga uppgifter.

## Ansökningsprocess

För att använda Flux Images Generation API ska du först hämta din API-token från [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) och spara den för senare användning.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig omdirigeras du automatiskt till inloggningssidan där du uppmanas att registrera dig och logga in. När det är klart återgår du automatiskt till den aktuella sidan.

**En API-token kan anropa alla plattformens tjänster, utan att du behöver ansöka separat för varje tjänst.** Vid den första ansökan får du gratis kredit som du kan använda för att prova tjänsten kostnadsfritt; när krediten är otillräcklig kan du fylla på det gemensamma saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Flux Images Generation API →](https://platform.acedata.cloud/documents/flux-images)

## Begäransexempel

Flux Tasks API kan användas för att fråga om resultat från Flux Images Generation API. För information om hur du använder Flux Images Generation API, se dokumentationen [Flux Images Generation API](https://platform.acedata.cloud/documents/flux-images-integration).

Vi använder ett uppgifts-ID som returneras av tjänsten Flux Images Generation API som exempel för att visa hur detta API används. Anta att vi har ett uppgifts-ID: 2db0168c-2373-4367-8d9a-9dc778802e8a, därefter visar vi hur man genom att ange ett uppgifts-ID.

### Ange begäranderubrik och begärandetext

**Request Headers** inkluderar:

- `accept`: Anger att svar i JSON-format ska tas emot, fyll i `application/json` här.
- `authorization`: Nyckeln för att anropa API:t, som kan väljas direkt från rullgardinsmenyn efter ansökan.

**Request Body** inkluderar:

- `id`: Det uppladdade uppgifts-ID:t.
- `action`: Åtgärden som ska utföras på uppgiften.

Några kodexempel följer:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "2c454ff3-4f8f-47f0-8147-acb29a84d1c2",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/flux/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "2c454ff3-4f8f-47f0-8147-acb29a84d1c2",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Det returnerade resultatet innehåller flera fält. Fältet `request` är request body när uppgiften startas, medan fältet `response` är response body som returneras efter att uppgiften har slutförts. Fältbeskrivningarna är följande.

- `id`, ID:t för denna bildgenereringsuppgift, används för att unikt identifiera denna bildgenereringsuppgift.
- `request`, begärandeinformationen i frågan om bilduppgiften.
- `response`, returinformationen i frågan om bilduppgiften.
- `created_at`, tidpunkten då uppgiften skapades, Unix-tidsstämpel (sekunder, flyttal).
- `started_at`, tidpunkten då uppgiften började köras, Unix-tidsstämpel (sekunder, flyttal).
- `finished_at`, tidpunkten då uppgiften slutfördes, Unix-tidsstämpel (sekunder, flyttal). Detta fält returneras inte när uppgiften inte är slutförd.
- `elapsed`, tiden det tar att köra uppgiften, i sekunder (flyttal, med 3 decimaler). Detta fält returneras inte när uppgiften inte är slutförd.

Detta används för att fråga om detaljinformation för bilduppgifter med flera uppgifts-ID:n. Skillnaden från ovan är att `action` måste väljas som `retrieve_batch`

**Request Body** inkluderar:

- `ids`: Arrayen med uppladdade uppgifts-ID:n.
- `action`: Åtgärden som ska utföras på uppgiften.

## Felhantering

Vid anrop av API:et returnerar API:et motsvarande felkod och information om ett fel uppstår. Till exempel:

- `400 token_mismatched`：Felaktig begäran, möjligen på grund av saknade eller ogiltiga parametrar.
- `400 api_not_implemented`：Felaktig begäran, möjligen på grund av saknade eller ogiltiga parametrar.
- `401 invalid_token`：Obehörig, ogiltig eller saknad auktoriseringstoken.
- `429 too_many_requests`：För många begäranden, du har överskridit hastighetsgränsen.
- `500 api_error`：Internt serverfel, något gick fel på servern.
