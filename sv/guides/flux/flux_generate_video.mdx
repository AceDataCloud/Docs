Flux Videos API använder `POST /flux/videos` för videogenerering, bild-till-video med nyckelbilder, videofortsättning och utkastförbättring. `action=generate` (standard), `mode` väljer genereringsläge; för att fråga resultat används enhetligt den befintliga `POST /flux/tasks`.

> För närvarande Beta. Text-till-video, bild-till-video, videofortsättning och utkastförbättring är tillgängliga. HTTP 200 och uppgifts-ID innebär endast att uppgiften har accepterats; du måste fortsätta fråga efter slutresultatet.

## 1. Hämta API Token

1. Registrera eller logga in på [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications), skapa en applikation och hämta API Token. En generell API Token kan anropa plattformstjänster; bekräfta att applikationen har behörighet att anropa Flux-tjänsten och tillgängligt saldo.
2. Se paket och priser för varje åtgärd på [Flux-tjänstsidan](https://platform.acedata.cloud/services/flux?tab=pricing). När saldot är otillräckligt, fyll på på [konsolens saldosida](https://platform.acedata.cloud/console/coin).
3. Begäran använder `Authorization: Bearer <din Token>`. Token ska lagras i miljövariabler på serversidan och får inte skrivas i frontend-sidor, offentliga kodförråd, skärmbilder eller callback-URL:er.

![Ansök om API Token i konsolen](https://cdn.acedata.cloud/dvc3cg.jpg)

Koden i denna artikel läser enhetligt miljövariabler:

```bash
export ACEDATACLOUD_API_TOKEN='替换为你自己的 API Token'
```

| Objekt      | Värde                                               |
| ------- | ----------------------------------------------- |
| API-rotadress | `https://api.acedata.cloud`                     |
| Skicka videouppgift  | `POST /flux/videos`                             |
| Fråga befintlig uppgift  | `POST /flux/tasks`                              |
| Autentisering      | `Authorization: Bearer $ACEDATACLOUD_API_TOKEN` |
| Begärandeformat    | `Content-Type: application/json`                |

För fullständiga fält och onlinedebuggning, se [Flux Videos API](https://platform.acedata.cloud/documents/flux-videos), och för uppgiftsfrågor, se [Flux Tasks API](https://platform.acedata.cloud/documents/flux-tasks).

## 2. Välj åtgärd och indata

| action                      | mode            | Indata                       | Resultat            |
| --------------------------- | --------------- | ------------------------ | ------------- |
| `generate` (standardvärdet när action utelämnas) | `t2v`           | `prompt`                 | Generera video från text       |
| `generate`                  | `i2v`           | `prompt`、`keyframes`     | Generera video från en eller flera nyckelbilder |
| `generate`                  | `v2v`           | `prompt`、`start_video`   | Fortsätt baserat på inmatad video      |
| `generate`                  | `draft_enhance` | `draft_task_id` för ditt färdigställda utkast | Förbättra detta utkast         |

Genereringsmodellen är `flux-3`, och `action` är `generate` (standard). Välj text-till-video, bild-till-video, videofortsättning eller utkastförbättring via `mode`.

### Gemensamma genereringsparametrar

| Parameter                 | Beskrivning                                                           |
| ------------------ | ------------------------------------------------------------ |
| `mode`             | Obligatorisk; `t2v`, `i2v`, `v2v` eller `draft_enhance`                       |
| `prompt`           | Obligatorisk för vanlig generering; utkastförbättring tillåter inte att den ursprungliga prompten skrivs över                                        |
| `duration`         | t2v/i2v är heltal på 5–20 sekunder, v2v är heltal på 5–15 sekunder, eller `auto`; den slutliga utdatalängden kan avvika något från det begärda värdet |
| `resolution`       | `hd`, `fhd`, `qhd`, `uhd`; vanlig generering har standardvärdet `hd`, utkastförbättring har standardvärdet `fhd`              |
| `aspect_ratio`     | `auto`, `21:9`, `2:1`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `9:21`   |
| `draft`            | Om ett utkast först ska genereras; utkast stöder endast `hd`                                           |
| `generate_audio`   | Om synkroniserat ljud ska genereras; `false` är ett giltigt värde, behåll explicit booleskt värde                               |
| `safety_tolerance` | Valfri; heltal från 0–4                                                   |
| `async`            | Rekommenderas att sättas till `true`, returnerar plattformsuppgifts-ID direkt och frågar sedan resultaten                                |
| `callback_url`     | Valfri; HTTP(S)-adress som tar emot slutligt JSON-resultat; när den är inställd accepteras uppgiften också asynkront                        |

Material-URL:er måste kunna läsas av tjänsten. Om tillfälliga signerade URL:er används, ska tillräcklig giltighetstid reserveras för nedladdning och bearbetning. Använd inte webbsidesadresser som bild- eller videofiladresser.

## 3. Text-till-video: fullständiga testade begäranden och resultat

Följande begäran kördes framgångsrikt i produktionsgränssnittet före prisjusteringen 2026-10-02. Att utelämna `action` verifierade standardbeteendet för generering; `async=true` undviker lång väntan på HTTP-anslutningen.

```bash
curl -X POST 'https://api.acedata.cloud/flux/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light, steady camera, no text.",
    "duration": 5,
    "resolution": "hd",
    "draft": true,
    "async": true
  }'
```

Acceptanssvar (verkligt uppgifts-ID):

```json
{
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607"
}
```

Spara `task_id` från ditt eget svar och fortsätt fråga; använd inte uppgifts-ID:n från dokumentationsexempel för att fråga efter resultat från andra konton.

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"替换为本次返回的 task_id"}'
```

Fältet `response` som returneras av uppgiftsfrågan innehåller det slutliga affärsresultatet. | --------------------------------- | ---------------------------------------- |
| `success`                         | Om den slutliga uppgiften lyckades; att task_id returneras i mottagningsfasen är inte lika med success=true |

Det nya priset den 2026-10-02 har sänkts med cirka 6.33 %; samma utkast på 5.041667 sekunder kostar enligt nuvarande pris 2.798125185 Credits (före konsumentrabatt), eller 2.5183126665 Credits om 10 % konsumentrabatt fortfarande gäller. Fakturor för historiska uppgifter räknas inte om. Andra kontons abonnemang och rabatter kan skilja sig; detta är inte ett fast pris i USD för alla användare.

## 4. Bild-till-video: vanlig och med tidsbestämda nyckelrutor

Nedan följer parameterexempel där material-URL:er behöver ersättas; detta är inte ett påstående om att exemplet redan har körts framgångsrikt. Efter att genereringen är klar, fråga enligt processen ovan; resultatstrukturen är densamma.

En eller två bilder använder en vanlig array:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "The camera slowly moves around the product in soft studio light.",
  "keyframes": [
    "https://example.com/first-frame.jpg"
  ],
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "async": true
}
```

När tidpunkter för nyckelrutor anges, använd par av `[sekunder, bild-URL]`:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "A smooth transition from morning light to a warm sunset.",
  "keyframes": [[0, "https://example.com/start.jpg"], [5, "https://example.com/end.jpg"]],
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

1–10 nyckelrutor tillåts. Arrayer med tid måste vara i stigande tidsordning, tiden är 0–20 sekunder, och vanliga URL:er och tidsbestämda poster får inte blandas. Tre eller fler vanliga nyckelrutor måste uttryckligen ange duration och kan inte använda auto.

## 6. Först utkast, sedan förbättring

1. Använd `draft=true`、`resolution=hd` för att generera ett utkast och vänta på att det lyckas.
2. Hämta plattformens utkast-ID från slutliga `data[0].draft_task_id`.
3. Skicka en förbättringsbegäran med applikationsuppgifter som har samma tillhörighet:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "draft_enhance",
  "draft_task_id": "Ersätt med ditt eget slutförda utkast-ID",
  "resolution": "fhd",
  "async": true
}
```

Utkastförbättring kan inte skicka in `prompt`、`duration`、`aspect_ratio`、`version`、`generate_audio`、`draft`、`keyframes`、`start_video` för att skriva över det ursprungliga innehållet. Utkastcachen är en tillfällig resurs, förbättra den i tid; permanent lagring eller ett fast antal lagringsdagar garanteras inte. Utkast som inte tillhör dig/den aktuella applikationen, ofullständiga utkast och utgången cache kan inte återanvändas. Utkast och förbättring är två uppgifter och debiteras separat efter lyckad körning.

## 7. Python-anrop från början till slut

Installera `requests`, ange din egen Token och kör skriptet nedan för att slutföra ”skicka in en gång → polla → mata ut video-URL”. Både förfrågningar och nätverksåterförsök bör använda det ursprungliga task_id för att undvika att betalda uppgifter skickas in flera gånger.
```python
import os
import time
import requests

base_url = "https://api.acedata.cloud"
headers = {
    "Authorization": "Bearer " + os.environ["ACEDATACLOUD_API_TOKEN"],
    "Accept": "application/json",
}
payload = {
    "action": "generate",
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light.",
    "duration": 5,
    "resolution": "hd",
    "draft": True,
    "async": True,
}
submitted = requests.post(base_url + "/flux/videos", json=payload, headers=headers, timeout=120)
submitted.raise_for_status()
accepted = submitted.json()
if accepted.get("error"):
    raise RuntimeError(accepted["error"])
task_id = accepted["task_id"]
print("Task ID:", task_id)  # 持久化保存，用于恢复轮询

# 30 分钟是本示例的客户端等待上限，不是服务的完成时限承诺。
deadline = time.monotonic() + 30 * 60
while time.monotonic() < deadline:
    polled = requests.post(
        base_url + "/flux/tasks",
        json={"action": "retrieve", "id": task_id},
        headers=headers,
        timeout=30,
    )
    polled.raise_for_status()
    task = polled.json()
    if task.get("error"):
        raise RuntimeError(task["error"])
    result = task.get("response") or task.get("result")
    if isinstance(result, dict) and result.get("success") is True:
        print("Video:", result["data"][0]["video_url"])
        print("Usage:", result.get("usage"))
        print("Cost:", result.get("cost"))
        break
    if isinstance(result, dict) and result.get("error"):
        raise RuntimeError(result["error"])
    time.sleep(10)
else:
    raise TimeoutError("Still processing; resume polling with task_id=" + task_id)
```

Efter en nätverkstimeout ska du inte betrakta en okänd status som ett fel och omedelbart skicka in på nytt. Om `task_id` redan har erhållits, fortsätt att fråga efter uppgiften; registrera `task_id` och `trace_id` för att underlätta felsökning. Själva pollinggränssnittet medför inga genereringsavgifter.

## 8. Använda callback

Lägg till `callback_url` vid inskickning; när uppgiften är klar kommer slutligt JSON-resultat att POST:as till denna adress. Framgångsstrukturen är densamma som den tidigare `response`, medan fel inkluderar `error`.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "t2v",
  "prompt": "A small sailboat on calm water.",
  "duration": 5,
  "resolution": "hd",
  "draft": true,
  "callback_url": "https://your-server.example/flux-callback"
}
```

Callback-adressen ska vara åtkomlig från det offentliga nätverket. Efter att ha mottagit en avisering, behandla den idempotent enligt `task_id` och returnera 2xx så snart som möjligt; affärsbearbetning kan köas. Detta dokument anger inte att callbacken har signaturautentisering: före känsliga åtgärder såsom tilldelning av affärsförmåner, använd din egen Token för att fråga samma uppgift och verifiera resultatet. Om callbacken inte tas emot kan du fortfarande fortsätta att polla, och ska inte generera på nytt.

## 10. Vanliga frågor och felsökning
