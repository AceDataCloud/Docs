MiMo 2.6 Pro och MiMo 2.6 Flash är modeller i Xiaomis MiMo-serie. Detta gränssnitt använder formatet OpenAI Chat Completions och debiteras baserat på indata-, utdata- och cacheträff-token.

## Modeller och gränssnitt

| Modell                | Positionering           |
| ----------------- | ------------ |
| `mimo-v2.6-pro`   | Komplex analys, resonemang och verktygsanrop |
| `mimo-v2.6-flash` | Vardagliga konversationer och lätta uppgifter    |

Aktivera MiMo och hämta motsvarande API-autentiseringsuppgifter, och skicka förfrågningar till `https://api.acedata.cloud/mimo/chat/completions`. OpenAI SDK:s `base_url` kan ställas in på `https://api.acedata.cloud/mimo`. Den enhetliga ingången `/v1/chat/completions` kräver också motsvarande tjänstbehörighet.

Det första gränssnittsomfånget är textbaserade Chat Completions; bilder, ljud, video, webbsökning, Responses, Messages, Batch och UltraSpeed ingår inte i denna lansering.

## Python-exempel

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ACEDATACLOUD_API_KEY"],
    base_url="https://api.acedata.cloud/mimo",
)
response = client.chat.completions.create(
    model="mimo-v2.6-pro",
    messages=[{"role": "user", "content": "解释彩虹形成的原因。"}],
    max_completion_tokens=256,
    extra_body={"thinking": {"type": "disabled"}},
)
print(response.choices[0].message.content)
print(response.usage)
```

Exemplet visar hur en förfrågan skrivs; ett exempel på ett faktiskt svar kommer att läggas till efter tjänstverifiering.

## Streaming, resonemang och verktygsanrop

Ställ in `stream=true` för att ta emot SSE; om slutlig användning behövs, skicka `stream_options={"include_usage": true}`. Klienten bör hantera inkrement för innehåll, resonemangsinnehåll och verktygsanrop, samt den slutliga usage-händelsen.

Använd `thinking.type=enabled` för att aktivera resonemang och `disabled` för att stänga av det. `reasoning_content` och det slutliga `content` returneras separat; när verktygsanrop fortsätts ska resonemangsinnehållet i assistentmeddelandet, fullständiga `tool_calls` och motsvarande `tool_call_id` behållas.

Skicka endast verktygsdeklarationer av typen `type=function`; `tool_choice` stöder endast `auto`. Applikationen ansvarar för att köra verktyget och återrapportera resultatet; att modellen returnerar ett verktygsanrop innebär inte i sig att verktyget har körts. Tjänstens inbyggda webbsökning är ännu inte öppen.

## Debitering

`prompt_tokens` inkluderar indata med cacheträffar; `prompt_tokens_details.cached_tokens` beräknas enligt cachepriset, medan övrig indata beräknas enligt det vanliga indatapriset. `completion_tokens` inkluderar resonemangsutdata; räkna inte resonemangstoken dubbelt. Streaming-anrop debiteras också enligt den slutliga faktiska användningen.

Priserna följer konsolen, och Credits dollarkostnad beror på det köpta paketet. Misslyckade förfrågningar bör inte betraktas som framgångsrikt slutförda; om du behöver kontrollera debiteringen, ange spårningsidentifieraren i svaret.

## Felhantering

Vid parameterfel, kontrollera förfrågningsformatet; vid autentiserings- eller behörighetsfel, kontrollera autentiseringsuppgifterna och tjänstens aktiveringsstatus; vid 429, gör ett nytt försök med backoff. När det saknas frisk modellkapacitet kan 503 returneras. Om ett avbrott inträffar efter att ett streamingsvar har startat, kontrollera först de redan mottagna resultaten och användningen för att undvika att blint upprepa förfrågan.
