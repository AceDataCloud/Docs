Den här artikeln introducerar en metod för integrering av SeeDream Images Generation API, som kan generera officiella bilder från SeeDream genom att ange anpassade parametrar.

## Ansökningsprocess

För att använda SeeDream Images Generation API ska du först hämta din API Token från [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) och spara den för senare användning.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig omdirigeras du automatiskt till inloggningssidan där du uppmanas att registrera dig och logga in. När detta är klart återgår du automatiskt till den aktuella sidan.

**En API Token kan användas för att anropa alla tjänster på plattformen, utan att du behöver ansöka separat för varje tjänst.** Vid första ansökan får du en kostnadsfri kvot för att testa tjänsten gratis; när kvoten inte räcker till kan du fylla på det gemensamma saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [SeeDream Images Generation API →](https://platform.acedata.cloud/documents/seedream-images)

## Grundläggande användning

Börja med att förstå det grundläggande användningssättet: genom att ange prompten `prompt`, genereringsåtgärden `action` och bildstorleken `size` kan du få det bearbetade resultatet. Först behöver du enkelt skicka fältet `action`, vars värde är `generate`, och sedan behöver vi även ange prompten. Det specifika innehållet är följande:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Här kan vi se att vi har angett Request Headers, inklusive:

- `accept`: Vilket format på svarsresultatet du vill ta emot. Här anges `application/json`, det vill säga JSON-format.
- `authorization`: Nyckeln för att anropa API:et, som kan väljas direkt i rullgardinsmenyn efter ansökan.

Dessutom har Request Body angetts, inklusive:

- `prompt`: Prompt.
- `model`: Genereringsmodell, standardvärdet är `doubao-seedream-5-0-lite-260128` (SeeDream 5.0 Lite, senaste). Stöder `doubao-seedream-5-0-pro-260628`, `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`. Bland dessa är `doubao-seedream-5-0-pro-260628` (SeeDream 5.0 Pro) flaggskeppsmodellen för enskilda bilder och genererar endast enskilda bilder, **stödjer inte bildgrupper (`sequential_image_generation`), strömning (`stream`) eller webbsökning (`tools`)**. **`model` måste skickas med den fullständiga modellsträngen (t.ex. `doubao-seedream-5-0-lite-260128`); förkortningar som `doubao-seedream-5.0-lite` returnerar 400.**
- `image`: Information om den inmatade bilden, stödjer URL eller Base64-kodning. `doubao-seedream-5-0-pro-260628` stödjer inmatning av en eller flera bilder (högst 10), och `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` stödjer inmatning av en eller flera bilder.
- `size`: Anger storleksinformationen för den genererade bilden och stödjer följande två metoder, som inte kan blandas. Metod 1 | Ange upplösningen för den genererade bilden och beskriv bildens bredd-höjd-förhållande med naturligt språk i prompten. **De förinställningar som stöds skiljer sig mellan modellerna**: `doubao-seedream-5-0-pro-260628` stödjer `1K`/`1.5K`/`2K`; `doubao-seedream-5-0-lite-260128` stödjer `2K`/`3K`/`4K`; `doubao-seedream-4-5-251128` stödjer endast `2K`/`4K`; `doubao-seedream-4-0-250828` stödjer `1K`/`2K`/`4K`. Metod 2 | Ange pixelvärden för bredd och höjd på den genererade bilden: standardvärdet är `2048x2048`, och intervallet för totalt antal pixlar och bredd-höjd-förhållandet varierar beroende på modell (till exempel har 5.0 Pro intervallet [921600, 4624220] för totalt antal pixlar, 5.0 Lite / 4.5 har en lägsta gräns på 3,686,400 pixlar och 4.0 har en lägsta gräns på 921,600).
- `sequential_image_generation`: Bildgrupp: en uppsättning innehållsmässigt relaterade bilder som genereras utifrån innehållet du anger. `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` stödjer denna parameter, standardvärdet är `disabled`.
- `stream`: Styr om läget för strömmande utdata ska aktiveras. `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` stödjer denna parameter, standardvärdet är `false`.
- `response_format`: Anger returformatet för den genererade bilden. Standardvärdet är `url`, och `b64_json` stöds också.
- `watermark`: Om en vattenstämpel ska läggas till i den genererade bilden. Standardvärdet är `true`.
- `output_format`: Anger filformatet för den genererade bilden, stödjer `jpeg` (standard) och `png`. Stöds endast av `doubao-seedream-5-0-pro-260628` och `doubao-seedream-5-0-lite-260128`.
- `tools`: Konfigurerar verktyg som modellen ska anropa; för närvarande stöds `web_search` (webbsökning). Stöds endast av Seedream 5.0 Lite.
- `optimize_prompt_options`: Konfiguration för promptoptimering. 5.0 Pro stödjer `standard`/`fast`; 5.0 Lite och 4.5 stödjer endast `standard`; 4.0 stödjer `standard`/`fast`.
- `background`: Stöds endast för redigering av enskilda bilder i 5.0 Pro. `transparent` kräver att en PNG med transparent kanal anges, och `output_format` måste vara `png`; `opaque` är en vanlig ogenomskinlig bakgrund.
- `layer_decomposition`: Stöds endast av 5.0 Pro. När värdet är `true` måste en PNG/JPEG anges; `prompt` kan utelämnas för automatisk uppdelning, eller element kan anges med naturligt språk/`<bbox>`; `size` stödjer `auto`/`1K`/`1.5K`/`2K`. Detta läge kan inte användas tillsammans med bildgrupper, strömning, webbsökning eller `background`.
- `callback_url`: URL:en som ska få återkopplingsresultatet.
- `async`: Om bearbetning ska ske i asynkront läge. När värdet är `true` returnerar gränssnittet omedelbart `task_id`; du behöver inte ange `callback_url`, och hämtar sedan resultatet genom att polla `/seedream/tasks`.

Efter valet kan du se att motsvarande kod också har genererats på höger sida, som visas i bilden:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

Klicka på knappen 「Try」 för att testa. Som visas i bilden ovan får vi följande resultat här:
```json
{
  "success": true,
  "task_id": "80ceeed1-17d4-4eb7-82e0-18b34290f36e",
  "trace_id": "96b7fdc8-0fc8-4e2e-82a9-83c0a82f0a08",

    {
      "prompt": "A single matte blue cube centered on a clean white studio background, neutral lighting",

    }
  ]

```

Det finns flera fält i returresultatet, som introduceras nedan:

- `success`, statusen för videogenereringsuppgiften vid denna tidpunkt.
- `task_id`, ID:t för videogenereringsuppgiften vid denna tidpunkt.
- `trace_id`, spårnings-ID:t för videogenereringen vid denna tidpunkt.
- `data`, resultatlistan för bildgenereringsuppgiften vid denna tidpunkt.
  - `image_url`, länken till bildgenereringsuppgiften vid denna tidpunkt.
  - `prompt`, prompten.
  - `size`: pixlarna för den genererade bilden

Vi kan se att vi har fått tillfredsställande bildinformation, vi behöver bara hämta den genererade SeeDream-bilden enligt bildlänkadressen i resultatets `data`.

Om du dessutom vill generera motsvarande integrationskod kan du kopiera och generera den direkt, till exempel är CURL-koden följande:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-5-0-lite-260128",
  "prompt": "A single matte blue cube centered on a clean white studio background, neutral lighting"
}'
```

## Bildredigeringsuppgift

Om du vill redigera en bild måste parametern `image` först innehålla länken till bilden som ska redigeras

- model: modellen som används för denna bildredigeringsuppgift, `doubao-seedream-5-0-pro-260628`, `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` stöder alla bildindata.
- image: ladda upp bilden som ska redigeras, en eller flera

Exempel på ifyllnad enligt följande:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Motsvarande kod:

```python
import requests

url = "https://api.acedata.cloud/seedream/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Lageruppdelning (Seedream 5.0 Pro)

Lageruppdelning delar upp en indatabild i 1 bakgrundsbild och upp till 16 oberoende redigerbara transparenta PNG-lager. Följande begäran låter modellen automatiskt identifiera huvudelement; om element behöver anges kan `prompt` läggas till, och normaliserade `<bbox>`-koordinater kan också användas i prompten.

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "model": "doubao-seedream-5-0-pro-260628",
  "image": "https://example.com/poster.png",
  "layer_decomposition": true,
  "size": "2K",
  "watermark": false
}'
```

Det returnerade `data` är ordnat från botten till toppen enligt `z_index`. Bakgrundsbildens `z_index` är 0; lagren innehåller även `name`, `description` och `bounding_box.absolute`/`normalized`. Vid återuppbyggnad med absoluta koordinater, skala lagret till `[right-left, bottom-top]`, placera det vid `[left, top]` och stapla sedan lagren i stigande ordning efter `z_index`. Om genereringen av något lager misslyckas misslyckas hela uppdelningen.

## Strömmande utdata

När Lite/4.x ställer in `stream: true`, använd begärandehuvudet `accept: application/x-ndjson`. Gränssnittet returnerar rad för rad `image_generation.partial_succeeded` eller `image_generation.partial_failed`, och returnerar slutligen den enda händelsen `image_generation.completed` samt den slutliga `usage`; endast slutförandehändelsen utlöser en debitering. Strömmande läge kan inte användas tillsammans med `async` eller `callback_url`.

## Asynkront återanrop

Eftersom tiden för generering med SeeDream Images Generation API är relativt lång, ungefär 1–2 minuter, kommer HTTP-begäran att fortsätta hålla anslutningen om API:t inte svarar under en längre tid, vilket leder till ytterligare förbrukning av systemresurser, därför erbjuder detta API också stöd för asynkrona återanrop.

Det övergripande flödet är: när klienten initierar en begäran anges dessutom ett fält `callback_url`, efter att klienten har initierat API-begäran returnerar API:t omedelbart ett resultat som innehåller fältinformationen `task_id`, vilket representerar ID:t för den aktuella uppgiften. När uppgiften är klar skickas resultatet av den genererade bilden i form av POST JSON till den `callback_url` som klienten har angett, vilket också inkluderar fältet `task_id`, så att uppgiftsresultaten kan kopplas samman via ID:t.

Om du inte har en offentlig adress som kan användas för återanrop kan du också låta bli att ange `callback_url` och i stället ställa in fältet `async` till `true` i begäran. Gränssnittet returnerar då också omedelbart `task_id`, men skickar inte resultatet, du behöver använda detta `task_id` för att anropa gränssnittet `/seedream/tasks` och fråga av uppgiftsstatusen för att få slutresultatet.

## Felhantering

När API:t anropas, om ett fel uppstår, returnerar API:t motsvarande felkod och information. Till exempel:

- `400 token_mismatched`: Felaktig begäran, möjligen på grund av saknade eller ogiltiga parametrar.
- `400 api_not_implemented`: Felaktig begäran, möjligen på grund av saknade eller ogiltiga parametrar.
- `401 invalid_token`: Obehörig, ogiltig eller saknad auktoriseringstoken.
- `429 too_many_requests`: För många begäranden, du har överskridit hastighetsgränsen.
- `500 api_error`: Internt serverfel, något gick fel på servern.

### Exempel på felsvar

```json
{

    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
