Detta dokument beskriver hur man integrerar SeeDream Images Generation API, vilket möjliggör generering av officiella SeeDream-bilder genom att mata in anpassade parametrar.

## Ansökningsprocess

För att använda API:et måste du först ansöka om tjänsten på [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images). När du kommer till sidan klickar du på knappen "Acquire", som visas nedan:

![](https://cdn.acedata.cloud/q6ytrc.png)

Om du inte är inloggad eller registrerad kommer du automatiskt att omdirigeras till inloggningssidan för att registrera dig och logga in. Efter inloggning återvänder du automatiskt till den aktuella sidan.

Vid första ansökan får du en gratis kvot som gör att du kan använda API:et kostnadsfritt.

## Grundläggande användning

Först bör du förstå den grundläggande användningen: genom att mata in prompt, action och bildstorlek (size) får du ett behandlat resultat. Du måste först skicka ett fält `action` med värdet `generate`, och sedan mata in prompten. Exempel på innehåll visas nedan:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Här ser vi att vi ställer in Request Headers, inklusive:

- `accept`: önskat format för svar, här `application/json` (JSON-format).
- `authorization`: API-nyckeln, som kan väljas från en dropdown efter ansökan.

Request Body innehåller:

- `prompt`: prompten.
- `model`: genereringsmodell, standard är `doubao-seedream-5.0-lite`. Stöder `doubao-seedream-5.0-lite` (senaste), `doubao-seedream-4.5`, `doubao-seedream-4.0`, `doubao-seedream-3.0-t2i`, `doubao-seededit-3.0-i2i`.
- `image`: bilddata, stödjer URL eller Base64-kodning. `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0` stödjer en eller flera bilder, `doubao-seededit-3.0-i2i` stödjer endast en bild, `doubao-seedream-3.0-t2i` stödjer inte denna parameter.
- `size`: specificerar bildstorlek, två metoder som inte kan kombineras. Metod 1: ange upplösning (t.ex. `2K`, `3K`, `4K`) och beskriv bildens aspektförhållande i prompten. Metod 2: ange bildens bredd och höjd i pixlar, standard `2048x2048`, värdeintervall varierar per modell.
- `seed`: slumpmässigt frö för att styra modellens slumpmässighet, värdeintervall [-1, 2147483647]. Stöds endast av `doubao-seedream-3.0-t2i` och `doubao-seededit-3.0-i2i`.
- `sequential_image_generation`: genererar en serie relaterade bilder baserat på input. Stöds av `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0`, standard `disabled`.
- `stream`: styr om strömningsläge ska aktiveras. Stöds av `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0`, standard `false`.
- `guidance_scale`: hur väl modellens output överensstämmer med prompten, högre värde ger starkare korrelation. Intervall [1, 10]. Standardvärde 2.5 för `doubao-seedream-3.0-t2i`, 5.5 för `doubao-seededit-3.0-i2i`, stöds ej av andra modeller.
- `response_format`: format för genererad bild, standard `url`, stöder även `b64_json`.
- `watermark`: om vattenstämpel ska läggas till i bilden, standard `true`.
- `output_format`: filformat för genererad bild, stöder `jpeg` (standard) och `png`. Endast `doubao-seedream-5.0-lite` stödjer detta.
- `tools`: konfigurerar verktyg som modellen ska använda, för närvarande stöds `web_search` (internet-sökning). Endast `doubao-seedream-5.0-lite` stödjer detta.
- `callback_url`: URL för asynkron callback.

När du valt inställningar genereras motsvarande kod till höger, som visas nedan:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

Klicka på "Try" för att testa. Resultatet kan se ut så här:

```json
{
  "success": true,
  "task_id": "25027ba3-0430-4a1b-91c8-d2297f19ba73",
  "trace_id": "8043a9e9-692f-43b0-82f7-5890f798be38",
  "data": [
    {
      "prompt": "a white siamese cat",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/3c060029-69b1-406f-a957-fcd55ddc9386.jpg"
    }
  ]
}
```

Resultatet innehåller flera fält:

- `success`: status för bildgenereringsuppgiften.
- `task_id`: ID för bildgenereringsuppgiften.
- `trace_id`: spårnings-ID för uppgiften.
- `data`: lista med resultat för bildgenerering.
  - `image_url`: URL till den genererade bilden.
  - `prompt`: prompten.
  - `size`: bildens pixelstorlek.

Vi har fått en bild som vi kan hämta via länken i `data`.

Om du vill generera motsvarande kod kan du kopiera den, till exempel CURL-koden nedan:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-4-0-250828",
  "prompt": "a white siamese cat"
}'
```

## Redigera bilduppgift

För att redigera en bild måste parametern `image` innehålla URL till bilden som ska redigeras.

- `model`: modellen som används för redigeringen. `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0` stödjer en eller flera bilder, `doubao-seededit-3.0-i2i` stödjer endast en bild.
- `image`: en eller flera bilder som ska redigeras.

Exempel:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Exempel på kod:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

När du kör detta får du omedelbart ett svar, t.ex.:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Resultatet visar en redigerad version av originalbilden, liknande tidigare exempel.

## Asynkron callback

Eftersom generering med SeeDream Images Generation API kan ta 1-2 minuter, och långa HTTP-anslutningar kan belasta systemresurser, stöds asynkron callback.

Processen är: klienten skickar en förfrågan med fältet `callback_url`. API:et svarar omedelbart med ett svar som innehåller `task_id`. När uppgiften är klar skickar API:et ett POST-anrop med JSON till den angivna `callback_url`, inklusive `task_id` för att koppla resultatet till uppgiften.

Exempel på svar vid anrop:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

Exempel på callback-innehåll:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Genom `task_id` kan uppgiften kopplas samman med resultatet.

## Felhantering

Vid fel returnerar API:et motsvarande felkod och meddelande, exempel:

- `400 token_mismatched`: Felaktig förfrågan, t.ex. saknade eller ogiltiga parametrar.
- `400 api_not_implemented`: Felaktig förfrågan, t.ex. saknade eller ogiltiga parametrar.
- `401 invalid_token`: Obefogad, ogiltig eller saknad auktoriseringstoken.
- `429 too_many_requests`: För många förfrågningar, gränsen för anrop har överskridits.
- `500 api_error`: Intern serverfel.

### Exempel på felrespons

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
