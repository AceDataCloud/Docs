OpenAI ChatGPT är ett mycket kraftfullt AI-konversationssystem som kan generera flytande och naturliga svar på bara några sekunder genom att mata in promptord. ChatGPT är unikt i branschen med sin enastående förmåga att förstå och generera språk. I dag har ChatGPT redan fått bred användning inom olika branscher och områden, och dess inflytande blir allt tydligare. Oavsett om det gäller dagliga samtal, kreativt skrivande, professionell rådgivning eller kodprogrammering kan ChatGPT erbjuda imponerande intelligent assistans och avsevärt förbättra människors arbetseffektivitet och kreativitet.

Detta dokument introducerar huvudsakligen användningsprocessen för OpenAI Chat Completion API, med vilket vi enkelt kan använda konversationsfunktionen i det officiella OpenAI ChatGPT.

## GPT-6.1 Sol

Använd `model: "gpt-6.1-sol"` för att välja denna modell. Stöder strömmande utdata, funktionsanrop, strukturerade utdata och bildindata. Under den första veckan efter öppningen är den endast tillgänglig för verifierade ACE T1+-innehavare (minst 100 000 ACE) eller auktoriserade användare; den specifika öppningstiden avgörs av åtkomstmeddelandet i konsolen.

Resoneringsnivåer stöder `low`, `medium`, `high`, `xhigh` och `max`, medan `none` eller `minimal` för närvarande inte stöds. Det rekommenderas att börja med `reasoning_effort: "low"`. När indata överstiger 272 000 tokens tillämpas prissättning för lång kontext på hela begäran, och kostnaden avgörs av det aktuella priset i konsolen.

## Ansökningsprocess

För att använda OpenAI Chat Completion API, gå först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API Token och spara den som reserv.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte är inloggad eller registrerad omdirigeras du automatiskt till inloggningssidan för att registrera och logga in, och när det är klart återvänder du automatiskt till den aktuella sidan.

**En API Token kan användas för att anropa alla tjänster på plattformen, utan att behöva ansöka separat för varje tjänst.** Vid första ansökan får du gratis kredit för kostnadsfri testning; om krediten inte räcker till kan du fylla på det gemensamma saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [OpenAI Chat Completion API →](https://platform.acedata.cloud/documents/openai-chat-completions)

## Grundläggande användning

Därefter kan du fylla i motsvarande innehåll i gränssnittet, som visas i bilden:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

När vi använder detta gränssnitt för första gången behöver vi minst fylla i tre saker. Den ena är `authorization`, som kan väljas direkt i rullgardinslistan. Den andra parametern är `model`, där `model` är den modellkategori från OpenAI ChatGPT:s officiella webbplats som vi väljer att använda. Här har vi främst 20 modeller, och du kan se detaljer om de modeller vi tillhandahåller. Den sista parametern är `messages`, där `messages` är den array av frågeord som vi matar in. Det är en array, vilket innebär att flera frågeord kan laddas upp samtidigt. Varje frågeord innehåller `role` och `content`, där `role` anger frågeställarens roll. Vi erbjuder tre identiteter: `user`, `assistant` och `system`. Den andra, `content`, är det specifika innehållet i vår fråga.

Samtidigt kan du se att motsvarande anropskod genereras till höger. Du kan kopiera koden och köra den direkt, eller klicka direkt på knappen ”Try” för att testa.

Vanliga valfria parametrar:

- `max_tokens`: Begränsar det maximala antalet tokens i ett enskilt svar.
- `temperature`: Genereringsslumpmässighet, mellan 0 och 2; ju högre värde, desto mer spritt.
- `n`: Hur många kandidatsvar som genereras åt gången.
- `response_format`: Inställning för returformat.

## Strömmande svar

Detta gränssnitt stöder också strömmande svar, vilket är mycket användbart för webbintegration och kan göra det möjligt för webbsidor att visa tecken för tecken.

Om du vill returnera svar strömmande kan du ändra parametern `stream ` i begärandehuvudet till `true`.

Ändringen visas i bilden, men anropskoden måste ändras motsvarande för att stödja strömmande svar.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

Efter att `stream` har ändrats till `true` returnerar API:t motsvarande JSON-data rad för rad, och på kodnivå behöver vi göra motsvarande ändringar för att få resultatet rad för rad.

Exempel på Python-anropskod:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Anslutning till OpenAI-Python

OpenAI Chat Completion API är kompatibelt med det officiella OpenAI-gränssnittet och kan anslutas direkt med den officiella SDK:n [OpenAI-Python](https://github.com/openai/openai-python). Den här artikeln kommer kortfattat att introducera användningen.

1. Först behöver du konfigurera en lokal `Python`-miljö, denna process kan du söka efter på Google.
2. Ladda ner och installera utvecklingsmiljön, till exempel VSCode-redigeraren.
3. Konfigurera miljövariabler för `OpenAI`.

- Skapa och spara en fil med namnet `.env` i projektmappen.
- Innehållet i filen `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # Påminnelse igen: om du använder en key från OpenAI:s officiella webbplats, använd inte denna adress.
```

Ersätt `sk-xxx` med din egen key. `OPENAI_BASE_URL` är proxygränssnittet för åtkomst till OpenAI.

4. Installera paketen som projektet är beroende av

```shell
pip install openai
```

I Mac OS är kommandot:

```shell
pip3 install openai
```

5. Skapa en exempelkällkodsfil

Anta att vi har skapat en exempelkod `index.py`, det specifika innehållet är följande:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Visuell modell

gpt-4o är en multimodal stor språkmodell utvecklad av OpenAI, den har lagt till visuell förståelseförmåga på basis av GPT-4. Denna modell kan samtidigt bearbeta text- och bildindata och uppnå förståelse och generering över flera modaliteter.

Textbearbetningen med modellen gpt-4o är densamma som innehållet för grundläggande användning ovan. Nedan kommer vi kortfattat att introducera hur man använder modellens bildbearbetningsförmåga.

Bildbearbetningsförmågan hos modellen gpt-4o används främst genom att lägga till ett `type`-fält på basis av det ursprungliga `content`-innehållet. Genom detta fält kan man veta om det som laddas upp är text eller en bild, och därmed använda bildbearbetningsförmågan hos modellen gpt-4o. Nedan beskrivs främst hur denna funktion anropas på två sätt: Curl och Python.

- Curl-skriptmetod

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

- Python-skriptmetod
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
                    }
                },
            ],
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Felhantering

När API:et anropas returnerar API:et motsvarande felkoder och information om ett fel uppstår. Till exempel:

- `400 token_mismatched`: Felaktig begäran, möjligen på grund av saknade eller ogiltiga parametrar.
- `400 api_not_implemented`: Felaktig begäran, möjligen på grund av saknade eller ogiltiga parametrar.
- `401 invalid_token`: Obehörig, ogiltig eller saknad auktoriseringstoken.
- `429 too_many_requests`: För många begäranden, du har överskridit hastighetsgränsen.
- `500 api_error`: Internt serverfel, något gick fel på servern.

### Exempel på felsvar

```
    "message": "fetch failed"
  },

}
```
