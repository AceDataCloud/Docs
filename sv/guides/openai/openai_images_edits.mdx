Öppna [Ace Data Cloud-applistan](https://platform.acedata.cloud/console/applications), gå in i en tillgänglig app och kopiera API Key.

## 2. Redigera med bild-URL

Originalbild:

![GPT Image 2 originalbild för redigering](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
```

## 3. Ladda upp lokala bilder

Använd `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` kan skickas in upprepade gånger, GPT Image-serien stöder upp till 16 referensbilder. `image` i JSON-begäran kan vara en enskild URL eller en URL-array; lokala filer laddas upp med multipart.

### Modeller och debiteringsmetoder

| Modell                                | Tillämpliga scenarier och debiteringsmetoder                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | Standardkanal för omvänd teknik, fast debitering per antal lyckade bilder                               |
| `gpt-image-2:reverse`             | Välj explicit kanalen för omvänd teknik, fast debitering per antal lyckade bilder                             |
| `gpt-image-2:official`            | Officiell API-kanal, högre stabilitet, debitering enligt faktisk tokenanvändning                   |
| `gpt-image-2.5-flare`             | Fokus på genereringshastighet, fast debitering per antal lyckade bilder                               |
| `gpt-image-2.6-flare`             | Fokus på genereringshastighet, fast debitering per antal lyckade bilder                               |
| `gpt-image-2.5-flare:reverse`     | Explicit alias för omvänd teknik, motsvarar `gpt-image-2.5-flare`, fast debitering per antal lyckade bilder    |
| `gpt-image-2.6-flare:reverse`     | Explicit alias för omvänd teknik, motsvarar `gpt-image-2.6-flare`, fast debitering per antal lyckade bilder    |
| `gpt-image-2.5-flare:official`    | Officiell API-kanal, högre stabilitet och fokus på genereringshastighet, debitering enligt faktisk tokenanvändning            |
| `gpt-image-2.6-flare:official`    | Officiell API-kanal, högre stabilitet och fokus på genereringshastighet, debitering enligt faktisk tokenanvändning            |
| `gpt-image-2.5-sunburst`          | Fokus på hög återgivningstrohet och detaljerad kontroll, fast debitering per antal lyckade bilder                           |
| `gpt-image-2.6-sunburst`          | Fokus på hög återgivningstrohet och detaljerad kontroll, fast debitering per antal lyckade bilder                           |
| `gpt-image-2.5-sunburst:reverse`  | Explicit alias för omvänd teknik, motsvarar `gpt-image-2.5-sunburst`, fast debitering per antal lyckade bilder |
| `gpt-image-2.6-sunburst:reverse`  | Explicit alias för omvänd teknik, motsvarar `gpt-image-2.6-sunburst`, fast debitering per antal lyckade bilder |
| `gpt-image-2.5-sunburst:official` | Officiell API-kanal, högre stabilitet och fokus på hög återgivningstrohet samt detaljerad kontroll, debitering enligt faktisk tokenanvändning        |
| `gpt-image-2.6-sunburst:official` | Officiell API-kanal, högre stabilitet och fokus på hög återgivningstrohet samt detaljerad kontroll, debitering enligt faktisk tokenanvändning        |

Modellerna för omvänd teknik 2.0 / 2.5 (inklusive `:reverse`-alias) kan använda GPT Image 2.5 Flare för att slutföra begäran vid automatisk återställning; den begärda modellen och metoden med debitering per antal lyckade bilder förblir oförändrade.

Sidans pris för den officiella API-kanalen är en uppskattning före begäran, och det slutliga priset baseras på den faktiska tokenanvändningen i svaret och användningsposterna.

`quality` stöder `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare och Sunburst (inklusive varianterna `:reverse` och `:official`) stöder dessutom `xhigh`, `max`. Detta fält kan skickas in både för JSON-redigering med bild-URL och multipart-redigering av filer; den officiella kanalen debiterar enligt faktisk tokenanvändning.

## 4. Använd mask för lokal redigering

Det officiella Images Edit-gränssnittet anger området som får ändras via `mask`. Ace Data Clouds `:official`-modeller följer samma multipart-kontrakt:

- `mask` måste vara en PNG med alfakanal och får inte vara större än 4 MB;
- maskens storlek måste vara exakt samma som den första `image`;
- transparenta pixlar med alfa `0` anger att redigering är tillåten, icke-transparenta pixlar anger att de ska bevaras;
- RGB-bilder som endast är svartvita men saknar transparenskanal kan inte användas som giltiga masker;
- prompten bör beskriva den fullständiga önskade bilden, samtidigt som den tydligt anger den lokala ändringen och innehållet som behöver förbli oförändrat.

Nedan genereras först en mask från originalbilden. Exemplet gör den centrala rektangeln transparent och tillåter endast modellen att ändra detta område:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Ladda sedan upp originalbilden och masken tillsammans:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Du kan också fortsätta använda anropssättet `images.edit` i OpenAI:s officiella Python SDK; du behöver bara peka `base_url` mot Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

När du använder `mask` måste originalbilden och masken laddas upp separat i samma multipart-begäran via `image=@input.png` och `mask=@mask.png`. Blanda inte en URL-originalbild med en lokal maskfil; rena URL-redigeringsbegäranden stöder inte att ytterligare en lokal `mask`-fil bifogas. Masken begränsar redigeringsområdet, men genereringsmodellen kan fortfarande utföra naturlig blandning vid kanterna; när strikta gränser krävs bör du använda tydliga Alpha-kanter och upprepa i prompten vilket innehåll som måste förbli oförändrat.

Ovanstående anropssätt överensstämmer med maskexemplen i [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) och [GPT Image officiella Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Vanliga parametrar

| Fält                | Beskrivning                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (snabbare) eller `gpt-image-2.5-sunburst` (högre återgivningstrohet och kontroll); alla tre kan välja motsvarande `:official`-variant, och `gpt-image-2` stöder även `:reverse` |
| `image`           | JSON använder en enskild URL eller en array med upp till 16 URL:er; multipart använder ett eller flera `image`-filfält. När `mask` används måste lokala bildfiler laddas upp                                              |
| `mask`            | Valfri PNG-mask, endast för multipart-filuppladdning; måste ha Alpha-kanal, ha samma storlek som den första `image` och inte överstiga 4 MB                                                                 |
| `prompt`          | Redigeringsinstruktion                                                                                                                             |
| `size`            | `auto` eller `WIDTHxHEIGHT` som uppfyller begränsningarna                                                                                                     |
| `n`               | 1–10; när `response_format=b64_json` används stöds endast 1                                                                                           |
| `response_format` | `url` eller `b64_json`                                                                                                               |
| `callback_url`    | Valfri asynkron återanropsadress                                                                                                                         |

Storleksreglerna är desamma som för genereringsgränssnittet: bredd och höjd måste vara multiplar av 16, den längsta sidan får inte överstiga 3840, det totala antalet pixlar ska vara 655 360–8 294 400 och bildförhållandet får inte överstiga 3:1. När `size` utelämnas eller `auto` används väljer modellen format baserat på prompten och den första referensbilden.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` och deras `:reverse`-alias debiteras per antal lyckade bilder; `gpt-image-2:official`, `gpt-image-2.5-flare:official` och `gpt-image-2.5-sunburst:official` debiteras baserat på den faktiska Token-användningen för textinmatning, referensbildsinmatning och bildutmatning, och den slutliga användningsloggen gäller.

## 6. Asynkrona återanrop och felsökning

Långa uppgifter kan inkludera följande i begäran:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Det asynkrona 200-svaret är `{"task_id": "..."}`; det slutliga resultatet återanropas efter slutförande. Synkrona begäranden returnerar däremot `created` och `data`.

| Status  | Kontroll                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Bildformat/-antal, parameterkombinationer och storleksformat; vid användning av `mask`, kontrollera PNG Alpha-kanalen, 4 MB-gränsen och att dess storlek överensstämmer med den första originalbilden |
| 401 | API Key och Bearer Header                                           |
| 429 | Begärandefrekvens                                                              |
| 504 | Byt till asynkront återanrop                                                            |

Felsvar innehåller `trace_id`. Ange detta ID när du rapporterar problem, men ange inte API Key.

Fullständiga fält och realtidsuppräkningar finns på sidan [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). För bildgenerering från enbart text, se [GPT Image 2 / 2.5 / 2.6 bildgenerering](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

GPT Image 2.6 använder samma gränssnitt för generering, redigering, asynkrona uppgifter och debitering som 2.5:

| Modell                                                          | Debitering                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/bild                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/bild                   |
| `gpt-image-2.6-flare:official`                              | Samma som 2.5 official, debiteras enligt faktisk Token-användning |
| `gpt-image-2.6-sunburst:official`                           | Samma som 2.5 official, debiteras enligt faktisk Token-användning |

Kvaliteten kan vara `auto`, `low`, `medium`, `high`, `xhigh` eller `max`; för storlek används `auto` eller `WIDTHxHEIGHT` som uppfyller ovanstående begränsningar. Detta gränssnitt stöder `png`, `jpeg` och `webp`; GPT Image 2.6 stöder dessutom animerade `gif`-bilder direkt, men SVG stöds för närvarande inte. Redigering stöder bild-URL:er i JSON och multipart-filuppladdning. `:reverse` är ett uttryckligt alias för den vanliga versionen med samma namn. Använd det fullständiga modellnamnet, och skicka inte `gpt-image-2.6`.

### GPT Image 2.6 bild till GIF-animation
Flare standardversion, `:reverse`, `:official` samt `gpt-image-2.6-sunburst:official` kan använda `output_format: "gif"`. Sunburst standardversion och `:reverse` har tills vidare inte öppnat för GIF och stöder fortfarande generering och redigering av statiska bilder. Animationsbildrutor, loopinformation och uppspelningstid bevaras; `frame_count` anger antalet bildrutor och `frame_duration_ms` anger antalet millisekunder per bildruta, båda måste vara positiva heltal och används endast för GIF. Om de inte anges är standardvärdet 9 bildrutor och 200 millisekunder per bildruta; när GIF:s size utelämnas eller är auto används förinställningen 512x512.

Det rekommenderas att först använda `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. GIF har separata begränsningar för storlek och antal bildrutor, och de statiska 4K-specifikationerna kan inte tillämpas direkt; vissa modeller justerar den faktiska utdatastorleken. `n` anger antalet GIF-filer som returneras, inte antalet animationsbildrutor. Standardversionen och `:reverse` debiteras fortfarande efter antalet lyckade filer, medan den officiella versionen debiteras efter faktisk Token-användning.

```json
{
  "model": "gpt-image-2.6-flare",
  "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
  "prompt": "Animate the mug gently moving left and right. Keep its appearance and the background, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### GPT Image 2.6 4K-statiska bilder

Flare, Sunburst och deras `:reverse`-, `:official`-varianter kan alla använda de tidigare nämnda 4K-pixelförinställningarna, såsom `3840x2160` och `2160x3840`. Både generering och redigering skickar in specifika pixlar via `size`; `4K` är inte ett giltigt `size`-värde, och `4096x4096` överskrider också den aktuella pixelgränsen. Ovanstående 4K-specifikationer gäller för statiska PNG/JPEG/WebP; för GIF ska dess särskilda parametrar användas.
