## 3. Ladda upp lokala bilder

Använd `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` kan skickas in upprepade gånger, och GPT Image-serien stöder högst 16 referensbilder. `image` i JSON-begäran kan vara en enskild URL eller en URL-array; lokala filer laddas upp via multipart.

### Modeller och debiteringsmetoder

| Modell                                | Tillämpliga scenarier och debiteringsmetoder                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | Standardkanal för omvänd teknik, fast debitering per antal lyckade bilder                               |
| `gpt-image-2:reverse`             | Väljer uttryckligen kanalen för omvänd teknik, fast debitering per antal lyckade bilder                             |
| `gpt-image-2:official`            | Officiell API-kanal, högre stabilitet, debitering enligt faktisk Token-användning                   |
| `gpt-image-2.5-flare`             | Fokuserar på genereringshastighet, fast debitering per antal lyckade bilder                               |
| `gpt-image-2.6-flare`             | Fokuserar på genereringshastighet, fast debitering per antal lyckade bilder                               |
| `gpt-image-2.5-flare:reverse`     | Uttryckligt alias för omvänd teknik, likvärdigt med `gpt-image-2.5-flare`, fast debitering per antal lyckade bilder    |
| `gpt-image-2.6-flare:reverse`     | Uttryckligt alias för omvänd teknik, likvärdigt med `gpt-image-2.6-flare`, fast debitering per antal lyckade bilder    |
| `gpt-image-2.5-flare:official`    | Officiell API-kanal, högre stabilitet och fokus på genereringshastighet, debitering enligt faktisk Token-användning            |
| `gpt-image-2.6-flare:official`    | Officiell API-kanal, högre stabilitet och fokus på genereringshastighet, debitering enligt faktisk Token-användning            |
| `gpt-image-2.5-sunburst`          | Fokuserar på hög kvalitet och detaljerad kontroll, fast debitering per antal lyckade bilder                           |
| `gpt-image-2.6-sunburst`          | Fokuserar på hög kvalitet och detaljerad kontroll, fast debitering per antal lyckade bilder                           |
| `gpt-image-2.5-sunburst:reverse`  | Uttryckligt alias för omvänd teknik, likvärdigt med `gpt-image-2.5-sunburst`, fast debitering per antal lyckade bilder |
| `gpt-image-2.6-sunburst:reverse`  | Uttryckligt alias för omvänd teknik, likvärdigt med `gpt-image-2.6-sunburst`, fast debitering per antal lyckade bilder |
| `gpt-image-2.5-sunburst:official` | Officiell API-kanal, högre stabilitet och fokus på hög kvalitet och detaljerad kontroll, debitering enligt faktisk Token-användning        |
| `gpt-image-2.6-sunburst:official` | Officiell API-kanal, högre stabilitet och fokus på hög kvalitet och detaljerad kontroll, debitering enligt faktisk Token-användning        |

2.0 / 2.5-modeller för omvänd teknik (inklusive `:reverse`-alias) kan använda GPT Image 2.5 Flare för att slutföra begäran vid automatisk återställning; den begärda modellen och metoden med debitering per antal lyckade bilder förblir oförändrade.

Sidans pris för den officiella API-kanalen är en uppskattning före begäran; det slutliga priset baseras på den faktiska Token-användningen i svaret och användningsregistren.

`quality` stöder `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare och Sunburst (inklusive varianterna `:reverse` och `:official`) stöder dessutom `xhigh`, `max`. Detta fält kan skickas både vid JSON-redigering med bild-URL och multipart-filredigering; den officiella kanalen debiteras enligt faktisk Token-användning.

## 4. Använd mask för lokal redigering

Det officiella Images Edit-gränssnittet anger området som får ändras via `mask`. Ace Data Clouds `:official`-modeller följer samma multipart-kontrakt:

- `mask` måste vara en PNG med alfakanal och får inte vara större än 4 MB;
- maskens storlek måste vara exakt samma som den första `image`;
- transparenta pixlar med Alpha `0` anger att redigering är tillåten, medan icke-transparenta pixlar anger vad som ska behållas;
- RGB-bilder som endast är svartvita i färg men saknar transparenskanal kan inte användas som giltiga masker;
- prompten bör beskriva den kompletta önskade bilden och samtidigt tydligt ange den lokala ändringen och innehållet som behöver förbli oförändrat.

Nedan genereras först en mask från originalbilden. Exemplet gör den centrala rektangeln transparent och tillåter endast modellen att ändra det området:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Ladda sedan upp originalbilden och masken tillsammans:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Du kan också fortsätta använda anropssättet `images.edit` i OpenAI:s officiella Python SDK; du behöver bara peka `base_url` mot Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

När `mask` används måste originalbilden och masken laddas upp separat i samma multipart-begäran via `image=@input.png` och `mask=@mask.png`. Blanda inte URL-originalbilder med lokala maskfiler; rena URL-redigeringsbegäranden stöder inte att en lokal `mask`-fil läggs till. Masken begränsar redigeringsområdet, men genereringsmodellen kan fortfarande utföra naturlig sammanfogning vid kanterna; när strikta gränser krävs bör tydliga Alpha-kanter användas och prompten upprepat ange vilket innehåll som måste förbli oförändrat.

Ovanstående anropssätt överensstämmer med maskexemplen i [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) och [GPT Image officiella Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Vanliga parametrar

| Fält                | Beskrivning                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (snabbare) eller `gpt-image-2.5-sunburst` (högre återgivningstrohet och kontroll); alla tre kan välja motsvarande `:official`-variant, och `gpt-image-2` stöder även `:reverse` |
| `image`           | JSON använder en enskild URL eller en array med upp till 16 URL:er; multipart använder ett eller flera `image`-filfält. Vid användning av `mask` måste lokala bildfiler laddas upp                                              |
| `mask`            | Valfri PNG-mask, endast för multipart-filuppladdning; måste ha Alpha-kanal, samma storlek som den första `image` och får inte överstiga 4 MB                                                                 |
| `prompt`          | Redigeringsinstruktion                                                                                                                             |
| `size`            | `auto` eller en `WIDTHxHEIGHT` som uppfyller begränsningarna                                                                                                     |
| `n`               | 1–10; när `response_format=b64_json` används stöds endast 1                                                                                           |
| `response_format` | `url` eller `b64_json`                                                                                                               |
| `callback_url`    | Valfri asynkron återanropsadress                                                                                                                         |

Storleksreglerna är desamma som för genereringsgränssnittet: bredd och höjd måste vara multiplar av 16, längsta sidan får inte överstiga 3840, det totala antalet pixlar ska vara 655 360–8 294 400 och bildförhållandet får inte överstiga 3:1. När `size` utelämnas eller `auto` används väljer modellen format utifrån prompten och den första referensbilden.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` och deras `:reverse`-alias debiteras per antal lyckade bilder; `gpt-image-2:official`, `gpt-image-2.5-flare:official` och `gpt-image-2.5-sunburst:official` debiteras enligt faktisk Token-användning för textinmatning, referensbildsinmatning och bildutmatning, och den slutliga uppgiften baseras på användningsposterna.

## 6. Asynkrona återanrop och felsökning

Långa uppgifter kan inkludera följande i begäran:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Det asynkrona 200-svaret är `{"task_id": "..."}`; det slutliga resultatet skickas tillbaka när uppgiften är klar. Synkrona begäranden returnerar däremot `created` och `data`.

| Status  | Kontroll                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Bildformat/-antal, parameterkombinationer och storleksformat; kontrollera vid användning av `mask` PNG Alpha-kanalen, 4 MB-gränsen och att dess storlek överensstämmer med den första originalbilden |
| 401 | API Key och Bearer Header                                           |
| 429 | Begärandefrekvens                                                              |
| 504 | Byt till asynkront återanrop                                                            |

Felsvar innehåller `trace_id`. Ange detta ID när du rapporterar problem, men ange inte API Key.

Fullständiga fält och aktuella uppräkningar finns på sidan [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). För att generera bilder från enbart text, se [GPT Image 2 / 2.5 / 2.6 bildgenerering](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

GPT Image 2.6 använder samma gränssnitt som 2.5 för generering, redigering, asynkrona uppgifter och debitering:

| Modell                                                          | Debitering                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/bild                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/bild                   |
| `gpt-image-2.6-flare:official`                              | Samma som 2.5 official, debiteras enligt faktisk Token-användning |
| `gpt-image-2.6-sunburst:official`                           | Samma som 2.5 official, debiteras enligt faktisk Token-användning |

Kvaliteten kan väljas som `auto`, `low`, `medium`, `high`, `xhigh`, `max`; för storlek används `auto` eller `WIDTHxHEIGHT` som uppfyller ovanstående begränsningar. Detta gränssnitt stöder `png`, `jpeg`, `webp`, men stöder för närvarande inte SVG/GIF. Redigering stöder JSON-bild-URL:er och multipart-filuppladdning. `:reverse` är ett uttryckligt alias för den vanliga versionen med samma namn. Använd fullständigt modellnamn och skicka inte `gpt-image-2.6`.
