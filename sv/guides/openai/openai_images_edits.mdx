## 1. Hämta API Key

Öppna [Ace Data Cloud-applistan](https://platform.acedata.cloud/console/applications), gå in i den tillgängliga appen och kopiera API Key.

![Hämta Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Redigera med bild-URL

Originalbild:

![GPT Image 2 originalbild för redigering](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

Lyckat svar:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Detta är redigeringsresultatet som faktiskt slutfördes via Ace Data Cloud den 8 september 2026. Muggen blev orange, bakgrunden blev mörk marinblå, och den ursprungliga kompositionen samt storleken 1024×1536 behölls:

![GPT Image 2 redigeringsresultat med orange kaffemugg](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Ladda upp lokal bild

Använd `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` kan skickas in upprepade gånger, och GPT Image-serien stöder upp till 16 referensbilder. `image` i JSON-förfrågningar kan vara en enskild URL eller en URL-array; lokala filer laddas upp med multipart.

## 4. Vanliga parametrar

| Fält                | Beskrivning                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (snabbare) eller `gpt-image-2.5-sunburst` (högre detaljtrohet och kontroll); alla tre kan välja motsvarande `:official`-variant, och `gpt-image-2` stöder även `:reverse` |
| `image`           | JSON använder en enskild URL eller en array med upp till 16 URL:er; multipart använder ett eller flera `image`-filfält                                                                    |
| `prompt`          | Redigeringsinstruktion                                                                                                                             |
| `size`            | `auto` eller `WIDTHxHEIGHT` som uppfyller begränsningarna                                                                                                     |
| `n`               | 1–10; när `response_format=b64_json` används stöds endast 1                                                                                           |
| `response_format` | `url` eller `b64_json`                                                                                                               |
| `callback_url`    | Valfri asynkron callback-adress                                                                                                                         |

Storleksreglerna är desamma som för genereringsgränssnittet: bredd och höjd måste vara multiplar av 16, den längsta sidan får inte överstiga 3840, det totala antalet pixlar ska vara 655 360–8 294 400 och bildförhållandet får inte överstiga 3:1. När `size` utelämnas eller `auto` används väljer modellen bildformat utifrån prompten och den första referensbilden.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` och `gpt-image-2:reverse` debiteras per antal lyckade bilder; `gpt-image-2:official`, `gpt-image-2.5-flare:official` och `gpt-image-2.5-sunburst:official` debiteras enligt de faktiska token för textinmatning, referensbildsinmatning och bildutmatning, och den slutliga debiteringen baseras på användningsposterna.

## 5. Asynkron callback och felsökning

Långa uppgifter kan inkludera följande i förfrågan:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Det asynkrona 200-svaret är `{"task_id": "..."}`; när uppgiften är klar skickas callbacken med slutresultatet. Synkrona förfrågningar returnerar däremot `created` och `data`.

| Status  | Kontroll                      |
| --- | ----------------------- |
| 400 | Bildformat/antal, parameterkombinationer och storleksformat       |
| 401 | API Key och Bearer Header |
| 429 | Förfrågningsfrekvens                    |
| 504 | Byt till asynkron callback                  |

Felsvar innehåller `trace_id`. Ange detta ID när du rapporterar problem, men ange inte API Key.

Se sidan [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) för fullständiga fält och uppdaterade uppräkningar. För att generera bilder från enbart text, se [GPT Image 2 / 2.5 bildgenerering](https://platform.acedata.cloud/documents/openai-images-generations).
