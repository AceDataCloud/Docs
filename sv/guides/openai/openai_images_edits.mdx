## 2. Redigera med bild-URL

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
```

## 3. Ladda upp lokal bild

Använd `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` kan skickas in upprepade gånger, GPT Image-serien stöder högst 16 referensbilder. `image` i JSON-begäran kan vara en enskild URL eller en URL-array; lokala filer laddas upp med multipart.

### Modeller och debiteringssätt

| Modell                                | Användningsområde och debiteringssätt                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Standardkanal för omvänd åtkomst, fast debitering per antal lyckade bilder                        |
| `gpt-image-2:reverse`             | Välj uttryckligen kanalen för omvänd åtkomst, fast debitering per antal lyckade bilder                      |
| `gpt-image-2:official`            | Officiell API-kanal, högre stabilitet, debitering efter faktisk Token-användning            |
| `gpt-image-2.5-flare`             | Fokuserar på genereringshastighet, fast debitering per antal lyckade bilder                        |
| `gpt-image-2.5-flare:official`    | Officiell API-kanal, högre stabilitet och fokus på genereringshastighet, debitering efter faktisk Token-användning     |
| `gpt-image-2.5-sunburst`          | Fokuserar på hög återgivningstrohet och detaljerad kontroll, fast debitering per antal lyckade bilder                    |
| `gpt-image-2.5-sunburst:official` | Officiell API-kanal, högre stabilitet och fokus på hög återgivningstrohet och detaljerad kontroll, debitering efter faktisk Token-användning |

Sidpriset för den officiella API-kanalen är en uppskattning före begäran, och det slutliga priset baseras på faktisk Token-användning i svaret och användningsposterna.

## 4. Använd mask för lokal redigering

Det officiella Images Edit-gränssnittet använder `mask` för att ange området som får ändras. Ace Data Clouds `:official`-modeller följer samma multipart-kontrakt:

- `mask` måste vara en PNG med Alpha-kanal och får inte vara större än 4 MB;
- maskens storlek måste vara exakt samma som den första `image`;
- transparenta pixlar med Alpha `0` anger att redigering är tillåten, och icke-transparenta pixlar anger att de ska bevaras;
- RGB-bilder som endast är svartvita men saknar transparenskanal kan inte användas som giltiga masker;
- prompten bör beskriva den önskade kompletta bilden, samtidigt som den lokala ändringen och innehållet som behöver förbli oförändrat tydligt anges.

Nedan genereras först en mask från originalbilden. Exemplet gör den centrala rektangeln transparent och tillåter endast modellen att ändra detta område:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Ladda sedan upp originalbilden och masken tillsammans:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Du kan också fortsätta använda anropssättet `images.edit` i OpenAI:s officiella Python SDK, och behöver bara peka `base_url` till Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

När `mask` används måste originalbilden och masken laddas upp i samma multipart-begäran via `image=@input.png` respektive `mask=@mask.png`. Blanda inte en URL-originalbild med en lokal maskfil; rena URL-redigeringsbegäranden stöder inte att ytterligare bifoga en lokal `mask`-fil. Masken begränsar redigeringsområdet, men den generativa modellen kan fortfarande göra naturliga övergångar vid kanterna; när strikta gränser krävs bör tydliga Alpha-kanter användas och det bör upprepas i prompten vilket innehåll som måste förbli oförändrat.

Ovanstående anropssätt stämmer överens med maskexemplen i [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) och [GPT Image officiella Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).
## 5. Vanliga parametrar

| Fält                | Beskrivning                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (snabbare) eller `gpt-image-2.5-sunburst` (högre återgivningstrohet och kontroll); alla tre kan välja motsvarande `:official`-variant, och `gpt-image-2` stöder även `:reverse` |
| `image`           | JSON använder en enskild URL eller en array med högst 16 URL:er; multipart använder ett eller flera `image`-filfält. När `mask` används måste lokala bildfiler laddas upp                                              |
| `mask`            | Valfri PNG-mask, endast för uppladdning av multipart-filer; måste ha en Alpha-kanal, samma storlek som den första `image` och inte överstiga 4 MB                                                                 |
| `prompt`          | Redigeringsinstruktion                                                                                                                             |
| `size`            | `auto` eller `WIDTHxHEIGHT` som uppfyller begränsningarna                                                                                                     |
| `n`               | 1–10; när `response_format=b64_json` används stöds endast 1                                                                                           |
| `response_format` | `url` eller `b64_json`                                                                                                               |
| `callback_url`    | Valfri asynkron callback-adress                                                                                                                         |

Storleksreglerna är desamma som för genereringsgränssnittet: bredd och höjd måste vara multiplar av 16, den längsta sidan får inte överstiga 3840, det totala antalet pixlar är 655 360–8 294 400 och bildförhållandet får inte överstiga 3:1. När `size` utelämnas eller `auto` används väljer modellen format baserat på prompten och den första referensbilden.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` och `gpt-image-2:reverse` debiteras per antal lyckade bilder; `gpt-image-2:official`, `gpt-image-2.5-flare:official` och `gpt-image-2.5-sunburst:official` debiteras utifrån de faktiska token för textinmatning, referensbildsinmatning och bildutmatning, och den slutliga uppgiften baseras på användningsregistreringen.

## 6. Asynkrona callbacks och felsökning

För långa uppgifter kan följande läggas till i begäran:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Det asynkrona 200-svaret är `{"task_id": "..."}`; när uppgiften är klar skickas det slutliga resultatet via callback. Synkrona begäranden returnerar i stället `created` och `data`.

| Status  | Kontroll                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Bildformat/-antal, parameterkombinationer och storleksformat; vid användning av `mask`, kontrollera PNG Alpha-kanalen, 4 MB-gränsen och om dess storlek överensstämmer med den första originalbilden |
| 401 | API Key och Bearer Header                                           |
| 429 | Begärandefrekvens                                                              |
| 504 | Byt till asynkron callback                                                            |

Felsvar innehåller `trace_id`. Ange detta ID när du rapporterar problem, och ange inte API Key.

Fullständiga fält och realtidsuppräkningar finns på sidan [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). För att generera bilder enbart från text, se [GPT Image 2 / 2.5 bildgenerering](https://platform.acedata.cloud/documents/openai-images-generations).
