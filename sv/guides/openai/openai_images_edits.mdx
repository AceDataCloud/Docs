## 1. Hämta API-nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Redigera med bild-URL

Originalbild:

![GPT Image 2 redigera originalbild](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer din API-nyckel" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Behåll muggen, bordet, kameravinkeln, porträttlayouten och mjuk skugga oförändrade. Ändra endast muggens färg från vit till livlig orange och den bleka krämfärgade bakgrunden till solid mörk marinblå. Ingen text och ingen logotyp.",
    "size": "1024x1536"
  }'
```

Framgångsrikt svar:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Detta är redigeringsresultatet som genomfördes den 8 september 2026 via Ace Data Cloud, muggen blev orange, bakgrunden blev mörk marinblå, och den ursprungliga kompositionen och storleken 1024×1536 behölls:

## 3. Ladda upp lokal bild

Använd `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer din API-nyckel" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Byt bakgrunden till en ljus modern studio"
```

Du kan upprepade gånger skicka in `image`, GPT Image-serien stöder upp till 16 referensbilder. `image` i JSON-förfrågan kan vara en enda URL eller en array av URL:er; lokala filer använder multipart-uppladdning.

## 4. Vanliga parametrar

| Fält                | Beskrivning                                                      |
| ----------------- | ------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2:official` eller `gpt-image-2:reverse`  |
| `image`           | JSON använder en enda URL eller upp till 16 URL:er i en array; multipart använder ett eller flera `image` filfält |
| `prompt`          | Redigeringsinstruktion                                          |
| `size`            | `auto` eller en giltig `BREDDAxHÖJD`                             |
| `n`               | 1–10; `response_format=b64_json` stöder endast 1                |
| `response_format` | `url` eller `b64_json`                                        |
| `callback_url`    | Valfri asynkron callback-adress                                  |

Storleksreglerna är desamma som för genereringsgränssnittet: bredd och höjd måste vara multiplar av 16, långsidan får inte överstiga 3840, och totalt antal pixlar får inte överstiga 8 294 400. Om `size` utelämnas eller `auto` används, kommer modellen att välja format baserat på prompten och den första referensbilden.

Standard `gpt-image-2` och `:reverse` debiteras baserat på antalet framgångsrika bilder; `gpt-image-2:official` debiteras baserat på det faktiska antalet tokens för textinmatning, referensbildsinmatning och bildutmatning, slutligen baserat på användningshistorik.

## 5. Asynkron callback och felsökning

Långa uppgifter kan inkludera:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asynkront 200-svar är `{"task_id": "..."}`; efter slutförande callbackar det slutgiltiga resultatet. Synkrona förfrågningar returnerar `created` och `data`.

| Status  | Kontroll                      |
| --- | ----------------------- |
| 400 | Bildformat/antal, parameterkombinationer och storleksformat       |
| 401 | API-nyckel och Bearer-header |
| 429 | Begärningsfrekvens                    |
| 504 | Använd asynkron callback                  |

Felaktiga svar kommer att innehålla `trace_id`. Vid rapportering av problem, ange detta ID, ge inte API-nyckeln.

Fullständiga fält och realtidsuppräkning finns på [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) sidan. För ren textgenerering av bilder, se [GPT Image 2 bildgenerering](https://platform.acedata.cloud/documents/openai-images-generations).
