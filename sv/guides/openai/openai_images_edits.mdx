## 1. Hämta API Nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API nyckeln.

![Hämta Ace Data Cloud API Nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Använda bild-URL för redigering

Originalbild:

![GPT Bild 2 redigera originalbild](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer din API nyckel" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Behåll muggen, bordet, kameravinkeln, porträttlayouten och mjuk skugga oförändrade. Ändra endast muggens färg från vit till livlig orange och den bleka krämfärgade bakgrunden till solid mörk marinblå. Ingen text och ingen logotyp.",
    "size": "1024x1536"
  }'
```

## 3. Ladda upp lokal bild

Använd `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer din API nyckel" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Byt ut bakgrunden mot en ljus modern studio"
```

Det går att skicka flera `image`, GPT Bild-serien stöder upp till 16 referensbilder. `image` i JSON-förfrågan kan vara en enda URL eller en array av URL:er; lokala filer laddas upp med multipart.

## 4. Vanliga parametrar

| Fält                | Beskrivning                                                                                                               |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (snabbare), `gpt-image-2.5-sunburst` (högre trohet och kontroll), `gpt-image-2:official` eller `gpt-image-2:reverse` |
| `image`           | JSON använder en enda URL eller upp till 16 URL:er i en array; multipart använder ett eller flera `image` filfält                                                            |
| `prompt`          | Redigeringsinstruktion                                                                                                   |
| `size`            | `auto` eller en giltig begränsning av `WIDTHxHEIGHT`                                                                                     |
| `n`               | 1–10; endast 1 stöds när `response_format=b64_json`                                                                       |
| `response_format` | `url` eller `b64_json`                                                                                                   |
| `callback_url`    | Valfri asynkron callback-adress                                                                                           |

Storleksreglerna är desamma som för genereringsgränssnittet: bredd och höjd måste vara multiplar av 16, den längsta sidan får inte överstiga 3840, totalt antal pixlar mellan 655,360–8,294,400, och bildförhållandet får inte överstiga 3:1. Om `size` utelämnas eller `auto` används, kommer modellen att välja format baserat på prompten och den första referensbilden.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` och `:reverse` debiteras baserat på antalet framgångsrika bilder; `gpt-image-2:official` debiteras baserat på det faktiska antalet tokens för textinmatning, referensbildsinmatning och bildutdata, slutligen baserat på användningshistorik.

## 5. Asynkron callback och felsökning

Långa uppgifter kan inkludera:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asynkront 200-svar är `{"task_id": "..."}`; callback med det slutliga resultatet efter slutförande. Synkrona förfrågningar returnerar `created` och `data`.

| Status  | Kontroll                      |
| --- | ----------------------- |
| 400 | Bildformat/antal, parameterkombinationer och storleksformat       |
| 401 | API nyckel och Bearer Header |
| 429 | Begärningsfrekvens                    |
| 504 | Använd asynkron callback                  |

Felaktiga svar kommer att innehålla `trace_id`. Vid rapportering av problem, ange detta ID, ge inte ut API nyckeln.

Fullständiga fält och realtidsuppräkning finns på [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) sidan. För att generera bilder i ren text, se [GPT Bild 2 / 2.5 bildgenerering](https://platform.acedata.cloud/documents/openai-images-generations).
