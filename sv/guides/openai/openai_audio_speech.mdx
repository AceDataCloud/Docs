---
title: "OpenAI röstsyntes API (/v1/audio/speech)"
description: "OpenAI generation API guide - Ace Data Cloud"
---

Sammanfoga text till naturligt tal, **helt kompatibel med OpenAI:s `/v1/audio/speech`**. Alla OpenAI SDK:er behöver bara peka `base_url` till `https://api.acedata.cloud` och byta ut nyckeln mot din AceData Token för att använda den direkt. Gränssnittet returnerar ljudbyte-ström synkront.

- **Begärningsadress**: `POST https://api.acedata.cloud/v1/audio/speech` (alias `POST /openai/audio/speech`)
- **Autentisering**: Begärningshuvud `Authorization: Bearer {token}`
- **Avgift**: Avgift baseras på begärd texts byteantal, cirka 85% av OpenAI:s officiella pris (se tabellen nedan).

## Begärningsparametrar

| Fält                | Typ     | Obligatoriskt | Beskrivning                                                      |
| ----------------- | ------ | ------------ | ------------------------------------------------------------- |
| `input`           | string | Ja           | Texten som ska sammanfogas.                                     |
| `model`           | string | Nej          | `tts-1` (snabbare) eller `tts-1-hd` (högre ljudkvalitet, standard). |
| `voice`           | string | Nej          | En av `alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`, standard `alloy`. |
| `response_format` | string | Nej          | `mp3` (standard), `opus`, `aac`, `flac`, `wav`, `pcm`.        |
| `speed`           | number | Nej          | Talhastighet 0.25–4.0, standard 1.0.                          |

## Exempel

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/speech' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -o speech.mp3 \
  -d '{
    "model": "tts-1-hd",
    "input": "Vad om en API gav dig varje AI videomodell?",
    "voice": "nova",
    "response_format": "mp3"
  }'
```

Det som returneras är själva ljudfilen (`Content-Type: audio/mpeg`), skriv direkt till `speech.mp3` för att spela upp.

Använd officiella OpenAI Python SDK:

```python
from openai import OpenAI
client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
client.audio.speech.create(model="tts-1-hd", voice="nova", input="Hej från AceData.").stream_to_file("speech.mp3")
```

## Priser

| Modell         | OpenAI officiella pris | Detta plattformspris (cirka 85% rabatt) |
| ---------- | ------------------ | --------------------- |
| `tts-1`    | $15 / 1 miljon tecken | cirka $12.75 / 1 miljon tecken |
| `tts-1-hd` | $30 / 1 miljon tecken | cirka $25.5 / 1 miljon tecken  |

> Avgift baseras på begärd texts byteantal; `official_price` fältet visar OpenAI:s officiella pris för jämförelse.

## Felkoder

| Statuskod | kod                    | Beskrivning           |
| --- | ----------------------- | -------------------- |
| 400 | `bad_request`           | `input` är tomt eller parameter är ogiltig. |
| 401 | `authentication_failed` | token är ogiltig.    |
| 403 | `used_up`               | Otillräcklig balans. |
| 429 | `too_many_requests`     | Begärningar för ofta. |
| 500 | `api_error`             | Uppströms/intern fel. |
