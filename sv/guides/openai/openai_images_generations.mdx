## 1. Hämta API-nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Skicka den första förfrågan

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer din API-nyckel" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal redaktionell produktillustration: en enkel vit keramik kaffekopp centrerad på ett solidt koboltblått bord, blek krämfärgad bakgrund, mjuk skugga, rena geometriska former, ingen text, ingen logotyp, porträttkomposition",
    "size": "1024x1536"
  }'
```

Den framgångsrika responsens bild finns på `data[].url`. Här är resultatet 1024×1536 som erhölls genom en faktisk förfrågan via Ace Data Cloud den 8 september 2026 (uppdrag `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, spår `eb938601-8192-407f-b539-1e0554b697ec`):

![GPT Bild 2 genererad vit kaffekopp](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Vanliga parametrar

| Fält               | Beskrivning                                                                                                                               |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (standard rekommenderad), `gpt-image-2.5-flare` (snabbare) eller `gpt-image-2.5-sunburst` (högre trohet och kontroll); kan också explicit välja `gpt-image-2:official` eller `gpt-image-2:reverse` |
| `prompt`          | Bildbeskrivning, max 32 000 tecken                                                                                                        |
| `size`            | `auto` eller `BREDDAxHÖJD`; bredd och höjd måste vara multiplar av 16, långsidan får inte överstiga 3840, totalt antal pixlar 655 360–8 294 400, bildförhållande får inte överstiga 3:1                             |
| `n`               | 1–10; `response_format=b64_json` stödjer endast 1                                                                                          |
| `quality`         | `low`, `medium`, `high` eller `auto`; olika linjer har olika stöd och debiteringsmetoder                                                                 |
| `response_format` | `url` eller `b64_json`                                                                                                                  |
| `callback_url`    | Valfritt; skicka resultatet till denna adress efter att långa uppgifter är klara                                                                 |

Vanliga storlekar:

| Förhållande | 1K          | 2K          | 4K          |
| ----------- | ----------- | ----------- | ----------- |
| 1:1         | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3         | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4         | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9        | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16        | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` väljer bildformat baserat på förhållandet, pixlar och layoutintentioner i prompten; ange storlek direkt när exakta pixlar behövs.

## 4. Generera flera bilder

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer din API-nyckel" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "En liten räv som läser under en lysande svamp, akvarellillustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` och `:reverse` debiteras baserat på antalet framgångsrika bilder; `gpt-image-2:official` debiteras baserat på den faktiska token som används för textinmatning och bildutdata. Priserna på sidan är uppskattningar före förfrågan, den slutliga debiteringen baseras på användningshistorik.

## 5. Asynkron callback

När `callback_url` läggs till i begäran kommer API:et först att returnera `{"task_id": "..."}`, och när det är klart kommer det att POST:a det slutliga resultatet till den URL:en; synkrona förfrågningar returnerar fortfarande `created` och `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "En produktposter med tydlig typografi",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Callback-mottagaren bör använda `task_id` för att undvika dubbletter och verifiera begärans källa och dataformat.

## 6. Felsökning

| Status | Kontroll                                               |
| ------ | ----------------------------------------------------- |
| 400    | `model`, `prompt`, storleksformat, `n` och `response_format` kombination |
| 401    | Är API-nyckeln komplett, är Header `Authorization: Bearer ...` |
| 429    | För många förfrågningar, försök igen senare                     |
| 504    | Synkron generering timeout; använd istället `callback_url` |

Felresponsen kommer att innehålla `error.code`, `error.message` och `trace_id`. Vid feedback av problem, ange `trace_id`, ge inte ut API-nyckeln.

Fullständiga fält och realtidsuppräkning finns på [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations) sidan. För bildredigering, se [GPT Bild 2 / 2.5 bildredigering](https://platform.acedata.cloud/documents/openai-images-edits).
