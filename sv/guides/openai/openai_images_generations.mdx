## 1. Hämta API-nyckel

Öppna [Ace Data Cloud-applikationslistan](https://platform.acedata.cloud/console/applications), gå in i den tillgängliga applikationen och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Skicka den första begäran

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Bilden i det lyckade svaret finns i `data[].url`. Nedan visas resultatet i 1024×1536 som faktiskt erhölls genom en begäran via Ace Data Cloud den 8 september 2026 (uppgift `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Vit kaffemugg genererad av GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Vanliga parametrar

| Fält                | Beskrivning                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (rekommenderas som standard), `gpt-image-2.5-flare` (snabbare) eller `gpt-image-2.5-sunburst` (högre återgivningstrohet och kontroll); alla tre kan välja motsvarande `:official`-variant, och `gpt-image-2` har även stöd för `:reverse` |
| `prompt`          | Bildbeskrivning, högst 32 000 tecken                                                                                                                     |
| `size`            | `auto` eller `WIDTHxHEIGHT`; bredd och höjd måste vara multiplar av 16, den längsta sidan får inte överstiga 3840, totalt antal pixlar är 655 360–8 294 400, och bildförhållandet får inte överstiga 3:1                                                       |
| `n`               | 1–10; endast 1 stöds när `response_format=b64_json` används                                                                                                 |
| `quality`         | `low`, `medium`, `high` eller `auto`; stöd och faktureringssätt varierar mellan olika rutter                                                                                          |
| `response_format` | `url` eller `b64_json`                                                                                                                     |
| `callback_url`    | Valfritt; skickar resultat till denna adress när långa uppgifter har slutförts                                                                                                                      |

Vanliga storlekar:

| Förhållande   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` väljer bildformat baserat på bildförhållandet, pixlarna och layoutavsikten i prompten; ange storleken direkt när exakta pixlar krävs.

## 4. Generering av flera bilder

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` och `gpt-image-2:reverse` debiteras per antal lyckade bilder; `gpt-image-2:official`, `gpt-image-2.5-flare:official` och `gpt-image-2.5-sunburst:official` avräknas enligt faktiska Token för textinmatning och bildutmatning i svaret. Priset på sidan är en uppskattning före begäran, och det slutliga underlaget är användningsposterna.

## 5. Asynkron återuppringning

Efter att `callback_url` har lagts till i begärans brödtext returnerar gränssnittet först `{"task_id": "..."}` och POST:ar slutresultatet till denna URL när uppgiften har slutförts; synkrona begäranden returnerar fortfarande `created` och `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Mottagaren av återuppringningen bör använda `task_id` för dubblettkontroll och verifiera begärans källa och dataformatet.

## 6. Felsökning

| Status  | Kontrollera                                                  |
| --- | --------------------------------------------------- |
| 400 | Kombinationen av `model`, `prompt`, storleksformat, `n` och `response_format`    |
| 401 | Om API-nyckeln är komplett och om Header är `Authorization: Bearer ...` |
| 429 | Begäran är för frekvent, försök igen senare                                         |
| 504 | Synkron generering har överskridit tidsgränsen; använd `callback_url`                            |

Felsvaret innehåller `error.code`, `error.message` och `trace_id`. Ange `trace_id` när du rapporterar problem, men ange inte API-nyckeln.

För kompletta fält och realtidsuppräkningar, se sidan [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). För bildredigering, se [GPT Image 2 / 2.5 Bildredigering](https://platform.acedata.cloud/documents/openai-images-edits).
