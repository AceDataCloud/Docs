## 1. Hämta API-nyckel

Öppna [Ace Data Cloud applikationslista](https://platform.acedata.cloud/console/applications), gå till tillgängliga applikationer och kopiera API-nyckeln.

![Hämta Ace Data Cloud API-nyckel](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Skicka den första förfrågan

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer din API-nyckel" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal redaktionell produktillustration: en enkel vit keramik kaffekopp centrerad på ett solidt koboltblått bord, blek krämfärgad bakgrund, mjuk skugga, rena geometriska former, ingen text, ingen logotyp, porträttkomposition",
    "size": "1024x1536"
  }'
```

Den framgångsrika responsens bild finns på `data[].url`. Här är resultatet 1024×1536 som faktiskt begärdes den 8 september 2026 via Ace Data Cloud (uppdrag `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, spår `eb938601-8192-407f-b539-1e0554b697ec`):

![GPT Image 2 genererad vit kaffekopp](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Vanliga parametrar

| Fält                | Beskrivning                                                               |
| ----------------- | ---------------------------------------------------------------------- |
| `model`           | Använd `gpt-image-2`; kan också uttryckligen välja `gpt-image-2:official` eller `gpt-image-2:reverse` |
| `prompt`          | Bildbeskrivning, max 32 000 tecken                                          |
| `size`            | `auto` eller `WIDTHxHEIGHT`; bredd och höjd måste vara multiplar av 16, långsidan får inte överstiga 3840, totalt antal pixlar får inte överstiga 8 294 400        |
| `n`               | 1–10; `response_format=b64_json` stöder endast 1                          |
| `quality`         | `low`, `medium`, `high` eller `auto`; olika linjer har olika stöd och prissättning                          |
| `response_format` | `url` eller `b64_json`                                                 |
| `callback_url`    | Valfritt; skicka resultatet till denna adress efter att långa uppgifter är klara                                                      |

Vanliga storlekar:

| Förhållande | 1K          | 2K          | 4K          |
| ----------- | ----------- | ----------- | ----------- |
| 1:1         | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3         | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4         | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9        | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16        | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` väljer bildformat baserat på förhållandet, pixlar och layoutintentioner i prompten; ange storlek direkt när exakta pixlar behövs.

## 4. Flera generationer

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer din API-nyckel" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "En liten räv som läser under en lysande svamp, akvarellillustration",
    "size": "1536x1024",
    "n": 2
  }'
```

Standard `gpt-image-2` och `:reverse` debiteras baserat på antalet framgångsrika bilder; `gpt-image-2:official` debiteras baserat på den faktiska tokenberäkningen av textinmatning och bildutmatning i svaret. Priserna på sidan är uppskattningar före begäran, den slutliga kostnaden baseras på användningshistorik.

## 5. Asynkron callback

När begärningskroppen inkluderar `callback_url`, kommer gränssnittet först att returnera `{"task_id": "..."}`, och när det är klart skickas det slutliga resultatet till den URL:en med POST; synkrona förfrågningar returnerar fortfarande `created` och `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "En produktposter med tydlig typografi",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Callback-mottagaren bör använda `task_id` för att undvika dubbletter och verifiera begärningens källa och dataformat.

## 6. Felsökning

| Status | Kontroll                                               |
| ------ | ----------------------------------------------------- |
| 400    | `model`, `prompt`, storleksformat, `n` och `response_format` kombination    |
| 401    | Är API-nyckeln komplett, är Header `Authorization: Bearer ...` |
| 429    | För många förfrågningar, försök igen senare                     |
| 504    | Synkron generation timeout; använd istället `callback_url`            |

Felresponsen kommer att innehålla `error.code`, `error.message` och `trace_id`. Vid rapportering av problem, ange `trace_id`, ge inte ut API-nyckeln.

Fullständiga fält och realtidsuppräkning finns på [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations) sidan. För bildredigering, se [GPT Image 2 Bildredigering](https://platform.acedata.cloud/documents/openai-images-edits).
