## 1. Hämta API Key

Öppna [Ace Data Cloud-applistan](https://platform.acedata.cloud/console/applications), gå till en tillgänglig app och kopiera API Key.

![Hämta Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Skicka den första begäran

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Bilden i ett lyckat svar finns i `data[].url`. Nedan är resultatet i 1024×1536 som faktiskt erhölls genom en begäran via Ace Data Cloud den 8 september 2026 (uppgift `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Vit kaffemugg genererad av GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Vanliga parametrar

| Fält                | Beskrivning                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (standardrekommendation), `gpt-image-2.5-flare` (snabbare) eller `gpt-image-2.5-sunburst` (högre återgivningstrohet och kontroll); alla tre kan välja motsvarande variant `:official`, och `gpt-image-2` har även stöd för `:reverse` |
| `prompt`          | Bildbeskrivning, högst 32 000 tecken                                                                                                                     |
| `size`            | `auto` eller `WIDTHxHEIGHT`; bredd och höjd måste vara multiplar av 16, längsta sidan får inte överstiga 3840, totalt antal pixlar är 655 360–8 294 400 och bildförhållandet får inte överstiga 3:1                                                       |
| `n`               | 1–10; endast 1 stöds när `response_format=b64_json` används                                                                                                 |
| `quality`         | GPT Image-modeller har stöd för `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare / Sunburst (inklusive `:official`) har dessutom stöd för `xhigh`, `max`. Officiella kanaler debiteras enligt faktisk Token-användning             |
| `response_format` | `url` eller `b64_json`                                                                                                                     |
| `callback_url`    | Valfritt; skickar resultat till denna adress när långa uppgifter är slutförda                                                                                                                      |

Vanliga storlekar:

| Förhållande   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` väljer bildformat baserat på proportionerna, pixlarna och layoutavsikten i prompten; ange storleken direkt när exakta pixlar krävs.

Priset som visas på sidan för den officiella API-kanalen är en uppskattning före begäran. Slutlig debitering baseras på den faktiska Token-användningen i svaret och användningsloggen.

## 4. Generering av flera bilder

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` och deras `:reverse`-alias debiteras per antal lyckade bilder; `gpt-image-2:official`, `gpt-image-2.5-flare:official` och `gpt-image-2.5-sunburst:official` debiteras baserat på den faktiska Token-användningen för textinmatning och bildutmatning i svaret. Priserna på sidan är uppskattningar före begäran; det slutliga beloppet baseras på användningsposterna.

## 5. Asynkron återanrop

När `callback_url` läggs till i begärandetexten returnerar gränssnittet först `{"task_id": "..."}` och POST:ar slutresultatet till den URL:en när det är klart; synkrona begäranden returnerar fortfarande `created` och `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Mottagaren av återanropet bör använda `task_id` för deduplicering och verifiera begärans källa och dataformatet.

## 6. Felsökning

| Status  | Kontrollera                                                  |
| --- | --------------------------------------------------- |
| 400 | Kombinationen av `model`, `prompt`, storleksformat, `n` och `response_format`    |
| 401 | Om API Key är komplett och om Header är `Authorization: Bearer ...` |
| 429 | Begäran är för frekvent, försök igen senare                                         |
| 504 | Tidsgräns för synkron generering; använd `callback_url`                            |

Felsvar innehåller `error.code`, `error.message` och `trace_id`. Ange `trace_id` när du rapporterar problem, men ange inte API Key.

Fullständiga fält och aktuella uppräkningar finns på sidan [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). För bildredigering, se [GPT Image 2 / 2.5 / 2.6 bildredigering](https://platform.acedata.cloud/documents/openai-images-edits).

## GPT Image 2.6

GPT Image 2.6 använder samma gränssnitt för generering, redigering, asynkrona uppgifter och debitering som 2.5:

| Modell                                                          | Debitering                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/bild                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/bild                   |
| `gpt-image-2.6-flare:official`                              | Samma som 2.5 official, debiteras enligt faktisk Token-användning |
| `gpt-image-2.6-sunburst:official`                           | Samma som 2.5 official, debiteras enligt faktisk Token-användning |

Kvalitet kan vara `auto`, `low`, `medium`, `high`, `xhigh`, `max`; för storlek används `auto` eller `WIDTHxHEIGHT` som uppfyller ovanstående begränsningar. Detta gränssnitt stöder `png`, `jpeg`, `webp`; GPT Image 2.6 stöder även inbyggda `gif`-animationer, men stöder för närvarande inte SVG. Redigering stöder JSON-bild-URL:er och multipart-filuppladdning. `:reverse` är ett explicit alias för den vanliga versionen med samma namn. Använd fullständigt modellnamn, och skicka inte `gpt-image-2.6`.

### GPT Image 2.6 GIF-animationer

De vanliga versionerna, `:reverse` och `:official` för GPT Image 2.6 Flare och Sunburst kan alla använda `output_format: "gif"`. Animationsbildrutor, loopinformation och uppspelningstid bevaras; `frame_count` anger antalet bildrutor och `frame_duration_ms` anger millisekunder per bildruta. Antalet bildrutor måste vara ett heltal mellan 2–16, varaktigheten per bildruta måste vara ett heltal mellan 20–655350 millisekunder och används endast för GIF; kodningen avrundas till närmaste 10 ms. Om inget anges används som standard 9 bildrutor och 200 millisekunder per bildruta; när GIF:ens size utelämnas eller är auto används förinställningen 512x512.

Det rekommenderas att först använda `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. GIF har egna begränsningar för storlek och antal bildrutor och kan inte direkt använda statiska 4K-specifikationer; vissa modeller justerar den faktiska utmatningsstorleken. `n` anger antalet GIF-filer som returneras, inte antalet animationsbildrutor. Den vanliga versionen och `:reverse` debiteras fortfarande per antal lyckade filer, medan den officiella versionen debiteras enligt faktisk Token-användning.

```json
{
  "model": "gpt-image-2.6-flare",
  "prompt": "A small red ball moves left and right on a white background, seamless looping animation, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### GPT Image 2.6 4K-stillbilder

Flare, Sunburst och deras `:reverse`- och `:official`-varianter kan alla använda ovanstående 4K-pixelförinställningar, till exempel `3840x2160` och `2160x3840`. Både generering och redigering skickar specifika pixlar via `size`; `4K` är inte ett giltigt `size`-värde och `4096x4096` överskrider också den nuvarande pixelgränsen. Ovanstående 4K-specifikationer gäller statiska PNG/JPEG/WebP-bilder; för GIF ska dess särskilda parametrar användas.

### GPT Image 2.6 kompositionskomplexitet

`complexity` kan vara `low`, `medium`, `high`; om det utelämnas används modellens standardvärde `high`. Det styr planeringskomplexiteten och är oberoende av renderingskvaliteten `quality`; ingen extra avgift tas per användning, och den officiella versionen debiteras fortfarande enligt faktisk Token-användning. Andra modeller stöder inte denna parameter.

GIF stöder inte mask, annoteringsbilder, anpassad komprimering, omskrivning av prompt eller partiell bildströmning; inkompatibla kombinationer avvisas före generering. Storlek, antal bildrutor och antal begränsas gemensamt av modellens pixelbudget; `1024x1024` och 2 bildrutor har verifierats fungera för vanliga Flare, men denna slutsats kan inte utvidgas till alla 1K-kombinationer eller 4K-GIF.
