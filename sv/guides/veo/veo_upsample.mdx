Denna artikel kommer att introducera Veo Upsample API:s integrationsanvisningar. Detta gränssnitt används för att uppsample en redan genererad Veo-video eller för att producera en GIF-förhandsvisning.

## Ansökningsprocess

För att använda API:t måste du först gå till den motsvarande sidan för Veo-tjänsten och ansöka. Om du inte är inloggad eller registrerad kommer du automatiskt att omdirigeras till inloggningssidan.

## Grundläggande användning

För att anropa detta gränssnitt krävs två parametrar:

- `video_id`: ID för uppgiftsvideon. Det kan vara video-ID från valfritt av följande gränssnitt: `/veo/videos`, `/veo/extend`, `/veo/reshoot`, `/veo/objects`.
- `action`: Uppsamplingåtgärd, stöder följande tre alternativ:
  - `1080p`: Uppsample videon till 1080p-upplösning.
  - `4k`: Uppsample videon till 4K-upplösning.
  - `gif`: Konvertera videon till en GIF-förhandsvisning.

Exempel på begäran:

```shell
curl -X POST 'https://api.acedata.cloud/veo/upsample' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "4k"
  }'
```

Returresultatet är detsamma som för `/veo/videos`, det är fortfarande en asynkron uppgiftsstruktur, och du kan kontrollera uppgiftsstatus via `task_id` i `/veo/tasks`-gränssnittet:

```json
{
  "success": true,
  "task_id": "8f5a90ae-3f86-4c4f-86f7-7126f5e92c76",
  "trace_id": "0f3e09c2-4c2e-46ea-9cdc-a31ec48b7c12",
  "data": [
    {
      "id": "253eedc47f1c4eb2a370ed2312168f4b",
      "video_url": "https://platform.cdn.acedata.cloud/veo/8f5a90ae.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

Förklaring av returfält:

- `success`: Om uppsamplinguppgiften har skickats framgångsrikt.
- `task_id`: ID för denna uppsamplinguppgift.
- `data`: Resultatet av den uppsamplede videon.
  - `video_url`: Adressen till den uppsamplede videon.

## Avgiftsbeskrivning

- `action=1080p`: 0.16 Credit / gång
- `action=4k`: 0.50 Credit / gång
- `action=gif`: 0.13 Credit / gång

Om den angivna `action` inte finns i ovanstående enumeration kommer den att debiteras som 0.50 Credit som standard. Det rekommenderas att uttryckligen ange stödda värden.

## Asynkron återkoppling

Gränssnittet stöder också asynkron läge, ange `callback_url` för att få resultatet via POST-begäran efter att uppgiften har slutförts. Om det inte finns någon offentlig återkopplingsadress kan du också ställa in `async` till `true`, gränssnittet kommer också omedelbart att returnera `task_id`, och du kan sedan använda motsvarande uppgiftsfrågegränssnitt för att pollera resultatet.
