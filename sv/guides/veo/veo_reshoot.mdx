Denna artikel kommer att introducera Veo Reshoot API:s integrationsbeskrivning. Detta gränssnitt används för att **återgenerera** en redan skapad Veo-video enligt **ett nytt kamerarörelsemönster**, där bildinnehållet förblir detsamma, men kamerans position och rörelse kommer att återskapas enligt `motion_type`.

## Ansökningsprocess

För att använda API:et måste du först ansöka på den motsvarande sidan för Veo-tjänsten. Om du inte är inloggad eller registrerad kommer du automatiskt att omdirigeras till inloggningssidan.

## Grundläggande användning

För att anropa detta gränssnitt krävs följande parametrar:

- `video_id` (obligatorisk): Uppgifts-ID för källvideon. **Kan inte** vara en utdata-video från `/veo/extend`.
- `motion_type` (obligatorisk): Det nya kamerarörelsemönstret, använd en förkortad alias i versaler med understreck.

### Stödda värden för `motion_type`

| Alias                             | Betydelse           |
| ------------------------------ | ------------ |
| `STATIONARY`                   | Kameran är stilla       |
| `STATIONARY_UP`                | Kameran är stilla, lutar uppåt    |
| `STATIONARY_DOWN`              | Kameran är stilla, lutar nedåt    |
| `STATIONARY_LEFT`              | Kameran är stilla, svänger vänster      |
| `STATIONARY_RIGHT`             | Kameran är stilla, svänger höger      |
| `STATIONARY_DOLLY_IN_ZOOM_OUT` | Kameran är stilla, trycker fram + zoomar ut |
| `STATIONARY_DOLLY_OUT_ZOOM_IN` | Kameran är stilla, backar + zoomar in |
| `UP`                           | Kameran stiger         |
| `DOWN`                         | Kameran sjunker         |
| `LEFT_TO_RIGHT`                | Kameran rör sig från vänster till höger     |
| `RIGHT_TO_LEFT`                | Kameran rör sig från höger till vänster     |
| `FORWARD`                      | Kameran rör sig framåt       |
| `BACKWARD`                     | Kameran rör sig bakåt        |
| `DOLLY_IN_ZOOM_OUT`            | Rör sig framåt + zoomar ut   |
| `DOLLY_OUT_ZOOM_IN`            | Rör sig bakåt + zoomar in   |

Exempel på begäran:

```shell
curl -X POST 'https://api.acedata.cloud/veo/reshoot' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "motion_type": "LEFT_TO_RIGHT"
  }'
```

Returresultatets struktur är densamma som för `/veo/videos`.

## Avgiftsbeskrivning

- Enstaka omtagning: 1.20 kredit.

## Asynkron återkoppling

Gränssnittet stöder asynkron läge, ange `callback_url` för att få resultatet via POST-begäran efter att uppgiften är slutförd. Om det inte finns någon offentlig återkopplingsadress kan du också ställa in `async` till `true`, gränssnittet returnerar omedelbart `task_id`, och du kan sedan använda motsvarande uppgiftsfrågegränssnitt för att pollera resultatet.
