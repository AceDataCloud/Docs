Denna artikel kommer att introducera Veo Extend API:s integrationsbeskrivning. Detta gränssnitt används för att **förlänga längden** på en redan genererad Veo-video, AI kommer automatiskt att fortsätta skriva efterföljande bilder.

## Ansökningsprocess

För att använda API:t måste du först ansöka på den motsvarande sidan för Veo-tjänsten. Om du inte har loggat in eller registrerat dig kommer du automatiskt att omdirigeras till inloggningssidan.

## Grundläggande användning

För att anropa detta gränssnitt krävs följande parametrar:

- `video_id` (obligatorisk): ID för uppgiften av källvideon (från `/veo/videos` eller detta gränssnitt).
- `model` (obligatorisk): Modellen som används för förlängning, **endast `veo31-fast` och `veo31` stöds**, andra modeller stöds inte av upstream.
- `prompt` (valfri): Textledtråd för att styra de förlängda segmentens bilder.
- `aspect_ratio` (valfri): `16:9` eller `9:16`, standard `16:9`.
- `resolution` (valfri): `720p` eller `1080p`.

Exempel på begäran:

```shell
curl -X POST 'https://api.acedata.cloud/veo/extend' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "model": "veo31-fast",
    "prompt": "kameran zoomar långsamt ut för att avslöja mer av landskapet"
  }'
```

Returresultatet är detsamma som för `/veo/videos`:

```json
{
  "success": true,
  "task_id": "5fa2d9a6-7e54-481b-a4b0-3dc6f25dd2ab",
  "data": [
    {
      "id": "9b6f3b6b9c45419fbf2e3fe2f10b2b3a",
      "video_url": "https://platform.cdn.acedata.cloud/veo/5fa2d9a6.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

## Viktiga begränsningar

`video_id` måste komma från TTAPI-linjen som genererades eller förlängdes efter `data[].id`. Historiska video-ID:n som genererades av den gamla linjen innan bytet till TTAPI kan inte användas med detta gränssnitt, anropet kommer att returnera `400 bad_request`; vänligen regenerera via `/veo/videos` innan du förlänger.

Videor som förlängs från `/veo/extend` kan **fortsätta att förlängas med `/veo/extend` igen**, men **kan inte** behandlas av följande gränssnitt:

- `/veo/reshoot` —— kan inte byta kamerarörelse
- `/veo/objects` —— kan inte göra fler objektläggningar eller borttagningar

Om det angivna `video_id` är ett förlängningsresultat kommer relaterade gränssnitt att returnera 400-fel, vänligen använd den ursprungliga videon som källa.

## Avgiftsbeskrivning

- `model=veo31-fast`: 1.68 Credit / gång
- `model=veo31`: 12.00 Credit / gång

## Asynkron återkoppling

Gränssnittet stöder asynkron läge, ange `callback_url` för att få resultatet via POST-begäran när uppgiften är klar. Om det inte finns någon offentlig återkopplingsadress kan du också ställa in `async` till `true`, gränssnittet returnerar omedelbart `task_id`, och du kan sedan använda motsvarande uppgiftsfrågegränssnitt för att pollera resultatet.
