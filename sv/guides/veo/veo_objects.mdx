Denna artikel kommer att introducera integrationsbeskrivningen för Veo Objects API. Detta gränssnitt används för att utföra **tillägg eller borttagning av objekt** på en redan genererad Veo-video (baserat på maskbaserad lokal omritning).

## Ansökningsprocess

För att använda API:et måste du först ansöka på den motsvarande sidan för Veo-tjänsten. Om du inte är inloggad eller registrerad kommer du automatiskt att omdirigeras till inloggningssidan.

## Grundläggande användning

För att anropa detta gränssnitt krävs följande parametrar:

- `video_id` (obligatorisk): ID för uppgiften av källvideon. **Kan inte** vara en utdata-video från `/veo/extend`.
- `action` (obligatorisk): Typ av åtgärd, `insert` eller `remove`.
- `prompt`:
  - `action=insert`: **Obligatorisk**, beskriv objektet som ska läggas till.
  - `action=remove`: valfri, beskriv innehållet som ska tas bort (används främst för loggning, det faktiska borttagningsområdet bestäms av `image_mask`).
- `image_mask`:
  - `action=insert`: valfri. Om den inte anges kommer AI automatiskt att bestämma inläggningsposition; om den anges, kommer den att infogas i de vita pixelområdena.
  - `action=remove`: **Obligatorisk**, de vita pixelområdena är objekten som ska tas bort.

`image_mask` accepterar två format:

1. En **offentligt tillgänglig HTTP(S) bildadress** (rekommenderas).
2. **base64-kodad JPEG-sträng**, kan ha prefixet `data:image/jpeg;base64,` eller vara ren base64.

Exempel på begäran (infoga objekt, utan att ange mask, låt AI automatiskt lokalisera):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "insert",
    "prompt": "add a flying pig with black wings"
  }'
```

Exempel på begäran (ta bort objekt enligt mask):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "remove",
    "image_mask": "https://example.com/mask.jpg",
    "prompt": "remove the white cloud"
  }'
```

Returresultatets struktur är densamma som för `/veo/videos`.

## Avgiftsbeskrivning

- `action=insert` eller `remove`: 1.50 Credit / gång.

## Asynkron återkoppling

Gränssnittet stöder asynkron läge, ange `callback_url` för att få resultatet via POST-begäran efter att uppgiften är slutförd. Om det inte finns någon offentlig återkopplingsadress kan du också ställa in `async` till `true`, gränssnittet kommer också omedelbart att returnera `task_id`, och du kan sedan använda motsvarande uppgiftsfrågegränssnitt för att pollera resultatet.
