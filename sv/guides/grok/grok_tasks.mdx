Grok Tasks API:s huvudfunktion är att genom att ange det uppdrag ID som genererats av Grok Videos Generation API för att kontrollera statusen för det uppdraget.

Detta dokument kommer att ge en detaljerad beskrivning av Grok Tasks API:s integrationsanvisningar, vilket hjälper dig att enkelt integrera och kontrollera statusen för uppdrag som skapats av Grok Videos Generation API.

## Ansökningsprocess

För att använda Grok Videos Generation API, börja med att gå till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API-token, som du kan spara för framtida bruk.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Om du inte har loggat in eller registrerat dig kommer du automatiskt att omdirigeras till inloggningssidan som bjuder in dig att registrera dig och logga in, och efter att ha slutfört detta kommer du automatiskt att återvända till den aktuella sidan.

**En API-token räcker för att anropa alla tjänster på plattformen, det behövs ingen separat ansökan för varje tjänst.** Vid första ansökan får du en gratis kvot för att prova; när kvoten är slut kan du ladda på allmän balans i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Grok Videos Generation API →](https://platform.acedata.cloud/documents/grok-videos)

## Begärningsexempel

Grok Tasks API kan användas för att kontrollera resultaten från Grok Videos Generation API.

### Ställ in begärningshuvuden och begärningskropp

**Begärningshuvuden** inkluderar:

- `accept`: anger att du tar emot svar i JSON-format, här anges `application/json`.
- `authorization`: nyckeln för att anropa API:t, som kan väljas direkt efter ansökan.

**Begärningskropp** inkluderar:

- `id`: det uppdrag ID som ska kontrolleras.
- `action`: åtgärden för uppdraget, för enskild kontroll anges `retrieve`.

### CURL kodexempel

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Svarsexempel

Vid en lyckad begäran kommer API:t att returnera detaljerad information om detta uppdrag. Där `request`-fältet är begärningskroppen vid uppdragets start, och `response`-fältet är svaret som returneras efter att uppdraget har slutförts, till exempel:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262729.623,
  "elapsed": 7.8,
  "request": {
    "prompt": "En filmisk bild av en kattunge som jagar en fjäril i en solbelyst trädgård",
    "model": "grok-imagine-video-1.5-fast:reverse",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video-1.5-fast:reverse:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Fälten beskrivs nedan:

- `id`: ID för det genererade uppdraget, används för att unikt identifiera detta genererade uppdrag.
- `request`: begärningsinformation i uppdraget.
- `response`: returinformation i uppdraget.
- `created_at`: tidpunkten då uppdraget skapades, Unix-tidsstämpel (sekunder, flyttal).
- `started_at`: tidpunkten då uppdraget började utföras, Unix-tidsstämpel (sekunder, flyttal).
- `finished_at`: tidpunkten då uppdraget slutfördes, Unix-tidsstämpel (sekunder, flyttal). Detta fält returneras inte om uppdraget inte är slutfört.
- `elapsed`: tiden som uppdraget tog, i sekunder (flyttal, med 3 decimaler). Detta fält returneras inte om uppdraget inte är slutfört.

## Batchfrågeoperationer

För att kontrollera detaljer för flera uppdrag ID, ställ in `action` till `retrieve_batch`, och skicka in uppdrag ID-arrayen via `ids`:

**Begärningskropp** inkluderar:

- `ids`: array av uppdrag ID som ska kontrolleras.
- `action`: åtgärden för uppdraget, för batchfrågor anges `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
