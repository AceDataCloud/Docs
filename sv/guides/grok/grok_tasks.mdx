Grok Tasks API:s huvudsakliga funktion är att genom att ange uppgifts-ID:t som genererats av Grok Videos Generation API, kunna fråga om uppgiftens utförande.

Detta dokument kommer att ge en detaljerad beskrivning av Grok Tasks API:s integration, för att hjälpa dig att enkelt integrera och fråga om Grok Videos Generation API:s uppgiftsutförande.

## Ansökningsprocess

För att använda Grok Videos Generation API, börja med att gå till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API-token, som du kan spara för framtida bruk.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Om du inte har loggat in eller registrerat dig, kommer du automatiskt att omdirigeras till inloggningssidan som bjuder in dig att registrera dig och logga in, och efter att ha slutfört detta kommer du automatiskt att återvända till den aktuella sidan.

**En API-token räcker för att anropa alla tjänster på plattformen, det behövs ingen separat ansökan för varje tjänst.** Vid första ansökan får du en gratis kvot för att prova på; när kvoten är slut kan du ladda på allmän balans i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Grok Videos Generation API →](https://platform.acedata.cloud/documents/grok-videos)

## Begärningsexempel

Grok Tasks API kan användas för att fråga om resultaten från Grok Videos Generation API.

### Ställ in begärningshuvuden och begärningskropp

**Begärningshuvuden** inkluderar:

- `accept`: anger att du vill ta emot svar i JSON-format, här anges `application/json`.
- `authorization`: nyckeln för att anropa API:t, som kan väljas direkt efter ansökan.

**Begärningskropp** inkluderar:

- `id`: uppgifts-ID:t som ska frågas.
- `action`: hur uppgiften ska hanteras, för enskild fråga anges `retrieve`.

### CURL kodexempel

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Svarsexempel

Vid en lyckad begäran kommer API:t att returnera detaljerad information om uppgiften här. Där `request`-fältet är begärningskroppen vid uppgiftsstart och `response`-fältet är svaret som returneras efter att uppgiften har slutförts, till exempel:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "En filmisk bild av en kattunge som jagar en fjäril i en solbelyst trädgård",
    "model": "grok-imagine-video-1.5-fast:reverse",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video-1.5-fast:reverse:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Fälten beskrivs nedan:

- `id`: ID:t för den genererade uppgiften, som används för att unikt identifiera denna genererade uppgift.
- `request`: begärningsinformationen i uppgiften.
- `response`: returinformationen i uppgiften.

## Batchfrågeoperationer

För att fråga om detaljer för flera uppgifts-ID:n, ställ in `action` till `retrieve_batch`, och skicka in en array av uppgifts-ID:n via `ids`:

**Begärningskropp** inkluderar:

- `ids`: array av uppgifts-ID:n som ska frågas.
- `action`: hur uppgiften ska hanteras, för batchfrågor anges `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
