Grok Tasks API:s huvudsakliga funktion är att genom att ange task ID som genererats av Grok Videos Generation API, kunna kontrollera statusen för den aktuella uppgiften.

Denna dokumentation ger en detaljerad beskrivning av hur man integrerar Grok Tasks API, för att enkelt kunna koppla samman och kontrollera statusen för uppgifter i Grok Videos Generation API.

## Ansökningsprocess

För att använda Grok Tasks API måste du först ansöka om tjänsten på sidan [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos) och kopiera det task ID som returneras av Grok Videos Generation API.

Sedan går du till sidan [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) för att ansöka om motsvarande tjänst. När du är på sidan klickar du på knappen „Acquire“.

Om du inte är inloggad eller inte har registrerat dig, omdirigeras du automatiskt till [Inloggningssidan](https://platform.acedata.cloud) där du kan registrera dig och logga in. Efter inloggning återvänder du automatiskt till den aktuella sidan.

Vid första ansökan tilldelas du en gratis kvot, så att du kan använda API:t kostnadsfritt.

## Exempel på förfrågan

Grok Tasks API kan användas för att kontrollera resultaten av Grok Videos Generation API.

### Konfigurera request headers och body

**Request Headers** inkluderar:

- `accept`: Anger att du vill ha ett JSON-svar, här sätts till `application/json`.
- `authorization`: API-nyckeln för att autentisera anropet, kan väljas från en dropdown efter ansökan.

**Request Body** inkluderar:

- `id`: Det task ID du vill kontrollera.
- `action`: Hur du vill hantera uppgiften, för en enskild förfrågan sätts detta till `retrieve`.

### CURL-exempel

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Exempel på svar

Vid lyckad förfrågan returnerar API:t detaljerad information om uppgiften. `request`-fältet visar den ursprungliga request body, medan `response`-fältet visar resultatet efter att uppgiften är slutförd, exempelvis:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/grok/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Fälten förklaras nedan:

- `id`: Det unika ID:t för genereringsuppgiften.
- `request`: Den ursprungliga förfrågan som skickades.
- `response`: Resultatet av förfrågan.

## Batch-uppdatering av förfrågningar

För att kontrollera flera task ID:n samtidigt, sätt `action` till `retrieve_batch` och skicka en lista med ID:n via `ids`.

**Request Body**:

- `ids`: En array av task ID:n.
- `action`: För batch-uppdatering sätts detta till `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
