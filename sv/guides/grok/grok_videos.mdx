Denna artikel beskriver integrationsbeskrivningen för Grok Videos Generation API, som kan generera Grok Imagine (xAI) videor genom att mata in textprompt, inmatningsbild och valfria referensbilder.

## Ansökningsprocess

För att använda API:et måste du först ansöka om motsvarande tjänst på [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos). När du går in på sidan klickar du på knappen "Acquire", som visas nedan:

![](https://cdn.acedata.cloud/q6ytrc.png)

Om du inte är inloggad eller registrerad omdirigeras du automatiskt till inloggningssidan för att registrera och logga in. Efter inloggning eller registrering återvänder du automatiskt till den aktuella sidan.

Vid första ansökan får du en gratis kvot som gör att du kan använda API:et kostnadsfritt.

## Modellbeskrivning

Detta API stöder två modeller:

- `grok-imagine-video-1.5-fast` (standard): Stöder text-till-video (endast `prompt`) och bild-till-video (med `image_url`), till en lägre kostnad.
- `grok-imagine-video-1.5`: Stöder endast bild-till-video, **måste** ange `image_url`.

## Grundläggande användning

Först lär vi oss den grundläggande användningen, där du matar in prompt `prompt`, modell `model` och andra parametrar för att generera motsvarande video.

Här har vi satt Request Headers, inklusive:

- `accept`: vilket format svaret ska ha, här `application/json` för JSON-format.
- `authorization`: API-nyckeln för att anropa API:et, kan väljas direkt efter ansökan.

Dessutom har vi satt Request Body, inklusive:

- `prompt`: textprompt som beskriver innehållet i videon som ska genereras. Obligatoriskt för text-till-video med `grok-imagine-video-1.5-fast`; valfritt när `image_url` anges.
- `model`: modellen som genererar videon, kan vara `grok-imagine-video-1.5-fast` (standard) eller `grok-imagine-video-1.5`.
- `image_url`: URL till inmatningsbild för bild-till-video. Obligatoriskt när `model` är `grok-imagine-video-1.5`.
- `reference_image_urls`: valfri lista med URL:er till referensbilder för att styra videons stil eller innehåll.
- `aspect_ratio`: bildförhållande för videon, val mellan `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`.
- `resolution`: utdataupplösning, val mellan `480p` (standard) eller `720p`. Högre upplösning förbrukar mer kvot.
- `duration`: videons längd i sekunder, mellan 1–15, standard 8. Kostnad baseras på utdata i sekunder.
- `callback_url`: URL för asynkron callback. Om satt returnerar API omedelbart `task_id` och postar resultatet till denna URL när uppgiften är klar.

Klicka på knappen "Try" för att testa, resultatet ser ut ungefär så här:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video-1.5-fast:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
      "state": "succeeded"
    }
  ]
}
```

Svarsfälten är:

- `success`: om videogenereringsförfrågan lyckades.
- `task_id`: ID för videogenereringsuppgiften.
- `trace_id`: spårnings-ID för förfrågan, används för felsökning.
- `data`: lista med genererade videor.
  - `id`: unik identifierare för den genererade videon.
  - `video_url`: URL till den genererade videon.
  - `state`: status för videogenereringsuppgiften, kan vara `pending` / `succeeded` / `failed`.

Vi behöver bara använda `video_url` i `data` för att hämta den genererade videon.

Motsvarande CURL-kod:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "resolution": "480p",
  "duration": 8
}'
```

Motsvarande Python-kod:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video-1.5-fast",
    "resolution": "480p",
    "duration": 8
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Bild-till-video

Om du vill generera video baserat på en inmatningsbild kan du ange `image_url`. Vid användning av `grok-imagine-video-1.5` är detta obligatoriskt:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5",
  "image_url": "https://cdn.acedata.cloud/5hmkdg.jpg",
  "resolution": "720p",
  "duration": 8
}
```

## Referensbildsstyrning

Om du vill styra videons stil eller innehåll med en eller flera referensbilder kan du ange en lista med bild-URL:er i `reference_image_urls`:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video-1.5-fast",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/vunnjf.png"
  ]
}
```

## Asynkron callback

Videogenerering tar viss tid. Om du inte vill hålla en lång anslutning öppen kan du ange `callback_url`. API:et returnerar då omedelbart `task_id` och postar slutresultatet till denna URL när uppgiften är klar:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "duration": 8,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

Omedelbart svar:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Fråga uppgiftsresultat

Om du använder asynkron callback eller vill aktivt kontrollera uppgiftsstatus kan du via [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) fråga efter aktuell status och resultat med `task_id`.

## Prissättning

Tjänsten debiteras baserat på videons "utdata i sekunder", där priset bestäms av `model` och `resolution`. Totalpris = pris per sekund × `duration` (standard 8 sekunder). `720p` kostar mer än `480p`, och `grok-imagine-video-1.5` kostar mer än `grok-imagine-video-1.5-fast`. Exakta priser finns på prissättningssidan.

## Felhantering

Vid problem returnerar API:et motsvarande felkod och beskrivning. Vanliga fel:

- `400`: fel i förfrågningsparametrar, t.ex. saknad `prompt` för text-till-video, saknad `image_url` för `grok-imagine-video-1.5`, eller `duration` utanför 1–15.
- `401`: autentisering misslyckades, ogiltig token eller token matchar inte API.
- `403`: otillräckligt saldo eller prompten avvisades vid innehållsgranskning.
- `429`: för många förfrågningar, upstream rate limiting, försök igen senare.
- `500`: serverfel eller upstream genereringsfel.
