title: "Wan uppgiftssökning API"
description: "Wan API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/wan/tasks` används för att söka, göra batchsökningar eller ta bort Wan videouppgifter. Uppgiftssökning debiterar inte genereringskostnader.

## Sök enskild uppgift

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Den fullbordade uppgiftens `response.data.video_url` är en permanent CDN-adress; `response.usage` innehåller upplösning, in-/utgångsvideosekunder, bildfrekvens och förhållande; `response.cost` är kostnaden för genereringsuppgiften.

## Batchsökning

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Returnerar `{ "items": [...], "count": 2 }`. När uppgiften pågår kan det hända att `finished_at` och slutgiltig `response` ännu inte finns.

## Ta bort uppgiftsregister

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

Att ta bort påverkar endast uppgiftens historik, det kommer inte att ta bort redan genererade CDN-videor.
