`POST https://api.acedata.cloud/wan/videos` stöder samtidigt befintliga Wan 2.6-modeller och `wan3.0-video`. Wan 3 identifierar automatiskt text-, första och sista bildruta- eller referensmaterialläge baserat på `media`.

## Wan 3 text-till-video

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "A paper boat drifting through a neon city at night",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 stöder heltal på 2–30 sekunder eller `-1` för intelligent längd, med upplösningarna `480P`, `720P`, `1080P`.

## Multimediereferenser

```json
{
  "model": "wan3.0-video",
  "prompt": "Create a cinematic product reveal",
  "media": [
    {"type":"first_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"},
    {"type":"last_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460-a2a2c1afbf39.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` stöder:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

Läget för första och sista bildruta och läget för referensmaterial kan inte användas tillsammans. Referensvideor debiteras slutligen utifrån det faktiska antalet sekunder i den inmatade videon plus antalet sekunder i den framgångsrikt genererade utdatavideon; text-, bild- och ljudinmatning ökar inte antalet videosekunder.

| 720P  | $0.10/sekund |
| 1080P | $0.20/sekund |

## Wan 2.6-kompatibilitet

Befintliga `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` och flash-varianter fortsätter att använda parametrar som `action`, `image_url`, `reference_video_urls`, och anropsvägen förblir oförändrad.

## Asynkronitet och resultat

Efter att `async: true` har angetts erhålls `task_id` omedelbart, och slutstatus hämtas via `/wan/tasks`. Framgångsrika videor överförs till AceDataCloud CDN, och faktisk usage och cost returneras i svaret.
