title: "Wan video generation API"

`POST https://api.acedata.cloud/wan/videos` stöder både den befintliga Wan 2.6-modellen och `wan3.0-video`. Wan 3 identifierar automatiskt text, första och sista bildruta eller referensmaterialmönster baserat på `media`.

## Wan 3 text till video

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "En pappersbåt som driver genom en neonsk city på natten",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 stöder heltal mellan 2–30 sekunder eller `-1` för intelligent längd, med upplösning på `480P`, `720P`, `1080P`.

## Multimedia referens

```json
{
  "model": "wan3.0-video",
  "prompt": "Skapa en filmisk produktavslöjande",
  "media": [
    {"type":"first_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"},
    {"type":"last_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` stöder:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

Första och sista bildruta-mönster samt referensmaterialmönster kan inte blandas. Referensvideoer räknas slutligen baserat på den verkliga inmatade videons sekunder plus de framgångsrika utgångsvideons sekunder; text, bilder och ljudinmatningar ökar inte videons sekunder.

## Officiella standardpriser

| Upplösning |      Pris |
| ----- | ------: |
| 480P  | $0.05/sek |
| 720P  | $0.10/sek |
| 1080P | $0.20/sek |

## Wan 2.6 kompatibilitet

Befintliga `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` och flashvarianter fortsätter att använda parametrar som `action`, `image_url`, `reference_video_urls`, med oförändrad anropsväg.

## Asynkron och resultat

Genom att ställa in `async: true` får du omedelbart `task_id`, och kan hämta slutstatus via `/wan/tasks`. Framgångsrika videor kommer att lagras på AceDataCloud CDN och verklig användning och kostnad returneras i svaret.
