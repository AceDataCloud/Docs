Detta dokument beskriver huvudsakligen användningsflödet för ADSL Proxy API, med hjälp av det kan vi enkelt extrahera ADSL:s IP och lägga till IP-whitelist för ADSL Proxy.

## Ansökningsflöde

För att använda extraheringen av ADSL:s IP och lägga till IP-whitelist för ADSL Proxy, kan du först gå till [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/d8426c17-d22c-449a-b6bf-0a7790928e4d) och [ADSL Proxy Whitelist API](https://platform.acedata.cloud/documents/c21534fe-1f62-424b-9b10-a805cb473dd1) sidorna och klicka på "Acquire"-knappen för att få de nödvändiga autentiseringsuppgifterna:

![](https://cdn.acedata.cloud/nyq0xz.png)

Om du inte har loggat in eller registrerat dig, kommer du automatiskt att omdirigeras till inloggningssidan där du bjuds in att registrera dig och logga in. Efter inloggning eller registrering kommer du automatiskt att återvända till den aktuella sidan.

Vid första ansökan kommer det att finnas en gratis kvot som ges, så att du kan använda API:t gratis.

## Extrahera ADSL:s IP

Därefter kan du fylla i motsvarande innehåll på sidan [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/d8426c17-d22c-449a-b6bf-0a7790928e4d), här visas hur man extraherar ADSL:s IP.

### Ställ in begärningshuvuden och begärningskropp

**Request Headers** inkluderar:

- `accept`: anger att du tar emot svar i JSON-format, här fylls det i som `application/json`.
- `authorization`: nyckeln för att anropa API:t, efter ansökan kan du direkt välja från rullgardinsmenyn.

**Request Body** inkluderar:

- `number`: antalet ADSL:s IP som ska extraheras, standard är 1.
- `type`: typen av ADSL:s IP som ska extraheras, huvudsakligen uppdelad i `http` och `socks`, standard är `http`.
- `province`: provinsen där IP:t extraheras, standard är slumpmässig.
- `city`: staden där IP:t extraheras, standard är slumpmässig.

För inställningen av parametrarna `province` och `city` finns det krav, de måste motsvara varandra, till exempel `city`: Nanchang måste motsvara `province`: Jiangxi, de måste kopplas ihop med provinsen, de specifika reglerna är som följer:

```python
import requests
```

När begäran lyckas kommer API:et att returnera information om resultatet av ansiktsbyte-bild. Till exempel:

```json
{
  "success": true,
  "data": [
    {
      "ip": "115.219.4.171",
      "port": 23456,
      "proxy": "115.219.4.171:23456",
      "outbound_ip": "115.219.4.171",
      "provins": "浙江",
      "stad": "温州",
      "expire_at": 1721877364.588,
      "dialed_at": 1721876984.588

  "trace_id": "406465b0-f086-4a12-87a7-cdf05a3930a1"
```

Det kan ses att resultatet innehåller ett `data`-fält, som innehåller detaljer om denna IP-uppgift, och annan information visas i bilden nedan:

- `success` - resultatstatus för denna ADSL IP-uppgift.
- `data` - detaljerad information om den extraherade ADSL IP:n.

Från `data` kan man tydligt se detaljerad information om denna IP, där `ip` representerar den IP-adress som extraherades, och annan information är som följer:

- `ip` - den extraherade ADSL IP-adressen.
- `port` - portinformationen för den extraherade ADSL IP:n.
- `proxy` - den fullständiga informationen om den extraherade ADSL IP-proxyn.
- `provins` - provinsen där den extraherade ADSL IP:n finns.
- `stad` - staden där den extraherade ADSL IP:n finns.

Det kan ses att vi enkelt kan använda ovanstående `proxy` för att utföra nästa steg i IP-proxyarbetet.

Först, innan vi använder IP-proxyn, behöver vi lägga till vår egen nätverks IP-adress (metod för att få lokal nätverks IP, vänligen sök själv) i den vita listan nedan, och vi kommer att förklara hur IP-proxyn används:

### Använda proxy

> Observera: Innan du använder den extraherade proxy-IP:n, se till att lägga till IP i den vita listan, annars kan den inte användas. För information om hur man lägger till den vita listan, se innehållet nedan.

Curl exempel kod:

```shell
curl -x 115.219.4.171:23456 myip.vpsnb.net # http proxy
curl --socks5 115.219.3.54:23457 myip.vpsnb.net # socks proxy
```

Python exempel proxy:

```python
import requests
import socks
import socket
import time

def test_http_proxy(proxy):
    try:
        start_time = time.time()
        response = requests.get(
            'http://httpbin.org/ip', proxies={'http': proxy, 'https': proxy}, timeout=100)
        elapsed_time = time.time() - start_time
        print(response)
        if response.status_code == 200:
            print(f"HTTP Proxy {proxy} success. time: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"HTTP Proxy {proxy} failed. code: {response.status_code}")
    except Exception as e:
        print(f"HTTP Proxy {proxy} failed: {str(e)}")

def test_socks_proxy(proxy):
    proxy_parts = proxy.split(':')
    if len(proxy_parts) != 2:
        print(f"SOCKS failed: {proxy}")
        return

    host, port = proxy_parts
    port = int(port)

    try:
        start_time = time.time()
        socks.set_default_proxy(socks.SOCKS5, host, port)
        socket.socket = socks.socksocket
        response = requests.get('http://httpbin.org/ip', timeout=10)
        elapsed_time = time.time() - start_time

        if response.status_code == 200:
            print(f"SOCKS Proxy {proxy} success. time: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"SOCKS Proxy {proxy} failed. code: {response.status_code}")
    except Exception as e:
        print(f"SOCKS Proxy {proxy} failed: {str(e)}")
    finally:
        socks.set_default_proxy()
        socket.socket = socket.socket

if __name__ == "__main__":
    # HTTP Proxy
    http_proxy = "http://115.219.4.171:23456"
    test_http_proxy(http_proxy)

    # SOCKS Proxy
    socks_proxy = "115.219.3.54:23457"
    test_socks_proxy(socks_proxy)

```

## Lägg till IP vitlista

Nästa steg är att fylla i motsvarande innehåll på gränssnittet, som visas i bilden:

<p><img src="https://cdn.acedata.cloud/wz4obo.png" width="500" class="m-auto"></p>

Vid första användningen av detta gränssnitt behöver vi fylla i minst tre uppgifter, en är `authorization`, som vi direkt väljer från rullgardinslistan. Den andra parametern är `ip`, `ip` är den lokala nätverksadressen för den IP-proxy som vi har extraherat ovan. Den sista parametern är `action`, `action` är den åtgärd vi utför på vitlistan, här är det en åtgärd för att lägga till i vitlistan.

Samtidigt kan du notera att det finns motsvarande anropskod som genereras till höger, du kan kopiera koden för att köra den direkt, eller så kan du klicka på "Try" knappen för att testa.

<p><img src="https://cdn.acedata.cloud/cs5ib2.png" width="500" class="m-auto"></p>

Python exempel på anropskod:

```python
import requests

url = "https://api.acedata.cloud/adsl/whitelist"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "ip": "113.112.122.132",
    "action": "add"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Efter anropet upptäckte vi att returresultatet ser ut som följer:

```json
{
  "success": true
}
```

Returresultatet har ett fält, som beskrivs nedan:

- `success `, status för denna åtgärd.

Där `success` innehåller status för åtgärden, vi kan se att IP `113.112.122.132` har lagts till i vitlistan framgångsrikt.

## Felhantering

Vid anrop av API:et, om ett fel uppstår, kommer API:et att returnera motsvarande felkod och information. Till exempel:

- `400 token_mismatched`：Felaktig begäran, möjligtvis på grund av saknade eller ogiltiga parametrar.
- `400 api_not_implemented`：Felaktig begäran, möjligtvis på grund av saknade eller ogiltiga parametrar.
- `401 invalid_token`：Obehörig, ogiltig eller saknad auktoriseringstoken.
- `429 too_many_requests`：För många begärningar, du har överskridit hastighetsgränsen.
- `500 api_error`：Intern serverfel, något gick fel på servern.
