I takt med att AI används allt mer har olika AI-program gradvis blivit vanliga. AI har successivt fördjupats i alla aspekter av människors arbetsliv och vardag. Branscherna som AI omfattar blir också fler och fler, från det ursprungliga skrivandet till sjukvård och utbildning, och nu till video.

Luma är en professionell plattform för högkvalitativ videogenerering. Användare behöver bara ladda upp material för att automatiskt generera högkvalitativa videor enligt olika stilar och effekter. Denna AI-videogenerator har utvecklats av teammedlemmar från välkända teknikföretag, med målet att låta alla enkelt skapa enastående videor utan komplexa redigeringsverktyg.

Luma erbjuder dock inte officiellt något API. AceDataCloud erbjuder en uppsättning API:er för Luma som simulerar integration med Suno officiellt, vilket gör det möjligt att enkelt och snabbt generera önskade videor.

## Ansökan och användning

För att använda Luma Videos Generation API ska du först hämta din API-token i [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) och spara den för senare användning.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig omdirigeras du automatiskt till inloggningssidan för att registrera och logga in, och när det är klart återgår du automatiskt till den aktuella sidan.

**En API-token kan anropa alla plattformens tjänster, utan att behöva ansöka separat för varje tjänst.** Vid första ansökan får du kostnadsfri kredit för att testa gratis; när krediten inte räcker till kan du fylla på det gemensamma saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Luma Videos Generation API →](https://platform.acedata.cloud/documents/luma-videos)

## Grundläggande användning

För vilken video du vill generera kan du ange valfri text, till exempel om jag vill generera en video om astronauter som färdas mellan rymden och en vulkan, kan jag ange `Astronauts shuttle from space to volcano`, som visas i bilden:

Den genererade koden är följande:

Huvudsakliga begärandeparametrar:

- `prompt`: Prompten för att generera video.
- `aspect_ratio`: Videons bildförhållande, standard är 16:9.
- `end_image_url`: Valfritt, anger slutbildrutan.
- `enhancement`: Valfritt, omkopplare för skärpeförbättring.
- `loop`: Om en loopande video ska genereras, standard är false.
- `timeout`: Valfritt, antal sekunder för timeout.
- `callback_url`: Asynkron callback-adress.
- `async`: Valfritt, när det sätts till `true` returnerar gränssnittet omedelbart `task_id`, utan att `callback_url` behöver anges, och resultatet hämtas sedan genom polling via motsvarande gränssnitt för uppgiftsfrågor.

Fältbeskrivningarna är följande:

- success: Om genereringen lyckades, `true` om den lyckades, annars `false`

- video_url: Länken till resultatvideon för videogenereringsuppgiften här
- video_height: Höjden på den genererade videons omslagsbild
- video_width: Bredden på den genererade videons omslagsbild
- state: Statusen för videogenereringsuppgiften här, `completed` om uppgiften är klar.
- thumbnail_url: Länken till den genererade videons omslagsbild
- thumbnail_width: Bredden på den genererade videons omslagsbild
- thumbnail_height: Höjden på den genererade videons omslagsbild

## Anpassad generering med start- och slutbildruta

Om du vill generera en video genom att anpassa videons start- och slutbildruta kan du ange bildlänkarna för start- och slutbildrutorna:

Vid denna tidpunkt kan fältet `start_image_url` för videons startbildruta ta emot följande bild som videons startbildruta:

![Startbildruta](https://cdn.acedata.cloud/r9vsv9.png)

Därefter kan vi ange följande innehåll för att anpassa videogenerering baserat på start- och slutbildruta samt nyckelord:

- action: Beteendet för videogenereringsuppgiften, vanligtvis vanlig generering `generate` och utökad generering `extend`, standard är `generate`.
- start_image_url: Anger startbildrutan för den genererade videon.
- end_image_url: Anger slutbildrutan för den genererade videon.
- prompt: Nyckelordsinnehållet för att generera video.

Exempel på ifyllnad är följande:

<p><img src="https://cdn.acedata.cloud/zvzydx.png" width="500" className="m-auto" /></p>

När ifyllningen är klar genereras följande kod automatiskt:

<p><img src="https://cdn.acedata.cloud/tx80pu.png" width="500" className="m-auto" /></p>

Motsvarande kod:

```python
import requests

url = "https://api.acedata.cloud/luma/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "start_image_url": "https://cdn.acedata.cloud/r9vsv9.png",
    "action": "generate",
    "prompt": "Astronauts shuttle from space to volcano"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Det erhållna resultatet är följande:

## Videoutvidgningsfunktion

Om du vill fortsätta generera den skapade videon kan du ange parametern `action` till `extend` och ange ID:t eller videolänken för videon som behöver fortsätta genereras. Video-ID:t och videolänken hämtas enligt den grundläggande användningen, som visas i bilden nedan:

<p><img src="https://cdn.acedata.cloud/fwknj4.png" width="500" className="m-auto" /></p>

Vid denna tidpunkt kan du se att videons ID är:

```
"video_id": "0105c090-03a5-425a-8026-523341cd575b",
"video_url": "https://platform.cdn.acedata.cloud/luma/12a18694-fd4b-47e7-9c50-34f30862cff6.mp4"
```

> Observera att `video_id` och `video_url` i videon här är ID:t och videolänken för den genererade videon. Om du inte vet hur man genererar en video kan du läsa den grundläggande användningen ovan för att generera en video.

För att fortsätta generera en video måste du ladda upp videolänken eller videons ID. Nedan demonstreras hur man använder video-ID:t för utvidgning. Därefter måste vi fylla i nyckelord för att anpassa den genererade videon, och följande innehåll kan anges:

- action: Beteendet för att utvidga videon vid denna tidpunkt, vilket här ska vara `extend`.
- prompt: Nyckelord för videon som behöver utvidgas.
- video_url: Länken till videon som behöver utvidgas.
- video_id: Det unika ID:t för videon som behöver utvidgas.
- end_image_url: Bildlänken för den sista bildrutan som kan anges vid utvidgning av videon, valfri parameter.

## Asynkron återuppringning

Eftersom Luma tar relativt lång tid att generera videor, ungefär 1–2 minuter, kommer HTTP-begäran att fortsätta hålla anslutningen om API:t inte svarar under lång tid, vilket leder till ytterligare förbrukning av systemresurser. Därför tillhandahåller detta API även stöd för asynkron återuppringning.
Den övergripande processen är: när klienten initierar en begäran anges dessutom ett fält `callback_url`. Efter att klienten har initierat API-begäran returnerar API:et omedelbart ett resultat som innehåller fältet `task_id`, vilket representerar ID:t för den aktuella uppgiften. När uppgiften är slutförd skickas resultatet av den genererade musiken i form av POST JSON till den `callback_url` som klienten har angett, vilket också inkluderar fältet `task_id`, så att uppgiftsresultatet kan kopplas samman via ID:t.
