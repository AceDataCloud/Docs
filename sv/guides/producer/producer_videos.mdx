Producer tillåter oss att ladda ner videor relaterade till låtar, detta dokument förklarar hur man integrerar med den relaterade API:n.

Denna API har endast en inparametrar, nämligen `audio_id`, som är låtens unika ID.

Här är det `audio_id` vi anger: `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, vilket är ett Producer-genererat låt-ID.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Resultatet ser ut som följer:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4"
  }
}
```

Som vi kan se, är `data` fältet `video_url` länken till den nedladdade videon.
