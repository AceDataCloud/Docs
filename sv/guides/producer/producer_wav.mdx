Producer låter oss ladda ner WAV-filer relaterade till låtar, detta dokument förklarar integrationsmetoden för relaterade API:er.

Detta API har endast en indataparameter, nämligen `audio_id`, som är låtens unika ID.

Här är den `audio_id` vi matar in `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, vilket är ett låt-ID som genererats av Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/wav' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Resultatet är följande:

```
{
  "success": true,
  "task_id": "44963173-b6c5-463c-915f-96730d14ec63",
  "trace_id": "f75d6a27-54bc-49fd-a40e-6d4cd0427764",
  "data": [
    {
      "title": "Woke up with the sun in my eyes",
      "file_url": "https://cdn.acedata.cloud/assets/examples/fish/64adc04b-c196-4a0f-9070-222ba101ce6c-fc50de38c165.wav"
    }
  ]
}
```

Som du kan se är fältet `file_url` i `data` länken för nedladdning av WAV.
