Producer låter oss ladda upp referensljud för sekundär bearbetning. Detta dokument förklarar hur man integrerar relaterade API:er.

Detta API har endast en indataparameter, `audio_url`, som är en offentligt tillgänglig CDN-adress och stöder mp3-suffix.

Här är den `audio_url` vi matar in `https://cdn.acedata.cloud/suno_demo.mp3`, vilket är en offentligt tillgänglig CDN-adress.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Resultatet är som följer:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Soft female vocals, bright and cheerful]\n\n[Verse 1]\n阳光洒在海边\n浪花笑得灿烂\n你和我在沙滩\n钟表停止转\n冰淇淋在融化\n手牵手去散步\n风儿轻轻吹过\n心跳不停跳\n\n[Chorus]\n夏天夏天\n时间停在这一天\n笑声回荡\n蔚蓝天空在身旁",
    "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
  }
}
```

Som du kan se är fältet `audio_id` i `data` den uppladdade låtens ID.

När vi har låt-ID:t kan vi använda [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration) för att skapa anpassade låtar. Om exempelvis `action` skickas in som `upload_extend` och `audio_id` samtidigt skickas in med det returnerade låt-ID:t, kan en ny låt genereras baserat på referensljudet.
