Producer tillåter oss att ladda upp referensljud för vidare skapande, detta dokument förklarar hur man integrerar relaterade API:er.

Detta API har endast en inparametrar, nämligen `audio_url`, som är en offentligt tillgänglig CDN-adress som stöder mp3-förlängning.

Här är vår inmatade `audio_url` `https://cdn.acedata.cloud/suno_demo.mp3`, som är en offentligt tillgänglig CDN-adress.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Resultatet ser ut som följer:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Akustisk Pop]\n[Mjuka kvinnliga röster, ljus och glad]\n\n[Vers 1]\nSolen skiner vid havet\nVågorna ler strålande\nDu och jag på stranden\nKlockan stannar\nGlassen smälter\nHand i hand går vi på promenad\nVinden blåser lätt\nHjärtat slår oavbrutet\n\n[Refräng]\nSommar sommar\nTiden stannar denna dag\nSkratt ekar\nDen blå himlen vid sidan",
    "audio_url": "https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"
  }
}
```

Man kan se att `data` fältet `audio_id` är ID:t för låten efter uppladdningen.

Med låtens ID kan vi använda [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration) för att generera anpassade låtar, till exempel genom att skicka `action` som `upload_extend`, samtidigt som `audio_id` skickas som det returnerade låt-ID:t, så kan vi generera en ny låt baserat på referensljudet.
