Detta dokument beskriver integration och användning av Nano Banana Images API. Gränssnittet stöder två funktioner: **bildgenerering (generate)** och **bildredigering (edit)**.

## Ansökningsprocess

För att använda Nano Banana Images API ska du först hämta din API-token i [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) och spara den för senare användning.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte är inloggad eller registrerad omdirigeras du automatiskt till inloggningssidan för att registrera och logga in. När detta är klart återgår du automatiskt till den aktuella sidan.

**En API-token kan anropa alla plattformens tjänster, utan att behöva ansökas separat för varje tjänst.** Vid första ansökan får du kostnadsfri kvot för att prova tjänsten gratis; när kvoten inte räcker till kan du fylla på det gemensamma saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## Gränssnittsöversikt

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **Autentiseringsmetod**：Inkludera `authorization: Bearer {token}` i HTTP Header
- **Begärandehuvuden**：
  - `accept: application/json`
  - `content-type: application/json`
- **Åtgärd (action)**：
  - `generate`：Generera bilder utifrån textprompter
  - `edit`：Redigera utifrån angivna bilder
- **Modell (model)**（valfritt）：
  - `nano-banana`（standard）：Baserad på Gemini 2.5 Flash Image, snabb och kostnadseffektiv
  - `nano-banana-2-lite`：Baserad på Gemini 3.1 Flash Lite Image, stöder endast 1K och genererar snabbt
  - `nano-banana-2`：Baserad på Gemini 3.1 Flash Image Preview, kvalitet på Pro-nivå + Flash-hastighet
  - `nano-banana-pro`：Baserad på Gemini 3 Pro Image Preview, högsta kvalitet
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`：Officiella kanalversioner av motsvarande modeller, med bättre bildkvalitet och stabilitet samt annorlunda prissättning
- **Asynkron återuppringning**：Valfritt, ta emot aviseringar om slutförda uppgifter och resultat via `callback_url`
- **Antal bilder**：Valfritt, ange 1–4 bilder via `count`, standard är 1 bild; varje bild slutförs genom ett separat genereringsanrop; vanliga tekniska fel eller säkerhetsavslag från leverantören påverkar endast motsvarande anrop, medan övriga lyckade bilder returneras som vanligt och debiteras utifrån det faktiska antalet lyckade bilder

## Snabbstart: generera bilder（`action=generate`）

**Minsta obligatoriska parametrar**：`action`、`prompt`
När du bara vill skapa en bild direkt utifrån en prompt ska du ange `action` som `generate` och tillhandahålla en tydlig `prompt`.

### Exempel på begäran（cURL）

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Exempel på begäran（Python）

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

```json
  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {

      "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }
  ]
```

### Fältbeskrivning

- `success`：Om denna begäran lyckades.
- `task_id`：Uppgifts-ID.
- `trace_id`：ID för spårning av anropskedjan, vilket underlättar felsökning.
- `count`：Antalet bilder som begärs genererade eller redigerade, stöder 1–4 och standard är 1. `data` innehåller endast bilder som har genererats framgångsrikt, och debitering sker utifrån det faktiska antalet returnerade bilder. Varje genereringsanrop använder obligatoriskt leverantörens inbyggda säkerhetspolicy; om ett anrop avvisas påverkas inte andra lyckade anrop, och 403 returneras när samtliga anrop avvisas.
- `data[]`：Resultatlista.
  - `prompt`：Prompten som användes för generering (återges).
  - `image_url`：Direkt URL till den genererade bilden.

> Obs: `/nano-banana/images` behöver endast `action` och `prompt` för att generera bilder

## Redigera bilder（`action=edit`）

När du vill redigera baserat på befintliga bilder ska du ange `action` som `edit`, skicka en lista med länkar till bilderna som ska redigeras (en eller flera bilder) via `image_urls`, och samtidigt ange en `prompt` som beskriver redigeringsmålet.

Om vi till exempel tillhandahåller ett porträttfoto och ett klädesfoto, och vill att personen ska bära klädesplagget, kan vi skicka båda bildlänkarna samtidigt och ange action som `edit`. URL:en kan vara en HTTP URL, en offentligt tillgänglig länk med protokollet `https` eller `http`, eller en Base64-kodad bild, till exempel `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Exempel på begäran（cURL）
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Exempel på begäran (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

```json

  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",
  "data": [
    {
      "prompt": "let this man wear on this T-shirt",

    }
```

### Fältbeskrivning

- `image_urls[]`: URL-lista över bilder som ska redigeras (måste vara offentligt tillgängliga). Flera bilder kan skickas, och tjänsten kombinerar dessa material med `prompt` för att slutföra redigeringen.
- Övriga fält är samma som för svaret för ”Generera bild”.

## Asynkron återuppringning (valfritt, rekommenderas)

Generering eller redigering kan ta en viss tid. För att undvika att långvariga anslutningar tar upp resurser rekommenderas att använda **Webhook-återuppringning** via `callback_url`:

1. Lägg till `callback_url` i begärans brödtext, till exempel din servers Webhook-adress (måste vara offentligt tillgänglig och stödja POST JSON).
2. API:et kommer att **omedelbart returnera** ett svar som innehåller `task_id` (eller innehåller grundläggande resultat).
3. När uppgiften är klar skickar plattformen fullständig JSON till `callback_url` via `POST`. Du kan associera begäran med resultatet genom `task_id`.

**Exempel på återuppringningsnyttolast** (fältstrukturen är densamma som för synkront lyckat svar):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Felhantering

Vid misslyckade anrop returneras ett standardiserat felformat och ett spårnings-ID. Vanliga fel är följande:

- **400 `token_mismatched`**: Begäran är ogiltig eller har felaktiga parametrar.
- **400 `api_not_implemented`**: Gränssnittet är inte implementerat (kontakta supporten).
- **401 `invalid_token`**: Autentiseringen misslyckades eller Token saknas.
- **403 `forbidden`**: Leverantörens inbyggda säkerhetspolicy avvisade begäran eller genereringsresultatet. Detta anrop returnerar ingen bild och debiteras inte; begäranden med flera bilder kan fortfarande returnera och debitera andra lyckade anrop.
- **429 `too_many_requests`**: Gränsen för begärandefrekvens har överskridits.
- **500 `api_error`**: Serverundantag.

### Exempel på felsvar

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Parameteröversikt och anmärkningar

- **Obligatoriskt**: `action`, `prompt`
- **Endast för redigering**: `image_urls` (array, minst 1 objekt)
- **Valfritt**: `model` (standard är `nano-banana`, valbara alternativ är `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-pro` eller motsvarande officiella kanalversion med `:official`), `aspect_ratio` (bildförhållande, såsom `1:1`, `16:9`), `resolution` (upplösning, såsom `1K`, `2K`, `4K`; `nano-banana-2-lite` stöder endast `1K`), `callback_url` (används för asynkron återuppringning)
- **Headers**: Måste ange `authorization: Bearer {token}`; `accept` rekommenderas vara satt till `application/json`
- **Bildåtkomst**: `image_urls` måste vara direktlänkar som är offentligt tillgängliga (HTTP/HTTPS), HTTPS rekommenderas
- **Idempotens och spårning**: Behåll `task_id` och `trace_id` för enklare felsökning och resultatsamband
