Den här artikeln beskriver hur du integrerar och använder Nano Banana Images API. Gränssnittet stöder två funktioner: **bildgenerering (generate)** och **bildredigering (edit)**.

## Ansökningsprocess

För att använda Nano Banana Images API går du först till [Ace Data Clouds kontrollpanel](https://platform.acedata.cloud/console/applications) för att hämta din API-token och spara den för senare användning.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du inte har loggat in eller registrerat dig ännu kommer du automatiskt att omdirigeras till inloggningssidan där du kan registrera dig och logga in. När du är klar återgår du automatiskt till den aktuella sidan.

**En enda API-token räcker för att anropa alla plattformens tjänster. Du behöver inte ansöka separat för varje tjänst.** Vid den första ansökan får du en kostnadsfri kredit som du kan använda för att prova tjänsten utan kostnad. När krediten inte räcker till kan du fylla på ditt allmänna saldo i [kontrollpanelen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## Översikt över API-gränssnittet

- **Base URL**: `https://api.acedata.cloud`
- **Endpoint**: `POST /nano-banana/images`
- **Autentiseringsmetod**: Skicka med `authorization: Bearer {token}` i HTTP Header.
- **Begärandehuvuden**:
  - `accept: application/json`
  - `content-type: application/json`
- **Åtgärd (action)**:
  - `generate`: Generera bilder utifrån textbeskrivningar
  - `edit`: Redigera bilder baserat på angivna bilder
- **Modell (model)** (valfritt):
  - `nano-banana` (standard): Baserad på Gemini 2.5 Flash Image, snabb hastighet och låg kostnad
  - `nano-banana-2-lite`: Baserad på Gemini 3.1 Flash Lite Image, stöder endast 1K och har snabb bildgenerering
  - `nano-banana-2`: Baserad på Gemini 3.1 Flash Image Preview, Pro-kvalitet med Flash-hastighet
  - `nano-banana-2.1`: Nästa generations effektiva bildmodell som stöder bildgenerering och redigering i 1K, 2K och 4K
  - `nano-banana-pro`: Baserad på Gemini 3 Pro Image Preview, högsta kvalitet
  - `nano-banana:official`, `nano-banana-2-lite:official`, `nano-banana-2:official`, `nano-banana-pro:official`: Officiella kanalversioner av motsvarande modeller, med bättre bildkvalitet och stabilitet samt olika debiteringsvillkor
- **Asynkron återuppringning**: Valfritt, ta emot meddelanden om slutförda uppgifter och resultat via `callback_url`
- **Antal bilder**: Valfritt, använd `count` för att ange 1–4 bilder, standardvärdet är 1. Varje bild genereras genom ett separat anrop. Vanliga tekniska fel eller säkerhetsavslag från leverantören påverkar endast det aktuella anropet. Övriga bilder som genereras framgångsrikt returneras som vanligt, och debiteringen baseras på det faktiska antalet lyckade bilder.

## Kom igång snabbt: Generera bilder (`action=generate`)

**Minsta obligatoriska parametrar**: `action`, `prompt`

När du bara vill generera en bild direkt utifrån en prompt ställer du in `action` på `generate` och anger en tydlig `prompt`.

### Exempel på begäran (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Exempel på begäran (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

```json

  "success": true,
  "task_id": "70e6931b-6e34-43db-9e36-8765e2809d04",
  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {
      "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay.       "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }
  ]

```

### Fältbeskrivningar

- `success`: Anger om den aktuella begäran lyckades.
- `task_id`: Uppgiftens ID.
- `trace_id`: Spårnings-ID för att underlätta felsökning.
- `count`: Antalet bilder som begärs för generering eller redigering. Stöder 1–4, standardvärdet är 1. `data` innehåller endast bilder som har genererats framgångsrikt, och debiteringen baseras på det faktiska antalet returnerade bilder. Varje genereringsanrop följer obligatoriskt leverantörens ursprungliga säkerhetspolicy. Om ett enskilt anrop avvisas påverkar det inte andra lyckade anrop. Om samtliga anrop avvisas returneras 403.
- `data[]`: Resultatlista.
  - `prompt`: Prompten som användes för genereringen (returneras i svaret).
  - `image_url`: Den direkta URL:en till den genererade bilden.

> Obs: `/nano-banana/images` behöver endast `action` och `prompt` för att generera bilder.

## Redigera bilder (`action=edit`)

När du vill redigera befintliga bilder ställer du in `action` på `edit` och skickar listan över bildlänkar som ska redigeras via `image_urls` (en eller flera bilder). Ange samtidigt en `prompt` som beskriver redigeringsmålet.

Till exempel kan vi tillhandahålla ett foto av en person och ett foto av ett klädesplagg och låta personen bära plagget. Då kan vi skicka in bildlänkarna samtidigt och ange `action` som `edit`. URL:en kan vara en HTTP-URL, det vill säga en offentligt tillgänglig länk med protokollet `https` eller `http`, eller en Base64-kodad bild, till exempel `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Exempel på begäran (cURL)
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Exempel på begäran (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",

    {

    }

### Fältbeskrivning

- `image_urls[]`: Lista över URL:er till bilder som ska redigeras (måste vara offentligt tillgängliga). Flera bilder kan skickas, och tjänsten kombinerar dessa material med `prompt` för att utföra redigeringen.
- Övriga fält är desamma som i svaret för ”Generera bild”.

## Asynkron återuppringning (valfritt, rekommenderas)

Generering eller redigering kan ta en viss tid. För att undvika att långvariga anslutningar upptar resurser rekommenderas att använda **Webhook-återuppringning** via `callback_url`:

1. Lägg till `callback_url` i begärandekroppen, till exempel adressen till din servers Webhook (måste vara offentligt tillgänglig och stödja POST JSON).
2. API:et returnerar **omedelbart** ett svar som innehåller `task_id` (eller grundläggande resultat).
3. När uppgiften är slutförd skickar plattformen den fullständiga JSON-datan till `callback_url` med metoden `POST`. Du kan använda `task_id` för att koppla samman begäran och resultatet.

**Exempel på återuppringningsdata** (fältstrukturen är densamma som i det synkrona lyckade svaret):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Felhantering

När ett anrop misslyckas returneras ett standardiserat felformat med ett spårnings-ID. Vanliga fel är följande:

- **400 `token_mismatched`**: Ogiltig begäran eller felaktiga parametrar.
- **400 `api_not_implemented`**: Gränssnittet är inte implementerat (kontakta supporten).
- **401 `invalid_token`**: Autentiseringen misslyckades eller Token saknas.
- **403 `forbidden`**: Leverantörens ursprungliga säkerhetspolicy avvisade begäran eller genereringsresultatet. Detta anrop returnerar ingen bild och debiteras inte; begäranden med flera bilder kan fortfarande returnera resultat och debiteras för andra lyckade anrop.
- **429 `too_many_requests`**: Begärandefrekvensen har överskridit gränsen.
- **500 `api_error`**: Serverfel.

### Exempel på felsvar

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Parameteröversikt och anmärkningar

- **Obligatoriska**: `action`, `prompt`
- **Endast för redigering**: `image_urls` (array, minst 1 objekt)
- **Valfria**: `model` (standard är `nano-banana`, valbara alternativ är `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-2.1`, `nano-banana-pro`; förutom `nano-banana-2.1` finns även motsvarande officiella kanalversioner med suffixet `:official`), `aspect_ratio` (`auto` eller ett specifikt bildförhållande, till exempel `1:1`, `16:9`), `resolution` (upplösning, till exempel `1K`, `2K`, `4K`; `nano-banana-2-lite` stöder endast `1K`), `callback_url` (används för asynkron återuppringning)
- **Headers**: Du måste ange `authorization: Bearer {token}`; det rekommenderas att ställa in `accept` till `application/json`
- **Bilders tillgänglighet**: `image_urls` måste vara direktlänkar som är offentligt tillgängliga (HTTP/HTTPS). HTTPS rekommenderas.
- **Idempotens och spårning**: Spara `task_id` och `trace_id` för felsökning och koppling av resultat.

Om du uttryckligen skickar `"aspect_ratio": "auto"` väljs det förinställda bildförhållande som bäst motsvarar proportionerna, riktningen eller layouten i prompten. Detta gäller både generering och redigering. Om prompten till exempel innehåller ”YouTube-miniatyrbild” kan formatet `16:9` väljas. Om prompten inte innehåller några storlekskrav eller om automatisk identifiering inte är tillgänglig används standardformatet för text-till-bild-generering, medan bildredigering följer den första referensbilden och använder det närmaste formatet som stöds. Om fältet utelämnas används standardformatet eller referensbildens bildförhållande. Om det redan finns ett uttryckligt krav på bildformat ska du skicka det specifika bildförhållandet direkt.
