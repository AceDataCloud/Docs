Detta dokument beskriver integrationen och användningen av Nano Banana Images API. Detta gränssnitt stöder två funktioner: **bildgenerering (generate)** och **bildredigering (edit)**.

## Ansökningsprocess

För att använda Nano Banana Images API, gå först till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att hämta din API Token och spara den för senare användning.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Om du ännu inte har loggat in eller registrerat dig omdirigeras du automatiskt till inloggningssidan där du uppmanas att registrera dig och logga in. När det är klart återgår du automatiskt till den aktuella sidan.

**En API Token kan användas för att anropa alla tjänster på plattformen, utan att behöva ansöka separat för varje tjänst.** Vid första ansökan får du en kostnadsfri kvot för att prova tjänsten gratis; om kvoten är otillräcklig kan du fylla på det allmänna saldot i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## API-översikt

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **Autentiseringsmetod**：Skicka med `authorization: Bearer {token}` i HTTP Header
- **Begärandehuvuden**：
  - `accept: application/json`
  - `content-type: application/json`
- **Åtgärd (action)**：
  - `generate`：Generera bilder baserat på textpromptar
  - `edit`：Redigera baserat på en angiven bild
- **Modell (model)**（valfritt）：
  - `nano-banana`（standard）：Baserad på Gemini 2.5 Flash Image, snabb och kostnadseffektiv
  - `nano-banana-2-lite`：Baserad på Gemini 3.1 Flash Lite Image, stöder endast 1K och har snabb generering
  - `nano-banana-2`：Baserad på Gemini 3.1 Flash Image Preview, Pro-kvalitet + Flash-hastighet
  - `nano-banana-2.1`：Ny generation effektiv bildmodell som stöder bildgenerering och redigering i 1K, 2K och 4K
  - `nano-banana-pro`：Baserad på Gemini 3 Pro Image Preview, högsta kvalitet
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`：Officiella kanalversioner av motsvarande modeller, med bättre bildkvalitet och stabilitet samt annan prissättning
- **Asynkron återuppringning**：Valfritt, ta emot meddelanden om slutförda uppgifter och resultat via `callback_url`
- **Antal bilder**：Valfritt, ange 1–4 bilder via `count`, standardvärdet är 1 bild; varje bild slutförs genom ett separat genereringsanrop; vanliga tekniska fel eller säkerhetsavslag från leverantören påverkar endast motsvarande anrop, medan övriga lyckade bilder returneras som vanligt och debiteras enligt det faktiska antalet lyckade bilder

## Snabbstart: generera bilder（`action=generate`）

**Minsta obligatoriska parametrar**：`action`、`prompt`
När du endast vill skapa en bild direkt utifrån en prompt, ange `action` som `generate` och tillhandahåll en tydlig `prompt`.

### Begärandeexempel（cURL）

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Begärandeexempel（Python）

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Fältbeskrivning

- `success`：Om denna begäran lyckades.
- `task_id`：Uppgifts-ID.
- `trace_id`：ID för spårning av anropskedjan, för att underlätta felsökning.
- `count`：Antalet bilder som begärs för generering eller redigering, stöder 1–4 och standardvärdet är 1. `data` innehåller endast bilder som har genererats framgångsrikt, och debitering sker enligt det faktiska antalet returnerade bilder. Varje genereringsanrop använder obligatoriskt leverantörens inbyggda säkerhetspolicy; om ett anrop avvisas påverkas inte andra lyckade anrop, och 403 returneras när alla anrop avvisas.
- `data[]`：Resultatlista.
  - `prompt`：Prompten som används för generering (återges).
  - `image_url`：Direktlänks-URL för den genererade bilden.

> Obs: `/nano-banana/images` kräver endast `action` och `prompt` för att generera en bild

## Redigera bilder（`action=edit`）

När du vill redigera baserat på en befintlig bild, ange `action` som `edit` och skicka via `image_urls` en lista med bildlänkar som ska redigeras (en eller flera bilder), samtidigt som du tillhandahåller en `prompt` som beskriver redigeringsmålet.

Om vi till exempel tillhandahåller ett foto av en person och ett foto av ett plagg, och vill att personen ska bära detta plagg, kan vi skicka in bildlänkarna samtidigt och ange action som `edit`. URL:en kan vara en HTTP URL, en offentligt åtkomlig länk med protokollet `https` eller `http`, eller en Base64-kodad bild, till exempel `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Begärandeexempel（cURL）
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Begäransexempel (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Fältbeskrivning

- `image_urls[]`: Lista över URL:er till bilder som ska redigeras (måste vara offentligt åtkomliga). Flera bilder kan skickas, och tjänsten kommer att kombinera dessa resurser med `prompt` för att slutföra redigeringen.
- Övriga fält är desamma som i svaret för ”generera bild”.

## Asynkron återuppringning (valfritt, rekommenderas)

Generering eller redigering kan kräva en viss tid. För att undvika att långvariga anslutningar tar upp resurser rekommenderas att använda **Webhook-återuppringning** via `callback_url`:

1. Lägg till `callback_url` i begärandetexten, till exempel din servers Webhook-adress (måste vara offentligt åtkomlig och stödja POST JSON).
2. API:t kommer att **omedelbart returnera** ett svar som innehåller `task_id` (eller grundläggande resultat).
3. När uppgiften är klar skickar plattformen fullständig JSON till `callback_url` via `POST`. Du kan koppla samman begäran och resultatet med hjälp av `task_id`.

**Exempel på återuppringningsnyttolast** (fältstrukturen är densamma som vid synkront lyckat svar):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Felhantering

Vid misslyckat anrop returneras ett standardiserat felformat och ett spårnings-ID. Vanliga fel är följande:

- **400 `token_mismatched`**: Begäran är ogiltig eller har felaktiga parametrar.
- **400 `api_not_implemented`**: Gränssnittet är inte implementerat (kontakta supporten).
- **401 `invalid_token`**: Autentisering misslyckades eller Token saknas.
- **403 `forbidden`**: Leverantörens inbyggda säkerhetspolicy avvisade begäran eller genereringsresultatet. Detta anrop returnerar ingen bild och debiteras inte; för begäranden med flera bilder kan andra lyckade anrop fortfarande returneras och debiteras.
- **429 `too_many_requests`**: Begärandefrekvensen har överskridits.
- **500 `api_error`**: Serverfel.

### Exempel på felsvar

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Parameteröversikt och anmärkningar

- **Obligatoriskt**: `action`, `prompt`
- **Endast för redigering**: `image_urls` (array, minst 1 objekt)
- **Valfritt**: `model` (standard är `nano-banana`, valbara är `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-2.1`, `nano-banana-pro`; förutom `nano-banana-2.1` finns även motsvarande officiella kanalversioner med `:official`), `aspect_ratio` (bildförhållande, till exempel `1:1`, `16:9`), `resolution` (upplösning, till exempel `1K`, `2K`, `4K`; `nano-banana-2-lite` stöder endast `1K`), `callback_url` (för asynkron återuppringning)
- **Headers**: `authorization: Bearer {token}` måste tillhandahållas; `accept` rekommenderas att sättas till `application/json`
- **Bildåtkomlighet**: `image_urls` måste vara direktlänkar som är offentligt åtkomliga (HTTP/HTTPS), HTTPS rekommenderas
- **Idempotens och spårning**: Behåll `task_id` och `trace_id` för att underlätta felsökning och koppling av resultat
