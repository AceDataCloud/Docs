Denna artikel kommer att introducera integrationsbeskrivningen för Gemini Videos Generation API, som kan generera Google Gemini (omni-flash) videor genom att mata in textpromptar (och valfria referensbilder).

## Ansökningsprocess

För att använda Gemini Videos Generation API, börja med att gå till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att få din API-token, som du ska spara.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Om du inte har loggat in eller registrerat dig, kommer du automatiskt att omdirigeras till inloggningssidan för att registrera dig och logga in, och efter att ha slutfört detta kommer du automatiskt att återvända till den aktuella sidan.

**En API-token kan användas för att anropa alla tjänster på plattformen, det behövs ingen separat ansökan för varje tjänst.** Första ansökan ger en gratis kvot, så att du kan prova gratis; när kvoten är slut kan du ladda på allmän balans i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Grundläggande användning

Först, förstå den grundläggande användningen, mata in prompten `prompt`, modellen `model` och bildförhållandet `aspect_ratio`, så kan du generera motsvarande video.

Här kan vi se att vi har ställt in begärningshuvuden, inklusive:

- `accept`: vilken format av svar du vill ta emot, här anges `application/json`, vilket innebär JSON-format.
- `authorization`: nyckeln för att anropa API:et, efter ansökan kan du direkt välja från rullgardinsmenyn.

Dessutom har vi ställt in begärningskroppen, inklusive:

- `prompt`: textprompten som beskriver vad du vill generera i videoinnehållet, **obligatorisk**.
- `model`: modellen för att generera videon, för närvarande stöds endast `omni-flash`, vilket är standard.
- `aspect_ratio`: bildförhållandet för den genererade videon, valfritt `16:9` (liggande) eller `9:16` (stående), standard `16:9`.
- `resolution`: valfri utdataupplösning, valfritt `720p` eller `1080p`, standard `720p`.
- `image_urls`: valfri array av referensbildlänkar som används för att vägleda videoproduktionen, tomma fält kommer att ignoreras. När `video_urls` används för videoredigering är detta parameter obligatoriskt (minst en bild).
- `video_urls`: valfri array av referensvideolänkar (max 1), för **videoredigering / videoreferens**; om den tillhandahålls måste minst en `image_urls` också tillhandahållas.
- `callback_url`: asynkron återkopplingsadress, efter att ha ställts in kommer API:et omedelbart att returnera `task_id`, och när uppgiften är klar kommer resultatet att POST:as till den adressen.
- `async`: valfritt, om det sätts till `true` returnerar gränssnittet omedelbart `task_id`, utan att behöva ange `callback_url`, och sedan kan du använda motsvarande uppgiftsfrågegränssnitt för att hämta resultatet.

Klicka på "Try" knappen för att testa, resultatet kommer att likna följande:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Det returnerade resultatet har flera fält, som beskrivs nedan:

- `success`: om denna videogenereringsbegäran var framgångsrik.
- `task_id`: ID för denna videogenereringsuppgift.
- `trace_id`: spårnings-ID för denna begäran, används för att felsöka problem.
- `data`: lista över genererade videor.
  - `id`: unik identifierare för den genererade videon.
  - `video_url`: länkadressen till den genererade videon.
  - `state`: status för videogenereringsuppgiften, valfritt `pending` / `succeeded` / `failed`.

Vi behöver bara hämta den genererade videon baserat på `video_url` länken i `data`.

Motsvarande CURL-kod ser ut så här:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Motsvarande Python-kod ser ut så här:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Bild till video

Om du vill generera video baserat på referensbilder kan du ange en eller flera bildlänkar i `image_urls`, som används för att vägleda videoproduktionen:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## Videoredigering / referensvideo

Stöder direkt redigering eller referens av befintliga videor: ange en referensvideolänk (max 1) i `video_urls`, och **samtidigt** tillhandahålla minst en referensbild i `image_urls` (hård krav från upstream). Du kan beskriva den önskade redigeringseffekten (ändra stil, byta scen, lägga till eller ta bort element, etc.) genom `prompt`:

```json
{
  "prompt": "Restyle the video into cinematic anime, keep the motion",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ],
  "video_urls": [
    "https://cdn.acedata.cloud/example-source.mp4"
  ]
}
```

> Observera: högst 1 referensvideo; och när `video_urls` tillhandahålls måste minst en `image_urls` tillhandahållas (annars returneras parameterfel).

## Asynkron återkoppling

Videogenerering kräver viss behandlingstid. Om du inte vill hålla en lång anslutning och vänta kan du ange `callback_url`, då kommer API:et omedelbart att returnera `task_id`, och när uppgiften är klar kommer det slutliga resultatet att POST:as till den adressen:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Det omedelbart returnerade resultatet ser ut så här:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Fråga uppgiftsresultat

Om du har använt asynkron återkoppling eller vill aktivt fråga uppgiftens status kan du använda [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) för att fråga den senaste statusen och resultatet för uppgiften baserat på `task_id`.

## Felhantering

När en begäran uppstår problem kommer API:et att returnera motsvarande felkod och beskrivning, vanliga är följande:
- `400`：Begärningsparametrarna är felaktiga, till exempel saknas `prompt` eller `aspect_ratio` har ett ogiltigt värde.
- `401`：Autentisering misslyckades, token är ogiltig eller matchar inte API:et.
- `403`：Otillräckligt saldo, eller så har sökordet träffat innehållsgranskningen och blivit avvisat.
- `500`：Internt serverfel eller misslyckande vid uppströms generering.
