Denna artikel kommer att introducera integrationsbeskrivningen för Gemini Videos Generation API, som kan generera Google Gemini (omni-flash) videor genom att mata in textpromptar (och valfria referensbilder).

## Ansökningsprocess

För att använda Gemini Videos Generation API, börja med att gå till [Ace Data Cloud-konsolen](https://platform.acedata.cloud/console/applications) för att få din API-token, som du ska spara.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Om du inte har loggat in eller registrerat dig kommer du automatiskt att omdirigeras till inloggningssidan för att registrera dig och logga in, och efter att ha slutfört detta kommer du automatiskt att återvända till den aktuella sidan.

**En API-token räcker för att anropa alla tjänster på plattformen, det behövs ingen separat ansökan för varje tjänst.** Första ansökan ger en gratis kvot, så att du kan prova gratis; när kvoten är slut kan du ladda på allmän balans i [konsolen](https://platform.acedata.cloud/console/coin).

> 📘 Fullständig dokumentation: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Grundläggande användning

Först, förstå den grundläggande användningen, mata in prompten `prompt`, modellen `model` och bildförhållandet `aspect_ratio`, så kan du generera motsvarande video.

Här kan vi se att vi har ställt in begärningshuvuden, inklusive:

- `accept`: vilken typ av format du vill ta emot som svar, här anges `application/json`, vilket innebär JSON-format.
- `authorization`: nyckeln för att anropa API:et, som kan väljas direkt efter ansökan.

Dessutom har vi ställt in begärningskroppen, inklusive:

- `prompt`: textprompten som beskriver det videoinnehåll du vill generera, **obligatorisk**.
- `model`: modellen för att generera videon, för närvarande stöds endast `omni-flash`, vilket är standard.
- `aspect_ratio`: bildförhållandet för den genererade videon, valfritt `16:9` (liggande) eller `9:16` (stående), standard `16:9`.
- `resolution`: valfri utdataupplösning, valfritt `720p` eller `1080p`, standard `720p`.
- `image_urls`: valfri array av referensbildlänkar som används för att vägleda videoproduktionen, tomma fält kommer att ignoreras. När `video_urls` används för videoredigering är detta parameter obligatorisk (minst en bild).
- `video_urls`: valfri array av referensvideolänkar (max 1), för **videoredigering / videoreferens**; om den tillhandahålls måste minst en `image_urls` också tillhandahållas.
- `callback_url`: asynkron återkopplingsadress, när den är inställd kommer API:et omedelbart att returnera `task_id`, och när uppgiften är klar kommer resultatet att POST:as till den adressen.
- `async`: valfritt, om det sätts till `true` returnerar gränssnittet omedelbart `task_id`, utan att behöva ange `callback_url`, och sedan kan resultaten hämtas genom att fråga motsvarande uppgiftsgränssnitt.

Klicka på "Try" knappen för att testa, resultatet kommer att likna följande:

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://platform2.cdn.acedata.cloud/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden"
    }
  ],
  "started_at": "2026-07-15T10:55:53.856Z",
  "finished_at": "2026-07-15T10:57:01.328Z",
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Det returnerade resultatet har flera fält, som beskrivs nedan:

- `success`: om denna video-genereringsbegäran var framgångsrik.
- `task_id`: ID för denna video-genereringsuppgift.
- `trace_id`: spårnings-ID för denna begäran, används för att felsöka problem.
- `data`: lista över genererade videoresultat.
  - `id`: unik identifierare för den genererade videon.
  - `video_url`: länkadressen till den genererade videon (`state` är `pending` när den är `null`).
  - `state`: status för video-genereringsuppgiften, valfritt `pending` / `succeeded` / `failed`.
  - `aspect_ratio`: bildförhållandet för videon, som överensstämmer med begärningsparametern.
  - `prompt`: prompten som användes för att generera videon.

Vid synkron återkoppling kommer även `started_at`, `finished_at`, `elapsed` (tid, sekunder) och `cost` (denna avgift, enhet Credit) att bifogas.

Vi behöver bara hämta den genererade videon via `video_url`-länkadressen i resultatet.

Motsvarande CURL-kod ser ut så här:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Motsvarande Python-kod ser ut så här:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Bild till video

Om du vill generera video baserat på referensbilder kan du ange en eller flera bildlänkar i `image_urls`, som används för att vägleda videoproduktionen:

```json
{
  "prompt": "The woman slowly turns around and smiles at the camera, gentle breeze",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3.png"
  ]
}
```

## Videoredigering / Referensvideo (inmatad video, generera video)

Stöder direkt "mata in en video, generera en ny video": ange en referensvideolänk i `video_urls` (max 1), och **samtidigt** tillhandahålla minst en referensbild i `image_urls` (hård krav från upstream), och använd `prompt` för att beskriva den önskade redigeringseffekten (ändra stil, byta scen, lägga till eller ta bort element osv.).

Här är ett komplett verkligt exempel - att ändra en video av en solig strand till en vinterlandskap med snöfall, samtidigt som layouten av stranden, palmerna och båten behålls. Videoredigeringen tar längre tid (detta exempel tar cirka 6,5 minuter), så vi använder `async: true` för att skicka in asynkront:
```json
{
  "prompt": "Förvandla denna soliga tropiska strand till en snöig vinterscen med kraftigt fallande snö och molnig himmel; behåll samma strand, palmer och båtlayout.",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://platform2.cdn.acedata.cloud/seedance/dd3dc063-3383-4f29-bedc-e771a096758c.mp4"
  ],
  "async": true
}
```

Skicka in och API:et returnerar omedelbart `task_id`:

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

Använd sedan detta `task_id` som `id` för att pollera [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks), när uppgiften är klar kan du få den genererade nya videon (detta är det verkliga resultatet av detta exempel):

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://platform2.cdn.acedata.cloud/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "Förvandla denna soliga tropiska strand till en snöig vinterscen med kraftigt fallande snö och molnig himmel; behåll samma strand, palmer och båtlayout."
    }
  ],
  "started_at": "2026-07-15T03:01:22.914Z",
  "finished_at": "2026-07-15T03:07:57.090Z",
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

För att få ett mer högupplöst resultat kan du ställa in `resolution` till `1080p` (övriga parametrar förblir oförändrade).

> Tips: Inmatnings- / utmatningsmedialänkarna i exemplet är verkliga genererade resultat. **Videor och bildlänkar som genereras av plattformen har en sparande tidsgräns, och kommer att upphöra att gälla efter utgång**. Vänligen ladda ner och spara dem i din egen lagring så snart du får resultaten.

> Observera: Referensvideon får vara högst 1; och när `video_urls` tillhandahålls måste minst en `image_urls` tillhandahållas, annars kommer följande parameterfel att returneras:

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (minst en referensbild) krävs när video_urls tillhandahålls."
  }
}
```

## Asynkron återkoppling

Videogenerering kräver viss behandlingstid. Om du inte vill hålla en lång anslutning och vänta kan du skicka in `callback_url`, då kommer API:et omedelbart att returnera `task_id`, och när uppgiften är klar kommer det slutliga resultatet att POST:as till den adressen:

```json
{
  "prompt": "En filmisk bild av en kattunge som jagar en fjäril i en solbelyst trädgård",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Omedelbart returnerat resultat ser ut så här:

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## Fråga uppgiftsresultat

Om du har använt asynkron återkoppling eller vill aktivt kontrollera uppgiftens status kan du använda [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) för att fråga den senaste statusen och resultaten för uppgiften baserat på `task_id`. Skicka in `task_id` som returnerades när videon skapades som `id`:

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

Resultatet som returneras när uppgiften är klar liknar följande, strukturen för `response.data` är densamma som vid synkron generering (under generering är `state` `pending`, `video_url` är `null`):

```json

  "type": "videos",
  "request": {

    "prompt": "En timelapse av moln över snöiga berg vid soluppgången",

      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
```

## Felhantering

När en begäran uppstår problem kommer API:et att returnera motsvarande felkod och beskrivning, vanliga är följande:

- `400`: Begärningsparametrar är felaktiga, till exempel saknas `prompt` eller `aspect_ratio` har ett ogiltigt värde.
- `401`: Autentisering misslyckades, token är ogiltig eller matchar inte API:et.
- `403`: Otillräcklig balans, eller prompten träffade innehållsgranskning och avvisades.
- `500`: Intern serverfel eller misslyckande vid uppströms generering.
