Den här artikeln beskriver integrationsinstruktionerna för Gemini Videos Generation API, som kan generera Google Gemini (omni-flash) videor genom att mata in textpromptar (och valfria referensbilder).

## Ansökningsprocess

För att använda API:et behöver du först ansöka om motsvarande tjänst på [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos). När du går in på sidan klickar du på knappen "Acquire", som visas nedan:

![](https://cdn.acedata.cloud/q6ytrc.png)

Om du inte är inloggad eller registrerad kommer du automatiskt att omdirigeras till inloggningssidan där du kan registrera dig och logga in. Efter inloggning eller registrering återvänder du automatiskt till den aktuella sidan.

Vid första ansökan får du en gratis kvot som gör att du kan använda API:et kostnadsfritt.

## Grundläggande användning

Först går vi igenom den grundläggande användningen: genom att mata in prompten `prompt`, modellen `model` och bildförhållandet `aspect_ratio` kan du generera motsvarande video.

Här ser vi att vi ställer in Request Headers, inklusive:

- `accept`: vilket format vi vill ta emot svaret i, här anges `application/json`, alltså JSON-format.
- `authorization`: API-nyckeln för att anropa API:et, som kan väljas direkt efter ansökan.

Dessutom ställer vi in Request Body, inklusive:

- `prompt`: textprompten som beskriver innehållet i videon, **obligatoriskt**.
- `model`: modellen som genererar videon, för närvarande stöds endast `omni-flash`, som är standard.
- `aspect_ratio`: bildförhållandet för videon, kan vara `16:9` (landskap) eller `9:16` (porträtt), standard är `16:9`.
- `image_urls`: en valfri lista med länkar till referensbilder (eller videor) som styr videoproduktionen, tomma poster ignoreras.
- `callback_url`: en asynkron callback-adress; om den anges returnerar API:et omedelbart ett `task_id` och när uppgiften är klar POST:as resultatet till denna adress.

Klicka på knappen "Try" för att testa, och du får ett svar som liknar följande:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Svarsfälten är följande:

- `success`: om videoproduktionsförfrågan lyckades.
- `task_id`: ID för videoproduktionsuppgiften.
- `trace_id`: spårnings-ID för förfrågan, används för felsökning.
- `data`: lista med genererade videor.
  - `id`: unikt ID för den genererade videon.
  - `video_url`: URL till den genererade videon.
  - `state`: status för videoproduktionsuppgiften, kan vara `pending` / `succeeded` / `failed`.

Vi behöver bara hämta den genererade videon via `video_url` i `data`.

Motsvarande CURL-kod är:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Motsvarande Python-kod är:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Bild-till-video

Om du vill generera video baserat på referensbilder kan du skicka en eller flera bildlänkar i `image_urls` för att styra videoproduktionen:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## Asynkron callback

Videoproduktion tar viss tid. Om du inte vill hålla en lång anslutning öppen kan du skicka med `callback_url`. API:et returnerar då omedelbart ett `task_id` och när uppgiften är klar POST:as slutresultatet till den angivna adressen:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Det omedelbara svaret är:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Kontrollera uppgiftsresultat

Om du använder asynkron callback eller vill aktivt kontrollera uppgiftens status kan du via [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) fråga efter den senaste statusen och resultatet med `task_id`.

## Felsökning

Om det uppstår problem med förfrågan returnerar API:et motsvarande felkod och beskrivning. Vanliga fel är:

- `400`: Fel i förfrågningsparametrar, t.ex. saknat `prompt` eller ogiltigt värde för `aspect_ratio`.
- `401`: Auktorisering misslyckades, token är ogiltig eller matchar inte API:et.
- `403`: Otillräcklig saldo, eller prompten har avvisats av innehållsgranskning.
- `500`: Intern serverfel eller fel i upstream-generering.
