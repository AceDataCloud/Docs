Gemini Tasks API:s huvudsakliga funktion är att genomföra förfrågningar om status för en uppgift med hjälp av uppgifts-ID som genererats av Gemini Videos Generation API.

Det här dokumentet ger en detaljerad beskrivning av integrationen av Gemini Tasks API för att hjälpa dig att enkelt integrera och kontrollera status för uppgifter från Gemini Videos Generation API.

## Ansökningsprocess

För att använda Gemini Tasks API behöver du först ansöka om tjänsten på sidan [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos) och kopiera uppgifts-ID:t som returneras av Gemini Videos Generation API.

Därefter går du till sidan [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) för att ansöka om motsvarande tjänst. När du är inne på sidan klickar du på knappen „Acquire“.

Om du inte är inloggad eller registrerad kommer du automatiskt att omdirigeras till [inloggningssidan](https://platform.acedata.cloud) där du kan registrera dig och logga in. Efter inloggning eller registrering återvänder du automatiskt till den aktuella sidan.

Vid första ansökan får du en gratis kvot som gör att du kan använda API:et kostnadsfritt.

## Exempel på förfrågan

Gemini Tasks API kan användas för att kontrollera resultatet från Gemini Videos Generation API.

### Inställning av request headers och request body

**Request Headers** inkluderar:

- `accept`: anger att svaret ska vara i JSON-format, här sätts värdet till `application/json`.
- `authorization`: API-nyckeln för att anropa API:et, som kan väljas från en dropdown efter ansökan.

**Request Body** inkluderar:

- `id`: uppgifts-ID:t som ska kontrolleras.
- `action`: åtgärden på uppgiften, för enstaka förfrågan används `retrieve`.

### CURL-exempel

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Exempel på svar

Vid lyckad förfrågan returnerar API:et detaljerad information om uppgiften. Fältet `request` innehåller request body som användes vid skapandet av uppgiften, och fältet `response` innehåller response body efter att uppgiften slutförts, till exempel:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
        "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Fältbeskrivning:

- `id`: ID för genereringsuppgiften, används för att unikt identifiera uppgiften.
- `request`: förfrågningsinformationen för uppgiften.
- `response`: svarsinformationen för uppgiften.

## Batchförfrågningar

För att kontrollera flera uppgifter samtidigt sätts `action` till `retrieve_batch` och en lista med uppgifts-ID:n skickas via `ids`:

**Request Body** inkluderar:

- `ids`: en array med uppgifts-ID:n som ska kontrolleras.
- `action`: åtgärden på uppgifterna, för batchförfrågan används `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
