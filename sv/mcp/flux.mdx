[MCP (Model Context Protocol)](https://modelcontextprotocol.io) är ett modellkontextprotokoll lanserat av Anthropic som tillåter AI-modeller (som Claude, GPT med flera) att anropa externa verktyg via ett standardiserat gränssnitt. Med Flux MCP Server från AceData Cloud kan du direkt generera och redigera AI-bilder i AI-klienter som Claude Desktop, VS Code, Cursor med flera.

## Funktionsöversikt

Flux MCP Server erbjuder följande kärnfunktioner:

- **Text-till-bild-generering** — generera högkvalitativa bilder från textpromptar  
- **Bildredigering** — redigera befintliga bilder baserat på textinstruktioner  
- **Stöd för flera modeller** — stödjer Flux Pro, Flux Dev, Flux Schnell, Flux Kontext med flera modeller  
- **Modellförfrågningar** — visa alla tillgängliga modeller och deras kapaciteter  
- **Uppgiftsförfrågningar** — övervaka genereringsstatus och hämta resultat  

## Förberedelser

Innan användning behöver du skaffa en AceData Cloud API-token:

1. Registrera dig eller logga in på [AceData Cloud-plattformen](https://platform.acedata.cloud)  
2. Gå till sidan för [Flux Images API](https://platform.acedata.cloud/documents/flux-images)  
3. Klicka på "Acquire" för att få en API-token (första ansökan ger gratis kvot)  

## Installation och konfiguration

### Metod 1: pip-installation (rekommenderas)

```bash
pip install mcp-flux-pro
```

### Metod 2: installation från källkod

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

När installationen är klar kan du starta tjänsten med kommandot `mcp-flux-pro`.

## Användning i Claude Desktop

Redigera Claude Desktops konfigurationsfil:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`  
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`  

Lägg till följande konfiguration:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "din API-token"
      }
    }
  }
}
```

Om du använder `uvx` (ingen förhandsinstallation av paket krävs):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "din API-token"
      }
    }
  }
}
```

Spara konfigurationen och starta om Claude Desktop för att använda Flux-verktygen i konversationer.

## Användning i VS Code / Cursor

Skapa filen `.vscode/mcp.json` i projektets rotkatalog:

```json
{
  "servers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "din API-token"
      }
    }
  }
}
```

Eller använd `uvx`:

```json
{
  "servers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "din API-token"

    }
  }

```

## Tillgängliga verktyg

| Verktygsnamn           | Beskrivning                          |
|-----------------------|------------------------------------|
| `flux_generate_image`  | Generera bild från textprompt       |
| `flux_edit_image`      | Redigera befintlig bild med textinstruktioner |
| `flux_get_task`        | Fråga status för en enskild uppgift |
| `flux_get_tasks_batch` | Fråga status för flera uppgifter i batch |
| `flux_list_models`     | Lista alla tillgängliga modeller och deras kapaciteter |
| `flux_list_actions`    | Lista alla tillgängliga verktyg och arbetsflödesexempel |

## Exempel på användning

När konfigurationen är klar kan du direkt använda naturligt språk i AI-klienter för att anropa funktionerna, till exempel:

- "Hjälp mig att generera en cyberpunk-stil stadsnatt med Flux"  
- "Byt bakgrunden på det här fotot till en strand"  
- "Redigera den här bilden med Flux Kontext Pro-modellen och ändra klädfärgen till röd"  
- "Lista alla tillgängliga Flux-modeller"
