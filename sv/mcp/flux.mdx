[MCP (Model Context Protocol)](https://modelcontextprotocol.io) är ett modellkontextprotokoll lanserat av Anthropic, som gör det möjligt för AI-modeller (som Claude, GPT osv.) att anropa externa verktyg via standardiserade gränssnitt. Genom Flux MCP Server som tillhandahålls av AceData Cloud kan du direkt generera och redigera AI-bilder i AI-klienter som Claude Desktop, VS Code och Cursor.

## Funktionsöversikt

Flux MCP Server erbjuder följande kärnfunktioner:

- **Text-till-bild-generering** — Generera högkvalitativa bilder via textpromptar
- **Bildredigering** — Redigera befintliga bilder baserat på textinstruktioner
- **Stöd för flera modeller** — Stöd för flera modeller som Flux Pro, Flux Dev, Flux 2 och Flux Kontext
- **Modellfrågor** — Visa alla tillgängliga modeller och deras funktioner
- **Uppgiftsfrågor** — Övervaka genereringsförloppet och hämta resultat

## Förberedelser

Innan användning behöver du hämta en AceData Cloud API-token:

1. Registrera dig eller logga in på [AceData Cloud-plattformen](https://platform.acedata.cloud)
2. Gå till sidan [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Klicka på 「Acquire」 för att hämta API-token (den första ansökan inkluderar gratis kredit)

## Metod ett: Använd hostad MCP Server (rekommenderas, noll installation)

AceData Cloud har redan hostat **Flux MCP Server** i molnet, **utan behov av att installera några lokala beroenden**. Fyll bara i följande URL direkt i AI-klienten för att använda den:

```
https://flux.mcp.acedata.cloud/mcp
```

Autentiseringsmetod: Lägg bara till `Authorization: Bearer din API-token` i förfrågningshuvudet (Claude.ai slutför detta automatiskt via OAuth, så du behöver inte fylla i token manuellt).

### Claude.ai (webbversion, OAuth-inloggning, enklast)

1. Öppna [Claude.ai](https://claude.ai) → **Customize** längst ned till vänster → **Connectors** → **Add More**
2. Fyll i följande vid URL: `https://flux.mcp.acedata.cloud/mcp`
3. Slutför OAuth-auktoriseringsinloggningen (omdirigeras automatiskt till AceData Clouds inloggningssida)
4. Återgå till konversationsgränssnittet, så kan verktygen användas

### Claude Desktop

Redigera konfigurationsfilen:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Starta om Claude Desktop efter att du har sparat för att aktivera ändringarna.

### Claude Code (terminalkommandorad)

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Andra klienter som stöder MCP

Alla klienter som stöder MCP Streamable HTTP-protokollet (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant osv.) kan integreras genom att fylla i följande två uppgifter:

- **URL**: `https://flux.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer din API-token`

## Metod två: Kör lokalt (pip / uvx-installation)

Om du behöver köra offline, anpassa koden eller distribuera till ett internt nätverk kan du installera MCP Server lokalt och starta den via stdio.

### Installation

Installation med pip (rekommenderas):

```bash
pip install mcp-flux-pro
```

Eller installation från källkod:

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Efter installationen kan du använda kommandot `mcp-flux-pro` för att starta tjänsten.

### Använd i Claude Desktop (lokalt)

Redigera Claude Desktops konfigurationsfil:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lägg till följande konfiguration:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Om du använder `uvx` (utan att installera paketet i förväg):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Starta om Claude Desktop efter att du har sparat konfigurationen för att aktivera ändringarna.

### Använd i VS Code / Cursor (lokalt)

Skapa `.vscode/mcp.json` i projektets rotkatalog:

## Lista över tillgängliga verktyg

| Verktygsnamn                    | Beskrivning                       |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | Generera bilder via textpromptar              |
| `flux_edit_image`      | Redigera befintliga bilder baserat på textinstruktioner             |
| `flux_generate_video`  | FLUX 3 text-till-video/bild-till-video/videogenerering och förbättring av befintliga utkast |
| `flux_get_task`        | Fråga efter status för en enskild uppgift                 |
| `flux_get_tasks_batch` | Fråga efter uppgiftsstatus i batch                 |
| `flux_list_models`     | Lista alla tillgängliga modeller och deras funktioner             |
| `flux_list_actions`    | Lista alla tillgängliga verktyg och arbetsflödesexempel           |

## Modell- och storleksbegränsningar
`flux-2-flex`、`flux-2-pro`、`flux-2-max` och Kontext-modellerna måste använda
proportioner för `size`, till exempel `1:1` eller `16:9`, och kan inte använda pixeldimensioner som `1024x1024`.
`flux-2-klein` stöder endast generering och ingår inte bland de valbara modellerna i `flux_edit_image`.

`flux_generate_video` skiljer mellan `t2v`、`i2v`、`v2v` och
`draft_enhance` via `request.mode`, och indata visas beroende på läge. Utkastsförbättring måste referera till sitt eget tillfälliga `draft_task_id`.
Inskick är som standard asynkront, behåll det returnerade uppgifts-ID:t och använd `flux_get_task` för att läsa resultatet.
