[MCP (Model Context Protocol)](https://modelcontextprotocol.io) är ett modellkontextprotokoll lanserat av Anthropic som tillåter AI-modeller (som Claude, GPT med flera) att anropa externa verktyg via ett standardiserat gränssnitt. Genom Veo MCP Server som tillhandahålls av AceData Cloud kan du direkt använda Google Veo för att generera AI-videor i AI-klienter som Claude Desktop, VS Code, Cursor med flera.

## Funktionsöversikt

Veo MCP Server erbjuder följande kärnfunktioner:

- **Text till video** — generera högkvalitativa videor från textpromptar
- **Bild till video** — skapa videor baserat på bilder
- **Stöd för flera modeller** — stöd för veo3, veo2, veo31-fast-ingredients med flera
- **Flera upplösningar** — stöd för 4K, 1080p, GIF och andra utdataformat
- **Flera bildförhållanden** — stöd för 16:9, 9:16 med flera proportioner
- **1080p uppgradering** — uppgradera redan genererade videor till 1080p
- **Uppgiftsförfrågningar** — övervaka genereringsstatus och hämta resultat

## Förberedelser

Innan användning behöver du skaffa en AceData Cloud API Token:

1. Registrera dig eller logga in på [AceData Cloud-plattformen](https://platform.acedata.cloud)
2. Gå till sidan för [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos)
3. Klicka på „Acquire“ för att erhålla en API Token (första gången får du en gratis kvot)

## Installation och konfiguration

### Metod 1: pip-installation (rekommenderas)

```bash
pip install mcp-veo
```

### Metod 2: Installation från källkod

```bash
git clone https://github.com/AceDataCloud/VeoMCP.git
cd VeoMCP
pip install -e .
```

Efter installation kan du starta tjänsten med kommandot `mcp-veo`.

## Användning i Claude Desktop

Redigera Claude Desktops konfigurationsfil:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lägg till följande konfiguration:

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "din API Token"
      }
    }
  }
}
```

Om du använder `uvx` (ingen förhandsinstallation av paket krävs):

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "din API Token"
      }
    }
  }
}
```

Spara konfigurationen och starta om Claude Desktop för att kunna använda Veo-relaterade verktyg i konversationer.

## Tillgängliga verktyg

| Verktygsnamn           | Beskrivning                      |
|-----------------------|---------------------------------|
| `veo_text_to_video`    | Genererar video från textprompt |
| `veo_image_to_video`   | Skapar video baserat på bild    |
| `veo_get_1080p`        | Uppgraderar video till 1080p    |
| `veo_get_task`         | Hämtar status för en enskild uppgift |
| `veo_get_tasks_batch`  | Hämtar status för flera uppgifter |

## Användningsexempel

När konfigurationen är klar kan du direkt i AI-klienten använda naturligt språk för att anropa funktionerna, till exempel:

- „Hjälp mig att generera en timelapse-video av stjärnhimlen med Veo“
- „Skapa en 4K-video från denna landskapsbild“
- „Generera en kort video i stående 9:16-format“
- „Uppgradera denna video till 1080p“
