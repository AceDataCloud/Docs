[MCP (Model Context Protocol)](https://modelcontextprotocol.io) är en modellkontextprotokoll som lanserats av Anthropic, vilket tillåter AI-modeller (som Claude, GPT, etc.) att anropa externa verktyg via standardiserade gränssnitt. Genom Suno MCP Server som tillhandahålls av AceData Cloud kan du direkt generera musik, texter och hantera ljudprojekt i AI-klienter som Claude Desktop, VS Code, Cursor, etc.

## Funktionsöversikt

Suno MCP Server erbjuder följande kärnfunktioner:

- **Musikgenerering** — Generera AI-musik genom textpromptar
- **Anpassad skapelse** — Full kontroll över texter, titlar och musikstilar
- **Låtförlängning** — Fortsätt en befintlig låt från valfri tidpunkt
- **Cover/remix** — Skapa coverversioner i olika stilar
- **Textgenerering** — Generera strukturerade texter baserat på beskrivningar
- **Röstroller** — Spara och återanvända röststilar
- **Mediekonvertering** — Få MP4, WAV, MIDI, röstseparation, etc.
- **Stiloptimering** — Optimera musikstiltaggar
- **Uppgiftsfråga** — Övervaka genereringsprocessen och få resultat

## Förberedelser

Innan användning behöver du skaffa ett AceData Cloud API-token:

1. Registrera dig eller logga in på [AceData Cloud-plattformen](https://platform.acedata.cloud)
2. Gå till sidan [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Klicka på "Acquire" för att få API-token (första ansökan ger gratis kvot)

## Installationskonfiguration

### Metod 1: pip-installation (rekommenderas)

```bash
pip install mcp-suno
```

### Metod 2: Källkodinstallation

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

När installationen är klar kan du använda kommandot `mcp-suno` för att starta tjänsten.

## Använda i Claude Desktop

Redigera konfigurationsfilen för Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lägg till följande konfiguration:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ditt API-token"
      }
    }
  }
}
```

Om du använder `uvx` (ingen förinstallation av paket krävs):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ditt API-token"
      }
    }
  }
}
```

Spara konfigurationen och starta om Claude Desktop för att använda Suno-relaterade verktyg i dialogen.

## Tillgängliga verktyg

| Verktygsnamn                     | Beskrivning           |
| ---------------------------- | ------------------- |
| `suno_generate_music`        | Generera musik genom textpromptar  |
| `suno_generate_custom_music` | Anpassa texter och stil för musik |
| `suno_extend_music`          | Fortsätt låten från en angiven tidpunkt   |
| `suno_cover_music`           | Skapa en coverversion       |
| `suno_concat_music`          | Sätta ihop låtklipp       |
| `suno_generate_with_persona` | Generera musik med angiven röstroll |
| `suno_remaster_music`        | Remastra låten       |
| `suno_stems_music`           | Separera ljudspår (röst/ackompanjemang)  |
| `suno_replace_section`       | Byt ut en specifik del av låten   |
| `suno_upload_extend`         | Ladda upp ljud och fortsätt skriva      |
| `suno_upload_cover`          | Ladda upp ljud och göra en cover      |
| `suno_mashup_music`          | Blanda flera låtar       |
| `suno_generate_lyrics`       | Generera texter baserat på beskrivningar     |
| `suno_create_persona`        | Skapa en röstroll       |
| `suno_get_mp4`               | Hämta låtens MP4-video  |
| `suno_get_timing`            | Hämta textens tidslinje      |
| `suno_extract_vocals`        | Extrahera röst         |
| `suno_get_wav`               | Hämta högkvalitativ WAV    |
| `suno_get_midi`              | Hämta MIDI-fil   |
| `suno_optimize_style`        | Optimera musikstiltaggar     |
| `suno_mashup_lyrics`         | Blanda texter         |
| `suno_upload_audio`          | Ladda upp anpassat ljud      |
| `suno_get_task`              | Fråga om status för enskild uppgift     |
| `suno_get_tasks_batch`       | Batchfråga uppgiftsstatus     |

## Användningsexempel

När konfigurationen är klar kan du direkt använda naturligt språk för att anropa dessa funktioner i AI-klienten, till exempel:

- "Hjälp mig att generera en poplåt om sommaren"
- "Gör en jazzcover av den här låten"
- "Fortsätt skriva den här låten från 30 sekunder"
- "Generera en låttext på kinesiska med temat resor"
- "Separera sången från den här låten"
- "Hjälp mig att konvertera den här låten till MIDI-format"
