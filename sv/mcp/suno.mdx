[MCP (Model Context Protocol)](https://modelcontextprotocol.io) är ett modellkontextprotokoll lanserat av Anthropic, som tillåter AI-modeller (såsom Claude, GPT osv.) att anropa externa verktyg via standardiserade gränssnitt. Genom Suno MCP Server som tillhandahålls av AceData Cloud kan du direkt generera musik och låttexter samt hantera ljudprojekt i AI-klienter som Claude Desktop, VS Code och Cursor.

## Funktionsöversikt

Suno MCP Server erbjuder följande kärnfunktioner:

- **Musikgenerering** — Generera AI-musik med textprompter
- **Anpassat skapande** — Fullständig kontroll över låttexter, titlar och musikstil
- **Fortsätt skriva låtar** — Fortsätt förlänga befintliga låtar från valfri tidpunkt
- **Covers/remixer** — Skapa coverversioner i olika stilar
- **Låttextgenerering** — Generera strukturerade låttexter baserat på beskrivningar
- **Sångroller** — Spara och återanvänd röststilar
- **Mediakonvertering** — Hämta MP4, WAV, MIDI, sångseparering osv.
- **Stiloptimering** — Optimera taggar för musikstil
- **Uppgiftsfrågor** — Övervaka genereringsförloppet och hämta resultat

## Förberedelser

Innan användning behöver du hämta en AceData Cloud API-token:

1. Registrera dig eller logga in på [AceData Cloud-plattformen](https://platform.acedata.cloud)
2. Gå till sidan [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Klicka på ”Acquire” för att hämta en API-token (vid första ansökan får du gratis krediter)

## Metod ett: Använd en värdbaserad MCP Server (rekommenderas, ingen installation)

AceData Cloud har redan värdbaserat **Suno MCP Server** i molnet, **utan behov av att installera några lokala beroenden**. Fyll bara i följande URL i AI-klienten för att använda den:

```
https://suno.mcp.acedata.cloud/mcp
```

Autentiseringsmetod: Lägg bara till `Authorization: Bearer din API-token` i request-headern (Claude.ai slutför detta automatiskt via OAuth, utan att du behöver fylla i token manuellt).

### Claude.ai (webbversion, OAuth-inloggning, enklast)

1. Öppna [Claude.ai](https://claude.ai) → **Customize** längst ned till vänster → **Connectors** → **Add More**
2. Fyll i följande vid URL: `https://suno.mcp.acedata.cloud/mcp`
3. Slutför OAuth-auktoriseringsinloggningen (omdirigeras automatiskt till AceData Clouds inloggningssida)
4. Återgå till konversationsgränssnittet, så kan verktyget användas

### Claude Desktop

Redigera konfigurationsfilen:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Starta om Claude Desktop efter att du har sparat för att aktivera ändringarna.

### Claude Code (kommandorad i terminal)

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Andra klienter som stöder MCP

Alla klienter som stöder MCP Streamable HTTP-protokollet (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant osv.) kan integreras genom att fylla i följande två uppgifter:

## Metod två: Kör lokalt (installation via pip / uvx)

Om du behöver köra offline, anpassa koden eller distribuera till ett internt nätverk kan du installera MCP Server lokalt och starta den via stdio.

### Installation

Installation med pip (rekommenderas):

```bash
pip install mcp-suno
```

Eller installation från källkod:

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

Efter installationen kan du använda kommandot `mcp-suno` för att starta tjänsten.

### Använd i Claude Desktop (lokalt)

Redigera Claude Desktops konfigurationsfil:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lägg till följande konfiguration:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Om du använder `uvx` (utan att behöva installera paketet i förväg):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Starta om Claude Desktop efter att du har sparat konfigurationen för att aktivera ändringarna.

## Avancerad kontroll och Studio-projekt

`suno_generate_music` har stöd för `variety`; `suno_generate_custom_music` har dessutom stöd för
`max_mode` och `audio_weight`. `max_mode` använder en högre API-prisnivå, är inte aktiverat som standard
och bör ställas in efter att användaren uttryckligen har valt förbättrat läge. Aktuella priser anges på plattformens tjänstsida.

`suno_generate_with_custom_model` kan använda `instrumental=true` för att generera instrumentalmusik, eller använda
`lyric_prompt` för att automatiskt generera låttexter; annars tillhandahålls `lyric`. Titel och stil kan utelämnas, och du kan även skicka
`negative_tags`, `vocal_gender`, `weirdness`, `style_influence`, `duration` och
`callback_url`. Explicit angivna kontrollvärden på `0` behålls.

`suno_manage_project`s `request.action` kan vara `create`, `retrieve`, `save`,
`upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`,
`remove_track` eller `render`. Indata skiljer sig åt beroende på åtgärd, och projektändringar bör använda det senast återlästa `version_id`;
vid sparande ska fullständigt `state` skickas, med befintliga spår och fält bevarade.

Förutom `retrieve` måste varje anrop ange `idempotency_key`. Använd en ny nyckel för nya skrivåtgärder;
vid tidsgräns eller osäkert mottagningsresultat ska du behålla den ursprungliga nyckeln och försöka igen med exakt samma begäran, eller kontrollera den ursprungliga uppgiften, och inte automatiskt
byta nyckel och skicka om avgiftsbelagd generering. Källjudsintervall använder sekunder, och projektets tidslinjeintervall använder taktslag. Generering skapar endast kandidater;
du måste välja en kandidat och anropa `commit_candidate` för att den ska skrivas till spåret.

Det asynkront mottagna `task_id` kontrolleras med `suno_get_task`. Fortsätt vänta när `finished_at` är tomt,
och kontrollera `response.success` och fel efter slutstatus; betrakta inte lyckad mottagning som att generering, incheckning eller export har lyckats.
`suno_get_tasks_batch` returnerar fullständiga JSON-uppgiftsposter och bevarar objekt för anpassade modeller, projektstatus,
kandidater och alla typer av resultat, inklusive MIDI. Se [guiden för Studio-projekt](https://platform.acedata.cloud/documents/suno-projects-integration) för det fullständiga arbetsflödet.
