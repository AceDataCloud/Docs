[MCP (Model Context Protocol)](https://modelcontextprotocol.io) är ett modellkontextprotokoll som lanserats av Anthropic och som gör det möjligt för AI-modeller (som Claude, GPT osv.) att anropa externa verktyg via standardiserade gränssnitt. Genom Seedance MCP Server som tillhandahålls av AceData Cloud kan du direkt använda ByteDances Seedance för att generera AI-videor i AI-klienter som Claude Desktop, VS Code och Cursor.

## Funktionsöversikt

Seedance MCP Server erbjuder följande kärnfunktioner:

- **Text-till-video** — Generera högkvalitativa videor via textpromptar
- **Bild-till-video** — Generera videor med bilder som referens (lägen som första bildruta, sista bildruta, referensbild osv.)
- **Stöd för flera modeller** — Stöd för Seedance 1.x, 1.5, 2.0 och 2.5
- **Flera upplösningar** — Stöd för 480p, 720p, 1080p, och vissa modeller har stöd för 4k
- **Flera bildformat** — Stöd för 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 och adaptive
- **Flexibel längd** — 2–30 sekunder eller automatisk längd beroende på modellens stöd
- **Multimodal video** — Stöd för ljudgenerering, referensljud/-video samt videoredigering och förlängning i 2.5
- **Uppgiftsfrågor** — Övervaka genereringsförloppet och hämta resultat

## Rekommenderat: OAuth-auktorisering för hanterad MCP

Lägg till serveradressen i klienter som stöder OAuth för fjärr-MCP:

```text
https://seedance.mcp.acedata.cloud/mcp
```

Välj anslut eller logga in, logga in på Ace Data Cloud, granska behörigheterna och auktorisera, och aktivera sedan verktygen. Denna väg kräver inte att du först skapar eller kopierar en API-token. Tjänsten stöder OAuth discovery, dynamisk klientregistrering (DCR) och S256 PKCE; DCR registrerar klienten, användaren måste fortfarande logga in och auktorisera, och API-användning debiteras som vanligt.

| Klient                            | Anslutningsmetod och villkor                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Claude webbversion eller Desktop-versioner som erbjuder fjärranslutningar | Lägg till ovanstående adress i anslutningsgränssnittet och auktorisera; åtkomsten beror på version och abonnemang. Skriv inte fjärr-HTTP-konfiguration i lokala stdio-konfigurationsfiler.                      |
| VS Code med stöd för inbyggd OAuth för fjärr-MCP     | Kör **MCP: Add Server**, välj HTTP, fyll i adressen och logga in enligt anvisningarna; det dedikerade AceDataCloud-tillägget använder en separat API Key-inställning. |
| Andra klienter                          | Bekräfta att den aktuella versionen stöder fjärr-HTTP, OAuth/DCR, och använd den klientens konfigurationsanvisningar. Konfigurationsfilformat kan inte användas gemensamt mellan olika klienter.                     |

## Alternativ väg med API-token

Lokal stdio, självhosting eller klienter som inte stöder fjärr-OAuth använder API-token. Logga in på [Ace Data Cloud-plattformen](https://platform.acedata.cloud), välj tjänst och skapa API-autentiseringsuppgifter med nödvändiga behörigheter. Spara token i klientens autentiseringsinställningar eller lokala miljövariabler, och lägg den inte i URL:er, chattinnehåll eller versionsarkiv. HTTP Header-konfiguration för olika klienter ska fyllas i enligt anvisningarna för deras versioner.

Installation av MCP med öppen källkod eller slutförd auktorisering innebär inte att du får fria kvoter, och garanterar inte genereringstid eller kommersiella användningsrättigheter. Kontrollera aktuella tjänstepriser, saldo och tillämpliga villkor före generering.

## Metod två: Kör lokalt (installation med pip / uvx)

Om du behöver lokal stdio, anpassad kod eller självhosting kan du starta MCP Server lokalt. Genereringen behöver fortfarande anropa API:et via nätverket och är inte offline-inferens.

### Installation

Installation med pip (rekommenderas):

```bash
pip install mcp-seedance
```

Eller installation från källkod:

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Efter installationen kan du använda kommandot `mcp-seedance` för att starta tjänsten.

### Användning i Claude Desktop (lokalt)

Redigera Claude Desktops konfigurationsfil:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lägg till följande konfiguration:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "din API-token"
      }
    }
  }
}
```

Om du använder `uvx` (utan att behöva installera paketet i förväg):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "din API-token"
      }
    }
  }
}
```

Starta om Claude Desktop efter att ha sparat konfigurationen för att den ska träda i kraft.

### Användning i VS Code (lokalt)

Skapa `.vscode/mcp.json` i projektets rotkatalog:

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "din API-token"
      }
    }
  }
}
```

Eller använd `uvx`:

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "din API-token"
      }
    }
  }
}
```

För andra lokala klienter, fyll i command, args och env enligt stdio-konfigurationsanvisningarna för deras aktuella versioner; använd inte VS Codes konfiguration direkt som ett allmänt format.

## Verifiera resultat och vanliga fel

Be klienten att generera ett enkelt videoverk, behåll uppgiftsnumret och fråga efter samma uppgift tills slutstatusen är lyckad, och öppna eller spela sedan upp den slutliga länken. Lyckad anslutning, laddad verktygslista, HTTP 200, uppgiftsnummer och förhandsvisning under bearbetning representerar inte den slutliga produkten.

Vid 401, logga in igen eller kontrollera token och behörigheter; vid otillräckligt saldo, kontrollera faktureringen; fortsätt fråga när uppgiften bearbetas; vid slutligt fel, läs felet och avgör om du ska försöka igen, eftersom en ny generering kan debiteras på nytt.

## Lista över tillgängliga verktyg

| Verktygsnamn                                  | Beskrivning             |
| ------------------------------------ | -------------- |
| `seedance_generate_video`            | Generera video via textpromptar    |
| `seedance_generate_video_from_image` | Generera video med en bild som referens     |
| `seedance_get_task`                  | Fråga efter status för en enskild uppgift       |
| `seedance_get_tasks_batch`           | Fråga efter uppgiftsstatus i batch       |
| `seedance_list_models`               | Lista alla tillgängliga modeller och deras funktioner   |
| `seedance_list_resolutions`          | Lista tillgängliga upplösningar och bildformat   |
| `seedance_list_actions`              | Lista alla tillgängliga verktyg och arbetsflödesexempel |

## Användningsexempel

När konfigurationen är klar kan du direkt anropa dessa funktioner med naturligt språk i AI-klienten, till exempel:

- 「Hjälp mig att använda Seedance för att generera en time-lapse-video av en stadsgata」
- 「Använd detta foto som första bildruta och generera en 8 sekunder lång video」
- 「Generera en kortvideo i 1080p, vertikalt 9:16-format」
- 「Använd modellen Seedance 1.5 Pro för att generera en video med ljud」
