[MCP (Model Context Protocol)](https://modelcontextprotocol.io) är en modellkontextprotokoll som lanserats av Anthropic, vilket tillåter AI-modeller (som Claude, GPT etc.) att anropa externa verktyg via standardiserade gränssnitt. Genom Nano Banana MCP Server som tillhandahålls av AceData Cloud kan du direkt generera och redigera AI-bilder i AI-klienter som Claude Desktop, VS Code, Cursor etc.

## Funktionsöversikt

Nano Banana MCP Server erbjuder följande kärnfunktioner:

- **Bildgenerering** — Generera högkvalitativa bilder genom textpromptar
- **Bilderedigering** — Modifiera befintliga bilder eller kombinera flera bilder
- **Virtuell provning** — Klä på kläder på personbilder
- **Produktplacering** — Placera produkter i verkliga scenarier
- **Fler modellstöd** — Stöd för modellerna nano-banana, nano-banana-2 och nano-banana-pro
- **Uppgiftsfråga** — Övervaka genereringsprocessen och få resultat

## Förberedelser

Innan användning behöver du skaffa ett AceData Cloud API-token:

1. Registrera dig eller logga in på [AceData Cloud-plattformen](https://platform.acedata.cloud)
2. Gå till sidan [Nano Banana Images API](https://platform.acedata.cloud/documents/nano-banana-images)
3. Klicka på "Acquire" för att få API-token (första ansökan ger gratis kvot)

## Installationskonfiguration

### Metod ett: pip-installation (rekommenderas)

```bash
pip install mcp-nanobanana-pro
```

### Metod två: källkodinstallation

```bash
git clone https://github.com/AceDataCloud/NanoBananaMCP.git
cd NanoBananaMCP
pip install -e .
```

När installationen är klar kan du använda kommandot `mcp-nanobanana-pro` för att starta tjänsten.

## Använda i Claude Desktop

Redigera konfigurationsfilen för Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lägg till följande konfiguration:

```json
{
  "mcpServers": {
    "nanobanana": {
      "command": "mcp-nanobanana-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ditt API-token"
      }
    }
  }
}
```

Om du använder `uvx` (ingen förinstallation av paket krävs):

```json
{
  "mcpServers": {
    "nanobanana": {
      "command": "uvx",
      "args": ["mcp-nanobanana-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ditt API-token"
      }
    }
  }
}
```

Spara konfigurationen och starta om Claude Desktop för att använda Nano Banana-relaterade verktyg i dialogen.

Skapa `.vscode/mcp.json` i projektets rotkatalog:

## Tillgänglig verktygslista

| Verktygsnamn                     | Beskrivning                |
| ---------------------------- | --------------------- |
| `nanobanana_generate_image`  | Generera bilder genom textpromptar |
| `nanobanana_edit_image`      | Redigera eller kombinera befintliga bilder |
| `nanobanana_get_task`        | Fråga om status för enskild uppgift |
| `nanobanana_get_tasks_batch` | Batchfråga om uppgiftsstatus |
