[MCP (Model Context Protocol)](https://modelcontextprotocol.io) är ett modellkontextprotokoll lanserat av Anthropic som tillåter AI-modeller (som Claude, GPT med flera) att anropa externa verktyg via ett standardiserat gränssnitt. Med ShortURL MCP Server från AceData Cloud kan du direkt generera korta länkar i AI-klienter som Claude Desktop, VS Code, Cursor med flera.

## Funktionsöversikt

ShortURL MCP Server erbjuder följande kärnfunktioner:

- **Kortlänk för enskild URL** — Konvertera långa URL:er till korta och lättdelade länkar
- **Batchkortlänk** — Kortlänka flera URL:er samtidigt (upp till 10 stycken)
- **Användarguide** — Få fullständig användardokumentation och bästa praxis
- **API-information** — Visa API-tjänstens detaljer och felkoder

## Förberedelser

Innan användning behöver du skaffa en AceData Cloud API-token:

1. Registrera dig eller logga in på [AceData Cloud-plattformen](https://platform.acedata.cloud)
2. Gå till sidan för [ShortURL API](https://platform.acedata.cloud/documents/short-url)
3. Klicka på "Acquire" för att få din API-token (första gången får du en gratis kvot)

## Installation och konfiguration

### Metod 1: pip-installation (rekommenderas)

```bash
pip install mcp-shorturl
```

### Metod 2: Installation från källkod

```bash
git clone https://github.com/AceDataCloud/ShortURLMCP.git
cd ShortURLMCP
pip install -e .
```

Efter installation kan du starta tjänsten med kommandot `mcp-shorturl`.

## Användning i Claude Desktop

Redigera Claude Desktops konfigurationsfil:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lägg till följande konfiguration:

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "din API-token"
      }
    }
  }
}
```

Om du använder `uvx` (ingen förhandsinstallation av paket krävs):

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "uvx",
      "args": ["mcp-shorturl"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "din API-token"
      }
    }
  }
}
```

Spara och starta om Claude Desktop för att börja använda ShortURL-verktygen i dina konversationer.

## Tillgängliga verktyg

| Verktygsnamn            | Beskrivning                          |
|------------------------|------------------------------------|
| `shorturl_create`       | Kortlänka en enskild URL            |
| `shorturl_batch_create` | Kortlänka flera URL:er (upp till 10) |
| `shorturl_get_usage_guide` | Hämta fullständig användarguide    |
| `shorturl_get_api_info` | Hämta API-tjänstens detaljer        |

## Exempel på användning

När konfigurationen är klar kan du använda dessa funktioner direkt i AI-klienten med naturligt språk, till exempel:

- "Kan du korta ner den här länken åt mig?"
- "Kortlänka dessa 5 URL:er i batch"
- "Generera en kort länk för att dela"
