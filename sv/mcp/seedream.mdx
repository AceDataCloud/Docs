[MCP (Model Context Protocol)](https://modelcontextprotocol.io) är ett modellkontextprotokoll lanserat av Anthropic, som tillåter AI-modeller (som Claude, GPT med flera) att anropa externa verktyg via ett standardiserat gränssnitt. Med Seedream MCP Server från AceData Cloud kan du direkt använda ByteDance Seedream för att generera och redigera AI-bilder i AI-klienter som Claude Desktop, VS Code, Cursor med flera.

## Funktionsöversikt

Seedream MCP Server erbjuder följande kärnfunktioner:

- **Text-till-bild** — Generera högkvalitativa bilder från textpromptar (stöd för både kinesiska och engelska)
- **Bildredigering** — Modifiera befintliga bilder med stil, bakgrund, attribut med mera
- **Virtuell provning** — Applicera kläder på personfoton
- **Stöd för flera modeller** — Stödjer Seedream v4.5, v4.0, v3.0 T2I, SeedEdit v3.0 I2I med flera
- **Flera upplösningar** — Stöd för 1K, 2K, 4K samt adaptiv upplösning
- **Seed-kontroll** — Reproducerbara resultat via seed-parameter
- **Uppgiftsförfrågan** — Övervaka genereringsstatus och hämta resultat

## Förberedelser

Innan användning behöver du skaffa en AceData Cloud API Token:

1. Registrera dig eller logga in på [AceData Cloud-plattformen](https://platform.acedata.cloud)
2. Gå till sidan för [Seedream Images API](https://platform.acedata.cloud/documents/seedream-images)
3. Klicka på "Acquire" för att få din API Token (första gången får du gratis kvot)

## Installation och konfiguration

### Metod 1: pip-installation (rekommenderas)

```bash
pip install mcp-seedream-pro
```

### Metod 2: Installation från källkod

```bash
git clone https://github.com/AceDataCloud/SeedreamMCP.git
cd SeedreamMCP
pip install -e .
```

Efter installation kan du starta tjänsten med kommandot `mcp-seedream-pro`.

## Användning i Claude Desktop

Redigera Claude Desktops konfigurationsfil:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lägg till följande konfiguration:

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "din API Token"
      }
    }
  }
}
```

Om du använder `uvx` (ingen förhandsinstallation av paket krävs):

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "din API Token"
      }
    }
  }
}
```

Spara konfigurationen och starta om Claude Desktop för att använda Seedream-verktygen i dialogen.

## Tillgängliga verktyg

| Verktygsnamn               | Beskrivning                    |
|---------------------------|-------------------------------|
| `seedream_generate_image` | Generera bild från textprompt |
| `seedream_edit_image`     | Redigera eller modifiera bild |
| `seedream_get_task`       | Fråga status för en uppgift   |
| `seedream_get_tasks_batch`| Batchfråga status för uppgifter|
| `seedream_list_models`    | Lista alla tillgängliga modeller och deras kapabiliteter |
| `seedream_list_sizes`     | Lista tillgängliga bildstorlekar och upplösningar |

## Exempel på användning

När konfigurationen är klar kan du direkt använda naturligt språk i AI-klienten för att anropa funktionerna, till exempel:

- "Hjälp mig att generera en kinesisk bläckmålning av landskap med Seedream"
- "Byt bakgrunden på detta foto till en stjärnhimmel"
- "Generera ett 4K högupplöst porträtt med Seedream v4.5"
- "Virtuellt prova denna klädsel på detta foto"
