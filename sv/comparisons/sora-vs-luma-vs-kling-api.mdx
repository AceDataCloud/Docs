Sora vs Luma vs Kling är populära AI-videogenererings-API-tjänster. De kan alla anropas via Ace Data Clouds enhetliga API-plattform, med samma autentiseringsmetod och anropssätt, utan att behöva integrera varje leverantörs API separat.

## Detaljerad analys

### Funktioner

Sora, Luma och Kling anropas alla via Ace Data Clouds enhetliga API med stöd för standard REST-gränssnitt och Bearer Token-autentisering.

**Sora** huvudsakliga endpoint är `POST https://api.acedata.cloud/sora/videos`, och stöder text-till-video, flera längder, liggande/stående orientering, karaktärskontroll med mera. Dessutom finns endpoints som `/sora/tasks`.

**Luma** huvudsakliga endpoint är `POST https://api.acedata.cloud/luma/videos`, och stöder text-till-video, bild-till-video, videoförlängning, kontroll av första och sista bildruta med mera. Dessutom finns endpoints som `/luma/tasks`.

**Kling** huvudsakliga endpoint är `POST https://api.acedata.cloud/kling/videos`, och stöder text-till-video, bild-till-video, videoförlängning, flera längder med mera. Dessutom finns endpoints som `/kling/tasks`, `/kling/motion`.

## Kodexempel

Följande exempel visar hur man anropar Sora, Luma och Kling via Ace Data Cloud API. Alla anrop använder samma bas-URL (`https://api.acedata.cloud`) och autentiseringsmetod.

### Anropa Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
},
)
print(response.json())
```
