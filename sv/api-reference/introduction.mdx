## Bas-URL

Basadressen för alla API-endpoints:

```
https://api.acedata.cloud
```

## Autentisering

Alla endpoints kräver Bearer Token-autentisering:

```
Authorization: Bearer YOUR_API_TOKEN
```

## Online testning

Varje endpoint i denna referens innehåller en interaktiv sandbox. Ange API-token för att testa förfrågningar direkt i webbläsaren.

<Note title="Tip">
  Hämta API-token på [platform.acedata.cloud](https://platform.acedata.cloud).
</Note>
