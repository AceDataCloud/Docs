## Översikt

AI-videogenerering utvecklas snabbt. Ace Data Cloud erbjuder 7 olika videogenererings-API:er som täcker olika scenarier från text-till-video till bild-till-video.

## Tillgängliga videogenereringstjänster

| Tjänst | Endpoint | Modell | Egenskaper |
|--------|----------|--------|------------|
| Sora   | `POST /sora/videos` | sora-2, sora-2-pro | Från OpenAI, filmkvalitet |
| Veo    | `POST /veo/videos` | veo3, veo3-fast | Från Google, stöd för 4K |
| Kling  | `POST /kling/videos` | kling-v2-5-turbo | Från Kuaishou, snabb hastighet |
| Luma   | `POST /luma/videos` | — | Kontroll av första och sista bildruta |
| Hailuo | `POST /hailuo/videos` | minimax-t2v | Från MiniMax |
| Seedance | `POST /seedance/videos` | doubao-seedance-1-0-pro-250528 | Från ByteDance |
| Wan    | `POST /wan/videos` | wan2.6-t2v | Från Alibaba |

## Kom igång snabbt

### Sora videogenerering

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A cat playing in a sunny garden",
        "model": "sora-2",
        "duration": 10,
        "orientation": "landscape",
    },
)
print(response.json())
```

### Kling videogenerering

```python
response = requests.post(
    "https://api.acedata.cloud/kling/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A white cat walking in the snow",
        "model": "kling-v2-5-turbo",
        "duration": 5,
        "aspect_ratio": "16:9",
    },
)
print(response.json())
```

## Asynkron uppgiftshantering

Videogenerering tar vanligtvis längre tid. Alla video-API:er stödjer:

1. **Callback-notifiering**: Ange `callback_url` i förfrågan för att automatiskt få resultatet när genereringen är klar  
2. **Polling**: Kontrollera uppgiftsstatus via `/tasks` endpoint

```python
# Använd callback-URL
data = {
    "prompt": "A sunrise over mountains",
    "model": "sora-2",
    "callback_url": "https://your-server.com/webhook",
}

# Eller pollning av uppgiftsstatus
task_response = requests.post("https://api.acedata.cloud/sora/tasks",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json={"task_id": "your-task-id"})
```

## Rekommendationer för val

- **Snabbaste hastighet**: Kling (kling-v2-5-turbo)  
- **Högsta upplösning**: Veo (stödjer 4K)  
- **Kontroll av första och sista bildruta**: Luma  
- **Bäst pris/prestanda**: Wan
