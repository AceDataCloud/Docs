## Introduktion till Suno

Suno är en av de mest kraftfulla AI-baserade musikgenereringsplattformarna idag. Genom Ace Data Clouds Suno API kan du enkelt generera högkvalitativ musik med några få API-anrop.

## API-endpoints

| Endpoint | Funktion |
|----------|----------|
| `POST /suno/audios` | Generera musik (huvudendpoint) |
| `POST /suno/lyrics` | Generera låttexter |
| `POST /suno/persona` | Hantera sångarstil |
| `POST /suno/wav` | Hämta WAV-format |
| `POST /suno/mp4` | Hämta MP4-format |
| `POST /suno/tasks` | Kontrollera uppgiftsstatus |

## Grundläggande generering

### Textbeskrivningsgenerering

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### Anpassad låttextsgenerering

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\n夏日的阳光洒满了海岸\n微风中传来浪花的声音\n\n[Chorus]\n让我们一起去远方\n追逐那自由的梦想",
        "style": "pop upbeat",
        "title": "夏日冒险",
    },
)
```

## Avancerade funktioner

### Fortsättning på låt

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### Generera låttexter

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "写一首关于冬天的歌",
    },
)
```

## Tillgängliga modeller

| Modell | Egenskaper |
|--------|------------|
| chirp-v5 | Senaste versionen, bästa ljudkvalitet |
| v4-5-plus | Förbättrad version |
| v4-5 | Stabil version |
| v4 | Klassisk version |
