## Vad är MCP

Model Context Protocol (MCP) är ett öppet protokoll som tillåter AI-assistenter (som Claude, Cursor) att direkt anropa externa verktyg och API:er. Med MCP kan AI inte bara svara på frågor utan också utföra faktiska operationer.

## MCP Server som erbjuds av Ace Data Cloud

| MCP Server       | PyPI-paketnamn     | Funktion          |
|------------------|--------------------|-------------------|
| MCPSuno          | mcp-suno           | AI-musikgenerering|
| MCPSerp          | mcp-serp           | Google-sökning    |
| MCPMidjourney    | mcp-midjourney     | AI-bildgenerering |
| MCPLuma          | mcp-luma           | AI-videogenerering|
| MCPSora          | mcp-sora           | AI-videogenerering|
| MCPVeo           | mcp-veo            | AI-videogenerering|
| MCPNanoBanana    | mcp-nano-banana    | AI-bildgenerering |

## Installation och användning

### Installation

```bash
pip install mcp-suno  # eller annan MCP Server
```

### Konfigurera miljövariabler

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### Konfigurera i Cursor

Lägg till i Cursors MCP-inställningar:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### Konfigurera i Claude Desktop

Redigera Claude Desktops konfigurationsfil och lägg till MCP Server-konfiguration.

## Användningsscenarier

1. **Generera musik i Cursor**: Säg till AI "generera en glad låt med Suno", AI anropar API direkt  
2. **Sök aktuell information**: AI kan söka senaste information via SERP MCP Server  
3. **Generera projektmaterial**: AI kan anropa Midjourney för att skapa bilder som behövs i projektet

## MCP vs direkt API-anrop

- **MCP**: passar för användning i AI-programmeringsverktyg, anropas automatiskt av AI  
- **API**: passar för integration i egna applikationer med programmeringskontroll

Båda använder samma Ace Data Cloud API-token och anropar samma API-endpoints i botten.

## Sammanfattning

MCP gör det möjligt för AI-assistenter att direkt anropa olika API:er från Ace Data Cloud. Alla MCP-servrar finns publicerade på PyPI, installation och konfiguration är enkel och gör dina AI-verktyg kraftfullare.

Besök [platform.acedata.cloud](https://platform.acedata.cloud) för att skaffa API-token.
