Germey Technology, LLC (hädanefter "vi" eller "vår"), företaget bakom Ace Data Cloud, är engagerade i att skydda din integritet. Denna integritetspolicy förklarar hur vi samlar in, använder, avslöjar och skyddar din information när du besöker vår Ace Data Cloud webbplatsplattform. Vänligen läs denna integritetspolicy noggrant. Genom att använda denna plattform godkänner du villkoren i denna integritetspolicy.

## Information vi samlar in

Vi samlar in olika typer av information för att tillhandahålla och förbättra våra tjänster:

1. **Personlig information**: Information som kan användas för att identifiera dig, såsom ditt namn, e-postadress, telefonnummer, betalningsinformation och annan liknande data.

2. **Icke-personlig information**: Information som inte kan användas för att identifiera dig, inklusive men inte begränsat till din IP-adress, webbläsartyp, operativsystem, hänvisande URL och relaterad information om din användning av vår plattform.

3. **Teknisk data**: Data om din användning av våra API:er, inklusive antal förfrågningar, typer av förfrågade data och relaterad metadata.

## Användningsändamål

Den information vi samlar in används för följande ändamål:

1. **Tillhandahålla och underhålla tjänster**: Driva och underhålla vår plattform, inklusive att hantera transaktioner och erbjuda kundsupport.

2. **Förbättra vår plattform**: Förstå hur du använder vår plattform och förbättra och förstärka funktioner och användarupplevelse.

3. **Kommunicera med dig**: Skicka uppdateringar, marknadsföringsmaterial och annan information som kan vara av intresse för dig. Du kan när som helst välja att avregistrera dig från dessa kommunikationer.

4. **Säkerställa säkerhet**: Övervaka och analysera användning och aktivitetsmönster för att säkerställa plattformens säkerhet och integritet.

5. **Efterleva rättsliga skyldigheter**: Följa tillämpliga lagar, förordningar och rättsliga förfaranden.

## Informationsdelning

Vi kan avslöja din information under följande omständigheter:

1. **Tjänsteleverantörer**: Vi kan dela din information med tredje parts tjänsteleverantörer som agerar på våra vägnar för att tillhandahålla tjänster, såsom betalningshantering, dataanalys, e-postutskick, hostingtjänster och kundsupport.

2. **Rättsliga krav**: Om lagen kräver det eller som svar på giltiga förfrågningar från offentliga myndigheter (t.ex. domstolar eller statliga organ) kan vi avslöja din information.

3. **Affärsöverföringar**: Vid sammanslagningar, försäljning av företags tillgångar, finansiering eller försäljning av hela eller delar av vår verksamhet till ett annat företag, eller under förhandlingar om sådana transaktioner, kan vi avslöja eller överföra din information.

4. **Ditt samtycke**: Med ditt uttryckliga samtycke kan vi avslöja din information för andra ändamål.

## Säkerhetsåtgärder

Vi implementerar rimliga säkerhetsåtgärder för att skydda din information från obehörig åtkomst, användning, ändring och avslöjande. Dessa åtgärder inkluderar:

1. **Datakryptering**: Vi använder branschstandardiserad krypteringsteknik för att skydda data som överförs till och från vår plattform.

2. **Åtkomstkontroll**: Endast auktoriserad personal som behöver tillgång till din personliga information för att utföra sina arbetsuppgifter har sådan åtkomst.

3. **Regelbunden revision**: Vi genomför regelbundna revisioner av våra säkerhetssystem och processer för att säkerställa efterlevnad av branschstandarder och bästa praxis.

4. **Säker lagring**: Vi lagrar personlig information i en säker miljö för att förhindra obehörig åtkomst, användning eller avslöjande.

### Dina rättigheter

Du har rätt att:

1. **Få tillgång till din information**: Begära tillgång till den personliga information vi innehar om dig.

2. **Korrigera din information**: Begära rättelse av felaktig eller ofullständig personlig information.

3. **Radera din information**: Under vissa lagstadgade undantag kan du begära att din personliga information raderas. Om du vill radera din information, vänligen kontakta vårt supportteam på office@acedata.cloud.

4. **Avregistrera dig**: Välja att avregistrera dig från att ta emot våra marknadsföringsmeddelanden genom att följa avregistreringsinstruktionerna som finns i dessa meddelanden.

## Google API-tjänsters användardatapolicy (Begränsad användning)

När du väljer att ansluta Ace Data Cloud till Google-tjänster (inklusive Google Workspace API, Google Drive, Gmail, Google Calendar med flera) följer vi fullt ut [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy) för all information mottagen från Google API:er, inklusive kraven för **Begränsad användning (Limited Use)**. Specifikt:

1. **Endast för funktioner du begär**: Vi får endast åtkomst till dina Google-data när du aktivt begär och aktiverar en funktion (t.ex. läsa dina Drive-filer, skicka kalenderinbjudningar, organisera Gmail-meddelanden) och endast för att möjliggöra just den funktionen.

2. **Ej för annonsering**: Vi använder aldrig data från Google API för annonsering, annonsinriktning eller tredjepartsmarknadsföring.

3. **Ej försäljning till tredje part**: Vi säljer aldrig användardata erhållna från Google API.

4. **Ej överföring till tredje part**: Vi överför inte data från Google API till andra parter, förutom i följande fall: (a) när det är nödvändigt för att tillhandahålla eller förbättra funktioner direkt riktade till användare; (b) för säkerhetsändamål (t.ex. utredning av missbruk); (c) för att följa tillämplig lag; eller (d) som en del av en sammanslagning, förvärv eller försäljning av tillgångar, och med användarens bekräftade samtycke.

5. **Ingen manuell läsning**: Vi tillåter inte någon manuell granskning av data från Google API, om inte: (a) du uttryckligen samtyckt; (b) för säkerhetsändamål (t.ex. utredning av missbruk); (c) för att följa tillämplig lag; eller (d) data har aggregerats och anonymiserats för intern drift.

Om du vill återkalla Ace Data Clouds åtkomst till ditt Google-konto när som helst kan du göra det via sidan [Google-kontoanslutna appar](https://myaccount.google.com/connections).
