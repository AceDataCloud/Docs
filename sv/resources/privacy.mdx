title: "Integritetspolicy"
---

Germey Technology, LLC (hädanefter "vi" eller "våra"), företaget bakom Ace Data Cloud, är engagerat i att skydda din integritet. Denna integritetspolicy förklarar hur vi samlar in, använder, avslöjar och skyddar din information när du besöker vår Ace Data Cloud-webbplatsplattform. Vänligen läs denna integritetspolicy noggrant. Genom att använda denna plattform godkänner du villkoren i denna integritetspolicy.

## Informationen vi samlar in

Vi samlar in olika typer av information för att kunna tillhandahålla och förbättra våra tjänster:

1. **Personlig information**: Information som kan användas för att identifiera dig, såsom ditt namn, e-postadress, telefonnummer, betalningsinformation och annan liknande data.
2. **Icke-personlig information**: Information som inte kan användas för att identifiera dig, inklusive men inte begränsat till din IP-adress, webbläsartyp, operativsystem, referens-URL och information relaterad till din användning av vår plattform.
3. **Teknisk data**: Data om din användning av vår API, inklusive antal förfrågningar, typ av förfrågningsdata och relaterad metadata.

## Användningsändamål

Den information vi samlar in används för följande olika ändamål:

1. **Tillhandahålla och underhålla tjänster**: Driva och underhålla vår plattform, inklusive att behandla transaktioner och tillhandahålla kundsupport.
2. **Förbättra vår plattform**: Förstå hur du använder vår plattform och förbättra och förstärka funktioner och användarupplevelse.
3. **Kommunicera med dig**: Skicka uppdateringar, marknadsföringsmaterial och annan information som kan vara av intresse för dig. Du kan när som helst välja att avregistrera dig från dessa kommunikationer.
4. **Säkerställa säkerhet**: Övervaka och analysera användning och aktivitetstrender för att säkerställa säkerheten och integriteten för vår plattform.
5. **Följa lagliga skyldigheter**: Följa tillämpliga lagar, förordningar och rättsliga procedurer.

## Informationsavslöjande

Vi kan avslöja din information under följande omständigheter:

1. **Tjänsteleverantörer**: Vi kan dela din information med tredje parts tjänsteleverantörer som agerar på våra vägnar för att tillhandahålla tjänster, såsom betalningsbehandling, dataanalys, e-postutskick, hostingtjänster och kundsupport.
2. **Lagliga krav**: Om lagen kräver det eller som svar på giltiga förfrågningar från offentliga myndigheter (t.ex. domstolar eller statliga organ) kan vi avslöja din information.
3. **Affärsöverföring**: Vid en eventuell sammanslagning, försäljning av företags tillgångar, finansiering eller försäljning av hela eller delar av vår verksamhet till ett annat företag, eller under förhandlingar om sådana transaktioner, kan vi avslöja eller överföra din information.
4. **Ditt samtycke**: Med ditt uttryckliga samtycke kan vi avslöja din information för andra ändamål.

## Säkerhetsåtgärder

Vi implementerar rimliga säkerhetsåtgärder för att skydda din information mot obehörig åtkomst, användning, ändring och avslöjande. Dessa åtgärder inkluderar:

1. **Data kryptering**: Vi använder branschstandard krypteringstekniker för att skydda data som överförs till och från vår plattform.
2. **Åtkomstkontroll**: Åtkomst till din personliga information är begränsad till behörig personal som behöver denna information för att utföra sina arbetsuppgifter.
3. **Regelbundna revisioner**: Vi genomför regelbundna revisioner av våra säkerhetssystem och processer för att säkerställa efterlevnad av branschstandarder och bästa praxis.
4. **Säker lagring**: Vi lagrar personlig information i en säker miljö för att förhindra obehörig åtkomst, användning eller avslöjande.

### Dina rättigheter

Du har rätt att:

1. **Få tillgång till din information**: Begära tillgång till den personliga information vi har om dig.
2. **Korrigera din information**: Begära korrigering av eventuell felaktig eller ofullständig personlig information.
3. **Radera din information**: Under vissa lagstadgade undantag kan du begära att din personliga information raderas. Om du vill radera din information, vänligen kontakta vårt supportteam - office@acedata.cloud.
4. **Avregistrera dig**: Välja att avregistrera dig från att ta emot våra marknadsföringskommunikationer genom att följa avregistreringsanvisningarna som ingår i dessa kommunikationer.

## Ändringar i denna integritetspolicy

Vi kan uppdatera denna integritetspolicy från tid till annan. Vi kommer att publicera en ny integritetspolicy på plattformen för att informera dig om eventuella ändringar. Vi rekommenderar att du regelbundet kontrollerar eventuella ändringar i denna integritetspolicy. Ändringar i denna integritetspolicy träder i kraft vid publicering.
