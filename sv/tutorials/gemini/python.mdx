## Introduktion

Gemini är en AI-chattjänst från Ace Data Cloud, baserad på Googles Gemini-serie av stora språkmodeller. Genom Ace Data Clouds enhetliga API kan du snabbt integrera Gemini med Python och använda funktioner som flerrundiga konversationer, systempromptar, strömmande utdata och JSON-utmatningsläge.

## Förutsättningar

- Ett konto hos [Ace Data Cloud](https://platform.acedata.cloud) och en API-token
- Python 3.7 eller senare
- Installera requests-biblioteket: `pip install requests`

## Grundläggande användning

Huvudendpoint för att anropa Gemini API är:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

I detta exempel används modellen `gemini-2.5-flash`.
Tillgängliga modeller inkluderar: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Fullständigt Python-exempel:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gemini-2.5-flash",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Byt ut `YOUR_API_TOKEN` mot din faktiska token från Ace Data Cloud-plattformen.

## Hantering av svar

Vid lyckad anrop returnerar API:et data i JSON-format. Det rekommenderas att kontrollera HTTP-statuskoden:

```python
if response.status_code == 200:
    result = response.json()
    print("Anrop lyckades:", result)
else:
    print(f"Anrop misslyckades, statuskod: {response.status_code}")
    print(response.text)
```

## Avancerad användning

För chatt-API:er stöds strömmande utdata för att få realtidsrespons:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Felhantering

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräcklig saldo eller åtkomst nekad |
| 429       | Överskriden anropsfrekvens |
| 500       | Intern serverfel |
