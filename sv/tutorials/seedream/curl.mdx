## Introduktion

Seedream är en AI-bildtjänst som tillhandahålls av Ace Data Cloud, med ByteDance Seedream bildgenereringsmodell. Genom Ace Data Cloud:s enhetliga API kan du snabbt anropa Seedream med cURL för att skapa bilder från text, redigera bilder, använda olika upplösningar, kontrollera vattenstämplar med mera.

## Förutsättningar

- Ett konto hos [Ace Data Cloud](https://platform.acedata.cloud) och en API-token
- En terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för att anropa Seedream API är:

```
POST https://api.acedata.cloud/seedream/images
```

Exemplet använder modellen `doubao-seedream-4-0-250828`.
Tillgängliga modeller inkluderar: `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`, `doubao-seedream-3-0-t2i-250415`, `doubao-seededit-3-0-i2i-250628`.

Fullständigt exempel på cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "en vit siamesisk katt som sitter på fönsterbrädan", "model": "doubao-seedream-4-0-250828", "size": "1K"}'
```

Byt ut `YOUR_API_TOKEN` mot din faktiska token från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att hantera svar

Det rekommenderas att använda verktyget jq för att formatera utdata:

```bash
curl -s -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "en vit siamesisk katt som sitter på fönsterbrädan", "model": "doubao-seedream-4-0-250828", "size": "1K"}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401 | Autentisering misslyckades, kontrollera API-token |
| 403 | Otillräcklig saldo eller åtkomst nekad |
| 429 | För många förfrågningar |
| 500 | Intern serverfel |
