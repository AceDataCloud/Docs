## Introduktion

ADSL HTTP Proxy är en nätverksproxy-tjänst som tillhandahålls av Ace Data Cloud för extrahering av dynamiska ADSL proxy-IP-adresser. Genom Ace Data Clouds enhetliga API kan du snabbt använda cURL för att anropa ADSL HTTP Proxy och få funktioner som HTTP/SOCKS-proxy, flera operatörer, flera provinser, anpassad varaktighet, IP-vitlista med mera.

## Förutsättningar

- Ha ett [Ace Data Cloud](https://platform.acedata.cloud) konto och skaffa en API Token
- Ha en terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för att anropa ADSL HTTP Proxy API är:

```
POST https://api.acedata.cloud/adsl/extract
```

Exempel på komplett cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}'
```

Byt ut `YOUR_API_TOKEN` mot den faktiska token du fått från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att bearbeta svar

Det rekommenderas att använda verktyget jq för att formatera utdata:

```bash
curl -s -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401       | Autentisering misslyckades, kontrollera API Token |
| 403       | Otillräckligt saldo eller ingen åtkomst |
| 429       | För många förfrågningar, överskriden gräns |
| 500       | Intern serverfel |
