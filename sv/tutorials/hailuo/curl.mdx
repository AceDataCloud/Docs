## Introduktion

Hailuo är en AI-videotjänst från Ace Data Cloud, MiniMax Hailuo videoproduktionsmodell. Genom Ace Data Cloud:s enhetliga API kan du snabbt använda cURL för att anropa Hailuo och skapa video från text, video från bilder, regissörsläge med mera.

## Förutsättningar

- Ha ett [Ace Data Cloud](https://platform.acedata.cloud) konto och få en API-token
- Ha en terminalmiljö med cURL installerat

## Grundläggande användning

Hailuo API:s huvudendpoint är:

```
POST https://api.acedata.cloud/hailuo/videos
```

Detta exempel använder modellen `minimax-t2v`.
Tillgängliga modeller inkluderar: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Exempel på komplett cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}'
```

Byt ut `YOUR_API_TOKEN` mot den faktiska token du fått från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckat anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att bearbeta svar

Det rekommenderas att använda verktyget jq för att formatera utdata:

```bash
curl -s -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}' | jq .
```

## Felhantering

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräcklig balans eller ingen åtkomst |
| 429       | För många förfrågningar |
| 500       | Intern serverfel |
