## Introduktion

Wan är en AI-videotjänst från Ace Data Cloud, baserad på Alibabas Wanxiang videoproduktionsmodell. Genom Ace Data Clouds enhetliga API kan du snabbt anropa Wan med cURL för att skapa video från text, video från bild, referensvideo, samt generera i olika upplösningar.

## Förutsättningar

- Ett konto på [Ace Data Cloud](https://platform.acedata.cloud) och en API-token
- En terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för Wan API är:

```
POST https://api.acedata.cloud/wan/videos
```

Exemplet använder modellen `wan2.6-t2v`.
Tillgängliga modeller inkluderar: `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`.

Fullständigt exempel på cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/wan/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "model": "wan2.6-t2v", "prompt": "Astronauts shuttle from space to volcano", "resolution": "720P"}'
```

Byt ut `YOUR_API_TOKEN` mot den faktiska token du fått från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att bearbeta svar

Det rekommenderas att använda verktyget jq för formaterad utskrift:

```bash
curl -s -X POST https://api.acedata.cloud/wan/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "model": "wan2.6-t2v", "prompt": "Astronauts shuttle from space to volcano", "resolution": "720P"}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning                       |
|-----------|---------------------------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräckligt saldo eller ingen åtkomst |
| 429       | För många förfrågningar          |
| 500       | Intern serverfel                 |
