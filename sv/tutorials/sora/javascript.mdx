## Introduktion

Sora är en AI-videotjänst från Ace Data Cloud, baserad på OpenAI Sora videogenereringsmodell. Genom Ace Data Clouds enhetliga API kan du snabbt integrera Sora med JavaScript för att skapa videor från text, med olika längder, liggande eller stående format, karaktärskontroll, referensbilder med mera.

## Förutsättningar

- Ett konto hos [Ace Data Cloud](https://platform.acedata.cloud) och en API-token
- Node.js 18+ eller en modern webbläsare

## Grundläggande användning

Huvudendpoint för att anropa Sora API är:

```
POST https://api.acedata.cloud/sora/videos
```

Detta exempel använder modellen `sora-2`.
Tillgängliga modeller är: `sora-2`, `sora-2-pro`.

Fullständigt JavaScript-exempel:

```javascript
const response = await fetch("https://api.acedata.cloud/sora/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "A cat running across a sunny meadow",
  "model": "sora-2",
  "duration": 10,
  "orientation": "landscape"
}),
});

const result = await response.json();
console.log(result);
```

Byt ut `YOUR_API_TOKEN` mot din faktiska token från Ace Data Cloud-plattformen.

## Hantering av svar

Det rekommenderas att kontrollera statuskoden och hantera fel:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Anrop lyckades:", result);
} else {
  console.error(`Anrop misslyckades, statuskod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-wrapper

Rekommenderas att kapsla in i en återanvändbar funktion:

```javascript
async function callSora(data) {
  const response = await fetch("https://api.acedata.cloud/sora/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-fel: ${response.status}`);
  return response.json();
}
```

## Felhantering

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräcklig balans eller ingen åtkomst |
| 429       | För många förfrågningar |
| 500       | Intern serverfel |
