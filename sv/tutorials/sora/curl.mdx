## Introduktion

Sora är en AI-videotjänst från Ace Data Cloud, OpenAI Sora videogenereringsmodell. Genom Ace Data Clouds enhetliga API kan du snabbt använda cURL för att anropa Sora och skapa text-till-video, med olika längder, liggande eller stående format, karaktärskontroll, referensbilder med mera.

## Förutsättningar

- Ett konto hos [Ace Data Cloud](https://platform.acedata.cloud) och en API-token
- En terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för att anropa Sora API är:

```
POST https://api.acedata.cloud/sora/videos
```

Exemplet använder modellen `sora-2`.
Tillgängliga modeller inkluderar: `sora-2`, `sora-2-pro`.

Fullständigt exempel på cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}'
```

Byt ut `YOUR_API_TOKEN` mot din faktiska token från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckat anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Hantera svar med jq

Det rekommenderas att använda verktyget jq för att formatera utdata:

```bash
curl -s -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning                     |
|-----------|--------------------------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräckligt saldo eller ingen åtkomst |
| 429       | För många förfrågningar         |
| 500       | Intern serverfel                |
