## Introduktion

Kling är en AI-videotjänst från Ace Data Cloud, en snabb videoproduktionsmodell. Genom Ace Data Clouds enhetliga API kan du snabbt anropa Kling med cURL för att skapa video från text, video från bild, video-fortsättning, olika längder och olika bildförhållanden.

## Förutsättningar

- Ha ett [Ace Data Cloud](https://platform.acedata.cloud) konto och skaffa en API-token
- Ha en terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpunkten för att anropa Kling API är:

```
POST https://api.acedata.cloud/kling/videos
```

Exemplet använder modellen `kling-v2-5-turbo`.
Tillgängliga modeller inkluderar: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`.

Exempel på komplett cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/kling/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A white cat walking in the snow", "model": "kling-v2-5-turbo", "duration": 5, "aspect_ratio": "16:9"}'
```

Byt ut `YOUR_API_TOKEN` mot den faktiska token du fått från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Hantera svar med jq

Rekommenderas att använda verktyget jq för formaterad utskrift:

```bash
curl -s -X POST https://api.acedata.cloud/kling/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A white cat walking in the snow", "model": "kling-v2-5-turbo", "duration": 5, "aspect_ratio": "16:9"}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401 | Autentisering misslyckades, kontrollera API-token |
| 403 | Otillräcklig balans eller åtkomst nekad |
| 429 | För många förfrågningar |
| 500 | Internt serverfel |
