## Introduktion

QR Art är en AI-bildtjänst för AI-konst QR-koder som tillhandahålls av Ace Data Cloud. Genom Ace Data Clouds enhetliga API kan du snabbt använda cURL för att anropa QR Art och skapa QR-koder för länkar, text, förinställda stilar, anpassade parametrar med mera.

## Förutsättningar

- Ha ett konto på [Ace Data Cloud](https://platform.acedata.cloud) och skaffa en API-token
- Ha en terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för att anropa QR Art API är:

```
POST https://api.acedata.cloud/qrart/generate
```

Fullständigt exempel på cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}'
```

Byt ut `YOUR_API_TOKEN` mot den faktiska token du fått från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att hantera svar

Det rekommenderas att använda verktyget jq för att formatera utdata:

```bash
curl -s -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}' | jq .
```

## Felhantering

Vanliga felkoder:

| Statuskod | Beskrivning                      |
|-----------|---------------------------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräckligt saldo eller ingen åtkomst |
| 429       | För många förfrågningar          |
| 500       | Intern serverfel                 |
