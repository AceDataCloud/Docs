## Introduktion

Veo är en AI-videotjänst från Ace Data Cloud, baserad på Google Veo videoproduktionsmodell. Genom Ace Data Clouds enhetliga API kan du snabbt använda cURL för att anropa Veo och skapa video från text, video från bilder, 4K-upplösning, olika bildförhållanden med mera.

## Förutsättningar

- Ett [Ace Data Cloud](https://platform.acedata.cloud) konto och API-token
- En terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för att anropa Veo API är:

```
POST https://api.acedata.cloud/veo/videos
```

Detta exempel använder modellen `veo3`. Tillgängliga modeller inkluderar: `veo2`, `veo2-fast`, `veo3`, `veo3-fast`, `veo31`, `veo31-fast`.

Exempel på komplett cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/veo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A coffee mug rotating slowly on a marble counter", "model": "veo3"}'
```

Byt ut `YOUR_API_TOKEN` mot din faktiska token från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att hantera svar

Det rekommenderas att använda verktyget jq för formaterad utskrift:

```bash
curl -s -X POST https://api.acedata.cloud/veo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A coffee mug rotating slowly on a marble counter", "model": "veo3"}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräckligt saldo eller ingen åtkomst |
| 429       | För många förfrågningar |
| 500       | Intern serverfel |
