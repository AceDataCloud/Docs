## Introduktion

Image2Text är en CAPTCHA-tjänst för bildigenkänning som tillhandahålls av Ace Data Cloud. Genom Ace Data Clouds enhetliga API kan du snabbt använda cURL för att anropa Image2Text och utföra bild-CAPTCHA-igenkänning, inklusive Base64-inmatning och URL-inmatning.

## Förutsättningar

- Ha ett konto på [Ace Data Cloud](https://platform.acedata.cloud) och erhåll en API-token
- Ha en terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för att anropa Image2Text API är:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Fullständigt exempel på cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}'
```

Byt ut `YOUR_API_TOKEN` mot den faktiska token du fått från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att hantera svar

Det rekommenderas att använda verktyget jq för att formatera utdata:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning                     |
|-----------|--------------------------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräckligt saldo eller ingen åtkomst |
| 429       | För många förfrågningar         |
| 500       | Intern serverfel                |
