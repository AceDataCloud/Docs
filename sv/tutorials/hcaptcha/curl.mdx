## Introduktion

hCaptcha är en CAPTCHA-tjänst som tillhandahålls av Ace Data Cloud. Med hCaptcha-lösningen kan du via Ace Data Clouds enhetliga API snabbt använda cURL för att anropa hCaptcha, inklusive funktioner som att hämta hCaptcha-token och bildigenkänning för hCaptcha.

## Förutsättningar

- Ha ett konto hos [Ace Data Cloud](https://platform.acedata.cloud) och skaffa en API-token
- En terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för att anropa hCaptcha API är:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Exempel på komplett cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}'
```

Byt ut `YOUR_API_TOKEN` mot den faktiska token du fått från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att bearbeta svar

Det rekommenderas att använda verktyget jq för att formatera utskriften:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräckligt saldo eller ingen åtkomst |
| 429       | För många förfrågningar, gräns förfrågningsfrekvens överskriden |
| 500       | Intern serverfel |
