## Introduktion

Google Search är en söktjänst som tillhandahålls av Ace Data Cloud, Google Search API. Genom Ace Data Clouds enhetliga API kan du snabbt använda cURL för att anropa Google Search och utföra webb-, bild-, nyhets-, kart- och videosökningar.

## Förutsättningar

- Ha ett [Ace Data Cloud](https://platform.acedata.cloud) konto och erhåll en API-token
- Ha en terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för att anropa Google Search API är:

```
POST https://api.acedata.cloud/serp/google
```

Exempel på komplett cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}'
```

Byt ut `YOUR_API_TOKEN` mot den faktiska token du fått från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att bearbeta svar

Det rekommenderas att använda verktyget jq för formaterad utskrift:

```bash
curl -s -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}' | jq .
```

## Felhantering

Vanliga felkoder:

| Statuskod | Beskrivning                      |
|-----------|---------------------------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräcklig balans eller åtkomst nekad |
| 429       | För många förfrågningar          |
| 500       | Intern serverfel                 |
