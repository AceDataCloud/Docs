## Introduktion

Identity är en autentiseringstjänst som tillhandahålls av Ace Data Cloud för verifiering av ID-kort/bankkort/telefonnummer med verkliga namn. Genom Ace Data Clouds enhetliga API kan du snabbt använda cURL för att anropa Identity och utföra funktioner som ID-korts OCR, ID-kortsverifiering, bankkortsverifiering och telefonnummerverifiering.

## Förutsättningar

- Ha ett [Ace Data Cloud](https://platform.acedata.cloud) konto och få en API-token
- Ha en terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för att anropa Identity API är:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Fullständigt exempel på cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}'
```

Byt ut `YOUR_API_TOKEN` mot den faktiska token du fått från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckat anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att hantera svar

Det rekommenderas att använda verktyget jq för formaterad utskrift:

```bash
curl -s -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}' | jq .
```

## Felhantering

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401 | Autentisering misslyckades, kontrollera API-token |
| 403 | Otillräcklig saldo eller ingen åtkomst |
| 429 | För många förfrågningar |
| 500 | Intern serverfel |
