## Introduktion

Face Change är en AI-bildtjänst för ansiktsbehandling som tillhandahålls av Ace Data Cloud. Genom Ace Data Clouds enhetliga API kan du snabbt använda Face Change med cURL för att utföra ansiktsbyte, ansiktsförbättring, åldersändring, könsbyte, anime-effekter, ansiktsanalys med mera.

## Förutsättningar

- Ha ett konto på [Ace Data Cloud](https://platform.acedata.cloud) och skaffa en API-token
- Ha en terminalmiljö med cURL installerad

## Grundläggande användning

Huvudendpoint för att anropa Face Change API är:

```
POST https://api.acedata.cloud/face/swap
```

Fullständigt exempel på cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}'
```

Byt ut `YOUR_API_TOKEN` mot den faktiska token du fått från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Hantera svar med jq

Det rekommenderas att använda verktyget jq för att formatera utdata:

```bash
curl -s -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401 | Autentisering misslyckades, kontrollera API-token |
| 403 | Otillräcklig balans eller ingen åtkomst |
| 429 | För många förfrågningar |
| 500 | Intern serverfel |
