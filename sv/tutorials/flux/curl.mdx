## Introduktion

Flux är en AI-bildtjänst från Ace Data Cloud, baserad på Black Forest Labs Flux bildgenereringsmodell. Genom Ace Data Clouds enhetliga API kan du snabbt anropa Flux med cURL för att skapa bilder från text, redigera bilder, använda olika modeller och anpassa storlekar.

## Förutsättningar

- Ha ett konto på [Ace Data Cloud](https://platform.acedata.cloud) och erhåll en API-token
- Ha en terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för att anropa Flux API är:

```
POST https://api.acedata.cloud/flux/images
```

I detta exempel används modellen `flux-pro-1.1`. Tillgängliga modeller inkluderar: `flux-dev`, `flux-pro`, `flux-pro-1.1`, `flux-pro-1.1-ultra`, `flux-kontext-pro`, `flux-kontext-max`.

Exempel på komplett cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/flux/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat sitting on a windowsill", "model": "flux-pro-1.1", "size": "1024x1024"}'
```

Byt ut `YOUR_API_TOKEN` mot din faktiska token från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att hantera svar

Det rekommenderas att använda verktyget jq för att formatera utdata:

```bash
curl -s -X POST https://api.acedata.cloud/flux/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat sitting on a windowsill", "model": "flux-pro-1.1", "size": "1024x1024"}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning                          |
|-----------|------------------------------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräckligt saldo eller ingen åtkomst |
| 429       | För många förfrågningar (rate limit) |
| 500       | Intern serverfel                   |
