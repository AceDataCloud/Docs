## Introduktion

AI Chat är en AI-chattjänst från Ace Data Cloud, som erbjuder flermodells AI-dialogtjänster. Genom Ace Data Clouds enhetliga API kan du snabbt använda cURL för att anropa AI Chat och få stöd för flera modeller, tillståndsbaserad konversation, förinställda roller med mera.

## Förutsättningar

- Ha ett [Ace Data Cloud](https://platform.acedata.cloud) konto och skaffa en API-token
- Ha en terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för att anropa AI Chat API är:

```
POST https://api.acedata.cloud/aichat/conversations
```

Exemplet använder modellen `gpt-4o`.
Tillgängliga modeller inkluderar: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Fullständigt cURL-kommandosexempel:

```bash
curl -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}'
```

Byt ut `YOUR_API_TOKEN` mot den faktiska token du fått från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckat anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att hantera svar

Det rekommenderas att använda verktyget jq för att formatera utdata:

```bash
curl -s -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräcklig balans eller ingen åtkomst |
| 429       | För många förfrågningar |
| 500       | Intern serverfel |
