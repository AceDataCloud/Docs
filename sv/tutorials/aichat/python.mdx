## Introduktion

AI Chat är en AI-chattjänst som tillhandahålls av Ace Data Cloud, en multi-modell AI-dialogtjänst. Genom Ace Data Clouds enhetliga API kan du snabbt integrera AI Chat med Python och få funktioner som stöd för flera modeller, tillståndsbaserad konversation och förinställda roller.

## Förutsättningar

- Ett konto hos [Ace Data Cloud](https://platform.acedata.cloud) och en API-token
- Python 3.7 eller senare
- Installera requests-biblioteket: `pip install requests`

## Grundläggande användning

Huvudendpoint för att anropa AI Chat API är:

```
POST https://api.acedata.cloud/aichat/conversations
```

Detta exempel använder modellen `gpt-4o`.
Tillgängliga modeller inkluderar: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Fullständigt Python-exempel:

```python
import requests

url = "https://api.acedata.cloud/aichat/conversations"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gpt-4o",
    "question": "什么是人工智能？",
    "stateful": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Byt ut `YOUR_API_TOKEN` mot din faktiska token från Ace Data Cloud-plattformen.

## Hantering av svar

Vid lyckad anrop returnerar API:et data i JSON-format. Det rekommenderas att kontrollera HTTP-statuskoden:

```python
if response.status_code == 200:
    result = response.json()
    print("Anrop lyckades:", result)
else:
    print(f"Anrop misslyckades, statuskod: {response.status_code}")
    print(response.text)
```

## Avancerad användning

För API:er som stödjer asynkrona uppgifter kan resultat erhållas via en callback-URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Resultatet kommer att skickas till din server via callback-URL
```

## Felhantering

Vanliga felkoder:

| Statuskod | Beskrivning                      |
|-----------|---------------------------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräcklig balans eller åtkomst nekad |
| 429       | För många förfrågningar          |
| 500       | Intern serverfel                 |
