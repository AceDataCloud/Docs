## Introduktion

Short URL är en verktygstjänst för kortlänksgenerering som tillhandahålls av Ace Data Cloud. Genom Ace Data Clouds enhetliga API kan du snabbt anropa Short URL med cURL för att förkorta URL:er, anpassa domännamn och andra funktioner.

## Förutsättningar

- Ha ett [Ace Data Cloud](https://platform.acedata.cloud) konto och erhåll en API-token
- Ha en terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för att anropa Short URL API är:

```
POST https://api.acedata.cloud/shorturl
```

Fullständigt exempel på cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}'
```

Byt ut `YOUR_API_TOKEN` mot den faktiska token du fått från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Hantera svar med jq

Det rekommenderas att använda verktyget jq för att formatera utdata:

```bash
curl -s -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräcklig balans eller ingen åtkomst |
| 429       | För många förfrågningar |
| 500       | Intern serverfel |

## Nästa steg

- Gå till [Ace Data Cloud kontrollpanel](https://platform.acedata.cloud) för att hämta API-token
- Läs [API-dokumentationen](https://docs.acedata.cloud/zh-CN/api-reference) för fullständig parameterbeskrivning
