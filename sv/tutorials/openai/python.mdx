## Introduktion

OpenAI är en AI-chattjänst som tillhandahålls av Ace Data Cloud, baserad på OpenAI GPT-seriens stora språkmodeller. Genom Ace Data Clouds enhetliga API kan du snabbt integrera OpenAI med Python för att genomföra flerrundiga konversationer, systempromptar, strömmande utdata, JSON-utmatningsläge, textinbäddningar, bildgenerering och andra funktioner.

## Förutsättningar

- Ha ett [Ace Data Cloud](https://platform.acedata.cloud) konto och skaffa en API-token
- Python 3.7 eller senare
- Installera requests-biblioteket: `pip install requests`

## Grundläggande användning

Huvudendpoint för att anropa OpenAI API är:

```
POST https://api.acedata.cloud/openai/chat/completions
```

Det här exemplet använder modellen `gpt-4o`.
Tillgängliga modeller inkluderar: `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`.

Fullständigt Python-exempel:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Byt ut `YOUR_API_TOKEN` mot den faktiska token du fått från Ace Data Cloud-plattformen.

## Hantering av svar

Vid lyckad anrop returnerar API:et data i JSON-format. Det rekommenderas att kontrollera HTTP-statuskoden:

```python
if response.status_code == 200:
    result = response.json()
    print("Anrop lyckades:", result)
else:
    print(f"Anrop misslyckades, statuskod: {response.status_code}")
    print(response.text)
```

## Avancerad användning

För chatt-API:er stöds strömmande utdata för att få realtidsrespons:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Felhantering

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräcklig saldo eller ingen åtkomst |
| 429       | Överskriden anropsfrekvens |
| 500       | Intern serverfel |
