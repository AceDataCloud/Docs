## Introduktion

OpenAI är Ace Data Clouds AI-chattjänst, baserad på OpenAI GPT-seriens stora språkmodeller. Genom Ace Data Clouds enhetliga API kan du snabbt integrera OpenAI med JavaScript för att möjliggöra flerstegsdialoger, systempromptar, strömmande output, JSON-utdata, textinbäddningar, bildgenerering med mera.

## Förutsättningar

- Ett konto hos [Ace Data Cloud](https://platform.acedata.cloud) och en API-token
- Node.js 18+ eller en modern webbläsare

## Grundläggande användning

Huvudendpoint för att anropa OpenAI API är:

```
POST https://api.acedata.cloud/openai/chat/completions
```

Det här exemplet använder modellen `gpt-4o`.
Tillgängliga modeller inkluderar: `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`.

Fullständigt JavaScript-exempel:

```javascript
const response = await fetch("https://api.acedata.cloud/openai/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "gpt-4o",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Byt ut `YOUR_API_TOKEN` mot din faktiska token från Ace Data Cloud-plattformen.

## Hantering av svar

Det rekommenderas att kontrollera svarskoden och hantera fel:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Anrop lyckades:", result);
} else {
  console.error(`Anrop misslyckades, statuskod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-wrapper

Rekommenderas att kapsla in i en återanvändbar funktion:

```javascript
async function callOpenAI(data) {
  const response = await fetch("https://api.acedata.cloud/openai/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Felhantering

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräcklig saldo eller åtkomst nekad |
| 429       | För många förfrågningar |
| 500       | Intern serverfel |
