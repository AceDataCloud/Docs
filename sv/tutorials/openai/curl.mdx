## Introduktion

OpenAI är en AI-chattjänst som tillhandahålls av Ace Data Cloud, baserad på OpenAI GPT-seriens stora språkmodeller. Genom Ace Data Cloud:s enhetliga API kan du snabbt använda cURL för att anropa OpenAI och få funktioner som flerrundiga konversationer, systempromptar, strömmande utdata, JSON-utdataformat, textinbäddningar, bildgenerering med mera.

## Förutsättningar

- Ha ett [Ace Data Cloud](https://platform.acedata.cloud) konto och erhåll en API-token
- Ha en terminalmiljö med cURL installerad

## Grundläggande användning

Huvudendpoint för att anropa OpenAI API är:

```
POST https://api.acedata.cloud/openai/chat/completions
```

Detta exempel använder modellen `gpt-4o`.  
Tillgängliga modeller inkluderar: `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`.

Fullständigt exempel på cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Byt ut `YOUR_API_TOKEN` mot den faktiska token du fått från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att bearbeta svar

Det rekommenderas att använda verktyget jq för att formatera utdata:

```bash
curl -s -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning                      |
|-----------|---------------------------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräcklig balans eller ingen åtkomst |
| 429       | För många förfrågningar          |
| 500       | Intern serverfel                 |
