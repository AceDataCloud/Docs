## Introduktion

Grok är en AI-chattjänst som tillhandahålls av Ace Data Cloud, en del av xAI Grok-serien av stora språkmodeller. Genom Ace Data Cloud:s enhetliga API kan du snabbt integrera Grok med JavaScript för att möjliggöra flerstegsdialoger, systempromptar, strömmande output, JSON-utdataformat, visuell förståelse med mera.

## Förutsättningar

- Ett konto hos [Ace Data Cloud](https://platform.acedata.cloud) och en API-token
- Node.js 18+ eller en modern webbläsarmiljö

## Grundläggande användning

Huvudendpoint för att anropa Grok API är:

```
POST https://api.acedata.cloud/grok/chat/completions
```

Detta exempel använder modellen `grok-3`. Tillgängliga modeller inkluderar: `grok-4`, `grok-4-1-fast`, `grok-3`, `grok-3-mini`, `grok-2-vision`.

Fullständigt JavaScript-exempel:

```javascript
const response = await fetch("https://api.acedata.cloud/grok/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "grok-3",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Byt ut `YOUR_API_TOKEN` mot din faktiska token från Ace Data Cloud-plattformen.

## Hantering av svar

Det rekommenderas att kontrollera svarskoden och hantera fel:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Anrop lyckades:", result);
} else {
  console.error(`Anrop misslyckades, statuskod: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-inkapsling

Det rekommenderas att kapsla in anropet i en återanvändbar funktion:

```javascript
async function callGrok(data) {
  const response = await fetch("https://api.acedata.cloud/grok/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-fel: ${response.status}`);
  return response.json();
}
```

## Felhantering

Vanliga statuskoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräcklig balans eller ingen åtkomst |
| 429       | För många förfrågningar |
| 500       | Intern serverfel |
