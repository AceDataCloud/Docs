## Introduktion

Grok är en AI-chattjänst från Ace Data Cloud, en del av xAI Grok-serien av stora språkmodeller. Genom Ace Data Clouds enhetliga API kan du snabbt använda cURL för att anropa Grok och få funktioner som flerstegsdialog, systempromptar, strömmande utdata, JSON-utmatningsläge och visuell förståelse.

## Förutsättningar

- Ha ett konto på [Ace Data Cloud](https://platform.acedata.cloud) och skaffa en API-token
- Ha en terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för att anropa Grok API är:

```
POST https://api.acedata.cloud/grok/chat/completions
```

Exemplet använder modellen `grok-3`.
Tillgängliga modeller inkluderar: `grok-4`, `grok-4-1-fast`, `grok-3`, `grok-3-mini`, `grok-2-vision`.

Fullständigt exempel på cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/grok/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "grok-3", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Byt ut `YOUR_API_TOKEN` mot din faktiska token från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att hantera svar

Det rekommenderas att använda verktyget jq för formaterad utskrift:

```bash
curl -s -X POST https://api.acedata.cloud/grok/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "grok-3", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning                      |
|-----------|---------------------------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräckligt saldo eller ingen åtkomst |
| 429       | För många förfrågningar          |
| 500       | Intern serverfel                 |
