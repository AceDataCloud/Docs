## Introduktion

Nano Banana är en AI-bildtjänst från Ace Data Cloud, baserad på Geminis bildgenereringstjänst. Genom Ace Data Clouds enhetliga API kan du snabbt anropa Nano Banana med cURL för att skapa bilder från text, redigera bilder, använda olika bildförhållanden och högupplösta bilder.

## Förutsättningar

- Ett konto hos [Ace Data Cloud](https://platform.acedata.cloud) och en API-token
- En terminalmiljö med cURL installerat

## Grundläggande användning

Huvudendpoint för Nano Banana API är:

```
POST https://api.acedata.cloud/nano-banana/images
```

Detta exempel använder modellen `nano-banana-2`.
Tillgängliga modeller inkluderar: `nano-banana`, `nano-banana-2`, `nano-banana-pro`.

Exempel på komplett cURL-kommando:

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat", "model": "nano-banana-2", "aspect_ratio": "1:1"}'
```

Byt ut `YOUR_API_TOKEN` mot din faktiska token från Ace Data Cloud-plattformen.

## Exempel på svar

Vid lyckad anrop returneras data i JSON-format, till exempel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Använda jq för att hantera svar

Det rekommenderas att använda verktyget jq för att formatera utdata:

```bash
curl -s -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat", "model": "nano-banana-2", "aspect_ratio": "1:1"}' | jq .
```

## Felsökning

Vanliga felkoder:

| Statuskod | Beskrivning |
|-----------|-------------|
| 401       | Autentisering misslyckades, kontrollera API-token |
| 403       | Otillräcklig saldo eller åtkomst nekad |
| 429       | För många förfrågningar |
| 500       | Intern serverfel |
