## はじめに

Seedance は Ace Data Cloud が提供する AI 動画サービスで、ByteDance の Seedance 動画生成モデルを使用しています。Ace Data Cloud の統一 API を通じて、cURL を使って Seedance を素早く呼び出し、テキストから動画生成、画像から動画生成、音声生成、複数解像度対応などの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) のアカウントを持ち、API トークンを取得していること
- cURL がインストールされた端末環境

## 基本的な使い方

Seedance API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/seedance/videos
```

本例では `doubao-seedance-1-0-pro-250528` モデルを使用しています。  
利用可能なモデルには、`doubao-seedance-1-5-pro-251215`、`doubao-seedance-1-0-pro-250528`、`doubao-seedance-1-0-pro-fast-251015` があります。

完全な cURL コマンド例：

```bash
curl -X POST https://api.acedata.cloud/seedance/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "doubao-seedance-1-0-pro-250528", "content": [{"type": "text", "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"}]}'
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス例

呼び出し成功時には JSON 形式のデータが返されます。例：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq を使ったレスポンス処理

jq ツールを使って出力を整形することを推奨します：

```bash
curl -s -X POST https://api.acedata.cloud/seedance/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "doubao-seedance-1-0-pro-250528", "content": [{"type": "text", "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"}]}' | jq .
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                         |
|------------------|------------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし     |
| 429              | リクエスト頻度制限超過           |
| 500              | サーバ内部エラー               |
