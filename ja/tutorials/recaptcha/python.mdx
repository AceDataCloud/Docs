## はじめに

reCAPTCHA は Ace Data Cloud が提供するキャプチャサービスであり、Google reCAPTCHA ソリューションです。Ace Data Cloud の統一 API を通じて、Python を使って reCAPTCHA を素早く統合し、reCAPTCHA v2 トークン、reCAPTCHA v2 認識、reCAPTCHA v3 トークンなどの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) のアカウントを持ち、API トークンを取得していること
- Python 3.7 以上の環境
- requests ライブラリのインストール：`pip install requests`

## 基本的な使い方

reCAPTCHA API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/captcha/token/recaptcha2
```

完全な Python コード例：

```python
import requests

url = "https://api.acedata.cloud/captcha/token/recaptcha2"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-",
    "website_url": "https://www.google.com/recaptcha/api2/demo"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス処理

呼び出しが成功すると、API は JSON 形式のデータを返します。HTTP ステータスコードを確認することを推奨します：

```python
if response.status_code == 200:
    result = response.json()
    print("呼び出し成功:", result)
else:
    print(f"呼び出し失敗、ステータスコード: {response.status_code}")
    print(response.text)
```

## 応用的な使い方

非同期タスクをサポートする API については、コールバック URL を通じて結果を取得できます：

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# 結果はコールバック URL を通じてあなたのサーバーにプッシュされます
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明 |
|-----------------|------|
| 401 | 認証失敗、API トークンを確認してください |
| 403 | 残高不足またはアクセス権限なし |
| 429 | リクエスト頻度超過 |
| 500 | サーバー内部エラー |

## その他のエンドポイント

reCAPTCHA サービスは以下のエンドポイントも提供しています：

- `POST https://api.acedata.cloud/captcha/recognition/recaptcha2`
- `POST https://api.acedata.cloud/captcha/token/recaptcha3`
