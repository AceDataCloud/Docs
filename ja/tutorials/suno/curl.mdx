## はじめに

Suno は Ace Data Cloud が提供する AI オーディオサービスであり、Suno AI 音楽生成を実現します。Ace Data Cloud の統一 API を通じて、cURL を使って Suno を素早く呼び出し、テキストからの音楽生成、カスタム歌詞、曲の続き作成、カバー、ボーカル分離、歌詞生成などの機能を利用できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) アカウントを所有し、API トークンを取得していること
- cURL がインストールされたターミナル環境

## 基本的な使い方

Suno API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/suno/audios
```

本例では `chirp-v5` モデルを使用しています。利用可能なモデルは：`chirp-v5`、`v4-5-plus`、`v4-5`、`v4`、`v3-5` です。

完全な cURL コマンド例：

```bash
curl -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}'
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス例

正常に呼び出すと JSON 形式のデータが返されます。例：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq を使ったレスポンス処理

jq ツールを使って出力を整形することを推奨します：

```bash
curl -s -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}' | jq .
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                         |
|------------------|------------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし        |
| 429              | リクエスト頻度制限超過              |
| 500              | サーバ内部エラー                  |
