## はじめに

Localization は Ace Data Cloud が提供するツールサービスで、AI 翻訳ローカリゼーションサービスです。Ace Data Cloud の統一 API を通じて、cURL を使って Localization を素早く呼び出し、Markdown 翻訳、JSON 翻訳、18 言語対応、フォーマット保持などの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) のアカウントを持ち、API トークンを取得していること
- cURL がインストールされた端末環境

## 基本的な使い方

Localization API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/localization/translate
```

本例では `gpt-4` モデルを使用しています。  
利用可能なモデル：`gpt-3.5`、`gpt-4`。

完全な cURL コマンド例：

```bash
curl -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}'
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス例

正常に呼び出すと JSON 形式のデータが返されます。例：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq を使ったレスポンス処理

jq ツールを使って整形出力することを推奨します：

```bash
curl -s -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}' | jq .
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                           |
|------------------|--------------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし       |
| 429              | リクエスト頻度制限超過             |
| 500              | サーバー内部エラー                 |
