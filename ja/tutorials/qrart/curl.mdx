## はじめに

QR Art は Ace Data Cloud が提供する AI 画像サービスで、AI アートのQRコード生成を行います。Ace Data Cloud の統一APIを通じて、cURLを使ってQR Artを素早く呼び出し、リンクQRコード、テキストQRコード、プリセットスタイル、カスタムパラメータなどの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) のアカウントを持ち、APIトークンを取得していること
- cURLがインストールされた端末環境

## 基本的な使い方

QR Art API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/qrart/generate
```

完全な cURL コマンド例：

```bash
curl -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}'
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス例

正常に呼び出すと、JSON形式のデータが返されます。例：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq を使ったレスポンス処理

jqツールを使ってフォーマット出力することを推奨します：

```bash
curl -s -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}' | jq .
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                           |
|------------------|--------------------------------|
| 401              | 認証失敗、APIトークンを確認してください |
| 403              | 残高不足またはアクセス権限なし  |
| 429              | リクエスト頻度制限超過          |
| 500              | サーバー内部エラー              |
