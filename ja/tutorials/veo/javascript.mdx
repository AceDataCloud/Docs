## はじめに

Veo は Ace Data Cloud が提供する AI 動画サービスであり、Google Veo 動画生成モデルです。Ace Data Cloud の統一 API を通じて、JavaScript を使って Veo を素早く統合し、テキストから動画生成、画像から動画生成、4K 解像度、様々なアスペクト比などの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) のアカウントを持ち、API トークンを取得していること
- Node.js 18+ またはモダンブラウザ環境

## 基本的な使い方

Veo API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/veo/videos
```

本例では `veo3` モデルを使用します。利用可能なモデルは：`veo2`、`veo2-fast`、`veo3`、`veo3-fast`、`veo31`、`veo31-fast` です。

完全な JavaScript コード例：

```javascript
const response = await fetch("https://api.acedata.cloud/veo/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "text2video",
  "prompt": "A coffee mug rotating slowly on a marble counter",
  "model": "veo3"
}),
});

const result = await response.json();
console.log(result);
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス処理

レスポンスのステータスコードを確認し、エラー処理を行うことを推奨します：

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("呼び出し成功:", result);
} else {
  console.error(`呼び出し失敗、ステータスコード: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js ラッパー

再利用可能な関数としてラップすることを推奨します：

```javascript
async function callVeo(data) {
  const response = await fetch("https://api.acedata.cloud/veo/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明 |
|-----------------|------|
| 401 | 認証失敗、API トークンを確認してください |
| 403 | 残高不足またはアクセス権限なし |
| 429 | リクエスト頻度制限超過 |
| 500 | サーバー内部エラー |
