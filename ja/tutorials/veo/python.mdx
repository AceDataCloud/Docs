## はじめに

Veo は Ace Data Cloud が提供する AI 動画サービスであり、Google Veo 動画生成モデルです。Ace Data Cloud の統一 API を通じて、Python で Veo を素早く統合し、テキストから動画生成、画像から動画生成、4K 解像度、様々なアスペクト比などの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) アカウントを持ち、API トークンを取得していること
- Python 3.7 以上の環境
- requests ライブラリのインストール：`pip install requests`

## 基本的な使い方

Veo API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/veo/videos
```

本例では `veo3` モデルを使用します。利用可能なモデルは：`veo2`、`veo2-fast`、`veo3`、`veo3-fast`、`veo31`、`veo31-fast` です。

完全な Python コード例：

```python
import requests

url = "https://api.acedata.cloud/veo/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "text2video",
    "prompt": "A coffee mug rotating slowly on a marble counter",
    "model": "veo3"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス処理

呼び出しが成功すると、API は JSON 形式のデータを返します。HTTP ステータスコードを確認することを推奨します：

```python
if response.status_code == 200:
    result = response.json()
    print("呼び出し成功:", result)
else:
    print(f"呼び出し失敗、ステータスコード: {response.status_code}")
    print(response.text)
```

## 応用的な使い方

非同期タスクをサポートする API では、コールバック URL を通じて結果を取得できます：

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# 結果はコールバック URL を通じてあなたのサーバーにプッシュされます
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                         |
|------------------|------------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし       |
| 429              | リクエスト頻度制限超過             |
| 500              | サーバー内部エラー               |
