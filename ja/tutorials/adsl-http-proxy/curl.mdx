## はじめに

ADSL HTTP Proxy は Ace Data Cloud が提供するネットワークプロキシサービスであり、ADSL 動的プロキシ IP 抽出を行います。Ace Data Cloud の統一 API を通じて、cURL を使って ADSL HTTP Proxy を素早く呼び出し、HTTP/SOCKS プロキシ、多キャリア、多県、省指定、カスタム期間、IP ホワイトリストなどの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) のアカウントを持ち、API トークンを取得していること
- cURL がインストールされたターミナル環境

## 基本的な使い方

ADSL HTTP Proxy API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/adsl/extract
```

完全な cURL コマンド例：

```bash
curl -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}'
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス例

正常に呼び出すと JSON 形式のデータが返されます。例えば：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq を使ったレスポンス処理

jq ツールを使ってフォーマットされた出力を推奨します：

```bash
curl -s -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}' | jq .
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                          |
|------------------|-------------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし       |
| 429              | リクエスト頻度制限超過             |
| 500              | サーバー内部エラー               |
