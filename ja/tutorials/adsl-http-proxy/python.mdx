## はじめに

ADSL HTTP Proxy は Ace Data Cloud が提供するネットワークプロキシサービスで、ADSL 動的代理 IP の抽出を行います。Ace Data Cloud の統一 API を通じて、Python で簡単に ADSL HTTP Proxy を統合し、HTTP/SOCKS プロキシ、多キャリア、多県、省、カスタム期間、IP ホワイトリストなどの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) アカウントを所有し、API トークンを取得していること
- Python 3.7 以上の環境
- requests ライブラリのインストール：`pip install requests`

## 基本的な使い方

ADSL HTTP Proxy API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/adsl/extract
```

完全な Python コード例：

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "number": 5,
    "type": "http",
    "duration": 300,
    "province": "广东",
    "isp": "电信"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス処理

呼び出しが成功すると、API は JSON 形式のデータを返します。HTTP ステータスコードを確認することを推奨します：

```python
if response.status_code == 200:
    result = response.json()
    print("呼び出し成功:", result)
else:
    print(f"呼び出し失敗、ステータスコード: {response.status_code}")
    print(response.text)
```

## 応用的な使い方

非同期タスクをサポートする API では、コールバック URL を通じて結果を取得できます：

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# 結果はコールバック URL を通じてあなたのサーバーにプッシュされます
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                       |
|------------------|----------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし        |
| 429              | リクエスト頻度超過               |
| 500              | サーバー内部エラー               |
