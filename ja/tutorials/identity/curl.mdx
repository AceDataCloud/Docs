## はじめに

Identity は Ace Data Cloud が提供する認証サービスで、身分証・銀行カード・電話番号の実名認証を行います。Ace Data Cloud の統一 API を通じて、cURL を使って Identity を素早く呼び出し、身分証 OCR、身分証検証、銀行カード検証、電話番号検証などの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) のアカウントを所有し、API トークンを取得していること
- cURL がインストールされた端末環境

## 基本的な使い方

Identity API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

完全な cURL コマンド例：

```bash
curl -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}'
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス例

成功すると JSON 形式のデータが返されます。例：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq を使ったレスポンス処理

jq ツールを使ってフォーマットされた出力を推奨します：

```bash
curl -s -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}' | jq .
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                         |
|------------------|------------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし       |
| 429              | リクエスト頻度制限超過             |
| 500              | サーバ内部エラー                 |
