## はじめに

Grok は Ace Data Cloud が提供する AI チャットサービスであり、xAI Grok シリーズの大規模言語モデルです。Ace Data Cloud の統一 API を通じて、JavaScript で Grok を素早く統合し、多段対話、システムプロンプト、ストリーミング出力、JSON 出力モード、ビジュアル理解などの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) アカウントを所有し、API トークンを取得していること
- Node.js 18+ またはモダンブラウザ環境

## 基本的な使い方

Grok API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/grok/chat/completions
```

本例では `grok-3` モデルを使用しています。利用可能なモデルは：`grok-4`、`grok-4-1-fast`、`grok-3`、`grok-3-mini`、`grok-2-vision` です。

完全な JavaScript コード例：

```javascript
const response = await fetch("https://api.acedata.cloud/grok/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "grok-3",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス処理

レスポンスのステータスコードをチェックし、エラー処理を行うことを推奨します：

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("呼び出し成功:", result);
} else {
  console.error(`呼び出し失敗、ステータスコード: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js ラッパー

再利用可能な関数としてラップすることを推奨します：

```javascript
async function callGrok(data) {
  const response = await fetch("https://api.acedata.cloud/grok/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                           |
|------------------|--------------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし       |
| 429              | リクエスト頻度制限超過             |
| 500              | サーバー内部エラー                 |
