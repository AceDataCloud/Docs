## はじめに

OpenAI は Ace Data Cloud が提供する AI チャットサービスであり、OpenAI GPT シリーズの大規模言語モデルです。Ace Data Cloud の統一 API を通じて、cURL を使って OpenAI を素早く呼び出し、多段対話、システムプロンプト、ストリーミング出力、JSON 出力モード、テキスト埋め込み、画像生成などの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) のアカウントを持ち、API トークンを取得していること
- cURL がインストールされたターミナル環境

## 基本的な使い方

OpenAI API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/openai/chat/completions
```

本例では `gpt-4o` モデルを使用します。  
利用可能なモデルは：`gpt-4o`、`gpt-4o-mini`、`o1`、`o3-mini` です。

完全な cURL コマンド例：

```bash
curl -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス例

正常に呼び出すと JSON 形式のデータが返されます。例：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq を使ったレスポンス処理

jq ツールを使って出力を整形することを推奨します：

```bash
curl -s -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                         |
|------------------|------------------------------|
| 401              | 認証失敗。API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし  |
| 429              | リクエスト頻度制限超過        |
| 500              | サーバー内部エラー            |
