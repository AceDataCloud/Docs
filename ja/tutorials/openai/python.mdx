## はじめに

OpenAI は Ace Data Cloud が提供する AI チャットサービスであり、OpenAI GPT シリーズの大規模言語モデルです。Ace Data Cloud の統一 API を通じて、Python で OpenAI を素早く統合し、多段階対話、システムプロンプト、ストリーミング出力、JSON 出力モード、テキスト埋め込み、画像生成などの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) のアカウントを持ち、API トークンを取得していること
- Python 3.7 以上の環境
- requests ライブラリのインストール：`pip install requests`

## 基本的な使い方

OpenAI API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/openai/chat/completions
```

本例では `gpt-4o` モデルを使用しています。利用可能なモデルには `gpt-4o`、`gpt-4o-mini`、`o1`、`o3-mini` があります。

完全な Python コード例：

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス処理

呼び出しが成功すると、API は JSON 形式のデータを返します。HTTP ステータスコードを確認することを推奨します：

```python
if response.status_code == 200:
    result = response.json()
    print("呼び出し成功:", result)
else:
    print(f"呼び出し失敗、ステータスコード: {response.status_code}")
    print(response.text)
```

## 応用的な使い方

チャット API では、リアルタイムレスポンスを取得するためにストリーミング出力をサポートしています：

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                         |
|------------------|------------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし   |
| 429              | リクエスト頻度制限超過          |
| 500              | サーバ内部エラー               |
