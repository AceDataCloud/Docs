## はじめに

Seedream は Ace Data Cloud が提供する AI 画像サービスで、ByteDance の Seedream 画像生成モデルを利用しています。Ace Data Cloud の統一 API を通じて、Python で Seedream を素早く統合し、テキストから画像生成、画像編集、複数解像度対応、ウォーターマーク制御などの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) アカウントを所有し、API トークンを取得していること
- Python 3.7 以上の環境
- requests ライブラリのインストール：`pip install requests`

## 基本的な使い方

Seedream API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/seedream/images
```

本例では `doubao-seedream-4-0-250828` モデルを使用します。利用可能なモデルは以下の通りです：`doubao-seedream-4-5-251128`、`doubao-seedream-4-0-250828`、`doubao-seedream-3-0-t2i-250415`、`doubao-seededit-3-0-i2i-250628`。

完全な Python コード例：

```python
import requests

url = "https://api.acedata.cloud/seedream/images"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "白いシャム猫が窓辺に座っている",
    "model": "doubao-seedream-4-0-250828",
    "size": "1K"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス処理

呼び出しが成功すると、API は JSON 形式のデータを返します。HTTP ステータスコードを確認することを推奨します：

```python
if response.status_code == 200:
    result = response.json()
    print("呼び出し成功:", result)
else:
    print(f"呼び出し失敗、ステータスコード: {response.status_code}")
    print(response.text)
```

## 応用的な使い方

非同期タスクに対応した API では、コールバック URL を指定して結果を取得できます：

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# 結果はコールバック URL を通じてあなたのサーバーにプッシュされます
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明 |
|-----------------|------|
| 401             | 認証失敗、API トークンを確認してください |
| 403             | 残高不足またはアクセス権限なし |
| 429             | リクエスト頻度制限超過 |
| 500             | サーバー内部エラー |
