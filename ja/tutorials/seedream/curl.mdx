## はじめに

Seedream は Ace Data Cloud が提供する AI 画像サービスで、ByteDance の Seedream 画像生成モデルを使用しています。Ace Data Cloud の統一 API を通じて、cURL を使って Seedream を素早く呼び出し、テキストから画像生成、画像編集、複数解像度、水印制御などの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) のアカウントを持ち、API トークンを取得していること
- cURL がインストールされたターミナル環境

## 基本的な使い方

Seedream API のメインエンドポイントは以下の通りです：

```
POST https://api.acedata.cloud/seedream/images
```

本例では `doubao-seedream-4-0-250828` モデルを使用しています。利用可能なモデルは以下の通りです：`doubao-seedream-4-5-251128`、`doubao-seedream-4-0-250828`、`doubao-seedream-3-0-t2i-250415`、`doubao-seededit-3-0-i2i-250628`。

cURL コマンドの完全な例：

```bash
curl -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}'
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス例

正常に呼び出すと JSON 形式のデータが返されます。例：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq を使ったレスポンス処理

jq ツールを使って出力を整形することを推奨します：

```bash
curl -s -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}' | jq .
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                     |
|------------------|--------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし       |
| 429              | リクエスト頻度制限超過             |
| 500              | サーバー内部エラー               |
