## はじめに

Seedream は Ace Data Cloud が提供する AI 画像サービスであり、ByteDance の Seedream 画像生成モデルです。Ace Data Cloud の統一 API を通じて、JavaScript で Seedream を素早く統合し、テキストから画像生成、画像編集、複数解像度対応、ウォーターマーク制御などの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) のアカウントを持ち、API トークンを取得していること
- Node.js 18+ またはモダンブラウザ環境

## 基本的な使い方

Seedream API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/seedream/images
```

本例では `doubao-seedream-4-0-250828` モデルを使用しています。利用可能なモデルは以下の通りです：`doubao-seedream-4-5-251128`、`doubao-seedream-4-0-250828`、`doubao-seedream-3-0-t2i-250415`、`doubao-seededit-3-0-i2i-250628`。

完全な JavaScript コード例：

```javascript
const response = await fetch("https://api.acedata.cloud/seedream/images", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "白いシャム猫が窓辺に座っている",
  "model": "doubao-seedream-4-0-250828",
  "size": "1K"
}),
});

const result = await response.json();
console.log(result);
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス処理

レスポンスのステータスコードを確認し、エラー処理を行うことを推奨します：

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("呼び出し成功:", result);
} else {
  console.error(`呼び出し失敗、ステータスコード: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js ラッパー

再利用可能な関数としてラップすることを推奨します：

```javascript
async function callSeedream(data) {
  const response = await fetch("https://api.acedata.cloud/seedream/images", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                       |
|------------------|----------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし |
| 429              | リクエスト頻度制限超過      |
| 500              | サーバー内部エラー          |
