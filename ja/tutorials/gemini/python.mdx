## はじめに

Gemini は Ace Data Cloud が提供する AI チャットサービスであり、Google Gemini シリーズの大規模言語モデルです。Ace Data Cloud の統一 API を通じて、Python で Gemini を素早く統合し、多段対話、システムプロンプト、ストリーミング出力、JSON 出力モードなどの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) のアカウントを持ち、API トークンを取得していること
- Python 3.7 以上の環境
- requests ライブラリのインストール：`pip install requests`

## 基本的な使い方

Gemini API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/gemini/chat/completions
```

本例では `gemini-2.5-flash` モデルを使用しています。  
利用可能なモデルには、`gemini-2.5-flash`、`gemini-2.5-pro`、`gemini-2.0-flash`、`gemini-3.0-pro` があります。

完全な Python コード例：

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gemini-2.5-flash",
    "messages": [
        {
            "role": "user",
            "content": "こんにちは、自己紹介をお願いします"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス処理

呼び出しが成功すると、API は JSON 形式のデータを返します。HTTP ステータスコードを確認することを推奨します：

```python
if response.status_code == 200:
    result = response.json()
    print("呼び出し成功:", result)
else:
    print(f"呼び出し失敗、ステータスコード: {response.status_code}")
    print(response.text)
```

## 上級使用法

チャット系 API ではストリーミング出力をサポートしており、リアルタイムの応答を取得できます：

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                           |
|-----------------|------------------------------|
| 401             | 認証失敗、API トークンを確認してください |
| 403             | 残高不足またはアクセス権限なし       |
| 429             | リクエスト頻度制限超過             |
| 500             | サーバー内部エラー                 |
