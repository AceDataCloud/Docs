## はじめに

DeepSeek は Ace Data Cloud が提供する AI チャットサービスであり、DeepSeek シリーズの大規模言語モデルです。Ace Data Cloud の統一 API を通じて、Python で DeepSeek を素早く統合し、多段対話、システムプロンプト、ストリーミング出力、JSON 出力モード、深層推論などの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) アカウントを所有し、API トークンを取得していること
- Python 3.7 以上の環境
- requests ライブラリのインストール：`pip install requests`

## 基本的な使い方

DeepSeek API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

本例では `deepseek-r1` モデルを使用します。利用可能なモデルは：`deepseek-r1`、`deepseek-r1-0528`、`deepseek-v3`、`deepseek-v3-250324` です。

完全な Python コード例：

```python
import requests

url = "https://api.acedata.cloud/deepseek/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "deepseek-r1",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス処理

呼び出し成功後、API は JSON 形式のデータを返します。HTTP ステータスコードの確認を推奨します：

```python
if response.status_code == 200:
    result = response.json()
    print("呼び出し成功:", result)
else:
    print(f"呼び出し失敗、ステータスコード: {response.status_code}")
    print(response.text)
```

## 応用的な使い方

チャット API では、リアルタイムレスポンスを得るためにストリーミング出力をサポートしています：

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                         |
|-----------------|------------------------------|
| 401             | 認証失敗、API トークンを確認してください |
| 403             | 残高不足またはアクセス権限なし       |
| 429             | リクエスト頻度制限超過             |
| 500             | サーバ内部エラー                 |
