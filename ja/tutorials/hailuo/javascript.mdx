## はじめに

Hailuo は Ace Data Cloud が提供する AI 動画サービスであり、MiniMax 海螺動画生成モデルです。Ace Data Cloud の統一 API を通じて、JavaScript を使って Hailuo を素早く統合し、テキスト生成動画、画像生成動画、ディレクターモードなどの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) のアカウントを持ち、API トークンを取得していること
- Node.js 18+ またはモダンブラウザ環境

## 基本的な使い方

Hailuo API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/hailuo/videos
```

本例では `minimax-t2v` モデルを使用しています。
利用可能なモデルには `minimax-i2v`、`minimax-t2v`、`minimax-i2v-director` があります。

完全な JavaScript コード例：

```javascript
const response = await fetch("https://api.acedata.cloud/hailuo/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "model": "minimax-t2v",
  "prompt": "A golden sunset over the ocean waves"
}),
});

const result = await response.json();
console.log(result);
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス処理

レスポンスのステータスコードを確認し、エラー処理を行うことを推奨します：

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("呼び出し成功:", result);
} else {
  console.error(`呼び出し失敗、ステータスコード: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js ラッパー

再利用可能な関数としてラップすることを推奨します：

```javascript
async function callHailuo(data) {
  const response = await fetch("https://api.acedata.cloud/hailuo/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明 |
|------------------|------|
| 401 | 認証失敗、API トークンを確認してください |
| 403 | 残高不足またはアクセス権限なし |
| 429 | リクエスト頻度制限超過 |
| 500 | サーバー内部エラー |
