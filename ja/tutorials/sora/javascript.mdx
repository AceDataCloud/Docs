## はじめに

Sora は Ace Data Cloud が提供する AI 動画サービスであり、OpenAI Sora 動画生成モデルです。Ace Data Cloud の統一 API を通じて、JavaScript を使って Sora を素早く統合し、テキストから動画生成、多様な動画長さ、横縦画面、キャラクター制御、参照画像などの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) アカウントを持ち、API トークンを取得していること
- Node.js 18+ または最新のブラウザ環境

## 基本的な使い方

Sora API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/sora/videos
```

本例では `sora-2` モデルを使用しています。利用可能なモデルは `sora-2`、`sora-2-pro` です。

完全な JavaScript コード例：

```javascript
const response = await fetch("https://api.acedata.cloud/sora/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "A cat running across a sunny meadow",
  "model": "sora-2",
  "duration": 10,
  "orientation": "landscape"
}),
});

const result = await response.json();
console.log(result);
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス処理

レスポンスのステータスコードを確認し、エラー処理を行うことを推奨します：

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("呼び出し成功:", result);
} else {
  console.error(`呼び出し失敗、ステータスコード: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js ラッパー関数

再利用可能な関数としてラップすることを推奨します：

```javascript
async function callSora(data) {
  const response = await fetch("https://api.acedata.cloud/sora/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                         |
|------------------|------------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし         |
| 429              | リクエスト頻度制限超過               |
| 500              | サーバー内部エラー                 |
