## はじめに

Producer は Ace Data Cloud が提供する AI オーディオサービスで、FUZZ Producer AI 音楽生成を実現します。Ace Data Cloud の統一 API を通じて、JavaScript で Producer を素早く統合し、テキストからの音楽生成、カスタム歌詞、曲の続き作成、カバーソング、人声分離、MV 生成などの機能を利用できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) アカウントを所有し、API トークンを取得していること
- Node.js 18+ またはモダンブラウザ環境

## 基本的な使い方

Producer API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/producer/audios
```

本例では `FUZZ-2.0 Pro` モデルを使用しています。
利用可能なモデルは：`FUZZ-2.0 Pro`、`FUZZ-2.0`、`FUZZ-1.1 Pro`、`FUZZ-1.0 Pro` です。

完全な JavaScript コード例：

```javascript
const response = await fetch("https://api.acedata.cloud/producer/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A relaxing jazz piece for a coffee shop",
  "model": "FUZZ-2.0 Pro",
  "lyric": "[Verse]\nSoft piano keys in the morning light",
  "custom": true
}),
});

const result = await response.json();
console.log(result);
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス処理

レスポンスのステータスコードをチェックし、エラー処理を行うことを推奨します：

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("呼び出し成功:", result);
} else {
  console.error(`呼び出し失敗、ステータスコード: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js ラッパー

再利用可能な関数としてラップすることを推奨します：

```javascript
async function callProducer(data) {
  const response = await fetch("https://api.acedata.cloud/producer/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                           |
|------------------|--------------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし   |
| 429              | リクエスト頻度制限超過          |
| 500              | サーバー内部エラー             |
