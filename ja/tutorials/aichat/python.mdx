## はじめに

AI Chat は Ace Data Cloud が提供する AI チャットサービスであり、マルチモデル AI 対話サービスです。Ace Data Cloud の統一 API を通じて、Python を使って AI Chat を迅速に統合し、マルチモデル対応、ステートフル対話、プリセットロールなどの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) アカウントを所有し、API トークンを取得していること
- Python 3.7 以上の環境
- requests ライブラリのインストール：`pip install requests`

## 基本的な使い方

AI Chat API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/aichat/conversations
```

本例では `gpt-4o` モデルを使用します。利用可能なモデルは：`gpt-4o`、`gpt-4`、`deepseek-r1`、`grok-3` です。

完全な Python コード例：

```python
import requests

url = "https://api.acedata.cloud/aichat/conversations"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gpt-4o",
    "question": "什么是人工智能？",
    "stateful": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス処理

呼び出し成功後、API は JSON 形式のデータを返します。HTTP ステータスコードを確認することを推奨します：

```python
if response.status_code == 200:
    result = response.json()
    print("呼び出し成功:", result)
else:
    print(f"呼び出し失敗、ステータスコード: {response.status_code}")
    print(response.text)
```

## 応用的な使い方

非同期タスクをサポートする API では、コールバック URL を通じて結果を取得できます：

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# 結果はコールバック URL を通じてあなたのサーバーにプッシュされます
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                           |
|-----------------|------------------------------|
| 401             | 認証失敗、API トークンを確認してください |
| 403             | 残高不足またはアクセス権限なし       |
| 429             | リクエスト頻度制限超過             |
| 500             | サーバー内部エラー                 |
