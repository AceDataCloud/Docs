## はじめに

AI Chat は Ace Data Cloud が提供する AI チャットサービスであり、マルチモデル対応の AI 対話サービスです。Ace Data Cloud の統一 API を通じて、cURL を使って AI Chat を迅速に呼び出し、マルチモデル対応、ステートフル対話、プリセットロールなどの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) のアカウントを持ち、API トークンを取得していること
- cURL がインストールされた端末環境

## 基本的な使い方

AI Chat API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/aichat/conversations
```

本例では `gpt-4o` モデルを使用します。利用可能なモデルは `gpt-4o`、`gpt-4`、`deepseek-r1`、`grok-3` です。

完全な cURL コマンド例：

```bash
curl -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}'
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス例

正常に呼び出すと JSON 形式のデータが返されます。例：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq を使ったレスポンス処理

jq ツールを使った整形出力を推奨します：

```bash
curl -s -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}' | jq .
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                         |
|------------------|------------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし         |
| 429              | リクエスト頻度制限超過               |
| 500              | サーバー内部エラー                 |
