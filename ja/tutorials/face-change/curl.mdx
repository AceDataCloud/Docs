## はじめに

Face Change は Ace Data Cloud が提供する AI 画像サービス、AI 顔処理サービスです。Ace Data Cloud の統一 API を通じて、cURL を使って Face Change を素早く呼び出し、顔の置換、顔の美化、年齢変換、性別変換、アニメ化、顔分析などの機能を実現できます。

## 前提条件

- [Ace Data Cloud](https://platform.acedata.cloud) アカウントを持ち、API トークンを取得していること
- cURL がインストールされた端末環境

## 基本的な使い方

Face Change API のメインエンドポイントは以下です：

```
POST https://api.acedata.cloud/face/swap
```

完全な cURL コマンド例：

```bash
curl -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}'
```

`YOUR_API_TOKEN` は Ace Data Cloud プラットフォームで取得した実際のトークンに置き換えてください。

## レスポンス例

正常に呼び出すと JSON 形式のデータが返されます。例：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq を使ったレスポンス処理

jq ツールを使って出力を整形することを推奨します：

```bash
curl -s -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}' | jq .
```

## エラー処理

よくあるエラーコード：

| ステータスコード | 説明                         |
|------------------|------------------------------|
| 401              | 認証失敗、API トークンを確認してください |
| 403              | 残高不足またはアクセス権限なし   |
| 429              | リクエスト頻度制限超過         |
| 500              | サーバー内部エラー             |
