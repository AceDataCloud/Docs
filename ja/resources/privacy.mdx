Germey Technology, LLC（以下「私たち」または「私たちの」）、つまりAce Data Cloudの公司は、お客様のプライバシー保護に努めています。本プライバシーポリシーは、お客様が私たちのAce Data Cloudウェブサイトプラットフォームにアクセスする際に、どのように情報を収集、利用、開示および保護するかを説明しています。詳細をよくお読みください。本プラットフォームの利用により、これらの条項に同意したものとみなされます。

## 私たちが収集する情報

私たちは、サービスの提供と改善のためにさまざまな種類の情報を収集します：

1. **個人情報**：あなたを識別できる情報，如氏名、メールアドレス、電話番号、支払い情報、その他類似のデータ。

2. **非個人情報**：あなたを識別できない情報、例としてIPアドレス、ブラウザの種類、OS、リファラーURL、プラットフォームの利用状況に関する情報。

3. **技術データ**：私たちのAPIの利用状況に関する情報、リクエスト回数、リクエストデータの種類、関連するメタデータなど。

## 利用目的

収集した情報は、以下の目的で使用します：

1. **サービスの提供と維持**：プラットフォームの運営とメンテナンス、取引処理、カスタマーサポートの提供。

2. **プラットフォームの改善**：お客様の利用状況を把握し、機能やユーザー体験の向上・強化。

3. **コミュニケーション**：更新情報、宣伝資料やその他関心のある情報の送信。これらの通信をいつでも停止できます。

4. **セキュリティ確保**：利用状況やトレンドを監視・分析し、プラットフォームの安全性と完全性を確保。

5. **法的義務の遵守**：適用される法律、規則および法的手続きの遵守。

## 情報の開示

以下の場合に、お客様の情報を開示することがあります：

1. **サービス提供者**：決済処理、データ分析、メール送信、ホスティングサービス、カスタマーサポートなど、私たちに代わってサービスを提供する第三者サービス提供者と共有。

2. **法的要求**：法律の要求や公的機関の有効な要求（裁判所や政府機関など）に応じて開示。

3. **事業移転**：合併、会社資産売却、資金調達、または全てまたは一部の事業を他社に売却する場合や、その交渉期間中。

4. **お客様の同意**：明示的な同意を得た場合にその他の目的で開示。

## セキュリティ対策

私たちは、お客様の情報を不正アクセス、使用、改ざん、開示から保護するために合理的なセキュリティ対策を実施しています。これらには：

1. **データ暗号化**：業界標準の暗号化技術を使用してデータの送受信を保護。

2. **アクセス制御**：必要な業務権限のある担当者のみが個人情報にアクセス可能。

3. **定期監査**：セキュリティシステムとプロセスを定期的に監査し、業界標準およびベストプラクティスの遵守を保証。

4. **安全な保存**：個人情報を安全な環境に保存し、無断アクセスや使用、開示を防止。

### お客様の権利

お客様は、以下の権利を有します：

1. **情報へのアクセス**：私たちが保有するお客様の個人情報へのアクセスを請求。

2. **情報の訂正**：誤りや不完全な情報の訂正を請求。

3. **情報の削除**：法律の例外条項を除き、個人情報の削除を請求可能。削除希望の場合は support@acedata.cloud までご連絡ください。

4. **購読の停止**：配信停止指示に従って、宣伝通信の受信を停止。

## Google API サービスのユーザーデータポリシー（限定利用）

お客様がAce Data CloudをGoogleサービス（Google Workspace API、Google Drive、Gmail、Google Calendar等）に接続することを選択した場合、Google APIから受信する情報の利用と送信は、[Google API サービスユーザーデータポリシー](https://developers.google.com/terms/api-services-user-data-policy)を完全に遵守し、「限定使用（Limited Use）」の要件を含みます。具体的には：

1. **リクエストした機能のみに限定**：お客様が明示的にリクエストし、有効化した機能（例：Driveのファイル閲覧、カレンダー招待送信、Gmailメール整理）の範囲内でのみアクセスし、その機能の実現にのみ使用。

2. **広告には利用しない**：Google APIから取得したデータを広告配信、ターゲティング、第三者のマーケティング目的に使用しません。

3. **第三者への販売禁止**：Google APIから取得したユーザーデータを販売しません。

4. **第三者への譲渡禁止**：以下の場合を除き、取得したデータを第三者に譲渡しません：(a) 直接のお客様向けの機能の提供や改善に必要な場合；(b) セキュリティ目的（例：不正行為の調査）；(c) 適用法の遵守；(d) 統合、買収、資産売却などの一環として、かつお客様の確認と同意を得た場合。

5. **人的閲覧禁止**：スタッフによるデータの閲覧は、(a) 明示的な同意を得た場合；(b) セキュリティ目的（例：不正行為の調査）；(c) 法令遵守；(d) 集約・匿名化済みの内部運営目的のみ。

お客様は、いつでも [Google アカウント接続済みのアプリ](https://myaccount.google.com/connections) でAce Data Cloudのアクセス権を撤回可能です。
