## サービス形式と内容

Ace Data Cloudが提供するサービスには、APIサービス、HTTPプロキシサービス、バルクデータ提供サービスが含まれます。本契約が発効した後、ユーザーは相応のサービス料金を前払いする必要があります。前払いを受けた後、Ace Data Cloudはサービスをアクティブにします。

ユーザーは、Ace Data Cloudが第三者と情報源の検証サービスに関してやり取りを行うことを許可する必要があります。ユーザーは、Ace Data Cloudが品質、技術能力などの要因に基づいて特定の情報源を選択して検証サービスを提供できることに同意します。情報源が利用できない場合、Ace Data Cloudは代替の情報源を提供します。

## サービスのアクティベーション、支払いおよび課金

APIインターフェースサービスには前払いが必要です。ユーザーは必要に応じて相応の製品パッケージを選択し、前払いすることができます。パッケージの単価は市場条件に応じて変動する可能性があります。ユーザーは、サービスの中断を避けるために、アカウントの残高と残りの呼び出し回数が十分であることを確認する必要があります。

## 返金、返品およびキャンセルポリシー

**返金ポリシー**
Ace Data Cloudが提供するすべての仮想製品およびサービスは、通常の状況下で販売後の返金は行われません。技術的な故障やその他の不可抗力の要因によりサービスが正常に提供できない場合に限り、確認後にユーザーは返金を申請できます。具体的な返金額および条件は、Ace Data Cloudが実際の状況に基づいて決定します。

**返金申請プロセス**
返金を申請する場合、ユーザーは公式ウェブサイトのカスタマーサポートチャネルを通じて申請を提出し、サービスの中断または故障の詳細な証明を提供する必要があります。確認後、条件を満たす返金申請は合理的な期間内に処理されます。

**キャンセルポリシー**
サブスクリプションサービスについては、ユーザーはいつでもサービスをキャンセルできます。前払い料金の返金は、技術的な問題やその他の不可抗力の要因によりサービスが正常に提供できない場合にのみ考慮されます。上記の状況を除き、サービスのキャンセルには返金は行われません。

**配送および納品ポリシー**
すべての製品およびサービスはデジタル形式で提供されるため、物理的な商品の配送または納品ポリシーは適用されません。

**返品ポリシー**
仮想製品の特性上、販売された製品は返品を受け付けません。製品やサービスに関して疑問や問題がある場合は、速やかにカスタマーサポートにご連絡ください。具体的な状況に応じて適切な解決策を提供いたします。

本返金、返品およびキャンセルポリシーは、適用される法律および会社の運営ニーズに基づいて随時更新されます。ユーザーがサービスを引き続き利用することは、現在のポリシー条項に従うことに同意することを意味します。
