この記事では、Nano Banana Images API の接続方法と使用方法について説明します。このインターフェースは、**画像生成（generate）** と **画像編集（edit）** の2つの機能に対応しています。

## インターフェース概要

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **認証方式**：HTTP Header に `authorization: Bearer {token}` を指定
- **リクエストヘッダー**：
  - `accept: application/json`
  - `content-type: application/json`
- **アクション（action）**：
  - `generate`：テキストプロンプトに基づいて画像を生成
  - `edit`：指定した画像に基づいて編集
- **モデル（model）**（任意）：
  - `nano-banana`（デフォルト）：Gemini 2.5 Flash Image をベースとしており、処理速度が速く、コストが低い
  - `nano-banana-2-lite`：Gemini 3.1 Flash Lite Image をベースとしており、1K のみに対応し、生成速度が速い
  - `nano-banana-2`：Gemini 3.1 Flash Image Preview をベースとしており、Pro レベルの品質と Flash の速度を実現
  - `nano-banana-2.1`：次世代の高効率画像モデルで、1K、2K、4K の画像生成と編集に対応
  - `nano-banana-pro`：Gemini 3 Pro Image Preview をベースとしており、最高品質を実現
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`：各モデルに対応する公式チャネル版。画質と安定性がより優れており、料金体系は異なる
- **非同期コールバック**：任意。`callback_url` を通じてタスク完了通知と結果を受信できます。
- **画像枚数**：任意。`count` で1～4枚を指定でき、デフォルトは1枚です。各画像は独立した生成呼び出しによって生成されます。通常の技術的な失敗やプロバイダー側の安全性に関する拒否は、該当する呼び出しにのみ影響し、その他の成功した画像は通常どおり返されます。料金は実際に成功した枚数に基づいて計算されます。

## クイックスタート：画像を生成する（`action=generate`）

**最低限必要なパラメータ**：`action`、`prompt`

プロンプトに基づいて直接画像を生成したい場合は、`action` を `generate` に設定し、明確な `prompt` を指定するだけです。

### リクエスト例（cURL）

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### リクエスト例（Python）

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

```json

  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {
      "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
      "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }
  ]
}
```

### フィールドの説明

- `success`：今回のリクエストが成功したかどうか。
- `task_id`：タスク ID。
- `trace_id`：問題の調査に役立つトレース ID。
- `count`：生成または編集する画像の枚数。1～4枚に対応し、デフォルトは1枚です。`data` には生成に成功した画像のみが含まれ、実際に返された枚数に基づいて課金されます。各生成呼び出しには、プロバイダーのネイティブ安全ポリシーが強制的に適用されます。いずれかの呼び出しが拒否されても、その他の成功した呼び出しには影響しません。すべての呼び出しが拒否された場合は、403 が返されます。
- `data[]`：結果のリスト。
  - `prompt`：生成に使用されたプロンプト（そのまま返されます）。
  - `image_url`：生成された画像の直接 URL。

> 注：`/nano-banana/images` では、`action` と `prompt` を指定するだけで画像を生成できます。

## 画像を編集する（`action=edit`）

既存の画像に基づいて編集したい場合は、`action` を `edit` に設定し、`image_urls` を通じて編集対象の画像リンクリスト（1枚または複数枚）を渡し、さらに編集内容を説明する `prompt` を指定してください。

例えば、人物の写真と服の写真を1枚ずつ用意し、その人物にこの服を着せたい場合、画像リンクを同時に渡し、action を `edit` に指定できます。URL には HTTP URL を使用でき、`https` または `http` プロトコルによる一般公開されているアクセス可能なリンクのほか、Base64 エンコードされた画像も使用できます。例えば、`data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### リクエスト例（cURL）
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "この男性にこのTシャツを着せてください",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### リクエスト例（Python）

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "この男性にこのTシャツを着せてください",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

- その他のフィールドは「画像生成」のレスポンスと同じです。

## 非同期コールバック（任意、推奨）

画像の生成や編集には一定の時間がかかる場合があります。長時間の接続によるリソースの占有を避けるため、`callback_url` を使用した **Webhookコールバック** を推奨します。

1. リクエストボディに `callback_url` を追加します。例えば、自分のサーバーのWebhookアドレスを指定します（インターネットからアクセス可能で、POST JSONに対応している必要があります）。
2. APIは `task_id` を含むレスポンス（または基本的な結果）を **直ちに返します**。
3. タスクが完了すると、プラットフォームは `POST` メソッドで完全なJSONを `callback_url` に送信します。`task_id` を使用してリクエストと結果を関連付けることができます。

**コールバックペイロードの例**（フィールド構造は同期処理の成功レスポンスと同じです）：

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "白いシャム猫",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## エラー処理

呼び出しに失敗した場合、標準的なエラー形式とトレースIDが返されます。一般的なエラーは以下のとおりです。

- **400 `token_mismatched`**：リクエストが無効、またはパラメータに誤りがあります。
- **400 `api_not_implemented`**：インターフェースが実装されていません（サポートにお問い合わせください）。
- **401 `invalid_token`**：認証に失敗したか、Tokenが不足しています。
- **403 `forbidden`**：プロバイダーのネイティブ安全ポリシーによってリクエストまたは生成結果が拒否されました。この呼び出しでは画像は返されず、課金も発生しません。複数画像のリクエストでは、ほかの成功した呼び出しについては結果が返され、課金される場合があります。
- **429 `too_many_requests`**：リクエスト頻度が制限を超えています。
- **500 `api_error`**：サーバー側の異常です。

### エラーレスポンス例

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## パラメータの対応関係と注意事項

- **必須**：`action`、`prompt`
- **編集専用**：`image_urls`（配列、最低1項目）
- **任意**：`model`（デフォルトは `nano-banana`。`nano-banana-2-lite`、`nano-banana-2`、`nano-banana-2.1`、`nano-banana-pro` を選択可能。`nano-banana-2.1` を除き、それぞれに対応する `:official` 公式チャネル版もあります）、`aspect_ratio`（`auto` または `1:1`、`16:9` などの具体的なアスペクト比）、`resolution`（`1K`、`2K`、`4K` などの解像度。`nano-banana-2-lite` は `1K` のみ対応）、`callback_url`（非同期コールバック用）
- **Headers**：`authorization: Bearer {token}` を必ず指定してください。`accept` は `application/json` に設定することを推奨します。
- **画像のアクセス性**：`image_urls` はインターネットからアクセス可能な直接リンク（HTTP/HTTPS）である必要があります。HTTPSの使用を推奨します。
- **冪等性と追跡**：障害の調査や結果の関連付けに備えて、`task_id` と `trace_id` を保持してください。

`"aspect_ratio": "auto"` を明示的に指定すると、プロンプト内の比率、方向、またはレイアウトに基づいて、最も近いプリセットが選択されます。これは画像生成と画像編集の両方に適用されます。例えば、プロンプトに「YouTubeサムネイル」と記載すると、`16:9` が選択されます。プロンプトにサイズの指定がない場合、または自動判定が利用できない場合、テキストからの画像生成ではデフォルトのアスペクト比が使用され、画像編集では最初の参照画像に従って、対応している最も近い比率が使用されます。このフィールドを省略した場合は、デフォルトのアスペクト比または参照画像の比率が使用されます。すでに明確なアスペクト比の指定がある場合は、具体的な比率を直接渡してください。
