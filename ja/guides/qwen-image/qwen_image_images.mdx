---
title: "Qwen Image 画像 API 統合ガイド"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` は `qwen-image-3.0` と `qwen-image-3.0-pro` の文生図と 1–3 枚の参考画像編集をサポートしています。

## 文生図

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen-image-3.0","prompt":"一枚の極簡なテクノロジーポスター","size":"1024*1024","n":1}'
```

## 画像編集

同じリクエストに `image_urls` を追加し、1–3 枚の公開画像をサポートします：

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "主体を保持し、暖かい**###**ポスタースタイルに変更",
  "image_urls": ["https://cdn.acedata.cloud/r9vsv9.png"],
  "size": "2048*2048",
  "prompt_extend": true,
  "prompt_extend_mode": "direct",
  "enable_thinking": true,
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` は文生図のみサポートします。`n` の範囲は 1–6 です。出力サイズの総ピクセルは 512×512 から 2048×2048 の間で、アスペクト比は 1:8 から 8:1 です。

## 非同期呼び出し

`async: true` を設定すると、すぐに `task_id` を取得できます。また、`callback_url` を渡して最終結果を受け取ることもできます。完了後は `/qwen-image/tasks` で確認します。

成功したレスポンスには `data[].image_url`、`usage`、`task_id`、および `trace_id` が含まれます。画像リンクは可能な限り Ace Data Cloud CDN に転送されます。実際のレスポンスサンプルは、製品の E2E 検証後に追加されます。
