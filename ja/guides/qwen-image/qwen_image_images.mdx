`POST https://api.acedata.cloud/qwen-image/images` 同じインターフェースを通じて文生図と1–3枚の参考画像の編集を行い、`qwen-image-3.0`と`qwen-image-3.0-pro`をサポートします。

## モデルの選択

| モデル                   | 適したシーン       | 公式標準価格                   |
| -------------------- | ---------- | ----------------------- |
| `qwen-image-3.0`     | バッチ制作、迅速な反復  | 出力 $0.030/枚             |
| `qwen-image-3.0-pro` | 複雑なレイアウト、高精度の作品 | 1K $0.040/枚；2K $0.075/枚 |

参考画像は実際の入力数に基づいて課金され、公式標準価格は $0.003/枚です。

## 同期生成

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "クリーンな白い背景に中央に配置されたシンプルな赤い円。",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

成功した応答には、永久CDN画像のURL、実際の使用量、および今回の費用が含まれます：

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },

}
```

## 参考画像編集

`image_urls`を追加し、1–3枚の公開アクセス可能な画像をサポートします：

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "主体を保持し、背景を暖かい**###**ポスタースタイルに変更",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"
  ],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent`は文生図のみに使用されます。`n`の範囲は1–6；アスペクト比は1:8から8:1の間でなければなりません。

## 非同期タスク

`async: true`を設定すると、インターフェースはすぐに`task_id`を返します。`/qwen-image/tasks`を使用して最終状態を照会するか、`callback_url`を渡して完了通知を受け取ります。生成は一度だけ課金され、タスクの照会は重複して課金されません。
