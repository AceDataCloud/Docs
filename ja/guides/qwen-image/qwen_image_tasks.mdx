---

`POST https://api.acedata.cloud/qwen-image/tasks` を使用して非同期画像生成タスクを照会します。この照会インターフェースは無料です。

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

バッチ照会には `action=retrieve_batch` と `ids` 配列を使用します。タスクが成功した後、`response.data` には生成された画像の永久アドレスと実際の使用量が含まれます。
