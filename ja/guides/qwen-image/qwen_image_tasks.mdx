---
title: "Qwen Image タスク照会 API"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/tasks` は、Qwen Image の非同期タスクを照会、バッチ照会、または削除するために使用されます。このインターフェースは追加の API 消費を生じません。

## 単一タスクの照会

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

タスクが完了すると、`response.data` には永久 CDN 画像アドレスが含まれ、`response.usage` には実際の入力/出力数が含まれ、`response.cost` は生成タスクの決済情報です。

## バッチ照会

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

返されるのは `{ "items": [...], "count": 2 }` です。リスト照会はユーザー、アプリケーション、作成時間範囲でのフィルタリングもサポートしています。

## タスク記録の削除

```json
{"action":"delete","id":"TASK_ID"}
```

削除はタスクの履歴記録にのみ影響し、生成された CDN ファイルは削除されません。
