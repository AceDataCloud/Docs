本文では、Veo Upsample API の接続説明を紹介します。このインターフェースは、生成された Veo ビデオをアップサンプリングしたり、アニメーション GIF プレビューを出力するために使用されます。

## 申請プロセス

API を使用するには、まず Veo サービスの該当ページで申請する必要があります。まだログインまたは登録していない場合は、自動的にログインページにリダイレクトされます。

## 基本使用

このインターフェースを呼び出すには、2 つのパラメータを渡す必要があります：

- `video_id`：元のビデオのタスク ID。`/veo/videos`、`/veo/extend`、`/veo/reshoot`、`/veo/objects` のいずれかのインターフェースで生成されたビデオ ID である必要があります。
- `action`：アップサンプリングアクションで、以下の 3 つをサポートしています：
  - `1080p`：ビデオを 1080p 解像度にアップサンプリングします。
  - `4k`：ビデオを 4K 解像度にアップサンプリングします。
  - `gif`：ビデオをアニメーション GIF プレビューに変換します。

リクエストの例：

```shell
curl -X POST 'https://api.acedata.cloud/veo/upsample' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "4k"
  }'
```

返される結果は `/veo/videos` と同じで、依然として非同期タスク構造であり、`task_id` を使用して `/veo/tasks` インターフェースでタスクの状態を確認できます：

```json
{
  "success": true,
  "task_id": "8f5a90ae-3f86-4c4f-86f7-7126f5e92c76",
  "trace_id": "0f3e09c2-4c2e-46ea-9cdc-a31ec48b7c12",
  "data": [
    {
      "id": "253eedc47f1c4eb2a370ed2312168f4b",
      "video_url": "https://platform.cdn.acedata.cloud/veo/8f5a90ae.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

返されるフィールドの説明：

- `success`：アップサンプリングタスクが正常に送信されたかどうか。
- `task_id`：今回のアップサンプリングタスクの ID。
- `data`：アップサンプリング後のビデオ結果。
  - `video_url`：アップサンプリング後のビデオの URL。

## 課金説明

- `action=1080p`：0.16 クレジット / 回
- `action=4k`：0.50 クレジット / 回
- `action=gif`：0.13 クレジット / 回

渡された `action` が上記のいずれにも該当しない場合、デフォルトで 0.50 クレジットが課金されます。サポートされている値を明示的に渡すことをお勧めします。

## 非同期コールバック

インターフェースは非同期モードもサポートしており、`callback_url` を渡すことで、タスクが完了した後に POST リクエストで結果をコールバックできます。パブリックなコールバックアドレスがない場合は、`async` を `true` に設定することもでき、インターフェースは即座に `task_id` を返し、その後対応するタスククエリインターフェースで結果をポーリングして取得できます。
