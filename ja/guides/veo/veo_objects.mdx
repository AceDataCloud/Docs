本文では、Veo Objects API の接続説明を紹介します。このインターフェースは、生成された Veo 動画に対して**物体の追加または削除**操作（マスクに基づく部分再描画）を行うためのものです。

## 申請プロセス

API を使用するには、まず Veo サービスの該当ページで申請する必要があります。まだログインまたは登録していない場合は、自動的にログインページにリダイレクトされます。

## 基本使用

このインターフェースを呼び出すには、以下のパラメータを渡す必要があります：

- `video_id`（必須）：元の動画のタスク ID。**/veo/extend** の出力動画であってはなりません。
- `action`（必須）：操作タイプ、`insert` または `remove`。
- `prompt`：
  - `action=insert`：**必須**、追加する物体の説明。
  - `action=remove`：任意、削除する内容の説明（主にログ記録用で、実際の消去領域は `image_mask` によって決まります）。
- `image_mask`：
  - `action=insert`：任意。渡さない場合、AI が自動的に挿入位置を決定します。渡す場合は、白いピクセル領域に挿入されます。
  - `action=remove`：**必須**、白いピクセル領域は消去する対象です。

`image_mask` は二つの形式を受け入れます：

1. **公開アクセス可能な HTTP(S) 画像アドレス**（推奨）。
2. **base64 エンコードされた JPEG 文字列**、`data:image/jpeg;base64,` プレフィックスを付けることも、裸の base64 でも可能です。

リクエスト例（物体を挿入し、マスクを渡さずに AI に自動定位させる）：

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "insert",
    "prompt": "add a flying pig with black wings"
  }'
```

リクエスト例（マスクに基づいて物体を削除）：

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "remove",
    "image_mask": "https://example.com/mask.jpg",
    "prompt": "remove the white cloud"
  }'
```

返却結果の構造は `/veo/videos` と同じです。

## 課金説明

- `action=insert` または `remove`：1.50 クレジット / 回。

## 非同期コールバック

インターフェースは非同期モードをサポートしており、`callback_url` を渡すことで、タスク完了後に POST リクエストで結果をコールバックします。パブリックなコールバックアドレスがない場合は、`async` を `true` に設定することもでき、インターフェースは即座に `task_id` を返し、その後対応するタスク照会インターフェースでポーリングして結果を取得できます。
