本文では、Veo Extend API の接続説明を紹介します。このインターフェースは、生成された Veo ビデオの**長さを延長**するために使用され、AI が自動的に後続の映像を続けます。

## 申請プロセス

API を使用するには、まず Veo サービスの該当ページで申請する必要があります。まだログインまたは登録していない場合は、自動的にログインページにリダイレクトされます。

## 基本使用

このインターフェースを呼び出すには、以下のパラメータを渡す必要があります：

- `video_id`（必須）：元のビデオのタスク ID（`/veo/videos` またはこのインターフェース自体から）。
- `model`（必須）：延長に使用するモデル、**`veo31-fast` と `veo31` の2つのモデルのみをサポート**、他のモデルは上流でサポートされていません。
- `prompt`（任意）：延長部分の映像を導くためのテキストヒント。
- `aspect_ratio`（任意）：`16:9` または `9:16`、デフォルトは `16:9`。
- `resolution`（任意）：`720p` または `1080p`。

リクエストの例：

```shell
curl -X POST 'https://api.acedata.cloud/veo/extend' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "model": "veo31-fast",
    "prompt": "the camera slowly zooms out to reveal more of the landscape"
  }'
```

返却結果は `/veo/videos` と同じです：

```json
{
  "success": true,
  "task_id": "5fa2d9a6-7e54-481b-a4b0-3dc6f25dd2ab",
  "data": [
    {
      "id": "9b6f3b6b9c45419fbf2e3fe2f10b2b3a",
      "video_url": "https://platform.cdn.acedata.cloud/veo/5fa2d9a6.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

## 重要な制限

`video_id` は TTAPI ラインから生成されたか、延長が完了した後の `data[].id` から取得する必要があります。TTAPI を切り替える前に旧ラインから生成された履歴ビデオ ID はこのインターフェースで使用できず、呼び出すと `400 bad_request` が返されます；`/veo/videos` を通じて再生成してから延長してください。

`/veo/extend` からの延長結果ビデオは**再度 `/veo/extend` で延長することができます**が、**以下のインターフェースで処理することはできません**：

- `/veo/reshoot` —— カメラの動きを変更できません
- `/veo/objects` —— 物体の追加や削除はできません

渡された `video_id` が延長結果である場合、関連インターフェースは 400 エラーを返しますので、元のビデオをソースとして使用してください。

## 課金説明

- `model=veo31-fast`：1.68 クレジット / 回
- `model=veo31`：12.00 クレジット / 回

## 非同期コールバック

インターフェースは非同期モードをサポートしており、`callback_url` を渡すことで、タスクが完了した後に POST リクエストで結果をコールバックできます。パブリックなコールバックアドレスがない場合は、`async` を `true` に設定することもでき、インターフェースは即座に `task_id` を返し、その後対応するタスククエリインターフェースを通じて結果をポーリングして取得できます。
