本文では、Veo Reshoot API の接続説明を紹介します。このインターフェースは、生成された Veo ビデオの一部を **新しいカメラの動きの方法で再生成**するために使用され、画面の内容は同じですが、カメラの位置と動きは `motion_type` に従って再演出されます。

## 申請プロセス

API を使用するには、まず Veo サービスの該当ページで申請する必要があります。まだログインまたは登録していない場合は、自動的にログインページにリダイレクトされます。

## 基本使用

このインターフェースを呼び出すには、以下のパラメータを渡す必要があります：

- `video_id`（必須）：元のビデオのタスク ID。**`/veo/extend` の出力ビデオではないこと。**
- `motion_type`（必須）：新しいカメラの動きの方法で、大文字のアンダースコアスタイルの簡潔なエイリアスを使用します。

### `motion_type` サポート値

| エイリアス                          | 意味           |
| --------------------------------- | ------------ |
| `STATIONARY`                     | カメラ固定       |
| `STATIONARY_UP`                  | カメラ固定、上に仰角    |
| `STATIONARY_DOWN`                | カメラ固定、下に仰角    |
| `STATIONARY_LEFT`                | カメラ固定、左にパン      |
| `STATIONARY_RIGHT`               | カメラ固定、右にパン      |
| `STATIONARY_DOLLY_IN_ZOOM_OUT`   | カメラ固定、前に押し + ズームアウト |
| `STATIONARY_DOLLY_OUT_ZOOM_IN`   | カメラ固定、後ろに引き + ズームイン |
| `UP`                             | カメラ上昇         |
| `DOWN`                           | カメラ下降         |
| `LEFT_TO_RIGHT`                  | カメラ左から右に平行移動     |
| `RIGHT_TO_LEFT`                  | カメラ右から左に平行移動     |
| `FORWARD`                        | カメラ前進       |
| `BACKWARD`                       | カメラ後退        |
| `DOLLY_IN_ZOOM_OUT`              | 移動中前に押し + ズームアウト   |
| `DOLLY_OUT_ZOOM_IN`              | 移動中後ろに引き + ズームイン   |

リクエスト例：

```shell
curl -X POST 'https://api.acedata.cloud/veo/reshoot' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "motion_type": "LEFT_TO_RIGHT"
  }'
```

返却結果の構造は `/veo/videos` と同じです。

## 課金説明

- 一回の再撮影：1.20 クレジット。

## 非同期コールバック

インターフェースは非同期モードをサポートしており、`callback_url` を渡すことで、タスク完了後に POST リクエストで結果をコールバックします。パブリックなコールバックアドレスがない場合は、`async` を `true` に設定することもでき、インターフェースは即座に `task_id` を返し、その後対応するタスククエリインターフェースでポーリングして結果を取得します。
