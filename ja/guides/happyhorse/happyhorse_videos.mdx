本文は HappyHorse Videos API の接続方法について説明します。このインターフェースは、統一された `/happyhorse/videos` エンドポイントと `action` パラメータを通じて、文生動画、首フレーム画像生動画、参考画像生動画、および動画編集をサポートします。

## 申請プロセス

HappyHorse Videos API を使用するには、まず [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications) にアクセスして、API トークンを取得し、保管してください。

![](https://cdn.acedata.cloud/5hmkdg.jpg)

まだログインまたは登録していない場合は、自動的にログインページにリダイレクトされ、登録とログインを促されます。完了後、現在のページに自動的に戻ります。

**1つの API トークンでプラットフォームのすべてのサービスを呼び出すことができ、各サービスごとに個別に申請する必要はありません。** 初回申請時には無料枠が付与され、無料で体験できます。枠が不足した場合は、[コンソール](https://platform.acedata.cloud/console/coin) で共通残高をチャージできます。

> 📘 完全なドキュメント：[HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## 操作タイプ

`action` は今回のリクエストの生成モードを決定します：

- `generate`：文生動画、デフォルトのアクションで、`happyhorse-1.0-t2v` と `happyhorse-1.1-t2v` をサポートし、`prompt` を必ず渡す必要があります。
- `image_to_video`：首フレーム画像生動画、`happyhorse-1.0-i2v` と `happyhorse-1.1-i2v` をサポートし、`image_url` を必ず渡す必要があります。
- `reference_to_video`：参考画像生動画、`happyhorse-1.0-r2v` と `happyhorse-1.1-r2v` をサポートし、`prompt` と 1–9 枚の `image_urls` を必ず渡す必要があります。
- `video_edit`：動画編集、`happyhorse-1.0-video-edit` をサポートし、`prompt` と `video_url` を必ず渡す必要があります。追加で 0–5 枚の参考画像 `image_urls` を渡すことができます。

各アクションはデフォルトで 1.1 モデルを使用します；`video_edit` は現在 `happyhorse-1.0-video-edit` のみです。

## 基本使用

文生動画は `prompt` を提供するだけで済み、`resolution`、`ratio`、`duration` などのパラメータを指定することもできます：

```json
{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

返却結果の例は以下の通りです：

```json
{
  "success": true,
  "task_id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
  "trace_id": "6071ab5e-2f37-46f0-9e07-f1e378112e69",
  "data": [
    {
      "id": "9650580f-6d9e-4bc1-823a-29011790c5cb",
      "video_url": "https://platform2.cdn.acedata.cloud/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1.mp4",
      "state": "succeeded",
      "duration": 5,
      "resolution": "720P",
      "ratio": null
    }
  ]
}
```

フィールドの説明：

- `success`：今回のリクエストが成功したかどうか。
- `task_id`：Ace Data Cloud 側のタスク ID、タスクの状態を確認するために使用できます。
- `trace_id`：今回のリクエストのトレース ID、問題の調査に使用します。
- `data`：動画結果のリスト。
  - `id`：上流の HappyHorse タスク ID。
  - `video_url`：生成された動画の CDN リンクアドレス。
  - `state`：タスクの状態、選択肢は `pending` / `succeeded` / `error`。
  - `duration`：課金対象の動画の長さ、単位は秒；`video_edit` は入力と出力の動画の長さの合計。
  - `resolution`：出力解像度。
  - `ratio`：出力のアスペクト比。

対応する CURL コードは以下の通りです：

```shell
curl -X POST 'https://api.acedata.cloud/happyhorse/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}'
```

対応する Python コードは以下の通りです：

```python
import requests

url = "https://api.acedata.cloud/happyhorse/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
    "resolution": "720P",
    "ratio": "16:9",
    "duration": 5,
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 首フレーム画像生動画

`image_to_video` を使用する際、`image_url` は動画の首フレームとして使用されます。出力のアスペクト比は首フレーム画像にできるだけ従うため、このアクションでは `ratio` を渡す必要はありません。

```json
{
  "action": "image_to_video",
  "model": "happyhorse-1.1-i2v",
  "image_url": "https://cdn.acedata.cloud/b1c82e4937.png",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "1080P",
  "duration": 5
}
```

## 参考画像生動画

`reference_to_video` を使用する際、`image_urls` に 1–9 枚の参考画像を渡すことができます。プロンプト内で `character1`、`character2` などの方法で対応する順序の画像を参照できます。

```json
{
  "action": "reference_to_video",
  "model": "happyhorse-1.1-r2v",
  "prompt": "character1 walks forward through a sunrise meadow with the warm leather and gold trim style from character2",
  "image_urls": [
    "https://cdn.acedata.cloud/b1c82e4937.png",
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

## 動画編集

`video_edit` を使用する際は、編集対象の動画 `video_url` と編集意図 `prompt` を必ず渡す必要があります。オプションの `image_urls` は参考画像として使用され、例えば衣装変更、スタイル転送、または部分的な置き換えに使用されます。`audio_setting` は `auto` または `origin` を選択でき、`origin` は元の動画の音声を保持することを意味します。

```json
{
  "action": "video_edit",
  "model": "happyhorse-1.0-video-edit",
  "prompt": "Apply the warm leather and gold trim style from the reference image while preserving the original camera motion",
  "video_url": "https://platform2.cdn.acedata.cloud/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1.mp4",
  "image_urls": [
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "audio_setting": "auto"
}
```

## 非同期コールバック
動画生成には一定の処理時間が必要です。長時間接続を維持したくない場合は、`callback_url`を渡すことができます。この場合、APIはすぐに`task_id`を返し、タスクが完了した後に最終結果をそのアドレスにPOSTします：

```json
{
  "action": "generate",
  "prompt": "雪の森を駆ける馬",
  "duration": 5,
  "callback_url": "https://your-domain.com/callback/happyhorse"
}
```

即時に返される結果は以下の通りです：

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

ポーリングのみを希望し、コールバックが不要な場合は、`"async": true`を渡すことができ、その後[HappyHorse Tasks API](https://platform.acedata.cloud/documents/happyhorse-tasks)を通じてタスク結果を確認できます。

## 課金説明

HappyHorseは出力動画の秒数と解像度に基づいて課金します：

- `720P`：約 $0.105 / 秒から。
- `1080P`：約 $0.18 / 秒から。
- `video_edit`：入力動画と出力動画の長さの合計に基づいて課金され、実際の課金時間はタスク完了後の上流統計に基づきます。

失敗したタスクは課金されず、無料枠も消費しません。

## エラーハンドリング

リクエストに問題が発生した場合、APIは対応するエラーコードと説明を返します。一般的なものは以下の通りです：

- `400`：リクエストパラメータに誤りがある、例えばactionとmodelが一致しない、`prompt` / `image_url` / `video_url`が欠けている、または`duration`が3〜15秒の範囲を超えている。
- `401`：認証失敗、トークンが無効またはAPIと一致しない。
- `403`：残高不足、またはプロンプトがコンテンツ審査に引っかかり拒否された。
- `429`：リクエストが頻繁すぎて、上流の制限に触れたため、後で再試行してください。
- `500`：サーバー内部エラーまたは上流生成失敗。
