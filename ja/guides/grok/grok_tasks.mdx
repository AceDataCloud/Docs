Grok Tasks API の主な機能は、Grok Videos Generation API で生成されたタスク ID を入力して、そのタスクの実行状況を照会することです。

本ドキュメントでは、Grok Tasks API の連携方法を詳しく説明し、Grok Videos Generation API のタスク実行状況を簡単に統合・照会できるようサポートします。

## 申請手順

Grok Tasks API を使用するには、まず申請ページ [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos) で該当サービスを申請し、Grok Videos Generation API から返されるタスク ID をコピーしてください。

その後、[Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) ページにアクセスして該当サービスを申請します。ページに入ったら「Acquire」ボタンをクリックしてください。

まだログインまたは登録していない場合は、自動的に[ログインページ](https://platform.acedata.cloud)にリダイレクトされ、登録・ログインを促されます。ログイン・登録後は自動的に元のページに戻ります。

初回申請時には無料枠が付与され、この API を無料で利用できます。

## リクエスト例

Grok Tasks API は Grok Videos Generation API の結果を照会するために使用できます。

### リクエストヘッダーとリクエストボディの設定

**Request Headers** は以下を含みます：

- `accept`：JSON形式のレスポンスを受け取るために `application/json` を指定します。
- `authorization`：API 呼び出しのためのキー。申請後にプルダウンから選択可能です。

**Request Body** は以下を含みます：

- `id`：照会したいタスク ID。
- `action`：タスクに対する操作方法。単一照会の場合は `retrieve` を指定します。

### CURL コード例

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### レスポンス例

リクエストが成功すると、API は該当タスクの詳細情報を返します。`request` フィールドはタスク発行時のリクエストボディ、`response` フィールドはタスク完了後に返されたレスポンスボディです。例：

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

フィールドの説明は以下の通りです：

- `id`：生成タスクの ID。今回の生成タスクを一意に識別します。
- `request`：照会タスクのリクエスト情報。
- `response`：照会タスクのレスポンス情報。

## 一括照会操作

複数のタスク ID でタスク詳細を照会する場合は、`action` を `retrieve_batch` に設定し、`ids` にタスク ID の配列を渡します。

**Request Body** は以下を含みます：

- `ids`：照会したいタスク ID の配列。
- `action`：タスクに対する操作方法。一括照会の場合は `retrieve_batch` を指定します。

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
