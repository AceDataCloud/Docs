本書では、Grok Videos Generation APIの連携方法について説明します。入力テキストのプロンプト、画像、及び任意の参考画像を用いてGrok Imagine（xAI）動画を生成できます。

## 申請手順

APIを利用するには、まず [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos) の該当ページからサービス申請を行います。ページにアクセスしたら、「Acquire」ボタンをクリックしてください。図のように表示されます。

![](https://cdn.acedata.cloud/q6ytrc.png)

未ログインまたは未登録の場合、自動的にログインページにリダイレクトされ、登録・ログイン後は自動的に元のページに戻ります。

初回申請時には無料のクォータが付与され、無料でAPIを利用できます。

## モデルの説明

本APIは2種類のモデルに対応しています。

- `grok-imagine-video-1.5-fast`（デフォルト）：文章から動画生成（`prompt`のみ）と画像から動画生成（`image_url`）をサポート。価格が安い。
- `grok-imagine-video-1.5`：画像から動画生成のみをサポートし、**必須**で`image_url`を指定。

## 基本的な使い方

まず、基本的な使い方を理解します。`prompt`や`model`などのパラメータを入力して、対応する動画を生成します。

リクエストヘッダーには以下を設定します。

- `accept`：受信したいレスポンスのフォーマット。ここでは`application/json`を指定し、JSON形式で受け取ります。
- `authorization`：API呼び出し用のAPIキー。申請後に選択可能。

また、リクエストボディには以下を設定します。

- `prompt`：生成したい動画の内容を記述したテキスト。`grok-imagine-video-1.5-fast`を使う場合は**必須**。`image_url`を指定する場合は任意。
- `model`：動画生成に使うモデル。`grok-imagine-video-1.5-fast`（デフォルト）または`grok-imagine-video-1.5`。
- `image_url`：画像から動画を生成する場合の入力画像のURL。`model`が`grok-imagine-video-1.5`の場合は**必須**。
- `reference_image_urls`：参考画像のURL配列。動画のスタイルや内容の指針として利用。
- `aspect_ratio`：生成動画の縦横比。`1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`から選択。
- `resolution`：出力解像度。`480p`（デフォルト）または`720p`。高解像度ほど消費クォータが増加。
- `duration`：動画の長さ（秒）。範囲は1–15秒。デフォルトは8秒。出力秒数に基づき課金。
- `callback_url`：非同期コールバック用URL。設定するとAPIは即座に`task_id`を返し、完了時に結果をPOSTします。

「Try」ボタンをクリックしてテスト可能です。結果例は以下の通り。

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video-1.5-fast:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
      "state": "succeeded"
    }
  ]
}
```

結果には複数のフィールドがあります。

- `success`：動画生成リクエストの成功可否。
- `task_id`：今回のタスクID。
- `trace_id`：リクエストのトレースID。問題調査に利用。
- `data`：生成された動画のリスト。
  - `id`：動画の一意識別子。
  - `video_url`：動画のURL。
  - `state`：タスクの状態。`pending` / `succeeded` / `failed`。

`data`内の`video_url`を取得して動画を確認します。

対応するcURL例は以下の通り。

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "resolution": "480p",
  "duration": 8
}'
```

Python例は以下。

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video-1.5-fast",
    "resolution": "480p",
    "duration": 8
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 画像から動画生成

画像を入力して動画を生成したい場合は、`image_url`を指定します。`grok-imagine-video-1.5`を使う場合は必須です。

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5",
  "image_url": "https://cdn.acedata.cloud/5hmkdg.jpg",
  "resolution": "720p",
  "duration": 8
}
```

## 参考画像による指示

複数の参考画像を用いて動画のスタイルや内容を指示したい場合は、`reference_image_urls`に画像URL配列を設定します。

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video-1.5-fast",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/vunnjf.png"
  ]
}
```

## 非同期コールバック

動画生成には時間がかかるため、長時間待ちたくない場合は`callback_url`を指定します。設定するとAPIは即座に`task_id`を返し、完了後に結果をPOSTします。

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "duration": 8,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

即時のレスポンス例は以下。

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## タスク結果の確認

非同期コールバックを利用するか、または`task_id`を用いて結果を取得したい場合は、[Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks)の`POST https://api.acedata.cloud/grok/tasks`を使い、`task_id`から最新の状態と結果を照会します。

## 料金体系

本サービスは動画の「出力秒数」に基づいて課金されます。単価は`model`と`resolution`により決定され、総額は`単価`×`duration`（デフォルト8秒）です。`720p`は`480p`より高価で、`grok-imagine-video-1.5`は`grok-imagine-video-1.5-fast`より高価です。詳細な単価は料金ページを参照してください。

## エラー処理

リクエストに問題がある場合、APIはエラーコードと説明を返します。代表的なものは以下の通り。

- `400`：リクエストパラメータ誤り。例：文章動画で`prompt`未設定、`grok-imagine-video-1.5`で`image_url`未設定、`duration`が1–15範囲外。
- `401`：認証失敗。トークン無効または不一致。
- `403`：残高不足、または内容審査拒否。
- `429`：リクエスト過多。上流のレートリミット超過。しばらく待って再試行。
- `500`：サーバー内部エラーまたは上流生成失敗。
