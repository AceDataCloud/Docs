## 1. API Key を取得する

[Ace Data Cloud アプリケーション一覧](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリケーションに入り、API Key をコピーします。

![Ace Data Cloud API Key を取得する](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. OpenCode をインストールする

```bash
curl -fsSL https://opencode.ai/install | bash
```

npm を使用することもできます：

```bash
npm install -g opencode-ai
```

## 3. API Key を設定する

```bash
export ACEDATACLOUD_API_KEY="あなたの API Key"
```

長期的に有効にする必要がある場合は、この行を `~/.zshrc` または `~/.bashrc` に追加してから、ターミナルを再度開きます。

## 4. Provider を設定する

`~/.config/opencode/opencode.json` を編集します：

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ace Data Cloud",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  }
}
```

[モデルカタログ](https://platform.acedata.cloud/models)に移動してモデル名（例：`claude-opus-5`、`gpt-6-sol`）を確認し、すべての `MODEL_ID` を同じ名前に置き換えます。厳密な確認時には、`/v1/models` のレスポンスにある `id` の値を基準にしてください。この値は API の `model` パラメータで使用するモデル名であり、サービスまたは API の UUID ではありません。Ace Data Cloud ではここで Chat Completions を使用するため、adapter は `@ai-sdk/openai-compatible` です。

## 5. 検証して起動する

```bash
opencode auth list
opencode models acedatacloud
opencode run --model acedatacloud/MODEL_ID "Reply only OK"
```

その後、プロジェクトディレクトリで `opencode` を実行します。モデルが表示されない場合は、設定ファイルのパス、JSON 構文、環境変数を確認してください。401 は Key が無効であるか、エクスポートされていないことを示します。

IDE 拡張機能は同じ OpenCode runtime 設定を再利用します。[OpenCode IDE Extension](https://platform.acedata.cloud/documents/opencode-ide-integration)を参照してください。
