## 1. API キーの取得

[Ace Data Cloud アプリケーションリスト](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリにアクセスして API キーをコピーします。

![Ace Data Cloud API キーの取得](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. OpenClaw とプラグインのインストール

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

プラグインは OpenClaw `2026.4.2` 以上を要求し、現在はネイティブで Chat と Web Search 機能を提供しています。

## 3. キーの設定

オンボーディングを使用することをお勧めします：

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "あなたの API キー"
```

環境変数を使用することもできます：

```bash
export ACEDATACLOUD_API_KEY="あなたの API キー"
```

## 4. オプション：手動設定

オンボーディングを使用しない場合、`~/.openclaw/openclaw.json` でプラグインを有効にし、デフォルトモデルを設定します：

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

API キーをこのファイルに書き込まないでください；環境変数を使用し続けてください。

## 5. モデルの選択と検証

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "OK のみ返信"
```

`MODEL_ID` を Coding Plan が現在提供しているモデルに置き換えます。デフォルトモデルとして設定する必要がある場合は、次のコマンドを実行します：

```bash
openclaw models set acedatacloud/MODEL_ID
```

呼び出し履歴は [使用履歴](https://platform.acedata.cloud/console/usages) で確認できます。401 はキーが無効であることを示します；モデルが存在しない場合は、まず正確な ID とプラグインのバージョンを確認してください。プラグインディレクトリ内の `cost: 0` は、OpenClaw による再評価が行われないことを示すだけで、実際の費用は Ace Data Cloud によって記録されます。

## Web Search

```bash
openclaw infer web search \
  --provider acedatacloud --query "最新の AI エージェントフレームワーク" --limit 5
```

現在、プラグイン紹介に含まれる画像、動画、音楽機能を OpenClaw のネイティブプロバイダー機能として扱わないでください。
