## 1. API キーの取得

[Ace Data Cloud アプリケーションリスト](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリに入り、API キーをコピーします。

![Ace Data Cloud API キーの取得](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 設定

Kilo CLI は `kilo.jsonc` を読み込み、CLI を起動したシェルから API キーを取得します。

`~/.config/kilo/kilo.jsonc` に書き込みます：

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

次に、現在のシェルでトークンをエクスポートします：

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
```

## 3. 検証

```bash
kilo run -m acedatacloud/MODEL_ID "Reply only OK"
```

CLI がトークンを読み取れない場合、変数が `export` されていることを確認し、未読み込みの `.env` ファイルに書き込まれているだけではないことを確認してください。
