## 1. API Key を取得する

[Ace Data Cloud アプリケーション一覧](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリケーションに入り、API Key をコピーします。

![Ace Data Cloud API Key を取得する](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. ウィザードを実行する

```bash
hermes model
```

**Custom endpoint** を選択し、以下の順に入力します：

| フィールド             | 値                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | 先ほどコピーした API Key                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | [モデルカタログ](https://platform.acedata.cloud/models)で確認し、対象モデル名をそのまま入力します。例：`claude-opus-5`、`gpt-6-sol` |
| Context length | 空欄のまま自動検出するか、モデルカタログに従って入力                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model` は API リクエストの `model` パラメータで使用するモデル名であり、サービスまたは API の UUID ではありません。まず[モデルカタログ](https://platform.acedata.cloud/models)で確認できます。正確な検証が必要な場合は、現在の API Key を使用して `GET https://api.acedata.cloud/v1/models` をリクエストし、レスポンスの `data` 配列から対象モデルの `id` 値をコピーしてください。

ウィザードは `~/.hermes/config.yaml` とローカルの認証情報ファイルに書き込みます。

## 3. 検証

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

ウィザードが設定を保存しなかった場合は、`hermes model --reset` を実行してから再試行できます。401 は API Key が無効であるか、現在のユーザーの設定によって読み取られていないことを示します。
