Continue の JetBrains プラグインは、VS Code と同じ YAML モデル形式を使用します。設定と Secret は、JetBrains プラグインを実行するユーザーに属する必要があります。

## 設定

Continue のローカル YAML 設定に追加します：

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Continue secrets に `ACEDATACLOUD_API_KEY` を保存します。Remote Development シナリオでは、プラグインが実際に実行されるホストの設定が必要です。

## 検証

JetBrains IDE を再起動し、Continue ツールウィンドウを開き、Local Config モデルを選択して `Reply only OK` を送信します。その後、再度読み取り専用ファイルタスクを実行します。まだ古いモデルを使用している場合は、リモートバックエンドを再起動し、YAML のインデントを確認します。
