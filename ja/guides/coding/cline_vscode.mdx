## 1. API Key を取得する

[Ace Data Cloud アプリケーション一覧](https://platform.acedata.cloud/console/applications) を開き、利用可能なアプリケーションに入り、API Key をコピーします。

![Ace Data Cloud API Key を取得する](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Cline を設定する

VS Code で Cline をインストールして開き、Cline パネル内の設定ボタンから Provider 設定に入り、以下を入力します：

| フィールド                                | 値                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| API Provider                      | `OpenAI Compatible`                                                                            |
| Base URL                          | `https://api.acedata.cloud/v1`                                                                 |
| API Key                           | 先ほどコピーした API Key                                                                                  |
| Model ID                          | [モデルカタログ](https://platform.acedata.cloud/models) で確認し、対象モデル名をそのまま入力します。例：`claude-opus-5`、`gpt-6-sol` |
| Custom Headers                    | 空欄                                                                                             |
| Set Azure API version             | 空欄                                                                                             |
| Use Azure Identity Authentication | オフ                                                                                             |

![Cline OpenAI Compatible 設定画面](https://cdn.acedata.cloud/8f356c2f1378.png)

`Model ID` は API リクエストの `model` パラメータで使用するモデル名であり、サービスまたは API の UUID ではなく、独自に省略することもできません。まずは[モデルカタログ](https://platform.acedata.cloud/models)で確認できます。正確に検証する必要がある場合は、現在の API Key を使用して `GET https://api.acedata.cloud/v1/models` をリクエストし、レスポンスの `data` 配列から対象モデルの `id` 値をコピーしてください。

その他のモデル機能設定はまずデフォルトのままにしてください。画像またはより大きなコンテキストが必要な場合は、選択したモデルの実際の機能に応じて調整してください。

## 3. 検証

保存後、新しいタスクを作成して `Reply only OK` を送信します。次に、Cline にテストファイルを読み取らせ、モデルがツール呼び出しに対応していることを確認してください。呼び出し履歴は[使用履歴](https://platform.acedata.cloud/console/usages)で確認できます。

401 は通常 Key の誤りを示します。404 は通常 Base URL が正しくない、または入力した Model ID がカタログ内の `id` と完全に一致していないことを示します。モデルがチャットできてもファイルを操作できない場合は、そのモデルのツール呼び出し機能を確認してください。
