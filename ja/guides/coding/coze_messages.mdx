Coze 公式カスタムモデルドキュメントは Anthropic Messages API をサポートしています。異なる Coze テナントバージョンは、ヘッダー、パスの結合、ストリーミング、およびツール呼び出しの処理が異なる場合があります。初めて接続する場合は、以下の項目を順に確認してください。

## 設定

1. Coze モデル管理に入り、新しいカスタムモデルを追加します。
2. プロトコルに Anthropic Messages API を選択します。
3. ベース API URL に `https://api.acedata.cloud` を入力します。
4. API キーにあなたの Ace Data Cloud API トークンを入力します。
5. モデルにモデルディレクトリ内で Anthropic Messages をサポートする正確なモデル ID を入力します。
6. 保存して Coze の接続テストを完了します。
7. Bot/Agent に `Reply only OK` を送信し、再度ツール呼び出しをテストします。

## 現在の制約

- 異なる Coze エリア、バージョン、またはプランは異なるフォームを表示する場合があります。
- ベース API URL に `/v1/messages` を重複して追加してはいけません；現在の UI が完全な API URL を明示的に要求する場合は、フォームの指示に従ってください。
- Messages、Chat Completions、および Responses は三つの独立したルートであり、互いに置き換えて検証することはできません。
