## 1. APIキーの取得

[Ace Data Cloud アプリケーションリスト](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリに入り、APIキーをコピーします。

![Ace Data Cloud APIキーの取得](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. プロバイダーの設定

Kilo CodeのJetBrainsプラグインは`kilo.jsonc`プロバイダー形式を使用します。設定は、実際にプラグインを実行するユーザー環境に存在する必要があります。リモート開発時は通常、リモートバックエンドホストです。

`~/.config/kilo/kilo.jsonc`に次のように書き込みます：

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

JetBrainsバックエンドを起動する環境で`ACEDATACLOUD_API_KEY`をエクスポートし、IDEまたはリモートバックエンドを再起動します。

## 3. 検証

`acedatacloud/MODEL_ID`を選択し、`Reply only OK`を送信し、エージェントにテストファイルを読み込ませます。ローカルが正常でリモートが失敗した場合、まず設定ファイルと環境変数がリモートホストに正しく書かれているかを確認します。
