## 1. API Key を取得する

[Ace Data Cloud アプリケーションリスト](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリケーションに入り、API Key をコピーします。

![Ace Data Cloud API Key を取得する](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Custom provider を追加する

Kilo Code で **Settings → Providers** を開き、**Custom provider** をクリックしてから、以下を入力します：

| フィールド           | 値                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------- |
| Provider ID  | `acedatacloud`                                                                                 |
| Display name | `AceDataCloud`                                                                                 |
| Provider API | `OpenAI Compatible`                                                                            |
| Base URL     | `https://api.acedata.cloud/v1`                                                                 |
| API key      | 先ほどコピーした API Key                                                                                |
| Models       | [モデルカタログ](https://platform.acedata.cloud/models)に移動して確認し、使用するモデル名を追加します。例：`claude-opus-5`、`gpt-6-sol` |

![Kilo Code Custom provider 設定画面](https://cdn.acedata.cloud/94eb5abd7a6f.png)

ここでのモデル `id` は、API リクエストの `model` パラメータで使用するモデル名であり、サービスまたは API の UUID ではありません。まずは[モデルカタログ](https://platform.acedata.cloud/models)で確認できます。厳密な検証を行う際は、`/v1/models` レスポンスの `data` 配列からそのままコピーし、自分で推測したり省略したりしないでください。

**Submit** をクリックすると、モデルがセレクターに表示されます。チーム共有やより詳細な設定が必要な場合は、公式ドキュメントに従ってユーザーレベルの `~/.config/kilo/kilo.jsonc` またはプロジェクトレベルの `./kilo.jsonc` を編集することもできます。

## 3. 検証

`acedatacloud/MODEL_ID` を選択して `Reply only OK` を送信し、その後、読み取り専用のファイル操作を 1 回実行します。モデルが表示されない場合は、Provider が送信済みであるか、モデル名がカタログ内の `id` と完全に一致しているか、そして Base URL が正しいかを確認してください。
