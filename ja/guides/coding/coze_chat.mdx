Coze 公式カスタムモデルドキュメントは OpenAI Chat API をサポートしています。異なる Coze テナントバージョンでは、パスの結合、ストリーミング出力、ツール呼び出しの処理が異なる場合があります。初めて接続する場合は、以下の項目を順に確認してください。

## 設定

1. Coze モデル管理に入り、新しいカスタムモデルを追加します。
2. プロトコルを OpenAI Chat API に選択します。
3. ベース API URL に `https://api.acedata.cloud/v1` を記入します。
4. API キーにあなたの Ace Data Cloud API トークンを記入します。
5. モデルにモデルディレクトリ内で Chat Completions をサポートする正確なモデル ID を記入します。
6. 保存して Coze の接続テストを完了します。
7. Bot/Agent に `Reply only OK` を送信し、再度ツール呼び出しをテストします。

## 現在の制約

- 異なる Coze エリア、バージョン、またはプランでは異なるフォームが表示される場合があります。
- ベース API URL はベースを使用し、`/chat/completions` を繰り返し追加しないでください。現在の UI が完全な API URL を明示的に要求する場合は、フォームの指示に従ってください。
- Chat Completions、Responses、および Anthropic Messages は三つの独立したルートであり、互いに置き換えて検証することはできません。
