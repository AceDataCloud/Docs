## 1. API Key の取得

[Ace Data Cloud アプリケーション一覧](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリケーションに入り、API Key をコピーします。

![Ace Data Cloud API Key の取得](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 設定

Roo Code 公式は OpenAI-compatible Provider を提供しており、モデルがネイティブの OpenAI tools/function calling をサポートしていることを要求します。

1. VS Code で Roo Code の設定を開きます。
2. **API Provider** を **OpenAI Compatible** に設定します。
3. 以下を入力します：

| フィールド       | 値                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | 先ほどコピーした API Key                  |
| Model ID | Coding 設定ウィザードで選択したモデル ID         |

![Roo Code OpenAI Compatible 設定画面](https://cdn.acedata.cloud/b6a0e7156438.png)

続いて、モデルの実際の能力に応じて context、max output、画像、および computer-use のオプションを設定します。最後に設定を保存し、VS Code を再読み込みします。

## 3. 検証

まず `Reply only OK` を送信し、その後 Roo Code にテストファイルを読み取らせます。通常のチャットは成功するものの Agent ツールが失敗する場合は、ネイティブの tool calling をサポートするモデルに変更し、互換エンドポイントがツールのパラメータと結果を正しくストリーミングで返せることを確認してください。
