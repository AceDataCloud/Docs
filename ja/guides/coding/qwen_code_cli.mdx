Qwen Code は `~/.qwen/settings.json` の `modelProviders` 設定を使用してカスタムプロバイダーを設定します。ここでは OpenAI 互換プロトコルを固定で使用します。

## 設定

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud` は配列でなければなりません。プロバイダー項目は独立して設定され、他のトップレベルのコンテキスト、ヘッダー、またはボディパラメータを自動的に継承することはありません。

## 検証

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Reply only OK"
```

入った後に `Reply only OK` を送信し、再度読み取り専用ファイルツールを実行します。厳密に互換性のあるエンドポイントがツールの結果形式を拒否する場合は、現在の Qwen Code バージョンと公式の互換性説明を確認してください。
