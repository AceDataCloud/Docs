ContinueはOpenAI互換APIをサポートしています。Chat Completionsを固定するためには、`useResponsesApi: false`を明示的に設定する必要があります。

## 設定

ContinueのローカルYAML設定に以下を追加します：

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Continueのシークレット管理に`ACEDATACLOUD_API_KEY`を保存し、実際のトークンをプロジェクト設定にコミットしないでください。ContinueのJSON設定は廃止され、新しい設定はYAMLを使用します。

## 検証

VS Codeを再読み込みし、Continueサイドバーを開いて、Local Configのモデルを選択し、`Reply only OK`を送信します；次に、再度読み取り専用ファイルタスクを実行します。リクエストが誤って`/responses`に送信された場合は、`useResponsesApi: false`がそのモデルエントリ内にあるか確認してください。
