Aider は LiteLLM の `openai/` モデルプレフィックスを通じて OpenAI 互換 API に接続します。

## 設定

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

`MODEL_ID` を Coding 設定ウィザードで選択したモデルに置き換えます。対応するオプションをローカルの `.env` または `.aider.conf.yml` に書き込むこともできますが、実際のトークンを提出しないでください。

## 検証

```bash
aider --model openai/MODEL_ID --message "Reply only OK"
```

未知のモデルを初めて使用する際、Aider はモデルメタデータが不足していることを示す場合がありますが、これは認証失敗とは異なります。401 はトークンを確認し、404 はモデル ID と `/v1` ベース URL を確認します。
