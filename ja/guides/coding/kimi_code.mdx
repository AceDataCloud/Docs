## 1. API Key を取得する

[Ace Data Cloud アプリケーション一覧](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリケーションに入り、API Key をコピーします。

![Ace Data Cloud API Key を取得する](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Kimi Code をインストールする

macOS / Linux：

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

npm 経由でインストールすることもできます：

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. AceDataCloud を設定する

`~/.kimi/config.toml` を編集し、以下の設定を追加します：

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "あなたの API Key"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

[モデルディレクトリ](https://platform.acedata.cloud/models)に移動してモデル名（例：`claude-opus-5`、`gpt-6-sol`）を確認し、すべての `MODEL_ID` を同じ名前に置き換えます。厳密に確認する場合は、`/v1/models` レスポンス内の `id` 値を基準にしてください。この値が API の `model` パラメータで使用するモデル名であり、サービスまたは API の UUID ではありません。`type = "openai"` は OpenAI Chat Completions プロトコルを使用します。

設定ファイルには Key が含まれるため、macOS / Linux では権限を制限することを推奨します：

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. 検証して起動する

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

プロジェクトに入った後、`kimi` を実行すれば使用を開始できます。401 が返される場合は API Key を確認してください。model not found と表示される場合は、`default_model`、モデルテーブル名、および `model` フィールドで同じ ID を使用していることを確認してください。
