Flux Videos API は `POST /flux/videos` を使用して動画生成、キーフレーム画像からの動画生成、動画の継続、およびドラフト強化を行います。`action` は生成、編集、超解像を区別し、`mode` は生成モードを選択します。結果の照会には、既存の `POST /flux/tasks` を統一して使用します。

> 現在は Beta です。テキストからの動画生成、画像からの動画生成、動画の継続、およびドラフト強化はすでに公開されています。2026-10-02 の実測では、動画編集と超解像は `service_unavailable` を返し、この 2 項目は現在利用できません。失敗したタスクでは生成料金は差し引かれません。HTTP 200 とタスク ID はタスクの受理のみを示すため、最終結果を引き続き照会する必要があります。

## 1. API Token を取得する

1. [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications) で登録またはログインし、アプリケーションを作成して API Token を取得します。汎用 API Token 1 つでプラットフォームサービスを呼び出せます。アプリケーションに Flux サービスの呼び出し権限と利用可能な残高があることを確認してください。
2. [Flux サービスページ](https://platform.acedata.cloud/services/flux?tab=pricing) でプランおよび各操作の価格を確認します。残高が不足している場合は、[コンソール残高ページ](https://platform.acedata.cloud/console/coin) でチャージしてください。
3. リクエストでは `Authorization: Bearer &lt;あなたの Token>` を使用します。Token はサーバー側の環境変数に保存し、フロントエンドページ、公開リポジトリ、スクリーンショット、またはコールバック URL に書き込まないでください。

![コンソールで API Token を申請](https://cdn.acedata.cloud/dvc3cg.jpg)

本文のコードはすべて環境変数を読み取ります：

```bash
export ACEDATACLOUD_API_TOKEN='自分の API Token に置き換える'
```

| 項目      | 値                                               |
| ------- | ----------------------------------------------- |
| API ルートアドレス | `https://api.acedata.cloud`                     |
| 動画タスクを送信  | `POST /flux/videos`                             |
| 既存タスクを照会  | `POST /flux/tasks`                              |
| 認証      | `Authorization: Bearer $ACEDATACLOUD_API_TOKEN` |
| リクエスト形式    | `Content-Type: application/json`                |

完全なフィールドとオンラインデバッグについては [Flux Videos API](https://platform.acedata.cloud/documents/flux-videos)、タスク照会については [Flux Tasks API](https://platform.acedata.cloud/documents/flux-tasks) を参照してください。

## 2. 操作と入力を選択する

| action                      | mode            | 入力                       | 結果            |
| --------------------------- | --------------- | ------------------------ | ------------- |
| `generate`（action を省略した場合のデフォルト値） | `t2v`           | `prompt`                 | テキストから動画を生成       |
| `generate`                  | `i2v`           | `prompt`、`keyframes`     | 1 枚または複数枚のキーフレームから動画を生成 |
| `generate`                  | `v2v`           | `prompt`、`start_video`   | 入力動画に基づいて継続      |
| `generate`                  | `draft_enhance` | 自身が完了したドラフトの `draft_task_id` | そのドラフトを強化         |
| `edit`                      | 渡さない              | `video`、`prompt`         | 動画編集（現在利用不可）    |
| `upscale`                   | 渡さない              | `input_video`            | 動画超解像（現在利用不可）    |

生成モデルは `flux-3` です。編集と超解像ではそれぞれ固有のフィールドを使用し、生成用の `model`、`mode`、`duration`、`draft` などのパラメータは渡しません。`action=upsale` はスペルミスであり、`upscale` にする必要があります。

### 共通生成パラメータ

| パラメータ                 | 説明                                                           |
| ------------------ | ------------------------------------------------------------ |
| `mode`             | 必須；`t2v`、`i2v`、`v2v` または `draft_enhance`                       |
| `prompt`           | 通常生成では必須；ドラフト強化では元のプロンプトを上書きできない                                        |
| `duration`         | t2v/i2v は 5～20 秒の整数、v2v は 5～15 秒の整数、または `auto`；最終出力の長さはリクエスト値とわずかに異なる可能性がある |
| `resolution`       | `hd`、`fhd`、`qhd`、`uhd`；通常生成のデフォルトは `hd`、ドラフト強化のデフォルトは `fhd`              |
| `aspect_ratio`     | `auto`、`21:9`、`2:1`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`9:21`   |
| `draft`            | 先にドラフトを生成するかどうか；ドラフトは `hd` のみ対応                                           |
| `generate_audio`   | 同期音声を生成するかどうか；`false` は有効な値なので、明示的なブール値を保持すること                               |
| `safety_tolerance` | 任意；0～4 の整数                                                   |
| `async`            | `true` に設定することを推奨。プラットフォームのタスク ID を即座に返し、その後結果をポーリングする                                |
| `callback_url`     | 任意；最終 JSON 結果を受け取る HTTP(S) アドレス；設定後も非同期で受理される                        |

素材 URL はサービスから読み取れる必要があります。一時的な署名 URL を使用する場合は、ダウンロードと処理のために十分な有効期間を確保してください。Web ページのアドレスを画像または動画ファイルのアドレスとして使用しないでください。

## 3. テキストから動画：完全な実測リクエストと結果

以下のリクエストは、2026-10-02 の価格改定前に本番インターフェースで正常に実行されました。`action` を省略することでデフォルトの生成動作を検証し、`async=true` により HTTP 接続の長時間待機を回避しています。

```bash
curl -X POST 'https://api.acedata.cloud/flux/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light, steady camera, no text.",
    "duration": 5,
    "resolution": "hd",
    "draft": true,
    "async": true
  }'
```

受理レスポンス（実際のタスク ID）：

```json
{
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607"
}
```

自身のレスポンス内の `task_id` を保存して、引き続き照会してください。ドキュメント例のタスク ID を使用して、他のアカウントの結果を照会しないでください。

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"今回返された task_id に置き換える"}'
```

タスク照会で返される `response` フィールドには、最終的なビジネス結果が含まれます。以下は今回の実測で成功した `response` であり、外側のタスクメタデータは省略されています。ドキュメント内の動画 URL は、長期利用可能なサンプル CDN 上の同一ファイルのコピー（SHA-256 は一致）に置き換えられています。実際の呼び出しでは、今回のタスク固有の結果 URL が返されます：
```json
{
  "success": true,
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607",
  "data": [
    {
      "id": "4341eb66-3845-4972-bb86-712a6cfae845",
      "model": "flux-3",
      "video_url": "https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4",
      "seconds": 5.041667,
      "width": 1280,
      "height": 704,
      "fps": 24,
      "draft_task_id": "4341eb66-3845-4972-bb86-712a6cfae845"
    }
  ],
  "usage": {
    "action": "generate",
    "seconds": 5.041667,
    "output_mp_seconds": 4.3326825781250005,
    "mode": "t2v",
    "resolution": "hd",
    "draft": true
  },
  "cost": {
    "amount": 2.6884689277500002,
    "currency": "credit",
    "list_amount": 2.9871876975000005
  }
}
```

[今回の実測動画を確認](https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4)。メディア検査により、出力は 1280×704、24 fps、5.041667 秒の MP4 であり、ファイルサイズは 2,607,276 バイトであることを確認しました。

| レスポンスフィールド                              | 用途                                       |
| --------------------------------- | ---------------------------------------- |
| `success`                         | 最終タスクが成功したかどうか。受付段階で task_id が返されることは success=true と同義ではない |
| `task_id`                         | プラットフォームのタスク ID。ポーリングおよび業務上の冪等処理に使用                      |
| `trace_id`                        | 問題調査時にサポート担当者へ提供                             |
| `data[].video_url`                | 読み取り可能な動画結果のアドレス                               |
| `data[].seconds/width/height/fps` | サーバー側で測定された実際の出力時間、サイズ、フレームレート                       |
| `data[].draft_task_id`            | ドラフト強化の入力 ID。再利用可能なドラフトが返される場合にのみ出現                  |
| `usage`                           | 最終的な課金使用量。リクエストの duration で実際の seconds を上書きしないこと      |
| `cost.amount`                     | 今回最終的に差し引かれた Credits。`currency=credit` は米ドルではない   |
| `cost.list_amount`                | アプリユーザーの割引適用前の Credits。該当する場合に返される                 |

これは価格改定前の過去の実測です：`list_amount=2.9871876975` Credits、アカウントは当時 10% の利用割引を享受しており、実際の `amount=2.68846892775` Credits でした。2026-10-02 に新価格は約 6.33% 引き下げられました。同じ 5.041667 秒のドラフトは現在価格で 2.798125185 Credits（利用割引前）であり、引き続き 10% の利用割引がある場合は 2.5183126665 Credits です。過去のタスクの請求額は再計算されません。他のアカウントのプランや割引は異なる場合があります。これはすべてのユーザーに固定された米ドル価格ではありません。

## 4. 画像から動画：通常と時間付きキーフレーム

以下はパラメータ例であり、素材 URL を置き換える必要があります。この例がすでに正常に実行されたことを示すものではありません。生成完了後は上記のフローに従って照会してください。結果の構造は同じです。

1 枚または 2 枚の画像には通常の配列を使用します：

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "The camera slowly moves around the product in soft studio light.",
  "keyframes": ["https://example.com/first-frame.jpg"],
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "async": true
}
```

キーフレーム時刻を指定する場合は、`[秒数, 画像 URL]` のペアを使用します：

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "A smooth transition from morning light to a warm sunset.",
  "keyframes": [[0, "https://example.com/start.jpg"], [5, "https://example.com/end.jpg"]],
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

1～10 枚のキーフレームが許可されます。時間付き配列は時間の昇順である必要があり、時間は 0～20 秒です。通常の URL と時間付き項目を混在させることはできません。3 枚以上の通常のキーフレームでは、duration を明示的に指定する必要があり、auto は使用できません。

## 5. 動画の継続

`start_video` に既存の動画ファイル URL を渡し、`mode=v2v`、長さは最大 15 秒です。これは編集で使用する `video` とは異なるフィールドです。

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "v2v",
  "prompt": "Continue the sailboat drifting forward with the same steady camera.",
  "start_video": "https://example.com/source.mp4",
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

## 6. まずドラフト、その後に強化

1. `draft=true`、`resolution=hd` でドラフトを生成し、成功するまで待機します。
2. 最終的な `data[0].draft_task_id` からプラットフォームのドラフト ID を取得します。
3. 同じ帰属のアプリケーション認証情報を使用して強化リクエストを送信します。

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "draft_enhance",
  "draft_task_id": "替换为自己的已完成草稿 ID",
  "resolution": "fhd",
  "async": true
}
```

ドラフト強化では、`prompt`、`duration`、`aspect_ratio`、`version`、`generate_audio`、`draft`、`keyframes`、`start_video` を渡して元の内容を上書きすることはできません。ドラフトキャッシュは一時リソースのため、速やかに強化してください。永続保存または固定された保存日数は保証されません。本人以外／現在のアプリケーション以外のドラフト、未完了のドラフト、期限切れのキャッシュは再利用できません。ドラフトと強化は 2 回のタスクであり、成功後にそれぞれ課金されます。

## 7. Python エンドツーエンド呼び出し

`requests` をインストールし、自身の Token を設定して、以下のスクリプトを実行すれば「1 回送信 → ポーリング → 動画 URL の出力」を完了できます。クエリとネットワーク再試行はいずれも元の task_id を使用し、課金タスクの重複送信を避ける必要があります。
```python
import os
import time
import requests

base_url = "https://api.acedata.cloud"
headers = {
    "Authorization": "Bearer " + os.environ["ACEDATACLOUD_API_TOKEN"],
    "Accept": "application/json",
}
payload = {
    "action": "generate",
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light.",
    "duration": 5,
    "resolution": "hd",
    "draft": True,
    "async": True,
}
submitted = requests.post(base_url + "/flux/videos", json=payload, headers=headers, timeout=120)
submitted.raise_for_status()
accepted = submitted.json()
if accepted.get("error"):
    raise RuntimeError(accepted["error"])
task_id = accepted["task_id"]
print("Task ID:", task_id)  # 持久化保存，用于恢复轮询

# 30 分钟是本示例的客户端等待上限，不是服务的完成时限承诺。
deadline = time.monotonic() + 30 * 60
while time.monotonic() < deadline:
    polled = requests.post(
        base_url + "/flux/tasks",
        json={"action": "retrieve", "id": task_id},
        headers=headers,
        timeout=30,
    )
    polled.raise_for_status()
    task = polled.json()
    if task.get("error"):
        raise RuntimeError(task["error"])
    result = task.get("response") or task.get("result")
    if isinstance(result, dict) and result.get("success") is True:
        print("Video:", result["data"][0]["video_url"])
        print("Usage:", result.get("usage"))
        print("Cost:", result.get("cost"))
        break
    if isinstance(result, dict) and result.get("error"):
        raise RuntimeError(result["error"])
    time.sleep(10)
else:
    raise TimeoutError("Still processing; resume polling with task_id=" + task_id)
```

ネットワークタイムアウト後、未知の状態を失敗と見なして直ちに再送信しないでください。すでに task_id を取得している場合は、そのタスクを継続して照会してください。調査のために task_id と trace_id を記録してください。ポーリングインターフェース自体には生成料金はかかりません。

## 8. コールバックの使用

送信時に `callback_url` を追加すると、タスク完了後にそのアドレスへ最終 JSON 結果が POST されます。成功時の構造は前述の response と一致し、失敗時には error が含まれます。

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "t2v",
  "prompt": "A small sailboat on calm water.",
  "duration": 5,
  "resolution": "hd",
  "draft": true,
  "callback_url": "https://your-server.example/flux-callback"
}
```

コールバックアドレスはパブリックネットワークからアクセス可能である必要があります。通知を受信した後は、task_id に基づいて冪等に処理し、できるだけ早く 2xx を返してください。業務処理はキューに入れることができます。本書では、コールバックに署名認証があるとは宣言しません。業務上の権益の付与などの機密操作を行う前に、自身の Token を使用して同じタスクを照会し、結果を照合してください。コールバックを受信しない場合でもポーリングを継続できるため、再生成しないでください。

## 10. 現在の課金と価格表

米ドルへの換算：`実際の料金（USD）= cost.amount（Credits）× プラン price / プラン amount`。チャージプランと利用割引は実際の価格に影響し、Credits を直接 USD と見なすことはできません。失敗したタスクには生成料金はかかりません。最終金額は完了結果およびコンソールの呼び出し記録に従います。

## 11. よくある質問とトラブルシューティング
| 状況                       | 推奨                                           |
| ------------------------ | -------------------------------------------- |
| パラメータエラー（400）                | action のスペル、mode、duration、キーフレーム形式を確認する；異なる操作のフィールドを混在させない |
| 認証エラー（401）                | Bearer Token、アプリケーション権限および認証情報が有効か確認する                  |
| コンテンツ審査による拒否（403）              | 素材とプロンプトを調整し、そのまま繰り返し送信しない                            |
| レート制限（429）                  | 並行実行数を減らし、バックオフして再試行する                                    |
| service_unavailable（503） | 現在の操作は利用不可；受理済みの非同期タスクは最終 response でこのエラーを報告する可能性がある        |
| task_id は返されたがまだ動画がない        | response を引き続き照会し、HTTP 200 を生成完了と見なさない             |
| 下書きを再利用できない                   | 本人／現在のアプリケーションであること、タスクが完了していること、元のリクエストが draft=true であることを確認し、一時キャッシュがまだ有効か確認する  |

フィードバック時には task_id、trace_id、リクエスト時刻およびマスキング済みパラメータを提供し、API Token を送信しない。その他の方法については[Flux MCP 統合ガイド](https://platform.acedata.cloud/documents/flux-mcp)を参照。
