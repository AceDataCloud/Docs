`POST /flux/videos` を通じてタスクを送信し、`action` で生成、編集、またはアップスケールを選択します。`action` を省略した場合は `generate` と同等です。既存の `POST /flux/tasks` を使用してプラットフォームタスクを照会します。`async=true` と `callback_url` をサポートします。完了結果には、プラットフォームの動画リンクと、サーバー側で測定された長さ、サイズ、フレームレートが含まれます。

## 生成：action=generate

`mode=t2v/i2v/v2v/draft_enhance` をサポートします。通常生成では 5～20 秒の整数または `auto` をサポートします。動画継続では 5～15 秒をサポートします。i2v では 1～10 枚のキーフレームを指定でき、順序付きの `[秒数, 画像]` ペアをサポートします。出力解像度は hd/fhd/qhd/uhd で、同期オーディオをサポートします。ドラフトは hd のみを出力し、プラットフォームの `draft_task_id` を返します。ドラフトを再利用するには同一の帰属である必要があり、生成キャッシュの有効期限による制限を受けます。ドラフトの再現では、元のプロンプトと素材を上書きできません。

```json
{"action":"generate","model":"flux-3","mode":"t2v","prompt":"海边日落","duration":5,"resolution":"hd","async":true}
```

## 編集：action=edit

`video` と `prompt` を渡します。編集は実際の出力秒数に基づいて課金され、生成用の `mode`、`duration` などのフィールドは受け付けません。

```json
{"action":"edit","video":"https://example.com/video.mp4","prompt":"将场景改为蓝色调","async":true}
```

## アップスケール：action=upscale

`input_video` を渡し、オプションで `upscale_factor`（1.5～3）と `creativity`（0 は正確、1 はクリエイティブ）を指定できます。実際の出力 MP・秒に基づいて課金されます：`長さ × 幅 × 高さ / 1048576 × フレームレート / 24`、1 MP = 1024×1024。生成パラメータは受け付けません。

```json
{"action":"upscale","input_video":"https://example.com/video.mp4","upscale_factor":2,"creativity":0,"async":true}
```

各操作には現在の FLUX 基準価格係数が適用され、実際の出力に基づいて課金されます。失敗したタスクには生成料金は請求されません。動的課金タスクの最終料金は、完了結果によって決まります。異なる操作はそれぞれのパラメータのみを受け付け、未知の action はパラメータエラーを返します。
