Flux Videos API は `POST /flux/videos` を使用して、動画生成、キーフレーム画像からの動画生成、動画継続、ドラフト強化を実行します。`action=generate`（デフォルト）で、`mode` により生成モードを選択します。結果の照会はすべて既存の `POST /flux/tasks` を使用します。

> 現在は Beta です。テキストからの動画生成、画像からの動画生成、動画継続、ドラフト強化が公開されています。HTTP 200 とタスク ID はタスクが受理されたことのみを示すため、最終結果を引き続き照会する必要があります。

## 1. API Token を取得する

1. [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications)で登録またはログインし、アプリケーションを作成して API Token を取得します。汎用 API Token はプラットフォームサービスを呼び出せます。アプリケーションに Flux サービスの呼び出し権限と利用可能な残高があることを確認してください。
2. [Flux サービスページ](https://platform.acedata.cloud/services/flux?tab=pricing)でプランおよび各操作の価格を確認します。残高が不足している場合は、[コンソール残高ページ](https://platform.acedata.cloud/console/coin)でチャージしてください。
3. リクエストでは `Authorization: Bearer &lt;あなたの Token>` を使用します。Token はサーバー側の環境変数に保存し、フロントエンドページ、公開リポジトリ、スクリーンショット、またはコールバック URL に書き込まないでください。

![コンソールで API Token を申請](https://cdn.acedata.cloud/dvc3cg.jpg)

本記事のコードはすべて環境変数を読み取ります。

```bash
export ACEDATACLOUD_API_TOKEN='替换为你自己的 API Token'
```

| 項目      | 値                                               |
| ------- | ----------------------------------------------- |
| API ルートアドレス | `https://api.acedata.cloud`                     |
| 動画タスクを送信  | `POST /flux/videos`                             |
| 既存タスクを照会  | `POST /flux/tasks`                              |
| 認証      | `Authorization: Bearer $ACEDATACLOUD_API_TOKEN` |
| リクエスト形式    | `Content-Type: application/json`                |

完全なフィールドおよびオンラインデバッグについては [Flux Videos API](https://platform.acedata.cloud/documents/flux-videos)を、タスク照会については [Flux Tasks API](https://platform.acedata.cloud/documents/flux-tasks)を参照してください。

## 2. 操作と入力を選択する

| action                      | mode            | 入力                       | 結果            |
| --------------------------- | --------------- | ------------------------ | ------------- |
| `generate`（action を省略した場合のデフォルト値） | `t2v`           | `prompt`                 | テキストから動画を生成       |
| `generate`                  | `i2v`           | `prompt`、`keyframes`     | 1 枚または複数のキーフレームから動画を生成 |
| `generate`                  | `v2v`           | `prompt`、`start_video`   | 入力動画に基づいて継続      |
| `generate`                  | `draft_enhance` | 自身で完了済みのドラフトの `draft_task_id` | そのドラフトを強化         |

生成モデルは `flux-3`、`action` は `generate`（デフォルト）です。`mode` を通じて、テキストからの動画生成、画像からの動画生成、動画継続、またはドラフト強化を選択します。

### 共通生成パラメータ

| パラメータ                 | 説明                                                           |
| ------------------ | ------------------------------------------------------------ |
| `mode`             | 必須。`t2v`、`i2v`、`v2v` または `draft_enhance`                       |
| `prompt`           | 通常生成では必須。ドラフト強化では元のプロンプトを上書きできません                                        |
| `duration`         | t2v/i2v は 5～20 秒の整数、v2v は 5～15 秒の整数、または `auto`。最終出力の長さはリクエスト値とわずかに異なる場合があります |
| `resolution`       | `hd`、`fhd`、`qhd`、`uhd`。通常生成のデフォルトは `hd`、ドラフト強化のデフォルトは `fhd`              |
| `aspect_ratio`     | `auto`、`21:9`、`2:1`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`9:21`   |
| `draft`            | 先にドラフトを生成するかどうか。ドラフトは `hd` のみ対応                                           |
| `generate_audio`   | 同期音声を生成するかどうか。`false` は有効な値のため、明示的なブール値を保持してください                               |
| `safety_tolerance` | 任意。0～4 の整数                                                   |
| `async`            | `true` に設定することを推奨。プラットフォームタスク ID を直ちに返し、その後結果をポーリングします                                |
| `callback_url`     | 任意。最終 JSON 結果を受信する HTTP(S) アドレス。設定した場合も非同期で受理されます                        |

素材 URL はサービスが読み取れる必要があります。一時的な署名 URL を使用する場合は、ダウンロードと処理に十分な有効期限を確保してください。Web ページのアドレスを画像または動画ファイルのアドレスとして使用しないでください。

## 3. テキストからの動画生成：完全な実測リクエストと結果

以下のリクエストは、2026-10-02 の価格改定前に本番インターフェースで正常に実行されました。`action` を省略することでデフォルトの生成動作を検証し、`async=true` により HTTP 接続の長時間待機を回避しています。

```bash
curl -X POST 'https://api.acedata.cloud/flux/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light, steady camera, no text.",
    "duration": 5,
    "resolution": "hd",
    "draft": true,
    "async": true
  }'
```

受理レスポンス（実際のタスク ID）：

```json
{
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607"
}
```

自身のレスポンス内の `task_id` を保存し、引き続き照会してください。ドキュメントのサンプルタスク ID を使用して、他のアカウントの結果を照会しないでください。

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"替换为本次返回的 task_id"}'
```

タスク照会で返される `response` フィールドには、最終的な業務結果が含まれます。以下は今回の実測で成功した `response` であり、外側のタスクメタデータは省略されています。ドキュメント内の動画 URL は、長期サンプル CDN 上の同一ファイルのコピー（SHA-256 一致）に置き換えられています。実際の呼び出しでは、今回のタスク固有の結果 URL が返されます。
```json
{
  "success": true,
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607",
  "data": [
    {
      "id": "4341eb66-3845-4972-bb86-712a6cfae845",
      "model": "flux-3",
      "video_url": "https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4",
      "seconds": 5.041667,
      "width": 1280,
      "height": 704,
      "fps": 24,
      "draft_task_id": "4341eb66-3845-4972-bb86-712a6cfae845"
    }
  ],
  "usage": {
    "action": "generate",
    "seconds": 5.041667,
    "output_mp_seconds": 4.3326825781250005,
    "mode": "t2v",
    "resolution": "hd",
    "draft": true
  },
  "cost": {
    "amount": 2.6884689277500002,
    "currency": "credit",
    "list_amount": 2.9871876975000005
  }
}
```

[今回の実測動画を確認する](https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4)。メディア検査により、出力が 1280×704、24 fps、5.041667 秒の MP4 であり、ファイルサイズが 2,607,276 バイトであることを確認しました。

| レスポンスフィールド                              | 用途                                       |
| --------------------------------- | ---------------------------------------- |
| `success`                         | 最終タスクが成功したかどうか；受付段階で返される task_id は success=true と同義ではない |
| `task_id`                         | プラットフォームのタスク ID。ポーリングおよび業務上の冪等処理に使用                      |
| `trace_id`                        | 問題調査時にサポート担当者へ提供する                             |
| `data[].video_url`                | 読み取り可能な動画結果のアドレス                               |
| `data[].seconds/width/height/fps` | サーバー側で測定された実際の出力時間、サイズ、フレームレート                       |
| `data[].draft_task_id`            | ドラフト拡張の入力 ID；再利用可能なドラフトが返される場合にのみ出現                  |
| `usage`                           | 最終課金使用量；リクエストの duration で実際の seconds を上書きしない      |
| `cost.amount`                     | 今回最終的に差し引かれた Credits；`currency=credit` は米ドルではない   |
| `cost.list_amount`                | アプリユーザーの割引適用前の Credits；該当する場合に返される                 |

これは価格改定前の過去の実測です：`list_amount=2.9871876975` Credits、当時アカウントには 10% の利用割引があり、実際の `amount=2.68846892775` Credits でした。2026-10-02 に新価格は約 6.33% 引き下げられました；同じ 5.041667 秒のドラフトは現在価格で 2.798125185 Credits（利用割引前）であり、引き続き 10% の利用割引がある場合は 2.5183126665 Credits です。過去のタスクの請求額は再計算されません。他のアカウントのプランと割引は異なる場合があります；これはすべてのユーザーに固定された米ドル価格ではありません。

## 4. 画像から動画：通常と時間付きキーフレーム

以下はパラメータ例であり、素材 URL を置き換える必要があります。この例がすでに正常に実行されたという宣言ではありません。生成完了後は上記のフローに従って照会してください。結果構造は同じです。

1 枚または 2 枚の画像では通常の配列を使用します：

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "The camera slowly moves around the product in soft studio light.",
  "keyframes": ["https://example.com/first-frame.jpg"],
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "async": true
}
```

キーフレームの時刻を指定する場合は、`[秒数, 画像 URL]` のペアを使用します：

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "A smooth transition from morning light to a warm sunset.",
  "keyframes": [[0, "https://example.com/start.jpg"], [5, "https://example.com/end.jpg"]],
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

1～10 枚のキーフレームを使用できます。時間付き配列は時間の昇順でなければならず、時刻は 0～20 秒であり、通常の URL と時間付き項目を混在させることはできません。通常のキーフレームが 3 枚以上の場合は、必ず duration を明示的に指定する必要があり、auto は使用できません。

```json
  "action": "generate",
  "model": "flux-3",
  "prompt": "The toy sailboat drifts slowly across calm water. A steady camera, gentle daylight, no people or text.",
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "draft": false,
  "mode": "i2v",

}
```

```json
  "resolution": "hd",
```

## 6. 先にドラフト、後で強化

1. `draft=true`、`resolution=hd` を使用してドラフトを生成し、成功するまで待機します。
2. 最終的な `data[0].draft_task_id` からプラットフォームのドラフト ID を取得します。
3. 同一の帰属を持つアプリケーション認証情報を使用して、強化リクエストを送信します。

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "draft_enhance",
  "draft_task_id": "自身の完了済みドラフト ID に置き換え",
  "resolution": "fhd",
  "async": true
}
```

ドラフト強化では、`prompt`、`duration`、`aspect_ratio`、`version`、`generate_audio`、`draft`、`keyframes`、`start_video` を渡して元の内容を上書きすることはできません。ドラフトキャッシュは一時的なリソースですので、速やかに強化してください。永続的な保存または固定の保持日数は保証されません。本人以外／現在のアプリケーション以外のドラフト、未完了のドラフト、期限切れのキャッシュは再利用できません。ドラフトと強化は 2 回のタスクであり、成功後にそれぞれ課金されます。

## 7. Python エンドツーエンド呼び出し

`requests` をインストールし、自身の Token を設定して、以下のスクリプトを実行するだけで「1 回送信 → ポーリング → 動画 URL の出力」を完了できます。クエリとネットワーク再試行では、課金タスクの重複送信を避けるため、元の task_id を使用する必要があります。
```python
import os
import time
import requests

base_url = "https://api.acedata.cloud"
headers = {
    "Authorization": "Bearer " + os.environ["ACEDATACLOUD_API_TOKEN"],
    "Accept": "application/json",
}
payload = {
    "action": "generate",
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light.",
    "duration": 5,
    "resolution": "hd",
    "draft": True,
    "async": True,
}
submitted = requests.post(base_url + "/flux/videos", json=payload, headers=headers, timeout=120)
submitted.raise_for_status()
accepted = submitted.json()
if accepted.get("error"):
    raise RuntimeError(accepted["error"])
task_id = accepted["task_id"]
print("Task ID:", task_id)  # 永続的に保存し、ポーリングの再開に使用する

# 30 分はこの例のクライアント側の待機上限であり、サービスの完了期限の保証ではない。
deadline = time.monotonic() + 30 * 60
while time.monotonic() < deadline:
    polled = requests.post(
        base_url + "/flux/tasks",
        json={"action": "retrieve", "id": task_id},
        headers=headers,
        timeout=30,
    )
    polled.raise_for_status()
    task = polled.json()
    if task.get("error"):
        raise RuntimeError(task["error"])
    result = task.get("response") or task.get("result")
    if isinstance(result, dict) and result.get("success") is True:
        print("Video:", result["data"][0]["video_url"])
        print("Usage:", result.get("usage"))
        print("Cost:", result.get("cost"))
        break
    if isinstance(result, dict) and result.get("error"):
        raise RuntimeError(result["error"])
    time.sleep(10)
else:
    raise TimeoutError("Still processing; resume polling with task_id=" + task_id)
```

ネットワークタイムアウト後、未知の状態を失敗とみなして直ちに再送信しないでください。すでに task_id を取得している場合は、そのタスクを引き続き照会してください。調査しやすいように task_id と trace_id を記録してください。ポーリングインターフェース自体には生成料金はかかりません。

## 8. コールバックの使用

送信時に `callback_url` を追加すると、タスク完了後にそのアドレスへ最終 JSON 結果が POST されます。成功時の構造は前述の response と一致し、失敗時には error が含まれます。

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "t2v",
  "prompt": "A small sailboat on calm water.",
  "duration": 5,
  "resolution": "hd",
  "draft": true,
  "callback_url": "https://your-server.example/flux-callback"
}
```

コールバックアドレスはパブリックネットワークからアクセス可能である必要があります。通知を受信した後は、task_id に基づいて冪等に処理し、できるだけ早く 2xx を返してください。業務処理はキューに投入できます。本書では、コールバックに署名認証があることを表明しません。業務上の権利付与などの機密操作を行う前に、自身の Token を使用して同じタスクを照会し、結果を照合してください。コールバックを受信しなかった場合もポーリングを継続できるため、再生成しないでください。

## 10. よくある質問とトラブルシューティング

| 状況                       | 推奨事項                                                   |
| ------------------------ | ---------------------------------------------------- |
| パラメータエラー（400）                | action=generate、mode、duration、キーフレーム形式を確認してください。異なる生成モードのフィールドを混在させないでください |
| 認証エラー（401）                | Bearer Token、アプリケーション権限、および認証情報が有効か確認してください                          |
| コンテンツ審査拒否（403）              | 素材とプロンプトを調整し、そのまま繰り返し送信しないでください                                    |
| レート制限（429）                  | 同時実行数を減らし、バックオフして再試行してください                                            |
| service_unavailable（503） | 現在の操作は利用できません。受理済みの非同期タスクでは、最終 response でこのエラーが報告される場合があります                |
| task_id は返されたが動画がまだない        | response を引き続き照会し、HTTP 200 を生成完了とみなさないでください                     |
| 下書きを再利用できない                   | 本人/現在のアプリケーションであること、タスクが完了していること、元のリクエストが draft=true であることを確認し、一時キャッシュがまだ有効か確認してください          |

フィードバック時には task_id、trace_id、リクエスト時刻、およびマスキング済みパラメータを提供し、API Token は送信しないでください。その他の方法については、[Flux MCP 統合ガイド](https://platform.acedata.cloud/documents/flux-mcp)を参照してください。
