---
title: "Codex 設定チュートリアル"
description: "Codex 集成指南 - Ace Data Cloud"
---

Codex CLI は OpenAI が提供するオープンソースのローカルプログラミングエージェントで、ターミナル上でコードの閲覧、ファイルの修正、コマンドの実行、開発タスクの支援が可能です。Ace Data Cloud のプロキシを通じて、より低価格で Codex CLI を利用でき、OpenAI の公式アカウントを別途契約する必要はありません。

利用シーンに応じた完全な設定チュートリアルを選択してください：

| プラットフォーム | 説明 | チュートリアルリンク |
|------|------|---------|
| **VS Code** | 公式拡張機能で、エディタのサイドバーでチャット、ファイル参照、差分プレビューが可能 | [VS Code 設定チュートリアル](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| **ターミナル (CLI)** | コア体験で、任意のターミナルで `codex` を実行するだけで開始可能 | [ターミナル設定チュートリアル](https://platform.acedata.cloud/documents/codex-terminal-integration) |

> **ヒント**：初回申請は [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications) で API トークンを取得すると無料枠が付与されます。Codex CLI は Ace Data Cloud の OpenAI Responses 互換インターフェース（`/v1/responses`）を通じて動作し、より多くのモデルや課金情報は [OpenAI サービスページ](https://platform.acedata.cloud/documents/openai) をご参照ください。
