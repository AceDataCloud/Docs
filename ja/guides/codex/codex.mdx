Codex CLI、Desktop および VS Code 拡張は `~/.codex/config.toml` を共有します。一度 `acedatacloud` プロバイダーを設定すれば、Ace Data Cloud を通じて Codex を使用できます。

| 使用方法           | 設定ガイド                                                                                    |
| -------------- | --------------------------------------------------------------------------------------- |
| Terminal / CLI | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)        |
| Desktop        | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)     |
| VS Code        | [Codex for VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)  |
| グラフィカル切り替え | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration) |

共通設定は三項目のみです：

- プロバイダー：`acedatacloud`
- ベース URL：`https://api.acedata.cloud/v1`
- API キー： [アプリケーションリスト](https://platform.acedata.cloud/console/applications) から取得し、`ACEDATACLOUD_API_KEY` に保存します。

接続設定でモデルを固定する必要はありません；Codex を起動した後、直接モデルを選択できます。

[コーディングプラン設定センター](https://platform.acedata.cloud/documents/coding-plan-integration) に戻ります。
