Codex VS Code 拡張は Codex CLI と `~/.codex/config.toml` を共有します。

## 1. API キーの取得

[Ace Data Cloud アプリケーションリスト](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリに入り、API キーをコピーします。

![Ace Data Cloud API キーの取得](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 拡張のインストール

VS Code 拡張マーケットで OpenAI が公開した **Codex – OpenAI's coding agent** をインストールするか、次のコマンドを実行します：

```bash
code --install-extension openai.chatgpt
```

## 3. API キーの設定

macOS / Linux：

```bash
export ACEDATACLOUD_API_KEY="あなたの API キー"
```

長期間有効にするには、この行を `~/.zshrc` または `~/.bashrc` に追加します。Windows PowerShell では次のようにします：

```powershell
setx ACEDATACLOUD_API_KEY "あなたの API キー"
```

## 4. AceDataCloud の設定

`~/.codex/config.toml`（Windows では `%USERPROFILE%\.codex\config.toml`）を編集し、次の内容を追加します：

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Windows では最後の二行を次のように変更します：

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

`model` を記入する必要はありません；Codex パネルでモデルを選択できます。

## 5. 再起動と確認

完全に終了し、VS Code を再度開き、Codex パネルを開きます。`/model` を実行し、Provider が `acedatacloud` であることを確認し、簡単なメッセージを送信します；呼び出し履歴は [使用履歴](https://platform.acedata.cloud/console/usages) で確認できます。

拡張がキーを読み取れない場合は、設定された環境変数のあるターミナルから VS Code を起動するか、システムレベルの環境変数を設定した後に VS Code を再起動してください。Remote SSH、WSL、Dev Container は、実際に拡張を実行する環境でそれぞれ設定する必要があります。
