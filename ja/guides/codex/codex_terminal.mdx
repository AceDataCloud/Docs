## 1. API キーの取得

[Ace Data Cloud アプリケーションリスト](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリに入り、API キーをコピーします。

![Ace Data Cloud API キーの取得](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Codex のインストール

```bash
npm install -g @openai/codex
```

## 3. API キーの設定

macOS / Linux：

```bash
export ACEDATACLOUD_API_KEY="あなたの API キー"
```

長期間有効にするには、この行を `~/.zshrc` または `~/.bashrc` に追加します。Windows PowerShell では次のようにします：

```powershell
setx ACEDATACLOUD_API_KEY "あなたの API キー"
```

設定後、ターミナルを再度開いてください。

## 4. AceDataCloud の設定

`~/.codex/config.toml`（Windows では `%USERPROFILE%\.codex\config.toml`）を編集し、次を追加します：

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Windows では最後の二行を次のように変更します：

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

`model` を記入する必要はありません；起動後に Codex でモデルを選択できます。他の設定がある場合は保持し、同名のプロバイダーを重複して作成しないでください。

## 5. 起動

```bash
cd /path/to/your/project
codex
```

Codex に入ったら `/model` を実行し、プロバイダーが `acedatacloud` であることを確認し、必要なモデルを選択します。呼び出し記録と残高は [使用履歴](https://platform.acedata.cloud/console/usages) と [アプリケーションリスト](https://platform.acedata.cloud/console/applications) で確認できます。

キーが不足しているというメッセージや 401 が返された場合は、環境変数が設定されていることを確認し、完全に終了した後にターミナルと Codex を再度開いてください。
