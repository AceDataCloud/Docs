Claude Code は Anthropic が提供する **Agentic Coding** ツールであり、世界最強のプログラミングエージェントの一つとも言われています。Claude Code デスクトップアプリは独立したグラフィカルインターフェースを提供し、Diff レビュー、並行セッション（Git Worktree による隔離）、リモートセッションなどの機能をサポートし、IDE に依存することなく使用できます。

この文書では、AceData Cloud のプロキシサービスを通じて、Claude Code デスクトップアプリを設定し使用する方法を主に紹介します。

> **注意**：Claude Code デスクトップアプリは現在プレビュー段階（Preview）であり、macOS と Windows のみをサポートしています。

## 申請プロセス

Claude Code を使用するには、まず [Claude Messages サービスページ](https://platform.acedata.cloud/documents/claude-messages) にアクセスし、「Acquire」ボタンをクリックして、リクエストに必要な認証情報を取得します：

![](https://cdn.acedata.cloud/nyq0xz.png)

まだログインまたは登録していない場合、自動的にログインページにリダイレクトされ、登録とログインを促されます。ログインまたは登録後、現在のページに自動的に戻ります。

初回申請時には無料のクレジットが付与され、Claude Code サービスを無料で体験できます。

## デスクトップアプリのインストール

### システム要件

- macOS（Intel および Apple Silicon）または Windows（x64 / ARM64）
- Linux はデスクトップアプリをサポートしていません

### ダウンロードとインストール

[Claude 公式ダウンロードページ](https://claude.ai) にアクセスし、対応するプラットフォームのインストーラをダウンロードします：

- **macOS**：`.dmg` ファイルをダウンロードし、Applications フォルダにドラッグします
- **Windows x64**：`.exe` インストーラをダウンロードし、指示に従ってインストールします
- **Windows ARM64**：ARM64 バージョンをダウンロードします（注意：ARM64 はローカルセッションをサポートしておらず、リモートセッションを使用する必要があります）

![Claude デスクトップアプリダウンロードページ](https://cdn.acedata.cloud/c3c8c57264.png)

インストールが完了したら、Applications フォルダ（macOS）またはスタートメニュー（Windows）から Claude を起動します。

## AceData Cloud API の設定

デスクトップアプリを起動した後、Anthropic アカウントにログインする必要があります。環境変数を設定することで、AceData Cloud のプロキシ API を使用できます。**公式のサブスクリプションは不要です**。

デスクトップアプリはあなたの Shell 環境から環境変数を読み取るため、Shell 設定ファイルで設定する必要があります。

### 環境変数の設定

**macOS ユーザー**

以下の内容を `~/.zshrc`（または `~/.bashrc`）に追加し、`{token}` をあなたの API トークンに置き換えます：

```bash
# AceData Cloud - Claude Code プロキシ設定
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

保存後、次のコマンドを実行します：

```bash
source ~/.zshrc
```

**Windows ユーザー**

「システムのプロパティ → 詳細 → 環境変数」から以下のシステム環境変数を追加します：

| 変数名                    | 値                           |
| ---------------------- | --------------------------- |
| `ANTHROPIC_AUTH_TOKEN` | `{token}`（あなたの API トークンに置き換え）     |
| `ANTHROPIC_BASE_URL`   | `https://api.acedata.cloud` |

または PowerShell を使用して：

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**settings.json での設定も可能**

`~/.claude/settings.json` を編集します（存在しない場合は作成）：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **ヒント**：API トークンは [AceData Cloud コンソール](https://platform.acedata.cloud/console) で確認できます。設定が完了したら、**デスクトップアプリを再起動**して環境変数を有効にします。

## 基本的な使用法

### プロジェクトを開く

1. Claude デスクトップアプリを起動します
2. 上部の **Code** タブをクリックします
3. **Local** 実行モードを選択します
4. **Select folder** をクリックしてプロジェクトディレクトリを選択します

### 対話を開始する

入力ボックスに自然言語でニーズを記述します：

- 「TODO コメントを見つけて修正してください」
- 「メイン関数にテストを追加してください」
- 「このプロジェクトのアーキテクチャを説明してください」

Claude はあなたのコードベースを分析し、変更提案を行い、Diff ビューで変更を表示します。

### 権限モード

送信ボタンの隣にあるモードセレクターで切り替えます：

| モード       | 説明                 |
| -------- | ------------------ |
| **Ask**  | 毎回変更前に確認を求める（初心者に推奨）  |
| **Code** | 自動的にファイル編集を受け入れますが、ターミナルコマンドは確認が必要です |
| **Plan** | 先に詳細な計画を立て、承認を待ってから実行します |

### 並行セッション

サイドバーの **+ New session** をクリックすると、複数の並行セッションを開始できます。Git リポジトリの場合、各セッションは Worktree を通じて独立したプロジェクトのコピーを取得し、互いに干渉しません。

Worktree はデフォルトで `~/.claude-worktrees/` ディレクトリに保存されます。

### Diff レビュー

Claude がファイルを変更した後、変更統計（例： `+12 -1`）が表示され、クリックすると Diff ビューアが開き、ファイルごとに変更をレビューできます。特定のコード行をクリックしてコメントを追加することもでき、Claude はあなたのフィードバックに基づいて調整を行います。

## 外部ツールとの接続

セッションを開始する前に、**⋯** ボタンをクリックし、**Connectors** を選択して外部統合を追加できます：

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- その他...

接続後、Claude は直接カレンダーを読み取り、メッセージを送信し、Issue を作成することができます。

## CLI との関係

デスクトップアプリと CLI は同じ基盤エンジンを使用し、以下の設定を共有します：

- `CLAUDE.md` / `CLAUDE.local.md` プロジェクトメモリファイル
- `~/.claude.json` / `.mcp.json` の MCP サーバー設定
- `~/.claude/settings.json` の設定
- Hooks と Skills の設定

両者は同じプロジェクトで同時に実行でき、それぞれ独立したセッション履歴を維持します。

## よくある質問

### 接続に失敗した場合は？

1. `~/.claude/config.json` ファイルが正しく作成されているか確認します
2. 環境変数が正しく設定されているか確認します（デスクトップアプリを再起動して有効にします）
3. API トークンが有効であることを確認します（[コンソール](https://platform.acedata.cloud/console) で確認できます）
4. `settings.json` で環境変数を設定している場合、ファイル形式が正しいか確認します

### インストールしたツールが見つからない場合は？

Claude が `npm`、`node` などのコマンドを見つけられない場合：

1. これらのツールが通常のターミナルで正常に使用できるか確認します
2. Shell 設定ファイル（`~/.zshrc`、`~/.bashrc`）が正しく PATH を設定しているか確認します
3. 環境変数を再読み込みするためにデスクトップアプリを再起動します

### 残りのクレジットを確認するには？

[AceData Cloud コンソール](https://platform.acedata.cloud/console) にログインすると、現在のアカウントの残りのクレジットと使用状況を確認できます。
