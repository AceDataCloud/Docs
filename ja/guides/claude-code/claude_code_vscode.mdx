Claude Code は Anthropic が提供するプログラミングツールであり、世界最強のプログラミングエージェントの一つとも言われています。Claude Code の VS Code 拡張はネイティブなグラフィカルインターフェースを提供し、VS Code で Claude Code を使用するための推奨方法です。

この文書では、Ace Data Cloud のプロキシサービスを通じて、VS Code で Claude Code 拡張を設定し使用する方法を主に紹介します。

## 申請プロセス

Claude Code を使用するには、まず [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications) にアクセスし、API トークンを取得しておきます。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

まだログインまたは登録していない場合は、自動的にログインページにリダイレクトされ、登録とログインを促されます。ログインまたは登録後は自動的に現在のページに戻ります。

初回申請時には無料のクレジットが付与され、Claude Code サービスを無料で体験できます。

## Claude Code プラグインのインストール

VS Code の拡張マーケットで **Claude Code** を検索し、発行者が **Anthropic** であることを確認してインストールします。インストールが完了すると、アクティビティバーに Claude Code のエントリが表示されます。

## Ace Data Cloud API の設定

プラグインを初めて開くと、Anthropic の公式アカウントにログインするように求められます。公式ログインをスキップし、Ace Data Cloud のプロキシ API を設定することで使用できます。公式のサブスクリプションは不要です。

拡張機能とターミナル CLI は同じ Claude Code 設定を読み取ります。完全な認証、資格情報の競合処理、およびグローバル設定方法については [Claude Code ターミナル設定ガイド](https://platform.acedata.cloud/documents/claude-code-terminal-integration) を参照してください。現在のプロジェクトにのみ適用したい場合は、プロジェクトのルートディレクトリに `.gitignore` に追加した `.claude/settings.local.json` を作成します：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

ここで `{token}` は先ほどコピーした API キーです。VS Code の環境に古い `ANTHROPIC_API_KEY` が既に存在する場合は、その環境で `unset ANTHROPIC_API_KEY` を実行してください。空の文字列をクリアとして扱わず、実際のキーをチームで共有する `.claude/settings.json` に入れないでください。

以下は、VS Code 1.136.1 と Claude Code 拡張 2.1.251 を使用してローカルで完了した設定です。スクリーンショットではプレースホルダーキーを使用し、実際の資格情報の漏洩を防いでいます：

![VS Code 中の Ace Data Cloud Claude Code 設定](https://cdn.acedata.cloud/f925e9e9597b.png)

設定が完了したら、VS Code を再起動します。

> 注意：上記の設定は現在のプロジェクトにのみ適用され、上記の `.claude/settings.local.json` 設定ファイルのパスを `.gitignore` ファイルに追加することをお勧めします。リモートリポジトリに持ち込まれないようにします。

すべてのプロジェクトに適用したい場合は、ユーザーディレクトリに直接その設定を配置できます。対応するパスは `~/.claude/settings.json` です。

> 注意：設定が完了したら、再起動または再読み込みを行わないと、上記の設定は適用されません。

## 基本的な使用法

設定が完了したら、Claude Code パネルで「README.md を読み取り、一文で要約する」といった簡単な読み取りタスクを送信します。タスクが成功したら、[使用履歴](https://platform.acedata.cloud/console/usages) で今回の呼び出しを確認できます。

## 残高を確認する方法

[Ace Data Cloud コンソール - アプリケーションリスト](https://platform.acedata.cloud/console/applications) を通じて、現在のアカウントの残高を確認できます。

[Ace Data Cloud コンソール - 使用履歴](https://platform.acedata.cloud/console/usages) を通じて、すべての使用履歴と請求の詳細を確認できます。
