Claude Code は Anthropic が提供する **Agentic Coding** ツールであり、世界最強のプログラミングエージェントの一つとも言われています。端末 CLI は Claude Code のコア体験であり、任意の端末で `claude` コマンドを実行することで、自然言語を通じて AI とプログラミングの協力ができます。

この文書では、AceData Cloud のプロキシサービスを通じて、端末に Claude Code CLI をインストール、設定、使用する方法を主に紹介します。

## 申請プロセス

Claude Code を使用するには、まず [Claude Messages サービスページ](https://platform.acedata.cloud/documents/claude-messages) にアクセスし、「Acquire」ボタンをクリックして、リクエストに必要な認証情報を取得します：

![](https://cdn.acedata.cloud/nyq0xz.png)

まだログインまたは登録していない場合は、自動的にログインページにリダイレクトされ、登録とログインを促されます。ログインまたは登録後、現在のページに自動的に戻ります。

初回申請時には無料のクレジットが付与され、Claude Code サービスを無料で体験できます。

## Claude Code のインストール

### システム要件

- macOS、Linux または Windows（WSL を含む）
- Node.js は必須ではなく、ネイティブインストール方式で依存関係が自動的に処理されます

### インストール方法

Claude Code は複数のインストール方法をサポートしています：

**方法一：ネイティブインストール（推奨）**

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows CMD：

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**方法二：Homebrew（macOS / Linux）**

```bash
brew install claude-code
```

**方法三：WinGet（Windows）**

```cmd
winget install Claude.ClaudeCode
```

ネイティブインストールはバックグラウンドで自動的に更新され、常に最新バージョンを維持します。

## AceData Cloud API の設定

インストールが完了すると、デフォルトで Anthropic の公式アカウントにログインするよう求められます。環境変数を設定することで、AceData Cloud のプロキシ API を使用できます。**公式のサブスクリプションは不要です**。

### 環境変数の設定

環境変数を設定する方法は二つあり、いずれかを選択できます。

**方法一：シェル設定ファイルに設定（推奨）**

以下の内容をシェル設定ファイル（`~/.zshrc`、`~/.bashrc` または `~/.bash_profile`）に追加し、`{token}` を AceData Cloud コンソールで取得した API トークンに置き換えます：

```bash
# AceData Cloud - Claude Code プロキシ設定
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

変更後、以下のコマンドを実行して設定を有効にします：

```bash
source ~/.zshrc  # または source ~/.bashrc
```

**方法二：Claude Code settings.json に設定**

`~/.claude/settings.json` を編集し（存在しない場合は作成）、`env` 設定を追加します：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

この方法の利点は、環境変数が Claude Code のみに作用し、他のプログラムには影響しないことです。

> **ヒント**：API トークンは [AceData Cloud コンソール](https://platform.acedata.cloud/console) で確認できます。`ANTHROPIC_AUTH_TOKEN` の値には自動的に `Bearer` プレフィックスが追加され、サーバーに送信されます。

## 使用開始

### インタラクティブモードの起動

端末を開き、プロジェクトディレクトリに移動してから、次のコマンドを実行します：

```bash
cd /path/to/your/project
claude
```

Claude Code のウェルカム画面が表示され、自然言語を直接入力することでインタラクションを開始できます。

### よく使うコマンド

| コマンド               | 説明          | 例                   |
| ---------------- | ----------- | -------------------- |
| `claude`         | インタラクティブモードを起動      | `claude`             |
| `claude "タスク"`    | 一回限りのタスクを実行     | `claude "ビルドエラーを修正"`    |
| `claude -p "クエリ"` | クエリを実行して終了     | `claude -p "この関数を説明して"` |
| `claude -c`      | 現在のディレクトリの最近の対話を続ける | `claude -c`          |
| `claude -r`      | 前の対話を復元     | `claude -r`          |
| `claude commit`  | Git コミットを作成   | `claude commit`      |

### インタラクティブモードコマンド

インタラクティブモードでは、以下の組み込みコマンドを使用できます：

| コマンド                | 機能        |
| ----------------- | --------- |
| `/help`           | ヘルプ情報を表示    |
| `/clear`          | 対話履歴をクリア    |
| `/config`         | 設定パネルを開く    |
| `/model`          | モデルを切り替える      |
| `/mcp`            | MCP サービスを管理 |
| `/compact`        | コンテキストを圧縮     |
| `/memory`         | メモリを管理      |
| `/login`          | アカウントを切り替える      |
| `exit` または `Ctrl+C` | 終了        |

### 対話インタラクションの例

```bash
# プロジェクトの分析
> このプロジェクトは何をしますか？

# バグ修正
> ユーザーが空のフォームを送信できるバグがあります - 修正してください

# テストの作成
> 計算機関数のユニットテストを書いてください

# コードのリファクタリング
> 認証モジュールを async/await を使用するようにリファクタリングしてください

# Git 操作
> 変更を説明するメッセージでコミットしてください
> この機能のためのプルリクエストを作成してください
```

## 高度な使い方

### パイプとスクリプト化

Claude Code は Unix の哲学に従い、パイプとスクリプト化操作をサポートしています：

```bash
# ログを監視し自動アラート
tail -f app.log | claude -p "異常が発見された場合は通知してください"

# 新しいテキストを自動翻訳
claude -p "新しいテキスト文字列があれば、フランス語に翻訳して PR を作成してください"

# コードレビュー
git diff main | claude -p "これらの変更をレビューしてください"
```

### 環境変数の参考

以下は Claude Code がサポートする一般的な環境変数です：

| 変数                           | 説明                                    |
| ---------------------------- | ------------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`       | カスタム Authorization ヘッダーの値（自動的に Bearer プレフィックスが追加される） |
| `ANTHROPIC_API_KEY`          | API キー（X-Api-Key ヘッダーとして送信）              |
| `ANTHROPIC_BASE_URL`         | API 基本 URL                            |
| `ANTHROPIC_MODEL`            | デフォルトモデルを上書き                                |
| `ANTHROPIC_SMALL_FAST_MODEL` | Haiku レベルモデル（バックグラウンドタスク用）                     |
| `MAX_THINKING_TOKENS`        | 思考トークンの予算を設定（0 に設定すると思考モードを無効にする）            |
| `DISABLE_COST_WARNINGS`      | 1 に設定すると費用警告を無効にする                           |

### CLAUDE.md プロジェクトメモリ

プロジェクトのルートディレクトリに `CLAUDE.md` ファイルを作成することで、Claude Code にプロジェクト特有の指示やコンテキストを提供できます。Claude は起動時にこのファイルを自動的に読み込みます。

```markdown
# プロジェクト説明
これは Django + Vue.js のフルスタックプロジェクトです。

## コーディング規範
- Python 3.12 を使用
- PEP 8 コードスタイルに従う
- すべての API にはユニットテストを書く必要があります
```

## よくある質問

### 接続に失敗した場合はどうすればよいですか？
1. `~/.claude/config.json` ファイルが正しく作成されているか確認し、内容は `{"primaryApiKey": "self"}` であること。
2. 環境変数が正しく設定されているか確認：
   ```bash
   echo $ANTHROPIC_AUTH_TOKEN
   echo $ANTHROPIC_BASE_URL
   ```
3. API トークンが有効であることを確認（[コンソール](https://platform.acedata.cloud/console) で確認可能）
4. ターミナルを再起動してみる

### command not found: claude

インストール後に `command not found` と表示された場合は、次のことを試してください：

1. ターミナルを閉じて再度開く
2. PATH を確認：`echo $PATH`
3. 再インストール：`curl -fsSL https://claude.ai/install.sh | bash`

### 残りのクレジットを確認するには？

[AceData Cloud コンソール](https://platform.acedata.cloud/console) にログインすると、現在のアカウントの残りのクレジットと使用状況を確認できます。
