## 1. API キーの取得

[Ace Data Cloud アプリケーションリスト](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリに入り、API キーをコピーします。

![Ace Data Cloud API キーの取得](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Claude Code のインストール

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
```

インストール後の確認：

```bash
claude --version
```

## 3. Ace Data Cloud の設定

全体で使用する場合、以下の変数を `~/.zshrc` または `~/.bashrc` に追加します：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="あなたの API キー"
unset ANTHROPIC_API_KEY
```

ターミナルを再起動するか、対応する設定ファイルを `source` します。

現在のプロジェクトのみに有効にする場合、`.gitignore` に追加された `.claude/settings.local.json` を作成できます：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "あなたの API キー"
  }
}
```

どちらか一方を選択してください。実際のキーをチームで共有される `.claude/settings.json` に書き込まないでください；環境に `ANTHROPIC_API_KEY` が既に存在する場合は、実際にそれを解除し、空の文字列に設定しないでください。

## 4. 起動と検証

```bash
cd /path/to/your/project
claude
```

入ったら、例えば「README.md を読み取り、一文で要約してください」といった読み取り専用のタスクを送信します。呼び出しの記録と残高は [使用履歴](https://platform.acedata.cloud/console/usages) と [アプリケーションリスト](https://platform.acedata.cloud/console/applications) で確認できます。

401 が返された場合、キーが完全であるか、古い `ANTHROPIC_API_KEY` が解除されているかを確認し、Claude Code を完全に再起動してください。モデルは接続設定に固定する必要はなく、Claude Code 内で現在利用可能なモデルを選択できます。
