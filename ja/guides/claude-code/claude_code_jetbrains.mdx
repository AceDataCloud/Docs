Claude Code は Anthropic が提供する **Agentic Coding** ツールであり、世界最強のプログラミングエージェントの一つとも言われています。Claude Code は JetBrains IDE 専用のプラグインを提供しており、IntelliJ IDEA、PyCharm、WebStorm、GoLand、PhpStorm、Android Studio など、全ての JetBrains IDE に対応しています。

この文書では、AceData Cloud のプロキシサービスを通じて、JetBrains IDE で Claude Code を設定し使用する方法を主に説明します。

## 申請プロセス

Claude Code を使用するには、まず [Claude Messages サービスページ](https://platform.acedata.cloud/documents/claude-messages) にアクセスし、「Acquire」ボタンをクリックして、リクエストに必要な認証情報を取得します：

![](https://cdn.acedata.cloud/nyq0xz.png)

まだログインまたは登録していない場合は、自動的にログインページにリダイレクトされ、登録とログインを促されます。ログインまたは登録後、現在のページに自動的に戻ります。

初回申請時には無料のクレジットが付与され、Claude Code サービスを無料で体験できます。

## インストール

### 前提条件

Claude Code JetBrains プラグインは Claude Code CLI に依存しているため、まず CLI がインストールされていることを確認してください：

```bash
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# または Homebrew を使用
brew install claude-code
```

インストールが完了したら、以下のコマンドで確認できます：

```bash
claude --version
```

### プラグインのインストール

![JetBrains Marketplace の Claude Code プラグイン](https://cdn.acedata.cloud/de78fd305b.png)

1. JetBrains IDE を開く
2. **Settings** → **Plugins** → **Marketplace** に移動
3. **Claude Code** を検索
4. **Install** をクリックしてプラグインをインストール
5. IDE を再起動

または、[JetBrains Marketplace](https://plugins.jetbrains.com/plugin/27310-claude-code-beta-) に直接アクセスしてオンラインでインストールします。

> **重要**：プラグインをインストールした後は、**IDE を完全に再起動**する必要があります（複数回再起動が必要な場合があります）。

## AceData Cloud API の設定

Claude Code JetBrains プラグインは統合ターミナルを通じて `claude` コマンドを実行するため、環境変数の設定方法は CLI と同じです。

### ステップ1：config.json の作成

Claude Code の設定ファイルを作成します：

| システム                | パス                                   |
| ----------------- | ------------------------------------ |
| **macOS / Linux** | `~/.claude/config.json`              |
| **Windows**       | `C:\Users\{ユーザー名}\.claude\config.json` |

このファイルに以下の内容を書き込み、保存します：

```json
{
  "primaryApiKey": "self"
}
```

macOS / Linux での迅速な作成コマンド：

```bash
mkdir -p ~/.claude && echo '{"primaryApiKey": "self"}' > ~/.claude/config.json
```

### ステップ2：環境変数の設定

**方法1：Shell 設定ファイルに設定（推奨）**

以下の内容を `~/.zshrc` または `~/.bashrc` に追加し、`{token}` をあなたの API トークンに置き換えます：

```bash
# AceData Cloud - Claude Code プロキシ設定
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

変更後、`source ~/.zshrc` を実行して設定を有効にし、その後**JetBrains IDE を再起動**します。

**方法2：Claude Code settings.json に設定**

`~/.claude/settings.json` を編集します（存在しない場合は作成）：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **ヒント**：API トークンは [AceData Cloud コンソール](https://platform.acedata.cloud/console) で確認できます。

## 基本的な使用法

### IDE 内部ターミナルから起動

JetBrains IDE の統合ターミナルを開き、次のコマンドを実行します：

```bash
claude
```

IDE の統合ターミナルで実行すると、すべての統合機能（Diff ビュー、コンテキスト選択など）が自動的に有効になります。

### 外部ターミナルから接続

外部ターミナルで Claude Code を実行している場合は、`/ide` コマンドを使用して JetBrains IDE に接続できます：

```bash
claude
> /ide
```

IDE プロジェクトのルートディレクトリと同じパスから Claude Code を起動することを確認してください。そうすれば Claude は同じファイル群にアクセスできます。

### ショートカットキー

| ショートカットキー                                      | 機能                      |
| ------------------------------------------------ | ----------------------- |
| `Cmd+Esc`（Mac）/ `Ctrl+Esc`（Windows/Linux）        | Claude Code を迅速に開く        |
| `Cmd+Option+K`（Mac）/ `Alt+Ctrl+K`（Windows/Linux） | ファイル参照を挿入（例：`@File#L1-99`） |

### 統合機能

Claude Code JetBrains プラグインは以下の統合機能を提供します：

- **Diff ビュー**：コードの変更が IDE の Diff ビューアに直接表示される
- **コンテキスト選択**：現在選択されているコードとタブが自動的に Claude に共有される
- **ファイル参照**：ショートカットキーを使用してファイルと行番号を迅速に参照
- **診断共有**：IDE 内の Lint、構文エラーなどの診断情報が自動的に Claude に共有される

## プラグイン設定

**Settings** → **Tools** → **Claude Code [Beta]** で設定できます：

| 設定                            | 説明                                         |
| ----------------------------- | ------------------------------------------ |
| **Claude コマンド**            | カスタム Claude コマンドパス（例：`/usr/local/bin/claude`） |
| **自動更新を有効にする**  | プラグインの更新を自動的に確認しインストールする                                |
| **Option+Enter の使用を有効にする** | macOS で Option+Enter を使用してプロンプトボックスで改行する             |

### WSL ユーザーの設定

WSL 環境で使用する場合、Claude コマンドを次のように設定する必要があります：

```
wsl -d Ubuntu -- bash -lic "claude"
```

（`Ubuntu` をあなたの WSL ディストリビューション名に置き換えてください）

## よくある質問

### 接続に失敗した場合は？

1. `~/.claude/config.json` ファイルが正しく作成されているか確認する
2. 環境変数が正しく設定されているか確認する
3. API トークンが有効であることを確認する（[コンソール](https://platform.acedata.cloud/console) で確認可能）
4. JetBrains IDE を再起動して再試行する

### プラグインが動作しない？

1. プロジェクトのルートディレクトリから Claude Code を実行していることを確認する
2. IDE 設定でプラグインが有効になっているか確認する
3. IDE を完全に再起動する（複数回再起動が必要な場合があります）
4. リモート開発モードを使用している場合、プラグインがリモートホストにインストールされていることを確認する（Settings → Plugin (Host)）

### IDE が検出されない？

1. プラグインがインストールされていて有効になっていることを確認する
2. IDE を再起動する
3. 統合ターミナルで Claude Code を実行していることを確認する
4. WSL ユーザーは [WSL トラブルシューティングガイド](https://code.claude.com/docs/en/troubleshooting#jetbrains-ide-not-detected-on-wsl2) を参照してください

### command not found

Claude アイコンをクリックした際に "command not found" と表示された場合：

1. CLI がインストールされていることを確認する：`which claude`
2. プラグイン設定で Claude コマンドの完全なパスを設定する
3. WSL ユーザーは上記の WSL コマンド形式を使用する
### 残高を確認する方法は？

[AceData Cloud コンソール](https://platform.acedata.cloud/console)にログインすると、現在のアカウントの残高と使用状況を確認できます。
