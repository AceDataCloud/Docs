このドキュメントの目的はただ一つ：**5分以内に** AceData Cloud プロキシを使って最初の Claude Code コマンドを実行することです。完全なチュートリアルは各 IDE のサブドキュメント（[VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)）をご覧ください。本稿は「**ターミナル CLI** + **VS Code 拡張機能**」の最速ルートのみを扱います。

> **なぜ AceData Cloud プロキシで Claude Code を使うのか**：
> - 国内から直接接続可能で VPN 不要
> - 公式よりも安価（プラットフォームのトークン課金）
> - 同じキーで Claude Messages API と Claude Code Token プロトコルの両方をサポート

## 1分目：認証情報の取得

[Claude Messages サービスページ](https://platform.acedata.cloud/documents/claude-messages)を開き、「**Acquire**」ボタンをクリック：

![](https://cdn.acedata.cloud/nyq0xz.png)

プラットフォームが自動的に Application を作成し、無料クレジットを付与します。詳細ページの **Base URL** と **API Token** をメモしてください —— 以降の5ステップで使用します。

| フィールド | 値 | 用途 |
|------|------|------|
| `BASE_URL` | `https://api.acedata.cloud` | Claude Messages 互換エンドポイント |
| `API_TOKEN` | `sk-...`（詳細ページからコピー可能） | Anthropic 互換認証トークン |

## 2分目：Claude Code のインストール

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows（ネイティブ PowerShell）：

```powershell
irm https://claude.ai/install.ps1 | iex
```

インストール完了後、新しいターミナルを開いて以下を実行し、動作確認：

```bash
claude --version
```

> バージョン番号が表示されれば成功です。Claude Code は Node.js ランタイムを内蔵しており、マシンの Node バージョンに依存しません。

## 3分目：環境変数を AceData Cloud に向ける

公式の `claude login` フローは使わず、環境変数で上書きします。以下のいずれかの方法を選択してください：

**方法 A：一時的（現在のシェルセッションのみ）**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-あなたの-Token"
```

**方法 B：永続化（推奨）**

上記2行を `~/.zshrc` または `~/.bashrc` に追記し、`source` コマンドで反映。

> **よくある落とし穴**：環境変数名は `ANTHROPIC_AUTH_TOKEN` であり、`ANTHROPIC_API_KEY` ではありません。誤った名前を使うと Claude Code は公式エンドポイントにフォールバックし、401 エラーになります。

## 4分目：最初のコマンドを実行

任意の Git リポジトリに移動して、以下を実行：

```bash
claude
```

初回起動時にログインを求められたら、`Esc` キーでスキップしてください。続いて以下を入力：

```
現在のプロジェクトの依存関係を一覧表示し、それぞれの用途を簡単に説明してください。
```

正常なら Claude が `read_file` / `glob` / `grep` などのツールを使ってリポジトリを参照し、一覧を返します。画面下部のステータスバーに `connected to api.acedata.cloud` と表示されれば、プロキシが有効になっている証拠です。

## 5分目：VS Code 拡張機能の接続

1. VS Code を開き、拡張機能パネルで「Claude Code」を検索し、Anthropic 公式のものをインストール；
2. **Cmd+Shift+P** を押して `Claude Code: Set Custom API Endpoint` を入力；
3. `https://api.acedata.cloud` を入力して Enter；
4. 続けて `Claude Code: Set API Token` を実行し、あなたのトークンを入力。

成功するとサイドバーに Claude Code パネルが表示され、ファイルをドラッグして質問したり、`@-mention` でファイルの修正提案ができます。すべての課金は AceData Cloud 経由です。

## プロキシ経由を確認する方法

Claude Code の対話で以下を入力：

```
https://api.acedata.cloud/whoami にアクセスして、返ってきた内容を教えてください
```

あなたのアカウント情報（`{user_id, plan, ...}`）が返れば、リクエストは確実に AceData Cloud エッジを通っています。公式ドメインにリダイレクトされて 401 エラーになる場合は、3分目の環境変数名を再確認してください。

## よくある5つの質問

**Q：`claude login` を実行後に環境変数を AceData 用に変えたが反映されないのはなぜ？**  
A：`claude login` は `~/.claude/.credentials.json` に公式トークンを書き込み、**環境変数より優先されます**。このファイルを削除し、`source ~/.zshrc` すれば解決します。

**Q：`--model claude-opus-4-7` のようなモデル名は使えますか？**  
A：使えます。AceData Cloud プロキシは model フィールドを透過的に通すため、すべての Anthropic 公開モデルと当社拡張の `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5` がサポートされています。

**Q：複数のプロファイル（個人用＋会社用）を設定できますか？**  
A：できます。Claude Code は `~/.claude/settings.json` で複数プロファイルをサポートしています。もっと簡単には、2つのシェル関数 `claude_personal` / `claude_work` を作り、それぞれ異なる `ANTHROPIC_AUTH_TOKEN` を export してから `claude $@` を呼び出す方法もあります。

**Q：GitHub Actions で実行できますか？**  
A：できます。詳細は [Claude Code GitHub Actions 設定チュートリアル](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) を参照してください。

**Q：無料クレジットがなくなったら？**  
A：[アプリ管理](https://platform.acedata.cloud/applications) → 対象の Claude Application を選択 → Topup でチャージ（トークン消費に応じて課金）、またはポイントサブスクリプションに切り替え可能です。
