title: "Claude Code 配置チュートリアル"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code は Anthropic が提供するプログラミングエージェントで、ターミナル、IDE、デスクトップアプリなどさまざまな環境で使用できます。AceData Cloud プロキシを通じて、より低価格で Claude Code を利用できます。

使用シーンに応じて、対応するプラットフォームの設定チュートリアルを選択してください：

| プラットフォーム         | 説明                                        | チュートリアルリンク                                                                                                   |
| ------------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **ターミナル (CLI)**       | コア体験、任意のターミナルで `claude` を実行するだけで開始                | [ターミナル設定チュートリアル](https://platform.acedata.cloud/documents/claude-code-terminal-integration)                    |
| **VS Code**        | ネイティブ拡張、インライン Diff、@-メンション、レビューの計画をサポート            | [VS Code 設定チュートリアル](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)               |
| **JetBrains IDE**  | IntelliJ IDEA、PyCharm、WebStorm など全系 IDE をサポート | [JetBrains 設定チュートリアル](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)          |
| **GitHub Actions** | `@claude` を使用してコードレビューと Issue 処理を自動化             | [GitHub Actions 設定チュートリアル](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **ヒント**：初回申請は [Claude Messages サービスページ](https://platform.acedata.cloud/documents/claude-messages) にアクセスし、「Acquire」をクリックして証明書を取得すると、無料クレジットが付与されます。
