description: "Claude Code 集成指南 - Ace Data Cloud"

Claude Code は Anthropic が提供するプログラミングエージェントで、ターミナル、IDE、デスクトップアプリなど様々な環境で利用できます。AceData Cloud のプロキシを通じて、より低価格で Claude Code を利用可能です。

> **初めての接続ですか？** まずは [Claude Code 5分で始めるクイックスタート](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) をご覧ください——認証情報の取得から最初のコマンド実行まで、5ステップで完了します。

利用シーンに応じたプラットフォーム別の完全設定チュートリアル：

| プラットフォーム | 説明 | チュートリアルリンク |
|------|------|---------|
| **⚡ 5分でクイックスタート** | 認証情報取得から最初の `claude` コマンド実行まで5ステップで完了 | [5分チュートリアル](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) |
| **ターミナル (CLI)** | コア体験。任意のターミナルで `claude` を実行するだけで開始可能 | [ターミナル設定チュートリアル](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code** | ネイティブ拡張。インラインDiff、@メンション、レビュー計画をサポート | [VS Code 設定チュートリアル](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | VS Code 互換エディタ。Claude Code 拡張を完全サポート | [Cursor 設定チュートリアル](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **JetBrains IDE** | IntelliJ IDEA、PyCharm、WebStorm など全シリーズのIDEをサポート | [JetBrains 設定チュートリアル](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | `@claude` を使ったコードレビューやIssue処理の自動化 | [GitHub Actions 設定チュートリアル](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |
| **デスクトップアプリ (プレビュー)** | 独立したGUIクライアント。並列セッションや外部ツール連携をサポート | [デスクトップアプリ設定チュートリアル](https://platform.acedata.cloud/documents/claude-code-desktop-integration) |

> **ヒント**：初回申請は [Claude Messages サービスページ](https://platform.acedata.cloud/documents/claude-messages) で「Acquire」をクリックして認証情報を取得すると、無料クレジットが付与されます。
