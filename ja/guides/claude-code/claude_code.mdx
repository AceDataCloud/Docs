Claude Code は Anthropic Messages プロトコルを通じて Coding Plan に接続されており、現在端末と VS Code の二つの構成入口を提供しています。

| 使用入口           | 配置ガイド                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| Terminal / CLI | [Claude Code 端末配置](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code        | [Claude Code for VS Code 配置](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## 共通配置

- Base URL：`https://api.acedata.cloud`
- API Token：Coding Application から取得し、ガイドの `ANTHROPIC_AUTH_TOKEN` で構成
- Model ID：リアルタイムモデルディレクトリから選択
- 構成を変更後：Claude Code を再起動；VS Code ユーザーはウィンドウを再読み込みする必要があります

古い `ANTHROPIC_API_KEY` を同時に保持しないでください。また、実際の Token をチーム共有ファイルに書き込まないでください。

[Coding Plan 配置センター](https://platform.acedata.cloud/documents/coding-plan-integration) に戻る。
