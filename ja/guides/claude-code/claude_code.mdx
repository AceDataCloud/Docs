title: "Claude Code 設定チュートリアル"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code は Anthropic が提供するプログラミングエージェントで、ターミナル、IDE、CI/CD パイプラインなどさまざまな環境で利用できます。AceData Cloud のプロキシを通じて、より低価格で Claude Code を利用可能です。

利用シーンに応じて対応プラットフォームの完全設定チュートリアルを選択してください：

| プラットフォーム | 説明 | チュートリアルリンク |
|------|------|---------|
| **VS Code** | ネイティブ拡張機能、インライン Diff、@メンション、コードレビュー計画をサポート | [VS Code 設定チュートリアル](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | VS Code 互換エディタ、Claude Code 拡張機能を完全サポート | [Cursor 設定チュートリアル](https://platform.acedata.cloud/documents/development_cursor_coding) |
| **ターミナル (CLI)** | コア体験、任意のターミナルで `claude` を実行するだけで開始可能 | [ターミナル設定チュートリアル](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **GitHub Actions** | `@claude` を使った自動コードレビューと Issue 処理 | [GitHub Actions 設定チュートリアル](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **ヒント**：初回申請は [Claude Messages サービスページ](https://platform.acedata.cloud/documents/claude-messages) にアクセスし、「Acquire」をクリックして認証情報を取得すると無料クレジットが付与されます。
