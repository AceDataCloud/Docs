## 1. API キーの取得

[Ace Data Cloud アプリケーションリスト](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリに入り、API キーをコピーします。

![Ace Data Cloud API キーの取得](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. CC Switch のインストール

[CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest)からダウンロードし、macOSでも実行できます：

```bash
brew install --cask cc-switch
```

## 3. プロバイダーの追加

CC Switchを開き、**Claude Code → Add Provider → Custom**を選択し、以下を入力します：

| フィールド     | 値                           |
| ---------- | --------------------------- |
| Name       | `Ace Data Cloud`            |
| Base URL   | `https://api.acedata.cloud` |
| API Key    | 先ほどコピーしたAPIキー               |
| API Format | `Anthropic Messages`        |

JSONエディタを使用する場合、次のように設定します：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

CC Switchは設定をClaude Codeのユーザー設定に書き込みます。実際のキーをチームリポジトリに保存しないでください。また、古い`ANTHROPIC_API_KEY`を同時に保持しないでください。

## 4. 有効化と検証

保存後、**Ace Data Cloud**を有効にし、Claude Codeを再起動します。簡単な読み取り専用タスクを送信し、[使用履歴](https://platform.acedata.cloud/console/usages)で呼び出しを確認します。切り替え後も古い設定を使用している場合は、Claude CodeとCC Switchを完全に終了し、再試行してください。
