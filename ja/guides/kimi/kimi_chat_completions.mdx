Kimi は月之暗面が提供する AI モデルシリーズです。現在は `kimi-k3.1-pro` が推奨されており、長時間のプログラミング、複雑な推論、視覚理解、ナレッジワークに適しています。`kimi-k3` も引き続き利用可能です。OpenAI 互換の Chat Completions API を通じて呼び出します。

本ドキュメントでは主に Kimi Chat Completion API 操作の使用フローを紹介し、これを利用することで公式 Kimi の対話機能を簡単に使用できます。

## 申請フロー

Kimi Chat Completion API を使用するには、まず [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications) にアクセスして API Token を取得し、予備として保存してください。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

まだログインまたは登録していない場合は、自動的にログインページへ移動して登録とログインを促されます。完了後、自動的に現在のページへ戻ります。

**1 つの API Token でプラットフォーム上のすべてのサービスを呼び出すことができ、サービスごとに個別申請する必要はありません。** 初回申請時には無料クレジットが付与され、無料で試用できます。クレジットが不足した場合は、[コンソール](https://platform.acedata.cloud/console/coin) で共通残高をチャージできます。

> 📘 完全なドキュメント：[Kimi Chat Completion API →](https://platform.acedata.cloud/documents/kimi-chat-completions)

## 基本的な使用方法

続いて、画面上で対応する内容を入力できます。図のとおりです。

<p><img src="https://cdn.acedata.cloud/ej5ozg.png" width="400" className="m-auto" /></p>

このインターフェースを初めて使用する場合、少なくとも 3 つの内容を入力する必要があります。`authorization` はドロップダウンリストから直接選択できます。`model` は Kimi モデルの選択に使用され、`kimi-k3.1-pro` の使用が推奨されます。`messages` は対話メッセージの配列であり、各メッセージには `role` と `content` が含まれ、そのうち `role` は `user`、`assistant`、`system`、`tool` をサポートします。

同時に、右側には対応する呼び出しコードが生成されていることに気づくでしょう。コードをコピーして直接実行することも、「Try」ボタンを直接クリックしてテストすることもできます。

<p><img src="https://cdn.acedata.cloud/six7e3.png" width="400" className="m-auto" /></p>

以下は `reasoning_effort: max` を使用して取得した実際の K3 レスポンスです（使用されていない拡張フィールドは省略）。

```json
{
  "id": "msg_2D4Btbg1WgvkNE3tCYkR4xGA",
  "object": "chat.completion",
  "created": 1784466588,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 86,
    "completion_tokens": 206,
    "total_tokens": 292
  }
}
```

返却結果には複数のフィールドがあり、以下のとおりです。

- `id`、この対話タスクの ID を生成し、この対話タスクを一意に識別するために使用されます。
- `model `、選択された Kimi 公式サイトのモデル。
- `choices`Kimi が質問文に対して提供する回答情報。
- `usage `：今回の質疑応答ペアにおける token の統計情報。

そのうち `choices` には Kimi の回答情報が含まれており、その中の `choices` は Kimi の回答の具体的な情報です。図のとおり確認できます。

<p><img src="https://cdn.acedata.cloud/tv9rul.png" width="400" className="m-auto" /></p>

確認できるように、`choices` 内の `content` フィールドには Kimi の返信の具体的な内容が含まれます。K3 は推論プロセスを示すための `reasoning_content` を返す場合もあります。

## K3.1 Pro の推論強度

`kimi-k3.1-pro` は常に推論を有効にします。リクエストボディのトップレベルで `reasoning_effort` を `low`、`high`、または `max` に設定できます。推論を無効にする設定は渡さないでください。モデルは最大 1,048,576 token のコンテキストをサポートしますが、実際のリクエスト上限は引き続き現在のインターフェースに準拠します。料金は入力、出力、キャッシュヒットの使用量に基づいて計算されます。詳細はモデルカタログの Pricing カードを参照してください。

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3.1-pro",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "low"
  }'
```

以下の K3 サンプルは既存の統合向けに保持されており、サンプルレスポンスは実際に K3 リクエストによって取得されたものです。

## K3 の推論強度

`kimi-k3` は常に推論を有効にします。リクエストボディのトップレベルでは `reasoning_effort` フィールドをサポートしており、現在サポートされている唯一の値は `max` です。このフィールドを省略した場合も `max` が使用されます。`standard`、`high`、またはその他の文字列は、一部の互換上流で緩く受け入れられる可能性がありますが、推論動作の変更は保証されないため、依存しないでください。

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "max"
  }'
```

OpenAI SDK を使用する場合、このフィールドを直接渡すことができます。

```python
response = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "设计一个可靠的任务队列"}],
    reasoning_effort="max",
)
```

複数ターンの対話およびツール呼び出し時には、`reasoning_content` と `tool_calls` を含め、前のターンの完全な assistant メッセージを `messages` に返送してください。

### 公式リファレンス

- [Thinking Effort](https://platform.kimi.ai/docs/guide/use-thinking-effort)：Kimi K3 が常に推論を有効にし、現在 `reasoning_effort` でサポートされる唯一の値が `max` であることを説明しています。
- [Model Parameter Reference](https://platform.kimi.ai/docs/api/models-overview)：K3 と K2 シリーズの推論パラメータ、コンテキストウィンドウ、ツール呼び出しの違いを比較しています。
- [Create Chat Completion](https://platform.kimi.ai/docs/api/chat)：Moonshot 公式の Chat Completions リクエスト、レスポンス、および OpenAPI フィールド定義。

## ストリーミングレスポンス

このインターフェースはストリーミングレスポンスにも対応しており、Web ページとの連携に非常に役立ち、Web ページで一文字ずつ表示する効果を実現できます。

レスポンスをストリーミングで返したい場合は、リクエストヘッダー内の `stream ` パラメータを変更し、`true` に設定できます。

図のように変更しますが、ストリーミングレスポンスをサポートするには、呼び出しコードにも対応する変更が必要です。

<p><img src="https://cdn.acedata.cloud/a3nzpw.png" width="400" className="m-auto" /></p>

`stream` を `true` に変更すると、API は対応する JSON データを行ごとに返します。コードレベルでは、行ごとの結果を取得するために対応する変更を行う必要があります。

Python サンプル呼び出しコード：
```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"user","content":"Hello"}],
    "reasoning_effort": "max",
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

以下は、同一の実際の K3 Max ストリーミングレスポンスから抜粋した、開始、推論、本文、終了、および使用量のデータブロックです：

```json
data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"","role":"assistant"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"reasoning_content":"The"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"Hello"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{},"finish_reason":"stop"}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[],"usage":{"prompt_tokens":172,"completion_tokens":168,"total_tokens":340}}

data: [DONE]
```

ご覧のとおり、レスポンスには多数の `data` があり、`data` 内の `choices` が最新の回答内容であり、上記で紹介した内容と一致しています。`choices` は追加された回答内容であり、結果に基づいてご自身のシステムに連携できます。同時に、ストリーミングレスポンスの終了は `data` の内容に基づいて判断され、内容が `[DONE]` の場合、ストリーミングレスポンスの回答がすべて終了したことを示します。返される `data` の結果には複数のフィールドがあり、以下のとおりです：

- `id`，今回の対話タスクを生成する ID であり、今回の対話タスクを一意に識別するために使用されます。
- `model `，選択した Kimi 公式サイトのモデルです。
- `choices`，質問文に対して Kimi が提供する回答情報です。

JavaScript もサポートされています。たとえば、Node.js のストリーミング呼び出しコードは以下のとおりです：

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "kimi-k3",
    messages: [{ role: "user", content: "Hello" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

Java のサンプルコード：

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "kimi-k3");
jsonObject.put("messages", new JSONArray().put(new JSONObject().put("role", "user").put("content", "Hello")));
jsonObject.put("stream", true);
MediaType mediaType = MediaType.parse("application/json; charset=utf-8");
RequestBody body = RequestBody.create(jsonObject.toString(), mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/kimi/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.println(response.body().string());
```

その他の言語については、別途ご自身で書き換えることができます。原理はすべて同じです。

## 複数ターンの対話

複数ターンの対話機能を連携したい場合は、`messages` フィールドに複数の質問文をアップロードする必要があります。複数の質問文の具体例は次の図に示されています：

<p><img src="https://cdn.acedata.cloud/g85v2a.png" width="400" className="m-auto" /></p>

Python のサンプル呼び出しコード：

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"assistant","content":"Hello! How can I help you today?"},{"role":"user","content":"What model are you?"}],
    "reasoning_effort": "max"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

複数の質問文をアップロードすることで、複数ターンの対話を簡単に実現できます。以下は、このリクエストで取得された実際の K3 Max レスポンスです（未使用の拡張フィールドは省略しています）：

```json
{
  "id": "msg_Rqp8nPGBDHWwBlL4VpxuafOp",
  "object": "chat.completion",
  "created": 1784466628,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "I’m Kimi, an AI assistant developed by Moonshot AI (月之暗面). I don’t have a specific public model version identifier to share from here."
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 134,
    "completion_tokens": 346,
    "total_tokens": 480
  }
}
```

ご覧のとおり、`choices` に含まれる情報は基本的な使用方法の内容と一致しており、これは複数の対話に対して Kimi が返信する具体的な内容を含んでいます。このようにして、複数の対話内容に基づいて対応する質問に回答できます。

## エラー処理

API の呼び出し時にエラーが発生した場合、API は対応するエラーコードと情報を返します。例：

- `400 token_mismatched`：Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`：Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`：Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`：Too many requests, you have exceeded the rate limit.
- `500 api_error`：Internal server error, something went wrong on the server.
