---
title: "OpenAI 音声合成 API（/v1/audio/speech）"
description: "OpenAI generation API guide - Ace Data Cloud"
---

テキストを自然な音声に合成します。**完全に OpenAI の `/v1/audio/speech` と互換性があります**。任意の OpenAI SDK は `base_url` を `https://api.acedata.cloud` に設定し、キーをあなたの AceData Token に置き換えるだけで直接使用できます。インターフェースは音声バイトストリームを同期的に返します。

- **リクエストURL**：`POST https://api.acedata.cloud/v1/audio/speech`（別名 `POST /openai/audio/speech`）
- **認証**：リクエストヘッダー `Authorization: Bearer {token}`
- **料金**：リクエストテキストのバイト数に基づいて課金され、OpenAI の公式価格の約 85%（下表参照）。

## リクエストパラメータ

| フィールド            | タイプ     | 必須  | 説明                                                            |
| ----------------- | ------ | --- | ------------------------------------------------------------- |
| `input`           | string | はい   | 合成するテキスト。                                                   |
| `model`           | string | いいえ   | `tts-1`（より速い）または `tts-1-hd`（より高音質、デフォルト）。                     |
| `voice`           | string | いいえ   | `alloy`、`echo`、`fable`、`onyx`、`nova`、`shimmer` のいずれか、デフォルトは `alloy`。 |
| `response_format` | string | いいえ   | `mp3`(デフォルト)、`opus`、`aac`、`flac`、`wav`、`pcm`。                  |
| `speed`           | number | いいえ   | 読み上げ速度 0.25–4.0、デフォルトは 1.0。                                     |

## 例

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/speech' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -o speech.mp3 \
  -d '{
    "model": "tts-1-hd",
    "input": "もし1つのAPIがすべてのAIビデオモデルを提供したらどうなるでしょうか？",
    "voice": "nova",
    "response_format": "mp3"
  }'
```

返されるのは音声ファイル自体（`Content-Type: audio/mpeg`）で、直接 `speech.mp3` に書き込むことで再生できます。

公式 OpenAI Python SDK を使用する：

```python
from openai import OpenAI
client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
client.audio.speech.create(model="tts-1-hd", voice="nova", input="AceDataからこんにちは。").stream_to_file("speech.mp3")
```

## 価格

| モデル         | OpenAI 公式価格    | 本プラットフォーム価格（約 85 割引）       |
| ---------- | ------------- | ------------------ |
| `tts-1`    | $15 / 100 万文字 | 約 $12.75 / 100 万文字 |
| `tts-1-hd` | $30 / 100 万文字 | 約 $25.5 / 100 万文字  |

> リクエストテキストのバイト数に基づいて課金されます; `official_price` フィールドは比較のために OpenAI の公式価格を表示します。

## エラーコード

| ステータスコード | code                    | 説明               |
| --- | ----------------------- | ---------------- |
| 400 | `bad_request`           | `input` が空またはパラメータが不正。 |
| 401 | `authentication_failed` | トークンが無効。        |
| 403 | `used_up`               | 残高不足。            |
| 429 | `too_many_requests`     | リクエストが多すぎます。          |
| 500 | `api_error`             | 上流/内部エラー。         |
