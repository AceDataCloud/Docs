## 1. API Key の取得

[Ace Data Cloud アプリケーション一覧](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリケーションに入り、API Key をコピーします。

![Ace Data Cloud API Key を取得](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 最初のリクエストを送信

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

正常なレスポンスの画像は `data[].url` にあります。以下は 2026 年 9 月 8 日に Ace Data Cloud を通じて実際にリクエストして得られた 1024×1536 の結果です（タスク `d56455e2-e7f7-4bcd-b935-475b0a1e0948`、trace `eb938601-8192-407f-b539-1e0554b697ec`）：

![GPT Image 2 が生成した白いマグカップ](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. よく使うパラメータ

| フィールド                | 説明                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`（デフォルト推奨）、`gpt-image-2.5-flare`（高速）または `gpt-image-2.5-sunburst`（より高い忠実度と制御）；いずれも対応する `:official` バリアントを選択でき、`gpt-image-2` は `:reverse` もサポート |
| `prompt`          | 画像の説明、最長 32,000 文字                                                                                                                     |
| `size`            | `auto` または `WIDTHxHEIGHT`；幅と高さは 16 の倍数である必要があり、長辺は 3840 以下、総ピクセル数は 655,360–8,294,400、アスペクト比は 3:1 以下                                                       |
| `n`               | 1–10；`response_format=b64_json` の場合は 1 のみサポート                                                                                                 |
| `quality`         | `low`、`medium`、`high` または `auto`；サポートと課金方法はルートによって異なる                                                                                          |
| `response_format` | `url` または `b64_json`                                                                                                                     |
| `callback_url`    | 任意；長時間タスクの完了後にこのアドレスへ結果を送信                                                                                                                      |

よく使うサイズ：

| 比率   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` は、プロンプト内の比率、ピクセル数、レイアウト意図に基づいて画面サイズを選択します；正確なピクセル数が必要な場合は、直接サイズを指定してください。

### モデルと課金方法

| モデル                                | 適用シーンと課金方法                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | デフォルトのリバースルート、成功した画像枚数に応じた固定課金                        |
| `gpt-image-2:reverse`             | リバースルートを明示的に選択、成功した画像枚数に応じた固定課金                      |
| `gpt-image-2:official`            | 公式 API ルート、安定性がより高く、実際の Token 使用量に応じて課金            |
| `gpt-image-2.5-flare`             | 生成速度を重視、成功した画像枚数に応じた固定課金                        |
| `gpt-image-2.5-flare:official`    | 公式 API ルート、安定性がより高く生成速度を重視、実際の Token 使用量に応じて課金     |
| `gpt-image-2.5-sunburst`          | 高忠実度と細かな制御を重視、成功した画像枚数に応じた固定課金                    |
| `gpt-image-2.5-sunburst:official` | 公式 API ルート、安定性がより高く高忠実度と細かな制御を重視、実際の Token 使用量に応じて課金 |

公式 API ルートのページ価格はリクエスト前の見積もりであり、最終的にはレスポンス内の実際の Token 使用量と利用記録に準拠します。

## 4. 複数枚生成

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` および `gpt-image-2:reverse` は成功枚数に応じて課金されます；`gpt-image-2:official`、`gpt-image-2.5-flare:official` および `gpt-image-2.5-sunburst:official` は、レスポンス内のテキスト入力と画像出力の実際の Token に基づいて精算されます。ページ価格はリクエスト前の見積もりであり、最終的には利用記録に準拠します。

## 5. 非同期コールバック

リクエストボディに `callback_url` を追加すると、インターフェースは先に `{"task_id": "..."}` を返し、完了時にその URL へ最終結果を POST します；同期リクエストは引き続き `created` と `data` を返します：

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

コールバック受信側は `task_id` を使用して重複排除を行い、リクエスト元とデータ形式を検証する必要があります。

## 6. トラブルシューティング

| ステータス  | 確認                                                  |
| --- | --------------------------------------------------- |
| 400 | `model`、`prompt`、サイズ形式、`n` と `response_format` の組み合わせ    |
| 401 | API Key が完全か、Header が `Authorization: Bearer ...` か |
| 429 | リクエスト頻度が高すぎるため、後で再試行                                         |
| 504 | 同期生成がタイムアウト；`callback_url` を使用                            |

エラーレスポンスには `error.code`、`error.message` および `trace_id` が含まれます。問題を報告する際は `trace_id` を提供し、API Key は提供しないでください。

完全なフィールドとリアルタイムの列挙値については、[OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations)ページを参照してください。画像編集については、[GPT Image 2 / 2.5 画像編集](https://platform.acedata.cloud/documents/openai-images-edits)を確認してください。
