## 1. API キーの取得

[Ace Data Cloud アプリケーションリスト](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリにアクセスして API キーをコピーします。

![Ace Data Cloud API キーの取得](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 最初のリクエストを送信

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer あなたの API キー" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "最小限の編集的な製品イラスト：無地の白いセラミックコーヒーマグが、固体のコバルトブルーのテーブルトップの中央に配置され、淡いクリーム色の背景、柔らかい影、クリーンな幾何学的形状、テキストなし、ロゴなし、ポートレート構図",
    "size": "1024x1536"
  }'
```

成功した応答の画像は `data[].url` にあります。以下は 2026 年 9 月 8 日に Ace Data Cloud を通じて実際にリクエストして得られた 1024×1536 の結果（タスク `d56455e2-e7f7-4bcd-b935-475b0a1e0948`、トレース `eb938601-8192-407f-b539-1e0554b697ec`）です：

![GPT Image 2 生成の白いマグカップ](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. よく使うパラメータ

| フィールド           | 説明                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`（デフォルト推奨）、`gpt-image-2.5-flare`（より速い）または `gpt-image-2.5-sunburst`（より高い忠実度と制御）；明示的に `gpt-image-2:official` または `gpt-image-2:reverse` を選択することも可能です |
| `prompt`          | 画像の説明、最大 32,000 文字                                                                                                                     |
| `size`            | `auto` または `WIDTHxHEIGHT`；幅と高さは 16 の倍数でなければならず、長辺は 3840 を超えず、総ピクセルは 655,360–8,294,400、アスペクト比は 3:1 を超えないこと                                                       |
| `n`               | 1–10；`response_format=b64_json` の場合は 1 のみサポート                                                                                                 |
| `quality`         | `low`、`medium`、`high` または `auto`；異なるラインのサポートと課金方法が異なります                                                                                          |
| `response_format` | `url` または `b64_json`                                                                                                                     |
| `callback_url`    | オプション；長いタスクが完了した後にこのアドレスに結果を送信します                                                                                                                      |

よく使うサイズ：

| 比率   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` は、プロンプト内の比率、ピクセル、およびレイアウトの意図に基づいてアスペクト比を選択します；正確なピクセルが必要な場合は、サイズを直接入力してください。

## 4. 複数生成

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer あなたの API キー" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "光るキノコの下で本を読んでいる小さな狐、水彩画のイラスト",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` および `:reverse` は成功した枚数に基づいて課金されます；`gpt-image-2:official` は応答内のテキスト入力と画像出力に基づいて実際のトークンを計算します。ページの価格はリクエスト前の見積もりであり、最終的には使用記録に基づきます。

## 5. 非同期コールバック

リクエストボディに `callback_url` を追加すると、インターフェースは最初に `{"task_id": "..."}` を返し、完了時にその URL に最終結果を POST します；同期リクエストは依然として `created` と `data` を返します：

```json
{
  "model": "gpt-image-2",
  "prompt": "明確なタイポグラフィのある製品ポスター",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

コールバック受信者は `task_id` を使用して重複を排除し、リクエストの出所とデータ形式を検証する必要があります。

## 6. トラブルシューティング

| ステータス | チェック                                                  |
| --- | --------------------------------------------------- |
| 400 | `model`、`prompt`、サイズ形式、`n` と `response_format` の組み合わせ    |
| 401 | API キーが完全であるか、ヘッダーが `Authorization: Bearer ...` であるか |
| 429 | リクエストが多すぎます。後で再試行してください。                                         |
| 504 | 同期生成がタイムアウトしました；`callback_url` を使用してください。                            |

エラー応答には `error.code`、`error.message` および `trace_id` が含まれます。問題を報告する際は `trace_id` を提供し、API キーは提供しないでください。

完全なフィールドとリアルタイムの列挙は [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations) ページを参照してください。画像編集については [GPT Image 2 / 2.5 画像編集](https://platform.acedata.cloud/documents/openai-images-edits) をご覧ください。
