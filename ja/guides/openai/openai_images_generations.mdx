## 1. API Key の取得

[Ace Data Cloud アプリケーション一覧](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリケーションに入り、API Key をコピーします。

![Ace Data Cloud API Key を取得](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 最初のリクエストを送信

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

成功レスポンスの画像は `data[].url` にあります。以下は、2026年9月8日に Ace Data Cloud を通じて実際にリクエストして得られた 1024×1536 の結果です（タスク `d56455e2-e7f7-4bcd-b935-475b0a1e0948`、trace `eb938601-8192-407f-b539-1e0554b697ec`）：

![GPT Image 2 が生成した白いマグカップ](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. よく使われるパラメータ

| フィールド                | 説明                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`（デフォルト推奨）、`gpt-image-2.5-flare`（より高速）または `gpt-image-2.5-sunburst`（より高い忠実度と制御）；3つとも対応する `:official` バリアントを選択でき、`gpt-image-2` は `:reverse` もサポート |
| `prompt`          | 画像の説明、最大 32,000 文字                                                                                                                     |
| `size`            | `auto` または `WIDTHxHEIGHT`；幅と高さは 16 の倍数である必要があり、長辺は 3840 を超えず、総ピクセル数は 655,360～8,294,400、アスペクト比は 3:1 を超えない                                                       |
| `n`               | 1～10；`response_format=b64_json` の場合は 1 のみサポート                                                                                                 |
| `quality`         | GPT Image モデルは `auto`、`low`、`medium`、`high` をサポート；2.5 / 2.6 Flare / Sunburst（`:official` を含む）は追加で `xhigh`、`max` をサポート。公式チャネルは実際の Token 使用量に応じて課金             |
| `response_format` | `url` または `b64_json`                                                                                                                     |
| `callback_url`    | 任意；長時間タスクの完了後、このアドレスに結果を送信                                                                                                                      |

よく使われるサイズ：

| 比率   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` は、プロンプト内の比率、ピクセル、およびレイアウト意図に基づいてキャンバスサイズを選択します；正確なピクセル数が必要な場合は、直接サイズを指定してください。

| `gpt-image-2:reverse` | リバースチャネルを明示的に選択。生成に成功した画像数に応じて固定料金で課金されます。 |
| `gpt-image-2:official` | 公式 API チャネル。安定性が高く、実際のトークン使用量に応じて課金されます。 |
| `gpt-image-2.5-flare` | 生成速度を重視。生成に成功した画像数に応じて固定料金で課金されます。 |
| `gpt-image-2.6-flare` | 生成速度を重視。生成に成功した画像数に応じて固定料金で課金されます。 |
| `gpt-image-2.5-flare:reverse` | 明示的なリバースエイリアス。`gpt-image-2.5-flare` と同等で、生成に成功した画像数に応じて固定料金で課金されます。 |
| `gpt-image-2.6-flare:reverse` | 明示的なリバースエイリアス。`gpt-image-2.6-flare` と同等で、生成に成功した画像数に応じて固定料金で課金されます。 |
| `gpt-image-2.5-flare:official` | 公式 API チャネル。安定性が高く、生成速度を重視しています。実際の Token 使用量に基づいて課金されます。 |
| `gpt-image-2.6-flare:official` | 公式 API チャネル。安定性が高く、生成速度を重視しています。実際の Token 使用量に基づいて課金されます。 |
| `gpt-image-2.5-sunburst` | 高忠実度と精密な制御を重視しています。成功した画像数ごとに定額で課金されます。 |
| `gpt-image-2.6-sunburst` | 高忠実度と精密な制御を重視しています。成功した画像数ごとに定額で課金されます。 |
| `gpt-image-2.5-sunburst:reverse` | 明示的な逆方向エイリアスです。`gpt-image-2.5-sunburst` と同等で、成功した画像数ごとに定額で課金されます。 |
| `gpt-image-2.6-sunburst:reverse` | 明示的な逆方向エイリアスです。`gpt-image-2.6-sunburst` と同等で、成功した画像数ごとに定額で課金されます。 |
| `gpt-image-2.5-sunburst:official` | 公式 API チャネル。安定性が高く、高忠実度と精密な制御を重視しています。実際の Token 使用量に基づいて課金されます。 |

公式 API チャネルのページ上の価格はリクエスト前の見積もりです。最終的にはレスポンス内の実際の Token 使用量と利用記録に基づきます。

## 4. 複数枚生成

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` およびその `:reverse` エイリアスは成功した画像数に応じて課金されます；`gpt-image-2:official`、`gpt-image-2.5-flare:official`、および `gpt-image-2.5-sunburst:official` はレスポンス内のテキスト入力と画像出力の実際の Token に基づいて精算されます。ページ上の価格はリクエスト前の見積もりであり、最終的には利用記録に基づきます。

## 5. 非同期コールバック

リクエストボディに `callback_url` を追加すると、インターフェースはまず `{"task_id": "..."}` を返し、完了時にその URL へ最終結果を POST します；同期リクエストは引き続き `created` と `data` を返します：

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

コールバック受信側は `task_id` を使用して重複排除を行い、リクエスト元とデータ形式を検証する必要があります。

## 6. トラブルシューティング

| ステータス | 確認                                                  |
| --- | --------------------------------------------------- |
| 400 | `model`、`prompt`、サイズ形式、`n` と `response_format` の組み合わせ    |
| 401 | API Key が完全か、Header が `Authorization: Bearer ...` か |
| 429 | リクエストが頻繁すぎます。しばらくしてから再試行してください                         |
| 504 | 同期生成がタイムアウトしました；`callback_url` を使用してください                            |

エラーレスポンスには `error.code`、`error.message`、および `trace_id` が含まれます。問題をフィードバックする際は `trace_id` を提供し、API Key は提供しないでください。

完全なフィールドとリアルタイムの列挙値は [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations) ページを参照してください。画像編集については [GPT Image 2 / 2.5 / 2.6 画像編集](https://platform.acedata.cloud/documents/openai-images-edits) を確認してください。

## GPT Image 2.6

GPT Image 2.6 は 2.5 の生成、編集、非同期タスク、および課金インターフェースを継承します：

| モデル                                                          | 課金                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/枚                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/枚                   |
| `gpt-image-2.6-flare:official`                              | 2.5 official と同じで、実際の Token 使用量に応じて課金 |
| `gpt-image-2.6-sunburst:official`                           | 2.5 official と同じで、実際の Token 使用量に応じて課金 |

品質は `auto`、`low`、`medium`、`high`、`xhigh`、`max` から選択できます；サイズには `auto` または上記の制約に準拠する `WIDTHxHEIGHT` を使用します。本インターフェースは `png`、`jpeg`、`webp` をサポートします；GPT Image 2.6 はネイティブの `gif` アニメーションもサポートしますが、SVG は現在サポートしていません。編集では JSON 画像 URL および multipart ファイルアップロードをサポートします。`:reverse` は同名の通常版の明示的なエイリアスです。完全なモデル名を使用し、`gpt-image-2.6` を渡さないでください。

### GPT Image 2.6 GIF アニメーション

GPT Image 2.6 Flare、Sunburst の通常版、`:reverse`、`:official` はすべて `output_format: "gif"` を使用できます。アニメーションフレーム、ループ情報、再生時間は保持されます；`frame_count` はフレーム数を表し、`frame_duration_ms` は各フレームのミリ秒数を表します。フレーム数は 2～16 の整数でなければならず、各フレームの時間は 20～655350 ミリ秒の整数でなければならず、GIF にのみ使用されます；エンコード時には最も近い 10ms に丸められます。指定しない場合、デフォルトは 9 フレーム、各フレーム 200 ミリ秒です；GIF で size を省略するか auto にすると、512x512 プリセットが使用されます。

まず `size: "512x512"`、`frame_count: 9`、`frame_duration_ms: 200` を使用することを推奨します。GIF には独自のサイズおよびフレーム数の制限があり、静的 4K 仕様をそのまま適用することはできません；一部のモデルは実際の出力サイズを調整します。`n` は返される GIF ファイルの数を表し、アニメーションフレーム数ではありません。通常版と `:reverse` は引き続き成功したファイル数に応じて課金され、公式版は実際の Token 使用量に応じて課金されます。

```json
{
  "model": "gpt-image-2.6-flare",
  "prompt": "A small red ball moves left and right on a white background, seamless looping animation, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### GPT Image 2.6 4K 静止画

Flare、Sunburst およびその `:reverse`、`:official` バリアントはすべて、前述の `3840x2160` や `2160x3840` などの 4K ピクセルプリセットを使用できます。生成と編集はいずれも `size` を通じて具体的なピクセル数を渡します；`4K` は有効な `size` 値ではなく、`4096x4096` も現在のピクセル上限を超えています。上記の 4K 仕様は静的 PNG/JPEG/WebP に適用され、GIF には専用パラメータを使用してください。

### GPT Image 2.6 構図の複雑度

`complexity` は `low`、`medium`、`high` から選択でき、省略時はモデルのデフォルトである `high` が使用されます。これはプランニングの複雑度を制御し、`quality` のレンダリング品質とは独立しています；追加の回数課金は発生せず、公式版は引き続き実際の Token に基づいて精算されます。他のモデルはこのパラメータをサポートしていません。

GIF は mask、注釈画像、カスタム圧縮、プロンプトの書き換え、または一部の画像ストリーミング出力をサポートしません；互換性のない組み合わせは生成前に拒否されます。サイズ、フレーム数、数量はモデルのピクセル予算による制限を共同で受けます；通常版 Flare の `1024x1024`、2 フレームは動作確認済みですが、この結論をすべての 1K 組み合わせや 4K GIF に拡張することはできません。
