## 1. API Key を取得する

[Ace Data Cloud アプリケーション一覧](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリケーションに入り、API Key をコピーします。

![Ace Data Cloud API Key を取得する](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 画像 URL を使用して編集する

元画像：

![GPT Image 2 編集元画像](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer あなたの API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "マグカップ、テーブルトップ、カメラアングル、縦長レイアウト、柔らかな影は変更しないでください。マグカップの色のみを白から鮮やかなオレンジに変更し、淡いクリーム色の背景を単色の濃いネイビーブルーに変更してください。文字やロゴは入れないでください。",
    "size": "1024x1536"
  }'
```

成功レスポンス：

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

これは 2026 年 9 月 8 日に Ace Data Cloud を通じて実際に完了した編集結果です。カップはオレンジ色に、背景は濃いネイビーブルーに変更され、元の構図と 1024×1536 のサイズが維持されています：

![GPT Image 2 オレンジ色のマグカップ編集結果](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. ローカル画像をアップロードする

`multipart/form-data` を使用します：

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer あなたの API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=背景を明るくモダンなスタジオに置き換えてください"
```

`image` は繰り返し渡すことができ、GPT Image シリーズは最大 16 枚の参照画像をサポートします。JSON リクエストの `image` には単一の URL または URL 配列を使用でき、ローカルファイルは multipart でアップロードします。

## 4. よく使われるパラメータ

| フィールド                | 説明                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`、`gpt-image-2.5-flare`（より高速）または `gpt-image-2.5-sunburst`（より高忠実度・高制御）；いずれも対応する `:official` バリアントを選択でき、`gpt-image-2` は `:reverse` もサポート |
| `image`           | JSON では単一の URL または最大 16 個の URL の配列；multipart では 1 つまたは複数の `image` ファイルフィールド                                                                    |
| `prompt`          | 編集指示                                                                                                                             |
| `size`            | `auto` または制限に適合する `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1～10；`response_format=b64_json` の場合は 1 のみサポート                                                                                           |
| `response_format` | `url` または `b64_json`                                                                                                               |
| `callback_url`    | 任意の非同期コールバック URL                                                                                                                         |

サイズ規則は生成インターフェースと同じです。幅と高さは 16 の倍数である必要があり、長辺は 3840 を超えず、総ピクセル数は 655,360～8,294,400、アスペクト比は 3:1 を超えてはなりません。`size` を省略するか `auto` を使用すると、モデルはプロンプトと最初の参照画像を組み合わせて画面比率を選択します。

`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst`、および `gpt-image-2:reverse` は成功した画像数に応じて課金されます。`gpt-image-2:official`、`gpt-image-2.5-flare:official`、および `gpt-image-2.5-sunburst:official` は、テキスト入力、参照画像入力、画像出力の実際の Token に基づいて精算され、最終的には利用記録に準拠します。

## 5. 非同期コールバックとトラブルシューティング

長時間タスクでは、リクエストに以下を追加できます：

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

非同期の 200 レスポンスは `{"task_id": "..."}` です。完了後、最終結果がコールバックされます。同期リクエストでは `created` と `data` が返されます。

| ステータス  | 確認事項                      |
| --- | ----------------------- |
| 400 | 画像形式/数、パラメータの組み合わせ、サイズ形式       |
| 401 | API Key と Bearer Header |
| 429 | リクエスト頻度                    |
| 504 | 非同期コールバックに切り替える                  |

エラーレスポンスには `trace_id` が含まれます。問題を報告する際はこの ID を提供し、API Key は提供しないでください。

完全なフィールドとリアルタイムの列挙値については、[OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) ページを参照してください。テキストのみで画像を生成する場合は、[GPT Image 2 / 2.5 画像生成](https://platform.acedata.cloud/documents/openai-images-generations)を参照してください。
