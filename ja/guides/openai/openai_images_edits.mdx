## 1. APIキーの取得

[Ace Data Cloud アプリ一覧](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリに入り、APIキーをコピーします。

## 2. 画像URLを使った編集

元の画像：

![GPT Image 2 編集元画像](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer あなたのAPIキー" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "マグカップ、テーブルトップ、カメラアングル、ポートレートレイアウト、ソフトシャドウはそのままにしてください。白色のマグカップの色を鮮やかなオレンジに変更し、淡いクリーム色の背景を濃いネイビーブルーの単色にしてください。テキストやロゴは不要です。",
    "size": "1024x1536"
  }'
```


これは2026年9月8日にAce Data Cloudを通じて実際に完了した編集結果で、マグカップはオレンジ色に、背景は深海軍色に変わり、元の構図と1024×1536のサイズを維持しています。

## 3. ローカル画像のアップロード

`multipart/form-data`を使用：

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer あなたのAPIキー" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=明るい現代的なスタジオに背景を置き換える"
```

`image`を繰り返し送信可能で、GPT Imageシリーズは最大16枚の参考画像をサポートします。JSONリクエストの`image`は単一のURLまたはURL配列にできます。ローカルファイルはmultipartアップロードを使用します。

## 4. マスクを使った部分編集

公式Images Edit APIは`mask`を指定して編集可能な領域を決めます。Ace Data Cloudの`:official`モデルは同じmultipart契約に従います。

- `mask`はAlphaチャンネル付きのPNGで、サイズは4MBを超えないこと；
- マスクのサイズは最初の`image`と完全に一致する必要があります；
- Alpha値が`0`の透明ピクセルは編集を許可し、非透明ピクセルは保持されます；
- 透明チャンネルのない黒白のRGB画像は有効なマスクとして使えません；
- プロンプトは期待する全体像を記述し、局所的な変更と保持すべき内容を明確にします。

まず元画像からマスクを生成します。例では中央の矩形を透明に設定し、その部分だけモデルに編集を許可します。

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

次に、元画像とマスクを一緒にアップロード：

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer あなたのAPIキー" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=構図、照明、透明マスクの外側のすべてのオブジェクトはそのままにしてください。マスク内の空のテーブルトップを小さな青い陶器の花瓶に置き換えてください。"
```

または、OpenAI公式Python SDKの`images.edit`を使う場合は、`base_url`をAce Data Cloudに設定します。

```python
from openai import OpenAI

client = OpenAI(
    api_key="あなたのAPIキー",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "構図、照明、透明マスクの外側のすべてのオブジェクトはそのままにしてください。"
            "マスク内の空のテーブルトップを小さな青い陶器の花瓶に置き換えてください。"
        ),
    )

print(result.data[0].url)
```

`mask`を使う場合、元画像とマスクは同じmultipartリクエスト内で`image=@input.png`と`mask=@mask.png`でそれぞれアップロードしてください。URLの画像とローカルのマスクファイルを混在させて送信しないでください。純粋なURL編集リクエストはローカルの`mask`ファイルを付加できません。マスクは編集範囲を制約しますが、生成モデルはエッジを自然に融合させることもあります。厳密な境界線が必要な場合は、明確なAlphaエッジを使用し、プロンプト内で保持すべき内容を繰り返し指示してください。

これらの呼び出しは[OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit)や[GPT Image公式クックブック](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image)のマスク例と一致します。

## 5. よく使われるパラメータ

| 項目               | 説明                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`、`gpt-image-2.5-flare`（高速）、または`gpt-image-2.5-sunburst`（高忠実度・高コントロール）；いずれも`:official`バリアントを選択可能。`gpt-image-2`は`:reverse`もサポート |
| `image`           | JSONは単一URLまたは最大16個のURL配列；multipartは1つまたは複数の`image`ファイルフィールド。`mask`使用時はローカル画像ファイルをアップロード必須 |
| `mask`            | オプションのPNGマスク（multipartファイルアップロードのみ）；Alphaチャンネル必須、最初の`image`と同じサイズ、4MB以内 |
| `prompt`          | 編集指示                                                                                                                             |
| `size`            | `auto`または制限内の`WIDTHxHEIGHT`                                                                                                   |
| `n`               | 1～10；`response_format=b64_json`時は1のみサポート                                                                                   |
| `response_format` | `url`または`b64_json`                                                                                                               |
| `callback_url`    | オプションの非同期コールバックURL                                                                                                    |
サイズルールは生成インターフェースと同じ：幅と高さは16の倍数でなければならず、長辺は3840を超えない。総ピクセル数は655,360〜8,294,400で、縦横比は3:1を超えない。`size`を省略するか`auto`を使用すると、モデルはプロンプトと最初の参考画像に基づいて画幅を選択します。

`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst`、および`gpt-image-2:reverse`は成功した枚数に応じて課金されます。`gpt-image-2:official`、`gpt-image-2.5-flare:official`、および`gpt-image-2.5-sunburst:official`は、テキスト入力、参考画像入力、および画像出力の実際のトークン数に基づいて請求され、最終的には使用記録を基準とします。

## 6. 非同期コールバックとトラブルシューティング

長時間のタスクはリクエストに次のように追加できます。

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

非同期の200レスポンスは`{"task_id": "..."}`となり、完了後に最終結果をコールバックします。同期リクエストは`created`と`data`を返します。

| 状態  | チェック内容                                                        |
| --- | ----------------------------------------------------------------- |
| 400 | 画像フォーマット/数、パラメータの組み合わせとサイズフォーマット；`mask`使用時はPNGのAlphaチャンネル、4MB制限、そのサイズが最初の原画像と一致しているかを確認 |
| 401 | APIキーとBearerヘッダー                                              |
| 429 | リクエスト頻度                                                      |
| 504 | 非同期コールバックに切り替え                                         |

エラー応答には`trace_id`が含まれます。問題を報告する際はこのIDを提供し、APIキーは提供しないでください。

完全なフィールドとリアルタイムの列挙は[OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits)ページを参照してください。純粋なテキストから画像を生成する場合は[GPT Image 2 / 2.5 画像生成](https://platform.acedata.cloud/documents/openai-images-generations)をご覧ください。
