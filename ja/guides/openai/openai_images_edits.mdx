## 3. ローカル画像のアップロード

`multipart/form-data` を使用します：

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` は繰り返し渡すことができ、GPT Image シリーズは最大 16 枚の参照画像をサポートします。JSON リクエスト内の `image` は単一の URL または URL 配列にできます。ローカルファイルは multipart でアップロードします。

### モデルと課金方式

| モデル                                | 適用シーンと課金方式                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | デフォルトのリバースチャネル、成功した画像枚数に応じた固定課金                               |
| `gpt-image-2:reverse`             | リバースチャネルを明示的に選択、成功した画像枚数に応じた固定課金                             |
| `gpt-image-2:official`            | 公式 API チャネル、安定性がより高く、実際の Token 使用量に応じた課金                   |
| `gpt-image-2.5-flare`             | 生成速度を重視、成功した画像枚数に応じた固定課金                               |
| `gpt-image-2.6-flare`             | 生成速度を重視、成功した画像枚数に応じた固定課金                               |
| `gpt-image-2.5-flare:reverse`     | 明示的なリバース別名、`gpt-image-2.5-flare` と同等で、成功した画像枚数に応じた固定課金    |
| `gpt-image-2.6-flare:reverse`     | 明示的なリバース別名、`gpt-image-2.6-flare` と同等で、成功した画像枚数に応じた固定課金    |
| `gpt-image-2.5-flare:official`    | 公式 API チャネル、安定性がより高く生成速度を重視、実際の Token 使用量に応じた課金            |
| `gpt-image-2.6-flare:official`    | 公式 API チャネル、安定性がより高く生成速度を重視、実際の Token 使用量に応じた課金            |
| `gpt-image-2.5-sunburst`          | 高忠実度と精密な制御を重視、成功した画像枚数に応じた固定課金                           |
| `gpt-image-2.6-sunburst`          | 高忠実度と精密な制御を重視、成功した画像枚数に応じた固定課金                           |
| `gpt-image-2.5-sunburst:reverse`  | 明示的なリバース別名、`gpt-image-2.5-sunburst` と同等で、成功した画像枚数に応じた固定課金 |
| `gpt-image-2.6-sunburst:reverse`  | 明示的なリバース別名、`gpt-image-2.6-sunburst` と同等で、成功した画像枚数に応じた固定課金 |
| `gpt-image-2.5-sunburst:official` | 公式 API チャネル、安定性がより高く高忠実度と精密な制御を重視、実際の Token 使用量に応じた課金        |
| `gpt-image-2.6-sunburst:official` | 公式 API チャネル、安定性がより高く高忠実度と精密な制御を重視、実際の Token 使用量に応じた課金        |

2.0 / 2.5 のリバースモデル（`:reverse` 別名を含む）は、自動復旧時に GPT Image 2.5 Flare を使用してリクエストを完了する場合があります。リクエストモデルおよび成功した画像枚数に応じた課金方式は変わりません。

公式 API チャネルのページ上の価格はリクエスト前の見積もりであり、最終的にはレスポンス内の実際の Token 使用量および利用記録に基づきます。

`quality` は `auto`、`low`、`medium`、`high` をサポートします。2.5 / 2.6 Flare および Sunburst（`:reverse` と `:official` バリアントを含む）は、さらに `xhigh`、`max` をサポートします。JSON による画像 URL 編集と multipart によるファイル編集の両方でこのフィールドを渡すことができます。公式チャネルは実際の Token 使用量に応じて課金されます。

## 4. マスクを使用した部分編集

公式 Images Edit インターフェースは、`mask` によって変更を許可する領域を指定します。Ace Data Cloud の `:official` モデルは同じ multipart 契約に従います：

- `mask` は Alpha チャネルを持つ PNG でなければならず、サイズは 4MB を超えてはいけません；
- マスクのサイズは最初の `image` と完全に一致している必要があります；
- Alpha が `0` の透明なピクセルは編集を許可することを示し、不透明なピクセルは保持すべきことを示します；
- 色が白黒のみで透明チャネルを持たない RGB 画像は、有効なマスクとして使用できません；
- プロンプトでは、期待する完全な画像を説明すると同時に、部分的な変更と変更せずに維持する必要がある内容を明確に指定する必要があります。

以下ではまず元画像からマスクを生成します。この例では中央の長方形を透明に設定し、モデルがその領域のみを変更できるようにします：
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

その後、元画像とマスクを一緒にアップロードします：

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

OpenAI 公式 Python SDK の `images.edit` 呼び出し方法をそのまま使用することもでき、`base_url` を Ace Data Cloud に指定するだけです：

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

`mask` を使用する場合、元画像とマスクは同一の multipart リクエスト内で、それぞれ `image=@input.png` と `mask=@mask.png` によりアップロードする必要があります。URL の元画像とローカルのマスクファイルを混在させて渡さないでください。純粋な URL 編集リクエストでは、ローカルの `mask` ファイルを追加で添付することはサポートされていません。マスクは編集領域を制約しますが、生成モデルは依然としてエッジを自然にブレンドする可能性があります。厳密な境界が必要な場合は、明確な Alpha エッジを使用し、プロンプト内で変更してはならない内容を繰り返し指定してください。

上記の呼び出し方法は、[OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) および [GPT Image 公式 Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image) のマスク例と一致しています。

## 5. よく使われるパラメータ

| フィールド                | 説明                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`、`gpt-image-2.5-flare`（より高速）または `gpt-image-2.5-sunburst`（より高い忠実度と制御）；3 つとも対応する `:official` バリアントを選択でき、`gpt-image-2` は `:reverse` もサポート |
| `image`           | JSON では単一の URL または最大 16 個の URL の配列を使用；multipart では 1 つ以上の `image` ファイルフィールドを使用。`mask` を使用する場合はローカル画像ファイルをアップロードする必要があります                                              |
| `mask`            | オプションの PNG マスク。multipart ファイルアップロードのみ；Alpha チャネルを備え、最初の `image` と同じサイズで、4MB を超えない必要があります                                                                 |
| `prompt`          | 編集指示                                                                                                                             |
| `size`            | `auto` または制限に適合する `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1～10；`response_format=b64_json` の場合は 1 のみサポート                                                                                           |
| `response_format` | `url` または `b64_json`                                                                                                               |
| `callback_url`    | オプションの非同期コールバック URL                                                                                                                         |

サイズ規則は生成インターフェースと同じです：幅と高さは 16 の倍数である必要があり、長辺は 3840 を超えず、総ピクセル数は 655,360～8,294,400、アスペクト比は 3:1 を超えません。`size` を省略するか `auto` を使用した場合、モデルはプロンプトと最初の参照画像に基づいて画角を選択します。

`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` およびそれらの `:reverse` エイリアスは成功画像数に応じて課金されます；`gpt-image-2:official`、`gpt-image-2.5-flare:official`、および `gpt-image-2.5-sunburst:official` はテキスト入力、参照画像入力、画像出力の実際の Token に基づいて精算され、最終的には利用記録に従います。

## 6. 非同期コールバックとトラブルシューティング

長時間タスクでは、リクエストに以下を追加できます：

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

非同期の 200 レスポンスは `{"task_id": "..."}` です；完了後、最終結果がコールバックされます。同期リクエストでは `created` と `data` が返されます。

| ステータス  | 確認事項                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | 画像形式/数、パラメータの組み合わせ、サイズ形式；`mask` を使用する場合は PNG Alpha チャネル、4MB 制限、およびそのサイズが最初の元画像と一致するかを確認 |
| 401 | API Key と Bearer Header                                           |
| 429 | リクエスト頻度                                                              |
| 504 | 非同期コールバックに切り替える                                                            |

エラーレスポンスには `trace_id` が含まれます。問題をフィードバックする際はこの ID を提供し、API Key は提供しないでください。

完全なフィールドとリアルタイムの列挙値は [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) ページに従ってください。テキストのみからの画像生成については、[GPT Image 2 / 2.5 / 2.6 画像生成](https://platform.acedata.cloud/documents/openai-images-generations) を参照してください。

## GPT Image 2.6

GPT Image 2.6 は 2.5 の生成、編集、非同期タスク、および課金インターフェースを継承しています：

| モデル                                                          | 課金                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/枚                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/枚                   |
| `gpt-image-2.6-flare:official`                              | 2.5 official と同じで、実際の Token 使用量に応じて課金 |
| `gpt-image-2.6-sunburst:official`                           | 2.5 official と同じで、実際の Token 使用量に応じて課金 |

品質は `auto`、`low`、`medium`、`high`、`xhigh`、`max` から選択できます；サイズには `auto` または上記の制約に適合する `WIDTHxHEIGHT` を使用します。本インターフェースは `png`、`jpeg`、`webp` をサポートし、現時点では SVG/GIF はサポートしていません。編集では JSON 画像 URL および multipart ファイルアップロードをサポートしています。`:reverse` は同名の通常版の明示的なエイリアスです。完全なモデル名を使用し、`gpt-image-2.6` を渡さないでください。
