## 1. API Key を取得する

[Ace Data Cloud アプリケーションリスト](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリケーションに入り、API Key をコピーします。

![Ace Data Cloud API Key を取得する](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 画像 URL を使用して編集する

元画像：

![GPT Image 2 編集元画像](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"

```

## 3. ローカル画像をアップロードする

`multipart/form-data` を使用します：

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` は繰り返し渡すことができ、GPT Image シリーズは最大 16 枚の参照画像をサポートします。JSON リクエスト内の `image` は単一の URL または URL 配列にでき、ローカルファイルは multipart でアップロードします。

### モデルと課金方式

| モデル                                | 適用シーンと課金方式                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | デフォルトのリバースチャネル、成功した画像枚数に応じた固定課金                        |
| `gpt-image-2:reverse`             | リバースチャネルを明示的に選択、成功した画像枚数に応じた固定課金                      |
| `gpt-image-2:official`            | 公式 API チャネル、安定性が高く、実際の Token 使用量に応じて課金            |
| `gpt-image-2.5-flare`             | 生成速度を重視、成功した画像枚数に応じた固定課金                        |
| `gpt-image-2.5-flare:official`    | 公式 API チャネル、安定性が高く生成速度を重視、実際の Token 使用量に応じて課金     |
| `gpt-image-2.5-sunburst`          | 高忠実度と精密な制御を重視、成功した画像枚数に応じた固定課金                    |
| `gpt-image-2.5-sunburst:official` | 公式 API チャネル、安定性が高く高忠実度と精密な制御を重視、実際の Token 使用量に応じて課金 |

公式 API チャネルのページ上の価格はリクエスト前の見積もりであり、最終的にはレスポンス内の実際の Token 使用量と利用記録に基づきます。

## 4. マスクを使用した部分編集

公式 Images Edit インターフェースでは、`mask` によって変更を許可する領域を指定します。Ace Data Cloud の `:official` モデルは同じ multipart 契約に従います：

- `mask` は Alpha チャネル付きの PNG である必要があり、サイズは 4MB を超えてはなりません；
- マスクのサイズは最初の `image` と完全に一致している必要があります；
- Alpha が `0` の透明ピクセルは編集を許可することを示し、不透明なピクセルは保持すべきことを示します；
- 白黒の色だけで透明チャネルを持たない RGB 画像は、有効なマスクとして使用できません；
- プロンプトでは期待する完全な画像を説明するとともに、部分的な変更と変わらずに保持する必要がある内容を明確にする必要があります。

以下ではまず元画像からマスクを生成します。例では中央の長方形を透明に設定し、モデルがその領域のみを変更できるようにします：

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

次に、元画像とマスクを一緒にアップロードします：

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

OpenAI 公式 Python SDK の `images.edit` 呼び出し方法をそのまま使用することもできます。`base_url` を Ace Data Cloud に向けるだけです：

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

`mask` を使用する場合、元画像とマスクは同一の multipart リクエスト内で、それぞれ `image=@input.png` と `mask=@mask.png` によりアップロードする必要があります。URL の元画像とローカルのマスクファイルを混在させて渡さないでください。URL のみの編集リクエストでは、ローカルの `mask` ファイルを追加で添付することはサポートされていません。マスクは編集領域を制約しますが、生成モデルはエッジを自然に融合させる可能性があります。厳密な境界が必要な場合は、明確な Alpha エッジを使用し、プロンプトで変更せずに保持すべき内容を繰り返し明記してください。

上記の呼び出し方法は、[OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit)および[GPT Image 公式 Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image)のマスク例と一致しています。

## 5. よく使用されるパラメータ
| フィールド                | 説明                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`、`gpt-image-2.5-flare`（より高速）または `gpt-image-2.5-sunburst`（より高い忠実度と制御）；3つとも対応する `:official` バリアントを選択可能で、`gpt-image-2` は `:reverse` もサポート |
| `image`           | JSON では単一の URL または最大 16 個の URL の配列を使用；multipart では 1 つ以上の `image` ファイルフィールドを使用。`mask` を使用する場合はローカル画像ファイルをアップロードする必要があります                                              |
| `mask`            | オプションの PNG マスク。multipart ファイルアップロードのみ；Alpha チャネルを含み、最初の `image` と同じ寸法で、4MB を超えないこと                                                                 |
| `prompt`          | 編集指示                                                                                                                             |
| `size`            | `auto` または制限に準拠した `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1～10；`response_format=b64_json` の場合は 1 のみサポート                                                                                           |
| `response_format` | `url` または `b64_json`                                                                                                               |
| `callback_url`    | オプションの非同期コールバック URL                                                                                                                         |

サイズ規則は生成インターフェースと同じです：幅と高さは 16 の倍数である必要があり、長辺は 3840 を超えず、総ピクセル数は 655,360～8,294,400、アスペクト比は 3:1 を超えません。`size` を省略するか `auto` を使用した場合、モデルはプロンプトと最初の参照画像に基づいて画角を選択します。

`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` と `gpt-image-2:reverse` は成功した画像数に応じて課金されます；`gpt-image-2:official`、`gpt-image-2.5-flare:official`、`gpt-image-2.5-sunburst:official` はテキスト入力、参照画像入力、画像出力の実際の Token に基づいて精算され、最終的には使用記録に準拠します。

## 6. 非同期コールバックとトラブルシューティング

長時間のタスクでは、リクエストに以下を追加できます：

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

非同期の 200 レスポンスは `{"task_id": "..."}` です；完了後、最終結果がコールバックされます。同期リクエストでは `created` と `data` が返されます。

| ステータス  | 確認事項                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | 画像形式/数量、パラメータの組み合わせ、サイズ形式；`mask` 使用時は PNG Alpha チャネル、4MB 制限、およびそのサイズが最初の元画像と一致するかを確認 |
| 401 | API Key と Bearer Header                                           |
| 429 | リクエスト頻度                                                              |
| 504 | 非同期コールバックに切り替える                                                            |

エラーレスポンスには `trace_id` が含まれます。問題をフィードバックする際はこの ID を提供し、API Key は提供しないでください。

完全なフィールドとリアルタイムの列挙は [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) ページを参照してください。テキストのみからの画像生成については、[GPT Image 2 / 2.5 画像生成](https://platform.acedata.cloud/documents/openai-images-generations) を確認してください。
