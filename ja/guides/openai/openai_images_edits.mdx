## 1. API Key の取得

[Ace Data Cloud アプリケーションリスト](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリにアクセスして API Key をコピーします。

![Ace Data Cloud API Key の取得](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 画像 URL を使用して編集

元の画像：

![GPT Image 2 編集元画像](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer あなたの API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "マグカップ、テーブル、カメラアングル、ポートレートレイアウト、柔らかい影を変更せずに保持します。マグカップの色を白から鮮やかなオレンジに、淡いクリームの背景を濃いネイビーブルーに変更します。テキストやロゴは不要です。",
    "size": "1024x1536"
  }'
```

成功レスポンス：

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

これは 2026 年 9 月 8 日に Ace Data Cloud を通じて実際に完了した編集結果で、マグカップがオレンジ色に、背景が濃いネイビーブルーに変わり、元の構図と 1024×1536 サイズを保持しています：

![GPT Image 2 オレンジ色マグカップ編集結果](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. ローカル画像のアップロード

`multipart/form-data` を使用：

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer あなたの API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=背景を明るい現代的なスタジオに置き換えます"
```

`image` を繰り返し渡すことができ、GPT Image シリーズは最大 16 枚の参照画像をサポートします。JSON リクエストの `image` は単一の URL または URL 配列であり、ローカルファイルは multipart でアップロードします。

## 4. よく使うパラメータ

| フィールド           | 説明                                                                                                                       |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `model`           | `gpt-image-2`、`gpt-image-2.5-flare`（より速い）、`gpt-image-2.5-sunburst`（より高い忠実度と制御）、`gpt-image-2:official` または `gpt-image-2:reverse` |
| `image`           | JSON では単一の URL または最大 16 の URL の配列；multipart では 1 つまたは複数の `image` ファイルフィールド                                                            |
| `prompt`          | 編集指示                                                                                                                     |
| `size`            | `auto` または制限に合った `WIDTHxHEIGHT`                                                                                             |
| `n`               | 1–10；`response_format=b64_json` の場合は 1 のみ                                                                                   |
| `response_format` | `url` または `b64_json`                                                                                                       |
| `callback_url`    | オプションの非同期コールバックアドレス                                                                                                                 |

サイズのルールは生成インターフェースと一致します：幅と高さは 16 の倍数でなければならず、長辺は 3840 を超えず、総ピクセルは 655,360–8,294,400、アスペクト比は 3:1 を超えません。`size` を省略するか `auto` を使用すると、モデルはプロンプトと最初の参照画像に基づいてアスペクト比を選択します。

`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` および `:reverse` は成功した画像の数に基づいて課金されます；`gpt-image-2:official` はテキスト入力、参照画像入力、画像出力の実際のトークンに基づいて決済され、最終的には使用記録に基づきます。

## 5. 非同期コールバックとトラブルシューティング

長いタスクはリクエストに次のように追加できます：

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

非同期 200 レスポンスは `{"task_id": "..."}` です；完了後に最終結果をコールバックします。同期リクエストは `created` と `data` を返します。

| 状態  | チェック                      |
| --- | ----------------------- |
| 400 | 画像形式/数量、パラメータの組み合わせとサイズ形式       |
| 401 | API Key と Bearer ヘッダー |
| 429 | リクエスト頻度                    |
| 504 | 非同期コールバックに切り替え                  |

エラーレスポンスには `trace_id` が含まれます。問題を報告する際はこの ID を提供し、API Key は提供しないでください。

完全なフィールドとリアルタイムの列挙は [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) ページを参照してください。純粋なテキスト生成画像については [GPT Image 2 / 2.5 画像生成](https://platform.acedata.cloud/documents/openai-images-generations) をご覧ください。
