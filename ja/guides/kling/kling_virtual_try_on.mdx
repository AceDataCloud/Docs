`POST /kling/virtual-try-on` を通じてタスクを送信し、既存の `POST /kling/tasks` を使用してプラットフォームのタスク状態を照会します。

## 入力

product_image と person_image をそれぞれちょうど1枚提供する必要があります。keep_face、keep_pose、keep_background はすべてデフォルトで true であり、個別に無効化できます。入力画像の最長辺は 2048px を超えず、最短辺は 300px より大きく、ファイルは 10MB を超えません。

以下はリクエスト構造の例です。素材 URL を置き換えてから呼び出してください。

```json
{
  "contents": [
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "person_image",
      "url": "https://your-cdn.example/person.jpg"
    }
  ],
  "async": true
}
```

## 結果と課金

同期モードでは生成結果が返されます。非同期モードではまず `task_id` が返され、完了結果には `data` 内の動画または画像リンクと、サーバー側で計算された `usage` が含まれます。`callback_url` は完了通知に使用されます。`watermark=true` リクエストでは、ウォーターマーク版も同時に返されます。

1.12 Credits/枚で、実際の出力画像数に基づいて課金されます。動画は実際の生成時間に基づいて精算され、生成前の1秒あたりの基本価格はタスク全体の合計価格を表すものではありません。失敗したタスクには生成料金は請求されません。
