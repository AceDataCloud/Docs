---
title: "Kling Talking Photo API（Kling Talking Photo）"
description: "Kling video generation API guide - Ace Data Cloud"
---

**1 枚の写真 + 1 つの音声**をワンクリックで「話す動画」に変換します。サービス内部で 2 つのステップが自動的に完了します:まず image2video で写真を動かし、その後 lip-sync で音声に合わせて口パクを行います。呼び出しは**1 回だけ**です。

- **エンドポイント**：`POST https://api.acedata.cloud/kling/talking-photo`
- **料金**：時間に応じて、5 秒 **16.45 Credits**、10 秒 **30.45 Credits**（= image2video + lip-sync の統合価格）

## リクエストヘッダー

| フィールド              | 値                   |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## リクエストパラメータ

| パラメータ             | 型      | 必須  | デフォルト                  | 説明                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | はい   | —                   | 人物写真の公開 URL、鮮明な正面顔を推奨                    |
| `audio_url`    | string  | はい   | —                   | 音声を駆動する公開 URL（.mp3/.wav/.m4a/.aac、≤5MB） |
| `prompt`       | string  | いいえ   | —                   | 写真アニメーション化段階の動作/表情プロンプト                      |
| `model`        | string  | いいえ   | `kling-v2-1-master` | 写真アニメーション化に使用する Kling モデル                     |
| `duration`     | integer | いいえ   | `5`                 | 動画の長さ（5 または 10 秒）                        |
| `mode`         | string  | いいえ   | `pro`               | アニメーション化品質（std/pro）                        |
| `callback_url` | string  | いいえ   | —                   | 渡すか `async=true` の場合、非同期で task_id を返す        |
| `async`        | boolean | いいえ   | `false`             | 非同期モード、`/kling/tasks` のポーリングまたはコールバックと併用          |

## リクエスト例

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## レスポンス例

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| フィールド                 | 説明                        |
| ------------------ | ------------------------- |
| `video_url`        | 最終的な話す動画（すでに本プラットフォームの CDN に保存済み）      |
| `source_video_url` | 中間の写真アニメーション動画（image2video の結果） |
| `video_id`         | Kling 動画 ID                   |

## 注意事項

- 写真は鮮明な正面顔、1 人を推奨します。
- 音声の長さは動画の長さ（5 秒/10 秒）を超えないことを推奨します。
- 課金は成功時に発生します;パラメータ検証失敗（4xx）の場合は課金されません。
- 生成には約 4～6 分かかります（2 ステップ）ので、`async=true` + `/kling/tasks` のポーリングを推奨します。
