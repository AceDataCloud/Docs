`POST /kling/goods-studio` を通じてタスクを送信し、既存の `POST /kling/tasks` を使用してプラットフォームのタスク状態を照会します。

## 入力

1～5 枚の商品画像と最大 200 文字の商品タイトルを提供します。商品説明は任意で、最大 2000 文字です。時間は任意で、15、30、または 60 秒です。

以下はリクエスト構造の例です。素材 URL を置き換えてから呼び出してください。

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "あなたの商品またはナレーション内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## 結果と課金

同期モードでは生成結果を返します。非同期モードではまず `task_id` を返し、完了結果には `data` 内の動画または画像リンクと、サーバー側で算出された `usage` が含まれます。`callback_url` は完了通知に使用されます。`watermark=true` リクエストでは、ウォーターマーク付きバージョンも同時に返されます。

720p：2.38 Credits/秒；1080p：2.8 Credits/秒。動画は実際の生成時間に基づいて精算され、生成前の秒あたりの基本価格はタスク全体の総額を示すものではありません。失敗したタスクには生成料金は請求されません。
