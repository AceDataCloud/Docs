`POST /kling/apparel` を通じてタスクを送信し、既存の `POST /kling/tasks` を使用してプラットフォームのタスク状態を照会します。

## 入力

最大 2500 文字の商品説明、5～180 秒の参考動画、および 1～5 枚の商品画像を提供します。追加で 1～5 枚のモデル画像、背景音楽ファイル、および指定のナレーション音声を提供できます。音声を指定しない場合は、ネイティブ音声ナレーションを使用します。

以下はリクエスト構造の例です。素材 URL を置き換えてから呼び出してください。

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "あなたの商品またはナレーション内容"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## 結果と課金

同期モードでは生成結果を返します。非同期モードではまず `task_id` を返し、完了結果には `data` 内の動画または画像リンク、およびサーバー側で計算された `usage` が含まれます。`callback_url` は完了通知に使用されます。`watermark=true` リクエストでは、透かし入りバージョンも同時に返されます。

ネイティブ音声ナレーション：720p は 1.82 Credits/秒、1080p は 2.38 Credits/秒です。指定ナレーション：720p は 2.38 Credits/秒、1080p は 2.8 Credits/秒です。動画は実際の生成時間に基づいて精算され、生成前の秒あたりの基本価格はタスク全体の総価格を表すものではありません。失敗したタスクには生成料金はかかりません。
