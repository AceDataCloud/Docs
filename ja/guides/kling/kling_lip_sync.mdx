既存の**可灵動画**（5秒または10秒）を音声またはテキストで「口を開けて話す」ようにする——すなわち対口型（Lip Sync）。`/kling/videos`の`image2video`（写真を動かす）と組み合わせることで、完全な「**話す写真 / デジタル人口播**」のプロセスを構成できます。

> 本インターフェースはAceDataCloudが提供する単一ステップの便利なラッパーで、一般的な音声/テキスト駆動のシナリオを対象としています；これはKling公式の「顔認識 → Advanced Lip Sync」の多段階インターフェースのフィールドミラーではありません。本ページのパラメータ表を基準としてください。

- **インターフェースアドレス**：`POST https://api.acedata.cloud/kling/lip-sync`
- **リクエスト形式**：`application/json`
- **レスポンス形式**：`application/json`
- **課金**：成功した呼び出しごとに**2.45クレジット**（固定）

## リクエストヘッダー（Request Headers）

| フィールド              | 値                   | 説明                                               |
| --------------- | ------------------- | ------------------------------------------------ |
| `authorization` | `Bearer ${API_KEY}` | あなたのAPIキー、[取得先](https://platform.acedata.cloud) |
| `content-type`  | `application/json`  | リクエストボディの形式                                            |
| `accept`        | `application/json`  | レスポンス形式                                             |

## リクエストパラメータ（Request Body）

| パラメータ               | タイプ      | 必須  | デフォルト      | 説明                                                                                                                       |
| ---------------- | ------- | --- | ------- | ------------------------------------------------------------------------------------------------------------------------ |
| `mode`           | string  | はい   | —       | 生成モード。列挙：`audio2video`（音声駆動）、`text2video`（テキスト駆動）                                                                           |
| `video_id`       | string  | 二者択一 | —       | 可灵生成動画のID（例：`/kling/videos`のimage2videoが返す`video_id`）。**30日以内に生成された5s/10s動画のみサポート**。`video_id`と`video_url`は二者択一で、同時に送信不可 |
| `video_url`      | string  | 二者択一 | —       | 公開アクセス可能な動画リンク。制約：`.mp4`/`.mov`、≤100MB、長さ2–10s、720p/1080pのみ、辺の長さ720–1920px。`video_id`と二者択一                                  |
| `audio_url`      | string  | 条件  | —       | 駆動音声のダウンロードURL、`audio2video` + `audio_type=url`の時必須。形式`.mp3`/`.wav`/`.m4a`/`.aac`、≤5MB                                     |
| `audio_type`     | string  | いいえ   | `url`   | 音声伝送方式。列挙：`url`、`file`（`audio2video`の時有効）                                                                                |
| `audio_file`     | string  | 条件  | —       | 音声ファイルのBase64、`audio_type=file`の時必須。形式は同上、≤5MB                                                                             |
| `text`           | string  | 条件  | —       | 読み上げるテキスト、`text2video`の時必須、**最大120字**                                                                                     |
| `voice_id`       | string  | 条件  | —       | 音色ID、`text2video`の時必須                                                                                                   |
| `voice_language` | string  | いいえ   | `zh`    | 音色言語。列挙：`zh`、`en`（`text2video`の時有効）                                                                                      |
| `voice_speed`    | float   | いいえ   | `1.0`   | 語速、範囲`0.8`–`2.0`、小数点以下1桁まで（`text2video`の時有効）                                                                              |
| `callback_url`   | string  | いいえ   | —       | コールバックアドレス。この項目または`async=true`を渡すと**非同期モード**：即座に`task_id`を返し、結果生成後にコールバック                                                                 |
| `async`          | boolean | いいえ   | `false` | 非同期かどうか。`true`の時即座に`task_id`を返し、`/kling/tasks`でポーリングするか、`callback_url`でコールバック                                                      |

## リクエスト例

### 1）音声駆動（audio2video）

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2）テキスト駆動（text2video）

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "兄さん、お久しぶりです。私は元気です。あなたも自分を大切にしてください。",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## レスポンス例（同期成功）

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| フィールド          | タイプ      | 説明                                         |
| ----------- | ------- | ------------------------------------------ |
| `success`   | boolean | 成功したかどうか                                       |
| `task_id`   | string  | 今回のタスクID（`/kling/tasks`での照会に使用可能）             |
| `video_id`  | string  | 生成された動画の可灵 ID（次回の`extend`/`lip-sync`の入力として使用可能） |
| `video_url` | string  | 生成された話す動画のURL（本プラットフォームCDNに保存済み、長期有効）              |
| `duration`  | string  | 動画の長さ（秒）                                    |
| `state`     | string  | タスクの状態：`succeed` / `failed`                  |

## 非同期モードと照会

`callback_url`または`async: true`を渡すと、インターフェースは**即座に**`task_id`を返します；その後は：

- **ポーリング**：`POST /kling/tasks`、ボディ`{ "action": "retrieve", "id": "<task_id>" }`（無料）
- **コールバック**：生成が完了した後、結果があなたの`callback_url`にPOSTされます

## 完全なプロセス：話す写真（image2video → lip-sync）
```bash
# 第 1 步：写真を動かして、video_idを取得
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"カメラを見て、自然に","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# 第 2 步：音声に合わせて口を動かす
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"}'
# → { "video_url": "https://platform2.cdn.acedata.cloud/kling/....mp4", ... }
```

## エラーレスポンス

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "video_idまたはvideo_urlのいずれかが必要です" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | コード                    | 意味                                                 |
| ---- | ----------------------- | -------------------------------------------------- |
| 400  | `bad_request`           | パラメータが欠落または不正（modeが未指定、videoとaudioの選択が衝突、textが120字を超えるなど） |
| 401  | `authorization_missing` | 無効または欠落したAPIキー                                      |
| 403  | `forbidden`             | コンテンツが風控によりブロックされた                                            |
| 429  | `too_many_requests`     | 上流の同時接続制限、後で再試行してください                                       |
| 500  | `api_error`             | 上流または内部エラー                                            |

## 注意事項

- `video_id`は**30日以内**に生成された可動動画で、**5秒または10秒**でなければなりません。そうでない場合は、`video_url`を使用して制約に合った動画を提供してください。
- 入力動画は**鮮明な正面、1人**を推奨し、口型効果が最適です。
- 音声/テキストの長さは動画の長さと一致する必要があります（音声は動画の長さを超えないこと）。
- 課金は**成功時**に発生します（2.45クレジット/回）；パラメータ検証失敗（4xx）は課金されません。
