Gemini Tasks API の主な機能は、Gemini Videos Generation API で生成されたタスク ID を入力して、そのタスクの実行状況を照会することです。

本ドキュメントでは、Gemini Tasks API の連携手順を詳しく説明し、Gemini Videos Generation API のタスク実行状況を簡単に統合・照会できるようサポートします。

## 申請手順

Gemini Tasks API を使用するには、まず申請ページ [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos) で該当サービスを申請し、Gemini Videos Generation API が返すタスク ID をコピーしてください。

その後、[Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) ページにアクセスして該当サービスを申請します。ページに入ったら、「Acquire」ボタンをクリックしてください。

ログインまたは登録していない場合は、自動的に[ログインページ](https://platform.acedata.cloud)へリダイレクトされ、登録・ログインを促されます。ログイン・登録後は自動的に元のページに戻ります。

初回申請時には無料枠が付与され、この API を無料で利用可能です。

## リクエスト例

Gemini Tasks API は Gemini Videos Generation API の結果照会に利用できます。

### リクエストヘッダーとリクエストボディの設定

**Request Headers** は以下を含みます：

- `accept`：JSON形式のレスポンスを受け取るために `application/json` を指定します。
- `authorization`：API 呼び出しのためのキーで、申請後にプルダウンから選択可能です。

**Request Body** は以下を含みます：

- `id`：照会したいタスク ID。
- `action`：タスクに対する操作方法。単一照会の場合は `retrieve` を指定します。

### CURL コード例

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### レスポンス例

リクエスト成功時、API は該当タスクの詳細情報を返します。`request` フィールドはタスク開始時のリクエストボディ、`response` フィールドはタスク完了後のレスポンスボディです。例：

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
        "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

フィールドの説明は以下の通りです：

- `id`：生成タスクの ID。該当生成タスクを一意に識別します。
- `request`：照会対象タスクのリクエスト情報。
- `response`：照会対象タスクのレスポンス情報。

## 複数タスク一括照会操作

複数のタスク ID でタスク詳細を照会する場合、`action` を `retrieve_batch` に設定し、`ids` にタスク ID の配列を渡します。

**Request Body** は以下を含みます：

- `ids`：照会したいタスク ID の配列。
- `action`：タスク操作方法。複数照会の場合は `retrieve_batch` を指定します。

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
