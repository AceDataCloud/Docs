本文では、Gemini Videos Generation API の接続説明を紹介します。これは、テキストプロンプト（およびオプションの参考画像）を入力することで、Google Gemini（omni-flash）動画を生成することができます。

## 申請プロセス

Gemini Videos Generation API を使用するには、まず [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications) にアクセスして、API トークンを取得し、保管してください。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

まだログインまたは登録していない場合は、自動的にログインページにリダイレクトされ、登録とログインを促されます。完了後、現在のページに自動的に戻ります。

**1つの API トークンでプラットフォームのすべてのサービスを呼び出すことができ、各サービスごとに個別に申請する必要はありません。** 初回申請時には無料枠が付与され、無料で体験できます。枠が不足した場合は、[コンソール](https://platform.acedata.cloud/console/coin) で共通残高をチャージできます。

> 📘 完全なドキュメント：[Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## 基本使用

まず、基本的な使用方法を理解します。プロンプト `prompt`、モデル `model`、およびアスペクト比 `aspect_ratio` を入力することで、対応する動画を生成できます。

ここでは、リクエストヘッダーを設定しています。これには以下が含まれます：

- `accept`：受け取りたいレスポンスの形式。ここでは `application/json`、つまり JSON 形式を指定します。
- `authorization`：API を呼び出すためのキー。申請後、直接ドロップダウンから選択できます。

さらに、リクエストボディを設定しています。これには以下が含まれます：

- `prompt`：生成したい動画内容を説明するテキストプロンプト、**必須**。
- `model`：動画を生成するモデル。現在は `omni-flash` のみをサポートし、デフォルトは `omni-flash` です。
- `aspect_ratio`：生成する動画のアスペクト比。オプションで `16:9`（横向き）または `9:16`（縦向き）を選択でき、デフォルトは `16:9` です。
- `resolution`：オプションの出力解像度。オプションで `720p` または `1080p` を選択でき、デフォルトは `720p` です。
- `image_urls`：動画生成を導くためのオプションの参考画像リンクの配列。空の項目は無視されます。`video_urls` を使用して動画編集を行う場合、このパラメータは必須です（少なくとも1枚）。
- `video_urls`：オプションの参考動画リンクの配列（最大1つ）。**動画編集 / 動画参考**に使用されます。提供する場合は、少なくとも1枚の `image_urls` を同時に提供する必要があります。
- `callback_url`：非同期コールバックアドレス。設定後、API はすぐに `task_id` を返し、タスクが完了した際に結果をそのアドレスに POST します。
- `async`：オプション。`true` に設定すると、インターフェースはすぐに `task_id` を返し、`callback_url` を提供する必要はありません。その後、対応するタスククエリインターフェースを使用して結果をポーリングで取得します。

「Try」ボタンをクリックするとテストが行え、得られる結果は以下のようになります：

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://platform2.cdn.acedata.cloud/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden"
    }
  ],
  "started_at": 1784112953.856,
  "finished_at": 1784113021.328,
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

返された結果には複数のフィールドがあり、以下のように説明されます：

- `success`：今回の動画生成リクエストが成功したかどうか。
- `task_id`：今回の動画生成タスクの ID。
- `trace_id`：今回のリクエストのトレース ID。問題を調査するために使用されます。
- `data`：生成された動画結果のリスト。
  - `id`：生成された動画のユニークな識別子。
  - `video_url`：生成された動画のリンクアドレス（`state` が `pending` の場合は `null`）。
  - `state`：動画生成タスクの状態。選択肢は `pending` / `succeeded` / `failed`。
  - `aspect_ratio`：その動画のアスペクト比。リクエストパラメータと一致します。
  - `prompt`：その動画を生成するために使用されたプロンプト。

同期で返される場合、最上位には `started_at`、`finished_at`、`elapsed`（経過時間、秒）および `cost`（今回の課金、単位はクレジット）などのフィールドも付随します。

私たちは、結果の `data` の `video_url` リンクアドレスに基づいて生成された動画を取得するだけです。

対応する CURL コードは以下の通りです：

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

対応する Python コードは以下の通りです：

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 画像から動画生成

参考画像に基づいて動画を生成したい場合は、`image_urls` に1つ以上の画像リンクを渡して、動画生成を導くことができます：

```json
{
  "prompt": "The woman slowly turns around and smiles at the camera, gentle breeze",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3.png"
  ]
}
```

## 動画編集 / 参考動画（入力動画、生成動画）

「入力した動画から新しい動画を生成する」ことを直接サポートしています：`video_urls` に参考動画リンク（最大1つ）を渡し、**同時に** `image_urls` に少なくとも1枚の参考画像を提供し（上流の厳格な要件）、`prompt` で希望する編集効果（スタイル変更、シーン変更、要素の追加・削除など）を説明します。

以下は、実際の完全な例です——陽光のビーチの動画を大雪の冬のシーンに変更し、ビーチ、ヤシの木、小舟のレイアウトを保持します。動画編集には時間がかかるため（この例では約6.5分）、`async: true` で非同期に提出します：
```json
{
  "prompt": "この晴れたトロピカルビーチを、重い雪が降り、曇り空の雪の冬のシーンに変えてください。同じビーチ、ヤシの木、ボートのレイアウトを維持してください。",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://platform2.cdn.acedata.cloud/seedance/dd3dc063-3383-4f29-bedc-e771a096758c.mp4"
  ],
  "async": true
}
```

提出後、インターフェースはすぐに `task_id` を返します：

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

その後、`task_id` を `id` として使用して [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) をポーリングし、タスクが完了したら生成された新しいビデオを取得できます（これはこの例の実際の返結果です）：

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://platform2.cdn.acedata.cloud/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "この晴れたトロピカルビーチを、重い雪が降り、曇り空の雪の冬のシーンに変えてください。同じビーチ、ヤシの木、ボートのレイアウトを維持してください。"
    }
  ],
  "started_at": 1784084482.914,
  "finished_at": 1784084877.09,
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

より高解像度の結果が必要な場合は、`resolution` を `1080p` に設定できます（他のパラメータはそのまま）。

> ヒント：例の入力/出力メディアリンクはすべて実際の生成結果です。**プラットフォームが生成したビデオ、画像リンクには保存期限があり、期限切れ後は無効になります**。結果を受け取ったら、すぐにダウンロードして自分のストレージに保存してください。

> 注意：参考ビデオは最大1つまで；また、`video_urls` を提供する場合は、少なくとも1つの `image_urls` を提供する必要があります。そうしないと、次のようなパラメータエラーが返されます：

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (at least one reference image) is required when video_urls is provided."
  }
}
```

## 非同期コールバック

ビデオ生成には一定の処理時間が必要です。長時間接続を維持したくない場合は、`callback_url` を渡すことができます。この場合、APIはすぐに `task_id` を返し、タスクが完了したら最終結果をそのアドレスにPOSTします：

```json
{
  "prompt": "日差しの中の庭で蝶を追いかける子猫のシネマティックショット",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

すぐに返される結果は次のとおりです：

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## タスク結果の確認

非同期コールバックを使用した場合や、タスクの状態を手動で確認したい場合は、[Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks)（`POST https://api.acedata.cloud/gemini/tasks`）を使用して、`task_id` に基づいてタスクの最新の状態と結果を確認できます。リクエストボディには、ビデオ作成時に返された `task_id` を `id` として渡します：

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

タスクが完了した後に返される結果は次のようになります。`response.data` の構造は同期生成時と一致します（生成中は `state` が `pending`、`video_url` が `null` です）：

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
  "type": "videos",
  "request": {
    "model": "omni-flash",
    "prompt": "日の出時の雪山の上の雲のタイムラプス",
    "aspect_ratio": "16:9",
    "async": true
  },
  "response": {
    "success": true,
    "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
    "data": [
      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
        "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4",
        "state": "succeeded",
        "aspect_ratio": "16:9",
        "prompt": "日の出時の雪山の上の雲のタイムラプス"
      }
    ],
    "elapsed": 96.716,
    "cost": {
      "amount": 1.932,
      "currency": "credit",
      "list_amount": 2.1
    }
  }
}
```

## エラーハンドリング

リクエストに問題が発生した場合、APIは対応するエラーコードと説明を返します。一般的なものは次のとおりです：

- `400`：リクエストパラメータに誤りがある（例：`prompt` または `aspect_ratio` が不足している、または無効な値）。
- `401`：認証失敗、トークンが無効またはAPIと一致しない。
- `403`：残高不足、またはプロンプトがコンテンツ審査に引っかかって拒否された。
- `500`：サーバー内部エラーまたは上流生成失敗。
