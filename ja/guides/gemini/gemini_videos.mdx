本稿では Gemini Videos Generation API の接続方法について説明します。本APIはテキストプロンプト（および任意の参考画像）を入力することで、Google Gemini（omni-flash）動画を生成できます。

## 申請手順

APIを利用するには、まず [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos) の該当ページでサービスを申請してください。ページにアクセスしたら、「Acquire」ボタンをクリックします。以下の図のように表示されます：

![](https://cdn.acedata.cloud/q6ytrc.png)

ログインまたは登録していない場合は、自動的にログインページに遷移し、登録およびログインを促されます。ログイン後は自動的に元のページに戻ります。

初回申請時には無料枠が付与され、このAPIを無料で利用可能です。

## 基本的な使い方

まず基本的な使い方を理解しましょう。プロンプト `prompt`、モデル `model`、アスペクト比 `aspect_ratio` を入力することで、対応する動画を生成できます。

ここではリクエストヘッダーを設定しています。内容は以下の通りです：

- `accept`：受け取りたいレスポンス形式。ここでは `application/json`（JSON形式）を指定。
- `authorization`：API呼び出し用のキー。申請後にプルダウンから選択可能。

また、リクエストボディには以下を設定します：

- `prompt`：生成したい動画内容を表すテキストプロンプト。**必須**。
- `model`：動画生成モデル。現在は `omni-flash` のみ対応。デフォルトは `omni-flash`。
- `aspect_ratio`：動画のアスペクト比。`16:9`（横長）または `9:16`（縦長）から選択可能。デフォルトは `16:9`。
- `image_urls`：任意の参考画像（または動画）URLの配列。動画生成の誘導に使用。空の項目は無視されます。
- `callback_url`：非同期コールバックURL。設定するとAPIは即座に `task_id` を返し、処理完了後に結果をPOSTします。

「Try」ボタンを押すとテストが可能で、以下のような結果が返ります：

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

返却されるフィールドは以下の通りです：

- `success`：動画生成リクエストが成功したかどうか。
- `task_id`：動画生成タスクのID。
- `trace_id`：リクエストのトレースID。問題解析に利用。
- `data`：生成された動画の結果リスト。
  - `id`：生成動画の一意識別子。
  - `video_url`：生成動画のURL。
  - `state`：動画生成タスクの状態。`pending` / `succeeded` / `failed` のいずれか。

結果の `data` 内の `video_url` を利用して生成動画を取得してください。

対応するCURLコードは以下の通りです：

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

対応するPythonコードは以下の通りです：

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 画像から動画生成

参考画像を基に動画を生成したい場合は、`image_urls` に1つ以上の画像URLを渡して動画生成の誘導に利用できます：

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## 非同期コールバック

動画生成には一定の処理時間がかかります。長時間接続を維持したくない場合は `callback_url` を指定してください。この場合、APIは即座に `task_id` を返し、処理完了後に結果を指定URLへPOSTします：

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

即時返却される結果は以下の通りです：

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## タスク結果の照会

非同期コールバックを利用した場合や、タスク状態を能動的に確認したい場合は、[Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks)（`POST https://api.acedata.cloud/gemini/tasks`）を使い、`task_id` から最新の状態と結果を照会できます。

## エラー処理

リクエストに問題がある場合、APIは対応するエラーコードと説明を返します。主なものは以下の通りです：

- `400`：リクエストパラメータの誤り。例：`prompt`の欠如や`aspect_ratio`の不正な値。
- `401`：認証失敗。トークンが無効かAPIと一致しない。
- `403`：残高不足、またはプロンプトがコンテンツ審査で拒否された場合。
- `500`：サーバ内部エラーまたは上流生成失敗。
