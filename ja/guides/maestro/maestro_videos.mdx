Maestro は **Agent ネイティブ**の動画制作インターフェースです：自然言語の `prompt` で作りたい動画を一文で説明し（任意で `file_urls` を使って参考画像 / 動画 / 音声を添付）、ヘッドレスの「AI ディレクター」が自動的に企画選定、台本作成、映像生成、ナレーション、BGM、合成とレンダリングを完了し、最終的に字幕付きの完成動画を生成して CDN にアップロードします。

本記事では、Maestro 動画生成 API の連携ガイドを詳しく紹介し、迅速に統合してこの API の能力を十分に活用できるよう支援します。

これは**非同期タスク**インターフェースです：送信後すぐに `task_id` が返され、その後 [Maestro タスク照会 API](/ja/guides/maestro/maestro_tasks)（`POST /maestro/tasks`）を通じて結果をポーリング取得します（ポーリングは無料で課金されません）。既存の動画をもとに引き続きイテレーションするには、`action: remix` / `edit` / `extend` と `ref_task_id` を組み合わせて使用できます。

## 申請手順

Maestro 動画生成 API を使用するには、まず [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications)で API Token を取得し、控えておいてください。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

まだログインまたは登録していない場合は、自動的にログインページへ移動して登録とログインを促され、完了後に現在のページへ自動的に戻ります。

**1 つの API Token でプラットフォーム上のすべてのサービスを呼び出せるため、サービスごとに個別申請する必要はありません。** 初回申請時には無料クレジットが付与され、無料で体験できます。クレジットが不足した場合は、[コンソール](https://platform.acedata.cloud/console/coin)で共通残高をチャージできます。

> 📘 完全なドキュメント：[Maestro 動画生成 API →](https://platform.acedata.cloud/documents/maestro-videos)

## 基本的な使用方法

`POST https://api.acedata.cloud/maestro/videos`

最も基本的な使い方では、自然言語の `prompt` を 1 つ渡すだけで、AI ディレクターが台本、映像、ナレーション、編集を自動的に決定します。ここでは、設定が必要なリクエストヘッダーとリクエストボディについて確認します。

**Request Headers** には以下が含まれます：

- `accept`：受け取りたいレスポンス結果の形式です。ここでは `application/json`、つまり JSON 形式を指定します。
- `authorization`：API を呼び出すためのキーです。申請後に直接ドロップダウンから選択できます。
- `content-type`：リクエストボディの形式です。ここでは `application/json` を指定します。

**Request Body** には主に以下が含まれます：

- `prompt`：作成したい動画を自然言語で説明します（テーマ、表示するもの、スタイル、対象者）。
- `langs`：完成動画の言語配列です。毎回 1 種類のみ渡します。例：`["zh-cn"]`、デフォルトは `["zh-cn"]`。
- `aspect`：画面比率です。`9:16`（デフォルト）/ `16:9` / `1:1`。
- `duration`：目標時間（秒）です。デフォルトは 30。

リクエストボディのすべてのフィールドは以下の表のとおりです：

| フィールド            | 型       | 必須  | 説明                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | はい   | 作成したい動画を自然言語で説明します（テーマ、表示するもの、スタイル、対象者）。台本、映像、ナレーション、編集はすべて AI が決定します                                                                                                                                                                             |
| `action`      | string   | いいえ   | `generate`（デフォルト、新規動画を生成）/ `remix` / `edit` / `extend`（既存動画上でイテレーション、`ref_task_id` と組み合わせて使用する必要があります）                                                                                                                                                |
| `ref_task_id` | string   | いいえ   | `action` が remix / edit / extend の場合は必須：起点となる過去タスクの `task_id`                                                                                                                                                                   |
| `file_urls`   | string[] | いいえ   | 参考メディア（画像 / 動画 / 音声 URL）。例：登場させる商品画像、logo、または字幕を追加する素材クリップ                                                                                                                                                                             |
| `langs`       | string[] | いいえ   | 完成動画の言語。毎回 1 種類のみ渡せます。例：`["zh-cn"]`、デフォルトは `["zh-cn"]`                                                                                                                                                                                    |
| `aspect`      | string   | いいえ   | `9:16`（デフォルト）/ `16:9` / `1:1`、出力はすべて 1080p/30fps                                                                                                                                                                                  |
| `duration`    | int      | いいえ   | 目標時間（秒）。デフォルトは 30、**5～300 秒**に対応。実際の完成動画時間に基づいて課金されますが、リクエスト時間を超えることはありません                                                                                                                                                                             |
| `scenario`    | string   | いいえ   | 動画タイプ：`auto` / `narrated` / `captions` / `avatar` / `drama`。`captions` では元動画の指定が必要で、`avatar` では人物画像の指定が必要です                                                                                                                                    |
| `style`       | string   | いいえ   | ビジュアルスタイルのプリセット：`auto`（デフォルト）/ `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`。ソフトヒントとして自由テキストも受け付けます。`scenario` とは直交しており、ルーティングを変更しません |
| `voice`       | string   | いいえ   | ナレーション音声（言語に依存せず、言語間で共通）：`auto`（デフォルト）/ `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`                                    |

以下では、具体例を通じて説明します。中国語、縦画面、20 秒の科学解説ショート動画を生成すると仮定した場合、対応する CURL コードは以下のとおりです：

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

対応する Python コードは以下のとおりです：

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

実行をクリックすると、以下のような結果がすぐに取得できることがわかります：

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

返却結果のフィールド説明は以下のとおりです：
- `success`：今回のタスクが正常に送信されたかどうか。
- `task_id`：今回の動画生成タスクの ID。後続で [Maestro タスク照会 API](/ja/guides/maestro/maestro_tasks) を使用して結果をポーリングします。
- `trace_id`：今回のリクエストの追跡 ID。問題が発生した場合は、技術サポートに提供して調査できます。

動画生成には比較的長い時間がかかるため、インターフェースはここで**直ちに `task_id` を返却**し、動画レンダリングの完了は待ちません。続いて `task_id` を使用して結果をポーリングする必要があります。詳細は「結果の取得」セクションを参照してください。

## 動画タイプとスタイルの指定（scenario / style）

`scenario` を渡さない場合は AI が自動で判断します（`auto` と同等）。動画を特定のタイプに固定したい場合は明示的に渡します。たとえば、**縦型ショートドラマ**を作成する場合は、以下の内容を指定できます。

- `scenario`：動画タイプ。ここでは `drama`（キャラクター + セリフのショートドラマ）に設定します。
- `style`：ビジュアルスタイル。ここでは `cinematic`（映画のような質感）に設定します。

記入例の CURL コードは以下のとおりです。

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

一般的な組み合わせ方法：

- 解説ショート動画：`scenario: "narrated"`。
- 自動字幕：`scenario: "captions"`。`file_urls` を使用して元動画を渡す必要があります。
- デジタルヒューマン / 話し動画：`scenario: "avatar"`。`file_urls` を使用して人物画像を 1 枚渡す必要があります。
- ショートドラマ：`scenario: "drama"`（キャラクター + セリフ）。
- `style` はビジュアルスタイルのプリセットです（例：`modern` / `neon` / `luxury`）。タイプは変更せず、見た目の印象のみを変えます。
- `voice` はナレーションの音色を指定するために使用します（例：`warm-female` / `deep-male`）。言語とは無関係で、言語をまたいで共通利用できます。

返却結果は「基本的な使用方法」と同様で、同じく直ちに `task_id` が返却されます。

## 完成動画の言語

1 つのタスクでは、1 つの言語による 1 本の完成動画のみが納品されます。`langs` には `["zh-cn"]` または `["en"]` のように、1 つの言語コードのみを含めることができます。複数の言語を渡すと 400 が返されます。異なる言語の動画が必要な場合は、それぞれタスクを作成してください。言語の選択によって秒単価は変わりません。

## 既存動画をベースにした反復（remix / edit / extend）

`action` と前回のタスクの `ref_task_id` を渡すことで、元のプロジェクトをベースに差分修正を行えます（例：「第 2 幕のタイトルを変更する」「音声を変更する」「全体を暗くする」）。小さな変更は速く、大きな変更は作り直しになります。

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`：元動画の構成をベースに再演出します（テーマを維持し、表現を調整します）。
- `edit`：指定した部分を細かく編集します（例：タイトル変更、音声変更、カラー調整）。
- `extend`：元動画をベースにコンテンツを拡張します。

返却結果も同様に、新しい `task_id` が直ちに返却されます。これをポーリングすれば、反復後の完成動画を取得できます。

## 結果の取得

動画生成には比較的長い時間がかかるため、本インターフェースは送信後に直ちに `task_id` を返却します。これを使用して [Maestro タスク照会 API](/ja/guides/maestro/maestro_tasks) で結果をポーリングする必要があります。

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

タスクが完了すると、1 件の完成動画情報（`variants` 配列内）が返されます。`status` は `pending → planning → producing → succeeded`（または `failed`）と遷移します。**ポーリングは無料で、クレジットを消費しません**。完全なレスポンス形式と履歴一覧の照会については、[Maestro タスク照会 API 連携説明](/ja/guides/maestro/maestro_tasks) を参照してください。

## 課金

**タスクの成功後、実際に納品された完成動画の長さに応じて課金され、失敗時には課金されません。** 課金時間は整数秒単位で計算され、リクエストした時間を超えることはありません。完成動画の長さを読み取れない場合は、リクエスト時間にフォールバックします。タスクの送信自体には別途課金されず、`/maestro/tasks` のポーリングは無料です。

```
クレジット = 実際の課金秒数 × 0.7
```

すべてのシナリオ、アクション、言語は同一価格であり、シナリオ倍率や言語追加料金はありません。各タスクで納品されるのは、1 つの言語による 1 本の完成動画のみです。リクエストする目標時間は 5～300 秒に対応し、出力はすべて 1080p / 30fps です。

| 実際の課金時間              |  クレジット |
| ------------------- | --: |
| 30 秒                |  21 |
| 60 秒                |  42 |
| 120 秒               |  84 |
| 300 秒               | 210 |
| `/maestro/tasks` のポーリング |  無料 |

## エラー処理

API の呼び出し時にエラーが発生した場合、API は対応するエラーコードと情報を返します。例：

- `400 invalid_request`：不正なリクエスト。`prompt` の欠落または無効なパラメータが原因である可能性があります。
- `401 invalid_token`：認証されていません。認証トークンが無効または欠落しています。
- `403 forbidden`：アクセス禁止。残高またはアクセス権限が不足しています。
- `429 too_many_requests`：リクエストが多すぎます。レート制限を超過しています。
- `500 api_error`：内部サーバーエラー。サーバー側で問題が発生しました。

### エラーレスポンス例

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## まとめ

本ドキュメントを通じて、Maestro 動画生成 API の使用方法をご理解いただけたはずです。自然言語の `prompt` を 1 文入力するだけで、スクリプト、素材、音声、BGM、編集、字幕、完成動画のレンダリングまで自動的に完了できます。また、動画タイプ、スタイル、音色、完成動画の言語の指定、および既存動画をベースにした反復もサポートしています。本ドキュメントが、本 API のより良い連携と利用に役立つことを願っています。ご不明な点がございましたら、いつでも技術サポートチームまでお問い合わせください。
