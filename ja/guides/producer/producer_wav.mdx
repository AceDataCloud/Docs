---
title: "Producer WAV API ダウンロード接続説明"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer は私たちが曲に関連するWAVファイルをダウンロードすることを許可します。本ドキュメントでは関連するAPIの接続方法を説明します。

このAPIには1つの入力パラメータしかなく、それは `audio_id` です。これは曲の唯一のIDです。

ここで入力する `audio_id` は `a54609c6-13e2-4176-be0f-4d7eebc68e1f` で、Producerが生成した曲のIDです。

```bash
curl -X POST 'https://api.acedata.cloud/producer/wav' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

結果は以下の通りです：

```
{
  "success": true,
  "task_id": "44963173-b6c5-463c-915f-96730d14ec63",
  "trace_id": "f75d6a27-54bc-49fd-a40e-6d4cd0427764",
  "data": [
    {
      "title": "Woke up with the sun in my eyes",
      "file_url": "https://platform2.cdn.acedata.cloud/fish/64adc04b-c196-4a0f-9070-222ba101ce6c.wav"
    }
  ]
}
```

見ることができるように、`data` の `file_url` フィールドがダウンロードのWAVリンクです。
