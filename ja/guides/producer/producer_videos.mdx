---
title: "Producer ダウンロード動画 API 連携説明"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer は私たちが曲に関連する動画をダウンロードすることを許可します。本ドキュメントでは関連 API の連携方法を説明します。

この API には唯一の入力パラメータがあり、それは `audio_id` です。これは曲の唯一のIDです。

ここで入力する `audio_id` は `a54609c6-13e2-4176-be0f-4d7eebc68e1f` で、Producer が生成した曲のIDです。

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

結果は以下の通りです：

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4"
  }
}
```

見ることができるように、`data` の `video_url` フィールドがダウンロード動画のリンクです。
