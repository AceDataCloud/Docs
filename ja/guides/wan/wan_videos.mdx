`POST https://api.acedata.cloud/wan/videos` は、既存の Wan 2.6 モデルと `wan3.0-video` の両方をサポートしています。Wan 3 は `media` に基づいて自動的にテキスト、最初と最後のフレーム、または参照素材のパターンを認識します。

## Wan 3 文生動画

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "ネオンの街を漂う紙のボート",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 は 2–30 秒の整数または `-1` のインテリジェントな長さをサポートし、解像度は `480P`、`720P`、`1080P` です。

## マルチメディア参照

```json
{
  "model": "wan3.0-video",
  "prompt": "映画のような製品発表を作成する",
  "media": [
    {"type":"first_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"},
    {"type":"last_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` は以下をサポートします：

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

最初と最後のフレームのモードと参照素材のモードは混在できません。参照動画は最終的に実際の入力動画の秒数に成功した出力動画の秒数を加算して計算されます；テキスト、画像、音声の入力は動画の秒数を増加させません。

## 公式標準価格

| 解像度   |      価格 |
| ----- | ------: |
| 480P  | $0.05/秒 |
| 720P  | $0.10/秒 |
| 1080P | $0.20/秒 |

## Wan 2.6 互換性

既存の `wan2.6-t2v`、`wan2.6-i2v`、`wan2.6-r2v` と flash バリアントは引き続き `action`、`image_url`、`reference_video_urls` などのパラメータを使用し、呼び出しパスは変わりません。

## 非同期と結果

`async: true` を設定すると、すぐに `task_id` を取得し、`/wan/tasks` を通じて最終状態を取得します。成功した動画は AceDataCloud CDN に保存され、応答に実際の使用量とコストが返されます。
