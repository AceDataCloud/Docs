---
title: "Wan 任务查询 API"
description: "Wan API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/wan/tasks` は、Wan ビデオタスクを照会、バッチ照会、または削除するために使用されます。タスクの照会は生成費用を再度請求しません。

## 単一タスクの照会

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

完了したタスクの `response.data.video_url` は永久的な CDN アドレスです；`response.usage` には解像度、入力/出力ビデオの秒数、フレームレート、比率が含まれます；`response.cost` は生成タスクの決済です。

## バッチ照会

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

返されるのは `{ "items": [...], "count": 2 }` です。タスクが進行中の場合、`finished_at` と最終 `response` がまだない可能性があります。

## タスク記録の削除

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

削除はタスクの履歴記録にのみ影響し、生成された CDN ビデオは削除されません。
