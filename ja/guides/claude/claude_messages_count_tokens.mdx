Claude Messages Count Tokens API は、実際にメッセージを作成することなく、ツール、画像、ドキュメントなどのコンテンツの Token カウントを含む、1 つの Message の入力 Token 数を計算できます。これは、コストを見積もる必要がある場合や、入力がモデルのコンテキスト制限を超えていないか確認する際に非常に便利です。

本ドキュメントでは主に、Claude Messages Count Tokens API の使用手順を紹介します。

## 申請手順

Claude Messages Count Tokens API を使用するには、まず [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications) にアクセスして API Token を取得し、控えておいてください。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

まだログインまたは登録していない場合は、ログインページに自動的に遷移して登録とログインを促されます。完了後、自動的に現在のページに戻ります。

**1 つの API Token でプラットフォーム上のすべてのサービスを呼び出すことができ、サービスごとに個別で申請する必要はありません。** 初回申請時には無料クレジットが付与され、無料で試用できます。クレジットが不足した場合は、[コンソール](https://platform.acedata.cloud/console/coin) で共通残高をチャージできます。

> 📘 完全なドキュメント：[Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## 基本的な使用方法

Claude Messages Count Tokens API のリクエストパスは `/v1/messages/count_tokens` であり、Anthropic 公式 API と一致しています。少なくとも次の 2 つの必須パラメータを指定する必要があります。

- `model`：使用する Claude モデルを選択します。`claude-opus-5-5` は最新フラッグシップの `claude-fable-5-1` など、Messages Token Count に使用できます。旧 `claude-fable-5` も引き続き互換性を保って提供されています。
- `messages`：入力メッセージの配列で、各メッセージには `role`（役割）と `content`（内容）が含まれます。

よく使用されるオプションパラメータ：

- `system`：システムプロンプト。Token 数に含まれます。
- `tools`：ツール定義。Token 数に含まれます。
- `thinking`：拡張思考設定。
- `tool_choice`：ツール選択設定。
- `cache_control`：トップレベルまたはコンテンツブロックレベルのキャッシュ制御設定。

`messages`、`system`、ツール呼び出しの再生、URL 画像および document/PDF コンテンツブロックは、Messages API と同じ安定したリクエスト構造を使用します。

### cURL の例

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python の例

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

返却結果の例：

```json
{
  "input_tokens": 11
}
```

### Anthropic SDK を使用する

Claude Messages Count Tokens API は Anthropic SDK の安定したリクエスト構造を受け付け、`anthropic` ライブラリを介して呼び出すことができます。インターフェースは、選択したモデルに対応するネイティブの Count Tokens 機能を使用して入力をカウントし、Messages リクエストを送信する前に入力規模を確認するために使用できます。

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## ツールを含む Token カウント

リクエストにツール定義が含まれている場合、これらのツールも Token 数に含まれます。

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## システムプロンプトを含む Token カウント

システムプロンプトも Token 数に含まれます。

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## 注意事項

- この API は入力 Token 数のみを計算し、モデル出力は一切生成しません。
- Token カウント結果は入力規模の見積もりおよびコンテキストウィンドウの確認に使用できます。最終的な課金は、実際の Messages レスポンス内の `usage` に基づきます。
- 画像、PDF、ツール定義、システムプロンプトおよび thinking 設定は、選択したモデルの入力ルールに従って結果に含まれます。
- この API は完全無料で、いかなるクレジットも消費しません。
