---
title: "Suno カスタム歌手スタイル API 連携説明"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO では、生成済みの楽曲に歌手スタイルを設定し、それに基づいて二次創作を行うことができます。本ドキュメントでは、関連 API の連携方法について説明します。

`GET /suno/persona` によるリスト照会および `DELETE /suno/persona` によるレコード削除は課金対象外であり、追加の課金免除リクエストヘッダーは不要です。`POST /suno/persona` の作成操作は、引き続きインターフェースの料金規則に従って課金されます。

音色照会をサポートする作成経路では、元のアプリケーションおよび呼び出し元の ID を使用して、作成結果内の `persona_id` を `POST /suno/availability` に渡すことができます。利用可能であることを確認した場合、`data.available=true` が返されます。[音色利用可能性照会ガイド](https://platform.acedata.cloud/documents/suno-availability-integration)

この API には入力パラメーターが 3 つだけあります。まず `audio_id` は、公式で生成に成功した楽曲 ID です。次に `name`、`description` は、歌手スタイルに対する名称と説明です。

ここで入力する `audio_id` は `https://cdn.acedata.cloud/2qhzs3.png` です。これは [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) を参照してカスタム楽曲生成を行うことができ、最終的に `audio_id` を取得できます。

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

結果は以下のとおりです。

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

確認できるように、`data` の `persona_id` フィールドが生成後の歌手スタイル ID です。

歌手スタイル ID を取得した後、[Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) を使用してカスタム楽曲生成を行うことができます。例えば、`action` に `artist_consistency` を渡し、同時に `audio_id` にアップロードした楽曲 ID を渡し、さらに `persona_id` パラメーターをアップロードする必要があります。この値は上記で返された歌手スタイル ID であり、参照する歌手スタイルに基づいて新しい楽曲を生成できます。
