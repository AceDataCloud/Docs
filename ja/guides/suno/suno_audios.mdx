AI の活用が広がるにつれ、さまざまな AI プログラムが徐々に普及しています。AI は人々の仕事や生活のあらゆる側面に徐々に深く入り込んでいます。そして AI が関わる業界もますます増えており、当初の執筆から、医療・教育、そして現在の音楽にまで及んでいます。

Suno は、プロフェッショナルで高品質な AI 楽曲・音楽制作プラットフォームです。ユーザーは簡単なテキストプロンプトを入力するだけで、ジャンルスタイルと歌詞に基づき、ボーカル付きの楽曲を生成できます。この AI 音楽生成器は、Meta、TikTok、Kensho などの有名テクノロジー企業出身のチームメンバーによって開発されており、いかなる楽器ツールも必要とせず、誰もが素晴らしい音楽を創造できることを目指しています。

以下はモデル更新の進捗です：

| v6 Wild | chirp-v6-wild   | 2026.09.09 | —        | —        | —      |

> 上表の `lyric` と `style` の制限は、カスタムモード（`custom` が `true`）における上限です。非カスタムのインスピレーションモード（`custom` が `false`）では `prompt` のみを入力し、その長さの上限は 500 文字です（すべてのモデルで共通）。

Suno は現在、`chirp-v6`、`chirp-v6-wild`、および `chirp-v6-mini` をサポートしています。`chirp-v6` の使用を推奨します。旧モデル名も引き続き互換性があります。

しかし、Suno 公式は API を提供していません。AceDataCloud は Suno の API セットを提供しており、Suno 公式との連携をシミュレートし、必要な音楽を便利かつ迅速に生成できます。

## 申請と使用

Suno Audios Generation API を使用するには、まず [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications)で API Token を取得し、控えとして保管してください。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

まだログインまたは登録していない場合は、自動的にログインページへ移動して登録とログインを促され、完了後に自動的に現在のページへ戻ります。

**1 つの API Token でプラットフォーム上のすべてのサービスを呼び出すことができ、サービスごとに個別に申請する必要はありません。** 初回申請時には無料枠が付与され、無料で体験できます。枠が不足した場合は、[コンソール](https://platform.acedata.cloud/console/coin)で共通残高をチャージできます。

> 📘 完全なドキュメント：[Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## 基本的な使用方法

どのような楽曲を考えているか、任意のテキストを入力できます。たとえば、クリスマスに関する楽曲を生成したい場合は、`a song for Christmas` と入力できます。図のとおりです：

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

ここでは Request Headers を設定していることが分かります。内容は以下のとおりです：

- `accept`：どの形式のレスポンス結果を受け取りたいかを指定します。ここでは `application/json`、つまり JSON 形式を入力します。
- `authorization`：API を呼び出すためのキーです。申請後、直接プルダウンから選択できます。

さらに Request Body を設定します。内容は以下のとおりです：
- `action`：今回の音楽生成タスクのアクション。デフォルトは `generate` で、主に以下を含みます：`extend`、`upload_extend`、`cover`、`upload_cover`、`replace_section`、`replace_section`、`concat`、`stems`、`all_stems`、`remaster`。
- `prompt`：Suno 公式のインスピレーションモード用プロンプト（`custom` が `false` の場合に有効）。最大 500 文字。
- `model`：今回の音楽生成タスクのモデル。v6 シリーズには `chirp-v6`、`chirp-v6-wild`、`chirp-v6-mini` が含まれます。旧モデル名も引き続き互換性があります。
- `lyric`：Suno 公式のカスタムモードの歌詞内容。`chirp-v3-5` と `chirp-v4` は最大 3000 文字、`chirp-v4-5` 以降（`chirp-v5`、`chirp-v5-5` を含む）は最大 5000 文字。
- `custom`：カスタムモードを使用するかどうか。デフォルトは `false`。
- `instrumental`：Suno 公式のインスピレーションモードにおけるインストゥルメンタルオプション。
- `title`：Suno 公式のカスタムモードの楽曲タイトル。`chirp-v3-5`、`chirp-v4` は最大 80 文字、`chirp-v4-5` 以降は最大 100 文字。
- `style`：Suno 公式のカスタムモードの音楽スタイル。`chirp-v3-5` と `chirp-v4` は最大 200 文字、`chirp-v4-5` 以降（`chirp-v5`、`chirp-v5-5` を含む）は最大 1000 文字。
- `negative_tags`：カスタムモード（`custom` が `true`）で、生成結果から除外したい音楽スタイルまたはジャンル。
- `audio_weight`：アップロードした参照オーディオの比率。範囲は 0～1 で、値が大きいほど参照オーディオへの依存度が高くなります。
- `audio_id`：参照音楽の ID。
- `overpainting_start`/`overpainting_end`：既存のインストゥルメンタル楽曲にボーカルを追加する開始・終了時間。単位は秒。
- `underpainting_start`/`underpainting_end`：アカペラに伴奏を追加する開始・終了時間。単位は秒。
- `persona_id`：アーティストの楽曲 ID。
- `continue_at`：続きの生成境界。単位は秒。例えば、213.5 は 3 分 33.5 秒の地点から後続セグメントの生成を開始することを示します。`lyric` と `style` は境界以降の新しい内容のみを導き、元のオーディオ内における境界以前の歌詞や歌唱を置き換えることはありません。
- `style_influence`：カスタムモードにおける「Style Influence」高度パラメータ。範囲は 0～1 で、値が大きいほど選択したスタイルに近づきます。
- `replace_section_end`：置換するセグメントの終了時間。
- `replace_section_start`：置換するセグメントの開始時間。
- `vocal_gender`：男女の声の好みを制御します。女性の声は `f`、男性の声は `m`。4.5 以降のモデルで有効です。あくまで優先設定であり、厳密な遵守は保証されません。
- `weirdness`：カスタムモードにおける「Weirdness」高度パラメータ。範囲は 0～1 で、値が大きいほど創造性と実験性が高くなります。
- `duration`：希望する楽曲の長さ。単位は秒で、整数である必要があり、値の範囲は 10～360 です。このパラメータは、カスタムモード（`custom` が `true`）の楽曲生成に使用されます。これは厳密な制約ではなく傾向を示すプロンプトです。モデルはこれを参照しますが、到達することは保証されません。実際の完成曲の長さはレスポンス内の `duration` フィールドに従い、通常は希望値より短くなります。
- `lyric_prompt`：歌詞を生成するためのプロンプト。`custom` が `true` であり、かつ `lyric` が渡されていない場合にのみ有効です。
- `callback_url`：結果のコールバックが必要な URL。
- `async`：任意。`true` に設定した場合、インターフェースは直ちに `task_id` を返します。`callback_url` を指定する必要はなく、その後、対応するタスク照会インターフェースを通じてポーリングし、結果を取得します。

## カスタム生成

歌詞をカスタム生成したい場合は、歌詞を入力できます：

このとき、`lyric` フィールドには以下のような内容を渡すことができます：

```
[Verse]\nSnowflakes falling all around\nGlistening white\nCovering the ground\nChildren laughing\nFull of delight\nIn this winter wonderland tonight\nSanta's sleigh\nUp in the sky\nRudolph's nose shining bright\nOh my\nHear the jingle bells\nRinging so clear\nBringing joy and holiday cheer\n[Verse 2]\nRoasting chestnuts by the fire's glow\nChristmas lights\nThey twinkle and show\nFamilies gathering with love and cheer\nSpreading warmth to everyone near
```

> 注意：ここで歌詞内の `\n` は改行文字です。歌詞の生成方法がわからない場合は、AceDataCloud が提供する歌詞生成 API を使用して、prompt から歌詞を生成できます。API は [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics) です。

次に、歌詞、タイトル、スタイルに基づいて曲をカスタム生成するには、以下の内容を指定できます：

- lyric：歌詞テキスト
- custom：`true` を指定するとカスタム生成を表します。このパラメータのデフォルト値は false で、`prompt` を使用して生成することを表します。
- title：曲のタイトル。
- style：曲のスタイル。任意。

入力例は以下のとおりです：

<p><img src="https://cdn.acedata.cloud/qp3iba.png" width="500" className="m-auto" /></p>

入力後、自動生成されたコードは以下のとおりです：

```shell
curl -X POST 'https://api.acedata.cloud/suno/audios' \

-d '{
  "action": "generate",
  "prompt": "A song for Christmas",
  "model": "chirp-v4-5",
  "lyric": "[Verse]\\nSnowflakes falling all around\\nGlistening white\\nCovering the ground\\nChildren laughing\\nFull of delight\\nIn this winter wonderland tonight\\nSanta's sleigh\\nUp in the sky\\nRudolph's nose shining bright\\nOh my\\nHear the jingle bells\\nRinging so clear\\nBringing joy and holiday cheer\\n[Verse 2]\\nRoasting chestnuts by the fire's glow\\nChristmas lights\\nThey twinkle and show\\nFamilies gathering with love and cheer\\nSpreading warmth to everyone near",

```

## カスタム歌手スタイル生成機能
歌手スタイルを使用して楽曲を生成したい場合、まず上記の基本的な使用方法で楽曲を1曲生成します。  
最後に、この楽曲を歌手スタイルとして設定する必要があります。その後、[Suno Persona API](https://platform.acedata.cloud/documents/suno-persona) にアクセスし、公式が生成した音楽 ID `audio_id` に基づいて、歌手スタイルの id パラメータ `persona_id` を生成する必要があります。具体的なパラメータは下図のとおりです：

<p><img src="https://cdn.acedata.cloud/pmzo3l.png" width="500" className="m-auto" /></p>

入力完了後、自動生成されたコードは以下のとおりです：

<p><img src="https://cdn.acedata.cloud/a5g0nj.png" width="500" className="m-auto" /></p>

対応する Python コード：

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "name": "test"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 続きの生成機能

すでに生成された Suno 楽曲の続きを生成したい場合は、パラメータ `action` を `extend` に設定し、続きを生成する必要がある楽曲の ID を入力できます。楽曲 ID は基本的な使用方法に基づいて取得します。上記から、このとき楽曲の ID は以下であることが確認できます：

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> 注意：ここでの歌詞内の `id` は生成後の楽曲 ID です。楽曲の生成方法が分からない場合は、上記の基本的な使用方法を参照して楽曲を生成できます。

自分でアップロードした楽曲の続きを生成したい場合は、パラメータ `action` を `upload_extend` に設定し、続きを生成する必要があるカスタムアップロード済み楽曲の ID を入力できます。楽曲 ID は [Suno Upload Generation API](https://platform.acedata.cloud/documents/suno-upload) を使用して取得します。下図のとおりです：

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" className="m-auto" /></p>

次に、続きとして生成するセグメントの歌詞を必ず入力する必要があり、スタイルを指定することもできます：

- lyric：`continue_at` より後に新しく生成されるセグメントの歌詞を誘導するためだけに使用され、元の音声におけるその時点より前の歌詞は置き換えられません。
- custom：`true` を入力するとカスタム生成を表します。このパラメータのデフォルト値は false であり、`prompt` を使用して生成することを表します。
- style：続きとして生成するセグメントの楽曲スタイル。任意入力です。
- continue_at：続きの生成境界。単位は秒です。たとえば、213.5 は3分33.5秒の位置から後続セグメントの生成を開始することを表します。

> `extend` は既存の楽曲に続けて後方へ創作するためのものであり、楽曲全体の歌詞を変更するものではありません。楽曲全体を最初から新しい歌詞で作成したい場合は、`generate` を使用して再生成してください。既存の楽曲を参考にして再演奏したい場合は、`cover` を使用できます。新しい歌詞全体を渡した場合でも、`continue_at` より前の元の歌詞は置き換えられません。

## セクションの置換

楽曲生成後、楽曲セクションの置換を単独で行う二次創作が必要な場合、楽曲のあるセクションを置換できます。

> ⚠️ **注意**：`replace_section_result_mode` のデフォルトは `full_song` です：システムは新たに生成された 2 つの候補をそれぞれ結合し、2 曲の完全な楽曲を返します。まだ結合されていない置換セクション候補のみが必要な場合は、明示的に `candidates` に設定し、その後候補を選択して[音楽の結合](#音楽の結合)を呼び出してください。

パラメータの説明は以下のとおりです：

- action：内容は `replace_section` です。
- audio_id：元の楽曲（置換されるソース楽曲）の ID。
- model: 楽曲生成モデル。
- lyric: 置換後の完全な歌詞（置換されるセクションおよびその前後の文脈を含み、`prompt` の内容と一致させます）。
- prompt：置換するセクションの新しい歌詞。
- style：楽曲のスタイル、任意。
- replace_section_start：置換されるセクションの元の楽曲内での開始時間（秒）。
- replace_section_end：置換されるセクションの元の楽曲内での終了時間（秒）。
- replace_section_result_mode：返却モード、デフォルトは `full_song`。`full_song` は 2 つの候補をそれぞれ結合して 2 曲の完全な楽曲を返します。`candidates` は未結合の候補セクションを 2 つ返します。

## 楽曲の長さを制御する

デフォルトでは、生成される楽曲の長さはモデルによって自動的に決定され、通常は 30 秒から 4 分の間です。より長い、またはより短い完成品が必要な場合は、`duration` パラメータで希望する長さを指定できます。単位は秒で、値は 10 から 360 の間の整数です。

このパラメータは、カスタムモード（`custom` が `true`）の楽曲生成に使用されます。特に説明が必要なのは、`duration` は**傾向を示すヒントであり、厳密な制約ではない**ということです：モデルは作成時にこの値を参照しますが、到達することは保証されません。実測では実際の長さは通常、期待値より明らかに短く、同じリクエストで返される2曲の長さも数倍異なる場合があります。完全に同じリクエストであっても、複数回送信して得られる長さには大きな差が生じる可能性があります。そのため、これを正確な長さの制御として使用しないでください。業務上固定の長さが必要な場合は、完成品を取得後にご自身でトリミングするか、再試行してください。

対応する Python コード：

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "Under the City Lights",
    "style": "lo-fi piano",
    "lyric": "[Verse]\nSunrise creepin\nGold on the floor\n[Chorus]\nUnder the city lights\n",
    "duration": 330
}

```

注意すべき点として、リクエスト内の `duration` は**希望する長さ**であり、レスポンスの `data` 内にある各楽曲の `duration` フィールドはその楽曲の**実際の長さ**です。両者は同じ名称ですが意味が異なり、実際の長さが希望値と等しいことは保証されません。歌詞の長さは完成品の長さに影響する主な要因の1つであり、より長い完成品が必要な場合は、より完全な歌詞も同時に提供することを推奨します。

インターフェースは `duration` に対して追加の検証を行わず、パラメータはそのままモデルに渡されます。現在のモードまたはモデルでサポートされていない値を渡した場合、その値が無視されるように動作する可能性があります。まず1回のリクエストで効果を確認してから、一括で使用することを推奨します。

## Inspo インスピレーション創作機能

Inspo インスピレーション創作機能では、1～4本の完全な参照音声をもとに新しい音楽を生成でき、音声をドラッグ＆ドロップまたはアップロードしてインスピレーション源として使用できます。API では既存の `inspo` action を使用します。クライアントは公開アクセス可能な音声 URL を提供し、サービスが参照音声の準備と創作を自動的に完了するため、クライアント側で歌詞、スタイル、または長さをそれぞれ取得してリクエストを組み立てる必要はありません。これは上記の区間サンプリングとも、原曲のスタイルを再現する Cover とも異なります。使用時には、以下のパラメータを入力する必要があります。

- action：内容は `inspo`。
- audio_urls：参照音声の URL リスト。公開アクセス可能な音声アドレスを 1～4 件提供する必要があります。
- model：使用するモデル。`chirp-v6` を推奨します。
- prompt：歌詞または創作プロンプト（任意）。

> 注：参照音声は、公開アクセス可能な音声ファイルである必要があります。参照音声がプラットフォームの楽曲ライブラリ内にある既知の録音と完全に一致する場合、Suno は著作権チェックにより生成を拒否することがあります。自身で所有する音声、または Suno によって生成された音声をインスピレーション源として使用することを推奨します。

対応する Python コード：

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "inspo",
    "model": "chirp-v6",
    "audio_urls": [
        "https://cdn.acedata.cloud/uploads/a0bc051f-42c2-4a46-aeb4-582dcc884ad2"
    ],
    "prompt": "Rework these references as warm acoustic folk with soft vocals"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 非同期コールバック

Suno の音楽生成には比較的長い時間がかかり、約 1〜2 分を要します。API が長時間応答しない場合、HTTP リクエストは接続を維持し続け、追加のシステムリソースを消費するため、本 API では非同期コールバックもサポートしています。

全体のフローは次のとおりです。クライアントがリクエストを開始する際に、追加で `callback_url` フィールドを指定します。クライアントが API リクエストを開始した後、API は直ちに結果を返します。この結果には、現在のタスク ID を表す `task_id` フィールド情報が含まれます。タスクが完了すると、生成された音楽の結果は POST JSON の形式でクライアントが指定した `callback_url` に送信され、その中にも `task_id` フィールドが含まれるため、タスク結果を ID で関連付けることができます。

以下の例で、具体的な操作方法を確認します。
