AIの応用が広がるにつれて、さまざまなAIプログラムが徐々に普及しています。AIは人々の仕事や生活のあらゆる面に深く浸透しています。そして、AIが関与する業界もますます増えています。最初の執筆から、医療教育、そして現在の音楽へと進化しています。

Sunoは、専門的で高品質なAI歌曲および音楽創作プラットフォームで、ユーザーは簡単なテキストプロンプトを入力するだけで、ジャンルスタイルや歌詞に基づいてボーカル付きの曲を生成できます。このAI音楽生成器は、Meta、TikTok、Kenshoなどの著名なテクノロジー企業のチームメンバーによって開発されており、楽器やツールを必要とせず、誰でも素晴らしい音楽を創造できることを目指しています。

以下はモデル更新の進捗です：

| バージョン | model           | リリース日       | prompt 制限 | style 制限 | 曲の最長時間 |
| ----- | --------------- | ---------- | --------- | -------- | ------ |
| v5    | chirp-v5        | 2025.09.23 | 5000      | 1000     | 8 分   |
| v4.5+ | chirp-v4-5-plus | 2025.07.17 | 5000      | 1000     | 8 分   |
| v4.5  | chirp-v4-5      | 2025.05.03 | 5000      | 1000     | 4 分   |

Sunoは最新の音楽生成モデルをV5バージョンにアップグレードしました。最新のV5を呼び出すには、modelパラメータを`chirp-v5`に変更するだけで、9分の曲を生成できます。

しかし、Suno公式はAPIを提供していません。AceDataCloudはSunoのAPIを提供しており、Suno公式に接続を模倣して、希望する音楽を簡単かつ迅速に生成できます。

## 申請と使用

Suno Audios APIを使用するには、まず[Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios)ページにアクセスし、「Acquire」ボタンをクリックして、リクエストに必要な認証情報を取得します：

![](https://cdn.acedata.cloud/nyq0xz.png)

まだログインまたは登録していない場合は、自動的にログインページにリダイレクトされ、登録とログインを促されます。ログインまたは登録後、現在のページに自動的に戻ります。

初回申請時には無料のクレジットが付与され、このAPIを無料で使用できます。

## 基本使用

どのような曲を作りたいかを考え、任意のテキストを入力できます。例えば、クリスマスに関する曲を生成したい場合は、`a song for Christmas`と入力します。以下のように表示されます：

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

ここでは、Request Headersを設定しています。これには以下が含まれます：

- `accept`：受け取りたいレスポンス結果の形式。ここでは`application/json`、つまりJSON形式を指定します。
- `authorization`：APIを呼び出すためのキー。申請後、直接ドロップダウンから選択できます。

さらに、Request Bodyを設定しています。これには以下が含まれます：

- `action`：今回の音楽生成タスクの行動。デフォルトは`generate`で、主に`extend`、`upload_extend`、`cover`、`upload_cover`、`replace_section`、`concat`、`stems`、`all_stems`、`remaster`が含まれます。
- `prompt`：Suno公式のインスピレーションモードのプロンプト。
- `model`：今回の音楽生成タスクのモデル。デフォルトは`chirp-v3-5`で、主に`chirp-v3`、`chirp-v4`、`chirp-v3-5`、`chirp-v4-5`、`chirp-v4-5-plus`、`chirp-v5`が含まれます。
- `lyric`：Suno公式のカスタムモードの歌詞内容。
- `custom`：カスタムモードを使用するかどうか。デフォルトは`false`。
- `instrumental`：Suno公式のインスピレーションモードの純音楽オプション。
- `title`：Suno公式のカスタムモードの音楽タイトル。
- `style`：Suno公式のカスタムモードの音楽スタイル。
- `style_negative`：Suno公式のカスタムモードの除外スタイル。
- `audio_weight`：アップロードした参考音声の比率。範囲は0-1で、大きいほど参考音声に依存します。
- `audio_id`：参考音楽のID。
- `overpainting_start`/`overpainting_end`：既存の純音楽にボーカルを追加する開始・終了時間（秒単位）。
- `underpainting_start`/`underpainting_end`：アカペラに伴奏を追加する開始・終了時間（秒単位）。
- `persona_id`：アーティストの曲ID。
- `continue_at`：既存の音声を続ける時間（秒単位）。例えば、213.5は3分33.5秒まで続けることを示します。
- `style_influence`：`style_influence`の高度なパラメータ。
- `replace_section_end`：置き換えセクションの最終時間。
- `replace_section_start`：置き換えセクションの開始時間。
- `vocal_gender`：男女の声を制御します。女性声は`f`、男性声は`m`、4.5以上のモデルで有効です。
- `weirdness`：`weirdness`の高度なパラメータ。
- `lyric_prompt`：歌詞を生成するためのプロンプト。`custom`が`true`で、`lyric`が渡されていない場合にのみ有効です。
- `callback_url`：結果をコールバックする必要があるURL。

## カスタム生成

歌詞をカスタマイズして生成したい場合は、歌詞を入力できます：

この時、 `lyric` フィールドには以下のような内容を渡すことができます：

```
[Verse]\n雪の結晶が周りに落ちる\n輝く白\n地面を覆う\n子供たちが笑っている\n喜びに満ちて\n今夜この冬のワンダーランドで\nサンタのそり\n空に上がって\nルドルフの鼻が明るく輝く\nおお、私の\n鈴の音が聞こえる\nはっきりと鳴って\n喜びとホリデーの楽しさをもたらす\n[Verse 2]\n暖炉の光のそばで焼かれる栗\nクリスマスの光\nそれらはきらめいて見せる\n家族が愛と楽しさで集まる\n近くのすべての人に温かさを広げる
```

> 注意：ここでの歌詞中の `\n` は改行文字です。歌詞を生成する方法がわからない場合は、AceDataCloudが提供する歌詞生成APIを使用して、プロンプトを通じて歌詞を生成できます。APIは [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics) です。

次に、歌詞、タイトル、スタイルに基づいてカスタム生成を行うために、以下の内容を指定できます：

- lyric：歌詞テキスト
- custom： `true` と記入し、カスタム生成を示します。このパラメータはデフォルトでfalseで、 `prompt` 生成を示します。
- title：曲のタイトル。
- style：曲のスタイル、任意。

## 続けて生成する機能

既に生成された Suno 曲を続けて生成したい場合、パラメータ `action` を `extend` に設定し、続けて生成する曲の ID を入力します。曲 ID の取得は基本的な使用法に基づいて行います。上記から、この時点で曲の ID は次のようになります：

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> 注意：ここでの歌詞中の `id` は生成後の曲の ID です。曲を生成する方法がわからない場合は、上記の基本的な使用法を参考にして曲を生成してください。

自分がアップロードした曲を続けて生成したい場合、パラメータ `action` を `upload_extend` に設定し、続けて生成するカスタムアップロードの曲 ID を入力します。曲 ID の取得は [Suno Upload Generation API](https://platform.acedata.cloud/documents/suno-upload) を使用して行います。以下の図の通りです：

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" class="m-auto"></p>

次に、歌詞、スタイルを指定してカスタム生成曲を作成する必要があります。以下の内容を指定できます：

- lyric：歌詞テキスト
- custom：`true` と記入し、カスタム生成を示します。このパラメータはデフォルトで false で、`prompt` による生成を示します。
- style：曲のスタイル、任意。
- continue_at：既存の音声の時間を秒単位で続けます。例えば、213.5 は 3 分 33.5 秒まで続けることを示します。

```json
{
  "action": "concat",
```

- action：內容為 `replace_section`。
- audio_id：之前生成歌曲的 ID。
- model: 歌曲生成模型，
- lyric: 替換後的完整歌詞（只需要與 prompt 有重複就行，不需要完全的歌詞），

## Add Insterumental 機能

2025年8月にSunoは新しいAdd Insterumental機能を発表しました。まず、無伴奏の清唱曲をアップロードし、Sunoに伴奏を付けてもらう必要があります。まず、[Suno Upload API](https://platform.acedata.cloud/documents/suno-upload)にアクセスして、無伴奏の清唱曲をアップロードします。操作は以下の図の通りです：

<p><img src="https://cdn.acedata.cloud/fxl914.png" width="500" class="m-auto"></p>

次に、アップロード後の`audio_id`を記録する必要があります。具体的な結果は以下の図の通りです：

<p><img src="https://cdn.acedata.cloud/47t6wj.png" width="500" class="m-auto"></p>

最後に、次のパラメータを記入する必要があります：

- action：内容は `underpainting`。
- underpainting_start：アップロードした曲に伴奏を追加する開始時間、デフォルト値は0。
- underpainting_end：アップロードした曲に伴奏を追加する終了時間、曲の総時間より小さくなければなりません。
- audio_id：アップロードした無伴奏の曲のID。
- style：伴奏のスタイル、歌詞は不要です。やはり伴奏ですから。

## ボーカル追加機能

## リマスタ機能

2025年12月にsunoが新たに追加したリマスタ機能では、この機能を使用して曲を再生成することができ、アカウントを跨いではいけません。その後、以下のパラメータを入力する必要があります：

- action：内容は`remaster`。
- audio_id：再生成する曲のID。
- model：v4.5+、v5のみサポート。
- variation_category：v5以上のバージョンでのみサポートされ、3つの値high、normal、subtleのみ。

<p><img src="https://cdn.acedata.cloud/7h4zmw.png" width="500" className="m-auto" /></p>

```python
import requests

    "action": "remaster",
```

## 非同期コールバック

Sunoによる音楽生成には比較的長い時間がかかり、約1〜2分必要です。APIが長時間応答しない場合、HTTPリクエストは接続を維持し続け、追加のシステムリソースを消費するため、本APIは非同期コールバックのサポートも提供しています。

全体の流れは、クライアントがリクエストを発行する際に、追加で`callback_url`フィールドを指定します。クライアントがAPIリクエストを発行した後、APIはすぐに結果を返し、現在のタスクIDを示す`task_id`フィールド情報を含みます。タスクが完了すると、生成された音楽の結果がPOST JSON形式でクライアントが指定した`callback_url`に送信され、その中にも`task_id`フィールドが含まれているため、タスク結果をIDで関連付けることができます。

以下の例を通じて、具体的にどのように操作するかを理解しましょう。

まず、WebhookコールバックはHTTPリクエストを受け取ることができるサービスであり、開発者は自分で構築したHTTPサーバーのURLに置き換える必要があります。ここではデモのために、公開のWebhookサンプルサイトhttps://webhook.site/を使用します。このサイトを開くと、Webhook URLが得られます。

![](https://cdn.acedata.cloud/fwfqin.png)

このURLをコピーすれば、Webhookとして使用できます。このサンプルはhttps://webhook.site/03e60575-3d96-4132-b681-b713d78116e2です。
