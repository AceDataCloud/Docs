AI の応用範囲が広がるにつれて、さまざまな AI プログラムが徐々に普及しています。AI はすでに人々の仕事や生活のあらゆる面に深く浸透しています。そして AI が関わる業界もますます増えており、初期の文章作成から、医療教育、そして現在の音楽分野へと広がっています。

Suno は、プロフェッショナルで高品質な AI 楽曲および音楽制作プラットフォームです。ユーザーは簡単なテキストプロンプトを入力するだけで、ジャンルやスタイル、歌詞に基づいてボーカル付きの楽曲を生成できます。この AI 音楽生成ツールは、Meta、TikTok、Kensho などの有名テクノロジー企業出身のチームメンバーによって開発されており、楽器などのツールを一切必要とせず、誰でも素晴らしい音楽を創作できることを目標としています。

以下はモデル更新の進捗です：

| バージョン | model           | リリース時間   | lyric 制限 | style 制限 | 楽曲最長時間 |
| ----- | --------------- | ---------- | -------- | -------- | ------ |
| v5.5  | chirp-v5-5      | 2026.03.27 | 5000     | 1000     | 8 分   |
| v5    | chirp-v5        | 2025.09.23 | 5000     | 1000     | 8 分   |
| v4.5+ | chirp-v4-5-plus | 2025.07.17 | 5000     | 1000     | 8 分   |
| v4.5  | chirp-v4-5      | 2025.05.03 | 5000     | 1000     | 4 分   |
| v4    | chirp-v4        | 2024.12.17 | 3000     | 200      | 150 秒  |
| v3.5  | chirp-v3-5      | ---        | 3000     | 200      | 120 秒  |

> 上記表の `lyric` と `style` の制限は、カスタムモード（`custom` が `true`）の場合の上限です。非カスタムのインスピレーションモード（`custom` が `false`）では `prompt` のみを入力し、その長さ上限は 500 文字です（各モデル共通）。

Suno は現在、最新の `chirp-v5-5` モデルをサポートしています。最新バージョンを呼び出す場合は、`model` パラメータを `chirp-v5-5` に設定するだけです。`chirp-v5` およびそれ以前のバージョンも引き続き使用できます。

しかし、Suno 公式は API を提供していません。AceDataCloud は Suno の API セットを提供しており、Suno 公式との接続をシミュレートして、必要な音楽を簡単かつ迅速に生成できます。

## 申請と使用

Suno Audios Generation API を使用するには、まず [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications) にアクセスして API Token を取得し、予備として保存してください。

![](https://cdn.acedata.cloud/5hmkdg.jpg)

まだログインまたは登録していない場合は、自動的にログインページへ移動し、登録とログインを促します。完了後、自動的に現在のページへ戻ります。

**1 つの API Token でプラットフォーム上のすべてのサービスを呼び出すことができ、サービスごとに個別申請する必要はありません。** 初回申請時には無料枠が付与され、無料で体験できます。枠が不足した場合は、[コンソール](https://platform.acedata.cloud/console/coin) で共通残高をチャージできます。

> 📘 完全なドキュメント：[Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## 基本使用

どのような曲を作成したいか、任意の文章を入力できます。例えば、クリスマスに関する曲を生成したい場合は、`a song for Christmas` と入力できます。以下の図のようになります：

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

ここでは Request Headers を設定していることがわかります。内容は以下の通りです：

- `accept`：どのような形式のレスポンス結果を受け取りたいかを指定します。ここでは `application/json`、つまり JSON 形式を入力します。
- `authorization`：API を呼び出すためのキーです。申請後、直接プルダウンから選択できます。

また、Request Body も設定しています。内容は以下の通りです：
- `action`：今回の音楽生成タスクの行動、デフォルトは `generate`、主に含まれるのは：`extend`、`upload_extend`、`cover`、`upload_cover`、`replace_section`、`replace_section`、`concat`、`stems`、`all_stems`、`remaster`。
- `prompt`：Suno公式のインスピレーションモードのヒントワード（`custom` が `false` の場合に有効）、最大500文字。
- `model`：今回の音楽生成タスクのモデル、デフォルトは `chirp-v4`、主に含まれるのは：`chirp-v3`、`chirp-v4`、`chirp-v3-5`、`chirp-v4-5`、`chirp-v4-5-plus`、`chirp-v5`、`chirp-v5-5`。
- `lyric`：Suno公式のカスタムモードの歌詞内容。`chirp-v3-5` と `chirp-v4` は最大3000文字；`chirp-v4-5` 以上（含む `chirp-v5`、`chirp-v5-5`）は最大5000文字。
- `custom`：カスタムモードを使用するかどうか、デフォルトは: `false`。
- `instrumental`：Suno公式のインスピレーションモードの純音楽オプション。
- `title`：Suno公式のカスタムモードの音楽タイトル。`chirp-v3-5`、`chirp-v4` は最大80文字；`chirp-v4-5` 以上は最大100文字。
- `style`：Suno公式のカスタムモード音楽スタイル。`chirp-v3-5` と `chirp-v4` は最大200文字；`chirp-v4-5` 以上（含む `chirp-v5`、`chirp-v5-5`）は最大1000文字。
- `style_negative`：Suno公式のカスタムモードの除外スタイル。
- `audio_weight`：アップロードされた参考音声の比率、範囲0-1、数値が大きいほど参考音声に依存。
- `audio_id`：参考音楽のID。
- `overpainting_start`/`overpainting_end`：既存の純音楽にボーカルを追加する開始・終了時間、単位は秒。
- `underpainting_start`/`underpainting_end`：アカペラに伴奏を加える開始・終了時間、単位は秒。
- `persona_id`：アーティストの曲ID。
- `continue_at`：既存の音声を続ける時間（秒単位）。例えば、213.5は3分33.5秒まで続けることを示す。
- `style_influence`：カスタムモードの「スタイルインフルエンス」高度なパラメータ、範囲0-1、数値が大きいほど選択したスタイルに合致。
- `replace_section_end`：置き換えセクションの最終時間。
- `replace_section_start`：置き換えセクションの開始時間。
- `vocal_gender`：男女声の好みを制御、女性声は `f`、男性声は `m`、4.5以上のモデルで有効；好みの項目であり、厳密に遵守されることは保証されない。
- `weirdness`：カスタムモードの「ウィアードネス」高度なパラメータ、範囲0-1、数値が大きいほど創造的で実験的。
- `duration`：期待される曲の長さ、単位は秒、値は10-360の整数。`action` が `generate`、`custom` が `true` かつ `model` が `chirp-v5-5` の場合にのみ有効、他の組み合わせでは400が返される。これは目標の長さであり、実際の製品の長さは応答の `duration` フィールドに基づく、わずかな偏差がある可能性がある。
- `lyric_prompt`：歌詞を生成するためのプロンプト、`custom` が `true` で `lyric` が渡されていない場合にのみ有効。
- `callback_url`：結果をコールバックする必要があるURL。
- `async`：オプション、`true` に設定するとインターフェースは即座に `task_id` を返し、`callback_url` を提供する必要がなく、その後対応するタスククエリインターフェースを通じて結果をポーリングして取得。

## カスタム生成

歌詞をカスタマイズして生成したい場合は、歌詞を入力できます：

この時、 `lyric` フィールドには以下のような内容を渡すことができます：

```
[Verse]\n雪の結晶が周りに落ちる\n輝く白\n地面を覆う\n子供たちが笑っている\n喜びに満ちて\n今夜この冬のワンダーランドで\nサンタのそり\n空に上がって\nルドルフの鼻が明るく輝く\nおお、私\n鈴の音が聞こえる\nはっきりと鳴って\n喜びとホリデーの楽しさをもたらす\n[Verse 2]\n暖炉の光で焼かれる栗\nクリスマスの光\nそれらはきらめいて見せる\n家族が愛と楽しさで集まる\n近くのすべての人に温かさを広げる
```

> 注意：ここでの歌詞中の `\n` は改行コードです。歌詞を生成する方法がわからない場合は、AceDataCloudが提供する歌詞生成APIを使用して、プロンプトを通じて歌詞を生成できます。APIは [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics) です。

次に、歌詞、タイトル、スタイルに基づいてカスタム生成を行うために、以下の内容を指定できます：

- lyric：歌詞テキスト
- custom： `true` と記入し、カスタム生成を示します。このパラメータはデフォルトでfalseで、プロンプト生成を示します。
- title：曲のタイトル。
- style：曲のスタイル、任意。

## カスタム歌手スタイル生成機能

import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)

## セクション置換

楽曲生成後に、楽曲の一部を置換する二次創作を個別に行う必要がある場合、楽曲の特定のセクションに対して置換操作を実行できます。

> ⚠️ **注意**：`replace_section` を単独で使用した場合、**新しく生成された「置換セクション」自体のみが返されます**（つまり、置換対象となった部分の新しい音声で、長さはおおよそ `replace_section_end - replace_section_start` に等しく、少量のコンテキストが付加されます）。**元の楽曲と結合された完全な楽曲は返されません**。元の楽曲と結合された完成品を取得するには、`replace_section` が成功した後、返されたセクション ID に対して再度 [音楽結合](#音楽拼接) タスクを開始する必要があります。完全な手順は以下を参照してください。

パラメータの説明は以下の通りです：

- action：内容は `replace_section`。
- audio_id：元の楽曲（置換対象となるソース楽曲）の ID。
- model：楽曲生成モデル。
- lyric：置換後の完全な歌詞（置換対象のセクションおよびそのコンテキストを含み、`prompt` 内の内容と一致させる必要があります）。
- prompt：置換する必要がある部分の新しい歌詞。
- style：楽曲のスタイル。任意入力。
- replace_section_start：元の楽曲内で置換されるセクションの開始時間（秒）。
- replace_section_end：元の楽曲内で置換されるセクションの終了時間（秒）。

## 曲の長さを制御する

デフォルトでは、生成される曲の長さはモデルが自動的に決定し、通常30秒から4分の間です。より長いまたは短い完成品が必要な場合は、`duration` パラメータで希望の長さ（秒単位、整数）を指定できます。通常は10秒から360秒の範囲で指定することを推奨します。

このパラメータは主にカスタムモード（`custom` が `true`）での曲生成向けで、新しいモデル（例：`chirp-v5-5`）と組み合わせると最も効果的です。モデルや操作によって長さ制御の対応状況は異なり、対応していない場合はパラメータが無視されたりエラーが返されたりします。返却結果を見て調整してください。

対応するPythonコード：

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "Under the City Lights",
    "style": "lo-fi piano",
    "lyric": "[Verse]\nSunrise creepin\nGold on the floor\n[Chorus]\nUnder the city lights\n",
    "duration": 330
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

注意すべきは、リクエスト中の `duration` は**希望の長さ**であり、レスポンスの `data` 内の各曲の `duration` フィールドはその曲の**実際の長さ**です。同じ名前ですが意味が異なり、実際の長さは希望値の周辺で変動し、正確に一致する保証はありません。

もしモデルや操作が長さ制御に対応していない場合、APIはパラメータを無視するかエラーを返すことがあります。まず1回リクエストして効果を確認してから大量に使うことを推奨します。

## Add Instrumental 機能

2025年8月にsunoはAdd Instrumental機能をリリースしました。まずはボーカルのみで伴奏なしの曲をアップロードし、sunoに伴奏を付けてもらいます。まずは [Suno Upload API](https://platform.acedata.cloud/documents/suno-upload) でボーカルのみの曲をアップロードします。操作は以下の図のようになります：

<p><img src="https://cdn.acedata.cloud/fxl914.png" width="500" className="m-auto" /></p>

アップロード後の `audio_id` を記録します。具体的な結果は以下の図の通りです：

<p><img src="https://cdn.acedata.cloud/47t6wj.png" width="500" className="m-auto" /></p>

最終的に得られた `audio_id` は：92254cab-3372-4d9e-bce9-cdcfdbc39070 です。次に以下のパラメータを入力します：

- action：内容は `underpainting`。
- underpainting_start：アップロードした曲に伴奏を追加する開始時間。デフォルトは0。
- underpainting_end：伴奏を追加する終了時間。曲の総長さより短くなければならない。
- audio_id：アップロードしたボーカルのみの曲のID。
- style：伴奏のスタイル。歌詞は使わない方が良い、伴奏用なので。

入力完了後、自動生成されたコードは以下の通りです：

<p><img src="https://cdn.acedata.cloud/8x1ic6.png" width="500" className="m-auto" /></p>

## ボーカル追加機能

2025年8月にsunoが新たに追加したボーカル追加機能では、まず純粋な音楽をアップロードし、sunoに歌詞を作成させ、ボーカルを追加します。まずは[Suno Upload API](https://platform.acedata.cloud/documents/suno-upload)にアクセスして、アカペラの無伴奏曲をアップロードします。操作は以下の図のようになります：

Sunoの新しいInspoインスピレーション創作機能は、1から4段の参考音声をインスピレーションの源として、全く新しい音楽を生成することができます。カバーとは異なり、Inspoは原曲を再現するのではなく、参考音声からスタイルのインスピレーションを抽出し、プロンプトやスタイルタグなどと組み合わせて新しい作品を生成します。使用する際には、以下のパラメータを記入する必要があります：

- action：内容は`inspo`。
- audio_urls：参考音声のURLリスト、1から4個の公開アクセス可能な音声アドレスを提供する必要があります。
- model：使用するモデル、例えば`chirp-v5`。
- prompt：歌詞や創作のヒント（オプション）。
- tags：音楽スタイルタグ、例えば`acoustic, folk, warm`（オプション）。
- title：曲のタイトル（オプション）。
- audio_weight：生成結果に対する参考音声の影響の重み、範囲は0から1（オプション）。

> 説明：参考音声は公開アクセス可能な音声ファイルでなければなりません。参考音声がプラットフォームの曲庫にある既知の録音と完全に一致する場合、Sunoは著作権の確認により生成を拒否する可能性があるため、自分の音声やSunoが生成した音声をインスピレーションの源として使用することをお勧めします。

対応するPythonコード：

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "inspo",
    "model": "chirp-v5",
    "audio_urls": [
        "https://cdn1.suno.ai/935dd2f5-ddef-43cf-8e68-5a262425694d.mp3"
    ],
    "prompt": "温かいアコースティックフォークと柔らかいボーカル",
    "tags": "アコースティック, フォーク, 温かい",
    "title": "Inspoデモ",
    "audio_weight": 0.6
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 非同期コールバック

Sunoが音楽を生成するのにかかる時間は比較的長く、約1〜2分かかります。APIが長時間応答しない場合、HTTPリクエストは接続を維持し続け、追加のシステムリソースを消費するため、このAPIは非同期コールバックのサポートも提供しています。

全体の流れは、クライアントがリクエストを発行する際に、追加で`callback_url`フィールドを指定し、クライアントがAPIリクエストを発行した後、APIはすぐに結果を返し、現在のタスクIDを示す`task_id`フィールド情報を含みます。タスクが完了すると、生成された音楽の結果がPOST JSON形式でクライアントが指定した`callback_url`に送信され、その中にも`task_id`フィールドが含まれているため、タスクの結果をIDで関連付けることができます。
