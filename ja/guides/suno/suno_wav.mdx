SUNO は私たちが音楽の wav 形式ファイルを取得することを許可します。本ドキュメントでは関連する API の接続方法を説明します。

この API のコア入力パラメータは `audio_id` で、これは公式に生成された曲の ID です。オプションとして `callback_url` 非同期コールバックアドレスもサポートされています。

ここで入力する `audio_id` は `4e43116a-bf09-472c-8e1c-655eabf02682` です。

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer YOUR_API_KEY",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

結果は以下の通りです：

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://cdn.acedata.cloud/e724d7f13d.png?example=image-001"
    }
  ]
}
```

`data` の `file_url` フィールドは取得した音楽の wav 形式ファイルであり、公開アクセス可能な CDN アドレスです。

> **WAV リンクの永続化について**
> プラットフォームは、返却前に優先的に最終状態の WAV ファイルを Ace Data Cloud CDN に永続化します。上記の URL は応答形式を示すものであり、長期的に存在する実際のオブジェクトを表すものではありません。CDN の永続化が完了していない場合、かつ元のメディアアドレスが即時検証で有効な WAV ファイルをダウンロードできる場合にのみ、`file_url` はそのアドレスを保持する可能性があります。アドレスが無効になったり、ファイル検証に失敗した場合、リクエストは失敗またはタイムアウトを返し、ダウンロードできないアドレスを成功結果として扱うことはありません。タスクが完了した後は、速やかにダウンロードし、適切に保存してください。具体的な保持期間はプラットフォームの現在のストレージポリシーに基づきます。
