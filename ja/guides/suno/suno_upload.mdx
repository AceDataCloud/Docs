SUNO では、参照オーディオをアップロードして二次創作を行うことができます。本ドキュメントでは、関連 API の連携方法について説明します。

通常のアップロードでは `audio_url` のみが必要です。これは公開アクセス可能なオーディオ CDN アドレスです。`mode` はデフォルトで `standard` のため、既存の呼び出しを変更する必要はありません。通常のアップロードが成功すると **0.06 Credits** が消費されます。アップロードに失敗した場合、課金されません。

ここで入力する `audio_url` は `https://cdn.acedata.cloud/suno_demo.mp3` であり、公開アクセス可能な CDN アドレスです。

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

楽曲 ID を取得した後、[Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) を通じて `upload_extend`、`upload_cover`、または区間サンプリングなど、`audio_id` を必要とする操作を呼び出せます。Inspo インスピレーション作成機能を通じて、1〜4本の完全な参照オーディオに基づいて新しい音楽を作成する場合は、`action=inspo` を直接呼び出し、元の公開オーディオ URL リストを渡してください。サービスがアップロードと分析を自動的に完了するため、クライアント側でオーディオ metadata を組み立てる必要はありません。

## プライベート音声用にカバー元曲をアップロードする

`/suno/voices` を使用して作成したプライベート音声でカバーする場合は、通常のアップロードリクエストでその音声の `persona_id` を渡し、元曲を音声に関連付けます：

```json
{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "mode": "standard",
  "persona_id": "<音声作成インターフェースから返される persona_id>"
}
```

アップロード成功後、返却された `data.audio_id` を使用して `/suno/audios` を呼び出し、`action: "upload_cover"` を設定して、同じ `persona_id` を渡します。以前にこの音声と関連付けられていないオーディオ ID を引き続き使用しないでください。

`persona_id` は通常のアップロードのみをサポートし、`mode: "enhanced"` と同時には使用できません。`vocal_gender` を追加で指定する必要はありません。性別の設定は音声 ID の代わりにはなりません。音声の作成、元曲のアップロード、カバーには同じサービスチャネルを使用する必要があります。

## 拡張アップロードモード

> `audio_url` は入力アドレスであり、オーディオ処理フローに直接渡されます。最終メディア永続化サービスによって事前に転送・保存されることはありません。タスク処理中に公開アクセス可能であることを確認してください。

通常のアップロードで、お客様が所有している、または使用許可を取得済みのオーディオを処理できない場合、`mode` を `enhanced` に設定できます。このモードでは、1〜100文字の `name` も必須であり、公開アクセス可能な HTTPS `audio_url` を使用する必要があります。

拡張アップロードは常に非同期処理を採用し、通常2分以上かかります。処理が成功すると **1.87 Credits** が消費されます。処理に失敗した場合、課金されません。

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

インターフェースは直ちに `task_id` と `trace_id` を返します。[Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) を使用してタスクを照会し、成功後に `response.data.audio_id` からアップロード後のオーディオ ID を読み取ります。HTTPS の `callback_url` を提供して最終状態を受信することもできます。
アップロードして取得した `audio_id` は Cover、Samples、および Mashup に使用できます。伴奏と MIDI の抽出、全トラック分離、およびボーカル/伴奏分離は、依然として音声の所有アカウントによる制限を受ける可能性があります。記載されていない操作については、アカウントをまたいだ使用を保証しません。音声が短いほど、通常は処理の成功率が高くなります。
