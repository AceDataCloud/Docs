SUNO では、参考音声をアップロードして二次創作を行うことができます。本ドキュメントでは、関連 API の連携方法を解説します。

通常のアップロードでは `audio_url` のみが必要です。これは公開アクセス可能な音声 CDN アドレスです。`mode` のデフォルトは `standard` のため、既存の呼び出しを変更する必要はありません。通常のアップロードが成功すると **0.06 Credits** を消費します。アップロードに失敗した場合は課金されません。

ここで入力する `audio_url` は `https://cdn.acedata.cloud/suno_demo.mp3` であり、公開アクセス可能な CDN アドレスです。

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

ご覧のとおり、`data` は常にオブジェクトであり、`audio_id` はアップロード後の楽曲 ID です。`lyric`、`style`、`duration`、タイトル、メディア URL などの分析結果は任意フィールドであり、具体的には返却内容に準じます。

楽曲 ID を取得した後は、[Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) を通じて、`upload_extend`、`upload_cover`、または区間サンプリングなど、`audio_id` を必要とする操作を呼び出すことができます。Inspo インスピレーション作成機能で、1～4 本の完全な参考音声に基づいて新しい音楽を作成する場合は、直接 `action=inspo` を呼び出し、元の公開音声 URL リストを渡してください。サービスが自動的にアップロードと分析を完了するため、クライアント側で音声 metadata を組み立てる必要はありません。

## 拡張アップロードモード

> `audio_url` は入力アドレスであり、音声処理フローに直接渡されます。最終メディア永続化サービスによって事前に転送・保存されることはありません。タスク処理中に公開アクセス可能であることを確認してください。

通常のアップロードで、所有している、または使用許可を得ている音声を処理できない場合は、`mode` を `enhanced` に設定できます。このモードでは、1～100 文字の `name` も必須であり、公開アクセス可能な HTTPS `audio_url` を使用する必要があります。

拡張アップロードは常に非同期処理となり、通常は 2 分以上かかります。処理に成功すると **1.87 Credits** を消費します。処理に失敗した場合は課金されません。

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

API は直ちに `task_id` と `trace_id` を返します。[Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) を使用してタスクを照会し、成功後に `response.data.audio_id` からアップロード後の音声 ID を読み取ります。HTTPS `callback_url` を提供して最終状態を受信することもできます。

拡張アップロードで取得した `audio_id` は、Cover、Samples、Mashup に使用できます。伴奏および MIDI の抽出、全トラック分離、ボーカル／伴奏分離は、依然として音声が属するアカウントによる制限を受ける可能性があります。記載されていない操作については、アカウントをまたいだ利用がサポートされる保証はありません。音声が短いほど、通常は処理成功率が高くなります。
