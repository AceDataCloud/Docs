---
title: "Suno 歌詞生成 API 連携説明"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

もし自分で歌詞を作成したくないが、カスタマイズされた曲を生成したい場合は、AceDataCloud が提供する歌詞生成 API を使用してプロンプトを通じて歌詞を生成できます。この API は [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics) です。

この API の主な入力パラメータは `prompt` で、オプションの `model`（選択肢は `default`、`remi-v1`、デフォルトは `default`）があります。記入例は以下の通りです：

![](https://cdn.acedata.cloud/p53wtj.png)

ここで入力する `prompt` は `A song about winter` で、冬に関連する曲を生成します。

実行をクリックすると、結果は以下の通りです：

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\n雪の結晶が空から降り注ぐ\n冬の冷たい触れ合い\nそれが私を高揚させる\n私は重ね着をして\nとても快適\n外に出て鼻に霜を感じる\n\n[Chorus]\nああ\n冬の冷たい触れ合い\n私がとても愛する季節\n雪が降ると神聖な気持ちをもたらす\n冬の冷たい触れ合い\n魔法のような時",
      "title": "冬の冷たい触れ合い",
      "status": "complete",
      "tags": ["夢のような, メロウ, バラード"]
    },
    {
      "text": "[Verse]\n世界は白い毛布に覆われている\n氷柱がぶら下がって\nとても明るく輝いている\n冷たい空気が息をするたびに肺を満たす\n雪の中を歩き\n足跡を残す\n\n[Chorus]\n冬のワンダーランド\nすべてがとても明るい\n冬のワンダーランド\n夜を通して私を抱きしめて",
      "title": "冬のワンダーランド",
      "status": "complete",
      "tags": ["ドリームポップ, メロウ, シューゲイザー"]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,
  "elapsed": 7.433
}
```

`data` は配列であり、毎回複数の歌詞候補が返されます。その中の各要素の `text` フィールドが歌詞の内容で、`title` がタイトル、`tags` が推奨される曲風タグです。

歌詞が得られたら、[Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) を使用してカスタマイズされた曲の生成を行うことができます。
