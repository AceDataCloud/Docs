---
title: "Suno 歌詞生成 API 対接説明"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

もし自分で歌詞を作成したくないが、カスタマイズされた歌を生成したい場合は、AceDataCloudが提供する歌詞生成APIを使用してプロンプトから歌詞を生成できます。このAPIは [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics) です。

このAPIの主な入力パラメータは `prompt` で、オプションの `model`（デフォルトは chirp-v3）があります。記入例は以下の通りです：

![](https://cdn.acedata.cloud/p53wtj.png)

ここで入力する `prompt` は `A song about winter` で、冬に関連する歌を生成します。

実行をクリックすると、結果は以下の通りです：

```
{
  "success": true,
  "task_id": "57e8ce3a-39cb-41a2-802f-e70a324f4d0a",
  "data": {
    "text": "[Verse]\n雪の結晶が空から降り注ぐ\n冬の冷たい触れ合い\nそれが私を高揚させる\n私は重ね着をして\nとても快適\n外に出て鼻に霜を感じる\n見て\n\n[Verse 2]\n世界は白い毛布に覆われている\nつららがぶら下がり\nとても明るく輝いている\n冷たい空気が一息ごとに私の肺を満たす\n雪の中を歩き\n残されない足跡を残す\n\n[Chorus]\nああ\n冬の冷たい触れ合い\n私がとても愛する季節\n雪が降ると神聖な感覚をもたらす\n冬の冷たい触れ合い\nそれは魔法のような時",
    "title": "冬の冷たい触れ合い",
    "status": "complete"
  }
}
```

`data` の `text` フィールドが歌詞情報であることがわかります。

歌詞ができたら、[Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) を使用してカスタマイズされた歌の生成を行うことができます。
