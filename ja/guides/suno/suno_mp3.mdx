---
title: "Suno MP3 URL API 接続説明"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Suno MP3 URL API は、既存の音楽に対して `.mp3` で終わる再生可能なアドレスを生成するもので、古いダウンロードリンクが無効になった場合や、モバイル端末での再生、公開音声 URL を再取得する必要があるシーンに適しています。

必須パラメータ `audio_id` は、Suno 音声生成インターフェースが返す音声 ID です。毎回の呼び出しで独立した MP3 URL タスクが作成され、元の音楽生成タスクは変更されず、元の音声 ID も変わりません。

## 同期呼び出し

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={
        "accept": "application/json",
        "authorization": "Bearer <YOUR_API_TOKEN>",
        "content-type": "application/json"
    },
    json={"audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f"},
    timeout=240
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["file_url"])
```

成功した場合、`data[0].file_url` は再生可能な音声アドレスです。インターフェースは優先的に `https://platform2.cdn.acedata.cloud/suno/{audio_id}.mp3` に転送されます；転送が 30 秒を超えるか失敗した場合は、現在利用可能な元の音声アドレスが返されます。

## 非同期呼び出し

処理時間が長い場合は、`async: true` を渡すことができます：

```python
submission = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={"authorization": "Bearer <YOUR_API_TOKEN>"},
    json={
        "audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f",
        "async": True
    }
).json()

export_task_id = submission["task_id"]
```

その後、`/suno/tasks` を通じて `export_task_id` を照会します。また、`callback_url` を提供することで、タスク完了後に最終結果を受け取ることもできます。同期応答、タスク照会、コールバックは同じ最終データ構造を使用します。

## 注意事項

- `audio_id` は認識可能な Suno 音声から取得する必要があります。
- MP3 URL タスクは元の音楽生成タスクとは独立しています。
- 転送は最大で 30 秒待機します；転送がタイムアウトまたは失敗した場合、結果をブロックせず、元の音声アドレスに戻ります。
- ビジネス側では、結果を受け取った後、迅速にダウンロードし、自身のデータ保持ポリシーに従って保存することをお勧めします。
