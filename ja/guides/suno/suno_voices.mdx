---
title: "Suno 音声クローン API 接続説明"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

SUNO は、任意の音声ファイルを通じてカスタム音声キャラクターを作成し、音声クローンを音楽生成に利用することを可能にします。既存の Persona API（Suno によって生成された `audio_id` を使用）とは異なり、この API は公開アクセス可能な `audio_url`、つまりあなた自身の声の録音を受け入れます。本ドキュメントでは音声クローン API の接続方法を説明します。

この API には三つの入力パラメータがあります：`audio_url`（必須）、これは単一の明瞭な人声を含む公開アクセス可能な MP3 または WAV 形式の音声ファイルの URL です；`name` と `description`（任意）、これは音声キャラクターの名前と説明です。

**音声ファイルの要件：**

- フォーマット：MP3 または WAV
- 時間：最低 10 秒
- 内容：単一の明瞭な人声、背景ノイズや音楽をできるだけ減らす

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://example.com/my-vocal-recording.mp3",
  "name": "My Voice",
  "description": "A warm male voice"
}'
```

結果は以下の通りです：

```json
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dde0be60-5280-4bd2-89a0-4020ddd3db52",
    "name": "My Voice",
    "is_public": false
  }
}
```

ここで、`data` の `persona_id` フィールドが作成された音声キャラクターの ID です。`is_public` フィールドは常に `false` で、音声をアップロードして作成された音声キャラクターはプライベートです。

音声キャラクター ID を取得したら、[Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) を使用して音楽生成を行うことができます。`action` を `vox` に設定し、`persona_id` を上記の返された値に設定すると、生成された曲はクローンされた声で歌われます。
