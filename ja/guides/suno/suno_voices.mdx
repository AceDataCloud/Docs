SUNO は任意の音声ファイルからカスタム音声キャラクターを作成し、音声クローンを用いて音楽生成を実現できます。既存の Persona API（Suno で生成された `audio_id` を使用）とは異なり、本 API は公開アクセス可能な `audio_url`、すなわち自身の音声録音を受け入れます。本ドキュメントでは音声クローン API の接続方法を解説します。

## 第1ステップ：音声キャラクターの作成

本 API には3つの入力パラメータがあります：`audio_url`（必須）、公開アクセス可能な MP3 または WAV 形式の音声ファイル URL で、単一人物の明瞭な音声を含むもの；`name` と `description`（任意）、音声キャラクターの名前と説明です。

**音声ファイルの要件：**
- 形式：MP3 または WAV
- 長さ：最低10秒以上
- 内容：単一人物の明瞭な音声で、できるだけ背景ノイズや音楽を減らすこと

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

結果は以下の通りです：

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

`data` 内の `persona_id` フィールドが作成された音声キャラクターの ID です。`is_public` フィールドは常に `false` で、アップロードした音声から作成された音声キャラクターはプライベートです。

## 第2ステップ：音声キャラクターを使った音楽生成

音声キャラクター ID を取得したら、[Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) を使って音楽生成が可能です。`action` を `generate` に設定し、`persona_id` に上記で取得した音声キャラクター ID を指定すると、生成される楽曲はクローンした声で歌唱されます。

> **注意：** 音声クローンは `chirp-v4-5` 以降のモデル（例：`chirp-v4-5`、`chirp-v5`、`chirp-v5-5`）のみ対応し、`chirp-v4` は対応していません。

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

結果は以下の通りです：

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

生成された楽曲はクローンした声で歌唱されています。`persona_id` は `cover` アクションと組み合わせて使用することもでき、クローンした声で既存の楽曲をカバーできます。
