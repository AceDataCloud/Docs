SUNO では、任意の音声ファイルからカスタム音声キャラクターを作成し、音楽生成のための音声クローンを実現できます。既存の Persona API（Suno により生成された `audio_id` を使用）とは異なり、この API は、あなた自身の音声録音である公開アクセス可能な `audio_url` を受け取ります。本ドキュメントでは、音声クローン API の連携方法を解説します。

## 第1ステップ：音声キャラクターを作成する

この API には 3 つの入力パラメータがあります：`audio_url`（必須）は、明瞭な単一人物の音声を含む、公開アクセス可能な MP3 または WAV 形式の音声ファイル URL です；`name` と `description`（任意）は、音声キャラクターの名前と説明です。

> **音声ファイルの要件**
> - 音声形式は `WAV` または `MP3` である必要があります
> - 音声の長さは `10～240 秒` の間である必要があり、`30～60 秒` のクリーンな単一人物のドライボイス素材の使用を推奨します
> - 音声には**明瞭で識別可能な単一人物の話し声または歌声**が含まれている必要があります
> - **背景ノイズ、伴奏、エコー、リバーブ**は必ず避けてください；伴奏付きのフル楽曲は通常、声紋検証に通りません
> - **複数の話者**や**複数のボーカル**を含めないでください
> - 音量が低すぎる、音声が不明瞭、ノイズが多すぎる素材は、**クローン失敗**または**生成品質の低下**につながる可能性があります
> **利用制限について**
> - アップロードした音声から作成された音声キャラクターは**プライベートリソース**です
> - この音声キャラクターは**アカウント間で再利用できません**
> - 作成に成功した後はできるだけ早く使用することを推奨します。長期間使用しない場合、**無効化または利用不可**になる可能性があります
> - 返される `name` はシステムによって自動生成されるため、返された `persona_id` を基準にしてください

> **呼び出しに失敗した場合は、まず再試行してください**
> 音声クローンは計算リソースを大量に消費するタスクであり、素材が完全に要件を満たしていても、一定の確率で偶発的な失敗が発生する可能性があります。一般的な返却値には
> `voices_sound_different`（声紋検証不合格）などがあります。**この種の失敗は音声品質とは無関係であり、同じ素材で再試行すれば通常は成功します**。
> 統合時には、失敗結果に対して 1～2 回の自動再試行を実装することを推奨します。失敗したリクエストは課金されません。

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> 上記の `https://cdn.acedata.cloud/suno_demo.mp3` は直接呼び出し可能なサンプル素材です（MP3、41 秒、単一人物のドライボイス）。
> `WAV` 形式のサンプルが必要な場合は、
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765`（WAV、41 秒、モノラル 44.1kHz）を使用できます。

結果は以下のとおりです：

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

ご覧のとおり、`data` の `persona_id` フィールドが作成された音声キャラクター ID です。アップロードした音声から作成される音声キャラクターはプライベートであるため、`is_public` フィールドは常に `false` です。返される `name` はシステムによって自動生成されるため、以降は `persona_id` を使用してこの音声キャラクターを参照してください。

## 第2ステップ：音声キャラクターを使用して音楽を生成する

音声キャラクター ID を取得した後、[Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) を使用して音楽を生成できます。`action` を `generate` に設定し、`persona_id` を上記で返された音声キャラクター ID に設定すると、生成される楽曲はクローンされた声で歌唱されます。

> **注意：** 音声クローンは `chirp-v4-5` 以降のモデル（`chirp-v4-5`、`chirp-v5`、`chirp-v5-5` など）のみをサポートし、`chirp-v4` はサポートしていません。

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

結果は以下のとおりです：

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

ご覧のとおり、生成された楽曲はクローンされた声で歌唱されています。`persona_id` は `cover` アクションと組み合わせて使用することもでき、クローンされた声で既存の楽曲をカバーできます。
