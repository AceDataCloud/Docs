SUNO では、任意の音声ファイルを通じてカスタム音声キャラクターを作成し、音楽生成のための音声クローンを実現できます。既存の Persona API（Suno によって生成された `audio_id` を使用）とは異なり、この API は公開アクセス可能な `audio_url`、つまりご自身の音声録音を受け付けます。本ドキュメントでは、音声クローン API の連携方法を説明します。

音色照会をサポートする作成経路では、元のアプリケーションと呼び出し元の身元情報を使用して、作成結果内の `persona_id` を `POST /suno/availability` に渡すことができます。関連アカウントがオンラインの場合は `data.available=true` が返され、オフラインであることが確認された場合は `data.available=false` が返されます。[音色可用性照会ガイド](https://platform.acedata.cloud/documents/suno-availability-integration)

## ステップ 1：音声キャラクターの作成

料金：音声キャラクターの作成成功後、各リクエストの標準料金は **0.15 Credits** です。適用される消費割引は実際の請求書に準じ、失敗したリクエストには料金はかかりません。

この API には 3 つの入力パラメータがあります：`audio_url`（必須）は、明瞭な単一人物の音声を含む、公開アクセス可能な MP3 または WAV 形式の音声ファイル URL です；`name` と `description`（任意）は、音声キャラクターの名前と説明です。

> **音声ファイルの要件**
> - 音声形式は `WAV` または `MP3` である必要があります
> - 音声の長さは `10~240 秒` の間である必要があり、`30~60 秒` のクリーンな単一人物のドライボイス素材の使用を推奨します
> - 音声には**明瞭で識別可能な単一人物の話し声または歌声**が含まれている必要があります
> - **背景ノイズ、伴奏、エコー、残響**は必ず避けてください；伴奏付きの完成した楽曲は通常、声紋検証を通過できません
> - **複数の話者**または**複数のボーカル**を含めないでください
> - 音量が低すぎる、音声が不明瞭、ノイズが多すぎる素材は、**クローン作成の失敗**または**生成品質の低下**を招く可能性があります
> **利用制限の説明**
> - 音声をアップロードして作成された音声キャラクターは**プライベートリソース**です
> - この音声キャラクターは**アカウント間で再利用できません**
> - 作成成功後はできるだけ早く使用することを推奨します。長期間使用しない場合、**失効または利用不可**になる可能性があります
> - 返される `name` はシステムによって自動生成されるため、返された `persona_id` を基準にしてください

> **明示的なリトライフラグに従って失敗を処理してください**
> エラーオブジェクト内の `retryable` は任意のブール型フィールドです。`error.retryable` が `true` の場合、今回の失敗では同じ素材と同じパラメータを使用して後で再リクエストすることが許可されていることを示します。明示的に受理されなかったサービス混雑、または一部の一時的な声紋検証失敗にはこのフラグが付く場合があり、バックオフ間隔を使用し、リトライ回数を制限することを推奨します。
> `retryable` が `false` の場合、またはフィールドが存在しない場合は、HTTP 500、`busy`、またはエラーテキストのみに基づいて自動再送しないでください。形式、長さ、明瞭さ、重複録音、コンテンツ審査の問題は先に修正してください；送信タイムアウト、接続中断、または作成結果が不明確な場合は、重複した音色作成を避けるため、元の `task_id` を使用してタスクを照会することを優先してください。失敗したリクエストには課金されず、リトライに成功したリクエストは通常のルールに従って課金されます。

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> 上記の `https://cdn.acedata.cloud/suno_demo.mp3` は、直接呼び出し可能なサンプル素材です（MP3、41 秒、単一人物のドライボイス）。
> `WAV` 形式のサンプルが必要な場合は、
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765`（WAV、41 秒、モノラル 44.1kHz）を使用できます。

結果は以下のとおりです：

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

ご覧のとおり、`data` の `persona_id` フィールドが作成された音声キャラクター ID です。音声をアップロードして作成された音声キャラクターはプライベートであるため、`is_public` フィールドは常に `false` です。返される `name` はシステムによって自動生成されるため、以降は `persona_id` を使用してこの音声キャラクターを参照してください。

## ステップ 2：音声キャラクターを使用して音楽を生成する

音声キャラクター ID を取得した後、[Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) を使用して音楽を生成できます。`action` を `generate` に設定し、`persona_id` を上記で返された音声キャラクター ID に設定すると、生成される楽曲はクローンされた音声で歌唱されます。

> **注意：** 音声クローンは `chirp-v4-5` 以上のモデル（例：`chirp-v4-5`、`chirp-v5`、`chirp-v5-5`）のみをサポートし、`chirp-v4` はサポートしていません。

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

結果は以下のとおりです：

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` は `generate` による生成に使用できるほか、`cover` / `upload_cover` によるカバーにも使用できます。音声を指定する場合、`vocal_gender` を同時に記入する必要はありません；音声の類似度は引き続き参照素材と生成結果に依存します。

本インターフェースで作成された音声はプライベートリソースです。既存の楽曲をカバーする前に、まず `/suno/upload` を呼び出し、原曲の `audio_url` とこの音声の `persona_id` を渡します；アップロード成功後、返された `data.audio_id` と同じ `persona_id` を使用して `/suno/audios` を呼び出します：
```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

音声の作成、原曲のアップロード、およびカバーには同じサービスチャネルを使用する必要があります。このプライベート音声に関連付けられていない以前の曲 ID を直接再利用しないでください。詳細は [Suno アップロード参考音声](https://platform.acedata.cloud/documents/suno-upload) を参照してください。
