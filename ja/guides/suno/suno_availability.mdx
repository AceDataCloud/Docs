---
title: "Suno オーディオ可用性チェック API"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

`POST /suno/availability` は `audio_id` に基づき、オーディオが現在の経路で引き続き処理可能であることを示す肯定的な証拠を探します。続編作成やカバーなどの操作前に呼び出すことができます。結果はチェック時点の状態のみを反映し、特定の操作が必ず成功することを保証するものではありません。この API は同期的にレスポンスを返し、API Token が必要です。現在、Credits は消費されません。

`audio_id` は完了済みの Suno タスクが返す楽曲 ID であり、`task_id` ではありません。

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

成功レスポンス例：

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

チェックに成功した場合、`data.available` は `true` になります。確認できない場合は `503 availability_unknown` が返され、`false` は返されません。`audio_id` の形式が不正な場合は 400 が返され、レート制限またはサービス障害の場合もエラーレスポンスが返されます。チェック完了後から実際の操作までの間に、状態が変化する可能性があります。
