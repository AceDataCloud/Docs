---
title: "Suno オーディオ可用性チェック API"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

`POST /suno/availability` は `audio_id` に基づいて、オーディオが現在の回線で引き続き処理可能であるという肯定的な証拠を探します。続きの生成、カバーなどの操作前に呼び出すことができます。結果はチェック時の状態のみを反映し、特定の操作が必ず成功することを保証するものではありません。この API は同期的に返され、API Token が必要で、現在は Credits を消費しません。

`audio_id` は完了した Suno タスクが返す楽曲 ID であり、`task_id` ではありません。

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

成功レスポンス例：

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

チェックが成功した場合、`data.available` は `true` のみになります。一部の回線が返す「オフライン」状態は、その後の続きの生成などの操作が成功しないことを証明するものではないため、本 API は確認できない場合に `503 availability_unknown` を返し、`false` は返しません。`audio_id` の形式が不正な場合は 400 が返され、レート制限または上流の障害もエラーレスポンスを返します。チェック完了後から実際の操作までの間に、状態が変化する可能性があります。
