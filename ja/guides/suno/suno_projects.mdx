`POST https://api.acedata.cloud/suno/projects` はマルチトラックプロジェクトを管理するための Beta インターフェースです。1 つのエンドポイントが `action` によって作成、保存、候補生成、候補コミット、エクスポートを区別します。呼び出し側は以下の公開フィールドのみを使用すればよく、基盤となる生成サービスの内部リクエスト構造を入力する必要はありません。

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Idempotency-Key: 每次修改操作使用新的 UUID
```

`retrieve` を除き、**すべての操作で** `Idempotency-Key` が必要です。同じキーかつ同じリクエストでは元の結果のみが返されます。同じキーで異なるリクエストを送信すると 409 が返されます。課金対象の生成でネットワークタイムアウトや送信結果が不確実な場合は、まず元のタスク ID または同じ冪等キーで照会し、直接キーを変更して再送してはいけません。

## まずこれらの ID と時間単位を区別してください

| 名称                             | 取得元                                                                                      | 使用先                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| `id`                           | `create` レスポンスの `data.id`                                                                      | 現在のプロジェクトに対するすべての後続リクエスト                                      |
| `version_id`                   | 直近の `retrieve`、`save`、`add_track`、`commit_candidate` または `remove_track` の `data.version_id` | 変更、候補生成、エクスポート。必ず最新バージョンを使用する                              |
| `audio_id` / `source_audio_id` | `upload` 終了時の `response.data.candidate.audio_id`、または既存の完了済み音声 ID                                | `add_track`、生成または置換時に元音声を参照する                          |
| `render_audio_id`              | `render` 終了時の `response.data.audio_id`                                                       | `generate_track` のプロジェクトミックス参照                         |
| `operation_id`                 | `generate_track` または `replace_section` 終了時の `response.data.operation_id`                       | `commit_candidate`。通常は生成タスクの `task_id` と同じですが、返り値を読み取る必要があります |
| `candidate_id`                 | 生成終了時の `response.data.candidates[].id`                                                       | 1 つの候補を選択してコミットする                                         |
| `track_id`                     | プロジェクトの `data.state.tracks[].id`                                                                | 候補のコミットまたはトラックの削除                                        |
| `task_id`                      | 非同期操作の送信レスポンス                                                                                   | `/suno/tasks` を使用して終了状態を照会する。プロジェクト ID ではありません                   |

`start_seconds` / `end_seconds` は**元音声内の秒数**です。`start_beats` / `end_beats` は**プロジェクトタイムライン上の拍数**です。`state.timing.bps` は毎秒の拍数で、デフォルトは 2 です。たとえば、41 秒のクリップが第 0 拍から始まる場合、デフォルトの終点は第 82 拍です。`generate_track` の秒数範囲は生成参照を指定するために使用され、候補がその範囲だけの長さになることを保証しません。

## 操作順序と結果の判定

| 順序  | `action`                             | 役割                         | 返却方式         |
| --- | ------------------------------------ | -------------------------- | ------------ |
| 1   | `create`                             | 空のプロジェクトを作成する                      | 同期プロジェクトデータ       |
| 2   | `retrieve`                           | 最新バージョンと完全な `state` を読み取る          | 同期プロジェクトデータ       |
| 3   | `save`                               | 初回保存、または変更後の `state` 全体を保存する      | 同期プロジェクトデータ       |
| 4   | `upload`                             | HTTPS 音声アドレスから素材を作成する           | 非同期タスク         |
| 5   | `add_track`                          | 素材音声をプロジェクトに配置する                  | 非同期タスク、バージョン更新    |
| 6   | `save`                               | 新しいトラック候補を受け取る必要がある場合、先に空のターゲットトラックを保存する        | 同期プロジェクトデータ、バージョン更新  |
| 7   | `render`                             | 現在聴取可能なトラックをエクスポートし、ミックス参照 `audio_id` を取得する | 非同期タスク         |
| 8   | `generate_track` または `replace_section` | それぞれ新トラック候補または部分置換候補を生成する            | 非同期タスク、プロジェクトはまだ変更しない  |
| 9   | `commit_candidate`                   | 1 つの候補を選択してコミットする                  | 非同期タスク、成功後にバージョン更新 |
| 任意  | `remove_track`                       | 指定トラックを削除する                     | 同期プロジェクトデータ、バージョン更新  |

部分置換のみを行う場合は、既存の使用可能な元音声があればよく、先に `render` する必要はありません。元音声がすでにプロジェクト内にある場合は、`upload` と `add_track` を省略することもできます。`render_audio_id` は `generate_track` の必須参照にすぎません。

非同期操作の送信時には、まず `{ "task_id": "...", "trace_id": "..." }` が返されますが、**これは生成の成功を意味しません**。ポーリング：

```http
POST /suno/tasks
Content-Type: application/json

{"action":"retrieve","id":"上一步返回的 task_id"}
```

タスク記録に `finished_at` があり、かつその中の `response.success` が `true` である場合にのみ成功とみなされます。`response.success=false` の場合は `response.error` を読み取ります。`save` は `task_id` を含む場合がありますが、このインターフェース内では同期的に完了します。`upload`、`render`、`generate_track`、`replace_section` はプロジェクトバージョンを変更しません。`save`、`add_track`、`commit_candidate`、`remove_track` が成功した後は、新しい `version_id` を取得する必要があります。

## リクエストパラメータ

### 共通フィールドとリクエストヘッダー

| パラメータ                | 型と適用範囲                                                                                   | 説明                                                              |
| ----------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `action`          | 必須文字列                                                                                     | 本ページに記載された操作名のいずれかに固定されます。1 回のリクエストで実行できる操作は 1 つだけです。                                      |
| `id`              | `create` を除き必須の文字列                                                                         | プロジェクト ID。`create.data.id` から取得します。                                      |
| `version_id`      | 変更、候補生成、エクスポート時は必須文字列。初回の空プロジェクト `save` では省略可能                                                         | 最新バージョンを使用します。古いバージョンは拒否されます。`retrieve` では不要です。                                 |
| `Idempotency-Key` | `retrieve` を除く必須リクエストヘッダー、1～128 文字                                                              | 新しい操作ごとに新しいキーを使用します。同じキー・同じリクエストでは元の結果が返され、再生成や課金は行われません。                                   |
| `async`           | `upload`、`add_track`、`generate_track`、`replace_section`、`commit_candidate`、`render` で任意のブール値 | これらの操作は常に非同期です。`false` であっても生成は同期になりません。                                    |
| `callback_url`    | 上記の任意の非同期フィールドを持つ操作で任意の URL                                                                       | 終了状態の通知を受け取ります。省略した場合は `task_id` により `/suno/tasks` を照会します。引き続き `response.success` を確認する必要があります。 |

### プロジェクトと素材
| `action`       | 固有パラメータ                    | 型と条件                              | 説明                                                                 |
| -------------- | --------------------------- | -------------------------------- | ------------------------------------------------------------------ |
| `create`       | `title`                     | 必須文字列、1～200 文字                   | 新しいプロジェクトのタイトル。                                                     |
| `retrieve`     | なし                          | —                                | `action` とプロジェクト `id` のみ必要。完全で編集可能な `state` を返す。                              |
| `save`         | `state`                     | 必須オブジェクト                         | プロジェクト状態を**全体置換**するものであり、部分パッチではない。直近の `retrieve.data.state` を基に変更して完全に送信し、不明なフィールドを保持する。 |
| `save`         | `title`                     | 任意文字列                            | プロジェクトタイトル。省略時は `state.title` を引き継ぎ、それもない場合はデフォルトタイトルを使用する。                              |
| `upload`       | `audio_url`                 | 必須 HTTPS URL                     | 公開アクセス可能な音声素材のアドレス。成功後、最終状態の `candidate.audio_id` を読み取る。素材は呼び出し元が使用権を保有している必要がある。            |
| `add_track`    | `audio_id`                  | 必須文字列                            | 完了済み素材の音声 ID であり、URL ではない。                                                |
| `add_track`    | `name` / `color`            | 任意文字列                            | 新しいトラック名、色。名前のデフォルトは音声タイトル、色は `#RRGGBB` を推奨し、デフォルトは `#7251F7`。                    |
| `add_track`    | `title`                     | 任意文字列                            | 同時にプロジェクトタイトルを変更する。通常は省略する。                                                     |
| `add_track`    | `start_beats` / `end_beats` | 任意の非負数値、`end_beats > start_beats` | プロジェクトタイムライン上のクリップ位置。開始点のデフォルトは 0、終了点のデフォルトは `開始点 + 音声時間 × timing.bps`。                  |
| `add_track`    | `gain`                      | 任意の非負数値、デフォルトは 1                      | クリップおよび新しいトラックの音量係数。                                                       |
| `remove_track` | `track_id`                  | 必須文字列                            | 削除する既存トラック ID。成功後は返された新しいバージョンを使用する。                                           |

`state.timing.bps` は正数でなければならず、デフォルトは 2。`state.tracks` はトラック配列である。既存の音声クリップの `clipId` は音声 ID を参照し、`startBeats`、`endBeats`、`readStartBeats` はプロジェクトの拍単位を使用する。最も安全な編集方法は、完全な `state` を読み取り、対象トラックまたはクリップのみを変更してから、全体を `save` することである。新しい空の対象トラックには少なくとも一意の `id`、`type:"audio"`、`clips:[]` が必要である。実際に使用可能な完全な形状は、下記のステップ 5 を参照。音声分析結果の拍点をプロジェクトタイムライン座標として直接扱わないこと。

### 生成、送信、エクスポート
| `action`                             | 専用パラメータ                               | 型と条件                                  | 説明                                                                                                                                                        |
| ------------------------------------ | ---------------------------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `generate_track` / `replace_section` | `source_audio_id`                  | 必須文字列                                  | 完成済みのソース音声 ID。先にソース音声をプロジェクトに追加すると、後続の候補が対応する位置を見つけられる。                                                                                                                        |
| `generate_track` / `replace_section` | `model`                            | 必須列挙文字列                                | `chirp-v3-5`、`chirp-v4`、`chirp-v4-5`、`chirp-v4-5-plus`、`chirp-v5`、`chirp-v5-5`、`chirp-v6`、`chirp-v6-wild`、`chirp-v6-mini` から選択可能。モデルおよび操作が利用可能かどうかはタスク終端状態に従う；他のモデルへ自動的に切り替わることはない。 |
| `generate_track` / `replace_section` | `start_seconds` / `end_seconds`    | 必須数値，`0 ≤ start_seconds &lt; end_seconds` | ソース音声内の開始・終了秒数；置換時は終了点がソース音声の実際の長さを超えてはならない。これらはプロジェクト拍数ではなく、候補出力の長さも保証しない。                                                                                                         |
| `generate_track`                     | `render_audio_id`                  | 必須文字列                                  | 現在のプロジェクトを正常に `render` した後の `response.data.audio_id`。生成時のミックス参照として使用する。                                                                                                   |
| `generate_track`                     | `stem_control_tags`                | 必須文字列                                  | 新しいパートの説明。例：`add Piano`、`add Drums`、`add Bass`；固定列挙ではない。                                                                                                      |
| `generate_track`                     | `batch_size`                       | 任意の整数 1–4，デフォルト 2                          | リクエストする生成候補数。                                                                                                                                                |
| `generate_track`                     | `instrumental` / `vocal_gender`    | 任意のブール値／列挙文字列                            | `instrumental` のデフォルトは `true`；ボーカルの希望には `f`、`m`、`unspecified` を指定でき、デフォルトは `unspecified`。希望に従うかどうかは実際の音声に従う。                                                                     |
| `generate_track` / `replace_section` | `title` / `tags` / `negative_tags` | 任意の文字列                                  | 候補タイトル、希望するスタイル説明、避けたいスタイルタグ。`tags` と `negative_tags` を省略する場合は空文字列を渡す。                                                                                                  |
| `generate_track`                     | `prompt`                           | 任意の文字列                                  | 新しいパートのテキストまたは歌詞プロンプト；純粋なインストゥルメンタルでは省略可能。                                                                                                                                       |
| `replace_section`                    | `prompt` / `replacement_lyrics`    | 任意の文字列                                  | 前者は元の楽曲の歌詞またはコンテキストテキスト、後者は置換区間の新しい歌詞；省略する場合は空文字列を渡す。                                                                                                                      |
| `replace_section`                    | `fixed`                            | 任意のブール値，デフォルト `false`                       | 固定長置換をリクエストする；`true` の場合、区間は 26 秒未満である必要があり、選択したモデルが対応していない可能性がある。今回の実際の例ではデフォルトモードを使用しており、`fixed=true` は未検証。                                                                                    |
| `commit_candidate`                   | `operation_id` / `candidate_id`    | 必須文字列                                  | それぞれ生成終端状態の `data.operation_id` と、選択した `data.candidates[].id` を使用する；候補は現在のプロジェクトバージョンに属している必要がある。                                                                                    |
| `commit_candidate`                   | `track_id`                         | 必須文字列                                  | 新規トラック候補は**生成前に保存した空のトラック**にコミットする；部分置換候補は一意のソースセグメントを含む元のトラックにコミットする。                                                                                                              |
| `commit_candidate`                   | `start_beats` / `end_beats`        | 新規トラック候補でのみ任意の非負数値                           | 新しいセグメントのプロジェクトタイムライン上の位置を指定する；省略時はソースセグメントの開始点を引き継ぎ、候補の実際の長さに基づいて終了点を計算する。対象トラック内の既存セグメントと重複してはならない。**部分置換候補では必ず省略する**。                                                                                      |
| `commit_candidate`                   | `name` / `gain`                    | 新規トラック候補でのみ任意の文字列／非負数値                       | 生成セグメント名と音量係数。`gain` のデフォルトは 1。                                                                                                                                  |
| `render`                             | `title`                            | 必須文字列                                  | エクスポート音声のタイトル。                                                                                                                                                   |
| `render`                             | `lyrics` / `tags`                  | 任意の文字列                                  | エクスポート時の歌詞テキストとスタイル説明；歌詞のデフォルトは `[Instrumental]`。                                                                                                                      |
| `render`                             | `start_beats` / `end_beats`        | 任意の非負数値，終了は開始より大きい必要がある                         | エクスポートするプロジェクト拍数範囲；省略時はすべての可聴セグメントの最も早い開始点と最も遅い終了点を使用する。無音セグメントは含まれず、solo トラックが存在する場合は solo トラックのみを選択する。                                                                                             |

生成は候補のみを作成し、**自動的にプロジェクトへ追加されることはない**。`commit_candidate` は候補が引き続き現在のバージョンに属することを確認する。部分置換候補は、実際の長さが完全なソース音声または選択区間と確実に一致できる場合にのみ自動コミットできる；一致しない場合は元のプロジェクトを保持してエラーを返し、手動で拍数を推測して強引に結合することはできない。

## 2026-10-09 実際のリクエストとレスポンス

以下のリクエストボディとレスポンスフィールドは、いずれも同一プロジェクトでの実際の呼び出しから取得したものです。各 JSON グループは順に、リクエスト、受付レスポンス（非同期の場合）、タスク終端状態レスポンスです。読みやすさのため、レスポンスにはこのフローの完了に必要なフィールドのみを抜粋しています；アカウント、使用量、所要時間のフィールドは表示していません。例の ID は今回のテストアプリケーションに属するため、導入時には自分のリクエストが返した ID と新しい `Idempotency-Key` を使用する必要があります。

### 1. 空のプロジェクトを作成して取得する：`create`、`retrieve`

`create` リクエスト：

```json
{
  "action": "create",
  "title": "Suno Projects Documentation Verification 2026-10-09"
}
```

```json
{
  "success": true,
  "trace_id": "42408a82-988b-4127-ba68-9b89348a7c56",
  "data": {
    "id": "af0e104a-2a4c-40e0-9c70-7614566824a6",
    "title": "Suno Projects Documentation Verification 2026-10-09",
    "state": {
      "tracks": [],
      "timing": {
        "bps": 2
      }
    }
  }
}
```

直後に `retrieve` を呼び出す：

```json
{
  "action": "retrieve",
  "id": "af0e104a-2a4c-40e0-9c70-7614566824a6"
}
```

```json
{
  "success": true,
  "trace_id": "a335ceac-5cb7-4b1c-9773-77b9d5c84bd7",
  "data": {
    "id": "af0e104a-2a4c-40e0-9c70-7614566824a6",
    "title": "Suno Projects Documentation Verification 2026-10-09",
    "state": {
      "tracks": [],
      "timing": {
        "bps": 2
      }
    }
  }
}
```


## エラーと復旧

| 結果                                                                            | 意味                          | 次の手順                                    |
| ----------------------------------------------------------------------------- | --------------------------- | -------------------------------------- |
| `project_version_conflict` / `project_candidate_stale`（409）                   | プロジェクトのバージョンが変更された、または候補が現在のバージョンに属していない。         | 最新のプロジェクトを `retrieve` して変更を再計画する。古い候補を再実行しない。        |
| `bad_request` / `studio_state_invalid` / `studio_model_unsupported`（通常 400）   | パラメータ、トラック状態、候補の長さ、またはモデルが操作と一致しない。      | タスクの終端状態のエラーを確認し、入力を修正する。候補を安全に接続できない場合は元のプロジェクトを保持する。          |
| `studio_audio_unavailable` / `studio_access_denied` / `content_rejected`（403） | 参照音声をそのプロジェクト操作に使用できない、アクセス権がない、またはコンテンツチェックで拒否された。 | 音声ソースとタスクの `trace_id` を確認する。すでに生成された候補を、楽曲全体がエクスポート可能であることと同一視しない。 |
| `too_many_requests`（429）                                                      | リクエストがレート制限を受けている。                   | まず元のタスクを照会し、その後、新しい冪等キーで新規操作を開始するかを決定する。                |
| `studio_unavailable` / `studio_model_unavailable`（503）                        | プロジェクト処理または選択したモデルが一時的に利用できない。             | 元のタスク結果を保持する。後で明示的に再試行し、自動的にモデルを切り替えない。                |
| `studio_processing_failed` / タイムアウト（500/504）                                      | 処理に失敗した、または終端状態が不確定である。                 | `task_id` または元の冪等キーで照会し、重複課金となる生成を避ける。          |

プロジェクトと候補は、それらを作成したアプリケーションおよび実行環境に紐付けられており、アプリケーション間での再利用や自動フェイルオーバーを想定することはできません。正常にエクスポートされた最終音声 URL を永続化し、調査のために `trace_id` を保持してください。
