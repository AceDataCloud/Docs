`POST https://api.acedata.cloud/suno/projects` は、マルチトラックプロジェクトを管理するための Beta インターフェースです。`action` によって、作成、保存、候補生成、候補コミット、エクスポートを区別します。

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Idempotency-Key: <每次写操作的新 UUID>
```

`retrieve` を除き、**すべての操作で** `Idempotency-Key` が必要です。同じキーと同じリクエストの場合は元の結果のみが再読込されます。同じキーで異なるリクエストを送信した場合は 409 が返されます。有料生成でネットワークタイムアウトが発生した場合、またはコミット結果が不明な場合は、まず元のタスク ID または同じ冪等キーで照会し、直接キーを変更して再送してはいけません。

## 識別子と時間単位

| 名前                             | 取得元                                                                                      | 使用先                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| `id`                           | `create` レスポンスの `data.id`                                                                      | 現在のプロジェクトに対するすべての後続リクエスト                                      |
| `version_id`                   | 直近の `retrieve`、`save`、`add_track`、`commit_candidate` または `remove_track` の `data.version_id` | 変更、候補生成、エクスポート。最新バージョンを使用する必要があります                              |
| `audio_id` / `source_audio_id` | `upload` 終了時の `response.data.candidate.audio_id`、または既存の完了済み音声 ID                                | `add_track`、生成または置換時に元音声を参照                          |
| `render_audio_id`              | `render` 終了時の `response.data.audio_id`                                                       | `generate_track` のプロジェクトミックス参照                         |
| `operation_id`                 | `generate_track` または `replace_section` 終了時の `response.data.operation_id`                       | `commit_candidate`。通常は生成タスクの `task_id` と同じですが、戻り値を読み取る必要があります |
| `candidate_id`                 | 生成終了時の `response.data.candidates[].id`                                                       | コミットする候補を 1 つ選択                                         |
| `track_id`                     | プロジェクトの `data.state.tracks[].id`                                                                | 候補のコミットまたはトラックの削除                                        |
| `task_id`                      | 非同期操作の送信レスポンス                                                                                   | `/suno/tasks` を使用して終了状態を照会。これはプロジェクト ID ではありません                   |

`start_seconds` / `end_seconds` は**元音声内の秒数**です。`start_beats` / `end_beats` は**プロジェクトタイムライン上の拍数**です。`state.timing.bps` は 1 秒あたりの拍数で、デフォルトは 2 です。例えば、41 秒のクリップが第 0 拍から開始する場合、デフォルトの終了位置は第 82 拍です。`generate_track` の秒数範囲は生成参照を指定するために使用され、候補がその範囲のみの長さになることは保証されません。

## 操作フロー

| 順序  | `action`                             | 役割                         | 返却方法         |
| --- | ------------------------------------ | -------------------------- | ------------ |
| 1   | `create`                             | 空のプロジェクトを作成                      | 同期プロジェクトデータ       |
| 2   | `retrieve`                           | 最新バージョンと完全な `state` を取得          | 同期プロジェクトデータ       |
| 3   | `save`                               | 初回保存、または変更後の `state` 全体を保存      | 同期プロジェクトデータ       |
| 4   | `upload`                             | HTTPS 音声アドレスから素材を作成           | 非同期タスク         |
| 5   | `add_track`                          | 素材音声をプロジェクトに配置                  | 非同期タスク、バージョン更新    |
| 6   | `save`                               | 新しいトラック候補を受け取る必要がある場合、先に空のターゲットトラックを保存        | 同期プロジェクトデータ、バージョン更新  |
| 7   | `render`                             | 現在聴取可能なトラックをエクスポートし、ミックス参照 `audio_id` を取得 | 非同期タスク         |
| 8   | `generate_track` または `replace_section` | それぞれ新しいトラック候補または部分置換候補を生成            | 非同期タスク、プロジェクトはまだ変更しない  |
| 9   | `commit_candidate`                   | 1 つの候補を選択してコミット                  | 非同期タスク、成功後にバージョン更新 |
| 任意  | `remove_track`                       | 指定したトラックを削除                     | 同期プロジェクトデータ、バージョン更新 |

部分置換のみを行う場合は、使用可能な元音声が既にあればよく、先に `render` を行う必要はありません。元音声がすでにプロジェクト内にある場合は、`upload` と `add_track` も省略できます。`render_audio_id` は `generate_track` の必須参照にすぎません。

非同期操作の送信時には、まず `{ "task_id": "...", "trace_id": "..." }` が返されますが、**生成成功を意味するものではありません**。ポーリング：

```http
POST /suno/tasks
Content-Type: application/json

{"action":"retrieve","id":"上一步返回的 task_id"}
```

タスクレコードに `finished_at` があり、かつその中の `response.success` が `true` である場合にのみ成功と見なされます。`response.success=false` の場合は `response.error` を読み取ってください。`save` には `task_id` が含まれる場合がありますが、このインターフェース内では同期的に完了します。`upload`、`render`、`generate_track`、`replace_section` はプロジェクトバージョンを変更しません。`save`、`add_track`、`commit_candidate`、`remove_track` が成功した後は、新しい `version_id` を取得する必要があります。

## リクエスト規約

| パラメータ                | 型と適用範囲                                                                                   | 説明                                                              |
| ----------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `action`          | 必須文字列                                                                                     | 本ページに記載された操作名のいずれかに固定されます。1 回のリクエストで実行できる操作は 1 つのみです。                                      |
| `id`              | `create` を除き必須文字列                                                                         | プロジェクト ID。`create.data.id` から取得します。                                      |
| `version_id`      | 変更、候補生成、エクスポート時に必須文字列。初回の空プロジェクト `save` では省略可能                                                         | 最新バージョンを使用します。古いバージョンは拒否されます。`retrieve` には不要です。                                 |
| `Idempotency-Key` | `retrieve` を除き必須リクエストヘッダー、1～128 文字                                                              | 新しい操作ごとに新しいキーを使用します。同じキーと同じリクエストでは元の結果が再読込され、再生成や課金は行われません。                                   |
| `async`           | `upload`、`add_track`、`generate_track`、`replace_section`、`commit_candidate`、`render` で任意のブール値 | これらの操作は常に非同期です。`false` でも生成が同期に変わることはありません。                                    |
| `callback_url`    | 非同期操作で任意の URL                                                                                | 終了状態の通知を受け取ります。省略した場合は、`task_id` に基づいて `/suno/tasks` を照会します。引き続き `response.success` を確認する必要があります。 |

以下の例では、各操作間の ID とバージョンの受け渡しを連続して示します。レスポンスには現在の手順に関連するフィールドのみを記載しています。統合時には、現在のアプリケーションのレスポンス値でサンプル ID を置き換えてください。

## プロジェクト状態を保存

| パラメータ | 型と説明 |
|---|---|
| `state` | 必須オブジェクト。部分的なパッチではなく、**完全なプロジェクト状態**を送信します。直近の読み取りまたは変更操作で返された `data.state` を基にし、不明なフィールドを保持してください。 |
| `title` | 任意の文字列。省略時は `state.title` を引き継ぎ、それもない場合はデフォルトタイトルを使用します。 |
| `version_id` | 初回保存で新しい空のプロジェクトを作成する場合は省略できます。それ以降は最新バージョンを使用する必要があります。 |

`state.timing.bps` は正の数である必要があり、デフォルトは 2 です。`state.tracks` はトラック配列です。既存のオーディオクリップの `clipId` はオーディオ ID を参照し、`startBeats`、`endBeats`、`readStartBeats` はプロジェクト拍単位を使用します。最も安全な編集方法は、完全な `state` を読み取り、対象のトラックまたはクリップのみを変更してから、全体を `save` することです。新しい空の対象トラックには、少なくとも一意の `id`、`type:"audio"`、`clips:[]` が必要です。完全な空トラック構造については、「新しいオーディオトラックを生成」の例を参照してください。オーディオ分析結果内の拍点を、プロジェクトタイムライン座標として直接使用しないでください。

## オーディオをアップロードしてトラックを追加

| 操作 | パラメータ | 型と説明 |
|---|---|---|
| `upload` | `audio_url` | 必須の HTTPS URL。公開アクセス可能で、かつ使用権限を持つオーディオを指します。終態の `candidate.audio_id` はトラック追加に使用できます。 |
| `add_track` | `audio_id` | 必須文字列。URL ではなく、完了済み素材のオーディオ ID です。 |
| `add_track` | `name`、`color` | 任意の文字列。トラック名はデフォルトでオーディオタイトルを使用し、色は `#RRGGBB` を推奨、デフォルトは `#7251F7` です。 |
| `add_track` | `title` | 任意の文字列。同時にプロジェクトタイトルも変更します。通常は省略します。 |
| `add_track` | `start_beats`、`end_beats` | 任意の非負数。終点は始点より大きくなければなりません。デフォルトでは第 0 拍から開始し、終点はオーディオの長さと `timing.bps` に基づいて計算されます。 |
| `add_track` | `gain` | 任意の非負数。デフォルトは 1。クリップおよびトラックの音量係数です。 |

## 新しいオーディオトラックを生成

候補は生成時のプロジェクトバージョンに紐づきます。まず候補を受け取る空のトラックを保存し、次に現在のミックスを生成用参照としてエクスポートします。生成完了後、候補を 1 つ選んでその空トラックに送信します。

### 対象トラックを予約：`save`

`generate_track` の候補は現在のプロジェクトバージョンに紐づきます。前の `add_track` 終態で返された**完全な** `state` に、次の空トラックを `state.tracks` へ追加してから、`save` で保存します。他の既存フィールドはそのまま保持してください：
```

"type": "audio",
"name": "Generated piano",
"clips": [],
"takeLanes": [],
"mute": false,
"solo": false,
"amplitude": 1,
"instrument": &#123;
"type": "song"
&#125;,
"color": "#7251F7"
&#125;

```

### 候補を生成：`generate_track`

毎回、固定で 2 つの候補として送信する。

| パラメータ | 型と説明 |
|---|---|
| `source_audio_id` | 必須；完了済みのソースオーディオ ID。まずソースオーディオをプロジェクトに追加し、その後に候補の位置を決定できる。 |
| `render_audio_id` | 必須；上記 `render` の終状態にある `response.data.audio_id` であり、オーディオ URL ではない。 |
| `model` | 必須；`chirp-v3-5`、`chirp-v4`、`chirp-v4-5`、`chirp-v4-5-plus`、`chirp-v5`、`chirp-v5-5`、`chirp-v6`、`chirp-v6-wild`、`chirp-v6-mini` から選択可能。具体的な組み合わせが利用可能かどうかはタスク終状態を基準とする。 |
| `start_seconds`、`end_seconds` | 必須の数値、`0 ≤ start_seconds < end_seconds`；ソースオーディオ内の秒数区間であり、プロジェクトの拍数ではなく、出力の長さも保証されない。 |
| `stem_control_tags` | 必須文字列；`add Piano`、`add Drums`、`add Bass` などの追加パートの説明であり、固定列挙ではない。 |
| `instrumental`、`vocal_gender` | 任意；インストゥルメンタルのデフォルトは `true`、ボーカルの好みには `f`、`m`、`unspecified` を指定でき、デフォルトは `unspecified`。 |
| `title`、`tags`、`negative_tags`、`prompt` | 任意文字列；それぞれ候補タイトル、期待するスタイル、避けるスタイル、新しいパートのテキストまたは歌詞プロンプト。 |

```

&#123;
"action": "generate_track",
"id": "af0e104a-2a4c-40e0-9c70-7614566824a6",
"version_id": "cb0a82c9-aa5b-48cc-9395-0528675fc18d",
"source_audio_id": "b21be571-bfe4-47c1-b59c-2abc55c6f9c3",

### 候補を採用：`commit_candidate`

| パラメータ | 型と説明 |
|---|---|
| `operation_id` | 必須；生成タスク終態の `data.operation_id`。 |

## 既存クリップの置換

`replace_section` は、先にミックスをエクスポートすることなく、既存の元音声を直接使用できます。生成では候補のみが返されます；コミット時には、一意の元クリップを含む元のトラックを選択します。

| パラメータ | 型と説明 |
|---|---|
| `source_audio_id` | 必須；置換する完了済み元音声 ID。 |
| `model` | 必須；「候補を生成」で列挙されている公開モデルを使用し、モデルと操作の利用可能性はタスク終態に従います。 |

| `title`、`tags`、`negative_tags` | 任意の文字列；候補タイトル、期待するスタイル、避けるスタイル。 |
| `fixed` | 任意のブール値、デフォルトは `false`；`true` に設定する場合、区間は 26 秒未満でなければならず、モデルが対応していない可能性があります。 |

## エラーと復旧

| 結果 | 意味 | 次の手順 |
|---|---|---|
| `project_version_conflict` / `project_candidate_stale`（409） | プロジェクトのバージョンが変更されたか、候補が現在のバージョンに属していません。 | `retrieve`：最新のプロジェクトで変更を再計画し、古い候補を再生しないでください。 |
| `bad_request` / `studio_state_invalid` / `studio_model_unsupported`（通常は 400） | パラメータ、トラックの状態、候補の長さ、またはモデルが操作と一致していません。 | タスクの終端状態のエラーを確認して入力を修正してください。候補を安全に結合できない場合は、元のプロジェクトを保持してください。 |
| `studio_audio_unavailable` / `studio_access_denied` / `content_rejected`（403） | 参照オーディオをこのプロジェクト操作で使用できない、アクセス権がない、またはコンテンツチェックで拒否されています。 | オーディオのソースとタスクの `trace_id` を確認してください。生成済みの候補を、楽曲全体としてエクスポート可能なものと同一視しないでください。 |
| `too_many_requests`（429） | リクエストがレート制限されています。 | まず元のタスクを照会し、その後、新しい冪等キーで新しい操作を開始するかどうかを決定してください。 |
| `studio_unavailable` / `studio_model_unavailable`（503） | プロジェクト処理または選択したモデルが一時的に利用できません。 | 元のタスク結果を保持してください。後で明示的に再試行し、モデルを自動的に切り替えないでください。 |
| `studio_processing_failed` / タイムアウト（500/504） | 処理に失敗したか、終端状態が不明です。 | `task_id` または元の冪等キーで照会し、重複課金となる生成を避けてください。 |

プロジェクトと候補は、それらを作成したアプリに紐付けられています。元のアプリを使用してアクセスしてください。正常にエクスポートされた最終オーディオ URL を永続化し、トラブルシューティングのために `trace_id` を保持してください。
