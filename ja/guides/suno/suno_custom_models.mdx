専用音楽モデルは、6～24曲の許諾済み音声から一貫した音楽的特徴を学習し、その後の楽曲制作に使用できます。作成は非同期操作です。より安定した効果を得るには、スタイルが一貫し音質が明瞭な24曲の音声を使用することを推奨します。

> モデル作成およびその後の生成について、合法的な使用権を所有している、または許諾を取得している音声のみを送信できます。許可を得ていない音楽または音声素材をアップロードしないでください。

## モデルの作成

`POST /suno/custom-models` を呼び出し、`action=create` を設定します。

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

API は直ちにプラットフォームモデル ID とタスク ID を返します。作成が完了すると、コールバックまたは照会結果の `status` は `ready` に変わります。モデルの作成に成功した場合にのみ **10 Credits** が課金されます。作成に失敗した場合は課金されません。

## モデルの照会

単一モデルを照会します。

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

現在のアプリケーションのモデルをページネーションで照会します。

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

すべてのモデルは、それを作成した Suno アプリケーションに帰属します。API 認証情報をローテーションしてもモデルの帰属は変わらず、他のアプリケーションはそのモデルを照会または使用できません。

## モデルを使用した楽曲生成

モデルのステータスが `ready` になった後、引き続き `POST /suno/custom-models` を呼び出し、`action=generate` を設定します。

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id` は、現在のアプリケーション配下でステータスが `ready` の専用音楽モデルでなければなりません。モデルが利用できない場合、リクエストは失敗し、他のモデルに自動的に切り替えられることはありません。`persona_id` と専用音楽モデルは相互排他的です。同時に送信した場合、API はリクエストが生成サービスに送信される前に HTTP 400 を返し、課金は発生しません。Persona を使用する必要がある場合は、`/suno/audios` の `artist_consistency` または `artist_consistency_vox` 操作を使用してください。

楽曲生成に成功すると **0.90 Credits** が消費されます。生成に失敗した場合は課金されません。モデルの照会およびアーカイブは無料です。

## モデルのアーカイブ

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

現在の Beta バージョンでは、モデルはアーカイブされ、以後の使用が禁止されます。レスポンス内の `capacity_released=false` は、アーカイブによってモデル容量が解放されることは保証されないことを示します。アーカイブ操作は繰り返し呼び出すことができ、重複して課金されることはありません。
