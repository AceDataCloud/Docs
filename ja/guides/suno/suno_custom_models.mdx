専用音楽モデルは、6から24の許可された音声から一貫した音楽の特徴を学習し、その後の曲作りに使用されます。作成は非同期操作です；24曲のスタイルが一致し、音質が明瞭な音声を使用することをお勧めします。

> あなたが合法的に使用権を持っている、またはモデルの作成およびその後の生成の許可を取得した音声のみを提出してください。許可のない音楽や音声素材をアップロードしないでください。

## モデルの作成

`POST /suno/custom-models`を呼び出し、`action=create`を設定します。ユニークな`Idempotency-Key`リクエストヘッダーを同時に送信することをお勧めします；ネットワークの再試行時に同じキーを再利用し、重複作成を避けます：

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

インターフェースはすぐにプラットフォームモデルIDとタスクIDを返します。作成が完了すると、コールバックまたは結果の`status`が`ready`に変わります。モデルの作成が成功した場合のみ料金が発生し、作成に失敗した場合は料金は発生しません。

## モデルの照会

単一モデルを照会：

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

現在のアプリケーションのモデルをページング照会：

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

すべてのモデルは、それを作成したSunoアプリに属します。API資格情報のローテーションはモデルの帰属を変更せず、他のアプリはそのモデルを照会または使用できません。

## モデルを使用して曲を生成

モデルの状態が`ready`になった後、引き続き`POST /suno/custom-models`を呼び出し、`action=generate`を設定します：

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id`は現在のアプリケーション下で状態が`ready`の専用音楽モデルでなければなりません。モデルが使用できない場合、リクエストは失敗し、他のモデルに自動的に切り替わることはありません。

## モデルのアーカイブ

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

現在のベータ版では、モデルがアーカイブされ、使用が禁止されます。応答の`capacity_released=false`は、アーカイブがモデルの容量を解放することを約束しないことを示します。アーカイブ操作は繰り返し呼び出すことができ、重複して料金は発生しません。
