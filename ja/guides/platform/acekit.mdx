おそらくこんな状況に遭遇したことがあるでしょう：Claude Code、Cursor、または Codex を使っていて、コードを書いている最中に、突然 1 枚の画像、BGM、短い動画が必要になったり、ついでに最新情報を調べてもらいたくなったりする。すると気づく——agent 自体はそれらをできない。自分で API を探し、ドキュメントを読み、key を設定し、呼び出しコードを書き、非同期ポーリングを処理しなければならず、一連の手間を終える頃には、インスピレーションはとっくに冷めている。

[AceKit](https://github.com/AceDataCloud/AceKit) は、この一連の手間を丸ごと省くためのものです。1 行のコマンドで、AceData Cloud 上の画像生成、動画生成、音楽生成、ウェブ検索、LLM 対話などの機能を、まとめてあなたのコーディング agent に導入します。導入後はそのまま自然言語で指示するだけで、agent が自ら対応するスキルを読み込み、自ら認証し、自らポーリングして、作業を完了します。

## 30 秒でわかる、何をするものか

導入前 vs 導入後：

| あなたの指示               | 導入前                   | 導入後（agent が自ら実行）                      |
| ------------------ | --------------------- | ----------------------------------- |
| "この README に表紙画像を付けて" | agent にはできず、自分で画像生成 API を探す必要がある | NanoBanana / Flux / Midjourney を呼び出して画像生成 |
| "このスクリプトを 30 秒の短編動画にして"  | できない                    | Sora / Veo / Kling / Seedance を呼び出して動画生成  |
| "この demo に BGM を付けて"  | できない                    | Suno を呼び出して音楽生成                           |
| "最新の X を検索して要約して"     | インターネットに接続できない                  | Google SERP を呼び出してリアルタイム結果を取得                 |
| "この長いリンクを短縮して"         | できない                    | 短縮リンクサービスを呼び出して surl.id リンクを返す                  |

一言で言えば：**あなたのコーディング agent は「コードを書くことしかできない」状態から、「画像生成、動画生成、音楽生成、ウェブ検索もできる」状態になります。**

## 3 ステップで始める

全体の流れは数分で完了し、Node.js 18+ が必要です。

**ステップ 1 · API Token を取得する。** [コンソール](https://platform.acedata.cloud/console/applications) で Token をコピーします——すべての機能でこの 1 つを共用し、初回申請時には無料クレジットが付与されるため、まずは無料で試せます。

![コンソールで API Token をコピー](https://cdn.acedata.cloud/dvc3cg.jpg)

**ステップ 2 · インストールする。** 1 行のコマンド：

```bash
npx acekit
```

これはマシン上のコーディング agent を自動検出し、スキル一式を導入します。実際の実行はこのようになります（このマシンには Claude Code のみがインストールされています）：

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> Token が設定されていない場合、初回実行時に対話形式で貼り付けを求められます；事前に `export ACEDATACLOUD_API_TOKEN=あなたのtoken` を設定して、完全無人でインストールすることもできます。スキル数はプラットフォーム機能の追加に伴って変動するため、`npx acekit list` に表示される現在の一覧を基準にしてください。

**ステップ 3 · 自然言語で指示する。** agent を一度リロードしてから、直接指示します。たとえば：

```text
short-url スキルで https://platform.acedata.cloud/services を短縮して
```

agent は自らスキルを読み込み、自ら呼び出しを実行し、実際にアクセス可能な結果を返します。

## 実際に一度実行してみる（出力付き）

以下の 4 つの例はすべて**実際の呼び出しで、その場で返された結果**であり、例示ではありません。コマンド内の `$KEY` はあなたの API Token です。

**① URL を短縮する（同期、即時応答）**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

`https://surl.id/r/1uKp2kilXQ` が返されます——開くと 302 で元の services ページへリダイレクトされます。

**② ウェブ検索（同期）**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

リアルタイムの Google 検索結果を取得します（抜粋）：

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ LLM 対話（同期、1 つのインターフェースで 50+ モデルに接続）**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP は、モデルのコンテキスト情報を統一的に管理・交換するためのプロトコルです。
（39 tokens、今回は約 0.00007 credit）
```

**④ 画像生成（非同期、約 20 秒、agent が画像生成まで自動ポーリング）**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

約 22 秒後に実際の画像が返されます（HTTP 200 · image/png · 317 KB · 今回は約 0.13 credit）：

![AceKit が実際に生成した画像](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

これらのインターフェースを覚える必要はありません——スキルを導入すれば、agent がそれぞれの `SKILL.md` に従って、正しいリクエストを自ら組み立て、認証とポーリングを処理します。上記はあくまで「裏側で何をしているか」をあなたに見せるためのものです。

## 実際には何をインストールするのか

AceKit は AceData の開発者ツール全体への「正面玄関」であり、現在 1 回のインストールで導入されるのは**スキルツールセット（Skills）**です：

- **一連の Agent スキル**：各スキルは、あらかじめ作成された `SKILL.md` 操作マニュアルです——認証、非同期ポーリング、エラー再試行、パラメータの設定方法まですべて明記されており、agent はそれに従って実行するだけです。`npx acekit list` を実行して現在の一覧を確認できます（この記事執筆時点では 19 個で、継続的に増加中）：
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **Token を統一**：1つの `ACEDATACLOUD_API_TOKEN` ですべての機能を利用でき、実際の使用量に応じて課金されます。

機能別の分類（`npx acekit list` に準拠）：

| 種類         | 提供元                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ 画像生成      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 動画生成      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 音楽 / 音声生成 | Suno · Producer · Fish Audio（TTS）                    |
| 💬 LLM 対話   | 50+ モデルの統一インターフェース（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 検索       | Google SERP（ウェブ · 画像 · ニュース · 地図 · 動画）                  |
| 🔗 ツール       | 短縮URL · 顔処理                                            |

> 同じこれらの機能について、AceData は個別の **MCP サーバー**（Suno、Midjourney、Sora、SERP… は PyPI / VS Code / Smithery / Docker に公開済み）、**コマンドライン CLI**、および **Python / TypeScript SDK** も提供しており、必要に応じて個別に利用できます。AceKit v0.2 では、`acekit add <name>` による単一機能のインストール、および各 agent の MCP 設定への自動書き込みをサポートする予定です。

## 対応 Agent

| Agent                        | スキルのインストール先                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode など | `~/.agents/skills`（あなたの agent がここを参照するようにしてください） |

インストール時、AceKit はマシンにインストール済みの agent を自動検出し、検出されたものにのみインストールします。

## おまけ：同じ Token で Claude Code 自体を動かす

AceData のインターフェースは Anthropic の `/v1/messages` 形式にも対応しているため、**Anthropic 公式サブスクリプションは不要**です。同じ AceData Token で Claude Code を動かせます。プロジェクトのルートディレクトリに `.claude/settings.local.json` を作成します：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Claude Code を再起動するだけで——Claude 全モデルシリーズを使えるだけでなく、AceKit を通じて画像生成・動画生成・音楽生成の「手」も手に入ります。詳細は [Claude Code 統合ガイド](https://platform.acedata.cloud/documents/claude-code-integration) をご覧ください。
