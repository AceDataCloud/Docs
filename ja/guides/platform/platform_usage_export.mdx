現在のアカウントの API 呼び出し明細を CSV として直接ダウンロードします。財務照合、オフライン分析、または大量の記録の保存に適しています。ページ上で少数の明細のみを確認する場合は、先に[呼び出し記録リスト](https://platform.acedata.cloud/documents/platform-usage-list)をご利用ください。

呼び出し記録と請求サマリーの照会範囲は直近 60 日間です。リクエストおよびレスポンス本文は、直近 30 日間のみ個別に保持されます。本文の期限切れは、その記録の実際の課金、使用量、または集計統計を変更しません。

## 準備作業

1. [AceDataCloud プラットフォーム](https://platform.acedata.cloud)にログインします。
2. [Account Token コンソール](https://platform.acedata.cloud/console/platform-tokens)でアカウントトークンを作成し、直ちにパスワードマネージャーまたは Secret Manager に保存します。
3. 必要に応じて、[サービス申請リスト](https://platform.acedata.cloud/documents/platform-application-list)、[API 認証情報リスト](https://platform.acedata.cloud/documents/platform-credential-list)、または[API リスト](https://platform.acedata.cloud/documents/platform-api-list)からフィルター ID を取得します。

トークンの完全な説明については、[アカウントトークンの管理](https://platform.acedata.cloud/documents/platform-token)をご覧ください。アカウントトークンと業務 API を呼び出すための Credential は混用できません。

```shell
export PLATFORM_TOKEN='あなたのアカウントトークン'
```

## API 概要

| 項目          | 内容                                                         |
| ----------- | ---------------------------------------------------------- |
| メソッド        | `GET`                                                      |
| URL         | `https://platform.acedata.cloud/api/v1/usage/apis/export/` |
| 認証          | `Authorization: Bearer ${PLATFORM_TOKEN}`                  |
| OAuth Scope | `usage:read`（`platform:read` / `platform` に展開して含まれる）           |
| レスポンス      | `200 text/csv; charset=utf-8`                              |
| ファイル名      | `usages.csv`                                               |

この API は CSV を同期的にストリーミングで返し、エクスポートタスクを作成せず、JSON やダウンロードリンクも返しません。開始時刻と終了時刻の両方が提供されない場合にのみ、現在の暦月の開始から現在時刻までの記録をデフォルトでエクスポートします。片側の境界のみを指定した場合、もう一方が当月の境界で自動補完されることはありません。

## クエリパラメータ

| パラメータ              | 型       | 必須  | デフォルト | 説明                         |
| ----------------- | -------- | --- | ------ | -------------------------- |
| `perspective`     | string   | いいえ | `both` | `billing`、`actor` または `both` |
| `service_id`      | UUID     | いいえ | —      | サービスでフィルター；繰り返しパラメータ対応               |
| `application_id`  | UUID     | いいえ | —      | Application でフィルター；繰り返しパラメータ対応    |
| `api_id`          | UUID     | いいえ | —      | API でフィルター；繰り返しパラメータ対応            |
| `credential_id`   | UUID     | いいえ | —      | API 認証情報でフィルター；繰り返しパラメータ対応          |
| `status_code`     | integer  | いいえ | —      | 繰り返しまたはカンマ区切りの値をサポート                 |
| `created_at_from` | datetime | いいえ | —      | ISO 8601 の開始時刻              |
| `created_at_to`   | datetime | いいえ | —      | ISO 8601 の終了時刻              |

エクスポート範囲は常に、現在のアカウントが支払主体および/または実際の呼び出し元として閲覧できる記録に制限され、アカウントをまたぐエクスポートはサポートされません。

## リクエスト例

現在の月の CSV を直接保存する場合：

```shell
curl --fail-with-body --location \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

Application、時刻、ステータスコードでエクスポートする場合：

```shell
export APPLICATION_ID='あなたの Application ID'

curl --fail-with-body --get \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'status_code=200,500' \
  --data-urlencode 'created_at_from=2026-09-01T00:00:00Z' \
  --data-urlencode 'created_at_to=2026-09-08T00:00:00Z' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

Python でストリーミング保存し、完全性を確認する場合：

```python
import os
from pathlib import Path

import requests

url = "https://platform.acedata.cloud/api/v1/usage/apis/export/"
headers = {"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"}
params = {
    "created_at_from": "2026-09-01T00:00:00Z",
    "created_at_to": "2026-09-08T00:00:00Z",
    "perspective": "both",
}
output = Path("usages.csv")

with requests.get(url, headers=headers, params=params, stream=True, timeout=120) as response:
    response.raise_for_status()
    if not response.headers.get("content-type", "").startswith("text/csv"):
        raise RuntimeError("サーバーが CSV を返しませんでした")
    with output.open("wb") as file:
        for chunk in response.iter_content(chunk_size=64 * 1024):
            file.write(chunk)

last_line = output.read_text(encoding="utf-8").splitlines()[-1]
if last_line.startswith("# truncated:") or last_line.startswith("# error:"):
    raise RuntimeError(f"エクスポートが不完全です：{last_line}")
```

## CSV 列

CSV ヘッダーの順序は次のとおり固定されています：

```text
Usage ID,API,Status Code,Deducted Amount,Original Amount,Trace ID,Created At
```

| 列                 | 説明                         |
| ----------------- | -------------------------- |
| `Usage ID`        | 呼び出し記録 ID                    |
| `API`             | API タイトル；一致しない場合は API ID または空値になる可能性があります |
| `Status Code`     | HTTP ステータスコード                   |
| `Deducted Amount` | 最終的に実際に差し引かれたクォータ                   |
| `Original Amount` | アプリケーション割引前の元のクォータ                 |
| `Trace ID`        | リクエスト追跡識別子                     |
| `Created At`      | 記録作成時刻、ISO 8601            |

クォータの単位は、対応する Application の `service.unit` によって決まります。

## エクスポートが完全かどうかの判定

1 回につき最大 1,000,000 件のデータを出力します。サーバーが CSV の返却を開始した後は、中途エラーを別の HTTP ステータスに変更できないため、クライアントは最後の行を確認する必要があります：

- `# truncated:`：行数の上限に達しました；より小さい時間枠に分割してエクスポートしてください。
- `# error:`：ストリーミング読み取りが中断されました；範囲を縮小して再エクスポートしてください。

照合プログラムは、いずれかの marker を検出した場合、必ずファイルを不完全として扱う必要があり、黙って計上してはいけません。

## エラーと再試行

| 状況                          | 対処方法                                  |
| --------------------------- | ------------------------------------- |
| `400 usage_history_expired` | レスポンス内の `available_from` を使用して直近 60 日間の範囲内に調整する |
| `401 not_authenticated`     | Account Token が存在し、正しく、削除されていないか確認する          |
| CSV 以外のレスポンス                    | 成功ファイルとして保存しない；先にエラーレスポンスを読み、リクエストを修正する                |
| ダウンロードの中断または marker                | 時間枠を縮小し、バックオフ戦略を使用して再エクスポートする                     |
