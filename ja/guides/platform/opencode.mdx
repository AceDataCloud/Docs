OpenCode の Coding Plan モデル Provider、IDE Extension と MCP は三つの独立した能力です。IDE Extension はローカル OpenCode runtime に接続し、同一の Provider 設定を再利用します；これはホストエディタが Ace Data Cloud をネイティブにサポートしていることを示すものではありません。

| ルート                            | 説明                                                      | リンク                                                                                    | 状態      |
| ----------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------- |
| Terminal / CLI / TUI Provider | `opencode.json[c]` と Chat Completionsを使用                | [Provider 設定](https://platform.acedata.cloud/documents/opencode-terminal-integration) | 検証済み設定契約 |
| IDE Extension                 | VS Code、Cursor、Windsurf、VSCodium などのホストが OpenCode runtime に接続 | [IDE 設定](https://platform.acedata.cloud/documents/opencode-ide-integration)           | 実験的     |
| MCP                           | OpenCode 内でリモートツールを呼び出す                                      | [MCP 概要](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | 独立した能力    |

Provider 設定が成功した後、IDE Extension は同じ Provider とモデルを使用する必要があります。IDE 内でのチャット、ファイル読み取り、編集およびツール呼び出しはそれぞれ検証する必要があり、CLI の一度の普通のリクエストをすべての IDE 能力に自動的に外挿すべきではありません。

モデル ID は [リアルタイムディレクトリ](https://platform.acedata.cloud/models) に基づきます。
