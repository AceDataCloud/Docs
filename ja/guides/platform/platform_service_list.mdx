現在のサイトで表示可能な Service カタログをページネーションで返します。サービス種別、表示情報、無料枠、プラン、および関連する API/Proxy ID を含みます。サービスマーケットプレイスの構築や、申請するサービスの選択に適しています。

## API 概要

| 項目   | 内容                                                |
| --- | ------------------------------------------------- |
| メソッド  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| 認証  | 公開；ログイン状態では `applied` のみが現在のアカウントを反映                        |
| ページネーション  | `count` + `items`                                 |

## クエリパラメータ

| パラメータ               | 型      | 必須  | 説明                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | いいえ   | サービス ID でフィルタリング；繰り返しパラメータをサポート         |
| `private`        | boolean | いいえ   | 公開状態でフィルタリング；サイトの可視性ルールは引き続き適用      |
| `type`           | string  | いいえ   | サービス種別；繰り返しパラメータをサポート              |
| `tag`            | string  | いいえ   | タグでフィルタリング                    |
| `include_facets` | boolean | いいえ   | `true` の場合、現在のサイトで利用可能な種別/タグの統計を追加 |
| `limit`          | integer | いいえ   | 1 ページあたりの件数、最大 100              |
| `offset`         | integer | いいえ   | ページネーションのオフセット                    |
| `ordering`       | string  | いいえ   | `rank` または `-rank` のみサポート     |

一覧は `alias` によるフィルタリングをサポートしていません；既に alias がある場合は直接 `/api/v1/services/{alias}` をリクエストしてください。`applied_count`、`updated_at` は許可されているソートフィールドではありません。

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## レスポンスの説明

レスポンスは `{count, items}` です；`include_facets=true` の場合にのみ `facets` が追加されます。サービス項目には、`id`、`alias`、`title`、`description`、`type`、`applied_count`、`free_amount`、`unit`、`private`、`need_verify`、`rank`、`tags`、`thumbnail`、`doc_url`、`demo_url`、`api_ids`、`proxy_ids`、`cost`、`packages` などの現在公開されているフィールドが含まれます。

匿名の一覧における `applied` は、特定のアカウントの申請状態を表すものではありません。アカウント関連の状態が必要な場合は、有効なログイン状態を使用し、最終的な基準として[サービス申請一覧](https://platform.acedata.cloud/documents/platform-application-list)を参照してください。
