Inferpal は Visual Studio 2022/2026 向けの拡張機能で、公式に OpenAI 互換サービスへの接続をサポートしています。拡張版は編集、ツール呼び出し、使用量記録に影響を与える可能性があります。初回接続時は固定バージョンを使用し、以下の最小検証を完了してください。

## 設定

1. Visual Studio Marketplace または公式リポジトリから Inferpal をインストールします。
2. Inferpal の **Settings → Connection** を開きます。
3. Provider を OpenAI-compatible に選択します。
4. Base URL に `https://api.acedata.cloud/v1` を入力します。
5. API Key にあなたの Ace Data Cloud API Token を入力します。
6. Model にモデルディレクトリ内で Chat Completions をサポートする正確なモデル ID を入力します。
7. 保存後に `Reply only OK` を送信し、再度コードコンテキストを含むリクエストを実行します。

## 現在の境界

- 本ガイドは Inferpal のみをカバーしており、Visual Studio 内蔵の Copilot や他の拡張が同じフィールドをサポートしていることを示すものではありません。
- 異なるバージョンは Base URL に自動的にパスを追加する場合があります。リクエストが失敗した場合は、最終的なリクエストが Chat Completions endpoint に該当するかを確認してください。
- 固定バージョンの E2E を完了するまで、すべての編集、補完、またはツール呼び出しモードが利用可能であることを保証しません。
