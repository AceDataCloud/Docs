title: "AceDataCloud プラットフォームの実行設定を取得"

現在のリクエストコンテキストにおける公開機能フラグと国/地域判定を読み取ります。フロントエンドの起動時に機能を表示するかどうかを決定するのに適しています；これはサイトブランド、連絡先情報、またはお知らせディレクトリではありません。

## API 概要

| 項目   | 内容                                              |
| --- | ----------------------------------------------- |
| メソッド  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| 認証  | 公開；ログイン状態を伴う場合、一部の機能フラグはユーザーごとに計算される可能性があります                          |

## クエリパラメータとリクエストヘッダー

| 名前                    | 場所     | 説明                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | 機能フラグの上書き式；クライアントによる上書きが許可されたフラグ、またはスーパー管理者にのみ有効 |
| `X-Feature-Overrides` | header | `features` と同じ上書き元           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## 実際のレスポンス構造

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| フィールド         | 型            | 説明                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | 現在のリクエストで表示可能な機能フラグ；キーはプラットフォーム設定に応じて変更されるため、クライアントは必要に応じて読み取り、欠落したキーには安全なデフォルト値を設定する必要があります |
| `region`   | string / null | リクエスト IP に基づいて検出された国または地域コード、小文字；識別できない場合は `null`        |

この API からサイト名、CDN、通貨、言語、カスタマーサービスの連絡先情報、またはお知らせを読み取らないでください；これらのフィールドは現在のレスポンス契約に含まれていません。

## 使用上の推奨事項

- 機能フラグはユーザー、フィンガープリント、およびサイトコンテキストに応じて計算されるため、ユーザー間で長期間キャッシュを共有しないでください。
- 地域セレクターの選択はフロントエンドにのみ保存され、表示時には選択済みの地域を優先して使用し、そうでない場合はこの API の `region` を使用します。この API は地域上書きパラメータを受け付けません。
- 認識されない query パラメータは無視されます；このページに記載されているパラメータのみを使用してください。
