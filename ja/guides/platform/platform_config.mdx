現在のリクエストコンテキストにおける公開機能フラグと国/地域判定を読み取ります。フロントエンド起動時に機能を表示するかどうかを決定するのに適しています。これはサイトのブランド、連絡先情報、またはお知らせディレクトリではありません。

## API 概要

| 項目   | 内容                                              |
| --- | ----------------------------------------------- |
| メソッド  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| 認証  | 公開；ログイン状態を伴う場合、一部の機能フラグはユーザーごとに計算される可能性があります                          |

## クエリパラメータとリクエストヘッダー

| 名前                    | 場所     | 説明                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | 2 文字の ASCII 国コード；レスポンス内の表示国を上書きするために使用し、サーバー側のセキュリティ判定は変更しません |
| `features`            | query  | 機能フラグ上書き式；クライアントによる上書きが許可されたフラグまたはスーパ管理者に対してのみ有効        |
| `X-Feature-Overrides` | header | `features` と同じ上書きソース                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## 実際のレスポンス構造

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| フィールド         | 型            | 説明                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | 現在のリクエストで表示可能な機能フラグ；キーはプラットフォーム設定に応じて変化するため、クライアントは必要に応じて読み取り、欠落したキーには安全なデフォルト値を設定する必要があります |
| `country`  | string / null | 小文字の国コード；識別できない場合は `null` となる可能性があります                     |

本 API からサイト名、CDN、通貨、言語、カスタマーサポート連絡先、またはお知らせを取得しないでください；これらのフィールドは現在のレスポンス契約に含まれません。

## 使用上の推奨事項

- 機能フラグはユーザー、フィンガープリント、およびサイトコンテキストに応じて計算されるため、ユーザー間で長期間キャッシュを共有しないでください。
- クライアントから渡される `country` は返り値にのみ影響し、サーバー側の地域またはセキュリティポリシーを回避することはできません。
- 認識されない query パラメータは無視されます；本ページに記載されたパラメータのみを使用してください。
