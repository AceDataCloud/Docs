$ACE を保有し、ご自身の Solana ウォレットを認証すると、Ace Data Cloud の**当該特典に対応する Credits API サービス**で呼び出し割引を受けられます。$ACE は常にご自身のウォレット内に保持されます。プラットフォームはオンチェーン残高を読み取るのみで、トークンをカストディ、ロック、移転または消費することはありません。

> $ACE はプラットフォームのチャージ残高ではなく、支払い承認やステーキング商品でもありません。割引はページに記載された Credits API サービスにのみ適用され、チャージ注文、x402 USDC 支払い、またはその他の Credits 以外の消費経路には適用されません。

## $ACE とは

$ACE は Solana メインネットにデプロイされた Ace Data Cloud エコシステムトークンです。現在すでに提供されている用途は保有特典です。ウォレット内の $ACE 残高が該当するしきい値に達すると、プラットフォームは対応する API サービスに割引を自動適用します。

| 項目      | 情報                                                                                           |
| ------- | -------------------------------------------------------------------------------------------- |
| ネットワーク      | Solana メインネット                                                                                    |
| トークン      | $ACE                                                                                         |
| 公式 Mint | `GnHpRsrcyfHSMZNzmpjAzTFQA26vnbRMzbKQ11ZKpump`                                               |
| 特典入口    | [$ACE 保有特典ページを開く](https://platform.acedata.cloud/console/coin)                                |
| オンチェーン検証    | [Solscan で公式 Mint を確認する](https://solscan.io/token/GnHpRsrcyfHSMZNzmpjAzTFQA26vnbRMzbKQ11ZKpump) |

**購入または交換前に、完全な Mint を一文字ずつ確認してください。** トークンの略称やアイコンは重複する可能性があり、完全な Mint のみが同一トークンを識別する信頼できる根拠です。

## 第1ステップ：$ACE を購入する

$ACE の購入では、**事前にプラットフォームでウォレットを連携する必要はありません**。必要なのは以下のみです：

- Phantom や Solflare などの Solana メインネットウォレット；
- 交換に使用できる SOL、USDC、またはページで実際に対応しているその他の資産；
- Solana ネットワーク手数料の支払いに必要な少量の SOL。

プラットフォームがシードフレーズや秘密鍵の提供を求めることはありません。シードフレーズ、秘密鍵、またはウォレットのリモート操作を求めるページは、通常の手順ではありません。

### 1. プラットフォームが提供する正確な入口からアクセスする

[$ACE 保有特典ページ](https://platform.acedata.cloud/console/coin)を開き、最初のステップのカードで完全な Mint を確認して「$ACE を購入」をクリックします。あるいは、直接以下を開くこともできます：

[Jupiter で $ACE を確認して交換する](https://jup.ag/tokens/GnHpRsrcyfHSMZNzmpjAzTFQA26vnbRMzbKQ11ZKpump)

このリンクには現在の公式 Mint がすでに含まれています。トークンの略称だけを検索して結果を選択しないでください。

### 2. ご自身の Solana ウォレットを接続する

交換ページで準備したウォレットを接続し、現在のネットワークが Solana メインネットであることを確認してください。初めてウォレットを使用する場合は、まずウォレット独自のセキュリティ注意事項とトランザクション確認画面を理解してください。

### 3. 交換に使用する資産と数量を選択する

SOL、USDC、またはページで実際に対応しているその他の資産を支払い資産として選択し、交換したい数量を入力します。ページに表示される対象トークンの Mint が、以下のアドレスと完全に一致することを確認してください：

```text
GnHpRsrcyfHSMZNzmpjAzTFQA26vnbRMzbKQ11ZKpump
```

### 4. 交換情報を確認する

送信前に以下を確認してください：

- 受け取る予定の $ACE 数量；
- 為替レート、価格影響、および最小受取数量；
- ネットワーク手数料およびページに記載されているその他の手数料；
- ウォレットのポップアップに表示される実際のトランザクション内容。

オンチェーン交換の価格および流動性は変動します。プラットフォームは約定価格、約定可能数量、またはトークン価値を保証しません。取引内容を理解し、リスクを負担できる場合にのみ、ご自身の判断で確認してください。

### 5. ウォレットで確認する

確認後、Solana ネットワークがトランザクションを完了するまで待ち、その後ウォレットに戻って $ACE 残高を確認してください。ウォレットがトランザクションの失敗またはキャンセルを明確に通知しない限り、ウォレットの確認待ちのポップアップを閉じたり更新したりしないでください。

## 第2ステップ：購入後にウォレットを接続して認証する

購入完了後、プラットフォームに戻ってウォレットを接続し、認証します。購入前に連携は不要であり、購入自体によってアカウントが自動連携されることもありません。**$ACE を保有している同じウォレット**を使用して、以下の操作を行ってください：

1. [$ACE 保有特典ページ](https://platform.acedata.cloud/console/coin)に戻る；
2. 「ウォレットを接続」をクリックし、先ほど使用したウォレットを選択する；
3. 「認証して連携」をクリックする；
4. ウォレットでプラットフォームが表示する所有権認証メッセージに署名する；
5. プラットフォームが finalized オンチェーン残高を同期するまで待つ。

所有権認証の署名は、ご自身がそのウォレットを管理していることを証明するだけであり、**支払いまたはトークン移転を承認するものではありません**。通常の手順では、読み取り可能なメッセージに署名し、未知のアドレスへの送金を求められることはありません。

認証に成功すると、ページにはウォレットの短縮アドレス、$ACE 残高、最終同期時刻、および現在適用されている割引が表示されます。オンチェーン取引の完了とプラットフォームの残高同期の間には遅延が生じる場合があるため、購入完了後に割引がすぐ表示されないことがあります。

## 割引の適用方法

|    $ACE 保有量 | Credits API 呼び出し割引 |
| ----------: | ---------------: |
|     100,000 |               1% |
|     250,000 |               2% |
|     500,000 |               3% |
|   1,000,000 |               5% |
|   5,000,000 |               7% |
|  10,000,000 |              10% |
|  25,000,000 |              12% |
|  50,000,000 |              15% |
| 100,000,000 |              20% |

割引はサービスごとの設定に基づきます。保有特典ページ内の「ACE 特典に対応するサービス」リストおよび各サービスに現在表示されている割引を基準とし、プラットフォーム上のすべてのサービスを対象とするものと理解しないでください。

残高はバックグラウンドタスクによって Solana の finalized 状態から読み取られます。Coin タイプの割引には有効期限があります：

- 同期に成功すると、しきい値を満たす割引が自動適用されます；
- 一時的に同期に失敗した場合、ページに残高状態の異常が表示されます；
- 有効期限を過ぎても更新できない場合、課金経路では古い割引が停止されます；
- ウォレット残高が減少した場合、または $ACE を売却した場合、次回の同期成功時に新しい残高に基づいて特典が再計算されます。

## セキュリティ確認
- 完全な Mint のみを認識します：`GnHpRsrcyfHSMZNzmpjAzTFQA26vnbRMzbKQ11ZKpump`；
- [Solscan](https://solscan.io/token/GnHpRsrcyfHSMZNzmpjAzTFQA26vnbRMzbKQ11ZKpump) を通じてオンチェーンアドレスを独自に確認できます；
- 第三者のウォレットまたは取引ページに表示される名称、アイコン、「検証済み」ラベルは参考情報にすぎず、Mint の確認に代わるものではありません；
- Ace Data Cloud はお客様のウォレットをホストせず、シードフレーズを保管せず、またお客様に代わってオンチェーン取引を完了することもありません；
- シードフレーズ、秘密鍵、またはウォレットのエクスポートファイルを誰にも送信しないでください；
- ウォレットのポップアップに表示される操作がページの説明と一致しない場合は、署名を拒否して操作を停止してください。

## よくある質問

### 購入後もプラットフォーム残高が 0 のままなのはなぜですか？

まず、取引が Solana メインネットで完了していること、および紐付けられているのが $ACE を保有している同じウォレットであることを確認してください。プラットフォームは finalized のオンチェーン状態を読み取るため、取引確認とバックエンド同期のいずれも短時間の遅延が発生する可能性があります。ページで同期異常が継続して表示される場合は、後でもう一度お試しいただくか、サポートチームまでお問い合わせください。

### 検証メッセージに署名できないのはなぜですか？

現在の優先フローでは、ウォレットが `signMessage` をサポートしている必要があります。ウォレットのバージョンを更新するか、メッセージ署名に対応した Solana ウォレットをご利用ください。送金や秘密鍵の提出によって検証を回避しないでください。

### 間違ったウォレットを接続した場合はどうすればよいですか？

ブラウザ上の「ウォレット接続を解除」は、現在のブラウザ接続を解除するだけであり、プラットフォーム上の紐付けは変更されません。特典ウォレットを変更するには、保有特典ページで「ウォレットの紐付けを解除」をクリックし、現在の ACE 割引の取消を確認した後、新しいウォレットを接続して検証してください。

### ウォレット署名によって資産が移転されますか？

いいえ。紐付けフローで署名するのは所有権検証メッセージであり、トークン送金や支払い承認ではありません。署名前には引き続きウォレットに表示されるメッセージ内容を確認してください。取引、送金、または見慣れない承認リクエストが表示された場合は、拒否してください。

### どれだけの $ACE を購入すれば割引を受けられますか？

現在の第1段階のしきい値は 100,000 $ACE であり、対応する Credits API サービスに対して 1% の割引を提供します。各段階については上表をご確認ください。実際に適用されるサービスと現在の割引は、保有特典ページの内容に準じます。

### どのサービスが $ACE 特典に対応していますか？

保有特典ページの「ACE 特典に対応するサービス」エリアをご確認ください。チャージ注文、x402 USDC 支払い、および Credits 以外の消費経路では、この割引は使用されません。

### $ACE を売却または送出した後はどうなりますか？

特典はオンチェーン残高に基づいて計算されます。残高が減少すると、次回の同期成功時に対応する割引が減額または取り消されます。古い割引にも有効期限があり、無期限に保持されることはありません。

### 古いウォレットにアクセスできない場合はどうすればよいですか？

プラットフォームアカウントにログインし、保有特典ページで「ウォレットの紐付けを解除」をクリックして確認してください。紐付け解除は、プラットフォーム内のウォレット関連付けと ACE 割引を取り消すだけであり、ウォレット内の資産を移転、破棄、または操作することはありません。完了後、新しいウォレットを接続して検証できます。
