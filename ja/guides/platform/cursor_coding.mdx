Cursor 現在提供 OpenAI API Key と **Override OpenAI Base URL** 設定があり、OpenAI互換サービスに接続できます。この機能は存在しますが、異なるバージョンで `/chat/completions`、`/responses`、モデルリスト、エージェント/コンポーザーなどのモードの処理は完全に一致していません。

異なる Cursor バージョン、オペレーティングシステム、およびリクエストモードの互換性範囲は異なる場合があります。このページの設定に従って実際のモードチェックを完了し、単一のチャット成功に基づいてすべての機能が利用可能であると推測しないでください。

## Cursor 公式 BYOK 現在保証すること

[Cursor 公式 Bring your own API key ドキュメント](https://cursor.com/help/models-and-usage/api-keys) によると：

- OpenAI、Anthropic、Google、Azure OpenAI、および AWS Bedrock の資格情報をサポート；
- カスタム API Key はチャットモデルのみに使用され、タブ補完は引き続き Cursor 内蔵モデルを使用；
- API Key は Cursor サーバーに永続化されず、各リクエストごとに Key が Cursor バックエンドに送信され、最終的なプロンプトビルディングに使用；
- 自有 Key を使用する場合、Cursor の Zero Data Retention ポリシーは適用されず、データ処理は選択したプロバイダーのポリシーに従う。

## 設定

1. Cursor 設定 → モデルを開く。
2. OpenAI API Key にあなたの Ace Data Cloud API トークンを入力。
3. **Override OpenAI Base URL** を有効にし、`https://api.acedata.cloud/v1` を入力。
4. 現在の Cursor プロトコルと互換性のある正確なモデル ID を選択または追加。
5. まず `Reply only OK` を送信し、次に実際に使用するモードの Ask/Edit/Agent などをテスト。

## 現在の境界

- カスタム API Key はチャットモデルのみに使用され、タブ補完は引き続き Cursor 内蔵モデルを使用。
- Cursor はサーバー側で最終的なプロンプトビルディングを完了する可能性があります；公式のプライバシー説明を考慮してデータパスを評価してください。
- Base URL Override は一部のリクエストのみを上書きする可能性があり、バージョンの変化により Chat Completions/Responses の間で切り替わることがあります。
- 単一のチャットリクエストが成功したからといって、エージェント、オート、コンポーザー、またはバックグラウンドタスクがすべて接続されていると主張すべきではありません。

## 現在の選択肢

Coding Plan を使用する際は、明確な設定契約と検証ゲートがあるクライアントを優先的に選択：

## 完全互換性チェック

生産ワークフローで長期的に使用する場合は、以下のチェックを同時に完了してください：

1. 固定 Cursor バージョンとオペレーティングシステム；
2. このバージョンで実際のクライアントのスモークテストを完了し、最終リクエストプロトコルとパスを記録；
3. 正確なモデルの Chat Completions リクエストが成功；
4. ツール呼び出しとエージェントリクエストが確実にターゲットエンドポイントを通過；
5. 使用量と請求が確認可能；
6. リクエストが Cursor サーバーを経由したかどうか、および対応するプライバシー制限を明確に記録。

クライアントのアップグレード後は、これらのチェックを再実行し、リクエストプロトコル、ツール呼び出し、およびデータパスに変更がないことを確認してください。
