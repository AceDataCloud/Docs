[LobeChat](https://lobehub.com/) は、プラグイン、ナレッジベース、セルフホスティングに対応したオープンソースの AI クライアントであり、オンライン版または Docker デプロイで使用できます。カスタム OpenAI 互換エンドポイントをサポートしているため、Ace Data Cloud に接続できます。本記事では設定手順を紹介します。

## 申請手順

LobeChat で Ace Data Cloud に接続するには、まず [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications) にアクセスし、API Token を取得して控えておきます。

![Ace Data Cloud API Key の取得](https://cdn.acedata.cloud/dvc3cg.jpg)

まだログインまたは登録していない場合は、自動的にログインページへ移動して登録とログインを案内します。ログイン・登録後は自動的に現在のページへ戻ります。

初回申請時には無料クレジットが付与され、Ace Data Cloud のモデルサービスを無料で試用できます。

## Ace Data Cloud を設定する

LobeChat の **アプリ設定 → 言語モデル** に入り、**OpenAI** カードを見つけて有効にし、以下を入力します：

| フィールド       | 値                              | 説明                         |
| -------- | ------------------------------ | -------------------------- |
| API Key  | あなたの Ace Data Cloud Token        | コンソールからコピーした Token               |
| API プロキシアドレス | `https://api.acedata.cloud/v1` | **必ず `/v1` で終わる必要があります**           |
| クライアントリクエストモード  | 有効                             | ブラウザから直接接続し、Key は LobeChat サーバーを経由しません |

![LobeChat OpenAI Provider 設定画面](https://cdn.acedata.cloud/629ef9d3084a.png)

> Chat Completions インターフェースを使用する場合は、Responses API Specification を無効のままにしてください。

LobeChat は Base URL に `/v1` を自動的に追加しません。リクエストパスは直接 `{API プロキシアドレス}/chat/completions` になります：

| API プロキシアドレス                              | 実際のリクエスト                                                   | 結果                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | 正しい                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | 使用可能                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404（`/openai` 配下に `/v1` はありません） |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404（`/v1` がありません）             |

LobeChat はデフォルトで `/v1/models` を呼び出してモデルを自動取得します。Ace Data Cloud から返されるモデル数が多い場合、画面の一覧が非常に長くなるため、「モデルリスト → カスタムモデル名」で allow list を手動入力することを推奨します。英語のカンマで区切ってください。表示名をカスタマイズする必要がある場合は、`=` を使用できます。形式は `MODEL_ID=表示名` です。

## モデルを選択する

モデルカタログは継続的に更新されます。クライアントが自動読み込みしたモデルリストを優先して使用してください。手動で入力する必要がある場合は、まず `GET https://api.acedata.cloud/v1/models` をリクエストして現在のモデル ID を取得し、その後クライアントが対応するコンテキスト、画像、ツール呼び出し機能に応じて選択してください。

## 接続を検証する

問題が LobeChat にあるのかネットワークにあるのか不明な場合は、まず curl を使用してエンドポイントを直接検証できます（`{token}` をあなたの Token に置き換えてください）：

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

OpenAI 互換の `chat.completion` オブジェクトが返れば、Token とエンドポイントの両方が準備できていることを示します。`HTTP 403 used_up` が返る場合は、Token は有効ですが残高が不足していることを示します。[コンソール](https://platform.acedata.cloud/console/applications)でチャージしてください。

## 上級編：Docker セルフホスティング

チーム向けにプライベート版をデプロイしたい場合は、Docker の1行コマンドで起動できます（`{token}` をあなたの Token に置き換えてください）：

```bash
docker run -d \
  --name lobe-chat \
  -p 3210:3210 \
  -e OPENAI_API_KEY={token} \
  -e OPENAI_PROXY_URL=https://api.acedata.cloud/v1 \
  -e ACCESS_CODE=your-secret-password \
  -e OPENAI_MODEL_LIST="MODEL_ID" \
  lobehub/lobe-chat:latest
```

`http://あなたのサーバーIP:3210` を開き、`ACCESS_CODE` を入力すれば使用できます。チームメンバーはそれぞれ Key を入力する必要がありません。上記で使用した `OPENAI_API_KEY`、`OPENAI_PROXY_URL`、`OPENAI_MODEL_LIST` などの環境変数の完全な説明は、[LobeChat モデルプロバイダー環境変数ドキュメント](https://lobehub.com/docs/self-hosting/environment-variables/model-provider)を参照してください。nginx のリバースプロキシで HTTPS を追加する場合は、必ず `proxy_buffering off;` を追加してください。追加しないとストリーミングレスポンスがバッファリングされます。その他のデプロイ形態については、[LobeChat セルフホスティング入門](https://lobehub.com/docs/self-hosting/start)および [Docker Compose デプロイ](https://lobehub.com/docs/self-hosting/platform/docker-compose)を参照してください。

## よくある質問

### 404 Not Found と表示される

通常、API プロキシアドレスが `.../openai/v1` になっているか、`/v1` が抜けています。`https://api.acedata.cloud/v1` に変更してください。

### モデルリストが空である

「クライアントリクエストモード」スイッチを有効にしてください。または、「カスタムモデル名」にモデル allow list を手動入力してください。

### 401 Unauthorized と表示される

API Key に貼り付けたのが Ace Data Cloud の Token であること（`Bearer` プレフィックスを含まず、余分な空白がないこと）、および所属するアプリケーションの残高が十分であることを確認してください。
