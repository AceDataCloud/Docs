ビジネス API 認証情報をページネーションで一覧表示します。このレスポンスには現在 Token または Identity 認証情報の機密フィールドが含まれており、必ずサーバーサイドでのみ処理し、ログ、分析プラットフォーム、フロントエンドの永続化、または公開リポジトリへの書き込みを禁止します。

## 準備作業

[Account Token](https://platform.acedata.cloud/documents/platform-token) を作成し、`GET /api/v1/platform-tokens/me/` を通じて現在のアカウント UUID を取得します。

```shell
export PLATFORM_TOKEN='あなたのアカウントトークン'
export USER_ID='あなたのアカウント UUID'
```

## インターフェース概要

| 項目   | 内容                                                   |
| --- | ---------------------------------------------------- |
| メソッド  | `GET`                                                |
| URL | `https://platform.acedata.cloud/api/v1/credentials/` |
| 認証  | Account Token、OAuth token には `credentials:read` が必要       |
| ページネーション  | `count` + `items`                                    |

一般ユーザーは自分の `user_id` または認可済みの `application_id` を渡す必要があります。そうしない場合、ページネーション中に権限のないオブジェクトに遭遇すると `403` が返される可能性があります。

## クエリパラメータ

| パラメータ                 | 型      | 必須  | 説明                             |
| ------------------ | ------- | --- | ------------------------------ |
| `user_id`          | string  | 状況による | 認証情報の所有者；繰り返しパラメータをサポート                   |
| `application_id`   | UUID    | いいえ   | Application でフィルタリング；繰り返しパラメータをサポート        |
| `host`             | string  | いいえ   | host による完全一致フィルタリング；繰り返しパラメータをサポート             |
| `name`             | string  | いいえ   | 名前による完全一致フィルタリング；繰り返しパラメータをサポート                 |
| `granted`          | boolean | いいえ   | `true` は他者に付与した認証情報、`false` は自分用の認証情報 |
| `limit` / `offset` | integer | いいえ   | ページネーション                             |
| `ordering`         | string  | いいえ   | `created_at` または `-created_at`   |

`service_id`、`disabled`、`expired` は現在フィルタパラメータではありません。

```shell
curl --get 'https://platform.acedata.cloud/api/v1/credentials/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## レスポンスの説明

本番環境で検証済みのレスポンスは `{count, items}` です。各項目には `id`、`application_id`、`application`、`user_id`、`creator_id`、`name`、`type`、`limited_amount`、`used_amount`、`expired_at`、`allowed_api_ids`、`host`、`granted`、`granted_to_user_id`、`tags`、`metadata` および時間フィールドが含まれ、タイプに応じて `token` または `username/password` が返されます。

> 現在、一覧レスポンスは完全な機密値を返します。ブラウザコンソールまたは収集システムに表示せず、一覧による平文の復元にも依存しないでください；クライアントは将来のマスキング戦略に対応すべきです。
