GitHub Copilot 公式 BYOK ドキュメントは、VS Code をサポートされているローカルクライアントとしてリストし、OpenAI-compatible Provider をサポートしています。VS Code のバージョン、企業ポリシー、モデルの可視性が最終的なエンドポイントに影響を与えます。初回接続時は以下を確認してください。

## 設定範囲

1. あなたの GitHub Copilot アカウントまたは組織が BYOK/Custom Models 機能を有効にしていることを確認してください。
2. VS Code の Copilot モデル管理に OpenAI-compatible Provider を追加します。
3. Base URL に `https://api.acedata.cloud/v1` を入力します。
4. API Key にあなたの Ace Data Cloud API Token を入力します。
5. Model にモデルディレクトリ内で選択したプロトコルに互換性のある正確なモデル ID を入力します。
6. Copilot Chat に `Reply only OK` を送信し、ワークスペースのコンテキストを持つリクエストを再度テストします。

## 現在の境界

- Copilot App、CLI、GitHub Desktop、Enterprise BYOK と VS Code の設定契約は異なるため、本ガイドは他のクライアントの手順を直接 VS Code に適用しません。
- 組織のポリシーにより、個人が Provider またはモデルを追加することが禁止されている場合があります。
- Tab completion、Chat、Agent およびバックグラウンドタスクは異なるモデルパスを使用する可能性があるため、それぞれ検証する必要があります。
