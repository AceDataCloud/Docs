Hermes Agent は OpenAI Chat Completions プロトコルを通じて Ace Data Cloud に接続します。任意の構成方法を選択してください：

| 構成方法                | ガイド                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| `hermes model` インタラクティブガイド | [ガイド構成](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| `config.yaml` 手動構成  | [手動構成](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| プラットフォームのプライベートデプロイ              | [ホスティングデプロイ](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

ローカル接続の共通パラメータ：

- Base URL：`https://api.acedata.cloud/v1`
- Transport：`chat_completions`
- Provider：`custom:acedatacloud`
- API Key： [アプリケーションリスト](https://platform.acedata.cloud/console/applications) から取得

2つのローカル方式は最終的に `~/.hermes/config.yaml` に書き込まれ、重複して構成しないでください。

[Coding Plan 構成センター](https://platform.acedata.cloud/documents/coding-plan-integration) に戻る。
