---
title: "AceDataCloud プラットフォームの Proxy 呼び出し記録を取得する"

現在のアカウントにおける Proxy タイプサービスの使用量記録を照会します。通常の API 呼び出しには、[API 呼び出し記録](https://platform.acedata.cloud/documents/platform-usage-list)を使用してください。サービスのタイプが不明な場合は、まず[サービス詳細](https://platform.acedata.cloud/documents/platform-service-detail)の `type` を確認できます。

## 準備作業

1. [AceDataCloud プラットフォーム](https://platform.acedata.cloud)にログインします。
2. [Account Token コンソール](https://platform.acedata.cloud/console/platform-tokens)でアカウントトークンを作成し、直ちにパスワードマネージャーまたは Secret Manager に保存します。
3. [プロフィールページ](https://auth.acedata.cloud/user/profile)を開いて現在のアカウント UUID をコピーし、`USER_ID` として保存します。アカウントトークン作成レスポンス内の `user_id` も使用できます。
4. [サービス申請一覧](https://platform.acedata.cloud/documents/platform-application-list)から Proxy タイプサービスの `application_id` を取得します。Proxy エンドポイントで絞り込む必要がある場合は、[サービス配下の Proxy 一覧](https://platform.acedata.cloud/documents/platform-service-proxies)から `proxy_id` を取得します。

完全なトークンの説明は[アカウントトークンの管理](https://platform.acedata.cloud/documents/platform-token)を参照してください。本インターフェースでは Account Token を使用し、ビジネス API を呼び出すための Credential は使用しません。

```shell
export PLATFORM_TOKEN='你的账户令牌'
export USER_ID='你的账户 UUID'
export APPLICATION_ID='你的 Proxy Application ID'
```

## インターフェース概要

| 項目     | 内容                                                     |
| ----- | ------------------------------------------------------ |
| メソッド    | `GET`                                                  |
| URL   | `https://platform.acedata.cloud/api/v1/usage/proxies/` |
| 認証    | `Authorization: Bearer ${PLATFORM_TOKEN}`              |
| Scope | `usage:read`                                           |
| ページネーション    | `count` + `items`、デフォルトで1ページあたり10件                            |

Application 所有者が `application_id` で照会する場合、サーバーは先に当該 Application の利用可能な記録を同期してから一覧を返すため、レスポンス時間が通常の API usage 一覧より長くなる可能性があります。権限を付与されたユーザーは既存の可視記録を読み取れますが、所有者側の同期はトリガーされません。

## クエリパラメータ

| パラメータ               | 型      | 必須     | デフォルト            | 説明                            |
| ---------------- | ------- | ------ | ------------- | ----------------------------- |
| `user_id`        | UUID    | 一般ユーザーは必須 | —             | 現在のアカウント UUID。他のアカウントを渡すと `403` が返されます     |
| `application_id` | UUID    | 推奨     | —             | Proxy Application で絞り込みます。重複パラメータをサポートします |
| `proxy_id`       | UUID    | いいえ      | —             | Proxy エンドポイントで絞り込みます。重複パラメータをサポートします           |
| `limit`          | integer | いいえ      | 10            | 1ページあたりの件数、最大 100                   |
| `offset`         | integer | いいえ      | 0             | ページネーションのオフセット                         |
| `ordering`       | string  | いいえ      | `-created_at` | 作成時刻の降順                       |

現在のインターフェースは、モデル、HTTP ステータスコード、Credential、または時間範囲による直接的な絞り込みをサポートしておらず、API usage インターフェースの `perspective` パラメータもサポートしていません。これらの未サポートパラメータをリクエストに追加し、有効になっていると想定しないでください。

## リクエスト例

```shell
curl --get 'https://platform.acedata.cloud/api/v1/usage/proxies/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=-created_at' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Python のページネーション例：

```python
import os
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/usage/proxies/",
    headers={"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"},
    params={
        "user_id": os.environ["USER_ID"],
        "application_id": os.environ["APPLICATION_ID"],
        "limit": 100,
    },
    timeout=60,
)
response.raise_for_status()
data = response.json()

for usage in data["items"]:
    print(usage["created_at"], usage["deducted_amount"], usage["remaining_amount"])
```

## 主要フィールド

| フィールド                       | 説明                       |
| ------------------------ | ------------------------ |
| `user_id`                | 今回の課金を負担するアカウント                |
| `actor_user_id`          | 実際の呼び出し元。古い記録では空の場合があります            |
| `application_id`         | この記録を生成した Proxy Application |
| `proxy_id`               | 対応する Proxy エンドポイント             |
| `credential_id`          | 関連する認証情報 ID。古い記録では空の場合があります          |
| `used_amount`            | 元の記録の使用量。空の場合があります             |
| `deducted_amount`        | 最終的に実際に差し引かれたクォータ                 |
| `remaining_amount`       | 課金後の Application の残りクォータ    |
| `metadata`               | 公開メタデータ。空の場合があります               |
| `service` / `credential` | 表示に便利な関連オブジェクトの概要。関連オブジェクトが存在しない場合は空の場合があります |

クォータの単位は、対応する Application の `service.unit` によって決まります。

## エラー処理

| HTTP | 意味         | 対処方法                                        |
| ---- | ---------- | ------------------------------------------- |
| 401  | アカウントトークンがない、または無効  | Account Token を確認し、ビジネス Credential を誤用しないでください          |
| 403  | リクエスト内の記録を閲覧する権限がない | 現在のアカウントに属する Application を使用し、権限のない `user_id` を削除してください      |
| 5xx  | 同期または照会が一時的に失敗  | 絞り込み条件を保持してバックオフ再試行してください。継続的に失敗する場合は、Application ID と時刻をサポート担当者に提供してください |

## 次のステップ

- [API 呼び出し記録を表示](https://platform.acedata.cloud/documents/platform-usage-list)：通常の API タイプサービスの詳細を照会します。
- [サービス配下の Proxy 一覧を取得](https://platform.acedata.cloud/documents/platform-service-proxies)：`proxy_id` を取得します。
- [サービス申請詳細を表示](https://platform.acedata.cloud/documents/platform-application-detail)：残りクォータと単位を確認します。
