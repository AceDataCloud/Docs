Ace Data Cloud は Hermes Agent プライベートデプロイの入口を提供します。この入口は制御されたサービスであり、利用可能かどうかおよび選択可能なリソースは、コンソールに現在表示されている内容に基づきます。

## 使用手順

1. プラットフォームで **Hermes Agent プライベートデプロイ** を見つけます。
2. ページの指示に従って利用可能な構成を選択し、サービスを作成します。
3. プラットフォームが準備完了の状態を表示するのを待ちます。
4. ページで提供された入口と認証情報を使用してインスタンスにアクセスします。
5. まず `Reply only OK` を送信し、その後に実際のタスクを開始します。

モデル、認証情報、ストレージ、および削除の動作は、作成ページおよび確認ポップアップに基づきます；ローカルの Hermes チュートリアルにある YAML を直接プラットフォームのデプロイ契約として扱わないでください。削除する前に、保持する必要のあるデータをエクスポートしてください。

コンソールに作成入口が表示されていない場合、現在のアカウントではこのサービスが開放されていないことを示します。その場合は、[Hermes インタラクティブウィザード](https://platform.acedata.cloud/documents/hermes-wizard-integration) または [手動構成](https://platform.acedata.cloud/documents/hermes-manual-integration) を利用してください。
