Coze 公式カスタムモデルドキュメントは OpenAI Responses API をサポートし、Base API URL、API Key およびモデルフィールドを提供します。異なる Coze テナントバージョンは、パスの結合、ストリーミング出力、およびツール呼び出しの処理が異なる場合があります。初めて接続する場合は、以下の項目を順に確認してください。

## 設定

1. Coze モデル管理に入り、新しいカスタムモデルを追加します。
2. プロトコルに OpenAI Responses API を選択します。
3. Base API URL に `https://api.acedata.cloud/v1` を記入します。
4. API Key にあなたの Ace Data Cloud API トークンを記入します。
5. モデルにモデルディレクトリ内で Responses API をサポートする正確なモデル ID を記入します。
6. 保存して Coze の接続テストを完了します。
7. Bot/Agent に `Reply only OK` を送信し、再度ツール呼び出しをテストします。

## 現在の境界

- 異なる Coze エリア、バージョン、またはプランは異なるフォームを表示する場合があります。
- Base API URL はベースを使用し、`/responses` を繰り返し追加しないでください；現在の UI が完全な API URL を明示的に要求する場合は、フォームの指示に従ってください。
- Chat Completions、Responses、および Anthropic Messages は三つの独立したルートであり、互いに置き換えて検証することはできません。
