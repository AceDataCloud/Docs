---
title: "AceDataCloud プラットフォームのモデル一覧を取得"
description: "Platform API guide - Ace Data Cloud"
---

プラットフォームで公開されているモデルカタログを返します。レスポンスは OpenAI スタイルの `{ "object": "list", "data": [...] }` 構造を採用します。このカタログはモデルの選択と機能の確認に使用され、現在のアカウントが該当するサービスを申請済みであることを必ずしも意味しません。

## インターフェース概要

| 項目   | 内容                                              |
| --- | ----------------------------------------------- |
| メソッド  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| 認証  | 公開、アカウントトークン不要                                       |
| ページネーション  | ページネーションなし、すべての一致項目は `data` に含まれる                              |

## クエリパラメータ

| パラメータ             | 型      | 必須  | 説明                                      |
| -------------- | ------- | --- | --------------------------------------- |
| `owned_by`     | string  | いいえ   | カタログ内のモデルプロバイダー識別子で完全一致フィルタリング                        |
| `type`         | string  | いいえ   | モデルタイプで完全一致フィルタリング、例：`chat`                     |
| `capability`   | string  | いいえ   | `capabilities` にこの機能を含むモデルのみを返す、例：`vision` |
| `with_pricing` | boolean | いいえ   | `1`、`true` または `yes` の場合、公開価格情報を追加            |

`service_id`、`tag`、`limit`、`offset` および `ordering` は現在サポートされていません。渡しても、対応するフィルタリングまたはページネーション効果は発生しません。

## リクエスト例

```shell
# すべての公開モデル
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# ビジョン対応の chat モデル、価格付き
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## 実際のレスポンス構造

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

`pricing` およびトップレベルの `credit_usd_rate` は、`with_pricing=true` の場合にのみ表示されます。すべてのモデルに計算可能な `pricing` があるわけではありません。モデルオブジェクトは `config/models.json` の公開フィールドに準拠し、クライアントは追加されたフィールドを無視する必要があります。

> 価格フィールドはカタログ表示用データです。実際の業務呼び出しについては、引き続き対応する API/Service の課金ルールおよび最終的な使用量記録が基準となります。
