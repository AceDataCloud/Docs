[Ace Data Cloud Studio](https://studio.acedata.cloud) は、クリエイター、運用、デザイン、ビジネスチーム向けに、AI チャット、画像、動画、音楽、自動動画作成ツールを一元的に提供します。ユーザーはクリエイティブの目標からワークフローを選択でき、複数の製品間で繰り返し登録、チャージ、切り替えを行う必要はありません。

![Studio ホーム：クリエイティブの目標からチャット、画像、動画、音楽へ](https://cdn.acedata.cloud/uploads/34c26779-82a4-4a9b-b81b-fb98ccd525be)

## どのようなシーンに適しているか

- **コンテンツ制作**：執筆、リサーチ、ポスター、カバー、ショート動画、BGM；
- **マーケティング運用**：商品画像、ソーシャルメディア素材、イベントビジュアル、ブランドコンテンツ；
- **デザイン探索**：参考画像の編集、スタイル探索、構図、複数バージョンの案；
- **ビジネスチーム**：自然言語でクロスモデル・複数ステップのクリエイティブタスクを完了；
- **開発者および上級ユーザー**：対応するシーンで API Key、Connector、Skill、またはローカルツールを設定。

具体的に利用できる機能は、サイト設定、地域、アカウント、製品バージョンにより変わります。現在のページに実際に表示される内容を基準としてください。

## 始め方

1. [studio.acedata.cloud](https://studio.acedata.cloud) にアクセスします；
2. ページで現在提供されているログイン方法を選択します；
3. ホームのクリエイティブ目標、または左側の機能ナビゲーションからツールに入ります；
4. 現在のサービスの価格、パラメーター、コンテンツ要件を確認します；
5. まず低コストのタスクでフローを検証してから、高解像度、長尺動画、または一括生成を行います。

サービスごとに課金単位、処理時間、パラメーターは異なります。送信前に現在のページと利用履歴を確認し、過去のスクリーンショットに基づいて価格を推測しないでください。

## コアワークフロー

### AI チャット

執筆、分析、学習、プログラミング、マルチモーダルな議論に使用します。具体的なモデル、コンテキスト機能、ツール対応は、現在のモデルセレクターを基準とします。

### AI 画像

テキストからの画像生成、参考画像の編集、画像拡張、スタイル変換、ビジュアルデザインをカバーします。画像サービスごとに、サイズ、文字レンダリング、人物の一貫性、編集機能でそれぞれ重点が異なります。

### AI 動画と自動動画作成

テキスト、画像、参考素材、またはスクリプトによる動画制作をサポートします。自動動画作成ワークフローでは、スクリプト、映像、ナレーション、字幕、音楽を組み合わせることができます；長時間タスクでは、ステータス照会、失敗原因、最終出力の完全性に注意してください。

### AI 音楽

スタイルまたは歌詞から楽曲を生成し、ページで提供される機能に応じて編集または拡張を続けることをサポートします。商用利用前に、コンテンツの権利と対象プラットフォームのルールを自ら確認してください。

### Connector、Skill と高度なツール

一部のアカウントまたはサイトでは、Connector、Skill、ローカルツールを使用できます。これらの入口は、現在の製品、権限、実行環境による制約を受け、すべてのユーザーまたはホワイトラベルサイトにデフォルトで開放されているわけではありません。

## Web、モバイル、デスクトップ

Studio Web 版は `studio.acedata.cloud` にあります。モバイル版とデスクトップ版では、機能やサイト管理の入口が異なる場合があります：

- ホワイトラベルサイト管理は、Web 版で現在の Site 管理者にのみ表示されます；
- ネイティブモバイル版とデスクトップ版には、すべてのサイト運用設定は表示されません；
- スマートフォン幅では下部の機能ナビゲーションを使用し、複雑なクリエイティブフォームにはデスクトップブラウザがより適しています。

## 自分のブランドサブサイトを作成する

自身の名前、Logo、ページドメイン、機能カタログ、チャネル価格で Studio を運営する必要がある場合は、公式 Studio Web 版で以下を開きます：

**ユーザーアバター → 設定 → マイサブサイト**

作成後、「マイサブサイト」から対象サブサイトの **管理** をクリックし、ブランド、ログイン、機能、価格、バナー、統計、カスタムドメインを設定します。

## ホワイトラベルと販売代理の境界

- ホワイトラベルは共有プラットフォーム上の Site 設定であり、独立デプロイや独立データベースではありません；
- ユーザーアカウント、残高、プラン、ほとんどのアセットは共有システムに属します；
- チャージ、機能、サービスを非表示にすることはページ表示の制御にすぎず、権限の分離ではありません；
- Site の上乗せ価格は通常のホワイトラベル購入フローにおけるチャネル価格であり、アカウントのすべての入口における強制テナント価格ではありません；
- 販売代理収益は有効注文、招待関係、レベル、返金、リスク管理に依存し、固定比率、入金速度、または収益額を保証しません。

## 利用上の推奨事項

- 重要な事実と生成コンテンツは人による再確認が必要です；
- プロンプト、スクリーンショット、チャット、チケットでパスワード、API Key、身分証明書、支払い情報を漏らさないでください；
- 肖像、音声、商標、著作権素材については必要な許可を取得してください；
- 高コストのタスクは先にサンプルを作成し、パラメーターを確認してから規模を拡大してください；
- 異常が発生した場合は、時刻、サービス、ステータスコード、公開可能なリクエスト識別子を記録し、完全な token を送信しないでください。

## ホームページのサードパーティサイト向け OAuth 認可

サイトコンポーネントの設定で OAuth を有効にし、サードパーティが ACE Data Cloud に登録したアプリケーション ID とコールバックアドレスを入力します。サイトとコールバックアドレスは Studio のオリジンとは異なる、同一の HTTPS オリジンを使用する必要があります。設定にアプリケーションシークレットを入力しないでください。

サードパーティページは OAuth メッセージプロトコルを統合する必要があります。ログイン済みの訪問者には、コンポーネント領域に公式の同意ページが表示されます；同意後、サードパーティは OAuth token を通じて、その訪問者が既に持っている API Key を読み取ることができます。未ログインまたは認可を拒否した場合、Key は提供されません。

Key の読み取りを許可した後、サードパーティはそれを保存して使用できます。OAuth 認可を取り消しても、すでにコピーされた Key は無効になりません；別途 Key を取り消すかローテーションしてください。詳細は「Ace Data Cloud ログイン（OAuth 2.0）の統合」の Studio コンポーネント説明を参照してください。
