[Ace Data Cloud Studio](https://studio.acedata.cloud) は、クリエイター、運用担当者、デザイナー、ビジネスチーム向けに、AI チャット、画像、動画、音楽、自動動画作成ツールを統合して提供します。ユーザーはクリエイティブ目標からワークフローを選択でき、複数の製品間で何度も登録、チャージ、切り替えを行う必要はありません。

![Studio ホーム：クリエイティブ目標からチャット、画像、動画、音楽へ進む](https://cdn.acedata.cloud/uploads/34c26779-82a4-4a9b-b81b-fb98ccd525be)

## 適しているシーン

- **コンテンツ制作**：執筆、リサーチ、ポスター、カバー、ショート動画、BGM；
- **マーケティング運用**：商品画像、ソーシャルメディア素材、イベントビジュアル、ブランドコンテンツ；
- **デザイン探索**：参照画像の編集、スタイル探索、構図、複数バージョンの案；
- **ビジネスチーム**：自然言語を使って、モデル横断・複数ステップのクリエイティブタスクを完了；
- **開発者と上級ユーザー**：対応するシーンで API Key、Connector、Skill、またはローカルツールを設定。

具体的に利用可能な機能は、サイト設定、地域、アカウント、製品バージョンによって変わるため、現在のページに実際に表示される内容を基準としてください。

## 始め方

1. [studio.acedata.cloud](https://studio.acedata.cloud) にアクセスする；
2. ページで現在提供されているログイン方法を選択する；
3. ホームのクリエイティブ目標または左側の機能ナビゲーションからツールに進む；
4. 現在のサービスの価格、パラメータ、コンテンツ要件を確認する；
5. まず低コストのタスクでフローを検証してから、高解像度、長尺動画、または一括生成を行う。

サービスごとに課金単位、処理時間、パラメータは異なります。送信前に現在のページと利用履歴を確認し、過去のスクリーンショットに基づいて価格を推測しないでください。

## コアワークフロー

### AI チャット

執筆、分析、学習、プログラミング、マルチモーダルなディスカッションに使用します。具体的なモデル、コンテキスト機能、ツール対応は、現在のモデルセレクターに表示される内容を基準とします。

### AI 画像

テキストからの画像生成、参照画像の編集、アウトペインティング、スタイル変換、ビジュアルデザインをカバーします。画像サービスごとに、サイズ、文字レンダリング、人物の一貫性、編集機能でそれぞれ特徴があります。

### AI 動画と自動動画作成

テキスト、画像、参照素材、またはスクリプトによる動画制作をサポートします。自動動画作成ワークフローでは、スクリプト、映像、ナレーション、字幕、音楽を組み合わせることができます；長時間タスクでは、ステータス照会、失敗原因、最終出力の完全性に注意する必要があります。

### AI 音楽

スタイルまたは歌詞から楽曲を生成し、ページで提供される機能に従ってさらに編集または拡張できます。商用利用前には、コンテンツの権利と対象プラットフォームのルールを自ら確認してください。

### Connector、Skill と高度なツール

一部のアカウントまたはサイトでは、Connector、Skill、ローカルツールを使用できます。これらの入口は現在の製品、権限、実行環境による制約を受け、すべてのユーザーまたはホワイトラベルサイトでデフォルトで開放されているわけではありません。

## Web、モバイル版とデスクトップ版

Studio Web 版は `studio.acedata.cloud` にあります。モバイル版とデスクトップ版では、機能やサイト管理入口が異なる場合があります：

- ホワイトラベルサイトの管理は、Web 版で現在の Site 管理者にのみ表示されます；
- ネイティブモバイル版とデスクトップ版では、すべてのサイト運用設定は表示されません；
- スマートフォン幅では下部の機能ナビゲーションを使用し、複雑な制作フォームにはデスクトップブラウザがより適しています。

![Studio モバイル版：下部の機能ナビゲーションと縦方向の制作入口](https://cdn.acedata.cloud/uploads/3c1be999-d0ee-45ea-a72e-5f26a40a3703)

## 自分のブランド分サイトを作成する

独自の名称、Logo、ページドメイン、機能カタログ、チャネル価格で Studio を運営する必要がある場合は、公式 Studio Web 版で以下を開くことができます：

**ユーザーアイコン → 設定 → 私の分サイト**

作成後、「私の分サイト」から対象の分サイトで **管理** をクリックし、ブランド、ログイン、機能、価格、バナー、統計、カスタムドメインを設定します。

## ホワイトラベルと販売代理の境界

- ホワイトラベルは共有プラットフォーム上の Site 設定であり、独立デプロイや独立データベースではありません；
- ユーザーアカウント、残高、プラン、および大半のアセットは共有システムに属します；
- チャージ、機能、サービスを非表示にすることは画面表示の制御にすぎず、権限の分離ではありません；
- Site の上乗せ価格は通常のホワイトラベル購入フローにおけるチャネル価格であり、アカウントがすべての入口で強制されるテナント価格ではありません；
- 販売代理の収益は、有効注文、招待関係、レベル、返金、リスク管理に依存し、固定比率、入金速度、収益額を保証するものではありません。

## 利用に関する提案

- 重要な事実と生成コンテンツは人の手で再確認する必要があります；
- プロンプト、スクリーンショット、チャット、チケット内で、パスワード、API Key、身分証明書、支払い情報を漏らさないでください；
- 人物画像、音声、商標、著作権素材については、必要な許諾を取得してください；
- 高コストのタスクはまず試作を行い、パラメータを確認してから規模を拡大してください；
- 異常が発生した場合は、時刻、サービス、ステータスコード、公開可能なリクエスト識別子を記録し、完全な token を送信しないでください。

## ホームページのサードパーティサイトにおける OAuth 認可

ウェブサイトコンポーネントでは、標準 OAuth リダイレクトを採用するか、Studio の現在のアカウントによるコンポーネント認可を使用できます。標準リダイレクトでは、サードパーティのボタンから認可ページを開き、その後、登録されたコールバックアドレスに戻ります；Studio のメッセージプロトコルは必要とせず、Studio のログイン状態も自動的には再利用しません。通常の iframe で初回ログイン後に認可を継続することには現在も不足があるため、連携ドキュメントに従って検証するか、独立したページ／コンポーネント認可を使用する必要があります。

Studio の現在のアカウントを使用したい場合は、「設定 → ホームページ → ウェブサイトコンポーネント」で OAuth を有効にし、サードパーティアプリケーション ID とコールバックアドレスを入力してください。ウェブサイトとコールバックアドレスは、Studio のオリジンとは異なる、同一の HTTPS オリジンを使用する必要があります。設定にアプリケーションシークレットを入力しないでください。サードパーティページではさらにコンポーネントメッセージプロトコルを実装する必要があり、URL を入力するだけでは OAuth 連携は自動的に完了しません。
コンポーネントは `profile:read credentials:read` を申請し、`offline_access` は含みません。ログイン済みの訪問者が同意した後、第三者は一回限りの認可コードを受け取り、自身の PKCE verifier を使用して OAuth token と交換し、さらに `https://platform.acedata.cloud/api/v1/credentials/?user_id=<UserInfoが返すid>&limit=100` を通じて `items[*].token` を読み取ります。未ログインまたは認可を拒否した場合、Key は提供されません。

完全な説明、実行可能な標準リダイレクト例、scope ディレクトリおよびエラー処理については [OAuth 接続ガイド](https://docs.acedata.cloud/zh-Hans/guides/oauth) を参照してください。Studio セッションを使用するアプリケーションについては、別途 [コンポーネントメッセージの例](https://github.com/AceDataCloud/Nexior/blob/main/docs/integrations/studio-home-oauth.md) も参照してください。

Key の読み取りを許可した後、第三者はそれを保存して使用できます。現在、OAuth 失効エンドポイントの成功レスポンスは JWT が即時に無効になることを意味せず、すでにコピーされた API Key も無効にしません。ユーザーは別途その Key を失効またはローテーションする必要があります。
