現在のアカウントの直近 60 日間のビジネス API 呼び出し明細を照会します。課金の照合、失敗したリクエストの特定、サービス、Application、API または認証情報別の問題調査に適しています。

> このページで照会するのはアカウント自身の呼び出し履歴です。特定の API のプラットフォーム全体における公開呼び出し統計のみを確認したい場合は、[API 呼び出し統計](https://platform.acedata.cloud/documents/platform-api-usage)を使用してください。

## データ保持範囲

呼び出し記録および課金サマリーは直近 60 日間保持されます。リクエストとレスポンスの本文は直近 30 日間保持されます。30～60 日前の記録についても trace、ステータス、時刻、モデル、使用量および実際の課金額などのサマリーを照会できますが、詳細内の `metadata.request`、`metadata.response` は返されなくなります。モデル集計および有効な結果の統計に必要なサマリーは、本文の有効期限前まで保持されます。本文を長期保存する必要がある場合は、呼び出し時にご自身で保存してください。

## 準備作業

### 1. アカウントトークンを作成する

このインターフェースはプラットフォーム管理 API に属しており、**Account Token（アカウントトークン）**を使用する必要があります。

1. [AceDataCloud プラットフォーム](https://platform.acedata.cloud)にログインします。
2. [Account Token コンソール](https://platform.acedata.cloud/console/platform-tokens)を開きます。
3. 「作成」をクリックし、直ちにトークンをパスワードマネージャーまたは Secret Manager に保存します。

完全な説明については、[AceDataCloud プラットフォームアカウントトークンの管理](https://platform.acedata.cloud/documents/platform-token)を参照してください。アカウントトークンは `platform.acedata.cloud/api/v1/**` 用です。`api.acedata.cloud/**` のビジネスインターフェースの呼び出しには API 認証情報（Credential）を使用し、両者を混用することはできません。

```shell
export PLATFORM_TOKEN='你的账户令牌'
```

トークンをフロントエンドコード、ログ、または公開リポジトリに書き込まないでください。漏洩した場合は、直ちにコンソールで削除して再作成してください。

### 2. 絞り込み ID を準備する（任意）

絞り込み条件を渡さなくても、現在のアカウントが閲覧権限を持つ記録を確認できます。範囲を絞り込む必要がある場合：

- `application_id`：[サービス申請リスト](https://platform.acedata.cloud/documents/platform-application-list)から取得します。
- `credential_id`：[API 認証情報リスト](https://platform.acedata.cloud/documents/platform-credential-list)から取得します。
- `api_id`：[API リスト](https://platform.acedata.cloud/documents/platform-api-list)から取得します。
- `service_id`：[サービスリスト](https://platform.acedata.cloud/documents/platform-service-list)から取得します。

一般ユーザーは `user_id` を渡す必要はありません。明示的に渡す場合は現在のアカウントと一致している必要があり、一致しない場合は `403` が返されます。管理者はこのパラメータを使用してアカウントをまたいで絞り込めます。

## インターフェース概要

| 項目           | 内容                                                  |
| ----------- | --------------------------------------------------- |
| メソッド          | `GET`                                               |
| URL         | `https://platform.acedata.cloud/api/v1/usage/apis/` |
| 認証          | `Authorization: Bearer ${PLATFORM_TOKEN}`           |
| OAuth Scope | `usage:read`（`platform:read` / `platform` に展開して含まれる）    |
| ページネーション          | `count` + `items`、デフォルトは 1 ページあたり 10 件                         |

## 照会範囲

| `perspective` | 意味                    |
| ------------- | --------------------- |
| `both`        | デフォルト値。現在のアカウントが支払った、または実際に呼び出した記録を返す |
| `billing`     | 現在のアカウントが支払った記録のみを返す         |
| `actor`       | 現在のアカウントが実際に呼び出した記録のみを返す       |

## クエリパラメータ

| パラメータ                | 型       | 必須  | デフォルト            | 説明                         |
| ----------------- | -------- | --- | ------------- | -------------------------- |
| `perspective`     | string   | いいえ   | `both`        | `billing`、`actor` または `both` |
| `user_id`         | UUID     | いいえ   | —             | 管理者のみユーザーで絞り込み可能。繰り返しパラメータに対応           |
| `service_id`      | UUID     | いいえ   | —             | サービスで絞り込み。繰り返しパラメータに対応               |
| `application_id`  | UUID     | いいえ   | —             | Application で絞り込み。繰り返しパラメータに対応    |
| `api_id`          | UUID     | いいえ   | —             | API で絞り込み。繰り返しパラメータに対応            |
| `credential_id`   | UUID     | いいえ   | —             | API 認証情報で絞り込み。繰り返しパラメータに対応          |
| `status_code`     | integer  | いいえ   | —             | HTTP ステータスコードで絞り込み。繰り返しまたはカンマ区切りの値に対応    |
| `created_at_from` | datetime | いいえ   | —             | 作成時刻の下限、ISO 8601            |
| `created_at_to`   | datetime | いいえ   | —             | 作成時刻の上限、ISO 8601            |
| `limit`           | integer  | いいえ   | 10            | 1 ページあたりの件数、最大 100                |
| `offset`          | integer  | いいえ   | 0             | ページネーションのオフセット                      |
| `ordering`        | string   | いいえ   | `-created_at` | 作成時刻の降順                    |

リクエスト時刻が直近 60 日より前の場合、インターフェースは `400` のフィールド検証エラーを返し、完全な呼び出し明細は 60 日間のみ保持されることを通知します。

## リクエスト例

直近 100 件の記録を照会する：

```shell
curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/' \
  --data-urlencode 'perspective=both' \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=-created_at' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

時刻、Application、および失敗ステータスで絞り込む：

```shell
export APPLICATION_ID='你的 Application ID'

curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'created_at_from=2026-09-01T00:00:00Z' \
  --data-urlencode 'created_at_to=2026-09-02T00:00:00Z' \
  --data-urlencode 'status_code=500' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Python ページネーションの例：

```python
import os
import requests

url = "https://platform.acedata.cloud/api/v1/usage/apis/"
headers = {"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"}
params = {"perspective": "both", "limit": 100, "offset": 0}

response = requests.get(url, headers=headers, params=params, timeout=30)
response.raise_for_status()
data = response.json()

for usage in data["items"]:
    print(usage["created_at"], usage["status_code"], usage["deducted_amount"], usage["trace_id"])

if params["offset"] + len(data["items"]) < data["count"]:
    params["offset"] += len(data["items"])
```

## 主要フィールド

| フィールド                            | 説明                                  |
| -------------------------------- | ----------------------------------- |
| `user_id`                        | 今回の課金を負担するアカウント                       |
| `actor_user_id`                  | 実際に呼び出しを開始したアカウント。認証情報の使用を他者に許可した場合、`user_id` と異なる可能性がある |
| `used_amount`                    | 今回の呼び出しについて元のルールに基づいて計算された使用量             |
| `original_amount`                | アプリケーション割引前の元の使用量                       |
| `deducted_amount`                | 最終的に実際に差し引かれたクォータ                       |
| `remaining_amount`               | 今回の課金完了後の Application の残りクォータ           |
| `elapsed`                        | サーバー側で記録された呼び出し時間。単位は秒                 |
| `trace_id`                       | 単一リクエストの調査時に使用するトレース識別子                  |
| `metadata`                       | 公開メタデータ。リストでは完全なリクエストまたはレスポンス内容は返されない               |
| `api` / `service` / `credential` | 表示に便利な関連オブジェクトの概要。関連オブジェクトがすでに存在しない場合は空になる可能性がある           |

クォータの単位は対応する Application の `service.unit` によって決まり、デフォルトで米ドルとして扱うべきではありません。

## エラーと再試行

| HTTP | `error`                   | 意味             | 処理方法                               |
| ---- | ------------------------- | -------------- | ---------------------------------- |
| 400  | フィールド検証エラー                    | クエリ範囲が 60 日間の保持期間より前 | 開始時刻を直近 60 日以内に調整する                  |
| 401  | `not_authenticated`       | アカウントトークンがないか無効      | Account Token を確認し、業務用 Credential を誤用しない |
| 403  | `permission_denied`       | リクエストに閲覧権限のないレコードが含まれている    | 未認可のユーザーフィルター条件を削除する                       |
| 429  | `usage_query_in_progress` | 完全に同一のクエリがまだ実行中    | `Retry-After` を待ってからバックオフして再試行する             |
| 503  | `usage_query_timeout`     | クエリがサーバー側の安全な時間制限を超過した    | 時間範囲を縮小するかフィルター条件を追加してから再試行する                   |

同じクエリパラメータのセットでは、進行中のリクエストを最大 1 件だけ保持します。大規模な範囲のクエリでは、1 日またはそれより小さいウィンドウを優先し、固定間隔で同じリクエストを重ねないでください。
