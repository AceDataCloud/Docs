## 1. API Key を取得する

[Ace Data Cloud アプリケーション一覧](https://platform.acedata.cloud/console/applications)を開き、利用可能なアプリケーションに入り、API Key をコピーします。

![Ace Data Cloud API Key を取得](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Provider を追加する

Cherry Studio を開き、**設定 → モデルサービス → プロバイダーを追加** に進み、以下を入力します：

| フィールド      | 値                           |
| ------- | --------------------------- |
| プロバイダー名   | `Ace Data Cloud`            |
| プロバイダータイプ   | `OpenAI`                    |
| API Key | 先ほどコピーした API Key               |
| API アドレス  | `https://api.acedata.cloud` |

![Cherry Studio に Ace Data Cloud Provider を追加する設定画面](https://cdn.acedata.cloud/b67a927eae62.png)

Cherry Studio は OpenAI タイプに対して `/v1/chat/completions` を自動補完します。共通エンドポイントを使用する場合、アドレス末尾に `#` を追加しないでください。また、モデルファミリーごとに複数の Provider を作成する必要もありません。

## 3. モデルを追加して有効化する

1. **モデル一覧を取得** をクリックします。現在のバージョンが自動取得をサポートしていない場合は、[モデルカタログ](https://platform.acedata.cloud/models)で確認し、`claude-opus-5`、`gpt-6-sol` などの対象モデル名を手動で追加してください。
2. API Key の横にあるチェックボタンをクリックして接続を検証します。
3. Provider の **有効化** スイッチをオンにします。
4. チャットモデルセレクターで、追加したモデルを選択します。

![Cherry Studio Provider とモデル一覧](https://cdn.acedata.cloud/149de1d088bf.png)

> モデルの取得または手動追加が完了したら、右上の Provider スイッチをオンにしてください。

`Reply only OK` を送信し、[利用履歴](https://platform.acedata.cloud/console/usages)で呼び出しを確認します。401 の場合は Key を確認してください。モデルが表示されない場合は Provider が有効化されているか確認してください。404 の場合は、手動入力したモデル名がカタログ内の `id` と完全に一致しているか確認してください。

## GPT Image 2 について

Cherry Studio の通常のカスタムチャット Provider は、Images API を直接呼び出すことができません。`gpt-image-2` の生成と編集には、Ace Data Cloud 専用インターフェースを使用してください：

- [GPT Image 2 画像生成](https://platform.acedata.cloud/documents/openai-images-generations)
- [GPT Image 2 画像編集](https://platform.acedata.cloud/documents/openai-images-edits)

`/openai/images/generations` をチャット Provider に入力しないでください。
