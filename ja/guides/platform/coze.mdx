Coze は公式にカスタムモデルの接続をサポートしており、OpenAI Chat API、OpenAI Responses API、Anthropic Messages API の三つのプロトコルを提供しています。三つのルートの Base URL、パスの結合、ヘッダー、ストリーミング、およびツール呼び出しの契約は異なるため、それぞれを個別に設定および検証する必要があります。

| ルート                      | 状態  | ガイド                                                                                  |
| ----------------------- | --- | ----------------------------------------------------------------------------------- |
| OpenAI Chat Completions | 実験的 | [Chat 設定](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | 実験的 | [Responses 設定](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | 実験的 | [Messages 設定](https://platform.acedata.cloud/documents/coze-messages-integration)   |

「実験的」とは、公式の機能と設定の入口が確認されていることを意味しますが、異なる Coze の地域、バージョン、またはプランによって異なるフォームが表示される可能性があります。Ace Data Cloud は依然としてプロトコルに従って固定バージョンの検証を完了する必要があります。あるプロトコルの成功を他の二つに外挿しないでください。

## 設定の原則

- Base API URL は文書に示されたベースを優先して記入してください。クライアントが自動的に補完するエンドポイントパスを重複して追加しないでください。
- API Key はあなたの Ace Data Cloud API トークンを使用してください。
- Model は選択したプロトコルと互換性のあるモデルディレクトリ内の正確なモデル ID を使用してください。
- 通常のテキストが成功した後、ストリーミングとツール呼び出しも検証する必要があります。
