Service UUID を通じてページネーションで、そのサービスにマウントされている Proxy エンドポイントを返します。alias のみの場合は、まず[サービス詳細](https://platform.acedata.cloud/documents/platform-service-detail)を呼び出して `id` を取得してください。

## インターフェース概要

| 項目   | 内容                                                                     |
| --- | ---------------------------------------------------------------------- |
| メソッド  | `GET`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| 認証  | 公開、アカウントトークン不要                                                              |
| ページネーション  | `count` + `items`                                                      |

## パラメータ

| パラメータ                 | 位置    | 必須  | 説明                               |
| ------------------ | ----- | --- | -------------------------------- |
| `service_id`       | path  | はい   | Service UUID、alias は非対応           |
| `limit` / `offset` | query | いいえ   | ページネーション                               |
| `ordering`         | query | いいえ   | Django のソート式；`rank` または `-rank` を推奨 |

```shell
export SERVICE_ID='あなたの Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## レスポンス説明

リスト項目は Proxy モデルによってシリアライズされ、オンラインで検証済みのフィールドには `id`、`service_id`、`title`、`endpoint`、`price`、`stage`、`rank`、`tags`、`metadata`、`document_id`、`service` および時間フィールドが含まれます。

- ビジネスエントリーフィールドは `endpoint` であり、`path` ではありません。
- 価格フィールドは `price` であり、`cost` ではありません。
- Service タイプが Proxy ではない、または Proxy がマウントされていない場合は、空の `items` が返されます。

公開統合は `endpoint` と公開済みの機能のみに依存すべきであり、公開されていない実装詳細に依存すべきではありません。
