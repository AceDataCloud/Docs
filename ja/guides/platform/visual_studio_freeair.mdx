FreeAIr は Visual Studio 2022/2026 向けのオープンソース拡張機能で、公式に任意の OpenAI-compatible API に接続できると声明しています。異なる拡張バージョンのリクエスト動作は変わる可能性があります；初回接続時は固定バージョンを使用し、以下の最小検証を完了してください。

## 設定

1. Visual Studio Marketplace または公式リポジトリから FreeAIr をインストールします。
2. FreeAIr 設定を開き、OpenAI-compatible 接続を追加します。
3. Endpoint に `https://api.acedata.cloud/v1` を入力します。
4. Token にあなたの Ace Data Cloud API Token を入力します。
5. Model にモデルディレクトリ内で Chat Completions をサポートする正確なモデル ID を入力します。
6. 保存後に `Reply only OK` を送信し、プロジェクトコンテキストを含むリクエストを再度テストします。

## 現在の境界

- 本ガイドは FreeAIr のみをカバーしており、Visual Studio 内蔵の Copilot が arbitrary Base URL をサポートすることを示すものではありません。
- 拡張バージョンによって endpoint の結合方法が変わる可能性があります；検証時には最終リクエスト URL を確認する必要があります。
- ツール呼び出しと拡張内の MCP 機能は独立して検証する必要があり、通常のチャットの成功で代替することはできません。
