OpenCode の公式 IDE 拡張機能は、VS Code、Cursor、Windsurf、VSCodium などのエディタをサポートし、OpenCode のローカルランタイムとプロバイダー設定を再利用します。IDE 拡張機能はローカル CLI プロバイダーを再利用しますが、異なるエディタバージョンのリクエストチェーンは変わる可能性があります。初めて接続する場合は、バージョンを固定し、最小限の検証を完了してください。

## プロバイダーの設定

まず、[OpenCode Terminal 設定](https://platform.acedata.cloud/documents/opencode-terminal-integration)に従って、`opencode.json` または `opencode.jsonc` に Ace Data Cloud プロバイダーを設定します：

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## IDE 拡張機能のインストール

1. エディタの統合ターミナルで `opencode` を実行し、公式の手順に従って自動的に拡張機能をインストールします。または、対応するマーケットプレイスから手動でインストールすることもできます。
2. エディタをリロードします。
3. OpenCode 拡張機能から `Reply only OK` を発信します。
4. 再度、ファイルを読み取るかコードを変更するリクエストを実行し、IDE 拡張機能が同じプロバイダーとモデルを使用していることを確認します。

## 現在の制約

- プロバイダーの能力は OpenCode ランタイムから来ており、ホストエディタが Ace Data Cloud をネイティブにサポートしていることを示すものではありません。
- VS Code と各フォークの拡張バージョンは異なる可能性があるため、それぞれのバージョンを記録する必要があります。
- 通常のチャットの成功は、ファイルの読み取り、編集、およびツール呼び出しの検証の代わりにはなりません。
