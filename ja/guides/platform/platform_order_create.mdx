---
title: "AceDataCloud プラットフォームのチャージ注文を作成"
description: "Platform API guide - Ace Data Cloud"
---

1つまたは複数の Application に対して支払い待ち注文を作成します。作成すると注文は記録されますが、支払いは自動的に完了しません。支払い前に、レスポンス内の `price`、パッケージ、および Application を確認してください。

## 準備作業

- [Account Token](https://platform.acedata.cloud/documents/platform-token)を作成します。
- [Application リスト](https://platform.acedata.cloud/documents/platform-application-list)から `application_id` を取得します。
- [サービス詳細](https://platform.acedata.cloud/documents/platform-service-detail)の `packages` から、Application のタイプに一致し購入可能な `package_id` を選択します。

```shell
export PLATFORM_TOKEN='あなたのアカウントトークン'
export APPLICATION_ID='あなたの Application ID'
export PACKAGE_ID='あなたの Package ID'
```

## インターフェース概要

| 項目    | 内容                                              |
| ---- | ----------------------------------------------- |
| メソッド   | `POST`                                          |
| URL  | `https://platform.acedata.cloud/api/v1/orders/` |
| 認証   | Account Token、OAuth token には `orders:write` が必要      |
| Body | JSON                                            |

## リクエストボディ

単一 Application の注文では `application_id` + `package_id` を使用します。バッチ注文では長さが対応する `application_ids` + `package_ids` を使用します。通常の注文では、後続の `/pay/` リクエストで支払い方法を選択します。iOS アプリ内課金注文では、作成時に `pay_way: "AppleIAP"` を渡し、`metadata.apple_product_id` および `metadata.apple_price` を持つ Usage パッケージを1つだけ選択できます。Apple アプリ内課金では独立した米ドルの事前設定価格を使用し、会員割引、支払い方法割引、またはサイト加算料金は適用されません。他の地域での現地通貨の請求額は、Apple の支払い確認ページに従います。

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/orders/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d "{\"application_id\":\"${APPLICATION_ID}\",\"package_id\":\"${PACKAGE_ID}\"}"
```

## レスポンスの説明

成功時には `201` と新しく作成された Order オブジェクトが返されます。主要なフィールドには `id`、`price`、`discount`、`state`、`application_id/application_ids`、`package_id/package_ids`、`expired_at` および時間フィールドが含まれます。新しい注文は通常 `Pending` であり、その後[注文を支払う](https://platform.acedata.cloud/documents/platform-order-pay)を呼び出します。

- `price` はサーバーがパッケージ、サイト加算料金、および割引に基づいて計算した支払額です。クライアント側で独自に計算しないでください。
- Package と Application のサービスまたはタイプが一致しない場合は `400` が返されます。
- 無料でシステム管理されている Package は、公開注文インターフェースを通じて自分で取得することはできません。
- 現在のアカウントに属さない Application の注文を作成すると拒否されます。
