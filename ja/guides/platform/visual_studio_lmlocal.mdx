LMLocal は Visual Studio 2022/2026 向けの拡張機能で、公式に OpenAI 互換 API とカスタム Base URL をサポートしています。設定の入口は拡張のバージョンによって変わる可能性があります。初めて接続する場合は、バージョンを固定し、実際の編集、ツール呼び出し、使用量の記録を確認してください。

## 設定

1. Visual Studio Marketplace または公式リポジトリから LMLocal をインストールします。
2. Providers に Custom/OpenAI 互換 Provider を追加します。
3. Base URL に `https://api.acedata.cloud/v1` を入力します。
4. Auth Key にあなたの Ace Data Cloud API Token を入力します。
5. Model にモデルディレクトリ内で Chat Completions をサポートする正確なモデル ID を入力します。
6. 保存後に `Reply only OK` を送信し、再度プロジェクト編集フローをテストします。

## 現在の境界

- このガイドは LMLocal のみをカバーしており、他の Visual Studio 拡張の共有設定を代表するものではありません。
- 異なるバージョンはそれぞれチャット、編集、ビルドおよびテストリクエストを処理する可能性があり、各モードは独立して検証する必要があります。
- クライアントが自動的に `/v1` またはエンドポイントパスを追加する場合は、重複したパスを避けてください。
