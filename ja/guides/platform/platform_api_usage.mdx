---
title: "AceDataCloud プラットフォーム API の最近の呼び出しサンプルを取得"
description: "Platform API guide - Ace Data Cloud"
---

ある API の直近 15 分間の呼び出し記録サンプルを公開で返し、最近の状態を素早く観察するために使用します。これはステータスコード別に集計されたカウント用インターフェースではなく、個人の請求、SLA、または完全な使用量統計には使用できません。

## インターフェース概要

| 項目   | 内容                                                           |
| --- | ------------------------------------------------------------ |
| メソッド  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| 認証  | 公開、アカウントトークン不要                                                    |
| 上限  | 最近作成/完了した記録を統合後、最大 5,000 件を返却                                    |

`api_id` は [API リスト](https://platform.acedata.cloud/documents/platform-api-list)から取得します。

```shell
export API_ID='あなたの API ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## 実際のレスポンス構造

レスポンスはページネーション envelope を使用せず、直接配列です。

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| フィールド            | 説明        |
| ------------- | --------- |
| `api_id`      | API ID    |
| `created_at`  | 記録作成時刻    |
| `trace_id`    | リクエスト追跡識別子    |
| `status_code` | HTTP ステータスコード  |
| `elapsed`     | 呼び出し所要時間、単位は秒 |

API が存在しない場合でも、現在は空の配列を返す可能性があります。これは、この action が API オブジェクトを先に検証せず、ID によって最近の usage を直接クエリするためです。成功率を計算するには、クライアントが返されたサンプルを自らグループ化する必要があります。個人の課金を確認するには、アカウントレベルのインターフェースを使用してください。
