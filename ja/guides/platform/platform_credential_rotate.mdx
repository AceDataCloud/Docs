---
title: "AceDataCloud プラットフォーム API 認証情報のローテーション"
description: "Platform API guide - Ace Data Cloud"
---

既存の Credential に対して新しい Token またはパスワードを生成します。認証情報 ID、Application の関連付け、上限およびその他のフィールドは変更されず、古いシークレットは直ちに無効になります。

> ローテーションにより、引き続き古いシークレットを使用しているクライアントは中断されます。書き込み操作を実行する前に、安全な配布およびロールバックの計画を準備してください。

## インターフェース概要

| 項目    | 内容                                                                          |
| ---- | --------------------------------------------------------------------------- |
| メソッド   | `POST`                                                                      |
| URL  | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}/rotate/` |
| 認証   | Account Token                                                               |
| Body | なしまたは `{}`                                                                     |

[認証情報リスト](https://platform.acedata.cloud/documents/platform-credential-list)から `credential_id` を取得します：

```shell
export PLATFORM_TOKEN='あなたのアカウントトークン'
export CREDENTIAL_ID='ローテーションする Credential ID'

curl -X POST \
  "https://platform.acedata.cloud/api/v1/credentials/${CREDENTIAL_ID}/rotate/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

成功すると、更新された Credential が返されます。`type=Token` の場合は新しい `token` を読み取り、`type=Identity` の場合は新しい `password` を読み取ります。完全なレスポンスをシークレットとして扱い、直ちに呼び出し元を更新してください。

## エラー処理

- `401`：Account Token が無効です。
- `403`：この認証情報を管理する権限がありません。
- `404`：Credential ID が存在しません。
