---
title: "Tripo 3D 生成"
description: "Tripo 3D API guide - Ace Data Cloud"
---

`POST /tripo/generations` を呼び出して新しいモデルを作成し、テキスト、単一画像、または同じ物体の複数視点を渡します。AceDataCloud Token を使用し、デフォルトでは結果が同期的に返されます。`async: true` または `callback_url` を渡した場合、まず HTTP 200 と `task_id` が返されます。完了時のコールバックは同期結果と同じ JSON 構造を持ちます。

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

`action` のデフォルトは `generate` です。入力は `prompt`（1～1024 文字）、`image_url`、`image_urls` のいずれかを選択します。画像は最大 20 MiB の公開 HTTPS PNG/JPEG です。複数視点は正面、左、背面、右の順に並べ、正面と少なくとももう一面を指定する必要があります。間の視点は null で省略できます。

`model` のデフォルトは `v3.1-20260211` で、`v3.0-20250812`、`v2.5-20250123`、`P1-20260311`、または `P2-20260801` を明示的に選択することもできます。`texture` のデフォルトは `standard` で、ジオメトリのみの場合は `none` を使用します。モデルとテクスチャのグレードによって消費されるクォータが異なります。

`data[0].model_url` から GLB をダウンロードします。`image_url` は任意のプレビューです。後続のテクスチャ、変換、またはボーン操作に使用するため、`data[0].id` を保持してください。同じ送信を再試行する際は、同じ `Idempotency-Key` とリクエスト本文を保持してください。
