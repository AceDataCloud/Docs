title: "Tripo モデル処理"

`POST /tripo/models` を使用して既存のモデルを処理し、必要な `action` を渡します。同期、非同期、コールバック、アカウントへの帰属、およびタスクの照会は 3D 生成と同じです。

| action  | 入力                                                                | 結果                                                                   |
| ------- | ----------------------------------------------------------------- | -------------------------------------------------------------------- |
| import  | `model_url`、公開 HTTPS の GLB、GLTF、FBX、OBJ、または STL ファイル、最大 150 MiB       | 引き続き参照できるモデル ID と GLB；データがある場合は `normalize_scale` と `normalize_translation` を返す |
| texture | `model_id` または `model_url`；オプションで `prompt`、`image_url`、`image_urls` のいずれか一つ | 新しいモデル、テクスチャ、およびオプションのプレビュー                                                          |
| convert | `model_id` または `model_url`、および変換先の `format`                            | 変換後のモデルファイル                                                             |

```json
{"action":"texture","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","prompt":"蓝色哑光表面","texture_quality":"standard","async":true}
```

テクスチャ品質は `fast`、`standard`、`detailed`、`extreme` に対応しています。テキストプロンプトを使用する場合は `style_image_url` を追加できます；画像およびマルチビューの参照は生成インターフェースの形式に従います。その他のテクスチャパラメータについては OpenAPI を参照してください。

変換は `GLTF`、`FBX`、`USDZ`、`OBJ`、`STL`、および `3MF` に対応しています。返される項目の `format` は実際の提供形式を示します；例えば、GLTF をリクエストした場合、バイナリ GLB が提供されることがあります。OBJ はマテリアルとテクスチャを ZIP にパッケージ化します。FBX をリクエストする際に `texture_packaging: "zip"` を設定すると、分離されたテクスチャを取得でき、パッケージ化された結果には `container: "ZIP"` と明記されます。デフォルト以外のメッシュまたはテクスチャ設定を有効にすると、高度な変換として課金される場合があります。詳しくはサービス料金を参照してください。

`data[0].id` を使用して本アカウントのモデルを参照します。インポートされた正規化変換は `normalized = original × normalize_scale + normalize_translation` を満たします。モデルのダウンロード先は `data[0].model_url` にあります。
