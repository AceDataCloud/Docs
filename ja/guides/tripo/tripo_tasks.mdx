---
title: "Tripo モデルタスクの照会"
description: "Tripo 3D API guide - Ace Data Cloud"
---

AceDataCloud Token を使って `POST /tripo/tasks` を呼び出します。照会は無料で、生成時と同じアカウントを使用します。単一タスクには `id` または `trace_id` を使用し、`action` のデフォルトは `retrieve` です。

```bash
curl -X POST https://api.acedata.cloud/tripo/tasks \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H "Content-Type: application/json" \
  -d "{\"action\":\"retrieve\",\"id\":\"${TASK_ID}\"}"
```

単一タスクの結果はタスクレコードで、`id`、`type`、`trace_id`、元のリクエスト `request`、`started_at`、`progress` が含まれます。処理中は数秒間隔で照会を続けることができます。完了後は `response.success` を確認し、成功した場合は `response.data[0].model_url` がダウンロード先で、失敗した場合は `response.error` にエラーコードとメッセージが含まれます。タイムスタンプ、`finished_at`、所要時間 `elapsed` はタスクレコードのトップレベルにあり、単位は秒です。`submission_unknown` が発生した場合は、元のタスク ID を保持して確認します。

一括照会には `{"action":"retrieve_batch","ids":["&lt;タスク ID 1>","&lt;タスク ID 2>"]}` を使用し、`trace_ids` も使用できます。1 回につき最大 100 件です。レスポンスは `{"items":[...],"count":2}` で、入力順序と重複項目が保持されます。見つからない、または読み取り権限のないタスクは、単一照会では `{}` が返され、一括照会では対応する位置が `null` になります。

タスクレコードの `type` は `generations`、`models` または `animations` です。骨格チェックでは `response.data[0].riggable` を読み取り、ファイル関連の操作では `response.data[0].model_url` を読み取ります。
