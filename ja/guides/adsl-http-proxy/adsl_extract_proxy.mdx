本文書は、ADSL Proxy API 操作の使用フローについて説明します。これを利用することで、ADSL の IP を簡単に抽出し、ADSL Proxy に IP ホワイトリストを追加することができます。

## 申請フロー

ADSL の IP を抽出し、ADSL Proxy に IP ホワイトリストを追加するには、まず [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/adsl-extract) と [ADSL Proxy Whitelist API](https://platform.acedata.cloud/documents/adsl-whitelist) ページで「Acquire」ボタンをクリックして、リクエストに必要な認証情報を取得します：

![](https://cdn.acedata.cloud/nyq0xz.png)

まだログインまたは登録していない場合は、自動的にログインページにリダイレクトされ、登録とログインを促されます。ログインまたは登録後、現在のページに自動的に戻ります。

初回申請時には無料のクレジットが付与され、この API を無料で使用できます。

## ADSL の IP を抽出

次に、[ADSL Proxy Extract API](https://platform.acedata.cloud/documents/adsl-extract) インターフェースで対応する内容を入力し、ADSL の IP を抽出する方法を示します。

### リクエストヘッダーとリクエストボディの設定

**Request Headers** には以下が含まれます：

- `accept`：JSON形式のレスポンス結果を受け取ることを指定します。ここには `application/json` と記入します。
- `authorization`：APIを呼び出すためのキーで、申請後に直接ドロップダウンから選択できます。

**Request Body** には以下が含まれます：

- `number`：抽出する ADSL の IP 数量で、デフォルトは 1 です。
- `type`：抽出する ADSL の IP タイプで、主に `http` と `socks` に分かれ、デフォルトは `http` です。
- `province`：IP の所在省で、デフォルトはランダムです。
- `city`：IP の所在都市で、デフォルトはランダムです。

パラメータ `province` と `city` の設定には要件があります。これらは対応している必要があります。例えば、`city` ：南昌は `province` ：江西 に対応する必要があります。具体的なルールは以下の通りです：

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/adsl/extract' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "province": "浙江",
  "city": "温州"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "province": "浙江",
    "city": "温州"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

結果には `data` フィールドがあり、ここにはこの場所で抽出された IP タスクの詳細が含まれています。他の情報は以下の図の通りです：

- `success`、ここで抽出された ADSL の IP タスクの結果状態。
- `data`、抽出された ADSL の IP 詳細情報。

`data` からこの IP の詳細情報が明確にわかります。主な情報は `ip` が今回抽出された IP アドレスを示し、他の情報は以下の通りです：

- `ip`、ここで抽出された ADSL の IP アドレス。
- `port`、ここで抽出された ADSL の IP ポート情報。
- `proxy`、抽出された ADSL の IP プロキシの完全情報。
- `province`、抽出された ADSL の IP が所在する省。
- `city`、抽出された ADSL の IP が所在する都市。

上記の `proxy` を使用して次の IP プロキシ作業を簡単に行うことができます。

まず、IP プロキシを使用する前に、自分のネットワーク IP アドレス（ローカルネットワーク IP の取得方法は自分で調べてください）を以下のホワイトリストに追加する必要があります。次に、IP プロキシの使用方法について説明します：

### プロキシの使用

> 注意：抽出されたプロキシ IP を使用する前に、必ず IP ホワイトリストに追加してください。そうしないと使用できません。ホワイトリストの追加に関する説明は以下の内容を参照してください。

Curl の例コード：

```shell
curl -x 115.219.4.171:23456 myip.vpsnb.net # http プロキシ
curl --socks5 115.219.3.54:23457 myip.vpsnb.net # socks プロキシ
```

Python の例プロキシ：

```python
import requests
import socks
import socket
import time

def test_http_proxy(proxy):
    try:
        start_time = time.time()
        response = requests.get(
            'http://httpbin.org/ip', proxies={'http': proxy, 'https': proxy}, timeout=100)
        elapsed_time = time.time() - start_time
        print(response)
        if response.status_code == 200:
            print(f"HTTP プロキシ {proxy} 成功。時間: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"HTTP プロキシ {proxy} 失敗。コード: {response.status_code}")
    except Exception as e:
        print(f"HTTP プロキシ {proxy} 失敗: {str(e)}")

def test_socks_proxy(proxy):
    proxy_parts = proxy.split(':')
    if len(proxy_parts) != 2:
        print(f"SOCKS 失敗: {proxy}")
        return

    host, port = proxy_parts
    port = int(port)

    try:
        start_time = time.time()
        socks.set_default_proxy(socks.SOCKS5, host, port)
        socket.socket = socks.socksocket
        response = requests.get('http://httpbin.org/ip', timeout=10)
        elapsed_time = time.time() - start_time

        if response.status_code == 200:
            print(f"SOCKS プロキシ {proxy} 成功。時間: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"SOCKS プロキシ {proxy} 失敗。コード: {response.status_code}")
    except Exception as e:
        print(f"SOCKS プロキシ {proxy} 失敗: {str(e)}")
    finally:
        socks.set_default_proxy()
        socket.socket = socket.socket

if __name__ == "__main__":
    # HTTP プロキシ
    http_proxy = "http://115.219.4.171:23456"
    test_http_proxy(http_proxy)

    # SOCKS プロキシ
    socks_proxy = "115.219.3.54:23457"
    test_socks_proxy(socks_proxy)
```

## IPホワイトリストの追加

次に、画面上に対応する内容を入力できます。以下の図のように：

<p><img src="https://cdn.acedata.cloud/wz4obo.png" width="500" class="m-auto"></p>

このインターフェースを初めて使用する際には、少なくとも3つの内容を入力する必要があります。一つは`authorization`で、ドロップダウンリストから直接選択できます。もう一つのパラメータは`ip`で、`ip`は上文から抽出したIPプロキシのローカルネットワークアドレスです。最後のパラメータは`action`で、`action`はホワイトリストに対する操作であり、ここではホワイトリストに追加する操作です。

また、右側に対応する呼び出しコードが生成されていることに注意できます。コードをコピーして直接実行することも、直接「Try」ボタンをクリックしてテストすることもできます。

<p><img src="https://cdn.acedata.cloud/cs5ib2.png" width="500" class="m-auto"></p>

Pythonのサンプル呼び出しコード：

```python
import requests

url = "https://api.acedata.cloud/adsl/whitelist"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "ip": "113.112.122.132",
    "action": "add"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

呼び出し後、返された結果は以下の通りです：

```json
{
  "success": true
}
```

返された結果には一つのフィールドがあり、以下のように説明されます：

- `success`、ここでの操作結果の状態。

`success`は操作結果の状態を含んでおり、IP `113.112.122.132`がホワイトリストに正常に追加されたことがわかります。

## エラーハンドリング

APIを呼び出す際にエラーが発生した場合、APIは対応するエラーコードと情報を返します。例えば：

- `400 token_mismatched`：不正なリクエスト、パラメータが欠落または無効である可能性があります。
- `400 api_not_implemented`：不正なリクエスト、パラメータが欠落または無効である可能性があります。
- `401 invalid_token`：未認証、無効または欠落した認証トークン。
- `429 too_many_requests`：リクエストが多すぎます、レート制限を超えました。
- `500 api_error`：内部サーバーエラー、サーバーで何かがうまくいきませんでした。
