Google SERP（Search Engine Results Page）は、ユーザーが Google 検索エンジンでクエリを入力した後に表示される結果ページです。自然検索結果、広告、強調スニペット、ナレッジグラフ、および画像、動画などの多様なコンテンツを表示し、ユーザーに最も関連性の高い情報を提供することを目的としています。

本記事では Google SERP API について詳しく紹介します。これは Google 検索エンジンでクエリを入力して結果を取得でき、結果のコンテンツにも強調スニペット、ナレッジグラフ、および画像などの多様な結果が含まれています。

本ドキュメントでは Google SERP API の連携ガイドを紹介します。

## 申請手順

Google SERP API を使用するには、まず [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications) で API Token を取得し、予備として保管してください。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

まだログインまたは登録していない場合は、自動的にログインページへリダイレクトされ、登録とログインを求められます。完了後は自動的に現在のページへ戻ります。

**1 つの API Token でプラットフォームのすべてのサービスを呼び出すことができ、サービスごとに個別申請する必要はありません。** 初回申請時には無料クレジットが付与され、無料で体験できます。クレジットが不足した場合は [コンソール](https://platform.acedata.cloud/console/coin) で共通残高をチャージできます。

> 📘 完全なドキュメント：[Google SERP API →](https://platform.acedata.cloud/documents/serp-google)

## 基本的な使用方法

キーワードと検索リソースの種類を入力するだけで結果を取得できます。`query` でキーワードを渡し、`type` でウェブページ、画像、ニュースなどの検索タイプを選択します。このインターフェースでは `model` を渡す必要はありません。

例えば、「apple inc」に関する情報を検索する場合、次にインターフェース上で対応する内容を入力できます。図のとおりです。

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

ここでは Request Headers を設定していることがわかります。以下が含まれます。

- `accept`：どのような形式のレスポンス結果を受け取りたいかを指定します。ここでは `application/json`、つまり JSON 形式を入力します。
- `authorization`：API を呼び出すためのキーであり、申請後に直接ドロップダウンから選択できます。

また、Request Body も設定しています。以下が含まれます。

- `type`：検索リソースのタイプです。現在は 6 種類のタイプのみをサポートしており、デフォルトは `search` です。
- `query`：検索キーワードです。
- `country`：検索結果の対象国をカスタマイズします。デフォルトはアメリカ（US）です。
- `language`：検索結果の言語をカスタマイズします。デフォルトは英語（en）です。
- `range`：検索結果の期間範囲をカスタマイズします。デフォルトでは制限なしです。
- `number`：検索結果のページネーションのページサイズをカスタマイズします。デフォルトは 10 です。
- `page`：検索結果のページネーションのページ番号をカスタマイズします。デフォルトは 1 です。

選択後、右側にも対応するコードが生成されていることがわかります。図のとおりです。

また、対応する連携コードを生成したい場合は、直接コピーして生成できます。たとえば、CURL のコードは以下のとおりです。

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc"
}'
```

Python の連携コードは以下のとおりです。

```python
import requests

url = "https://api.acedata.cloud/serp/google"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "query": "apple inc"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## カスタム検索タイプ

検索リソースのタイプをカスタマイズする場合は、パラメータ `type` を変更できます。これには通常リソース `search`、画像リソース `images`、ニュースリソース `news`、地図リソース `maps`、地域リソース `places`、動画リソース `videos` が含まれます。本文では動画リソース `videos` を例として示します。

以下では、具体的な操作を実演します。

まず、`type` パラメータを `videos` に設定し、通常どおり `query` パラメータを渡します。以下の図のとおりです。
<p><img src="https://cdn.acedata.cloud/czlt12.png" width="500" className="m-auto" /></p>

対応するコードは以下のとおりです：

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "videos",
  "query": "apple inc"
}'
```
