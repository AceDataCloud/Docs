Google SERP（検索エンジン結果ページ）は、ユーザーが Google 検索エンジンにクエリを入力した後に表示される結果ページです。自然検索結果、広告、特徴的な要約、知識グラフ、画像、動画など、さまざまなコンテンツを表示し、ユーザーに最も関連性の高い情報を提供することを目的としています。

この記事では、Google SERP API について詳しく説明します。これは、Google 検索エンジンにクエリを入力して結果を取得するためのもので、結果の内容には特徴的な要約、知識グラフ、画像など、さまざまなタイプが含まれています。

この文書では、Google SERP API の接続説明を紹介します。

## 申請プロセス

Google SERP API を使用するには、まず [Google SERP API](https://platform.acedata.cloud/documents/serp-google) の該当ページでサービスを申請する必要があります。ページに入ったら、「Acquire」ボタンをクリックします。以下の図のように：

![](https://cdn.acedata.cloud/q6ytrc.png)

まだログインまたは登録していない場合は、自動的にログインページにリダイレクトされ、登録とログインを促されます。ログインまたは登録後、現在のページに自動的に戻ります。

初回申請時には無料のクレジットが付与され、この API を無料で使用できます。

## 基本使用

まず、基本的な使用方法を理解します。検索リソースのタイプとキーワードを入力することで、検索結果を得ることができます。単純に `query` フィールドを渡し、対応するモデルを指定するだけです。

例えば、「apple inc」に関する情報を探す場合、次に画面に対応する内容を入力します。以下の図のように：

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

ここでは、Request Headers を設定しています。これには以下が含まれます：

- `accept`：受け取りたいレスポンス結果の形式。ここでは `application/json`、つまり JSON 形式を指定します。
- `authorization`：API を呼び出すためのキー。申請後、直接ドロップダウンから選択できます。

さらに、Request Body を設定しています。これには以下が含まれます：

- `type`：検索リソースのタイプ。現在は6種類のみサポートされており、デフォルトは `search` です。
- `query`：検索するキーワード。
- `country`：検索結果の国をカスタマイズ。デフォルトはアメリカ（US）です。
- `language`：検索結果の言語をカスタマイズ。デフォルトは英語（en）です。
- `range`：検索結果の時間範囲をカスタマイズ。デフォルトは制限なしです。
- `number`：検索結果のページサイズをカスタマイズ。デフォルトは10です。
- `page`：検索結果のページ数をカスタマイズ。デフォルトは1です。

また、対応する接続コードを生成したい場合は、生成されたものを直接コピーできます。例えば、CURLのコードは以下の通りです：

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "アップル社"
}'
```

Pythonの接続コードは以下の通りです：

```python
import requests

url = "https://api.acedata.cloud/serp/google"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "query": "アップル社"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## カスタム検索タイプ

カスタム検索リソースのタイプを指定する場合、`type`パラメータを変更できます。これには、通常のリソース`search`、画像リソース`images`、ニュースリソース`news`、地図リソース`maps`、地域リソース`places`、動画リソース`videos`が含まれます。この記事では、動画リソース`videos`を例に示します。

次に、具体的な操作を示します。

まず、`type`パラメータを`videos`に設定し、`query`パラメータを正常に渡します。
<p><img src="https://cdn.acedata.cloud/czlt12.png" width="500" className="m-auto" /></p>

対応するコードは以下の通りです：

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "videos",
  "query": "apple inc"
}'
```
