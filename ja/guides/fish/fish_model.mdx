本インターフェースは [Fish Audio 公式 Model API](https://docs.fish.audio/resources/api-reference/model) に基づき、**1つの音声サンプルに基づいて長期的に再利用可能なクローン音声モデルを作成する**ために使用されます。エンドポイントは `POST https://api.acedata.cloud/fish/model` です。

> 参考音声を一時的に使用するだけの場合は、モデルを作成する必要はなく、[Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) の `references` を直接使用して一度限りの即時クローンを行えます。既存の音色をページネーションで検索する場合は [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query) を参照してください。`_id` によって単一の音色詳細を照会する場合は [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get) を参照してください。

## 申請フロー

Fish Model API を使用するには、まず [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications) にアクセスして API Token を取得し、控えておいてください。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

まだログインまたは登録していない場合は、ログインページに自動的にリダイレクトされ、登録とログインを促されます。完了後、自動的に現在のページへ戻ります。

**1つの API Token でプラットフォーム上のすべてのサービスを呼び出すことができ、サービスごとに個別の申請は不要です。** 初回申請時には無料クレジットが付与され、無料で試用できます。クレジットが不足した場合は [コンソール](https://platform.acedata.cloud/console/coin) で共通残高をチャージできます。

> 📘 完全なドキュメント：[Fish Model API →](https://platform.acedata.cloud/services/fish)

## リクエストボディフィールド

| フィールド                      | 型       | 必須  | 説明                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | はい   | 音色名。コンソールのリストで識別するために使用されます。                                                             |
| `voices`                | string   | はい   | 音声サンプルの HTTP(S) URL（**単一の文字列**であり、配列ではありません）。本インターフェースは multipart/バイナリアップロードをサポートしていないため、先に音声を任意の公開アクセス可能なオブジェクトストレージに配置してください。 |
| `description`           | string   | いいえ   | 音色の説明。                                                                         |
| `cover_image`           | string   | いいえ   | カバー画像の HTTP(S) URL。                                                              |
| `tags`                  | string[] | いいえ   | 公開ライブラリ検索タグ。例：`["male","narration","zh"]`。                                       |
| `texts`                 | string[] | いいえ   | サンプルに対応する参照テキスト（発音の補正に使用）。                                                           |
| `enhance_audio_quality` | boolean  | いいえ   | 学習前にサンプルの音質を強化するかどうか。                                                                |
| `generate_sample`       | boolean  | いいえ   | 学習完了後にサンプル音声を自動生成するかどうか。                                                            |

> 音色モデルの詳細については、[Fish 公式ドキュメント](https://docs.fish.audio/resources/api-reference/model) を参照してください。

> 作成された音色は長期的に公開保存され、他のユーザーが検索して使用する可能性があります。`visibility` を渡す必要はありません。`private` または `unlist` を渡した場合でも、現在のインターフェースではそれに応じて公開範囲は変更されません。

## 例：公開クローン音声を作成する

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "私のクローン音色",
    "description": "ポッドキャスト録音の一部を使用してクローンした中国語音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> 注意：`voices` は配列ではなく、**文字列**（単一の音声 URL）である必要があります。`["..."]` の指定はサポートされていません。`.mp3` または `.wav` の拡張子を持ち、公開ダウンロード可能な直接リンクを使用することを推奨します。

成功時のレスポンスでは、Fish プラットフォームの ModelEntity オブジェクトが直接返されます（以下の例は、当社でテスト済みの最小限の使用可能な音声であり、読みやすさのため一部の長いフィールドを省略しています）：

`_id` は、後続の [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) における `reference_id` フィールドの値として使用でき、このクローン音声を用いた音声合成に使用されます：

作成に成功した音声は公開保存されます。[Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query) の `self=true` を使用して、現在の呼び出しユーザーが本プラットフォームで作成した音声を照会できます。`self=true` はリストの絞り込みのみを行い、他のユーザーによるこの音声の使用を制限するものではありません。

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "こんにちは、これは私が先ほど作成したクローン音色を使用して合成した音声です。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## サンプル要件

推奨事項（詳細は [Fish 公式ドキュメント](https://docs.fish.audio/resources/api-reference/model) を参照）：

- 長さは 30 秒以上、5 分以内が最適です。10 分を超える場合、追加の効果は限定的です。
- サンプリングレートは 16 kHz 以上で、モノラル・ステレオのどちらでも使用できます。
- 内容はできるだけクリーンにしてください。背景音楽、エコー、目立つ環境ノイズがなく、同一話者であることが望ましいです。
- 推奨フォーマット：`mp3` / `wav`。

サンプル品質に不安がある場合は、`enhance_audio_quality: true` を同時に渡して音質向上を有効にできます。

## 料金説明
音色クローンモデル（`POST /fish/model`）の作成は無料で、料金は一切かかりません。音色の照会インターフェース（[Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)、[Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)）も同様に課金されません。料金が発生するのは、その後 [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) を呼び出して音声を合成する際の使用量のみです。

## エラー処理

- `400 token_mismatched`：リクエストパラメータが不足しているか不正です（最も多いのは、`voices` が URL ではない、または配列として渡されているケースです）。
- `400`：参照音声をダウンロードできない、長さが短すぎる、または形式を認識できない場合は、音声 URL とファイル形式を確認してください。
- `401 invalid_token`：認証 token が存在しないか無効です。
- `429 too_many_requests`：アカウントのレート制限が発動しています。
- `500 api_error`：サーバー内部エラーです。

エラーレスポンスの例：

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 結論

このインターフェースを呼び出すには、公開アクセス可能なサンプル音声 URL を用意し、それを `voices` フィールドに入れるだけで `_id` を取得できます。その後、それを `/fish/tts` の `reference_id` に渡せば、エンドツーエンドの「クローン → 合成」が完了します。よくある落とし穴は、`voices` が文字列でなければならず、配列にはできないことです。

## MCP を通じた音色の作成と再利用

Fish MCP では、次を呼び出します。
`fish_create_model(title="私の音色", voices="https://example.com/authorized-voice.wav")`。
`voices` は単一の HTTP(S) 音声 URL です。`description`、`cover_image`、`tags`、
`texts`、`enhance_audio_quality`、`generate_sample` も渡せます。

このツールは公開音色を長期間保存し、他のユーザーが見つけて使用する可能性があります。処理および公開の許可を得た
音声素材のみを使用してください。ツールには非公開または非公開設定のオプションはありません。作成成功時に返される `_id` は
`fish_generate_audio` の `reference_id` に使用され、`fish_list_models(self=true)` では自分が
保存した音色を照会できます。一度だけ参照音声を使用する場合は、`fish_generate_audio` の `references` を使用し、
長期的な音色を作成する必要はありません。
