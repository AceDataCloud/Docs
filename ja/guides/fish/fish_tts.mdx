本インターフェースは、テキストを音声に変換し、保存された音声を呼び出し、一時的な音声クローンを提供します。アドレスは `POST https://api.acedata.cloud/fish/tts` です。

## 申請プロセス

Fish TTS API を使用するには、まず [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications) で API トークンを取得し、保管してください。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

まだログインまたは登録していない場合は、自動的にログインページにリダイレクトされ、登録とログインを促されます。完了後、現在のページに自動的に戻ります。

**1つの API トークンでプラットフォームのすべてのサービスを呼び出すことができ、各サービスごとに個別に申請する必要はありません。** 初回申請時には無料枠が付与され、無料で体験できます。枠が不足した場合は、[コンソール](https://platform.acedata.cloud/console/coin) で共通残高をチャージできます。

> 📘 完全なドキュメント：[Fish TTS API →](https://platform.acedata.cloud/services/fish)

## リクエストヘッダー

| ヘッダー          | 必須  | 説明                                                                                                     |
| --------------- | --- | ------------------------------------------------------------------------------------------------------ |
| `authorization` | はい   | `Bearer {token}`、`{token}` はこのプラットフォームで申請したキーです。                                                                 |
| `content-type`  | はい   | `application/json`。                                                                                    |
| `accept`        | いいえ | `application/json`。                                                                                    |
| `model`         | いいえ | TTS モデル、選択肢は `s1`、`s2-pro` または `s2.1-pro`、デフォルトは `s2-pro`。`s2.1-pro` は最新世代、`s2-pro` は表現力が強い；`s1` はより安定しており、長文がずれにくい。3つは同価格です。 |

## リクエストボディフィールド

| フィールド         | タイプ                 | 必須  | 説明                                                                                                                                                                                                     |
| -------------- | ------------------ | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `text`         | string             | はい   | 合成するテキスト、空でない文字列。                                                                                                                                                                                          |
| `format`       | string             | いいえ | 出力音声フォーマット、選択肢は `mp3`（デフォルト）、`wav`、`pcm`。`wav` と `pcm` は WAV コンテナで返されます。`opus` はサポートされておらず、入力すると直接 `400` が返されます。                                                                                                                  |
| `reference_id` | string \| string[] | いいえ | 保存済みまたは公共の音声のモデル ID、[Fish Model API](https://platform.acedata.cloud/documents/fish-model) で作成するか、[Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) で取得できます。`references` と同時に使用することはできません。 |
| `references`   | object[]           | いいえ | 一時的な音声クローン、1つの `{audio, text}` サンプルのみサポート：`audio` は公開 HTTPS MP3/WAV URL、`text` は音声の正確な逐語訳です。`reference_id` と同時に使用することはできません。                                                                                             |
| `sample_rate`  | integer            | いいえ | サンプリングレート、一般的には `16000`、`22050`、`44100`。`format=mp3` の場合はデフォルトで 44100。                                                                                                                                                  |
| `mp3_bitrate`  | integer            | いいえ | MP3 ビットレート、選択肢は `64`、`128`、`192`。`format=mp3` の場合のみ有効です。                                                                                                                                                          |
| `prosody`      | object             | いいえ | 韻律のカバー、`speed`（速度、1.0 が元の速度）と `volume`（音量ゲイン dB）をサポートします。例： `{"speed":1.2,"volume":0}`。                                                                                                                          |
| `chunk_length` | integer            | いいえ | 上流のチャンク長、デフォルトは上流が決定します。                                                                                                                                                                                         |
| `temperature`  | number             | いいえ | サンプリング温度、範囲は約 0.0–1.0。                                                                                                                                                                                      |
| `top_p`        | number             | いいえ | top-p サンプリングパラメータ。                                                                                                                                                                                            |
| `latency`      | string             | いいえ | `normal` または `balanced`、デフォルトはこのインターフェースが自動的に `normal` を補完します（空文字列を送信すると上流が拒否します）。                                                                                                                                                |
| `normalize`    | boolean            | いいえ | テキストを正規化するかどうか。                                                                                                                                                                                             |
| `callback_url` | string             | いいえ | 非同期コールバックアドレス、詳細は下記「非同期コールバック」を参照してください。**これは公式インターフェースの拡張です。**                                                                                                                                                                     |

> 一時的なクローンは HTTPS 音声 URL のみを受け付け、MessagePack、Base64、data URI または認証付き URL は受け付けません。参考音声は 10–270 秒を推奨；Studio ではより保守的な 10–60 秒の範囲を使用します。

## 例 1：最小リクエスト（`text` + `format=mp3`）

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hello world.",
    "format": "mp3"
  }'
```

返却（実測）：

```json
{
  "audio_url": "https://platform2.cdn.acedata.cloud/fish/e2ffcc06-18da-4a8c-b9aa-9337d0f9ec1d.mp3"
}
```

`audio_url` は本プラットフォームの CDN を指し、直接 GET でダウンロードするか `<audio>` で再生できます。最終的な成功応答には、トップレベルの `cost` も返され、その中の `amount` は今回実際に差し引かれたクレジットです；アカウント割引がある場合、`list_amount` は割引前の額を示します。リンクは長期間利用可能ですが、自分のストレージにもコピーを残すことをお勧めします。

## 例 2：クローン音色 `reference_id` の使用

以下は Fish プラットフォーム上の公開されたスペイン語音色を使用します（`_id` は [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) で取得できます）：

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

返却（実測）：

```json
{
  "audio_url": "https://platform2.cdn.acedata.cloud/fish/b6f161f2-a100-4818-add2-47694f234659.mp3"
}
```

## 例 3：一時的な音声クローン（`references`）

参考音声を公開 HTTPS アドレスに置き、実際に話された正確な原文を提供します。この音声は今回の合成のみに使用され、長期モデルは作成されません：

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s2-pro' \
  -d '{
    "text": "新的旅程从这一刻开始，让我们一起向前。",
    "format": "mp3",
    "references": [{
      "audio": "https://platform2.cdn.acedata.cloud/fish/6220d605-39d0-4d43-9e58-0f12949dc9b9.mp3",
      "text": "春天的清晨，阳光穿过树叶，落在安静的小路上。"
    }]
  }'
```

実測成功応答：
```json
{
  "audio_url": "https://platform2.cdn.acedata.cloud/fish/995dfe37-b187-474d-8323-b08d6678ed8f.mp3",
  "cost": {"amount": 0.007609319999999999, "currency": "credit"}
}
```

| 方法             | ライフサイクル       | 適用シーン                          |
| -------------- | ---------- | ----------------------------- |
| `references`   | 今回の TTS リクエストのみ | 一時的な使用または毎回異なる音声                   |
| `reference_id` | 繰り返し使用可能      | 公共の音声または `/fish/model` で作成された長期的な音声 |

## 例 3：話速 / 音量の調整（`prosody`）

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Faster speech with prosody overrides.",
    "prosody": { "speed": 1.2, "volume": 0 },
    "format": "mp3"
  }'
```

返却（実測）：

```json
{
  "audio_url": "https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"
}
```

`speed` が 1 より大きいと速く、小さいと遅くなります；`volume` の単位は dB で、0 は変わらず、正の数は増加、負の数は減少を示します。

## 例 5：モデルの切り替え + ビットレートの制御

HTTP ヘッダー `model: s1` で安定型モデルに切り替え、リクエストボディに `mp3_bitrate: 128` を追加して MP3 ビットレートを制御します：

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s1' \
  -d '{
    "text": "high bitrate mp3",
    "format": "mp3",
    "mp3_bitrate": 128
  }'
```

返却（実測）：

```json
{
  "audio_url": "https://platform2.cdn.acedata.cloud/fish/7e7abf3d-3d72-4c9f-8eb6-8af932d7c96e.mp3"
}
```

## 例 6：PCM 生波形

ブラウザでリアルタイムに結合する必要がある、またはクライアントで後処理（ミキシング、速度変更）を行うシーンでは、`pcm` の使用を推奨します：

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "hi",
    "format": "pcm",
    "sample_rate": 16000
  }'
```

返却（実測）：

```json
{
  "audio_url": "https://platform2.cdn.acedata.cloud/fish/64adc04b-c196-4a0f-9070-222ba101ce6c.wav"
}
```

> リンクの拡張子はリクエスト内の `format` に従います：`mp3` で `.mp3`、`wav` と `pcm` で `.wav`（WAV コンテナ、16 bit PCM）。

## 非同期コールバック（`callback_url`）

長いテキストの合成には十数秒から数十秒かかることがあり、接続が中断された場合は再試行が必要です。リクエストボディに `callback_url` を渡すと、インターフェースはすぐに `{task_id, started_at}` を返し、上流が実際に完了した時に完全な結果を POST JSON 形式でその URL にコールバックします。リクエストボディには同じ `task_id` と今回の最終的な請求のトップレベル `cost` が含まれます。初期タスクの確認は合成がまだ完了していないため、`cost` は含まれません。

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "今天天気真好，我们一起出去散散步吧。",
    "format": "mp3",
    "callback_url": "https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34"
  }'
```

即時返却（実測）：

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "started_at": 1778462584.742
}
```

後で `callback_url` は次のような形で受け取ります：

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "audio_url": "https://platform2.cdn.acedata.cloud/fish/bd66b8c5-7543-4557-b684-baa72407e336.mp3"
}
```

また、[Fish Tasks API](https://platform.acedata.cloud/documents/fish-tasks) を使用して `task_id` に基づいて結果をプルすることもできます；最終状態の記録の `response.cost` はコールバック内の `cost` と一致し、詳細はその文書を参照してください。

## エラーハンドリング

- `400 token_mismatched`：リクエストパラメータが欠落または不正（最も一般的なのは `text` が空、または `format` に `mp3`/`wav`/`pcm` 以外の値が渡された場合）。
- `401 invalid_token`：認証トークンが存在しないか無効。
- `429 too_many_requests`：アカウントのレート制限が発動。
- `500 api_error`：サーバー内部エラー。

エラー応答の例：

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

パラメータ検証エラーは `message` フィールドに不正なフィールドを説明します。例えば：

```json
{
  "status": 400,
  "message": "[{\"type\":\"literal_error\",\"loc\":[\"format\"],\"msg\":\"Input should be 'pcm' or 'mp3'\",\"input\":\"wav\"}]"
}
```

## 結論

Fish TTS を接続するための最小コストは：既存の `api.fish.audio/v1/tts` を呼び出すコード内で認証をこのプラットフォームのトークンに変更し、リクエストボディに**明示的に** `format: "mp3"` を含めることです。長いテキストのシーンでは `callback_url` 非同期コールバックの使用を推奨します；クローン音色 `reference_id` の発見には、[Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) と [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) を組み合わせて使用してください。
