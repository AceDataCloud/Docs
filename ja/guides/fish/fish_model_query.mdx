本インターフェースは [Fish Audio 公式 Model API](https://docs.fish.audio/resources/api-reference/model) に基づいており、**Fish の公開音色ライブラリまたは現在のアカウント配下のクローン音色をページネーションで検索する**ために使用されます。URL は `GET https://api.acedata.cloud/fish/model` です。

> 音色の作成については [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model) を参照してください。`_id` による単一音色の詳細検索については [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get) を参照してください。

## 申請フロー

Fish Model API を使用するには、まず [Ace Data Cloud コンソール](https://platform.acedata.cloud/console/applications) で API Token を取得し、控えておいてください。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

まだログインまたは登録していない場合は、ログインページに自動的に移動して登録とログインを促されます。完了後、自動的に現在のページへ戻ります。

**1 つの API Token でプラットフォーム上のすべてのサービスを呼び出すことができ、サービスごとに個別に申請する必要はありません。** 初回申請時には無料クレジットが付与され、無料でお試しいただけます。クレジットが不足した場合は、[コンソール](https://platform.acedata.cloud/console/coin) で共通残高をチャージできます。

> 📘 完全なドキュメント：[Fish Model API →](https://platform.acedata.cloud/services/fish)

## クエリパラメータ

| パラメータ             | 型    | デフォルト | 説明                                                                                  |
| ---------------- | ------- | ---- | ------------------------------------------------------------------------------------- |
| `page_size`      | integer | 10   | 1ページあたりの件数。                                                                            |
| `page_number`    | integer | 1    | 1から始まるページ番号。                                                                          |
| `title`          | string  | —    | タイトルであいまい検索します。                                                                      |
| `tag`            | string  | —    | 単一のタグでフィルタリングします。                                                                      |
| `self`           | boolean | —    | `true` の場合、現在の呼び出しアカウントが本プラットフォームを通じて作成・保存した音声のみを返します。                                |
| `author_id`      | string  | —    | 音声作成者 ID でフィルタリングします。                                                                  |
| `language`       | string  | —    | 音声の言語でフィルタリングします。例：`en`、`zh`、`es`。                                                  |
| `title_language` | string  | —    | 公開音声ライブラリ内で、タイトルの言語によりフィルタリングします。                                                        |
| `sort_by`        | string  | —    | ソートフィールド。`self=true` の場合、`created_at`、`task_count` をサポートします。                              |

## 例 2：タイトルによるあいまい検索（`title`）

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

レスポンス（実測）：

```json
{
  "total": 161,
  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",
      "type": "tts",
      "title": "Miles Morales ( Narration Paw )",
      "tags": ["male", "middle-aged", "entertainment", "storytelling", "Children's Content"],
      "languages": ["en"],
      "visibility": "public",

    },
    {
```

`title` は「グローバルあいまい一致」であり、Fish 公開ライブラリ内のすべての音色に一致することに注意してください（自分のものだけではありません）。

## 例 3：自分で作成した音色のみを一覧表示（`self=true`）

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

レスポンス例：

```json
{
  "total": 1,
  "items": [
    {
      "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
      "type": "tts",
      "title": "copilot-smoke-test",
      "description": "smoke test from api.acedata.cloud",
      "state": "trained",
      "languages": ["zh"],
      "visibility": "public",
      "samples": [
        {
          "title": "Default Sample",
          "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
          "task_id": "6a1bf398dfae49dca0e23159214342a0",
          "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
        }
      ],
      "created_at": "2026-05-10T03:52:55.601000Z",
      "author": {
        "_id": "780f2b2f862d41a08c0507bbbda77eb6",
        "nickname": "Penny Conrad"
      }
    }
  ],
  "has_more": false
}
```
`self=true` は、実際に呼び出しを行うアカウントによって本プラットフォーム上で作成・保存された音声を一覧表示します。同一アカウントが異なる API Token を使用して作成した音声も一緒に一覧表示されます。結果は作成時間の降順でページネーションされ、`author_id` でこれらの音声の作者 ID をさらに絞り込めます。このパラメータは一覧のみを絞り込み、音声は引き続き公開利用可能です。

`self=true` は `title_language` をサポートしません。タイトルの言語で検索する必要がある場合は、公開音声ライブラリを照会してください。

## 例4：言語 + タグでフィルタリング

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> `tag` は比較的緩やかに一致します。ヒット件数が 0 の場合は、`title` のあいまい一致を使用することを推奨します。

## レスポンスフィールド

`items[]` 内の各項目は完全な ModelEntity オブジェクトであり、よく使用されるフィールドは以下のとおりです。

| フィールド            | 型       | 説明                                        |
| ------------- | -------- | ----------------------------------------- |
| `_id`         | string   | 音声 ID。`/fish/tts` 内の `reference_id` の値として使用します。 |
| `type`        | string   | モデルタイプ。通常は `tts`。                           |
| `title`       | string   | 音声名。                                     |
| `description` | string   | 音声の説明。                                     |
| `state`       | string   | トレーニング状態：`trained` は利用可能であることを示します。                      |
| `tags`        | string[] | 公開ライブラリのタグ。                                    |
| `languages`   | string[] | 音声が得意とする言語。                                  |
| `visibility`  | string   | `public` または `private`。                     |
| `samples`     | object[] | プリセットサンプル（`audio` の直接リンクを含む）。                       |
| `like_count`  | integer  | 公開ライブラリのいいね数。                                   |
| `task_count`  | integer  | 過去の合成回数。                                   |
| `author`      | object   | 音声作者情報：`_id` / `nickname` / `avatar`。     |
| `total`（トップレベル）   | integer  | 条件を満たす総件数。                                 |
| `has_more`    | boolean? | `self=true` の場合はブール値。公開音声ライブラリの照会では `null` になる可能性があります。      |

## 料金について

本インターフェースは課金されません——音声リストのページネーション照会は無料操作です。音声の作成（[Fish Model Create](https://platform.acedata.cloud/documents/fish-model)）も同様に無料で、料金は [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) を呼び出して音声を合成する際にのみ、使用量に応じて発生します。

## エラー処理

- `400 token_mismatched`：リクエストパラメータが不足している、または不正です。
- `401 invalid_token`：認証 token が存在しない、または無効です。
- `429 too_many_requests`：アカウントのレート制限が発動しました。
- `500 api_error`：サーバー内部エラーです。

エラーレスポンス例：

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 結論

Fish 公開ライブラリから音声を選択して `/fish/tts` の `reference_id` に渡すには、まず本インターフェースで `title` / `tag` / `language` を組み合わせて検索し、対象の `_id` を特定してから、[Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) でサンプルを取得して試聴します。自分で作成した音声を一覧表示するには、`self=true` を渡すだけです。
