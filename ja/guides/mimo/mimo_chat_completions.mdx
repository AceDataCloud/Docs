MiMo 2.6 Pro と MiMo 2.6 Flash は Xiaomi MiMo シリーズのモデルです。本インターフェースは OpenAI Chat Completions 形式を使用し、入力、出力、およびキャッシュヒット token に基づいて課金されます。

## モデルとインターフェース

| モデル                | 用途           |
| ----------------- | ------------ |
| `mimo-v2.6-pro`   | 複雑な分析、推論、ツール呼び出し |
| `mimo-v2.6-flash` | 日常会話と軽量タスク    |

MiMo を有効化して対応する API 認証情報を取得し、`https://api.acedata.cloud/mimo/chat/completions` にリクエストを送信します。OpenAI SDK の `base_url` は `https://api.acedata.cloud/mimo` に設定できます。統一された `/v1/chat/completions` エントリにも、対応するサービス権限が必要です。

初回のインターフェース範囲はテキスト Chat Completions です。画像、音声、動画、インターネット検索、Responses、Messages、Batch、および UltraSpeed は今回のリリース範囲に含まれません。

## Python の例

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ACEDATACLOUD_API_KEY"],
    base_url="https://api.acedata.cloud/mimo",
)
response = client.chat.completions.create(
    model="mimo-v2.6-pro",
    messages=[{"role": "user", "content": "解释彩虹形成的原因。"}],
    max_completion_tokens=256,
    extra_body={"thinking": {"type": "disabled"}},
)
print(response.choices[0].message.content)
print(response.usage)
```

この例はリクエストの記述方法を示しています。実際のレスポンス例は、サービス検証後に追加されます。

## ストリーミング、推論、およびツール呼び出し

`stream=true` を設定して SSE を受信します。最終的な使用量が必要な場合は、`stream_options={"include_usage": true}` を渡します。クライアントは、コンテンツ、推論コンテンツ、ツール呼び出しの増分、および最終的な usage イベントを処理する必要があります。

`thinking.type=enabled` を使用して推論を有効化し、`disabled` で無効化します。`reasoning_content` と最終的な `content` は分けて返されます。ツール呼び出しを継続する際は、アシスタントメッセージ内の推論コンテンツ、完全な `tool_calls`、および対応する `tool_call_id` を保持します。

`type=function` のツール宣言のみを送信し、`tool_choice` は `auto` のみをサポートします。アプリケーションはツールを実行して結果を返送する責任を負います。モデルがツール呼び出しを返すこと自体は、ツールが実行済みであることを意味しません。サービス内蔵のインターネット検索はまだ公開されていません。

## 課金

`prompt_tokens` にはキャッシュヒットした入力が含まれます。`prompt_tokens_details.cached_tokens` はキャッシュ価格で計算され、残りの入力は通常の入力価格で計算されます。`completion_tokens` には推論出力が含まれるため、推論 token を重複して加算しないでください。ストリーミング呼び出しも最終的な実使用量に基づいて精算されます。

価格はコンソールの内容に準拠し、Credit の米ドルコストは購入プランによって異なります。失敗したリクエストは正常に完了したものと見なすべきではありません。課金を確認する必要がある場合は、レスポンス内の追跡識別子を提供してください。

## エラー処理

パラメータエラーの場合はリクエスト形式を確認してください。認証または権限エラーの場合は認証情報とサービスの有効化状況を確認してください。429 が発生した場合は、バックオフして再試行してください。正常なモデル容量がない場合、503 が返されることがあります。ストリーミングレスポンスの開始後に中断が発生した場合は、受信済みの結果と使用量を先に確認し、無闇にリクエストを繰り返さないでください。
