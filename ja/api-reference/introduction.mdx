## 基本 URL

すべての API エンドポイントの基本アドレス：

```
https://api.acedata.cloud
```

## 認証

すべてのエンドポイントは Bearer トークン認証が必要です：

```
Authorization: Bearer YOUR_API_TOKEN
```

## オンラインテスト

本リファレンスの各エンドポイントにはインタラクティブなサンドボックスが含まれています。API トークンを入力するだけでブラウザ上で直接リクエストをテストできます。

<Note title="Tip">
  [platform.acedata.cloud](https://platform.acedata.cloud) で API トークンを取得してください。
</Note>
