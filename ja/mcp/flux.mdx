[MCP（Model Context Protocol）](https://modelcontextprotocol.io) は Anthropic が発表したモデルコンテキストプロトコルであり、AI モデル（Claude、GPT など）が標準化されたインターフェースを通じて外部ツールを呼び出すことを可能にします。AceData Cloud が提供する Flux MCP Server を使用すると、Claude Desktop、VS Code、Cursor などの AI クライアントで AI 画像を直接生成・編集できます。

## 機能概要

Flux MCP Server は以下の主要機能を提供します：

- **テキストから画像を生成** — テキストプロンプトを通じて高品質な画像を生成
- **画像編集** — テキスト指示に基づいて既存の画像を編集
- **複数モデル対応** — Flux Pro、Flux Dev、Flux 2、Flux Kontext など複数のモデルに対応
- **モデル照会** — 利用可能なすべてのモデルおよびその機能を確認
- **タスク照会** — 生成の進行状況を監視して結果を取得

## 事前準備

使用前に、AceData Cloud API Token を取得する必要があります：

1. [AceData Cloud プラットフォーム](https://platform.acedata.cloud)に登録またはログイン
2. [Flux Images API](https://platform.acedata.cloud/documents/flux-images) ページにアクセス
3. 「Acquire」をクリックして API Token を取得（初回申請時は無料クレジットを進呈）

## 方法 1：ホスト型 MCP Server を使用（推奨、インストール不要）

AceData Cloud はすでに **Flux MCP Server** をクラウド上でホストしており、**ローカルに依存関係をインストールする必要はありません**。AI クライアントに以下の URL を直接入力するだけで使用できます：

```
https://flux.mcp.acedata.cloud/mcp
```

認証方法：リクエストヘッダーに `Authorization: Bearer あなたのAPI Token` を追加するだけです（Claude.ai は OAuth を通じて自動的に完了するため、Token を手動で入力する必要はありません）。

### Claude.ai（Web 版、OAuth ログイン、最も簡単）

1. [Claude.ai](https://claude.ai) を開く → 左下の **Customize** → **Connectors** → **Add More**
2. URL に入力：`https://flux.mcp.acedata.cloud/mcp`
3. OAuth 認可ログインを完了（AceData Cloud ログインページに自動的にリダイレクト）
4. 会話画面に戻ると、ツールを使用できます

### Claude Desktop

設定ファイルを編集：

- macOS：`~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows：`%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

保存後、Claude Desktop を再起動すると有効になります。

### Claude Code（ターミナルコマンドライン）

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### その他の MCP 対応クライアント

MCP Streamable HTTP プロトコルに対応するすべてのクライアント（Windsurf、Cline、ChatGPT Connectors、Gemini CLI、JetBrains AI Assistant など）は、以下の 2 項目を入力することで連携できます：

- **URL**：`https://flux.mcp.acedata.cloud/mcp`
- **Header**：`Authorization: Bearer あなたのAPI Token`

## 方法 2：ローカル実行（pip / uvx インストール）

オフライン実行、コードのカスタマイズ、またはイントラネットへのデプロイが必要な場合は、MCP Server をローカルにインストールし、stdio を通じて起動できます。

### インストール

pip によるインストール（推奨）：

```bash
pip install mcp-flux-pro
```

またはソースからインストール：

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

インストール完了後、`mcp-flux-pro` コマンドを使用してサービスを起動できます。

### Claude Desktop で使用（ローカル）

Claude Desktop の設定ファイルを編集：

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

以下の設定を追加：

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

`uvx` を使用する場合（事前にパッケージをインストールする必要なし）：

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

設定を保存後、Claude Desktop を再起動すると有効になります。

## 利用可能なツール一覧

| ツール名                    | 説明                       |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | テキストプロンプトを通じて画像を生成              |
| `flux_edit_image`      | テキスト指示に基づいて既存の画像を編集             |
| `flux_generate_video`  | FLUX 3 のテキストから動画/画像から動画/動画生成および既存ドラフトの強化 |
| `flux_get_task`        | 単一タスクの状態を照会                 |
| `flux_get_tasks_batch` | タスクの状態を一括照会                 |
| `flux_list_models`     | 利用可能なすべてのモデルおよびその機能を一覧表示             |
| `flux_list_actions`    | 利用可能なすべてのツールとワークフロー例を一覧表示           |

## 使用例

設定完了後、AI クライアントで自然言語を使ってこれらの機能を直接呼び出すことができます。例えば：

- 「Flux を使ってサイバーパンク風の都市の夜景を生成して」
- 「この写真の背景をビーチに変更して」
- 「Flux Kontext Pro モデルを使ってこの画像を編集し、服の色を赤に変更して」
- 「利用可能なすべての Flux モデルを一覧表示して」

## モデルとサイズの制約
`flux-2-flex`、`flux-2-pro`、`flux-2-max` および Kontext モデルの `size` には、
`1:1` や `16:9` などの比率を使用する必要があり、`1024x1024` のようなピクセル寸法は使用できません。
`flux-2-klein` は生成のみをサポートしており、`flux_edit_image` の選択可能なモデルには含まれません。

`flux_generate_video` は `request.mode` によって `t2v`、`i2v`、`v2v` および
`draft_enhance` を区別し、入力はモードに応じて表示されます。ドラフト強化は自身の一時的な `draft_task_id` を参照する必要があります。
送信はデフォルトで非同期であり、返されたタスク ID を保持し、`flux_get_task` を使用して結果を取得します。
