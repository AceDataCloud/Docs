[ MCP（Model Context Protocol）](https://modelcontextprotocol.io) は Anthropic が提供するモデルコンテキストプロトコルであり、AI モデル（Claude、GPT など）が標準化されたインターフェースを通じて外部ツールを呼び出すことを可能にします。AceData Cloud が提供する Suno MCP Server を通じて、Claude Desktop、VS Code、Cursor などの AI クライアントで音楽や歌詞を直接生成し、オーディオプロジェクトを管理できます。

## 機能概要

Suno MCP Server は以下の主要機能を提供します：

- **音楽生成** — テキストプロンプトを通じて AI 音楽を生成
- **カスタム作成** — 歌詞、タイトル、音楽スタイルを完全に制御
- **楽曲の続きを作成** — 任意の時点から既存の楽曲を継続して延長
- **カバー/リミックス** — 異なるスタイルでカバーバージョンを作成
- **歌詞生成** — 説明に基づいて構造化された歌詞を生成
- **ボーカルキャラクター** — 声のスタイルを保存して再利用
- **メディア変換** — MP4、WAV、MIDI、ボーカル分離などを取得
- **スタイル最適化** — 音楽スタイルタグを最適化
- **タスク照会** — 生成の進捗を監視して結果を取得

## 事前準備

使用前に、AceData Cloud API Token を取得する必要があります：

1. [AceData Cloud プラットフォーム](https://platform.acedata.cloud)に登録またはログイン
2. [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios) ページに移動
3. 「Acquire」をクリックして API Token を取得（初回申請では無料クレジットを進呈）

## 方法一：ホスティングされた MCP Server を使用（推奨、インストール不要）

AceData Cloud はすでに **Suno MCP Server** をクラウド上でホスティングしており、**ローカルに依存関係をインストールする必要はありません**。AI クライアントで以下の URL を入力するだけで使用できます：

```
https://suno.mcp.acedata.cloud/mcp
```

認証方法：リクエストヘッダーに `Authorization: Bearer 你的API Token` を追加するだけです（Claude.ai では OAuth により自動的に完了するため、Token を手動で入力する必要はありません）。

### Claude.ai（Web版、OAuth ログイン、最も簡単）

1. [Claude.ai](https://claude.ai) を開く → 左下の **Customize** → **Connectors** → **Add More**
2. URL に以下を入力：`https://suno.mcp.acedata.cloud/mcp`
3. OAuth 認可ログインを完了（AceData Cloud のログインページへ自動的に遷移）
4. 会話画面に戻ると、ツールを使用できます

### Claude Desktop

設定ファイルを編集：

- macOS：`~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows：`%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

保存後、Claude Desktop を再起動すると有効になります。

### Claude Code（ターミナルコマンドライン）

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### その他の MCP 対応クライアント

MCP Streamable HTTP プロトコルに対応するすべてのクライアント（Windsurf、Cline、ChatGPT Connectors、Gemini CLI、JetBrains AI Assistant など）は、以下の 2 項目を入力して連携できます：

- **URL**：`https://suno.mcp.acedata.cloud/mcp`

## 方法二：ローカルで実行（pip / uvx インストール）

オフライン実行、コードのカスタマイズ、またはイントラネットへのデプロイが必要な場合は、MCP Server をローカルにインストールして stdio 経由で起動できます。

### インストール

pip によるインストール（推奨）：

```bash
pip install mcp-suno
```

またはソースコードからインストール：

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

インストール完了後、`mcp-suno` コマンドを使用してサービスを起動できます。

### Claude Desktop で使用（ローカル）

Claude Desktop の設定ファイルを編集：

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

以下の設定を追加：

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

`uvx` を使用する場合（パッケージを事前にインストールする必要はありません）：

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

設定を保存した後、Claude Desktop を再起動すると有効になります。

設定完了後、AI クライアントで自然言語を使ってこれらの機能を直接呼び出せます。たとえば：

- 「夏についてのポップミュージックを1曲生成して」

- 「この曲のボーカルを分離して」
- 「この曲を MIDI 形式に変換して」

## 高度な制御と Studio プロジェクト

`suno_generate_music` は `variety` をサポートします。`suno_generate_custom_music` はさらに
`max_mode` と `audio_weight` をサポートします。`max_mode` はより高い API 課金ティアを使用し、デフォルトでは有効化されません。
ユーザーが強化モードを明示的に選択した後に設定する必要があります。現在の価格はプラットフォームのサービスページに準じます。

`suno_generate_with_custom_model` は `instrumental=true` を使用してインストゥルメンタルを生成するか、
`lyric_prompt` を使用して歌詞を自動生成できます。それ以外の場合は `lyric` を提供します。タイトル、スタイルは省略でき、さらに
`negative_tags`、`vocal_gender`、`weirdness`、`style_influence`、`duration` と
`callback_url` を渡すことができます。明示的な `0` の制御値は保持されます。

`suno_manage_project` の `request.action` では、`create`、`retrieve`、`save`、
`upload`、`add_track`、`generate_track`、`replace_section`、`commit_candidate`、
`remove_track`、`render` を選択できます。入力はアクションごとに異なり、プロジェクトの変更では直近に読み戻した `version_id` を使用する必要があります。
保存時には完全な `state` を渡し、既存のトラックとフィールドを保持します。

`retrieve` を除き、各呼び出しでは必ず `idempotency_key` を指定する必要があります。新しい書き込み操作には新しいキーを使用します。
タイムアウトまたは受理結果が不確かな場合は、元のキーと完全に同一のリクエストで再試行するか、元のタスクを照会し、自動的に
キーを変更して有料生成を再送しないでください。ソース音声の区間には秒を使用し、プロジェクトのタイムライン区間には拍数を使用します。生成では候補のみが作成され、
候補を選択して `commit_candidate` を呼び出した場合にのみトラックへ書き込まれます。

非同期で受理された `task_id` は `suno_get_task` で照会します。`finished_at` が空の場合は待機を続け、
終端状態になった後に `response.success` とエラーを確認してください。受理成功を生成、コミット、またはエクスポートの成功と見なさないでください。
`suno_get_tasks_batch` は完全な JSON タスクレコードを返し、カスタムモデルオブジェクト、プロジェクト状態、
候補、MIDI などの各種結果を保持します。完全なワークフローについては、[Studio プロジェクトガイド](https://platform.acedata.cloud/documents/suno-projects-integration)を参照してください。
