[MCP（Model Context Protocol）](https://modelcontextprotocol.io) は、Anthropic によって提供されるモデルコンテキストプロトコルで、AI モデル（Claude、GPT など）が標準化されたインターフェースを通じて外部ツールを呼び出すことを可能にします。AceData Cloud が提供する Midjourney MCP サーバーを使用することで、Claude Desktop、VS Code、Cursor などの AI クライアントで直接 AI 画像を生成および編集できます。

## 機能概要

Midjourney MCP サーバーは以下のコア機能を提供します：

- **画像生成（Imagine）** — テキストプロンプトを使用して高品質の画像を生成
- **画像編集** — 生成された画像の一部を修正
- **画像変換** — 既存の画像を拡大、縮小、移動
- **画像混合（Blend）** — 複数の画像を融合して新しい画像を作成
- **参考画像生成** — 参考画像を使用して生成をガイド
- **画像説明（Describe）** — 画像に基づいてテキスト説明を生成
- **プロンプト翻訳** — 中国語のプロンプトを英語に翻訳
- **シード取得** — 画像のシード値を取得して再現
- **動画生成** — 画像に基づいて動的な動画を生成
- **タスククエリ** — 生成の進捗を監視し、結果を取得

## 前提準備

使用する前に、AceData Cloud API トークンを取得する必要があります：

1. [AceData Cloud プラットフォーム](https://platform.acedata.cloud) に登録またはログイン
2. [Midjourney Imagine API](https://platform.acedata.cloud/documents/midjourney-imagine) ページに移動
3. 「Acquire」をクリックして API トークンを取得（初回申請で無料枠をプレゼント）

## インストール設定

### 方法一：pip インストール（推奨）

```bash
pip install mcp-midjourney
```

### 方法二：ソースコードインストール

```bash
git clone https://github.com/AceDataCloud/MidjourneyMCP.git
cd MidjourneyMCP
pip install -e .
```

インストールが完了したら、`mcp-midjourney` コマンドを使用してサービスを起動できます。

## Claude Desktop での使用

Claude Desktop の設定ファイルを編集：

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

以下の設定を追加：

```json
{
  "mcpServers": {
    "midjourney": {
      "command": "mcp-midjourney",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPIトークン"
      }
    }
  }
}
```

`uvx` を使用する場合（事前にパッケージをインストールする必要はありません）：

```json
{
  "mcpServers": {
    "midjourney": {
      "command": "uvx",
      "args": ["mcp-midjourney"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPIトークン"
      }
    }
  }
}
```

設定を保存した後、Claude Desktop を再起動すると、対話の中で Midjourney 関連のツールを使用できるようになります。

## VS Code / Cursor での使用

プロジェクトのルートディレクトリに `.vscode/mcp.json` を作成：

```json
{

    "midjourney": {
      "command": "mcp-midjourney",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPIトークン"
```

または `uvx` を使用：

## 利用可能なツール一覧

| ツール名                          | 説明           |
| ---------------------------- | ------------ |
| `midjourney_imagine`         | テキストプロンプトを使用して画像を生成  |
| `midjourney_edit`            | 既存の画像の一部を編集  |
| `midjourney_transform`       | 既存の画像を拡大、縮小、移動 |
| `midjourney_blend`           | 複数の画像を混合して一つにする   |
| `midjourney_with_reference`  | 参考画像を使用して画像を生成    |
| `midjourney_describe`        | 画像に基づいてテキスト説明を生成   |
| `midjourney_translate`       | プロンプトを英語に翻訳     |
| `midjourney_get_seed`        | 画像のシード値を取得 |
| `midjourney_generate_video`  | 画像に基づいて動画を生成     |
| `midjourney_extend_video`    | 既存の動画を延長       |
| `midjourney_get_task`        | 単一タスクの状態を確認     |
| `midjourney_get_tasks_batch` | 複数タスクの状態を一括確認     |

## 使用例

設定が完了したら、AI クライアントで自然言語を使用してこれらの機能を直接呼び出すことができます。例えば：

- 「サイバーパンクスタイルの都市の夜景を生成して」
- 「この画像の背景を海辺に変更して」
- 「この4枚の画像を1枚に混合して」
- 「この画像の内容を説明して」
- 「この画像を動画にして」
- 「この画像の2番目のバリエーションを拡大して」
