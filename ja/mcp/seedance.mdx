[MCP（Model Context Protocol）](https://modelcontextprotocol.io) は Anthropic が提供するモデルコンテキストプロトコルであり、AI モデル（Claude、GPT など）が標準化されたインターフェースを通じて外部ツールを呼び出すことを可能にします。AceData Cloud が提供する Seedance MCP Server を通じて、Claude Desktop、VS Code、Cursor などの AI クライアントで ByteDance Seedance を直接使用して AI 動画を生成できます。

## 機能概要

Seedance MCP Server は以下のコア機能を提供します：

- **テキストから動画生成** — テキストプロンプトを通じて高品質な動画を生成
- **画像から動画生成** — 画像を参照して動画を生成（開始フレーム、終了フレーム、参照画像などのモード）
- **複数モデルのサポート** — Seedance 1.x、1.5、2.0、2.5 をサポート
- **複数の解像度** — 480p、720p、1080p をサポートし、一部のモデルは 4k をサポート
- **複数のアスペクト比** — 16:9、9:16、1:1、4:3、3:4、21:9、adaptive をサポート
- **柔軟な長さ** — モデルに応じて 2～30 秒または自動長をサポート
- **マルチモーダル動画** — 音声生成、参照音声/動画、および 2.5 の動画編集と延長をサポート
- **タスク照会** — 生成の進捗を監視し、結果を取得

## 推奨：ホスト型 MCP の OAuth 認可を使用する

リモート MCP OAuth をサポートするクライアントでサーバーアドレスを追加します：

```text
https://seedance.mcp.acedata.cloud/mcp
```

接続またはログインを選択し、Ace Data Cloud にログインして、権限を確認して認可し、その後ツールを有効にします。この方法では、事前に API Token を作成またはコピーする必要はありません。サービスは OAuth discovery、動的クライアント登録（DCR）、および S256 PKCE をサポートしています。DCR はクライアントを登録しますが、ユーザーは引き続きログインと認可を行う必要があり、API の利用は通常どおり課金されます。

| クライアント                            | 接続方法と条件                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Claude Web 版またはリモートコネクタを提供する Desktop 版 | コネクタ画面で上記アドレスを追加して認可します。利用入口はバージョンとプランにより異なります。リモート HTTP 設定をローカル stdio 設定ファイルに書き込まないでください。                      |
| ネイティブのリモート MCP OAuth をサポートする VS Code     | **MCP: Add Server** を実行し、HTTP を選択してアドレスを入力し、指示に従ってログインします。専用 AceDataCloud 拡張機能は独立した API Key 設定を使用します。 |
| その他のクライアント                          | 現在のバージョンがリモート HTTP、OAuth/DCR をサポートしていることを確認し、そのクライアントの設定説明を使用してください。設定ファイル形式はクライアント間で共通ではありません。                     |

## API Token の代替経路

ローカル stdio、セルフホスト、またはリモート OAuth をサポートしないクライアントでは API Token を使用します。[Ace Data Cloud プラットフォーム](https://platform.acedata.cloud) にログインし、サービスを選択して必要な権限を持つ API 認証情報を作成します。Token はクライアントの認証情報設定またはローカル環境変数に保存し、URL、チャット内容、またはリポジトリには配置しないでください。異なるクライアントの HTTP Header 設定は、各バージョンの説明に従って入力してください。

オープンソース MCP をインストールすること、または認可を完了することは、無料枠の取得を意味するものではなく、生成時間または商用利用権を保証するものでもありません。生成前に、現在のサービス価格、残高、適用される規約を確認してください。

## 方法 2：ローカルで実行（pip / uvx インストール）

ローカル stdio、カスタムコード、またはセルフホストが必要な場合は、ローカルで MCP Server を起動できます。生成には引き続きネットワーク経由で API を呼び出す必要があり、オフライン推論ではありません。

### インストール

pip インストール（推奨）：

```bash
pip install mcp-seedance
```

またはソースからインストール：

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

インストール完了後、`mcp-seedance` コマンドを使用してサービスを起動できます。

### Claude Desktop で使用する（ローカル）

Claude Desktop の設定ファイルを編集します：

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

以下の設定を追加します：

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPI Token"
      }
    }
  }
}
```

`uvx` を使用する場合（事前にパッケージをインストールする必要はありません）：

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPI Token"
      }
    }
  }
}
```

設定を保存した後、Claude Desktop を再起動すると有効になります。

### VS Code で使用する（ローカル）

プロジェクトのルートディレクトリに `.vscode/mcp.json` を作成します：

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPI Token"
      }
    }
  }
}
```

または `uvx` を使用します：

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPI Token"
      }
    }
  }
}
```

その他のローカルクライアントについては、現在のバージョンの stdio 設定説明に従って command、args、env を入力し、VS Code の設定をそのまま汎用形式として使用しないでください。

## 結果の検証とよくある失敗

クライアントに簡単な動画作品を生成させ、タスク番号を保持して同じタスクを照会し、最終状態で成功するまで待ってから、最終リンクを開くか再生してください。接続成功、ツール一覧の読み込み、HTTP 200、タスク番号、および処理中のプレビューは、いずれも最終成果物を意味するものではありません。

401 が発生した場合は、再ログインするか Token と権限を確認してください。残高不足の場合は請求情報を確認してください。タスク処理中は照会を続けてください。最終的に失敗した場合はエラーを確認してから再試行するかを決定してください。新たな生成では再度課金される可能性があります。

## 利用可能なツール一覧

| ツール名                                  | 説明             |
| ------------------------------------ | -------------- |
| `seedance_generate_video`            | テキストプロンプトを通じて動画を生成    |
| `seedance_generate_video_from_image` | 画像を参照して動画を生成     |
| `seedance_get_task`                  | 単一タスクの状態を照会       |
| `seedance_get_tasks_batch`           | タスクの状態を一括照会       |
| `seedance_list_models`               | 利用可能なすべてのモデルとその能力を一覧表示   |
| `seedance_list_resolutions`          | 利用可能な解像度とアスペクト比を一覧表示   |
| `seedance_list_actions`              | 利用可能なすべてのツールとワークフロー例を一覧表示 |

## 使用例

設定完了後、AI クライアント内で自然言語を使ってこれらの機能を直接呼び出すことができます。例えば：

- 「Seedance を使って都市の街頭のタイムラプス動画を生成して」
- 「この写真を最初のフレームとして使用し、8 秒の動画を生成して」
- 「1080p の縦型 9:16 のショート動画を生成して」
- 「Seedance 1.5 Pro モデルで音声付き動画を生成して」
