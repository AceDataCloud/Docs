[MCP（Model Context Protocol）](https://modelcontextprotocol.io) は、Anthropic によって提唱されたモデルコンテキストプロトコルで、AI モデル（Claude、GPT など）が標準化されたインターフェースを通じて外部ツールを呼び出すことを可能にします。AceData Cloud が提供する Sora MCP サーバーを使用することで、Claude Desktop、VS Code、Cursor などの AI クライアントで OpenAI Sora を直接使用して AI ビデオを生成できます。

## 機能概要

Sora MCP サーバーは以下のコア機能を提供します：

- **テキスト生成ビデオ** — テキストプロンプトを使用して高品質のビデオを生成
- **画像生成ビデオ** — 画像を基にビデオを生成
- **キャラクター一貫性ビデオ** — 参照画像を使用してキャラクターの一貫性を保持
- **非同期生成** — 非同期タスクの提出と結果の照会をサポート
- **多様な画面方向** — 横向き（landscape）および縦向き（portrait）をサポート
- **タスク照会** — 生成進捗を監視し、結果を取得

## 前提準備

使用する前に、AceData Cloud API トークンを取得する必要があります：

1. [AceData Cloud プラットフォーム](https://platform.acedata.cloud) に登録またはログイン
2. [Sora Videos API](https://platform.acedata.cloud/documents/sora-videos) ページに移動
3. 「Acquire」をクリックして API トークンを取得（初回申請で無料枠をプレゼント）

## インストール設定

### 方法一：pip インストール（推奨）

```bash
pip install mcp-sora
```

### 方法二：ソースコードインストール

```bash
git clone https://github.com/AceDataCloud/MCPSora.git
cd MCPSora
pip install -e .
```

インストールが完了したら、`mcp-sora` コマンドを使用してサービスを起動できます。

## Claude Desktop での使用

Claude Desktop の設定ファイルを編集します：

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

以下の設定を追加します：

```json
{
  "mcpServers": {
    "sora": {
      "command": "mcp-sora",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPIトークン"
      }
    }
  }
}
```

`uvx` を使用する場合（事前にパッケージをインストールする必要はありません）：

```json
{
  "mcpServers": {
    "sora": {
      "command": "uvx",
      "args": ["mcp-sora"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPIトークン"
      }
    }
  }
}
```

設定を保存した後、Claude Desktop を再起動すると、対話の中で Sora 関連ツールを使用できるようになります。

## VS Code / Cursor での使用

プロジェクトのルートディレクトリに `.vscode/mcp.json` を作成します：

```json
{
  "servers": {
    "sora": {
      "command": "mcp-sora",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPIトークン"
      }
    }
  }
}
```

または `uvx` を使用する場合：

```json
{
  "servers": {
    "sora": {
      "command": "uvx",
      "args": ["mcp-sora"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPIトークン"

  }

```

## 利用可能なツール一覧

| ツール名                                  | 説明             |
| ------------------------------------ | -------------- |
| `sora_generate_video`                | テキストプロンプトを使用してビデオを生成    |
| `sora_generate_video_from_image`     | 画像を基にビデオを生成     |
| `sora_generate_video_with_character` | 参照キャラクター画像を使用して一貫性のあるビデオを生成 |
| `sora_generate_video_async`          | ビデオ生成タスクを非同期で提出     |
| `sora_get_task`                      | 単一タスクの状態を照会       |
| `sora_get_tasks_batch`               | タスクの状態をバッチで照会       |

## 使用例

設定が完了したら、AI クライアントで自然言語を使用してこれらの機能を直接呼び出すことができます。例えば：

- 「Sora を使って草の上を走る猫のビデオを生成して」
- 「この人物の写真を使ってビデオを生成し、キャラクターの一貫性を保って」
- 「縦向きのビデオを生成し、内容は都市の日の出」
- 「ビデオを非同期で生成し、後で結果を照会」
