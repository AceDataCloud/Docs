[MCP（Model Context Protocol）](https://modelcontextprotocol.io) は、Anthropic によって提唱されたモデルコンテキストプロトコルで、AI モデル（Claude、GPT など）が標準化されたインターフェースを通じて外部ツールを呼び出すことを可能にします。AceData Cloud が提供する SERP MCP サーバーを使用することで、Claude Desktop、VS Code、Cursor などの AI クライアントで直接 Google 検索を行い、ウェブページ、画像、ニュース、動画、場所などの検索結果を取得できます。

## 機能概要

SERP MCP サーバーは以下のコア機能を提供します：

- **ウェブ検索** — Google ウェブ結果を検索
- **画像検索** — Google 画像を検索
- **ニュース検索** — Google ニュースを検索
- **動画検索** — Google 動画を検索
- **場所検索** — Google 場所情報を検索
- **地図検索** — Google 地図を検索
- **多言語多地域** — カスタム国と言語パラメータをサポート
- **時間範囲フィルタ** — 日、週、月、年で結果をフィルタ

## 前提準備

使用する前に、AceData Cloud API トークンを取得する必要があります：

1. [AceData Cloud プラットフォーム](https://platform.acedata.cloud) に登録またはログイン
2. [Google SERP API](https://platform.acedata.cloud/documents/serp-google) ページに移動
3. 「Acquire」をクリックして API トークンを取得（初回申請で無料枠をプレゼント）

## インストール設定

### 方法一：pip インストール（推奨）

```bash
pip install mcp-serp
```

### 方法二：ソースコードインストール

```bash
git clone https://github.com/AceDataCloud/SerpMCP.git
cd SerpMCP
pip install -e .
```

インストールが完了したら、`mcp-serp` コマンドを使用してサービスを起動できます。

## Claude Desktop での使用

Claude Desktop の設定ファイルを編集します：

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

以下の設定を追加します：

```json
{
  "mcpServers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPIトークン"
      }
    }
  }
}
```

`uvx` を使用する場合（事前にパッケージをインストールする必要はありません）：

```json
{
  "mcpServers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPIトークン"
      }
    }
  }
}
```

設定を保存した後、Claude Desktop を再起動すると、対話の中で Google 検索関連ツールを使用できるようになります。

## VS Code / Cursor での使用

プロジェクトのルートディレクトリに `.vscode/mcp.json` を作成します：

```json
{
  "servers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPIトークン"
      }
    }
  }
}
```

または `uvx` を使用する場合：

```json
{
  "servers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "あなたのAPIトークン"

  }

```

## 利用可能なツール一覧

| ツール名                  | 説明          |
| -------------------- | ----------- |
| `serp_google_search` | Google ウェブ検索 |
| `serp_google_images` | Google 画像検索 |
| `serp_google_news`   | Google ニュース検索 |
| `serp_google_videos` | Google 動画検索 |
| `serp_google_places` | Google 場所検索 |
| `serp_google_maps`   | Google 地図検索 |

## 使用例

設定が完了したら、AI クライアントで自然言語を使ってこれらの機能を直接呼び出すことができます。例えば：

- 「最新の AI 論文を検索して」
- 「北京の美味しい火鍋店を検索して」
- 「Python の非同期プログラミングに関する画像を探して」
- 「今日のテクノロジーニュースを検索して」
- 「地図で近くのカフェを探して」
