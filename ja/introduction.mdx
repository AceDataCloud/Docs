## Ace Data Cloud とは？

Ace Data Cloud は統一された AI API プラットフォームで、1つの API Key と一貫したインターフェースを通じて、世界をリードする AI サービスにアクセスできます。

## コアメリット

- **統一 API** — 1つの API Key で50以上の AI サービスにアクセス可能
- **OpenAI 互換** — Claude、Gemini、DeepSeek などは OpenAI インターフェースを通じて直接呼び出し可能
- **インタラクティブサンドボックス** — ドキュメント内で各 API を直接テスト可能
- **従量課金制** — サブスクリプション不要、実際の利用量に応じて課金
- **MCP サーバー** — Cursor、Claude などの AI プログラミングツールをネイティブサポート
