すべての Ace Data Cloud API は **Bearer Token** 認証を使用します。

## トークンの取得

[アプリケーション一覧](https://platform.acedata.cloud/console/applications?lang=ja&utm_source=docs&utm_medium=referral&utm_campaign=evergreen)にログインし、**General Application** を開きます。**API KEY** の右側にあるコピーボタンをクリックします。

![General Application の API キー](https://cdn.acedata.cloud/dvc3cg.jpg)

キーはサーバー側で保管し、サンプルの `YOUR_API_TOKEN` をコピーした値に置き換えてください。

## トークンの使用

各リクエストの `Authorization` ヘッダーにトークンを含めます：

```bash
Authorization: Bearer YOUR_API_TOKEN
```


## レート制限

レート制限はサービスおよび購読レベルによって異なります。制限を超えると、API は `429 Too Many Requests` を返します。

## セキュリティのベストプラクティス

- クライアントコードに API トークンを露出しない
- 環境変数でトークンを管理する
- 定期的にトークンをローテーションする
- 開発環境と本番環境で異なるトークンを使用する
