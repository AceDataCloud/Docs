---
title: "認証"
description: "Ace Data Cloud API を使用した認証方法"
---

すべての Ace Data Cloud API は **Bearer Token** 認証を使用します。

## トークンの取得

1. [platform.acedata.cloud](https://platform.acedata.cloud) でアカウントを登録する
2. 必要なサービスを購読する
3. 各サービスごとに認証情報（API トークン）を作成する

## トークンの使用

各リクエストの `Authorization` ヘッダーにトークンを含めます：

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="ヒント">
  各トークンは特定のサービス購読に紐づいています。異なるサービスには異なるトークンを使用するか、サービス間で使用可能な**グローバル**認証情報を作成してください。
</Note>

## レート制限

レート制限はサービスおよび購読レベルによって異なります。制限を超えると、API は `429 Too Many Requests` を返します。

## セキュリティのベストプラクティス

- クライアントコードに API トークンを露出しない
- 環境変数でトークンを管理する
- 定期的にトークンをローテーションする
- 開発環境と本番環境で異なるトークンを使用する
