[MCP (Model Context Protocol)](https://modelcontextprotocol.io) ist ein von Anthropic eingeführtes Modellkontextprotokoll, das es KI-Modellen (wie Claude, GPT usw.) ermöglicht, externe Tools über standardisierte Schnittstellen aufzurufen. Über den von AceData Cloud bereitgestellten Seedance MCP Server kannst du ByteDances Seedance zur Generierung von KI-Videos direkt in KI-Clients wie Claude Desktop, VS Code und Cursor verwenden.

## Funktionsübersicht

Der Seedance MCP Server bietet die folgenden Kernfunktionen:

- **Text-zu-Video** — Generiere hochwertige Videos über Text-Prompts
- **Bild-zu-Video** — Generiere Videos mit Bildern als Referenz (Modi wie erster Frame, letzter Frame, Referenzbild usw.)
- **Unterstützung mehrerer Modelle** — Unterstützt Seedance 1.x, 1.5, 2.0 und 2.5
- **Mehrere Auflösungen** — Unterstützt 480p, 720p, 1080p, einige Modelle unterstützen 4k
- **Mehrere Seitenverhältnisse** — Unterstützt 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 und adaptive
- **Flexible Dauer** — Je nach Modell 2–30 Sekunden oder automatische Dauer
- **Multimodale Videos** — Unterstützt Audiogenerierung, Referenzaudio/-video sowie Videobearbeitung und -verlängerung in 2.5
- **Aufgabenabfrage** — Überwache den Generierungsfortschritt und rufe Ergebnisse ab

## Empfohlen: OAuth-Autorisierung über gehostetes MCP verwenden

Füge in Clients, die Remote-MCP-OAuth unterstützen, die Serveradresse hinzu:

```text
https://seedance.mcp.acedata.cloud/mcp
```

Wähle Verbinden oder Anmelden, melde dich bei Ace Data Cloud an, prüfe die Berechtigungen und autorisiere, aktiviere dann die Tools. Bei diesem Weg musst du nicht zuerst einen API-Token erstellen oder kopieren. Der Dienst unterstützt OAuth Discovery, dynamische Client-Registrierung (DCR) und S256 PKCE; DCR registriert den Client, Benutzer müssen sich weiterhin anmelden und autorisieren, die API-Nutzung wird wie gewohnt abgerechnet.

| Client                            | Integrationsmethode und Voraussetzungen                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Claude Webversion oder Desktop-Versionen mit Remote-Connectors | Füge die obige Adresse in der Connector-Oberfläche hinzu und autorisiere; der Zugang hängt von Version und Tarif ab. Schreibe keine Remote-HTTP-Konfiguration in lokale stdio-Konfigurationsdateien.                      |
| VS Code mit nativer Remote-MCP-OAuth-Unterstützung     | Führe **MCP: Add Server** aus, wähle HTTP, gib die Adresse ein und melde dich gemäß den Anweisungen an; die spezielle AceDataCloud-Erweiterung verwendet eine eigenständige API-Key-Einstellung. |
| Andere Clients                          | Bestätige, dass die aktuelle Version Remote-HTTP, OAuth/DCR unterstützt, und verwende die Konfigurationsanleitung dieses Clients. Konfigurationsdateiformate können nicht zwischen verschiedenen Clients gemeinsam verwendet werden.                     |

## Alternativer Weg über API-Token

Lokales stdio, selbst gehostete oder Clients ohne Remote-OAuth-Unterstützung verwenden API-Token. Melde dich bei der [Ace Data Cloud-Plattform](https://platform.acedata.cloud) an, wähle den Dienst aus und erstelle API-Anmeldedaten mit den erforderlichen Berechtigungen. Speichere den Token in den Anmeldedateneinstellungen des Clients oder in lokalen Umgebungsvariablen, lege ihn nicht in URLs, Chat-Inhalten oder Versionsrepositories ab. Die HTTP-Header-Konfiguration verschiedener Clients sollte gemäß deren Versionsanleitung ausgefüllt werden.

Die Installation von Open-Source-MCP oder der Abschluss einer Autorisierung bedeutet nicht, dass kostenlose Kontingente gewährt werden, und garantiert weder Generierungszeit noch kommerzielle Nutzungsrechte. Prüfe vor der Generierung die aktuellen Servicepreise, das Guthaben und die geltenden Bedingungen.

## Methode zwei: Lokal ausführen (pip / uvx-Installation)

Wenn du lokales stdio, benutzerdefinierten Code oder Selbsthosting benötigst, kannst du den MCP Server lokal starten. Die Generierung muss weiterhin online APIs aufrufen und ist keine Offline-Inferenz.

### Installation

Installation mit pip (empfohlen):

```bash
pip install mcp-seedance
```

Oder Installation aus dem Quellcode:

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Nach Abschluss der Installation kannst du den Dienst mit dem Befehl `mcp-seedance` starten.

### In Claude Desktop verwenden (lokal)

Bearbeite die Claude-Desktop-Konfigurationsdatei:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Füge die folgende Konfiguration hinzu:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Dein API-Token"
      }
    }
  }
}
```

Bei Verwendung von `uvx` (keine vorherige Paketinstallation erforderlich):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Dein API-Token"
      }
    }
  }
}
```

Starte Claude Desktop nach dem Speichern der Konfiguration neu, damit sie wirksam wird.

### In VS Code verwenden (lokal)

Erstelle im Projektstammverzeichnis `.vscode/mcp.json`:

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Dein API-Token"
      }
    }
  }
}
```

Oder verwende `uvx`:

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Dein API-Token"
      }
    }
  }
}
```

Für andere lokale Clients fülle command, args und env gemäß der stdio-Konfigurationsanleitung ihrer aktuellen Version aus; verwende die VS-Code-Konfiguration nicht direkt als universelles Format.

## Ergebnisse überprüfen und häufige Fehler

Bitte den Client, ein einfaches Videowerk zu generieren, behalte die Aufgaben-ID bei und frage dieselbe Aufgabe ab, bis der Endstatus erfolgreich ist, öffne oder spiele dann den endgültigen Link ab. Erfolgreiche Verbindung, geladene Tool-Liste, HTTP 200, Aufgaben-ID und Vorschau während der Verarbeitung stehen nicht für das endgültige Ergebnis.

Bei einem 401 melde dich erneut an oder überprüfe Token und Berechtigungen; bei unzureichendem Guthaben prüfe die Abrechnung; frage bei einer in Verarbeitung befindlichen Aufgabe weiter ab; lies bei einem endgültigen Fehlschlag den Fehler und entscheide dann, ob du es erneut versuchst, eine neue Generierung kann erneut kostenpflichtig sein.

## Liste verfügbarer Tools

| Toolname                                  | Beschreibung             |
| ------------------------------------ | -------------- |
| `seedance_generate_video`            | Generiert Videos über Text-Prompts    |
| `seedance_generate_video_from_image` | Generiert Videos mit Bildern als Referenz     |
| `seedance_get_task`                  | Fragt den Status einer einzelnen Aufgabe ab       |
| `seedance_get_tasks_batch`           | Fragt Aufgabenstatus stapelweise ab       |
| `seedance_list_models`               | Listet alle verfügbaren Modelle und ihre Fähigkeiten auf   |
| `seedance_list_resolutions`          | Listet verfügbare Auflösungen und Seitenverhältnisse auf   |
| `seedance_list_actions`              | Listet alle verfügbaren Tools und Workflow-Beispiele auf |

## Anwendungsbeispiele

Nach Abschluss der Konfiguration kannst du diese Funktionen im KI-Client direkt in natürlicher Sprache aufrufen, zum Beispiel:

- „Hilf mir, mit Seedance ein Zeitraffer-Video einer Stadtstraße zu generieren“
- „Verwende dieses Foto als ersten Frame und generiere ein 8-sekündiges Video“
- „Generiere ein kurzes vertikales 1080p-Video im Format 9:16“
- „Generiere mit dem Modell Seedance 1.5 Pro ein Video mit Audio“
