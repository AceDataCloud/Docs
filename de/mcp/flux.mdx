[MCP (Model Context Protocol)](https://modelcontextprotocol.io) ist ein von Anthropic eingeführtes Modellkontextprotokoll, das es KI-Modellen (wie Claude, GPT usw.) ermöglicht, externe Tools über standardisierte Schnittstellen aufzurufen. Über den von AceData Cloud bereitgestellten Flux MCP Server kannst du KI-Bilder direkt in KI-Clients wie Claude Desktop, VS Code, Cursor usw. generieren und bearbeiten.

## Funktionsübersicht

Der Flux MCP Server bietet die folgenden Kernfunktionen:

- **Text-zu-Bild-Generierung** — Generiert hochwertige Bilder über Text-Prompts
- **Bildbearbeitung** — Bearbeitet vorhandene Bilder basierend auf Textanweisungen
- **Unterstützung mehrerer Modelle** — Unterstützt verschiedene Modelle wie Flux Pro, Flux Dev, Flux 2, Flux Kontext usw.
- **Modellabfrage** — Zeigt alle verfügbaren Modelle und ihre Fähigkeiten an
- **Aufgabenabfrage** — Überwacht den Generierungsfortschritt und ruft Ergebnisse ab

## Voraussetzungen

Vor der Verwendung musst du ein AceData Cloud API-Token erhalten:

1. Registriere dich oder melde dich bei der [AceData Cloud-Plattform](https://platform.acedata.cloud) an
2. Gehe zur Seite [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Klicke auf „Acquire“, um ein API-Token zu erhalten (bei der ersten Beantragung wird ein kostenloses Kontingent vergeben)

## Methode eins: Gehosteten MCP Server verwenden (empfohlen, keine Installation)

AceData Cloud hat den **Flux MCP Server** bereits in der Cloud gehostet. **Es müssen keinerlei Abhängigkeiten lokal installiert werden**. Trage einfach die folgende URL direkt im KI-Client ein, um ihn zu verwenden:

```
https://flux.mcp.acedata.cloud/mcp
```

Authentifizierungsmethode: Füge einfach `Authorization: Bearer dein API-Token` zum Request-Header hinzu (Claude.ai erledigt dies automatisch über OAuth, ohne dass du das Token manuell eingeben musst).

### Claude.ai (Webversion, OAuth-Anmeldung, am einfachsten)

1. Öffne [Claude.ai](https://claude.ai) → unten links **Customize** → **Connectors** → **Add More**
2. Gib bei URL Folgendes ein: `https://flux.mcp.acedata.cloud/mcp`
3. Schließe die OAuth-Autorisierungsanmeldung ab (automatische Weiterleitung zur AceData Cloud-Anmeldeseite)
4. Kehre zur Gesprächsoberfläche zurück, dann kann das Tool verwendet werden

### Claude Desktop

Bearbeite die Konfigurationsdatei:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Starte Claude Desktop nach dem Speichern neu, damit die Änderungen wirksam werden.

### Claude Code (Terminal-Kommandozeile)

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Andere Clients mit MCP-Unterstützung

Jeder Client, der das MCP-Streamable-HTTP-Protokoll unterstützt (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant usw.), kann durch das Eintragen der folgenden beiden Angaben integriert werden:

- **URL**: `https://flux.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer dein API-Token`

## Methode zwei: Lokal ausführen (pip / uvx-Installation)

Wenn du eine Offline-Ausführung, benutzerdefinierten Code oder eine Bereitstellung im Intranet benötigst, kannst du den MCP Server lokal installieren und über stdio starten.

### Installation

Installation mit pip (empfohlen):

```bash
pip install mcp-flux-pro
```

Oder Installation aus dem Quellcode:

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Nach Abschluss der Installation kannst du den Dienst mit dem Befehl `mcp-flux-pro` starten.

### Verwendung in Claude Desktop (lokal)

Bearbeite die Claude Desktop-Konfigurationsdatei:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Füge die folgende Konfiguration hinzu:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Bei Verwendung von `uvx` (keine vorherige Paketinstallation erforderlich):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Starte Claude Desktop nach dem Speichern der Konfiguration neu, damit die Änderungen wirksam werden.

## Liste der verfügbaren Tools

| Toolname                    | Beschreibung                       |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | Generiert Bilder über Text-Prompts              |
| `flux_edit_image`      | Bearbeitet vorhandene Bilder basierend auf Textanweisungen             |
| `flux_generate_video`  | FLUX 3 Text-zu-Video/Bild-zu-Video/Videogenerierung und Verbesserung vorhandener Entwürfe |
| `flux_get_task`        | Fragt den Status einer einzelnen Aufgabe ab                 |
| `flux_get_tasks_batch` | Fragt Aufgabenstatus stapelweise ab                 |
| `flux_list_models`     | Listet alle verfügbaren Modelle und ihre Fähigkeiten auf             |
| `flux_list_actions`    | Listet alle verfügbaren Tools und Workflow-Beispiele auf           |

## Verwendungsbeispiele

Nach Abschluss der Konfiguration kannst du diese Funktionen direkt in KI-Clients mit natürlicher Sprache aufrufen, zum Beispiel:

- „Hilf mir, mit Flux ein Stadtpanorama bei Nacht im Cyberpunk-Stil zu generieren“
- „Ändere den Hintergrund dieses Fotos in einen Strand“
- „Bearbeite dieses Bild mit dem Modell Flux Kontext Pro und ändere die Farbe der Kleidung in Rot“
- „Liste alle verfügbaren Flux-Modelle auf“

## Modell- und Größenbeschränkungen
`flux-2-flex`, `flux-2-pro`, `flux-2-max` und Kontext-Modelle müssen für `size`
Seitenverhältnisse verwenden, zum Beispiel `1:1` oder `16:9`, und dürfen keine Pixeldimensionen wie `1024x1024` verwenden.
`flux-2-klein` unterstützt nur die Generierung und gehört nicht zu den optionalen Modellen in `flux_edit_image`.

`flux_generate_video` unterscheidet über `request.mode` zwischen `t2v`, `i2v`, `v2v` und
`draft_enhance`, die Eingaben werden je nach Modus angezeigt. Die Entwurfsverbesserung muss auf ihre eigene temporäre `draft_task_id` verweisen.
Die Übermittlung erfolgt standardmäßig asynchron; behalten Sie die zurückgegebene Aufgaben-ID und verwenden Sie `flux_get_task`, um die Ergebnisse abzurufen.
