[MCP (Model Context Protocol)](https://modelcontextprotocol.io) ist ein von Anthropic eingeführtes Modellkontextprotokoll, das es KI-Modellen (wie Claude, GPT usw.) ermöglicht, externe Tools über standardisierte Schnittstellen aufzurufen. Über den von AceData Cloud bereitgestellten SERP MCP Server kannst du direkt in AI-Clients wie Claude Desktop, VS Code, Cursor usw. Google-Suchen durchführen und Ergebnisse wie Webseiten, Bilder, Nachrichten, Videos, Orte usw. abrufen.

## Funktionsübersicht

Der SERP MCP Server bietet folgende Kernfunktionen:

- **Websuche** — Suche nach Google-Webergebnissen
- **Bildersuche** — Suche nach Google-Bildern
- **Nachrichtensuche** — Suche nach Google-Nachrichten
- **Videosuche** — Suche nach Google-Videos
- **Ortsuche** — Suche nach Google-Ortsinformationen
- **Kartensuche** — Suche nach Google-Karten
- **Mehrsprachigkeit und Regionen** — Unterstützung für benutzerdefinierte Länder- und Sprachparameter
- **Zeitraumfilterung** — Ergebnisse nach Tag, Woche, Monat, Jahr filtern

## Vorbereitungen

Vor der Nutzung musst du ein AceData Cloud API-Token erhalten:

1. Registriere dich oder melde dich bei der [AceData Cloud Plattform](https://platform.acedata.cloud) an
2. Gehe zur [Google SERP API](https://platform.acedata.cloud/documents/serp-google) Seite
3. Klicke auf „Acquire“, um ein API-Token zu erhalten (bei der ersten Anfrage gibt es ein kostenloses Kontingent)

## Installation und Konfiguration

### Methode 1: pip-Installation (empfohlen)

```bash
pip install mcp-serp
```

### Methode 2: Quellcode-Installation

```bash
git clone https://github.com/AceDataCloud/MCPSerp.git
cd MCPSerp
pip install -e .
```

Nach der Installation kannst du den Dienst mit dem Befehl `mcp-serp` starten.

## Verwendung in Claude Desktop

Bearbeite die Konfigurationsdatei von Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Füge die folgende Konfiguration hinzu:

```json
{
  "mcpServers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "dein API-Token"
      }
    }
  }
}
```

Wenn du `uvx` verwendest (keine vorherige Installation erforderlich):

```json
{
  "mcpServers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "dein API-Token"
      }
    }
  }
}
```

Speichere die Konfiguration und starte Claude Desktop neu, um Google-Suchwerkzeuge im Dialog zu verwenden.
