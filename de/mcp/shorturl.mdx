[MCP (Model Context Protocol)](https://modelcontextprotocol.io) ist ein von Anthropic entwickeltes Modellkontextprotokoll, das es KI-Modellen (wie Claude, GPT usw.) ermöglicht, externe Tools über eine standardisierte Schnittstelle aufzurufen. Mit dem von AceData Cloud bereitgestellten ShortURL MCP Server können Sie in AI-Clients wie Claude Desktop, VS Code, Cursor direkt Kurzlinks generieren.

## Funktionsübersicht

Der ShortURL MCP Server bietet folgende Kernfunktionen:

- **Einzelne URL verkürzen** — Lange URLs in kurze, leicht teilbare Kurzlinks umwandeln
- **Batch-URL-Verkürzung** — Mehrere URLs auf einmal verkürzen (bis zu 10)
- **Benutzerhandbuch** — Vollständige Gebrauchsanweisung und Best Practices erhalten
- **API-Informationen** — API-Dienstdetails und Fehlercodes einsehen

## Voraussetzungen

Vor der Nutzung benötigen Sie ein AceData Cloud API Token:

1. Registrieren oder anmelden auf der [AceData Cloud Plattform](https://platform.acedata.cloud)
2. Zur [ShortURL API](https://platform.acedata.cloud/documents/short-url) Seite wechseln
3. Auf „Acquire“ klicken, um das API Token zu erhalten (bei der ersten Beantragung gibt es ein kostenloses Kontingent)

## Installation und Konfiguration

### Methode 1: Installation via pip (empfohlen)

```bash
pip install mcp-shorturl
```

### Methode 2: Installation aus dem Quellcode

```bash
git clone https://github.com/AceDataCloud/ShortURLMCP.git
cd ShortURLMCP
pip install -e .
```

Nach der Installation können Sie den Dienst mit dem Befehl `mcp-shorturl` starten.

## Verwendung in Claude Desktop

Bearbeiten Sie die Konfigurationsdatei von Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Fügen Sie folgende Konfiguration hinzu:

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ihr API Token"
      }
    }
  }
}
```

Wenn Sie `uvx` verwenden möchten (kein vorheriges Installieren von Paketen nötig):

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "uvx",
      "args": ["mcp-shorturl"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ihr API Token"
      }
    }
  }
}
```

Speichern Sie die Konfiguration und starten Sie Claude Desktop neu, um die ShortURL-Tools im Chat verwenden zu können.

## Verfügbare Tools

| Toolname               | Beschreibung                          |
|------------------------|------------------------------------|
| `shorturl_create`      | Einzelne URL verkürzen              |
| `shorturl_batch_create`| Mehrere URLs gleichzeitig verkürzen (max. 10) |
| `shorturl_get_usage_guide` | Vollständige Gebrauchsanleitung abrufen |
| `shorturl_get_api_info`| API-Dienstdetails abrufen           |

## Anwendungsbeispiele

Nach der Konfiguration können Sie diese Funktionen direkt in Ihrem AI-Client per natürlicher Sprache aufrufen, zum Beispiel:

- „Bitte kürze diesen Link für mich“
- „Verkürze diese 5 URLs in einem Batch“
- „Erstelle einen Kurzlink zum Teilen“
