[MCP (Model Context Protocol)](https://modelcontextprotocol.io) ist ein von Anthropic eingeführtes Modellkontextprotokoll, das es KI-Modellen (wie Claude, GPT usw.) ermöglicht, externe Tools über standardisierte Schnittstellen aufzurufen. Über den von AceData Cloud bereitgestellten Suno MCP Server kannst du direkt in KI-Clients wie Claude Desktop, VS Code und Cursor Musik und Songtexte generieren sowie Audioprojekte verwalten.

## Funktionsübersicht

Der Suno MCP Server bietet die folgenden Kernfunktionen:

- **Musikgenerierung** — KI-Musik durch Text-Prompts generieren
- **Benutzerdefinierte Erstellung** — Vollständige Kontrolle über Songtexte, Titel und Musikstil
- **Songfortsetzung** — Bestehende Songs ab einem beliebigen Zeitpunkt weiter verlängern
- **Cover/Remix** — Coverversionen in unterschiedlichen Stilen erstellen
- **Songtextgenerierung** — Strukturierte Songtexte anhand einer Beschreibung generieren
- **Stimmrollen** — Stimmstile speichern und wiederverwenden
- **Medienkonvertierung** — MP4, WAV, MIDI, Vocal-Separation usw. abrufen
- **Stiloptimierung** — Musikstil-Tags optimieren
- **Aufgabenabfrage** — Generierungsfortschritt überwachen und Ergebnisse abrufen

## Vorbereitung

Vor der Verwendung musst du einen AceData Cloud API-Token erhalten:

1. Registriere dich oder melde dich bei der [AceData Cloud-Plattform](https://platform.acedata.cloud) an
2. Gehe zur Seite [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Klicke auf „Acquire“, um einen API-Token zu erhalten (bei der ersten Beantragung wird ein kostenloses Kontingent vergeben)

## Methode eins: Gehosteten MCP Server verwenden (empfohlen, keine Installation)

AceData Cloud hat den **Suno MCP Server** bereits in der Cloud gehostet. **Es müssen keinerlei Abhängigkeiten lokal installiert werden**; gib einfach diese URL direkt im KI-Client ein:

```
https://suno.mcp.acedata.cloud/mcp
```

Authentifizierungsmethode: Füge einfach `Authorization: Bearer dein API-Token` zum Request-Header hinzu (Claude.ai erledigt dies automatisch über OAuth, ohne dass du den Token manuell eingeben musst).

### Claude.ai (Webversion, OAuth-Anmeldung, am einfachsten)

1. Öffne [Claude.ai](https://claude.ai) → unten links **Customize** → **Connectors** → **Add More**
2. Gib bei URL Folgendes ein: `https://suno.mcp.acedata.cloud/mcp`
3. Schließe die OAuth-Autorisierungsanmeldung ab (automatische Weiterleitung zur AceData Cloud-Anmeldeseite)
4. Kehre zur Chat-Oberfläche zurück, dann können die Tools verwendet werden

### Claude Desktop

Bearbeite die Konfigurationsdatei:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Starte Claude Desktop nach dem Speichern neu, damit die Änderungen wirksam werden.

### Claude Code (Terminal-Kommandozeile)

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Andere Clients mit MCP-Unterstützung

Jeder Client, der das MCP-Streamable-HTTP-Protokoll unterstützt (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant usw.), kann durch Eingabe der folgenden zwei Angaben integriert werden:

- **URL**: `https://suno.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer dein API-Token`

## Methode zwei: Lokal ausführen (pip / uvx-Installation)

Wenn du eine Offline-Ausführung, benutzerdefinierten Code oder die Bereitstellung im Intranet benötigst, kannst du den MCP Server lokal installieren und über stdio starten.

### Installation

pip-Installation (empfohlen):

```bash
pip install mcp-suno
```

Oder Installation aus dem Quellcode:

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

Nach Abschluss der Installation kannst du den Dienst mit dem Befehl `mcp-suno` starten.

### Verwendung in Claude Desktop (lokal)

Bearbeite die Claude-Desktop-Konfigurationsdatei:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Füge die folgende Konfiguration hinzu:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Bei Verwendung von `uvx` (keine vorherige Paketinstallation erforderlich):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Starte Claude Desktop nach dem Speichern der Konfiguration neu, damit die Änderungen wirksam werden.

## Verwendungsbeispiele

Nach Abschluss der Konfiguration kannst du diese Funktionen im AI-Client direkt in natürlicher Sprache aufrufen, zum Beispiel:

- „Hilf mir, einen Popsong über den Sommer zu generieren“
- „Erstelle von diesem Song eine Coverversion im Jazz-Stil“
- „Setze diesen Song ab Sekunde 30 fort“
- „Generiere einen chinesischen Liedtext zum Thema Reisen“
- „Trenne den Gesang aus diesem Song“
- „Hilf mir, diesen Song in das MIDI-Format umzuwandeln“

## Erweiterte Steuerung und Studio-Projekte

`suno_generate_music` unterstützt `variety`; `suno_generate_custom_music` unterstützt zusätzlich
`max_mode` und `audio_weight`. `max_mode` verwendet eine höhere API-Abrechnungsstufe und ist standardmäßig nicht aktiviert.
Es sollte festgelegt werden, nachdem der Benutzer den erweiterten Modus ausdrücklich ausgewählt hat. Die aktuellen Preise richten sich nach der Plattform-Service-Seite.

`suno_generate_with_custom_model` kann mit `instrumental=true` reine Musik generieren oder mit
`lyric_prompt` automatisch Liedtexte generieren; andernfalls wird `lyric` bereitgestellt. Titel und Stil können weggelassen werden, außerdem können
`negative_tags`, `vocal_gender`, `weirdness`, `style_influence`, `duration` und
`callback_url` übergeben werden. Explizite Steuerwerte von `0` bleiben erhalten.

Für `suno_manage_project` kann `request.action` `create`, `retrieve`, `save`,
`upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`,
`remove_track`, `render` sein. Die Eingabe unterscheidet sich je nach Aktion; für Projektänderungen sollte die zuletzt zurückgelesene `version_id` verwendet werden;
beim Speichern muss der vollständige `state` übergeben werden, wobei vorhandene Spuren und Felder beibehalten werden.

Außer bei `retrieve` muss bei jedem Aufruf ein `idempotency_key` angegeben werden. Für neue Schreibvorgänge wird ein neuer Schlüssel verwendet;
bei Zeitüberschreitungen oder ungewissen Annahmeergebnissen den ursprünglichen Schlüssel und exakt dieselbe Anfrage beibehalten und erneut versuchen oder die ursprüngliche Aufgabe abfragen, nicht automatisch
den Schlüssel wechseln und kostenpflichtige Generierungen erneut senden. Quellaudiointervalle werden in Sekunden angegeben, Projektzeitlinienintervalle in Beats. Generierungen erstellen nur Kandidaten,
es muss ein Kandidat ausgewählt und `commit_candidate` aufgerufen werden, bevor er in die Spur geschrieben wird.

Die `task_id` einer asynchron angenommenen Aufgabe wird mit `suno_get_task` abgefragt. Wenn `finished_at` leer ist, weiter warten,
nach dem Endstatus `response.success` und Fehler prüfen; eine erfolgreiche Annahme nicht als erfolgreiche Generierung, Übernahme oder Export behandeln.
`suno_get_tasks_batch` gibt vollständige JSON-Aufgabenaufzeichnungen zurück und bewahrt benutzerdefinierte Modellobjekte, Projektstatus,
Kandidaten sowie verschiedene Ergebnisse wie MIDI. Den vollständigen Workflow findest du im [Studio-Projektleitfaden](https://platform.acedata.cloud/documents/suno-projects-integration).
