[MCP (Model Context Protocol)](https://modelcontextprotocol.io) ist ein von Anthropic entwickeltes Modellkontextprotokoll, das es KI-Modellen (wie Claude, GPT usw.) ermöglicht, externe Tools über eine standardisierte Schnittstelle aufzurufen. Mit dem von AceData Cloud bereitgestellten Veo MCP Server können Sie in AI-Clients wie Claude Desktop, VS Code, Cursor direkt Google Veo zur KI-Videoerzeugung nutzen.

## Funktionsübersicht

Der Veo MCP Server bietet folgende Kernfunktionen:

- **Text-zu-Video** — Erzeugung hochwertiger Videos anhand von Texteingaben
- **Bild-zu-Video** — Videoerzeugung basierend auf Bildern
- **Multi-Modell-Unterstützung** — Unterstützung für Modelle wie veo3, veo2, veo31-fast-ingredients usw.
- **Verschiedene Auflösungen** — Ausgabeformate wie 4K, 1080p, GIF usw.
- **Verschiedene Seitenverhältnisse** — Unterstützung von 16:9, 9:16 usw.
- **1080p Upgrade** — Hochskalierung bereits erzeugter Videos auf 1080p
- **Aufgabenabfrage** — Überwachung des Erzeugungsfortschritts und Abruf der Ergebnisse

## Voraussetzungen

Vor der Nutzung benötigen Sie einen AceData Cloud API Token:

1. Registrieren oder anmelden auf der [AceData Cloud Plattform](https://platform.acedata.cloud)
2. Zur [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos) Seite navigieren
3. Auf „Acquire“ klicken, um den API Token zu erhalten (bei Erstbeantragung kostenloses Guthaben)

## Installation und Konfiguration

### Methode 1: Installation via pip (empfohlen)

```bash
pip install mcp-veo
```

### Methode 2: Installation aus dem Quellcode

```bash
git clone https://github.com/AceDataCloud/VeoMCP.git
cd VeoMCP
pip install -e .
```

Nach der Installation können Sie den Dienst mit dem Befehl `mcp-veo` starten.

## Nutzung in Claude Desktop

Bearbeiten Sie die Konfigurationsdatei von Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Fügen Sie folgende Konfiguration hinzu:

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ihr API Token"
      }
    }
  }
}
```

Wenn Sie `uvx` verwenden (kein vorheriges Installieren von Paketen erforderlich):

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ihr API Token"
      }
    }
  }
}
```

Speichern Sie die Konfiguration und starten Sie Claude Desktop neu. Danach können Sie Veo-bezogene Tools im Chat verwenden.

## Nutzung in VS Code / Cursor

## Verfügbare Tools

| Toolname             | Beschreibung                         |
|----------------------|------------------------------------|
| `veo_text_to_video`  | Videoerzeugung anhand von Text      |
| `veo_image_to_video` | Videoerzeugung basierend auf Bildern|
| `veo_get_1080p`      | Hochskalierung eines Videos auf 1080p |
| `veo_get_task`       | Abfrage des Status einer einzelnen Aufgabe |
| `veo_get_tasks_batch`| Batch-Abfrage des Status mehrerer Aufgaben |

## Anwendungsbeispiele

Nach der Konfiguration können Sie diese Funktionen in Ihrem AI-Client direkt per natürlicher Sprache aufrufen, z.B.:

- „Erstelle mir ein Zeitraffer-Video vom Sternenhimmel mit Veo“
- „Erzeuge aus diesem Landschaftsbild ein 4K-Video“
- „Generiere ein vertikales Kurzvideo im Format 9:16“
- „Skaliere dieses Video auf 1080p hoch“
