[MCP (Model Context Protocol)](https://modelcontextprotocol.io) ist ein von Anthropic entwickeltes Modellkontextprotokoll, das es KI-Modellen (wie Claude, GPT usw.) ermöglicht, externe Tools über standardisierte Schnittstellen aufzurufen. Über den von AceData Cloud bereitgestellten Seedream MCP Server können Sie in KI-Clients wie Claude Desktop, VS Code, Cursor usw. direkt die von ByteDance Seedream generierten und bearbeiteten KI-Bilder verwenden.

## Funktionsübersicht

Der Seedream MCP Server bietet folgende Kernfunktionen:

- **Text-zu-Bild-Generierung** — Erzeugung hochwertiger Bilder anhand von Text-Prompts (unterstützt Chinesisch und Englisch)
- **Bildbearbeitung** — Anpassung von Stil, Hintergrund, Eigenschaften vorhandener Bilder
- **Virtuelle Anprobe** — Ankleiden von Personenfotos mit Kleidung
- **Multi-Modell-Unterstützung** — Unterstützung von Seedream v4.5, v4.0, v3.0 T2I, SeedEdit v3.0 I2I u.a.
- **Verschiedene Auflösungen** — Unterstützung von 1K, 2K, 4K und adaptiven Auflösungen
- **Seed-Kontrolle** — Reproduzierbare Ergebnisse durch den seed-Parameter
- **Aufgabenabfrage** — Überwachung des Fortschritts und Abruf der Ergebnisse

## Voraussetzungen

Vor der Nutzung benötigen Sie ein AceData Cloud API Token:

1. Registrieren oder anmelden auf der [AceData Cloud Plattform](https://platform.acedata.cloud)
2. Zur Seite [Seedream Images API](https://platform.acedata.cloud/documents/seedream-images) navigieren
3. Auf „Acquire“ klicken, um das API Token zu erhalten (bei erstmaliger Beantragung kostenlose Kontingente)

## Installation und Konfiguration

### Methode 1: Installation via pip (empfohlen)

```bash
pip install mcp-seedream-pro
```

### Methode 2: Installation aus dem Quellcode

```bash
git clone https://github.com/AceDataCloud/MCPSeedream.git
cd MCPSeedream
pip install -e .
```

Nach der Installation können Sie den Dienst mit dem Befehl `mcp-seedream-pro` starten.

## Nutzung in Claude Desktop

Bearbeiten Sie die Konfigurationsdatei von Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Fügen Sie folgende Konfiguration hinzu:

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ihr API Token"
      }
    }
  }
}
```

Wenn Sie `uvx` verwenden (kein vorheriges Paket-Setup nötig):

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ihr API Token"
      }
    }
  }
}
```

Nach dem Speichern der Konfiguration starten Sie Claude Desktop neu, um Seedream-Tools im Chat zu verwenden.

## Verfügbare Tools

| Toolname                  | Beschreibung                      |
|---------------------------|---------------------------------|
| `seedream_generate_image` | Bildgenerierung anhand von Text  |
| `seedream_edit_image`     | Bearbeitung oder Modifikation von Bildern |
| `seedream_get_task`       | Abfrage des Status einer einzelnen Aufgabe |
| `seedream_get_tasks_batch`| Batch-Abfrage von Aufgabenstatus |
| `seedream_list_models`    | Auflistung aller verfügbaren Modelle und deren Fähigkeiten |
| `seedream_list_sizes`     | Auflistung verfügbarer Bildgrößen und Auflösungen |

## Anwendungsbeispiele

Nach der Konfiguration können Sie diese Funktionen direkt in Ihrem KI-Client per natürlicher Sprache aufrufen, z.B.:

- „Erstelle mir mit Seedream ein Landschaftsbild im Stil einer Tuschmalerei“
- „Ändere den Hintergrund dieses Fotos in einen Sternenhimmel“
- „Erzeuge ein 4K hochauflösendes Porträt mit Seedream v4.5“
- „Ziehe dieses Kleid virtuell auf das Foto an“
