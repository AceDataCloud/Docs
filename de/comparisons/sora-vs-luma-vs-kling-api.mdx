## Detaillierte Analyse

### Funktionen

Sora, Luma und Kling werden alle über die einheitliche API von Ace Data Cloud aufgerufen und unterstützen standardisierte REST-Schnittstellen sowie Bearer-Token-Authentifizierung.

**Sora** Hauptendpunkt ist `POST https://api.acedata.cloud/sora/videos` und unterstützt Text-zu-Video, verschiedene Längen, Quer- und Hochformat sowie Charaktersteuerung. Zusätzlich stehen Endpunkte wie `/sora/tasks` zur Verfügung.

**Luma** Hauptendpunkt ist `POST https://api.acedata.cloud/luma/videos` und unterstützt Text-zu-Video, Bild-zu-Video, Video-Fortsetzung sowie Steuerung von Anfangs- und Endbild. Zusätzlich gibt es Endpunkte wie `/luma/tasks`.

**Kling** Hauptendpunkt ist `POST https://api.acedata.cloud/kling/videos` und unterstützt Text-zu-Video, Bild-zu-Video, Video-Fortsetzung sowie verschiedene Längen. Weitere Endpunkte sind `/kling/tasks` und `/kling/motion`.

## Codebeispiele

Die folgenden Beispiele zeigen, wie man über die Ace Data Cloud API jeweils Sora, Luma und Kling aufruft. Alle Anfragen verwenden dieselbe Basis-URL (`https://api.acedata.cloud`) und Authentifizierungsmethode.

### Aufruf von Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
},
)
print(response.json())
```
