## Überblick

KI-Chatbots sind eine der häufigsten KI-Anwendungen. Über die einheitliche API von Ace Data Cloud können Sie gleichzeitig verschiedene große Sprachmodelle wie Claude und OpenAI integrieren und leistungsstarke Multi-Turn-Dialogsysteme erstellen.

## Betroffene Dienste

- **Claude**: `POST https://api.acedata.cloud/v1/chat/completions`
- **OpenAI**: `POST https://api.acedata.cloud/openai/chat/completions`

## Technische Lösung

### Voraussetzungen

1. Registrierung eines Kontos bei [Ace Data Cloud](https://platform.acedata.cloud)
2. Erhalt eines API-Tokens
3. Installation von Python 3.7+ und der requests-Bibliothek

### Implementierungsschritte

### Schritt 1: Registrierung und Token-Erhalt

Registrieren Sie sich auf [platform.acedata.cloud](https://platform.acedata.cloud) und erhalten Sie Ihren API-Token.

### Schritt 2: Modell auswählen

Claude eignet sich für sichere und kohärente lange Dialoge, OpenAI GPT-4o ist für allgemeine Anwendungsfälle geeignet. Sie können je nach Bedarf flexibel wechseln.

### Schritt 3: Dialoglogik implementieren

Verwalten Sie das messages-Array, um den Kontext von Multi-Turn-Dialogen zu pflegen.

## Codebeispiel

Nachfolgend ein vollständiges Python-Beispiel mit Claude:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_claude():
    response = requests.post(
        "https://api.acedata.cloud/v1/chat/completions",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "model": "claude-sonnet-4-6",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
},
    )
    return response.json()

result = call_claude()
print(result)
```

## Best Practices

- **Fehler-Retry**: Exponentielles Backoff bei 429 (Rate Limiting) und 5xx-Fehlern
- **Asynchrone Verarbeitung**: Für zeitintensive Aufgaben (Bild-/Videoerzeugung) Ergebnisse asynchron über callback_url empfangen
- **Kostenkontrolle**: Überwachung von Nutzung und Kosten über die Ace Data Cloud-Konsole
- **Token-Sicherheit**: Speichern Sie den API-Token in Umgebungsvariablen, nicht im Code hardcodieren
