## Einführung

reCAPTCHA ist ein Captcha-Dienst von Ace Data Cloud, eine Google reCAPTCHA-Lösung. Über die einheitliche API von Ace Data Cloud können Sie reCAPTCHA schnell mit Python integrieren und Funktionen wie reCAPTCHA v2 Token, reCAPTCHA v2 Erkennung und reCAPTCHA v3 Token nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) und ein API-Token
- Python 3.7 oder höher
- Installation der requests-Bibliothek: `pip install requests`

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der reCAPTCHA-API lautet:

```
POST https://api.acedata.cloud/captcha/token/recaptcha2
```

Vollständiges Python-Beispiel:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/recaptcha2"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-",
    "website_url": "https://www.google.com/recaptcha/api2/demo"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Antwortverarbeitung

Nach einem erfolgreichen Aufruf gibt die API Daten im JSON-Format zurück. Es wird empfohlen, den HTTP-Statuscode zu prüfen:

```python
if response.status_code == 200:
    result = response.json()
    print("Aufruf erfolgreich:", result)
else:
    print(f"Aufruf fehlgeschlagen, Statuscode: {response.status_code}")
    print(response.text)
```

## Erweiterte Verwendung

Für APIs, die asynchrone Aufgaben unterstützen, können Ergebnisse über eine Callback-URL abgerufen werden:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Das Ergebnis wird über die Callback-URL an Ihren Server gesendet
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                          |
|------------|-------------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragerate überschritten            |
| 500        | Interner Serverfehler                |

## Weitere Endpunkte

Der reCAPTCHA-Dienst bietet außerdem folgende Endpunkte an:

- `POST https://api.acedata.cloud/captcha/recognition/recaptcha2`
- `POST https://api.acedata.cloud/captcha/token/recaptcha3`
