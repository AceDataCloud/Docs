## Einführung

reCAPTCHA ist ein Captcha-Dienst, der von Ace Data Cloud bereitgestellt wird und die Google reCAPTCHA-Lösung nutzt. Über die einheitliche API von Ace Data Cloud können Sie reCAPTCHA schnell mit cURL aufrufen und Funktionen wie reCAPTCHA v2 Token, reCAPTCHA v2 Erkennung und reCAPTCHA v3 Token nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) besitzen und einen API-Token erhalten
- Ein Terminal mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt zum Aufrufen der reCAPTCHA API ist:

```
POST https://api.acedata.cloud/captcha/token/recaptcha2
```

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/captcha/token/recaptcha2 \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-", "website_url": "https://www.google.com/recaptcha/api2/demo"}'
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispielantwort

Nach erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, z.B.:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/token/recaptcha2 \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-", "website_url": "https://www.google.com/recaptcha/api2/demo"}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                     |
|------------|--------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token überprüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragefrequenz überschritten   |
| 500        | Interner Serverfehler           |

## Nächste Schritte

- Besuchen Sie die [Ace Data Cloud Konsole](https://platform.acedata.cloud), um Ihren API-Token zu erhalten
- Lesen Sie die [API-Dokumentation](https://docs.acedata.cloud/zh-CN/api-reference) für vollständige Parameterinformationen
- Informieren Sie sich über die [Preismodelle](https://platform.acedata.cloud/services) zu den Kosten
