## Einführung

Kimi ist ein von Ace Data Cloud bereitgestellter KI-Chat-Service, basierend auf der Kimi-Serie großer Sprachmodelle von 月之暗面. Über die einheitliche API von Ace Data Cloud können Sie Kimi mit JavaScript schnell integrieren und Funktionen wie mehrstufige Dialoge, System-Prompts, Streaming-Ausgabe und JSON-Ausgabemodus nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) und ein API-Token
- Node.js 18+ oder eine moderne Browserumgebung

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Kimi API lautet:

```
POST https://api.acedata.cloud/kimi/chat/completions
```

In diesem Beispiel wird das Modell `kimi-k2.5` verwendet. Verfügbare Modelle sind: `kimi-k2.5`, `kimi-k2-thinking-turbo`, `kimi-k2-thinking`, `kimi-k2-instruct-0905`.

Vollständiges JavaScript-Codebeispiel:

```javascript
const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "kimi-k2.5",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Antwortverarbeitung

Es wird empfohlen, den Antwortstatus zu prüfen und Fehler zu behandeln:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Aufruf erfolgreich:", result);
} else {
  console.error(`Aufruf fehlgeschlagen, Statuscode: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js Wrapper

Es wird empfohlen, eine wiederverwendbare Funktion zu erstellen:

```javascript
async function callKimi(data) {
  const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                          |
|------------|-------------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API Token überprüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten          |
| 500        | Interner Serverfehler               |
