## Einführung

Kimi ist ein von Ace Data Cloud bereitgestellter KI-Chat-Service, basierend auf dem großen Sprachmodell der Kimi-Serie von Moon's Dark Side. Über die einheitliche API von Ace Data Cloud können Sie Kimi schnell mit cURL aufrufen und Funktionen wie mehrstufige Dialoge, System-Prompts, Streaming-Ausgabe und JSON-Ausgabemodus nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) und ein API-Token
- Ein Terminal mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Kimi API lautet:

```
POST https://api.acedata.cloud/kimi/chat/completions
```

In diesem Beispiel wird das Modell `kimi-k2.5` verwendet.
Verfügbare Modelle sind: `kimi-k2.5`, `kimi-k2-thinking-turbo`, `kimi-k2-thinking`, `kimi-k2-instruct-0905`.

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "kimi-k2.5", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispielantwort

Bei erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, zum Beispiel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "kimi-k2.5", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                       |
|------------|----------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API Token prüfen |
| 403        | Unzureichendes Guthaben oder keine Zugriffsberechtigung |
| 429        | Anfragerate überschritten         |
| 500        | Interner Serverfehler             |

## Nächste Schritte

- Besuchen Sie die [Ace Data Cloud Konsole](https://platform.acedata.cloud), um Ihren API Token zu erhalten
- Lesen Sie die [API-Dokumentation](https://docs.acedata.cloud/zh-CN/api-reference) für vollständige Parameterdetails
- Informieren Sie sich über die [Preismodelle](https://platform.acedata.cloud/services) zu den Kosten
