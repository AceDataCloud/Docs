## Einführung

AI Chat ist ein von Ace Data Cloud bereitgestellter AI-Chat-Service mit Multi-Model AI-Konversationsdiensten. Über die einheitliche API von Ace Data Cloud können Sie AI Chat schnell mit cURL aufrufen und Funktionen wie Multi-Model-Unterstützung, zustandsbehaftete Dialoge und voreingestellte Rollen nutzen.

## Voraussetzungen

- Ein [Ace Data Cloud](https://platform.acedata.cloud) Konto und ein API-Token
- Eine Terminalumgebung mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der AI Chat API ist:

```
POST https://api.acedata.cloud/aichat/conversations
```

Dieses Beispiel verwendet das Modell `gpt-4o`.
Verfügbare Modelle sind: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}'
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch Ihren tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispielantwort

Bei erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, z.B.:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                     |
|------------|--------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragerate überschritten       |
| 500        | Interner Serverfehler           |
