## Einführung

Identity ist ein Authentifizierungsdienst von Ace Data Cloud zur Verifizierung von Personalausweis, Bankkarte und Handynummer. Über die einheitliche API von Ace Data Cloud können Sie mit cURL schnell Identity aufrufen und Funktionen wie Personalausweis-OCR, Personalausweis-Verifizierung, Bankkarten-Verifizierung und Handynummer-Verifizierung nutzen.

## Voraussetzungen

- Ein [Ace Data Cloud](https://platform.acedata.cloud) Konto besitzen und einen API Token erhalten
- Eine Terminalumgebung mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Identity API lautet:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Vollständiges Beispiel für einen cURL-Befehl:

```bash
curl -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}'
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispielantwort

Nach einem erfolgreichen Aufruf wird eine JSON-formatierte Antwort zurückgegeben, zum Beispiel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur formatierten Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                     |
|------------|--------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten     |
| 500        | Interner Serverfehler          |

## Nächste Schritte

- Besuchen Sie die [Ace Data Cloud Konsole](https://platform.acedata.cloud), um Ihren API Token zu erhalten
- Lesen Sie die [API-Dokumentation](https://docs.acedata.cloud/zh-CN/api-reference) für vollständige Parameterinformationen
- Informieren Sie sich über die [Preismodelle](https://platform.acedata.cloud/services) für Kostenübersicht
