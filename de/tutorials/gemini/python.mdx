## Einführung

Gemini ist ein von Ace Data Cloud bereitgestellter KI-Chat-Service, basierend auf der Google Gemini-Serie großer Sprachmodelle. Über die einheitliche API von Ace Data Cloud können Sie Gemini mit Python schnell integrieren und Funktionen wie mehrstufige Dialoge, System-Prompts, Streaming-Ausgabe und JSON-Ausgabemodus nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) und ein API-Token
- Python 3.7 oder höher
- Installation der requests-Bibliothek: `pip install requests`

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Gemini-API ist:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

In diesem Beispiel wird das Modell `gemini-2.5-flash` verwendet.
Verfügbare Modelle sind: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Vollständiges Python-Beispiel:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gemini-2.5-flash",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud-Plattform erhalten haben.

## Antwortverarbeitung

Nach einem erfolgreichen Aufruf gibt die API Daten im JSON-Format zurück. Es wird empfohlen, den HTTP-Statuscode zu prüfen:

```python
if response.status_code == 200:
    result = response.json()
    print("Aufruf erfolgreich:", result)
else:
    print(f"Aufruf fehlgeschlagen, Statuscode: {response.status_code}")
    print(response.text)
```

## Erweiterte Verwendung

Für Chat-APIs wird Streaming-Ausgabe unterstützt, um Echtzeit-Antworten zu erhalten:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                         |
|------------|------------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token überprüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten         |
| 500        | Interner Serverfehler              |
