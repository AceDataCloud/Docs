## Einführung

Gemini ist ein von Ace Data Cloud bereitgestellter KI-Chat-Service, basierend auf der Google Gemini-Serie großer Sprachmodelle. Über die einheitliche API von Ace Data Cloud können Sie mit cURL schnell auf Gemini zugreifen und Funktionen wie mehrstufige Dialoge, System-Prompts, Streaming-Ausgabe und JSON-Ausgabemodus nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) und ein API-Token
- Eine Terminalumgebung mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Gemini-API lautet:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

In diesem Beispiel wird das Modell `gemini-2.5-flash` verwendet. Verfügbare Modelle sind: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/gemini/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gemini-2.5-flash", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispielantwort

Bei erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, z. B.:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/gemini/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gemini-2.5-flash", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                         |
|------------|------------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten         |
| 500        | Interner Serverfehler              |

## Nächste Schritte

- Besuchen Sie die [Ace Data Cloud Konsole](https://platform.acedata.cloud), um Ihren API-Token zu erhalten
- Lesen Sie die [API-Dokumentation](https://docs.acedata.cloud/zh-CN/api-reference) für vollständige Parameterinformationen
- Informieren Sie sich über die [Preismodelle](https://platform.acedata.cloud/services) zu den Kosten
