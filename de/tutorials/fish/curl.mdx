## Einführung

Fish TTS ist ein von Ace Data Cloud bereitgestellter KI-Audioservice, der Fish-Sprachsynthese anbietet. Über die einheitliche API von Ace Data Cloud können Sie mit cURL schnell Fish TTS aufrufen und Funktionen wie Text-zu-Sprache, verschiedene Stimmen und benutzerdefinierte Klänge nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) und ein API-Token
- Eine Terminalumgebung mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Fish TTS API lautet:

```
POST https://api.acedata.cloud/fish/audios
```

In diesem Beispiel wird das Modell `fish-tts` verwendet.
Verfügbare Modelle sind: `fish-tts`.

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/fish/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "speech", "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务", "voice_id": "d7900c21663f485ab63ebdb7e5905036", "model": "fish-tts"}'
```

Ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispielantwort

Bei erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, z. B.:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/fish/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "speech", "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务", "voice_id": "d7900c21663f485ab63ebdb7e5905036", "model": "fish-tts"}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                        |
|------------|-----------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API Token überprüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten        |
| 500        | Interner Serverfehler             |

## Nächste Schritte

- Besuchen Sie die [Ace Data Cloud Konsole](https://platform.acedata.cloud), um Ihren API Token zu erhalten
- Lesen Sie die [API-Dokumentation](https://docs.acedata.cloud/zh-CN/api-reference) für vollständige Parameterinformationen
- Informieren Sie sich über die [Preismodelle](https://platform.acedata.cloud/services) zu den Kosten
