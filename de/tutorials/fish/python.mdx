## Einführung

Fish TTS ist ein von Ace Data Cloud bereitgestellter KI-Audioservice, der Fish-Sprachsynthese anbietet. Über die einheitliche API von Ace Data Cloud können Sie Fish TTS mit Python schnell integrieren und Funktionen wie Text-zu-Sprache, verschiedene Stimmen und benutzerdefinierte Klänge nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) und ein API-Token
- Python 3.7 oder höher
- Installation der requests-Bibliothek: `pip install requests`

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Fish TTS API ist:

```
POST https://api.acedata.cloud/fish/audios
```

In diesem Beispiel wird das Modell `fish-tts` verwendet.  
Verfügbare Modelle: `fish-tts`.

Vollständiges Python-Codebeispiel:

```python
import requests

url = "https://api.acedata.cloud/fish/audios"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "speech",
    "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务",
    "voice_id": "d7900c21663f485ab63ebdb7e5905036",
    "model": "fish-tts"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud-Plattform erhalten haben.

## Antwortverarbeitung

Nach einem erfolgreichen Aufruf gibt die API Daten im JSON-Format zurück. Es wird empfohlen, den HTTP-Statuscode zu prüfen:

```python
if response.status_code == 200:
    result = response.json()
    print("Aufruf erfolgreich:", result)
else:
    print(f"Aufruf fehlgeschlagen, Statuscode: {response.status_code}")
    print(response.text)
```

## Erweiterte Verwendung

Für APIs, die asynchrone Aufgaben unterstützen, können Sie Ergebnisse über eine Callback-URL erhalten:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Das Ergebnis wird über die Callback-URL an Ihren Server gesendet
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                      |
|------------|---------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten      |
| 500        | Interner Serverfehler           |
