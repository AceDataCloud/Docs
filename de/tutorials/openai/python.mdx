## Einführung

OpenAI ist ein von Ace Data Cloud bereitgestellter KI-Chat-Service, basierend auf der OpenAI GPT-Serie großer Sprachmodelle. Über die einheitliche API von Ace Data Cloud können Sie OpenAI mit Python schnell integrieren und Funktionen wie mehrstufige Dialoge, System-Prompts, Streaming-Ausgabe, JSON-Ausgabemodus, Text-Embedding, Bildgenerierung und mehr nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) und ein API-Token
- Python 3.7 oder höher
- Installation der requests-Bibliothek: `pip install requests`

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der OpenAI API ist:

```
POST https://api.acedata.cloud/openai/chat/completions
```

In diesem Beispiel wird das Modell `gpt-4o` verwendet. Verfügbare Modelle sind: `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`.

Vollständiges Python-Beispiel:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Antwortverarbeitung

Nach einem erfolgreichen Aufruf gibt die API Daten im JSON-Format zurück. Es wird empfohlen, den HTTP-Statuscode zu prüfen:

```python
if response.status_code == 200:
    result = response.json()
    print("Aufruf erfolgreich:", result)
else:
    print(f"Aufruf fehlgeschlagen, Statuscode: {response.status_code}")
    print(response.text)
```

## Erweiterte Verwendung

Für Chat-APIs wird Streaming-Ausgabe unterstützt, um Echtzeit-Antworten zu erhalten:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                       |
|------------|----------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder keine Zugriffsberechtigung |
| 429        | Anfragerate überschritten         |
| 500        | Interner Serverfehler             |
