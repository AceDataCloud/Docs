## Einführung

OpenAI ist ein von Ace Data Cloud bereitgestellter AI-Chat-Service, basierend auf der OpenAI GPT-Serie großer Sprachmodelle. Über die einheitliche API von Ace Data Cloud können Sie mit cURL schnell OpenAI aufrufen und Funktionen wie mehrstufige Dialoge, System-Prompt, Streaming-Ausgabe, JSON-Ausgabemodus, Text-Embedding, Bildgenerierung und mehr nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) und ein API-Token
- Ein Terminal mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der OpenAI API ist:

```
POST https://api.acedata.cloud/openai/chat/completions
```

In diesem Beispiel wird das Modell `gpt-4o` verwendet. Verfügbare Modelle sind: `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`.

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispielantwort

Nach erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, z.B.:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                          |
|------------|------------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten          |
| 500        | Interner Serverfehler               |

## Nächste Schritte

- Besuchen Sie die [Ace Data Cloud Konsole](https://platform.acedata.cloud), um Ihren API-Token zu erhalten
- Lesen Sie die [API-Dokumentation](https://docs.acedata.cloud/zh-CN/api-reference) für vollständige Parameterinformationen
- Informieren Sie sich über die [Preismodelle](https://platform.acedata.cloud/services) für Kostenübersicht
