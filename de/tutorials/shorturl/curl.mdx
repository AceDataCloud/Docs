## Einführung

Short URL ist ein Tool-Service von Ace Data Cloud, der Kurzlink-Generierung anbietet. Über die einheitliche API von Ace Data Cloud können Sie mit cURL schnell Short URL aufrufen und Funktionen wie URL-Verkürzung und benutzerdefinierte Domains nutzen.

## Voraussetzungen

- Ein [Ace Data Cloud](https://platform.acedata.cloud) Konto besitzen und einen API Token erhalten
- Ein Terminal mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Short URL API ist:

```
POST https://api.acedata.cloud/shorturl
```

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}'
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispielantwort

Bei erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, z.B.:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                     |
|------------|---------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten       |
| 500        | Interner Serverfehler            |

## Nächste Schritte
