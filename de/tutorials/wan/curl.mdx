## Einführung

Wan ist ein von Ace Data Cloud bereitgestellter KI-Videoservice, das Video-Generierungsmodell von Alibaba Wanxiang. Über die einheitliche API von Ace Data Cloud können Sie mit cURL schnell Wan aufrufen, um Funktionen wie Text-zu-Video, Bild-zu-Video, Referenzvideo-Generierung und verschiedene Auflösungen zu nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) besitzen und einen API-Token erhalten
- Ein Terminal mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Wan API lautet:

```
POST https://api.acedata.cloud/wan/videos
```

In diesem Beispiel wird das Modell `wan2.6-t2v` verwendet. Verfügbare Modelle sind: `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`.

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/wan/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "model": "wan2.6-t2v", "prompt": "Astronauts shuttle from space to volcano", "resolution": "720P"}'
```

Ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispielantwort

Bei erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, z.B.:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/wan/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "model": "wan2.6-t2v", "prompt": "Astronauts shuttle from space to volcano", "resolution": "720P"}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                     |
|------------|--------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragerate überschritten       |
| 500        | Interner Serverfehler           |

## Nächste Schritte

- Besuchen Sie die [Ace Data Cloud Konsole](https://platform.acedata.cloud), um Ihren API-Token zu erhalten
- Lesen Sie die [API-Dokumentation](https://docs.acedata.cloud/zh-CN/api-reference) für vollständige Parameterinformationen
- Informieren Sie sich über die [Preismodelle](https://platform.acedata.cloud/services) für Kostenübersicht
