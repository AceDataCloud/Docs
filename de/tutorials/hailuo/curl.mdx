## Einführung

Hailuo ist ein von Ace Data Cloud bereitgestellter KI-Videoservice, das MiniMax Hailuo Video-Generierungsmodell. Über die einheitliche API von Ace Data Cloud können Sie Hailuo schnell mit cURL aufrufen und Funktionen wie Text-zu-Video, Bild-zu-Video und Regie-Modus nutzen.

## Voraussetzungen

- Ein [Ace Data Cloud](https://platform.acedata.cloud) Konto und ein API-Token
- Ein Terminal mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Hailuo API lautet:

```
POST https://api.acedata.cloud/hailuo/videos
```

In diesem Beispiel wird das Modell `minimax-t2v` verwendet. Verfügbare Modelle sind: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}'
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispielantwort

Bei erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, z. B.:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                     |
|------------|--------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token überprüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten     |
| 500        | Interner Serverfehler          |
