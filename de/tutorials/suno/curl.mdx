## Einführung

Suno ist ein von Ace Data Cloud bereitgestellter KI-Audiodienst für die Suno KI-Musikgenerierung. Über die einheitliche API von Ace Data Cloud können Sie mit cURL schnell auf Suno zugreifen und Funktionen wie Text-zu-Musik-Generierung, benutzerdefinierte Liedtexte, Songfortsetzung, Coverversionen, Gesangstrennung und Liedtextgenerierung nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) und ein API-Token
- Ein Terminal mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt der Suno API lautet:

```
POST https://api.acedata.cloud/suno/audios
```

Dieses Beispiel verwendet das Modell `chirp-v5`. Verfügbare Modelle sind: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`.

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}'
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispielantwort

Bei erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, z.B.:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                     |
|------------|--------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriffsrecht          |
| 429        | Anfragelimit überschritten                                |
| 500        | Interner Serverfehler                                     |
