## Einführung

Seedance ist ein von Ace Data Cloud bereitgestellter KI-Videoservice, basierend auf dem Seedance Video-Generierungsmodell von ByteDance. Über die einheitliche API von Ace Data Cloud können Sie Seedance schnell mit Python integrieren und Funktionen wie Text-zu-Video, Bild-zu-Video, Audioerzeugung sowie verschiedene Auflösungen nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) und ein API-Token
- Python 3.7 oder höher
- Installation der requests-Bibliothek: `pip install requests`

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Seedance API lautet:

```
POST https://api.acedata.cloud/seedance/videos
```

In diesem Beispiel wird das Modell `doubao-seedance-1-0-pro-250528` verwendet. Verfügbare Modelle sind: `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`.

Vollständiges Python-Codebeispiel:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "doubao-seedance-1-0-pro-250528",
    "content": [
        {
            "type": "text",
            "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"
        }
    ]
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Antwortverarbeitung

Nach erfolgreichem Aufruf gibt die API Daten im JSON-Format zurück. Es wird empfohlen, den HTTP-Statuscode zu prüfen:

```python
if response.status_code == 200:
    result = response.json()
    print("Aufruf erfolgreich:", result)
else:
    print(f"Aufruf fehlgeschlagen, Statuscode: {response.status_code}")
    print(response.text)
```

## Erweiterte Verwendung

Für APIs, die asynchrone Aufgaben unterstützen, können Sie Ergebnisse über eine Callback-URL erhalten:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Das Ergebnis wird über die Callback-URL an Ihren Server gesendet
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                     |
|------------|---------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token überprüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten      |
| 500        | Interner Serverfehler           |
