## Einführung

Seedance ist ein von Ace Data Cloud bereitgestellter KI-Videoservice, basierend auf dem Seedance Video-Generierungsmodell von ByteDance. Über die einheitliche API von Ace Data Cloud können Sie mit cURL schnell auf Seedance zugreifen und Funktionen wie Text-zu-Video, Bild-zu-Video, Audioerzeugung und verschiedene Auflösungen nutzen.

## Voraussetzungen

- Ein [Ace Data Cloud](https://platform.acedata.cloud) Konto und ein API-Token
- Ein Terminal mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Seedance API lautet:

```
POST https://api.acedata.cloud/seedance/videos
```

In diesem Beispiel wird das Modell `doubao-seedance-1-0-pro-250528` verwendet. Verfügbare Modelle sind: `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`.

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/seedance/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "doubao-seedance-1-0-pro-250528", "content": [{"type": "text", "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"}]}'
```

Ersetzen Sie `YOUR_API_TOKEN` durch Ihren tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Antwortbeispiel

Bei erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, z. B.:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/seedance/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "doubao-seedance-1-0-pro-250528", "content": [{"type": "text", "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"}]}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                     |
|------------|--------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten      |
| 500        | Interner Serverfehler           |

## Nächste Schritte

- Besuchen Sie die [Ace Data Cloud Konsole](https://platform.acedata.cloud), um Ihren API-Token zu erhalten
- Lesen Sie die [API-Dokumentation](https://docs.acedata.cloud/zh-CN/api-reference) für vollständige Parameterinformationen
- Informieren Sie sich über die [Preismodelle](https://platform.acedata.cloud/services) für Kostenübersicht
