## Einführung

QR Art ist ein von Ace Data Cloud bereitgestellter KI-Bilddienst zur Erstellung von KI-Kunst-QR-Codes. Über die einheitliche API von Ace Data Cloud können Sie mit cURL schnell QR Art aufrufen und Funktionen wie Link-QR-Codes, Text-QR-Codes, voreingestellte Stile und benutzerdefinierte Parameter nutzen.

## Voraussetzungen

- Ein [Ace Data Cloud](https://platform.acedata.cloud) Konto und ein API-Token
- Ein Terminal mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der QR Art API lautet:

```
POST https://api.acedata.cloud/qrart/generate
```

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}'
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispielantwort

Bei erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, z. B.:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                      |
|------------|---------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten      |
| 500        | Interner Serverfehler           |

## Nächste Schritte

- Besuchen Sie die [Ace Data Cloud Konsole](https://platform.acedata.cloud), um Ihren API-Token zu erhalten
- Lesen Sie die [API-Dokumentation](https://docs.acedata.cloud/zh-CN/api-reference) für vollständige Parameterinformationen
- Informieren Sie sich über die [Preismodelle](https://platform.acedata.cloud/services) zu den Kosten
