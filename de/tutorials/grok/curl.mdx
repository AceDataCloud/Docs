## Einführung

Grok ist ein von Ace Data Cloud bereitgestellter AI-Chat-Service, basierend auf der xAI Grok-Serie großer Sprachmodelle. Über die einheitliche API von Ace Data Cloud können Sie Grok schnell mit cURL aufrufen und Funktionen wie mehrstufige Dialoge, System-Prompts, Streaming-Ausgabe, JSON-Ausgabe-Modus und visuelles Verständnis nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) und ein API-Token
- Ein Terminal mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Grok-API lautet:

```
POST https://api.acedata.cloud/grok/chat/completions
```

In diesem Beispiel wird das Modell `grok-3` verwendet.
Verfügbare Modelle sind: `grok-4`, `grok-4-1-fast`, `grok-3`, `grok-3-mini`, `grok-2-vision`.

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/grok/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "grok-3", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispielantwort

Bei erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, z.B.:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/grok/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "grok-3", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                          |
|------------|------------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten          |
| 500        | Interner Serverfehler               |
