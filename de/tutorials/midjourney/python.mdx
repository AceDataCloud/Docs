## Einführung

Midjourney ist ein von Ace Data Cloud bereitgestellter KI-Bilddienst zur Midjourney KI-Bilderzeugung. Über die einheitliche API von Ace Data Cloud können Sie Midjourney mit Python schnell integrieren und Funktionen wie Text-zu-Bild, Bildbearbeitung, Bildbeschreibung, Bild-zu-Video, Seed-Steuerung und asynchrone Callbacks nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) und ein API-Token
- Python 3.7 oder höher
- Installation der requests-Bibliothek: `pip install requests`

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Midjourney API ist:

```
POST https://api.acedata.cloud/midjourney/imagine
```

Vollständiges Python-Beispiel:

```python
import requests

url = "https://api.acedata.cloud/midjourney/imagine"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "A serene Japanese garden with cherry blossoms",
    "action": "generate",
    "mode": "fast",
    "translation": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Antwortverarbeitung

Nach einem erfolgreichen Aufruf gibt die API Daten im JSON-Format zurück. Es wird empfohlen, den HTTP-Statuscode zu prüfen:

```python
if response.status_code == 200:
    result = response.json()
    print("Aufruf erfolgreich:", result)
else:
    print(f"Aufruf fehlgeschlagen, Statuscode: {response.status_code}")
    print(response.text)
```

## Erweiterte Verwendung

Für APIs, die asynchrone Aufgaben unterstützen, können Sie Ergebnisse über eine Callback-URL erhalten:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Das Ergebnis wird über die Callback-URL an Ihren Server gesendet
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                        |
|------------|-----------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder keine Zugriffsberechtigung |
| 429        | Anfragelimit überschritten        |
| 500        | Interner Serverfehler             |

## Weitere Endpunkte

Der Midjourney-Dienst bietet außerdem folgende Endpunkte:

- `POST https://api.acedata.cloud/midjourney/seed`
- `POST https://api.acedata.cloud/midjourney/edits`
- `POST https://api.acedata.cloud/midjourney/videos`
- `POST https://api.acedata.cloud/midjourney/describe`
