## Einführung

Claude ist ein von Ace Data Cloud bereitgestellter KI-Chat-Service, basierend auf der großen Sprachmodellreihe Anthropic Claude. Über die einheitliche API von Ace Data Cloud können Sie Claude mit Python schnell integrieren und Funktionen wie mehrstufige Dialoge, System-Prompt, Streaming-Ausgabe und JSON-Ausgabemodus nutzen.

## Voraussetzungen

- Ein [Ace Data Cloud](https://platform.acedata.cloud) Konto und ein API-Token
- Python 3.7 oder höher
- Installation der requests-Bibliothek: `pip install requests`

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Claude API ist:

```
POST https://api.acedata.cloud/v1/chat/completions
```

In diesem Beispiel wird das Modell `claude-sonnet-4-6` verwendet. Verfügbare Modelle sind: `claude-sonnet-4-6`, `claude-opus-4-5-20251101`, `claude-3-5-sonnet`.

Vollständiges Python-Codebeispiel:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "claude-sonnet-4-6",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Antwortverarbeitung

Nach einem erfolgreichen Aufruf gibt die API Daten im JSON-Format zurück. Es wird empfohlen, den HTTP-Statuscode zu prüfen:

```python
if response.status_code == 200:
    result = response.json()
    print("Aufruf erfolgreich:", result)
else:
    print(f"Aufruf fehlgeschlagen, Statuscode: {response.status_code}")
    print(response.text)
```

## Erweiterte Verwendung

Für Chat-APIs wird Streaming-Ausgabe unterstützt, um Echtzeit-Antworten zu erhalten:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                          |
|------------|-------------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragerate überschritten            |
| 500        | Interner Serverfehler                |

## Weitere Endpunkte

Der Claude-Service bietet außerdem folgende Endpunkte:

- `POST https://api.acedata.cloud/v1/messages`
- `POST https://api.acedata.cloud/v1/messages/count_tokens`
