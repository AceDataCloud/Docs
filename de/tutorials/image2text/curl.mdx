## Einführung

Image2Text ist ein Captcha-Dienst von Ace Data Cloud zur Erkennung von Bild-Captchas. Über die einheitliche API von Ace Data Cloud können Sie mit cURL schnell auf Image2Text zugreifen und Funktionen wie Bild-Captcha-Erkennung, Base64-Eingabe und URL-Eingabe nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) besitzen und einen API-Token erhalten
- Eine Terminal-Umgebung mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt der Image2Text API lautet:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}'
```

Ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispielantwort

Bei erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, z.B.:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur formatierten Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                    |
|------------|--------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriffsrecht           |
| 429        | Anfragelimit überschritten                                  |
| 500        | Interner Serverfehler                                      |

## Nächste Schritte

- Besuchen Sie die [Ace Data Cloud Konsole](https://platform.acedata.cloud), um Ihren API-Token zu erhalten
- Lesen Sie die [API-Dokumentation](https://docs.acedata.cloud/zh-CN/api-reference) für vollständige Parameterangaben
- Informieren Sie sich über die [Preismodelle](https://platform.acedata.cloud/services) zu den Kosten
