## Einführung

Localization ist ein von Ace Data Cloud bereitgestellter Tool-Service für AI-Übersetzungen und Lokalisierungsdienste. Über die einheitliche API von Ace Data Cloud können Sie mit Python schnell Localization integrieren und Funktionen wie Markdown-Übersetzung, JSON-Übersetzung, 18 Sprachen und Formatbeibehaltung nutzen.

## Voraussetzungen

- Ein [Ace Data Cloud](https://platform.acedata.cloud) Konto und ein API Token
- Python 3.7 oder höher
- Installation der requests-Bibliothek: `pip install requests`

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der Localization API lautet:

```
POST https://api.acedata.cloud/localization/translate
```

In diesem Beispiel wird das Modell `gpt-4` verwendet. Verfügbare Modelle sind: `gpt-3.5`, `gpt-4`.

Vollständiges Python-Beispiel:

```python
import requests

url = "https://api.acedata.cloud/localization/translate"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "input": "# 欢迎使用\n\n这是一段示例文本。",
    "locale": "en",
    "extension": "md",
    "model": "gpt-4"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Antwortverarbeitung

Nach einem erfolgreichen Aufruf gibt die API Daten im JSON-Format zurück. Es wird empfohlen, den HTTP-Statuscode zu prüfen:

```python
if response.status_code == 200:
    result = response.json()
    print("Aufruf erfolgreich:", result)
else:
    print(f"Aufruf fehlgeschlagen, Statuscode: {response.status_code}")
    print(response.text)
```

## Erweiterte Verwendung

Für APIs, die asynchrone Aufgaben unterstützen, kann das Ergebnis über eine Callback-URL abgerufen werden:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Das Ergebnis wird über die Callback-URL an Ihren Server gesendet
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                      |
|------------|---------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten      |
| 500        | Interner Serverfehler           |
