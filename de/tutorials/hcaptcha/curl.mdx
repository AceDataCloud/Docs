## Einführung

hCaptcha ist ein Captcha-Dienst, der von Ace Data Cloud bereitgestellt wird. Mit der hCaptcha-Lösung können Sie über die einheitliche API von Ace Data Cloud hCaptcha schnell per cURL aufrufen, um Funktionen wie das Abrufen von hCaptcha-Tokens und die Erkennung von hCaptcha-Bildern zu realisieren.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) besitzen und einen API-Token erhalten
- Eine Terminalumgebung mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt zum Aufrufen der hCaptcha-API lautet:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Vollständiges cURL-Beispiel:

```bash
curl -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}'
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Antwortbeispiel

Nach erfolgreichem Aufruf wird eine JSON-Antwort zurückgegeben, zum Beispiel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                          |
|------------|------------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragelimit überschritten          |
| 500        | Interner Serverfehler               |
