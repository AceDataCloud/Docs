## Einführung

DeepSeek ist ein von Ace Data Cloud bereitgestellter KI-Chat-Service, basierend auf der DeepSeek-Serie großer Sprachmodelle. Über die einheitliche API von Ace Data Cloud können Sie DeepSeek schnell mit cURL aufrufen und Funktionen wie mehrstufige Dialoge, System-Prompting, Streaming-Ausgabe, JSON-Ausgabe-Modus und tiefgehende Inferenz nutzen.

## Voraussetzungen

- Ein Konto bei [Ace Data Cloud](https://platform.acedata.cloud) und ein API-Token
- Ein Terminal mit installiertem cURL

## Grundlegende Verwendung

Der Hauptendpunkt für den Aufruf der DeepSeek-API lautet:

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

In diesem Beispiel wird das Modell `deepseek-r1` verwendet. Verfügbare Modelle sind: `deepseek-r1`, `deepseek-r1-0528`, `deepseek-v3`, `deepseek-v3-250324`.

Vollständiges Beispiel für den cURL-Befehl:

```bash
curl -X POST https://api.acedata.cloud/deepseek/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-r1", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Bitte ersetzen Sie `YOUR_API_TOKEN` durch den tatsächlichen Token, den Sie auf der Ace Data Cloud Plattform erhalten haben.

## Beispiel für die Antwort

Nach erfolgreichem Aufruf wird eine JSON-formatierte Antwort zurückgegeben, zum Beispiel:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Verarbeitung der Antwort mit jq

Es wird empfohlen, das Tool jq zur Formatierung der Ausgabe zu verwenden:

```bash
curl -s -X POST https://api.acedata.cloud/deepseek/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-r1", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Fehlerbehandlung

Häufige Fehlercodes:

| Statuscode | Beschreibung                      |
|------------|---------------------------------|
| 401        | Authentifizierung fehlgeschlagen, bitte API-Token prüfen |
| 403        | Unzureichendes Guthaben oder kein Zugriff |
| 429        | Anfragerate überschritten       |
| 500        | Interner Serverfehler           |

## Nächste Schritte

- Besuchen Sie die [Ace Data Cloud Konsole](https://platform.acedata.cloud), um Ihren API-Token zu erhalten
- Lesen Sie die [API-Dokumentation](https://docs.acedata.cloud/zh-CN/api-reference) für vollständige Parameterdetails
- Informieren Sie sich über die [Preismodelle](https://platform.acedata.cloud/services) für Kostenübersicht
