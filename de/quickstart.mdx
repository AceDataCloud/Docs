## 1. API-Schlüssel erhalten

Melden Sie sich in der [Anwendungsliste](https://platform.acedata.cloud/console/applications?lang=de&utm_source=docs&utm_medium=referral&utm_campaign=evergreen) an und öffnen Sie **General Application**. Klicken Sie bei der ersten Nutzung auf **Initialize General Application**. Klicken Sie auf die Kopierschaltfläche rechts neben **API KEY**.

![API-Schlüssel der allgemeinen Anwendung](https://cdn.acedata.cloud/dvc3cg.jpg)

Speichern Sie den Schlüssel auf Ihrem Server und ersetzen Sie damit `YOUR_API_TOKEN` im Beispiel.

## 2. Erste Anfrage senden

Alle APIs verwenden Bearer-Token-Authentifizierung:

<CodeGroup>

```bash cURL
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-20250514",
    "messages": [{"role": "user", "content": "你好！"}]
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.acedata.cloud/v1/chat/completions",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json={
        "model": "claude-sonnet-4-20250514",
        "messages": [{"role": "user", "content": "你好！"}],
    },
)
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://api.acedata.cloud/v1/chat/completions", {
  method: "POST",
  headers: {
    Authorization: "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "claude-sonnet-4-20250514",
    messages: [{ role: "user", content: "你好！" }],
  }),
});
const data = await response.json();
console.log(data);
```

</CodeGroup>
