---

Alle Ace Data Cloud APIs verwenden **Bearer Token** zur Authentifizierung.

## Token erhalten

Melden Sie sich unter [Applications](https://platform.acedata.cloud/console/applications?lang=de&utm_source=docs&utm_medium=referral&utm_campaign=evergreen) an und öffnen Sie **General Application**. Falls die Anwendung beim ersten Besuch fehlt, wählen Sie **Initialize General Application**. Klicken Sie neben **API KEY** auf die mit **1** markierte Kopierschaltfläche.

![Mit 1 markierte Kopierschaltfläche neben dem API-Schlüssel](https://raw.githubusercontent.com/AceDataCloud/NanoBananaDify/2522b2f57210597af2db866445319334a1677a23/_assets/tutorial/get-api-key-en.png)

Speichern Sie den Schlüssel auf Ihrem Server und ersetzen Sie damit `YOUR_API_TOKEN` im Beispiel.

## Token verwenden

Fügen Sie in jedem Request den Token im `Authorization`-Header hinzu:

```bash
Authorization: Bearer YOUR_API_TOKEN
```


## Ratenbegrenzung

Die Ratenbegrenzung variiert je nach Dienst und Abonnementstufe. Bei Überschreitung der Grenze gibt die API `429 Too Many Requests` zurück.

## Sicherheitsbest Practices

- API Token nicht im Client-Code offenlegen
- Token in Umgebungsvariablen speichern
- Token regelmäßig rotieren
- Für Entwicklungs- und Produktionsumgebungen unterschiedliche Tokens verwenden
