---
title: "Authentifizierung"
description: "Wie man die Ace Data Cloud API zur Authentifizierung verwendet"
---

Alle Ace Data Cloud APIs verwenden **Bearer Token** zur Authentifizierung.

## Token erhalten

1. Registrieren Sie ein Konto auf [platform.acedata.cloud](https://platform.acedata.cloud)
2. Abonnieren Sie die benötigten Dienste
3. Erstellen Sie für jeden Dienst Anmeldeinformationen (API Token)

## Token verwenden

Fügen Sie in jedem Request den Token im `Authorization`-Header hinzu:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Hinweis">
  Jeder Token ist an ein bestimmtes Dienstabonnement gebunden. Für verschiedene Dienste werden unterschiedliche Tokens verwendet, oder es kann ein **globaler** Token erstellt werden, der dienstübergreifend genutzt werden kann.
</Note>

## Ratenbegrenzung

Die Ratenbegrenzung variiert je nach Dienst und Abonnementstufe. Bei Überschreitung der Grenze gibt die API `429 Too Many Requests` zurück.

## Sicherheitsbest Practices

- API Token nicht im Client-Code offenlegen
- Token in Umgebungsvariablen speichern
- Token regelmäßig rotieren
- Für Entwicklungs- und Produktionsumgebungen unterschiedliche Tokens verwenden
