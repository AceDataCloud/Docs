## Basis-URL

Die Basisadresse aller API-Endpunkte:

```
https://api.acedata.cloud
```

## Authentifizierung

Alle Endpunkte erfordern eine Bearer-Token-Authentifizierung:

```
Authorization: Bearer YOUR_API_TOKEN
```

## Online-Test

Jeder Endpunkt in dieser Referenz enthält eine interaktive Sandbox. Geben Sie Ihren API-Token ein, um Anfragen direkt im Browser zu testen.

<Note title="Tipp">
  Erhalten Sie Ihren API-Token auf [platform.acedata.cloud](https://platform.acedata.cloud).
</Note>
