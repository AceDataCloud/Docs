## Was ist MCP

Model Context Protocol (MCP) ist ein offenes Protokoll, das es AI-Assistenten (wie Claude, Cursor) ermöglicht, externe Tools und APIs direkt aufzurufen. Mit MCP kann AI nicht nur Fragen beantworten, sondern auch praktische Aktionen ausführen.

## Von Ace Data Cloud bereitgestellte MCP Server

| MCP Server       | PyPI Paketname     | Funktion            |
|------------------|--------------------|---------------------|
| MCPSuno          | mcp-suno           | AI-Musikgenerierung |
| MCPSerp          | mcp-serp           | Google-Suche        |
| MCPMidjourney    | mcp-midjourney     | AI-Bilderzeugung    |
| MCPLuma          | mcp-luma           | AI-Videogenerierung |
| MCPSora          | mcp-sora           | AI-Videogenerierung |
| MCPVeo           | mcp-veo            | AI-Videogenerierung |
| MCPNanoBanana    | mcp-nano-banana    | AI-Bilderzeugung    |

## Installation und Nutzung

### Installation

```bash
pip install mcp-suno  # oder ein anderer MCP Server
```

### Umgebungsvariablen konfigurieren

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### Konfiguration in Cursor

Fügen Sie in den MCP-Einstellungen von Cursor Folgendes hinzu:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### Konfiguration in Claude Desktop

Bearbeiten Sie die Konfigurationsdatei von Claude Desktop und fügen Sie die MCP Server-Konfiguration hinzu.

## Anwendungsfälle

1. **Musik in Cursor generieren**: Sagen Sie der AI "Erzeuge mit Suno ein fröhliches Lied", die AI ruft die API direkt auf  
2. **Echtzeitinformationen suchen**: Die AI kann über den SERP MCP Server die neuesten Informationen suchen  
3. **Projektmaterialien generieren**: Die AI kann Midjourney aufrufen, um benötigte Bildmaterialien für Projekte zu erzeugen

## MCP vs direkter API-Aufruf

- **MCP**: Geeignet für die Nutzung in AI-Programmierwerkzeugen, wird automatisch von der AI aufgerufen  
- **API**: Geeignet zur Integration in eigene Anwendungen, programmatische Steuerung

Beide verwenden denselben Ace Data Cloud API Token und rufen dieselben API-Endpunkte auf.

## Zusammenfassung

MCP ermöglicht AI-Assistenten, verschiedene APIs von Ace Data Cloud direkt aufzurufen. Alle MCP Server sind auf PyPI veröffentlicht, die Installation und Konfiguration ist einfach, wodurch Ihre AI-Tools leistungsfähiger werden.

Besuchen Sie [platform.acedata.cloud](https://platform.acedata.cloud), um Ihren API Token zu erhalten.
