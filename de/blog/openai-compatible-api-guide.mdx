## Was ist die OpenAI-kompatible Schnittstelle

Das Chat Completions API-Format von OpenAI hat sich zum De-facto-Standard in der Branche entwickelt. Viele große Sprachmodelle bieten eine OpenAI-kompatible Schnittstelle an, sodass Entwickler mit demselben Code auf verschiedene Modelle zugreifen können.

Ace Data Cloud stellt für Modelle wie Claude, Gemini, DeepSeek, Grok, Kimi und weitere eine OpenAI-kompatible Chat Completions Schnittstelle bereit. Ein Wechsel ist einfach durch Anpassung der Basis-URL und des Modellnamens möglich.

## Unterstützte Modelle

| Dienst | Endpunkt | Beispielmodell |
|--------|----------|----------------|
| Claude | `POST /v1/chat/completions` | claude-sonnet-4-6 |
| OpenAI | `POST /openai/chat/completions` | gpt-4o |
| Gemini | `POST /gemini/chat/completions` | gemini-2.5-flash |
| DeepSeek | `POST /deepseek/chat/completions` | deepseek-r1 |
| Grok | `POST /grok/chat/completions` | grok-3 |
| Kimi | `POST /kimi/chat/completions` | kimi-k2.5 |

## Einheitliche Aufrufmethode

Alle Chat-Modelle verwenden dasselbe Anfrageformat:

```python
import requests

def chat(endpoint, model, message):
    return requests.post(
        f"https://api.acedata.cloud{endpoint}",
        headers={
            "Authorization": "Bearer YOUR_API_TOKEN",
            "Content-Type": "application/json",
        },
        json={
            "model": model,
            "messages": [{"role": "user", "content": message}],
            "max_tokens": 1024,
            "temperature": 0.7,
        },
    ).json()

# Aufruf verschiedener Modelle – nur Endpunkt und Modellname ändern
claude = chat("/v1/chat/completions", "claude-sonnet-4-6", "你好")
gpt = chat("/openai/chat/completions", "gpt-4o", "你好")
gemini = chat("/gemini/chat/completions", "gemini-2.5-flash", "你好")
deepseek = chat("/deepseek/chat/completions", "deepseek-r1", "你好")
```

## Streaming-Ausgabe

Alle Chat-APIs unterstützen Streaming-Ausgabe (Server-Sent Events):

```python
data = {
    "model": "claude-sonnet-4-6",
    "messages": [{"role": "user", "content": "写一首诗"}],
    "stream": True,
}

response = requests.post(
    "https://api.acedata.cloud/v1/chat/completions",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json=data,
    stream=True,
)

for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Kompatibilität mit dem OpenAI SDK

Da das Schnittstellenformat kompatibel ist, können Sie das offizielle OpenAI SDK direkt verwenden, indem Sie nur die base_url anpassen:

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_TOKEN",
    base_url="https://api.acedata.cloud/v1",  # Claude
    # base_url="https://api.acedata.cloud/openai",  # OpenAI
    # base_url="https://api.acedata.cloud/gemini",  # Gemini
)

response = client.chat.completions.create(
    model="claude-sonnet-4-6",
    messages=[{"role": "user", "content": "你好"}],
)
print(response.choices[0].message.content)
```

## Zusammenfassung

Mit der OpenAI-kompatiblen Schnittstelle von Ace Data Cloud können Sie:

- Mit einem einzigen Code auf über 6 große Sprachmodelle zugreifen
- Flexibel zwischen Modellen wechseln, um Leistung und Kosten zu vergleichen
- Das OpenAI SDK direkt nutzen, ohne Migrationsaufwand
- Einheitliche Abrechnung und Überwachung

Probieren Sie es kostenlos aus unter [platform.acedata.cloud](https://platform.acedata.cloud).
