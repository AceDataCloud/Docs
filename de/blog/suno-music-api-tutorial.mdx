## Einführung in Suno

Suno ist eine der leistungsstärksten KI-Musikgenerierungsplattformen. Über die Suno API von Ace Data Cloud können Sie durch einfache API-Aufrufe hochwertige Musik erzeugen.

## API-Endpunkte

| Endpunkt | Funktion |
|----------|----------|
| `POST /suno/audios` | Musik generieren (Hauptendpunkt) |
| `POST /suno/lyrics` | Songtexte generieren |
| `POST /suno/persona` | Sängerstil verwalten |
| `POST /suno/wav` | WAV-Format abrufen |
| `POST /suno/mp4` | MP4-Format abrufen |
| `POST /suno/tasks` | Aufgabenstatus abfragen |

## Grundlegende Generierung

### Textbeschreibungsgenerierung

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### Benutzerdefinierte Songtextgenerierung

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\n夏日的阳光洒满了海岸\n微风中传来浪花的声音\n\n[Chorus]\n让我们一起去远方\n追逐那自由的梦想",
        "style": "pop upbeat",
        "title": "夏日冒险",
    },
)
```

## Erweiterte Funktionen

### Songfortsetzung

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### Songtext generieren

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "写一首关于冬天的歌",
    },
)
```

## Verfügbare Modelle

| Modell    | Eigenschaften          |
|-----------|-----------------------|
| chirp-v5  | Neueste Version, beste Klangqualität |
| v4-5-plus | Verbesserte Version    |
| v4-5      | Stabile Version       |
| v4        | Klassische Version    |

## Zusammenfassung

Die Suno API bietet über die Ace Data Cloud Plattform umfassende Musikgenerierungsfunktionen. Ob einfache Textgenerierung oder benutzerdefinierte Songtextkreation – alles lässt sich mit wenigen Codezeilen realisieren.

Registrieren Sie sich und probieren Sie es aus unter [platform.acedata.cloud](https://platform.acedata.cloud).
