Claude Code ist ein Programmierwerkzeug, das von Anthropic eingeführt wurde und auch als einer der stärksten Programmier-Agenten der Welt bezeichnet wird. Die VS Code-Erweiterung von Claude Code bietet eine native grafische Benutzeroberfläche und ist die empfohlene Methode, um Claude Code in VS Code zu verwenden.

Dieses Dokument beschreibt hauptsächlich, wie man über den Proxy-Service von Ace Data Cloud die Claude Code-Erweiterung in VS Code konfiguriert und verwendet.

## Antragsprozess

Um Claude Code zu verwenden, können Sie zunächst zur [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications) gehen, um Ihr API-Token zu erhalten, das Sie zur Sicherheit aufbewahren sollten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, die Sie zur Registrierung und Anmeldung einlädt. Nach der Anmeldung werden Sie automatisch zur aktuellen Seite zurückgeleitet.

Bei der ersten Beantragung gibt es ein kostenloses Kontingent, mit dem Sie die Claude Code-Dienste kostenlos ausprobieren können.

## Installation des Claude Code Plugins

Suchen Sie im VS Code-Erweiterungsmarkt nach **Claude Code**, und installieren Sie es, nachdem Sie bestätigt haben, dass der Herausgeber **Anthropic** ist. Nach der Installation wird im Aktivitätsbereich der Zugang zu Claude Code angezeigt.

## Konfiguration der Ace Data Cloud API

Beim ersten Öffnen des Plugins werden Sie aufgefordert, sich mit einem offiziellen Anthropic-Konto anzumelden. Wir können die offizielle Anmeldung überspringen und die Proxy-API von Ace Data Cloud konfigurieren, um sie zu verwenden, ohne ein offizielles Abonnement zu benötigen.

Die Erweiterung und das Terminal-CLI lesen dasselbe Claude Code Settings. Vollständige Authentifizierung, Konfliktbehandlung von Anmeldeinformationen und globale Konfigurationsmethoden finden Sie im [Claude Code Terminal-Konfigurationshandbuch](https://platform.acedata.cloud/documents/claude-code-terminal-integration). Wenn Sie möchten, dass die Konfiguration nur für das aktuelle Projekt gilt, erstellen Sie im Stammverzeichnis des Projekts eine `.claude/settings.local.json`, die in `.gitignore` aufgenommen wurde:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Dabei ist `{token}` der gerade kopierte API-Schlüssel. Wenn in der Umgebung, in der Sie VS Code starten, bereits ein alter `ANTHROPIC_API_KEY` vorhanden ist, setzen Sie diesen bitte zuerst mit `unset ANTHROPIC_API_KEY` in dieser Umgebung zurück; verwenden Sie keinen leeren String zur Bereinigung und fügen Sie keinen echten Schlüssel in die teamgeteilte `.claude/settings.json` ein.

Hier ist die Konfiguration, die auf meinem lokalen System mit VS Code 1.136.1 und der Claude Code-Erweiterung 2.1.251 abgeschlossen wurde. Der Screenshot verwendet Platzhalter-Keys, um die Offenlegung echter Anmeldeinformationen zu vermeiden:

![Ace Data Cloud Claude Code Konfiguration in VS Code](https://cdn.acedata.cloud/f925e9e9597b.png)

Nach der Konfiguration starten Sie VS Code neu.

> Hinweis: Die oben genannte Konfiguration gilt nur für das aktuelle Projekt, und es wird empfohlen, den oben genannten Pfad zur `.claude/settings.local.json` in die `.gitignore`-Datei aufzunehmen, um zu verhindern, dass sie in das Remote-Repository gelangt.

Wenn Sie möchten, dass alle Projekte betroffen sind, können Sie diese Konfiguration direkt im Benutzerverzeichnis speichern. Der entsprechende Pfad ist `~/.claude/settings.json`,

> Hinweis: Nach der Konfiguration starten Sie bitte VS Code neu oder laden Sie es neu, damit die oben genannte Konfiguration wirksam wird.

## Grundlegende Verwendung

Nachdem Sie konfiguriert haben, senden Sie im Claude Code-Bereich eine einfache schreibgeschützte Aufgabe, wie zum Beispiel „Lesen Sie README.md und fassen Sie es in einem Satz zusammen“. Nach erfolgreichem Abschluss der Aufgabe können Sie den aktuellen Aufruf in der [Verwendungshistorie](https://platform.acedata.cloud/console/usages) überprüfen.

## So überprüfen Sie das verbleibende Kontingent

Über die [Ace Data Cloud-Konsole - Anwendungsübersicht](https://platform.acedata.cloud/console/applications) können Sie das verbleibende Kontingent Ihres aktuellen Kontos einsehen.

Über die [Ace Data Cloud-Konsole - Verwendungshistorie](https://platform.acedata.cloud/console/usages) können Sie alle Verwendungshistorien und Abrechnungsdetails einsehen.
