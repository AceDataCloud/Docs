Dieses Dokument hat nur ein Ziel: Dir **innerhalb von 5 Minuten** zu zeigen, wie du mit dem AceData Cloud Proxy den ersten Claude Code Befehl ausführst. Die vollständigen Tutorials findest du in den jeweiligen IDE-Unterdokumenten ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); hier gehen wir nur den schnellsten Weg mit „**Terminal CLI** + **VS Code Erweiterung**“.

> **Warum AceData Cloud als Proxy für Claude Code verwenden**:
> - Direkter Zugriff aus China ohne VPN
> - Günstiger als die offizielle Abrechnung (Token-basiert über die Plattform)
> - Ein einziger Key unterstützt gleichzeitig Claude Messages API + Claude Code Token Protokoll

## Minute 1: Zugangsdaten beantragen

Öffne die [Claude Messages Service-Seite](https://platform.acedata.cloud/documents/claude-messages) und klicke auf den Button „**Acquire**“:

![](https://cdn.acedata.cloud/nyq0xz.png)

Die Plattform erstellt automatisch eine Application für dich und schenkt dir ein kostenloses Kontingent. Notiere dir die beiden Werte **Base URL** + **API Token** aus der Detailseite — du brauchst sie in den nächsten 5 Schritten.

| Feld | Wert | Zweck |
|------|------|-------|
| `BASE_URL` | `https://api.acedata.cloud` | Claude Messages kompatibler Endpunkt |
| `API_TOKEN` | `sk-...` (auf der Detailseite kopierbar) | Anthropic-kompatibler Authentifizierungs-Token |

## Minute 2: Claude Code installieren

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell nativ):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Nach der Installation öffne ein neues Terminal und prüfe die Version:

```bash
claude --version
```

> Wenn die Versionsnummer angezeigt wird, ist alles in Ordnung. Claude Code bringt eine eigene Node.js Laufzeit mit und ist nicht von der Node-Version auf deinem Rechner abhängig.

## Minute 3: Umgebungsvariablen auf AceData Cloud setzen

Verwende nicht den offiziellen `claude login` Prozess, sondern überschreibe die Einstellungen per Umgebungsvariablen. Wähle eine der beiden Methoden:

**Methode A: Temporär (nur aktuelle Shell-Sitzung)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-dein-Token"
```

**Methode B: Permanent (empfohlen)**

Füge die beiden Zeilen in deine `~/.zshrc` oder `~/.bashrc` ein und führe anschließend `source` aus.

> **Häufige Fehlerquelle**: Der Variablenname muss `ANTHROPIC_AUTH_TOKEN` lauten, nicht `ANTHROPIC_API_KEY`; bei falschem Namen fällt Claude Code auf den offiziellen Endpunkt zurück und gibt 401 zurück.

## Minute 4: Ersten Befehl ausführen

Wechsle in ein beliebiges Git-Repository und führe aus:

```bash
claude
```

Wenn beim ersten Start eine Anmeldung verlangt wird, drücke `Esc`, um sie zu überspringen. Gib dann ein:

```
Liste die Abhängigkeiten des aktuellen Projekts auf und erkläre kurz deren Zweck.
```

Normalerweise siehst du, wie Claude `read_file` / `glob` / `grep` usw. verwendet, um das Repository zu durchsuchen, und anschließend eine Liste ausgibt. Wenn das Modell korrekt antwortet und kein 401 erscheint, funktioniert der Proxy.

## Minute 5: VS Code Erweiterung einrichten

1. Öffne VS Code → Erweiterungen → suche nach `Claude Code` und installiere die offizielle Anthropic-Erweiterung;
2. Starte VS Code neu oder führe im Kommando-Panel `Developer: Reload Window` aus, damit die Erweiterung die in Minute 3 gesetzte `~/.claude/settings.json` lädt;
3. Klicke oben rechts im Editor auf das ✦ Spark-Symbol oder in der Statusleiste auf „✱ Claude Code“, um das Panel zu öffnen;
4. Beim ersten Mal wirst du zur offiziellen Anmeldung aufgefordert, drücke `Esc`, um sie zu überspringen — die Erweiterung verwendet automatisch die in Minute 3 konfigurierten `ANTHROPIC_BASE_URL` und `ANTHROPIC_AUTH_TOKEN`.

> **Tipp**: Die VS Code Erweiterung und die CLI teilen sich dieselbe `~/.claude/settings.json`, du musst also nichts extra in VS Code konfigurieren. Für projektbezogene Einstellungen kannst du im Root-Verzeichnis des Repos `.claude/settings.local.json` anlegen (ist in `.gitignore`).

Nach erfolgreicher Einrichtung kannst du im Panel Dateien per Drag & Drop zum Fragen verwenden oder mit `@-mention` Dateien referenzieren, um Änderungsvorschläge zu machen. Alle Kosten laufen über AceData Cloud.

## Überprüfen, ob der Proxy aktiv ist

Starte einmal mit `--debug`, um zu sehen, ob die Anfrage tatsächlich an AceData Cloud geht:

```bash
claude --debug -p "say hi" 2>&1 | grep -iE 'base.?url|api\.acedata|anthropic\.com' | head
```

Wenn du `https://api.acedata.cloud` siehst, ist der Proxy aktiv; erscheint `api.anthropic.com` oder ein 401, überprüfe die Umgebungsvariablen (müssen `ANTHROPIC_AUTH_TOKEN` heißen, nicht `ANTHROPIC_API_KEY`) und stelle sicher, dass `~/.claude/.credentials.json` nicht den offiziellen Token enthält (lösche die Datei ggf.).

## Die 5 häufigsten Fragen

**Q: Ich habe `claude login` ausgeführt und danach die Umgebungsvariablen auf AceData geändert, warum funktioniert es nicht?**  
A: `claude login` schreibt den offiziellen Token in `~/.claude/.credentials.json`, der Vorrang vor Umgebungsvariablen hat. Lösche diese Datei und lade deine Shell-Konfiguration neu (`source ~/.zshrc`).

**Q: Kann ich Modelle wie `--model claude-opus-4-7` verwenden?**  
A: Ja. Der AceData Cloud Proxy leitet das `model`-Feld durch. Alle öffentlich verfügbaren Anthropic-Modelle plus unsere Erweiterungen `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5` werden unterstützt.

**Q: Kann ich mehrere Profile (privat + beruflich) konfigurieren?**  
A: Ja. Claude Code unterstützt mehrere Profile in `~/.claude/settings.json`; oder am einfachsten: Schreibe zwei Shell-Funktionen `claude_personal` / `claude_work`, die jeweils unterschiedliche `ANTHROPIC_AUTH_TOKEN` exportieren und dann `claude $@` aufrufen.

**Q: Kann ich das in GitHub Actions verwenden?**  
A: Ja. Siehe [Claude Code GitHub Actions Konfiguration Tutorial](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**Q: Was passiert, wenn das kostenlose Kontingent aufgebraucht ist?**  
A: Gehe zu [Application Management](https://platform.acedata.cloud/applications) → wähle die Claude Application → Topup aufladen (Abrechnung nach tatsächlichem Token-Verbrauch) oder wechsle zu einem Punkt-Abonnement.
