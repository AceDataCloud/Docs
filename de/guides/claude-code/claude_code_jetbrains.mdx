## 1. API-Schlüssel erhalten

Öffnen Sie die [Ace Data Cloud Anwendungsübersicht](https://platform.acedata.cloud/console/applications), gehen Sie zu den verfügbaren Anwendungen und kopieren Sie den API-Schlüssel.

![API-Schlüssel von Ace Data Cloud erhalten](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. CLI und Plugins installieren

Zuerst Claude Code CLI installieren.

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

Dann das **Claude Code** Plugin aus dem JetBrains Marketplace installieren und die IDE neu starten. Das Plugin ruft den lokalen `claude` Befehl auf; wenn der Befehl nicht gefunden wird, geben Sie den vollständigen Pfad unter **Einstellungen → Werkzeuge → Claude Code** ein.

## 3. Ace Data Cloud konfigurieren

In der Umgebung, in der JetBrains Backend gestartet wird, einstellen.

macOS / Linux / WSL:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="dein API-Schlüssel"
unset ANTHROPIC_API_KEY
```

Windows PowerShell:

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "dein API-Schlüssel"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

Es kann auch in einem Projekt mit der ignorierten Datei `.claude/settings.local.json` verwendet werden:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "dein API-Schlüssel"
  }
}
```

Remote Development muss auf dem Remote-Host konfiguriert und das Plugin installiert werden; WSL-Nutzer können den Claude-Befehl auf `wsl -d Ubuntu -- bash -lic "claude"` setzen.

## 4. Überprüfung

Führen Sie `claude` im integrierten Terminal der IDE aus oder geben Sie `/ide` in ein externes Terminal ein. Lassen Sie Claude nach erfolgreicher Verbindung mit `OK` antworten, lesen Sie dann eine Testdatei und überprüfen Sie die Anfrage in der Ace Data Cloud [Nutzungsverlauf](https://platform.acedata.cloud/console/usages).

Wenn das Plugin nicht startet, führen Sie zuerst `claude --version` im selben Terminal aus; bei 401 überprüfen Sie die tatsächlich geerbten Umgebungsvariablen des Backends und den alten `ANTHROPIC_API_KEY`.
