Claude Code ist ein von Anthropic entwickeltes **Agentic Coding**-Tool, das auch als einer der stärksten Programmier-Agenten der Welt bezeichnet wird. Claude Code bietet ein spezielles Plugin für JetBrains IDE, das IntelliJ IDEA, PyCharm, WebStorm, GoLand, PhpStorm, Android Studio und die gesamte Reihe von JetBrains IDE unterstützt.

Dieses Dokument beschreibt hauptsächlich, wie man Claude Code über den Proxy-Service von AceData Cloud in JetBrains IDE konfiguriert und verwendet.

## Antragsprozess

Um Claude Code zu verwenden, können Sie zunächst auf die [Claude Messages-Dienstseite](https://platform.acedata.cloud/documents/claude-messages) gehen und auf die Schaltfläche „Acquire“ klicken, um die benötigten Anmeldeinformationen zu erhalten:

![](https://cdn.acedata.cloud/nyq0xz.png)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach der Anmeldung werden Sie automatisch auf die aktuelle Seite zurückgeleitet.

Bei der ersten Antragstellung gibt es ein kostenloses Kontingent, mit dem Sie den Claude Code-Dienst kostenlos ausprobieren können.

## Installation

### Voraussetzungen

Das Claude Code JetBrains-Plugin hängt von Claude Code CLI ab, bitte stellen Sie sicher, dass CLI installiert ist:

```bash
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# Oder mit Homebrew
brew install claude-code
```

Nach der Installation können Sie dies überprüfen:

```bash
claude --version
```

### Plugin installieren

![Claude Code Plugin im JetBrains Marketplace](https://cdn.acedata.cloud/de78fd305b.png)

1. Öffnen Sie JetBrains IDE
2. Gehen Sie zu **Einstellungen** → **Plugins** → **Marketplace**
3. Suchen Sie nach **Claude Code**
4. Klicken Sie auf **Installieren**, um das Plugin zu installieren
5. Starten Sie die IDE neu

Oder besuchen Sie direkt den [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/27310-claude-code-beta-) für die Online-Installation.

> **Wichtig**: Nach der Installation des Plugins ist ein **vollständiger Neustart der IDE** erforderlich (möglicherweise sind mehrere Neustarts erforderlich), damit es wirksam wird.

## Konfiguration der AceData Cloud API

Das Claude Code JetBrains-Plugin führt den Befehl `claude` über das integrierte Terminal aus, daher ist die Konfiguration der Umgebungsvariablen die gleiche wie bei CLI.

### Schritt 1: Erstellen von config.json

Erstellen Sie die Konfigurationsdatei für Claude Code:

| System                | Pfad                                   |
| ----------------- | ------------------------------------ |
| **macOS / Linux** | `~/.claude/config.json`              |
| **Windows**       | `C:\Users\{Benutzername}\.claude\config.json` |

Schreiben Sie den folgenden Inhalt in diese Datei und speichern Sie sie:

```json
{
  "primaryApiKey": "self"
}
```

Schneller Befehl zum Erstellen unter macOS / Linux:

```bash
mkdir -p ~/.claude && echo '{"primaryApiKey": "self"}' > ~/.claude/config.json
```

### Schritt 2: Umgebungsvariablen konfigurieren

**Methode 1: In der Shell-Konfigurationsdatei festlegen (empfohlen)**

Fügen Sie den folgenden Inhalt zu Ihrer `~/.zshrc` oder `~/.bashrc` hinzu und ersetzen Sie `{token}` durch Ihr API-Token:

```bash
# AceData Cloud - Claude Code Proxy-Konfiguration
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Führen Sie nach der Änderung `source ~/.zshrc` aus, um die Konfiguration wirksam zu machen, und **starten Sie JetBrains IDE neu**.

**Methode 2: In der Claude Code settings.json festlegen**

Bearbeiten Sie `~/.claude/settings.json` (falls nicht vorhanden, erstellen Sie es):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Hinweis**: Das API-Token kann im [AceData Cloud-Dashboard](https://platform.acedata.cloud/console) eingesehen werden.

## Grundlegende Nutzung

### Starten aus dem integrierten Terminal der IDE

Öffnen Sie das integrierte Terminal von JetBrains IDE und führen Sie aus:

```bash
claude
```

Wenn Sie im integrierten Terminal der IDE ausführen, werden alle integrierten Funktionen (Diff-Ansicht, Kontextauswahl usw.) automatisch aktiviert.

### Verbindung über ein externes Terminal

Wenn Sie Claude Code in einem externen Terminal ausführen, können Sie den Befehl `/ide` verwenden, um sich mit JetBrains IDE zu verbinden:

```bash
claude
> /ide
```

Stellen Sie sicher, dass Sie Claude Code aus dem gleichen Pfad des Projektstammverzeichnisses starten, damit Claude auf dieselbe Gruppe von Dateien zugreifen kann.

### Tastenkombinationen

| Tastenkombination                                      | Funktion                      |
| ------------------------------------------------ | ----------------------- |
| `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux)        | Claude Code schnell öffnen        |
| `Cmd+Option+K` (Mac) / `Alt+Ctrl+K` (Windows/Linux) | Datei-Referenz einfügen (z. B. `@File#L1-99`) |

### Integrierte Funktionen

Das Claude Code JetBrains-Plugin bietet die folgenden integrierten Funktionen:

- **Diff-Ansicht**: Codeänderungen werden direkt im Diff-Viewer der IDE angezeigt
- **Kontextauswahl**: Der aktuell ausgewählte Code und die Registerkarte werden automatisch an Claude weitergegeben
- **Datei-Referenzen**: Verwenden Sie Tastenkombinationen, um schnell auf Dateien und Zeilennummern zu verweisen
- **Diagnosefreigabe**: Diagnosedaten wie Lint- und Syntaxfehler in der IDE werden automatisch an Claude weitergegeben

## Plugin-Einstellungen

In **Einstellungen** → **Tools** → **Claude Code [Beta]** können Sie konfigurieren:

| Einstellung                        | Beschreibung                                         |
| ----------------------------- | ------------------------------------------ |
| **Claude-Befehl**            | Benutzerdefinierter Pfad zum Claude-Befehl (z. B. `/usr/local/bin/claude`) |
| **Automatische Updates aktivieren**  | Automatisch nach Plugin-Updates suchen und installieren                                |
| **Verwendung von Option+Enter aktivieren** | Verwenden Sie Option+Enter unter macOS, um in Eingabefeldern Zeilenumbrüche zu machen             |

### WSL-Benutzereinstellungen

Wenn Sie in einer WSL-Umgebung arbeiten, müssen Sie den Claude-Befehl wie folgt festlegen:

```
wsl -d Ubuntu -- bash -lic "claude"
```

(Ersetzen Sie `Ubuntu` durch den Namen Ihrer WSL-Distribution)

## Häufige Fragen

### Was tun, wenn die Verbindung fehlschlägt?

1. Überprüfen Sie, ob die Datei `~/.claude/config.json` korrekt erstellt wurde
2. Stellen Sie sicher, dass die Umgebungsvariablen korrekt gesetzt sind
3. Überprüfen Sie, ob das API-Token gültig ist (kann im [Dashboard](https://platform.acedata.cloud/console) eingesehen werden)
4. Starten Sie JetBrains IDE neu und versuchen Sie es erneut

### Was tun, wenn das Plugin nicht funktioniert?

1. Stellen Sie sicher, dass Sie Claude Code aus dem Projektstammverzeichnis ausführen
2. Überprüfen Sie, ob das Plugin in den IDE-Einstellungen aktiviert ist
3. Starten Sie die IDE vollständig neu (möglicherweise sind mehrere Neustarts erforderlich)
4. Wenn Sie den Remote-Entwicklungsmodus verwenden, stellen Sie sicher, dass das Plugin auf dem Remote-Host installiert ist (Einstellungen → Plugin (Host))

### Was tun, wenn die IDE nicht erkannt wird?

1. Stellen Sie sicher, dass das Plugin installiert und aktiviert ist
2. Starten Sie die IDE neu
3. Stellen Sie sicher, dass Sie Claude Code im integrierten Terminal ausführen
4. WSL-Benutzer sollten die [WSL-Fehlerbehebungshinweise](https://code.claude.com/docs/en/troubleshooting#jetbrains-ide-not-detected-on-wsl2) beachten

### command not found

Wenn beim Klicken auf das Claude-Symbol "command not found" angezeigt wird:

1. Überprüfen Sie, ob CLI installiert ist: `which claude`
2. Konfigurieren Sie den vollständigen Pfad des Claude-Befehls in den Plugin-Einstellungen
3. WSL-Benutzer verwenden das oben genannte WSL-Befehlsformat
### Wie kann ich das verbleibende Guthaben einsehen?

Melden Sie sich bei der [AceData Cloud-Konsole](https://platform.acedata.cloud/console) an, um das aktuelle Guthaben und die Nutzung Ihres Kontos einzusehen.
