Claude Code ist ein von Anthropic entwickeltes **Agentic Coding**-Tool, das auch als einer der stärksten Programmier-Agenten der Welt bezeichnet wird. Die Terminal-CLI ist das zentrale Erlebnis von Claude Code, in dem du den Befehl `claude` in jedem Terminal ausführen kannst, um durch natürliche Sprache mit KI zusammenzuarbeiten.

Dieses Dokument beschreibt hauptsächlich, wie man Claude Code CLI über den Proxy-Service von AceData Cloud im Terminal installiert, konfiguriert und verwendet.

## Antragsprozess

Um Claude Code zu verwenden, kannst du zunächst auf die [Claude Messages-Dienstseite](https://platform.acedata.cloud/documents/claude-messages) gehen und auf die Schaltfläche „Acquire“ klicken, um die benötigten Anmeldeinformationen zu erhalten:

![](https://cdn.acedata.cloud/nyq0xz.png)

Wenn du noch nicht angemeldet oder registriert bist, wirst du automatisch zur Anmeldeseite weitergeleitet, um dich zu registrieren und anzumelden. Nach der Anmeldung wirst du automatisch zur aktuellen Seite zurückgeleitet.

Bei der ersten Anfrage gibt es ein kostenloses Kontingent, mit dem du den Claude Code-Dienst kostenlos ausprobieren kannst.

## Installation von Claude Code

### Systemanforderungen

- macOS, Linux oder Windows (einschließlich WSL)
- Node.js ist nicht erforderlich, die native Installationsmethode kümmert sich automatisch um die Abhängigkeiten

### Installationsmethoden

Claude Code unterstützt mehrere Installationsmethoden:

**Methode 1: Native Installation (empfohlen)**

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows CMD:

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**Methode 2: Homebrew (macOS / Linux)**

```bash
brew install claude-code
```

**Methode 3: WinGet (Windows)**

```cmd
winget install Claude.ClaudeCode
```

Die native Installation aktualisiert sich automatisch im Hintergrund und bleibt immer auf dem neuesten Stand.

## Konfiguration der AceData Cloud API

Nach der Installation wirst du standardmäßig aufgefordert, dich mit einem offiziellen Anthropic-Konto anzumelden. Wir können die Umgebungsvariablen konfigurieren, um die Proxy-API von AceData Cloud zu verwenden, **ohne offizielle Abonnements**.

### Konfiguration der Umgebungsvariablen

Es gibt zwei Möglichkeiten, die Umgebungsvariablen zu konfigurieren, wähle eine davon.

**Methode 1: In der Shell-Konfigurationsdatei festlegen (empfohlen)**

Füge den folgenden Inhalt zu deiner Shell-Konfigurationsdatei (`~/.zshrc`, `~/.bashrc` oder `~/.bash_profile`) hinzu und ersetze `{token}` durch das API-Token, das du im AceData Cloud-Dashboard erhalten hast:

```bash
# AceData Cloud - Claude Code Proxy-Konfiguration
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Führe nach der Änderung den folgenden Befehl aus, um die Konfiguration wirksam zu machen:

```bash
source ~/.zshrc  # oder source ~/.bashrc
```

**Methode 2: In der Claude Code settings.json festlegen**

Bearbeite `~/.claude/settings.json` (erstelle es, wenn es nicht existiert) und füge die `env`-Konfiguration hinzu:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Der Vorteil dieser Methode ist, dass die Umgebungsvariablen nur für Claude Code gelten und andere Programme nicht beeinflussen.

> **Hinweis**: Das API-Token kann im [AceData Cloud-Dashboard](https://platform.acedata.cloud/console) eingesehen werden. Der Wert von `ANTHROPIC_AUTH_TOKEN` wird automatisch mit dem Präfix `Bearer` an den Server gesendet.

## Erste Schritte

### Interaktiven Modus starten

Öffne das Terminal, gehe in dein Projektverzeichnis und führe dann aus:

```bash
cd /path/to/your/project
claude
```

Du wirst die Willkommensseite von Claude Code sehen, gib einfach natürliche Sprache ein, um die Interaktion zu beginnen.

### Häufig verwendete Befehle

| Befehl               | Beschreibung          | Beispiel                   |
| ---------------- | ------------------- | -------------------- |
| `claude`         | Interaktiven Modus starten      | `claude`             |
| `claude "Aufgabe"`    | Einmalige Aufgabe ausführen     | `claude "Baue Fehler beheben"`    |
| `claude -p "Abfrage"` | Abfrage ausführen und beenden     | `claude -p "Erkläre diese Funktion"` |
| `claude -c`      | Fortsetzen des letzten Gesprächs im aktuellen Verzeichnis | `claude -c`          |
| `claude -r`      | Vorheriges Gespräch wiederherstellen     | `claude -r`          |
| `claude commit`  | Git-Commit erstellen   | `claude commit`      |

### Interaktive Modusbefehle

Im interaktiven Modus kannst du die folgenden eingebauten Befehle verwenden:

| Befehl                | Funktion        |
| ----------------- | ------------- |
| `/help`           | Hilfe anzeigen    |
| `/clear`          | Gesprächsverlauf löschen    |
| `/config`         | Einstellungsfenster öffnen    |
| `/model`          | Modell wechseln      |
| `/mcp`            | MCP-Dienste verwalten |
| `/compact`        | Kontext komprimieren     |
| `/memory`         | Gedächtnis verwalten      |
| `/login`          | Konto wechseln      |
| `exit` oder `Ctrl+C` | Beenden        |

### Beispiel für Dialoginteraktion

```bash
# Projekt analysieren
> was macht dieses Projekt?

# Bug beheben
> es gibt einen Fehler, bei dem Benutzer leere Formulare einreichen können - behebe es

# Tests schreiben
> schreibe Unit-Tests für die Taschenrechnerfunktionen

# Code umstrukturieren
> strukturiere das Authentifizierungsmodul um, um async/await zu verwenden

# Git-Operationen
> commit meine Änderungen mit einer beschreibenden Nachricht
> erstelle einen PR für dieses Feature
```

## Erweiterte Nutzung

### Pipes und Skripting

Claude Code folgt der Unix-Philosophie und unterstützt Pipe- und Skriptoperationen:

```bash
# Protokolle überwachen und automatisch alarmieren
tail -f app.log | claude -p "Wenn eine Ausnahme gefunden wird, benachrichtige mich"

# Neue Texte automatisch übersetzen
claude -p "Wenn neue Textzeichenfolgen vorhanden sind, übersetze sie ins Französische und erstelle einen PR"

# Code-Überprüfung
git diff main | claude -p "Überprüfe diese Änderungen"
```

### Umgebungsvariablen Referenz

Hier sind die gängigen Umgebungsvariablen, die von Claude Code unterstützt werden:

| Variable                           | Beschreibung                                    |
| ---------------------------- | ------------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`       | Wert des benutzerdefinierten Authorization-Headers (automatisch mit Bearer-Präfix hinzugefügt) |
| `ANTHROPIC_API_KEY`          | API-Schlüssel (als X-Api-Key-Header gesendet)              |
| `ANTHROPIC_BASE_URL`         | Basis-URL der API                            |
| `ANTHROPIC_MODEL`            | Standardmodell überschreiben                                |
| `ANTHROPIC_SMALL_FAST_MODEL` | Haiku-Level-Modell (für Hintergrundaufgaben)                     |
| `MAX_THINKING_TOKENS`        | Budget für Denk-Token festlegen (auf 0 setzen, um den Denkmodus zu deaktivieren)            |
| `DISABLE_COST_WARNINGS`      | Auf 1 setzen, um Kostenwarnungen zu deaktivieren                           |

### CLAUDE.md Projektgedächtnis

Erstelle eine `CLAUDE.md`-Datei im Stammverzeichnis des Projekts, um Claude Code spezifische Anweisungen und Kontexte für das Projekt bereitzustellen. Claude lädt diese Datei beim Start automatisch.

```markdown
# Projektbeschreibung
Dies ist ein Full-Stack-Projekt mit Django + Vue.js.

## Codierungsrichtlinien
- Verwende Python 3.12
- Befolge den PEP 8-Code-Stil
- Alle APIs müssen Unit-Tests haben
```

## Häufig gestellte Fragen

### Was tun, wenn die Verbindung fehlschlägt?
1. Überprüfen Sie, ob die Datei `~/.claude/config.json` korrekt erstellt wurde, der Inhalt ist `{"primaryApiKey": "self"}`
2. Bestätigen Sie, dass die Umgebungsvariablen korrekt gesetzt sind:
   ```bash
   echo $ANTHROPIC_AUTH_TOKEN
   echo $ANTHROPIC_BASE_URL
   ```
3. Bestätigen Sie, dass der API-Token gültig ist (kann in der [Konsole](https://platform.acedata.cloud/console) eingesehen werden)
4. Versuchen Sie, das Terminal neu zu starten

### Befehl nicht gefunden: claude

Wenn nach der Installation `command not found` angezeigt wird, versuchen Sie:

1. Schließen Sie das Terminal und öffnen Sie es erneut
2. Überprüfen Sie den PATH: `echo $PATH`
3. Neuinstallation: `curl -fsSL https://claude.ai/install.sh | bash`

### Wie kann ich das verbleibende Guthaben einsehen?

Melden Sie sich bei der [AceData Cloud Konsole](https://platform.acedata.cloud/console) an, um das aktuelle Guthaben und die Nutzung Ihres Kontos einzusehen.
