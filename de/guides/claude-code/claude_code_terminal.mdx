## 1. API-Schlüssel erhalten

Öffnen Sie die [Ace Data Cloud Anwendungsübersicht](https://platform.acedata.cloud/console/applications), gehen Sie zu den verfügbaren Anwendungen und kopieren Sie den API-Schlüssel.

![API-Schlüssel von Ace Data Cloud erhalten](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Claude Code installieren

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
```

Überprüfen Sie nach der Installation:

```bash
claude --version
```

## 3. Ace Data Cloud konfigurieren

Für die globale Nutzung fügen Sie die folgenden Variablen zu `~/.zshrc` oder `~/.bashrc` hinzu:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="Ihr API-Schlüssel"
unset ANTHROPIC_API_KEY
```

Öffnen Sie das Terminal erneut oder verwenden Sie `source` für die entsprechende Konfigurationsdatei.

Wenn es nur für das aktuelle Projekt gelten soll, können Sie eine `.claude/settings.local.json` erstellen, die in `.gitignore` aufgenommen wurde:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "Ihr API-Schlüssel"
  }
}
```

Wählen Sie eine der beiden Methoden. Schreiben Sie den echten Schlüssel nicht in die teamgeteilte `.claude/settings.json`; wenn die Umgebung bereits `ANTHROPIC_API_KEY` hat, sollte dieser wirklich entfernt werden, nicht auf einen leeren String gesetzt werden.

## 4. Starten und überprüfen

```bash
cd /path/to/your/project
claude
```

Senden Sie nach dem Betreten eine schreibgeschützte Aufgabe, wie „Lesen Sie README.md und fassen Sie es in einem Satz zusammen“. Die Aufrufprotokolle und das Guthaben können in der [Nutzungshistorie](https://platform.acedata.cloud/console/usages) und der [Anwendungsübersicht](https://platform.acedata.cloud/console/applications) eingesehen werden.

Wenn 401 zurückgegeben wird, überprüfen Sie, ob der Schlüssel vollständig ist, ob der alte `ANTHROPIC_API_KEY` entfernt wurde und starten Sie Claude Code vollständig neu. Das Modell muss nicht in der Konfiguration festgelegt werden, es kann im Claude Code das aktuell verfügbare Modell ausgewählt werden.
