## 1. API-Schlüssel abrufen

Öffnen Sie die [Ace Data Cloud Anwendungsübersicht](https://platform.acedata.cloud/console/applications), gehen Sie zu den verfügbaren Anwendungen und kopieren Sie den API-Schlüssel.

![API-Schlüssel von Ace Data Cloud abrufen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. CC Switch installieren

Laden Sie von [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest) herunter, macOS kann ebenfalls ausgeführt werden:

```bash
brew install --cask cc-switch
```

## 3. Provider hinzufügen

Öffnen Sie CC Switch, wählen Sie **Claude Code → Provider hinzufügen → Benutzerdefiniert**, füllen Sie aus:

| Feld        | Wert                           |
| ----------- | ----------------------------- |
| Name        | `Ace Data Cloud`              |
| Basis-URL   | `https://api.acedata.cloud`   |
| API-Schlüssel | Gerade kopierter API-Schlüssel |
| API-Format  | `Anthropic Messages`          |

Wenn Sie den JSON-Editor verwenden möchten, konfigurieren Sie ihn wie folgt:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

CC Switch wird die Konfiguration in die Benutzereinstellungen von Claude Code schreiben. Speichern Sie den echten Schlüssel nicht im Team-Repository und behalten Sie nicht gleichzeitig den alten `ANTHROPIC_API_KEY`.

## 4. Aktivieren und überprüfen

Aktivieren Sie nach dem Speichern **Ace Data Cloud** und starten Sie Claude Code neu. Senden Sie eine einfache schreibgeschützte Aufgabe und überprüfen Sie den Aufruf in der [Nutzungsverlauf](https://platform.acedata.cloud/console/usages). Wenn nach dem Wechsel weiterhin die alte Konfiguration verwendet wird, versuchen Sie es erneut, nachdem Sie Claude Code und CC Switch vollständig beendet haben.
