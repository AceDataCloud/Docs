Claude Code integriert sich über das Anthropic Messages-Protokoll in den Coding Plan und bietet derzeit zwei Konfigurationszugänge: Terminal und VS Code.

| Nutzungseingang     | Konfigurationsanleitung                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------------------------- |
| Terminal / CLI     | [Claude Code Terminal-Konfiguration](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code            | [Claude Code für VS Code Konfiguration](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## Gemeinsame Konfiguration

- Basis-URL: `https://api.acedata.cloud`
- API-Token: Von der Coding-Anwendung erhalten und über die Anleitung mit `ANTHROPIC_AUTH_TOKEN` konfigurieren
- Modell-ID: Aus dem Echtzeit-Modellverzeichnis auswählen
- Nach der Änderung der Konfiguration: Claude Code neu starten; VS Code-Nutzer müssen das Fenster neu laden

Bewahren Sie nicht gleichzeitig den alten `ANTHROPIC_API_KEY` auf und schreiben Sie auch kein echtes Token in teamgeteilte Dateien.

Zurück zum [Coding Plan Konfigurationszentrum](https://platform.acedata.cloud/documents/coding-plan-integration).
