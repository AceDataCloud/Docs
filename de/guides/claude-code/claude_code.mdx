Claude Code ist der von Anthropic entwickelte Programmier-Intelligent, das in verschiedenen Umgebungen wie Terminal, IDE, Desktop-Anwendungen usw. verwendet werden kann. Über den AceData Cloud Proxy können Sie Claude Code zu einem günstigeren Preis nutzen.

> **Erstmaliger Zugriff?** Es wird empfohlen, zuerst den [Claude Code 5-Minuten Schnellstart](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) anzusehen — vom Erhalt des Tokens bis zum erfolgreichen Ausführen des ersten Befehls in fünf Schritten.

Wählen Sie die vollständige Konfigurationsanleitung für die jeweilige Plattform entsprechend Ihres Anwendungsfalls:

| Plattform | Beschreibung | Anleitung Link |
|------------|--------------|----------------|
| **⚡ 5 Minuten Schnellstart** | Vom Token-Erhalt bis zum ersten `claude` Befehl, in fünf Schritten | [5-Minuten-Anleitung](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) |
| **Terminal (CLI)** | Kern-Erfahrung, starten Sie einfach `claude` in jedem Terminal | [Terminal-Konfigurationsanleitung](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code** | Native Erweiterung, unterstützt Inline-Diff, @-Mentions, Planüberprüfung | [VS Code Konfigurationsanleitung](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | VS Code kompatibler Editor, voll unterstützte Claude Code Erweiterung | [Cursor Konfigurationsanleitung](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **JetBrains IDE** | Unterstützt IntelliJ IDEA, PyCharm, WebStorm und andere IDEs | [JetBrains Konfigurationsanleitung](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automatisierte Code-Reviews und Issue-Verarbeitung mit `@claude` | [GitHub Actions Konfigurationsanleitung](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |
| **Desktop-Anwendung (Vorschau)** | Eigenständiger grafischer Client, unterstützt parallele Sitzungen, Verbindung zu externen Tools | [Desktop-Anwendung Konfigurationsanleitung](https://platform.acedata.cloud/documents/claude-code-desktop-integration) |

> **Hinweis**: Für den ersten Antrag können Sie auf der [Claude Messages Service-Seite](https://platform.acedata.cloud/documents/claude-messages) auf „Acquire“ klicken, um das Token zu erhalten, das kostenlose Guthaben beinhaltet.
