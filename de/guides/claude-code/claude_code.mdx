---

Claude Code ist ein von Anthropic eingeführter Programmieragent, der in verschiedenen Umgebungen wie Terminal, IDE, Desktop-Anwendungen usw. verwendet werden kann. Über den AceData Cloud Proxy kannst du Claude Code zu einem günstigeren Preis nutzen.

Bitte wähle je nach deinem Nutzungsszenario das entsprechende Konfigurationstutorial für die Plattform aus:

| Plattform            | Beschreibung                                 | Tutorial-Link                                                                                              |
| ------------------- | ------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Terminal (CLI)**   | Kern-Erlebnis, einfach `claude` in jedem Terminal ausführen, um zu beginnen | [Terminal Konfiguration Tutorial](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code**         | Native Erweiterung, unterstützt Inline-Diff, @-Erwähnungen, geplante Überprüfungen | [VS Code Konfiguration Tutorial](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)  |
| **JetBrains IDE**   | Unterstützt IntelliJ IDEA, PyCharm, WebStorm und alle IDEs | [JetBrains Konfiguration Tutorial](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions**  | Automatisiere Code-Überprüfungen und Issue-Behandlungen mit `@claude` | [GitHub Actions Konfiguration Tutorial](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Hinweis**: Bei der ersten Anfrage kannst du zur [Claude Messages Service-Seite](https://platform.acedata.cloud/documents/claude-messages) gehen und auf „Acquire“ klicken, um ein Zertifikat zu erhalten, das dir ein kostenloses Kontingent gewährt.
