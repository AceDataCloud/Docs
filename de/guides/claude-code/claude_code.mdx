---
title: "Claude Code Konfiguration Anleitung"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code ist der von Anthropic entwickelte Programmier-Intelligent, das in verschiedenen Umgebungen wie Terminal, IDE und CI/CD-Pipelines verwendet werden kann. Durch den AceData Cloud Proxy können Sie Claude Code zu einem günstigeren Preis nutzen.

Wählen Sie die vollständige Konfigurationsanleitung entsprechend Ihrer Anwendungsumgebung:

| Plattform | Beschreibung | Anleitung Link |
|------------|--------------|----------------|
| **VS Code** | Native Erweiterung, unterstützt Inline Diff, @-Mentions, Planüberprüfung | [VS Code Konfigurationsanleitung](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | Kompatibler Editor zu VS Code, vollständige Unterstützung für Claude Code Erweiterung | [Cursor Konfigurationsanleitung](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **Terminal (CLI)** | Kernerfahrung, starten Sie einfach `claude` in jedem Terminal | [Terminal Konfigurationsanleitung](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **JetBrains IDE** | Unterstützt IntelliJ IDEA, PyCharm, WebStorm und andere JetBrains IDEs | [JetBrains Konfigurationsanleitung](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automatisierte Code-Überprüfung und Issue-Verwaltung mit `@claude` | [GitHub Actions Konfigurationsanleitung](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Hinweis**: Für die erste Beantragung können Sie auf der [Claude Messages Service-Seite](https://platform.acedata.cloud/documents/claude-messages) auf „Acquire“ klicken, um die Zugangsdaten zu erhalten, was ein kostenloses Kontingent beinhaltet.
