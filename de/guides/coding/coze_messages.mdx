Die offizielle Dokumentation für benutzerdefinierte Modelle von Coze unterstützt die Anthropic Messages API. Verschiedene Coze-Mietversionen können Header, Pfadverkettung, Streaming und Toolaufrufe unterschiedlich behandeln. Bitte überprüfen Sie bei der ersten Anbindung jeden Punkt wie unten beschrieben.

## Konfiguration

1. Gehen Sie zu Coze Modellverwaltung und fügen Sie ein benutzerdefiniertes Modell hinzu.
2. Wählen Sie als Protokoll die Anthropic Messages API.
3. Geben Sie die Basis-API-URL als `https://api.acedata.cloud` ein.
4. Geben Sie den API-Schlüssel als Ihr Ace Data Cloud API-Token ein.
5. Geben Sie das Modell in der Modellverzeichnis, das die Anthropic Messages unterstützt, mit der genauen Modell-ID ein.
6. Speichern Sie und führen Sie den Verbindungstest von Coze durch.
7. Senden Sie im Bot/Agent `Reply only OK` und testen Sie den Toolaufruf erneut.

## Aktuelle Grenzen

- Verschiedene Coze-Regionen, Versionen oder Pakete können unterschiedliche Formulare anzeigen.
- Die Basis-API-URL sollte nicht wiederholt `/v1/messages` hinzufügen; wenn die aktuelle UI eine vollständige API-URL ausdrücklich verlangt, ist die Formulartipp zu beachten.
- Messages, Chat Completions und Responses sind drei unabhängige Routen und können nicht gegenseitig zur Validierung ersetzt werden.
