## 1. API Key abrufen

Öffnen Sie die [Ace Data Cloud Anwendungsliste](https://platform.acedata.cloud/console/applications), rufen Sie eine verfügbare Anwendung auf und kopieren Sie den API Key.

![Ace Data Cloud API Key abrufen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Konfiguration

Roo Code bietet offiziell einen OpenAI-kompatiblen Provider und erfordert, dass das Modell natives OpenAI tools/function calling unterstützt.

1. Öffnen Sie die Roo Code-Einstellungen in VS Code.
2. Setzen Sie **API Provider** auf **OpenAI Compatible**.
3. Füllen Sie Folgendes aus:

| Feld       | Wert                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | Der gerade kopierte API Key                  |
| Model ID | Die in der Coding-Konfigurationsanleitung ausgewählte Modell-ID         |

![Roo Code OpenAI Compatible Konfigurationsoberfläche](https://cdn.acedata.cloud/b6a0e7156438.png)

Legen Sie anschließend context, max output sowie die Bild- und computer-use-Optionen entsprechend den tatsächlichen Fähigkeiten des Modells fest. Speichern Sie die Konfiguration abschließend und laden Sie VS Code neu.

## 3. Überprüfung

Senden Sie zuerst `Reply only OK` und lassen Sie Roo Code anschließend eine Testdatei lesen. Falls der normale Chat erfolgreich ist, aber die Agent-Tools fehlschlagen, wechseln Sie zu einem Modell, das natives tool calling unterstützt, und stellen Sie sicher, dass der kompatible Endpunkt Tool-Parameter und Ergebnisse korrekt per Streaming zurückgeben kann.
