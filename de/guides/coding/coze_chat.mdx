Die offizielle Coze-Dokumentation für benutzerdefinierte Modelle unterstützt die OpenAI Chat API. Verschiedene Coze-Mietversionen können die Handhabung von Pfadverkettung, Streaming-Ausgaben und Toolaufrufen unterschiedlich handhaben. Bitte überprüfen Sie bei der ersten Anbindung die folgenden Punkte.

## Konfiguration

1. Gehen Sie zu Coze Modellverwaltung und fügen Sie ein benutzerdefiniertes Modell hinzu.
2. Wählen Sie als Protokoll die OpenAI Chat API.
3. Geben Sie die Basis-API-URL als `https://api.acedata.cloud/v1` ein.
4. Geben Sie den API-Schlüssel als Ihr Ace Data Cloud API-Token ein.
5. Geben Sie das Modellverzeichnis mit der genauen Modell-ID ein, die Chat Completions unterstützt.
6. Speichern Sie und führen Sie den Verbindungstest mit Coze durch.
7. Senden Sie im Bot/Agent `Reply only OK` und testen Sie den Toolaufruf erneut.

## Aktuelle Grenzen

- Verschiedene Coze-Regionen, Versionen oder Pakete können unterschiedliche Formulare anzeigen.
- Die Basis-API-URL sollte die Basis verwenden, fügen Sie nicht erneut `/chat/completions` hinzu; wenn die aktuelle UI ausdrücklich die vollständige API-URL verlangt, orientieren Sie sich an den Formulartipps.
- Chat Completions, Responses und Anthropic Messages sind drei unabhängige Routen und können nicht gegenseitig zur Validierung verwendet werden.
