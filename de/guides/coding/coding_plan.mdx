## Dynamischer Modellkatalog

Sie können zuerst den [Modellkatalog](https://platform.acedata.cloud/models) öffnen, um die aktuellen Modellnamen anzuzeigen, beispielsweise `claude-opus-5`, `gpt-6-sol`. Wenn bestätigt werden muss, ob die Coding-Anmeldedaten und das API-Protokoll übereinstimmen, verwenden Sie gültige Coding-Application-Anmeldedaten für die Anfrage:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

Der Modellkatalog ändert sich fortlaufend; in diesem Dokument wird keine feste Anzahl oder statische Modellliste gepflegt. Die `id` jedes Eintrags in der Antwort ist der **Modellname**, der direkt an den API-Parameter `model` übergeben werden kann, beispielsweise entspricht `{"id":"deepseek-v4-pro"}` der Eingabe von `deepseek-v4-pro`; sie ist nicht die UUID eines Dienstes, einer API oder einer Application. `/v1/models` gibt den globalen Modellkatalog zurück und wird nicht automatisch anhand der Coding-Anmeldedaten gefiltert; vor der Konfiguration muss weiterhin die Übereinstimmung mit dem API-Scope der Anmeldedaten, dem ausgewählten Protokoll und dem Kompatibilitätsumfang des Clients überprüft werden.

## Häufige Fehlerbehebung

- **Unzureichendes Guthaben**: Rufen Sie die [Applications-Konsole](https://platform.acedata.cloud/console/applications) auf, suchen Sie die Coding Application und erwerben Sie aktiv eine Verlängerung.
- **Client fordert weiterhin die ursprüngliche Adresse an**: Bestätigen Sie, dass die Konfiguration zu demselben Benutzer und Arbeitsbereich gehört, der den Client gestartet hat, und starten Sie den Client nach dem vollständigen Beenden erneut.
- **Modellname nicht verfügbar**: Fragen Sie `/v1/models` erneut ab und prüfen Sie, ob der eingegebene Modellname genau mit der `id` im Katalog übereinstimmt, sowie den API-Scope der Anmeldedaten und das vom Client unterstützte Protokoll.
- **Token kann die Schnittstelle nicht aufrufen**: Bestätigen Sie, dass die Anmeldedaten zu einer Coding Application gehören, und überprüfen Sie `allowed_api_ids` und die API-Berechtigungen der Anwendung.
