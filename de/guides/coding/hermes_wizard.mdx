## 1. API Key abrufen

Öffnen Sie die [Ace Data Cloud-Anwendungsliste](https://platform.acedata.cloud/console/applications), rufen Sie eine verfügbare Anwendung auf und kopieren Sie den API Key.

![Ace Data Cloud API Key abrufen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Assistenten ausführen

```bash
hermes model
```

Wählen Sie **Custom endpoint** und füllen Sie nacheinander aus:

| Feld             | Wert                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | Der gerade kopierte API Key                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | Gehen Sie zum [Modellverzeichnis](https://platform.acedata.cloud/models), um es anzuzeigen, und tragen Sie den Namen des Zielmodells unverändert ein, zum Beispiel `claude-opus-5`, `gpt-6-sol` |
| Context length | Für automatische Erkennung leer lassen oder gemäß Modellverzeichnis ausfüllen                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model` ist der Modellname, der für den Parameter `model` in der API-Anfrage verwendet wird, und nicht die UUID des Dienstes oder der API. Sie können ihn zuerst im [Modellverzeichnis](https://platform.acedata.cloud/models) einsehen; falls eine genaue Überprüfung erforderlich ist, verwenden Sie anschließend den aktuellen API Key, um `GET https://api.acedata.cloud/v1/models` anzufordern, und kopieren Sie den `id`-Wert des Zielmodells aus dem `data`-Array der Antwort.

Der Assistent schreibt in `~/.hermes/config.yaml` und in die lokale Anmeldedatei.

## 3. Überprüfung

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

Falls der Assistent die Konfiguration nicht gespeichert hat, können Sie `hermes model --reset` ausführen und es erneut versuchen; 401 bedeutet, dass der API Key ungültig ist oder nicht von der Konfiguration des aktuellen Benutzers gelesen wird.
