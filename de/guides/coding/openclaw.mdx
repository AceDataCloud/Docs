## 1. API-Schlüssel erhalten

Öffnen Sie die [Ace Data Cloud Anwendungsübersicht](https://platform.acedata.cloud/console/applications), gehen Sie zu den verfügbaren Anwendungen und kopieren Sie den API-Schlüssel.

![API-Schlüssel von Ace Data Cloud erhalten](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. OpenClaw und Plugin installieren

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

Das Plugin erfordert OpenClaw `2026.4.2` oder höher, derzeit bietet es nativ Chat- und Web-Suchfähigkeiten.

## 3. Schlüssel konfigurieren

Es wird empfohlen, das Onboarding zu verwenden:

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "Ihr API-Schlüssel"
```

Es kann auch eine Umgebungsvariable verwendet werden:

```bash
export ACEDATACLOUD_API_KEY="Ihr API-Schlüssel"
```

## 4. Optional: Manuelle Konfiguration

Wenn Sie das Onboarding nicht verwenden, aktivieren Sie das Plugin in `~/.openclaw/openclaw.json` und setzen Sie das Standardmodell:

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

Schreiben Sie den API-Schlüssel nicht in diese Datei; verwenden Sie weiterhin Umgebungsvariablen.

## 5. Modell auswählen und überprüfen

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "Antworten Sie nur mit OK"
```

Ersetzen Sie `MODEL_ID` durch das derzeit von Coding Plan bereitgestellte Modell. Wenn es als Standardmodell festgelegt werden soll, führen Sie Folgendes aus:

```bash
openclaw models set acedatacloud/MODEL_ID
```

Die Aufrufprotokolle können unter [Nutzungsverlauf](https://platform.acedata.cloud/console/usages) eingesehen werden. 401 bedeutet, dass der Schlüssel ungültig ist; wenn das Modell nicht existiert, überprüfen Sie zuerst die exakte ID und die Plugin-Version. `cost: 0` im Plugin-Verzeichnis bedeutet nur, dass keine wiederholte Schätzung durch OpenClaw erfolgt, die tatsächlichen Kosten werden weiterhin von Ace Data Cloud erfasst.

## Web-Suche

```bash
openclaw infer web search \
  --provider acedatacloud --query "neueste AI-Agenten-Frameworks" --limit 5
```

Aktuell sollten die in der Plugin-Einführung genannten Bild-, Video- oder Musikfähigkeiten nicht als native Provider-Fähigkeiten von OpenClaw betrachtet werden.
