Continue unterstützt die OpenAI-kompatible API. Um sicherzustellen, dass die Chat Completions verwendet werden, muss `useResponsesApi: false` explizit festgelegt werden.

## Konfiguration

Fügen Sie in der lokalen YAML-Konfiguration von Continue Folgendes hinzu:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Speichern Sie `ACEDATACLOUD_API_KEY` in der Geheimnisverwaltung von Continue und geben Sie das echte Token nicht in der Projektkonfiguration an. Die JSON-Konfiguration von Continue ist veraltet, die neue Konfiguration verwendet YAML.

## Überprüfung

Laden Sie VS Code neu, öffnen Sie die Continue-Seitenleiste, wählen Sie das Modell in der lokalen Konfiguration aus und senden Sie `Reply only OK`; führen Sie dann erneut die schreibgeschützte Dateiaufgabe aus. Wenn die Anfrage fälschlicherweise an `/responses` gesendet wird, überprüfen Sie, ob `useResponsesApi: false` innerhalb des Modell-Eintrags steht.
