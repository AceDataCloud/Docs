Qwen Code verwendet die `modelProviders` Konfiguration in `~/.qwen/settings.json` für benutzerdefinierte Provider. Hier wird das OpenAI-kompatible Protokoll festgelegt.

## Konfiguration

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud` muss ein Array sein. Die Provider-Einträge sind unabhängig konfiguriert und erben keine anderen übergeordneten Kontext-, Header- oder Body-Parameter automatisch.

## Überprüfung

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Reply only OK"
```

Senden Sie nach dem Betreten `Reply only OK` und führen Sie dann das schreibgeschützte Dateitool erneut aus. Wenn der streng kompatible Endpunkt das Format der Toolergebnisse ablehnt, überprüfen Sie die aktuelle Qwen Code-Version und die offiziellen Kompatibilitätsinformationen.
