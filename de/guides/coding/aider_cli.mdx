Aider verbindet sich über das `openai/` Modellpräfix von LiteLLM mit der OpenAI-kompatiblen API.

## Konfiguration

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

Ersetzen Sie `MODEL_ID` durch das Modell, das Sie im Coding-Konfigurationsassistenten ausgewählt haben. Sie können die entsprechenden Optionen auch in die lokale `.env` oder `.aider.conf.yml` schreiben, aber geben Sie kein echtes Token ein.

## Überprüfung

```bash
aider --model openai/MODEL_ID --message "Antworten Sie nur mit OK"
```

Bei der ersten Verwendung eines unbekannten Modells kann Aider darauf hinweisen, dass Metadaten des Modells fehlen; dies ist nicht gleichbedeutend mit einem Authentifizierungsfehler. 401 überprüft das Token, 404 überprüft die Modell-ID und die `/v1` Basis-URL.
