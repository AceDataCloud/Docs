## 1. API Key erhalten

Öffne die [Ace Data Cloud Anwendungsliste](https://platform.acedata.cloud/console/applications), gehe zu einer verfügbaren Anwendung und kopiere den API Key.

![Ace Data Cloud API Key erhalten](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Kimi Code installieren

macOS / Linux:

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

Kann auch über npm installiert werden:

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. AceDataCloud konfigurieren

Bearbeite `~/.kimi/config.toml` und füge die folgende Konfiguration hinzu:

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "dein API Key"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

Gehe zum [Modellverzeichnis](https://platform.acedata.cloud/models), um die Modellnamen anzuzeigen (zum Beispiel `claude-opus-5`, `gpt-6-sol`), und ersetze alle `MODEL_ID` durch denselben Namen; bei genauer Überprüfung gilt der `id`-Wert in der Antwort von `/v1/models`. Dieser Wert ist der Modellname, der vom API-Parameter `model` verwendet wird, und nicht die UUID des Dienstes oder der API. `type = "openai"` verwendet das OpenAI-Chat-Completions-Protokoll.

Die Konfigurationsdatei enthält den Key, unter macOS / Linux wird empfohlen, die Berechtigungen einzuschränken:

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. Überprüfen und starten

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

Führe nach dem Betreten des Projekts `kimi` aus, um die Verwendung zu starten. Wenn 401 zurückgegeben wird, überprüfe den API Key; wenn model not found angezeigt wird, bestätige, dass `default_model`, der Name in der Modelltabelle und das Feld `model` dieselbe ID verwenden.
