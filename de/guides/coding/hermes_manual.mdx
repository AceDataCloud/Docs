## 1. API Key abrufen

Öffnen Sie die [Ace Data Cloud Anwendungsliste](https://platform.acedata.cloud/console/applications), gehen Sie zu einer verfügbaren Anwendung und kopieren Sie den API Key.

![Ace Data Cloud API Key abrufen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Key speichern

Schreiben Sie in `~/.hermes/.env`:

```dotenv
ACEDATACLOUD_API_KEY=Ihr API Key
```

## 3. Provider konfigurieren

Fügen Sie in `~/.hermes/config.yaml` Folgendes hinzu:

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

Gehen Sie zum [Modellkatalog](https://platform.acedata.cloud/models), um die Modellnamen anzuzeigen (z. B. `claude-opus-5`, `gpt-6-sol`), und ersetzen Sie alle `MODEL_ID` durch denselben Namen; bei einer genauen Prüfung ist der `id`-Wert in der Antwort von `/v1/models` maßgeblich. Dieser Wert ist der Modellname, der vom API-Parameter `model` verwendet wird, und nicht die UUID des Dienstes oder der API. Schreiben Sie keinen echten Key in YAML und übermitteln Sie keine `.env`.

## 4. Überprüfung

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

Wenn 401 zurückgegeben wird, überprüfen Sie `~/.hermes/.env`; wenn die Konfiguration nicht wirksam wird, beenden Sie Hermes vollständig und starten Sie es neu.
