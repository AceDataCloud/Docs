Das Continue JetBrains-Plugin verwendet dasselbe YAML-Modellformat wie VS Code; Konfiguration und Geheimnisse müssen dem Benutzer gehören, der das JetBrains-Plugin ausführt.

## Konfiguration

Fügen Sie in der lokalen YAML-Konfiguration von Continue Folgendes hinzu:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Speichern Sie `ACEDATACLOUD_API_KEY` in den Continue-Geheimnissen. Im Remote-Entwicklungsszenario muss die Konfiguration auf dem Host erfolgen, auf dem das Plugin tatsächlich ausgeführt wird.

## Überprüfung

Starten Sie die JetBrains IDE neu, öffnen Sie das Continue-Toolfenster, wählen Sie das Local Config-Modell aus und senden Sie `Reply only OK`; führen Sie dann erneut die schreibgeschützte Dateiaufgabe aus. Wenn weiterhin das alte Modell verwendet wird, starten Sie das Remote-Backend neu und überprüfen Sie die YAML-Einrückung.
