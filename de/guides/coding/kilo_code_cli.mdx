## 1. API-Schlüssel abrufen

Öffnen Sie die [Ace Data Cloud Anwendungsübersicht](https://platform.acedata.cloud/console/applications), gehen Sie zu den verfügbaren Anwendungen und kopieren Sie den API-Schlüssel.

![Ace Data Cloud API-Schlüssel abrufen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Konfiguration

Kilo CLI liest `kilo.jsonc` und liest den API-Schlüssel aus der Shell, in der die CLI gestartet wird.

Schreiben Sie in `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Exportieren Sie dann das Token in der aktuellen Shell:

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
```

## 3. Überprüfung

```bash
kilo run -m acedatacloud/MODEL_ID "Antworten Sie nur mit OK"
```

Wenn die CLI das Token nicht lesen kann, stellen Sie sicher, dass die Variable `export` wurde und nicht nur in eine nicht geladene `.env`-Datei geschrieben wurde.
