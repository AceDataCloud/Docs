## 1. API Key erhalten

Öffnen Sie die [Ace Data Cloud Anwendungsliste](https://platform.acedata.cloud/console/applications), rufen Sie eine verfügbare Anwendung auf und kopieren Sie den API Key.

![Ace Data Cloud API Key erhalten](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Custom provider hinzufügen

Öffnen Sie in Kilo Code **Settings → Providers**, klicken Sie auf **Custom provider** und füllen Sie dann aus:

| Feld           | Wert                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------- |
| Provider ID  | `acedatacloud`                                                                                 |
| Display name | `AceDataCloud`                                                                                 |
| Provider API | `OpenAI Compatible`                                                                            |
| Base URL     | `https://api.acedata.cloud/v1`                                                                 |
| API key      | Der gerade kopierte API Key                                                                     |
| Models       | Rufen Sie den [Modellkatalog](https://platform.acedata.cloud/models) auf, um die Modellnamen anzuzeigen, und fügen Sie die zu verwendenden Modellnamen hinzu, zum Beispiel `claude-opus-5`, `gpt-6-sol` |

![Kilo Code Custom provider Konfigurationsoberfläche](https://cdn.acedata.cloud/94eb5abd7a6f.png)

Die `id` des Modells hier ist der Modellname, der vom Parameter `model` in API-Anfragen verwendet wird, und nicht die UUID des Dienstes oder der API. Sie können ihn zunächst im [Modellkatalog](https://platform.acedata.cloud/models) einsehen; bei genauer Prüfung kopieren Sie ihn bitte unverändert aus dem Array `data` der Antwort von `/v1/models`, und raten oder kürzen Sie ihn nicht selbst.

Klicken Sie auf **Submit**, und das Modell wird im Selektor angezeigt. Wenn Teamfreigabe oder detailliertere Konfigurationen erforderlich sind, können Sie auch gemäß der offiziellen Dokumentation die benutzerbezogene `~/.config/kilo/kilo.jsonc` oder die projektbezogene `./kilo.jsonc` bearbeiten.

## 3. Überprüfung

Wählen Sie `acedatacloud/MODEL_ID` und senden Sie `Reply only OK`, und führen Sie dann einmal eine schreibgeschützte Dateioperation aus. Wenn das Modell nicht angezeigt wird, prüfen Sie, ob der Provider übermittelt wurde, ob der Modellname vollständig mit der `id` im Katalog übereinstimmt und ob die Base URL korrekt ist.
