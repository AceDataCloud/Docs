## 1. API-Schlüssel abrufen

Öffnen Sie die [Ace Data Cloud Anwendungsübersicht](https://platform.acedata.cloud/console/applications), gehen Sie zu den verfügbaren Anwendungen und kopieren Sie den API-Schlüssel.

![Ace Data Cloud API-Schlüssel abrufen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Provider konfigurieren

Das JetBrains-Plugin von Kilo Code verwendet das `kilo.jsonc` Provider-Format. Die Konfiguration muss sich in der tatsächlichen Benutzerumgebung befinden, in der das Plugin ausgeführt wird; bei Remote Development ist dies normalerweise der Remote-Backend-Host.

Schreiben Sie in `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Exportieren Sie `ACEDATACLOUD_API_KEY` in der Umgebung, in der der JetBrains-Backend gestartet wird, und starten Sie dann die IDE oder den Remote-Backend neu.

## 3. Überprüfung

Wählen Sie `acedatacloud/MODEL_ID`, senden Sie `Reply only OK` und lassen Sie den Agenten eine Testdatei lesen. Wenn es lokal funktioniert, aber remote fehlschlägt, überprüfen Sie zuerst, ob die Konfigurationsdatei und die Umgebungsvariablen auf dem Remote-Host korrekt geschrieben sind.
