---
title: "Tripo 3D-Generierung"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Rufe `POST /tripo/generations` auf, um ein neues Modell zu erstellen, und übergib Text, ein einzelnes Bild oder mehrere Ansichten desselben Objekts. Verwende ein AceDataCloud-Token; standardmäßig wird das Ergebnis synchron zurückgegeben. Bei Übergabe von `async: true` oder `callback_url` werden zunächst HTTP 200 und eine `task_id` zurückgegeben. Der Abschluss-Callback und das synchrone Ergebnis haben dieselbe JSON-Struktur.

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

`action` ist standardmäßig `generate`. Wähle eine von drei Eingaben: `prompt` (1–1024 Zeichen), `image_url` oder `image_urls`. Bilder müssen öffentlich zugängliche HTTPS-PNG- oder JPEG-Dateien mit maximal 20 MiB sein. Mehrere Ansichten werden in der Reihenfolge vorne, links, hinten, rechts angeordnet; die Vorderansicht und mindestens eine weitere Ansicht müssen angegeben werden, dazwischenliegende Ansichten können mit null übersprungen werden.

`model` ist standardmäßig `v3.1-20260211`; alternativ können `v3.0-20250812`, `v2.5-20250123`, `P1-20260311` oder `P2-20260801` ausdrücklich ausgewählt werden. `texture` ist standardmäßig `standard`; für reine Geometrie verwende `none`. Verschiedene Modelle und Texturstufen verbrauchen unterschiedliche Kontingente.

Lade die GLB-Datei über `data[0].model_url` herunter; `image_url` ist eine optionale Vorschau. Bewahre `data[0].id` für spätere Textur-, Konvertierungs- oder Skelettoperationen auf. Behalte beim erneuten Versuch derselben Übermittlung denselben `Idempotency-Key` und denselben Anfrage-Body bei.
