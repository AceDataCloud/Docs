---
title: "Tripo-Modellverarbeitung"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Verwenden Sie `POST /tripo/models`, um ein vorhandenes Modell zu verarbeiten, und übergeben Sie die gewünschte `action`. Synchroner und asynchroner Betrieb, Rückrufe, Kontozuordnung und Aufgabenabfrage entsprechen der 3D-Generierung.

| action  | Eingabe                                                                | Ergebnis                                                                   |
| ------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| import  | `model_url`, eine öffentlich zugängliche HTTPS-Datei im Format GLB, GLTF, FBX, OBJ oder STL, maximal 150 MiB | Eine weiterverwendbare Modell-ID und GLB; bei vorhandenen Daten werden `normalize_scale` und `normalize_translation` zurückgegeben |
| texture | `model_id` oder `model_url`; optional eines von `prompt`, `image_url` und `image_urls` | Neues Modell, Texturen und optionale Vorschau |
| convert | `model_id` oder `model_url` sowie das Zielformat `format`               | Konvertierte Modelldatei                                                   |

```json
{"action":"texture","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","prompt":"蓝色哑光表面","texture_quality":"standard","async":true}
```

Die Texturqualität unterstützt `fast`, `standard`, `detailed` und `extreme`. Bei Verwendung eines Text-Prompts kann `style_image_url` hinzugefügt werden; Bild- und Mehransichtsreferenzen entsprechen dem Format der Generierungsschnittstelle. Weitere Texturparameter finden Sie in OpenAPI.

Die Konvertierung unterstützt `GLTF`, `FBX`, `USDZ`, `OBJ`, `STL` und `3MF`. Das `format` des zurückgegebenen Elements gibt das tatsächlich gelieferte Format an; beispielsweise kann bei einer GLTF-Anfrage ein binäres GLB geliefert werden. Bei OBJ werden Materialien und Texturen als ZIP gepackt. Setzen Sie bei einer FBX-Anfrage `texture_packaging: "zip"`, um separate Texturen zu erhalten; das gepackte Ergebnis wird mit `container: "ZIP"` gekennzeichnet. Die Aktivierung von nicht standardmäßigen Mesh- oder Textureinstellungen kann als erweiterte Konvertierung berechnet werden; Einzelheiten finden Sie in den Servicepreisen.

Verwenden Sie `data[0].id`, um ein Modell dieses Kontos zu referenzieren. Die importierte Normalisierungstransformation erfüllt `normalized = original × normalize_scale + normalize_translation`. Die Downloadadresse des Modells befindet sich in `data[0].model_url`.
