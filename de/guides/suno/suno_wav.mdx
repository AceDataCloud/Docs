SUNO ermöglicht es uns, Musik im WAV-Format zu erhalten. Dieses Dokument erklärt die Integrationsmethoden der entsprechenden API.

Der zentrale Eingabeparameter dieser API ist `audio_id`, die die offizielle generierte Song-ID ist; optional wird auch `callback_url` als asynchrone Rückrufadresse unterstützt.

Hier ist die eingegebene `audio_id`: `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer YOUR_API_KEY",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Das Ergebnis sieht wie folgt aus:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://cdn.acedata.cloud/suno/41572926-1a7a-41bc-adb8-9431e494c144.wav"
    }
  ]
}
```

Wie zu sehen ist, ist das `file_url` Feld in `data` die erhaltene Musik im WAV-Format, es handelt sich um eine öffentlich zugängliche CDN-Adresse.

> **Zur Persistenz des WAV-Links**
> Die Plattform wird vor der Rückgabe priorisieren, die endgültige WAV-Datei im Ace Data Cloud CDN zu speichern. Die obige URL zeigt nur das Antwortformat und stellt kein langfristig existierendes reales Objekt dar. Nur wenn die CDN-Persistenz nicht abgeschlossen ist und die ursprüngliche Medienadresse bei sofortiger Überprüfung weiterhin auf eine gültige WAV-Datei heruntergeladen werden kann, könnte `file_url` diese Adresse behalten; wenn die Adresse ungültig ist oder die Dateiüberprüfung fehlschlägt, wird die Anfrage fehlschlagen oder zeitlich ablaufen und keine nicht herunterladbare Adresse als Erfolgsergebnis zurückgeben. Bitte laden Sie die Datei nach Abschluss der Aufgabe umgehend herunter und bewahren Sie sie ordnungsgemäß auf, die spezifische Aufbewahrungsdauer richtet sich nach der aktuellen Speicherstrategie der Plattform.
