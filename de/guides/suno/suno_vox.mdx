SUNO ermöglicht uns die Erstellung der neuen Persona-v2-vox-Version: Sängerstil. Anders als bei der alten Version muss zunächst die `vox_audio_id` abgerufen werden. Dieses Dokument erklärt die Integrationsmethode zur Erstellung der neuen Persona-v2-vox.

Zunächst muss über diese API der Parameterwert `vox_audio_id` abgerufen werden. Diese API kann mehrere Eingabeparameter entgegennehmen, wie `audio_id`, `vocal_start` und `vocal_end`; sie beziehen sich auf die Song-ID und den ausgewählten Zeitbereich.

Die hier eingegebene `audio_id` ist `42599b24-fb14-4cd3-a444-e15ffde3661b`.

```python
import requests

url = "https://api.acedata.cloud/suno/vox"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Wie zu sehen ist, ist das Feld `id` in `data` die gewünschte `vox_audio_id`. Anschließend erstellen wir über die [Persona API](https://platform.acedata.cloud/documents/suno-persona) die neue Persona-v2-vox-Version: Sängerstil. Die konkreten Eingaben sind wie folgt:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "test",
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20,
    "vox_audio_id": "24f0827e-5847-4011-b9b7-fc0b62032b65"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Nach dem Aufruf wird folgendes Ergebnis erhalten:

```json
{
  "success": true,
  "task_id": "e04b06a1-ff61-48e2-9fcc-15284bd18481",
  "data": {
    "persona_id": "49bef16d-6a09-49d1-8c24-a81663698b98"
  }
}
```

Anschließend können wir mit dem obigen Wert `persona_id` Kreationen im neuen Persona-v2-vox-Sängerstil erstellen. Die konkrete Erstellungsmethode entspricht der [Anleitung zur Suno Song-Generierungs-API-Integration](https://platform.acedata.cloud/documents/suno-audios-integration#%E8%87%AA%E5%AE%9A%E4%B9%89%E6%AD%8C%E6%89%8B%E9%A3%8E%E6%A0%BC%E7%94%9F%E6%88%90%E5%8A%9F%E8%83%BD). Abschließend können wir über die Suno Vox API im neuen Persona-v2-vox-Sängerstil Songs erstellen.
