SUNO ermöglicht es uns, benutzerdefinierte Stimmcharaktere durch beliebige Audiodateien zu erstellen, um Stimmklone für die Musikproduktion zu erzeugen. Im Gegensatz zur bestehenden Persona API (die mit von Suno generierten `audio_id` arbeitet) akzeptiert diese API eine öffentlich zugängliche `audio_url`, also eine eigene Sprachaufnahme. Dieses Dokument erklärt die Integration der Voice Cloning API.

## Schritt 1: Erstellen eines Stimmcharakters

Die API hat drei Eingabeparameter: `audio_url` (Pflichtfeld), eine öffentlich zugängliche MP3- oder WAV-Datei mit klarer Einzelstimme; `name` und `description` (optional), der Name und die Beschreibung des Stimmcharakters.

**Anforderungen an die Audiodatei:**
- Format: MP3 oder WAV
- Länge: mindestens 10 Sekunden
- Inhalt: klare Einzelstimme, möglichst wenig Hintergrundgeräusche oder Musik

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

Das Ergebnis sieht wie folgt aus:

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

Man sieht, dass das Feld `persona_id` in `data` die ID des erstellten Stimmcharakters ist. Das Feld `is_public` ist immer `false`, da durch Hochladen erstellte Stimmcharaktere privat sind.

## Schritt 2: Musik mit dem Stimmcharakter generieren

Mit der Stimmcharakter-ID können wir die [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) zur Musikgenerierung verwenden. Setze `action` auf `generate` und `persona_id` auf die oben erhaltene Stimmcharakter-ID, dann wird das erzeugte Lied mit der geklonten Stimme gesungen.

> **Hinweis:** Voice Cloning wird nur von Modellen `chirp-v4-5` und höher unterstützt (z. B. `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), nicht von `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

Das Ergebnis sieht so aus:

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

Man sieht, dass das generierte Lied mit der geklonten Stimme gesungen wird. Die `persona_id` kann auch mit der Aktion `cover` verwendet werden, um bestehende Songs mit der geklonten Stimme neu zu interpretieren.
