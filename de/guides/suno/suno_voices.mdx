---
title: "Anleitung zur Anbindung der Suno-Stimmenklon-API"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO ermöglicht es uns, über beliebige Audiodateien benutzerdefinierte Stimmencharaktere zu erstellen und Stimmenklonen für die Musikgenerierung umzusetzen. Im Gegensatz zur bestehenden Persona-API (die von Suno generierte `audio_id` verwendet) akzeptiert diese API eine öffentlich zugängliche `audio_url`, also deine eigene menschliche Stimmaufnahme. Dieses Dokument erläutert die Anbindungsmethode der Stimmenklon-API.

## Schritt eins: Stimmencharakter erstellen

Diese API verfügt über drei Eingabeparameter: `audio_url` (erforderlich), eine öffentlich zugängliche URL zu einer Audiodatei im MP3- oder WAV-Format, die eine klare Stimme einer einzelnen Person enthält; `name` und `description` (optional), der Name und die Beschreibung des Stimmencharakters.

> **Anforderungen an Audiodateien**
> - Das Audioformat muss `WAV` oder `MP3` sein
> - Die Audiodauer muss zwischen `10~240 Sekunden` liegen; empfohlen werden `30~60 Sekunden` sauberes, trockenes Material mit einer einzelnen Stimme
> - Das Audio sollte eine **klare, erkennbare Sprech- oder Gesangsstimme einer einzelnen Person** enthalten
> - Bitte unbedingt **Hintergrundgeräusche, Begleitung, Echo und Hall** vermeiden; vollständige Songs mit Begleitung bestehen die Stimmabdruckprüfung normalerweise nicht
> - Keine **mehreren Sprecher** oder **mehrstimmigen Gesänge** einschließen
> - Material mit zu geringer Lautstärke, unklarer Sprache oder zu starkem Rauschen kann zu **fehlgeschlagenem Klonen** oder **schlechteren Generierungsergebnissen** führen
> **Hinweise zu Nutzungsbeschränkungen**
> - Durch das Hochladen von Audio erstellte Stimmencharaktere sind **private Ressourcen**
> - Dieser Stimmencharakter **unterstützt keine kontoübergreifende Wiederverwendung**
> - Es wird empfohlen, ihn nach erfolgreicher Erstellung möglichst bald zu verwenden; bei längerer Nichtverwendung kann er **ungültig oder nicht verfügbar** werden
> - Der zurückgegebene `name` wird automatisch vom System generiert; maßgeblich ist die zurückgegebene `persona_id`

> **Bitte bei fehlgeschlagenem Aufruf zuerst erneut versuchen**
> Stimmenklonen ist eine rechenintensive Aufgabe; selbst wenn das Material vollständig konform ist, besteht eine gewisse Wahrscheinlichkeit gelegentlicher Fehler, häufige Rückgaben sind beispielsweise
> `voices_sound_different` (Stimmabdruckprüfung nicht bestanden) usw. **Diese Art von Fehler hängt nicht mit der Audioqualität zusammen; ein erneuter Versuch mit demselben Material ist normalerweise erfolgreich**,
> es wird empfohlen, bei der Integration für fehlgeschlagene Ergebnisse 1~2 automatische Wiederholungen zu implementieren. Fehlgeschlagene Anfragen werden nicht berechnet.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Das oben genannte `https://cdn.acedata.cloud/suno_demo.mp3` ist Beispielmaterial, das direkt aufgerufen werden kann (MP3, 41 Sekunden, trockene Einzelstimme).
> Wenn ein Beispiel im `WAV`-Format benötigt wird, kann
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` verwendet werden (WAV, 41 Sekunden, Mono 44,1 kHz).

Das Ergebnis lautet wie folgt:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Wie zu sehen ist, ist das Feld `persona_id` in `data` genau die ID des erstellten Stimmencharakters. Das Feld `is_public` ist immer `false`, da durch das Hochladen von Audio erstellte Stimmencharaktere privat sind. Beachte, dass der zurückgegebene `name` automatisch vom System generiert wird; verwende anschließend bitte `persona_id`, um auf diesen Stimmencharakter zu verweisen.

## Schritt zwei: Musik mit dem Stimmencharakter generieren

Nachdem wir die ID des Stimmencharakters haben, können wir die [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) zur Musikgenerierung verwenden. Setze `action` auf `generate` und `persona_id` auf die oben zurückgegebene ID des Stimmencharakters; der generierte Song wird mit der geklonten Stimme gesungen.

> **Hinweis:** Stimmenklonen unterstützt nur Modelle ab `chirp-v4-5` (wie `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`) und unterstützt `chirp-v4` nicht.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Das Ergebnis lautet wie folgt:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

Wie zu sehen ist, verwendet der generierte Song die geklonte Stimme zum Singen. `persona_id` kann auch zusammen mit der Aktion `cover` verwendet werden, um bestehende Songs mit der geklonten Stimme zu covern.
