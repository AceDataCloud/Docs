---
title: "Anleitung zur Integration der Suno-Stimmklon-API"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO ermöglicht es uns, über beliebige Audiodateien benutzerdefinierte Stimmrollen zu erstellen und Stimmklonung für die Musikgenerierung zu nutzen. Anders als die bestehende Persona-API (die die von Suno generierte `audio_id` verwendet) akzeptiert diese API eine öffentlich zugängliche `audio_url`, also deine eigene Gesangsaufnahme. Dieses Dokument erklärt die Integrationsmethode der Stimmklon-API.

## Erster Schritt: Stimmrolle erstellen

Abrechnung: Nach erfolgreicher Erstellung der Stimmrolle betragen die Standardkosten pro Anfrage **0.15 Credits**. Anwendbare Verbrauchsrabatte richten sich nach der tatsächlichen Abrechnung, fehlgeschlagene Anfragen werden nicht berechnet.

Diese API hat drei Eingabeparameter: `audio_url` (erforderlich), eine öffentlich zugängliche Audio-Datei-URL im MP3- oder WAV-Format, die klare menschliche Stimme einer einzelnen Person enthält; `name` und `description` (optional), der Name und die Beschreibung der Stimmrolle.

> **Anforderungen an Audiodateien**
> - Das Audioformat muss `WAV` oder `MP3` sein
> - Die Audiodauer muss zwischen `10~240 Sekunden` liegen, empfohlen wird sauberes, trockenes Einzelstimmenmaterial von `30~60 Sekunden`
> - Das Audio sollte **klare, erkennbare Sprech- oder Gesangsstimme einer einzelnen Person** enthalten
> - Bitte unbedingt **Hintergrundgeräusche, Begleitung, Echo, Hall** vermeiden; vollständige Songs mit Begleitung bestehen die Stimmabdruckprüfung in der Regel nicht
> - Keine **mehreren Sprecher** oder **mehrfachen Stimmen** enthalten
> - Material mit zu niedriger Lautstärke, unklarer Sprache oder zu starkem Rauschen kann zu **fehlgeschlagenem Klonen** oder **schlechteren Generierungsergebnissen** führen
> **Hinweise zu Nutzungsbeschränkungen**
> - Durch das Hochladen von Audio erstellte Stimmrollen sind **private Ressourcen**
> - Diese Stimmrolle **unterstützt keine kontoübergreifende Wiederverwendung**
> - Es wird empfohlen, sie nach erfolgreicher Erstellung möglichst zeitnah zu verwenden; bei längerer Nichtverwendung kann sie **ungültig oder nicht verfügbar** werden
> - Der zurückgegebene `name` wird automatisch vom System generiert, maßgeblich ist die zurückgegebene `persona_id`

> **Bei einem Aufruffehler bitte zuerst erneut versuchen**
> Stimmklonung ist eine rechenintensive Aufgabe, und selbst bei vollständig konformem Material besteht eine gewisse Wahrscheinlichkeit sporadischer Fehler, häufige Rückgaben sind beispielsweise
> `voices_sound_different` (Stimmabdruckprüfung nicht bestanden) usw. **Diese Art von Fehler steht in keinem Zusammenhang mit der Audioqualität; ein erneuter Versuch mit demselben Material ist normalerweise erfolgreich**,
> es wird empfohlen, bei der Integration für fehlgeschlagene Ergebnisse 1~2 automatische Wiederholungsversuche zu implementieren. Fehlgeschlagene Anfragen werden nicht berechnet.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Das oben genannte `https://cdn.acedata.cloud/suno_demo.mp3` ist Beispielmaterial, das direkt aufgerufen werden kann (MP3, 41 Sekunden, trockene Einzelstimme).
> Wenn ein Beispiel im `WAV`-Format benötigt wird, kann
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` verwendet werden (WAV, 41 Sekunden, Mono 44.1kHz).

Das Ergebnis lautet wie folgt:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Wie zu sehen ist, ist das Feld `persona_id` in `data` genau die ID der erstellten Stimmrolle. Das Feld `is_public` ist stets `false`, da durch Hochladen von Audio erstellte Stimmrollen privat sind. Beachte, dass der zurückgegebene `name` automatisch vom System generiert wird; verwende anschließend `persona_id`, um auf diese Stimmrolle zu verweisen.

## Zweiter Schritt: Musik mit der Stimmrolle generieren

Nach Erhalt der Stimmrollen-ID können wir die [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) für die Musikgenerierung verwenden. Setze `action` auf `generate` und `persona_id` auf die oben zurückgegebene Stimmrollen-ID; der generierte Song wird mit der geklonten Stimme gesungen.

> **Hinweis:** Stimmklonung unterstützt nur Modelle ab `chirp-v4-5` (wie `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), `chirp-v4` wird nicht unterstützt.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Das Ergebnis lautet wie folgt:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` kann für die `generate`-Generierung verwendet werden und auch für `cover` / `upload_cover`-Coverversionen. Bei Angabe einer Stimme muss `vocal_gender` nicht gleichzeitig ausgefüllt werden; die Stimmähnlichkeit hängt weiterhin vom Referenzmaterial und dem Generierungsergebnis ab.

Die über diese Schnittstelle erstellten Stimmen sind private Ressourcen. Rufe vor dem Covern eines bestehenden Songs zuerst `/suno/upload` auf und übergib die `audio_url` des Originalsongs sowie die `persona_id` dieser Stimme; nach erfolgreichem Upload rufe `/suno/audios` mit der zurückgegebenen `data.audio_id` und derselben `persona_id` auf:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

Das Erstellen der Stimme, das Hochladen des Originalsongs und die Coverversion müssen über denselben Servicekanal erfolgen. Bitte verwende nicht direkt zuvor erstellte Song-IDs wieder, die nicht mit dieser privaten Stimme verknüpft wurden; Details siehe [Suno-Referenzaudio hochladen](https://platform.acedata.cloud/documents/suno-upload).
