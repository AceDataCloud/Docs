---
title: "Anleitung zur API-Integration für benutzerdefinierte Suno-Sängerstile"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO ermöglicht es uns, für bereits generierte Songs einen Sängerstil festzulegen und dann darauf basierend eine sekundäre Kreation durchzuführen. Dieses Dokument erläutert die Integrationsmethode der entsprechenden API.

`GET /suno/persona` zum Abfragen der Liste und `DELETE /suno/persona` zum Löschen von Einträgen sind kostenfrei, es ist kein zusätzlicher Header für kostenfreie Anfragen erforderlich. Der Erstellungsvorgang über `POST /suno/persona` wird weiterhin gemäß den Preisregeln der Schnittstelle berechnet.

Diese API hat nur drei Eingabeparameter: zunächst `audio_id`, dies ist eine Song-ID eines bereits offiziell erfolgreich generierten Songs; anschließend sind `name` und `description` eine Bezeichnung und Beschreibung des Sängerstils.

Die hier eingegebene `audio_id` ist `https://cdn.acedata.cloud/2qhzs3.png`; dies kann sich auf die [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) beziehen, um eine benutzerdefinierte Song-Generierung durchzuführen, und letztendlich kann `audio_id` erhalten werden.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Das Ergebnis ist wie folgt:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Es ist zu sehen, dass das Feld `persona_id` in `data` die generierte Sängerstil-ID ist.

Nachdem wir die Sängerstil-ID haben, können wir die [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) verwenden, um eine benutzerdefinierte Song-Generierung durchzuführen, beispielsweise wird für `action` `artist_consistency` übergeben, gleichzeitig wird für `audio_id` die ID des hochgeladenen Songs übergeben, außerdem muss der Parameter `persona_id` hochgeladen werden; dieser Wert ist die oben zurückgegebene Sängerstil-ID. So können neue Songs basierend auf dem referenzierten Sängerstil generiert werden.
