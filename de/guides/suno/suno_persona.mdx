---
title: "Suno API-Integrationsanleitung für benutzerdefinierte Sänger-Stile"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO ermöglicht es uns, für bereits generierte Songs einen Sänger-Stil festzulegen und anschließend darauf basierend eine zweite kreative Bearbeitung durchzuführen. Dieses Dokument erläutert die Integrationsmethode der entsprechenden API.

Die Listenabfrage mit `GET /suno/persona` und das Löschen von Einträgen mit `DELETE /suno/persona` sind kostenfrei und erfordern keinen zusätzlichen Request-Header für kostenfreie Anfragen. Die Erstellung mit `POST /suno/persona` wird weiterhin gemäß den Preisregeln der Schnittstelle berechnet.

Bei Erstellungslinien, die Abfragen der Stimmfarbe unterstützen, kann mit der ursprünglichen Anwendung und der Identität des Aufrufers die `persona_id` aus dem Erstellungsergebnis an `POST /suno/availability` übergeben werden. Wenn die Verfügbarkeit bestätigt wird, wird `data.available=true` zurückgegeben. [Leitfaden zur Abfrage der Stimmfarbenverfügbarkeit](https://platform.acedata.cloud/documents/suno-availability-integration)

Diese API hat nur drei Eingabeparameter: zunächst `audio_id`, dies ist eine Song-ID, die bereits offiziell erfolgreich generiert wurde; anschließend `name` und `description`, dies sind ein Name und eine Beschreibung für den Sänger-Stil.

Die hier eingegebene `audio_id` ist `https://cdn.acedata.cloud/2qhzs3.png`. Dies kann unter Bezugnahme auf die [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) zur benutzerdefinierten Song-Generierung verwendet werden; schließlich kann man die `audio_id` erhalten.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Das Ergebnis lautet wie folgt:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Wie zu sehen ist, ist das Feld `persona_id` in `data` die ID des generierten Sänger-Stils.

Nachdem wir die Sänger-Stil-ID erhalten haben, können wir die [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) zur benutzerdefinierten Song-Generierung verwenden, beispielsweise indem wir `action` mit `artist_consistency` übergeben und gleichzeitig `audio_id` mit der ID des hochgeladenen Songs übergeben. Außerdem muss der Parameter `persona_id` hochgeladen werden; dieser Wert ist die oben zurückgegebene Sänger-Stil-ID. Auf diese Weise können neue Songs basierend auf dem referenzierten Sänger-Stil generiert werden.
