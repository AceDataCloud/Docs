Das exklusive Musikmodell kann aus 6 bis 24 autorisierten Audios konsistente Musikmerkmale lernen und für die anschließende Songkreation verwendet werden. Die Erstellung ist eine asynchrone Operation; es wird empfohlen, 24 stilistisch konsistente und qualitativ hochwertige Audios für stabilere Ergebnisse zu verwenden.

> Es dürfen nur Audios eingereicht werden, für die Sie das rechtmäßige Nutzungsrecht besitzen oder die Sie zur Erstellung des Modells und zur anschließenden Generierung autorisiert haben. Bitte laden Sie keine nicht lizenzierten Musik- oder Klangmaterialien hoch.

## Modell erstellen

Rufen Sie `POST /suno/custom-models` auf und setzen Sie `action=create`. Es wird empfohlen, gleichzeitig einen einzigartigen `Idempotency-Key`-Header zu senden; verwenden Sie denselben Schlüssel bei Netzwerk-Wiederholungen, um eine doppelte Erstellung zu vermeiden:

```json
{
  "action": "create",
  "name": "Mein Indie-Modell",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

Die Schnittstelle gibt sofort die Plattformmodell-ID und die Aufgaben-ID zurück. Nach Abschluss der Erstellung ändert sich der `status` im Callback oder in den Abfrageergebnissen auf `ready`. Nur erfolgreiche Modellkreationen werden berechnet; bei einem Fehlschlag erfolgt keine Abrechnung.

## Modell abfragen

Einzelnes Modell abfragen:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Seitenweise Abfrage der aktuellen Modelle der Anwendung:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Alle Modelle gehören der Suno-Anwendung, die sie erstellt hat. Der Wechsel der API-Anmeldeinformationen ändert nicht die Zugehörigkeit des Modells, andere Anwendungen können dieses Modell nicht abfragen oder verwenden.

## Modell zur Songgenerierung verwenden

Nachdem der Modellstatus `ready` ist, rufen Sie weiterhin `POST /suno/custom-models` auf und setzen Sie `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nStadtlichter fallen durch den Regen",
  "style": "indie rock, warmer analoger Synth"
}
```

`id` muss das exklusive Musikmodell sein, das im aktuellen Anwendungskontext den Status `ready` hat. Wenn das Modell nicht verfügbar ist, schlägt die Anfrage fehl und es wird nicht automatisch ein anderes Modell verwendet.

## Modell archivieren

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Die aktuelle Beta-Version archiviert das Modell und verbietet die weitere Nutzung. `capacity_released=false` in der Antwort bedeutet, dass das Archivieren keine Freigabe der Modellkapazität garantiert. Der Archivierungsprozess kann wiederholt aufgerufen werden, es erfolgt keine doppelte Abrechnung.
