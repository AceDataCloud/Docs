---
title: "Leitfaden zur Integration exklusiver Suno-Musikmodelle"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Exklusive Musikmodelle können aus 6 bis 24 autorisierten Audiodateien konsistente musikalische Merkmale lernen und für die anschließende Songerstellung verwendet werden. Die Erstellung ist ein asynchroner Vorgang; es wird empfohlen, 24 Audiodateien mit einheitlichem Stil und klarer Klangqualität zu verwenden, um stabilere Ergebnisse zu erzielen.

> Sie dürfen nur Audiodateien einreichen, für die Sie ein rechtmäßiges Nutzungsrecht besitzen oder eine Genehmigung zur Modellerstellung und anschließenden Generierung erhalten haben. Bitte laden Sie keine Musik- oder Klangmaterialien ohne Genehmigung hoch.

## Modell erstellen

Rufen Sie `POST /suno/custom-models` auf und setzen Sie `action=create`:

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

Die Schnittstelle gibt sofort die Plattform-Modell-ID und die Aufgaben-ID zurück. Nach Abschluss der Erstellung wird `status` im Callback oder Abfrageergebnis zu `ready`. Nur bei erfolgreicher Modellerstellung werden **10 Credits** berechnet; bei fehlgeschlagener Erstellung fallen keine Gebühren an.

## Modell abfragen

Ein einzelnes Modell abfragen:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Modelle der aktuellen Anwendung paginiert abfragen:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Alle Modelle gehören zu der Suno-Anwendung, die sie erstellt hat. Eine Rotation der API-Anmeldedaten ändert die Modellzugehörigkeit nicht, und andere Anwendungen können das Modell weder abfragen noch verwenden.

## Songs mit dem Modell generieren

Nachdem der Modellstatus `ready` lautet, rufen Sie weiterhin `POST /suno/custom-models` auf und setzen Sie `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id` muss ein exklusives Musikmodell mit dem Status `ready` unter der aktuellen Anwendung sein. Wenn das Modell nicht verfügbar ist, schlägt die Anfrage fehl; es wird nicht automatisch ein anderes Modell verwendet. `persona_id` und exklusive Musikmodelle schließen sich gegenseitig aus; bei gleichzeitiger Übermittlung gibt die Schnittstelle HTTP 400 zurück, bevor die Anfrage an den Generierungsdienst gesendet wird, und es fallen keine Gebühren an. Wenn Sie Persona verwenden möchten, nutzen Sie stattdessen die Aktionen `artist_consistency` oder `artist_consistency_vox` von `/suno/audios`.

Eine erfolgreiche Songgenerierung verbraucht **0.90 Credits**; bei fehlgeschlagener Generierung fallen keine Gebühren an. Das Abfragen und Archivieren von Modellen ist kostenlos.

## Modell archivieren

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Die aktuelle Beta-Version archiviert das Modell und verhindert seine weitere Verwendung; `capacity_released=false` in der Antwort bedeutet, dass die Archivierung keine Freigabe der Modellkapazität garantiert. Der Archivierungsvorgang kann wiederholt aufgerufen werden, ohne dass erneut Gebühren berechnet werden.
