title: "Suno Exklusive Musikmodell Integrationsanleitung"

Das exklusive Musikmodell kann aus 6 bis 24 autorisierten Audiodateien konsistente musikalische Merkmale lernen und für die anschließende Songkreation verwendet werden. Die Erstellung ist eine asynchrone Operation; es wird empfohlen, 24 stilistisch konsistente und qualitativ hochwertige Audiodateien zu verwenden, um stabilere Ergebnisse zu erzielen.

> Es dürfen nur Audiodateien eingereicht werden, für die Sie das rechtmäßige Nutzungsrecht besitzen oder die Sie für die Erstellung des Modells und die anschließende Generierung autorisiert haben. Bitte laden Sie keine nicht lizenzierten Musik- oder Klangmaterialien hoch.

## Modell erstellen

Rufen Sie `POST /suno/custom-models` auf und setzen Sie `action=create`:

```json
{
  "action": "create",
  "name": "Mein Indie Modell",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

Die Schnittstelle gibt sofort die Plattformmodell-ID und die Aufgaben-ID zurück. Nach Abschluss der Erstellung ändert sich der `status` im Callback oder in den Abfrageergebnissen auf `ready`. Nur wenn das Modell erfolgreich erstellt wurde, werden **10 Credits** berechnet; bei einem Fehlschlag fallen keine Gebühren an.

## Modell abfragen

Einzelnes Modell abfragen:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Seitenweise Abfrage der aktuellen Modelle:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Alle Modelle gehören der Suno-Anwendung, die sie erstellt hat. Der Wechsel der API-Anmeldeinformationen ändert nicht die Zugehörigkeit des Modells, andere Anwendungen können dieses Modell nicht abfragen oder verwenden.

## Modell zur Songgenerierung verwenden

Nachdem der Modellstatus `ready` ist, rufen Sie weiterhin `POST /suno/custom-models` auf und setzen Sie `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nStadtlichter fallen durch den Regen",
  "style": "indie rock, warmer analoger Synth"
}
```

`id` muss das exklusive Musikmodell sein, dessen Status im aktuellen Anwendung `ready` ist. Wenn das Modell nicht verfügbar ist, schlägt die Anfrage fehl und es wird nicht automatisch auf ein anderes Modell umgeschaltet. Die erfolgreiche Songgenerierung verbraucht **0,90 Credits**; bei einem Fehlschlag fallen keine Gebühren an. Die Abfrage und Archivierung von Modellen ist kostenlos.

## Modell archivieren

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Die aktuelle Beta-Version archiviert das Modell und verbietet die weitere Nutzung. `capacity_released=false` in der Antwort bedeutet, dass die Archivierung nicht garantiert, dass Modellkapazität freigegeben wird. Der Archivierungsprozess kann wiederholt aufgerufen werden, ohne dass zusätzliche Gebühren anfallen.
