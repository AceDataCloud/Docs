Mit der zunehmenden Anwendung von KI haben sich verschiedene KI-Programme allmählich verbreitet. KI hat sich zunehmend in alle Aspekte des Arbeits- und Lebensalltags der Menschen integriert. Die Branchen, die von KI betroffen sind, werden ebenfalls immer vielfältiger, von anfänglichem Schreiben über Gesundheitswesen und Bildung bis hin zur Musik.

Suno ist eine professionelle, hochwertige Plattform zur Erstellung von KI-Songs und Musik. Benutzer müssen lediglich einfache Textanweisungen eingeben, um basierend auf Genre-Stilen und Texten Lieder mit Gesang zu generieren. Dieser KI-Musikgenerator wurde von Teammitgliedern bekannter Technologieunternehmen wie Meta, TikTok und Kensho entwickelt, mit dem Ziel, dass jeder ohne Musikinstrumente wunderbare Musik schaffen kann.

Hier ist der Fortschritt der Modellaktualisierungen:

| Version | Modell            | Veröffentlichungsdatum | Lyric-Beschränkung | Style-Beschränkung | Maximale Songlänge |
| ------- | ----------------- | --------------------- | ------------------ | ------------------ | ------------------ |
| v5.5    | chirp-v5-5       | 2026.03.27            | 5000               | 1000               | 8 Minuten          |
| v5      | chirp-v5         | 2025.09.23            | 5000               | 1000               | 8 Minuten          |
| v4.5+   | chirp-v4-5-plus  | 2025.07.17            | 5000               | 1000               | 8 Minuten          |
| v4.5    | chirp-v4-5       | 2025.05.03            | 5000               | 1000               | 4 Minuten          |
| v4      | chirp-v4         | 2024.12.17            | 3000               | 200                | 150 Sekunden       |
| v3.5    | chirp-v3-5       | ---                   | 3000               | 200                | 120 Sekunden       |

> In der obigen Tabelle sind die `lyric` und `style` Beschränkungen die Obergrenze im benutzerdefinierten Modus (`custom` ist `true`). Im nicht benutzerdefinierten Inspirationsmodus (`custom` ist `false`) wird nur `prompt` ausgefüllt, dessen Längenobergrenze 500 Zeichen beträgt (bei allen Modellen gleich).

Suno unterstützt jetzt das neueste `chirp-v5-5` Modell. Um die neueste Version aufzurufen, setzen Sie den `model` Parameter auf `chirp-v5-5`; `chirp-v5` und frühere Versionen können weiterhin verwendet werden.

Allerdings bietet Suno offiziell keine API an, AceDataCloud stellt eine API für Suno zur Verfügung, die die offizielle Suno-API simuliert und es ermöglicht, schnell und einfach die gewünschte Musik zu generieren.

## Antrag und Nutzung

Um die Suno Audios Generation API zu nutzen, gehen Sie zuerst zur [Ace Data Cloud Konsole](https://platform.acedata.cloud/console/applications), um Ihr API-Token zu erhalten, das Sie für später aufbewahren sollten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, die Sie zur Registrierung und Anmeldung einlädt. Nach Abschluss werden Sie automatisch zur aktuellen Seite zurückgeleitet.

**Ein API-Token reicht aus, um alle Dienste der Plattform zu nutzen, es ist nicht erforderlich, für jeden Dienst separat zu beantragen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, um es kostenlos auszuprobieren; wenn das Kontingent nicht ausreicht, können Sie im [Dashboard](https://platform.acedata.cloud/console/coin) Ihr allgemeines Guthaben aufladen.

> 📘 Vollständige Dokumentation: [Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## Grundlegende Nutzung

Was auch immer Sie sich für Songs wünschen, können Sie beliebigen Text eingeben, zum Beispiel, wenn ich ein Lied über Weihnachten generieren möchte, kann ich `a song for Christmas` eingeben, wie im Bild gezeigt:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

Hier haben wir die Request-Header festgelegt, einschließlich:

- `accept`: In welchem Format Sie die Antwort erhalten möchten, hier eingetragen als `application/json`, also im JSON-Format.
- `authorization`: Der Schlüssel zum Aufrufen der API, den Sie nach der Beantragung direkt auswählen können.

Außerdem haben wir den Request-Body festgelegt, einschließlich:
- `action`：Die Aktion dieser Musikgenerierungsaufgabe, standardmäßig `generate`, umfasst hauptsächlich: `extend`, `upload_extend`, `cover`, `upload_cover`, `replace_section`, `replace_section`, `concat`, `stems`, `all_stems`, `remaster`.
- `prompt`：Die offiziellen Inspirationsmodus-Hinweise von Suno (wirksam, wenn `custom` auf `false` gesetzt ist), maximal 500 Zeichen.
- `model`：Das Modell dieser Musikgenerierungsaufgabe, standardmäßig `chirp-v4`, umfasst hauptsächlich: `chirp-v3`, `chirp-v4`, `chirp-v3-5`, `chirp-v4-5`, `chirp-v4-5-plus`, `chirp-v5`, `chirp-v5-5`.
- `lyric`：Der Inhalt der Lyrics im benutzerdefinierten Modus von Suno. `chirp-v3-5` und `chirp-v4` maximal 3000 Zeichen; `chirp-v4-5` und höher (einschließlich `chirp-v5`, `chirp-v5-5`) maximal 5000 Zeichen.
- `custom`：Ob der benutzerdefinierte Modus verwendet wird, standardmäßig: `false`.
- `instrumental`：Die reine Musikoption im Inspirationsmodus von Suno.
- `title`：Der Titel der Musik im benutzerdefinierten Modus von Suno. `chirp-v3-5`, `chirp-v4` maximal 80 Zeichen; `chirp-v4-5` und höher maximal 100 Zeichen.
- `style`：Der Musikstil im benutzerdefinierten Modus von Suno. `chirp-v3-5` und `chirp-v4` maximal 200 Zeichen; `chirp-v4-5` und höher (einschließlich `chirp-v5`, `chirp-v5-5`) maximal 1000 Zeichen.
- `negative_tags`：Musikstile oder Genres, die im benutzerdefinierten Modus (`custom` ist `true`) von den Ergebnissen ausgeschlossen werden sollen.
- `audio_weight`：Der Anteil der hochgeladenen Referenzaudio, Bereich 0-1, je größer, desto mehr wird auf das Referenzaudio vertraut.
- `audio_id`：Die ID der Referenzmusik.
- `overpainting_start`/`overpainting_end`：Die Start- und Endzeit für das Hinzufügen von Gesang zu bereits vorhandener reiner Musik, Einheit Sekunden.
- `underpainting_start`/`underpainting_end`：Die Start- und Endzeit für das Hinzufügen von Begleitmusik zu einem Gesang, Einheit Sekunden.
- `persona_id`：Die ID des Künstlersongs.
- `continue_at`：Die Zeit in Sekunden, um die vorhandene Audio fortzusetzen. Zum Beispiel bedeutet 213.5, dass bis 3 Minuten 33.5 Sekunden fortgesetzt wird.
- `style_influence`：Der „Style Influence“-Parameter im benutzerdefinierten Modus, Bereich 0-1, je größer, desto mehr entspricht es dem gewählten Stil.
- `replace_section_end`：Die Endzeit des zu ersetzenden Abschnitts.
- `replace_section_start`：Die Startzeit des zu ersetzenden Abschnitts.
- `vocal_gender`：Steuert die Präferenz für männliche oder weibliche Stimmen, weiblich `f`, männlich `m`, ab Modell 4.5 wirksam; ist eine Präferenz, die nicht strikt eingehalten wird.
- `weirdness`：Der „Weirdness“-Parameter im benutzerdefinierten Modus, Bereich 0-1, je größer, desto kreativer und experimenteller.
- `duration`：Die gewünschte Songlänge, Einheit Sekunden, muss eine ganze Zahl sein, Wertebereich 10 bis 360. Dieser Parameter wird für die Songgenerierung im benutzerdefinierten Modus (`custom` ist `true`) verwendet. Es ist ein Hinweis, kein striktes Limit: Das Modell wird sich darauf beziehen, aber es wird nicht garantiert, dass es erreicht wird, die tatsächliche Länge des Endprodukts wird durch das `duration`-Feld in der Antwort bestimmt, normalerweise kürzer als der erwartete Wert.
- `lyric_prompt`：Der Prompt zur Generierung von Lyrics, der nur wirksam ist, wenn `custom` auf `true` gesetzt ist und `lyric` nicht übergeben wurde.
- `callback_url`：Die URL, an die die Ergebnisse zurückgerufen werden sollen.
- `async`：Optional, wenn auf `true` gesetzt, gibt die Schnittstelle sofort `task_id` zurück, ohne dass `callback_url` bereitgestellt werden muss, anschließend wird das Ergebnis über die entsprechende Task-Abfrage-Schnittstelle abgefragt.

## 自定义歌手风格生成功能
Wenn Sie den Stil eines Sängers verwenden möchten, um ein Lied zu generieren, müssen Sie zunächst mit der grundlegenden Verwendung oben ein Lied generieren. Schließlich müssen Sie dieses Lied auf den Stil des Sängers einstellen und dann die [Suno Persona API](https://platform.acedata.cloud/documents/suno-persona) aufrufen, um anhand der von der offiziellen API generierten Musik-ID `audio_id` eine Sängerstil-ID-Parameter `persona_id` zu generieren. Die spezifischen Parameter sind wie im folgenden Bild dargestellt:

<p><img src="https://cdn.acedata.cloud/a5g0nj.png" width="500" className="m-auto" /></p>

Entsprechender Python-Code:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "name": "test"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Fortsetzungsfunktion

Wenn Sie ein bereits generiertes Suno-Lied weiter generieren möchten, können Sie den Parameter `action` auf `extend` setzen und die ID des Liedes eingeben, das Sie weiter generieren möchten. Die ID des Liedes kann anhand der grundlegenden Verwendung ermittelt werden. Wie oben erwähnt, können Sie die ID des Liedes sehen:

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> Hinweis: Hier ist die `id` in den Lyrics die ID des generierten Liedes. Wenn Sie nicht wissen, wie man ein Lied generiert, können Sie sich auf die grundlegende Verwendung oben beziehen, um ein Lied zu generieren.

Wenn Sie ein selbst hochgeladenes Lied weiter generieren möchten, können Sie den Parameter `action` auf `upload_extend` setzen und die ID des benutzerdefinierten hochgeladenen Liedes eingeben. Die ID des Liedes kann über die [Suno Upload Generation API](https://platform.acedata.cloud/documents/suno-upload) abgerufen werden, wie im folgenden Bild dargestellt:

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" className="m-auto" /></p>

Als Nächstes müssen wir die Lyrics und den Stil für die benutzerdefinierte Generierung des Liedes ausfüllen, und wir können die folgenden Inhalte angeben:

- lyric: Text der Lyrics
- custom: auf `true` setzen, was bedeutet, dass es sich um eine benutzerdefinierte Generierung handelt. Dieser Parameter ist standardmäßig auf false gesetzt, was bedeutet, dass die Generierung mit `prompt` erfolgt.
- style: Stil des Liedes, optional.
- continue_at: Zeit in Sekunden, um die bestehende Audiozeit fortzusetzen. Zum Beispiel bedeutet 213.5, dass es bis 3 Minuten und 33,5 Sekunden fortgesetzt wird.

## Musikübertragung

- action: Inhalt ist `cover`, wenn es sich um eine Coverversion einer benutzerdefiniert hochgeladenen Musik handelt, muss der Inhalt `upload_cover` sein.
- audio_id: Die ID des zuvor generierten Songs.

Zum Beispiel, wenn die ID des ursprünglich generierten Songs ist: 0a1e1b10-c36a-41c9-9bfb-b26d9d25db98, können die Parameter wie folgt gesetzt werden:

## Abschnitt ersetzen

Wenn nach der Generierung eines Songs ein einzelner Abschnitt des Songs ersetzt werden muss, kann ein bestimmter Abschnitt des Songs ersetzt werden.

> ⚠️ **Hinweis**: `replace_section` wird allein verwendet, **gibt nur den neu generierten "Ersatzabschnitt" selbst zurück** (d.h. die neue Audioaufnahme des ersetzten Abschnitts, die ungefähr der Dauer von `replace_section_end - replace_section_start` entspricht, und enthält eine kleine Menge an Kontext), **und gibt nicht das zusammengefügte gesamte Lied zurück**. Um das vollständige Produkt zu erhalten, das mit dem Originalstück zusammengefügt ist, muss nach dem Erfolg von `replace_section` eine weitere [Musikzusammenführungs](#Musikzusammenführung) Aufgabe für die zurückgegebene Abschnitts-ID initiiert werden. Der vollständige Prozess ist im Folgenden beschrieben.

Parameterbeschreibung ist wie folgt:

- action: Inhalt ist `replace_section`.
- audio_id: Die ID des ursprünglichen Songs (des ersetzten Quell-Songs).
- model: Das Modell zur Songgenerierung.
- lyric: Der vollständige Text nach der Ersetzung (einschließlich des ersetzten Abschnitts und seines Kontexts, der mit dem Inhalt in `prompt` übereinstimmt).
- prompt: Der neue Text, der ersetzt werden soll.
- style: Der Stil des Songs, optional.
- replace_section_start: Die Startzeit des ersetzten Abschnitts im Originalstück (Sekunden).
- replace_section_end: Die Endzeit des ersetzten Abschnitts im Originalstück (Sekunden).

## Steuerung der Songlänge

Standardmäßig wird die Länge des generierten Songs vom Modell selbst bestimmt, normalerweise zwischen 30 Sekunden und 4 Minuten. Wenn ein längeres oder kürzeres Produkt benötigt wird, kann die gewünschte Länge über den Parameter `duration` angegeben werden, die Einheit ist Sekunden, und der Wert muss eine ganze Zahl zwischen 10 und 360 sein.

Dieser Parameter wird für die Songgenerierung im benutzerdefinierten Modus (`custom` ist `true`) verwendet. Es ist besonders zu beachten, dass `duration` ein **tendenzieller Hinweis und keine strikte Vorgabe** ist: Das Modell wird diesen Wert bei der Erstellung berücksichtigen, garantiert jedoch nicht, dass er erreicht wird. In der Praxis ist die tatsächliche Länge oft deutlich kürzer als der erwartete Wert, und die Längen der beiden Songs, die in einer einzigen Anfrage zurückgegeben werden, können ebenfalls um ein Vielfaches variieren. Selbst bei identischen Anfragen kann die Länge bei mehrfachen Einreichungen erheblich variieren. Daher sollte dies nicht als präzise Längensteuerung verwendet werden. Wenn eine feste Länge geschäftlich erforderlich ist, schneiden Sie das Produkt nach Erhalt selbst oder versuchen Sie es erneut.

Entsprechender Python-Code:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "Unter den Stadtlichtern",
    "style": "lo-fi piano",
    "lyric": "[Strophe]\nSonnenaufgang schleicht\nGold auf dem Boden\n[Refrain]\nUnter den Stadtlichtern\n",
    "duration": 330
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Es ist zu beachten, dass die `duration` in der Anfrage die **erwartete Länge** ist, während das `duration`-Feld in den `data` der Antwort die **tatsächliche Länge** des jeweiligen Songs ist. Beide haben denselben Namen, aber unterschiedliche Bedeutungen; die tatsächliche Länge garantiert nicht, dass sie dem erwarteten Wert entspricht. Die Länge des Textes ist einer der Hauptfaktoren, die die Länge des Produkts beeinflussen. Wenn ein längeres Produkt benötigt wird, wird empfohlen, gleichzeitig vollständigere Texte bereitzustellen.

Die Schnittstelle führt keine zusätzlichen Überprüfungen der `duration` durch; die Parameter werden unverändert an das Modell übergeben. Wenn Werte übergeben werden, die vom aktuellen Modus oder Modell nicht unterstützt werden, kann dies dazu führen, dass dieser Wert ignoriert wird. Es wird empfohlen, zunächst eine Anfrage zu verwenden, um die Wirkung zu bestätigen, bevor Sie sie in großen Mengen verwenden.

## Add Insterumental Funktion

Im August 2025 hat Suno die Add Insterumental-Funktion neu eingeführt. Zuerst müssen Sie ein a cappella Lied ohne Begleitstimme hochladen, damit Suno Ihnen die Musik untermalt. Zuerst können Sie zur [Suno Upload API](https://platform.acedata.cloud/documents/suno-upload) gehen, um ein a cappella Lied ohne Begleitmusik hochzuladen, die entsprechenden Schritte sind wie im folgenden Bild dargestellt:

<p><img src="https://cdn.acedata.cloud/fxl914.png" width="500" class="m-auto"></p>

Dann müssen Sie die `audio_id` nach dem Hochladen aufzeichnen. Das spezifische Ergebnis ist im folgenden Bild dargestellt:

<p><img src="https://cdn.acedata.cloud/47t6wj.png" width="500" class="m-auto"></p>

Schließlich haben wir eine `audio_id` erhalten: 92254cab-3372-4d9e-bce9-cdcfdbc39070, und wir müssen die folgenden Parameter ausfüllen:

## Inspo Kreativitätsfunktion

Die neu eingeführte Inspo Kreativitätsfunktion von Suno kann basierend auf 1 bis 4 Referenz-Audios als Inspirationsquelle neue Musik generieren. Im Gegensatz zu Coverversionen wird Inspo das Originalstück nicht nachahmen, sondern Stil-Inspirationen aus den Referenz-Audios extrahieren und mit Stichwörtern, Stil-Tags usw. kombinieren, um neue Werke zu schaffen. Bei der Verwendung müssen die folgenden Parameter ausgefüllt werden:

- action: Inhalt ist `inspo`.
- audio_urls: Liste der URLs der Referenz-Audios, es müssen 1 bis 4 öffentlich zugängliche Audio-Adressen bereitgestellt werden.
- model: Verwendetes Modell, z. B. `chirp-v5`.
- prompt: Liedtexte oder kreative Stichwörter (optional).
- tags: Musikstil-Tags, z. B. `akustisch, folk, warm` (optional).
- title: Titel des Songs (optional).
- audio_weight: Einflussgewicht der Referenz-Audios auf das generierte Ergebnis, Wertebereich 0 bis 1 (optional).

> Hinweis: Die Referenz-Audios müssen öffentlich zugängliche Audiodateien sein. Wenn die Referenz-Audios mit bekannten Aufnahmen in der Plattformbibliothek vollständig übereinstimmen, kann Suno aufgrund von Urheberrechtsprüfungen die Generierung ablehnen. Es wird empfohlen, eigene oder von Suno generierte Audios als Inspirationsquelle zu verwenden.

Entsprechender Python-Code:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "inspo",
    "model": "chirp-v5",
    "audio_urls": [
        "https://cdn1.suno.ai/935dd2f5-ddef-43cf-8e68-5a262425694d.mp3"
    ],
    "prompt": "warme akustische Folk mit sanften Vocals",
    "tags": "akustisch, folk, warm",
    "title": "Inspo Demo",
    "audio_weight": 0.6
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asynchrone Rückrufe

Da die Musikgenerierung durch Suno relativ lange dauert, etwa 1-2 Minuten, bleibt die HTTP-Anfrage bei längerer Nichtreaktion des API verbunden, was zu einem zusätzlichen Verbrauch von Systemressourcen führt. Daher bietet diese API auch Unterstützung für asynchrone Rückrufe.

Der gesamte Ablauf ist: Wenn der Client die Anfrage startet, gibt er zusätzlich ein Feld `callback_url` an. Nachdem der Client die API-Anfrage gestartet hat, gibt die API sofort ein Ergebnis zurück, das ein Feld `task_id` enthält, das die aktuelle Aufgaben-ID darstellt. Wenn die Aufgabe abgeschlossen ist, wird das Ergebnis der Musikgenerierung in Form von POST JSON an die vom Client angegebene `callback_url` gesendet, wobei auch das Feld `task_id` enthalten ist, sodass das Aufgabenergebnis über die ID verknüpft werden kann.

Lassen Sie uns anhand eines Beispiels verstehen, wie dies konkret funktioniert.

Zunächst ist der Webhook-Rückruf ein Dienst, der HTTP-Anfragen empfangen kann. Entwickler sollten die URL ihres eigenen HTTP-Servers ersetzen.
