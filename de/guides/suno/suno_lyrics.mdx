---
title: "Anleitung zur Integration der Suno-API zur Liedtextgenerierung"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Wenn du die Generierung von Songs individuell anpassen möchtest, aber nicht unbedingt selbst Liedtexte schreiben willst, kannst du die von AceDataCloud bereitgestellte API zur Liedtextgenerierung verwenden, um Liedtexte über einen Prompt zu generieren. Die API ist die [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Abrechnung: Nach erfolgreicher Generierung beträgt die Standardgebühr pro Anfrage **0.08 Credits**. Auch wenn eine Anfrage mehrere Liedtextkandidaten zurückgibt, wird sie nur einmal abgerechnet; anwendbare Verbrauchsrabatte richten sich nach der tatsächlichen Rechnung, fehlgeschlagene Anfragen werden nicht berechnet.

Der Haupteingabeparameter dieser API ist `prompt`, optional ist `model` (optionale Werte: `default`, `remi-v1`, Standardwert: `default`), ein Ausfüllbeispiel lautet wie folgt:

![](https://cdn.acedata.cloud/p53wtj.png)

Hier lautet der eingegebene `prompt` `A song about winter`, um einen Song mit Bezug zum Winter zu generieren.

Klicke auf Ausführen, das Ergebnis lautet wie folgt:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nSnowflakes falling from the sky\nWinter's cold touch\nOh how it gets me high\nI bundle up in layers\nOh so cozy\nStepping out and feeling the frost on my nose\n\n[Chorus]\nOh\nWinter's cold touch\nIt's a season that I love so much\nSnowfall brings a feeling so divine\nWinter's cold touch\nIt's a magical time",
      "title": "Winter's Cold Touch",
      "status": "complete",
      "tags": ["dreamy, mellow, ballad"]
    },
    {
      "text": "[Verse]\nThe world is covered in a blanket of white\nIcicles hanging\nShimmering so bright\nThe chilly air fills my lungs with every breath\nWalking in the snow\nLeaving footprints behind\n\n[Chorus]\nWinter wonderland\nEverything is so bright\nWinter wonderland\nHold me through the night",
      "title": "Winter Wonderland",
      "status": "complete",
      "tags": ["dream pop, mellow, shoegaze"]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,
  "elapsed": 7.433
}
```

Wie man sehen kann, ist `data` ein Array, das jedes Mal mehrere Liedtextkandidaten zurückgibt. Dabei ist das Feld `text` jedes Elements der Liedtextinhalt, `title` ist der Titel und `tags` sind die empfohlenen Musikstil-Tags.

Nachdem wir die Liedtexte haben, können wir die [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) verwenden, um eine individuelle Songgenerierung durchzuführen.
