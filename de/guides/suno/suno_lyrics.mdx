title: "Suno Lyrics Generation API Integration Instructions"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Wenn Sie benutzerdefinierte Songs erstellen möchten, aber nicht selbst die Texte schreiben möchten, können Sie die von AceDataCloud bereitgestellte Lyrics Generation API verwenden, um Texte über einen Prompt zu generieren. Die API ist [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Der Hauptparameter der API ist `prompt`, optional `model` (optionale Werte `default`, `remi-v1`, standardmäßig `default`), ein Beispiel für die Eingabe sieht wie folgt aus:

![](https://cdn.acedata.cloud/p53wtj.png)

Hier ist unser eingegebener `prompt` `Ein Lied über den Winter`, das ein Lied über den Winter generiert.

Klicken Sie auf Ausführen, das Ergebnis sieht wie folgt aus:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Strophe]\nSchneeflocken fallen vom Himmel\nWinters kalte Berührung\nOh, wie es mich hoch bringt\nIch wickele mich in Schichten ein\nOh so gemütlich\nTritt hinaus und fühle den Frost auf meiner Nase\n\n[Refrain]\nOh\nWinters kalte Berührung\nEs ist eine Jahreszeit, die ich so sehr liebe\nDer Schneefall bringt ein Gefühl so göttlich\nWinters kalte Berührung\nEs ist eine magische Zeit",
      "title": "Winters Kalte Berührung",
      "status": "complete",
      "tags": ["träumerisch, sanft, Ballade"]
    },
    {
      "text": "[Strophe]\nDie Welt ist mit einer Decke aus Weiß bedeckt\nEiszapfen hängen\nGlitzern so hell\nDie kalte Luft füllt meine Lungen mit jedem Atemzug\nGehe im Schnee\nHinterlasse Fußabdrücke\n\n[Refrain]\nWinterwunderland\nAlles ist so hell\nWinterwunderland\nHalt mich durch die Nacht",
      "title": "Winterwunderland",
      "status": "complete",
      "tags": ["Traum-Pop, sanft, Shoegaze"]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,
  "elapsed": 7.433
}
```

Wie zu sehen ist, ist `data` ein Array, das bei jedem Aufruf mehrere Textvorschläge zurückgibt, wobei das `text`-Feld jedes Elements den Textinhalt darstellt, `title` der Titel ist und `tags` die empfohlenen Musikstil-Tags sind.

Nachdem wir die Texte haben, können wir die [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) verwenden, um benutzerdefinierte Songs zu generieren.
