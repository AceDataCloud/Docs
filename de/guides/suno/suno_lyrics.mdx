title: "Suno Liedtext-Generierung API Anweisungen"

---

Wenn Sie benutzerdefinierte Songs erstellen möchten, aber nicht selbst die Texte schreiben möchten, können Sie die von AceDataCloud bereitgestellte Liedtext-Generierungs-API verwenden, um über einen Prompt Liedtexte zu generieren. Die API ist [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/514d82dc-f7ab-4638-9f21-8b9275916b08).

Der Hauptparameter der API ist `prompt`, optional `model` (Standard ist chirp-v3), ein Beispiel für die Eingabe sieht wie folgt aus:

![](https://cdn.acedata.cloud/p53wtj.png)

Hier ist unser eingegebener `prompt` `Ein Lied über den Winter`, das ein Lied über den Winter generiert.

Klicken Sie auf Ausführen, das Ergebnis sieht wie folgt aus:

```
{
  "success": true,
  "task_id": "57e8ce3a-39cb-41a2-802f-e70a324f4d0a",
  "data": {
    "text": "[Strophe]\nSchneeflocken fallen vom Himmel\nWinters kalte Berührung\nOh, wie es mich hoch bringt\nIch wickele mich in Schichten ein\nOh so gemütlich\nTritt hinaus und fühle den Frost auf meiner Nase\nSieh\n\n[Strophe 2]\nDie Welt ist mit einer Decke aus Weiß bedeckt\nEiszapfen hängen\nGlitzern so hell\nDie kalte Luft füllt meine Lungen mit jedem Atemzug\nGehen im Schnee\nHinterlasse Fußabdrücke, die nicht zurückgelassen werden\n\n[Refrain]\nOh\nWinters kalte Berührung\nEs ist eine Jahreszeit, die ich so sehr liebe\nDer Schneefall bringt ein Gefühl so göttlich\nWinters kalte Berührung\nEs ist eine magische Zeit",
    "title": "Winters Kalte Berührung",
    "status": "complete"
  }
}
```

Man kann sehen, dass das `text` Feld von `data` die Liedtextinformationen enthält.

Nachdem wir die Liedtexte haben, können wir die [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) verwenden, um benutzerdefinierte Songs zu generieren.
