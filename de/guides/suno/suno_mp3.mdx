title: "Suno MP3 URL API Integrationsanleitung"

---

Die Suno MP3 URL API generiert einen abspielbaren Link, der mit `.mp3` endet, für bereits vorhandene Musik und ist geeignet für Szenarien, in denen alte Download-Links nicht mehr funktionieren, mobile Wiedergabe erforderlich ist oder ein neuer öffentlicher Audio-URL benötigt wird.

Der erforderliche Parameter `audio_id` ist die Audio-ID, die von der Suno Audio-Generierungs-API zurückgegeben wird. Bei jedem Aufruf wird eine unabhängige MP3-URL-Aufgabe erstellt, die die ursprüngliche Musikgenerierungsaufgabe nicht ändert und die ursprüngliche Audio-ID nicht beeinflusst.

## Synchroner Aufruf

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={
        "accept": "application/json",
        "authorization": "Bearer <YOUR_API_TOKEN>",
        "content-type": "application/json"
    },
    json={"audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f"},
    timeout=240
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["file_url"])
```

Im Erfolgsfall ist `data[0].file_url` die abspielbare Audioadresse. Die API speichert zuerst unter `https://cdn.acedata2.cloud/suno/{audio_id}.mp3`; wenn die Persistierung fehlschlägt, wird die derzeit verfügbare ursprüngliche Medienadresse zurückgegeben.

## Asynchroner Aufruf

Wenn die Bearbeitungszeit länger ist, kann `async: true` übergeben werden:

```python
submission = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={"authorization": "Bearer <YOUR_API_TOKEN>"},
    json={
        "audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f",
        "async": True
    }
).json()

export_task_id = submission["task_id"]
```

Anschließend kann über `/suno/tasks` nach `export_task_id` abgefragt werden. Es kann auch eine `callback_url` bereitgestellt werden, um das endgültige Ergebnis nach Abschluss der Aufgabe zu erhalten. Synchronantworten, Aufgabenabfragen und Rückrufe verwenden dieselbe endgültige Datenstruktur.

## Hinweise

- `audio_id` muss von einer erkennbaren Suno-Audioquelle stammen.
- MP3-URL-Aufgaben sind unabhängig von den ursprünglichen Musikgenerierungsaufgaben.
- Ein Persistierungsfehler blockiert das Ergebnis nicht und fällt auf die ursprüngliche Medienadresse zurück; bitte rechtzeitig herunterladen.
- Es wird empfohlen, dass die Geschäftseite die Ergebnisse zeitnah herunterlädt und gemäß ihrer eigenen Datenaufbewahrungsrichtlinien speichert.
