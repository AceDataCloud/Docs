title: "Suno MP3 URL API Integrationsanleitung"

---

Die Suno MP3 URL API generiert einen abspielbaren Link, der auf `.mp3` endet, für bereits vorhandene Musik und ist geeignet für Szenarien, in denen alte Download-Links nicht mehr funktionieren, mobile Wiedergabe erforderlich ist oder ein neuer öffentlicher Audio-URL benötigt wird.

Der erforderliche Parameter `audio_id` ist die Audio-ID, die von der Suno Audio-Generierungs-API zurückgegeben wird. Bei jedem Aufruf wird eine unabhängige MP3-URL-Aufgabe erstellt, die die ursprüngliche Musikgenerierungsaufgabe nicht ändert und die ursprüngliche Audio-ID nicht beeinflusst.

## Synchrone Aufrufe

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={
        "accept": "application/json",
        "authorization": "Bearer <YOUR_API_TOKEN>",
        "content-type": "application/json"
    },
    json={"audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f"},
    timeout=240
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["file_url"])
```

Im Erfolgsfall ist `data[0].file_url` die abspielbare Audioadresse. Die API wird bevorzugt auf `https://platform2.cdn.acedata.cloud/suno/{audio_id}.mp3` umspeichern; wenn das Umspeichern länger als 30 Sekunden dauert oder fehlschlägt, wird die derzeit verfügbare Quell-Audioadresse zurückgegeben.

## Asynchrone Aufrufe

Wenn die Bearbeitungszeit länger ist, kann `async: true` übergeben werden:

```python
submission = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={"authorization": "Bearer <YOUR_API_TOKEN>"},
    json={
        "audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f",
        "async": True
    }
).json()

export_task_id = submission["task_id"]
```

Anschließend kann über `/suno/tasks` nach `export_task_id` gesucht werden. Es kann auch eine `callback_url` bereitgestellt werden, um das endgültige Ergebnis nach Abschluss der Aufgabe zu erhalten. Synchrone Antworten, Aufgabenabfragen und Rückrufe verwenden dieselbe endgültige Datenstruktur.

## Hinweise

- `audio_id` muss von einer erkennbaren Suno-Audioquelle stammen.
- MP3-URL-Aufgaben sind unabhängig von der ursprünglichen Musikgenerierungsaufgabe.
- Das Umspeichern kann maximal 30 Sekunden warten; ein Timeout oder ein Fehlschlag beim Umspeichern blockiert das Ergebnis nicht und fällt auf die Quell-Audioadresse zurück.
- Es wird empfohlen, dass die Geschäftseite die Ergebnisse nach Erhalt umgehend herunterlädt und gemäß ihrer eigenen Datenaufbewahrungsrichtlinien speichert.
