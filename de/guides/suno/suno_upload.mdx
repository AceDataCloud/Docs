SUNO ermöglicht es uns, Referenzaudio für die sekundäre Kreation hochzuladen. Dieses Dokument erklärt die Integrationsmethoden der entsprechenden API.

Der normale Upload benötigt nur `audio_url`, das ist eine öffentlich zugängliche Audio-CDN-Adresse. `mode` ist standardmäßig auf `standard` gesetzt, daher sind keine Änderungen an bestehenden Aufrufen erforderlich.

Hier geben wir die `audio_url` als `https://cdn.acedata.cloud/suno_demo.mp3` ein, die eine öffentlich zugängliche CDN-Adresse ist.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Man kann sehen, dass das `audio_id` Feld in `data` die ID des nach dem Upload erstellten Songs ist.

Mit der Song-ID können wir die [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) verwenden, um benutzerdefinierte Songs zu generieren. Zum Beispiel, wenn `action` auf `upload_extend` gesetzt wird und `audio_id` die zurückgegebene Song-ID ist, können wir basierend auf dem Referenzaudio einen neuen Song generieren.

## Verbesserter Upload-Modus

Wenn der normale Upload nicht mit dem Audio umgehen kann, das Sie besitzen oder für das Sie die Erlaubnis zur Nutzung haben, können Sie `mode` auf `enhanced` setzen. In diesem Modus muss auch ein `name` mit 1 bis 100 Zeichen bereitgestellt werden, und es muss eine öffentlich zugängliche HTTPS `audio_url` verwendet werden.

Der verbesserte Upload erfolgt immer asynchron und benötigt normalerweise 2 Minuten oder länger. Eine erfolgreiche Verarbeitung verbraucht **1,87 Credits**, was ungefähr **¥1,20 pro Vorgang** entspricht; bei einer fehlgeschlagenen Verarbeitung fallen keine Kosten an.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

Die Schnittstelle gibt sofort `task_id` und `trace_id` zurück. Verwenden Sie die [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks), um den Task abzufragen. Nach erfolgreicher Verarbeitung lesen Sie die hochgeladene Audio-ID aus `response.data.audio_id`. Sie können auch eine HTTPS `callback_url` bereitstellen, um den Endstatus zu empfangen.

Die durch den verbesserten Upload erhaltene `audio_id` kann für Cover, Samples und Mashups verwendet werden. Begleitmusik und MIDI-Extraktion, vollständige Spurtrennung sowie Gesang/Begleitmusik-Trennung können weiterhin durch die Kontobeschränkungen des Audios eingeschränkt sein; nicht aufgeführte Operationen garantieren keine Unterstützung für die Nutzung über Konten hinweg. Je kürzer das Audio, desto höher ist in der Regel die Erfolgsquote der Verarbeitung.
