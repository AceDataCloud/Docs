Die Hauptfunktion der Hailuo Tasks API besteht darin, den Status der Ausführung eines Auftrags anhand der Auftrags-ID abzufragen, die über die Hailuo Videos Generation API generiert wurde.

Dieses Dokument wird die Integrationsanleitung der Hailuo Tasks API detailliert beschreiben, um Ihnen zu helfen, diese API einfach zu integrieren und ihre leistungsstarken Funktionen voll auszuschöpfen. Mit der Hailuo Tasks API können Sie den Status der Ausführung von Aufträgen der Hailuo Videos Generation API problemlos abfragen.

## Antragsprozess

Um die Hailuo Tasks API zu nutzen, müssen Sie zunächst auf die Antragsseite [Hailuo Videos Generation API](https://platform.acedata.cloud/documents/ee06377b-9185-438f-ac84-3376bcb1275e) gehen und den entsprechenden Dienst beantragen, dann kopieren Sie die Auftrags-ID der Hailuo Videos Generation API, wie im Bild gezeigt:

<p><img src="https://cdn.acedata.cloud/4f9d95.png" width="500" class="m-auto"></p>

Gehen Sie schließlich zur Tasks API-Seite [Hailuo Tasks API](https://platform.acedata.cloud/documents/4b1ccdbc-b8ed-4171-9a14-48e10970ba04), um den entsprechenden Dienst zu beantragen. Nachdem Sie die Seite betreten haben, klicken Sie auf die Schaltfläche „Acquire“, wie im Bild gezeigt:

![Antragsseite](https://cdn.acedata.cloud/rci31i.png)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur [Anmeldeseite](https://platform.acedata.cloud) weitergeleitet, die Sie zur Registrierung und Anmeldung einlädt. Nach der Anmeldung werden Sie automatisch zur aktuellen Seite zurückgeleitet.

Bei der ersten Antragstellung gibt es ein kostenloses Kontingent, mit dem Sie die API kostenlos nutzen können.

## Anfragebeispiel

Die Hailuo Tasks API kann verwendet werden, um die Ergebnisse der Hailuo Videos Generation API abzufragen. Informationen zur Verwendung der Hailuo Videos Generation API finden Sie im Dokument [Hailuo Videos Generation API](https://platform.acedata.cloud/documents/d2fc9087-2996-4573-bfe5-8b1c828fdfc7).

Wir nehmen eine von der Hailuo Videos Generation API zurückgegebene Auftrags-ID als Beispiel, um zu demonstrieren, wie man diese API verwendet. Angenommen, wir haben eine Auftrags-ID: 58cc618b-9639-4ee7-add2-d2fcf260d9a3, im Folgenden zeigen wir, wie man dies durch die Eingabe einer Auftrags-ID macht.

### Anfrageheader und Anfragekörper festlegen

**Request Headers** umfassen:

- `accept`: Gibt an, dass die Antwort im JSON-Format empfangen werden soll, hier eingetragen als `application/json`.
- `authorization`: Der Schlüssel zur API-Nutzung, der nach der Beantragung direkt ausgewählt werden kann.

**Request Body** umfasst:

- `id`: Die hochgeladene Auftrags-ID.
- `action`: Die Art der Operation für den Auftrag.

Einstellung wie im folgenden Bild gezeigt:

Es kann festgestellt werden, dass auf der rechten Seite der Seite bereits automatisch Code in verschiedenen Sprachen generiert wurde, wie im Bild gezeigt:

Einige Codebeispiele sind wie folgt:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/hailuo/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "58cc618b-9639-4ee7-add2-d2fcf260d9a3",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/hailuo/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "58cc618b-9639-4ee7-add2-d2fcf260d9a3",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Die Rückgabe enthält mehrere Felder, das Feld request ist der request body, der beim Starten des Auftrags gesendet wurde, während das Feld response der response body ist, der nach Abschluss des Auftrags zurückgegeben wird. Die Feldbeschreibung ist wie folgt.

- `request`, Informationen zur Anfrage im Videoauftrag.
- `response`, Informationen zur Rückgabe im Videoauftrag.

## Fehlerbehandlung

Bei der Verwendung der API, wenn ein Fehler auftritt, gibt die API den entsprechenden Fehlercode und die Informationen zurück. Zum Beispiel:

- `400 token_mismatched`：Ungültige Anfrage, möglicherweise aufgrund fehlender oder ungültiger Parameter.
- `400 api_not_implemented`：Ungültige Anfrage, möglicherweise aufgrund fehlender oder ungültiger Parameter.
- `401 invalid_token`：Nicht autorisiert, ungültiger oder fehlender Autorisierungstoken.
- `429 too_many_requests`：Zu viele Anfragen, Sie haben das Rate-Limit überschritten.
- `500 api_error`：Interner Serverfehler, etwas ist auf dem Server schiefgelaufen.

### Fehlerantwort Beispiel

```json
{
  "success": false,
  "error": {

    "message": "Abruf fehlgeschlagen"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
