Dieser Artikel beschreibt die API zur asynchronen Abfrage von Captcha-Aufgaben `POST /captcha/tasks`. Wenn Sie bei der Verwendung einer beliebigen Captcha-Schnittstelle (Token-Serie oder Erkennungsserie) `async: true` übergeben, gibt die Schnittstelle sofort eine `task_id` zurück, die Sie dann verwenden können, um diese Schnittstelle abzufragen und das endgültige Ergebnis zu erhalten. Dies ist geeignet für Szenarien wie Multi-Solver-Rotation: Nachdem Sie die Aufgabe eingereicht haben, erhalten Sie sofort die `task_id`, um andere Solver zu beauftragen und später das Ergebnis abzurufen.

> 📘 Vollständige interaktive Dokumentation (einschließlich Online-Debugging): [API zur Abfrage von Captcha-Aufgaben →](https://platform.acedata.cloud/documents/captcha-tasks)

## Antragsprozess

Um diese Schnittstelle zu verwenden, gehen Sie zuerst zur [Ace Data Cloud Konsole](https://platform.acedata.cloud/console/applications), um Ihr API-Token zu erhalten, das Sie als Backup aufbewahren. **Ein API-Token reicht aus, um alle Dienste der Plattform zu nutzen, es ist nicht erforderlich, für jeden Dienst separat zu beantragen.**

## Grundlegende Nutzung

### Schritt 1: Aufgabe asynchron erstellen

Übergeben Sie in der Anfrage an eine beliebige Captcha-Schnittstelle `async: true`, die Schnittstelle gibt sofort eine `task_id` zurück (HTTP 201), ohne zu blockieren und zu warten:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/token/recaptcha2' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-",
  "website_url": "https://www.google.com/recaptcha/api2/demo",
  "async": true
}'
```

```json
{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

### Schritt 2: Ergebnisse mit task_id abfragen

Verwenden Sie die in Schritt 1 zurückgegebene `task_id`, um `POST /captcha/tasks` abzufragen (empfohlen alle 3-5 Sekunden):

```shell
curl -X POST 'https://api.acedata.cloud/captcha/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002"
}'
```

Während der Verarbeitung wird `status: processing` zurückgegeben:

```json
{ "success": true, "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002", "status": "processing" }
```

Nach Abschluss der Verarbeitung wird `status: ready` und das entsprechende Ergebnisfeld zurückgegeben – die Struktur der Felder ist identisch mit der im synchronen Modus:

- **Token-Serie** (hcaptcha, recaptcha2, recaptcha3) gibt `token` zurück:

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "ready",
  "token": "03AFcWeA5kjJyDQ9S1a9UYimR6nuxnpEnAs5x2Pixao0dXZhMB......"
}
```

- **Erkennungs-Kategorie** (recognition/recaptcha2, recognition/hcaptcha) gibt `solution` zurück; **recognition/image2text** gibt `text` zurück.

`/captcha/tasks` ist für alle Captcha-Schnittstellen (Token- und Erkennungsserie) allgemein gültig, Sie können dasselbe `task_id` zur Abfrage verwenden.

## Abrechnungsinformationen

Im asynchronen Modus werden die Erstellung von Aufgaben und die Abfrage von „verarbeitend“ nicht berechnet; **es wird nur einmal berechnet, wenn das Ergebnis erfolgreich abgerufen wird** (zu den gleichen Preisen wie im synchronen Modus). Daher entstehen beim Abbrechen von noch nicht abgeschlossenen Aufgaben während der Rotation keine Kosten.

## Fehlerbehandlung

Wenn Sie diese Schnittstelle aufrufen und auf einen Fehler stoßen, wird der entsprechende Fehlercode und die Fehlermeldung zurückgegeben. Zum Beispiel:

- `400 invalid_request`: Anfrage fehlt der `task_id`-Parameter.
- `401 invalid_token`: Nicht autorisiert, der Autorisierungs-Token ist ungültig oder fehlt.
- `404 not_found`: `task_id` existiert nicht oder gehört nicht zum aktuellen Konto.

### Beispiel für eine Fehlerantwort

```json
{
  "success": false,
  "error": {
    "code": "not_found",
    "message": "Aufgabe nicht gefunden"
  }
}
```
