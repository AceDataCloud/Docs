Dieser Artikel beschreibt eine hCaptcha Bildverarbeitungs-API-Integrationsanleitung, die es ermöglicht, durch Benutzereingaben und hCaptcha-Bildverifizierung die Koordinaten des kleinen Bildes zurückzugeben, das angeklickt werden muss, um die Verifizierung abzuschließen.

## Antragsprozess

Um die hCaptcha Bildverarbeitungs-API zu nutzen, gehen Sie zuerst zur [Ace Data Cloud Konsole](https://platform.acedata.cloud/console/applications), um Ihr API-Token zu erhalten und es für zukünftige Verwendung zu speichern.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach Abschluss werden Sie automatisch zur aktuellen Seite zurückgeleitet.

**Ein API-Token reicht aus, um alle Dienste der Plattform zu nutzen, es ist nicht erforderlich, für jeden Dienst separat zu beantragen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, um es kostenlos auszuprobieren; wenn das Kontingent erschöpft ist, können Sie im [Dashboard](https://platform.acedata.cloud/console/coin) Ihr Guthaben aufladen.

> 📘 Vollständige Dokumentation: [hCaptcha Bildverarbeitungs-API →](https://platform.acedata.cloud/documents/recognition-hcaptcha-integration)

## Grundlegende Nutzung

Zuerst sollten Sie die grundlegende Nutzung verstehen, indem Sie das hCaptcha-Bild eingeben, das verarbeitet werden soll, um das Ergebnis zu erhalten. Zuerst müssen Sie ein `queries`-Feld übergeben, das das spezifische hCaptcha-Bild enthält. Wir müssen dieses Bild von einer Website mit hCaptcha verifizieren, ein Beispiel-Link zur Website ist: `https://democaptcha.com/demo-form-eng/hcaptcha.html`, klicken Sie auf das Kontrollkästchen, um das vollständige hCaptcha-Bild anzuzeigen, wie im folgenden Bild gezeigt:

<p><img src="https://cdn.acedata.cloud/xryo59.png" width="500" className="m-auto" /></p>

Das `queries`-Feld ist der Screenshot des oben genannten hCaptcha-Bildes. Die Bildgröße sollte 100 KB nicht überschreiten. Außerdem müssen Sie den Bereich, auf den der rote Pfeil im Bild zeigt, ebenfalls screenshotten und das Bild selbst komprimieren sowie in Base64 kodieren, wie im folgenden Bild gezeigt:

<p><img src="https://cdn.acedata.cloud/g8ikkb.png" width="500" className="m-auto" /></p>

Zusätzlich müssen Sie den mit dem hCaptcha-Bild verbundenen Erkennungsinhalt als Parameter `question` eingeben. Dies unterstützt die Übersetzung zwischen Chinesisch und Englisch, und Sie können den relevanten Erkennungsinhalt direkt eingeben. Aus dem oben genannten Bild ist zu erkennen, dass der `question`-Eingang `Please click on the UNIQUE object among the others.` sein sollte. Der spezifische Inhalt ist wie folgt:

<p><img src="https://cdn.acedata.cloud/empncr.png" width="500" className="m-auto" /></p>

Hier haben wir die Request-Header festgelegt, einschließlich:

- `accept`: In welchem Format Sie die Antwort erhalten möchten, hier eingetragen als `application/json`, also im JSON-Format.
- `authorization`: Der Schlüssel zur API-Nutzung, den Sie nach der Beantragung direkt auswählen können.

Zusätzlich haben wir den Request-Body festgelegt, einschließlich:

- `queries`: Liste der Base64-kodierten hCaptcha-Bilder.
- `question`: Parameter für den Erkennungsinhalt des hCaptcha-Bildes, unterstützt die direkte Eingabe in Chinesisch und Englisch.

Nach der Auswahl können Sie sehen, dass auf der rechten Seite der entsprechende Code generiert wurde, wie im Bild gezeigt:

<p><img src="https://cdn.acedata.cloud/bww9b0.png" width="500" className="m-auto" /></p>

Klicken Sie auf die Schaltfläche „Try“, um einen Test durchzuführen. Wie im obigen Bild gezeigt, haben wir folgendes Ergebnis erhalten:

```json
{
  "solution": {
    "label": "Please click on the UNIQUE object among the others",
    "box": [
      "360",
      "276"
    ],
    "confidences": 0.6354503631591797
  }
}
```

Die Rückgabe hat mehrere Felder, die wie folgt beschrieben werden:

- `solution`, das Ergebnis der hCaptcha-Bildverarbeitungsaufgabe.
    - `label`, der erkannte Inhalt des hCaptcha-Bildes.
    - `box`, die Positionsinformationen des Erkennungsergebnisses des hCaptcha-Bildes, die aus den Koordinaten des Bildes bestehen.
    - `confidences`, die Vertrauenswürdigkeit des Erkennungsergebnisses des hCaptcha-Bildes.
- `started_at`, `finished_at`: Die Zeit, zu der die Anfrage bearbeitet und das Ergebnis erzeugt wurde, Unix-Zeitstempel (Sekunden, Fließkomma).
- `elapsed`: Die gesamte Bearbeitungszeit (Sekunden).

Wir haben das Verifizierungsergebnis des hCaptcha-Bildes erhalten. Wir müssen nur die Koordinateninformationen aus dem `box`-Feld verwenden, um auf den entsprechenden Bereich des hCaptcha-Bildes zu klicken, um die Verifizierung zu bestehen.

Im Folgenden wird beschrieben, wie man durch die Positionsinformationen des `box`-Feldes klicken kann. Zuerst wird ein rechtwinkliges Koordinatensystem für das hochgeladene hCaptcha-Bild erstellt, wobei der Ursprung in der linken unteren Ecke des Bildes liegt. 360 ist die entsprechende x-Koordinate und 276 die entsprechende y-Koordinate. Wir müssen nur simulieren, dass wir auf die entsprechenden Koordinaten des hCaptcha-Bildes klicken, wie im folgenden Bild gezeigt:

<p><img src="https://cdn.acedata.cloud/4ykvbl.png" width="500" className="m-auto" /></p>

Wenn Sie den entsprechenden Integrationscode generieren möchten, können Sie ihn direkt kopieren, zum Beispiel ist der CURL-Code wie folgt:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/hcaptcha' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "question": "Please click on the UNIQUE object among the others.",
  "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"]
}'
```

Der Python-Integrationscode sieht wie folgt aus:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/hcaptcha"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "question": "Please click on the UNIQUE object among the others.",
    "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asynchroner Modus (async)

Standardmäßig ist die API synchron blockierend: Eine Anfrage wartet, bis das Erkennungsergebnis verarbeitet ist, bevor sie zurückgegeben wird. Wenn Sie mehrere Solver-Rotationen durchführen und „nach der Einreichung der Aufgabe sofort die task_id erhalten möchten, um andere Solver zu planen und später das Ergebnis abzurufen“, können Sie im Anfragekörper `async: true` übergeben.

Wenn Sie `async: true` übergeben, gibt die Schnittstelle sofort eine `task_id` zurück, ohne zu blockieren:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/hcaptcha' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "question": "Please click on the UNIQUE object among the others.",
  "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"],
  "async": true
}'
```
```json
{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

Anschließend verwenden Sie die `task_id`, um `POST /captcha/tasks` abzufragen (empfohlen alle 3-5 Sekunden), um das Ergebnis zu erhalten:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002"
}'
```

Während der Verarbeitung wird `status: processing` zurückgegeben:

```json
{ "success": true, "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002", "status": "processing" }
```

Nach Abschluss der Verarbeitung wird `status: ready` und das Erkennungsergebnis `solution` zurückgegeben (die Struktur der Felder ist identisch mit dem synchronen Modus):

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "ready",
  "solution": {
    "label": "Bitte klicken Sie auf das EINZIGARTIGE Objekt unter den anderen",
    "box": ["360", "276"],
    "confidences": 0.6354503631591797
  }
}
```

Abrechnungsbeschreibung: Im asynchronen Modus werden die Erstellung von Aufgaben und die Abfrage „in Bearbeitung“ nicht berechnet; **es wird nur einmal berechnet, wenn das Erkennungsergebnis erfolgreich abgerufen wird** (entspricht dem Preis im synchronen Modus). Daher entstehen beim Abbrechen von noch nicht abgeschlossenen Aufgaben während der Abfrage keine Kosten. `/captcha/tasks` ist für alle CAPTCHA-Schnittstellen (Token und Erkennungsserie) allgemein und kann mit derselben `task_id` abgefragt werden.

## Fehlerbehandlung

Wenn beim Aufruf der API ein Fehler auftritt, gibt die API den entsprechenden Fehlercode und die Informationen zurück. Zum Beispiel:

- `400 token_mismatched`: Ungültige Anfrage, möglicherweise aufgrund fehlender oder ungültiger Parameter.
- `400 api_not_implemented`: Ungültige Anfrage, möglicherweise aufgrund fehlender oder ungültiger Parameter.
- `401 invalid_token`: Unbefugt, ungültiger oder fehlender Autorisierungstoken.
- `429 too_many_requests`: Zu viele Anfragen, Sie haben das Rate-Limit überschritten.
- `500 api_error`: Interner Serverfehler, etwas ist auf dem Server schiefgelaufen.

### Beispiel für eine Fehlerantwort

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Abruf fehlgeschlagen"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
