`POST https://api.acedata.cloud/webextrator/extract`

Die WebExtrator Smart-Extraction-API wandelt eine URL in **typisierte strukturierte Ergebnisse** um — Artikel, Produkte,
Rezepte, Videos, Diskussionen, Stellenangebote und mehr — jeweils zusammen mit bereinigtem Markdown und reinem Text. Wenn du "saubere strukturierte Daten" statt rohem HTML benötigst, ist dies die richtige Schnittstelle.

## Antragsprozess

Um den WebExtrator-Dienst zu nutzen, gehen Sie zuerst zur [Ace Data Cloud Konsole](https://platform.acedata.cloud/console/applications), um Ihr API-Token zu erhalten, das Sie für später aufbewahren.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, die Sie zur Registrierung und Anmeldung einlädt. Nach Abschluss werden Sie automatisch zur aktuellen Seite zurückgeleitet.

**Ein API-Token reicht aus, um auf alle Dienste der Plattform zuzugreifen, ohne dass für jeden Dienst separat beantragt werden muss.** Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, um es kostenlos auszuprobieren; wenn das Kontingent erschöpft ist, können Sie im [Dashboard](https://platform.acedata.cloud/console/coin) Ihr allgemeines Guthaben aufladen.

> 📘 Vollständige Dokumentation: [WebExtrator-Dienstseite →](https://platform.acedata.cloud/service/webextrator)

## Authentifizierung

```
Authorization: Bearer YOUR_API_KEY
Content-Type:  application/json
```

## Anfrageparameter

Extract akzeptiert **alle** Parameter der [Render API](/de/guides/webextrator/webextrator_render)
（`url`、`user_agent`、`timeout`、`wait_until`、`delay`、`wait_for_selector`、
`block_resources`、`headers`、`cookies`、`callback_url`、`bypass_cache`、
`cache_ttl_seconds`、`async`）sowie zwei Extract-spezifische Felder:

| Feld | Typ | Erforderlich | Standard | Beschreibung |
|------|------|:----:|------|------|
| `expected_type` | enum | ❌ | Automatische Erkennung | Hinweis zum Seitentyp: `product` / `article` / `general`. Gibt den erwarteten Ergebnistyp an. |
| `enable_llm` | boolean | ❌ | `false` | Ermöglicht den Aufruf des LLM-Extraktors, wenn schema.org keine Treffer liefert. Auf Seiten ohne JSON-LD wie Amazon / HN / Greenhouse muss dies aktiviert werden, um typisierte Ergebnisse zu erhalten. |

### Felder der obersten Ebene

| Feld | Typ | Beschreibung |
|------|------|------|
| `kind` | string | Immer `"extract"`. |
| `url` | string | Die von Ihnen übermittelte URL. |
| `finalUrl` | string | Die endgültige URL nach Weiterleitungen. |
| `contentType` | enum | Seitentyp: `product` / `article` / `general`. |
| `title` | string | Seitentitel. |
| `description` | string? | Seitenbeschreibung oder Zusammenfassung. |
| `byline` | string? | Autor, Kanal oder Unternehmen. |
| `language` | string? | `<html lang>`.  |
| `siteName` | string? | `og:site_name`.  |
| `publishedAt` | string? | Veröffentlichungszeitpunkt im ISO-8601-Format. |
| `images` | string[] | Bis zu 50 `<img src />`, in absolute URLs aufgelöst, dedupliziert und `data:`-URIs verworfen. |
| `links` | string[] | Bis zu 100 externe Links, gefiltert nach Fragmenten / `javascript:` / `mailto:` / `tel:`. |
| `markdown` | string | Der Markdown-Inhalt der Seite. |
| `text` | string | Der Klartext der Seite. |
| `structured` | object | Vollständiges strukturiertes Ergebnis, siehe unten. |
| `rawSignals` | object | Diagnoseinformationen zum Debuggen. |
| `cached` | boolean? | Bei einem Cache-Treffer ist dies `true`. |
| `cacheStoredAt` | number? | Unix-Zeitstempel in Millisekunden, zu dem der Cache-Eintrag erstmals geschrieben wurde. |

### `data.structured`-Unterfelder

| Unterfeld | Wann es erscheint | Beschreibung |
|--------|---------|------|
| `schemaOrg` | Immer | `{ primary, breadcrumbs, all }`. `primary` ist die typisierte Entität mit der höchsten Priorität; falls nicht gefunden, ist es `null`. |
| `openGraph` | Immer | `{ title, description, image, type }`, abgeleitet von `<meta property="og:*" />`. |
| `jsonLd` | Immer | Rohes JSON-Array aller `<script type="application/ld+json">`-Blöcke. |
| `llm` | Wenn das LLM ausgeführt wurde und erfolgreich war | `{ kind, data, model, promptCharCount }`, typisiertes Ergebnis. |
| `llmError` | Wenn das LLM ausgeführt wurde, aber fehlgeschlagen ist | `{ kind, error, model }`, die Anfrage kann weiterhin andere extrahierte Felder zurückgeben. |
| `amazon` | Wenn die URL `amazon.*` ist | Legacy-Amazon-Erweiterungsergebnis; für neue Integrationen typisierte Ergebnisse verwenden. |

## schema.org-Ergebnistypen

`structured.schemaOrg.primary` unterstützt die folgenden Ergebnistypen:

| schema.org-Typ | kind | Ausgabefelder |
|----------------|----------|----------|
| `Product` | product | `name, sku, gtin, model, color, brand, url, images, offer.{price,currency,availability,condition,seller}, rating.{value,count}, reviews[], properties[]` |
| `Recipe` | recipe | `name, description, image, datePublished, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords, recipeCategory, recipeCuisine` |
| `VideoObject` | video | `name, description, thumbnailUrl, uploadDate, duration, embedUrl, contentUrl, channel, interactionCount` |
| `JobPosting` | job | `title, description, datePosted, validThrough, hiringOrganization, jobLocation, baseSalary, employmentType` |
| `Event` (einschließlich `*Event`) | event | `name, description, startDate, endDate, location.{name,address}, organizer, offer.{url,price,currency}` |
| `Article` / `NewsArticle` / `BlogPosting` / `ScholarlyArticle` / `TechArticle` / `Report` / `*NewsArticle` | article | `subtype, headline, description, datePublished, dateModified, author, publisher, image[], url, sameAs[]` |
| `FAQPage` | faq | `questions[{question, answer}]` |
| `BreadcrumbList` | (an sibling angehängt) | Wird immer in `structured.schemaOrg.breadcrumbs[]` ausgegeben, niemals als primary. |

## LLM-Ergebnistypen

Wenn `enable_llm: true` und die Seite keine verfügbaren schema.org-strukturierten Daten enthält, können Extraktionsergebnisse der folgenden Typen zurückgegeben werden:

| Kind | Pflichtfelder | Optionale Felder |
|------|---------|---------|
| `article` | `headline` | `description, byline, publishedAt, language, topics[], sections[{heading,summary}]` |
| `product` | `name` | `description, brand, sku, price, currency, availability, rating.{value,count}, bullets[], specifications[{name,value}]` |
| `discussion` | `title` | `author, postedAt, points, commentCount, body, url` |
| `recipe` | `name` | `description, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords[]` |
| `video` | `name` | `description, channel, uploadDate, duration, viewCount, likeCount, thumbnailUrl, transcript` |
| `job` | `title` | `description, company, location, remote, employmentType, datePosted, validThrough, salaryMin, salaryMax, salaryCurrency, salaryPeriod, responsibilities[], qualifications[]` |

## Cache

Identische URL, Anfrageparameter, `cookies` und `headers` können Cache-Ergebnisse wiederverwenden; `async`, `bypass_cache` und `cache_ttl_seconds` werden verwendet, um die Ausführungsweise und das Cache-Verhalten zu steuern.

| Feld | Effekt |
|------|------|
| `bypass_cache: true` | Lesevorgang überspringen; das Ergebnis dieser Anfrage wird weiterhin in den Cache geschrieben und kann bei einer identischen Anfrage beim nächsten Mal getroffen werden. |
| `cache_ttl_seconds: 0` | Diese Antwort wird **nicht zwischengespeichert**. |
| `cache_ttl_seconds: N` | Benutzerdefinierte TTL für diesen Eintrag (Standard: 3600 Sekunden). |

Antworten aus dem Cache enthalten `data.cached: true` und `data.cacheStoredAt: <unix-ms>`.

## Asynchroner Modus und Rückruf

Setzen Sie `async: true`, um in den asynchronen Modus zu wechseln (das Bereitstellen von `callback_url` führt ebenfalls automatisch dazu). Die Plattform gibt sofort zurück (HTTP 200):

```json
{
  "success": true,
  "task_id": "550e8400-...",
  "trace_id": "6ba7b810-...",
  "started_at": 1777717800.123
}
```

Wenn die Aufgabe abgeschlossen ist, wird das vollständige Envelope an Ihre `callback_url` (sofern konfiguriert) `POST` gesendet. Sie können auch später aktiv über [`/webextrator/tasks`](/de/guides/webextrator/webextrator_tasks) abfragen.

## Beispiel

### 1. Wikipedia Artikel (schema.org Treffer, kein LLM benötigt)

```bash
curl -X POST https://api.acedata.cloud/webextrator/extract \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://en.wikipedia.org/wiki/Diffbot",
    "expected_type": "article"
  }'
```

`data.structured.schemaOrg.primary` Schlüssel-Felder:
```json
{
  "kind": "article",
  "subtype": "Artikel",
  "headline": "Amerikanisches Unternehmen für maschinelles Lernen und Wissensmanagement",
  "datePublished": "2007-08-08T05:47:27Z",
  "dateModified": "2025-07-10T20:42:45Z",
  "author": { "name": "Beitragende zu Wikimedia-Projekten", "type": "Organisation" },
  "publisher": { "name": "Wikimedia Foundation, Inc." }
}
```

### Python (requests)

```python
import os, requests

API_KEY = os.environ["ACEDATA_API_KEY"]

resp = requests.post(
    "https://api.acedata.cloud/webextrator/extract",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "url": "https://en.wikipedia.org/wiki/Diffbot",
        "expected_type": "article",
    },
    timeout=120,
)
resp.raise_for_status()
data = resp.json()["data"]

primary = (data.get("structured") or {}).get("schemaOrg", {}).get("primary")
print("contentType:", data["contentType"])
print("title:      ", data["title"])
print("byline:     ", data.get("byline"))
print("publishedAt:", data.get("publishedAt"))
if primary and primary["kind"] == "article":
    print("headline:    ", primary["headline"])
    print("dateModified:", primary.get("dateModified"))
```

### Node.js (fetch)

```js
const apiKey = process.env.ACEDATA_API_KEY;

const res = await fetch('https://api.acedata.cloud/webextrator/extract', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${apiKey}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://www.allrecipes.com/recipe/16354/easy-meatloaf/',
  }),
});
const { data } = await res.json();
const recipe = data?.structured?.schemaOrg?.primary;
console.log(recipe.name, recipe.cookTime, recipe.ingredients.length, 'Zutaten');
```

## Hinweise und Fallstricke

- **Übergeben Sie `expected_type`, wenn ein Seitentyp angegeben werden muss.** Verwenden Sie beispielsweise `article` für Artikelseiten und `product` für Produktseiten.
- **`enable_llm: true` ist auf Seiten kostenlos, die mit schema.org übereinstimmen.** Das LLM wird nur aufgerufen, wenn schema.org
  kein primary hat, daher ist es sicher, dies standardmäßig aktiviert zu lassen.
- **Prüfen Sie beim Debugging zuerst `rawSignals.hasJsonLd`.** Wenn es `true` ist, aber `structured.schemaOrg.primary`
  `null` ist, bedeutet dies, dass `@type` der Seite derzeit nicht unterstützt wird. Sie können uns Feedback geben.
- **`structured.llmError` ist rein informativ.** Die Anfrage kann weiterhin erfolgreich andere extrahierte Felder zurückgeben. Prüfen Sie
  `llmError.error`, um die Ursache zu ermitteln (Timeout, Fehler beim JSON-Parsing, Fehler bei der Strukturvalidierung).
- **`links[]` auf Nicht-Artikelseiten wird nicht nach Relevanz sortiert.** Es wird nur nach dem Prinzip „maximal 100 Einträge + ungültige Protokolle herausfiltern“
  bestmöglich bereinigt.
- **Auch Cache-Treffer werden berechnet.**
