Maestro ist eine **Agent-native** Schnittstelle zur Videoproduktion: Sie beschreiben das gewünschte Video mit einem natürlichen Sprach-`prompt` (optional können Sie mit `file_urls` Referenzbilder / -videos / -audios anhängen), und ein kopfloser „KI-Regisseur“ erledigt automatisch Themenauswahl, Drehbucherstellung, Bildgenerierung, Vertonung, Hintergrundmusik, Komposition und Rendering. Schließlich wird ein fertiges Video mit Untertiteln erstellt und auf das CDN hochgeladen.

Dieser Artikel stellt die Anleitung zur Integration der Maestro-API für die Videogenerierung ausführlich vor, um Ihnen zu helfen, diese API schnell zu integrieren und ihre Funktionen vollständig zu nutzen.

Dies ist eine **asynchrone Aufgabe**-Schnittstelle: Nach der Übermittlung wird sofort `task_id` zurückgegeben. Anschließend erhalten Sie die Ergebnisse durch Abfragen über die [Maestro-Aufgabenabfrage-API](/de/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (Abfragen sind kostenlos und werden nicht berechnet). Um auf einem vorhandenen Video weiter zu iterieren, können Sie `action: remix` / `edit` / `extend` zusammen mit `ref_task_id` verwenden.

## Antragsprozess

Um die Maestro-API für die Videogenerierung zu verwenden, rufen Sie zunächst in der [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications) Ihren API-Token ab und bewahren Sie ihn als Reserve auf.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Falls Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet und zur Registrierung und Anmeldung aufgefordert. Nach Abschluss kehren Sie automatisch zu dieser Seite zurück.

**Ein API-Token kann alle Dienste der Plattform aufrufen; Sie müssen ihn nicht für jeden Dienst separat beantragen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, das Sie kostenlos ausprobieren können; bei unzureichendem Kontingent können Sie in der [Konsole](https://platform.acedata.cloud/console/coin) ein allgemeines Guthaben aufladen.

> 📘 Vollständige Dokumentation: [Maestro-API für die Videogenerierung →](https://platform.acedata.cloud/documents/maestro-videos)

## Grundlegende Verwendung

`POST https://api.acedata.cloud/maestro/videos`

Für die grundlegendste Verwendung müssen Sie nur einen natürlichen Sprach-`prompt` übergeben. Der KI-Regisseur entscheidet automatisch über Drehbuch, Bildmaterial, Vertonung und Schnitt. Hier sehen wir uns zunächst die einzurichtenden Request-Header und den Request-Body an.

**Request Headers** umfassen:

- `accept`: In welchem Format Sie das Antwortergebnis erhalten möchten; tragen Sie hier `application/json`, also das JSON-Format, ein.
- `authorization`: Der Schlüssel zum Aufrufen der API, den Sie nach der Beantragung direkt aus der Auswahlliste wählen können.
- `content-type`: Das Format des Request-Bodys; tragen Sie hier `application/json` ein.

**Request Body** umfasst hauptsächlich:

- `prompt`: Beschreiben Sie das zu erstellende Video in natürlicher Sprache (Thema, was gezeigt werden soll, Stil, Zielgruppe).
- `langs`: Array der Sprache des fertigen Videos; übergeben Sie jedes Mal nur eine Sprache, z. B. `["zh-cn"]`; Standardwert ist `["zh-cn"]`.
- `aspect`: Bildseitenverhältnis, `9:16` (Standard) / `16:9` / `1:1`.
- `duration`: Ziellänge (Sekunden), Standardwert 30.

Alle Felder des Request-Bodys sind in der folgenden Tabelle aufgeführt:

| Feld            | Typ       | Erforderlich  | Beschreibung                                                                                                                                                                                                                                    |
| ------------- | -------- | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Ja   | Beschreiben Sie das zu erstellende Video in natürlicher Sprache (Thema, was gezeigt werden soll, Stil, Zielgruppe). Drehbuch, Bildmaterial, Vertonung und Schnitt werden alle von der KI bestimmt                                                                                                                                                                                      |
| `action`      | string   | Nein   | `generate` (Standard, neues Video generieren) / `remix` / `edit` / `extend` (auf einem vorhandenen Video iterieren, muss zusammen mit `ref_task_id` verwendet werden)                                                                                                                                                         |
| `ref_task_id` | string   | Nein   | Erforderlich, wenn `action` remix / edit / extend ist: die historische Aufgaben-`task_id` als Ausgangspunkt                                                                                                                                                                            |
| `file_urls`   | string[] | Nein   | Referenzmedien (Bild- / Video- / Audio-URL), beispielsweise Produktbilder oder Logos, die im Bild erscheinen sollen, oder Materialclips, denen Untertitel hinzugefügt werden sollen                                                                                                                                                                                      |
| `langs`       | string[] | Nein   | Sprache des fertigen Videos; jedes Mal kann nur eine Sprache übergeben werden, z. B. `["zh-cn"]`; Standardwert ist `["zh-cn"]`                                                                                                                                                                                             |
| `aspect`      | string   | Nein   | `9:16` (Standard) / `16:9` / `1:1`, einheitliche Ausgabe mit 1080p/30fps                                                                                                                                                                                           |
| `duration`    | int      | Nein   | Ziellänge (Sekunden), Standardwert 30, unterstützt **5–300 Sekunden**. Die Abrechnung erfolgt nach der tatsächlichen Länge des fertigen Videos, überschreitet jedoch nicht die angeforderte Länge                                                                                                                                                                                      |
| `scenario`    | string   | Nein   | Videotyp: `auto` / `narrated` / `captions` / `avatar` / `drama`. Für `captions` muss ein Quellvideo übergeben werden, für `avatar` ein Porträt                                                                                                                                             |
| `style`       | string   | Nein   | Voreinstellung für den visuellen Stil: `auto` (Standard) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`; freier Text wird ebenfalls als weicher Hinweis akzeptiert. Orthogonal zu `scenario`, verändert das Routing nicht          |
| `voice`       | string   | Nein   | Sprecherstimme (sprachunabhängig, sprachübergreifend universell): `auto` (Standard) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`; unterstützt auch 32-stellige hexadezimale Stimm-`reference_id`; anderer freier Text ist keine gültige Stimm-ID |

Nachfolgend wird dies anhand eines konkreten Beispiels demonstriert. Angenommen, wir möchten ein chinesisches, vertikales, 20-sekündiges populärwissenschaftliches Kurzvideo generieren. Der entsprechende CURL-Code lautet:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

Der entsprechende Python-Code lautet:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Klicken Sie auf Ausführen; Sie werden feststellen, dass Sie sofort ein Ergebnis wie das folgende erhalten:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Die Felder des Rückgabeergebnisses werden wie folgt vorgestellt:
- `success`: Ob diese Aufgabe erfolgreich übermittelt wurde.
- `task_id`: Die ID dieser Videogenerierungsaufgabe, die anschließend für die Abfrage der Ergebnisse über die [Maestro-Aufgabenabfrage-API](/de/guides/maestro/maestro_tasks) verwendet wird.
- `trace_id`: Die Tracking-ID dieser Anfrage, die bei Problemen dem technischen Support zur Fehlerlokalisierung bereitgestellt werden kann.

Da die Videoproduktion relativ zeitaufwendig ist, gibt die Schnittstelle hier **sofort `task_id` zurück** und wartet nicht, bis das Video-Rendering abgeschlossen ist. Anschließend muss `task_id` verwendet werden, um die Ergebnisse abzufragen. Details finden Sie im Abschnitt „Ergebnis abrufen“.

## Videotyp und Stil angeben (scenario / style)

Wenn `scenario` nicht übergeben wird, erfolgt die automatische Bestimmung durch die KI (entspricht `auto`); wenn das Video auf einen bestimmten Typ festgelegt werden soll, übergeben Sie ihn explizit. Um beispielsweise ein **Kurzdrama im Hochformat** zu erstellen, können Sie Folgendes angeben:

- `scenario`: Videotyp, hier auf `drama` gesetzt (Kurzdrama mit Charakteren + Dialogen).
- `style`: Visueller Stil, hier auf `cinematic` gesetzt (filmische Qualität).

Der CURL-Code für das Ausfüllbeispiel lautet wie folgt:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Gängige Kombinationsmöglichkeiten:

- Erklär-Kurzfilm: `scenario: "narrated"`.
- Automatische Untertitel: `scenario: "captions"`, das Quellvideo muss über `file_urls` übergeben werden.
- Digitaler Mensch / Sprechvideo: `scenario: "avatar"`, ein Porträtbild muss über `file_urls` übergeben werden.
- Kurzdrama: `scenario: "drama"` (Charaktere + Dialoge).
- `style` ist eine Voreinstellung für den visuellen Stil (z. B. `modern` / `neon` / `luxury`), die den Typ nicht verändert und nur den visuellen Eindruck beeinflusst.
- `voice` wird verwendet, um die Stimmfarbe der Erzählstimme anzugeben (z. B. `warm-female` / `deep-male`), unabhängig von der Sprache und sprachübergreifend verwendbar.

Das Rückgabeergebnis entspricht der „Grundlegenden Verwendung“ und gibt ebenfalls sofort `task_id` zurück.

## Sprache des fertigen Videos

Eine Aufgabe liefert nur ein fertiges Video in einer Sprache. `langs` darf nur einen Sprachcode enthalten, z. B. `["zh-cn"]` oder `["en"]`; bei mehreren Sprachen wird 400 zurückgegeben. Wenn Videos in unterschiedlichen Sprachen benötigt werden, erstellen Sie bitte separate Aufgaben. Die Sprachauswahl verändert den Preis pro Sekunde nicht.

## Auf bestehenden Videos iterieren (remix / edit / extend)

Durch Übergabe von `action` und `ref_task_id` der vorherigen Aufgabe können Sie inkrementelle Änderungen auf Grundlage des ursprünglichen Projekts vornehmen (z. B. „Den Titel der zweiten Szene ändern“, „Eine andere Synchronstimme verwenden“, „Das Gesamtbild abdunkeln“). Kleine Änderungen sind schnell, bei großen Änderungen wird neu erstellt:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: Auf Grundlage der ursprünglichen Videostruktur neu interpretieren (Thema beibehalten, Darstellung anpassen).
- `edit`: Bestimmte lokale Bereiche detailliert bearbeiten (z. B. Titel, Synchronstimme oder Farbgebung ändern).
- `extend`: Inhalte auf Grundlage des ursprünglichen Videos erweitern.

Auch das Rückgabeergebnis gibt sofort eine neue `task_id` zurück, mit der das iterierte fertige Video durch Abfrage abgerufen werden kann.

## Ergebnis abrufen

Da die Videoproduktion relativ zeitaufwendig ist, gibt diese Schnittstelle nach der Übermittlung sofort `task_id` zurück. Sie müssen diese verwenden, um die Ergebnisse über die [Maestro-Aufgabenabfrage-API](/de/guides/maestro/maestro_tasks) abzufragen:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Nach Abschluss der Aufgabe wird eine Information zum fertigen Video zurückgegeben (im Array `variants`). `status` durchläuft `pending → planning → producing → succeeded` (oder `failed`), **die Abfrage ist kostenlos und verbraucht keine Credits**. Das vollständige Antwortformat und die Abfrage der Verlaufsliste finden Sie in der [Integrationsanleitung für die Maestro-Aufgabenabfrage-API](/de/guides/maestro/maestro_tasks).

## Abrechnung

**Nach erfolgreicher Aufgabe erfolgt die Abrechnung nach der tatsächlichen Dauer des gelieferten fertigen Videos; bei einem Fehlschlag fallen keine Kosten an.** Die Abrechnungsdauer wird in ganzen Sekunden berechnet und überschreitet nicht die angeforderte Dauer; wenn die Dauer des fertigen Videos nicht gelesen werden kann, wird auf die angeforderte Dauer zurückgegriffen. Die Übermittlung der Aufgabe selbst wird nicht separat berechnet, die Abfrage über `/maestro/tasks` ist kostenlos.

```
Credits = Tatsächlich abgerechnete Sekunden × 0.7
```

Alle Szenarien, Aktionen und Sprachen verwenden denselben Preis, ohne Szenario-Multiplikator oder Sprachaufschlag. Jede Aufgabe liefert nur ein fertiges Video in einer Sprache. Die angeforderte Zieldauer unterstützt 5–300 Sekunden, einheitliche Ausgabe in 1080p / 30fps.

| Tatsächliche Abrechnungsdauer | Credits |
| ------------------- | --: |
| 30 Sekunden         |  21 |
| 60 Sekunden         |  42 |
| 120 Sekunden        |  84 |
| 300 Sekunden        | 210 |
| `/maestro/tasks`-Abfrage | Kostenlos |

## Fehlerbehandlung

Wenn beim Aufrufen der API ein Fehler auftritt, gibt die API den entsprechenden Fehlercode und die entsprechende Information zurück. Zum Beispiel:

- `400 invalid_request`: Ungültige Anfrage, möglicherweise aufgrund eines fehlenden `prompt` oder ungültiger Parameter.
- `401 invalid_token`: Nicht autorisiert, ungültiges oder fehlendes Autorisierungstoken.
- `403 forbidden`: Verboten, unzureichendes Guthaben oder unzureichender Zugriff.
- `429 too_many_requests`: Zu viele Anfragen, Sie haben das Ratenlimit überschritten.
- `500 api_error`: Interner Serverfehler, auf dem Server ist ein Fehler aufgetreten.

### Beispiel für eine Fehlerantwort

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
