Maestro ist eine **Agent-native** Schnittstelle zur Videoproduktion: Sie beschreiben das gewünschte Video mit einem natürlichsprachlichen `prompt` (optional können Sie mit `file_urls` Referenzbilder / -videos / -audio anhängen), und ein kopfloser „KI-Regisseur“ erledigt automatisch Themenauswahl, Drehbucherstellung, Bilderzeugung, Vertonung, Musikuntermalung, Komposition und Rendering. Schließlich wird ein fertiges Video mit Untertiteln erstellt und auf das CDN hochgeladen.

Dieser Artikel stellt die Anleitung zur Integration der Maestro-Videoerzeugungs-API detailliert vor und hilft Ihnen, diese API schnell zu integrieren und ihre Fähigkeiten vollständig zu nutzen.

Dies ist eine Schnittstelle für **asynchrone Aufgaben**: Nach der Übermittlung wird sofort `task_id` zurückgegeben, anschließend rufen Sie das Ergebnis per Polling über die [Maestro-Aufgabenabfrage-API](/de/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) ab (Polling ist kostenlos und wird nicht berechnet). Um auf einem bestehenden Video weiter zu iterieren, können Sie `action: remix` / `edit` / `extend` zusammen mit `ref_task_id` verwenden.

## Antragsprozess

Um die Maestro-Videoerzeugungs-API zu verwenden, rufen Sie zunächst die [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications) auf, um Ihr API-Token zu erhalten, und bewahren Sie es als Reserve auf.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Falls Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet und zur Registrierung und Anmeldung aufgefordert. Nach Abschluss kehren Sie automatisch zur aktuellen Seite zurück.

**Ein API-Token kann alle Dienste der Plattform aufrufen, ohne dass Sie für jeden Dienst separat einen Antrag stellen müssen.** Beim ersten Antrag erhalten Sie ein kostenloses Guthaben, mit dem Sie den Dienst kostenlos testen können; bei unzureichendem Guthaben können Sie in der [Konsole](https://platform.acedata.cloud/console/coin) ein allgemeines Guthaben aufladen.

> 📘 Vollständige Dokumentation: [Maestro-Videoerzeugungs-API →](https://platform.acedata.cloud/documents/maestro-videos)

## Grundlegende Verwendung

`POST https://api.acedata.cloud/maestro/videos`

Für die grundlegendste Verwendung müssen Sie nur einen natürlichsprachlichen `prompt` übergeben; der KI-Regisseur entscheidet automatisch über Drehbuch, Bildmaterial, Vertonung und Schnitt. Hier erfahren wir zunächst, welche Request-Header und welcher Request-Body festgelegt werden müssen.

**Request Headers** umfassen:

- `accept`: In welchem Format Sie das Antwortergebnis erhalten möchten; hier wird `application/json`, also das JSON-Format, eingetragen.
- `authorization`: Der Schlüssel zum Aufrufen der API, der nach dem Antrag direkt über ein Dropdown ausgewählt werden kann.
- `content-type`: Das Format des Request-Bodys; hier wird `application/json` eingetragen.

**Request Body** umfasst hauptsächlich:

- `prompt`: Beschreiben Sie das zu erstellende Video in natürlicher Sprache (Thema, was gezeigt werden soll, Stil, Zielgruppe).
- `langs`: Array der Sprache des fertigen Videos; jedes Mal wird nur eine Sprache übergeben, z. B. `["zh-cn"]`, standardmäßig `["zh-cn"]`.
- `aspect`: Bildseitenverhältnis, `9:16` (Standard) / `16:9` / `1:1`.
- `duration`: Zielzeitdauer (Sekunden), standardmäßig 30.

Alle Felder des Request-Bodys sind in der folgenden Tabelle aufgeführt:

| Feld            | Typ       | Erforderlich  | Beschreibung                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Ja   | Beschreiben Sie das zu erstellende Video in natürlicher Sprache (Thema, was gezeigt werden soll, Stil, Zielgruppe). Drehbuch, Bildmaterial, Vertonung und Schnitt werden alle von der KI entschieden                                                                                                                                                                             |
| `action`      | string   | Nein   | `generate` (Standard, neues Video erstellen) / `remix` / `edit` / `extend` (auf bestehendem Video iterieren, muss zusammen mit `ref_task_id` verwendet werden)                                                                                                                                                |
| `ref_task_id` | string   | Nein   | Erforderlich, wenn `action` remix / edit / extend ist: `task_id` der historischen Aufgabe, die als Ausgangspunkt dient                                                                                                                                                                   |
| `file_urls`   | string[] | Nein   | Referenzmedien (Bild- / Video- / Audio-URL), beispielsweise Produktbilder, Logos, die im Video erscheinen sollen, oder Materialclips, denen Untertitel hinzugefügt werden sollen                                                                                                                                                                             |
| `langs`       | string[] | Nein   | Sprache des fertigen Videos; jedes Mal kann nur eine Sprache übergeben werden, z. B. `["zh-cn"]`, standardmäßig `["zh-cn"]`                                                                                                                                                                                    |
| `aspect`      | string   | Nein   | `9:16` (Standard) / `16:9` / `1:1`, einheitliche Ausgabe mit 1080p/30fps                                                                                                                                                                                  |
| `duration`    | int      | Nein   | Zielzeitdauer (Sekunden), standardmäßig 30, unterstützt **5–300 Sekunden**. Die Abrechnung erfolgt nach der tatsächlichen Länge des fertigen Videos, überschreitet jedoch nicht die bei der Anfrage angegebene Dauer                                                                                                                                                                             |
| `scenario`    | string   | Nein   | Videotyp: `auto` / `narrated` / `captions` / `avatar` / `drama`. Für `captions` muss ein Quellvideo übergeben werden, für `avatar` muss ein Porträt übergeben werden                                                                                                                                    |
| `style`       | string   | Nein   | Voreinstellung für den visuellen Stil: `auto` (Standard) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`; freier Text wird ebenfalls als weicher Hinweis akzeptiert. Orthogonal zu `scenario`, ändert das Routing nicht |
| `voice`       | string   | Nein   | Sprecherstimme (unabhängig von der Sprache, sprachübergreifend verwendbar): `auto` (Standard) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`                                    |

Im Folgenden wird dies anhand eines konkreten Beispiels demonstriert. Angenommen, wir möchten ein chinesisches, vertikales, 20-sekündiges wissenschaftliches Kurzvideo erzeugen. Der entsprechende CURL-Code lautet:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

Der entsprechende Python-Code lautet:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Nach dem Klicken auf „Ausführen“ können Sie feststellen, dass sofort ein Ergebnis zurückgegeben wird, wie folgt:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Die Felder des Rückgabeergebnisses werden wie folgt vorgestellt:
- `success`: Ob diese Aufgabe erfolgreich eingereicht wurde.
- `task_id`: Die ID dieser Videogenerierungsaufgabe, die anschließend zur Abfrage der Ergebnisse über die [Maestro-Aufgabenabfrage-API](/de/guides/maestro/maestro_tasks) verwendet wird.
- `trace_id`: Die Tracking-ID dieser Anfrage, die bei Problemen dem technischen Support zur Fehlerlokalisierung bereitgestellt werden kann.

Da die Videoproduktion längere Zeit in Anspruch nimmt, gibt die Schnittstelle hier **sofort `task_id` zurück** und wartet nicht, bis das Video-Rendering abgeschlossen ist. Anschließend muss `task_id` zur Abfrage der Ergebnisse verwendet werden, siehe den Abschnitt „Ergebnisse abrufen“.

## Videotyp und Stil festlegen (scenario / style)

Wenn `scenario` nicht übergeben wird, erfolgt die automatische Bestimmung durch die KI (entspricht `auto`); wenn das Video auf einen bestimmten Typ festgelegt werden soll, übergeben Sie ihn explizit. Um beispielsweise ein **Kurzdrama im Hochformat** zu erstellen, können Sie Folgendes festlegen:

- `scenario`: Videotyp, hier auf `drama` gesetzt (Kurzdrama mit Rollen + Dialogen).
- `style`: Visueller Stil, hier auf `cinematic` gesetzt (filmische Anmutung).

Der ausgefüllte CURL-Code lautet wie folgt:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Gängige Kombinationsmöglichkeiten:

- Erklär-Kurzfilm: `scenario: "narrated"`.
- Automatische Untertitel: `scenario: "captions"`, das Quellvideo muss über `file_urls` übergeben werden.
- Digitaler Mensch / Sprecherbeitrag: `scenario: "avatar"`, ein Porträt muss über `file_urls` übergeben werden.
- Kurzdrama: `scenario: "drama"` (Rollen + Dialoge).
- `style` ist eine Voreinstellung für den visuellen Stil (wie `modern` / `neon` / `luxury`), verändert nicht den Typ und beeinflusst nur den Eindruck.
- `voice` wird verwendet, um die Klangfarbe der Erzählstimme festzulegen (wie `warm-female` / `deep-male`), ist sprachunabhängig und sprachübergreifend einsetzbar.

Das Rückgabeergebnis entspricht der „Grundlegenden Verwendung“, auch hier wird sofort `task_id` zurückgegeben.

## Sprache des fertigen Videos

Eine Aufgabe liefert nur ein fertiges Video in einer Sprache. `langs` darf nur einen Sprachcode enthalten, wie `["zh-cn"]` oder `["en"]`; bei der Übergabe mehrerer Sprachen wird 400 zurückgegeben. Wenn Videos in unterschiedlichen Sprachen benötigt werden, erstellen Sie bitte jeweils separate Aufgaben. Die Sprachauswahl verändert den Preis pro Sekunde nicht.

## Auf bestehenden Videos iterieren (remix / edit / extend)

Durch die Übergabe von `action` und `ref_task_id` der vorherigen Aufgabe können differenzielle Änderungen auf Basis des ursprünglichen Projekts vorgenommen werden (wie „Den Titel der 2. Szene ändern“, „Eine andere Vertonung verwenden“, „Insgesamt abdunkeln“). Kleine Änderungen sind schnell, bei großen Änderungen wird neu erstellt:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: Neuinterpretation auf Grundlage der ursprünglichen Videostruktur (Thema beibehalten, Darstellung anpassen).
- `edit`: Feinschliff an bestimmten Bereichen (wie Titel ändern, Vertonung ändern, Farbkorrektur).
- `extend`: Inhalte auf Grundlage des ursprünglichen Videos erweitern.

Als Rückgabeergebnis wird ebenfalls sofort eine neue `task_id` zurückgegeben, mit der das iterierte fertige Video per Abfrage abgerufen werden kann.

## Ergebnisse abrufen

Da die Videoproduktion längere Zeit in Anspruch nimmt, gibt diese Schnittstelle nach der Einreichung sofort `task_id` zurück; Sie müssen diese zur Abfrage der Ergebnisse über die [Maestro-Aufgabenabfrage-API](/de/guides/maestro/maestro_tasks) verwenden:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Nach Abschluss der Aufgabe werden Informationen zu einem fertigen Video zurückgegeben (im Array `variants`). `status` durchläuft `pending → planning → producing → succeeded` (oder `failed`), **die Abfrage ist kostenlos und verbraucht keine Credits**. Informationen zum vollständigen Antwortformat und zur Abfrage der Verlaufsliste finden Sie in der [Integrationsanleitung für die Maestro-Aufgabenabfrage-API](/de/guides/maestro/maestro_tasks).

## Abrechnung

**Nach erfolgreicher Aufgabe erfolgt die Abrechnung anhand der tatsächlich gelieferten Dauer des fertigen Videos, bei Fehlschlag wird nichts berechnet.** Die Abrechnungsdauer wird in ganzen Sekunden berechnet und überschreitet die angeforderte Dauer nicht; wenn die Dauer des fertigen Videos nicht gelesen werden kann, wird auf die angeforderte Dauer zurückgegriffen. Die Einreichung der Aufgabe selbst wird nicht separat berechnet, die Abfrage über `/maestro/tasks` ist kostenlos.

```
Credits = Tatsächliche abrechenbare Sekunden × 0.7
```

Für alle Szenarien, Aktionen und Sprachen gilt derselbe Preis, ohne Szenario-Multiplikatoren oder Sprachaufschläge. Jede Aufgabe liefert nur ein fertiges Video in einer Sprache. Die angeforderte Zieldauer unterstützt 5–300 Sekunden, einheitliche Ausgabe in 1080p / 30fps.

| Tatsächliche abrechenbare Dauer | Credits |
| ------------------- | --: |
| 30 Sekunden         |  21 |
| 60 Sekunden         |  42 |
| 120 Sekunden        |  84 |
| 300 Sekunden        | 210 |
| `/maestro/tasks`-Abfrage | kostenlos |

## Fehlerbehandlung

Wenn bei der API-Aufruf ein Fehler auftritt, gibt die API den entsprechenden Fehlercode und Informationen zurück. Zum Beispiel:

- `400 invalid_request`: Ungültige Anfrage, möglicherweise aufgrund eines fehlenden `prompt` oder ungültiger Parameter.
- `401 invalid_token`: Nicht autorisiert, ungültiges oder fehlendes Autorisierungstoken.
- `403 forbidden`: Verboten, unzureichendes Guthaben oder fehlender Zugriff.
- `429 too_many_requests`: Zu viele Anfragen, Sie haben das Ratenlimit überschritten.
- `500 api_error`: Interner Serverfehler, auf dem Server ist etwas schiefgelaufen.

### Beispiel einer Fehlerantwort

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
