Dieser Artikel stellt die Integrationsmethode der HappyHorse Videos API vor. Diese Schnittstelle unterstützt Text-zu-Video, Bild-zu-Video mit dem ersten Frame, Bild-zu-Video mit Referenzbildern und Videobearbeitung über den einheitlichen Einstieg `/happyhorse/videos` und den Parameter `action`.

## Antragsprozess

Um die HappyHorse Videos API zu verwenden, rufen Sie zunächst die [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications) auf, um Ihren API-Token abzurufen und für die spätere Verwendung aufzubewahren.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Falls Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach Abschluss kehren Sie automatisch zur aktuellen Seite zurück.

**Mit einem API-Token können alle Dienste der Plattform aufgerufen werden, ohne dass Sie ihn für jeden Dienst separat beantragen müssen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Guthaben zum kostenlosen Ausprobieren; bei unzureichendem Guthaben können Sie Ihr allgemeines Guthaben in der [Konsole](https://platform.acedata.cloud/console/coin) aufladen.

> 📘 Vollständige Dokumentation: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Aktionstypen

`action` bestimmt den Generierungsmodus dieser Anfrage:

- `generate`: Text-zu-Video, die standardmäßige action, unterstützt `happyhorse-1.0-t2v` und `happyhorse-1.1-t2v`; `prompt` muss übergeben werden.
- `image_to_video`: Bild-zu-Video mit dem ersten Frame, unterstützt `happyhorse-1.0-i2v` und `happyhorse-1.1-i2v`; `image_url` muss übergeben werden.
- `reference_to_video`: Bild-zu-Video mit Referenzbildern, unterstützt `happyhorse-1.0-r2v` und `happyhorse-1.1-r2v`; `prompt` und 1–9 `image_urls` müssen übergeben werden.
- `video_edit`: Videobearbeitung, unterstützt `happyhorse-1.0-video-edit`; `prompt` und `video_url` müssen übergeben werden, zusätzlich können 0–5 Referenzbilder als `image_urls` übergeben werden.

Für alle Aktionen wird standardmäßig das Modell 1.1 verwendet; für `video_edit` gibt es derzeit nur `happyhorse-1.0-video-edit`.

## Grundlegende Verwendung

Für Text-zu-Video muss nur `prompt` bereitgestellt werden; Parameter wie `resolution`, `ratio` und `duration` können ebenfalls angegeben werden:

```json
{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

Ein Beispiel für das Rückgabeergebnis lautet wie folgt:

```json
{
  "success": true,
  "task_id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
  "trace_id": "6071ab5e-2f37-46f0-9e07-f1e378112e69",
  "data": [
    {
      "id": "9650580f-6d9e-4bc1-823a-29011790c5cb",
      "video_url": "https://cdn.acedata.cloud/assets/examples/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1-2c108ce23554.mp4",
      "state": "succeeded",
      "duration": 5,
      "resolution": "720P",
      "ratio": null
    }
  ]
}
```

Felderklärung:

- `success`: Ob diese Anfrage erfolgreich war.
- `task_id`: Die Aufgaben-ID auf der Seite von Ace Data Cloud, die zum Abfragen des Aufgabenstatus verwendet werden kann.
- `trace_id`: Die Tracking-ID dieser Anfrage, die zur Fehlerbehebung verwendet wird.
- `data`: Liste der Videoergebnisse.
  - `id`: Die Aufgaben-ID auf der Seite von HappyHorse.
  - `video_url`: Die CDN-Linkadresse des generierten Videos.
  - `state`: Aufgabenstatus, optional `pending` / `succeeded` / `error`.
  - `duration`: Abrechenbare Videodauer in Sekunden; bei `video_edit` die Gesamtdauer von Eingabe- und Ausgabevideo.
  - `resolution`: Ausgabeauflösung.
  - `ratio`: Ausgabe-Seitenverhältnis.

Der entsprechende CURL-Code lautet wie folgt:

```shell
curl -X POST 'https://api.acedata.cloud/happyhorse/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}'
```

Der entsprechende Python-Code lautet wie folgt:

```python
import requests

url = "https://api.acedata.cloud/happyhorse/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
    "resolution": "720P",
    "ratio": "16:9",
    "duration": 5,
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Bild-zu-Video mit dem ersten Frame

Bei der Verwendung von `image_to_video` wird `image_url` als erster Frame des Videos verwendet. Das Ausgabe-Seitenverhältnis folgt nach Möglichkeit dem Bild des ersten Frames, daher muss für diese Aktion `ratio` nicht übergeben werden.

```json
{
  "action": "image_to_video",
  "model": "happyhorse-1.1-i2v",
  "image_url": "https://cdn.acedata.cloud/b1c82e4937.png",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "1080P",
  "duration": 5
}
```

## Bild-zu-Video mit Referenzbildern

Bei der Verwendung von `reference_to_video` können 1–9 Referenzbilder in `image_urls` übergeben werden. Im Prompt können die Bilder in der entsprechenden Reihenfolge mit `character1`, `character2` usw. referenziert werden.

```json
{
  "action": "reference_to_video",
  "model": "happyhorse-1.1-r2v",
  "prompt": "character1 walks forward through a sunrise meadow with the warm leather and gold trim style from character2",
  "image_urls": [
    "https://cdn.acedata.cloud/b1c82e4937.png",
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

## Videobearbeitung

Die Ausgabedauer und das Bildformat von `video_edit` werden vom Quellvideo übernommen; die Übergabe von `duration` oder `ratio` ändert sie nicht. Auch das Bildformat von Bild-zu-Video übernimmt das Quellbild. Die Bearbeitungskosten werden anhand der Gesamtdauer von Eingabe- und Ausgabevideo berechnet.

Bei der Verwendung von `video_edit` müssen das zu bearbeitende Video `video_url` und die Bearbeitungsabsicht `prompt` übergeben werden. Optionale `image_urls` werden als Referenzbilder verwendet, beispielsweise für Kleidungswechsel, Stilübertragung oder lokalen Ersatz. `audio_setting` kann optional `auto` oder `origin` sein, wobei `origin` bedeutet, dass das Originalaudio des Videos beibehalten wird.
```json
{
  "action": "video_edit",
  "model": "happyhorse-1.0-video-edit",
  "prompt": "Apply the warm leather and gold trim style from the reference image while preserving the original camera motion",
  "video_url": "https://cdn.acedata.cloud/assets/examples/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1-2c108ce23554.mp4",
  "image_urls": [
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "audio_setting": "auto"
}
```

## Asynchroner Rückruf

Die Videogenerierung benötigt eine gewisse Verarbeitungszeit. Wenn Sie nicht auf eine lange Verbindung warten möchten, können Sie `callback_url` übergeben. In diesem Fall gibt die API sofort `task_id` zurück, und nach Abschluss der Aufgabe wird das Endergebnis per POST an diese Adresse gesendet:

```json
{
  "action": "generate",
  "prompt": "A horse running through a snowy forest",
  "duration": 5,
  "callback_url": "https://your-domain.com/callback/happyhorse"
}
```

Das sofort zurückgegebene Ergebnis lautet wie folgt:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

Wenn Sie nur abfragen möchten und keinen Rückruf benötigen, können Sie auch `"async": true` übergeben und anschließend das Aufgabenergebnis über die [HappyHorse Tasks API](https://platform.acedata.cloud/documents/happyhorse-tasks) abfragen.

## Abrechnungshinweise

HappyHorse berechnet nach Sekunden des Ausgabevideos und Auflösung:

- `720P`: bereits ab ca. $0.105 / Sekunde.
- `1080P`: bereits ab ca. $0.18 / Sekunde.
- `video_edit`: Die Abrechnung erfolgt nach der Gesamtdauer des Eingabe- und Ausgabevideos; die tatsächliche Abrechnungsdauer richtet sich nach der Statistik nach Abschluss der Aufgabe.

Fehlgeschlagene Aufgaben werden nicht berechnet und verbrauchen auch kein kostenloses Kontingent.

## Fehlerbehandlung

Wenn bei der Anfrage ein Problem auftritt, gibt die API den entsprechenden Fehlercode und eine Beschreibung zurück. Häufige Fälle sind:

- `400`: Anfrageparameter sind fehlerhaft, z. B. stimmen action und model nicht überein, `prompt` / `image_url` / `video_url` fehlt, oder `duration` liegt außerhalb des Bereichs von 3–15 Sekunden.
- `401`: Authentifizierung fehlgeschlagen, das Token ist ungültig oder stimmt nicht mit der API überein.
- `403`: Unzureichendes Guthaben oder der Prompt wurde von der Inhaltsprüfung abgelehnt.
- `429`: Zu häufige Anfragen haben die Ratenbegrenzung ausgelöst. Bitte versuchen Sie es später erneut.
- `500`: Interner Serverfehler oder Generierung fehlgeschlagen.
