HappyHorse Tasks API wird verwendet, um die von der HappyHorse Videos API erstellten Videoerstellungs- oder -bearbeitungsaufgaben abzufragen.

## Antragsprozess

Um die HappyHorse Videos API zu nutzen, müssen Sie zunächst im [Ace Data Cloud Dashboard](https://platform.acedata.cloud/console/applications) Ihr API-Token abrufen und für später aufbewahren.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, die Sie zur Registrierung und Anmeldung einlädt. Nach Abschluss werden Sie automatisch zur aktuellen Seite zurückgeleitet.

**Ein API-Token reicht aus, um auf alle Dienste der Plattform zuzugreifen, es ist nicht erforderlich, für jeden Dienst separat zu beantragen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, um es kostenlos auszuprobieren; wenn das Kontingent erschöpft ist, können Sie im [Dashboard](https://platform.acedata.cloud/console/coin) das allgemeine Guthaben aufladen.

> 📘 Vollständige Dokumentation: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Anfragebeispiel

Die HappyHorse Tasks API kann verwendet werden, um die Ergebnisse der HappyHorse Videos API abzufragen.

### Anfrageheader und Anfragekörper festlegen

**Request Headers** umfassen:

- `accept`: Gibt an, dass die Antwort im JSON-Format empfangen werden soll, hier eingetragen als `application/json`.
- `authorization`: Der Schlüssel zum Aufrufen der API, nach der Beantragung kann er direkt ausgewählt werden.

**Request Body** umfasst:

- `id`: Die ID der zu abfragenden Aufgabe.
- `action`: Die Art der Operation auf der Aufgabe, für eine Einzelabfrage `retrieve` eintragen.

### CURL Codebeispiel

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Antwortbeispiel

Nach erfolgreicher Anfrage gibt die API die Details der Aufgabe zurück. Das Feld `request` ist der Anfragekörper zum Erstellen der Aufgabe, das Feld `response` ist der Antwortkörper nach Abschluss der Aufgabe, zum Beispiel:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262774.423,
  "elapsed": 52.6,
  "request": {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic shot of a white horse running across a moonlit beach",
    "resolution": "720P",
    "duration": 5
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "1469cfc3-3004-4d9e-ab10-xxxxxx",
        "video_url": "https://cdn.acedata.cloud/happyhorse/c8cbf53aa0.mp4",
        "state": "succeeded",
        "duration": 5,
        "resolution": "720P",
        "ratio": "16:9"
      }
    ]
  }
}
```

Feldbeschreibung:

- `id`: Die ID der generierten Aufgabe, die zur eindeutigen Identifizierung dieser Generierungsaufgabe dient.
- `request`: Die Anfrageinformationen zum Erstellen der Aufgabe.
- `response`: Die aktuellen oder endgültigen Rückgabedaten der Aufgabe.
- `created_at`: Erstellungszeit der Aufgabe, Unix-Zeitstempel (Sekunden, Fließkomma).
- `started_at`: Beginn der Ausführungszeit der Aufgabe, Unix-Zeitstempel (Sekunden, Fließkomma).
- `finished_at`: Abschlusszeit der Aufgabe, Unix-Zeitstempel (Sekunden, Fließkomma). Dieses Feld wird nicht zurückgegeben, wenn die Aufgabe nicht abgeschlossen ist.
- `elapsed`: Die für die Ausführung der Aufgabe benötigte Zeit, Einheit ist Sekunden (Fließkomma, auf 3 Dezimalstellen gerundet). Dieses Feld wird nicht zurückgegeben, wenn die Aufgabe nicht abgeschlossen ist.

## Batch-Abfrageoperation

Um die Details mehrerer Aufgaben-IDs abzufragen, setzen Sie `action` auf `retrieve_batch` und übergeben Sie das Array der Aufgaben-IDs über `ids`:

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```

Das Rückgabeergebnis enthält die Felder `items` und `count`, wobei `items` das Array der Aufgabendetails und `count` die Anzahl der in dieser Abfrage gefundenen Aufgaben darstellt.
