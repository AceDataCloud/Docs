Google Gemini ist ein sehr leistungsstarkes KI-Dialogsystem, das durch die Eingabe von Prompts innerhalb weniger Sekunden flüssige und natürliche Antworten generieren kann. Dieses Dokument beschreibt hauptsächlich die Verwendung der Gemini Generate Content API. Dies ist das offizielle native API-Format von Google und unterstützt die beiden Endpunkte `generateContent` und `streamGenerateContent`.

## Unterschiede zur Chat Completions API

Die Gemini Generate Content API verwendet das offizielle native Anfrageformat von Google (Feld `contents`) und nicht das OpenAI-kompatible Format (Feld `messages`). Wenn Sie bereits das Google Gemini SDK verwenden oder mit dem offiziellen API-Format vertraut sind, können Sie diese API direkt verwenden, ohne das Anfrageformat ändern zu müssen.

## Aktuell unterstützter Umfang

Die Schnittstelle akzeptiert Text-, Bild-, Video- und Audioeingaben (`inlineData` oder `fileData`), Denk-Konfigurationen sowie benutzerdefinierte Funktionsdeklarationen. Für native Felder wie Audioausgabe, integrierte Tools und explizites Kontext-Caching gibt es derzeit keine einheitliche Verfügbarkeitsgarantie; maßgeblich sind die tatsächlichen Rückgaben des jeweiligen Modells.

Wenn Sie Audiodateien und andere Dateien über `fileData.fileUri` übermitteln, stellen Sie bitte sicher, dass die Dateien direkt über HTTPS zugänglich sind, nicht von einem Anmeldestatus abhängen und die Gültigkeitsdauer signierter Links die gesamte Verarbeitungszeit der Anfrage abdeckt. Nicht-streamende Audioanalysen liefern erst Ergebnisse zurück, nachdem das Modell die Verarbeitung abgeschlossen hat, und können länger als 90 Sekunden dauern; der Client sollte abhängig von Dateigröße und Geschäftsszenario eine ausreichend lange Gesamtauszeit festlegen, um zu vermeiden, dass die Verbindung getrennt wird, während der Server noch verarbeitet.

## Antragsprozess

Bevor Sie die Gemini Generate Content API verwenden, besuchen Sie bitte die Seite [Gemini Generate Content API](https://platform.acedata.cloud/documents/gemini-generate-content-api) und klicken Sie auf die Schaltfläche „Abrufen“, um die für die Anfrage erforderlichen Zugangsdaten zu erhalten.

Falls Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet. Beim ersten Antrag erhalten Sie ein kostenloses Kontingent.

## Grundlegende Verwendung

### Non-Streaming (nicht streamend)

Senden Sie eine POST-Anfrage an `/v1beta/models/{model}:generateContent`:

> **Hinweis**: Die Flash-Modelle der Serie `gemini-3.x` sind Denkmodelle und verbrauchen zuerst Reasoning-Tokens; setzen Sie `generationConfig.maxOutputTokens` auf über 512, da andernfalls möglicherweise nur leerer Inhalt zurückgegeben wird.

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "你好，请介绍一下你自己"
          }
        ]
      }
    ]
  }'
```

Beispiel für die Rückgabe:

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [{"text": "你好！很高兴与你交流。"}]
      },
      "finishReason": "MAX_TOKENS"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 6,
    "candidatesTokenCount": 19,
    "thoughtsTokenCount": 489,
    "totalTokenCount": 514
  },
  "usage": {
    "prompt_tokens": 6,
    "completion_tokens": 19,
    "total_tokens": 514,
    "thoughts_tokens": 489,
    "cost": {
      "amount": 0.008860916380159999,
      "currency": "credit",
      "list_amount": 0.009631430847999998
    }
  },
  "modelVersion": "gemini-3.5-flash",
  "model": "gemini-3.5-flash"
}
```

Die Token-Felder in `usageMetadata` werden gemäß der nativen Gemini-Semantik abgerechnet:

- `promptTokenCount` enthält `cachedContentTokenCount`; zwischengespeicherte Treffer werden zum Preis für Cache-Lesezugriffe berechnet und nicht erneut als normale Eingabe gezählt.
- `promptTokensDetails` und `cacheTokensDetails` werden unter `usage.prompt_tokens_details` in `text_tokens`, `image_tokens`, `video_tokens`, `audio_tokens` sowie die entsprechenden `cached_*`-Details normalisiert. Diese Werte sind jeweils in `prompt_tokens` und `cached_tokens` enthalten; unterschiedliche Modalitäten werden nur nach ihren jeweiligen Preisen neu berechnet und nicht doppelt abgerechnet.
- `candidatesTokenCount` und `thoughtsTokenCount` werden beide zum Preis für Ausgabe-Tokens berechnet.
- `toolUsePromptTokenCount` sind unabhängige Tool-Eingabe-Tokens und werden zum Preis für Eingabe-Tokens berechnet.

Ace Data Cloud gibt zusätzlich ein normalisiertes `usage`-Objekt zurück; modellübergreifend wird die Gebühr für diesen Aufruf einheitlich aus `usage.cost` gelesen. `cost` ist eine optionale Kostenvorschau; wenn die Preisvorschau vorübergehend nicht verfügbar ist, wird die Modellantwort dennoch normal zurückgegeben, enthält dieses Feld jedoch möglicherweise nicht. Die endgültige Abrechnung richtet sich nach den Nutzungsaufzeichnungen.

### Streaming (streamend)

Senden Sie eine POST-Anfrage an `/v1beta/models/{model}:streamGenerateContent?alt=sse`:

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "写一首关于春天的诗"
          }
        ]
      }
    ]
  }'
```

Die Stream-Rückgabe liefert Inhalte schrittweise im SSE-Format (Server-Sent Events) zurück. Zwischenereignisse enthalten normalerweise nur inkrementelle Inhalte; das Endereignis mit maßgeblichen Nutzungsdaten enthält `usageMetadata` und das normalisierte `usage`, wobei sich die Kosten weiterhin in `usage.cost` befinden:

```text
data: {"candidates":[{"content":{"parts":[{"text":"Hello!"}],"role":"model"},"index":0}],"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

data: {"candidates":[{"content":{"parts":[],"role":"model"},"finishReason":"STOP","index":0}],"usageMetadata":{"promptTokenCount":7,"candidatesTokenCount":89,"totalTokenCount":96},"usage":{"prompt_tokens":7,"completion_tokens":89,"total_tokens":96,"cost":{"amount":0.00026161075472,"currency":"credit","list_amount":0.000284359516}},"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

```

Das Schließen der Verbindung signalisiert das Ende des Streams; native Gemini-Streams senden kein `data: [DONE]`. Wenn die Preisvorschau für den Endzustand vorübergehend nicht verfügbar ist, gibt `usage` weiterhin die Token-Nutzung zurück, lässt jedoch `cost` weg.

## Erweiterte Funktionen

### Systemanweisung

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "你好"}]
    }
  ],
  "systemInstruction": {
    "parts": [{"text": "你是一个专业的诗人，所有回复都用诗歌形式。"}]
  }
}
```

### Generierungskonfiguration

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "讲一个故事"}]
    }
  ],
  "generationConfig": {
    "temperature": 0.7,
    "maxOutputTokens": 1024,
    "topP": 0.9,
    "topK": 40
  }
}
```

### JSON-Modus

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {
          "text": "列出三个中国城市及其人口"
        }
      ]
    }
  ],
  "generationConfig": {
    "responseMimeType": "application/json",
    "responseSchema": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "city": {
            "type": "string"
          },
          "population": {
            "type": "integer"
          }
        }
      }
    }
  }
}
```

### Denkmodus (Thinking)

Modelle, die Denkfunktionen unterstützen (wie gemini-2.5-flash und gemini-2.5-pro), können den Denkmodus aktivieren:

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "解释量子纠缠"}]
    }
  ],
  "generationConfig": {
    "thinkingConfig": {
      "includeThoughts": true,
      "thinkingBudget": 2048
    }
  }
}
```

### Funktionsaufruf

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "北京现在的天气怎么样？"}]
    }
  ],
  "tools": [
    {
      "functionDeclarations": [
        {
          "name": "get_weather",
          "description": "获取指定城市的天气信息",
          "parameters": {
            "type": "object",
            "properties": {
              "city": {
                "type": "string",
                "description": "城市名称"
              }
            },
            "required": ["city"]
          }
        }
      ]
    }
  ]
}
```

### Mehrturn-Dialog

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "你好，我叫小明"}]
    },
    {
      "role": "model",
      "parts": [{"text": "你好小明！很高兴认识你。"}]
    },
    {
      "role": "user",
      "parts": [{"text": "我叫什么名字？"}]
    }
  ]
}
```

### Bildverständnis

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {"text": "描述这张图片"},
        {
          "inlineData": {
            "mimeType": "image/jpeg",
            "data": "base64_encoded_image_data..."
          }
        }
      ]
    }
  ]
}
```

## Sicherheitseinstellungen

Die Inhaltsfilterung kann über `safetySettings` gesteuert werden:

```json
{
  "contents": [...],
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_ONLY_HIGH"
    }
  ]
}
```

## Fehlerbehandlung

| HTTP-Statuscode | Bedeutung             |
| -------- | -------------- |
| 400      | Ungültige Anfrageparameter         |
| 401      | Authentifizierung fehlgeschlagen, bitte Token überprüfen |
| 403      | Inhalt wurde vom Sicherheitsfilter abgefangen     |
| 429      | Anfrage zu häufig         |
| 500      | Interner Serverfehler        |
