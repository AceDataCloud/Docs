Die Hauptfunktion der Gemini Tasks API besteht darin, den Status der Ausführung eines Auftrags abzufragen, indem die Auftrags-ID eingegeben wird, die über die Gemini Videos Generation API generiert wurde.

Dieses Dokument wird die Integrationsanleitung der Gemini Tasks API detailliert beschreiben, um Ihnen zu helfen, die Gemini Videos Generation API einfach zu integrieren und den Status der Auftragsausführung abzufragen.

## Antragsprozess

Um die Gemini Videos Generation API zu nutzen, müssen Sie zunächst Ihr API-Token im [Ace Data Cloud Dashboard](https://platform.acedata.cloud/console/applications) abrufen und für zukünftige Verwendung aufbewahren.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, die Sie zur Registrierung und Anmeldung einlädt. Nach Abschluss werden Sie automatisch zur aktuellen Seite zurückgeleitet.

**Ein API-Token reicht aus, um auf alle Dienste der Plattform zuzugreifen, es ist nicht erforderlich, für jeden Dienst separat zu beantragen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, um die Dienste kostenlos auszuprobieren; wenn das Kontingent erschöpft ist, können Sie im [Dashboard](https://platform.acedata.cloud/console/coin) Ihr Guthaben aufladen.

> 📘 Vollständige Dokumentation: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Anfragebeispiel

Die Gemini Tasks API kann verwendet werden, um die Ergebnisse der Gemini Videos Generation API abzufragen.

### Anfrageheader und Anfragekörper festlegen

**Request Headers** umfassen:

- `accept`: Gibt an, dass die Antwort im JSON-Format empfangen werden soll, hier eingetragen als `application/json`.
- `authorization`: Der Schlüssel zur Aufrufung der API, nach der Beantragung kann er direkt ausgewählt werden.

**Request Body** umfasst:

- `id`: Die zu abfragende Auftrags-ID.
- `action`: Die Art der Operation auf dem Auftrag, für eine Einzelabfrage `retrieve` eintragen.

### CURL Codebeispiel

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Antwortbeispiel

Nach erfolgreicher Anfrage gibt die API die Detailinformationen zu diesem Auftrag zurück. Das Feld `request` ist der Anfragekörper, der beim Starten des Auftrags gesendet wurde, das Feld `response` ist der Antwortkörper, der nach Abschluss des Auftrags zurückgegeben wird, zum Beispiel:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262730.723,
  "elapsed": 8.9,
  "request": {
    "prompt": "Eine filmische Aufnahme eines Kätzchens, das einem Schmetterling in einem sonnigen Garten nachjagt",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
        "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Die Feldbeschreibung ist wie folgt:

- `id`: Die ID des generierten Auftrags, die zur eindeutigen Identifizierung dieses Generierungsauftrags verwendet wird.
- `request`: Die Anfrageinformationen im Auftrag.
- `response`: Die Rückgabeinformationen im Auftrag.
- `created_at`: Erstellungszeit des Auftrags, Unix-Zeitstempel (Sekunden, Fließkomma).
- `started_at`: Beginn der Ausführung des Auftrags, Unix-Zeitstempel (Sekunden, Fließkomma).
- `finished_at`: Abschlusszeit des Auftrags, Unix-Zeitstempel (Sekunden, Fließkomma). Dieses Feld wird nicht zurückgegeben, wenn der Auftrag nicht abgeschlossen ist.
- `elapsed`: Die für die Ausführung des Auftrags benötigte Zeit, Einheit in Sekunden (Fließkomma, auf 3 Dezimalstellen gerundet). Dieses Feld wird nicht zurückgegeben, wenn der Auftrag nicht abgeschlossen ist.

## Batch-Abfrageoperation

Um die Auftragsdetails für mehrere Auftrags-IDs abzufragen, setzen Sie `action` auf `retrieve_batch` und übergeben Sie die Auftrags-ID-Array über `ids`:

**Request Body** umfasst:

- `ids`: Das Array der zu abfragenden Auftrags-IDs.
- `action`: Die Art der Operation auf dem Auftrag, für die Batch-Abfrage `retrieve_batch` eintragen.

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
