Dieser Artikel beschreibt die Integrationsanleitung für die Gemini Videos Generation API, die Videos von Google Gemini (omni-flash) basierend auf Texteingabeaufforderungen (und optionalen Referenzbildern) generieren kann.

## Antragsprozess

Um die Gemini Videos Generation API zu nutzen, müssen Sie zunächst ein API-Token im [Ace Data Cloud Dashboard](https://platform.acedata.cloud/console/applications) anfordern und für zukünftige Verwendung aufbewahren.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach Abschluss werden Sie automatisch zur aktuellen Seite zurückgeleitet.

**Ein API-Token reicht aus, um auf alle Dienste der Plattform zuzugreifen, es ist nicht erforderlich, für jeden Dienst separat zu beantragen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, um es kostenlos auszuprobieren; wenn das Kontingent erschöpft ist, können Sie im [Dashboard](https://platform.acedata.cloud/console/coin) Ihr Guthaben aufladen.

> 📘 Vollständige Dokumentation: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Grundlegende Nutzung

Zunächst sollten Sie die grundlegende Nutzung verstehen. Geben Sie die Eingabeaufforderung `prompt`, das Modell `model` und das Seitenverhältnis `aspect_ratio` ein, um das entsprechende Video zu generieren.

Hier haben wir die Request-Header festgelegt, einschließlich:

- `accept`: In welchem Format Sie die Antwort erhalten möchten, hier eingetragen als `application/json`, also im JSON-Format.
- `authorization`: Der Schlüssel zur API, den Sie nach der Beantragung direkt auswählen können.

Außerdem haben wir den Request-Body festgelegt, einschließlich:

- `prompt`: Der Text, der den gewünschten Inhalt des Videos beschreibt, **erforderlich**.
- `model`: Das Modell zur Videoerzeugung, derzeit wird nur `omni-flash` unterstützt, standardmäßig ist es `omni-flash`.
- `aspect_ratio`: Das Seitenverhältnis des zu generierenden Videos, wahlweise `16:9` (Querformat) oder `9:16` (Hochformat), standardmäßig `16:9`.
- `resolution`: Die optionale Ausgabedimension, wahlweise `720p` oder `1080p`, standardmäßig `720p`.
- `image_urls`: Ein Array von optionalen Referenzbild-Links, das zur Anleitung der Videoerzeugung dient; leere Felder werden ignoriert. Wenn `video_urls` zur Videobearbeitung verwendet wird, ist dieses Feld erforderlich (mindestens ein Bild).
- `video_urls`: Ein Array von optionalen Referenzvideo-Links (maximal 1), zur **Videobearbeitung / Video-Referenz**; wenn bereitgestellt, muss gleichzeitig mindestens ein `image_urls` bereitgestellt werden.
- `callback_url`: Die asynchrone Rückrufadresse, nach der Einstellung gibt die API sofort `task_id` zurück, und bei Abschluss des Auftrags wird das Ergebnis an diese Adresse POST gesendet.
- `async`: Optional, wenn auf `true` gesetzt, gibt die Schnittstelle sofort `task_id` zurück, ohne dass `callback_url` bereitgestellt werden muss, und die Ergebnisse können dann über die entsprechende Abfrage-Schnittstelle abgerufen werden.

Klicken Sie auf die Schaltfläche „Try“, um einen Test durchzuführen. Das Ergebnis sieht ähnlich aus wie folgt:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Die Rückgabe hat mehrere Felder, die wie folgt beschrieben werden:

- `success`: Ob die Videoerzeugungsanfrage erfolgreich war.
- `task_id`: Die ID der Videoerzeugungsaufgabe.
- `trace_id`: Die Verfolgungs-ID dieser Anfrage, die zur Fehlersuche verwendet wird.
- `data`: Die Liste der generierten Videoergebnisse.
  - `id`: Die eindeutige Kennung des generierten Videos.
  - `video_url`: Die URL des generierten Videos.
  - `state`: Der Status der Videoerzeugungsaufgabe, wahlweise `pending` / `succeeded` / `failed`.

Wir müssen nur die `video_url` aus dem `data`-Ergebnis abrufen, um das generierte Video zu erhalten.

Der entsprechende CURL-Code sieht wie folgt aus:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Der entsprechende Python-Code sieht wie folgt aus:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Bild zu Video

Wenn Sie ein Video basierend auf Referenzbildern generieren möchten, können Sie ein oder mehrere Bild-Links in `image_urls` übergeben, um die Videoerzeugung zu leiten:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## Videobearbeitung / Referenzvideo

Es wird unterstützt, vorhandene Videos direkt zu bearbeiten oder zu referenzieren: Geben Sie in `video_urls` einen Referenzvideo-Link (maximal 1) an und **gleichzeitig** mindestens ein Referenzbild in `image_urls` (obligatorische Anforderung). Sie können über `prompt` die gewünschten Bearbeitungseffekte beschreiben (Stil ändern, Szenen wechseln, Elemente hinzufügen oder entfernen usw.):

```json
{
  "prompt": "Restyle the video into cinematic anime, keep the motion",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ],
  "video_urls": [
    "https://cdn.acedata.cloud/example-source.mp4"
  ]
}
```

> Hinweis: Es ist maximal 1 Referenzvideo erlaubt; und wenn `video_urls` bereitgestellt wird, muss mindestens ein `image_urls` bereitgestellt werden (ansonsten wird ein Parameterfehler zurückgegeben).

## Asynchrone Rückrufe

Die Videoerzeugung benötigt eine gewisse Verarbeitungszeit. Wenn Sie keine lange Verbindung aufrechterhalten möchten, können Sie `callback_url` übergeben. In diesem Fall gibt die API sofort `task_id` zurück, und nach Abschluss des Auftrags wird das endgültige Ergebnis an diese Adresse POST gesendet:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Das sofort zurückgegebene Ergebnis sieht wie folgt aus:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Abfrage des Auftragsstatus

Wenn Sie asynchrone Rückrufe verwendet haben oder den Status des Auftrags aktiv abfragen möchten, können Sie über die [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) den neuesten Status und das Ergebnis des Auftrags anhand der `task_id` abfragen.

## Fehlerbehandlung

Wenn bei der Anfrage ein Problem auftritt, gibt die API den entsprechenden Fehlercode und die Beschreibung zurück, häufige sind wie folgt:
- `400`: Die Anfrageparameter sind ungültig, z. B. fehlt `prompt` oder der Wert von `aspect_ratio` ist ungültig.
- `401`: Authentifizierung fehlgeschlagen, Token ist ungültig oder stimmt nicht mit der API überein.
- `403`: Unzureichendes Guthaben oder der Hinweis wurde aufgrund von Inhaltsüberprüfung abgelehnt.
- `500`: Interner Serverfehler oder Fehler bei der Generierung durch den Upstream.
