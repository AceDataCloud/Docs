Dieser Artikel beschreibt die Integrationsanleitung für die Gemini Videos Generation API, mit der durch Eingabe von Texteingabeaufforderungen (und optionalen Referenzbildern) Google Gemini (omni-flash) Videos generiert werden können.

## Antragsprozess

Um die API zu nutzen, müssen Sie zunächst auf der entsprechenden Seite der [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos) den Dienst beantragen. Nach dem Aufruf der Seite klicken Sie auf die Schaltfläche „Acquire“, wie im Bild gezeigt:

![](https://cdn.acedata.cloud/q6ytrc.png)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach der Anmeldung oder Registrierung kehren Sie automatisch zur aktuellen Seite zurück.

Beim ersten Antrag erhalten Sie ein kostenloses Kontingent, mit dem Sie die API kostenfrei nutzen können.

## Grundlegende Nutzung

Zunächst wird die grundlegende Nutzung erläutert: Durch Eingabe der Eingabeaufforderung `prompt`, des Modells `model` und des Seitenverhältnisses `aspect_ratio` kann das entsprechende Video generiert werden.

Hier sehen wir, dass wir die Request-Header setzen, darunter:

- `accept`: Gibt an, in welchem Format die Antwort erwartet wird. Hier wird `application/json` angegeben, also im JSON-Format.
- `authorization`: Der API-Schlüssel für den Aufruf der API, der nach der Beantragung direkt aus einer Dropdown-Liste ausgewählt werden kann.

Außerdem wird der Request-Body gesetzt, der folgende Felder enthält:

- `prompt`: Textbeschreibung des gewünschten Videoinhalts, **Pflichtfeld**.
- `model`: Das Modell zur Videogenerierung, derzeit wird nur `omni-flash` unterstützt, Standard ist `omni-flash`.
- `aspect_ratio`: Seitenverhältnis des generierten Videos, wählbar zwischen `16:9` (Querformat) oder `9:16` (Hochformat), Standard ist `16:9`.
- `image_urls`: Optionales Array von Referenzbild- (oder Video-) URLs zur Steuerung der Videogenerierung, leere Einträge werden ignoriert.
- `callback_url`: Asynchrone Callback-URL. Wird diese gesetzt, gibt die API sofort eine `task_id` zurück, und nach Abschluss der Aufgabe wird das Ergebnis per POST an diese URL gesendet.

Mit einem Klick auf „Try“ kann ein Test durchgeführt werden, das Ergebnis sieht etwa so aus:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Die Rückgabe enthält mehrere Felder, die wie folgt erklärt werden:

- `success`: Ob die Videogenerierungsanfrage erfolgreich war.
- `task_id`: Die ID der Videogenerierungsaufgabe.
- `trace_id`: Die Nachverfolgungs-ID der Anfrage zur Fehleranalyse.
- `data`: Liste der generierten Videoergebnisse.
  - `id`: Eindeutige Kennung des generierten Videos.
  - `video_url`: URL des generierten Videos.
  - `state`: Status der Videogenerierungsaufgabe, möglich sind `pending` / `succeeded` / `failed`.

Wir müssen lediglich die `video_url` aus dem `data`-Feld verwenden, um das generierte Video abzurufen.

Der entsprechende CURL-Code lautet:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Der entsprechende Python-Code lautet:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Bild-zu-Video

Wenn Sie Videos basierend auf Referenzbildern generieren möchten, können Sie ein oder mehrere Bild-URLs im Feld `image_urls` übergeben, um die Videogenerierung zu steuern:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## Asynchrone Rückruffunktion

Die Videogenerierung benötigt eine gewisse Verarbeitungszeit. Wenn Sie keine lange Verbindung offen halten möchten, können Sie `callback_url` übergeben. In diesem Fall gibt die API sofort eine `task_id` zurück, und nach Abschluss der Aufgabe wird das endgültige Ergebnis per POST an diese URL gesendet:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Die sofort zurückgegebene Antwort sieht wie folgt aus:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Abfrage des Aufgabenstatus

Wenn Sie die asynchrone Rückruffunktion nutzen oder den Status der Aufgabe aktiv abfragen möchten, können Sie über die [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) anhand der `task_id` den aktuellen Status und das Ergebnis der Aufgabe abfragen.

## Fehlerbehandlung

Wenn bei der Anfrage Probleme auftreten, gibt die API entsprechende Fehlercodes und Beschreibungen zurück. Häufige Fehler sind:

- `400`: Ungültige Anfrageparameter, z. B. fehlendes `prompt` oder ungültiger Wert für `aspect_ratio`.
- `401`: Authentifizierungsfehler, ungültiges Token oder nicht mit der API kompatibel.
- `403`: Unzureichendes Guthaben oder Ablehnung aufgrund von Inhaltsüberprüfung der Eingabeaufforderung.
- `500`: Interner Serverfehler oder Fehler bei der Generierung durch vorgelagerte Systeme.
