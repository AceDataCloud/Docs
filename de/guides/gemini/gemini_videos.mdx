Dieser Artikel beschreibt die Integrationsanleitung für die Gemini Videos Generation API, die Videos von Google Gemini (omni-flash) basierend auf Texteingaben (und optionalen Referenzbildern) generieren kann.

## Antragsprozess

Um die Gemini Videos Generation API zu nutzen, müssen Sie zunächst ein API-Token im [Ace Data Cloud Dashboard](https://platform.acedata.cloud/console/applications) anfordern und für zukünftige Verwendung aufbewahren.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach Abschluss werden Sie automatisch zur aktuellen Seite zurückgeleitet.

**Ein API-Token reicht aus, um auf alle Dienste der Plattform zuzugreifen, es ist nicht erforderlich, für jeden Dienst separat zu beantragen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, um es kostenlos auszuprobieren; wenn das Kontingent erschöpft ist, können Sie im [Dashboard](https://platform.acedata.cloud/console/coin) Ihr Guthaben aufladen.

> 📘 Vollständige Dokumentation: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Grundlegende Nutzung

Zunächst sollten Sie die grundlegende Nutzung verstehen. Geben Sie die Eingabeaufforderung `prompt`, das Modell `model` und das Seitenverhältnis `aspect_ratio` ein, um das entsprechende Video zu generieren.

Hier haben wir die Request-Header festgelegt, einschließlich:

- `accept`: In welchem Format Sie die Antwort erhalten möchten, hier eingetragen als `application/json`, also im JSON-Format.
- `authorization`: Der Schlüssel zur API, den Sie nach der Beantragung direkt auswählen können.

Außerdem haben wir den Request-Body festgelegt, einschließlich:

- `prompt`: Der Text, der den Inhalt des zu generierenden Videos beschreibt, **erforderlich**.
- `model`: Das Modell zur Generierung des Videos, derzeit wird nur `omni-flash` unterstützt, standardmäßig ist es `omni-flash`.
- `aspect_ratio`: Das Seitenverhältnis des zu generierenden Videos, optional `16:9` (Querformat) oder `9:16` (Hochformat), standardmäßig `16:9`.
- `resolution`: Die optionale Ausgabedimension, wählbar zwischen `720p` oder `1080p`, standardmäßig `720p`.
- `image_urls`: Ein optionales Array von Referenzbild-Links, das zur Anleitung der Videoerstellung verwendet wird; leere Felder werden ignoriert. Wenn `video_urls` zur Video-Bearbeitung verwendet wird, ist dieses Feld erforderlich (mindestens ein Bild).
- `video_urls`: Ein optionales Array von Referenzvideo-Links (maximal 1), verwendet für **Video-Bearbeitung / Video-Referenz**; wenn bereitgestellt, muss gleichzeitig mindestens ein `image_urls` bereitgestellt werden.
- `callback_url`: Die asynchrone Rückrufadresse, nach der Einstellung gibt die API sofort `task_id` zurück, und bei Abschluss wird das Ergebnis an diese Adresse POST gesendet.
- `async`: Optional, wenn auf `true` gesetzt, gibt die Schnittstelle sofort `task_id` zurück, ohne dass `callback_url` bereitgestellt werden muss, und die Ergebnisse können dann über die entsprechende Task-Abfrage-Schnittstelle abgefragt werden.

Klicken Sie auf die Schaltfläche „Try“, um einen Test durchzuführen. Das Ergebnis sieht ähnlich aus wie folgt:

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://platform2.cdn.acedata.cloud/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "Eine filmische Aufnahme einer Katze, die in einem sonnigen Garten einem Schmetterling nachjagt"
    }
  ],
  "started_at": "2026-07-15T10:55:53.856Z",
  "finished_at": "2026-07-15T10:57:01.328Z",
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Die Rückgabe enthält mehrere Felder, die wie folgt beschrieben werden:

- `success`: Ob die Videoerstellungsanfrage erfolgreich war.
- `task_id`: Die ID der Videoerstellungsaufgabe.
- `trace_id`: Die Verfolgungs-ID dieser Anfrage, die zur Fehlersuche verwendet wird.
- `data`: Liste der generierten Videoergebnisse.
  - `id`: Die eindeutige Kennung des generierten Videos.
  - `video_url`: Die Linkadresse des generierten Videos (`state` ist `pending`, dann ist es `null`).
  - `state`: Der Status der Videoerstellungsaufgabe, wählbar zwischen `pending` / `succeeded` / `failed`.
  - `aspect_ratio`: Das Seitenverhältnis des Videos, das mit den Anfrageparametern übereinstimmt.
  - `prompt`: Die Eingabeaufforderung, die zur Erstellung dieses Videos verwendet wurde.

Bei synchroner Rückgabe werden auch die Felder `started_at`, `finished_at`, `elapsed` (Dauer in Sekunden) und `cost` (Kosten dieser Anfrage, Einheit Credit) mitgeliefert.

Wir müssen nur die generierte Video-URL aus dem `data`-Feld abrufen.

Der entsprechende CURL-Code sieht wie folgt aus:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Eine filmische Aufnahme einer Katze, die in einem sonnigen Garten einem Schmetterling nachjagt",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Der entsprechende Python-Code sieht wie folgt aus:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "Eine filmische Aufnahme einer Katze, die in einem sonnigen Garten einem Schmetterling nachjagt",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Bild zu Video

Wenn Sie ein Video basierend auf Referenzbildern generieren möchten, können Sie ein oder mehrere Bild-Links in `image_urls` übergeben, um die Videoerstellung zu leiten:

```json
{
  "prompt": "Die Frau dreht sich langsam um und lächelt in die Kamera, sanfter Wind",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3.png"
  ]
}
```

## Video-Bearbeitung / Referenzvideo (Eingangsvideo, Generierung eines Videos)

Es wird unterstützt, direkt „ein Video einzugeben und ein neues Video zu generieren“: Geben Sie einen Referenzvideo-Link in `video_urls` ein (maximal 1) und **gleichzeitig** mindestens ein Referenzbild in `image_urls` (obligatorisch), und verwenden Sie `prompt`, um die gewünschten Bearbeitungseffekte zu beschreiben (Stil ändern, Szenen wechseln, Elemente hinzufügen oder entfernen usw.).

Hier ist ein vollständiges, reales Beispiel – ein sonniges Strandvideo in eine winterliche Szene mit fallendem Schnee zu ändern, während das Layout von Strand, Palmen und Boot beibehalten wird. Die Video-Bearbeitung dauert länger (in diesem Beispiel etwa 6,5 Minuten), daher wird `async: true` asynchron eingereicht:
```json
{
  "prompt": "Verwandle diesen sonnigen tropischen Strand in eine verschneite Winterlandschaft mit stark fallendem Schnee und bewölktem Himmel; behalte denselben Strand, die Palmen und die Anordnung der Boote bei.",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://platform2.cdn.acedata.cloud/seedance/dd3dc063-3383-4f29-bedc-e771a096758c.mp4"
  ],
  "async": true
}
```

Nach dem Einreichen gibt die Schnittstelle sofort `task_id` zurück:

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

Danach verwende die `task_id` als `id`, um die [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) abzufragen. Nach Abschluss der Aufgabe kannst du das generierte neue Video abrufen (dies ist das tatsächliche Rückgabeergebnis dieses Beispiels):

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://platform2.cdn.acedata.cloud/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "Verwandle diesen sonnigen tropischen Strand in eine verschneite Winterlandschaft mit stark fallendem Schnee und bewölktem Himmel; behalte denselben Strand, die Palmen und die Anordnung der Boote bei."
    }
  ],
  "started_at": "2026-07-15T03:01:22.914Z",
  "finished_at": "2026-07-15T03:07:57.090Z",
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Für ein höher aufgelöstes Ergebnis kann die `resolution` auf `1080p` gesetzt werden (die anderen Parameter bleiben unverändert).

> Hinweis: Die in diesem Beispiel verwendeten Eingabe- / Ausgabemedienlinks sind echte generierte Ergebnisse. **Die von der Plattform generierten Video- und Bildlinks haben eine Speicherfrist und laufen nach Ablauf ab**, bitte lade die Ergebnisse nach Erhalt umgehend herunter und speichere sie in deinem eigenen Speicher.

> Achtung: Es darf maximal 1 Referenzvideo geben; und wenn `video_urls` bereitgestellt wird, muss mindestens ein `image_urls` bereitgestellt werden, andernfalls wird der folgende Parameterfehler zurückgegeben:

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (mindestens ein Referenzbild) ist erforderlich, wenn video_urls bereitgestellt wird."
  }
}
```

## Asynchrone Rückrufe

Die Videoerstellung benötigt eine gewisse Verarbeitungszeit. Wenn du keine lange Verbindung aufrechterhalten möchtest, kannst du `callback_url` übergeben. In diesem Fall gibt die API sofort `task_id` zurück, und nach Abschluss der Aufgabe wird das endgültige Ergebnis an diese Adresse POST gesendet:

```json
{
  "prompt": "Eine filmische Aufnahme eines Kätzchens, das einem Schmetterling in einem sonnigen Garten nachjagt",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Das sofort zurückgegebene Ergebnis sieht wie folgt aus:

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## Abfrage des Aufgabenergebnisses

Wenn du asynchrone Rückrufe verwendet hast oder den Status der Aufgabe aktiv abfragen möchtest, kannst du die [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) verwenden, um den neuesten Status und das Ergebnis der Aufgabe anhand der `task_id` abzufragen. Übergebe die bei der Erstellung des Videos zurückgegebene `task_id` als `id`:

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

Das Ergebnis, das nach Abschluss der Aufgabe zurückgegeben wird, sieht ähnlich aus, wobei die Struktur von `response.data` mit der bei synchroner Erstellung übereinstimmt (während der Erstellung ist `state` auf `pending` und `video_url` auf `null`):

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
  "type": "videos",
  "request": {
    "model": "omni-flash",
    "prompt": "Ein Zeitraffer von Wolken über schneebedeckten Bergen bei Sonnenaufgang",
    "aspect_ratio": "16:9",
    "async": true
  },
  "response": {
    "success": true,
    "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
    "data": [
      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
        "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4",
        "state": "succeeded",
        "aspect_ratio": "16:9",
        "prompt": "Ein Zeitraffer von Wolken über schneebedeckten Bergen bei Sonnenaufgang"
      }
    ],
    "elapsed": 96.716,
    "cost": {
      "amount": 1.932,
      "currency": "credit",
      "list_amount": 2.1
    }
  }
}
```

## Fehlerbehandlung

Wenn bei der Anfrage ein Problem auftritt, gibt die API den entsprechenden Fehlercode und die Beschreibung zurück, häufige sind:

- `400`: Anfrageparameter sind fehlerhaft, z. B. fehlt `prompt` oder der Wert von `aspect_ratio` ist ungültig.
- `401`: Authentifizierung fehlgeschlagen, Token ungültig oder stimmt nicht mit der API überein.
- `403`: Unzureichendes Guthaben oder der Hinweis wurde aufgrund von Inhaltsprüfungen abgelehnt.
- `500`: Interner Serverfehler oder Fehler bei der Generierung durch den upstream.
