Gibt das Service-Verzeichnis zurück, das auf der aktuellen Website sichtbar ist, einschließlich Diensttyp, Anzeigeinformationen, Freikontingent, Paketen und zugehörigen API-/Proxy-IDs. Geeignet für den Aufbau eines Dienstmarktplatzes oder die Auswahl von zu beantragenden Diensten.

## Schnittstellenübersicht

| Element   | Inhalt                                            |
| --- | ------------------------------------------------- |
| Methode  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| Authentifizierung  | Öffentlich; bei angemeldetem Status spiegelt `applied` erst das aktuelle Konto wider                        |
| Paginierung  | `count` + `items`                                 |

## Abfrageparameter

| Parameter               | Typ      | Erforderlich  | Beschreibung                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | Nein   | Nach Dienst-ID filtern; wiederholte Parameter werden unterstützt         |
| `private`        | boolean | Nein   | Nach öffentlichem Status filtern; die Sichtbarkeitsregeln der Website bleiben weiterhin wirksam      |
| `type`           | string  | Nein   | Diensttyp; wiederholte Parameter werden unterstützt              |
| `tag`            | string  | Nein   | Nach Tags filtern                    |
| `include_facets` | boolean | Nein   | Bei `true` werden die für die aktuelle Website verfügbaren Typ-/Tag-Statistiken hinzugefügt |
| `limit`          | integer | Nein   | Anzahl der Einträge pro Seite, maximal 100              |
| `offset`         | integer | Nein   | Paginierungsversatz                    |
| `ordering`       | string  | Nein   | Unterstützt nur `rank` oder `-rank`     |

Die Liste unterstützt keine Filterung nach `alias`; bei vorhandenem Alias direkt `/api/v1/services/{alias}` anfordern. `applied_count` und `updated_at` sind keine zulässigen Sortierfelder.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## Antwortbeschreibung

Die Antwort ist `{count, items}`; `facets` wird nur bei `include_facets=true` hinzugefügt. Diensteinträge enthalten unter anderem die derzeit öffentlichen Felder `id`, `alias`, `title`, `description`, `type`, `applied_count`, `free_amount`, `unit`, `private`, `need_verify`, `rank`, `tags`, `thumbnail`, `doc_url`, `demo_url`, `api_ids`, `proxy_ids`, `cost` und `packages`.

`applied` stellt in einer anonymen Liste nicht den Antragsstatus eines bestimmten Kontos dar. Wenn ein kontobezogener Status benötigt wird, sollte ein gültiger Anmeldestatus verwendet werden und die [Liste der Dienstanträge](https://platform.acedata.cloud/documents/platform-application-list) als endgültige Grundlage dienen.
