Das Coding Plan Modell von OpenCode, Provider, IDE Extension und MCP sind drei unabhängige Fähigkeiten. Die IDE Extension verbindet sich mit der lokalen OpenCode Runtime und verwendet dieselbe Provider-Konfiguration; sie stellt nicht die native Unterstützung des Host-Editors für Ace Data Cloud dar.

| Route                          | Beschreibung                                              | Link                                                                                     | Status      |
| ----------------------------- | ------------------------------------------------------- | --------------------------------------------------------------------------------------- | ----------- |
| Terminal / CLI / TUI Provider | Verwendung von `opencode.json[c]` und Chat Completions | [Provider-Konfiguration](https://platform.acedata.cloud/documents/opencode-terminal-integration) | Konfiguration verifiziert |
| IDE Extension                 | VS Code, Cursor, Windsurf, VSCodium und andere Hosts verbinden sich mit der OpenCode Runtime | [IDE-Konfiguration](https://platform.acedata.cloud/documents/opencode-ide-integration)           | Experimentell |
| MCP                           | Aufruf von Remote-Tools innerhalb von OpenCode          | [MCP Übersicht](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | Unabhängige Fähigkeit |

Nach erfolgreicher Provider-Konfiguration sollte die IDE Extension denselben Provider und dasselbe Modell verwenden. Es muss weiterhin separat die Chat-Funktion, das Lesen von Dateien, das Bearbeiten und den Aufruf von Tools innerhalb der IDE validiert werden; eine einmalige normale Anfrage der CLI sollte nicht automatisch auf alle IDE-Funktionen extrapoliert werden.

Die Modell-ID ist gemäß dem [Live-Verzeichnis](https://platform.acedata.cloud/models) gültig.
