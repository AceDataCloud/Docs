Die offizielle OpenCode IDE Erweiterung unterstützt Editoren wie VS Code, Cursor, Windsurf, VSCodium und nutzt die lokale Runtime und Provider-Konfiguration von OpenCode. Die IDE-Erweiterung verwendet den lokalen CLI Provider, jedoch kann sich die Anforderungskette je nach Version des Editors ändern; bei der ersten Anbindung bitte eine feste Version verwenden und die minimale Validierung abschließen.

## Provider konfigurieren

Zuerst gemäß der [OpenCode Terminal Konfiguration](https://platform.acedata.cloud/documents/opencode-terminal-integration) den Ace Data Cloud Provider in `opencode.json` oder `opencode.jsonc` konfigurieren:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## IDE Erweiterung installieren

1. Führen Sie im integrierten Terminal des Editors `opencode` aus, um die Erweiterung automatisch gemäß dem offiziellen Prozess zu installieren; alternativ kann sie manuell aus dem entsprechenden Marketplace installiert werden.
2. Laden Sie den Editor neu.
3. Initiieren Sie `Reply only OK` von der OpenCode Erweiterung.
4. Führen Sie erneut eine Anfrage aus, die das Lesen von Dateien oder das Ändern von Code erfordert, um zu bestätigen, dass die IDE Erweiterung denselben Provider und dasselbe Modell verwendet.

## Aktuelle Grenzen

- Die Fähigkeiten des Providers stammen aus der OpenCode Runtime und bedeuten nicht, dass der Host-Editor Ace Data Cloud nativ unterstützt.
- Die Erweiterungsversionen von VS Code und den verschiedenen Forks können unterschiedlich sein, daher sollten die Versionen separat dokumentiert werden.
- Ein erfolgreicher allgemeiner Chat kann das Lesen von Dateien, das Bearbeiten und die Validierung von Toolaufrufen nicht ersetzen.
