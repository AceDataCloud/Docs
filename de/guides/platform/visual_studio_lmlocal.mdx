LMLocal ist eine Erweiterung für Visual Studio 2022/2026, die offiziell die OpenAI-kompatible API und benutzerdefinierte Basis-URLs unterstützt. Der Konfigurationszugang kann je nach Erweiterungsversion variieren; bei der ersten Anbindung bitte eine feste Version verwenden und die tatsächliche Bearbeitung, Toolaufrufe und Nutzungsprotokolle überprüfen.

## Konfiguration

1. Installieren Sie LMLocal aus dem Visual Studio Marketplace oder dem offiziellen Repository.
2. Fügen Sie im Bereich Providers einen benutzerdefinierten/OpenAI-kompatiblen Provider hinzu.
3. Geben Sie die Basis-URL als `https://api.acedata.cloud/v1` ein.
4. Geben Sie den Auth Key als Ihr Ace Data Cloud API Token ein.
5. Geben Sie das Modell im Modellverzeichnis mit der genauen Modell-ID an, die Chat Completions unterstützt.
6. Senden Sie nach dem Speichern `Reply only OK` und testen Sie den Projektbearbeitungsprozess erneut.

## Aktuelle Grenzen

- Diese Anleitung behandelt nur LMLocal und stellt nicht die gemeinsame Konfiguration anderer Visual Studio-Erweiterungen dar.
- Verschiedene Versionen können Chat-, Bearbeitungs-, Build- und Testanfragen unterschiedlich behandeln; jede Modus muss unabhängig validiert werden.
- Wenn der Client automatisch `/v1` oder den Endpunkt-Pfad hinzufügt, vermeiden Sie doppelte Pfade.
