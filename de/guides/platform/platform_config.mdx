Liest die öffentlichen Funktionsschalter und die Länder-/Regionsbestimmung im Kontext der aktuellen Anfrage. Geeignet, um beim Frontend-Start zu entscheiden, ob Funktionen angezeigt werden; dies sind keine Website-Marke, Kontaktinformationen oder Ankündigungsverzeichnisse.

## API-Übersicht

| Element   | Inhalt                                              |
| --- | ----------------------------------------------- |
| Methode  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Authentifizierung  | Öffentlich; bei mitgeführtem Anmeldestatus können einige Funktionsschalter benutzerspezifisch berechnet werden                          |

## Abfrageparameter und Request-Header

| Name                    | Position     | Beschreibung                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | Überschreibungsausdruck für Funktionsschalter; gilt nur für Schalter, deren clientseitige Überschreibung erlaubt ist, oder für Superadministratoren |
| `X-Feature-Overrides` | header | Dieselbe Überschreibungsquelle wie `features`           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## Tatsächliche Antwortstruktur

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| Feld         | Typ            | Beschreibung                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Funktionsschalter, die für die aktuelle Anfrage sichtbar sind; Schlüssel können sich mit der Plattformkonfiguration ändern, Clients sollten sie bei Bedarf lesen und sichere Standardwerte für fehlende Schlüssel festlegen |
| `region`   | string / null | Anhand der Request-IP erkannter Länder- oder Regionscode, in Kleinbuchstaben; bei fehlender Erkennung `null`        |

Lesen Sie über diese API keinen Websitenamen, kein CDN, keine Währung, keine Sprache, keine Kundenservice-Kontaktdaten oder Ankündigungen; diese Felder gehören nicht zum aktuellen Antwortvertrag.

## Nutzungsempfehlungen

- Funktionsschalter werden nach Benutzer, Fingerabdruck und Website-Kontext berechnet; teilen Sie keinen Langzeit-Cache benutzerübergreifend.
- Die Auswahl des Regionsauswählers wird nur im Frontend gespeichert; verwenden Sie bei der Anzeige bevorzugt die ausgewählte Region, andernfalls die `region` dieser API. Diese API akzeptiert keine Parameter zur Regionsüberschreibung.
- Nicht erkannte query-Parameter werden ignoriert; verwenden Sie nur die auf dieser Seite aufgeführten Parameter.
