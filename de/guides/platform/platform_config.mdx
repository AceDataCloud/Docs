Liest die öffentlichen Funktionsschalter und die Länder-/Regionsbestimmung im Kontext der aktuellen Anfrage. Geeignet, um beim Start des Frontends zu entscheiden, ob Funktionen angezeigt werden; dies sind nicht der Markenname der Website, Kontaktinformationen oder ein Ankündigungsverzeichnis.

## Schnittstellenübersicht

| Element   | Inhalt                                              |
| --- | ----------------------------------------------- |
| Methode  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Authentifizierung  | Öffentlich; beim Mitführen eines Anmeldestatus können einige Funktionsschalter benutzerspezifisch berechnet werden                          |

## Abfrageparameter und Anfrage-Header

| Name                    | Position     | Beschreibung                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | Zweistelliger ASCII-Ländercode; wird verwendet, um das Anzeigeland in der Antwort zu überschreiben, ohne die serverseitige Sicherheitsbewertung zu ändern |
| `features`            | query  | Ausdruck zur Überschreibung von Funktionsschaltern; gilt nur für Schalter, deren clientseitige Überschreibung erlaubt ist, oder für Superadministratoren        |
| `X-Feature-Overrides` | header | Überschreibungsquelle identisch mit `features`                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## Tatsächliche Antwortstruktur

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| Feld         | Typ            | Beschreibung                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Für die aktuelle Anfrage sichtbare Funktionsschalter; Schlüssel können sich mit der Plattformkonfiguration ändern, Clients sollten sie bedarfsgerecht lesen und sichere Standardwerte für fehlende Schlüssel festlegen |
| `country`  | string / null | Ländercode in Kleinbuchstaben; bei fehlender Erkennung möglicherweise `null`                     |

Lesen Sie über diese Schnittstelle nicht den Namen der Website, CDN, Währung, Sprache, Kundendienst-Kontaktinformationen oder Ankündigungen aus; diese Felder gehören nicht zum aktuellen Antwortvertrag.

## Nutzungsempfehlungen

- Funktionsschalter werden anhand von Benutzer, Fingerabdruck und Website-Kontext berechnet; teilen Sie den Cache nicht langfristig benutzerübergreifend.
- Das vom Client übergebene `country` beeinflusst nur den Rückgabewert und umgeht keine serverseitigen Regions- oder Sicherheitsrichtlinien.
- Nicht erkannte Query-Parameter werden ignoriert; verwenden Sie nur die auf dieser Seite aufgeführten Parameter.
