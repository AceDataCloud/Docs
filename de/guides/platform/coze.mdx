Coze unterstützt offiziell die Integration benutzerdefinierter Modelle und bietet drei Protokolle an: OpenAI Chat API, OpenAI Responses API und Anthropic Messages API. Die Basis-URL, Pfadverkettung, Header, Streaming und die Verträge für Toolaufrufe unterscheiden sich zwischen den drei Routen, daher müssen sie separat konfiguriert und validiert werden.

| Route                      | Status     | Anleitung                                                                                  |
| ----------------------- | -------- | ----------------------------------------------------------------------------------- |
| OpenAI Chat Completions | Experimentell | [Chat-Konfiguration](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | Experimentell | [Responses-Konfiguration](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | Experimentell | [Messages-Konfiguration](https://platform.acedata.cloud/documents/coze-messages-integration)   |

„Experimentell“ bedeutet, dass die offiziellen Fähigkeiten und Konfigurationszugänge bestätigt wurden, jedoch unterschiedliche Coze-Regionen, Versionen oder Pakete unterschiedliche Formulare anzeigen können. Ace Data Cloud muss weiterhin die Validierung fester Versionen gemäß den Protokollen abschließen. Erfolgreiche Implementierungen eines Protokolls sollten nicht auf die anderen beiden extrapoliert werden.

## Konfigurationsprinzipien

- Die Basis-API-URL sollte vorrangig mit der im Dokument angegebenen Basis ausgefüllt werden; fügen Sie keinen Endpunkt-Pfad hinzu, der automatisch vom Client ergänzt wird.
- Der API-Schlüssel verwendet Ihr Ace Data Cloud API-Token.
- Das Modell verwendet die genaue Modell-ID, die im Modellverzeichnis mit dem gewählten Protokoll kompatibel ist.
- Nach erfolgreichem Test mit einfachem Text sollten auch Streaming und Toolaufrufe validiert werden.
