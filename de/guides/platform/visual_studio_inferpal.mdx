Inferpal ist eine Erweiterung für Visual Studio 2022/2026, die offiziell die Verbindung zu OpenAI-kompatiblen Diensten unterstützt. Die Erweiterungsversion kann die Bearbeitung, den Aufruf von Tools und die Nutzungserfassung beeinflussen; bei der ersten Integration bitte die Version fixieren und die nachfolgende minimale Validierung durchführen.

## Konfiguration

1. Installieren Sie Inferpal aus dem Visual Studio Marketplace oder dem offiziellen Repository.
2. Öffnen Sie die **Einstellungen → Verbindung** von Inferpal.
3. Wählen Sie als Anbieter OpenAI-kompatibel.
4. Geben Sie die Basis-URL als `https://api.acedata.cloud/v1` ein.
5. Geben Sie den API-Schlüssel als Ihr Ace Data Cloud API-Token ein.
6. Geben Sie das Modell als die genaue Modell-ID ein, die im Modellverzeichnis Chat Completions unterstützt.
7. Senden Sie nach dem Speichern `Reply only OK` und führen Sie dann erneut eine Anfrage mit dem Codekontext aus.

## Aktuelle Grenzen

- Diese Anleitung deckt nur Inferpal ab und stellt nicht sicher, dass Visual Studio's integrierter Copilot oder andere Erweiterungen dieselben Felder unterstützen.
- Unterschiedliche Versionen können automatisch Pfade zur Basis-URL hinzufügen; wenn die Anfrage fehlschlägt, überprüfen Sie bitte zuerst, ob die endgültige Anfrage im Chat Completions-Endpunkt liegt.
- Vor Abschluss der festen Version E2E wird nicht garantiert, dass alle Bearbeitungs-, Vervollständigungs- oder Toolaufrufmodi verfügbar sind.
