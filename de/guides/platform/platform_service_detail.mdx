Rufen Sie die vollständigen Informationen eines einzelnen Dienstes über die Dienst-ID (UUID) oder den Alias (`alias`) ab — die zurückgegebenen Felder sind umfassender als bei [AceDataCloud-Plattform-Dienstliste abrufen](https://platform.acedata.cloud/documents/platform-service-list), zusätzlich werden verknüpfte Objekte wie `apis`, `proxies`, `datasets`, `packages` usw. erweitert. Geeignet für Szenarien wie Dienst-Detailseiten, Preisvergleichsseiten und Agent-Tool-Beschreibungen.

> ℹ️ Diese Schnittstelle gehört zur **AceDataCloud-Plattformverwaltungs-API** mit dem einheitlichen Präfix `https://platform.acedata.cloud/api/v1/`. Den vollständigen Schnittstellenindex finden Sie unter [AceDataCloud-Plattform-Dokumentliste abrufen](https://platform.acedata.cloud/documents/platform-document-list).

## Schnittstellenübersicht

| Element   | Inhalt                                                        |
| --- | ------------------------------------------------------------- |
| Methode  | `GET`                                                         |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}` |
| Authentifizierung  | ❌ Öffentlich                                                          |

`/services/{id}` und `/services/{id}/` sind derzeit beide verfügbar; die Beispiele verwenden einheitlich die Form ohne abschließenden Schrägstrich.

## Hinweise zur Authentifizierung

Diese Schnittstelle ist vollständig öffentlich. **Wenn jedoch ein Kontotoken mitgegeben wird, spiegelt das Feld `applied` in der Antwort den tatsächlichen Antragsstatus des aktuellen Kontos wider**, andernfalls ist es immer `false`.

Wie Sie das Kontotoken erhalten, erfahren Sie unter [AceDataCloud-Plattform-Kontotoken verwalten](https://platform.acedata.cloud/documents/platform-token).

## Pfadparameter

| Parameter           | Typ            | Erforderlich  | Beschreibung                                                    |
| ------------ | ------------- | --- | ----------------------------------------------------- |
| `service_id` | UUID / string | ✅   | Dienst-ID (UUID) oder Alias (z. B. `midjourney`, `openai`, `webextrator`) |

## Anfragebeispiele

### cURL

```shell
# 按 UUID 查询
curl 'https://platform.acedata.cloud/api/v1/services/8efa1d83-9b75-4562-b44a-af95ce563d05' \
  -H 'accept: application/json'

# 按 alias 查询
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json'

# 带账户令牌看 applied 状态
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

resp = requests.get(
    "https://platform.acedata.cloud/api/v1/services/midjourney",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
svc = resp.json()
print(f"服务: {svc['title']} ({svc['alias']})")
print(f"已申请: {svc['applied']}, 免费额度: {svc['free_amount']} {svc['unit']}")
print(f"API 数: {len(svc['apis'])}, 套餐数: {len(svc['packages'])}")
for pkg in svc["packages"]:
    print(f"  ¥{pkg['price']:>7.2f}  ->  {pkg['amount']} {svc['unit']}")
```

### Node.js

```javascript
const r = await fetch('https://platform.acedata.cloud/api/v1/services/midjourney', {
  headers: { accept: 'application/json' },
})
const svc = await r.json()
console.log(`${svc.title} - 套餐 ${svc.packages.length} 个 - API ${svc.apis.length} 个`)
```

## Beschreibung der Antwortfelder

Die Detail-Schnittstelle erweitert zusätzlich zu allen Feldern der [Listenschnittstelle](https://platform.acedata.cloud/documents/platform-service-list):

| Feld         | Typ    | Beschreibung                                                            |
| ---------- | ----- | ------------------------------------------------------------- |
| `apis`     | array | Vollständige Liste der verknüpften API-Objekte (jeder Eintrag enthält `id`, `name`, `title`, `path`, `stage`, `cost`) |
| `proxies`  | array | Vollständige Liste der verknüpften Proxy-Objekte                                              |
| `datasets` | array | Verknüpfte Datensätze (wenn `type=Dataset`)                                      |
| `packages` | array | Paketliste mit `type` (`Usage`/`Period`), `price`, `amount`, `duration`   |

Die Definitionen der übrigen Felder finden Sie unter [AceDataCloud-Plattform-Dienstliste abrufen → Beschreibung der Antwortfelder](https://platform.acedata.cloud/documents/platform-service-list).

## Fehlerbehandlung

| HTTP | code        | Bedeutung                            |
| ---- | ----------- | ----------------------------- |
| 404  | `not_found` | `service_id` (UUID oder Alias) existiert nicht |
| 500  | —           | Meist wurde am Ende der URL fälschlicherweise ein Schrägstrich hinzugefügt; entfernen Sie ihn und versuchen Sie es erneut          |

## Praktische Hinweise

- **`alias` > `UUID`**: Es ist stabiler, den `alias` (z. B. `midjourney`) im Code fest zu hinterlegen; die UUID ändert sich bei der Migration von Umgebungen.
- **Das Feld `apis` enthält keine OpenAPI-Definition**: Das vollständige OpenAPI-3.0-Schema befindet sich in der Schnittstelle [AceDataCloud-Plattform-API-Details abrufen](https://platform.acedata.cloud/documents/platform-api-detail).
- **Die „vollständigen Fähigkeiten“ eines Dienstes abrufen**: Verwenden Sie diese Schnittstelle, um `api_ids` zu erhalten, und rufen Sie dann einzeln `/apis/{api_id}` auf, um Details abzurufen.
- **Wenn `applied=true`**, können Sie direkt [API-Anmeldedaten erstellen](https://platform.acedata.cloud/documents/platform-credential-create), um das für den Aufruf der Geschäftsschnittstelle erforderliche 32-stellige Token zu erhalten, ohne erneut einen Antrag stellen zu müssen.
