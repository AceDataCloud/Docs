---
title: "Abrufen der Proxy-Liste unter einem AceDataCloud-Plattformdienst"
description: "Platform API guide - Ace Data Cloud"
---

Gibt die an diesen Dienst angehängten Proxy-Endpunkte seitenweise über die Service UUID zurück. Wenn nur ein alias vorhanden ist, rufen Sie zuerst [Servicedetails](https://platform.acedata.cloud/documents/platform-service-detail) auf, um `id` zu erhalten.

## Schnittstellenübersicht

| Element   | Inhalt                                                                     |
| --- | ---------------------------------------------------------------------- |
| Methode  | `GET`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| Authentifizierung  | Öffentlich, kein Kontotoken erforderlich                                                              |
| Paginierung  | `count` + `items`                                                      |

## Parameter

| Parameter                 | Position    | Erforderlich  | Beschreibung                               |
| ------------------ | ----- | --- | -------------------------------- |
| `service_id`       | path  | Ja   | Service UUID, alias wird nicht unterstützt           |
| `limit` / `offset` | query | Nein   | Paginierung                               |
| `ordering`         | query | Nein   | Django-Sortierausdruck; empfohlen `rank` oder `-rank` |

```shell
export SERVICE_ID='Deine Service-ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## Antwortbeschreibung

Listenelemente werden durch das Proxy-Modell serialisiert, online verifizierte Felder umfassen `id`, `service_id`, `title`, `endpoint`, `price`, `stage`, `rank`, `tags`, `metadata`, `document_id`, `service` und Zeitfelder.

- Das Geschäftseinstiegsfeld ist `endpoint`, nicht `path`.
- Das Preisfeld ist `price`, nicht `cost`.
- Wenn der Service-Typ nicht Proxy ist oder kein Proxy angehängt ist, werden leere `items` zurückgegeben.

Öffentliche Integrationen stützen sich nur auf `endpoint` und veröffentlichte Fähigkeiten und sollten sich nicht auf unveröffentlichte Implementierungsdetails stützen.
