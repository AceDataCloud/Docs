Gibt den öffentlichen Modellkatalog der Plattform zurück; die Antwort verwendet die OpenAI-ähnliche Struktur `{ "object": "list", "data": [...] }`. Dieser Katalog dient der Modellauswahl und Fähigkeitserkennung und bedeutet nicht, dass das aktuelle Konto die entsprechenden Dienste bereits beantragt hat.

## Schnittstellenübersicht

| Element   | Inhalt                                              |
| --- | ----------------------------------------------- |
| Methode  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| Authentifizierung  | Öffentlich, kein Kontotoken erforderlich                                       |
| Seitennummerierung  | Keine Seitennummerierung, alle Übereinstimmungen befinden sich in `data`                              |

## Abfrageparameter

| Parameter             | Typ      | Erforderlich  | Beschreibung                                      |
| -------------- | ------- | --- | --------------------------------------- |
| `owned_by`     | string  | Nein   | Exakte Filterung nach der Anbieterkennung des Modells im Katalog                        |
| `type`         | string  | Nein   | Exakte Filterung nach Modelltyp, beispielsweise `chat`                     |
| `capability`   | string  | Nein   | Gibt nur Modelle zurück, deren `capabilities` diese Fähigkeit enthalten, beispielsweise `vision` |
| `with_pricing` | boolean | Nein   | Fügt bei `1`, `true` oder `yes` öffentliche Preisinformationen hinzu            |

`service_id`, `tag`, `limit`, `offset` und `ordering` werden derzeit nicht unterstützt; ihre Übergabe führt nicht zu entsprechenden Filterungs- oder Seitennummerierungseffekten.

## Anfragebeispiele

```shell
# Alle öffentlichen Modelle
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# Chat-Modelle mit visueller Unterstützung, einschließlich Preise
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## Tatsächliche Antwortstruktur

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

`pricing` und das oberste `credit_usd_rate` erscheinen nur bei `with_pricing=true`; nicht jedes Modell verfügt über berechenbares `pricing`. Maßgeblich für Modellobjekte sind die öffentlichen Felder in `config/models.json`; Clients sollten neu hinzugefügte Felder ignorieren.

> Preisfelder sind Kataloganzeigedaten. Für tatsächliche geschäftliche Aufrufe gelten weiterhin die Abrechnungsregeln der entsprechenden API/des entsprechenden Service sowie die endgültigen Nutzungsaufzeichnungen.
