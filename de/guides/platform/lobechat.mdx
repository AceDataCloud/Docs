[LobeChat](https://lobehub.com/) ist ein Open-Source-AI-Client, der Plugins, Wissensdatenbanken und Selbstbereitstellung unterstützt und online oder per Docker genutzt werden kann. Er unterstützt benutzerdefinierte OpenAI-kompatible Endpunkte und kann daher mit Ace Data Cloud verbunden werden. Dieser Artikel beschreibt den Konfigurationsprozess.

## Antragsprozess

Um Ace Data Cloud in LobeChat zu integrieren, gehen Sie zunächst zur [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications), holen Sie sich Ihren API-Token und bewahren Sie ihn als Reserve auf.

![Ace Data Cloud API Key abrufen](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach der Anmeldung und Registrierung kehren Sie automatisch zu dieser Seite zurück.

Bei der ersten Beantragung wird ein kostenloses Kontingent vergeben, mit dem Sie die Modelldienste von Ace Data Cloud kostenlos testen können.

## Ace Data Cloud konfigurieren

Gehen Sie in LobeChat zu **App-Einstellungen → Sprachmodelle**, suchen Sie die Karte **OpenAI**, aktivieren Sie sie und tragen Sie Folgendes ein:

| Feld       | Wert                              | Beschreibung                         |
| -------- | ------------------------------ | -------------------------- |
| API Key  | Ihr Ace Data Cloud Token        | Der aus der Konsole kopierte Token               |
| API-Proxy-Adresse | `https://api.acedata.cloud/v1` | **Muss mit `/v1` enden**           |
| Client-Anfragemodus  | Aktivieren                             | Direkte Browserverbindung, der Key passiert nicht den LobeChat-Server |

![LobeChat OpenAI Provider Konfigurationsoberfläche](https://cdn.acedata.cloud/629ef9d3084a.png)

> Bei Verwendung der Chat-Completions-Schnittstelle lassen Sie Responses API Specification deaktiviert.

LobeChat fügt `/v1` nicht automatisch an die Base URL an; der Anfragepfad lautet direkt `{API-Proxy-Adresse}/chat/completions`:

| API-Proxy-Adresse                              | Tatsächliche Anfrage                                                   | Ergebnis                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | Korrekt                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | Ebenfalls verfügbar                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (unter `/openai` gibt es kein `/v1`) |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404 (`/v1` fehlt)             |

LobeChat ruft standardmäßig `/v1/models` auf, um Modelle automatisch abzurufen. Wenn Ace Data Cloud viele Modelle zurückgibt, kann die Oberfläche sehr lang werden. Es wird empfohlen, unter „Modellliste → Benutzerdefinierte Modellnamen“ manuell eine Allowlist einzugeben, getrennt durch englische Kommas. Wenn Sie einen benutzerdefinierten Anzeigenamen benötigen, können Sie `=` im Format `MODEL_ID=Anzeigename` verwenden.

## Modell auswählen

Der Modellkatalog wird fortlaufend aktualisiert. Verwenden Sie vorrangig die automatisch vom Client geladene Modellliste; wenn eine manuelle Eingabe erforderlich ist, fragen Sie zunächst `GET https://api.acedata.cloud/v1/models` ab, um die aktuellen Modell-IDs zu erhalten, und wählen Sie dann entsprechend den vom Client unterstützten Kontext-, Bild- und Tool-Call-Funktionen aus.

## Integration überprüfen

Wenn Sie nicht sicher sind, ob das Problem bei LobeChat oder beim Netzwerk liegt, können Sie zunächst den Endpunkt direkt mit curl überprüfen (ersetzen Sie `{token}` durch Ihren Token):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Wenn ein OpenAI-kompatibles `chat.completion`-Objekt zurückgegeben wird, sind Token und Endpunkt bereit; wenn `HTTP 403 used_up` zurückgegeben wird, ist der Token gültig, aber das Guthaben reicht nicht aus. Laden Sie einfach in der [Konsole](https://platform.acedata.cloud/console/applications) Guthaben auf.

## Erweitert: Docker-Selbstbereitstellung

Wenn Sie eine private Version für Ihr Team bereitstellen möchten, können Sie Docker mit einem einzigen Befehl starten (ersetzen Sie `{token}` durch Ihren Token):

```bash
docker run -d \
  --name lobe-chat \
  -p 3210:3210 \
  -e OPENAI_API_KEY={token} \
  -e OPENAI_PROXY_URL=https://api.acedata.cloud/v1 \
  -e ACCESS_CODE=your-secret-password \
  -e OPENAI_MODEL_LIST="MODEL_ID" \
  lobehub/lobe-chat:latest
```

Öffnen Sie `http://Ihre-Server-IP:3210` und geben Sie `ACCESS_CODE` ein, um es zu verwenden. Teammitglieder müssen ihre Keys nicht jeweils selbst eintragen. Die vollständige Beschreibung der oben verwendeten Umgebungsvariablen wie `OPENAI_API_KEY`, `OPENAI_PROXY_URL` und `OPENAI_MODEL_LIST` finden Sie in der [Dokumentation zu Umgebungsvariablen für LobeChat-Modellanbieter](https://lobehub.com/docs/self-hosting/environment-variables/model-provider). Wenn Sie einen nginx-Reverse-Proxy mit HTTPS verwenden, fügen Sie unbedingt `proxy_buffering off;` hinzu, da Streaming-Antworten sonst gepuffert werden. Weitere Bereitstellungsformen finden Sie unter [LobeChat Selbstbereitstellung – Einstieg](https://lobehub.com/docs/self-hosting/start) und [Docker-Compose-Bereitstellung](https://lobehub.com/docs/self-hosting/platform/docker-compose).

## Häufig gestellte Fragen

### Hinweis 404 Not Found

Normalerweise wurde die API-Proxy-Adresse als `.../openai/v1` eingetragen oder `/v1` fehlt. Ändern Sie sie zu `https://api.acedata.cloud/v1`.

### Modellliste ist leer

Aktivieren Sie den Schalter „Client-Anfragemodus“; oder tragen Sie die Modell-Allowlist manuell unter „Benutzerdefinierte Modellnamen“ ein.

### Hinweis 401 Unauthorized

Bitte bestätigen Sie, dass im API Key der Token von Ace Data Cloud eingefügt wurde (ohne das Präfix `Bearer` und ohne zusätzliche Leerzeichen) und dass das Guthaben der zugehörigen Anwendung ausreichend ist.
