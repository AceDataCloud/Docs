Du bist wahrscheinlich auch schon auf diese Situation gestoßen: Du verwendest Claude Code, Cursor oder Codex, bist gerade mitten im Programmieren, und plötzlich brauchst du ein passendes Bild, ein Stück Hintergrundmusik, ein kurzes Video oder möchtest es schnell die neuesten Informationen nachschlagen lassen. Dann stellst du fest – der Agent selbst kann das nicht. Du musst selbst nach APIs suchen, Dokumentationen lesen, Keys konfigurieren, Aufrufcode schreiben und asynchrones Polling verarbeiten. Nach diesem ganzen Aufwand ist die Inspiration längst verflogen.

[AceKit](https://github.com/AceDataCloud/AceKit) ist dazu da, dir genau diesen ganzen Aufwand zu ersparen. Mit einer einzigen Zeile Befehl installiert es die Funktionen von AceData Cloud für Bildgenerierung, Videogenerierung, Musikgenerierung, Websuche, LLM-Dialoge und mehr als komplettes Paket in deinem Coding-Agenten. Nach der Installation sprichst du einfach ganz normal, und der Agent lädt die passenden Skills selbst, authentifiziert sich selbst, führt selbst das Polling durch und erledigt die Aufgabe.

## In 30 Sekunden verstehen, was es macht

Vor der Installation vs. nach der Installation:

| Was du sagst               | Vor der Installation                   | Nach der Installation (der Agent erledigt es selbst)                      |
| ------------------ | --------------------- | ----------------------------------- |
| "Gib dieser README ein Titelbild" | Der Agent kann das nicht und lässt dich selbst nach einer Bildgenerierungs-API suchen | Ruft NanoBanana / Flux / Midjourney zur Bildgenerierung auf |
| "Mach aus diesem Skript ein 30-sekündiges Kurzvideo"  | Kann er nicht                    | Ruft Sora / Veo / Kling / Seedance zur Videoerstellung auf  |
| "Gib diesem Demo ein Stück Hintergrundmusik"  | Kann er nicht                    | Ruft Suno zur Musikerstellung auf                           |
| "Suche nach dem neuesten X und fasse es dann zusammen"     | Hat keinen Internetzugang                  | Ruft Google SERP auf, um Echtzeitergebnisse abzurufen                 |
| "Kürze diesen langen Link"         | Kann er nicht                    | Ruft einen Kurzlink-Dienst auf und gibt einen surl.id-Link zurück                  |

Kurz gesagt: **Dein Coding-Agent entwickelt sich von „kann nur Code schreiben“ zu „kann auch Bilder, Videos und Musik generieren sowie im Internet suchen“.**

## Einstieg in drei Schritten

Der gesamte Prozess ist in wenigen Minuten erledigt und benötigt Node.js 18+.

**Schritt eins · Einen API-Token besorgen.** Kopiere den Token in der [Konsole](https://platform.acedata.cloud/console/applications) – alle Funktionen verwenden denselben Token. Bei der ersten Beantragung gibt es kostenloses Guthaben, sodass du es zunächst kostenlos ausprobieren kannst.

![API-Token in der Konsole kopieren](https://cdn.acedata.cloud/dvc3cg.jpg)

**Schritt zwei · Installieren.** Ein einziger Befehl:

```bash
npx acekit
```

Es erkennt automatisch die Coding-Agenten auf deinem Rechner und installiert das komplette Skill-Paket. So sieht ein tatsächlicher Durchlauf aus (auf diesem Rechner ist nur Claude Code installiert):

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> Wenn kein Token gesetzt ist, wirst du beim ersten Ausführen interaktiv aufgefordert, ihn einzufügen; alternativ kannst du vorher `export ACEDATACLOUD_API_TOKEN=dein_token` setzen, um die Installation vollständig unbeaufsichtigt durchzuführen. Die Anzahl der Skills kann sich mit den wachsenden Plattformfunktionen ändern; maßgeblich ist die aktuelle Liste, die `npx acekit list` anzeigt.

**Schritt drei · Normal sprechen.** Lade den Agenten neu und gib dann direkt Anweisungen, zum Beispiel:

```text
Kürze mit dem short-url-Skill https://platform.acedata.cloud/services
```

Der Agent lädt den Skill selbst, startet den Aufruf selbst und liefert dir ein echtes Ergebnis, zu dem du navigieren kannst.

## Ein echter Durchlauf (mit Ausgabe)

Die folgenden vier Beispiele sind allesamt **echte Aufrufe mit direkt zurückgegebenen Ergebnissen**, keine Demonstrationen. Das `$KEY` in den Befehlen ist dein API-Token.

**① URL kürzen (synchron, Antwort in Sekunden)**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

Gibt `https://surl.id/r/1uKp2kilXQ` zurück – beim Öffnen erfolgt eine 302-Weiterleitung zurück zur ursprünglichen services-Seite.

**② Internetsuche (synchron)**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

Es werden aktuelle Google-Ergebnisse abgerufen (Auszug):

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ LLM-Dialog (synchron, eine Schnittstelle für 50+ Modelle)**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP ist ein Protokoll zur einheitlichen Verwaltung und zum Austausch von Modellkontextinformationen.
（39 Tokens, dieses Mal etwa 0.00007 Credit）
```

**④ Bildgenerierung (asynchron, etwa 20 Sekunden, der Agent führt automatisch Polling bis zur Bildausgabe durch)**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

Nach etwa 22 Sekunden wird ein echtes Bild zurückgegeben (HTTP 200 · image/png · 317 KB · dieses Mal etwa 0.13 Credit):

![Von AceKit tatsächlich generiertes Bild](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

Diese Schnittstellen musst du dir eigentlich nicht merken – nach der Installation der Skills stellt der Agent anhand der jeweiligen `SKILL.md` selbst die korrekten Anfragen zusammen und verarbeitet Authentifizierung und Polling. Oben wird dir nur aufgeschlüsselt gezeigt, „was es im Hintergrund macht“.

## Was installiert es eigentlich

AceKit ist der „Vordereingang“ der gesamten Entwickler-Tool-Landschaft von AceData; derzeit installiert eine Installation das **Skill-Toolkit (Skills)**:

- **Ein Satz Agent-Skills**: Jeder Skill ist ein fertig geschriebenes `SKILL.md`-Bedienungshandbuch – Authentifizierung, asynchrones Polling, Fehlerwiederholungen und das Ausfüllen der Parameter sind alle klar beschrieben, sodass der Agent ihnen einfach folgen kann. Führe `npx acekit list` aus, um die aktuelle Liste zu sehen (zum Zeitpunkt des Schreibens dieses Artikels sind es 19 und es werden kontinuierlich mehr):
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **Ein einheitliches Token**: Ein `ACEDATACLOUD_API_TOKEN` schaltet alle Funktionen frei, Abrechnung nach tatsächlicher Nutzung.

Nach Funktionen kategorisiert (maßgeblich ist `npx acekit list`):

| Typ         | Anbieter                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ Bildgenerierung      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 Videogenerierung      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 Musik- / Audiogenerierung | Suno · Producer · Fish Audio（TTS）                    |
| 💬 LLM-Chat   | Einheitliche Schnittstelle für 50+ Modelle（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 Suche       | Google SERP（Web · Bilder · Nachrichten · Karten · Videos）                  |
| 🔗 Tools       | Kurzlinks · Gesichtsverarbeitung                                            |

> Dieselben Funktionen bietet AceData auch als eigenständige **MCP-Server**（Suno、Midjourney、Sora、SERP… bereits auf PyPI / VS Code / Smithery / Docker veröffentlicht）、**Kommandozeilen-CLI** und **Python- / TypeScript-SDK** an und können bei Bedarf einzeln verwendet werden. AceKit v0.2 plant, die Installation einzelner Funktionen mit `acekit add <name>` sowie das automatische Schreiben der MCP-Konfigurationen verschiedener Agents zu unterstützen.

## Welche Agents werden unterstützt

| Agent                        | Installationspfad für Skills                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode usw. | `~/.agents/skills`（lasse deinen Agent darauf verweisen） |

Bei der Installation erkennt AceKit automatisch die bereits auf dem Rechner installierten Agents und installiert es nur in den erkannten.

## Easter Egg: Claude Code selbst mit demselben Token betreiben

Die Schnittstelle von AceData ist gleichzeitig mit dem Anthropic-Format `/v1/messages` kompatibel, daher **brauchst du kein offizielles Anthropic-Abonnement** und kannst Claude Code mit demselben AceData-Token betreiben. Erstelle im Projekt-Stammverzeichnis `.claude/settings.local.json`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Starte Claude Code einfach neu – es nutzt dann sowohl die gesamte Claude-Modellreihe als auch über AceKit die „Hände“ zur Bild-, Video- und Musikgenerierung. Weitere Details findest du im [Claude-Code-Integrationsleitfaden](https://platform.acedata.cloud/documents/claude-code-integration).
