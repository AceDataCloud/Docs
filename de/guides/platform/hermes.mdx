Hermes Agent integriert sich über das OpenAI Chat Completions-Protokoll in die Ace Data Cloud. Wählen Sie eine der Konfigurationsmethoden:

| Konfigurationsmethode        | Anleitung                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| `hermes model` Interaktivführer | [Führer-Konfiguration](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| `config.yaml` manuelle Konfiguration  | [Manuelle Konfiguration](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| Plattform-private Bereitstellung              | [Verwaltete Bereitstellung](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

Gemeinsame Parameter für die lokale Integration:

- Basis-URL: `https://api.acedata.cloud/v1`
- Transport: `chat_completions`
- Anbieter: `custom:acedatacloud`
- API-Schlüssel: von [Anwendungsliste](https://platform.acedata.cloud/console/applications) abrufen

Beide lokalen Methoden werden schließlich in `~/.hermes/config.yaml` geschrieben, nicht doppelt konfigurieren.

Zurück zum [Coding Plan Konfigurationszentrum](https://platform.acedata.cloud/documents/coding-plan-integration).
