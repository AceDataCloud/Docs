---
title: "Abrufen der Liste der APIs unter einem AceDataCloud-Plattformdienst"
description: "Platform API guide - Ace Data Cloud"
---

Gibt die derzeit aktivierten und nicht verworfenen APIs dieses Dienstes seitenweise über die Service-UUID zurück. Wenn nur ein Alias vorhanden ist, rufen Sie zuerst [Servicedetails](https://platform.acedata.cloud/documents/platform-service-detail) auf, um die `id` zu erhalten.

## Schnittstellenübersicht

| Element   | Inhalt                                                              |
| --- | ------------------------------------------------------------------- |
| Methode  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| Authentifizierung  | Öffentlich, kein Kontotoken erforderlich                                                           |
| Seitennummerierung  | `count` + `items`                                                   |

## Parameter

| Parameter           | Position    | Erforderlich  | Beschreibung                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | Ja   | Service-UUID, Alias wird nicht unterstützt           |
| `limit`      | query | Nein   | Anzahl der Einträge pro Seite, maximal 100                      |
| `offset`     | query | Nein   | Offset der Seitennummerierung                            |
| `ordering`   | query | Nein   | Django-Sortierausdruck; empfohlen `rank` oder `-rank` |

Die aktuelle Schnittstelle unterstützt keine `stage`-Filterung; sie hat `Deprecated`-APIs bereits ausgeschlossen.

```shell
export SERVICE_ID='Deine Service-ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

Listeneinträge verwenden dieselbe Indexstruktur wie die [Plattform-API-Liste](https://platform.acedata.cloud/documents/platform-api-list) und enthalten derzeit `definition`. Wenn ein stabiler Einstieg für eine einzelne API benötigt wird, rufen Sie weiterhin `/api/v1/apis/{api_id}` auf.

## Fehlerbehandlung

- Der Dienst existiert nicht oder ist auf der aktuellen Website nicht sichtbar: `404`.
- `service_id` muss eine UUID sein; der Alias wird in dieser Aktion nicht aufgelöst.
