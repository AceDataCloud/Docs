FreeAIr ist eine Open-Source-Erweiterung für Visual Studio 2022/2026, die offiziell erklärt, dass sie sich mit beliebigen OpenAI-kompatiblen APIs verbinden kann. Das Anforderungsverhalten kann je nach Version der Erweiterung variieren; bei der ersten Anbindung bitte eine feste Version wählen und die nachfolgende minimale Validierung durchführen.

## Konfiguration

1. Installieren Sie FreeAIr aus dem Visual Studio Marketplace oder dem offiziellen Repository.
2. Öffnen Sie die FreeAIr-Einstellungen und fügen Sie eine OpenAI-kompatible Verbindung hinzu.
3. Geben Sie für den Endpoint `https://api.acedata.cloud/v1` ein.
4. Geben Sie für das Token Ihren Ace Data Cloud API-Token ein.
5. Geben Sie für das Model die genaue Modell-ID ein, die Chat Completions im Modellverzeichnis unterstützt.
6. Senden Sie nach dem Speichern `Reply only OK` und testen Sie erneut eine Anfrage mit Projektkontext.

## Aktuelle Grenzen

- Diese Anleitung behandelt nur FreeAIr und stellt nicht dar, dass Visual Studio eingebauten Copilot Unterstützung für beliebige Basis-URLs bietet.
- Die Version der Erweiterung kann die Art und Weise ändern, wie der Endpoint zusammengesetzt wird; bei der Validierung sollte die endgültige Anforderungs-URL überprüft werden.
- Die Nutzung von Tools und die MCP-Funktionalität innerhalb der Erweiterung müssen unabhängig validiert werden und können nicht durch den Erfolg eines normalen Chats ersetzt werden.
