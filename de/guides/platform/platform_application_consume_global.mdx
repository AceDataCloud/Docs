---
title: "Globale Guthabenfreigabe für AceDataCloud Application festlegen"
description: "Platform API guide - Ace Data Cloud"
---

Legen Sie `allow_consume_global` fest. Nach der Aktivierung können berechtigte nutzungsbasierte Applications bei unzureichendem eigenem Guthaben weiterhin das globale Kontoguthaben verwenden.

## Vorbereitungen

- Erstellen und speichern Sie sicher einen [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Erhalten Sie aus der [Liste der Service-Anträge](https://platform.acedata.cloud/documents/platform-application-list) die `application_id`, die Ihnen gehört.

```shell
export PLATFORM_TOKEN='Ihr Konto-Token'
export APPLICATION_ID='Ihre Application-ID'
```

## Schnittstellenübersicht

| Element    | Inhalt                                                                                             |
| ---- | -------------------------------------------------------------------------------------------------- |
| Methode   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Authentifizierung   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

Bei Erfolg wird das aktualisierte Application-Objekt zurückgegeben. Maßgeblich ist `allow_consume_global` in der Antwort, anstatt anzunehmen, dass der Anfragewert unbedingt gespeichert wurde.

> Applications vom Typ `Period` dürfen kein globales Guthaben verbrauchen. Auch wenn `true` angefragt wird, hält der Server dieses Feld auf `false`.

## Fehlerbehandlung

- `401`: Account Token ist ungültig oder fehlt.
- `403`: Das aktuelle Konto ist nicht der Eigentümer dieser Application.
- `404`: Application-ID existiert nicht.

Der Aufladezugang für globales Guthaben und die verfügbaren Pakete richten sich nach der Plattformkonsole und den tatsächlich von [Bestellung erstellen](https://platform.acedata.cloud/documents/platform-order-create) zurückgegebenen Paketen; nehmen Sie nicht an, dass Pakete vom Typ `Wallet` vorhanden sind.

## Anwendungen mit autorisiertem Überziehen

Wenn das schreibgeschützte Feld `allow_overdraft=true` einer nutzungsbasierten Anwendung gesetzt ist, kann diese Anwendung weiterhin Gebühren von ihrem eigenen Guthaben abziehen, auch wenn das Guthaben negativ wird, und wechselt nicht aufgrund eines unzureichenden Guthabens zum globalen Konto. Anwendungen ohne aktiviertes Überziehen folgen weiterhin `allow_consume_global`; ob nach dem Wechsel ein Überziehen erlaubt ist, richtet sich nach der Einstellung der globalen Application, von der tatsächlich abgebucht wird.
