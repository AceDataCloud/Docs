---
title: "Globale Guthabenfreigabe für AceDataCloud Application festlegen"
description: "Platform API guide - Ace Data Cloud"
---

Legen Sie `allow_consume_global` fest. Nach der Aktivierung können berechtigte nutzungsbasierte Applications bei unzureichendem eigenem Guthaben weiterhin das globale Kontoguthaben verwenden.

## Vorbereitungen

- Erstellen und speichern Sie sicher einen [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Erhalten Sie die Ihnen gehörende `application_id` aus der [Liste der Service-Anträge](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='Ihr Konto-Token'
export APPLICATION_ID='Ihre Application-ID'
```

## API-Übersicht

| Element    | Inhalt                                                                                             |
| ---- | -------------------------------------------------------------------------------------------------- |
| Methode   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Authentifizierung   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

Bei Erfolg wird das aktualisierte Application-Objekt zurückgegeben. Maßgeblich ist `allow_consume_global` in der Antwort, statt anzunehmen, dass der Anforderungswert unbedingt gespeichert wurde.

> Applications vom Typ `Period` dürfen kein globales Guthaben verbrauchen. Selbst bei einer Anforderung von `true` hält der Server dieses Feld auf `false`.

## Fehlerbehandlung

- `401`: Der Account Token ist ungültig oder fehlt.
- `403`: Das aktuelle Konto ist nicht der Eigentümer dieser Application.
- `404`: Die Application-ID existiert nicht.

Der Aufladezugang für das globale Guthaben und die verfügbaren Pakete richten sich nach der Plattformkonsole sowie den tatsächlich in der [Bestellerstellung](https://platform.acedata.cloud/documents/platform-order-create) zurückgegebenen Paketen; gehen Sie nicht davon aus, dass Pakete vom Typ `Wallet` existieren.
