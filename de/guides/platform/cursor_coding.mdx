Cursor bietet derzeit die OpenAI API Key und die Einstellung **Override OpenAI Base URL** an, um sich mit OpenAI-kompatiblen Diensten zu verbinden. Diese Fähigkeit ist vorhanden, jedoch ist die Handhabung von `/chat/completions`, `/responses`, der Modellliste sowie der Modi Agent/Composer in verschiedenen Versionen nicht vollständig konsistent.

Die Kompatibilität kann je nach Cursor-Version, Betriebssystem und Anforderungsmodus variieren. Bitte führen Sie die tatsächliche Modusprüfung gemäß der Konfiguration auf dieser Seite durch und schließen Sie nicht aus einer einmaligen erfolgreichen Unterhaltung auf die Verfügbarkeit aller Funktionen.

## Was garantiert Cursor offiziell für BYOK

Laut [Cursor offizieller Bring your own API key Dokumentation](https://cursor.com/help/models-and-usage/api-keys):

- Unterstützung für Anmeldeinformationen von OpenAI, Anthropic, Google, Azure OpenAI und AWS Bedrock;
- Benutzerdefinierte API-Keys werden nur für Chat-Modelle verwendet, die Tab-Vervollständigung verwendet weiterhin die integrierten Modelle von Cursor;
- API-Keys werden nicht auf den Cursor-Servern persistent gespeichert, sondern bei jeder Anfrage an das Cursor-Backend gesendet, um den endgültigen Prompt zu erstellen;
- Bei Verwendung eines eigenen Keys gilt die Zero Data Retention-Politik von Cursor nicht, die Datenverarbeitung unterliegt den Richtlinien des gewählten Anbieters.

## Konfiguration

1. Öffnen Sie Cursor Einstellungen → Modelle.
2. Geben Sie Ihren Ace Data Cloud API Token im OpenAI API Key ein.
3. Aktivieren Sie **Override OpenAI Base URL** und geben Sie `https://api.acedata.cloud/v1` ein.
4. Wählen oder fügen Sie die genaue Modell-ID hinzu, die mit dem aktuellen Cursor-Protokoll kompatibel ist.
5. Senden Sie zuerst `Reply only OK`, und testen Sie dann die Modi Ask/Edit/Agent, die Sie tatsächlich verwenden.

## Aktuelle Grenzen

- Benutzerdefinierte API-Keys werden nur für Chat-Modelle verwendet, die Tab-Vervollständigung verwendet weiterhin die integrierten Modelle von Cursor.
- Cursor kann weiterhin auf dem Server den endgültigen Prompt erstellen; bitte bewerten Sie den Datenpfad in Verbindung mit den offiziellen Datenschutzbestimmungen.
- Die Base URL Override könnte nur einen Teil der Anfragen überschreiben oder aufgrund von Versionsänderungen zwischen Chat Completions/Responses wechseln.
- Man sollte nicht nur aufgrund einer erfolgreichen Chat-Anfrage behaupten, dass Agent, Auto, Composer oder Hintergrundaufgaben verbunden sind.

## Vollständige Kompatibilitätsprüfung

Um eine langfristige Nutzung in Produktions-Workflows zu gewährleisten, führen Sie bitte die folgenden Prüfungen durch:

1. Feste Cursor-Version und Betriebssystem;
2. Führen Sie einen echten Client-Smoketest für diese Version durch und dokumentieren Sie das endgültige Anfrageprotokoll und den Pfad;
3. Erfolgreiche Chat Completions-Anfrage für das genaue Modell;
4. Toolaufrufe und Agent-Anfragen gehen tatsächlich über den Ziel-Endpunkt;
5. Verbrauch und Abrechnung sind überprüfbar;
6. Dokumentieren Sie klar, ob die Anfragen über den Cursor-Server und die entsprechenden Datenschutzbeschränkungen liefen.

Nach einem Client-Upgrade sollten diese Prüfungen erneut durchgeführt werden, um sicherzustellen, dass sich das Anfrageprotokoll, die Toolaufrufe und der Datenpfad nicht geändert haben.
