---

Die offizielle BYOK-Dokumentation von GitHub Copilot listet VS Code als unterstützten lokalen Client und unterstützt OpenAI-kompatible Anbieter. Die Version von VS Code, Unternehmensrichtlinien und die Sichtbarkeit des Modells beeinflussen den endgültigen Endpunkt; bitte überprüfen Sie bei der ersten Integration die tatsächliche Anfrage gemäß den folgenden Punkten.

## Konfigurationsbereich

1. Bestätigen Sie, dass Ihr GitHub Copilot-Konto oder Ihre Organisation die BYOK/Custom Models-Funktion aktiviert hat.
2. Fügen Sie im Copilot-Modulmanagement von VS Code einen OpenAI-kompatiblen Anbieter hinzu.
3. Geben Sie die Basis-URL als `https://api.acedata.cloud/v1` ein.
4. Geben Sie den API-Schlüssel als Ihr Ace Data Cloud API-Token ein.
5. Geben Sie das Modell als die genaue Modell-ID im Modellverzeichnis ein, die mit dem gewählten Protokoll kompatibel ist.
6. Senden Sie im Copilot-Chat `Reply only OK` und testen Sie dann erneut eine Anfrage mit dem Kontext des Arbeitsbereichs.

## Aktuelle Grenzen

- Die Konfigurationsverträge für die Copilot-App, CLI, GitHub Desktop und Enterprise BYOK unterscheiden sich von VS Code; diese Anleitung wendet die Schritte anderer Clients nicht direkt auf VS Code an.
- Unternehmensrichtlinien können es Einzelpersonen verbieten, Anbieter oder Modelle hinzuzufügen.
- Tab-Vervollständigung, Chat, Agent und Hintergrundaufgaben können unterschiedliche Modellpfade verwenden und sollten separat überprüft werden.
