title: "Abrufen aktueller API-Aufrufbeispiele der AceDataCloud-Plattform"

Gibt öffentlich Aufzeichnungsbeispiele von API-Aufrufen innerhalb der letzten 15 Minuten zurück, um den aktuellen Status schnell zu beobachten. Es handelt sich nicht um eine nach Statuscodes aggregierte Zählschnittstelle und sie kann nicht für persönliche Abrechnungen, SLAs oder vollständige Nutzungsstatistiken verwendet werden.

## Schnittstellenübersicht

| Punkt   | Inhalt                                                           |
| --- | ------------------------------------------------------------ |
| Methode  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| Authentifizierung  | Öffentlich, kein Kontotoken erforderlich                                                    |
| Obergrenze  | Nach Zusammenführung der zuletzt erstellten/abgeschlossenen Aufzeichnungen werden höchstens 5.000 Einträge zurückgegeben                                    |

`api_id` wird aus der [API-Liste](https://platform.acedata.cloud/documents/platform-api-list) abgerufen.

```shell
export API_ID='deine API-ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## Tatsächliche Antwortstruktur

Die Antwort ist direkt ein Array und verwendet kein Pagination-Envelope:

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| Feld            | Beschreibung        |
| ------------- | --------- |
| `api_id`      | API-ID    |
| `created_at`  | Erstellungszeit der Aufzeichnung    |
| `trace_id`    | Kennung zur Anfrageverfolgung    |
| `status_code` | HTTP-Statuscode  |
| `elapsed`     | Aufrufdauer in Sekunden |

Wenn die API nicht existiert, kann derzeit ebenfalls ein leeres Array zurückgegeben werden, da diese Action die aktuelle Nutzung direkt anhand der ID abfragt und nicht zuerst das API-Objekt validiert. Um die Erfolgsrate zu berechnen, muss der Client die zurückgegebenen Beispiele selbst gruppieren; für die Abfrage persönlicher Gebühren verwenden Sie bitte die Schnittstelle auf Kontoebene.
