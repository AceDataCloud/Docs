Dieses Dokument beschreibt hauptsächlich den Ablauf der Nutzung des ADSL Proxy API, mit dem wir einfach die ADSL-IP extrahieren und eine IP-Whitelist für den ADSL Proxy hinzufügen können.

## Antragsprozess

Um die ADSL-IP zu extrahieren und eine IP-Whitelist für den ADSL Proxy hinzuzufügen, können Sie zunächst auf die Seiten [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/d8426c17-d22c-449a-b6bf-0a7790928e4d) und [ADSL Proxy Whitelist API](https://platform.acedata.cloud/documents/c21534fe-1f62-424b-9b10-a805cb473dd1) klicken Sie auf die Schaltfläche „Erwerben“, um die erforderlichen Anmeldeinformationen zu erhalten:

![](https://cdn.acedata.cloud/nyq0xz.png)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, die Sie zur Registrierung und Anmeldung einlädt. Nach der Anmeldung oder Registrierung werden Sie automatisch zur aktuellen Seite zurückgeleitet.

Bei der ersten Antragstellung gibt es ein kostenloses Kontingent, mit dem Sie die API kostenlos nutzen können.

## ADSL-IP extrahieren

Als Nächstes können Sie auf der Seite [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/d8426c17-d22c-449a-b6bf-0a7790928e4d) die entsprechenden Inhalte ausfüllen. Im Folgenden wird gezeigt, wie man die ADSL-IP extrahiert.

### Anfrageheader und Anfragekörper festlegen

**Anfrageheader** umfasst:

- `accept`: Gibt an, dass das Antwortformat JSON ist, hier wird `application/json` eingetragen.
- `authorization`: Der Schlüssel zur Nutzung der API, nach der Beantragung kann er direkt ausgewählt werden.

**Anfragekörper** umfasst:

- `number`: Die Anzahl der zu extrahierenden ADSL-IP-Adressen, standardmäßig 1.
- `type`: Der Typ der zu extrahierenden ADSL-IP, hauptsächlich unterteilt in `http` und `socks`, standardmäßig `http`.
- `province`: Die Provinz, in der die IP extrahiert wird, standardmäßig zufällig.
- `city`: Die Stadt, in der die IP extrahiert wird, standardmäßig zufällig.

Für die Festlegung der Parameter `province` und `city` gibt es Anforderungen, sie müssen übereinstimmen, zum Beispiel muss `city`: Nanchang mit `province`: Jiangxi übereinstimmen, sie müssen mit der Provinz übereinstimmen, die spezifischen Regeln sind wie folgt:

Es ist zu sehen, dass das Ergebnis ein `data`-Feld enthält, das die Details der IP-Extraktionsaufgabe enthält, weitere Informationen sind im folgenden Bild dargestellt:

- `success`, der Status des Ergebnisses der ADSL-IP-Extraktionsaufgabe.
- `data`, die detaillierten Informationen zur extrahierten ADSL-IP.

Aus `data` kann man deutlich die detaillierten Informationen dieser IP erkennen, wobei die Hauptinformation `ip` die IP-Adresse darstellt, die extrahiert wurde, weitere Informationen sind wie folgt:

- `ip`, die IP-Adresse der extrahierten ADSL.
- `port`, die Portinformationen der extrahierten ADSL-IP.
- `proxy`, die vollständigen Informationen des ADSL-IP-Proxys.
- `province`, die Provinz der extrahierten ADSL-IP.
- `city`, die Stadt der extrahierten ADSL-IP.

Es ist zu sehen, dass wir den oben genannten `proxy` leicht für die nächste IP-Proxy-Arbeit verwenden können.

Zuerst müssen wir, bevor wir den IP-Proxy verwenden, unsere eigene Netzwerk-IP-Adresse (wie man die lokale Netzwerk-IP erhält, bitte selbst nachschlagen) zur folgenden Whitelist hinzufügen. Als nächstes wird erklärt, wie der IP-Proxy verwendet wird:

### Verwendung des Proxys

> Hinweis: Bitte fügen Sie die IP-Whitelist hinzu, bevor Sie den extrahierten Proxy-IP verwenden, andernfalls kann er nicht verwendet werden. Informationen zum Hinzufügen der Whitelist finden Sie im folgenden Inhalt.

Curl-Beispielcode:

```shell
curl -x 115.219.4.171:23456 myip.vpsnb.net # http proxy
curl --socks5 115.219.3.54:23457 myip.vpsnb.net # socks proxy
```

Python-Beispielproxy:

```python
import requests
import socks
import socket
import time

def test_http_proxy(proxy):
    try:
        start_time = time.time()
        response = requests.get(
            'http://httpbin.org/ip', proxies={'http': proxy, 'https': proxy}, timeout=100)
        elapsed_time = time.time() - start_time
        print(response)
        if response.status_code == 200:
            print(f"HTTP Proxy {proxy} success. time: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"HTTP Proxy {proxy} failed. code: {response.status_code}")
    except Exception as e:
        print(f"HTTP Proxy {proxy} failed: {str(e)}")

def test_socks_proxy(proxy):
    proxy_parts = proxy.split(':')
    if len(proxy_parts) != 2:
        print(f"SOCKS failed: {proxy}")
        return

    host, port = proxy_parts
    port = int(port)

    try:
        start_time = time.time()
        socks.set_default_proxy(socks.SOCKS5, host, port)
        socket.socket = socks.socksocket
        response = requests.get('http://httpbin.org/ip', timeout=10)
        elapsed_time = time.time() - start_time

        if response.status_code == 200:
            print(f"SOCKS Proxy {proxy} success. time: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"SOCKS Proxy {proxy} failed. code: {response.status_code}")
    except Exception as e:
        print(f"SOCKS Proxy {proxy} failed: {str(e)}")
    finally:
        socks.set_default_proxy()
        socket.socket = socket.socket

if __name__ == "__main__":
    # HTTP Proxy
    http_proxy = "http://115.219.4.171:23456"
    test_http_proxy(http_proxy)

    # SOCKS Proxy
    socks_proxy = "115.219.3.54:23457"
    test_socks_proxy(socks_proxy)

```

## ADSL-Proxy-Typ `type`

Wir können auch den Typ des ADSL-IP-Proxys festlegen, der hauptsächlich in zwei Arten unterteilt ist: die erste Art ist `http`, die andere ist `socks`, da die erste Art standardmäßig verwendet wird. Im Folgenden verwenden wir die zweite Art als Beispiel und können die folgenden Einstellungen vornehmen.

Die folgende Einstellung des IP-Proxy-Typs ist `socks`, die spezifischen Einstellungen sind im folgenden Bild dargestellt:

Gleichzeitig können Sie beachten, dass auf der rechten Seite der entsprechenden Aufrufcode generiert wird, den Sie kopieren und direkt ausführen oder einfach auf die Schaltfläche „Try“ klicken können, um einen Test durchzuführen.

Python-Beispielaufrufcode:

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

    "province": "浙江",
    "city": "温州",
    "type": "socks"
}

response = requests.post(url, json=payload, headers=headers)

```

## 添加 IP 白名单

接下来就可以在界面上填写对应的内容，如图所示：

<p><img src="https://cdn.acedata.cloud/wz4obo.png" width="500" class="m-auto"></p>

在第一次使用该接口时，我们至少需要填写三个内容，一个是 `authorization`，直接在下拉列表里面选择即可。另一个参数是 `ip`， `ip` 就是我们需要使用上文提取到的 IP 代理的本机网络地址。最后一个参数是`action`，`action` 是我们对白名单进行的操作，这里是对白名单进行添加的操作。

同时您可以注意到右侧有对应的调用代码生成，您可以复制代码直接运行，也可以直接点击「Try」按钮进行测试。

<p><img src="https://cdn.acedata.cloud/cs5ib2.png" width="500" class="m-auto"></p>

Python 样例调用代码：

```python
import requests

url = "https://api.acedata.cloud/adsl/whitelist"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "ip": "113.112.122.132",
    "action": "add"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

调用之后，我们发现返回结果如下：

```json
{
  "success": true
}
```

返回结果一共有一个字段，介绍如下：

- `success `，此处操作结果的状态。

其中 `success` 是包含了操作结果的状态，我们可以看到将 IP `113.112.122.132` 已经成功添加到白名单内。
