OpenAI ChatGPT ist ein sehr leistungsstarkes KI-Dialogsystem; solange Sie Prompt-Wörter eingeben, kann es innerhalb weniger Sekunden flüssige und natürliche Antworten generieren. ChatGPT hebt sich mit seinem hervorragenden Sprachverständnis und seiner Generierungsfähigkeit in der Branche hervor; heutzutage wird ChatGPT bereits in verschiedenen Branchen und Bereichen weit verbreitet eingesetzt, und sein Einfluss wird immer deutlicher. Ob bei alltäglichen Gesprächen, kreativem Schreiben oder professioneller Beratung und Code-Programmierung – ChatGPT kann erstaunliche intelligente Unterstützung bieten und die Arbeitseffizienz und Kreativität der Menschen erheblich steigern.

Dieses Dokument stellt hauptsächlich den Nutzungsprozess der OpenAI Chat Completion API vor; mit ihr können wir die Dialogfunktion des offiziellen OpenAI ChatGPT problemlos nutzen.

## GPT-6.1 Sol

Verwenden Sie `model: "gpt-6.1-sol"`, um dieses Modell auszuwählen. Es unterstützt Streaming-Ausgabe, Funktionsaufrufe, strukturierte Ausgabe und Bildeingabe. In der ersten Woche nach der Freigabe ist es nur für verifizierte ACE-T1+-Inhaber (mindestens 100.000 ACE) oder autorisierte Benutzer verfügbar; die konkrete Freigabezeit richtet sich nach dem Zugriffshinweis in der Konsole.

Die Reasoning-Stufen unterstützen `low`, `medium`, `high`, `xhigh` und `max`; `none` oder `minimal` werden vorerst nicht unterstützt. Es wird empfohlen, mit `reasoning_effort: "low"` zu beginnen. Wenn die Eingabe 272.000 Tokens überschreitet, gilt für die gesamte Anfrage die Preisgestaltung für langen Kontext; die Gebühren richten sich nach den aktuellen Preisen in der Konsole.

## Antragsprozess

Um die OpenAI Chat Completion API zu nutzen, rufen Sie zunächst die [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications) auf, um Ihren API-Token zu erhalten und ihn als Reserve aufzubewahren.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie sich noch nicht angemeldet oder registriert haben, werden Sie automatisch zur Anmeldeseite weitergeleitet, auf der Sie zur Registrierung und Anmeldung eingeladen werden; nach Abschluss kehren Sie automatisch zur aktuellen Seite zurück.

**Ein API-Token kann alle Dienste der Plattform aufrufen, ohne dass Sie ihn für jeden Dienst einzeln beantragen müssen.** Bei der ersten Beantragung wird ein kostenloses Guthaben verschenkt, das kostenlos ausprobiert werden kann; wenn das Guthaben nicht ausreicht, können Sie in der [Konsole](https://platform.acedata.cloud/console/coin) ein allgemeines Guthaben aufladen.

## Grundlegende Nutzung

Anschließend können Sie die entsprechenden Inhalte in der Oberfläche ausfüllen, wie in der Abbildung gezeigt:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

Bei der ersten Nutzung dieser Schnittstelle müssen wir mindestens drei Inhalte ausfüllen: Einer davon ist `authorization`, der direkt in der Dropdown-Liste ausgewählt werden kann. Ein weiterer Parameter ist `model`; `model` ist die Modellkategorie der offiziellen OpenAI-ChatGPT-Website, deren Nutzung wir auswählen. Hier haben wir hauptsächlich 20 Modelle; Details finden Sie bei den von uns bereitgestellten Modellen. Der letzte Parameter ist `messages`; `messages` ist das Array der von uns eingegebenen Fragewörter. Es ist ein Array und bedeutet, dass mehrere Fragewörter gleichzeitig hochgeladen werden können. Jedes Fragewort enthält `role` und `content`, wobei `role` die Rolle des Fragestellers darstellt. Wir bieten drei Identitäten an, nämlich `user`, `assistant`, `system`. Das andere, `content`, ist der konkrete Inhalt unserer Frage.

Gleichzeitig können Sie beachten, dass auf der rechten Seite entsprechender Aufrufcode generiert wird. Sie können den Code kopieren und direkt ausführen oder direkt auf die Schaltfläche „Try“ klicken, um ihn zu testen.

Häufig verwendete optionale Parameter:

- `max_tokens`: Begrenzt die maximale Anzahl von Tokens für eine einzelne Antwort.
- `temperature`: Zufälligkeit der Generierung, zwischen 0 und 2; je größer der Wert, desto stärker die Streuung.
- `n`: Wie viele Kandidatenantworten auf einmal generiert werden.
- `response_format`: Einstellung des Rückgabeformats.

## Streaming-Antwort

Diese Schnittstelle unterstützt auch Streaming-Antworten, was für die Anbindung von Webseiten sehr nützlich ist und es Webseiten ermöglichen kann, einen Effekt der zeichenweisen Anzeige zu erzielen.

Wenn Sie die Antwort als Stream zurückgeben möchten, können Sie den Parameter `stream ` im Anfrage-Header ändern und auf `true` setzen.

Die Änderung ist wie in der Abbildung gezeigt; allerdings muss der Aufrufcode entsprechend geändert werden, um Streaming-Antworten zu unterstützen.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

Nachdem `stream` auf `true` geändert wurde, gibt die API die entsprechenden JSON-Daten zeilenweise zurück; auf Codeebene müssen wir entsprechende Änderungen vornehmen, um die zeilenweisen Ergebnisse zu erhalten.

Python-Beispielaufrufcode:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```javascript
  .then((response) => response.json())
```

## Anbindung von OpenAI-Python

Die OpenAI Chat Completion API bleibt mit der offiziellen OpenAI-Schnittstelle kompatibel und kann direkt mit dem offiziellen SDK [OpenAI-Python](https://github.com/openai/openai-python) angebunden werden. Dieser Artikel wird die Verwendung kurz vorstellen.

1. Zunächst muss eine lokale `Python`-Umgebung eingerichtet werden; dieser Prozess kann über eine Google-Suche gefunden werden.
2. Laden Sie die Entwicklungsumgebung herunter und installieren Sie sie, beispielsweise den VSCode-Editor.
3. Konfigurieren Sie die `OpenAI`-Umgebungsvariablen.

- Erstellen Sie im Projektordner eine Datei mit dem Namen `.env` und speichern Sie sie.
- Inhalt der `.env`-Datei:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # Nochmals zur Erinnerung: Wenn Sie den Key von der offiziellen OpenAI-Website verwenden, nutzen Sie diese Adresse nicht.
```

Ersetzen Sie `sk-xxx` durch Ihren eigenen Key. `OPENAI_BASE_URL` ist die Proxy-Schnittstelle für den Zugriff auf OpenAI.

4. Installieren Sie die vom Projekt benötigten Pakete

```shell
pip install openai
```

Unter Mac OS lautet der Befehl:

```shell
pip3 install openai
```

5. Erstellen Sie eine Beispiel-Quellcodedatei

Angenommen, wir erstellen einen Beispielcode `index.py`; der konkrete Inhalt lautet wie folgt:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Visuelles Modell

gpt-4o ist ein von OpenAI entwickeltes multimodales großes Sprachmodell, das auf Grundlage von GPT-4 um visuelle Verständnisfähigkeiten erweitert wurde. Dieses Modell kann Text- und Bildeingaben gleichzeitig verarbeiten und ermöglicht modalitätsübergreifendes Verstehen und Generieren.

Die Textverarbeitung mit dem gpt-4o-Modell stimmt mit dem oben beschriebenen Inhalt zur grundlegenden Verwendung überein. Im Folgenden wird kurz vorgestellt, wie die Bildverarbeitungsfähigkeit des Modells verwendet wird.

Die Bildverarbeitungsfähigkeit des gpt-4o-Modells wird hauptsächlich durch das Hinzufügen eines `type`-Feldes auf Grundlage des ursprünglichen `content`-Inhalts verwendet. Über dieses Feld kann erkannt werden, ob Text oder ein Bild hochgeladen wird, um so die Bildverarbeitungsfähigkeit des gpt-4o-Modells zu nutzen. Im Folgenden wird hauptsächlich beschrieben, wie diese Funktion über Curl und Python auf zwei Arten aufgerufen wird.

- Curl-Skriptmethode

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

- Python-Skriptmethode
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
                    }
                },
            ],
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```


Es ist zu sehen, dass der Antwortinhalt auf dem Bild basiert. Daher können die Text- und Bildverarbeitungsfähigkeiten des Modells gpt-4-vision über die beiden oben genannten Methoden einfach verwendet werden.

Neben gpt-4o gibt es auch ein kostengünstigeres Modell namens gpt-4o-mini. gpt-4o-mini ist die neueste Generation großer Sprachmodelle, die von OpenAI entwickelt wurde. Es reagiert nicht nur schnell, sondern ist auch günstiger und unterstützt ebenfalls Multimodalität. Für die Verwendung der Vision-Funktion kann auf den Inhalt zur Verwendung des Modells gpt-4o oben verwiesen werden.

## Fehlerbehandlung

Wenn bei der API-Aufrufung ein Fehler auftritt, gibt die API den entsprechenden Fehlercode und die Informationen zurück. Zum Beispiel:

- `400 token_mismatched`: Ungültige Anfrage, möglicherweise aufgrund fehlender oder ungültiger Parameter.
- `400 api_not_implemented`: Ungültige Anfrage, möglicherweise aufgrund fehlender oder ungültiger Parameter.
- `401 invalid_token`: Nicht autorisiert, ungültiges oder fehlendes Autorisierungstoken.
- `429 too_many_requests`: Zu viele Anfragen, Sie haben das Ratenlimit überschritten.
- `500 api_error`: Interner Serverfehler, auf dem Server ist etwas schiefgelaufen.

### Beispiel für eine Fehlerantwort

```
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
