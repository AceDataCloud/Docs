## 1. API-Schlüssel erhalten

Öffnen Sie die [Ace Data Cloud Anwendungsübersicht](https://platform.acedata.cloud/console/applications), gehen Sie zu den verfügbaren Anwendungen und kopieren Sie den API-Schlüssel.

![API-Schlüssel von Ace Data Cloud erhalten](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Erste Anfrage senden

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer Ihr API-Schlüssel" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimale redaktionelle Produktillustration: eine schlichte weiße Keramiktasse, zentriert auf einem soliden kobaltblauen Tisch, blasscremfarbener Hintergrund, sanfter Schatten, klare geometrische Formen, kein Text, kein Logo, Hochformat",
    "size": "1024x1536"
  }'
```

Das erfolgreich zurückgegebene Bild befindet sich in `data[].url`. Hier ist das Ergebnis von 1024×1536, das am 8. September 2026 über Ace Data Cloud angefordert wurde (Aufgabe `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, Trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Von GPT Image 2 generierte weiße Tasse](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Häufig verwendete Parameter

| Feld               | Beschreibung                                                              |
| ----------------- | ----------------------------------------------------------------------- |
| `model`           | Verwenden Sie `gpt-image-2`; Sie können auch explizit `gpt-image-2:official` oder `gpt-image-2:reverse` wählen |
| `prompt`          | Bildbeschreibung, maximal 32.000 Zeichen                                   |
| `size`            | `auto` oder `WIDTHxHEIGHT`; Breite und Höhe müssen Vielfache von 16 sein, die lange Seite darf 3840 nicht überschreiten, die Gesamtpixelzahl darf 8.294.400 nicht überschreiten |
| `n`               | 1–10; nur 1 unterstützt, wenn `response_format=b64_json`                  |
| `quality`         | `low`, `medium`, `high` oder `auto`; unterschiedliche Linienunterstützung und Abrechnungsarten |
| `response_format` | `url` oder `b64_json`                                                  |
| `callback_url`    | Optional; sendet das Ergebnis an diese Adresse, nachdem lange Aufgaben abgeschlossen sind |

Häufig verwendete Größen:

| Verhältnis | 1K          | 2K          | 4K          |
| --------- | ----------- | ----------- | ----------- |
| 1:1       | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3       | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4       | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9      | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16      | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` wählt das Format basierend auf dem Verhältnis, den Pixeln und der Layout-Intention im Prompt; bei Bedarf nach genauen Pixeln geben Sie die Größe direkt an.

## 4. Mehrere Generierungen

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer Ihr API-Schlüssel" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Ein kleiner Fuchs, der unter einem leuchtenden Pilz liest, Aquarellillustration",
    "size": "1536x1024",
    "n": 2
  }'
```

Standardmäßig wird `gpt-image-2` und `:reverse` nach der Anzahl der erfolgreichen Bilder abgerechnet; `gpt-image-2:official` wird basierend auf den tatsächlichen Token für die Texteingabe und die Bildausgabe abgerechnet. Die auf der Seite angegebenen Preise sind Schätzungen vor der Anfrage, die endgültige Abrechnung erfolgt basierend auf den Nutzungsaufzeichnungen.

## 5. Asynchrone Rückrufe

Wenn der Anfragekörper `callback_url` enthält, gibt die Schnittstelle zuerst `{"task_id": "..."}` zurück und sendet das endgültige Ergebnis per POST an diese URL, wenn die Aufgabe abgeschlossen ist; synchrone Anfragen geben weiterhin `created` und `data` zurück:

```json
{
  "model": "gpt-image-2",
  "prompt": "Ein Produktposter mit klarer Typografie",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Der Empfänger des Rückrufs sollte `task_id` zur Duplikatsvermeidung verwenden und die Anfragequelle sowie das Datenformat überprüfen.

## 6. Fehlersuche

| Status | Überprüfung                                               |
| ------ | ------------------------------------------------------- |
| 400    | Kombination von `model`, `prompt`, Größenformat, `n` und `response_format` |
| 401    | Ist der API-Schlüssel vollständig? Header muss `Authorization: Bearer ...` sein |
| 429    | Zu viele Anfragen, bitte später erneut versuchen                  |
| 504    | Synchroner Generierungszeitüberschreitung; verwenden Sie `callback_url` |

Fehlerantworten enthalten `error.code`, `error.message` und `trace_id`. Geben Sie bei der Meldung von Problemen die `trace_id` an, aber nicht den API-Schlüssel.

Die vollständigen Felder und Echtzeitauflistungen sind auf der Seite [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations) zu finden. Für die Bildbearbeitung siehe [GPT Image 2 Bildbearbeitung](https://platform.acedata.cloud/documents/openai-images-edits).
