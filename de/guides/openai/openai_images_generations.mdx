## 1. API-Key abrufen

Öffnen Sie die [Ace Data Cloud Anwendungsliste](https://platform.acedata.cloud/console/applications), rufen Sie eine verfügbare Anwendung auf und kopieren Sie den API-Key.

![Ace Data Cloud API-Key abrufen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Die erste Anfrage senden

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Das Bild der erfolgreichen Antwort befindet sich unter `data[].url`. Unten sehen Sie das tatsächlich über Ace Data Cloud angefragte Ergebnis in 1024×1536 vom 8. September 2026 (Aufgabe `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, Trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Von GPT Image 2 generierte weiße Kaffeetasse](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Häufig verwendete Parameter

| Feld                | Beschreibung                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (standardmäßig empfohlen), `gpt-image-2.5-flare` (schneller) oder `gpt-image-2.5-sunburst` (höhere Wiedergabetreue und Kontrolle); für alle drei kann die entsprechende Variante `:official` gewählt werden, `gpt-image-2` unterstützt außerdem `:reverse` |
| `prompt`          | Bildbeschreibung, maximal 32.000 Zeichen                                                                                                                     |
| `size`            | `auto` oder `WIDTHxHEIGHT`; Breite und Höhe müssen Vielfache von 16 sein, die längere Seite darf 3840 nicht überschreiten, die Gesamtpixelzahl beträgt 655.360–8.294.400 und das Seitenverhältnis darf 3:1 nicht überschreiten                                                       |
| `n`               | 1–10; bei `response_format=b64_json` wird nur 1 unterstützt                                                                                                 |
| `quality`         | GPT-Image-Modelle unterstützen `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare / Sunburst (einschließlich `:official`) unterstützen zusätzlich `xhigh`, `max`. Der offizielle Kanal wird nach tatsächlichem Token-Verbrauch abgerechnet             |
| `response_format` | `url` oder `b64_json`                                                                                                                     |
| `callback_url`    | Optional; nach Abschluss langer Aufgaben werden die Ergebnisse an diese Adresse gesendet                                                                                                                      |

Häufig verwendete Größen:

| Verhältnis   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` wählt den Bildausschnitt basierend auf dem Verhältnis, den Pixeln und der Layoutabsicht im Prompt aus; wenn präzise Pixel erforderlich sind, geben Sie die Größe direkt an.

Die auf der Seite angezeigten Preise des offiziellen API-Kanals sind Schätzungen vor der Anfrage. Maßgeblich sind der tatsächliche Token-Verbrauch und die Nutzungsaufzeichnungen in der Antwort.

## 4. Mehrere Bilder generieren

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` und ihre `:reverse`-Aliase werden nach der Anzahl erfolgreich erstellter Bilder abgerechnet; `gpt-image-2:official`, `gpt-image-2.5-flare:official` und `gpt-image-2.5-sunburst:official` werden anhand der tatsächlichen Token für Texteingabe und Bildausgabe in der Antwort abgerechnet. Die Seitenpreise sind Schätzungen vor der Anfrage, maßgeblich sind letztlich die Nutzungsaufzeichnungen.

## 5. Asynchroner Rückruf

Nach dem Hinzufügen von `callback_url` zum Anfragekörper gibt die Schnittstelle zunächst `{"task_id": "..."}` zurück und sendet nach Abschluss das Endergebnis per POST an diese URL; synchrone Anfragen geben weiterhin `created` und `data` zurück:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Der Empfänger des Rückrufs sollte mit `task_id` Duplikate entfernen und die Anfragequelle sowie das Datenformat verifizieren.

## 6. Fehlerbehebung

| Status  | Prüfen                                                  |
| --- | --------------------------------------------------- |
| 400 | Kombination von `model`, `prompt`, Größenformat, `n` und `response_format`    |
| 401 | Ob der API Key vollständig ist und ob der Header `Authorization: Bearer ...` lautet |
| 429 | Die Anfragen sind zu häufig, später erneut versuchen                                         |
| 504 | Zeitüberschreitung bei synchroner Generierung; stattdessen `callback_url` verwenden                            |

Fehlerantworten enthalten `error.code`, `error.message` und `trace_id`. Geben Sie bei der Meldung von Problemen `trace_id` an, aber nicht den API Key.

Die vollständigen Felder und Echtzeit-Enumerationen richten sich nach der Seite [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Für die Bildbearbeitung siehe [GPT Image 2 / 2.5 / 2.6 Bildbearbeitung](https://platform.acedata.cloud/documents/openai-images-edits).

## GPT Image 2.6

GPT Image 2.6 verwendet die Generierungs-, Bearbeitungs-, asynchronen Aufgaben- und Abrechnungsschnittstellen von 2.5 weiter:

| Modell                                                          | Abrechnung                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/Bild                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/Bild                   |
| `gpt-image-2.6-flare:official`                              | Wie 2.5 official, Abrechnung nach tatsächlichem Token-Verbrauch |
| `gpt-image-2.6-sunburst:official`                           | Wie 2.5 official, Abrechnung nach tatsächlichem Token-Verbrauch |

Für die Qualität sind `auto`, `low`, `medium`, `high`, `xhigh`, `max` verfügbar; verwenden Sie für die Größe `auto` oder `WIDTHxHEIGHT`, das den obigen Einschränkungen entspricht. Diese Schnittstelle unterstützt `png`, `jpeg`, `webp`; GPT Image 2.6 unterstützt außerdem native `gif`-Animationen, SVG wird vorerst nicht unterstützt. Die Bearbeitung unterstützt JSON-Bild-URLs und multipart-Dateiuploads. `:reverse` ist ein expliziter Alias der normalen Version desselben Namens. Verwenden Sie die vollständige Modellbezeichnung und übergeben Sie nicht `gpt-image-2.6`.

### GPT Image 2.6 GIF-Animationen

Die normalen Versionen, `:reverse` und `:official` von GPT Image 2.6 Flare und Sunburst können alle `output_format: "gif"` verwenden. Animationsframes, Schleifeninformationen und Wiedergabedauer bleiben erhalten; `frame_count` bezeichnet die Anzahl der Frames, `frame_duration_ms` bezeichnet die Millisekunden pro Frame. Die Frame-Anzahl muss eine ganze Zahl von 2–16 sein, die Dauer pro Frame muss eine ganze Zahl von 20–655350 Millisekunden sein und gilt nur für GIFs; die Kodierung wird auf die nächsten 10 ms gerundet. Falls nicht angegeben, sind standardmäßig 9 Frames mit jeweils 200 Millisekunden eingestellt; wenn die GIF-Größe ausgelassen wird oder `auto` ist, wird die Voreinstellung 512x512 verwendet.

Es wird empfohlen, zunächst `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200` zu verwenden. GIFs haben unabhängige Beschränkungen für Größe und Frame-Anzahl, die statischen 4K-Spezifikationen können nicht direkt angewendet werden; einige Modelle passen die tatsächliche Ausgabegröße an. `n` bezeichnet die Anzahl der zurückgegebenen GIF-Dateien, nicht die Anzahl der Animationsframes. Die normale Version und `:reverse` werden weiterhin nach der Anzahl erfolgreicher Dateien abgerechnet, die offizielle Version nach dem tatsächlichen Token-Verbrauch.

```json
{
  "model": "gpt-image-2.6-flare",
  "prompt": "A small red ball moves left and right on a white background, seamless looping animation, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### GPT Image 2.6 4K-Standbilder

Flare, Sunburst und ihre Varianten `:reverse` und `:official` können alle die zuvor genannten 4K-Pixelvoreinstellungen verwenden, beispielsweise `3840x2160` und `2160x3840`. Sowohl Generierung als auch Bearbeitung übergeben die konkreten Pixel über `size`; `4K` ist kein gültiger `size`-Wert, und `4096x4096` überschreitet ebenfalls die aktuelle Pixelobergrenze. Die obigen 4K-Spezifikationen gelten für statische PNG/JPEG/WebP-Dateien; für GIFs verwenden Sie deren spezielle Parameter.

### GPT Image 2.6 Komplexität der Komposition

Für `complexity` sind `low`, `medium`, `high` verfügbar; wenn es ausgelassen wird, wird der Modellstandard `high` verwendet. Es steuert die Planungskomplexität und ist unabhängig von der Renderqualität `quality`; es fallen keine zusätzlichen Gebühren pro Aufruf an, die offizielle Version wird weiterhin nach den tatsächlichen Token abgerechnet. Andere Modelle unterstützen diesen Parameter nicht.

GIF unterstützt keine Masken, annotierten Bilder, benutzerdefinierte Komprimierung, Prompt-Umschreibung oder teilweises Bildstreaming; inkompatible Kombinationen werden vor der Generierung abgelehnt. Größe, Frame-Anzahl und Menge unterliegen gemeinsam der Pixelbudgetbegrenzung des Modells; bei normalem Flare wurde `1024x1024` mit 2 Frames als funktionsfähig verifiziert, diese Schlussfolgerung kann nicht auf alle 1K-Kombinationen oder 4K-GIFs ausgeweitet werden.
