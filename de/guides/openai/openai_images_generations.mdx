## 1. API Key abrufen

Öffnen Sie die [Ace Data Cloud Anwendungsliste](https://platform.acedata.cloud/console/applications), gehen Sie zu einer verfügbaren Anwendung und kopieren Sie den API Key.

![Ace Data Cloud API Key abrufen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Die erste Anfrage senden

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Das Bild in der erfolgreichen Antwort befindet sich unter `data[].url`. Unten ist das 1024×1536-Ergebnis, das am 8. September 2026 durch eine tatsächliche Anfrage über Ace Data Cloud erhalten wurde (Aufgabe `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, Trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Von GPT Image 2 generierter weißer Kaffeebecher](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Häufig verwendete Parameter

| Feld                | Beschreibung                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (standardmäßig empfohlen), `gpt-image-2.5-flare` (schneller) oder `gpt-image-2.5-sunburst` (höhere Wiedergabetreue und Kontrolle); alle drei können die entsprechende `:official`-Variante wählen, `gpt-image-2` unterstützt außerdem `:reverse` |
| `prompt`          | Bildbeschreibung, maximal 32.000 Zeichen                                                                                                                     |
| `size`            | `auto` oder `WIDTHxHEIGHT`; Breite und Höhe müssen Vielfache von 16 sein, die lange Seite darf 3840 nicht überschreiten, die Gesamtpixelzahl beträgt 655.360–8.294.400, und das Seitenverhältnis darf 3:1 nicht überschreiten                                                       |
| `n`               | 1–10; bei `response_format=b64_json` wird nur 1 unterstützt                                                                                                 |
| `quality`         | `low`, `medium`, `high` oder `auto`; Unterstützung und Abrechnung unterscheiden sich je nach Route                                                                                          |
| `response_format` | `url` oder `b64_json`                                                                                                                     |
| `callback_url`    | Optional; sendet Ergebnisse nach Abschluss langer Aufgaben an diese Adresse                                                                                                                      |

Häufig verwendete Größen:

| Verhältnis   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` wählt das Bildformat anhand des Verhältnisses, der Pixel und der Layoutabsicht im Prompt aus; wenn präzise Pixel erforderlich sind, geben Sie die Größe direkt an.

## 4. Mehrere Bilder generieren

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` und `gpt-image-2:reverse` werden nach der Anzahl erfolgreich generierter Bilder abgerechnet; `gpt-image-2:official`, `gpt-image-2.5-flare:official` und `gpt-image-2.5-sunburst:official` werden anhand der tatsächlichen Token für Texteingabe und Bildausgabe in der Antwort abgerechnet. Die Preise auf der Seite sind Schätzungen vor der Anfrage, maßgeblich sind die endgültigen Nutzungsaufzeichnungen.

## 5. Asynchroner Callback

Nachdem `callback_url` zum Anfragetext hinzugefügt wurde, gibt die Schnittstelle zunächst `{"task_id": "..."}` zurück und POSTet das Endergebnis nach Abschluss an diese URL; synchrone Anfragen geben weiterhin `created` und `data` zurück:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Der Callback-Empfänger sollte mithilfe von `task_id` Duplikate entfernen und die Anfragequelle sowie das Datenformat verifizieren.

## 6. Fehlerbehebung

| Status  | Prüfen                                                  |
| --- | --------------------------------------------------- |
| 400 | Kombination aus `model`, `prompt`, Größenformat, `n` und `response_format`    |
| 401 | Ob der API Key vollständig ist und der Header `Authorization: Bearer ...` lautet |
| 429 | Anfrage zu häufig, später erneut versuchen                                         |
| 504 | Zeitüberschreitung bei synchroner Generierung; `callback_url` verwenden                            |

Fehlerantworten enthalten `error.code`, `error.message` und `trace_id`. Geben Sie bei der Meldung von Problemen `trace_id` an, aber nicht den API Key.

Die vollständigen Felder und Echtzeit-Enumerationen richten sich nach der Seite [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Für die Bildbearbeitung siehe [GPT Image 2 / 2.5 Bildbearbeitung](https://platform.acedata.cloud/documents/openai-images-edits).
