## 1. API-Schlüssel abrufen

Öffnen Sie die [Ace Data Cloud Anwendungsübersicht](https://platform.acedata.cloud/console/applications), gehen Sie zu den verfügbaren Anwendungen und kopieren Sie den API-Schlüssel.

![API-Schlüssel von Ace Data Cloud abrufen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Bild-URL zur Bearbeitung verwenden

Originalbild:

![GPT Image 2 Bearbeitungsoriginalbild](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer Ihr API-Schlüssel" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Behalten Sie die Tasse, den Tisch, den Kamerawinkel, das Hochformat und den sanften Schatten unverändert. Ändern Sie nur die Farbe der Tasse von Weiß zu lebhaftem Orange und den blassen Creme-Hintergrund in ein einheitliches dunkles Marineblau. Kein Text und kein Logo.",
    "size": "1024x1536"
  }'
```

Erfolgreiche Antwort:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Dies ist das am 8. September 2026 über Ace Data Cloud tatsächlich durchgeführte Bearbeitungsergebnis, die Tasse wurde orange, der Hintergrund wurde dunkelmarineblau und die ursprüngliche Komposition und Größe von 1024×1536 wurden beibehalten:

## 3. Lokales Bild hochladen

Verwenden Sie `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer Ihr API-Schlüssel" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Ersetzen Sie den Hintergrund durch ein helles modernes Studio"
```

Sie können `image` mehrfach übergeben, die GPT Image-Serie unterstützt bis zu 16 Referenzbilder. Im JSON-Antrag kann `image` eine einzelne URL oder ein Array von URLs sein; lokale Dateien werden mit multipart hochgeladen.

## 4. Häufig verwendete Parameter

| Feld                | Beschreibung                                                  |
| ----------------- | ----------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2:official` oder `gpt-image-2:reverse` |
| `image`           | JSON verwendet eine einzelne URL oder ein Array von maximal 16 URLs; multipart verwendet ein oder mehrere `image`-Dateifelder |
| `prompt`          | Bearbeitungsanweisung                                        |
| `size`            | `auto` oder eine zulässige `WIDTHxHEIGHT`-Kombination      |
| `n`               | 1–10; nur 1 bei `response_format=b64_json`                  |
| `response_format` | `url` oder `b64_json`                                      |
| `callback_url`    | Optionale asynchrone Rückrufadresse                          |

Die Größenregeln sind mit der Generierungs-API identisch: Breite und Höhe müssen Vielfache von 16 sein, die lange Seite darf 3840 nicht überschreiten, die Gesamtpixelzahl darf 8.294.400 nicht überschreiten. Wenn `size` weggelassen oder `auto` verwendet wird, wählt das Modell das Format basierend auf den Eingabeaufforderungen und dem ersten Referenzbild aus.

Standardmäßig wird `gpt-image-2` und `:reverse` nach der Anzahl der erfolgreichen Bilder abgerechnet; `gpt-image-2:official` wird basierend auf der tatsächlichen Token-Nutzung für Texteingaben, Referenzbilder und Bildausgaben abgerechnet, wobei die Nutzungserfassung maßgeblich ist.

## 5. Asynchrone Rückrufe und Fehlersuche

Lange Aufgaben können im Antrag hinzugefügt werden:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asynchrone 200-Antwort ist `{"task_id": "..."}`; nach Abschluss wird das endgültige Ergebnis zurückgerufen. Synchrone Anfragen geben `created` und `data` zurück.

| Status  | Überprüfung                  |
| --- | --------------------------- |
| 400 | Bildformat/Menge, Parameterkombinationen und Größenformat |
| 401 | API-Schlüssel und Bearer-Header |
| 429 | Anfragefrequenz              |
| 504 | Verwenden Sie asynchrone Rückrufe |

Fehlerantworten enthalten `trace_id`. Geben Sie diese ID an, wenn Sie ein Problem melden, und nicht den API-Schlüssel.

Vollständige Felder und Echtzeitauflistungen sind auf der Seite [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) zu finden. Für die reine Textgenerierung von Bildern siehe [GPT Image 2 Bildgenerierung](https://platform.acedata.cloud/documents/openai-images-generations).
