## 1. API-Key abrufen

Öffnen Sie die [Ace Data Cloud-Anwendungsliste](https://platform.acedata.cloud/console/applications), gehen Sie zu einer verfügbaren Anwendung und kopieren Sie den API-Key.

![Ace Data Cloud API-Key abrufen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Mit einer Bild-URL bearbeiten

Originalbild:

![GPT Image 2 Originalbild zur Bearbeitung](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

Erfolgreiche Antwort:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Dies ist das am 8. September 2026 über Ace Data Cloud tatsächlich fertiggestellte Bearbeitungsergebnis: Der Becher wird orange, der Hintergrund wird dunkel marineblau, und die ursprüngliche Komposition sowie die Größe von 1024×1536 bleiben erhalten:

![GPT Image 2 Bearbeitungsergebnis mit orangem Becher](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Lokale Bilder hochladen

Verwenden Sie `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` kann wiederholt übergeben werden; die GPT-Image-Serie unterstützt bis zu 16 Referenzbilder. `image` in JSON-Anfragen kann eine einzelne URL oder ein URL-Array sein; lokale Dateien werden per Multipart hochgeladen.

## 4. Häufig verwendete Parameter

| Feld                | Beschreibung                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (schneller) oder `gpt-image-2.5-sunburst` (höhere Wiedergabetreue und Kontrolle); alle drei können die entsprechende `:official`-Variante auswählen, `gpt-image-2` unterstützt zusätzlich `:reverse` |
| `image`           | JSON verwendet eine einzelne URL oder ein Array mit bis zu 16 URLs; Multipart verwendet ein oder mehrere `image`-Dateifelder                                                                    |
| `prompt`          | Bearbeitungsanweisung                                                                                                                             |
| `size`            | `auto` oder ein zulässiges `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1–10; bei `response_format=b64_json` wird nur 1 unterstützt                                                                                           |
| `response_format` | `url` oder `b64_json`                                                                                                               |
| `callback_url`    | Optionale asynchrone Callback-Adresse                                                                                                                         |

Die Größenregeln entsprechen der Generierungs-API: Breite und Höhe müssen Vielfache von 16 sein, die lange Seite darf 3840 nicht überschreiten, die Gesamtpixelzahl beträgt 655.360–8.294.400, und das Seitenverhältnis darf 3:1 nicht überschreiten. Wenn `size` ausgelassen oder `auto` verwendet wird, wählt das Modell das Format anhand des Prompts und des ersten Referenzbilds aus.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` und `gpt-image-2:reverse` werden nach der Anzahl erfolgreich erstellter Bilder abgerechnet; `gpt-image-2:official`, `gpt-image-2.5-flare:official` und `gpt-image-2.5-sunburst:official` werden anhand der tatsächlichen Tokens für Texteingabe, Referenzbildeingabe und Bildausgabe abgerechnet, maßgeblich ist letztlich der Nutzungsdatensatz.

## 5. Asynchrone Callbacks und Fehlerbehebung

Bei langen Aufgaben kann Folgendes zur Anfrage hinzugefügt werden:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Die asynchrone 200-Antwort lautet `{"task_id": "..."}`; nach Abschluss wird das Endergebnis per Callback gesendet. Synchrone Anfragen geben dagegen `created` und `data` zurück.

| Status  | Prüfen                      |
| --- | ----------------------- |
| 400 | Bildformat/-anzahl, Parameterkombination und Größenformat       |
| 401 | API-Key und Bearer-Header |
| 429 | Anfragerate                    |
| 504 | Asynchronen Callback verwenden                  |

Fehlerantworten enthalten `trace_id`. Geben Sie bei der Meldung von Problemen diese ID an, nicht den API-Key.

Vollständige Felder und Echtzeit-Aufzählungen finden Sie auf der Seite [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Für die Bildgenerierung nur aus Text siehe [GPT Image 2 / 2.5 Bildgenerierung](https://platform.acedata.cloud/documents/openai-images-generations).
