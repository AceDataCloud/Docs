---
title: "OpenAI Sprachsynthese API (/v1/audio/speech)"
description: "OpenAI generation API guide - Ace Data Cloud"
---

Text in natürliche Sprache umwandeln, **vollständig kompatibel mit OpenAI's `/v1/audio/speech`**. Jedes OpenAI SDK muss lediglich die `base_url` auf `https://api.acedata.cloud` setzen und den Schlüssel durch dein AceData Token ersetzen, um direkt verwendet zu werden. Die Schnittstelle gibt die Audio-Byte-Streams synchron zurück.

- **Anforderungsadresse**: `POST https://api.acedata.cloud/v1/audio/speech` (Alias `POST /openai/audio/speech`)
- **Authentifizierung**: Anfrage-Header `Authorization: Bearer {token}`
- **Abrechnung**: Abrechnung nach der Anzahl der Byte im Anfrage-Text, etwa 85% des offiziellen OpenAI-Preises (siehe Tabelle unten).

## Anfrageparameter

| Feld                | Typ     | Pflicht | Beschreibung                                                    |
| ----------------- | ------ | ------ | ------------------------------------------------------------- |
| `input`           | string | Ja     | Der zu synthetisierende Text.                                  |
| `model`           | string | Nein   | `tts-1` (schneller) oder `tts-1-hd` (höhere Audioqualität, Standard). |
| `voice`           | string | Nein   | Eines von `alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`, Standard `alloy`. |
| `response_format` | string | Nein   | `mp3` (Standard), `opus`, `aac`, `flac`, `wav`, `pcm`.       |
| `speed`           | number | Nein   | Sprechgeschwindigkeit 0.25–4.0, Standard 1.0.                |

## Beispiel

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/speech' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -o speech.mp3 \
  -d '{
    "model": "tts-1-hd",
    "input": "Was wäre, wenn eine API dir jedes KI-Video-Modell geben würde?",
    "voice": "nova",
    "response_format": "mp3"
  }'
```

Zurückgegeben wird die Audiodatei selbst (`Content-Type: audio/mpeg`), die direkt in `speech.mp3` geschrieben werden kann, um sie abzuspielen.

Mit dem offiziellen OpenAI Python SDK:

```python
from openai import OpenAI
client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
client.audio.speech.create(model="tts-1-hd", voice="nova", input="Hallo von AceData.").stream_to_file("speech.mp3")
```

## Preise

| Modell         | Offizieller OpenAI Preis | Preis dieser Plattform (ca. 15% Rabatt) |
| -------------- | ------------------------ | --------------------------------------- |
| `tts-1`       | $15 / 1 Million Zeichen  | ca. $12.75 / 1 Million Zeichen         |
| `tts-1-hd`    | $30 / 1 Million Zeichen  | ca. $25.5 / 1 Million Zeichen          |

> Abrechnung nach der Anzahl der Byte im Anfrage-Text; das Feld `official_price` zeigt den offiziellen OpenAI Preis zum Vergleich an.

## Fehlercodes

| Statuscode | code                    | Beschreibung          |
| ---------- | ----------------------- | --------------------- |
| 400        | `bad_request`           | `input` ist leer oder Parameter ungültig. |
| 401        | `authentication_failed` | Token ungültig.       |
| 403        | `used_up`               | Guthaben unzureichend. |
| 429        | `too_many_requests`     | Anfragen zu häufig.   |
| 500        | `api_error`             | Fehler upstream/intern. |
