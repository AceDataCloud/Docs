---
title: "Anleitung zur Anbindung der Producer-API zum Herunterladen von Videos"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer ermöglicht uns, Videos zu Liedern herunterzuladen. Dieses Dokument erläutert die Methode zur Anbindung der entsprechenden API.

Diese API hat nur einen Eingabeparameter, nämlich `audio_id`, der die eindeutige ID des Liedes ist.

Die hier eingegebene `audio_id` lautet `a54609c6-13e2-4176-be0f-4d7eebc68e1f` und ist eine von Producer generierte Lied-ID.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Das Ergebnis lautet wie folgt:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4"
  }
}
```

Wie zu sehen ist, ist das Feld `video_url` von `data` der Link zum herunterzuladenden Video.
