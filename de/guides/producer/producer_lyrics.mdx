Producer ermöglicht es uns, Liedtexte durch Eingabewörter zu generieren. Dieses Dokument erklärt die entsprechenden API-Integrationsmethoden.

Die API hat nur einen Eingabeparameter, nämlich `prompt`, der das Eingabewort für die Liedtextgenerierung ist.

Hier ist unser eingegebener `prompt`: `Ein Lied über den Winter`, das das Eingabewort für die Liedtextgenerierung ist.

```bash
curl -X POST 'https://api.acedata.cloud/producer/lyrics' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Ein Lied über den Winter"
}'
```

Das Ergebnis sieht wie folgt aus:

```
{
    "success": true,
    "task_id": "d354b519-43c0-4888-a3da-83adbf845fd6",
    "data": {
        "title": "Barmherzigkeit in den Bäumen",
        "lyrics": "[Strophe 1]\nIch ging hinaus vorbei am Güterbahnhof\nWo die Kiefern dick mit Frost wachsen\nDer Schnee kümmert sich nicht um das, was ich getan habe\nEr bedeckt alles gleich\n\n[Strophe 2]\nEs gibt eine Kapelle aus Birkenstämmen\nUnd der Altar ist der Boden\nIch knie dort wie ein Verräter\nWarte darauf, dass die Stille vergibt\n\n[Refrain]\nDer Winter ist ein schwerer Mantel\nDer Winter ist ein schwerer Mantel\n\n[Strophe 3]\nDu bist gegangen, bevor der erste Sturm kam\nIch blieb, um zuzusehen, wie die Welt weiß wird\nJetzt ist jeder Ast ein Knochen\nUnd ich zähle nur, was bleibt\n\n[Strophe 4]\nSie sagen, die Kälte wird dich umbringen\nAber ich denke, sie macht dich nur ehrlich\nHier draußen mit der gefrorenen Erde\nGibt es keinen Ort mehr, um deine Hände zu verstecken\n\n[Refrain]\nDer Winter ist ein schwerer Mantel\nDer Winter ist ein schwerer Mantel\n\n[Strophe 5]\nIch fand deinen Brief in meiner Tasche\nDie Tinte war aus dem ganzen Tau geschmolzen\nAber ich konnte immer noch Barmherzigkeit lesen\nGeschrieben im leeren Raum dazwischen\n\n[Outro]\nDie Bäume fragen nicht nach Absolution\nSie stehen einfach da, nackt und wahr\nIch lerne, das Gleiche zu tun\nLasse den Schnee begraben, was er begraben muss"
    }
}
```

Man kann sehen, dass das Feld `lyrics` in `data` den generierten Liedtextinhalt darstellt.
