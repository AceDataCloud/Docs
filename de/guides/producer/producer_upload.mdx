Producer ermöglicht es uns, Referenzaudio für eine zweite kreative Bearbeitung hochzuladen. Dieses Dokument erklärt die Integrationsmethoden der entsprechenden API.

Diese API hat nur einen Eingabeparameter, nämlich `audio_url`, der eine öffentlich zugängliche CDN-Adresse ist und die Endung mp3 unterstützt.

Hier ist die eingegebene `audio_url`: `https://cdn.acedata.cloud/suno_demo.mp3`, eine öffentlich zugängliche CDN-Adresse.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Das Ergebnis sieht wie folgt aus:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Akustik Pop]\n[Sanfte weibliche Stimmen, hell und fröhlich]\n\n[Strophe 1]\nSonnenlicht fällt am Meer\nDie Wellen lachen strahlend\nDu und ich am Strand\nDie Uhr bleibt stehen\nDas Eis schmilzt\nHand in Hand spazieren\nDer Wind weht sanft\nDas Herz schlägt unaufhörlich\n\n[Refrain]\nSommer, Sommer\nDie Zeit bleibt an diesem Tag stehen\nLachen hallt wider\nDer azurblaue Himmel ist neben uns",
    "audio_url": "https://storage.googleapis.com/corpusant-app-public/producer/raw/d906da31-87cb-42f5-98df-2fc4969923b1.mp3"
  }
}
```

Man kann sehen, dass das Feld `audio_id` im `data` die ID des hochgeladenen Songs ist.

Mit der Song-ID können wir die [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration) verwenden, um benutzerdefinierte Songs zu generieren. Zum Beispiel, wenn `action` auf `upload_extend` gesetzt wird und `audio_id` die zurückgegebene Song-ID erhält, können wir basierend auf dem Referenzaudio einen neuen Song generieren.
