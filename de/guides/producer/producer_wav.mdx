---
title: "Anleitung zur Anbindung der Producer-WAV-Download-API"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer ermöglicht uns das Herunterladen von WAV-Dateien, die mit Songs zusammenhängen. Dieses Dokument erläutert die Anbindungsmethode der entsprechenden API.

Diese API hat nur einen Eingabeparameter, nämlich `audio_id`, die eindeutige ID des Songs.

Die hier eingegebene `audio_id` lautet `a54609c6-13e2-4176-be0f-4d7eebc68e1f` und ist eine von Producer generierte Song-ID.

```bash
curl -X POST 'https://api.acedata.cloud/producer/wav' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Das Ergebnis lautet wie folgt:

```
{
  "success": true,
  "task_id": "44963173-b6c5-463c-915f-96730d14ec63",
  "trace_id": "f75d6a27-54bc-49fd-a40e-6d4cd0427764",
  "data": [
    {
      "title": "Woke up with the sun in my eyes",
      "file_url": "https://cdn.acedata.cloud/assets/examples/fish/64adc04b-c196-4a0f-9070-222ba101ce6c-fc50de38c165.wav"
    }
  ]
}
```

Wie zu sehen ist, ist das Feld `file_url` in `data` der WAV-Link zum Herunterladen.
