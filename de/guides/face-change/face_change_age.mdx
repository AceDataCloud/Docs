Dieser Artikel beschreibt eine API zur Gesichtsalteränderung, die es ermöglicht, das Alter der Gesichter in einem Bild durch Eingabe eines Bildes und eines Alters zu ändern. Die grundlegende Verwendung besteht darin, dass der Benutzer ein Gesichtsfoto hochlädt, und basierend auf Algorithmen zur Gesichtsbearbeitung und -erzeugung wird ein Bild eines älteren oder jüngeren Gesichts ausgegeben, das verschiedene Altersveränderungen des Gesichts unterstützt.

## Antragsprozess

Um die API zu nutzen, müssen Sie zunächst auf die entsprechende Seite der [API zur Gesichtsalteränderung](https://platform.acedata.cloud/documents/0c5b4165-25ba-4dc2-8f02-e3cd74ab4238) gehen und den entsprechenden Dienst beantragen. Nach dem Betreten der Seite klicken Sie auf die Schaltfläche „Acquire“, wie im Bild gezeigt:

![](https://cdn.acedata.cloud/q6ytrc.png)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach der Anmeldung werden Sie automatisch zur aktuellen Seite zurückgeleitet.

Bei der ersten Beantragung gibt es ein kostenloses Kontingent, mit dem Sie die API kostenlos nutzen können.

## Grundlegende Nutzung

Zunächst sollten Sie die grundlegende Verwendung verstehen, bei der Sie den Bildlink und die Altersinformationen eingeben, um das bearbeitete Ergebnisbild zu erhalten. Zuerst müssen Sie einfach ein `image_url`-Feld übergeben, das das Gesichtsfoto wie im Bild gezeigt enthält:

<p><img src="https://cdn.acedata.cloud/f5687u.png" width="500" class="m-auto"></p>

Dann müssen wir auch die Altersinformationen für das Gesicht hochladen, die im Parameter `age_infos` enthalten sind. Dies ist ein Array, in dem wir mehrere Informationen übermitteln können. Anschließend können wir die entsprechenden Inhalte auf der Benutzeroberfläche ausfüllen, wie im Bild gezeigt:

<p><img src="https://cdn.acedata.cloud/cn95e8.png" width="500" class="m-auto"></p>

Hier haben wir die Request-Header festgelegt, einschließlich:

- `accept`: In welchem Format Sie die Antwort erhalten möchten, hier eingetragen als `application/json`, also im JSON-Format.
- `authorization`: Der Schlüssel zur API-Nutzung, den Sie nach der Beantragung direkt auswählen können.

Außerdem haben wir den Request-Body festgelegt, einschließlich:

- `image_url`: Der Link zum zu bearbeitenden Gesichtsfoto.
- `age_infos`: Informationen über das Alter und die Region des Gesichts, wobei das Alter ein Pflichtparameter ist.

Nach der Auswahl können Sie feststellen, dass auf der rechten Seite auch der entsprechende Code generiert wurde, wie im Bild gezeigt:

<p><img src="https://cdn.acedata.cloud/zk8qkl.png" width="500" class="m-auto"></p>

Klicken Sie auf die Schaltfläche „Try“, um einen Test durchzuführen, wie im obigen Bild gezeigt. Hier haben wir folgendes Ergebnis erhalten:

```json
{
  "image_url": "https://faceeffect-1254418846.cos.ap-guangzhou.myqcloud.com/ft/ChangeAgePic/1256437459/bfce1ab8-5fd7-464d-8878-b38433f84d0e"
}
```

Hier sehen wir, dass das zurückgegebene Ergebnis ein `image_url`-Feld enthält, das das Bild des Gesichts nach der Altersänderung basierend auf dem eingegebenen Alter darstellt. Die veränderten Gesichtsmerkmale sind wie folgt dargestellt:

<p><img src="https://cdn.acedata.cloud/01rmiv.png" width="500" class="m-auto"></p>

Das Gesicht im Bild hat sich entsprechend dem eingegebenen Alter verändert.

Wenn Sie den entsprechenden Integrationscode generieren möchten, können Sie ihn direkt kopieren, zum Beispiel sieht der CURL-Code wie folgt aus:

```shell
curl -X POST 'https://api.acedata.cloud/face/change-age' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "age_infos": [{"age":60}],
  "image_url": "https://cdn.acedata.cloud/f5687u.png"
}'
```

Der Integrationscode in Python sieht wie folgt aus:

```python
import requests

url = "https://api.acedata.cloud/face/change-age"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "age_infos": [{"age":60}],
    "image_url": "https://cdn.acedata.cloud/f5687u.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Fehlerbehandlung

Wenn beim Aufruf der API ein Fehler auftritt, gibt die API den entsprechenden Fehlercode und die Informationen zurück. Zum Beispiel:

- `400 token_mismatched`: Ungültige Anfrage, möglicherweise aufgrund fehlender oder ungültiger Parameter.
- `400 api_not_implemented`: Ungültige Anfrage, möglicherweise aufgrund fehlender oder ungültiger Parameter.
- `401 invalid_token`: Unbefugt, ungültiger oder fehlender Autorisierungstoken.
- `429 too_many_requests`: Zu viele Anfragen, Sie haben das Kontingent überschritten.
- `500 api_error`: Interner Serverfehler, etwas ist auf dem Server schiefgelaufen.

### Beispiel für eine Fehlerantwort

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
