Dieser Artikel beschreibt die Integrationsanleitung für die Grok Videos Generation API, mit der durch Eingabe von Text-Prompts, Eingabebildern und optionalen Referenzbildern Grok Imagine (xAI) Videos generiert werden können.

## Antragsprozess

Um die API zu nutzen, müssen Sie zunächst auf der entsprechenden Seite [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos) den Dienst beantragen. Nach dem Aufruf der Seite klicken Sie auf die Schaltfläche „Acquire“, wie im Bild gezeigt:

![](https://cdn.acedata.cloud/q6ytrc.png)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach der Anmeldung oder Registrierung kehren Sie automatisch zur aktuellen Seite zurück.

Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, mit dem Sie die API kostenlos nutzen können.

## Modellbeschreibung

Diese API unterstützt zwei Modelle:

- `grok-imagine-video-1.5-fast` (Standard): Unterstützt Text-zu-Video (nur `prompt` erforderlich) und Bild-zu-Video (mit `image_url`), zu einem günstigeren Preis.
- `grok-imagine-video-1.5`: Unterstützt nur Bild-zu-Video, es **muss** `image_url` übergeben werden.

## Grundlegende Nutzung

Zunächst lernen Sie die grundlegende Nutzung kennen: Durch Eingabe des Prompts `prompt`, des Modells `model` und weiterer Parameter können Sie das entsprechende Video generieren.

Hier sehen wir, dass wir die Request Headers setzen, darunter:

- `accept`: Gibt das gewünschte Antwortformat an, hier `application/json` für JSON-Format.
- `authorization`: Der API-Schlüssel für den Aufruf der API, der nach Beantragung direkt aus der Dropdown-Liste ausgewählt werden kann.

Außerdem werden im Request Body folgende Parameter gesetzt:

- `prompt`: Textbeschreibung des gewünschten Videoinhalts. Bei Verwendung von `grok-imagine-video-1.5-fast` für Text-zu-Video **Pflicht**; bei Übergabe von `image_url` optional.
- `model`: Das Modell zur Videogenerierung, wählbar zwischen `grok-imagine-video-1.5-fast` (Standard) oder `grok-imagine-video-1.5`.
- `image_url`: Eingabebild-URL für Bild-zu-Video. Bei Modell `grok-imagine-video-1.5` **Pflicht**.
- `reference_image_urls`: Optionales Array von Referenzbild-URLs zur Steuerung von Stil oder Inhalt des Videos.
- `aspect_ratio`: Seitenverhältnis des generierten Videos, wählbar aus `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`.
- `resolution`: Ausgabeauflösung, wählbar `480p` (Standard) oder `720p`. Höhere Auflösung verbraucht mehr Kontingent.
- `duration`: Videolänge in Sekunden, Wertebereich 1–15, Standard 8. Abrechnung erfolgt nach Ausgabelänge.
- `callback_url`: Asynchrone Callback-URL. Wird diese gesetzt, gibt die API sofort eine `task_id` zurück und sendet das Ergebnis per POST an diese Adresse, sobald die Aufgabe abgeschlossen ist.

Klicken Sie auf die Schaltfläche „Try“, um einen Test durchzuführen. Das Ergebnis sieht etwa so aus:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video-1.5-fast:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
      "state": "succeeded"
    }
  ]
}
```

Die Rückgabe enthält mehrere Felder, die wie folgt erklärt werden:

- `success`: Ob die Videogenerierungsanfrage erfolgreich war.
- `task_id`: Die ID der aktuellen Videogenerierungsaufgabe.
- `trace_id`: Die Trace-ID der Anfrage zur Fehlerbehebung.
- `data`: Liste der generierten Videoergebnisse.
  - `id`: Eindeutige Kennung des generierten Videos.
  - `video_url`: URL des generierten Videos.
  - `state`: Status der Videogenerierungsaufgabe, möglich sind `pending` / `succeeded` / `failed`.

Wir müssen nur die `video_url` aus dem `data`-Feld verwenden, um das generierte Video abzurufen.

Das entsprechende CURL-Beispiel lautet:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "resolution": "480p",
  "duration": 8
}'
```

Das entsprechende Python-Beispiel lautet:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video-1.5-fast",
    "resolution": "480p",
    "duration": 8
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Bild-zu-Video

Wenn Sie ein Video basierend auf einem Eingabebild generieren möchten, können Sie `image_url` übergeben. Bei Verwendung von `grok-imagine-video-1.5` ist dieses Feld zwingend erforderlich:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5",
  "image_url": "https://cdn.acedata.cloud/5hmkdg.jpg",
  "resolution": "720p",
  "duration": 8
}
```

## Referenzbildführung

Wenn Sie den Stil oder Inhalt des generierten Videos mit einem oder mehreren Referenzbildern steuern möchten, können Sie ein Array von Bild-URLs in `reference_image_urls` übergeben:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video-1.5-fast",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/vunnjf.png"
  ]
}
```

## Asynchrone Callback

Die Videogenerierung benötigt eine gewisse Verarbeitungszeit. Wenn Sie keine lange Verbindung offen halten möchten, können Sie `callback_url` übergeben. Die API gibt dann sofort eine `task_id` zurück und sendet das Ergebnis per POST an die angegebene Adresse, sobald die Aufgabe abgeschlossen ist:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "duration": 8,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

Die sofort zurückgegebene Antwort sieht wie folgt aus:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Abfrage des Aufgabenstatus

Wenn Sie asynchrone Callback verwenden oder den Status der Aufgabe aktiv abfragen möchten, können Sie über die [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) anhand der `task_id` den aktuellen Status und das Ergebnis der Aufgabe abfragen.

## Abrechnungsinformationen

Der Dienst wird nach der „Ausgabedauer“ des generierten Videos abgerechnet. Der Preis wird durch `model` und `resolution` bestimmt. Der Gesamtpreis = Einzelpreis × `duration` (Standard 8 Sekunden). `720p` ist teurer als `480p`, und `grok-imagine-video-1.5` ist teurer als `grok-imagine-video-1.5-fast`. Die genauen Preise entnehmen Sie bitte der Preisseite.

## Fehlerbehandlung

Bei Problemen mit der Anfrage gibt die API entsprechende Fehlercodes und Beschreibungen zurück. Häufige Fehler sind:

- `400`: Fehlerhafte Anfrageparameter, z. B. fehlendes `prompt` bei Text-zu-Video, fehlendes `image_url` bei `grok-imagine-video-1.5` oder `duration` außerhalb des Bereichs 1–15.
- `401`: Authentifizierungsfehler, ungültiger Token oder nicht zum API-Schlüssel passend.
- `403`: Unzureichendes Guthaben oder Ablehnung durch Inhaltsprüfung des Prompts.
- `429`: Zu viele Anfragen, Überschreitung der Rate-Limits, bitte später erneut versuchen.
- `500`: Interner Serverfehler oder Fehler bei der Generierung upstream.
