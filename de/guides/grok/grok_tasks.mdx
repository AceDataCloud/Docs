Die Hauptfunktion der Grok Tasks API besteht darin, den Status der Ausführung eines Tasks abzufragen, indem die Task-ID eingegeben wird, die durch die Grok Videos Generation API generiert wurde.

Dieses Dokument wird die Integrationsanleitung der Grok Tasks API detailliert beschreiben, um Ihnen zu helfen, die Ausführung von Tasks der Grok Videos Generation API einfach zu integrieren und abzufragen.

## Antragsprozess

Um die Grok Videos Generation API zu nutzen, müssen Sie zunächst Ihr API-Token im [Ace Data Cloud Dashboard](https://platform.acedata.cloud/console/applications) abrufen und für zukünftige Verwendung aufbewahren.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, die Sie zur Registrierung und Anmeldung einlädt. Nach Abschluss werden Sie automatisch zur aktuellen Seite zurückgeleitet.

**Ein API-Token reicht aus, um auf alle Dienste der Plattform zuzugreifen, es ist nicht erforderlich, für jeden Dienst separat zu beantragen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, um es kostenlos auszuprobieren; wenn das Kontingent erschöpft ist, können Sie im [Dashboard](https://platform.acedata.cloud/console/coin) Ihr allgemeines Guthaben aufladen.

> 📘 Vollständige Dokumentation: [Grok Videos Generation API →](https://platform.acedata.cloud/documents/grok-videos)

## Anfragebeispiel

Die Grok Tasks API kann verwendet werden, um die Ergebnisse der Grok Videos Generation API abzufragen.

### Anfrageheader und Anfragekörper festlegen

**Request Headers** umfassen:

- `accept`: Gibt an, dass die Antwort im JSON-Format empfangen werden soll, hier eingetragen als `application/json`.
- `authorization`: Der Schlüssel zur Aufrufung der API, nach der Beantragung kann er direkt ausgewählt werden.

**Request Body** umfasst:

- `id`: Die zu abfragende Task-ID.
- `action`: Die Art der Operation auf dem Task, für eine Einzelabfrage `retrieve` eintragen.

### CURL-Codebeispiel

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Antwortbeispiel

Nach erfolgreicher Anfrage gibt die API die Detailinformationen zu diesem Task zurück. Das `request`-Feld ist der Request Body, der beim Starten des Tasks verwendet wurde, das `response`-Feld ist der Response Body, der nach Abschluss des Tasks zurückgegeben wird, zum Beispiel:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262729.623,
  "elapsed": 7.8,
  "request": {
    "prompt": "Eine filmische Aufnahme eines Kätzchens, das einem Schmetterling in einem sonnigen Garten nachjagt",
    "model": "grok-imagine-video-1.5-fast:reverse",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video-1.5-fast:reverse:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Die Feldbeschreibung ist wie folgt:

- `id`: Die ID des generierten Tasks, die zur eindeutigen Identifizierung dieses Generierungs-Tasks verwendet wird.
- `request`: Die Anfrageinformationen im Task.
- `response`: Die Rückgabeinformationen im Task.
- `created_at`: Erstellungszeit des Tasks, Unix-Zeitstempel (Sekunden, Fließkomma).
- `started_at`: Beginn der Ausführung des Tasks, Unix-Zeitstempel (Sekunden, Fließkomma).
- `finished_at`: Abschlusszeit des Tasks, Unix-Zeitstempel (Sekunden, Fließkomma). Dieses Feld wird nicht zurückgegeben, wenn der Task nicht abgeschlossen ist.
- `elapsed`: Die für die Ausführung des Tasks benötigte Zeit, Einheit in Sekunden (Fließkomma, auf 3 Dezimalstellen gerundet). Dieses Feld wird nicht zurückgegeben, wenn der Task nicht abgeschlossen ist.

## Batch-Abfrageoperation

Um die Details mehrerer Task-IDs abzufragen, setzen Sie `action` auf `retrieve_batch` und übergeben Sie die Task-ID-Array über `ids`:

**Request Body** umfasst:

- `ids`: Das Array der zu abfragenden Task-IDs.
- `action`: Die Art der Operation auf dem Task, für eine Batch-Abfrage `retrieve_batch` eintragen.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
