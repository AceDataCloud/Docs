description: "Codex 集成指南 - Ace Data Cloud"
---

Codex CLI ist ein von OpenAI veröffentlichtes Open-Source-Programmier-Agent, das lokal ausgeführt wird. Es kann im Terminal Code lesen, Dateien bearbeiten, Befehle ausführen und bei Entwicklungsaufgaben unterstützen. Über den Ace Data Cloud Proxy können Sie Codex CLI zu einem günstigeren Preis nutzen, ohne ein separates OpenAI-Konto abonnieren zu müssen.

Wählen Sie die vollständige Konfigurationsanleitung entsprechend Ihrem Anwendungsfall:

| Plattform | Beschreibung | Anleitung |
|-----------|--------------|-----------|
| **VS Code** | Offizielle Erweiterung, Chatten in der Seitenleiste des Editors, Dateien referenzieren, Diff-Vorschau | [VS Code Konfigurationsanleitung](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| **Terminal (CLI)** | Kernfunktionalität, starten Sie `codex` in einem beliebigen Terminal | [Terminal Konfigurationsanleitung](https://platform.acedata.cloud/documents/codex-terminal-integration) |

> **Hinweis**: Für die erste Anmeldung besuchen Sie die [Ace Data Cloud Konsole](https://platform.acedata.cloud/console/applications), um ein API-Token zu erhalten und kostenlose Kontingente zu sichern. Codex CLI arbeitet über die OpenAI Responses kompatible Schnittstelle von Ace Data Cloud (`/v1/responses`). Weitere Informationen zu Modellen und Abrechnung finden Sie auf der [OpenAI Service-Seite](https://platform.acedata.cloud/documents/openai).
