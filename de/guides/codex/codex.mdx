Codex CLI, Desktop und VS Code Erweiterung teilen sich `~/.codex/config.toml`. Konfigurieren Sie einmal den `acedatacloud` Provider, um Codex über Ace Data Cloud zu verwenden.

| Verwendung         | Konfigurationsleitfaden                                                                  |
| ----------------- | --------------------------------------------------------------------------------------- |
| Terminal / CLI    | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)        |
| Desktop           | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)     |
| VS Code           | [Codex für VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)  |
| Grafische Umschaltung | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration) |

Die gemeinsamen Konfigurationen bestehen nur aus drei Punkten:

- Provider: `acedatacloud`
- Basis-URL: `https://api.acedata.cloud/v1`
- API-Schlüssel: von [Anwendungsliste](https://platform.acedata.cloud/console/applications) abrufen und in `ACEDATACLOUD_API_KEY` speichern

Es ist nicht erforderlich, das Modell in der Integrationskonfiguration festzulegen; nach dem Start von Codex kann das Modell direkt ausgewählt werden.

Zurück zum [Coding Plan Konfigurationszentrum](https://platform.acedata.cloud/documents/coding-plan-integration).
