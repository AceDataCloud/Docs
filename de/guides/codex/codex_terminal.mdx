## 1. API-Schlüssel erhalten

Öffnen Sie die [Ace Data Cloud Anwendungsübersicht](https://platform.acedata.cloud/console/applications), gehen Sie zu den verfügbaren Anwendungen und kopieren Sie den API-Schlüssel.

![API-Schlüssel von Ace Data Cloud erhalten](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Codex installieren

```bash
npm install -g @openai/codex
```

## 3. API-Schlüssel festlegen

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="Ihr API-Schlüssel"
```

Um dies dauerhaft zu machen, fügen Sie diese Zeile zu `~/.zshrc` oder `~/.bashrc` hinzu. Windows PowerShell verwenden:

```powershell
setx ACEDATACLOUD_API_KEY "Ihr API-Schlüssel"
```

Nach der Einstellung das Terminal neu öffnen.

## 4. AceDataCloud konfigurieren

Bearbeiten Sie `~/.codex/config.toml` (Windows ist `%USERPROFILE%\.codex\config.toml`) und fügen Sie hinzu:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Ändern Sie die letzten beiden Zeilen für Windows in:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Es ist nicht erforderlich, `model` auszufüllen; nach dem Start können Sie im Codex das Modell auswählen. Vorhandene andere Konfigurationen können beibehalten werden, erstellen Sie keinen Provider mit demselben Namen erneut.

## 5. Starten

```bash
cd /path/to/your/project
codex
```

Nachdem Sie in Codex sind, führen Sie `/model` aus, um zu bestätigen, dass der Provider `acedatacloud` ist, und wählen Sie dann das benötigte Modell aus. Aufrufprotokolle und Guthaben können in der [Nutzungshistorie](https://platform.acedata.cloud/console/usages) und der [Anwendungsübersicht](https://platform.acedata.cloud/console/applications) eingesehen werden.

Wenn Sie aufgefordert werden, dass der Schlüssel fehlt oder eine 401 zurückgegeben wird, stellen Sie sicher, dass die Umgebungsvariable gesetzt ist, und schließen Sie das Terminal und Codex vollständig, bevor Sie es erneut öffnen.
