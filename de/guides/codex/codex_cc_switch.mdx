title: "Codex CC Switch Konfigurationsanleitung"
description: "Codex API guide - Ace Data Cloud"
---

CC Switch kann die Provider und API-Schlüssel von Codex über eine grafische Benutzeroberfläche verwalten.

## 1. API-Schlüssel abrufen

Öffnen Sie die [Ace Data Cloud Anwendungsübersicht](https://platform.acedata.cloud/console/applications), gehen Sie zu den verfügbaren Anwendungen und kopieren Sie den API-Schlüssel.

![API-Schlüssel von Ace Data Cloud abrufen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. CC Switch installieren

Laden Sie von [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest) herunter und installieren Sie es, oder führen Sie auf macOS aus:

```bash
brew install --cask cc-switch
```

## 3. Provider hinzufügen

1. Öffnen Sie CC Switch und wechseln Sie zu **Codex**.
2. Klicken Sie auf **Provider hinzufügen**, wählen Sie **Benutzerdefiniert**.
3. Füllen Sie aus:

| Feld      | Inhalt                             |
| --------- | ---------------------------------- |
| Name      | `acedatacloud`                    |
| Basis-URL | `https://api.acedata.cloud/v1`    |
| API-Schlüssel | Den gerade kopierten Ace Data Cloud API-Schlüssel   |

Wenn CC Switch einen benutzerdefinierten Konfigurationseditor bereitstellt, sollte die Konfiguration wie folgt aussehen:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"
requires_openai_auth = true
```

CC Switch speichert den API-Schlüssel in `~/.codex/auth.json`:

```json
{
  "OPENAI_API_KEY": "{token}"
}
```

Fügen Sie in dem oben genannten Provider kein `env_key` oder `[model_providers.acedatacloud.auth]` hinzu; manuelle Konfiguration oder CC Switch-Konfiguration sind alternativ. Es ist nicht erforderlich, `model` festzulegen, wählen Sie einfach direkt in Codex aus.

## 4. Aktivieren und überprüfen

Aktivieren Sie den `acedatacloud` Provider, beenden Sie Codex oder VS Code vollständig und starten Sie es neu. Führen Sie `/model` aus, um zu bestätigen, dass der Provider `acedatacloud` ist, wählen Sie dann ein Modell aus und senden Sie eine einfache Nachricht.

Wenn 401 zurückgegeben wird, stellen Sie sicher, dass der aktuell aktivierte Provider `acedatacloud` ist, und überprüfen Sie, ob der `OPENAI_API_KEY` in `~/.codex/auth.json` der gerade kopierte Ace Data Cloud API-Schlüssel ist. Die Aufrufprotokolle können in der [Nutzungsverlauf](https://platform.acedata.cloud/console/usages) eingesehen werden.
