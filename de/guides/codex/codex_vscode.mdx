Codex VS Code Erweiterung und Codex CLI teilen sich `~/.codex/config.toml`.

## 1. API-Schlüssel erhalten

Öffnen Sie die [Ace Data Cloud Anwendungsübersicht](https://platform.acedata.cloud/console/applications), gehen Sie zu den verfügbaren Anwendungen und kopieren Sie den API-Schlüssel.

![API-Schlüssel von Ace Data Cloud erhalten](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Erweiterung installieren

Installieren Sie die von OpenAI veröffentlichte **Codex – OpenAI's coding agent** im VS Code Marketplace oder führen Sie aus:

```bash
code --install-extension openai.chatgpt
```

## 3. API-Schlüssel einrichten

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="dein API-Schlüssel"
```

Um dies dauerhaft zu machen, fügen Sie diese Zeile zu `~/.zshrc` oder `~/.bashrc` hinzu. Windows PowerShell verwenden:

```powershell
setx ACEDATACLOUD_API_KEY "dein API-Schlüssel"
```

## 4. AceDataCloud konfigurieren

Bearbeiten Sie `~/.codex/config.toml` (Windows ist `%USERPROFILE%\.codex\config.toml`) und fügen Sie hinzu:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Ändern Sie die letzten beiden Zeilen für Windows in:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Es ist nicht erforderlich, `model` auszufüllen; das Modell kann im Codex-Panel ausgewählt werden.

## 5. Neustart und Überprüfung

Beenden Sie VS Code vollständig und öffnen Sie es erneut, dann öffnen Sie das Codex-Panel. Führen Sie `/model` aus, um zu bestätigen, dass der Provider `acedatacloud` ist, und senden Sie dann eine einfache Nachricht; die Aufrufprotokolle können unter [Nutzungsverlauf](https://platform.acedata.cloud/console/usages) eingesehen werden.

Wenn die Erweiterung den Schlüssel nicht lesen kann, starten Sie VS Code aus einem Terminal mit den gesetzten Umgebungsvariablen oder setzen Sie die systemweiten Umgebungsvariablen und starten Sie VS Code neu. Remote SSH, WSL und Dev Container müssen in der Umgebung konfiguriert werden, in der die Erweiterung tatsächlich ausgeführt wird.
