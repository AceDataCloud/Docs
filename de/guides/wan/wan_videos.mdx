`POST https://api.acedata.cloud/wan/videos` unterstützt gleichzeitig die bestehenden Wan 2.6-Modelle und `wan3.0-video`. Wan 3 erkennt anhand von `media` automatisch den Text-, Anfangs-/Endframe- oder Referenzmaterialmodus.

## Wan 3 Text-zu-Video

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "A paper boat drifting through a neon city at night",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 unterstützt ganze Zahlen von 2–30 Sekunden oder die intelligente Dauer `-1`, mit den Auflösungen `480P`, `720P`, `1080P`.

## Multimediale Referenzen

```json
{
  "model": "wan3.0-video",
  "prompt": "Create a cinematic product reveal",
  "media": [
    {"type":"first_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"},
    {"type":"last_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460-a2a2c1afbf39.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` unterstützt:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

Der Anfangs-/Endframe-Modus und der Referenzmaterialmodus können nicht gemischt verwendet werden. Referenzvideos werden letztlich anhand der tatsächlichen Sekunden des Eingabevideos plus der erfolgreich ausgegebenen Videosekunden abgerechnet; Text-, Bild- und Audioeingaben erhöhen die Videosekunden nicht.

| Auflösung   |      Preis |
| ----- | ------: |
| 480P  | $0.05/Sekunde |
| 720P  | $0.10/Sekunde |
| 1080P | $0.20/Sekunde |

## Wan 2.6-Kompatibilität

Die bestehenden Varianten `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` und flash verwenden weiterhin Parameter wie `action`, `image_url`, `reference_video_urls`; der Aufrufpfad bleibt unverändert.

## Asynchronität und Ergebnisse

Nach dem Setzen von `async: true` wird sofort eine `task_id` erhalten; der Endstatus wird über `/wan/tasks` abgerufen. Erfolgreiche Videos werden im AceDataCloud CDN gespeichert, und die tatsächliche usage sowie die cost werden in der Antwort zurückgegeben.
