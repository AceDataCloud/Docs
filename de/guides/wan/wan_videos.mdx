`POST https://api.acedata.cloud/wan/videos` unterstützt sowohl das bestehende Wan 2.6 Modell als auch `wan3.0-video`. Wan 3 erkennt automatisch Text, Anfangs- und Endbilder oder Referenzmaterialmuster basierend auf `media`.

## Wan 3 Text-zu-Video

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "Ein Papierboot, das nachts durch eine Neonstadt treibt",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 unterstützt Ganzzahlen von 2–30 Sekunden oder `-1` für intelligente Dauer, mit Auflösungen von `480P`, `720P`, `1080P`.

## Multimedia-Referenz

```json
{
  "model": "wan3.0-video",
  "prompt": "Erstelle eine filmische Produktenthüllung",
  "media": [
    {"type":"first_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"},
    {"type":"last_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` unterstützt:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

Anfangs- und Endbildmuster sowie Referenzmaterialmuster können nicht gemischt werden. Referenzvideos werden letztendlich basierend auf der tatsächlichen Eingabedauer des Videos und der erfolgreich ausgegebenen Videodauer abgerechnet; Texte, Bilder und Audioeingaben erhöhen nicht die Videodauer.

| Auflösung |      Preis |
| ----- | ------: |
| 480P  | $0.05/Sekunde |
| 720P  | $0.10/Sekunde |
| 1080P | $0.20/Sekunde |

## Wan 2.6 Kompatibilität

Das bestehende `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` und Flash-Varianten verwenden weiterhin Parameter wie `action`, `image_url`, `reference_video_urls`, der Aufrufpfad bleibt unverändert.

## Asynchron und Ergebnisse

Nach dem Setzen von `async: true` erhalten Sie sofort eine `task_id`, um den Endstatus über `/wan/tasks` abzurufen. Erfolgreiche Videos werden im AceDataCloud CDN gespeichert und die tatsächliche Nutzung sowie die Kosten werden in der Antwort zurückgegeben.
