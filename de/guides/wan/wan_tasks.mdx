---
title: "Wan Aufgabenabfrage API"
description: "Tongyi Wansiang Video Generation API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/wan/tasks` wird verwendet, um Wan Videoaufgaben abzufragen, in großen Mengen abzufragen oder zu löschen. Die Aufgabenabfrage verursacht keine zusätzlichen Generierungskosten.

## Abfrage einer einzelnen Aufgabe

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Die `response.data.video_url` der abgeschlossenen Aufgabe ist die permanente CDN-Adresse; `response.usage` enthält die Auflösung, die Sekundenanzahl des Eingangs/Ausgangs-Videos, die Bildrate und das Verhältnis; `response.cost` ist die Abrechnung der Generierungsaufgabe.

## Batch-Abfrage

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Gibt `{ "items": [...], "count": 2 }` zurück. Während die Aufgabe läuft, sind möglicherweise noch kein `finished_at` und die endgültige `response` vorhanden.

## Löschen von Aufgabenaufzeichnungen

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

Das Löschen betrifft nur die Aufgabenhistorie und entfernt nicht die bereits generierten CDN-Videos.
