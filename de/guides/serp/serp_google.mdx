Google SERP (Search Engine Results Page) ist die Ergebnisseite, die Benutzer sehen, nachdem sie eine Abfrage in der Google-Suchmaschine eingegeben haben. Sie zeigt natürliche Suchergebnisse, Werbung, hervorgehobene Zusammenfassungen, Wissensgraphen sowie Bilder, Videos und verschiedene andere Inhalte an, um den Benutzern die relevantesten Informationen bereitzustellen.

Dieser Artikel wird die Google SERP API im Detail vorstellen, die Ergebnisse liefert, wenn Abfragen in der Google-Suchmaschine eingegeben werden. Die Ergebnisse enthalten auch viele Arten von Inhalten, wie hervorgehobene Zusammenfassungen, Wissensgraphen und Bilder.

Dieses Dokument wird die Integrationsanleitung der Google SERP API vorstellen.

## Antragsprozess

Um die Google SERP API zu nutzen, müssen Sie zunächst im [Ace Data Cloud Dashboard](https://platform.acedata.cloud/console/applications) Ihr API-Token anfordern und zur späteren Verwendung aufbewahren.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, die Sie zur Registrierung und Anmeldung einlädt. Nach Abschluss werden Sie automatisch zur aktuellen Seite zurückgeleitet.

**Ein API-Token reicht aus, um auf alle Dienste der Plattform zuzugreifen, es ist nicht erforderlich, für jeden Dienst separat zu beantragen.** Bei der ersten Anfrage erhalten Sie ein kostenloses Kontingent, um es kostenlos auszuprobieren; wenn das Kontingent erschöpft ist, können Sie im [Dashboard](https://platform.acedata.cloud/console/coin) Ihr allgemeines Guthaben aufladen.

> 📘 Vollständige Dokumentation: [Google SERP API →](https://platform.acedata.cloud/documents/serp-google)

## Grundlegende Nutzung

Zunächst sollten Sie die grundlegende Nutzung verstehen, bei der Sie den Typ der Suchressource und das Schlüsselwort eingeben, um die Suchergebnisse zu erhalten. Sie müssen lediglich das Feld `query` übergeben und das entsprechende Modell angeben.

Zum Beispiel, um Informationen über „apple inc“ zu finden, können wir die entsprechenden Inhalte auf der Benutzeroberfläche eingeben, wie im Bild gezeigt:

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

Hier haben wir die Request-Header festgelegt, einschließlich:

- `accept`: In welchem Format Sie die Antwort erhalten möchten, hier eingetragen als `application/json`, also im JSON-Format.
- `authorization`: Der Schlüssel zur API, den Sie nach der Beantragung direkt auswählen können.

Zusätzlich haben wir den Request-Body festgelegt, einschließlich:

- `type`: Der Typ der Suchressource, derzeit werden nur sechs Typen unterstützt, standardmäßig ist es `search`.
- `query`: Das Suchschlüsselwort.
- `country`: Das Land, in dem die Suchergebnisse angezeigt werden sollen, standardmäßig ist es die USA (US).
- `language`: Die Sprache der Suchergebnisse, standardmäßig ist es Englisch (en).
- `range`: Der Zeitrahmen der Suchergebnisse, standardmäßig ohne Einschränkungen.
- `number`: Die Seitengröße der Suchergebnisse, standardmäßig 10.
- `page`: Die Seitenzahl der Suchergebnisse, standardmäßig 1.

Nach der Auswahl können Sie feststellen, dass auf der rechten Seite auch der entsprechende Code generiert wurde, wie im Bild gezeigt:

<p><img src="https://cdn.acedata.cloud/1j81zr.png" width="500" className="m-auto" /></p>

Wenn Sie auch den entsprechenden Code generieren möchten, können Sie ihn direkt kopieren, zum Beispiel ist der CURL-Code wie folgt:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc"
}'
```

Der Python-Code für die Integration sieht wie folgt aus:

```python
import requests

url = "https://api.acedata.cloud/serp/google"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "query": "apple inc"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Benutzerdefinierte Suchtypen

Wenn Sie den Typ der Suchressourcen anpassen möchten, können wir den Parameter `type` ändern, der die normalen Ressourcen `search`, Bildressourcen `images`, Nachrichtenressourcen `news`, Kartenressourcen `maps`, Ortsressourcen `places`, Videoressourcen `videos` umfasst. In diesem Artikel werden wir ein Beispiel mit Videoressourcen `videos` geben.

Lassen Sie uns nun die spezifischen Operationen demonstrieren.

Zuerst setzen Sie den Parameter `type` auf `videos` und übergeben den `query` Parameter normal, wie im Bild gezeigt:
<p><img src="https://cdn.acedata.cloud/czlt12.png" width="500" className="m-auto" /></p>

Der entsprechende Code lautet wie folgt:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "videos",
  "query": "apple inc"
}'
```

## Anpassung des Zeitrahmens der Suchergebnisse
本文 kann auch den Zeitrahmen der Suchergebnisse anpassen, einschließlich fünf Arten: `qdr:h` (letzte Stunde), `qdr:d` (letzter Tag), `qdr:w` (letzte Woche), `qdr:m` (letzter Monat), standardmäßig ohne Einschränkungen. Wir können den entsprechenden Zeitrahmen über `range` übergeben, zum Beispiel hier auf `qdr:d` gesetzt, was bedeutet, dass die Ergebnisse der letzten 24 Stunden gesucht werden, also wie folgt eingegeben:

<p><img src="https://cdn.acedata.cloud/qccfib.png" width="500" className="m-auto" /></p>

Der entsprechende Code lautet:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "range": "qdr:d",
  "query": "apple inc"
}'
```
