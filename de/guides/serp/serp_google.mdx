Google SERP (Search Engine Results Page) ist die Ergebnisseite, die Nutzer sehen, nachdem sie eine Suchanfrage in der Google-Suchmaschine eingegeben haben. Sie zeigt organische Suchergebnisse, Werbung, hervorgehobene Snippets, Knowledge Graphs sowie verschiedene Inhalte wie Bilder und Videos an und zielt darauf ab, Nutzern die relevantesten Informationen bereitzustellen.

Dieser Artikel wird die Google SERP API detailliert vorstellen, die Ergebnisse bereitstellen kann, indem Anfragen in der Google-Suchmaschine eingegeben werden. Die Inhalte der Ergebnisse umfassen ebenfalls viele Typen, wie hervorgehobene Snippets, Knowledge Graphs sowie verschiedene Ergebnisse wie Bilder.

Dieses Dokument wird die Integrationsanleitung für die Google SERP API vorstellen.

## Antragsprozess

Um die Google SERP API zu verwenden, rufen Sie zunächst die [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications) auf, um Ihren API-Token zu erhalten und ihn als Reserve aufzubewahren.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet und zur Registrierung und Anmeldung eingeladen. Nach Abschluss kehren Sie automatisch zu dieser Seite zurück.

**Ein API-Token kann alle Dienste der Plattform aufrufen, ohne dass für jeden Dienst ein separater Antrag erforderlich ist.** Bei der ersten Beantragung wird ein kostenloses Guthaben vergeben, das kostenlos ausprobiert werden kann; wenn das Guthaben nicht ausreicht, kann in der [Konsole](https://platform.acedata.cloud/console/coin) ein allgemeines Guthaben aufgeladen werden.

> 📘 Vollständige Dokumentation: [Google SERP API →](https://platform.acedata.cloud/documents/serp-google)

## Grundlegende Verwendung

Durch Eingabe von Schlüsselwörtern und des Typs der Suchressource können Ergebnisse erhalten werden: Verwenden Sie `query`, um Schlüsselwörter zu übermitteln, und `type`, um Suchtypen wie Webseiten, Bilder und Nachrichten auszuwählen; diese Schnittstelle benötigt keinen Parameter `model`.

Wenn Sie beispielsweise nach Informationen über „apple inc“ suchen, können wir anschließend die entsprechenden Inhalte in der Oberfläche ausfüllen, wie in der Abbildung gezeigt:

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

Hier sehen wir, dass wir die Request Headers festgelegt haben, einschließlich:

- `accept`: Welches Format der Antwortergebnisse empfangen werden soll; hier wird `application/json` eingetragen, also das JSON-Format.
- `authorization`: Der Schlüssel zum Aufrufen der API, der nach der Beantragung direkt über das Dropdown-Menü ausgewählt werden kann.

Zusätzlich wurden die Request Body-Einstellungen festgelegt, einschließlich:

- `type`: Der Typ der Suchressource. Derzeit werden nur sechs Typen unterstützt, der Standardwert ist `search`.
- `query`: Das Schlüsselwort für die Suche.
- `country`: Das Land, in dem die Suchergebnisse angepasst werden sollen; der Standardwert sind die Vereinigten Staaten (US).
- `language`: Die Sprache, in der die Suchergebnisse angepasst werden sollen; der Standardwert ist Englisch (en).
- `range`: Der Zeitraum, in dem die Suchergebnisse angepasst werden sollen; standardmäßig gibt es keine Einschränkung.
- `number`: Die Seitengröße der Paginierung für die angepassten Suchergebnisse; der Standardwert ist 10.
- `page`: Die Seitenzahl der Paginierung für die angepassten Suchergebnisse; der Standardwert ist 1.

Nach der Auswahl können Sie feststellen, dass auf der rechten Seite auch der entsprechende Code generiert wurde, wie in der Abbildung gezeigt:

<p><img src="https://cdn.acedata.cloud/1j81zr.png" width="500" className="m-auto" /></p>

Wenn Sie außerdem den entsprechenden Integrationscode generieren möchten, können Sie ihn direkt kopieren und generieren, zum Beispiel lautet der CURL-Code wie folgt:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc"
}'
```

Der Python-Integrationscode lautet wie folgt:

```python
import requests

url = "https://api.acedata.cloud/serp/google"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "query": "apple inc"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Benutzerdefinierter Suchtyp

Wenn Sie den Typ der Suchressourcen anpassen, können wir den Parameter `type` ändern. Er umfasst allgemeine Ressourcen `search`, Bildressourcen `images`, Nachrichtenressourcen `news`, Kartenressourcen `maps`, regionale Ressourcen `places` und Videoressourcen `videos`; dieser Artikel verwendet die Videoressource `videos` als Beispiel.

Im Folgenden demonstrieren wir die konkreten Schritte.

Setzen Sie zunächst den Parameter `type` auf `videos` und übergeben Sie den Parameter `query` wie gewohnt, wie in der Abbildung gezeigt:
<p><img src="https://cdn.acedata.cloud/czlt12.png" width="500" className="m-auto" /></p>

Der entsprechende Code lautet wie folgt:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "videos",
  "query": "apple inc"
}'
```

## Sprache der benutzerdefinierten Suchergebnisse
Wir können auch die Sprache der Suchergebnisse anpassen. Hier fügen wir zusätzlich das Feld `language` hinzu, dessen Inhalt `zh-cn` ist, wobei es für die Sprache Chinesisch (vereinfacht) steht. Gleichzeitig werden auch andere Sprachen unterstützt, aber es muss die Abkürzung der eingegebenen Sprache angegeben werden, wie zum Beispiel en (English), fr (French), zh-cn (Chinese (Simplified)) und andere Sprachen, wie in der Abbildung gezeigt:

<p><img src="https://cdn.acedata.cloud/yyrssp.png" width="500" className="m-auto" /></p>

Der entsprechende Code lautet wie folgt:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "news",
  "query": "apple inc",
  "language": "zh-cn"
}'
```

## Zeitbereich der Suchergebnisse anpassen
Hier kann auch der Zeitraum der Suchergebnisse angepasst werden, einschließlich fünf Arten, nämlich `qdr:h` (vergangene Stunde), `qdr:d` (vergangener Tag), `qdr:w` (vergangene Woche), `qdr:m` (vergangener Monat) und standardmäßig unbegrenzt. Wir können den entsprechenden Zeitraum über `range` übergeben. Wenn hier beispielsweise `qdr:d` eingestellt wird, bedeutet dies, dass die Ergebnisse des vergangenen Tages gesucht werden. Die Eingabe lautet also wie folgt:

<p><img src="https://cdn.acedata.cloud/qccfib.png" width="500" className="m-auto" /></p>

Der entsprechende Code lautet wie folgt:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "range": "qdr:d",
  "query": "apple inc"
}'
```

## Benutzerdefinierte Paginierung der Suchergebnisse

Diese API unterstützt auch die benutzerdefinierte Paginierungsanzeige von Suchergebnissen. `number` und `page` stehen für die Seitengröße und Seitenzahl der Paginierung. In diesem Artikel wird die Paginierungsanzeige mit 20 Suchergebnissen pro Seite eingestellt. Die genauen Informationen sind in der Abbildung dargestellt:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
```
