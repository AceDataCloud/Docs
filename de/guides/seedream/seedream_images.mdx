Dieses Dokument beschreibt die Integration der SeeDream Images Generation API, mit der Sie durch Eingabe benutzerdefinierter Parameter offizielle SeeDream-Bilder generieren können.

## Antragsverfahren

Um die API zu nutzen, müssen Sie zunächst den entsprechenden Dienst auf der [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images) Seite beantragen. Nach dem Aufruf der Seite klicken Sie auf die Schaltfläche „Acquire“, wie im Bild gezeigt:

![](https://cdn.acedata.cloud/q6ytrc.png)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach der Anmeldung kehren Sie automatisch zur aktuellen Seite zurück.

Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, mit dem Sie die API kostenlos nutzen können.

## Grundlegende Nutzung

Zunächst lernen wir die grundlegende Verwendung kennen: Durch Eingabe des Prompt `prompt`, der Aktion `action` und der Bildgröße `size` erhalten Sie das bearbeitete Ergebnis. Zuerst muss ein Feld `action` mit dem Wert `generate` übergeben werden, dann geben wir den Prompt ein. Die Details sind wie folgt:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Hier sehen wir die Request Headers, darunter:

- `accept`: Das gewünschte Antwortformat, hier `application/json` für JSON.
- `authorization`: Der API-Schlüssel, der nach der Beantragung direkt ausgewählt werden kann.

Außerdem werden im Request Body folgende Parameter gesetzt:

- `prompt`: Der Eingabe-Prompt.
- `model`: Das Generierungsmodell, Standard ist `doubao-seedream-5.0-lite`. Unterstützt werden `doubao-seedream-5.0-lite` (neueste Version), `doubao-seedream-4.5`, `doubao-seedream-4.0`, `doubao-seedream-3.0-t2i`, `doubao-seededit-3.0-i2i`.
- `image`: Eingabebildinformationen, unterstützt werden URL oder Base64-Codierung. `doubao-seedream-5.0-lite`, `doubao-seedream-4.5` und `doubao-seedream-4.0` unterstützen Einzel- oder Mehrfachbilder, `doubao-seededit-3.0-i2i` nur Einzelbilder, `doubao-seedream-3.0-t2i` unterstützt diesen Parameter nicht.
- `size`: Bildgröße, unterstützt werden zwei Methoden, die nicht kombiniert werden dürfen. Methode 1 | Angabe der Auflösung (z.B. `2K`, `3K`, `4K`) und Beschreibung des Seitenverhältnisses im Prompt in natürlicher Sprache. Methode 2 | Angabe der Pixelmaße, Standard ist `2048x2048`, Wertebereich variiert je nach Modell.
- `seed`: Zufallszahl-Seed zur Steuerung der Zufälligkeit der Generierung. Wertebereich [-1, 2147483647]. Unterstützt nur `doubao-seedream-3.0-t2i` und `doubao-seededit-3.0-i2i`.
- `sequential_image_generation`: Bilderserie, generiert eine zusammenhängende Bilderserie basierend auf dem Eingabeprompt. Unterstützt von `doubao-seedream-5.0-lite`, `doubao-seedream-4.5` und `doubao-seedream-4.0`, Standard `disabled`.
- `stream`: Steuerung des Streaming-Ausgabemodus. Unterstützt von `doubao-seedream-5.0-lite`, `doubao-seedream-4.5` und `doubao-seedream-4.0`, Standard `false`.
- `guidance_scale`: Grad der Übereinstimmung zwischen Modelloutput und Prompt, je größer der Wert, desto höher die Korrelation. Wertebereich [1, 10]. Standard 2.5 für `doubao-seedream-3.0-t2i`, 5.5 für `doubao-seededit-3.0-i2i`, nicht unterstützt von anderen Modellen.
- `response_format`: Rückgabeformat des generierten Bildes. Standard `url`, unterstützt auch `b64_json`.
- `watermark`: Ob ein Wasserzeichen im generierten Bild hinzugefügt wird. Standard `true`.
- `output_format`: Dateiformat des generierten Bildes, unterstützt `jpeg` (Standard) und `png`. Nur `doubao-seedream-5.0-lite` unterstützt dies.
- `tools`: Konfiguration der vom Modell zu nutzenden Werkzeuge, aktuell unterstützt `web_search` (Internet-Suche). Nur `doubao-seedream-5.0-lite` unterstützt dies.
- `callback_url`: URL für asynchrone Rückrufe.

Nach Auswahl wird auf der rechten Seite der entsprechende Code generiert, wie im Bild gezeigt:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

Mit einem Klick auf „Try“ kann der Test durchgeführt werden. Das Ergebnis sieht wie folgt aus:

```json
{
  "success": true,
  "task_id": "25027ba3-0430-4a1b-91c8-d2297f19ba73",
  "trace_id": "8043a9e9-692f-43b0-82f7-5890f798be38",
  "data": [
    {
      "prompt": "a white siamese cat",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/3c060029-69b1-406f-a957-fcd55ddc9386.jpg"
    }

```

Die Antwort enthält mehrere Felder, die wie folgt erklärt werden:

- `success`: Status der Bildgenerierungsaufgabe.
- `task_id`: ID der Bildgenerierungsaufgabe.
- `trace_id`: Verfolgungs-ID der Aufgabe.
- `data`: Ergebnisliste der Bildgenerierung.
  - `image_url`: Link zum generierten Bild.
  - `prompt`: Eingabeprompt.
  - `size`: Pixelgröße des generierten Bildes.

Sie erhalten somit die Bildinformationen und können das generierte SeeDream-Bild über den Link in `data` abrufen.

Wenn Sie den entsprechenden Integrationscode generieren möchten, können Sie diesen direkt kopieren, z.B. CURL-Code:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-4-0-250828",
  "prompt": "a white siamese cat"
}'
```

## Bildbearbeitungsaufgabe

Wenn Sie ein Bild bearbeiten möchten, muss der Parameter `image` mit dem Link des zu bearbeitenden Bildes übergeben werden.

- `model`: Das Modell für die Bildbearbeitung, `doubao-seedream-5.0-lite`, `doubao-seedream-4.5` und `doubao-seedream-4.0` unterstützen Einzel- oder Mehrfachbilder, `doubao-seededit-3.0-i2i` nur Einzelbilder.
- `image`: Das hochzuladende Bild, ein oder mehrere.

Beispiel:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Der entsprechende Code:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Nach Ausführung erhalten Sie sofort ein Ergebnis, z.B.:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Das Ergebnis zeigt die bearbeitete Version des Originalbildes, ähnlich wie oben beschrieben.

## Asynchrone Rückrufe

Da die Generierung mit der SeeDream Images Generation API relativ lange dauert (ca. 1-2 Minuten), bleibt die HTTP-Verbindung bei längerer Wartezeit offen, was zu zusätzlichem Systemressourcenverbrauch führt. Daher unterstützt die API asynchrone Rückrufe.

Der Ablauf ist: Der Client gibt beim API-Aufruf zusätzlich ein Feld `callback_url` an. Die API antwortet sofort mit einem Ergebnis, das ein `task_id` enthält, die die aktuelle Aufgabe identifiziert. Nach Abschluss der Aufgabe sendet die API das Ergebnis per POST JSON an die angegebene `callback_url`, inklusive `task_id`, so dass die Aufgabe über die ID zugeordnet werden kann.

Ein Beispiel:

Nach Ausführung erhalten Sie sofort:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

Das Ergebnis ist:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Das Feld `task_id` ermöglicht die Zuordnung der Aufgabe, die anderen Felder entsprechen den vorherigen Ergebnissen.

## Fehlerbehandlung

Bei Fehlern gibt die API entsprechende Fehlercodes und Nachrichten zurück, z.B.:

- `400 token_mismatched`: Ungültige Anfrage, möglicherweise fehlende oder ungültige Parameter.
- `400 api_not_implemented`: Ungültige Anfrage, möglicherweise fehlende oder ungültige Parameter.
- `401 invalid_token`: Nicht autorisiert, ungültiger oder fehlender Autorisierungstoken.
- `429 too_many_requests`: Zu viele Anfragen, das Limit wurde überschritten.
- `500 api_error`: Interner Serverfehler.

### Beispiel einer Fehlerantwort

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
