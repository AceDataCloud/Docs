In diesem Artikel wird die Integration der SeeDream Images Generation API vorgestellt. Mit ihr können offizielle SeeDream-Bilder durch die Eingabe benutzerdefinierter Parameter generiert werden.

## Antragsverfahren

Um die SeeDream Images Generation API zu verwenden, rufen Sie zunächst die [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications) auf, um Ihr API-Token abzurufen und für die spätere Verwendung bereitzuhalten.

![]()

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, auf der Sie sich registrieren und anmelden können. Nach Abschluss des Vorgangs kehren Sie automatisch zur aktuellen Seite zurück.

**Ein einziges API-Token reicht aus, um alle Dienste der Plattform aufzurufen. Sie müssen keinen separaten Antrag für jeden Dienst stellen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Guthaben, mit dem Sie den Dienst kostenlos testen können. Wenn das Guthaben nicht ausreicht, können Sie in der [Konsole](https://platform.acedata.cloud/console/coin) Ihr allgemeines Guthaben aufladen.

> 📘 Vollständige Dokumentation: [SeeDream Images Generation API →](https://platform.acedata.cloud/documents/seedream-images)

## Modellauswahl

| Modell | Anwendungsbereich |
| ----------------------------------------------------------- | ------------------------------- |
| `doubao-seedream-5-5-261028` | Mehrstufige Bearbeitung, Text-zu-Transparentbild-Generierung, transparente Bearbeitung mit mehreren Referenzbildern, Ebenenaufteilung und Texterkennung auf Textebenen |
| `doubao-seedream-5-0-flash-260915` | Einzelbildgenerierung mit geringer Latenz, Bearbeitung mit mehreren Referenzbildern, Bearbeitung transparenter Bilder und Ebenenaufteilung |
| `doubao-seedream-5-0-pro-260628` | Einzelbildgenerierung, detaillierte Bearbeitung, Bearbeitung transparenter Bilder und Ebenenaufteilung |
| `doubao-seedream-5-0-lite-260128` | Einzelbilder, Bildgruppen, Streaming-Ausgabe und Websuche |
| `doubao-seedream-4-5-251128` / `doubao-seedream-4-0-250828` | Ältere Versionen der Bildgenerierung und -bearbeitung |

5.5 und 5.0 Flash verwenden denselben Endpunkt `POST /seedream/images` und unterstützen beide `1K`, `1.5K`, `2K` sowie bis zu 10 Referenzbilder. Die Ebenenaufteilungsaufgaben beider Modelle akzeptieren jeweils nur ein Bild und geben eine URL zurück. Bei 5.5 kann `layer_decomposition_options: {"max_images": 12, "text_recognition": true}` festgelegt werden. Es können bis zu 100 Bilder ausgegeben werden (einschließlich des Hintergrundbildes). Erkennbare Textebenen geben zeilenweise Texte und Formatierungen in `data[].text_recognition` zurück. 5.0 Flash gibt maximal ein Hintergrundbild und 16 Ebenen zurück.

5.5 unterstützt die direkte Generierung transparenter PNG-Bilder mit `background: "transparent"`. Für die Bearbeitung transparenter Bilder mit 5.0 Flash ist ein Referenzbild mit Alphakanal erforderlich. 5.5 berechnet die Kosten anhand der Pixelauflösung des erfolgreich ausgegebenen Bildes und erhebt zusätzlich 0.13 Credits pro eingegebenem Referenzbild. 5.0 Flash berechnet 0.31 Credits pro erfolgreich ausgegebenem Bild; Referenzbilder sind kostenlos. Die Ebenenaufteilung wird anhand der tatsächlichen Anzahl erfolgreich ausgegebener Bilder berechnet, wobei das Hintergrundbild ebenfalls mitgezählt wird. Siehe [Echtzeit-Preise](https://platform.acedata.cloud/services/seedream?tab=pricing).

## Grundlegende Verwendung

Machen Sie sich zunächst mit der grundlegenden Verwendung vertraut. Durch die Eingabe des Prompts `prompt`, der Generierungsaktion `action` und der Bildgröße `size` können Sie das verarbeitete Ergebnis erhalten. Zunächst müssen Sie einfach ein Feld `action` übergeben, dessen Wert `generate` lautet. Anschließend müssen Sie noch den Prompt eingeben. Der konkrete Inhalt sieht wie folgt aus: Der konkrete Inhalt sieht wie folgt aus:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Wie Sie sehen können, haben wir hier die Request Headers festgelegt, darunter:

- `accept`: Gibt an, welches Format die Antwort haben soll. Hier wird `application/json` eingetragen, also das JSON-Format.
- `authorization`: Der Schlüssel zum Aufrufen der API. Nach der Beantragung können Sie ihn direkt über das Dropdown-Menü auswählen.

Außerdem wurden die Request Body festgelegt, darunter:

- `prompt`: Der Prompt.
- `model`: Bitte geben Sie die vollständige Modell-ID aus der obigen Tabelle ein.
- `image`: Eingabe einer Bild-URL, eines Base64-Strings oder eines Arrays. 5.5, 5.0 Pro und 5.0 Flash unterstützen maximal 10 Referenzbilder.
- `size`: Auflösungsstufe oder `BreitexHöhe`. 5.5, 5.0 Pro und 5.0 Flash unterstützen `1K`, `1.5K` und `2K`. 5.0 Lite unterstützt `2K`, `3K` und `4K`.
- `sequential_image_generation`: Bildgruppe: Basierend auf den von Ihnen eingegebenen Inhalten wird eine Gruppe zusammenhängender Bilder generiert. `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128` und `doubao-seedream-4-0-250828` unterstützen diesen Parameter. Der Standardwert ist `disabled`.
- `stream`: Steuert, ob der Streaming-Ausgabemodus aktiviert wird. `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128` und `doubao-seedream-4-0-250828` unterstützen diesen Parameter. Der Standardwert ist `false`.
- `response_format`: Legt das Rückgabeformat des generierten Bildes fest. Der Standardwert ist `url`. Auch `b64_json` wird unterstützt.
- `watermark`: Gibt an, ob dem generierten Bild ein Wasserzeichen hinzugefügt werden soll. Der Standardwert ist `true`.
- `output_format`: Das Ausgabeformat ist `jpeg` oder `png`. Bei 5.5 ist PNG das Standardformat, bei 5.0 Pro/Flash/Lite ist JPEG das Standardformat.
- `tools`: Konfiguriert die Tools, die das Modell aufrufen soll. Derzeit wird `web_search` (Websuche) unterstützt. Nur Seedream 5.0 Lite unterstützt diese Funktion.
- `optimize_prompt_options`: Konfiguration zur Prompt-Optimierung. 5.0 Pro unterstützt `standard`/`fast`; 5.5, 5.0 Flash, 5.0 Lite und 4.5 unterstützen nur `standard`; 4.0 unterstützt `standard`/`fast`.
- `background`: Unterstützt `transparent` und `opaque`. 5.5 unterstützt zusätzlich `auto`. Für transparente Ausgaben wird PNG verwendet.
- `layer_decomposition`: Wird von 5.5, 5.0 Pro und 5.0 Flash unterstützt. Wenn der Wert auf `true` gesetzt wird, muss ein PNG/JPEG-Bild eingegeben werden. Sie können den Parameter `prompt` weglassen, um die automatische Ebenenaufteilung durchzuführen, oder natürliche Sprache/`<bbox>` verwenden, um Elemente anzugeben. `size` unterstützt `auto`/`1K`/`1.5K`/`2K`. Dieser Modus kann nicht gleichzeitig mit Bildgruppen, Streaming, Websuche oder `background` verwendet werden.
- `callback_url`: Die URL, an die das Ergebnis zurückgesendet werden soll.
- `async`: Gibt an, ob die Verarbeitung im asynchronen Modus erfolgen soll. Wenn der Wert auf `true` gesetzt wird, gibt die Schnittstelle sofort eine `task_id` zurück. Eine Angabe von `callback_url` ist nicht erforderlich. Anschließend können die Ergebnisse durch Abfragen von `/seedream/tasks` abgerufen werden.

Nach der Auswahl können Sie feststellen, dass auf der rechten Seite auch der entsprechende Code generiert wird, wie in der Abbildung gezeigt:

Das zurückgegebene Ergebnis enthält mehrere Felder, die im Folgenden beschrieben werden:

- `success`: Der aktuelle Status der Videogenerierungsaufgabe.
- `task_id`: Die ID der aktuellen Videogenerierungsaufgabe.
- `trace_id`: Die Tracking-ID der aktuellen Videogenerierung.
- `data`: Die Ergebnisliste der aktuellen Bildgenerierungsaufgabe.

  - `size`: Die Pixelgröße des generierten Bildes.

Wie zu sehen ist, haben wir zufriedenstellende Bildinformationen erhalten. Wir müssen lediglich die Bild-URL aus `data` verwenden, um das generierte SeeDream-Bild abzurufen.

Wenn Sie außerdem den entsprechenden Integrationscode generieren möchten, können Sie ihn direkt kopieren. Der CURL-Code sieht beispielsweise wie folgt aus:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-5-0-lite-260128",
  "prompt": "A single matte blue cube centered on a clean white studio background, neutral lighting"
}'
```

## Bildbearbeitungsaufgabe

Wenn Sie ein bestimmtes Bild bearbeiten möchten, muss zunächst der Parameter `image` mit dem Link des zu bearbeitenden Bildes übergeben werden.

- model: Übergeben Sie die vollständige Modell-ID, die in der obigen Tabelle für die Bildbearbeitung unterstützt wird.
- image: Laden Sie das zu bearbeitende Bild hoch, ein oder mehrere Bilder.

Ein Ausfüllbeispiel sieht wie folgt aus:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Der entsprechende Code:

```python
import requests

url = "https://api.acedata.cloud/seedream/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Ebenenaufteilung (Seedream 5.0 Pro)

Bei der Ebenenaufteilung wird ein Eingabebild in ein Hintergrundbild und bis zu 16 unabhängig bearbeitbare transparente PNG-Ebenen zerlegt. Die folgende Anfrage ermöglicht es dem Modell, die Hauptelemente automatisch zu erkennen. Wenn bestimmte Elemente angegeben werden sollen, kann `prompt` hinzugefügt werden. Außerdem können im Prompt normalisierte `<bbox>`-Koordinaten verwendet werden.

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "model": "doubao-seedream-5-0-pro-260628",
  "image": "https://example.com/poster.png",
  "layer_decomposition": true,
  "size": "2K",
  "watermark": false
}'
```

Das zurückgegebene `data` ist nach `z_index` von unten nach oben sortiert. Das Hintergrundbild hat den `z_index` 0. Die Ebenen enthalten außerdem `name`, `description` und `bounding_box.absolute`/`normalized`. Bei der Rekonstruktion mithilfe absoluter Koordinaten skalieren Sie die Ebenen auf `[right-left, bottom-top]`, positionieren Sie sie bei `[left, top]` und stapeln Sie sie anschließend in aufsteigender Reihenfolge von `z_index`. Wenn die Generierung einer beliebigen Ebene fehlschlägt, schlägt die gesamte Aufteilung fehl.

## Streaming-Ausgabe

Wenn bei Lite/4.x `stream: true` eingestellt ist, muss der Request-Header `accept: application/x-ndjson` verwenden. Die Schnittstelle gibt zeilenweise `image_generation.partial_succeeded` oder `image_generation.partial_failed` zurück und liefert am Ende ein einziges `image_generation.completed`-Ereignis sowie das endgültige `usage`. Nur das Abschlussereignis löst eine einmalige Abrechnung aus. Der Streaming-Modus kann nicht zusammen mit `async` oder `callback_url` verwendet werden.

## Asynchrone Rückrufe

Da die Generierung mit der SeeDream Images Generation API relativ lange dauert und etwa 1–2 Minuten benötigt, bleibt die HTTP-Anfrage bei einer längeren Reaktionszeit der API weiterhin verbunden, was zu einem zusätzlichen Verbrauch von Systemressourcen führt. Daher unterstützt diese API auch asynchrone Rückrufe.

Der gesamte Ablauf sieht folgendermaßen aus: Beim Senden einer Anfrage gibt der Client zusätzlich ein Feld `callback_url` an. Nachdem der Client die API-Anfrage gesendet hat, gibt die API sofort ein Ergebnis zurück, das ein Feld mit der Information `task_id` enthält, welche die aktuelle Aufgaben-ID darstellt. Sobald die Aufgabe abgeschlossen ist, werden die Ergebnisse der Bildgenerierung im JSON-Format per POST an die vom Client angegebene `callback_url` gesendet. Dabei wird auch das Feld `task_id` übermittelt, sodass die Aufgabenergebnisse anhand der ID zugeordnet werden können.

Wenn Sie keine öffentlich zugängliche Adresse für Rückrufe haben, können Sie `callback_url` auch weglassen und stattdessen das Feld `async` in der Anfrage auf `true` setzen. In diesem Fall gibt die Schnittstelle ebenfalls sofort `task_id` zurück, übermittelt jedoch keine Ergebnisse. Sie müssen die zurückgegebene `task_id` verwenden, um die Schnittstelle `/seedream/tasks` aufzurufen und den Aufgabenstatus regelmäßig abzufragen, bis das endgültige Ergebnis verfügbar ist.

## Fehlerbehandlung

Wenn bei einem API-Aufruf ein Fehler auftritt, gibt die API den entsprechenden Fehlercode und eine Fehlermeldung zurück. Zum Beispiel:

- `400 token_mismatched`: Ungültige Anfrage, möglicherweise aufgrund fehlender oder ungültiger Parameter.
- `400 api_not_implemented`: Ungültige Anfrage, möglicherweise aufgrund fehlender oder ungültiger Parameter.
- `401 invalid_token`: Nicht autorisiert, ungültiges oder fehlendes Autorisierungstoken.
- `429 too_many_requests`: Zu viele Anfragen, das Ratenlimit wurde überschritten.
- `500 api_error`: Interner Serverfehler, auf dem Server ist ein Fehler aufgetreten.

### Beispiel einer Fehlerantwort

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
