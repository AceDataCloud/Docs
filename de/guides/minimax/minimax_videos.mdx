Dieser Artikel beschreibt die Integration und Nutzung der MiniMax H3 Video-Generierung API. Die Schnittstelle unterstützt die Generierung von Videos aus Text, die Steuerung von Anfangs- und Endbildern sowie multimodale Referenzvideos und verwendet eine einheitliche V2 multimodale `content` Struktur zur Erstellung von Aufgaben.

## Antragsprozess

Um die MiniMax H3 Video-Generierung API zu nutzen, müssen Sie zunächst im [Ace Data Cloud Dashboard](https://platform.acedata.cloud/console/applications) Ihr API-Token abrufen und für spätere Verwendung aufbewahren.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, wo Sie sich registrieren und anmelden können. Nach Abschluss werden Sie automatisch zur aktuellen Seite zurückgeleitet.

**Ein API-Token reicht aus, um auf alle Dienste der Plattform zuzugreifen, es ist nicht erforderlich, für jeden Dienst separat zu beantragen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, um die Dienste kostenlos auszuprobieren; wenn das Kontingent erschöpft ist, können Sie im [Dashboard](https://platform.acedata.cloud/console/coin) Ihr Guthaben aufladen.

> 📘 Vollständige Dokumentation: [MiniMax H3 Video-Generierung API →](https://platform.acedata.cloud/documents/minimax-videos-integration)

Es wird empfohlen, das Token als Umgebungsvariable zu speichern und nicht in den Quellcode zu schreiben oder in ein Versionskontrollsystem hochzuladen:

```bash
export ACEDATACLOUD_API_KEY="YOUR_API_KEY"
```

## Schnittstellenübersicht

- **Basis-URL**: `https://api.acedata.cloud`
- **Endpoint**: `POST /minimax/videos`
- **Authentifizierungsmethode**: HTTP-Header mit `authorization: Bearer {token}`
- **Anforderungsheader**:
  - `accept: application/json`
  - `content-type: application/json`
- **Modell (model)**: `MiniMax-H3`
- **Eingabestruktur**: Über `content` werden Text, Bilder, Videos und Audios einheitlich übergeben
- **Ausgabemodus**: Standardmäßig synchron, wartet auf die Fertigstellung der Generierung und gibt die vollständige `task` zurück; bei Angabe von `async: true` oder `callback_url` wird sofort `task_id` und `trace_id` zurückgegeben
- **Ergebnisabfrage**: Über die [MiniMax H3 Task-Abfrage API](/documents/minimax-tasks-integration) den Status und das Endprodukt abrufen
- **Asynchrone Rückrufe**: Optional, um das endgültige Aufgabenergebnis über `callback_url` zu empfangen

Sie müssen `action` nicht übergeben, um den Generierungsmodus auszuwählen; die Schnittstelle bestimmt automatisch den Zweck basierend auf den Materialtypen und `role` in `content`.

## Geeignete Szenarien

| Szenario         | Eingabekombination                  | Häufige Verwendung                      |
| -------------- | --------------------- | ------------------------- |
| Text-zu-Video       | Text                    | Werbeideen, Storyboarding, Kurzvideos, Atmosphärische Aufnahmen        |
| Erstes Bild-zu-Video     | Text + Erstes Bild             | Lassen Sie Produktbilder, Poster, Porträts oder Illustrationen natürlich lebendig werden      |
| Letztes Bild / Erstes und letztes Bild-Video | Text + Letztes Bild, oder Text + Erstes Bild + Letztes Bild | Steuerung von Intro und Outro, Übergänge, Wachstumsveränderungen und Vorher-Nachher-Vergleiche      |
| Multimodale Referenz-zu-Video   | Text + Referenzbilder / Videos / Audios   | Beibehaltung von Charakteren und Produkten, Nachahmung von Bewegungen, Kameraführung, Klangfarbe oder Schnitt-Rhythmus |

## Aufrufprozess

Standardmäßig, wenn `async` nicht übergeben wird, wartet `/minimax/videos` auf die Fertigstellung der Generierung und gibt direkt die vollständige `task` zurück. Wenn die Verbindung sofort freigegeben werden muss, übergeben Sie `async: true` oder `callback_url`:

1. Speichern Sie die `task_id` und `trace_id` aus der sofortigen Antwort.
2. Wenn kein Callback konfiguriert ist, rufen Sie alle 10 Sekunden `/minimax/tasks` ab.
3. Wenn `task.status` auf `succeeded` wechselt, holen Sie das Video von `task.content.url`.
4. Wenn der Status `failed` oder `cancelled` ist, stoppen Sie die Abfrage und lesen Sie `task.error`.

## Oberste Anforderungsparameter

| Parameter             | Typ       | Pflichtfeld   | Standardwert        | Beschreibung                                                |
| -------------- | -------- | ---- | ---------- | ------------------------------------------------- |
| `model`        | string   | Ja    | -          | Festgelegt auf `MiniMax-H3`                                  |
| `content`      | object[] | Ja    | -          | Array multimodaler Inhalte, muss ein nicht leeres `text` Element enthalten                         |
| `resolution`   | string   | Ja    | -          | `768P` oder `2K`                                     |
| `duration`     | integer  | Ja    | -          | Generierungsdauer, Ganzzahl zwischen 4 und 15 Sekunden                                     |
| `ratio`        | string   | Bedingte Pflichtfeld | `adaptive` | `adaptive`, `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16` |
| `async`        | boolean  | Nein   | `false`    | Bei `true` wird sofort die Aufgabenkennung zurückgegeben, Ergebnisse werden über die Aufgaben-Schnittstelle abgerufen                       |
| `callback_url` | string   | Nein   | -          | Öffentlich zugängliche Callback-URL für das endgültige Aufgabenergebnis; bei Bereitstellung wird der asynchrone Modus automatisch aktiviert                     |

Die Regeln für `ratio` hängen vom Workflow ab:

- **Text-zu-Video**: Pflichtfeld, darf nicht `adaptive` sein.
- **Erstes Bild, letztes Bild oder erstes und letztes Bild-Video**: Das Seitenverhältnis wird durch das Eingabebild bestimmt, es wird empfohlen, es wegzulassen oder `adaptive` zu übergeben.
- **Multimodale Referenz-zu-Video**: Kann weggelassen werden, Standard ist `adaptive`; es kann auch ein festes Verhältnis angegeben werden.

Die Schnittstelle akzeptiert keine alten oder kompatiblen Felder wie `prompt`, `image_urls`, `audio_urls`, `messages` und `first_frame_image`. Bei Erhalt solcher Parameterfehler löschen Sie die alten Felder und migrieren Sie zu `content`; zum Beispiel `"prompt": "Eine Katze winkt"` ändern in `"content": [{"type": "text", "text": "Eine Katze winkt"}]`. Senden Sie nicht gleichzeitig alte und neue Formate.

## content Inhaltselementparameter

Jedes Inhaltselement muss `type` haben, die anderen Felder werden durch den Typ bestimmt:

| `type`      | Datenfeld            | `role`            | Beschreibung                                     |
| ----------- | --------------- | ----------------- | -------------------------------------- |
| `text`      | `text`          | Nicht übergeben                | Jeder Antrag muss ein nicht leeres Textelement enthalten, maximal 7000 Zeichen             |
| `image_url` | `image_url.url` | `first_frame`     | Erstes Bild; wenn nur ein Bild vorhanden ist und `role` weggelassen wird, wird es ebenfalls als erstes Bild behandelt         |
| `image_url` | `image_url.url` | `last_frame`      | Letztes Bild; kann einzeln verwendet werden oder zusammen mit `first_frame` zur Steuerung von Start- und Endpunkt |
| `image_url` | `image_url.url` | `reference_image` | Referenzobjekt, Charakter, Produkt, Kleidung, Szene oder Stil                    |
| `video_url` | `video_url.url` | `reference_video` | Referenzbewegung, Kameraführung, Darbietung oder Schnittstruktur                        |
| `audio_url` | `audio_url.url` | `reference_audio` | Referenzklangfarbe, Dialog, Musik oder Rhythmus                          |

Medienadressen unterstützen drei Formen:

- Öffentlich zugängliche HTTPS-URLs, empfohlen für große Dateien.
- `mm_file://{file_id}`, um bereits hochgeladene oder vorhandene Ergebnisse zu referenzieren.
- Entsprechende Medienarten als Base64-Daten-URI. Base64 erhöht das Volumen um etwa ein Drittel, stellen Sie sicher, dass der gesamte Anforderungstext 64 MB nicht überschreitet.

## Material-Spezifikationen und Mengenbeschränkungen
| Material | Format                                       | Single File Limit | Size / Duration                                                   | Quantity Limit                     |
| --- | ------------------------------------------- | --------- | --------------------------------------------------------------- | --------------------------- |
| Bild  | JPG, JPEG, PNG, WEBP, HEIC, HEIF                 | Max. 30 MB | Breite und Höhe jeweils 256-5760 px; Seitenverhältnis 0.4-2.5                                    | Max. 1 Bild für den ersten Frame, max. 1 Bild für den letzten Frame, max. 9 Referenzbilder |
| Video | MP4, MOV; H.264/AVC oder H.265/HEVC; Audiotrack AAC oder MP3 | Max. 50 MB | Jede Sequenz 2-15 Sekunden, insgesamt max. 15 Sekunden; Breite und Höhe jeweils 256-5760 px; Seitenverhältnis 0.4-2.5; 23.976-60 fps | Max. 3 Referenzvideos                  |
| Audio | WAV, MP3                                     | Max. 15 MB | Jede Sequenz 2-15 Sekunden, insgesamt max. 15 Sekunden                                            | Max. 3 Referenz-Audios                  |

In multimodalen Referenzszenarien sind insgesamt maximal 12 Dateien für Bilder, Videos und Audios zulässig. Szenen mit ersten und letzten Frames sowie Referenzmaterial-Szenen sind gegenseitig ausschließend: Sobald `reference_image`, `reference_video` oder `reference_audio` verwendet wird, können `first_frame` oder `last_frame` nicht mehr verwendet werden und umgekehrt.

Das Folgende sind keine Konzeptbilder oder Platzhaltermaterialien, sondern echte Referenzeingaben und tatsächliche Videoausgaben der offiziellen Produktionsfähigkeitsmuster von MiniMax H3. | Fähigkeit       | Wichtige Beobachtungen                |
| -------- | --------------------------- |
| Konsistenz von Personen und Gesichtern | Stabilität von Gesichtszügen, Frisur, Make-up und Charakter nach mehreren Kamerawinkeln     |
| Gesichtsausdruck     | Blick, Mikroexpressionen, emotionale Spannung und natürliche Kopfbewegungen in Nahaufnahmen      |

## Text-zu-Video

Wenn nur ein Textelement vorhanden ist, handelt es sich um Text-zu-Video. Es eignet sich, um direkt aus Ideen, Skripten oder Kamerabeschreibungen Bilder zu generieren. Die Stichworte können in der Reihenfolge "Subjekt + Aktion + Szene + Kamera + Licht + Ton" organisiert werden.

```bash
curl -X POST 'https://api.acedata.cloud/minimax/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MiniMax-H3",
    "content": [
      {
        "type": "text",
        "text": "15 Sekunden filmreklame für Parfüm: Auf den schwarzen Felsen der Küste am Morgen wird eine transparente Parfümflasche von Nebel und Wellen umgeben. Nahaufnahmen zeigen Wassertropfen auf der Flasche und die Lichtbrechung des Glases, die Kamera zieht langsam von der Produktaufnahme auf die weite Meeresoberfläche; silberblaue Töne, echtes natürliches Licht, hochklassig und zurückhaltend, das Ende bleibt auf dem Produkt stehen."
      }
    ],
    "resolution": "2K",
    "duration": 15,
    "ratio": "16:9"
  }'
```

Der Standard-Synchronmodus gibt nach Abschluss der Generierung die vollständige Aufgabe zurück:

```json
{
  "task": {
    "id": "f5977217-ed2c-40da-adbe-93d08235618f",
    "model": "MiniMax-H3",
    "status": "succeeded",
    "content": { "url": "https://cdn.acedata.cloud/minimax/f5977217.mp4" },
    "resolution": "2K",
    "duration": 15,
    "ratio": "16:9"
  }
}
```

Wenn die Anfrage `"async": true` enthält, gibt die Schnittstelle sofort zurück:

```json
{
  "task_id": "f5977217-ed2c-40da-adbe-93d08235618f",
  "trace_id": "trace_7f8c2b1a"
}
```

## Erstes Bild-zu-Video

Das Bild wird als `first_frame` markiert, das Modell beginnt mit dieser Szene zu generieren. Es eignet sich, um Poster, Produktbilder, Charakterdesigns und Fotografien natürlich zum Leben zu erwecken.

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "Die Figur atmet natürlich und schaut aus dem Fenster, der Saum ihrer Kleidung wird vom Wind bewegt, die Kamera fährt langsam näher."
    },
    {
      "type": "image_url",
      "image_url": {
        "url": "https://cdn.acedata.cloud/b1c82e4937.png"
      },
      "role": "first_frame"
    }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "adaptive"
}
```

## Letztes Bild und Erst-zu-Endbild-Video
只提供 `last_frame` kann das Modell dazu bringen, natürlich bis zum angegebenen Bild zu generieren; gleichzeitig kann die Bereitstellung von `first_frame` und `last_frame` den Start- und Endpunkt klar steuern. Geeignet für Übergänge, Formveränderungen, Wachstumsprozesse oder Produktvergleiche.

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "Das Mädchen wächst natürlich von der Kindheit zur Jugend, die Zeit vergeht sanft, die Figur bleibt immer in der Mitte des Bildes."
    },
    {
      "type": "image_url",
      "image_url": { "url": "YOUR_FIRST_FRAME_URL" },
      "role": "first_frame"
    },
    {
      "type": "image_url",
      "image_url": { "url": "YOUR_LAST_FRAME_URL" },
      "role": "last_frame"
    }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "adaptive"
}
```

Die Größe und das Seitenverhältnis von Erst- und Endbild sollten möglichst übereinstimmen, und die Position des Hauptmotivs, die Komposition und die Lichtunterschiede sollten nicht zu groß sein, damit ein natürlicher Übergang leichter erreicht werden kann.

## Multimodale Referenzlebensvideos

Referenzmaterial kann kombiniert verwendet werden: Referenzbilder steuern das Aussehen von Charakteren oder Produkten, Referenzvideos steuern Bewegungen und Kameraführung, Referenzaudio steuert den Dialogton, die Musik oder den Schnittrhythmus. In den Hinweisen sollte klar angegeben werden, was jede Art von Material steuern soll, um zu vermeiden, dass nur Material hochgeladen wird, ohne die Beziehung anzugeben.

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "Die Gesichtszüge, Frisur und Kleidung des Referenzcharakters sollen beibehalten werden, und das Modevideo soll gemäß den Darbietungsbewegungen im Referenzvideo erstellt werden; der Kamerarhythmus folgt dem Referenzaudio, Nahaufnahmen heben natürliche Gesichtsausdrücke hervor."
    },
    {
      "type": "image_url",
      "image_url": { "url": "YOUR_CHARACTER_IMAGE_URL" },
      "role": "reference_image"
    },
    {
      "type": "video_url",
```

## Rückrufbenachrichtigung

Die Übermittlung von `callback_url` aktiviert automatisch den asynchronen Modus: Die Erstellungsschnittstelle gibt sofort `task_id` und `trace_id` zurück und sendet das endgültige Ergebnis nach Abschluss der Aufgabe an diese Adresse per POST, die Struktur entspricht der Antwort zur Aufgabenabfrage.

Der endgültige Status im Rückruf ist `succeeded`, `failed` oder `cancelled`. Selbst bei Verwendung von Rückrufen wird empfohlen, `task_id` zu speichern, um proaktiv abzufragen oder versäumte Benachrichtigungen zu kompensieren.

## Häufige Fehler

| HTTP-Statuscode | Bedeutung           | Handlungsempfehlung                           |
| -------- | ------------ | ------------------------------ |
| `400`    | Parameterfehler oder ungültige Materialkombination | Überprüfen Sie die Pflichtfelder, `role`, die Anzahl und das Format des Materials          |
| `401`    | Token fehlt oder ungültig  | Überprüfen Sie `Authorization: Bearer ...` |
| `402`    | Guthaben oder Limit unzureichend      | Fügen Sie im Dashboard allgemeines Guthaben hinzu                     |
| `422`    | Inhaltssicherheitsprüfung nicht bestanden    | Passen Sie die Hinweise oder das Material an und reichen Sie es erneut ein                  |
| `429`    | Anfragen zu häufig       | Nach exponentiellem Backoff erneut versuchen; Aufgabenabfrage wird empfohlen, etwa alle 10 Sekunden         |
| `500`    | Dienst vorübergehend nicht verfügbar      | Behalten Sie die Anforderungsinformationen und versuchen Sie es später erneut                    |

Der `task.status: succeeded` in der synchronen Antwort zeigt an, dass das Video generiert wurde; die asynchrone Bestätigung bedeutet nur, dass die Aufgabe in die Warteschlange eingetreten ist. Nur wenn die Aufgabe letztendlich erfolgreich ist, wird eine Gebühr erhoben, die Abfrage der Aufgabe selbst ist kostenlos und es fallen keine wiederholten Gebühren an.
