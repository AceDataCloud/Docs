Dieser Artikel stellt die Integration und Nutzung der Nano Banana Images API vor. Diese Schnittstelle unterstützt zwei Funktionen: **Bildgenerierung (generate)** und **Bildbearbeitung (edit)**.

## Antragsprozess

Um die Nano Banana Images API zu verwenden, rufen Sie zunächst die [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications) auf, um Ihren API-Token zu erhalten und ihn als Reserve aufzubewahren.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach Abschluss kehren Sie automatisch zur aktuellen Seite zurück.

**Ein API-Token kann alle Dienste der Plattform aufrufen; es ist nicht erforderlich, ihn für jeden Dienst einzeln zu beantragen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent zum kostenlosen Testen; wenn das Kontingent nicht ausreicht, können Sie in der [Konsole](https://platform.acedata.cloud/console/coin) allgemeines Guthaben aufladen.

> 📘 Vollständige Dokumentation: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## Schnittstellenübersicht

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **Authentifizierungsmethode**：`authorization: Bearer {token}` im HTTP-Header mitführen
- **Request-Header**：
  - `accept: application/json`
  - `content-type: application/json`
- **Aktion (action)**：
  - `generate`：Bilder anhand von Text-Prompts generieren
  - `edit`：Bilder auf Grundlage der bereitgestellten Bilder bearbeiten
- **Modell (model)**（optional）：
  - `nano-banana`（Standard）：Basierend auf Gemini 2.5 Flash Image, schnell und kostengünstig
  - `nano-banana-2-lite`：Basierend auf Gemini 3.1 Flash Lite Image, unterstützt nur 1K, schnelle Generierung
  - `nano-banana-2`：Basierend auf Gemini 3.1 Flash Image Preview, Pro-Qualität + Flash-Geschwindigkeit
  - `nano-banana-pro`：Basierend auf Gemini 3 Pro Image Preview, höchste Qualität
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`：Versionen der offiziellen Kanäle der jeweiligen Modelle, mit besserer Bildqualität und Stabilität sowie abweichender Abrechnung
- **Asynchroner Callback**：Optional, empfängt über `callback_url` Benachrichtigungen über den Abschluss der Aufgabe und Ergebnisse
- **Bildanzahl**：Optional, über `count` können 1–4 Bilder angegeben werden, standardmäßig 1 Bild; jedes Bild wird durch einen unabhängigen Generierungsaufruf erstellt; gewöhnliche technische Fehler oder Sicherheitsablehnungen des Anbieters betreffen nur den entsprechenden Aufruf, die übrigen erfolgreich generierten Bilder werden wie gewohnt zurückgegeben und nach der tatsächlich erfolgreichen Bildanzahl abgerechnet

## Schnellstart: Bilder generieren（`action=generate`）

**Minimal erforderliche Parameter**：`action`、`prompt`
Wenn Sie nur anhand eines Prompts direkt ein Bild erstellen möchten, setzen Sie `action` auf `generate` und geben Sie einen klaren `prompt` an.

### Request-Beispiel（cURL）

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Request-Beispiel（Python）

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Beispiel für eine erfolgreiche Rückgabe

```json
{
  "success": true,
  "task_id": "70e6931b-6e34-43db-9e36-8765e2809d04",
  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {
      "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
      "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }
  ]
}
```

### Feldbeschreibung

- `success`：Ob diese Anfrage erfolgreich war.
- `task_id`：Aufgaben-ID.
- `trace_id`：ID zur Ablaufverfolgung, erleichtert die Fehlerbehebung.
- `count`：Anzahl der angeforderten zu generierenden oder zu bearbeitenden Bilder, unterstützt 1–4, Standardwert ist 1. `data` enthält nur erfolgreich generierte Bilder und wird nach der tatsächlich zurückgegebenen Anzahl abgerechnet. Jeder Generierungsaufruf verwendet zwingend die nativen Sicherheitsrichtlinien des Anbieters; die Ablehnung eines Aufrufs beeinträchtigt andere erfolgreiche Aufrufe nicht. Wenn alle Aufrufe abgelehnt werden, wird 403 zurückgegeben.
- `data[]`：Ergebnisliste.
  - `prompt`：Der für die Generierung verwendete Prompt (Echo).
  - `image_url`：Direkte URL des generierten Bildes.

> Hinweis: Für `/nano-banana/images` sind zur Bildgenerierung nur `action` und `prompt` erforderlich

## Bilder bearbeiten（`action=edit`）

Wenn Sie ein vorhandenes Bild bearbeiten möchten, setzen Sie `action` auf `edit` und übergeben Sie über `image_urls` eine Liste der zu bearbeitenden Bildlinks (ein oder mehrere Bilder) sowie einen `prompt`, der das Bearbeitungsziel beschreibt.

Wenn wir beispielsweise hier ein Personenfoto und ein Kleidungsfoto bereitstellen und die Person dieses Kleidungsstück tragen lassen möchten, können wir die Bildlinks gleichzeitig übergeben und `action` auf `edit` setzen. Die URL kann eine HTTP-URL sein, ein öffentlich zugänglicher Link mit dem Protokoll `https` oder `http`, oder auch ein Base64-codiertes Bild, wie `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Request-Beispiel（cURL）
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Anforderungsbeispiel (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Beispiel für erfolgreiche Rückgabe

```json
{
  "success": true,
  "task_id": "93f11baf-347b-4bb4-9520-8653cb46d6a3",
  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",
  "data": [
    {
      "prompt": "let this man wear on this T-shirt",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/8e9e0253-26f4-45b9-b3f8-ac1aed1c284b.png"
    }
  ]
}
```

### Feldbeschreibung

- `image_urls[]`: Liste der URLs der zu bearbeitenden Bilder (müssen öffentlich zugänglich sein). Es können mehrere Bilder übergeben werden; der Dienst kombiniert diese Materialien mit `prompt`, um die Bearbeitung abzuschließen.
- Die übrigen Felder entsprechen der Rückgabe von „Bild generieren“.

## Asynchroner Callback (optional, empfohlen)

Die Generierung oder Bearbeitung kann eine gewisse Zeit in Anspruch nehmen. Um zu vermeiden, dass lange Verbindungen Ressourcen belegen, wird empfohlen, **Webhook-Callbacks** über `callback_url` zu verwenden:

1. Füge im Anfragetext `callback_url` hinzu, beispielsweise die Webhook-Adresse deines Servers (muss öffentlich zugänglich sein und POST JSON unterstützen).
2. Die API gibt **sofort** eine Antwort zurück, die `task_id` enthält (oder grundlegende Ergebnisse enthält).
3. Wenn die Aufgabe abgeschlossen ist, sendet die Plattform das vollständige JSON per `POST` an `callback_url`. Du kannst die Anfrage und das Ergebnis über `task_id` verknüpfen.

**Beispiel für Callback-Nutzlast** (die Feldstruktur entspricht der synchronen erfolgreichen Rückgabe):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Fehlerbehandlung

Bei einem fehlgeschlagenen Aufruf werden ein Standardfehlerformat und eine Tracking-ID zurückgegeben. Häufige Fehler sind:

- **400 `token_mismatched`**: Die Anfrage ist ungültig oder die Parameter sind fehlerhaft.
- **400 `api_not_implemented`**: Die Schnittstelle ist nicht implementiert (bitte den Support kontaktieren).
- **401 `invalid_token`**: Authentifizierung fehlgeschlagen oder Token fehlt.
- **403 `forbidden`**: Die native Sicherheitsrichtlinie des Anbieters hat die Anfrage oder das Generierungsergebnis abgelehnt. Dieser Aufruf gibt kein Bild zurück und wird nicht abgerechnet; Anfragen mit mehreren Bildern können weiterhin andere erfolgreiche Aufrufe zurückgeben und abrechnen.
- **429 `too_many_requests`**: Das Anfragelimit wurde überschritten.
- **500 `api_error`**: Serverausnahme.

### Beispiel für Fehlerantwort

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Parametervergleich und Hinweise

- **Erforderlich**: `action`, `prompt`
- **Nur für die Bearbeitung**: `image_urls` (Array, mindestens 1 Eintrag)
- **Optional**: `model` (standardmäßig `nano-banana`, optional `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-pro` oder die entsprechenden offiziellen Kanalversionen mit `:official`), `aspect_ratio` (Seitenverhältnis, z. B. `1:1`, `16:9`), `resolution` (Auflösung, z. B. `1K`, `2K`, `4K`; `nano-banana-2-lite` unterstützt nur `1K`), `callback_url` (für asynchrone Callbacks)
- **Headers**: `authorization: Bearer {token}` muss bereitgestellt werden; `accept` sollte auf `application/json` gesetzt werden
- **Bildzugänglichkeit**: `image_urls` müssen direkt verlinkte, öffentlich zugängliche URLs (HTTP/HTTPS) sein; HTTPS wird empfohlen
- **Idempotenz und Tracking**: Bewahre `task_id` und `trace_id` auf, um die Fehlerbehebung und Ergebniszuordnung zu erleichtern
