Die Hauptfunktion der Grok Tasks API besteht darin, den Ausführungsstatus einer Aufgabe anhand der von der Grok Videos Generation API generierten Aufgaben-ID abzufragen.

Dieses Dokument beschreibt ausführlich die Integration der Grok Tasks API und hilft Ihnen dabei, die Ausführungsstatus der Aufgaben der Grok Videos Generation API einfach abzufragen.

## Antragsprozess

Um die Grok Tasks API zu nutzen, müssen Sie zunächst auf der Antragsseite [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos) den entsprechenden Dienst beantragen und die von der Grok Videos Generation API zurückgegebene Aufgaben-ID kopieren.

Anschließend gehen Sie auf die Seite [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks), um den entsprechenden Dienst zu beantragen. Nach dem Aufrufen der Seite klicken Sie einfach auf die Schaltfläche „Acquire“.

Falls Sie noch nicht eingeloggt oder registriert sind, werden Sie automatisch zur [Login-Seite](https://platform.acedata.cloud) weitergeleitet, um sich zu registrieren und anzumelden. Nach der Anmeldung kehren Sie automatisch zur aktuellen Seite zurück.

Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, mit dem Sie die API kostenlos nutzen können.

## Beispielanfrage

Die Grok Tasks API kann verwendet werden, um die Ergebnisse der Grok Videos Generation API abzufragen.

### Festlegen von Request-Headern und Request-Body

**Request Headers** umfassen:

- `accept`: Gibt an, dass die Antwort im JSON-Format erwartet wird, hier `application/json`.
- `authorization`: Der API-Schlüssel für den Aufruf der API, der nach der Beantragung direkt aus dem Dropdown ausgewählt werden kann.

**Request Body** umfasst:

- `id`: Die abzufragende Aufgaben-ID.
- `action`: Die Art der Aktion auf die Aufgabe, bei Einzelabfrage `retrieve`.

### CURL-Beispielcode

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Beispielantwort

Nach erfolgreicher Anfrage gibt die API die Detailinformationen zur Aufgabe zurück. Das Feld `request` enthält den Request-Body der ursprünglichen Aufgabe, das Feld `response` die Antwort nach Abschluss der Aufgabe, zum Beispiel:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/grok/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Felderklärung:

- `id`: Die ID der generierten Aufgabe, die zur eindeutigen Identifikation der Aufgabe dient.
- `request`: Die Anfragedaten der abgefragten Aufgabe.
- `response`: Die Antwortdaten der abgefragten Aufgabe.

## Batch-Abfrage

Für die Abfrage mehrerer Aufgaben-IDs gleichzeitig setzen Sie `action` auf `retrieve_batch` und übergeben die Aufgaben-IDs als Array über `ids`:

**Request Body** umfasst:

- `ids`: Array der abzufragenden Aufgaben-IDs.
- `action`: Die Art der Aktion auf die Aufgaben, bei Batch-Abfrage `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
