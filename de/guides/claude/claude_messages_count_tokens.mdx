Die Claude Messages Count Tokens API kann die Anzahl der Eingabe-Token einer Message berechnen, ohne tatsächlich eine Nachricht zu erstellen, einschließlich der Token-Zählung für Inhalte wie Tools, Bilder und Dokumente. Dies ist sehr nützlich, wenn Kosten geschätzt oder überprüft werden müssen, ob die Eingabe die Kontextbegrenzung des Modells überschreitet.

Dieses Dokument stellt hauptsächlich den Nutzungsablauf der Claude Messages Count Tokens API vor.

## Beantragungsprozess

Um die Claude Messages Count Tokens API zu verwenden, rufen Sie zunächst die [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications) auf, um Ihren API Token zu erhalten und ihn als Reserve aufzubewahren.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Falls Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach Abschluss kehren Sie automatisch zur aktuellen Seite zurück.

**Ein API Token kann alle Dienste der Plattform aufrufen, ohne dass Sie jeden Dienst einzeln beantragen müssen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Guthaben, das Sie kostenlos ausprobieren können; bei unzureichendem Guthaben können Sie in der [Konsole](https://platform.acedata.cloud/console/coin) ein allgemeines Guthaben aufladen.

> 📘 Vollständige Dokumentation: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Grundlegende Verwendung

Der Anfragepfad der Claude Messages Count Tokens API lautet `/v1/messages/count_tokens` und stimmt mit der offiziellen Anthropic API überein. Wir müssen mindestens zwei erforderliche Parameter bereitstellen:

- `model`: Wählen Sie das zu verwendende Claude-Modell, wie das neueste Flaggschiff `claude-fable-5-1`; das ursprüngliche `claude-fable-5` bleibt weiterhin kompatibel verfügbar.
- `messages`: Das Eingabe-Nachrichtenarray, wobei jede Nachricht `role` (Rolle) und `content` (Inhalt) enthält.

Häufig verwendete optionale Parameter:

- `system`: System-Prompt, wird in die Token-Anzahl einbezogen.
- `tools`: Tool-Definitionen, werden in die Token-Anzahl einbezogen.
- `thinking`: Konfiguration für erweitertes Denken.
- `tool_choice`: Konfiguration für die Tool-Auswahl.
- `cache_control`: Cache-Steuerungskonfiguration auf oberster Ebene oder auf Inhaltblockebene.

`messages`, `system`, Tool-Aufrufwiedergaben, URL-Bilder und document/PDF-Inhaltsblöcke verwenden dieselbe stabile Anfragestruktur wie die Messages API.

### cURL-Beispiel

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python-Beispiel

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Beispiel für das Rückgabeergebnis:

```json
{
  "input_tokens": 11
}
```

### Verwendung des Anthropic SDK

Die Claude Messages Count Tokens API akzeptiert die stabile Anfragestruktur des Anthropic SDK und kann über die `anthropic`-Bibliothek aufgerufen werden. Die Schnittstelle verwendet die native Count-Tokens-Fähigkeit des ausgewählten Modells, um die Eingabe zu zählen, und kann verwendet werden, um den Umfang der Eingabe vor dem Senden einer Messages-Anfrage zu überprüfen.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Token-Zählung mit Tools

Wenn Ihre Anfrage Tool-Definitionen enthält, werden diese Tools ebenfalls in die Token-Anzahl einbezogen:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Token-Zählung mit System-Prompt

Der System-Prompt wird ebenfalls in die Token-Anzahl einbezogen:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Hinweise

- Diese API berechnet nur die Anzahl der Eingabe-Token und erzeugt keinerlei Modellausgabe.
- Das Token-Zählergebnis kann zur Schätzung des Eingabeumfangs und zur Überprüfung des Kontextfensters verwendet werden; die endgültige Abrechnung richtet sich nach `usage` in der tatsächlichen Messages-Antwort.
- Bilder, PDFs, Tool-Definitionen, System-Prompts und thinking-Konfigurationen werden gemäß den Eingaberegeln des ausgewählten Modells in das Ergebnis einbezogen.
- Diese API ist vollständig kostenlos und verbraucht keinerlei Guthaben.
