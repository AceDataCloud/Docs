Die Claude Messages Count Tokens API kann die Anzahl der Eingabe-Token einer Message berechnen, einschließlich der Token-Zählung von Tools, Bildern und Dokumenten usw., ohne tatsächlich eine Nachricht zu erstellen. Dies ist sehr nützlich, wenn Kosten geschätzt oder überprüft werden müssen, ob die Eingabe die Kontextbegrenzung des Modells überschreitet.

Dieses Dokument stellt hauptsächlich den Nutzungsprozess der Claude Messages Count Tokens API vor.

## Beantragungsprozess

Um die Claude Messages Count Tokens API zu verwenden, rufen Sie zunächst die [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications) auf, um Ihren API-Token zu erhalten, und bewahren Sie ihn als Reserve auf.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie sich noch nicht angemeldet oder registriert haben, werden Sie automatisch zur Anmeldeseite weitergeleitet, um Sie zur Registrierung und Anmeldung einzuladen. Nach Abschluss kehren Sie automatisch zur aktuellen Seite zurück.

**Ein API-Token kann alle Plattformdienste aufrufen, ohne dass für jeden Dienst separat ein Antrag gestellt werden muss.** Bei der ersten Beantragung wird ein kostenloses Guthaben verschenkt, das kostenlos getestet werden kann; bei unzureichendem Guthaben kann das allgemeine Guthaben in der [Konsole](https://platform.acedata.cloud/console/coin) aufgeladen werden.

> 📘 Vollständige Dokumentation: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Grundlegende Verwendung

Der Anfragepfad der Claude Messages Count Tokens API lautet `/v1/messages/count_tokens` und stimmt mit der offiziellen Anthropic API überein. Wir müssen mindestens zwei erforderliche Parameter bereitstellen:

- `model`: Wählen Sie das zu verwendende Claude-Modell aus; `claude-opus-5-5` kann für Messages Token Count verwendet werden, ebenso wie das neueste Flaggschiff `claude-fable-5-1`; das ursprüngliche `claude-fable-5` bleibt weiterhin kompatibel erhalten.
- `messages`: Das Array der eingegebenen Nachrichten, wobei jede Nachricht `role` (Rolle) und `content` (Inhalt) enthält.

Häufig verwendete optionale Parameter:

- `system`: System-Prompt, wird in die Token-Anzahl einbezogen.
- `tools`: Tool-Definitionen, werden in die Token-Anzahl einbezogen.
- `thinking`: Konfiguration für erweitertes Denken.
- `tool_choice`: Konfiguration der Tool-Auswahl.
- `cache_control`: Cache-Steuerungskonfiguration auf oberster Ebene oder auf Inhaltsblockebene.

`messages`, `system`, die Wiedergabe von Tool-Aufrufen, URL-Bilder und document/PDF-Inhaltsblöcke verwenden dieselbe stabile Anfragestruktur wie die Messages API.

### cURL-Beispiel

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python-Beispiel

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Beispiel für das Rückgabeergebnis:

```json
{
  "input_tokens": 11
}
```

### Verwendung des Anthropic SDK

Die Claude Messages Count Tokens API akzeptiert die stabile Anfragestruktur des Anthropic SDK und kann über die Bibliothek `anthropic` aufgerufen werden. Die Schnittstelle verwendet die native Count-Tokens-Fähigkeit des ausgewählten Modells, um die Eingabe zu zählen, und kann verwendet werden, um den Umfang der Eingabe vor dem Senden einer Messages-Anfrage zu überprüfen.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Token-Zählung mit Tools

Wenn Ihre Anfrage Tool-Definitionen enthält, werden diese Tools ebenfalls in die Token-Anzahl einbezogen:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Token-Zählung mit System-Prompt

Der System-Prompt wird ebenfalls in die Token-Anzahl einbezogen:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Hinweise

- Diese API berechnet nur die Anzahl der Eingabe-Token und erzeugt keine Modellausgabe.
- Die Token-Zählergebnisse können zur Schätzung des Eingabeumfangs und zur Überprüfung des Kontextfensters verwendet werden; die endgültige Abrechnung richtet sich nach `usage` in der tatsächlichen Messages-Antwort.
- Bilder, PDFs, Tool-Definitionen, System-Prompts und thinking-Konfigurationen werden gemäß den Eingaberegeln des ausgewählten Modells in das Ergebnis einbezogen.
- Diese API ist vollständig kostenlos und verbraucht kein Guthaben.
