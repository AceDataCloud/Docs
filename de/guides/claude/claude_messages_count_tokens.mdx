Die Claude Messages Count Tokens API kann die Anzahl der Eingabe-Tokens einer Message berechnen, einschließlich der Token-Zählung für Inhalte wie Tools, Bilder und Dokumente, ohne tatsächlich eine Nachricht zu erstellen. Dies ist sehr nützlich, wenn Kosten geschätzt oder überprüft werden müssen, ob die Eingabe die Kontextbegrenzung des Modells überschreitet.

Dieses Dokument stellt hauptsächlich den Nutzungsprozess der Claude Messages Count Tokens API vor.

## Beantragungsprozess

Um die Claude Messages Count Tokens API zu verwenden, rufen Sie zunächst in der [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications) Ihren API-Token ab und bewahren Sie ihn zur späteren Verwendung auf.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Falls Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach Abschluss kehren Sie automatisch zur aktuellen Seite zurück.

**Ein API-Token kann alle Dienste der Plattform aufrufen, ohne dass er für jeden Dienst separat beantragt werden muss.** Bei der ersten Beantragung wird ein kostenloses Guthaben vergeben, mit dem Sie den Dienst kostenlos ausprobieren können; bei unzureichendem Guthaben können Sie in der [Konsole](https://platform.acedata.cloud/console/coin) ein universelles Guthaben aufladen.

> 📘 Vollständige Dokumentation: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Grundlegende Verwendung

Der Anfragepfad der Claude Messages Count Tokens API lautet `/v1/messages/count_tokens` und stimmt mit der offiziellen Anthropic API überein. Wir müssen mindestens zwei Pflichtparameter bereitstellen:

- `model`: Wählen Sie das zu verwendende Claude-Modell aus; `claude-opus-5-5` kann für Messages Token Count verwendet werden, ebenso wie das neueste Flaggschiff `claude-fable-5-1`; das ursprüngliche `claude-fable-5` bleibt weiterhin kompatibel erhalten. `claude-sonnet-5-5` wurde zur nativen Messages-Serienschnittstelle hinzugefügt und unterstützt Bildeingaben sowie adaptives Denken; die offiziellen Referenzpreise für Eingabe, Ausgabe und Cache-Lesen betragen jeweils 2, 10 und 0,20 US-Dollar pro Million Tokens.
- `messages`: Das Array der eingegebenen Nachrichten, wobei jede Nachricht `role` (Rolle) und `content` (Inhalt) enthält.

Häufig verwendete optionale Parameter:

- `system`: System-Prompt, wird bei der Token-Anzahl berücksichtigt.
- `tools`: Tool-Definitionen, werden bei der Token-Anzahl berücksichtigt.
- `thinking`: Konfiguration für erweitertes Denken.
- `tool_choice`: Konfiguration für die Tool-Auswahl.
- `cache_control`: Cache-Steuerungskonfiguration auf oberster Ebene oder auf Inhaltblockebene.

`messages`, `system`, die Wiedergabe von Tool-Aufrufen, URL-Bilder und document/PDF-Inhaltsblöcke verwenden dieselbe stabile Anfragestruktur wie die Messages API.

### cURL-Beispiel

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python-Beispiel

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Beispiel für das Rückgabeergebnis:

```json
{
  "input_tokens": 11
}
```

### Verwendung des Anthropic SDK

Die Claude Messages Count Tokens API akzeptiert die stabile Anfragestruktur des Anthropic SDK und kann über die Bibliothek `anthropic` aufgerufen werden. Die Schnittstelle verwendet die native Count-Tokens-Funktion des ausgewählten Modells, um Eingaben zu zählen, und kann verwendet werden, um die Eingabegröße vor dem Senden einer Messages-Anfrage zu überprüfen.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Token-Zählung mit Tools

Wenn Ihre Anfrage Tool-Definitionen enthält, werden diese Tools ebenfalls bei der Token-Anzahl berücksichtigt:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Token-Zählung mit System-Prompt

Der System-Prompt wird ebenfalls bei der Token-Anzahl berücksichtigt:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Hinweise

- Diese API berechnet nur die Anzahl der Eingabe-Tokens und erzeugt keinerlei Modellausgabe.
- Das Token-Zählergebnis kann zur Schätzung der Eingabegröße und zur Überprüfung des Kontextfensters verwendet werden; die endgültige Abrechnung richtet sich nach `usage` in der tatsächlichen Messages-Antwort.
- Bilder, PDFs, Tool-Definitionen, System-Prompts und die `thinking`-Konfiguration werden gemäß den Eingaberegeln des ausgewählten Modells in das Ergebnis einbezogen.
- Diese API ist vollständig kostenlos und verbraucht keinerlei Guthaben.
