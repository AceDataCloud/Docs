Claude Messages Count Tokens API kann die Anzahl der Eingabe-Token einer Nachricht berechnen, ohne tatsächlich Nachrichten zu erstellen, einschließlich der Token-Zählung von Werkzeugen, Bildern und Dokumenten. Dies ist besonders nützlich, wenn Kosten geschätzt oder überprüft werden müssen, ob die Eingabe die Kontextgrenze des Modells überschreitet.

Dieses Dokument beschreibt hauptsächlich den Ablauf der Nutzung der Claude Messages Count Tokens API.

## Antragsprozess

Um die Claude Messages Count Tokens API zu nutzen, müssen Sie zunächst Ihr API-Token im [Ace Data Cloud Dashboard](https://platform.acedata.cloud/console/applications) abrufen und für später aufbewahren.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach Abschluss werden Sie automatisch zur aktuellen Seite zurückgeleitet.

**Ein API-Token reicht aus, um alle Dienste der Plattform zu nutzen, es ist nicht erforderlich, für jeden Dienst separat zu beantragen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, um es kostenlos auszuprobieren; wenn das Kontingent erschöpft ist, können Sie im [Dashboard](https://platform.acedata.cloud/console/coin) Ihr allgemeines Guthaben aufladen.

> 📘 Vollständige Dokumentation: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Grundlegende Nutzung

Der Anfragepfad der Claude Messages Count Tokens API lautet `/v1/messages/count_tokens`, was mit der offiziellen API von Anthropic übereinstimmt. Wir müssen mindestens zwei erforderliche Parameter bereitstellen:

- `model`: Wählen Sie das zu verwendende Claude-Modell, wie `claude-opus-4-8`, `claude-sonnet-4-6` usw.
- `messages`: Eingabemeldungsarray, jede Nachricht enthält `role` (Rolle) und `content` (Inhalt).

Häufig verwendete optionale Parameter:

- `system`: Systemaufforderung, die in die Tokenanzahl einfließt.
- `tools`: Werkzeugdefinition, die in die Tokenanzahl einfließt.
- `thinking`: Erweiterte Denk-Konfiguration.
- `tool_choice`: Werkzeugauswahl-Konfiguration.
- `cache_control`: Cache-Steuerung auf oberster oder Inhaltsebene.

`messages`, `system`, Werkzeugaufruf-Wiedergabe, URL-Bilder und document/PDF-Inhalt verwenden die gleiche stabile Anfrage-Struktur wie die Messages API.

### cURL Beispiel

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-opus-4-8",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python Beispiel

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-opus-4-8",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Beispiel für die Rückgabe:

```json
{
  "input_tokens": 11
}
```

### Verwendung des Anthropic SDK

Die Claude Messages Count Tokens API akzeptiert die stabile Anfrage-Struktur des Anthropic SDK und kann über die `anthropic`-Bibliothek aufgerufen werden. Derzeit wird der Rückgabewert von einem lokalen Schätzer von Ace Data Cloud berechnet und ist nicht das genaue Ergebnis des offiziellen Tokenizers von Anthropic; die tatsächliche Token-Anzahl für multimodale, Werkzeug- und verschiedene Claude-Modelle kann abweichen.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Token-Zählung mit Werkzeugen

Wenn Ihre Anfrage Werkzeugdefinitionen enthält, werden diese Werkzeuge ebenfalls in die Tokenanzahl einbezogen:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Token-Zählung mit Systemaufforderungen

Systemaufforderungen fließen ebenfalls in die Tokenanzahl ein:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Hinweise

- Diese API berechnet nur die Anzahl der Eingabe-Token und erzeugt keine Modell-Ausgaben.
- Die Token-Zählungsergebnisse können zur groben Schätzung des Eingabeumfangs verwendet werden, sollten jedoch nicht als Grundlage für präzise Abrechnungen, Kontextfensterzugriffe oder Modell-Tokenizer-Vergleiche dienen.
- Derzeit berechnet der Schätzer die visuellen/dokumentarischen Tokens von Bildern und PDFs nicht genau und kann die Unterschiede zwischen den offiziellen Tokenizern verschiedener Claude-Modelle nicht widerspiegeln.
- Diese API ist vollständig kostenlos und verbraucht kein Guthaben.
