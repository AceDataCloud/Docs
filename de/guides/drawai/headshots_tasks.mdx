Die Hauptfunktion der AI Passfoto Task API besteht darin, den Status der Ausführung eines Auftrags zu überprüfen, indem die von der AI Passfoto Erstellung API generierte Auftrags-ID eingegeben wird.

Dieses Dokument wird die Integrationsanleitung für die AI Passfoto Task API detailliert beschreiben, um Ihnen zu helfen, diese API einfach zu integrieren und ihre leistungsstarken Funktionen voll auszuschöpfen. Mit der AI Passfoto Task API können Sie den Status der Ausführung von Aufträgen der AI Passfoto Erstellung API einfach abfragen.

## Antragsprozess

Um die AI Passfoto Task API zu nutzen, müssen Sie zunächst auf die Anmeldeseite [AI Passfoto Erstellung API](https://platform.acedata.cloud/documents/bf7214a3-8447-4157-8a75-f5bb39d5ed1b) gehen und den entsprechenden Dienst beantragen, dann kopieren Sie die Auftrags-ID der AI Passfoto Erstellung API, wie im Bild gezeigt:

<p><img src="https://cdn.acedata.cloud/7ezmmn.png" width="500" class="m-auto"></p>

Gehen Sie schließlich zur Tasks API-Seite [AI Passfoto Task API](https://platform.acedata.cloud/documents/3a23ee34-8689-406b-9042-7954224348ad), um den entsprechenden Dienst zu beantragen. Klicken Sie nach dem Betreten der Seite auf die Schaltfläche „Acquire“, wie im Bild gezeigt:

![Anmeldeseite](https://cdn.acedata.cloud/rci31i.png)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur [Anmeldeseite](https://platform.acedata.cloud) weitergeleitet, um sich zu registrieren und anzumelden. Nach der Anmeldung werden Sie automatisch zur aktuellen Seite zurückgeleitet.

Bei der ersten Antragstellung gibt es ein kostenloses Kontingent, mit dem Sie die API kostenlos nutzen können.

## Anfragebeispiel

Die AI Passfoto Task API kann verwendet werden, um die Ergebnisse der AI Passfoto Erstellung API abzufragen. Informationen zur Nutzung der AI Passfoto Erstellung API finden Sie im Dokument [AI Passfoto Erstellung API](https://platform.acedata.cloud/documents/d6ea75a4-836e-490a-aee5-7ca911a808fd).

Wir nehmen als Beispiel eine von der AI Passfoto Erstellung API zurückgegebene Auftrags-ID und demonstrieren, wie man diese API verwendet. Angenommen, wir haben eine Auftrags-ID: `16f96e95-d95c-46ef-b183-139b9bd1aebd`, im Folgenden zeigen wir, wie man durch Eingabe einer Auftrags-ID vorgeht.

### Anfrageheader und Anfragekörper festlegen

**Request Headers** umfassen:

- `accept`: Gibt an, dass die Antwort im JSON-Format empfangen werden soll, hier eingetragen als `application/json`.
- `authorization`: Der Schlüssel zur API, der nach der Beantragung direkt ausgewählt werden kann.

**Request Body** umfasst:

- `id`: Die hochgeladene Auftrags-ID.
- `action`: Die Art der Operation für den Auftrag.

Einstellung wie im folgenden Bild gezeigt:

Einige Codebeispiele sind wie folgt:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/headshots/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "16f96e95-d95c-46ef-b183-139b9bd1aebd",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/headshots/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "16f96e95-d95c-46ef-b183-139b9bd1aebd",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Fehlerbehandlung

Bei der Verwendung der API, wenn ein Fehler auftritt, gibt die API den entsprechenden Fehlercode und die Informationen zurück. Zum Beispiel:

- `400 token_mismatched`: Ungültige Anfrage, möglicherweise aufgrund fehlender oder ungültiger Parameter.
- `400 api_not_implemented`: Ungültige Anfrage, möglicherweise aufgrund fehlender oder ungültiger Parameter.
- `401 invalid_token`: Unbefugt, ungültiger oder fehlender Autorisierungstoken.
- `429 too_many_requests`: Zu viele Anfragen, Sie haben das Rate-Limit überschritten.
- `500 api_error`: Interner Serverfehler, etwas ist auf dem Server schiefgelaufen.

### Fehlerantwort Beispiel

```json
{
  "success": false,
  "error": {

    "message": "fetch failed"
  },

}
```
