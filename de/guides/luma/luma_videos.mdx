Mit der zunehmenden Verbreitung von KI-Anwendungen haben sich verschiedene KI-Programme allmählich etabliert. KI ist zunehmend in alle Aspekte des Arbeits- und Alltagslebens der Menschen vorgedrungen. Auch die Branchen, die KI betreffen, werden immer vielfältiger, von den anfänglichen Schreibanwendungen über Medizin und Bildung bis hin zu den heutigen Videos.

Luma ist eine professionelle Plattform zur Erstellung hochwertiger Videos. Benutzer müssen lediglich Material hochladen, um automatisch hochwertige Videos in unterschiedlichen Stilen und Effekten zu generieren. Dieser KI-Videogenerator wurde von Teammitgliedern bekannter Technologieunternehmen entwickelt und hat das Ziel, ohne komplexe Bearbeitungstools jedem die einfache Erstellung herausragender Videos zu ermöglichen.

Luma stellt offiziell jedoch keine API bereit. AceDataCloud bietet eine Reihe von Luma-APIs an, die die offizielle Suno-Integration simulieren und die gewünschte Videogenerierung bequem und schnell ermöglichen.

## Beantragung und Nutzung

Um die Luma Videos Generation API zu verwenden, holen Sie sich zunächst Ihr API-Token in der [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications) und bewahren Sie es als Reserve auf.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach Abschluss kehren Sie automatisch zu dieser Seite zurück.

**Ein API-Token kann alle Dienste der Plattform aufrufen, ohne dass Sie jeden Dienst einzeln beantragen müssen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Guthaben zur kostenlosen Nutzung; bei unzureichendem Guthaben können Sie das allgemeine Guthaben in der [Konsole](https://platform.acedata.cloud/console/coin) aufladen.

> 📘 Vollständige Dokumentation: [Luma Videos Generation API →](https://platform.acedata.cloud/documents/luma-videos)

## Grundlegende Verwendung

Für welches Video Sie auch immer generieren möchten, Sie können beliebigen Text eingeben. Wenn ich beispielsweise ein Video über Astronauten generieren möchte, die zwischen Weltraum und Vulkanen pendeln, kann ich `Astronauts shuttle from space to volcano` eingeben, wie in der Abbildung gezeigt:

<p><img src="https://cdn.acedata.cloud/yub02j.png" width="500" className="m-auto" /></p>

Der generierte Code lautet wie folgt:

<p><img src="https://cdn.acedata.cloud/ieq7yn.png" width="500" className="m-auto" /></p>

Wichtige Anfrageparameter:

- `prompt`: Der Prompt für die Videogenerierung.
- `aspect_ratio`: Das Seitenverhältnis des Videos, standardmäßig 16:9.
- `end_image_url`: Optional, gibt das Endbild an.
- `enhancement`: Optional, Schalter zur Verbesserung der Klarheit.
- `loop`: Ob ein Loop-Video generiert werden soll, standardmäßig false.
- `timeout`: Optional, Anzahl der Sekunden bis zum Timeout.
- `callback_url`: Adresse für asynchrone Rückrufe.
- `async`: Optional, wenn auf `true` gesetzt, gibt die Schnittstelle sofort `task_id` zurück, ohne dass `callback_url` bereitgestellt werden muss; anschließend wird das Ergebnis durch Abfragen der entsprechenden Aufgabenschnittstelle per Polling abgerufen.

Sie können auf die Schaltfläche „Try“ klicken, um die API direkt zu testen. Warten Sie 1–2 Minuten, das Ergebnis lautet wie folgt:

```json

  "task_id": "e4018a99-1522-4f24-9330-62c2a9b50b59",

  "prompt": "Astronauts shuttle from space to volcano",
  "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "video_height": 752,
  "video_width": 1360,
  "state": "completed",
  "thumbnail_url": "https://platform.cdn.acedata.cloud/luma/e4018a99-1522-4f24-9330-62c2a9b50b59.jpg",
  "thumbnail_width": 1360,
  "thumbnail_height": 752
}
```

Sie können sehen, dass wir zu diesem Zeitpunkt die relevanten Informationen zu diesem Video erhalten haben, einschließlich Video-ID, Videolink, Videovorschaubild und anderen Inhalten.

Die Feldbeschreibungen lauten wie folgt:

- success: Ob die Generierung erfolgreich war; bei Erfolg ist der Wert `true`, andernfalls `false`
- task_id: Die eindeutige ID der Videogenerierungsaufgabe hier
- video_id: Die eindeutige ID des durch diese Videogenerierungsaufgabe erzeugten Videos
- prompt: Die Schlüsselwörter dieser Videogenerierungsaufgabe
- video_url: Der Ergebnis-Videolink dieser Videogenerierungsaufgabe
- video_height: Die Höhe des nach der Generierung erstellten Videovorschaubildes
- video_width: Die Breite des nach der Generierung erstellten Videovorschaubildes
- state: Der Status dieser Videogenerierungsaufgabe; wenn die Aufgabe abgeschlossen ist, lautet er `completed`.
- thumbnail_url: Der Link zum nach der Generierung erstellten Videovorschaubild
- thumbnail_width: Die Breite des nach der Generierung erstellten Videovorschaubildes
- thumbnail_height: Die Höhe des nach der Generierung erstellten Videovorschaubildes

## Generierung mit benutzerdefinierten Start- und Endbildern

Wenn Sie ein Video über benutzerdefinierte Start- und Endbilder des Videos generieren möchten, können Sie die Bildlinks für Start- und Endbild eingeben:

Zu diesem Zeitpunkt kann das Feld `start_image_url` für das erste Bild des Videos das folgende Bild als erstes Bild des Videos übergeben:

![Startbild](https://cdn.acedata.cloud/r9vsv9.png)

Als Nächstes möchten wir anhand der Start- und Endbilder sowie der Schlüsselwörter ein Video benutzerdefiniert generieren und können dazu die folgenden Inhalte angeben:

- action: Das Verhalten der Videogenerierungsaufgabe, normalerweise die reguläre Generierung `generate` und die erweiterte Generierung `extend`, standardmäßig `generate`.
- start_image_url: Gibt das erste Bild des generierten Videos an.
- end_image_url: Gibt das Endbild des generierten Videos an.
- prompt: Der Inhalt der Schlüsselwörter für die Videogenerierung.

Ein Ausfüllbeispiel lautet wie folgt:

<p><img src="https://cdn.acedata.cloud/zvzydx.png" width="500" className="m-auto" /></p>

Nach dem Ausfüllen wird der folgende Code automatisch generiert:

<p><img src="https://cdn.acedata.cloud/tx80pu.png" width="500" className="m-auto" /></p>

Der entsprechende Code:

```python
import requests

url = "https://api.acedata.cloud/luma/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "start_image_url": "https://cdn.acedata.cloud/r9vsv9.png",
    "action": "generate",
    "prompt": "Astronauts shuttle from space to volcano"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Das erhaltene Ergebnis lautet wie folgt:

## Videoerweiterungsfunktion

Wenn das generierte Video weiter generiert werden soll, kann der Parameter `action` auf `extend` gesetzt werden, und die ID oder der Videolink des Videos, das weiter generiert werden soll, muss eingegeben werden. Die Video-ID und der Videolink werden gemäß der grundlegenden Verwendung abgerufen, wie in der folgenden Abbildung gezeigt:

<p><img src="https://cdn.acedata.cloud/fwknj4.png" width="500" className="m-auto" /></p>

Zu diesem Zeitpunkt ist die Video-ID sichtbar als:

```
"video_id": "0105c090-03a5-425a-8026-523341cd575b",
"video_url": "https://platform.cdn.acedata.cloud/luma/12a18694-fd4b-47e7-9c50-34f30862cff6.mp4"
```

> Hinweis: Das `video_id` und `video_url` des Videos hier sind die ID und der Videolink des nach der Generierung erstellten Videos. Wenn Sie nicht wissen, wie man ein Video generiert, können Sie sich auf die grundlegende Verwendung oben beziehen, um ein Video zu generieren.

Um ein Video weiter zu generieren, muss ein Videolink oder die ID des Videos hochgeladen werden. Im Folgenden wird die Verwendung der Video-ID zur Erweiterung demonstriert. Als Nächstes müssen wir Schlüsselwörter eingeben, um das generierte Video anzupassen, und können den folgenden Inhalt angeben:

- action: Das Verhalten zum Erweitern des Videos, hier sollte es `extend` sein.
- prompt: Die Schlüsselwörter für das zu erweiternde Video.
- video_url: Der Link des Videos, das erweitert generiert werden soll.
- video_id: Die eindeutige ID des Videos, das erweitert generiert werden soll.
- end_image_url: Beim erweitert generierten Video kann ein Bildlink für den letzten Frame angegeben werden, optionaler Parameter.

Das Ausfüllbeispiel lautet wie folgt:

import requests

## Asynchroner Rückruf

Da die Zeit für Luma zur Videogenerierung relativ lang ist und etwa 1–2 Minuten benötigt, bleibt die HTTP-Anfrage verbunden, wenn die API lange Zeit nicht reagiert, was zu zusätzlichem Verbrauch von Systemressourcen führt. Daher bietet diese API auch Unterstützung für asynchrone Rückrufe.
Der gesamte Ablauf ist: Wenn der Client eine Anfrage initiiert, gibt er zusätzlich ein Feld `callback_url` an. Nachdem der Client eine API-Anfrage initiiert hat, gibt die API sofort ein Ergebnis zurück, das die Feldinformation `task_id` enthält, welche die aktuelle Aufgaben-ID repräsentiert. Wenn die Aufgabe abgeschlossen ist, wird das Ergebnis der Musikgenerierung in Form von POST JSON an die vom Client angegebene `callback_url` gesendet, die ebenfalls das Feld `task_id` enthält, sodass das Aufgabenergebnis über die ID zugeordnet werden kann.

Im Folgenden erfahren wir anhand eines Beispiels, wie genau dies funktioniert.

Zunächst ist der Webhook-Rückruf ein Dienst, der HTTP-Anfragen empfangen kann. Entwickler sollten ihn durch die URL ihres selbst eingerichteten HTTP-Servers ersetzen. Zur Vereinfachung der Demonstration wird hier eine öffentliche Webhook-Beispielwebsite https://webhook.site/ verwendet. Beim Öffnen dieser Website kann eine Webhook-URL abgerufen werden, wie in der Abbildung gezeigt:

Kopieren Sie diese URL, dann kann sie als Webhook verwendet werden. Das Beispiel hier ist https://webhook.site/0c87ca0e-cd74-4577-8d68-f2b80fbf8a13.
