Diese Schnittstelle basiert auf der [offiziellen Fish Audio Model API](https://docs.fish.audio/resources/api-reference/model) und wird verwendet, um **auf Grundlage eines Audiobeispiels ein langfristig wiederverwendbares geklontes Stimmenmodell zu erstellen**. Die Adresse lautet `POST https://api.acedata.cloud/fish/model`.

> Wenn eine Referenzstimme nur vorübergehend verwendet werden soll, muss kein Modell erstellt werden; stattdessen kann das einmalige sofortige Klonen über `references` der [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) direkt verwendet werden. Informationen zum paginierten Abrufen vorhandener Stimmen finden Sie in der [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query); Informationen zum Abrufen von Details einer einzelnen Stimme anhand von `_id` finden Sie in der [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Antragsprozess

Um die Fish Model API zu verwenden, rufen Sie zunächst Ihr API-Token in der [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications) ab und bewahren Sie es zur späteren Verwendung auf.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Falls Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden; nach Abschluss kehren Sie automatisch zur aktuellen Seite zurück.

**Ein API-Token kann alle Dienste der Plattform aufrufen; es ist nicht erforderlich, für jeden Dienst einen separaten Antrag zu stellen.** Bei der ersten Beantragung wird ein kostenloses Kontingent vergeben, das kostenlos getestet werden kann; bei unzureichendem Kontingent kann ein allgemeines Guthaben in der [Konsole](https://platform.acedata.cloud/console/coin) aufgeladen werden.

> 📘 Vollständige Dokumentation: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Felder des Request-Bodys

| Feld                      | Typ       | Erforderlich  | Beschreibung                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | Ja   | Name der Stimme, zur Identifizierung in der Konsolenliste.                                                             |
| `voices`                | string   | Ja   | HTTP(S)-URL des Audiobeispiels (**ein einzelner String**, kein Array). Diese Schnittstelle unterstützt kein multipart-/Binär-Upload; legen Sie das Audio bitte zunächst in einem beliebigen öffentlich zugänglichen Objektspeicher ab. |
| `description`           | string   | Nein   | Beschreibung der Stimme.                                                                         |
| `cover_image`           | string   | Nein   | HTTP(S)-URL des Titelbilds.                                                              |
| `tags`                  | string[] | Nein   | Such-Tags für die öffentliche Bibliothek, beispielsweise `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | Nein   | Referenztexte, die den Beispielen entsprechen (zur Korrektur der Aussprache).                                                           |
| `enhance_audio_quality` | boolean  | Nein   | Ob vor dem Training eine Verbesserung der Audioqualität für das Beispiel durchgeführt werden soll.                                                                |
| `generate_sample`       | boolean  | Nein   | Ob nach Abschluss des Trainings automatisch ein Beispielaudio erstellt werden soll.                                                            |

> Weitere Informationen zum Stimmenmodell finden Sie in der [offiziellen Fish-Dokumentation](https://docs.fish.audio/resources/api-reference/model).

> Die erstellten Stimmen werden langfristig öffentlich gespeichert und können von anderen Benutzern gesucht und verwendet werden. `visibility` muss nicht übergeben werden; selbst wenn `private` oder `unlist` übergeben wird, ändert die aktuelle Schnittstelle den öffentlichen Bereich dadurch nicht.

## Beispiel: Eine öffentliche geklonte Stimme erstellen

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的中文音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Hinweis: `voices` muss ein **String** (eine einzelne Audio-URL) und kein Array sein. Die Übergabe von `["..."]` wird nicht unterstützt. Es wird empfohlen, einen direkt herunterladbaren öffentlichen Link mit der Endung `.mp3` oder `.wav` zu verwenden.

Bei Erfolg wird direkt ein ModelEntity-Objekt der Fish-Plattform zurückgegeben (das folgende Beispiel zeigt die kleinste von uns getestete funktionsfähige Stimme; einige lange Felder wurden zur besseren Lesbarkeit entfernt):

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，这是一段使用我刚创建的克隆音色合成的语音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Anforderungen an die Probe

Referenzempfehlungen (siehe [offizielle Fish-Dokumentation](https://docs.fish.audio/resources/api-reference/model)):

- Empfohlene Dauer: mindestens 30 Sekunden; optimale Ergebnisse innerhalb von 5 Minuten. Über 10 Minuten hinaus ist der zusätzliche Nutzen gering.
- Abtastrate von 16 kHz oder höher; Mono oder Stereo sind beide möglich.
- Der Inhalt sollte möglichst sauber sein: keine Hintergrundmusik, kein Echo, keine deutlichen Umgebungsgeräusche; derselbe Sprecher.
- Empfohlene Formate: `mp3` / `wav`.

Wenn Sie sich bezüglich der Probenqualität unsicher sind, können Sie gleichzeitig `enhance_audio_quality: true` übermitteln, um die Klangverbesserung zu aktivieren.

## Abrechnungshinweise
Das Erstellen eines Stimmklonmodells (`POST /fish/model`) ist kostenlos und es fallen keine Gebühren an; auch die Abfrageschnittstellen für Stimmen ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query), [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) sind kostenlos. Kosten entstehen nur bei der anschließenden Nutzung von [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) zur Sprachsynthese nach Verbrauch.

## Fehlerbehandlung

- `400 token_mismatched`: Anforderungsparameter fehlen oder sind ungültig (am häufigsten ist `voices` keine URL oder wurde als Array übergeben).
- `400`: Wenn die Referenz-Audiodatei nicht heruntergeladen werden kann, zu kurz ist oder das Format nicht erkannt werden kann, überprüfen Sie bitte die Audio-URL und das Dateiformat.
- `401 invalid_token`: Das Authentifizierungs-Token existiert nicht oder ist ungültig.
- `429 too_many_requests`: Das Ratenlimit des Kontos wurde ausgelöst.
- `500 api_error`: Interner Serverfehler.

Beispiel für eine Fehlerantwort:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Fazit

Für den Aufruf dieser Schnittstelle müssen Sie nur eine öffentlich zugängliche Beispiel-Audio-URL vorbereiten und sie in das Feld `voices` einfügen, um die `_id` zu erhalten. Anschließend übergeben Sie sie an `reference_id` von `/fish/tts`, womit der vollständige Ablauf „Klonen → Synthese“ abgeschlossen ist. Ein häufiger Fehlerpunkt ist, dass `voices` ein String sein muss und kein Array sein darf.

## Stimme über MCP erstellen und wiederverwenden

Rufen Sie in Fish MCP
`fish_create_model(title="Meine Stimme", voices="https://example.com/authorized-voice.wav")` auf.
`voices` ist eine einzelne HTTP(S)-Audio-URL; außerdem können `description`, `cover_image`, `tags`,
`texts`, `enhance_audio_quality` und `generate_sample` übergeben werden.

Dieses Tool speichert öffentliche Stimmen langfristig, und andere Benutzer können sie möglicherweise entdecken und verwenden; verwenden Sie bitte nur Audiomaterial, dessen Verarbeitung und Veröffentlichung genehmigt ist. Das Tool verfügt über keine private oder nicht öffentliche Option. Die bei erfolgreicher Erstellung zurückgegebene `_id` wird für
`reference_id` von `fish_generate_audio` verwendet, und mit `fish_list_models(self=true)` können Sie Ihre
gespeicherten Stimmen abfragen. Wenn Sie eine Referenzstimme nur einmalig benötigen, verwenden Sie `references` von `fish_generate_audio`,
ohne eine langfristige Stimme zu erstellen.
