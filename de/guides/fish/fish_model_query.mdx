Diese Schnittstelle basiert auf der [Fish Audio offiziellen Model API](https://docs.fish.audio/resources/api-reference/model) und dient zur **seitengerechten Abfrage des öffentlichen Klangarchivs von Fish oder der Klonklänge des aktuellen Kontos**. Die Adresse lautet `GET https://api.acedata.cloud/fish/model`.

> Für die Erstellung von Klängen siehe bitte die [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); für die Abfrage von Einzelklangdetails nach `_id` siehe bitte die [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Antragsprozess

Um die Fish Model API zu nutzen, müssen Sie zunächst im [Ace Data Cloud Dashboard](https://platform.acedata.cloud/console/applications) Ihr API-Token abrufen und für zukünftige Verwendung aufbewahren.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach Abschluss werden Sie automatisch zur aktuellen Seite zurückgeleitet.

**Ein API-Token reicht aus, um alle Dienste der Plattform zu nutzen, es ist nicht erforderlich, für jeden Dienst separat zu beantragen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Kontingent, um es kostenlos auszuprobieren; wenn das Kontingent nicht ausreicht, können Sie im [Dashboard](https://platform.acedata.cloud/console/coin) Ihr Guthaben aufladen.

> 📘 Vollständige Dokumentation: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Abfrageparameter

| Parameter          | Typ      | Standard | Beschreibung                               |
| ------------------ | ------- | -------- | ----------------------------------------- |
| `page_size`        | integer | 10       | Anzahl der Einträge pro Seite.            |
| `page_number`      | integer | 1        | Seitenzahl, beginnend bei 1.              |
| `title`            | string  | —        | Unscharfe Suche nach Titel.               |
| `tag`              | string  | —        | Filterung nach einem einzelnen Tag.       |
| `self`             | boolean | —        | Bei `true` werden nur Klänge zurückgegeben, die vom aktuellen Konto erstellt wurden, ohne zusätzliche Bedingungen. |
| `author_id`        | string  | —        | Filterung nach dem `_id` des übergeordneten Benutzers. |
| `language`         | string  | —        | Filterung nach Sprachtyp, z. B. `en`, `zh`, `es`. |
| `title_language`   | string  | —        | Filterung nach der Sprache des Titels.    |
| `sort_by`          | string  | —        | Sortierfeld, identisch mit dem übergeordneten, z. B. `created_at`, `task_count`. |

> Die Parameterbenennung entspricht genau der des übergeordneten `GET https://api.fish.audio/model`, siehe [Fish offizielle Dokumentation](https://docs.fish.audio/resources/api-reference/model).

## Beispiel 1: Standardseitennavigation (nach `page_size`)

## Beispiel 2: Unscharfe Suche nach Titel (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Rückgabe (gemessen):

```json
{
  "total": 161,
  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",
      "type": "tts",
      "title": "Miles Morales (Narration Paw)",
      "tags": ["male", "middle-aged", "entertainment", "storytelling", "Children's Content"],
      "languages": ["en"],
      "visibility": "public",
      "task_count": 770
    },
    {
      "_id": "76b55591c758444cb95253708696dfad",
      "type": "tts",
      "title": "Joe NARRATION",
      "tags": ["male", "middle-aged", "narration", "deep", "raspy"],
      "languages": ["en"],
      "visibility": "public"
    }

  "has_more": null

```

Beachten Sie, dass `title` eine „globale unscharfe Übereinstimmung“ ist, die alle Klänge im öffentlichen Archiv von Fish erfasst (nicht nur die eigenen).

## Beispiel 3: Nur eigene erstellte Klänge auflisten (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Rückgabe (gemessen, im aktuellen Konto gibt es nur 1 Klang):

```json
{
  "total": 1,
  "items": [
    {
      "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
      "type": "tts",

      "description": "Smoke-Test von api.acedata.cloud",
      "state": "trained",
      "languages": ["zh"],
```

## Beispiel 4: Filterung nach Sprache + Tag
```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> Der Upstream gibt auch Ergebnisse für `tag` zurück, die nicht im Tag-Wörterbuch enthalten sind, aber die Übereinstimmung ist relativ locker; wenn die Trefferzahl 0 beträgt, wird empfohlen, eine unscharfe Übereinstimmung mit `title` zu verwenden.

## Antwortfelder

Jeder Eintrag in `items[]` ist ein vollständiges ModelEntity-Objekt, häufig verwendete Felder:

| Feld            | Typ       | Beschreibung                                          |
| ------------- | -------- | ------------------------------------------------- |
| `_id`         | string   | Stimm-ID, die als Wert für `reference_id` in `/fish/tts` dient.         |
| `type`        | string   | Modelltyp, normalerweise `tts`.                                   |
| `title`       | string   | Stimmname.                                             |
| `description` | string   | Stimmbeschreibung.                                     |
| `state`       | string   | Trainingsstatus: `trained` bedeutet verfügbar.                              |
| `tags`        | string[] | Tags aus der öffentlichen Bibliothek.                    |
| `languages`   | string[] | Sprachen, in denen die Stimme spezialisiert ist.          |
| `visibility`  | string   | `public` oder `private`.                             |
| `samples`     | object[] | Voreingestellte Samples (einschließlich `audio` Direktlink).               |
| `like_count`  | integer  | Anzahl der Likes in der öffentlichen Bibliothek.         |
| `task_count`  | integer  | Anzahl der historischen Synthesen.                       |
| `author`      | object   | Informationen zum Upstream-Autor: `_id` / `nickname` / `avatar`.         |
| `total`（oberste Ebene）   | integer  | Gesamtanzahl der erfüllenden Bedingungen.                     |
| `has_more`    | boolean? | Paging-Indikator des Upstreams, kann `null` sein. Es wird empfohlen, `total / page_size` zur Berechnung der Gesamtseitenanzahl zu verwenden. |

## Abrechnungsinformationen

Diese Schnittstelle ist kostenlos – die Abfrage der Stimmliste ist eine kostenlose Operation. Die Erstellung von Stimmen ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) ist ebenfalls kostenlos, Kosten entstehen nur bei der Verwendung von [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) zur Sprachsynthese.

## Fehlerbehandlung

- `400 token_mismatched`: Fehlende oder ungültige Anforderungsparameter.
- `401 invalid_token`: Authentifizierungstoken existiert nicht oder ist ungültig.
- `429 too_many_requests`: Konto-Rate-Limit überschritten.
- `500 api_error`: Interner Serverfehler.

Beispiel für eine Fehlerantwort:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Fazit

Um eine Stimme aus der öffentlichen Bibliothek von Fish für das `reference_id` von `/fish/tts` auszuwählen, verwenden Sie zuerst diese Schnittstelle in Kombination mit `title` / `tag` / `language`, um die Ziel-_id zu lokalisieren, und verwenden Sie dann [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get), um Samples zum Anhören zu erhalten. Um die von Ihnen erstellten Stimmen aufzulisten, übergeben Sie einfach `self=true`.
