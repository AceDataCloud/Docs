Diese Schnittstelle basiert auf der offiziellen [Fish Audio Model API](https://docs.fish.audio/resources/api-reference/model) und wird verwendet, um **die öffentliche Fish-Stimmbibliothek oder die unter dem aktuellen Konto geklonten Stimmen paginiert abzurufen**. Die Adresse lautet `GET https://api.acedata.cloud/fish/model`.

> Informationen zum Erstellen von Stimmen finden Sie unter [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); Informationen zum Abrufen der Details einer einzelnen Stimme anhand von `_id` finden Sie unter [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Antragsprozess

Um die Fish Model API zu verwenden, rufen Sie zunächst in der [Ace Data Cloud-Konsole](https://platform.acedata.cloud/console/applications) Ihren API-Token ab und bewahren Sie ihn als Reserve auf.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Falls Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet, um sich zu registrieren und anzumelden. Nach Abschluss kehren Sie automatisch zur aktuellen Seite zurück.

**Ein API-Token kann alle Dienste der Plattform aufrufen; es ist nicht erforderlich, ihn für jeden Dienst separat zu beantragen.** Bei der ersten Beantragung erhalten Sie ein kostenloses Guthaben, das Sie kostenlos ausprobieren können; bei unzureichendem Guthaben können Sie in der [Konsole](https://platform.acedata.cloud/console/coin) allgemeines Guthaben aufladen.

> 📘 Vollständige Dokumentation: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Abfrageparameter

| Parameter               | Typ      | Standard  | Beschreibung                                              |
| ---------------- | ------- | --- | ----------------------------------------------- |
| `page_size`      | integer | 10  | Anzahl der Einträge pro Seite.                                           |
| `page_number`    | integer | 1   | Seitennummer, beginnend bei 1.                                         |
| `title`          | string  | —   | Unscharfe Suche nach Titel.                                        |
| `tag`            | string  | —   | Nach einem einzelnen Tag filtern.                                        |
| `self`           | boolean | —   | Bei `true` werden nur Stimmen zurückgegeben, die vom aktuellen aufrufenden Konto über diese Plattform erstellt und gespeichert wurden.                 |
| `author_id`      | string  | —   | Nach der ID des Stimmenautors filtern.                                    |
| `language`       | string  | —   | Nach der Sprache der Stimme filtern, z. B. `en`, `zh`, `es`.                       |
| `title_language` | string  | —   | In der öffentlichen Stimmbibliothek nach der Titelsprache filtern.                                 |
| `sort_by`        | string  | —   | Sortierfeld; bei `self=true` werden `created_at`, `task_count` unterstützt. |

> Die Parameternamen stimmen vollständig mit dem Upstream-`GET https://api.fish.audio/model` überein. Details finden Sie in der [offiziellen Fish-Dokumentation](https://docs.fish.audio/resources/api-reference/model).

## Beispiel 1: Standard-Paginierung (nach `page_size`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=2'
```

## Beispiel 2: Unscharfe Suche nach Titel (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Rückgabe (getestet):


## Beispiel 3: Nur selbst erstellte Stimmen auflisten (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Rückgabebeispiel:

```json
{
  "total": 1,
  "items": [
    {
      "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
      "type": "tts",
      "title": "copilot-smoke-test",
      "description": "smoke test from api.acedata.cloud",
      "state": "trained",
      "languages": ["zh"],
      "visibility": "public",
      "samples": [
        {
          "title": "Default Sample",
          "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
          "task_id": "6a1bf398dfae49dca0e23159214342a0",
          "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
        }
      ],
      "created_at": "2026-05-10T03:52:55.601000Z",
      "author": {
        "_id": "780f2b2f862d41a08c0507bbbda77eb6",
        "nickname": "Penny Conrad"
      }
    }
  ],
  "has_more": false
}
```
`self=true` listet die über diese Plattform erstellten und gespeicherten Stimmen nach dem tatsächlich aufrufenden Konto auf; Stimmen, die von demselben Konto mit unterschiedlichen API-Tokens erstellt wurden, werden ebenfalls gemeinsam aufgelistet. Die Ergebnisse werden paginiert in absteigender Reihenfolge nach Erstellungszeit sortiert; `author_id` kann diese Stimmen weiter nach der Autoren-ID filtern. Dieser Parameter filtert nur die Liste, die Stimmen bleiben weiterhin öffentlich verfügbar.

`self=true` unterstützt `title_language` nicht; wenn Sie nach der Titelsprache suchen müssen, fragen Sie bitte die öffentliche Stimmenbibliothek ab.

## Beispiel 4: Filtern nach Sprache + Tag

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> Der Upstream gibt auch für `tag`, die nicht im Tag-Wörterbuch enthalten sind, Ergebnisse zurück, aber die Übereinstimmung ist relativ locker; wenn die Anzahl der Treffer 0 beträgt, wird empfohlen, stattdessen eine unscharfe Übereinstimmung mit `title` zu verwenden.

## Antwortfelder

Jeder Eintrag in `items[]` ist ein vollständiges ModelEntity-Objekt, häufig verwendete Felder:

| Feld            | Typ       | Beschreibung                                        |
| ------------- | -------- | ----------------------------------------- |
| `_id`         | string   | Stimmen-ID, als Wert von `reference_id` in `/fish/tts`. |
| `type`        | string   | Modelltyp, normalerweise `tts`.                           |
| `title`       | string   | Stimmenname.                                     |
| `description` | string   | Stimmenbeschreibung.                                     |
| `state`       | string   | Trainingsstatus: `trained` bedeutet verfügbar.                      |
| `tags`        | string[] | Tags der öffentlichen Bibliothek.                                    |
| `languages`   | string[] | Sprachen, für die die Stimme besonders geeignet ist.                                  |
| `visibility`  | string   | `public` oder `private`.                     |
| `samples`     | object[] | Voreingestellte Samples (einschließlich direkter `audio`-Links).                       |
| `like_count`  | integer  | Anzahl der Likes in der öffentlichen Bibliothek.                                   |
| `task_count`  | integer  | Anzahl der bisherigen Synthesen.                                   |
| `author`      | object   | Informationen zum Stimmenautor: `_id` / `nickname` / `avatar`.     |
| `total`（oberste Ebene）   | integer  | Gesamtzahl der Einträge, die die Bedingungen erfüllen.                                 |
| `has_more`    | boolean? | Bei `self=true` ein boolescher Wert; Abfragen der öffentlichen Stimmenbibliothek können `null` sein.      |

## Abrechnungshinweise

Für diese Schnittstelle fallen keine Gebühren an — die paginierte Abfrage der Stimmenliste ist kostenlos. Das Erstellen von Stimmen ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) ist ebenfalls kostenlos; Kosten entstehen nur nutzungsabhängig bei der Sprachsynthese über [Fish TTS](https://platform.acedata.cloud/documents/fish-tts).

## Fehlerbehandlung

- `400 token_mismatched`: Anfrageparameter fehlen oder sind ungültig.
- `401 invalid_token`: Das Authentifizierungs-Token existiert nicht oder ist ungültig.
- `429 too_many_requests`: Das Ratenlimit des Kontos wurde ausgelöst.
- `500 api_error`: Interner Serverfehler.

Beispiel für eine Fehlerantwort:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Fazit

Um aus der öffentlichen Fish-Bibliothek eine Stimme auszuwählen und sie an `reference_id` von `/fish/tts` zu übergeben, suchen Sie zunächst mit dieser Schnittstelle in Kombination mit `title` / `tag` / `language`, ermitteln die Ziel-`_id` und verwenden dann [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get), um Samples zum Probehören abzurufen. Um selbst erstellte Stimmen aufzulisten, übergeben Sie einfach `self=true`.
