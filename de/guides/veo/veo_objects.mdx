Dieser Artikel beschreibt die Integrationsanleitung für die Veo Objects API. Diese Schnittstelle wird verwendet, um **Objekte hinzuzufügen oder zu entfernen** (basierend auf maskenbasierter Teilneuzeichnung) in einem bereits generierten Veo-Video.

## Antragsprozess

Um die API zu nutzen, müssen Sie zunächst auf die entsprechende Seite des Veo-Dienstes gehen und einen Antrag stellen. Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet.

## Grundlegende Nutzung

Um diese Schnittstelle aufzurufen, müssen die folgenden Parameter übergeben werden:

- `video_id` (erforderlich): Die Aufgaben-ID des Quellvideos. **Darf nicht** das Ausgabevideo von `/veo/extend` sein.
- `action` (erforderlich): Art der Operation, `insert` oder `remove`.
- `prompt`:
  - `action=insert`: **Erforderlich**, Beschreibung des hinzuzufügenden Objekts.
  - `action=remove`: Optional, Beschreibung des zu entfernenden Inhalts (hauptsächlich zur Protokollierung, der tatsächliche Löschbereich wird durch `image_mask` bestimmt).
- `image_mask`:
  - `action=insert`: Optional. Wenn nicht übergeben, entscheidet die KI automatisch über den Einfügeort; wenn übergeben, wird im Bereich der weißen Pixel eingefügt.
  - `action=remove`: **Erforderlich**, der Bereich der weißen Pixel ist das zu löschende Objekt.

`image_mask` akzeptiert zwei Formate:

1. Eine **öffentlich zugängliche HTTP(S) Bildadresse** (empfohlen).
2. **base64-kodierter JPEG-String**, der mit dem Präfix `data:image/jpeg;base64,` oder als reines base64 übergeben werden kann.

Beispielanfrage (Objekt einfügen, ohne Maske, damit die KI automatisch positioniert):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "insert",
    "prompt": "add a flying pig with black wings"
  }'
```

Beispielanfrage (Objekt gemäß Maske entfernen):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "remove",
    "image_mask": "https://example.com/mask.jpg",
    "prompt": "remove the white cloud"
  }'
```

Die Struktur der Rückgabewerte ist identisch mit der von `/veo/videos`.

## Abrechnungsinformationen

- `action=insert` oder `remove`: 1,50 Credit / Vorgang.

## Asynchrone Rückrufe

Die Schnittstelle unterstützt den asynchronen Modus. Geben Sie `callback_url` an, um das Ergebnis nach Abschluss der Aufgabe über einen POST-Rückruf zu erhalten. Wenn keine öffentliche Rückrufadresse vorhanden ist, können Sie auch `async` auf `true` setzen, die Schnittstelle gibt ebenfalls sofort `task_id` zurück, und Sie können das Ergebnis anschließend über die entsprechende Aufgabenabfrage-Schnittstelle abfragen.
