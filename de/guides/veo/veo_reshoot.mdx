Dieser Artikel beschreibt die Integrationsanleitung für die Veo Reshoot API. Diese Schnittstelle wird verwendet, um ein bereits generiertes Veo-Video gemäß einer **neuen Kamerabewegungsart neu zu generieren**, wobei der Inhalt des Bildes gleich bleibt, aber die Kameraposition und -bewegung gemäß `motion_type` neu interpretiert werden.

## Antragsprozess

Um die API zu nutzen, müssen Sie zunächst auf die entsprechende Seite des Veo-Dienstes gehen und einen Antrag stellen. Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet.

## Grundlegende Nutzung

Um diese Schnittstelle aufzurufen, müssen die folgenden Parameter übergeben werden:

- `video_id` (erforderlich): Die Aufgaben-ID des Quellvideos. **Darf nicht** das Ausgabevideo von `/veo/extend` sein.
- `motion_type` (erforderlich): Die neue Kamerabewegungsart, die in einem prägnanten Alias im Großbuchstaben-Unterstrich-Stil angegeben wird.

### Unterstützte Werte für `motion_type`

| Alias                             | Bedeutung           |
| ------------------------------ | ------------ |
| `STATIONARY`                   | Kamera bleibt stationär       |
| `STATIONARY_UP`                | Kamera bleibt stationär, nach oben neigen    |
| `STATIONARY_DOWN`              | Kamera bleibt stationär, nach unten neigen    |
| `STATIONARY_LEFT`              | Kamera bleibt stationär, nach links schwenken      |
| `STATIONARY_RIGHT`             | Kamera bleibt stationär, nach rechts schwenken      |
| `STATIONARY_DOLLY_IN_ZOOM_OUT` | Kamera bleibt stationär, vorwärts schieben + Fokus ziehen |
| `STATIONARY_DOLLY_OUT_ZOOM_IN` | Kamera bleibt stationär, rückwärts schieben + Fokus ziehen |
| `UP`                           | Kamera steigt         |
| `DOWN`                         | Kamera sinkt         |
| `LEFT_TO_RIGHT`                | Kamera bewegt sich von links nach rechts     |
| `RIGHT_TO_LEFT`                | Kamera bewegt sich von rechts nach links     |
| `FORWARD`                      | Kamera bewegt sich vorwärts       |
| `BACKWARD`                     | Kamera bewegt sich rückwärts        |
| `DOLLY_IN_ZOOM_OUT`            | Während der Bewegung vorwärts schieben + Fokus ziehen   |
| `DOLLY_OUT_ZOOM_IN`            | Während der Bewegung rückwärts schieben + Fokus ziehen   |

Beispielanfrage:

```shell
curl -X POST 'https://api.acedata.cloud/veo/reshoot' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "motion_type": "LEFT_TO_RIGHT"
  }'
```

Die Struktur der Rückgabeergebnisse ist identisch mit der von `/veo/videos`.

## Abrechnungsinformationen

- Einmalige Neudrehung: 1,20 Credit.

## Asynchrone Rückrufe

Die Schnittstelle unterstützt den asynchronen Modus. Geben Sie `callback_url` an, um nach Abschluss der Aufgabe das Ergebnis über eine POST-Anfrage zurückzurufen. Wenn keine öffentliche Rückrufadresse vorhanden ist, können Sie auch `async` auf `true` setzen, die Schnittstelle gibt ebenfalls sofort `task_id` zurück, und Sie können das Ergebnis anschließend über die entsprechende Aufgabenabfrageschnittstelle abfragen.
