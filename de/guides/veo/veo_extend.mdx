Dieser Artikel beschreibt die Integrationsanleitung für die Veo Extend API. Diese Schnittstelle wird verwendet, um die **Dauer eines bereits generierten Veo-Videos zu verlängern**, wobei die KI automatisch die nachfolgenden Szenen fortschreibt.

## Antragsprozess

Um die API zu nutzen, müssen Sie zunächst auf die entsprechende Seite des Veo-Dienstes gehen und einen Antrag stellen. Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet.

## Grundlegende Nutzung

Um diese Schnittstelle aufzurufen, müssen die folgenden Parameter übergeben werden:

- `video_id` (erforderlich): Die Aufgaben-ID des Quellvideos (stammt von `/veo/videos` oder dieser Schnittstelle selbst).
- `model` (erforderlich): Das Modell, das für die Verlängerung verwendet wird, **unterstützt nur die Modelle `veo31-fast` und `veo31`**, andere Modelle werden nicht unterstützt.
- `prompt` (optional): Textliche Hinweise zur Anleitung der erweiterten Szenen.
- `aspect_ratio` (optional): `16:9` oder `9:16`, standardmäßig `16:9`.
- `resolution` (optional): `720p` oder `1080p`.

Beispielanfrage:

```shell
curl -X POST 'https://api.acedata.cloud/veo/extend' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "model": "veo31-fast",
    "prompt": "die Kamera zoomt langsam heraus, um mehr von der Landschaft zu zeigen"
  }'
```

Die Rückgabe ist identisch mit der von `/veo/videos`:

```json
{
  "success": true,
  "task_id": "5fa2d9a6-7e54-481b-a4b0-3dc6f25dd2ab",
  "data": [
    {
      "id": "9b6f3b6b9c45419fbf2e3fe2f10b2b3a",
      "video_url": "https://platform.cdn.acedata.cloud/veo/5fa2d9a6.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

## Wichtige Einschränkungen

`video_id` muss von der aktuellen `/veo/videos`-Linie stammen, die generiert oder nach der Verlängerung abgeschlossen wurde `data[].id`. Ältere Video-IDs aus historischen Linien können nicht für diese Schnittstelle verwendet werden, bei Aufruf wird `400 bad_request` zurückgegeben; bitte generieren Sie es erneut über `/veo/videos`, bevor Sie es verlängern.

Videos, die aus `/veo/extend` stammen, können **weiterhin über `/veo/extend` erneut verlängert werden**, dürfen jedoch **nicht** von den folgenden Schnittstellen verarbeitet werden:

- `/veo/reshoot` — Kamerabewegungen können nicht geändert werden
- `/veo/objects` — Objekte können nicht hinzugefügt oder entfernt werden

Wenn die übergebene `video_id` das Ergebnis einer Verlängerung ist, geben die entsprechenden Schnittstellen einen 400-Fehler zurück, bitte verwenden Sie das Originalvideo als Quelle.

## Abrechnungsinformationen

- `model=veo31-fast`: 1,68 Credit / Anfrage
- `model=veo31`: 12,00 Credit / Anfrage

## Asynchrone Rückrufe

Die Schnittstelle unterstützt den asynchronen Modus, indem Sie `callback_url` übergeben, um das Ergebnis nach Abschluss der Aufgabe per POST-Anfrage zurückzurufen. Wenn keine öffentliche Rückrufadresse vorhanden ist, können Sie auch `async` auf `true` setzen, die Schnittstelle gibt ebenfalls sofort `task_id` zurück, und Sie können die Ergebnisse anschließend über die entsprechende Aufgabenabfrageschnittstelle abfragen.
