Dieser Artikel beschreibt die Integrationsanleitung für die Veo Upsample API. Diese Schnittstelle wird verwendet, um ein bereits generiertes Veo-Video hochzuskalieren oder eine GIF-Vorschau auszugeben.

## Antragsprozess

Um die API zu nutzen, müssen Sie zunächst auf die entsprechende Seite des Veo-Dienstes gehen und einen Antrag stellen. Wenn Sie noch nicht angemeldet oder registriert sind, werden Sie automatisch zur Anmeldeseite weitergeleitet.

## Grundlegende Nutzung

Um diese Schnittstelle aufzurufen, müssen zwei Parameter übergeben werden:

- `video_id`: Die Aufgaben-ID des Quellvideos. Dies kann die Video-ID von beliebigen Schnittstellen wie `/veo/videos`, `/veo/extend`, `/veo/reshoot`, `/veo/objects` sein.
- `action`: Die Hochskalierungsaktion, die die folgenden drei Optionen unterstützt:
  - `1080p`: Das Video auf 1080p Auflösung hochskalieren.
  - `4k`: Das Video auf 4K Auflösung hochskalieren.
  - `gif`: Das Video in eine GIF-Vorschau umwandeln.

Beispielanfrage:

```shell
curl -X POST 'https://api.acedata.cloud/veo/upsample' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "4k"
  }'
```

Die Rückgabe ist identisch mit der von `/veo/videos`, es handelt sich weiterhin um eine asynchrone Aufgabenstruktur, die über `task_id` im `/veo/tasks`-Interface den Status der Aufgabe abfragen kann:

```json
{
  "success": true,
  "task_id": "8f5a90ae-3f86-4c4f-86f7-7126f5e92c76",
  "trace_id": "0f3e09c2-4c2e-46ea-9cdc-a31ec48b7c12",
  "data": [
    {
      "id": "253eedc47f1c4eb2a370ed2312168f4b",
      "video_url": "https://platform.cdn.acedata.cloud/veo/8f5a90ae.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

Erläuterung der Rückgabefelder:

- `success`: Ob die Hochskalierungsaufgabe erfolgreich eingereicht wurde.
- `task_id`: Die ID der aktuellen Hochskalierungsaufgabe.
- `data`: Die Ergebnisse des hochskalierten Videos.
  - `video_url`: Die Adresse des hochskalierten Videos.

## Abrechnungsinformationen

- `action=1080p`: 0,16 Credit / Vorgang
- `action=4k`: 0,50 Credit / Vorgang
- `action=gif`: 0,13 Credit / Vorgang

Wenn der übergebene `action`-Wert nicht in den oben genannten Aufzählungen enthalten ist, wird standardmäßig mit 0,50 Credit abgerechnet. Es wird empfohlen, die unterstützten Werte explizit zu übergeben.

## Asynchrone Rückrufe

Die Schnittstelle unterstützt ebenfalls den asynchronen Modus. Durch die Übergabe von `callback_url` können die Ergebnisse nach Abschluss der Aufgabe über eine POST-Anfrage zurückgerufen werden. Wenn keine öffentliche Rückrufadresse vorhanden ist, kann auch `async` auf `true` gesetzt werden, wodurch die Schnittstelle ebenfalls sofort `task_id` zurückgibt, und die Ergebnisse können anschließend über die entsprechende Aufgabenabfrage-Schnittstelle abgefragt werden.
