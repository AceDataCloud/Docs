---
title: "Integrationsleitfaden für E-Commerce-Sprachvideos"
description: "Kling video generation API guide - Ace Data Cloud"
---

Reichen Sie Aufgaben über `POST /kling/video-commerce` ein und verwenden Sie das vorhandene `POST /kling/tasks`, um den Status der Plattformaufgabe abzufragen.

## Eingabe

Laden Sie ein Personenbild hoch und geben Sie eine voice_id an, oder verwenden Sie eine voreingestellte avatar_id (beides schließt sich gegenseitig aus; für voreingestellte Personen kann keine separate voice_id angegeben werden). Es muss ein speech_script mit maximal 2000 Zeichen bereitgestellt werden. Bei Angabe von Produktinformationen werden mindestens ein ref_image und ein goods_title benötigt; Produkt-Sprachvideos unterstützen keine speech_rate. Normale Personen-Sprachvideos unterstützen eine Sprechgeschwindigkeit von 0.8, 1.0 oder 1.2.

Nachfolgend ein Beispiel für die Anfragestruktur. Ersetzen Sie die Material-URLs vor dem Aufruf.

```json
{
  "contents": [
    {
      "type": "avatar_image",
      "url": "https://your-cdn.example/person.jpg"
    },
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    },
    {
      "type": "speech_script",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "voice_id": "male_calm_informative"
  },
  "async": true
}
```

## Ergebnisse und Abrechnung

Der synchrone Modus gibt das Generierungsergebnis zurück; der asynchrone Modus gibt zunächst eine `task_id` zurück, und das Abschlussergebnis enthält die Video- oder Bildlinks in `data` sowie die serverseitig berechnete `usage`. `callback_url` wird für Abschlussbenachrichtigungen verwendet; Anfragen mit `watermark=true` geben gleichzeitig eine Version mit Wasserzeichen zurück.

Normale Personen-Sprachvideos: 720p kosten 1.4 Credits/Sekunde, 1080p kosten 1.68 Credits/Sekunde; Produkt-Sprachvideos: 720p kosten 1.96 Credits/Sekunde, 1080p kosten 2.24 Credits/Sekunde. Videos werden nach der tatsächlich generierten Dauer abgerechnet; der Grundpreis pro Sekunde vor der Generierung stellt nicht den Gesamtpreis der gesamten Aufgabe dar. Für fehlgeschlagene Aufgaben werden keine Generierungskosten berechnet.
