Lassen Sie ein **bereits vorhandenes Kling-Video** (5 Sekunden oder 10 Sekunden) "sprechen" - das heißt, synchronisieren Sie die Lippenbewegungen (Lip Sync) mit Audio oder Text. In Kombination mit `/kling/videos` `image2video` (um Fotos zum Leben zu erwecken) kann ein vollständiger Prozess für "**sprechende Fotos / digitale Sprachsynthese**" erstellt werden.

> Diese Schnittstelle ist eine einfache, ein Schritt umfassende Verpackung, die von AceDataCloud bereitgestellt wird und sich an gängige Audio-/Text-gesteuerte Szenarien richtet; sie ist kein Feldspiegel der mehrstufigen Schnittstelle „Gesichtserkennung → Advanced Lip Sync“ von Kling. Bitte orientieren Sie sich an der Parameterübersicht auf dieser Seite.

- **Schnittstellenadresse**: `POST https://api.acedata.cloud/kling/lip-sync`
- **Anforderungsformat**: `application/json`
- **Antwortformat**: `application/json`
- **Abrechnung**: Jede erfolgreiche Anfrage kostet **2,45 Credits** (fest)

## Anfrageheader (Request Headers)

| Feld              | Wert                   | Beschreibung                                           |
| ---------------- | --------------------- | ---------------------------------------------------- |
| `authorization`  | `Bearer ${API_KEY}`   | Ihr API-Schlüssel, [Erhaltungsadresse](https://platform.acedata.cloud) |
| `content-type`   | `application/json`    | Format des Anfragekörpers                             |
| `accept`         | `application/json`    | Antwortformat                                         |

## Anfrageparameter (Request Body)

| Parameter         | Typ      | Pflicht  | Standard  | Beschreibung                                                                                                           |
| ---------------- | ------- | ------- | -------- | -------------------------------------------------------------------------------------------------------------------- |
| `mode`           | string  | Ja      | —        | Generierungsmodus. Enumeration: `audio2video` (audio-gesteuert), `text2video` (text-gesteuert)                     |
| `video_id`       | string  | Entweder | —        | ID des von Kling generierten Videos (z. B. `video_id`, das von `/kling/videos` `image2video` zurückgegeben wird). **Unterstützt nur 5s/10s Videos, die innerhalb von 30 Tagen erstellt wurden**. `video_id` und `video_url` sind alternativ, können nicht gleichzeitig übergeben werden |
| `video_url`      | string  | Entweder | —        | Öffentlich zugänglicher Video-Link. Einschränkungen: `.mp4`/`.mov`, ≤100MB, Dauer 2–10s, nur 720p/1080p, Seitenlängen 720–1920px. Alternativ zu `video_id`                                  |
| `audio_url`      | string  | Bedingung | —        | Download-URL des treibenden Audios, erforderlich, wenn `audio2video` + `audio_type=url`. Formate `.mp3`/`.wav`/`.m4a`/`.aac`, ≤5MB                                     |
| `audio_type`     | string  | Nein    | `url`    | Audioübertragungsart. Enumeration: `url`, `file` (wirksam bei `audio2video`)                                        |
| `audio_file`     | string  | Bedingung | —        | Base64 des Audiofiles, erforderlich, wenn `audio_type=file`. Formate wie oben, ≤5MB                                 |
| `text`           | string  | Bedingung | —        | Zu lesender Text, erforderlich bei `text2video`, **maximal 120 Zeichen**                                             |
| `voice_id`       | string  | Bedingung | —        | Stimm-ID, erforderlich bei `text2video`                                                                          |
| `voice_language` | string  | Nein    | `zh`     | Sprachsprache. Enumeration: `zh`, `en` (wirksam bei `text2video`)                                                  |
| `voice_speed`    | float   | Nein    | `1.0`    | Sprechgeschwindigkeit, Bereich `0.8`–`2.0`, auf eine Dezimalstelle genau (wirksam bei `text2video`)                |
| `callback_url`   | string  | Nein    | —        | Rückrufadresse. Wenn dieses Feld oder `async=true` übergeben wird, dann **asynchroner Modus**: sofortige Rückgabe von `task_id`, Rückruf nach Ergebnisgenerierung |
| `async`          | boolean | Nein    | `false`  | Ob asynchron. Bei `true` sofortige Rückgabe von `task_id`, in Kombination mit `/kling/tasks` abfragen oder Rückruf über `callback_url` |

## Anfragebeispiele

### 1) Audio-gesteuert (audio2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2) Text-gesteuert (text2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "Bruder, lange nicht gesehen, mir geht es gut, pass gut auf dich auf.",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## Antwortbeispiel (synchron erfolgreich)

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| Feld          | Typ      | Beschreibung                                   |
| ------------- | ------- | ---------------------------------------------- |
| `success`     | boolean | Ob erfolgreich                                  |
| `task_id`     | string  | ID dieser Aufgabe (kann zur Abfrage von `/kling/tasks` verwendet werden) |
| `video_id`    | string  | ID des generierten Videos von Kling (kann als Eingabe für das nächste `extend`/`lip-sync` verwendet werden) |
| `video_url`   | string  | URL des generierten Sprechvideos (wurde auf dieser Plattform CDN gespeichert, langfristig gültig) |
| `duration`    | string  | Videodauer (Sekunden)                          |
| `state`       | string  | Aufgabenstatus: `succeed` / `failed`          |

## Asynchroner Modus und Abfrage

Wenn `callback_url` oder `async: true` übergeben wird, gibt die Schnittstelle **sofort** `task_id` zurück; danach kann man:

- **Abfragen**: `POST /kling/tasks`, body `{ "action": "retrieve", "id": "<task_id>" }` (kostenlos)
- **Rückruf**: Nach Abschluss der Generierung wird das Ergebnis an Ihre `callback_url` gepostet

## Vollständiger Prozess: Sprechende Fotos (image2video → lip-sync)
```bash
# Schritt 1: Lass das Foto lebendig werden, erhalte video_id
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"look at camera, natural","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# Schritt 2: Lippen synchronisieren mit Audio
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"}'
# → { "video_url": "https://platform2.cdn.acedata.cloud/kling/....mp4", ... }
```

## Fehlerantwort

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "eines von video_id oder video_url ist erforderlich" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | code                    | Bedeutung                                           |
| ---- | ----------------------- | -------------------------------------------------- |
| 400  | `bad_request`           | Fehlende oder ungültige Parameter (z. B. kein mode übergeben, Konflikt zwischen video und audio, text über 120 Zeichen) |
| 401  | `authorization_missing` | Fehlender oder ungültiger API-Schlüssel            |
| 403  | `forbidden`             | Inhalt wurde durch Risikokontrolle blockiert       |
| 429  | `too_many_requests`     | Überlastung durch gleichzeitige Anfragen, bitte später erneut versuchen |
| 500  | `api_error`             | Fehler im upstream oder intern                      |

## Hinweise

- `video_id` muss ein **innerhalb von 30 Tagen** generiertes Kling-Video sein und **5s oder 10s** lang sein; andernfalls bitte `video_url` verwenden, um ein konformes Video zu übergeben.
- Eingabewideo sollte **klar, frontal, Einzelperson** sein, um die besten Lippenbewegungseffekte zu erzielen.
- Die Dauer von Audio/Text sollte mit der Videolänge übereinstimmen (Audio darf die Videolänge nicht überschreiten).
- Die Abrechnung erfolgt bei **Erfolg** (2,45 Credits/Versuch); Parameterprüfungsfehler (4xx) werden nicht abgerechnet.
