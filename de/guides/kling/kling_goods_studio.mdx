Über `POST /kling/goods-studio` Aufgaben übermitteln und mit dem vorhandenen `POST /kling/tasks` den Status von Plattformaufgaben abfragen.

## Eingabe

Stellen Sie 1–5 Produktbilder und einen Produkttitel mit maximal 200 Zeichen bereit; die Produktbeschreibung ist optional und darf maximal 2000 Zeichen umfassen. Die Dauer ist optional und kann 15, 30 oder 60 Sekunden betragen.

Nachfolgend ein Beispiel für die Anfragestruktur. Ersetzen Sie die Material-URL und rufen Sie sie anschließend auf.

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## Ergebnisse und Abrechnung

Der synchrone Modus gibt das Generierungsergebnis zurück; der asynchrone Modus gibt zunächst `task_id` zurück, und das Abschlussergebnis enthält die Video- oder Bildlinks in `data` sowie die serverseitig berechnete `usage`. `callback_url` wird für die Abschlussbenachrichtigung verwendet; Anfragen mit `watermark=true` geben gleichzeitig die Version mit Wasserzeichen zurück.

720p: 2,38 Credits/Sekunde; 1080p: 2,8 Credits/Sekunde. Videos werden nach der tatsächlich generierten Dauer abgerechnet; der Basispreis pro Sekunde vor der Generierung stellt nicht den Gesamtpreis der gesamten Aufgabe dar. Für fehlgeschlagene Aufgaben werden keine Generierungsgebühren berechnet.
