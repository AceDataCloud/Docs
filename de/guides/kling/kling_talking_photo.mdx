---
title: "Kling sprechendes Foto API (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Mit einem Klick **ein Foto + eine Audioaufnahme** in ein „sprechendes Video“ verwandeln. Der Service führt intern automatisch zwei Schritte aus: Zuerst wird mit image2video das Foto zum Leben erweckt, dann wird mit lip-sync das Lippen-Synchronisieren basierend auf dem Audio durchgeführt. Sie müssen nur **einmal** aufrufen.

- **API-Adresse**: `POST https://api.acedata.cloud/kling/talking-photo`
- **Abrechnung**: Nach Dauer, 5 Sekunden **16,45 Credits**, 10 Sekunden **30,45 Credits** (= Preis für die Kombination von image2video + lip-sync)

## Anfrage-Header

| Feld              | Wert                   |
| ---------------- | --------------------- |
| `authorization`  | `Bearer ${API_KEY}`   |
| `content-type`   | `application/json`    |

## Anfrageparameter

| Parameter        | Typ      | Pflicht  | Standard              | Beschreibung                                |
| ---------------- | ------- | ------- | --------------------- | ------------------------------------------- |
| `image_url`      | string  | Ja      | —                     | Öffentliche URL des Personenfotos, empfohlen ist ein klares Frontalbild |
| `audio_url`      | string  | Ja      | —                     | Öffentliche URL des Audio ( .mp3/.wav/.m4a/.aac, ≤5MB) |
| `prompt`         | string  | Nein     | —                     | Hinweise zu Bewegungen/Gesichtsausdrücken während der Fotoanimation |
| `model`          | string  | Nein     | `kling-v2-1-master`  | Kling-Modell, das für die Fotoanimation verwendet wird |
| `duration`       | integer | Nein     | `5`                   | Videolänge (5 oder 10 Sekunden)            |
| `mode`           | string  | Nein     | `pro`                 | Animationsqualität (std/pro)               |
| `callback_url`   | string  | Nein     | —                     | Bei Angabe oder `async=true` wird task_id asynchron zurückgegeben |
| `async`          | boolean | Nein     | `false`               | Asynchroner Modus, zusammen mit `/kling/tasks` abfragen oder Rückruf |

## Anfragebeispiel

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Antwortbeispiel

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Feld                 | Beschreibung                              |
| -------------------- | ----------------------------------------- |
| `video_url`          | Das endgültige sprechende Video (auf dieser Plattform im CDN gespeichert) |
| `source_video_url`   | Das Zwischenvideo der Fotoanimation (Ergebnis von image2video) |
| `video_id`           | Kling Video ID                            |

## Hinweise

- Fotos sollten klar, frontal und von einer Person sein.
- Die Audio-Dauer sollte idealerweise die Videolänge (5s/10s) nicht überschreiten.
- Die Abrechnung erfolgt bei Erfolg; Parameterprüfungsfehler (4xx) werden nicht abgerechnet.
- Die Generierung dauert etwa 4–6 Minuten (zwei Schritte), es wird empfohlen, `async=true` + `/kling/tasks` zur Abfrage zu verwenden.
