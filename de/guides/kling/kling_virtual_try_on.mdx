Über `POST /kling/virtual-try-on` Aufgaben übermitteln und mit dem vorhandenen `POST /kling/tasks` den Status der Plattformaufgabe abfragen.

## Eingabe

Es muss genau ein product_image und ein person_image bereitgestellt werden. keep_face, keep_pose und keep_background sind standardmäßig alle auf true gesetzt und können unabhängig deaktiviert werden. Die längste Seite der Eingabebilder darf 2048px nicht überschreiten, die kürzeste Seite muss größer als 300px sein, und die Datei darf 10MB nicht überschreiten.

Nachfolgend ein Beispiel für die Anfragestruktur. Bitte nach dem Ersetzen der Material-URL aufrufen.

```json
{
  "contents": [
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "person_image",
      "url": "https://your-cdn.example/person.jpg"
    }
  ],
  "async": true
}
```

## Ergebnisse und Abrechnung

Der synchrone Modus gibt das Generierungsergebnis zurück; der asynchrone Modus gibt zunächst `task_id` zurück, und das fertige Ergebnis enthält die Video- oder Bildlinks in `data` sowie das serverseitig berechnete `usage`. `callback_url` wird für die Benachrichtigung nach Abschluss verwendet; Anfragen mit `watermark=true` geben gleichzeitig eine Version mit Wasserzeichen zurück.

1,12 Credits/Bild, abgerechnet nach der tatsächlichen Anzahl der ausgegebenen Bilder. Videos werden nach der tatsächlich generierten Dauer abgerechnet; der Grundpreis pro Sekunde vor der Generierung stellt nicht den Gesamtpreis der gesamten Aufgabe dar. Für fehlgeschlagene Aufgaben werden keine Generierungskosten berechnet.
