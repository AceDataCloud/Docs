Über `POST /kling/apparel` Aufgaben übermitteln und mit dem vorhandenen `POST /kling/tasks` den Aufgabenstatus der Plattform abfragen.

## Eingabe

Stellen Sie eine Produktbeschreibung mit maximal 2500 Zeichen, ein 5–180 Sekunden langes Referenzvideo und 1–5 Produktbilder bereit. Zusätzlich können 1–5 Modelbilder, eine Hintergrundmusikdatei sowie eine bestimmte Sprecherstimme bereitgestellt werden; wenn keine Stimme angegeben wird, wird die native Sprachaufnahme verwendet.

Nachfolgend ein Beispiel für die Anfragestruktur; bitte nach dem Ersetzen der Material-URLs aufrufen.

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "Dein Produkt- oder Sprachaufnahmeinhalt"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## Ergebnisse und Abrechnung

Der synchrone Modus gibt das Generierungsergebnis zurück; der asynchrone Modus gibt zunächst `task_id` zurück, und das Abschlussergebnis enthält die Video- oder Bildlinks in `data` sowie die serverseitig berechnete `usage`. `callback_url` wird für Abschlussbenachrichtigungen verwendet; bei einer Anfrage mit `watermark=true` wird gleichzeitig eine Version mit Wasserzeichen zurückgegeben.

Native Sprachaufnahme: 720p kostet 1,82 Credits/Sekunde, 1080p kostet 2,38 Credits/Sekunde; angegebene Sprecherstimme: 720p kostet 2,38 Credits/Sekunde, 1080p kostet 2,8 Credits/Sekunde. Videos werden nach der tatsächlich generierten Dauer abgerechnet; der Grundpreis pro Sekunde vor der Generierung stellt nicht den Gesamtpreis der gesamten Aufgabe dar. Für fehlgeschlagene Aufgaben werden keine Generierungsgebühren erhoben.
