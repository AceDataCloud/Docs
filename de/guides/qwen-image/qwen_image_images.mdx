title: "Qwen Image Generierung und Bearbeitung API"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` führt über dieselbe Schnittstelle sowohl Text-zu-Bild-Generierung als auch die Bearbeitung von 1–3 Referenzbildern durch und unterstützt `qwen-image-3.0` sowie `qwen-image-3.0-pro`.

## Modellwahl

| Modell                | Geeignete Szenarien       | Offizieller Standardpreis       |
| --------------------- | ------------------------ | ------------------------------ |
| `qwen-image-3.0`      | Massenproduktion, schnelle Iteration | Ausgabe $0.030/Bild            |
| `qwen-image-3.0-pro`  | Komplexes Layout, hochpräzise Endbilder | 1K $0.040/Bild; 2K $0.075/Bild |

Referenzbilder werden nach der tatsächlichen Eingabemenge berechnet, offizieller Standardpreis $0.003/Bild.

## Synchrone Generierung

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "A simple red circle centered on a clean white background.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

Erfolgreiche Antwort enthält permanente CDN-Bildadresse, tatsächliche Nutzung und aktuelle Kosten:

## Referenzbildbearbeitung

Fügen Sie `image_urls` hinzu, unterstützt 1–3 öffentlich zugängliche Bilder:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "保留主体，将背景改成暖**###**海报风格",
  "image_urls": ["https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` ist nur für Text-zu-Bild-Generierung. `n` liegt im Bereich 1–6; das Seitenverhältnis muss zwischen 1:8 und 8:1 liegen.

## Asynchrone Aufgaben

Nach Setzen von `async: true` gibt die Schnittstelle sofort `task_id` zurück. Verwenden Sie `/qwen-image/tasks`, um den Endstatus abzufragen, oder übergeben Sie `callback_url`, um Benachrichtigungen bei Abschluss zu erhalten. Die Generierung wird nur einmal berechnet, Abfragen der Aufgabe verursachen keine wiederholten Kosten.
