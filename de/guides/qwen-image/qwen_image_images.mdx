---
title: "Qwen Image Bilder API Integrationsleitfaden"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` unterstützt `qwen-image-3.0` und `qwen-image-3.0-pro` für die Erstellung von Bildern aus Text und die Bearbeitung von 1–3 Referenzbildern.

## Bilder aus Text

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen-image-3.0","prompt":"Ein extrem minimalistisches Technologie-Poster","size":"1024*1024","n":1}'
```

## Bildbearbeitung

Fügen Sie im gleichen Request `image_urls` hinzu, unterstützt 1–3 öffentliche Bilder:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "Behalte das Hauptmotiv, ändere es in einen warmen**###** Poster-Stil",
  "image_urls": ["https://cdn.acedata.cloud/r9vsv9.png"],
  "size": "2048*2048",
  "prompt_extend": true,
  "prompt_extend_mode": "direct",
  "enable_thinking": true,
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` unterstützt nur Bilder aus Text. `n` reicht von 1–6. Die Gesamtpixelgröße der Ausgabe muss zwischen 512×512 und 2048×2048 liegen, das Seitenverhältnis beträgt 1:8 bis 8:1.

## Asynchrone Aufrufe

Setzen Sie `async: true`, um sofort `task_id` zu erhalten; Sie können auch `callback_url` übergeben, um das endgültige Ergebnis zu empfangen. Nach Abschluss über `/qwen-image/tasks` abfragen.

Die erfolgreiche Antwort enthält `data[].image_url`, `usage`, `task_id` und `trace_id`. Die Bildlinks werden nach Möglichkeit in das Ace Data Cloud CDN übertragen. Echte Antwortbeispiele werden nach der Produktions-E2E-Überprüfung ergänzt.
