---
title: "Qwen Image Generierung und Bearbeitung API"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` führt Text-zu-Bild und die Bearbeitung von 1–3 Referenzbildern über dieselbe Schnittstelle aus und unterstützt `qwen-image-3.0` sowie `qwen-image-3.0-pro`.

## Modell auswählen

| Modell               | Geeignete Szenarien       | Offizieller Standardpreis     |
| -------------------- | ------------------------- | ----------------------------- |
| `qwen-image-3.0`     | Stapelerstellung, schnelle Iteration | Ausgabe $0.030/Bild |
| `qwen-image-3.0-pro` | Komplexes Layout, hochpräzise Endergebnisse | 1K $0.040/Bild; 2K $0.075/Bild |

Referenzbilder werden nach der tatsächlichen Anzahl der Eingaben berechnet, offizieller Standardpreis $0.003/Bild.

## Synchrone Generierung

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "A simple red circle centered on a clean white background.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

Die erfolgreiche Antwort enthält eine permanente CDN-Bildadresse, die tatsächliche usage und die Kosten dieser Anfrage:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Bearbeitung mit Referenzbildern

Fügen Sie `image_urls` hinzu; 1–3 öffentlich zugängliche Bilder werden unterstützt:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "保留主体，将背景改成暖色电影海报风格",
  "image_urls": ["https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` wird nur für Text-zu-Bild verwendet. Der Bereich von `n` liegt bei 1–6; das Seitenverhältnis muss zwischen 1:8 und 8:1 liegen.

## Asynchrone Aufgaben

Nach dem Setzen von `async: true` gibt die Schnittstelle sofort `task_id` zurück. Verwenden Sie `/qwen-image/tasks`, um den Endstatus abzufragen, oder übergeben Sie `callback_url`, um eine Abschlussbenachrichtigung zu erhalten. Die Generierung wird nur einmal abgerechnet, Aufgabenabfragen werden nicht erneut berechnet.
