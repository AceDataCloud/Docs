---
title: "Qwen Image Aufgaben API Integrationsleitfaden"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

Verwenden Sie `POST https://api.acedata.cloud/qwen-image/tasks`, um asynchrone Bildgenerierungsaufgaben abzufragen. Diese Abfrage-Schnittstelle ist kostenlos.

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Für die Batch-Abfrage verwenden Sie `action=retrieve_batch` und das `ids`-Array. Nach erfolgreichem Abschluss der Aufgabe enthält `response.data` die permanenten Adressen der generierten Bilder sowie die tatsächliche Nutzung.
