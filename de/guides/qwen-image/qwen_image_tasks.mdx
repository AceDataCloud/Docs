---
title: "Qwen Image Aufgabenabfrage API"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/tasks` wird verwendet, um Qwen Image asynchrone Aufgaben abzufragen, in großen Mengen abzufragen oder zu löschen. Diese Schnittstelle verursacht keine zusätzlichen API-Kosten.

## Abfrage einer einzelnen Aufgabe

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Nach Abschluss der Aufgabe enthält `response.data` die permanente CDN-Bildadresse, `response.usage` die tatsächliche Eingabe-/Ausgabemenge und `response.cost` die Abrechnungsinformationen der generierten Aufgabe.

## Batch-Abfrage

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Gibt `{ "items": [...], "count": 2 }` zurück. Die Listenabfrage unterstützt auch die Filterung nach Benutzer, Anwendung und Erstellungszeitraum.

## Löschen von Aufgabenaufzeichnungen

```json
{"action":"delete","id":"TASK_ID"}
```

Das Löschen betrifft nur die Aufgabenhistorie und entfernt keine bereits generierten CDN-Dateien.
