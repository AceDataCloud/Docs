Codex Desktop jakaa `~/.codex/config.toml` Codex CLI:n kanssa.

## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusten lista](https://platform.acedata.cloud/console/applications), siirry käytettävissä oleviin sovelluksiin ja kopioi API-avain.

![Hanki Ace Data Cloud API-avain](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Aseta API-avain

macOS:

```bash
launchctl setenv ACEDATACLOUD_API_KEY "sinun API-avain"
```

Windows PowerShell:

```powershell
setx ACEDATACLOUD_API_KEY "sinun API-avain"
```

## 3. Konfiguroi AceDataCloud

Muokkaa `~/.codex/config.toml` (Windowsissa `%USERPROFILE%\.codex\config.toml`), lisää:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Windowsissa vaihda viimeiset kaksi riviä:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Ei tarvitse täyttää `model`-kenttää; avaa Codex ja valitse malli suoraan.

## 4. Käynnistä uudelleen ja varmista

Sulje Codex kokonaan ja avaa se uudelleen, luo paikallinen tehtävä ja lähetä yksinkertainen viesti. Providerin tulisi näkyä nimellä `acedatacloud`; todelliset kutsut voi tarkistaa [käyttöhistoriasta](https://platform.acedata.cloud/console/usages).

Jos konfigurointi ei ole voimassa, varmista, että muokkaat nykyisen käyttäjän `~/.codex/config.toml`-tiedostoa, ympäristömuuttuja on asetettu ja käynnistä sovellus uudelleen kokonaan. Pilvitehtävät tai automaatio, jotka toimivat eri ympäristöissä, tarvitsevat avaimen erikseen kussakin ympäristössä.
