CC Switchiä voidaan hallita graafisen käyttöliittymän kautta Codexin provideria ja API-avainta.

## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusten lista](https://platform.acedata.cloud/console/applications), siirry käytettävissä oleviin sovelluksiin ja kopioi API-avain.

![Hanki Ace Data Cloud API-avain](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Asenna CC Switch

Lataa ja asenna [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest) -sivulta tai suorita macOS:llä:

```bash
brew install --cask cc-switch
```

## 3. Lisää provider

1. Avaa CC Switch, vaihda **Codex**-tilaan.
2. Napsauta **Add Provider** ja valitse **Custom**.
3. Täytä:

| Kenttä    | Sisältö                          |
| --------- | ------------------------------- |
| Nimi      | `acedatacloud`                 |
| Perus-URL | `https://api.acedata.cloud/v1` |
| API-avain | Äskettäin kopioitu Ace Data Cloud API-avain |

Jos CC Switch tarjoaa mukautetun konfigurointieditorin, konfiguraation tulisi pysyä seuraavana:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"
requires_openai_auth = true
```

CC Switch tallentaa API-avaimen `~/.codex/auth.json`:

```json
{
  "OPENAI_API_KEY": "{token}"
}
```

Älä lisää `env_key` tai `[model_providers.acedatacloud.auth]` yllä olevaan provideriin; manuaalinen konfigurointi tai CC Switchin konfigurointi, valitse toinen. Ei tarvitse kiinnittää `model`-arvoa, voit valita sen suoraan Codexissä.

## 4. Ota käyttöön ja vahvista

Ota käyttöön `acedatacloud` provider, sulje täysin ja käynnistä Codex tai VS Code uudelleen. Suorita `/model`, varmista että Provider on `acedatacloud`, valitse malli ja lähetä yksinkertainen viesti.

Jos saat takaisin 401, varmista että käytössä on `acedatacloud` ja tarkista `~/.codex/auth.json` tiedostosta, että `OPENAI_API_KEY` on juuri kopioitu Ace Data Cloud API-avain. Käyttöhistoriaa voi tarkastella [käyttöhistoriassa](https://platform.acedata.cloud/console/usages).
