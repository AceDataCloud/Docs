Codex VS Code -laajennus jakaa `~/.codex/config.toml` Codex CLI:n kanssa.

## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusten lista](https://platform.acedata.cloud/console/applications), siirry käytettävissä oleviin sovelluksiin ja kopioi API-avain.

![Hanki Ace Data Cloud API-avain](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Asenna laajennus

Asenna OpenAI:n julkaisema **Codex – OpenAI:n koodausagentti** VS Code -laajennusmarkkinoilta tai suorita:

```bash
code --install-extension openai.chatgpt
```

## 3. Aseta API-avain

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="oma API-avain"
```

Jos haluat, että se on voimassa pitkään, lisää tämä rivi `~/.zshrc` tai `~/.bashrc` -tiedostoon. Windows PowerShell käyttää:

```powershell
setx ACEDATACLOUD_API_KEY "oma API-avain"
```

## 4. Konfiguroi AceDataCloud

Muokkaa `~/.codex/config.toml` (Windowsissa `%USERPROFILE%\.codex\config.toml`), lisää:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Windowsissa viimeiset kaksi riviä muutetaan:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

`model`-kenttää ei tarvitse täyttää; voit valita mallin Codex-paneelista.

## 5. Käynnistä uudelleen ja varmista

Sulje VS Code kokonaan ja avaa se uudelleen, avaa sitten Codex-paneeli. Suorita `/model`, varmista että Provider on `acedatacloud`, ja lähetä sitten yksinkertainen viesti; kutsuhistoriaa voi tarkastella [käyttöhistoriasta](https://platform.acedata.cloud/console/usages).

Jos laajennus ei pysty lukemaan avainta, käynnistä VS Code ympäristömuuttujat asetetusta terminaalista tai aseta järjestelmänlaajuiset ympäristömuuttujat ja käynnistä VS Code uudelleen. Remote SSH, WSL ja Dev Container tarvitsevat erilliset asetukset ympäristössä, jossa laajennusta käytetään.
