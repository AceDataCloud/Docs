Codex CLI, Desktop ja VS Code -laajennus jakavat `~/.codex/config.toml`. Konfiguroi kerran `acedatacloud` provider, niin voit käyttää Codexia Ace Data Cloudin kautta.

| Käyttötapa        | Konfigurointiohje                                                                                   |
| -------------- | --------------------------------------------------------------------------------------- |
| Terminal / CLI | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)        |
| Desktop        | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)     |
| VS Code        | [Codex for VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)  |
| Graafinen vaihto     | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration) |

Yhteiset asetukset ovat vain kolme:

- Provider: `acedatacloud`
- Perus-URL: `https://api.acedata.cloud/v1`
- API-avain: saatavilla [sovellusluettelosta](https://platform.acedata.cloud/console/applications) ja tallenna se `ACEDATACLOUD_API_KEY`-muuttujaan.

Ei tarvitse kiinnittää mallia liitännäisasetuksiin; käynnistä Codex ja valitse malli suoraan.

Palaa [Coding Plan -konfigurointikeskukseen](https://platform.acedata.cloud/documents/coding-plan-integration).
