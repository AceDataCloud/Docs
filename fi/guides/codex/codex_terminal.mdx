## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusten lista](https://platform.acedata.cloud/console/applications), siirry käytettävissä oleviin sovelluksiin ja kopioi API-avain.

![Hanki Ace Data Cloud API-avain](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Asenna Codex

```bash
npm install -g @openai/codex
```

## 3. Aseta API-avain

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="oma API-avain"
```

Jos haluat, että se on voimassa pitkään, lisää tämä rivi `~/.zshrc` tai `~/.bashrc` -tiedostoon. Windows PowerShell käyttää:

```powershell
setx ACEDATACLOUD_API_KEY "oma API-avain"
```

Asetusten jälkeen avaa terminaali uudelleen.

## 4. Konfiguroi AceDataCloud

Muokkaa `~/.codex/config.toml` (Windowsissa `%USERPROFILE%\.codex\config.toml`), lisää:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Windowsissa viimeiset kaksi riviä muutetaan:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

`model`-kenttää ei tarvitse täyttää; käynnistyksen jälkeen voit valita mallin Codexissa. Jos sinulla on muita asetuksia, voit säilyttää ne, älä luo samaa nimeä olevaa provideria uudelleen.

## 5. Käynnistä

```bash
cd /path/to/your/project
codex
```

Siirry Codexiin ja suorita `/model`, varmista että Provider on `acedatacloud`, ja valitse sitten tarvittava malli. Kutsuhistoria ja saldo voidaan tarkistaa [käyttöhistoriasta](https://platform.acedata.cloud/console/usages) ja [sovellusten listasta](https://platform.acedata.cloud/console/applications).

Jos saat ilmoituksen puuttuvasta avaimesta tai saat 401-virheen, varmista, että ympäristömuuttuja on asetettu, ja sulje terminaali kokonaan ennen kuin avaat sen ja Codexin uudelleen.
