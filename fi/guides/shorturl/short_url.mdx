Tässä artikkelissa esitellään lyhyt URL API -liittymisohje, joka voi muuntaa pidempiä URL-osoitteita lyhyemmiksi.

## Hakuprosessi

Käyttääksesi lyhyt URL API:ta, sinun on ensin mentävä [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tunnuksesi, jota voit säilyttää varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Valmiina se palauttaa sinut automaattisesti nykyiselle sivulle.

**Yksi API-tunnus riittää kutsumaan kaikkia palveluja, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jonka avulla voit kokeilla ilmaiseksi; jos saldo on riittämätön, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Lyhyt URL API →](https://platform.acedata.cloud/documents/shorturl)

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttää pidempi URL-osoite, joka halutaan muuntaa, ja saat käsitellyn tuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `content`-kenttä. Voimme seuraavaksi täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/4ascb2.png" width="500" className="m-auto" /></p>

Täällä olemme asettaneet pyyntöotsikot, mukaan lukien:

- `accept`: minkälaista vastausmuotoa haluat vastaanottaa, tässä on täytetty `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemuksen jälkeen.

Lisäksi on asetettu pyyntökeho, mukaan lukien:

- `content`: lyhennettävän URL-osoitteen sisältö.

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/r3uakb.png" width="500" className="m-auto" /></p>

Napsauta "Kokeile"-painiketta testataksesi, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavan tuloksen:

```json
{
  "success": true,
  "data": {
    "url": "https://surl.id/1uHCs01xa5"
  }
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `success`, tässä tehtävän onnistumisen tila.
- `data`, joka sisältää tässä muunnellun URL-osoitteen.

Voimme nähdä, että alkuperäinen pidempi URL-osoite `https://platform.acedata.cloud/documents/shorturl` on onnistuneesti muutettu lyhyeksi URL-osoitteeksi `https://surl.id/1uHCs01xa5`.

Jos haluat luoda vastaavan liittymiskoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/shorturl' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "content": "https://platform.acedata.cloud/documents/shorturl"
}'
```

Pythonin liittymiskoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/shorturl"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": "https://platform.acedata.cloud/documents/shorturl"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
