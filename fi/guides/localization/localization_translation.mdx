Localization Translate API:n päätoiminto on saada käännetty teksti syöttämällä käännettävä teksti, ja käännettävä kieli voidaan mukauttaa. Käännetyt tulokset voidaan esittää kahdella päämenetelmällä: `json` ja `markdown`.

Tässä asiakirjassa käsitellään yksityiskohtaisesti Translate API:n liittämistä, jotta voit helposti integroida ja hyödyntää tämän API:n voimakkaita ominaisuuksia. Translate API:n avulla voit helposti kääntää syötetyn tekstin tiettyyn kieleen ja se tukee erityisiä tapoja käännöstulosten esittämiseen.

## Hakuprosessi

Käyttääksesi Localization Translate API:a, siirry ensin [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tokenisi, jota voit käyttää myöhemmin.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Valmiina palaat automaattisesti nykyiselle sivulle.

**Yksi API-token riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jonka avulla voit kokeilla palvelua ilmaiseksi; jos määrä loppuu, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen asiakirja: [Localization Translate API →](https://platform.acedata.cloud/documents/localization-translate)

## Pyyntöesimerkki

Otetaan esimerkki englanninkielisestä syötteestä ja näytetään, kuinka tätä API:a käytetään. Oletetaan, että englanninkielinen kuvaus on: `# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.`, seuraavaksi näytetään, kuinka ladataan englanninkielinen kuvaus ja saadaan kiinan käännös, samalla esitetään se markdown-muodossa.

### Pyyntöotsikon ja -kehon asettaminen

**Request Headers** sisältää:

- `accept`: määrittää, että vastaanotetaan JSON-muotoista vastausta, tässä täytetään `application/json`.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

**Request Body** sisältää:

- `input`: käännettävä sisältö. `extension=md` -tilassa lähetetään merkkijono, `extension=json` -tilassa lähetetään JSON-objekti.
- `locale`: mukautettu käännöskieli.
- `extension`: syöteformaatin tyyppi, valinnainen `md` tai `json`.
- `model`: käytettävä käännösmalli, oletuksena gpt-3.5.

| `extension` | `input` tyyppi | Esimerkki                                   |
| ----------- | ---------- | ------------------------------------------ |
| `md`        | merkkijono | `"# Title\n\nParagraph"`                   |
| `json`      | objekti    | `{"title": "Hello", "button": "Submit"}` |

`extension` on pakollinen ja sen on vastattava `input`-tyyppiä; merkkijonoa ei voi käyttää `json`:n kanssa, JSON-objektia ei voi käyttää `md`:n kanssa.

### Koodiesimerkki

Voit huomata, että sivun oikealla puolella on automaattisesti luotu koodia eri kielillä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/tn5nno.png" width="500" className="m-auto" /></p>

Osittainen koodiesimerkki on seuraava:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/localization/translate' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "input": "# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.",
  "locale": "zh-CN",
  "extension": "md"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/localization/translate"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.",
    "locale": "zh-CN",
    "extension": "md"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Vastausesimerkki

Kun pyyntö onnistuu, API palauttaa käännöstehtävän tulos tiedot. Esimerkiksi:

```json
{
  "data": "# 标题 1\n\n这是一个段落。\n\n## 标题 2\n\n这是另一个段落。",
  "usage": {
    "prompt_tokens": 172,
    "completion_tokens": 25
  },
  "model": "gpt-3.5-turbo-16k",
  "locale": "zh-CN"
}
```

Voit nähdä, että tuloksessa on `data`-kenttä, joka sisältää käännetyn kiinan, ja se palautetaan markdown-muodossa. Muut tiedot ovat seuraavat:

- `data`, tämän käännöstehtävän tulos.
- `model`, tämän käännöstehtävän käyttämä kielimalli.
- `locale`, tämän käännöstehtävän käännöskielityyppi.

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutus token.
- `429 too_many_requests`: Liikaa pyyntöjä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
