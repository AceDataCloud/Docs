Localization Translate API:n päätoiminto on saada käännetty teksti syöttämällä käännettävä teksti, ja käännettävä kieli voidaan mukauttaa. Käännöksen tulokset voidaan esittää kahdella pääasiallisella menetelmällä, `json` ja `markdown`.

Tässä asiakirjassa esitellään yksityiskohtaisesti Translate API:n liittämisohjeet, jotka auttavat sinua integroimaan ja hyödyntämään tämän API:n voimakkaita ominaisuuksia. Translate API:n avulla voit helposti kääntää syötetyn tekstin tiettyyn kieleen ja se tukee erityisiä tapoja käännöksen tulosten esittämiseen.

## Hakuprosessi

Käyttääksesi Localization Translate API:a, sinun on ensin mentävä hakusivulle [Localization Translate API](https://platform.acedata.cloud/documents/6dcc60d0-a973-4ad2-92d8-11f4d3775532) ja haettava tarvittavaa palvelua. Kun olet siirtynyt sivulle, napsauta "Acquire"-painiketta, kuten kuvassa näkyy:

![Hakusivu](https://cdn.acedata.cloud/rci31i.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti [kirjautumissivulle](https://platform.acedata.cloud), jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Pyyntöesimerkki

Otetaan esimerkki englanninkielisestä syötteestä ja näytetään, kuinka tätä API:a käytetään. Oletetaan, että englanninkielinen kuvaus on: `# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.`, seuraavaksi näytetään, kuinka ladataan englanninkielinen kuvaus ja saadaan kiinan käännös, ja esitetään se markdown-muodossa.

### Pyyntöotsikoiden ja -kehon asettaminen

**Pyyntöotsikot** sisältävät:

- `accept`: määrittää, että vastaanotetaan JSON-muotoista vastausta, tässä kohdassa on `application/json`.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

**Pyyntökeho** sisältää:

- `input`: ladattava käännettävä teksti.
- `locale`: mukautettu käännettävä kieli.
- `extension`: mukautettu käännöksen tulosten esitysmuoto.
- `model`: käytettävä suuri malli käännöksessä, oletuksena on gpt-3.5.

### Koodiesimerkki

Voit huomata, että sivun oikealla puolella on automaattisesti luotu koodia eri kielillä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/tn5nno.png" width="500" className="m-auto" /></p>

Osittainen koodiesimerkki on seuraava:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/localization/translate' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "input": "# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.",
  "locale": "zh-CN",
  "extension": "md"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/localization/translate"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "# Title 1\n\nThis is a paragraph.\n\n## Title 2\n\nThis is another paragraph.",
    "locale": "zh-CN",
    "extension": "md"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Vastausesimerkki

Kun pyyntö onnistuu, API palauttaa käännöstehtävän tulos tiedot. Esimerkiksi:

```json
{
  "data": "# 标题 1\n\n这是一个段落。\n\n## 标题 2\n\n这是另一个段落。",
  "usage": {
    "prompt_tokens": 172,
    "completion_tokens": 25
  },
  "model": "gpt-3.5-turbo-16k",
  "locale": "zh-CN"
}
```

Voit nähdä, että tuloksessa on `data`-kenttä, joka sisältää käännetyn kiinan, ja se palautetaan markdown-muodossa. Muut tiedot ovat seuraavat:

- `data`, tämän käännöstehtävän tulos.
- `model`, tämän käännöstehtävän käyttämä suuri kielimalli.
- `locale`, tämän käännöstehtävän käännöskielityyppi.

## Virheiden käsittely

Kun kutsut API:a, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liikaa pyyntöjä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
