---
title: "Qwen Image tehtäväkysely API"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/tasks` käytetään Qwen Image asynkronisten tehtävien kyselyyn, joukkokyselyyn tai poistamiseen. Tämä rajapinta ei aiheuta ylimääräisiä API-kustannuksia.

## Yksittäisen tehtävän kysely

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Tehtävän valmistuttua, `response.data` sisältää pysyvän CDN-kuvan osoitteen, `response.usage` sisältää todellisen syötteen/ulostulon määrän, ja `response.cost` on tehtävän laskentatiedot.

## Joukkokysely

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Palauttaa `{ "items": [...], "count": 2 }`. Luettelokysely tukee myös suodattamista käyttäjän, sovelluksen ja luontiajan mukaan.

## Tehtävähistorian poistaminen

```json
{"action":"delete","id":"TASK_ID"}
```

Poistaminen vaikuttaa vain tehtävähistorian tietoihin, eikä se poista jo luotuja CDN-tiedostoja.
