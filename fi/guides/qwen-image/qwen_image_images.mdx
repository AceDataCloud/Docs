`POST https://api.acedata.cloud/qwen-image/images` suorittaa samalla rajapinnalla tekstistä kuvaksi -luonnin ja 1–3 viitekuvan muokkauksen, tukien malleja `qwen-image-3.0` ja `qwen-image-3.0-pro`.

## Mallin valinta

| Malli                | Sopivat tilanteet       | Virallinen vakiohinta       |
| -------------------- | ----------------------- | --------------------------- |
| `qwen-image-3.0`     | Eräluonti, nopea iterointi | Tuloste $0.030/kuva      |
| `qwen-image-3.0-pro` | Monimutkainen taitto, erittäin tarkka lopputulos | 1K $0.040/kuva; 2K $0.075/kuva |

Viitekuvista veloitetaan todellisen syötetyn määrän mukaan, virallinen vakiohinta $0.003/kuva.

## Synkroninen luonti

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "A simple red circle centered on a clean white background.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

Onnistunut vastaus sisältää pysyvän CDN-kuvaosoitteen, todellisen usagen ja tämän kerran kustannuksen:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Viitekuvan muokkaus

Lisää `image_urls`, joka tukee 1–3 julkisesti saatavilla olevaa kuvaa:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "保留主体，将背景改成暖色电影海报风格",
  "image_urls": [
    "https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"
  ],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` on tarkoitettu vain tekstistä kuvaksi -luontiin. `n`-arvon alue on 1–6; kuvasuhteen on oltava välillä 1:8–8:1.

## Asynkroniset tehtävät

Kun asetetaan `async: true`, rajapinta palauttaa välittömästi `task_id`:n. Käytä `/qwen-image/tasks`-osoitetta lopputilan kyselyyn tai anna `callback_url` vastaanottaaksesi valmistumisilmoituksen. Luonnista veloitetaan vain kerran, eikä tehtäväkyselyistä veloiteta uudelleen.
