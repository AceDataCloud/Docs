SeeDance Tasks API:n päätoiminto on kysyä tehtävän suoritustilaa syöttämällä SeeDance Video Generation API:n tuottama tehtävä-ID.

Tässä asiakirjassa käsitellään SeeDance Tasks API:n integrointia, jotta voit helposti hyödyntää tämän API:n voimakkaita ominaisuuksia. SeeDance Tasks API:n avulla voit helposti tarkistaa SeeDance Video Generation API:n tehtävien suoritustilan.

## Hakuprosessi

Käyttääksesi SeeDance Tasks API:a, sinun on ensin mentävä hakusivulle [SeeDance Video Generation API](https://platform.acedata.cloud/documents/seedance-videos) ja haettava vastaavaa palvelua, sitten kopioi SeeDance Video Generation API:n tehtävä-ID, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" class="m-auto"></p>

Lopuksi siirry Tasks API -sivulle [SeeDance Tasks API](https://platform.acedata.cloud/documents/seedance-tasks) ja hae vastaavaa palvelua, siirryttyäsi sivulle, napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![Hakusivu](https://cdn.acedata.cloud/rci31i.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti [kirjautumissivulle](https://platform.acedata.cloud), jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joita voit käyttää API:n ilmaiseksi.

## Pyyntöesimerkki

SeeDance Tasks API:a voidaan käyttää SeeDance Video Generation API:n tulosten tarkistamiseen. Tietoa SeeDance Video Generation API:n käytöstä löytyy asiakirjasta [SeeDance Video Generation API](https://platform.acedata.cloud/documents/seedance-videos-integration).

Otetaan esimerkki yhdestä SeeDance Video Generation API:n palauttamasta tehtävä-ID:stä ja näytetään, kuinka tätä API:a käytetään. Oletetaan, että meillä on tehtävä-ID: 20068983-0cc9-4c6a-aeb6-9c6a3c668be0, seuraavaksi näytetään, kuinka syötetään tämä tehtävä-ID.

### Pyyntöotsikon ja -kehon asettaminen

**Request Headers** sisältää:

- `accept`: määrittää, että vastaanotetaan JSON-muotoisia vastauksia, tässä täytetään `application/json`.
- `authorization`: API:n kutsuavain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

**Request Body** sisältää:

- `id`: ladattu tehtävä-ID.
- `action`: tehtävän toimintatapa.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/seedance/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "a6e0d456-189b-4c78-9232-2fe72166ab39",
  "action": "retrieve"
}'
```

Virheiden käsittely

Kun API:ta kutsutaan, jos virheitä ilmenee, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
