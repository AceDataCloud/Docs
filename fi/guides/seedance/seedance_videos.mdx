Tässä artikkelissa esitellään SeeDance Videos Generation API -integrointiohjeet, joiden avulla voidaan luoda SeeDancen virallisia videoita syöttämällä mukautettuja parametreja.

## Hakuprosessi

Jos haluat käyttää SeeDance Videos Generation API:a, hanki ensin [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) API Token -tunnuksesi ja säilytä se myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Token -tunnuksella voit kutsua kaikkia alustan palveluita, eikä sinun tarvitse hakea kutakin palvelua erikseen.** Ensimmäisen hakemuksen yhteydessä saat ilmaista käyttökiintiötä, joten voit kokeilla palvelua maksutta; kun kiintiö ei riitä, voit ladata yleistä saldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [SeeDance Videos Generation API →](https://platform.acedata.cloud/documents/seedance-videos)

## Peruskäyttö

Tutustutaan ensin peruskäyttötapaan: syötä kehote `content.text`, tyyppi `content.type=text` sekä malli `model`, niin saat käsitellyn tuloksen. Tarkat tiedot ovat seuraavat:

<p><img src="https://cdn.acedata.cloud/seedance_parameters.png" width="500" className="m-auto" /></p>

Voidaan nähdä, että tässä asetamme Request Headers -otsakkeet, mukaan lukien:

- `accept`: millaisessa muodossa haluat vastaanottaa vastaustuloksen; tähän syötetään `application/json`, eli JSON-muoto.
- `authorization`: API-kutsun avain, jonka voi valita suoraan pudotusvalikosta hakemisen jälkeen.

Lisäksi asetetaan Request Body, mukaan lukien:

- `model`: videon luomiseen käytettävä malli.
  - **Seedance 1.x -sarja**: `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`, `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-lite-t2v-250428`, `doubao-seedance-1-0-lite-i2v-250428`.
  - **Seedance 2.0 -sarja** (tukee hahmojen sekä ääni- ja videomonimodaalisia viitteitä): `doubao-seedance-2-0-260128` (vakio), `doubao-seedance-2-0-fast-260128` (nopea), `doubao-seedance-2-0-mini-260615` (kevyt).
  - **Seedance 2.5**: `doubao-seedance-2-5-260628`, tukee enintään 30 sekuntia, pelkkiä ääniviitteitä, enemmän materiaaleja, videoeditointia ja pidentämistä.
- `content`: syöttösisältötaulukko, jossa `type` voi olla `text` (kehote), `image_url` (viitekuva), `audio_url` (viiteääni), `video_url` (viitevideo). Kuville voidaan määrittää käyttötarkoitus `role`-kentällä: `first_frame` (ensimmäinen ruutu) / `last_frame` (viimeinen ruutu) / `reference_image` (hahmo- / kohdeviite).
- `resolution`: tulostusresoluutio, valittavissa `480p` / `720p` / `1080p` / `4k`. 2.5 tukee 480p:tä, 720p:tä ja 1080p:tä; 2.0 Fast/Mini tukee 480p:tä ja 720p:tä; 2.0 Standard tukee enintään 4k:ta.
- `ratio`: kuvasuhde, valittavissa `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive`.
- `duration`: videon kesto (sekunteina, kokonaisluku). 1.0-sarja 2–12; 1.5 Pro 4–12; 2.0-sarja 4–15; 2.5 on 4–30. 1.5/2.x tukee `-1`-arvoa (automaattinen kesto).
- `seed`: satunnaissiemen, kokonaisluku väliltä -1–4294967295.
- `camerafixed`: lukitaanko kamera, `true` / `false`.
- `watermark`: lisätäänkö vesileima, `true` / `false`.
- `generate_audio`: luodaanko videolle ääni, `true` / `false`; Seedance 1.5 Pro ja 2.x -sarja tukevat tätä.
- `return_last_frame`: palautetaanko tuloksessa videon viimeisen ruudun kuvan URL-osoite.
- `omni_reference_task_type`: vain 2.5; `auto` / `reference` / `edit` / `extend`.
- `output_format`: vain 2.5; `mp4` / `mov`, oletusarvoisesti `mp4`.
- `tools`: vain 2.5; tällä hetkellä tuetaan `web_search`-verkkohakutyökalua, jolla voidaan rajoittaa tulosten määrää, avainsanojen määrää ja hakulähteitä.
- `priority`: 2.5:n valinnainen tehtäväprioriteetti, kokonaisluku 0–9, oletusarvo 0.
- `safety_identifier`: vakaa anonyymi loppukäyttäjätunniste, enintään 64 merkkiä; käytä hashia tai sisäistä anonyymiä ID:tä, älä välitä nimeä, sähköpostia tai puhelinnumeroa.
- `execution_expires_after`: tehtävän aikakatkaisuaika (sekunteina), alue 3600–259200.
- `callback_url`: asynkroninen takaisinsoitto-osoite; asetuksen jälkeen API palauttaa välittömästi `task_id`-arvon, ja tehtävän valmistuttua tulos POSTataan tähän osoitteeseen.
- `async`: valinnainen; kun asetetaan arvoksi `true`, rajapinta palauttaa välittömästi `task_id`-arvon ilman `callback_url`-osoitetta, minkä jälkeen tulos haetaan kyselevällä polling-menetelmällä vastaavan tehtävän kyselyrajapinnan kautta.

## Sisäisten parametrien kuvaus

`content[].text`-kehotteen loppuun voidaan lisätä generointiparametreja muodossa `--parameter value` (vanha tapa, heikko validointi, virheellisellä täytöllä käytetään automaattisesti oletusarvoa). Täydellinen parametriluettelo on seuraava:

| Sisäinen parametri       | Vastaava kenttä              | Kuvaus      | Arvoalue                                                          |
| ---------- | ----------------- | ------- | ------------------------------------------------------------- |
| `--rs`     | `resolution`      | Tulostarkkuus   | `480p` / `720p` / `1080p`                                     |
| `--rt`     | `ratio`           | Kuvasuhde     | `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` |
| `--dur`    | `duration`        | Videon kesto (sekunteina) | 2–12                                                          |
| `--frames` | `frames`          | Videokehysten määrä    | Kokonaisluvut välillä [29, 289], jotka täyttävät ehdon 25+4n (**vain 1.0-sarja tukee**)                       |
| `--fps`    | `framespersecond` | Kuvataajuus      | Tukee vain arvoa `24`                                                      |
| `--seed`   | `seed`            | Satunnaissiemen    | -1–4294967295                                               |
| `--cf`     | `camerafixed`     | Onko kamera kiinteä | `true` / `false`                                              |
| `--wm`     | `watermark`       | Lisätäänkö vesileima  | `true` / `false`                                              |

> **Suositeltu tapa**: käytä vastaavia ylimmän tason kenttiä (kuten `resolution`, `ratio` jne.) suoraan Request Bodyssa. Tämä on vahvan validoinnin tila, jossa virheellisistä parametreista palautetaan selkeä virheilmoitus, mikä helpottaa ongelmien selvittämistä.

## Äänellisten videoiden generointi

Seedance 1.5 Pro- ja 2.x-sarjat tukevat ääntä sisältävien videoiden generointia `generate_audio`-parametrin avulla:

```json
{
  "model": "doubao-seedance-1-5-pro-251215",
  "content": [
    {
      "type": "text",
      "text": "A girl holds a fox, the wind blows her hair, you can hear the sound of the wind"
    }
  ],
  "generate_audio": true,
  "ratio": "16:9",
  "duration": 5
}
```

1.0-sarja ei tue tätä parametria.

## Seedance 2.5:n kokonaismultimodaalinen generointi, muokkaus ja pidennys

`doubao-seedance-2-5-260628` tukee 480p / 720p / 1080p -tarkkuuksia, 4–30 sekuntia tai automaattista kestoa, ja nostaa materiaalien ylärajan 30 viitekuvaan, 10 viitevideoon ja 10 viiteääneen (yhteensä enintään 50). 2.5 tukee myös pelkän viiteäänen välittämistä eikä enää edellytä kuvan tai videon tarjoamista samanaikaisesti.

Tavallisessa kokonaismultimodaalisessa generoinnissa `omni_reference_task_type` voidaan jättää pois, asettaa arvoon `auto` tai määrittää eksplisiittisesti arvoksi `reference`. Videon muokkaus ja pidennys edellyttävät `reference_video`-kentän välittämistä:

```json
{
  "model": "doubao-seedance-2-5-260628",
  "content": [
    {"type": "text", "text": "Replace the sky with a warm sunset while preserving the subject and camera motion."},
    {"type": "video_url", "role": "reference_video", "video_url": {"url": "https://cdn.acedata.cloud/input.mp4"}}
  ],
  "resolution": "720p",
  "ratio": "adaptive",
  "duration": -1,
  "omni_reference_task_type": "edit",
  "output_format": "mov"
}
```

- `reference`: välitä vähintään yksi `reference_image`, `reference_video` tai `reference_audio`; 2.5 tukee pelkän viiteäänen välittämistä.
- `edit`: on käytettävä arvoja `ratio: adaptive` ja `duration: -1`; tulosteen kesto laskutetaan todellisen tuloksen mukaan.
- `extend`: on käytettävä arvoa `ratio: adaptive`; `duration` voi olla 4–30 tai `-1`.
- `auto`: malli valitsee automaattisesti generoinnin, muokkauksen tai pidennyksen kehotteen ja materiaalien perusteella.
- Kun tehtävätyyppi ei vastaa materiaaleja tai kehotetta, tehtävä epäonnistuu ja palauttaa paikannettavan parametrivirheen; säädä se yllä olevien rajoitusten mukaisesti ja lähetä uudelleen.

## Kuvasta videoksi -videon ensimmäinen kehys

Jos haluat kuvasta videoksi -tehtävän, `content`-parametrin on ensin sisällettävä kohde, jonka `type` on `image_url`, ja `image_url`-kentän on oltava objektimuodossa: `{"url": "https://..."}` tai Base64-muodossa `{"url": "data:image/png;base64,..."}`.

> **Huomautus**: `image_url` ei tue merkkijonomuodon suoraa välittämistä (kuten `"image_url": "https://cdn.acedata.cloud/e724d7f13d.png"`), vaan objektimuotoa `"image_url": {"url": "https://..."}` on käytettävä, muuten palautetaan 400-virhe.

Vastaava koodi:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": [
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/i2v_foxrgirl.png"
            }
        },
        {
            "type": "text",
            "text": "A girl holds a fox in her arms. She opens her eyes and gazes tenderly at the camera, while the fox affectionately holds her back. As the camera slowly pulls away, her hair is gently blown by the wind. --ratio adaptive  --dur 5"
        }
    ],
    "model": "doubao-seedance-1-0-pro-250528"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Suorita napsauttamalla, ja voit huomata saavasi välittömästi tuloksen seuraavasti:

```
{
  "success": true,
  "task_id": "dc7cceb5-3c12-4de7-a5f4-abcbba3e8e39",
  "trace_id": "b3b09de3-b7fa-4bb0-88b5-aad4b4a96fd4",
  "data": {
    "task_id": "cgt-20251222072003-x2259",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/6afb78b8-5ba8-424f-adcd-69423a700b50.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

Voidaan nähdä, että generointitehoste on kuvasta videoksi -videon luonti, ja tulos on samanlainen kuin edellä.

## Kuvasta videoksi -videon ensimmäinen ja viimeinen kehys

Jos haluat kuvasta videoksi -videon ensimmäisen ja viimeisen kehyksen, `content`-parametrin on ensin välitettävä tyyppi `image_url`, ja `role` on asetettava vastaavasti arvoihin `first_frame` ja `last_frame`, jolloin voidaan määrittää seuraava sisältö:

- role: määrittää ensimmäisen tai viimeisen kehyksen.
- image_url
  - url-kuvalinkki
    Samanaikaisesti `content`-kenttään on myös syötettävä tyyppi `text` prompt-kehotteena

Vastaava koodi:
```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
   "model": "doubao-seedance-1-0-pro-250528",
    "content": [
         {
            "type": "text",
            "text": "360-degree shot"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_first_frame.jpeg"
            },
            "role": "first_frame"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_last_frame.jpeg"
            },
            "role": "last_frame"
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Napsauttamalla suorita voidaan havaita, että tulos saadaan välittömästi seuraavasti:


Voidaan nähdä, että luotu tehoste on hahmon videonluonti, ja tulos on samanlainen kuin edellä.

## Hahmo- sekä ääni- ja videomonimodaaliset viitteet (Seedance 2.0)

**Seedance 2.0 -sarja** (`doubao-seedance-2-0-260128`, `doubao-seedance-2-0-fast-260128`, `doubao-seedance-2-0-mini-260615`) tukee `reference_image`-, `reference_audio`- ja `reference_video`-viitteitä. Voit käyttää omia tai käyttöoikeuden saaneita materiaaleja säilyttääksesi hahmon, kohteen, toiminnan, kameratyön, äänen ja rytmin yhdenmukaisuuden.

> Lataa vain omia tai käyttöoikeuden saaneita oikeiden ihmisten ja hahmojen materiaaleja. Eri mallit tukevat oikeiden ihmisten materiaaleja eri tavoin; pyyntömuoto säilyy muuttumattomana, ja jos materiaali ei täytä vaatimuksia, palautetaan selkeä virhe.

Käyttöön liittyvät keskeiset kohdat:

- Vain **Seedance 2.0 -sarjan** mallit tukevat `reference_image`-viitettä; käytä 1.x-malleissa `first_frame` / `last_frame` -asetuksia (kuvasta videoksi -toiminnon alku- ja loppuruudut).
- Kuvasta videoksi -toiminnon aloitusruutu, kuvasta videoksi -toiminnon alku- ja loppuruudut sekä täysimodaalinen viite ovat kolme toisensa poissulkevaa käyttötapausta: `first_frame` / `last_frame` -asetuksia ei voi käyttää yhdessä `reference_image` / `reference_video` / `reference_audio` -asetusten kanssa.
- Jos haluat määrittää alku- ja loppuruudut täysimodaalisessa viitteessä, merkitse kuvat `reference_image`-viitteiksi ja kirjoita kehotteeseen “kuva 1 aloitusruutuna” tai “kuva 2 loppuruutuna”; jos alku- ja loppuruudut täytyy lukita tiukasti, käytä vain `first_frame` / `last_frame` -asetuksia.
- Monimodaalisten viitteiden enimmäismäärä: `image_url` enintään **9** kuvaa; 2.0 tukee lisäksi `audio_url`-osoitteita (`role` on `reference_audio`, enintään 3 kpl) ja `video_url`-osoitteita (`role` on `reference_video`, enintään 3 kpl).
- **Viiteäänen (`audio_url`) materiaalivaatimukset**: muodot `wav` / `mp3`; **yksittäisen tallenteen kesto 2–15 sekuntia**, enintään 3 tallennetta ja **kokonaiskesto enintään 15 sekuntia**; yksittäinen tallenne enintään 15 Mt. Kestoalueen ylittäminen aiheuttaa epäonnistumisen materiaalin käsittelyvaiheessa.
- **Viitevideoiden (`video_url`) materiaalivaatimukset**: muodot `mp4` / `mov`; **yksittäisen videon kesto 2–15 sekuntia**, enintään 3 videota ja **kokonaiskesto enintään 15 sekuntia**.
- Viitekuvissa suositellaan käytettäväksi **yksittäisen henkilön, edestä otettuja, selkeitä ja esteettömiä** valokuvia; mitä selkeämmät kasvot ovat, sitä suurempi on samankaltaisuus.

### Esimerkki kaksi: sijoita sama henkilö täysin uuteen ympäristöön

`reference_image`-viitteen vahvuus on siinä, että vain **henkilön identiteetti** säilytetään, kun taas ympäristö, vaatetus ja toiminta määräytyvät täysin kehotteen perusteella. Alla käytetään samaa kasvokuvaa, jotta henkilö kävelee beigen takin yllään syksyisessä puistossa:

```json
{
  "model": "doubao-seedance-2-0-fast-260128",
  "content": [
    {
      "type": "text",
      "text": "The same woman wearing a beige coat walks through a sunny autumn park, golden leaves falling around her, she smiles softly at the camera, cinematic tracking shot."
    },
    {
      "type": "image_url",
      "role": "reference_image",
      "image_url": {
        "url": "https://cdn.acedata.cloud/assets/examples/nanobanana/8e075897-0f50-4443-8500-666751791c6c-4346f66287c0.jpg"
      }
    }
  ],
  "resolution": "720p",
  "ratio": "9:16",
  "duration": 5
}
```

Palautettu tulos on seuraava: henkilön ulkonäkö säilyy, mutta ympäristö on vaihtunut syksyiseksi puistoksi:

## Asynkroninen takaisinsoitto

Koska SeeDance Videos Generation API:n luontiaika on pitkä (noin 1–2 minuuttia), voit käyttää asynkronista tilaa `callback_url`-kentän kautta välttääksesi HTTP-yhteyden pitkäaikaisen varauksen.

Kokonaisprosessi: asiakas määrittää `callback_url`-osoitteen pyynnön lähettämisen yhteydessä, ja API palauttaa välittömästi `task_id`-tunnuksen sisältävän vastauksen; tehtävän valmistuttua alusta lähettää luontituloksen POST JSON -muodossa `callback_url`-osoitteeseen, ja tulos sisältää myös `task_id`-tunnuksen yhdistämistä varten.

```json
{
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd"
}
```

Kun tehtävä valmistuu, alusta lähettää `callback_url`-osoitteeseen seuraavan sisällön:

```json
{
  "success": true,
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd",
  "trace_id": "4a4a3721-00fb-43d2-aff2-3b516ac01a8a",
  "data": {
    "task_id": "cgt-20251222073134-54qcw",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

Tuloksen `task_id`-kenttä vastaa pyynnön yhteydessä palautettua kenttää, ja tämän kentän avulla tehtävät voidaan yhdistää toisiinsa.

## Virheenkäsittely

Jos API:a kutsuttaessa kohdataan virhe, API palauttaa vastaavan virhekoodin ja -viestin. Esimerkiksi:

- `400 token_mismatched`：Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Ei valtuutusta, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, palvelimella tapahtui jokin virhe.
