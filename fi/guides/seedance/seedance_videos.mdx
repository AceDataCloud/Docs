Tässä artikkelissa esitellään SeeDance Videos Generation API -liittymisohje, jonka avulla voidaan luoda SeeDance-virallisia videoita syöttämällä mukautettuja parametreja.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [SeeDance Videos Generation API](https://platform.acedata.cloud/documents/seedance-videos) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi napsauta "Acquire"-painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joita voit käyttää API:ta ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttää kehotteet `content.text`, tyyppi `content.type=text` sekä malli `model`, jolloin saat käsitellyn tuloksen. Tarkat tiedot ovat seuraavat:

<p><img src="https://cdn.acedata.cloud/seedance_parameters.png" width="500" class="m-auto"></p>

Voit nähdä, että olemme asettaneet Request Headers, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu Request Body, joka sisältää:

- `model`: videon luomiseen käytettävä malli, valittavissa: `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`, `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-lite-t2v-250428`, `doubao-seedance-1-0-lite-i2v-250428`.
- `content`: syötteen sisältötaulukko, `type` voi olla `text` tai `image_url`.
- `resolution`: lähtöresoluutio, valittavissa `480p` / `720p` / `1080p`.
- `ratio`: kuvasuhde, valittavissa `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive`.
- `duration`: videon kesto (sekunteina), alue 2–12.
- `seed`: satunnainen siemen, kokonaisluku, -1 - 4294967295.
- `camerafixed`: onko kamera kiinteä, `true` / `false`.
- `watermark`: lisätäänkö vesileima, `true` / `false`.
- `generate_audio`: luodaanko äänivideo, `true` / `false`, **vain `doubao-seedance-1-5-pro-251215` tukee**.
- `service_tier`: päättelytila, `default` (verkkoyhteys) tai `flex` (offline, hinta 50 % verkkohinnasta).
- `return_last_frame`: palautetaanko tuloksena videon viimeisen kehyksen kuvan URL.
- `execution_expires_after`: tehtävän aikakatkaisu (sekunteina), alue 3600–259200.
- `callback_url`: asynkroninen palautusosoite, asetuksen jälkeen API palauttaa heti `task_id`:n, ja tehtävän valmistuttua tulos POSTataan tähän osoitteeseen.

Valinnan jälkeen voit huomata, että oikealle puolelle on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/seedance_request.png" width="500" class="m-auto"></p>

Napsauta "Try"-painiketta testataksesi, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavanlaisen tuloksen:

```json
{
  "success": true,
  "task_id": "ec22ae22-0140-4033-8c86-a48b536da595",
  "trace_id": "1cc87db0-8ee5-4436-969b-35cc571a9fd5",
  "data": {
    "task_id": "cgt-20251222005129-62fhb",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/f592800a-b87c-4705-8796-cbb8018cae35.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `success`, videon luontitehtävän tila.
- `task_id`, videon luontitehtävän ID.
- `trace_id`, videon luontitehtävän jäljitystunnus.
- `data`, videon luontitehtävän tulosluettelo.
  - `task_id`, videon luontitehtävän palvelinpuolen ID.
  - `video_url`, videon luontitehtävän videolinkki.
  - `status`, videon luontitehtävän tila.
    - `model`, videon luontiin käytetty malli.

Voimme nähdä, että olemme saaneet tyydyttävän videoinfon, ja meidän tarvitsee vain käyttää tuloksessa `data`:n videolinkkiä saadaksemme luodun SeeDance-videon.

Jos haluat luoda vastaavan liittymiskoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/seedance/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "content": [{"text":"A kitten yawning at the camera. --rs 720p --rt 16:9 --dur 5 --fps 24 --wm true --seed 11 --cf false","type":"text"}],
  "model": "doubao-seedance-1-0-pro-250528"
}'
```

## Inline-parametrien selitys

`content[].text` -kehotteen lopussa voit lisätä `--parameter value` -muodossa luontiparametreja (vanha tapa, heikko tarkistus, virheellisesti syötettäessä käytetään automaattisesti oletusarvoja). Täydellinen parametrilista on seuraava:

| Inline-parametri | Vastaa kenttää      | Selitys      | Arvoväli                                                          |
| ---------------- | ------------------- | ------------ | ------------------------------------------------------------- |
| `--rs`           | `resolution`        | Lähtöresoluutio   | `480p` / `720p` / `1080p`                                     |
| `--rt`           | `ratio`             | Kuvasuhde     | `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` |
| `--dur`          | `duration`          | Videon kesto (sekunteina) | 2–12                                                          |
| `--frames`       | `frames`            | Videon kehykset    | [29, 289] -alueen kokonaisluku, joka täyttää 25+4n               |
| `--fps`          | `framespersecond`   | Kehysnopeus      | Tukee vain `24`                                                  |
| `--seed`         | `seed`              | Satunnainen siemen    | -1 - 4294967295                                               |
| `--cf`          | `camerafixed`       | Onko kamera kiinteä | `true` / `false`                                              |
| `--wm`          | `watermark`         | Lisätäänkö vesileima  | `true` / `false`                                              |

> **Suositeltu käytäntö**: Käytä suoraan Request Bodyssa vastaavia ykköskenttiä (kuten `resolution`, `ratio` jne.), jotta käytetään vahvaa tarkistusmallia. Virheellisesti syötettäessä palautetaan selkeä virheilmoitus, mikä helpottaa ongelmien selvittämistä.

## Äänivideon luominen

`doubao-seedance-1-5-pro-251215` tukee äänivideon luomista `generate_audio`-parametrin avulla:

```json
{
  "model": "doubao-seedance-1-5-pro-251215",
  "content": [
    {
      "type": "text",
      "text": "A girl holds a fox, the wind blows her hair, you can hear the sound of the wind"
    }
  ],
  "generate_audio": true,
  "ratio": "16:9",
  "duration": 5
}
```
Muut mallit eivät tue tätä parametria, ja se ohitetaan, jos se syötetään.

## Kuvasta video ensimmäinen kehys

Jos haluat luoda videon kuvasta, ensinnäkin `content`-parametrin on sisällettävä `type`, joka on `image_url`, ja `image_url`-kentän on oltava objektimuodossa: `{"url": "https://..."}` tai Base64-muodossa `{"url": "data:image/png;base64,..."}`.

> **Huomio**: `image_url` ei tue suoran merkkijonomuodon syöttämistä (kuten `"image_url": "https://..."`), vaan sen on oltava objektimuodossa `"image_url": {"url": "https://..."}`; muuten se palauttaa 400 virheen.

Vastaava koodi:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": [
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/i2v_foxrgirl.png"
            }
        },
        {
            "type": "text",
            "text": "Tyttö pitää foxia sylissään. Hän avaa silmänsä ja katsoo hellästi kameraan, kun foxi pitää häntä hellästi takaisin. Kun kamera vetäytyy hitaasti, tuuli puhaltaa hänen hiuksiaan lempeästi. --ratio adaptive  --dur 5"
        }
    ],
    "model": "doubao-seedance-1-0-pro-250528"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kun napsautat suorita, voit huomata, että saat heti tuloksen, kuten alla:

```
{
    "success": true,
    "task_id": "dc7cceb5-3c12-4de7-a5f4-abcbba3e8e39",
    "trace_id": "b3b09de3-b7fa-4bb0-88b5-aad4b4a96fd4",
    "data": {
        "task_id": "cgt-20251222072003-x2259",
        "status": "succeeded",
        "video_url": "https://platform.cdn.acedata.cloud/seedance/6afb78b8-5ba8-424f-adcd-69423a700b50.mp4",
        "model": "doubao-seedance-1-0-pro-250528"
    }
}
```

Voit nähdä, että luotu efekti on kuvasta video, ja tulos on samanlainen kuin edellä.

## Kuvasta video ensimmäinen ja viimeinen kehys

Jos haluat luoda videon ensimmäisestä ja viimeisestä kehyksestä, ensinnäkin `content`-parametrin on syötettävä tyyppi `image_url`, ja `role` on asetettava `first_frame` ja `last_frame`, jolloin voit määrittää seuraavat sisällöt:

- role: määrittää ensimmäisen tai viimeisen kehyksen.
- image_url
  - url kuvalinkki
    Samalla `content`-kenttään on myös syötettävä tyyppi `text` promptti-viestinä.

Vastaava koodi:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
   "model": "doubao-seedance-1-0-pro-250528",
    "content": [
         {
            "type": "text",
            "text": "360 asteen kuva"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_first_frame.jpeg"
            },
            "role": "first_frame"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_last_frame.jpeg"
            },
            "role": "last_frame"
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kun napsautat suorita, voit huomata, että saat heti tuloksen, kuten alla:

```
{
    "success": true,
    "task_id": "f7096c6c-9430-4392-8201-d259632d7afd",
    "trace_id": "4a4a3721-00fb-43d2-aff2-3b516ac01a8a",
    "data": {
        "task_id": "cgt-20251222073134-54qcw",
        "status": "succeeded",
        "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",
        "model": "doubao-seedance-1-0-pro-250528"
    }
}
```

Voit nähdä, että luotu efekti on hahmojen luoma video, ja tulos on samanlainen kuin edellä.

## Asynkroninen palautus

Koska SeeDance Videos Generation API:n luomisaika on pitkä (noin 1-2 minuuttia), voit käyttää `callback_url`-kenttää asynkronisessa tilassa, jotta vältetään HTTP-yhteyden pitkäaikainen käyttö.

Kokonaisprosessi: asiakas aloittaa pyynnön määrittämällä `callback_url`, API palauttaa heti vastauksen, joka sisältää `task_id`; kun tehtävä on valmis, alusta lähettää luodut tulokset POST JSON -muodossa `callback_url`:iin, ja tuloksessa on myös `task_id`, jotta se voidaan yhdistää.

```json
{
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd"
}
```

Kun tehtävä on valmis, alusta työntää `callback_url`:iin seuraavan sisällön:

```json
{
  "success": true,
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd",
  "trace_id": "4a4a3721-00fb-43d2-aff2-3b516ac01a8a",
  "data": {
    "task_id": "cgt-20251222073134-54qcw",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

Tuloksen `task_id`-kenttä on sama kuin pyynnön aikana palautettu, ja tämän kentän avulla voit yhdistää tehtävät.

## Virheiden käsittely

Kun kutsut API:a, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
