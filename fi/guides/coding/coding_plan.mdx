## Dynaaminen mallihakemisto

Voit ensin avata [mallihakemiston](https://platform.acedata.cloud/models) nähdäksesi nykyiset mallinimet, esimerkiksi `claude-opus-5`, `gpt-6-sol`. Kun sinun on vahvistettava, että Coding-tunnistetiedot ja API-protokolla vastaavat toisiaan, tee pyyntö kelvollisilla Coding Application -tunnistetiedoilla:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

Mallihakemisto muuttuu jatkuvasti, eikä tässä ylläpidetä kiinteää määrää tai staattista malliluetteloa. Vastauksen jokaisen kohteen `id` on **mallinimi**, joka voidaan välittää suoraan API:n `model`-parametrille, esimerkiksi `{"id":"deepseek-v4-pro"}` vastaa arvoa `deepseek-v4-pro`; se ei ole palvelun, API:n tai Applicationin UUID. `/v1/models` palauttaa globaalin mallihakemiston, eikä sitä rajata automaattisesti Coding-tunnistetietojen mukaan; ennen määritystä on edelleen vahvistettava ristiin tunnistetietojen API scope, valittu protokolla ja asiakasohjelman yhteensopivuusalue.

## Yleinen vianmääritys

- **Saldo ei riitä**: siirry [Applications-konsoliin](https://platform.acedata.cloud/console/applications), etsi Coding Application ja uusi se aktiivisesti.
- **Asiakasohjelma pyytää edelleen alkuperäistä osoitetta**: varmista, että määritys kuuluu samalle käyttäjälle ja työtilalle, joka käynnistää asiakasohjelman, ja sulje asiakasohjelma kokonaan ennen sen uudelleenkäynnistämistä.
- **Mallinimi ei ole käytettävissä**: pyydä `/v1/models` uudelleen, tarkista, että annettu mallinimi vastaa täsmälleen hakemiston `id`:tä, sekä tunnistetietojen API scope ja asiakasohjelman tukema protokolla.
- **Token ei voi kutsua rajapintaa**: varmista, että tunnistetiedot kuuluvat Coding Applicationille, ja tarkista `allowed_api_ids` sekä sovelluksen API-käyttöoikeudet.
