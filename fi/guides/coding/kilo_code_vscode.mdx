## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API-avain.

![Hae Ace Data Cloud API -avain](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Lisää Custom provider

Avaa Kilo Codessa **Settings → Providers**, napsauta **Custom provider** ja täytä sitten:

| Kenttä           | Arvo                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------- |
| Provider ID  | `acedatacloud`                                                                                 |
| Display name | `AceDataCloud`                                                                                 |
| Provider API | `OpenAI Compatible`                                                                            |
| Base URL     | `https://api.acedata.cloud/v1`                                                                 |
| API key      | Juuri kopioitu API-avain                                                                       |
| Models       | Siirry [malliluetteloon](https://platform.acedata.cloud/models) tarkistamaan se ja lisää käytettävien mallien nimet, esimerkiksi `claude-opus-5`、`gpt-6-sol` |

![Kilo Code Custom provider -määritysnäkymä](https://cdn.acedata.cloud/94eb5abd7a6f.png)

Tässä mallin `id` on API-pyynnön `model`-parametrissa käytetty mallin nimi, ei palvelun tai API:n UUID. Voit ensin tarkistaa sen [malliluettelosta](https://platform.acedata.cloud/models); tarkan varmennuksen yhteydessä kopioi se sellaisenaan `/v1/models`-vastauksen `data`-taulukosta, älä arvaa tai lyhennä sitä itse.

Napsauta **Submit**, ja malli näkyy valitsimessa. Kun tarvitaan tiimin jakamista tai tarkempaa määritystä, voit myös muokata virallisten ohjeiden mukaisesti käyttäjätason `~/.config/kilo/kilo.jsonc`- tai projektitason `./kilo.jsonc`-tiedostoa.

## 3. Varmennus

Valitse `acedatacloud/MODEL_ID` ja lähetä `Vastaa vain OK`, ja suorita sitten kerran vain luku -tiedostotoiminto. Jos malli ei ilmesty, tarkista, onko Provider lähetetty, vastaako mallin nimi täsmälleen luettelon `id`:tä ja onko Base URL oikea.
