## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API-avain.

![Hanki Ace Data Cloud API-avain](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Tallenna avain

Kirjoita tiedostoon `~/.hermes/.env`:

```dotenv
ACEDATACLOUD_API_KEY=oma API-avaimesi
```

## 3. Määritä Provider

Lisää tiedostoon `~/.hermes/config.yaml`:

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

Siirry [malliluetteloon](https://platform.acedata.cloud/models) tarkistamaan mallin nimi (esimerkiksi `claude-opus-5`, `gpt-6-sol`) ja korvaa kaikki `MODEL_ID`-esiintymät samalla nimellä; tarkassa varmennuksessa käytä `/v1/models`-vastauksen `id`-arvoa. Tämä arvo on API:n `model`-parametrissa käytetty mallin nimi, ei palvelun tai API:n UUID. Älä kirjoita oikeaa avainta YAML-tiedostoon tai commitoi `.env`-tiedostoa.

## 4. Vahvista

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

Jos palautetaan 401, tarkista `~/.hermes/.env`; jos määritys ei tule voimaan, sulje Hermes kokonaan ja käynnistä se uudelleen.
