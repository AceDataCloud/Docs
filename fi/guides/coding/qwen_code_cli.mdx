Qwen Code käyttää `~/.qwen/settings.json` tiedoston `modelProviders` asetusta mukautetun Providerin määrittämiseen. Tässä käytetään kiinteästi OpenAI-yhteensopivaa protokollaa.

## Asetukset

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud` on oltava taulukko. Providerin kohteet on määritettävä erikseen, eikä ne automaattisesti peri muita ylimmän tason konteksteja, Header- tai body-parametreja.

## Vahvistus

```bash
export ACEDATACLOUD_API_KEY="LIITÄ_TÄHÄN_ACEDATACLOUD_API_TOKEN"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Vastaa vain OK"
```

Kirjaudu sisään ja lähetä `Vastaa vain OK`, sitten suorita uudelleen vain luku -työkalua. Jos tiukka yhteensopivuus päätepiste kieltäytyy työkalun tulosmuodosta, tarkista nykyinen Qwen Code -versio ja viralliset yhteensopivuusohjeet.
