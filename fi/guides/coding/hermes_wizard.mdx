## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API-avain.

![Hanki Ace Data Cloud API -avain](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Suorita opas

```bash
hermes model
```

Valitse **Custom endpoint** ja täytä seuraavat tiedot järjestyksessä:

| Kenttä             | Arvo                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | Juuri kopioitu API-avain                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | Siirry [malliluetteloon](https://platform.acedata.cloud/models) tarkistamaan ja täytä kohdemallin nimi sellaisenaan, esimerkiksi `claude-opus-5` tai `gpt-6-sol` |
| Context length | Jätä tyhjäksi automaattista tunnistusta varten tai täytä malliluettelon mukaisesti                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model` on mallin nimi, jota käytetään API-pyynnön `model`-parametrissa, ei palvelun tai API:n UUID. Voit tarkistaa sen ensin [malliluettelosta](https://platform.acedata.cloud/models); jos tarvitset tarkan vahvistuksen, käytä sitten nykyistä API-avainta pyytääksesi `GET https://api.acedata.cloud/v1/models` ja kopioi vastauksen `data`-taulukosta kohdemallin `id`-arvo.

Opas kirjoittaa tiedot kohteisiin `~/.hermes/config.yaml` ja paikalliseen tunnistetiedostoon.

## 3. Vahvistus

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

Jos opas ei tallentanut määritystä, voit suorittaa `hermes model --reset` ja yrittää uudelleen; 401 tarkoittaa, että API-avain on virheellinen tai nykyisen käyttäjän määritys ei lue sitä.
