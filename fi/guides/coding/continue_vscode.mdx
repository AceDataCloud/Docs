Continue tukee OpenAI-yhteensopivaa API:ta. Jotta Chat Completions -toiminto olisi käytössä, on asetettava erikseen `useResponsesApi: false`.

## Konfigurointi

Lisää Continue:n paikalliseen YAML-konfiguraatioon:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Tallenna Continue:n salaisuuksien hallintaan `ACEDATACLOUD_API_KEY`, äläkä lähetä oikeaa Tokenia projektin konfiguraatioon. Continue:n JSON-konfiguraatio on jo poistettu käytöstä, uusi konfiguraatio käyttää YAML:ia.

## Vahvistus

Lataa VS Code uudelleen, avaa Continue-sivupaneeli, valitse Local Config -osiossa malli ja lähetä `Reply only OK`; suorita sitten uudelleen vain luku -tiedostotehtävä. Jos pyyntö lähetetään virheellisesti `/responses`-osoitteeseen, tarkista, että `useResponsesApi: false` on kyseisen mallin kohdalla.
