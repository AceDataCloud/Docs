## 1. API-avaimen hankkiminen

Avaa [Ace Data Cloud -sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API-avain.

![Ace Data Cloud API -avaimen hankkiminen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Clinen määrittäminen

Asenna ja avaa Cline VS Codessa, siirry sitten Provider-määrityksiin Cline-paneelin asetuspainikkeen kautta ja täytä:

| Kenttä                                | Arvo                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| API Provider                      | `OpenAI Compatible`                                                                            |
| Base URL                          | `https://api.acedata.cloud/v1`                                                                 |
| API Key                           | Juuri kopioitu API-avain                                                                                  |
| Model ID                          | Siirry [malliluetteloon](https://platform.acedata.cloud/models) tarkistamaan ja täytä kohdemallin nimi sellaisenaan, esimerkiksi `claude-opus-5` tai `gpt-6-sol` |
| Custom Headers                    | Jätä tyhjäksi                                                                                             |
| Set Azure API version             | Jätä tyhjäksi                                                                                             |
| Use Azure Identity Authentication | Poista käytöstä                                                                                             |

![Cline OpenAI Compatible -määritysnäkymä](https://cdn.acedata.cloud/8f356c2f1378.png)

`Model ID` on API-pyynnön `model`-parametrissa käytettävä mallin nimi, ei palvelun tai API:n UUID, eikä sitä voi lyhentää itse. Voit tarkistaa sen ensin [malliluettelosta](https://platform.acedata.cloud/models); jos tarvitset tarkan vahvistuksen, pyydä nykyisellä API-avaimella `GET https://api.acedata.cloud/v1/models` ja kopioi kohdemallin `id`-arvo vastauksen `data`-taulukosta.

Pidä muiden malliominaisuuksien määritykset toistaiseksi oletusarvoisina; säädä niitä valitun mallin todellisten ominaisuuksien mukaan vasta, kun tarvitset kuvia tai suurempaa kontekstia.

## 3. Vahvistaminen

Luo tallentamisen jälkeen uusi tehtävä ja lähetä `Reply only OK`. Pyydä sitten Clinea lukemaan testitiedosto varmistaaksesi, että malli tukee työkalukutsuja; kutsulokit voi tarkistaa [käyttöhistoriasta](https://platform.acedata.cloud/console/usages).

401 tarkoittaa yleensä, että avain on virheellinen; 404 tarkoittaa yleensä, että Base URL ei ole oikea tai että annettu Model ID ei vastaa täysin luettelon `id`-arvoa. Jos malli pystyy keskustelemaan mutta ei käsittelemään tiedostoja, tarkista mallin työkalukutsuominaisuudet.
