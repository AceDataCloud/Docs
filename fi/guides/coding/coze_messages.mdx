Coze virallinen mukautettujen mallien dokumentaatio tukee Anthropic Messages API:ta. Eri Coze vuokraversiot voivat käsitellä Headeria, polkujen yhdistämistä, streamingia ja työkalukutsuja eri tavoin, joten tarkista ensimmäisellä kerralla alla olevat kohdat.

## Konfigurointi

1. Siirry Coze-mallinhallintaan ja lisää mukautettu malli.
2. Protokollaksi valitse Anthropic Messages API.
3. Täytä Base API URL:ksi `https://api.acedata.cloud`.
4. Täytä API Key:ksi oma Ace Data Cloud API Tokenisi.
5. Täytä Model:ksi mallihakemistossa Anthropic Messages -tukea tarjoavan tarkan mallin ID.
6. Tallenna ja suorita Cozen yhteystesti.
7. Lähetä Bot/Agentissa `Reply only OK`, ja testaa työkalukutsua uudelleen.

## Nykyiset rajat

- Eri Coze alueet, versiot tai paketit voivat näyttää erilaisia lomakkeita.
- Base API URL:ia ei tule toistaa lisäämällä `/v1/messages`; jos nykyinen UI selvästi vaatii täydellistä API URL:ia, noudata lomakkeen ohjeita.
- Messages, Chat Completions ja Responses ovat kolme erillistä reittiä, joita ei voi korvata toistensa vahvistamisessa.
