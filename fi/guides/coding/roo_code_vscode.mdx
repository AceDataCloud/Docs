## 1. API-avaimen hankkiminen

Avaa [Ace Data Cloud -sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API-avain.

![Ace Data Cloud API-avaimen hankkiminen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Määritys

Roo Code tarjoaa virallisesti OpenAI-yhteensopivan Providerin ja edellyttää, että malli tukee natiiveja OpenAI tools/function calling -toimintoja.

1. Avaa Roo Code -asetukset VS Codessa.
2. Aseta **API Provider** arvoon **OpenAI Compatible**.
3. Täytä:

| Kenttä       | Arvo                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | Juuri kopioitu API-avain                  |
| Model ID | Coding-määritysoppaassa valittu mallin ID         |

![Roo Code OpenAI Compatible -määritysnäkymä](https://cdn.acedata.cloud/b6a0e7156438.png)

Aseta sitten context-, max output-, kuva- ja computer-use-vaihtoehdot mallin todellisten ominaisuuksien mukaisesti. Tallenna lopuksi määritys ja lataa VS Code uudelleen.

## 3. Vahvistus

Lähetä ensin `Reply only OK`, ja pyydä sitten Roo Codea lukemaan testitiedosto. Jos tavallinen keskustelu onnistuu mutta Agent-työkalu epäonnistuu, vaihda malliin, joka tukee natiivia tool callingia, ja varmista, että yhteensopiva päätepiste voi palauttaa työkalun parametrit ja tulokset oikein suoratoistona.
