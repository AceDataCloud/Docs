## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusten luettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä oleviin sovelluksiin ja kopioi API-avain.

![Hanki Ace Data Cloud API-avain](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Määritä Provider

Kilo Code -sovelluksen JetBrains-laajennus käyttää `kilo.jsonc` Provider -muotoa. Määrittelyn on oltava käyttäjän ympäristössä, jossa laajennusta ajetaan; etäkehityksessä se on yleensä etäbackend-isäntä.

Kirjoita `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Vie `ACEDATACLOUD_API_KEY` ympäristössä, jossa JetBrains backend käynnistetään, ja käynnistä IDE tai etäbackend uudelleen.

## 3. Vahvista

Valitse `acedatacloud/MODEL_ID`, lähetä `Reply only OK`, ja anna Agentin lukea testitiedosto. Jos paikallisesti toimii mutta etänä epäonnistuu, tarkista ensin, onko konfigurointitiedosto ja ympäristömuuttujat kirjoitettu etäisäntään.
