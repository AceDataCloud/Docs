## 1. Hanki API-avain

Avaa [Ace Data Cloud sovellusten lista](https://platform.acedata.cloud/console/applications), siirry käytettävissä oleviin sovelluksiin ja kopioi API-avain.

![Hanki Ace Data Cloud API-avain](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Konfigurointi

Kilo CLI lukee `kilo.jsonc` ja ottaa API-avaimen käyttöön CLI:n käynnistämisen shellistä.

Kirjoita `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Sitten vie Token nykyisessä shellissä:

```bash
export ACEDATACLOUD_API_KEY="LIITÄ_TÄNNE_ACEDATACLOUD_API_TOKEN"
```

## 3. Vahvistus

```bash
kilo run -m acedatacloud/MODEL_ID "Vastaa vain OK"
```

Jos CLI ei pysty lukemaan Tokenia, varmista, että muuttuja on jo `export`-tilassa, eikä vain kirjoitettu lataamattomaan `.env`-tiedostoon.
