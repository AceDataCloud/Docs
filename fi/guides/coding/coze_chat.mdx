Coze virallinen mukautettujen mallien dokumentaatio tukee OpenAI Chat API:ta. Eri Coze vuokraversiot voivat käsitellä polkujen yhdistämistä, virtaavaa ulostuloa ja työkalujen kutsuja eri tavoin, joten tarkista ensimmäisellä kerralla alla olevat kohdat.

## Konfigurointi

1. Siirry Coze-mallinhallintaan ja lisää mukautettu malli.
2. Protokollaksi valitse OpenAI Chat API.
3. Perus API URL täytä `https://api.acedata.cloud/v1`.
4. API-avain täytä Ace Data Cloud API Tokenisi.
5. Malli täytä mallihakemistossa tuetun Chat Completions tarkka mallin ID.
6. Tallenna ja suorita Cozen yhteystesti.
7. Lähetä Bot/Agentissa `Reply only OK`, ja testaa työkalun kutsu uudelleen.

## Nykyiset rajat

- Eri Coze alueet, versiot tai paketit voivat näyttää erilaisia lomakkeita.
- Perus API URL:n tulisi käyttää basea, älä lisää `/chat/completions` uudelleen; jos nykyinen käyttöliittymä selvästi vaatii täydellistä API URL:ia, noudata lomakkeen ohjeita.
- Chat Completions, Responses ja Anthropic Messages ovat kolme erillistä reittiä, joita ei voi käyttää toistensa vahvistamiseen.
