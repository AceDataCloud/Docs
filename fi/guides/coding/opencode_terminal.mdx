## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API-avain.

![Hanki Ace Data Cloud API-avain](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Asenna OpenCode

```bash
curl -fsSL https://opencode.ai/install | bash
```

Voit käyttää myös npm:ää:

```bash
npm install -g opencode-ai
```

## 3. Aseta API-avain

```bash
export ACEDATACLOUD_API_KEY="你的 API Key"
```

Jos haluat sen olevan voimassa pitkään, lisää tämä rivi tiedostoon `~/.zshrc` tai `~/.bashrc` ja avaa sitten pääte uudelleen.

## 4. Määritä Provider

Muokkaa tiedostoa `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ace Data Cloud",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  }
}
```

Siirry [malliluetteloon](https://platform.acedata.cloud/models) tarkastelemaan mallien nimiä (esimerkiksi `claude-opus-5`, `gpt-6-sol`) ja korvaa kaikki `MODEL_ID` samalla nimellä; tarkassa varmennuksessa käytä `/v1/models`-vastauksen `id`-arvoa. Tämä arvo on API:n `model`-parametrissa käytetty mallin nimi, ei palvelun tai API:n UUID. Ace Data Cloud käyttää tässä Chat Completionsia, joten adapteri on `@ai-sdk/openai-compatible`.

## 5. Vahvista ja käynnistä

```bash
opencode auth list
opencode models acedatacloud
opencode run --model acedatacloud/MODEL_ID "Reply only OK"
```

Suorita sitten `opencode` projektihakemistossa. Jos malli ei näy, tarkista määritystiedoston polku, JSON-syntaksi ja ympäristömuuttujat; 401 tarkoittaa, että Key on virheellinen tai sitä ei ole viety.

IDE-laajennus käyttää samaa OpenCode runtime -määritystä, katso [OpenCode IDE Extension](https://platform.acedata.cloud/documents/opencode-ide-integration).
