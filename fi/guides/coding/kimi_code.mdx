## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API-avain.

![Ace Data Cloud API -avaimen hankkiminen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Asenna Kimi Code

macOS / Linux:

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

Voit asentaa myös npm:n kautta:

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. Määritä AceDataCloud

Muokkaa tiedostoa `~/.kimi/config.toml` ja lisää seuraava määritys:

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "你的 API Key"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

Siirry [malliluetteloon](https://platform.acedata.cloud/models) tarkistamaan mallin nimi (esimerkiksi `claude-opus-5`, `gpt-6-sol`) ja korvaa kaikki `MODEL_ID`-esiintymät samalla nimellä; tarkassa tarkistuksessa käytä `/v1/models`-vastauksen `id`-arvoa. Tämä arvo on API:n `model`-parametrissa käytettävä mallin nimi, ei palvelun tai API:n UUID. `type = "openai"` käyttää OpenAI Chat Completions -protokollaa.

Määritystiedosto sisältää avaimen, joten macOS:ssä / Linuxissa on suositeltavaa rajoittaa käyttöoikeudet:

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. Vahvista ja käynnistä

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

Kun olet siirtynyt projektiin, suorita `kimi` aloittaaksesi käytön. Jos palautetaan 401, tarkista API-avain; jos näyttöön tulee model not found, varmista, että `default_model`, mallitaulun nimi ja `model`-kenttä käyttävät samaa ID:tä.
