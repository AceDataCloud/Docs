Aider yhdistää OpenAI-yhteensopivan API:n LiteLLM:n `openai/` mallin etuliitteen kautta.

## Asetukset

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

Korvaa `MODEL_ID` valitsemallasi mallilla Coding-asetusten ohjaimessa. Voit myös kirjoittaa vastaavat asetukset paikalliseen `.env` tai `.aider.conf.yml`, mutta älä lähetä todellista Tokenia.

## Vahvistus

```bash
aider --model openai/MODEL_ID --message "Vastaa vain OK"
```

Ensimmäisellä kerralla tuntemattomalla mallilla Aider saattaa ilmoittaa puuttuvasta mallin metatiedosta; tämä ei ole sama kuin todennuksen epäonnistuminen. 401 tarkistaa Tokenin, 404 tarkistaa mallin ID:n ja `/v1` Base URL:n.
