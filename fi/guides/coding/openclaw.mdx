## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusten luettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä oleviin sovelluksiin ja kopioi API-avain.

![Hanki Ace Data Cloud API-avain](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Asenna OpenClaw ja liitännät

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

Liitännät vaativat OpenClaw `2026.4.2` tai uudemman version, ja nykyisin ne tarjoavat natiivisti Chat- ja Web-hakuominaisuuksia.

## 3. Konfiguroi avain

Suositellaan käytettäväksi onboardingia:

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "oma API-avain"
```

Voit myös käyttää ympäristömuuttujia:

```bash
export ACEDATACLOUD_API_KEY="oma API-avain"
```

## 4. Valinnainen: manuaalinen konfigurointi

Jos et käytä onboardingia, ota liitännät käyttöön ja määritä oletusmalli tiedostossa `~/.openclaw/openclaw.json`:

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

Älä kirjoita API-avain tähän tiedostoon; jatka ympäristömuuttujien käyttöä.

## 5. Valitse malli ja varmista

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "Vastaa vain OK"
```

Korvaa `MODEL_ID` Coding Planin tällä hetkellä tarjoamalla mallilla. Jos se on asetettava oletusmalliksi, suorita:

```bash
openclaw models set acedatacloud/MODEL_ID
```

Kutsuhistoriaa voi tarkastella [käyttöhistoriassa](https://platform.acedata.cloud/console/usages). 401 tarkoittaa, että avain on virheellinen; jos mallia ei ole, tarkista ensin tarkka ID ja liitännän versio. Liitännän hakemistossa oleva `cost: 0` tarkoittaa vain, että OpenClaw ei arvioi uudelleen, todelliset kustannukset kirjataan edelleen Ace Data Cloudissa.

## Web-haku

```bash
openclaw infer web search \
  --provider acedatacloud --query "latest AI agent frameworks" --limit 5
```

Älä tällä hetkellä pidä liitännän esittelyssä olevia kuvia, videoita tai musiikkikykyjä OpenClawin natiivina Provider-kykynä.
