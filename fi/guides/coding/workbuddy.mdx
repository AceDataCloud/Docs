## 1. Hanki API Key

Avaa [Ace Data Cloud -sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API Key.

![Hanki Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Lisää malli

Siirry WorkBuddyssa kohtaan **Asetukset → Mallit → Mukautetut mallit → Lisää malli**, ja täytä sitten:

| Kenttä       | Arvo                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------ |
| Provider | `Custom`                                                                                         |
| Rajapintaosoite     | `https://api.acedata.cloud/v1`                                                                   |
| API Key  | Juuri kopioitu API Key                                                                                    |
| Mallin nimi     | Siirry [malliluetteloon](https://platform.acedata.cloud/models) tarkistamaan ja täytä kutsuttavan mallin nimi sellaisenaan, esimerkiksi `claude-opus-5`、`gpt-6-sol` |
| Mukautettu protokolla    | Pois käytöstä                                                                                               |

![WorkBuddy Custom Provider -määritysnäkymä](https://cdn.acedata.cloud/189027b68722.png)

> Tässä `id` on API-pyynnön `model`-parametrissa käytettävä mallin nimi, ei palvelun, API:n tai Applicationin UUID eikä mukautettu näyttönimi. Vain kun reaaliaikainen luettelo palauttaa `{"id":"ds-4.0"}`, voidaan täyttää `ds-4.0`; jos sitä ei ole luettelossa, se tarkoittaa, ettei se ole tällä hetkellä käytettävissä. Älä arvaa tai lyhennä sitä.

Voit ensin tarkistaa valittavissa olevat mallit [malliluettelosta](https://platform.acedata.cloud/models); jos tarvitset vahvistuksen siitä, mikä on nykyisillä Coding-tunnuksilla kutsuttavissa oleva tarkka nimi, kysy API-luetteloa juuri kopioidulla API Keyllä:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Etsi vastauksen `data`-taulukosta kohdemalli ja kopioi sen `id`-arvo sellaisenaan. Määritä kyvykkyyskytkimet mallin tosiasiallisen tuen mukaisesti.

Kun ”mukautettu protokolla” pidetään pois käytöstä, WorkBuddy täydentää polun OpenAI Chat Completions -sääntöjen mukaisesti. Ota käyttöön edistyneiden kyvykkyyksien kytkimet (työkalut, kuvat, päättely) vain valitun mallin tosiasiallisten kyvykkyyksien mukaisesti; jos olet epävarma, pidä ensin oletusasetukset.

## 3. Vahvista

Tallentamisen jälkeen valitse juuri lisätty malli chat-mallin valitsimessa ja lähetä `Vastaa vain OK`. Suorita sitten vielä vain luku -tiedosto- tai työkalutehtävä varmistaaksesi, että tarvittavat kyvykkyydet ovat käytettävissä; kutsutiedot voi tarkistaa [käyttöhistoriasta](https://platform.acedata.cloud/console/usages).

Jos malli ei tule näkyviin, varmista, että määritys on tallennettu ja otettu käyttöön; 401:ssä tarkista Key; 404:ssä tarkista, vastaako täytetty mallin nimi täysin luettelon `id`:tä ja onko rajapintaosoite oikein. WorkBuddyn virallisten ohjeiden mukaan Key tallennetaan paikalliseen määritykseen, mutta pyynnön sisältö lähetetään silti määritettyyn mallipalveluun.
