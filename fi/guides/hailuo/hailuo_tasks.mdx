Hailuo Tasks API:n päätoiminto on kysyä tehtävän suoritustilaa syöttämällä Hailuo Videos Generation API:n tuottama tehtävä-ID.

Tässä asiakirjassa käsitellään Hailuo Tasks API:n liittämistä, jotta voit helposti integroida ja hyödyntää tämän API:n voimakkaita ominaisuuksia. Hailuo Tasks API:n avulla voit helposti kysyä Hailuo Videos Generation API:n tehtävän suoritustilaa.

## Hakuprosessi

Hailuo Tasks API:n käyttämiseksi sinun on ensin mentävä hakusivulle [Hailuo Videos Generation API](https://platform.acedata.cloud/documents/ee06377b-9185-438f-ac84-3376bcb1275e) ja haettava vastaavaa palvelua, sitten kopioitava Hailuo Videos Generation API:n tehtävä-ID, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/4f9d95.png" width="500" className="m-auto" /></p>

Lopuksi siirry Tasks API -sivulle [Hailuo Tasks API](https://platform.acedata.cloud/documents/4b1ccdbc-b8ed-4171-9a14-48e10970ba04) ja hae vastaavaa palvelua, siirryttyäsi sivulle, napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![Hakusivu](https://cdn.acedata.cloud/rci31i.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti [kirjautumissivulle](https://platform.acedata.cloud), joka kutsuu sinua rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joita voit käyttää tämän API:n ilmaiseksi.

## Pyyntöesimerkki

Hailuo Tasks API:ta voidaan käyttää Hailuo Videos Generation API:n tulosten kysymiseen. Lisätietoja Hailuo Videos Generation API:n käytöstä löytyy asiakirjasta [Hailuo Videos Generation API](https://platform.acedata.cloud/documents/d2fc9087-2996-4573-bfe5-8b1c828fdfc7).

Otetaan esimerkki Hailuo Videos Generation API:n palvelusta palautetusta tehtävä-ID:stä ja näytetään, kuinka tätä API:a käytetään. Oletetaan, että meillä on tehtävä-ID: 58cc618b-9639-4ee7-add2-d2fcf260d9a3, seuraavaksi näytetään, kuinka syötetään tämä tehtävä-ID.

### Pyyntöotsikon ja -kehon asettaminen

**Request Headers** sisältää:

- `accept`: määrittää, että vastaanotetaan JSON-muotoisia vastauksia, tässä täytetään `application/json`.
- `authorization`: API:n avain, joka voidaan valita suoraan alasvetovalikosta hakemisen jälkeen.

**Request Body** sisältää:

- `id`: ladattu tehtävä-ID.
- `action`: tehtävän toimintatapa.

Aseta kuten alla olevassa kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/e9btl5.png" width="500" className="m-auto" /></p>

### Koodiesimerkki

Voit huomata, että sivun oikealla puolella on automaattisesti luotu koodia eri kielillä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/tfn261.png" width="500" className="m-auto" /></p>

Osittainen koodiesimerkki on seuraava:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/hailuo/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "58cc618b-9639-4ee7-add2-d2fcf260d9a3",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/hailuo/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "58cc618b-9639-4ee7-add2-d2fcf260d9a3",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajan.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
