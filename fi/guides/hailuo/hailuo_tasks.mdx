Hailuo Tasks API:n päätoiminto on kysyä tehtävän suoritustilaa syöttämällä Hailuo Videos Generation API:n tuottama tehtävä-ID.

Tässä asiakirjassa käsitellään Hailuo Tasks API:n liittämistä, jotta voit helposti integroida ja hyödyntää tämän API:n voimakkaita ominaisuuksia. Hailuo Tasks API:n avulla voit helposti kysyä Hailuo Videos Generation API:n tehtävän suoritustilaa.

## Hakuprosessi

Käyttääksesi Hailuo Videos Generation API:a, siirry ensin [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tunnuksesi, jota voit käyttää myöhemmin.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Valmiina palaat automaattisesti nykyiselle sivulle.

**Yksi API-tunnus riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jonka avulla voit kokeilla palvelua ilmaiseksi; kun määrä loppuu, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen asiakirja: [Hailuo Videos Generation API →](https://platform.acedata.cloud/documents/hailuo-videos-integration)

## Pyyntöesimerkki

Hailuo Tasks API:a voidaan käyttää Hailuo Videos Generation API:n tulosten kysymiseen. Lisätietoja Hailuo Videos Generation API:n käytöstä löytyy asiakirjasta [Hailuo Videos Generation API](https://platform.acedata.cloud/documents/hailuo-videos-generation-integration).

Otetaan esimerkki Hailuo Videos Generation API:n palauttamasta tehtävä-ID:stä, ja näytetään, kuinka tätä API:a käytetään. Oletetaan, että meillä on tehtävä-ID: 58cc618b-9639-4ee7-add2-d2fcf260d9a3, seuraavaksi näytetään, kuinka syötetään tämä tehtävä-ID.

### Pyyntöotsikon ja -kehon asettaminen

**Pyyntöotsikot** sisältävät:

- `accept`: määrittää, että vastaanotetaan JSON-muotoisia vastauksia, tässä täytetään `application/json`.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemuksen jälkeen.

**Pyyntökeho** sisältää:

- `id`: ladattu tehtävä-ID.
- `action`: tehtävän toimintatapa.

Aseta kuten alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/e9btl5.png" width="500" className="m-auto" /></p>

### Koodiesimerkki

Voit huomata, että sivun oikealla puolella on automaattisesti luotu koodia eri kielillä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/tfn261.png" width="500" className="m-auto" /></p>

Osittainen koodiesimerkki on seuraava:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/hailuo/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "58cc618b-9639-4ee7-add2-d2fcf260d9a3",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/hailuo/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "58cc618b-9639-4ee7-add2-d2fcf260d9a3",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Palautetussa tuloksessa on useita kenttiä, `request`-kenttä on se, joka sisältää tehtävän aloituksessa käytetyn pyyntökehon, ja `response`-kenttä on se, joka sisältää tehtävän valmistuttua palautetun vastauksen. Kenttien selitykset ovat seuraavat.

- `id`, tämän videotehtävän ID, jota käytetään tämän videon generointitehtävän yksilöimiseen.
- `request`, kyselyvideotehtävän pyyntöinformaatio.
- `response`, kyselyvideotehtävän palautusinformaatio.
- `created_at`, tehtävän luontiaika, Unix-aikaleima (sekunnit, liukuluku).
- `started_at`, tehtävän aloitusaika, Unix-aikaleima (sekunnit, liukuluku).
- `finished_at`, tehtävän valmistumisaika, Unix-aikaleima (sekunnit, liukuluku). Tätä kenttää ei palauteta, jos tehtävä ei ole valmis.
- `elapsed`, tehtävän suorittamiseen kulunut aika, yksikkönä sekunnit (liukuluku, 3 desimaalia). Tätä kenttää ei palauteta, jos tehtävä ei ole valmis.

## Virheiden käsittely

Kun kutsut API:ta, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki
