Tässä artikkelissa esitellään Hailuo Videos Generation API -integraatio-ohje, jonka avulla voidaan luoda Hailuo-virallisia videoita syöttämällä mukautettuja parametreja.

## Hakuprosessi

Hailuo Videos Generation API:n käyttämiseksi sinun on ensin mentävä [Ace Data Cloud -ohjauspaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tunnuksesi, joka kannattaa säilyttää.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Valmiina palat takaisin nykyiselle sivulle.

**Yksi API-tunnus riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen käyttöoikeuden, jonka avulla voit kokeilla palvelua ilmaiseksi; jos käyttöoikeus loppuu, voit ladata yleistä saldoa [ohjauspaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Hailuo Videos Generation API →](https://platform.acedata.cloud/documents/hailuo-videos-integration)

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, joka tarkoittaa, että syötät kehotteen `prompt`, generointitoiminnon `action`, ensimmäisen kehyksen viittauskuvan `first_image_url` sekä mallin `model`, jolloin saat käsitellyn tuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `action`-kenttä, jonka arvo on `generate`, ja sitten meidän on syötettävä malli. Tällä hetkellä käytettävissä ovat pääasiassa kuvasta videoksi -malli `minimax-i2v` ja tekstistä videoksi -malli `minimax-t2v`, tarkat tiedot ovat seuraavat:

<p><img src="https://cdn.acedata.cloud/7jyu0n.png" width="500" className="m-auto" /></p>

Voit nähdä, että olemme asettaneet pyyntöotsikot, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemuksen jälkeen.

Lisäksi olemme asettaneet pyyntökehon, joka sisältää:

- `model`: videon luomiseen käytettävä malli, pääasiassa kuvasta videoksi -malli `minimax-i2v` ja tekstistä videoksi -malli `minimax-t2v`.
- `action`: tämän videon luontitehtävän toiminto.
- `first_image_url`: kun valitaan kuvasta videoksi -malli `minimax-i2v`, on pakko ladata ensimmäisen kehyksen viittauskuvan linkki, Base64-koodaus ei ole tuettu.
- `prompt`: kehotteet.
- `callback_url`: URL, johon tulokset palautetaan.
- `async`: valinnainen, jos asetetaan `true`, rajapinta palauttaa heti `task_id`:n, eikä `callback_url`:ia tarvitse antaa, ja tulokset voidaan myöhemmin kysyä vastaavasta tehtäväkyselyrajapinnasta.

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/8psuxw.png" width="500" className="m-auto" /></p>

Napsauta "Kokeile" -painiketta testataksesi, kuten yllä olevassa kuvassa näkyy, saimme seuraavanlaisen tuloksen:

```json
{
  "success": true,
  "task_id": "baf1034c-684c-46be-ae6d-89ebb89b690d",
  "trace_id": "3221eb74-1a25-447a-ba69-7d9b310e306c",
  "data": [
    {
      "id": "0pv8yhe4fdrge0cmckpv23pd2g",
      "model": "minimax-t2v",
      "prompt": "Internal heat",
      "video_url": "https://platform.cdn.acedata.cloud/czjl/qoueLWBokF3ud6tdVD6VJTZuXTnK5HaMO2qAOS46Ef8VSBFUA/tmp9e3u11c1.output.mp4",
      "state": "succeeded"
    }
  ]
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `success`, tämänhetkisen videon luontitehtävän tila.
- `task_id`, tämänhetkisen videon luontitehtävän ID.
- `trace_id`, tämänhetkisen videon luontiseurannan ID.
- `data`, tämänhetkisen videon luontitehtävän tuloslista.
    - `id`, tämänhetkisen videon luontitehtävän videon ID.
    - `prompt`, tämänhetkisen videon luontitehtävän kehotteet.
    - `model`, tämänhetkisen videon luontitehtävän kansilinkki.
    - `video_url`, tämänhetkisen videon luontitehtävän videolinkki.
    - `state`, tämänhetkisen videon luontitehtävän tila.

Voit nähdä, että olemme saaneet tyydyttävää videoinformaatiota, ja meidän tarvitsee vain käyttää tuloksessa `data`-kentän videolinkkiä saadaksemme luodun Hailuo-videon.

Jos haluat luoda vastaavan integraatiokoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/hailuo/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "prompt": "Internal heat"
}'
```

## Asynkroninen palautus

Koska Hailuo Videos Generation API:n luomisaika on suhteellisen pitkä, noin 1-2 minuuttia, jos API ei vastaa pitkään aikaan, HTTP-pyyntö pitää yhteyden auki, mikä johtaa ylimääräisiin järjestelmäresurssien kulutuksiin. Siksi tämä API tarjoaa myös asynkronisen palautustuen.

Kokonaisprosessi on seuraava: asiakas käynnistää pyynnön, kun se määrittää ylimääräisen `callback_url`-kentän. Asiakas käynnistää API-pyynnön, ja API palauttaa heti tuloksen, joka sisältää `task_id`-kentän tiedot, joka edustaa nykyistä tehtävä ID:tä. Kun tehtävä on valmis, luodun videon tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`:iin, johon sisältyy myös `task_id`-kenttä, jolloin tehtävän tulos voidaan yhdistää ID:n avulla.

Katsotaanpa esimerkin avulla, miten tämä toimii.

Ensinnäkin Webhook-palaute on palvelu, joka voi vastaanottaa HTTP-pyyntöjä, ja kehittäjän tulisi korvata se omalla HTTP-palvelimensa URL-osoitteella. Tässä esimerkin vuoksi käytämme julkista Webhook-esimerkkisivustoa https://webhook.site/, avaa tämä sivusto saadaksesi Webhook URL:n, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/cjjfly.png)

Kopioi tämä URL, niin voit käyttää sitä Webhookina, tässä esimerkki on `https://webhook.site/580b81f5-596e-4321-b03f-606770b0bb83`.

Seuraavaksi voimme asettaa kentän `callback_url` yllä olevaan Webhook URL:iin ja täyttää vastaavat parametrit, tarkat tiedot ovat kuvassa näkyvät:

<p><img src="https://cdn.acedata.cloud/odabh3.png" width="500" className="m-auto" /></p>

Napsauta Suorita, ja voit huomata, että saat heti tuloksen, kuten seuraavassa:

```
{
  "task_id": "05aff65c-5e84-442b-8e29-3a5d27130840"
}
```

Odota hetki, ja voit tarkastella luodun videon tulosta osoitteessa `https://webhook.site/580b81f5-596e-4321-b03f-606770b0bb83`, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/7jngb4.png)

Sisältö on seuraava:
```json
{
    "success": true,
    "task_id": "05aff65c-5e84-442b-8e29-3a5d27130840",
    "trace_id": "b9856b8a-725d-45c9-befe-e789d9fd9ffb",
    "data": [
        {
            "id": "t80jhsf96srg80cmcm6b0rk8gm",
            "model": "minimax-t2v",
            "prompt": "Sisäinen lämpö",
            "video_url": "https://platform.cdn.acedata.cloud/czjl/YPaUz2DcwpJqItTXAG9XHAoEoj3dbF0XPU69LT5nefCMzBFUA/tmp8s_59jez.output.mp4",
            "state": "onnistui"
        }
    ]
}
```

Virheiden käsittely

Kun kutsut API:ta, jos kohtaat virheen, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "haku epäonnistui"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
