Tässä artikkelissa esitellään Hailuo Videos Generation API -integrointiohje, jonka avulla voidaan luoda Hailuon virallisia videoita syöttämällä mukautettuja parametreja.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [Hailuo Videos Generation API](https://platform.acedata.cloud/documents/ee06377b-9185-438f-ac84-3376bcb1275e) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, joka tarkoittaa, että syötät kehotteen `prompt`, generointitoiminnon `action`, ensimmäisen kuvan URL-osoitteen `first_image_url` sekä mallin `model`, jolloin saat käsitellyn tuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `action`-kenttä, jonka arvo on `generate`, ja sitten meidän on syötettävä malli. Tällä hetkellä käytettävissä ovat pääasiassa kuvasta videoon -malli `minimax-i2v` ja tekstistä videoon -malli `minimax-t2v`, tarkat tiedot ovat seuraavat:

<p><img src="https://cdn.acedata.cloud/7jyu0n.png" width="500" class="m-auto"></p>

Voit nähdä, että olemme asettaneet Request Headers -asetukset, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen tarvittava avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu Request Body, joka sisältää:

- `model`: videon luomiseen käytettävä malli, pääasiassa kuvasta videoon -malli `minimax-i2v` ja tekstistä videoon -malli `minimax-t2v`.
- `action`: tämän videon luontitehtävän toiminto.
- `first_image_url`: kun valitaan kuvasta videoon -malli `minimax-i2v`, on pakko ladata ensimmäisen kuvan URL-osoite, Base64-koodaus ei ole tuettu.
- `prompt`: kehotteet.
- `callback_url`: URL-osoite, johon tulokset palautetaan.

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/8psuxw.png" width="500" class="m-auto"></p>

Napsauta "Try" -painiketta, niin voit testata, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavanlaisen tuloksen:

```json
{
  "success": true,
  "task_id": "baf1034c-684c-46be-ae6d-89ebb89b690d",
  "trace_id": "3221eb74-1a25-447a-ba69-7d9b310e306c",
  "data": [
    {
      "id": "0pv8yhe4fdrge0cmckpv23pd2g",
      "model": "minimax-t2v",
      "prompt": "Internal heat",
      "video_url": "https://file.aigpai.com/czjl/qoueLWBokF3ud6tdVD6VJTZuXTnK5HaMO2qAOS46Ef8VSBFUA/tmp9e3u11c1.output.mp4",
      "state": "succeeded"
    }
  ]
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `success`, tämänhetkisen videon luontitehtävän tila.
- `task_id`, tämänhetkisen videon luontitehtävän ID.
- `trace_id`, tämänhetkisen videon luontitehtävän jäljitystunnus.
- `data`, tämänhetkisen videon luontitehtävän tuloslista.
  - `id`, tämänhetkisen videon luontitehtävän videon ID.
  - `prompt`, tämänhetkisen videon luontitehtävän kehotteet.
  - `model`, tämänhetkisen videon luontitehtävän kansilinkki.
  - `video_url`, tämänhetkisen videon luontitehtävän videon linkki.
  - `state`, tämänhetkisen videon luontitehtävän tila.

Voit nähdä, että olemme saaneet tyydyttävää videoinformaatiota, ja meidän tarvitsee vain käyttää tuloksessa olevan `data`-kentän videolinkkiä saadaksemme luodun Hailuo-videon.

Jos haluat luoda vastaavan integrointikoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/hailuo/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "prompt": "Internal heat"
}'
```

## Asynkroninen palautus

Koska Hailuo Videos Generation API:n luomisaika on suhteellisen pitkä, noin 1-2 minuuttia, jos API ei vastaa pitkään aikaan, HTTP-pyyntö pitää yhteyden auki, mikä johtaa ylimääräisiin järjestelmäresurssien kulutuksiin. Siksi tämä API tarjoaa myös asynkronisen palautuksen tuen.

Kokonaisprosessi on seuraava: asiakas lähettää pyynnön, kun se määrittää ylimääräisen `callback_url`-kentän. Kun asiakas lähettää API-pyynnön, API palauttaa heti tuloksen, joka sisältää `task_id`-kentän tiedot, joka edustaa nykyistä tehtävän ID:tä. Kun tehtävä on valmis, luodun videon tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`:iin, johon sisältyy myös `task_id`-kenttä, jolloin tehtävän tulos voidaan yhdistää ID:n avulla.

Katsotaanpa esimerkin avulla, miten tämä toimii.

Ensinnäkin, Webhook-palaute on palvelu, joka voi vastaanottaa HTTP-pyyntöjä, ja kehittäjän tulisi korvata se omalla HTTP-palvelimensa URL-osoitteella. Tässä esimerkin vuoksi käytämme julkista Webhook-esimerkkisivustoa https://webhook.site/, avaa tämä sivusto saadaksesi Webhook URL:n, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/cjjfly.png)

Kopioi tämä URL, niin voit käyttää sitä Webhookina, tässä esimerkki on `https://webhook.site/580b81f5-596e-4321-b03f-606770b0bb83`.

Seuraavaksi voimme asettaa kentän `callback_url` yllä olevaan Webhook URL:iin ja täyttää vastaavat parametrit, tarkat tiedot ovat seuraavat:

<p><img src="https://cdn.acedata.cloud/odabh3.png" width="500" class="m-auto"></p>

Napsauta Suorita, ja huomaat, että saat heti tuloksen, kuten seuraavassa:

```
{
  "task_id": "05aff65c-5e84-442b-8e29-3a5d27130840"
}
```

Odota hetki, niin voit tarkastella luodun videon tulosta osoitteessa `https://webhook.site/580b81f5-596e-4321-b03f-606770b0bb83`, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/7jngb4.png)

Sisältö on seuraava:

```json
{
    "success": true,
    "task_id": "05aff65c-5e84-442b-8e29-3a5d27130840",
    "trace_id": "b9856b8a-725d-45c9-befe-e789d9fd9ffb",
    "data": [
        {
            "id": "t80jhsf96srg80cmcm6b0rk8gm",
            "model": "minimax-t2v",
            "prompt": "Internal heat",
            "video_url": "https://file.aigpai.com/czjl/YPaUz2DcwpJqItTXAG9XHAoEoj3dbF0XPU69LT5nefCMzBFUA/tmp8s_59jez.output.mp4",
            "state": "succeeded"
        }
    ]
}
```

Voit nähdä, että tuloksessa on `task_id`-kenttä, ja muut kentät ovat samankaltaisia kuin edellä, tämän kentän avulla voit yhdistää tehtävät.

## Virheiden käsittely
API:ta kutsuttaessa, jos kohtaat virheen, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
